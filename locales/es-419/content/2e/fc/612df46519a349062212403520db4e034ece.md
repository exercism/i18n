# Introducción

## Explicación

Además de los tipos de datos primitivos como `number` y `string`, en JavaScript existe otro tipo de datos importante llamado `object`.
Los objetos son colecciones de pares clave-valor.
Como tales, se pueden usar como lo que en otros lenguajes suele llamarse mapas o diccionarios.

En otros lenguajes, a menudo todos los valores de un mapa deben tener el mismo tipo de datos.
En JavaScript, solo se restringe el tipo de la clave: tiene que ser un string.
Los valores dentro de un mismo objeto pueden tener tipos diferentes.
Pueden ser tipos primitivos como números, pero también arrays, otros objetos o incluso funciones.
Esto hace que los objetos sean muy versátiles, de modo que también son entidades clave para la [programación orientada a objetos][oop] (POO) en JavaScript.

En lo que sigue, nos centraremos en los objetos como colecciones o mapas. Otros usos de los objetos se tratarán en otros conceptos, por ejemplo en [Clases][concept-classes].

## Crear un objeto

Creas un objeto usando llaves.
También puedes incluir algunas entradas directamente.
Para eso, escribe primero la clave, seguida de dos puntos y el valor.

```javascript
const emptyObject = {};

const obj = {
  favoriteNumber: 42,
  greeting: 'Hello World',
  useGreeting: true,
  address: {
    street: 'Trincomalee Highway',
    city: 'Batticaloa',
  },
  fruits: ['melon', 'papaya'],
  addNumbers: function (a, b) {
    return a + b;
  },
};
```

La coma final después de la última entrada es opcional en JavaScript.

Quizá te preguntes por qué las claves no están entre comillas aunque se supone que son strings.
Es una notación abreviada.
Si la clave sigue las reglas de nombres de un [identificador][mdn-identifier] de JavaScript, puedes omitir las comillas.
Para las claves con caracteres especiales en el nombre, debes usar la notación habitual de string.

```javascript
const obj = {
  '1keyStartsWithNumber': '...',
  'key/with/slashes': '...',
  'key-with-dashes': '...',
  'key with spaces': '...',
  '#&()[]{}èä樹keyWithSpecialChars': '...',
};
```

## Obtener un valor

Hay dos maneras de obtener el valor de una clave dada: la notación de punto y la notación de corchetes.

```javascript
const obj = { greeting: 'hello world' };

obj.greeting;
// => hello world

obj['greeting'];
// => hello world

// Bracket notation also works with variables.
const key = 'greeting';
obj[key];
// => hello world
```

Usar la notación de punto como forma abreviada tiene la misma restricción que omitir las comillas.
Solo funciona si la clave sigue las reglas de nombres de los identificadores.
En otras palabras, si tu clave no es una sola palabra formada únicamente por letras, debes usar la notación de corchetes.

## Agregar o cambiar un valor

Puedes agregar o cambiar un valor usando el operador de asignación `=`.
De nuevo, tienes disponibles la notación de punto y la de corchetes.

```javascript
const obj = { greeting: 'hello world' };

obj.greeting = 'Hi there!';
obj['greeting'] = 'Welcome.';

obj.newKey1 = 'new value 1';
obj['new key 2'] = 'new value 2';

const key = 'new key 3';
obj[key] = 'new value 3';
```

## Eliminar una entrada

Puedes eliminar un par clave-valor de un objeto usando la palabra clave `delete`.

```javascript
const obj = {
  key1: 'value1',
  key2: 'value2',
};

delete obj.key1;
delete obj['key2'];
```

## Comprobar si existe una clave

Puedes comprobar si una determinada clave existe en un objeto con el método `hasOwnProperty`.

```javascript
const obj = { greeting: 'hello world' };

obj.hasOwnProperty('greeting');
// => true

obj.hasOwnProperty('age');
// => false
```

## Recorrer un objeto

Existe un bucle `for...in` especial para iterar sobre todas las claves de un objeto.

```javascript
const obj = {
  name: 'Ali',
  age: 65,
};

for (let key in obj) {
  console.log(key, obj[key]);
}
// name Ali
// age 65
```

Para evitar errores sutiles, siempre debes asumir que el bucle `for...in` recorre las claves en un orden arbitrario.
Además, ten en cuenta que `for...in` incluye [claves heredadas][concept-inheritance] en su iteración.
