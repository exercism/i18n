# Flujo de trabajo de configlet

Configlet usa la [herramienta configlet](/docs/building/configlet) para verificar que los archivos (de configuración) de un track estén correctamente estructurados, tanto sintáctica como semánticamente.
Para ello, ejecuta [`configlet lint`](/docs/building/configlet/lint).

## Activar la verificación del formato de los archivos

Los tracks pueden usar [`configlet fmt`](/docs/building/configlet/format) para dar formato a los distintos archivos de configuración del track.
El mismo comando también se puede usar para verificar que todos los archivos de configuración tengan el formato correcto.

El flujo de trabajo `configlet` admite verificar si los archivos de configuración tienen el formato correcto, pero esto es opcional y está desactivado de forma predeterminada.
Si quieres activar la verificación del formato de los archivos de configuración, sigue estos pasos:

1. Crea un archivo `.github/org-wide-files-config.toml` con el siguiente contenido

```toml
[configlet]
fmt = true
```

2. Una vez que este archivo se fusione en `main`, se abrirá automáticamente un PR que modifica el flujo de trabajo `configlet.yml` de la siguiente manera:

```diff
  jobs:
    configlet:
      uses: exercism/github-actions/.github/workflows/configlet.yml@main
+     with:
+       fmt: true
```

3. Una vez que se fusione este PR, el flujo de trabajo `configlet` también verificará el formato de los archivos de configuración del track.

## Fuente

El flujo de trabajo se define en el archivo `.github/workflows/configlet.yml`.
