# Introducción

Aunque el modificador `readonly` impide que se sobrescriba el valor o la referencia de un campo, no ofrece ninguna protección para los miembros de un tipo de referencia.

```csharp
readonly List<int> ints = new List<int>();

void Foo()
{
    ints.Add(1);    // ok
    ints = new List<int>(); // fails to compile
}
```

Para asegurar que todos los miembros de un tipo de referencia estén protegidos, los campos se pueden marcar como `readonly` y se pueden definir propiedades automáticas sin un descriptor de acceso `set`.

La biblioteca de clases base (BCL) proporciona algunas versiones de solo lectura de colecciones para cuando se necesita evitar que los miembros de una colección se actualicen. Estas vienen en forma de contenedores:

- `ReadOnlyDictionary<T>` expone un `Dictionary<T>` como de solo lectura.
- `ReadOnlyCollection<T>` expone un `List<T>` como de solo lectura.
