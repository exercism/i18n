# Anexo de instrucciones

## Nota

Este tipo de problemas (en los que una respuesta depende de una anterior) suelen recibir el nombre de recursión. Hay distintas maneras de programar la recursión; quizá valga la pena investigar al respecto si no la conoces. Pharo está bien optimizado para la recursión, y es un patrón que se usa mucho.

Nota: en la especificación original del problema, se llama a grainsCalculator mediante #square; sin embargo, hemos renombrado este método a #atSquare:, un nombre más al estilo de Smalltalk, que describe mejor que estás pidiendo una respuesta «en una casilla».
