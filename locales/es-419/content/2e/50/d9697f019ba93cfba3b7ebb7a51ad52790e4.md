# Introducción

En F#, asignar un valor a un nombre se conoce como _enlace_. Los enlaces son inmutables, lo que los hace similares a las constantes de otros lenguajes. Como F# es un lenguaje de tipado estático, cada enlace tiene un tipo en tiempo de compilación.

Los enlaces se definen con la palabra clave `let`. Especificar el tipo de un enlace es opcional para la mayoría de los enlaces, ya que la _inferencia de tipos_ de F# normalmente puede inferir el tipo a partir de su valor. Un enlace se ve así:

```fsharp
// Automatically inferred type
let fingers = 10
```

Las funciones también son enlaces normales, pero con uno o más parámetros. Una función devuelve automáticamente su última expresión. La inferencia de tipos también funciona para la mayoría de las funciones, analizando con qué valores se llama a la función y qué valor devuelve.

```fsharp
// Automatically inferred types for parameters and return type
let add x y = x + y
```

Para llamar a una función, se especifica su nombre y se pasan argumentos para cada parámetro de la función.

```fsharp
let five = add 2 3
```

Si no se puede inferir el tipo de un enlace, el compilador mostrará un error. Para solucionarlo, agrega una anotación de tipo explícita al enlace.

```fsharp
// Explicit type annotation
let fingers: int = 10

// Explicit type annotation (also for parameters)
let add (x: int) (y: int): int = x + y
```

Los enlaces en F# solo se pueden usar _después_ de que se hayan definido. Usar un enlace antes de que se haya definido da como resultado un error de compilación.

```fsharp
// Compile error as the add binding has not yet been defined
// let seven = add 3 4

let add x y = x + y
```

F# usa espacios en blanco significativos para definir el ámbito. Esto significa que el ámbito se define al indentar el código con espacios, en relación con la línea que declara el enlace. La convención predeterminada es usar cuatro espacios para la indentación:

```fsharp
let toes =
    let left = 5
    let right = 5
    left + right

let multiplyPlusTwo x y =
    let product = x * y
    product + 2

// Trying to access the left, right or product bindings
// here would result in a compile error
```

Los enlaces de F# (que incluyen funciones) normalmente se organizan en módulos. Un módulo agrupa funcionalidad relacionada y se define con la palabra clave `module`. La definición del módulo debe ir antes de sus enlaces:

```fsharp
module Calculator

let pi = 3.14

let add x y = x + y
```

F# admite dos tipos de comentarios. Los comentarios de una sola línea van precedidos por `//` y los comentarios multilínea se insertan entre `(*` y `*)`.
