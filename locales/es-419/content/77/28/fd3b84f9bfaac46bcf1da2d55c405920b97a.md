# Anexo de instrucciones

## Instrucciones específicas del track

Necesitas definir dos verbos llamados `allergic_to` y `list`.

## Argumentos

1. El verbo `allergic_to` es una **díada**, donde:

    - **Argumento izquierdo**: es un string que contiene el nombre del alérgeno.
    - **Argumento derecho**: es el puntaje obtenido.

1. El verbo `list` es una **mónada**, donde:

    - El único argumento es el puntaje obtenido.

Tus verbos se llamarán con estos argumentos de esta manera:

```j
  'cats' allergic_to 255
  list 5
```

## Salidas

La salida del verbo `allergic_to` es un **booleano**

La salida de `list` es una **lista de cajas**
