# Anexo de instrucciones

## Proceso de IO

A diferencia de otros ejercicios, `grep` requiere interactuar con el «mundo externo»: leer archivos, manejar errores del sistema e imprimir en `stdout`.

En Lean, la interacción con el sistema suele hacerse en la mónada [IO][io], que permite que ocurran efectos secundarios en un entorno contenido sin afectar el estado puro de la mayoría de las demás funciones.

## Lectura de argumentos

Lean permite llamar a un archivo como script, ya sea directamente como un script independiente con `lean --run` o mediante el uso de `lake`.

Un proyecto de Lean tiene un único punto de entrada, una función llamada `main`, que recibe una `List String` con todos los argumentos que se le pasan.
Para simular la ejecución de `Grep.lean` como un ejecutable, en este ejercicio los argumentos se pasan de la misma manera.

## Lectura de archivos

Lean ofrece [funciones][files] para manipular archivos en la mónada `IO.FS`.
Por ejemplo, `IO.FS.readFile` se puede usar para leer el contenido de un archivo en una ruta dada, como `String`.

## Escritura de la salida

En lugar de devolver un valor, este ejercicio requiere que los resultados se escriban en la salida estándar o en la salida de errores.
Lean tiene [funciones][console] para este propósito.

## Manejo de errores del sistema

A diferencia de los errores en `Except`, las excepciones de `IO` son en realidad excepciones en tiempo de ejecución.
Puedes usar `try`/`catch` para manejarlas:

```
try
    /- 
        code that may possibly raise an exception 
    -/
catch msg =>
    /-
        code that is executed only if an exception was thrown
    -/
```
