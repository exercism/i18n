# Introducción

## Funciones

En Gleam, las funciones se definen con la sintaxis `pub fn`.

```gleam
pub fn add(x: Int, y: Int) -> Int {
  x + y
}
```

Esta función recibe dos argumentos, ambos de tipo `Int`, y devuelve un valor de tipo `Int`. En Gleam no existe la palabra clave `return`: el valor de la última expresión de una función siempre se _devuelve de forma implícita_.

Las anotaciones de tipo para los argumentos y el tipo de retorno son opcionales, y Gleam siempre verificará por completo los tipos de tu código. Por lo general, quienes programan en Gleam anotan los tipos de sus funciones para mayor claridad, pero puedes omitirlas si lo prefieres.

```gleam
pub fn add(x, y) {
  x + y
}
```

Puedes llamar a una función con la sintaxis `function_name(argument1, argument2)`.

```gleam
pub fn double(x: Int) -> Int {
  // Call the add function defined above
  add(x, x)
}
```

## Variables

En Gleam, las variables se definen con la sintaxis `let name = expression`.

```gleam
pub fn main() {
  let count = 1
}
```

Las variables se pueden declarar con anotaciones de tipo. Al igual que los argumentos de una función, son opcionales, aunque la mayoría de quienes programan en Gleam omiten las anotaciones de tipo en las variables por brevedad.

```gleam
pub fn main() {
  let count: Int = 1
}
```

## Literales de string

En Gleam, los strings se escriben entre comillas dobles.

```gleam
pub fn greeting() {
  "Hello, world!"
}
```

## Comentarios en el código

Los comentarios sirven para dejar notas a otras personas que lean el código fuente. En Gleam, los comentarios son líneas individuales precedidas por `//`.

```gleam
pub fn main() {
  // This is a comment
  let x = 1
}
```
