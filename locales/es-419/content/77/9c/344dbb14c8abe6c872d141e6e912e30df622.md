# Apéndice de instrucciones

## Pistas

Para completar este ejercicio, necesitas crear el tipo de datos `ForthState`
e implementar las siguientes funciones:

- `emptyState` devuelve un `ForthState` vacío.
- `evalText` evalúa un argumento de tipo Text y devuelve el nuevo estado.
- `toList` devuelve la pila actual como una lista, donde el elemento que está
en la parte superior de la pila es el elemento más a la derecha (el último).

Encontrarás una declaración de datos ficticia y las firmas de tipo ya en su
lugar, pero depende de ti definir las funciones y crear un tipo de datos, un
newtype o un sinónimo de tipo que tenga sentido.
