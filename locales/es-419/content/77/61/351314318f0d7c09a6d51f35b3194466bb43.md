# Instrucciones

En este ejercicio ayudas a tu hermana menor a corregir su ensayo para la escuela. El maestro busca puntuación y gramática correctas, y una excelente elección de palabras.

Tienes cuatro tareas para limpiar y modificar strings.

## 1. Capitalizar el título del ensayo

Todo buen ensayo necesita un título con el formato correcto.
Implementa la función `capitalize_title(<title>)` que toma como parámetro un título de tipo `str` y pone en mayúscula la primera letra de cada palabra.
Esta función debe devolver un `str` en formato de título.


```python
>>> capitalize_title("my hobbies")
"My Hobbies"
```

## 2. Comprobar si cada oración termina con un punto

Quieres asegurarte de que la puntuación del ensayo sea perfecta.
Implementa la función `check_sentence_ending()` que toma `sentence` como parámetro. Esta función debe devolver un `bool`.


```python
>>> check_sentence_ending("I like to hike, bake, and read.")
True
```

## 3. Limpiar el espaciado

Para que el ensayo se vea profesional, hay que eliminar el espaciado innecesario.
Implementa la función `clean_up_spacing()` que toma `sentence` como parámetro.
La función debe eliminar los espacios en blanco adicionales tanto al principio como al final de la oración, y devolver una nueva oración actualizada de tipo `str`.


```python
>>> clean_up_spacing(" I like to go on hikes with my dog.  ")
"I like to go on hikes with my dog."
```

## 4. Reemplazar palabras por un sinónimo

Para que el ensayo sea _aún mejor_, puedes reemplazar algunos de los adjetivos por sus sinónimos.
Escribe la función `replace_word_choice()` que toma `sentence`, `old_word` y `new_word` como parámetros.
Esta función debe reemplazar todas las apariciones de `old_word` por `new_word`, y devolver un nuevo `str` con la oración actualizada.


```python
>>> replace_word_choice("I bake good cakes.", "good", "amazing")
"I bake amazing cakes."
```
