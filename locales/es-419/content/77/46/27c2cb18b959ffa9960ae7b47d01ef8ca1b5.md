# Pistas

## General

- El paquete [`roc-random`](https://github.com/kili-ilo/roc-random) está disponible con el alias `random` en la app de pruebas.
  El stub importa `random.Random`.

- Un `Random.Generator(a)` describe cómo generar un valor de tipo `a`.

- Usa `Random.list` para combinar extracciones y `Random.map` para transformar sus resultados.

- `Random.step(state, generator)` devuelve `{ value, state }`; lleva el estado actualizado entre los grupos simulados para que no repitas la misma muestra.
