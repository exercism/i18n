# Acerca de

[D](https://dlang.org) es un lenguaje de programación de sistemas con
sintaxis similar a C y tipado estático. Combina eficiencia, control y potencia de modelado con seguridad
y productividad del programador. El lenguaje fue desarrollado originalmente por [Walter Bright](https://en.wikipedia.org/wiki/Walter_Bright) y [Andrei
Alexandrescu](https://en.wikipedia.org/wiki/Andrei_Alexandrescu) a partir de la versión 2 de D.

D es el resultado de décadas de experiencia implementando compiladores para muchos lenguajes diversos, y tiene una gran cantidad
de [características únicas](http://dlang.org/overview.html):

- construcciones de alto nivel para una gran potencia de modelado
- alto rendimiento, lenguaje compilado
- tipado estático
- evolución de C++ (sin los errores)
- interfaz directa con las API del sistema operativo y el hardware
- tiempos de compilación increíblemente rápidos
- permite programación segura en cuanto a memoria (SafeD)
- código mantenible y fácil de entender.
- curva de aprendizaje corta (sintaxis similar a C, parecida a Java y otros)
- compatible con la interfaz binaria de aplicaciones de C
- multiparadigma (imperativo, estructurado, orientado a objetos, genérico, pureza de programación funcional e incluso ensamblador)
- prevención de errores integrada (contratos, pruebas unitarias)

La [D Language Foundation](https://dlang.org/foundation.html) es la organización dedicada a desarrollar y
hacer avanzar el lenguaje D.
