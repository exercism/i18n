# Instrucciones

Te han encargado escribir un servicio que recibe eventos. Cada evento tiene una fecha asociada, pero notas que se están enviando 3 formatos diferentes al endpoint de tu servicio:

- `"01/01/1970"`
- `"January 1, 1970"`
- `"Thursday, January 1, 1970"`

Puedes ver que hay algunas similitudes entre cada uno de ellos, así que decides escribir algunos patrones de expresiones regulares componibles.

## 1. Haz coincidir el día, el mes y el año de una fecha

Implementa `day/0`, `month/0` y `year/0` para que devuelvan un patrón de cadena que, al compilarse, coincida con los componentes numéricos de `"01/01/1970"` (`dd/mm/yyyy`). El día y el mes pueden aparecer como `1` o `01` (rellenados por la izquierda con ceros).

```elixir
"31" =~ DateParser.day() |> Regex.compile!()
# => true
"12" =~ DateParser.month() |> Regex.compile!()
# => true
"1970" =~ DateParser.year() |> Regex.compile!()
# => true
```

## 2. Haz coincidir el día de la semana y el mes del año

Implementa `day_names/0` y `month_names/0` para que devuelvan un patrón de cadena que, al compilarse, coincida con el nombre del día de la semana y el nombre del mes del año, respectivamente.

```elixir
"Tuesday" =~ DateParser.day_names() |> Regex.compile!()
# => true
"June" =~ DateParser.month_names() |> Regex.compile!()
# => true
```

## 3. Captura el día, el mes y el año

Implementa `capture_day/0`, `capture_month/0`, `capture_year/0`, `capture_day_name/0`, `capture_month_name/0` para que devuelvan un patrón de cadena que capture los componentes respectivos con los nombres: `"day"`, `"month"`, `"year"`, `"day_name"`, `"month_name"`

```elixir
DateParser.capture_month_name()
|> Regex.compile!()
|> Regex.named_captures("December")

# => %{"month_name" => "December"}
```

## 4. Combina las capturas para capturar la fecha completa

Implementa `capture_numeric_date/0`, `capture_month_name_date()`, y `capture_day_month_name_date/0` para que devuelvan un patrón de cadena que capture los componentes de la parte 3 usando el formato de fecha correspondiente:

- fecha numérica - `"01/01/1970"`
- fecha con nombre de mes - `"January 1, 1970"`
- fecha con nombre de día y de mes - `"Thursday, January 1, 1970"`

```elixir
DateParser.capture_numeric_date()
|> Regex.compile!()
|> Regex.named_captures("01/01/1970")

# => %{"day" => "01", "month" => "01", "year" => "1970"}
```

## 5. Restringe la captura para que coincida solo con la fecha

Implementa `match_numeric_date/0`, `match_month_name_date/0` y `match_day_month_name_date/0` para que devuelvan una expresión regular compilada que solo coincida con la fecha y que además pueda capturar los componentes.

```elixir
"Thursday, January 1, 1970 was the Unix epoch." =~ DateParser.match_day_month_name_date()
# => false
"Thursday, January 1, 1970" =~ DateParser.match_day_month_name_date()
# => true

DateParser.match_day_month_name_date()
|> Regex.named_captures("Thursday, January 1, 1970")

# => %{
#     "day" => "1",
#     "day_name" => "Thursday",
#     "month_name" => "January",
#     "year" => "1970"
#   }
```
