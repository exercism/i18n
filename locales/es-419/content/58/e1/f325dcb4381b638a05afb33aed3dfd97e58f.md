# Pistas

## 1. Comprueba si un valor es de tipo Boolean

- Puedes usar `typeof` para averiguar el tipo de un valor.
- `typeof` devuelve un string.

## 2. Comprueba si un valor es un número.

- Puedes usar `typeof` para averiguar el tipo de un valor.
- `typeof` devuelve un string.
- Debes comprobar `Infinity` y `NaN`.
- `NaN` nunca es igual a sí mismo, pero existe una [función integrada][isNaN] para comprobar si un valor es `NaN`.

## 3. Comprueba si un valor es un objeto

- Puedes usar `typeof` para averiguar el tipo de un valor.
- `typeof` devuelve un string.
- Tendrás que comprobar `null`.

## 4. Comprueba si un string es numérico

- Puedes usar `typeof` para averiguar el tipo de un valor.
- `typeof` devuelve un string.
- Puedes recorrer un string para comprobar si todos sus caracteres son dígitos.

## 5. Comprueba si un objeto es electrónico

- Puedes usar `instanceof` para comprobar si un objeto es una instancia de una clase o de una de sus clases hijas.

## 6. Comprueba si un valor es un array no vacío

- Puedes usar `typeof` para averiguar el tipo de un valor.
- `typeof` devuelve un string.
- Puedes comprobar la longitud de un array para saber cuántos elementos contiene.

## 7. Comprueba si un valor es un array vacío

- Puedes usar `typeof` para averiguar el tipo de un valor.
- `typeof` devuelve un string.
- Puedes comprobar la longitud de un array para saber cuántos elementos contiene.

## 8. Comprueba si un objeto tiene una propiedad o un método `type`

- Puedes usar el operador `in` para comprobar si un objeto tiene una propiedad o un método.

## 9. Lanza un error si un objeto no tiene la propiedad o el método `id`

- Puedes usar el operador `in` para comprobar si un objeto tiene una propiedad o un método.
- Si falta la propiedad o el método `id`, tu función debe lanzar un `Error`.

## 10. Comprueba si un objeto tiene una propiedad `id`

- Para comprobar si un objeto tiene una propiedad (y no un método), puedes usar la función `Object.hasOwn()`.

## 11. Comprueba si un objeto tiene una propiedad `type` definida

- Para comprobar si un objeto tiene una propiedad (y no un método), puedes usar la función `Object.hasOwn()`.
- Tendrás que acceder a la propiedad `type` y comprobar si está definida.

[isNaN]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/isNaN
