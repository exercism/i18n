# Introducción

En general, no quieres reinventar la rueda cuando se trata de programación. Para muchos algoritmos estándar, es posible que alguien ya haya hecho el trabajo por ti.

## Inclusión de archivos

Para incluir el contenido de otros archivos, C++ usa la directiva `include`. Estas inclusiones deben declararse al principio del archivo. Durante la compilación, la línea con la directiva se reemplaza por el contenido del archivo correspondiente. Después de las inclusiones, los espacios de nombres se mantienen tal como están en el archivo original.

## La biblioteca estándar

La biblioteca estándar ofrece muchas funciones, algoritmos y estructuras de datos comunes. La biblioteca estándar usa el espacio de nombres `std`.

Un ejemplo es la biblioteca numérica de C, `cmath`. Proporciona muchas operaciones matemáticas comunes.

```cpp
#include <cmath>

int cube_me(int a) {
    // raise `a` to the third power
    return std::pow(a, 3);
}
```

~~~~exercism/note
Las bibliotecas estándar se incluyen con paréntesis angulares `<>` en lugar de comillas dobles `"`. La diferencia está en la ubicación donde el compilador busca los archivos correspondientes. Con la versión de paréntesis angulares, se omite la búsqueda en el proyecto actual y se empieza directamente en los directorios de inclusión del sistema. Si quieres incluir archivos locales, usarías comillas dobles: `#include "myfile"`
~~~~
