# parámetro obligatorio inesperado

En los tests, se llama al parámetro `${'parameter.name'}` con y sin un valor, pero _no está marcado como opcional_, lo que significa que los tests no pasarán. Un parámetro de TypeScript se puede marcar explícitamente como opcional con el sufijo `?`:

```typescript
function(${'parameter.name'}?: ${'parameter.type'}) {
  //
}
```

O, como alternativa, asignándole un valor por defecto:

```typescript
function(${'parameter.name'}: ${'parameter.type'} = <default>) {
  //
}
```
