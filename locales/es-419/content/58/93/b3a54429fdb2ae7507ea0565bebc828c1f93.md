# Acerca de

Las [guardas][guards] se usan como complemento de la [coincidencia de patrones][exercism-pattern-matching], que veremos en un concepto posterior.
Las guardas nos permiten tener distintas implementaciones de una función según el valor del argumento.
También permiten hacer comprobaciones más complejas.

Una sentencia de guarda se define con una barra vertical `|` seguida de una expresión booleana, y termina con un signo igual `=` y el cuerpo de la función.
Puede haber varias sentencias de guarda para una misma función.
Las sentencias de guarda se evalúan de arriba hacia abajo, y se ejecuta la primera que evalúe a `True`.
Una sentencia de guarda permite incluir una sentencia `otherwise`, que sirve de comodín para cualquier valor que no coincida con las sentencias de guarda anteriores.

```haskell
isEven :: Int -> String
isEven n
    | even n = "n is even"
    | otherwise = "n is odd"
```

También podemos definir nuestra función y usarla dentro de la sentencia de guarda.

```haskell
isEven' :: Int -> Bool
isEven' n = even n

isEven :: Int -> String
isEven n
    | isEven' n = "n is even"
    | otherwise = "n is odd"
```
