# Conversión de tipos

Cairo admite la conversión de tipos mediante los traits `Into` y `TryInto` de la biblioteca core, que se usan habitualmente tanto con tipos integrados como con tipos personalizados.

Estos traits definen métodos para convertir valores entre tipos:  

- **`Into`**: se usa para conversiones garantizadas e infalibles.  
- **`TryInto`**: se usa para conversiones que pueden fallar y devuelve `Option<T>`.

## Cómo usar `Into`

`Into` se encarga de las conversiones en las que el tipo de destino siempre puede albergar el valor de origen.

```rust
fn main() {
    let my_u8: u8 = 10;
    let my_felt252: felt252 = my_u8.into(); // Infallible conversion
    let my_u256: u256 = my_felt252.into(); // Conversion to larger types
}
```

## Cómo usar `TryInto`

`TryInto` es para los casos en los que la conversión puede fallar y devuelve `Option<T>`.

```rust
fn main() {
    let my_u256: u256 = 10;
    let my_felt252: felt252 = my_u256.try_into().unwrap(); // Success
    let my_large_u16: u16 = 2048;
    let my_large_u8: u8 = my_large_u16.try_into().unwrap(); // Panics because value doesn't fit in `u8`
}
```

## Conversión de tipos personalizados

Puedes implementar estos traits para tus propios tipos.  

### Ejemplo: `Into`

```rust
#[derive(Drop)]
struct Rectangle {
    width: u64,
    height: u64,
}

#[derive(Drop)]
struct Square {
    side_length: u64,
}

impl SquareIntoRectangle of Into<Square, Rectangle> {
    fn into(self: Square) -> Rectangle {
        Rectangle { width: self.side_length, height: self.side_length }
    }
}
```

### Ejemplo: `TryInto`

```rust
impl RectangleIntoSquare of TryInto<Rectangle, Square> {
    fn try_into(self: Rectangle) -> Option<Square> {
        if self.height == self.width {
            Option::Some(Square { side_length: self.height })
        } else {
            Option::None
        }
    }
}
```

Esta configuración ofrece conversiones flexibles y con seguridad de tipos tanto para los tipos integrados como para los personalizados en Cairo.
