# Hints

## 1. Permitir cambiar el tiempo esperado en el horno

- Los [valores predeterminados de los parámetros][default-parameter-values] se pueden especificar en la firma de la función.
- La especificación del valor predeterminado se coloca después de la anotación de tipo del parámetro.

## 2. Permitir diferentes cantidades de capas

- Los [parámetros variádicos][variadic-parameters] se pueden especificar en la firma de la función.
- La notación del parámetro variádico se coloca después del nombre del tipo del parámetro.
- El parámetro variádico de un tipo _T_ será accesible en el cuerpo de la función como un array cuyos elementos son de tipo _T_.
  \_ Puedes obtener el número de elementos de un array llamado `items` accediendo a la propiedad count. Es decir, `items.count`.

## 3. Calcular las cantidades de fideos y salsa

- [Se pueden devolver varios valores desde una función][multiple-return-values] usando una tupla para combinarlos en un único valor compuesto.

## 4. Convertir litros a onzas líquidas en el lugar

- Los [parámetros de entrada y salida][in-out-parameters] se pueden especificar colocando `inout` antes del nombre del tipo del parámetro.
- El nuevo valor debe asignarse al parámetro antes de que la función devuelva, para que se pueda copiar en la variable que se pasó.

## 5. Determinar el mejor vino para servir

- Las funciones se pueden [anidar][nested-functions] dentro de otra función declarando una función, como es normal, dentro de otra función.
- Las funciones anidadas se pueden llamar como es normal dentro de las funciones en las que están definidas.
- Las funciones anidadas tienen acceso a todos los parámetros, constantes y variables de la función que las rodea. No es necesario pasárselos a la función anidada.
