# Pistas

## General

- Usa el [tipo de lista (enlazada)][list] integrado.

## 1. Define una función que devuelva una lista de lenguajes vacía

- La función debe devolver `[]`.

## 2. Define una función que agregue un lenguaje a la lista

- Puedes anteponer un elemento a una lista usando `|`.

## 3. Define una función que elimine un lenguaje de la lista

- Elixir [proporciona una función][tl] para devolver una lista sin el primer elemento.

## 4. Define una función que devuelva el primer elemento de la lista

- Elixir [proporciona una función][hd] para obtener el primer elemento de una lista.

## 5. Define una función que devuelva cuántos lenguajes hay en la lista

- Elixir [proporciona una función][length] para contar la longitud de una lista.

## 6. Define una función que determine si la lista incluye un lenguaje funcional

- Tu función debe devolver un valor Boolean que indique si `"Elixir"` es un miembro de la lista. Elixir [proporciona una función][in] para comprobar si un elemento pertenece a la lista.
