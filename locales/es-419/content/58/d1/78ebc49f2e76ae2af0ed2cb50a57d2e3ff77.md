# Introducción

Un *conjunto disjunto* (una estructura union-find) mantiene una colección de valores dividida en grupos que no se superponen, y responde rápidamente una pregunta: ¿estos dos valores están en el mismo grupo? Vive en el vocabulario [`disjoint-sets`][disjoint-sets].

## Cómo construir un conjunto disjunto

`<disjoint-set>` construye una estructura vacía. Los valores (los *átomos*) se agregan con `add-atom` uno a la vez, o con `add-atoms` a partir de una secuencia. Cada átomo empieza en un grupo propio.

```
<disjoint-set> ( -- disjoint-set )
add-atom       ( atom disjoint-set -- )
add-atoms      ( seq disjoint-set -- )
```

```factor
USING: disjoint-sets ;

<disjoint-set>
{ 1 2 3 } over add-atoms   ! 1, 2 and 3 each in their own group
```

El conjunto disjunto es *mutable*: `add-atom`, `add-atoms` y `equate` lo modifican en el lugar en vez de devolver uno nuevo. `keep` es útil cuando quieres que el conjunto disjunto vuelva a quedar en la pila después de que una de esas palabras lo haya consumido.

## Cómo unir grupos

`equate` une los dos grupos que contienen sus átomos. La unión es transitiva: iguala dos átomos y luego uno de ellos con un tercero, y los tres terminan en un solo grupo.

```
equate ( atom1 atom2 disjoint-set -- )
```

## Representantes

Cada grupo tiene un miembro canónico, su *representante*. `representative` lo devuelve, y dos átomos pertenecen al mismo grupo exactamente cuando sus representantes son iguales.

```
representative ( atom disjoint-set -- representative )
```

```factor
USING: disjoint-sets ;

<disjoint-set>
{ 1 2 3 } over add-atoms
1 2 pick equate
1 over representative .   ! => 1
2 over representative .   ! => 1   (same representative as 1)
3 over representative .   ! => 3   (still on its own)
```

Cuál átomo elige un grupo como su representante es un detalle interno: nunca dependas de que se elija un átomo en particular, solo de que dos átomos del mismo grupo coincidan.
