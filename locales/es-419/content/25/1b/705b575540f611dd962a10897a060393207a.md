# Acerca de

Una [tupla](https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/tuples) es una agrupación _inmutable_ de valores sin nombre pero ordenados.
Las tuplas pueden contener cualquier tipo de dato (o varios), incluidas otras tuplas.

Las tuplas se definen como valores separados por comas entre los caracteres `(` y `)`: `(<element_1>, ... , <element_n>)`.

```fsharp
("one", 2) // Tuple pair (2 values)
("one", 2, true) // Tuple triplet (3 values)
```

Solo se pueden comparar las tuplas que tienen la misma longitud y los mismos tipos (en el mismo orden).
Las tuplas tienen igualdad estructural, lo que significa que son iguales _solo_ si todos sus valores son iguales.

```fsharp
(1, 2) = (1, 2) // Same length, same types, same values, same order
// => true

(1, 2) = (2, 1) // Same length, same types, same values, different order
// => false

(1, 2) = (1, "2") // Same length, different types
// compiler error

(1, 2) = (1, 2, 3) // Different length
// compiler error
```

Existen [tres formas de extraer valores de una tupla](https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/tuples#obtaining-individual-values):

- Las funciones `fst` y `snd`
- La deconstrucción de tuplas
- La coincidencia de patrones

```fsharp
let person = ("Jordan", 170)

// Option 1: fst/snd
let name1 = fst person
let length1 = snd person

// Option 2: deconstruction
let (name2, length2) = person

// Option 3: pattern matching
match person with
| name3, length3 -> printf "%s: %d" name3 length3
```

~~~~exercism/note
Técnicamente, puedes acceder al valor de una tupla usando sus propiedades `.Item1`, `.Item2`, ..., pero esto no es recomendable y genera una advertencia del compilador.
~~~~

## Puntos clave sobre las tuplas

Algunas cosas clave que debes saber sobre las tuplas son:

- Una instancia concreta de un tipo de tupla es un solo objeto, similar, por ejemplo, a un array de dos elementos en C#. Cuando las usas con funciones, cuentan como un solo parámetro. La única excepción es cuando llamas a código que no es de F# con varios parámetros; en ese caso pasas una tupla y sus valores se extraen automáticamente al valor del parámetro correspondiente.
- A los tipos de tupla no se les pueden dar nombres explícitos. El «nombre» del tipo de tupla lo determina la combinación de tipos que se multiplican entre sí.
- La coma es el símbolo fundamental que define las tuplas, no los paréntesis. Puedes definir tuplas sin los paréntesis, aunque a veces puede resultar confuso. En F#, si ves una coma, probablemente sea parte de una tupla.
- Las tuplas se pueden usar como argumentos de una función y como valor de retorno de una función.
