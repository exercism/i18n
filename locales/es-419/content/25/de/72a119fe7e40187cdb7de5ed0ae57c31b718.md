# Apéndice de instrucciones

## Registros

| Registro | Uso       | Tipo    | Descripción                       |
| -------- | --------- | ------- | --------------------------------- |
| `$a0`    | entrada   | entero  | x                                 |
| `$a1`    | entrada   | entero  | y                                 |
| `$v0`    | salida    | entero  | puntos obtenidos                  |
| `$t0-9`  | temporal  | cualquiera | usado para almacenamiento temporal |
