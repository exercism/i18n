# Instrucciones

Trabajas con un equipo de desarrollo web para mantener un sitio web de un equipo de básquetbol local. El equipo de desarrollo web no está muy familiarizado con Elixir y te pide una función que permita extraer datos de una serie de mapas anidados para facilitar el desarrollo rápido.

## 1. Extraer datos de una estructura de mapas anidados

Implementa la función `extract_from_path/2` para que reciba dos argumentos:

- `data`: una estructura de mapas anidados con datos sobre el equipo de básquetbol.
- `path`: un string formado por claves separadas por puntos para obtener el valor asociado con la última clave.

Si el valor o la clave no existen en ningún punto de la ruta, se debe devolver `nil`

```elixir
data = %{
  "team_mascot" => %{
    "animal" => "bear",
    "actor" => %{
      "first_name" => "Noel"
    }
  }
}

BasketballWebsite.extract_from_path(data, "team_mascot.animal")
# => "bear"
BasketballWebsite.extract_from_path(data, "team_mascot.colors")
# => nil
```

Usa el _Access Behaviour_ al implementar esta función.

No uses ninguna función de los módulos `Map` o `Kernel` para trabajar con la estructura de mapas anidados.

## 2. Refactoriza usando las funciones incluidas

Tu compañero de trabajo, que revisa tu código, te habla de una función del módulo `Kernel` que hace algo muy similar a tu implementación.

Implementa `get_in_path/2` para usar esta función del módulo `Kernel`.

Los argumentos esperados son los mismos que en la parte 1.

```elixir
BasketballWebsite.get_in_path(data, "team_mascot.actor.first_name")
# => "Noel"
```
