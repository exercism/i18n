# Introducción

## Variables de instancia

Los objetos pueden guardar su propio estado al definir _variables de instancia_.
Estas variables viven dentro de un objeto y normalmente se usan para almacenar algún estado interno.

Las variables de instancia siempre empiezan con un `@`.
Puedes crear una nueva variable de instancia al asignar una variable que empiece con `@`.
Por ejemplo:

```ruby
class Repeater
  def hear(something)
    # Save what's been heard into a new instance variable called @heard
    @heard = something
  end

  def repeat
    # Return the value of the instance variable
    @heard
  end
end

repeater = Repeater.new
repeater.hear("Hello, friend!")
print repeater.repeat # Prints "Hello, friend!"
```

Por lo general, los objetos establecen su estado inicial en un método `initialize`, el cual se llama automáticamente cuando llamas a `new` en una clase.

```ruby
class Airplane
  def initialize
    @wings = 2
  end

  def wings
    @wings
  end
end

plane = Airplane.new
plane.wings # returns 2
```

El método `initialize` también puede recibir argumentos, para que cada instancia pueda empezar con un estado personalizado:

```ruby
class Suitcase
  def initialize(locked)
    @locked = locked
  end
end
```

Es una buena práctica considerar las variables de _instancia_ como privadas frente a lecturas y escrituras externas.
En su lugar, definimos métodos para obtener y establecer sus valores.
Por ejemplo:

```ruby
class Suitcase
  def initialize
    @locked = false
  end

  def locked? # Query methods should be named with a trailing `?`
    @locked
  end

  def lock! # Methods which mutate state should have trailing `!`
    @locked = true
  end
end

suitcase = Suitcase.new
suitcase.locked? # false
suitcase.lock!
suitcase.locked? # true
```

## Nil

[Nil][nil-dictionary] es una palabra en inglés que significa «nada» o «cero».
En Ruby, `nil` se usa para expresar la _ausencia_ de un objeto.
En otros lenguajes de programación, los valores `null` o `none` pueden cumplir un papel similar.

```ruby
# I do not have a favorite color
favorite_color = nil
```

Ruby le da a cualquier variable de instancia el valor predeterminado de `nil` cuando se encuentra por primera vez, hasta que se le asigne otro valor.

```ruby
print @favourite_color # prints nil
@favourite_color = "blue"
print @favourite_color # prints "blue"
```
