# Introducción

El flujo de control en Cairo, mediante construcciones como las expresiones `if` y los bucles, te permite dirigir la ejecución de tus programas según una lógica condicional o tareas repetitivas.
Las expresiones `if` permiten bifurcar la ejecución según si las condiciones se evalúan como `true` o `false`, mientras que los bucles (`loop`, `while`, `for`) facilitan la ejecución repetida de bloques de código hasta que se cumplen ciertos criterios.
Estas construcciones son fundamentales para implementar lógica, iteración y manejar múltiples condiciones de forma concisa, lo que las convierte en herramientas esenciales para escribir código eficiente y dinámico en Cairo.
