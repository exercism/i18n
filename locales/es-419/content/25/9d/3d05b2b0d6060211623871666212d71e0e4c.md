# Instrucciones

Estás llevando un conteo diario de cuántos pájaros visitan tu jardín. Los datos se guardan como un array de enteros, con **el conteo de hoy primero**.

## 1. El conteo de hoy

Define `today` para tomar un array de conteos diarios de la pila y devolver el conteo de hoy, o `f` si el array está vacío.

```factor
{ 2 5 1 } today .
! => 2

{ } today .
! => f
```

## 2. Incrementa el conteo de hoy

Define `increment-day-count` para devolver un nuevo array con el conteo de hoy aumentado en uno. Si el argumento está vacío, devuelve `{ 1 }`.

```factor
{ 4 0 2 } increment-day-count .
! => { 5 0 2 }

{ } increment-day-count .
! => { 1 }
```

## 3. ¿Hubo algún día sin pájaros?

Define `has-day-without-birds?` para devolver `t` si al menos un día registró cero pájaros, o `f` en caso contrario.

**Usa recursión** en lugar de `any?` u otras palabras de orden superior para secuencias.

```factor
{ 2 0 4 } has-day-without-birds? .   ! => t
{ 3 8 1 5 } has-day-without-birds? . ! => f
```

## 4. Total de pájaros desde que empezaste

Define `total` para devolver la suma de todos los conteos.

**Usa recursión** en lugar de `sum`.

```factor
{ 4 0 9 0 5 } total .
! => 18
```

## 5. Días ocupados

Un día ocupado es uno con cinco pájaros o más. Define `busy-days` para devolver el número de días ocupados.

**Usa recursión** en lugar de `count`.

```factor
{ 4 5 0 0 6 } busy-days .
! => 2
```
