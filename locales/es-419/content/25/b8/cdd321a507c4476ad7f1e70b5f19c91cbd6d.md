# Introducción

## Arrays

Los arrays en PHP son mapas ordenados.
Un mapa es una estructura de datos que asocia una clave a un valor.
Los arrays son versátiles y se pueden tratar como un array lineal (como en `C` o `Java`), lista [vector], tabla hash, diccionario, colección, pila o cola.

Una clave es opcional, pero si se especifica debe ser un `int` o un `string`.
Cuando no se proporciona una clave, PHP usa por defecto claves enteras en orden creciente, empezando en `0`.

```php
$no_keys = ["my", "first", "array"];
$integer_keys = [0 => "my", 1 => "first", 2 => "array"];

$no_keys == $integer_keys // => equal returns true
$no_keys === $integer_keys // => strictly equal returns true
```

Un array puede almacenar valores de todos los tipos.
Cada valor puede tener un tipo diferente.

### Cómo usar los arrays

Los arrays se pueden declarar como un literal (escrito en el código, como se hizo arriba) o crearse y manipularse con funciones.
Accede, asigna y agrega valores usando el operador de índice:

```php
$prime_numbers = [2, 3, 5, 6];

$prime_numbers[3] = 7; // replace 6 with 7

$prime_numbers[] = 11; // array now contains [2, 3, 5, 7, 11]
```

## Argumentos de longitud variable

Los argumentos de una función se pueden especificar de manera que acepte cualquier número de argumentos:

```php
<?php

function actOnItems(...$items) {
  // $items is an array containing 0 or more values
  // used to call the function.
}

actOnItems(1, 2, 3, 4); // $items => [1, 2, 3, 4]
```
