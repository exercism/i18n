# Instrucciones

Cuando los extraterrestres de Lisp llegaron por primera vez a la Tierra, se encontraron con incontables cosas raras y maravillosas, pero uno de sus descubrimientos favoritos fue el de las «mascotas». Seamos honestos, ¿a qué clase de extraterrestre no se le derretiría el corazón por un cachorro o un gatito?

Ludwig, después de sus recientes vacaciones en la Tierra, ¡ha decidido que quiere una mascota propia! ¿El único problema? ¡Demasiadas opciones! ¿Quizás podrías escribir un programa que ayude a Ludwig a encontrar y cuidar a su próximo amigo adorable?

## 1. Elegir a un compañero

Aunque Ludwig está decidido a conseguir una mascota, hasta ahí llega su plan. El primer paso, entonces, ¡es decidir qué tipo de mascota conseguir!

Ludwig quiere encontrar un compañero con una personalidad que complemente la suya. ¿Podrías escribirle a Ludwig una función llamada `pal-picker` que reciba algún rasgo de personalidad (una palabra clave) y devuelva el tipo de mascota (un string) con ese rasgo?

En este caso en particular:

- `:lazy` -> `"Cat"`
- `:energetic` -> `"Dog"`
- `:quiet` -> `"Fish"`
- `:hungry` -> `"Rabbit"`
- `:talkative` -> `"Bird"`

Para otras personalidades desconocidas, tu función debe evaluar a: `"I don't know... A dragon?"`

```lisp
(pal-picker :quiet) ; => "Fish"
```

## 2. En su hábitat natural

¡Ahora que Ludwig tiene un nuevo amigo, necesitará un lugar donde quedarse! ¿Puedes ayudar a Ludwig a elegir la cama / pecera / jaula del tamaño adecuado para su mascota?

Aquí, Ludwig necesita una función llamada `habitat-fitter` que seleccione el tamaño de hábitat adecuado (una palabra clave) a partir del peso de su mascota en kilogramos (un entero).

Los hábitats que necesita cada tamaño de mascota son:

- 40kg o más -> `:massive`
- de 20kg a 39kg inclusive -> `:large`
- de 10kg a 19kg inclusive -> `:medium`
- de 1kg a 9kg inclusive -> `:small`
- 0kg o menos -> `:just-your-imagination`

```lisp
(habitat-fitter 42) ; => :MASSIVE
```

## 3. Y ahora, el festín

¡Una cosa que todas las mascotas terrestres tienen en común es su necesidad de comida! Sin embargo, este concepto le resulta un poco ajeno a Ludwig, ya que es propenso a olvidarse de rellenar el plato de comida de su mascota.

A Ludwig le vendría bien una función sencilla llamada `feeding-time` que le avise cuando haya que rellenar el plato. La función recibiría un porcentaje de llenado (un entero) y devolvería un mensaje en forma de string.

Si el nivel de comida es:

- Por encima del 20% -> `"All is well."`
- 20% o menos -> `"It's feeding time!"`

```lisp
(feeding-time 15) ; => "It's feeding time!"
```

## 4. Un código de conducta

Con lo básico ya resuelto, Ludwig está deseando probar varias cosas emocionantes, como «acariciar» y jugar a «traer». Dicho esto, no todas las mascotas son adecuadas para estas actividades.

A Ludwig le gustaría tener un par de funciones, `pet` y `play-fetch`, que reciban el tipo de mascota (como un string) y devuelvan o bien nada, o bien un mensaje como: `"Maybe not with this pet..."` si la acción no es apropiada.

Supón que solo los `"Dog"` jugarán a traer y que a todas las mascotas excepto `"Fish"` se les puede acariciar.

```lisp
(pet "Dog")         ; => NIL
(play-fetch "Fish") ; => "Maybe not with this pet..."
```
