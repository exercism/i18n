# Instrucciones

En este ejercicio vas a generar informes del clima para una estación de noticias local.

## Genera informes del clima

Empezarás con algunas funciones sin implementar y el siguiente enum:

```rust
#[derive(Drop, Clone, PartialEq, Debug)]
pub enum WeatherCondition {
    Sunny,
    Rainy,
    Cloudy,
    Stormy
}
```

Tendrás que dar formato a un informe del clima como `"Today is <CONDITION> with a temperature of <TEMPERATURE> degrees Celsius."`.
Tendrás que implementar la función que genera las condiciones climáticas correctas.

Por ejemplo, el siguiente fragmento muestra una salida esperada de la función `get_weather_report` para un día «lluvioso».

```rust
get_weather_report(WeatherCondition::Rainy, "25")
// Returns: "Today is RAINY with a temperature of 25 degrees Celsius."
```

Y para un día «soleado»:

```rust
get_weather_report(WeatherCondition::Sunny, "30")
// Returns: "Today is SUNNY with a temperature of 30 degrees Celsius."
```
