# Ejecutar las pruebas

Para compilar y ejecutar las pruebas, solo ejecuta lo siguiente en el directorio de tu ejercicio:
```bash
$ ponyc
$ ./exercise-name
```

(Reemplaza `exercise-name` por el nombre del directorio del ejercicio)

El binario compilado ejecuta las pruebas en su actor Main, así que solo ejecuta el binario y fíjate si tus pruebas pasaron. Pony revisa todo el código en tiempo de compilación, así que puede que tus pruebas no compilen hasta que escribas el código necesario. Puedes comentar las pruebas que no compilen empezando cada línea con `//`. Después, cuando estés listo para trabajar en esa prueba, puedes descomentarla.
