# Introducción

Una plantilla es un string o un archivo que se usa para producir cualquier tipo de salida de texto según los datos que recibe.

```haxe
var sample = "My name is ::name::";
var template = new haxe.Template(sample);
var myName = {name: "Joe"};
var output = template.execute(myName);

trace(output); // My name is Joe
```

Entre otras cosas, también puedes usar condicionales para hacer comprobaciones dentro de las plantillas:

```haxe
var sample = "::if isAwake:: I'm awake ::else:: Zzzzz ::end::";
var template = new haxe.Template(sample);
var awake = {isAwake: false};
var output = template.execute(awake);

trace(output); // Zzzzz
```
