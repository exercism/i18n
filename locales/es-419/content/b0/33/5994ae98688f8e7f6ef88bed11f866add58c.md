# Acerca de

Cada instancia de un struct o una clase tiene una propiedad implícita llamada `self`, que hace referencia a la instancia misma.
El uso más común de `self` es desambiguar entre una propiedad de la instancia y un parámetro que tiene el mismo nombre:

```swift
struct Position {
    var x = 0

    mutating func move(x: Int) {
        // Here, 'self.x' refers to the struct's property,
        // while 'x' refers to the parameter passed to the method.
        self.x = x
    }
}
```

Los tipos de Swift también ofrecen la palabra clave `Self` con mayúscula inicial, que hace referencia al *tipo* de la instancia y no a la instancia misma.
