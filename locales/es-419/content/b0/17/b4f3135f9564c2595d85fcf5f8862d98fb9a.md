# Acerca de

Go contiene tipos numéricos básicos que pueden representar conjuntos de valores enteros o de punto flotante.
Existen distintos tipos según el tamaño del valor que necesites y la arquitectura de la computadora donde se ejecute la aplicación (por ejemplo, de 32 bits y de 64 bits).

Este concepto se centrará en dos tipos de números:

- `int`: por ejemplo, `0`, `255`, `2147483647`.
   Un entero con signo que ocupa al menos 32 bits (con un rango de valores de -2147483648 a 2147483647).
   Pero esto dependerá de la arquitectura del sistema.
   La mayoría de las computadoras modernas son de 64 bits, por lo que `int` ocupará 64 bits (con un rango de valores de -9223372036854775808 a 9223372036854775807).

- `float64`: por ejemplo, `0.0`, `3.14`.
   Contiene el conjunto de todos los números de punto flotante de 64 bits.

Para ver la lista completa de los tipos numéricos disponibles y más detalles, consulta los siguientes recursos:

- [Declaraciones de tipos integrados de Go][go-builtins]
- [Digital Ocean: entender los tipos de datos en Go][do-understanding-types]
- [Arden Labs: entender los tipos en Go][arden-understanding-types]

Go admite el conjunto estándar de operadores aritméticos `+`, `-`, `*`, `/` y `%` (residuo, no módulo).

En Go, asignar un valor entre tipos distintos requiere una conversión explícita.
Por ejemplo, para convertir un `int` a un `float64` tendrías que hacer lo siguiente:

```go
var x int = 42
f := float64(x)

fmt.Printf("x is of type: %s\n", reflect.TypeOf(x))
// Output: x is of type: int

fmt.Printf("f is of type: %s\n", reflect.TypeOf(f))
// Output: f is of type: float64
```

Para más información sobre la conversión de tipos, consulta [A Tour of Go: conversiones de tipos][type-conversion]
