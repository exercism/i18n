# argumentos splat inesperados

Define un parámetro llamado `%{splat-arg.name}` con el tipo `%{parameter.type}`,
en lugar de usar `...%{splat-arg.name}: %{parameter.type}[]`.

Los [parámetros rest / argumentos splat](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Functions/rest_parameters)
son muy útiles si la función no dicta cuántos valores quiere recibir,
pero en este caso está definido explícitamente con cuántos valores se llamará
a la función.
