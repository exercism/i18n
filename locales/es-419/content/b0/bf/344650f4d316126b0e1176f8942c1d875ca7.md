# Pistas

## General

- En un string codificado en ASCII, todos los caracteres ocupan 1 byte en memoria.
- Necesitas usar `[]` para desreferenciar ubicaciones de memoria.
- El valor ASCII de una letra mayúscula es 32 menos que el valor ASCII de la letra minúscula equivalente.

## 1. Obtén la primera letra de una oración

- En un string codificado en ASCII, todos los caracteres ocupan 1 byte en memoria.
- Necesitas usar `[]` para desreferenciar ubicaciones de memoria.
- El valor ASCII de una letra mayúscula es 32 menos que el valor ASCII de la letra minúscula equivalente.
- Los valores de 1 byte se devuelven en `al`.

## 2. Capitaliza una palabra

- En un string codificado en ASCII, todos los caracteres ocupan 1 byte en memoria.
- Necesitas usar `[]` para desreferenciar ubicaciones de memoria.
- El valor ASCII de una letra mayúscula es 32 menos que el valor ASCII de la letra minúscula equivalente.
- Capitalizar significa tener un solo carácter en _mayúscula_, seguido de caracteres en _minúscula_.
- Solo los valores entre 'a' y 'z' son letras minúsculas, y solo los valores entre 'A' y 'Z' son letras mayúsculas.
- Así que primero necesitas extraer la primera letra y convertirla a mayúscula si está en minúscula.
- Luego necesitas determinar el resto del string: cada carácter después del primero debe convertirse a minúscula si es una letra mayúscula, o dejarse igual en caso contrario.
- El string termina cuando se encuentra `'\0'` (el carácter NUL).
- Puedes usar `lodsb` para cargar en `al` un byte de la ubicación de memoria en `rsi`, cambiando `rsi` en 1.
- Puedes usar `stosb` para almacenar en la ubicación de memoria en `rdi` un byte cargado en `al`, cambiando `rdi` en 1.

## 3. Obtén la última letra de una oración

- En un string codificado en ASCII, todos los caracteres ocupan 1 byte en memoria.
- Necesitas usar `[]` para desreferenciar ubicaciones de memoria.
- El valor ASCII de una letra mayúscula es 32 menos que el valor ASCII de la letra minúscula equivalente.
- Necesitas recorrer el string en un bucle para encontrar la última letra.
- Solo los valores entre 'a' y 'z' son letras minúsculas, y solo los valores entre 'A' y 'Z' son letras mayúsculas.
- Los valores de 1 byte se devuelven en `al`.

## 4. Sé amable

- En un string codificado en ASCII, todos los caracteres ocupan 1 byte en memoria.
- Necesitas usar `[]` para desreferenciar ubicaciones de memoria.
- El valor ASCII de una letra mayúscula es 32 menos que el valor ASCII de la letra minúscula equivalente.
- Reutiliza una función existente para capitalizar la palabra.
- Puedes usar `movsb` para copiar un byte de la dirección de memoria en `rsi` a la dirección de memoria en `rdi`, cambiando tanto `rsi` como `rdi` en 1.
- Puedes definir un string inicializado en _section .rodata_ o _section .data_.
- Debes usar `rel` para calcular una dirección relativa.
- Para un array declarado con la etiqueta `arr`, `$ - arr` sería el tamaño total de `arr` en bytes si se usa justo después de declarar el array.
- Puedes usar `rep` para repetir una instrucción de string como `movsb` la cantidad de veces que especifique `rcx`.
- El string debe terminar con `'\0'` (el carácter NUL) como terminador.
- Recuerda que los caracteres especiales con una barra invertida (como `'\0'`) deben definirse entre backticks (`` ` ``), o usando su valor decimal (que es `0` para NUL).
