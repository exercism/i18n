# Instrucciones

En este ejercicio, vas a escribir algo de código para ayudarte a prepararte para comprar un vehículo.

Tienes tres tareas: una para determinar si vas a necesitar obtener una licencia, otra para ayudarte a elegir entre dos vehículos y otra para estimar el precio aceptable de un vehículo usado.

## 1. Determina si vas a necesitar una licencia de conducir

Algunos tipos de vehículos requieren una licencia de conducir para conducirlos.
Supón que solo los tipos `'car'` y `'truck'` requieren una licencia; todo lo demás se puede conducir sin licencia.

Implementa la función `needsLicense(kind)` que recibe el tipo de vehículo y devuelve un booleano que indica si necesitas una licencia para ese tipo de vehículo.

```javascript
needsLicense('car');
// => true

needsLicense('bike');
// => false
```

## 2. Elige entre dos vehículos posibles para comprar

Evalúas tus opciones de vehículos disponibles.
Logras reducirlas a dos opciones, pero necesitas ayuda para tomar la decisión final.
Para eso, implementa la función `chooseVehicle(option1, option2)` que recibe dos vehículos como argumentos y devuelve una decisión que incluye la opción que aparece primero en orden alfabético.

```javascript
chooseVehicle('Wuling Hongguang', 'Toyota Corolla');
// =>  'Toyota Corolla is clearly the better choice.'

chooseVehicle('Volkswagen Beetle', 'Volkswagen Golf');
// =>  'Volkswagen Beetle is clearly the better choice.'
```

## 3. Calcula una estimación del precio de un vehículo usado

Ahora que tomaste tu decisión, quieres asegurarte de conseguir un precio justo en el concesionario.
Como te interesa comprar un vehículo usado, el precio depende de la antigüedad del vehículo.
Como estimación aproximada, supón que si el vehículo tiene menos de 3 años, cuesta el 80 % del precio original que tenía cuando era nuevo.
Si tiene más de 10 años, cuesta el 50 %.
Si el vehículo tiene al menos 3 años pero no más de 10, cuesta el 70 % del precio original.

Implementa la función `calculateResellPrice(originalPrice, age)` que aplica esta lógica usando `if`, `else if` y `else` (hay otras formas si quieres practicar).
Recibe el precio original y la antigüedad del vehículo como argumentos y devuelve el precio estimado en el concesionario.

```javascript
calculateResellPrice(1000, 1);
// => 800

calculateResellPrice(1000, 5);
// => 700

calculateResellPrice(1000, 15);
// => 500
```
