# Pistas para el ejercicio de Buscaminas en Bash

Este ejercicio parece requerir un array bidimensional.
Bash solo ofrece [arrays][array] unidimensionales indexados o asociativos.

Los arrays multidimensionales se pueden simular usando arrays asociativos: codificar los índices en un string separado por comas para usarlo como clave del array.

```bash
# store this matrix:
#   a b
#   c d
declare -A array2d
array2d["0,0"]="a"
array2d["0,1"]="b"
array2d["1,0"]="c"
array2d["1,1"]="d"
```

[array]: https://www.gnu.org/software/bash/manual/bash.html#Arrays
