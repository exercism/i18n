# Instrucciones

En este ejercicio vas a implementar el manejo de errores para una calculadora sencilla.

El objetivo es tener una calculadora funcional que devuelva un string con el siguiente patrón: `16 + 51 = 67`, cuando recibe los argumentos `16`, `51` y `+`.

```ruby
SimpleCalculator.calculate(16, 51, "+")
# => "16 + 51 = 67"
SimpleCalculator.calculate(32, 6, "*")
# => "32 * 6 = 192"
SimpleCalculator.calculate(512, 4, "/")
# => "512 / 4 = 128"
```

## 1. Maneja el código que puede generar errores dentro del método `calculate`

El método principal que implementarás en esta tarea será el método de clase `SimpleCalculator.calculate()`.
Recibe tres argumentos.
Los primeros dos argumentos son números sobre los que se va a realizar una operación.
El tercer argumento es de tipo string y, para este ejercicio, es necesario implementar las siguientes operaciones:

- la suma usando el string `+`
- la multiplicación usando el string `*`
- la división usando el string `/`

## 2. Maneja las operaciones no válidas

Actualiza el método `SimpleCalculator.calculate()` para que lance una excepción `UnsupportedOperation` cuando el símbolo de la operación sea desconocido.

```ruby
SimpleCalculator.calculate(1, 2, '-')
# => Raises an UnsupportedOperation
```

~~~~exercism/note
En este ejercicio, se espera que definas la excepción `UnsupportedOperation` para un ámbito específico.
~~~~

## 3. Maneja los argumentos no válidos

Actualiza el método `SimpleCalculator.calculate()` para que lance una excepción `ArgumentError` cuando los tipos de los argumentos no sean válidos.

```ruby
SimpleCalculator.calculate(1, '2', '*')
# => Raises an ArgumentError
```

## 4. Maneja las excepciones DivideByZero

Actualiza `SimpleCalculator.calculate()` para manejar las excepciones `ZeroDivisionError`.
El código de manejo debe devolver el string con el contenido `Division by zero is not allowed.`.
Ninguna otra excepción debe ser manejada por el método `SimpleCalculator.calculate()`.

```ruby
SimpleCalculator.calculate(512, 0, "/")
# => returns "Division by zero is not allowed."
```
