## Sentencias condicionales

Las sentencias condicionales son sentencias que toman decisiones y que pueden ejecutar efectos secundarios o controlar el flujo de ejecución de un programa.
Las sentencias condicionales incluyen las sentencias `if`, `if/else`, `switch` y `ternary`.

Las sentencias condicionales se usan para hacer preguntas sobre un valor o sobre una relación entre valores.
La pregunta da como resultado un valor Boolean, pero la propia sentencia `if` puede devolver cualquier valor o simplemente ejecutar un efecto secundario.

## Sentencias if

La sentencia `if` más simple evalúa una expresión y ejecuta una sola línea.
La expresión que se evalúa siempre va entre paréntesis.

Puede ejecutar un efecto secundario

```c
if (count > 10)
    printf("count is greater than 10");
```

o puede cambiar el flujo de ejecución


```c
if (count > 10)
    return sum;
```

Si una sentencia `if` ejecuta más de una línea, debe colocar esas líneas entre llaves

```c
if (count > 10) {
    printf("count is greater than 10");
    return sum;
}
```

Algunos equipos de programación pueden establecer como norma que las sentencias `if` siempre usen llaves, incluso para una sola línea.


## if else

Una sentencia `if` se puede combinar con un `else`

```c
if (number % 2 == 0)
    return "even";
else
    return "odd";
```

## if else if


Un `else` se puede combinar con otro `if` para crear lo que se conoce como una `if-else-if ladder`.

```c
if (number == 0)
    return "zero";
else if (number < 0)
    return "negative";
else if (number < 10)
    return "single digit";   
else if (number % 2 == 0)
    return "even";
else
    return "odd";
```

## switch


A veces, una `if-else-if ladder` se puede representar mejor con un `switch`.
Al igual que con `if`, la expresión que se evalúa siempre se pone entre paréntesis.

```c
switch (number) {
    case -1:
        return "negative one";
    case 0:
        return "zero";
    case 1:
        return "positive one";
    case 10:
        return "positive ten";
    case -10:
        return "negative ten";
    default:
        return "don't care";
}
```

El caso `default` se ejecuta si el valor que se evalúa no coincide con ninguno de los casos anteriores.

Si un caso de `switch` no devuelve un valor, normalmente se inserta un `break` para terminar cada caso; de lo contrario, la lógica «cae» hacia el siguiente caso.
A veces, esa caída se usa de forma intencional.

```c
switch (number) {
    case 0:
        msg = "zero"; break;
    case 1:
        msg = "one"; break;
    case 2: case 3: case 4:
        msg = "more than one and less than five"; break;
    default:
        msg = "don't care";
}
```

Cuando la caída ocurre sin querer, es un bug.

```c
switch (number) {
    case 0:
        msg = "zero"; // bug! fallthrough of 0 will set msg to "one"
    case 1:
        msg = "one"; break; 
    case 2: case 3: case 4:
        msg = "more than one and less than five"; break;
    default:
        msg = "don't care";
}
```

Un `switch` puede ser útil cuando se compara con valores específicos en lugar de un rango de valores.
Puede ser más rápido que una `if-else-if ladder` porque el compilador puede optimizar la sentencia `switch` de formas que no puede lograr con una escalera.
A veces, un `switch` puede verse más legible que una escalera.

## El operador ternario (también llamado condicional)

El operador ternario es una sentencia condicional de tres partes que se usa con frecuencia para asignar un valor.
La expresión que se va a evaluar va antes del signo de interrogación y no tiene que ir entre paréntesis.
El valor que se devuelve si es verdadera va antes de los dos puntos, y el valor que se devuelve si es falsa va después de los dos puntos.
Se puede devolver tanto un literal como una variable.

```c
int i = j > 5 ? 5: j;
```

Los operadores ternarios se pueden anidar para reducir el desorden sintáctico.

```c
// the below could also be 
i = j > 5 ? j :k > 5 ? k: 10;
// but that may not be quite as readable

i = j > 5 ? j
    :k > 5 ? k
    :10;

// which is the same as
if (j > 5) i = j;
else if (k > 5) i = k;
else i = 10;
```

## Comparaciones condicionales con números de punto flotante

Debido a cómo se implementan los números de punto flotante, una operación matemática simple puede producir un error de redondeo que haga que una prueba de igualdad no devuelva el resultado esperado.

```c
    a = 1.345f;
    b = 1.123f;
    c = a + b;
    // c may equal something like 2.4679999352
    if (c == 2.468)
        return "I won the lottery!";
```

Se puede usar un valor de tolerancia, conocido como `epsilon`, para determinar un rango dentro del cual un valor se puede considerar igual al compararlo con otro valor.
Algunas plataformas tienen constantes integradas para los epsilon de float y double.
Consulta la documentación de tu compilador para obtener más información.
Calcular el epsilon puede ser bastante complejo y puede variar de una plataforma a otra, incluso entre máquinas individuales.
Aquí tienes un programa de ejemplo que usa una comparación simple.

```c
#include <stdio.h>
#include <math.h>
#include <stdbool.h>

const double MY_EPSILON = .002;

bool same(double x, double y)
{
    return fabs(x - y) < MY_EPSILON;
}

int main()
{
    // Same should return true if the difference is less than MY_EPSILON
    printf("%s\n", same(1.1, 1.099) ? "true" : "false"); // prints true
    printf("%s\n", same(1.1, 1.098) ? "true" : "false"); // prints false
    return 0;
}
```

¡Ten cuidado cuando compares `float`s o `double`s por igualdad!
