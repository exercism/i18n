# Anexo de instrucciones

## Formato de salida

Genera la letra como un string terminado en null.

## Registros

| Registro | Uso           | Tipo    | Descripción                    |
| -------- | ------------- | ------- | ------------------------------ |
| `$a0`    | entrada       | entero  | botellas iniciales             |
| `$a1`    | entrada       | entero  | cantidad a quitar              |
| `$a2`    | entrada/salida | dirección | string de salida terminado en null |
| `$t0-9`  | temporal      | cualquiera | para almacenamiento temporal |
