# Pistas

## General

- Lee sobre la composición de funciones en el [manual][function-composition-manual].
- Explora los [métodos disponibles para _Strings_][string-methods].

## 1. Limpia el nombre

- Hay un [método integrado][string-replace] para reemplazar todas las apariciones de un substring en un string.
- Hay un [método integrado][string-strip] para eliminar los espacios en blanco al principio y al final de un string.

## 2. Obtén la primera letra del nombre

- Para obtener un carácter específico de un string, puedes usar la [indexación][string-indexing].
- La forma más limpia de escribir esto es usar el operador de composición `∘`.

## 3. Da formato a la primera letra como inicial

- Hay un [método integrado][string-uppercase] para convertir todos los caracteres de un string a su variante en mayúsculas.

## 4. Coloca las iniciales dentro del corazón

- Puedes usar caracteres Unicode en los strings con: `'\u<id>'`, donde, en el caso del emoji de corazón, el id es `2764`.
- Esto se puede hacer con [concatenación][string-concatenation] o [interpolación][string-interpolation].
