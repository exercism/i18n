# Pistas

## 1. Obtener los permisos predeterminados para un tipo de cuenta

- Define la enumeración `Permission` con valores para los siguientes tipos de permisos: `None`, `Read`, `Write` y `Delete`.
- Usar los flags de la enumeración permitiría usar operaciones bit a bit directamente para la enumeración `Permission`, [consulta `enum` `Flags`][docs-enum-flags].
- El miembro `All` de la enumeración se puede definir como una combinación de los miembros `Read`, `Write` y `Delete`.
- Define la enumeración `AccountType` con valores para los siguientes tipos de cuenta: `Guest`, `User` y `Moderator`.
- Para manejar cada tipo de cuenta, se podría usar una sentencia `if`, pero la [sentencia `switch`][docs.microsoft.com-switch-keyword] es una gran alternativa.
- Combinar flags significa poner un bit específico en `1` usando uno de los [operadores bit a bit][docs.microsoft.com-bitwise-and-shift-operators].

## 2. Otorgar un permiso

- Combinar flags significa poner un bit específico en `1` usando uno de los [operadores bit a bit][docs.microsoft.com-bitwise-and-shift-operators].

## 3. Revocar un permiso

- Quitar un flag significa poner un bit específico en `0` usando una combinación de dos [operadores bit a bit][docs.microsoft.com-bitwise-and-shift-operators].

## 4. Verificar un permiso

- Para verificar un permiso, puedes comprobar el resultado de aplicar uno de los [operadores bit a bit][docs.microsoft.com-bitwise-and-shift-operators].
