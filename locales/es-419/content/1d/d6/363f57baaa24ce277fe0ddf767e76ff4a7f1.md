# Pistas

## 1. Lee las direcciones de correo electrónico desde un archivo

- La [función `simplifile.read`][file-read] se puede usar para leer el contenido de un archivo.

## 2. Crea un archivo de registro para escribir

- La [función `simplifile.create_file`][file-create] se puede usar para crear un archivo vacío.

## 3. Registra un correo enviado

- La [función `simplifile.append`][file-append] se puede usar para agregar texto a un archivo.

## 5. Envía el boletín

- Todas las operaciones necesarias sobre archivos ya se implementaron en los pasos anteriores.
- La [función `result.try`][result-try] y la [función `list.try_each`][list-try-each] se pueden usar para trabajar con el tipo `Result`.

[file-append]: https://hexdocs.pm/simplifile/simplifile.html#append

[list-try-each]: https://hexdocs.pm/gleam_stdlib/gleam/list.html#try_each
