# Ayuda

Si tienes problemas y necesitas ayuda, puedes usar uno de estos recursos:

- [Documentación de la biblioteca estándar](http://caml.inria.fr/pub/docs/manual-ocaml/libref/index.html)
- [/r/ocaml](https://www.reddit.com/r/ocaml) es el subreddit de OCaml.
- Puedes usar [StackOverflow](http://stackoverflow.com/questions/tagged/ocaml) para buscar tu problema y ver si ya lo respondieron. También puedes hacer y responder preguntas.
