# Anexo de instrucciones

## Salida

En este ejercicio, implementarás un verbo que genera el triángulo de Pascal hasta un número determinado de filas. La salida de tu verbo se puede formatear de una de estas dos maneras:

  1. Como un array de arrays encajonados, donde cada array representa una fila del triángulo de Pascal.
  1. Como una tabla, donde los números están alineados a la derecha y se usan ceros para rellenar los espacios vacíos a la izquierda.

### Ejemplo de salida

Aquí tienes dos salidas válidas para `pascal 3`:

  - Como un array de arrays encajonados:
```j
  (1 ; 1 1 ; 1 2 1) -: pascal 3          NB. This test will pass
```
  - Como una tabla con relleno:
```j
  (3 3$1 0 0 1 1 0 1 2 1) -: pascal 3   NB. This test also passes
```
