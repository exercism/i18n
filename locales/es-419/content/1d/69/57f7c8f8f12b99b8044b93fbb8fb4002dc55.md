# Acerca de

La coincidencia de patrones es el proceso de ramificar según si un valor coincide con patrones dados, posiblemente profundos. En Haxe, la **coincidencia de patrones** se hace con la expresión `switch` y expresiones `case` individuales.

Considera esta estructura de datos:

```haxe
enum Tree<T> {
  Leaf(v:T);
  Node(l:Tree<T>, r:Tree<T>);
}
```

- Los patrones siempre se evalúan de arriba a abajo.
- El primer patrón que coincide con el valor de entrada es el que ejecuta su expresión.
- Un patrón `_` coincide con cualquier cosa, así que `case _:` es equivalente a `default:`

## Coincidencia con enum

Los enum se pueden hacer coincidir por su constructor de forma natural:

```haxe
var myTree = Node(Leaf("foo"), Node(Leaf("bar"), Leaf("foobar")));

var match = switch (myTree) {
  // Matches any Leaf
  case Leaf(_):
    "0";

  // Matches any Node that has r = Leaf
  case Node(_, Leaf(_)):
    "1";

  // Matches any Node that has
  // r = another Node which has
  // l = Leaf("bar")
  case Node(_, Node(Leaf("bar", _))):
    "2";

  // Matches anything
  case _:
    "3";
}

trace(match); // 2
```
