# Acerca de

Lo más importante que debes recordar sobre los strings de Java es que son objetos inmutables que representan texto como una cadena de caracteres Unicode (letras, dígitos, puntuación, etc.).
Las comillas dobles se usan para definir una instancia de `String`:

```java
String fruit = "Apple";
```

Puedes manipular un string con los métodos de la clase [`String`][string-class].
Como los valores de tipo string nunca cambian después de haberse definido, todos los métodos de manipulación de strings devuelven un string nuevo.

Un string se delimita con comillas dobles (`"`).
Algunos caracteres especiales necesitan escaparse usando el carácter de barra invertida (`\`).
Caracteres que se deben escapar en Java:

- `"`
- `\`

```java
String escaped = "c:\\test.txt";
// => c:\test.txt
```

Por último, hay muchas formas de concatenar strings.
La más simple es el operador `+`:

```java
String name = "Jane";
"Hello " + name + "!";
// => "Hello Jane!"
```

Para cualquier formato de string más complejo que una simple concatenación, se prefiere el método `String.format`.

```java
String name = "Jane";
String.format("Hello %s!",name);
// => "Hello Jane!"
```

Otras posibilidades son:

- usar la clase [`StringBuilder`][string-builder]
- usar el método [`String.concat`][string-concat]
