# reutilización de funciones

Reutilizar una función que ya escribiste puede ayudarte a la hora de escribir código fácil de mantener.

Reutiliza las funciones que ya existen:
- `remaining_minutes_in_oven/1` puede reutilizar `expected_minutes_in_oven/0`
- `total_time_in_minutes/2` puede reutilizar `preparation_time_in_minutes/1`
