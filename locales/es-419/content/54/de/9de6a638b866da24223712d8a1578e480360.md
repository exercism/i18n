# Instrucciones

Como aficionado al ajedrez, te gustaría escribir tu propia versión del juego. Sí, es probable que ya haya muchas implementaciones de ajedrez disponibles en línea, pero ¡la tuya será única!

Pero antes de que puedas dar rienda suelta a tu imaginación, tienes que ocuparte de lo básico. Empecemos por generar el tablero.

Cada casilla del tablero de ajedrez se identifica con un par de letra y número. Las columnas verticales de casillas, llamadas *files*, se etiquetan de la A a la H. Las filas horizontales de casillas, llamadas *ranks*, se numeran del 1 al 8.

## 1. Define el rango de las filas

Implementa la función `rank_range()`. Debe devolver un rango de números enteros, del 1 al 8.

```julia-repl
julia> rank_range()
# output omitted
```

## 2. Define el rango de las columnas

Implementa la función `file_range()`. 
Debe devolver un rango de caracteres, desde la letra A mayúscula hasta la letra H mayúscula.

```julia-repl
julia> file_range()
# output omitted
```

## 3. Transforma el rango de las filas en un vector de filas

Implementa la función `ranks()`. Debe devolver un vector de números enteros, del 1 al 8. 
No escribas el vector a mano; genéralo a partir del rango que devuelve la función `rank_range()`.

```julia-repl
julia> ranks()
[1, 2, 3, 4, 5, 6, 7, 8]
```

## 4. Transforma el rango de las columnas en un vector de columnas

Implementa la función `files`. Debe devolver un vector de caracteres, de 'A' a 'H'. 
No escribas el vector a mano; genéralo a partir del rango que devuelve la función `file_range()`.

```julia-repl
julia> files()
['A', 'B', 'C', 'D', 'E', 'F', 'G', 'H']
```
