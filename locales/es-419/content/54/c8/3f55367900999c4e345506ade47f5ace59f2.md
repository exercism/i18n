# Pistas

## General

- [Esta página][case-expressions] tiene una buena introducción a las expresiones case en Gleam.

## 1. Responde a una suposición correcta

- Puedes usar un patrón literal para hacer coincidir un número específico.

## 2. Responde a una suposición cercana

- Puedes usar un patrón literal, o bien un patrón de variable y una guarda.

## 3. Responde a suposiciones demasiado bajas

- Puedes usar una combinación de un patrón de variable y una guarda.

## 4. Responde a suposiciones demasiado altas

- Puedes usar una combinación de un patrón de variable y una guarda, o un patrón de descarte.
