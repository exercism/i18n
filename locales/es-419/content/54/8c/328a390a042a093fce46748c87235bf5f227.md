# Pistas

## 1. Calcula cuántos autos que funcionan se producen por hora

* El porcentaje (que se pasa como argumento) es un número entre 0 y 100. Para que este porcentaje sea un poco más fácil de manejar, empieza por dividirlo entre 100.
* Para calcular la cantidad de autos que se producen correctamente, multiplica el porcentaje (dividido entre 100) por la cantidad de autos producidos.

## 2. Calcula cuántos autos que funcionan se producen por minuto

* Empieza por calcular la producción de autos que funcionan por hora. Para esto, puedes usar la función `calculate_working_cars_per_hour` que escribiste antes.
* Conociendo la producción de autos por hora, puedes obtener la producción por minuto dividiendo la producción por hora entre 60 (la cantidad de minutos que tiene una hora).
* Como el número que se devuelve debe ser un entero, el [operador de división entera](https://www.lua.org/manual/5.4/manual.html#3.4.1) puede ser útil para esto.

## 3. Calcula el costo de producción

* Empieza por calcular cuántos grupos de 10 autos hay. Puedes hacerlo dividiendo la cantidad de autos entre 10.
* Luego calcula cuántos autos sobran (el [operador de módulo](https://www.lua.org/manual/5.4/manual.html#3.4.1) es útil para esto).
* Para obtener el costo total, multiplica la cantidad de grupos por el costo de producir 10 autos y luego multiplica la cantidad de autos que sobran por el costo de producir cada auto individual. Después, suma entre sí los resultados de las multiplicaciones.
