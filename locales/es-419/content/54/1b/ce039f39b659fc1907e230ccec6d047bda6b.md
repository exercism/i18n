# Acerca de

Los números de punto flotante son números con uno o más dígitos después del separador decimal.

```gleam
let float = 3.45
// -> 3.45
```

Los números de punto flotante también tienen su propio conjunto de operadores.

```gleam
1.0 +. 1.4 // -> 2.4
5.0 -. 1.5 // -> 3.5
5.0 /. 2.0 // -> 2.5
3.0 *. 3.1 // -> 9.3

2.0 >. 1.0  // -> True
2.0 <. 1.0  // -> False
2.0 >=. 1.0 // -> True
2.0 <=. 1.0 // -> False
```

También puedes agregar guiones bajos a los números de punto flotante para que se lean con más claridad.

```gleam
1_000_000.0 // One million
```

También puedes usar notación científica con los números de punto flotante:

```gleam
1.01e3 // -> 1010
15.1e-3 // -> 0.0151
```
