# Acerca de

Aunque el modificador `readonly` impide que se sobrescriba el valor o la referencia de un campo, no ofrece ninguna protección para los miembros de un tipo de referencia.

```csharp
readonly List<int> ints = new List<int>();

void Foo()
{
    ints.Add(1);    // ok
    ints = new List<int>(); // fails to compile
}
```

Para asegurarte de que todos los miembros de un tipo de referencia estén protegidos, puedes hacer que los campos sean `readonly` y definir propiedades automáticas sin un descriptor de acceso `set`.

La Biblioteca de Clases Base (BCL) ofrece algunas versiones de solo lectura de las colecciones cuando se necesita evitar que se actualicen los miembros de una colección. Estas vienen en forma de envoltorios:

- [`ReadOnlyDictionary<T>`][ReadOnlyDictionary]
- [`ReadOnlyCollection<T>`][ReadOnlyCollection]
