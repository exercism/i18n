# Acerca de

En Gleam, una expresión `case` se puede usar para ejecutar código de forma condicional. Con una expresión `case`, se puede comparar un valor con uno o más _patrones_. Un ejemplo de esos patrones es el _patrón literal_, que compara un valor con un valor literal (por ejemplo, `1` o `"hello"`).

Las expresiones `case` se escriben con la palabra clave `case`:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    1 -> "One"
  }
}
```

Aunque esto puede parecerse a las sentencias `switch` de otros lenguajes, la coincidencia de patrones empieza a destacar cuando además se usan otros patrones. Uno de esos patrones es el _patrón de variable_, que permite asignar un valor a una variable. En este ejemplo, a la variable `i` se le asignará el valor de `number` si no es `0`:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i -> "Non zero"
  }
}
```

En algunos casos, quizás quieras agregar una condición adicional a un patrón. Esto se conoce como _guarda_ (cláusula), y se puede agregar con la palabra clave `if`:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i if i < 0 -> "Negative number"
  }
}
```

Por razones de rendimiento, en las guardas solo se permiten operadores matemáticos y booleanos básicos; no se pueden usar otras funciones en las guardas.

En el ejemplo anterior, no todos los valores posibles tendrán un patrón que coincida. El compilador lo detectará y mostrará un error. Esto se conoce como _verificación exhaustiva_. Para resolver la advertencia, hay que cubrir todos los casos. Para eso se puede usar el _patrón de descarte_, que es un patrón que coincide con cualquier valor:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i if i < 0 -> "Negative number"
    _ -> "Positive number"
  }
}

// No compiler error
```

Las expresiones `case` comparan un valor con cada patrón de arriba hacia abajo, hasta encontrar un patrón que coincida y ejecutar la lógica asociada a ese patrón. ¡El orden de los patrones importa!
