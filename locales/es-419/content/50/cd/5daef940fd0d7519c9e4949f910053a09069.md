# Enlaces internos

Los enlaces que se renderizan a través del parser de Markdown de Exercism se revisan para ver si son internos y, de serlo, se pueden decorar con tooltips.

El tooltip de un concepto podría verse así:

<img src="https://raw.githubusercontent.com/exercism/docs/main/.imgs/concept-tooltip.png" height="200">

## Uso

No hay una sintaxis especial para que los enlaces se decoren de esta manera.
En su lugar, revisamos si el href del enlace sigue una de estas dos formas:

- Una URL. Por ejemplo: https://exercism.org/tracks/ruby/concepts/basics
- Una ruta absoluta. Por ejemplo: /tracks/ruby/concepts/basics

Por ahora no admitimos URL relativas (por ejemplo, las que empiezan con `./` o `../`), porque el parser de Markdown no conoce el contexto del documento que renderiza, ni el contexto en el que se está renderizando, ni la estructura de un repositorio de Git.

## Alternativas

En lugar de usar enlaces normales, quizás prefieras renderizar Widgets.
Por lo general, se usan al final de un documento para sugerir lecturas adicionales o buenos ejercicios con los que aprender algo.

Consulta [la documentación de Widgets](/docs/building/markdown/widgets) para más detalles.
