# Pruebas

Para ejecutar las pruebas, ejecuta el siguiente comando:

```bash
make
```

## Pruebas omitidas

Resolver un ejercicio significa hacer que todas sus pruebas pasen.
De forma predeterminada, cuando ejecutas las pruebas solo se ejecuta una prueba (la primera).
Esto es intencional, ya que te permite concentrarte solo en hacer que esa prueba pase.
Cuando pase, puedes habilitar la siguiente prueba eliminando la línea `TEST_IGNORE()`.
Cuando hayas habilitado todas las pruebas y tu implementación haga que todas pasen, ¡habrás resuelto el ejercicio!

## Depuración

Para ayudarte con la depuración, hay varias macros definidas en un archivo `debug.mac`.
Se pueden llamar con uno o más argumentos del tamaño adecuado.
Por ejemplo:

```x86asm
debugf32 xmm0, xmm1 ; prints the value of two 32-bit floating-point numbers
debugd16 ax, cx, dx ; prints the value of three signed 16-bit integers
debugx64 [rax]      ; prints the value of a 64-bit integer in hexadecimal format
debugs rsi          ; prints a NUL-terminated string whose address is stored in `rsi`
debugu8_xmm xmm1    ; prints 16 packed 8-bit unsigned integers
```

Para usar cualquiera de esas macros, `debug.mac` debe incluirse al inicio del archivo de la solución:

```x86asm
%include "debug.mac"
```
