# Anexo de instrucciones

## Funciones y pruebas

El código inicial que se te proporciona,
```scheme
(provide hello)

(define (hello)
  "Goodbye, Mars!")
```
define una función llamada `hello` y la hace disponible para ejecutar.
El ejecutor de pruebas toma esta función y la ejecuta, comparando el valor que devuelve con el valor que espera.
Usa esta definición de función inicial como base para tu solución.
