# Marcador de posición

## General

- La [función numérica][rand-func] `rand` puede generar números aleatorios.
- La [función numérica][srand-func] `srand` te será útil para establecer la semilla de `rand`.

## Generación de laberintos

Puedes usar cualquier algoritmo para generar un laberinto perfecto. El [backtracker recursivo][recursive-backtracker] es una buena opción.

## Caracteres de dibujo de cajas

| Carácter | Nombre                                  | Unicode |
|:---------:|:--------------------------------------|:--------|
|     ┌     | dibujo de caja luz hacia abajo y a la derecha |  U+250C |
|     ─     | dibujo de caja luz horizontal         |  U+2500 |
|     ┬     | dibujo de caja luz hacia abajo y horizontal |  U+252C |
|     ┐     | dibujo de caja luz hacia abajo y a la izquierda |  U+2510 |
|     │     | dibujo de caja luz vertical           |  U+2502 |
|     └     | dibujo de caja luz hacia arriba y a la derecha |  U+2514 |
|     ┴     | dibujo de caja luz hacia arriba y horizontal |  U+2534 |
|     ┘     | dibujo de caja luz hacia arriba y a la izquierda |  U+2518 |
|     ├     | dibujo de caja luz vertical y a la derecha |  U+2520 |
|     ⇨     | flecha blanca hacia la derecha        |  U+21E8 |
