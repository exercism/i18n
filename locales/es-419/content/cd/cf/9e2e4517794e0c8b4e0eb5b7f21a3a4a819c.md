# Introducción

Las expresiones regulares en Gleam siguen la especificación **PCRE** (**P**erl **C**ompatible **R**egular **E**xpressions), de manera similar a otros lenguajes populares como Java, JavaScript o Ruby.

El módulo `gleam/regex` ofrece funciones para trabajar con expresiones regulares.

~~~~exercism/note
Este ejercicio asume que ya conoces la sintaxis de las expresiones regulares, incluidas las clases de caracteres, los cuantificadores, los grupos y las capturas.

Si necesitas refrescar tus conocimientos de expresiones regulares, revisa una de estas fuentes: [Regular-Expressions.info](https://www.regular-expressions.info), [Rex Egg](https://www.rexegg.com/), [RegexOne](https://regexone.com/), [Regular Expressions 101](https://regex101.com/), [RegExr](https://regexr.com/).
~~~~

La forma más común de crear expresiones regulares es usar la función `regex.from_string`.

```gleam
let assert Ok(re) = regex.from_string("test")
```

La función `regex.from_string` produce un `Error` si la sintaxis de la expresión regular no es válida, por lo que aquí se ha usado una aserción `let` para asegurar que la expresión regular sea válida.

La función `regex.check` se puede usar para comprobar si una expresión regular coincide con un string.

```gleam
let assert Ok(re) = regex.from_string("test")

regex.check(re, "this is a test")
// -> True

regex.check(re, "this is too")
// -> False
```


## Capturas

Si quieres capturar subcadenas con una expresión regular, puedes usar la función `regex.scan` para devolver una lista de coincidencias.

```gleam
let assert Ok(re) = regex.from_string("[oi]n a (\\w+)")
regex.scan(with: re, content: "I am on a boat in a lake.")
// -> [
//   Match(
//     content: "on a boat",
//     submatches: [Some("boat")]
//   ),
//   Match(
//     content: "in a lake",
//     submatches: [Some("lake")]
//   )
// ]
```

## Modificadores

El comportamiento de una expresión regular se puede modificar creándola con la función `regex.compile` y pasando opciones.

```gleam
let options = regex.Options(case_insensitive: True, multi_line: False)
let assert Ok(re) = regex.compile("[A-Z]", with: options)
regex.check(re, "abc123")
// -> True
```
