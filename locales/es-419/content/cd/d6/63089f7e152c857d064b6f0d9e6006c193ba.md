# Depuración

Cuando una prueba falla, se muestra un mensaje que describe qué salió mal y con qué entrada.
También puedes aprovechar que todo lo que se imprima en la «salida estándar» se mostrará.
Puedes escribir en la salida estándar con `println!`:

```rust
println!("Debug message");
```

Usa llaves `{}` para imprimir el valor de una variable o una expresión:

```rust
let secret_number = 4321;
println!("My banking password is {}, which is better than {}.", secret_number, 1200 + 34);
```

Ten en cuenta que no todos los tipos se pueden imprimir de esta forma, solo aquellos que se pueden presentar a los usuarios sin ambigüedad.
Por ejemplo, los vectores (arrays) no se pueden imprimir así, ¡porque no está claro cómo debería mostrarse un vector a los usuarios!
Para estos otros tipos, puedes indicarle a la macro `println!` que use el _formato de depuración_ con: `{:?}`.
Esta representación está pensada para que solo la vean los desarrolladores.
Un ejemplo:

```rust
let words = vec!["hello", "world"];
println!("words that are often combined: {:?}", words);
```

Incluso existe la práctica macro `dbg!`, que puedes usar para depurar expresiones grandes directamente, sin tener que descomponerlas en declaraciones de variables separadas.

Supongamos que tenemos la siguiente expresión:

```rust
"hello world".split(' ').collect::<Vec<_>>().join("-")
```

Ahora queremos ver qué devuelve la llamada a `collect`.
Podríamos hacer lo siguiente:

```rust
let my_temporary_debug_variable = "hello world".split(' ').collect::<Vec<_>>();
println!("{:?}", my_temporary_debug_variable);
my_temporary_debug_variable.join("-")
```

¡Pero eso es engorroso!
No queremos reescribir nuestras lindas expresiones solo para poder depurarlas.
Demos la bienvenida al escenario a: `dbg!`

```rust
dbg!(
    "hello world".split(' ').collect::<Vec<_>>()
).join("-")
```

Los espacios en blanco son solo para mayor claridad.
Puedes envolver cualquier expresión en `dbg!()`, lo que imprimirá ese valor (con formato de depuración).
Después puedes seguir usando el valor en una expresión más grande, como si `dbg!` ni siquiera estuviera ahí.

¡Feliz depuración!
