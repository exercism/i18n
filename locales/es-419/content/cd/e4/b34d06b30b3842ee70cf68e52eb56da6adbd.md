# Anexo de instrucciones

## Pistas

El valor que devuelve `countWords` puede ser cualquier tipo de tabla hash con una clave de tipo `string` y un valor de tipo `int`.

Las tablas hash (también conocidas como «diccionarios» o «mapas» en otros lenguajes de programación) están implementadas por el módulo `tables`; consulta la [documentación]

Por ejemplo, `countWords` podría devolver un `TableRef[string, int]`

```nim
proc countWords*(sentence: string): TableRef[string, int] =
  ...
```

[documentación]: https://nim-lang.org/docs/tables.html
