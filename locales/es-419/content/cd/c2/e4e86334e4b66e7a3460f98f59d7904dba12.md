# Pistas

## 1. Captura la información necesaria para generar las tarjetas con regex

- `\p{L}` coincide con cualquier tipo de letra de cualquier idioma.
- Puedes usar la siguiente expresión para capturar la información:
  ```julia
  re = r"""»(.*)«                     # title
           \ –\ (.*?)                 # name
           (?:\ \((.*?)\)|)           # optional pronouns
           (?:,\ from\ (.*?)|).       # optional organisation
           \ Start:\ (.*?),\          # start time
           (?:Q&A:\ (.*?),\ |)        # optional Q&A time
           End:\ (.*)                 # end time
        """x
  ```
