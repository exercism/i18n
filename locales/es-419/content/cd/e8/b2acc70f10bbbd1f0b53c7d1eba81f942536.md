# Instrucciones

En este ejercicio, debes implementar algunas reglas de [Pac-Man][Pac-Man], el clásico juego de arcade de la década de 1980.

Hay seis tareas en total; cuatro de ellas son reglas relacionadas con los estados del juego.

> _No te preocupes por cómo se derivan los argumentos en las funciones, solo concéntrate en combinar los argumentos para devolver el resultado deseado._

## 0. Define un estado de poder

Define una variable llamada `PowerOn` con un valor que represente que el poder está efectivamente activado.

```powershell
> $PowerOn
True
```

## 1. Define si Pac-Man se come a un fantasma

Define la función `EatGhost` que recibe dos parámetros (_si Pac-Man tiene una píldora de poder activa_ y _si Pac-Man está tocando a un fantasma_) y devuelve un valor Boolean si Pac-Man puede comerse al fantasma.
La función debe devolver `True` solo si Pac-Man tiene una píldora de poder activa y está tocando a un fantasma.

```powershell
> EatGhost -ActivePower $false -TouchingGhost $true
False
```

## 2. Define si Pac-Man anota

Define la función `Score` que recibe dos parámetros (_si Pac-Man está tocando una píldora de poder_ y _si Pac-Man está tocando un punto_) y devuelve un valor Boolean si Pac-Man anota.
La función debe devolver `True` si Pac-Man está tocando una píldora de poder o un punto.

```powershell
> Score -TouchDot $true -TouchPowerPellet $true
4
```

## 3. Define si Pac-Man pierde

Define la función `Lose` que recibe dos parámetros (_si Pac-Man tiene una píldora de poder activa_ y _si Pac-Man está tocando a un fantasma_) y devuelve un valor Boolean si Pac-Man pierde.
La función debe devolver `True` si Pac-Man está tocando a un fantasma y no tiene una píldora de poder activa.

```powershell
> Lose -ActivePower $false -TouchingGhost $true
True
```

## 4. Define si Pac-Man gana

Define la función `Win` que recibe tres parámetros (_si Pac-Man se ha comido todos los puntos_, _si Pac-Man tiene una píldora de poder activa_ y _si Pac-Man está tocando a un fantasma_) y devuelve un valor Boolean si Pac-Man gana.
La función debe devolver `True` si Pac-Man se ha comido todos los puntos y no ha perdido según los parámetros definidos en la parte 3.

```powershell
> Win -EatenAllDots $false -ActivePower $true -TouchingGhost $false
False
```

## 5. Escribe la sinopsis para la condición de victoria

Regresa a la última función, agrega una sección `Synopsis` al bloque de comentarios como una breve descripción de cómo ganar el juego.
La descripción debe tener como mínimo diez caracteres de longitud.

```powershell
function MyFunc($Arg) {
    <#
    .DESCRIPTION
    This is a demonstration of the comment-based help with the description keyword.
    #>
}
```
