# Pistas

## General

- Presta mucha atención a la sintaxis de los punteros.
  Vas a usar `*` (operador de desreferencia) y `->` (acceso a un miembro a través de un puntero).
- Asegúrate de verificar si hay punteros nulos (`nullptr`) cuando sea necesario, para evitar acceder a memoria no válida.
- Puedes ejecutar los tests aunque tu código no esté completo; una estructura básica basta para ver los resultados de los tests.
- Todas las funciones que usan los tests deben estar declaradas en el archivo de cabecera.
- Si tu programa se bloquea o se comporta de forma inesperada, muchas veces se debe a una desreferencia de puntero nulo.
  Vuelve a revisar que manejes `nullptr` correctamente.
- Cuando uses aritmética de punteros, asegúrate de mantenerte dentro de los límites del array de sensores.
  Salirte de la capacidad del array puede provocar problemas de memoria.

## 1. Verifica la conexión del sensor (`connection_check`)

- La tarea consiste principalmente en verificar si un puntero es nulo o no.
- Usa el operador de comparación `!=` para comprobar si un puntero es válido.
- Si tienes dudas sobre si estás verificando bien el puntero, piensa en lo que representa `nullptr` (la ausencia de una dirección de memoria válida).


## 2. Cuenta la actividad de los sensores (`activity_counter`)

- Necesitas recorrer el array de sensores.
  Un array en C++ se puede tratar como un puntero a su primer elemento.
- Usa aritmética de punteros (`sensor_array + i`) para acceder al sensor en el índice `i`.
- El operador `->` se usa para acceder a un miembro del struct a través de un puntero.

### Ejemplo

```cpp
int sum = (sensor_array + i)->activity; // Access activity using pointer arithmetic
```

- Usa el operador `->` para acceder al miembro `activity` del struct `pillar_men_sensor`.
- Piensa bien qué debería pasar si el nivel de actividad del sensor es `0`.

- Usa el operador `&` para pasar un puntero al array de datos del sensor a la función `uv_light_heuristic`.
- Asegúrate de verificar correctamente que no haya un puntero nulo antes de acceder a los datos del sensor.
