# Introducción

En Kotlin, `when` es una expresión condicional para elegir entre varias opciones.
Es similar a `switch` en Java y más flexible que una cadena de `if` ... `else if` ... `else`.

Al igual que `if`, `when` también se puede usar como una expresión que produce un valor.

## Coincidir con un valor

Dale a `when` un valor entre paréntesis con el que comparar.
Cada rama compara ese valor hasta que una coincide:

```kotlin
val animal = "chicken"
val type = when (animal) {
    "chicken" -> "bird"
    "poodle" -> "dog"
    else -> "unknown"
}
// type => "bird"
```

- Cada rama se escribe como `pattern -> result`.
- Las ramas se prueban de arriba a abajo hasta que se encuentra una coincidencia.
  Solo se ejecuta la primera rama.
- Usa `else` para cualquier valor que no aparezca arriba (similar al `else` final de una cadena de `if`).

Esto es similar a la [coincidencia de patrones][pattern-matching].
El `pattern` puede ser un valor con el que coincidir, o puedes usar `is` para coincidir por tipo:

```kotlin
fun typeText(subject: Any): String {
    return when(subject) {
        is Animal -> "Animal"
        is Fruit -> "Fruit"
        is String -> "Text"
        else -> "Unknown"
    }
}
```

o usa `in` para comprobar si está contenido en un rango, una colección, un string o cualquier otra cosa que tenga un método `contains`:

```kotlin
fun describe(number: Int, position: String) {
    // Range
    when(number) {
        in 1..10 -> println("From 1 to 10")
        in 11..20 -> println("From 11 to 20")
    }

    // Collection
    when(number) {
        in listOf(2, 4, 6) -> println("small even")
        in listOf(3, 5, 7) -> println("small odd")
    }

    // String
    when(position) {
        in "center middle" -> println("inner")
        in "left right boundary" -> println("outer")
    }
}
```

## Condiciones de guarda

Al coincidir con un valor, se pueden colocar condiciones adicionales en un `if` después del patrón.
Estas condiciones se llaman condiciones de guarda.

```kotlin
val x = 5
val y = 10
val description = when (x) {
    5 if y % 2 == 0 -> "x is 5, y is even"
    else -> "other"
}
// description => "x is 5, y is even"
```

Incluso se puede usar `else if`.

```kotlin
val x = 7
val y = 10
val description = when (x) {
    5 if y % 2 == 0 -> "x is 5, y is even"
    else if y % 2 == 0 -> "y is an even number"
    else -> "other"
}
// description => "y is an even number"
```


## Coincidir con condiciones

Como alternativa, se puede omitir el valor y colocar condiciones booleanas en cada rama:

```kotlin
val x = 5
val y = 8
val description = when {
    x % 2 != 0 -> "x is odd"
    y % 2 == 0 -> "y is even"
    else -> "neither condition matched first"
}
// description => "x is odd"
```

De nuevo, las ramas se comprueban de arriba a abajo y solo se ejecuta la primera rama cuya condición sea `true`.

## Usar `when` como expresión

Cuando se usa `when` por su resultado (asignado a una variable, devuelto desde una función, etcétera), se deben cubrir todos los casos posibles.

- Al coincidir con un valor, agrega `else` a menos que ya se hayan cubierto todos los valores posibles (por ejemplo, todos los valores de un `Boolean` o de un `enum`).
- Al coincidir con condiciones, se requiere una rama `else`, porque el compilador no puede saber que tus condiciones cubren todos los casos.

```kotlin
fun label(n: Int): String = when (n) {
    0 -> "zero"
    1 -> "one"
    else -> "other"
}
```
