# Aprendizaje

Exercism ofrece ejercicios y comentarios, pero puede ser difícil de abordar para quienes están aprendiendo Clojurescript por primera vez.
Clojurescript es un dialecto de Clojure. La sintaxis y las funciones del Core son casi iguales. Pero Clojurescript se diferencia de Clojure de forma significativa en aspectos profundos, debido a la plataforma anfitriona.
Por eso, se recomienda entender Clojure como lenguaje. Por ese motivo, encontrarás algunos recursos de Clojure en este mismo documento.

Estos recursos pueden ayudarte a empezar:

## Referencias
- [ClojureScript.org](https://clojurescript.org/index) El sitio web oficial del lenguaje.
- [ClojureScript Documentation](https://clojurescript.org/reference/documentation) Una página de documentación oficial.

## Ejercicios y tutoriales
- [Clojurescript Koans](http://clojurescriptkoans.com/) es una ruta de aprendizaje interactiva.
