# Instalación

Primero, asegúrate de tener Erlang instalado, siguiendo las instrucciones que correspondan en la página de instalación de [Erlang][1].
[1]: /languages/erlang

## Homebrew para Mac OS X

Actualiza tu Homebrew a la última versión:

```bash
$ brew update
```

Instala LFE:

```bash
$ brew install lfe
```

## Instalación desde el código fuente
Instala las «herramientas de desarrollo» o los «paquetes de compilación esenciales» de tu sistema, `git` y `erl` de Erlang.

Por ejemplo, en Ubuntu 18.04:

```bash
$ sudo apt-get install build-essential git erlang erlang-base-hipe
```

Después puedes descargar y compilar LFE con lo siguiente:

```bash
$ git clone https://github.com/lfe/lfe.git
$ cd lfe
$ make
$ make install
```

Una vez que hayas compilado LFE, puedes iniciar el REPL (sesión interactiva) ejecutando el binario ``lfe``:

```bash
$ ./bin/lfe
```
