# Instalación

Necesitas [NodeJS LTS](https://nodejs.org/en).

> 💡 Es probable que este track funcione con versiones estables anteriores, así como con la versión «current».
> Sin embargo, [por diseño](https://github.com/nodejs/release#release-schedule), las versiones impares nunca son estables.
> Asegúrate siempre de instalar una versión par de NodeJS.

Instala [Yarn 4+](https://yarnpkg.com/getting-started/install) usando `corepack` de Node.JS:

```shell
corepack enable yarn
```

## Comprobar tu instalación

Por lo general, necesitas abrir una terminal nueva para poder usar los binarios que acabas de instalar.

```shell
$ node -v
v20.15.0

$ corepack -v
0.28.1

$ corepack yarn -v
v4.3.1
```

_Nota: es probable que tus versiones sean distintas de estas._

## Instalación de los ejercicios

**Cada ejercicio** necesita algunas herramientas para ejecutar las pruebas:

Se pueden instalar ejecutando este comando dentro del directorio de cada ejercicio:

```bash
$ corepack yarn install
```

Según tu editor, es necesario instalar el [Editor SDK](https://yarnpkg.com/getting-started/editor-sdks) en cada ejercicio para que funcione con las instalaciones de Plug'n'Play.
Al momento de escribir esto, se admiten los siguientes:

- [CoC nvim](https://yarnpkg.com/getting-started/editor-sdks#coc-nvim)
- [Emacs](https://yarnpkg.com/getting-started/editor-sdks#emacs)
- [Neovim Native LSP](https://yarnpkg.com/getting-started/editor-sdks#neovim-native-lsp)
- [VSCode](https://yarnpkg.com/getting-started/editor-sdks#vscode)
