# Pistas

## General

- Lee sobre [`alias` e `import`][getting-started] en la guía de primeros pasos.
- Lee sobre la [composición de módulos][elixir-school-module-composition] en elixirschool.com.

## 1. Corrige el error de compilación `Race.__struct__/0 is undefined`

- Puedes crear un alias con la forma especial [`alias`][alias].

## 2. Corrige el error de compilación `Car.__struct__/0 is undefined`

- Puedes crear un alias con la forma especial [`alias`][alias].
- La forma especial `alias` acepta una opción `:as`.

## 3. Corrige el error de compilación `undefined function puts/1`

- Puedes importar funciones con la forma especial [`import`][import].
- La forma especial [`import`][import] acepta una opción `:only`. Su valor debe ser una lista de palabras clave con los nombres de las funciones como claves y las aridades de las funciones como valores.

## 4. Corrige el error de compilación `undefined function default_color/0`

- Puedes importar funciones con la forma especial [`import`][import].
- La forma especial [`import`][import] acepta una opción `:except`. Su valor debe ser una lista de palabras clave con los nombres de las funciones como claves y las aridades de las funciones como valores.
