# Acerca de

Ruby incluye una Biblioteca Estándar (a la que a menudo se le llama simplemente «stdlib»): una colección de clases para trabajar con cosas como fechas, json y redes.
También te ofrece algunas funcionalidades útiles que hacen más fácil trabajar con tu código.

`OpenStruct` forma parte de la Biblioteca Estándar y te permite crear fácilmente un objeto a partir de un `Hash`.
En lugar de tener que acceder a los valores usando las claves de un `Hash`, `OpenStruct` nos permite usar métodos para acceder a ellos y asignarlos.

Cuando usas clases de la Biblioteca Estándar, o de cualquier otra biblioteca, necesitas requerir esa clase usando el método `require`.

```ruby
require 'ostruct'

attributes = { name: "Jeremy Walker", age: 21, location: "Nomadic" }
person = OpenStruct.new(attributes)

person.name
#=> Jeremy Walker

person.location
#=> Nomadic

# Update the age
person.age = 35

# It sets correctly
person.age
#=> 35
```

Una ventaja adicional de esto es que puedes aprovechar un atajo cuando usas la sintaxis de bloques.
Cuando un bloque llama a un solo método, puedes reemplazar el bloque con `&:` seguido del nombre del método.
Por ejemplo, estas dos líneas son sinónimas:

```ruby
people.sum { |person| person.age }
people.sum(&:age)
```
