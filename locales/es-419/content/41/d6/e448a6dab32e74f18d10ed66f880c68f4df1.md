# Acerca de

La biblioteca estándar de Elixir ofrece 4 módulos diferentes para trabajar con fechas y horas, cada uno con su propio struct.

- El [módulo `Date`][date]. Un struct `Date` se puede crear con el [sigilo `~D`][sigil-d].
    ```elixir
    ~D[2021-01-01]
    ```

- El [módulo `Time`][time]. Un struct `Time` se puede crear con el [sigilo `~T`][sigil-t].
    ```elixir
    ~T[12:00:00]
    ```

- El [módulo `NaiveDateTime`][naivedatetime] para fechas y horas sin zona horaria. Un struct `NaiveDateTime` se puede crear con el [sigilo `~N`][sigil-n].
    ```elixir
    ~N[2021-01-01 12:00:00]
    ```

- El [módulo `DateTime`][datetime] para fechas y horas con zona horaria. Usar este módulo para zonas horarias distintas de UTC requiere una dependencia externa, una base de datos de zonas horarias. Un struct `DateTime` se puede representar con el [sigilo `~U`][sigil-u], pero conviene crearlo con funciones de `DateTime`.
    ```elixir
    DateTime.new!(~D[2021-01-01], ~T[12:00:00], "Etc/UTC")
    # => ~U[2021-01-01 12:00:00Z]
    ```

## Comparaciones

Para comparar fechas u horas entre sí, busca una función `compare` o `diff` en el módulo correspondiente. Los operadores de comparación como `==`, `>` y `<` _parecen_ funcionar, pero no hacen una comparación semántica correcta para esos structs.

```elixir
Date.compare(~D[2020-11-30], ~D[2020-12-01])
# => :lt

Time.diff(~T[13:45:00], ~T[13:46:30])
# => -90
```

## Desplazamiento

Las fechas, las horas y las fechas y horas se pueden desplazar hacia adelante y hacia atrás en el tiempo usando la función `add/2` del módulo correspondiente.

```elixir
# add 4 days
Date.add(~D[2021-01-01], 4)
# => ~D[2021-01-05]

# subtract 1 second
Time.add(~T[12:00:00], -1)
# => ~T[11:59:59.000000]

# add 4 days and 30 seconds
NaiveDateTime.add(~N[2021-01-01 12:00:00], 4 * 24 * 60 * 60 + 30)
# => ~N[2021-01-05 12:00:30]
```

## Conversiones

Un struct `NaiveDateTime` se puede descomponer en un struct `Date` y un struct `Time` usando [`NaiveDateTime.to_date/1`][naivedatetime-to-date] y [`NaiveDateTime.to_time/1`][naivedatetime-to-time]. Lo contrario se puede lograr con [`NaiveDateTime.new!/2`][naivedatetime-new].

```elixir
NaiveDateTime.to_date(~N[2021-01-01 12:00:00])
# => ~D[2021-01-01]

NaiveDateTime.to_time(~N[2021-01-01 12:00:00])
# => ~T[12:00:00]

NaiveDateTime.new!(~D[2021-01-01], ~T[12:00:00])
# => ~N[2021-01-01 12:00:00]
```
