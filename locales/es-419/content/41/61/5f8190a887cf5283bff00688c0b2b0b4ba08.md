# Instrucciones

Implementa el método clásico para componer mensajes secretos llamado código cuadrado.

Dado un texto en inglés, produce la versión codificada de ese texto.

Primero, la entrada se normaliza: se eliminan los espacios y la puntuación del texto en inglés y el mensaje se pasa a minúsculas.

Luego, los caracteres normalizados se dividen en filas. Estas filas se pueden considerar como formando un rectángulo cuando se imprimen con saltos de línea intermedios.

Por ejemplo, la frase

```text
"If man was meant to stay on the ground, god would have given us roots."
```

se normaliza a:

```text
"ifmanwasmeanttostayonthegroundgodwouldhavegivenusroots"
```

El texto plano debe organizarse en un rectángulo. El tamaño del rectángulo (`r x c`) debe decidirse según la longitud del mensaje, de modo que `c >= r` y `c - r <= 1`, donde `c` es el número de columnas y `r` es el número de filas.

Nuestro texto normalizado tiene 54 caracteres, lo que determina un rectángulo con `c = 8` y `r = 7`:

```text
"ifmanwas"
"meanttos"
"tayonthe"
"groundgo"
"dwouldha"
"vegivenu"
"sroots  "
```

El mensaje codificado se obtiene leyendo hacia abajo por las columnas, de izquierda a derecha.

El mensaje de arriba se codifica como:

```text
"imtgdvsfearwermayoogoanouuiontnnlvtwttddesaohghnsseoau"
```

Produce el texto codificado en fragmentos que llenen rectángulos perfectos `(r X c)`, con `c` fragmentos de longitud `r`, separados por espacios. Para las frases a las que les falten `n` caracteres para el rectángulo perfecto, rellena cada uno de los últimos `n` fragmentos con un solo espacio al final.

```text
"imtgdvs fearwer mayoogo anouuio ntnnlvt wttddes aohghn  sseoau "
```

Fíjate que si apiláramos estos fragmentos, podríamos decodificar visualmente el criptograma y recuperar el mensaje original:

```text
"imtgdvs"
"fearwer"
"mayoogo"
"anouuio"
"ntnnlvt"
"wttddes"
"aohghn "
"sseoau "
```
