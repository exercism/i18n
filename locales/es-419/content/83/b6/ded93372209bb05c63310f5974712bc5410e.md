# Anexo de las instrucciones

## Palabras

Define una tupla `school` que contenga la lista de estudiantes (cómo almacenas a los
estudiantes dentro de ella depende de ti) y luego implementa las palabras que aparecen a
continuación.

- `<school> ( -- school )`: construye una escuela vacía.
- `add-student ( school name grade -- ? )`: agrega `name` a
  `grade`. Devuelve `t` si tiene éxito, o `f` si `name` ya se había
  agregado (a este grado o a cualquier otro), en cuyo caso la lista
  no se modifica.
- `roster ( school -- names )`: todos los estudiantes, ordenados por grado
  y luego alfabéticamente por nombre.
- `grade ( school n -- names )`: los estudiantes del grado `n`,
  ordenados alfabéticamente por nombre.
