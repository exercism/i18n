# Introducción

## Alias

Para compartir código entre distintos módulos de Elixir dentro de un mismo proyecto, necesitas referirte al módulo externo por su nombre completo. Pero, ¿qué pasa si ese nombre es demasiado largo o confuso?

La forma especial `alias` te permite acortar o cambiar el nombre con el que te refieres a un módulo externo. Cuando se usa sin argumentos, reduce el nombre del módulo a su último segmento, por ejemplo, `MyApp.Logger.Settings` pasa a ser `Settings`. Puedes especificar un nombre personalizado con la opción `:as`.

Por lo general, los alias se agregan al inicio de la definición del módulo.

```elixir
defmodule Square do
  alias Integer, as: I

  def area(a), do: I.pow(a, 2)
end
```

## Import

La forma especial `import` te permite usar funciones de un módulo externo sin usar el nombre del módulo.

Importar un módulo externo completo puede crear conflictos con las funciones locales que ya existen. Para evitarlo, tienes dos opciones disponibles: `:except` y `:only`. Ambas esperan una lista de palabras clave, donde la clave es el nombre de la función y el valor es la aridad de la función.

Por lo general, las importaciones se agregan al inicio de la definición del módulo.

```elixir
defmodule Square do
  import Integer, only: [pow: 2]

  def area(a), do: pow(a, 2)
end
```
