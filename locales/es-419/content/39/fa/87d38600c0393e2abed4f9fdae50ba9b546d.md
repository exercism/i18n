# Introducción

Las tablas hash en Common Lisp son estructuras de datos para almacenar datos asociativos.
Asocian claves (que pueden ser cualquier objeto) con valores (que también pueden ser cualquier objeto).
Otros lenguajes pueden referirse a este concepto como mapas, diccionarios o hashes.

## Crear tablas hash

Las tablas hash se pueden crear con la función `make-hash-table`.

`(make-hash-table) ; => #<HASH-TABLE :TEST EQL :COUNT 0 {10024AD2B3}>`

(Ten en cuenta que la presentación impresa de una tabla hash depende de la implementación, así que puede verse diferente en tu REPL.)

## Obtener valores por clave

Para obtener un valor a partir de una clave de la tabla hash, usas la función `gethash`:

```lisp
*h* ; => #<HASH-TABLE :TEST EQL :COUNT 3 {10024AD2B3}>`
(gethash :foo *h*) ; => :bar
                   ;    T
```

`gethash` devuelve [múltiples valores][concept-multiple-values], lo cual se explicará en otro concepto.

## Insertar valores

Para insertar un valor en una tabla hash, usas `setf` junto con `gethash` así:

`(setf (gethash :foo *hash-table*) :bar) : => :bar`

Esto modifica el valor de la clave `:foo` en la tabla hash `*hash-table*` para que sea `:bar`.
Devuelve el valor.

El uso de `setf` se explicará en otro concepto.
