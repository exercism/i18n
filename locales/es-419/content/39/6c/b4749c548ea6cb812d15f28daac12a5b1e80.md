# Anexo de instrucciones

## Funciones y pruebas

Se te proporciona una definición inicial para la función `SayHi`.

```delphi
function SayHi : string;
begin
  result := 'Goodbye, Mars!';
end;
```

El ejecutor de pruebas toma esta función y la ejecuta, comparando el valor que [devuelve][returns] con el valor que espera.
Usa esta definición inicial de la función como base para tu solución.
