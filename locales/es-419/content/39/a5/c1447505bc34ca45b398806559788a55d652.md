# Introducción

Una `list` en R es una colección ordenada de elementos, que se diferencia de los `vectors` en varios aspectos:

- Los elementos pueden ser de distintos tipos (por ejemplo, mezclar `numeric` con `character`).
- Los elementos pueden ser estructuras complejas (por ejemplo, vectores, otras listas, etc.).
- Hay una sintaxis distinta para acceder a los elementos.

Las analogías con otros lenguajes son imprecisas.
Una `list` de R se parece un poco a un diccionario de Python, pero la `list` está ordenada y se puede acceder a ella mediante un índice numérico.
También se parece un poco a un `struct` de C, salvo que la `list` se puede extender fácilmente en tiempo de ejecución.

## Crear listas

Asignar nombres (a los que a menudo se les llama «tags») a los elementos es más común en las listas que en los vectores:

```R
list(x = 5.3, y = 4.2, color = "blue")
$x
#> [1] 5.3

$y
#> [1] 4.2

$color
#> [1] "blue"
```

Sin embargo, los tags son opcionales, y en ese caso R solo usa números de índice:

```R
list(5.3, 4.2, "blue")
#> [[1]]
#> [1] 5.3

#> [[2]]
#> [1] 4.2

#> [[3]]
#> [1] "blue"
```

## Acceder a los elementos de una lista

Hay tres formas de hacerlo, y cada una es útil en contextos distintos.

### 1. Con la notación `$tag`

Es muy común si los nombres de los tags se conocen de antemano.

```R
point <- list(x = 5.3, y = 4.2, color = "blue")
point$x
#> [1] 5.3
point$color
#> [1] "blue"
```

### 2. Con la notación `[[tag]]`

Tiene la ventaja de que el nombre del tag se puede elegir en tiempo de ejecución.
Fíjate en los corchetes dobles.

```R
want <- "y"
point[[want]] # same as point$y
#> [1] 4.2
```

### 3. Con el índice de posición

Funciona tanto si la lista tiene tags como si no.
De nuevo, los corchetes van dobles.

```R
point[[3]] # same as point$color
#> [1] "blue"
```

## Agregar y eliminar elementos

Es sencillo: asignar un valor a un elemento lo modifica si ya existe, o lo inserta si es nuevo.

```R
point$color <- "red"
point[[trust]] <- TRUE
str(point)
#> List of 4
#>  $ x    : num 5.3
#>  $ y    : num 4.2
#>  $ color: chr "red"
#>  $ trust: logi TRUE
```

Para eliminar, asigna `NULL` al elemento que no quieras.

```R
point$trust <- NULL
str(point)
#> List of 3
#>  $ x    : num 5.3
#>  $ y    : num 4.2
#>  $ color: chr "red"
```
