# Instrucciones

Un amigo tuyo tiene una antigua tienda mayorista llamada **Gross Store**.

El nombre viene de la cantidad de artículos que vende la tienda: todo está en [unidades de gruesa][gross-unit].

Tu amigo te pidió que implementaras un sistema de punto de venta (POS) para su tienda.

**Primero, quieres construir un prototipo para él.**

**En tu prototipo, tu sistema solo registrará la cantidad.**

Tu amigo te dio una lista de medidas para ayudarte:

| Unidad             | Valor |
| ------------------ | ----- |
| quarter_of_a_dozen | 3     |
| half_of_a_dozen    | 6     |
| dozen              | 12    |
| small_gross        | 120   |
| gross              | 144   |
| great_gross        | 1728  |

## 1. Guarda la unidad de medida en tu programa

Para poder usar la medida, necesitas guardarla en tu programa.

```rust
let units = units();
// Felt252Dictionary with entries like { 'dozen': 12 }
```

## 2. Crea una nueva cuenta de cliente

Necesitas implementar una función que cree una nueva cuenta (vacía) para el cliente.

```rust
let bill = new_bill();
// Empty Felt252Dictionary
```

## 3. Agrega un artículo a la cuenta del cliente

Para implementar esto, necesitas:

- Devolver `false` si la `unit` dada no está en el mapa `units`.
- De lo contrario, agrega el artículo a la `bill` del cliente, indexado por el nombre del artículo, y luego devuelve `true`.
- Si el artículo ya está presente en la cuenta, aumenta su cantidad en la que corresponde a la `unit` proporcionada.

```rust
let bill = new_bill();
let units = units();
let ok = add_item(bill, units, 'carrot', 'dozen');
println!(ok);
// Output: true (since dozen is a valid unit)
```

> Ten en cuenta que el valor devuelto es de tipo `bool`.

## 4. Elimina un artículo de la cuenta del cliente

Para implementar esto, necesitas:

- Devolver `false` si el artículo dado **no** está en la cuenta.
Un artículo se considera que no está en la cuenta si su cantidad es 0.
- Devolver `false` si la `unit` dada no está en el mapa `units`.
- Devolver `false` si la nueva cantidad fuera menor que 0.
- Si la nueva cantidad es 0, el artículo se considera eliminado de la `bill`, así que puedes devolver `true`.
- De lo contrario, reduce la cantidad del artículo y devuelve `true`.

```rust
let bill = new_bill();
let units = units();
let ok = remove_item(bill, units, 'carrot', 'dozen');
println!(ok);
// Output: false (because there are no carrots in the bill)
```

> Ten en cuenta que el valor devuelto es de tipo `bool`.

## 5. Devuelve la cantidad de un artículo específico que está en la cuenta del cliente

```rust
let mut bill: Felt252Dict<u32> = Default::default();
bill.insert('carrot', 12);
bill.insert('grapes', 3);
let qty = get_item(bill, 'carrot');
println!(qty);
// Output: 12
```

> Ten en cuenta que el valor devuelto es de tipo `u32`.

[gross-unit]: https://en.wikipedia.org/wiki/Gross_(unit)
