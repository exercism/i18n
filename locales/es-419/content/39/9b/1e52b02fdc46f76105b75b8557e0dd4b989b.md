# Luhn: usar el trait From

Antes de hacer este ejercicio probablemente deberías hacer el ejercicio original de Luhn. Si todavía no completaste Luhn, puedes obtenerlo ejecutando el comando:

```shell
exercism download --exercise=luhn --track=rust
```

En el ejercicio original de Luhn solo validabas strings, pero el algoritmo de Luhn también se puede aplicar a números enteros.

En este ejercicio implementarás el [trait From](https://doc.rust-lang.org/std/convert/trait.From.html) para convertir strings, strs y enteros sin signo en un struct que realiza la validación.
