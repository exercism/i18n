# Tests

## Ejecutar los tests

Para ejecutar los tests, ejecuta el siguiente comando:

```bash
make
```

## Resolver el ejercicio

Resolver un ejercicio significa hacer que todos sus tests pasen.
Por defecto, solo se ejecuta un test (el primero) cuando ejecutas los tests.
Esto es a propósito, ya que te permite enfocarte solo en hacer que ese único test pase.
Una vez que pase, puedes habilitar el siguiente test eliminando la línea `TEST_IGNORE()`.
Cuando todos los tests estén habilitados y tu implementación haga que todos pasen, ¡habrás resuelto el ejercicio!
