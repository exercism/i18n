# Números

`INT` es el tipo de Sather para los números enteros: `0`, `7`, `-3`. Una rutina
que responde con un número entero lo indica después de los dos puntos, igual
que una rutina que responde con texto indica `STR`.

```sather
   goals : INT is
      return 42;
   end;
```

Las rutinas pueden recibir **argumentos**: valores que se pasan cuando se llama
a la rutina. Cada argumento lleva un nombre y un tipo, entre paréntesis después
del nombre de la rutina:

```sather
   total(first : INT, second : INT) : INT is
      return first + second;
   end;
```

Cuando dos argumentos tienen el mismo tipo, puedes nombrarlos juntos:

```sather
   total(first, second : INT) : INT is
```

La llamas poniendo los valores entre paréntesis:

```sather
SCORES::total(3, 4)     -- this is 7
```

Los cinco operadores aritméticos son `+`, `-`, `*`, `/` y `%`.

La `/` entre dos `INT` es **división entera**: descarta el residuo en lugar de
darte una fracción.

```sather
7 / 2      -- 3, not 3.5
```

El `%` da lo que sobra de esa división.

```sather
7 % 2      -- 1
```

Los dos van juntos: `7` son `3` veces `2` y sobra `1`.
