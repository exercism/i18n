# Acerca de

PHP tiene varias estructuras de control de bucles integradas, como `while`. La forma básica de una sentencia `while` es:

```php
while (expr) {
  // statements
}
```

Mientras la expresión (_expr_) se evalúe a un valor _truthy_, iterará sobre las sentencias que están dentro del bucle. Si la expresión (_expr_) se evalúa como false antes de la primera iteración, las sentencias nunca se ejecutan.

Como alternativa, puedes usar un bucle `do-while`, que ejecuta las sentencias del bucle una vez antes de evaluar la expresión (_expr_).

```php
do {
  // statements
} while (expr);
```
