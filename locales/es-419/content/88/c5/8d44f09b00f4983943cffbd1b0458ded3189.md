# Introducción

Los caracteres de Factor son enteros, es decir, puntos de código Unicode, así que los `<`, `>`, `=` numéricos te dan directamente un orden que distingue mayúsculas de minúsculas. El vocabulario [`unicode`][unicode] agrega predicados que entienden Unicode y la conversión de mayúsculas y minúsculas de un solo carácter.

## Predicados de caracteres

```
LETTER?  ( c -- ? )    ! uppercase letter
letter?  ( c -- ? )    ! lowercase letter
Letter?  ( c -- ? )    ! letter, either case
digit?   ( c -- ? )    ! decimal digit
blank?   ( c -- ? )    ! whitespace
```

```factor
USING: unicode ;

CHAR: A LETTER? .    ! => t
CHAR: a letter? .    ! => t
CHAR: 7 digit?  .    ! => t
```

## Conversión de mayúsculas y minúsculas

`ch>upper` y `ch>lower` cambian un solo carácter. Las versiones a nivel de string, `>upper` y `>lower`, las aplican a cada carácter de un string.

```factor
CHAR: a ch>upper .   ! => 65   (which is CHAR: A)
"Hello" >upper .     ! => "HELLO"
```
