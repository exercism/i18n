# Pistas

## 1. Obtén la primera carta

- [Esta guía][destructuring_resource] tiene un buen resumen de la desestructuración secuencial. Puedes encontrar un ejemplo de cómo vincular nombres a valores.

## 2. Obtén la segunda carta

- Puedes usar marcadores de posición para ignorar uno o más valores en la vinculación.

## 3. Intercambia las dos primeras cartas

- Es posible usar `&` para combinar los elementos restantes en una secuencia.

## 4. Descarta la carta superior

- Puedes usar `:as all` para vincular el vector completo al símbolo `all`.

## 5. Inserta cartas con figuras

- Puedes encontrar más información sobre dónde desestructurar [aquí][where-to-destructure].
