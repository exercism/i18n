# Recursos

## Aprendizaje

- [Nim basics](https://narimiran.github.io/nim-basics/) - para quienes están empezando a programar.
- [Nim tutorial, part 1](https://nim-lang.org/docs/tut1.html) - para quienes ya tienen algo de experiencia en programación.
- [Learn X in Y minutes for Nim](https://learnxinyminutes.com/docs/nim/) - una introducción a la sintaxis.
- [Nim for Python programmers](https://github.com/nim-lang/Nim/wiki/Nim-for-Python-Programmers)
- [Nim for C programmers](https://github.com/nim-lang/Nim/wiki/Nim-for-C-programmers)
- [Nim in Action](https://www.manning.com/books/nim-in-action) - disponible como libro impreso o como libro electrónico.

Consulta la página oficial [Learn Nim](https://nim-lang.org/learn.html) para ver más.
