# Instrucciones

En este ejercicio vas a trabajar con cuentas de ahorro. Cada año, el saldo de tu cuenta de ahorro se actualiza según su tasa de interés. La tasa de interés que te da el banco depende de la cantidad de dinero que hay en tu cuenta (su saldo):

- 3.213% para un saldo negativo (da como resultado un interés negativo).
- 0.5% para un saldo positivo menor que `1000` dólares.
- 1.621% para un saldo positivo mayor o igual que `1000` dólares y menor que `5000` dólares.
- 2.475% para un saldo positivo mayor o igual que `5000` dólares.

Cada año, el gobierno te permite donar un porcentaje de tu dinero a organizaciones benéficas, libre de impuestos. Como eres una buena persona, si tu saldo termina siendo positivo al final del año, tomas el porcentaje libre de impuestos y lo duplicas, redondeando hacia abajo al dólar entero más cercano. No te importa pagar impuestos por la segunda mitad de la donación.

Tienes tres tareas, y cada una trata sobre tu saldo y su tasa de interés.

## 1. Calcula la tasa de interés

Implementa la función `interestRate` para calcular la tasa de interés a partir del saldo indicado:

```fsharp
interestRate 200.75m
// => 0.5f
```

Ten en cuenta que el valor que se devuelve es un `single`.

## 2. Calcula el interés

Implementa el método `interest` para calcular el interés a partir del saldo indicado:

```fsharp
interest 200.75m
// => 1.00375m
```

Ten en cuenta que el valor que se devuelve es un `decimal`.

## 3. Calcula la actualización anual del saldo

Implementa la función `annualBalanceUpdate` para calcular la actualización anual del saldo, teniendo en cuenta la tasa de interés:

```fsharp
annualBalanceUpdate 200.75m
// => 201.75375m
```

Ten en cuenta que el valor que se devuelve es un `decimal`.

## 4. Calcula cuánto dinero donar

Implementa la función `amountToDonate` para calcular cuánto dinero donar a organizaciones benéficas a partir del saldo y del porcentaje libre de impuestos que permite el gobierno:

```fsharp
let balance = 550.5m
let taxFreePercentage = 2.5
amountToDonate balance taxFreePercentage
// => 27
```

Ten en cuenta que el valor que se devuelve es un `int`.
