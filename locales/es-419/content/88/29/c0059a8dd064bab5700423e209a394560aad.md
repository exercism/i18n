# Pruebas

Las pruebas requieren que el paquete `{testthat}` esté instalado en R.
Para ejecutar las pruebas de un ejercicio, simplemente ejecuta el script `test_<exercise_name>.R` desde dentro del directorio del ejercicio.

Esto lo puedes hacer cómodamente con [la función `auto_test` de testthat](https://testthat.r-lib.org/reference/auto_test.html). Como el código de Exercism y las pruebas están en la misma carpeta, usa esta misma ruta para los parámetros `code_path` y `test_path`. Desde la línea de comandos, también puedes ejecutar `Rscript test_<exercise_name>.R`.

Consulta la [página de pruebas](https://exercism.org/docs/tracks/r/tests) para más información.
