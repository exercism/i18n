# Números

Crystal tiene un tipo, `Number`, que es el tipo base de todos los tipos numéricos.
Dentro del tipo Number hay dos subtipos principales: [`Int`][int] y [`Float`][float].

`Int` es la abreviación de integer y representa números enteros.
`Int` puede ser negativo o positivo, y no lleva punto decimal.

```crystal
1.class
# => Int32

-1.class
# => Int32
```

`Float` representa números con punto decimal.
Los valores `Float` pueden ser negativos o positivos.

```crystal
10.5.class
# => Float64
```

## Conversión entre `Int` y `Float`

Usando los métodos `to_i` y `to_f`, puedes convertir entre `Int` y `Float`.
Al convertir de `Float` a `Int`, el número se redondea hacia abajo.

```crystal
1.to_f
# => 1.0

1.0.to_i
# => 1

1.9.to_i
# => 1
```

## Operadores aritméticos

Puedes usar los [operadores aritméticos básicos][math] con `Int` y `Float`.
Los operadores son `+`, `-`, `*`, `/` y `%`.
Al usar estos operadores, puedes combinar `Int` y `Float`.

### Suma, resta y multiplicación

El operador `+` se usa para la suma, el operador `-` para la resta y el operador `*` para la multiplicación.

| Operador | Ejemplo        |
| -------- | -------------- |
| `+`      | `4 + 6 => 10`  |
| `-`      | `15 - 10 => 5` |
| `*`      | `2 * 3 => 6`   |

### División

La división sirve para dividir números.
El operador `/` se usa para la división.
El resultado siempre será un Float.

```crystal
4 / 2
# => 2.0

4.0 / 2
# => 2.0
```

~~~~exercism/caution
En algunos lenguajes de programación, al dividir entre cero el resultado es un error.

En Crystal, al dividir entre cero el resultado es `Infinity` o `-Infinity`.
La única excepción es dividir cero entre cero, lo que da como resultado `NaN` (no es un número).
`Infinity` y `NaN` son valores particulares del tipo `Float`.

```crystal
1 / 0
# => Infinity

-1 / 0
# => -Infinity

0 / 0
# => NaN
```
~~~~

### Módulo

El módulo se usa para obtener el residuo de una división.
El operador `%` se usa para el módulo.

```crystal
5 % 2
# => 1

5.0 % 2
# => 1.0

5 % 3
# => 2
```

~~~~exercism/caution
Dividir entre cero al usar el módulo da como resultado un DivisionByZeroError.
Esto es distinto de la división normal.

```crystal
1 % 0
# Error: Unhandled exception: Division by 0 (DivisionByZeroError)
```
~~~~

## Redondeo

El método `round` toma un argumento opcional: el número de decimales a los que se redondea.
El número de decimales por defecto es 0.

```crystal
1.0.round
# => 1

1.5.round
# => 2

1.234.round(2)
# => 1.23
```

## Prioridad y paréntesis

Crystal permite usar paréntesis (`()`), que sirven para agrupar expresiones.
Esto es útil cuando quieres cambiar el orden de las operaciones.

Cuando usas varios operadores aritméticos, el orden de las operaciones es el mismo que en matemáticas, también conocido como [PEMDAS][pemdas].
Sigue el orden de los paréntesis (`()`), los exponentes (`**`), la multiplicación (`*`) y la división (`/`), y la suma (`+`) y la resta (`-`).

```crystal
2 + 3 - 4 * 4
# => -11

(2 + 3 - 4) * 4
# => 4
```
