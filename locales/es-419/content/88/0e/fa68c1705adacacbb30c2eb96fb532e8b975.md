# Introducción

## Expresiones regulares

Las expresiones regulares en Gleam siguen la especificación **PCRE** (**P**erl **C**ompatible **R**egular **E**xpressions), de forma similar a otros lenguajes populares como Java, JavaScript o Ruby.

El módulo `gleam/regexp` del paquete `gleam_regexp` ofrece funciones para trabajar con expresiones regulares.

~~~~exercism/note
Este ejercicio asume que ya conoces la sintaxis de las expresiones regulares, incluidas las clases de caracteres, los cuantificadores, los grupos y las capturas.

Si necesitas repasar tus conocimientos sobre expresiones regulares, revisa una de estas fuentes: [Regular-Expressions.info](https://www.regular-expressions.info), [Rex Egg](https://www.rexegg.com/), [RegexOne](https://regexone.com/), [Regular Expressions 101](https://regex101.com/), [RegExr](https://regexr.com/).
~~~~

La forma más común de crear expresiones regulares es usando la función `regexp.from_string`.

```gleam
let assert Ok(re) = regexp.from_string("test")
```

Las funciones de creación de expresiones regulares devuelven un error si la sintaxis de la expresión regular no es válida, así que aquí se usó un let-assertion para asegurar que la expresión regular sea válida.

La función `regexp.check` se puede usar para comprobar si una expresión regular coincide con un string.

```gleam
let assert Ok(re) = regexp.from_string("test")

regexp.check(re, "this is a test")
// -> True

regexp.check(re, "this is too")
// -> False
```


### Capturas

Si quieres capturar subcadenas usando una expresión regular, puedes usar la función `regexp.scan` para obtener una lista de coincidencias.

```gleam
let assert Ok(re) = regexp.from_string("[oi]n a (\\w+)")
regexp.scan(with: re, content: "I am on a boat in a lake.")
// -> [
//   Match(
//     content: "on a boat",
//     submatches: [Some("boat")]
//   ),
//   Match(
//     content: "in a lake",
//     submatches: [Some("lake")]
//   )
// ]
```

### Modificadores

El comportamiento de una expresión regular se puede modificar creándola con la función `regexp.compile` y pasando opciones.

```gleam
let options = regexp.Options(case_insensitive: True, multi_line: False)
let assert Ok(re) = regexp.compile("[A-Z]", with: options)
regexp.check(re, "abc123")
// -> True
```
