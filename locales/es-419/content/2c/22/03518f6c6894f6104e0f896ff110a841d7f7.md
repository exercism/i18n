# Pistas

## 1. Genera las letras de los asientos

- El valor devuelto debe ser de _tipo_ `generator`.
- Puedes tener una secuencia de letras de `A` a `D` y recorrerlas cíclicamente.
- Usa `yield` para devolver la siguiente letra.

## 2. Genera los asientos

- El valor devuelto debe ser de _tipo_ `generator`.
- La fila `13` se debe omitir, así que ve del `12` al `14`.
- Ten en cuenta que los valores devueltos deben estar ordenados de menor a mayor. `1A, 1B, 2A, ...`
- Aquí podría ser buena idea reutilizar o llamar a funciones que ya hayas definido.

## 3. Asigna asientos a los pasajeros

- Asegúrate de que tus números de asiento no tengan espacios.
- Aquí podría ser buena idea reutilizar o llamar a funciones que ya hayas definido.

## 4. Códigos de boletos

- Puedes usar `len()` para obtener la longitud de un string.
- Puedes usar `"<string>" * <int>` para repetir un string.
