# Sentencias `case`

Cuando un valor se compara con una lista de posibilidades, una cadena de `elsif` repite lo mismo una y otra vez:

```sather
   if zone = 0 then
      return 0;
   elsif zone = 1 then
      return 550;
   elsif zone = 2 then
      return 370;
   else
      return 920;
   end;
```

`case` lo dice una sola vez:

```sather
   case zone
   when 0 then return 0;
   when 1 then return 550;
   when 2 then return 370;
   else return 920;
   end;
```

El valor va después de `case`. Cada `when` da un valor con el cual compararlo, y se ejecuta el primero que coincida.

## Varios valores en un mismo `when`

Un `when` puede listar valores, separados por comas:

```sather
   case day
   when "Sat", "Sun" then return "Weekend";
   when "Mon", "Tue", "Wed", "Thu", "Fri" then return "Weekday";
   else return "Unknown";
   end;
```

Esto funciona con números enteros, caracteres y strings, cualquier cosa que se pueda comparar con `=`.

## El `else` no es opcional

**Un `case` que no coincide con nada y no tiene `else` es un error que detiene el programa cuando ocurre.**

Eso es distinto de `if`, donde omitir el `else` simplemente significa que no pasa nada. También es distinto de la mayoría de los lenguajes, donde un `case` sin coincidencia no hace nada en silencio.

Así que todo `case` necesita un `else`, incluso cuando tienes la certeza de que las partes `when` ya cubren todos los valores. Más adelante se agrega una cuarta zona, no se actualiza el `case` para que coincida, y el programa se detiene con el primer pasajero que la use.

## Solo se ejecuta un `when`

Cuando un `when` coincide, se ejecutan las sentencias que siguen a su `then` y el `case` termina; el programa continúa después del `end`. Las partes `when` que están debajo nunca se revisan, así que no hay nada que tengas que escribir para evitar que la siguiente también se ejecute.
