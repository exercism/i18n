# Instalación

Hay [binarios de Uiua precompilados][releases] disponibles, así que no es necesario compilar.
Consulta la [guía de instalación oficial][install-guide] para ver las instrucciones más recientes, incluida la integración con el IDE y las fuentes.

```exercism/note
Por ahora, nuestro ejecutor de pruebas en línea usa la versión `0.18.1`.
Con el rápido ritmo de desarrollo de Uiua, eso podría cambiar, así que tenlo en cuenta si no puedes reproducir los resultados de las pruebas del sitio web.
```

Una vez que lo hayas descargado en la ubicación que quieras, tendrás que agregar Uiua al PATH de tu sistema.

- **macOS:** Usa Finder para abrir `Applications > Utilities > Terminal`. Escribe `export PATH="/path/to/uiua:$PATH"` para ejecutar Uiua desde cualquier ubicación.

- **Windows:** Abre «Edit Environment Variables» desde el menú Inicio. En «Path», agrega tu carpeta de Uiua.

- **Linux:** Abre la Terminal y agrega `export PATH="/path/to/uiua:$PATH"` a `~/.bashrc` o `~/.profile` para acceder fácilmente.

[releases]: https://github.com/uiua-lang/uiua/releases
[install-guide]: https://www.uiua.org/docs/install#basic
