# Recursos

## General

* [La documentación del lenguaje Unison](https://www.unison-lang.org/learn/fundamentals/values-and-functions/terms/) es un excelente lugar para aprender los conceptos centrales de Unison
* [Unison Share](https://share.unison-lang.org/) es el repositorio donde alojamos las bibliotecas y el código públicos
* Siempre puedes hacer preguntas en [el Discord de Unison](https://unison-lang.org/discord)
* [El blog de Unison](https://www.unison-lang.org/blog/) contiene novedades del lenguaje y temas especiales
* Un artículo sobre cómo usar [la capacidad Remote de Unison para implementar una biblioteca similar a Spark](https://www.unison-lang.org/articles/distributed-datasets/)
