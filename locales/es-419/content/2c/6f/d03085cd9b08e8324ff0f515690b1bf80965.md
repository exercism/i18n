# Instrucciones adicionales

## Instrucciones específicas del track

Tu tarea es escribir una función `nucleotideCounts` que recibe como argumento un string y devuelve como resultado un array asociativo que cuenta cuántas veces está presente cada nucleótido.
Si el string es una secuencia inválida, la función debe lanzar un `IllegalArgumentError` con el mensaje `Invalid nucleotide in strand`.
