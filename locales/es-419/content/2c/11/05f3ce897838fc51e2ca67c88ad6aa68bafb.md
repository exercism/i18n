## Boolean

PowerShell tiene el tipo [`bool`][booleans] para representar valores verdaderos y falsos.
En este tipo solo hay dos valores: `True` y `False`.
Puedes asignar estos valores a variables con el prefijo `$`:

```powershell
> $TrueVar  = $true
> $FalseVar = $FALSE
#Case senstitivity doesn't matter here
```

Podemos usar [operadores lógicos][logical-operators] como `-and`, `-or` y `-not` para combinar y evaluar expresiones booleanas.

```powershell
> $TrueVar  = $true -and $true
> $FalseVar = $true -and $false

> $TrueVar  = $true -or $false
> $FalseVar = $false -or $false

> $TrueVar  = -not $false
> $FalseVar = -not $true
```

## Conversión y veracidad

PowerShell puede tratar implícitamente cualquier tipo como un Boolean.
Sin embargo, también puedes usar el acelerador de tipo Boolean `[bool]` para hacer una conversión explícita.

Estas son algunas reglas generales que PowerShell usa para convertir otros tipos a valores booleanos:

$false:
- Cadenas vacías como `''` o `""`
- Valores nulos como `$null`
- Tipos numéricos con el valor cero (0)

$true:
- Cadenas no vacías
- Instancias de cualquier otro tipo que no sea de colección

```powershell
> [bool] 0
False

> [bool] 0.0
False

> [bool] ""
False

> [bool] "Hello"
True

> [bool] 1234
True
```

Para conocer las reglas detalladas sobre cómo convertir valores booleanos a partir de tipos de colección, consulta [aquí][collection-conversion].
