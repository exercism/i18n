# Instrucciones

Estás desarrollando un sistema para ayudar al personal del sitio web de un club de fútbol a informar sobre los partidos.
Los datos se reciben de varias fuentes y se canalizan hacia un único flujo después de ser depurados.

## 1. Muestra las descripciones de los jugadores según su número de camiseta

El equipo siempre juega con una formación 4-3-3 y nunca ha estado de acuerdo con el cambio de 1965 a las reglas que permitía las sustituciones, y mucho menos con las plantillas ampliadas.

Las descripciones de los jugadores son las siguientes:

```text
1 -> "goalie"
2 -> "left back"
3 & 4 "center back"
5 -> "right back"
6, 7, & 8 -> "midfielder"
9 -> "left wing"
10 -> "striker"
11 -> "right wing"
```

Implementa el método estático `FootballMatchReports.onField()` para mostrar la descripción de un jugador según su número de camiseta.

```java
FootballMatchReports.onField(10);
// => "striker"
```

## 2. Muestra «invalid» si el número de camiseta no forma parte de la lista oficial

Modifica el método `FootballMatchReports.onField()` para que devuelva «invalid» cuando se procese un número de camiseta fuera del rango 1-11.

```java
FootballMatchReports.onField(13);
// => "invalid"
```
