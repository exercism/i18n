# Instrucciones

En este ejercicio, necesitas implementar algunas reglas del clásico juego Pac-Man.

Tienes cuatro reglas que implementar, todas relacionadas con los estados del juego.

## 1. Define si Pac-Man se come a un fantasma

Implementa una función que recibe si Pac-Man tiene una píldora de poder activa y si Pac-Man está tocando a un fantasma, y devuelve un valor Boolean que indica si Pac-Man puede comerse al fantasma. La función debe devolver `true` solo si Pac-Man tiene una píldora de poder activa y está tocando a un fantasma.

```lua
rules.eat_ghost(false, true)
-- => false
```

## 2. Define si Pac-Man anota puntos

Implementa una función que recibe si Pac-Man está tocando una píldora de poder y si Pac-Man está tocando un punto, y devuelve un valor Boolean que indica si Pac-Man anotó puntos. La función debe devolver `true` si Pac-Man está tocando una píldora de poder o un punto.

```lua
rules.score(true, true)
-- => true
```

## 3. Define si Pac-Man pierde

Implementa una función que recibe si Pac-Man tiene una píldora de poder activa y si Pac-Man está tocando a un fantasma, y devuelve un valor Boolean que indica si Pac-Man pierde. La función debe devolver `true` si Pac-Man está tocando a un fantasma y no tiene una píldora de poder activa.

```lua
rules.lose(false, true)
-- => true
```

## 4. Define si Pac-Man gana

Implementa una función que recibe si Pac-Man se comió todos los puntos, si Pac-Man tiene una píldora de poder activa y si Pac-Man está tocando a un fantasma, y devuelve un valor Boolean que indica si Pac-Man gana. La función debe devolver `true` si Pac-Man se comió todos los puntos y no ha perdido según los argumentos definidos en la parte 3.

```lua
rules.win(false, true, false)
-- => false
```
