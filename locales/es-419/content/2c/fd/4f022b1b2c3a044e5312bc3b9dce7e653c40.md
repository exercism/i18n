# Tareas

Las tareas son issues de GitHub en los que nos gustaría que la gente colaborara, desde revisar textos hasta crear ejercicios de concepto.
Se muestran en el sitio web y enlazan al issue correspondiente en GitHub.
Cada tarea lleva una o más propiedades, que se obtienen de las etiquetas del issue.
Después, quien use el sitio puede filtrar las tareas según sus propiedades.

## Etiquetas

Para que un issue se considere una tarea, debe llevar una o más etiquetas específicas de tareas.
Así, el equipo de mantenimiento puede elegir que solo algunos issues aparezcan como tareas.

Cada etiqueta de tarea tiene el formato `x:<type>/<value>` y se admiten cinco tipos de tareas:

- `action`
- `knowledge`
- `module`
- `size`
- `type`

### Etiqueta `action`

Las etiquetas `x:action/<value>` describen en qué tipo de trabajo se involucrará quien contribuya cuando trabaje en el issue.

| Etiqueta             | Descripción                            |
| -------------------- | -------------------------------------- |
| `x:action/create`    | Trabajar en algo desde cero            |
| `x:action/fix`       | Corregir un issue                      |
| `x:action/improve`   | Mejorar funcionalidad o contenido existente |
| `x:action/proofread` | Revisar textos                         |
| `x:action/sync`      | Sincronizar el contenido con su versión más reciente |

### Etiqueta `knowledge`

Las etiquetas `x:knowledge/<value>` describen cuánto conocimiento de Exercism necesita quien contribuya.

| Etiqueta                   | Descripción                                |
| -------------------------- | ------------------------------------------ |
| `x:knowledge/none`         | No se necesita ningún conocimiento previo de Exercism |
| `x:knowledge/elementary`   | Se necesita poco conocimiento de Exercism  |
| `x:knowledge/intermediate` | Se necesita bastante conocimiento de Exercism |
| `x:knowledge/advanced`     | Se necesita un conocimiento amplio de Exercism |

### Etiqueta `module`

Las etiquetas `x:module/<value>` indican en qué parte de Exercism trabajará quien contribuya.

| Etiqueta                     | Descripción                 |
| ---------------------------- | --------------------------- |
| `x:module/analyzer`          | Trabajar en los analizadores |
| `x:module/concept`           | Trabajar en los conceptos   |
| `x:module/concept-exercise`  | Trabajar en los ejercicios de concepto |
| `x:module/generator`         | Trabajar en los generadores de ejercicios |
| `x:module/practice-exercise` | Trabajar en los ejercicios de práctica |
| `x:module/representer`       | Trabajar en los representadores |
| `x:module/test-runner`       | Trabajar en los ejecutores de tests |

### Etiqueta `size`

Las etiquetas `x:size/<value>` describen la cantidad de trabajo que se espera de quien contribuya.

| Etiqueta         | Descripción            |
| ---------------- | ---------------------- |
| `x:size/tiny`    | Una cantidad mínima de trabajo |
| `x:size/small`   | Poca cantidad de trabajo |
| `x:size/medium`  | Una cantidad media de trabajo |
| `x:size/large`   | Una gran cantidad de trabajo |
| `x:size/massive` | Una cantidad enorme de trabajo |

### Etiqueta `type`

Las etiquetas `x:type/<value>` describen el tipo de trabajo en el que se involucrará quien contribuya.

| Etiqueta         | Descripción                                                                                                                                                                                                    |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `x:type/ci`      | Trabajar en integración continua (por ejemplo, flujos de trabajo de GitHub Actions)                                                                                                                            |
| `x:type/coding`  | Escribir código que no forma parte del contenido que ve el estudiante. Normalmente son tareas relacionadas con las herramientas de producción (por ejemplo, los ejecutores de tests), las herramientas internas (generadores) o bibliotecas que mantiene Exercism. |
| `x:type/content` | Trabajar en contenido (por ejemplo, ejercicios, conceptos)                                                                                                                                                     |
| `x:type/docker`  | Trabajar en Dockerfiles                                                                                                                                                                                        |
| `x:type/docs`    | Trabajar en documentación                                                                                                                                                                                      |

## Etiquetas de tarea tomadas y disponibles

Para ocultar una tarea porque alguien ya está trabajando en ella, un issue puede agregar la etiqueta `x:status/claimed`.
