# Anexo de instrucciones

## Pistas

Para que el reto tenga el nivel de dificultad adecuado, deberías usar solo la funcionalidad que incluye Prelude. Trata de no usar Data.List, Data.Char, Data.Bits ni Numeric.

Intenta usar seq, $! o BangPatterns de forma adecuada para asegurarte de que la solución sea eficiente.

No es necesario manejar entradas inválidas.
