# Introducción

## Operadores de comparación

Los [operadores de comparación][comparison-operators] comparan dos valores del mismo tipo y devuelven un valor `Bool` (`true` o `false`).
Si intentas comparar valores de tipos distintos, el compilador produce un error.

Los operadores de comparación estándar en Swift son:

| Operador | Descripción              | Ejemplo         |
| -------- | ------------------------ | --------------- |
| `==`     | Igual a                  | `1 == 1` (verdadero) |
| `!=`     | Distinto de              | `1 != 2` (verdadero) |
| `<`      | Menor que                | `4 < 5`  (verdadero) |
| `<=`     | Menor o igual que        | `4 <= 4` (verdadero) |
| `>`      | Mayor que                | `3 > 1`  (verdadero) |
| `>=`     | Mayor o igual que        | `2 >= 2` (verdadero) |

## Sentencias `if` y `else`

Una [sentencia condicional][conditional-statement] ejecuta código según si una condición se evalúa como `true` o `false`.
El condicional más común es la [sentencia `if`][if], que solo ejecuta un bloque de código cuando su condición es `true`.
Escribe una sentencia `if` con la palabra clave `if`, seguida de la condición y del bloque de código encerrado entre llaves:

```swift
let wheelCount = 4
if wheelCount == 4 {
    print("Your vehicle is a car")
}
// Prints "Your vehicle is a car"
```

Puedes combinar `if` con una cláusula `else` para ejecutar código alternativo cuando la condición es `false`:

```swift
let precipitationInMM = 0.5
if precipitationInMM > 0.5 {
    print("You will need an umbrella")
} else {
    print("You will not need an umbrella")
}
// Prints "You will not need an umbrella"
```

Para probar varias condiciones en secuencia, encadena sentencias con `else if`.
Una sentencia `if` no requiere una rama `else`, pero puedes incluirla para cubrir los casos en los que ninguna de las condiciones coincida:

```swift
let favoriteFruit = "Apple"

if favoriteFruit == "Banana" {
    print("Your favorite fruit is a banana")
} else if favoriteFruit == "Orange" {
    print("Your favorite fruit is an orange")
} else if favoriteFruit == "Apple" {
    print("Your favorite fruit is an apple")
} else {
    print("Your favorite fruit is not a banana, orange, or apple")
}
// Prints "Your favorite fruit is an apple"
```

## Expresiones `if`

En el Swift moderno, las sentencias `if` también pueden usarse como expresiones que producen un valor.
Cada rama se evalúa como un valor, lo que facilita asignar resultados de forma condicional:

```swift
let cpuBits = 32
let architecture = if cpuBits == 64 {
    "x86_64"
} else {
    "x86_32"
}

print(architecture)
// Prints "x86_32"
```

## Operador ternario

El [operador condicional ternario][ternary-operator] es una forma abreviada y concisa de una expresión `if-else`.
Evalúa una condición y devuelve uno de dos valores según si esa condición es `true` o `false`.

El operador usa tres partes: `condition ? trueExpression : falseExpression`.
Si `condition` se evalúa como `true`, se evalúa `trueExpression` y se devuelve ese valor; de lo contrario, se evalúa `falseExpression` y se devuelve ese valor.

El operador ternario es ideal para elecciones simples de una sola línea:

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = showFahrenheit ? temperatureInCelsius * 9 / 5 + 32 : temperatureInCelsius
print(temperature)
// Prints 86
```

El ejemplo anterior es un equivalente compacto de:

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = if showFahrenheit {
    temperatureInCelsius * 9 / 5 + 32
} else {
    temperatureInCelsius
}
```
