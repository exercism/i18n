# Introducción

La mayoría de los datos en Factor viven en *secuencias*. Los arrays, los vectores y los strings son todos secuencias y comparten un conjunto común de palabras del vocabulario [`sequences`][sequences].

## Literales de array

Un array literal usa `{ }` con espacio en blanco entre los elementos:

```factor
{ 1 2 3 } .          ! => { 1 2 3 }
{ "a" "b" "c" } .    ! => { "a" "b" "c" }
```

Los arrays tienen una longitud fija, así que palabras como `suffix` y `remove-nth`, que cambian cuántos elementos hay, devuelven una secuencia *nueva* en lugar de agrandar la original.

## Longitud e indexación

```
length   ( seq -- n   )
first    ( seq -- elt )
rest     ( seq -- tailseq )    ! everything but the first element
last     ( seq -- elt )
but-last ( seq -- headseq )    ! everything but the last element
nth      ( n seq -- elt )      ! 0-based
?nth     ( n seq -- elt/f )    ! 0-based; f when out of bounds
```

```factor
{ 10 20 30 } length .       ! => 3
{ 10 20 30 } first .        ! => 10
{ 10 20 30 } rest .         ! => { 20 30 }
{ 10 20 30 } last .         ! => 30
{ 10 20 30 } but-last .     ! => { 10 20 }
1 { 10 20 30 } nth .        ! => 20
```

`?nth` es la versión segura ante límites: puedes consultar una posición sin comprobar antes la longitud.

```factor
1 { 10 20 30 } ?nth .       ! => 20
9 { 10 20 30 } ?nth .       ! => f  (out of bounds, no error)
```

## Rebanado

```
head ( seq n -- headseq )    ! first n elements
tail ( seq n -- tailseq )    ! drop first n
```

```factor
{ 1 2 3 4 5 } 3 head .   ! => { 1 2 3 }
{ 1 2 3 4 5 } 3 tail .   ! => { 4 5 }
```

Ambas lanzan un error si `n` es mayor que la secuencia. Si `n` es demasiado grande, `index-or-length` lo reduce hasta la longitud de la secuencia, así que el corte que sigue no puede pasarse del final:

```
index-or-length ( seq n -- seq n' )
```

```factor
{ 10 20 30 40 50 } 3 index-or-length head .   ! => { 10 20 30 }
{ 10 20 } 3 index-or-length head .            ! => { 10 20 }
```

Las variantes con asterisco `head*` y `tail*` cuentan desde el final: `head*` descarta los últimos `n` y `tail*` conserva los últimos `n`:

```
head* ( seq n -- headseq )   ! everything except the last n
tail* ( seq n -- tailseq )   ! the last n elements
```

```factor
{ 1 2 3 4 5 } 2 head* .   ! => { 1 2 3 }
{ 1 2 3 4 5 } 2 tail* .   ! => { 4 5 }
```

Para un corte arbitrario entre dos índices, `subseq` toma el *inicio* (inclusive) y el *final* (exclusive):

```
subseq ( from to seq -- subseq )
```

```factor
1 4 { 10 20 30 40 50 } subseq .   ! => { 20 30 40 }
1 4 "hello" subseq .              ! => "ell"
```

Cuando tienes un *inicio y una longitud*, súmalos para obtener el final:

```factor
2 dup 3 + "hello world" subseq .  ! => "llo"
```

(Ese es el rango de índices `[2, 5)`: tres caracteres que empiezan en la posición 2.)

La pregunta inversa, *dónde* aparece una subsecuencia, la responde `subseq-index`, que devuelve el índice inicial de la primera coincidencia, o `f` cuando no hay ninguna:

```
subseq-index ( seq subseq -- i/f )
```

```factor
"hello world" "o w" subseq-index .   ! => 4
"hello world" "xyz" subseq-index .   ! => f
```

## Relleno

```
pad-head ( seq n elt -- padded )    ! prepend copies of elt
pad-tail ( seq n elt -- padded )    ! append copies of elt
```

Ambas extienden `seq` hasta que su longitud sea al menos `n`. Si `seq` ya es así de larga, se devuelve sin cambios.

```factor
{ 2 5 0 } 6 0 pad-tail .   ! => { 2 5 0 0 0 0 }
{ 4 1 } 5 9 pad-head .     ! => { 9 9 9 4 1 }
```

## Las mismas palabras funcionan con strings

Un string es una secuencia de caracteres, así que todo lo anterior también funciona con strings: el resultado es simplemente otro string en lugar de un array:

```factor
"hello" length .            ! => 5
"hello" 3 head .             ! => "hel"
"abc" 6 CHAR: . pad-tail .   ! => "abc..."
```

## Agregación

`sum` y `product` (en [`sequences`][sequences]) suman o multiplican los elementos de una secuencia numérica:

```factor
{ 2 5 0 7 } sum .        ! => 14
{ 2 5 3 7 } product .    ! => 210
```

`count` ejecuta un predicado sobre la secuencia y devuelve cuántos elementos lo hicieron verdadero:

```
count ( seq quot -- n )
```

```factor
{ 2 5 0 7 4 1 } [ even? ] count .    ! => 3
```

## Predicados sobre toda la secuencia

```
any?   ( seq quot -- ? )
all?   ( seq quot -- ? )
empty? ( seq -- ? )
```

```factor
{ 2 5 0 7 } [ 4 > ] any? .      ! => t
{ 2 5 0 7 } [ 0 > ] all? .      ! => f
```

## Construir una secuencia nueva

`suffix` agrega un elemento al final de una secuencia; `prefix` agrega uno al principio. `unclip` desprende el primer elemento y `unclip-last` desprende el último:

```
prefix      ( seq elt -- newseq )
suffix      ( seq elt -- newseq )
unclip      ( seq -- rest first )
unclip-last ( seq -- butlast last )
```

```factor
{ 7 9 } 3 prefix .             ! => { 3 7 9 }
{ 7 9 } 3 suffix .             ! => { 7 9 3 }
{ 4 0 9 } unclip .s
! => { 0 9 }
! => 4
```

Combinar `unclip-last` y `suffix` da una actualización no destructiva del último elemento (y `unclip` + `prefix` hace lo mismo con el primero):

```factor
{ 10 20 30 } unclip-last 2 * suffix .
! => { 10 20 60 }
```

## Convertir entre tipos de secuencia

`>array`, `>vector` y `>string` (en [`arrays`][arrays] y los vocabularios correspondientes) fuerzan una secuencia a un tipo concreto en particular. Es útil cuando una operación devolvió un corte o una secuencia genérica y necesitas recuperar un array (o un string).

```factor
{ 1 2 3 } 1 tail >array .   ! => { 2 3 }
"hello" >array .            ! => { 104 101 108 108 111 }
{ 65 66 67 } >string .      ! => "ABC"
```
