# Anexo de instrucciones

## Pistas

Necesitas implementar la función `rotate`, que recibe un `Int` y un `String`, y luego lo codifica con un cifrado rotacional.
Puedes usar la firma que te damos si tienes dudas sobre los tipos, pero no dejes que limite tu creatividad.

Este ejercicio trabaja con datos de texto. Por razones históricas, el tipo
`String` de Haskell es sinónimo de `[Char]`, una lista de caracteres. Para
manejar datos de texto de forma más eficiente, se puede usar el tipo `Text`.

Como extensión opcional de este ejercicio, puedes

- leer sobre los [tipos de string](https://haskell-lang.org/tutorial/string-types) en
  Haskell.
- agregar `- text` a tu lista de dependencias en package.yaml.
- importar `Data.Text` de [la siguiente
  manera](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c):

```haskell
import qualified Data.Text as T
import           Data.Text (Text)
```

- usar el tipo `Text`, por ejemplo `rotate :: Int -> Text -> Text`, y referirte a
  los combinadores de `Data.Text` como, por ejemplo, `T.pack`.
- consultar la documentación de
  [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html).
- reemplazar todas las apariciones de `String` por `Text` en RotationalCipher.hs, es decir:

```haskell
rotate :: Int -> Text -> Text
```

Esta parte es totalmente opcional.
