# Consejos

## General

- Usa el [tipo array][array] integrado.

## 1. Define un método que devuelva un array vacío de lenguajes

- La función debe devolver un array vacío con el tipo `Array(String)`.
- La sintaxis para crear un array vacío es `[]`.
  El tipo se puede especificar con `of String`.

## 2. Define un método para agregar un lenguaje al array

- Puedes agregar un elemento a un array con `<<`.

## 3. Define un método para eliminar un lenguaje del array

- Crystal [proporciona un método][pop] para eliminar el último elemento de un array.

## 4. Define un método que devuelva el n-ésimo elemento del array

- Crystal [proporciona un método][index] para obtener el elemento en un índice específico de un array.

## 5. Define un método para parsear un string de lenguajes

- Crystal [proporciona un método][split] para convertir un string en un array usando un delimitador.
