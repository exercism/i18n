# Pruebas

## Ejecutar todas las pruebas

Hay un script de Perl con la extensión `.t` en el directorio `t/`, que se usará para probar tu solución.
Puedes ejecutar las pruebas con el comando:

`prove`

Antes de que empieces el ejercicio, la salida probablemente se verá más o menos así:

```
./t/hello-world.t .. 1/2
# Failed test 'Say Hi!'
# at exercises/hello-world/t/hello-world.t line 15.
# +---------+---------------+
# | GOT     | CHECK         |
# +---------+---------------+
# | <UNDEF> | Hello, World! |
# +---------+---------------+
exercises/hello-world/t/hello-world.t .. Dubious, test returned 1 (wstat 256, 0x100)
Failed 1/2 subtests

Test Summary Report
-------------------
./t/hello-world.t (Wstat: 256 Tests: 2 Failed: 1)
  Failed test:  2
  Non-zero exit status: 1
Files=1, Tests=2,  0 wallclock secs ( 0.03 usr  0.00 sys +  0.18 cusr  0.02 csys =  0.23 CPU)
Result: FAIL
```

Tendrás que modificar el módulo con la extensión `.pm`, que está en el directorio `lib/`, y escribir una solución que pase las pruebas.
Una vez que las pruebas pasen, la salida del comando anterior probablemente se verá más o menos así:

```
./t/hello-world.t .. ok
All tests successful.
Files=1, Tests=2,  0 wallclock secs ( 0.02 usr  0.00 sys +  0.07 cusr  0.01 csys =  0.10 CPU)
Result: PASS
```

Puedes encontrar documentación sobre las aserciones que se usan en los archivos de prueba en [Test2::Manual::Testing::Introduction][test2-manual].
Puedes encontrar una explicación más detallada de `Test2` en [perldoc][test2].

[test2-manual]: https://metacpan.org/pod/Test2::Manual::Testing::Introduction
[test2]: https://perldoc.perl.org/Test2
