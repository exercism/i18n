# Instrucciones

En este ejercicio vas a trabajar en un sistema para agendar citas de un salón de belleza en Nueva York que abrió el 15 de septiembre de 2012.

Tienes cuatro tareas, y todas girarán en torno a las fechas de las citas. Las fechas y las horas usarán uno de los siguientes tres formatos:

- `"7/25/2019 13:45:00"`
- `"July 25, 2019 13:45:00"`
- `"Thursday, July 25, 2019 13:45:00"`

Las pruebas establecerán automáticamente la cultura en `en-US`; no tienes que establecer ni especificar la cultura tú mismo.

## 1. Analizar la fecha de la cita

Implementa el método (_static_) `Appointment.Schedule()` para analizar una representación textual de la fecha de una cita y convertirla al formato `DateTime` correspondiente:

```csharp
Appointment.Schedule("7/25/2019 13:45:00")
// => new DateTime(2019, 7, 25, 13, 45, 0)
```

## 2. Comprobar si una cita ya pasó

Implementa el método (_static_) `Appointment.HasPassed()` que recibe la fecha de una cita y comprueba si la cita quedó en algún momento del pasado:

```csharp
Appointment.HasPassed(new DateTime(1999, 12, 31, 9, 0, 0))
// => true
```

## 3. Comprobar si la cita es por la tarde

Implementa el método (_static_) `Appointment.IsAfternoonAppointment()` que recibe la fecha de una cita y comprueba si la cita es por la tarde (>= 12:00 y < 18:00):

```csharp
Appointment.IsAfternoonAppointment(new DateTime(2019, 03, 29, 15, 0, 0))
// => true
```

## 4. Describir la hora y la fecha de la cita

Implementa el método (_static_) `Appointment.Description()` que recibe la fecha de una cita y devuelve una descripción de esa fecha y hora:

```csharp
Appointment.Description(new DateTime(2019, 03, 29, 15, 0, 0))
// => "You have an appointment on 3/29/2019 3:00:00 PM."
```

## 5. Devolver la fecha del aniversario

Implementa el método (_static_) `Appointment.AnniversaryDate()` que devuelve la fecha del aniversario de este año, que es el 15 de septiembre:

```csharp
Appointment.AnniversaryDate()
// => new DateTime(2019, 9, 15, 0, 0, 0)
```
