# Pistas

## General

- Puede que te resulte útil tener una lista de todas las operaciones numéricas de Lisp.
Puedes encontrar una [lista completa aquí](http://www.lispworks.com/documentation/HyperSpec/Body/12_aa.htm)

## 1. Una proporción de masa

- Common Lisp tiene [una constante incorporada](http://www.lispworks.com/documentation/HyperSpec/Body/v_pi.htm) para π (pi)
- En cuanto al redondeo, la especificación de Common Lisp ofrece [una serie de
  funciones](http://www.lispworks.com/documentation/HyperSpec/Body/f_floorc.htm)

## 2. Un chorrito de salsa

- Existe [un operador incorporado](http://www.lispworks.com/documentation/HyperSpec/Body/f_sqrt_.htm) que podría ayudarte a calcular la raíz cuadrada de un número

## 3. Un poco de queso, por favor

- Para elevar números al cuadrado o al cubo, existe [una función de exponenciación incorporada](http://www.lispworks.com/documentation/HyperSpec/Body/f_exp_e.htm)
- Quizá quieras echar un vistazo a [esta página de operaciones de redondeo](http://www.lispworks.com/documentation/HyperSpec/Body/f_floorc.htm) y revisar algunas de las alternativas a `round`.

## 4. Una repartición justa

- Esta parte requiere usar una función que quizá no hayas visto antes, la [función de
módulo](https://en.wikipedia.org/wiki/Modulo_operation) (`mod`). Esta función te da el residuo de la división entre dos números.
- Para comparar el resultado de `mod` con otro número, [esta página de operadores de comparación](http://www.lispworks.com/documentation/HyperSpec/Body/f_eq_sle.htm).
