# Pruebas

Para ejecutar las pruebas, ensambla y ejecuta el archivo del ejecutor de pruebas para un ejercicio determinado, ya sea mediante la interfaz gráfica del simulador MARS o en la línea de comandos. Para ejecutarlo en la línea de comandos, especifica primero el archivo runner y luego tu implementación, así:

    java -jar /path/to/mars.jar nc runner.mips impl.mips

Para ejecutarlo en la interfaz gráfica, `include` tu implementación al final de «runner.mips» descomentando la última línea.

El ejecutor de pruebas terminará con un mensaje de «success» o se detendrá en una prueba fallida con un mensaje que especifica la entrada para la cual falló esa prueba.
