# Pistas

## 1. Crear una nueva lista

- Common Lisp tiene una [función con un nombre bastante descriptivo][hyper-list] para crear una _LIST_.

## 2. Agregar cosas a la lista.

- Para agregar algo al principio de una lista, lo idiomático es *CONS*truir una nueva lista con el elemento como el `car` y la lista como el `cdr`. En el Hyperspec se puede encontrar una [página][hyper-cons] que describe esta función.

## 3. ¿Qué sigue en la lista?

- Common Lisp tiene una función de propósito general para obtener un elemento [de cualquier índice de una lista][hyper-nth].
- También tiene [varios ayudantes][hyper-first-tenth] para acceder a los índices menores que 11.
- Los índices de las listas empiezan en cero.

## 4. Quitar algo de la lista

- Una forma idiomática de quitar el primer elemento de una lista es usar una función que pueda separar el `cdr` de la lista del `car` de la lista. En el Hyperspec se puede encontrar una [página][hyper-rest] que describe una de las funciones para hacer esto.

## 5. Listas más grandes a partir de listas más pequeñas

- Common Lisp tiene una función [específicamente para agregar una lista al frente de otra][hyper-append]

## 6. ¿Cuánto más larga?

- Common Lisp tiene una función [de nombre obvio][hyper-length] para obtener la longitud de una lista.
