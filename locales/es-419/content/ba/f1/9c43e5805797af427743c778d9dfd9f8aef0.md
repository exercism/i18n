# Instrucciones

Estás dando las indicaciones para la producción de tu escuela. El regidor de escena quiere que las líneas estándar queden escritas, para que cualquiera pueda manejar la consola.

Tienes cuatro tareas, todas en la clase `STAGE_DIRECTIONS`.

## 1. Anuncia el inicio

Devuelve la línea que abre la función.

```sather
STAGE_DIRECTIONS::opening_line
-- => "The curtain rises."
```

## 2. Anuncia el intermedio

Devuelve la línea que se dice en el intermedio.

```sather
STAGE_DIRECTIONS::interval_line
-- => "Interval. Fifteen minutes."
```

## 3. Anuncia el final

Devuelve la línea que cierra la función.

```sather
STAGE_DIRECTIONS::closing_line
-- => "The curtain falls."
```

## 4. Da la indicación final

La indicación final es la misma línea que cierra la función. En lugar de escribir el texto una segunda vez, llama a la rutina que ya escribiste.

```sather
STAGE_DIRECTIONS::final_cue
-- => "The curtain falls."
```
