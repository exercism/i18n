# Introducción

## Clases

La principal construcción orientada a objetos en C# es la _clase_, que es una combinación de datos (_campos_) y comportamiento (_métodos_). Los campos y métodos de una clase se conocen como sus _miembros_.

El acceso a los miembros se puede restringir mediante modificadores de acceso, y los dos más comunes son:

- `public`: se puede acceder al miembro desde cualquier código (sin restricciones).
- `private`: solo se puede acceder al miembro desde código de la misma clase.

Puedes pensar en una clase como una plantilla para crear instancias de esa clase. Para crear una instancia de una clase (también conocida como _objeto_), se usa la palabra clave `new`:

```csharp
class Car
{
}

// Create two car instances
var myCar = new Car();
var yourCar = new Car();
```

Los campos tienen un tipo y se pueden definir en cualquier parte de una clase.
Los campos públicos se definen en PascalCase y los campos privados se definen en camelCase y llevan el prefijo de un guion bajo `_`:

```csharp
class Car
{
    // Accessible by anyone
    public int Weight;

    // Only accessible by code in this class
    private string _color;
}
```

Opcionalmente, se puede asignar un valor inicial a un campo. Si un campo _no_ especifica un valor inicial, se establece en el valor predeterminado de su tipo. Los valores de los campos de una instancia se pueden consultar y actualizar usando la notación de punto.

```csharp
class Car
{
    // Will be set to specified value
    public int Weight = 2500;

    // Will be set to default value (0)
    public int Year;
}

var newCar = new Car();
newCar.Weight; // => 2500
newCar.Year;   // => 0

// Update value of the field
newCar.Year = 2018;
```

Los campos privados suelen actualizarse como efecto secundario de llamar a un método. Esos métodos normalmente no devuelven ningún valor, en cuyo caso el tipo de retorno debe ser `void`:

```csharp
class CarImporter
{
    private int _carsImported;

    public void ImportCars(int numberOfCars)
    {
        // Update private field from public method
        _carsImported = _carsImported + numberOfCars;
    }
}
```
