# Introducción

Recuerda que un programa de `jq` es un _pipeline de expresiones_.
**La asignación de variables** sigue esta regla: una _asignación de variable_ es una expresión que se ve así:

```jq
... | expr as $varname | ...
```

## El filtro devuelve la entrada

Igual que la _expresión de identidad_ `.`, la salida de la _asignación de variable_ es la misma que su entrada.
Establecer el valor de la variable es un efecto secundario.

Ejemplo, que muestra que `.` después de la asignación es igual a la entrada inicial:

```sh
$ jq -c -n '42 | (. * 2) as $double | [., $double]'
[42,84]
```

## El ámbito de las variables

El ámbito de la variable es «léxico»: la variable estará en el ámbito durante el resto del pipeline.
Las variables definidas dentro de funciones (ya llegaremos a las funciones más adelante) son «locales» a la función.

## Los nombres de las variables

La variable debe empezar con `$`.
El resto del nombre de la variable es un **identificador**: empieza con una letra o un guion bajo, seguido de letras, números o guiones bajos.

## Asignación por desestructuración

Del manual:

> Se pueden declarar varias variables con una sola expresión `as` proporcionando un patrón que _coincide con la estructura de la entrada_ (esto se conoce como «desestructuración»).

Ejemplos:

```jq
[1, 2, 3] as [$a, $b, $c]
| [$a, $b, $c]     # => [1, 2, 3]
```

```jq
{"foo": "bar", "len": [10, 20]} as {foo: $f, len: [$h, $w]}
| [$f, $h, $w]     # => ["bar", 10, 20]
```

Hacer coincidir el nombre de la variable con la _clave del objeto_ ofrece un atajo:

```jq
{"x": 4, "y": 7} as {$x, $y}
| [$x, $y]         # => [4, 7]
```

```jq
{"foo": "bar", "len": [10, 20]} as {$foo, $len}
| [$foo, $len]     # => ["bar", [10, 20]]
```

## Constantes

Como se muestra en el ejemplo anterior, las variables son útiles para almacenar constantes.
Es mejor darle un nombre a las constantes que dejar que aparezcan «números mágicos» en el código.

## Muchas veces las variables no son necesarias

A menudo es más legible omitir las variables.

Considera calcular el promedio de un array de números

```jq
[2, 4, 8, 7]
| add as $sum
| length as $len
| $sum / $len
```

en comparación con

```jq
[2, 4, 8, 7] | add / length
```

Esto resalta uno de los aspectos más poderosos de `jq`: la entrada de un filtro se le proporciona a _cada_ subexpresión:

- el array de entrada `[2,4,8,7]` se pasa a `add` (que suma los números aplicando el operador `+` a todos los elementos)
- _en paralelo_, `[2,4,8,7]` también se pasa a `length`
- cuando estas subexpresiones terminan, sus resultados se dividen y devuelven el valor promedio de los números del array de entrada.

## Operadores de `jq` que necesitarás para el ejercicio de aprendizaje

### El operador alternativo: `//`

La expresión `a // b` da como resultado `b` si `a` es false o null; de lo contrario, da como resultado `a`.
En el contexto de establecer una variable, esto es muy útil para proporcionar un valor predeterminado:

```jq
(.input.theAnswer // 42) as $answer | ...
```

### Operadores aritméticos

- `+`, `-` y `*` son los operadores habituales de suma, resta y multiplicación de números.
