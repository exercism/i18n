# Introducción

## El operador de tubería

El operador `|>` se llama operador de tubería. Se puede usar para encadenar llamadas a funciones de manera que el valor devuelto por la llamada anterior se pase a la siguiente llamada.

```gleam
"hello"
|> string.uppercase
|> string.append("?!")
// -> "HELLO?!"
```

El código de arriba es equivalente al siguiente:

```gleam
string.append(string.uppercase("hello"), "?!")
```

El operador de tubería pasa el valor como primer argumento de la llamada a la función, o como único argumento de una nueva llamada, eligiendo la opción que tenga el tipo correcto.

```gleam
100
|> function_that_takes_two_arguments(1)

// Is equivalent to
function_that_takes_two_arguments(100, 1)
```

```gleam
100
|> function_that_returns_a_function(1)

// Is equivalent to
function_that_returns_a_function(1)(100)
```

A veces queremos pasar el valor a otra posición; en ese caso, podemos usar el marcador de posición `_` para indicar dónde se debe insertar el valor.

```gleam
100
|> some_function(1, _, 2)
```
