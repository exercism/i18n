# Pistas

## 1. Imprime una credencial para un empleado

- Puedes usar [la interpolación de strings][string-interpolation] para dar formato a la credencial de forma concisa.
- Existe un [método integrado para convertir un string a mayúsculas][toupper].

## 2. Imprime una credencial para un empleado nuevo

- Debes verificar si el ID es `null` antes de usarlo.
- [Este tutorial explica en detalle cómo trabajar con tipos de valor que admiten null][nullable-types-tutorial].

## 3. Imprime una credencial para el dueño

- Debes verificar si el departamento es `null` antes de usarlo.
- [Este tutorial explica en detalle cómo trabajar con tipos de referencia que admiten null][nullable-reference-types-tutorial].
- Puedes usar el [operador condicional nulo][null-conditional-operator] para simplificar la llamada a un miembro en un valor que admite null.
- Puedes usar el [operador de fusión de null][null-coalescing-operator] para simplificar el devolver un valor distinto si un valor que admite null es `null`.
