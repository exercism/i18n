# Introducción

En Python, las sentencias [`if`][if statement], `elif` (_una contracción de «else and if»_) y `else` se usan para [controlar el flujo][control flow tools] de la ejecución y tomar decisiones en un programa.
A diferencia de muchos otros lenguajes de programación, las versiones 3.9 y anteriores de Python no ofrecen una sentencia formal de tipo case-switch, sino que usan varias sentencias `elif` para cumplir una función similar.

Python 3.10 incorpora una variante de sentencia case-switch llamada `pattern matching`, que se verá por separado en otro concepto.

Las sentencias condicionales usan expresiones que deben resolverse a `True` o `False`, ya sea devolviendo un `bool` directamente, o evaluando si son [«truthy» o «falsy»][truth value testing].


```python
x = 10
y = 5

# The comparison '>' returns the bool 'True',
# so the statement is printed.
if x > y:
    print("x is greater than y")
...
>>> x is greater than y
```

Cuando se combina con `if`, un bloque de código `else` opcional se ejecutará cuando la condición original del `if` se evalúe como `False`:

```python
x = 5
y = 10

# The comparison '>' here returns the bool False,
# so the 'else' block is executed instead of the 'if' block.
if x > y:
    print("x is greater than y")
else:
    print("y is greater than x")
...
>>> y is greater than x
```

`elif` permite múltiples evaluaciones o ramas.

```python
x = 5
y = 10
z = 20

# The elif statement allows for the checking of more conditions.
if x > y > z:
    print("x is greater than y and z")
elif y > x > z:
    print("y is greater than x and z")
else:
    print("z is greater than x and y")
...
>>> z is greater than x and y
```

Las [operaciones booleanas][boolean operations] y las [comparaciones][comparisons] se pueden combinar con condicionales para hacer pruebas más complejas:

```python
>>> def classic_fizzbuzz(number):
...     if number % 3 == 0 and number % 5 == 0:
...         say = 'FizzBuzz!'
...     elif number % 5 == 0:
...         say = 'Buzz!'
...     elif number % 3 == 0:
...         say = 'Fizz!'
...     else:
...         say = str(number)
...     return say

>>> classic_fizzbuzz(15)
'FizzBuzz!'

>>> classic_fizzbuzz(13)
'13'
```
