# Ejecutar las pruebas

Para ejecutar la prueba de un ejercicio determinado, entra con `cd` a la carpeta y ejecuta lo siguiente:

```bash 
box task run TestRunner
# Or start up a test watcher that will rerun when files change
box task run TestRunner --:watcher
```

Las pruebas usan una biblioteca llamada TestBox que admite los estilos de prueba xUnit y BDD. Todas las suites de pruebas se escribirán en el [estilo BDD](https://testbox.ortusbooks.com/content/primers/bdd/specs.html), que usa clausuras para definir las especificaciones de prueba. No tendrás que preocuparte por instalar TestBox. El ejecutor de pruebas de la CLI se encargará de eso por ti. Solo necesitas estar conectado a internet la primera vez que lo ejecutes. Puedes leer más al respecto aquí:

[https://testbox.ortusbooks.com](https://testbox.ortusbooks.com)
