# Acerca de

[Clojure](http://clojure.org) es un lenguaje de programación dinámico que se ejecuta sobre la Java Virtual Machine (JVM). 
Diseñado como un lenguaje de propósito general, Clojure combina lo accesible de un lenguaje de scripting con una infraestructura robusta para la programación multihilo.

Clojure es predominantemente un lenguaje de programación funcional, y cuenta con un rico conjunto de [estructuras de datos](http://clojure.org/data_structures) inmutables y persistentes.

Clojure es de código abierto, y la información sobre cómo contribuir al lenguaje [está disponible aquí](http://clojure.org/contributing).

Rich Hickey, el creador de Clojure, quería un Lisp moderno para la programación funcional, simbiótico con la consolidada plataforma Java y diseñado para la concurrencia; así nació Clojure.

Aquí hay un par de citas que ejemplifican los objetivos de Clojure:

* _El buen diseño no consiste en hacer grandes planes, sino en descomponer las cosas._
* _Programar no consiste en teclear... consiste en pensar._
