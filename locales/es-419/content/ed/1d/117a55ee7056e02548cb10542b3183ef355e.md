# Introducción

Las funciones son ciudadanos de primera clase en Elixir. Esto significa que:

- Las funciones con nombre y las funciones anónimas se pueden asignar a variables.
- Las funciones con nombre y las funciones anónimas se pueden pasar de un lado a otro como datos, ya sea como argumentos o como valores de retorno.
- Las funciones anónimas se pueden crear dinámicamente.

Las funciones anónimas, a diferencia de las funciones con nombre, no tienen una referencia estática disponible; solo existen si se asignan a una variable o se invocan de inmediato.

Podríamos usar funciones anónimas para:

- Ocultar datos usando el ámbito léxico (también conocido como clausura).
- Crear funciones dinámicamente en tiempo de ejecución.

Las funciones anónimas empiezan con la palabra reservada `fn`, los argumentos se separan del cuerpo de la función con el token `->`, y terminan con un `end`. Igual que con las funciones con nombre, la última expresión de la función se _devuelve implícitamente_ a la función que la llamó.

Para invocar una referencia a una función, debes usar un `.` entre la variable de referencia y la lista de argumentos:

```elixir
function_variable = fn param ->
  param + 1
end

function_variable.(1)
# => 2
```

Incluso puedes usar la notación abreviada de captura para que esto sea más conciso:

```elixir
variable = &(&1 + 1)

variable.(1)
# => 2
```
