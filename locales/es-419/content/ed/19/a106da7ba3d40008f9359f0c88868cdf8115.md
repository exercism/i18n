# Acerca de

Cuando hacemos coincidencia de patrones sobre un valor en Gleam, tenemos que asegurarnos de que los patrones coincidan con todos los valores posibles del tipo; de lo contrario, el código no compilará.

Esta función debería ser rechazada, ya que no ha cubierto el caso en que la lista está vacía:

```gleam
pub fn get_first_element_or_crash(items: List(e)) -> e {
  case items {
    [item, ..] -> item
  }
}
```

La mayoría de las veces, en los programas de Gleam queremos cubrir todos los casos posibles, pero en algunos programas, como prototipos y scripts rápidos, quizá queramos centrarnos solo en el caso exitoso y no escribir código para los demás casos. Aquí es donde entra en juego `let assert` de Gleam.

Con las aserciones con `let assert`, un patrón puede coincidir solo con algunos de los valores posibles de un tipo, y si el patrón no coincide con un valor, el programa fallará. Usando `let assert`, podemos escribir la función de arriba así:

```gleam
pub fn get_first_element_or_crash(items: List(e)) -> e {
  let assert [item, ..] = items
  item
}
```

Las bibliotecas de Gleam nunca deberían usar aserciones con `let assert`, ya que pueden hacer que el programa falle; en su lugar, deberían usar el tipo `Result` y dejar que quien desarrolla la aplicación decida cómo manejar los errores.
