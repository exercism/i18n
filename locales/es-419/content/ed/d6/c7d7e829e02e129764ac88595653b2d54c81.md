# Apéndice de instrucciones

## Instrucciones específicas de Odin

### Zipper en árboles binarios

Las instrucciones anteriores explican el zipper usando un árbol rosa (varios hijos por nodo), pero el concepto de zipper se puede aplicar a cualquier tipo de árbol e incluso a una lista.
Para este ejercicio, usaremos un árbol binario (cada nodo tiene dos hijos), así podemos enfocarnos en las operaciones del zipper en lugar de enfocarnos en manejar una cantidad dinámica de hijos.

Las operaciones que aparecen en las instrucciones se actualizaron para que coincidan con los árboles binarios:

| Operation       | Description                                                                |
| --------------- | -------------------------------------------------------------------------- |
|`zip_from_tree`  | Get a zipper out of a tree, the focus is on the root node.                 |
|`zip_to_tree`    | Get the tree out of the zipper.                                            |
| `zip_value`     | Get the value of the focus node.                                           |
| `zip_left`      | Move the focus to the left child of the focus node, returns a new zipper.  |
| `zip_right`     | Move the focus to the right child of the focus node, returns a new zipper. |
| `zip_up`        | Move the focus to the parent of the focus node, returns a new zipper.      |
| `zip_set_value` | Set the value of the focus node, returns a new zipper.                     |
| `zip_set_left`  | Set the left subtree of the focus node, returns a new zipper.              |
| `zip_set_right` | Set the right subtree of the focus node, returns a new zipper.             |

### Gestión de memoria

En Odin tienes que gestionar la memoria manualmente.
Para simplificar el ejercicio y centrarnos en las operaciones del zipper, la memoria que se asigna a los nodos del árbol y a los caminos se gestiona automáticamente por ti mediante un asignador de arena.
Solo necesitas asignar memoria cuando sea necesario con `new(Node)` y `new(Step)`; cuando terminemos de operar sobre el árbol, la prueba llamará automáticamente a `free_all()` sobre la arena.
Esta es la forma idiomática de manejar las asignaciones de memoria en Odin para cualquier proceso periódico (como un bucle de juego o un conjunto de solicitudes y respuestas).

Si quieres aprender más sobre los asignadores en Odin, específicamente los asignadores de arena, puede que te resulten interesantes los siguientes documentos: [The Allocator chapter in the Odin Overview][allocators-overview], [Understand the Temporary Allocator; Understand arenas by Karl Zylinski][allocators-zylinksi], y [Linear/Arena Allocators by gingerBill][allocators-gingerbill].
