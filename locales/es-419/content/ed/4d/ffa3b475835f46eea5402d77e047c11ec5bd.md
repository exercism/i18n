# Instrucciones

Tu grupo de cuerdas va a dar un recital, y alguien tiene que escribir el programa de mano.

Las cinco tareas van en la clase `PROGRAMME_NOTES`.

## 1. Nombra la pieza y quién la escribió

Pon la pieza primero, después ` by `, y luego el compositor.

```sather
PROGRAMME_NOTES::full_title("Nocturne", "Chopin")
-- => "Nocturne by Chopin"
```

## 2. Mide una línea

El impresor necesita saber cuánto mide una línea.

```sather
PROGRAMME_NOTES::title_length("Nocturne")
-- => 8
```

## 3. Las primeras letras

Dado un título y un número, devuelve esa cantidad de letras desde el principio.

```sather
PROGRAMME_NOTES::opening_letters("Nocturne", 3)
-- => "Noc"
```

## 4. Las últimas letras

Lo mismo, pero contando desde el final.

```sather
PROGRAMME_NOTES::closing_letters("Nocturne", 4)
-- => "urne"
```

## 5. Acorta un título largo

Los títulos que no caben se recortan a sus primeras seis letras, con tres puntos suspensivos después.

```sather
PROGRAMME_NOTES::short_title("Nocturne in E flat")
-- => "Noctur..."
```
