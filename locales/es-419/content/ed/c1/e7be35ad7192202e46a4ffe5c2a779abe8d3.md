# Introducción

Todo el código de Common Lisp se compone de S-Expressions (expresiones simbólicas). Se les llama sexprs para abreviar. Cada sexpr es un átomo o un cons. Cuando se evalúan las S-Expressions, devuelven automáticamente algún valor que ocupa el lugar de la expresión. Cuando escribes tus propias funciones (usando `defun`), el último valor dentro del cuerpo del `defun` se devuelve automáticamente:

```lisp
;; Defining a new function
(defun gimme-foo () 'foo)
;; Calling the function as an S-Expression
(gimme-foo) ; => FOO
```
