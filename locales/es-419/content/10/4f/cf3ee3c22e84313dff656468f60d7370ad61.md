# Case

[Case][case] (a menudo llamado switch en otros lenguajes) es una forma de expresión de control como if-else.
Case permite encadenar múltiples sentencias if-else-if y puede ser más legible a la vez que sigue proporcionando control de flujo.

Un case se define con la palabra clave `case`, seguida de una expresión opcional.
Luego, para cada case, se usa la palabra clave `when` seguida de una expresión que se compara con la expresión de case.
La palabra clave `when` no debe estar indentada con respecto a la palabra clave `case`.
Después de la palabra clave `when` va el código que debe ejecutarse si la expresión de case coincide con la expresión de when.
Case permite una sentencia `else` opcional que se ejecuta si ningún otro case coincide.

La expresión de case se evalúa y luego se compara con cada expresión de `when`.
La expresión se compara usando el operador de igualdad de case (`===`).

```ruby
value = 1
case value
when 1
  "One"
when 2
  "Two"
else
  "Other"
end

# This is the same as:
value = 1
if 1 === value
  "One"
elsif 2 === value
  "Two"
else
  "Other"
end
```

## Operador de igualdad de case (`===`)

El operador de igualdad de case (`===`) es un poco diferente del operador de igualdad (`==`).
El operador verifica si el lado derecho es un miembro del conjunto descrito por el lado izquierdo.
Esto significa que sí importa dónde se coloca cada operando.
Cómo funciona esto depende del tipo del lado izquierdo; por ejemplo, un `Range` verificaría si el lado derecho está dentro del rango, o un `Object` verificaría si el lado derecho es una instancia de `Object`.

```ruby
(1..3) == 1  # => false
(1..3) === 1 # => true

String == "foo"  # => false
String === "foo" # => true
```

## Case con múltiples expresiones

Case permite hacer coincidir múltiples expresiones en un solo case, con cada valor posible separado por una coma.
Ejecutará el código si alguna de las expresiones coincide.
Esto puede ser útil cuando quieres que un solo case tenga múltiples valores posibles.

```ruby
case var
when 1, 2
  "One or two"
else
  "Other"
end
```

## Case con rangos

Case también puede verificar si un valor está dentro de un rango.
Esto se hace usando un rango como expresión de when.

```ruby
case var
when 1..3
  puts "One to three"
else
  puts "Other"
end
```

## Case sin expresión de case

Cuando no se necesita una expresión de case, es posible omitirla.
Hacer esto hará que cada expresión de case se evalúe según su veracidad.
Y hace que se comporten como sentencias if-else-if.

```ruby
case
when 1 == 1
  "One is equal to one"
when 1 > 2
  "One is greater than two"
else
  "Other"
end
```

## when en una sola línea

Ruby permite sentencias case de una sola línea.
Esto se puede usar cuando tienes una sentencia simple de una sola línea.
La sentencia when de una sola línea se escribe como `when <expression> then <statement>`.
Y cuando se usa en la sentencia else, se escribe como `else <statement>`.

```ruby
case var
when 1 then "One"
when 2 then "Two"
else "Other"
end
```

## Case con tipos

Case permite hacer coincidencias con tipos.
Esto es útil cuando quieres un comportamiento diferente según el tipo de una variable.

```ruby
case var
when Integer
  "Integer"
when String
  "String"
else
  "Other"
end
```
