# Instrucciones

Logan, el alienígena de Lisp, ama los números y también le gusta organizar.

Te pide que le ayudes a escribir una función que reciba un array de números y produzca un par de dos arrays: el primero contiene todos los números impares y el segundo, todos los números pares.

## 1. Categorizar un número

Primero vas a necesitar crear una función que reciba un par de dos arrays y un número, y que coloque ese número en el array correcto según si es impar o par:

```lisp
(categorize-number '((1) . (2)) 23) ; => ((23 1) . (2))
(categorize-number '((1) . (2)) 42) ; => ((1) . (42 2))
```

## 2. Categorizar muchos números

Ahora, usando la función que acabas de crear, puedes escribir otra función que reciba un array de números y los categorice como lo hiciste arriba:

```lisp
(partition-numbers '(1 2 3 4))     ; => ((3 1) . (4 2))
(partition-numbers '(42 31 24 13)) ; => ((13 31) . (24 42))
```
