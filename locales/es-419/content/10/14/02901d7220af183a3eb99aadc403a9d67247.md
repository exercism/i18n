# Acerca de

El tipo [unión discriminada][define] representa un número fijo de casos con nombre. Cada valor de una unión discriminada corresponde exactamente a uno de los casos con nombre. Este tipo de dato se conoce como _tipo suma_.

Cada caso de una unión discriminada puede tener datos asociados de forma opcional, y distintos casos pueden tener distintos tipos de datos. Si ninguno de los casos tiene datos asociados, la unión discriminada se parece a lo que otros lenguajes suelen llamar una _enumeración_ (o _enum_).

Una unión discriminada se define con la palabra clave `type` y requiere muy poca sintaxis. Esto las hace fáciles de usar, y las encontrarás en muchos lugares, incluida la biblioteca base.

```fsharp
// Discriminated union without associated data
type Season =
    | Spring
    | Summer
    | Autumn
    | Winter

// Discriminated union with associated data
type Number =
    | Integer of int
    | Float of float
    | Invalid
```

Para crear un valor para un caso específico, puedes referirte a su nombre, o a su nombre completo si el nombre no es único. Como los nombres de los casos son solo funciones constructoras, los datos asociados se pueden pasar como un argumento normal de función.

```fsharp
let byName = Integer 2
let byFullName = Number.Invalid
```

Las uniones discriminadas tienen _igualdad estructural_, lo que significa que dos valores del mismo caso y con los mismos datos (opcionales) son equivalentes.

La forma preferida de trabajar con uniones discriminadas es mediante la [coincidencia de patrones][pattern-matching], usando el [patrón de identificador][identifier-patterns]:

```fsharp
let describe number =
    match number with
    | Integer i -> sprintf "Integer: %d" i
    | Float d  -> sprintf "Float: %f" d
    | Invalid   -> "Invalid"
```
