# Pistas

## General

- Lee sobre los strings en la [guía de String][string-guide] oficial.
- Explora los [métodos disponibles para _Strings_][string-methods].

## 1. Limpia el nombre

- Existe un [método integrado][string-replace] para reemplazar todas las apariciones de una subcadena en un string.
- Existe un [método integrado][string-strip] para eliminar los espacios en blanco al inicio y al final de un string.

## 2. Obtén la primera letra del nombre

- Para obtener un carácter específico de un string, puedes usar el [operador de indexación][string-indexing].

## 3. Formatea la primera letra como una inicial

- Existe un [método integrado][string-upcase] para convertir todos los caracteres de un string a su variante en mayúsculas.

## 4. Coloca las iniciales dentro del corazón

- Existe una sintaxis especial para [interpolar][string-interpolation] una expresión dentro de un string.
- Puedes poner un emoji de corazón en un string usando el escape: `\u<id>`, el id del emoji de corazón es `2764`.
