# Instalación

Hay muchas formas de instalar Zig, y la cantidad de formas de instalar Zig crece de manera constante a medida que el lenguaje madura.
Por suerte, todos los métodos de instalación populares están listados en la [página de instalación de Zig][install-zig].

## Versión de Zig

Actualmente, Exercism solo admite Zig 0.16.0 (publicada el 14 de abril de 2026).

Es posible que un ejercicio sea compatible con otra versión de Zig, pero eso no está garantizado.
Zig todavía no ha alcanzado la versión 1.0, y los cambios que rompen la compatibilidad son habituales.

## Utilidades adicionales

### Zig fmt - Generar código bien formateado

Al resolver cualquier ejercicio, puedes usar todo tipo de estilos de código en tus soluciones.
Sin embargo, fuera de la resolución de ejercicios, por ejemplo al crear aplicaciones o bibliotecas, normalmente es buena idea que tu código sea consistente y legible.
Eso es especialmente importante cuando otras personas que quieran ayudar con tus proyectos tengan que leer tu código.

Para resolver este problema, el compilador de Zig incluye un [linter][linters] ligero integrado que formatea tu código de manera conveniente.
Este formateador de código busca seguir la [guía de estilo][style-guide] ya establecida por la [documentación de Zig][documentation].

Para ver las funcionalidades del formateador nativo de Zig, usa el siguiente comando:

```bash
zig fmt --help
```

### Zig Zen - Reglas para programar

A veces, un poco de orientación ayuda mucho al hacer cualquier tarea, incluso al escribir código.
Por suerte, tenemos un comando divertido integrado directamente en el compilador de Zig para recordarnos algunos de los objetivos que hay detrás de escribir buen código Zig.

Para ver estas palabras de sabiduría, puedes usar el siguiente comando:

```bash
zig zen
```

### El servidor de lenguaje de Zig - Soporte completo para Zig en tu editor

Este software de terceros ofrece autocompletado en el editor y funcionalidades mejoradas de navegación de código Zig que pueden ayudarte a aprender el lenguaje más rápido.

Consulta la [guía de instalación de ZLS][install-zls] para obtener las instrucciones más recientes.
