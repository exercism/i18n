# Instrucciones

Ellen está creando un juego en el que el jugador tiene que pelear contra alienígenas.
Acaba de aprender sobre la programación orientada a objetos (POO) y tiene muchas ganas de aprovechar lo que el uso de `classes` podría aportarle a su programa.

Para alegría de Ellen, te ofreciste a ayudar y ella te encargó la tarea de programar los alienígenas contra los que el jugador tiene que pelear.


## 1. Crea la clase Alien

Define la clase Alien con un constructor que acepte dos parámetros `<x_coordinate>` y `<y_coordinate>`, y asígnalos a las variables de instancia `x_coordinate` y `y_coordinate`.
Además, cada alienígena comenzará con un nivel de salud de 3, así que también debes inicializar la variable `health`.

```python
>>> alien = Alien(2, 0)
>>> alien.x_coordinate
2
>>> alien.y_coordinate
0
>>> alien.health
3
```

Ahora, cada alienígena debería poder llevar un seguimiento interno de su propia posición y su salud.

## 2. El método `hit`

A Ellen le gustaría que la `class` Alien tuviera un método `hit` que reduzca en 1 la salud de un objeto alienígena cada vez que se lo llama.
De esta forma, puede simplemente llamar a `<alien>.hit()` en lugar de tener que cambiar manualmente la salud de un alienígena.
Depende de ti si `hit()` lleva los puntos de salud _hasta_ cero o _por debajo_ de cero.

```python
>>> alien = Alien(0, 0)

# Initialized health value.
>>> alien.health
3

# Decrements health by 1 point.
>>> alien.hit()
>>> alien.health
2
```

## 3. El método `is_alive`

Te das cuenta de que, si la salud sigue disminuyendo, en algún momento probablemente llegará a 0 (_¡o incluso menos!_ ).
Sería buena idea agregar un método `is_alive` al que Ellen pueda llamar rápidamente para verificar si el alienígena está... bueno... vivo. 😉
`<alien>.is_alive()` debe devolver un Boolean.

```python
>>> alien.health
1
>>> alien.is_alive()
True
>>> alien.hit()
>>> alien.health
0
>>> alien.is_alive()
False
```

## 4. El método `teleport`

¡En el juego de Ellen, los alienígenas pueden teletransportarse!
Vas a tener que escribir un método `teleport` que reciba nuevos valores de `x_coordinate` y `y_coordinate`, y cambie las coordenadas del alienígena en consecuencia.

```python
>>> alien.teleport(5, -4)
>>> alien.x_coordinate
5
>>> alien.y_coordinate
-4
```

## 5. El método `collision_detection`

Obviamente, si algo puede golpear a los alienígenas, entonces necesitan poder detectar cuándo ocurrió esa colisión.
Sin embargo, los algoritmos de detección de colisiones pueden ser complicados, y todavía no sabes cómo implementar uno.
Ellen dijo que lo hará más adelante, pero aun así le gustaría que el método `collision_detection` aparezca en la clase como recordatorio para desarrollar esa funcionalidad.
Va a tener que recibir una variable de algún tipo (probablemente otro objeto), pero eso es realmente todo lo que sabes.
Vas a tener que asegurarte de que incluir la definición del método en la clase no cause errores cuando se lo llame:

```python
>>> alien.collision_detection(other_object)
>>>
```

## 6. Contador de alienígenas

Ellen volvió con una nueva petición para ti.
Quiere llevar un registro de cuántos alienígenas se han creado a lo largo de la partida.
Dice que tiene algo que ver con el sistema de puntuación.

Por ejemplo:

```python
>>> alien_one = Alien(5, 1)
>>> alien_one.total_aliens_created
1
>>> alien_two = Alien(3, 0)
>>> alien_two.total_aliens_created
2
>>> alien_one.total_aliens_created
2
# Accessing the variable from the class directly
>>> Alien.total_aliens_created
2
```

A Ellen le encanta lo que has hecho hasta ahora, pero tiene un favor más que pedirte.
Le gustaría una función independiente (_fuera de la clase `Alien()`_ ) que cree una `list` de objetos `Alien()`, a partir de una lista de posiciones (como `tuples`).

Por ejemplo:
