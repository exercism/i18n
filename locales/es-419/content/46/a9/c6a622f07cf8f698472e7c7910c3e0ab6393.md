# Ficticio

## Instrucciones específicas de Tcl

Tcl te permite aplicar capas de «transformaciones» a los canales abiertos.
Estas transformaciones te permiten manipular los datos entrantes y salientes como quieras.

Referencias:

* La [propuesta][tip230] original para las transformaciones de canales.
* La documentación del comando [`chan push`][chan].
* La documentación de [`transchan`][transchan] que describe la API para las transformaciones de canales.

[tip230]: https://core.tcl-lang.org/tips/doc/trunk/tip/230.md
[transchan]: https://www.tcl-lang.org/man/tcl9.0/TclCmd/transchan.html
[chan]: https://www.tcl-lang.org/man/tcl9.0/TclCmd/chan.html#M33
