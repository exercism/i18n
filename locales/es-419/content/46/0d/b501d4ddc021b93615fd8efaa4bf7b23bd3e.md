# Contador de líneas de código

El contador de líneas de código (LoC) toma una solución y cuenta sus líneas de código.

De forma predeterminada, solo se cuentan las líneas de código de los archivos que envió el estudiante.
Si el estudiante envió un archivo de pruebas, este se ignorará.

Si bien esto funciona bien para la mayoría de los envíos, algunos tracks podrían necesitar ignorar archivos adicionales.
Para eso, permitimos que el contador de líneas de código se [personalice por track][lines-of-code-counter-customize].

## Implementación

Usamos la biblioteca [tokei][tokei] para hacer el conteo real.
Como los pull requests a menudo no se fusionan con rapidez, creamos nuestro propio [fork][tokei-fork].
Esto nos permite iterar más rápido y agregar compatibilidad con cualquier lenguaje que queramos.

## Lenguajes compatibles

Puedes comprobar si tu lenguaje es compatible de forma predeterminada buscándolo en el archivo [languages.json][languages.json].

### Agregar un nuevo lenguaje

Si tu lenguaje **no** es compatible, puedes agregar compatibilidad de la siguiente manera:

1. Agrega una entrada para tu lenguaje al archivo [languages.json].
   Consulta la [documentación para agregar lenguajes][adding-language] para más información.
2. Agrega pruebas para verificar que el conteo funciona correctamente para tu lenguaje.
   Consulta la [documentación para agregar pruebas][adding-tests] para más información.

Una vez que hayas hecho estos cambios, abre un pull request al [repositorio exercism/tokei][tokei-fork].
Aquí hay un [pull request de ejemplo][example-pr] que agrega compatibilidad con el lenguaje Arturo.
