# Introducción

Un diccionario (`dict`) en Python es una estructura de datos que asocia _claves_ [hashable][term-hashable] con _valores_, y en otros lenguajes de programación se conoce como [tabla hash][hashtable-wikipedia] redimensionable, hashmap o [array asociativo][associative-array].
Los diccionarios son el único [tipo de mapeo][mapping-types-dict] integrado de Python.


Las `Keys` deben ser hashables y únicas en todo el diccionario.
Los tipos de clave pueden incluir `numbers`, `str` o `tuples` (de valores _inmutables_).
No pueden contener estructuras de datos _mutables_ como `lists`, `dict`s o `set`s.
A partir de Python 3.7, se garantiza que el orden de las claves de un `dict` es el orden en que se insertan las entradas.

Los `values` pueden ser de cualquier tipo o estructura de datos.
 Los valores también pueden anidarse _de forma arbitraria_, así que pueden incluir listas de listas, subdiccionarios y otras estructuras de datos personalizadas o compuestas.

Dado un `key`, los diccionarios pueden recuperar un `value` en tiempo constante (en promedio), _independientemente del número de entradas_.
En comparación con buscar un valor dentro de un `list` o `array` (_sin conocer la posición del `index`_), un `dict` usa bastante más memoria, pero su recuperación es muy rápida.
Los diccionarios son especialmente útiles en escenarios donde la colección de elementos es grande y se debe acceder a ella y actualizarla con frecuencia.


## Construcción de diccionarios

Los diccionarios se pueden crear de muchas maneras.
Las dos más directas son usar el constructor `dict()` o declarar un _literal_ de `dict`.

### El constructor de la clase `dict()`

`dict()` (_el constructor de la clase diccionario_) se puede usar con cualquier iterable de pares `key`, `value` o con una serie de _argumentos_ `<name>=<value>`:

```python
#Passing a list of key,value tuples.
>>> wombat = dict([('name', 'Wombat'),('speed', 23),('land_animal', True)])
{'name': 'Wombat', 'speed': 23, 'land_animal': True}


#Using key=value arguments.
>>> bear = dict(name="Black Bear", speed=40, land_animal=True)
{'name': 'Black Bear', 'speed': 40, 'land_animal': True}
```

### Literales de diccionario

Un `dict` también se puede escribir directamente como un _literal de diccionario_, usando llaves (`{}`) que encierran pares `key : value`:

```python
>>> whale = {"name": "Blue Whale", "speed": 35, "land_animal": False}
{'name': 'Blue Whale', 'speed': 35, 'land_animal': False}
```

## Acceder a los valores de un diccionario

Puedes acceder a una entrada de un diccionario usando una _clave_ entre corchetes (`[]`).
Si un `key` no existe en el `dict`, se lanza un `KeyError`:

```python
>>> bear["speed"]
40

>>> bear["color"]
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
KeyError: 'color'
```

Acceder a una entrada mediante el método `.get(<key>, <default value>)` puede evitar el `KeyError`:

```python
>>> bear.get("color", 'not found')
'not found'
```

## Cambiar o agregar valores de un diccionario

Puedes cambiar el `value` de una entrada asignando a su _clave_:

```python
#Assigning the value "Grizzly Bear" to the name key.
>>> bear["name"] = "Grizzly Bear"
{'name': 'Grizzly Bear', 'speed': 40, 'land_animal': True}

>>> whale["speed"] = 25
{'name': 'Blue Whale', 'speed': 25, 'land_animal': False}
```

Los nuevos pares `key`:`value` se pueden _agregar_ de la misma forma:

```python
# Adding a new "color" key with a new "tawney" value.
>>> bear["color"] = 'tawney'
{'name': 'Grizzly Bear', 'speed': 40, 'land_animal': True, 'color': 'tawney'}

>>> whale["blowholes"] = 1
{'name': 'Blue Whale', 'speed': 25, 'land_animal': False, 'blowholes': 1}
```

## Eliminar (con pop) entradas de un diccionario

Puedes usar el método `.pop(<key>)` para eliminar una entrada del diccionario.
`.pop()` elimina el par (`key`, `value`) y devuelve el `value` para que lo uses.
Al igual que `.get()`, `.pop(<key>)` acepta un segundo argumento (_`dict.pop(<key>, <default value>)`_) que se devolverá si no se encuentra el `key`.
Esto evita que se lance un `KeyError`:

```python
#Using .pop() removes both the key and value, returning the value.
>>> bear.pop("name")
'Grizzly Bear'


#The "name" key is now removed from the dictionary.
#Attempting .pop() a second time will throw a KeyError.
>>> bear.pop("name")
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
KeyError: 'name'


#Using a default argument with .pop() will prevent a KeyError from a missing key.
>>> bear.pop("name", "Unknown")
'Unknown'
```

## Recorrer e iterar un diccionario

Recorrer un diccionario con `for item in dict` o `while item` iterará de forma predeterminada solo sobre las _claves_.
Puedes acceder a los _valores_ dentro del mismo bucle usando _corchetes_:

```python
>>> for key in bear:
>>>     print((key, bear[key])) #this forms a tuple of (key, value) and prints it.
('name', 'Black Bear')
('speed', 40)
('land_animal', True)
```

También puedes usar el método `.items()`, que devuelve tuplas (`key`, `value`) automáticamente:

```python
#dict.items() forms (key, value tuples) that can be unpacked and iterated over.
>>> for key, value in whale.items():
>>>     print(key, ":", value)
name : Blue Whale
speed : 25
land_animal : False
blowholes : 1
```

De manera similar, el método `.keys()` devolverá `keys` y el método `.values()` devolverá `values`.
