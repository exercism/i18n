# Instrucciones

Llevas el horario de travesías de un pequeño ferri que va a una isla. Las
salidas se registran como fechas, y necesitas algunas funciones auxiliares
para trabajar con ellas.

## 1. Registra la fecha de una travesía

Define `make-date` para que reciba un año, un mes y un día, y devuelva la
marca de tiempo correspondiente.

```factor
2024 7 14 make-date .
! => T{ timestamp { year 2024 } { month 7 } { day 14 } ... }
```

## 2. Nombra el día de la semana

Define `weekday-name` para que reciba la marca de tiempo de una travesía y
devuelva el nombre del día de la semana en el que cae.

```factor
2024 1 8 make-date weekday-name .
! => "Monday"
```

## 3. Años bisiestos

Define `leap?` para que reciba un año y devuelva si es un año bisiesto.

```factor
2024 leap? .   ! => t
2023 leap? .   ! => f
```

## 4. Días de un mes

Define `month-length` para que reciba un año y un mes y devuelva el número
de días de ese mes (recuerda febrero).

```factor
2024 2 month-length .   ! => 29
2023 2 month-length .   ! => 28
```

## 5. Días después

Define `add-days` para que reciba una marca de tiempo y un número de días, y
devuelva la marca de tiempo correspondiente a esa cantidad de días después.

```factor
2024 2 28 make-date 1 add-days >date< .
! => 29   (2024-02-29)
```
