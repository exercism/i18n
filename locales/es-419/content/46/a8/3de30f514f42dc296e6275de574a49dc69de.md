# Módulos y rutas en Cairo

Cairo usa **módulos** para organizar el código.

Los módulos ayudan a estructurar proyectos y a controlar la visibilidad de elementos como funciones, structs y traits.

## Definir módulos

Los módulos se definen con `mod` y se pueden anidar:

```rust
mod front_of_house {
    pub mod hosting {
        pub fn add_to_waitlist() {}
    }
}
```

Las funciones, los structs y los traits son **privados por defecto**.

Usa `pub` para hacerlos accesibles fuera de su módulo.

## Rutas: absolutas y relativas

Para referirte a un elemento de otro módulo, puedes usar:

- **Rutas absolutas** (comienzan desde `crate::`):

  ```rust
  crate::front_of_house::hosting::add_to_waitlist();
  ```

- **Rutas relativas** (comienzan desde el módulo actual):

  ```rust
  front_of_house::hosting::add_to_waitlist();
  ```

  Esto funciona si `front_of_house` está en el mismo módulo.

## Traer módulos al ámbito con `use`

Escribir rutas completas una y otra vez es incómodo.

La palabra clave `use` permite referencias más cortas:

```rust
use crate::front_of_house::hosting;

pub fn eat_at_restaurant() {
    hosting::add_to_waitlist(); // Shorter path
}
```

`use` se aplica **solo en el ámbito donde aparece**; si se necesita en otro lugar, hay que repetirlo.

### Uso idiomático de `use`

- Trae **módulos** al ámbito, no funciones:

  ```rust
  use crate::front_of_house::hosting; // ✅
  hosting::add_to_waitlist();
  ```

  En vez de:

  ```rust
  use crate::front_of_house::hosting::add_to_waitlist; // ❌
  add_to_waitlist();
  ```

- Para **traits, structs y enums**, usa la ruta completa:

  ```rust
  use core::num::traits::BitSize;
  ```

### Alias con `as`

Renombra las importaciones cuando sea necesario:

```rust
use core::array::ArrayTrait as Arr;

fn main() {
    let mut arr = Arr::new();
    arr.append(1);
}
```

### Importar varios elementos

En vez de varias sentencias `use`, agrupa las importaciones:

```rust
use shapes::{Square, Circle, Triangle};
```

## Reexportar con `pub use`

Para exponer un módulo en una estructura diferente, usa `pub use`:

```rust
pub use crate::front_of_house::hosting;
```

Ahora el código externo puede usar `restaurant::hosting::add_to_waitlist()` en vez de `restaurant::front_of_house::hosting::add_to_waitlist()`.

## Usar paquetes externos con Scarb

Para agregar una dependencia, actualiza `Scarb.toml`:

```toml
[dependencies]
alexandria_math = { git = "https://github.com/keep-starknet-strange/alexandria.git" }
```

Usa `scarb add <package>` para agregar dependencias y `scarb rm <package>` para eliminarlas.

## El operador glob (`*`)

Para importar todo de un módulo:

```rust
use core::num::traits::*;
```

Esto debe usarse con cuidado, ya que puede hacer que el código sea más difícil de leer.
