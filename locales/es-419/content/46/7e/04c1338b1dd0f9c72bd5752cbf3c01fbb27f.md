# Introducción

## Listas de palabras clave

Las listas de palabras clave son una estructura de datos de clave-valor.

```elixir
[month: "April", year: 2018]
```

Las listas de palabras clave son listas de tuplas `{key, value}` [tuplas][exercism-tuples], y también se pueden escribir así, pero la sintaxis más corta se usa mucho más.

```elixir
[month: "April"] == [{:month, "April"}]
# => true
```

Las claves de una lista de palabras clave deben ser [átomos][exercism-atoms], pero los valores pueden ser cualquier cosa. Cada clave se puede usar más de una vez. Los pares clave-valor de una lista de palabras clave están ordenados.

Puedes trabajar con las listas de palabras clave usando los mismos enfoques que con las listas, o puedes usar el módulo `Keyword`.

[exercism-tuples]: https://exercism.org/tracks/elixir/concepts/tuples
[exercism-atoms]: https://exercism.org/tracks/elixir/concepts/atoms
