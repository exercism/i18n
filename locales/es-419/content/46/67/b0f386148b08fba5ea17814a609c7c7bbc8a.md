# Anexo de las instrucciones

## Registros

| Registro | Uso       | Tipo    | Descripción                                                |
| -------- | --------- | ------- | ---------------------------------------------------------- |
| `$a0`    | entrada   | entero  | categoría: `0` = choice, `1` = ones, `2` = twos, `3` = threes, `4` = fours, `5` = fives, `6` = sixes, `7` = little_straight, `8` = big_straight, `9` = full_house, `10` = four_of_a_kind, `11` = yacht |
| `$a2`    | entrada   | dirección | dados (array de palabras)                                  |
| `$v0`    | salida    | entero  | puntuación resultante                                      |
| `$t0-9`  | temporal  | cualquiera | se usan para almacenamiento temporal                     |
