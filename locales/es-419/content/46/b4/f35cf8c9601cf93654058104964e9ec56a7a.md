# Pistas

## 1. Define el tiempo esperado de horneado en minutos

- Necesitas definir una [constante][constants] que contenga el valor [entero][integers] especificado en la receta.
- La constante debe definirse dentro de la [clase][classes] `Lasagna`.
- Debe definirse fuera de un método.

## 2. Calcula el tiempo restante de horneado en minutos

- Necesitas definir un [método][methods] con un solo parámetro para el tiempo que ya transcurrió.
- Puedes usar el operador matemático (`-`) para restar valores.
- Es posible usar la [constante][constants] que definiste antes.

## 3. Calcula el tiempo de preparación en minutos

- Necesitas definir un [método][methods] con un solo parámetro para el número de capas.
- Puedes usar el operador matemático (`*`) para multiplicar valores.

## 4. Calcula el tiempo total de trabajo en minutos

- Necesitas definir un [método][methods] con dos parámetros con nombre.
- Puedes llamar a uno de los otros métodos que definiste antes.
- Puedes usar el operador matemático (`+`) para sumar valores.
