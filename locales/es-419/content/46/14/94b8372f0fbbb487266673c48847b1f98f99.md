# Operador ternario

Los _operadores ternarios_ se pueden ver como una versión compacta de _if-else_.
Por lo general se usan en sentencias `return` (aunque no están limitados a ellas); necesitan una sola línea para tomar la decisión, y devuelven el valor de la izquierda si la expresión es `true` y el valor de la derecha si es `false`.

Muchas expresiones simples de _if/else_ se pueden simplificar usando _operadores ternarios_.

```java
// this ternary statement
return 5 > 4 ? true : false;

// is equivalent to this if/else
if ( 5 > 4 ) {
    return true;
} else {
    return false;
}
```

Entonces, ¿cómo decidir entre _if-else_ y _ternario_?
Pues los _operadores ternarios_ se usan en escenarios simples, donde solo necesitas devolver un valor según una condición y no hace falta ningún cálculo adicional.
Usa un _if-else_ para todo lo demás, como condiciones anidadas, expresiones grandes y casos en los que necesitas más de una línea para decidir el valor que devuelves.

Si bien puedes anidar _operadores ternarios_, el código suele volverse difícil de leer.
En esos casos es preferible usar if anidados.

```java
// hard to read
int value = expr1 ? expr2 && expr3 ? val1 : (val2 + val3) : expr4;

// easier to read
if (expr1){

    if (expr2 && expr3){

        return val1;
    }

    return val2 + val3;
}
return val4;


```

Los _operadores ternarios_ y las sentencias _if/else_ son un buen ejemplo de que al programar tienes distintas formas de lograr el mismo resultado.
