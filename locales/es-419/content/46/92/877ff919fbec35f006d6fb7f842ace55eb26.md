# Instrucciones

El mosaico del centro comunitario de artes terminó de instalarse el mes pasado, y ahora Magpie Marg lo descubrió. Casi todos los días cambia una que otra pieza por otras más brillantes de su **tesoro** cercano, o arranca una pieza y desaparece durante una hora.

Tú eres la persona voluntaria que registra cada cambio. El mosaico en sí es un **array de tamaño fijo**: una casilla por cada posición de pieza, que guarda un string con el color o `f` para «falta». El tesoro de Magpie Marg es un **vector** de piezas sueltas que ha robado.

## 1. Prepara una fila nueva

Define `fresh-mosaic` para que reciba una longitud `n` y devuelva un array de `n` casillas vacías (cada una con `f`).

```factor
4 fresh-mosaic .
! => { f f f f }
```

## 2. Coloca una pieza

Define `place-tile` para que reciba una fila, una posición y un color, y actualice la fila en el mismo lugar, de modo que la posición indicada pase a tener ese color. La palabra no devuelve nada.

```factor
5 fresh-mosaic   ! { f f f f f }
dup 2 "ruby" place-tile
.
! => { f f "ruby" f f }
```

## 3. Desprende una pieza

Define `chip-tile` para que reciba una fila y una posición, y actualice la fila en el mismo lugar, de modo que la posición indicada vuelva a ser `f`.

```factor
{ "ruby" "lapis" "jade" } 1 chip-tile .
! => { "ruby" f "jade" }
```

## 4. Vuelve a colorear una pieza

Define `recolour-tile` para que reciba una fila, una posición y una quotation de un argumento, y actualice la fila en el mismo lugar aplicando la quotation a la pieza que está en esa posición.

```factor
{ "RUBY" "LAPIS" "JADE" } 1 [ >lower ] recolour-tile .
! => { "RUBY" "lapis" "JADE" }
```

## 5. Toma una instantánea antes de que llegue Marg

Define `snapshot-mosaic` para que reciba una fila y devuelva una copia independiente que no se vea afectada por las mutaciones posteriores del original.

```factor
{ "ruby" "lapis" "jade" } dup snapshot-mosaic    ! two equal but independent copies
swap 0 "amber" place-tile                        ! mutate the first
.s
! => { "ruby" "lapis" "jade" }                   (the snapshot)
! => { "amber" "lapis" "jade" }                  (the mutated original)
```

## 6. Marg se guarda una pieza

Define `stash-tile` para que reciba el tesoro de Marg (un vector) y un color, y agregue el color al tesoro. No devuelve nada.

```factor
V{ } clone   ! a fresh empty hoard
dup "ruby"  stash-tile
dup "lapis" stash-tile
.
! => V{ "ruby" "lapis" }
```

## 7. Marg devuelve una pieza

Define `return-tile` para que reciba el tesoro de Marg y quite y devuelva la pieza guardada más recientemente (la que está arriba).

```factor
V{ "ruby" "lapis" "jade" } clone
dup return-tile .
! => "jade"
.
! => V{ "ruby" "lapis" }
```
