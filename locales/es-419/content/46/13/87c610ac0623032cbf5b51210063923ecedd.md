# Acerca de

Las funciones **definidas por el usuario** se crean con la palabra clave `function`. Después debe seguirle un nombre de función y una lista de argumentos.

```php
function alarm($hour, $minute, $second)
{
    return 'Alarm!';
}
```

Se puede llamar a las funciones en un archivo antes de definirlas, ya que se elevan al principio de su ámbito.

## Nombres

Los nombres de las funciones en PHP siguen las reglas de las demás etiquetas: deben comenzar con un guion bajo o una letra, y después pueden ir seguidas de cualquier cantidad de letras, números o guiones bajos.
