# Introducción

Las listas en C# son colecciones de valores primitivos o de instancias de structs o clases. En la biblioteca de clases base se implementan como `List<T>`, donde `T` es el tipo del elemento de la lista. La API expone un amplio conjunto de métodos para crear y manipular listas.

Se pueden agregar y quitar elementos de las listas. Crecen y se reducen según sea necesario.

```csharp
var listOfStrings = new List<string>();
```
