# Instrucciones

En este ejercicio, implementarás la lógica de la misión para un nuevo juego de rol que está desarrollando un amigo.

La protagonista del juego es Annalyn, una chica valiente con un perro feroz y leal. Por desgracia, todo se complica: su mejor amigo fue secuestrado mientras buscaba bayas en el bosque.

Annalyn intentará encontrar y liberar a su mejor amigo, y puede que lleve a su perro con ella en esta misión.

Después de pasar un tiempo siguiendo el rastro de su mejor amigo, encuentra el campamento en el que está prisionero. Resulta que hay dos secuestradores: un caballero poderoso y un arquero astuto.

Una vez que encuentra a los secuestradores, Annalyn considera cuáles de las siguientes acciones puede realizar:

- _Ataque rápido_: se puede hacer un ataque rápido si el caballero está durmiendo, ya que tarda en ponerse la armadura, así que estará vulnerable.
- _Espiar_: se puede espiar al grupo si al menos uno de ellos está despierto. De lo contrario, espiar es una pérdida de tiempo.
- _Hacer señales al prisionero_: se le pueden hacer señales al prisionero usando sonidos de aves si el prisionero está despierto y el arquero está durmiendo, ya que los arqueros están entrenados en las señales con aves y podrían interceptar el mensaje.
- _Liberar al prisionero_: Annalyn puede intentar colarse en el campamento para liberar al prisionero.
  Es algo arriesgado y solo puede salir bien de una de estas dos maneras:
  - Si Annalyn lleva a su perro, puede rescatar al prisionero si el arquero está dormido.
    El caballero le tiene miedo al perro y el arquero no tendrá tiempo de prepararse antes de que Annalyn y el prisionero escapen.
  - Si Annalyn no lleva a su perro, ella y el prisionero tendrán que actuar con mucho sigilo.
    Annalyn puede liberar al prisionero si el prisionero está despierto y el caballero y el arquero están durmiendo, pero si el prisionero está durmiendo no se lo puede rescatar: el prisionero se asustaría con la aparición repentina de Annalyn y despertaría al caballero y al arquero.

Tienes cuatro tareas: implementar la lógica para determinar si las acciones anteriores están disponibles según el estado de los tres personajes que están en el bosque y según si el perro de Annalyn está presente o no.

## 1. Comprobar si se puede hacer un ataque rápido

Implementa el método `can_fast_attack()` que recibe un valor Boolean que indica si el caballero está despierto. Este método devuelve `TRUE` si se puede hacer un ataque rápido según el estado del caballero. De lo contrario, devuelve `FALSE`:

```R
knight_is_awake <- TRUE
can_fast_attack(knight_is_awake)
# => FALSE
```

## 2. Comprobar si se puede espiar al grupo

Implementa el método `can_spy()` que recibe tres valores Boolean que indican si el caballero, el arquero y el prisionero, respectivamente, están despiertos. El método devuelve `TRUE` si se puede espiar al grupo según el estado de los tres personajes. De lo contrario, devuelve `FALSE`:

```R
knight_is_awake <- FALSE
archer_is_awake <- TRUE
prisoner_is_awake <- FALSE
can_spy(knight_is_awake, archer_is_awake, prisoner_is_awake)
# => TRUE
```

## 3. Comprobar si se le pueden hacer señales al prisionero

Implementa el método `can_signal_prisoner()` que recibe dos valores Boolean que indican si el arquero y el prisionero, respectivamente, están despiertos. El método devuelve `TRUE` si se le pueden hacer señales al prisionero según el estado de los dos personajes. De lo contrario, devuelve `FALSE`:

```R
archer_is_awake <- FALSE
prisoner_is_awake <- TRUE
can_signal_prisoner(archer_is_awake, prisoner_is_awake)
# => TRUE
```

## 4. Comprobar si se puede liberar al prisionero

Implementa el método `can_free_prisoner()` que recibe cuatro valores Boolean. Los tres primeros parámetros indican si el caballero, el arquero y el prisionero, respectivamente, están despiertos. El último parámetro indica si el perro de Annalyn está presente. El método devuelve `TRUE` si se puede liberar al prisionero según el estado de los tres personajes y la presencia del perro de Annalyn. De lo contrario, devuelve `FALSE`:

```R
knight_is_awake <- FALSE
archer_is_awake <- TRUE
prisoner_is_awake <- FALSE
pet_dog_is_present <- FALSE
can_free_prisoner(knight_is_awake, archer_is_awake, prisoner_is_awake, pet_dog_is_present)
# => FALSE
```
