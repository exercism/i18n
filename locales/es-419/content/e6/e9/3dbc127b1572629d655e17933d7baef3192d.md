# Acerca de

CoffeeScript es un lenguaje que transpila a JavaScript y se usa para crear sitios web dinámicos (tanto en el navegador web como en el servidor).
El transpilador se usa para transformar el código de CoffeeScript en JavaScript antes de ejecutarlo, y así mantener la compatibilidad y el mismo rendimiento de JavaScript, ¡al mismo tiempo que ofrece muchas características nuevas!

CoffeeScript se creó para ofrecer una forma simplificada de escribir JavaScript, basada en una mezcla de los lenguajes Ruby y Python.
Una de sus diferencias es el uso de la indentación y las flechas para reemplazar el verboso código de funciones de JavaScript, y además incorpora características útiles de los lenguajes funcionales, como la coincidencia de patrones.

CoffeeScript es uno de los muchos lenguajes nuevos que transpilan a JavaScript, como TypeScript y Flow: la comunidad está creciendo y este tipo de lenguajes es muy popular.
