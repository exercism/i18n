# Introducción

## Listas

Una [`List`][lists] en Elm es una colección inmutable de cero o más valores del mismo tipo.

Las listas se pueden definir de la siguiente manera:

```elm
empty = []
singleValue = [ 5 ]
threeValues = [ "a", "b", "c" ]
```

La forma más común de agregar un elemento a una lista es mediante el operador `::` (cons):

```elm
twoToFour = [ 2, 3, 4 ]
oneToFour = 1 :: twoToFour --> [ 1, 2, 3, 4 ]
```

Las listas se manipulan con funciones y operadores definidos en el [módulo `List`][list-module] o mediante [coincidencia de patrones][list-destructuring]

```elm
describe : List String -> String
describe list =
    case list of
        [] ->
            "Empty list"

        [ "hello" ] ->
            "Singleton list with: hello"

        x :: xs ->
            "Non-empty list with head: " ++ x

describe []                   --> "Empty list"
describe [ "hello" ]          --> "Singleton list with: hello"
describe [ "hello", "world" ] --> "Non-empty list with head: hello"
```
