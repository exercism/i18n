# Introducción

[Los rangos][range] representan un intervalo entre dos valores.
Los rangos se usan comúnmente con tipos como `Int`, `String` y `Character` para iterar sobre secuencias, rebanar colecciones o comprobar si un valor cae dentro de los límites.

Swift ofrece dos operadores de rango principales:

- **Operador de rango cerrado (`...`)**: incluye tanto el valor inicial como el final (`1...5` incluye 1, 2, 3, 4 y 5).
- **Operador de rango semiabierto (`..<`)**: incluye el valor inicial pero excluye el final (`1..<5` incluye 1, 2, 3 y 4).

```swift
let closed = 1...5
let halfOpen = 1..<5
```

~~~~exercism/note
Cuando llamas a un método directamente sobre un literal de rango, encierra la expresión de rango entre paréntesis para que el compilador evalúe primero el rango:

```swift
(1...5).contains(3) // Returns true
// 1...5.contains(3) // Error: value of type 'Int' has no member 'contains'
```
~~~~

## Convertir un rango en un array

Puedes convertir un rango de números en un `Array` usando el inicializador `Array(_:)`:

```swift
let range = 1...5
let numbers = Array(range)
// numbers is [1, 2, 3, 4, 5]
```

## Rebanar un array con rangos

Puedes usar rangos para rebanar subsecciones de un array:

```swift
let array = [10, 20, 30, 40, 50]
let slice = array[1...3]
// slice contains [20, 30, 40]
```

## Propiedades y métodos de los rangos

Las operaciones más comunes con rangos incluyen:

| Miembro                 | Descripción                                                | Ejemplo                              |
| ----------------------- | ---------------------------------------------------------- | ------------------------------------ |
| `count`                 | Devuelve el número de elementos del rango                  | `(1...5).count` devuelve `5`         |
| [`contains(_:)`][contains] | Devuelve `true` si el rango incluye el valor especificado | `(1...5).contains(3)` devuelve `true` |

## Rangos de un solo lado

Swift también admite rangos de un solo lado (parciales), donde omites el valor inicial o el final:

- `array[2...]`: desde el índice 2 hasta el final de la colección.
- `array[...2]`: desde el inicio de la colección hasta el índice 2, incluido.
- `array[..<2]`: desde el inicio de la colección hasta el índice 2, sin incluirlo.

## Rangos de string y carácter

También se pueden crear rangos entre caracteres o strings que cumplan con `Comparable`:

```swift
let letters = "a"..."z"
print(letters.contains("m")) // Prints true
print(letters.contains("A")) // Prints false
```
