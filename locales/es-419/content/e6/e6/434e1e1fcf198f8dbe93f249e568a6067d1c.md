# Pistas

## 1. Haz que `preparation-time-in-minutes` sea más fácil de usar

- Un «parámetro rest» recoge en una lista todos los argumentos que no consumen los demás parámetros.
- Un «parámetro rest» se designa en la lista lambda con la palabra clave `&rest`.
- Puedes usar la función `length` para obtener la cantidad de elementos de una lista.

## 2. Permite cambiar el tiempo esperado en el horno

- Un parámetro opcional se puede proporcionar o no.
- Un parámetro opcional puede tener un valor predeterminado.
- Los parámetros opcionales se designan con la palabra clave `&optional`.

## 3. Lilly recuerda otro estilo de cocción preferido

- Puedes especificar un «parámetro supplied-p» junto con el parámetro opcional para determinar si quien llama proporcionó el parámetro.

## 4. Dividir las sobras

- Los parámetros de palabra clave tienen nombre y son opcionales.
- Los parámetros de palabra clave se designan con la palabra clave `&key`.

## 5. Hacer suposiciones

- Los parámetros de palabra clave pueden tener valores predeterminados.

## 6. Cantidad estándar de sobras

- Los parámetros de palabra clave pueden tener un «parámetro supplied-p», igual que los parámetros opcionales.
