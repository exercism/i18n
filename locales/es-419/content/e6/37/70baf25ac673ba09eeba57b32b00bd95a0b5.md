# Introducción

Cuando una quotation necesita *recordar* valores de su entorno, Factor ofrece dos herramientas: `curry`/`compose` de [`kernel`][kernel], y la sintaxis fry `'[ … ]` de [`fry`][fry].

`curry` coloca un valor al inicio de una quotation:

```
curry ( value quot -- newquot )
```

```factor
3 [ + ] curry .          ! => [ 3 + ]
10 3 [ + ] curry call .  ! => 13
```

`compose` une dos quotations entre sí:

```factor
[ 1 + ] [ 2 * ] compose .       ! => [ 1 + 2 * ]
5 [ 1 + ] [ 2 * ] compose call . ! => 12
```

Para más de una o dos capturas, fry resulta más limpio. Cada marcador de posición `_` se llena, en orden, con un valor tomado de la pila:

```factor
2 3 '[ _ _ + + ] .    ! => [ 2 3 + + ]
```

fry también llega hasta las quotations anidadas.

[kernel]: https://docs.factorcode.org/content/vocab-kernel.html
[fry]: https://docs.factorcode.org/content/vocab-fry.html
