# Fundamentos

Un programa en Sather está hecho de **clases**. Una clase es una caja con nombre que contiene rutinas. Una **rutina** es una pieza de trabajo con nombre que produce una respuesta.

```sather
class GREETER is

   hello : STR is
      return "Hello!";
   end;

end; -- class GREETER
```

Si lo lees desde arriba:

- `class GREETER is` abre la caja y le da nombre. Los nombres de las clases se escriben en mayúsculas.
- `hello : STR is` inicia una rutina llamada `hello` que produce un `STR`, una pieza de texto, llamada *cadena*. El `: STR` es una promesa sobre qué tipo de respuesta regresa.
- `return "Hello!";` devuelve la respuesta. El texto se escribe entre comillas dobles.
- `end;` cierra la rutina, y el segundo `end;` cierra la clase.

Todo lo que va después de `--` en una línea es un **comentario**. Sather lo ignora; está ahí para las personas.

```sather
-- This line is for the reader, not the computer.
```

Para usar una rutina desde otro lugar, escribe el nombre de la clase, dos puntos dobles, y el nombre de la rutina:

```sather
GREETER::hello        -- this is "Hello!"
```

Dentro de la misma clase puedes omitir el nombre de la clase:

```sather
class GREETER is

   hello : STR is
      return "Hello!";
   end;

   greeting_again : STR is
      return hello;      -- calls the routine just above
   end;

end; -- class GREETER
```

Una rutina que no recibe argumentos se llama sin paréntesis: `hello`, no `hello()`.
