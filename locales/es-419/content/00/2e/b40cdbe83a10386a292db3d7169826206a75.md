# Introducción

Common Lisp tiene un concepto llamado «The Printer» que abarca todas las funciones para escribir representaciones textuales de datos de Lisp. Una de esas funciones es `format`, que permite darle a los datos el formato que se quiera.

Las capacidades de `format` y de The Printer en general son un tema extenso; aquí se describirán los aspectos básicos del uso de `format`.

## La función FORMAT

La función `format` recibe al menos dos argumentos: un flujo al que imprimir y una cadena de control que define qué se imprime y cómo.

Los flujos son un concepto aparte y se describirán en otra parte. Pero por ahora lo único que necesitas saber es que la impresión se hace hacia el flujo y que hay dos valores especiales para este argumento: `t` y `nil`. `t` significa imprimir en la salida estándar (en realidad, el flujo al que está vinculada la variable `*standard-output*`), y `nil` significa crear una cadena y devolverla.

Ten en cuenta que `format` siempre devolverá `nil`, excepto en ese último caso, en el que se especifica `nil` como flujo. Esta es una forma común de hacer una simple interpolación o construcción de cadenas.

```lisp
(format nil "hello world") ; => "hello world"
(format t "hello world")   ; => NIL (but "hello world" is printed to standard output)
```

## Directivas de formato

La cadena de control puede contener «directivas de formato», que le dan instrucciones a `format` sobre qué imprimir y cómo interpretar cualquier otro parámetro que se le pase. En cierto sentido, la cadena de control es un programa que `format` interpreta y ejecuta. Todas las directivas comienzan con `~` y van seguidas de un carácter (_p. ej._, `~A`, `~D`, `~&`). No importa si el carácter está en mayúscula o en minúscula.

La mayoría de las directivas de formato simplemente interpolan un argumento de `format` en la salida. Se dice que «consumen» el argumento. Algunas directivas no consumen argumentos, o consumen más de uno. Incluso hay una directiva que te permite saltar de un lado a otro en la lista de argumentos u omitir argumentos.

## Formato básico

Una directiva de formato muy general es `~A`. Imprime una versión «legible para humanos» de los datos.

```lisp
(format nil "Value = ~a" 10)                ; => "10"
(format nil "hello ~a" "world")             ; => "hello world"
(format nil "The list is: ~A" (list 1 2 3)) ; => "The list is: (1 2 3)"
```

Otra directiva de formato útil es `~S`. Imprime una versión «legible para la máquina» de los datos. Puede resultar muy útil si quieres poder interpretar la salida generada como datos de Lisp. En muchas cosas se verá igual que `~A`, pero fíjate en que, por ejemplo, para las cadenas la salida incluirá las comillas (escapadas cuando se incluyen dentro de otra cadena), de modo que el valor se pueda volver a leer como el parámetro de tipo cadena.

```lisp
(format nil "~s" 10)            ; => "10"
(format nil "~s" "hello world") ; => "\"hello world\""
(format nil "~s" (list 1 2 3))  ; => "(1 2 3)"
```

Otras dos directivas muy útiles son `~%` y `~&`. La primera emite un carácter de nueva línea, mientras que la segunda emite una «línea nueva». La diferencia es que `~%` siempre emite una nueva línea, mientras que `~&` la emite solo si no estás ya al principio de una línea. Ninguna de las dos consume argumentos.

```lisp
(format nil "~%new~%lines") ; => "
                                  new
                                  lines"

(format nil "~&new~&lines"  ; => "new
                                  lines"
```

Por último, `~~` es una directiva sencilla que emite un `~` literal.
