# Introducción

Un `string` (una cadena) en Go es una secuencia inmutable de bytes, que no necesariamente tiene que representar caracteres.

Un literal de string se define entre comillas dobles:

```go
const name = "Jane"
```

Los strings se pueden concatenar con el operador `+`:

```go
"Jane" + " " + "Austen"
// => "Jane Austen"
```

Algunos caracteres especiales hay que escaparlos con una barra invertida delante, como `\t` para un tabulador y `\n` para un salto de línea en los strings.

```go
"How is the weather today?\nIt's sunny"  
// =>
// How is the weather today?
// It's sunny
```

El paquete `strings` contiene muchas funciones útiles para trabajar con strings.
Para más información sobre las funciones para strings, consulta la [documentación del paquete strings](https://pkg.go.dev/strings).
Aquí tienes algunos ejemplos:

```go
import "strings"

// strings.ToLower returns the string given as argument with all its characters lowercased
strings.ToLower("MaKEmeLoweRCase")
// => "makemelowercase"

// strings.Repeat returns a string with a substring given as argument repeated many times
strings.Repeat("Go", 3)
// => "GoGoGo"
```
