# Instrucciones

Mientras trabajas en _Instruments of Texas_, se te encarga trabajar en una calculadora experimental de notación polaca inversa [RPN] escrita en Elixir. Tu equipo tiene un problema con algunas operaciones que lanzan errores y hacen que el proceso se caiga. Se te ha encargado escribir una función que envuelva a la función de operación para que los errores se puedan manejar de forma más elegante con código idiomático de Elixir.

## 1. Advertir al equipo

Implementa la función `calculate!/2` para llamar a la función de operación con la pila como único argumento. La función de operación está definida en otro lugar, pero sabes que puede completarse con éxito o lanzar un error.

```elixir
stack = []
operation = fn _ -> :ok end
RPNCalculator.calculate!(stack, operation)
# => :ok

stack = []
operation = fn _ -> raise ArgumentError, "An error occurred" end
RPNCalculator.calculate!(stack, operation)
# => ** (ArgumentError) An error occurred
```

> Los nombres de funciones que terminan en `!` son una advertencia para los programadores de que esta función puede lanzar un error

## 2. Envolver el error

Cuando investigas más, te das cuenta de que muchas funciones usan átomos y tuplas para indicar su éxito o fracaso. Implementa `calculate/2` usando esta estrategia.

```elixir
stack = []
operation = fn _ -> "operation completed" end
RPNCalculator.calculate(stack, operation)
# => {:ok, "operation completed"}

stack = []
operation = fn _ -> raise ArgumentError, "An error occurred" end
RPNCalculator.calculate(stack, operation)
# => :error
```

## 3. Transmitir el mensaje

Algunos de los errores contienen información importante que tus compañeros de trabajo necesitan para asegurar el correcto funcionamiento del sistema. Implementa `calculate_verbose/2` para transmitir el mensaje de error. El error es una estructura que tiene un campo `:message`.

```elixir
stack = []
operation = fn _ -> "operation completed" end
RPNCalculator.calculate_verbose(stack, operation)
# => {:ok, "operation completed"}

stack = []
operation = fn _ -> raise ArgumentError, "An error occurred" end
RPNCalculator.calculate_verbose(stack, operation)
# => {:error, "An error occurred"}
```
