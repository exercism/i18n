# Pistas

Tu código debe contener una función frequency :: Int -> [Text] -> Map Char Int
que recibe una cantidad de trabajadores para usar en paralelo y una lista
de textos, y que devuelve la frecuencia total de cada letra del texto.

## Prueba de rendimiento

Comprueba cómo afecta al rendimiento de tu solución cambiar la cantidad de trabajadores ejecutando la prueba de rendimiento. Usa `stack bench` para ejecutarla. No dudes en modificar `bench/Benchmark.hs` para explorar el rendimiento de tu solución con distintas entradas.
