# Instrucciones

Convierte un número octal, representado como un string (por ejemplo, «1735263»), a su equivalente decimal usando los principios básicos (es decir, no, no puedes usar bibliotecas integradas ni externas para hacer la conversión).

Implementa la conversión de octal a decimal.
Dado un string de entrada en octal, tu programa debe producir una salida decimal.

## Nota

- Implementa la conversión por tu cuenta.
  No uses otra cosa que haga la conversión por ti.
- Trata la entrada no válida como el octal 0.

## Acerca del octal (base 8)

El decimal es un sistema de base 10.

Un número 233 en notación de base 10 se puede entender
como una combinación lineal de potencias de 10:

- El dígito de más a la derecha se multiplica por 10^0 = 1
- El siguiente número se multiplica por 10^1 = 10
- ...
- El n-ésimo número se multiplica por 10^_(n-1)_.
- Todos estos valores se suman.

Entonces:

```text
   233 # decimal
 = 2*10^2 + 3*10^1 + 3*10^0
 = 2*100  + 3*10   + 3*1
```

El octal es similar, pero usa potencias de 8 en lugar de potencias de 10.

Entonces:

```text
   233 # octal
 = 2*8^2 + 3*8^1 + 3*8^0
 = 2*64  + 3*8   + 3*1
 = 128   + 24    + 3
 = 155
```
