# Acerca de

Una [`list`][list] es una colección mutable de elementos en _secuencia_.
 Como la mayoría de las colecciones (_mira las integradas [`tuple`][tuple], [`dict`][dict] y [`set`][set]_), las listas pueden guardar referencias a cualquier tipo de dato (o a varios tipos), incluidas otras listas.
 En Python se consideran una [secuencia][sequence type] y se pueden copiar entera o parcialmente mediante la [notación de rebanadas][slice notation].
Como cualquier secuencia, puedes hacer referencia a los elementos de las `lists` por un número de índice `0-based` desde la izquierda, o un número de índice `0-based index` desde la derecha.

Las listas admiten tanto las [operaciones de secuencia comunes][common sequence operations] como las [operaciones de secuencia mutables][mutable sequence operations], por ejemplo `min(<list>)`/`max(<list>)`, `<list>.index()`, `<list>.append()` y `<list>.reverse()`.
 Se puede iterar sobre los elementos con la construcción `for item in <list>`, y con `for index, item in enumerate(<list>)` cuando necesitas tanto el elemento como su índice.

Python ofrece muchos [métodos][list-methods] útiles para trabajar con listas.

 Como las listas son mutables, los métodos de lista **modifican el objeto de lista original** que se pasa al método.
Si no quieres modificar la lista original, necesitas hacer una `shallow copy` (_como mínimo_) de la `list` original mediante `slice` o `<list>.copy()`.


## Agregar elementos

Puedes agregar elementos al final de una lista existente con `<list>.append(<item>)`:

```python
>>> numbers = [1, 2, 3]
>>> numbers.append(9)

>>> numbers
[1, 2, 3, 9]
```

En lugar de _agregar al final_, `<list>.insert(<index>, <item>)` coloca el elemento en un _índice específico_ dentro de la lista.
`<index>` es el índice del elemento _antes del cual_ quieres que aparezca el nuevo elemento.
`<item>` es el elemento que se va a insertar.

**Nota**: Si `<index>` es 0, el elemento se agregará al inicio de la lista.
Si `<index>` es mayor que el último índice de la lista, el elemento se agregará en la última posición, es decir, lo mismo que usar `<list>.append(<item>)`.

```python
>>> numbers = [1, 2, 3]
>>> numbers.insert(0, -2)

>>> numbers
[-2, 1, 2, 3]

>>> numbers.insert(1, 0)

>>> numbers
[-2, 0, 1, 2, 3]
```

Un `iterable` se puede _combinar_ con una lista existente (concatenando los dos) mediante `<list>.extend(<iterable>)`.
`<list>.extend(<iterable>)` _desempaqueta_ el iterable que le pases y agrega sus elementos, en el mismo orden, al final de la lista destino.
Usar `<list>.append(<item>)` en este caso agregaría todo el iterable como _**un solo elemento**_.


```python
>>> numbers = [1, 2, 3]
>>> other_numbers = [5, 6, 7]

>>> numbers.extend(other_numbers)

>>> numbers
[1, 2, 3, 5, 6, 7]

>>> numbers.extend([8, 9])

>>> numbers
[1, 2, 3, 5, 6, 7, 8, 9]
```


## Eliminar elementos

Puedes usar `<list>.remove(<item>)` para eliminar un elemento de la lista.
 `<list>.remove(<item>)` lanzará un `ValueError` si el elemento no está presente en la lista.


```python
>>> numbers = [1, 2, 3]
>>> numbers.remove(2)

>>> numbers
[1, 3]

# Trying to remove a value that is not in the list throws a ValueError.
>>> numbers.remove(0)
ValueError: list.remove(x): x not in list
```

Como alternativa, el método `<list>.pop(<index>)` elimina un elemento **y** lo `return` para que puedas usarlo.

`<list>.pop(<index>)` recibe un parámetro opcional: el `index` del elemento que se va a eliminar y devolver.
Si no se especifica el argumento opcional `<index>`, se eliminará y devolverá el último elemento de la lista.
Si `<index>` es un número mayor que el último índice de la lista, se lanzará un `IndexError`.


```python
>>> numbers = [1, 2, 3]
>>> numbers.pop(0)
1

>>> numbers
[2, 3]
>>> numbers.pop()
3

>>> numbers
[2]

# This will throw an error because there is only index 0.
>>> numbers.pop(1)
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
IndexError: pop index out of range
```

Puedes eliminar todos los elementos de una `list` con `<list>.clear()`. No recibe ningún parámetro.


```python
>>> numbers = [1, 2, 3]
>>> numbers.clear()

>>> numbers
[]
```


## Invertir y reordenar

El orden de los elementos de una lista se puede invertir _**en el mismo lugar**_ con `<list>.reverse()`. Esto modifica la lista original.


```python
>>> numbers = [1, 2, 3]
>>> numbers.reverse()

>>> numbers
[3, 2, 1]
```

Una lista se puede reordenar _**en el mismo lugar**_ con la ayuda de [`<list>.sort()`][sort].
De manera predeterminada, la lista se ordena de forma _ascendente_, de izquierda a derecha.
La documentación de Python ofrece [consejos y técnicas adicionales para ordenar][sorting how to].

```python
>>> names = ["Tony", "Natasha", "Thor", "Bruce"]

# The default sort order is *ascending*.
>>> names.sort()

>>> names
["Bruce", "Natasha", "Thor", "Tony"]
```

Para ordenar una lista en orden _descendente_, pasa un argumento `reverse=True` al método:


```python
>>> names = ["Tony", "Natasha", "Thor", "Bruce"]
>>> names.sort(reverse=True)

>>> names
["Tony", "Thor", "Natasha", "Bruce"]
```


Cuando modificar la `list` original no sea lo que quieres, puedes usar las funciones integradas [`sorted()`][sorted] y [`reversed()`][reversed].
 `sorted(<list>)` devuelve una _copia_ ordenada y recibe los mismos parámetros que `<list>.sort()`.
 `reversed(<list>)` devuelve un _iterador_ que entrega los elementos de la lista en orden inverso.
 Los `Iterators` se tratarán en detalle en otro ejercicio.


## Ocurrencias de un elemento en una lista

Puedes averiguar cuántas veces aparece un elemento en una lista con `<list>.count(<item>)`.
 Devuelve el número total de veces que `<item>` aparece como elemento en la lista.


```python
>>> items = [1, 4, 7, 8, 2, 9, 2, 1, 1, 0, 4, 3]

>>> items.count(1)
3
```


## Encontrar el índice de los elementos

`<list>.index(<item>)` devuelve el número de índice de la _primera aparición_ del elemento que le pases.
 Si no aparece ninguna vez, se genera un `ValueError`.
 La indexación es `-1-based index` desde la izquierda, lo que significa que la posición del primer elemento es el índice `0`.
 También se admite la indexación desde la derecha, que comienza con el índice `-1`.


```python
>>> items = [7, 4, 1, 0, 2, 5]
>>> items.index(4)
1

>>> items.index(10)
ValueError: 10 is not in list
```

Si indicas los índices `start` y `end`, la búsqueda se hace dentro de una sección específica de la lista:


```python
>>> names = ["Tina", "Leo", "Thomas", "Tina", "Emily", "Justin"]
>>> names.index("Tina")
0

>>> names.index("Tina", 2, 5)
3
```

Si no necesitas la posición exacta de un elemento, el operador integrado `in` es más eficiente para comprobar si está en la lista.


```python
>>> names = ["Tina", "Leo", "Thomas", "Tina", "Emily", "Justin"]

>>> "Thomas" in names
True
```


## Hacer copias

Recuerda que las variables en Python son nombres que apuntan a objetos subyacentes.
 Los nombres se pueden vincular o volver a vincular a distintos objetos a lo largo de la vida de un programa.
 Asignar un objeto `list` a un nuevo _**nombre**_ de variable no copia el objeto ni ninguno de los datos a los que hace referencia.
 El nombre nuevo y el viejo apuntarán al mismo objeto `list`.
 Además, las listas son objetos de tipo _contenedor_. Para ahorrar espacio, los contenedores solo guardan _referencias_ a los elementos que contienen, no los elementos en sí.
 Esta «optimización» puede tener consecuencias inesperadas para quien no está atento.

`<list>.copy()` crea un nuevo objeto `list`, pero **no** crea objetos nuevos para los _elementos_ de la lista referenciados: la copia es «superficial».
 Una `shallow copy` suele ser suficiente cuando quieres agregar o quitar elementos de uno de los objetos `list` sin modificar el otro.
 Pero si existe alguna posibilidad de que los _elementos subyacentes_ de una `list` se modifiquen por accidente (_y con ello se modifiquen todas las copias superficiales relacionadas_), deberías usar [`copy.deepcopy()`][deepcopy] del módulo `copy` para crear una copia completa o «profunda» de **todas** las referencias y los objetos.

Para ver una explicación detallada del comportamiento de los nombres, los valores, las listas y las listas anidadas, mira esta excelente publicación de blog de [Ned Batchelder][ned batchelder]: [Names and values: making a game board][names and values].
 [Shallow vs Deep Copying of Python Objects][shallow vs deep] también ofrece un buen resumen de las consideraciones al copiar.
