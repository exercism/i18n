# Acerca de

Los operadores aritméticos y de comparación principales se pueden adaptar para que los use tu propio **abstract**. Esto se conoce como sobrecarga de operadores.

Usa el campo de clase con metadatos `@:op()` para sobrecargar un operador:

```haxe
abstract MyAbstract(String) {
  public inline function new(s:String) {
    this = s;
  }

  @:op(A * B)
  public function repeat(rhs:Int):MyAbstract {
    var s:StringBuf = new StringBuf();
    for (i in 0...rhs)
      s.add(this);
    return new MyAbstract(s.toString());
  }
}

class Main {
  static public function main() {
    var a = new MyAbstract("foo");
    trace(a * 3); // foofoofoo
  }
}
```
