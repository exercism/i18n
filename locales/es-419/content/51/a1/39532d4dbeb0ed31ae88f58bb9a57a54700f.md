# Instrucciones

Ozan está armando una lista de reproducción para un próximo viaje por carretera. No quiere escuchar la misma canción más de una vez, pero la lista de reproducción se ha vuelto tan larga que le cuesta recordar qué canciones ya agregó.

La API del reproductor de música de Ozan solo sabe trabajar con vectores. No es posible usar bucles explícitos ni lógica de if/else. ¡Necesita tu ayuda!

## 1. Eliminar las canciones duplicadas

Implementa la función `remove_duplicates`, que recibe una lista de reproducción como _parámetro_ y _devuelve_ una nueva lista de reproducción en la que todas las canciones son únicas.

```R
> playlist <- c(
  "Court and Spark - Joni Mitchell",
  "Big Yellow Taxi - Joni Mitchell",
  "Court and Spark - Joni Mitchell"
)

> remove_duplicates(playlist)
[1] "Court and Spark - Joni Mitchell" "Big Yellow Taxi - Joni Mitchell"
```

## 2. Comprobar si una canción ya se agregó

Implementa la función `has_track`, que recibe una lista de reproducción y una canción como _parámetros_ y _devuelve_ un Boolean que indica si la lista de reproducción contiene la canción.

```R
> playlist <- c(
  "The Fashion Show - Grace Jones",
  "Dr. Funkenstein - Parliament"
)

> has_track(playlist, "Dr. Funkenstein - Parliament")
[1] TRUE

> has_track(playlist, "Walking in the Rain - Grace Jones")
[1] FALSE
```

## 3. Agregar canciones

Implementa la función `add_tracks`, que recibe una lista de reproducción y un vector de una o más canciones como _parámetros_ y _devuelve_ una nueva lista de reproducción que incluye las canciones.

```R
> playlist <- c("Selma - Bijelo Dugme")

> playlist <- add_tracks(playlist, "Atomic Dog - George Clinton")
> playlist
[1] "Selma - Bijelo Dugme"   "Atomic Dog - George Clinton"

> add_tracks(playlist, "Selma - Bijelo Dugme")
[1] "Selma - Bijelo Dugme"   "Atomic Dog - George Clinton"

> add_tracks(playlist, c("The Chain - Fleetwood Mac", "Selma - Bijelo Dugme"))
[1] "Selma - Bijelo Dugme"   "Atomic Dog - George Clinton" "The Chain - Fleetwood Mac"  

```

## 4. Borrar canciones

Implementa la función `delete_tracks`, que recibe una lista de reproducción y una o más canciones como _parámetros_ y _devuelve_ una nueva lista de reproducción que no incluye las canciones.

```R
> playlist <- c(
  "The Treasure - Fra Lippo Lippi",
  "After the Fall - Klaus Nomi"
)

> playlist <- delete_tracks(playlist, "The Treasure - Fra Lippo Lippi")
> playlist
[1] "After the Fall - Klaus Nomi"

> delete_tracks(playlist, "I Feel the Magic - Belinda Carlisle")
[1] "After the Fall - Klaus Nomi"
```

## 5. Comparar listas de reproducción

Ozan conoce a alguien nuevo y se pregunta qué tan parecidos son sus gustos musicales. 
Implementa la función `find_common_tracks`, que recibe dos listas de reproducción y devuelve una nueva lista de reproducción que contiene solo las canciones presentes en ambas.

```R
> playlist_1 <- c("Karma - Taylor Swift", "Tired - Adele")
> playlist_2 <- c("Andromeda - Weyes Blood", "Karma - Taylor Swift")
> find_common_tracks(playlist_1, playlist_2)
[1] "Karma - Taylor Swift"
````
