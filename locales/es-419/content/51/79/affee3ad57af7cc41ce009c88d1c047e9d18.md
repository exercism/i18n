# Pistas

## General

- Usa `Bitwise` (o div/rem).
- Si usas `Bitwise`, una forma fácil de ver si un bit en particular está activado es comparar
el AND binario (`&&&`) de un conjunto de bits con el patrón de bits que quieres
comprobar, y determinar si el resultado es el mismo que el patrón que estás
comprobando.
