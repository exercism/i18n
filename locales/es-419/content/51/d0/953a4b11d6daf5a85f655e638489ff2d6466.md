# Anexo de instrucciones

## Sugerencia de rendimiento

Todos los argumentos y valores devueltos están en ASCII.
Rust `String`s y `&str` son utf8, así que, aunque uno podría esperar que `"Hello".chars()` sea sencillo, en realidad tiene que comprobar cada char para ver si mide 1, 2, 3 o 4 `u8`s de largo.
Si sabemos que un `&str` es ASCII, entonces podemos llamar a `.as_bytes()` y referirnos a los datos subyacentes como un `&[u8]` (segmento de bytes).
Iterar sobre un segmento de bytes ASCII es mucho más rápido, ya que no hay puntos de código involucrados: cada byte ASCII mide un `u8`.
