# Instrucciones

Toma un array anidado y devuelve un solo array aplanado con todos los valores excepto nil/null.

El reto es escribir una función que acepte una estructura similar a un array anidado con una profundidad arbitraria y devuelva una estructura aplanada sin valores nil/null.

Por ejemplo:

argumento: [1,[2,3,null,4],[null],5]

resultado: [1,2,3,4,5]
