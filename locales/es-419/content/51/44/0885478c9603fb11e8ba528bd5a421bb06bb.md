# Acerca de

En Clojure, asignar un valor a un nombre se conoce como [_var_][vars]. Las vars de nivel superior (globales) son similares a las constantes de otros lenguajes, pero es común redefinirlas para facilitar el desarrollo dinámico.

Las vars de nivel superior se definen con [`def`][def]:

```clojure
(def fingers 10)
```

Puedes usar las funciones del núcleo para [las operaciones con números][operators] y realizar aritmética con los valores.

La macro `defn` sirve para definir una [función][functions] que recibe cero o más argumentos. Una función siempre devuelve el resultado de la última expresión de su cuerpo.

```clojure
(defn add [x y]
  (+ x y))
```

Para llamar a una función, escribes su nombre y pasas un argumento por cada parámetro de la función.

```clojure
(def five (add 2 3))
```

Las funciones y los valores en Clojure solo se pueden usar _después_ de haberlos definido. Usarlos antes de definirlos produce un error de compilación.

```clojure
;; Compile error as `add` has not yet been defined
(def seven (add 3 4))

(defn add [x y]
  (+ x y))
```

En Clojure, los espacios en blanco no tienen otro significado que el de dar formato.

Las funciones y las vars de Clojure se organizan en espacios de nombres. Un espacio de nombres agrupa funcionalidad relacionada y se define con la macro `ns`:

```clojure
(ns calculator)

(def pi 3.14)

(defn add [x y]
  (+ x y))
```

Clojure admite dos tipos de comentarios. Los comentarios de una sola línea van precedidos por `;`, y la forma `comment` se usa para evitar que se evalúe todo lo que hay entre `(comment` y `)`.
