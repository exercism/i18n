# Acerca de

Las secuencias de Factor vienen en dos variantes cuando necesitas *modificarlas*:

- **Los arrays** (`{ … }`) tienen una longitud fija. Puedes cambiar lo que está *en* cada posición con `set-nth` / `change-nth`, pero no puedes hacerlos crecer ni encogerlos.
- **Los vectores** (`V{ … }`) tienen longitud variable. `push` agrega al final, `pop` elimina y devuelve el último elemento.

```factor
USING: arrays kernel sequences ;

! Fixed-length: build a counter array of zeros, then bump one slot.
3 0 <array>            ! { 0 0 0 }
dup [ 1 + ] 1 rot change-nth
.                      ! { 0 1 0 }

! Variable-length: build a vector of names by pushing.
V{ } clone
"alice" over push
"bob" over push
dup pop drop           ! removes "bob"
.                      ! V{ "alice" }
```

| palabra         | efecto                                         |
|-----------------|------------------------------------------------|
| `<array>`       | `( n elt -- array )`: array de `n` copias de `elt` |
| `<vector>`      | `( n -- vector )`: vector vacío con capacidad `n` |
| `V{ }`          | literal de vector vacío                        |
| `set-nth`       | `( elt n seq -- )`: asigna el elemento en el índice `n` |
| `change-nth`    | `( i seq quot -- )`: aplica `quot` al elemento en `i` |
| `push`          | `( elt seq -- )`: agrega al final de un vector |
| `suffix!`       | `( seq elt -- seq )`: agrega en el lugar, devuelve el vector |
| `pop`           | `( seq -- elt )`: elimina y devuelve el último |
| `pop*`          | `( seq -- )`: elimina el último y lo descarta |
| `clone`         | `( obj -- copy )`: copia nueva e independiente |
| `new-sequence`  | `( n exemplar -- newseq )`: secuencia nueva de la misma clase que `exemplar` |
| `new-resizable` | `( n exemplar -- newseq )`: variante redimensionable nueva |

Cuando modificas una secuencia que te pasó quien llama, el cambio es visible para quien llama, porque los dos tienen el mismo objeto. Si eso no es lo que quieres, usa `clone` primero para obtener una copia independiente.
