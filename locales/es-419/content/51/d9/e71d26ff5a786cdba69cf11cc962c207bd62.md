# Instrucción

Tu tarea es resolver un puzzle binario.
Cada puzzle binario tiene exactamente _una_ solución, que se puede encontrar aplicando estas reglas:

1. Cada celda debe contener un cero o un uno.
2. No puede haber más de dos dígitos iguales adyacentes. Entonces, si dos celdas adyacentes contienen el mismo dígito, las celdas que están junto a esos dígitos deben contener el otro dígito.
3. Cada fila y cada columna deben contener la misma cantidad de ceros y unos.
4. Cada fila y cada columna son únicas.

Recibirás un puzzle sin completar como filas de ceros y unos, con marcadores de posición (`_`) para los valores desconocidos.
El objetivo es definir las reglas del puzzle binario, lo que permitirá que las pruebas deduzcan los valores de los marcadores de posición (eso no lo haces tú).
Tu implementación debe usar la [programación lógica con restricciones sobre dominios finitos (CLP(FD))](https://www.swi-prolog.org/man/clpfd.html) de Prolog, que es perfecta para este tipo de tareas.
