# Introducción

Un bucle es una forma de llamar repetidamente a una o más sentencias en un conjunto.
Cada ejecución de un conjunto de sentencias se llama una iteración.

## Bucle `while`

Un bucle `while` ejecuta un conjunto de sentencias mientras una expresión Boolean en la parte superior del bucle sea verdadera.
Cuando la expresión Boolean es falsa, el bucle deja de ejecutarse y la ejecución continúa con la siguiente línea de código después del bucle.

Si la expresión Boolean se evalúa como falsa desde el principio, el bucle `while` no se ejecutará en absoluto y la ejecución pasará a la siguiente línea de código después del bucle.

```c
int main() {
    int i = 0;
    while (i < 5) {
        printf("Number is %i\n", i++);
    }    
    return 0;
}
```

Es importante que haya una condición para terminar el bucle; de lo contrario, es un bucle infinito que bloqueará todo el progreso del código.
Si al código anterior se le quitara el `++` de `i`, sería un bucle infinito.

## Bucle `do`

Un bucle `do` evalúa su expresión Boolean en la parte inferior del bucle.
Un bucle `do` siempre se ejecutará al menos una vez, como en el siguiente ejemplo

```c
do {
    printf("Enter the Answer to the Ultimate Question of Life: ");
    scanf("%d", &answer);
} while (answer != 42); 
// Note that a semicolon is needed after the Boolean expression.
```

Con un bucle `while`, esto sería más verboso

```c
printf(""Enter the Answer to the Ultimate Question of Life: ");
scanf("%d", &answer);
while (answer != 42) {
    printf(""Enter the Answer to the Ultimate Question of Life: ");
    scanf("%d", &answer);
}
```

## Bucle `for`

A menudo, un bucle actualiza una variable y termina cuando la variable alcanza un cierto valor.
Un bucle `for` es una forma de inicializar, actualizar y evaluar una o más variables en una sola línea dentro de paréntesis.
La primera sección es para inicializar la variable, la segunda sección para evaluar la variable, y la tercera sección es para actualizar el valor de la variable.

```c
for (int i = 0; i < 5; i++) {
    printf("Number is %i\n", i);
}
```

Esto es menos verboso que el equivalente con un bucle `while`, y aun así sigue siendo legible.
