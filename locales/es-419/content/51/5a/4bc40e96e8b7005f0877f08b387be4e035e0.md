# Instrucciones

En este ejercicio vas a escribir código para imprimir gafetes con el nombre de los empleados de una fábrica.

## 1. Imprime un gafete para un empleado

Los empleados tienen un ID, un nombre y el nombre del departamento.
Las etiquetas de los gafetes de los empleados tienen el siguiente formato: `"[id] - name - DEPARTMENT"`.
Implementa el método `printBadge()` para que devuelva la etiqueta del gafete de un empleado:

```kotlin
printBadge(734, "Ernest Johnny Payne", "Strategic Communication")
// => "[734] - Ernest Johnny Payne - STRATEGIC COMMUNICATION"
```

~~~~exercism/note
Ten en cuenta que el departamento debe ir en mayúsculas en la etiqueta.
~~~~

## 2. Imprime un gafete para un empleado nuevo

Debido a una peculiaridad del sistema informático, a veces los empleados nuevos todavía no tienen un ID cuando empiezan a trabajar en la fábrica.
Como los gafetes son obligatorios, recibirán un gafete temporal sin el prefijo del ID.
Modifica el método `printBadge()` para que admita empleados nuevos que todavía no tienen un ID:

```kotlin
printBadge(null, "Jane Johnson", "Procurement")
// => "Jane Johnson - PROCUREMENT"
```

## 3. Imprime un gafete para el dueño

Incluso el dueño de la fábrica tiene que llevar un gafete en todo momento.
Sin embargo, el dueño no tiene un departamento.
En este caso, la etiqueta debe imprimir `"OWNER"` en lugar del nombre del departamento.
Modifica el método `printBadge()` para que imprima la etiqueta del dueño:

```kotlin
printBadge(254, "Charlotte Hale", null)
// => "[254] - Charlotte Hale - OWNER"
```

~~~~exercism/note
Ten en cuenta que es posible que el dueño también sea un empleado nuevo:

```kotlin
printBadge(null, "Charlotte Hale", null)
// => "Charlotte Hale - OWNER"
```
~~~~
