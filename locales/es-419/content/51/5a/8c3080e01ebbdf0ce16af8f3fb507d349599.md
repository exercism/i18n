# Introducción

El módulo `Agent` facilita una abstracción para crear [procesos y el _bucle de recibir y enviar_][exercism-processes]. De aquí en adelante, llamaremos _«procesos agente»_ a los procesos iniciados con el módulo `Agent`. Se puede elegir un _proceso agente_ para representar un estado compartido central.

Para iniciar un _proceso agente_, `Agent` proporciona la función `start/2`. La función que proporcionas al iniciar el _proceso agente_ con `start` devuelve el estado inicial del proceso:

```elixir
# Start an agent process with an initial value of an empty list
{:ok, agent_pid} = Agent.start(fn -> [] end)
```

Igual que `Map` o `List`, `Agent` proporciona muchas funciones para trabajar con _procesos agente_.

Es habitual organizar y encapsular toda la funcionalidad relacionada con `Agent` en un módulo para el dominio que estás modelando.

[exercism-processes]: https://exercism.org/tracks/elixir/concepts/processes
