# Introducción

Las charlists se crean usando el sigilo `~c`.

```elixir
~c"hello"
```

~~~~exercism/note
Ten en cuenta que en versiones anteriores de Elixir, las charlists se representan como `'hello'` con comillas simples.
~~~~

Aunque se parecen mucho a los strings, los dos tipos de datos son bastante diferentes entre sí. Una charlist es una lista de números enteros. Los números enteros representan los valores Unicode de un carácter, también conocidos como puntos de código.

```elixir
[65, 66, 67]
# => ~c"ABC"
```

Puedes anteponer un `?` a un carácter para obtener su punto de código.

```elixir
?A
# => 65

[?:, ?)]
# => ~c":)"
```

Como las charlists son listas, puedes trabajar con ellas igual que con cualquier otra lista, usando recursión y coincidencia de patrones.

```elixir
[first_letter | _] = ~c"cat"
first_letter
# => 99
```

Puedes concatenar dos listas usando `++`.

```elixir
~c"hi" ++ ~c"!"
# => ~c"hi!"
```

Cuanto más larga sea la primera lista, más lenta será la concatenación, así que evita agregar elementos repetidamente a listas de longitud arbitraria.
