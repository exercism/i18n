# Pistas

## General

- Usa el [tipo de array (enlazado)][list] integrado.
- Usa las funciones integradas del módulo [`Stream`][stream] para crear un stream.

## 1. Capturar argumentos inválidos

- Usa una [guarda][guards] para atrapar los casos en los que no se pasa un entero como argumento a `generate/1`.

## 2. Generar los casos base

- Puedes usar varias [cláusulas de función][multiple-fn-clauses] y [coincidencia de patrones][pattern-matching] para crear las funciones de los casos base.

## 3. Crear el caso generalizado

- Usa la función [`Stream.iterate/2`][stream-iterate] para generar una secuencia de números, donde cada uno se crea a partir del anterior.
- Los números iniciales son `2` y luego `1`, que puedes pasar juntos usando una tupla para formar un par `{2, 1}`.
- Asegúrate de que el siguiente número sea la suma de los dos números anteriores a él.
- Para evaluar el stream a un array, usa una función de [`Enum`][enum].
