# Introducción

## Pares

Un `Pair` no es más que dos elementos unidos entre sí.
A esos dos elementos se los llama, con mucha imaginación, `first` y `second`.

Puedes crearlos con el operador `=>` o con el constructor `Pair()`.

```julia-repl
julia> p1 = "k" => 2
"k" => 2

julia> p2 = Pair("k", 2)
"k" => 2

# Both forms of syntax give the same result
julia> p1 == p2
true

# Each component has its own separate type
julia> dump(p1)
Pair{String, Int64}
  first: String "k"
  second: Int64 2

# Get a component using dot syntax
julia> p1.first
"k"

julia> p1.second
2
```

## Diccionarios

Un `Vector` de pares es como cualquier otro array: ordenado, homogéneo en su tipo y almacenado de forma consecutiva en memoria.

```julia-repl
julia> pv = ['a' => 1, 'b' => 2, 'c' => 3]
3-element Vector{Pair{Char, Int64}}:
 'a' => 1
 'b' => 2
 'c' => 3

# Each pair is a single entry
julia> length(pv)
3
```

Un `Dict` es parecido en apariencia, pero ahora su almacenamiento está implementado de una forma que permite recuperar valores rápidamente por su clave, incluso cuando el número de entradas crece mucho.

```julia-repl
julia> pd = Dict('a' => 1, 'b' => 2, 'c' => 3)
Dict{Char, Int64} with 3 entries:
  'a' => 1
  'c' => 3
  'b' => 2

julia> pd['b']
2

# Key must exist
julia> pd['d']
ERROR: KeyError: key 'd' not found

# Generators are accepted in the constructor (and note the unordered output)
julia> Dict(x => 1 / x for x in 1:5)
Dict{Int64, Float64} with 5 entries:
  5 => 0.2
  4 => 0.25
  2 => 0.5
  3 => 0.333333
  1 => 1.0
  ```

En otros lenguajes, algo muy parecido a un `Dict` puede llamarse dictionary (Python), Hash (Ruby) o HashMap (Java).

En el caso de los pares, ya sea de forma aislada o dentro de un Vector, hay pocas restricciones sobre el tipo de cada componente.

Para ser válido dentro de un `Dict`, el `Pair` debe ser un par `key => value`, donde la `key` sea «hashable».
Lo más importante es que esto significa que la `key` debe ser _inmutable_, así que `Char`, `Int`, `String`, `Symbol` y `Tuple` sirven sin problema, pero `Vector` no está permitido.

### Modificar un Dict

Las entradas se pueden agregar, con una clave nueva, o sobrescribir, con una clave que ya existe.

```julia-repl
julia> pd
Dict{Char, Int64} with 3 entries:
  'a' => 1
  'c' => 3
  'b' => 2

# Add
julia> pd['d'] = 4
4

# Overwrite
julia> pd['a'] = 42
42

julia> pd
Dict{Char, Int64} with 4 entries:
  'a' => 42
  'c' => 3
  'd' => 4
  'b' => 2
```

Para eliminar una entrada, usa la función `delete!()`, que modificará el Dict si la clave existe y, si no, no hará nada en silencio.

```julia-repl
julia> delete!(pd, 'd')
Dict{Char, Int64} with 3 entries:
  'a' => 42
  'c' => 3
  'b' => 2
```

### Comprobar si existe una clave o un valor

Hay distintas formas de hacerlo.
Para comprobar una clave existe la función `haskey()`:

```julia-repl
julia> haskey(pd, 'b')
true
```

Como alternativa, puedes buscar entre las claves o entre los valores:

```julia-repl
julia> 'b' in keys(pd)
true

julia> 43 in values(pd)
false

julia> 42 ∈ values(pd)
true
```
