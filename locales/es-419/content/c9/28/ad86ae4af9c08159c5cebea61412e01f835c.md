## Importing

Un módulo normalmente se carga con la palabra clave `use`.
Esto carga el módulo y además llama a su método `import`, con lo que se importan todos los símbolos exportados.

Los símbolos que están en el array `@EXPORT` del paquete se importan por defecto.
Los símbolos que están en el array `@EXPORT_OK` del paquete deben importarse de forma explícita.

Antes de Perl `v5.37`, un módulo tenía que terminar en un valor verdadero (normalmente `1`) para indicar que se había cargado correctamente.
Esto ya no es necesario cuando usas la característica [`module_true`][module_true].

## Exporting

Para que un símbolo se pueda importar, primero hay que exportarlo.
El módulo [Exporter][Exporter] viene incluido con Perl y es una de las opciones más convenientes para exportar.

Definir el módulo:
```perl
package Foo;

use Exporter ('import');
our @EXPORT_OK = ('bar');

sub bar { ... }
```

Usar el módulo:
```perl
use Foo ('bar');

bar();
```

## Pragma

Un pragma es un módulo que influye en algún aspecto del comportamiento de Perl.

Los pragmas [`strict`][strict] y [`warnings`][warnings] se recomiendan habitualmente, para restringir construcciones inseguras y señalar posibles problemas, respectivamente.
El pragma `strict` se activa junto con `use v5.12` o superior.
El pragma `warnings` se activa junto con `use v5.35` o superior.

El pragma [`feature`][feature] te permite activar características nuevas y experimentales de Perl.
Cuando le das una versión específica de Perl al `use`, se activa el conjunto de características de esa versión.

## Core Modules

Junto con [Exporter][Exporter], Perl tiene una gran variedad de [módulos del núcleo][perl-core-modules] disponibles para usar.
Algunos ejemplos útiles para los ejercicios que puedes encontrar aquí incluyen [List::Util][List::Util], [Time::Piece][Time::Piece] y [Math::BigRat][Math::BigRat].

## CPAN

Además de los módulos del núcleo, [CPAN][metacpan] tiene miles de módulos adicionales creados por la comunidad de Perl disponibles para instalar.
El track de Perl usa un [cpanfile][test-runner-cpanfile] para instalar una selección de módulos que se pueden usar con el test runner de Perl de Exercism.
