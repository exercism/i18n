# Instalación

Sigue las instrucciones para tu sistema en la página de instalación de [golang.org](http://golang.org/doc/install).

## Versión de Go

Este track usa Go 1.26.

Podrías usar una versión anterior de Go si modificas el archivo `go.mod` de cada ejercicio y cambias la línea `go 1.26`.
Sin embargo, los tests usan funcionalidades introducidas en Go 1.22 y no funcionarán con una versión anterior sin modificarlos.
