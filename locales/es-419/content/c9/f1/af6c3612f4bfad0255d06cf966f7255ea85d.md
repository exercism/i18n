# ¡Lanzamiento!

Para activar el track, simplemente cambia el interruptor `active` de `config.json` a `true`.
Al cabo de un momento, el track aparecerá en el [sitio web](https://exercism.org/tracks).

A partir de este momento, cualquier cambio que hagas en tu track se sincronizará automáticamente con el [sitio web](https://exercism.org/tracks).
