# Anexo de instrucciones

## Registros

| Registro | Uso      | Tipo       | Descripción                                      |
| -------- | -------- | ---------- | ------------------------------------------------ |
| `$a0`    | entrada  | entero     | año que hay que verificar                        |
| `$v0`    | salida   | boolean    | la entrada es un año bisiesto (`0` = `false`, `1` = `true`) |
| `$t0-9`  | temporal | cualquiera | se usa para almacenamiento temporal              |
