# Introducción

Un `vector` en R es una colección de valores del mismo `type`: `numeric`, `character`, etc. Si se le dan entradas mixtas, R las convertirá silenciosamente a un tipo común, normalmente `character`, lo que puede producir resultados inesperados.

```R
v <- c(2, 5.4, "txt")
v
#> [1] "2"   "5.4" "txt"
typeof(v)
#> [1] "character"
```

## Crear vectores

Si ya tienes todos los valores, usa `c()` (abreviatura de «concatenar» o «combinar»):

```R
x <- 10
v <- c(4, 7, x)
```

La función `c()` es muy flexible, y sus entradas pueden incluir otros vectores y rangos.
`c()` acepta cualquier cantidad y variedad de entradas y las aplana en un solo vector.

## Rangos, secuencias y repeticiones

Para un rango de valores consecutivos (creciente o decreciente) puedes usar la notación `:`

```R
v <- 1:5 # equivalent to c(1, 2, 3, 4, 5)
w <- 10:7 # c(10, 9, 8, 7)
```

La función `seq()` ofrece un control más preciso:

```R
# specify step size
seq(2, 11, by = 3) # c(2, 5, 8, 11)

# specify number of values, evenly-spaced
seq(2.5, 4, length.out = 5) # c(2.500, 2.875, 3.250, 3.625, 4.000) 
```

Algunos rangos están predefinidos como constantes integradas:

```R
letters  # LETTERS is the UPPERCASE equivalent
#> [1] "a" "b" "c" "d" "e" "f" "g" "h" "i" "j" "k" "l" "m" "n" "o" "p" "q" "r" "s" "t" "u" "v" "w" "x" "y" "z"

month.name
#> [1] "January"   "February"  "March"     "April"     "May"       "June"      "July"      "August"   
#> [9] "September" "October"   "November"  "December" 

month.abb
#> [1] "Jan" "Feb" "Mar" "Apr" "May" "Jun" "Jul" "Aug" "Sep" "Oct" "Nov" "Dec"
```

## Aritmética

Las operaciones se aplican automáticamente elemento por elemento a lo largo del vector. 
Los bucles, la comprensión de listas y la recursión, comunes en otros lenguajes, no son necesarios y (*por razones de rendimiento*) por lo general conviene evitarlos.

```R
2 + 1:3 # c(3, 4, 5)
2 * 1:3 # c(2, 4, 6)
12 / 1:3 # c(12  6  4)
2 ^ (1:3) # c(2, 4, 8) : exponentiation, precedence order here needs ()
```

Los pares de vectores también funcionan elemento por elemento:

```R
v <- 1:3
w <- 5:7

v + w
#> [1]  6  8 10

v * w
#> [1]  5 12 21

v ^ w
#> [1]    1   64 2187
```

## Acceder a los elementos de un vector

Como en muchos lenguajes, podemos usar el índice entre corchetes:

```R
v <- 4:7
v[2]
#> [1] 5
v[2:4]
#> [1] 5 6 7
```

Pero cuidado: ***R usa indexación basada en 1 de forma predeterminada***. 

Esto es habitual en los lenguajes científicos (Fortran, Matlab, Julia), pero es distinto de la indexación basada en cero de C y de sus muchos sucesores.

Se pueden usar rangos, como en el ejemplo anterior, pero también en la muy flexible función `c()`:

```R
v <- c(4, 7, 10)
w <- c(2, v[2:3], 11) # c(2, 7, 10, 11)
```

Los `vectors` (como casi todo en R) se pueden tratar como mutables, usando una sintaxis flexible similar para escribir en uno o varios elementos:

```R
v <- 1:10
v[2] <- 42
v[4:6] <- c(11, 12, 13)
v
#> [1]  1 42  3 11 12 13  7  8  9 10
```

## Índices negativos

Quienes programan y conocen otros lenguajes podrían pensar que `v[-1]` es una forma de acceder al último elemento de un vector.
*¡Incorrecto!*
Para eso se usa `tail(v, n=1)`.

En realidad, los índices negativos son una forma de ***eliminar*** un elemento, devolviendo un vector más corto:

```R
v <- c(2, 4, 6)
v[-2]
#> [1] 2 6  # second element gone
```

## Condicionales con vectores

Aplicar comparaciones a un vector devolverá un vector de booleanos de la misma longitud.
Esto puede ser muy conveniente dentro de funciones como `all()` y `any()`:

```R
v <- c(4, 7, 10)
v >= 6
#> [1] FALSE  TRUE  TRUE
all(v > 6)
#> [1] FALSE    # not all elements match this condition
any(v > 6)
#> [1] TRUE     # at least one element matches
```

Para expresiones lógicas más complicadas, es importante usar los operadores `&` y `|`, que funcionan con vectores.
Los de doble carácter `&&` y `||` están pensados solo para comparar valores individuales.

```R
v %% 2 == 0 & v > 5
#> [1] FALSE FALSE  TRUE
```
