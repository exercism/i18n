# Instrucciones

El ejercicio introductorio clásico.
Solo di «Hello, World!».

[«Hello, World!»][hello-world] es el tradicional primer programa para quienes empiezan a programar en un lenguaje o un entorno nuevos.

Los objetivos son simples:

- Modifica el código que te proporcionamos para que produzca el string «Hello, World!».
- Ejecuta la suite de pruebas y asegúrate de que tenga éxito.
- Envía tu solución y verifícala en el sitio web.

Si todo sale bien, ya podrás obtener tu primer ejercicio real.

[hello-world]: https://en.wikipedia.org/wiki/%22Hello,_world!%22_program
