# Transformación de JSON de combustible

## Planteamiento del problema

Cada empleado de ABC Corp recibe una asignación ilimitada de combustible. Se pide a los empleados que envíen un registro cada vez que llenan el tanque de sus vehículos. Estos registros se agregan al mismo archivo JSON y se procesan al final del mes.

Como miembro del equipo de operaciones digitales, tu tarea es leer este archivo JSON y escribir los resultados en otro archivo JSON. El archivo de salida debe contener una entrada por cada empleado con los siguientes datos:

- Número de empleado
- Cantidad de cargas de combustible
- Costo total del combustible
- Total de galones
- Total de millas acumuladas

Recibes dos argumentos de tipo `string`.

1. Ruta del archivo JSON de entrada.
1. Ruta del archivo JSON de salida.

El archivo JSON de entrada contiene un array de objetos JSON. Cada objeto JSON tiene la siguiente forma.


```json
{
    "type": "array",
    "items": {
        "type": "object",
        "properties": {
            "employeeId": {
                "type": "integer"
            },
            "odometerReading": {
                "type": "integer"
            },
            "gallons": {
                "type": "number"
            },
            "gasPrice": {
                "type": "number"
            }
        },
        "required": [
            "employeeId",
            "odometerReading",
            "gallons",
            "gasPrice"
        ]
    }
}
```

```ballerina
// Ballerina record type definition
type FillUpEntry record {|
    int employeeId;
    int odometerReading;
    decimal gallons;
    decimal gasPrice;
|};
```

Tu tarea es transformar la entrada JSON al siguiente formato JSON y escribir el contenido en la ruta indicada. El archivo de salida debe contener una entrada por cada empleado, ordenadas de forma ascendente según el `employeeId`.

```json
{
    "type": "array",
    "items": {
        "type": "object",
        "properties": {
            "employeeId": {
                "type": "integer"
            },
            "gasFillUpCount": {
                "type": "integer"
            },
            "totalFuelCost": {
                "type": "number"
            },
            "totalGallons": {
                "type": "number"
            },
            "totalMilesAccrued": {
                "type": "integer"
            }
        },
        "required": [
            "employeeId",
            "gasFillUpCount",
            "totalFuelCost",
            "totalGallons",
            "totalMilesAccrued"
        ]
    }
 }
```

```ballerina
// Ballerina record type definition
type EmployeeFillUpSummary record {|
    int employeeId;
    int gasFillUpCount;
    decimal totalFuelCost;
    decimal totalGallons;
    int totalMilesAccrued;
|};
```

## Restricciones

- Cantidad de registros de carga `n` en el archivo JSON de entrada: 0 <= n <= 1000
- Cantidad de empleados en la empresa: 97
- El precio de la gasolina es por galón
- No hay registros de carga faltantes

## Sugerencias

- Usa el [módulo `ballerina/io`](https://lib.ballerina.io/ballerina/io/latest) para leer y escribir archivos JSON.
- Convierte los valores JSON a tipos específicos de la aplicación para trabajar con los datos con seguridad de tipos. Consulta el [ejemplo de conversión a un tipo definido por el usuario](https://ballerina.io/learn/by-example/convert-from-json-to-user-defined-type) en Ballerina By Examples (BBE) para obtener más información.

```ballerina
   json jsonPayload = {id: "2", title: "Jeru", artist: "Gerry Mulligan", price: 17.99};

   // Using cloneWithType  
   Album album1 = check jsonPayload.cloneWithType();
   io:println(album1);
 
   // Using fromJsonWithType
   Album album2 = check jsonPayload.fromJsonWithType();
   io:println(album2);
```

- [La desestructuración de registros](https://ballerina.io/learn/by-example/destructure-records-using-query) puede ser útil para reducir la verbosidad del código.

```ballerina
   Album {id, title, artist, price} = album1;
   io:println(id);
   io:println(title);
```

- Usa funciones con cuerpo de expresión para las funciones que tienen una sola expresión. Por ejemplo, las funciones que solo tienen la sentencia `return`.

```ballerina
   function cfr(int deaths, int cases) returns decimal => <decimal>deaths / <decimal>cases * 100;
```
