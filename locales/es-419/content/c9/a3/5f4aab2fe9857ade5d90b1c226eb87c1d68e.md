# Pistas

## 1. Comprueba si la acción «ataque rápido» es posible

- El operador lógico NOT (`!`) se puede colocar antes de una expresión para negar su valor.
- Echa un vistazo a [este artículo de MDN](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Logical_Operators#Logical_NOT_!) sobre los operadores lógicos.

## 2. Comprueba si la acción «espía» es posible

- Las expresiones lógicas se evalúan de izquierda a derecha y se comprueban los posibles «cortocircuitos».
- Para entender bien el mecanismo de izquierda a derecha, ¡echa un vistazo a [este artículo](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Operator_Precedence)!

## 3. Comprueba si la acción «hacer señales al prisionero» es posible

- Los operadores lógicos en orden de precedencia (de mayor a menor): `!`, `&&`, `||`.
- Echa un vistazo a [este artículo de MDN](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Operator_Precedence#Precedence_And_Associativity) sobre la precedencia de operadores.

## 4. Comprueba si la acción «liberar al prisionero» es posible

- `()` es el operador con mayor precedencia. Úsalo para agrupar expresiones lógicas.
