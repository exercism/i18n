# Tests

## Ejecutar los tests

Para ejecutar los tests, ejecuta el siguiente comando:

```bash
dotnet test
```

Para ejecutar los tests automáticamente cada vez que se modifica un archivo fuente, ejecuta el siguiente comando:

```bash
dotnet watch test
```

## Resolver el ejercicio

Resolver un ejercicio significa hacer que todos sus tests pasen. De forma predeterminada, solo se ejecuta un test (el primero) cuando ejecutas los tests. Esto es intencional, ya que te permite concentrarte solo en hacer que ese test pase. Una vez que pase, puedes habilitar el siguiente test quitando `Skip = "Remove this Skip property to run this test"` del atributo `[Fact]` o `[Theory]` del test. Cuando hayas habilitado todos los tests y tu implementación haga que todos pasen, ¡habrás resuelto el ejercicio!

Para ayudarte a empezar, cada ejercicio incluye un archivo de implementación inicial. Puedes usar este archivo como punto de partida para construir tu solución. No dudes en eliminar o modificar este archivo si crees que es lo correcto.

## Usar paquetes

Deberías poder resolver la mayoría de los ejercicios sin usar paquetes externos. Sin embargo, en los ejercicios en los que sí quieras usar un paquete externo, puedes agregarlo a tu proyecto ejecutando el siguiente comando:

```bash
dotnet add package [package-name]
```
