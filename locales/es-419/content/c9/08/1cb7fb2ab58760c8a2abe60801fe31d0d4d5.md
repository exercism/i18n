# Introducción

El bucle `for` es una de las sentencias más usadas para ejecutar repetidamente cierta lógica.
En JavaScript consta de la palabra clave `for`, un _encabezado_ entre paréntesis y un bloque de código que contiene el _cuerpo_ del bucle entre llaves.

```javascript
for (initialization; condition; step) {
  // code that is executed repeatedly as long as the condition is true
}
```

La inicialización normalmente prepara una variable contadora, la condición verifica si el bucle debe continuar o detenerse, y el paso incrementa el contador al final de cada repetición.
Las distintas partes del encabezado se separan con puntos y coma.

```javascript
const list = ['a', 'b', 'c'];
for (let i = 0; i < list.length; i++) {
  // code that should be executed for each item list[i]
}
```
