# Listas

`LIST{T}` es una colección ordenada que puede crecer, respaldada por un array que se reemplaza por uno más grande cuando se llena.

```sather
   notes ::= #LIST{STR};
   notes.append("muddy boots");
   notes[0]                     -- "muddy boots"
   notes[0] := "clean boots";
   notes.size
   notes.is_empty
   notes.has("clean boots")
   notes.remove_index(0);
```

## ¿Array o lista?

| | `ARRAY{T}` | `LIST{T}` |
| --- | --- | --- |
| tamaño | fijo al crearse | cambia |
| append | no | sí |
| remove | no | sí |
| indexación | `a[i]` | `l[i]` |
| sobrecarga | ninguna | un tamaño y espacio de sobra |

Usa un `ARRAY` cuando el tamaño se conoce y está fijo: una fila de bailarines, una semana de conteos. Usa una `LIST` cuando las cosas llegan o se van.

## En el lugar, no funcional

`append`, `remove_index` y `[i] :=` cambian la lista misma. No hace falta reasignar nada, y una lista que le pasas a una rutina no está a salvo de eso.

Eso es lo contrario de `FMAP` y `FSET`, y vale la pena tener claro cuál tienes en las manos. La regla general: una `F` al principio del nombre significa funcional, y todo lo demás cambia en el lugar.

Para entregar una lista que nada pueda echar a perder, da una copia:

```sather
   return notes.copy;
```

## El costo de agregar al final

Agregar al final es barato en promedio. Cuando el array de respaldo se llena, se toma uno nuevo del doble de tamaño y se copia todo, así que la mayoría de las veces agregar casi no cuesta nada y de vez en cuando cuesta una copia. A lo largo de muchas operaciones de agregado, eso da un costo constante en promedio, y por eso se duplica el tamaño en lugar de crecer de a uno cada vez.

`remove_index` no es barato: todo lo que está después de la posición eliminada se corre un lugar hacia arriba. Eliminar repetidamente desde el inicio de una lista larga es lento de una forma que es fácil no notar.

## Rutinas útiles

| Llamada | Hace |
| --- | --- |
| `l.append(x)` | agrega al final |
| `l.insert_before(i, x)` | agrega en una posición |
| `l.remove_index(i)` | saca una posición |
| `l.has(x)` | ¿está ahí dentro? |
| `l.copy` | una copia independiente |
| `l.str` | el contenido, entre llaves |
| `l.elt!`, `l.ind!` | recorre los valores, o las posiciones |
