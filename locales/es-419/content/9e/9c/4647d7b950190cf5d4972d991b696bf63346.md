# Instrucciones

Jen trabaja en la sala de clasificación de una fábrica grande.
La sala de clasificación necesita procesar todo lo que llega categorizándolo con una etiqueta.
Jen se encarga de las cosas que se clasificaron previamente como números y necesita un programa que la ayude con la clasificación.

La mayoría de los valores primitivos debería recibir etiquetas sencillas.
Para los números, quiere strings que digan `"This is the number 2.0"` (si el número era 2).
Jen quiere el mismo resultado para enteros y números de punto flotante.

Hay unas cuantas interfaces `Box` que hay que desenvolver para obtener su contenido.
Para un `NumberBox`, quiere strings que digan `"This is a box containing the number 3.0"` (si el método `Number()` devuelve 3).
Para un `FancyNumberBox`, quiere strings que digan `"This is a fancy box containing the number 4.0"`, pero solo si el tipo es un `FancyNumber`.

Cualquier cosa inesperada debe decir `"Return to sender"` para que Jen pueda devolverlas de donde vinieron.

## 1. Describe números simples

Jen quiere que los números devuelvan strings como `"This is the number 2.0"` (incluyendo un dígito después del punto decimal):

```go
fmt.Println(DescribeNumber(-12.345))
// Output: This is the number -12.3
```

## 2. Describe una caja de números

Jen quiere que las cajas de números devuelvan strings como `"This is a box containing the number 2.0"` (una vez más, incluyendo un dígito después del punto decimal):

```go
fmt.Println(DescribeNumberBox(numberBoxContaining{12}))
// Output: This is a box containing the number 12.0
```

## 3. Implementa un método que extraiga el número de una caja de números elegante

Jen necesita una función auxiliar para extraer el número de un `FancyNumberBox`.
Si el `FancyNumberBox` es un `FancyNumber`, extrae su valor y conviértelo de `string` a `int`.
Cualquier otro tipo de `FancyNumberBox` debe devolver 0.

```go
fmt.Println(ExtractFancyNumber(FancyNumber{"10"}))
// Output: 10
fmt.Println(ExtractFancyNumber(AnotherFancyNumber{"4"}))
// Output: 0
```

## 4. Describe una caja de números elegante

Si el `FancyNumberBox` es un `FancyNumber`, Jen quiere strings que digan `"This is a fancy box containing the number 4.0"`.
Cualquier otro tipo de `FancyNumberBox` debe decir `"This is a fancy box containing the number 0.0"`.

```go
fmt.Println(DescribeFancyNumberBox(FancyNumber{"10"}))
// Output: This is a fancy box containing the number 10.0
fmt.Println(DescribeFancyNumberBox(AnotherFancyNumber{"4"}))
// Output: This is a fancy box containing the number 0.0
```

NOTA: ¡deberíamos usar la función `ExtractFancyNumber`!

## 5. Implementa `DescribeAnything`, que usa todas ellas

Esta es la función principal que Jen necesita y que recibe cualquier argumento.
`DescribeAnything` debe delegar a las otras funciones según el tipo del valor que se le pase.
Más específicamente:

- Tanto `int` como `float64` deben delegar a `DescribeNumber`
- `NumberBox` debe delegar a `DescribeNumberBox`
- `FancyNumberBox` debe delegar a `DescribeFancyNumberBox`
- cualquier otra cosa debe dar como resultado `"Return to sender"`

```go
fmt.Println(DescribeAnything(numberBoxContaining{12.345}))
// Output: This is a box containing the number 12.3
fmt.Println(DescribeAnything("some string"))
// Output: Return to sender
```
