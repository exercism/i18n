# Tests

## Ejecutar los tests de forma interactiva

Inicia tu implementación de Common Lisp en el directorio del ejercicio en el que estás trabajando (o, si ya tienes una implementación de Common Lisp en ejecución, cambia su directorio actual a ese directorio).
Si usas roswell, hazlo con `ros run`.

(Todos los ejemplos de aquí suponen un ejercicio llamado `exercise-name`; ajústalos según sea necesario.)

Carga el archivo de test en tu implementación de Lisp en ejecución, por ejemplo, `(load "exercise-name-test")`. 
(Esto también cargará el archivo de solución por ti.)
Una vez que el archivo de test esté cargado, puedes ejecutar los tests evaluando `(exercise-name-test:run-tests)` en el REPL.

A medida que hagas cambios en la solución que estás escribiendo, usa la funcionalidad de tu editor para cargar los cambios o evalúa `(load "exercise-name")` para cargar tu archivo de solución.

Recuerda evaluar `(exercise-name-test:run-tests)` para volver a ejecutar los tests después de cargar tu solución actualizada.

## Ejecutar los tests desde la línea de comandos

Puedes lanzar los tests con esta invocación de línea de comandos (de nuevo, reemplaza «exercise» con el nombre correspondiente en dos lugares)

```sh
ros run --load exercise-test.lisp --eval '(uiop:quit (if (exercise-test:run-tests) 0 1))'
```

Ese comando es bastante engorroso.
Un colaborador escribió algunas notas sobre [cómo hacer que sea más fácil de invocar](https://glennj.github.io/exercism/cli).
