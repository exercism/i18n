# Instrucciones

A los alienígenas de Lisp les gusta celebrar aniversarios.
Para ellos, una fecha de aniversario importante es el Gigasecond.
Es decir: 1,000,000,000 de segundos desde el evento.

## 1. Calcula la fecha del aniversario de Gigasecond

Escribe una función `from` que reciba 6 parámetros: `year`, `month`, `day`, `hour`, `min`, `sec`, y calcule la fecha y la hora del aniversario de Gigasecond.
Esta función debe devolver la fecha como una lista con el mismo orden y el mismo significado que los parámetros que recibe.

```
(from 2000 1 1 0 0 0) ; => (2031 9 9 1 46 40)
```
