# Apéndice de instrucciones

## Instrucciones específicas de Odin

Odin admite argumentos predeterminados.
Los argumentos predeterminados son una funcionalidad muy útil que permite llamar a un procedimiento con distintos conjuntos de parámetros para casos de uso en los que necesitas API relacionadas pero diferentes.

Sin argumentos predeterminados, podrías terminar con una explosión en la cantidad de procedimientos que tu API necesita.
Los lenguajes que no admiten argumentos predeterminados, como Java, recurren a la sobrecarga de métodos para lograr el mismo efecto (con más código) o tienen que ofrecer procedimientos con, potencialmente, un gran conjunto de argumentos.

Veamos el ejemplo de un procedimiento `greeting` en el que queremos poder especificar el idioma, si el nombre va en mayúsculas y si debemos incluir un signo de exclamación al final del saludo.
Después de algunos análisis, descubrimos que el grupo más grande de usuarios especifica inglés como idioma, no escribe el nombre en mayúsculas y no quiere un signo de exclamación al final; el segundo grupo más grande agrega un signo de exclamación al final del saludo.

Podríamos crear un único procedimiento con todos los argumentos:

```odin
greeting :: proc(name: string, language: Language, do_uppercase: bool, add_exclamation: bool) {
	...
}
```

Esto obligaría a todos los usuarios a leer la documentación de todos los argumentos y a llenarlos siempre.

Sin argumentos predeterminados, también podríamos definir varios procedimientos con distintos conjuntos de parámetros:

```odin
greeting_common :: proc(name: string) {...}

greeting_with_exclamation :: proc(name: string) {...}

greeting_general :: proc(name: string, language: Language, do_uppercase: bool, add_exclamation: bool) {...}

// Odin supports overloading but it has to be explicitly defined
greeting :: proc {
	greeting_common,
	greeting_with_exclamation,
	greeting_general,
}
```

Si tu lenguaje admite argumentos predeterminados, como lo hace Odin, puedes simplemente dar valores predeterminados razonables a los argumentos menos usados.
Quien llama puede omitir los argumentos predeterminados, con lo que el procedimiento usa los valores predeterminados provistos, o sobrescribirlos.

```odin
greeting :: proc(name: string, language: Language = Language.English, do_uppercase : bool = false, add_exclamation: bool = false) {...}

// Note: because Odin supports type inference, we can simplify the interface.
greeting :: proc(name: string, language:= Language.English, do_uppercase := false, add_exclamation:= false) {...}
```

Se puede llamar al procedimiento con todos los argumentos predeterminados:

```odin
greeting("John Doe")
```

Los argumentos importantes para quien llama se pueden sobrescribir:

```odin
greeting("John Doe", Language.Spanish)
```

Si los argumentos que necesitas están en orden posicional, como en el ejemplo anterior, no hace falta nombrarlos, pero si necesitas omitir algunos, entonces tienes que nombrar los argumentos a partir del primero que omitas.

```odin
greeting("John Doe", add_exclamation=true)
```

## Gestión de memoria

En este ejercicio vas a implementar un procedimiento que debe asignar memoria para el string que devuelve. Liberar ese string es responsabilidad de quien llama al procedimiento.

```odin
// The procedure will be called like that:
str := two_fer("Alice")
// ...
// and eventually the caller will delete the string
delete(str)
```
