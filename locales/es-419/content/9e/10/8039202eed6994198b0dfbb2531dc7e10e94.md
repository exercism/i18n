# Introducción

Además de `cond`, Elixir también proporciona la macro [`if/2`][getting-started-if], que es útil cuando necesitas comprobar una sola condición.

[`if/2`][kernel-if] acepta una condición y dos opciones. Devuelve la primera opción si la condición es _truthy_, y la segunda opción si la condición es _falsy_.

```elixir
age = 15

if age >= 16 do
  "You are allowed to drink beer in Germany."
else
  "No beer for you!"
end

# => "No beer for you!"
```

También es posible escribir una expresión `if` en una sola línea. Fíjate en la coma que va después de la condición.

```elixir
if age > 16, do: "beer", else: "no beer"
```

Esta sintaxis es útil para expresiones muy cortas, pero es mejor evitarla si la expresión no cabe en una sola línea.

## _Truthy_ y _falsy_

En Elixir, todos los tipos de datos se evalúan como un valor _truthy_ o _falsy_ cuando aparecen en un contexto booleano (como una expresión `if`). Todos los datos se consideran _truthy_ **excepto** `false` y `nil`. En particular, las cadenas vacías, el entero `0` y las listas vacías se consideran _truthy_ en Elixir.
