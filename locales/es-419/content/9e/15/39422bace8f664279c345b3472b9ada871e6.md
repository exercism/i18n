## Boolean

Raku tiene los literales Boolean `True` y `False`.
En contexto Boolean, cualquier valor indefinido se considera `False`.
Además de `Bool::False` en sí mismo, los valores definidos que se consideran `False` incluyen `0`, `NaN`, `()` (lista vacía), `""` (cadena vacía) y objetos del tipo `Failure`.

El operador [prefijo `?`][&prefix:<?>] fuerza el contexto Boolean sobre un objeto.
Su comportamiento es el mismo que llamar al método [`Bool`][routine/Bool] sobre ese objeto.
El operador [prefijo `!`][&prefix:<!>] da el inverso del prefijo `?`.

## Operadores infijos Boolean

### Smartmatch

El operador [infijo `~~`][&infix:<~~>], también conocido como smartmatch, es una herramienta de uso común en Raku.
Su comportamiento depende del objeto que se da al lado derecho del operador, ya que es un atajo para el método [`ACCEPTS`][routine/ACCEPTS] de ese objeto.
El valor del lado izquierdo se pasa como argumento a `ACCEPTS`.
El resultado es un valor Boolean.

### AND/OR lógicos

Raku tiene los operadores [`&&`][&infix:<&&>]/[`and`][&infix:<and>], [`||`][&infix:<||>]/[`or`][&infix:<or>], [`//`][&infix:<//>]/[`orelse`][&infix:<orelse>] y [`^^`][&infix:<^^>]/[`xor`][&infix:<xor>] para la lógica Boolean (de precedencia alta y baja, respectivamente).
Se pueden encadenar.

```raku
1 xor 1 xor 1;
# Nil in Raku, 1 in Perl (because the latter makes the first pair false).
```

### Ternario

Raku tiene un operador ternario/condicional [infijo `?? !!`][infix-??-!!], que se escribe de esta forma: `$condition ?? $true !! $false`.

## Flujo de control

### if/elsif/else

Una [sentencia `if`][control-if] se usa para ejecutar un bloque de código de forma condicional.
Para crear una sentencia `if`, a la palabra clave `if` le sigue una [expresión][statements-and-expressions] y después un [bloque][control-block].

La expresión se evalúa en [contexto Boolean][contexts-boolean], y el bloque se ejecuta si la expresión se evalúa como `True`.

Una sentencia `if` se puede extender con las palabras clave [`elsif` y `else`][control-else/elsif], escritas de la misma forma que `if`. Un bloque `else` se ejecuta si todas las expresiones anteriores se evalúan como `False`, y un bloque `elsif` se ejecuta de la misma forma si su propia expresión se evalúa como `True`.

Como alternativa, `if` se puede usar en la forma de modificador de sentencia:

```raku
say 'success' if True;
```

La forma de modificador de sentencia no se puede usar con `elsif` ni con `else`.

### given/when/default

La [sentencia `given`][control-given] es la palabra clave topicalizadora de Raku, de forma similar a como `switch` topicaliza en lenguajes como C.
Las palabras clave para los casos individuales son [`when` y `default`][control-default-and-when].

### for/while/loop

Una [sentencia `for`][control-for] itera sobre una lista dada y ejecuta un bloque por cada elemento presente en esa lista.

Una [sentencia `while`][control-while] ejecuta un bloque repetidamente mientras su expresión dada se evalúe como `True`.

Una [sentencia `loop`][control-loop] se puede escribir de dos maneras.
Si solo se le da un bloque, ejecuta ese bloque repetidamente hasta que algo interrumpa el bucle de forma explícita.
También se puede escribir como un bucle `for` al estilo de C, con un inicializador, una condición y un incrementador entre paréntesis antes del bloque.

```raku
loop (my $i = 0; $i < 10; $i++) {
    say $i;
}
```
