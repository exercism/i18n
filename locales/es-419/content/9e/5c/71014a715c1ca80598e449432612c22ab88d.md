# Hints

## General  

- [The Cairo Book: ByteArrays][book-bytearrays]  
- [Starknet By Example: Strings & ByteArrays][sbe-strings]  

### 1. Formatea un cántico mágico  

- Usa la macro `format!` para combinar varios argumentos `ByteArray` en un solo string.  
- Separa los cánticos con un delimitador como `"-"` para que coincida con la salida esperada.  
- Asegúrate de devolver la salida como un `ByteArray`.  

### 2. Implementa el trait `Display` para `EchoStone`  

- El trait `Display` te permite definir cómo debe mostrarse el `EchoStone` cuando se imprime con `{}`.  
- Usa la macro `write!` dentro de la función `fmt` para dar formato al string de salida.  
- Incluye los campos `power` y `duration` en un formato claro y conciso, por ejemplo, `EchoStone [power: X, duration: Y]`.  

### 3. Implementa el trait `Debug` para `EchoStone`  

- El trait `Debug` se usa para depurar, y permite una salida más detallada o estructurada cuando se imprime con `{:?}`.  
- Sigue un formato de depuración claro, como `Debugging EchoStone: { power: X, duration: Y }`.  
- Usa la macro `write!` para crear la salida de depuración.
