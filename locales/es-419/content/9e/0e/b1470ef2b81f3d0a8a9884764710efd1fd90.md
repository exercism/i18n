# Acerca de

Los [rangos][range] representan una secuencia de uno o varios números enteros consecutivos. Estos:

- Se crean con el [operador `..`][range-operator] y pueden ser tanto ascendentes como descendentes.
- Su paso predeterminado es `1`, pero se puede modificar con el [operador `..//`][range-operator-with-step] (desde Elixir 1.12).
- Incluyen el primer y el último valor.
- Implementan el [_protocolo Enumerable_][enumerable].
- Se representan internamente como un struct, pero se les puede aplicar coincidencia de patrones con `..`.
- Se pueden usar con enteros escritos en notación binaria, octal, hexadecimal y de punto de código.
- Se pueden convertir en listas con funciones como [`Enum.to_list/1`][enum-to-list] o [`Enum.map/2`][enum-map].

```elixir
Enum.to_list(9..1)
# => [9, 8, 7, 6, 5, 4, 3, 2, 1]

Enum.map(?A..?F, &<<&1>>)
["A", "B", "C", "D", "E", "F"]
```
