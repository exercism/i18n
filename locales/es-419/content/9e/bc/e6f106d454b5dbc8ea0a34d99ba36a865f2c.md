# Instrucciones

En este ejercicio trabajas en una pizzería que hace entregas a domicilio.

Ofreces tres tipos de pizza:

- Margherita: \$7
- Caprese: \$9
- Formaggio: \$10

Los clientes también pueden elegir dos opciones adicionales por un pequeño cargo extra:

1. Salsa extra: \$1
1. Ingredientes extra: \$2

Cuando los clientes hacen un pedido, se agrega un cargo adicional si solo piden una o dos pizzas:

- 1 pizza: \$3
- 2 pizzas: \$2

Tienes tres tareas, y cada una trabaja con pizzas y su precio.

## 1. Define los tipos de pizza y las opciones

Define la unión discriminada `Pizza` para representar los tipos de pizza y las dos opciones adicionales que se pueden agregar a una pizza:

- `Margherita`
- `Caprese`
- `Formaggio`
- `ExtraSauce`
- `ExtraToppings`

## 2. Calcula el precio de la pizza

Implementa la función `pizzaPrice` para calcular el precio de una pizza:

```fsharp
pizzaPrice Caprese
// => 9
```

## 3. Calcula el precio de un pedido

Implementa la función `orderPrice` para calcular el precio de un pedido de pizzas:

```fsharp
orderPrice [Margherita; Formaggio]
// => 19
```
