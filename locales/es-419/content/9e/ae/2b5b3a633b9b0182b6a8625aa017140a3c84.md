# Anexo de instrucciones

## Pistas

Para este ejercicio te resulta útil la siguiente funcionalidad de F#:

- El tipo [Map](https://en.wikibooks.org/wiki/F_Sharp_Programming/Sets_and_Maps#Maps) asocia claves con valores. Es muy similar al tipo `Dictionary<TKey, TValue>` de .NET, pero con una diferencia importante: `Map` es [inmutable](https://fsharpforfunandprofit.com/posts/correctness-immutability/).
- Una [abreviatura de tipo](https://fsharpforfunandprofit.com/posts/type-abbreviations/) se usa para crear un alias descriptivo de un tipo más complejo.
