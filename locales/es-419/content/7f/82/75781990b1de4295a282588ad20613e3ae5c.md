# Acerca de

La clase [`TimeZoneInfo`][TimeZoneInfo] ofrece rutinas para manejar las diferencias entre zonas horarias. La clase `TimeZoneInfo` también contiene métodos que facilitan el trabajo con el horario de verano.

La clase [`CultureInfo`][CultureInfo] admite formatos de fecha y hora que dependen de la configuración regional.

Para facilitar la programación multiplataforma, la clase [`RuntimeInformation`][RuntimeInformation] te permite detectar en qué sistema operativo se está ejecutando tu código: Linux, Windows o OSX.

[TimeZoneInfo]: https://docs.microsoft.com/en-us/dotnet/api/system.timezoneinfo
[CultureInfo]: https://docs.microsoft.com/en-us/dotnet/api/system.globalization.cultureinfo
[RuntimeInformation]: https://docs.microsoft.com/en-us/dotnet/api/system.runtime.interopservices.runtimeinformation
