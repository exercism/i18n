# Instrucciones

En este ejercicio vas a implementar una forma de llevar un registro de los puntajes máximos del juego más popular de tu sala de arcade local.

Tienes que implementar 5 funciones, en su mayoría relacionadas con la manipulación de un objeto que contiene puntajes máximos.

## 1. Crea un nuevo tablero de puntajes máximos

Crea una función `createScoreBoard` que cree un objeto que sirva como tablero de puntajes máximos.
Las claves de este objeto serán los nombres de los jugadores y los valores serán sus puntajes.
Para propósitos de prueba, quieres incluir directamente una entrada en el objeto.
Esta entrada inicial debe consistir en `The Best Ever` como nombre del jugador y `1000000` como puntaje.

```javascript
createScoreBoard();
// returns an object with one initial entry
```

## 2. Agrega jugadores a un tablero de puntajes

Para agregar un jugador al tablero de puntajes máximos, define la función `addPlayer`.
Acepta 3 parámetros:

- El primer parámetro es un objeto de tablero de puntajes existente.
- El segundo parámetro es el nombre de un jugador como string.
- El tercer parámetro es el puntaje como número.

La función devuelve el mismo objeto de tablero de puntajes que se pasó, después de agregar al nuevo jugador.

```javascript
addPlayer({ 'Dave Thomas': 0 }, 'José Valim', 486373);
// => {'Dave Thomas': 0, 'José Valim': 486373}
```

## 3. Elimina jugadores de un tablero de puntajes

Si los jugadores violan las reglas de la sala de arcade, se los elimina manualmente del tablero de puntajes máximos.
Define `removePlayer`, que recibe 2 parámetros:

- El primer parámetro es un objeto de tablero de puntajes existente.
- El segundo parámetro es el nombre del jugador como string.

Esta función debe eliminar del tablero la entrada del jugador dado y devolver el tablero después.
Si el jugador no estaba en el tablero desde un principio, no debe pasarle nada al tablero.
Debe devolverse tal como está.

```javascript
removePlayer({ 'Dave Thomas': 0 }, 'Dave Thomas');
// => {}

removePlayer({ 'Dave Thomas': 0 }, 'Rose Fanaras');
// => { 'Dave Thomas': 0 }
```

## 4. Aumenta el puntaje de un jugador

Si un jugador termina otra partida en la sala de arcade, se sumará cierta cantidad de puntos al puntaje anterior en el tablero.
Implementa `updateScore`, que recibe 3 parámetros:

- El primer parámetro es un objeto de tablero de puntajes existente.
- El segundo parámetro es el nombre del jugador cuyo puntaje debe aumentarse.
- El tercer parámetro es el puntaje que deseas **sumar** al puntaje máximo almacenado.

La función debe devolver el tablero de puntajes después de realizar la actualización.

```javascript
updateScore({ 'Freyja Ćirić': 12771008 }, 'Freyja Ćirić', 73);
// => {"Freyja Ćirić", 12771081}
```

## 5. Aplica los puntos de bonificación de los lunes

La sala de arcade lleva un tablero de puntajes aparte los lunes.
Al final del día, cada jugador de ese tablero recibe 100 puntos adicionales.

Implementa la función `applyMondayBonus`, que acepta un tablero de puntajes.
La función suma los puntos de bonificación a cada jugador que aparece en ese tablero.
Después, se devuelve el tablero.

```javascript
const scoreBoard = {
  'Dave Thomas': 44,
  'Freyja Ćirić': 539,
  'José Valim': 265,
};

applyMondayBonus(scoreBoard);
// => { 'Dave Thomas': 144, 'Freyja Ćirić': 639, 'José Valim': 365 }
```
