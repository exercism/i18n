# Instrucciones

Un espectáculo de circo es un orden de actuación de actos. Los distintos actos tienen interiores completamente distintos, y quien arma el espectáculo necesita las mismas dos cosas de cada uno de ellos.

Este es el primer ejercicio en el que escribes varias clases en un mismo archivo. El esqueleto te da la clase abstracta; escribe el resto debajo de ella.

## 1. Los tres actos

Escribe tres clases, cada una un `$ACT`.

| Clase | `name` | `minutes` |
| --- | --- | --- |
| `JUGGLING` | `"Juggling"` | 5 |
| `TUMBLING` | `"Tumbling"` | 3 |
| `TRAPEZE` | `"Trapeze at "` y después la altura y luego `"m"` | 8 |

`JUGGLING` y `TUMBLING` se crean sin argumentos. `TRAPEZE` se crea con la altura en metros:

```sather
#JUGGLING
#TRAPEZE(4)
```

así que `#TRAPEZE(4).name` es `"Trapeze at 4m"`.

## 2. El espectáculo

Escribe una clase `CIRCUS_ACTS` con tres rutinas, cada una de las cuales recibe el orden de actuación como un `ARRAY{$ACT}`.

**`total_minutes`**: cuánto dura todo el espectáculo.

```sather
CIRCUS_ACTS::total_minutes(|#JUGGLING, #TUMBLING|)
-- => 8
```

**`billing`**: los nombres de los actos, unidos con `", "`.

```sather
CIRCUS_ACTS::billing(|#JUGGLING, #TUMBLING|)
-- => "Juggling, Tumbling"
```

**`longest`**: el nombre del acto que más dura. Cuando dos duran lo mismo, gana el que aparece primero. Un espectáculo vacío no tiene acto más largo, así que la respuesta es `""`.

```sather
CIRCUS_ACTS::longest(|#JUGGLING, #TUMBLING|)
-- => "Juggling"
```

Ninguna de las tres puede preguntar de qué tipo de acto se trata.
