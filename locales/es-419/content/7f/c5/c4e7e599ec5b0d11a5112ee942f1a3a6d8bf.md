# Apéndice de instrucciones

## Implementación

Este ejercicio presenta los [genéricos](https://docs.oracle.com/javase/tutorial/java/generics/index.html).
Para que las pruebas pasen, necesitas construir tu clase de modo que acepte cualquier tipo de argumento, por ejemplo `Integer` o `String`.

Los genéricos son útiles porque te permiten escribir código más general y reutilizable.
Las implementaciones de [List](https://docs.oracle.com/javase/8/docs/api/java/util/List.html) y [Map](https://docs.oracle.com/javase/8/docs/api/java/util/Map.html) de Java son ambos ejemplos de clases que usan genéricos.
Al usarlos, puedes construir una `List` que contenga `Integers`, o una lista que contenga `Strings`, o cualquier otro tipo.

Hay algunas restricciones sobre los tipos que se usan con los genéricos.
Una de ellas es que, una vez que construiste una `List` que contiene `Integers`, no puedes poner `Strings` en ella.
Tienes que especificar qué tipo quieres poner en la clase cuando la construyes, y esa instancia solo se puede usar con ese tipo.

Por ejemplo, podrías construir una lista de `Integers`:

`List<Integer> someList = new LinkedList<>();`

Ahora `someList` solo puede contener `Integers`. También podrías hacer:

`List<String> someOtherList = new LinkedList<>()`

Ahora `someOtherList` solo puede contener `Strings`.

Otra restricción es que cualquier tipo que se use con genéricos no puede ser un [tipo primitivo](https://docs.oracle.com/javase/tutorial/java/nutsandbolts/datatypes.html), como `int` o `long`.
Sin embargo, cada tipo primitivo tiene un tipo de referencia correspondiente, así que en lugar de `int` puedes usar [`Integer`](https://docs.oracle.com/javase/8/docs/api/java/lang/Integer.html) y en lugar de `long` puedes usar [`Long`](https://docs.oracle.com/javase/8/docs/api/java/lang/Long.html).

Puede ayudarte mirar un [ejemplo de caso de uso de los genéricos](https://docs.oracle.com/javase/tutorial/java/generics/types.html) para empezar.
