# Introducción

## Funciones anónimas

Las funciones son ciudadanos de primera clase en Elixir. Esto significa que:

- Las funciones con nombre y las funciones anónimas se pueden asignar a variables.
- Las funciones con nombre y las funciones anónimas se pueden pasar de un lado a otro como datos, como argumentos y como valores devueltos.
- Las funciones anónimas se pueden crear dinámicamente.

Las funciones anónimas, a diferencia de las funciones con nombre, no tienen una referencia estática disponible; solo existen si se asignan a una variable o se invocan de inmediato.

Podríamos usar funciones anónimas para:

- Ocultar datos usando el ámbito léxico (también conocido como clausura).
- Crear funciones dinámicamente en tiempo de ejecución.

Las funciones anónimas comienzan con la palabra reservada `fn`, los argumentos se separan del cuerpo de la función con el token `->`, y terminan con un `end`. Al igual que con las funciones con nombre, la última expresión de la función se _devuelve implícitamente_ a la función que la llamó.

Para invocar una referencia a una función, debes usar un `.` entre la variable de referencia y la lista de argumentos:

```elixir
function_variable = fn param ->
  param + 1
end

function_variable.(1)
# => 2
```

Incluso puedes usar la notación abreviada de captura para que esto sea más conciso:

```elixir
variable = &(&1 + 1)

variable.(1)
# => 2
```

## Manipulación de bits

Elixir admite muchas funciones para trabajar con bits que se encuentran en el _módulo Bitwise_.

- `band/2`: AND a nivel de bits
- `bsl/2`: SHIFT LEFT a nivel de bits
- `bsr/2`: SHIFT RIGHT a nivel de bits
- `bxor/2`: XOR a nivel de bits
- `bor/2`: OR a nivel de bits
- `bnot/1`: NOT a nivel de bits

Aquí tienes un ejemplo de cómo usar una función bit a bit:

```elixir
Bitwise.bsl(1, 3)
# => 8
```

Todas las funciones bit a bit solo funcionan con números enteros.

Si usas la versión 1.9 de Elixir o una anterior, deberás llamar a `require Bitwise` al inicio de la definición del módulo para poder usar el módulo _Bitwise_.
