# Anexo de instrucciones

## Pistas

Para completar este ejercicio necesitas implementar la función `slices`,
que toma un *text* y devuelve las subsecuencias de dígitos con un
tamaño especificado:

Si es la primera vez que resuelves este ejercicio, se recomienda que te
quedes con la firma proporcionada:

```haskell
slices :: Int -> String -> [[Int]]
```

Más adelante, puede ser buena idea volver a este problema y jugar con otros tipos
de datos y bibliotecas:

- `ByteString`, del paquete *bytestring*.
- `Sequence`, del paquete *containers*.
- `Text`, del paquete *text*.
- `Vector`, del paquete *vector*.

La suite de tests se diseñó a propósito para aceptar casi cualquier firma de tipo
que tenga sentido, así que te animamos a encontrar la que creas que es la mejor.
