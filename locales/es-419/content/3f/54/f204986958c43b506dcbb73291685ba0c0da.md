# Introducción

## Parámetros

Este ejercicio analiza algunos detalles de los parámetros de los métodos y su uso en C#.

Los parámetros llevan información desde un método que llama hasta un método llamado.

- El comportamiento de los parámetros se puede modificar con el uso de modificadores como `ref` y `out`.

- Un parámetro con el modificador `out` devuelve un valor desde el método llamado hacia quien lo llama. El parámetro se puede pasar al método llamado sin estar inicializado y, en cualquier caso, dentro del método llamado se trata como si, al entrar, no se hubiera inicializado. La manera más fácil de entender el comportamiento y las reglas de los modificadores de parámetros es mediante ejemplos (ver abajo) y mensajes del compilador.

```csharp
void Foo(out int val)
{
    val = 42;
}
void Bar(int val)
{
    val = 42;
}

int importantValue = 1729;
Foo(out importantValue);
var result = importantValue == 42;
// => true

importantValue = 1729;
Bar(importantValue);
result = importantValue == 1729;
// => true
```

- A los parámetros `out` se les debe asignar un valor dentro del método llamado.

- Un parámetro con el modificador `ref` pasa un valor hacia el método llamado. Cuando el método termina, quien lo llamó encontrará en ese parámetro cualquier actualización que haya hecho el método llamado.

```csharp
void Foo(ref int val)
{
    val *= 7;
}

int importantValue = 6;
Foo(ref importantValue);
return importantValue;
// => 42
```

- Los parámetros `ref` deben ser variables, ya que el método llamado operará directamente sobre el parámetro tal como lo ve quien llama.
- Los modificadores `out` y `ref` son obligatorios tanto en la firma del método llamado como en el lugar donde se hace la llamada.
