# Instrucciones

La dueña de la pizzería de tu barrio te pidió ayuda para calcular los tiempos de cocción de distintas pizzas. En este ejercicio vas a escribir unas cuantas funciones para calcularlo.

Tienes tres tareas.

## 1. Calcula el tiempo restante de horneado en minutos

Define e implementa la función `remainingMinutesInOven()`, que contará cuántos minutos más necesitas mantener la pizza en el horno.

La función debe aceptar un parámetro **opcional** (con valor predeterminado) para la cantidad de minutos que pasaron desde que empezaste a hornear la pizza. Si el parámetro no se indica, asume que acabas de meter la pizza en el horno y que ya pasaron **0 (cero)** minutos.

Para simplificar, supongamos que todos los tipos de pizza necesitan exactamente 40 minutos en el horno para estar listas.

```kotlin
remainingMinutesInOven()   // => 40

remainingMinutesInOven(10)   // => 30
```

## 2. Calcula el tiempo de preparación en minutos

Antes de hornear la pizza, necesitas preparar la masa, estirarla y ponerle los ingredientes.

Define e implementa la función `preparationTimeInMinutes()`, que contará cuántos minutos se necesitan para preparar la pizza antes de meterla en el horno.

La función debe aceptar un parámetro **obligatorio** (`numberOfIngredientTypes`) para la cantidad de tipos de ingredientes de cobertura que se usarán.

Asume que necesitas 5 minutos para hacer y estirar la masa, y 2 minutos por **cada** tipo de cobertura.

```kotlin
preparationTimeInMinutes(0) // => 5

preparationTimeInMinutes(1) // => 7
```

## 3. Calcula el tiempo transcurrido en minutos

Define e implementa la función `elapsedCookingTimeInMinutes()`, que contará cuántos minutos se necesitan para preparar, hornear y servir la pizza. Usa las funciones de los pasos anteriores para hacer los cálculos.

La función debe aceptar dos parámetros. El primero es **obligatorio** y es la cantidad de tipos de ingredientes de cobertura. El segundo es **opcional** y es el tiempo para servir la pizza, en minutos (asume que es 0 si no se indica).

```kotlin
elapsedCookingTimeInMinutes(1)  // => 47

elapsedCookingTimeInMinutes(2, 3)  // => 52
```
