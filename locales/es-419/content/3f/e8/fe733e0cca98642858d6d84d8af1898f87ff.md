# Pistas

## 1. Describe números simples

- usa `fmt.Sprintf` para dar formato

## 2. Describe una caja de números

- obtén el resultado del método `Number()`
- usa `fmt.Sprintf` para dar formato

## 3. Implementa un método que extraiga el número de una caja de números fancy

- usa una aserción de tipo para comprobar si esto es un `FancyNumber`
- obtén el `string` del método `Value()`
- usa `strconv.Atoi` para convertir el `string` a un `int` (podemos descartar el error, ya que queremos 0 si no se puede convertir a un `int`)

## 4. Describe una caja de números fancy

- usa `ExtractFancyNumber` para obtener el valor `int`
- convierte el `int` a un `float64`
- usa `fmt.Sprintf` para dar formato

## 5. Implementa `DescribeAnything`, que usa todos los anteriores

- usa aserciones de tipo (por ejemplo, `i.(someType)`) o un switch de tipo (`switch v := i.(type)`)
- recuerda convertir `int` a un `float64`
