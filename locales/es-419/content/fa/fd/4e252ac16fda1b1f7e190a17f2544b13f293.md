# Instrucciones

Unos desarrolladores «otros» han estado trabajando en el proyecto del auto a control remoto [exercise:csharp/remote-control-competition](). Te han llamado para limpiar el código.

## 1. Separa las responsabilidades entre el propio auto y el sistema de telemetría

Refactoriza la clase `RemoteControlCar` para separar los métodos y las propiedades de telemetría, a los que se accede a través de una propiedad `Telemetry`.

```csharp
var car = new RemoteControlCar();
car.Telemetry.Calibrate();
car.Telemetry.SelfTest();
car.Telemetry.ShowSponsor("Walker Industries Inc.");
car.CurrentSponsor
// => "Walker Industries Inc."
car.Telemetry.SetSpeed(100, "cps");
car.GetSpeed()
// => "100 centimeters per second"
```

## 2. Evita que otro código dependa demasiado del tipo `Telemetry`

Asegúrate de que la instancia de `Telemetry` no se pueda crear fuera del ámbito del auto.

## 3. Evita que otro código dependa de la estructura `Speed`

Asegúrate de que la estructura `Speed` no se pueda usar fuera del ámbito de la clase `RemoteControlCar`.

## 4. Evita que otro código dependa de la enumeración `SpeedUnits`

Asegúrate de que la enumeración `SpeedUnits` no se pueda usar fuera del ámbito de la clase `RemoteControlCar`.
