# Anexo a las instrucciones

Este es un buen ejercicio para experimentar con literales de string no estándar y metaprogramación.

Puedes encontrar una breve introducción a los literales de string no estándar en esta [entrada de blog](https://web.archive.org/web/20170625222109/https://iaindunning.com/blog/julia-unicode.html). Una guía detallada de metaprogramación está en el [manual](https://docs.julialang.org/en/v1/manual/metaprogramming/).

Puedes ampliar tu solución agregando la funcionalidad que se describe a continuación.

El bonus A solo requiere lo básico que se explica en la entrada de blog. El bonus B requiere bastante más conocimiento de metaprogramación en Julia.

## Bonus A
Implementa un literal de string que aplique `ROT13` al string:
```julia
R13"abcdefghijklmnopqrstuvwxyz" == "nopqrstuvwxyzabcdefghijklm"
```

## Bonus B
Implementa los literales de string `R<i>`, `i = 0, ..., 26`, que desplazan el string según los valores de `i`:
```julia
R0"Hello, World!" == "Hello, World!"
R4"Testing 1 2 3 testing" == "Xiwxmrk 1 2 3 xiwxmrk"
R13"abcdefghijklmnopqrstuvwxyz" == "nopqrstuvwxyzabcdefghijklm"
```
