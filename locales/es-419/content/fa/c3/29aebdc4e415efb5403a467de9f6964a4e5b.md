# Clases

Las clases son un concepto central en la [programación orientada a objetos][object-oriented-programming].
[En Crystal, todo es un objeto][everything-is-an-object], cada objeto tiene un tipo y puede responder a algunos métodos.
Las clases son planos para crear objetos: proporcionan valores iniciales para el estado, como las variables, y las implementaciones del comportamiento, como los métodos.
Los objetos son instancias de una clase que contienen todas las variables de instancia y los estados.

## Definición de una clase

Una clase se define con la palabra clave `class`, seguida del nombre de la clase escrito en `UpperCamelCase`.

```crystal
class Account
end
```

## Crear una instancia

Para [crear una instancia de una clase][new-initialize], llama al nombre de la clase usando el método `new`.

```crystal
class Account
end

account = Account.new
```

En el ejemplo anterior, la variable `account` es una instancia de la clase `Account`.

Al crear una instancia, un método especial llamado `initialize` actúa como constructor.
Se llama cuando se crea una instancia.
El constructor te permite establecer el estado inicial de la instancia.
El método `initialize` puede recibir argumentos, que se pasan al crear una instancia.

```crystal
class Account
  def initialize(number)
    5 + number # => 9
  end
end

Account.new(4)
```

~~~~exercism/note
El método `initialize` no puede devolver un valor manualmente; en su lugar, `new` devuelve la instancia recién creada.

```crystal
class Account
  def initialize(number)
    5 + number
  end
end

Account.new(4)
# => #<Account:0x7f5dc33dcea0>
```
~~~~

## Métodos de instancia

Un método de instancia es un método que está disponible para una instancia de una clase y que se puede llamar en esa instancia.
Los métodos de instancia se definen con la palabra clave `def`, seguida del nombre del método.
Se definen dentro de la definición de la clase.

```crystal
class Account
  def balance
    100
  end
end

account = Account.new
account.balance # => 100
```

## Variables de instancia

Las [variables de instancia][instance-variable] son variables que están disponibles en todos los métodos de la instancia.
Para acceder a una variable de instancia, necesitas definir un método de instancia.
Se pueden inicializar en el método `initialize`.
Se definen con el prefijo `@`.

```crystal
class Account
  def initialize
    @balance = 100
  end

  def balance
    @balance
  end
end

account = Account.new
account.balance
# => 100
```

Las variables de instancia también se pueden definir dentro de la definición de la clase.

```crystal
class Account
  @age = 0
end
```

### Variables de instancia con inicialización

Las variables de instancia se pueden inicializar con un argumento que se pasa al método `initialize`.
Como Crystal no puede inferir el tipo del argumento que se usa durante la inicialización, hay que especificarlo.
Si quieres leer más sobre esto, puedes consultar: [inferencia de tipos][type-inference].
Para especificar el tipo de la variable puedes usar el símbolo `:`, seguido del tipo.
Por ejemplo, si quieres crear una variable de instancia llamada `balance` de tipo `Int32`, puedes hacer lo siguiente: `@balance : Int32`.
O, si quieres crear una variable de instancia llamada `raining` de tipo `Bool`, puedes hacer lo siguiente: `@raining : Bool`.

Hay varias formas de implementar esto: una es declarar el argumento con su tipo en el método `initialize` y luego asignar el argumento a la variable de instancia, como en el siguiente ejemplo:

```crystal
class Account
  def initialize(balance : Int32)
    @balance = balance
  end

  def balance
    @balance
  end
end

account = Account.new(1)
account_2 = Account.new(5)

account.balance
# => 1

account_2.balance
# => 5
```

Otra forma es declarar el tipo de la variable de instancia en la definición de la clase con la forma `@<variable> : <Type>`, como en el siguiente ejemplo:

```crystal
class Weather

  @raining : Bool

  def initialize(raining)
    @raining = raining
  end

  def raining
    @raining
  end
end

weather = Weather.new(true)
weather.raining
# => true
```

## Modificar variables de instancia

Los métodos pueden modificar variables de instancia.
Estos métodos se pueden llamar en la instancia de la clase.
Cuando un método modifica una variable de instancia, ese cambio solo está disponible en la instancia de la clase en la que lo llamaste.

```crystal
class Account
  def initialize(balance : Int32)
    @balance = balance
  end

  def withdraw(amount)
    @balance -= amount
  end

  def balance
    @balance
  end
end

account = Account.new(10)
account_2 = Account.new(10)
account.balance
# => 10

account_2.balance
# => 10

account.withdraw(5)
account.balance
# => 5

account_2.balance
# => 10
```

## Métodos de clase

Los [métodos de clase][class-methods] son métodos que se definen para una clase, pero no para sus instancias.
Ofrecen una forma de crear métodos que no dependen del estado de la instancia.
Se definen con la palabra clave `def`, seguida de `self.<method name>`.
`self` es una referencia al espacio de nombres desde el que se llama a `self`.
En este caso, se refiere a la clase `Account`.
Sería lo mismo que escribir `Account.`, pero `self.` es la forma preferida.

```crystal
class Account
  def self.balance
    100
  end
end

Account.balance
# => 100
```
