# Instalación

La forma más sencilla de instalar PureScript es con Node.js y NPM.

Si todavía no tienes Node.js instalado en tu computadora, puedes descargarlo desde el [sitio web de Node.js](https://nodejs.org/). Una vez que tengas Node.js funcionando, escribe este comando en la terminal para instalar el compilador de PureScript y la herramienta de compilación Spago:

    npm install --global purescript spago

Puedes encontrar más información en el [repositorio de PureScript](https://github.com/purescript/purescript/blob/master/INSTALL.md).
