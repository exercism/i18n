# Instrucciones

En este ejercicio vas a crear las reglas para el sitio web de un cine.

## 1. Verifica si un espectador tiene derecho al descuento para pensionados

El cine ofrece un descuento para «pensionados».
Quien tenga 60 años o más paga 10.00 por la entrada.
Quien sea más joven paga los 15.00 completos.

Escribe el método `Moviegoer#ticket_price` usando una sentencia ternaria.

```ruby
Moviegoer.new(21).ticket_price
#=> 15

Moviegoer.new(65).ticket_price
#=> 10
```

## 2. Verifica si un espectador puede ver películas de terror

El cine tiene un sistema simplificado de verificación de edad.
Si tienes 18 años o más, puedes ver películas de terror.
Si eres más joven, no puedes.

Implementa el método `Moviegoer#watch_scary_movie?`.
Debe devolver si alguien tiene permitido ver la película o no.

```ruby
Moviegoer.new(21).watch_scary_movie?
#=> true

Moviegoer.new(17).watch_scary_movie?
#=> false
```

## 3. Verifica si un espectador tiene derecho a palomitas de maíz gratis

El cine tiene un programa llamado Club de Cine.
Los miembros reciben palomitas de maíz gratis cuando ven cualquier película.

Implementa el método `Moviegoer.claim_free_popcorn!`.
Si quien ve la película es miembro del club de cine, debe recibir sus palomitas de maíz gratis.
Si no lo es, el método debe lanzar la excepción `UnsupportedOperation` definida al inicio del código.

```ruby
Moviegoer.new(21, member: true).claim_free_popcorn!
#=> 🍿

Moviegoer.new(17, member: false).claim_free_popcorn!
#=> Exception was raised! (NotMovieClubMemberError)
```

~~~~exercism/note
En este ejercicio, se espera que definas la excepción `UnsupportedOperation` para un ámbito específico.
~~~~
