# Introducción

## Strings

En Common Lisp, los strings son [vectores][concept-vectors] de [caracteres][concept-characters].
Se escriben como caracteres rodeados de comillas dobles (_por ejemplo_, "Hello World!").

El predicado `stringp` devolverá verdadero solo si el valor dado es un string.

Los strings se pueden dividir en subcadenas con la función `subseq`, que recibe el string, un índice de inicio y, opcionalmente, un índice final.
La indexación empieza en cero.

```lisp
(subseq "Hello World" 1 5)   ; => "ello"
(subseq "skip to the end" 5) ; => "to the end"
```

Los strings se pueden comparar para ver si son iguales con `string=`.
Si se deben ignorar las mayúsculas y minúsculas de los caracteres, puedes usar `string-equal`.

```lisp
(string= "macaroni" "macaroni")      ; => T
(string= "macaroni" "MACARONI")      ; => NIL
(string-equal "macaroni" "MACARONI") ; => T
```

Operaciones como convertir a mayúsculas, convertir a minúsculas y capitalizar strings se pueden hacer con `string-upcase` `string-downcase` y `string-capitalize`.

```lisp
(string-upcase "not too loud")                ; => "NOT TOO LOUD"
(string-downcase "YELL IT FROM THE ROOFTOPS") ; => "yell it from the rooftops"
(string-capitalize "practical COMMON LiSP")   ; => "Practical Common Lisp"
```
