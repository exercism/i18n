# Ayuda

Si tienes problemas y necesitas ayuda, puedes usar uno de los siguientes recursos:

- [Pharo Syntax Cheatsheet](http://files.pharo.org/media/pharoCheatSheet.pdf)
- [Pharo Community Resources](http://pharo.org/community) (incluye el enlace al chat de Discord)
- [/r/pharo](https://www.reddit.com/r/pharo) es el subreddit de Pharo.
- [StackOverflow](http://stackoverflow.com/questions/tagged/pharo) puedes usarlo para buscar tu problema y ver si ya se respondió. También puedes hacer y responder preguntas.
