# Pistas

## General

- Cada tarea construye texto en un bucle, así que todas empiezan con `#FSTR` y
  terminan con `.str`.
- Asigna el resultado de cada `+` de vuelta al acumulador:
  `script := script + ...`.

## 1. Repite una señal

- `1.upto!(times)` ejecuta el bucle la cantidad correcta de veces. El valor que
  devuelve no es necesario, así que puedes guardarlo directamente en una variable
  que nunca uses, o usar `times.times!`, que no devuelve nada.
- Que no haya veces no necesita ningún manejo especial: el bucle simplemente no
  se ejecuta.

## 2. Las iniciales del elenco

- `names.elt!` devuelve cada nombre; `[0]` toma su primer carácter.
- Un `FSTR` acepta un `CHAR` directamente, así que no hace falta convertirlo en
  un string primero.

## 3. Numera las líneas

- Dos iteradores en un solo bucle, como en el ejercicio anterior: `1.up!` para el
  número y `lines.elt!` para el texto.
- La línea nueva va *antes* de cada línea excepto la primera. Probar el número es
  la forma más fácil: `if number > 1 then ... end`.
- Un `FSTR` acepta el número directamente, así que `script + number + ". "`
  funciona sin convertirlo.

## 4. Grita una línea

- `line.elt!` recorre un string carácter por carácter.
- `.upper` deja intacto todo lo que no sea una letra, así que el espacio no
  necesita ningún manejo especial.
