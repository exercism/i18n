# Instrucciones

El contramaestre dirige un briefing diario de la guardia en la cubierta: un saludo fijo, un pase de lista de la tripulación de guardia y, para terminar, una despedida. Vas a descomponer el briefing en pequeñas líneas con nombre y luego las vas a componer.

Vas a editar **dos archivos** en este ejercicio:

- `bosuns-briefing/helpers/helpers.factor`: piezas pequeñas y reutilizables. Vocabulario: `bosuns-briefing.helpers`.
- `bosuns-briefing/bosuns-briefing.factor`: el archivo principal que compone los helpers. Vocabulario: `bosuns-briefing`.

## 1. Saludo

En `helpers.factor`, define `greeting` para que devuelva la cadena fija de apertura `"All hands, attention!"`.

```factor
greeting .
! => "All hands, attention!"
```

## 2. Línea de la tripulación

En `helpers.factor`, define `crew-line` para que reciba un string con un nombre y devuelva ese nombre precedido por `"  - "` (dos espacios, un guion y un espacio).

```factor
"Lopez" crew-line .
! => "  - Lopez"
```

## 3. Despedida

En `helpers.factor`, define `closing` para que devuelva la cadena fija de despedida `"Carry on."`.

```factor
closing .
! => "Carry on."
```

## 4. Lista de la tripulación

En `bosuns-briefing.factor`, define `roster` para que reciba un array de nombres de tripulantes y devuelva un único string de varias líneas con cada nombre formateado por `crew-line` y unidos por saltos de línea.

```factor
{ "Lopez" "Mwangi" } roster .
! => "  - Lopez\n  - Mwangi"

{ } roster .
! => ""
```

## 5. Briefing

En `bosuns-briefing.factor`, define `briefing` para que reciba un array de nombres de tripulantes y devuelva el briefing completo como un único string: el saludo en la primera línea, la lista en las siguientes y la despedida en la última. Usa los helpers y `roster`.

```factor
{ "Lopez" "Mwangi" } briefing .
! => "All hands, attention!\n  - Lopez\n  - Mwangi\nCarry on."

{ } briefing .
! => "All hands, attention!\n\nCarry on."
```
