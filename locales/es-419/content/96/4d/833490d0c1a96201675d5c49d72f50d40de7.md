# Pistas

## General

- Los arrays en Swift usan índices basados en cero. El primer índice de un array es `0`.

## 1. Recupera una carta de la pila

- Para obtener el `n`-ésimo elemento de un slice, [usa un subscript][array-access].
- Un array siempre empieza con el índice `0`.

## 2. Intercambia una carta en la pila

- Para establecer el `n`-ésimo elemento de un array, [usa un subscript][array-access] y asígnale un valor nuevo.
- Un array siempre empieza con el índice `0`.

## 3. Inserta una carta en la parte superior de la pila

- Existe un [método de array][array-append-docs] para agregar un valor nuevo al final del array.

## 4. Elimina una carta de la pila

- Existe un [método de array][array-removeat-docs] que puedes usar para eliminar elementos en un índice específico.

## 5. Elimina la carta de arriba de la pila

- Existe un [método de array][array-removelast-docs] para eliminar el último elemento del array.

## 6. Inserta una carta en la parte inferior de la pila

- Existe un [método de array][array-insert-docs] para agregar un valor nuevo en un índice específico del array.
- Un array siempre empieza con el índice `0`.

## 7. Elimina una carta de la parte inferior de la pila

- Existe un [método de array][array-removefirst-docs] para eliminar el primer elemento del array.

## 8. Comprueba el tamaño de la pila

- Los arrays tienen una [propiedad][array-count-docs] para obtener su longitud.

## 9. Cuenta el número de cartas pares de la pila

- Puedes recorrer los elementos de un array usando un [bucle `for-in`][for-in-loops].
- Los tipos enteros en Swift tienen el método [`isMultiple(of:)`][int-ismultiple-docs] para comprobar si son múltiplos de otro entero.
