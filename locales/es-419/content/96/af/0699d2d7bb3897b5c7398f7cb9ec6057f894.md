# Acerca de

Cuando modelas datos que solo pueden tomar un conjunto específico de estados posibles, como los días de la semana, los puntos cardinales o los botones de un control, los tipos básicos como `Int` o `String` tienen desventajas importantes.
Con enteros o strings, tu código debe verificar constantemente si hay valores inválidos (como un código de estado de `999` o un error de escritura como `"leftt"`), y a quien lo lee le cuesta saber qué representan los números.

Swift resuelve este problema con las [_enumeraciones_][enumerations] (a las que a menudo se les llama *enums*).
Un enum define un tipo común para un grupo de valores relacionados y con nombre. Como el compilador conoce de antemano todos los casos posibles, puede verificar que tu código sea correcto y esté completo en tiempo de compilación.
Los enums también pueden tener métodos, inicializadores y propiedades calculadas.

## Definir enums

Define un enum con la palabra clave `enum` seguida del nombre del tipo, y enumera sus casos dentro de llaves.
Por convención en Swift, el nombre del tipo usa `UpperCamelCase`, mientras que cada caso usa `lowerCamelCase`:

```swift
enum NESButton {
    case up
    case down
    case left
    case right
    case a
    case b
    case select
    case start
}
```

También puedes definir varios casos en una sola línea, separados por comas:

```swift
enum NESButton {
    case up, down, left, right, a, b, select, start
}
```

Para referirte a un caso de un enum, escribe el nombre del tipo del enum, un punto (`.`) y el nombre del caso. Una vez que el compilador conoce el tipo o puede inferirlo, puedes omitir el nombre del tipo y usar la sintaxis abreviada con punto:

```swift
var lastPressed = NESButton.up

// Swift infers the type, so you can omit the type name:
lastPressed = .down

let konamiCode: [NESButton] = [.up, .up, .down, .down, .left, .right, .left, .right, .b, .a]
```

## Enums y sentencias switch

Los enums funcionan a la perfección con las [sentencias `switch`][enums-and-switches].
Como un `switch` en Swift debe ser exhaustivo, el compilador se asegura de que manejes todos los casos posibles:

```swift
lastPressed = .left
switch lastPressed {
case .up: print("You pressed the UP button")
case .down: print("You pressed the DOWN button")
case .left: print("You pressed the LEFT button")
case .right: print("You pressed the RIGHT button")
case .a: print("You pressed the A button")
case .b: print("You pressed the B button")
case .select: print("You pressed the SELECT button")
case .start: print("You pressed the START button")
}
// Prints "You pressed the LEFT button"
```

Si omites algún caso y no proporcionas una cláusula `default`, el compilador reporta un error:

```swift
switch lastPressed {
case .up, .down, .left, .right:
    print("You pressed a direction button.")
}
// Error: Switch must be exhaustive
```

Enumerar todos los casos de forma explícita suele ser preferible a usar `default`. De ese modo, si agregas un caso nuevo en el futuro, el compilador te avisará de inmediato para que actualices cada sentencia `switch` que maneje ese enum.

## Métodos e inicializadores

Los enums pueden definir métodos e inicializadores personalizados igual que las clases y los structs. Dentro de un método de un enum, `self` se refiere al valor del caso actual:

```swift
enum Coin {
    case heads
    case tails

    init(_ value: Int) {
        if value.isMultiple(of: 2) {
            self = .heads
        } else {
            self = .tails
        }
    }

    func flip() -> Coin {
        switch self {
        case .heads: return .tails
        case .tails: return .heads
        }
    }
}

let tails = Coin(13)     // .tails
let heads = Coin(0)      // .heads
let flipped = heads.flip() // .tails
```

## Valores brutos

Los casos de un enum se pueden precargar con valores predeterminados llamados [_valores brutos_][raw-values].
Todos los valores brutos de un enum deben compartir el mismo tipo (como `Int`, `String` o `Character`):

```swift
enum NESButton: Character {
    case up = "⬆️"
    case down = "⬇️"
    case left = "⬅️"
    case right = "➡️"
    case a = "🅰️"
    case b = "🅱️"
    case select = "✅"
    case start = "🚦"
}

print(NESButton.left.rawValue) // Prints "⬅️"
```

Puedes inicializar un enum a partir de un valor bruto usando `init(rawValue:)`. Como es posible que se proporcione un valor bruto inválido, este inicializador devuelve un opcional:

```swift
let upButton = NESButton(rawValue: "⬆️") // Optional(NESButton.up)
let invalid = NESButton(rawValue: "🙄")  // nil
```

Swift puede asignar valores brutos automáticamente a los enums de tipo `String` e `Int`:

- Para los enums de tipo `String`, el valor bruto de cada caso es, de forma predeterminada, el nombre del caso.
- Para los enums de tipo `Int`, los valores brutos empiezan en `0` y aumentan de 1 en 1, a menos que se especifique lo contrario.

```swift
enum Planet: Int {
    case mercury = 1, venus, earth, mars
}

print(Planet.earth.rawValue) // Prints 3
```

## Valores asociados

Los casos de un enum también pueden almacenar valores personalizados de distintos tipos junto con cada caso, conocidos como [_valores asociados_][associated-values]:

```swift
enum Suit: Character {
    case diamonds = "♦️", clubs = "♣️", hearts = "♥️", spades = "♠️"
}

enum Card {
    case ace(Suit)
    case king(Suit)
    case queen(Suit)
    case jack(Suit)
    case number(Suit, Int)

    func description() -> String {
        switch self {
        case .ace(let suit): return "A\(suit.rawValue)"
        case .king(let suit): return "K\(suit.rawValue)"
        case .queen(let suit): return "Q\(suit.rawValue)"
        case .jack(let suit): return "J\(suit.rawValue)"
        case let .number(suit, value): return "\(value)\(suit.rawValue)"
        }
    }
}

let aceOfSpades = Card.ace(.spades)
let twoOfHearts = Card.number(.hearts, 2)

print(aceOfSpades.description()) // Prints "A♠️"
print(twoOfHearts.description()) // Prints "2♥️"
```

Un enum puede usar valores brutos o valores asociados, pero no ambos.

## Enumeraciones recursivas

Una [enumeración recursiva][recursive-enumerations] es un enum que tiene otra instancia del enum como valor asociado de uno o más casos.
Para permitir la recursión, marca el caso (o el enum completo) con la palabra clave `indirect`:

```swift
enum BinaryTree {
    case leaf(value: Int)
    indirect case node(left: BinaryTree, value: Int, right: BinaryTree)
}

let tree: BinaryTree = .node(
    left: .leaf(value: 1),
    value: 3,
    right: .node(left: .leaf(value: 5), value: 6, right: .leaf(value: 9))
)
```
