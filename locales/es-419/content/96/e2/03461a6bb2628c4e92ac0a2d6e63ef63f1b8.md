# Anexo de instrucciones

## Sobre la ability Stream

Un `Stream` es una ability de Unison que se usa para emitir valores.

Podrías usar la ability `Stream` si tienes una función que debe producir valores como efecto secundario al ser llamada. Por ejemplo, esta función devuelve el último valor de la List, pero emite un total acumulado a medida que ve cada elemento:

```
emitRunningTotal : '{Stream Nat} Nat
emitRunningTotal = 'let
  use Nat +
  List.foldLeft (
    acc a -> let
      runningTotal = acc + a
      Stream.emit runningTotal
      a
    ) 0 [1,2,3,4,5]
```

Podemos materializar el Stream como una List junto con el valor que devuelve la función que lo produce, usando un manejador de ability:

```
> Stream.toListWithResult! emitRunningTotal
  ⧩
  ([1, 3, 5, 7, 9], 5)
```
