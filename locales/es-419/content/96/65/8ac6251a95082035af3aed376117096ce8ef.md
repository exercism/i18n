# Instrucciones

En este ejercicio vas a escribir algo de código para ayudarte a prepararte para comprar un vehículo.

Tienes tres tareas: una para determinar si necesitas una licencia, otra para ayudarte a elegir entre dos vehículos y otra para estimar el precio aceptable de un vehículo usado.

## 1. Determina si vas a necesitar una licencia de conducir

Algunos tipos de vehículos requieren una licencia de conducir para manejarlos.
Supón que solo los tipos `"car"` y `"truck"` requieren licencia; todo lo demás se puede manejar sin licencia.

Implementa la función `NeedsLicense(kind)`, que recibe el tipo de vehículo y devuelve un valor Boolean que indica si necesitas una licencia para ese tipo de vehículo.

```go
needLicense := NeedsLicense("car")
// => true

needLicense = NeedsLicense("bike")
// => false

needLicense = NeedsLicense("truck")
// => true
```

## 2. Elige entre dos vehículos posibles para comprar

Evalúa tus opciones de vehículos disponibles.
Logras reducirlas a dos opciones, pero necesitas ayuda para tomar la decisión final.
Para eso, implementa la función `ChooseVehicle(option1, option2)`, que recibe dos vehículos como argumentos y devuelve una decisión que incluye la opción que aparece primero en orden lexicográfico.

```go
vehicle := ChooseVehicle("Wuling Hongguang", "Toyota Corolla")
// => "Toyota Corolla is clearly the better choice."

ChooseVehicle("Volkswagen Beetle", "Volkswagen Golf")
// => "Volkswagen Beetle is clearly the better choice."
```

## 3. Calcula una estimación del precio de un vehículo usado

Ahora que tomaste una decisión, quieres asegurarte de obtener un precio justo en la concesionaria.
Como te interesa comprar un vehículo usado, el precio depende de la antigüedad del vehículo.
Para una estimación aproximada, supón que si el vehículo tiene menos de 3 años, cuesta el 80% del precio original que tenía cuando era nuevo.
Si tiene al menos 10 años, cuesta el 50%.
Si el vehículo tiene al menos 3 años pero menos de 10, cuesta el 70% del precio original.

Implementa la función `CalculateResellPrice(originalPrice, age)`, que aplica esta lógica usando `if`, `else if` y `else` (hay otras formas si quieres practicar).
Recibe el precio original y la antigüedad del vehículo como argumentos y devuelve el precio estimado en la concesionaria.

```go
CalculateResellPrice(1000, 1)
// => 800

CalculateResellPrice(1000, 5)
// => 700

CalculateResellPrice(1000, 15)
// => 500
```

**Nota**: el valor devuelto es un `float64`.
