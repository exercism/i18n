# Agrega un nuevo track

El primerísimo paso para agregar un nuevo track de lenguaje a Exercism es:

- [Solicita un nuevo track de lenguaje](/docs/building/tracks/new/request-new)

Una vez que hayas completado ese paso, los siguientes pasos son:

- [Únete a nuestra comunidad](/docs/building/tracks/new/join-our-community)
- [Selecciona la variante del lenguaje de programación](/docs/building/tracks/new/select-programming-language-variant) (si corresponde)
- [Selecciona el framework de pruebas](/docs/building/tracks/new/select-testing-framework)
- [Agrega el primer ejercicio](/docs/building/tracks/new/add-first-exercise)
- [Configura la integración continua](/docs/building/tracks/new/setup-continuous-integration)
- [Agrega los ejercicios iniciales](/docs/building/tracks/new/add-initial-exercises)
- [Crea el ejecutor de pruebas](/docs/building/tracks/new/build-test-runner)
- [Configura las herramientas](/docs/building/tracks/new/configure-tooling)
- [Prepárate para el lanzamiento](/docs/building/tracks/new/prepare-for-launch)
- [Prueba el track](/docs/building/tracks/new/test-track)
- [Encuentra mantenedores](/docs/building/tracks/new/find-maintainers)
- [¡Lanza!](/docs/building/tracks/new/launch)
- [Habilita el resaltado de sintaxis](/docs/building/tracks/new/syntax-highlighting)
- [Implementa herramientas adicionales](/docs/building/tracks/new/implement-tooling)
- [Prepárate para las contribuciones de código abierto de personas desconocidas](/docs/building/tracks/new/prepare-for-contributions)
