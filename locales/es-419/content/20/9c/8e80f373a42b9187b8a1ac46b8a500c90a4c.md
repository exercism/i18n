# Instrucciones

En este ejercicio vas a procesar entradas de registro.

Cada línea de registro es un string con el siguiente formato: `"[<LEVEL>]: <MESSAGE>"`.

Hay tres niveles de registro diferentes:

- `INFO`
- `WARNING`
- `ERROR`

Tienes tres tareas, y cada una tomará una línea de registro y te pedirá que hagas algo con ella. Hay muchas formas de resolver estas tareas: elige tus técnicas favoritas de los ejemplos anteriores y mira qué se te ocurre.

## 1. Obtén el mensaje de una línea de registro

Implementa la función `message` para devolver el mensaje de una línea de registro:

```jq
"[ERROR]: Invalid operation" | message
# => "Invalid operation"
```

Se deben eliminar los espacios en blanco que haya al principio o al final:

```jq
"[WARNING]:  Disk almost full\r\n" | message
# => "Disk almost full"
```

## 2. Obtén el nivel de registro de una línea de registro

Implementa la función `log_level` para devolver el nivel de registro de una línea de registro, el cual debe devolverse en minúsculas:

```ruby
"[ERROR]: Invalid operation" | log_level
# => "error"
```

## 3. Dale otro formato a una línea de registro

Implementa la función `reformat` que le da otro formato a la línea de registro, poniendo el mensaje primero y el nivel de registro después, entre paréntesis:

```ruby
"[INFO]: Operation completed" | reformat
# => "Operation completed (info)"
```
