# Instrucciones

La troupe de baile se forma en filas, y tú llevas la cuenta de quién va en cada lugar.

Las cinco tareas van en la clase `DANCE_FORMATION`.

## 1. ¿Cuántos hay en la fila?

```sather
DANCE_FORMATION::dancer_count(|"Mia", "Ana", "Ben"|)
-- => 3
```

## 2. ¿Quién va al frente?

El líder es quien queda en primer lugar.

```sather
DANCE_FORMATION::leader(|"Mia", "Ana", "Ben"|)
-- => "Mia"
```

## 3. ¿Quién está al final?

El marcador de atrás es quien queda al final, sin importar lo larga que sea la fila.

```sather
DANCE_FORMATION::back_marker(|"Mia", "Ana", "Ben"|)
-- => "Ben"
```

## 4. La formación de apertura

La troupe siempre abre en el mismo orden: Mia, Ana, Ben. Devuelve esa fila.

```sather
DANCE_FORMATION::opening_row
-- => an array holding "Mia", "Ana" and "Ben", in that order
```

Esta rutina no lleva argumentos.

## 5. Cuenta los pasos

Cada persona del grupo tiene una cantidad de pasos por hacer. Súmalos.

```sather
DANCE_FORMATION::total_steps(|8, 16, 8|)
-- => 32
```

Una fila vacía equivale a cero pasos.
