# Pruebas

## Clojure CLI

Los ejercicios de Clojure en Exercism vienen con un archivo `deps.edn` con un alias `:test` para invocar el [cognitect-labs test-runner](https://github.com/cognitect-labs/test-runner):

``` bash
clj -X:test
```

## Leiningen

También se puede usar Leiningen para ejecutar las pruebas del ejercicio ejecutando el siguiente comando desde el directorio del ejercicio:

```bash
lein test
```
