# Introducción

Cuando tienes varios valores discretos posibles sobre los que despachar, `case` (en [`combinators`][combinators]) encaja mejor que una cadena de `if`s.

## `case`

```
case ( obj assoc -- )
```

`case` toma el valor de la parte superior de la pila y un *assoc* de cláusulas. Cada cláusula es `{ value [ body ] }`. La primera cláusula cuyo valor sea `=` a la entrada gana; su cuerpo se ejecuta con el valor de entrada *ya consumido*. Una entrada final que es solo `[ body ]` es la predeterminada: la entrada *sigue en la pila* cuando se ejecuta.

```factor
USING: combinators ;

: name-of ( n -- s )
    {
        { 1 [ "one" ] }
        { 2 [ "two" ] }
        [ drop "many" ]
    } case ;
```

La igualdad se determina con `=`, así que cualquier cosa que se compare como igual sirve como clave: números, strings y símbolos también.

## `cond` para ramas con guardas

Cuando la elección depende de un *predicado* en lugar de la igualdad (por ejemplo, `x > 11`), `cond` es la herramienta que corresponde. Ya conociste `cond` en [¡Autos, ensámblense!][cars-assemble].

## Símbolos

Un `SYMBOL:` declara una palabra que se empuja a sí misma a la pila: un valor de etiqueta que se evalúa a sí mismo. `SYMBOLS:` declara varias a la vez:

```factor
SYMBOLS: yes no maybe ;
```

Ahora `yes` es un valor, comparable con `=`, que puedes usar como clave de `case`:

```factor
: invert ( ? -- ?' )
    { { yes [ no ] } { no [ yes ] } [ ] } case ;
```
