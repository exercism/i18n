# Apéndice de instrucciones

## Instrucciones específicas del track

### Formato del campo minado

El campo minado se representa como un string, con un carácter de nueva línea al final de cada fila.

Un ejemplo sería `"   \n * \n   \n"`

### Memoria reservada

El búfer para el string de entrada usa los bytes 64-319 de la memoria lineal.

El string de entrada se puede modificar en el lugar si lo deseas.
