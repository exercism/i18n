# Introducción

PHP permite declarar funciones dentro de otras funciones. Estas funciones no necesitan tener un nombre, pero puedes asignarlas a variables o incluso pasarlas directamente a otra función que requiera un parámetro de tipo función.

```php
function onlyOdds(array $numbers): array
{
    return array_filter($numbers, function($num) {
        return $num % 2 === 1;
    });
}
```
