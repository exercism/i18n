# Instrucciones

Estás en el proceso de desarrollar el nuevo y muy apreciado juego **Crystal Hunter**.
En el juego, eres un personaje que se mueve por el escenario y recolecta cristales.
El jugador gana si recoge todos los cristales.
Si el jugador entra en contacto con un bandido, pierde todos sus cristales y el juego.
Hay una excepción a esta regla: el jugador puede tener un power-up activo que lo hace invisible para los bandidos.

Tu objetivo es escribir algunas reglas que se usarán en el juego.

## 1. Define si el personaje obtiene puntos de bonificación

En el juego, el personaje obtiene puntos de bonificación si toca a un bandido mientras tiene un power-up.

Define el método `Rules#bonus_points?` que recibe dos argumentos (_si el personaje tiene un power-up activo_ y _si el personaje está tocando a un bandido_) y devuelve un valor Boolean que indica si el personaje obtendrá puntos de bonificación.
El método debe devolver `true` solo si el personaje tiene un power-up activo y está tocando a un bandido, y `false` en caso contrario.

```Crystal
Rules.new.bonus_points?(false, true)
# => false
```

## 2. Define si el personaje anota puntos

El jugador obtiene puntos en el juego cuando recoge un cristal o un power-up.

Define el método `Rules#score?`, que recibe dos argumentos (_si el personaje está tocando un power-up_ y _si el personaje está tocando un cristal_) y devuelve un valor Boolean que indica si el personaje anotó puntos o no.
El método debe devolver `true` si el personaje toca un power-up o un cristal, y `false` en caso contrario.

```crystal
Rules.new.score?(true, true)
# => true
```

## 3. Define si el personaje pierde

Define el método `Rules#lose?`, que recibe dos argumentos (_si el personaje tiene un power-up activo_ y _si el personaje está tocando a un bandido_) y devuelve un valor Boolean que indica si el personaje pierde o no.
El método debe devolver `true` si el personaje toca a un bandido y no tiene un power-up activo, y `false` en caso contrario.

```crystal
Rules.new.lose?(false, true)
# => true
```

## 4. Define si el personaje gana

Define el método `Rules#win?`, que recibe tres argumentos (_si el personaje ha recogido todos los cristales_, _si el personaje tiene un power-up activo_ y _si el personaje está tocando a un bandido_) y devuelve un valor Boolean que indica si el personaje gana o no.
El método debe devolver `true` si el personaje ha reunido todos los cristales y no ha perdido según los argumentos definidos en la parte 3, y `false` en caso contrario.

```crystal
Rules.new.win?(false, true, false)
# => false
```
