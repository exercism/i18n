# Introducción

En Elixir, para elegir un elemento aleatorio de una estructura de datos enumerable (por ejemplo, un array, un rango), usamos `Enum.random`. Esta función elige un solo elemento, y cada elemento tiene la misma probabilidad de ser elegido.

Elixir no tiene funciones propias para elegir un número de punto flotante aleatorio. Para hacerlo, tenemos que usar Erlang directamente.
