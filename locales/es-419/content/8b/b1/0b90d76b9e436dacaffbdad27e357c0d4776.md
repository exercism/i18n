# Instrucciones

En este ejercicio, implementarás la lógica de la misión para un nuevo juego de rol que está desarrollando un amigo.
La protagonista del juego es Annalyn, una chica valiente con un perro mascota feroz y leal.
Por desgracia, ocurre una catástrofe, ya que su mejor amigo fue secuestrado mientras buscaba bayas en el bosque.
Annalyn intentará encontrar y liberar a su mejor amigo, y podrá llevar a su perro con ella en esta misión.

Después de pasar un tiempo siguiendo el rastro de su mejor amigo, encuentra el campamento en el que está prisionero.
Resulta que hay dos secuestradores: un caballero poderoso y un arquero astuto.

Una vez que encuentra a los secuestradores, Annalyn considera cuáles de las siguientes acciones puede realizar:

- _Ataque rápido_: se puede hacer un ataque rápido si el caballero está dormido, ya que tarda un tiempo en ponerse la armadura, así que estará vulnerable.
- _Espiar_: se puede espiar al grupo si al menos uno de ellos está despierto.
  De lo contrario, espiar es una pérdida de tiempo.
- _Hacer señales al prisionero_: se le pueden hacer señales al prisionero usando sonidos de aves si el prisionero está despierto y el arquero está dormido, ya que los arqueros están entrenados en las señales con sonidos de aves, así que podrían interceptar el mensaje.
- _Liberar al prisionero_: Annalyn puede intentar colarse en el campamento para liberar al prisionero.
  Es algo arriesgado y solo puede salir bien de una de dos maneras:
  - Si Annalyn lleva a su perro con ella, puede rescatar al prisionero si el arquero está dormido.
    El caballero le tiene miedo al perro y el arquero no tendrá tiempo de prepararse antes de que Annalyn y el prisionero puedan escapar.
  - Si Annalyn no lleva a su perro, entonces ella y el prisionero tendrán que ser muy sigilosos.
    Annalyn puede liberar al prisionero si el prisionero está despierto y tanto el caballero como el arquero están dormidos, pero si el prisionero está dormido no se le puede rescatar: el prisionero se sobresaltaría con la aparición repentina de Annalyn y despertaría al caballero y al arquero.

Tienes cuatro tareas: implementar la lógica para determinar si las acciones anteriores están disponibles según el estado de los tres personajes que se encuentran en el bosque y si el perro de Annalyn está presente o no.

## 1. Comprueba si se puede hacer un ataque rápido

Define la función `can_fast_attack()` que recibe un valor Boolean que indica si el caballero está despierto.
Esta función devuelve `true` si se puede hacer un ataque rápido según el estado del caballero.
De lo contrario, devuelve `false`:

```rust
let knight_awake = true;
can_fast_attack(knight_awake); // false
```

## 2. Comprueba si se puede espiar al grupo

Define la función `can_spy()` que recibe tres valores Boolean, que indican si el caballero, el arquero y el prisionero, respectivamente, están despiertos.
La función devuelve `true` si se puede espiar al grupo, según el estado de los tres personajes.
De lo contrario, devuelve `false`:

```rust
let knight_awake = false;
let archer_awake = true;
let prisoner_awake = false;
can_spy(knight_awake, archer_awake, prisoner_awake); // true
```

## 3. Comprueba si se le pueden hacer señales al prisionero

Define la función `can_signal_prisoner()` que recibe dos valores Boolean, que indican si el arquero y el prisionero, respectivamente, están despiertos.
La función devuelve `true` si se le pueden hacer señales al prisionero, según el estado de los dos personajes.
De lo contrario, devuelve `false`:

```rust
let archer_awake = false;
let prisoner_awake = true;
can_signal_prisoner(archer_awake, prisoner_awake); // true
```

## 4. Comprueba si se puede liberar al prisionero

Define la función `can_free_prisoner()` que recibe cuatro valores Boolean.
Los primeros tres parámetros indican si el caballero, el arquero y el prisionero, respectivamente, están despiertos.
El último parámetro indica si el perro de Annalyn está presente.
La función devuelve `true` si se puede liberar al prisionero según el estado de los tres personajes y la presencia del perro de Annalyn.
De lo contrario, devuelve `false`:

```rust
let knight_awake = false;
let archer_awake = true;
let prisoner_awake = false;
let dog_present = false;
can_free_prisoner(knight_awake, archer_awake, prisoner_awake, dog_present); // false
```
