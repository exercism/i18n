# Pistas

## 1. Obtener el mensaje de una línea de log

- Extrae el texto que está después de los _primeros_ dos puntos.
  - Puedes usar `index/1` y la notación de slice.
  - O explorar el uso de las funciones de expresiones regulares.
- Usa la función `trim` que se te proporciona.

## 2. Obtener el nivel de log de una línea de log

- Extrae el texto que está dentro del primer par de corchetes.
- Devuelve el resultado en minúsculas.

## 3. Reformatear una línea de log

- Reutiliza las funciones existentes.
- Dos enfoques son usar la interpolación de strings o la concatenación.
