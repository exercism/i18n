# Instrucciones

Estás escribiendo un sistema embebido para una máquina Take-A-Number. Es un modelo muy simple. Puede entregar números consecutivos e informar cuál fue el último número entregado.

## 1. Inicia la máquina

Implementa la función `start/0`. Debe crear un nuevo proceso y devolver el PID del proceso. El nuevo proceso todavía no necesita hacer nada.

```elixir
TakeANumber.start()
# => #PID<0.138.0>
```

Ten en cuenta que cada vez que ejecutes este código, el PID puede ser distinto.

## 2. Reporta el estado de la máquina

Modifica la máquina para que el proceso recién creado esté listo para recibir mensajes (inicia un _bucle de recepción_) con un estado inicial de `0`. Debe poder recibir mensajes `{:report_state, sender_pid}`. Como respuesta a esos mensajes, debe enviar su estado actual (el último turno entregado) a `sender_pid` y luego esperar más mensajes.

```elixir
machine_pid = TakeANumber.start()

# a client sending a message to the machine
send(machine_pid, {:report_state, self()})

# a client receiving a message from the machine
receive do
  msg -> msg
end

# => 0
```

## 3. Entrega números

Modifica la máquina para que pueda recibir mensajes `{:take_a_number, sender_pid}`. Debe aumentar su estado en 1, enviar el nuevo estado a `sender_pid` y luego esperar más mensajes.

```elixir
machine_pid = TakeANumber.start()

# a client sending a message to the machine
send(machine_pid, {:take_a_number, self()})

# a client receiving a message from the machine
receive do
  msg -> msg
end

# => 1
```

## 4. Detén la máquina

Modifica la máquina para que pueda recibir un mensaje `:stop`. Debe dejar de esperar más mensajes.

## 5. Ignora los mensajes inesperados

Modifica la máquina para que, cuando reciba un mensaje inesperado, lo ignore y siga esperando más mensajes.
