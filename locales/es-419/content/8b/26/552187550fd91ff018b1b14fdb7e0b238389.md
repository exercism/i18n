# Instrucciones

Después de una revisión de seguridad reciente, te pidieron que limpiaras los archivos de log archivados de la organización.

## 1. Identifica las líneas de log distorsionadas

Necesitas darte una idea de cuántas líneas de log de tu archivo no cumplen con los estándares actuales.
Crees que una prueba simple revela si una línea de log es válida.
Para considerarse válida, una línea debe comenzar con uno de los siguientes strings:

- `[DEBUG]`
- `[INFO]`
- `[WARNING]`
- `[ERROR]`

Implementa la función `is_valid_line` para que devuelva `True` si la línea de log es válida.

```gleam
log_parser.valid_line("[ERROR] Network Failure")
// -> True

log_parser.valid_line("Network Failure")
// -> False
```

## 2. Divide la línea de log

Poco después de comenzar el proyecto de análisis de logs, te das cuenta de que los logs de una aplicación no están divididos en líneas como los de las demás. En este proyecto, lo que deberían haber sido líneas separadas está en una sola línea, conectado por flechas elegantes como `<--->` o `<*~*~>`.

De hecho, cualquier string que tenga como primer carácter `<`, como último carácter `>`, y cero o más de los siguientes caracteres `~`, `*`, `=` y `-` en el medio, puede usarse como separador en los logs de este proyecto.

Implementa la función `split_line` que toma una línea y devuelve una lista de strings.

```gleam
log_parser.split_line("[INFO] Start.<*>[INFO] Processing...<~~~>[INFO] Success.")
// -> ["[INFO] Start.", "[INFO] Processing...", "[INFO] Success."]
```

## 3. Etiqueta las líneas con nombres de usuario

Has notado que algunas de las líneas de log incluyen oraciones que hacen referencia a usuarios.
Estas oraciones siempre contienen el string `"User"`, seguido de uno o más caracteres de espacio en blanco, y luego un nombre de usuario.
Decides etiquetar esas líneas.

Implementa una función `tag_with_user_name` que procese las líneas de log:

- Las líneas que no contienen el string `"User"` quedan sin cambios.
- Para las líneas que contienen el string `"User"`, antepón a la línea `[USER]` seguido del nombre de usuario.

```gleam
log_parser.tag_with_user_name("[INFO] User Alice created a new project")
// -> "[USER] Alice [INFO] User Alice created a new project"
```

Puedes asumir que:

- Cada aparición del string `"User"` va seguida de uno o más caracteres de espacio en blanco y del nombre de usuario.
- Hay como máximo una aparición del string `"User"` en cada línea.
- Los nombres de usuario son strings no vacíos que no contienen espacios en blanco.
