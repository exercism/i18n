# Flujo de trabajo de despliegue

El flujo de trabajo de despliegue se usa para desplegar las [herramientas del track](/docs/building/tooling) en:

1. [Docker Hub](https://hub.docker.com/): se usa en scripts o para pruebas locales.
   Disponible públicamente.
2. [ECR](https://aws.amazon.com/ecr/): se usa en el entorno de producción para probar las soluciones enviadas.
   Privado.

## Fuente

El flujo de trabajo se define en el archivo `.github/workflows/deploy.yml`.
