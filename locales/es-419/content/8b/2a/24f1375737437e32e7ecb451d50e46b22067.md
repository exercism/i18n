# Introducción

El filtrado es el proceso de crear una secuencia a partir de otra secuencia copiando todos los elementos de la secuencia original excepto algunos.
La decisión sobre qué elementos incluir en la nueva secuencia puede hacerse mediante una función predicado (una función que se evalúa a un valor Boolean), o mediante igualdad con un objeto específico.

## Eliminar mediante un predicado

`remove-if` es una función que toma una función predicado y una secuencia como argumentos, y devuelve una secuencia con solo aquellos elementos para los cuales el predicado se evaluó a un valor falso.
En otras palabras, «elimina» todos los elementos de la secuencia para los cuales el predicado se evalúa a verdadero. Sin embargo, ¡nota que esta función no modifica la secuencia original!
En cambio, devuelve una nueva secuencia sin los elementos correspondientes. Si el predicado era verdadero para todos los valores, se devuelve una secuencia vacía.

```lisp
(remove-if #'evenp '(1 2 3 4 5)) ; => (1 3 5)
(remove-if #'oddp '(1 3 5))      ; => ()
```

## Eliminar un elemento específico

Si quieres eliminar un elemento específico de una secuencia, puedes usar `remove`, que toma el elemento a eliminar y una secuencia.
Se devuelven todos los valores de la secuencia que no son iguales al elemento que se quiere eliminar.
NOTA: La igualdad se comprueba con el `eql` [predicado genérico de igualdad][concept-equality] de forma predeterminada.

```lisp
(remove 1 '(1 2 1 3 1 4)) ; => (2 3 4)
(remove #\l "hello")      ; => "heo"
```
