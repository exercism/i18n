# Introducción

## Iteradores

Un `Iterator` en Gleam es similar a una lista en que es una colección ordenada de valores, donde todos los valores son del mismo tipo. Se diferencia de una lista en que es perezoso, lo que significa que no almacena todos sus valores en memoria a la vez, sino que los calcula a medida que se necesitan.

Esto es útil cuando trabajas con secuencias que son muy grandes o incluso infinitas, ya que te permite trabajar con ellas cuando no tienes suficiente memoria libre para almacenarlas todas a la vez.

El módulo `gleam/iterator` define el tipo `Iterator`, así como funciones para trabajar con iteradores.

Muchas de las funciones para listas también existen para los iteradores, como `map`, `filter` y `take`. Estas funciones devuelven iteradores, así que en realidad no hacen ningún trabajo hasta que se consume el iterador.

```gleam
let iter = 
  [1, 2, 3, 4, 5, 6]
  |> iterator.from_list
  |> iterator.filter(fn(x) { x > 2 })
  |> iterator.take(2)

// No work has been done yet as the iterator has not been consumed

// Consume the iterator and collect the values into a list
iterator.to_list(iter)
// -> [3, 4]
```

La función `unfold` se puede usar para crear iteradores a partir de una función que se llama repetidamente para producir el siguiente valor de la secuencia.

Aquí se usa la función `unfold` para crear un iterador que produce la sucesión de Fibonacci:

```gleam 
iterator.unfold(#(0, 1), fn(pair) {
  let x = pair.0 + pair.1
  iterator.Next(element: x, accumulator: #(pair.1, x))
})
|> iterator.take(6)
|> iterator.to_list
// -> [1, 2, 3, 5, 8, 13]
```

La secuencia aquí es infinita, así que se usa la función `take` para hacerla finita antes de recopilar los valores en una lista. Si se llama a `to_list` en un iterador infinito, el programa se ejecutará hasta quedarse sin memoria y bloquearse.
