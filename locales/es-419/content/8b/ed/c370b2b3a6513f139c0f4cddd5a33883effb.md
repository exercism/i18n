# Pistas

## General

- La [documentación de la API de `Map`][map-docs] contiene una lista de los métodos disponibles en la interfaz `Map`.

## 1. Devuelve los códigos en un map

- Tendrás que definir un `Map` de [tal manera][declaring-members] que puedas usarlo en los métodos de la clase.

## 2. Agrega entradas al diccionario

- Los maps tienen un [método][map-put-docs] para agregar y actualizar el valor de una clave.

## 3. Busca el país de un código de marcación

- Los maps tienen un [método][map-get-docs] para obtener el valor de la clave.

## 4. No permitas duplicados

- Hay una forma de comprobar si el map tiene una [clave][map-contains-key-docs] o un [valor][map-contains-value-docs].

## 5. Encuentra el código de marcación de un país

- Hay una [forma][map-entry-set-docs] de obtener una colección iterable de entradas de un map, lo que te permite recorrer los pares clave-valor.

## 6. Actualiza el código de marcación del país

- No olvides que el código de marcación anterior del país seguirá estando en el map.
- Hay un [método][map-remove-docs] para eliminar una entrada del map.
