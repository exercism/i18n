# Introducción

Hay dos tipos diferentes de números en Gleam: los enteros y los números de punto flotante.

Los enteros son números que no tienen decimales.

```gleam
let integer = 3
// -> 3
```

También puedes agregar guiones bajos a los enteros para mayor claridad.

```gleam
1_000_000 // One million
```

Gleam tiene varios operadores que funcionan con enteros.

```gleam
1 + 1 // -> 2
5 - 1 // -> 4
5 / 2 // -> 2
3 * 3 // -> 9
5 % 2 // -> 1

2 > 1  // -> True
2 < 1  // -> False
2 >= 1 // -> True
2 <= 1 // -> False
```
