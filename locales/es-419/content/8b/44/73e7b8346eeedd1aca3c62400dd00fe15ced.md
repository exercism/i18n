## Tareas adicionales

Si intentas estas tareas, escribe tus propias pruebas para ellas en tu archivo de solución.

* Define una macro de string de modo que `isbn"3-598-21507-X" == ISBN("3-598-21507-X")`.

* Haz que el constructor acepte también los ISBN-13. El mismo ISBN debe ser igual sin importar el formato: `ISBN("1-234-56789-X") == ISBN("978-1-234-56789-7")`.

* Define una función o un iterador que genere un ISBN válido, quizás incluso a partir de un ISBN inicial dado.

 ¿Puedes guardar el ISBN como un entero en lugar de un string, y sería eso alguna vez una buena idea?
 Si lo hicieras, ¿podrías aún así imprimir el ISBN (incluido el dígito verificador) como un string?
