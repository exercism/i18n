# Instrucciones

Tu tarea es crear un verificador de contraseñas.
Un verificador de contraseñas valida la contraseña propuesta por un usuario para garantizar que cumple con un conjunto de requisitos definidos por la organización que controla el acceso al recurso en cuestión.

Para este ejercicio, los requisitos de la contraseña son:
* Debe tener 12 caracteres o más
* Debe tener al menos una letra mayúscula
* Debe tener al menos una letra minúscula
* Debe tener al menos un dígito
* Debe tener al menos un símbolo del conjunto !@#$%^&*

Tu solución debe usar un `Result` para encapsular el estado de éxito o de fallo.
Para el caso de éxito, el `Result` debe comunicar la contraseña validada como un string.
Para el caso de fallo, el `Result` debe comunicar la regla que se violó en ese caso.

~~~~exercism/note
Para este ejercicio, el verificador de contraseñas será simplista: solo indicará cuándo se ha violado una única regla.
Un ejercicio posterior explorará un verificador de contraseñas más realista que pueda indicar cuándo se han violado varias reglas a la vez.
~~~~

## 1. Implementa la función `checkPassword`

La función `checkPassword` verifica la contraseña dada contra las reglas mencionadas. En caso de fallo, indica la regla que se violó encapsulando uno de los valores de `PasswordRule` dentro del valor del resultado.

```fsharp
checkPassword "abcdefghij5#"
// => Error MissingUppercaseLetter
```

## 2. Implementa la ``getStatusMessage` función

La función `getStatusMessage` devuelve un string que contiene un mensaje legible para humanos que indica el significado del resultado devuelto por `checkPassword`.

```fsharp
getStatusMessage (Error MissingDigit)
// => "Error: does not have at least one digit"
```
