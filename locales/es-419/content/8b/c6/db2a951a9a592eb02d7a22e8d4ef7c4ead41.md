# Pistas

## General

- Lee sobre el [módulo `Agent`][getting-started-agent] en la guía de inicio.
- Lee la documentación sobre el [módulo `Agent`][elixir-doc-agent].
- Mira [ElixirCasts: Introduction to Agents][elixircasts-agent].

## 1. Abre el jardín

- Revisa la documentación de [`Agent`][elixir-doc-agent].
- La función que inicializa el estado del _proceso del agente_ debe devolver el estado inicial.

## 2. Lista los registros

- El módulo [`Agent`][elixir-doc-agent] contiene muchas funciones para obtener el estado actual del _proceso del agente_.

## 3. Registra parcelas a una persona

- El módulo [`Agent`][elixir-doc-agent] contiene funciones para obtener y actualizar el estado del _proceso del agente_.
- Por lo general, las funciones requieren una función que transforme el estado y devuelva una forma específica.
- Para llevar un registro del id de la próxima parcela por asignar, el estado de tu _proceso del agente_ debe llevar un registro de las parcelas y también del próximo id que usarás para una parcela.

## 4. Libera parcelas

- El módulo [`Agent`][elixir-doc-agent] contiene funciones para obtener y actualizar el estado del _proceso del agente_.
- Por lo general, las funciones requieren una función que transforme el estado y devuelva el estado siguiente.

## 5. Obtén una parcela registrada

- El módulo [`Agent`][elixir-doc-agent] contiene funciones para obtener el estado del _proceso del agente_.
- Obtén la parcela y luego maneja el resultado para devolver el resultado correcto.
