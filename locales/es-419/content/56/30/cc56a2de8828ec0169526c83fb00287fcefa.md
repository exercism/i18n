# Acerca de

De forma predeterminada, los valores en C# son _mutables_, es decir, pueden cambiar con el tiempo. Para hacer que un valor sea _inmutable_, tienes dos opciones:

1. Agregar el [modificador `const`][const-modifier].
2. Agregar el [modificador `readonly`][readonly-modifier].

El modificador `const` tiene algunas restricciones:

1. Solo se puede aplicar a tipos «constantes»: string, Boolean y números.
1. El valor `const` se debe inicializar de inmediato.

Consulta [definir constantes][defining-constants] para obtener más información.

Si tu valor es de un tipo no constante o necesitas inicializarlo en un constructor, puedes usar `readonly` para garantizar la inmutabilidad.
