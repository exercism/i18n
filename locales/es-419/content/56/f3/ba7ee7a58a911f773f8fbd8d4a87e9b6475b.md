# Introducción

Common Lisp permite al programador escribir «comentarios» que la computadora ignora.
Los comentarios de una sola línea empiezan con un punto y coma o varios (`;`) y, en ocasiones, puedes ver lo siguiente:

```lisp
(code...) ; => value
```

Donde el comentario se usa para indicar qué valor devuelve Common Lisp después de ejecutar el código de esa línea.

Es idiomático usar un solo punto y coma para un comentario breve al final de una línea, dos para un comentario más largo encima de una sección de código, tres para un comentario extenso que describe algo como una función, y cuatro para un comentario como el encabezado al inicio de un archivo fuente.
