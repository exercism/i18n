# Instalación

Este track se apoya en [Node.js][web-nodejs] para proporcionar un entorno de ejecución para WebAssembly.
Esto significa que asumimos que toda la ejecución de JavaScript en tu computadora ocurrirá usando [Node.js][web-nodejs].

## Requisitos del track

Muchas máquinas vienen con [Node.js][web-nodejs] preinstalado, o puede que ya se haya instalado antes, o como una dependencia.
Así que, antes de hacer nada, conviene comprobar si ya está instalado:

1. Abre una _terminal_ (`Terminal`, `cmd`, `Powershell`, `bash`, ...)
1. Ejecuta `node -v`

Si [Node.js][web-nodejs] está instalado, se mostrará una versión.
Anota esta versión.
Si [Node.js][web-nodejs] _no_ está instalado, se mostrará un error.
Por lo general, algo como `'node' is not recognised`.

## Node.js

### Si Node.js ya está preinstalado

Ve a [el sitio web de Node.js][web-nodejs].
Mostrará _dos_ versiones (si detecta tu sistema operativo; si no, selecciona primero tu sistema operativo).
Si la versión que te dio `node -v` coincide con una de ellas, todo bien.
Si no coincide, te recomendamos usar Node.js LTS.
Si te preocupa que actualizar pueda romper algo en tu sistema, puedes continuar como si todo estuviera bien;
sin embargo, es posible que no podamos ofrecer soporte si ocurre algo inesperado.

### Si Node.js no está instalado

Hay un par de maneras de instalar [Node.js][web-nodejs]:

- mediante un [instalador o binario][web-nodejs-download]
- mediante un [gestor de paquetes][web-nodejs-package]

Ambas opciones son compatibles con Windows, macOS y Linux. Si no sabes qué hacer, usar un instalador es lo más fácil.

- Te recomendamos usar la versión **LTS**. En el sitio web de [Node.js][web-nodejs] también aparece marcada como _recomendada_ «para la mayoría de los usuarios».
- Sigue las instrucciones de la página web o del instalador (o de ambos) e instala [Node.js][web-nodejs].

## Probar la instalación

Cuando el instalador termine, o el gestor de paquetes haya acabado, o se haya copiado el binario y se hayan seguido las instrucciones, es buena idea comprobar que todo esté bien.

1. Abre una _terminal_ (`Terminal`, `cmd`, `Powershell`, `bash`, ...)
1. Ejecuta `node -v`

La versión debe coincidir con la que aparece en el sitio web.

**Nota**: Es importante abrir una ventana de terminal _nueva_.
Puede que las ventanas de terminal que ya tienes abiertas no se hayan actualizado cuando terminó la instalación.
Eso significa que esas terminales no saben que se instaló un programa nuevo.

> _**Ayuda**_: `'node' is not recognised`
>
> Si usaste el instalador oficial, tu `PATH` debería haberse configurado automáticamente, pero si tu shell tiene problemas para encontrar tus módulos instalados globalmente, o si compilas Node.js desde el código fuente, actualiza tu `PATH` para incluir los binarios de `npm`.
>
> En macOS y Linux puedes lograrlo agregando lo siguiente a `~/.bash_profile` o a `~/.zshrc`:
>
> ```shell
> export PATH=/usr/local/share/npm/bin:$PATH
> ```
>
> En Windows, abre el menú de inicio y busca «environment variables».
> Tendrás que editar la entrada `PATH` y _agregar_ aquí la ruta a los binarios de `npm`.
> Por lo general, estos se encuentran en `C:\Program Files\nodejs`.
> Si navegas aquí con tu `File Explorer`, deberías encontrar `node.exe`, `npm.bat` y `npx.bat`.
>
> Cierra las terminales que tengas abiertas y abre una nueva.

## Requisitos del ejercicio

Sigue [estas instrucciones][cli-walkthrough] para descargar la CLI de Exercism para tu sistema operativo.

Una vez que la CLI esté configurada y lista, descarga el primer ejercicio, `hello-world`:

```shell
exercism download --exercise=hello-world --track=wasm
```

Después, cada ejercicio necesita algunas herramientas para ejecutar los tests.
Puedes instalarlas ejecutando este comando dentro de la carpeta de cada ejercicio:

```shell
npm install
```

> _**Ayuda**_: `'<package>' is missing / cannot be found`
>
> Si ves esto después de _actualizar_ tu ejercicio, bienvenido a npm 7.
> Elimina `node_modules` y `package-lock.json` y vuelve a ejecutar el comando para resolverlo.

Si te preocupa el espacio en disco y no te importa instalar otra herramienta, échale un vistazo a [pnpm](https://pnpm.io/), que garantiza que solo se instale en disco una copia de cada versión de paquete.
En ese caso, ejecuta `pnpm install` en lugar de `npm install`, y todo debería funcionar como se espera.

> **Pero ¿qué es npm y por qué funciona esto?**
>
> No necesitas esta información para completar el track de JavaScript, pero si tienes curiosidad por entender qué acaba de pasar, los siguientes párrafos son para ti:
>
> Esto funciona porque `npm` es un gestor de paquetes que viene incluido con Node.js, que se instaló siguiendo los pasos anteriores.
> El comando `npm` busca un archivo `package.json`, que está presente en _cada_ carpeta de ejercicio.
> Este archivo lista las `"dependencies"` de arriba, que luego `npm` descarga y coloca en la carpeta `node_modules`.
>
> Los scripts del `package.json` usan los binarios de la carpeta local `node_modules`, y son esos scripts los que se usan para ejecutar los tests, como se indica en la descripción del `exercise`.
