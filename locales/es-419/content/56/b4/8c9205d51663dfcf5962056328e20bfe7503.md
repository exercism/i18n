# Instrucciones

La Bellebrook Basketball League es una liga con varios equipos, cada uno con una plantilla de jugadores.
Está a punto de comenzar una nueva temporada y necesitan crear un nuevo sistema de venta de entradas para vender entradas para los partidos.
La temporada pasada vendían las entradas en la puerta del estadio, pero la popularidad se disparó y este año decidieron venderlas en línea para atender la creciente demanda.

La liga se ha puesto en contacto contigo y te ha pedido que crees un sistema para gestionar la venta de entradas.

## 1. Crea un sistema de venta de entradas

Primero, necesitas crear un sistema de venta de entradas para gestionar las ventas.
El sistema debe indicar cuántas entradas hay disponibles para un partido.

Se debe crear una instancia de una clase llamada `TicketSystem` para cada partido.
El estado inicializado debe contener la siguiente información:

1. Cuántas entradas hay disponibles para el partido.
2. En qué estadio se juega el partido.

Construye un estado inicializado a partir de argumentos que indiquen la cantidad de entradas disponibles y en qué estadio se juega el partido.
El estado inicializado debe constar de las variables de instancia `@tickets_available` y `@stadium`.
Estas deben contener el primer y el segundo argumento dados, respectivamente.

```crystal
TicketSystem.new(100, "Bellebrook")
# => #<TicketSystem:0x10f0b8 @tickets_available=100, @stadium="Bellebrook">
```

## 2. Obtén la cantidad de entradas disponibles

Primero, necesitas crear un método que devuelva la cantidad de entradas disponibles para un partido dado.

Define un módulo llamado `TicketingReservation` antes de la clase ya definida.
Este módulo debe incluirse en la clase `TicketSystem`.

Dentro del módulo, define un método llamado `tickets_available`.
Este método debe devolver la cantidad de entradas disponibles.

```crystal
ticket_system = TicketSystem.new(100)
ticket_system.tickets_available
#=> 100
```

## 3. Haz un pedido de entradas

Debes crear un método que verifique si hay entradas disponibles para un partido dado.
El partido necesita tener 100 entradas en reserva.
Esto es para asegurar que siempre haya entradas disponibles para las personas que compran entradas en la puerta del estadio.

Dentro del módulo `TicketingReservation`, define un método llamado `order_ticket?`.
El método debe devolver `true` si hay al menos 100 entradas disponibles y `false` en caso contrario.
Si hay al menos 100 entradas disponibles, el método también debe disminuir en 1 la cantidad de entradas disponibles.

```crystal
ticket_system = TicketSystem.new(100)
ticket_system.order_ticket?
#=> true
```

## 4. Mensaje del pedido

El sistema de venta de entradas debe tener mensajes fáciles de entender para los usuarios.
Además, los mensajes deben sentirse personales, así que deben incluir el nombre del usuario.

Si la compra de la entrada fue exitosa, el usuario debe recibir un mensaje que le indique que la compra fue exitosa, cuál es su número de entrada y en qué estadio se juega el partido.
El número de entrada debe ser la cantidad de entradas disponibles antes del pedido.

Si la compra fue exitosa, el mensaje debe verse así: `{name}, your purchase was successful, your ticket number is #{ticket_number}, and the game is played at the {stadium_name} stadium.`.
Si la compra no fue exitosa, el mensaje debe verse así: `{name}, your purchase was unsuccessful, there are not enough tickets available.`.

Dentro del módulo `TicketingReservation,` define un método llamado `order_message` que reciba un argumento `name` con el nombre de la persona que compra.
El método debe devolver una cadena con el mensaje.

```crystal
ticket_system = TicketSystem.new(100, "Bellebrook")
ticket_system.order_message("John")
#=> "John, your purchase was successful, your ticket number is #100, and the game is played at the Bellebrook stadium."
```
