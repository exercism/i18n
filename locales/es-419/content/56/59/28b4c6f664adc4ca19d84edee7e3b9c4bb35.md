# Parámetros variádicos

Los [_parámetros variádicos_][variadic-parameters] en Swift permiten pasar cero o más valores del mismo tipo a un solo parámetro de una función. Esto se indica agregando `...` a la anotación de tipo del parámetro.

Estos valores se agrupan automáticamente en un array cuyos elementos son del mismo tipo que el del parámetro variádico.

```swift
func geometricMean(_ numbers: Double...) -> Double {
  var total = 1.0
  for number in numbers {
      total *= number
  }
  return pow(total, 1.0 / Double(numbers.count))
}

geometricMean(1, 2, 3, 4, 5)
// => 2.605171084697352
```

Ten en cuenta que Swift tiene una limitación al usar parámetros variádicos.
Si una función tiene parámetros que van después del parámetro variádico en la definición, es _obligatorio_ que el primer parámetro que sigue al parámetro variádico tenga una etiqueta de argumento.

[variadic-parameters]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/functions/#Variadic-Parameters
