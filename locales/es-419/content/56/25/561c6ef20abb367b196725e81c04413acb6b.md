# Instalación

Para obtener las instrucciones de instalación recomendadas para tu plataforma,
visita [el sitio oficial de Rust][the official Rust website].

¡Tener la cadena de herramientas instalada no lo es todo!
El soporte para IDE es un enorme impulso de productividad que la mayoría de los desarrolladores ya da por sentado.
Si usas Visual Studio Code, échale un vistazo a su [documentación para el soporte de Rust][vscode].
¡Además, te recomendamos de todo corazón que habilites el [linting con clippy][vscode-linting]!

[the official Rust website]: https://www.rust-lang.org/tools/install
[vscode]: https://code.visualstudio.com/docs/languages/rust
[vscode-linting]: https://code.visualstudio.com/docs/languages/rust#_linting
