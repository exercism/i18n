# Pistas

## General

- `matches?`, `all-matching-subseqs`, `count-matches` y
  `re-replace` viven en [`regexp`][regexp]. Escribe cada patrón como un
  literal entre `R/ ` y `/`.
- Un código de insignia válido son dos mayúsculas, un guion y cuatro dígitos:
  `R/ [A-Z]{2}-\d{4}/`.

## 1. Verifica un código de insignia

- `matches?` prueba el string *completo*, que es exactamente lo que se necesita
  para responder «¿es un código de insignia válido?»: `R/ [A-Z]{2}-\d{4}/ matches?`.

## 2. Extrae cada código de una línea de log

- `all-matching-subseqs` devuelve cada coincidencia como una secuencia de
  strings; pásale el mismo patrón de código de insignia.

## 3. Cuenta los dígitos de un código

- `\d` coincide con un dígito; `count-matches` cuenta cuántas veces coincide el
  patrón: `R/ \d/ count-matches`.

## 4. Oculta las contraseñas

- `\S` significa «un carácter que no es un espacio», así que `R/ pass=\S+/` coincide con
  `pass=` más el secreto que le sigue.
- `re-replace` recibe el string, el patrón y el texto de reemplazo
  `"pass=****"`.

[regexp]: https://docs.factorcode.org/content/vocab-regexp.html
