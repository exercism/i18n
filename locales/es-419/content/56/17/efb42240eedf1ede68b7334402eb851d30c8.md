# Instrucciones

En este ejercicio, vas a aplicar las [reglas del juego de Go](https://matmoore.github.io/learngo/). Las reglas ya están escritas, solo necesitas aplicarlas para actualizar el Game y manejar cualquier error o violación de las reglas.

El juego se representa de la siguiente manera:

```gleam
pub type Player {
  Black
  White
}


pub type Game {
  Game(
    white_captured_stones: Int,
    black_captured_stones: Int,
    player: Player,
    error: String,
  )
}
```

Hay 4 reglas en el juego:

- Cada punto solo puede tener una piedra.
- Las piedras del oponente se pueden capturar.
- No puedes colocar una piedra donde se capturaría a sí misma.
- No puedes usar el mismo punto dos veces.

## 1. Aplica las reglas

Escribe el contenido de la función `apply_rules`, que recibe un `Game` inicial y un conjunto de reglas, y devuelve el nuevo `Game` después de aplicar las reglas.

Tres de las reglas verifican si se violan las reglas y pueden devolver un error, por lo que tienen el tipo de retorno `Result(Game, String)`. Si alguna de estas reglas falla, se debe devolver el juego original, pero con el campo `error` actualizado con el error correspondiente.

La otra regla no verifica si hay violaciones, así que no puede fallar (aunque puede devolver un `Game` modificado), y por eso tiene el tipo de retorno `Game`.

Si todas las reglas pasan, se deben conservar los cambios que las reglas hicieron en `Game` y se debe cambiar el jugador.

```gleam
pub fn apply_rules(
  game: Game,
  rule1: fn(Game) -> Result(Game, String),
  rule2: fn(Game) -> Game,
  rule3: fn(Game) -> Result(Game, String),
  rule4: fn(Game) -> Result(Game, String),
) -> Game {
  // -> If all rules pass, return a `Game` with all changes from the rules applied, and change player
  // -> If any rule fails, return the original Game, but with the error field set
}
```
