# Acerca de

[Las listas][list] son un tipo de dato básico en Haskell para contener una colección de valores.
Las listas son _inmutables_, lo que significa que no se pueden modificar.
Cualquier operación que cambie una lista devuelve una lista nueva.
Hay varias funciones en el Prelude que te permiten trabajar con listas.

Las listas en Haskell se implementan como [listas enlazadas][linked-list-wiki], y no como arrays de ubicaciones de memoria contiguas.
Por lo tanto, acceder a un elemento de una lista toma tiempo lineal dependiendo de la longitud de la lista.

Las listas se pueden escribir en forma literal, en notación cabeza-cola (que usa el operador `cons` `:`), o en una combinación de ambas:

```haskell
-- Literal Form
[]
[1]
[1, 2, 3]

-- Head-tail Notation
[]
-- same as [1]
1 : []
-- same as [1, 2, 3]
1 : (2 : (3 : []))

-- Mixed
-- same as [1, 2, 3]
1 : [2, 3]
```

La notación cabeza-cola se puede usar para agregar elementos a una lista.

```haskell
list = [2, 1]

[3, 2, 1] == 3 : list
-- -> True
```

Agregar elementos a una lista durante la iteración se considera un antipatrón.
Agregar un elemento requiere recorrer toda la lista y agregar el elemento al final; por lo tanto, agregar un elemento nuevo en cada iteración requeriría recorrer toda la lista en cada iteración.

Podemos lograr el mismo resultado si anteponemos un elemento a la lista invertida y luego invertimos el resultado.
Anteponer es una operación rápida y requiere tiempo constante.

```haskell
-- Appending to the end of a list (potentially slow)
[1, 2, 3] ++ [4] ++ [5] ++ [6]

-- Prepend to the start of a list (faster, due to the nature of linked lists)
6 : (5 : (4 : [3, 2, 1]))
-- then reverse!
```

Hay varias funciones comunes del Prelude para listas:

- [`head`][head] devuelve la _cabeza_ de una lista: el _primer_ elemento de la lista.
- [`tail`][tail] devuelve la _cola_ de la lista: la lista _sin_ el _primer_ elemento.
- [`length`][length] devuelve el número de elementos de la lista.
- [`elem`][elem] devuelve un valor Boolean que indica si el elemento está en la lista.

También está el [módulo `Data.List`][list].

## Tipos de listas

En Haskell, las listas son **homogéneas**.
Esto significa que todos los elementos de una lista tienen el mismo tipo.
Cuando intentas poner elementos de diferentes tipos en la misma lista, obtienes un error de tipo.

```haskell
list = [1, "string"]
-- Error: No instance for (Num String) arising from the literal ‘1’
```

La anotación de tipo de una lista es `[a]`, donde a es el tipo que contiene la lista, por ejemplo `String` o `Int`.

``` haskell
a :: [Int] 
a = [1, 2, 3]
```
