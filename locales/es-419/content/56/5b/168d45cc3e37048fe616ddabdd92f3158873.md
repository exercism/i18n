# Introducción

Go es de tipado estático, así que toda variable tiene un tipo que se conoce en tiempo de compilación.
Una vez declarada, el tipo de una variable no puede cambiar.

## Crear una variable

La sentencia `var` puede declarar el tipo de una variable nueva, establecer su valor o hacer ambas cosas a la vez:

```go
var total int     // Type explicitly declared, value implicitly set (see note on zero values below)
var count int = 1 // Type explicitly declared, value explicitly set
var sum = 100     // Type implictly declared, value explicitly set
```

Dentro de una función, también puedes usar la sentencia de asignación corta `:=`.

```go
count := 1 // Type implictly declared, value explicitly set
```

Una variable en Go siempre tiene un valor.
Si no se establece uno en la declaración, Go proporciona uno [llamado valor cero][zero-values], según el tipo de la variable.

```go
var total int     // 0
var name string   // ""
var ready bool    // false
```

## Actualizar una variable

Dentro de una función, el operador de asignación `=` puede establecer un nuevo valor para una variable que ya existe:

```go
count := 1
count = 2
```

El nuevo valor debe tener el mismo tipo que la variable:

```go
count := 1
count = false // compile error: a Boolean is not an int
```

[zero-values]: https://exercism.org/tracks/go/concepts/zero-values
