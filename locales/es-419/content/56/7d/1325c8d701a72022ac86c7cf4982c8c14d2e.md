# Acerca de

`Sed` es una herramienta tradicional y un lenguaje de programación de los sistemas Unix que se usa para hacer transformaciones de texto sobre un flujo de entrada (un archivo o la entrada de una tubería), haciendo una sola pasada sobre la entrada y leyendo el texto línea por línea. Este track se enfoca en `sed` como lenguaje de programación.

## Características principales
+ Comando de sustitución `s/<REGEX>/[REPLACEMENT]/[FLAGS]`.
+ [Expresiones regulares][regex-wiki].
+ Dos variables: **espacio de patrón** y **espacio de retención**.
+ Control de flujo usando instrucciones similares a goto, *regex* y direcciones de línea.

## Variantes
`Sed` se desarrolló en 1974 y tiene algunas implementaciones clásicas. Este track usará la implementación de [GNU Sed][sed-home] junto con todas las extensiones de *GNU* y las [ERE (expresiones regulares extendidas)][ere-info].
