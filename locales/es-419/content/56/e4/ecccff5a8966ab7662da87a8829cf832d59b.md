# Introducción

Una expresión Boolean es una pregunta que se le hace a uno o más valores y que se puede responder con `true` o `false`.
Una expresión verdadera devuelve `1`; una expresión falsa devuelve `0`.
Además, los números tienen valores true/false. El cero es `false`; cualquier valor distinto de cero es `true`.

El código C antiguo usa directamente el tipo `int` para los valores Boolean, o bien el programador define constantes como `TRUE` y `FALSE` para asociar `1` y `0` a una representación Boolean.

Con la versión C99 se agregó el tipo `_Bool`.
El archivo de encabezado `stdbool.h` define tres nuevos símbolos Boolean: `bool`; `true` y `false`.
`true` corresponde a `1`; `false` corresponde a `0`; y `bool` corresponde a `_Bool`.
Así que ahora, en lugar de usar `int` directamente o de crear sus propias equivalencias Boolean, los programadores pueden incluir `stdbool.h` y obtener automáticamente símbolos Boolean en su código.

## Operadores de comparación

C admite seis operadores de comparación: `==` (igual), `!=` (distinto), `>` (mayor que), `<` (menor que), `>=`(mayor o igual que), `<=` (menor o igual que).
Estos operadores comparan las relaciones entre valores y las resuelven en valores Boolean.

```c
0 == 0 // true. Although 0 is false, 0 equals 0 is true.
0 != 0 // false
1 > 0 // true
1 < 0 // false
1 >= 0 // true
1 <= 0 // false
```

## Operadores Boolean

C admite tres operadores Boolean: `||` (o), `&&` (y), y `!` (no).

`!` se usa con un operando.
Invierte el valor Boolean del operando.
Por ejemplo, `0` es `false`, pero `!0` es `true`.

`||` y `&&` se usan con dos operandos.
El operando de la derecha solo se evalúa cuando el operando de la izquierda todavía no determina el resultado de la expresión.
Es decir, `||` solo evalúa su operando de la derecha cuando su operando de la izquierda se evalúa como `false`.
`&&` solo evalúa su operando de la derecha cuando su operando de la izquierda se evalúa como `true`.
