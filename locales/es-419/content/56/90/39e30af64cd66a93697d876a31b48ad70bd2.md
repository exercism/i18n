# Instala `testthat`

Las pruebas de este track usan el paquete `testthat`.

Para instalar el paquete, simplemente abre R y ejecuta:

`install.packages("testthat")`

Puedes verificar que el paquete se instaló correctamente ejecutando:

`library(testthat)`

# Ejecutar las pruebas

Cada problema tendrá un script llamado `test_<exercise-name>.R` (por ejemplo, `test_hello-world.R`).

Para ejecutar las pruebas de un ejercicio, simplemente ejecuta este script de R.

En RStudio, esto es tan simple como abrir el script de prueba y hacer clic en «Source» en la parte superior derecha del panel de código. Esto cargará tu código de solución mediante el comando `source` de la primera línea del script de prueba, y luego ejecutará el conjunto de pruebas de `testthat` que siguen.

Ten en cuenta, sin embargo, que el comando `source()` de la primera línea del script de prueba solo funcionará si tu script de solución (`<exercise-name>.R`) está en tu directorio de trabajo. Si no es así, tendrás que hacer una de estas dos cosas:
- cambiar tu directorio de trabajo, por ejemplo `setwd('exercism/r/hello-world/')`, o
- actualizar la primera línea del script de prueba, por ejemplo `source('exercism/r/hello-world/hello-world.R')`

Si lo prefieres, también puedes ejecutar las pruebas desde la línea de comandos con `Rscript path_to_exercise_directory/test_<exercise-name>.R` (por ejemplo, `Rscript hello-world/test_hello-world.R`)

Otra forma cómoda de ejecutar estas pruebas es usar [la función `auto_test` de testthat](https://www.rdocumentation.org/packages/testthat/topics/auto_test). Como el código y las pruebas de Exercism están en la misma carpeta, usa esa misma ruta para los parámetros `code_path` y `test_path`. Después de ejecutar `auto_test()`, las pruebas del ejercicio se ejecutarán automáticamente cada vez que actualices o guardes tu código de R para el ejercicio. Esto puede ayudarte a iterar rápidamente mientras trabajas en tu solución.
