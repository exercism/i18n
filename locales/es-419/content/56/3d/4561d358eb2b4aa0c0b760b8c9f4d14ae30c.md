# Aprendizaje

Si quieres aprender TypeScript, revisa los siguientes recursos.

- [TS Tutorial](https://www.typescriptlang.org/docs/handbook/release-notes/overview.html)
- [TS Playground](https://www.typescriptlang.org/play)

TypeScript es un superconjunto de JS.
TypeScript ofrece todas las características de JavaScript, y una capa adicional sobre estas: el sistema de tipos de TypeScript.

- [Exploring ES6](https://leanpub.com/exploring-es6) libro, de Axel Rauschmayer
- [ES6 Katas](https://jskatas.org/#bundle-es6-katas) sitio web
- [Babel compiler](https://github.com/babel/babel)
