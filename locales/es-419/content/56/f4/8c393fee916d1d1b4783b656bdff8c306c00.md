# Instrucciones

En este ejercicio escribirás código para imprimir gafetes con los nombres de los empleados de una fábrica. Los empleados tienen un ID, un nombre y el nombre de su departamento. Las etiquetas de los gafetes de los empleados tienen el siguiente formato: `"[id] - name - DEPARTMENT"`.

## 1. Imprime un gafete para un empleado

Implementa la función `NameBadge.print/3`. Debe recibir un ID, un nombre y un departamento. Debe devolver la etiqueta del gafete, con el nombre del departamento en mayúsculas.

```elixir
NameBadge.print(67, "Katherine Williams", "Strategic Communication")
# => "[67] - Katherine Williams - STRATEGIC COMMUNICATION"
```

## 2. Imprime un gafete para un empleado nuevo

Debido a una peculiaridad en el sistema de la computadora, en ocasiones los empleados nuevos todavía no tienen un ID cuando empiezan a trabajar en la fábrica. Como los gafetes son obligatorios, recibirán un gafete temporal sin el prefijo del ID.

Extiende la función `NameBadge.print/3`. Cuando falte el ID, debe imprimir un gafete sin él.

```elixir
NameBadge.print(nil, "Robert Johnson", "Procurement")
# => "Robert Johnson - PROCUREMENT"
```

## 3. Imprime un gafete para el dueño

Incluso el dueño de la fábrica tiene que llevar un gafete en todo momento. Sin embargo, un dueño no tiene un departamento. En este caso, la etiqueta debe imprimir `"OWNER"` en lugar del nombre del departamento.

Extiende la función `NameBadge.print/3`. Cuando falte el departamento, asume que el gafete pertenece al dueño de la empresa.

```elixir
NameBadge.print(204, "Rachel Miller", nil)
# => "[204] - Rachel Miller - OWNER"
```

Fíjate que es posible que el dueño también sea un empleado nuevo.

```elixir
NameBadge.print(nil, "Rachel Miller", nil)
# => "Rachel Miller - OWNER"
```
