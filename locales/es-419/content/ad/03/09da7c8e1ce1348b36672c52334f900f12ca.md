# Instrucciones

A Lilly le encanta cocinar.
Quiere hacer una fiesta de pizza con sus amigos.
Para aprovechar al máximo sus ingredientes, necesita saber cuánto de cada ingrediente requiere antes de empezar.

Para resolver esto, Lilly redactó un programa que automatiza parte de la planeación, pero necesita tu ayuda para terminarlo.
¿Ayudarás a Lilly a hacer una fiesta de pizza con las proporciones perfectas?

## 1. Una proporción de masa

A Lilly le encantan las pizzas delgadas y crujientes, con una corteza más fina.
La masa necesaria para el centro es de 200 g como mínimo, pero cada persona a la que sirve requiere 20 g más de masa.

`grams = pizzas * ((persons * 20) + 200)`

Lilly necesita una función que:

- Reciba el número de pizzas
- El número de personas a las que servirá cada pizza
- Y devuelva la masa necesaria redondeada al gramo más cercano.

Por ejemplo, para hacer 4 pizzas que alimentan a 8 personas:

```php
<?php

$pizza_pi = new PizzaPi();
$pizza_pi->calculateDoughRequirement(4, 8);
// => 1440
```

## 2. Un toque de salsa

Lilly es meticulosa al aplicar su salsa, pero el tamaño de sus pizzas puede ser irregular.
Por experiencia, sabe que se necesitan 125 mL de salsa por pizza.
Lilly necesita una función que calcule cuántas latas de salsa comprar.

`cans of sauce = pizzas * sauce per pizza / sauce can volume`

Por ejemplo, dado que Lilly necesita hacer 8 pizzas y cada lata es de 250 mL:

```php
<?php

$pizza_pi = new PizzaPi();
$pizza_pi->calculateSauceRequirement(8, 250);
// => 4
```

## 3. Un poco de queso, por favor

El queso viene en cubos perfectos y se vende por tamaño.

La fórmula que usa Lilly no es la fórmula del área de la pizza, ya que ella _no_ quiere que el queso cubra toda el área.
Decidió usar la siguiente fórmula para determinar cuántas pizzas de cierto diámetro (`diameter`) se pueden hacer con un cubo de queso de cierta longitud de lado (`cheese_dimension`):

`pizzas = (cheese_dimension³) / (thickness * PI * diameter)`

Crea una función que:

- Reciba la longitud del lado de un cubo de queso
- Reciba el grosor deseado de la capa de queso
- Reciba el diámetro de la pizza
- Y use la fórmula de Lilly para devolver el número de pizzas que se pueden hacer, redondeando hacia abajo.

Por ejemplo, dado un cubo de queso de 25x25x25 cm, una capa de queso de 0.5 cm de grosor y pizzas de 30 cm de diámetro:

```php
<?php

$pizza_pi = new PizzaPi();
$pizza_pi->calculateCheeseCubeCoverage(25, 0.5, 30);
// => 331
```

## 4. Un reparto justo

Por último, Lilly quiere que sus pizzas se dividan en 8 rebanadas cada una y se distribuyan de manera uniforme entre sus amigos.

Crea una función que:

- Reciba un número de pizzas y un número de amigos
- y devuelva el número de rebanadas que sobrarán si cada persona toma la misma cantidad de rebanadas.

Por ejemplo:

```php
<?php

$pizza_pi = new PizzaPi();
$pizza_pi->calculateLeftOverSlices(2, 4);
// => 0
$pizza_pi->calculateLeftOverSlices(4, 3);
// => 2
```
