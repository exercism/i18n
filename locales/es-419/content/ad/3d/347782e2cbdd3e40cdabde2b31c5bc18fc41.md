# Instrucciones

Dado un número de 0 a 999,999,999,999, escribe ese número con palabras en inglés.

## Paso 1

Resuelve el caso básico de 0 a 99.

Si la entrada al programa es `22`, la salida debe ser `'twenty-two'`.

Tu programa debe quejarse a gritos si recibe un número fuera del rango permitido.

Algunos buenos casos de prueba para este programa son:

- 0
- 14
- 50
- 98
- -1
- 100

### Extensión

Si usas una Mac, invoca el programa `say` de Mac OS X desde la terminal para hablar en voz alta.
Si usas Linux o Windows, puede que eSpeakNG esté disponible con el comando `espeak`.

## Paso 2

Implementa la división de un número en grupos de miles.

Así, `1234567890` debe producir una lista como 1, 234, 567 y 890, mientras que el mucho más simple `1000` debe producir solo 1 y 0.

## Paso 3

Ahora encárgate de insertar la palabra de escala adecuada entre esos grupos.

Así, `1234567890` debe producir `'1 billion 234 million 567 thousand 890'`

El programa también debe reportar cualquier valor que esté fuera de rango.
Está bien detenerse en "trillion".

## Paso 4

Ponlo todo junto para obtener nada más que inglés simple.

`12345` debe producir `twelve thousand three hundred forty-five`.

El programa también debe reportar cualquier valor que esté fuera de rango.
