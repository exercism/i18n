# Anexo de instrucciones

## Valor máximo de un entero

Según [la documentación de Vim][number]:

> Suponiendo que se usan números de 64 bits (consulta v:numbersize), un número sin signo se trunca a 0x7fffffffffffffff o 9223372036854775807.

En otras palabras, Vim script no puede expresar ningún número `2^63` o mayor como un entero.

Algunas de las pruebas de este ejercicio requieren enteros de 64 bits, lo cual supera la limitación de tamaño de entero de Vim script.
Debido a esta limitación, los resultados de los cálculos se comparan con un string que expresa el valor entero, en lugar de expresar la respuesta como Integer.
¿Puedes resolverlo evitando usar directamente números más grandes de lo que el lenguaje permite?

[number]: https://vimhelp.org/eval.txt.html#expr-number
