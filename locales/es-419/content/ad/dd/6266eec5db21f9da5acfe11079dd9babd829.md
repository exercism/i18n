# Introducción

## Structs

Los structs son una extensión construida sobre los [mapas][exercism-maps], que proporcionan verificaciones en tiempo de compilación y valores predeterminados. Un struct recibe el nombre del módulo en el que se define. Para definir un struct, usa la construcción `defstruct`. Por lo general, la construcción va inmediatamente después de la definición del módulo. `defstruct` acepta una lista de átomos (para valores predeterminados `nil`) o una lista de palabras clave (para valores predeterminados especificados). Los campos sin valores predeterminados deben ir antes que los campos con valores predeterminados.

```elixir
defmodule Plane do
  defstruct [:engine, wings: 2]
end

plane = %Plane{}
# => %Plane{engine: nil, wings: 2}
```

### Acceder a los campos y actualizarlos

Como los structs se construyen sobre mapas, podemos usar la mayoría de las funciones de mapas para obtener y manipular valores. El _Access Behaviour_ **no** está implementado para los structs. En su lugar, se recomienda usar el _operador de acceso estático_ `.` para acceder a los campos del struct.

- obtener/consultar los valores de los campos:

  ```elixir
  plane = %Plane{}
  plane.engine
  # => nil
  Map.fetch(plane, :wings)
  # => {:ok, 2}
  ```

- actualizar los valores de los campos

  ```elixir
  plane = %Plane{}
  %{plane | wings: 4}
  # => %Plane{engine: nil, wings: 4}
  ```

### Coincidencia de patrones

Los structs se pueden usar en la coincidencia de patrones con o sin el nombre del struct.

```elixir
plane = %Plane{}
%Plane{wings: wings} = plane
%{wings: wings} = plane
```

Al incluir el nombre del struct en el patrón, puedes asegurarte de que tanto el lado izquierdo como el derecho sean structs del mismo tipo.

```elixir
defmodule Helicopter do
  defstruct [:engine, rotors: 1]
end

%Plane{} = %Helicopter{}
# => (MatchError) no match of right hand side value: %Helicopter{engine: nil, rotors: 1}
```

### Exigir la inicialización de los valores de los campos

Podemos usar el atributo de módulo `@enforce_keys` con una lista de las claves de los campos para asegurarnos de que los valores se inicialicen cuando se crea el struct. Si una clave no está en la lista, su valor será `nil`, como se vio en el ejemplo anterior. Si una clave exigida no se inicializa, se produce un error.

```elixir
defmodule User do
  @enforce_keys [:username]
  defstruct [:username]
end

%User{}
# => (ArgumentError) the following keys must also be given when building struct User: [:username]
```
