# Anexo de instrucciones

## Pistas

Para completar este ejercicio necesitas crear el tipo de datos `School`
e implementar las siguientes funciones:

- `add`
- `empty`
- `grade`
- `sorted`

Ya encontrarás una declaración de datos ficticia y las firmas de tipo en su
lugar, pero depende de ti definir las funciones y crear un tipo de datos,
un newtype o un sinónimo de tipo que tenga sentido.
