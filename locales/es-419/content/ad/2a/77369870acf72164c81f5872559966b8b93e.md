# Introducción

## Alias de tipo

Un alias de tipo se puede usar en Gleam para darle un nombre cómodo a un tipo que ya existe y que de otro modo sería engorroso de escribir.

```gleam
pub type Headers =
  List(#(String, String))

pub fn html_headers() -> Headers {
  [
    #("content-type", "text/html"),
    #("x-frame-options", "DENY"),
  ]
}
```

Cuando se escribe con `pub type`, el alias se puede usar fuera del módulo en el que se define. Si omites `pub`, el alias es privado y no se puede hacer referencia a él en otros módulos.
