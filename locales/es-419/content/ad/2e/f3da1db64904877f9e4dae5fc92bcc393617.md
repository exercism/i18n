# Introducción

## Funciones matemáticas

Las raíces cuadradas, los ángulos y las curvas de crecimiento son difíciles de calcular solo con `+`, `-`, `*` y `/`. El vocabulario [`math.functions`][math.functions] tiene palabras que los calculan por ti, y [`math.constants`][math.constants] tiene π. Como cualquier otra palabra, cada una toma sus argumentos de la pila y deja allí su respuesta.

## Raíces cuadradas

```
sqrt ( x -- y )
```

```factor
USING: kernel math math.constants math.functions math.libm prettyprint ;

9 sqrt .     ! => 3.0
2 sqrt .     ! => 1.4142135623730951
```

Una escalera de 5 metros de largo, con el pie a 3 metros de una pared, alcanza 4 metros de altura en la pared:

```factor
5 sq 3 sq - sqrt .   ! => 4.0
```

## Pi

`pi` (de `math.constants`) empuja π, el número de veces que el diámetro de un círculo cabe a lo largo de su borde:

```factor
: wheel-edge ( diameter -- edge ) pi * ;

2 wheel-edge .   ! => 6.283185307179586
```

## Los ángulos van en radianes

```
sin ( x -- y )
cos ( x -- y )
tan ( x -- y )
```

`sin`, `cos` y `tan` toman un ángulo, pero no en grados. Usan **radianes**, donde media vuelta es π y no 180. Pasarles grados no es un error: te da la respuesta equivocada sin avisar.

`deg>rad` convierte grados a radianes, y `rad>deg` hace la conversión inversa. Equivale a multiplicar por π y dividir entre 180, o al revés:

```
deg>rad ( x -- y )
rad>deg ( x -- y )
```

```factor
30 deg>rad .       ! => 0.5235987755982988
30 pi * 180 / .    ! => 0.5235987755982988
pi rad>deg .       ! => 180.0
```

Convierte los grados a radianes antes de llamar a `sin`:

```factor
: ramp-rise ( length degrees -- rise ) deg>rad sin * ;

10 30 ramp-rise .   ! => 4.999999999999999
```

Una rampa de 10 metros de largo a 30 grados sube 5 metros. La respuesta se imprime como `4.999999999999999` porque las funciones matemáticas dan el número de punto flotante más cercano, no el valor exacto. Sin la conversión, `30 sin` trata 30 como radianes (casi cinco vueltas completas) y la rampa «subiría» `-9.88` metros.

## Encontrar un ángulo

`fatan2` hace lo contrario: dadas la distancia *vertical* y la distancia *horizontal*, devuelve el ángulo en radianes. Está en [`math.libm`][math.libm]. La distancia *vertical* va primero en la pila, y luego la distancia *horizontal*:

```
fatan2 ( y x -- radians )
```

```factor
1.0 1.0 fatan2 .              ! => 0.7853981633974483
1.0 1.0 fatan2 rad>deg .      ! => 45.0
-1.0 -1.0 fatan2 rad>deg .    ! => -135.0
0.0 -1.0 fatan2 rad>deg .     ! => 180.0
```

El ángulo se mide desde la dirección *horizontal* positiva. `fatan2` se fija en los signos de ambas distancias, así que puede responder en cualquier punto entre −180 y 180 grados.

## Potencias de diez: 10^ y log10

`10^` eleva 10 a una potencia:

```factor
5 10^ .     ! => 100000
2 10^ .     ! => 100
0.5 10^ .   ! => 3.1622776601683795
```

`log10` hace el camino inverso. Responde a la pregunta «¿a qué potencia hay que elevar 10 para obtener este número?». Esa respuesta es el **logaritmo** del número:

```factor
100000 log10 .   ! => 5.0
100 log10 .      ! => 2.0
1 log10 .        ! => 0.0
0.001 log10 .    ! => -3.0
```

## e^ y log

`e^` y `log` son el mismo par, con *e* (aproximadamente 2.718) en lugar de 10. `e^` eleva *e* a una potencia, y `log` responde «¿a qué potencia hay que elevar *e* para obtener este número?».

```
e^  ( x -- y )
log ( x -- y )
```

Los matemáticos usan *e* para todo lo que crece o se reduce en la misma fracción en cada paso. El dinero que gana interés es un ejemplo, y una taza de té que se enfría es otro:

```factor
! 80 degrees hotter than the room, the gap shrinking by 5% a minute
: tea-gap ( minutes -- gap ) -0.05 * e^ 80 * ;

0 tea-gap .    ! => 80.0
10 tea-gap .   ! => 48.52245277701067
```

`log` deshace `e^`. Eso responde a la pregunta al revés: ¿cuántos minutos faltan para que la diferencia baje a 40 grados?

```factor
80 40 / log 0.05 / .   ! => 13.862943611198904
```
