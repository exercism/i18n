# Ejecutar las pruebas

Elige tu sistema operativo:

- [Windows](#windows)
- [macOS](#macos)
- [Linux](#linux)

## Windows

1. Abre el Command Prompt.
2. Descarga el primer ejercicio:

   ```batchfile
   C:\Users\JohnDoe>exercism download --exercise hello-world --track java
   ```

3. Cambia al directorio del ejercicio:

   ```batchfile
   C:\Users\JohnDoe>cd C:\Users\JohnDoe\exercism\java\hello-world
   ```

4. Ejecuta las pruebas:

   ```batchfile
   C:\Users\JohnDoe>gradlew.bat test
   ```

   _(No te preocupes si las pruebas fallan al principio, así es como empiezas cada ejercicio.)_

5. Resuelve el ejercicio. Busca la guía `instructions.append.md` y síguela ([ver en GitHub](https://github.com/exercism/java/blob/main/exercises/practice/hello-world/.docs/instructions.append.md#tutorial)).

¡Mucha suerte! ¡Que te diviertas!

## macOS

1. En la ventana de la terminal, descarga el primer ejercicio:

   ```sh
   exercism download --exercise hello-world --track java
   ```

2. Cambia al directorio del ejercicio:

   ```sh
   cd /Users/johndoe/exercism/java/hello-world
   ```

3. Ejecuta las pruebas:

   ```sh
   ./gradlew test
   ```

   _(No te preocupes si las pruebas fallan al principio, así es como empiezas cada ejercicio.)_
