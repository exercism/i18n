# Introducción

Un generador en Python es una _función invocable_ o una expresión que devuelve un tipo especial de [iterador][iterator] llamado [iterador de generador][generator-iterator].
Los `Generator-iterators` son [perezosos][lazy iterator]: no almacenan sus `values` en memoria, sino que _generan_ sus valores cuando se necesitan.

Una función generadora se ve como cualquier otra función, pero contiene una o más [expresiones yield][yield expression].
Cada `yield` suspenderá la ejecución del código y guardará el estado de ejecución actual (_incluidas todas las variables locales y las sentencias try_).
Cuando la función generadora se reanuda, retoma el estado desde la suspensión, a diferencia de las funciones normales, que se reinician con cada llamada.
