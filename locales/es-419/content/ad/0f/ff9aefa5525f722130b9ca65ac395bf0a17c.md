# Instalación

## Qué se necesita

Los elementos básicos que necesitas para desarrollar en Common Lisp son:

- Una «implementación» de Lisp, que te permitirá compilar y ejecutar código, además de ofrecerte un REPL.
- Un editor de texto con soporte para código Lisp.
- (Opcional, pero recomendable) La referencia más usada para el lenguaje Common Lisp, el ["Common Lisp Hyperspec"][hyperspec].

## Roswell

[Roswell][roswell] es un comando para instalar y gestionar implementaciones de Common Lisp, y tiene muchas funcionalidades que facilitan desarrollar y distribuir aplicaciones en Lisp.
Lo usamos para simplificar los pasos de instalación y de prueba.

### Instalar Roswell

Consulta la [guía de instalación][ros-inst] y sigue las instrucciones para tu plataforma.
Para la mayoría de los usuarios, lo siguiente será suficiente:

* Para MacOS y Linux, [Homebrew][brew] lo hace muy simple:
  ```sh
  brew install roswell
  ```
* Para Windows, usa [Scoop][scoop]:
  ```powershell
  scoop install roswell
  ```

La primera vez que uses Roswell, este descargará e instalará SBCL y Quicklisp.
Solo tienes que ejecutar esto:
```sh
ros help
```

Entra al REPL con
```sh
ros run
```

## Configura tu editor de texto

Quienes recién empiezan con Common Lisp, en particular si ya tienen experiencia previa con Emacs, pueden comenzar de forma fácil y rápida instalando [Portacle, el entorno portátil de Common Lisp][portacle].
Es gratuito y viene con todas las funcionalidades, funciona en todas las plataformas comunes y ya viene preconfigurado «listo para usar». Esto te ofrece:

- Una implementación de Lisp: SBCL, que incluye Quicklisp y ASDF.
- Un editor de texto: Emacs

... con un montón de complementos para escribir código Lisp:
- SLIME, el «Superior Lisp Interaction Mode for Emacs», convierte Emacs en un IDE de Common Lisp
- ParEdit, que facilita trabajar con paréntesis.

Todo viene ya configurado y listo para usar. Instala Portacle descargándolo desde la [página principal][portacle].

Nota: si no estás acostumbrado, Emacs (el editor de texto) puede resultar desconcertante al principio. Por suerte, hay muchos tutoriales introductorios sobre Emacs y SLIME disponibles en línea.

## Instalación tradicional

Si prefieres instalar las herramientas necesarias por separado, tendrás que instalar y configurar:

- un editor de texto con soporte para Lisp: una opción común es [Emacs][emacs] con el paquete [Slime][slime] o [Sly][sly], pero también funcionan bien [VIM][vim] con [SLIMV][slimv], [Atom][atom] con [SLIMA][slima] o [VSCode][vscode] con un [complemento de Common Lisp][vscode-plugin].
- una implementación de Common Lisp: [SBCL][sbcl] es una opción «segura» que funciona en Linux, MacOS y Windows. Como el lenguaje se basa en un estándar, otras [implementaciones conformes][awesome-cl-implementations] también funcionarán.
- [Quicklisp][quicklisp] para gestionar bibliotecas. Después de descargarlo, sigue las [instrucciones][quicklisp-install] para asegurarte de que quede bien integrado con tu implementación de Common Lisp.
