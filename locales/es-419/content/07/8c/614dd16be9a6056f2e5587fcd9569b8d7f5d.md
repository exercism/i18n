# Instrucciones

Determina si un conjunto dado de tres fichas de dominó se puede ordenar de manera que formen una cadena de dominó correcta (los puntos de una mitad de una ficha coinciden con los puntos de la mitad vecina de una ficha adyacente) y que los puntos de las mitades de las fichas que no tienen vecina (la primera y la última ficha) coincidan entre sí. Algunos casos de prueba pueden usar fichas duplicadas en la solución de una cadena. Devuelve `True` si se puede ordenar una cadena de dominó correcta y `False` en caso contrario.

```text
For example, given: [(2,1),(2,3),(1,3)]
    True

For example, given: [(1,2),(4,1),(2,3)]
    False
```
