# Apéndice

## El «null» en Tcl

Tcl no tiene un valor `null` ni `nil`.
En la práctica, muchas veces se usa la cadena vacía para indicar «sin valor».
Pero eso puede ser complicado en situaciones donde la cadena vacía en realidad es un valor válido, por ejemplo en un array que representa una fila de datos CSV.

Para este ejercicio, trata la cadena vacía como un valor null que se debe descartar.
