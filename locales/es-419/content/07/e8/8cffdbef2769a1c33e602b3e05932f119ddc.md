# Consejos

## General

Los condicionales se usan para verificar ciertas condiciones y/o criterios. La forma más básica de realizar una operación condicional es usar una sola sentencia `if`.

## 1. Calcula el puntaje de cualquier carta.

La función `parseCard` debe recibir la string `card` (por ejemplo, `ace`) y convertirla en su valor (por ejemplo, 11).

- Usa una gran [sentencia `switch`][switch-statement] sobre la variable `card`.
- El rey, la reina, la jota y el 10 se pueden manejar con un solo caso.
- El `switch` puede tener un caso `default`. En cualquier caso, la función debe devolver `0` para las cartas desconocidas.

## 2. Determina si dos cartas forman un Blackjack.

`isBlackJack` verifica si 2 cartas tienen un valor combinado de 21.

- Debe usar la función `parseCard` para obtener el valor de cada carta.
- Debe sumar los valores de las 2 cartas.
- Debe devolver `true` si la suma es igual a `21`.
- No se necesita ninguna sentencia adicional aquí. Se puede devolver el resultado de la comparación.

## 3. Implementa la lógica de decisión para puntajes de mano mayores a 20 puntos.

Como la función `largeHand` solo se llama para manos con un valor mayor a 20, solo hay 2 manos posibles: un **BlackJack** con un valor total de `21` y **2 ases** con un valor total de `22`.

- La función debe verificar [si][if-statement] `isBlackJack` es `true` y, de lo contrario, devolver "P".
- Si `isBlackJack` es `true`, hay que verificar si dealerScore es menor a 10. [Si][if-statement] es menor, devuelve "W"; de lo contrario, "S".

## 4. Implementa la lógica de decisión para puntajes de mano menores a 21 puntos.

La función `smallHand` solo se llama si no hay ases en la mano (`handScore` es menor a 21).

- Implementa cada condición usando [operadores lógicos][logical-operators] si es necesario:
  - [Si][if-statement] tus cartas suman 17 o más, siempre debes _plantarte_.
  - [Si][if-statement] tus cartas suman 11 o menos, siempre debes _pedir_.
  - [Si][if-statement] tus cartas suman un valor dentro del rango [12, 16], siempre debes _plantarte_ si el crupier tiene 6 o menos.
  - [Si][if-statement] tus cartas suman un valor dentro del rango [12, 16], siempre debes _pedir_ si el crupier tiene 7 o más.
- (opcional) Intenta optimizar las condiciones:
  - Reúne las condiciones para _plantarse_ en una sola.
  - Reúne las condiciones para _pedir_ en una sola.
  - Elimina las partes redundantes de las condiciones (por ejemplo, `A || !A && B` puede ser `A || B`).
