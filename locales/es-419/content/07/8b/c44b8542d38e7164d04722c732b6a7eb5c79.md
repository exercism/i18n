# Cómo probar los ejercicios

Sigue los pasos de abajo para desarrollar la solución de un ejercicio y probarla localmente.

## Descarga el ejercicio

Abre un Command Prompt y ejecuta el siguiente comando con el nombre del ejercicio que quieras descargar.

```sh
exercism download --track ballerina --exercise <exercise-name>
```

## Desarrolla tu solución

1. Ejecuta el siguiente comando para ir al directorio del ejercicio que acabas de descargar.

     >**Consejo:** La ubicación del directorio en el siguiente comando depende de tu sistema operativo y de tu espacio de trabajo de Exercism configurado. Puedes averiguar la ubicación de tu espacio de trabajo ejecutando el comando `exercism configure`.

     ```sh
     cd ~/exercism/ballerina/hello-world/
     ```

2. Sigue las instrucciones que se te dan y desarrolla una solución para el ejercicio.

## Prueba tu solución

Algunos ejercicios de Ballerina tendrán un solo test, mientras que otros tendrán varios tests. Los tests están en el archivo de test correspondiente del directorio `/tests`, dentro del directorio raíz del ejercicio.

### Probar un ejercicio con un solo test

Ejecuta el siguiente comando para ejecutar el test del ejercicio.

De forma predeterminada, solo el primer test está habilitado. Esto es intencional, ya que te permite concentrarte en hacer pasar únicamente ese test. 
     
```sh
bal test
```

### Probar un ejercicio con varios tests

Sigue los pasos de abajo para probar un ejercicio con varios tests.

1. Cuando pase el primer test, habilita el siguiente quitando la propiedad `enable: false` de la anotación `@test:Config`.

     ```ballerina
     @test:Config {
       enable: false
     }
     function nextTestCase() {
     }
     ``` 

2.  Ejecuta el siguiente comando para ejecutar el test habilitado.

   ```sh
     bal test
   ```

3. Repite los dos pasos anteriores para habilitar los tests restantes.

Habrás completado el ejercicio con éxito cuando hayas habilitado todos los tests y te hayas asegurado de que tu implementación pasa cada uno.
