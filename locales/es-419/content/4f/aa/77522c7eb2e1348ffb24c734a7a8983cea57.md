# Anexo a las instrucciones

## Notas

El argumento y el valor de retorno de la función `gigasecond` son de tipo [Date][date-link].

Es posible devolver un valor correcto para este ejercicio si modificas el argumento de la función de la solución. Aunque hay casos de uso legítimos para modificar los argumentos de una función, por lo general esto no es deseable y, en el caso de este ejercicio, claramente es inesperado. Por esta razón, el conjunto de pruebas incluye una prueba que falla si el argumento se modificó después de ejecutar la función.

[date-link]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Date
