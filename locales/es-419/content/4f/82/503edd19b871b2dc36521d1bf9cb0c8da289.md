# Introducción

Python tiene dos construcciones de bucle.
Los bucles `while` sirven para la iteración _indefinida_ (sin conteo) y los bucles `for` para la iteración _definida_ (con conteo).
Las palabras clave `break`, `continue` y `else` ayudan a personalizar el comportamiento del bucle.
Las funciones `range(<length of sequence>)` y `enumerate(<iterable>)` ayudan con el conteo del bucle y con los índices.


Los bucles `while` no tienen especificado un número de repeticiones que deban ejecutarse, y continúan mientras la expresión del bucle o «test» se evalúe como `True`.
El bucle termina cuando la expresión del bucle se evalúa como `False`.

```python
while expression:
    set_of_statements
```

Los bucles `for` recorren los valores de cualquier secuencia y terminan cuando ya no quedan valores que devolver.
La función `range(<length of sequence>)` proporciona un contador `loop` o una secuencia cuando no hay una estructura de datos u otro iterable sobre el cual iterar.

```python
# Python will keep track of the loop count internally.
for item in sequence:
    set_of_statements
    
# `range()` is used as an explicit loop counter.  
# This will loop 12 times, from index 0 to index 11.
for item in range(12):
    set_of_statements
```
