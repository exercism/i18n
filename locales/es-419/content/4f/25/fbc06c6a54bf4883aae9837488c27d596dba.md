# Ejecutar los tests

Desde la terminal, cámbiate al directorio base del ejercicio y luego ejecuta los tests con:

```bash
$ gleam test
```

Esto ejecutará el archivo de tests que se encuentra en la subcarpeta `test`, un archivo que termina en `_test.gleam`.

## Funciones de test

Los tests usan un [framework de tests personalizado](https://github.com/exercism/gleam-test-runner/tree/main/runner).
Cualquier función pública del directorio `test` cuyo nombre termine en `_test` será considerada un test por el framework de tests.

Por ejemplo:

```gleam
import bob
import exercism/should

pub fn shouting_test {
  bob.hey("WATCH OUT!")
  |> should.equal("Whoa, chill out!")
}
```
