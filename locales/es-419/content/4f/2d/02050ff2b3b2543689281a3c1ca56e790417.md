# Pistas

## 1. Los tres actos

- El encabezado de la clase nombra la clase abstracta después de `<`:
  `class JUGGLING < $ACT is`.
- Cada una debe definir tanto `name` como `minutes`, exactamente como los declara
  la clase abstracta. Si falta uno, es un error de compilación que nombra la rutina.
- Cada una también necesita un `create`, o `#JUGGLING` no tendrá nada que llamar.
  `create : SAME is return new; end;` es todo lo necesario para dos de ellas.
- `TRAPEZE` necesita un atributo para la altura y un `create` que la reciba.
- `+` une un número a un string, así que `"Trapeze at " + height + "m"` no
  necesita conversión.

## 2. El espectáculo

- El tipo del argumento es `ARRAY{$ACT}`. Eso es lo que permite que un solo
  array contenga los tres tipos.
- `acts.elt!` devuelve un `$ACT`. Llamar a `.minutes` sobre él ejecuta la versión
  correcta por sí sola: eso es el despacho dinámico, y es el punto del ejercicio.
  No hay nada que verificar ni ningún `typecase` que escribir.
- `billing` construye un string en un bucle, así que `FSTR`, y el `", "` va antes
  de cada nombre excepto el primero.
- `longest` guarda el mejor acto hasta el momento. Empezar los mejores minutos en
  `-1` hace que el primer acto siempre lo supere, lo que resuelve el espectáculo
  vacío sin un caso especial: el nombre se queda como `""`.
