# Apéndice de instrucciones

## Declaración de constantes

En este ejercicio se te pide que declares una serie de constantes que se usan para identificar diferentes tipos de triángulos. Elige el tipo de dato que creas que funciona mejor para esto y haz que las pruebas pasen.

Después, puede que valga la pena leer sobre el identificador predeclarado de Go [iota](https://golang.org/ref/spec#Iota). Hay [un excelente artículo al respecto](https://splice.com/blog/iota-elegant-constants-golang/).
