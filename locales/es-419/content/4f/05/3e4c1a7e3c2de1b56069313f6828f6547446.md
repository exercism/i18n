Aunque es posible concatenar strings manualmente en Haxe, el lenguaje admite la [interpolación de strings][string-interpolation], que ofrece una sintaxis más corta y cómoda:

```haxe
var x = 42;
//The following two statements are equivalent:

// manual concatenation
trace("the number is " + x);

// using interpolation
trace('the number is $x');
```

Como se muestra arriba, los strings interpolados se encierran entre comillas simples (`'`), a diferencia de los [strings][strings] normales, y pueden contener identificadores especiales precedidos por el signo de dólar (`$`) que activan la interpolación.

Es posible incluir expresiones completas usando `${expr}`, donde `expr` es cualquier expresión válida de Haxe:

```haxe
trace('the next number is ${x + 1}');
```

Para suprimir la interpolación cuando quieres un signo de dólar literal, puedes usar `$$`:

```haxe
trace('the price is $$42'); // outputs: the price is $42
```

Por último, ten en cuenta que la interpolación de strings es una funcionalidad que se resuelve en tiempo de compilación y no afecta el rendimiento en tiempo de ejecución. Internamente, el compilador de Haxe genera el código equivalente a la concatenación manual.

[string-interpolation]: https://haxe.org/manual/lf-string-interpolation.html
[strings]: https://haxe.org/manual/std-String.html
