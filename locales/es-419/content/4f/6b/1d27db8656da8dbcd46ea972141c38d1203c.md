# Depuración

Para ayudarte a depurar, hay varias macros definidas en un [archivo debug.mac][debug].
Se pueden llamar con uno o más argumentos del tipo y tamaño adecuados.
Por ejemplo:

```x86asm
debugf32 xmm0, xmm1 ; prints the value of two 32-bit floating-point numbers
debugd16 ax, cx, dx ; prints the value of three signed 16-bit integers
debugx64 [rax]      ; prints the value of a 64-bit integer in hexadecimal format
debugs rel mem, rsi ; prints two NUL-terminated strings
debugu8_xmm xmm1    ; prints 16 packed 8-bit unsigned integers
debug_flag e        ; prints true if je would jump, and false otherwise
```

Para usar cualquiera de esas macros, debes incluir `debug.mac` al inicio del archivo de la solución:

```x86asm
%include "debug.mac"
```

Ten en cuenta que todas las macros modifican `rsp` de forma temporal.
Para depurar un valor que está en la pila, primero cárgalo a él, o a su dirección, en otro registro.

[debug]: https://github.com/exercism/x86-64-assembly/tree/main/templates/debug.mac
