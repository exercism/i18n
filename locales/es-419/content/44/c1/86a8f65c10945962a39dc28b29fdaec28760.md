# Introducción

Los Boolean en Go se representan mediante el tipo booleano predeclarado `bool`, cuyos valores pueden ser `true` o `false`.
Es un tipo definido.

```go
var closed bool    // boolean variable 'closed' implicitly initialized with 'false'
speeding := true   // boolean variable 'speeding' initialized with 'true'
hasError := false  // boolean variable 'hasError' initialized with 'false' 
```

Go admite tres operadores lógicos que pueden reducir expresiones a valores Boolean, y devuelven `true` o `false`.

| Operador    | Qué significa                                 |
| ----------- | --------------------------------------------- |
| `&&` (y)    | Es verdadero si ambas afirmaciones son verdaderas. |
| `\|\|` (o)  | Es verdadero si al menos una afirmación es verdadera. |
| `!` (no)    | Es verdadero solo si la afirmación es falsa.  |
