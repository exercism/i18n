# Instrucciones

Traduce secuencias de ARN a proteínas.

El ARN se puede dividir en secuencias de tres nucleótidos llamadas codones, y luego traducirse a una proteína así:

ARN: `"AUGUUUUCU"` => se traduce a

Codones: `"AUG", "UUU", "UCU"`
=> que se convierten en una proteína con la siguiente secuencia =>

Proteína: `"Methionine", "Phenylalanine", "Serine"`

Hay 64 codones que a su vez corresponden a 20 aminoácidos; sin embargo, no todas las secuencias de codones ni todos los aminoácidos resultantes son importantes en este ejercicio.
Si funciona para un codón, el programa debería funcionar para todos.
Sin embargo, siéntete libre de ampliar la lista en la suite de pruebas para incluirlos todos.

También hay tres codones de terminación (también conocidos como codones «STOP»); si se encuentra alguno de estos codones (por el ribosoma), toda la traducción termina y la proteína queda terminada.

Todos los codones posteriores se ignoran, así:

ARN: `"AUGUUUUCUUAAAUG"` =>

Codones: `"AUG", "UUU", "UCU", "UAA", "AUG"` =>

Proteína: `"Methionine", "Phenylalanine", "Serine"`

Fíjate que el codón de terminación `"UAA"` pone fin a la traducción y la metionina final no se traduce a la secuencia de proteína.

A continuación se muestran los codones y los aminoácidos resultantes que se necesitan para el ejercicio.

| Codón              | Aminoácido    |
| :----------------- | :------------ |
| AUG                | Methionine    |
| UUU, UUC           | Phenylalanine |
| UUA, UUG           | Leucine       |
| UCU, UCC, UCA, UCG | Serine        |
| UAU, UAC           | Tyrosine      |
| UGU, UGC           | Cysteine      |
| UGG                | Tryptophan    |
| UAA, UAG, UGA      | STOP          |

Aprende más sobre la [traducción de proteínas en Wikipedia][protein-translation].
