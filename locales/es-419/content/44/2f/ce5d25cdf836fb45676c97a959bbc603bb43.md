# Instrucciones

En este ejercicio escribirás código para procesar un array de lenguajes de programación que planeas practicar en la plataforma Exercism.

Tienes seis tareas.

## 1. Crea un array nuevo

Antes de poder agregar lenguajes, tendrás que empezar creando un array nuevo. Define una función que devuelva un array vacío.

```clojure
(new-list)
;; => ()
```

## 2. Agrega un nuevo lenguaje al array

A medida que explores Exercism y encuentres lenguajes que quieras aprender, necesitarás poder agregarlos a tu array. Define una función que agregue un nuevo lenguaje al principio de tu array.

```clojure
(add-language '("Clojurescript") "JavaScript")
;; => '("JavaScript" "Clojurescript")
```

## 3. Verifica el último lenguaje agregado

Querrás verificar rápidamente qué lenguaje acabas de agregar. Define una función que devuelva el primer lenguaje de tu array.

```clojure
(first-language '("Haskell" "Python"))
;; => "Haskell"
```

## 4. Elimina el primer lenguaje del array

A veces cambiarás de opinión sobre un lenguaje que acabas de agregar. Define una función que elimine el primer lenguaje de tu array.

```clojure
(remove-language '("Common Lisp" "Racket" "Scheme"))
;; => '("Racket" "Scheme")
```

## 5. Cuenta los lenguajes del array

Contar los lenguajes uno por uno es incómodo. Define una función que cuente la cantidad de lenguajes de tu array.

```clojure
(count-languages '("C#" "Racket" "Rust" "Ruby"))
;; => 4
```

## 6. Combínalo todo

Define una función `learning-list`, dentro de la cual usarás algunas de las funciones que definiste antes.

- Crea un array vacío.
- Agrega 2 lenguajes de programación nuevos al array.

  - "Clojure"
  - "Lisp"

- Elimina "Lisp" del array, ya que quizás no tengas suficiente tiempo durante el año y es bastante similar a Clojure.
- Agrega 2 lenguajes de programación más al array.

  - "Java"
  - "JavaScript"

- Devuelve el número total de lenguajes. Pista: debería ser 3.

```clojure
(learning-list)
;; => 3
```
