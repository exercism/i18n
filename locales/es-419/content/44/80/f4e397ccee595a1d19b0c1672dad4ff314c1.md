# Instalación

Consulta [System/Installation][install-link] para obtener instrucciones sobre cómo preparar todo en tu sistema.

~~~exercism/caution
Si tienes instalado el Java Development Kit (JDK), el ejecutable `jconsole` podría entrar en conflicto con la Java Console, que usa el mismo nombre.

Algunas posibles soluciones son:

- Renombrar el ejecutable `jconsole` del lenguaje de programación J a algo único (por ejemplo, `jconsole-jlang`).

- Ajustar las variables de entorno de tu sistema o el PATH para dar prioridad al `jconsole` del lenguaje de programación J.

- **Si usas Linux**, hay un script de bash en `bin/install.sh` que crea un **enlace simbólico** llamado `ijconsole` en el directorio `/usr/`. Puedes usar ese enlace escribiendo `ijconsole` en tu terminal.
~~~

Una vez que hayas instalado J, abre una consola de J en tu terminal e ingresa los siguientes comandos para instalar el framework de pruebas unitarias:

```j
  load 'pacman'
  'update' jpkg ''
  'install' jpkg 'general/unittest'
  exit 0
```
