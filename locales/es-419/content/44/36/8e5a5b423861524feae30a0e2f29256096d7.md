# Instrucciones

En este ejercicio vas a trabajar en un sistema para agendar citas de un salón de belleza en Nueva York que abrió el 15 de septiembre de 2012.

Tienes cinco tareas, y todas tienen que ver con fechas de citas.
Las horas están en formato de 24 horas (sin AM/PM).
Para simplificar al máximo los problemas de zona horaria, asume que todo usa UTC.

## 1. Analizar una fecha de cita totalmente numérica

Implementa la función `schedule_appointment()` para analizar una representación textual de una fecha de cita y convertirla al formato `DateTime` correspondiente.

Ten en cuenta que la entrada está en el orden mes/día/año al estilo estadounidense.

```julia-repl
julia> schedule_appointment("07/25/2023 13:45:00")
2023-07-25T13:45:00
```

## 2. Comprobar si una cita ya pasó

Implementa la función `has_passed()` que recibe una fecha de cita y comprueba si la cita fue en algún momento del pasado:

```julia-repl
julia> has_passed(DateTime(1999, 12, 31, 9, 0, 0))
true
```

## 3. Comprobar si la cita es por la tarde

Implementa la función `is_afternoon_appointment()` que recibe una fecha de cita y comprueba si la cita es por la tarde (>= 12:00 y < 18:00):

```julia-repl
julia> is_afternoon_appointment(DateTime(2023, 3, 29, 15, 0, 0))
true
```

## 4. Comprobar el día de la semana de una cita

Implementa la función `day_of_week()` que devuelve el día de la semana _numérico_.
El salón está cerrado los domingos, así que el lunes es el día 1 y el sábado es el día 6.

```R
# a Friday
day_of_week(make_datetime(2026, 06, 05, 12, 30, 00))
#> [1] 5
```

## 5. Reprogramar una cita

Cuando un cliente necesita reprogramar una cita, esta se reprograma automáticamente para el siguiente viernes a la misma hora del día (ya que es el día más tranquilo de la semana).

Implementa la función `reschedule()` que recibe la cita original (como un string de texto en orden mes/día/año) y devuelve una cita reprogramada.

```R
# a Saturday
reschedule("06/13/2026 12:30:00")
#> [1] "2026-06-19 12:30:00 UTC"
```

Si la cita original era de lunes a jueves, reprograma para el viernes de _esta_ semana.
Para las citas de viernes o sábado, reprograma para el viernes de la semana _siguiente_.
