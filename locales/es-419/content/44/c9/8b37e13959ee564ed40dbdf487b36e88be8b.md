# Acerca de

Elixir usa [_Behaviours_][behaviours] para proporcionar interfaces genéricas comunes a la vez que facilita implementaciones específicas para cada módulo que implementa el behaviour. Uno de esos behaviours es el _Access Behaviour_.

El _Access Behaviour_ proporciona una interfaz común para obtener datos basados en claves de una estructura de datos. Está implementado para mapas y listas de palabras clave.

El módulo [`Access`][access] define los callbacks requeridos para la interfaz. Luego, los módulos [`Map`][map] y [`Keyword`][keyword] implementan los callbacks requeridos [`fetch/2`][map-fetch], [`get_and_update/3`][map-get-and-update] y [`pop/2`][map-pop].

Para usar el behaviour, puedes escribir corchetes a continuación de una variable enlazada y luego usar la clave para obtener el valor asociado con esa clave. Los mapas admiten claves de cualquier tipo, mientras que las listas de palabras clave solo admiten claves de tipo átomo.

```elixir
# Atom as key
my_map = %{key: "my value"}
my_map[:key]
# => "my value"

# String as key
another_map = %{"key" => "my value"}
another_map["key"]
# => "my value"
```

Si la clave no existe en la estructura de datos, se devuelve `nil`. Esto puede ser una fuente de comportamiento no deseado, porque no lanza un error.

```elixir
my_map = %{key: "my value"}
my_map[:wrong_key][:other_wrong_key]
# => nil
```

Ten en cuenta que `nil` en sí mismo implementa el Access Behaviour y siempre devuelve `nil` para cualquier clave.

```elixir
nil[:key]
# => nil
```

Los structs no implementan el behaviour de Access.
