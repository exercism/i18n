# Introducción

Se crea una instancia de una clase llamando a su [_constructor_][constructor] mediante el operador `new`. Un constructor es un método especial dentro de una clase cuyo objetivo es inicializar la clase. En Haxe, el método constructor tiene el nombre `new()`.

```haxe
class Library {
  private var books:Int;

  public function new() {
    this.books = 10; // Initialize the books field
  }
}

var library = new Library(); // This calls the constructor
```

Igual que los métodos normales, los constructores pueden tener parámetros. Estos parámetros se guardan (normalmente) en campos privados y se accede a ellos más adelante.

```haxe
class Building {
  private var numberOfStories:Int;
  private var totalHeight: Float;

  public function new(numberOfStories:Int, storyHeight:Float) {
    this.numberOfStories = numberOfStories;
    this.totalHeight = storyHeight * numberOfStories;
  }
}

var largeBuilding = new Building(55, 6.2);
```

**No puedes** crear una nueva instancia de una clase si esta no tiene un constructor. Por lo tanto, usar un constructor vacío es la única manera.

```haxe
class Car {
  public var weight:Int = 1000;

  public function new() {}
}

var myCar = new Car();
```
