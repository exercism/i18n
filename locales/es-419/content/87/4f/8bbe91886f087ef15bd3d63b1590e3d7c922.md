# Acerca de los strings

Un [`string`][ref-string] (o _cadena_) en Kotlin es una secuencia inmutable de caracteres Unicode.

[`Immutable`][wiki-immutable] significa que cualquier operación sobre un string debe devolver un string nuevo: el string original nunca puede cambiar.

[`Unicode`][wiki-unicode] significa que se pueden representar la mayoría de los sistemas de escritura del mundo, pero (a diferencia de lenguajes más antiguos como C) no hay una correspondencia 1:1 entre caracteres y bytes.
Esto se tratará más adelante en el concepto [`Chars`][concept-chars].

Un string va rodeado de comillas dobles `" "`.

Algunos caracteres necesitan escape: `\\`, además de los habituales caracteres no imprimibles como `\t` (tabulador) y `\n` (salto de línea).

```kotlin
val s = "Escape backslash \\."
// Escape backslash \.
```

Los strings multilínea van rodeados de 3 comillas dobles y pueden contener texto arbitrario (no hace falta escaparlo).

```kotlin
val multi = """I'm a
    multi-line
    string with special characters \ \t """
//I'm a
//    multi-line
//    string with special characters  \ \t 
```

Usa [trimIndent][trimIndent-doc] para quitar la indentación común de las líneas.
Esto es útil para dar formato al string:

```kotlin
val multi = """
    I'm a
      multi-line
    string""".trimIndent()

//I'm a
//  multi-line
//string
```

Como alternativa, [trimMargin][trimMargin-doc] te permite especificar un delimitador.
Entonces cada línea del `String` empieza después del delimitador.
El delimitador predeterminado es `|`, pero puedes especificar otro delimitador como parámetro.
Por ejemplo:

```kotlin
val multi = """
    |I'm a
    |  multi-line
    |string""".trimMargin()

//I'm a
//  multi-line
//string

val multi2 = """
    start>I'm a
    start>  multi-line
    start>string""".trimMargin("start>")

//I'm a
//  multi-line
//string
```

Los strings se pueden concatenar con `+`, pero conviene limitarlo a casos cortos y sencillos.
Hay otras opciones, a menudo mejores.

## Plantillas de strings

Las [`Templates`][ref-templates] son lo que otros lenguajes llaman «interpolación».

Si un string contiene un signo de dólar `$` seguido de un identificador, o contiene llaves (`{expression}`) que rodean a una expresión, se sustituyen por el valor o por el resultado de la expresión, respectivamente.

```kotlin
val x = 42
val st = "x is $x, x squared is {x * x}"
// x is 42, x squared is 1764
```

## Formato de strings

Solo en la plataforma JVM, `String.format()` permite un formato más preciso que las plantillas de strings, con una [sintaxis][web-formats] similar a las funciones [`printf`][wiki-printf] (_¡muy antiguas!_).

```kotlin
String.format("%s %.3f", "π ≈", 3.14159)
//π ≈ 3.142
```

## Funciones de strings

Kotlin ofrece _muchas_ [`functions`][ref-string-functions] para manipular strings.

En su mayoría, no son miembros de la clase `String`, sino [`extensions functions`][ref-extensions], aunque esto influye poco en cómo las usamos.

~~~~exercism/note
Las páginas de [documentación][ref-string-functions] de Kotlin, bastante complejas, ocultan las funciones de extensión en la vista predeterminada.
Al momento de escribir esto, el contenido más valioso está oculto en una pestaña llamada `Members & Extensions`.
Haz clic en ella para expandir esa sección y ver todos los miembros y extensiones disponibles en la clase `String`.

[ref-string-functions]: https://kotlinlang.org/api/core/kotlin-stdlib/kotlin/-string/
~~~~

El siguiente ejemplo muestra solo una pequeña selección de lo que hay disponible:

```kotlin
val str = "Hello World!"

str.length              // => 12 (a property, not a function)
str.elementAt(6)        // => W
str.elementAtOrNull(20) // => null (index out of range)
str.substring(6, 11)    // => "World"
str.substringAfter(" ") // => "World!"

str.lowercase()         // => "hello world!"
str.uppercase()         // => "HELLO WORLD!"

str.startsWith("Hel")   // => true
str.endsWith("xyz")     // => false
str.indexOf("0")        // => 4

str.toCharArray()       // => [H, e, l, l, o,  , W, o, r, l, d, !]
"42".toInt() + 1        // => 43  (parsing; see also toFloat)

"Howdy!  ".trim()       // => "Howdy"
```

## Construir un string

A veces hay que construir un string largo por etapas, por ejemplo dentro de un bucle.

Concatenar strings con `+` pronto deja de ser elegante y eficiente: la inmutabilidad hace que haya que copiar _muchísimo_.

Kotlin tiene varias formas más eficientes de combinar varios strings:

- Las plantillas de strings, descritas antes.
- [`joinToString()][ref-jointostring], que se tratará en el concepto [Listas][concept-lists].
- El [`StringBuilder`][ref-stringbuilder] de Java, que no se considera especialmente idiomático en Kotlin.
- El [`buildString()`][ref-buildstring] de Kotlin, que envuelve a `StringBuilder` en una sintaxis más concisa e idiomática.
Este toma la lógica de construcción del string como un argumento lambda, que se tratará en un concepto posterior.

En esencia, un `StringBuilder` es una estructura similar a una lista, con muchos métodos prácticos.
Esta es una pequeña selección:

- [`append()`][ref-sb-append] para agregar al final.
- [`insert()`][ref-sb-insert] para agregar en una posición específica.
- [`deleteAt()`][ref-sb-deleteat] y [`deleteRange()`][ref-sb-deleterange] para eliminar desde posiciones específicas.
- `toString()` para convertir al final en un string normal: concatena todo en una sola operación eficiente.

```kotlin
// Available, not recommended
val sb = StringBuilder()
sb.append("Hello ")
sb.append("World!")
sb.toString()
//Hello World!
```

Un ejemplo de `buildString()`, con sintaxis de conceptos posteriores:

```kotlin
val countDown = buildString {
    for (i in 5 downTo 1) {
        append(i)
        append("_")
    }
}
// countDown is "5_4_3_2_1_"
```
