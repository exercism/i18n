# Pistas

## 1. Define el tipo externo `GbTree`

- Los tipos externos se pueden definir con la sintaxis `pub type TypeName(a, b, c)`.

## 2. Define la función `new_gb_tree`

- Las funciones externas se pueden definir con la sintaxis `@external(erlang, "module", "function")`.
- La función debe usar `gb_trees:empty/0`.

## 3. Define la función `insert`

- Consulta la documentación de `gb_trees:insert/3` para confirmar el orden correcto de los argumentos.
- La función externa puede ser una función privada a la que llama la función `insert` para cambiar el orden de los argumentos.
- La función debe usar `gb_trees:insert/3`.

## 4. Define la función `delete`

- Consulta la documentación de `gb_trees:delete_any/2` para confirmar el orden correcto de los argumentos.
- La función externa puede ser una función privada a la que llama la función `delete` para cambiar el orden de los argumentos.
- La función debe usar `gb_trees:delete_any/2`.
- La función `gb_trees:delete/2` fallará si no se encuentra la clave, así que no se debe usar.
