# Anexo de instrucciones

Hay muchas maneras de resolver este ejercicio, pero lo hemos adaptado para quienes quieran practicar cómo escribir sus propios [ability handlers][ability-handler-docs].

Escribe una ability `Zipper` que te permita navegar por una estructura de datos de árbol binario.

La ability `Zipper` ya está definida para ti, pero tendrás que implementar el handler que le permite navegar por la estructura de datos de árbol binario que designamos para este ejercicio.

Dado el siguiente árbol binario, si llamáramos a `Zipper.right`, `Zipper.right`, `Zipper.up` y luego a `Zipper.left`, deberíamos quedar en el nodo con valor `5`.

```
     1
   /   \
  2     4
 /     /  \
3     5    7
```

Para este ejercicio, si llamas a `left` o `right` sobre un árbol binario que no tiene una rama izquierda o derecha, puedes devolver el valor del nodo actual.

## Cosas para reflexionar

¿En qué sentido un ability handler se parece a un zipper? ¿Podrías considerar la `continuation` de una función como un puntero al siguiente «nodo» de tu programa? ¿Podrías guardar en tu handler las llamadas anteriores a la continuation para poder navegar «atrás» hacia un estado anterior?

¿Qué otras estructuras de datos podrías recorrer de esta manera? ¿Podrías escribir un Zipper sobre JSON o uno sobre el árbol DOM del HTML?
