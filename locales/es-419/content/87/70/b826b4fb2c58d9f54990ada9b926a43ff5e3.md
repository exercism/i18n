# Instrucciones

Es otra noche ajetreada en el patio de maniobras de Amberes. Eres el despachador de turno: los vagones de carga que llegan hay que reagruparlos en trenes de salida, inspeccionar los enganches, dividir las rutas en los empalmes y agrupar la carga idéntica para la facturación.

Cada *vagón* es un string que indica lo que lleva: `"coal"`, `"timber"`, `"crates"`, etc.

## 1. Acopla los vagones en trenes

Define `couple` para que reciba un array de vagones y una longitud `n`, y devuelva trenes de `n` vagones que no se solapen. El último tren puede ser más corto si la cantidad no se divide de forma exacta.

```factor
{ "coal" "coal" "coke" "ore" "ore" "timber" "timber" } 3 couple .
! => { { "coal" "coal" "coke" } { "ore" "ore" "timber" } { "timber" } }
```

## 2. Asómate a los enganches

Define `peek-couplings` para que reciba un array de vagones y devuelva cada par adyacente, para que el inspector pueda examinar cada enganche.

```factor
{ "coal" "ore" "timber" "crates" } peek-couplings .
! => { { "coal" "ore" } { "ore" "timber" } { "timber" "crates" } }
```

## 3. Divide la cadena en los empalmes

Define `split-at-junctions` para que reciba un array de vagones y un array de `junctions` (vagones que marcan un punto de corte), y devuelva los tramos entre los vagones de empalme. Los propios vagones de empalme no se conservan.

```factor
{ "coal" "coal" "switch" "ore" "switch" "timber" }
{ "switch" } split-at-junctions .
! => { { "coal" "coal" } { "ore" } { "timber" } }
```

## 4. Agrupa la carga idéntica

Define `coalesce-cargo` para que reciba un array de vagones y agrupe en tramos los vagones *consecutivos* que llevan la misma carga.

```factor
{ "coal" "coal" "ore" "ore" "ore" "timber" "coal" } coalesce-cargo .
! => { { "coal" "coal" } { "ore" "ore" "ore" } { "timber" } { "coal" } }
```
