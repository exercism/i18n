# Introducción

Una `List` es muy similar a un `Array`. Sin embargo, hay diferencias importantes que no querrás pasar por alto:

1. No se puede indexar una lista usando corchetes, es decir, `[0]`.
2. Una lista no se puede inicializar.
3. No hay comprensiones de listas.
4. Una lista puede modificar sus elementos libremente mientras se itera sobre ella.

`List` es un miembro del paquete `haxe.ds`, así que cada vez que quieras usar listas, necesitas importar su paquete:

```haxe
import haxe.ds.List;

class Main {
  static function main() {
    var myList = List<Int>();

    for (i in 0...5) {
      myList.add(i);
    }

    trace(myList); // {0, 1, 2, 3, 4}
  }
}
```
