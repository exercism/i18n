# Configurar las herramientas

Hay tres herramientas que deberías ajustar para tu track:

- El **Contador de líneas de código** ([Lines of Code Counter](/docs/building/tooling/lines-of-code-counter)): esta herramienta se encarga de contar las líneas de código de cada iteración enviada.
- El **Extractor de fragmentos** ([Snippet Extractor](/docs/building/tooling/snippet-extractor)): esta herramienta extrae un fragmento de cada iteración, que se muestra en el sitio web.
- La **[CLI de Exercism](/docs/building/tooling/cli)**: los estudiantes usan esta herramienta para trabajar en un track de forma local, en su propia computadora.

```exercism/note
Aunque ajustar estas herramientas es opcional, hará que la integración de tu track en el sitio web sea _mucho_ mejor.
Por eso te recomendamos ajustar las tres herramientas.
```
