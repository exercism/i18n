# Instrucciones

En este ejercicio vas a procesar líneas de log.

Cada línea de log es una cadena con el siguiente formato: `"[<LEVEL>]: <MESSAGE>"`.

Hay tres niveles de log diferentes:

- `INFO`
- `WARNING`
- `ERROR`

Tienes tres tareas, y cada una recibe una línea de log y te pide hacer algo con ella.

## 1. Obtén el mensaje de una línea de log

Implementa el método (_static_) `LogLine.Message()` para devolver el mensaje de una línea de log:

```csharp
LogLine.Message("[ERROR]: Invalid operation")
// => "Invalid operation"
```

Se deben eliminar los espacios en blanco al principio y al final:

```csharp
LogLine.Message("[WARNING]:  Disk almost full\r\n")
// => "Disk almost full"
```

## 2. Obtén el nivel de log de una línea de log

Implementa el método (_static_) `LogLine.LogLevel()` para devolver el nivel de log de una línea de log, que debe devolverse en minúsculas:

```csharp
LogLine.LogLevel("[ERROR]: Invalid operation")
// => "error"
```

## 3. Dale un nuevo formato a una línea de log

Implementa el método (_static_) `LogLine.Reformat()` que le da un nuevo formato a la línea de log, colocando primero el mensaje y después el nivel de log entre paréntesis:

```csharp
LogLine.Reformat("[INFO]: Operation completed")
// => "Operation completed (info)"
```
