# Pistas

## General

- Puedes definir una función para que reciba varios argumentos empaquetados juntos usando el parámetro `*args` para argumentos de tipo `list` y `tuple`, o el parámetro `**kwargs` para argumentos basados en diccionarios o en palabras clave.
- Para empaquetar o desempaquetar, usa el operador `*` o `**`.

## 1. Crea una lista con todos los vagones

- Puedes empaquetar varios argumentos de los parámetros de la función con el operador `*args`.

## 2. Corrige la lista de vagones

- Usar el desempaquetado con el operador `*` te permite extraer los dos primeros elementos de una `list` y mantener el resto intacto.
- Para agregar otra `list` dentro de una `list` existente, puedes usar el operador `*` para «esparcir» la `list`.

## 3. Agrega las paradas faltantes

- Usar `**kwargs` como parámetro de función permite pasar una cantidad arbitraria de argumentos de palabra clave.
- Usar `**<dict>` como argumento desempaqueta un diccionario en argumentos de palabra clave.
- Puedes poner argumentos de palabra clave en un `{}` o en `dict()`.
- Para obtener los valores de un diccionario, puedes usar el método `<dict>.values()`.

## 4. Amplía la información de rutas

- Usar `**<dict>` como argumento desempaqueta un diccionario en argumentos de palabra clave.
- Puedes poner argumentos de palabra clave en un `{}` o en `dict()`.

## 5. Corrige el depósito de vagones

- Puedes usar `zip(*iterators)` para transponer una `list` anidada.
- Para extraer datos de los iteradores comprimidos con zip, puedes usar un bucle `for`.
- También puedes desempaquetar iteradores comprimidos con zip usando `*`.
  `[*content] = zip(iterator_1, iterator_2)` descomprime el `tuple` que produce `zip()` y lo convierte en una `list`.
