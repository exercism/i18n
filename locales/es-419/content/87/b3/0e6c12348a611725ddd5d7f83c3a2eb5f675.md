# Pistas

## 1. Convierte una calificación numérica a una calificación con letra

- Usa una [expresión `if-then-else`][jq-man-if] con tantas ramas `elif` como sea necesario.

## 2. Cuenta el número de estudiantes por cada calificación con letra

- El filtro `reduce` necesita un _flujo_ sobre el cual iterar.
  El argumento es un objeto.
  Usa la expresión `to_entries` para transformar el objeto en un array.
- El objeto resultante debe tener todas las calificaciones con letra posibles como claves, aunque ningún estudiante haya obtenido esa calificación.
- La [asignación `+=`][jq-man-arith-assign] te será útil.

[jq-man-if]: https://jqlang.org/manual/#if-then-else-end
[jq-man-arith-assign]: https://jqlang.org/manual/#arithmetic-update-assignment
