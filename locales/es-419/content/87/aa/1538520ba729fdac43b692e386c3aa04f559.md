# Introducción

La desestructuración es una forma de descomponer valores compuestos en Rust. A menudo se usa para extraer campos de tuplas o estructuras.

Por ejemplo, el siguiente fragmento extrae dos valores de una tupla:

```rust
let (first, second) = (1, 2);
```

El valor `1` se vincula a la variable `first`.
El valor `2` se vincula a la variable `second`.
