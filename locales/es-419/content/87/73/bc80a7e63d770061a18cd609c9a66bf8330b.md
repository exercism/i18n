# Apéndice de instrucciones

## Palabras

Define una tupla `rat` con los campos `numerator` y `denominator`.
`<rat>` debe reducir sus argumentos a su mínima expresión, con el
signo en el numerador (de modo que el denominador siempre sea positivo).

- `<rat> ( numerator denominator -- rat )`: construye un racional
  reducido.
- `>rat ( pair -- rat )`: construye un `rat` a partir de `{ numerator denominator }`.
- `rat>pair ( rat -- pair )`: devuelve `{ numerator denominator }`.
- `r+ ( a b -- c )`, `r- ( a b -- c )`, `r* ( a b -- c )`,
  `r/ ( a b -- c )`: operaciones aritméticas entre dos racionales.
- `r-abs ( a -- |a| )`: valor absoluto.
- `r^ ( a n -- a^n )`: eleva un racional a una potencia entera
  (se permiten exponentes negativos).
- `real^r ( x a -- y )`: eleva un número real a un exponente
  racional y devuelve un número de punto flotante.

Los genéricos `MATH:` de Factor (`+`, `-`, `*`, `/`) solo despachan sobre
la jerarquía matemática incorporada, así que este ejercicio usa nombres
de palabras dedicados en lugar de métodos sobre esos genéricos.
