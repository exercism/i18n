# Anexo a las instrucciones

## Pistas

El módulo Sgf debe exportar un módulo parseSgf con la siguiente firma:

```haskell
parseSgf :: Text -> Maybe (Tree (Map Text [Text]))
```

Puede que te resulte útil copiar las siguientes definiciones de SgfTree
y SgfNode:

```haskell
-- | A tree of nodes.
type SgfTree = Tree SgfNode

-- | A node is a property list, each key can only occur once.
-- Keys may have multiple values associated with them.
type SgfNode = Map Text [Text]
```

aprovecharla.
