# Sobre los tipos genéricos

Un **tipo genérico** es una clase o interfaz genérica parametrizada sobre tipos. Esto permite que el compilador imponga la seguridad de tipos en la clase o la interfaz.

Considera esta interfaz `Container` no genérica:

```java
class Container {
    private Object object;

    public void set(Object object) { this.object = object; }
    public Object get() { return object; }
}
```

Como acepta y devuelve tipos Object, funciona con cualquier tipo no primitivo. Sin embargo, esto tiene un costo porque algún código puede llamar a `get` esperando `Integer` mientras que otro código llama a `set` añadiendo `String`, lo que resulta en una excepción en tiempo de ejecución.

Una **clase genérica** y una **interfaz genérica** tienen los siguientes formatos:

```java
class ClassName<T1, T2, ..., Tn> { ... }
interface InterfaceName<T1, T2, ..., Tn> { ... }
```

La sección de parámetros de tipo, delimitada por paréntesis angulares (`<>`), que sigue al nombre de la clase o interfaz, especifica los parámetros de tipo (también llamados variables de tipo) `T1`, `T2`, ..., y `Tn`. Estos se pueden usar dentro del cuerpo de la clase o la interfaz para obtener seguridad de tipos genéricos.

Aquí está la versión genérica de `Container`:

```java
class Container<E> {
    private E object;

    public void set(E object) { this.object = object; }
    public E get() { return object; }
}
```

Al crearla, ahora tenemos que declarar qué tipo contiene y el compilador impondrá esa restricción:

```java
// empty <> can infer from context
Container<String> stringContainer = new Container<>();
// compiler knows this is a String, so it is allowed
stringContainer.set("Some string");
// no cast needed, compiler knows it is a String
String result = stringContainer.get();
// this causes a compiler error:
stringContainer.set(42);
```
