# Pistas

## 1. Encontrar una carta en la baraja

- Hay un [método incorporado][index] que puede encontrar el primer elemento de la colección que cumpla la condición especificada en el bloque, y devolver su índice o `nil` si no se encuentra ningún elemento.

## 2. Poner en mayúscula todos los caracteres

- Hay un [método incorporado][map] para transformar todos los elementos de la colección.
- Hay un [método incorporado][capitalize] para poner en mayúscula las palabras de un `String`.

## 3. Calcular el nivel de poder de todas las cartas

- Puedes usar el [método `sum`] para calcular el nivel de poder total de todas las cartas.
- El método `sum` también puede aceptar un bloque para transformar los elementos antes de sumarlos.

## 4. Decodificar una carta

- Hay un [método incorporado][each_char_with_index] para iterar sobre los caracteres de un `String` con un índice.
