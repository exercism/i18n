# Rangos

Los [rangos][range] representan un intervalo entre dos valores.
Los tipos más comunes que admiten rangos son `Int`, `Char` y `String`.
Se pueden usar para muchas cosas, como crear una colección rápidamente, cortar strings, comprobar si un valor está dentro de un rango e iterar.
Se crean con el operador de rango `..` o `...` (inclusivo y exclusivo, respectivamente).

```crystal
1..5  # A range containing 1, 2, 3, 4, 5
1...5 # A range containing 1, 2, 3, 4
```

La razón de tener dos operadores de rango es poder crear rangos que incluyan o excluyan el valor final. Esto puede ser útil cuando, por ejemplo, trabajas con índices que empiezan en cero.

Los rangos también se pueden crear con el inicializador `Range`.

```crystal
Range.new(1, 5) # A range containing 1, 2, 3, 4, 5
```

~~~~exercism/note
Cuando creas un rango en Crystal con los operadores de rango `..` o `...` y quieres llamar a un método sobre el rango, necesitas encerrar el rango entre paréntesis.
Esto se debe a que, de lo contrario, el método se llamaría sobre el segundo argumento del operador de rango.

```crystal
(1..5).size # => 5
1..5.size # => Error: undefined method 'size' for Int32
```
~~~~

## Obtener subcadenas

Cuando quieres cortar un string, puedes usar el operador de rango para obtener una subcadena. Es decir, creando un rango con el índice de inicio y el índice de fin de la subcadena.

```crystal
"Hello World"[0..4] # => "Hello"
"Hello World"[6..10] # => "World"
```

También puedes usar índices negativos para obtener la subcadena desde el final del string.

```crystal
"Hello World"[-5..-1] # => "World"
"Hello World"[6..-4] # => "Wo"
```

## Métodos de los rangos

Los rangos tienen un conjunto de métodos que puedes usar para trabajar con ellos.
Por ejemplo, estos métodos te permiten obtener la suma de todos los valores del rango o comprobar si el rango incluye un valor.

| Método                  | Descripción                                                             | Ejemplo                         |
|-------------------------|-------------------------------------------------------------------------|---------------------------------|
| [`sum`][sum]            | Devuelve la suma de todos los valores del rango                         | `(1..5).sum # => 15`            |
| [`size`][size]          | Devuelve el tamaño del rango                                            | `(1..5).size # => 5`            |
| [`includes?`][indludes] | Devuelve `true` si el rango incluye el valor dado; de lo contrario, `false` | `(1..5).includes?(3) # => true` |

## Rangos sin fin y sin inicio

Un rango puede ser sin fin o sin inicio.
El rango sin fin o sin inicio tiene su valor de inicio o de fin como `nil`, pero `nil` se puede omitir al definir el rango.

Usar rangos sin inicio y sin fin es útil cuando quieres, por ejemplo, cortar un string desde el principio o hasta el final.

```crystal
"Hello World"[0..] # => "Hello World"
"Hello World"[4..] # => "o World"
"Hello World"[..5] # => "Hello"
```

~~~~exercism/caution
Si no se usa sobre una colección, el rango sin fin puede provocar una secuencia sin fin si no se usa con cuidado.
~~~~

## Rangos de Char

Los Char se pueden usar en rangos y te permiten obtener un intervalo de caracteres entre dos caracteres.
Por ejemplo, esto puede ser útil cuando quieres obtener el alfabeto.

```crystal
'a'..'z' # A range containing ['a', 'b', 'c', ..., 'z']
```

## Rangos de String

Los strings también se pueden usar en rangos, lo que permite obtener un intervalo de strings entre dos strings.
Pero su comportamiento es un poco diferente al de `Char` cuando se usan varios caracteres en un rango de strings.
Su comportamiento puede volverse confuso cuando haces rangos de strings más complejos, así que ten cuidado.

```crystal
("aa".."az") # A range containing ["aa", "ab", "ac", ..., "az"]
```
