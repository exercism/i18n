# Anexo a las instrucciones

## Cambios específicos de Elixir

La descripción anterior de este ejercicio es compartida por todas las pistas de Exercism.

Para ser consistentes con la biblioteca estándar de Elixir, las funciones que usan `foldl` y `foldr` deben recibir el elemento como primer argumento y el acumulador como segundo.

Además, para no entrar en conflicto con la función `Kernel.length/1`, que se importa automáticamente, la función que cuenta la longitud se llamará `count`.

## Pruebas lentas

Una o varias de las pruebas de este ejercicio están etiquetadas como `:slow`, porque pueden tardar mucho en terminar. Por esta razón, el ejecutor de pruebas automatizado no las ejecutará en la plataforma. Si vas a resolver este ejercicio directamente en la plataforma, en el editor web, quizás te convenga descargar el ejercicio a tu computadora. Así podrás ejecutar todas las pruebas y comprobar la eficiencia de tu solución.
