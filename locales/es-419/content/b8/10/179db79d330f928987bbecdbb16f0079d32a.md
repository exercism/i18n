# Introducción

Un `string` en Clojure es un string de Java, es decir, una cadena: un objeto que representa texto inmutable como una secuencia de caracteres Unicode (letras, dígitos, signos de puntuación, etc.) y se define así:

```clojure
(def fruit "Apple")
```

La biblioteca `clojure.string` proporciona muchas funciones estándar de manipulación y procesamiento de strings. Además, todos los métodos habituales de Java para operar con strings están disponibles a través de la interoperabilidad.
