# Acerca de

A veces no necesitas la carga adicional de crear un objeto con estado.
En estos casos, puedes usar un `module`.

Un módulo es muy similar a una clase (de hecho, `Module` es el padre de `Classes` en la jerarquía de objetos): la diferencia principal es que, en lugar de usar métodos de instancia, usamos métodos de clase.
Los métodos de clase comienzan con `self.` y se llaman directamente en un módulo.

Por ejemplo:

```ruby
module Speaker
  def self.echo(something)
    "#{something} ... #{something}"
  end
end

Speaker.echo("Hello")   #=> "Hello ... Hello"
```
