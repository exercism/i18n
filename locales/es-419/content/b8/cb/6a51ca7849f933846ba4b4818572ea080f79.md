# Anexo de instrucciones

## Pistas

Puedes pensar en esta estructura de datos como un [`Rose Tree`](https://en.wikipedia.org/wiki/Rose_tree).
Se te da un tipo de dato `'a tree` que representa esta estructura de datos.

**Notas**

- Para este ejercicio, `Empty` representa `null`
- La lista anidada se representa con `List [...]`.
- El ejemplo de entrada se representa con `List [Elem 1, List [Elem 2, Elem 3, Empty, Elem 4], List [Empty], Elem 5]`
