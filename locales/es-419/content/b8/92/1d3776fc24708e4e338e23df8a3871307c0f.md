# Introducción

## Verdadero y falso

Los estados lógicos verdadero y falso se representan con `true` y `false` en Ruby.
Se pueden usar como literales por sí solos, o como resultado de métodos lógicos o de comparación.

```ruby
happy = true
sad = false

true && false
# => false

1 < 2
# => true
```

## _Truthy_ y _falsey_

Cuando se evalúan objetos en condicionales `if` u otros contextos booleanos, todos los objetos se evalúan como _truthy_, **excepto** `false` y `nil`.

## Flujo de control

Las evaluaciones _truthy_ y _falsey_ son útiles en el contexto del flujo de control.
Como en los lenguajes procedimentales, Ruby tiene una construcción `if`...`else`, pero puede ser más común usar `if` como una sentencia de «guarda» para modificar la evaluación de una expresión.

```ruby
def falsey
  nil || false
end

def truthy
  not falsey
end

if truthy
  # this block is evaluated
end

if falsey
  # this block is not evaluated
else
  # this block is evaluated
end

1 + 1 if truthy
# this will evaluate and return 2

2 + 2 if falsey
# the numbers are not added because of the modifier, nil is returned
```

Ruby ofrece `unless` para que el código se lea bien.
Por ejemplo, en lugar de `eat_desert if not too_full`, también podemos escribir `eat_desert unless too_full`.

```ruby
3 + 3 unless truthy
# the numbers are not added because of the modifier, nil is returned

4 + 4 unless falsey
# this will evaluate and return 8
```
