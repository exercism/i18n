# Clases con estado

```sather
class SCOREBOARD is

   attr home_team, away_team : STR;
   attr home_score, away_score : INT;

   create(home, away : STR) : SAME is
      board ::= new;
      board.home_team := home;
      board.away_team := away;
      return board;
   end;

   home_goal is home_score := home_score + 1; end;

end; -- class SCOREBOARD
```

## attr, readonly attr, private attr

| Escrito | Se lee desde afuera | Se cambia desde afuera |
| --- | --- | --- |
| `attr x : INT` | sí | sí |
| `readonly attr x : INT` | sí | no |
| `private attr x : INT` | no | no |

`readonly` es el que deberías usar por defecto. Deja que cualquiera vea el
puntaje y exige que cambiarlo pase por `home_goal`, que es donde viven las
reglas sobre cómo anotar.

## create y new

`new` produce un objeto de esta clase con todos los atributos vacíos. Solo
se puede usar dentro de la clase.

`create` es una rutina normal con un nombre acordado: `#C(args)` es
exactamente `C::create(args)`. Una clase puede tener varias, que se
distinguen por sus argumentos, y una clase que no tenga ninguna simplemente
no se puede crear con `#`.

## SAME

`SAME` representa la clase en la que está escrito. En `create` es el tipo
de retorno; también sirve en un argumento, y es lo que hace que una rutina
heredada hable de la clase que hereda en lugar de la clase de la que viene.

## Rutinas sin tipo de retorno

```sather
   home_goal is
      home_score := home_score + 1;
   end;
```

Sin `:` y sin tipo. Una rutina así se llama como una sentencia y no puede
aparecer en una expresión. Es la señal de que lo importante de la llamada
es el cambio que produce.

## self

Dentro de una rutina, `self` es el objeto sobre el que se llamó. Rara vez
se escribe, porque un atributo o una rutina nombrados por sí solos ya se
refieren a los de `self`. Se necesita cuando el objeto tiene que pasarse a
otra parte o devolverse:

```sather
   with_goal : SAME is
      home_score := home_score + 1;
      return self;
   end;
```

`self`, `new`, `void`, `result`, `value` y `out` son palabras que Sather ya
se reservó, y ninguna se puede usar como nombre propio.

## Referencia, no valor

Se llega a un objeto a través de una referencia. Dos nombres para el mismo
marcador ven el mismo puntaje:

```sather
   a ::= #SCOREBOARD("Vixens", "Magpies");
   b ::= a;         -- not a copy
   b.home_goal;
   a.home_score     -- 1
```

`immutable class`, más adelante, es la forma de obtener el otro
comportamiento.
