# Introducción

El [paquete `strings`](https://pkg.go.dev/strings) ofrece funciones para trabajar con strings.
A continuación verás algunas de las funciones del paquete; ¡echa un vistazo a la documentación para conocer el resto!

| Rol                                | Función                                             | Propósito                                                            |
| ---------------------------------- | --------------------------------------------------- | -------------------------------------------------------------------- |
| Conversión de mayúsculas y minúsculas | [ToLower](https://pkg.go.dev/strings#ToLower)    | Convierte un string a minúsculas                                     |
| Conversión de mayúsculas y minúsculas | [ToUpper](https://pkg.go.dev/strings#ToUpper)    | Convierte un string a mayúsculas                                     |
| Búsqueda                           | [Contains](https://pkg.go.dev/strings#Contains)     | Comprueba si un string contiene una subcadena específica             |
| Búsqueda                           | [Count](https://pkg.go.dev/strings#Count)           | Cuenta las apariciones no superpuestas de una subcadena              |
| Búsqueda                           | [HasPrefix](https://pkg.go.dev/strings#HasPrefix)   | Comprueba si un string empieza con una subcadena específica          |
| Búsqueda                           | [HasSuffix](https://pkg.go.dev/strings#HasSuffix)   | Comprueba si un string termina con una subcadena específica          |
| Búsqueda                           | [Index](https://pkg.go.dev/strings#Index)           | Devuelve el índice de la primera aparición de una subcadena, o -1    |
| Modificación                       | [Replace](https://pkg.go.dev/strings#Replace)       | Reemplaza hasta n apariciones de una subcadena                       |
| Modificación                       | [ReplaceAll](https://pkg.go.dev/strings#ReplaceAll) | Reemplaza todas las apariciones de una subcadena                     |
| Modificación                       | [TrimSpace](https://pkg.go.dev/strings#TrimSpace)   | Elimina los espacios en blanco al principio y al final               |
| División o unión                   | [Fields](https://pkg.go.dev/strings#Fields)         | Divide un string en palabras separadas por espacios en blanco        |
| División o unión                   | [FieldsSeq](https://pkg.go.dev/strings#FieldsSeq)   | Obtén cada palabra de una en una                                     |
| División o unión                   | [Join](https://pkg.go.dev/strings#Join)             | Une un slice de strings con un separador                             |
| División o unión                   | [Split](https://pkg.go.dev/strings#Split)           | Divide un string en partes usando un separador                       |
| División o unión                   | [SplitSeq](https://pkg.go.dev/strings#SplitSeq)     | Obtén cada parte de una en una                                       |

```go
import (
    "fmt"
    "strings"
)

// Case conversion
strings.ToLower("Gopher")              // "gopher"
strings.ToUpper("Gopher")              // "GOPHER"

// Searching
strings.Contains("Apple", "le")        // true
strings.Index("Apple", "le")           // 3
strings.Index("Apple", "xyz")          // -1
strings.Count("test", "t")             // 2
strings.HasPrefix("Gopher", "Go")      // true
strings.HasSuffix("Gopher", "er")      // true

// Modifying
strings.TrimSpace("  hello  ")         // "hello"
strings.Replace("aabbcc", "b", "x", 1) // "aaxbcc"
strings.ReplaceAll("aabbcc", "b", "x") // "aaxxcc"

// Splitting or Joining
strings.Fields("  a b\tc  ")               // []string{"a", "b", "c"}
strings.Split("a,b,c", ",")                // []string{"a", "b", "c"}
strings.Join([]string{"a", "b", "c"}, ",") // "a,b,c"

// You do not need to worry about this range syntax yet.
// It is covered later in the range iteration concept.
for word := range strings.FieldsSeq("  a b\tc  ") {
    fmt.Println(word)
}
// Output:
// a
// b
// c

for part := range strings.SplitSeq("a,b,c", ",") {
    fmt.Println(part)
}
// Output:
// a
// b
// c
```
