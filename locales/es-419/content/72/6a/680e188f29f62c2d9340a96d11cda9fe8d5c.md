# Ejecutar los tests

Para ejecutar los tests de un ejercicio, ejecuta el script `<exercise>.test` que está en el directorio del ejercicio:

```bash
tclsh <exercise>.test
```

En la mayoría de los ejercicios, todos los tests, menos el primero, estarán «skipped».
Esto te permite a ti, que estás desarrollando el ejercicio, practicar el desarrollo guiado por tests: escribir solo el código necesario para pasar cada test, uno por uno.
Para anular los comandos de omisión, asigna a la variable de entorno `RUN_ALL` un valor verdadero válido de Tcl \[1\] antes de ejecutar la suite de tests:

```bash
RUN_ALL=yes tclsh <exercise>.test
```

\[1\]: Los valores verdadero/falso de Tcl están documentados en la página de manual de la función de biblioteca de C [Tcl_GetBoolean][bool].

[bool]: https://www.tcl-lang.org/man/tcl8.6/TclLib/GetInt.htm
