# Instrucciones

Diriges los juegos de azar en la sala de juegos del paseo marítimo. Los jugadores tiran los dados, la máquina de garra atrapa un premio y la mesa de cartas necesita que se baraje el mazo y se repartan las manos. Todo funciona gracias al azar. Al final de la noche también quieres una funcionalidad de «repetición» para poder volver a ejecutar una partida en disputa a partir de la misma semilla.

## 1. Tira un dado

Define `roll-die` para que reciba el número de caras y devuelva una tirada en el rango de `1` a `sides` (inclusive).

```factor
6 roll-die .
! => 4   (some value from 1..6)
```

## 2. Atrapa un premio

Define `pick-prize` para que reciba una secuencia de premios y devuelva uno de ellos al azar.

```factor
{ "teddy" "goldfish" "keyring" } pick-prize .
! => "goldfish"
```

## 3. Baraja el mazo

Define `shuffle-deck` para que reciba un mazo (una secuencia) y lo devuelva con las cartas en un orden aleatorio.

```factor
{ 1 2 3 4 5 } shuffle-deck .
! => { 3 1 5 2 4 }
```

## 4. Reparte una mano

Define `deal-hand` para que reciba un mazo y una cantidad `n`, y devuelva `n` cartas *distintas* del mazo.

```factor
{ 10 20 30 40 50 } 3 deal-hand .
! => { 40 10 30 }
```

## 5. Repite la partida desde una semilla

Define `play-seeded` para que reciba una semilla y una quotation, y ejecute la quotation con un generador inicializado con esa semilla entera, de modo que la misma semilla siempre reproduzca el mismo resultado. El resultado de la quotation debe devolverse a quien la llama.

```factor
42 [ 6 roll-die ] play-seeded .
! => the same value every time for seed 42

! Same seed, same game:
99 [ 5 deal-hand ] play-seeded   99 [ 5 deal-hand ] play-seeded   =  .
! => t
```
