# Instrucciones

Vas a escribir código para gestionar el inventario de artículos de una tienda.
El inventario será una referencia a un hash que contiene los artículos del inventario y su cantidad.

## 1. Crea un inventario nuevo a partir de los artículos

Modifica la subrutina `InventoryManagement::create_inventory`, que recibe como argumento una referencia a un array de artículos, para que devuelva una referencia a un hash de inventario recién creado, donde las claves sean los nombres de los artículos y los valores, la cantidad.

## 2. Agrega los artículos al inventario

Modifica la subrutina `InventoryManagement::add_items`, que recibe como argumentos una referencia a un hash de inventario y una referencia a un array de artículos, para que devuelva una referencia a un hash con los artículos agregados al inventario.

## 3. Quita los artículos del inventario

Modifica la subrutina `InventoryManagement::remove_items`, que recibe como argumentos una referencia a un hash de inventario y una referencia a un array de artículos, para que devuelva una referencia a un hash con los artículos quitados del inventario.
Las cantidades de los artículos no deben quedar por debajo de cero.

## 4. Elimina el artículo del inventario por completo

Modifica la subrutina `InventoryManagement::delete_item`, que recibe como argumentos una referencia a un hash de inventario y el nombre de un artículo, para que devuelva una referencia a un hash con el artículo eliminado del inventario por completo.
