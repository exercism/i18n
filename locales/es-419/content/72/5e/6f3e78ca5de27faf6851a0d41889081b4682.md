# Instalación de Swift

Swift está disponible en macOS, Linux y Windows.
El proceso de instalación varía según el sistema operativo que uses.
Con respecto a la compatibilidad con Linux, es importante tener en cuenta que Swift solo es compatible (de forma oficial) con las siguientes distribuciones:
- Ubuntu
- Debian
- RedHat
- Fedora
- Amazon Linux

Si usas una distribución de Linux diferente, tendrás que buscar la manera de instalar Swift por tu cuenta.

## Xcode (macOS)

Swift viene incluido con Xcode, el entorno de desarrollo integrado (IDE) de Apple para el desarrollo en macOS e iOS.
Para el track de Exercism necesitarás tener instalada la versión 16.0 o superior de Xcode.
Xcode está disponible de forma gratuita en la [Mac App Store][xcode].
Hay versiones adicionales de Xcode (incluida la beta más reciente) disponibles en el [centro de desarrolladores de Apple][apple-developer-center].

## macOS y Linux

Para macOS y Linux, existe un gestor de instalación de Swift llamado [swiftly][swiftly].
Es una herramienta de línea de comandos que te permite instalar y administrar varias versiones de Swift en tu sistema.
El comando para instalar swiftly en macOS lo puedes encontrar [aquí][swiftly-macos], y [aquí][swiftly-linux] para Linux.

Otro método de instalación para macOS es [Homebrew][homebrew].
Para Linux, puedes instalar usando el tarball del [sitio web oficial de Swift][tarball].

## Windows

La forma recomendada de instalar Swift en Windows es usar el [instalador de WinGet][winget-windows].
También puedes instalar Swift con el gestor de paquetes Scoop o hacer una instalación manual.
Para ver todas las opciones, consulta la página [Install Swift for Windows][swift-windows].
