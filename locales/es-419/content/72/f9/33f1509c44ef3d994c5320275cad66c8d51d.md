# Pistas


## 1. Convierte Fahrenheit a Celsius

- Puedes convertir Fahrenheit a Celsius restando 32 y luego dividiendo entre 1.8.
- La división tiene mayor precedencia que la resta, así que debes envolver la resta en un bloque o asignarla a una variable para asegurarte de que se realice primero.

## 2. Compara dos temperaturas

- Puedes usar la coincidencia de patrones en el tipo `Temperature` para extraer el valor de las variantes `Celsius` y `Fahrenheit`.
- La función `float.compare` te permite comparar dos temperaturas una vez que las hayas convertido a la misma unidad.

## 3. Ordena las ciudades por temperatura

- La función [`list.sort`][list-sort] te permite ordenar una lista usando una función de comparación dada.

[list-sort]: https://hexdocs.pm/gleam_stdlib/gleam/list.html#sort
