# Tests

Para ejecutar el test del ejercicio con el CLI, ejecuta el siguiente comando desde el directorio del ejercicio:

```bash
clojure -M:test
```

## REPL

Para ejecutar el test del ejercicio con el REPL, ejecuta el siguiente comando desde el directorio del ejercicio:

```bash
$ clojure -m cljs.main -re node
```

Luego, haz `require` del namespace de test del ejercicio y del namespace de test de Clojure):

```clojure
;; replace <exercise> with the exercise's name
=> (require '<exercise>-test)
nil
;; and the test namespace
=> (require 'cljs.test)
```

Cambia el ns al namespace de test:

```clojure
;; replace <exercise> with the exercise's name
=> (ns <exercise>-test)
nil
```

Luego, llama a `run-tests`:

```clojure
=> (cljs.test/run-tests)
```
