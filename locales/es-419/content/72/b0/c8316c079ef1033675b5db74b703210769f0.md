# Instrucciones

En este ejercicio vas a trabajar con cuentas de ahorro.
Cada año, el saldo de tu cuenta de ahorro se actualiza según su tasa de interés.
La tasa de interés que te da tu banco depende de la cantidad de dinero que haya en tu cuenta (su saldo):

- 3.213% para un saldo menor que `0` dólares (el saldo se vuelve más negativo).
- 0.5% para un saldo mayor o igual a `0` dólares y menor que `1000` dólares.
- 1.621% para un saldo mayor o igual a `1000` dólares y menor que `5000` dólares.
- 2.475% para un saldo mayor o igual a `5000` dólares.

Tienes cuatro tareas, y cada una se ocupa de tu saldo y de su tasa de interés.

## 1. Calcula la tasa de interés

Implementa la función `InterestRate()` para calcular la tasa de interés según el saldo especificado:

```go
InterestRate(200.75)
// => 0.5
```

Ten en cuenta que el valor que se devuelve es un `float32`.

## 2. Calcula el interés

Implementa la función `Interest()` para calcular el interés según el saldo especificado:

```go
Interest(200.75)
// => 1.003750
```

Ten en cuenta que el valor que se devuelve es un `float64`.

## 3. Calcula la actualización anual del saldo

Implementa la función `AnnualBalanceUpdate()` para calcular la actualización anual del saldo, teniendo en cuenta la tasa de interés:

```go
AnnualBalanceUpdate(200.75)
// => 201.75375
```

Ten en cuenta que el valor que se devuelve es un `float64`.

## 4. Calcula los años antes de alcanzar el saldo deseado

Implementa la función `YearsBeforeDesiredBalance()` para calcular la cantidad mínima de años necesarios para alcanzar el saldo deseado, teniendo en cuenta que cada año se suma el interés al saldo.
Esto significa que el saldo después de un año es: saldo inicial + interés del saldo inicial.
El saldo después del segundo año es: saldo después de un año + interés del saldo después de un año.
Y así sucesivamente, hasta que el saldo del año actual sea mayor o igual que el saldo objetivo.

```go
balance := 200.75
targetBalance := 214.88
YearsBeforeDesiredBalance(balance, targetBalance)
// => 14
```

Ten en cuenta que el valor que se devuelve es un `int`.
