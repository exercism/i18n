# Instalación

## Opciones de instalación

¡La versión actual de Unison está disponible para Mac OS X, Linux de 64 bits y usuarios de Windows! Esperamos que, si estás probando Unison, vengas a hablar con nosotros en el foro de Exercism o en el [Discord de Unison](https://unison-lang.org/discord). ¡Ven a hacer preguntas y a reportar los problemas que encuentres! ¡Queremos que tengas una experiencia acogedora y positiva cuando estés empezando! 😊

Puedes descargar Unison con [homebrew](https://brew.sh/), [Nix](https://github.com/ceedubs/unison-nix/#usage), o directamente mediante binarios empaquetados. Todas estas opciones de descarga se describen en la [página de instrucciones de instalación de nuestro sitio web](https://www.unison-lang.org/learn/quickstart/#installation-options). Una vez que tengas el UCM instalado, ¡vuelve aquí!

### Opción 1: usar Homebrew

Primero [instala homebrew](https://brew.sh/) si aún no lo tienes.

Luego, desde la línea de comandos, escribe estos comandos:

```
brew tap unisonweb/unison
brew install unison-language
```

Esto instalará el ejecutable del gestor de la base de código de Unison, `ucm`. Si estás actualizando desde una versión anterior, solo haz

```
brew upgrade unison-language.
```

Nota: si en este punto te pide un nombre de usuario y una contraseña de GitHub, asegúrate de haber escrito bien unisonweb/unison.

### Opción 2: instalación manual para usuarios de Mac y Linux

[Los enlaces de instalación manual para Linux y Mac están aquí](https://www.unison-lang.org/learn/quickstart/#installation-options), en las respectivas secciones de descarga manual para Linux y Mac.

Ejecutarás un comando en tu shell parecido a este, pero el enlace de arriba contendrá el binario más actualizado:

```
mkdir unisonlanguage
curl -L https://github.com/unisonweb/unison/releases/download/release_VERSION_NAME/ucm-YOUR_PLATFORM.tar.gz --output unisonlanguage/ucm.tar.gz
tar -xzf unisonlanguage/ucm.tar.gz -C unisonlanguage
./unisonlanguage/ucm
```

### Opción 3: instalación manual para usuarios de Windows

1. Configura tu aplicación de terminal predeterminada como «Windows Terminal» para obtener mejores resultados. Busca «Terminal» en Settings, o sigue [esta guía práctica.](https://bit.ly/3IXwdlY)
2. Si no estás seguro de si ya lo tienes, instala Git:
  * Con winget: `winget install --id Git.Git -e --source winget`
  * Si usas Windows 10 y no tienes winget, puedes instalarlo desde [la Microsoft Store](https://www.microsoft.com/en-us/p/app-installer/9nblggh4nns1), y luego ejecutar el comando de arriba.
3. [Descarga el UCM con el enlace que aparece aquí](https://www.unison-lang.org/learn/quickstart/#installation-options) y extráelo en la ubicación que prefieras.
4. Ejecuta `ucm.exe`

### Opción 4: instalación con Nix
Ve a [https://github.com/ceedubs/unison-nix/#usage](https://github.com/ceedubs/unison-nix/#usage) y sigue las instrucciones del readme que encontrarás allí.

## Crea tu base de código de Unison

Ejecuta `ucm` para inicializar una base de código de Unison en `$HOME/.unison`. Aquí es donde Unison guardará las definiciones de función, los tipos, los espacios de nombres, etc. De forma predeterminada, el gestor de la base de código de Unison (abreviado «UCM») empezará a descargar la biblioteca estándar, llamada `base`, que usarás para escribir código Unison. ¡Puede tardar un momento! 🕰

## Flujo de trabajo con Unison

Cuando quieras escribir código Unison, ejecutarás el comando `ucm` para iniciar el gestor de la base de código. Luego, el UCM observará los cambios de cualquier archivo con extensión `.u` en el directorio desde el que se ejecuta. Por ejemplo, quizá estés implementando funciones en un archivo llamado `scratch.u` en un directorio llamado `~/exercism/unison/my-exercise/`. Deberías hacer `cd` a `~/exercism/unison/my-exercise/` y ejecutar `ucm`. Así te asegurarás de que el UCM esté observando tu archivo `scratch.u` en busca de cambios.

Si en algún momento no tienes claro en qué directorio está el `ucm` observando los cambios de archivos, se muestra en la pantalla de bienvenida al iniciar la CLI.

```
👀 I'm watching for changes to .u files under /Users/myUser/exercism/unison/my-exercise
```

[¡Consulta más consejos sobre el flujo de trabajo aquí!](https://exercism.org/docs/tracks/unison/workflow)

## Compatibilidad con editores

Puedes usar cualquier editor de texto para escribir tus archivos `.u`. Unison tiene [compatibilidad con LSP](https://github.com/unisonweb/unison/blob/trunk/docs/language-server.markdown), así que tu IDE favorito puede ayudarte con cosas como ver los tipos al pasar el cursor y el autocompletado. A continuación se muestran algunos editores populares con compatibilidad con Unison:

### Vim

Con [vim-plug](https://github.com/junegunn/vim-plug):

1. Instala [`vim-plug`](https://github.com/junegunn/vim-plug) si aún no lo tienes.
2. Agrega lo siguiente a tu .vimrc: `Plug 'unisonweb/unison', { 'branch': 'trunk', 'rtp': 'editor-support/vim' }`
3. Ejecuta el comando de vim `:PlugInstall`.

Para más información, ejecuta `:help unison`
desde vim o consulta el [documento de ayuda en línea](https://github.com/unisonweb/unison/blob/trunk/editor-support/vim/doc/unison.txt).

### Atom
Desde la consola, ejecuta:

```
apm install unisonweb/atom-unison
```

### VS Code

1. Abre la vista de extensiones haciendo clic en el ícono de extensiones en la Activity Bar, a un lado de VS Code, o con ⇧⌘X.
2. Busca «unison»
3. Instala la [extensión Unison para VS Code](https://marketplace.visualstudio.com/items?itemName=unison-lang.unison)

### Emacs
Instala [`unison-mode`](https://github.com/dariooddenino/unison-mode-emacs).
