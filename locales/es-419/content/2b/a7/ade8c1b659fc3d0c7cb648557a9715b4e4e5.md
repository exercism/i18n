# Instrucciones

Has estado trabajando en un proyecto que permite a los usuarios subir archivos al servidor para compartirlos con otros usuarios. Te han encargado escribir una función para verificar que una carga coincida con su [tipo de medio][mimetype]. Investigas un poco y descubres que los primeros bytes de un archivo suelen ser únicos de ese tipo de archivo, lo que le da una especie de firma.

Usa la siguiente tabla como referencia:

| Tipo de archivo | Extensión común | Tipo de medio                | «firma» binaria                                  |
| --------------- | --------------- | ---------------------------- | ------------------------------------------------ |
| ELF             | `"exe"`         | `"application/octet-stream"` | `0x7F, 0x45, 0x4C, 0x46`                         |
| BMP             | `"bmp"`         | `"image/bmp"`                | `0x42, 0x4D`                                     |
| PNG             | `"png"`         | `"image/png"`                | `0x89, 0x50, 0x4E, 0x47, 0x0D, 0x0A, 0x1A, 0x0A` |
| JPG             | `"jpg"`         | `"image/jpg"`                | `0xFF, 0xD8, 0xFF`                               |
| GIF             | `"gif"`         | `"image/gif"`                | `0x47, 0x49, 0x46`                               |

## 1. Dada una extensión, devuelve el tipo de medio esperado

Implementa la función `type_from_extension/1`. Debe recibir una extensión de archivo (string) y devolver el tipo de medio (string) o nil si la extensión no coincide con las esperadas.

```elixir
FileSniffer.type_from_extension("exe")
# => "application/octet-stream"

FileSniffer.type_from_extension("txt")
# => nil
```

## 2. Dado un archivo binario, devuelve el tipo de medio esperado

Implementa la función `type_from_binary/1`. Debe recibir un archivo (binario) y devolver el tipo de medio (string) o nil si la firma del archivo no coincide con las esperadas.

```elixir
file = File.read!("application.exe")
FileSniffer.type_from_binary(file)
# => "application/octet-stream"

file = File.read!("example.txt")
FileSniffer.type_from_binary(file)
# => nil
```

No te preocupes por leer el archivo como binario. Asume que eso ya se hizo por ti y que las pruebas lo proporcionan como argumento.

## 3. Dada una extensión y un archivo binario, verifica que el archivo coincida con el tipo esperado

Implementa la función `verify/2`. Debe recibir un archivo (binario) y una extensión (string) y devolver una tupla `:ok` o `:error`.

```elixir
file = File.read!("application.exe")

FileSniffer.verify(file, "exe")
# => {:ok, "application/octet-stream"}

FileSniffer.verify(file, "png")
# => {:error, "Warning, file format and file extension do not match."}
```

[mimetype]: https://en.wikipedia.org/wiki/Media_type
