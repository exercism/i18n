# Instrucciones

En este ejercicio vas a escribir un TreasureChest genérico (¡y mágico!) para guardar algunos tesoros.

## 1. Define el tipo personalizado genérico TreasureChest

Define un tipo personalizado `TreasureChest` con una sola variante.

La variante debe tener un valor `String` asociado, que se usará para almacenar la contraseña del cofre del tesoro.

La variante también debe tener un valor genérico asociado, que se usará para almacenar el tesoro.
Este valor es genérico para que el tesoro pueda ser cualquier cosa.

## 2. Define el tipo UnlockResult

Define un tipo personalizado `UnlockResult` con dos variantes.

La primera variante debe ser `Unlocked`, y debe contener un valor genérico, que se usará para almacenar el tesoro.

La segunda variante debe ser `WrongPassword`, que no contiene ningún valor.

## 3. Define la función get_treasure

Esta función debe recibir dos parámetros:

- un tipo personalizado genérico `TreasureChest`
- un `String` (para probar una contraseña)

Esta función debe comparar el intento de contraseña proporcionado con el `String` del `TreasureChest`.

La función debe devolver un `UnlockResult`.

Si las contraseñas coinciden, devuelve `Unlocked` con el valor genérico del `TreasureChest` (¡el tesoro!)

Si las contraseñas no coinciden, devuelve `WrongPassword`.
