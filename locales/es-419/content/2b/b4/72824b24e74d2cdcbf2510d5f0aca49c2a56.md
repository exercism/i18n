# Anexo de instrucciones

Una posible solución para este ejercicio es implementar tu propia función de exponenciación modular.
Para aprender más sobre esto, consulta la [siguiente página](https://en.wikipedia.org/wiki/Modular_exponentiation).

## Para puntos extra

Muchas implementaciones no funcionan para todo el dominio de argumentos.
Hay tests opcionales adicionales definidos que ayudan a garantizar que todos los argumentos válidos produzcan resultados válidos.

Para ejecutar los tests de bonificación, quita el flag `#[ignore]` y ejecuta los tests con la feature `big-primes`, así:

```bash
$ cargo test --features big-primes
```
