# Introducción

## Arrays

En Common Lisp, al igual que en otros lenguajes, un array (es decir, un arreglo) es un conjunto de elementos a los que se accede mediante índices enteros.
Los tipos de los elementos pueden ser heterogéneos.
El array puede ser multidimensional (no simplemente unidimensional).

### Creación

`make-array` permite crear arrays.
Tiene muchas opciones, pero en sus formas más simples permite crear arrays de N dimensiones con todos los elementos inicializados a un mismo valor, o con el array inicializado a los valores de otra secuencia (como una lista).
Su primer argumento es una lista con el tamaño de cada dimensión.

```lisp
(make-array '(4) :initial-element 3)    ; => #(3 3 3 3)
(make-array '(2 2) :initial-element 'x) ; => #2A((X X) (X X))
```

(Fíjate cómo se imprimen los arrays de N dimensiones con el número de dimensiones.)

También puedes crear arrays usando el mismo formato en el que se imprimen:

```lisp
#(x y z)         ; => #(X Y Z)
#2A((1 2) (3 4)) ; => #2A((1 2) (3 4))
```

### Acceder a los elementos

Para acceder a los elementos de un vector, usa `aref`; los índices empiezan en cero.
La cantidad de índices que proporciones debe coincidir con el rango del array.

```lisp
(aref #2A((1 2 3) (3 4 5)) 
       1 0)           ; => 3
(aref #3A(((a b) (c d)) 
           ((e f) (g h)) 
           ((t u) (v w))) 
       2 0 1)         ; => U
(aref #2A((1) (2)) 0) ; => ERROR (because not enough indexes provided)
```
