# Instrucciones

Elena, la nueva gerente de calidad de una fábrica de periódicos, te pide que escribas un pequeño programa para monitorear la sala de producción.

## 1. Define un error personalizado

Define una clase de tupla de error `machine-error` usando la palabra de análisis `ERROR:`. No necesita slots.

```factor
machine-error   ! throws a fresh machine-error
```

## 2. Verifica la humedad

Define `check-humidity`. Toma una lectura de humedad de la pila y hace `throw` del string `"humidity too high"` cuando la lectura es estrictamente mayor que `70`. De lo contrario, no devuelve nada.

```factor
50 check-humidity   ! returns nothing
80 check-humidity   ! throws "humidity too high"
```

## 3. Verifica la temperatura

Define `check-temperature`. Toma una lectura de temperatura y hace `throw` del string `"temperature too high"` cuando la lectura es estrictamente mayor que `500`. De lo contrario, no devuelve nada.

```factor
400 check-temperature   ! returns nothing
600 check-temperature   ! throws "temperature too high"
```

## 4. Monitorea la máquina

Define `monitor` para que tome una humedad y una temperatura de la pila y ejecute ambas verificaciones. Si alguna de las verificaciones hace `throw`, `monitor` debe hacer `throw` de un `machine-error` nuevo en su lugar. Si ambas pasan, `monitor` no devuelve nada.

```factor
50 400 monitor   ! returns nothing
80 400 monitor   ! throws a machine-error
50 600 monitor   ! throws a machine-error
```

## 5. Monitorea un lote de lecturas

Define `monitor-batch` para que tome un array de lecturas `{ humidity temperature }` y devuelva cuántas de ellas fallarían (es decir, cuántas harían que `monitor` haga `throw`).

```factor
{ { 50 400 } { 80 400 } { 50 600 } { 60 200 } } monitor-batch .
! => 2
```
