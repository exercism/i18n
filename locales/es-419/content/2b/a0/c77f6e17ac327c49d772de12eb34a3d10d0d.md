# Instrucciones

En este ejercicio vas a escribir código para imprimir insignias con el nombre de los empleados de una fábrica.
Los empleados tienen un ID, un nombre y el nombre de un departamento.
Las etiquetas de las insignias de los empleados tienen el siguiente formato: `"[id] - name - DEPARTMENT"`.

## 1. Imprime una insignia para un empleado

Implementa la función `print_name_badge`. Debe recibir un ID, un nombre y un departamento.
Debe devolver la etiqueta de la insignia, con el nombre del departamento en mayúsculas.

```R
print_name_badge(67, "Katherine Williams", "Strategic Communication")
# => "[67] - Katherine Williams - STRATEGIC COMMUNICATION"
```

## 2. Imprime una insignia para un empleado nuevo

Debido a una peculiaridad del sistema informático, a veces los empleados nuevos todavía no tienen un ID cuando empiezan a trabajar en la fábrica.
Como las insignias son obligatorias, recibirán una insignia temporal sin el prefijo del ID.

Extiende la función `print_name_badge`. Cuando falte el id, debe imprimir una insignia sin él.

```R
print_name_badge(NA, "Robert Johnson", "Procurement")
# => "Robert Johnson - PROCUREMENT"
```

## 3. Imprime una insignia para el dueño

Incluso el dueño de la fábrica tiene que llevar una insignia en todo momento.
Sin embargo, un dueño no tiene departamento y nunca lo tendrá: está por encima de todos los departamentos.
En este caso, la etiqueta debe imprimir `"OWNER"` en lugar del nombre del departamento.

Extiende la función `print_name_badge`. Cuando el departamento sea `NULL`, asume que la insignia pertenece al dueño de la empresa.

```R
print_name_badge(204, "Rachel Miller", NULL)
# => "[204] - Rachel Miller - OWNER"
```

Ten en cuenta que es posible que el dueño también sea un empleado nuevo.

```R
print_name_badge(NA, "Rachel Miller", NULL)
# => "Rachel Miller - OWNER"
```

## 4. Calcula el salario total de los empleados sin ID

Como una medida aproximada de qué tan bien se están emitiendo los ID, quieres ver el salario combinado de los empleados que no tienen ID.
Un valor alto significa que hay muchos esperando, o que el problema está afectando a personas con más antigüedad: ambas cosas son malas.

Implementa la función `salaries_no_id`, que recibe un vector de ID y un vector correspondiente de salarios, y devuelve la suma de los salarios de las personas que todavía no tienen ID.
Ambos vectores tienen la misma longitud.

```R
ids <- c(204, NA, 210, 352, NA, 263)
salaries <- c(23, 21, 47, 35, 17, 101) * 1000
salaries_no_id(ids, salaries)
# => 38,000
```

_Como aprendizaje adicional que no se evalúa:_ Si no hay empleados sin ID, ¿cuál es el «vector vacío» que estás sumando?
