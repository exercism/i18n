# error de cláusula de función con raise

[comment]: # (This error is raised when the submission includes a call to `raise FunctionClauseError` rather than having Elixir fail in matching the call to the two_fer function for non-string types.)

No llames directamente a `raise FunctionClauseError`.

> Lanzar este error es un [code smell](https://en.wikipedia.org/wiki/Code_smell) que indica que las cláusulas de la función se deberían reordenar o que se deberían implementar guardas para evitar que la función coincida.

1. Cuando Elixir ejecuta código, intenta hacer coincidir la llamada a las [funciones con nombre](https://elixir-lang.org/getting-started/modules-and-functions.html#named-functions) y sus parámetros con cada función, de arriba a abajo.
2. Si se usan [guardas](https://hexdocs.pm/elixir/master/guards.html), es posible evitar que se invoque una función con argumentos que no coinciden con el uso previsto de la función.
3. Si no hay ninguna coincidencia para una función con nombre, la [BEAM VM](<https://en.wikipedia.org/wiki/BEAM_(Erlang_virtual_machine)>) lanza un `FunctionClauseError` en tiempo de ejecución.
