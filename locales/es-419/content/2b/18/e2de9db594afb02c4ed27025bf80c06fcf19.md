# Instalación

Lo único que necesitarás para ejecutar estos ejercicios es tener instalados [CommandBox CLI](https://commandbox.ortusbooks.com/getting-started-guide) y [Java 8](https://java.com/en/download/). CommandBox CLI es compatible con Mac, Linux y Windows, y la guía de instalación se encuentra aquí:

[https://commandbox.ortusbooks.com/setup/installation](https://commandbox.ortusbooks.com/setup/installation)

Un ejemplo de cómo instalar CommandBox CLI si eres usuario de Homebrew en Mac sería:

```bash
brew install commandbox
```

Una vez que tengas la CLI instalada, puedes jugar con el REPL:

```bash
box repl
```

Puedes ejecutar directamente páginas .cfm:

```bash
box exec myTest.cfm
```

E incluso puedes iniciar un servidor web en cualquier directorio de tu disco duro:

```bash
box server start
```

CommandBox tiene un shell interactivo que puedes usar, que tiene autocompletado con tabulación mejorado y se ejecuta más rápido. Puedes entrar a él ejecutando el binario `box` sin argumentos.

```bash
box
```
