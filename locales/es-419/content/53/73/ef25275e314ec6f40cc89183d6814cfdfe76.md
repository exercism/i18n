# Acerca de

Al recorrer una secuencia, a veces el elemento por sí solo no es suficiente: también necesitas la posición. Las palabras de iteración *indexada* de Factor le dan a la cita por elemento ambos valores, con el índice en la parte superior de la pila. `times` es la palabra relacionada para la iteración contada sin una secuencia de fondo.

```factor
USING: io kernel math.parser sequences ;

! map-index: build a new sequence; quot sees ( elt index )
{ "alice" "bob" "carol" }
[ number>string ": " glue ] map-index .
! => { "alice: 0" "bob: 1" "carol: 2" }

! each-index: for side effect; quot sees ( elt index )
{ "alice" "bob" } [
    number>string ": " glue print
] each-index
! prints alice: 0
! prints bob: 1

! times: run a quotation N times
3 [ "tick " print ] times
```

| palabra      | efecto                                                               |
|--------------|----------------------------------------------------------------------|
| `each-index` | `( seq quot: ( elt index -- ) -- )`                                  |
| `map-index`  | `( seq quot: ( elt index -- newelt ) -- newseq )`                    |
| `times`      | `( n quot: ( -- ) -- )`, pero mira más abajo                         |

Una sutileza sobre `times`: aunque su cita está documentada como `( -- )`, la palabra es `inline`, así que una cita con un efecto balanceado como `( str -- str )` funciona sin problema y va pasando la pila de una iteración a otra. Eso te da un acumulador contado sin ningún estado mutable:

```factor
USING: kernel sequences ;

"" 3 [ "clop " append ] times .    ! => "clop clop clop "
```

El mismo truco sirve para `each-index` y `map-index`: el efecto declarado por elemento es un *mínimo*, no un máximo.
