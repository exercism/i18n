# Strings

Los strings son una serie de caracteres, rodeados de comillas.
Se admiten tanto las comillas simples como las dobles.

```php
<?php

$where = "Spain";
$what = 'rain';
```

## Expansión de variables en strings

En los strings con comillas dobles, si se hace referencia a una variable que está dentro del ámbito, su valor se inserta en el string.

```php
<?php

$answer = 42;
$expanded = "The answer to life, the universe, and everything is $answer"; 
```

## Compatibilidad con la codificación de caracteres

Históricamente, las funciones de strings en PHP solo admitían caracteres ASCII y no admitían las codificaciones Unicode modernas.
Los caracteres ASCII ocupan 1 byte cada uno, mientras que los caracteres Unicode pueden medir de 1 a 4 bytes.
Si necesitas manipular strings de Unicode de forma segura, consulta las [versiones multibyte][multi-byte-fns] de las funciones históricas.

```php
<?php

$byte_length = strlen('😃'); // => 4
$string_length = mb_strlen('😃'); // => 1
```

[multi-byte-fns]: https://www.php.net/manual/en/ref.mbstring.php
