# Módulo

Las comparaciones con el operador módulo son perfectamente válidas en Crystal, pero una forma más legible de comparar el residuo de una división es con el método [`divisible_by?`][divisible_by].
O incluso mejor, si quieres comprobar si un número es par o impar, usa los métodos [`odd?`][odd?] y [`even?`][even?].

Por ejemplo:

```crystal
# Rather than:
number %% 2 == 0

# Consider:
number.even?
```
