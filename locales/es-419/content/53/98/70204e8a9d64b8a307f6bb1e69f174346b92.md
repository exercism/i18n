# Acerca de

Puedes usar los [tipos de enumeración][enumeration types] siempre que tengas un conjunto fijo de valores constantes. Usar un `enum` te da una forma segura en cuanto a tipos de interactuar con valores constantes. Un enum se define con la palabra clave `enum`. Para referirte a un miembro de un enum, antepones el nombre del enum y un punto (por ejemplo, `Status.Active`).

Cada miembro del enum es una asociación de un nombre y un valor `int`. Si el primer miembro no tiene un valor explícito, su valor se establece en `0`. Si no se define explícitamente un valor para un miembro del enum, su valor se asigna automáticamente al valor del miembro anterior más `1`.

```csharp
enum Season
{
    Spring,     // Auto set 0
    Summer = 2, // Set the value 2
    Autumn,     // Auto set 3
    Winter = 7  // Set the value 7
}
```

Los enums son muy declarativos. Compara las siguientes dos llamadas a métodos:

```csharp
Users.WithStatus(1)
Users.WithStatus(Status.Active)
```

Para quien lee el código, la segunda versión (con enum) será más fácil de entender.

## Enums con tipo numérico

Aunque el tipo numérico predeterminado de los valores es `int`, lo puedes cambiar si especificas explícitamente cualquier otro tipo [numérico entero][integral numeric].

El siguiente enum usa el tipo numérico `byte` para sus valores:

```csharp
enum Priority : byte
{
    Low = 0,
    Medium = 127,
    High = 255
}
```

## Convertir a un miembro del enum

Siempre deberías considerar usar un enum cuando quieras modelar algo como un Boolean. Además de los beneficios de legibilidad ya mencionados, los enums tienen otra ventaja sobre los Boolean: siempre se pueden agregar valores nuevos a un enum, mientras que un valor Boolean solo puede ser `true` o `false`. Por eso, usar un enum está más preparado para el futuro.

```csharp
enum Status
{
    Inactive = 0,
    Active = 1
}

Status active = (Status) 1;
active == Status.Active; // True
```

Ten en cuenta que, aunque _puedes_ convertir valores enteros a un enum, hacerlo puede dar lugar a resultados inesperados cuando el valor entero no corresponde a ningún valor del enum:

```csharp
Status status = (Status) 2;
status == Status.Inactive; // False
status == Status.Active;   // False
```

## Convertir una cadena a un enum

A veces es útil convertir una cadena a un miembro del enum según su nombre con [`Enum.Parse`][enum parse]:

```csharp
var input = "Inactive";
Status status = (Status)Enum.Parse(typeof(Status), input);
// Inactive
```

Para comprobar si un nombre o un valor existe en el enum, puedes usar [`Enum.TryParse`][enum tryparse] o [`Enum.IsDefined`][enum isdefined]; ambos devuelven un Boolean que indica si el miembro del enum existe:

```csharp
bool doesExist = Enum.IsDefined(typeof(Status), "Inexistent");
// False
```
