# Acerca de

Como la mayoría de los lenguajes de programación, Gleam tiene «efectos secundarios», por lo que las funciones pueden leer y cambiar el estado del mundo, además de devolver un valor.

El módulo `gleam/io` de la biblioteca estándar de Gleam proporciona funciones para imprimir strings en la consola.

```gleam
io.println("Hello, Joe!")
// Hello, Joe!
// -> Nil
```

Otros paquetes pueden proporcionar otras funciones de entrada/salida, como `simplifile`, un paquete que proporciona funciones para leer y escribir archivos.

```gleam
simplifile.read("favourite-colour.txt")
// -> Ok("Pink\n")
```
