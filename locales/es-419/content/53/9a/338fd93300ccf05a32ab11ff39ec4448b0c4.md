# Pruebas

Para ejecutar las pruebas de esta pista, necesitarás instalar DUnitX. Consulta las instrucciones de [instalación](http://www.exercism.org/docs/tracks/delphi/installation) para obtener más información.

### Cargar ejercicios en Delphi

Si Delphi está instalado correctamente y los archivos con extensión `*.dpr` están asociados con Delphi, hacer doble clic en el archivo `*.dpr` que se proporciona iniciará Delphi y cargará el ejercicio/proyecto. `control + F9` es el atajo de teclado para compilar el proyecto, o bien, si presionas `F9`, se compilará y ejecutará el proyecto.

Como alternativa, puedes iniciar Delphi y cargar tu proyecto desde el menú desplegable `File`.
