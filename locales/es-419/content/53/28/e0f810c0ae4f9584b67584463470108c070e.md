# Instrucciones

Heidi, una joven alienígena de Forth, necesita avanzar en su proyecto de alfabetos humanos y te pregunta si puedes ayudarla a programar algunas palabras que va a necesitar.

## 1. Compara dos caracteres

Define `compare-chars` para que tome dos caracteres y devuelva el símbolo `less`, `greater` o `equal` según si el primero es menor que, mayor que o igual al segundo. Compara distinguiendo mayúsculas y minúsculas.

```factor
CHAR: A CHAR: B compare-chars .   ! => less
CHAR: B CHAR: A compare-chars .   ! => greater
CHAR: A CHAR: A compare-chars .   ! => equal
CHAR: A CHAR: a compare-chars .   ! => less
```

## 2. Determina el tamaño de un carácter

Heidi necesita saber si un carácter es «big» (mayúscula), «small» (minúscula) o si no tiene tamaño. Define `size-of-char` para que devuelva `big`, `small` o `no-size`.

```factor
CHAR: A size-of-char .       ! => big
CHAR: a size-of-char .       ! => small
CHAR: 5 size-of-char .       ! => no-size
CHAR: space size-of-char .   ! => no-size
```

## 3. Cambia el tamaño de un carácter

A veces, Heidi necesita cambiar un carácter a un tamaño diferente. Define `change-size-of-char` para que tome un carácter y un tamaño deseado (`big` o `small`) y devuelva el carácter con la capitalización correspondiente.

```factor
CHAR: a big change-size-of-char .     ! => 65   (CHAR: A)
CHAR: A small change-size-of-char .   ! => 97   (CHAR: a)
```

## 4. Determina el tipo de un carácter

Heidi también necesita saber qué *tipo* de carácter es. Define `type-of-char` para que devuelva:

- `alpha` para cualquier letra (mayúscula o minúscula)
- `numeric` para un dígito decimal
- `space` para el carácter de espacio
- `newline` para el carácter de nueva línea
- `unknown` en cualquier otro caso

```factor
CHAR: A type-of-char .       ! => alpha
CHAR: 5 type-of-char .       ! => numeric
CHAR: space type-of-char .   ! => space
CHAR: \n type-of-char .      ! => newline
CHAR: ! type-of-char .       ! => unknown
```
