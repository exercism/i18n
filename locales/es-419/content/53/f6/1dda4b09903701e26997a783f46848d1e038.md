# Pruebas

Para ejecutar las pruebas, ejecuta el comando `sbt test` en el directorio del ejercicio.
Consulta la [página de pruebas](https://exercism.org/docs/tracks/scala/tests) para obtener más información.

## Pruebas omitidas

Inicialmente, solo se habilitará la primera prueba.
Esto es para animarte a resolver el ejercicio paso a paso.
Una vez que logres que la primera prueba pase, elimina la palabra clave `pending` del principio de la siguiente prueba y trabaja en lograr que esa prueba pase.
