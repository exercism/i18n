# Instalación

## Instala .NET 10

La ruta de Visual Basic usa .NET 10.
Para compilar y probar los ejercicios de forma local, instala [el SDK de .NET 10 para tu sistema operativo][install-sdk]:
Instala el SDK, no solo el entorno de ejecución.

## Verifica tu instalación

Abre una nueva terminal y ejecuta:

```bash
dotnet --version
```

El comando debería mostrar `10.0.0` o una versión posterior.

## Compatibilidad con editores

El SDK de .NET y un editor de texto sencillo es todo lo que necesitas para completar los ejercicios.
Para funcionalidades más avanzadas, como el autocompletado de código y la depuración, considera uno de estos editores:

- [Visual Studio 2026][visual-studio] en Windows
- [Visual Studio Code][visual-studio-code] en Windows, Linux o macOS
- [JetBrains Rider][rider] en Windows, Linux o macOS
