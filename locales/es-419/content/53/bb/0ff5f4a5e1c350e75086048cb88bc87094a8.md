# Introducción

## Variables y asignación

R es un lenguaje de tipado dinámico, así que en general no es necesario especificar el tipo de una variable. El operador de asignación preferido es `<-` 

```R
x <- 42
avogadro <- 6.02e23
mystr <- "Hello, World!"
```

Usar `=` en lugar de `<-` muchas veces funciona, pero no siempre, y se considera de mal estilo.
Si trabajas en RStudio, puedes escribirlo con el atajo de teclado `Alt-minus`.

Los operadores son en su mayoría convencionales, pero fíjate en `%/%` y `%%`:

```R
2 + 3   # 5
2 - 3   # -1
2 * 3   # 6
2 / 3   # 0.6666667
8 %/% 3 # 2 (integer division)
8 %% 3  # 2 (remainder)
2 ^ 3   # 8 (exponential)
```

En R, `#` inicia un comentario de una sola línea.
No hay una sintaxis aparte para los comentarios de varias líneas.

## Funciones

Para definir una función:

```R
squareit <- function(x) {
    x * x
}
```

Las funciones pueden tener cero o más argumentos, separados por comas.
Se necesitan paréntesis (`()`) al usar `function()`, aunque no haya parámetros.

Se pueden especificar valores predeterminados para los argumentos de una función, aunque deben ir después de cualquier argumento sin valor predeterminado, y se usa `=` y no `<-` para asignar el valor predeterminado.
Como un ejemplo bastante inútil:

```R
squareit <- function(x = 42) {
    x * x
}

squareit()
#> [1] 1764
```

Las llaves (`{ }`) no son estrictamente necesarias para cuerpos de función de una sola línea, pero incluirlas se considera buen estilo.

R devuelve automáticamente el valor final de una función, como en los ejemplos anteriores.

`return()` se puede usar en cualquier parte del cuerpo de la función para hacer explícito un valor de retorno.

Llamar a una función es igual que en muchos otros lenguajes:

```R
squareit(3)
#> [1] 9
```
