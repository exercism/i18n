# Pistas

## General

- Todas las direcciones de memoria de este ejercicio están alineadas a 16 bytes, así que las variantes de movimiento alineadas (`movaps` para números de punto flotante, `movdqa` para enteros) son las apropiadas.
  La memoria alineada también se puede usar directamente como operando fuente (pero no como destino).
- Las máscaras se pueden definir en memoria.

## 1. Rectifica la traza

- El signo de un número de punto flotante de 32 bits es su bit más alto.
  Poner a cero el bit más alto hace que el número no sea negativo.
- Es posible poner a cero el bit más alto al aplicar AND con un número de 32 bits en el que todos los bits están activados excepto el más alto.
- Una máscara se puede definir en memoria con 4 números de 32 bits empaquetados.
- La instrucción `andps` aplica AND a valores de punto flotante.

## 2. Lee la escala de un temblor

- El campo del exponente de un número de punto flotante IEEE-754 de 32 bits está en los bits de las posiciones 23 a 30, inclusive.
- Los bits del exponente se pueden aislar al aplicar AND (`andps` o `pand`) a los números de punto flotante con una máscara en la que solo estén activados los bits 23 a 30.
- Una vez aislados los bits del exponente, se pueden deslizar hasta el fondo de cada carril con un desplazamiento lógico a la derecha (`psrld`).
- El sesgo de un número de punto flotante IEEE-754 de 32 bits es 127.
  Se puede eliminar al restar 127 de cada carril (`psubd`).

## 3. Reduce la resolución

- Un desplazamiento aritmético a la derecha (`psrad`) de `n` divide entre `2^n` y, al mismo tiempo, conserva el signo y redondea hacia menos infinito.
- Las instrucciones de desplazamiento empaquetado toman su cuenta de un inmediato o de un registro `xmm`, no de un registro de propósito general (GPR).
- La instrucción `movq` se puede usar para mover 64 bits sin procesar de un GPR a un registro `xmm`.

## 4. Pon compuertas a los canales

- `por` se puede usar para combinar todos los bits activados en cualquiera de los dos operandos.
- `pandn` calcula ((NOT destino) AND origen) en una sola instrucción.
  Se puede usar para poner a cero todos los bits del origen que están activados en el destino.

## 5. Alterna los bits de calibración

- Para invertir solo los bits desbloqueados, primero hay que poner a cero todos los bits bloqueados en el valor de alternancia.
- `pandn` calcula ((NOT destino) AND origen) en una sola instrucción.
  Se puede usar para poner a cero todos los bits del origen que están activados en el destino.
- `pxor` se puede usar para invertir, en cada palabra de estado, los bits que selecciona el valor de alternancia restante.

## 6. Amplifica la traza

- El campo del exponente de un número de punto flotante IEEE-754 de 32 bits está en los bits de las posiciones 23 a 30, inclusive.
  Para mover la ganancia `k` a la posición correcta, hay que desplazarla a la izquierda.
- Sumar las ganancias desplazadas a los bits sin procesar de las lecturas (`paddd`) tiene el efecto de multiplicar la lectura por `2^k`.
  El patrón de bits sigue siendo válido porque se garantiza que las entradas y los resultados son normales.
