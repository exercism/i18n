# Acerca de

Una lista en Gleam es una colección inmutable de cero o más valores. Todos los valores de una lista deben tener el mismo tipo. Como las listas son inmutables, una vez que se ha construido una lista, su valor nunca puede cambiar. Cualquier función u operador que parezca modificar una lista (como agregar un elemento) en realidad devuelve una nueva lista.

Las listas se pueden definir así:

```gleam
let empty = []
let singleValue = [5]
let threeValues = ["a", "b", "c"]
```

La forma más común de agregar un elemento a una lista es anteponerlo con la sintaxis de propagación:

```gleam
let two_to_four = [2, 3, 4]
let one_to_four = [1, ..two_to_four]
// -> [1, 2, 3, 4]
```

El módulo [`gleam/list`](https://hexdocs.pm/gleam_stdlib/gleam/list.html) de la biblioteca estándar de Gleam contiene muchas funciones útiles para trabajar con listas. Este módulo se usa muchísimo en el código de Gleam, así que es buena idea conocerlo bien.

Los patrones de listas se pueden usar en las expresiones case para hacer coincidir listas y asignar los valores que contienen a variables:

```gleam
pub fn describe(list: List(String)) -> String {
  case list {
    [] -> "Empty list"
    [x] -> "List with one item: " <> x
    [x, y] -> "List with two items: " <> x <> " and " <> y
    _ -> "List with three or more items"
  }
}
```

Además de hacer coincidir listas de longitud exacta, la sintaxis de propagación se puede usar para hacer coincidir listas de al menos cierta longitud:

```gleam
pub fn describe(list: List(String)) -> String {
  case list {
    [_, _, ..] -> "List with at least two items"
    [_] -> "List with one item"
    [] -> "Empty list"
  }
}
```

La sintaxis de propagación también se puede usar para asignar el resto de la lista a una variable:

```gleam
pub fn remove_first_item(list: List(String)) -> List(String) {
  case list {
    // Return the list without the first item
    [_, ..rest] -> rest

    // There's no first item to remove, return an empty list
    _ -> []
  }
}
```

Las expresiones case deberían tener un patrón para cada valor posible del tipo con el que se hace la coincidencia, por lo que a menudo se usa un patrón de descarte final (`_`) para manejar los valores restantes.
