# debes evitar el bucle imperativo

Evita usar bucles `for` en este ejercicio.

Según la introducción, el objeto Array de JavaScript tiene métodos integrados pensados para el análisis.

Echa un vistazo a la introducción o a la [documentación de MDN](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array#instance_methods) para ver qué métodos puedes usar.
