# Acerca de

Los tipos de números incorporados en C++ se pueden dividir en enteros y números de punto flotante.
Los enteros son números sin parte decimal, como `0`, `691` o `-2`.
Los números de punto flotante son números con punto decimal, como `6.02214076`, `0.1` o `-1.616`.

## Enteros

El siguiente ejemplo muestra la declaración y la inicialización de cuatro variables diferentes

```cpp
int m_morales{9241};              // base 10: 0-9
int a_apaec{0x24CD};              // base 16: 0-9 and A-F
int m_gargan{0b10010000011001};   // base  2: 0-1
int b_reilly{022031};             // base  8: 0-7
                                  // Leading with a 0 not the letter o.
```

Cuando asignas un valor a una variable `int`, puedes hacerlo directamente con un literal.
Un literal es un número escrito directamente en el código, como `9241`.
Existen diferentes literales enteros para varias bases de representación.
Los literales enteros decimales son los más comunes y usan los dígitos `0` a `9`.
Al añadir un prefijo especial, como `0x`, es posible usar otras bases.
El ejemplo anterior muestra el número `9421` en sus cuatro representaciones y prefijos.
Todas las variables se inicializan con el mismo valor.

Para más detalles sobre los distintos sistemas de representación, echa un vistazo a [un pequeño tutorial][cpp_numerical_bases].

Puedes usar un apóstrofo para separar los dígitos y que sea más fácil de leer.
`9'241` es lo mismo que `0b0100'100'0001'1001` o `92'4'1`.

## Números de punto flotante

Los literales de punto flotante vienen en dos formas.
Además del intuitivo `0.0024`, es posible usar su notación científica `2.4e-3`.
El tipo de punto flotante más común es `double`.

## Aritmética

C++ admite `+`, `-`, `*`, `/`, `(` y `)` y `%` para formar expresiones.
El resultado de la operación entre dos enteros también es un entero.
`5 / 2` devolverá `2`.
Cuando uno de los tipos involucrados es de punto flotante, el resultado también será de punto flotante.
`5.0 / 2` y `5 / 2.0` devolverán `2.5`.
`%` es el operador de residuo y devuelve el residuo de una división entera: `5%3` es `2`.

## Operador de asignación

El operador de asignación asigna un literal a una variable.
Siempre se realiza de derecha a izquierda, y nunca al revés.

```cpp
int length = 5;
int width = 2;
length = width;
```

Aquí el valor entero `5` se asigna a la variable `length`.
Luego el valor entero `2` se asigna a la variable `width`.
Finalmente, el valor de `width` se copia a la variable `length` y el valor anterior `5` se pierde.
Ten en cuenta también que solo asignamos el valor de `width` a `length` en el momento de la operación de asignación.
Por lo tanto, si el valor de `width` cambia más adelante, no afectará al valor que toma `length`.

El operador de asignación se puede combinar con los demás operadores (aritméticos y a nivel de bits), lo que da lugar a los operadores conocidos como de `compound assignment`: `+=`, `-=`, `*=`, `/=`, `%=`.
Estos operadores modifican el valor actual de una variable realizando una operación sobre él.

```cpp
// we start with 0 people
int people{};
// we need 0 eggs
int eggs{};
// two people joined:
people += 2;
// people is now 2
// let's add 3 eggs per person
eggs += 3 * people;
// eggs is now 6
```

Las variables `people` y `eggs` se inicializan a `0`.
Luego, sumamos el valor entero `2` al valor existente `0` de la variable `people` y lo asignamos de nuevo a `people`.
`people` ahora es `2`.
Después, sumamos `3` huevos por cada persona, lo que da `6` huevos en total.
Ahora sumamos este `6` al valor existente `0` de la variable `eggs` y lo asignamos de nuevo a `eggs`.
`eggs` ahora será `6`.
La expresión equivalente sería `people = people + 2` y `eggs = eggs + (3 * people)`.

## Conversión de tipos

La conversión de tipos es el paso de un tipo a otro.
Si se necesita un `double`, se puede usar un `int` en su lugar.
El ejemplo `5.0 / 2` de arriba se resuelve con una conversión implícita de `2` a `2.0`.
Un `double` que se convierte a `int` puede perder información.
Es buena práctica hacer explícitas estas conversiones a otro tipo T mediante `static_cast<T>`.
La conversión al estilo C antiguo mediante `(T)` no se recomienda en C++ moderno, pero conviene conocerla de todos modos.

```cpp
double pi{3.14};
int about_2_times_pi_cpp{static_cast<int>(pi) * 2};
// Old C-style cast:
int about_2_times_pi_c{(int)pi * 2};
```

## Precisión y representación

Los números en C++ no pueden ser arbitrariamente grandes.
`int`, por ejemplo, se representa con 32 bits.
Eso alcanza para un conjunto de `2^32` números, aproximadamente 4 mil millones.
Incluyendo el `0`, esto fija los números `int` más grande y más pequeño en `-2^31` y `2^31 - 1`.

Los números de punto flotante suelen implementarse con 15 decimales de precisión, pero su representación varía según el sistema anfitrión.
