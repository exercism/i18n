# Instrucciones específicas de SQLite

* La columna **digits** contiene una lista de números enteros codificada en JSON.
  Ejemplo:
  ```json
  [1,0,1,0,1,0]
  ```
* La columna **result** debe contener datos codificados en JSON: un objeto con los dígitos como números enteros o una descripción de los errores.
  Ejemplos:
  ```json
  {"digits":[1,0,1,0,1,0]}
  ```
  o
  ```json
  {"error":"some error description"}
  ```

## Esquema de la tabla

```sql
CREATE TABLE IF NOT EXISTS "all-your-base" (
  input_base  INTEGER NOT NULL,
  digits      TEXT    NOT NULL, -- json array
  output_base INTEGER NOT NULL,
  result      TEXT              -- json object
);
```
