# Char

`Char` es un tipo de dato en Crystal que representa un punto de código [Unicode][unicode] de 32 bits.
Su tamaño los hace eficientes en memoria y les da propiedades específicas que los String no tienen.
Se crean usando comillas simples (`'`) y solo permiten que se coloque un único punto de código Unicode dentro.

```crystal
'a' # => 'a'
'a'.class # => Char
```

Es bastante común trabajar con Char cuando trabajas con String en Crystal, ya que bastantes métodos de la clase String devuelven Char o reciben Char como argumentos.
Por ejemplo, el método [`String#[]`][index] devuelve un Char, o el método [`String#chars`][chars] devuelve una colección de Char.

## Incremento / Decremento

Como un char es un punto Unicode de 32 bits, admite incremento y decremento; esto hace que, si tienes `'a'`, puedas obtener `'b'` sumándole uno.

```crystal
'a' + 5
# => 'f'

'z' - 25
# => 'a'
```

También existe un método llamado [`Char#succ`][succ], que devuelve el siguiente char de la tabla Unicode, y [`Char#pred`][pred], que devuelve el char anterior de la tabla Unicode.

```crystal
'a'.succ
# => 'b'

'z'.pred
# => 'y'
```

## Concatenación

Como los Char solo están pensados para representar un Unicode de 32 bits, no se pueden concatenar dos char entre sí.
Por lo tanto, los Char solo se pueden concatenar con String.

```Crystal
'a' + "bc"
# => "abc"

'a' + 'b'
# => error: expected argument #1 to 'Char#+' to be Int or String, not Char
```

## Métodos de propiedades

Crystal tiene algunos métodos para obtener información sobre un carácter, como si es un número o una letra, o si está en mayúsculas o en minúsculas.
Aquí tienes una lista de algunos de los métodos; para ver la lista completa, consulta la [API de Char][char-api]:

| Método                           | Descripción                                          |
| -------------------------------- | ---------------------------------------------------- |
| [`Char#number?`][number]         | Devuelve `true` si el Char es un número              |
| [`Char#letter?`][letter]         | Devuelve `true` si el Char es una letra              |
| [`Char#lowercase?`][lowercase]   | Devuelve `true` si el Char está en minúscula         |
| [`Char#uppercase?`][uppercase]   | Devuelve `true` si el Char está en mayúscula         |
| [`Char#ascii?`][ascii]           | Devuelve `true` si el Char es un carácter ASCII      |
| [`Char#whitespace?`][whitespace] | Devuelve `true` si el Char es un carácter de espacio |

## Conversión

### Conversión entre puntos de código y Char

Como un Char es un punto Unicode de 32 bits, puedes convertir entre Char y puntos de código (Int).
Esto se puede hacer con el método [`Char#ord`][ord], que devolverá el punto de código del Char, o con el método [`Int#chr`][chr], que devolverá el Char del punto de código.

```crystal
'a'.ord
# => 97

97.chr
# => 'a'
```

### Conversión entre tipos

Como con otros tipos de datos, los char tienen algunos métodos para convertir entre tipos.
El más común es el método `Char#to_s`, que convierte el Char a un String. Sin embargo, también está el método `Char#to_i`, que convierte el Char a un Int, y el método `Char#to_f`, que convierte el Char a un Float.

```crystal
'a'.to_s
# => "a"

'4'.to_i
# => 4

'a'.to_i
# => Error: Invalid integer: a (ArgumentError)
```

## Escapes

Al igual que con String, hay ciertos caracteres que no se pueden escribir directamente y, para escribirlos, necesitas escaparlos.
Puedes usar el carácter `\` para escribir una secuencia de escape seguida del carácter que quieres escapar.

Estos son los caracteres especiales en Crystal:

| Valor    | Descripción                   |
| -------- | ----------------------------- |
| `\a`     | Alerta                        |
| `\b`     | Retroceso                     |
| `\e`     | Escape                        |
| `\f`     | Avance de página              |
| `\n`     | Salto de línea                |
| `\r`     | Retorno de carro              |
| `\t`     | Tabulador horizontal          |
| `\v`     | Tabulador vertical            |
| `\\`     | Barra invertida               |
| `\'`     | Comilla simple                |
| `\"`     | Comilla doble                 |
| `\377`   | Carácter ASCII octal          |
| `\xFF`   | Carácter ASCII hexadecimal    |
| `\uFFFF` | Carácter unicode hexadecimal  |
