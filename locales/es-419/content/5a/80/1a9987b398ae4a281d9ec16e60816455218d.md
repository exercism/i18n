# Introducción

Elixir ofrece muchas funciones para trabajar con bits, que se encuentran en el _módulo Bitwise_.

- `band/2`: AND bit a bit
- `bsl/2`: desplazamiento a la izquierda bit a bit
- `bsr/2`: desplazamiento a la derecha bit a bit
- `bxor/2`: XOR bit a bit
- `bor/2`: OR bit a bit
- `bnot/1`: NOT bit a bit

Aquí tienes un ejemplo de cómo usar una función bit a bit:

```elixir
Bitwise.bsl(1, 3)
# => 8
```

Todas las funciones bit a bit solo funcionan con números enteros.

Si usas la versión 1.9 de Elixir o una anterior, tendrás que llamar a `require Bitwise` al principio de la definición del módulo para poder usar el _módulo Bitwise_.
