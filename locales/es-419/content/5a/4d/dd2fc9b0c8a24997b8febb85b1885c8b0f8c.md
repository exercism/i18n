# Introducción

Un bloque es un conjunto de sentencias y declaraciones agrupadas en una sola unidad sintáctica.
Los bloques a menudo se definen entre llaves, aunque no siempre.
Los bloques pueden anidarse dentro de funciones y dentro de otros bloques.

Una función actúa de forma parecida a un bloque.
Un identificador de una variable definida en una función no puede verse fuera de la función, igual que un identificador de una variable definida en un bloque no puede verse fuera del bloque.
Dos variables en dos funciones pueden tener el mismo nombre, ya que las dos funciones no se ven entre sí, igual que dos variables en dos bloques pueden tener el mismo nombre, ya que los dos bloques no se ven entre sí.
Pero las funciones y los bloques no son idénticos.
Una función no puede anidarse dentro de otra función, pero un bloque sí puede anidarse dentro de otro bloque.

En el siguiente ejemplo, `number` se define dentro de la función `main`.
`flag` se define dentro del bloque `if`, que está anidado dentro de la función `main`.
Las variables definidas dentro de un bloque solo son válidas dentro de ese bloque.
Por lo tanto, intentar compilar el código da como resultado un error de compilación.

```c
#include <stdio.h>

int main() {

  int number = 1;

  if (number == 1) {
      int flag = 1;
      printf("%d", flag);
  }

  // this line generates a compilation error
  // error: 'flag' undeclared (first use in this function)
  printf("%d", flag);
    
}
```

El mensaje de error puede resultar confuso, ya que `flag` _sí_ se usa antes en la función.
Sin embargo, `flag` se define dentro de un bloque que está dentro de la función.
El bloque interno puede «ver» la variable `number` de su función externa, pero la función externa no puede «ver» la variable `flag` definida dentro de su bloque interno.
Una vez que la ejecución sale del bloque, la variable `flag` se destruye automáticamente y ya no está disponible para el programa.
La función `main` ve el identificador `flag` por primera vez en la última sentencia `printf`.
Si se elimina la última sentencia `printf`, el programa se compilará e imprimirá `1` cuando se ejecute.
Esto se debe a que la variable `flag` es válida en el bloque que contiene la primera sentencia `printf`.

A partir de `C99`, las sentencias `if`, `for`, `while` y `do` de una sola línea también se consideran bloques.
En el siguiente ejemplo, aunque `i` no se define entre llaves, existe solo en el bloque definido por la sentencia `for`, y no es visible para la función `main` externa.

```c
#include <stdio.h>

int main() {

    for (int i = 0, j = 11; i < j; i+=2)
        printf("%d", i);

    // this line generates a compilation error
    // error: 'i' undeclared (first use in this function)
    printf("%d", i);
    
}
```

Si se elimina la última sentencia `printf`, el programa se compilará e imprimirá `0 2 4 6 8 10 ` cuando se ejecute.
Algunos lenguajes, como Go y Rust, establecen explícitamente que las sentencias condicionales y de bucle de una sola línea constituyen un bloque.
Exigen que esas sentencias de una sola línea sigan encerradas entre llaves.
