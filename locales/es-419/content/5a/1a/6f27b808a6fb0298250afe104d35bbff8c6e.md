# Clona el track de ABAP

## Requisitos previos

1. Sistema ABAP versión 7.4 o superior
2. abapGit v1.115.0 o superior
3. Autorizaciones para implementar paquetes, programas y clases de ABAP

## Instalar abapGit

El track de ABAP con todos los ejercicios está implementado como un repositorio de abapGit. Para clonar el track en tu propio sistema, primero tienes que instalar abapGit.

1. Ve a [https://github.com/abapGit/abapGit](https://github.com/abapGit/abapGit)
2. Descarga el archivo `zabapgit_standalone.prog.abap`
3. Crea el programa `zabapgit_standalone` en tu propio sistema
4. Sube el código fuente de `zabapgit_standalone.prog.abap` al programa `zabapgit_standalone`
5. Activa el programa

## Instalar el track de ABAP de Exercism

### Repositorio en línea

Usa este método si tu sistema está conectado a Internet y tiene acceso a GitHub.com (método recomendado).

1. Ejecuta abapGit

![Repositorio en línea de abapGit](https://github.com/exercism/abap/blob/main/docs/clone_01.png?raw=true)

2. En «Repository Overview», selecciona «New Online»
3. Ingresa los siguientes valores
- URL: `https://github.com/exercism/abap`
- Package: `$exer`
- Display Name: `Exercism - ABAP Track`

Nota: si el nombre del paquete es demasiado largo, como `$exercism`, recibirás un error al intentar importar el repositorio. Mantén el nombre corto como se menciona arriba.

![Repositorio en línea de abapGit](https://github.com/exercism/abap/blob/main/docs/clone_02.png?raw=true)

4. Selecciona «Create Online Repository». Deberías ver una lista de objetos con el estado «A»:

![Repositorio en línea de abapGit](https://github.com/exercism/abap/blob/main/docs/clone_03.png?raw=true)

5. Selecciona «Pull» para clonar todos los objetos en tu sistema. Cuando termine, deberías ver todos los objetos con el estado vacío

![Repositorio en línea de abapGit](https://github.com/exercism/abap/blob/main/docs/clone_04.png?raw=true)

### Repositorio sin conexión

Usa este método si tu sistema *no* está conectado a Internet.

1. Ve a [https://github.com/exercism/abap](https://github.com/exercism/abap)
2. Descarga el archivo ZIP del repositorio

![Repositorio sin conexión de abapGit](https://github.com/exercism/abap/blob/main/docs/clone_10.png?raw=true)

3. Ejecuta abapGit
4. En «Repository Overview», selecciona «New Offline»
5. Ingresa los siguientes valores
- Repository Name: `Exercism - ABAP Track`
- Package: `$exer`

![Repositorio sin conexión de abapGit](https://github.com/exercism/abap/blob/main/docs/clone_11.png?raw=true)

6. Selecciona «Create Offline Repository»

![Repositorio sin conexión de abapGit](https://github.com/exercism/abap/blob/main/docs/clone_12.png?raw=true)

7. Selecciona «Import ZIP» y elige el archivo ZIP que descargaste. Deberías ver una lista de objetos con el estado «A»:

![Repositorio sin conexión de abapGit](https://github.com/exercism/abap/blob/main/docs/clone_13.png?raw=true)

8. Selecciona «Pull ZIP» para clonar todos los objetos en tu sistema. Cuando termine, deberías ver todos los objetos con el estado vacío

![Repositorio sin conexión de abapGit](https://github.com/exercism/abap/blob/main/docs/clone_14.png?raw=true)

## Desinstalar el track de ABAP de Exercism

Puedes eliminar todos los objetos de tu sistema de la siguiente manera:

1. Ejecuta abapGit
2. Ve al repositorio `Execism - ABAP Track`
3. Selecciona «Advanced > Uninstall»
4. Confirma la eliminación de todos los objetos y del repositorio

## Solución de problemas

- Si tienes problemas de conexión, revisa [SSL Setup](https://docs.abapgit.org/user-guide/setup/ssl-setup.html)
- Si recibes el error `Package $EXERCISM_DIFFERENCE-OF-SQUARES exceeds ABAP 30-characters name limit`, usa un nombre de paquete más corto, como `$exer`.
- Algunos archivos mostrarán diferencias después de hacer pull en tu sistema ABAP. Las diferencias relacionadas con caracteres de fin de archivo o marcas de orden de bytes se pueden ignorar.
