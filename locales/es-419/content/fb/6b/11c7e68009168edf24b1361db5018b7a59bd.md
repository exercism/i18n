# Pistas

## General

Este [artículo][gobyexample] da una buena introducción al paquete `math/rand`.

Si trabajas localmente y usas Go 1.19 o una versión anterior, asegúrate de inicializar tu generador de números aleatorios usando la hora actual como semilla.

## 1. Lanza un dado

Este [artículo][yourbasic] muestra cómo generar números enteros en un rango determinado.

## 2. Genera energía de varita

La función [rand.Float64][float64] devuelve un número `float64` aleatorio entre 0.0 y 1.0.

## 3. Mezcla un slice

Crea un slice con los ocho strings de animales, luego llama a [rand.Shuffle][shuffle] para ponerlo en un orden aleatorio.
