# Acerca de

La sentencia `guard` de Swift sirve para salir de una función de Swift antes de tiempo, cuando no se cumple una condición necesaria para que el procesamiento continúe, por ejemplo:

```swift
guard myValue = 0 else { return 0 }
let root = myValue.squareRoot()
```

Aquí, `guard` verifica si la expresión Boolean que sigue a la palabra clave `guard` se evalúa como verdadera. Si es así, el procesamiento continúa con el código que sigue a la sentencia `guard` (aquí `let root = myValue.squareRoot()`. De lo contrario, se ejecutará el código de la cláusula else. A diferencia de una sentencia `if`, una sentencia `guard` _debe_ tener una cláusula else y, a diferencia de la cláusula else de un if-else, la cláusula else de un guard _debe_ salir del ámbito de la sentencia `guard`. Es decir, debe usar una sentencia de transferencia de control como `return`, `continue` o `break`, o bien debe lanzar un error o salir del programa.

Un ejemplo de su uso es la función sinc, que es igual a sin(x)/x con sinc(0) definido como 1, lo que evita problemas con la división por 0. Esta función se puede escribir en Swift, usando un `guard`, de esta forma:

```swift
func sinc(_ x: Double) -> Double {
    guard x != 0 else { return 1 }
    return sin(x) / x
}

sinc(0)              // returns 1
sinc(Double.pi / 2)  // returns 0.6366197723675814
```
