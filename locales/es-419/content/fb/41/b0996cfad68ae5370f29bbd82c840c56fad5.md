# Edición estándar

La Edición estándar de Exercism está pensada para que cada persona la use en su aprendizaje personal, mientras se ayudan entre sí a través de nuestros sistemas comunitarios.

No está diseñada ni pensada para que las organizaciones la usen para capacitar a su personal ni para impulsar bootcamps.
Consulta la [Edición para equipos](/docs/editions/teams) para saber cómo puedes lograr esos objetivos.
