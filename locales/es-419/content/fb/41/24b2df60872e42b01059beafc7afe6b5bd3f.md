# Introducción

Así como se puede crear un puntero a un `int` u otro tipo de dato básico, también se puede crear un puntero a una función.
Un puntero a función se puede usar para pasar una función a otra función.
Una función que se pasa como valor de parámetro a otra función se conoce como función de primera clase.
Una función que recibe una o más funciones como parámetro, o que devuelve una función, se conoce como función de orden superior.

En el siguiente ejemplo, `is_even` y `is_odd` son funciones de primera clase.
La función de orden superior es `test_number`.

```c
#include <stdio.h>
#include <stdbool.h>

bool is_even (int number) {
    return number & 1 != 1;
}

bool is_odd (int number) {
    return number & 1 == 1;
}

// this function takes any other function which takes a number and returns a bool
void test_number(bool (*func) (int), int number, char *text){
    printf(text, number, func(number)? "true": "false");
}

int main() {
    // prints Testing odd for 3 is true
    test_number(is_odd, 3,"Testing odd for %d is %s\n");
    // prints Testing even for 3 is false
    test_number(is_even, 3,"Testing even for %d is %s\n");
}
```
La firma de la función `bool (*func) (int)` del primer argumento de `test_number` coincide con la firma de las funciones que se pasan.
Tanto `is_even` como `is_odd` reciben un parámetro `int` y devuelven un `bool`.
En `(*func)`, `func` representa el nombre de la función que se va a usar.
Si se hubiera usado `(*fn)`, se habría llamado así: `printf(text, number, fn(number)? "true": "false");`.
Para satisfacer el parámetro de puntero a función, pasamos el nombre de una función que tenga la firma esperada al llamar a `test_number`.
Así vemos que el nombre de una función apunta a la dirección de esa función con nombre.
