# Instrucciones

En este ejercicio vas a procesar líneas de log.

Cada línea de log es un string con el siguiente formato: `"[<LEVEL>]: <MESSAGE>"`.

Hay tres niveles de log distintos:

- `INFO`
- `WARNING`
- `ERROR`

Tienes varias tareas; cada una recibe una línea de log y te pide que hagas algo con ella.

## 1. Permite obtener el string que sigue a una subcadena específica

Al mirar los logs del último mes, ves que el mensaje de prueba siempre está después de una subcadena específica. Como prevés que tendrás que extraer el mensaje de prueba pronto, decides crear un método auxiliar que te ayude con eso.

Implementa el método de extensión (_static_) `LogAnalysis.SubstringAfter()`, que recibe un string delimitador y devuelve la subcadena que va después del delimitador.

```csharp
var log = "[INFO]: File Deleted.";
log.SubstringAfter(": "); // => returns "File Deleted."
```

## 2. Permite obtener el string que está entre dos subcadenas

Al revisar más a fondo, ves que el nivel de log siempre está entre corchetes (`[` y `]`). Como también prevés que tendrás que extraer el nivel de log pronto, decides crear otro método auxiliar que te ayude con eso.

Implementa el método de extensión (_static_) `LogAnalysis.SubstringBetween()` que recibe dos strings delimitadores y devuelve la subcadena que está entre los dos delimitadores.

```csharp
var log = "[INFO]: File Deleted.";
log.SubstringBetween("[", "]"); // => returns "INFO"
```

## 3. Extrae el mensaje de un log

Implementa el método de extensión (_static_) `LogAnalysis.Message()` para devolver el mensaje contenido en un log.

```csharp
var log = "[ERROR]: Missing ; on line 20.";
log.Message(); // => returns "Missing ; on line 20."
```

## 4. Extrae el nivel de log de un log

Implementa el método de extensión (_static_) `LogAnalysis.LogLevel()` para devolver el nivel de log de un log.

```csharp
var log = "[ERROR]: Missing ; on line 20.";
log.LogLevel(); // => returns "ERROR"
```
