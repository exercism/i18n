# Nociones básicas de sintaxis de Elm 1

## Constantes y funciones

Los programas en Elm se componen de definiciones y expresiones.
Todo en Elm es una definición o una expresión.

Un valor constante se define con `name = expression`.

```elm
five = 5

six = 3 + 3
```

Las funciones se definen con `name parameters... = expression`,
y los parámetros se separan solo con espacios.

```elm
add number1 number2 = number1 + number2
```

Llamar a una función también es una expresión y se hace escribiendo su nombre
y pasando argumentos para cada uno de los parámetros de la función,
separados por espacios, igual que en la definición de la función.

```elm
five = add 2 3
```

Puedes usar paréntesis para especificar el orden de evaluación de una expresión.

```elm
six = add 2 (1 * 4)

twelve = add 2 1 * 4
```

## Indentación / espacios en blanco significativos

Elm no usa marcadores sintácticos como llaves, paréntesis o puntos y coma para delimitar el código. En su lugar, usa espacios en blanco e indentación.

- Las definiciones de módulos, importaciones y funciones de nivel superior deben comenzar en la columna más a la izquierda.
- Si una expresión se divide en varias líneas, el código que forma parte de esa expresión debe estar indentado bajo ella con al menos un espacio.
- Las partes de la expresión que van agrupadas deben indentarse con la misma cantidad de espacios.

```elm
-- A function split over multiple lines, so subsequent lines must be indented
add number1 number2 =
    number1 + number2
```

https://elmprogramming.com/indentation.html

## Módulos

Cada archivo en Elm es un módulo y debe contener una sentencia `module` antes que cualquier otro código.
Los nombres de los módulos deben coincidir con el nombre de su archivo, así que el módulo `Calculator` debe estar en el archivo Calculator.elm.
Todo lo que se define dentro de un módulo tiene ámbito privado en él
y no se puede acceder desde fuera del módulo, a menos que se incluya en `exposing`.

```elm
-- Define the Calculator module, and expose the `add` function
module Calculator exposing (add)

six = 3 + 3

add number1 number2 = number1 + number2
```

```elm
-- Define the Calculator module, and expose everything within: `six` and `add`
module Calculator exposing (..)

six = 3 + 3

add number1 number2 = number1 + number2
```

https://elm-lang.org/docs/syntax#modules

## Comentarios

Un comentario es texto dentro del archivo de Elm que no se interpreta como código.
Su función principal es que lo lean tú y otras personas que programan.
Existe una sintaxis ligera para los comentarios de una sola línea, basada en el doble guion.
Los comentarios de varias líneas también son posibles con el par de delimitadores de apertura y cierre `{-` y `-}`.

```elm
-- a single line comment
-- another single line comment

{- a multiline comment
   spawning multiple lines
-}
```

## Formato

Existe una [guía de estilo](https://elm-lang.org/docs/style-guide),
y puedes usar [elm-format](https://github.com/avh4/elm-format) para dar formato al código automáticamente.
