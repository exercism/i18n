# Condicionales innecesarios

En esta solución se usan condicionales de forma innecesaria.
Usar un [argumento por defecto][default argument] junto con [str.format][str.format] o [f-strings][f-strings] (_también conocidos como «formatted string literals» o «interpolated strings»_) puede hacer que el código sea más claro y menos verboso.

Consulta esta publicación sobre [argumentos por defecto en Python][python default arguments] para más detalles.
La publicación de blog [formateo de strings en Python][string formatting in python] también puede ser un buen punto de partida para aprender sobre las opciones de formateo de strings de Python.
