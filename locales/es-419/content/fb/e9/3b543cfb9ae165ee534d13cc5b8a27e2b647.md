# Instrucciones

De repente te dan unas ganas enormes de comer panqueques.
Como una persona moderna con inclinación por la tecnología, escribes una lista de compras de los ingredientes para panqueques en formato JSON.
La estructura de la lista es:

```json
{
  "name": "name of shopping list",
  "ingredients": [ ...list of ingredients... ],
  "optional ingredients": [ ...list of ingredients... ]
}
```

Un ingrediente se representa como un objeto JSON, así:

```json
{
  "item": "flour",
  "amount": {
    "quantity": 2,
    "unit": "cup"
  }
}
```

Un ingrediente tiene una propiedad opcional llamada `"substitute"` que contiene un string con otro ingrediente que se puede usar en su lugar.

Veamos cómo podemos examinar la lista de compras con `jq`

## 1. Extrae el nombre de la lista de compras

Escribe una expresión que devuelva el elemento `"name"` de la lista de compras.

## 2. Cuenta cuántos ingredientes se necesitan

Cuenta solo los ingredientes `"required"`. No incluyas los ingredientes opcionales.

## 3. ¿Cuánta azúcar?

Escribe una expresión que devuelva la cantidad de azúcar.
Solo se quiere la parte numérica.

## 4. Mapea los ingredientes que se pueden sustituir

Algunos de los ingredientes se pueden sustituir (si no tienes el ingrediente X puedes usar Y).
Devuelve un objeto JSON que mapee el ingrediente recomendado a su sustitución.
Incluye los ingredientes opcionales en el mapeo.
