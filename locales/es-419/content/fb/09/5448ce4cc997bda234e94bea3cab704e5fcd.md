# Anexo a las instrucciones

## Pistas

Para resolver este ejercicio necesitas implementar estas dos funciones:

- `largestPalindrome`
- `smallestPalindrome`

Ambas funciones reciben un límite inferior y uno superior de factores, y devuelven un par
`(value, [(factor1, factor2)])` que contiene el palíndromo y sus posibles pares de factores.

Puedes usar las firmas que te damos si tienes dudas sobre los tipos, pero no dejes que
limiten tu creatividad.

No hay problema si devuelves duplicados en el array de factores, y el orden de los factores
es irrelevante.

Considera usar un algoritmo un poco distinto para encontrar palíndromos pequeños o grandes.
