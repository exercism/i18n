# Acerca de

El filtrado es el proceso de crear una secuencia a partir de otra secuencia, copiando todos los elementos de la secuencia original excepto algunos.
La elección de qué elementos incluir en la nueva secuencia se puede hacer mediante una función predicado (una función que evalúa a un valor Boolean) o mediante la igualdad con un objeto específico.

## Eliminar mediante un predicado

`remove-if` es una función que toma una función predicado y una secuencia como argumentos, y devuelve una secuencia con solo aquellos elementos para los cuales el predicado evaluó a un valor falso.
En otras palabras, «elimina» todos los elementos de la secuencia para los cuales el predicado evalúa a verdadero. Sin embargo, ¡ten en cuenta que esta función no modifica la secuencia original!
En cambio, devuelve una nueva secuencia sin los elementos correspondientes. Si el predicado era verdadero para todos los valores, se devuelve una secuencia vacía.

```lisp
(remove-if #'evenp '(1 2 3 4 5)) ; => (1 3 5)
(remove-if #'oddp '(1 3 5))      ; => ()
```

## Conservar elementos mediante un predicado

Existe una función `remove-if-not` que es igual a `remove-if`, excepto que *conserva* el elemento para el cual el predicado evalúa a verdadero.

Como alternativa, se puede usar `complement` para convertir un predicado en su «opuesto».

```lisp
(remove-if #'evenp '(1 2 3 4 5 6))             ; => (1 3 5)
(remove-if-not #'oddp '(1 2 3 4 5 6))          ; => (1 3 5)
(remove-if (complement #'oddp) '(1 2 3 4 5 6)) ; => (1 3 5)
```

## Eliminar un elemento específico

Si se quiere eliminar un elemento específico de una secuencia, se puede usar `remove`, que toma el elemento a eliminar y una secuencia.
Se devuelven todos los valores de la secuencia que no son iguales al elemento a eliminar.

```lisp
(remove 1 '(1 2 1 3 1 4)) ; => (2 3 4)
(remove #\l "hello")      ; => "heo"
```

La función que se usa para la igualdad se puede especificar con el [parámetro de palabra clave][concept-keyword-parameters] `:test`.

Ten en cuenta que `remove` se podría implementar con `remove-if` escribiendo un predicado que comprueba si un objeto es igual a un elemento específico.

## Muchas opciones

Cada una de estas funciones también acepta muchos otros [parámetros de palabra clave][concept-keyword-parameters] que les permiten trabajar solo sobre subsecuencias, aplicarse solo un cierto número de veces y otras cosas. Consulta la [documentación del Hyperspec][hyperspec-remove] para ver todos los detalles


## Opciones destructivas

Además de `remove`, `remove-if` y `remove-if-not`, existen `delete`, `delete-if` y `delete-if-not`, que tienen el mismo efecto, excepto que pueden modificar la secuencia que se les pasa.
