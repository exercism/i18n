# Acerca de

Kotlin fue diseñado y desarrollado por JetBrains, la empresa detrás de IntelliJ. 
Es un lenguaje que se ejecuta en la JVM y que puede apuntar a las versiones 6+ (incluida la [plataforma Android](https://blog.jetbrains.com/kotlin/2017/05/kotlin-on-android-now-official/)).
JetBrains quería usar un lenguaje de tipado estático que eliminara el código repetitivo de Java, ofreciera paradigmas funcionales modernos y tuviera una interoperabilidad bidireccional perfecta con Java en su base de código existente. 
La JVM ya tenía lenguajes alternativos como Groovy y Scala, pero ninguno cumplía con sus criterios, así que crearon Kotlin.

La sintaxis de Kotlin es similar a la de Scala y Swift, pero toma las mejores características de otros lenguajes como
C# y Groovy. 
Kotlin adoptó un enfoque pragmático con las características incluidas en el lenguaje, ya que solo ofrece funcionalidad que
ha demostrado ser útil para los desarrolladores. 
Con esta decisión implementaron un subconjunto de las características de Scala con la intención de ofrecer un código más mantenible y una curva de aprendizaje más sencilla para los desarrolladores que buscan un «Java mejor».

JetBrains tiene un equipo de desarrolladores dedicado a trabajar en Kotlin, y la base de código está disponible en [Github](https://github.com/JetBrains/kotlin).
