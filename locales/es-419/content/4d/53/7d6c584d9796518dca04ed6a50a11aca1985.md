# Instalación

## Ubuntu (y la mayoría de las otras distribuciones basadas en Debian)

Para compilar código de forma local, vas a necesitar gcc y make, que puedes instalar con

```shell
sudo apt install gcc make
```

Si no estás trabajando sobre hardware ARM64, instala el emulador [QEMU][] y la cadena de herramientas cruzadas GCC ARM64 con

```shell
sudo apt install qemu-user libc6-dev-arm64-cross gcc-aarch64-linux-gnu
```

## Windows

Usa el [Windows Subsystem for Linux][] con una distribución basada en Debian y sigue las instrucciones de Ubuntu de arriba.
Como alternativa, puedes configurar una máquina virtual de Linux.

## macOS

Puedes iniciar una máquina virtual de Linux con cualquier solución de virtualización que te sirva (por ejemplo, [Lima][]).

[QEMU]: https://www.qemu.org/
[Windows Subsystem for Linux]: https://docs.microsoft.com/en-gb/windows/wsl/about
[Lima]: https://lima-vm.io/
