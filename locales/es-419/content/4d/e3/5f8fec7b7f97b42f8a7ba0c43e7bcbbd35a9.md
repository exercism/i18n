# Pistas

## 1. Obtén la primera letra del título

- Hay [un método][index] que devuelve un `Char` de un `String` en un índice dado.

## 2. Obtén las iniciales de los autores

- Puedes usar métodos ya implementados para obtener la primera letra de un `String`.
- Para combinar valores en un `String` puedes usar la [interpolación de strings][string-interpolation].

## 3. Descifra la letra

- Hay [un método][uppercase] para comprobar si un `Char` está en mayúscula.
- Hay [un método][ord] para obtener el punto de código de un `Char`.

## 4. Descifra el texto

- Puedes usar [bucles][while] para ejecutar código varias veces.
