## 1. Error al dividir entre cero

- Implementa el módulo, especificando el mensaje usando una [macro integrada especial para definir excepciones][defexception].
- Los módulos se pueden anidar dentro de otros módulos.

## 2. Error al encontrar un desbordamiento inferior de la pila

- Implementa el módulo, especificando el mensaje usando una [macro integrada especial para definir excepciones][defexception].
- Puedes usar uno de los callbacks del comportamiento Exception para definir una excepción cuyo mensaje cambie según los argumentos que se pasan a `raise/2`.
- Los módulos se pueden anidar dentro de otros módulos.

## 3. Escribe una función que divida

- Escribe una función con múltiples cláusulas usando guardas para el control de flujo.
- Puedes hacer pattern matching en la lista de argumentos de la función para vincular los valores de la pila a variables.
