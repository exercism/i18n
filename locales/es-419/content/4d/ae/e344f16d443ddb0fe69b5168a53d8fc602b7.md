# Introducción

## Funciones callback

Las funciones callback son funciones que se pasan como argumentos.
Este patrón de programación crea una secuencia de llamadas a funciones, tanto en la programación síncrona como en la asíncrona.
Escribir una función callback no es distinto de escribir una función; sin embargo, la función callback debe coincidir con la firma que define la función que la llama.

```javascript
const squareLength = 5;

// Caller function takes a callback function
function applyToSquare(callback) {
  return callback(squareLength);
}

// Callback must expect the possible argument from the calling function
function areaOfSquare(number) {
  return number * number;
}

applyToSquare(areaOfSquare); // => 25
```

También puedes escribir los callbacks como una expresión de función, una expresión de función anónima o una expresión de función flecha:

```javascript
applyToSquare(function squarePerimeter(side) {
  return side * 4;
});

applyToSquare(function (side) {
  return side * 4;
});

applyToSquare((side) => {
  return side * 4;
});
```
