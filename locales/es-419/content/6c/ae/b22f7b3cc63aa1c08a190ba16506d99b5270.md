# return innecesario

Las buenas prácticas de Scala indican que se debe evitar la palabra clave `return`. En Scala, el resultado de la última expresión de una función se devuelve de forma implícita. Especificar `return` de forma explícita al final de una función puede tener efectos secundarios no deseados. [Say No To Return](https://blog.knoldus.com/scala-best-practices-say-no-to-return/).
