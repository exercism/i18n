# Acerca de

Clojure usa el tipo subyacente `java.lang.Character`, que es una cantidad de 16 bits para representar los componentes direccionables más pequeños del texto.
Varios `char` pueden formar un string como `"word"`, o los `char` se pueden
procesar de forma independiente. Sus literales se escriben así: `\a \b \c`.

Los `char` de Clojure admiten la codificación Unicode UTF-16, así que además del conjunto de caracteres latinos,
prácticamente todos los sistemas de escritura que se usan en el mundo se pueden representar,
por ejemplo, la letra griega `'β'`.

Hay muchos métodos de biblioteca para inspeccionar y manipular `char`. Se
puede acceder a ellos mediante interop como los métodos de la clase `Character`. Clojure también incluye una biblioteca de utilidades para string integrada, `clojure.string`, que ofrece muchas funciones potentes para operar sobre caracteres.
