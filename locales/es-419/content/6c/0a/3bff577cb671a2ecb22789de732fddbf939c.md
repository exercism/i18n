# Apéndice de instrucciones

## Implementación

Las pruebas requieren un constructor que reciba un array. La implementación interna de tu conjunto personalizado puede usar otras estructuras de datos, pero es posible que tengas que implementar un constructor externo que reciba exactamente un array para que las pruebas pasen.

Algunos métodos tienen un operador Unicode equivalente. Por ejemplo, `intersect(CustomSet([1, 2, 3, 4]), CustomSet([]))` es equivalente a `CustomSet([1, 2, 3, 4]) ∩ CustomSet([])`.
