# Apéndice de instrucciones

Este ejercicio presenta un par de conceptos que quizá no hayas visto antes:

## Espacio de nombres definido por el usuario

Las palabras en 8th pertenecen todas a un espacio de nombres; por ejemplo, `a:new` se refiere a la palabra `new` del espacio de nombres `a`.
También puedes definir espacios de nombres personalizados, que es lo que hacemos al inicio del archivo `circular-buffer.8th`:

```8th
ns: cb
```

Esto significa que puedes acceder a todas las palabras de ese archivo mediante `cb:<word>`, lo que es una excelente manera de agrupar funcionalidad relacionada.

Para más información, consulta la documentación de [espacios de nombres][namespaces].

## Excepciones

Se espera que las palabras `read` y `write` lancen una excepción cuando se las llama sobre un búfer circular con un estado inválido.
Para más información, consulta la documentación de [excepciones y manejo de errores][exceptions-and-error-handling].

## Objetos

Aunque eres libre de implementar el búfer circular como quieras, podrías considerar usar el [soporte de objetos][objects] de 8th.
