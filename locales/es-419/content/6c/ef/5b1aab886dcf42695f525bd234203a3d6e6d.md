# Introducción

Muchos lenguajes de programación tienen tipos numéricos específicos para representar distintos tipos de números, pero JavaScript solo tiene dos:

- `number`: un tipo de dato numérico en el formato de punto flotante de doble precisión de 64 bits (IEEE 754).
  Algunos ejemplos son `-6`, `-2.4`, `0`, `0.1`, `1`, `3.14`, `16.984025`, `25`, `976`, `1024.0` y `500000`.
- `bigint`: un tipo de dato numérico que puede representar _enteros_ en el formato de precisión arbitraria.
  Algunos ejemplos son `-12n`, `0n`, `4n` y `9007199254740991n`.

Si necesitas [precisión arbitraria][ref-arbitrary-precision] o trabajas con números extremadamente grandes, usa el tipo `bigint`.
De lo contrario, el tipo `number` probablemente sea la mejor opción.

## Redondeo

Hay un objeto global incorporado llamado `Math` que ofrece varias [funciones de redondeo][ref-math-object-rounding]. Por ejemplo, puedes redondear hacia abajo (`floor`) o hacia arriba (`ceil`) números decimales al número entero más cercano.

```javascript
Math.floor(234.34); // => 234
Math.ceil(234.34); // => 235
```
