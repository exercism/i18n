# Instrucciones

En tu laboratorio de investigación de ADN, has estado probando varias formas de comprimir tus datos de investigación para ahorrar espacio de almacenamiento. Alguien de tu equipo sugiere convertir los datos de ADN a una representación binaria:

| Ácido nucleico | Código |
| -------------- | ------ |
| un espacio     | `0000` |
| A              | `0001` |
| C              | `0010` |
| G              | `0100` |
| T              | `1000` |

Le das vueltas a la idea, ya que podría reducir a la mitad el costo del almacenamiento de datos, aunque a costa de la legibilidad humana. Decides escribir un módulo para codificar y decodificar tus datos y así medir cuánto ahorras.

## 1. Codifica el ácido nucleico a un valor binario

Implementa `encode_nucleotide/1` para que acepte el punto de código del ácido nucleico y devuelva el valor entero del código codificado.

```elixir
DNA.encode_nucleotide(?A)
# => 1
# (which is equal to 0b0001)
```

## 2. Decodifica el valor binario al ácido nucleico

Implementa `decode_nucleotide/1` para que acepte el valor entero del código codificado y devuelva el punto de código del ácido nucleico.

```elixir
DNA.decode_nucleotide(0b0001)
# => 65
# (which is equal to ?A)
```

## 3. Codifica una charlist de ADN

Implementa `encode/1` para que acepte una charlist que represente ácidos nucleicos y espacios y devuelva un bitstring de los datos codificados.

```elixir
DNA.encode(~c"AC GT")
# => <<18, 4, 8::size(4)>>
```

## 4. Decodifica un bitstring de ADN

Implementa `decode/1` para que acepte un bitstring que represente ácidos nucleicos y espacios y devuelva los datos decodificados como una charlist.

```elixir
DNA.decode(<<132, 2, 1::size(4)>>)
# => ~c"TG CA"
```
