# Introducción

## Enumeraciones

El tipo `enum` de C# representa un conjunto fijo de constantes con nombre (una enumeración). Su propósito principal es proporcionar una forma segura en cuanto a tipos de interactuar con constantes numéricas, limitando los valores disponibles a un conjunto predefinido. Una enumeración simple se puede definir de la siguiente manera:

```csharp
enum Season
{
    Spring,
    Summer,
    Autumn,
    Winter
}
```

Si no se definen explícitamente, los miembros de la enumeración recibirán automáticamente valores enteros consecutivos, siendo el primero cero. También es posible asignar valores explícitamente:

```csharp
enum Answer
{
    Maybe = 1,
    Yes = 3,
    No = 5
}
```
