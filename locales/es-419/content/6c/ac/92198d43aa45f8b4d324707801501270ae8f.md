# Instrucciones

En este ejercicio escribirás código para imprimir distintivos con el nombre de los empleados de una fábrica.

## 1. Imprime un distintivo para un empleado

Los empleados tienen un ID, un nombre y el nombre de su departamento. Las etiquetas de los distintivos de los empleados tienen el siguiente formato: `"[id] - name - DEPARTMENT"`. Implementa el método (_static_) `Badge.Print()` para devolver la etiqueta del distintivo de un empleado:

```csharp
Badge.Print(734, "Ernest Johnny Payne", "Strategic Communication");
// => "[734] - Ernest Johnny Payne - STRATEGIC COMMUNICATION"
```

Ten en cuenta que el departamento debe escribirse en mayúsculas en la etiqueta.

## 2. Imprime un distintivo para un empleado nuevo

Debido a una peculiaridad del sistema de la computadora, a veces los empleados nuevos todavía no tienen un ID cuando empiezan a trabajar en la fábrica. Como los distintivos son obligatorios, recibirán un distintivo temporal sin el prefijo del ID. Modifica el método (_static_) `Badge.Print()` para admitir a los empleados nuevos que todavía no tienen un ID:

```csharp
Badge.Print(id: null, "Jane Johnson", "Procurement");
// => "Jane Johnson - PROCUREMENT"
```

## 3. Imprime un distintivo para el dueño

Incluso el dueño de la fábrica tiene que llevar un distintivo en todo momento. Sin embargo, el dueño no tiene un departamento. En este caso, la etiqueta debe imprimir `"OWNER"` en lugar del nombre del departamento. Modifica el método (_static_) `Badge.Print()` para imprimir la etiqueta del dueño:

```csharp
Badge.Print(254, "Charlotte Hale", department: null);
// => "[254] - Charlotte Hale - OWNER"
```

Ten en cuenta que es posible que el dueño también sea un empleado nuevo:

```csharp
Badge.Print(id: null, "Charlotte Hale", department: null);
// => "Charlotte Hale - OWNER"
```
