# Introducción

La capacidad de algo de definirse en términos de sí mismo se llama recursión. En Gleam, la recursión aparece con mayor frecuencia en las funciones recursivas, que son funciones que se llaman a sí mismas.

Una función recursiva necesita tener al menos un _caso base_ y al menos un _caso recursivo_. Un _caso base_ devuelve un valor sin volver a llamar a la función. Un _caso recursivo_ vuelve a llamar a la función, modificando el argumento para que en algún momento coincida con el caso base.

```gleam
pub fn factorial(x: Int) -> Int {
  case x {
    // Base case
    1 -> 1

    // Recursive case
    _ -> x * factorial(x - 1)
  }
}
```

Gleam no tiene una sintaxis especial para hacer bucles, así que todos los bucles se hacen con recursión.

```gleam
pub fn list_length(list: List(String)) -> Int {
  case list {
    [] -> 0
    [_, ..rest] -> 1 + list_length(rest)
  }
}
```

Gleam también admite tipos personalizados recursivos. En un tipo personalizado recursivo, una o más de sus variantes se refieren al propio tipo en los datos que contienen.

```gleam
pub type RussianDoll {
  Child               // Base case
  Mother(RussianDoll) // Recursive case
}
```
```gleam
let very_big_doll = Mother(Mother(Mother(Child)))
let small_doll = Mother(Child)
```
