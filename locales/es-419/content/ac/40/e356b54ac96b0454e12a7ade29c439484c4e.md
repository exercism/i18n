# Instrucciones

Tu amigo acaba de enviarte un mensaje con un secreto importante.
Como no quería que fuera fácil para otras personas leerlo, el mensaje fue cifrado usando una serie de manipulaciones de bits.
Vas a tener que escribir un programa que te ayude a descifrar el mensaje.

## 1. Desplaza los bits de vuelta

El primer paso para descifrar el mensaje es revertir el desplazamiento del proceso de cifrado desplazando los bits de vuelta hacia la izquierda.
La cantidad de posiciones que hay que desplazar puede variar entre mensajes.

Implementa el método `Secrets.shift_back`, que recibe un valor y la cantidad de posiciones que hay que desplazar a la izquierda.

```crystal
Secrets.shift_back(0b0001, 2)
# => 0b0100
```

## 2. Aplica una máscara de bits

El siguiente paso es aplicar una máscara de bits para extraer el valor de ciertos bits.
La máscara se aplica realizando un AND bit a bit entre el valor y la máscara.

Implementa el método `Secrets.apply_mask`, que recibe un valor y le aplica una máscara.

```crystal
Secrets.apply_mask(0b0110, 0b0101)
# => 0b0100
```

## 3. Establece algunos bits

Desplazar bits a la izquierda agregó algunos bits nuevos en 0.
Algunos de esos bits nuevos deben establecerse en 1.
El OR bit a bit es útil para establecer ciertos bits en 1 mientras se conservan los demás.

Implementa el método `Secrets.set_bits`, que recibe dos valores y realiza un OR bit a bit.

```crystal
Secrets.set_bits(0b0110, 0b0101)
# => 0b111
```

## 4. Invierte el XOR

Parte del proceso de cifrado aplica un XOR con un valor acordado.
Para volver al valor original, basta con aplicar XOR de nuevo al valor cifrado con el valor acordado.
Sin embargo, debido a un malentendido, tu amigo invirtió los bits del valor acordado (es decir, aplicó un NOT bit a bit al valor acordado) antes de aplicar el XOR.

Implementa el método `Secrets.reverse_xor`, que recibe el valor cifrado y el valor acordado, y calcula el valor original.

```crystal
Secrets.reverse_xor(0b1100, 0b0101)
# => 0b(0110)
```
