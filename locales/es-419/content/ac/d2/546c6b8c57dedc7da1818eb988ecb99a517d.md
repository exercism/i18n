# Introducción

Una *reducción* combina los elementos de una secuencia en un solo valor (o en una secuencia derivada de valores acumulados). El reductor de propósito general de Factor es `reduce`; `math.statistics` agrega una familia de operaciones acumulativas (sumas, productos, mínimos y máximos acumulados) para cuando quieres cada resultado intermedio en lugar de solo el último.

```factor
USING: math math.statistics sequences ;

{ 2 5 1 3 } 0 [ + ] reduce .         ! => 11

{ 2 5 1 3 } cum-sum .                ! => { 2 7 8 11 }
{ 2 5 1 3 } cum-product .            ! => { 2 10 10 30 }
{ 2 5 1 3 } cum-min .                ! => { 2 2 1 1 }
{ 2 5 1 3 } cum-max .                ! => { 2 5 5 5 }
```
