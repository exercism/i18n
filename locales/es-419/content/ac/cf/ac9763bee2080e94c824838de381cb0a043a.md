# Introducción

Entender las referencias es fundamental para usar Perl de manera efectiva.
Como las referencias son escalares, y los arrays y los hash solo pueden contener escalares, las referencias son clave para anidar estas estructuras de datos.

Puedes crear referencias a variables y subrutinas existentes usando el operador de barra invertida `\`:

* `\$scalar` para crear una referencia a un escalar (puede ser cualquier escalar, por ejemplo `\1`, no solo una variable).
* `\@array` para crear una referencia a un array.
* `\%hash` para crear una referencia a un hash.
* `\&sub` para crear una referencia a código.

También puedes crear lo que se conoce como una referencia anónima para arrays, hash y subrutinas:

* `['Alice', 'Bob', 'Charlie']` para crear una referencia anónima a un array.
* `{foo => 'a', bar => 'b', baz => 'c'}` para crear una referencia anónima a un hash.
* `sub { return 1 }` para crear una referencia anónima a código.

ADVERTENCIA: las llaves en Perl pueden ser ambiguas en ciertos contextos. Si no obtienes la referencia a hash que esperas, agrega un signo más al inicio para desambiguarla, por ejemplo `+{}`. Consulta [Llaves][perlrefcurlybrackets] para más información.

Puedes acceder a las referencias usando el operador de flecha `->`:

* `$ref->[0]` para acceder a un elemento dentro de una referencia a array.
* `$ref->{foo}` para acceder a un valor dentro de una referencia a hash.
* `$ref->($arg)` para llamar a una subrutina a través de una referencia a código.

Puedes acceder a los datos dentro de estructuras de datos complicadas, como arrays multidimensionales y hash anidados, encadenando subíndices, por ejemplo `$ref->{foo}[0]{bar}` (lo mismo que `$ref->{foo}->[0]->{bar}`).

Si quieres desreferenciar un array o un hash completo, puedes usar el operador de flecha seguido de `@*` o `%*` respectivamente, por ejemplo `$ref->@*` o `$ref->%*`.
También puedes obtener rebanadas de una referencia a array o a hash reemplazando el `*` con un subíndice, por ejemplo `$ref->@[0..2]` o `$ref->@{'Foo', 'Bar'}`.
Para las rebanadas, la variación de sigilo se aplica aquí de la misma manera que con las variables de array y hash.

[perlrefcurlybrackets]: https://perldoc.perl.org/perlref#Curly-Brackets
