# Pistas

## General

- Vuelve a revisar el [concepto de objetos][concept-objects] si lo necesitas para repasar lo básico.

## 1. Define Size para almacenar las dimensiones de la ventana

- Recuerda usar la [sintaxis de prototipos][mdn-prototype] para esta tarea.
- Empieza por definir una función con el nombre `Size` y asegúrate de [exportarla][mdn-export].
- Los argumentos que se pasan a la función constructora deben agregarse al objeto `this`.
- Los valores predeterminados se pueden aplicar usando [parámetros predeterminados][mdn-default-params].
- Puedes agregar un método mediante la propiedad `prototype` de la función constructora.

## 2. Define Position para almacenar la posición de una ventana

- Recuerda usar la [sintaxis de prototipos][mdn-prototype] para esta tarea.
- Empieza por definir una función con el nombre `Position` y asegúrate de [exportarla][mdn-export].
- Los argumentos que se pasan a la función constructora deben agregarse al objeto `this`.
- Los valores predeterminados se pueden aplicar usando [parámetros predeterminados][mdn-default-params].
- Puedes agregar un método mediante la propiedad `prototype` de la función constructora.

## 3. Define una clase ProgramWindow

- Recuerda usar la [sintaxis de clases][mdn-class] para esta tarea.
- Asegúrate de [exportar][mdn-export] la clase.
- Define campos agregándolos al objeto `this`.
- Usa las clases que definiste en las tareas anteriores.
- Verifica que tu función constructora no acepte ningún argumento.

## 4. Agrega un método para redimensionar la ventana

- Recuerda usar la [sintaxis de clases][mdn-class] para esta tarea.
  Eso significa que agregas la definición del método directamente en el cuerpo de la clase.
- Para encontrar los valores correctos del cambio de tamaño, primero piensa en el ancho que quieres alcanzar, teniendo en cuenta el límite inferior (`1`).
- Luego calcula el ancho máximo permitido, considerando el tamaño de la pantalla y la posición `x` actual de la ventana.
- Con esos dos valores, puedes decidir qué aplicar y usar una lógica análoga para la altura.
- Usa el método `resize` del objeto `Size` para aplicar el cambio.

## 5. Agrega un método para mover la ventana

- Recuerda usar la [sintaxis de clases][mdn-class] para esta tarea.
  Eso significa que agregas la definición del método directamente en el cuerpo de la clase.
- Para encontrar los valores correctos del desplazamiento, primero piensa en la posición `x` que quieres alcanzar, teniendo en cuenta el límite inferior (`0`).
- Luego calcula el valor máximo permitido de `x`.
  Considera el tamaño de la pantalla y el ancho actual de la ventana.
- Con esos dos valores, puedes decidir qué aplicar y usar una lógica análoga para la altura.
- Usa el método `move` del objeto `Position` para aplicar el cambio.

## 6. Cambia una ventana de programa

- Primero, define una función `changeWindow` y asegúrate de [exportarla][mdn-export].
- Crea una instancia de la clase `Size` con la palabra clave `new` y pasa las dimensiones deseadas como argumentos. (Algo similar para el objeto de posición que necesites.)
- Usa los métodos definidos en las tareas 4 y 5. Por ejemplo, llamas a un método `a` de un objeto `obj` con `obj.a()`.
- Asegúrate de devolver la instancia de `Window` que recibiste como argumento.
