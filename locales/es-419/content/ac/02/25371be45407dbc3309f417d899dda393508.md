# Pistas

## General

- Lee sobre los [structs][getting-started-structs] en la guía de introducción.
- Lee sobre [`defstruct`][docs-defstruct] en la documentación.
- Mira [Elixir Casts - #106: Intro to Structs][elixir-casts].

## 1. Crea un auto a control remoto totalmente nuevo

- El atributo de módulo `@enforce_keys` se puede usar para especificar los valores requeridos. Se debe definir antes de llamar a `defstruct`.
- El campo `nickname` no debe tener un valor predeterminado especificado.
- La función `new/0` debe inicializar el campo `nickname` con el valor `"none"`.

## 2. Crea un auto a control remoto totalmente nuevo con un apodo

- Usa [`multiple-function-clauses`][multiple-fn-clauses] para reutilizar el nombre de la función pero aceptar distintos argumentos.
- Considera un [`default-argument`][default-arg] para la función.

## 3. Muestra la distancia

- Para las funciones que aceptan solo un tipo específico de struct, asegúrate de hacer una coincidencia de patrones para verificar el argumento.
- Usa el _operador de acceso estático_ para obtener los valores de los campos.

## 4. Muestra el porcentaje de batería

- Para las funciones que aceptan solo un tipo específico de struct, asegúrate de hacer una coincidencia de patrones para verificar el argumento.
- Usa el _operador de acceso estático_ para obtener los valores de los campos.

## 5. Conducir cambia la batería y la distancia recorrida

- Para las funciones que aceptan solo un tipo específico de struct, asegúrate de hacer una coincidencia de patrones para verificar el argumento.
- Usa el _operador de acceso estático_ para obtener los valores de los campos.
- Revisa la introducción para actualizar structs.

## 6. Ten en cuenta la conducción con una batería descargada

- Si la batería está descargada, debe devolver el struct sin cambios.
