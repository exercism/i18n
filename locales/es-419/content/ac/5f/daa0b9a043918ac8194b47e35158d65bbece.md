# Pistas

## General

- `H{ } clone` es la forma correcta de empezar una tabla hash nueva y mutable; los literales `H{ }` se pueden compartir entre llamadas.
- `inc-at`, de [`assocs`][assocs], suma 1 al valor de una clave (o la inserta con 1 si no existe).

## 1. Construye un inventario a partir de una lista

- Empieza con `H{ } clone` y usa `inc-at` para cada elemento. Una quotation de fry `'[ _ inc-at ]` captura la tabla hash para que puedas pasarla por `each`.
- Encierra la iteración en `[ … ] keep` para que la tabla hash sea el valor que queda en la pila.

## 2. Agrega más elementos

- La estructura es la misma que en la tarea 1, salvo que empiezas a partir de un `clone` del inventario de entrada en vez de uno vacío.

## 3. Decrementa los conteos

- Usa `key?` primero; solo se tocan los elementos que ya están en el inventario.
- `change-at` acepta una quotation `( old -- new )`; combínala con `[ 1 - 0 max ]` (con `max` de [`math.order`][math.order]) para que el conteo nunca se vuelva negativo.

## 4. Elimina un elemento por completo

- `delete-at` modifica la tabla hash y no devuelve nada: primero `clone`, luego `delete-at` y, por último, deja el clon en la pila.

## 5. Lista los elementos disponibles

- `>alist` convierte la tabla hash en una secuencia de pares.
- `[ second 0 > ] filter` conserva solo los elementos que hay en existencia.
- `sort-keys` (en [`sorting`][sorting]) ordena una alist por clave.

[math.order]: https://docs.factorcode.org/content/vocab-math.order.html
[sorting]: https://docs.factorcode.org/content/vocab-sorting.html
