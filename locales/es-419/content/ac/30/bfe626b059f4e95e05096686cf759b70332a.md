# Prefiere la concatenación de string

Aunque `String.format` y `String.formatted()` son métodos maravillosos y potentes, son más lentos para un problema que solo requiere una concatenación simple de `String` con el operador `+`.
Para obtener más información sobre el rendimiento de `String.format` y `String.formatted()`, consulta [Java String Concatenation: Which Way Is Best?](https://redfin.engineering/java-string-concatenation-which-way-is-best-8f590a7d22a8).
