# Instrucciones

En este ejercicio vas a procesar líneas de log.

Cada línea de log es una cadena con el siguiente formato: `"[<LVL>]: <MESSAGE>"`.

Estos son los diferentes niveles de log:

- `TRC` (trace)
- `DBG` (debug)
- `INF` (info)
- `WRN` (warning)
- `ERR` (error)
- `FTL` (fatal)

Tienes tres tareas, y cada una debe completarse para proporcionar la funcionalidad necesaria.

## 1. Crea la enumeración LogLevel

Define una enumeración `LogLevel` que tenga seis casos correspondientes a los niveles de log anteriores, más un caso desconocido para los niveles faltantes o no estándar.

- `trace`
- `debug`
- `info`
- `warning`
- `error`
- `fatal`
- `unknown`

## 2. Analiza el nivel de log

Ahora implementa el inicializador de `LogLevel` para analizar el nivel de log de una línea de log:

```swift
LogLevel("[INF]: File deleted")
// Returns LogLevel.info
LogLevel("Something went wrong!")
// Returns LogLevel.unknown
```

## 3. Convierte la línea de log al formato corto

El nivel de log de una línea de log es bastante verboso.
Para reducir el espacio en disco que se necesita para almacenar las líneas de log, se desarrolló un formato corto: `"<ENCODED_LEVEL>:<MESSAGE>"`.

El nivel de log codificado es un simple mapeo de un nivel de log a un número:

- `trace` - `0`
- `debug` - `1`
- `info` - `4`
- `warning` - `5`
- `error` - `6`
- `fatal` - `7`
- `unknown` - `42`

Implementa el método `shortFormat(message: String) -> String`, que devuelve la línea de log en formato corto como un `String`:

```swift
let overflow = LogLevel.error
overflow.shortFormat(message: "Stack overflow")
// Returns "6:Stack overflow"
```
