## 1. Verifica si un visitante tiene un pase de atracciones

- Convierte el pass_id a un objeto Boolean.
- Mira la clase [`BasicObject`][basicobject-class], que contiene métodos que heredan la mayoría de las clases.

## 2. Verifica si un visitante cumple los requisitos de altura para una atracción

- Compara la altura mínima de la atracción con la altura del visitante.
- Mira el módulo [`Comparable`][comparable-module], que contiene métodos para comparar objetos que se pueden usar cuando se incluyen.
  - La clase [Integer][integer-class] incluye el módulo [`Comparable`][comparable-module].

## 3. Verifica si un visitante tiene permitido subir a una atracción

- Combina los métodos de instancia que creaste usando un [operador Boolean][pr-boolean-operator] para devolver el resultado.
