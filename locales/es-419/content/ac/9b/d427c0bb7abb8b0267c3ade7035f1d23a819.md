# defmacro con `_is` y signo de interrogación

Elixir tiene convenciones de nombres específicas que incluyen cómo nombrar las [funciones que devuelven booleanos](https://hexdocs.pm/elixir/naming-conventions.html#trailing-question-mark-foo) y las [verificaciones que devuelven booleanos y son válidas en cláusulas de guarda](https://hexdocs.pm/elixir/naming-conventions.html#is_-prefix-is_foo):

> Las funciones que devuelven un booleano se nombran con un signo de interrogación al final.

> Las verificaciones de tipos y otras verificaciones booleanas que se permiten en las cláusulas de guarda se nombran con el prefijo `is_`.

Las macros se pueden usar en ambos contextos, así que la notación depende del caso, pero las dos convenciones de nombres no se deben mezclar.

```elixir
# this is the expected name of macros that return booleans

%{option1}

# this is the expected name of macros that return booleans and are valid in guard clauses

%{option2}

# this is the current name

%{actual}
```
