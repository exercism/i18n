# Resolver ejercicios

La principal forma en que Exercism te ayuda a aprender es resolviendo ejercicios.

Hay dos formas de resolver ejercicios en Exercism:

1. [En línea, con el editor del sitio web en el navegador](/docs/using/solving-exercises/using-the-online-editor)
2. [En tu computadora, con la CLI](/docs/using/solving-exercises/working-locally)

## ¿Qué opción debería elegir?

Hay distintas ventajas y desventajas entre usar el editor en línea o la CLI:

|            | Editor en línea                       | CLI                                          |
| ---------- | -------------------------------------- | -------------------------------------------- |
| Instalación | No                                     | Sí (por ejemplo, SDK)                        |
| Edición    | Navegador                              | Tu editor preferido                          |
| Pruebas    | Ejecutar las pruebas en el sitio web   | Ejecutar las pruebas en tu computadora       |
| Depuración | Soporte limitado (solo para algunos tracks) | Soporte completo (según tu entorno)      |

En general, el editor en línea es ideal para empezar tracks nuevos, mientras que el enfoque con la CLI es perfecto si quieres usar tu propio entorno de programación personalizado.
