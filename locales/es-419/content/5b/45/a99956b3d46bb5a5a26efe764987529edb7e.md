# Introducción

Factor modela fechas y horas con el vocabulario [`calendar`][calendar]. Un punto en el tiempo es un `timestamp`; un lapso de tiempo es un `duration`.

## Construir una fecha

`<date>` (en [`calendar`][calendar]) construye un `timestamp` a la medianoche del día dado:

```
<date> ( year month day -- timestamp )
```

```factor
USING: calendar ;

1904 11 16 <date> .
! a timestamp at midnight on 1904-11-16
```

`>date<` divide un timestamp de nuevo en sus partes:

```
>date< ( timestamp -- year month day )
```

```factor
1904 11 16 <date> >date< .   ! => 16   (with 1904 and 11 below it)
```

## Inspeccionar una fecha

`day-of-week` devuelve el día de la semana como un número entero, `0` para domingo hasta `6` para sábado. `day-names` (en [`calendar.english`][english]) es la lista de nombres correspondiente, así que `day-names nth` convierte el número en una palabra:

```factor
USING: calendar calendar.english sequences ;

2024 1 8 <date> day-of-week .          ! => 1
day-names .   ! { "Sunday" "Monday" ... "Saturday" } — Sunday first
```

`leap-year?` acepta un año (o un timestamp), y `days-in-month` devuelve la cantidad de días del mes de un timestamp, que ya tiene en cuenta los años bisiestos:

```
leap-year?    ( obj -- ? )
days-in-month ( timestamp -- n )
```

```factor
2024 leap-year? .                ! => t
2024 2 1 <date> days-in-month .  ! => 29
```

## Aritmética de fechas

Palabras como `days`, `weeks` y `hours` construyen un `duration`, y `time+` desplaza un timestamp en uno:

```
days  ( x -- duration )
time+ ( timestamp duration -- timestamp )
```

```factor
2024 2 28 <date> 1 days time+ >date< .
! => 29   (2024-02-29, with 2024 and 2 below it)
```

La aritmética funciona correctamente al cruzar los límites de mes y año, y dos timestamps que nombran el mismo instante se comparan como iguales con `=`.

## Horas del día

`<timestamp>` construye un timestamp completo, hasta el segundo. Su último argumento es el desplazamiento respecto a UTC; `instant` (un `duration` de cero) mantiene el timestamp en UTC:

```
<timestamp> ( year month day hour minute second gmt-offset -- timestamp )
```

```factor
USING: calendar ;

1969 7 21 2 56 15 instant <timestamp> .
! a timestamp at 02:56:15 on 1969-07-21
```

`>time<` es la contraparte de `>date<`, y divide un timestamp en su hora, minuto y segundo:

```
>time< ( timestamp -- hour minute second )
```

```factor
1969 7 21 2 56 15 instant <timestamp> >time< .   ! => 15   (with 2 and 56 below it)
```

`seconds` y `minutes` construyen un `duration` igual que `days`, `weeks` y `hours`, así que cualquiera de ellos se puede pasar a `time+`:

```
seconds ( x -- duration )
minutes ( x -- duration )
```

Los campos individuales de un timestamp se leen con los accesores `year>>`, `month>>`, `day>>`, `hour>>`, `minute>>` y `second>>`:

```factor
1969 7 21 2 56 15 instant <timestamp> hour>> .   ! => 2
```
