# Acerca de

En Haxe, una `class` es la estructura de datos principal, que encapsula datos (campos) y comportamiento (métodos). Los campos y los métodos también se llaman miembros de una clase.

El acceso a los miembros se puede restringir con [modificadores de acceso][visibility], que son:

- `public`: se puede acceder al miembro desde cualquier lugar.
- `private`: solo se puede acceder al miembro desde la misma clase.

Las clases se pueden ver como plantillas para crear instancias. Para crear una [instancia][class-instance], simplemente usa la palabra clave `new`:

```haxe
class Car {
  public function new() {}
}

var myCar = new Car();
var yourCar = new Car();
```

Para definir un campo, usa un modificador de acceso seguido del nombre de la variable y su tipo:

```haxe
class Car {
  public var weight:Int; // Accessable by anyone

  private var color:String; // Accessable only within this class
}
```

También puedes asignar un valor inicial al definir un campo. Si un campo no especifica un valor inicial, tomará el valor `null`. Puedes acceder a un campo con la notación de punto:

```haxe
class Car {
  public var weight:Int = 2500; // Weight will be set to 2500
  public var year:Int; // year will be null

  public function new() {}
}

var newCar = new Car();
newCar.weight; // 2500
newCar.year; // null

// Update value of field
newCar.year = 2020;
```
