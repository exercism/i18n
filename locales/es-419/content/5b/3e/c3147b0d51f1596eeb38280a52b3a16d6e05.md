# Pistas

## General

- Lee sobre la [coincidencia de patrones][pattern-matching] en la guía oficial.
- Echa un vistazo a esta hoja de referencia sobre la [desestructuración][destructuring].
- La coincidencia de patrones para registros se [explica aquí][records-pattern-matching] con más detalle.

## 1. Detectar comentarios vacíos

- Puedes usar `(a, b)` directamente en el argumento de la función si el argumento es un par.
- Puedes reemplazar los valores que recibes pero no usas por el comodín `_`.
- Para comprobar si un string está vacío, consulta la [documentación de `String`][string-docs].

## 2. Contar la cantidad de comentarios del creador

- Puedes desestructurar un tipo personalizado con una sola variante `type Box = Box AB` directamente en el argumento de una función así: `(Box ab)`.
- Puedes hacer coincidencia de patrones sobre el campo `a` de un registro `{a : A, b : B}` usando: `{ a }`.
- Puedes usar ambas técnicas anteriores al mismo tiempo para tipos personalizados que contienen un registro.
- No puedes hacer coincidencia de patrones directamente sobre el par `ab` de un registro `{ ab : (A, B) }`. Primero debes hacer coincidencia de patrones sobre `{ ab }` y luego usar `( a, b) = ab` en una vinculación `let`.
- Para encontrar la cantidad de elementos que cumplen una condición en una lista, usa las [funciones de `List`][list-docs].
- Puedes desestructurar pares directamente en los argumentos de las funciones anónimas.

## 3. Detectar tickets asignados al Dev Team

- Como en la tarea 2, puedes hacer coincidencia de patrones sobre los campos relevantes de un registro «envuelto» en el argumento de la función.
- Puedes usar la coincidencia de patrones de forma recursiva para hacer coincidir un valor anidado como `Just (Box "42")`.
- Puedes usar el comodín `_` para hacer coincidir cualquier cosa en una sentencia `case`.

## 4. Asignar tickets a los empleados de TI

- Como en las tareas 2 y 3, puedes hacer coincidencia de patrones sobre los campos relevantes de un registro «envuelto» en el argumento de la función.
- Además, puedes usar la palabra clave `as` para hacer coincidencia de patrones sobre un campo y también vincular el registro completo: `(Box ({ a } as ab))`.
- Puedes hacer coincidencia de patrones sobre los valores de un tipo personalizado con la sentencia `case`.
- Usa el constructor de tipo `Ticket` para devolver un ticket.
- Usa la [sintaxis de actualización de registros][record-update] para modificar registros.
