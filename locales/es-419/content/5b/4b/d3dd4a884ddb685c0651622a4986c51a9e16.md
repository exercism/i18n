# Pistas

## General

- Puedes completar todas estas tareas sin usar una sentencia `if`.

## 1. Determina si vas a necesitar una licencia de conducir

- Usa el [operador de igualdad][cmp] para verificar si el primer campo es igual a un string determinado.
- Usa una expresión regular para verificar si el segundo campo contiene las subcadenas requeridas.
- Usa uno de los dos [operadores Boolean][bool] para combinar los dos requisitos.

## 2.Calcula una estimación para el precio de un vehículo usado

- Usa los [operadores de comparación][cmp] para determinar qué descuento usar.

[cmp]: https://www.gnu.org/software/gawk/manual/html_node/Comparison-Operators.html
[bool]: https://www.gnu.org/software/gawk/manual/html_node/Boolean-Ops.html
