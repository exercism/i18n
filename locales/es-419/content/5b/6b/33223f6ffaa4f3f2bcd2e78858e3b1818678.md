# Introducción

PowerShell es un lenguaje de scripting dinámico y con tipado implícito (_aunque también admite [variables de tipado fuerte][strong typed]_) de Microsoft, enfocado principalmente en la automatización de tareas y la administración de la configuración.

PowerShell admite programación imperativa, funcional, orientada a objetos e incluso de estilo pipeline.

PowerShell se construyó sobre la plataforma .NET y se lanzó por primera vez en 2006.
Viene incluido por defecto en todos los sistemas Windows modernos y también se puede instalar en Mac y Linux.


## Variables

Hay dos formas comunes de definir una variable en PowerShell.

Los nombres de las variables en PowerShell deben empezar con `$` y usar el operador de asignación `=` para vincular el nombre de la variable a un valor.

```powershell
> $intVar = 1
> $doubleVar = 2.0
> $stringVar = "Hello"

# Checking a variable type using the GetType() method
> Write-Host $doubleVar.GetType()
System.Double
```

También puedes especificar el tipo de una variable de forma explícita, si quieres forzar o exigir que el valor sea de un tipo determinado.
PowerShell hará todo lo posible por convertir el valor de un tipo a otro si es posible.

```powershell
# String represents a floating number can be converted to integer
> [int]$staticOne = "1.234"
> $staticOne
1

# String of letters can not be converted to double type
> [double]$staticTwo = "hello"
MetadataError: Cannot convert value "hello" to type "System.Double"
```


### Constantes

Las constantes en PowerShell son variables que no se pueden **cambiar** ni **eliminar** después de definirlas.
Esto nos lleva a la segunda forma de definir variables: usar el cmdlet `New-Variable`.

```powershell
> New-Variable -Name "MyConstant" -Value 100 -Option Constant
> $MyConstant
```

Para conocer formas más detalladas y avanzadas de crear una variable, lee [New-Variable][New-Variable].


## Funciones

Las [funciones][functions] en PowerShell se definen con la palabra clave `function`.
Cada función puede tener cero o más parámetros formales entre paréntesis `()`, seguidos del ámbito de la función, que empieza con `{` y termina con `}`.

```powershell
function Greeting {
    return "Hello!"
}
```

Las funciones en PowerShell pueden devolver valores de forma explícita con la palabra clave `return`, después de llamarlas con la sintaxis `FuncName $Arg`.

```powershell
function AddTwoNumbers($NumOne, $NumTwo):
    $result = $NumOne + $NumTwo
    return $result

> AddTwoNumbers 10 20
30
```

Una mirada más avanzada de cómo escribir una definición de función detallada, y de cómo las funciones pueden devolver valores de forma implícita, se cubrirá en el módulo de conceptos `Functions`.


## Comentarios

Los comentarios de una sola línea en PowerShell empiezan con `#` y terminan al final de la línea.
Los bloques de comentarios en PowerShell empiezan con `<#` y terminan con `#>`.
En el módulo de conceptos `Functions` se cubrirá una muestra más avanzada del bloque de comentarios para crear Comment-Based Help.

```powershell
function Main() {
    #This is a comment
    <#
    And this is a comment block
    that can span multiple lines
    #>
}
```
