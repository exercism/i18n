# Instrucciones

En este ejercicio, vas a simular un sistema informático basado en ventanas.
Vas a crear algunas ventanas que se pueden mover y cambiar de tamaño.
La siguiente imagen es representativa de los valores con los que vas a trabajar a continuación.

## 1. Define las propiedades de ProgramWindow

Usando el esqueleto de clase que se proporciona, proporciona las propiedades para los valores `y`, `x`, `height` y `width`.

```php
<?php

$window = new ProgramWindow();
$window->y; // => null
$window->x; // => null
$window->height; // => null
$window->width; // => null
```

## 2. Define los valores iniciales de la ventana del programa

Define una función constructora para `ProgramWindow`.
No debe recibir argumentos, pero durante la ejecución del constructor establece los valores predeterminados de sus propiedades.
Debe establecer los valores iniciales de `y` y `x` en `0`.
Debe establecer los valores iniciales de `height` y `width` en un tamaño de pantalla de `600x800`.

```php
<?php

$window = new ProgramWindow();
$window->y; // => 0 
$window->x; // => 0
$window->height; // => 600
$window->width; // => 800
```

## 3. Define una función para cambiar el tamaño de la ventana

Define una clase nueva en `Size.php` para una clase Size.
Debe recibir argumentos del constructor para establecer las propiedades `height` y `width`.
Además, `ProgramWindow` requiere una función de cambio de tamaño, que recibe la instancia del objeto `Size` y actualiza sus propias propiedades.

```php
<?php 

$window = new ProgramWindow();
$size = new Size(764, 1080);
$window->resize($size)

$window->height;
// => 764
$window->width;
// => 1080
```

## 4. Define una función para mover la ventana

Define una clase nueva en `Position.php` para una clase Position.
Debe recibir argumentos del constructor para establecer las propiedades `y` y `x`.
Además, `ProgramWindow` requiere una función de movimiento, que recibe la instancia del objeto `Position` y actualiza sus propias propiedades.

```php
<?php 

$window = new ProgramWindow();
$position = new Position(80, 313);
$window->move($position)

$window->y;
// => 80
$window->x;
// => 313
```
