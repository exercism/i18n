# Introducción

## Constantes y funciones

Un valor constante se define con `name = expression`,
donde en Elm todo, excepto las definiciones, son expresiones.

```elm
five = 5

six = 3 + 3
```

Las funciones se definen con `name parameters... = expression`,
y los parámetros se separan solamente con un espacio.

```elm
add number1 number2 = number1 + number2
```

Llamar a una función también es una expresión, y se hace
especificando su nombre y pasando argumentos para cada uno de los parámetros de la función,
separados por un espacio, igual que en la definición de la función.

```elm
five = add 2 3
```

Los paréntesis se pueden usar para especificar el orden de evaluación de una expresión.

```elm
six = add 2 (1 * 4)

twelve = add 2 1 * 4
```

## Indentación / espacios en blanco significativos

Elm no usa marcadores sintácticos como llaves, paréntesis o punto y coma para especificar los límites del código. En su lugar, usa espacios en blanco e indentación.

- Las definiciones de módulos, importaciones y funciones de nivel superior deben comenzar en la columna más a la izquierda.
- Si una expresión se divide en varias líneas, el código que forma parte de esa expresión debe estar indentado bajo esa expresión con al menos un espacio.
- Las partes de la expresión que van agrupadas deben estar indentadas con el mismo número de espacios.

```elm
-- A function split over multiple lines, so subsequent lines must be indented
add number1 number2 =
    number1 + number2
```

https://elmprogramming.com/indentation.html

## Módulos

Cada archivo en Elm es un módulo y debe contener una sentencia `module` antes que cualquier otro código.
Los nombres de los módulos deben coincidir con el nombre de su archivo, así que el módulo `Calculator` debe estar en el archivo Calculator.elm.
Todo lo que se define dentro de un módulo tiene ámbito privado dentro de él
y no se puede acceder desde fuera de este módulo, a menos que se liste en `exposing`.

```elm
-- Define the Calculator module, and expose the `add` function
module Calculator exposing (add)

six = 3 + 3

add number1 number2 = number1 + number2
```

```elm
-- Define the Calculator module, and expose everything within: `six` and `add`
module Calculator exposing (..)

six = 3 + 3

add number1 number2 = number1 + number2
```

https://elm-lang.org/docs/syntax#modules

## Comentarios

Un comentario es un texto dentro del archivo de Elm que no se interpreta como código.
Está pensado principalmente para que lo lean tú y otros programadores.
Hay una sintaxis ligera para los comentarios de una sola línea, basada en dos guiones.
Los comentarios multilínea también son posibles con el par de delimitadores
de apertura y cierre `{-` y `-}`.

```elm
-- a single line comment
-- another single line comment

{- a multiline comment
   spawning multiple lines
-}
```

## Formato

Existe una [guía de estilo](https://elm-lang.org/docs/style-guide)
y se puede usar [elm-format](https://github.com/avh4/elm-format) para dar formato al código automáticamente.
