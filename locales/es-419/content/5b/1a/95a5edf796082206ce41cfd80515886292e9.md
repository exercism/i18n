# Introducción

Factor es un lenguaje *concatenativo*: cada palabra toma sus argumentos de
una **pila de datos** compartida y vuelve a poner sus salidas en ella. No
hay ninguna otra forma de pasar valores de un lado a otro.

Escribir un literal lo apila en la parte superior de la pila; el código se
lee de izquierda a derecha:

```factor
1 2 3    ! stack (bottom → top): 1 2 3
```

Una declaración de *efecto de pila* documenta el contrato de una palabra:

```factor
: restow ( a b -- b a ) swap ;
```

`( a b -- b a )` indica que la palabra saca dos valores y deja otros dos,
pero en el orden inverso. Los nombres son documentación (el compilador solo
verifica el *número* de argumentos y de salidas), y el nombre de la derecha
corresponde a la parte superior de la pila.

Las **palabras de reordenamiento** habituales de `kernel` reordenan la parte
superior de la pila:

```
dup  ( x   -- x x   )
drop ( x   --       )
swap ( x y -- y x   )
over ( x y -- x y x )
nip  ( x y -- y     )
rot  ( x y z -- y z x )
```

Las palabras se definen con `:` y terminan en `;`; el compilador rechaza
una definición cuyo cuerpo no coincida con el efecto declarado.
