# Instrucciones

El nuevo aeropuerto de Berlín contrató a desarrolladores para su laboratorio de robots, y tú empiezas a trabajar allí.
Tienen robots torpes, de aspecto un tanto humanoide, que están intentando usar para mejorar la atención al cliente.

Tu primera tarea en el trabajo es escribir un programa para que el robot pueda saludar a las personas en su idioma nativo después de que escaneen su pasaporte en el mostrador de auto check-in.

El robot está orgulloso de sus habilidades, así que siempre dirá primero qué idioma puede hablar y luego saludará a la persona.
Por ejemplo, si alguien escanea un pasaporte alemán, el robot diría:

```txt
I can speak German: Hallo Dietrich!
```

## 1. Crea la funcionalidad abstracta de saludo

No vas a escribir tú el código de los distintos idiomas, así que necesitas estructurar el código del robot de modo que otros desarrolladores puedan añadir más idiomas fácilmente después.

Como primer paso, define una interfaz `Greeter` con dos métodos.

- `LanguageName`, que devuelve el nombre del idioma (un `string`) en el que se supone que el robot saluda al visitante.
- `Greet`, que acepta el nombre de un visitante (un `string`) y devuelve un `string` con el mensaje de saludo en un idioma específico.

Luego, implementa una función `SayHello` que acepte como argumentos el nombre del visitante y cualquier cosa que implemente la interfaz `Greeter`, y que devuelva el string de saludo deseado.
Por ejemplo, imagina una implementación de `Greeter` en alemán para la cual `LanguageName` devuelve `"German"` y `Greet` devuelve `"Hallo {name}!"`:

```go
SayHello("Dietrich", germanGreeter)
// => "I can speak German: Hallo Dietrich!"
```

## 2. Implementa el italiano

Ahora tu trabajo es hacer que el robot funcione para las personas que escanean pasaportes italianos.

Para eso, crea una estructura `Italian` e implementa los dos métodos que se necesitan para que la estructura cumpla con la interfaz `Greeter` que definiste en la tarea 1.
Puedes saludar a alguien en italiano con `"Ciao {name}!"`.

## 3. Implementa el portugués

Antes de terminar el día, también se supone que debes completar la funcionalidad para saludar a la gente en portugués.

Para eso, crea una estructura `Portuguese` e implementa aquí también los dos métodos que se necesitan para que la estructura cumpla con la interfaz `Greeter`.
Puedes saludar a alguien en portugués con `"Olá {name}!"`.
