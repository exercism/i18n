# Manejo de errores

En este ejercicio, vas a implementar una función llamada `processString` que procesa un string de entrada con un manejo de errores adecuado.

Aprenderás a:

- Verificar los tipos de entrada y lanzar errores para entradas no válidas.
- Lanzar errores para casos específicos (por ejemplo, strings vacíos).
- Devolver la versión en mayúsculas del string si es válido.
- Manejar y capturar errores usando un bloque try..catch


Implementa la función processString usando un bloque `try…catch`.

Dentro del bloque `try`:
- Si la entrada no es un string, lanza un `TypeError`.
- Si la entrada es un string vacío, devuelve `null`.
- Si la longitud de la entrada es mayor que 100, o menor que 10, lanza un `RangeError`
- Si la entrada contiene una mezcla de letras y números, lanza un `SyntaxError`.
- De lo contrario, devuelve la entrada en `uppercase`.

*¡No olvides adjuntar mensajes de error adecuados cuando lances! Un mensaje de error informativo y bien estructurado puede ahorrarte horas de depuración.*

Dentro del bloque `catch`:
- registra el mensaje del error usando `console.log`
- haz `throw` del `error` para que se pueda probar su tipo.
