# Instrucciones

En este ejercicio vas a escribir un poco de código para ayudarte a cocinar una lasaña espectacular de tu libro de cocina favorito.

Tienes cuatro tareas, todas relacionadas con el tiempo que se dedica a cocinar la lasaña.

## 1. Define el tiempo esperado en el horno en minutos

Define el método `Lasagna.expectedMinutesInOven()`, que no recibe ningún parámetro y devuelve cuántos minutos debe estar la lasaña en el horno. Según el libro de cocina, el tiempo esperado en el horno es de 40 minutos:

```scala
val lasagna = new Lasagna()
lasagna.expectedMinutesInOven()
// => 40
```

## 2. Calcula el tiempo restante en el horno en minutos

Define el método `Lasagna.remainingMinutesInOven()`, que recibe como parámetro los minutos que la lasaña lleva en el horno y devuelve cuántos minutos le quedan por permanecer en el horno, según el tiempo esperado en el horno en minutos de la tarea anterior.

```scala
val lasagna = new Lasagna()
lasagna.remainingMinutesInOven(30)
// => 10
```

## 3. Calcula el tiempo de preparación en minutos

Define el método `Lasagna.preparationTimeInMinutes()`, que recibe como parámetro el número de capas que le agregaste a la lasaña y devuelve cuántos minutos dedicaste a prepararla, suponiendo que cada capa te toma 2 minutos de preparación.

```scala
val lasagna = new Lasagna()
lasagna.preparationTimeInMinutes(2)
// => 4
```

## 4. Calcula el tiempo transcurrido en minutos

Define el método `Lasagna.elapsedTimeInMinutes()`, que recibe dos parámetros: el primero es el número de capas que le agregaste a la lasaña y el segundo es el número de minutos que la lasaña lleva en el horno. La función debe devolver cuántos minutos has dedicado a cocinar la lasaña, que es la suma del tiempo de preparación en minutos y el tiempo en minutos que la lasaña ha pasado en el horno hasta el momento.

```scala
var lasagna = new Lasagna()
lasagna.elapsedTimeInMinutes(3, 20)
// => 26
```
