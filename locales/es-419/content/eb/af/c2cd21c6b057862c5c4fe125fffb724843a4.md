# índice de runes usado con bytes

Recorrer `runes` y usar el índice para obtener `bytes` individuales es seguro en este caso, porque el argumento está compuesto solo por caracteres ASCII. Para ver qué pasa cuando se usan caracteres que no son ASCII, agrega este caso de prueba:

```go
{
	s1:          "aüa",
	s2:          "aÃa",
	want:        1,
	expectError: false,
}
```
