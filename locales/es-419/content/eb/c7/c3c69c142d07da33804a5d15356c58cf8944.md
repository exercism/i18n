# Anexo a las instrucciones

## Registros

| Registro | Uso            | Tipo       | Descripción                                 |
| -------- | -------------- | ---------- | ------------------------------------------- |
| `$a0`    | entrada        | entero     | cantidad de monedas de entrada              |
| `$a1`    | entrada        | entero     | objetivo                                    |
| `$a2`    | entrada/salida | dirección  | array de palabras de monedas que se puede sobrescribir |
| `$v0`    | salida         | entero     | cantidad de monedas de salida, -1 si la entrada no es válida |
| `$t0-9`  | temporal       | cualquiera | se usa para almacenamiento temporal         |
