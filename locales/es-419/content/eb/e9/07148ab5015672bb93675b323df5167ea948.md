# Tests

Para probar la solución, solo tienes que **ejecutar el script de tests**. Puedes hacerlo desde la consola de Red usando la función `do` junto con la ruta del script de tests, así:

```red
do %exercism/red/hello-world/hello-world-test.red
```

O simplemente agregándolo como argumento al binario de Red en la terminal de tu sistema:

```shell
red exercism/red/hello-world/hello-world-test.red
```

Al principio, solo estará habilitado el primer test del archivo de tests. Esto es para animarte a resolver los ejercicios uno por uno. Cuando logres que el primer test pase, cambia el segundo *argumento* de la función `test-init` al inicio del archivo de tests y vuelve a ejecutarlo. Este valor es la cantidad de tests habilitados, así que cambiarlo de `1` a `2` habilitará el segundo test. También puedes quitar el refinamiento `\limit` de la función `test-init` y el segundo argumento, para ejecutar todos los tests sin omitir ninguno.
