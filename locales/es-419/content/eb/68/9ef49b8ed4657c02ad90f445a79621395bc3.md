# Acerca de

La mayor parte de la iteración en Factor se expresa con combinadores (`each`, `map`, `reduce`), pero la recursión explícita todavía tiene su lugar: cuando la recursión no tiene forma de lista, cuando el caso base no es trivial o cuando implementas un combinador por tu cuenta.

```factor
: total ( seq -- sum )
    [ 0 ] [ unclip swap total + ] if-empty ;

: gcd ( a b -- g )
    dup zero? [ drop ] [ tuck mod gcd ] if ;
```

Algunas cosas que debes saber:

- Las definiciones normales con `:` pueden ser recursivas sin ninguna sintaxis especial. El compilador infiere los efectos de pila a través de la llamada recursiva.
- `loop ( quot -- )` te permite iterar una quotation que devuelve un Boolean. Sigue mientras sea verdadero.
- Las llamadas de cola se compilan como saltos, así que las palabras muy recursivas no desbordan la pila.

El par `unclip` / `if-empty` es la forma estándar de recursión sobre secuencias; `cond` es la forma estándar de despacho entre varios casos.
