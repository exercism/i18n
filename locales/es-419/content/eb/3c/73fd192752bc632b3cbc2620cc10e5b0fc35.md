# Introducción

Cuando Elixir resuelve la función que se va a llamar, usa el nombre del módulo para hacer una búsqueda. La búsqueda se puede hacer de forma dinámica si el nombre del módulo está vinculado a una variable.

```elixir
defmodule MyModule do
  def message(), do: "My message"
end

atom = MyModule
atom.message()
# => "My message"
```

Internamente, el nombre de un módulo es un átomo. Todos los átomos de módulos de Elixir llevan automáticamente el prefijo `Elixir.`

```elixir
is_atom(Enum)
# => true
Enum == Elixir.Enum
# => true
```
