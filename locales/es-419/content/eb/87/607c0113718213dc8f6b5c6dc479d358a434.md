# Apéndice de instrucciones

## Registros

| Registro | Uso            | Tipo       | Descripción                                            |
| -------- | -------------- | ---------- | ------------------------------------------------------ |
| `$a0`    | entrada        | dirección  | cadena con el nombre terminada en null, o puntero nulo |
| `$a1`    | entrada/salida | dirección  | cadena de resultado terminada en null                  |
| `$t0-9`  | temporal       | cualquiera | para almacenamiento temporal                           |
