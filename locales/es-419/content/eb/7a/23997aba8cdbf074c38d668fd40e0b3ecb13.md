# Pistas

## 1. Monitorea el nivel de humedad de la habitación

- Si la humedad es demasiado alta, simplemente [detén la ejecución][ref-stopifnot]; no se necesita ningún mensaje.
- Si las condiciones son buenas, necesitas emitir un [mensaje][ref-message].

## 2. Detecta el sobrecalentamiento

- Hay varias condiciones que debes comprobar.
- Si necesitas [detener la ejecución][ref-stop], el mensaje de error es importante.
- Una condición preocupante pero aún no fatal necesita una [advertencia][ref-warning].
- Un buen resultado necesita un [mensaje][ref-message] tranquilizador.
- Recuerda el valor de retorno de tipo Boolean.

## 3. Monitorea la máquina

- Las tareas 1 y 2 tienen valores de retorno de tipo Boolean que puedes comprobar.
