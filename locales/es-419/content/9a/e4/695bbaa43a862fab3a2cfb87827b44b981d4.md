# Introducción

El tipo `Option` es el mecanismo del lenguaje F# para tratar con valores que pueden existir o no.
Ofrece una alternativa con seguridad de tipos al uso de `null`, que es habitual en otros lenguajes para manejar este tipo de valores.
Se usa en muchas funciones de la biblioteca estándar de F#, así que entenderlo es esencial para usar la biblioteca estándar de F# de forma efectiva.

## Uso

El tipo `Option` es un tipo genérico (tiene un tipo subyacente).
Los valores `Option` son `Some value`, que representa un valor concreto, o `None`, que representa la ausencia de valor.

La siguiente función muestra cómo crear un valor `Option`:

```fsharp
let keepIfPositive (a: int) : int option = if a > 0 then Some a else None
```

~~~~exercism/note
`T option` es la sintaxis posfija equivalente a `Option<T>`; las dos formas se pueden usar indistintamente.
Sin embargo, según la Guía de estilo de F#, se prefiere la notación posfija para los tipos Option (consulta [la sección de la Guía de estilo de F# sobre el formato de tipos y anotaciones de tipo](https://learn.microsoft.com/en-us/dotnet/fsharp/style-guide/formatting#for-types-prefer-prefix-syntax-for-generics-foot-with-some-specific-exceptions)).
~~~~

## Leer el contenido de un valor Option

La forma idiomática de leer un valor `Option` es mediante la coincidencia de patrones, como se muestra en el siguiente ejemplo:

```fsharp
// Returns "Hello, <name>!" if the name is provided; otherwise returns "Hello, you!"
let sayHello (optionalName: string option): string = 
    match optionalName with
    | Some name -> "Hello, " + name + "!"
    | None -> "Hello, you!"

sayHello (Some "Matthieu")
// --> "Hello, Matthieu!"

sayHello None
// --> "Hello, you!"
```

## Desempaquetar Options con valores predeterminados

Los `Option` se pueden «desempaquetar» (convertir a su tipo contenido) si proporcionas valores predeterminados con la función `Option.defaultValue`.
Esto es especialmente útil cuando quieres asegurarte de que el valor no sea `None`.
Por ejemplo:

```fsharp
Option.defaultValue "" (Some "F#")
// --> "F#"

Option.defaultValue 0 None
// --> 0
```
