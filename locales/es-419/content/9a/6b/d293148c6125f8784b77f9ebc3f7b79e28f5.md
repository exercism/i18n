# Pistas

## General

- Asegúrate de leer la documentación de los [decodificadores][decode] y los [codificadores][encode]
- La [documentación de GitHub][github] que inspiró este ejercicio contiene más información sobre los objetos JSON
- Deberías poder usar [`Decode.decodeString`][decode-decodeString] para probar tus decodificadores con cualquier entrada

## 1. ¡El ID, por favor!

La tarea se puede resolver con las siguientes funciones:

- [`int`][decode-int]
- [`field`][decode-field]

## 2. ¿Cómo me llamo, ya?

Hay dos formas principales de resolver la tarea:

- usando [`maybe`][decode-maybe]
- usando [`oneOf`][decode-oneOf] con dos decodificadores posibles, uno que usa una combinación de [`field`][decode-field], [`string`][decode-string] y [`map`][decode-map], y otro que usa [`succeed`][decode-succeed]

## 3. ¿User? ¡Apenas lo conozco!

La tarea se puede resolver con las siguientes funciones:

- `decodeId` y `decodeName`
- `User` usado como constructor de tipo
- [`map5`][decode-map5]
- [`field`][decode-field]
- [`int`][decode-int]
- [`string`][decode-string]
- [`bool`][decode-bool]

## 4. Soy un comentario fuerte e independiente

La tarea se puede resolver con las siguientes funciones:

- [`field`][decode-field]
- [`int`][decode-int]
- [`nullable`][decode-nullable]

## 5. Un ingreso extra

La tarea se puede resolver con las siguientes funciones:

- [`field`][decode-field]
- [`string`][decode-string]
- [`andThen`][decode-andThen]
- una sentencia `case` que verifica el contenido de la string que se decodifica
- [`succeed`][decode-succeed]
- [`fail`][decode-fail]

## 6. El despertar de los enlaces

La tarea se puede resolver con las siguientes funciones:

- [`field`][decode-field]
- [`dict`][decode-dict]
- [`string`][decode-string]

## 7. Sí, comentarios

`decodeComment` se puede resolver con las siguientes funciones:

- `decodeId`, `decodePullRequestReviewId`, `decodeUser`, `decodeSide`, `decodeLinks`
- `Comment` usado como constructor de tipo
- [`6`][decode-6]
- [`field`][decode-field]
- [`string`][decode-string]

`decodeComments` se puede resolver con las siguientes funciones:

- `decodeComment`
- [`list`][decode-list]

## 8. Todo encaja

Todas las funciones que se necesitan para esta tarea están definidas en [la documentación de los codificadores][encode], y posiblemente algunas del [módulo `Maybe`][maybe]
