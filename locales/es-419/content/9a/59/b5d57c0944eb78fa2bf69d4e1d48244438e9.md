# Instrucciones

Eres un ávido observador de aves que lleva la cuenta de cuántas aves han visitado tu jardín en los últimos siete días.

Tienes seis tareas, todas relacionadas con la cantidad de aves que visitaron tu jardín.

## 1. Revisa cuáles fueron los conteos de la semana pasada

Para poder comparar, siempre tienes cerca una copia de los conteos de la semana pasada, que fueron: 0, 2, 5, 3, 7, 8 y 4. Define el enlace `lastWeek` que contiene los conteos de la semana pasada:

```fsharp
lastWeek
// => [| 0; 2; 5; 3; 7; 8; 4 |]
```

## 2. Revisa cuántas aves visitaron ayer

Implementa la función `yesterday` para que devuelva cuántas aves visitaron tu jardín ayer. Los conteos de aves están ordenados por día: el primer elemento es el conteo del día más antiguo y el último elemento es el conteo de hoy.

```fsharp
yesterday [| 3; 5; 0; 7; 4; 1 |]
// => 4
```

## 3. Calcula el total de aves que visitaron el jardín

Implementa la función `total` para que devuelva la cantidad total de aves que han visitado tu jardín:

```fsharp
total [| 3; 5; 0; 7; 4; 1 |]
// => 20
```

## 4. Revisa si hubo un día sin aves visitantes

Implementa la función `dayWithoutBirds` que devuelve `true` si hubo un día en el que ninguna ave visitó el jardín; de lo contrario, devuelve `false`:

```fsharp
dayWithoutBirds [| 3; 5; 0; 7; 4; 1 |]
// => true
```

## 5. Incrementa el conteo de hoy

Implementa la función `incrementTodaysCount` para incrementar el conteo de hoy y devolver los conteos actualizados:

```fsharp
let birdCount = [| 3; 5; 0; 7; 4; 1 |]
incrementTodaysCount birdCount
// => [| 3; 5; 0; 7; 4; 2 |]
```

## 6. Revisa si la semana es inusual

Durante el último año, has notado que algunas semanas comparten los mismos patrones inusuales:
- En cada día par de la semana, no hubo aves
- En cada día par de la semana, se avistaron exactamente 10 aves
- En cada día impar de la semana, se avistaron exactamente 5 aves

Implementa la función `unusualWeek` que devuelve `true` si el patrón de conteo de aves de esta semana coincide con uno de los patrones inusuales:

```fsharp
unusualWeek [| 1; 0; 5; 0; 12; 0; 2 |]
// => true

unusualWeek [| 5; 0; 5; 12; 5; 3; 5|]
// => true
```

(Fíjate que la paridad de los días se cuenta desde 1, no desde 0: el primer elemento del array corresponde a un día impar)
