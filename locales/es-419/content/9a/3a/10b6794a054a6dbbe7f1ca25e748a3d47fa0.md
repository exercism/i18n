# Acerca de

De forma predeterminada, las variables están limitadas al ámbito en el que se definen. Si se definen en un archivo fuera de una función o una clase, quedan limitadas al ámbito del archivo. Si se definen dentro de una función o una clase, quedan limitadas al ámbito de la función o la clase.

```php
<?php

$file_scoped = "I am file scoped";

function example(): void
{
  $function_scoped = "I am function scoped!";
}
```

## Ámbito global

Usar la palabra clave `global` antes de la asignación de una variable crea una variable con ámbito global. Este patrón suele desaconsejarse, ya que genera [código fuertemente acoplado](<https://en.wikipedia.org/wiki/Coupling_(computer_programming)#Disadvantages_of_tight_coupling>).

```php
function example(): void
{
  global $hello = "World!";
}

echo $hello; // #=> "World!"
```

## Ámbito estático

Usar la palabra clave `static` antes de la asignación o la declaración de una variable preserva el ámbito de la variable, pero su valor se conserva entre ámbitos de ejecución.

```php
function counter(): int
{
  static $count = 0;
  $count += 1;
  return $count;
}
```

En este ejemplo, la variable `$count` se inicializa en 0 _solo en la primera llamada a la función_. En cada llamada posterior, el valor se arrastra a la llamada siguiente. Así, cada invocación de la función devuelve como respuesta un número entero que va aumentando.
