# Anexo de instrucciones

## Memoria reservada

El buffer para el string de entrada usa los bytes 64-191 de la memoria lineal.


## Formato de salida

La serie de números se espera como un solo array continuo de números u8; en la deserialización se dividirá por longitud:

```js
slice("123456", 3) => UInt8Array[1, 2, 3,   2, 3, 4,   3, 4, 5,   4, 5, 6]
// will be split into          [[1, 2, 3], [2, 3, 4], [3, 4, 5], [4, 5, 6]]
```
