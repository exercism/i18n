# Acerca de

## Bucles for

Una sentencia `for` repite un bloque de código.
Su primera línea controla cuántas veces se repite el bloque:

```go
for init; condition; post {
    // loop body
}
```

- La sentencia **init** se ejecuta una vez antes de la primera iteración. Es común declarar e inicializar una variable contadora que el bucle utiliza.
- La **condición** es una expresión Boolean que se evalúa antes de cada iteración. El bucle se detiene cuando esta evalúa a `false`.
- La sentencia **post** se ejecuta después de cada iteración completada. Se puede usar para actualizar un contador.

No rodees `init; condition; post` con paréntesis.
Sin embargo, las llaves `{ }` que rodean el cuerpo del bucle siempre son obligatorias.

Este bucle inicia `i` en `1`, imprime el valor actual de `i`, lo incrementa para la siguiente iteración y se detiene cuando `i` llega a `10`:

```go
for i := 1; i < 10; i++ {
    fmt.Println(i)
}
```

## Otras formas del bucle

### Bucle solo con condición

Las sentencias init y post se pueden omitir.
Una sentencia `for` que solo tiene una condición cumple la misma función que un bucle `while` en otros lenguajes.
Go no tiene la palabra clave `while`.

```go
sum := 1
for sum < 1000 {
    sum += sum
}
fmt.Println(sum)
// Output: 1024
```

### Bucle infinito

Una sentencia `for` se puede escribir sin condición:

```go
for {
    // loop body
}
```

Este bucle no termina por sí solo.
La ejecución debe salir del bucle de forma explícita, por ejemplo con `break` o `return`.

## Control de los bucles

### Break y continue

En este bucle, `break` sale del bucle:

```go
for n := 0; n <= 5; n++ {
    if n == 3 {
        break
    }
    fmt.Println(n)
}
// Output:
// 0
// 1
// 2
```

`continue` omite el resto del cuerpo del bucle actual y comienza la siguiente iteración:

```go
for n := 0; n <= 5; n++ {
    if n % 2 == 0 {
        continue
    }
    fmt.Println(n)
}
// Output:
// 1
// 3
// 5
```

### Break y continue con etiquetas

Con bucles anidados, un `break` o un `continue` sin etiqueta se aplica al bucle más interno.
Para etiquetar un bucle que lo contiene, coloca un identificador seguido de dos puntos en la línea inmediatamente superior.
Después, escribe la etiqueta del bucle después de `break` o de `continue` para dirigir la acción a ese bucle:

```go
OuterLoop:
for i := 0; i < 10; i++ {
    for j := 0; j < 10; j++ {
        if i + j == 10 {
            break OuterLoop
        }
    }
}
```
