# Instrucciones

Crear un servicio en Ballerina es fácil. Ahora puedes agregar un parámetro de consulta y una ruta relativa.

## Objetivos

- Modifica el código proporcionado.
- Debe tener un endpoint de eco que devuelva el valor de un parámetro de consulta `sound`. El servicio debe responder a una solicitud HTTP GET en la ruta `/echo?sound=hello`.
- Debe tener otro endpoint para definir la palabra «echo» que devuelva el string `"A sound or series of sounds caused by the reflection of sound waves from a surface back to the listener."`. El servicio debe responder a una solicitud HTTP GET en la ruta `/echo/definition`.
