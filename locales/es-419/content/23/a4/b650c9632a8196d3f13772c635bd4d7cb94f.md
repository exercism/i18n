# Introducción

Las [tuplas][tuples] agrupan varios valores en un único valor compuesto.
A diferencia de los arrays, los valores de una tupla no necesitan compartir el mismo tipo, y el tamaño de una tupla es fijo una vez que se crea.

Para crear una tupla, encierra entre paréntesis valores separados por comas:

```swift
let order = ("biscuits", 2.99, 3)
```

También puedes especificar anotaciones de tipo de forma explícita:

```swift
let order: (String, Double, Int) = ("biscuits", 2.99, 3)
```

Para extraer elementos individuales de una tupla sin nombres, usa la sintaxis de índice que empieza en cero (`.0`, `.1`, etc.):

```swift
let item = order.0     // "biscuits"
let quantity = order.2 // 3
```

## Tuplas con nombres

Puedes darle nombres a los elementos individuales de una tupla cuando la defines:

```swift
let order = (item: "biscuits", price: 2.99, quantity: 3)
```

Nombrar los elementos hace que el código sea más legible y te permite acceder a los elementos usando la notación de punto con sus etiquetas:

```swift
let item = order.item         // "biscuits"
let quantity = order.quantity // 3
```

También puedes incluir los nombres de los elementos en la anotación de tipo:

```swift
let order: (item: String, price: Double, quantity: Int) = (item: "biscuits", price: 2.99, quantity: 3)
```

## Modificar tuplas

Si una tupla se declara como una variable (`var`), puedes actualizar sus elementos:

```swift
var order = ("biscuits", 2.99, 3)
order.0 = "cookies"
order.1 = 1.99
order.2 = 5

print(order)
// Prints ("cookies", 1.99, 5)
```

## Devolver varios valores

Si bien las funciones de Swift solo pueden devolver un único valor, devolver una tupla te permite empaquetar y [devolver varios valores][multiple-return-values] desde una función:

```swift
func divide(_ dividend: Int, by divisor: Int) -> (quotient: Int, remainder: Int) {
    let quotient = dividend / divisor
    let remainder = dividend % divisor
    return (quotient, remainder)
}

let result = divide(14, by: 4)
print("Quotient: \(result.quotient), Remainder: \(result.remainder)")
// Prints "Quotient: 3, Remainder: 2"
```

## Descomposición de tuplas

Puedes descomponer (desempaquetar) los valores de una tupla en constantes o variables separadas:

```swift
let order = ("biscuits", 2.99, 3)
let (item, price, quantity) = order

print(item) // Prints "biscuits"
```

La descomposición de tuplas también funciona directamente en los bucles `for-in`:

```swift
let orders = [("biscuits", 2.99, 3), ("cookies", 1.99, 5)]

for (item, price, quantity) in orders {
    print("Item: \(item), Price: \(price), Quantity: \(quantity)")
}
```
