# Pruebas

Cada ejercicio tiene una configuración que se hace una sola vez y que puede tardar unos minutos:

```
npm install
```

Abre dos terminales y, en la primera, inicia el proceso de compilación.

```
npm start
```

En la segunda, empieza a ejecutar las pruebas.

```
npm test
```

A medida que edites el código, los dos procesos recompilarán y volverán a ejecutar las pruebas continuamente.
