# Instrucciones

Como una maga en ciernes, Elyse necesita analizar su baraja de muchas maneras distintas.
Para simplificar, solo usa cartas con valores del 1 al 10.

## 1. Determina cuántas cartas de cierto tipo hay en la baraja

Elyse quiere saber cuántas cartas de un tipo en particular tiene en su baraja.

Escribe una función `cardTypeCheck` que tome dos parámetros: un array de cartas (la baraja de Elyse) y el tipo de carta que se va a contar.

<!--prettier-ignore -->
~~~exercism/note
La función debe usar `forEach` y devolver el número de cartas del tipo especificado que hay en la baraja.
~~~

```javascript
const cardType = 3;
cardTypeCheck([1, 2, 3, 4], cardType);
// => 1
```

## 2. Determina cuántas cartas impares o pares hay

Para otro truco, Elyse necesita saber cuántas cartas impares o pares hay en su baraja.

Implementa una función `determineOddEvenCards` que reciba dos parámetros: un array de cartas (la baraja de Elyse) y un Boolean (true equivale a «par» y false equivale a «impar»).

Esta función debe devolver un solo número: la cantidad de cartas impares o pares que hay en la baraja (según el valor del segundo argumento).

<!--prettier-ignore -->
~~~exercism/note
Para practicar, esta vez usa un bucle `for...of` en la implementación de la función.
~~~

```javascript
determineOddEvenCards([1, 2, 3, 1, 5, 6], true);
// => 2

determineOddEvenCards([1, 2, 3, 1, 5, 6], false);
// => 4
```
