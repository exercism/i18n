# Introducción

## Valores predeterminados de los parámetros

Puedes especificar [valores predeterminados de los parámetros][default-parameter-values] para cualquiera de los parámetros de una función asignando un valor al parámetro en la lista de parámetros, justo después de la anotación de tipo del parámetro. Cuando se especifica un valor predeterminado para un parámetro, quien llama a la función puede omitir ese parámetro y se usará el valor predeterminado en su lugar.

```swift
func greeting(name: String = "guest", duration: Int = 2) -> String {
  "Welcome, \(name). Enjoy your \(duration) night stay."
}

greeting(name: "Bobo", duration: 7)
// Returns "Welcome, Bobo. Enjoy your 7 night stay."
greeting(duration: 3)
// Returns "Welcome, guest. Enjoy your 3 night stay."
greeting(name: "Wynona")
// Returns "Welcome, Wynona. Enjoy your 2 night stay."
greeting()
// Returns "Welcome, guest. Enjoy your 2 night stay."
```

## Parámetros variádicos

Los [_parámetros variádicos_][variadic-parameters] en Swift permiten pasar cero o más valores del mismo tipo a un solo parámetro de una función. Esto se indica agregando `...` a la anotación de tipo del parámetro.

Estos valores se agruparán automáticamente en un array cuyos elementos son del mismo tipo que el del parámetro variádico.

```swift
func geometricMean(_ numbers: Double...) -> Double {
  var total = 1.0
  for number in numbers {
      total *= number
  }
  return pow(total, 1.0 / Double(numbers.count))
}

geometricMean(1, 2, 3, 4, 5)
// => 2.605171084697352
```

Ten en cuenta que, al usar parámetros variádicos, Swift tiene una limitación.
Si una función tiene parámetros que van después del parámetro variádico en la definición, el primer parámetro que sigue al parámetro variádico _debe_ tener una etiqueta de argumento.

## Parámetros de entrada y salida

Dentro del cuerpo de una función, los parámetros se tratan como constantes, no como variables; intentar modificar el valor de un parámetro genera un error en tiempo de compilación.
Si una función quiere modificar el valor de un parámetro, debe usar un [_parámetro de entrada y salida_][in-out-parameters] para hacer explícita esta mutabilidad.

Para usar parámetros de entrada y salida, hay que cumplir tres condiciones:

1. La definición de la función debe marcar explícitamente los parámetros de entrada y salida escribiendo la palabra clave `inout` entre el `:` y el nombre del tipo en la anotación de tipo del parámetro.
2. El valor que se pasa al parámetro de entrada y salida debe estar declarado como una variable, no como una constante. Del mismo modo, no puede ser un literal.
3. El nombre de la variable debe ir precedido por un `&` en la llamada a la función, lo que marca explícitamente que se puede modificar.

Cuando se hace esto, la función crea una copia interna del parámetro de entrada y salida, la modifica según lo indicado en el cuerpo de la función y, al finalizar la función, copia el valor modificado de vuelta en la variable que se había pasado.

```swift
func updateVersion(_ record: inout (version: Int, title: String)) {
  record.version += 1
}

var dbRecord = (version: 2, title: "Exercism")
updateVersion(&dbRecord)

// dbRecord is now (3, "Exercism")
```

~~~~exercism/warning
Hay un par de reglas adicionales que conviene tener en cuenta sobre los parámetros de entrada y salida.

1  Dentro de una función con parámetros de entrada y salida, no puedes hacer referencia a la variable que se pasó como parámetro de entrada y salida.
2. La misma variable no se puede pasar como varios parámetros de entrada y salida en la misma función.
   Por ejemplo, `inoutFunc(&mutVar, &mutVar)` genera un error del compilador.
~~~~

## Funciones anidadas

En Swift, puedes definir [funciones dentro de otras funciones][nested-functions].
Estas se conocen como **funciones anidadas**.

Las funciones anidadas suelen usarse como funciones auxiliares privadas que realizan tareas concretas para la función que las contiene, sin saturar el ámbito externo:

```swift
func makeNumber(_ number: Int) -> Int {
    func double(_ x: Int) -> Int {
        x * 2
    }

    func increment(_ x: Int) -> Int {
        x + 1
    }

    return number.isMultiple(of: 2) ? increment(double(number)) : double(number)
}

print(makeNumber(3)) // Prints 6
print(makeNumber(4)) // Prints 9
```

Las funciones anidadas se comportan como funciones estándar, pero su visibilidad se limita al cuerpo de la función que las contiene.
