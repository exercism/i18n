# Acerca de

[`Rational numbers`][rational] son fracciones con un numerador entero dividido por un denominador entero.

Por ejemplo, podemos guardar `2//3` como una fracción exacta en lugar del valor aproximado `Float64` `0.6666...`

La ventaja es que (excepto en el caso extremo de [desbordamiento de enteros][integer-overflow]) un número racional se mantendrá exacto, y así se evitan los errores de redondeo que a menudo son inevitables con los números de punto flotante.

Encontrarás más detalles en la [página del manual][julia-rational] de Julia.

Los números racionales son un tipo numérico bastante simple y su objetivo es funcionar tal como esperarías.
Como han sido un tipo estándar en Julia desde las primeras versiones, la mayoría de las funciones los aceptan como argumento igual que lo hacen con los enteros y los valores de punto flotante.

## Cómo crear números racionales

Crearlos es tan simple como usar `//` entre dos enteros.

```julia-repl
julia> 3//4
3//4

julia> a = 3; b = 4;

julia> a//b
3//4
```

Los factores comunes se eliminan automáticamente, lo que convierte la fracción a su [«mínima expresión»][lowest-terms]: los enteros más pequeños que representan con exactitud la fracción, y con un denominador no negativo.

```julia-repl
julia> 5//15
1//3

julia> 5//-15
-1//3
```

Los resultados infinitos se aceptan, aunque no [`NaN`][NaN].

```julia-repl
julia> 1//0
1//0

julia> float(1//0)
Inf

julia> 0//0
ERROR: ArgumentError: invalid rational: zero(Int64)//zero(Int64)
```

## Aritmética con números racionales

Los [`arithmetic operators`][operators] habituales `+ - * / ^ %` funcionan con los racionales, básicamente igual que con otros tipos numéricos.

Se pueden incluir enteros y otros `Rational` y el resultado es un `Rational`.
Si incluyes un `float` en la expresión, el resultado es de tipo `float`, con la consiguiente (posible) pérdida de precisión.

Si quieres un `float`, simplemente usa la función `float()` para convertir un racional.
Es bastante normal usar números racionales para conservar la precisión a lo largo de un cálculo largo y luego convertir a un número de punto flotante al final.

```julia-repl
julia> 3//4 + 1//3  # addition
13//12

julia> 3//4 * 1//3  # multiplication
1//4

julia> 3//4 / 1//3  # division
9//4

julia> 3//4 ^ 2  # exponentiation
3//16

julia> 3//4 + 5  # rational and int => rational
23//4

julia> 3//4 + 5.3  # rational and float => float
6.05

julia> float(3//4)  # casting
0.75
```

Los racionales también se pueden combinar con los [números complejos][complex].
Los números complejos se explican en un [concepto aparte][complex-concept].

## Otras operaciones

En Julia, los números racionales son simplemente números.
El compilador normalmente convierte los tipos cuando es necesario.

Sin embargo, ten en cuenta que las comparaciones funcionan para fracciones con una representación decimal finita:

```julia-repl
julia> 3//4 == 0.75
true

julia> 3//4 < 0.74
false
```

Pero, en caso contrario, un `Rational` se debe convertir a un `Float` para poder compararlos:

```julia-repl
julia> 1//3 == 1/3
false

julia> float(1//3) == 1/3
true
```

Las funciones matemáticas aceptan racionales como argumento, pero pueden dar un resultado de punto flotante:

```julia-repl
julia> sqrt(9//16)
0.75
```
