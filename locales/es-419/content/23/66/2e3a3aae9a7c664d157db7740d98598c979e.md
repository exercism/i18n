# Tests

## Línea de comandos

Puedes usar el siguiente comando para ejecutar los tests desde la línea de comandos:

```bash
swipl -f <exercise>.pl -s <exercise>_tests.plt -g run_tests,halt -t 'halt(1)'
```

Reemplaza `<exercise>` con el nombre del ejercicio que estás implementando.

## Modo interactivo

Para ejecutar Prolog de forma interactiva, primero ejecuta:

```bash
swipl
```

Después de que se inicie la consola de Prolog, carga tu implementación y ejecuta los tests con:

```
?- ["<exercise>.pl"].
?- ["<exercise>_tests.plt"].
?- run_tests.
```

Reemplaza `<exercise>` con el nombre del ejercicio que estás implementando.

### Recargar cambios

Una vez que hayas cargado los archivos anteriores, puedes aplicar cualquier cambio que hayas hecho ejecutando:

```
?- make.
```

## Tests omitidos

Cuando empiezas un ejercicio, solo se ejecuta el primer test. Los demás se han omitido al agregar `condition(pending)` a la meta `test`. Una vez que el primer test pase, deja de omitir el siguiente test cambiando `pending` en `condition(pending)` por `true`. Repite esto con cada test hasta que todos se ejecuten y pasen.

### Línea de comandos

Agrega el argumento `-- --all` al final del comando para ejecutar también los tests que estén pendientes:

```bash
swipl -f <exercise>.pl -s <exercise>_tests.plt -g run_tests,halt -t 'halt(1)' -- --all
```
