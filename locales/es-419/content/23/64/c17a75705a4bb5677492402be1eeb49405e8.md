# Acerca de

`jq` es una herramienta para analizar y transformar datos JSON.
`jq` es como `sed` para datos JSON: puedes usarlo para cortar, filtrar, mapear y transformar datos estructurados con la misma facilidad con la que `sed`, `awk`, `grep` y compañía te permiten jugar con texto.

`jq` es un lenguaje de programación funcional con tipado dinámico.
Todos los valores son inmutables.

Los programas de `jq` se componen de canalizaciones de «filtros»: cada filtro toma un solo elemento como argumento, actúa sobre él y produce cero o más elementos transformados.
A un «filtro» también se le puede llamar «expresión».

Lo que produce una expresión se puede pasar a otra usando el operador `|`.
`expressionA | expressionB` aplica `expressionA` a algún argumento y luego ejecuta `expressionB` repetidamente para cada una de las salidas de `expressionA`.

El argumento de una expresión se puede referir explícitamente como `.`.
Una expresión que suma `1` a su argumento se escribe así: `. + 1` (o `1 + .`).

## `jq` (el programa) frente a `jq` (el lenguaje)

`jq` es un programa que puedes instalar como paquete en diversos sistemas operativos, o compilar desde el código fuente (está escrito en C).
Tiene varias [opciones de línea de comandos][cli-options] útiles, y es bastante rápido.

El programa `jq` también implementa un _lenguaje_ que permite manipulaciones arbitrariamente complejas de los datos que recibe.

Este track de Exercism se centrará en el lenguaje.
Verás el uso del programa `jq` en las pruebas.

## JSON

De [json.org][json]:

> JSON (JavaScript Object Notation) es un formato ligero para el intercambio de datos.
> Es fácil de leer y escribir para las personas.
> Es fácil de analizar y generar para las máquinas.
> Se basa en un subconjunto del JavaScript Programming Language Standard ECMA-262 3rd Edition - December 1999.
> JSON es un formato de texto completamente independiente del lenguaje, pero usa convenciones que resultan familiares para quienes programan en la familia de lenguajes de C, incluidos C, C++, C#, Java, JavaScript, Perl, Python y muchos otros.
> Estas propiedades hacen de JSON un lenguaje ideal para el intercambio de datos.

Este track trata sobre `jq`, no sobre JSON.
Asumiremos que ya conoces la [sintaxis y los tipos de datos de JSON][wiki-json].
