# Acerca de las listas

Las **listas** son la colección de secuencias ordenadas en Java.
A diferencia de los arrays, una [`List`](https://docs.oracle.com/en/java/javase/11/docs/api/java.base/java/util/List.html) puede crecer en tamaño para acomodar cualquier cantidad de elementos.
Una implementación estándar es `ArrayList`, que se apoya en un array redimensionable.
Otra implementación estándar es la clase `LinkedList`, que se apoya en una lista doblemente enlazada.

Las `List` pueden estar vacías o contener cualquier cantidad de elementos (incluidos los duplicados).
Las `List` son una **interfaz genérica** que se tipa para indicar qué tipo de objetos puede contener.
Por ejemplo:

```java
List<String> emptyListOfStrings = List.of();
List<Integer> singleInteger = List.of(1);
List<Boolean> threeBooleans = List.of(true, false, true);
List<Object> listWithMultipleTypes = List.of("hello", 1, true);
```

Las `List` tienen varios métodos útiles para agregar, eliminar, obtener y comprobar si un elemento está presente:

```java
List<Character> vowels = new ArrayList<>(List.of('a', 'e', 'i', 'o', 'i', 'e', 'a'));
int startingSize = vowels.size(); // 7
vowels.add('u'); // vowels is now ['a', 'e', 'i', 'o', 'i', 'e', 'a', 'u']
char a = vowels.get(0); // 'a'
boolean hadI = vowels.remove('i'); // true and vowels is now ['a', 'e', 'o', 'i', 'e', 'a', 'u']
boolean hasI = vowels.contains('i'); // true (still have one more left)
```

La clase [`Collections`](https://docs.oracle.com/en/java/javase/11/docs/api/java.base/java/util/Collections.html) también ofrece algunas utilidades prácticas para trabajar con colecciones como `List`:

```java
List<Integer> numbers = new ArrayList<>(List.of(1, 5, 3, 2, 4));
Collections.sort(numbers); // [1, 2, 3, 4, 5]
Collections.reverse(numbers); // [5, 4, 3, 2, 1]
Collections.fill(numbers, 42); // [42, 42, 42, 42, 42]
List<Integer> fiveNines = Collections.nCopies(5, 9); // [9, 9, 9, 9, 9]
```
