# Introducción

[Los arrays][arrays-concept] tienen métodos integrados para analizar el contenido del array.
La mayoría de estos métodos reciben como argumento una función que devuelve true o false.
Esa función se llama un [`predicate`][predicate_in_programming].

Estos métodos integrados están pensados para usarse _en lugar de un bucle `for`_ o del método integrado `forEach`:

Ejemplo de análisis con un bucle `for`:

```javascript
const numbers = [1, 'two', 3, 'four'];
for (var i = 0; i < numbers.length; i++) {
  if (numbers[i] === 'two') {
    return i;
  }
}
// => 1
```

Ejemplo de análisis con un método integrado:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.indexOf('two');
// => 1
```

A continuación se muestran otros métodos integrados útiles que tienes disponibles para analizar un array. Consulta [MDN][mdn-array-methods] para ver una lista completa de los métodos de array.

## `includes`

> El método includes() determina si un array incluye un determinado valor entre sus elementos, y devuelve true o false según corresponda. [^1]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.includes(1);
// => true
numbers.includes('one');
// => false
```

## `every`

> El método every() comprueba si todos los elementos del array pasan la prueba que implementa la función proporcionada. Devuelve un valor Boolean. [^2]

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.every((num) => num % 2 !== 0);
// => true
```

## `some`

> El método some() comprueba si al menos un elemento del array pasa la prueba que implementa la función proporcionada. [^3]

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.some((num) => num % 2 !== 0);
// => true
```

## `find`

> El método find() devuelve el valor del primer elemento del array proporcionado que satisface la función de prueba proporcionada. Si ningún valor satisface la función de prueba, se devuelve undefined. [^4]

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.find((num) => num < 5);
// => 1
```

## `findIndex`

> El método findIndex() devuelve el índice del primer elemento del array que satisface la función de prueba proporcionada. De lo contrario, devuelve -1, lo que indica que ningún elemento pasó la prueba. [^5]

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.findIndex((num) => num > 7);
// => 4
numbers.findIndex((num) => num > 9);
// => -1
```
