# Pistas

## General

- El [paquete `strings`][strings-package] contiene muchas funciones de `string` útiles.
- El paquete `strings` se debe importar antes de poder usarlo.
- Para llamar a funciones del paquete `strings`, antepón `strings.` al nombre de la función.

## 1. Crea el mensaje de bienvenida

- Los `string` se pueden concatenar con el operador `+`.
- Hay una función para [convertir un `string` a mayúsculas][to-upper].

## 2. Agrega un borde llamativo

- Hay una función para [crear un `string` con un carácter específico repetido varias veces][repeat].
- Un salto de línea es un [carácter de escape][escape-characters] especial.

## 3. Limpia los mensajes de marketing antiguos

- Hay una función para [reemplazar cadenas dentro de un `string`][replace-all].
- Hay una función para [quitar los espacios al principio y al final de un `string`][trim-space].
