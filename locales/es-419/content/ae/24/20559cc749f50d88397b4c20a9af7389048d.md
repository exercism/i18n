# Anexo a las instrucciones

## Nota

Si estás editando este archivo en un editor de texto y no en Pharo, revisa la sección [Primeros pasos](https://www.exercism.org/tracks/pharo/installation).

Aunque puedes usar un editor de texto, el IDE de Pharo es en parte lo que hace que este lenguaje sea tan especial.

En Pharo puedes ejecutar código (incluidos los tests) con métodos que tienen errores y clases que no existen.
Cuando la VM se encuentra con código roto, abre un depurador que te permite explorar el problema un poco mejor.

Luego tienes la opción de presionar el botón Create para agregar una clase o un método que falte, y también de corregir cualquier código que cause un error.
Cuando lo hagas, el depurador retrocederá y te dejará reanudar la ejecución con tus nuevos cambios.

Intenta hacerlo con tu ejemplo HelloWorld, simplemente ejecutando cualquiera de los métodos de test unitario.
