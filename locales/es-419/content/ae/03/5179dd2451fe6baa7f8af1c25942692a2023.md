# Introducción

Los iteradores en Haxe se usan para iterar sobre un valor con un bucle `for`. Hay dos tipos de iteradores:

- `Iterator`, que itera sobre un valor.
- Los datos `Iterable`, que hacen posible iterar sobre un tipo de datos.

Ambos conceptos están representados por `Iterator<T>` e `Iterable<T>`:

```haxe
typedef Iterator<T> = {
  function hasNext():Bool;
  function next():T;
}

typedef Iterable<T> = {
  function iterator():Iterator<T>;
}
```

Cualquier clase que unifique con uno de estos tipos se puede iterar con un bucle `for`. Si una clase define los métodos `hasNext` y `next`, se considera un iterador; en caso contrario, si define un método `iterator`, se considera un tipo iterable.
