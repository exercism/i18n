Los [Boolean][booleans] en Haxe se representan con el tipo `Bool`, cuyos valores pueden ser `true` o `false`.

Haxe admite tres [operadores booleanos][operators]: `!` (NOT unario), `&&` (AND binario) y `||` (OR binario).

Las expresiones booleanas compuestas (`&&` y `||`) usan una evaluación _de cortocircuito_, en la que las expresiones se evalúan de izquierda a derecha, pero solo hasta donde sea necesario. Esto es importante en casos como el siguiente:

```haxe
object != null && object.field == x
```

La primera comprobación booleana garantiza que solo se acceda a `object.field` si `object` no es `null`, lo que protege contra un error en tiempo de ejecución.

Los tres operadores booleanos tienen distinta [precedencia][precedence] y se evalúan en este orden: `!` -> `&&` -> `||`.

Encerrar expresiones entre paréntesis `()` permite anular estas reglas de precedencia, ya que los paréntesis tienen una precedencia mayor.

```haxe
!true && false   // => false
!(true && false) // => true
```
