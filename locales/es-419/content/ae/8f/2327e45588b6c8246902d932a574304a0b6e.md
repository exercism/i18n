# Anexo a las instrucciones

## Pruebas lentas

Una o varias de las pruebas de este ejercicio están etiquetadas como `:slow`, porque pueden tardar mucho en terminar. Por esta razón, el ejecutor de pruebas automatizado no las ejecutará en la plataforma. Si vas a resolver este ejercicio directamente en la plataforma, en el editor web, quizás te convenga descargar el ejercicio a tu computadora. Así podrás ejecutar todas las pruebas y comprobar la eficiencia de tu solución.
