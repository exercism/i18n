# Instrucciones

En este ejercicio, vas a administrar un sistema de inventario.

El inventario debe organizarse por el nombre del elemento y debe llevar un registro del número de elementos disponibles.

Tendrás que encargarte de agregar elementos a un inventario.
Cada vez que un elemento aparece en un vector dado, la cantidad de ese elemento debe aumentar en `1` en el inventario.
También tendrás que encargarte de eliminar elementos de un inventario disminuyendo las cantidades en `1` cuando se solicite.

Por último, tendrás que implementar una función que devuelva todos los pares clave-valor de un inventario dado como un `vector` de `pair`s.

~~~~exercism/note
Las pruebas de este ejercicio son agnósticas a la mutación, pero los nombres de las funciones indican que no deberían mutar.
Si quieres usar las funciones de la introducción sin mutar la entrada, la función `copy()` te será útil.
~~~~

## 1. Crea un inventario a partir de un vector

Implementa la función `create_inventory(<input vector>)` que crea un «inventario» a partir de un vector de elementos.
Debe devolver un `dict` que contenga el nombre de cada elemento junto con su cantidad respectiva.

```julia-repl
julia> create_inventory(["coal", "wood", "wood", "diamond", "diamond", "diamond"])
Dict("coal" => 1, "wood" => 2, "diamond" => 3)
```

## 2. Agrega elementos de un vector a un diccionario existente

Implementa la función `add_items(<inventory dict>, <item vector>)` que agrega un vector de elementos al inventario que recibe:

```julia-repl
julia> add_items(Dict("coal" => 1), ["wood", "iron", "coal", "wood"])
Dict("coal" => 2, "wood" => 2, "iron" => 1)
```

## 3. Decrementa elementos del inventario

Implementa la función `decrement_items(<inventory dict>, <items vector>)` que recibe un `vector` de elementos.
Tu función debe restar `1` a la cantidad de un elemento por cada vez que ese elemento aparece en el `vector`:

```julia-repl
julia> decrement_items(Dict("coal" => 3, "diamond" => 1, "iron" => 5), ["diamond", "coal", "iron", "iron"])
Dict("coal" => 2, "diamond" => 0, "iron" => 3)
```

No se debe permitir que las cantidades de los elementos del inventario bajen de 0.
Si el número de veces que un elemento aparece en el `vector` supera la cantidad disponible, la cantidad indicada para ese elemento debe permanecer en 0.
Las solicitudes adicionales para quitar cantidades deben ignorarse una vez que la cantidad llegue a cero.

```julia-repl
julia> decrement_items(Dict("coal" => 2, "wood" => 1, "diamond" => 2), ["coal", "coal", "wood", "wood", "diamond"])
Dict("coal" => 0, "wood" => 0, "diamond" => 1)
```

## 4. Elimina por completo una entrada del inventario

Implementa la función `remove_item(<inventory dict>, <item>)` que elimina por completo un elemento y su cantidad de un inventario:

```julia-repl
julia> remove_item!(Dict("coal" => 2, "wood" => 1, "diamond" => 2), "coal")
Dict("wood" => 1, "diamond" => 2)
```

Si el elemento no se encuentra en el inventario, la función debe devolver el inventario original sin cambios.

```julia-repl
julia> remove_item(Dict("coal" => 2, "wood" => 1, "diamond" => 2), "gold")
Dict("coal" => 2, "wood" => 1, "diamond" => 2)
```

## 5. Devuelve todo el contenido del inventario

Implementa la función `list_inventory(<inventory dict>)` que recibe un inventario y devuelve un vector de pares `(item, quantity)`.

El vector solo debe incluir los elementos _disponibles_ (_con una cantidad mayor que cero_) y debe estar ordenado alfabéticamente por elemento:

```julia-repl
julia> list_inventory(Dict("coal" => 7, "wood" => 11, "diamond" => 2, "iron" => 7, "silver" => 0))
["coal" => 7, "diamond" => 2, "iron" => 7, "wood" => 11]
```
