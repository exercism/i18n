# Introducción

Los condicionales son sentencias que ejecutan código distinto según si una condición es `true` o `false`.

Una sentencia `if` ejecuta su cuerpo solo cuando su condición es `true`.
Go no tiene el concepto de valores «truthy» o «falsy», así que la condición debe ser de tipo `bool`.
Expresiones como `if mySlice { ... }` o `if 1 { ... }` son errores de compilación.

```go
func describe(val string) string {
    if val == "val" {
        return "was val"
    }
    return "was not val"
}
```

Usa `else if` para comprobar condiciones adicionales, y `else` como respaldo si ninguna se cumple.
Las condiciones se evalúan de arriba hacia abajo, y solo se ejecuta la primera rama cuya condición sea verdadera.

```go
number := 0
result := "This number is "

if number > 0 {
    result += "positive"
} else if number < 0 {
    result += "negative"
} else {
    result += "zero"
}
```

Una sentencia `if` también puede incluir una sentencia corta de inicialización.
Las variables que se declaran de esta manera solo tienen ámbito dentro de toda la cadena `if`/`else`.

```go
num := 7
if v := 2 * num; v > 10 {
    fmt.Println(v)
} else {
    fmt.Println(num)
}
// Output: 14
```
