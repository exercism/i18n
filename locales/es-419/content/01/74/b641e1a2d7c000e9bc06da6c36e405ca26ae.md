# Usa recursión de cola

El propósito de este ejercicio es enseñar la recursión de cola. Resuélvelo sin usar funciones recursivas que no sean de cola.

Funciones recursivas de cola encontradas en tu solución: %{tail_call_recursive_functions}. Otras funciones recursivas encontradas en tu solución: %{non_tail_call_recursive_functions}.

Recuerda que la recursión de cola ocurre cuando la _última_ expresión que evalúa la función es una llamada a sí misma.

```elixir
# this is tail call recursion,
# the last expression is a call to `do_encode`
defp do_encode([n | rest], acc) do
  do_encode(rest, <<acc::bitstring, encode_nucleotide(n)::4>>)
end

# this is not tail call recursion,
# the last expression is a call to `<<>>`
def encode([head | tail]) do
  <<encode_nucleotide(head)::4, encode(tail)::bitstring>>
end
```
