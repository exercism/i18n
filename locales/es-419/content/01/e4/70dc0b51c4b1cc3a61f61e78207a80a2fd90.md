# Introducción

## Strings

En F#, un `string`, es decir, una _cadena_, es un objeto que representa texto inmutable como una secuencia de caracteres Unicode (letras, dígitos, puntuación, etc.) y se define así:

```fsharp
let fruit = "Apple"
```

Para manipular un string, puedes llamar a sus métodos o usar las funciones del módulo `String`. Una vez que se ha construido un string, su valor nunca puede cambiar. Cualquier método o función que parezca modificar un string en realidad devuelve un string nuevo.

Los strings se pueden concatenar o formatear de varias maneras diferentes.
* Puedes usar el operador `+` para concatenar:
```fsharp
let sentence = "Apple" + " is a type of fruit."
```
* Puedes usar la función `sprintf` para dar formato al texto, donde tienes marcadores de posición en un texto de formato (`%s` para un `string`) y proporcionas los valores como argumentos:
```fsharp
let sentence = sprintf "%s is a type of %s." "Apple" "fruit"
```
