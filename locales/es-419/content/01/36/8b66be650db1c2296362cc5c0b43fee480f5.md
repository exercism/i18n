# Debug

Puedes usar [Debug.log](https://package.elm-lang.org/packages/elm/core/latest/Debug#log) para adjuntar mensajes a las pruebas que fallan, así:

```elm
hoursToSeconds : Int -> Int
hoursToSeconds hours =
    let
        secondsInOneHour =
            Debug.log "secondsInOneHour" (60 * 60)
    in
    hours * secondsInOneHour
```

En una prueba que falla, el log adjunto será `secondsInOneHour: 3600`.

Hay una advertencia: las constantes de nivel superior se evalúan solo una vez antes de que las pruebas empiecen a ejecutarse, por lo que las pruebas no pueden capturar sus mensajes de log. Por ejemplo:

```elm
secondsInOneHour : Int
secondsInOneHour =
    Debug.log "secondsInOneHour" (60 * 60)
```

no registrará nada durante las pruebas porque la variable de JavaScript asociada a `secondsInOneHour` ya se ha evaluado al valor 3600.
