# Introducción

Un número de punto flotante es un número con cero o más dígitos detrás del separador decimal. Algunos ejemplos son `-2.4`, `0.1`, `3.14`, `16.984025` y `1024.0`.

F# tiene tres tipos de punto flotante:

- `single`: 4 bytes (~6-9 dígitos de precisión). Se escribe como `2.45f`.
- `float`: 8 bytes (~15-17 dígitos de precisión). Este es el tipo más común. Se escribe como `2.45`.
- `decimal`: 16 bytes (28-29 dígitos de precisión). Normalmente se usa cuando se trabaja con datos monetarios, ya que su precisión genera menos errores de redondeo. Se escribe como `2.45m`.

Distintos tipos de punto flotante pueden almacenar distintas cantidades de dígitos después del separador decimal; a esto se le llama su precisión. Esto significa que si intentas almacenar PI en un `single`, solo se almacenarán los primeros 6 a 9 dígitos (y el último dígito se redondea).
