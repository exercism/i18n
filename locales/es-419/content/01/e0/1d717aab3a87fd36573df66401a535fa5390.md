# Anexo a las instrucciones

## Formato de salida

Devuelve la letra como un string terminado en null.

## Registros

| Registro | Uso          | Tipo    | Descripción                   |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | entrada      | entero  | verso inicial                 |
| `$a1`    | entrada      | entero  | verso final                   |
| `$a2`    | entrada/salida | dirección | string de salida terminado en null |
| `$t0-9`  | temporal     | cualquiera | para almacenamiento temporal |
