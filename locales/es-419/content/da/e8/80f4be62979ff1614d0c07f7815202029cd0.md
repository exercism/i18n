# Introducción

Las constantes son valores que se establecen en tiempo de compilación y no se pueden reasignar.
Usa la palabra clave `const` para declarar una sola constante:

```go
const greeting = "hello"
```

Se pueden declarar varias constantes en un bloque.
Dentro de un bloque, una constante sin un valor explícito repite la expresión anterior:

```go
const (
    greeting    = "hello"
    buffSize    = 4096
    chunkSize   // 4096
)
```

Por lo general, las constantes se declaran a nivel de paquete, aunque también se pueden declarar dentro de una función.

## Constantes con tipo y sin tipo

Si declaras una constante sin especificar un tipo, esta queda sin tipo.
Una constante sin tipo no tiene un tipo fijo; su valor determina con qué tipos es compatible.
Siempre que el valor subyacente sea compatible, el compilador la convertirá al tipo requerido en cada uso:

```go
const numA = 2

math.Sqrt(numA)  // numA is treated as float64 here
var numB int = numA  // numA is treated as int here
```

Una constante con tipo fija el tipo en el momento de la declaración:

```go
const num int = 2

math.Sqrt(num)  // compile error because a float is expected
```

## Qué puede ser una constante

Las constantes solo pueden contener Boolean, números, strings y runes.
Como los valores se establecen en tiempo de compilación, el resultado de una llamada a una función no se puede usar para una constante.

```go
const s = math.Sqrt(4)  // compile error because the value isn't known at compile time
```

## Iota

Dentro de un bloque de constantes, `iota` representa la posición de una constante dentro del bloque:

```go
const (
    Sunday    = iota // 0
    Monday           // 1
    Tuesday          // 2
    Wednesday        // 3
)
```

Cada constante después de la primera hereda la misma expresión, y `iota` se incrementa en uno.

`iota` también funciona en expresiones.

```go
const (
    _  = iota             // position 0: value discarded
    KB = 1 << (10 * iota) // position 1: 1 << 10 = 1024
    MB                    // position 2: 1 << 20 = 1048576
    GB                    // position 3: 1 << 30 = 1073741824
)
```
