# Instrucciones

En este ejercicio vas a escribir un poco más de código relacionado con la preparación y la cocción de esa magnífica lasaña de tu libro de cocina favorito.

Tienes cuatro tareas.
La primera está relacionada con la cocción en sí, y las otras tres tienen que ver con la preparación perfecta.

## 1. Estima el tiempo de preparación

Para la próxima lasaña que prepares, quieres asegurarte de reservar suficiente tiempo para poder disfrutar de la cocción.
Ya planeaste qué capas tendrá tu lasaña.
Ahora quieres estimar cuánto tardará la preparación según eso.

Implementa una función `PreparationTime` que acepte un slice de capas como un `[]string` y el tiempo de preparación promedio por capa en minutos como un `int`.
La función debe devolver la estimación del tiempo total de preparación según la cantidad de capas, como un `int`.
Go no tiene valores predeterminados para las funciones.
Si el tiempo de preparación promedio se pasa como `0` (el valor inicial predeterminado de un `int`), entonces se debe usar el valor predeterminado de `2`.

```go
layers := []string{"sauce", "noodles", "sauce", "meat", "mozzarella", "noodles"}
PreparationTime(layers, 3)
// => 18
PreparationTime(layers, 0)
// => 12
```

## 2. Calcula las cantidades de fideos y salsa necesarias

Además de reservar el tiempo, también quieres asegurarte de tener suficiente salsa y fideos para cocinar la lasaña de tus sueños.
Por cada capa de fideos en tu lasaña, necesitarás 50 gramos de fideos.
Por cada capa de salsa en tu lasaña, necesitarás 0,2 litros de salsa.

Define la función `Quantities` que recibe un slice de capas como parámetro, de tipo `[]string`.
Luego, la función determinará la cantidad de fideos y salsa necesarios para preparar tu comida.
El resultado debe devolverse como dos valores: `noodles` como un `int` y `sauce` como un `float64`.

```go
Quantities([]string{"sauce", "noodles", "sauce", "meat", "mozzarella", "noodles"})
// => 100, 0.4
```

## 3. Agrega el ingrediente secreto

Hace un tiempo visitaste a un amigo y comiste lasaña en su casa.
Estaba increíble y tenía algo especial.
Tu amigo te envió la lista de ingredientes y te dijo que el último elemento de la lista es el «ingrediente secreto» que hizo que la comida fuera tan especial.
Ahora quieres agregar ese ingrediente secreto también a tu receta.

Escribe una función `AddSecretIngredient` que acepte dos slices de ingredientes de tipo `[]string` como parámetros.
El primer parámetro es la lista que te envió tu amigo, y el segundo es la lista de ingredientes de tu propia receta.
El último elemento de tu lista de ingredientes siempre es `"?"`.
La función debe reemplazarlo con el último elemento de la lista de tu amigo.
**Nota:** `AddSecretIngredient` no devuelve nada; debes modificar la lista de tus ingredientes directamente.
La lista con los ingredientes de tu amigo **no** debe modificarse.
Además, como el `slice` se pasa a una función como un puntero, los cambios a los dos argumentos de tipo `[]string` que se pasan a `AddSecretIngredient` se modificarán directamente.

```go
friendsList := []string{"noodles", "sauce", "mozzarella", "kampot pepper"}
myList := []string{"noodles", "meat", "sauce", "mozzarella","?"}

AddSecretIngredient(friendsList, myList)
// myList => []string{"noodles", "meat", "sauce", "mozzarella", "kampot pepper"}
```

## 4. Escala la receta

Las cantidades que figuran en tu libro de cocina solo alcanzan para dos porciones de lasaña.
Como la próxima vez quieres cocinar para más personas, quieres calcular las cantidades para diferentes números de porciones.

Implementa una función `ScaleRecipe` que recibe dos parámetros.

- Un slice de cantidades `float64` necesarias para 2 porciones.
- La cantidad de porciones que quieres cocinar.

La función debe devolver un slice de `float64` con las cantidades necesarias para la cantidad de porciones deseada.
Sin embargo, quieres conservar la receta original.
Esto significa que el argumento `quantities` no debe modificarse en esta función.

```go
quantities := []float64{ 1.2, 3.6, 10.5 }
scaledQuantities := ScaleRecipe(quantities, 4)
// => []float64{ 2.4, 7.2, 21 }
```
