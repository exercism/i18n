# Instalación

Vas a necesitar acceso a una base de datos Oracle montada. Si todavía no tienes una instalada, aquí tienes algunas opciones:
* consigue un espacio de trabajo gratis en https://apex.oracle.com
* descarga VirtualBox de Oracle y ejecuta una de las imágenes disponibles gratuitamente; al momento de escribir esto, la más fácil para empezar podría ser, al momento de escribir esto, _Database App Development VM_. La imagen es bastante grande...
* descarga e instala una versión de Oracle DB. Las licencias de desarrollador son gratis.
