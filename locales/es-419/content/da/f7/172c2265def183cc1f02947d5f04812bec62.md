# Acerca de

El `<iota>` de Factor produce una secuencia *virtual* de los enteros
`0, 1, …, n-1`. Recorrerla con `map` da como resultado una secuencia
tabulada en la que cada elemento es una función de su posición:

```factor
USING: math sequences ;

5 <iota> [ sq ] map .         ! => { 0 1 4 9 16 }
8 <iota> [ 1 + ] map .        ! => { 1 2 3 4 5 6 7 8 }
```

Dos piezas te permiten convertir una secuencia de códigos enteros en
un string:

| palabra   | papel                                                   |
|-----------|---------------------------------------------------------|
| `CHAR:`   | literal que se evalúa al analizar la sintaxis y apila el punto de código de un carácter |
| `>string` | convierte una secuencia de puntos de código en un string |

Juntas, forman la forma idiomática estándar para construir una fila de
caracteres indexada por posición:

```factor
USING: kernel math sequences strings ;

10 <iota> [ 2 mod zero? [ CHAR: O ] [ CHAR: . ] if ] map >string .
! => "O.O.O.O.O."
```

Elegir el carácter con `if` (o `?`) dentro de la quotation mantiene la
decisión de cada posición cerca del índice del que depende.
