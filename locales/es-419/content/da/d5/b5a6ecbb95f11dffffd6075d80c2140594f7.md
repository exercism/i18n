# Instrucciones

La máquina básica Take-A-Number se vendía muy bien, pero algunos usuarios se quejaban de su falta de funcionalidades avanzadas en comparación con otros modelos disponibles en el mercado.

El fabricante escuchó los comentarios de los usuarios y decidió lanzar un modelo de lujo con más funcionalidades, y una vez más te encargaron escribir el software de esta máquina.

Las nuevas funcionalidades que se agregaron al modelo de lujo incluyen:
- Llevar un registro de los números que están actualmente en la cola.
- Establecer el número mínimo y máximo. Esto permitirá usar varias máquinas Take-A-Number de lujo para poner en cola a los clientes de diferentes departamentos de la misma instalación, y distinguir los departamentos por el rango de números.
- Permitir que ciertos números se salten la cola para dar un servicio prioritario a las mujeres embarazadas y a las personas mayores.
- Apagado automático para evitar que la máquina se quede encendida todo el fin de semana por accidente y desperdicie energía.

La lógica de negocio de la máquina ya la implementó tu colega y se encuentra en el módulo `TakeANumberDeluxe.State`. Ahora tu tarea es envolverla en un `GenServer`.

## 1. Iniciar la máquina

Usa el comportamiento `GenServer` en el módulo `TakeANumberDeluxe`.

Implementa la función `start_link/1` y el callback de `GenServer` necesario.

El argumento que se le pasa a `start_link/1` es una lista de palabras clave. Contiene las claves `:min_number` y `:max_number`. Los valores de esas claves se deben pasar a la función `TakeANumberDeluxe.State.new/2`.

Si `TakeANumberDeluxe.State.new/2` devuelve una tupla `{:ok, state}`, la máquina debe arrancar, usando el estado devuelto como su estado. Si en cambio devuelve una tupla `{:error, error}`, la máquina debe detenerse, usando el error devuelto como razón para detenerse.

```elixir
TakeANumberDeluxe.start_link(min_number: 1, max_number: 9)
# => {:ok, #PID<0.174.0>}

TakeANumberDeluxe.start_link(min_number: 9, max_number: 1)
# => {:error, :invalid_configuration}
```

Quizás hayas notado que la función `TakeANumberDeluxe.State.new/2` también recibe un tercer argumento opcional, `auto_shutdown_timeout`. Lo usaremos en el último paso de este ejercicio.

## 2. Reportar el estado de la máquina

Implementa la función `report_state/1` y el callback de `GenServer` necesario. La máquina debe responder a quien llama con su estado actual.

```elixir
{:ok, machine} = TakeANumberDeluxe.start_link(min_number: 1, max_number: 10)
TakeANumberDeluxe.report_state(machine)
# => %TakeANumberDeluxe.State{
#      max_number: 10,
#      min_number: 1,
#      queue: %TakeANumberDeluxe.Queue{in: [], out: []},
#      auto_shutdown_timeout: :infinity,
#    }
```

## 3. Encolar números nuevos

Implementa la función `queue_new_number/1` y el callback de `GenServer` necesario.

Debe llamar a la función `TakeANumberDeluxe.State.queue_new_number/1` con el estado actual de la máquina.

Si `TakeANumberDeluxe.State.queue_new_number/1` devuelve una tupla `{:ok, new_number, new_state}`, la máquina debe responder a quien llama con el número nuevo y establecer el estado nuevo como su estado. Si en cambio devuelve una tupla `{:error, error}`, la máquina debe responder a quien llama con el error y no cambiar su estado.

```elixir
{:ok, machine} = TakeANumberDeluxe.start_link(min_number: 1, max_number: 2)
TakeANumberDeluxe.queue_new_number(machine)
# => {:ok, 1}

TakeANumberDeluxe.queue_new_number(machine)
# => {:ok, 2}

TakeANumberDeluxe.queue_new_number(machine)
# => {:error, :all_possible_numbers_are_in_use}
```

## 4. Atender el siguiente número en la cola

Implementa la función `serve_next_queued_number/2` y el callback de `GenServer` necesario.

Debe llamar a la función `TakeANumberDeluxe.State.serve_next_queued_number/2` con el estado actual de la máquina y su segundo argumento opcional, `priority_number`.

Si `TakeANumberDeluxe.State.serve_next_queued_number/2` devuelve una tupla `{:ok, next_number, new_state}`, la máquina debe responder a quien llama con el número siguiente y establecer el estado nuevo como su estado. Si en cambio devuelve una tupla `{:error, error}`, la máquina debe responder a quien llama con el error y no cambiar su estado.

```elixir
{:ok, machine} = TakeANumberDeluxe.start_link(min_number: 1, max_number: 10)
TakeANumberDeluxe.queue_new_number(machine)
# => {:ok, 1}

TakeANumberDeluxe.serve_next_queued_number(machine)
# => {:ok, 1}

TakeANumberDeluxe.serve_next_queued_number(machine)
# => {:error, :empty_queue}
```

## 5. Reiniciar el estado

Implementa la función `reset_state/1` y el callback de `GenServer` necesario.

Debe llamar a la función `TakeANumberDeluxe.State.new/2` para crear un estado nuevo usando el `min_number` y el `max_number` del estado actual. La máquina debe establecer el estado nuevo como su estado. No debe responder a quien llama.

```elixir
{:ok, machine} = TakeANumberDeluxe.start_link(min_number: 1, max_number: 10)

TakeANumberDeluxe.reset_state(machine)
# => :ok
```

## 6. Implementar el apagado automático

Modifica el arranque de la máquina. Debe leer el valor de la clave `:auto_shutdown_timeout` en la lista de palabras clave que se pasa como `init_arg` y pasarlo como tercer argumento a `TakeANumberDeluxe.State.new/3`. Usa el valor predeterminado `:infinity` si no se proporcionó `:auto_shutdown_timeout`.

Modifica el reinicio del estado de la máquina para que también pase `auto_shutdown_timeout` a `TakeANumberDeluxe.State.new/3`.

Modifica los valores de retorno de todos los callbacks implementados (`init/1` y todos los callbacks `handle_*`) para establecer un tiempo de espera. Usa el valor de la clave `:auto_shutdown_timeout` en el estado actual de la máquina. No agregues el tiempo de espera al valor de retorno `{:stop, reason}` de `init/1`: los tiempos de espera solo se aplican después de que el servidor haya iniciado su bucle de recepción.

Implementa un callback de `GenServer` para manejar el mensaje `:timeout` que se le enviará a la máquina si no recibe ningún otro mensaje dentro del tiempo de espera dado. Debe terminar el proceso con razón `:normal`.

Asegúrate de manejar también cualquier mensaje inesperado ignorándolo.

```elixir
{:ok, machine} =
  TakeANumberDeluxe.start_link(
    min_number: 1,
    max_number: 10,
    auto_shutdown_timeout: :timer.hours(2)
  )

# after 3 hours...

TakeANumberDeluxe.queue_new_number(machine)
# => ** (exit) exited in: GenServer.call(#PID<0.171.0>, :queue_new_number, 5000)
#        ** (EXIT) no process: the process is not alive or there's no process currently associated with the given name, possibly because its application isn't started
#       (elixir 1.13.0) lib/gen_server.ex:1030: GenServer.call/3
```
