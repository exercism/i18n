# Introducción

Python tiene dos construcciones de bucle.
Los bucles `while` para la iteración _indefinida_ (no contada) y los bucles `for` para la iteración _definida_ (contada).
Las palabras clave `break`, `continue` y `else` ayudan a personalizar el comportamiento de los bucles.
`range()` y `enumerate()` ayudan con el conteo y la indexación de los bucles.


## While

Los bucles [`while`][while statement] seguirán ejecutándose mientras la `loop expression` o «prueba» se evalúe como `True` en un [`boolean context`][truth value testing], y terminarán cuando se evalúe como `False`:

```python

# Lists are considered "truthy" in a boolean context if they
# contain one or more values, and "falsy" if they are empty.

>>> placeholders = ["spam", "ham", "eggs", "green_spam", "green_ham", "green_eggs"]

>>> while placeholders:
...     print(placeholders.pop(0))
...
'spam'
'ham'
'eggs'
'green_spam'
'green_ham'
'green_eggs'
```


## For

El `loop` básico [`for`][for statement] de Python se describe mejor como un _`for each`_ que recorre los valores de cualquier [objeto iterable][iterable] y termina cuando ya no quedan valores que devolver al llamar a [`next()`][next built-in]:

```python

>>> word_list = ["bird", "chicken", "barrel", "bongo"]

>>> for word in word_list:
...    if word.startswith("b"):
...        print(f"{word.title()} starts with a B.")
...    else:
...        print(f"{word.title()} doesn't start with a B.")
...
'Bird starts with a B.'
'Chicken doesn\'t start with a B.'
'Barrel starts with a B.'
'Bongo starts with a B.'
```


## El objeto de secuencia range()

Cuando no se especifica un `iterable` concreto, la secuencia especial [`range()`][range] se usa como contador del bucle.
`range()` requiere un `int` antes del cual `stop` la secuencia, y puede tomar opcionalmente los parámetros `start` y `step`.
Si no se proporciona un número `start`, la secuencia comenzará en 0.
Los objetos `range()` son **perezosos** (_los valores se generan a petición_), admiten todas las [operaciones de secuencia comunes][common sequence operations] y ocupan una cantidad fija de memoria, sin importar qué tan larga sea la secuencia que se especifique.

```python
# Here we use range to produce some numbers, rather than creating a list of them in memory.
# The values will start with 1 and stop *before* 7

>>> for number in range(1, 7):
...    if number % 2 == 0:
...       print(f"{number} is even.")
...    else:
...       print(f"{number} is odd.")
'1 is odd.'
'2 is even.'
'3 is odd.'
'4 is even.'
'5 is odd.'
'6 is even.'

# range() can also take a *step* parameter.
# Here we use range to produce only the "odd" numbers, starting with 3 and stopping *before* 15.

>>> for number in range(3, 15, 2):
...    if number % 2 == 0:
...       print(f"{number} is even.")
...    else:
...       print(f"{number} is odd.")
...
'3 is odd.'
'5 is odd.'
'7 is odd.'
'9 is odd.'
'11 is odd.'
'13 is odd.'
```


## Valores e índices con enumerate()

Si se necesitan tanto los valores como sus índices, la función incorporada [`enumerate(<iterable>)`][enumerate] devolverá pares (`index`, `value`):

```python

>>> word_list = ["bird", "chicken", "barrel", "apple"]

# *index* and *word* are the loop variables.
# Loop variables can be any valid python name.

>>> for index, word in enumerate(word_list):
...    if word.startswith("b"):
...        print(f"{word.title()} (at index {index}) starts with a B.")
...    else:
...        print(f"{word.title()} (at index {index}) doesn't start with a B.")
...
'Bird (at index 0) starts with a B.'
'Chicken (at index 1) doesn\'t start with a B.'
'Barrel (at index 2) starts with a B.'
'Apple (at index 3) doesn\'t start with a B.'


# The same method can be used as a "lookup" for pairing items between two lists.
# Of course, if the lengths or indexes don't line up, this doesn't work.

>>> word_list = ["cat", "chicken", "barrel", "apple", "spinach"]
>>> category_list = ["mammal", "bird", "thing", "fruit", "vegetable"]

>>> for index, word in enumerate(word_list):
...    print(f"{word.title()} is in category: {category_list[index]}.")
...
'Cat is in category: mammal.'
'Chicken is in category: bird.'
'Barrel is in category: thing.'
'Apple is in category: fruit.'
'Spinach is in category: vegetable.'
```


## Modificar el comportamiento del bucle

La palabra clave [`continue`][continue statement] se puede usar para saltar a la siguiente iteración:

```python
word_list = ["bird", "chicken", "barrel", "bongo", "sliver", "apple", "bear"]

# This will skip *bird*, at index 0
for index, word in enumerate(word_list):
    if index == 0:
        continue
    if word.startswith("b"):
        print(f"{word.title()} (at index {index}) starts with a b.")

'Barrel (at index 2) starts with a b.'
'Bongo (at index 3) starts with a b.'
'Bear (at index 6) starts with a b.'
```


La palabra clave [`break`][break statement] (_como en muchos lenguajes relacionados con C_) se puede usar para detener la iteración y «salir» del `loop` más interno que la contiene:

```python
>>>  word_list = ["bird", "chicken", "barrel", "bongo", "sliver", "apple"]

>>> for index, word in enumerate(word_list):
...    if word.startswith("b"):
...        print(f"{word.title()} (at index {index}) starts with a B.")
...    elif word == "sliver":
...       break
...    else:
...       print(f"{word.title()} doesn't start with a B.")
... print("loop broken.")
...
'Bird (at index 0) starts with a B.'
'Chicken doesn\'t start with a B.'
'Barrel (at index 2) starts with a B.'
'Bongo (at index 3) starts with a B.'
'loop broken.'
```
