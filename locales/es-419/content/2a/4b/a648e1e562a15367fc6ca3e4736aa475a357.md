# Tests

Hay dos formas distintas de preparar el entorno para ejecutar los tests con Objective-C:

- Crear un proyecto de Xcode con un target de tests que ejecute los tests.
- Usar la gema `objc` de Ruby como una utilidad para ejecutar los tests.

Ambas se describen con más detalle aquí: https://exercism.org/tracks/objective-c/tests
