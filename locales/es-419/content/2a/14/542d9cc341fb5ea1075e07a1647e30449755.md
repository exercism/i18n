# Introducción

Los números de punto flotante son números con uno o más dígitos después del separador decimal. Usan el formato de punto flotante de doble precisión de 64 bits.

```elixir
float = 3.45
# => 3.45
```

## Trabajar con números

En los módulos [`Integer`][integer-functions] y [`Float`][float-functions] puedes encontrar algunas funciones útiles para trabajar con esos tipos. Los operadores aritméticos básicos están definidos en el módulo [`Kernel`][kernel-arithmetic-operators].

## Conversión

Los enteros y los números de punto flotante se pueden mezclar en una sola expresión aritmética. Usar un número de punto flotante en una expresión garantiza que el resultado también sea un número de punto flotante.

```elixir
2 * 3
# => 6

2 * 3.0
# => 6.0
```

Sin embargo, al hacer una división, el resultado siempre será un número de punto flotante, incluso si solo usas enteros.

```elixir
6 / 2
# => 3.0
```

Para convertir un número de punto flotante en un entero, puedes descartar la parte decimal con [`trunc/1`][trunc-1].
