# Pistas

## 1. Convierte una representación binaria en un entero

- Hay un [método incorporado][string-to_i] para convertir una string con una representación binaria en un entero, dada la base.

## 2. Obtén el bit menos significativo de un entero

- Hay un [método incorporado][integer-bit] para obtener un bit de un entero, dado un índice.
- El bit menos significativo es el bit que está más a la derecha.
  Se ubica en el índice 0.

## 3. Obtén el valor hexadecimal de un canal de color

- Hay un [método incorporado][integer-to_s] para convertir un entero en una string con una representación hexadecimal, dada la base.
- El método puede recibir un argumento opcional para especificar la precisión de la cantidad de dígitos generados.

## 4. Obtén el valor hexadecimal de un RGB

- Puedes usar los métodos ya definidos para obtener el valor hexadecimal de un canal de color.
