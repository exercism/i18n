# Pistas

## General

- La página [Definite Clause Grammar de Wikipedia](https://en.wikipedia.org/wiki/Definite_clause_grammar) da una excelente introducción a las DCG
- El [Prolog DCG Primer](https://www.metalevel.at/prolog/dcg) tiene una introducción muy útil a las DCG de Prolog
- La [documentación de dcg/basics de SWIPL](https://www.swi-prolog.org/pldoc/doc/_SWI_/library/dcg/basics.pl) enumera las primitivas integradas que puedes usar

## 3. Admite todos los espacios en blanco (excepto los saltos de línea)

- Hay una [primitiva integrada](https://www.swi-prolog.org/pldoc/doc/_SWI_/library/dcg/basics.pl) que puedes usar para esto

## 4. Analiza el hemisferio de la latitud

- Las reglas DCG pueden tener variables, igual que los hechos o las reglas normales
- Las reglas DCG pueden tener múltiples declaraciones, igual que los hechos o las reglas normales

## 5. Analiza el hemisferio de la longitud

- Las reglas DCG pueden tener variables, igual que los hechos o las reglas normales
- Las reglas DCG pueden tener múltiples declaraciones, igual que los hechos o las reglas normales

## 6. Analiza los grados

- Hay una [primitiva integrada](https://www.swi-prolog.org/pldoc/doc/_SWI_/library/dcg/basics.pl) que puedes usar para esto

## 7. Analiza los grados de la latitud

- Puedes reutilizar la regla `degrees`
- La construcción del lenguaje `{}//1` se puede usar para invocar predicados de Prolog desde dentro de una regla

## 9. Analiza la latitud

- El formato de una latitud es: `<LATITUDE_DEGREES> <LATITUDE_HEMISPHERE>`
- Reutiliza las reglas que ya implementaste

## 10. Analiza la longitud

- El formato de una longitud es: `<LONGITUDE_DEGREES> <LONGITUDE_HEMISPHERE>`
- Reutiliza las reglas que ya implementaste

## 11. Analiza la coordenada

- El formato de una coordenada es: `<LATITUDE_DEGREES> <LATITUDE_HEMISPHERE>, <LONGITUDE_DEGREES> <LONGITUDE_HEMISPHERE>`
- Reutiliza las reglas que ya implementaste
