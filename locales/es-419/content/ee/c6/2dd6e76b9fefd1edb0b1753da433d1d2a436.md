# Bucles `for`

La iteración es un concepto fundamental en programación que te permite ejecutar un bloque de código varias veces.
En Swift, hay dos tipos de bucles: los [bucles `for-in`][for-loops] y los bucles `while`.
En este capítulo vas a aprender sobre los bucles `for-in`.

Los bucles `for` te permiten recorrer una secuencia de valores, tomando cada elemento a su vez y asignándolo a la variable que elijas.
Swift te permite recorrer una gran variedad de secuencias, como rangos, arrays y strings (y más tipos que veremos más adelante).
Cuando ya se recorrió cada elemento de la secuencia, el bucle termina.

Los bucles `for` se declaran con la palabra clave `for`, seguida de un nombre de variable, la palabra clave `in` y una secuencia de valores que quieres recorrer.
La variable que se define en el bucle `for-in` es inmutable, lo que significa que no puedes cambiar su valor dentro del bucle.
Aquí tienes un ejemplo de un bucle `for-in` que recorre un array de números:

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
  print(number)
}
print("Done with numbers")

// prints:
// 3
// 10
// 7
// 11
// Done with numbers
```

~~~~exercism/note
La variable `number` se declara en el bucle `for-in` y solo está disponible dentro del ámbito del bucle.

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
    number + 1
}
number + 1
// Error: Use of unresolved identifier 'number'
```
~~~~

## Recorrer un rango

También puedes recorrer un rango de números con un bucle `for-in`.
Esto te permite ejecutar un bloque de código un número concreto de veces. Por ejemplo, el rango `1...5` recorre los números 1, 2, 3, 4 y 5, así que el bucle se ejecuta 5 veces.
A veces vas a querer recorrer índices dentro de una estructura de datos como un array, y para eso puedes usar un rango `0..<array.count`.

```swift
let numbers = [3, 10, 7, 11]

for i in 0..<numbers.count {
  print(numbers[i])
}

// prints:
// 3
// 10
// 7
// 11
```

## Recorrer un string

También puedes recorrer un string con un bucle `for-in`.
Esto te permite recorrer cada carácter del string, y fíjate bien en que el tipo que se indica en el bucle es `Character`.

```swift
let message = "Hello!"

for character in message {
  print(character)
}

// prints:
// H
// e
// l
// l
// o
// !
```

## Variables sin usar

Si no necesitas el valor de la variable dentro del bucle, puedes usar un guion bajo `_` para ignorarlo.

```swift
let numbers = [3, 10, 7, 11]

for _ in numbers {
  print("Hello!")
}
```

## stride

Swift también ofrece una función `stride` que te permite crear una secuencia sobre un rango con un paso específico, y después puedes recorrerla con un bucle `for-in`.
`stride` se define como [`stride(from:to:by:)`][stride-to] o [`stride(from:through:by:)`][stride-through]; la primera es exclusiva y la segunda es inclusiva.

```swift
for i in stride(from: 0, to: 10, by: 2) {
  print(i)
}

// prints:
// 0
// 2
// 4
// 6
// 8
```

Fíjate en que el parámetro `to` es exclusivo, así que el bucle recorre hasta el número anterior al parámetro `to`, mientras que el parámetro `through` es inclusivo, así que en este caso también incluiría el `10`.

[stride-to]: https://developer.apple.com/documentation/swift/stride(from:to:by:)
[stride-through]: https://developer.apple.com/documentation/swift/stride(from:through:by:)
[for-loops]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#For-In-Loops
