# Pistas

## General

- Para crear los métodos getter y setter debes usar las macros `getter`, `setter` y `property`.

## 1. Crea un estado inicial para la báscula

- Para inicializar la báscula debes usar el método `initialize`.
- El método debe recibir dos argumentos, `precision` y `metric`, que deben ser un `Int32` y un `Bool`, respectivamente.
  Estos deben usarse para establecer las variables de instancia `@precision` y `@metric`.
- La variable de instancia `@weight` debe establecerse en `0.0`.

## 2. Permite que la báscula tenga una precisión

- La macro `getter` te permite definir un método que devuelve el valor de una variable de instancia.

## 3. Permite establecer el peso en la báscula

- La macro `property` te permite definir un método que obtiene y establece el valor de una variable de instancia.

## 4. Permite que la máquina alterne entre unidades métricas e imperiales

- La macro `setter` te permite definir un método que establece el valor de una variable de instancia.
