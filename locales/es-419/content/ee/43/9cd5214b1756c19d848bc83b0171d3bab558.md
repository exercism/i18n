# Tipos de números

Crystal tiene una variedad de tipos de números distintos para diversos propósitos.
Por ejemplo, algunos tipos son más rápidos, pero tienen un rango más pequeño de valores posibles que otros.
Otros tienen un rango más amplio de valores posibles, pero son más lentos.

En Crystal existen tanto tipos de enteros con signo como tipos de enteros sin signo.
Los tipos de enteros con signo pueden ser positivos o negativos.
Los tipos de enteros sin signo solo pueden ser positivos.

## Tipos de enteros con signo

Estos son los [tipos de enteros con signo][int] en Crystal:

| Tipo     | Tamaño (bits) | Rango                                                                                                       |
| -------- | ------------- | ----------------------------------------------------------------------------------------------------------- |
| `Int8`   | 8             | -128 a 127                                                                                                  |
| `Int16`  | 16            | -32_768 a 32_767                                                                                            |
| `Int32`  | 32            | -2_147_483_648 a 2_147_483_647                                                                              |
| `Int64`  | 64            | -9_223_372_036_854_775_808 a 9_223_372_036_854_775_807                                                      |
| `Int128` | 128           | -170_141_183_460_469_231_731_687_303_715_884_105_728 a 170_141_183_460_469_231_731_687_303_715_884_105_727 |

Los tipos más pequeños usan menos memoria y son más rápidos que los tipos más grandes, pero tienen un rango más pequeño de valores posibles.

Cuando sabes que los valores van a estar dentro de cierto rango, lo mejor es usar el tipo más pequeño posible para ahorrar memoria y mejorar el rendimiento.

El tipo de entero predeterminado es `Int32`.
Para declarar un entero con un tipo específico, puedes usar el nombre del tipo como sufijo agregando `<number>_I <bit>`.

```crystal
1_i8.class
# => Int8
```

Puedes usar el método `to_i<bit>` para convertir entre distintos tipos de enteros.
El método `to_i` convierte al tipo de entero predeterminado, `Int32`.

```crystal
1_i8.to_i16.class
# => Int16

2_i16.to_i.class
# => Int32
```

## Tipos de enteros sin signo

Estos son los [enteros sin signo][uint] en Crystal:

`UInt8`, `UInt16`, `UInt32`, `UInt64`, `UInt128`

La única diferencia entre los enteros con signo y los enteros sin signo es que los enteros sin signo solo pueden ser positivos.
Para declarar un entero sin signo con un tipo específico, puedes usar el nombre del tipo como sufijo agregando `<number>_u<bit>`.
Puedes usar el método `to_u<bit>` para convertir entre distintos tipos de enteros sin signo.
El método `to_u` convierte al tipo de entero sin signo predeterminado, `UInt32`.

```crystal
1_u8.to_u16.class
# => UInt16
```

## Tipos de punto flotante

Estos son los tipos de punto flotante en Crystal:

| Tipo      | Tamaño (bits) | Rango                |
| --------- | ------------- | -------------------- |
| `Float32` | 32            | 1.2E-38 a 3.4E+38    |
| `Float64` | 64            | 2.3E-308 a 1.7E+308  |

Hay dos [tipos de punto flotante][float] distintos, uno es más preciso que el otro.

El tipo de punto flotante predeterminado es `Float64`.

Puedes usar el método `to_f<bit>` para convertir entre distintos tipos de punto flotante.
El método `to_f` convierte al tipo de punto flotante predeterminado, `Float64`.

[float]: https://crystal-lang.org/api/latest/Float.html
[int]: https://crystal-lang.org/api/latest/Int.html
[uint]: https://crystal-lang.org/api/latest/UInt32.html
