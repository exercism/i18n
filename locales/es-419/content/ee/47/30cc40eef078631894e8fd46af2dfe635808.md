# Pistas

## 1. Genera un número de registro aleatorio para la nave estelar

- Para generar un número aleatorio en el rango de _min_ (inclusive) a _max_ (exclusive), puedes usar el fragmento `min + Math.random()*(max - min)`.
- Existe una [función integrada][floor] para convertir un número de punto flotante en un número entero.

## 2. Genera una fecha estelar aleatoria

- Para generar un número aleatorio en el rango de _min_ (inclusive) a _max_ (exclusive), puedes usar el fragmento `min + Math.random()*(max - min)`.
