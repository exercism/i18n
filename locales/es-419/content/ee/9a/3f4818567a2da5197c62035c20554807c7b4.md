# Instalación

Este track se apoya en [Node.js][web-nodejs] en todo momento para proporcionar un entorno de ejecución para JavaScript.
Esto significa que asumimos que toda ejecución de JavaScript en tu computadora se hará usando [Node.js][web-nodejs].

## Requisitos del track

Muchas máquinas vienen con [Node.js][web-nodejs] preinstalado, o puede que se haya instalado antes, o como una dependencia.
Así que, antes de hacer cualquier cosa, conviene comprobar si ya está instalado:

1. Abre una _terminal_ (`Terminal`, `cmd`, `Powershell`, `bash`, ...)
1. `node -v`

Si [Node.js][web-nodejs] está instalado, se muestra una versión.
Anota esta versión.
Si [Node.js][web-nodejs] _no_ está instalado, se mostrará un error.
Normalmente, algo como `'node' is not recognised`.

## Node.js

### Si Node.js ya está preinstalado

Ve al [sitio web de Node.js][web-nodejs].
Mostrará _dos_ versiones (si detecta tu sistema operativo; si no, selecciona primero tu sistema operativo).
Si tu versión de `node -v` coincide con una de ellas, todo bien.
Si no coincide, te recomendamos que uses Node.js LTS.
Si te preocupa que actualizar pueda romper algo en tu sistema, puedes continuar como si todo estuviera bien; es posible que no podamos brindarte soporte si ocurre algo inesperado.

### Si Node.js no está instalado

Hay un par de formas de instalar [Node.js][web-nodejs]:

- mediante un [instalador o binario][web-nodejs-download]
- mediante un [gestor de paquetes][web-nodejs-package]

Ambas opciones son compatibles con Windows, macOS y Linux. Si no sabes qué hacer, usar un instalador es lo más fácil.

- Te recomendamos usar la versión **LTS**. En el sitio web de [Node.js][web-nodejs] también aparece como _recomendada_ «para la mayoría de los usuarios».
- Sigue las instrucciones de la página web y/o del instalador e instala [Node.js][web-nodejs].

## Probar la instalación

Cuando el instalador termine, o el gestor de paquetes haya terminado, o el binario se haya copiado y se hayan seguido las instrucciones, es buena idea comprobar que todo esté bien.

1. Abre una _terminal_ (`Terminal`, `cmd`, `Powershell`, `bash`, ...)
1. `node -v`

La versión debe coincidir con la que aparece en el sitio web.

> [!NOTE]
> Es importante abrir una ventana de terminal _nueva_.
> Las ventanas de terminal que ya estén abiertas puede que no se hayan actualizado después de que terminara la instalación.
> Esto significa que las terminales abiertas no saben que se instaló un programa nuevo.

> [!IMPORTANT] > _**Ayuda**_: `'node' is not recognised`
>
> Si usaste el instalador oficial, tu `PATH` debería haberse configurado automáticamente, pero si tu shell tiene problemas para localizar tus módulos instalados globalmente, o si compilas Node.js desde el código fuente, actualiza tu `PATH` para incluir los binarios de `npm`.
>
> En macOS y Linux puedes lograrlo agregando lo siguiente a `~/.bash_profile` o a `~/.zshrc`:
>
> ```shell
> export PATH=/usr/local/share/npm/bin:$PATH
> ```
>
> En Windows, abre el menú de inicio y busca «variables de entorno».
> Tendrás que editar la entrada `PATH` y _agregar_ aquí la ruta a los binarios de `npm`.
> Normalmente, se encuentran en `C:\Program Files\nodejs`.
> Si navegas hasta aquí con tu `File Explorer`, deberías encontrar `node.exe`, `npm.bat` y `npx.bat`.
>
> Cierra las terminales que estén abiertas y abre una nueva.

## Habilitar corepack

Para usar un gestor de paquetes con control de versiones compatible con este track, hay que habilitar `corepack` una vez:

```shell
corepack enable pnpm
```

## Requisitos del ejercicio

Sigue [estas instrucciones][cli-walkthrough] para descargar el CLI de Exercism para tu sistema operativo.

Una vez que el CLI esté instalado y configurado, descarga el primer ejercicio, `hello-world`:

```shell
exercism download --exercise=hello-world --track=javascript
```

Cada ejercicio necesita luego algunas herramientas para ejecutar las pruebas.
Se pueden instalar ejecutando este comando dentro del directorio de cada ejercicio:

```shell
corepack pnpm install
```

Como este track cambió a pnpm, no tienes que preocuparte por el espacio en disco.
Echa un vistazo a [pnpm](https://pnpm.io/), que garantiza que solo se instale en disco una copia de cada versión de paquete.

> **Pero, ¿qué es corepack y por qué funciona esto?**
>
> No necesitas esta información para completar el track de JavaScript, pero si tienes ganas de entender qué acaba de pasar, los siguientes párrafos son para ti:
>
> Esto funciona porque `corepack` es una herramienta que viene incluida con Node.js, que se instaló según los pasos anteriores.
> Puede instalar el gestor de paquetes `pnpm`. Configura el sistema.
> El comando `corepack` busca un archivo `package.json`, que está presente en _cada_ carpeta de ejercicio.
> Luego revisa `packageManager`, que coincide con `pnpm`, así que puede continuar. Si es necesario, primero actualizará `pnpm`.
> Este archivo también enumera las `"dependencies"` de arriba, que luego `pnpm` descarga y coloca en una caché local.
>
> Los scripts de `package.json` usan los binarios de la caché local, y son estos scripts los que se usan para ejecutar las pruebas, como se indica en la descripción de `exercise`.
