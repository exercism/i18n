# Introducción

En el concepto [`Vectors`][vectors], dijimos que «los arrays son el corazón del lenguaje Julia» y que un vector es un array unidimensional.

Dado esto, es razonable esperar que el lenguaje ofrezca muchas formas versátiles y potentes de _hacer cosas_ con los vectores, sea lo que sea que eso signifique.

## Funciones que reciben un vector como argumento

Algunas funciones muy simples reciben un vector como argumento y devuelven un escalar.

```julia
v = [2, 3, 4]
length(v)  # => 3
sum(v)  # => 9
```

## Aritmética

Supón que tienes un vector numérico y quieres restar 0.5 a cada valor.

```julia-repl
julia> v = [1.2, 1.5, 1.7]
3-element Vector{Float64}:
 1.2
 1.5
 1.7

julia> v - 0.5
ERROR: MethodError: no method matching -(::Vector{Float64}, ::Float64)
```

Eso falla, así que ¿qué tal si restamos otro vector?

```julia-repl
julia> v - [0.5, 0.5, 0.5]
3-element Vector{Float64}:
 0.7
 1.0
 1.2
```

Funciona, pero se vuelve bastante tedioso y consume mucha memoria a medida que los vectores se hacen más largos.

Por suerte, Julia tiene un punto «mágico» que resuelve este problema de forma muy sencilla: `v .- 0.5` es todo lo que necesitas.

La siguiente sección explica por qué.

## Broadcasting

Entonces, `v - 0.5` falla pero `v .- 0.5` funciona, y necesitamos entender qué hace el punto.

Son dos cosas que se combinan para dar el resultado deseado.

### 1. Aplicación elemento a elemento

Primero, agregar un punto _antes_ de cualquier operador infijo significa «aplicar esta operación a cada elemento por separado».

De forma similar, agregar un punto _después_ del nombre de una función la «vectoriza», incluso si la función se escribió para argumentos escalares.

```julia-repl
julia> sqrt.([1, 4, 9])
3-element Vector{Float64}:
 1.0
 2.0
 3.0
```

### 2. Expansión de singletons

Vimos en un ejemplo anterior que podemos restar vectores de igual longitud, aunque ten en cuenta que `.-` es un operador _más seguro_ que `-`, porque deja clara la intención de operar elemento a elemento.

```julia-repl
julia> v .- [0.5, 0.5, 0.5]
3-element Vector{Float64}:
 0.7
 1.0
 1.2
```

¿Y qué pasa con los vectores de longitud distinta?

```julia-repl
julia> v .- [0.5, 0.5]
ERROR: DimensionMismatch: arrays could not be broadcast to a common size

julia> v .- [0.5,]
3-element Vector{Float64}:
 0.7
 1.0
 1.2
```

En general, longitudes distintas son un error, _excepto_ cuando uno tiene longitud 1 (técnicamente, una dimensión «singleton»).

Los singletons como `[0.5,]` o simplemente `0.5` se expanden automáticamente a la longitud necesaria mediante repetición.
Eso es el corazón del `broadcasting`.

### Broadcasting in-place

Si el uso de memoria te preocupa, las operaciones in-place son una forma habitual de intentar reducir las asignaciones de memoria.

Sin embargo, las operaciones de broadcasting de los ejemplos anteriores crean un nuevo `Vector` en lugar de modificar el original.

Para modificar el `Vector` original in-place, hay que hacer broadcasting de la modificación.

```julia-repl
julia> v .= v .+ 1
3-element Vector{Int64}:
 2
 3
 4

julia> v .+= 1  # equivalent operation to above
3-element Vector{Int64}:
 3
 4
 5

julia> v
3-element Vector{Int64}:
 3
 4
 5
```

## Indexación

La selección de elementos de un vector por número de índice ya se ha tratado en conceptos anteriores.

```julia
a = collect('A':'Z')  # => 26-element Vector{Char}

# index with an integer
a[2]  # => 'B'

# index with a range
 a[12:2:18]  # => ['L', 'N', 'P, 'R']
 
 # index with another vector
 a[ [1, 3, 5] ]  # => ['A', 'C', 'E']
```

### Indexación lógica

También es posible seleccionar los elementos que satisfacen cierta expresión lógica (técnicamente, un «predicado»).
Esto normalmente requiere broadcasting.

```julia-repl
julia> a[a .< 'D']
3-element Vector{Char}:
 'A': ASCII/Unicode U+0041 (category Lu: Letter, uppercase)
 'B': ASCII/Unicode U+0042 (category Lu: Letter, uppercase)
 'C': ASCII/Unicode U+0043 (category Lu: Letter, uppercase)
```

En expresiones más complejas, los puntos tienden a multiplicarse (pero son pequeños y fáciles de escribir).

```julia-repl
julia> a[a .< 'D' .|| a .> 'W']
6-element Vector{Char}:
 'A': ASCII/Unicode U+0041 (category Lu: Letter, uppercase)
 'B': ASCII/Unicode U+0042 (category Lu: Letter, uppercase)
 'C': ASCII/Unicode U+0043 (category Lu: Letter, uppercase)
 'X': ASCII/Unicode U+0058 (category Lu: Letter, uppercase)
 'Y': ASCII/Unicode U+0059 (category Lu: Letter, uppercase)
 'Z': ASCII/Unicode U+005A (category Lu: Letter, uppercase)
```

Un recordatorio de que el «vector» puede ser, de hecho, cualquier iterable ordenado adecuado, como un rango:

```julia-repl
julia> n = 3:10
3:10

julia> n[isodd.(n)]
4-element Vector{Int64}:
 3
 5
 7
 9
```
