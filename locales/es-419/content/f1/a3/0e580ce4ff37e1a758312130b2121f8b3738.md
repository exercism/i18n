# Pistas

## General

- Un array de strings tiene el tipo `ARRAY{STR}`, y un array de números,
  `ARRAY{INT}`. Tanto el argumento como, en la tarea 4, la respuesta deben
  indicar cuál de los dos.

## 1. ¿Cuántos hay en la fila?

- `.size`, sin paréntesis después.

## 2. ¿Quién va adelante?

- La primera posición es `0`.

## 3. ¿Quién va atrás?

- La última posición es el tamaño menos uno, porque se empieza a contar
  desde cero.
- Obtén el valor a partir de `.size` en lugar de escribir `2`. Las pruebas
  usan filas de varias longitudes distintas.

## 4. La formación inicial

- La respuesta es un array de strings, así que la rutina se declara
  `: ARRAY{STR}`.
- Devuelve un array literal: los tres nombres entre las marcas `|`.

## 5. Cuenta los pasos

- Un total acumulado y un bucle, como en el ejercicio anterior.
- Cuenta una variable de posición desde `0` hacia arriba y termina el bucle
  con `until!(i >= steps.size)`.
- Empezar el total en `0` es lo que hace que la fila vacía dé cero sin
  ningún tratamiento especial.
