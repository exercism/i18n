# Introducción

En C++, puedes comparar valores con los operadores de comparación.

| Comparación       | Operador  |
| ------------------| --------- |
| igual a           | `==`      |
| distinto de       | `!=`      |
| menor que         | `<`       |
| menor o igual que | `<=`      |
| mayor que         | `>`       |
| mayor o igual que | `>=`      |

El resultado de estas comparaciones siempre es un valor Boolean:

```cpp
int a{3};

bool eq1 = a != 4; // true

bool eq2 = a > 5;  // false
```

Los operadores `==` y `!=` comprueban si un valor es igual a otro o no, respectivamente.
Aquí tienes algunos ejemplos comunes:

```cpp
bool eq3 = 2 == 3; // false, integer comparison

bool eq4 = 2.1 != 2.2; // true, float comparison

bool eq5 = "hello" == "hello"; // true, string comparison
```

Los demás operadores comprueban si un valor es mayor que (`>`), mayor o igual que (`>=`), menor que (`<`) o menor o igual que (`<=`) otro valor.
Este tipo de comparación está disponible para números y strings.
Cuando comparas strings, se sigue el orden del diccionario (también conocido como orden lexicográfico).

```cpp
bool eq6 = 2 > 3; // false, integer comparison

bool eq7 = 1.2 < 1.3; // true, float comparison

bool eq8 = "Hello" < "World"; // true, string comparison
```
