# Prefiere extraer la constante al nivel superior

Considera extraer la constante al ámbito de nivel superior:

```javascript
const %{name} = %{value}

// the rest of your code below it
export %{method.signature}
```

Solo las funciones, las clases y las constantes que se exportan con `export` son visibles y accesibles desde afuera. Estas constantes pueden vivir en el mismo archivo sin quedar expuestas a otro código. Además, extraer constantes ahorra memoria, ya que evita asignaciones repetidas en las funciones cuando se reutilizan esas mismas constantes.
