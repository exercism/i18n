# Instrucciones

Había una vez una ciudad bulliciosa llamada Cyberspace.
Cyberspace era una metrópolis digital, con millones de habitantes que iniciaban y cerraban sesión todos los días.
Para llevar un registro de todos estos usuarios, Cyberspace tenía un archivo especial llamado /etc/passwd.

El archivo /etc/passwd era como una guía telefónica de la ciudad.
En él se listaba cada usuario que tenía una cuenta en el sistema, junto con información importante sobre cada uno:

| n   | campo |
| --- | --- |
| 1   | nombre de usuario |
| 2   | contraseña («x» indica que la contraseña real se guarda en otro lugar, por seguridad) |
| 3   | UID, un ID de usuario numérico único |
| 4   | GID, un ID de grupo numérico único (normalmente el mismo que el UID) |
| 5   | información del usuario (normalmente el nombre completo del usuario, pero puede incluir otra información) |
| 6   | directorio home |
| 7   | shell de inicio de sesión |

Los campos están separados por un carácter de dos puntos.
Esta es una entrada típica:

```none
glennj:x:1010:1010:Glenn Jackman:/home/glennj:/usr/local/bin/fish
```

El archivo lo administraba un equipo de administradores de sistemas, que se encargaban de crear cuentas nuevas, actualizar las cuentas existentes y eliminar las antiguas.
Los administradores de sistemas eran los guardianes de Cyberspace, y se aseguraban de que solo los usuarios autorizados pudieran acceder al sistema.

Un día, contrataron a un nuevo administrador de sistemas llamado Alex para que se uniera al equipo.
A Alex le emocionaba el puesto y aprendió rápido los entresijos del archivo /etc/passwd.
Aprendió a agregar usuarios nuevos al sistema, a actualizar la información de los usuarios y a eliminar usuarios antiguos.

Mientras trabajaba en el archivo /etc/passwd, Alex notó algo extraño.
Algunos usuarios tenían directorios home extraños o poco habituales.
Algunos usuarios tenían su directorio home configurado como /dev/null, mientras que otros lo tenían configurado con rutas extrañas que no existían.

Alex se dio cuenta de que esos usuarios no eran personas reales, sino cuentas falsas que habían creado unos hackers.
Los hackers habían encontrado la forma de explotar una vulnerabilidad del sistema y habían creado esas cuentas falsas para obtener acceso a Cyberspace.

Alex sabía que había que actuar.
Usó awk para analizar el archivo /etc/passwd y escribió un script para identificar todas las cuentas falsas.
Luego trabajó con el resto del equipo para eliminar esas cuentas y para parchear la vulnerabilidad que había permitido a los hackers crearlas.

Gracias al uso de awk por parte de Alex, el equipo pudo identificar y eliminar las cuentas falsas, y hacer de Cyberspace un lugar más seguro para todos.
Los administradores de sistemas siguieron administrando el archivo /etc/passwd, manteniéndolo actualizado y seguro, y asegurándose de que solo los usuarios autorizados pudieran acceder al sistema.

Ahora es tu turno de ser un administrador de sistemas como Alex.

## 1. Lista los nombres de usuario

Escribe un programa en awk que imprima el primer campo separado por dos puntos de cada línea del archivo passwd.

## 2. Imprime los números de línea

Escribe un comando awk que imprima el número de línea de cada registro del archivo de entrada.
Imprime solo el número de línea, y ninguna otra información.

## 3. Imprime los registros con directorios home no válidos.

En Cyberspace, un directorio home «válido» comienza con `/home` o `/root`.
Imprime los registros del archivo de entrada con directorios home **no válidos**.

## 4. Imprime los usuarios válidos que usan bash

Imprime los registros donde el directorio home es válido **y** el shell de inicio de sesión es `bash`.
