# Pistas

## 1. Define el tiempo esperado en el horno en minutos

- Debes asignar el valor correcto a la variable `$ExpectedMinutesInOven`.

## 2. Calcula el tiempo restante en el horno en minutos

- Puedes restar números entre sí con el operador `-`.

## 3. Calcula el tiempo de preparación en minutos

- Puedes multiplicar números con el operador `*`.

## 4. Calcula el tiempo total de trabajo en minutos

- Puedes llamar a otras funciones definidas que te puedan resultar útiles, p. ej., `function($arg)`.
- Puedes sumar números entre sí con el operador `+`.

## 5. Crea una notificación de que la lasaña está lista

- Puedes crear un string encerrando el texto entre comillas simples `'` o dobles `"`.
