# Pistas

## General

- Declara los cuatro símbolos cardinales y los cuatro símbolos de demora relativa con una sola línea `SYMBOLS:`: `SYMBOLS: north east south west ahead starboard behind port ;`
- Cada tupla se declara con `TUPLE: <class> <slot1> <slot2> ;`.
- Una línea `GENERIC:` declara la palabra; cada línea `M:` agrega un método para una clase. Usa `M::` si quieres variables locales con nombre en el cuerpo del método.

## 1. `>cartesian` para cardinal

- Basta con un `case` pequeño sobre los cuatro símbolos de dirección.
- `{ north [ 0 1 ] }`: el cuerpo solo empuja los dos valores; la prueba espera `x` debajo de `y` en la pila.

## 2. `>cartesian` para polar

- Convierte grados a radianes: `bearing pi * 180 /`.
- `sin` y `cos` están en `math.functions`.
- Empuja `magnitude * sin(rad)` y luego `magnitude * cos(rad)`.

## 3. `>cartesian` para relativa

- Declara una variable dinámica: `SYMBOL: heading`.
- Léela en tu método con `heading get`.
- Asigna `ahead/starboard/behind/port` a un desplazamiento `0/90/180/270` con un `case`, y luego suma el rumbo. A partir de ahí es la misma conversión polar que en la tarea 2; considera extraer un auxiliar `: deg>cartesian ( magnitude bearing -- x y ) ... ;`.

## 4. `flip`

- `change-direction` sobre un `cardinal` y `change-bearing` sobre un `polar` o `relative` construyen una nueva tupla con una ranura modificada, dejando el resto intacto: `[ <transformation-quotation> ] change-bearing`.
- Para la rotación de `polar`: `[ 180 + 360 mod ] change-bearing`.

## 5. `add-bearings`

- Llama a `>cartesian` en cada argumento, luego suma las componentes x y las componentes y. Las variables locales hacen que esto sea legible:
  ```factor
  :: add-bearings ( a b -- x y )
      a >cartesian :> ay :> ax
      b >cartesian :> by :> bx
      ax bx +
      ay by + ;
  ```
