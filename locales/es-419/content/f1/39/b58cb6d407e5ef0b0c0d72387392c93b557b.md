# Instrucciones

Tadhg ha encontrado la biblioteca de Erlang perfecta para ayudarlo con su proyecto. Como es una biblioteca de Erlang más antigua, usa el módulo `gb_trees` en lugar del módulo `maps`, más nuevo, para almacenar datos.

Ayuda a Tadgh creando tipos y funciones externos para trabajar con `gb_trees` en Gleam.

## 1. Define el tipo externo `GbTree`

El tipo `GbTree` debe tener dos parámetros de tipo, un tipo de clave y un tipo de valor. No debe tener constructores, lo que lo convierte en un tipo externo.

## 2. Define la función `new_gb_tree`

La función `new_gb_tree` no debe recibir argumentos y debe devolver un `GbTree` vacío.

Debe usar la [función `gb_trees:empty/0`][empty] de la biblioteca estándar de Erlang.

## 3. Define la función `insert`

La función `insert` debe recibir un `GbTree` y una clave y un valor para insertar en el árbol. Debe devolver un nuevo `GbTree` con la clave y el valor insertados.

La función debe recibir tres argumentos:
1. El `GbTree` en el que se insertará.
2. La clave que se insertará.
3. El valor que se insertará.

Debe usar la [función `gb_trees:insert/3`][insert] de la biblioteca estándar de Erlang.

## 4. Define la función `delete`

La función `delete` debe recibir un `GbTree` y una clave para eliminar del árbol. Debe devolver un nuevo `GbTree` con la clave y el valor eliminados.

La función debe recibir dos argumentos:
1. El `GbTree` del que se eliminará.
2. La clave que se eliminará.

Debe usar la [función `gb_trees:delete_any/2`][delete_any] de la biblioteca estándar de Erlang.
