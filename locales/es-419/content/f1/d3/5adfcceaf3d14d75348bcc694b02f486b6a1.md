# Pistas

## General

- Una [estructura][structs] puede contener varios campos de distintos tipos.
- El [tipo Option][option] representa un valor que puede ser `Some(value)` o `None`.
- La [construcción `match`][match]: cómo hacer coincidencia de patrones en Cairo.

## 1. Implementa el método `revive`

- Usa [sentencias condicionales][if-else] para comprobar si la salud del jugador es 0.
- Puedes crear una nueva instancia de `Player` usando la [sintaxis de inicialización de estructuras][structs].
- Usa [coincidencia de patrones][match] o lógica condicional para determinar el valor de maná según el nivel del jugador.
- Devuelve `Option::Some(player)` si el jugador revive con éxito, o `Option::None` si el revivir falla.

## 2. Implementa el método `cast_spell`

- Usa [coincidencia de patrones][match] sobre el tipo `Option` para manejar los casos `Some` y `None` del maná.
- Puedes usar [operadores de comparación][operators] para comprobar si hay maná suficiente.
- Puedes usar los [operadores matemáticos][operators] de resta y multiplicación para calcular valores.
- Recuerda modificar el estado del jugador (la salud o el maná) usando referencias mutables.
