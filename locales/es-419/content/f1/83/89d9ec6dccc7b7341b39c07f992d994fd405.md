# Instructions

Un banco muy concurrido atiende a los clientes en espera por *prioridad*, no en el orden en que llegaron. A cada cliente se le asigna un número de prioridad cuando toma un turno, y el cajero siempre atiende el número más bajo a continuación (`1` es el más urgente). Un montículo mínimo es la fila de espera perfecta.

## 1. Abre la cola

Define `new-queue`, que no recibe nada y devuelve una cola de prioridad nueva y vacía.

```factor
new-queue
! => an empty priority queue
```

## 2. Agrega un cliente

Define `join-queue`, que recibe el nombre de un cliente, un número de prioridad y una cola. Agrega al cliente a la cola y devuelve la cola, así puedes agregar clientes uno tras otro.

```factor
new-queue "alice" 5 rot join-queue "bob" 2 rot join-queue
! => the queue, now holding alice (5) and bob (2)
```

## 3. ¿Quién sigue?

Define `next-name`, que recibe una cola y devuelve el nombre del cliente al que le toca ser atendido, el que tiene el menor número de prioridad, *sin* quitarlo de la cola.

```factor
new-queue "alice" 5 rot join-queue "bob" 2 rot join-queue next-name .
! => "bob"
```

## 4. Atiende a todos

Define `serve-all`, que recibe una cola y devuelve los nombres de todos los clientes en espera, en el orden en que serían atendidos.

```factor
new-queue "alice" 5 rot join-queue "bob" 2 rot join-queue
"carol" 9 rot join-queue serve-all .
! => { "bob" "alice" "carol" }
```
