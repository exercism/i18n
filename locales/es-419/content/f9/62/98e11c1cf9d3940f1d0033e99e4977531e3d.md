# Acerca de

El valor `null` se usa para denotar la _ausencia_ de un valor. Un tipo **anulable** es un tipo que permite que una variable tome el valor `null`. Para que cualquier tipo sea anulable, lo envolvemos con `Null<T>`:

```haxe
var a:Int = null; // Error
var b:Null<Int> = null; // Allowed
```

Para comprobar si un valor es `null` en este momento, simplemente usa una expresión `if`:

```haxe
var a:Null<Int> = 10;

if (a != null) {
  trace("a is not null"); // a is not null
}
```
