# Acerca de

En Go, los strings son inmutables.
Concatenar strings con `+` dentro de un bucle provoca asignaciones de memoria frecuentes y copia los datos varias veces.
El [paquete `strings`](https://pkg.go.dev/strings) proporciona [`Builder`](https://pkg.go.dev/strings#Builder) para minimizar el uso de memoria al ensamblar strings de forma eficiente.

## Construir strings

El valor cero de un `strings.Builder` está listo para usarse de inmediato, sin necesidad de inicialización ni asignación de memoria explícita.
Puedes agregar datos nuevos al `Builder` con métodos de escritura específicos.
Cada método de escritura devuelve un valor de error para cumplir con las interfaces estándar de Go, pero está garantizado que siempre será `nil` y, por lo general, se ignora en el código del día a día.

Los métodos que más se usan son:

- `WriteString(s string) (int, error)`: Agrega un string al búfer.
- `WriteRune(r rune) (int, error)`: Agrega la codificación UTF-8 de un rune.
- `WriteByte(c byte) error`: Agrega un solo byte.

```go
var sb strings.Builder

sb.WriteString("Hello")
var r rune = ' '
sb.WriteRune(r)
var b byte = '.'
sb.WriteByte(b)
```

## Obtener y restablecer

Cuando termines de ensamblar tu texto, puedes extraer el contenido acumulado como un string estándar de Go llamando al método `String()`.
Llamar a `String()` es una operación muy económica porque devuelve el slice de bytes subyacente como un string directamente, sin copiar los datos acumulados.

Si necesitas reutilizar la misma instancia del builder para ensamblar un string nuevo (por ejemplo, dentro de un bucle), puedes llamar al método `Reset()`.
Esto vacía el búfer interno, lo que te permite empezar de cero y construir el siguiente string mientras se conserva la capacidad de memoria ya asignada internamente.

```go
var sb strings.Builder

sb.WriteString("Task One")
fmt.Println(sb.String()) // Output: Task One

// Clear the buffer for resource reuse
sb.Reset()

sb.WriteString("Task Two")
fmt.Println(sb.String()) // Output: Task Two
```
