# Instrucciones

En este ejercicio escribirás parte de la lógica de un videojuego que está desarrollando un amigo.
La protagonista del juego es Annalyn, una chica valiente que tiene un perro feroz y leal.
Por desgracia, ocurre una tragedia: su mejor amiga es secuestrada mientras busca bayas en el bosque.
Annalyn intentará encontrar y liberar a su amiga, y puede llevar a su perro con ella en esta misión.

Finalmente, Annalyn encuentra el campamento en el que tienen prisionera a su amiga y resulta que hay dos secuestradores: un caballero poderoso y un arquero astuto.

Al jugador se le presentan varias opciones sobre qué hacer a continuación.
Para cada una de las cuatro opciones posibles debes escribir una función que le diga al juego si debe mostrar esa opción o no.

## 1. Comprobar si se debe mostrar la opción «Ataque rápido»

Si el caballero está dormido, Annalyn podrá hacer un ataque rápido al campamento antes de que él pueda despertarse del todo y ponerse la armadura.

Implementa una función llamada `can_do_fast_attack` que recibe un valor Boolean que indica si el caballero está despierto.
Esta función devuelve `true` si la acción «Ataque rápido» está disponible según el estado del personaje. Si no, devuelve `false`:

```julia-repl
julia> knight_awake = true

julia> can_do_fast_attack(knight_awake)
false
```

## 2. Comprobar si se debe mostrar la opción «Espiar»

Se puede espiar al grupo si al menos uno de ellos está despierto. Si no, espiar es una pérdida de tiempo.

Implementa una función llamada `can_spy` que recibe tres valores Boolean, que indican si el caballero, el arquero y la prisionera, respectivamente, están despiertos.
La función devuelve `true` si la acción «Espiar» está disponible según el estado de los personajes.
Si no, devuelve `false`:

```julia-repl
# Output suppressed from the next 3 lines
julia> knight_awake = false
julia> archer_awake = true
julia> prisoner_awake = false

julia> can_spy(knight_awake, archer_awake, prisoner_awake)
true
```

## 3. Comprobar si se debe mostrar la opción «Hacer señales a la prisionera»

Se le pueden hacer señales a la prisionera con sonidos de pájaros si ella está despierta y el arquero está dormido.
Si el arquero está despierto, no se le pueden hacer señales con seguridad, porque el arquero también domina las señales de pájaros.

Implementa una función llamada `can_signal_prisoner` que recibe dos valores Boolean, que indican si el arquero y la prisionera, respectivamente, están despiertos.
La función devuelve `true` si la acción «Hacer señales a la prisionera» está disponible según el estado de los personajes.
Si no, devuelve `false`:

```julia-repl
julia> archer_awake = false
julia> prisoner_awake = true

julia> can_signal_prisoner(archer_awake, prisoner_awake)
true
```

## 4. Comprobar si se debe mostrar la opción «Liberar a la prisionera»

Annalyn puede intentar colarse en el campamento para liberar a su amiga. Es algo arriesgado y solo puede salir bien de una de estas dos formas:

- Si Annalyn lleva a su perro con ella, puede rescatar a la prisionera si el arquero está dormido.
  El caballero le tiene miedo al perro y el arquero no tendrá tiempo de prepararse antes de que Annalyn y su amiga escapen.

- Si Annalyn no lleva a su perro, ella y la prisionera tendrán que ser muy sigilosas.
  Annalyn puede liberar a la prisionera si está despierta y el caballero y el arquero están los dos dormidos, pero si la prisionera está dormida, no se la puede rescatar: se asustaría con la aparición repentina de Annalyn y despertaría al caballero y al arquero.

Implementa una función llamada `can_free_prisoner` que recibe cuatro valores Boolean.
Los tres primeros parámetros indican si el caballero, el arquero y la prisionera, respectivamente, están despiertos.
El último parámetro indica si el perro de Annalyn está presente.
La función devuelve `true` si la acción «Liberar a la prisionera» está disponible según el estado de los personajes. Si no, devuelve `false`:

```julia-repl
julia> knight_awake = false
julia> archer_awake = true
julia> prisoner_awake = false
julia> dog_present = false

julia> can_free_prisoner(knight_awake, archer_awake, prisoner_awake, dog_present)
false
```
