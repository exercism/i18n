# Pistas

## 1. Calcula el precio de una pizza

- Define una función recursiva que devuelva el precio de una opción adicional sumado al precio de la pizza sin ese ingrediente adicional.
- Si aparece el error `Maximum call stack size exceeded`, verifica si te faltó el caso base.
- Si obtienes un `Memory Allocation Error`, verifica si estás duplicando el array de ingredientes que recibes en lugar de mutarlo.

## 2. Calcula el precio total de un pedido

- Con `pizzaPrice`, calcula el precio de cada pizza del array y ve sumándolos.
- Si aparece el error `Maximum call stack size exceeded` y falla más de un test, verifica si te faltó el caso base. Si solo falla un test, ¡intenta implementarlo con un bucle!
- Si obtienes un `Memory Allocation Error`, verifica si estás duplicando el array que recibes en lugar de mutarlo.
