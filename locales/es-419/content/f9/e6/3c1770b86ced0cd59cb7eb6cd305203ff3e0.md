# Instrucciones

El día que tanto esperaste finalmente llegó y ahora eres el orgulloso dueño de una hermosa granja en los Alpes.

Todavía no te gusta levantarte muy temprano para alimentar a tus vacas.
Como eres un excelente ingeniero, construyes un dispensador de comida, el `FEED-M-ALL`.

Lo último que se necesita para terminar tu proyecto es un fragmento de código que calcule la cantidad de forraje que debería recibir cada vaca.
Es importante que cada vaca reciba la misma cantidad, hay que evitar conflictos.
Las vacas son muy sensibles.

Por suerte, no necesitas deducir todas las fórmulas para calcular las cantidades de forraje por tu cuenta.
Usas una misteriosa biblioteca externa que encontraste en internet.
Se supone que da como resultado las vacas más felices.
La biblioteca expone un tipo que cumple con la siguiente interfaz.
Te apoyarás en esto en el código que escribas.

```go
type FodderCalculator interface {
	FodderAmount(int) (float64, error)
	FatteningFactor() (float64, error)
}
```

A medida que trabajes en tu código, mejorarás el manejo de errores para que sea más robusto y más fácil de depurar cuando lo uses en tu vida diaria en la granja.

## 1. Divide la comida en partes iguales

Primero que nada, te enfocas en escribir el código necesario para calcular la cantidad de forraje por vaca.

Implementa una función `DivideFood` que acepte un `FodderCalculator` y un número de vacas como entero como argumentos.
*Para esta tarea, asumes que el número de vacas que se pasa siempre es mayor que cero.*
La función debe devolver la cantidad de comida por vaca como un `float64` o un error si ocurrió alguno.

Para hacer el cálculo, primero necesitas obtener la cantidad total de forraje para todas las vacas.
Esto se hace llamando al método `FodderAmount` y pasando el número de vacas.
Además, necesitas un factor por el cual multiplicar esa cantidad.
Obtienes este factor llamando al método `FatteningFactor`.
Con estos dos valores y el número de vacas, ya puedes calcular la cantidad de comida por vaca (como un `float64`).
Eso es lo que debe devolver la función `DivideFood`.

Si uno de los métodos que llamas devuelve un error, la ejecución debe detenerse y ese error debe devolverse (tal cual) desde la función `DivideFood`.

```go
// For this example, we assume FodderAmount returns 50
// and FatteningFactor returns 1.5.
DivideFood(fodderCalculator, 5)
// => 15 <nil>

// Now assuming FodderAmount returns an error with message "something went wrong".
DivideFood(fodderCalculator, 5)
// => 0 "something went wrong"
```

## 2. Verifica la cantidad de vacas

Mientras trabajabas en la primera tarea, te diste cuenta de que la biblioteca externa que usas no tiene la calidad que pensabas.
Por ejemplo, no puede manejar correctamente los argumentos inválidos.
Quieres sortear esta limitación agregando una verificación del argumento en tu propio código.

Escribe una función `ValidateInputAndDivideFood` que tenga la misma firma que `DivideFood`.

- Si el número de vacas que se pasa es mayor que 0, la función debe llamar a `DivideFood` y devolver los resultados de esa llamada.
- Si el número de vacas es 0 o menos, la función debe devolver un error con el mensaje `"invalid number of cows"`.

```go
ValidateInputAndDivideFood(fodderCalculator, 5)
// => 15 <nil>

ValidateInputAndDivideFood(fodderCalculator, -2)
// => 0 "invalid number of cows"
```

## 3. Mejora el manejo de errores

Verificar el número de vacas antes de pasarlo fue una buena decisión, pero no estás del todo conforme con el mensaje de error tan poco específico.
Decides hacerlo mejor creando un tipo de error personalizado llamado `InvalidCowsError`.

El error personalizado debe contener el número de vacas (`int`) y un mensaje personalizado (`string`), y el método `Error` debe serializar los datos con el siguiente formato:

```txt
{number of cows} cows are invalid: {custom message}
```

Con tu error personalizado en mano, implementa una función `ValidateNumberOfCows` que acepte el número de vacas como entero y devuelva un error (o nil).

- Si el número de vacas es menor que 0, la función devuelve un `InvalidCowsError` con el mensaje personalizado establecido en `"there are no negative cows"`.
- Si el número de vacas es 0, la función devuelve un `InvalidCowsError` con el mensaje personalizado establecido en `"no cows don't need food"`.
- De lo contrario, la función devuelve `nil` para indicar que la validación fue exitosa.

```go
err := ValidateNumberOfCows(-5)
err.Error()
// => "-5 cows are invalid: there are no negative cows"
```

Dejas para otro día la tarea de agregar la nueva función de validación a tu código.
