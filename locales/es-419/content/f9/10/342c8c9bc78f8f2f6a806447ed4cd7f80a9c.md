# Introducción

Una *quotation* es un fragmento de código entre `[ ]`. Es un valor: puedes ponerlo en la pila, pasarlo a otra palabra o guardarlo en un array.

```factor
[ 1 + ] .          ! => [ 1 + ]
5 [ 1 + ] call .   ! => 6
```

La mayoría de las palabras de orden superior toman una quotation como su segundo argumento:

```factor
{ 1 2 3 } [ sq ] map .    ! => { 1 4 9 }
{ 1 2 3 } [ even? ] filter .  ! => { 2 }
```

El cuerpo de una quotation es código Factor común y corriente: los mismos operadores y efectos de pila que usas en todo lo demás.

Cuando construyes código a partir de datos (concatenando fragmentos, mapeando tokens a operaciones), el resultado es una secuencia; pásala por `>quotation` para poder llamarla:

```factor
{ [ 1 ] [ 2 + ] [ 3 * ] } concat >quotation call .   ! => 9
```
