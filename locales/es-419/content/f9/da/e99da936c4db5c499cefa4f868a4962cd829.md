# Introducción

Este ejercicio se apoya en la pila de datos y en la notación de efecto de pila que conociste en [Cargo Shuffle][cargo-shuffle]. Aquí vas a escribir palabras que combinan valores Boolean.

## Palabras de reordenamiento

Las palabras de reordenamiento más comunes están en [`kernel`][kernel]:

```
dup    ( x -- x x )
dupd   ( x y -- x x y )
drop   ( x -- )
swap   ( x y -- y x )
swapd  ( x y z -- y x z )
over   ( x y -- x y x )
pick   ( x y z -- x y z x )
rot    ( x y z -- y z x )
-rot   ( x y z -- z x y )
rotd   ( w x y z -- w y z x )
spin   ( x y z -- z y x )
nip    ( x y -- y )
tuck   ( x y -- y x y )

2dup   ( x y -- x y x y )
3dup   ( x y z -- x y z x y z )
4dup   ( w x y z -- w x y z w x y z )
2drop  ( x y -- )
3drop  ( x y z -- )
4drop  ( w x y z -- )
2nip   ( x y z -- z )
2swap  ( x y z w -- z w x y )
```

## Boolean

Los dos literales Boolean son `t` y `f`. `f` es el único valor que Factor considera falso: todo lo demás, incluidos `0` y las colecciones vacías, se considera verdadero.

```factor
t .    ! => t
f .    ! => f
```

## Palabras Boolean

Estas tres palabras Boolean del vocabulario `kernel`:

```
and ( x y -- ? )    ! true when both inputs are truthy
or  ( x y -- ? )    ! true when either input is truthy
not ( x   -- ? )    ! inverts its argument
```

```factor
t t and .    ! => t
t f and .    ! => f
f t or .     ! => t
t not .      ! => f
```

El `?` de cada salida es la convención de la notación de efecto de pila para «un Boolean».

Vas a necesitar `swap` para una de las tareas de abajo.
