# Introducción

Al igual que una sentencia _if/else_, una sentencia `switch` te permite cambiar el flujo del programa ejecutando código de forma condicional.
La diferencia es que una sentencia `switch` solo puede comparar el valor de una expresión primitiva o de un string con valores constantes predefinidos.

Algunas palabras clave son útiles cuando usas una sentencia `switch`.

- `switch`: esta palabra clave te permite declarar la estructura del switch.
  Va seguida de la expresión o la variable que cambiará el resultado.
- `case`: usarás esta palabra clave para declarar las distintas posibilidades del resultado.
- `break`: la palabra clave `break` es muy útil para detener la ejecución del switch al final del flujo deseado.
  Si la olvidas, el programa continuará y podría dar resultados inesperados.
- `default`: como su nombre lo indica, úsala como resultado predeterminado cuando ningún otro caso coincida con el resultado de tu expresión.

En su forma más simple, evalúan una expresión primitiva o de tipo string y toman una decisión basada en su valor.
Por ejemplo:

```java
String direction = getDirection();
switch (direction) {
    case "left":
        goLeft();
        break;
    case "right":
        goRight();
        break;
    default:
        // otherwise
        markTime();
        break;
}
```
