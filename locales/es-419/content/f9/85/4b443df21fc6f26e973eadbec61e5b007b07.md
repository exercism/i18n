# Introducción

## Operadores de comparación

R tiene un conjunto de operadores que es igual al de muchos otros lenguajes:

```R
1 == 2 # FALSE
1 != 2 # TRUE
1 < 2 # TRUE
1 > 2 # FALSE
1 <= 2 # TRUE
1 >= 2 # FALSE
```

## Bifurcación

La forma básica de un if-else es

```R
if (x > 10) {
    y <- "big"
} else if (x > 2) {
    y <- "medium"
} else {
    y <- "tiny"
}
```

En este caso, los paréntesis `()` alrededor del Boolean y las llaves `{}` alrededor de la sentencia son obligatorios.
Una sentencia `if` simple se puede acortar:

```R
if (x == 0) return("success")
```
