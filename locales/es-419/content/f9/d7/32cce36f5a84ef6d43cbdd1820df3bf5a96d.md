# Pistas

## 1. Define el rango de filas y columnas

- Necesitas definir dos [constantes][constants] que contengan un [rango][range] de filas y columnas.
- Las filas deben ser un rango de [enteros][integers] del 1 al 8.
- Las columnas deben ser un rango de [caracteres][characters] de 'A' a 'H'.
- La constante debe definirse en el [módulo][module] `Chess`.

## 2. Verifica si la casilla es válida

- Necesitas verificar si un valor está dentro de un rango.
- Hay [un método][include] que puedes usar para verificar si un valor está dentro de un rango.

## 3. Obtén el apodo del jugador

- Puedes obtener una subcadena usando el [operador de rango][range-operator] como índice.
- Hay [un método][upcase] que puedes usar para convertir un string a mayúsculas.

## 4. Crea el mensaje del movimiento

- Puedes indexar el string de la casilla para obtener la fila y la columna.
- Puedes usar los métodos ya definidos para obtener el apodo del jugador y para verificar si el movimiento es válido.
