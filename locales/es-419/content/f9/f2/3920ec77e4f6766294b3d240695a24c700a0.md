Elixir tiene convenciones de nombres específicas que incluyen cómo nombrar las [verificaciones que devuelven Boolean y son válidas en las cláusulas guard](https://hexdocs.pm/elixir/naming-conventions.html#is_-prefix-is_foo):

> Las verificaciones de tipo y otras verificaciones de valores Boolean que están permitidas en las cláusulas guard se nombran con un prefijo `is_`.

Estas verificaciones incluyen algunas funciones integradas, algunas macros y algunas guardas.

```elixir
# this is the expected name for checks that return booleans and are valid in guard clauses

%{expected}

# this is the current name

%{actual}
```
Ten en cuenta que las funciones y macros que devuelven Boolean y que no son válidas en cláusulas guard siguen otra convención y se nombran con un sufijo `?` (`def foo?`, `defmacro foo?`). Estas dos convenciones no deben mezclarse.
