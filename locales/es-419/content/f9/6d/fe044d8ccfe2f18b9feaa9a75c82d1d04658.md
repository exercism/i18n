# Acerca de

[SQLite][sqlite] es un sistema de gestión de [bases de datos relacionales][relational-database] de código abierto, ligero, sin servidor y autocontenido.
Es conocido por su simplicidad, su facilidad de uso y por no requerir configuración alguna.
SQLite se puede integrar dentro de las aplicaciones, lo que lo convierte en una opción ideal para apps, sistemas embebidos y proyectos de pequeña y mediana escala.

Creado por [D. Richard Hipp][hipp], SQLite sigue las propiedades [ACID][acid], pensadas para facilitar transacciones confiables.
Se usa ampliamente en diversas industrias gracias a su huella mínima y su rendimiento eficiente.

SQLite emplea una sintaxis sencilla basada en SQL para definir bases de datos e interactuar con ellas.
Las tablas, los índices y las consultas se crean con sentencias SQL estándar, lo que les da a los desarrolladores una forma familiar y expresiva de gestionar bases de datos.
El motor de la base de datos es autocontenido, lo que elimina la necesidad de un proceso de servidor aparte.
Esta simplicidad, combinada con sus potentes capacidades, hace de SQLite una excelente opción para proyectos en los que la facilidad de uso y la eficiencia son una prioridad.

Para obtener información detallada y documentación, consulta la [documentación oficial de SQLite][sqlite docs].
