# Pruebas

## Resumen
 
- Ve al directorio del problema (por ejemplo, `~/Exercism/hello-world`).
- Inicia una sesión de `jconsole` en una terminal.
- Carga tu archivo de solución (por ejemplo, `load 'hello-world.ijs'`).
- Carga el framework de pruebas unitarias escribiendo `load  'general/unittest'`.
- Prueba tu solución escribiendo `unittest 'test.ijs'`.
<br></br>
- Como alternativa, puedes ejecutar las pruebas en una sola línea así: `jconsole -js "load 'hello-world.ijs'" "echo unittest 'test.ijs'" "exit 0"`.

## Sesión de jconsole

La idea es que la configuración de las pruebas del track sea lo más simple posible.
Si estás trabajando en un ejercicio, digamos `hamming.ijs`, así es como debería fluir el trabajo.
Edita `hamming.ijs` escribiendo tu solución.
Constrúyela de forma interactiva escribiendo primero lo siguiente.

```j
NB. your j terminal binary may be ijconsole (eg. on Debian)
jconsole 'hamming.ijs' NB. start a J console session with definitions loaded hamming.ijs
```

Luego, desde dentro de la consola de J, recarga escribiendo

```j
load 'hamming.ijs'
```

El siguiente paso es cargar el framework de pruebas unitarias escribiendo

```j
load 'general/unittest'
```

Para ejecutar las pruebas, después de haber cargado tu solución, escribe

```j
unittest 'test.ijs'
```

Y luego observa los resultados.

## Línea de comandos

Puedes ejecutar las pruebas con un comando de una sola línea en la terminal usando la opción -js:

```j
jconsole  -js "load 'hamming.ijs'" "echo unittest 'test.ijs'" "exit 0"
```
donde cada argumento representa un comando que se ejecutará de forma secuencial.
