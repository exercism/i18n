# Pistas

## General

- El espacio de nombres `clojure.string` tiene muchas [funciones útiles de manipulación de strings][string-ns].

## 1. Obtén el mensaje de una línea de log

- La función [`split`][split] se puede usar para dividir un string con una expresión regular.
- La función [`trim`][trim] se puede usar para eliminar los espacios en blanco de los extremos de un string.

## 2. Obtén el nivel de log de una línea de log

- Un `string` se puede convertir a minúsculas usando [`lower-case`][lower-case].

## 3. Reformatea una línea de log

- La función [`str`][str] se puede usar para concatenar strings.
