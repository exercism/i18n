# Pruebas

## Ejecutar las pruebas

1. Consigue un ejercicio:

    ```bash
    $ exercism download -track=kotlin --exercise=hello-world
    ```

2. Cambia de directorio al ejercicio:

    ```bash
    $ cd <path_to_exercise_directory>
    ```

3. Ejecuta las pruebas:

    ```bash
    $ ./gradlew test
    ```

En la mayoría de los ejercicios, solo se ejecuta la primera prueba de forma predeterminada.  
Las demás pruebas están anotadas con `@Ignore` para omitirlas.  
A medida que resuelvas cada prueba, quita el `@Ignore` de la siguiente para avanzar.

Esta es una práctica común en el desarrollo guiado por pruebas (o TDD, para abreviar).
Se usa para garantizar que trabajes en un solo problema a la vez.
