# Pistas

## General

- Hay tres [operadores Boolean][boolean-operators] para trabajar con valores Boolean escalares.
- Puedes combinar varios operadores en una sola expresión.

## 1. Comprueba si se puede hacer un ataque rápido

- El operador lógico NOT (`!`) se puede colocar delante de una expresión para negar su valor.

## 2. Comprueba si se puede espiar al grupo

- Los operadores Boolean se suelen usar para evaluar si dos o más expresiones son `TRUE` o no`!`

## 3. Comprueba si se puede hacer señales al prisionero

- Los operadores Boolean se ejecutan en el orden de su precedencia (de mayor a menor): `!`, `&&`, `||`.
- En general, se recomienda usar paréntesis para que tu intención quede más clara.

## 4. Comprueba si se puede liberar al prisionero

- Los operadores Boolean se ejecutan en el orden de su precedencia (de mayor a menor): `!`, `&&`, `||`.
- En general, se recomienda usar paréntesis para que tu intención quede más clara.
