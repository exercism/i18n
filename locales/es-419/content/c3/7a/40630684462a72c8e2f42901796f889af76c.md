# Instrucciones

Vas a escribir algo de código para manejar un array de lenguajes de programación que quieres aprender. Ese array se llamará `@LanguageList::Languages`.

## 1. Agrega un lenguaje al array @Languages

Modifica la subrutina `LanguageList::add_language`, que recibe un nombre de lenguaje como argumento, para agregar el lenguaje al final del array `@LanguageList::Languages`.

## 2. Elimina un lenguaje del array @Languages

Modifica la subrutina `LanguageList::remove_language` para eliminar el último lenguaje del array `@LanguageList::Languages`.

## 3. Obtén el primer lenguaje del array @Languages

Modifica la subrutina `LanguageList::first_language` para que devuelva el primer lenguaje del array `@LanguageList::Languages`.

## 4. Obtén el último lenguaje del array @Languages

Modifica la subrutina `LanguageList::last_language` para que devuelva el último lenguaje del array `@LanguageList::Languages`.

## 5. Obtén una porción de lenguajes del array @Languages

Modifica la subrutina `LanguageList::get_languages`, que recibe varios números correspondientes a los elementos que quieres, para que devuelva una porción del array `@LanguageList::Languages`.

## 6. Verifica si un lenguaje existe en el array @Languages

Modifica la subrutina `LanguageList::has_language`, que recibe un nombre de lenguaje como argumento, para que devuelva un valor verdadero o falso que indique si el lenguaje existe en el array `@LanguageList::Languages`.
