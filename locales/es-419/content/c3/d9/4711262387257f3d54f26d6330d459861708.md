# Arrays

Un **array**, llamado _arreglo_ en español, guarda una fila de valores, todos del mismo tipo, en orden.

El tipo se escribe `ARRAY{T}`, donde `T` es lo que contiene. Un array de strings es `ARRAY{STR}`; un array de números enteros es `ARRAY{INT}`.

```sather
   row : ARRAY{STR} := |"Mia", "Ana", "Ben"|;
```

Los valores que están entre las dos marcas `|` son el **literal del array**. Sather calcula el tamaño a partir de cuántos hay.

## Obtener un valor

Los corchetes contienen la posición:

```sather
row[0]      -- "Mia"
row[1]      -- "Ana"
row[2]      -- "Ben"
```

El conteo empieza en **cero**, no en uno. Así que el primer valor está en `0`, y el último de una fila de tres está en `2`.

## ¿Cuántos hay?

`.size` indica cuántos valores contiene el array.

```sather
row.size    -- 3
```

Como el conteo empieza en cero, la última posición siempre es `.size - 1`:

```sather
row[row.size - 1]     -- "Ben"
```

Pedir una posición que no existe, como `row[3]` o `row[-1]`, es un error que Sather no va a detectar por ti, así que vale la pena escribir `.size - 1` en lugar de contar los valores a ojo.

## Recorrer un array

Un array y un bucle van de la mano. Ve incrementando una variable por las posiciones y úsala para llegar a cada valor:

```sather
   total ::= 0;
   i ::= 0;
   loop
      until!(i >= scores.size);
      total := total + scores[i];
      i := i + 1;
   end;
```
