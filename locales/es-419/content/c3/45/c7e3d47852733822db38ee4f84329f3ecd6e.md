# Introducción

La mayor parte del tiempo, Factor maneja la iteración mediante combinadores como `each`, `map` y `count`. A veces, sin embargo, la forma más limpia de expresar un cálculo es la **recursión**: una palabra que se llama a sí misma.

## Definir una palabra recursiva

Una definición con `:` puede llamarse a sí misma directamente:

```factor
: count-down ( n -- )
    dup 0 = [ drop ] [ dup . 1 - count-down ] if ;

5 count-down
! prints 5 4 3 2 1
```

## Ramificación según si está vacío o no

`if-empty` (en [`sequences`][sequences]) es el caso base natural de la recursión:

```
if-empty ( seq emptyquot nonemptyquot -- )
```

```factor
{ 4 0 9 } [ "empty" ] [ "got data" ] if-empty .
! => "got data"
```

`emptyquot` se ejecuta con la secuencia (vacía) ya consumida; `nonemptyquot` se ejecuta con la secuencia todavía en la pila.

## `cond`: una cadena de ramas condicionales

Cuando tu recursión tiene más de dos casos, `cond` (en [`combinators`][combinators]) mantiene el código legible:

```factor
: classify ( n -- label )
    {
        { [ dup 0 < ] [ drop "negative" ] }
        { [ dup 0 = ] [ drop "zero"     ] }
        [ drop "positive" ]
    } cond ;
```

## Referencias hacia adelante con `DEFER:`

Una definición con `:` puede llamarse a sí misma directamente, pero cuando dos palabras se llaman *entre sí*, el analizador sintáctico ve la primera palabra antes de que exista la segunda. `DEFER:` reserva un nombre para que la primera definición pueda compilarse:

```factor
DEFER: even?

: odd? ( n -- ? ) dup 0 = [ drop f ] [ 1 - even? ] if ;
: even? ( n -- ? ) dup 0 = [ drop t ] [ 1 - odd? ] if ;
```

`DEFER:` también es útil cuando una palabra auxiliar se lee de forma más natural *después* de la palabra que la usa.
