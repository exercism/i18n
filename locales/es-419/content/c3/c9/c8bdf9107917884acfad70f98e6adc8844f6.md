# Introducción

El atributo Flags permite que los valores definidos en una unión discriminada se representen como posiciones de bits (es decir, banderas).
Como banderas, esos valores se pueden combinar, lo que hace posible representar múltiples condiciones booleanas en un solo valor.

```fsharp
[<Flags>]
type PhoneFeatures =
| Call = 1
| Text = 2
```

```fsharp
[<Flags>]
type PhoneFeaturesBinary =
| Call = 0b00000001
| Text = 0b00000010
```

Activar una bandera se puede hacer con el operador OR bit a bit (`|||`); desactivar una bandera se puede hacer con una combinación del operador AND bit a bit (`&&&`) y el operador de negación bit a bit (`~~~`).
Aunque comprobar el estado de una bandera se puede hacer con el operador AND bit a bit, también se puede usar el método `HasFlag()`.

```fsharp
let features = PhoneFeatures.Call

// Set the Text flag
let moreFeatures = features ||| PhoneFeatures.Text

moreFeatures.HasFlag(PhoneFeatures.Call) // => true
moreFeatures.HasFlag(PhoneFeatures.Text) // => true
```

Consulta el [Resumen de los operadores bit a bit][bitwise-operators] para ver una lista completa de los operadores bit a bit disponibles en el lenguaje F#.
