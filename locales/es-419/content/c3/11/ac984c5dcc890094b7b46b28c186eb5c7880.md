# Instrucciones

Tu amiga Leticia trabaja en la oficina de objetos perdidos de una estación de metro.

Cada objeto que se encuentra se agrega como una nueva entrada en una lista de objetos del día.
Al final del mes, cualquier objeto que no haya sido reclamado se traslada a un depósito, en una caja etiquetada con la fecha en que se encontró.
Todo esto se hace en papel, así que a veces las cosas se vuelven difíciles de manejar.

Leticia te pidió ayuda para automatizar algunas de estas tareas.

~~~~exercism/note
Estas son las instrucciones mencionadas en este concepto:

| Instrucción   | Descripción                                                    |
|---------------|----------------------------------------------------------------|
| push a        | inserta a en la pila, reduciendo `rsp` en el tamaño de a        |
| pop a         | extrae a de la pila, aumentando `rsp` en el tamaño de a         |
~~~~

## 1. Crea una entrada para cada objeto

Lo primero que necesitas hacer es organizar todos los objetos, para que se puedan buscar de una manera más fácil.
Cada objeto se identifica en el almacenamiento por su ID, una descripción, la fecha en que se encontró y un número variable de categorías.

Define una función `create_item_entry` que no devuelve ningún valor e inserta una nueva entrada para un objeto en una ubicación de memoria.
Esta función puede recibir cualquier número de parámetros, de los cuales los primeros seis siempre son:

1. La dirección de una ubicación en memoria donde se debe almacenar la entrada.
2. El ID del objeto, como un entero sin signo de 64 bits.
3. La dirección de un string con la descripción del objeto.
4. El día en que se encontró el objeto, como un entero sin signo de 64 bits.
5. El mes en que se encontró el objeto, como un entero sin signo de 64 bits.
6. El número de categorías del objeto, como un entero sin signo de 64 bits.

Cada parámetro posterior es la dirección de un string con una de las categorías.

Los valores se deben almacenar en la ubicación de memoria proporcionada en el mismo orden de los argumentos: ID, descripción, día, mes, número de categorías y cada categoría en orden.

## 2. Reserva espacio para una lista mensual de objetos

Es engorroso buscar objetos en tantas listas diferentes.
Entonces, decides organizar todo en una sola lista por cada mes.
Esta lista se implementa como un array.

Define la función `create_monthly_list`, que asigna espacio en memoria para un array y devuelve la dirección de esa ubicación de memoria.
Recibe como parámetros:

1. La capacidad del array en bytes, como un entero sin signo de 64 bits.
2. Una función asignadora.

La función asignadora recibe como parámetro un entero sin signo de 64 bits que corresponde al tamaño en memoria que se debe asignar, en bytes, y devuelve la dirección del espacio asignado.

Ten en cuenta que el espacio asignado tiene un valor _indefinido_, así que se deben limpiar todos los bytes de ese espacio, es decir, su valor se debe establecer en `0`.

## 3. Inserta un objeto en la lista mensual

Cada día, cada objeto encontrado se debe insertar en la lista mensual.

Define la función `insert_found_item`, que no devuelve ningún valor y recibe como parámetros:

1. La dirección de un espacio en memoria donde se encuentra la lista mensual.
2. El número actual de entradas ya almacenadas en la lista, como un entero sin signo de 64 bits.
3. Una nueva entrada que se va a agregar a la lista.

Puedes suponer que la nueva entrada siempre cabe en la lista y que cada entrada de la lista ocupa 120 bytes de espacio.

## 4. Imprime un objeto

Buscar una entrada específica sería mucho más fácil si Leticia pudiera verla impresa en la pantalla.

Define la función `print_item`, que recibe como parámetros:

1. La dirección de un búfer donde se puede almacenar un string introductorio en ASCII terminado en NUL.
2. La dirección de un espacio en memoria donde se encuentra la lista mensual.
3. El índice de la entrada en el array del objeto que se debe imprimir, como un entero sin signo de 64 bits.
4. Una función de impresión.

Esta función no devuelve ningún valor y debe llamar a la función de impresión con los siguientes argumentos:

1. La dirección de una ubicación de memoria donde se almacena el string introductorio; o `0` (como un entero de 64 bits) si no se pasa ningún string.
2. El índice de la entrada en el array del objeto que se debe imprimir, como un entero sin signo de 64 bits.
3. El ID del objeto, como un entero sin signo de 64 bits.
4. La dirección de un string con la descripción del objeto.
5. El día en que se encontró el objeto, como un entero sin signo de 64 bits.
6. El mes en que se encontró el objeto, como un entero sin signo de 64 bits.
7. El número de categorías del objeto, como un entero sin signo de 64 bits.
8. La dirección del primer string de categoría.

El string introductorio es opcional.
Si se usa en la función de impresión, este string debe estar terminado en NUL (terminar en `0`) y tener como máximo 50 caracteres, ya considerando el terminador NUL.
De lo contrario, se debe pasar el valor `0` a la función de impresión en su lugar.

Puedes suponer que cada objeto de la lista ocupa 120 bytes de espacio.
