# Introducción

El tipo `char` de F# es un valor de 16 bits que representa los componentes direccionables más pequeños del texto, y es inmutable por defecto.

Los `char` se pueden definir como literales con comillas simples:

```fsharp
let ch = 'A'
// => val ch: char = 'A'
```

Los string son una secuencia de char.

Un `char` individual se puede obtener de un string con indexación (basada en cero):

```fsharp
"Exercism"[4] //  =>  'c'
```

Iterar sobre un string devuelve un `char` en cada paso.

El siguiente ejemplo usa una función de orden superior y una función anónima, por comodidad.
Estas se cubrirán como es debido más adelante en el temario, pero por ahora son, en esencia, una forma concisa de escribir un bucle sobre los caracteres de un string.

```fsharp
Seq.map (fun c -> c, int c) "F#"  //  =>  [('F', 70); ('#', 35)]
```

Como se muestra arriba, un `char` se puede convertir a su valor `int`.
Esto también funciona (*al menos algunas veces*) para otros sistemas de escritura:

```fsharp
Seq.map (fun c -> c, int c) "東京"  //  =>  [('東', 26481); ('京', 20140)]
```

El Int16 subyacente se usa al comparar caracteres:

```fsharp
'A' < 'D'  // =>  true
```

Además, un `int` se puede convertir a `char`:

```fsharp
char 77  // => 'M'
```

La biblioteca `System.Char` contiene el conjunto completo de métodos que se esperan de un lenguaje .NET, como las conversiones a mayúsculas/minúsculas:

```fsharp
'a' |> System.Char.ToUpper  // =>  'A'

'Q' |> System.Char.ToLower  // =>  'q'
```
