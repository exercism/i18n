# Instalación

## Instalar la CLI de Clojure
Clojure proporciona herramientas de línea de comandos que puedes usar para iniciar un REPL de Clojure, usar bibliotecas de Clojure y Java, y ejecutar programas de Clojure.

Si necesitas instalar Java, te recomendamos [Adoptium Temurin 17](https://adoptium.net/).

### Linux
Asegúrate de que estén instaladas las siguientes dependencias: `bash`, `curl`, `rlwrap` y `Java`.
Puedes instalar Clojure de cualquiera de estas 2 maneras:

1. LinuxBrew: requiere [Homebrew](https://brew.sh/)

```bash
brew install clojure/tools/clojure
```

2. Instalador por script

```bash
curl -O https://download.clojure.org/install/linux-install-1.11.1.1347.sh
chmod +x linux-install-1.11.1.1347.sh
sudo ./linux-install-1.11.1.1347.sh
```

### Homebrew para Mac OS X
Instala las herramientas de línea de comandos con brew desde el tap [clojure/tools](https://github.com/clojure/homebrew-tools):

```bash
brew install clojure/tools/clojure
```

#### Java

Cualquier distribución de Java funciona. Si lo necesitas, puedes instalar Temurin con brew:

```bash
brew tap homebrew/cask-versions
brew install --cask temurin17
```

### Windows

Clojure en Windows ha mejorado bastante últimamente. Antes recomendábamos usar WSL2, que funciona muy bien, pero ahora hay un instalador de PowerShell. Clojure en Windows está actualmente en estado alfa; consulta [clj-on-windows](https://github.com/clojure/tools.deps.alpha/wiki/clj-on-Windows#known-issues) para ver los problemas conocidos.

Asegúrate de que Java esté instalado y de que la variable de entorno `JAVA_HOME` esté definida, y ejecuta:

```powershell
iwr -useb download.clojure.org/install/win-install-1.11.1.1165.ps1 | iex
```

Otra forma de instalar Clojure en Windows es con el gestor de paquetes [Scoop](https://scoop.sh/). Para instalar scoop, abre PowerShell y ejecuta estos 2 comandos, uno después del otro:

 ```sh
 iwr -useb get.scoop.sh | iex
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser -Force
```

Para instalar Clojure con Scoop primero tienes que agregar dos buckets importantes:

```sh
# if you don't have git version control system installed
# it is required for adding new external buckets to your scoop installer
# you can skip this step otherwise
scoop install git

# add scoop bucket for Java 
scoop bucket add java

# add scoop bucket for clojure build
scoop bucket add scoop-clojure https://github.com/littleli/scoop-clojure
```

Ya podemos instalar Java y Clojure ejecutando los siguientes comandos:

```sh
# install Java runtime and compiler
scoop install adoptopenjdk-lts-hotspot

# install official clojure tools
scoop install clojure

# update to the newest version
scoop update clojure
```

Después de ejecutar los pasos anteriores correctamente, deberías poder ejecutar Clojure con lo siguiente:

```sh
clj
```

## Instalar Leiningen (opcional)

Aunque ya no es necesario, seguimos dando soporte a la completa herramienta de gestión de proyectos [Leiningen](https://leiningen.org/). Ofrece una gran variedad de tareas útiles, como pruebas cómodas, compilaciones y un REPL mejorado.

1. Descarga el [script de lein](https://raw.githubusercontent.com/technomancy/leiningen/stable/bin/lein) o [lein.bat](https://raw.githubusercontent.com/technomancy/leiningen/stable/bin/lein.bat) (Windows)
2. Colócalo en tu `$PATH` donde tu shell pueda encontrarlo (por ejemplo, `/usr/local/bin/`)
3. Hazlo ejecutable (`sudo chmod a+x /usr/local/bin/lein`)
4. Ejecuta `lein`.
