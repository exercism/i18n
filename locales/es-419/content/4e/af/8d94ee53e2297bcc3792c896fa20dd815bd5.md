# Introducción

## Interfaces

Una interfaz es un tipo que contiene miembros que definen un grupo de funcionalidad relacionada. Separa los usos de una clase de su implementación, lo que permite múltiples implementaciones diferentes o el soporte de algún comportamiento genérico, como el formato, la comparación o la conversión.

La sintaxis de una interfaz es similar a la de una clase o una estructura, con la diferencia de que los métodos y las propiedades aparecen solo como la firma y no se proporciona un cuerpo.

```csharp
public interface ILanguage
{
    string LanguageName { get; set; }
    string Speak();
}

public class ItalianTaveller : ILanguage, ICloneable
{
    public string LanguageName { get; set; } =  "Italiano";

    public string Speak()
    {
        return "Ciao mondo";
    }

    public object Clone()
    {
        ItalianTaveller it = new ItalianTaveller();
        it.LanguageName = this.LanguageName;
        return it;
    }
}
```

Todas las operaciones definidas por la interfaz deben implementarse.

Las interfaces pueden contener métodos y propiedades de instancia, entre otros miembros.

## Ordenamiento

Para permitir que un objeto se compare con otro objeto, este debe implementar la interfaz `IComparable<T>`.
Esta interfaz tiene un único método que es necesario implementar: `int CompareTo(T other)`.

El método `CompareTo` puede devolver tres valores posibles:

- Un valor menor que cero: el objeto actual es menor que el otro objeto.
- Un valor mayor que cero: el objeto actual es mayor que el otro objeto.
- Un valor igual a cero: el objeto actual es igual al otro objeto.
