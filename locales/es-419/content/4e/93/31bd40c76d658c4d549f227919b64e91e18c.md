# Anexo a las instrucciones

## Instrucciones específicas del track

### Formato de entrada

La entrada tendrá el formato de un string.
Para que este ejercicio sea apto para principiantes, no hace falta que esperes números de varios dígitos.

Los bytes 64-191 de la memoria lineal están reservados para el string de entrada.

### Formato de salida

La salida se espera en pares de fila y columna como u8 concatenados directamente.

Por ejemplo, si hay tres puntos de silla

fila: 2, columna: 1
fila: 2, columna: 2
fila: 2, columna: 3

entonces la salida esperada serían los valores u8 `2, 1, 2, 2, 2, 3`
