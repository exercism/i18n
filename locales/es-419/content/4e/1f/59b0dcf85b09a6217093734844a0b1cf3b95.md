# Instrucciones

Tu tarea es analizar un string de Smart Game Format (SGF) y devolver una estructura de datos de árbol que representa la partida.

Un string SGF representa un árbol de nodos. Todo el árbol está encerrado entre paréntesis `()`. Cada nodo del árbol se denota con un punto y coma `;`, seguido de una secuencia de propiedades. Una propiedad consiste en un identificador en mayúsculas (por ejemplo, `AB`), seguido de uno o más valores encerrados entre corchetes `[]`.

Por ejemplo, el string `(;FF[4]C[root])` representa un árbol con un único nodo raíz. Ese nodo tiene dos propiedades:
- Propiedad `FF` con un valor de `4`
- Propiedad `C` con un valor de `root`

**Variaciones (árboles y ramas)**
SGF admite variaciones de la partida al anidar árboles. Un árbol puede tener varios árboles hijos, que también se encierran entre paréntesis.
Por ejemplo, `(;A[B](;C[D])(;E[F]))` representa un nodo raíz con la propiedad `A`, que tiene dos ramas hijas:
1. Un nodo con la propiedad `C` y el valor `D`
2. Un nodo con la propiedad `E` y el valor `F`

**Formato y escapes**
Los valores entre corchetes pueden contener caracteres de escape. Una barra invertida `\` seguida de cualquier carácter representa ese carácter literal (por ejemplo, `\]` debe analizarse como un `]` literal). Además, si una nueva línea va precedida de una barra invertida, actúa como una continuación de línea y debe eliminarse del valor. Todas las demás nuevas líneas dentro de un valor deben conservarse.

**Manejo de errores**
Debes lanzar un error para los strings SGF no válidos. Los siguientes son ejemplos de SGF no válido:
- Un árbol que no empieza con paréntesis `()`.
- Un nodo que no empieza con un punto y coma `;`.
- Identificadores de propiedad que no constan únicamente de letras mayúsculas.
- Corchetes faltantes o paréntesis que no coinciden.

### Estructura de datos

Tu función de análisis debe devolver una representación del árbol. Un enfoque habitual es representar cada árbol como un objeto con dos campos:
- `properties`: Un objeto (o Map) donde las claves son los identificadores de propiedad (strings) y los valores son arrays de strings (ya que una propiedad puede tener varios valores).
- `children`: Un array que contiene los árboles hijos.


Ejemplo:

Argumento: `(;FF[4]C[root])`
Resultado: `{
  properties: {
    FF: ['4'],
    C: ['root']
  },
  children: []
}`

Argumento: `(;A[B](;C[D])(;E[F]))`
Resultado: `{
  properties: {
    A: ['B']
  },
  children: [
    {
      properties: {
        C: ['D']
      },
      children: []
    },
    {
      properties: {
        E: ['F']
      },
      children: []
    }
  ]
}`
