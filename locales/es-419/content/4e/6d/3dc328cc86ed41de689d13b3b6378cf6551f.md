# Introducción

## La sentencia _if-then_

La sentencia de control de flujo más básica en Java es la sentencia _if-then_.
Esta sentencia se usa para ejecutar una sección de código solo si se cumple una condición en particular, es decir, si es `true`.
Una sentencia _if-then_ se define con la cláusula `if`:

```java
class Car {
    void drive() {
        // the "if" clause: the car needs to have fuel left to drive
        if (fuel > 0) {
            // the "then" clause: the car drives, consuming fuel
            fuel--;
        }
    }
}
```

En el ejemplo anterior, si el auto se quedó sin combustible, llamar al método `Car.drive` no hará nada.

## La sentencia _if-then-else_

La sentencia _if-then-else_ ofrece una ruta de ejecución alternativa para cuando la condición de la cláusula `if` se evalúa como `false`.
Esta ruta de ejecución alternativa sigue a una cláusula `if` y se define con la cláusula `else`:

```java
class Car {
    void drive() {
        if (fuel > 0) {
            fuel--;
        } else {
            stop();
        }
    }
}
```

En el ejemplo anterior, si el auto se quedó sin combustible, llamar al método `Car.drive` llamará a otro método para detener el auto.

La sentencia _if-then-else_ también admite múltiples condiciones con la cláusula `else if`:

```java
class Car {
    void drive() {
        if (fuel > 5) {
            fuel--;
        } else if (fuel > 0) {
            turnOnFuelLight();
            fuel--;
        } else {
            stop();
        }
    }
}
```

En el ejemplo anterior, conducir el auto cuando el combustible es menor o igual a `5` hará que el auto avance, pero encenderá la luz de combustible.
Cuando el combustible llegue a `0`, el auto dejará de avanzar.
