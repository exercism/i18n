# Introducción

En el ejercicio anterior vimos que hay dos formas de escribir comentarios en Go: los comentarios de una sola línea, que van precedidos de `//`, y los bloques de comentarios de varias líneas, que se delimitan con `/*` y `*/`.

## Comentarios de documentación

En Go, los comentarios cumplen un papel importante en la documentación del código.
Los usa el comando `godoc`, que extrae esos comentarios para crear documentación sobre los paquetes de Go.
Un comentario de documentación debe ser una oración completa que empiece con el nombre de lo que se describe y termine con un punto.

Los comentarios deben ir antes de los paquetes y también de los identificadores exportados, por ejemplo las funciones, los métodos, las variables de paquete, las constantes y los structs exportados, sobre los cuales aprenderás más en los próximos ejercicios.

Una variable a nivel de paquete puede verse así:

```go
// TemperatureCelsius represents a certain temperature in degrees Celsius.
var TemperatureCelsius float64
```

## Comentarios de paquete

Los comentarios de paquete deben escribirse justo antes de la cláusula del paquete (`package x`) y empezar con `Package x ...`, así:

```go
// Package kelvin provides tools to convert
// temperatures to and from Kelvin.
package kelvin
```

## Comentarios de función

Un comentario de función debe escribirse justo antes de la declaración de la función.
Debe ser una oración completa que empiece con el nombre de la función.
Por ejemplo, el comentario exportado de la función `Calculate` debe tener la forma `Calculate  ...`.
También debe explicar qué argumentos recibe la función, qué hace con ellos y qué significan sus valores de retorno, y terminar con un punto):

```go
// CelsiusFreezingTemp returns an integer value equal to the temperature at which water freezes in degrees Celsius.
func CelsiusFreezingTemp() int {
	return 0
}
```
