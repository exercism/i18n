# Acerca de

En Java, los Boolean se representan con el tipo `boolean`, cuyos valores pueden ser `true` o `false`.

Java admite tres [operadores booleanos][operators]:

- `!` (NOT): niega el Boolean
- `&&` (AND): toma dos Boolean y da true si ambos son true
- `||` (OR): da true si cualquiera de los dos Boolean es true

Los operadores `&&` y `||` usan _evaluación de cortocircuito_, lo que significa que el lado derecho del operador solo se evalúa cuando es necesario.

También se conocen como operadores condicionales o lógicos.
El `!` a veces se clasifica como una operación bit a bit en la documentación, pero tiene la semántica convencional de _NOT_.

```java
true || false // => true
false || false // => false
false || true // => true
true && false // => false
true && true // => true
!true // => false
!false // => true
```

Los tres operadores booleanos tienen cada uno una [_precedencia de operadores_][precedence] diferente.
Como consecuencia, se evalúan en este orden: primero `not`, después `&&` y, por último, `||`.
Si quieres «escapar» de estas reglas, puedes encerrar una expresión booleana entre paréntesis (`()`), ya que los paréntesis tienen una precedencia de operadores aún mayor.

```java
!true && false   // => false
!(true && false) // => true
```
