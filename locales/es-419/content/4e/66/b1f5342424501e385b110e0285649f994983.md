# Instrucciones

Estás manteniendo el kit de generación de código de una estación de señales.
Cada macro es una *plantilla*: un pequeño molde que el compilador usa para
estampar código especializado en cada punto de llamada.

Solo escribes las cuatro macros. El archivo de pruebas define pequeñas
palabras envoltorio que *llaman* a tus macros (una macro solo se puede
observar a través del código que genera), y luego revisa los resultados en
tiempo de ejecución de los envoltorios. Deja los envoltorios tal como están.

En cada tarea, el cuerpo recibe en la pila los argumentos literales del punto
de llamada y debe dejar **un quotation**. Las líneas «compila a» muestran el
código lineal que debería producir tu quotation.

## 1. Dos veces

`twice` toma un quotation literal y devuelve un quotation que ejecuta el
original dos veces seguidas.

```factor
! : inc-twice ( x -- y ) [ 1 + ] twice ;
! body receives [ 1 + ]  ->  must build [ 1 + 1 + ]
5 inc-twice .   ! => 7
```

## 2. N repeticiones

`repeat-quot` toma un quotation literal y un conteo literal `n`,
y devuelve un quotation que ejecuta el original `n` veces seguidas.
`n = 0` devuelve el quotation vacío `[ ]`.

```factor
! : inc-thrice ( x -- y ) [ 1 + ] 3 repeat-quot ;
! body receives [ 1 + ] 3  ->  must build [ 1 + 1 + 1 + ]
5 inc-thrice .   ! => 8
```

## 3. Compón muchas

`compose-many` toma un array literal de quotations y devuelve un único
quotation que ejecuta cada una en orden. Un array vacío devuelve el quotation
vacío.

```factor
! : pipeline ( x -- y ) { [ 1 + ] [ 2 * ] [ 1 - ] } compose-many ;
! body receives { [ 1 + ] [ 2 * ] [ 1 - ] }  ->  must build [ 1 + 2 * 1 - ]
5 pipeline .   ! => 11
```

## 4. Iteración desenrollada

`each-literal` toma una secuencia literal y un quotation. Devuelve un
quotation que, para cada elemento de la secuencia, empuja ese elemento y
luego ejecuta el quotation: una iteración que ocurre en tiempo de
compilación, así que el código generado es lineal.

```factor
! : sum-three ( -- n ) 0 { 10 20 30 } [ + ] each-literal ;
! body receives { 10 20 30 } [ + ]  ->  must build [ 10 + 20 + 30 + ]
sum-three .   ! => 60
```

Esta es la más estructural de las cuatro: tanto la longitud de la secuencia
*como* los valores de sus elementos dan forma al código generado. Las pistas
te llevan paso a paso por su construcción.
