# Acerca de

La [sobrecarga de métodos][method-overloading] es un concepto clave en Java, pues permite que una clase tenga más de un método con el mismo nombre, siempre que cada uno tenga una lista de parámetros distinta.
Esta funcionalidad es un aspecto fundamental de la programación orientada a objetos de Java y ofrece una manera de realizar operaciones similares con distintos tipos o cantidades de argumentos.
La sobrecarga de métodos mejora la legibilidad y la organización del código, ya que permite que métodos que realizan funciones similares compartan el mismo nombre.
Es importante tener en cuenta que la sobrecarga se determina por la firma del método, que incluye el nombre del método y la lista de parámetros.

## Puntos clave

- **La firma importa**: el tipo de retorno no forma parte de la firma del método, así que cambiar solo el tipo de retorno de un método no constituye una sobrecarga.
- **Diferencias en los parámetros**: los métodos sobrecargados deben diferenciarse en la cantidad o el tipo de parámetros.
- **Uso**: la sobrecarga suele usarse para ofrecer maneras más intuitivas de usar un método con distintos tipos de argumentos.

## Ejemplos de sobrecarga de métodos

Imagina una clase `Calculator` que puede sumar números.
La sobrecarga permite distintos tipos de operaciones de suma:

```java
public class Calculator {

    public int add(int a, int b) {
        return a + b;
    }

    public double add(double a, double b) {
        return a + b;
    }

    public int add(int a, int b, int c) {
        return a + b + c;
    }
}
```

## Buenas prácticas

- **Claridad**: los métodos sobrecargados deben usarse de manera que el código resulte más intuitivo.
  - El comportamiento de los métodos sobrecargados debe estar relacionado y ser consistente.
- **Evita la ambigüedad**: asegúrate de que cada método sobrecargado tenga un propósito claro y que las diferencias en las listas de parámetros sean lo bastante significativas para evitar confusiones.
- **Documentación**: documenta adecuadamente cada versión de los métodos sobrecargados.
  - Una documentación clara ayuda a otros desarrolladores a entender el propósito y el uso de cada variante del método.
- **Tipos de retorno consistentes**: aunque los tipos de retorno pueden variar en los métodos sobrecargados, por lo general es buena práctica mantenerlos consistentes siempre que sea posible para evitar confusiones.
- **Limita la sobrecarga**: evita abusar de la sobrecarga de métodos.
  - El exceso de sobrecarga puede hacer que el código sea más difícil de leer y de mantener.

## Conclusión

La sobrecarga de métodos es una funcionalidad muy potente de Java que, cuando se usa correctamente, puede mejorar mucho la legibilidad y la flexibilidad de tu código.
Permite que los métodos sean más versátiles y se adapten a distintos contextos, lo que hace que tus programas en Java sean más modulares y fáciles de mantener.
