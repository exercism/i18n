# Null

Null es un tipo de valor primitivo con un solo valor: `null`.
A menudo se usa Null para representar la nada.
Se considera «falso», pero es distinto de `false` y de otros valores falsos.

```php
<?php

is_null(null); // => true
isset(null); // => false

null == true; // => false
null === true; // => false

null == false; // => true
null === false; // => false
```

## Trabajar con valores null

En PHP, los valores null pueden ser una causa común de errores, ya que a menudo se devuelven en lugar de un estado de error o para representar la nada.
Para evitar que surjan errores, muchas veces hay que comprobar que el valor no sea null antes de operar con él.

```php
<?php

$value = null;

$value->doSomething(); // throws an error as a null value is not an object instance.

if (!is_null($value)) {
    $value->doSomething(); // succeeds
}
```

Comprobar una y otra vez que el valor no sea null puede dar lugar a errores, así que PHP ofrece dos operadores para trabajar con valores null: el operador de acceso seguro ante null `?->` y el operador de fusión de null `??`.

```php
<?php

$value = null;
$result = $value?->doSomething(); // => return null rather than error
$result = $result ?? "default"; // => "default" is assigned to $result
```
