## Alias de tipo

En Gleam puedes usar un alias de tipo para darle un nombre conveniente a un tipo que ya existe y que de otro modo sería engorroso de escribir.

```gleam
pub type Headers =
  List(#(String, String))

pub fn html_headers() -> Headers {
  [
    #("content-type", "text/html"),
    #("x-frame-options", "DENY"),
  ]
}
```

Cuando se escribe con `pub type`, el alias se puede usar fuera del módulo en el que se define. Si omites `pub`, el alias es privado y no se puede referenciar en otros módulos.
