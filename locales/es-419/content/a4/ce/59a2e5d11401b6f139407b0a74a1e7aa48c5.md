# camelCase

[comment]: # "Este error se genera cuando una variable o un tipo no usa camelCase/PascalCase"
[comment]: # "requiere 2 parámetros:"
[comment]: # "- wrong: nombre con el uso incorrecto de mayúsculas y minúsculas"
[comment]: # "- correct: nombre con el uso correcto de mayúsculas y minúsculas"

La comunidad de Elm tiene una clara preferencia por usar camelCase para los nombres de variables y PascalCase para los tipos.

Encontramos el nombre `%{wrong}`, que debería reemplazarse por `%{correct}`.
