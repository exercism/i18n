# Enums

Los enums son un tipo de dato de Cairo que se usa para definir un conjunto de variantes predefinidas con el fin de lograr legibilidad y seguridad en el código.
En Cairo, las variantes de un `enum` se pueden declarar para que contengan distintos tipos de datos (enteros, structs, tuplas, otros enums, etc.).

El siguiente fragmento de código muestra cómo se podrían definir los enums:

```rust
#[derive(Drop)]
enum Direction {
    North,
    East,
    South,
    West,
}
```

El enum `Direction` declarado arriba es un enum simple con cuatro variantes: `North`, `East`, `South` y `West`.
La convención de nombres es usar PascalCase para las variantes del enum.
Cada variante representa un valor distinto del tipo enum `Direction`.
Cada variante en este ejemplo de enum en particular no tiene un valor asociado y se puede instanciar con esta sintaxis:

```rust
let direction = Direction::North;
```

A continuación se muestra el mismo enum `Direction`, pero con variantes que tienen valores asociados, que almacenan el grado exacto de la dirección:

```rust
#[derive(Drop)]
enum Direction {
    North: u128,
    East: u128,
    South: u128,
    West: u128,
}
```

En este ejemplo se ve claramente que cada variante del enum `Direction` tiene un valor asociado de tipo `u128`.
Este tipo de enum se puede instanciar así:

```rust
let direction = Direction::North(10);
```

## Ejemplo de enum complejo con tipos personalizados

Un enum se puede declarar con una combinación de distintos tipos de datos como sus variantes.
En el ejemplo de abajo, `Action` es un enum complejo que tiene como variantes una colección de `Quit`, `Direction`, `SendMessage`, `ChangeAvatar` y `ProfileState`.

```rust
#[derive(Drop)]
struct Move {
    up: u32,
    down: u32,
    right: u32,
    left: u32,
}

#[derive(Drop)]
enum UserCommand {
    Login,
    UpdateProfile,
    Logout,
}

#[derive(Drop)]
enum Action {
    Quit, //  variant with no associated value
    Direction: Move, // variant with the `Move` struct associated value
    SendMessage: felt252, // a single felt252 variant
    ChangeAvatarColor: (u8, u8, u8), // variant with the tuple of three associated values
    ProfileState: UserCommand // variant with an enum associated value
}
```

## Implementaciones de traits para enums

En Cairo, los traits se pueden definir e implementar en enums personalizados.
Esto te permite definir métodos y atributos asociados con un enum.
Abajo hay un ejemplo de esto, donde definimos un enum `Message` e implementamos un trait `Processing` para él:

```rust
#[derive(Drop)]
enum Message {
    Quit,
    Echo: felt252,
    Move: (u128, u128),
}

trait Processing {
    fn process(self: Message);
}

impl ProcessingImpl of Processing {
    fn process(self: Message) {
        match self {
            Message::Quit => { println!("quitting") },
            Message::Echo(value) => { println!("echoing {}", value) },
            Message::Move((x, y)) => { println!("moving from {} to {}", x, y) },
        }
    }
}
```

Así se podría usar el trait para procesar un mensaje `Quit`:

```rust
let msg: Message = Message::Quit;
msg.process(); // prints "quitting"
```

En muchas situaciones, los enums pueden resultar útiles, sobre todo cuando se usan con el flujo `match`, como en la implementación de traits de arriba.
Lee más sobre el flujo `match` en [The Cairo Book][match].
