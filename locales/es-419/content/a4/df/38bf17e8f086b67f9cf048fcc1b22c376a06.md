# Introducción

La forma especial `import` te permite usar funciones de un módulo externo sin usar el nombre del módulo.

Importar un módulo externo completo puede crear conflictos con las funciones locales que ya existen. Para evitar esto, tienes dos opciones: `:except` y `:only`. Ambas esperan una lista de palabras clave, donde la clave es el nombre de la función y el valor es la aridad de la función.

Por lo general, las importaciones se agregan al principio de la definición del módulo.

```elixir
defmodule Square do
  import Integer, only: [pow: 2]

  def area(a), do: pow(a, 2)
end
```
