# Anexo de las instrucciones

## Formato de entrada

El parámetro `board`, que representa el tablero de juego, está en el formato de un array de strings.

```javascript
['  B  ', ' B B ', 'B W B', ' W W ', '  W  '];
```

Cada carácter de un string representa una celda.
Los valores válidos para una celda son:

- ` ` un espacio en blanco que corresponde a una celda vacía
- `B` una celda que le pertenece al jugador negro
- `W` una celda que le pertenece al jugador blanco

## Formatos de salida

Se espera que la función `getTerritory` devuelva un objeto con 2 propiedades:

- `owner` El propietario del territorio (`NONE`, `BLACK` o `WHITE`)
- `territory` Un array de coordenadas que representa cada celda del territorio.

```javascript
{
    owner: 'BLACK',
    territory: [
        [0, 0],
        [0, 1],
        [1, 0],
    ],
}
```

Se espera que la función `getTerritories` devuelva un objeto con 3 propiedades:

- `territoryBlack` Un array de coordenadas que representa los territorios que le pertenecen al jugador `BLACK`
- `territoryWhite` Un array de coordenadas que representa los territorios que le pertenecen al jugador `WHITE`
- `territoryNone` Un array de coordenadas que representa los territorios que no le pertenecen a ninguno de los dos jugadores

```javascript
{
    territoryBlack: [
        [0, 0],
        [0, 1],
    ],
    territoryWhite: [
        [3, 0],
        [3, 1],
    ],
    territoryNone: [],
}
```
