# Introducción

Puedes usar una expresión `if/elif/else` para ejecutar lógica de forma condicional. F# también tiene otra forma más potente de ejecutar lógica de forma condicional: la coincidencia de patrones. Con la coincidencia de patrones, se puede comparar un valor con uno o más _patrones_. Un ejemplo de patrón es el _patrón constante_, que compara un valor con una constante (por ejemplo, `1` o `"hello"`).

En F#, la coincidencia de patrones se hace a través de la palabra clave `match`:

```fsharp
let describe number =
    match number with
    | 0 -> "Zero"
    | 1 -> "One"
```

Aunque esto puede parecerse a las sentencias `switch` de otros lenguajes, la coincidencia de patrones empieza a destacar cuando también usas otros patrones. Uno de esos patrones es el _patrón de variable_, que permite capturar un valor:

```fsharp
match number with
| 0 -> "Zero"
| i -> sprintf "Non zero: %d" i
```

En algunos casos, es posible que quieras agregar una condición adicional a un patrón. Esto se conoce como _guarda_ (cláusula), que se puede agregar usando la palabra clave `when`:

```fsharp
match number with
| 0 -> "Zero"
| i when i < 0 -> "Negative number"
```

En el ejemplo anterior, no todos los valores posibles tendrán un patrón que coincida. El compilador lo detectará y mostrará una advertencia. Esto se conoce como _comprobación exhaustiva_. Para resolver la advertencia, hay que manejar todos los casos. Para eso se puede usar el _patrón comodín_, que es un patrón que coincide con cualquier valor:

```fsharp
match number with
| i when i < 0 -> "Negative number"
| _ -> "Positive number"

// No compiler warning
```

La coincidencia de patrones compara un valor con cada patrón de arriba hacia abajo, hasta encontrar un patrón que coincida y ejecutar la lógica asociada a ese patrón. ¡El orden de los patrones importa!
