La concatenación de strings con el operador `+` es un enfoque válido, pero puede generar problemas de mantenimiento y de legibilidad.
Usar el método [str.format()][str.format()] o los [f-strings][f-strings] (_también conocidos como «literales de cadena formateados» o «cadenas interpoladas»_) puede ofrecer opciones que mejoran el mantenimiento y hacen más claro el reemplazo de variables dentro de los strings.

La entrada de blog [String Formatting in Python][string formatting in python] es un buen punto de partida para entender todas las opciones de formato de strings de Python, y [Newer Python String Format Techniques][newer python string format techniques] también ofrece buenos consejos y trucos para usar `str.format()` y `f-strings`.
