# Introducción

Recuerda que un programa de `jq` es un _pipeline de expresiones_.
La **asignación de variables** sigue esta regla: una _asignación de variable_ es una expresión que tiene esta forma:

```jq
... | expr as $varname | ...
```

## El filtro devuelve la misma entrada

Igual que la _expresión de identidad_ `.`, la salida de la _asignación de variable_ es la misma que su entrada.
Asignarle un valor a la variable es un efecto secundario.

Ejemplo que muestra que `.` después de la asignación es igual a la entrada inicial:

```sh
$ jq -c -n '42 | (. * 2) as $double | [., $double]'
[42,84]
```

## El ámbito de las variables

El ámbito de la variable es «léxico»: la variable estará dentro del ámbito durante el resto del pipeline.
Las variables que se definen en funciones (ya llegaremos a las funciones) son «locales» a la función.

## Los nombres de las variables

La variable debe empezar con `$`.
El resto del nombre de la variable es un **identificador**: empieza con una letra o un guion bajo, seguido de letras, números o guiones bajos.

## La asignación por desestructuración

Del manual:

> Se pueden declarar varias variables con una sola expresión `as` si proporcionas un patrón que _coincida con la estructura de la entrada_ (a esto se le llama «desestructuración»).

Ejemplos:

```jq
[1, 2, 3] as [$a, $b, $c]
| [$a, $b, $c]     # => [1, 2, 3]
```

```jq
{"foo": "bar", "len": [10, 20]} as {foo: $f, len: [$h, $w]}
| [$f, $h, $w]     # => ["bar", 10, 20]
```

Hacer que el nombre de la variable coincida con la _clave del objeto_ ofrece un atajo:

```jq
{"x": 4, "y": 7} as {$x, $y}
| [$x, $y]         # => [4, 7]
```

```jq
{"foo": "bar", "len": [10, 20]} as {$foo, $len}
| [$foo, $len]     # => ["bar", [10, 20]]
```

## Las constantes

Como se muestra en el ejemplo anterior, las variables son útiles para guardar constantes.
Es mejor darle un nombre a las constantes que dejar que aparezcan «números mágicos» en el código.

## Muchas veces las variables no son necesarias

A menudo es más legible omitir las variables.

Considera cómo calcular el promedio de un array de números

```jq
[2, 4, 8, 7]
| add as $sum
| length as $len
| $sum / $len
```

en comparación con

```jq
[2, 4, 8, 7] | add / length
```

Esto resalta uno de los aspectos más poderosos de `jq`: la entrada de un filtro se le proporciona a _cada_ subexpresión:

- el array de entrada `[2,4,8,7]` se le pasa a `add` (que suma los números aplicando el operador `+` a todos los elementos)
- _en paralelo_, `[2,4,8,7]` también se le pasa a `length`
- cuando estas subexpresiones terminan, sus resultados se dividen y dan como resultado el valor promedio de los números del array de entrada.
