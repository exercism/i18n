# Introducción

En Java hay dos tipos diferentes de números:

- Enteros: números sin dígitos después del separador decimal (números enteros).
  Por ejemplo: `-6`, `0`, `1`, `25`, `976` y `-500000`.
- Números de punto flotante: números con cero o más dígitos después del separador decimal.
  Por ejemplo: `-20.4`, `0.1`, `2.72`, `16.984025` y `1024.0`.

Los dos tipos numéricos más comunes en Java son `int` y `double`.
Un `int` es un entero de 32 bits y un `double` es un número de punto flotante de 64 bits.

La aritmética se hace con los operadores aritméticos estándar.
Los números se pueden comparar con los operadores de comparación numérica estándar (por ejemplo, `5 > 4` y `4 <= 5`) y con los operadores de igualdad (`==`) y desigualdad (`!=`).

Java tiene dos tipos de conversiones numéricas:

1. Conversiones implícitas: no se pierde ningún dato y no se necesita sintaxis adicional.
2. Conversiones explícitas: se podrían perder datos y se necesita sintaxis adicional en forma de _cast_.

Como un `int` tiene menos precisión que un `double`, convertir de un `int` a un `double` es seguro y, por lo tanto, es una conversión implícita.
Sin embargo, convertir de un `double` a un `int` podría significar perder datos, así que eso requiere una conversión explícita.
