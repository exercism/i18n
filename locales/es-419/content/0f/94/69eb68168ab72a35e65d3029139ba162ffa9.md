# Introducción

Una función es un bloque de código organizado y reutilizable que se usa para realizar alguna acción.
Hay varias maneras de definir funciones en JavaScript.
Aquí veremos las _declaraciones de función_ y las _expresiones de función_.
Otras posibilidades, como las [funciones flecha][concept-arrow-functions], se cubrirán en otros conceptos.

## Declaración de función

La forma estándar de definir una función en JavaScript es una _declaración de función_, también llamada _definición de función_ o _sentencia de función_.

Consiste en la palabra clave `function`, el nombre de la función y una lista de parámetros separados por comas entre paréntesis.
A esto le sigue el cuerpo de la función (el conjunto de sentencias que define qué hace una función), encerrado entre llaves.

```javascript
function someName(param1, param2, param3) {
  // ...
}
```

En JavaScript, una función se invoca (se llama) escribiendo el nombre de la función seguido de paréntesis que contienen los argumentos.

```javascript
someName(arg1, arg2, arg3);
```

## Parámetros

Cuando trabajas con parámetros dentro del cuerpo de la función, ten en cuenta los posibles efectos secundarios.

- Los valores de los [tipos de datos primitivos][mdn-primitives] son _inmutables_.
  El valor original nunca se ve afectado por lo que le ocurra al argumento dentro del cuerpo de la función.
- Para todos los demás valores (objetos, arrays, funciones), una reasignación no afectará el valor original.
  Sin embargo, si modificas ese argumento (por ejemplo, si agregas una clave a un objeto), también modificas el valor original que se pasó.

De forma predeterminada, todos los parámetros definidos en la declaración de la función son opcionales en JavaScript.
Si proporcionas menos argumentos que parámetros hay, los argumentos faltantes serán `undefined` dentro de la función; consulta [Null y Undefined][concept-null-undefined].
En muchos casos tiene sentido asignar un valor predeterminado más apropiado que `undefined`.
Esto se puede hacer especificando parámetros predeterminados directamente en la definición de la función.

```javascript
function someName(param1 = defaultValue1, param2 = defaultValue2) {
  // ...
}
```

## Sentencia return

Una sentencia `return` termina la ejecución de la función y especifica un valor que se devolverá a quien llamó a la función. Una función puede tener varias sentencias `return`.

```javascript
function checkNumber(num) {
  if (num === 0) {
    return 'You passed 0, please provide another number.';
  }

  return 'Thanks for passing such a nice number.';
}
```

El valor que devuelve una función se puede guardar en una variable.

```javascript
function sum(x, y) {
  return x + y;
}

const total = sum(5, 10);
// => 15
```

El resultado de una función que no devuelve ningún valor o que no tiene una sentencia `return` es `undefined`.
En JavaScript no hay `return` implícitos.

```javascript
function nakedReturn(a) {
  a * 2;
  return;
}

nakedReturn(1);
// => undefined

function noReturn(a) {
  a * 2;
}

noReturn(1);
// => undefined
```

En JavaScript solo puedes devolver exactamente un valor.
Si quieres pasar más información, primero debes combinarla en una sola entidad, por lo general en un [objeto][concept-objects] o un [array][concept-arrays].

```javascript
function divide(a, b) {
  return {
    quotient: Math.floor(a / b),
    remainder: a % b,
  };
}
```

## Expresión de función

Una declaración de función es una sentencia independiente.
Pero a veces es útil definir una función como parte de otra expresión, por ejemplo, en una asignación, como parámetro de una función ([callback][concept-callbacks]) o como valor en un [objeto][concept-objects].
Esto se puede hacer con una expresión de función.
Tiene la misma sintaxis que una declaración de función, solo que se puede omitir el nombre de la función para crear una _función anónima_.

```javascript
const someFunction = function (param) {
  // ...
};

someOtherFunction(function (param) {
  // ...
});

const obj = {
  someFunction: function (param) {
    // ...
  },
};
```
