# Introducción

En Cairo, uno de los conceptos fundamentales que encontrarás es el tipo `felt252`, también conocido como **elemento de campo**.
Este tipo representa números enteros dentro de un rango específico definido por un número primo grande $P$.
En este ejercicio, trabajarás exclusivamente con el tipo `felt252`, que es una parte esencial de la programación en Cairo.

El tipo `felt252` en Cairo es un tipo escalar que se usa para representar números enteros desde 0 hasta $P - 1$, donde $P$ es un número primo grande que actualmente está definido como $( 2^{251} + 17 \cdot 2^{192} + 1 )$.
Este tipo garantiza que todas las operaciones aritméticas se realicen módulo $P$, lo que lo hace distinto de los tipos de enteros estándar que puedes encontrar en otros lenguajes de programación.

Cairo ofrece soporte para operaciones aritméticas básicas con valores `felt252`:

- **Suma (`+`)**: suma dos valores `felt252`.
  Si el resultado supera $P$, se reduce módulo $P$.
- **Resta (`-`)**: resta un valor `felt252` de otro.
  Si el resultado es negativo, se ajusta para mantenerse dentro del rango sumando un múltiplo de $P$.
- **Multiplicación (`*`)**: multiplica dos valores `felt252`, y el resultado se calcula módulo $P$.
- **División (`/`)**: divide un valor `felt252` entre otro, asegurando que el resultado cumple la ecuación $( \frac{x}{y} \cdot y = x \mod P)$.
