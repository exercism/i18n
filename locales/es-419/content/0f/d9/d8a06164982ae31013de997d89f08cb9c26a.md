# Pistas

## General

- Lee la documentación sobre los [operadores de comparación][comparison-operators]
- Lee la documentación sobre [cómo ordenar listas][list-sort]
- Recuerda cómo puedes [acceder a los registros o hacer coincidencias de patrones][records]

## 1. Compara los niveles de poder

- Usa el [operador `(>)`][greater]

## 2. Encuentra el poder más alto

- Usa la [función `max`][max]

## 3. Ordena las cartas

- Usa la [función `List.sortBy`][sort-by]

## 4. Primero las cartas más geniales

- Usa las funciones [`List.sortBy`][sort-by] o [`List.sortWith`][sort-with]
- Puedes usar tuplas para ordenamientos jerárquicos

## 5. Poder brillante

- Puedes definir explícitamente un orden o usar la [función `compare`][compare] con un valor específico
- Puedes usar tuplas para ordenamientos jerárquicos

## 6. Haz tus apuestas

- Usa `compareShinyPower` en `expectedWinner`
- Usa un `case` para [hacer coincidir el orden con un patrón][pattern-match]
