# Invierte el `if` para que el camino feliz quede a la izquierda

Para simplificar, invierte la condición del `if` que maneja el caso de error y luego elimina la rama `else` devolviendo dentro del `if`.
Un proverbio de Go dice «[el camino feliz va alineado a la izquierda](https://medium.com/@matryer/line-of-sight-in-code-186dd7cdea88)», lo que significa que el flujo normal del control sigue el margen izquierdo y que solo los casos excepcionales o de error llevan sangría.
