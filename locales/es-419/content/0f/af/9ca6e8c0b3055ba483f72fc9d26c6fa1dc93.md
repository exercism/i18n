# Pistas

## 1. Imprime una insignia para un empleado

- Puedes usar la [interpolación de string][string-interpolation] para crear strings de descripción.
- Existe un [método integrado para convertir un string a mayúsculas][to-upper-case].

## 2. Imprime una insignia para un empleado nuevo

- Debes verificar si el ID es `null` antes de usarlo.
- Puedes usar los [operadores de igualdad][equality-operators] para comparar el valor con `null`.

## 3. Imprime una insignia para el dueño

- Debes verificar si el departamento es `null` antes de usarlo.
- Puedes usar los [operadores de igualdad][equality-operators] para comparar el valor con `null`.
