# Instalación

## ¿Qué awk tengo?

El track de AWK de Exercism usa `gawk`, el AWK de GNU.
Puede que ya lo tengas; para comprobarlo, ejecuta este comando
```sh
awk --version
```

Si eso devuelve:

* algo como `GNU Awk 5.1.0 ...`
    - Ya tienes GNU awk y puedes continuar con los ejercicios.

* algo como `awk version 20200816`
    - Esto es `nawk`, también conocido como BWK awk (por Brian Kernighan) o «one true awk».
    - Esto es lo que viene incluido con MacOS y los sistemas BSD.
    - Lee más abajo las instrucciones de instalación.

* el error `awk: not an option: --version`
    - Probablemente tienes `mawk`.
    - Confírmalo con: `awk -W version`, que puede devolver `mawk 1.3.4 20200120`.
    - mawk es una implementación de awk muy buena y rápida, pero no tiene algunas de las funcionalidades específicas de gawk que usaremos en el track.
    - Lee más abajo las instrucciones de instalación.

* el error `awk: unrecognized option: version` seguido de `BusyBox v1.35.0 ...`
    - Puede que estés usando Alpine Linux.
    - Lee más abajo las instrucciones de instalación.

* un error de «command not found»
    - Entonces, o tu PATH está mal configurado o simplemente no tienes awk instalado.
    - Lee más abajo las instrucciones de instalación.

### Linux

Varía según el gestor de paquetes de tu distribución. Normalmente:
```sh
apt install gawk
yum install gawk
apk add gawk
# and so on
```
Puede que necesites usar `sudo` para ejecutar el comando correspondiente.

### MacOS

[Homebrew][brew] es tu mejor aliado. Sigue el enlace para instalarlo y luego ejecuta:
```sh
brew install gawk
```

### Windows

Para [WSL][wsl], consulta las instrucciones para Linux de arriba.
Para cygwin, instala el paquete `gawk`.

### Compilar desde el código fuente

Para los valientes, hay instrucciones [disponibles en el manual de `gawk`][build].
