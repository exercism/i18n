# Anexo de instrucciones

## Instrucciones específicas de la pista

En el ejercicio «Yacht» crearás un verbo que calcula la puntuación de una sola tirada de cinco dados en el juego Yacht, según la categoría elegida.

Para este ejercicio, tu verbo recibirá dos argumentos:

- **Argumento izquierdo**: un string que representa la categoría de puntuación que se aplicará a la tirada de dados.
- **Argumento derecho**: un array de enteros que representa los cinco dados que salieron.

Tu verbo debe estar definido para manejar estos argumentos de la siguiente manera:

```j
  category =. 'Full House'
  dice     =. 1 3 3 3 5
  
  category scoreYacht dice
```
