# Instrucciones

En este ejercicio, vas a implementar la lógica de una misión para un nuevo juego de rol que está desarrollando un amigo.
La protagonista del juego es Annalyn, una niña valiente que tiene un perro feroz y leal.
Por desgracia, ocurre un desastre: su mejor amigo fue secuestrado mientras buscaba bayas en el bosque.
Annalyn intentará encontrar y liberar a su mejor amigo, y puede llevar a su perro con ella en esta misión.

Después de seguir durante un tiempo el rastro de su mejor amigo, encuentra el campamento en el que está prisionero.
Resulta que hay dos secuestradores: un caballero poderoso y un arquero astuto.

Una vez que encuentra a los secuestradores, Annalyn considera cuáles de las siguientes acciones puede llevar a cabo:

- _Ataque rápido_: se puede hacer un ataque rápido si el caballero está dormido, ya que tarda un tiempo en ponerse la armadura, así que estará vulnerable.
- _Espiar_: se puede espiar al grupo si al menos uno de ellos está despierto.
  De lo contrario, espiar es una pérdida de tiempo.
- _Hacer señales al prisionero_: se le pueden hacer señales al prisionero usando sonidos de pájaros si el prisionero está despierto y el arquero está dormido, ya que los arqueros están entrenados en hacer señales con sonidos de pájaros, por lo que podrían interceptar el mensaje.
- _Liberar al prisionero_: Annalyn puede intentar entrar a escondidas al campamento para liberar al prisionero.
  Es algo arriesgado y solo puede salir bien de una de dos maneras:
  - Si Annalyn lleva a su perro con ella, puede rescatar al prisionero si el arquero está dormido.
    El caballero le tiene miedo al perro y el arquero no tendrá tiempo de prepararse antes de que Annalyn y el prisionero puedan escapar.
  - Si Annalyn no lleva a su perro, ¡ella y el prisionero tendrán que ser muy sigilosos!
    Annalyn puede liberar al prisionero si el prisionero está despierto y el caballero y el arquero están ambos dormidos, pero si el prisionero está dormido no se le puede rescatar: el prisionero se asustaría con la aparición repentina de Annalyn y despertaría al caballero y al arquero.

Tienes cuatro tareas: implementar la lógica para determinar si las acciones anteriores están disponibles según el estado de los tres personajes que hay en el bosque y si el perro de Annalyn está presente o no.

## 1. Comprobar si se puede hacer un ataque rápido

Define la función `CanFastAttack()` que recibe un valor Boolean que indica si el caballero está despierto.
Esta función devuelve `true` si se puede hacer un ataque rápido según el estado del caballero.
De lo contrario, devuelve `false`:

```go
var knightIsAwake = true
fmt.Println(CanFastAttack(knightIsAwake))
// Output: false
```

## 2. Comprobar si se puede espiar al grupo

Define la función `CanSpy()` que recibe tres valores Boolean, que indican si el caballero, el arquero y el prisionero, respectivamente, están despiertos.
La función devuelve `true` si se puede espiar al grupo, según el estado de los tres personajes.
De lo contrario, devuelve `false`:

```go
var knightIsAwake = false
var archerIsAwake = true
var prisonerIsAwake = false
fmt.Println(CanSpy(knightIsAwake, archerIsAwake, prisonerIsAwake))
// Output: true
```

## 3. Comprobar si se le pueden hacer señales al prisionero

Define la función `CanSignalPrisoner()` que recibe dos valores Boolean, que indican si el arquero y el prisionero, respectivamente, están despiertos.
La función devuelve `true` si se le pueden hacer señales al prisionero, según el estado de los dos personajes.
De lo contrario, devuelve `false`:

```go
var archerIsAwake = false
var prisonerIsAwake = true
fmt.Println(CanSignalPrisoner(archerIsAwake, prisonerIsAwake))
// Output: true
```

## 4. Comprobar si se puede liberar al prisionero

Define la función `CanFreePrisoner()` que recibe cuatro valores Boolean.
Los tres primeros parámetros indican si el caballero, el arquero y el prisionero, respectivamente, están despiertos.
El último parámetro indica si el perro de Annalyn está presente.
La función devuelve `true` si se puede liberar al prisionero según el estado de los tres personajes y la presencia del perro de Annalyn.
De lo contrario, devuelve `false`:

```go
var knightIsAwake = false
var archerIsAwake = true
var prisonerIsAwake = false
var petDogIsPresent = false
fmt.Println(CanFreePrisoner(knightIsAwake, archerIsAwake, prisonerIsAwake, petDogIsPresent))
// Output: false
```
