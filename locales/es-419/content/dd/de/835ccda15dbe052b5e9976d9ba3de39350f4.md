# Introducción

Haxe tiene algunos operadores unarios y binarios para realizar manipulación a nivel de bits:

- `&`: AND a nivel de bits
- `|`: OR a nivel de bits
- `^`: XOR a nivel de bits
- `~`: NEGACIÓN a nivel de bits
- `<<`: desplazamiento a la izquierda
- `>>`: desplazamiento a la derecha
- `>>>`: desplazamiento a la derecha sin signo
