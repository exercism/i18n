# Instructions

En este ejercicio necesitas implementar algunas funciones para manipular una lista de lenguajes de programación.

## 1. Define una función que devuelva una lista de lenguajes vacía

Define la función `new`, que no recibe argumentos y devuelve una lista vacía.

```haskell
new
-- -> []
```

## 2. Define una función para agregar un lenguaje a la lista

Define la función `add/2`, que recibe 2 argumentos (una _lista de lenguajes_ y un literal de string de un _lenguaje_).
Debe devolver la lista resultante con el nuevo lenguaje agregado al inicio de la lista dada.

```haskell
add new "Clojure"
-- -> ["Clojure"]
add ["Clojure"] "Haskell"
-- -> ["Haskell", "Clojure"]
```

## 3. Define una función para eliminar un lenguaje de la lista

Define la función `remove`, que recibe 1 argumento (una _lista de lenguajes_).
Debe devolver la lista sin el primer elemento. Supón que la lista siempre tendrá al menos un elemento.

```haskell
remove ["Haskell", "Clojure", "Erlang"]
-- -> ["Clojure", "Erlang"]
```

## 4. Define una función que devuelva el primer elemento de la lista

Define la función `first`, que recibe 1 argumento (una _lista de lenguajes_).
Debe devolver el primer lenguaje de la lista.
Supón que la lista siempre tendrá al menos un elemento.

```haskell
first ["Elixir", "Haskell", "Clojure", "Prolog"]
-- -> "Elixir"
```

## 5. Define una función que devuelva cuántos lenguajes hay en la lista

Define la función `count`, que recibe 1 argumento (una _lista de lenguajes_). 
Debe devolver la cantidad de lenguajes que hay en la lista.

```haskell
count ["Prolog", "Elm"]
-- -> 2
```

## 6. Define una función que determine si la lista incluye un lenguaje funcional

Define la función `isFunctionalList`, que recibe 1 argumento (una _lista de lenguajes_). 
Debe devolver un valor Boolean. 
Debe devolver `True` si _"Haskell"_ es uno de los lenguajes de la lista.

```haskell
isFunctionalList ["Haskell"]
-- -> True
```
