# Anexo de instrucciones

## Cómo agregar métodos a la clase Array

Este ejercicio se centra en agregar métodos a la clase `Array` de Crystal.
Para lograrlo, tendrás que definir una clase con el nombre `Array(T)`.
Y colocar los métodos dentro de esta clase.

```crystal
class Array(T)
  # your solution here
end
```

La clase Array es una clase [genérica][generic], y también es [indexable][indexable] y [enumerable][enumerable].
Puedes encontrar el código fuente de la clase `Array` [aquí][array].

[generic]: https://crystal-lang.org/docs/syntax_and_semantics/generics.html
[indexable]: https://crystal-lang.org/api/Indexable.html
[enumerable]: https://crystal-lang.org/api/Enumerable.html
