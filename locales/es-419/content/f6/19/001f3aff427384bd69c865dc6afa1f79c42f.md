# Instrucciones

En toda obra de teatro escolar, cada papel tiene un suplente: alguien que puede entrar en escena y hacer lo que el papel necesita, sin que el director de escena sepa quién es.

Las cinco tareas van en la clase `UNDERSTUDY`. Las dos primeras son rutinas comunes que las tareas posteriores van a vincular.

## 1. Dos maneras de decir una línea

Escribe `shout`, que devuelve la línea en mayúsculas, y `whisper`, que la devuelve en minúsculas con `"..."` en cada extremo.

```sather
UNDERSTUDY::shout("who's there")
-- => "WHO'S THERE"
UNDERSTUDY::whisper("Who's There")
-- => "...who's there..."
```

## 2. Ensaya una línea

`rehearse` recibe una línea y una manera de decirla, y devuelve el resultado. Su segundo argumento tiene el tipo `ROUT{STR}:STR`.

```sather
UNDERSTUDY::rehearse("who's there", bind(UNDERSTUDY::shout(_)))
-- => "WHO'S THERE"
```

## 3. La escena completa

`run_scene` recibe un array de líneas y una manera de decirlas, y las devuelve todas dichas así, unidas con `" "`.

```sather
UNDERSTUDY::run_scene(|"Enter", "Exit"|, bind(UNDERSTUDY::shout(_)))
-- => "ENTER EXIT"
```

Una escena vacía es el string vacío.

## 4. Devuelve una manera de decir las cosas

`understudy_for` recibe el nombre de un estilo (`"shout"` o cualquier otra cosa) y devuelve un `ROUT{STR}:STR`. Si es `"shout"`, devuelve la que grita; cualquier otra cosa devuelve la que susurra.

```sather
part ::= UNDERSTUDY::understudy_for("shout");
part.call("who's there")
-- => "WHO'S THERE"
```

## 5. Fija un argumento

Escribe `repeat`, que recibe un número de veces y una línea, y devuelve la línea repetida esa cantidad de veces sin nada en medio:

```sather
UNDERSTUDY::repeat(3, "Ha")
-- => "HaHaHa"
```

Luego escribe `doubler`, que no recibe argumentos y devuelve un `ROUT{STR}:STR` que repite dos veces lo que se le dé, vinculando `repeat` con el número ya fijado.

```sather
UNDERSTUDY::doubler.call("Ha")
-- => "HaHa"
```
