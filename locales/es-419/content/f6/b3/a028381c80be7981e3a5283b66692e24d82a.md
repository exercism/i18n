# Pistas

## General

- Los índices de `Vector` empiezan en `1`.
- Las barajas de cartas no contienen cartas duplicadas.

## 1. Determinar si una carta está presente

- Hay un método [`in`/`∈`](https://docs.julialang.org/en/v1/base/collections/#Base.in) en Base para determinar si una colección contiene un valor.

## 2. Encontrar la posición de una carta

- Hay un método [`findfirst`](https://docs.julialang.org/en/v1/base/arrays/#Base.findfirst-Tuple{Function,%20Any}) en Base para encontrar la posición del primer elemento de una colección que coincida con un predicado dado.
- `==(x)` se puede usar como predicado para encontrar elementos que sean iguales a `x` en los métodos que aceptan funciones de predicado.

## 3. Determinar si cada carta es par

- Hay un método [`all`](https://docs.julialang.org/en/v1/base/collections/#Base.all-Tuple{AbstractArray,%20Any}) en Base que devuelve `true` si todos los elementos de una colección cumplen con un predicado dado.
- [`iseven`](https://docs.julialang.org/en/v1/base/numbers/#Base.iseven) es una función de predicado.

## 4. Comprobar si la baraja contiene una carta con valor impar

- Hay un método [`any`](https://docs.julialang.org/en/v1/base/collections/#Base.any-Tuple{AbstractArray,%20Any}) en Base que devuelve `true` si algún elemento de una colección cumple con un predicado dado.
- [`isodd`](https://docs.julialang.org/en/v1/base/numbers/#Base.isodd) es una función de predicado.

## 5. Determinar la posición de la primera carta que es par

- Hay un método [`findfirst`](https://docs.julialang.org/en/v1/base/arrays/#Base.findfirst-Tuple{Function,%20Any}) en Base para encontrar la posición del primer elemento de una colección que coincida con un predicado dado.
- [`iseven`](https://docs.julialang.org/en/v1/base/numbers/#Base.iseven) es una función de predicado.

## 6. Obtener la primera carta impar de la baraja

- Puedes obtener el `n`-ésimo valor de un vector `v` con `v[n]`.
- Hay un método [`findfirst`](https://docs.julialang.org/en/v1/base/arrays/#Base.findfirst-Tuple{Function,%20Any}) en Base para encontrar la posición del primer elemento de una colección que coincida con un predicado dado.
- Si ningún elemento de la colección dada coincide con el predicado que se le pasa a `findfirst`, `findfirst` devuelve `nothing`.
- Repasa cómo funciona `nothing` en Julia: [concept:julia/nothingness](../../../../concepts/nothingness/about.md)
- Repasa cómo funcionan los condicionales en Julia: [concept:julia/conditionals](../../../../concepts/conditionals/about.md)
