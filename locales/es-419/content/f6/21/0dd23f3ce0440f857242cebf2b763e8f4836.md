# Acerca de

Aunque Swift ofrece mucha funcionalidad en su biblioteca estándar, puedes acceder a muchas más si importas bibliotecas y frameworks externos.
Estos módulos pueden venir directamente del proyecto Swift (como [Swift Argument Parser][argument-parser]), de frameworks de las plataformas de Apple (como [Foundation][apple-foundation] y [Network Framework][network-framework]) o de bibliotecas de código abierto de terceros (como [SwiftyBeaver][swifty-beaver]).

Los módulos centrales como Foundation, una de las bibliotecas más usadas de Swift, vienen incluidos con la cadena de herramientas de Swift.
Las bibliotecas de terceros deben agregarse a la configuración de tu proyecto (por ejemplo, con Swift Package Manager) antes de poder importarlas.

Para importar un módulo, escribe la palabra clave `import` seguida del nombre del módulo:

```swift
import Foundation
```

Importar un módulo hace que sus tipos, métodos y funciones estén disponibles en tu código.
Por ejemplo, importar Foundation extiende `String` con métodos de utilidad muy prácticos como `components(separatedBy:)`.

Por convención, las sentencias `import` se colocan al inicio de un archivo de Swift, para que las dependencias sean visibles de inmediato para quien lea el código.

[argument-parser]: https://apple.github.io/swift-argument-parser/documentation/argumentparser/
[network-framework]: https://developer.apple.com/documentation/network
[swifty-beaver]: https://github.com/SwiftyBeaver/SwiftyBeaver
[apple-foundation]: https://developer.apple.com/documentation/foundation
