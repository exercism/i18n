# Pistas

## General

- Recuerda que una asignación de variable es una expresión dentro de un pipeline y devuelve el mismo valor que recibió como entrada.
- Usa [el operador alternativo `//`][alternative] para proporcionar valores predeterminados.

## 1. Define el tiempo esperado en el horno, en minutos

- Define una variable que contenga el valor del tiempo esperado.
- Incluye el valor en el objeto de salida, en la clave `"expected_minutes_in_oven"`.
- El atajo de construcción de objetos `{$foo}` es lo mismo que `{foo: $foo}`.

## 2. Calcula el tiempo restante en el horno, en minutos

- Incluye el valor calculado en el objeto de salida, en la clave `"remaining_minutes_in_oven"`.
- [El operador `-`][subtraction] se usa para hacer restas aritméticas con números.

## 3. Calcula el tiempo de preparación, en minutos

- Incluye el valor calculado en el objeto de salida, en la clave `"preparation_time"`.
- [El operador `*`][multiplication] se usa para hacer multiplicaciones aritméticas con números.
- Un buen estilo sugiere usar una variable para ponerle nombre al «valor mágico» del tiempo empleado por capa.

## 4. Calcula el tiempo total de trabajo, en minutos

- Incluye el valor calculado en el objeto de salida, en la clave `"total_time"`.
- [El operador `+`][addition] se usa para hacer sumas aritméticas con números.

[subtraction]: https://jqlang.org/manual/#subtraction
[multiplication]: https://jqlang.org/manual/#multiplication-division-modulo
