# Instrucciones

En este ejercicio eres un gran fanático del deporte y acabas de descubrir tu pasión por el básquetbol de la NBA. Como eres nuevo en el básquetbol de la NBA, estás haciendo una inmersión profunda en la historia de la NBA: llevas un registro de equipos, entrenadores y sus estadísticas de victorias y derrotas, y los comparas entre sí.

Como todavía no tienes un equipo favorito, también vas a desarrollar un algoritmo para determinar si deberías apoyar a un equipo en particular.

Tienes siete tareas que te ayudarán a desarrollar tu algoritmo patentado para _apoyar a un equipo_.

## 1. Define el modelo

Define el registro `Coach` con los siguientes dos campos:

- `Name`: el nombre del entrenador, de tipo `string`.
- `FormerPlayer`: indica si el entrenador fue un exjugador, de tipo `bool`.

Define el registro `Stats` con los siguientes dos campos:

- `Wins`: la cantidad de victorias, de tipo `int`.
- `Losses`: la cantidad de derrotas, de tipo `int`.

Define el registro `Team` con los siguientes tres campos:

- `Name`: el nombre del equipo, de tipo `string`.
- `Coach`: el entrenador del equipo, de tipo `Coach`.
- `Stats`: las estadísticas del equipo, de tipo `Stats`.

## 2. Crea el entrenador de un equipo

Implementa la función `createCoach` que toma como parámetros el nombre del entrenador y su condición de exjugador, y devuelve su registro `Coach`:

```fsharp
createCoach "Larry Bird" true
// => { Name = "Larry Bird"; FormerPlayer = true }
```

## 3. Crea las estadísticas de un equipo

Implementa la función `createStats` que toma como parámetros el número de victorias y el número de derrotas, y devuelve su registro `Stats`:

```fsharp
createStats 58 24
// => { Wins = 58; Losses = 24 }
```

## 4. Crea un equipo

Implementa la función `createTeam` que toma como parámetros el nombre del equipo, el entrenador y el registro, y devuelve su registro `Team`:

```fsharp
let coach = createCoach "Larry Bird" true
let record = createStats 58 24
createTeam "Indiana Pacers" coach record
// => { Name = "Indiana Pacers"
//      Coach = { Name = "Larry Bird"; FormerPlayer = true }
//      Stats = { Wins = 58; Losses = 24 } }
```

## 5. Reemplaza al entrenador

Como los dueños de los equipos de la NBA son impacientes, descubriste que los malos resultados del equipo a menudo llevaban a que reemplazaran al entrenador. Implementa la función `replaceCoach` que toma como parámetros el equipo y su nuevo entrenador, y devuelve el equipo pero con el nuevo entrenador:

```fsharp
let coach = createCoach "Larry Bird" true
let record = createStats 58 24
let team = createTeam "Indiana Pacers" coach record

let newCoach = createCoach "Isiah Thomas" true
replaceCoach team newCoach
// => { Name = "Indiana Pacers"
//      Coach = { Name = "Isiah Thomas"; FormerPlayer = true }
//      Stats = { Wins = 58; Losses = 24 } }
```

## 6. Comprueba si es el mismo equipo

Mientras profundizas en las estadísticas, mantienes listas de equipos y sus registros. A veces te equivocas y hay entradas duplicadas en tu lista. Implementa la función `isSameTeam` que toma dos equipos y devuelve `true` si son el mismo equipo; de lo contrario, devuelve `false`:

```fsharp
let pacersCoach = createCoach "Larry Bird" true
let pacersStats = createStats 58 24
let pacersTeam = createTeam "Indiana Pacers" pacersCoach pacersStats

let lakersCoach = createCoach "Del Harris" false
let lakersStats = createStats 61 21
let lakersTeam = createTeam "LA Lakers" lakersCoach lakersStats

isSameTeam pacersTeam lakersTeam
// => false
```

## 7. Comprueba si deberías apoyar a un equipo

Después de analizar muchos equipos y partidos, ideaste un algoritmo. Si se cumple alguna de las siguientes condiciones, apoyas a ese equipo:

- El nombre del entrenador es «Gregg Popovich»
- El entrenador es un exjugador
- El nombre del equipo es «Chicago Bulls»
- El equipo ha ganado 60 partidos o más
- El equipo tiene más derrotas que victorias

Implementa la función `rootForTeam` que toma un equipo y devuelve `true` si deberías apoyar a ese equipo; de lo contrario, `return` false:

```fsharp
let spursCoach = createCoach "Gregg Popovich" false
let spursStats = createStats 56 26
let spursTeam = createTeam "San Antonio Spurs" spursCoach spursStats
rootForTeam spursTeam
// => true
```
