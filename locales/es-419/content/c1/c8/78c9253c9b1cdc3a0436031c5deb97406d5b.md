# Introducción

La vinculación describe desde qué parte del código se puede acceder a un identificador.
Los valores con ámbito de bloque, de función o de prototipo de función no tienen vinculación.
Esto significa que no se puede acceder a ellos desde fuera de su ámbito.
Para obtener más información sobre el ámbito, consulta el [concepto de ámbito](../scope/introduction.md#Introduction).

## Vinculación externa

De forma predeterminada, los identificadores con ámbito de archivo tienen vinculación externa.
Se puede llamar a un identificador con vinculación externa desde cualquier archivo del programa.

## Vinculación interna

Puedes hacer que un identificador con ámbito de archivo tenga vinculación interna usando el especificador `static`.
Un identificador con vinculación interna solo se puede usar dentro de su archivo.

Por ejemplo

```c
int public_count = 0; // file scope, external linkage by default
static int private_count = 0;  // file scope, internal linkage 

// file scope, internal linkage
static void some_function()
{
    // code snipped
}

// file scope, external linkage by default
int main()
{
    // code snipped
}
```

No debes confundir la vinculación estática con la duración de almacenamiento estática.
Para obtener más información sobre la duración de almacenamiento estática, consulta el [concepto de duración de almacenamiento](https://github.com/exercism/c/blob/main/concepts/storage-class-specifiers/about.md#static-the-storage-specifier-not-to-be-confused-with-the-static-linkage-type).
