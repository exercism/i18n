# Introducción

SGF (Smart Game Format) es un formato de archivo basado en texto, muy popular, que se usa para guardar registros de partidas de juegos de mesa. Aunque se puede usar para muchos juegos distintos, como el ajedrez, el Othello y el backgammon, es más conocido y se usa sobre todo para el juego de Go.

Un archivo SGF está estructurado como un árbol de nodos. Esta estructura de árbol resulta especialmente útil porque permite que los registros de partidas se ramifiquen, lo que significa que puedes guardar la secuencia principal de movimientos y también variantes alternativas, análisis y comentarios, todo en el mismo archivo.

Cada nodo del árbol contiene un conjunto de propiedades, y cada propiedad tiene uno o más valores. Estas propiedades codifican desde los nombres y rangos de los jugadores hasta el resultado de la partida, el tamaño del tablero y cada uno de los movimientos colocados en él.
