# Anexo de instrucciones

## Pistas

Para completar este ejercicio, necesitas crear el tipo de dato `CustomSet`,
con instancias de `Eq` y `Show`, e implementar las siguientes funciones:

- `delete`
- `difference`
- `empty`
- `fromList`
- `insert`
- `intersection`
- `isDisjointFrom`
- `isSubsetOf`
- `member`
- `null`
- `size`
- `toList`
- `union`

Encontrarás una declaración de datos ficticia y las firmas de tipo ya puestas,
pero depende de ti definir las funciones y crear un tipo de dato, un newtype
o un sinónimo de tipo que tenga sentido.

Si te interesa escribir una implementación eficiente pero no sabes bien
por dónde empezar, la mejor introducción que conozco es «Purely Functional
Data Structures», de Chris Okasaki, de la cual puedes leer una versión aquí:
https://www.cs.cmu.edu/~rwh/theses/okasaki.pdf
