# Apéndice de instrucciones

## Formato de entrada

Cada lista de entradas se representa como un string terminado en nulo, con un carácter de nueva línea al final de cada entrada.

Un ejemplo sería `"nail\nshoe\nhorse\nrider\nmessage\nbattle\nkingdom\n"`

## Registros

| Registro | Uso          | Tipo    | Descripción                                                    |
| -------- | ------------ | ------- | -------------------------------------------------------------- |
| `$a0`    | entrada      | dirección | string de entrada terminado en nulo con una nueva línea después de cada entrada |
| `$a1`    | entrada/salida | dirección | string de salida terminado en nulo                            |
| `$t0-9`  | temporal     | cualquiera | para almacenamiento temporal                                |
