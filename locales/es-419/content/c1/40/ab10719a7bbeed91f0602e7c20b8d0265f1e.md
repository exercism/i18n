# Introducción

## Coincidencia de patrones

Una expresión `if/elif/else` se puede usar para ejecutar lógica de forma condicional. F# también tiene otra forma más potente de ejecutar lógica de forma condicional: la coincidencia de patrones. Con la coincidencia de patrones, un valor se puede probar contra uno o más _patrones_. Un ejemplo de este tipo de patrón es el _patrón constante_, que hace coincidir un valor con una constante (por ejemplo, `1` o `"hello"`).

En F#, la coincidencia de patrones se hace a través de la palabra clave `match`:

```fsharp
let describe number =
    match number with
    | 0 -> "Zero"
    | 1 -> "One"
```

Aunque esto pueda parecer una sentencia `switch` de otros lenguajes, la coincidencia de patrones empieza a brillar cuando además se usan otros patrones. Uno de esos patrones es el _patrón de variable_, que permite capturar un valor:

```fsharp
match number with
| 0 -> "Zero"
| i -> sprintf "Non zero: %d" i
```

En algunos casos, quizás quieras agregar una condición adicional a un patrón. Esto se conoce como una _guarda_ (cláusula), que se puede agregar usando la palabra clave `when`:

```fsharp
match number with
| 0 -> "Zero"
| i when i < 0 -> "Negative number"
```

En el ejemplo anterior, no todos los argumentos posibles tendrán un patrón que coincida. El compilador detectará esto y emitirá una advertencia. A esto se le conoce como _verificación exhaustiva_. Para resolver la advertencia, hay que manejar todos los casos. Para esto se puede usar el _patrón comodín_, que es un patrón que coincide con cualquier valor:

```fsharp
match number with
| i when i < 0 -> "Negative number"
| _ -> "Positive number"

// No compiler warning
```

La coincidencia de patrones probará un valor contra cada patrón de arriba hacia abajo, hasta que encuentre un patrón que coincida y ejecute la lógica asociada con ese patrón. ¡El orden de los patrones importa!
