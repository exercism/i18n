# Marcador de posición

## Valores ASCII

Este ejercicio requiere convertir caracteres ASCII a su valor numérico y de vuelta. La [extensión ordchr][ordchr] de GNU awk ofrece esta funcionalidad. Para agregar las funciones `ord()` y `chr()`, carga la extensión `ordchr` agregando una directiva `@load` al inicio de tu archivo:

```
@load "ordchr"
```

[ordchr]: https://www.gnu.org/software/gawk/manual/gawk.html#Extension-Sample-Ord
