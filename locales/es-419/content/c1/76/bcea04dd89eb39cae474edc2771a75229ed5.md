# Apéndice de instrucciones

## Implementación

En este ejercicio vas a implementar un procedimiento que se encarga de reservar el string que devuelve. Liberar ese string es responsabilidad de quien llama al procedimiento.

```odin
// The procedure will be called like that:
converted := convert(3)
// ...
// and eventually the caller will delete the string
delete(converted)
```
