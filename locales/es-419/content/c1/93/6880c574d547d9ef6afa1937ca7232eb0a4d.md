# Acerca de

Una [función de orden superior](https://docs.microsoft.com/en-us/dotnet/fsharp/introduction-to-functional-programming/first-class-functions) es una función que cumple una de estas dos cosas:

- Toma una función como argumento
- Devuelve una función

Un argumento de función es simplemente un argumento normal, aunque uno que puedes invocar.

```fsharp
let double = fun x -> x * 2

let apply f x = f x

apply double 3
// => 6
```
