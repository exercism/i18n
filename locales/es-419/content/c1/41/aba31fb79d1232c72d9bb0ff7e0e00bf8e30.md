# Acerca de

Los [símbolos][symbols] son identificadores con nombre que se pueden usar para referirse a un valor.
Los símbolos se crean mediante un literal de símbolo, que consiste en anteponer el carácter `:` a un nombre, por ejemplo, `:foo`.
También se pueden escribir entre comillas, por ejemplo, `:"foo"`, lo que permite, por ejemplo, espacios en el nombre.

```ruby
:foo # => :foo
:"foo boo" # => :"foo boo"
```

Los símbolos se usan en muchos lugares del lenguaje, incluso como claves en los hashes, para representar nombres de métodos y de variables.

## Identificador

Lo que hace diferentes a los símbolos de los strings es que son identificadores y no representan datos ni texto.
Esto significa que dos símbolos con el mismo nombre siempre son el mismo objeto.

```ruby
"foo".object_id # => 60
"foo".object_id # => 80
:foo.object_id # => 1086748
:foo.object_id # => 1086748
```

## Modificar símbolos

Los símbolos son inmutables, lo que significa que no se pueden modificar.
Esto significa que cuando «modificas» un símbolo, en realidad estás creando un símbolo nuevo.
Hay algunos métodos que se pueden usar para manipular símbolos y todos devuelven símbolos nuevos.
Todos los métodos se pueden encontrar en la [API de Symbol][symbols-api].

```ruby
:foo.upcase # => :FOO

:foo.object_id # => 1086748
:foo.upcase.object_id # => 60
```

La ventaja de que los símbolos sean inmutables es que son más eficientes en memoria que los strings, y además más seguros de usar como identificadores.

## Conversión

Los símbolos se pueden convertir en strings y viceversa.
Esto puede ser útil cuando quieres modificar un símbolo, o cuando quieres usar un símbolo como string.
Para presentar un string como símbolo, puedes usar el método `String#to_sym`, y para hacer lo contrario, puedes usar el método `Symbol#to_s`.
Como los símbolos tienen un conjunto limitado de métodos, puede ser útil convertir un símbolo en string para usar métodos de string sobre él, si necesitas un símbolo nuevo.

```ruby
:foo.to_s # => "foo"
"foo".to_sym # => :foo
```

## Obtener nombres en ámbitos

En Ruby puedes obtener nombres en ámbitos usando varios métodos que devuelven los nombres de constantes, métodos y variables.
Estos métodos devuelven arrays de símbolos.

Algunos métodos son `Module#constants`, `Module#instance_methods`, `Module#class_variables`, `global_variables` y `local_variables`.

```ruby
module Foo
  BAR = 1
  def self.baz; end
end

a = 1

Foo.constants # => [:BAR]
Foo.instance_methods # => [:baz]

local_variables # => [:a]
```

Todos los métodos se pueden encontrar en la [API de Kernel][kernel-api] y la [API de Module][module-api].
