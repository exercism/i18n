# Anexo de instrucciones

## Paquete de ordenamiento

En este ejercicio tienes que ordenar un array, pero esto no viene incluido en la biblioteca estándar.
Podrías escribir tu propia biblioteca de ordenamiento, pero una mejor opción es usar el [paquete sorts](https://github.com/diku-dk/sorts).

Puedes usar este paquete en tu solución ejecutando el siguiente comando en el directorio de la solución:

```shell
futhark pkg add github.com/diku-dk/sorts
futhark pkg sync
```

Luego, importa tus [algoritmos de ordenamiento deseados](https://github.com/diku-dk/sorts/tree/master/lib/github.com/diku-dk/sorts) con:

```futhark
import "lib/github.com/diku-dk/sorts/<sorting algorithm>"
```
