# Instrucciones

Lilly, la extraterrestre de Lisp, definitivamente ha preparado mucha lasaña con tu ayuda. Quiere agradecerte dándote algunas sobras. Pero primero tiene algunos comentarios sobre una de las funciones con las que la ayudaste.

En este ejercicio vas a escribir algunas funciones más para ayudar a Lilly con su cocina de lasaña, además de ayudarla a repartir las sobras contigo.

Tienes seis tareas: tres sobre mejorar las funciones existentes de cocina de lasaña y tres sobre repartir las sobras.

## 1. Haz que `preparation-time-in-minutes` sea más fácil de usar

Lilly dice que le resultó un poco incómodo usar tu `preparation-time-in-minutes`, ya que tenía que contar todas las capas antes de usar las funciones. Lilly se pregunta si podrías hacer una versión de la función que reciba las capas (cualquier cantidad de ellas) como argumentos y luego calcule el tiempo de preparación según cuántas capas haya. Como recordatorio, preparar una sola capa toma 19 minutos.

```lisp
(preparation-time 'sauce 'cheese 'right-handed-macaroni 'cheese 'sauce
                  'left-handed-macaroni 'sauce 'sauce 'cheese 'cheese)
                  ;; => 190 (because there are 10 layers.)
```

## 2. Permite cambiar el tiempo esperado en el horno

Mientras que las unidades parentales de Lilly siempre cocinaban su lasaña durante 337 minutos, Lilly admite que a otros extraterrestres de Lisp les gusta cocinar su lasaña por más o menos tiempo.

Así que sería bueno que `remaining-minutes-in-oven` no usara `expected-minutes-in-oven`, sino que en su lugar pudiera recibir un parámetro _opcional_ para definir si el tiempo debería ser más largo, muy largo, más corto o muy corto. Más largo o más corto significa sumar o restar 100 al tiempo predeterminado de 337. Muy largo o muy corto significa sumar o restar 200. Si no se proporciona ningún parámetro, o el argumento es «normal», debería devolverse el valor predeterminado de 337.

```lisp
(remaining-minutes-in-oven)             ;; => 337
(remaining-minutes-in-oven :normal)     ;; => 337
(remaining-minutes-in-oven :shorter)    ;; => 237
(remaining-minutes-in-oven :very-short) ;; => 137
(remaining-minutes-in-oven :longer)     ;; => 437
(remaining-minutes-in-oven :very-long)  ;; => 537
```

## 3. Lilly recuerda otro estilo de cocción preferido

Justo después de que terminaste ese cambio, Lilly recuerda que hay algunos extraterrestres de Lisp a los que les gustan los tiempos de cocción _realmente cortos_. Básicamente la quieren cruda. Así que ahora la función debería devolver 0 si el argumento fue `NIL`, además de los mismos valores que en la tarea anterior.

```lisp
(remaining-minutes-in-oven)     ;; => 337
(remaining-minutes-in-oven nil) ;; => 0
```

## 4. Repartir las sobras

Ahora que ayudaste a mejorar las funciones de cocina de la lasaña, ¡hay _mucha lasaña_! Lilly quiere pagarte por toda tu ayuda repartiendo las sobras contigo. Necesitarás escribir una función que reciba tres parámetros: la cantidad total de sobras, el número de recipientes para sobras que Lilly encontró en sus alacenas y el mismo dato para ti. Como buscar recipientes para sobras puede tomar cantidades de tiempo diferentes, y la cantidad exacta de sobras puede determinarse mientras tú y Lilly están buscando en sus alacenas, ambos acuerdan que la función debería recibir los argumentos en cualquier orden, de modo que a medida que se determine cada número lo puedas anotar. Cuando tengas los tres números, puedes simplemente cerrar el paréntesis de la llamada a la función y evaluarla.

La función debería devolver la cantidad de sobras que quedan, es decir, la diferencia entre el peso de las sobras y el número total de recipientes que tú y Lilly encontraron.

```lisp
(split-leftovers :weight 20 :human 10 :alien 5) ;; => 5
(split-leftovers :weight 20 :alien 10 :human 2) ;; => 8
(split-leftovers :alien 12 :weight 20 :human 4) ;; => 4
```

## 5. Hacer suposiciones

Después de unos cuantos viajes de ida y vuelta a sus respectivas alacenas, ambos acuerdan que sería genial si la función pudiera simplemente _asumir_ que tú o Lilly tenían... digamos, 10 recipientes si no se especificaba.

```lisp
(split-leftovers :weight 20 :human 5) ;; => 5
(split-leftovers :weight 20 :alien 5) ;; => 5
(split-leftovers :weight 20)          ;; => 0
```

## 6. Cantidad estándar de sobras

Mejor aún, la función podría _asumir_ que hay suficientes sobras para caber en los recipientes. Así que si no se proporciona el peso, la función debería devolver `:just-split-it`. _Sin embargo_, si se proporciona el peso y es `nil`, entonces debería devolver `:looks-like-someone-was-hungry`.

```lisp
(split-leftovers :human 5 :alien 5) ;; => :JUST-SPLIT-IT
(split-leftovers :weight NIL :human 5 :alien 5) ;; => :LOOKS-LIKE-SOMEONE-WAS-HUNGRY
```
