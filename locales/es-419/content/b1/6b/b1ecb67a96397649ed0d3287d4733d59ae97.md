# Anexo de instrucciones

## Palabras

- `tick ( matrix cols -- matrix' )`: avanza la cuadrícula una generación y devuelve la nueva cuadrícula.

Cada fila de la cuadrícula se representa como un número entero de 64 bits; `cols` es el número de columnas (64 como máximo). Por ejemplo,

```
    0 1 0
    1 0 0
    1 1 0
```

se representa como

```
0b010
0b100
0b110
```
