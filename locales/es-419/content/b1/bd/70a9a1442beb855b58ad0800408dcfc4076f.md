# Acerca de

La biblioteca estándar de Gleam implementa un tipo `Queue` en el módulo `gleam/queue`. Es similar al tipo `List`, pero con algunas diferencias clave:

- El tipo `Queue` no tiene una sintaxis literal que se pueda usar para construir colas ni para hacer coincidencia de patrones sobre ellas.
- Los elementos se pueden agregar y quitar de forma eficiente tanto por el frente como por el final del tipo `Queue`, mientras que el tipo `List` solo puede agregar y quitar elementos de forma eficiente por el frente.

La mayoría de las veces vas a querer usar el tipo `List`, pero cuando necesites poder agregar y quitar del final de una colección, el tipo `Queue` es una buena opción.

Las colas se pueden crear con las funciones `queue.new` y `queue.from_list`:

```gleam
let empty = queue.new()
let one_to_four = queue.from_list([1, 2, 3, 4])
```

Los elementos se pueden agregar a la cola con las funciones `queue.push_front` y `queue.push_back`:

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])
let one_to_five = queue.push_back(one_to_four, 5)
let zero_to_five = queue.push_front(one_to_five, 0)
```

Los elementos se pueden quitar de la cola con las funciones `queue.pop_front` y `queue.pop_back`:

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])

queue.pop_back(one_to_four)
// -> Ok(#(4, queue.from_list([1, 2, 3])))

queue.pop_front(one_to_four)
// -> Ok(#(1, queue.from_list([2, 3, 4])))

queue.pop_front(queue.new())
// -> Error(Nil)
```

Una cola se puede convertir en una lista con la función `queue.to_list`:

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])
queue.to_list(one_to_four)
// -> [1, 2, 3, 4]
```

## Igualdad de colas

Debido a cómo se implementan las colas, dos colas con los mismos elementos en el mismo orden pueden no ser iguales según el operador `==`, que compara valores de forma estructural. Por ejemplo:

```gleam
let empty = queue.new()
let a = queue.push_front(empty, 1)
let b = queue.push_back(empty, 1)
a == b
// -> False
```

Si necesitas comparar dos colas para ver si son iguales, puedes usar la función `queue.is_logically_equal`.

```gleam
queue.is_logically_equal(a, b, fn(x, y) { x == y })))
// -> True
```
