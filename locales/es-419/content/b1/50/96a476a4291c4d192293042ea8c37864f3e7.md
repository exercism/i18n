# Instrucciones

En este ejercicio vas a escribir código para analizar una línea de ensamblaje en una fábrica de autos.

## 1. Calcula la cantidad de autos que salen bien producidos por hora

Implementa una función que reciba la cantidad de autos producidos por hora y la tasa de éxito, y calcule la cantidad de autos que salen bien por hora. La tasa de éxito se da como un porcentaje, de `0` a `100`:

```lua
cars.calculate_working_cars_per_hour(1547, 90)
--> => 1392.3
```

**Nota:** el valor que devuelve debe ser un número de punto flotante.

## 2. Calcula la cantidad de autos que salen bien producidos por minuto

Implementa una función que reciba la cantidad de autos producidos por hora y la tasa de éxito, y calcule cuántos autos salen bien cada minuto:

```lua
cars.calculate_working_cars_per_minute(1105, 90)
-- => 16
```

**Nota:** el valor que devuelve debe ser un número entero.

## 3. Calcula el costo de producción

Producir cada auto por separado cuesta normalmente $10.000, sin importar si sale bien o no. Pero con un poco de planificación, se pueden producir 10 autos juntos por $95.000. Por ejemplo, 37 autos se pueden producir de la siguiente manera:
37 = 3 x grupos de diez + 7 autos individuales

Entonces, el costo de 37 autos es:
3 \* 95,.000 + 7 \* 10.000 = 355.000

Implementa una función que calcule el costo de producir una cantidad de autos, sin importar si salen bien o no:

```lua
cars.calculate_cost(37)
-- => 355000

cars.calculate_cost(21)
-- => 200000
```

**Nota:** el valor que devuelve debe ser un número entero.
