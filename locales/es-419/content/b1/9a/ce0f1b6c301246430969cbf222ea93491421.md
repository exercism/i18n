# Acerca de

Los strings (cadenas) en Haxe son objetos inmutables que representan texto como una secuencia de caracteres Unicode (letras, dígitos, signos de puntuación, etc.). Para definir una instancia de `string` se usan comillas dobles:

```haxe
var fruit:String = "Apple";
```

Puedes manipular un string llamando a uno de sus [métodos o propiedades][string-api]. Como los valores de tipo string nunca cambian una vez definidos, todos los métodos de manipulación de strings devuelven un string nuevo.

Un string está delimitado por comillas dobles (`"`). Algunos caracteres especiales se deben [escapar][escaping] usando el carácter barra invertida (`\`). Además, los strings en Haxe pueden ocupar varias líneas, lo que permite construir literales de string largos fácilmente:

```haxe
var escaped:String = "c:\\test.txt";
var multiline:String = "
- apple
- pear
- banana";
```

La forma más sencilla de concatenar strings es usar el [operador `+`][plus-operator].

```haxe
var name:String = "Jane";
trace("Hello " + name + "!");
// => "Hello Jane!"
```

Para un formato de strings más complejo, se prefiere la [interpolación de strings][interpolation]. Esto se hace encerrando el string entre comillas simples (`'`) y usando el signo de dólar (`$`) para activar la interpolación de variables. También puedes evaluar expresiones completas usando `${expr}`, donde `expr` es cualquier expresión válida de Haxe:

```haxe
var name:String = "Jane";
trace('Hello $name!');
// => "Hello Jane!"
trace('HELLO ${name.toUpperCase()}!');
// => "HELLO JANE!"
```
