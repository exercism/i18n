# Apéndice de instrucciones

## Registros

| Registro | Uso       | Tipo    | Descripción                                              |
| -------- | --------- | ------- | -------------------------------------------------------- |
| `$a0`    | entrada   | address | string de caracteres hexadecimales terminado en nulo      |
| `$v0`    | salida    | integer | valor decimal del string de entrada                       |
| `$t0-9`  | temporal  | any     | se usan para almacenamiento temporal                      |
