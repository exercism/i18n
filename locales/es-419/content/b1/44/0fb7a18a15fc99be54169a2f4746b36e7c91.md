# Pistas

## General

- No te preocupes por cómo se derivan los argumentos, solo concéntrate en combinarlos para devolver el resultado esperado.
- Unison tiene [reglas específicas para la precedencia de operadores][operator-precedence]; recuerda usar paréntesis si necesitas ordenar la aplicación de funciones de otra manera.

## 1. Define si Pac-Man puede comer un fantasma

- Necesitas definir una función con 2 argumentos. El primer argumento es un valor [Boolean][boolean] que indica si Pac-Man tiene una píldora de poder activa. El segundo argumento es un valor [Boolean][boolean] que indica si Pac-Man está tocando un fantasma.
- La función debe devolver un valor [Boolean][boolean].
- Puedes usar el operador [Boolean][boolean] `&&` para combinar los argumentos y obtener un resultado.

## 2. Define si Pac-Man anota

- Necesitas definir una función con 2 argumentos. El primer argumento es un valor [Boolean][boolean] que indica si Pac-Man está tocando una píldora de poder. El segundo argumento es un valor [Boolean][boolean] que indica si Pac-Man está tocando un punto.
- La función debe devolver un valor [Boolean][boolean].
- Puedes usar el operador [Boolean][boolean] `||` para combinar los argumentos y obtener un resultado.

## 3. Define si Pac-Man pierde

- Necesitas definir una función con 2 argumentos. El primer argumento es un valor [Boolean][boolean] que indica si Pac-Man tiene una píldora de poder activa. El segundo argumento es un valor [Boolean][boolean] que indica si Pac-Man está tocando un fantasma.
- La función debe devolver un valor [Boolean][boolean].
- Puedes usar los operadores [Boolean][boolean] `&&` y `not` para combinar los argumentos y obtener un resultado.

## 4. Define si Pac-Man gana

- Necesitas definir una función con 3 argumentos. El segundo argumento es un valor [Boolean][boolean] que indica si Pac-Man se comió todos los puntos. El primer argumento es un valor [Boolean][boolean] que indica si Pac-Man tiene una píldora de poder activa. El segundo argumento es un valor [Boolean][boolean] que indica si Pac-Man está tocando un fantasma.
- La función debe devolver un valor [Boolean][boolean].
- Puedes usar los operadores [Boolean][boolean] `&&` y `not` para combinar los argumentos y los resultados de las funciones invocadas.
