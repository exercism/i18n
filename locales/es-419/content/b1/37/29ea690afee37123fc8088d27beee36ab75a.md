# Clases genéricas

Has usado `ARRAY{STR}`, `FMAP{STR,INT}` y `FSET{STR}` desde el principio.
Las llaves siempre han contenido un tipo. Ahora escribes una clase con llaves
propias.

## El problema

La oficina de objetos perdidos necesita una caja que guarde una cosa y recuerde
quién la entregó. Una caja para un suéter:

```sather
class JUMPER_BOX is
   attr item : JUMPER;
   ...
end;
```

y luego la misma clase otra vez para una botella de agua, y otra vez para un
teléfono. Tres copias que difieren en una palabra.

## El parámetro de tipo

```sather
class LOST_BOX{T} is

   attr item : T;

   create(thing : T) : SAME is
      box ::= new;
      box.item := thing;
      return box;
   end;

end; -- class LOST_BOX{T}
```

`{T}` después del nombre de la clase es un **parámetro de tipo**. `T` no es un
tipo, sino un sustituto para cualquier tipo que se suministre cuando se usa la
clase. Dentro de la clase, `T` se usa exactamente como se usaría cualquier
nombre de tipo.

## Cómo usarlo

Suministra el tipo entre llaves:

```sather
   jumper ::= #LOST_BOX{STR}("blue jumper");
   count ::= #LOST_BOX{INT}(3);

   jumper.item      -- "blue jumper", a STR
   count.item       -- 3, an INT
```

`LOST_BOX{STR}` y `LOST_BOX{INT}` son dos tipos diferentes. Poner uno donde se
espera el otro es un error que el compilador detecta, exactamente como si
hubieras escrito las dos clases a mano, que, en efecto, es lo que sucede:
Sather construye una clase separada a partir del patrón para cada tipo que se
usa realmente.

Así que esto no tiene costo en tiempo de ejecución, ni pérdida de información
de tipo: `jumper.item` realmente es un `STR`, no algo que haya que verificar o
convertir.

## Más de uno

Una clase puede tomar varios parámetros, separados por comas. `FMAP{K,T}` es el
ejemplo que ya conoces.

```sather
class LABELLED{L,T} is
   attr label : L;
   attr item : T;
   ...
end;
```

## Nomenclatura

Letras mayúsculas individuales por convención: `T` para una cosa, `K` para una
clave, `E` para un elemento. La biblioteca las usa en todas partes.
