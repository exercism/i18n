# Pistas

## General

- Todas las palabras de lectura y escritura viven en [`io.files`][io.files]; la codificación `utf8` que todas reciben viene de [`io.encodings.utf8`][utf8].

## 1. Lee cada lectura

- `file-lines` devuelve un array de líneas con los saltos de línea eliminados.

## 2. Encuentra la última lectura

- Lee las líneas con `file-lines` y luego toma la `last` (de `sequences`).

## 3. Lee el registro sin procesar

- `file-contents` devuelve el archivo como un solo string, con todo y saltos de línea.

## 4. Registra una lectura

- Abre el archivo para agregarle contenido e imprime la lectura dentro de la quotation con `print`:
  `with-file-appender ( path encoding quot -- )`. La lectura se usa dentro de la quotation, mientras que la ruta se consume antes, así que las locales `::` mantienen el cuerpo legible:
  `:: record-reading ( reading path -- ) path utf8 [ reading print ]
  with-file-appender ;`.

## 5. Reescribe el registro

- `set-file-lines` escribe cada elemento de una secuencia en su propia línea y agrega los saltos de línea por ti.
