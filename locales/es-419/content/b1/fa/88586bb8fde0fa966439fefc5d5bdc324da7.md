# concatenación de strings

La concatenación de strings es perfectamente válida en Crystal, pero una forma más común de componer un string es con la [interpolación de strings][interpolation].
Por ejemplo:

```crystal
# Rather than:
"One for " + name_variable + ", one for me"

# Consider:
"One for #{name_variable}, one for me."
```

[interpolation]: https://crystal-lang.org/reference/latest/syntax_and_semantics/literals/string.html#interpolation
