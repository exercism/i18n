# Introducción

Trabajar con datos binarios es un concepto importante en cualquier lenguaje, y Elixir ofrece una sintaxis elegante para escribir, hacer coincidir y construir datos binarios.

En Elixir, a los datos binarios se les denomina tipo bitstring. El _tipo_ de datos binario (que no debe confundirse con los datos binarios en general) es una forma específica de bitstring, de la que hablaremos en un ejercicio posterior.

Los literales de bitstring se definen usando la forma especial de bitstring `<<>>`. Al definir un literal de bitstring, este se compone de segmentos. Cada segmento tiene un valor y un tipo, separados por el operador `::`. El tipo especifica cuántos bits se usarán para codificar el valor. El tipo se puede omitir por completo, en cuyo caso se asume por defecto un entero de 8 bits.

```elixir
# This defines a bitstring with three segments of a single bit each
<<0::1, 1::1, 0::1>>
```

Especificar el tipo como `::1` es una forma abreviada de escribir `::size(1)`. Necesitas usar la sintaxis larga si el tamaño en bits proviene de una variable.

## Binario

Al escribir literales de enteros binarios, podemos escribirlos directamente en notación base 2 anteponiendo `0b` al literal. Ten en cuenta que, de todos modos, se mostrarán como números decimales cuando aparezcan en los resultados de las pruebas o cuando uses iex.

```elixir
<<0b1011::4>> == <<11::4>>
# => true
```

## Truncamiento

Si el valor del segmento excede la capacidad del tipo del segmento, se truncará por la izquierda.

```elixir
<<0b1011::3>> == <<0b0011::3>>
# => true
```

## Anteponer y agregar al final

Puedes anteponer y agregar al final de un bitstring existente usando la forma especial. Debes usar el tipo `::bitstring` en el bitstring existente si este es de tamaño desconocido.

```elixir
value = <<0b110::3, 0b001::3>>
new_value = <<0b011::3, value::bitstring, 0b000::3>>
# => <<120, 8::size(4)>>
```

## Concatenación

Podemos concatenar bitstrings guardados en variables usando la forma especial. Debes usar el tipo `::bitstring` al concatenar dos bitstrings de tamaños desconocidos.

```elixir
first = <<0b110::3>>
second = <<0b001::3>>
concatenated = <<first::bitstring, second::bitstring>>
# => <<49::size(6)>>
```

## Coincidencia de patrones

También puedes hacer coincidencia de patrones para obtener valores de la forma especial. Debes saber la cantidad de bits de cada fragmento que quieras capturar, con una excepción: el tipo `::bitstring` se puede usar para hacer coincidencia de patrones en un bitstring de tamaño desconocido, pero solo se puede usar en el último fragmento.

```elixir
<<value::4, rest::bitstring>> = <<0b01101001::8>>
value == 0b0110
# => true
```

## Inspeccionar bitstrings

~~~~exercism/note
Puede que los bitstrings se impriman (por el ejecutor de pruebas o en iex) en
un formato distinto del que se usó para crearlos. Esto suele
causar confusión cuando se aprenden los bitstrings.
~~~~

De forma predeterminada, los bitstrings se muestran en fragmentos de 8 bits (un byte), incluso si los creaste con fragmentos de otro tamaño.

```elixir
<<2011::11>>
# => <<251, 3::size(3)>>
```

Si creas un bitstring que representa un string imprimible codificado en UTF-8, se muestra como un string.

```elixir
<<>>
# => ""

<<65, 66, 67>>
# => "ABC"
```
