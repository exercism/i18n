# Pistas

## 1. Preséntate

- Puedes usar la [función `option.unwrap`][unwrap] para obtener el valor de una option, o un valor predeterminado si no hay ninguno.

## 2. Implementa la mecánica de revivir

- Los valores de tipo option se pueden crear con los constructores `Some` y `None` del módulo `gleam/option`.

## 3. Implementa la mecánica de lanzar hechizos

- Puedes usar la [función `int.max`][max] para asegurarte de que la salud no baje de 0.

[max]: https://hexdocs.pm/gleam_stdlib/gleam/int.html#max
