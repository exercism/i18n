# Instrucciones

Un nuevo club de poesía abrió en la ciudad y estás pensando en asistir.
Como ha habido incidentes en el pasado, el club tiene una política de entrada muy específica que tendrás que dominar antes de intentar entrar.

En el club de poesía hay dos puertas, una delantera y una trasera, y ambas están custodiadas.
Para entrar, tendrás que descubrir la contraseña del día.

La contraseña siempre se basa en un poema y se puede obtener con un proceso de dos pasos.

1. El guardia recitará el poema, una línea a la vez, y tendrás que responder con la letra correspondiente de esa línea.
2. Luego el guardia te dirá todas las letras con las que respondiste de una vez, y tendrás que escribirlas en un papel con un formato específico.

Los detalles del proceso dependen de la puerta por la que intentes entrar.

## 1. Obtén la primera letra de una oración

Para determinar las letras de la contraseña de la puerta delantera, debes responder con la primera letra de la línea del poema que el guardia te recite.

Para terminar con una contraseña bonita, a los miembros del club de poesía les gusta usar poemas _acrósticos_.
Esto significa que la primera letra de cada oración forma una palabra.
Aquí tienes un ejemplo de uno de sus escritores favoritos, Michael Lockwood.

```text
Stands so high
Huge hooves too
Impatiently waits for
Reins and harness
Eager to leave
```

Entonces, cuando el guardia recite **Stands so high**, responderás **S**, y cuando recite **Huge hooves too**, responderás **H**.

Implementa la función `frontDoorResponse` que recibe una línea del poema como argumento y devuelve la primera letra de esa línea.

```javascript
frontDoorResponse('Stands so high');
// => "S"
```

## 2. Escribe una palabra con mayúscula inicial

Ahora que tienes todas las letras correctas, lo único que necesitas hacer para obtener la contraseña de la puerta delantera es escribir la palabra con la mayúscula inicial correcta.

Implementa la función `frontDoorPassword` que acepta un string (las letras combinadas que encontraste en la tarea 1) y lo devuelve con la mayúscula inicial correcta.

```javascript
frontDoorPassword('SHIRE');
// => "Shire"

frontDoorPassword('shire');
// => "Shire"
```

## 3. Obtén la última letra de una oración

Para determinar las letras de la contraseña de la puerta trasera, debes responder con la última letra de la línea del poema que el guardia te recite.

Los miembros del club de poesía son muy ingeniosos.
El poema que mencionamos antes también es _telestiquio_, lo que significa que la última letra de cada oración también forma una palabra:

```text
Stands so high
Huge hooves too
Impatiently waits for
Reins and harness
Eager to leave
```

Cuando el guardia recite **Stands so high**, responderás **h**, y cuando recite **Huge hooves too**, responderás **o**.

Ten en cuenta que a veces el guardia hace pausas estilísticas (en forma de espacios en blanco) al principio o al final de una línea.
Tendrás que ignorar esas pausas para obtener la letra correcta.

Implementa la función `backDoorResponse` que recibe una línea del poema como argumento y devuelve la última letra de esa línea que no sea un carácter de espacio en blanco.

```javascript
backDoorResponse('Stands so high');
// => "h"

backDoorResponse('Stands so high   ');
// => "h"
```

## 4. Sé cortés

Para entrar al club de poesía por la puerta trasera, necesitas ser extra cortés.
Así que para obtener la contraseña, esta vez necesitas escribir la palabra con la mayúscula inicial correcta y agregar `', please'` al final.

Implementa la función `backDoorPassword` que acepta un string (las letras combinadas que encontraste en la tarea 3) y devuelve la versión cortés de la contraseña con la mayúscula inicial.

```javascript
backDoorPassword('horse');
// => "Horse, please"
```
