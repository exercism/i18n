# Apéndice de las instrucciones

## Registros

| Registro | Uso        | Tipo    | Descripción                   |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | entrada        | dirección | cadena de dígitos terminada en null |
| `$a1`    | entrada        | entero | longitud                          |
| `$v0`    | salida       | entero | el mayor producto de la serie        |
| `$t0-9`  | temporal    | cualquiera     | para almacenamiento temporal         |
