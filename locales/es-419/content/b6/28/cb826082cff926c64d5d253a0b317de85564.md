# El signo + usado para concatenar

En este caso, usar `+` es casi con seguridad la opción correcta, ya que es más corto y, a menudo, más rápido para concatenaciones simples. Si no te resulta familiar, échale un vistazo al poderoso paquete `fmt`. Es lo que la gente suele usar para concatenaciones de string más complicadas y otras necesidades de formato de string.
