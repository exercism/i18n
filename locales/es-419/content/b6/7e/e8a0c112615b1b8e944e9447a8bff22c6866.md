# Introducción

## Conceptos básicos

C# es un lenguaje de tipado estático, lo que significa que todo tiene un tipo en tiempo de compilación. Asignar un valor a un nombre se conoce como definir una variable. Una variable se puede definir especificando su tipo de forma explícita, o dejando que el compilador de C# infiera su tipo a partir del valor asignado (esto se conoce como _inferencia de tipos_). Por lo tanto, las siguientes dos definiciones de variable son equivalentes:

```csharp
int explicitVar = 10; // Explicitly typed
var implicitVar = 10; // Implicitly typed
```

Actualizar el valor de una variable se hace con el operador `=`. Una vez que se define, el tipo de una variable nunca puede cambiar.

```csharp
var count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning different type
// count = false;
```

C# es un [lenguaje orientado a objetos][object-oriented-programming] y requiere que todas las funciones se definan dentro de una _clase_. La palabra clave `class` se usa para definir una clase. Los objetos (o _instancias_) se crean usando la palabra clave `new`.

```csharp
class Calculator
{
    // ...
}

var calculator = new Calculator();
```

Una función dentro de una clase se conoce como _método_. Cada método puede tener cero o más parámetros. Todos los parámetros deben tener un tipo explícito; no hay inferencia de tipos para los parámetros. De manera similar, el tipo de retorno también debe ser explícito. Los valores se devuelven desde los métodos usando la palabra clave `return`. Para permitir que el código de otros archivos llame a un método, se debe agregar el modificador de acceso `public`.

```csharp
class Calculator
{
    public int Add(int x, int y)
    {
        return x + y;
    }
}
```

Los métodos se invocan usando la sintaxis de punto (`.`) sobre una instancia, especificando el nombre del método que se va a llamar y pasando argumentos para cada uno de los parámetros del método. Los argumentos pueden especificar de forma opcional el nombre del parámetro correspondiente.

```csharp
var calculator = new Calculator();
var sum_v1 = calculator.Add(1, 2);
var sum_v2 = calculator.Add(x: 1, y: 2);
```

El ámbito en C# se define entre los caracteres `{` y `}`.

C# admite dos tipos de comentarios. Los comentarios de una sola línea van precedidos por `//` y los comentarios de varias líneas se insertan entre `/*` y `*/`.
