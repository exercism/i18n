# Flujo de trabajo de sincronización de etiquetas

El flujo de trabajo de sincronización de etiquetas sincroniza las [etiquetas de GitHub](https://docs.github.com/en/issues/using-labels-and-milestones-to-track-work/managing-labels) de un repositorio con el contenido del archivo `.github/labels.yml`.
Cada vez que cambie el archivo `.github/labels.yml`, el flujo de trabajo de sincronización de etiquetas actualizará automáticamente las etiquetas del repositorio.

## Personalizar las etiquetas

Las etiquetas definidas en `.github/labels.yml` vienen de dos formas:

- Etiquetas compartidas: son las etiquetas que usan _todos_ los repositorios de Exercism y se definen en el [repositorio org-wide-files](https://github.com/exercism/org-wide-files/blob/main/global-files/.github/labels.yml)
- Etiquetas específicas de cada track: se definen en un archivo `.appends/.github/labels.yml`

Para agregar etiquetas específicas de un track, deberás agregarlas al archivo `.appends/.github/labels.yml` (consulta [este ejemplo](https://github.com/exercism/python/blob/main/.appends/.github/labels.yml)).
Una vez que hayas fusionado los cambios en `main`, se abrirá automáticamente un pull request para cambiar el archivo `.github/labels.yml`.
Después de fusionar ese PR, las etiquetas se actualizarán automáticamente (consulta la descripción de arriba).

```exercism/caution
Nunca edites manualmente el archivo `.github/labels.yml`, porque esos cambios se sobrescribirán la próxima vez que se sincronicen las etiquetas.
```

## Fuente

El flujo de trabajo se define en el archivo `.github/workflows/sync-labels.yml`.
