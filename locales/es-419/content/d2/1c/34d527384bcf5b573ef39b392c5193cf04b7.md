# Pistas

## General

- La documentación del paquete `Random` se puede encontrar [aquí][random-module]

## 1. Empieza por el final

- Usa la función [`Random.constant`][random-constant]

## 2. No se cazan moscas con vinagre

- Usa la función [`Random.uniform`][random-uniform] para generar los tesoros
- Usa la función [`Random.map`][random-map] para envolver el tesoro

## 3. Ramificarse

- Usa la función [`Random.int`][random-int] para generar un valor entre 2 y 4
- Puedes acceder a este valor para crear una `Branch` con la función [`Random.andThen`][random-andThen]
- Usa la función [`Random.list`][random-list] para generar las ramas
- Usa la función [`Random.map`][random-map] para envolver las ramas

## 4. Laberintos asombrosos

- Usa la función [`Random.weighted`][random-weighted] para generar una distribución desigual de resultados
- Usa la función [`Random.lazy`][random-lazy] para usar un generador de forma recursiva
- Lee más sobre cómo definir estructuras de datos recursivas [aquí][bad-recursion]
- Si terminas definiendo un generador anidado `Generator (Generator Maze)`, puedes usar [`Random.andThen`][random-andThen] junto con la función `identity` para aplanarlo

## 5. Tenemos que ir más profundo

- Usa la función [`Random.uniform`][random-uniform] para generar los callejones sin salida o las salas a profundidad `0`
- Si terminas definiendo un generador anidado `Generator (Generator Maze)`, puedes usar [`Random.andThen`][random-andThen] junto con la función `identity` para aplanarlo
- Usa la función [`Random.lazy`][random-lazy] para usar un generador de forma recursiva
- Lee más sobre cómo definir estructuras de datos recursivas [aquí][bad-recursion]
