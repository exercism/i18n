# Introducción

## Números enteros

Los números enteros son números sin parte decimal que pertenecen al conjunto `{..., -2, -1, 0, 1, 2, ...}`.
Los valores máximo y mínimo de un número entero dependen del sistema en el que se ejecuta PHP.
Por lo general, en la mayoría de los sistemas modernos, el número entero es un valor de 64 bits, lo que significa que puede representar desde `-9_223_372_036_854_775_808` hasta `9_223_372_036_854_775_807` inclusive.

```php
<?php

$a = 1234;
$a = 1_234_567;
```

Puedes escribir valores literales de números enteros en una base distinta de la base 10 usando un prefijo de base:

```php
<?php

$a = 0123; // octal number (equivalent to 83 decimal)
$a = 0o123; // octal number (as of PHP 8.1.0)
$a = 0x1A; // hexadecimal number (equivalent to 26 decimal)
$a = 0b11111111; // binary number (equivalent to 255 decimal)
```

> Tomado de la [documentación][syntax] de PHP

## Números de punto flotante

En PHP, los números de punto flotante se usan para representar un subconjunto de los números reales.
Están formados por uno o más dígitos separados por un separador decimal.

```php
<?php

$a = 1.234; 
$b = 1.2e3; 
$c = 7E-10;
$d = 1_234.567; // as of PHP 7.4.0
```

### Trampas comunes

No todos los números ni todas las operaciones aritméticas se pueden manejar con números de punto flotante.
Usar números de punto flotante para representar dólares y centavos puede provocar errores de redondeo.

```php
<?php

$result = 0.1 + 0.2; // => 0.30000000000000004
```

## Operadores aritméticos

PHP ofrece varios operadores para realizar operaciones aritméticas. PHP sigue el orden de operaciones matemático estándar para sus operadores aritméticos. Los operadores que ofrece PHP son:

* Identidad (+)
* Negación (-)
* Suma (+)
* Resta (-)
* Multiplicación (*)
* División (/)
* Módulo (%)
* Exponenciación (**)

```php
$moles = +'10';
$aLotOfMoles = 6.022 * 10**23 * $moles;
```
