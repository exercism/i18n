# Operador ternario

El operador ternario proporciona una sintaxis alternativa para realizar una comparación `if..else..` y devolver un valor.

## Sintaxis

PHP proporciona un condicional if en el que se puede evaluar una acción según la «veracidad» de una condición.

```php
if ($condition) {
  $value = 1;
} else {
  $value = 2
}
```

Como alternativa, el operador ternario puede representar la misma operación:

```php
$value = $condition
  ? 1  // True branch
  : 2; // False branch
```

La sintaxis de la comparación es corta y se representa con `(condition) ? (evaluate if true) : (evaluate if false);`.

## Beneficios

El beneficio obvio de usar un operador ternario es la brevedad: la expresión condicional se escribe de forma más corta en comparación con una sentencia `if..else..`, pero también hay varias otras ventajas:

- Es una expresión que se puede usar dentro de otra expresión.
- Facilita la evaluación perezosa de cada rama.

  ```php
  function expensiveCalculation(): int
  {
    // An expensive calculation is performed
    $answerToEverything = 42;
    return $answerToEverything;
  }

  $needExactAnswer = false;
  $estimatedAnswer = 40;
  $answer = $needExactAnswer ? expensiveCalculation() : $estimatedAnswer;
  ```

  En este ejemplo, si no se requiere la respuesta exacta, no se invoca el cálculo costoso.

## Desventajas

Los operadores ternarios tienen varias desventajas, por lo que es importante considerar su uso:

- Un operador ternario puede ser más difícil de leer, ya que depende de interpretar símbolos en lugar del uso de palabras clave.
- Un operador ternario puede provocar bugs sin querer porque el operador ternario en PHP es asociativo por la izquierda, a diferencia de la mayoría de los lenguajes contemporáneos (p. ej., C, Java, JavaScript).
- La expresión evaluada en las ramas verdadera o falsa debe devolver un valor.

## Aún más corto

La sintaxis ternaria se puede acortar aún más a `(condition) ?: (evaluate if falsey)`.
Uno de esos usos sería poder proporcionar un valor de respaldo en una expresión:

```php
$fruit = null;
eat($fruit ?: 'apple');
```

Esto también se conoce a veces como el _operador Elvis_ (`?:`)
