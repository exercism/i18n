# Calculadora de cocina

## Historia

La historia facilita la exploración de las [tuplas][type-tuple] en un lenguaje.

Premisa básica: a menudo los ingredientes de cocina se miden de maneras poco claras y requieren conversiones distintas según las cantidades o las herramientas disponibles. Las tuplas se usan para dar [duck typing][concept-duck-typing] al componente numérico de la medida.

Así, esto explora la conversión básica de valores usando números de punto flotante.

### Conversiones

| De                 | A       |
| ------------------ | ------- |
| 1 mL               | 1mL     |
| 1 taza             | 240mL   |
| 1 onza líquida (EE. UU.) | 29.57mL |
| 1 cucharadita      | 5 mL    |
| 1 cucharada        | 15 mL   |

## Tareas

Esto debería guiar a los estudiantes sobre cómo usar:

- Tuplas
- Tuplas como información agrupada
- Obtener valores de una tupla usando el índice del elemento
- Obtener valores de una tupla usando coincidencia de patrones
- Crear nuevas tuplas
