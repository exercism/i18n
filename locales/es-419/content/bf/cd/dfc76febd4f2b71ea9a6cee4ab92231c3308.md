# Cómo aprender MoonScript

Lee [An Overview of MoonScript][leafo], de Leafo, el creador de MoonScript.
Es un excelente punto de partida si recién empiezas con MoonScript y con Lua a la vez, pues explica los conceptos fundamentales.

El lugar principal para recursos de aprendizaje es [el sitio web de MoonScript][learn].
Se asume que ya conoces Lua.
