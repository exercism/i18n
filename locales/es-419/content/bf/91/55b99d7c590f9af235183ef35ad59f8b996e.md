# Cómo ejecutar los tests

Los ejercicios que descargas con el [cliente de línea de comandos de Exercism](https://exercism.io/cli) se entregan con un mínimo de tres archivos: un archivo `readme.md`, un archivo `.dpr` y un archivo `.pas`. El archivo `.dpr` es el archivo de proyecto de Delphi y el archivo `.pas` es el test runner. Carga el proyecto de Delphi haciendo doble clic en el archivo `.dpr` o abriendo el proyecto desde Delphi. Serás responsable de crear un archivo `.pas` nuevo que contendrá el código de tu solución contra el que se ejecutarán los tests. Consulta el archivo `readme.md` para saber cómo compilar y ejecutar tu código.

Todos los tests están ignorados, excepto el primero, para que puedas empezar a trabajar. Para continuar, solo comenta el atributo `[Ignore]` del test para empezar a trabajar en él.

Asegúrate de que [DUnitX](https://github.com/VSoftTechnologies/DUnitX) esté instalado, si es que no lo instalaste ya durante la configuración anterior.
