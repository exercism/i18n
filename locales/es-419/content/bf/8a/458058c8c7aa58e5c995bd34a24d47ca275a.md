# Introducción

Hasta ahora hemos visto que los argumentos que se pasan a un método se asocian con los parámetros declarados del método según su posición. Un enfoque alternativo, sobre todo cuando una rutina recibe una gran cantidad de argumentos, permite que quien llama asocie los argumentos especificando el identificador del parámetro declarado.

Lo siguiente ilustra la sintaxis:

```csharp
class Card
{
    static string NewYear(int year, int month, int day)
    {
        return $"Happy {year}-{month}-{day}!";
    }
}

Card.NewYear(month: 1, day: 1, year: 2020);  // => "Happy 2020-1-1!"
```
