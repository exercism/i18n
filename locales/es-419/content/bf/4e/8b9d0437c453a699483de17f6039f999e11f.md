# Introducción

En Python, [un `enum`][enum-docs] es un conjunto de nombres que están vinculados a valores `literal` o `constant` únicos.
Los `Enums` se definen heredando de una clase `Enum` o subclasificándola.
Los tipos `enum` integrados están disponibles en el módulo `enum` y la clase `Enum` se puede importar con `from enum import Enum`.


```python
from enum import Enum

class Color(Enum):
    RED = 1
    GREEN = 2
```

Ten en cuenta que los valores de los miembros del `enum` pueden ser de cualquier tipo de dato, como `str`, `tuple`, `float`, etc.

```python
class Color(Enum):
    RED = 'red'
    GREEN = 'green'
```

Cuando asignas el mismo valor a dos miembros de un `enum`, el miembro asignado en segundo lugar será un alias del primero. No se permite usar el mismo nombre para dos miembros diferentes de un `enum`.

```python
class Color(Enum):
    RED = 1
    GREEN = 2
    ALIAS_OF_RED = 1

Color.ALIAS_OF_RED
#=> <Color.RED: 1>

Color.ALIAS_OF_RED.value
#=> 1
```

Puedes iterar por los miembros del `enum` con la sintaxis estándar `for member in`:

```python
for member in Color:
    print((member.name, member.value))
#=> (RED, 1)
#=> (GREEN, 2)
```

Los miembros de `Enum` se pueden comparar con [`is` (_operador de identidad_)][identity-keyword] o `is not`. Los operadores `==` o `!=` (_operadores de igualdad_) funcionan de la misma manera:

```python
a = Color.RED

a is Color.RED
#=> True

a == Color.RED
#=> True
```

Para acceder a un miembro del `enum` a partir de un valor dado, puedes usar `<EnumName>(<value>)`:

```python
g = Color(2)

g is Color.GREEN
#=> True

g
#=> <Color.GREEN: 2>
```
