# Introducción

Una [`list`][list] es una colección mutable de elementos en _secuencia_. Como la mayoría de las colecciones (mira los tipos integrados [`tuple`][tuple], [`dict`][dict] y [`set`][set]), una list puede contener referencias a cualquier tipo de dato (o a varios), incluida otra list. Una list se puede copiar en su totalidad o en parte mediante la [notación de rebanadas][slice notation] o usando `<list>.copy()`. Como en cualquier [tipo de secuencia][sequence type], se hace referencia a los elementos dentro de las `lists` mediante un número de `0-based index` desde la izquierda, o un número de `-1-based index` desde la derecha.

Una list admite tanto [operaciones de secuencia comunes][common sequence operations] como [mutables][mutable sequence operations], como `min(<list>)`/`max(<list>)`, `<list>.index()`, `<list>.append()` y `<list>.reverse()`. Se puede iterar sobre los elementos dentro de una `list` usando la construcción `for item in <list>`. `for index, item in enumerate(<list>)` se puede usar cuando necesitas tanto el índice como el valor del elemento.

Python también ofrece muchos [métodos de list][list-methods] útiles para trabajar con lists. A continuación se cubre una selección de estos `list methods`.

Ten en cuenta que cuando manipulas una `list` con un `list-method`, **alteras la list** que se pasó. Si no quieres mutar la `list` original, tendrás que hacer al menos una `shallow copy` de ella mediante una rebanada o `<list>.copy()`.

## Agregar elementos

Para agregar un elemento al final o al «lado derecho» de una list existente, usa `<list>.append(<item>)`:

```python
>>> numbers = [1, 2, 3]
>>> numbers.append(9)

>>> numbers
[1, 2, 3, 9]
```

En lugar de _agregar al final_, `<list>.insert()` te permite agregar el elemento en un _índice específico_ de la list. Recibe 2 parámetros:

1. el `<index>` en el que quieres insertar el elemento.
2. el `<item>` que se va a insertar.

**Nota**: Si el `index` dado es 0, el elemento se agregará al inicio (el «lado izquierdo») de la `list`. Si el `index` proporcionado es mayor que el `index` final de la `list`, el elemento se agregará en la última posición, lo que equivale a usar `<list>.append(<item>)`.

```python
>>> numbers = [1, 2, 3]
>>> numbers.insert(0, -2)

>>> numbers
[-2, 1, 2, 3]

>>> numbers.insert(1, 0)

>>> numbers
[-2, 0, 1, 2, 3]
```

`<list>.extend(<item>)` se puede usar para combinar una list existente con los elementos de otro iterable (por ejemplo, un `set`, `tuple`, `str` o `list`). El iterable se _desempaqueta_ y los elementos se agregan en orden (_usar `<list>.append(<item>)` en este caso agregaría el iterable completo como un **solo elemento**._).

```python
>>> numbers = [1, 2, 3]
>>> other_numbers = [5, 6, 7]

>>> numbers.extend(other_numbers)

>>> numbers
[1, 2, 3, 5, 6, 7]

>>> numbers.extend([8, 9])

>>> numbers
[1, 2, 3, 5, 6, 7, 8, 9]

>>> numbers.append([8,9])

>>> numbers
[1, 2, 3, 5, 6, 7, 8, 9, [8, 9]]
```

## Eliminar elementos

Para eliminar un elemento de una list, usa `<list>.remove(<item>)`, pasando como argumento el elemento que quieres eliminar. `<list>.remove(<item>)` lanzará un `ValueError` si el elemento no está presente en la `list`.

```python
>>> numbers = [1, 2, 3]
>>> numbers.remove(2)

>>> numbers
[1, 3]

# Trying to remove a value that is not in the list throws a ValueError
>>> numbers.remove(0)
ValueError: list.remove(x): x not in list
```

Como alternativa, el método `<list>.pop(<index>)` elimina un elemento **y** además lo `return` para que puedas usarlo.

`<list>.pop(<index>)` recibe un parámetro opcional: el `index` del elemento que se va a eliminar y devolver. Si no se especifica el argumento `index` (opcional), se eliminará y devolverá el último elemento de la `list`. Si el `index` especificado es mayor que el `index` del último elemento, se lanza un `IndexError`.

```python
>>> numbers = [1, 2, 3]

>>> numbers.pop(0)
1

>>> numbers
[2, 3]

>>> numbers.pop()
3

>>> numbers
[2]

>>> numbers.pop(1)
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
IndexError: pop index out of range
```

Se pueden eliminar todos los elementos de una `list` con `list.clear()`. No recibe ningún parámetro.

```python
>>> numbers = [1, 2, 3]
>>> numbers.clear()

>>> numbers
[]
```

## Invertir y reordenar

El método `<list>.reverse()` invierte el orden de los elementos **en el lugar**.

```python
>>> numbers = [1, 2, 3]
>>> numbers.reverse()

>>> numbers
[3, 2, 1]
```

Una list se puede reordenar _**en el lugar**_ con la ayuda de [`<list>.sort()`][sort]. El orden predeterminado es _ascendente_ desde la izquierda. La documentación de Python ofrece [consejos y técnicas adicionales para ordenar][sorting how to].

~~~~exercism/note
De 2002 a 2022, Python usó internamente un algoritmo llamado [`Timsort`][timsort] para organizar lists, pero cambió a [`Powersort`][powersort] a partir de `Python 3.11`.

[powersort]: https://www.wild-inter.net/publications/munro-wild-2018
[timsort]: https://en.wikipedia.org/wiki/Timsort
~~~~

```python
>>> names = ["Tony", "Natasha", "Thor", "Bruce"]

# The default sort order is *ascending*.
>>> names.sort()

>>> names
["Bruce", "Natasha", "Thor", "Tony"]
```

Si quieres un orden _descendente_, pasa el argumento `reverse=True`:

```python
>>> names = ["Tony", "Natasha", "Thor", "Bruce"]
>>> names.sort(reverse=True)

>>> names
["Tony", "Thor", "Natasha", "Bruce"]
```

Cuando no quieras mutar la list original, puedes usar la función integrada [`sorted(<iterable>)`][sorted] para devolver una **copia** ordenada.

```python
>>> names = ["Tony", "Natasha", "Thor", "Bruce"]

>>> sorted(names)
['Bruce', 'Natasha', 'Thor', 'Tony']
```

## Ocurrencias de un elemento en una list

El número de ocurrencias de un elemento en una list se puede calcular con `list.count(<item>)`. Recibe como argumento el `item` que se va a contar y devuelve el número total de veces que ese elemento aparece en la `list`.

```python
>>> items = [1, 4, 7, 8, 2, 9, 2, 1, 1, 0, 4, 3]

>>> items.count(1)
3
```

## Encontrar el índice de los elementos

`<list>.index(<item>)` devolverá el número de `index` de la _primera ocurrencia_ de un elemento que se pase. Si no hay ocurrencias, se lanza un `ValueError`. Si no necesitas la posición exacta de un elemento, el operador `in` integrado es más eficiente para comprobar si una list contiene un valor dado.

La indexación empieza en cero desde la izquierda, así que la posición del «primer» elemento es `0`. La indexación también funciona desde la derecha, comenzando con `-1`.

```python
>>> items = [7, 4, 1, 0, 2, 5]

>>> items.index(4)
1

>>> items.index(10)
ValueError: 10 is not in list
```

También se pueden indicar los índices `start` y `end` para limitar la búsqueda a una sección específica de la `list`:

```python
>>> names = ["Tina", "Leo", "Thomas", "Tina", "Emily", "Justin"]

>>> names.index("Tina")
0

>>> names.index("Tina", 2, 5)
3
```
