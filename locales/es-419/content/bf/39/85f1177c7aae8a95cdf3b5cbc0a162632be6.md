# CLI

## Configuración

La forma más sencilla de instalar Purescript es a través de Node.js y NPM.

Si todavía no tienes Node.js instalado en tu computadora, puedes descargarlo del [sitio web de Node.js][nodejs-website]. Una vez que tengas Node.js funcionando, escribe este comando en la terminal para instalar el compilador de PureScript y el gestor de paquetes y herramienta de compilación Spago.

```shell
npm install -g purescript spago
```

Puedes encontrar más información en el [repositorio de PureScript][purescript-repository].

## Requisitos

Instala las dependencias del ejercicio:

```shell
spago install
spago build
```

## Cómo hacer que pasen los tests

Ejecuta los tests con:

```shell
spago test
```

En las suites de tests, todos los tests menos el primero están omitidos. Esto es para animarte a resolver el ejercicio paso a paso.

Cuando logres que un test pase, puedes habilitar el siguiente cambiando `xit` por `it`.

## Enviar la solución

Cuando ya no haya tests omitidos y todos estén pasando, puedes enviar tu solución con:

```shell
exercism submit src/<NAME>.purs
```

## Cómo escribir tests personalizados

Si quieres escribir tests personalizados adicionales, crea un archivo nuevo `test/Custom.purs` y envíalo junto con tu solución junto con el archivo nuevo:

```shell
exercism submit src/<NAME>.purs test/Custom.purs
```
