# Pruebas

Cada ejercicio incluye las pruebas unitarias y una receta de compilación de Make.
Tú te encargas de la implementación.

Cada archivo de pruebas está pensado para enlazarse con tu implementación y producir un ejecutable de consola que ejecuta las pruebas.
Al ejecutar el ejecutable de pruebas, se imprime un mensaje por cada prueba que falla y se reporta un estado de salida distinto de cero cuando las pruebas fallan.

Para trabajar en un ejercicio:
* Crea la compilación inicial con Make.
* Para cada prueba unitaria:
  * Elimina la línea `TEST_IGNORE()`.
  * Resuelve los errores de compilación para que la prueba falle.
  * Implementa solo lo necesario para que la prueba pase.
  * Refactoriza tu implementación para mejorar la legibilidad, reducir la duplicación, etc.
