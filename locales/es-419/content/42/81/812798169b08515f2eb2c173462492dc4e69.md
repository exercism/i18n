# Acerca de

jq funciona pasando los datos JSON entrantes a través de una _expresión única_ (escrita como una _tubería de filtros_) para lograr los datos transformados deseados.

## Una introducción rápida a las opciones de línea de comandos de `jq`

El lenguaje `jq` es implementado por el _programa_ `jq`.
Este programa proporciona varias opciones de línea de comandos útiles para controlar cómo se consume la entrada y cómo se presenta la salida.

En los ejemplos a continuación encontrarás:

- `-n` o `--null-input`

  Normalmente, al programa `jq` se le da un archivo para leer, o le envías datos a su entrada.
  La opción `--null-input` te permite generar datos JSON sin ninguna entrada.

- `-c` o `--compact-output`

  `jq` formatea su salida de manera legible por defecto.
  Es extremadamente útil para los humanos ver los datos cuando están bien formateados.
  Sin embargo, eso no es necesario para las máquinas: la opción `--compact-output` elimina los espacios en blanco de formateo para minimizar el tamaño del JSON resultante.

- `-f filename` o `--from-file filename`

  Lee el programa `jq` desde `filename` en lugar de proporcionarlo en la línea de comandos.
  `sed` y `awk` usan la opción `-f` para el mismo propósito.
  Verás esto usado en los scripts de prueba para los ejercicios de práctica.

Consulta [el manual][man-cli] para detalles sobre todas las opciones.

## Filtros y tuberías

Los **filtros** también se conocen como **expresiones**.

Un _filtro_ toma una entrada y produce una salida.
Al igual que trabajas en una shell de Unix, puedes unir _filtros_ con una tubería `|` para conectar la salida de un _filtro_ a la entrada de otro.

## El filtro de identidad: `.`

Este es el _filtro_ más simple.
Simplemente pasa su entrada a su salida.
Por ejemplo, `jq` formatea de manera legible por defecto, así que pasar JSON al filtro `.` ¡da una salida bien formateada gratis!

```sh
$ echo '[1, 2, 3]' | jq '.'
[
  1,
  2,
  3
]
```

## Arrays

Esta será una introducción rápida al trabajo con **arrays**.
Cubriremos este tema con mayor detalle más adelante.

Los elementos del _array_ se acceden con corchetes, y están indexados desde cero.

```sh
$ echo '[10, 20, 30]' | jq '.[1]'
20
```

Un _filtro_ puede construir un _array_ envolviendo una expresión en `[` y `]`

- con una lista conocida de elementos:

  ```sh
  jq -n '[1, 2, 3]'
  ```

- para recolectar un flujo de elementos: por ejemplo,
  [`range`][man-range] es una función que produce un flujo de números

  ```sh
  $ jq -n 'range(10; 70; 15)'
  10
  25
  40
  55
  ```

  Usar `[]` recolecta los resultados de la expresión en un array

  ```sh
  $ jq -c -n '[range(10; 70; 15)]'
  [10,25,40,55]
  ```

## La coma es un operador

La _coma_ no es solo sintaxis que separa elementos de un _array_.
**La coma** es un **operador** que une flujos.

Por ejemplo, `[1, 2, 3]` es un _filtro_ que usa el constructor de _array_ `[]` para recolectar el resultado de unir las tres expresiones `1`, `2` y `3`.

¿Notaste los puntos y coma en `range(10; 70; 15)` de arriba?
Como las _comas_ tienen un propósito específico en el lenguaje `jq`, las funciones que toman múltiples argumentos usan puntos y coma para separar los argumentos.

## Objetos

Una introducción rápida a los **objetos**.

Similar a muchos lenguajes de programación, usa puntos para acceder a las propiedades de los _objetos_

```sh
$ echo '{"foo": {"bar": "qux"}}' | jq '.foo.bar'
"qux"
```

También se pueden usar corchetes para los _objetos_, pero entonces se necesitan comillas para los literales de string.
Este es un método para trabajar con claves que contienen espacios.

```sh
$ echo '{"foo bar": "qux"}' | jq '.["foo bar"]'
"qux"
```

Puedes construir un _objeto_ con `{}` y pares `key: value`.
No se requieren comillas alrededor de las _claves_ que son strings "simples".

```sh
jq -n '{question: (6 * 9), answer: 42}'
```

produce

```none
{
  "question": 54,
  "answer": 42
}
```

Para tratar la _clave_ como una _expresión_, debes encerrarla entre paréntesis (lo siguiente también produce lo mismo que arriba).

```sh
echo '[["question", "answer"], [54, 42]]' \
| jq '{(.[0][0]): .[1][0], (.[0][1]): .[1][1]}'
```

## Tuberías

Por ejemplo, dado `file.json` que contiene

```json
{
  "key1": "value1",
  "key2": [5, 15, 25]
}
```

Calculemos la longitud del _array_ key2:

```sh
$ jq '.key2 | length' file.json
3
```

Estamos _pasando por tubería_ la salida de la expresión `.key2` como la entrada a [`length`][man-length], que como era de esperar produce el número de elementos del array.

## Los filtros pueden ignorar su entrada

En este ejemplo, los datos JSON de entrada se ignoran y no tienen impacto en la salida:

```sh
$ echo '{"answer": 42}' | jq '6 * 9'
54
```

## Los filtros pueden producir flujos de datos

Un _filtro_ puede producir más de un valor.
Por ejemplo, el _filtro_ `.[]` produce cada elemento de un _array_ como un valor separado:

```sh
$ jq -n -c '[1, 2, 3]'
[1,2,3]

$ jq -n -c '[1, 2, 3] | .[]'
1
2
3
```

Al pasar por tubería un _filtro_ así a otro, se ejecutará el segundo _filtro_ **_para cada valor_**:

```sh
$ jq -n -c '[1, 2, 3] | .[] | . * 2'
2
4
6
```

Esto es como una iteración implícita.
Una vez que entiendas esta técnica, te darás cuenta de que los _filtros_ de `jq` muy potentes pueden ser muy concisos.

## Paréntesis

Los **paréntesis** se usan para agrupar subexpresiones y forzar el orden de las operaciones, igual que en otros lenguajes.
En `jq`, la necesidad de usarlos puede parecer algo sorprendente.

Por ejemplo, supongamos que queremos construir un _array_ con 2 elementos: la raíz cuadrada de 9; y _e_ elevado a la potencia 1.
Las dos expresiones individuales son `9 | sqrt` y `1 | exp`.
Esperamos que la salida sea el _array_ `[3, 2.7...]`

```jq
$ jq -n '[ 9|sqrt, 1|exp ]'
[
  20.085536923187668,
  2.718281828459045
]
```

¿Por qué no obtuvimos lo que esperábamos? `jq` lo interpreta así:

```jq
[ ((9|sqrt), 1) | exp ]
```

`jq` construye un flujo de dos elementos (`3` y `1`) que se pasan cada uno a `exp`.

Necesitamos asegurarnos de que `exp` solo tome un número como entrada.
En otras palabras, debemos forzar que la tubería se evalúe antes de la coma.

```jq
$ jq -n '[ 9|sqrt, (1|exp) ]'
[
  3,
  2.718281828459045
]
```

## Tipos

Del [manual][man-types]

> jq admite el mismo conjunto de tipos de datos que JSON: números, strings, booleanos, arrays, objetos (que en jerga de JSON son hashes con solo claves de tipo string) y «null».

Aprenderás más sobre estos en ejercicios posteriores.

## Espacios en blanco

Los espacios en blanco no son significativos en `jq`.
Usa espacios, tabulaciones o saltos de línea como mejor te parezca para formatear tu código.
No conocemos ninguna guía de estilo de `jq` existente.

## Valores inmutables

Los valores en `jq` son _inmutables_.
Los filtros que modifican un valor producirán un nuevo valor.
Esto implica que `jq` no tiene variables globales; tendrás que acostumbrarte a pasar el estado de un filtro a otro.

## «Veracidad»

Los valores `false` y `null` se consideran falsos. Cualquier otro valor
(incluyendo el número cero y el string/array/objeto vacío) es verdadero.

## Funciones y operadores

Sin entrar en gran profundidad (las funciones serán un tema para otro ejercicio), aquí hay algunas funciones integradas útiles:

- [`length`][man-length]

  Dado un array como entrada, produce el número de elementos del array.

  ```sh
  $ jq -n '[10, 20, 30, 40] | length'
  4
  ```

- [`+`][man-plus]

  Este operador hace cosas distintas según el tipo de sus operandos:
  suma números,
  concatena strings,
  añade arrays,
  fusiona objetos.

  ```sh
  $ jq -c -n '
      3 + 4,
      "foo" + "bar",
      ["a", "b"] + ["c"],
      {"m": 10} + {"n": 20}
  '
  7
  "foobar"
  ["a","b","c"]
  {"m":10,"n":20}
  ```

  [`add`][man-add] es una función que toma un array y devuelve un elemento con todos los elementos sumados usando las reglas de `+`.
  `[1, 2, 3] | add` produce `6`.

- [`map`][man-map]

  Dado un array como entrada y un filtro como argumento, produce un array donde el filtro se aplica a cada elemento

  ```sh
  $ jq -c -n '[10, 20, 30, 40] | map(. / 5)'
  [2,4,6,8]
  ```

- [`select`][man-select]

  Dado _algo_ de entrada y un filtro como argumento:
  - si el filtro aplicado al argumento da como resultado un valor _verdadero_, produce la entrada sin cambios
  - de lo contrario, no produce _nada_ (no el valor `null`, realmente ninguna salida)

  Por ejemplo, dados algunos números, selecciona los divisibles entre 3

  ```sh
  $ jq -n 'range(10) | select(. % 3 == 0)'
  0
  3
  6
  9
  ```

  Recuerda que `range` produce un _flujo_ de números.
  `select` se invocará una vez por cada número.
  Solo se emiten los números que «pasan» la expresión.

  A menudo necesitas seleccionar elementos de un array.
  Hay un par de formas de hacerlo.

  Con la entrada `["Anne", "Bob", "Cathy", "Dave"]`, selecciona los nombres que tengan longitud 4.
  - usar `map` y `select` juntos

    ```jq
    map(select(length == 4))
    ```

  - expandir el array en elementos, hacer `select` en ese flujo y recolectar los resultados

    ```jq
    [ .[] | select(length == 4) ]
    ```
