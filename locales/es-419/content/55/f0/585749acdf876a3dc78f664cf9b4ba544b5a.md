# Encabezado ficticio

## Instrucciones específicas de Bash

El objetivo de este ejercicio es considerar el número de argumentos que se pasan a tu programa.

Ten en cuenta que puedes pasar strings vacíos como argumentos.

`./program ""`

Esto es distinto de no pasar ningún argumento.

`./program`

Si tu programa se ejecuta con exactamente un argumento (aunque sea un string vacío), tómalo como el nombre de una persona e imprime un mensaje de saludo.
Si se ejecuta sin argumentos o con más de un argumento, imprime un mensaje de error y sal con un estado distinto de cero.
