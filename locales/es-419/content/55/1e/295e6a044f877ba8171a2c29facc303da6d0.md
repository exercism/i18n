# Conjuntos

Un [`set`][type-set] es una colección _mutable_ y _desordenada_ de objetos [_hashable_][hashable].
Los miembros de un conjunto deben ser distintos: no se permiten elementos duplicados.
Pueden contener varios tipos de datos diferentes e incluso estructuras anidadas, como una `tuple` de `tuples`, siempre que todos los elementos se puedan _hashear_.
Los conjuntos también tienen una versión inmutable: [`frozenset`][type-frozenset].

Los conjuntos se usan sobre todo para eliminar rápidamente los duplicados de otras estructuras de datos o agrupaciones de elementos.
También sirven para hacer comparaciones eficientes cuando no se necesita un orden ni un seguimiento de duplicados.

Como otros tipos de colecciones (_diccionarios, arrays, tuplas_), los `sets` admiten:
- Iteración con `for item in <set>`,
- Verificación de pertenencia con `in` y `not in`,
- Cálculo de la longitud con `len()`, y
- Copias superficiales con `copy()`.

Los `sets` no admiten:
- Ningún tipo de indexación
- Un orden, ya sea al ordenarlos o al insertarlos
- Rebanado
- Concatenación mediante `+`


Verificar si un elemento pertenece a un `set` tiene una complejidad temporal constante (en promedio), a diferencia de verificarlo en un `list` o un `string`, donde la complejidad temporal crece a medida que aumenta la cantidad de datos.
Métodos como `<set>.union()`, `<set>.intersection()` o `<set>.difference()` también tienen una complejidad temporal constante (en promedio).

[hashable]: https://docs.python.org/3.7/glossary.html#term-hashable
[type-frozenset]: https://docs.python.org/3/library/stdtypes.html#frozenset
