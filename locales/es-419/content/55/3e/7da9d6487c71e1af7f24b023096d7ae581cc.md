# Pistas

## General

- [Tutorial sobre cómo trabajar con enums][docs.microsoft.com-enumeration-types].

## 1. Analizar el nivel de log

- Existe un [método para obtener una parte de un string][docs.microsoft.com_system_string_substring].
- Puedes usar una [sentencia `switch`][docs.microsoft.com_keyword_switch] para manejar los distintos niveles de log de forma elegante.

## 2. Soportar un nivel de log desconocido

- Existe un [caso especial de switch][docs.microsoft.com_keyword_switch_default] que se puede usar para capturar los casos no especificados.

## 3. Convertir la línea de log al formato corto

- Se pueden [asignar valores específicos a los miembros del enum][docs.microsoft.com_creating-an-enumeration-type].
- Convertir un enum a un número se puede hacer mediante [casting][docs.microsoft.com_enumeration-types-casting] o usando una [cadena de formato][docs.microsoft.com_system.enum.tostring].
