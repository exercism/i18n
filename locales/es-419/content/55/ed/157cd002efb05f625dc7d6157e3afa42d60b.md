# Instrucciones

El puerto de Palermo es un puerto muy concurrido, con muchos barcos que entran y salen.
Durante mucho tiempo ha tenido un sistema manual para llevar un registro de los barcos que están actualmente en el puerto.
Este sistema es muy propenso a errores, y el jefe del puerto ha decidido reemplazarlo por un sistema computarizado.

El jefe del puerto te ha contratado para implementar el nuevo sistema.
El sistema debe manejar identificadores para los barcos, pero también para los destinos.

## 1. Crea el identificador del puerto

Lo primero que debes hacer es crear el identificador del puerto de Palermo.
El identificador se forma con las primeras cuatro letras del nombre del puerto, en mayúsculas.

Define la constante `Port::IDENTIFIER` como un símbolo con el valor `:PALE`.
    
```ruby
Port::IDENTIFIER 
# => :PALE
```

## 2. Obtén los identificadores de otros puertos

El programa también tendrá que manejar otros puertos, así que necesitas crear identificadores para ellos también.
Al puerto le gustaría que el sistema fuera automatizado y, como los puertos usan diferentes convenciones de nombres, los identificadores deben generarse a partir del nombre del puerto.
El identificador se forma con las primeras cuatro letras del nombre del puerto, en mayúsculas.

Define el método `Port.get_identifier` para que reciba un string como argumento y devuelva el identificador de ese puerto como un símbolo.

```ruby
Port.get_identifier("Hamburg") 
# => :HAMB
```

## 3. Determina en qué terminal debe atracar un barco

El puerto tiene dos terminales, y el sistema necesita determinar en qué terminal debe atracar un barco.
La terminal se determina por el identificador del barco.

El identificador se compone de 2 partes: la primera son 3 letras en mayúsculas que indican qué carga transporta el barco, y luego 3 números que son el identificador único del barco.

Si el barco transporta **OIL** o **GAS**, debe atracar en la terminal **A**.
De lo contrario, debe atracar en la terminal **B**.

Define el método `Port.get_terminal` para que reciba como argumento un símbolo que sea el identificador del barco.
El método debe devolver la terminal como un símbolo.

```ruby
Port.get_terminal(:OIL123)
# => :A
```
