# General

[El tutorial de comparaciones de Python][python comparisons tutorial] y los [ejemplos de comparaciones en Python][python comparisons examples] son una gran introducción que cubre el contenido de este ejercicio.

## 1. Calcula el valor de una carta

- Puedes usar el operador de comparación de igualdad `==` para determinar si una carta es un as: `card == 'A'`.
- Puedes usar el operador de pertenencia `in` para determinar si una subcadena está contenida dentro de un string: `'Q' in 'KJQ'`.
- Puedes usar el [constructor `int`][int constructor] para convertir un `str` de un `int` a un `int`: `int('13')`.

## 2. Determina qué carta tiene un valor más alto

- Una vez que hayas definido la función `value_of_card`, puedes llamarla desde otras funciones.
- Puedes usar los operadores de comparación de valores `>` y `<` para determinar si ciertas cartas son _mayores que_ o _menores que_ un valor dado: `3 < 12`.
- Puedes usar el operador de comparación de igualdad `==` para determinar si dos valores son iguales entre sí.

## 3. Calcula el valor de un as

- Una vez que hayas definido la función `value_of_card`, puedes llamarla desde otras funciones.
- Puedes usar el operador de comparación de orden `>` para decidir el curso de acción adecuado aquí.

## 4. Determina el blackjack

- Recuerda que puedes usar la [sintaxis de `if`/`elif`/`else`][if syntax] para manejar diferentes combinaciones de cartas.
- Puedes encadenar TANTO operadores de comparación como operadores Boolean _de forma arbitraria_: `y < z < x` o `(y or z) and (x or z)`
- Puedes reutilizar la función `value_of_card` que ya implementaste.

## 5. Divide las parejas

- Puedes reutilizar la función `value_of_card` que ya implementaste.
- Puedes manejar por separado el caso de la `A` (cuando al menos una de las cartas es un as).

## 6. Dobla la apuesta

- Un `A` con valor de 11 nunca permitirá doblar si hay dos cartas en la mano.
- Dado el primer punto, _deberías_ poder reutilizar la función `value_of_card` que ya implementaste.
- Puedes encadenar operadores de comparación _de forma arbitraria_: `y < z < x`.
- Puedes usar la [expresión condicional][conditional expression] (_a veces llamada «operador ternario»_)
  para acortar sentencias `if`/`else` simples: `13 if letter == 'M' else 3`.
