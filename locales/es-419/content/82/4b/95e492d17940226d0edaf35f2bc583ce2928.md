# Instrucciones

Mika, la organizadora de eventos, recibió un ascenso en el trabajo y, como parte de sus nuevas responsabilidades, quedó a cargo de la base de datos de eventos. Pronto se dio cuenta de que muchos de los datos están guardados de formas que dificultan trabajar con ellos, así que te unes a ella para limpiarlos con un script de una sola vez.

Como el script solo se va a ejecutar una vez y tienes confianza en la estructura de los datos, consideras que este es un buen lugar para usar las _aserciones let_ de Gleam.

## 1. Extrae los errores

Cada evento pasado tiene una lista de problemas que ocurrieron durante el evento. Se han guardado como resultados, pero siempre son la variante `Error`.


Implementa la función `extract_error`, que recibe un resultado que se espera que siempre sea un `Error` y devuelve el valor de error que contiene.

```gleam
extract_error(Error("Not enough coffee"))
// -> "Not enough coffee"
```

## 2. Quita el prefijo del equipo

A los nombres de los equipos se les ha agregado el prefijo «Team », pero eso no es necesario. Implementa la función `remove_team_prefix` para quitar el prefijo del nombre de un equipo.

```gleam
remove_team_prefix("Team Turtle")
// -> "Turtle"
```

## 3. Separa la región y el equipo

Cada evento lo organiza un equipo, y cada equipo pertenece a una región. En la base de datos se guardan en un solo string, separados por una coma.

Implementa la función `split_region_and_team` para dividir el string en una tupla de dos strings, uno para la región y otro para el equipo. Hay que quitar el prefijo «Team » del nombre del equipo.

```gleam
split_region_and_team("East,Team Orange")
// -> #("East", "Orange")
```
