# Instrucciones

Como futura maga, Elyse necesita practicar algunos conceptos básicos. Tiene una pila de cartas que quiere manipular.

Para que todo sea un poco más fácil, solo usa las cartas del 1 al 10, así que su pila de cartas se puede representar con un array de números. La posición de una carta corresponde al índice en el array. Es decir, la posición 0 se refiere a la primera carta, la posición 1 a la segunda, etc.

<!-- prettier-ignore-start -->
~~~~exercism/note
Todas las funciones, excepto dos, deben actualizar el array de cartas y luego devolver el array modificado. Es una forma común de trabajar conocida como el patrón Builder, que te permite encadenar funciones de forma muy ordenada.

Las dos excepciones son `getItem`, que debe devolver la carta en la posición dada, y `checkSizeOfStack`, que debe devolver `true` si el tamaño dado coincide.
~~~~
<!-- prettier-ignore-end -->

## 1. Obtén una carta de la pila

Para tomar una carta, devuelve la carta en el índice `position` de la pila dada.

```javascript
const position = 2;
getItem([1, 2, 4, 1], position);
// => 4
```

## 2. Intercambia una carta en la pila

Haz un poco de juego de manos e intercambia la carta en el índice `position` por la carta de reemplazo proporcionada.
Devuelve la pila ajustada.

```javascript
const position = 2;
const replacementCard = 6;
setItem([1, 2, 4, 1], position, replacementCard);
// => [1, 2, 6, 1]
```

## 3. Inserta una carta en la parte superior de la pila

Haz aparecer una carta insertando una carta nueva en la parte superior de la pila.
Devuelve la pila ajustada.

```javascript
const newCard = 8;
insertItemAtTop([5, 9, 7, 1], newCard);
// => [5, 9, 7, 1, 8]
```

## 4. Elimina una carta de la pila

Haz desaparecer una carta quitando la carta en la `position` dada de la pila.
Devuelve la pila ajustada.

```javascript
const position = 2;
removeItem([3, 2, 6, 4, 8], position);
// => [3, 2, 4, 8]
```

## 5. Elimina la carta superior de la pila

Haz desaparecer una carta quitando la carta de la parte superior de la pila.
Devuelve la pila ajustada.

```javascript
removeItemFromTop([3, 2, 6, 4, 8]);
// => [3, 2, 6, 4]
```

## 6. Inserta una carta en la parte inferior de la pila

Haz aparecer una carta insertando una carta nueva en la parte inferior de la pila.
Devuelve la pila ajustada.

```javascript
const newCard = 8;
insertItemAtBottom([5, 9, 7, 1], newCard);
// => [8, 5, 9, 7, 1]
```

## 7. Elimina una carta de la parte inferior de la pila

Haz desaparecer una carta quitando la carta de la parte inferior de la pila.
Devuelve la pila ajustada.

```javascript
removeItemAtBottom([8, 5, 9, 7, 1]);
// => [5, 9, 7, 1]
```

## 8. Comprueba el tamaño de la pila

Comprueba si el tamaño de la pila es igual a `stackSize` o no.

```javascript
const stackSize = 4;
checkSizeOfStack([3, 2, 6, 4, 8], stackSize);
// => false
```
