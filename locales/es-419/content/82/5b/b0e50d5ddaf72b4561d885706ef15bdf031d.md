# Introducción

En C#, las estructuras de datos que pueden contener cero o más elementos se conocen como _colecciones_. Un **array** (_arreglo_) es una colección que tiene un tamaño/longitud fijo y cuyos elementos deben ser todos del mismo tipo. A los elementos se les puede asignar un valor o recuperarlo de ellos usando un índice. En C#, los arrays están indexados desde cero, lo que significa que el índice del primer elemento siempre es cero:

```csharp
// Declare array with explicit size (size is 2)
int[] twoInts = new int[2];

// Assign second element by index
twoInts[1] = 8;

// Retrieve the second element by index
twoInts[1] == 8; // => true
```

Los arrays también se pueden definir con una notación abreviada que te permite crear el array y asignarle sus valores al mismo tiempo. Como ahora el compilador puede saber cuántos elementos tendrá el array, se puede omitir la longitud:

```csharp
// Three equivalent ways to declare and initialize an array (size is 3)
int[] threeIntsV1 = new int[] { 4, 9, 7 };
int[] threeIntsV2 = new[] { 4, 9, 7 };
int[] threeIntsV3 = { 4, 9, 7 };
```

Puedes manipular los arrays llamando a los métodos o las propiedades de una instancia de array, o usando los métodos estáticos definidos en la clase `Array`.
