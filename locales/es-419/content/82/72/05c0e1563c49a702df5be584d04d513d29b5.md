# Ayuda

Si tienes problemas, puedes usar uno de los siguientes recursos:

- [Tarjeta de referencia de ARM64](https://courses.cs.washington.edu/courses/cse469/19wi/arm64.pdf)
- [Documentación oficial de ARM](https://developer.arm.com/documentation)
- [El manual de GAS](https://sourceware.org/binutils/docs/as/)
- [La sección de detalles específicos de AArch64 de GAS](https://sourceware.org/binutils/docs/as/AArch64_002dDependent.html#AArch64_002dDependent)
- Puedes usar [StackOverflow](http://stackoverflow.com) para buscar tu problema y ver si ya tiene respuesta. También puedes hacer y responder preguntas.
