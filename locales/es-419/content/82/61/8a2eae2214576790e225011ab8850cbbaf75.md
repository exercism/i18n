# Vectores como pila

Una pila es una estructura de datos lineal optimizada para el acceso desde un extremo. Una metáfora adecuada es una pila de hojas de papel ensartadas en una varilla: las hojas nuevas siempre se añaden por el mismo extremo, y las hojas se retiran en el orden inverso al que se añadieron. Las hojas que se añadieron primero se retiran al final, y las que se añadieron al final se retiran primero.

La estructura de datos `Vec` de Rust es apropiada para usarla como pila. El [método `push`](https://doc.rust-lang.org/std/vec/struct.Vec.html#method.push) añade elementos al final del vector. El [método `pop`](https://doc.rust-lang.org/std/vec/struct.Vec.html#method.pop) elimina el último elemento del vector. Tanto `push` como `pop` requieren solo un tiempo amortizado `O(1)`.

## Ejemplo

En este ejemplo, usamos un vector como pila para una calculadora [RPN](https://en.wikipedia.org/wiki/Reverse_Polish_notation) sencilla. Puedes encontrar el código fuente completo en el [playground](https://play.rust-lang.org/?version=stable&mode=debug&edition=2018&gist=b40514e282cb753d0c3272778f92d736).

```rust
#[derive(Default)]
pub struct RpnCalculator {
    stack: Vec<Value>,
}

impl RpnCalculator {
    pub fn evaluate(&mut self, argument: Argument) -> Result<(), Error> {
        match argument {
            Argument::Value(value) => self.stack.push(value),
            Argument::Operator(operator) => {
                let b = self.stack.pop().ok_or(Error::StackUnderflow)?;
                let a = self.stack.pop().ok_or(Error::StackUnderflow)?;
                let output = operator.execute()(a, b);
                self.stack.push(output);
            }
        }
        Ok(())
    }

    pub fn conclude(self) -> Result<Value, Error> {
        if self.stack.len() == 1 {
            Ok(self.stack[0])
        } else {
            Err(Error::IncompleteCalculation)
        }
    }
}
```
