# Acerca de

[C++](https://en.wikipedia.org/wiki/C%2B%2B) (se pronuncia «ci plus plus») es un lenguaje de programación de propósito general desarrollado por [Bjarne Stroustrup](https://en.wikipedia.org/wiki/Bjarne_Stroustrup) a partir de 1979 en Bell Labs. Es inmensamente popular, sobre todo para las aplicaciones que requieren velocidad y/o acceso a ciertas características de bajo nivel. Se considera un lenguaje de nivel intermedio, ya que reúne características de lenguajes tanto de alto como de bajo nivel.

C++ admite la programación procedimental, orientada a objetos, funcional y genérica. Hay compiladores de C++ disponibles para prácticamente todas las plataformas, incluidas Windows, Mac OS y Linux.

Beneficios clave:
- **Seguridad de tipos:** Encapsula las operaciones inseguras necesarias
- **Seguridad de recursos:** No toda la gestión de recursos consiste en administrar memoria
- **Rendimiento:** Es importante para algunas partes de casi todos los sistemas
- **Previsibilidad:** Para sistemas de tiempo real duros y blandos
- **Facilidad de enseñanza:** La complejidad del código debe ser proporcional a la complejidad de la tarea
- **Legibilidad:** Para las personas y las máquinas («capacidad de análisis»)
- **Asignación directa al hardware:** de las instrucciones y los tipos de datos fundamentales
- **Abstracción sin sobrecarga:** Clases con constructores y destructores, herencia, programación genérica, técnicas de programación funcional

El estándar de C++ lo mantiene la Organización Internacional de Normalización (ISO), y la versión actual de C++ a junio de 2018 es C++17 (su nombre no indica que sea la decimoséptima versión de C++, sino que el estándar se ratificó en 2017).

Lo mejor de C++ es que se ejecuta en todo, desde procesadores embebidos con recursos muy limitados hasta el supercomputador mainframe más grande y cualquier computadora personal intermedia.
