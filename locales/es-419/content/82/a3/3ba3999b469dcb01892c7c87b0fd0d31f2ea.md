# Clases inmutables

```sather
immutable class BEARING is
   readonly attr degrees : INT;
   create(d : INT) : SAME is
      b : SAME;
      return b.degrees(d);
   end;
end;
```

## Qué cambia

| | clase ordinaria | clase inmutable |
| --- | --- | --- |
| asignación | comparte el objeto | copia el valor |
| puede ser void | sí | no |
| Escritor de `attr` | `x.a := v` | `x := x.a(v)` |
| `new` | sí | no; `x : SAME` ya existe |

Un objeto inmutable no puede ser void, así que `void(b)` siempre es falso y ninguna de sus rutinas puede fallar por falta de un objeto. Eso elimina toda una categoría de errores a costa de no poder decir nunca «todavía no hay un bearing».

## Dónde vive el valor

El valor se almacena donde está la variable, ya sea dentro de otro objeto o en la pila, en lugar de alcanzarse mediante una referencia. Así, un `ARRAY{BEARING}` contiene los propios objetos BEARING, no punteros a ellos, lo que lo hace más pequeño y más rápido de recorrer.

El costo es la copia: pasar un objeto inmutable grande lo copia cada vez. Es mejor mantenerlos pequeños.

## Las rutinas de atributo

`readonly attr degrees : INT` proporciona dos rutinas:

```sather
   b.degrees          -- read: INT
   b.degrees(90)      -- answer a new BEARING with degrees changed
```

La segunda existe incluso bajo `readonly`, porque no cambia nada: construye un nuevo valor. Bajo un `attr` normal es pública; bajo `private attr` no lo es.

## is_eq y str

Ninguna de las dos se proporciona. Escribe `is_eq` para `=`, y `str` para que el objeto se pueda imprimir y unir a strings:

```sather
   is_eq(other : SAME) : BOOL is return degrees = other.degrees; end;
   str : STR is return degrees.str + " degrees"; end;
```

Escribir `str` hace que la clase sea conforme a `$STR`, que es lo que permite que `+` y `#OUT` la acepten.

## Las integradas

`INT`, `BOOL`, `CHAR`, `FLTD` y `TUP` son todas clases inmutables. No tienen nada de especial: están escritas en Sather en la biblioteca de la misma manera, y se comportan como lo hacen por las razones anteriores.
