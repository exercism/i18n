## Formato

Aunque a Common Lisp no le importan la indentación ni el diseño del código, ni si usas espacios o tabulaciones, es algo importante que debes tener en cuenta al enviar soluciones a Exercism.
El widget de código de Exercism.org no maneja bien la mezcla de tabulaciones y espacios, así que se recomienda usar solo espacios para que el código sea más legible para las personas que lo revisan.
Revisa la configuración de tu editor para lograrlo.
A continuación tienes las instrucciones para los editores más populares de Common Lisp.

### VIM

Usa los siguientes comandos para asegurarte de que VIM use solo espacios para la indentación:

```vimscript
:set tabstop=2
:set shiftwidth=2
:set expandtab
```

(o en una sola línea, `:set tabstop=2 shiftwidth=2 expandtab`). Puedes agregarlo a tu archivo `~/.vimrc` para usarlo siempre.

### Emacs

Emacs es ideal para editar Common Lisp y tiene muchos paquetes adicionales potentes disponibles. Lo único que hay que hacer con un Emacs sin configurar para que funcione bien con Exercism.org es evaluar el siguiente código:

`(setq-default indent-tabs-mode nil)`

Puedes ponerlo en tu `~/.emacs` (o `~/.emacs.d/init.el`) para que quede configurado cada vez que inicies Emacs.

Un complemento recomendado para Emacs y Common Lisp es [SLIME][slime], que ofrece una integración estrecha con el REPL y hace que programar y probar de forma iterativa sea muy fácil.
