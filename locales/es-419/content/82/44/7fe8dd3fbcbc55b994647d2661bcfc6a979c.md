# Acerca de

Scala es un lenguaje de programación que escala contigo: desde pequeños scripts hasta grandes aplicaciones multiplataforma.

Scala combina la programación orientada a objetos y la programación funcional en un solo lenguaje conciso y de alto nivel. Los tipos estáticos de Scala ayudan a evitar bugs en aplicaciones complejas, y sus entornos de ejecución JVM, JavaScript y Native te permiten construir sistemas de alto rendimiento con acceso fácil a enormes ecosistemas de bibliotecas.

* Funcionalidades
    * Interoperabilidad con la JVM - Scala se ejecuta en la JVM, así que los stacks de Java y Scala se pueden combinar para lograr una integración fluida.
    * Interoperabilidad con JS y Native - Scala puede ejecutarse en el navegador y en dispositivos nativos, gracias a [Scala.js](https://www.scala-js.org/) y [Scala Native](https://github.com/scala-native/scala-native)
    * Inferencia de tipos - Scala tiene tipado estático. Sin embargo, Scala ofrece inferencia de tipos para aligerar la carga de un sistema de tipos avanzado.
    * Orientado a objetos - Scala es un lenguaje puramente orientado a objetos en el sentido de que cada valor es un objeto. Los tipos de datos y los comportamientos de los objetos se describen mediante clases y traits. Las abstracciones de clase se extienden mediante la creación de subclases y mediante un mecanismo flexible de composición basado en mixins para evitar los problemas de la herencia múltiple.
    * Funcional - Scala también es un lenguaje funcional en el sentido de que cada función es un valor. Scala ofrece una sintaxis ligera para definir funciones anónimas, admite funciones de orden superior, permite anidar funciones y admite currying. Las case classes de Scala y su soporte integrado para la coincidencia de patrones modelan los tipos algebraicos que se usan en muchos lenguajes de programación funcional. Los objetos singleton ofrecen una forma práctica de agrupar funciones que no son miembros de una clase.
    * Concurrencia y distribución - Usa operaciones de paralelismo de datos sobre colecciones, usa actores para la concurrencia y la distribución, o futures para la programación asíncrona.
