# Apéndice de las instrucciones

## Registros

| Registro | Uso       | Tipo    | Descripción                                            |
| -------- | --------- | ------- | ------------------------------------------------------ |
| `$a0`    | entrada   | dirección | primer color como string terminado en nulo            |
| `$a1`    | entrada   | dirección | segundo color como string terminado en nulo           |
| `$a2`    | entrada   | dirección | tercer color como string terminado en nulo (posiblemente vacío) |
| `$v0`    | salida    | entero  | valor de la resistencia                                |
| `$t0-9`  | temporal  | cualquiera | para almacenamiento temporal                        |
