# Anexo de instrucciones

## Implementación

Supuestos:

1. El cero siempre se representa en las salidas como [0] en lugar de [].
2. En ningún otro caso aparecen ceros a la izquierda en las salidas.
3. Los ceros a la izquierda sí se aceptan en las entradas.
4. Una secuencia vacía de dígitos de entrada se considera cero, no un error.

Maneja los casos problemáticos devolviendo un error cuyo método Error() devuelva uno de los siguientes mensajes:

- input base must be >= 2
- output base must be >= 2
- all digits must satisfy 0 <= d < input base
