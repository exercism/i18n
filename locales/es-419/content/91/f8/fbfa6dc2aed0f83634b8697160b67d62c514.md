# Acerca de

Los números de punto flotante son números fraccionarios o enteros que incluyen un punto decimal (como `3.14`, `-1.7`, `99.99`, `2048.0`).

El tipo float de Common Lisp se subdivide en varios subtipos, cada uno con sus propias características y precisión: short-float, single-float, double-float y long-float.

El subtipo short-float suele ocupar la menor cantidad de memoria y ofrece la precisión más baja de los cuatro subtipos. Es adecuado para situaciones en las que el uso de memoria es una preocupación, pero se puede aceptar menos precisión.

El subtipo single-float ofrece un equilibrio entre el uso de memoria y la precisión. Se usa comúnmente para cálculos de punto flotante de propósito general.

El subtipo double-float ofrece mayor precisión en comparación con single-float y es adecuado para aplicaciones que requieren cálculos más precisos, como cómputos científicos y simulaciones numéricas.

El subtipo long-float ofrece la mayor precisión de los cuatro subtipos, pero puede requerir más memoria en comparación con los otros. Por lo general se usa en aplicaciones especializadas que exigen cálculos extremadamente precisos.

Estos subtipos permiten a quienes programan en Common Lisp elegir el nivel adecuado de precisión y de uso de memoria según los requisitos de sus aplicaciones específicas.

En general, si trabajas solo con números enteros, conviene que prefieras los enteros, ya que no sufren la misma pérdida de precisión que los números de punto flotante a lo largo de muchos cálculos.

## Referencia

```lisp
;; Rounding to the Nearest Whole Number
(round 3.14)  ; => 3
(round -3.14) ; => -3
(round 2.72)  ; => 3
(round -2.72) ; => -3

;; Rounding Towards Zero
(truncate 3.14)  ; => 3
(truncate -3.14) ; => -3
(truncate 2.72)  ; => 2
(truncate -2.72) ; => -2

;; Rounding Towards Negative Infinity
(floor 3.14)  ; => 3
(floor -3.14) ; => -4
(floor 2.72)  ; => 2
(floor -2.72) ; => -3

;; Rounding Towards Positive Infinity
(ceiling 3.14)  ; => 4
(ceiling -3.14) ; => -3
(ceiling 2.72)  ; => 3
(ceiling -2.72) ; => -2
```
