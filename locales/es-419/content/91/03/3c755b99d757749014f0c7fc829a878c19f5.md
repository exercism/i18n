# Anexo de instrucciones

## Implementación

Este problema se puede resolver fácilmente con la [función `sqrt` integrada de Roc](sqrt).

Sin embargo, nos gustaría que consideres el reto de resolver este ejercicio sin usar funciones integradas ni módulos.

Aunque existe una fórmula matemática que permite hallar la raíz cuadrada de _cualquier_ número, hemos optado por aceptar como soluciones solo los [números naturales][natural-number] (enteros positivos).

[sqrt]: https://www.roc-lang.org/docs/main/Num/#F64.sqrt
[natural-number]: https://en.wikipedia.org/wiki/Natural_number
