# Instrucciones

Elyse, futura maga, continúa su entrenamiento.
Va a recibir varias barajas de cartas con las que deberá hacer sus trucos.
Para que sea todo un poco más fácil, solo usa las cartas del 1 al 10.
Solo tiene una de cada carta, no hay duplicados en sus barajas.

En este ejercicio, usa métodos de la biblioteca Base de Julia para analizar el contenido de un array.

## 1. Determina si una carta está presente

Elyse quiere determinar si una carta está presente en la baraja, es decir, si la baraja contiene un número específico.

```julia-repl
julia> card = 3;

julia> has_card([2, 3, 4, 5], card)
true
```

## 2. Encuentra la posición de una carta

Elyse quiere saber la posición (índice) de una carta en la baraja.
Si la carta no está en la baraja, devuelve `nothing`.

```julia-repl
julia> card = 2;

julia> find_card([9, 7, 3, 2], card)
4
```

## 3. Determina si cada carta es par

Elyse quiere saber si cada carta es par, es decir, si cada número de la baraja es par.

```julia-repl
julia> all_cards_even([2, 4, 6, 7])
false
```

## 4. Comprueba si la baraja contiene una carta con valor impar

Elyse quiere saber si hay un número impar en la baraja.

```julia-repl
julia> any_odd_cards([3, 2, 6, 4, 8])
true
```

## 5. Determina la posición de la primera carta que sea par

Elyse quiere saber la posición de la primera carta que sea par.
Si no hay cartas pares en la baraja, devuelve `nothing`.

```julia-repl
julia> first_even_card_idx([5, 2, 3, 1])
2
```

## 6. Obtén la primera carta impar de la baraja

Elyse quiere saber el valor de la primera carta que sea impar.
Si no hay cartas impares en la baraja, devuelve `nothing`.

```julia-repl
julia> first_odd_card([4, 2, 8, 7, 9])
7
```
