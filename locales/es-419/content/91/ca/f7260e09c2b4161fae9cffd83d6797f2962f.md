# Debug

Cuando una prueba falla, se muestra un mensaje que describe qué salió mal y para qué argumento. También puedes aprovechar que la [salida de la consola][fmt-println] se mostrará. Puedes escribir en la consola usando:

```go
import "fmt"
fmt.Println("Debug message")
```

[fmt-println]: https://pkg.go.dev/fmt#Println

Nota: cuando depuras con el editor del navegador, usar, por ejemplo, `fmt.Print` no agrega un salto de línea después de la salida, lo que puede provocar un bug en `go test --json` y arruinar la salida de las pruebas.
