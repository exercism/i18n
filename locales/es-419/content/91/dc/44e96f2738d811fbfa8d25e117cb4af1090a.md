# Instrucciones

Como te apasiona el ajedrez, quieres escribir tu propia versión del juego.
Sí, puede que ya haya muchas implementaciones de ajedrez disponibles en línea, ¡pero la tuya será única!

Empiezas implementando un sistema básico de movimiento para las piezas.

La partida de ajedrez se jugará en un tablero de ocho casillas de ancho por ocho casillas de largo.
Las casillas se identifican con una letra y un número.

## 1. Define el rango de filas y columnas

El juego tendrá que guardar las filas del tablero.
Las filas son las líneas horizontales del tablero y se numeran del 1 al 8.

El juego también tendrá que guardar las columnas del tablero.
Las columnas son las líneas verticales del tablero y se identifican con las letras de la A a la H.

Define las constantes `Chess::RANKS` y `Chess::FILES`, que almacenan el rango de filas y columnas respectivamente.

```crystal
Chess::RANKS
# => 1..8

Chess::FILES
# => 'A'..'H'
```

## 2. Comprueba si la casilla es válida

El juego tendrá que comprobar si una casilla es válida.
Una casilla es válida si la fila y la columna están dentro de los rangos de filas y columnas.

Define el método `Chess.valid_square?`, que toma los argumentos `rank`, que contiene un int de la fila, y `file`, que contiene un char de la columna.
El método debe devolver `true` si la fila y la columna están dentro del rango de filas y columnas, y devolver `false` en caso contrario.

```crystal
Chess.valid_square?(1, 'A')
# => true
```

## 3. Obtén el apodo del jugador

El juego tendrá que obtener el apodo del jugador.
El apodo son los dos primeros caracteres del nombre del jugador y los dos últimos caracteres de su apellido.
El apodo debe estar en mayúsculas.

Define el método `Chess.nickname`, que toma los argumentos `first_name`, que contiene un string con el nombre del jugador, y `last_name`, que contiene un string con el apellido del jugador.
El método debe devolver el apodo del jugador como un string en mayúsculas.

```crystal
Chess.nickname("John", "Doe")
# => "JOOE"
```

## 4. Crea el mensaje de movimiento

El juego tendrá que crear un mensaje para un movimiento en el que se indique qué jugador se movió a qué casilla.
El mensaje debe usar el apodo del jugador y la casilla a la que se movió.
El juego también debe determinar si el movimiento es válido comprobando que la columna y la fila de la casilla estén dentro de los rangos de columnas y filas.

Si el movimiento es válido, el mensaje debe ser: `"{nickname} moved to {square}"`
Si el movimiento no es válido, el mensaje debe ser: `"{nickname} attempted to move to {square}, but that is not a valid square"`

Define el método `Chess.move_message`, que toma los argumentos `first_name`, que contiene un string con el first_name del jugador, `last_name`, que contiene un string con el last_name del jugador, y `square`, que contiene un string con la casilla a la que se movió el jugador.
El método debe devolver el mensaje del movimiento como un string.

```crystal
Chess.move_message("John", "Doe", "A1")
# => "JOOE moved to A1"
```
