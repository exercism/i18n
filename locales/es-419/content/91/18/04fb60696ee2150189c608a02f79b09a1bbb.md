# Instrucciones

Tu tarea es analizar coordenadas GPS.
Cada coordenada está formateada usando la variante del [formato de grados decimales](https://en.wikipedia.org/wiki/Decimal_degrees) con hemisferios explícitos:

```text
<LATITUDE_DEGREES> <LATITUDE_HEMISPHERE>, <LONGITUDE_DEGREES> <LONGITUDE_HEMISPHERE>
```

Estos son los valores permitidos para cada componente individual:

- `<LATITUDE_DEGREES>`: un número de punto flotante en el rango 0..90 (inclusive)
- `<LATITUDE_HEMISPHERE>`: ya sea `N` o `S`
- `<LONGITUDE_DEGREES>`: un número de punto flotante en el rango 0..180 (inclusive)
- `<LONGITUDE_HEMISPHERE>`: ya sea `E` o `W`

Por ejemplo, `"48.8584 N, 2.2945 E"` se analiza como:

- `<LATITUDE_DEGREES>`: 48.8584
- `<LATITUDE_HEMISPHERE>`: N
- `<LONGITUDE_DEGREES>`: 2.2945
- `<LONGITUDE_HEMISPHERE>`: E

Tienes 11 tareas, en las que irás analizando coordenadas GPS de forma incremental.
Usarás el soporte de [gramática de cláusulas definidas](https://en.wikipedia.org/wiki/Definite_clause_grammar) (DCG) de Prolog, que están diseñadas para analizar texto estructurado.

````exercism/note
Para ayudarte a empezar, el archivo stub ya incluye la [biblioteca `dcg/basics`](https://www.swi-prolog.org/pldoc/doc/_SWI_/library/dcg/basics.pl) mediante:

```prolog
:- use_module(library(dcg/basics)).
```
````

## 1. Analiza una coma

Implementa la regla `comma` para analizar una sola coma (`","`):

```prolog
?- string_codes(",", Codes), phrase(comma, Codes).
```

## 2. Analiza un espacio

Implementa la regla `space` para analizar un solo espacio (`" "`):

```prolog
?- string_codes(" ", Codes), phrase(space, Codes).
```

## 3. Admite todos los espacios en blanco (excepto los saltos de línea)

Modifica la regla `space` para analizar _todos_ los espacios en blanco, excepto los saltos de línea:

```prolog
?- string_codes("\t", Codes), phrase(space, Codes).

?- string_codes("\n", Codes), phrase(space, Codes).
false.
```

## 4. Analiza el hemisferio de la latitud

El hemisferio de la latitud puede ser `"N"` o `"S"`, que deben analizarse como el átomo `north` o `south`.
Implementa la regla `latitude_hemisphere` para analizar el hemisferio de la latitud:

```prolog
?- string_codes("N", Codes), phrase(latitude_hemisphere(Hemisphere), Codes).
Hemisphere = north.
```

## 5. Analiza el hemisferio de la longitud

El hemisferio de la longitud puede ser `"E"` o `"W"`, que deben analizarse como el átomo `east` o `west`.
Implementa la regla `longitude_hemisphere` para analizar el hemisferio de la longitud:

```prolog
?- string_codes("E", Codes), phrase(longitude_hemisphere(Hemisphere), Codes).
Hemisphere = east.
```

## 6. Analiza los grados

Los grados de una longitud o una latitud se definen como un número de punto flotante.
Implementa la regla `degrees` para analizar números de punto flotante:

```prolog
?- string_codes("748.012", Codes), phrase(degrees(Degrees), Codes).
Degrees = 748.012.
```

## 7. Analiza los grados de latitud

Los grados de latitud no son solo números de punto flotante, sino números de punto flotante en el rango 0..90 (inclusive).
Implementa la regla `latitude_degrees` para analizar los grados de latitud usando el rango anterior:

```prolog
?- string_codes("48.745", Codes), phrase(latitude_degrees(Degrees), Codes).
Degrees = 48.745.

?- string_codes("117.844", Codes), phrase(latitude_degrees(Degrees), Codes).
false.
```

## 8. Analiza los grados de longitud

Los grados de longitud no son solo números de punto flotante, sino números de punto flotante en el rango 0..180 (inclusive).
Implementa la regla `longitude_degrees` para analizar los grados de longitud usando el rango anterior:

```prolog
?- string_codes("178.773", Codes), phrase(longitude_degrees(Degrees), Codes).
Degrees = 178.773.

?- string_codes("-22.523", Codes), phrase(longitude_degrees(Degrees), Codes).
false.
```

## 9. Analiza la latitud

Las latitudes tienen dos partes: sus grados y su hemisferio, que están separados por un espacio.
Implementa la regla `latitude` para analizar una latitud:

```prolog
?- string_codes("56.101 N", Codes), phrase(latitude(Degrees, Hemisphere), Codes).
Degrees = 56.101,
Hemisphere = north.
```

## 10. Analiza la longitud

Las latitudes tienen dos partes: sus grados y su hemisferio, que están separados por un espacio.
Implementa la regla `latitude` para analizar una latitud:

```prolog
?- string_codes("143.889 W", Codes), phrase(longitude(Degrees, Hemisphere), Codes).
Degrees = 143.889,
Hemisphere = west.
```

## 11. Analiza la coordenada

Las coordenadas tienen dos partes: su latitud y su longitud, que están separadas por una coma seguida de un espacio.
Implementa la regla `coordinate` para analizar tanto la latitud (grados y hemisferio):

```prolog
?- string_codes("48.8584 N, 2.2945 E", Codes), phrase(coordinate(Latitude, LatitudeHemisphere, Longitude, LongitudeHemisphere), Codes).
Latitude = 48.8584,
LatitudeHemisphere = north,
Longitude = 2.2945,
LongitudeHemisphere = east.
```
