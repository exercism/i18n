# Pistas

## General

- En la [guía de introducción][guide] de Elixir hay un buen repaso sobre las funciones con nombre.

## 1. Genera la respuesta cuando el intento coincide con el número secreto

- Puedes usar una [guarda][guard] para comprobar si los números son iguales con `===/2`.

## 2. Genera la respuesta cuando el intento es mayor que el número secreto

- Puedes agregar una [cláusula de función][multiple-fn-clauses] y [guardas][guard] para comprobar si el intento es mayor `>/2` que el número secreto.

## 3. Genera la respuesta cuando el intento es menor que el número secreto

- Puedes agregar una [cláusula de función][multiple-fn-clauses] y [guardas][guard] para comprobar si el intento es menor `</2` que el número secreto.

## 4. Genera las respuestas cuando el intento es uno más o uno menos que el número secreto

- Puedes agregar una [cláusula de función][multiple-fn-clauses] y [guardas][guard] para comprobar si el intento es uno menos o uno más que el número secreto.
- Las expresiones de guarda pueden usar `and/2` u `or/2` para combinar expresiones Boolean.
- Presta atención al orden de las cláusulas de función.

## 5. Genera la respuesta cuando no hay ningún intento

- Puedes hacer uso de un [argumento predeterminado][default-arg] para el intento. El valor predeterminado no tiene que ser un número entero.
- Usa un encabezado de función antes de todas las demás cláusulas de función para definir el argumento predeterminado.
