# Instrucciones

Trabajas para un prestigioso bufete de abogados especializado en gestionar solicitudes de testamentos poco comunes.

En este ejercicio, vas a abrir una bóveda misteriosa.
Eres el albacea de la herencia y deberás reunir los códigos secretos que tres familias han guardado durante mucho tiempo para obtener un número de cuenta y el código correspondiente.

Para evitar que alguna familia abra la bóveda por su cuenta, esta solo se puede abrir combinando sus conocimientos con un modificador secreto que conoces por el testamento.

Tienes tres tareas, todas relacionadas con ayudar a las familias a abrir la bóveda.

# 1. Toma asiento frente a las familias y prepara tus documentos

Define un espacio de nombres llamado `EstateExecutor`.
El código de las siguientes tareas debe definirse en el cuerpo del espacio de nombres `EstateExecutor`.

```ruby
class SomeName
  # The space between the class/module name
  # and the `end` keyword
  # is called body of the  namespace.
end
```

# 2. Encuentra el número de cuenta secreto

Este es tu gran momento.
Solo tú tienes la clave del modificador secreto para revelar el número de cuenta secreto.

Define el método `assemble_account_number(secret_modifier)`, que recibe el modificador secreto de tipo `Integer` como argumento y devuelve como `Integer` el número de cuenta ensamblado.

Para obtener el número correcto, debes sumar la `bank_number_part` de cada una de las tres familias.

# 3. Último paso: ingresa el código secreto

Las instrucciones del testamento te piden sumar primero todos los fragmentos azules y luego todos los rojos.
El código resultante se obtiene multiplicando ambas sumas.

Define el método `assemble_code`, que devuelve el código resultante combinando los fragmentos de las tres familias en un único resultado de tipo `Integer`.
El método no tiene argumentos y se apoya únicamente en la información de los espacios de nombres correspondientes de las familias.
