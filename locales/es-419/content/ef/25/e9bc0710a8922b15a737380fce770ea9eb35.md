# Acerca de

El operador `|>` se llama operador de tubería. Se puede usar para encadenar llamadas a funciones de manera que el valor que devuelve la llamada a la función anterior se pase a la llamada a la función siguiente.

```gleam
"hello"
|> string.uppercase
|> string.append("?!")
// -> "HELLO?!"
```

El código anterior es equivalente al siguiente:

```gleam
string.append(string.uppercase("hello"), "?!")
```

El operador de tubería pasa el valor como el primer argumento de la llamada a la función, o como el único argumento de una nueva llamada, según cuál de las dos opciones tenga el tipo correcto.

```gleam
100
|> function_that_takes_two_arguments(1)

// Is equivalent to
function_that_takes_two_arguments(100, 1)
```

```gleam
100
|> function_that_returns_a_function(1)

// Is equivalent to
function_that_returns_a_function(1)(100)
```

A veces queremos pasar el valor a otra posición; en ese caso se puede usar el marcador de posición `_` para indicar dónde se debe insertar el valor.

```gleam
100
|> some_function(1, _, 2)
```
