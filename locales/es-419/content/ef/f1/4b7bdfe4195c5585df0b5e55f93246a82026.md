# Acerca de

Todo en Common Lisp es una expresión.
Una expresión es una sola cosa (llamada átomo) o una lista de cosas (delimitada con paréntesis: `()`).

## Citar

Todas las S-Expressions, al igual que los símbolos, se pueden citar:

```lisp
;; This line is evaluated as code
(gimme-foo)  ; => FOO

;; This line is treated as data
'(gimme-foo) ; => (GIMME-FOO)
```

Esta cita impide la evaluación de una S-expression y, en su lugar, la trata como datos.
Aquí hay una excelente [respuesta de Stack Overflow][so-quoting] que analiza la cita con un poco más de detalle.

[so-quoting]: https://stackoverflow.com/questions/134887/when-to-use-or-quote-in-lisp
