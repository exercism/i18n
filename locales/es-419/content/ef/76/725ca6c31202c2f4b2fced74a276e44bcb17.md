# Anexo de las instrucciones

## Instrucciones específicas del track

Históricamente, Elm usaba programación reactiva funcional hasta que se especializó en el uso de la Arquitectura Elm.

Resuelve este ejercicio como si estuvieras escribiendo una aplicación web con la Arquitectura Elm.
La salida del programa debe ser HTML con la siguiente estructura

```html
<div>
  <dl>
    <dt>State</dt>
    <dd>Ongoing</dd>
    <dt>Word</dt>
    <dd>______</dd>
    <dt>Remaining failures</dt>
    <dd>5</dd>
  </dl>
</div>
```

donde `<dl>` es el elemento de lista de descripciones, `<dt>` el elemento de término de descripción y `<dd>` el elemento de detalles de descripción, todos elementos HTML estándar.

Si hay un error, la salida debe tener la siguiente estructura

```html
<div>
  <p>error message</p>
</div>
```
