# Debug

Como el ejecutor de pruebas actual usa [PonyTest](https://stdlib.ponylang.io/pony_test--index/), el actor Main está en test.pony y no deberías editarlo como parte de tu solución.

Como es una buena práctica en las aplicaciones Pony, no damos acceso a `Env` a menos que sea necesario. Esto significa que, en casi todos los casos, no puedes usar la depuración al estilo printf con `env.out.print()`.

Sin embargo, Pony tiene un módulo [debug](https://stdlib.ponylang.io/debug--index/) que permite que los programas compilados con la bandera `-d` tengan acceso especial a STDOUT y STDERR sin acceso a `Env`.

Si necesitas depuración al estilo printf, deberías usar esta funcionalidad.

Ejemplo de depuración:

```pony
use "debug"

actor Main
  new create(env: Env) =>
    MySolution.examplefn("First String", 42)

primitive MySolution
  fun examplefn(arg1: String, arg2: USize) =>
    Debug.out("arg1: " + arg1 + ", arg2: " + arg2.string() + " were provided to MySolution.examplefn()")
```
