# Introducción

## Comparaciones

En C++, puedes comparar valores usando los operadores de comparación.

| Comparación       | Operador  |
| ------------------| --------- |
| igual             | `==`      |
| distinto          | `!=`      |
| menor que         | `<`       |
| menor o igual que | `<=`      |
| mayor que         | `>`       |
| mayor o igual que | `>=`      |

El resultado de estas comparaciones siempre es un valor booleano:

```cpp
int a{3};

bool eq1 = a != 4; // true

bool eq2 = a > 5;  // false
```

Los operadores `==` y `!=` comprueban, respectivamente, si un valor es igual a otro o no.
Aquí tienes algunos ejemplos comunes:

```cpp
bool eq3 = 2 == 3; // false, integer comparison

bool eq4 = 2.1 != 2.2; // true, float comparison

bool eq5 = "hello" == "hello"; // true, string comparison
```

Los demás operadores comprueban si un valor es mayor que (`>`), mayor o igual que (`>=`), menor que (`<`) o menor o igual que (`<=`) que otro valor.
Este tipo de comparación está disponible para números y strings.
Al comparar strings, se sigue el orden del diccionario (también conocido como orden lexicográfico).

```cpp
bool eq6 = 2 > 3; // false, integer comparison

bool eq7 = 1.2 < 1.3; // true, float comparison

bool eq8 = "Hello" < "World"; // true, string comparison
```

## Condicionales if

Los condicionales en C++ son similares a los condicionales en otros lenguajes.
El tipo subyacente de cualquier operación condicional es el tipo `bool`, que puede tener el valor `true` o `false`.
Los condicionales suelen usarse como mecanismos de control de flujo para comprobar distintas condiciones.

Puedes usar una sentencia `if`, que ejecuta su código si la condición subyacente es `true`, así:

```cpp
std::string value{"val"};

if (value == "val") {
    return "was val";
}
```

Cuando hay más de un caso, puedes encadenar varias sentencias `if` usando las sentencias `else if` y `else`.

```cpp
int number{33};

if (number > 0) {
   return "positive";
} else if (number < 0) {
    return "negative";
} else {
   return "zero";
}
```

Desde C++17, las sentencias `if` también pueden incluir una sentencia de inicialización corta que sirve para inicializar una o más variables para la sentencia `if`.
Por ejemplo:

```cpp
int num{7};
if (int v{2 * num}; v > 10) {
    return v;
} else {
    return num;
}
// => 14
```

> Nota: no se puede acceder a las variables creadas en la inicialización después del final de la sentencia if.
