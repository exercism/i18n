# Introducción

## `Base.@kwdef`

La macro `Base.@kwdef` sirve para definir automáticamente constructores que toman argumentos de palabra clave para la definición de un [struct][struct].
También permite establecer valores predeterminados para los campos.

Por ejemplo, la siguiente definición

```julia
Base.@kwdef struct HumanStats
    birthyear::Int
    height::Int
    mass::Int
    bmi::Float64 = mass / (0.01 * height)^2
end
```

define tres constructores a la vez

```julia-repl
julia> methods(HumanStats)
# 3 methods for type constructor:
[1] HumanStats(; birthyear, height, mass, bmi) [...]
[2] HumanStats(birthyear::Int64, height::Int64, mass::Int64, bmi::Float64) [...]
[3] HumanStats(birthyear, height, mass, bmi) [...]
```

incluido un constructor basado en argumentos de palabra clave

```julia-repl
julia> HumanStats(
           birthyear = 2002,
           height = 193,
           mass = 83
       )
HumanStats(2002, 193, 83, 22.28247738194314)
```

mientras que la definición estándar

```julia
struct HumanStats
    birthyear::Int
    height::Int
    mass::Int
    bmi::Float64
end
```

solo define las dos siguientes

```julia-repl
julia> methods(HumanStats)
# 2 methods for type constructor:
[1] HumanStats(birthyear::Int64, height::Int64, mass::Int64, bmi::Float64) [...]
[2] HumanStats(birthyear, height, mass, bmi) [...]
```

y requeriría definir manualmente un constructor basado en palabras clave.

### ¿Cuándo usar `Base.@kwdef`?

Los constructores basados en palabras clave son especialmente útiles para construir structs que toman una gran cantidad de argumentos, sobre todo cuando el tipo o el valor de los argumentos no se relaciona directamente con su significado.

Considera la siguiente definición:

```julia
dirk = BasketballPlayer(1978, 1994, 2019, 213, 111, 42, 1998, [2011], 31560, 11489, 3651)
```

No queda claro qué significa cada valor sin conocer la definición del tipo.
E incluso si uno conoce la definición, probablemente tendría que consultar el orden una y otra vez.

Sin embargo, al usar un constructor basado en palabras clave, su significado es obvio de inmediato:

```julia
dirk = BasketballPlayer(
    birthyear = 1978,
    career_start = 1994,
    career_end = 2019,
    height = 213,
    weight = 111,
    number = 42,
    drafted = 1998,
    championships = [2011],
    points = 31560,
    rebounds = 11489,
    assists = 3651
)
```

~~~~exercism/caution
`Base.@kwdef` no se exporta ni está documentada en el manual, y por lo tanto no forma parte de la [API pública de Julia][public-api].
Esto significa que, técnicamente, no se garantiza que su interfaz sea estable y puede cambiar entre actualizaciones menores de Julia.

Sin embargo, la macro se usa ampliamente en todo el ecosistema, y es poco probable que cambie de forma incompatible.

Para más información, consulta:

- [«¿Qué hace `@kwdef`?»][discourse-kwdef]
- [Issue de Julia #32659 para agregar `@kwdef` al manual][add-kwdef-to-manual]
- [Issue de Julia #33192 para exportar `@kwdef`][export-kwdef]
