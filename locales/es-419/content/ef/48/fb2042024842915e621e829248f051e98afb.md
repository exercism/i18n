## Pares

Un `Pair` es una estructura de datos que contiene exactamente dos elementos accesibles a través de los campos `first` y `second`.

Se pueden construir con `x => y`:

```julia-repl
julia> p = 3 => true
3 => true

julia> p.first
3

julia> p.second
true
```

Los elementos de un `Pair` pueden ser de distinto tipo:

```julia-repl
julia> typeof(p)
Pair{Int64,Bool}
```

Los `Pair` tienen dos usos comunes en Julia: los diccionarios y los reemplazos.

### Reemplazos

Muchos métodos de reemplazo toman un `Pair` como argumento para dejar claro qué elemento se está reemplazando.
Esto permite una sintaxis como esta:

```julia-repl
julia> replace!([1, 3, 4, 1], 4 => 0)
4-element Array{Int64,1}:
 1
 3
 0
 1
```

donde cada `4` de la colección se reemplaza por `0`, en lugar de la sintaxis menos clara

```julia
replace!([1, 3, 4, 1], 4, 0) # this method doesn't exist
```
