# Introducción

Swift incluye un tipo incorporado llamado [`Bool`][bools] para representar valores de verdad (booleanos): `true` y `false`.

## Operadores lógicos

Swift incluye tres [operadores lógicos][logical-operators] (`!`, `&&` y `||`) para combinar y evaluar expresiones Boolean.

### AND lógico (`&&`)

El [operador _and_][and] (`&&`) devuelve `true` solo si ambos operandos son `true`.
Si cualquiera de los operandos es `false`, devuelve `false`.
Coloca una expresión o un valor Boolean a cada lado del símbolo `&&`:

```swift
true && true  // true
true && false // false
```

### OR lógico (`||`)

El [operador _or_][or] (`||`) devuelve `true` si **al menos uno** de los operandos es `true`.
Solo devuelve `false` cuando ambos operandos son `false`.
Coloca una expresión o un valor Boolean a cada lado del símbolo `||`:

```swift
true || true   // true
true || false  // true
false || false // false
```

### NOT lógico (`!`)

El [operador _not_][not] (`!`) invierte un valor Boolean.
Devuelve `true` si el valor es `false`, y `false` si el valor es `true`.
Coloca el operador `!` justo antes del valor o de la expresión:

```swift
!true  // false
!false // true
```

## Cómo usar los paréntesis (`()`)

Puedes usar [paréntesis][explicit-parentheses] para agrupar expresiones y controlar el orden de evaluación.
En Swift, las expresiones que están dentro de los paréntesis se evalúan primero:

```swift
true && false && false || true   // true
true && false && (false || true) // false
```

Agrupar con paréntesis también determina cómo se aplica el operador NOT a las expresiones complejas:

```swift
!true && false   // false (evaluates (!true) first, then false && false)
!(true && false) // true  (evaluates (true && false) first to false, then !false)
```

~~~~exercism/note
Usa paréntesis cuando necesites aclarar el orden de evaluación o hacer más fáciles de leer las condiciones complejas.
Evita agregar paréntesis innecesarios cuando la precedencia predeterminada ya es clara.
~~~~
