# Anexo a las instrucciones

## Pistas

Para completar este ejercicio, necesitas crear el tipo de dato `LinkedList`
e implementar las siguientes funciones:

- `datum`
- `fromList`
- `isNil`
- `new`
- `next`
- `nil`
- `reverseLinkedList`
- `toList`

Encontrarás una declaración de datos ficticia y las firmas de tipo ya puestas,
pero depende de ti definir las funciones y crear un tipo de dato,
un newtype o un sinónimo de tipo que tenga sentido.
