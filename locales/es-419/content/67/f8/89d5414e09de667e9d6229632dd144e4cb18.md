# Acerca de

Las [funciones binarias bit a bit][bitwise-wiki] se pueden realizar sobre números enteros usando funciones del [módulo Bitwise][bitwise-hexdocs].

- [`band/2`][bitwise-and]: AND bit a bit
- [`bsl/2`][bitwise-shift-left]: desplazamiento a la izquierda
- [`bsr/2`][bitwise-shift-right]: desplazamiento a la derecha
- [`bxor/2`][bitwise-xor]: XOR bit a bit
- [`bor/2`][bitwise-or]: OR bit a bit
- [`bnot/1`][bitwise-not]: NOT bit a bit

```elixir
Bitwise.band(0b1110, 0b1001)
# => 8 # 0b1000

Bitwise.bxor(0b1110, 0b1001)
# => 7 # 0b0111
```
