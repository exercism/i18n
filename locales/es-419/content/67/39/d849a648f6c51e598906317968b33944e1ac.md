# Pistas

## 1. Determina cuánto tiempo toma preparar un pedido

- Puedes usar un [bucle `for-in`][for-in-loops] para revisar una bebida a la vez.
- Puedes usar una sentencia `switch` para devolver el tiempo que toma preparar cada tipo de bebida.

## 2. Repón tu suministro de rodajas de lima

- Los [arrays tienen un método][array-docs] para eliminar el primer elemento de un array y devolvértelo.
- Necesitas hacer una copia en una variable de los parámetros de la función si quieres modificarlos.

## 3. Termina tu turno

- Si sabemos que todavía nos queda tiempo en nuestro turno, sabemos que tendremos que hacer al menos un pedido.
    Esto es una buena señal de que un [bucle `repeat-while`][repeat-loops] sería una buena opción.
- Los [arrays tienen un método][array-docs] para eliminar el primer elemento de un array y devolvértelo.

## 4. Registra ciertos pedidos

- Puedes usar un [bucle `for-in`][for-in-loops] para trabajar en cada pedido, uno a la vez.
- Puedes usar la descomposición de tuplas para nombrar los elementos individuales de la tupla en el bucle `for-in`.
- Puedes usar las [sentencias de transferencia de control][control-transfer] para saltar a la siguiente iteración del bucle en el caso de las bebidas que no nos interesan.
