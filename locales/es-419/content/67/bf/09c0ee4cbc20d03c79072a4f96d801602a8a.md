# Pruebas

## Ejecuta todas las pruebas

Hay un script de Raku con la extensión `.rakutest`, que se usará para probar tu solución.
Puedes ejecutar las pruebas con el comando:

`prove6`

Antes de que empieces el ejercicio, la salida probablemente se verá parecida a esto:

```
# Failed test 'Say Hi!'
# at t/hello-world.rakutest line 6
# expected: "Hello, World!"
#  matcher: 'infix:<eq>'
#      got: "Goodbye, Mars!"
# You failed 1 test of 1
t/hello-world.rakutest ... Dubious, test returned 1
Failed 1/1 subtests
```

Tendrás que modificar el módulo con la extensión `.rakumod`, que está en el directorio `lib/`, y escribir una solución que pase las pruebas.
Cuando las pruebas pasen, la salida del comando anterior probablemente se verá parecida a esto:

```
t/hello-world.rakutest ... ok
All tests successful.
```

## Detente después del primer fallo

Si tienes la variable de entorno `RAKU_TEST_DIE_ON_FAIL` configurada, el ejecutor de pruebas se detendrá después del primer fallo. Por ejemplo:

En Linux / OS X:

```bash
export RAKU_TEST_DIE_ON_FAIL=1
# now all the follow up runs will stop at the first failure
prove6
# until we do
unset RAKU_TEST_DIE_ON_FAIL
# or you can use it for one run like this:
RAKU_TEST_DIE_ON_FAIL=1 prove6
```

O en Windows:

```
SET RAKU_TEST_DIE_ON_FAIL=1
REM now all the follow up runs will stop at the first failure
prove6
REM until we do
set RAKU_TEST_DIE_ON_FAIL=
```

Para más información, consulta el
[capítulo sobre pruebas de la documentación de Raku](https://docs.raku.org/language/testing.html).

## Solución de problemas

Todos los módulos que se usan en el track de Raku vienen incluidos con Rakudo Star.
Si obtienes un mensaje de error como el anterior al intentar ejecutar una prueba, tendrás que asegurarte de tener la distribución más reciente de Rakudo Star, o instalar el módulo tú mismo usando un gestor de paquetes.
Consulta la [documentación de Raku sobre módulos](https://docs.raku.org/language/modules#Looking_for_and_installing_modules.) para saber cómo instalar módulos.
