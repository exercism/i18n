# Acerca de

Elm es un lenguaje puramente funcional, así que no hay sentencias, solo expresiones, y las funciones siempre son una sola expresión.

Esto fomenta funciones pequeñas y simples, y en general es algo bueno, pero a veces las funciones son inevitablemente más complejas y necesitamos una forma de asegurarnos de que se puedan escribir de manera elegante.

Aquí es donde entran las expresiones `let`. Tienen dos partes: una sección `let`, donde puedes crear tantas definiciones como necesites, y luego una sección `in`, que es una sola expresión que puede usar esas definiciones.

En términos de computación, `let` crea un ámbito que es local a la expresión dentro de `in`.

La expresión `let` es útil en algunas situaciones:

- Para simplificar expresiones
- Para nombrar los resultados de expresiones intermedias
- Dividir una expresión en partes más pequeñas si se está volviendo grande

Puedes hacer casi todo dentro de una expresión `let`, incluida la desestructuración, pero lo siguiente no está permitido:

- Tipos personalizados
- Alias de tipo
- Sombreado de nombres (no puedes redefinir ni reutilizar un nombre que ya está en el ámbito)

## Simplificar expresiones

Esta expresión suma los cubos de 3 números, pero es difícil de leer, y sería fácil que el cálculo resultara distinto para cada número.

```elm
(a * a * a) + (b * b * b) + (c * c * c)
```

Podemos definir una función `cube` en una expresión `let` para que el cálculo sea más simple, más expresivo y más seguro. Esta función podría tener una anotación de tipo, pero en código Elm idiomático esto es relativamente raro.

```elm
let
  cube x = x * x * x
in
  cube a + cube b + cube c
```

## Nombrar los resultados de expresiones intermedias

Este código define sideArea y topArea para que el cálculo sea más simple y más expresivo.

```elm
cylinderArea : Float -> Float -> Float
cylinderArea radius height =
    let
        sideArea = 2 * pi * radius * height
        topArea = pi * radius ^2
    in
        sideArea + 2 * topArea
```

## Dividir una expresión grande

Este código crea un patrón inicial para el [Juego de la vida](https://playgameoflife.com/) (un ejercicio de ejemplo común en programación).

No es importante entender exactamente cómo funciona, pero es de esperar que sea evidente que sería muy grande si se escribiera como una sola expresión, sin `let`.

```elm
beginWithPattern : Size -> Padding -> Pattern -> GameOfLife
beginWithPattern minimumSize padding pattern =
    let
        size = calculateSize minimumSize padding pattern

        center = Size.center size

        centeredPattern = Pattern.centerAt center pattern

        dimensions = { width = size, height = size }

        deadCells = Matrix.create dimensions Dead
    in
    GameOfLife (bringPatternToLife deadCells centeredPattern)
```
