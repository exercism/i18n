# Acerca de

Crystal es un lenguaje de programación compilado y orientado a objetos.
Estos son algunos de los objetivos del lenguaje:

- Sintaxis inspirada en Ruby.

- Con verificación estática de tipos, pero sin tener que especificar el tipo de las variables ni de los argumentos de los métodos.

- Poder llamar a código C escribiendo bindings para él en Crystal.

- Tener evaluación y generación de código en tiempo de compilación, para evitar el código repetitivo.

- Compilar a código nativo eficiente.
