# Cómo usar Markdown en la mentoría

Puedes usar Markdown en tus comentarios de mentoría en GitHub.
Esto te permite incluir fragmentos de código, agregar encabezados, negrita, cursiva, listas, etc., y citar frases anteriores.

En Exercism también permitimos algunos elementos del «Markdown al estilo de GitHub», específicamente el resaltado de sintaxis, las tablas y el tachado.

Si no conoces Markdown ni los extras de GitHub, te recomendamos leer la [guía de GitHub sobre Markdown](https://guides.github.com/features/mastering-markdown/).
