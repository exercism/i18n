# Depuración

YS tiene una función incorporada `DBG` que puede ser útil para depurar el código de tu solución.
Toma cualquier cantidad de argumentos y los imprime en la consola en stderr.
Devuelve el último argumento para que puedas usarlo en línea en tu código.


Puedes usar el operador en línea `.>` que es un atajo para `.DBG()`.

Aquí tienes un archivo de código de ejemplo:

```yaml
# file: program.ys

!YS-v0

defn do-it(nums):
  x =: 5

  DBG: -'my vars' x nums

  nums: .map(\(_ * x)).>
        .reverse().>
        .map(str).>
        .join(' - ')

say: do-it(3 .. 5)
```

Cuando ejecutes este código con `ys`, verás la siguiente salida:

```txt
>>>
"my vars"
5
(3 4 5)
<<<
>>>(15 20 25)<<<
>>>(25 20 15)<<<
>>>("25" "20" "15")<<<
25 - 20 - 15
```


## Compilación

Otra forma común de resolver un problema es observar el código Clojure al que se compila tu código YS.

Puedes hacer esto ejecutando el intérprete de línea de comandos `ys` con la opción `-c`.

Así se ve el archivo `program.ys` anterior cuando se compila:

```clojure
$ ys -c program.ys
(defn do-it [nums]
 (let [x 5]
  (DBG "my vars" x nums)
  (join
   (DBG
    (+map
     (DBG (reverse (DBG (+map nums (fn [& [_1]] (mul+ _1 x))))))
     str))
   " - ")))
(say (do-it (rng 3 5)))
```

Puedes ver claramente cómo el operador `.>` se compiló a la llamada a la función `DBG`.
