# Instrucciones

Aprende lo básico sobre las tablas internas de ABAP.

Tu clase tiene una tabla interna llamada `initial_data`. Tiene tres columnas: `GROUP`, `NUMBER` y `DESCRIPTION`.

```abap
TYPES group TYPE c LENGTH 1.
TYPES: BEGIN OF initial_type,
         group       TYPE group,
         number      TYPE i,
         description TYPE string,
       END OF initial_type,
       initial_data TYPE STANDARD TABLE OF initial_type WITH EMPTY KEY.
```

## Paso 1

Tu primera tarea es completar el método `fill_itab` y colocar 6 registros en esta tabla con los siguientes valores:

| GROUP | NUMBER | DESCRIPTION |
| --- | ----------- | ----------- |
| A | 10 | Group A-2 |
| B | 5 | Group B |
| A | 6 | Group A-1 |
| C | 22 | Group C-1 |
| A | 13 | Group A-3 |
| C | 500 | Group C-2 |

## Paso 2

Ahora implementa el método `add_to_itab` para agregar un registro al final de la tabla interna con el siguiente valor:

| GROUP | NUMBER | DESCRIPTION |
| --- | ----------- | ----------- |
| A | 19 | Group A-4 |

## Paso 3

Ahora ordena la tabla interna en el método `sort_itab` con la columna `GROUP` en orden alfabético y la columna `NUMBER` en orden descendente.

## Paso 4

En el método `search_itab`, busca en la tabla ordenada y devuelve el índice del registro que tiene un valor de 6 en la columna `NUMBER`.
