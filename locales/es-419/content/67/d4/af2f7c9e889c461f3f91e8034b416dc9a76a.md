# Introducción

Muchos tipos de miembros de struct y de class (siendo los campos la excepción principal) pueden usar la sintaxis de miembros con cuerpo de expresión. Definir un miembro con una expresión suele producir código más conciso y legible que los bloques o las sentencias tradicionales.

Los métodos y las propiedades de solo lectura están entre los miembros que se pueden definir con cuerpos de expresión.

```csharp
public int Times3(int input) => input * 3;

public int Interesting => 1729;
```
