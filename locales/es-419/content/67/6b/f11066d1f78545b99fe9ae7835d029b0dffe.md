# Introducción

Un diccionario (`dict`) en Python es una estructura de datos que asocia _claves_ [hashables][term-hashable] a _valores_ y se conoce en otros lenguajes de programación como una [tabla hash][hashtable-wikipedia] redimensionable, un hashmap o un [array asociativo][associative-array].
Los diccionarios son el único [tipo de mapeo][mapping-types-dict] integrado de Python.


Las `keys` deben ser hashables y únicas dentro del diccionario.
Los tipos de clave pueden incluir `number`s, `str`s o `tuple`s (de valores _inmutables_).
No pueden contener estructuras de datos _mutables_ como `list`s, `dict`s o `set`s.
A partir de Python 3.7, se garantiza que el orden de las claves de un `dict` es el orden en el que se insertan las entradas.

Los `values` pueden ser de cualquier tipo de dato o estructura.
 Los valores también pueden anidarse _de forma arbitraria_, así que pueden incluir listas de listas, subdiccionarios y otras estructuras de datos personalizadas o compuestas.

Dada una `key`, los diccionarios pueden recuperar un `value` en tiempo constante (en promedio) (_independientemente del número de entradas_).
En comparación con buscar un valor dentro de una `list` o un `array` (_sin conocer la posición del `index`_), un `dict` usa bastante más memoria, pero su recuperación es muy rápida.

Los diccionarios son especialmente útiles cuando la colección de elementos es grande y se debe acceder a ella y actualizarla con frecuencia.
