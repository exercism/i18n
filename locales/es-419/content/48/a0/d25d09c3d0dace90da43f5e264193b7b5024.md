# Apéndice de instrucciones

## Instrucciones específicas del track

Tu tarea es implementar un registro `circularBuffer` que tiene los siguientes métodos

- `clear()`: vacía el búfer.
- `write(item)`: agrega el elemento dado al búfer. Si el búfer está lleno, debe lanzar `Error("Cannot write to full buffer.")`.
- `read()`: elimina el elemento más antiguo del búfer y lo devuelve. Si el búfer está vacío, debe lanzar `Error("Cannot read from an empty buffer.")`.
- `overwrite(item)`: si el búfer está lleno, sobrescribe `item` en lugar del elemento más antiguo. Si el búfer no está lleno, se comporta como `write`.
