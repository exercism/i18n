# Analizador de líneas de log

## Historia

En este ejercicio vas a procesar líneas de log.

Cada línea de log es un string con el siguiente formato: `"[<LEVEL>]: <MESSAGE>"`.

Hay tres niveles de log distintos:

- `INFO`
- `WARNING`
- `ERROR`

## Tareas

Estas son tareas de ejemplo que encajan con el analizador de líneas de log:

- Obtener el mensaje de una línea de log
- Obtener el nivel de log de una línea de log
- Convertir una línea de log a un formato diferente
