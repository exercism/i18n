# Instrucciones

En este ejercicio, vas a ayudar a unos novios de secundaria a declarar su amor en las redes sociales generando una caja ASCII con sus iniciales:

```
❤-------------------❤
|  J. K.  +  M. B.  |
❤-------------------❤
```

## 1. Obtén la primera letra del nombre

Implementa la función `HighSchoolSweetheart.first_letter/1`. Debe tomar un nombre y devolver su primera letra. Debe limpiar cualquier espacio en blanco innecesario del nombre.

```elixir
HighSchoolSweetheart.first_letter("Jane")
# => "J"
```

## 2. Formatea la primera letra como una inicial

Implementa la función `HighSchoolSweetheart.initial/1`. Debe tomar un nombre y devolver su primera letra, en mayúscula, seguida de un punto. Asegúrate de reutilizar `HighSchoolSweetheart.first_letter/1`, que definiste en el paso anterior.

```elixir
HighSchoolSweetheart.initial("Robert")
# => "R."
```

## 3. Divide el nombre completo en el nombre y el apellido

Implementa la función `HighSchoolSweetheart.initials/1`. Debe tomar un nombre completo, formado por un nombre y un apellido separados por un espacio, y devolver las iniciales. Asegúrate de reutilizar `HighSchoolSweetheart.initial/1`, que definiste en el paso anterior.

```elixir
HighSchoolSweetheart.initials("Lance Green")
# => "L. G."
```

## 4. Coloca las iniciales dentro de la caja ASCII

Implementa la función `HighSchoolSweetheart.pair/2`. Debe tomar dos nombres completos y devolver las iniciales dentro de una caja ASCII. No necesitas dibujar la caja tú mismo; usa la caja que viene en el comentario del código. Asegúrate de reutilizar `HighSchoolSweetheart.initials/1`, que definiste en el paso anterior.

```elixir
HighSchoolSweetheart.pair("Blake Miller", "Riley Lewis")
# => """
# ❤-------------------❤
# |  B. M.  +  R. L.  |
# ❤-------------------❤
# """
```
