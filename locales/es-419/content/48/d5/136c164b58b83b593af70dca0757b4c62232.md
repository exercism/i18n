# Pruebas

Instala las dependencias.

```sh
dart pub get
```

Ejecuta las pruebas.

```sh
dart test
```

Para ver un resultado más detallado de cada prueba, usa el reporte ampliado.

```sh
dart test -r expanded
```

La mayoría de los ejercicios tienen varias pruebas, y de forma predeterminada se omiten todas menos la primera.
Para avanzar por las pruebas una por una, cambia `skip: true` por `skip: false` en cada prueba a medida que avanzas.

Como alternativa, ejecuta todas las pruebas a la vez sin editar el archivo.

```sh
dart test --run-skipped
```

El ejecutor de pruebas en línea ejecuta todas las pruebas cuando envías tu solución, incluidas las omitidas.
