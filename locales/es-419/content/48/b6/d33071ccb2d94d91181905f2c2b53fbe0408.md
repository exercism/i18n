# Introducción

Elixir facilita las prácticas del **principio de abierto/cerrado** al permitir que las funciones tengan múltiples cláusulas. Así, en lugar de una lógica de control extensa y rígida, puedes escribir funciones precisas que agreguen o quiten comportamiento con facilidad.

Elixir ofrece _múltiples cláusulas de función_ y _guardas_ para escribir:

```elixir
def number(n) when n == 7 do
  "Awesome, that's my favorite"
end

def number(_n) do
  "That's not my favorite"
end
```

En tiempo de ejecución, Elixir probará, de arriba a abajo del archivo fuente, qué cláusula de función invocar.

A las variables que no se usan se les debe anteponer un guion bajo.
