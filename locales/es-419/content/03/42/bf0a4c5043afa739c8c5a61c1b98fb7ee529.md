# Instrucciones

El clásico ejercicio de introducción. Solo di «Hello, World!».

["Hello, World!"](http://en.wikipedia.org/wiki/%22Hello,_world!%22_program) es el tradicional primer programa para quienes empiezan a programar en un lenguaje o un entorno nuevos.

Los objetivos son sencillos:

- Modifica el código que te damos para que produzca el string «Hello, World!».
- Ejecuta el conjunto de pruebas y asegúrate de que pasen.
- Envía tu solución y revísala en el sitio web.

Si todo sale bien, ya estarás listo para descargar tu primer ejercicio real.
