# Pistas

## General

## 1. Revisa cuáles fueron los conteos la semana pasada

- Devuelve el _penúltimo_ elemento del array.

## 2. Revisa cuántos pájaros visitaron ayer

- Como los datos son un array de arrays, tendrás que indexar una vez para obtener el array semanal correcto y luego indexar otra vez para obtener el día que buscas.
- «Hoy» es el último elemento del array semanal.

## 3. Calcula el número total de pájaros que visitaron

- Es posible calcular la suma de un array con el filtro [add][manual-add].
  Ya viste esta expresión en el concepto Básicos y en el ejercicio Compras.

## 4. Calcula la cantidad de días ocupados

- Tendrás que _seleccionar_ los días con un conteo mayor o igual a 5, y luego devolver el tamaño del array resultante.

## 5. Revisa si hubo un día sin pájaros visitantes

- La versión de un solo argumento del filtro [any][manual-any] será la adecuada.

[manual-add]: https://jqlang.org/manual/#add
[manual-any]: https://jqlang.org/manual/#any
