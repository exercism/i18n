# Normalizaciones del representer

El [representer de F#][representer] aplica las siguientes normalizaciones:

## Eliminar comentarios

Se eliminan todos los comentarios.

### Antes

```fsharp
module Fake

(* Block comment
   on multiple lines *)

let message = "Hi" (* Block comment after code *)

// Double-slash comment on single line
let reply = "Yo" // Double-slash comment after code

/// <summary>This function adds two numbers</summary>
/// <param name="x">The first number</param>
/// <param name="y">The second number</param>
/// <returns>The first number added to the second number</param>
let add x y = x + y
```

### Después

```fsharp
module Fake

let message = "Hi"

let reply = "Yo"

let add x y = x + y
```

## Eliminar las declaraciones de importación

Se eliminan todas las declaraciones de importación.

### Antes

```fsharp
module Fake

open System
open System.IO

let message = "Hi"
```

### Después

```fsharp
module Fake

let message = "Hi"
```

## Formatear el código

El código se formatea con la [biblioteca fantomas][fantomas].
Esto formatea el código según la guía de estilo de F#.
La lista completa de transformaciones que aplica fantomas está [aquí][fantomas-formatting].

### Antes

```fsharp
module Fake

let  add ( birthDate  :  DateTime)  =
    birthDate.Add (    2.0)

type Volume =
| Liter of float
| USPint of float
| ImperialPint of float
```

### Después

```fsharp
module Fake

let add (birthDate: DateTime) =
    birthDate.Add(2.0)

type Volume =
    | Liter of float
    | USPint of float
    | ImperialPint of float
```

## Normalizar los identificadores

Los identificadores se normalizan a un valor de marcador de posición.

### Antes

```fsharp
module Fake

let foo x = x + 1
```

### Después

```fsharp
module PLACEHOLDER_1

let PLACEHOLDER_3 PLACEHOLDER_2 = PLACEHOLDER_2 + 1
```
