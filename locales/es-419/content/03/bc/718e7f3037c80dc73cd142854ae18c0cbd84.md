# Introducción

Vimos en el concepto `Vectors` que un vector se puede usar en una expresión condicional, lo que da como resultado un vector lógico.
Esto, a su vez, se puede usar en funciones como `all()` y `any()`.

```R
v <- c(4, 7, 10)
v >= 6
#> [1] FALSE  TRUE  TRUE
all(v > 6)
#> [1] FALSE    # not all elements match this condition
any(v > 6)
#> [1] TRUE     # at least one element matches
```

Esta técnica puede hacer mucho más que esto.

## Subconjuntos de vectores

Puedes extraer elementos seleccionados de un vector con un número de índice o con un vector de índices:

```R
v <- 5:10
v
#> [1]  5  6  7  8  9 10
v[3] 
#> [1] 7
v[c(2, 4)]
#> [1] 6 8
```

Como alternativa, usa un vector lógico para filtrar el vector original y obtener un subconjunto de elementos que coinciden con un valor `TRUE`:

```R
v <- 1:3
bools <- c(FALSE, TRUE, TRUE)
v[bools]
#> [1] 2 3
```

A partir de ahí, solo hay un paso para generar el vector Boolean con una expresión condicional:

```R
bools <- v >= 2
bools
#> [1] FALSE  TRUE  TRUE

v[bools]
#> [1] 2 3

# simpler form
v[v >= 2]
#> [1] 2 3
```

## Encontrar índices

La función `which()` recibe un argumento de tipo Boolean y devuelve un vector de índices que dan `TRUE`.

```R
v
#> [1] 2 7 9

v[v > 5]  # returns values
#> [1]  7  9

which(v > 5) # returns indices
#> [1] 2 3
```

## Comprobar si existe un elemento

En las secciones anteriores vimos cómo encontrar elementos que cumplen algún criterio.

Si solo necesitas saber si el vector contiene un elemento específico, puedes usar el operador `%in%`.

```R
3 %in% 1:5
#> [1] TRUE
7 %in% 1:5
#> [1] FALSE
```

Esto es funcionalmente equivalente al siguiente código, pero mucho más cómodo:

```R
v <- 1:5
length(v[v == 3]) > 0
#> [1] TRUE
```
