# Pistas

## General

- No te preocupes por cómo se _derivan_ los argumentos; concéntrate en combinarlos para devolver el resultado esperado.

## 1. Define si el personaje obtiene puntos de bonificación

- Puedes usar [el operador lógico _and_][and] para combinar argumentos y obtener un resultado.

## 2. Define si el personaje anota

- Puedes usar [el operador lógico _or_][or] para combinar argumentos y obtener un resultado.

## 3. Define si el personaje pierde

- Puedes usar [el operador lógico _not_][not] para negar un argumento y obtener un resultado.

## 4. Define si el personaje gana

- Puedes usar los métodos anteriores para combinar argumentos y obtener un resultado.

[not]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/basicoperators/#Logical-NOT-Operator
[and]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/basicoperators/#Logical-AND-Operator
[or]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/basicoperators/#Logical-OR-Operator
