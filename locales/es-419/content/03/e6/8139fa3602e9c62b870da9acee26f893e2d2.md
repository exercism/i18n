# Pistas

Las primeras tres tareas llaman a la misma función `print_name_badge()`.
La implementación se puede ir construyendo paso a paso, agregando la lógica de las tareas 2 y 3 a medida que avanzas.

## 1. Crea una insignia para un empleado

- Este es el caso por defecto; solo arma los 3 argumentos en una cadena adecuada.
- La [interpolación de cadenas][interpolation] es probablemente el enfoque más sencillo.

## 2. Crea una insignia para un empleado nuevo

- Ahora el ID es `missing,`, así que el formato de la cadena objetivo es distinto.
- [`ismissing()][ismissing] es útil aquí.
- Julia tiene un [operador ternario][ternary] con una sintaxis concisa.

## 3. Crea una insignia para el dueño

- Ahora el departamento es `nothing`.
- Existe una función [`isnothing()`][isnothing].

## 4. Calcula el salario total de los empleados sin ID

- ¿Hay [algún][any] ID que falte? Si no, el valor devuelto es cero.
- Para extraer las entradas cuyo ID falta, puede ayudar empezar por [combinar con zip][zip] los vectores `ids` y `salaries`.
- Hay varias formas de iterar sobre el vector de tuplas resultante sin escribir un bucle explícito.
  - Al estilo de Python, con una [comprensión][comprehension] de vectores.
  - De forma funcional, con [`map()`][map] y una [función anónima][anonymous].
  - De forma vectorial, con [broadcasting][broadcasting] de una [función anónima][anonymous].
- Al final, habrá un [`sum()`][sum] sobre un vector de salarios modificado.
   - Los salarios de los empleados con ID se pueden omitir o poner en cero.
