# Instrucciones

La empresa para la que trabajas quiere reducir su huella de carbono, así que quiere que escribas un programa que calcule el consumo de energía y el costo de hacer funcionar sus aparatos electrónicos.

## 1. Obtén las horas extra

Tu empleador tiene un programa que calcula el tiempo que tardan en funcionar los diferentes aparatos electrónicos.
Actualmente, el tiempo se almacena en horas.
Cuando tu empleador sumó las horas, notó que la duración del tiempo no era correcta.
Quiere que agregues 3 horas extra a los datos de tiempo.
También le gustaría saber cuántas horas «extra» hay después de convertir los datos a días «completos» (un día son 24 horas).
Es posible que el tiempo a convertir no esté en días completos.

Implementa una función `get_extra_hours()` que acepte un entero con el número de horas.
La función debe hacer el ajuste de «horas extra» correspondiente y luego `return` un entero que represente cuántas horas hay que quitar del total para obtener el tiempo en días «completos».

```python
>>> get_extra_hours(25)
4
```

## 2. Obtén el valor en kW

Tu empleador quiere saber el consumo de energía de los diferentes aparatos electrónicos en kW.
kW significa kilovatio, y los vatios son una unidad de potencia.
Kilo en el nombre de la unidad es un prefijo del sistema métrico que significa 1000.
Un kilovatio == 1000 vatios.

Implementa una función `get_kW_value()` que acepte un entero con el número de vatios.
La función debe entonces `return` los vatios como kilovatios redondeados a 1 decimal.

```python
>>> get_kW_value(1150)
1.2
```

## 3. Obtén el valor en kWh

Para poder calcular el costo de hacer funcionar los aparatos electrónicos, tu empleador necesita saber el consumo de energía en kWh.
kWh significa kilovatio-hora, y la hora es una unidad de tiempo.
Un kilovatio-hora == 1000 vatios usados durante 1 hora.
Una hora se compone de 60 minutos y un minuto se compone de 60 segundos.
Una hora equivale a 3600 segundos.
Para calcular el valor en kWh, debes convertir los vatios a kW y luego hacer la división entera del resultado entre 3600.

Implementa una función `get_kWh_value()` que acepte un entero con el número de vatios.
La función debe entonces `return` los kilovatios-hora como un entero.

```python
>>> get_kWh_value(5000000)
1
```

## 4. Obtén la eficiencia

Los aparatos electrónicos no son 100% eficientes.
Por eso, tu empleador quiere que calcules la _eficiencia_ de los aparatos electrónicos.
Para obtener la eficiencia, debes dividir el factor de potencia (_un número de punto flotante entre 0 y 100_) entre 100.

Implementa una función `get_efficiency()` que acepte un número de punto flotante con el factor de potencia.
La función debe entonces `return` la eficiencia calculada como un número de punto flotante.

```python
>>> get_efficiency(80)
0.8
```

## 5. Obtén el costo

Tu empleador quiere saber el costo de hacer funcionar los aparatos electrónicos.
El costo de hacer funcionar los aparatos electrónicos es la potencia usada multiplicada por el costo por kWh.
La potencia usada es la potencia dada dividida entre la eficiencia calculada.

Implementa una función `get_cost(<watts>,<power_factor>,<price>)` que acepte un entero con el número de vatios, un número de punto flotante con el factor de potencia y un número de punto flotante con el costo por kWh.
La función debe entonces `return` el costo de hacer funcionar los aparatos electrónicos como un número de punto flotante.

```python
>>> get_cost(5000000, 80, 0.25)
0.3125
```
