# Ayuda

Si tienes problemas y necesitas ayuda, puedes usar uno de los siguientes recursos:

- [gleam.run](https://gleam.run/documentation/) es la documentación oficial de Gleam.
- [Discord](https://discord.gg/Fm8Pwmy) es el canal de Discord.
- [StackOverflow](https://stackoverflow.com/questions/tagged/gleam) te sirve para buscar tu problema y ver si ya se respondió. También puedes hacer y responder preguntas.
