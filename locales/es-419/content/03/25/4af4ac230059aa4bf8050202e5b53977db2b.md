# Introducción

## Conceptos básicos

[Lua](https://lua.org) es un lenguaje de scripting simple pero potente, eficiente, ligero y embebible. Fue diseñado, implementado y mantenido en [PUC-RIO](https://www.puc-rio.br/) en Brasil desde 1993 por el equipo de Roberto Ierusalimschy, Waldemar Celes y Luiz Henrique de Figueiredo.

### Comentarios

Los comentarios de una sola línea en Lua empiezan con `--` y los comentarios de varias líneas empiezan con `--[[` y terminan con `]]`.
```lua
-- This is a single line comment.

--[[This is
a multiline
comment
]]
```

### Variables

En Lua hay tres tipos de variables: variables globales, variables locales y campos de tabla. Para simplificar, aquí solo se explican las variables locales. De forma predeterminada, todas las variables son globales, así que debemos declarar las variables locales como tales con la palabra clave `local`.
```lua
local x
```

Se puede asignar un valor a una variable con el operador `=`.
```lua
local x = 1
```

El ámbito de una variable `local` se limita al bloque donde se declara. Un bloque puede ser el cuerpo de una estructura de control, el cuerpo de una función o un archivo o string donde se declara la variable.
```lua
local x = 1

if x == 1 then
  local x = 2
  print(x) -- prints 2
end

print(x) -- prints 1
```

### Funciones

Una función se declara con la palabra clave `function` y, igual que las variables, es global de forma predeterminada. Una definición de función tiene un nombre, una lista de parámetros y un cuerpo. La función termina cuando se alcanza la palabra clave `return` y devuelve todos los valores que se enumeran después de ella. Sin un `return` especificado, la función devolverá `nil`.

```lua
-- Defining a local function which returns "Hello " followed by 
-- the name which was given as parameter
local function say_hello(name)
  return 'Hello ' .. name
end
```

### Tablas

Las tablas son el único mecanismo de estructuración de datos en Lua y son muy potentes. Se usan para representar arrays, conjuntos, objetos, módulos y mucho más. Básicamente, una tabla en Lua es un array asociativo.
```lua
-- create a table and assign its reference to tbl
local tbl = {}

-- new entry with key 'x' and value 1
tbl['x'] = 1

-- printing the value
print(tbl['x'])  --> 1

-- uninitialized table fields evaluate to nil
print(tbl['y'])  --> nil

-- there is also syntactic sugar - the following is the same as above
tbl.y = 1
print(tbl.y)    --> 1
```

Esto es solo un pequeño adelanto que se necesita para la siguiente sección. Volveremos a este tema en detalle más adelante.

### Módulos

Un módulo es una colección de código que se guarda en un archivo fuente `.lua`. Todo lo que el módulo exporta se guarda en una tabla, y esa tabla se devuelve al final del archivo. Así, la tabla actúa básicamente como una especie de espacio de nombres.
```lua
-- say-hello.lua

-- defining the table 'say' which is exported at the end
local say = {}

-- defining the function 'hello' as a table field
-- this is syntax sugar for: say.hello = function() print('Hello!') end
function say.hello()
  print('Hello!')
end

-- returning (exporting) the table 'say'
return say
```

Ese módulo se puede cargar después en otro archivo a través de la función `require`, que devuelve la tabla.
```lua
-- lets_say_hello.lua
local say = require('say-hello')
say.hello() -- prints "Hello!"
```

Cuando vemos `say.hello`, pensaríamos en «la función `hello` del módulo `say`». Pero, sabiendo que nuestro `say-hello.lua` devuelve una tabla y volviendo a la sección de tablas, notamos que en Lua la expresión significa «indexar la tabla `say` usando el string `hello` como clave».

Aunque es una buena práctica que un módulo devuelva una tabla, también es perfectamente posible devolver cualquier otro tipo, como una función.

```lua
--- say-bye.lua
local function bye()
  print('Bye!')
end

return bye
```
