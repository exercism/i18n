# Anexo de instrucciones

## Pistas

Para este ejercicio, la siguiente funcionalidad de F# te resulta útil:

- Las [secuencias](https://docs.microsoft.com/en-us/dotnet/articles/fsharp/language-reference/sequences) se evalúan de forma perezosa. Te permiten trabajar con una secuencia infinita de valores.

Nota: para acelerar el cálculo, no deberías comprobar números que de antemano sabes que nunca serán primos. Para más información, consulta la [Criba de Eratóstenes](https://en.wikipedia.org/wiki/Sieve_of_Eratosthenes).
