# Instrucciones

Ellen está creando un juego en el que el jugador tiene que pelear contra aliens.
Acaba de aprender sobre Programación Orientada a Objetos (POO) y está ansiosa por aprovechar lo que el uso de `classes` podría ofrecerle a su programa.

Para alegría de Ellen, te has ofrecido a ayudar y ella te ha encargado la tarea de programar a los aliens contra los que el jugador tiene que pelear.


## 1. Crea la clase `Alien`

Define la clase `Alien` con un constructor que acepte dos parámetros `int`, `x` y `y`, y los guarde en las variables miembro `x_coordinate` y `y_coordinate`.
Cada alien también empezará con un nivel de salud de `3`, así que la variable miembro `health` también debe inicializarse.

`health` debe ser una variable miembro privada.
Para que otras partes del programa puedan leer la información de salud, Ellen quiere tener un método `public` `get_health()` que devuelva un `int`.

```cpp
Alien alien{2, 0};
alien.x_coordinate;
// => 2
alien.y_coordinate;
// => 0
alien.get_health();
// => 3
```

Ahora, cada alien debe poder hacer un seguimiento interno de su propia posición y salud.

## 2. La función `hit`

A Ellen le gustaría que la `class` Alien tenga un método `hit` que reduzca en `1` la salud de un objeto alien cuando se llame.
Así, puede simplemente llamar a `some_alien_instance.hit()` en lugar de tener que cambiar manualmente la salud de un alien.
Asegúrate de que los puntos de salud no bajen por debajo de cero.
La función debe devolver `true`.
Ellen quiere introducir escudos más adelante, que entonces reportarían `false` si el escudo está activo.

```cpp
Alien alien {0, 0};
alien.get_health();
// => 3 (Initial health value)

alien.hit(); // Decrements health by 1 point.
alien.get_health();
// => 2
```

## 3. La función `is_alive`

Te das cuenta de que, si la salud sigue bajando, en algún momento probablemente llegará a `0`.
Sería buena idea agregar un método `is_alive` al que Ellen pueda llamar rápidamente para comprobar si el alien está... bueno... vivo. 😉
`some_alien_instance.is_alive()` debe devolver un Boolean.

```cpp
alien.get_health();
// => 1
alien.is_alive();
// => true
alien.hit();
alien.get_health();
// => 0
alien.is_alive();
// => false
```

## 4. La función `teleport`

¡En el juego de Ellen los aliens pueden teletransportarse!
Tendrás que escribir un método `teleport` que tome los valores `x_new` y `y_new` y cambie las coordenadas del alien en consecuencia.
Por ahora, la función debe devolver `true`.
Ellen quiere agregar bombas que bloqueen el teletransporte en niveles posteriores, que entonces reportarían `false` para los intentos de teletransporte fallidos.

```cpp
alien.teleport(5, -4);
alien.x_coordinate;
// => 5
alien.y_coordinate;
// => -4
```

## 5. La función `collision_detection`

Si algo puede golpear a los aliens, entonces necesitan poder detectar cuándo podría ocurrir una colisión así.
Ellen necesita saber si dos aliens ocupan las mismas coordenadas.
La función `collision_detection()` toma otro objeto alien como argumento y devuelve un `bool`.

```cpp
Alien lrrr {3, 6};
Alien ndnd {-2, 12};
lrrr.collision_detection(ndnd);
// => false
ndnd.teleport(3, 6);
ndnd.collision_detection(lrrr);
// => true
```
