## General

- Ordenar una lista de manos de póker se puede considerar un problema de ordenamiento.
- Rust proporciona el método [sort](https://doc.rust-lang.org/std/vec/struct.Vec.html#method.sort) para `Vec<T> where T: Ord`.
- Los [tipos `Ord`](https://doc.rust-lang.org/std/cmp/trait.Ord.html) forman un [orden total](https://en.wikipedia.org/wiki/Total_order): exactamente uno de `a < b`, `a == b` o `a > b` debe ser verdadero.
- Las manos de póker no se ajustan a un orden total: es posible que dos manos no sean iguales pero tengan el mismo orden de clasificación. Por ejemplo: `"3S 4S 5D 6H JH"`, `"3H 4H 5C 6C JD"`.
- Rust proporciona el [trait `PartialOrd`](https://doc.rust-lang.org/std/cmp/trait.PartialOrd.html) para manejar el caso de cosas que se pueden ordenar y que no tienen un orden total. Sin embargo, no proporciona un método `sort` estándar para `Vec<T> where T: PartialOrd`. La forma idiomática estándar de ordenar un vector en este caso es `your_vec.sort_by(|a, b| a.partial_cmp(b).unwrap_or(Ordering::{Less|Equal|Greater}));`, según lo que necesites.
- Podrías considerar implementar un tipo que represente una mano de póker y que implemente `PartialOrd`.
