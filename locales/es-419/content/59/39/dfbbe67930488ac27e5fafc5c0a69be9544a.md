# Pistas

## General

- Las instancias de struct se crean declarando el nombre del struct seguido de los valores de los campos encerrados entre llaves.
- Puedes usar `@T` para declarar snapshots de algún tipo `T`; por ejemplo, `let i: @u32 = @1;` declara una variable `i` que es un snapshot del valor `u32` `1`;
- Puedes extraer un valor de un snapshot usando el operador `*` (desnap); por ejemplo, `let int = *an_int_snapshot;`.
- Puedes declarar un valor como mutable usando la palabra clave `mut`, como en `let mut i = 1;`.

## 1. Crea un contador de votos

- Necesitas crear un puntero a un struct `VoteCounter`; en otras palabras, un `@VoteCounter`.
- Puedes asignar el parámetro `value` directamente cuando creas una instancia del struct.

## 2. Obtén la cantidad de votos de un contador

- Puedes usar el operador `*` sobre un snapshot para quitarle el snapshot y obtener su valor; por ejemplo, `*my_snapshot`

## 3. Incrementa los votos de un contador

- En lugar de modificar el snapshot `@VoteCounter`, necesitas devolver una nueva instancia de `VoteCounter` con los votos incrementados.
- Puedes quitarle el snapshot al valor subyacente del contador de votos usando el operador `*`, o llamar a la función que creaste en la tarea anterior.

## 4. Crea los resultados de la elección

- Crea un nuevo struct o variable `ElectionResult` con los campos `name` y `vote_counter` llenos con los valores de los argumentos de la función.
- Puedes crear un snapshot de `VoteCounter` usando el operador `@` antes del nombre de la variable o de la declaración del struct, o llamar a la función `new_vote_counter` que hiciste en alguna de las tareas anteriores.

## 5. Anuncia los resultados

- Aunque recibes un snapshot de un `ElectionResult`, puedes acceder a sus campos con la notación de punto `.`, ¡como si no fuera un snapshot!
- Construye el mensaje accediendo a los campos `name` y `vote_counter` del struct.
- Cuando quitas el snapshot de un snapshot anidado, necesitas aplicar tantos operadores `*` como snapshots haya que quitar:

```rust
let result = @ElectionResult {
    name: "John",
    vote_counter: @VoteCounter { value: 32 },
};

println!("{}", **result.vote_counter.value); 
// => 32
```

## 6. Recuento de votos

- Debido a la [forma en que se implementan los diccionarios][dictionaries underneath], es un requisito que sean mutables tanto para modificarlos como para leerlos, lo que significa que los cambios que hagas al diccionario dentro de la función serán visibles fuera de la función.
- Para incrementar el valor de una clave en un `let mut m: Felt252Dict<u32>`, debes combinar sus funciones `get` e `insert`: `m.insert('mykey', m.get('mykey') + 1);`

[dictionaries underneath]: https://book.cairo-lang.org/ch03-02-dictionaries.html#dictionaries-underneath
