# Introducción

Una [sentencia `switch`][switch] compara un valor con varios patrones de coincidencia posibles.
Es una alternativa más limpia y legible a encadenar varias sentencias `if-else`.

Una sentencia `switch` empieza con la palabra clave `switch`, seguida del valor que se va a evaluar.
Cada posible coincidencia se introduce con la palabra clave `case`.
La palabra clave `default` define un caso por defecto que se ejecuta si ninguno de los casos explícitos coincide.
Al igual que las cadenas de `if-else`, una sentencia `switch` solo ejecuta el bloque de código asociado con el primer caso que coincide.

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

Considera la siguiente cadena de `if-else`:

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

Esto se puede escribir de forma más clara con una sentencia `switch`:

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```
