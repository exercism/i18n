# Bucles

```sather
   loop
      ...
   end;
```

Sather tiene exactamente una sentencia de bucle. No hay `while` ni `for`;
ambos se construyen a partir de `loop` y algo que lo termina.

## Variables

```sather
   total ::= 0;          -- declare, with a starting value
   total := total + 5;   -- assign
```

`::=` declara y toma el tipo del valor que se le da. Cuando una variable tiene
que existir antes de que haya un valor para ella, declárala con un tipo:

```sather
   total : INT;
   total := 0;
```

Una variable declarada sin un valor empieza como cero para `INT`, `false` para
`BOOL`, y void para un string o un objeto.

## Terminar un bucle

| Escrito | Termina el bucle |
| --- | --- |
| `until!(q)` | cuando `q` es verdadero |
| `while!(q)` | cuando `q` es falso |
| `break!` | de inmediato |

Los tres pueden aparecer en cualquier parte del cuerpo, y un bucle puede usar más de uno.

```sather
   loop
      until!(n > last);      -- may run no times at all
      ...
   end;

   loop
      ...
      until!(done);          -- always runs at least once
   end;
```

## El signo de exclamación

`until!`, `while!` y `break!` terminan en `!` porque son **iteradores**,
cosas que solo pueden aparecer dentro de un bucle y que pueden terminarlo. Escribir uno
fuera de un bucle es un error y no una advertencia. En ejercicios posteriores usarás los
otros iteradores de la biblioteca y, con el tiempo, escribirás nuevos.

## Bucles infinitos

Un bucle sin nada que lo termine se ejecuta para siempre. A veces eso es lo que
se quiere, pero mucho más a menudo significa que el valor por el que se
pregunta nunca cambia. Si un programa se queda colgado, lo primero que hay que
revisar es si algo dentro del bucle lo acerca a detenerse.
