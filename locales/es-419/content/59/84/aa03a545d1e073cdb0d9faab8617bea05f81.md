# Pistas

## General

- Recuerda consultar la tabla en las instrucciones.

## 1. Dada una extensión, devuelve el tipo de medio esperado

- Usa la [coincidencia de patrones][pattern-matching] para devolver el tipo de medio correcto.
- Puedes usar [varias cláusulas de función][mfc].

## 2. Dado un archivo binario, devuelve el tipo de medio esperado

- Usa la [forma especial de binarios][special-forms] que tienes disponible para escribir un literal binario.
- Usa la [coincidencia de patrones][binary-matching] para hacer coincidir los primeros bytes del binario del archivo.

## 3. Dadas una extensión y un archivo binario, verifica que el archivo coincida con el tipo esperado

- Reutiliza las funciones que creaste para las partes 1 y 2.
- Compara el valor de retorno de cada función y luego devuelve el valor adecuado.
  - Puedes usar la [macro condicional `if`][if] para condiciones binarias.
