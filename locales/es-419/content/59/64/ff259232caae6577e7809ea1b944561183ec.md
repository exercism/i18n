# Introducción

## Fechas y horas

La biblioteca estándar de Elixir ofrece 4 módulos diferentes para trabajar con fechas y horas, cada uno con su propio struct.

- El módulo `Date`. Se puede crear un struct `Date` con el sigilo `~D`.

  ```elixir
  ~D[2021-01-01]
  ```

- El módulo `Time`. Se puede crear un struct `Time` con el sigilo `~T`.

  ```elixir
  ~T[12:00:00]
  ```

- El módulo `NaiveDateTime` para fechas y horas sin zona horaria. Se puede crear un struct `NaiveDateTime` con el sigilo `~N`.

  ```elixir
  ~N[2021-01-01 12:00:00]
  ```

- El módulo `DateTime` para fechas y horas con zona horaria. Usar este módulo para zonas horarias distintas de UTC requiere una dependencia externa, una base de datos de zonas horarias.

### Comparaciones

Para comparar fechas u horas entre sí, busca una función `compare` o `diff` en el módulo correspondiente. Los operadores de comparación como `==`, `>`, y `<` _parecen_ funcionar, pero no hacen una comparación semántica correcta para esos structs.
