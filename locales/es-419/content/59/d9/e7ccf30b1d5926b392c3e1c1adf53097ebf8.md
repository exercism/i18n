# Instrucciones

En este ejercicio juegas a un juego de rol llamado «Wizard and Warriors», que te permite jugar como un Wizard o un Warrior.

Hay reglas distintas para los Warriors y los Wizards que determinan cuántos puntos de daño infligen.

Para un Warrior, estas son las reglas:

- Inflige 6 puntos de daño si el personaje al que ataca no es vulnerable
- Inflige 10 puntos de daño si el personaje al que ataca es vulnerable

Para un Wizard, estas son las reglas:

- Inflige 12 puntos de daño si el Wizard preparó un hechizo con antelación
- Inflige 3 puntos de daño si el Wizard no preparó un hechizo con antelación

En general, los personajes nunca son vulnerables. Sin embargo, los Wizards _sí_ son vulnerables si no han preparado un hechizo.

Tienes seis tareas que trabajan con personajes Warrior y Wizard.

## 1. Describe un personaje

Sobrescribe el método `ToString()` de la clase `Character` para devolver una descripción del personaje, con el formato `"Character is a <CHARACTER_TYPE>"`.

```csharp
var warrior = new Warrior();
warrior.ToString();
// => "Character is a Warrior"
```

## 2. Haz que los personajes no sean vulnerables de forma predeterminada

Asegúrate de que el método `Character.Vulnerable()` siempre devuelva `false`.

```csharp
var warrior = new Warrior();
warrior.Vulnerable();
// => false
```

## 3. Permite que los Wizards preparen un hechizo

Implementa el método `Wizard.PrepareSpell()` para permitir que un Wizard prepare un hechizo con antelación.

```csharp
var wizard = new Wizard();
wizard.PrepareSpell();
```

## 4. Haz que los Wizards sean vulnerables cuando no hayan preparado un hechizo

Asegúrate de que el método `Vulnerable()` devuelva `true` si el wizard no preparó un hechizo; de lo contrario, devuelve `false`.

```csharp
var wizard = new Wizard();
wizard.Vulnerable();
// => true
```

## 5. Calcula los puntos de daño de un Wizard

Implementa el método `Wizard.DamagePoints()` para devolver los puntos de daño infligidos: 12 puntos de daño cuando se ha preparado un hechizo, 3 puntos de daño cuando no.

```csharp
var wizard = new Wizard();
var warrior = new Warrior();

wizard.PrepareSpell();
wizard.DamagePoints(warrior);
// => 12
```

## 6. Calcula los puntos de daño de un Warrior

Implementa el método `Warrior.DamagePoints()` para devolver los puntos de daño infligidos: 10 puntos de daño cuando el objetivo es vulnerable, 6 puntos de daño cuando no.

```csharp
var warrior = new Warrior();
var wizard = new Wizard();

warrior.DamagePoints(wizard);
// => 10
```
