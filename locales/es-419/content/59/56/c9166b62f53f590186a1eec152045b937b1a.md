# Anexo de instrucciones

## Notas

La intención de este ejercicio es investigar algunos de los paralelismos que existen entre una instancia de un módulo de WebAssembly y una instancia de una clase en los lenguajes de programación orientados a objetos.

En tu solución, una instancia de WebAssembly debería considerarse como una instancia de una cuenta bancaria, y se deberían usar globales mutables de WebAssembly para modelar estados privados como en una clase.

¡No se debería necesitar memoria lineal!
