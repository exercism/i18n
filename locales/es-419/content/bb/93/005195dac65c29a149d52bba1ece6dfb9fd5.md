# Clases con estado

Todas las clases que has visto hasta ahora han sido una caja de rutinas. Cada una tomaba sus argumentos, calculaba una respuesta y olvidaba todo.

Una clase, en cambio, puede **recordar** cosas. Un marcador tiene que hacerlo: el puntaje ahora depende de cada gol desde que empezó el partido.

## Atributos

`attr` le da a una clase algo que recordar.

```sather
class SCOREBOARD is

   attr home_score : INT;
   attr away_score : INT;

end; -- class SCOREBOARD
```

Cada `attr` se convierte en una rutina que lee el valor, y en otra que lo cambia:

```sather
   board.home_score            -- read it
   board.home_score := 4;      -- change it
```

Los atributos del mismo tipo pueden compartir una declaración, igual que los argumentos:

```sather
   attr home_score, away_score : INT;
```

## Objetos

Una clase con atributos es un patrón para crear **objetos**. Cada objeto tiene sus propias copias de los atributos, así que dos marcadores llevan dos puntajes.

`new` crea un objeto. Va dentro de una rutina llamada `create`, que luego rellena el objeto y lo devuelve:

```sather
   create(home, away : STR) : SAME is
      board ::= new;
      board.home_team := home;
      board.away_team := away;
      return board;
   end;
```

`SAME` significa «esta clase». Escribir `SCOREBOARD` ahí diría lo mismo, pero `SAME` sigue funcionando si le cambias el nombre a la clase.

## Cómo crear uno

`#` llama a `create`:

```sather
   board ::= #SCOREBOARD("Vixens", "Magpies");
```

Has estado usando `#` desde `rehearsal-script`: `#FSTR` es exactamente esto.

## Rutinas que cambian el objeto

Dentro de la clase, un atributo se usa por su nombre, sin ningún objeto delante. Se refiere al objeto sobre el que se llamó a la rutina.

```sather
   home_goal is
      home_score := home_score + 1;
   end;
```

`home_goal` no declara ningún tipo de retorno, porque no devuelve nada: cambia el objeto. Llámala como una sentencia:

```sather
   board.home_goal;
```

## Los atributos empiezan vacíos

Un atributo que nadie ha establecido contiene cero para un `INT`, `false` para un `BOOL`, y void para un string o un objeto. Así que un marcador nuevo marca 0 a 0 sin que nada tenga que decirlo.
