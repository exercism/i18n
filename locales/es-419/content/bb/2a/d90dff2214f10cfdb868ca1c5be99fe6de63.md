# Acerca de

Los tipos de C# se pueden definir dentro del ámbito de una clase o una estructura. El tipo contenedor proporciona una especie de espacio de nombres. Se accede al tipo a través del tipo contenedor con la sintaxis de punto.

```csharp
class Outer
{
    public interface IInner {}
    public enum EInner {}
    public class CInner {}
    public struct SInner {}
}

var outer = new Outer();
var inner = new Outer.CInner();
```

## Niveles de acceso

Los niveles de acceso se pueden aplicar a los tipos internos. Por ejemplo, si una clase es `private`, no se puede ver fuera del ámbito del tipo contenedor y, por supuesto, tampoco se pueden ver ni usar sus instancias fuera de ese ámbito.

Los miembros privados de la clase externa están en el ámbito de todos los miembros de la clase interna, pero solo los miembros no privados de la clase interna están en el ámbito de los miembros de la clase externa. Para acceder a los miembros de la clase externa, se le debe pasar a la clase interna una instancia de la clase externa.

Esto se puede ver en el siguiente ejemplo:

```csharp
class Outer
{
    public class InnerImpl
    {
        private Outer outer;

        public int Interesting = 42;

        public InnerImpl(Outer outer, int interesting)
        {
            this.outer = outer;
            Interesting = interesting;
        }

    }

    public InnerImpl Inner;
    public Outer()
    {
        Inner = new InnerImpl(this, 42);
    }
}

var outer = new Outer();
outer.Inner.Interesting
// => 42
var inner = new Outer.InnerImpl(outer, 1729);
outer.Inner.Interesting
// => 1729
```

## Evitar la instanciación independiente

Existe un patrón para evitar que se cree un tipo instanciable fuera del tipo contenedor. Expone una interfaz pública, pero mantienes privada la clase que la implementa.

```csharp
class Outer
{
    public interface IInner
    {
        void DoSomething();
    }

    private class InnerImpl : IInner
    {
        private Outer outer;
        public InnerImpl(Outer outer)
        {
            this.outer = outer;
        }
        public void DoSomething()
        {
            outer.DoSomethingElse();
        }
    }

    public IInner Inner;

    public Outer()
    {
        Inner = new InnerImpl(this);
    }
    private void DoSomethingElse()
    {
    }
}

var outer = new Outer();
outer.Inner.DoSomething();

// NOT var inner = new Outer.Inner(outer);
```

## Nota para desarrolladores de Java

Las clases anidadas de C# son una mezcla entre las clases anidadas estáticas y las clases internas de Java. En C#, los miembros privados de la clase contenedora están en el ámbito de los miembros de la clase anidada, pero no existe una sintaxis especial para instanciarlas y vincularlas a una instancia de la clase contenedora. Tienes que usar alguna variante del patrón que se muestra en los ejemplos anteriores.

C# sí tiene clases anidadas estáticas, pero estas son simplemente clases contenidas con comportamiento estático.
