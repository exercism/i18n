# Pistas

## 1. ¿Cuántos tenemos?

- Pregúntale primero a `has_ind`, y usa `raise` cuando la respuesta sea falsa.
- El mensaje se construye con `+`, como cualquier string:
  `raise "Unknown prop: " + prop;`
- Nada de lo que va después de un `raise` se ejecuta, así que no hay ningún `else` que escribir. El `return` que está debajo solo se alcanza cuando la prop está presente.

## 2. Toma uno

- Llama a `count_of` para obtener el número. Si la prop es desconocida, esa llamada lanza una excepción, y `take_one` también. No tienes que escribir nada para eso, y no deberías.
- Después verifica si es cero y lanza `"Out of " + prop`.
- En caso contrario, devuelve uno menos.

## 3. Informa

- Usa `protect` alrededor de una llamada a `take_one`, con una rama `when $STR then`.
- En la parte de `protect`, toma uno y construye el mensaje de éxito a partir de lo que respondió.
- En la rama `when`, el mensaje es `exception.str` y nada más. No intentes averiguar cuál fue el fallo; lo que se haya lanzado ya son las palabras correctas.
