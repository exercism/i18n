# Instrucciones

En este ejercicio vas a trabajar un poco más con autos de control remoto.

Se ha desarrollado un auto experimental y hay que adaptar la pista de pruebas para que pueda manejar tanto los modelos de producción como los experimentales.
Los dos tipos de auto ya están construidos y necesitas encontrar la manera de lidiar con ambos en la pista de pruebas.

Además, los autos de producción están empezando a tener cierto éxito.
El jefe del equipo quiere mantener el espíritu competitivo publicando una clasificación de los autos de producción.

## 1. Implementa la interfaz

Agrega dos métodos a la interfaz `RemoteControlCar`:

- `drive()`, que no devuelve nada, y
- `getDistanceTravelled()`, que devuelve un `int`.

Luego haz que `ProductionRemoteControlCar` y `ExperimentalRemoteControlCar` implementen la interfaz `RemoteControlCar`.
Esto incluye implementar todos los métodos que requiere la interfaz.

## 2. Conduce

Cada llamada a `.drive()` debe hacer que el auto recorra una cierta distancia:

- un `ProductionRemoteControlCar` recorre 10 unidades,
- un `ExperimentalRemoteControlCar` recorre 20 unidades.

El método `.getDistanceTravelled()` debe devolver el número de unidades que el auto ha recorrido a lo largo de su vida.

```java
ProductionRemoteControlCar prod = new ProductionRemoteControlCar();
prod.drive();
prod.getDistanceTravelled();
// => 10
        
ExperimentalRemoteControlCar exp = new ExperimentalRemoteControlCar();
exp.drive();
exp.getDistanceTravelled();
// => 20
```

## 3. Compite

Implementa el método `TestTrack.race(RemoteControlCar car)`, en el que los `car` pueden `drive()`.

```java
TestTrack.race(new ProductionRemoteControlCar());
TestTrack.race(new ExperimentalRemoteControlCar());
// this should execute without an exception being thrown
```

## 4. Permite que los autos de producción se ordenen

Implementa la interfaz `Comparable<T>` en la clase `ProductionRemoteControlCar`.
El orden de clasificación predeterminado de los autos debe ser el orden descendente de victorias.

Implementa el método estático `TestTrack.getRankedCars()` para que devuelva los autos que se le pasan, ordenados de forma descendente por número de victorias.

```java
ProductionRemoteControlCar prc1 = new ProductionRemoteControlCar();
ProductionRemoteControlCar prc2 = new ProductionRemoteControlCar();
prc1.setNumberOfVictories(2);
prc2.setNumberOfVictories(3);
List<ProductionRemoteControlCar> unsortedCars = new ArrayList<>();
unsortedCars.add(prc1);
unsortedCars.add(prc2);
List<ProductionRemoteControlCar> rankings = TestTrack.getRankedCars(unsortedCars);
// => rankings.get(0) == prc2
// => rankings.get(1) == prc1
```
