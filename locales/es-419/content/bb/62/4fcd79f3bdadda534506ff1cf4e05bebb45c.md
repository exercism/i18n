# Ayuda

Si tienes problemas y necesitas ayuda, puedes usar uno de los siguientes recursos:

- [/r/fsharp](https://www.reddit.com/r/fsharp) es el subreddit de F#.
- [StackOverflow](http://stackoverflow.com/questions/tagged/f%23) puedes usarlo para buscar tu problema y ver si ya lo respondieron. También puedes hacer y responder preguntas.

## Paquetes

El track de F# admite un número limitado de paquetes.
Consulta la [lista de paquetes admitidos](https://exercism.org/docs/tracks/fsharp/packages) para saber cuáles son.
