# Instrucciones

Tu equipo de diseño está pasando de las transformaciones de CSS a Factor para parte de su trabajo de maquetación. Para que el resto del equipo esté contento, vas a construir pequeñas transformaciones reutilizables como quotations que reciben un punto 2D y devuelven un punto 2D.

Un punto es un array de 2 elementos `{ x y }`.

## 1. Traslada las coordenadas

Define `translate-2d` para que tome dos valores `dx` y `dy` de la pila y devuelva una quotation que traslade un punto en `(dx, dy)`.

```factor
{ 4 8 } 2 0 translate-2d call( p -- p' ) .
! => { 6 8 }
```

## 2. Escala las coordenadas

Define `scale-2d` de la misma forma, devolviendo una quotation que escale un punto en `(sx, sy)`.

```factor
{ 6 -3 } 2 2 scale-2d call( p -- p' ) .
! => { 12 -6 }
```

## 3. Compón dos transformaciones

Define `compose-transformations` para que tome dos quotations de transformación `f` y `g` y devuelva una única quotation que aplique `f` primero y luego `g`.

```factor
{ 0 1 } 2 0 translate-2d 2 2 scale-2d compose-transformations
call( p -- p' ) .
! => { 4 2 }
```

## 4. Aplica una transformación

Define `apply-transformation` para que tome un punto y una quotation de transformación de la pila y devuelva el punto transformado.

```factor
{ 4 8 } 2 0 translate-2d apply-transformation .
! => { 6 8 }
```

## 5. Transforma muchos puntos a la vez

Define `transform-points` para que tome un array de puntos y una quotation de transformación, y devuelva el array de puntos transformados.

```factor
{ { 0 0 } { 1 1 } { 2 2 } } 1 0 translate-2d transform-points .
! => { { 1 0 } { 2 1 } { 3 2 } }
```
