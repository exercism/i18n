# Introducción

## chars

El tipo primitivo `char` de Java es una representación de 16 bits de un solo carácter.
Varios `char`s pueden formar un string, como `"word"`, o los `char`s se pueden procesar de forma independiente.
Un literal `char` va entre comillas simples (por ejemplo, `'A'`).

```java
char lowerA = 'a';
char upperB = 'B';
```

## Obtener los `char`s de un `String`

El método `String.toCharArray` devuelve los chars de un String como un array.
Como se mencionó en arrays, puedes usar un bucle `for` para recorrer el array.

```java
String text = "Hello";
char[] asArray = text.toCharArray();

for (char ch: asArray) {
    System.out.println(ch);
}

// Outputs:
// H
// e
// l
// l
// o
```

## La clase Character

Hay muchos métodos de biblioteca integrados para inspeccionar y manipular `char`s.
Se encuentran como métodos estáticos de la clase `java.lang.Character`.
Aquí tienes algunos ejemplos:

```java
Character.isWhitespace(' ');    // true
Character.isWhitespace('#');    // false

Character.isLetter('a');        // true
Character.isLetter('3');        // false

Character.isDigit('6');         // true
Character.isDigit('?');         // false
```

## Agregar un `char` a un `String`

Puedes usar el operador `+` para agregar un `char` a un `String`.

```java
'a' + " banana"     // => "a banana"
"banana " + 'a'     // => "banana a"
```

~~~~exercism/caution
¡Ten cuidado de _no_ usar `+` para unir dos `char`s y formar un `String`!
¡Si sumas dos `char`s de esta forma obtienes un `int`, _no_ un `String`!
Por ejemplo:

```java
'b' + 'c';
// => 197 (not the String "bc")
```

Esto se debe a que Java promueve el `char` a un `int` (consulta [4.2 Primitive Types and Values ][jls-primitives] de la [Java Language Specification][jls-main]).

[jls-main]: https://docs.oracle.com/javase/specs/jls/se21/html/
[jls-primitives]: https://docs.oracle.com/javase/specs/jls/se21/html/jls-4.html#jls-4.2
~~~~

Sin embargo, cuando hay muchos caracteres que agregar, puede ser más eficiente usar un `StringBuilder`:

```java
StringBuilder builder = new StringBuilder();
builder.append('a');
builder.append('b');
builder.append('c');

String builtString = builder.toString();
// => abc
```
