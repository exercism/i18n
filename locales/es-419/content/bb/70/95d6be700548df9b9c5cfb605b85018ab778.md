# Acerca de

Un número de punto flotante es un número con cero o más dígitos después del separador decimal. Algunos ejemplos son `-2.4`, `0.1`, `3.14`, `16.984025` y `1024.0`.

F# tiene tres tipos de punto flotante:

- `single`: 4 bytes (~6-9 dígitos de precisión). Se escribe como `2.45f` o `2.45F`. El tipo `float32` se puede usar como alias.
- `float`: 8 bytes (~15-17 dígitos de precisión). Es el tipo más común. Se escribe como `2.45` o usando notación exponencial como `2.3E+32` o `2.3e+32`. El tipo `double` se puede usar como alias.
- `decimal`: 16 bytes (28-29 dígitos de precisión). Normalmente se usa cuando se trabaja con datos monetarios, ya que su precisión da lugar a menos errores de redondeo. Se escribe como `2.45m` o `2.45M`.

Cada tipo de punto flotante tiene su propia [precisión, rango aproximado y tamaño][floating-point-types]. La precisión indica cuántos dígitos después del separador decimal se pueden almacenar. Esto significa que si intentas almacenar PI en un `single`, solo se guardarán los primeros 6 a 9 dígitos (y el último se redondeará).

La conversión entre distintos tipos de punto flotante se hace con los [operadores de conversión][conversion-operators]:

```fsharp
let floatFromSingle = float 2.45f
```

Ten siempre cuidado cuando compares por igualdad los valores de tipos de punto flotante, porque valores que parecen representar lo mismo en realidad podrían ser distintos. Consulta [este artículo][precision-in-comparisons] para más información (los ejemplos de código están en C#).

Puedes encontrar una breve introducción a los números de punto flotante en [0.30000000000000004.com][0.30000000000000004.com]. La [página de Float Toy][evanw.github.io-float-toy] tiene una explicación gráfica muy buena de cómo los bits de un número de punto flotante se convierten en un valor de punto flotante real.
