# Anexo de instrucciones

## Extra

Prueba tu función con este string: `uüu` y mira qué pasa.
Intenta escribir una función que invierta este string correctamente.
Pista: grapheme clusters

Para que se ejecute la prueba extra, quita el indicador de ignorar (`#[ignore]`) de la última prueba y ejecuta las pruebas con:

```bash
cargo test --features grapheme
```

Para la tarea extra vas a necesitar bibliotecas externas (un `crate` en la jerga de Rust).
Un buen lugar para buscarlas es [crates.io](https://crates.io/), el repositorio oficial de crates.
Recuerda que nuestro ejecutor de pruebas solo admite un conjunto limitado de crates.
La lista completa está en [este archivo](https://github.com/exercism/rust-test-runner/blob/main/local-registry/Cargo.toml), en la sección `[dependencies]`.

[Consulta la documentación](https://doc.rust-lang.org/cargo/guide/dependencies.html) para saber cómo usar crates externos en tus proyectos.
