# Acerca de

[Nil][nil-dictionary] es una palabra del inglés que significa «nada» o «cero». En Elixir, `nil` es un valor especial que significa una _ausencia_ de valor.

```elixir
# I do not have a favorite color
favorite_color = nil
```

`nil` es un átomo, pero por lo general se escribe como `nil`, no como `:nil`. Los valores booleanos `true` y `false` también son átomos.

[//]: # (elixir-formatter-disable-next-block)

```elixir
nil === :nil
# => true

true === :true
# => true
```

Puedes comprobar si el valor de una variable es `nil` con [`==`][kernel-equal], con coincidencia de patrones o con el guard [`is_nil`][kernel-is-nil].

```elixir
def call(phone_number) do
  if phone_number == nil do
    :error
  end
end
```

```elixir
def call(phone_number) when is_nil(phone_number) do
  :error
end
```

```elixir
def call(nil) do
  :error
end
```
