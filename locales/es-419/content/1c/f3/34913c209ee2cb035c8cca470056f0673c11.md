# Instrucciones

En este ejercicio escribirás código para llevar un registro de los códigos de marcación internacionales mediante un mapa hash de códigos de marcación internacionales.

El mapa usa un entero para sus claves (el código de marcación) y un string (nombre del país) para sus valores.

Tienes 11 tareas que involucran códigos de marcación.

## 1. Crea un mapa hash precargado

Existe un mapa hash precargado que contiene los siguientes 3 códigos de marcación: «United States of America», que tiene un código 1, «Brazil», que tiene un código 55, e «India», que tiene un código 91. Define la variable `countries` para almacenar el mapa hash precargado:

```clojure
countries
;;=> {1 "United States of America", 55 "Brazil", 91 "India"}
```

## 2. Agrega un país a un mapa

Agrega «United Kingdom» con un código de marcación 44 al mapa creado en la tarea 1:

```clojure
(add-country countries 44 "United Kingdom")
;;=> {1 "United States of America", 44 "United Kingdom", 55 "Brazil", 91 "India"}
```

## 3. Obtén el nombre del país que coincide con un código de marcación

Recupera el nombre del país con código de marcación 55

```clojure
(country-name countries 55)
;;=> "Brazil"
```

## 4. Actualiza el nombre de un país

Cambia el nombre de «United States of America» a «Les États-Unis»:

```clojure
(update-map countries 1 "Les États-Unis")
;;=> {1 "Les États-Unis", 55 "Brazil", 91 "India"}
```

## 5. Verifica que un país existe en el mapa

Verifica que exista un registro para Brazil en el mapa creado en la tarea 1

```clojure
(code-exists? countries 55)
;;=> true
```

## 6. Intenta actualizar el nombre de un país que no está en el mapa

Intenta cambiar el nombre de un país con un código que no está en el mapa, por ejemplo, 999. Esto no debería producir ningún cambio en el mapa:

```clojure
(update-map countries 999, "Newlands")
;;=> {1 "United States of America", 44 "United Kingdom", 55 "Brazil", 91 "India"}
```

## 7. Elimina un país del mapa

Elimina India del mapa:

```clojure
(remove-country countries 91)
;;=> {1 "United States of America", 55 "Brazil"}
```

## 8. Encuentra el país con el nombre más largo

Procesa los valores del mapa para encontrar el que tenga el nombre más largo:

```clojure
(longest-name countries)
;;=> "United States of America"
```
