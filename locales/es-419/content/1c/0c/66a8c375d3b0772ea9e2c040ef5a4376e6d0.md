# Introducción

En Factor, combinas palabras simplemente escribiéndolas una tras otra: el orden en que las escribes *es* la forma en que se unen. (A esto los programadores lo llaman *composición de funciones*.) El cuerpo de una palabra es en sí mismo una secuencia de palabras: cada una consume algunos valores de la pila y empuja su resultado, y la siguiente palabra continúa donde la anterior quedó. Así, definir

```factor
! DOCTEST: SKIP   (cleanupname is hypothetical here — the exercise's job)
: firstletter ( name -- letter ) cleanupname first 1string ;
```

ya *es* la composición de `cleanupname`, `first` y `1string`.

Este ejercicio también presenta las **quotations**: un fragmento de código que puedes guardar como valor y ejecutar después, en lugar de ejecutarlo en el momento.

## Quotations

Una quotation es un fragmento de código encerrado entre corchetes. No se ejecuta al escribirla; se queda en la pila como un valor:

```factor
[ 2 * ] .       ! => [ 2 * ]
```

`call` ejecuta una quotation:

```factor
3 [ 2 * ] call .    ! => 6
```

Escribes una quotation cuando necesitas pasar código como dato: para ejecutarlo después, o para pasarlo a un *combinador*, una palabra que toma una quotation como argumento.

## `compose`

`compose ( quot1 quot2 -- combined )` une dos quotations en una, ejecutándolas en el orden en que están escritas:

```factor
[ 2 * ] [ 1 + ] compose .    ! => [ 2 * 1 + ]
```

Por lo general verás que definir una palabra pequeña con `:` ... `;` se lee mejor que `compose`, pero `compose` resulta práctico cuando necesitas construir quotations sobre la marcha. Cuando los bloques de construcción todavía no son quotations, `>quotation ( seq -- quot )` (de [`quotations`][quotations]) convierte una secuencia de valores y referencias a palabras en una quotation que se puede llamar:

```factor
USING: quotations sequences ;

{ [ 1 ] [ 2 + ] [ 3 * ] } concat >quotation call .   ! => 9
```

## Aplicar una quotation a dos argumentos

`bi@ ( x y quot -- ... )` ejecuta la quotation sobre `x` y de nuevo sobre `y`, dejando ambos resultados en la pila:

```factor
3 4 [ 2 * ] bi@ .s
! => 6
! => 8
```

La tarea `couple` del ejercicio toma dos nombres; `bi@` es la forma natural de aplicar `initial` a cada uno.

## Algunas palabras para strings

El ejercicio necesita unas cuantas palabras pequeñas para strings, tomadas de tres vocabularios: [`sequences`][sequences], [`ascii`][ascii] y [`strings`][strings]:

- `replace ( seq old new -- new-seq )` (en `splitting`): reemplaza subcadenas.
- `[ blank? ] trim` (`trim` en `sequences`, `blank?` en `ascii`): elimina los espacios en blanco al principio y al final.
- `1string ( char -- str )` (en `strings`): envuelve un solo carácter en un string.
- `>upper ( str -- upper )` (en `ascii`): convierte un string a mayúsculas.
- `append ( s1 s2 -- s )` (en `sequences`): concatena dos strings.
- `prepend ( s1 s2 -- s )` (en `sequences`): concatena `s2` y luego `s1` (`append` con sus argumentos en el orden inverso).
- `glue ( s1 s2 sep -- s )` (en `sequences`): concatena dos strings con un separador entre ellos.
- `surround ( seq pre post -- new )` (en `sequences`): envuelve un string con un prefijo y un sufijo.

Los caracteres Unicode se pueden escribir como `\u{XXXX}` dentro de un string, donde `XXXX` es el punto de código en hexadecimal. El corazón `\u{2764}` (❤) aparece en este ejercicio.

## Salida con formato

Cuando `append`, `glue` y `surround` no son lo bastante expresivos, [`formatting`][formatting] ofrece `sprintf`, al estilo de printf:

```
sprintf ( inputs... format-string -- str )
```

`%s` interpola un string, `%d` un entero y `%f` un número de punto flotante; los modificadores opcionales de ancho, precisión y relleno van entre `%` y la letra del tipo:

```factor
USING: formatting ;

"Alice" "Bob" "%s & %s" sprintf .   ! => "Alice & Bob"
3.14159 "%.2f" sprintf .             ! => "3.14"
42 "%05d" sprintf .                  ! => "00042"
```

Para convertir en ambos sentidos entre números y strings, [`math.parser`][math.parser] tiene `number>string` y `string>number`:

```factor
USING: math.parser ;

42 number>string .       ! => "42"
"3.14" string>number .   ! => 3.14
```
