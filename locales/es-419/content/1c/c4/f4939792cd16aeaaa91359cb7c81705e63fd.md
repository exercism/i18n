# Instrucciones

Eres un observador de aves entusiasta que lleva la cuenta de cuántas aves han visitado tu jardín en los últimos siete días.

Tienes cinco tareas, todas relacionadas con la cantidad de aves que visitaron tu jardín.

## 1. Revisa cuáles fueron los conteos de la semana pasada

Guardas tus conteos de aves en formato JSON.
Un array «principal» almacena arrays de conteos semanales.
Cada conteo semanal es un array de siete números enteros, un número por cada día de la semana.
Siempre agregas las semanas nuevas al final del array principal.
Implementa el filtro que devuelve los conteos de la semana pasada.

```sh
$ cat bird-counting-data.json
[
  ...,
  [0, 2, 5, 3, 7, 8, 4],
  [4, 5, 9, 10, 9, 4, 3]
]

$ jq -f bird-count.jq < bird-counting-data.json
{
  "last_week": [0, 2, 5, 3, 7, 8, 4],
  ...
```

## 2. Revisa cuántas aves visitaron ayer

Implementa el filtro que devuelve cuántas aves visitaron tu jardín ayer.
Los conteos de aves están ordenados por día, donde el primer elemento es el conteo del día más antiguo y el último elemento es el conteo de hoy.

```jq
$ jq -f bird-count.jq < bird-counting-data.json
{
  ...
  "yesterday": 4,
  ...
```

## 3. Calcula el número total de aves visitantes

Implementa el filtro que devuelve el número total de aves que han visitado tu jardín esta semana.

```jq
$ jq -f bird-count.jq < bird-counting-data.json
{
  ...
  "total": 44,
  ...
```

## 4. Calcula la cantidad de días ajetreados

Algunos días son más ajetreados que otros.
Un día ajetreado es aquel en el que cinco o más aves han visitado tu jardín.
Implementa el filtro que devuelve la cantidad de días ajetreados de esta semana.

```jq
$ jq -f bird-count.jq < bird-counting-data.json
{
  ...
  "busy_days": 4,
  ...
```

## 5. Revisa si hubo un día sin aves visitantes

Implementa el filtro que devuelve `true` si hubo algún día de esta semana en el que cero aves visitaron el jardín; de lo contrario, devuelve `false`.

```jq
$ jq -f bird-count.jq < bird-counting-data.json
{
  ...
  "has_day_without_birds": false
}
```
