# Apéndice de instrucciones

## Pistas

Este ejercicio requiere que trabajes con Reactive extensions. Para más información, consulta
[esta página](http://reactivex.io/intro.html).

En la programación reactiva es más fácil comunicar intenciones mediante diagramas de mármol. Los tests se complementan
con información de diagramas de mármol. El formato de texto se puede analizar con
[esta herramienta](https://bitbucket.org/achary/rx-marbles/src/master/docs/syntax.md?fileviewer=file-view-default)
.
