# Instrucciones

Una terna pitagórica es un conjunto de tres números naturales, {a, b, c}, para los cuales,

```text
a² + b² = c²
```

y tales que,

```text
a < b < c
```

Por ejemplo,

```text
3² + 4² = 5².
```

Dado un número entero N de entrada, encuentra todas las ternas pitagóricas para las cuales `a + b + c = N`.

Por ejemplo, con N = 1000, hay exactamente una terna pitagórica para la cual `a + b + c = 1000`: `{200, 375, 425}`.
