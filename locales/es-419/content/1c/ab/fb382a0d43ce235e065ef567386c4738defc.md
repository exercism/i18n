# Anexo de instrucciones

## Espera, ¡es imposible!

Implementar estas operaciones de arrays sin usar _ninguna_ función integrada es prácticamente imposible en Roc, porque necesitas una forma de agregar o anteponer elementos a un array.
En otros lenguajes podrías usar operadores como `:` en Haskell o `+=` en Python, pero en Roc tienes que usar las [funciones de `List`](https://www.roc-lang.org/builtins/main/#Builtin.List).

Así que para este ejercicio se te permite usar `List.append` (pero evita usar cualquier otra función integrada).

Muchos lenguajes de programación funcional usan listas enlazadas como tipo de colección principal.
Es eficiente anteponer un elemento o sacar el primer elemento de una lista enlazada, así que en esos lenguajes implementarías estas operaciones usando `List.prepend`.
En Roc, sin embargo, un `List` es un array (un bloque contiguo de bytes).
Los arrays tienen propiedades distintas de las listas enlazadas, como la capacidad de acceder a los elementos por índice de forma eficiente y de agregar elementos nuevos.
Por eso, en Roc usamos `List.append` con frecuencia y rara vez usamos `List.prepend`.

## Nombres

Roc usa nombres un poco distintos de los que aparecen en las instrucciones generales:

- `concat` en lugar de `append`
- `join` en lugar de `concatenate`
- `len` en lugar de `length`
- `fold` en lugar de `foldl`
- `fold_rev` en lugar de `foldr`

Sin embargo, los siguientes nombres de funciones son estándar en Roc:
- `filter`
- `map`
- `reverse`

## Pista

Prueba a usar:

```roc
match list {
    [] => ...
    [first, .. as rest] => ...
}
```

o

```roc
match list {
    [] => ...
    [.. as rest, last] => ...
}
```
