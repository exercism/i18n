# Instrucciones

Eres docente.
Al final del año, generaste una calificación numérica para cada uno de tus estudiantes.
Ahora necesitas convertirla en una calificación con letra y contar cuántos estudiantes obtuvieron cada calificación con letra.

## 1. Convierte una calificación numérica en una calificación con letra

La función `letter_grade` recibe una calificación numérica como argumento y devuelve la letra.
Usa estos rangos:

| Letra | Calificación |
| :----: | ---------: |
|   A    | 90% - 100% |
|   B    |  80% - 89% |
|   C    |  70% - 79% |
|   D    |  60% - 69% |
|   F    |   0% - 59% |

Ejemplo:

```jq
75 | letter_grade   # => "C"
```

## 2. Cuenta el número de estudiantes para cada calificación con letra

La función `count_letter_grades` recibe un objeto que asigna los nombres de los estudiantes a sus calificaciones.
El resultado será un objeto que asigna cada calificación con letra al número de estudiantes con esa calificación.

Ejemplo:

```jq
{"Joe": 78, "Jane": 93, "Richard": 72} | count_letter_grades
# => {"A": 1, "B": 0, "C": 2, "D": 0, "F": 0}
```

Hay varias maneras distintas de resolver esto.
Usa el filtro `reduce` para practicar.
