# Introducción

Los caracteres y los strings son la base para representar texto en Elm.
Los strings se pueden pensar como listas de caracteres, y la mayoría de las funciones de `List` tienen su equivalente en el módulo `String`.

## Caracteres

El tipo `Char` representa un solo carácter Unicode y se escribe entre comillas simples, por ejemplo `'a'`. 
El módulo `Char` proporciona funciones de predicado (`Char -> Bool`) para comprobar cualidades de un carácter: `isUpper`, `isLower`, `isAlpha` y `isAlphaNum`.
El módulo también ofrece funciones para convertir un carácter con `toUpper`, `toLower`, `toLocaleUpper` y `toLocaleLower`, así como para obtener su valor numérico Unicode (`Int`) y convertir desde él, con `toCode` y `fromCode`.

## Strings

El tipo `String` ofrece una representación integrada para manipular strings de forma eficiente y puede representar cualquier secuencia de caracteres Unicode.
Los strings se representan con comillas dobles: `"this is a string"`.
Los strings de varias líneas se representan con tres comillas dobles y pueden incluir comillas y saltos de línea sin escaparlos.

```elm 
haiku = 
"""
    Code's strings entwine
    , In binary, thoughts combine
    , Logic's elegant line.
"""
```

## Manipulación de strings

`reverse : String -> String` invierte el string.
```elm 
reverse "Hello world." 
    --> ".dlrow olleH"
```

`repeat : Int -> String -> String` repite un string n veces.
```elm 
repeat 2 "Hello world." 
    --> "Hello world.Hello world."
```

`replace : String -> String -> String -> String` reemplaza todas las apariciones de una subcadena dada.
```elm
replace "Hello" "Goodbye cruel" "Hello world." 
    --> "Goodbye cruel world."
```

`append : String -> String -> String` agrega un string al final de otro.
El operador `++` también sirve para hacer esto.
```elm
append "butter" "fly" 
    --> "butterfly"
"butter" ++ "fly" 
    --> "butterfly"
```

`concat : List String -> String` concatena una lista de strings en un solo string.
```elm
concat ["never", "the", "less"] 
    --> "nevertheless"
```

`split : String -> String -> List String` divide un string en una lista de strings usando el separador dado.
```elm
split ";" "cat;dog;cow" 
    --> ["cat", "dog", "cow"]
```

`join : String -> List String -> String` une una lista de strings usando un separador dado.
```elm
join "a" ["H", "w", "ii", "n"] 
    --> "Hawaiian"
```

`words : String -> List String` divide un string en varios strings, separándolos por bloques de espacios en blanco.
```elm
words "How are \t you? \n Good?" 
    --> ["How", "are", "you?", "Good?"]
```

`lines : String -> List String` divide un string en líneas, separándolas por saltos de línea.
```elm
lines "How are you?\nGood?" 
    --> ["How are you?", "Good?"]
```

`cons : Char -> String -> String` agrega un carácter al principio de un string.
```elm
cons 'T' "he truth is out there" 
    --> "The truth is out there"
```

`uncons : String -> Maybe ( Char, String )` divide un string no vacío en su cabeza y su cola.
Esto te permite hacer coincidencia de patrones con strings exactamente como lo harías con listas.
Los strings vacíos devuelven `Nothing`.
```elm
uncons "abc" 
    --> Just ('a', "bc")
uncons ""
    --> Nothing
```

## Obtención de substrings

`slice : Int -> Int -> String -> String` obtiene una subcadena a partir de un índice inicial y uno final.
Los índices negativos se cuentan desde el final de la lista.
```elm
slice 0 6 "snakes on a plane!" 
    --> "snakes"
slice 0 -7 "snakes on a plane!"
    --> "snakes on a"
```

`left : Int -> String -> String` y `right : Int -> String -> String` toman n caracteres del lado izquierdo o del lado derecho del string, respectivamente.

```elm
left 2 "Mulder" 
    --> "Mu"
right 2 "Scully" 
    --> "ly"
```

`dropLeft : Int -> String -> String` y `dropRight : Int -> String -> String` descartan n caracteres del lado izquierdo o del lado derecho de un string, respectivamente.
```elm
dropRight 6 "Hello world." 
    --> "Hello"
dropLeft 6 "Hello world." 
    --> "world"
```

## Comprobación de las cualidades de un string

`length : String -> Int` devuelve el número de caracteres de un string.
```elm 
length "Hello world." 
    --> 12
```

`isEmpty : String -> Bool` determina si un string está vacío. 
```elm 
isEmpty "Hello world." 
    --> False
```

`contains : String -> String -> Bool` comprueba si el segundo string contiene al primero.
```elm
contains "the" "theory" 
    --> True
contains "THE" "theory" 
    --> False
```

`startsWith : String -> String -> Bool` y `endsWith : String -> String -> Bool` comprueban si el segundo string empieza o termina con una subcadena dada.
```elm
startsWith "the" "theory" 
    --> True
endsWith "ory" "theory" 
    --> True
```

`indexes : String -> String -> List Int` obtiene una lista de todos los índices donde empieza una subcadena dentro de otro string.
```elm
indexes "ss" "Mississippi"  
    --> [2, 5]
```

## Conversión de strings
`toInt : String -> Maybe Int` intenta convertir un string en `Just Int` y devuelve `Nothing` para los strings con un formato incorrecto.
```elm
toInt "-42" 
    --> Just -42
toInt "3.1" 
    --> Nothing
toInt "two" 
    --> Nothing
```

`fromInt : Int -> String` convierte un número entero en un string.
```elm
fromInt -42 
    --> "-42"
```

`toFloat : String -> Maybe Float` intenta convertir un string en un número de punto flotante y falla si el string tiene un formato incorrecto.
```elm
toFloat "-42" 
    --> Just -42.0
toFloat "3.1" 
    --> Just 3.1
toFloat "two" 
    --> Nothing
```

`fromFloat : Float -> String` convierte un número de punto flotante en un string.
```elm
fromFloat 3.9 
    --> "3.9"
```

`toList : String -> List Char` y `fromList : List Char -> String` convierten un string a una lista de caracteres y viceversa, respectivamente.
```elm 
toList "abc" 
    --> ['a', 'b', 'c']
fromList ['a', 'b', 'c'] 
    --> "abc"
```

`fromChar : Char -> String` convierte un carácter en un string.
```elm
fromChar 'a' 
    --> "a"
```

## Formato de strings

`toUpper : String -> String` y `toLower : String -> String` convierten strings a todo mayúsculas o a todo minúsculas, respectivamente.
Son útiles para comparaciones que no distinguen mayúsculas de minúsculas.
```elm
toUpper "skinner" 
    --> "SKINNER"
toLower "X-FILES" 
    --> "x-files"
```

`pad : Int -> Char -> String -> String` rellena un string por ambos lados con el `Char` indicado hasta que tenga la longitud dada.
```elm
pad 5 ' ' "11"  
    --> "  11 "
```
De forma similar, `padLeft` y `padRight` rellenan un string por uno de los lados hasta que tenga una longitud dada.

`trim : String -> String` elimina los espacios en blanco a ambos lados de un string.
```elm
trim "  hats  \n" 
    --> "hats"
```
`trimLeft` y `trimRight` eliminan los espacios en blanco de uno de los lados de un string.

## Funciones de orden superior

`map : (Char -> Char) -> String -> String` transforma cada carácter de un string con la función dada.
Ten en cuenta que la función proporcionada debe ser una transformación de `Char` a `Char`.
```elm
map (\c -> if c == '/' then '.' else c) "a/b/c" 
    --> "a.b.c"
```

`filter : (Char -> Bool) -> String -> String` conserva solo los caracteres que pasan la prueba.
```elm
filter isDigit "R2-D2" 
    --> "22"
```

`foldl : (Char -> b -> b) -> b -> String -> b` reduce un string empezando por la izquierda.
La función se aplica con el primer carácter como primer parámetro y un valor inicial proporcionado como segundo parámetro.
El resultado de la función debe ser del mismo tipo que el valor inicial proporcionado y se aplica a cada carácter en secuencia.
```elm
foldl (\c acc -> Char.toCode c + acc) 0 "the sum of my unicode is " 
    --> 2260
```
`foldr` hace lo mismo, pero empezando por el lado derecho del string.

`any : (Char -> Bool) -> String -> Bool` determina si algún carácter devuelve `True` al predicado dado.
```elm
any isDigit "R2-D2" 
    --> True
any isDigit "heart" 
    --> False
```
`all : (Char -> Bool) -> String -> Bool` determina si todos los caracteres de un string devuelven `True` al predicado dado.
```elm
all isDigit "R2-D2" 
    --> False
all isAlpha "heart" 
    --> True
```
