# Acerca de

Los combinadores convierten los patrones de reordenamiento de la pila en palabras con nombre y componibles. Una vez que hayas escrito suficiente Factor, dejas de pensar «tengo que hacer `dup`, luego ejecutar F y después conservar el original» y simplemente escribes `[ F ] keep`.

| patrón | palabras de reordenamiento | combinador |
|------------------------------------|-------------------------------|-----------------|
| aplicar F y conservar el argumento | `dup F swap` | `[ F ] keep` |
| dos funciones sobre un mismo argumento | `dup F swap G` | `[ F ] [ G ] bi` |
| tres funciones sobre un mismo argumento | complicado | `[ F ] [ G ] [ H ] tri` |
| muchas funciones sobre un mismo argumento | muy complicado | `{ Fs … } cleave` |
| operar sobre los valores *debajo* del tope | `swap F swap` | `[ F ] dip` |
| la misma operación sobre dos valores | `swap F swap F` | `[ F ] bi@` |
| operaciones distintas sobre dos valores | `swap F swap G` | `[ F ] [ G ] bi*` |

La familia con prefijo `2` (`2bi`, `2dip`, `2tri`, `2dup`, `2drop`, `2nip`, `2swap`) hace lo mismo cuando cada operación necesita *dos* argumentos; `3dup` y `4dup` extienden el modismo de duplicación a tres o cuatro valores en el tope de la pila.

Además de la familia cleave/dip/bi, [`kernel`][kernel] también ofrece variantes de flujo de control que propagan `f` de forma limpia:

| palabra | efecto |
|-------------|-----------------------------------------------------|
| `if*` | la rama verdadera ve el valor; la rama falsa no |
| `?last` | el último elemento de una secuencia, o `f` si está vacía |
| `pop*` | variante de `pop` que descarta el valor (muta un vector) |
| `dupd` | duplica el *segundo* desde el tope |
| `pick` | copia el *tercero* desde el tope hacia arriba |
| `swapd` | intercambia el segundo y el tercero desde el tope |
| `rotd` | rota los tres de abajo de una pila de cuatro niveles |
| `tuck` | copia el tope debajo del segundo desde el tope |
| `with` | fija un valor dentro de una quotation para HOS |
| `while` | hace un bucle mientras se cumpla un predicado |
| `until` | hace un bucle hasta que se cumpla un predicado |

Elegir el combinador adecuado es una habilidad en sí misma. La regla general: cuando el cuerpo de una definición ya tiene más de una palabra de reordenamiento seguida, por lo general hay un combinador que captura mejor la intención.

[kernel]: https://docs.factorcode.org/content/vocab-kernel.html
