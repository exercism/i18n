# Instrucciones

Eres un observador de aves entusiasta que lleva la cuenta de cuántas aves han visitado tu jardín en los últimos siete días.

Tienes seis tareas, todas relacionadas con el número de aves que visitaron tu jardín.

## 1. Verifica cuáles fueron los conteos de la semana pasada

Para comparar, siempre tienes cerca una copia de los conteos de la semana pasada, que eran: 0, 2, 5, 3, 7, 8 y 4. Implementa el método `BirdWatcher.getLastWeek()` que devuelve los conteos de la semana pasada:

```java
BirdWatcher.getLastWeek();
// => [0, 2, 5, 3, 7, 8, 4]
```

## 2. Verifica cuántas aves visitaron hoy

Implementa el método `BirdWatcher.getToday()` para devolver cuántas aves visitaron tu jardín hoy. Los conteos de aves están ordenados por día, donde el primer elemento es el conteo del día más antiguo y el último elemento es el conteo de hoy.

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.getToday();
// => 1
```

## 3. Incrementa el conteo de hoy

Implementa el método `BirdWatcher.incrementTodaysCount()` para incrementar el conteo de hoy:

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.incrementTodaysCount();
birdCount.getToday();
// => 2
```

## 4. Verifica si hubo un día sin aves visitantes

Implementa el método `BirdWatcher.hasDayWithoutBirds()` que devuelve `true` si hubo un día en el que cero aves visitaron el jardín; de lo contrario, devuelve `false`:

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.hasDayWithoutBirds();
// => true
```

## 5. Calcula la cantidad de aves visitantes en los primeros días

Implementa el método `BirdWatcher.getCountForFirstDays()` que devuelve el número de aves que han visitado tu jardín desde el inicio de la semana, pero limita el conteo al número especificado de días desde el principio de la semana.

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.getCountForFirstDays(4);
// => 14
```

## 6. Calcula la cantidad de días ajetreados

Algunos días son más ajetreados que otros. Un día ajetreado es aquel en el que cinco o más aves visitaron tu jardín.
Implementa el método `BirdWatcher.getBusyDays()` para devolver la cantidad de días ajetreados:

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.getBusyDays();
// => 2
```
