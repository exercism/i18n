# Acerca de

El Printer de Common Lisp es la utilidad que permite enviar datos a flujos. Una de las funciones más comunes de esta utilidad es `format`.

`format` recibe dos parámetros obligatorios: un flujo en el que escribir y un string de control. El contenido del string de control determina cómo se usan los argumentos adicionales.

El primer parámetro tiene dos valores especiales: `t` y `nil`. `t` indica que se debe usar el flujo vinculado a `*standard-output*` y `nil` indica que se debe crear un string y devolverlo. `format` se evalúa a `nil` a menos que el parámetro de flujo sea `nil`.

El string de control puede contener directivas de formato, que se indican con una `~` seguida de un carácter (no importa si el carácter está en mayúscula o minúscula). La directiva de formato define si se consumen argumentos y cómo se formatean en el flujo.

Las directivas de formato básicas más importantes son:

* `~A` - formatea de manera _estética_, es decir, «legible para humanos».
* `~S` - formatea según el _estándar_, para que sea «legible para máquinas».
* `~%` - emite un salto de línea.
* `~&` - emite un salto de línea, a menos que ya se esté al principio de una línea.
* `~~` - emite una virgulilla.

Ejemplos:

```lisp
(format nil "The list is: ~A~%" (list 1 2 3)) ; => "The list is: (1 2 3)
                                                   "
(format nil "(format t ~S)" "hello world")    ; => "(format t \"hello world\""
(format nil "~&fresh~&lines")                 ;=> "fresh
                                                   lines"
(format nil "directives start with a ~~")     ; => "directives start with a ~"
```
