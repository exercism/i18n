# Pistas

## General

- Tu archivo de solución se incluye en otro, que llama a tus macros.
  Mantén el nombre y el orden de los argumentos de cada macro exactamente como los da la tarea, o el archivo no se podrá ensamblar.
- Los argumentos de una macro son tokens, que se sustituyen como `%1`, `%2`, `%3` dondequiera que aparezcan en el cuerpo.
  Pueden ser registros, expresiones de dirección o literales, siempre que cada expansión sea una instrucción válida.
- Cada macro se verifica por los registros que deja intactos, no solo por lo que escribe.
  Lee la nota sobre qué registros se modifican en cada tarea y cambia únicamente los que permite.

## 1. Nombra las constantes de formato

- Un `%define` de una sola línea le da un nombre a un valor, para que el resto del código pueda leer el nombre en lugar de un número sin más.
  Para un número fijo, `equ` hace lo mismo y es la opción habitual para una constante.
- Las constantes de byte se pueden escribir como hexadecimal (`0x20`) o como un literal de carácter (`' '`).
  Ambas se ensamblan al mismo valor.

## 2. Escribe la macro `fill_run`

- Deberías darle a `rcx` el nombre legible `COUNTER`.
- `fill_run` es una macro multilínea que recibe 3 argumentos.
  Las macros multilínea se definen con `%macro ... %endmacro`.
- El primer argumento de `fill_run` es una dirección de memoria en un registro de propósito general de 64 bits.
  El segundo es la cuenta, que se puede pasar en un registro de propósito general de 64 bits o como un inmediato.
  El tercero es un byte que se va a escribir, como un inmediato.
  Deberías planear el código de la macro teniendo en cuenta estas especificaciones.
- El único registro que `fill_run` puede modificar es `COUNTER`.
- Un bucle dentro de una macro normalmente necesita una etiqueta con el prefijo `%%`.
  Sin este prefijo, se crea la misma etiqueta cada vez que se llama a la macro, lo que puede causar un error si la macro se llama más de una vez.

## 3. Escribe la macro `lay_columns`

- `lay_columns` es una macro multilínea que recibe 2 argumentos.
  Las macros multilínea se definen con `%macro ... %endmacro`.
- Los dos argumentos de `lay_columns` se pasan en registros de propósito general de 64 bits.
  El primero es una dirección de memoria y el segundo es un entero.
  Deberías planear el código de la macro teniendo en cuenta estas especificaciones.
- Los únicos registros que `lay_columns` puede modificar son los dos que se pasan como argumentos.
- La cantidad de desplazamientos que la macro debe escribir está fijada en tiempo de ensamblado.
  Puedes usar `%rep ... %endrep` para repetir el código.
- El cálculo de los desplazamientos se hace con `offset[i] = margin + i * COLUMN_STRIDE`.
  `margin` es el segundo argumento de la macro.
  `i` es un contador de bucle que se puede definir como una variable de `%assign`.

## 4. Escribe la macro `set_header`

- `set_header` es una macro multilínea que recibe 2 argumentos.
  Las macros multilínea se definen con `%macro ... %endmacro`.
- El primer argumento de `set_header` es la expresión de una dirección de memoria efectiva.
  Toma un registro base que se puede sumar con un registro índice escalado por `1`, `2`, `4` u `8`, y un inmediato.
  Esto significa que un simple `rdi` es válido, igual que `rdi+rax*4+2`.
- El segundo argumento de `set_header` es un inmediato que puede tener los valores `0`, `1` o `2`.
- `set_header` no debe modificar ningún registro en absoluto.
- Deberías copiar un byte de forma condicional a la dirección de destino en tiempo de ensamblado, según el segundo argumento.
  Un valor de `0` debería copiar `PLAIN`, un valor de `1` debería copiar `RULED` y un valor de `2` debería copiar `BOXED`.
