# Anexo de instrucciones

## Notas específicas de WebAssembly

La firma de la función para la exportación `convert` de WebAssembly es la siguiente:

```wasm
(func (export "convert")
    (param $arrOffset i32)
    (param $arrLength i32)
    (param $inputBase i32)
    (param $outputBase i32)
    (result i32 i32 i32)
)
```

Los dos primeros parámetros, `$arrOffset` y `$arrLength`, expresan el desplazamiento base y la longitud de un array de enteros con signo de 32 bits. El parámetro de longitud se mide en número de elementos del array, no en bytes. Antes de llamar a esta función, quien la llama escribe este array en la memoria lineal de WebAssembly a partir del desplazamiento `$arrOffset`. La memoria lineal de WebAssembly siempre se expresa en little-endian.

Por lo tanto, quien llama codificaría el array `[1,2]` como la siguiente secuencia de ocho bytes.

```
| 64 | 65 | 66 | 67 | 68 | 69 | 70 | 71 |
| ---- arr[0] ----- | ---- arr[1] ----- |
,0x01,0x00,0x00,0x00,0x02,0x00,0x00,0x00,
```

Los parámetros `$inputBase` y `$outputBase` no involucran la memoria lineal.

El tipo de resultado es `(i32 i32 i32)`. Los dos primeros valores son el `offset` y el `length` de tu salida en la memoria lineal. Si lo prefieres, puedes sobrescribir las direcciones de la memoria lineal que se usaron para la entrada. El tercer valor de retorno es un código de estado i32 que se usa para el manejo de errores.

Si el tercer valor de retorno indica un estado de error, las pruebas unitarias no leen los dos primeros valores de retorno.
