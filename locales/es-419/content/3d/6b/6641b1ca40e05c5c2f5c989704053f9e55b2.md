# Instrucciones

El ejercicio introductorio clásico.
Solo di «Hello, World!».

[«Hello, World!»][hello-world] es el primer programa tradicional para quienes empiezan a programar en un nuevo lenguaje o entorno.

Los objetivos son simples:

- Modifica el código proporcionado para que produzca el string «Hello, World!».
- Ejecuta la suite de tests y asegúrate de que pase.
- Envía tu solución y revísala en el sitio web.

Si todo sale bien, ya podrás descargar tu primer ejercicio real.

[hello-world]: https://en.wikipedia.org/wiki/%22Hello,_world!%22_program
