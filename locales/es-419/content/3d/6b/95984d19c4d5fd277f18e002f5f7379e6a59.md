# Apéndice de las instrucciones

## Paquetes de Tcl

Este es el primer ejercicio que incluye un paquete ya escrito.
Fíjate en la presencia del archivo `pkgIndex.tcl` y en la inclusión del directorio actual en la variable `auto_path`.
Estos permiten que el comando `package require` encuentre el archivo fuente del paquete.

No es un paquete especialmente bien escrito: es solo código que se tomó prestado de varias fuentes.
La llamada a `interp alias` sirve para ocultar las imperfecciones y hacer que el paquete de permutaciones sea más fácil de usar.

Referencias:
* [`auto_path`](http://www.tcl-lang.org/man/tcl8.6/TclCmd/tclvars.htm)
* [`package`](http://www.tcl-lang.org/man/tcl8.6/TclCmd/package.htm)
* [`pkg_mkIndex`](http://www.tcl-lang.org/man/tcl8.6/TclCmd/pkgMkIndex.htm)
