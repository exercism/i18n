# Introducción


## Boolean

PowerShell tiene el tipo [`bool`][booleans] para representar valores verdadero y falso.
En este tipo solo hay dos valores: `True` y `False`.
Puedes asignar estos valores a variables con el prefijo `$`:

```powershell
> $TrueVar  = $true
> $FalseVar = $FALSE
#Case senstitivity doesn't matter here
```

Podemos usar [operadores lógicos][logical-operators] como `-and`, `-or` y `-not` para combinar y evaluar expresiones booleanas.

```powershell
> $TrueVar  = $true -and $true
> $FalseVar = $true -and $false

> $TrueVar  = $true -or $false
> $FalseVar = $false -or $false

> $TrueVar  = -not $false
> $FalseVar = -not $true
```


## Ayuda basada en comentarios

La [`Comment-based help`][comment-based help] en PowerShell ayuda a proporcionar información detallada de funciones y scripts escrita en comentarios.
Usa palabras clave especiales de comentarios de ayuda para especificar los temas en cuestión, por ejemplo `.SYNOPSIS`, `.EXAMPLE` o `.NOTES`.

```powershell
function ExampleFunction($Arg) {
    <#
    .DESCRIPTION
    A detailed description of the function or script. This keyword can be used only once in each topic.

    .PARAMETER Arg
    The description of a parameter, it must be follow with the parameter name.
    #>
}
```

Puedes mostrar la información de la ayuda basada en comentarios usando el cmdlet `Get-Help`.

```powershell
> Get-Help -Name "ExampleFunction"
```
