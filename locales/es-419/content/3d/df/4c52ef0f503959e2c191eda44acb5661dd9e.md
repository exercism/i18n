## 4. Define la actividad

- [Esta página][define] muestra cómo definir una unión discriminada, tanto para los casos con datos asociados como para los que no los tienen.

## 5. Califica la actividad

- La mejor forma de ejecutar lógica según el valor de la actividad es usar [coincidencia de patrones][pattern-matching].
- El patrón para coincidir con los casos de una unión discriminada (y, opcionalmente, sus datos asociados) es mediante [patrones de identificador][identifier-patterns].
- Si quieres agregar una condición adicional a un patrón, puedes agregar una [guarda][guards].
- Si quieres capturar más de un valor a la vez, puedes usar un [patrón comodín][wildcard-patterns].
