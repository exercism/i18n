# Tests

## clojure.test

Babashka viene con clojure.test incluido. Cuando estés listo para trabajar en un ejercicio y hayas creado un archivo para tu solución (como `bob.clj`), puedes ejecutar las pruebas con `clojure.test/run-tests` [como se describe aquí](http://clojure.github.io/clojure/clojure.test-api.html#clojure.test/run-tests).


El REPL te permite ejecutar código fácilmente y obtener retroalimentación inmediata, y también puedes usarlo para ejecutar las pruebas. Se recomienda usar `rlwrap` para habilitar la edición de líneas y el historial de comandos con las flechas arriba y abajo. Para probar un ejercicio, cámbiate a su directorio y abre un REPL de socket agregando los directorios `src` y `test` al classpath:
``` bash
/bob $ rlwrap bb --classpath src:test socket-repl 1666
```

Primero, usa `require` para cargar el espacio de nombres de pruebas:
``` clojure
=> (require 'bob-test)
nil
```

Luego llama a `run-tests` con `bob-test`:
``` clojure
=> (clojure.test/run-tests 'bob-test)

Testing bob-test

Ran 25 tests containing 25 assertions.
0 failures, 0 errors.
{:test 25, :pass 25, :fail 0, :error 0, :type :summary}
```

Para crear un script que ejecute las pruebas:

``` clojure
#!/usr/bin/env bb

(require '[clojure.test :as t]
         '[babashka.classpath :as cp])

(cp/add-classpath "src:test")                        

(require 'bob-test)                  

(def test-results
  (t/run-tests 'bob-test))           

(def failures-and-errors
  (let [{:keys [:fail :error]} test-results]
    (+ fail error)))                                 

(System/exit failures-and-errors)
```
