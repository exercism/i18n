# Introducción

## Conceptos básicos

En F#, asignar un valor a un nombre se conoce como _binding_. Los bindings son inmutables, lo que los hace similares a las constantes de otros lenguajes. Como F# es un lenguaje de tipado estático, cada binding tiene un tipo en tiempo de compilación.

Los bindings se definen con la palabra clave `let`. Especificar el tipo de un binding es opcional en la mayoría de los casos, ya que la _inferencia de tipos_ de F# normalmente puede inferir el tipo a partir de su valor. Un binding se ve así:

```fsharp
// Automatically inferred type
let fingers = 10
```

Las funciones también son bindings normales, pero con uno o más parámetros. Una función devuelve automáticamente su última expresión. La inferencia de tipos también funciona en la mayoría de las funciones, ya que analiza con qué valores se llama a la función y qué valor devuelve.

```fsharp
// Automatically inferred types for parameters and return type
let add x y = x + y
```

Para llamar a una función, escribes su nombre y pasas un argumento por cada uno de los parámetros de la función.

```fsharp
let five = add 2 3
```

Si no se puede inferir el tipo de un binding, el compilador dará un error. Para solucionarlo, agrega una anotación de tipo explícita al binding.

```fsharp
// Explicit type annotation
let fingers: int = 10

// Explicit type annotation (also for parameters)
let add (x: int) (y: int): int = x + y
```

Los bindings de F# solo se pueden usar _después_ de haberlos definido. Usar un binding antes de definirlo produce un error de compilación.

```fsharp
// Compile error as the add binding has not yet been defined
// let seven = add 3 4

let add x y = x + y
```

F# usa espacios en blanco significativos para definir el ámbito. Esto significa que el ámbito se define indentando el código con espacios, en relación con la línea que declara el binding. La convención predeterminada es usar cuatro espacios para la indentación:

```fsharp
let toes =
    let left = 5
    let right = 5
    left + right

let multiplyPlusTwo x y =
    let product = x * y
    product + 2

// Trying to access the left, right or product bindings
// here would result in a compile error
```

Los bindings de F# (que incluyen las funciones) normalmente se organizan en módulos. Un módulo agrupa funcionalidad relacionada y se define con la palabra clave `module`. La definición del módulo debe ir antes que sus bindings:

```fsharp
module Calculator

let pi = 3.14

let add x y = x + y
```

F# admite dos tipos de comentarios. Los comentarios de una sola línea van precedidos por `//`, y los comentarios de varias líneas se insertan entre `(*` y `*)`.
