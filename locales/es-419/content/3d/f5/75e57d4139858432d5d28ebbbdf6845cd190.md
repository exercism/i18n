# Introducción

Haxe admite la reflexión de tipos y campos en tiempo de ejecución. Para usar la reflexión correctamente, es necesario entender qué tipo de operaciones se admiten y cuáles no. Dada la naturaleza dinámica de la reflexión, esto no siempre se puede determinar en tiempo de compilación.

La API de reflexión consta de dos clases:

- `Reflect`: una API ligera que funciona mejor con estructuras anónimas, con soporte limitado para clases.
- `Type`: una API más robusta para trabajar con clases y enums.

Para el siguiente ejemplo, usamos el destino JavaScript:

```haxe
class Main {
  public static function main() {
    trace(Type.resolveClass("Main"));
  }
}

// This outputs
// class Test { static main() { console.log("Test.hx:3:",$hxClasses["Test"]); } }
```
