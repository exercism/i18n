# Aprendizaje

Vim ya viene con una excelente documentación integrada. La interfaz de la documentación es el comando `:help`.

Para una introducción, consulta `:h user-manual`.

Casi todas las instalaciones de Vim también incluyen un tutorial interactivo:

```
$ vimtutor
```

Vim tiene décadas de antigüedad y sigue siendo popular. Encontrarás muchos recursos sobre Vim en la web, algunos mejores que otros. Los buenos están listados [aquí](https://exercism.org/docs/tracks/vimscript/resources).
