# Instrucciones

Eres un observador de aves entusiasta que lleva la cuenta de cuántas aves han visitado tu jardín en los últimos siete días.

Tienes cinco tareas, todas relacionadas con la cantidad de aves que visitaron tu jardín.

## 1. Comprueba cuáles fueron los conteos de la semana pasada

Para poder comparar, siempre tienes cerca una copia de los conteos de la semana pasada, que fueron: 0, 2, 5, 3, 7, 8 y 4. Implementa el método `BirdCount.last_week` que devuelve los conteos de la semana pasada:

```ruby
BirdCount.last_week
# => [0, 2, 5, 3, 7, 8, 4]
```

## 2. Comprueba cuántas aves visitaron ayer

Implementa el método `BirdCount#yesterday` para que devuelva cuántas aves visitaron tu jardín ayer. Los conteos de aves están ordenados por día: el primer elemento es el conteo del día más antiguo y el último es el conteo de hoy.

```ruby
birds_per_day = [2, 5, 0, 7, 4, 1]
bird_count = BirdCount.new(birds_per_day)
bird_count.yesterday
# => 4
```

## 3. Calcula el número total de aves visitantes

Implementa el método `BirdCount#total` para que devuelva el número total de aves que han visitado tu jardín:

```ruby
birds_per_day = [2, 5, 0, 7, 4, 1]
bird_count = BirdCount.new(birds_per_day)
bird_count.total
# => 19
```

## 4. Calcula el número de días ocupados

Algunos días son más ocupados que otros. Un día ocupado es aquel en el que cinco aves o más han visitado tu jardín.
Implementa el método `BirdCount#busy_days` para que devuelva el número de días ocupados:

```ruby
birds_per_day = [2, 5, 0, 7, 4, 1]
bird_count = BirdCount.new(birds_per_day)
bird_count.busy_days
# => 2
```

## 5. Comprueba si hubo un día sin aves visitantes

Implementa el método `BirdCount#day_without_birds?` que devuelve `true` si hubo un día en el que cero aves visitaron el jardín; de lo contrario, devuelve `false`:

```ruby
birds_per_day = [2, 5, 0, 7, 4, 1]
bird_count = BirdCount.new(birds_per_day)
bird_count.day_without_birds?
# => true
```
