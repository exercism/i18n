# Introducción

Una *palabra genérica* declara una operación que puede tener distintas implementaciones según la clase de su argumento. Los métodos se agregan con `M:`.

```factor
USING: kernel math ;

GENERIC: area ( shape -- n )

TUPLE: square side ;
TUPLE: circle radius ;

M: square area side>> dup * ;
M: circle area radius>> dup * 3.14159 * ;
```

```factor
T{ square { side 4 } } area .    ! => 16
T{ circle { radius 2 } } area .  ! => 12.56636
```

`GENERIC:` declara la palabra y su efecto de pila. `M:` define un método en una clase específica. En tiempo de ejecución, Factor despacha según la clase del argumento que está en la parte superior de la pila.

Puedes preguntarle a la palabra genérica para qué clases tiene métodos, y agregar o quitar métodos después. No hay una sintaxis especial de herencia: cualquier clase de tupla es automáticamente apta para que se le definan métodos.
