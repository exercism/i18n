# Introducción a los tipos genéricos

Un **tipo genérico** es una clase o interfaz genérica que está parametrizada con tipos.
Esto permite que el compilador garantice la seguridad de tipos de la clase o la interfaz.

Fíjate en esta interfaz `Container`, que no es genérica:

```java
class Container {
    private Object object;

    public void set(Object object) { this.object = object; }
    public Object get() { return object; }
}
```

Como acepta y devuelve tipos `Object`, funciona con cualquier tipo que no sea primitivo.
Sin embargo, esto tiene un costo, porque puede que una parte del código llame a `get` esperando `Integer` mientras que otra llame a `set` agregando `String`, lo que da como resultado una excepción en tiempo de ejecución.

Una **clase genérica** y una **interfaz genérica** tienen el siguiente formato:

```java
class ClassName<T1, T2, ..., Tn> { ... }
interface InterfaceName<T1, T2, ..., Tn> { ... }
```

La sección de parámetros de tipo, delimitada por paréntesis angulares (`<>`) y ubicada después del nombre de la clase o la interfaz, especifica los parámetros de tipo (también llamados variables de tipo) `T1`, `T2`, ..., y `Tn`.
Puedes usarlos dentro del cuerpo de la clase o la interfaz para lograr la seguridad de tipos que ofrecen los genéricos.

Aquí tienes la versión genérica de `Container`:

```java
class Container<E> {
    private E object;

    public void set(E object) { this.object = object; }
    public E get() { return object; }
}
```

Ahora, al crearlo, tenemos que declarar qué tipo contiene, y el compilador se encargará de que se cumpla esa restricción:

```java
// empty <> can infer from context
Container<String> stringContainer = new Container<>();
// compiler knows this is a String, so it is allowed
stringContainer.set("Some string");
// no cast needed, compiler knows it is a String
String result = stringContainer.get();
// this causes a compiler error:
stringContainer.set(42);
```
