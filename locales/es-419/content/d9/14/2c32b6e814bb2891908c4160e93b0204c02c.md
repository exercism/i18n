# Instrucciones

Eres un mixólogo experto y preparas sabrosas bebidas para que el público las disfrute en sus salidas nocturnas.
Pero pensaste que podías hacerte la vida más fácil escribiendo un poco de código que te ayude con tu trabajo.

## 1. Determina cuánto tiempo toma preparar un pedido

Cada bebida toma una cantidad distinta de tiempo en prepararse:

- `"beer"`, `"soda"` y `"water"` toman 0.5 minutos cada una.
- Los `"shot"` toman 1.0 minutos, los `"mixed drink"` toman 1.5 minutos,
- los `"fancy drink"` toman 2.5 minutos,
- los `"frozen drink"` toman 3.0 minutos.

Implementa la función `timeToPrepare(drinks:)`, que toma el argumento `drinks`, el cual contiene un array de strings que representan las bebidas que hay que preparar.
La función debe devolver el tiempo total que tomará preparar todas las bebidas del array.

```swift
timeToPrepare(drinks: ["beer", "frozen drink", "shot"])
// returns 4.5
```

## 2. Reabastece tu suministro de gajos de lima

Una de las primeras cosas que debes hacer cuando empiezas tu turno es asegurarte de que tu pequeño recipiente de gajos de lima esté lleno para el turno que viene.
Tendrás limas de distintos tamaños que te darán distinta cantidad de gajos: puedes obtener 6 gajos de una lima "small", 8 gajos de una lima "medium" y 10 de una lima "large".

Mientras todavía necesites más gajos y todavía tengas más limas por cortar, toma la primera lima del array y resta la cantidad correspondiente de gajos a la cantidad que necesitas.
Continúa hasta que ya no necesites más gajos o se te acaben las limas.

Implementa la función `makeWedges(needed:limes:)`, que toma los argumentos `needed`, que contiene la cantidad de gajos que necesitas cortar, y `limes`, que contiene un array de strings que representan los tamaños de las limas que tienes disponibles para cortar.
La función debe devolver la cantidad de limas que cortaste.

```swift
makeWedges(needed: 25, limes: ["small", "small", "large", "medium", "small"])
// returns 4
```

## 3. Termina tu turno

¡Felicidades! Tu largo día de trabajo está por terminar y pronto irás a casa a trabajar en tu nueva app.
Pero todavía tienes una serie de pedidos de bebidas por preparar antes de poder pasarle los pedidos al siguiente turno e irte.

Mientras todavía te quede tiempo en tu turno, debes preparar el primer pedido del array y luego quitar ese pedido del array.
Luego puedes restar la cantidad de tiempo que tomó preparar ese pedido, según tu función `timeToPrepare(drinks:)`, del tiempo que te queda en tu turno.

Implementa la función `finishShift(minutesLeft:remainingOrders:)`, que recibe la cantidad de minutos que te quedan en tu turno (se garantiza que es mayor que 0) y un array no vacío de pedidos de bebidas.
La función debe devolver el array de pedidos que aún no alcanzaste a preparar antes de que terminara tu turno.

```swift
finishShift(minutesLeft: 5, remainingOrders: [["beer", "frozen drink", "shot"], ["fancy drink", "soda"], ["beer", "beer", "water"], ["mixed drink", "frozen drink"]])
// returns [["beer", "beer", "water"], ["mixed drink", "frozen drink"]]
```

## 4. Registra ciertos pedidos

Para asegurarte de que la beer y la soda se mantengan frescas, necesitas registrar sus pedidos junto con las horas a las que se hicieron esos pedidos.

Implementa la función `orderTracker(orders: [(drink: String, time: String)]) -> (beer: (first: String, last: String, total: Int)?, soda: (first: String, last: String, total: Int)?)` que, cuando recibe una lista de pedidos y horas, devuelve un par de tuplas opcionales que contienen las horas del primer y último pedido de beer y soda, junto con el número total de pedidos de cada una, y `nil` si no se hizo ningún pedido de esas bebidas. No necesitas registrar ninguna otra bebida.

Implementa la función `orderTracker(orders:)`, que recibe un array de tuplas, donde cada tupla contiene la bebida pedida y la hora a la que se hizo el pedido.
La función debe devolver una tupla que contiene la primera y la última hora a la que se pidió beer, el número total de pedidos de beer, la primera y la última hora a la que se pidió soda, y el número total de pedidos de soda.
Se debe devolver con el formato de una tupla: `(beer: (first: String, last: String, total: Int)?, soda: (first: String, last: String, total: Int)?)`.

```swift
let orders = [
    (drink: "beer", time: "10:01"), (drink: "frozen drink", time: "10:02"),
    (drink: "shot", time: "10:05"), (drink: "fancy drink", time: "10:06"),
    (drink: "soda", time: "10:09"), (drink: "beer", time: "10:15"), (drink: "beer", time: "10:22"),
    (drink: "water", time: "10:26"), (drink: "mixed drink", time: "10:28"),
    (drink: "frozen drink", time: "10:33"),
]

orderTracker(orders: orders)

// returns (beer: (first "10:01", last "10:22", total 3), soda: (first "10:09", last "10:09", total 1))
```
