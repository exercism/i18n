# Instrucciones

Lucy tiene una tienda de calcomanías en línea, donde vende lindas calcomanías con los lenguajes de programación favoritos de todos. Personas de todo el mundo compran sus calcomanías, y está teniendo algunos problemas para lidiar con todas las distintas monedas.

Crea un programa que Lucy pueda usar para calcular precios y asegurarse de que siempre esté usando la moneda correcta.

## 1. Define los tipos `Usd`, `Eur` y `Jpy`

Estos tipos se usan para representar las distintas monedas con las que los clientes de Lucy compran sus calcomanías.

Se deben usar como tipos fantasma y no necesitan tener ningún constructor.

## 2. Define el tipo `Money`.

El tipo `Money` debe tener un campo de tipo `Int` para la cantidad de dinero, un parámetro de tipo fantasma para la moneda, y debe ser un tipo opaco.

## 3. Define las funciones `dollar`, `euro` y `yen`

Define las funciones `dollar`, `euro` y `yen`, que toman un argumento de tipo `Int` y devuelven un valor de tipo `Money` con la moneda correcta.

## 4. Define la función `total`

Define la función `total`, que toma un array de valores `Money` y devuelve la cantidad total de dinero que hay en el array.

```gleam
total([euro(120), euro(200), euro(145)])
// -> euro(465)
```
