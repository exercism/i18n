# Introducción

Un vector es un array unidimensional.
Pueden contener elementos de distintos tipos.

## Creación de vectores

Los vectores se pueden crear con la función `vector` o usando su forma de lector `#()`

```lisp
(vector 1 t "foo" 'b) ; => #(1 T "foo" B)
#(2 nil "bar" a)      ; => #(2 NIL "bar" A)
```

Como son arrays, también se pueden crear con `make-array`:

```lisp
(make-array 3 :initial-element 'x)        ; => #(X X X)
(make-array 3 :initial-contents '(a b c)) ; => #(A B C)
```

## Predicado de vector

Para comprobar si un objeto es un vector, simplemente usa el predicado `vectorp`.

## Acceso a los elementos

Para acceder a los elementos de un vector usa `aref`, los índices empiezan en cero:

```lisp
(aref #(1 2 3) 1) ; => 2
(aref #(a b c) 0) ; => A
```
