# Elimina la función `main` y corrige el nombre del paquete

Elimina la función `main`, cambia el nombre del paquete de nuevo a `twofer` y ejecuta los tests.

Una función `main` se usa como punto de entrada a un programa. Exercism usa TDD ([desarrollo guiado por tests](http://testfirst.org/about#tdd)). Eso significa que el código se ejecuta al correr los tests para hacer que pasen. Para ejecutar los tests usa `go test` desde la terminal. Los tests pasarán si la funcionalidad está implementada correctamente.
