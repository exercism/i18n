# Introducción

En PHP, puedes llamar a una variable como si fuera una función si le aplicas paréntesis [`()`]. Cuando PHP intenta invocar la función, busca una función que tenga el mismo nombre que el valor de la variable.

```php
function foo(): string
{
    return "foo() invoked";
}

$func = 'foo';
$func(); // This calls foo()
```
