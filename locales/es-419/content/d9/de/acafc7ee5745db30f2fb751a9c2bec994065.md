# Introducción

## Constantes

Las constantes en Gleam son una forma de dar nombres a los valores. Se definen con la palabra clave `const`.

```gleam
pub const pi: Float = 3.14159

pub fn circle_area(radius: Float) -> Float {
  radius *. radius *. pi
}
```

Cuando se definen con la palabra clave `pub`, se puede acceder a las constantes del módulo desde otros módulos; de lo contrario, solo se puede acceder a ellas desde el módulo en el que se definen.

## Órdenes

El módulo `gleam/order` de la biblioteca estándar de Gleam contiene el tipo `Order`, que se usa para comparar valores.

La definición de `Order` se ve así:

```gleam
pub type Order {
  Gt
  Eq
  Lt
}
```

El tipo tiene tres variantes, cada una de las cuales se usa para representar la relación entre un valor y otro valor:

- `Gt`: el valor es _mayor_ que el otro valor.
- `Eq`: el valor es _igual_ al otro valor.
- `Lt`: el valor es _menor_ que el otro valor.

Si un tipo de datos se puede comparar por tamaño, es común que el módulo defina una función `compare` que devuelve un valor `Order`. Por ejemplo, `gleam/float` y `gleam/int` definen funciones `compare` que operan sobre números de punto flotante y enteros, respectivamente.

```gleam
int.compare(1, 2)
// -> Lt

int.compare(2, 2)
// -> Eq

float.compare(1.0, 2.0)
// -> Lt
```

Las funciones de ordenamiento como `list.sort` normalmente reciben una función que devuelve un valor `Order`, lo que permite que quien llama defina cómo se debe ordenar la lista.

```gleam
list.sort([3, 7, 3, 1], by: int.compare)
// -> [1, 3, 3, 7]
```
