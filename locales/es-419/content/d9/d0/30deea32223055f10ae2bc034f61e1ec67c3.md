# Introducción

## Boolean

El tipo `Bool` es uno de los bloques de construcción del lenguaje.
Su objetivo es describir si algo es verdadero o falso, con los respectivos valores `True` y `False`.

Los valores Boolean se pueden combinar con los operadores `&&` («Y») y `||` («O»), y se pueden negar con la función `not`.

Los valores Boolean también son muy útiles para crear ramas en tu código que solo se ejecuten si se cumplen ciertas condiciones.
En Elm, esto se hace con una expresión `if-then-else`, que se usa de la siguiente manera.

```elm
if someCondition || (someOtherCondition && anotherCondition) then
    doSomething
else
    doSomethingElse
```
