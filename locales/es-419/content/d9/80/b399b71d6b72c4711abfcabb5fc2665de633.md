# Pistas

## 1. Determina el número total de aves que has contado hasta ahora

- Consulta la introducción del ejercicio para ver un ejemplo de cómo usar un bucle `for` para iterar sobre un array.
- Usa una variable auxiliar para guardar el total y ve incrementando esa variable a medida que recorres el array.
- Piensa cuál es el valor inicial correcto para esa variable auxiliar.
- Vuelve al [concepto de array][concept-arrays] para repasar cómo obtener valores de un array.

## 2. Calcula el número de aves visitantes en una semana específica

- Esta tarea es similar a la primera.
  Puedes copiar tu código como punto de partida.
- Piensa qué índices del array tendrías que tener en cuenta para la semana 1 y la semana 2, respectivamente.
- Ahora, encuentra una forma general de calcular el primer y el último índice que se deben considerar.
- Con eso, puedes configurar el bucle `for` para que itere solo sobre la sección relevante del array.

## 3. Corrige un error de conteo

- De nuevo, necesitas configurar un bucle `for` para iterar sobre todo el array del recuento de aves.
- Esta vez solo necesitas visitar una de cada dos entradas del array.
- Cambia el paso para que la variable contadora se incremente en consecuencia después de cada iteración.
- En el cuerpo del bucle `for` puedes usar el operador de incremento para cambiar in situ el valor de un elemento del array.
