# Instalación

Necesitas [Vim](http://www.vim.org) para hacer los ejercicios:

- [macOS](#macos)
- [Ubuntu / Debian](#ubuntu--debian)
- [Windows](#windows)
- [Código fuente](#source)

## macOS

El sistema operativo ya viene con Vim por defecto, pero es una versión irremediablemente obsoleta.

Es probable que uses [MacPorts](https://www.macports.org) o
[Homebrew](https://brew.sh) para instalar software.

Homebrew:

```
$ brew update
$ brew install vim
```

MacPorts:

```
$ sudo port install vim +huge
```

Si quieres una interfaz gráfica, mejor echa un vistazo a [MacVim](https://macvim-dev.github.io/macvim).

## Ubuntu / Debian

Instala un Vim completo con soporte para interfaz gráfica (`gvim`):

```
$ sudo apt-get update
$ sudo apt-get install vim-gtk
```

## Windows

Usando [Chocolatey](https://chocolatey.org):

```
C:\> choco install vim
```

O descarga e instala directamente desde [aquí](http://www.vim.org/download.php#pc).

## Código fuente

Si quieres compilar la última versión de Vim por tu cuenta, echa un vistazo al [repositorio oficial en GitHub](https://github.com/vim/vim).
