# Pistas

## 1. Imprime una insignia para un empleado

- Para construir las cadenas en R base, la función [`sprintf`][ref-sprintf] es útil.
- Para un enfoque con Tidyverse, puedes usar [`str_glue`][ref-str_glue] de la librería `stringr`.

## 2. Imprime una insignia para un empleado nuevo

- Bifurca según [`is.na`][ref-isna].

## 3. Imprime una insignia para el dueño

- Bifurca según [`is.null`][ref-isnull].

## 4. Calcula el salario total de los empleados sin ID

- Puedes [filtrar][concept-vector-filtering] con [`is.na`][ref-isna] y luego usar [`sum`][ref-sum].
- ¿Qué es `salaries[is.na(ids)]` si no hay empleados sin ID? Sería útil comprobarlo en una consola de R. Si no tienes R instalado en tu computadora, las consolas en línea como [rdrr.io][web-rdrr] pueden ayudarte.
