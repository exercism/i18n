# Números de punto flotante

Los números de punto flotante se usan en PHP para representar un subconjunto de los números reales.
Empiezan con uno o más dígitos separados por un separador decimal.

```php
<?php

$a = 1.234; 
$b = 1.2e3; 
$c = 7E-10;
$d = 1_234.567; // as of PHP 7.4.0
```

## Trampas comunes

No todos los números ni todas las operaciones aritméticas se pueden realizar con números de punto flotante.
Usar números de punto flotante para representar dólares y centavos a menudo puede provocar errores de redondeo.

```php
<?php

$result = 0.1 + 0.2; // => 0.30000000000000004
```
