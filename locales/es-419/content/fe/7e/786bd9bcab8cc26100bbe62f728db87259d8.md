# Instrucciones

En este ejercicio vas a implementar una forma de llevar un registro de los puntajes más altos del juego más popular de tu salón de arcade local.

Tienes 6 funciones que implementar, relacionadas en su mayoría con la manipulación de un objeto que contiene los puntajes más altos.

## 1. Crea un nuevo tablero de puntajes altos

Escribe una función `create_score_board` que cree un objeto que sirva como tablero de puntajes altos.
Las claves de este objeto serán los nombres de los jugadores y los valores, sus puntajes.
Para fines de prueba, quieres incluir directamente una entrada en el objeto.
Esta entrada inicial debe consistir en `"The Best Ever"` como nombre del jugador y `1000000` como puntaje.

```jq
create_score_board
# returns an object with one initial entry
```

## 2. Agrega jugadores a un tablero de puntajes

Para agregar un jugador al tablero de puntajes altos, implementa la función `add_player`.
Recibe un tablero de puntajes como argumento y necesita dos parámetros: el nombre del jugador y el puntaje del jugador.
La función devuelve el objeto del tablero de puntajes con el nuevo jugador agregado.

```jq
{"José Valim", 486373}
| add_player("Dave Thomas"; 0)
# => {"Dave Thomas": 0, "José Valim": 486373} -- in some order
```

Si el jugador ya está en el tablero, devuelve el tablero sin cambios.

## 3. Elimina jugadores de un tablero de puntajes

Si un jugador viola las reglas del salón de arcade, se elimina manualmente del tablero de puntajes altos.
Implementa `remove_player`, que recibe un tablero como argumento y un parámetro: el nombre del jugador que se va a eliminar.
Esta función debe eliminar del tablero la entrada del jugador indicado y devolver el nuevo tablero.
Si el jugador no estaba en el tablero desde un principio, no debe pasarle nada al tablero; debe devolverse tal cual.

```q
{"Dave Thomas": 0} | remove_player("Dave Thomas")
# => {}

{"Dave Thomas": 0} | remove_player("Rose Fanaras")
# => {"Dave Thomas": 0}
```

## 4. Aumenta el puntaje de un jugador

Si un jugador termina otra partida en el salón de arcade, se sumará una cierta cantidad de puntos al puntaje anterior del tablero.
Implementa `update_score`, que recibe un tablero de puntajes como argumento y necesita dos parámetros: el nombre del jugador y la cantidad de puntaje que se va a sumar.
La función debe devolver el tablero de puntajes después de hacer la actualización.

```jq
{"Freyja Ćirić": 12771000} | update_score("Freyja Ćirić"; 73)
# => {"Freyja Ćirić": 12771073}
```

Esta función debe agregar al jugador al tablero si aún no estaba en él.

## 5. Aplica los puntos de bonificación de los lunes

El salón de arcade lleva un tablero de puntajes aparte los lunes.
Al final del día, cada jugador de ese tablero recibe 100 puntos adicionales.

Implementa la función `apply_monday_bonus`.
La función suma los puntos de bonificación a cada jugador que aparece en ese tablero.

```jq
{
  "Dave Thomas": 44,
  "Freyja Ćirić": 539,
  "José Valim": 265
}
| apply_monday_bonus
# => {"Dave Thomas": 144, "Freyja Ćirić": 639, "José Valim": 365}
```

## 6. Encuentra el puntaje total

Distintos salones de arcade compiten entre sí para determinar quién tiene los mejores jugadores.
El arcade con el puntaje total más alto se lleva el honor.

Escribe una función `total_score`.
Recibe un tablero de puntajes como argumento y devuelve la suma de los puntajes de todos los jugadores.

```jq
{
  "Dave Thomas": 44,
  "Freyja Ćirić": 539,
  "José Valim": 265
}
| total_score
# => 848
```
