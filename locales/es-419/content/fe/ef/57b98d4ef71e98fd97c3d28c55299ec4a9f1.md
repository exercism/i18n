# Introducción

## Variables

Recuerda que un programa de `jq` es un _pipeline de expresiones_.
La **asignación de variables** sigue esta regla: una _asignación de variable_ es una expresión que se ve así:

```jq
... | expr as $varname | ...
```

### La salida del filtro es la entrada

Al igual que la _expresión de identidad_ `.`, la salida de la _asignación de variable_ es la misma que su entrada.
Establecer el valor de la variable es un efecto secundario.

Ejemplo que muestra que `.` después de la asignación es igual que la entrada inicial:

```sh
$ jq -c -n '42 | (. * 2) as $double | [., $double]'
[42,84]
```

### Ámbito de las variables

El ámbito de la variable es «léxico»: la variable seguirá estando en el ámbito durante el resto del pipeline.
Las variables definidas en funciones (ya llegaremos a las funciones más adelante) son «locales» a la función.

### Nombres de variables

El nombre de la variable debe comenzar con `$`.
El resto del nombre de la variable es un **identificador**: comienza con una letra o un guion bajo, seguidos de letras, números o guiones bajos.

### Asignación por desestructuración

Del manual:

> Se pueden declarar varias variables con una sola expresión `as` si proporcionas un patrón que _coincida con la estructura de la entrada_ (esto se conoce como «desestructuración»).

Ejemplos:

```jq
[1, 2, 3] as [$a, $b, $c]
| [$a, $b, $c]     # => [1, 2, 3]
```

```jq
{"foo": "bar", "len": [10, 20]} as {foo: $f, len: [$h, $w]}
| [$f, $h, $w]     # => ["bar", 10, 20]
```

Hacer coincidir el nombre de la variable con la _clave del objeto_ ofrece un atajo:

```jq
{"x": 4, "y": 7} as {$x, $y}
| [$x, $y]         # => [4, 7]
```

```jq
{"foo": "bar", "len": [10, 20]} as {$foo, $len}
| [$foo, $len]     # => ["bar", [10, 20]]
```

### Constantes

Como se muestra en el ejemplo anterior, las variables son útiles para guardar constantes.
Es mejor darle un nombre a las constantes en lugar de dejar que aparezcan «números mágicos» en el código.

### Muchas veces las variables no son necesarias

A menudo es más legible omitir las variables.

Piensa en calcular el promedio de un array de números

```jq
[2, 4, 8, 7]
| add as $sum
| length as $len
| $sum / $len
```

en comparación con

```jq
[2, 4, 8, 7] | add / length
```

Esto resalta uno de los aspectos más potentes de `jq`: la entrada de un filtro se proporciona a _todas_ las subexpresiones:

- el array de entrada `[2,4,8,7]` se pasa a `add` (que suma los números aplicando el operador `+` a todos los elementos)
- _en paralelo_, `[2,4,8,7]` también se pasa a `length`
- cuando estas subexpresiones terminan, sus resultados se dividen, devolviendo el valor promedio de los números del array de entrada.

### Operadores de `jq` que necesitarás para el ejercicio de aprendizaje

#### Operador alternativo: `//`

La expresión `a // b` da como salida `b` si `a` es false o null; en caso contrario, da como salida `a`.
En el contexto de asignar una variable, esto es muy útil para proporcionar un valor predeterminado:

```jq
(.input.theAnswer // 42) as $answer | ...
```

#### Operadores aritméticos

- `+`, `-`, `*` son los operadores habituales de suma, resta y multiplicación.
