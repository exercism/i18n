# Módulo

Las comparaciones con módulo son perfectamente válidas en Crystal, pero una forma más legible de comparar el residuo de una división es con el método [`divisible_by?`][divisible_by].
Por ejemplo:

```crystal
# Rather than:
number %% 2 == 0

# Consider:
number.divisible_by?(2)
```

[divisible_by]: https://crystal-lang.org/api/latest/Int.html#divisible_by%%3F%%28num%%29%%3ABool-instance-method
