# Aprendizaje

COBOL tiene una variedad de recursos para ayudar tanto a programadores con experiencia como a principiantes, aunque algunos pueden ser poco conocidos. Por suerte, aquí tienes una recopilación de algunas fuentes populares.

## Libros

- [Beginning COBOL for Programmers][Coughlan Book]  
Este libro de Michael Coughlan cubre lo básico de escribir COBOL hasta llegar al estándar del año 2002. También incluye ejercicios para practicar programación, los cuales se completaron y se reunieron en este [repositorio de GitHub][Book Exercises].

- [Free COBOL Ebooks][Free Books]

## Documentación

- [Guía del programador de GnuCOBOL][Gnu Guide]  
Este recurso cubre los elementos del compilador GnuCOBOL y se actualiza con regularidad a medida que el compilador cambia.

## Cursos

- [Open Mainframe Project COBOL Course][Open Mainframe]  
Este curso cubre el dialecto de IBM en el entorno de VSCode que se proporciona.
