# Anexo a las instrucciones

## Implementación

Hay ocasiones en las que necesitas manejar problemas inesperados que surgen durante la ejecución del código.
En Dart, puedes usar excepciones para manejar estas situaciones.

Para lanzar una excepción en Dart, usa la palabra clave `throw` seguida de una instancia de la excepción específica que quieras lanzar.
Por ejemplo, `throw Exception()` lanza una instancia del tipo base Exception.

En este ejercicio, necesitas definir una excepción personalizada llamada `InvalidNucleotideException`.
Esta excepción debe lanzarse cuando se encuentre un nucleótido no válido.
El conjunto de pruebas solo verifica que se pase una instancia de `InvalidNucleotideException`, así que tienes la libertad de implementarla como mejor te parezca, siempre que se lance correctamente.

Para obtener más información sobre las excepciones en Dart, puedes consultar la [documentación de excepciones](https://dart.dev/language/error-handling).
Las excepciones personalizadas se pueden crear [implementando la interfaz Exception](https://dart.dev/language#interfaces-and-abstract-classes).
