# Introducción

## Listas

Una `list` en F# es una colección inmutable de cero o más valores. Los valores de una lista deben ser todos del mismo tipo. Como las listas son inmutables, una vez que se construye una lista, su valor nunca puede cambiar. Cualquier función u operador que parezca modificar una lista (por ejemplo, agregar un elemento) en realidad devolverá una lista nueva.

Las listas se pueden definir así:

```fsharp
let empty = []
let singleValue = [5]
let threeValues = ["a"; "b"; "c"]
```

La forma más común de agregar un elemento a una lista es mediante el operador `::` (cons):

```fsharp
let twoToFour = [2; 3; 4]
let oneToFour = 1 :: twoToFour
// => [1; 2; 3; 4]
```

Una lista de F# tiene una _cabeza_ (el primer elemento) y una _cola_ (todo lo que sigue después del primer elemento). La cola de una lista es en sí misma una lista.

Las listas se manipulan con las funciones y los operadores definidos en el módulo `List`, o manualmente mediante la coincidencia de patrones usando los patrones _list_ y _cons_:

```fsharp
let describe list =
    match list with
    | [] -> "Empty list"
    | head::tail -> sprintf "Non-empty list with head: %d" head

describe []        // => "Empty list"
describe [1]       // => "Non-empty with head: 1"
describe [5; 7; 9] // => "Non-empty with head: 5"
```

También puedes _descartar_ un valor cuando usas la coincidencia de patrones; cuando _no_ te importa un valor en un caso específico (es decir, no vas a _usar_ ese valor), puedes usar un guion bajo (`'_'`) para indicarlo:

```fsharp
let describe list =
    match list with
    | [] -> "Empty list"
    | [x] -> "List with one item"
    | [_; y] -> "List with two items (first item ignored)"
    | _ -> "List with many items (all items ignored)"

describe []        // => "Empty list"
describe [1]       // => "List with one item"
describe [5; 7]     // => "List with two items (first item ignored)"
describe [5; 7; 9] // => "List with many items (all items ignored)"
```

Ese único `'_'` siempre debe ir al _final_ cuando usas la coincidencia de patrones; todos los valores que _no_ coincidan con ninguno de los otros casos se manejarán con este caso.
