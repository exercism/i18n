# Acerca de

Las listas en C# son colecciones de valores primitivos o de instancias de structs o clases. Se implementan en la biblioteca de clases base como [`List<T>`][lists-docs], donde `T` es el tipo del elemento de la lista. La API expone un amplio conjunto de métodos para crear y manipular listas.

```csharp
var listOfStrings = new List<string>();
var listOfIntegers = new List<int>();
var listOfRandoms = new List<Random>();
var listOfBigIntegers = new List<BigInteger>();
```

La definición de una colección normalmente incluye un marcador de posición entre paréntesis angulares, a menudo `T` por convención. Esto permite que quien usa la colección especifique qué tipo de elementos se guardan en ella.

A diferencia de [concept:csharp/arrays](), las listas pueden cambiar de tamaño de forma dinámica.

## LINQ

Aunque la API integrada de `List<T>` es amplia (incluye mapeos y filtros como `ConvertAll`, `FindAll` y `Foreach`) y su [sintaxis de bucle][for-each] es muy clara, y sin duda necesitas familiarizarte con esta API, Language Integrated Query ([LINQ][linq]) está disponible para muchas tareas, es aún más potente y ampliamente usado, y tiene la ventaja de ofrecer una interfaz consistente entre colecciones de bibliotecas, colecciones de terceros y tus propias clases.
