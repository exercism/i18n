# Juego de tipos

El juego de tipos también se conoce como coerción de tipos.
El juego de tipos ocurre cuando dos valores de tipos distintos se convierten al mismo tipo para poder realizar una operación.

```php
$baskets = 5 // int
$apples_per_basket = "3" // string
$baskets * $apples_per_basket
# => 15 // int
```

Cuando se evalúa la expresión, el valor de tipo string se convierte implícitamente a un `int` para cumplir con lo que espera el operador `*`.
La decisión sobre a qué tipo convertir el valor la toma PHP según las reglas de la operación, y estas reglas varían mucho.

La coerción de tipos también ocurre al llamar a funciones y métodos:

```php
strlen(12321);
# => 5
```

## Conversión de tipos

En lugar de depender de la coerción implícita, podemos forzar explícitamente que un valor se evalúe como un tipo determinado usando la conversión de tipos al estilo de `C`:

```php
$apples_per_basket = "3" // string
$my_number = (int) $apples_per_basket // cast string to int
# => 3 // int
```

Esto convierte el valor al tipo que se especifica entre paréntesis `(...)`.
Todos los tipos primitivos se pueden usar como tipo de destino: `bool`, `int`, `float`, `string`, `array`, `object`.

## La conversión es solo temporal

El juego de tipos o la conversión **no cambian** el tipo del valor almacenado en una variable.
Solo se convierte el argumento que entra en la operación.

```php
$apples_per_basket = "3" // string
5 * $apples_per_basket
# $apples_per_basket => "3" // string

$my_number = (int) $apples_per_basket // cast string to int
# $apples_per_basket => "3" // string
```

## Pérdida de información

Cuando un valor se convierte a otro tipo, puede haber pérdida de información en el proceso:

```php
$exact_distance = 15.5
$rough_distance = (int) $exact_distance
// => 15

$is_distant = (bool) $exact_distance
// => true

$erroneous_distance = (float) $is_distant
// => 1.0
```

Depender de la conversión de tipos, ya sea explícita o implícita, puede producir errores en un sistema más grande.

## Conversión explícita de tipos a `array` y `object`

Los valores también se pueden convertir a los tipos `array` y `object`.
Si un valor que no es un array ni un objeto se convierte a `array`, se transforma en un único elemento dentro de un array:

```php
$day_of_the_week = 'Monday';
(array) $day_of_the_week
// => array(1) {
//      [0]=>
//        string(6) "Monday"
//    }
```

Cuando se convierte a `object`, el valor se asigna a una propiedad pública llamada `scalar`:

```php
$car = "Honda"
(object) $car
// => object(stdClass)#1 (1) {
//      ["scalar"]=>
//        string(5) "Honda"
//    }
```

> `stdClass` es el tipo de una clase anónima que viene integrada en PHP.
