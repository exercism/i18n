# Clases inmutables

Un `SCOREBOARD` es una cosa que cambia. Dos nombres para un mismo marcador ven el mismo puntaje, porque hay un solo marcador y ambos nombres apuntan a él.

Un rumbo no es así. `350 degrees` no se convierte en otra cosa; simplemente *es*. Los números se comportan así, y los strings también. Y las clases que tú mismo escribas también pueden.

## inmutable

```sather
immutable class BEARING is

   readonly attr degrees : INT;

end; -- class BEARING
```

Dos palabras lo cambian todo. Un objeto de una clase inmutable es un **valor**, no una cosa a la que se apunta:

- se copia cuando se asigna o se pasa, así que nadie más puede cambiar el tuyo;
- nunca puede quedar vacío;
- y no se puede asignar a sus atributos.

## Cambiar uno creando otro

Como `degrees := 90` no está permitido, `attr` ofrece otra cosa: una rutina que toma el nuevo valor y responde con **un objeto nuevo** que lo tiene cambiado.

```sather
   b ::= b.degrees(90);      -- not b.degrees := 90
```

El original queda intacto. Esa es toda la idea, y así es como se escribe `create`:

```sather
   create(d : INT) : SAME is
      b : SAME;                     -- starts with everything at nought
      return b.degrees(d);
   end;
```

Aquí no hay `new`. Un objeto inmutable siempre existe, así que `b : SAME` ya es uno, con cada atributo en su valor vacío.

Una rutina que «cambia» un rumbo, por lo tanto, devuelve uno nuevo:

```sather
   turned(by : INT) : SAME is
      return #BEARING(degrees + by);
   end;
```

## Comparar

Los valores se comparan por lo que contienen, no por cuál objeto son, pero tienes que decir cómo. Escribe `is_eq`, y `=` lo usará:

```sather
   is_eq(other : SAME) : BOOL is
      return degrees = other.degrees;
   end;
```

Sin él, `=` en dos rumbos no compilará.

## Cuál elegir

Usa una clase inmutable cuando la cosa no tiene identidad y nada en ella puede cambiar de forma razonable: un rumbo, un punto, una fecha, una longitud. Usa una clase común cuando la cosa es una cosa particular a la que le pasan cosas: un marcador, un arnés, un archivo.

La prueba es si «el mismo» significa «igual» o «exactamente el mismo».
