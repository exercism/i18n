# Apéndice de instrucciones

## Implementación

Tu función recibirá un array de strings.
Cada string representa una mano compuesta por 5 cartas separadas por espacios.
Una carta se representa con un número y su palo.

Debes devolver un array que contenga la mejor mano o, en caso de empate, las mejores manos.
Cada mano debe ser un string con el mismo formato en que se te dio inicialmente como argumento.
