# Pistas

## 1. Imprime una insignia para un empleado

- Puedes usar una [plantilla de string][string-template] para crear strings de descripción.
- Hay un [método integrado para convertir un string a mayúsculas][to-upper-case].

## 2. Imprime una insignia para un empleado nuevo

- Debes verificar si el ID es `null` antes de usarlo.
- Puedes usar un [operador de igualdad][kotlin-operators] para verificar si un valor es `null`.

## 3. Imprime una insignia para el dueño

- Puedes usar el [operador Elvis][elvis-operator] para usar un valor alternativo cuando una variable es `null`.
