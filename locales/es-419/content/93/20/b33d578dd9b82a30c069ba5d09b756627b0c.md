# Instalación

Para instalar Julia en tu sistema, sigue las instrucciones de la [página de descargas del lenguaje Julia](https://julialang.org/downloads/).

~~~~exercism/caution
No se recomienda instalar Julia a través del gestor de paquetes de tu sistema operativo. Esos paquetes no tienen mantenimiento oficial y pueden causar problemas.
~~~~

Para una instalación local, hay plugins disponibles para una gran cantidad de editores/IDE. La [extensión de VS Code](https://github.com/julia-vscode/julia-vscode) es la más popular. Puedes encontrar integraciones para otros editores en la organización [JuliaEditorSupport](https://github.com/JuliaEditorSupport) en GitHub.

Si prefieres un entorno más interactivo, puedes usar notebooks de Jupyter con [IJulia](https://github.com/JuliaLang/IJulia.jl), o usar [Pluto.jl](https://github.com/fonsp/Pluto.jl) para notebooks reactivos simples en Julia.

Una forma sencilla de empezar con Julia sin necesidad de una instalación local es [Nextjournal](https://nextjournal.com/), un IDE en línea basado en notebooks. Puedes acceder a él desde tu navegador, iniciar sesión y empezar a resolver ejercicios. Si solo quieres un REPL en línea, puedes usar [Repl.it](https://repl.it/languages/julia).
