# Introducción

## Funciones callback

Las funciones callback son funciones que se pasan como argumentos. Este patrón de programación crea una secuencia de llamadas a funciones tanto en la programación síncrona como en la asíncrona. Escribir una función callback no es diferente de escribir una función; sin embargo, la función callback debe coincidir con la firma que define la función que la llama.

```javascript
const sideLength = 5;

// Caller function takes a callback function
function applySideLength(callback) {
  return callback(sideLength);
}

// Callback must expect the possible argument from the calling function
function areaOfSquare(side) {
  return side * side;
}

applySideLength(areaOfSquare); // => 25
```

También puedes escribir los callbacks como una expresión de función:

```javascript
applySideLength(function squarePerimeterLength(side) {
  return side * 4;
});
```
