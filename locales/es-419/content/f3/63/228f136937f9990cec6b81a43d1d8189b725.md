# Instrucciones

En este ejercicio, vas a implementar el manejo de errores para una calculadora sencilla de números enteros.
La calculadora debe admitir las operaciones de suma, multiplicación y división, y devolver el resultado como una cadena con formato.
También vas a implementar el manejo de errores para cubrir las operaciones ilegales y la división entre cero.

El objetivo es tener una calculadora que funcione y que devuelva una cadena con el siguiente formato:

```rust
SimpleCalculator::calculate(16, 51, "+"); // => returns "16 + 51 = 67"

SimpleCalculator::calculate(32, 6, "*"); // => returns "32 * 6 = 192"

SimpleCalculator::calculate(512, 4, "/"); // => returns "512 / 4 = 128"
```

## 1. Implementa las operaciones de la calculadora

La función principal de esta tarea será `SimpleCalculator::calculate`, que recibe tres argumentos: dos números enteros y un `ByteArray` que representa la operación.
Implementa las siguientes operaciones:

- **Suma** con el símbolo `+`
- **Multiplicación** con el símbolo `*`
- **División** con el símbolo `/`

## 2. Maneja las operaciones ilegales

Si el símbolo de la operación es cualquier cosa distinta de `+`, `*` o `/`, la calculadora debe entrar en pánico o devolver un error:

- Si la operación es una cadena vacía, entra en pánico con un mensaje de error de tipo `ByteArray`: `"Operation cannot be an empty string"`.
- Para cualquier otra operación no válida, devuelve `Result::Err("Operation is out of range")`.

```rust
SimpleCalculator::calculate(100, 10, "-"); // => returns Result::Err("Operation is out of range")

SimpleCalculator::calculate(8, 2, ""); // => panics with "Operation cannot be an empty string"
```

## 3. Maneja los errores cuando se divide entre cero

Cuando se intenta dividir entre `0`, la calculadora debe entrar en pánico con un mensaje de error que indique que la división entre cero no está permitida.
El resultado devuelto debe ser un valor `felt252` igual a `'Division by zero is not allowed'`.

```rust
SimpleCalculator::calculate(512, 0, "/"); // => panics with 'Division by zero is not allowed'
```
