# Acerca de

Una [`function`][function] es un bloque de código organizado y reutilizable que se usa para realizar una tarea específica.
`Functions` brindan mejor modularidad para tu aplicación y un alto grado de reutilización de código.
Python, como otros lenguajes de programación, tiene [_funciones incorporadas_][built-in functions] ([`print`][print], [`map`][map], y así sucesivamente) que están disponibles de inmediato.
También puedes definir tus propias funciones. A esas se las llama [`user-defined functions`][user defined functions].
Las funciones pueden ejecutar algo tan simple como _imprimir un mensaje en la consola_, o pueden ser bastante complejas.

Para ejecutar el código dentro de una función, necesitas llamar a la función, lo cual se hace escribiendo el nombre de la función seguido de paréntesis [`()`].
Los datos, conocidos como [`arguments`][arguments], se pueden pasar a la función colocándolos dentro de los paréntesis.
Una definición de función puede incluir cero o más [`parameters`][parameters].
Los parámetros definen qué argumento(s) acepta la función.
Un parámetro define qué _tipo_ de argumento se va a pasar.
El argumento es el _valor_ real que se pasa cuando se llama a la función.
Las funciones pueden realizar distintas tareas según los argumentos que se pasen a los parámetros.

Una función también puede devolver un valor usando la palabra clave [`return`][return].
El valor que devuelve la función se conoce como el `return value`.
El valor devuelto se entrega a quien llamó a la función.

## Creación

En Python, las funciones se crean con la palabra clave [`def`][def].
A la definición de la función le siguen el nombre de la función y unos paréntesis [`()`].
Dentro de los paréntesis se especifican los parámetros, separados por comas.
Después del paréntesis de cierre, se usan los dos puntos (`:`) para separar la firma de la función del cuerpo de la función.

El cuerpo de la función es un bloque de código que se ejecuta cuando se llama a la función.
El cuerpo de la función va con sangría.
La sangría es importante porque Python se apoya en ella para saber dónde termina ese bloque de código.
Se puede devolver un valor desde la función usando la palabra clave `return`, que luego puede usar quien llamó a la función.

```python
def function_name(parameter1, parameter2, ...):
    # function body
    return parameter1 + parameter2

```

También podemos definir una función sin parámetros ni valor devuelto.

```python
def function_name():
    # function body
    pass

```

Fíjate que la función sí necesita un cuerpo, incluso si el cuerpo no hace nada; de lo contrario, intentar ejecutar el programa generará un error de sangría:

```python
>>> def my_bodyless_func():
...      

File ~/temp.py:1
    
    ^
IndentationError: expected an indented block
```

## Llamar a una función

Para llamar a una función, usa el nombre de la función seguido de paréntesis [`()`].
Los parámetros que se pasan a la función se colocan dentro de los paréntesis, separados por comas.

Considera la siguiente función:

```python
def greet():
    print("Hello")

```

La función anterior se puede llamar con la siguiente sintaxis:

```python
>>> greet()
Hello
```

## Parámetros y sus argumentos

Los argumentos son valores que se pasan a la función cuando se la llama.
Pueden ser de cualquier tipo de dato, incluidas otras funciones o clases.

Definamos una función `add` que suma dos números:

```python
def add(first, second):
    print(first + second)

```

Los parámetros `first` y `second` definen qué argumentos aceptará la función `add`.
(Cabe señalar que las palabras `parameter` y `argument` suelen usarse como sinónimos, aunque de forma imprecisa).
Cuando se llama a la función, los argumentos se pasan a la función.
Debemos pasar argumentos para ambos parámetros; de lo contrario, se lanzará un [`TypeError`][type-error].

```python
>>> add(2, 3)
5

# Function can be called multiple times, with different parameters
>>> add(4, 3)
7
>>> add(5, 6)
11

# Passing an incorrect number of parameters will raise a `TypeError`
>>> add(2)
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
TypeError: add() missing 1 required positional argument: 'second'

>>> add(2, 3, 4)
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
TypeError: add() takes 2 positional arguments but 3 were given
```

## Valor devuelto

El valor devuelto es un valor que se entrega a quien llamó a la función.
Un `return value` puede ser de cualquier tipo de dato, incluidas otras funciones o clases.
Quien llamó a la función puede usarlo para realizar más operaciones.
Si una función no define explícitamente un `return value`, el intérprete de Python devolverá el valor `None`.

Definamos una función `add`:

```python
def add(first, second):
    return first + second

```

Podemos guardar el valor devuelto en una variable y luego imprimirlo:

```python
>>> result = add(2, 3)
>>> print(result)
5
# Type of result is `int`
>>> type(result)
<class 'int'>

# We can also perform operations on the return value
>>> result * 2
10

# A function without an explicit return value will return `None`
>>> def log(message):
    print(message)

# Hello is printed because of print(message), but return value is `None`
>>> return_value = log("Hello")
Hello
>>> return_value
None
```

Usar `return` sale de la función de inmediato y devuelve el valor a quien la llamó.

```python
>>> def show(first, second):
    print(first)
    return first
    print(second)

# second never gets printed, because the function exits after the return statement
>>> show(1, 2)
1
```

## Modularidad

Los programas complejos se pueden dividir en partes más pequeñas.
Se pueden usar distintas funciones para realizar distintas tareas específicas.

Supongamos que un programa tiene que realizar las siguientes tareas:

* Calcular el área de un círculo
* Calcular el área de un rectángulo
* Calcular el área de un triángulo

Podemos dividir el programa en partes más pequeñas.

```python
def circle_area(radius):
    return 3.14 * radius * radius

def rectangle_area(length, breadth):
    return length * breadth

def triangle_area(base, height):
    return 0.5 * base * height

```

Ahora podemos llamar a las funciones en el orden que queramos.

```python
>>> circle_area(2)
12.56
>>> triangle_area(2, 3)
3.0
>>> rectangle_area(2, 3)
6
>>> rectangle_area(1, 2) + circle_area(2) + triangle_area(1, 2)
15.56
```

## Ámbito de las variables

Si una variable (_o nombre_) se define dentro de una función, solo será accesible _dentro_ del ámbito de la función (_o espacio de nombres local_), incluso si hay una variable con el mismo nombre fuera del ámbito de la función.

Las variables definidas fuera de una función, a _nivel de módulo_, se consideran dentro del _espacio de nombres global_.
Las variables definidas fuera de una función pero _dentro_ de una función o clase envolvente están en el _espacio de nombres no local_.


Python usa la [regla LEGB][LEGB Rule] (**L**ocal, **E**nclosing, **G**lobal, **B**uilt-in) para resolver los nombres de las variables mientras se ejecuta un programa:

1. Busca en el espacio de nombres **local** (o _de la función_).
2. Busca en el espacio de nombres **envolvente** (o _no local_) si un nombre no se encuentra en el local.
3. Busca en el espacio de nombres **global** (_nivel de módulo_) si el nombre no se encuentra en el no local o envolvente.
4. Busca en el espacio de nombres **incorporado** (_del programa o de todo Python_) si el nombre no se encuentra en el global.

Si el nombre sigue sin resolverse, Python lanzará una `NameError exception`.

```python
# Global namespace.
general_favorite = "apples"


def alices_favorite():
   # Local namespace.  
   favorite = "cherries"
   
   # This works because Python will eventually find general_favorite in the global namespace.
   # Python will find 'print' in the built-in namespace.
   print(f'Alice has always liked {favorite}, but most people like {general_favorite}.')

   
def our_favorite_fruits():
    # Enclosing or nonlocal namespace.
    yours = "peaches"
    
    def my_favorite():
        # Local namespace.
        mine = "pears"
        
        # This works because Python will eventually find 'yours' in the enclosing/nonlocal namespace.
        print(f'My favorite is {mine}, but you like {yours} instead.')
        
        # This works because Python will eventually find 'general_favorite' in the global namespace.
        print(f'Everyone seems to like {general_favorite}')
    
    # This function is in the local namespace of the 'our_favorite_fruits' function.  
    my_favorite()

    
# This will raise NameError: name 'favorite' is not defined, because the variable favorite is local to alices_favorite.
print(favorite)

```

Si queremos que el nombre de una variable sea accesible _fuera_ del ámbito local de la función (_o modificar una variable que se definió fuera del ámbito de la función_), debemos usar la palabra clave [`global`][global] o [`nonlocal`][nonlocal].

Usar la palabra clave `global` le indica a Python que empiece la búsqueda en el _espacio de nombres global_.
Entonces las asignaciones a la variable modificarán la variable _global_, en lugar de crear una versión _local_.
Cuando se usa `global` para declarar una variable, la variable se _agrega_ al espacio de nombres global.
Por eso, `global` debe usarse con precaución, ya que agregar o modificar una variable global podría afectar a todo el demás código que use su valor.

La palabra clave `nonlocal` le indica a Python que busque o cree la variable en el _espacio de nombres no local o envolvente_.
Se usa cuando una función está anidada dentro de otra función o clase y necesita acceso a las variables y al ámbito de la función externa.


## Las funciones como objetos de primera clase

En Python, las funciones se pueden asignar a variables y pasar como argumentos a otras funciones.
Se pueden usar como valores devueltos.
Las funciones también se pueden colocar en una secuencia ([`list`][list], [`tuple`][tuple], etc.) o como valor en un [`dict`][dict].
Las funciones se pueden usar en cualquier lugar donde se pueda usar cualquier otro objeto.
Esto se debe a que _las funciones son [_objetos de primera clase_][first class objects]_.
Por eso llevan atributos especiales e incluso pueden definir la obtención y la asignación de sus propios atributos personalizados.

```python
# print is a function

# A function can be assigned to a variable.
>>> function_as_variable = print
>>> function_as_variable("Hello")
Hello
>>> type(fake_print)
<class 'builtin_function_or_method'>

# Functions can be passed as an argument to another function.
>>> def check_print(func):
    func("Hello")
>>> check_print(print)
Hello

# Function can be used as an item in a sequence.
>>> my_list = [print, "Hello"]
>>> my_list[0]("Hello")
Hello

# Functions can be used as a value in a dictionary.
>>> my_dict = {"key": print}
>>> my_dict["key"]("Hello")
Hello

# Functions can be returned from a function.
>>> def return_func():
    return print
>>> return_func()("Hello")
Hello
```

Las funciones también se pueden anidar dentro de otras funciones.

```python
def outer():
    num = 10
    
    # This is a nested, or "inner" function.
    def inner():
        print(num)
    
    # Outer function calling inner function
    inner()
```

La función interna puede acceder a la variable `num` definida en la función externa.

```python
>>> outer()
10
```


## Atributos especiales

Las funciones en Python tienen atributos especiales. Algunos de ellos son:

* `__name__`: Nombre de la función
* `__doc__`: string de documentación de la función
* `__module__`: Módulo en el que se define la función
* `__globals__`: Diccionario de variables globales en la función
* `__code__`: Objeto de código que contiene las instrucciones de la función

```python
>>> def add(first, second):
      return first + second

# Function name
>>> print.__name__
'print'
>>> len.__name__
'len'
>>> add.__name__
'add'

# Function documentation
>>> abs.__doc__
'Return the absolute value of the argument.'

# Module
>>> len.__module__
'builtins'
>>> add.__module__
'__main__'
```

La lista completa de atributos de las funciones se encuentra en [el modelo de datos de Python][attributes].
