# Introducción

## Binarios

Elixir ofrece una sintaxis elegante para trabajar con datos binarios, como hemos visto con la forma especial `<<>>` que se proporciona para trabajar con [cadenas de bits][exercism-bitstrings].

El tipo binario es una especialización del tipo cadena de bits. Mientras que las cadenas de bits pueden tener cualquier longitud (cualquier cantidad de [bits][wiki-bit]), los binarios son aquellos en los que la cantidad de bits es divisible por 8. Es decir, cuando trabajamos con binarios, a menudo pensamos en términos de [bytes][wiki-byte] (8 bits). Un byte puede representar números enteros desde `0` hasta `255`. Es común trabajar con valores de byte en [hexadecimal][wiki-hexadecimal], `0x00 - 0xFF`.

Los literales binarios se definen usando la forma especial de cadena de bits `<<>>`. Al definir un literal binario, podemos usar literales de enteros y de string. Los valores enteros mayores que 255 se desbordarán y solo se usarán los últimos 8 bits del entero. De forma predeterminada, el modificador `::binary` se aplica al valor. Podemos concatenar binarios con el operador `<>/2`.

```elixir
<<255>> == <<0xFF>>
# Overflowing bits are truncated
<<256>> == <<0>>
<<2, 4, 6, 8, 10, 12, 14, 16>> == <<0x02, 0x04, 0x06, 0x08, 0x0A, 0x0C, 0x0E, 0x10>>
```

Un _byte nulo_ es otro nombre para `<<0>>`.

### Coincidencia de patrones en datos binarios

La [coincidencia de patrones][exercism-pattern-matching] se extiende incluso a los binarios, y podemos aplicar coincidencia de patrones a una porción de datos binarios, tal como haríamos con una lista.

```elixir
# Ignore the first 8 bytes, match and bind the remaining to `body`
<<_::binary-size(8), body::binary>>
```

Al igual que con otros tipos de coincidencia de patrones, podemos usar esto en las firmas de funciones para hacer coincidir al seleccionar entre múltiples cláusulas de función.
