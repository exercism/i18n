# Pistas

## 1. Crea una lista vacía

Crear una lista vacía es igual que crear una lista con elementos. Puedes hacerlo con `list` o con `quote` sobre una lista vacía.

## 2. Agrega un lenguaje nuevo a la lista

Clojure tiene una función del núcleo que puede [anteponer un elemento a una lista](https://clojuredocs.org/clojure.core/cons).

## 3. Comprueba el último lenguaje agregado

Como otros Lisps, Clojure tiene una función que [devuelve el primer elemento de una lista](https://clojuredocs.org/clojure.core/first).

## 4. Elimina el primer lenguaje de la lista

De manera similar, Clojure también tiene una función para [devolver una lista con el primer elemento eliminado](https://clojuredocs.org/clojure.core/rest).

## 5. Cuenta los lenguajes que hay en la lista

La [cantidad de elementos](https://clojuredocs.org/clojure.core/count) de una lista se puede obtener fácilmente con una función del núcleo de Clojure.

## 6. Únelo todo

Recuerda que las llamadas a funciones se pueden anidar.
