# Instrucciones

En este ejercicio vas a procesar líneas de log.

Cada línea de log es una cadena con el siguiente formato: «[<LEVEL>]: <MESSAGE>*».

## 1. Obtén el mensaje de una línea de log

Implementa la función `LogLevels.message()` para devolver el mensaje de una línea de log, quitando los espacios en blanco al principio y al final.

## 2. Obtén el nivel de log de una línea de log

Implementa la función `LogLevels.logLevel()` para devolver el nivel de log de una línea de log en minúsculas.

## 3. Reformatea una línea de log

Implementa el método `LogLevels.reformat()`, que recibe una línea de log y una cadena de ubicación, y la reformatea en un mensaje que contiene dos líneas.
La primera línea tiene el formato `<LEVEL>@<LOCATIOON>:`, donde:

* `<LEVEL>` es el nivel de log en minúsculas (como en 2. Obtén el nivel de log de una línea de log).
* `<LOCATION>` es la ubicación dada como segundo parámetro.

La segunda línea contiene exactamente dos espacios, seguidos del mensaje de log (como en 1. Obtén el mensaje de una línea de log):

```kotlin
reformat("[TRACE]: Start of function", 2, 8)
// => "trace@208:
  Start of function"
```
