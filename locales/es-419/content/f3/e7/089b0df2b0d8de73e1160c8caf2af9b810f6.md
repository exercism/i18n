# Instrucciones

Tu amigo acaba de enviarte un mensaje con un secreto importante.
Como no quería que fuera fácil para otros leerlo, el mensaje se cifró realizando una serie de manipulaciones de bits.
Deberás escribir los métodos que ayuden a descifrar el mensaje.

## 1. Desplaza los bits de vuelta

El primer paso para descifrar el mensaje es deshacer el desplazamiento del proceso de cifrado desplazando los bits de vuelta hacia la derecha.
Habrá más pasos en el proceso de descifrado que asumen que se insertan 0s desde el lado izquierdo.

Implementa el método `Secrets.shiftBack` que recibe un valor y el número de posiciones a desplazar y realiza el desplazamiento.

```java
Secrets.shiftBack(0b1001, 2);
# => 0b0010
```

## 2. Establece algunos bits

Ahora, hay algunos bits que hay que establecer en 1.

Implementa el método `Secrets.setBits` que recibe un valor y una máscara y devuelve el resultado de establecer en 1 los bits del valor.
Un bit del valor debe establecerse en 1 donde el bit de la máscara también sea 1.
Todos los demás bits deben mantenerse sin cambios.

```java
Secrets.setBits(0b0110, 0b0101);
# => 0b0111
```

## 3. Invierte bits específicos

Algunos bits se invierten durante el cifrado.
Habrá que invertirlos de vuelta para descifrar el mensaje.

Implementa el método `Secrets.flipBits` que recibe un valor y la máscara.
La máscara indica qué bits del valor hay que invertir.
Si el bit es 1 en la máscara, el bit se invierte en el valor.
Todos los demás bits se mantienen sin cambios.

```java
Secrets.flipBits(0b1100, 0b0101);
# => 0b1001
```

## 4. Borra bits específicos

Por último, también hay ciertos bits que siempre se descifran como 0.

Implementa el método `Secrets.clearBits` que recibe un valor y una máscara.
Los bits del `value` deben establecerse en 0 donde el bit de la máscara sea 1.
Todos los demás bits deben mantenerse sin cambios.

```java
Secrets.clearBits(0b0110, 0b0101);
# => 0b0010
```
