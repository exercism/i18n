# Instrucciones

En este ejercicio, tienes la tarea de escribir el software de un dispositivo de cifrado que funciona realizando transformaciones sobre los datos. Necesitas una forma flexible de crear funciones complicadas combinando funciones más simples.

Para cada tarea, devuelve una función anónima que se pueda invocar desde el ámbito desde el que se llama.

## 1. Crea un sumador

Implementa `secret_add`. Debe devolver una función que recibe un argumento y le suma el argumento que se pasó a `secret_add`.

```gleam
let adder = secret_add(2)
adder(2)
// -> 4
```

## 2. Crea un restador

Implementa `secret_subtract`. Debe devolver una función que recibe un argumento y le resta el secreto que se pasó a `secret_subtract`.

```gleam
let subtractor = secret_subtract(2)
subtractor(3)
// -> 1
```

## 3. Crea un multiplicador

Implementa `secret_multiply`. Debe devolver una función que recibe un argumento y lo multiplica por el secreto que se pasó a `secret_multiply`.

```gleam
let multiplier = secret_multiply(7)
multiplier(3)
// -> 21
```

## 4. Crea un divisor

Implementa `secret_divide`. Debe devolver una función que recibe un argumento y lo divide entre el secreto que se pasó a `secret_divide`.

```gleam
let divider = secret_divide(3)
divider(32)
// -> 10
```

## 5. Crea un combinador de funciones

Implementa `secret_combine`. Debe devolver una función que recibe un argumento y le aplica, en orden, las dos funciones que se pasaron a `secret_combine`.

```gleam
let multiply = secret_multiply(7)
let divide = secret_divide(3)
let combined = secret_combine(multiply, divide)

combined(6)
// -> 14
```
