# de prueba

## La opción `--argjson`

Las pruebas usan la opción `--argjson n 1` de `jq`.
Esto crea una variable jq llamada `$n` que contiene el valor de tipo _**número**_ `1`.

Compara esto con la opción `--arg n 1`,
que crea una variable jq llamada `$n` que contiene el valor de tipo _**string**_ `"1"`.

En tu solución, usa `$n` como argumento para obtener el n-ésimo número primo.

Consulta [Invocar jq][man-invoke] en el manual.

[man-invoke]: https://jqlang.org/manual/#invoking-jq
