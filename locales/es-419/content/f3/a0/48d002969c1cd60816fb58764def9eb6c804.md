# Instructions

Karl quiere llevar un registro de una lista de lenguajes que quiere aprender en el sitio web de Exercism.
Karl necesita poder agregar lenguajes nuevos, eliminar los antiguos y comprobar si ciertos lenguajes están en la lista.
¡Sería muy emocionante si Karl quiere aprender Java o Kotlin!

## 1. Define una función para comprobar si la lista de lenguajes está vacía

Karl necesita saber si en algún momento su lista de lenguajes queda vacía, para poder ir a buscar más que aprender.
Define un método llamado `isEmpty` que devuelve `true` si no hay lenguajes en la lista.

```java
if (languageList.isEmpty()) {
    findMoreLanguagesToLearn();
}
```

## 2. Define una función para agregar un lenguaje a la lista

¡Karl está ansioso por aprender Kotlin y Python!
Ayuda a Karl a empezar definiendo un método llamado `addLanguage` que recibe el lenguaje que quiere aprender y lo agrega a la lista.

```java
languageList.addLanguage("Kotlin");
languageList.addLanguage("Python");
```

## 3. Define una función para eliminar un lenguaje de la lista

Karl decidió que por ahora no quiere aprender Scala.
Ayuda a Karl a eliminarlo de la lista definiendo un método llamado `removeLanguage` que recibe el lenguaje que va a eliminar y lo quita de la lista.

```java
languageList.removeLanguage("Scala");
```

## 4. Define una función para devolver el primer elemento de la lista

Karl quiere recordar el primer lenguaje que agregó a la lista (que todavía sigue en la lista).
Define un método llamado `firstLanguage` que devuelve el primer lenguaje de la lista.

```java
String kotlin = languageList.firstLanguage(); // "Kotlin"
```

## 5. Define una función que devuelva cuántos lenguajes hay en la lista

Karl necesita saber cuántos lenguajes está intentando aprender.
Ayuda a Karl a encontrar la respuesta definiendo un método llamado `count` que devuelve la cantidad de lenguajes en la lista.

```java
int two = languageList.count(); // 2
```

## 6. Define una función para determinar si un lenguaje está en la lista

Karl está tratando de recordar si quería aprender Python o Ruby.
Define un método llamado `containsLanguage` que recibe el lenguaje por el que pregunta, ¡para que Karl pueda averiguarlo!

```java
boolean learningPython = languageList.containsLanguage("Python"); // true
boolean learningRuby = languageList.containsLanguage("Ruby"); // false
```

## 7. Define una función para determinar si la lista es emocionante

¡Si Karl quiere aprender Java o Kotlin, eso es muy emocionante!
Define un método llamado `isExciting` que devuelve true si Karl quiere aprender Java o Kotlin.

```java
javaLanguageList.isExciting() // true
neitherKotlinNorJavaLanguageList.isExciting() // false
```
