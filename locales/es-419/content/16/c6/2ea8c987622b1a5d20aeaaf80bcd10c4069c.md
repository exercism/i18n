# Introducción

En Clojure hay unas cuantas construcciones básicas de [control de flujo](https://clojure.org/guides/learn/flow). `if` es la expresión condicional más importante: consiste en una condición, un «then» y un «else» opcional. `if` solo evalúa la rama que selecciona el condicional.

```clojure
(if (even? 2) "even" "odd")
```

`cond` es una serie de pruebas y expresiones. Cada prueba se evalúa en orden y, para la primera prueba verdadera, se evalúa y se devuelve su expresión.

```clojure
(cond (= x 5) "Expression to evaluate when x equals 5"
      (> x 7) "Expression to evaluate when x is greater than 7"
      :else   "Expression to evaluate in all other cases")
```
