# Introducción

En Go, un `struct` es una secuencia de elementos con nombre llamados _campos_; cada campo tiene un nombre y un tipo.
El nombre de un campo debe ser único dentro del struct.
A los structs se los puede comparar con las _clases_ del paradigma de la programación orientada a objetos.

## Definir un struct

Para crear un nuevo struct usas las palabras clave `type` y `struct`, y defines explícitamente el nombre y el tipo de los campos.
Por ejemplo, aquí definimos el struct `Shape`, que guarda el nombre de una figura y su tamaño:

```go
type Shape struct {
    name string
    size int
}
```

Los nombres de los campos en los structs siguen la convención de Go: los campos cuyo nombre empieza con minúscula solo son visibles para el código del mismo paquete, mientras que los que empiezan con mayúscula son visibles en otros paquetes.

## Crear instancias de un struct

Una vez que definiste el `struct`, necesitas crear una nueva instancia definiendo los campos con el nombre de cada campo,
en cualquier orden:

```go
s := Shape {
    name: "Square",
    size: 25,
}
```

Para leer o modificar los campos de una instancia, usa la notación `.`:

```go
// Update the name and the size
s.name = "Circle"
s.size = 35
fmt.Printf("name: %s size: %d\n", s.name, s.size)
// Output: name: Circle size: 35
```

Los campos a los que no se les asigna un valor inicial tendrán su valor cero.
Por ejemplo:

```go
s := Shape{name: "Circle"}
fmt.Printf("name: %s size: %d\n", s.name, s.size)
// Output: name: Circle size: 0
```

Puedes crear una instancia de un `struct` sin usar los nombres de los campos, siempre que definas los campos _en orden_:

```go
s := Shape {
	"Oval",
	20,
}
```

Sin embargo, esta sintaxis se considera _código frágil_, ya que puede romperse cuando se agrega un campo, sobre todo si el campo nuevo es de un tipo diferente.
En el siguiente ejemplo agregamos un campo extra a `Shape`:

```go
type Shape struct {
	name        string
	description string // new field 'description' added
	size        int
}

s := Shape{
    "Circle",
    20,
}
// Since the second field of the struct is now a string and not an int,
// the compiler will throw an error when compiling the program:
// Output: cannot use 20 (type untyped int) as type string in field value
// Output: too few values in Shape{...}
```

## Funciones «New»

A veces puede ser útil tener funciones que nos ayuden a crear instancias de structs.
Por convención, estas funciones suelen llamarse `New` o tener nombres que empiezan con `New`, pero como son solo funciones normales, puedes darles el nombre que quieras.
Puede que te recuerden a los constructores de otros lenguajes, pero en Go son solo funciones normales.

En el siguiente ejemplo, se usa una de estas funciones `New` para crear una nueva instancia de `Shape` y asignarle automáticamente un valor por defecto al `size` de la figura:

```go
func NewShape(name string) Shape {
	return Shape{
		name: name,
		size: 100, //default-value for size is 100
	}
}

NewShape("Triangle")
// => Shape { name: "Triangle", size: 100 }

```

Usar funciones `New` puede tener las siguientes ventajas:

* la validación de los valores dados
* el manejo de valores por defecto
* como las funciones `New` a menudo se declaran en el mismo paquete que los structs que inicializan, pueden inicializar incluso campos privados del struct
