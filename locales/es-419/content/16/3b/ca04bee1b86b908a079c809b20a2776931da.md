# Instrucciones

Hola, Agente Double-Null0111.

Tu misión, si decides aceptarla, es escribir un par de herramientas que te ayuden a infiltrarte en el cuartel general de UMBRA (Secuaces Unidos Que Son Realmente Horribles) y recuperar los planos de su última y realmente espantosa maquinación. Necesitarás dos herramientas para llevar a cabo esta misión.

## 1. Protege los planos secretos recuperados con una contraseña

Una vez que tengas los planos secretos, tendrás que protegerlos para que solo quienes conocen la contraseña puedan recuperarlos.

Para lograrlo, tendrás que implementar la función `protectSecret(_ secret: String, withPassword password: String) -> (String) -> String`.
Esta función devolverá otra función que recibe posibles strings de contraseña como argumentos.
Si la contraseña que ingresas es correcta, la nueva función devuelve el secreto oculto; pero si la contraseña es incorrecta, la función devuelve «Sorry. No hidden secrets here.»

```swift
let secretFunction = protectSecret("Steal the world's supply of french fries!", withPassword: "5up3r53cr37")

secretFunction("Open sesame")
// Returns "Sorry. No hidden secrets here."

secretFunction("5up3r53cr37")
// Returns "Steal the world's supply of french fries!"
```

## 2. Genera una combinación para abrir su caja fuerte

Hemos descubierto que UMBRA basa todas las combinaciones de sus cajas fuertes en el número de la sala en la que se encuentran.
Las combinaciones de las cajas fuertes se generan aplicando repetidamente una función especial al número de la sala.
Así, el primer número de la combinación saldrá de aplicar la función al número de la sala, el segundo de aplicar la función al primer número y el tercero de aplicar la función al segundo número.

Sin embargo, UMBRA cambia con frecuencia la función que se usa para generar las combinaciones, así que tu herramienta tendrá que recibir tanto un número de sala como la función adecuada para generar la combinación.

Implementa la función `generateCombination(forRoom room: Int, usingFunction f: (Int) -> Int) -> (Int, Int, Int)` para generar la combinación que necesitarás.

```swift
func makeCombo(_ x: Int) -> Int {
  (x * 13) % 256
}

generateCombination(forRoom: 227, usingFunction: makeCombo)
// Returns (135, 219, 31)
```
