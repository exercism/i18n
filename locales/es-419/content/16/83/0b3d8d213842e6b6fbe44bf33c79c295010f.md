# Introducción

## Switch

Una [sentencia switch][switch] compara un valor con varios patrones de coincidencia posibles.
Ofrece una alternativa más limpia y legible a encadenar varias sentencias `if-else`.

Una sentencia `switch` empieza con la palabra clave `switch`, seguida del valor que se va a probar.
Cada posible coincidencia se introduce con la palabra clave `case`.
La palabra clave `default` define un caso alternativo que se ejecuta si ninguno de los casos explícitos coincide.
Al igual que las cadenas `if-else`, una sentencia `switch` solo ejecuta el bloque de código asociado con el primer caso que coincida.

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

Considera la siguiente cadena de `if-else`:

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

Esto se puede escribir de forma más clara con una sentencia `switch`:

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```

## Bucles while

Un [bucle while][while-loops] es una sentencia de flujo de control que permite ejecutar código mientras cierta condición sea verdadera.
Swift ofrece dos tipos de bucles while: el bucle while y el bucle repeat-while.
La condición del bucle while se evalúa antes de que se ejecute el cuerpo del bucle; si la condición es falsa, el cuerpo del bucle no se ejecutará en absoluto.
Los bucles while en Swift tienen la siguiente estructura:

```swift
while <#condition#> {
  <#code#>
}
```

Aquí el bucle se ejecutará mientras count sea mayor que 0, y por lo tanto imprimirá los números 2, 1 y «Liftoff!».

```swift
var count = 2
while count > 0 {
  print("\(count)…")
  count -= 1
}
print("Liftoff!")

// prints:
// 2…
// 1…
// Liftoff!
```

Un [bucle repeat-while][while-loops] es similar a un bucle while, pero la condición se evalúa después de que se ejecuta el cuerpo del bucle.
Esto significa que el cuerpo del bucle siempre se ejecutará al menos una vez, incluso si la condición es falsa.
Los bucles repeat-while en Swift tienen la siguiente estructura:

```swift
repeat {
  <#code#>
} while <#condition#>
```

Aquí el bucle solo se ejecutará una vez, ya que la condición es falsa.
Como es un bucle repeat-while, el cuerpo del bucle se ejecutará una vez antes de que se evalúe la condición.

```swift
var count = 2
repeat {
  print("\(count)…")
} while count < 0
print("Liftoff!")
```

## Transferencia de control

Swift ofrece sentencias de transferencia de control para alterar el flujo de ejecución de los bucles y de las sentencias switch.
Además de `return`, Swift incluye `continue`, `break`, las etiquetas de bucle y `fallthrough`.

### Continue

La sentencia `continue` le indica a un bucle que deje de ejecutar la iteración actual y que empiece de inmediato la siguiente iteración.
En un bucle `while` o `repeat-while`, salta directamente a la comprobación de la condición.
En un bucle `for-in`, avanza al siguiente elemento de la secuencia.

```swift
var count = 1
while count < 6 {
    count += 1
    if count == 4 {
        continue
    }
    print(count)
}

// Prints:
// 2
// 3
// 5
// 6
```

### Break

La sentencia `break` sale de inmediato de todo un bucle o de una sentencia switch.
La ejecución continúa en la primera línea de código que sigue al bucle o al switch.

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
    if !fruit.count.isMultiple(of: 2) {
        break
    }
    print(fruit)
}

// Prints:
// banana
// grapes
```

### Sentencias etiquetadas

En bucles anidados, puede que quieras que `break` o `continue` afecten a un bucle externo en lugar del bucle más interno.
Puedes etiquetar un bucle anteponiéndole un nombre y dos puntos (`labelName:`).
Después puedes pasar esa etiqueta a `break` o `continue`:

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
    print("\n--- \(fruit) ---")
    for letter in fruit {
        guard letter != "n" else {
            break outerLoop
        }
        print(letter)
    }
}

// Prints:
// --- banana ---
// b
// a
```
