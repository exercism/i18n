# Pistas

## 1. Determina si la lasaña está lista

- Usa un [condicional][mdn-if-else] para devolver un resultado según alguna condición.
- La mejor forma de resolver la tarea es comprobar primero las dos condiciones concretas.
- Recuerda que los parámetros faltantes serán `undefined` y puedes comprobar si una variable es `undefined` usando el operador de igualdad estricta `===`.

## 2. Estima el tiempo de preparación

- Usa un parámetro predeterminado para establecer el tiempo de preparación promedio en caso de que no se haya proporcionado cuando se llamó a la función.
- Repasa los [arrays][concept-arrays] para saber cómo determinar el número de capas (la longitud del array de capas).

## 3. Calcula las cantidades de pasta y salsa que se necesitan

- Primero, crea dos variables para llevar la cuenta de la cantidad de pasta y salsa.
  Defínelas con `let` para que puedas cambiar el valor más adelante en tu código.
  Además, asígnales un valor inicial adecuado.
- Usa un [bucle `for`][concept-for-loops] para recorrer las capas.
- Si encuentras una capa `'noodles'` o `'sauce'` en tu bucle, aumenta la cantidad guardada en la variable correspondiente.
- Usa un [objeto][concept-objects] para devolver ambos resultados.

## 4. Agrega el ingrediente secreto

- Repasa los [arrays][concept-arrays] para saber cómo obtener un elemento de un array y cómo agregar algo al final de un array.
- El índice del último elemento de un array `a` es `a.length - 1`.
- La función no debe tener una sentencia `return`.

## 5. Escala la receta

- Primero, calcula el factor que necesitas aplicar a todas las cantidades según las porciones objetivo.
- Una forma de asegurarte de que los argumentos no se modifiquen es usar un objeto nuevo para guardar los resultados.
- Usa un [bucle `for...in`][mdn-for-in] para recorrer todas las entradas de la receta original y llenar el objeto en consecuencia.
