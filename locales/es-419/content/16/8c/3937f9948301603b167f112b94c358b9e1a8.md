# Pistas

## 1. Genera un planeta aleatorio

- Java no proporciona una función para elegir un elemento de una colección al azar.
- Recuerda que puedes obtener un elemento de un array por su índice, que es un número entero.

## 2. Genera un número de registro de nave estelar aleatorio

- La clase `java.util.Random` proporciona un método para generar un `int` aleatorio entre 0 y un máximo dado.

## 3. Genera una fecha estelar aleatoria

- El método de la clase `java.util.Random` para generar un `double` aleatorio siempre devuelve un número entre `0.0` y `1.0`.
