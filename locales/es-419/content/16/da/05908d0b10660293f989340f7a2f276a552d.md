# formato de string

Además del método `String#%%`, una forma común de crear strings en Ruby es usar la [interpolación de strings](http://ruby-for-beginners.rubymonstas.org/bonus/string_interpolation.html). Por ejemplo:

```ruby
# Rather than:
"One for %%s, one for me." %% %{name_variable}

# Consider:
"One for #{%{name_variable}}, one for me."
```
