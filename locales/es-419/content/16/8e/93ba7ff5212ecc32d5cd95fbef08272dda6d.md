# Hints

## General


- Las [tuplas][tuples] son [tipos de secuencia][sequence types] inmutables que pueden contener cualquier tipo de dato.
- Las tuplas son [iterables][iterable]. Si necesitas índices además de los valores, usa [`enumerate()`][enumerate]
- Se puede acceder a los elementos de las tuplas mediante la [notación de corchetes][bracket notation], usando un índice basado en cero desde la izquierda, o -1 desde la derecha. También puedes usar otras [operaciones comunes de secuencia][common sequence operations] cuando trabajes con tuplas.

## 1. Extrae las coordenadas

- Recuerda: las tuplas permiten el acceso mediante el _índice_, usando _corchetes_. Los índices empiezan desde la izquierda en cero.

## 5. «Limpiar» y hacer un informe de todos los registros

- Recuerda: las tuplas son _inmutables_, pero se puede acceder al contenido mediante el _índice_ usando la _notación de corchetes_.
- Las tuplas no tienen que usar paréntesis a menos que haya _ambigüedad_.
- Python tiene varios métodos para dar formato a los strings. [`str.format()`][str.format] y [`f-strings`][f-strings] son dos de los más comunes.
- Hay varias opciones de formato de texto disponibles mediante el [`format specification mini-language`][format specification mini-language] de Python.
