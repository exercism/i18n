# General

## 1. Define el tipo personalizado genérico TreasureChest

- La guía de Elm tiene una sección sobre [tipos personalizados][custom-types].
- El tipo personalizado `TreasureChest` solo tiene una variante.
- Por convención en Elm, cuando un tipo personalizado tiene una sola variante, la variante y el tipo llevan el mismo nombre (en este caso, ambos se llamarían `TreasureChest`).

## 2. Define la función getTreasure

- Existe una [forma abreviada de desestructurar tipos personalizados de un solo miembro][single-member-custom-destructuring].
- La guía de Elm tiene una sección sobre [Maybe][maybe] si necesitas repasar.
