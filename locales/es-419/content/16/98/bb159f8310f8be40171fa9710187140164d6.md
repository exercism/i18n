# Instrucciones

Tu amigo Johannes ama hacer hardware DIY (hazlo tú mismo).
Acaba de construir una máquina de jugos, y eso le hace mucha ilusión.
La meta de Johannes es poder preparar jugo fresco cada mañana.

La máquina de jugos de Johannes tiene muchas funcionalidades sofisticadas.
Como un sistema de medición integrado, que puede decirte cuánto jugo hay en el vaso.
También tiene un temporizador, que te dice cuánto tiempo lleva funcionando la máquina.

Johannes no es el mejor programando, pero quiere hacer un programa para controlar la máquina.
Por eso te pidió que le ayudaras.

## 1. Luz de debug

La máquina tiene una luz de debug, es un mecanismo simple: si la máquina tiene corriente, la luz de debug está encendida.
El programa solo se ejecutará si la luz de debug está encendida.

Este método debe ser un método de clase llamado `JuiceMaker`.

Define el método de clase `JuiceMaker.debug_light_on?` que devuelve `true`.

```crystal
JuiceMaker.debug_light_on?
#=> true
```

## 2. Inicializa la máquina

Cuando la máquina se enciende, debe crear una instancia de una clase llamada `JuiceMaker`.
Se supone que la máquina tiene un estado inicial.
El estado inicial debe contener la siguiente información:

1. Si la máquina está funcionando o no. Esto siempre debe ser `false` cuando la máquina se enciende.
2. La cantidad de jugo en el vaso; este será un sensor que medirá la cantidad de jugo en el vaso.

Define el estado inicial, que toma la cantidad de jugo en el vaso como parámetro, y construye el estado inicial.
El estado inicial debe contener una variable de instancia `@running` que se establece en `false`, y una variable de instancia `@fluid` que se basa en un argumento dado cuando se inicializa la clase.

```crystal
JuiceMaker.new(5)
#=> #<JuiceMaker:0x10f0b8 @running=false, @fluid=5>
```

## 3. Enciende la máquina

La máquina se puede encender y apagar.
Necesitas definir un método para encender la máquina.
Cuando la máquina se enciende, el estado de funcionamiento debe establecerse en `true`.

Define el método `JuiceMaker#start` que enciende la máquina.

```crystal
juice_maker = JuiceMaker.new(5)
juice_maker.start

juice_maker
#=> #<JuiceMaker:0x10f0b8 @running=true, @fluid=5>
```

## 4. Estado de la máquina

La máquina debe poder decirte cuál es su estado.
Debe devolver `true` si la máquina está funcionando, y `false` si no está funcionando.

Define el método `JuiceMaker#running?` que devuelve el estado de la máquina.

```crystal
juice_maker = JuiceMaker.new(5)
juice_maker.start

juice_maker.running?
#=> true
```

## 5. Agrega jugo

La máquina puede agregar jugo al vaso.
La máquina puede decir cuánto jugo se agrega al vaso.
La máquina necesita ayuda para saber cuánto jugo hay en el vaso después de agregar el jugo.

Define el método `JuiceMaker#add_fluid`, que toma la cantidad de jugo agregada como parámetro y actualiza la cantidad de jugo en el vaso.

```crystal
juice_maker = JuiceMaker.new(5)
juice_maker.add_fluid(5)

juice_maker
#=> #<JuiceMaker:0x10f0b8 @running=false, @fluid=10>
```

## 6. Apaga la máquina

La máquina se puede encender y apagar.
Necesitas definir un método para apagar la máquina
Este método solo se llamará cuando la máquina esté funcionando.
Cuando la máquina se apaga, el estado de funcionamiento debe establecerse en `false`.
La máquina también necesita ayuda para determinar cuánto jugo hay en el vaso después de apagarse.
La máquina usa cinco unidades de jugo por minuto.

Define el método `JuiceMaker#stop`, que toma el número de minutos que la máquina ha estado funcionando como parámetro y devuelve la cantidad de jugo en el vaso después de apagar la máquina.

```crystal
juice_maker = JuiceMaker.new(5)

juice_maker.start
juice_maker
#=> <JuiceMaker:0x10f0b8 @running=true, @fluid=5>

juice_maker.stop(1)
#=> #<JuiceMaker:0x10f0b8 @running=false, @fluid=0>
```
