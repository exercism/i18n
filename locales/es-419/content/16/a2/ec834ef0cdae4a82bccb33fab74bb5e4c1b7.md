Diseña un conjunto de pruebas para una herramienta que cuenta líneas, letras y caracteres.

Este es un ejercicio especial. En lugar de crear código que funcione con
un conjunto de pruebas existente, tú defines el conjunto de pruebas. Para
ayudarte, se han proporcionado varias variantes del código que se va a
probar; tu conjunto de pruebas debería ser capaz al menos de detectar los
problemas (o la ausencia de ellos) que tienen.

Se supone que el sistema que se va a probar cuenta el número de líneas,
letras y caracteres totales en los strings que se le pasan.
La idea es que realices la operación «add string» varias veces,
pasando strings, y que después llames a las funciones «lines»,
«letters» y «characters» para obtener los totales.
