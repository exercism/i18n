# Introducción

Muchos programas necesitan valores aleatorios (_aparentemente_) para simular eventos del mundo real.

Algunos ejemplos comunes y conocidos son:
- El lanzamiento de una moneda: un valor aleatorio de `('Heads', 'Tails')`.
- La tirada de un dado: un número entero aleatorio del 1 al 6.
- Barajar una baraja de cartas: un orden aleatorio de una lista de cartas.
- La creación de árboles y arbustos en una simulación gráfica en 3D.

Generar valores _verdaderamente_ aleatorios con una computadora es un [desafío técnico sorprendentemente difícil][truly-random], por lo que quizá veas que a estos resultados se les llama «pseudoaleatorios».

En la práctica, una biblioteca bien diseñada como el módulo [`random`][random] de la biblioteca estándar de Python es rápida, flexible y da resultados que son más que suficientes para la mayoría de las aplicaciones de modelado, simulación y juegos.

Para esta breve introducción, mostramos las cuatro funciones más usadas del módulo.
Te invitamos a explorar la documentación completa de [`random`][random], ya que hay muchas herramientas y opciones.

Antes de poder usar las herramientas del módulo `random`, primero debes importarlo:

```python
>>> import random

# Choose random integer from a range
>>> random.randrange(1000)
360

>>> random.randrange(-1, 500)
228

>>> random.randrange(-10, 11, 2)
-8

# Choose random integer between two values (inclusive)
>>> random.randint(5, 25)
22

```

Para no tener que escribir el nombre del módulo, puedes importar funciones específicas por su nombre:

```python
>>> from random import choice, choices

# Using choice() to pick Heads or Tails 10 times
>>> tosses = []
... for side in range(10):
...    tosses.append(choice(['H', 'T']))    

>>> print(tosses)
['H', 'H', 'H', 'H', 'H', 'H', 'H', 'T', 'T', 'H']


# Using choices() to pick Heads or Tails 8 times
>>> picks = []
... picks.extend(choices(['H', 'T'], k=8))
... print(picks)
['T', 'H', 'H', 'T', 'H', 'H', 'T', 'T']
```



## `randrange()` y `randint()`

Como se muestra en el primer ejemplo de arriba, la función `randrange()` tiene tres formas:

1. `randrange(stop)` da un número entero `n` tal que `0 <= n < stop`
2. `randrange(start, stop)` da un número entero `n` tal que `start <= n < stop`
3. `randrange(start, stop, step)` da un número entero `n` tal que `start <= n < stop`
    y `n` está en la secuencia `start, start + step, start + 2*step...`

Para el caso más común, en el que `step == 1`, `randint(a, b)` puede ser más cómodo y legible.
Los posibles resultados de `randint()` _incluyen_ el límite superior, así que `randint(a, b)` es lo mismo que usar `randrange(a, b+1)`.



## `choice()` y `choices()`

Estas dos funciones suponen que partes de alguna [secuencia][sequence-types] u otro tipo de contenedor.
Por lo general, será una `list` o, con algunas limitaciones, una `tuple` o un `set` (_una `tuple` es inmutable y un `set` no tiene orden_).

La función `choice()` devuelve un miembro elegido al azar de una secuencia dada, y `choices()` devuelve una cantidad específica de miembros (`k`) elegidos al azar de una secuencia dada.
En los ejemplos mostrados arriba, supusimos una moneda justa con la misma probabilidad de cara o cruz, pero también se pueden especificar pesos.

Por ejemplo, si una bolsa contiene 10 pelotas rojas y 15 pelotas verdes, y queremos sacar una al azar:


```python
>>> random.choices(['red', 'green'], [10, 15])
['red']
```
