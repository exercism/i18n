# Anexo de instrucciones

## Registros

| Registro | Uso       | Tipo    | Descripción                       |
| -------- | --------- | ------- | --------------------------------- |
| `$a0`    | entrada   | dirección | array de palabras de factores    |
| `$a1`    | entrada   | entero  | cantidad de factores              |
| `$a2`    | entrada   | entero  | límite                            |
| `$v0`    | salida    | entero  | suma de los múltiplos bajo el límite |
| `$t0-9`  | temporal  | cualquiera | se usa como almacenamiento temporal |
