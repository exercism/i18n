# Snippet Extractor

El [Snippet Extractor][snippet-extractor] toma la entrega de un estudiante y extrae las primeras diez líneas de código «interesantes».
El fragmento extraído se muestra en varias páginas del sitio web.

Por defecto, se muestran las primeras diez líneas, ignorando las líneas vacías al inicio.
Esas primeras diez líneas _podrían_ incluir cosas como comentarios, que por lo general no son lo ideal para presentar en un fragmento.

## Personalizar la extracción de fragmentos

Recomendamos que cada track [personalice la extracción de fragmentos][snippet-extractor-customize] para, como mínimo, quitar los comentarios del código fuente.
Para personalizar la extracción de fragmentos, vas a tener que:

1. Agregar un archivo `lib/languages/<track_slug>.txt` que configure la extracción de fragmentos.
   Este archivo puede usar el [modo básico][basic-mode] o el [modo extendido][extended-mode].
   La mayoría de los tracks usan el modo extendido, ya que da más flexibilidad.
2. Agregar uno o más casos de prueba a un directorio `tests/<track_slug>/<test_slug>`.
   Cada directorio de pruebas va a necesitar dos archivos:

   1. `tests/<track_slug>/<test_slug>/code.<track_extension>`: el código sobre el que se ejecuta el extractor de fragmentos
   2. `tests/<track_slug>/<test_slug>/expected_snippet.<track_extension>`: el fragmento esperado

Mira [este pull request de ejemplo][example-pr] que personaliza la extracción de fragmentos para el lenguaje Arturo.
