# Acerca de

Un string en Factor es una secuencia de caracteres y comparte todo el
[protocolo `sequences`][sequence-protocol] (`length`, `nth`, `head`,
`tail`, `map`, `filter`, etc.) junto con sus vocabularios dedicados.

```factor
"hello"  length .       ! => 5
"hello"  reverse .      ! => "olleh"
"abcdef" 3 head .       ! => "abc"
```

Las palabras específicas de strings viven principalmente en [`splitting`][splitting],
[`ascii`][ascii] y [`unicode`][unicode]:

| palabra      | vocab         | qué hace                              |
|--------------|---------------|---------------------------------------|
| `split1`     | [`splitting`][splitting]   | corta en la primera aparición         |
| `split`      | [`splitting`][splitting]   | corta en cualquier carácter de un conjunto |
| `harvest`    | [`sequences`][sequences]   | descarta las piezas vacías del resultado de un split |
| `replace`    | [`splitting`][splitting]   | sustituye una subcadena               |
| `surround`   | [`sequences`][sequences]   | envuelve con un prefijo y un sufijo   |
| `glue`       | [`sequences`][sequences]   | une dos strings con un separador      |
| `join`       | [`sequences`][sequences]   | une un array de strings con un separador |
| `>lower`     | [`ascii`][ascii]       | convierte a minúsculas (ASCII)        |
| `>upper`     | [`ascii`][ascii]       | convierte a mayúsculas (ASCII)        |
| `[ blank? ] trim` | [`sequences`][sequences] | quita los espacios en blanco al inicio y al final |
| `first`, `second`, `third`, `fourth` | [`sequences`][sequences] | la posición inicial |
| `first2`, `first3`         | [`sequences`][sequences]   | desempaqueta dos o tres posiciones iniciales |
| `>string`    | [`strings`][strings]     | convierte una secuencia de caracteres en un string |
| `1string`    | [`strings`][strings]     | envuelve un solo carácter en un string de un carácter |
| `CHAR: x`    | parser        | un literal de un solo carácter (p. ej. `CHAR: A` → `65`) |

Para la conversión de números a strings y de strings a números,
[`math.parser`][math.parser] proporciona `number>string` y `string>number`.
Para la salida con formato, [`formatting`][formatting] proporciona `sprintf`
y similares.

Para la conversión de mayúsculas y minúsculas o la clasificación de
caracteres que tienen en cuenta Unicode, usa las palabras correspondientes
de [`unicode`][unicode].
