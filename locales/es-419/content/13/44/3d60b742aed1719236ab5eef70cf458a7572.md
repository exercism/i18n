# Instrucciones

Continuando con la temática del juego de magos y guerreros, es hora de agregar un método para lanzar un dado que sirva para todo propósito. Este será el tradicional dado de 18 caras con números del 1 al 18. Los jugadores también generan una fuerza del hechizo.

## 1. Permite que un jugador de _magos y guerreros_ lance un dado.

Implementa un método `RollDie()` en la clase `Player`.

```csharp
var player = new Player();
player.RollDie();
// => >= 1 <= 18
```

## 2. Los jugadores necesitan su fuerza. Proporciona un medio para generar la fuerza del hechizo

Implementa un método `GenerateSpellStrength()` en la clase del jugador. La fuerza del hechizo está entre 0.0 y 100.0, sin incluir este último.

Ten en cuenta que la fuerza del hechizo debe ser un número real (no un entero) para reducir la posibilidad de un empate cuando se comparan las fuerzas de dos adversarios.

```csharp
var player = new Player();
player.GenerateSpellStrength();
// => >= 0.0 < 100.0
```
