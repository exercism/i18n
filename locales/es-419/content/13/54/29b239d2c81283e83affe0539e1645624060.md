# Pistas

## General

- Este [artículo][time-overview] es una descripción general de fechas, horas y zonas horarias en .NET.
- La estructura `DateTime` está documentada [aquí][date-time].

## 1. Proporciona equivalentes en hora local de las citas en UTC (tiempo universal coordinado) para los administradores

Busca un miembro de `DateTime` adecuado que convierta de UTC a la hora local.

## 2. Programa citas en Nueva York, Londres y París

Usa la clase [`TimeZoneInfo`][time-zone-info] y selecciona los ids de zona horaria adecuados de las instrucciones de la tarea. Recuerda que Windows y OSX/Linux tienen ids diferentes.

El método [`RuntimeInformation.IsOSPlatform()`] es fundamental para tener rutas de código que apunten a distintos sistemas operativos.

## 3. Proporciona alertas a los clientes a intervalos antes de la cita

Un enfoque es usar [`TimeSpan`][time-span] para hacer aritmética con las horas.

## 4. Si el horario de verano cambió hace poco, enviamos un mensaje a los clientes para recordárselo.

`TimeZoneInfo` tiene métodos adecuados para esto.

## 5. Usa el formato de fecha y hora local para ingresar citas

Echa un vistazo a `DateTime.Parse()` y [`CultureInfo`][culture-info].
