# Introducción

## Manipulación de bits

Java tiene operadores para manipular los bits de un `byte`, `short`, `int`, `long` o `char`.

### Operadores de desplazamiento

Usa `<<` para desplazar los bits hacia la izquierda y `>>` para desplazarlos hacia la derecha.

```java
// Shift two places to the left
0b0000_1011 << 2;
// # => 0b0010_1100

// Shift two places to the right
0b0000_1011 >> 2;
// # => 0b0000_0010
```

El operador `<<` siempre inserta ceros en el lado derecho.
Sin embargo, `>>` inserta el mismo bit que el bit más a la izquierda (1 si el número es negativo o 0 si es positivo).

```java
// Shift 2 places to the right preserves the sign
// This is a negative value, whose binary representation is
// 1000_0000_0000_0000_0000_0000_0010_0110
int value = -0x7FFFFFDA;

// Shift two places to the right, preserving the sign bit
value >> 2;
// # => 1110_0000_0000_0000_0000_0000_0000_1001
```

Usa `>>>` en su lugar cuando se deban insertar ceros al desplazar hacia la derecha.

```java
// Shift two places to the right, inserting 0s on the left
value >>> 2;
// # => 0010_0000_0000_0000_0000_0000_0000_1001
```

### Operaciones a nivel de bits

#### AND a nivel de bits

El operador AND a nivel de bits (`&`) toma dos valores y realiza una operación AND sobre cada bit.
Compara cada bit del primer valor con el bit que está en la misma posición del segundo valor.
Si ambos son 1, el bit del resultado es 1.
De lo contrario, el bit del resultado es 0.

```java
0b0110_0101 & 0b0011_1100;
// # => 0b0010_0100
```

#### OR a nivel de bits

El operador OR a nivel de bits (`|`) toma dos valores y realiza una operación OR sobre cada bit.
Compara cada bit del primer valor con el bit que está en la misma posición del segundo valor.
Si cualquiera de los dos bits es 1, el bit del resultado es 1.
De lo contrario, es 0.

```java
0b0110_0101 | 0b0011_1100;
// # => 0b0111_1101
```

#### XOR a nivel de bits

El operador XOR a nivel de bits (`^`) realiza una operación XOR a nivel de bits sobre dos valores.
Al igual que los operadores AND y OR a nivel de bits, compara cada bit del primer valor con el bit que está en la misma posición del segundo valor.
Si solo uno de ellos es 1, el bit resultante es 1.
De lo contrario, es 0.

```java
0b0110_0101 ^ 0b0011_1100;
// # => 0b0101_1001
```

#### NOT a nivel de bits (`~`)

Por último, el operador NOT a nivel de bits (`~`) invierte cada bit.
A diferencia de los operadores anteriores, este es un operador unario, que actúa solo sobre un valor.

```java
~0b0110_0101;
// # => 0b1001_1010
```
