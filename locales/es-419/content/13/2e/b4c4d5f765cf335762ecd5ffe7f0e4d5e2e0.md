# Ayuda

## Ejecutar los tests

El track de Factor usa **Factor 0.101**. Después de
[instalarlo](https://exercism.org/docs/tracks/factor/installation),
ejecuta lo siguiente desde el directorio de este ejercicio:

```
factor -roots=. -run=exercism-tools <exercise>
```

Por ejemplo, para `hello-world`:

```
factor -roots=. -run=exercism-tools hello-world
```

Cada ejercicio viene con un pequeño vocabulario `exercism-tools`
que se encarga de ejecutar los tests. El runner termina con
estado 0 cuando pasan todos los tests, y con un estado distinto
de cero más la salida de diagnóstico si falla algún test.

### Tests omitidos

Por defecto, solo se ejecuta el primer test. El mecanismo es la
línea `STOP-HERE` del archivo de tests: al analizar el archivo,
le indica al lexer de Factor que ignore todo lo que está debajo
de ella, así que el runner solo ve los tests que están arriba.
Una vez que pase tu primer test, puedes habilitar más tests de
dos maneras:

- **Elimina la línea `STOP-HERE`** para habilitar de una vez
  todos los tests restantes.
- **Mueve la línea `STOP-HERE` más abajo** para habilitar los
  tests uno a la vez, o una tarea a la vez. Los ejercicios de
  concepto agrupan sus tests bajo marcadores `TASK:`; mover
  `STOP-HERE` justo antes del siguiente `TASK:` es un paso
  natural.

Cuando pasen todos los tests, habrás resuelto el ejercicio.

## Enviar tu solución

Desde el directorio del ejercicio:

```
exercism submit <exercise>/<exercise>.factor
```

Por ejemplo:

```
exercism submit hello-world/hello-world.factor
```

Si el archivo `.meta/config.json` del ejercicio lista más de un
archivo de solución (algunos ejercicios de concepto dividen la
solución en varios archivos dentro de un subvocabulario
auxiliar), pasa a `exercism submit` todos los archivos que
hayas editado.

## Enviar soluciones incompletas

Puedes enviar una solución aunque los tests fallen: eso te
permite ver cómo otras personas abordaron el ejercicio y pedir
comentarios de un mentor sobre lo que tengas hasta ahora.

## Cómo obtener más ayuda

- La [categoría de Factor en el foro de Exercism](https://forum.exercism.org/c/programming/factor/)
  es el mejor lugar para preguntas y comentarios específicos
  del track.
- El [Discord de Exercism](https://exercism.org/r/discord) tiene
  canales tanto para ayuda general como para tracks
  individuales.
- La documentación oficial de Factor es exhaustiva y se puede
  buscar. Dos buenos puntos de entrada:
  - [El manual de Factor](https://docs.factorcode.org/content/article-handbook.html),
    de estilo referencia y organizado por vocabulario.
  - [El libro de recetas de Factor](https://docs.factorcode.org/content/article-cookbook.html),
    con ejemplos cortos e idiomáticos por tema.
- El [tutorial de Factor](https://andreaferretti.github.io/factor-tutorial/)
  de Andrea Ferretti es una introducción rápida y amable al
  lenguaje y al entorno de desarrollo.
