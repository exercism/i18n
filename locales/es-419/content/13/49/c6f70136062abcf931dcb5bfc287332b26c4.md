# Booleanos

Haskell tiene un tipo conocido como [`Bool`][bools].
Es una enumeración de `True` y `False`.

## Operadores lógicos

Haskell tiene tres operadores lógicos (`not`, `||`, `&&`), que combinan valores booleanos y forman expresiones que producen valores diferentes.

### Y (`&&`)

El [operador _y_][and] en Haskell se representa con `&&` y devuelve `True` si ambos valores son `True`; de lo contrario, devuelve `False`.
Cuando usas el operador _y_, un valor booleano se coloca a la derecha del `&&` y otro a la izquierda.

```haskell
True && True
-- -> True

True && False
-- -> False
```

### O (`||`)

El [operador _o_][or] en Haskell se representa con `||` y devuelve `True` si **al menos uno** de los valores dados es `True`.
Si ambos valores son `False`, devuelve `False`.
Cuando usas el operador _o_, un valor booleano debe colocarse a la derecha del `||` y otro a la izquierda.

```haskell
True || True
-- -> True

True || False
-- -> True

False || False
-- -> False
```

### Negación (`not`)

El operador de negación en Haskell se representa con `not` y devuelve `True` si el valor booleano dado es `False`, y devuelve `False` si se proporciona `True`.
Cuando usas el operador de negación, un valor booleano debe colocarse después del operador (`not`).

```haskell
not True
-- -> False

not False
-- -> True
```

## Uso de los paréntesis (`()`)

Cuando trabajas con booleanos, puedes usar paréntesis para decidir qué valores booleanos evaluar primero.
El resultado puede variar según cómo se usen los paréntesis.
En Haskell, lo que está entre paréntesis se evalúa primero.

```haskell
True && False && False || True
-- -> True

True && False && (False || True)
-- -> False
```

Dado que lo que está entre paréntesis se evalúa primero, el operador de negación se aplicará a la expresión entre paréntesis en el siguiente ejemplo.

```haskell
not True && False
-- -> False

not (True && False)
-- -> True
```

Solo debes usar paréntesis cuando afecten el resultado; de lo contrario, deberías omitirlos.
