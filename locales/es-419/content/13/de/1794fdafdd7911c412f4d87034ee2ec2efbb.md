# Pistas

## General

- Intenta dividir un problema en un caso base y un caso recursivo
  Por ejemplo, supongamos que quieres contar cuántas galletas hay en el frasco de galletas con un enfoque recursivo
  Un caso base es un frasco vacío: tiene cero galletas.
  Si el frasco no está vacío, entonces la cantidad de galletas en el frasco es igual a una galleta más la cantidad de galletas en el frasco después de quitar una galleta.

## 1. Implementa una función que sume los números de un array

- La recursión consiste en iterar sobre los elementos del array, sumando cada uno a un acumulador.
- El caso base es un array vacío, cuya suma es igual a cero.
- El caso recursivo suma el primer elemento a la suma del resto del array.
- Recuerda la indexación y el corte de arrays del [concepto de Arrays][arrays-concept] para separar el primer elemento del array del resto de los elementos.

## 2. Invierte un array

- La recursión consiste en iterar sobre los elementos del array, agregando cada uno a otro array en orden inverso.
- El caso base es un array vacío.
- Recuerda que el [operador `+`][manual-addition] concatena cuando se aplica a arrays.

## 3. Transforma un array

- La recursión consiste en iterar sobre los elementos del array, agregando a un array acumulador el resultado de aplicar el filtro al elemento.
- Para aplicar el parámetro filtro a un elemento, usa la sintaxis habitual de pipe: `.element | filter`.
- El caso base es un array vacío.
