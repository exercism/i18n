# Pistas

## General

- Los conceptos anteriores [estructuras][], [mapas][] y [métodos][] te serán útiles aquí.


## 1. Seguimiento de los asistentes

- El concepto [definición de tipo][] explica cómo definir un nuevo tipo.
- Usa `make()` para crear una nueva instancia de `map`.
- Para agregar un valor al mapa, usa `struct{}{}` para crear una instancia del `struct{}` vacío.

## 2. Comprobación de los asistentes

- Si un elemento está en el mapa, el conjunto contiene ese valor.
- La [asignación de dos valores][] se puede usar para comprobar si un mapa contiene un elemento.

## 3. Comparación de los asistentes

- Dos conjuntos son iguales si todos los valores de cada uno están contenidos en el otro.
- Puedes usar `range` para revisar todos los elementos del conjunto.
