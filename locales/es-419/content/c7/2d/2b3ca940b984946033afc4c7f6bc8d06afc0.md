# Anexo de instrucciones

Para la ruta de Python, este ejercicio te pide crear una _clase_ `SpaceAge` (_[concept:python/classes]()_) que incluya métodos para todos los planetas del sistema solar.
Los métodos deben seguir la convención de nombres `on_<planet name>`.

Cada método debe `return` la edad (_la «on» de ese planeta_) en años, redondeada a dos decimales:

```python
#creating an instance with one billion seconds, and calling .on_earth().
>>> SpaceAge(1000000000).on_earth()

#This is one billion seconds on Earth in years
31.69
```
