# Introducción

En Java, la sobrecarga de métodos es una característica que permite que una clase tenga más de un método con el mismo nombre, si sus listas de parámetros son distintas.
Está relacionada con el polimorfismo en tiempo de compilación (o estático).
Este concepto es crucial para crear métodos que realizan tareas similares, pero con argumentos distintos.

## ¿Por qué sobrecargar métodos?

La sobrecarga de métodos aumenta la legibilidad del programa.
Se puede dar el mismo nombre a métodos diferentes, pero con parámetros distintos.
Dependiendo de la cantidad de parámetros o del tipo de parámetros, se llama al método correspondiente.

## ¿Cómo sobrecargar métodos?

La clave de la sobrecarga de métodos es la firma de un método.
Dos métodos se consideran diferentes si tienen firmas diferentes.
Hay dos formas de sobrecargar un método:

1. **Distinta cantidad de parámetros**: Los métodos pueden tener el mismo nombre, pero una cantidad distinta de parámetros.

   ```java
   public class Display {

       public void show(int x) {
           System.out.println("Show with int: " + x);
       }

       public void show(int x, int y) {
           System.out.println("Show with two ints: " + x + ", " + y);
       }
   }
   ```

2. **Distintos tipos de parámetros**: Los métodos pueden tener el mismo nombre y la misma cantidad de parámetros, pero con tipos diferentes.

   ```java
   public class Display {

       public void show(int x) {
           System.out.println("Show with int: " + x);
       }

       public void show(String s) {
           System.out.println("Show with String: " + s);
       }
   }
   ```

## Puntos a recordar

- Los métodos sobrecargados deben cambiar la lista de argumentos.
- Los métodos sobrecargados también pueden cambiar el tipo de retorno, pero cambiar únicamente el tipo de retorno no constituye sobrecarga de métodos.
- Los métodos se pueden sobrecargar en la misma clase o en una subclase.

En este concepto, exploraremos varios ejemplos y matices de la sobrecarga de métodos en Java.
