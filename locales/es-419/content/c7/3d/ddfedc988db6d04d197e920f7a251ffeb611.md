En Raku se hace un uso generoso de los bloques de código.
Son fundamentales para las funciones, pero también aparecen en herramientas como `grep` y `map`, como bloques de sentencias `if`, `for`, `while` y `given`, e incluso en los subíndices de los arrays.

## Rutinas

[`Subs`][type/Sub] y [`Methods`][type/Method] son tipos de [`Routines`][type/Routine] en Raku.

Una rutina puede salir en cualquier momento con un valor de retorno usando la palabra clave [`return`][control-return], una herramienta muy útil para crear funciones.
Si no se especifica un `return`, la última sentencia de la rutina será su valor de retorno implícito.

Una rutina puede tener una [`Signature`][language/signatures] entre paréntesis antes del bloque de código.

[`Routine`][type/Routine] es una subclase de [`Block`][type/Block].

```raku
sub add ($x, $y --> Int) { return $x + $y }
say add(1, 2); # 3
```

Los métodos se verán en otro concepto relacionado con clases y objetos.

## Bloques

Un [`Block`][type/Block] es un objeto de código reutilizable que normalmente se usa para crear lambdas.

La última sentencia de un bloque es su valor de retorno implícito.

Un bloque puede tener una [`Signature`][language/signatures] precedida por `->` antes del bloque de código.

[`Block`][type/Block] es una subclase de [`Code`][type/Code], que es la clase base fundamental de todos los objetos de código en Raku.

```raku
my $add = -> $x, $y { $x + $y };
say $add(1, 2); # 3
```

## Firmas

Una [`Signature`][language/signatures] se compone de cero o más [`Parameters`][type/Parameter], separados por comas.

Al final de una firma se puede especificar un tipo de retorno con una [flecha de tipo de retorno][signatures-return-type-arrow] `-->`.

Una firma puede usarse para especificar los argumentos que aceptará un `Block`.

En este concepto mantendremos las firmas simples, usando solo parámetros posicionales con variables con el sigilo escalar y un tipo de retorno.
Todo esto se ampliará en otros conceptos.

## Despacho múltiple

Raku permite escribir varias rutinas con el mismo nombre pero con firmas diferentes usando la palabra clave `multi`.
Esta funcionalidad se conoce como [despacho múltiple][multi-dispatch].
Cuando se llama a la rutina por su nombre, el entorno de ejecución determina el candidato adecuado y lo invoca.

Esto se verá con más detalle en un concepto sobre tipos.

```raku
multi foo () { say 'No arguments given'}

multi foo ($bar) { say "One argument given: $bar" }
```

## WhateverCode

Cuando una estrella `*` de [`Whatever`][type/Whatever] se usa en combinación con la mayoría de los operadores, se crea un objeto [`WhateverCode`][type/WhateverCode].
Esto te permite crear bloques con una sintaxis más simple.

```raku
# These will all give code blocks that increment a single argument by 1:
-> $x { $x  + 1 }; # Explicit signature
      { $^x + 1 }; # Signature via placeholder variable
      { $_  + 1 }; # Topic variable
          * + 1;   # WhateverCode
```
