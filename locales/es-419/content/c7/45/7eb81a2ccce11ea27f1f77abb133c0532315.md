# Pistas

## General

- Todos los nombres aquí terminan en `!`, y cada uno entrega valores con `yield` en lugar de `return`.
- Marca los argumentos como `once`. Nada de aquí necesita que un argumento se vuelva a evaluar en cada vuelta.
- Prueba un iterador escribiendo un bucle a su alrededor. No se puede llamar a un iterador por sí solo, así que sin un `loop` no hay nada que imprimir.

## 1. Los marcadores

- Un `loop` dentro del iterador, controlado por `1.upto!(count)`, que entrega el número `spacing` veces.
- No hace falta nada especial para un conteo de cero: `1.upto!(0)` no entrega nada, así que el bucle interno termina de inmediato y el iterador se acaba.

## 2. Hasta que termine el sendero

- Recorre el array con `elt!`, y usa `quit` cuando el valor sea `"end"`.
- El orden importa: `quit` antes del `yield`, o `"end"` se entrega antes de que te detengas.
- No hace falta nada para un array que no tenga ningún `"end"`. El `elt!` se agota y el iterador se acaba.

## 3. Solo los pájaros

- Recorre el array y usa `yield` solo dentro de un `if`. Una vuelta que no entrega nada simplemente sigue adelante: un iterador no está obligado a entregar algo cada vez.
- Un nombre empieza con mayúscula cuando `.is_upper` es verdadero para su primer carácter.
- Protégete contra un string vacío antes de buscar su primer carácter.

## 4. Numerados

- Dos iteradores dentro de tu propio iterador: `1.up!` para el número y `elt!` para el avistamiento. Este es el emparejamiento de `duet-practice`, ahora dentro de algo que tú escribiste.
- Construye el string con `+`. El número va primero, así que empieza con `number.str`, ya que a un string se le puede sumar un número, pero no al revés.
