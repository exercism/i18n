# Anexo de instrucciones

En [concept:python/unpacking-and-multiple-assignment](https://github.com/exercism/python/tree/main/concepts/unpacking-and-multiple-assignment), aprendiste varias técnicas para trabajar con `lists`/`tuples` de longitud arbitraria, así como con argumentos de función de longitud arbitraria.
Este ejercicio es un lugar excelente para practicar esas técnicas.

## Cómo se implementa este ejercicio en Python

Los casos de prueba de este track agregan un argumento de palabra clave adicional llamado `qualifier`.
Debes usar el valor de este argumento de palabra clave para modificar el verso final de tu Proverbio.
