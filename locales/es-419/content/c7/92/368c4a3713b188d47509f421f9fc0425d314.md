# Introducción

Un `string` en Clojure es un string de Java, es decir, un objeto que representa texto inmutable como una secuencia de caracteres Unicode (letras, dígitos, signos de puntuación, etc.).

La biblioteca `clojure.string` ofrece muchas funciones estándar para manipular y procesar strings. Además, todos los métodos habituales de Java para operar con strings están disponibles mediante la interoperabilidad.
