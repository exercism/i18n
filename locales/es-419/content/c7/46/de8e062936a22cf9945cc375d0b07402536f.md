## Editores

### Gratuitos y de código abierto

- [VS Code](https://code.visualstudio.com)

  VS Code es un editor de código de código abierto. Puedes encontrar información sobre cómo configurar TypeScript [aquí](https://code.visualstudio.com/docs/languages/typescript). VS Code es un editor popular para TypeScript porque Microsoft mantiene tanto VS Code como TypeScript, así que funciona bien con el lenguaje; VS Code soporta TS sin ninguna configuración adicional. De hecho, ¡VS Code fue escrito con TypeScript!

  Un problema común con VS Code y TS se da cuando las versiones de tu editor y de tu proyecto son diferentes, lo que puede hacer que VS Code muestre un mensaje de error que quizá te confunda. Encontrarás instrucciones sobre cómo manejar este error [aquí](https://code.visualstudio.com/docs/typescript/typescript-compiling#_using-newer-typescript-versions)

### Con licencia

- [Sublime Text](https://www.sublimetext.com)

  Sublime Text es un editor de código popular con soporte para la mayoría de los lenguajes mediante complementos instalables. Puedes probarlo gratis, pero se te pedirá con regularidad que compres una licencia, que actualmente cuesta \$70 USD.

- [WebStorm](https://www.jetbrains.com/webstorm/)

  WebStorm es un IDE (entorno de desarrollo integrado) completo para JavaScript/TypeScript. Soporta TypeScript sin configuración adicional y tiene pruebas, depuración y análisis de código integrados. Puedes probarlo gratis durante 30 días; después, una licencia anual cuesta \$129 USD el primer año.
