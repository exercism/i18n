# Apéndice de instrucciones

## Palabras

Define una tupla `robot` con los campos `x`, `y` y `direction`. El campo
`direction` contiene uno de los símbolos `north`, `east`, `south` o
`west` (declarados en el vocabulario de este ejercicio).

- `<robot> ( x y direction -- robot )`: construye un robot.
- `move ( robot instructions -- robot )`: aplica un string de instrucciones `R`,
  `L` y `A` y devuelve el robot actualizado.
