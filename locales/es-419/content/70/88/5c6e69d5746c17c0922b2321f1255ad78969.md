# Ayuda

Si tienes problemas y necesitas ayuda, puedes usar uno de los siguientes recursos:

- La [Groovy Language Documentation](http://docs.groovy-lang.org/docs/latest/html/documentation/)
- La entrada [Groovy Community](http://www.groovy-lang.org/community.html) de la Groovy Language Documentation
- [/r/groovy](https://www.reddit.com/r/groovy) es el subreddit de Groovy.
- Puedes usar [StackOverflow](http://stackoverflow.com/questions/tagged/groovy) para buscar tu problema y ver si ya lo respondieron. También puedes hacer y responder preguntas.
