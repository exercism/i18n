# Anexo de instrucciones

## Registros

| Registro | Uso      | Tipo    | Descripción                            |
| -------- | -------- | ------- | -------------------------------------- |
| `$a0`    | entrada  | dirección | array de pesos de los objetos         |
| `$a1`    | entrada  | dirección | array de valores de los objetos       |
| `$a2`    | entrada  | entero  | número de objetos                      |
| `$a3`    | entrada  | entero  | peso máximo                            |
| `$v0`    | salida   | entero  | valor máximo                           |
| `$t0-9`  | temporal | cualquiera | se usa para almacenamiento temporal |
