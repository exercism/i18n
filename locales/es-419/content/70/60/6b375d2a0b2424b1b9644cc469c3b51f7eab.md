# Anexo de las instrucciones

## Restricciones

No te quedes corto usando la biblioteca estándar de herramientas para colecciones. Puedes y debes completar este ejercicio sin herramientas como `Array.tryFindIndex`.

## Pistas

Para este ejercicio te resultan útiles las siguientes características de F#:

- [Recursión de cola](https://blogs.msdn.microsoft.com/fsharpteam/2011/07/08/tail-calls-in-f/) Evita desbordamientos de pila con entradas grandes usando recursión de cola. Aunque no hay casos de prueba que verifiquen esto explícitamente, usar recursión de cola conduce a una solución más eficiente. Otro buen recurso sobre la recursión de cola es [esta entrada de blog](http://blog.ploeh.dk/2015/12/22/tail-recurse/).
- La [coincidencia de patrones](https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/pattern-matching) es extremadamente poderosa y ayuda a simplificar la lógica condicional con múltiples ramas.
