# Arrays

`ARRAY{T}` es una fila fija de valores de tipo `T`.

```sather
   row : ARRAY{STR} := |"Mia", "Ana", "Ben"|;
   sizes : ARRAY{INT} := |3, 1, 2|;
```

## Las llaves

`ARRAY{STR}` se lee «array de `STR`». Las llaves contienen un **parámetro de tipo**: `ARRAY` por sí solo no es un tipo, porque un array tiene que ser un array de algo. Gran parte de la biblioteca de Sather está construida así, y escribir una clase como esta por tu cuenta viene más adelante.

## Posiciones

```sather
row[0]                 -- the first
row[row.size - 1]      -- the last
row.size               -- how many
```

Las posiciones van de `0` a `.size - 1`. Un array conoce su tamaño y nunca lo cambia: no se puede agregar nada a un `ARRAY`.

## Crear uno sin un literal

`#ARRAY{INT}(n)` crea un array de `n` valores, cada uno un cero:

```sather
   counts ::= #ARRAY{INT}(5);      -- five noughts
   counts[0] := 7;
```

Asignar a una posición usa los mismos corchetes a la izquierda de `:=`.

## Fuera de rango

Leer o escribir una posición que no existe no se verifica en una compilación normal. No detendrá el programa con un mensaje útil; leerá o escribirá lo que sea que esté a continuación en la memoria. Dos hábitos lo evitan: usa `.size - 1` en lugar de un número contado a ojo, y termina los bucles con `until!(i >= a.size)` en lugar de un literal.

## Imprimir uno

`.str` da el contenido entre llaves, lo que resulta útil mientras estás resolviendo algo:

```sather
   #OUT + row.str;      -- {Mia,Ana,Ben}
```
