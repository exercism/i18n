# Pruebas

La mayoría de las pruebas verifican que devuelves el valor esperado, ya sea asignando a [result] o pasando un valor a [exit].

Algunas pruebas verifican que [lances][raise] la excepción esperada.

## Ejecutar las pruebas

La utilidad `make` es una dependencia para ejecutar las pruebas.

Desde el directorio del ejercicio, escribe en una consola/terminal:

```sh
make
```

Si ni siquiera tocaste el archivo de la solución del ejercicio, verás un mensaje como:

```
Please implement your solution.
```

Así que elimina esta línea antes de empezar a escribir tu solución.

De forma predeterminada, solo se ejecuta la primera prueba.

```text
TAP version 14
1..10
ok 1 - ...
```

Para ejecutar todas las pruebas, escribe:

```sh
make test=all
```

```text
TAP version 14
1..10
ok 1 - empty_sentence
ok 2 - perfect_lower_case
ok 3 - only_lower_case
ok 4 - missing_the_letter_x
ok 5 - missing_the_letter_h
ok 6 - with_underscores
ok 7 - with_numbers
ok 8 - missing_letters_replaced_by_numbers
ok 9 - mixed_case_and_punctuation
ok 10 - am_and_AM_are_26_different_characters_but_not_a_pangram
```

Cuando todas las pruebas pasen, habrás terminado el ejercicio y podrás enviar la solución.

Es posible elegir una sola prueba para ejecutar pasando el número correspondiente, por ejemplo:

```sh
make test=2
```

solo ejecutaría la segunda prueba.
