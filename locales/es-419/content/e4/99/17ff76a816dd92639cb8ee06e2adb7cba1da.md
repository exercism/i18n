# Introducción

Los arrays son las secuencias de longitud fija de Factor: puedes cambiar los elementos, pero no la longitud. Ya sabes cómo escribir un array literal, `{ … }`, y cómo cortar y combinar uno. Este ejercicio cubre el pequeño conjunto de herramientas que aparece cuando construyes arrays a partir de valores en la pila y luego buscas o reordenas su contenido.

## Construir desde la pila

`1array`, `2array`, `3array` y `4array` (en [`arrays`][arrays]) toman 1, 2, 3 o 4 valores de la parte superior de la pila y los agrupan:

```
1array ( a       -- { a }       )
2array ( a b     -- { a b }     )
3array ( a b c   -- { a b c }   )
4array ( a b c d -- { a b c d } )
```

```factor
42 1array .                ! => { 42 }
3 4 2array .               ! => { 3 4 }
"x" "y" "z" 3array .       ! => { "x" "y" "z" }
1 2 3 4 4array .           ! => { 1 2 3 4 }
```

## Unir

`concat` (en [`sequences`][sequences]) toma una secuencia cuyos elementos son a su vez secuencias y las aplana un nivel. `join` hace lo mismo, pero con un separador insertado entre cada par:

```
concat ( seqs     -- seq )
join   ( seqs sep -- seq )
```

```factor
{ { 1 2 } { 3 4 } { 5 } } concat .
! => { 1 2 3 4 5 }

{ "alpha" "beta" "gamma" } ", " join .
! => "alpha, beta, gamma"
```

## Invertir

`reverse` devuelve una nueva secuencia con los elementos en orden inverso:

```
reverse ( seq -- newseq )
```

```factor
{ 1 2 3 4 } reverse .   ! => { 4 3 2 1 }
```

## ¿Es un array?

`array?` (en [`arrays`][arrays]) es el predicado de tipo. Es verdadero para cualquier valor construido por `<array>`, `1array`/`2array`/..., o un array literal `{ … }`, y falso para todo lo demás (incluidos los vectores, los strings y otras secuencias):

```
array? ( obj -- ? )
```

```factor
{ 1 2 3 } array? .         ! => t
"hello" array? .           ! => f
V{ 1 2 3 } array? .        ! => f
```

## Buscar

`index` devuelve la posición del primer elemento igual al valor que le pasas, o `f` si no está presente. `member?` devuelve solo un Boolean. Ambas reciben **primero el elemento** y **después la secuencia**. `members` (en [`sets`][sets]) devuelve los elementos *únicos* de una secuencia (la operación de deduplicación), y `all-unique?` (también en `sets`) comprueba si la secuencia ya no tiene duplicados:

```
index       ( elt seq -- i/f )
member?     ( elt seq -- ? )
members     ( seq     -- uniques )
all-unique? ( seq     -- ? )
```

```factor
"b" { "a" "b" "c" } index .       ! => 1
"z" { "a" "b" "c" } index .       ! => f
"b" { "a" "b" "c" } member? .     ! => t
"z" { "a" "b" "c" } member? .     ! => f
{ 1 2 3 2 1 } members .           ! => { 1 2 3 }
{ 1 2 3 } all-unique? .           ! => t
{ 1 2 1 } all-unique? .           ! => f
```
