# Instrucciones

En este ejercicio escribirás código para ayudar a una empresa de letreros a crear mensajes personalizados para sus letreros.

## 1. Crea un letrero de ocasión

Implementa la función `buildSign(occasion, name)` que acepta un string como parámetro `occasion` y un string que contiene el nombre de alguien como parámetro `name`.
Los dos parámetros se insertarán en una plantilla de string para mostrar el mensaje en el letrero.

```javascript
buildSign('Birthday', 'Rob');
// => "Happy Birthday Rob!"
```

## 2. Crea un letrero de cumpleaños

Implementa la función `buildBirthdaySign(age)` que acepta una edad y, según esa edad, determina parte del mensaje del letrero.
Si la edad es 50 o más, el letrero se referirá a la persona como _mature_; de lo contrario, se referirá a ella como _young_.
El resultado esperado exacto se muestra a continuación:

```javascript
buildBirthdaySign(50);
// => "Happy Birthday! What a mature fellow you are."

buildBirthdaySign(45);
// => "Happy Birthday! What a young fellow you are."
```

## 3. Crea un letrero de graduación

Implementa la función `graduationFor(name, year)`, que toma un nombre como parámetro de tipo string y un año como parámetro de tipo número, y usa la interpolación de strings para crear una frase para un letrero que usa un salto de línea para separar las dos líneas del mensaje.

```javascript
graduationFor('Hannah', 2022);
/* => "Congratulations Hannah!
       Class of 2022"
*/
```

## 4. Calcula el costo de un letrero

Implementa la función `costOf(sign, currency)`, que toma un string que contiene el contenido del letrero y un string que representa la moneda.
El letrero tiene un precio base de 20 en la moneda dada. Además, cada letra cuesta 2. (Los espacios en blanco se incluyen en el cálculo.)
La frase devuelta incluye el costo de crear el letrero, escrito con dos dígitos después del punto decimal, seguido del string de la moneda.

```javascript
costOf('Happy Birthday Rob!', 'dollars');
// => "Your sign costs 58.00 dollars."
```
