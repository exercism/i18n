# Acerca de

`case` es el selector múltiple basado en igualdad de Factor. Es la
herramienta adecuada cuando la elección depende de que un *único*
valor sea igual a una de varias alternativas, y no cuando cada rama
necesita una prueba distinta (para eso usa `cond`).

```factor
USING: combinators ;

SYMBOLS: yes no maybe ;

: invert ( ?/maybe -- ?'/maybe )
    {
        { yes [ no ] }
        { no  [ yes ] }
        [ ]            ! default: leave value alone
    } case ;
```

Algunas cosas que conviene tener claras:

- La igualdad es `=`. Cualquier valor que funcione con `=` sirve como
  clave: números, strings, caracteres, símbolos e incluso tuplas.
- Las ramas *coincidentes* ven la pila *sin* el valor que se está
  comparando. Las ramas *por defecto* todavía lo ven en la parte
  superior.
- Un `case` sin una rama por defecto y sin ninguna cláusula que
  coincida lanza un error.

Cuando es posible, `case` se compila a una tabla de saltos, así que no
es solo azúcar sintáctico para una cadena de `if`: también es rápido.
