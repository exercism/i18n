# Acerca de

Los tipos personalizados son la forma en que se definen nuevos tipos de datos en Gleam. Pueden tener múltiples _variantes_, cada una con su propio nombre.

```gleam
pub type Season {
  Spring
  Summer
  Autumn
  Winter
}
```

Cada caso de un tipo personalizado puede contener datos de forma opcional, y distintos casos pueden tener distintos tipos de datos. Cuando una variante contiene datos, se le llama _registro_.

```gleam
pub type Number {
  SomeInt(Int)
  SomeFloat(Float)
  Invalid
}
```

Puedes crear un valor para un caso específico refiriéndote a su nombre si no contiene datos adicionales (`Spring`), o llamándolo como una función si los contiene (`SomeInt(2)`).

```gleam
let spring = Spring
let integer_two = SomeInt(2)
```

Los tipos personalizados, al igual que todo en Gleam, tienen _igualdad estructural_, lo que significa que dos valores de la misma variante y con los mismos datos son equivalentes.

```gleam
Spring == Spring // -> True
Spring == Autumn // -> False
SomeInt(2) == SomeInt(2) // -> True
SomeInt(2) == SomeFloat(2.0) // -> False
```

Se puede usar coincidencia de patrones con las variantes de un tipo personalizado mediante expresiones case.

```gleam
import gleam/int
import gleam/float

pub fn describe(flexible_number: Number) -> String {
  case flexible_number {
    SomeFloat(f) -> "Float: " <> float.to_string(f)
    SomeInt(i) -> "Int: " <> int.to_string(i)
    Invalid -> "Neither a float nor an int"
  }
}
```
