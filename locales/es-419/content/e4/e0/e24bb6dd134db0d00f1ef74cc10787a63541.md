# Ignorar

## Unicode y los grupos de grafemas

Este ejercicio incluye tests con strings de Unicode que contienen grupos de grafemas.
Las funciones integradas de Perl para procesar strings no son suficientes para manejar estos strings.
Aquí tienes un par de recursos que te pueden ayudar:

* [Tratar los strings de Unicode como grupos de grafemas][foy]
* [Extraer por grafema en lugar de punto de código (regex)][christiansen]

[foy]: https://www.effectiveperlprogramming.com/2011/06/treat-unicode-strings-as-grapheme-clusters/
[christiansen]: https://www.perl.com/pub/2012/05/perlunicookbook-extract-by-grapheme-instead-of-codepoint-regex.html/
