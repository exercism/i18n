# Pistas

## 1. Define el tiempo de horno esperado en minutos

- Una función global y con nombre se define con
  [`defun`][cookbook-functions].
- Una función «devuelve» (_por ejemplo_, evalúa a) el valor de la última
  expresión en su cuerpo.
- Una definición de función puede incluir una cadena de documentación
  opcional después de la lista de parámetros.

## 2. Calcula el tiempo de horno restante en minutos

- Vas a necesitar escribir una [función][cookbook-functions] con un
  solo parámetro.
- Puedes usar [`-`][hyper-subtract] para restar números.

* Puedes llamar a otra función si colocas el nombre de la función como
  el primer elemento de una expresión (_por ejemplo_, `(func)`).

## 3. Calcula el tiempo de preparación en minutos

- Necesitas definir una [función][cookbook-functions] con un solo
  parámetro
- Puedes usar [`*`][hyper-multiply] para multiplicar números.

## 4. Calcula el tiempo transcurrido en minutos

- Necesitas definir una [función][cookbook-functions] con dos
  parámetros.
- Puedes usar [`+`][hyper-plus] para sumar números.
