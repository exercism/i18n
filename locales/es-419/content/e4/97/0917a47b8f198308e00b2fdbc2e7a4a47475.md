# Acerca de

Haxe tiene dos tipos de números: enteros y números de punto flotante:

- `Int`: Representa un número entero.
- `Float`: Representa un número de punto flotante de doble precisión de 64 bits.

```haxe
var integer:Int = 10;
var floating:Float = 5.4;
```

Aunque cada `Int` se puede usar donde se espera un `Float` (es decir, `Int` **es asignable a** o **se unifica con** `Float`), lo contrario no es cierto: asignar un `Float` a un `Int` puede causar pérdida de precisión, por lo que no se permite de forma implícita.

## Comparación

Dos números son iguales si tienen el mismo valor.

```haxe
1 == 1; // true

1.2 == 1.2; // true

1 == 1.0; // true

0.2 + 0.1 == 0.3 // false
```

Para el último caso, consulta [0.30000000000000004.com][0.30000000000000004.com] para ver una breve explicación.
