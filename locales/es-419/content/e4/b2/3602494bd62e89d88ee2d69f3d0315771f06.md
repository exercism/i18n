# Apéndice de instrucciones

## Instrucciones específicas de SML

Los árboles binarios de búsqueda son útiles para cualquier tipo de dato ordenado, no solo para números.

La sección 2.6 de [Notes on Programming SML/NJ][notes] analiza el polimorfismo, y la sección 4.1 analiza el uso de las funciones _compare_.
