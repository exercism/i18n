# Introducción

Kotlin es un lenguaje de programación **de tipado estático** desarrollado por JetBrains. Esto significa que el tipo de las variables se define en tiempo de compilación.

## Variables

De forma similar a otros lenguajes de programación de tipado estático, el tipo de cada variable debe definirse en tiempo de compilación. Puedes evitar las declaraciones explícitas de tipo cuando el compilador puede inferirlas a partir de su contexto.

Kotlin tiene variables inmutables (`val`) y mutables (`var`). El valor de una variable inmutable no se puede cambiar después de que se asigne su valor inicial. La mayor parte del tiempo usarás este tipo de variable.

```kotlin
val robotName = "HAL-9000"
userId = "T-1000"  // This will not compile
```

El valor de una variable mutable se puede cambiar una o más veces:

```kotlin
var index = 12
print(index)  // 12

index = 100
print(index)  // 100
```

Los puntos y coma en Kotlin son opcionales, excepto en algunos casos especiales que veremos más adelante.

## Funciones

Las funciones en Kotlin se definen con la palabra clave `fun` y son _ciudadanos de primera clase_ (no está relacionado con la POO). Esto significa que puedes declararlas (las llamadas `top-level functions`) directamente en los archivos (por ejemplo, en Java solo puedes definir métodos en clases, no en archivos):

```kotlin
// This is content of the Hello.kt file

fun hello() {}
```

Las funciones pueden recibir argumentos. Cada argumento tiene un nombre y un tipo. A diferencia de las variables, el tipo de los argumentos no se puede inferir. Las funciones pueden tener cero o más argumentos:

```kotlin
fun hello() {}

fun hello(name: String) {}

fun hello(name: String, age: Int) {}
```

Las funciones de Kotlin pueden devolver un valor o no:

```kotlin
fun min(a: Int, b: Int): Int

fun countBonuses(user: User): Bonuses

fun run() {}
```

Para devolver un valor desde una función, se usa la palabra clave `return`:

```kotlin
fun getName(): String {
    return "Alice"
}
```

Las funciones pueden tener parámetros con valores predeterminados. Estos valores se usarán si se omiten donde se invoca la función:

```kotlin
fun ping(host: String = "localhost") {
    println("PING --> $host")
}

ping("exercism.io")  // PING --> exercism.io
ping()               // PING --> localhost
```

## Comentarios

Usa `//` para definir un comentario de una línea:

```kotlin
foo() // Everything after `//` will be ignored by compiler

// I will be ignored too
```

o `/*` y `*/` para definir comentarios de varias líneas:

```kotlin
/*
   This this an example
   for a multiline comment
*/
```
