# Recursos

## Módulos

Perl viene equipado con un conjunto de módulos principales que puedes encontrar listados en [perldoc](https://perldoc.perl.org/modules). Por lo general, podrás usar cualquiera de estos módulos de inmediato. (Algunas distribuciones pueden requerir que instales los módulos principales por separado).

[Awesome Perl](https://github.com/hachiojipm/awesome-perl) es una lista curada de módulos útiles, y también remite a una selección de otras listas de recomendaciones.

Hay varios instaladores de módulos disponibles para Perl, que te permitirán instalar una gran variedad de módulos disponibles en [CPAN](https://metacpan.org/).

### App::cpm
Un instalador de módulos muy rápido y sencillo.
Hay un tutorial disponible en [CPAN](https://metacpan.org/pod/App::cpm::Tutorial).

Ya lo tendrás instalado si seguiste las instrucciones de `local::lib` de la [documentación de instalación](https://exercism.org/tracks/perl5/installation).

Solo ejecuta `cpm install` para instalar los módulos requeridos de un `cpanfile`, y usa `--with-recommends` o `--with-suggested` para instalar los módulos recomendados o sugeridos, respectivamente.

Ejecuta `cpm install Module::Name` para instalar un módulo específico de forma local, o ejecuta `cpm install -g Module::Name` para instalarlo de forma global.

### App::cpanminus
El instalador de módulos más conocido y más usado que existe.
Las instrucciones de instalación están en [CPAN](https://metacpan.org/pod/App::cpanminus).

Ejecuta `cpanm -L local --installdeps .` para instalar los módulos requeridos
de un `cpanfile`.
Ejecuta `cpanm -L local Module::Name` para instalar un módulo específico
de forma local, o ejecuta `cpanm Module::Name` para instalarlo de forma global.

## Estilo de código y linting

Si buscas buenos consejos generales sobre cómo programar en Perl, [Perl Best Practices][PBP] de Damian Conway es una buena referencia.

Para dar formato a tu código, puedes usar el módulo
[Perl::Tidy][PerlTidy].

Luego puedes usar el programa de utilidad `perltidy` que se proporciona
para reformatear tu código.

    # modify file in-place and save old version as some_script.pl.bak
    $ perltidy -b some_script.pl

`perltidy` tiene *muchísimas* opciones de configuración para todos los gustos. Están
documentadas [aquí][perltidyDocs].

También existe [tidyview], una interfaz visual que te permite
ajustar las distintas opciones y ver el resultado de inmediato.

Si quieres hacer cumplir ciertas prácticas de programación, también existe
[Perl::Critic][perlcritic]. Viene con las reglas descritas en
el libro *Perl Best Practices* que mencionamos antes, pero existen muchísimos
plugins, y se puede personalizar para adaptarlo a cualquier
regla de programación interna.

Para usarlo:

    $ perlcritic some_script.pl

La herramienta tiene muchísimos ajustes de configuración; consulta su
[documentación][perlcriticdocs] para conocer todos los detalles.
