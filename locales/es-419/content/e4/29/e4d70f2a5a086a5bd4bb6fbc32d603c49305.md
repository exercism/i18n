# Introducción

## Comparación

En JavaScript, los números se pueden comparar con los siguientes operadores relacionales y de igualdad.

| Comparación             | Operador  |
| ----------------------- | --------- |
| Mayor que               | `a > b`   |
| Mayor o igual que       | `a >= b`  |
| Menor que               | `a < b`   |
| Menor o igual que       | `a <= b`  |
| Igual (estricto)        | `a === b` |
| Distinto (estricto)     | `a !== b` |

El resultado de la comparación siempre es un valor Boolean: `true` o `false`.

```javascript
1 < 3;
// => true

2 !== 2;
// => false

1 === 1.0;
// => true
// All numbers are floating-points, so this is different syntax for
// the exact same value.
```

En JavaScript, los operadores de comparación anteriores también se pueden usar para comparar strings.
En ese caso, se aplica un orden de diccionario (lexicográfico).
Puedes encontrar una lista del orden exacto de todos los caracteres [aquí][utf-16-list].

```javascript
'Apple' > 'Pear';
// => false

'a' < 'above';
// => true

'a' === 'A';
// => false
```

## Condicionales

Una forma común de ejecutar lógica de manera condicional en JavaScript es el condicional.
Consiste en la palabra clave `if`, una condición encerrada entre paréntesis y un bloque de código encerrado entre llaves.
El bloque de código solo se ejecutará si la condición se evalúa como `true`.

```javascript
if (condition) {
  // code that is executed if "condition" is true
}
```

Se puede usar por sí solo o combinarse con la palabra clave `else`.

```javascript
if (condition) {
  // code that is executed if "condition" is true
} else {
  // code that is executed otherwise
}
```

Para anidar otra condición dentro de la sentencia `else`, puedes usar `else if`.

```javascript
if (condition1) {
  // code that is executed if "condition1" is true
} else if (condition2) {
  // code that is executed if "condition2" is true
  // but "condition1" was false
} else {
  // code that is executed otherwise
}
```
