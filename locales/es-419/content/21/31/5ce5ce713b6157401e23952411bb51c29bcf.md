# Instrucciones

Estás de vuelta en la cocina, mejorando la receta de lasaña de
[La deliciosa lasaña de Leah][lasagna]. Las tareas de este ejercicio te piden
manejar varios argumentos a la vez, y es justo ahí cuando los *locals*, los
enlaces con nombre de Factor, demuestran para qué sirven.

## 1. Determina el estado de cocción

Define `cooking-status` para que tome de la pila una lectura del temporizador y
devuelva un string con el estado.

- `0` → `"Lasagna is done."`
- `f` (el temporizador nunca se puso) → `"You forgot to set the timer."`
- cualquier otro número → `"Not done, please wait."`

```factor
12 cooking-status .   ! => "Not done, please wait."
0 cooking-status .    ! => "Lasagna is done."
f cooking-status .    ! => "You forgot to set the timer."
```

## 2. Estima el tiempo de preparación

Define `preparation-time` para que tome un array con los nombres de las capas y
un promedio de minutos por capa, y devuelva el tiempo total de preparación.

```factor
{ "sauce" "noodles" "sauce" "meat" "mozzarella" "noodles" } 3 preparation-time .
! => 18
```

## 3. Calcula los fideos y la salsa necesarios

Define `quantities` para que tome un array con los nombres de las capas y
devuelva *dos* valores: los gramos de fideos necesarios (50 g por cada capa de
fideos) y los litros de salsa necesarios (`1/5` de litro por cada capa de
salsa).

```factor
{ "sauce" "noodles" "sauce" "meat" "mozzarella" "noodles" } quantities .s
! => 100
! => 2/5
```

## 4. Agrega el ingrediente secreto

Tu amigo te manda una lista de ingredientes; el *último* elemento es su
secreto. Define `add-secret-ingredient` para que tome su lista y la tuya, y
devuelva tu lista con el secreto agregado al final.

```factor
{ "noodles" "sauce" "mozzarella" "kampot pepper" }
{ "noodles" "meat" "sauce" "mozzarella" }
add-secret-ingredient .
! => { "noodles" "meat" "sauce" "mozzarella" "kampot pepper" }
```

## 5. Escala la receta

La receta del libro rinde dos porciones. Define `scale-recipe` para que tome
una receta (un hashtable que va del nombre de cada ingrediente a su cantidad) y
un número de porciones objetivo, y devuelva una receta nueva escalada de forma
adecuada.

```factor
H{ { "noodles" 200 } { "sauce" 1/2 } { "mozzarella" 1 } { "meat" 100 } }
4 scale-recipe .
! => H{ { "noodles" 400 } { "sauce" 1 } { "mozzarella" 2 } { "meat" 200 } }
```
