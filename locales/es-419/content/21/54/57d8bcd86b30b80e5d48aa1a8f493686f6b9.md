# Apéndice de instrucciones

## Palabras

`convert ( rows -- str )` toma la cuadrícula como un array de strings,
un string por fila, y devuelve los dígitos reconocidos como un único
string. En la salida, varias filas de celdas se unen con comas (`,`).

## Errores

Lanza uno de estos strings (tal cual) si el argumento está mal formado:

- `"Number of input lines is not a multiple of four"`
- `"Number of input columns is not a multiple of three"`
