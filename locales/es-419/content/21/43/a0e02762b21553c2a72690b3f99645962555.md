# Introducción

En Clojure, vincular un valor a un nombre se conoce como _var_. Las vars de nivel superior (globales) son similares a las constantes de otros lenguajes.

Las vars de nivel superior se definen usando `def`:

```clojure
(def fingers 10)

fingers
;;=> 10
```

Puedes usar `defn` para definir una función que toma cero o más argumentos. Esta es una función que sumaría 2 números:

```clojure
(defn add [x y]
  (+ x y))
```

Esta función toma 2 argumentos que se colocan en el vector `[x y]`, seguidos del *cuerpo* de la función, que puede contener cualquier número de expresiones. El valor que devuelve siempre es el resultado de evaluar la última expresión del cuerpo, `(+ x y)`. Esta expresión es una lista que representa una llamada a función. El primer elemento de la lista es la función `+`, que se evalúa usando los siguientes elementos, `x` y `y`, como argumentos.

La función `add` definida arriba se llama de la misma manera:

```clojure
(add 2 3)
;;=> 5
```

Las funciones y los valores en Clojure solo se pueden usar _después_ de haber sido definidos, es decir, las formas siempre se evalúan en el orden en que aparecen.

En Clojure, los espacios en blanco no tienen ningún significado aparte del de dar formato.

Las funciones y las vars de Clojure se organizan en espacios de nombres. Un espacio de nombres agrupa funcionalidad relacionada y se define usando la macro `ns`:

```clojure
(ns calculator)

(def pi 3.14)

(defn add [x y]
  (+ x y))
```

Clojure admite dos tipos de comentarios. Los comentarios de una sola línea van precedidos por `;` y la forma `comment` se usa para evitar la evaluación de todo lo que hay entre `(comment` y `)`.
