Como aspirante a maga, Elyse necesita practicar algunos conceptos básicos.
Tiene un mazo de cartas que quiere manipular.

Para facilitar un poco las cosas, solo usa las cartas del 1 al 10.

## 1. Recupera una carta del mazo

Devuelve la carta en la posición `idx` del mazo dado.

```julia-repl
julia> idx = 2;

julia> card([1, 3, 4, 1], idx)
3
```

## 2. Intercambia una carta del mazo

Intercambia la carta en la posición `idx` por la nueva carta proporcionada y devuelve el mazo ajustado.
Ten en cuenta que esto mutará (cambiará) el vector de entrada, y está bien.

```julia-repl
julia> idx = 2; new_card = 6;

julia> replace_card!([1, 3, 4, 1], idx => new_card)
[1, 6, 4, 1]
```

## 3. Inserta una carta en la parte superior del mazo

Inserta una nueva carta en la parte superior del mazo y devuelve el mazo.

```julia-repl
julia> new_card = 8;

julia> insert_card_at_top!([1, 3, 4, 1], new_card)
[1, 3, 4, 1, 8]
```

## 4. Elimina una carta del mazo

Elimina la carta en la posición `idx` del mazo y devuelve el mazo.

```julia-repl
julia> idx = 2;

julia> remove_card!([1, 3, 4, 1], idx)
[1, 4, 1]
```

## 5. Elimina la carta superior del mazo

Elimina la carta de la parte superior del mazo y devuelve el mazo.

```julia-repl
julia> remove_card_from_top!([1, 3, 4, 1])
[1, 3, 4]
```

## 6. Inserta una carta en la parte inferior del mazo

Inserta una nueva carta en la parte inferior del mazo y devuelve el mazo.

```julia-repl
julia> new_card = 8;

julia> insert_card_at_bottom!([1, 3, 4, 1], new_card)
[8, 1, 3, 4, 1]
```

## 7. Elimina una carta de la parte inferior del mazo

Elimina la carta de la parte inferior del mazo y devuelve el mazo.

```julia-repl
julia> remove_card_at_bottom!([1, 3, 4, 1])
[3, 4, 1]
```

## 8. Comprueba el tamaño del mazo

Comprueba si el tamaño del mazo es igual a un `deck_size` dado.

```julia-repl
julia> deck_size = 4;

julia> check_deck_size([1, 3, 4, 1], deck_size)
true

julia> check_deck_size([1, 3, 4, 1, 5], deck_size)
false
```
