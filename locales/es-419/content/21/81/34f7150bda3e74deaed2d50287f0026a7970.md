# Consejos

## 1. Determinar cuánto tiempo toma mezclar un jugo

- Crea una [sentencia switch][mdn-switch] para la variable `name`.
- Los distintos casos deben representar los distintos nombres de jugos.
- Usa el caso `default` para cubrir todos los demás nombres.
- Recuerda que los casos [continúan al siguiente por defecto][mdn-fallthrough], así que asegúrate de hacer algo para evitarlo.

## 2. Reabastecer el suministro de gajos de lima

- Usa un [bucle while][mdn-while] para cortar una lima tras otra.
- Repasa el [concepto de arrays][concept-arrays] para encontrar una forma de quitar las limas de la lista en el orden correcto.
- Crea una [sentencia switch][mdn-switch] para obtener el número de gajos según el tamaño de una lima.
- Necesitas llevar la cuenta de dos cosas: cuántas limas ya se cortaron y cuántos gajos aún faltan.
- Puedes combinar dos condiciones para el bucle usando [operadores lógicos][concept-booleans].

## 3. Terminar el turno

- Usa un [bucle do-while][mdn-do-while] para atender un pedido tras otro.
- Repasa el [concepto de arrays][concept-arrays] para encontrar una forma de quitar las bebidas de la lista en el orden correcto.
- Ya tienes una función que determina el tiempo que toma preparar una bebida; úsala para reducir el tiempo restante en consecuencia.
- Puedes combinar dos condiciones para el bucle usando [operadores lógicos][concept-booleans].
