# Diccionarios

Los diccionarios en Cairo son almacenes de clave-valor similares a los mapas o las tablas hash de otros lenguajes.

Sin embargo, tienen algunas características únicas debido al modelo de memoria inmutable de Cairo.

## Concepto central

El tipo `Felt252Dict<T>` proporciona la funcionalidad de diccionario en Cairo, con `felt252` como tipo de clave y cualquier tipo admitido `T` como tipo de valor.

```rust
use core::dict::Felt252Dict;

fn main() {
    let mut balances: Felt252Dict<u64> = Default::default();
    balances.insert('Alice', 100);
    let balance = balances.get('Alice'); // Returns 100
}
```

## Características importantes

A diferencia de los diccionarios de otros lenguajes, los diccionarios de Cairo tienen algunas propiedades especiales:

1. Las claves deben ser valores `felt252`.
2. Todas las claves empiezan implícitamente con un valor de cero.
3. No puedes eliminar entradas: solo puedes actualizar valores.
4. Los valores deben implementar el trait `Felt252DictValue`.

## Nota sobre el rendimiento

Debido al modelo de memoria inmutable de Cairo, las operaciones sobre diccionarios tienen una complejidad $O(n)$, donde $n$ es el número de operaciones realizadas sobre el diccionario.

Cada operación crea una nueva entrada que registra el cambio.

## Trabajar con tipos complejos

Para los tipos que no implementan `Felt252DictValue` (como los arrays o los structs), puedes envolverlos en `Nullable<T>`:

```rust
let mut dict: Felt252Dict<Nullable<Span<felt252>>> = Default::default();
dict.insert(0, NullableTrait::new(array![1, 2, 3].span()));
```

## Gestión de la memoria

Los diccionarios implementan el trait `Destruct`, lo que significa que se «squashean» automáticamente (se validan y se optimizan) cuando salen del ámbito.

Esto es parte del sistema de pruebas de Cairo y ocurre tras bambalinas.

Recuerda: aunque los diccionarios pueden parecer menos eficientes que en otros lenguajes, están diseñados de esta manera para funcionar con el modelo de memoria único de Cairo y los requisitos de su sistema de pruebas.
