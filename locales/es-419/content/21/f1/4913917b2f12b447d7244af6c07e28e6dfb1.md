# Pistas

## 1. Determina cuántas cartas de cierto tipo hay en la baraja

- Primero, crear una variable de tipo entero para llevar la cuenta de las cartas del tipo indicado.
- Luego, como se menciona en las instrucciones, usar [forEach][mdn-foreach] para recorrer la baraja.
- Incrementar tu contador en el callback cuando encuentres una carta del tipo deseado.

## 2. Determina cuántas cartas impares o pares hay

- Primero, crear una variable de tipo entero para llevar la cuenta de las cartas del tipo deseado (impar o par).
- Luego, como se menciona en las instrucciones, usar [for...of][mdn-for-of] para recorrer la baraja.
- El residuo al dividir entre 2 te dice si un número es impar o par.
  Puedes calcular el residuo con el [operador de módulo][mdn-modulo] `%`.
- Incrementar tu contador cuando encuentres un número con el residuo deseado.

[mdn-foreach]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array/forEach
[mdn-for-of]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/for...of
[mdn-modulo]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Remainder
