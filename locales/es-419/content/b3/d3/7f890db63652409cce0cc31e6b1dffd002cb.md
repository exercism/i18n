# Instrucciones

En este ejercicio, vas a escribir algo de código que te ayude a prepararte para comprar un vehículo.

Tienes tres tareas: una para determinar si vas a necesitar obtener una licencia, otra para ayudarte a elegir entre dos vehículos y otra para estimar el precio aceptable de un vehículo usado.

## 1. Determina si vas a necesitar una licencia de conducir

Algunos tipos de vehículos requieren una licencia de conducir para manejarlos.
Supón que solo los tipos `car` y `truck` requieren licencia; todo lo demás se puede manejar sin licencia.

Implementa la función `needs_license(kind)`, que recibe el tipo de vehículo y devuelve un Boolean que indica si necesitas una licencia para ese tipo de vehículo.

```R
needs_license("car");
# => TRUE

needs_license("bike");
# => FALSE
```

## 2. Elige entre dos vehículos posibles para comprar

Evalúa tus opciones de vehículos disponibles.
Logras reducirlas a dos opciones, pero necesitas ayuda para tomar la decisión final.
Para eso, implementa la función `choose_vehicle(option1, option2)`, que recibe dos vehículos como argumentos y devuelve una decisión que es simplemente la opción que aparece primero en orden alfabético.

```R
choose_vehicle("Wuling Hongguang", "Toyota Corolla");
# =>  "Toyota Corolla"

choose_vehicle("Volkswagen Beetle", "Volkswagen Golf");
# =>  "Volkswagen Beetle"
```

## 3. Calcula una estimación del precio de un vehículo usado

Ahora que tomaste tu decisión, quieres asegurarte de obtener un precio justo en la agencia.
Como te interesa comprar un vehículo usado, el precio depende de qué tan viejo sea el vehículo.
Para una estimación aproximada, supón que si el vehículo tiene menos de 3 años, cuesta el 80% del precio original que tenía cuando era nuevo.
Si tiene más de 10 años, cuesta el 50%.
Si el vehículo tiene al menos 3 años pero no más de 10, cuesta el 70% del precio original.

Implementa la función `calculate_resale_price(original_price, age)`.
Recibe el precio original y la edad del vehículo como argumentos y devuelve el precio estimado en la agencia.

```R
calculate_resale_price(1000, 1);
# => 800

calculate_resale_price(1000, 5);
# => 700

calculate_resale_price(1000, 15);
# => 500
```
