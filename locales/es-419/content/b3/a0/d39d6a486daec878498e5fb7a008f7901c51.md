# Acerca de

El ámbito de un valor tiene que ver con el lugar del programa donde se puede acceder a ese valor.

## Los cuatro tipos de ámbito: bloque, función, prototipo de función, archivo

### Ámbito de bloque

Solo se puede acceder a un valor con ámbito de bloque desde dentro del bloque donde se define.
Para obtener más información sobre los bloques, consulta el [concepto de bloque](../blocks/introduction.md#Introduction).

### Ámbito de función

El ámbito de función es un tipo especial de ámbito que se aplica a las etiquetas que se usan con las sentencias `goto`.
Dos etiquetas con el mismo nombre no se pueden usar en la misma función, aunque las etiquetas se definan en bloques separados dentro de la función.

### Ámbito del prototipo de función

El ámbito del prototipo de función es otro tipo especial de ámbito que se aplica solo a los parámetros nombrados dentro del prototipo (también llamado declaración, teniendo en cuenta que no todas las declaraciones son prototipos).
El nombre de un parámetro suele ser opcional en una declaración de función.
El ámbito de un nombre solo es relevante dentro de la declaración.
En el siguiente ejemplo, el identificador `len` se define y luego se hace referencia a él más adelante en la declaración de la función.

```c
#include <stdio.h>

// len is defined and then referred to
void my_func(int len, int numbers[len]);

int main() {
    int numbers[2];
    numbers[0] = 1;
    numbers[1] = 2;
    my_func(2, numbers);
}

void my_func(int length, int numbers[length]) {
    // prints numbers should have 2 elements
    printf("numbers should have %d elements", length);
}
```

Ten en cuenta que, dentro de una declaración, los nombres deben coincidir cuando se hace referencia a la misma variable.
Si `my_func` se declarara como `void my_func(int len, int numbers[length]);`, se generaría un error de compilación parecido a

```
/tmp/scn62kKPEZ.c:4:35: error: 'length' undeclared here (not in a function)
    3 | void my_func(int len, int numbers[length]);
      |                                   ^~~~~~
/tmp/scn62kKPEZ.c: In function 'main':
/tmp/scn62kKPEZ.c:10:16: error: type of formal parameter 2 is incomplete
   10 |     my_func(2, numbers);
```

Una definición de función no tiene que usar el mismo nombre para un parámetro que el que se usó en la declaración de la función.
En el ejemplo anterior, se usó `len` en la declaración y `length` en la definición, lo que demuestra que el ámbito del identificador `len` solo abarcaba la declaración de la función.

### Ámbito de archivo

Se puede acceder a un valor con ámbito de archivo desde cualquier lugar del archivo.
Cualquier valor de este tipo se define fuera de una función.
