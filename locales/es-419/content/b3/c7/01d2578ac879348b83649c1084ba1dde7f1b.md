# Acerca de

Nos referiremos al _lenguaje_ como **AWK** y al _ejecutable_ que interpreta los programas de AWK como **`awk`** o **`gawk`**.

## Patrones y acciones

Un programa de AWK se compone de **pares patrón-acción**

```awk
pattern1 { action1 }
pattern2 { action2 }
...
```

Un **patrón** puede ser una expresión regular con la que se compara la entrada.
También puede ser cualquier expresión que dé como resultado un valor verdadero/falso.

Una **acción** es uno o más comandos de AWK.
Las llaves que la encierran son obligatorias.

Si el resultado del patrón es _verdadero_, se evalúa la acción correspondiente.

## Registros y campos

AWK analiza la entrada como una serie de **registros**.
Cada registro se divide en cero o más **campos**.

El comportamiento predeterminado es:

- dividir la entrada en registros usando el salto de línea como «separador de registros», de modo que cada _línea_ es un registro.
- dividir el registro en campos usando los espacios en blanco como «separador de campos», de modo que cada _palabra_ es un campo.

## Patrones y acciones, continuación

El patrón se puede omitir, en cuyo caso la acción se evalúa _para cada registro de entrada_.

La acción se puede omitir, en cuyo caso la acción predeterminada es imprimir el registro actual.

### Patrones especiales

Hay dos patrones especiales que se usan con frecuencia.

- `BEGIN` evalúa la acción asociada antes de que se consuma cualquier entrada.
- `END` evalúa la acción asociada después de que se consuma toda la entrada.

## Variables de campo

Haces referencia a los campos como `$1`, `$2`, `$3`, etc.

El registro actual es `$0`.

~~~~exercism/caution
Para ser explícitos, estos no son estrictamente «variables».
El `$` se puede considerar como un _operador_ que obtiene el valor del número de campo dado.
Profundizaremos en esto en conceptos posteriores.
~~~~

Aquí hay otras variables integradas que se usan con frecuencia.

### Variables integradas que controlan el análisis de la entrada

- `RS` es el separador de registros de entrada.
  Como se mencionó, su valor predeterminado es un salto de línea.
- `FS` es el separador de campos de entrada.

Estas variables suelen establecerse en el bloque de acción `BEGIN`.

### Variables integradas que transmiten información

AWK establece estas variables automáticamente durante la ejecución del programa.

- `NF` almacena el número de campos del registro actual.
  - Para obtener el valor del último campo, usa `$NF`.
- `NR` almacena el número del registro actual.
  - Cuando se procesan varios archivos de entrada, `NR` contiene el número total de registros procesados hasta el momento.
- `FNR` almacena el número del registro actual del archivo de entrada actual.
  - Para ilustrar la diferencia entre NR y FNR, aquí hay un modismo común de AWK.
    ```awk
    NR == FNR {action}
    ```
    Esto significa «si el número de registro acumulado es igual al número de registro del archivo actual».
    Esto solo puede ser verdadero para los registros del _primer archivo de entrada_.

## Veracidad

AWK usa el mismo concepto de veracidad que C:

- El número `0` es falso.
- Cualquier otro número es verdadero.

Como AWK es un lenguaje de procesamiento de texto, los valores de verdad se extienden a los strings.

- Un string vacío `""` es falso.
- Cualquier string que no esté vacío es verdadero.

~~~~exercism/note
> AWK usa el mismo concepto de veracidad que C

AWK se originó en Bell Labs en la década de 1970, en el mismo entorno donde se inventó C.
C tuvo una gran influencia en la sintaxis de AWK.
~~~~

~~~~exercism/caution
Una particularidad a la que hay que prestar atención

- El número `0` es falso.
- ¡El string `"0"` que no está vacío es verdadero!

Profundizaremos más en los tipos de datos de AWK en conceptos posteriores.
~~~~

## Comentarios

Los comentarios comienzan con el carácter `#` y se extienden hasta el final de la línea.

## Cómo darle entrada a `awk`

`awk` puede leer la entrada desde archivos o desde la entrada estándar.
Cualquiera de estas técnicas funciona.

```sh
awk '/regex/ {print $1}' file1 file2 ...

awk '/regex/ {print $1}' < file

some_command_here | awk '/regex/ {print $1}'
```

## Ejemplos

En los sistemas tipo Unix, `/etc/passwd` contiene información sobre los usuarios.
Cada usuario se describe en una línea aparte, con los campos separados por dos puntos.

Para listar los nombres de usuario:

```sh
awk '
    BEGIN { FS = ":" }
    { print $1 }
' /etc/passwd
```

Fíjate que la acción `{print $1}` no tiene patrón, así que se ejecuta para cada registro.

Si queremos limitar la salida a solo los usuarios que usan bash como shell de inicio de sesión, podemos hacer lo siguiente:

```sh
awk '
    BEGIN { FS = ":" }
    $7 == "/bin/bash" { print $1 }
' /etc/passwd
```

### Algunos ejemplos más

Aquí hay algunos programas de awk que producen los mismos resultados que otros comandos comunes de Unix.

- Mostrar un archivo

    ```sh
    cat file.txt

    awk '1' file.txt
    ```

- Buscar patrones en un archivo

    ```sh
    grep 'foo.*bar' file.txt

    awk '/foo.*bar/' file.txt
    ```

- Mostrar solo unas pocas líneas al inicio de un archivo

    ```sh
    head -n 20 file.txt

    awk '
        1
        NR == 20 {exit}
    ' file.txt
    ```

- Reemplazar texto en un archivo

    ```sh
    sed 's/foo/bar/' file.txt

    awk '{sub(/foo/, "bar")};1' file.txt
    # or more readably
    awk '
        {
            sub(/foo/, "bar")
            print
        }
    ' file.txt
    ```
