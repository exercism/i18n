# Instrucciones

Refactoriza un analizador de Markdown.

El ejercicio de markdown es un ejercicio de refactorización.
Hay código que analiza un string dado con [sintaxis de Markdown][markdown] y devuelve el HTML asociado a ese string.
Aunque este código está escrito de forma confusa y es difícil de seguir, de alguna manera funciona y ¡todas las pruebas pasan!
Tu reto es reescribir este código para que sea más fácil de leer y mantener, sin dejar de asegurarte de que todas las pruebas sigan pasando.

Sería útil que dejaras notas en comentarios sobre lo que hiciste en tu refactorización, para que quienes revisen puedan verlo, pero no es estrictamente necesario.
¡Lo más importante es mejorar el código!

[markdown]: https://docs.github.com/en/get-started/writing-on-github/getting-started-with-writing-and-formatting-on-github/basic-writing-and-formatting-syntax
