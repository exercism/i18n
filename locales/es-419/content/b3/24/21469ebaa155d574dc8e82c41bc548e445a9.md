# Acerca de

Una **palabra** es el nombre que Factor le da a una función. Conociste la pila de datos y las palabras de reordenamiento en `basics`; aquí defines tus propias palabras que calculan con sus argumentos.

```factor
: square ( x -- x*x ) dup * ;
: hello  ( -- )       "Hello, world!" print ;
: max3   ( a b c -- max ) max max ;
```

Una definición es `:`, un efecto de pila, el cuerpo y luego `;`. Los nombres dentro de `( … -- … )` son para quien lee; lo que el compilador verifica es el *número* de argumentos y resultados. Una discrepancia es un error en tiempo de compilación, lo que atrapa una clase de bugs que serían errores en tiempo de ejecución en un lenguaje de tipado dinámico sin este tipo de declaración.

Las palabras de aritmética de enteros `+`, `-`, `*` vienen del vocabulario `math` y cada una consume dos números de la parte superior de la pila. La parte superior de la pila es el operando de la derecha, así que `8 3 -` calcula `8 - 3`.

`CONSTANT:` define un nombre para un valor fijo; llamar al nombre apila el valor, exactamente igual que cualquier otra palabra. Coloca las constantes al principio del archivo, antes de cualquier palabra que las use.

El cuerpo de una palabra puede llamar a cualquier palabra que ya esté en el ámbito: definiciones anteriores en el mismo archivo, palabras de vocabularios importados y las constantes que declaraste. Componer palabras pequeñas y de un solo propósito es la forma normal de construir un programa.

Por convención:

- Las palabras y las constantes usan `lowercase-kebab-case`.
- Los predicados terminan en `?` y producen un Boolean (`even?`, `empty?`).
- Las palabras que mutan su argumento suelen compartir el nombre con la versión no mutante, y solo se distinguen por el contexto.
