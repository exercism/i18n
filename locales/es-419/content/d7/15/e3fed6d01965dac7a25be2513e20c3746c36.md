# Instalación

Crystal está disponible en Linux, macOS y Windows.

Ten en cuenta que el soporte de Crystal para Windows es experimental.
Esto significa que puede haber algunos casos límite que no funcionen y que quizá no sea lo ideal para casos de uso en producción.
Sin embargo, para Exercism y el uso básico, Windows nativo debería ser utilizable en la mayoría de los casos.

Si buscas una experiencia que no sea de vista previa para desarrollar en Windows, te recomendamos usar [WSL (Windows Subsystem for Linux)][wsl].
Es una funcionalidad **gratuita** de Windows 10 (1903+) y 11 que permite ejecutar un entorno de Linux sin necesidad de una máquina virtual.

Usa una de las [guías de instalación][installation guides] para obtener instrucciones sobre cómo instalar Crystal.

[wsl]: https://learn.microsoft.com/en-us/windows/wsl/install
[installation guides]: https://crystal-lang.org/install/
