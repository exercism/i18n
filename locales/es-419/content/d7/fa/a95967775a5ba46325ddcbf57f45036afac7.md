# Introducción

Las conversiones de tipos en Cairo te permiten transformar datos de un tipo a otro, lo que habilita una manipulación de datos flexible y segura.

## Conceptos básicos

Cairo ofrece varios mecanismos para convertir tipos:

### Conversión directa

Para tipos numéricos compatibles, puedes usar la conversión directa:

```rust
let small_number: u8 = 42;
let big_number: u32 = small_number.into();
```

### El trait Into

El trait `Into` permite convertir de un tipo a otro:

```rust
let value: u16 = 100;
let converted: u32 = value.into();
```

### El trait TryInto

Para conversiones que podrían fallar, usa `TryInto`, que devuelve un `Option`:

```rust
let large_value: u32 = 70000;
let small_value: Option<u16> = large_value.try_into();

match small_value {
    Option::Some(v) => println!("Converted: {}", v),
    Option::None => println!("Conversion failed"),
}
```

## Conversiones de tipos personalizadas

Puedes implementar `Into` para tus propios tipos:

```rust
#[derive(Drop)]
struct Celsius {
    value: i32,
}

#[derive(Drop)]
struct Fahrenheit {
    value: i32,
}

impl CelsiusIntoFahrenheit of Into<Celsius, Fahrenheit> {
    fn into(self: Celsius) -> Fahrenheit {
        Fahrenheit { value: (self.value * 9) / 5 + 32 }
    }
}
```

## Consideraciones de seguridad

- Usa `TryInto` cuando la conversión podría fallar (por ejemplo, de tipos grandes a pequeños)
- Usa `Into` cuando la conversión siempre tiene éxito
- Maneja siempre los casos `Option::None` que devuelve `TryInto`
- Ten en cuenta el desbordamiento y el subdesbordamiento al convertir entre tipos con signo y sin signo
