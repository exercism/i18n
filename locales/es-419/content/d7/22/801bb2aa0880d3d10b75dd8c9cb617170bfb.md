# Anexo de instrucciones

## Memoria reservada

Los bytes 1024-1279 de la memoria lineal están reservados para el string de entrada.

El string de entrada se puede modificar en el mismo lugar si lo deseas.

## Formato de entrada

Los codones se entregan concatenados y sin relleno, como un string.

## Formato de salida

Devuelve la secuencia de proteínas como un string terminado en nulo, con un carácter de salto de línea después de cada proteína.

Un ejemplo de salida sería `"Methionine\nPhenylalanine\nSerine\n"`

Si la entrada no es válida, devuelve un string vacío.
