# Introducción

Clases como `LocalDate` y `LocalDateTime` describen un _punto_ en el tiempo.
El paquete `java.time` también tiene dos clases que describen una _cantidad_ de tiempo:

- `java.time.Period` es una cantidad de tiempo en años, meses y días, como «2 meses y 5 días».
- `java.time.Duration` es una cantidad de tiempo en horas, minutos, segundos, milisegundos y nanosegundos, como «1 hora y 30 minutos».

Un `Period` sigue el calendario, así que se usa con fechas y con valores de fecha y hora.
Un `Duration` mide un tiempo exacto, así que se usa con horas y con valores de fecha y hora, pero no con fechas.

```exercism/note
Al igual que las demás clases de `java.time`, `Period` y `Duration` son inmutables.
Los métodos que parecen modificarlas devuelven en su lugar una instancia _nueva_.
```

## `Period`

Un `Period` se crea con uno de sus métodos de fábrica estáticos:

```java
Period.ofDays(10);
// => P10D

Period.ofMonths(3);
// => P3M

Period.of(1, 2, 15);
// => P1Y2M15D
```

El resultado de `toString()` usa la notación [ISO-8601][iso-8601-durations]: `P` (de «periodo»), seguida del número de años (`Y`), meses (`M`) y días (`D`).

Un periodo se puede sumar o restar a una fecha:

```java
LocalDate date = LocalDate.of(2024, 3, 10);

date.plus(Period.ofMonths(2));
// => 2024-05-10

date.minus(Period.ofDays(10));
// => 2024-02-29
```

Como los meses tienen distinta duración, al sumar meses puedes caer en un día que no existe.
En ese caso, el resultado se ajusta al último día válido del mes:

```java
LocalDate.of(2025, 1, 31).plus(Period.ofMonths(1));
// => 2025-02-28
```

`Period.between()` devuelve el periodo que va de una fecha (incluida) a otra (excluida):

```java
LocalDate start = LocalDate.of(2023, 3, 10);
LocalDate end = LocalDate.of(2024, 5, 25);

Period period = Period.between(start, end);
// => P1Y2M15D

period.getYears();
// => 1
period.getMonths();
// => 2
period.getDays();
// => 15
```

## Contar unidades con `ChronoUnit`

Un `Period` guarda por separado sus años, meses y días.
Por eso `getDays()` devuelve solo la _parte_ de días del periodo, no el total de días.
Para contar el total de una sola unidad entre dos fechas, usa el método `between()` de [`java.time.temporal.ChronoUnit`][chronounit-docs]:

```java
LocalDate start = LocalDate.of(2024, 1, 15);
LocalDate end = LocalDate.of(2024, 3, 20);

Period.between(start, end);
// => P2M5D

Period.between(start, end).getDays();
// => 5

ChronoUnit.DAYS.between(start, end);
// => 65
```

El resultado es negativo cuando la segunda fecha es anterior a la primera:

```java
ChronoUnit.DAYS.between(end, start);
// => -65
```

## `Duration`

Un `Duration` también se crea con métodos de fábrica estáticos:

```java
Duration.ofMinutes(90);
// => PT1H30M

Duration.ofHours(2).plusMinutes(15);
// => PT2H15M
```

En la notación ISO-8601, la `T` separa la parte de fecha de la parte de hora, y por eso las duraciones se escriben como `PT...`.

Una duración se puede sumar o restar a una fecha y hora:

```java
LocalDateTime start = LocalDateTime.of(2024, 3, 10, 22, 30);

start.plus(Duration.ofMinutes(90));
// => 2024-03-11T00:00
```

`Duration.between()` devuelve la cantidad exacta de tiempo entre dos fechas y horas:

```java
LocalDateTime checkIn = LocalDateTime.of(2024, 3, 10, 18, 5);
LocalDateTime checkOut = LocalDateTime.of(2024, 3, 10, 19, 40);

Duration.between(checkIn, checkOut);
// => PT1H35M
```

Una duración se puede convertir a una sola unidad con métodos como `toHours()`, `toMinutes()` y `toSeconds()`.
Estos devuelven la cantidad _total_ en esa unidad, redondeada hacia abajo:

```java
Duration duration = Duration.ofMinutes(95);

duration.toHours();
// => 1
duration.toMinutes();
// => 95
```

Para dividir una duración en sus partes, como en un reloj, usa los métodos `toXxxPart()`:

```java
Duration duration = Duration.ofMinutes(95);

duration.toHoursPart();
// => 1
duration.toMinutesPart();
// => 35
```
