# Etiquetas del analizador

Las etiquetas del analizador se usan para identificar _cómo_ se resolvió una solución.

Estas etiquetas se pueden usar para:

- Vincular una solución con enfoques
- Vincular una solución con conceptos
- Buscar soluciones con ciertas etiquetas

## Formato

Una etiqueta es un string que tiene el formato: `<category>:<thing>`.

Soportamos cuatro categorías distintas, de mayor a menor nivel:

| Categoría   | Descripción                                     | Especificidad                              | Ejemplos                              |
| ----------- | ----------------------------------------------- | ------------------------------------------ | ------------------------------------- |
| `paradigm`  | Un [paradigma de programación][programming-paradigms] | De muy alto nivel, no específico de un track | `imperative`, `functional`            |
| `technique` | Una técnica que se usa                          | De alto nivel, la mayoría no será específica de un track | `recursion`, `immutability`           |
| `construct` | Una construcción del lenguaje                   | Muchas no serán específicas de un track    | `bitwise-and`, `for-loop`             |
| `uses`      | Uso específico del lenguaje, como tipos o métodos | De bajo nivel, específico de un track      | `DateTime.add_seconds`, `IEnumerable` |

Algunas etiquetas de ejemplo:

- `paradigm:functional`
- `technique:recursion`
- `construct:bitwise-and`
- `uses:DateTime.add_seconds`

## Etiquetas de uso común

Si bien cada track es libre de etiquetar las soluciones como quiera, te recomendamos intentar usar la siguiente lista de etiquetas de uso común cuando sea posible.
Usar un conjunto común de etiquetas nos permitirá hacer cosas interesantes, como vincular soluciones entre tracks.
