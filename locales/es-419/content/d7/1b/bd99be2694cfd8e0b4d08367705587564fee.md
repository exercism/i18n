# Instrucciones

Tu amigo Kojo es un gran fanático de los números.
Tiene un sitio web pequeño llamado «fun-with-numbers».
Kojo no es muy bueno programando, así que te pidió ayuda.

Vas a crear dos funciones auxiliares para nuevos juegos de números en el sitio web de Kojo, y una tercera para validar cierta entrada que el usuario puede escribir.

## 1. Calcula la suma de los números de la máquina tragamonedas

Uno de los juegos del sitio web de Kojo se parece a una máquina tragamonedas que muestra dos grupos de ruedas con dígitos.
Cada grupo de dígitos representa un número.
Para la mecánica del juego, Kojo necesita saber la suma de esos dos números.

Escribe una función `twoSum` que acepte dos arrays como parámetros.
Cada array consta de uno o más números entre 0 y 9.
La función debe interpretar cada array como un número y devolver la suma de esos dos números.

```javascript
twoSum([1, 2, 3], [0, 7]);
//=> 130

// [1, 2, 3] represents 123 and [0, 7] represents 7.
// 123 + 7 = 130
```

## 2. Determina si un número es un palíndromo

Otro juego del sitio web es un pequeño concurso de preguntas llamado «Lucky Numbers».
Un usuario puede ingresar un número y luego ve si el número pertenece a alguna secuencia o patrón secreto.
La secuencia o el patrón de los «lucky numbers» cambia cada mes, y cada usuario solo tiene un número limitado de intentos para adivinarlo.

Los números de la suerte de este mes deben ser números que sean palíndromos.
Los números palindrómicos siguen siendo iguales cuando se invierten sus dígitos.

Implementa la nueva función `luckyNumber` que acepte un número como parámetro.
La función debe devolver `true` si el número es un palíndromo y `false` en caso contrario.
El número de entrada siempre será un entero positivo.

```javascript
luckyNumber(1441);
//=>  true

luckyNumber(123);
//=> false
```

## 3. Genera un mensaje de error para entradas de usuario no válidas

En varios lugares del sitio web hay campos de entrada donde los usuarios pueden ingresar números y hacer clic en un botón para desencadenar alguna acción.
Kojo quiere mejorar la experiencia del usuario de su sitio.
Quiere mostrar un mensaje de error en caso de que el usuario haga clic en el botón pero el campo contenga un valor de entrada no válido.

Aquí hay un poco más de información sobre cómo se proporciona el valor de un campo de entrada.

- Si el usuario escribe algo en un campo, el valor asociado siempre es un string, incluso si solo escribió números.
- Si el usuario escribe algo pero luego lo borra, la variable será un string vacío.
- Antes de que el usuario siquiera empiece a escribir, la variable puede ser `undefined` o `null`.

Escribe una función `errorMessage` que acepte la entrada del usuario como parámetro.
Si el usuario no proporcionó ninguna entrada, `errorMessage` debe devolver `'Required field'`.
Si la entrada no representa un número distinto de cero (según las reglas de conversión de JavaScript), se debe devolver `'Must be a number besides 0'`.
En todos los demás casos, puedes suponer que la entrada es válida; el valor de retorno debe ser un string vacío.

```javascript
errorMessage('123');
// => ''

errorMessage('');
// => 'Required field'

errorMessage('abc');
// => 'Must be a number besides 0'
```
