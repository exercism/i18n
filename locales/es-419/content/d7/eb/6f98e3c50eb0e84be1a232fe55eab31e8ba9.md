# Pistas

## General

- Un [valor entero][integers] se puede definir como uno o más dígitos consecutivos.

## 1. Define el tiempo de horneado esperado en minutos

- Necesitas definir un [método][methods] sin argumentos.
- Necesitas devolver un [entero][integers].

## 2. Calcula el tiempo de horneado restante en minutos

- Necesitas definir un [método][methods] con un solo parámetro.
- Tienes que [devolver explícitamente un entero][return] desde un método.
- El parámetro del método es un [entero][integers].
- Puedes usar el [operador matemático para la resta][operators] para restar valores.

## 3. Calcula el tiempo de preparación en minutos

- Necesitas definir un [método][methods] con un solo parámetro.
- Tienes que [devolver explícitamente un entero][return] desde un método.
- El parámetro del método es un [entero][integers].
- Puedes usar el [operador matemático para la multiplicación][operators] para multiplicar valores.

## 4. Calcula el tiempo transcurrido en minutos

- Necesitas definir un [método][methods] con dos parámetros.
- Tienes que [devolver explícitamente un entero][return] desde un método.
- El parámetro del método es un [entero][integers].
- Puedes [invocar][invocation] uno de los otros métodos que definiste antes.
- Puedes usar el [operador matemático para la suma][operators] para sumar valores.
