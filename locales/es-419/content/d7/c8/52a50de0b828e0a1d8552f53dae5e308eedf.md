# Instrucciones

Sarah está trabajando en un nuevo juego de rol y necesita tu ayuda con la mecánica del jugador.

## 1. Define la tupla `player`

Define una clase de tupla `player` con cuatro ranuras y valores predeterminados:

| ranura   | valor predeterminado |
| -------- | ------- |
| `name`   | `f`     |
| `level`  | `0`     |
| `health` | `100`   |
| `mana`   | `f`     |

Una vez definida, puedes construir un jugador como un literal:

```factor
T{ player { name "Merlin" } { level 5 } } .
! => T{ player { name "Merlin" } { level 5 } }
```

## 2. Presenta al jugador

Define `introduce` para que devuelva el nombre del jugador. Los jugadores sigilosos ocultan su nombre (`name` es `f`) y se deben presentar como `"Mighty Magician"`.

```factor
T{ player { name "Merlin" } } introduce .
! => "Merlin"

T{ player { health 8 } } introduce .
! => "Mighty Magician"
```

## 3. Revive a un jugador caído

Define `revive` para que devuelva un jugador *nuevo* con `health` en 100 y `mana` en 100, pero solo si el `health` del jugador es `0`. Si el jugador sigue vivo, devuelve `f`.

```factor
T{ player { name "Merlin" } { health 0 } } revive .
! => T{ player { name "Merlin" } { health 100 } { mana 100 } }

T{ player { health 50 } } revive .
! => f
```

## 4. Recibe daño

Define `take-damage` para que devuelva un jugador *nuevo* cuyo `health` se haya reducido en la cantidad dada, sin bajar nunca por debajo de `0`.

```factor
T{ player { health 100 } } 30 take-damage .
! => T{ player { health 70 } }

T{ player { health 5 } } 30 take-damage .
! => T{ player { health 0 } }
```
