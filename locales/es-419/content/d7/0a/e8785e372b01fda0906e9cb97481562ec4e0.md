# Instrucciones

Tu nostalgia por las cartas Blorkemon™️ no da señales de disminuir; incluso empezaste a coleccionarlas de nuevo y estás haciendo que tus amigos se unan a ti.

En este ejercicio, una colección de `Card` se representa con `Set Card`, ya que las cartas duplicadas no son importantes cuando tu meta es conseguir todas las cartas que existen.

## 1. Inicia una colección

De verdad quieres que tus amigos se sumen a tu locura por Blorkemon™️, y la mejor forma es darles una carta para arrancar su colección.

Implementa `newCollection`, que transforma una carta en una colección.

```elm
newCollection "Newthree"
    --> Set.fromList ["Newthree"]
```

## 2. Haz crecer la colección

Una vez que tienes una colección, esta cobra vida propia y tiene que crecer.

Implementa `addCard`, que recibe una `Card` y una colección, y devuelve una `Tuple` con dos valores: un `Bool` que indica si la `Card` ya estaba en la colección, y la colección con la carta añadida.

```elm
addCard "Scientuna" (Set.fromList ["Newthree"])
    --> (False, Set.fromList ["Newthree", "Scientuna"])
```

## 3. Empieza a intercambiar

Ahora que tus amigos están otra vez locos por Blorkemon™️, puedes aprovechar para hacer crecer tu propia colección intercambiando cartas.

No todos los intercambios valen la pena, ni siquiera se pueden hacer.
No puedes intercambiar una carta que no tienes, y no deberías intercambiar una carta por otra que ya tienes.

Implementa `tradeCard`, que recibe dos cartas para intercambiar (la tuya y la suya) y tu colección actual.
El valor de retorno es una `Tuple` de dos valores: un `Bool` que indica si el intercambio es posible y vale la pena, y la colección con la que terminarías si hicieras el intercambio (aunque en realidad no sea posible).

```elm
tradeCard "Scientuna" "Newthree" (Set.fromList ["Scientuna"])
    --> (True, Set.fromList ["Newthree"])
```

## 4. Solo puede haber una de cada una

Encuentras un viejo alijo de cartas en un mercado de pulgas.
Debes ordenar las cartas y eliminar las duplicadas para comparar la lista con tu colección.

Implementa `removeDuplicates`, que ordenará una lista de cartas y devolverá una lista de cartas únicas y ordenadas.

```elm
removeDuplicates ["Newthree", "Newthree", "Newthree", "Scientuna"]
    --> ["Newthree", "Scientuna"]
```

## 5. Cartas que ellos no tienen

Es hora de sentirte bien con tu colección.

Implementa `extraCards`, que recibe tu colección y otra colección, y devuelve la cantidad de cartas que la otra colección no tiene.

```elm
extraCards (Set.fromList ["Scientuna"]) (Set.fromList ["Newthree", "Scientuna"])
    --> 0
```

## 6. Cartas que todos tienen

Tú y tus amigos aficionados a Blorkemon™️ se reúnen y se preguntan cuáles son las cartas más comunes.

Implementa `boringCards`, que recibe una lista de colecciones y devuelve una lista de cartas ordenadas que todas las colecciones tienen.

```elm
boringCards [Set.fromList ["Scientuna"], Set.fromList ["Newthree", "Scientuna"]]
    --> ["Scientuna"]
```

## 7. Todas las cartas

¿Tú y tus amigos tienen en conjunto todas las cartas de Blorkemon™️?

Implementa `totalCards`, que recibe una lista de colecciones y devuelve el número total de cartas diferentes en todas las colecciones.

```elm
totalCards [Set.fromList ["Scientuna"], Set.fromList ["Newthree", "Scientuna"]]
    --> 2
```

## 8. Brillantes para ganar

Tu sobrino viene a visitarte pronto y tienes ganas de impresionarlo.
A los niños les gustan las cosas brillantes, ¿verdad?
¡Las cartas de Blorkemon™️ pueden ser brillantes!

Implementa `splitShinyCards`, que recibe una colección y devuelve una `Tuple` con dos listas de cartas ordenadas: una con todas las cartas que empiezan con `"Shiny"` y otra con las demás cartas.

```elm
splitShinyCards (Set.fromList ["Newthree", "Scientuna", "Shiny Scientuna"])
    --> (["Shiny Scientuna"], ["Newthree", "Scientuna"])
```
