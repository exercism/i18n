# Tests

## Ejecutar los tests

Para ejecutar los tests, usa el siguiente comando:

```bash
make
```

## Resolver el ejercicio

Resolver un ejercicio significa hacer que todos sus tests pasen. De forma predeterminada, cuando ejecutas los tests solo se ejecuta uno (el primero). Esto es intencional, ya que te permite concentrarte en hacer que ese único test pase. Cuando lo logres, puedes habilitar el siguiente test eliminando la línea `TEST_IGNORE()`. Cuando hayas habilitado todos los tests y tu implementación haga que todos pasen, ¡habrás resuelto el ejercicio!
