# Anexo de instrucciones

## Notas de implementación

Un programa de Factor se construye a partir de *palabras*, agrupadas en *vocabularios*.

Factor carga un *vocabulario* desde un directorio con el mismo nombre, así que el vocabulario `hello-world` es el archivo `hello-world.factor` dentro de un directorio `hello-world/`.

`: say-hello ( -- str ) … ;` define la palabra `say-hello`.
La parte entre paréntesis es su *efecto de pila*: que no haya nada a la izquierda de `--` significa que no recibe ningún argumento, y `str` a la derecha significa que deja un valor (el nombre es solo documentación, no un tipo).
Todo lo que está entre el efecto de pila y el `;` de cierre es el cuerpo: el código que se ejecuta cuando se llama a la palabra.

La suite de pruebas llama a `say-hello` y comprueba el valor que deja en la pila.
Cambia el cuerpo para que la palabra deje `"Hello, World!"` en su lugar, y después ejecuta las pruebas.
