# Introducción

En Common Lisp, una función no solo puede devolver un valor, sino que puede devolver varios.
Por ejemplo, `floor`, que redondea hacia abajo, hacia cero, devuelve dos valores: el primero es el valor redondeado y el segundo es el residuo.

```lisp
(floor 3.5) ; => 3
            ;    0.5
```
(Mostraremos los múltiples valores devueltos en líneas separadas de la salida.)

## Devolver varios valores

Si quieres que una función devuelva varios valores, usas el accesor `values`:

```lisp
(defun three-numbers () (values 1 2 3))
(three-numbers) ; => 1
                ;    2
                ;    3
```

## Cómo manejar varios valores

Si solo te interesa el primer valor, no hay que hacer nada especial. El lenguaje se encarga:

```lisp
(+ (values 1 2 3) (values 10 20 30)) ; => 11
```

Sin embargo, si quieres acceder a esos otros valores, hay varias funciones que tendrás que usar.
Dos macros principales son `multiple-value-list` y `multiple-value-bind`.
Se usan para envolver algo que devuelve varios valores y capturar todos los valores.
La primera crea una lista con todos los valores.
La segunda te permite vincular variables a cada uno de los valores.

```lisp
(multiple-value-list (values 1 2 3))                   ; => (1 2 3)
(multiple-value-bind (a b c) (values 1 2 3) 
   (+ a b c)) ; => 6
```

Otra función útil es `nth-value`
