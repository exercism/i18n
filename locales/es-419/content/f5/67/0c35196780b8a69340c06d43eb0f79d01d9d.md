# Anexo de instrucciones

## Implementación

Muchos de nuestros ejercicios de Pyret de nivel básico se pueden resolver solo con [expresiones de aplicación de función] de la forma `foo(1)`.
Este ejercicio, sin embargo, espera que se puedan usar [expresiones de punto] para acceder a los campos de datos y de método de lo que devuelve tu función.
Esto se puede hacer con [expresiones de objeto], que te permiten acceder a los campos de un objeto literal.
Las [declaraciones de datos] son un enfoque similar, pero más avanzado, que también utiliza campos de datos y de método.

[function application expressions]: https://pyret.org/docs/latest/Expressions.html#%28part._s~3aapp-expr%29
[dot expressions]: https://pyret.org/docs/latest/Expressions.html#%28part._s~3adot-expr%29
[object expressions]: https://pyret.org/docs/latest/Expressions.html#%28elem._%28bnf-prod._%28.Pyret._obj-expr%29%29%29
[data declarations]: https://pyret.org/docs/latest/s_declarations.html#%28part._s~3adata-decl%29
