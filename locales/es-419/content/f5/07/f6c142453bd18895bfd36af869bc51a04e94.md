# Acerca de

Un *montículo* (heap) es una colección que siempre conoce su elemento más pequeño (o más grande) y te permite quitarlo rápidamente: la implementación natural de una *cola de prioridad*. Los montículos viven en el vocabulario [`heaps`][heaps].

`<min-heap>` construye un montículo vacío cuya clave más pequeña sale primero; `<max-heap>` entrega primero la más grande. Cada elemento es un *valor* guardado bajo una *clave*, y la clave es la prioridad por la que Factor ordena:

```
<min-heap> ( -- min-heap )
<max-heap> ( -- max-heap )
heap-push  ( value key heap -- )
heap-push-all ( assoc heap -- )
```

```factor
USING: heaps ;

<min-heap>
"alice" 5 pick heap-push
"bob"   2 pick heap-push
```

Un montículo es *mutable*: `heap-push` y `heap-pop` lo modifican en el lugar.

```
heap-peek    ( heap -- value key )
heap-pop     ( heap -- value key )
heap-pop-all ( heap -- alist )
heap-empty?  ( heap -- ? )
heap-size    ( heap -- n )
```

`heap-peek` lee el frente sin quitarlo; `heap-pop` lo quita y lo devuelve; `heap-pop-all` vacía el montículo en una lista de asociaciones de pares `{ key value }`, en orden de prioridad.

```factor
USING: assocs heaps kernel prettyprint ;

<min-heap>
"alice" 5 pick heap-push
"bob"   2 pick heap-push
"carol" 9 pick heap-push
dup heap-pop .           ! => 2 "bob"   (removed; value then key)
heap-pop-all values .    ! => { "alice" "carol" }
```

Insertar es `O(log n)` y leer el frente es `O(1)`, así que repetir «toma el elemento más urgente y luego agrega más» se mantiene rápido incluso para una cola grande. La implementación es un montículo binario guardado en un array que puede crecer; la clave puede ser cualquier valor que se pueda ordenar (números, strings, …).

[heaps]: https://docs.factorcode.org/content/vocab-heaps.html
