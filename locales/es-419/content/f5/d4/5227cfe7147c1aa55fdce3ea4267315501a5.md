# Tests

Cada ejercicio contiene un archivo de tests.
Ejecuta los tests con el programa `bats`.

```bash
bats test-hello-world.bats
```

`bats` necesita estar instalado.
Consulta la página [Pruebas en el track de Bash][bash] para ver las instrucciones de instalación de `bats` en tu sistema.

### bats está implementado en bash

El archivo de bats es un script de bash, con algunas funciones especiales que reconoce el comando `bats`.
Verás algunos tests como este:

```sh
jq -f some-exercise.jq <<< "{some,json,here}"
```

Esa sintaxis `<<<` es un [Here String][here-string] de bash.
Envía el string que está del lado derecho a la entrada estándar del programa que está del lado izquierdo.
Es ([aproximadamente][so]) lo mismo que

```sh
echo "{some,json,here}" | jq -f some-exercise.jq
```

## Tests omitidos

Resolver un ejercicio significa hacer que todos sus tests pasen.
De forma predeterminada, cuando ejecutas los tests solo se ejecuta uno (el primero).
Esto es intencional, ya que te permite concentrarte solo en hacer que ese test pase.
Una vez que pase, puedes habilitar el siguiente test comentando o eliminando las

    [[ $BATS_RUN_SKIPPED == true ]] || skip

anotaciones que preceden a los otros tests.

## Anular las omisiones

Para ejecutar todos los tests, incluidos los que tienen anotaciones `skip`, puedes ejecutar:

```bash
BATS_RUN_SKIPPED=true bats test-some-exercise.bats
```

Puede ser cómodo usar una función contenedora para escribir menos: en `bash` puedes hacer lo siguiente:

```bash
bats() {
    BATS_RUN_SKIPPED=true command bats *.bats
}
```

Después, ejecuta los tests simplemente con:

```bash
bats
```

Úsalo mientras desarrollas las soluciones de tus ejercicios para inspeccionar los datos que hay en ese momento en el pipeline de jq.
