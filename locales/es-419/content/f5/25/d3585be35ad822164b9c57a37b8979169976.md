# Instrucciones

En este ejercicio vas a implementar un programa que determina el estado de una partida de [tres en línea][]. (_También puedes conocer el juego como «tres en raya» o «equis y ceros»._)

El juego se disputa en una cuadrícula de 3×3.
Los jugadores se turnan para colocar `X` y `O` en la cuadrícula.
El juego termina cuando un jugador gana al colocar tres marcas en una fila, una columna o una diagonal de la cuadrícula, o cuando toda la cuadrícula se llena.

En este ejercicio asumiremos que `X` empieza.

Tu trabajo es determinar en qué estado se encuentra una partida dada.

Hay 3 estados posibles:

- La partida está **ongoing**.
- La partida terminó en **draw**.
- La partida terminó en **win**.

Si el tablero dado es inválido, lanza un error apropiado.

Un tablero es inválido si cumple las siguientes condiciones:

- No se puede llegar al tablero dado si los turnos se toman en el orden correcto (recuerda que `X` empieza).
- Se siguió jugando después de que la partida ya había terminado.

## Ejemplos

### Partida en curso

```text
   |   |
 X |   |
___|___|___
   |   |
   | X | O
___|___|___
   |   |
 O | X |
   |   |
```

### Empate

```text
   |   |
 X | O | X
___|___|___
   |   |
 X | X | O
___|___|___
   |   |
 O | X | O
   |   |
```

### Victoria

```text
   |   |
 X | X | X
___|___|___
   |   |
   | O | O
___|___|___
   |   |
   |   |
   |   |
```

### Inválido

#### Orden de turnos incorrecto

```text
   |   |
 O | O | X
___|___|___
   |   |
   |   |
___|___|___
   |   |
   |   |
   |   |
```

#### Se siguió jugando después de la victoria

```text
   |   |
 X | X | X
___|___|___
   |   |
 O | O | O
___|___|___
   |   |
   |   |
   |   |
```
