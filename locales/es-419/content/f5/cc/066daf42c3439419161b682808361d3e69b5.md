# Escribir el código

Escribe tu código en `<exercise_name>.zig`.
Algunos ejercicios incluyen firmas ya escritas para construcciones específicas de Zig, como [constantes][constants], [funciones][functions], [importaciones][imports], [structs][structs] y [potencialmente muchas más][et-cetera].

Estas firmas ya escritas tienen como objetivo ayudarte a completar los ejercicios, ya que te brindan un punto de partida claro.
Sin embargo, no es necesario comenzar desde estas firmas.
Sobre todo teniendo en cuenta que cualquier código que pase sus pruebas es una solución perfectamente aceptable.

## Ejecutar las pruebas

Para ejecutar las pruebas, solo tienes que escribir el siguiente comando:

```bash
zig test test_exercise_name.zig
```

reemplazando `exercise_name` por el nombre del ejercicio.
El comando anterior debes ejecutarlo en el directorio raíz del ejercicio, ya que su archivo de pruebas debe estar en esa misma ubicación.
Además, todas las pruebas de cualquier ejercicio están habilitadas de forma predeterminada y ninguna se puede omitir.

Como todas las pruebas tienen estas condiciones, tendrías que [comentar][comments] las pruebas que no pasan si quieres ir una por una.
Comentar una prueba es tan sencillo como empezar cada línea con `//`.
De lo contrario, cuando ya confíes en que tu solución puede pasar las pruebas, puedes descomentar esas pruebas para ver si pasa.
