# Introducción

El tipo `char` de C# es una cantidad de 16 bits que representa los componentes más pequeños y direccionables del texto. Varios `char` pueden formar un string como `"word"`, o los `char` se pueden procesar de forma independiente. Sus literales usan comillas simples, por ejemplo `'A'`.

Los `char` de C# admiten la codificación Unicode UTF-16, así que además del conjunto de caracteres latinos se puede representar prácticamente cualquier sistema de escritura que se use en el mundo, por ejemplo la letra griega `'β'`.

Existen muchos métodos de biblioteca integrados para inspeccionar y manipular `char`. Los puedes encontrar como métodos estáticos de la clase `System.Char`.
