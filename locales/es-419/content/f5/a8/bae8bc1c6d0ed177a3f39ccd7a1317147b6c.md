# Instrucciones

En este ejercicio implementarás un conjunto parcial de funciones de utilidad para ayudar a un desarrollador a limpiar nombres de identificadores.

En las 5 tareas construirás gradualmente la función `clean`.
Un identificador válido se compone de cero o más letras y guiones bajos.

Si se pasa un string vacío a la función `clean`, se debe devolver un string vacío.

## 1. Reemplaza los espacios por guiones bajos

Implementa una función `clean1` para reemplazar cualquier espacio por guiones bajos. Esto también aplica a los espacios al principio y al final.

```elm
clean1 "my   Id"
    --> "my___Id"
```

## 2. Reemplaza los caracteres de control por el string en mayúsculas "[CTRL]"

Implementa `clean2` para hacer todo lo que hace la función anterior y reemplazar los caracteres de control comunes (\n, \t, y \r ) por el string `"[CTRL]"`.

```elm
clean2 "my\nId"
    --> "my[CTRL]Id",
```

## 3. Convierte de kebab-case a camelCase

Implementa `clean3` para hacer todo lo que hace la función anterior y convertir de kebab-case a camelCase.

```elm
clean3 "à-ḃç"
    --> "àḂç"
```

## 4. Omite los dígitos

Implementa `clean4` para hacer todo lo que hace la función anterior y omitir todos los dígitos.

```elm
clean4 "123"
    --> ""
```

## 5. Omite las letras griegas minúsculas

Por último, implementa `clean` para hacer todo lo que hace la función anterior y omitir cualquier letra griega en el rango de 'α' a 'ω'.

```elm
clean "My Οβιεγτ Finder"
    --> "My_Ο_Finder"
```
