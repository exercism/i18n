# Acerca de

Los bucles `for` son el tipo de bucle más complejo en PHP. Se comportan como los bucles `for` de `C`, `Java` y `JavaScript`. Su forma básica es:

```php
for (expr1; expr2; expr3) {
  // statements
}
```

La primera expresión (_expr1_) se evalúa antes de que el bucle comience. La segunda expresión (_expr2_) se evalúa antes de cada iteración. Si se evalúa como un valor _verdadero_, se ejecutan las sentencias. Después de ejecutar las sentencias, se evalúa la tercera expresión (_expr3_).
