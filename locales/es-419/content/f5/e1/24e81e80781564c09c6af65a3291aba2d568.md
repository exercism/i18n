# Instrucciones

Aprende a combinar datos de dos tablas internas diferentes en una sola tabla interna de resultado.

Tu clase recibirá dos tablas internas que contienen dos conjuntos de datos completamente diferentes, ALPHAS y NUMS.

```abap
TYPES: BEGIN OF alphatab_type,
         cola TYPE string,
         colb TYPE string,
         colc TYPE string,
       END OF alphatab_type.
TYPES: alphas TYPE STANDARD TABLE OF alphatab_type.
TYPES: BEGIN OF numtab_type,
         col1 TYPE string,
         col2 TYPE string,
         col3 TYPE string,
       END OF numtab_type.
TYPES: nums TYPE STANDARD TABLE OF numtab_type.
```

Los datos de la tabla ALPHA se muestran a continuación.

| COLA | COLB | COLC |
| --- | --- | --- |
| A | B | C | 
| D | E | F |
| G | H | I |

Los datos de la tabla NUMS se muestran a continuación.

| COL1 | COL2 | COL3 |
| --- | --- | --- |
| 1 | 2 | 3 | 
| 4 | 5 | 6 |
| 7 | 8 | 9 |

Tu tarea es devolver una tabla interna con registros que combinen los valores de cada celda de la tabla interna ALPHAS con los de la tabla interna NUMS. Por ejemplo, el valor de la primera columna de la primera fila de la tabla interna COMBINED_DATA debe ser «A1».

La tabla de retorno esperada tiene la siguiente definición:

```abap
TYPES: BEGIN OF combined_data_type,
         colx TYPE string,
         coly TYPE string,
         colz TYPE string,
       END OF combined_data_type.
TYPES: combined_data TYPE STANDARD TABLE OF combined_data_type WITH EMPTY KEY.
```
