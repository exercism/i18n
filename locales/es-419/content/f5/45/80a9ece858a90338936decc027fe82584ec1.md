# Clases genéricas

```sather
class LOST_BOX{T} is
   attr item : T;
   create(thing : T) : SAME is
      box ::= new;
      box.item := thing;
      return box;
   end;
end;
```

## Qué es el parámetro

`T` representa un tipo que se proporciona en el punto de uso. Sather construye
una clase distinta para cada combinación que realmente se usa, cuando se compila
el programa. Así que:

- `LOST_BOX{STR}` y `LOST_BOX{INT}` son tipos que no tienen relación entre sí;
- no hay verificación en tiempo de ejecución, ni boxing, ni conversión;
- un error en la clase aparece para cada tipo con el que se usa.

Este es el mismo enfoque de las plantillas de C++ o los genéricos de Rust, y
distinto del de los genéricos de Java, donde el tipo se borra y todo es en
realidad un objeto.

## Parámetros con restricciones

A un `T` a secas se le puede asignar un valor, se le puede pasar y se le puede
devolver, y nada más, porque no se sabe nada más sobre él. Para llamar rutinas
sobre él, especifica a qué debe conformarse:

```sather
class LOST_BOX{T < $STR} is
   describe : STR is return "a box holding " + item.str; end;
end;
```

`T < $STR` exige que `T` se conforme a `$STR` y, a cambio, permite llamar a
`item.str`. Todo lo que un `T` a secas no puede hacer se habilita con una
restricción.

Sin la restricción, `item.str` no compilará, y el mensaje señalará la línea
dentro de la clase genérica, no la línea que la usó.

## ¿Rutinas genéricas?

No las hay. Solo las clases reciben parámetros. Una rutina que necesita
funcionar con varios tipos o bien vive en una clase genérica, o bien recibe un
tipo abstracto como `$STR`.

## Elegir entre ambas

| | clase genérica | clase abstracta |
| --- | --- | --- |
| se decide | al compilar | al ejecutarse |
| contiene | un tipo por instanciación | cualquier tipo que conforme |
| costo | ninguno | un despacho |

`ARRAY{$ACT}` usa ambas: genérica en el tipo de sus elementos, abstracta en lo
que ese elemento puede ser.

Recurre a una clase genérica cuando el tipo sea el mismo de principio a fin y
quien usa la clase lo sepa. Recurre a una clase abstracta cuando varios tipos
deban convivir en una misma colección.
