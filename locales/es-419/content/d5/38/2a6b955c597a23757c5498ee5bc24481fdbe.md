# Acerca de

C es un lenguaje de tipado estático, lo que significa que todo tiene un tipo en tiempo de compilación.
Elegir un nombre para una [variable][variable] y establecer su tipo se conoce como declarar una variable.

Una variable se declara especificando explícitamente su tipo.
El nombre de una variable [debe seguir algunas reglas][name-rules], como empezar con una letra o con un guion bajo.
Algunos nombres no se pueden usar porque están reservados [para palabras clave][reserved-keywords] o [para otros identificadores][reserved-identifiers].

Establecer o actualizar la variable se hace mediante la asignación de variables.
Establecer el valor define esa variable.
Definir la variable también se conoce como inicialización.

```c
int foo;      // Declare an integer named var
foo = 10;     // Define the variable

int bar = 15; // Both can also be done in a single statement
```

El valor de una variable se puede asignar y actualizar con el [operador de asignación simple `=`][assignment-operator].
Una vez definida, el tipo de una variable nunca puede cambiar.

```c
int foo = 10; // Assign initial value
foo = 25;     // Update to new value

foo = false;  // Compiler error when assigning value of a different type
```

C es un lenguaje [imperativo][imperative] [procedural][procedural].
Todos los cálculos se llevan a cabo como parte de una serie de [sentencias][statements] que forman parte de una [función][function] o de varias funciones.

Cada función puede tener cero o más [parámetros][parameters].
Al definir una función, todos los parámetros y el valor devuelto deben tener un tipo explícito.
Los valores se devuelven desde las funciones con la [palabra clave `return`][return-keyword].
De forma predeterminada, las funciones tienen [clase de almacenamiento][storage_class] externa, lo que significa que existen durante toda la vida del programa y pueden ser visibles fuera del archivo.
Para evitarlo, se puede añadir la palabra clave `static` y especificar así visibilidad interna.

```c
static int add(int x, int y) {
  return x + y;
}
```

En el ejemplo anterior, las variables `x` y `y` solo se pueden usar dentro de la función, es decir, tienen ámbito de función.
El [ámbito][scope] es la idea de que el valor asociado a un nombre (de un elemento del programa) solo es accesible dentro del «área» de código donde se define.
Las principales áreas de código en C son:

- archivo
- función
- bloque (como dentro de bucles y otras construcciones)

Las funciones se invocan especificando el nombre de la función y pasando argumentos para cada uno de los parámetros de la función.

```c
int sum = add(1, 2);
```

C admite dos tipos de [comentarios][comments].
Los comentarios de una sola línea van precedidos por `//` (desde C99) y los comentarios de varias líneas se insertan entre `/*` y `*/`.
