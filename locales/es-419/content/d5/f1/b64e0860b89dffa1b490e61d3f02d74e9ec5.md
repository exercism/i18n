# Introducción

La macro `use` nos permite extender rápidamente nuestro módulo con funcionalidad proporcionada por otro módulo. Cuando usamos `use` en un módulo, ese módulo puede inyectar código en nuestro módulo; por ejemplo, puede definir funciones, `import` o `alias` otros módulos, o establecer atributos del módulo.

Si alguna vez miraste los archivos de prueba de algunos de los ejercicios de Elixir aquí en Exercism, seguramente notaste que todos comienzan con `use ExUnit.Case`. Esta única línea de código es lo que hace que las macros `test` y `assert` estén disponibles en el módulo de prueba.

```elixir
defmodule LasagnaTest do
  use ExUnit.Case

  test "expected minutes in oven" do
    assert Lasagna.expected_minutes_in_oven() === 40
  end
end
```

## Macro `__using__/1`

Qué sucede exactamente cuando usas `use` en un módulo está determinado por la macro `__using__/1` de ese módulo. Toma un argumento, una lista de palabras clave con opciones, y devuelve una [expresión citada][concept-ast]. El código en esta expresión citada se inserta en nuestro módulo al llamar a `use`.

```elixir
defmodule ExUnit.Case do
  defmacro __using__(opts) do
    # some real-life ExUnit code omitted here
    quote do
      import ExUnit.Assertions
      import ExUnit.Case, only: [describe: 2, test: 1, test: 2, test: 3]
    end
  end
end
```

Las opciones se pueden dar como segundo argumento al llamar a `use`, por ejemplo, `use ExUnit.Case, async: true`. Cuando no se dan explícitamente, por defecto son una lista vacía.

[concept-ast]: https://exercism.org/tracks/elixir/concepts/ast
