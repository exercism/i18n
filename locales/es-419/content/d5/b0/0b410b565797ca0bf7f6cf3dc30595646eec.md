# Introducción

Las operaciones bit a bit nos permiten manipular dígitos individuales dentro de números binarios.

Elm ofrece varios operadores bit a bit en su [módulo Bitwise](https://package.elm-lang.org/packages/elm/core/latest/Bitwise)

## Operaciones básicas

Modificar bits individuales de un número se llama _enmascaramiento_.
Una _máscara_ es un número en el que se han establecido bits específicos de una manera particular para manipular otro número usando operadores bit a bit como `and`, `or` y `xor`.

### and

`and` combina dos números conservando solo los bits que son `1` en ambos.
Esto es útil para comprobar si un bit individual está establecido.
Por ejemplo, para comprobar si el 4.º bit de un número está establecido en `1`, aplícale `and` con una máscara de `01000` (`8` en decimal) y observa si el resultado es distinto de cero:

```elm
Bitwise.and 13 8 --> 8
--  13 = 01101
--   8 = 01000
-- and = 01000 = 8
```

### or

`or` combina dos números estableciendo cada bit en `1` si es `1` en cualquiera de los dos o en ambos.
Esto es útil para establecer un bit específico en `1`.
Por ejemplo, para establecer el 2.º bit en `10101`, aplícale `or` con la máscara `00010`:

```elm
Bitwise.or 21 2 --> 23
-- 21 = 10101
--  2 = 00010
-- or = 10111 = 23
```

### Or exclusivo (xor)

`xor` combina dos números estableciendo cada bit en `1` si es `1` en uno de los números pero `0` en el otro.
Esto es útil para invertir un bit a su valor opuesto:

```elm
Bitwise.xor 20 5 --> 17
--  20 = 10100
--   5 = 00101
-- xor = 10001 = 17
```

### Complemento

`complement` invierte cada bit de un número (`0` pasa a `1`, `1` pasa a `0`).

Ten en cuenta que esto hará que los números positivos se vuelvan negativos, y los números negativos se vuelvan positivos.
Esto se debe a que los números negativos en binario se representan con `1` en la posición más a la izquierda.

```elm
Bitwise.complement 21 --> -22
--         21 = 00000000000000000000000000010101
-- complement = 11111111111111111111111111101010 = -22
```

### Desplazamiento de bits

Los siguientes operadores mueven bits hacia la izquierda o hacia la derecha una cantidad específica de posiciones, lo que equivale a multiplicar o dividir por potencias de 2.

`shiftLeftBy` mueve los bits hacia la izquierda, rellenando con `0` desde el lado derecho.
Por ejemplo, para desplazar `21` tres lugares a la izquierda:

```elm
Bitwise.shiftLeftBy 3 21 --> 168
--  21 = 10101
-- shiftLeftBy 3 = 10101000 = 168
```

Esto es lo mismo que decir `21 * 2^3 = 21 * 2 * 2 * 2 = 168`

`shiftRightBy`: mueve los bits hacia la derecha:

```elm
Bitwise.shiftRightBy 2 21 --> 5
--  21 = 10101
-- shiftRightBy 2 = 00101 = 5
```

Desplazar dos lugares a la derecha es lo mismo que la división entera entre 4.

Ten en cuenta que esta función duplica el valor que haya en el bit más a la izquierda.
Así, los números negativos seguirán siendo negativos:

```elm
Bitwise.shiftRightBy 3 -21 --> -3
--  -21 = 111...101011
-- shiftRightBy 3 = 111...11101 = -3
```

Si quieres desplazar a la derecha y rellenar con ceros, usa `shiftRightZfBy`:

```elm
Bitwise.shiftRightZfBy 3 -21 --> 536870909
--  -21 = 111...101011
-- shiftRightZfBy 3 = 00111...11101 = 536870909
```
