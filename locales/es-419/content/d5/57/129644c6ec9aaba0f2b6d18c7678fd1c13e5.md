# Instrucciones

En este ejercicio vas a trabajar en un sistema de citas para un salón de belleza en Nueva York que abrió el 15 de septiembre de 2012.

Tienes cuatro tareas, y todas girarán en torno a las fechas de las citas. Las fechas y horas usarán uno de los siguientes tres formatos:

- `"7/25/2019 13:45:00"`
- `"July 25, 2019 13:45:00"`
- `"Thursday, July 25, 2019 13:45:00:00"`

~~~~exercism/caution
Las pruebas establecerán automáticamente la cultura en `en-US`; no tienes que establecer ni especificar la cultura tú mismo.
~~~~

## 1. Interpretar la fecha de la cita

Implementa la función `schedule`, que puede interpretar una representación textual de la fecha de una cita y convertirla al formato `DateTime` correspondiente:

```fsharp
schedule "7/25/2019 13:45:00"
// => DateTime(2019, 7, 25, 13, 45, 0)
```

## 2. Verificar si una cita ya pasó

Implementa la función `hasPassed`, que recibe la fecha de una cita y verifica si la cita quedó en algún momento del pasado:

```fsharp
hasPassed (DateTime(1999, 12, 31, 9, 0, 0))
// => true
```

## 3. Verificar si la cita es por la tarde

Implementa la función `isAfternoonAppointment`, que recibe la fecha de una cita y verifica si la cita es por la tarde (>= 12:00 y < 18:00):

```fsharp
isAfternoonAppointment (DateTime(2019, 03, 29, 15, 0, 0))
// => true
```

## 4. Describir la hora y la fecha de la cita

Implementa la función `description`, que recibe la fecha de una cita y devuelve una descripción de esa fecha y hora:

```fsharp
description (DateTime(2019, 03, 29, 15, 0, 0))
// => "You have an appointment on 3/29/2019 3:00:00 PM."
```

## 5. Devolver la fecha del aniversario

Implementa la función `anniversaryDate`, que devuelve la fecha del aniversario de este año, que es el 15 de septiembre:

```fsharp
anniversaryDate()
// => DateTime(2019, 9, 15, 0, 0, 0)
```
