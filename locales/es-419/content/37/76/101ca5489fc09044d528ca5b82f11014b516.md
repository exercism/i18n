# Introducción

En Cairo, no hay un tipo nativo para los strings.
En su lugar, puedes usar un solo `felt252` para almacenar un string corto de hasta 31 caracteres, o un `ByteArray` para strings de longitud arbitraria.
Los strings cortos usan comillas simples y `ByteArray` usa comillas dobles.
Todos los caracteres deben seguir el estándar ASCII.
