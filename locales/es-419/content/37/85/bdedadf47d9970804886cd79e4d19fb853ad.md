# Resaltado de sintaxis

En el sitio web hay dos tipos de resaltado de sintaxis:

1. El resaltado del código _estático_ (fragmentos de código, iteraciones y demás).
   Consulta la [documentación del resaltado de sintaxis estático](/docs/building/tracks/new/syntax-highlighting/static) para más información.
2. El resaltado del código _dinámico_ (el editor en línea).
   Consulta la [documentación del resaltado de sintaxis dinámico](/docs/building/tracks/new/syntax-highlighting/dynamic) para más información.

```exercism/note
Los requisitos para el resaltado de sintaxis estático y dinámico son _muy_ diferentes, y por eso usan bibliotecas distintas.
```
