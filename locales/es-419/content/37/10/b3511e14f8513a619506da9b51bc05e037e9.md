# Introducción

Go no tiene un concepto de vacío, nulo o indefinido para los valores de las variables.
Las variables declaradas sin un valor inicial explícito toman por defecto el valor cero de su tipo correspondiente.

El valor cero de los tipos primitivos, como los booleanos, los tipos numéricos y los strings, es `false`, `0` y `""`, respectivamente.

El identificador `nil`, que significa cero, es el valor cero de los tipos más complejos, como los punteros, las funciones, las interfaces, los slices, los canales y los mapas.

La siguiente tabla detalla el valor cero de los tipos de Go.

| Tipo      | Valor cero |
| --------- | ---------- |
| booleano  | `false`    |
| numérico  | `0`        |
| string    | `""`       |
| puntero   | `nil`      |
| función   | `nil`      |
| interfaz  | `nil`      |
| slice     | `nil`      |
| canal     | `nil`      |
| mapa      | `nil`      |

Habrás notado que los tipos struct no aparecen en la tabla anterior.
Esto se debe a que el valor cero de un tipo struct depende de sus campos.
Un struct se establece en su valor cero cuando todos sus campos se establecen en su respectivo valor cero.
