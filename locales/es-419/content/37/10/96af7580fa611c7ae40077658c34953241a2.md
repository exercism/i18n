# Instrucciones

En este ejercicio implementarás la lógica de una misión para un nuevo juego de rol que está desarrollando un amigo. La protagonista del juego es Annalyn, una chica valiente con un perro feroz y leal. Por desgracia, ocurre un desastre: su mejor amigo fue secuestrado mientras buscaba bayas en el bosque. Annalyn intentará encontrar y liberar a su mejor amigo, y puede llevar a su perro con ella en esta misión.

Después de pasar un tiempo siguiendo el rastro de su mejor amigo, encuentra el campamento donde está prisionero. Resulta que hay dos secuestradores: un caballero poderoso y un arquero astuto.

Habiendo encontrado a los secuestradores, Annalyn considera cuáles de las siguientes acciones puede realizar:

- Ataque rápido: se puede hacer un ataque rápido si el caballero está durmiendo, ya que tarda un tiempo en ponerse la armadura, así que estará vulnerable.
- Espiar: se puede espiar al grupo si al menos uno de ellos está despierto. De lo contrario, espiar es una pérdida de tiempo.
- Hacer señales al prisionero: se le pueden hacer señales al prisionero usando sonidos de aves si el prisionero está despierto y el arquero está durmiendo, ya que los arqueros están entrenados en hacer señales con aves, así que podrían interceptar el mensaje.
- _Liberar al prisionero_: Annalyn puede intentar entrar a escondidas al campamento para liberar al prisionero.
  Esto es arriesgado y solo puede salir bien de una de dos maneras:
  - Si Annalyn tiene a su perro con ella, puede rescatar al prisionero si el arquero está dormido.
    El caballero le tiene miedo al perro y el arquero no tendrá tiempo de prepararse antes de que Annalyn y el prisionero puedan escapar.
  - Si Annalyn no tiene a su perro, entonces ella y el prisionero deben ser muy sigilosos.
    Annalyn puede liberar al prisionero si el prisionero está despierto y tanto el caballero como el arquero están durmiendo, pero si el prisionero está durmiendo no se le puede rescatar: el prisionero se asustaría con la repentina aparición de Annalyn y despertaría al caballero y al arquero.

Tienes cuatro tareas: implementar la lógica para determinar si las acciones anteriores están disponibles según el estado de los tres personajes que se encuentran en el bosque y según si el perro de Annalyn está presente o no.

## 1. Verifica si se puede hacer un ataque rápido

Implementa la función `canFastAttack`, que recibe un valor Boolean que indica si el caballero está despierto. Esta función devuelve `true` si se puede hacer un ataque rápido según el estado del caballero. De lo contrario, devuelve `false`:

```fsharp
let knightIsAwake = true
canFastAttack(knightIsAwake)
// => false
```

## 2. Verifica si se puede espiar al grupo

Implementa la función `canSpy`, que recibe tres valores Boolean que indican si el caballero, el arquero y el prisionero, respectivamente, están despiertos. La función devuelve `true` si se puede espiar al grupo, según el estado de los tres personajes. De lo contrario, devuelve `false`:

```fsharp
let knightIsAwake = false
let archerIsAwake = true
let prisonerIsAwake = false
canSpy(knightIsAwake, archerIsAwake, prisonerIsAwake)
// => true
```

## 3. Verifica si se le pueden hacer señales al prisionero

Implementa la función `canSignalPrisoner`, que recibe dos valores Boolean que indican si el arquero y el prisionero, respectivamente, están despiertos. La función devuelve `true` si se le pueden hacer señales al prisionero, según el estado de los dos personajes. De lo contrario, devuelve `false`:

```fsharp
let archerIsAwake = false
let prisonerIsAwake = true
canSignalPrisoner(archerIsAwake, prisonerIsAwake)
// => true
```

## 4. Verifica si se puede liberar al prisionero

Implementa la función `canFreePrisoner`, que recibe cuatro valores Boolean. Los primeros tres parámetros indican si el caballero, el arquero y el prisionero, respectivamente, están despiertos. El último parámetro indica si el perro de Annalyn está presente. La función devuelve `true` si se puede liberar al prisionero según el estado de los tres personajes y la presencia del perro de Annalyn. De lo contrario, devuelve `false`:

```fsharp
let knightIsAwake = false
let archerIsAwake = true
let prisonerIsAwake = false
let petDogIsPresent = false
canFreePrisoner(knightIsAwake, archerIsAwake, prisonerIsAwake, petDogIsPresent)
// => false
```
