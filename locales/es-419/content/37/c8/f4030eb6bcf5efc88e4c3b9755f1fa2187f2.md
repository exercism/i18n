## 1. Identifica las líneas de log corruptas

- Usa el [sigilo `r`][sigil-r] para crear una expresión regular.
- Hay [un operador][match-operator] que se puede usar para comprobar un string contra una expresión regular. También hay una [función de `Regex`][regex-match] y una [función de `String`][string-match] que pueden hacer lo mismo.
- No olvides escapar los caracteres que tienen un significado especial en las expresiones regulares.

## 2. Divide la línea de log

- Hay una [función de `Regex`][regex-split] y también una [función de `String`][string-split] que pueden dividir un string en un array de strings a partir de una expresión regular.
- No olvides escapar los caracteres que tienen un significado especial en las expresiones regulares.

## 3. Elimina los artefactos del log

- Hay una [función de `Regex`][regex-replace] y también una [función de `String`][string-replace] que pueden cambiar la parte de un string que coincide con una expresión regular dada por otro string distinto.
- Hay un [modificador][regex-modifiers] que puede hacer que toda la expresión regular no distinga entre mayúsculas y minúsculas.

## 4. Etiqueta las líneas con nombres de usuario

- Hay una [función de `Regex`][regex-run] que ejecuta una expresión regular sobre un string y devuelve todas las capturas.
