Si el argumento no es válido, devuelve una longitud vacía.

## Direcciones reservadas

El búfer para el primer string usa los bytes 1024-2047 de la memoria lineal.
El búfer para el segundo string usa los bytes 2048-3071 de la memoria lineal.
El búfer para el tercer string usa los bytes 3072-4095 de la memoria lineal.

El primer segmento de los bytes 0-1023 de la memoria lineal está libre para usar.
