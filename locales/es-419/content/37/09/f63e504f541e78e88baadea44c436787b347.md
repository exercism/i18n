# Strings

Crystal tiene un tipo conocido como [`String`][strings], también llamado _cadena_, que se usa para representar texto.
Los strings de Crystal son secuencias de caracteres Unicode.
Los strings son inmutables, es decir, no se pueden cambiar una vez creados.
Esto significa que cada vez que modificas un string se crea uno nuevo; por lo tanto, el string original no se modifica.

Para definir un string usas comillas dobles `"`.

```crystal
"Hello World"
```

## Concatenación

Para concatenar dos strings, usa el operador `+`.
El operador `+` devuelve un nuevo string que combina los dos strings.

```crystal
hello = "Hello"
hello + " World"
# => "Hello World"
```

## Conversión entre strings y números

El método `to_i` convierte un string en un número entero.
Como alternativa, puedes usar el método `to_f` para obtener un número de punto flotante.
Si el string no se puede convertir a un número, se lanza un `ArgumentError`.

```crystal
"1".to_i
# => 1

"1.0".to_f
# => 1.0

"Hello".to_i
# => ArgumentError: Invalid integer: Hello
```

Un número entero o de punto flotante se puede convertir a un string con el método `to_s`.

```crystal
1.to_s
# => "1"

1.0.to_s
# => "1.0"
```

## Interpolación

La interpolación es una forma cómoda de combinar strings e incrustar expresiones en ellos.
Para interpolar un string, puedes usar el carácter `#` seguido de llaves `{}`, con la expresión dentro de las llaves.

```crystal
name = "World"
"Hello #{name}!"
# => "Hello World!"
```

Crystal convierte automáticamente el resultado de la expresión a un string.

```crystal
"Hello #{1 + 1}!"
# => "Hello 2!"
```

## Tamaño

Cuando necesitas saber cuántos caracteres tiene un string, puedes usar el método `size`, que devuelve la longitud del string como un número entero.
El tamaño de un string es una propiedad almacenada del string, así que no tiene que calcular el tamaño cada vez que llamas al método, lo que lo hace muy rápido.

```crystal
"Hello World".size
# => 11
```

## Indexación

La indexación es cuando quieres obtener un carácter específico de un string.
Para obtener un carácter de un `String` puedes usar la conocida notación de corchetes.

~~~~exercism/note
`[]` está implementado como un método de instancia de String, donde el índice es el argumento del método.
~~~~

En Crystal, el primer carácter de un string está en el índice 0.

```crystal
"Hello World"[0]
# => 'H'

"Hello World"[6]
# => 'W'
```

Para obtener un carácter del final de un string, puedes tomar la longitud del string menos uno para obtener el índice del último carácter; para obtener el penúltimo carácter, tomas la longitud del string menos dos, y así sucesivamente.
Existe un atajo para esto y es simplemente usar un índice negativo, donde el último carácter está en el índice -1, el penúltimo carácter está en el índice -2, y así sucesivamente.

```crystal
name = "Hello World"
name[name.size - 1]
# => 'd'

name[-1]
# => 'd'
```

### Prueba de subcadena

Crystal permite comprobar si un string contiene una subcadena usando indexación.
La misma notación de corchetes lo hace, pero en lugar de un índice se le pasa una subcadena.
Si la subcadena se encuentra en el string, se devuelve la subcadena; de lo contrario, se lanza un `NilAssertionError`.

```crystal
"Hello World"["Hello"]
# => "Hello"

"Hello World"["Goodbye"]
# => NilAssertionError
```

Si quieres un valor `Bool` que indique si la subcadena se encuentra, puedes usar el método `includes?`.

```crystal
"Hello World".includes?("Hello")
# => true

"Hello World".includes?("Goodbye")
# => false
```

## Secuencias de escape

Algunos caracteres no se pueden escribir directamente en un string; en su lugar, tienes que usar una secuencia de escape.
Por ejemplo, si quieres usar comillas dobles en un string, tienes que escapar las comillas dobles.
Puedes usar el carácter `\` para escribir una secuencia de escape seguida del carácter que quieres escapar.

Estos son los caracteres especiales en Crystal:

| Valor    | Descripción                   |
| -------- | ----------------------------- |
| `\a`     | Alerta                        |
| `\b`     | Retroceso                     |
| `\e`     | Escape                        |
| `\f`     | Avance de página              |
| `\n`     | Salto de línea o nueva línea  |
| `\r`     | Retorno de carro              |
| `\t`     | Tabulación horizontal         |
| `\v`     | Tabulación vertical           |
| `\\`     | Barra invertida               |
| `\'`     | Comilla simple                |
| `\"`     | Comilla doble                 |
| `\377`   | Carácter ASCII octal          |
| `\xFF`   | Carácter ASCII hexadecimal    |
| `\uFFFF` | Carácter Unicode hexadecimal  |

```crystal
puts "Hello \"World\""
# => Hello "World"

puts "Hello \nWorld"
# => Hello
# => World
```

## Strings de varias líneas

Para escribir un string de varias líneas, usas la misma sintaxis que en un string de una sola línea, pero haces un salto de línea por cada línea que quieras en el string.

```crystal
"Hello
World"
# => "Hello\nWorld"
```

## Unicode

[Unicode][unicode] es un estándar para codificar, representar y procesar texto en distintos sistemas de escritura.
Unicode admite más de 100,000 caracteres, incluidas letras, signos de puntuación, símbolos y emojis.

Como Crystal usa Unicode para los strings, puedes, por ejemplo, poner emojis en ellos.

```crystal
"Hello 🌍"
# => "Hello 🌍"
```

A veces quieres usar un carácter que no está disponible en, por ejemplo, tu editor o tu sistema.
En ese caso, puedes usar la secuencia de escape de Unicode para escribir el carácter.

```crystal
"\u{1F310}"
# => "🌐"
```
