# Acerca de

En Haxe, un tipo abstracto es un tipo que en tiempo de ejecución es otro tipo distinto. Es una característica de tiempo de compilación que define tipos «por encima» de tipos concretos con el fin de modificar o ampliar su comportamiento:

```haxe
abstract AbstractInt(Int) {
    inline public function new(i:Int) {
        this = i;
    }
}
```

Aquí declaramos el tipo `AbstractInt` usando la palabra clave `abstract`. Su sintaxis es muy similar a la de `class`. Y al igual que las clases, los tipos abstractos pueden tener métodos. También se pueden instanciar y usar igual que las clases:

```haxe
class Main {
    static public function main() {
        var a = new AbstractInt(12);
        trace(a); // 12
    }
}
```

Como mencionamos antes, los abstractos son una característica de tiempo de compilación. Si compilas el ejemplo anterior a JavaScript, obtienes lo siguiente:

```javascript
var a = 12;
console.log(a)
```

El tipo abstracto `AbstractInt` desaparece por completo de la salida. Eso es porque el constructor de `Abstract` es [inline][inline], algo que veremos más adelante.

[inline]: https://haxe.org/manual/class-field-inline.html
