# Introducción

En programación, es esencial manejar los errores de forma adecuada para que las situaciones inesperadas no hagan que un programa falle o se comporte de manera impredecible.
Cairo ofrece dos mecanismos principales para el manejo de errores:

1. **Errores irrecuperables** con `panic`, que detienen el programa de inmediato.
2. **Errores recuperables** con `Result`, que permiten que el programa maneje los errores y responda a ellos.

## Errores irrecuperables con `panic`

A veces, un programa se encuentra con un error tan grave que no puede continuar.
En esos casos, Cairo usa la función `panic` para detener la ejecución de inmediato.
Esto es útil cuando un error, como intentar acceder a un índice fuera de los límites, hace imposible que el programa continúe de una manera razonable.
La función `panic` acepta un mensaje de tipo `ByteArray` que describe el motivo del error.

Por ejemplo, en Cairo:

```rust
fn main() {
    let data = array![1, 2];
    panic("An unrecoverable error has occurred!");
}
```

Este ejemplo muestra un pánico forzado, que detiene el programa de inmediato con un mensaje.

### La macro `assert!`

La macro `assert!` es una herramienta útil para hacer cumplir condiciones específicas en tu código.
Si la condición dentro de `assert!` se evalúa como `false`, el programa entrará en pánico con un mensaje de error de tipo `ByteArray`.
A menudo se usa para verificar suposiciones durante el desarrollo y asegurar que los valores cumplan ciertos criterios.

Por ejemplo:

```rust
fn main() {
    let x = 5;
    assert!(x > 0, "x must be greater than zero");
}
```

Si `x` no es mayor que cero, el programa entrará en pánico con el mensaje `"x must be greater than zero"`. `assert!` es útil para comprobar invariantes y precondiciones sin escribir manualmente código de manejo de errores.

## Errores recuperables con `Result`

No todos los errores necesitan detener el programa.
Algunos se pueden manejar de forma adecuada para que el programa continúe.
El enum `Result` de Cairo representa estos errores recuperables y tiene dos variantes:

- `Result::Ok` indica éxito.
- `Result::Err` representa un error.

Con `Result`, una función puede devolver un valor de éxito o un error, lo que permite que la función que la llamó decida qué hacer a continuación.

```rust
fn divide(a: u32, b: u32) -> Result<u32, ByteArray> {
    if b == 0 {
        Result::Err("Error: Division by zero")
    } else {
        Result::Ok(a / b)
    }
}
```

En este ejemplo, si `b` es cero, se devuelve un error; de lo contrario, se devuelve el resultado de la división.
