# Instrucciones

Hola, Agente Double-Null0111.

Tu misión, si decides aceptarla, es escribir un par de herramientas para ayudarte a infiltrarte en la sede de UMBRA (United Minions Being Really Awful) y recuperar los planes de su último y horrible complot. Necesitarás tres herramientas para llevar a cabo esta misión.

## 1. Genera un número de identificación

Cada esbirro tiene un identificador único que cambia cada día y depende de la cantidad de secretos que guarda y de la cantidad de horas que duerme.
Deberás escribir una función que reciba el día (como un `Int`) y cree una función generadora de identificadores para ese día.
La función generadora de identificadores recibe dos parámetros:

1. la cantidad de secretos que guarda
2. la cantidad de horas que duerme el esbirro

El identificador se calcula así:

1. multiplica la cantidad de secretos que guarda por la cantidad de horas que duerme
2. suma el día (representado como un `Int`) al resultado

```kotlin
val idGenerator = makeIdGenerator(4)
idGenerator(3, 6)
// => 22

idGenerator(11, 5)
//  => 59
```

## 2. Protege los planes secretos recuperados con una contraseña secreta

Una vez que tengas los planes secretos, deberás protegerlos para que solo quienes conozcan la contraseña puedan recuperarlos.
Para hacerlo, deberás implementar la función `protectSecret(secret: String, password: String) : (String) -> String`.
Esta función devolverá otra función que recibe como argumento posibles contraseñas.
Si la contraseña ingresada es correcta, la nueva función devuelve el secreto oculto; pero si la contraseña es incorrecta, la función devuelve «Sorry. No hidden secrets here.».

```kotlin
val secretFunction = protectSecret("Steal the world's supply of french fries!", "5up3r53cr37")

secretFunction("Open sesame")
// Returns "Sorry. No hidden secrets here."

secretFunction("5up3r53cr37")
// Returns "Steal the world's supply of french fries!"
```

## 3. Encuentra la contraseña secreta

La base de UMBRA tiene varias salas custodiadas por un guardia de seguridad que te pedirá la contraseña secreta.
La contraseña secreta depende del número de la sala.
Lamentablemente, solo conocemos la mitad del algoritmo para calcular la contraseña.
La otra mitad se puede obtener preguntándole a uno de los esbirros.

Implementa la función `getPassword`, que recibe lo siguiente y devuelve la contraseña:

1. el número de la sala
2. la función del esbirro y devuelve la contraseña secreta

La contraseña secreta se obtiene llamando a la función del esbirro con otra función que representa el algoritmo que conocemos.
Nuestra parte del algoritmo:

1. toma dos números y los suma
2. multiplica el resultado por el id de la sala

```kotlin
val minionFunction = { yourFunc : (Int, Int) -> Int ->
    "Password=${yourFunc(1, 3)}"
}

getPassword(5, minionFunction)
// Returns "Password=20"
```
