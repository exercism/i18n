# Pistas

## 1. Comprueba si es posible la acción «Ataque rápido»

- El operador lógico de negación (`not`) se puede colocar delante de una expresión para negar su valor.

## 2. Comprueba si es posible la acción «Acércate y espía»

- Las expresiones lógicas se evalúan de izquierda a derecha y se comprueban posibles «cortocircuitos».

## 3. Comprueba si es posible la acción «Señaliza al prisionero»

- Los operadores lógicos, en orden de precedencia (de mayor a menor): `not`, `&&`, `||`.
