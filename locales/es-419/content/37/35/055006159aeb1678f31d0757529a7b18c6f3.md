# Acerca de

Las [tuplas][tuple] se usan comúnmente para agrupar información; se diferencian de las listas en que tienen un tamaño fijo y pueden contener distintos tipos de datos.
Las tuplas se crean usando paréntesis, `()`, y a menudo se usan para devolver varios valores desde una función.

```haskell
tuple = (1, "abc", False)
```

Esto puede ser útil cuando, por ejemplo, quieres guardar una coordenada en un espacio 2D, ya que sabes que la tupla siempre tendrá dos elementos: la coordenada x y la coordenada y.

```haskell
coordinate = (3, 4)
```

## Acceder a los elementos

Con bastante frecuencia trabajarás con tuplas cortas, y puedes acceder a sus elementos con las funciones `fst` y `snd`.

```haskell
x = fst coordinate
-- x = 3
y = snd coordinate
-- y = 4
```

[tuple]: https://hackage.haskell.org/package/base/docs/Data-Tuple.html
