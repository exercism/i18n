# Pistas

Usar números complejos para las rotaciones en 2D puede dejar las cosas mucho más limpias y numéricamente más precisas.

## 1. Construye un número complejo a partir de coordenadas cartesianas

- El método incorporado [`complex(x, y)`][complex] es más eficiente que asignar `x + im*y`.
- Consulta la introducción para un repaso.

## 2. Construye un número complejo a partir de coordenadas polares

- Hay varias formas equivalentes de hacerlo (por ejemplo, `exp`, `cis`, `cispi`).
- Consulta la introducción y las instrucciones para un repaso adicional.

## 3. Realiza una rotación de vector en 2D

- La [fórmula de Euler][euler] te será de gran ayuda aquí, y podrías usar tu función `euler`.
- Hay métodos para obtener la parte [real][real] y la parte [imaginaria][imaginary] de un número complejo, ¡o ambas a la vez!

## 4. Realiza un desplazamiento radial

- Tu función `euler` puede servirte, o no...
- El método incorporado [`angle`][angle] se puede usar para encontrar rápidamente un argumento a partir de un número complejo.
- El método [`abs`][abs] se puede usar para encontrar la magnitud de un número complejo.

## 5. Encuentra la canción deseada

- Esta es una buena oportunidad para componer tus funciones `rotate` y `rdisplace`.
