# Acerca de

Un número de punto flotante es un número con cero o más dígitos después del separador decimal. Algunos ejemplos son `4.0`, `0.1`, `3.14`, `-6.4` `16.984025` y `1024.0`. En Ruby, los números de punto flotante se implementan a través de la clase [Float][Float].

Puedes encontrar una breve introducción a los números de punto flotante en [0.30000000000000004.com][0.30000000000000004.com].

La [página Float Toy][evanw.github.io-float-toy] tiene una explicación gráfica muy buena de cómo los bits de un número de punto flotante se convierten en un valor de punto flotante real.

Para ejecutar lógica de forma repetida, puedes usar bucles. En este ejemplo, el bucle `while` es útil porque sigue repitiendo _mientras_ una condición se evalúa como un valor verdadero (es decir, que no sea `false` ni `nil`). Ruby implementa un bucle similar al bucle `while`. Se llama bucle `until`, y probablemente ya adivinaste qué hace. Sigue repitiendo _hasta_ que una condición de tipo Boolean se evalúe como `true`. En algunos lenguajes, para hacer que un fragmento de código se ejecute un número ilimitado de veces, se usan construcciones como `while true`. En Ruby, el bucle `loop` existe para ese propósito. Aunque el bucle `loop` no depende de una sola condición, se puede cancelar usando la palabra clave `return` o `break`.

El método `#years_before_desired_balance` del ejercicio anterior podría haberse escrito usando cualquiera de los tres bucles mencionados:

## `while`

```ruby
def self.years_before_desired_balance(current_balance, desired_balance)
  years = 0
  while current_balance < desired_balance
    current_balance = annual_balance_update(current_balance)
    years += 1
  end
  years
end
```

## `until`

```ruby
def self.years_before_desired_balance(current_balance, desired_balance)
  years = 0
  until current_balance >= desired_balance
    current_balance = annual_balance_update(current_balance)
    years += 1
  end
  years
end
```

## `loop`

```ruby
def self.years_before_desired_balance(current_balance, desired_balance)
  years = 0
  loop do
    current_balance = annual_balance_update(current_balance)
    years += 1
    return years if current_balance >= desired_balance
  end
end
```

Como probablemente ya notaste, Ruby no tiene un operador de incremento (`i++`) como sí tienen otros lenguajes. En su lugar, puedes usar construcciones como `i += 1` (que equivale a `i = i + 1`).
