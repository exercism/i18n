# Introducción

Un `Map` se usa para almacenar pares de **clave** y **valor**. Los `Maps` se inicializan igual que un array, pero usan el operador de literal de mapa `=>`. También pueden tener sus tipos de clave y valor definidos explícitamente, o los tipos se pueden inferir. Las claves deben ser únicas; de lo contrario, se lanza un error.

```haxe
var map1:Map<Int, String> = [1 => "one", 2 => "two", 3 => "three"];

var map2 = ["one" => 1, "two" => 2, "three" => 3];

var map3 = [1 => "cat", 1 => "dog"]; // Error: Duplicate Key

var map4 = ["h" => "Hello", "b" => "Bye"];
trace(map4["h"]); // Hello
```

Un `Map` se puede recorrer con un bucle `for`. Puedes recorrer los valores o las claves:

```haxe
for (value in map) {
  // ...
}

for (key in map.keys()) {
  // ...
}
```
