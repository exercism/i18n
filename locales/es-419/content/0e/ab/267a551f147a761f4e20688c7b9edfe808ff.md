# Anexo de instrucciones

Cada lista de entradas se representa como un string, con un carácter de salto de línea al final de cada entrada.

Un ejemplo sería `"nail\nshoe\nhorse\nrider\nmessage\nbattle\nkingdom\n"`

Cada línea de salida debe terminar con un salto de línea `\n`.

## Memoria reservada

Los bytes 128-383 de la memoria lineal están reservados para el string de entrada.
