# Introducción

Una *tupla* agrupa varios valores con nombre en un solo objeto, lo que otros lenguajes llaman un registro, struct o clase. Cada clase de tupla tiene un conjunto fijo de ranuras con nombre, y Factor genera automáticamente getters y setters para ellas.

## Definir una tupla

Cada ranura se declara `{ name initial: default-value }`. Sin una cláusula `initial:`, el valor predeterminado es `f`.

```factor
TUPLE: point
    { x initial: 0 }
    { y initial: 0 } ;
```

## Construir una tupla

El constructor más simple es `new`:

```factor
point new .
! => T{ point }
```

`boa` («por orden de argumentos») llena las ranuras en el orden de declaración desde la pila de datos:

```factor
3 4 point boa .
! => T{ point { x 3 } { y 4 } }
```

La sintaxis literal `T{ class { slot value } … }` te permite construir una tupla con un subconjunto de ranuras establecidas, y se imprime de la misma manera:

```factor
T{ point { x 3 } } .
! => T{ point { x 3 } }
```

Cuando el valor de una ranura coincide con su valor predeterminado, se omite.

## Leer una ranura

Factor genera un getter `slot>>` para cada ranura. Los getters se encuentran en [`accessors`][accessors]:

```factor
T{ point { x 3 } { y 4 } } x>> .
! => 3
```

## Actualizar una ranura

Los setters se escriben `>>slot` y *mutan* la tupla en el mismo lugar:

```factor
T{ point { x 3 } { y 4 } } 10 >>x .
! => T{ point { x 10 } { y 4 } }
```

Para no modificar la tupla original, usa `clone` primero:

```factor
: shifted ( pt -- pt' )
    clone 10 >>x ;
```

`change-slot` toma una quotation que transforma el valor actual en el nuevo:

```factor
: shift-x ( pt dx -- pt )
    [ + ] curry change-x ;
```

`change-x` también muta, así que usa `clone` antes de llamarlo si quieres conservar la tupla original.
