# Acerca de

Imagina que tienes una base de código de varios cientos de miles de líneas. Te pasan el diccionario de desarrolladores a algún método que estás desarrollando. Tal vez te hayan encargado imprimir los detalles de los desarrolladores privilegiados. Decides borrar el color de ojos en el diccionario para proteger la privacidad de los desarrolladores. A menos que se haya hecho una [copia profunda][so-deep-copy] del diccionario en el método `Authenticator.GetDevelopers()` o, mejor aún, se haya envuelto en una colección de solo lectura, habrás destrozado el autenticador.

Esto sigue el principio de la [copia defensiva][defensive-copying]. Puedes asegurarte de que tu API formal no se eluda evitando exponer el estado interno modificable a quien llama.

[so-deep-copy]: https://stackoverflow.com/questions/78536/deep-cloning-objects
[defensive-copying]: https://www.informit.com/articles/article.aspx?p=31551&seqNum=2
