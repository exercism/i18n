# Introducción

Una propiedad en C# es un miembro de una clase que proporciona acceso a los datos dentro de esa clase.
Quien llama puede establecer los datos u obtenerlos (get). Las propiedades pueden ser autoimplementadas o
tener un campo de respaldo. Incluyen un descriptor de acceso set y/o un descriptor de acceso get.
En algunos otros lenguajes, un «mutator» equivale más o menos a
un descriptor de acceso set, y un «accessor» equivale más o menos a un descriptor de acceso get, aunque
la composición de la sintaxis es completamente distinta.

Al establecer una propiedad, el valor de entrada se puede validar, dar formato
o manipular de alguna otra manera y, de hecho, se puede ejecutar cualquier operación programática a la que tenga acceso el código de la
clase.

De forma similar, al obtener una propiedad, los datos se pueden calcular o dar formato y, una vez más,
se puede ejecutar cualquier operación programática disponible para la clase.

Las propiedades tienen modificadores de acceso (`public`, `private`, etc.) igual que los demás
miembros de la clase, pero el descriptor de acceso set puede tener un nivel de acceso independiente del descriptor de acceso de obtención (get)
y viceversa. Una propiedad no tiene que tener ambos descriptores de acceso; puede tener solo uno (ya sea get o set).

La sintaxis básica para expresar propiedades puede tomar dos formas:

## Propiedades respaldadas por un campo o una expresión:

```csharp
private int myField;
public int MyProperty
{
    get { return myField; }
    set { myField = value; }
}
```

## Propiedades autoimplementadas

```
public int MyProperty { get; private set; } = 42;
```

La inicialización es opcional.
