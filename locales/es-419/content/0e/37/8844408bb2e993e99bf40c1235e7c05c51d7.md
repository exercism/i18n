# Recursos

- [The Zig Programming Language Documentation][documentation] es un gran resumen de todas las funcionalidades del lenguaje que Zig ofrece a quienes lo usan.
- [The Zig Standard Library][std] es una buena referencia para aprender cómo se escribe el código de Zig y muestra muchas de las funciones que puedes importar en tu propio código.
- [Awesome Zig][awesome-zig] es una lista curada de proyectos de Zig.
- [#zig][irc] en irc.freenode.net es el canal principal de IRC de Zig.
- [Stack Overflow][stack-overflow] se puede usar para descubrir fragmentos de código y soluciones a problemas que quizás otros ya hayan preguntado y tal vez resuelto.
- [/r/Zig][reddit] es el subreddit principal de Zig.
- [The Zig Programming Language Discord][discord-zig] es el [Discord][discord] principal.
  Ofrece una gran forma de ponerte en contacto con la comunidad de Zig en general y de obtener ayuda rápida y directa para cualquier problema relacionado con Zig.
- [The Zig SHOWTIME Newsletter][newsletter] anuncia nuevos episodios, eventos importantes y enlaces a proyectos nuevos e interesantes de Zig.
