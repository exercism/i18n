# Acerca de

Un [bucle `for`][for-statement] te permite ejecutar código repetidamente en un bucle hasta que se cumpla una condición.

```csharp
for (int i = 0; i < 5; i++)
{
    System.Console.Write(i);
}

// => 01234
```

Un bucle `for` consta de cuatro partes:

1. El inicializador: se ejecuta una vez antes de entrar al bucle. Por lo general, se usa para definir las variables que se usarán dentro del bucle.
2. La condición: se ejecuta antes de cada iteración del bucle. El bucle sigue ejecutándose mientras esta se evalúe como `true`.
3. El iterador: se ejecuta después de cada iteración del bucle. Por lo general, se usa para modificar (a menudo: incrementar o decrementar) la variable o las variables del bucle.
4. El cuerpo: el código que se ejecuta en cada iteración del bucle.

## Bucles `for` frente a bucles `foreach`

En general, los [concept:csharp/foreach-loops]() son preferibles a los bucles `for` por las siguientes razones:

- Un bucle `foreach` garantiza que se itera sobre _todos_ los valores. Con un bucle `for`, es fácil omitir elementos, por ejemplo, debido a un error por desfase de uno.
- Un bucle `foreach` es más _declarativo_. Tu código comunica _qué_ quieres que haga, en lugar de un bucle `for` que comunica _cómo_ quieres hacerlo.
- Un bucle `foreach` es a prueba de errores, mientras que con los bucles `for` es fácil cometer un error por desfase de uno.
- Un bucle `foreach` funciona con todos los tipos de colección, incluidas aquellas que no permiten usar un indexador para acceder a los elementos.

Para garantizar que un bucle `foreach` itere sobre _todos_ los valores, el compilador no permite modificar una colección dentro de un bucle `foreach`:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // This would result in a compiler error
    // vowel = 'Y';
}
```

Un bucle `for` sí tiene algunas ventajas sobre un bucle `foreach`:

- Puedes empezar o detenerte en el índice que quieras.
- Puedes usar cualquier condición de terminación (de tipo Boolean) que quieras.
- Puedes omitir elementos personalizando el incremento de la variable del bucle.
- Puedes procesar colecciones de atrás hacia adelante contando hacia atrás.
- Puedes usar bucles `for` en escenarios que no involucran colecciones.
