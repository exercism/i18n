# Pruebas

## Ejecutar las pruebas

Para ejecutar las pruebas, ejecuta el siguiente comando en el directorio del ejercicio:

```shell
make
```

Esto ensambla tu solución, compila las pruebas, las enlaza en un programa RISC-V y lo ejecuta bajo `qemu-riscv32`.
El programa imprime una línea por cada prueba, mostrando si pasó, falló o se ignoró, y después un resumen.

## Resolver el ejercicio

Resolver un ejercicio significa hacer que todas sus pruebas pasen.
De forma predeterminada, solo se ejecuta una prueba (la primera) cuando ejecutas las pruebas.
Esto es intencional, ya que te permite concentrarte únicamente en hacer que esa prueba pase.
Una vez que pase, puedes habilitar la siguiente prueba eliminando la línea `TEST_IGNORE();`.
Cuando hayas habilitado todas las pruebas y tu implementación las haga pasar todas, ¡habrás resuelto el ejercicio!
