# Apéndice de instrucciones

## Pistas

Para completar este ejercicio necesitas implementar la función `score`,
que toma una secuencia de *tiradas* de boliche y devuelve el puntaje final o
el error correspondiente:

```haskell
score :: [Int] -> Either BowlingError Int

data BowlingError = IncompleteGame
                  | InvalidRoll { rollIndex :: Int, rollValue :: Int }
                  deriving (Eq, Show)
```

Encontrarás estas definiciones ya en su lugar, pero depende de ti
definir la función.

Ten en cuenta que el conjunto de pruebas espera que las tiradas se numeren
empezando desde cero.
