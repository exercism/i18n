# Instrucciones

En este ejercicio vas a escribir un `SecureTreasureChest` genérico (¡y hasta mágico!) para guardar un tesoro.
Los estudiantes con buen ojo habrán notado que el anterior `TreasureChest` no era tan seguro.
Si usabas la función `getTreasure`, tenías que proporcionar la contraseña, pero igual podías simplemente desestructurar el tipo `TreasureChest` para obtener el tesoro, sin tener que saber la contraseña.
Y lo que es peor, ¡incluso podías obtener la contraseña de la misma forma!
Vamos a arreglarlo usando un tipo opaco.

## 1. Define el tipo opaco Password usando el patrón «Parse, don't validate»

Define un tipo personalizado `Password` con una sola variante.

La variante debe tener un valor `String` asociado para la contraseña.

Debes exponer el tipo `Password`, pero no la variante.
Esto hace que `Password` sea un tipo opaco, y significa que ya no puedes usar desestructuración para obtener la contraseña.
No es posible comprobar si un tipo es opaco o no; en código de producción usarías [elm-review][elm-review] (una herramienta de análisis estático) para hacerlo cumplir.

Define y expón una función `createPassword`, con una anotación de tipo, que tome un `String` y devuelva un `Maybe Password`.

Owasp recomienda que [las contraseñas tengan al menos 8 caracteres][owasp-password-length], así que usemos el patrón [Parse, don't validate][parse-dont-validate] para hacer cumplir esta invariante.

Si la contraseña tiene menos de 8 caracteres, `createPassword` debe devolver `Nothing`; de lo contrario, debe devolver `Just Password`.

## 2. Expón SecureTreasureChest, pero no su variante

Debes exponer el tipo `SecureTreasureChest`, pero no la variante.
Esto hace que `SecureTreasureChest` sea un tipo opaco, y significa que ya no puedes usar desestructuración para obtener la contraseña ni el tesoro.

## 3. Define la función createTreasure

Esta función debe tomar dos parámetros y tener una anotación de tipo.

- un tipo genérico (para el tesoro)
- un `Password` (para la contraseña)

La función debe devolver un `SecureTreasureChest`.

Expón esta función para que otros módulos puedan crear instancias de `SecureTreasureChest`.

## 4. Define la función getTreasure

Esta función debe tomar dos parámetros y tener una anotación de tipo.

- un `String` (para la contraseña)
- un tipo personalizado genérico `SecureTreasureChest`

Esta función debe comprobar el intento de contraseña proporcionado contra el `Password` que está en el `SecureTreasureChest`.

La función debe devolver un `Maybe`.

Si las contraseñas coinciden, devuelve `Just` con el valor genérico del `SecureTreasureChest` (¡el tesoro!).

Si las contraseñas no coinciden, devuelve `Nothing`.

Expón esta función para que otros módulos puedan obtener el tesoro de un `SecureTreasureChest`, siempre que proporcionen la contraseña correcta.
