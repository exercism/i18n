# Pruebas

Puedes ejecutar las pruebas incluidas con DrRacket o desde la línea de comandos.

Para ejecutar las pruebas con DrRacket, solo abre el archivo de pruebas y haz clic en el botón «Run» en la parte superior derecha.

Para ejecutar las pruebas desde la línea de comandos, simplemente ejecútalas desde el directorio del ejercicio. Por ejemplo, si el conjunto de pruebas se llama `hello-world-test.rkt`, puedes ejecutar el siguiente comando:

```
raco test hello-world-test.rkt
```

que mostrará lo siguiente:

```
raco test: (submod "hello-world-test.rkt" test)
2 success(es) 0 failure(s) 0 error(s) 2 test(s) run
0
2 tests passed
```
