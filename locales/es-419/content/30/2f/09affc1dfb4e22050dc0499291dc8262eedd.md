# Acerca de

`assocs` es un [protocolo][assoc-protocol], no un único tipo de datos. Las tablas hash (`H{ }`),
las listas de asociación (secuencias de pares `{ key value }`) y los mapas de árbol
lo implementan todos, y la mayoría de las palabras sobre assocs son intercambiables
entre ellos.

```factor
USING: assocs ;

H{ } clone "coal" over inc-at
"coal" over inc-at
"wood" over inc-at      ! => H{ { "coal" 2 } { "wood" 1 } }
```

El conjunto completo de palabras es amplio (iteración ordenada, mapeo, filtrado),
pero la mayoría del trabajo a nivel de ejercicio gira en torno a un grupo pequeño:

| palabra     | efecto en la pila                             |
|-------------|-----------------------------------------------|
| `at`        | `( key assoc -- value/f )`                    |
| `at*`       | `( key assoc -- value ? )` distingue f como valor de una clave ausente |
| `key?`      | `( key assoc -- ? )`                          |
| `set-at`    | `( value key assoc -- )`: modifica el assoc   |
| `change-at` | `( key assoc quot -- )`: `quot` es `( old -- new )` |
| `inc-at`    | `( key assoc -- )`: suma `+1` e inserta `1` si no está |
| `delete-at` | `( key assoc -- )`: modifica el assoc         |
| `>alist`    | `( assoc -- pairs )`                          |

`sort-keys` y `sort-values` (en `sorting`) ordenan un alist según el
campo elegido.

[assoc-protocol]: https://docs.factorcode.org/content/article-assocs-protocol.html
