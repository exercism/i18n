# Instrucciones

Tu tarea es crear un cronómetro que lleve un registro preciso de los tiempos de vuelta.

El cronómetro usa cuatro comandos (start, stop, lap y reset) para llevar el registro de:

1. El tiempo registrado de la vuelta actual
2. Los tiempos de vuelta registrados anteriormente

Qué comandos se pueden usar depende del estado en el que se encuentre el cronómetro:

1. Ready: estado inicial
2. Running: registrando el tiempo
3. Stopped: sin registrar el tiempo

| Comando | Estado inicial | Estado final | Efecto                                                   |
| ------- | ----------- | --------- | -------------------------------------------------------- |
| Start   | Ready       | Running   | Empezar a registrar el tiempo                            |
| Start   | Stopped     | Running   | Reanudar el registro del tiempo                          |
| Stop    | Running     | Stopped   | Detener el registro del tiempo                           |
| Lap     | Running     | Running   | Agregar la vuelta actual a las vueltas anteriores y después reiniciar la vuelta actual |
| Reset   | Stopped     | Ready     | Reiniciar la vuelta actual y borrar las vueltas anteriores |
