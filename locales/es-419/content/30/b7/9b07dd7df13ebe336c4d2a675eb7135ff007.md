# Pistas

## 1. Reemplaza cualquier espacio que encuentres con guiones bajos

La biblioteca `clojure.string` integrada contiene una función [`replace`][str-replace].

## 2. Reemplaza los caracteres de control con el string en mayúsculas «CTRL»

Puedes usar el método [`isISOControl`][java-ctrl] de la clase `Character` de Java.

## 3. Convierte kebab-case a camelCase

Intenta separar el string en los guiones con [`split`][str-split].
Si no contiene guiones, debes devolverlo tal como está. Puedes verificar esto con [`includes?`][str-includes]. Usa [`upper-case`][str-upper-case] para formar las «jorobas» de camelCase. Por último, concaténalos con [`join`][str-join].

## 4. Omite los caracteres que no sean letras

Puedes filtrar caracteres usando [`Character/isLetter`][java-isletter] como predicado.

## 5. Omite las letras griegas minúsculas

Las letras griegas minúsculas son los puntos Unicode `\u03B1` a `\u03C9`, o los valores enteros 945 a 969.
