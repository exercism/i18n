# Acerca de

Los inicializadores de objetos son una alternativa a los constructores. La sintaxis es una lista de pares campo=valor separados por comas, como se muestra a continuación:

```csharp
public class Person
{
    public string Name;
    public string Address;
}

var person = new Person{Name="The President", Address = "Élysée Palace"};
```

Las colecciones también se pueden inicializar de esta manera. Por lo general, esto se logra con listas separadas por comas, como se muestra aquí:

```csharp
IList<Person> people = new List<Person>{ new Person(), new Person{Name="Joe Shmo"}};
```

Este enfoque (y esta sintaxis) se puede usar con cualquier clase que implemente `IEnumerable` y tenga un método `Add()`.

Los campos se pueden enumerar en cualquier orden u omitirse por completo.

Los diccionarios usan la siguiente sintaxis:

```csharp
IDictionary<int, string> numbers = new Dictionary<int, string>{ [0] = "zero", [1] = "one"...};

// or

IDictionary<int, string> numbers = new Dictionary<int, string>{ {0, "zero" }, {1,  "one"}...};
```

Los campos inicializados deben ser accesibles para quien llama. Por lo general, esto significa que deben ser `public` o `internal`.

Existe una fuerte tendencia a promover la inmutabilidad entre los diseñadores del lenguaje y los profesionales destacados, por lo que la mutabilidad de los objetos inicializados de esta manera se considera una desventaja. Hay propuestas para introducir una cláusula `init` en la próxima versión del lenguaje, C# 9, que podría resolver esto.

- La documentación de [inicializador de objetos][object-initializers] describe cómo usar los inicializadores.
- La documentación de [inicializador de colecciones][collection-initializers] ofrece un avance de cómo se pueden usar los inicializadores con colecciones como diccionarios y listas.
