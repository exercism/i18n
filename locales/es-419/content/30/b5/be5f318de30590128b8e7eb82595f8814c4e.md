# Anexo de instrucciones

## Implementación

Hay muchas formas de resolver este ejercicio, pero incluimos algunos stubs adicionales para quienes quieran practicar cómo escribir sus propios [ability handlers][ability-handler-docs].

La firma de la función auxiliar `checkBalance` que se da para este ejercicio hace uso de un requisito de ability, `{Stack}`.
La ability `Stack` está definida para ti, pero el handler, `Stack.run`, no lo está.
Si quieres, puedes implementar las funciones `Stack.run`, `checkBalance` e `isPaired`.
Los tests se ejecutarán igual aunque decidas no implementar este ejercicio con abilities.

[ability-handler-docs]: https://www.unison-lang.org/learn/fundamentals/abilities/writing-abilities/
