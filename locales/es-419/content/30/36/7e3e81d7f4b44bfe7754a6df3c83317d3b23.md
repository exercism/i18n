# Anexo de instrucciones

## Formato del campo minado

El campo minado se representa como un string terminado en null, con un carácter de nueva línea al final de cada fila.

Un ejemplo sería `"   \n * \n   \n"`

## Registros

| Registro | Uso          | Tipo    | Descripción                   |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | entrada      | dirección | string de entrada terminado en null  |
| `$a1`    | entrada/salida | dirección | string de salida terminado en null |
| `$t0-9`  | temporal     | cualquiera | para almacenamiento temporal         |
