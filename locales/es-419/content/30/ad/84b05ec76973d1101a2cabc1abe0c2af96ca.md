# Introducción

En un lenguaje funcional puro como Elm, una función llamada con los mismos argumentos debe devolver siempre el mismo valor.
Por lo tanto, una función con la firma de tipo `rand : Int` solo se puede implementar como `rand = 4`, lo que no augura nada bueno para generar números enteros aleatorios.

Entonces, ¿cómo generamos valores aleatorios en Elm?
Dividimos el problema en dos: primero describimos el valor que queremos generar con un `Random.Generator a`, y luego generamos un valor.

La primera forma de generar un valor es crear una `Random.Seed` con `initialSeed : Int -> Seed` y luego usar `step : Generator a -> Seed -> ( a, Seed )`, que devuelve un valor y una nueva semilla.
Ten en cuenta que ambas funciones son puras, así que si las llamas dos veces con los mismos argumentos obtendrás los mismos valores.

La segunda forma de generar un valor es usar `generate : (a -> msg) -> Generator a -> Cmd msg`, pero eso solo se puede hacer dentro de una aplicación de Elm.
En ese caso, el entorno de ejecución de Elm puede usar `step` y también recursos externos no puros para generar semillas.

De aquí en adelante nos centraremos en los generadores.

Supongamos, para poder mostrar ejemplos, que con `initialSeed` y `step` hemos definido una función `generate : Int -> Generator a -> List a` que genera cierta cantidad de valores a partir de un generador.

El módulo `Random` ofrece dos generadores básicos para generar números enteros y números de punto flotante dentro de un rango específico:

```elm
generate 5 (Random.int -5 5)
    --> [0, 3, -5, 5, 0]

generate 3 (Random.float 0 5)
    --> [1.61803, 3.14159, 2.71828]
```

Esos valores se pueden combinar en tuplas, o en listas de valores:

```elm
generate 2 (Random.list 3 (Random.int 0 3))
    --> [[0, 3, 3], [1, 3, 2]]

generate 2 (Random.pair (Random.int 0 3) (Random.float 10 10.3))
    --> [(0, 10.23412), (2, 10.17094)]
```

El paquete `elm-community/random-extra` ofrece muchos más generadores para diversas estructuras de datos: strings, fechas, diccionarios, arrays, conjuntos, etc.

Podemos crear generadores que solo devuelvan un único valor con `Random.constant`:

```elm
generate 4 (Random.constant "hello")
    --> ["hello", "hello", "hello", "hello"]
```

Podemos elegir al azar entre los elementos dados con la misma probabilidad usando `Random.uniform`:

```elm
generate 5 (Random.uniform Red [Green, Blue])
    --> [Red, Blue, Blue, Green, Red]
```

`Random.uniform` recibe dos argumentos (`Red` y `[Green, Blue]`) para garantizar que haya al menos un valor entre el que elegir, ya que una sola lista podría estar vacía.

También podemos ajustar las probabilidades con `Random.weighted`:

```elm
generate 5 (Random.weighted (80, Red) [(15, Green), (5, Blue)])
    --> [Red, Red, Green, Red, Red]
```

Los valores no tienen que sumar 100, de todos modos se van a renormalizar.

Podemos llegar al interior de un generador con `Random.map`:

```elm
generate 3 (Random.int 1 6 |> Random.map (\n -> n * 10))
    --> [30, 60, 10]
```

También podemos usar `Random.map2` hasta `Random.map5` para combinar más generadores:

```elm
position =
    Random.map3
      (\x y z -> Position x y z)
      (Random.float -100 100)
      (Random.float -100 100)
      (Random.float -100 100)

generate 1 position
    --> [Position 33.788 -98.321 10.0845]
```

Para usos más complejos, tenemos `Random.andThen : (a -> Generator b) -> Generator a -> Generator b`, que puede usar el valor generado por un generador para crear otro:

```elm
bool = Random.uniform True [False]

failHalfOfTheTime : Generator a -> Generator (Maybe a)
failHalfOfTheTime generator =
    bool
        |> Random.andThen
            (\boolResult ->
                if boolResult then
                    Random.map Just generator

                else
                    Random.constant Nothing
            )

generate 6 (Random.int 0 1 |> failHalfOfTheTime)
    --> [Nothing, Just 1, Just 0, Nothing, Just 1, Nothing]
```

A veces es útil definir un generador de forma autorrecursiva.
En esos casos, puede que necesites usar `Random.lazy` para evitar que el compilador expanda el generador infinitamente.

```elm
type Peano
    = Zero
    | Next Peano


peano : Generator Peano
peano =
    Random.uniform (Random.constant Zero)
        [ Random.map Next (Random.lazy (\_ -> peano))
        ]
        |> Random.andThen identity

generate 12 peano
    --> [Zero, Next(Next(Zero)), Zero, Next(Zero), Zero, Zero, Next(Zero), Zero, Zero, Next(Zero), Next(Next(Next(Zero)))]
```

Este ejemplo es un poco complicado, así que vamos a desglosarlo.

`Peano` es un tipo que representa números enteros positivos: `Zero` es 0, `Next(Zero)` es 1, `Next(Next(Zero))` es 2, etc.
Definimos `peano` para que nos dé un número `Peano` aleatorio.

En primer lugar, fíjate que `Random.lazy` no aporta nada a la lógica, solo evita que el compilador escriba `peano` dentro de `peano` indefinidamente.

Usamos `Random.uniform` para elegir entre cero (con 50% de probabilidad) y otro número `Peano` más uno (con 50% de probabilidad).
Sin embargo, a diferencia del ejemplo anterior, `Random.uniform` no elige entre valores (como `Zero`), sino entre generadores (como `Random.constant Zero`), ya que queremos usar `peano` mismo.
Esto significa que `Random.uniform` devolverá un valor de tipo `Generator (Generator Peano)`, que no es lo que necesitamos.

Para «aplanar» el generador, lo pasamos por `Random.andThen : (a -> Generator b) -> Generator a -> Generator b`, donde queremos que `b` sea `Peano`.
Como `Generator a` es `Generator (Generator Peano)`, `a` debe ser `Generator Peano`, y la función `(a -> Generator b)` debe ser de tipo `(Generator Peano -> Generator Peano)`.
No queremos modificar nada, así que `identity` es la opción correcta.

Por último, ¿qué tipo de números producirá `peano`?
Sabemos que producirá 0 el 50% de las veces, u otra iteración de sí mismo más uno el otro 50% de las veces.
Eso significa que los números serán 0 (el 50% de las veces), 1 (el 25% de las veces), 2 (el 12% de las veces), 3 (el 6% de las veces), etc.
`peano` puede producir números arbitrariamente grandes, pero con una probabilidad que disminuye exponencialmente.
