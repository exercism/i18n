# Pistas

## 1. Extrae los errores

- Puedes hacer coincidir los errores con un patrón usando la sintaxis de patrón `Error(value)`.

## 2. Elimina el prefijo del equipo

- Puedes hacer coincidir los prefijos de string con un patrón usando la sintaxis de patrón `"prefix" <> rest`.

## 3. Separa la región y el equipo

- Puedes dividir un string en un carácter usando la [función `string.split`][split].
- Puedes hacer coincidir las listas con un patrón usando la sintaxis de patrón `[a, b, c]`.

[split]: https://hexdocs.pm/gleam_stdlib/gleam/string.html#split
