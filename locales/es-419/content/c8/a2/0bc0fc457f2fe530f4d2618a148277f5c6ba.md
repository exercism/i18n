# Instrucciones

En este ejercicio debes implementar algunas funciones para manipular un array de lenguajes de programación.

## 1. Define una función que devuelva un array de lenguajes vacío

Define la función `language_list` que no toma argumentos y devuelve un array vacío.

```php
<?php

language_list();
// => []
```

## 2. Modifica la función para crear un array a partir de cualquier cantidad de lenguajes

Modifica la función `language_list` para que tome un argumento variádico de lenguajes (strings).
Debe devolver el array resultante con los lenguajes incluidos.

```php
<?php

$language_list = language_list();
// => []
$language_list = language_list("Clojure", "PHP");
// => ["Clojure", "PHP"]
$language_list = language_list("PHP", "Haskell", "Java", "C++", "Rust")
// => ["PHP", "Haskell", "Java", "C++", "Rust"]
```

## 3. Define una función para agregar un lenguaje al array

Define la función `add_to_language_list` que toma 2 argumentos: un array de lenguajes y el nuevo lenguaje.

```php
<?php

$language_list = language_list();
// => []
$language_list = add_to_language_list($language_list, "Clojure");
// => ["Clojure"]
```

## 4. Define una función para eliminar un elemento del array de lenguajes

Define la función `prune_language_list` para eliminar el primer lenguaje del array de lenguajes.

```php
<?php

$language_list = language_list("PHP");
// => ["PHP"]
$language_list = prune_language_list($language_list);
// => []
```

## 5. Define una función para obtener el primer elemento del array

Define la función `current_language` que toma 1 argumento (un _array de lenguajes_).
Debe devolver el primer lenguaje del array.
Supón que el array siempre tendrá al menos un elemento.

```php
<?php

$language_list = language_list("PHP", "Prolog");
// => ["PHP", "Prolog"]
$first = current_language($language_list);
// => "PHP"
```

## 6. Define una función que devuelva cuántos lenguajes hay en el array

Define la función `language_list_length` que toma 1 argumento (un _array de lenguajes_).
Debe devolver la cantidad de lenguajes en el array.

```php
<?php

$language_list = language_list("PHP", "Prolog", "Wren");
// => ["PHP", "Prolog", "Wren"]
language_list_length($language_list);
// => 3
```
