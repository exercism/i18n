# If, Elseif, Else

Las sentencias condicionales con `if`, `elseif` y `else` son una parte fundamental del control de flujo de un programa.
La sentencia `if` evalúa una expresión y, si es `true`, ejecuta la rama de código.

```php
<?php

if ($expression) {
    // .. executed if $expression is true
}
```

Si la expresión no es un valor Boolean, la evaluación determina si el valor es «verdadero» o «no falso».
En PHP, los siguientes valores se consideran iguales a false:

- Boolean `false`
- número entero `0`
- número de punto flotante `0.0` y `-0.0`
- un array vacío `[]`
- un string vacío `""` o un string numérico `"0"`
- `null`

Todos los demás valores se consideran true.

## Cómo responder a varias condiciones

Después de una sentencia `if`, puedes encadenar varias condiciones con `elseif` y `else`.

```php
<?php

if ($value === 0) {
    // .. do something
} elseif ($value === 1) {
    // .. do something else
} else {
    // ,, do this if nothing else
}
```

Solo se ejecutará una sentencia condicional evaluada como true.
Por eso, si varias condiciones pueden evaluarse como true, el orden en que están escritas es importante.

```php
<?php

if (true) {
    // .. always do something
} elseif (true)
    // .. will never be executed
} else {
    // .. will never be executed
}
```
