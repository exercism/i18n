# Instrucciones

Te han contratado como ingeniero asistente de producción en una empresa que fabrica colchas para tortugas.

Los pedidos llegan a lo largo del día como un nombre o número de cliente y una cantidad de pedido.
Luego se procesan por la mañana, antes de que empiece la producción del día.

Puedes irte a casa con el sueldo completo en cuanto se completen todos los pedidos del día, así que hay incentivos para acortar la jornada laboral todo lo posible.
Como cada pedido lo maneja una sola máquina, programar primero los pedidos más grandes permite trasladar la sobrecarga de arrancar un trabajo a los pedidos más pequeños, lo que acorta el tiempo total de producción.
Por lo tanto, has decidido crear algunas funciones de ordenamiento que ayuden a acelerar esta programación, para que puedas llegar a casa a tejerle un suéter a tu tortuga.

## 1. ¡Ordena las cantidades!

Como se mencionó, el array de cantidades deberá ordenarse de mayor a menor.
Debido al tamaño potencialmente grande de estos arrays, deben ordenarse *in situ*.
Para llevar la cuenta de todo correctamente, también necesitarás poder ordenar el array de clientes para que coincida con las cantidades, así que se necesitará una permutación de ordenamiento de las cantidades.

Escribe una función `sortquantity!(qty)` que recibe un `Vector` de cantidades `Integer`.
Esta función ordena la `qty` de entrada in situ en orden descendente y devuelve una permutación de ordenamiento de este orden.

```julia-repl
julia> qty = [8, 9, 5, 6]
4-element Vector{Int64}:
 8
 9
 5
 6

julia> sortquantity!(qty)
4-element Vector{Int64}:
 2
 1
 4
 3

julia> qty # original vector is sorted in-place
4-element Vector{Int64}:
 9
 8
 6
 5
```

## 2. Ordena los clientes

Como se dijo antes, necesitas llevar la cuenta de los clientes en un orden definido.

Escribe una función `sortcustomer(cust, srtperm)` que recibe un `Vector` de clientes `cust` y un `Vector` de permutación de ordenamiento `srtperm`.
Esta función devuelve un nuevo array con los clientes en el orden que prescribe la permutación de ordenamiento.

```julia-repl
julia> cust = ["a", "b", "c"]
3-element Vector{String}:
 "a"
 "b"
 "c"

julia> sortcustomer(cust, [2, 3, 1])
3-element Vector{String}:
 "b"
 "c"
 "a"

julia> cust # original vector remains unsorted
3-element Vector{String}:
 "a"
 "b"
 "c"
```

## 3. ¡Programa la producción!

¡Ahora puedes unirlo todo para ayudar a mantener calentitas a esas tortugas!
Ya puedes ordenar las cantidades y los clientes correctamente, pero necesitas poder recuperar el orden original para el envío.
Esto se puede hacer con una permutación de ordenamiento inversa.

Escribe una función `production_schedule!(cust, qty)` que recibe un `Vector` de clientes y un `Vector` de cantidades.
Esta función ordena las cantidades in situ en orden descendente.
Devuelve un nuevo `Vector` de clientes ordenados en el mismo orden que las cantidades y una permutación de ordenamiento *inversa* que se puede usar para restaurar los vectores ordenados a su orden original.

```julia-repl
julia> cust, qty = ["a", "b", "c"], [2, 3, 1]
(["a", "b", "c"], [2, 3, 1])

julia> orderedcust, invperm = production_schedule!(cust, qty)
(["b", "a", "c"], [2, 1, 3])

julia> qty # has been sorted in-place
3-element Vector{Int64}:
 3
 2
 1

julia> orderedcust[invperm], qty[invperm] # inverse permutation gives original ordering
(["a", "b", "c"], [2, 3, 1])
```
