# Conceptos básicos

Un programa de Sather está compuesto por **clases** que contienen **rutinas**.

```sather
class GREETER is

   hello : STR is
      return "Hello!";
   end;

end; -- class GREETER
```

## Clases

El nombre de una clase se escribe en mayúsculas, con guiones bajos entre las palabras:
`GREETER`, `STAGE_DIRECTIONS`. Por lo general, el nombre del archivo coincide, en
minúsculas: `stage_directions.sa`.

Toda rutina vive dentro de una clase. No hay código fuera de una.

## Rutinas

Una rutina que produce una respuesta declara el tipo de respuesta después de dos
puntos:

```sather
   hello : STR is
      return "Hello!";
   end;
```

`STR` es el tipo que corresponde al texto. Una rutina que no recibe argumentos se
escribe y se llama sin paréntesis.

Una rutina puede recibir argumentos, escritos entre paréntesis después del nombre:

```sather
   louder(word : STR) : STR is
      return word;
   end;
```

`return` devuelve una respuesta y detiene la rutina de inmediato, así que cualquier
línea que esté debajo se omite.

## Llamadas

Desde fuera de la clase, escribe el nombre de la clase, luego `::` y luego la rutina:

```sather
GREETER::hello
```

Desde dentro de la misma clase, puedes omitir el nombre de la clase. Esta es la forma
habitual de que una rutina use otra:

```sather
   greeting_again : STR is
      return hello;
   end;
```

## Comentarios

Dos guiones marcan el inicio de un comentario que llega hasta el final de la línea.

```sather
   -- Explain why, not what: the code already says what.
   hello : STR is
      return "Hello!";   -- a trailing comment is fine too
   end;
```

Por convención, una clase termina con un comentario que la nombra. Las rutinas, los
bucles y las clases se cierran todas con `end;`, así que el comentario indica a cuál
pertenece ese `end;`:

```sather
end; -- class GREETER
```

## Puntos y coma

Las sentencias terminan con punto y coma. El punto y coma después de la última
sentencia de una rutina es opcional, pero escribirlo siempre es una cosa menos en la
que pensar.
