# Desempaquetado y asignación múltiple

El desempaquetado se refiere al acto de extraer los elementos de una colección, como una `list`, un `tuple` o un `dict`, usando iteración.
Los valores desempaquetados se pueden asignar luego a variables dentro de la misma sentencia.
Un ejemplo muy común de este comportamiento es `for item in list`, donde `item` toma el valor de cada elemento de la `list` a su vez a lo largo de la iteración.

La [asignación múltiple][multiple assignment] es la capacidad de asignar varias variables a valores desempaquetados dentro de una misma sentencia.
Esto permite que el código sea más conciso y legible, y se logra separando con una coma las variables que se van a asignar, como en `first, second, third = (1,2,3)` o `for index, item in enumerate(iterable)`.

Los operadores especiales `*` y `**` se usan a menudo en contextos de desempaquetado.
`*` se puede usar para combinar varias `list`/`tuple` en una sola `list`/`tuple` _desempaquetando_ cada una en una nueva `list`/`tuple` común.
`**` se puede usar para combinar varios diccionarios en un solo diccionario _desempaquetando_ cada uno en un nuevo `dict` común.

Cuando el operador `*` se usa sin una colección, _empaqueta_ una serie de valores en una `list`.
Esto se usa a menudo en la asignación múltiple para agrupar todos los elementos «sobrantes» que no tienen asignaciones individuales en una sola variable.

En Python también es común aprovechar este comportamiento de desempaquetado/empaquetado al usar o definir funciones que aceptan una cantidad arbitraria de argumentos posicionales o de palabra clave.
A menudo verás estos parámetros «especiales» definidos como `def some_function(*args, **kwargs)` y los argumentos «especiales» usados como `some_function(*some_tuple, **some_dict)`.

~~~~exercism/caution
`*<variable_name>` y `**<variable_name>` no deben confundirse con `*` y `**`. Mientras que `*` y `**` se usan para la multiplicación y la exponenciación respectivamente, `*<variable_name>` y `**<variable_name>` se usan como operadores de empaquetado y desempaquetado.
