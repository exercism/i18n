# Instrucciones

Josh está trabajando en un nuevo juego de rol y necesita tu ayuda para implementar algunas de sus mecánicas.

## 1. Define uniones de tipos

Define una unión de tipos de `String` y `Missing` llamada `StringOrMissing`, que puedas usar más adelante en el código.
Define una unión de tipos de `Int64` y `Nothing` llamada `IntOrNothing`, que puedas usar más adelante en el código.

## 2. Implementa el tipo compuesto Player

El tipo compuesto Player debe contener cuatro campos, cada uno con una anotación de tipo y un valor predeterminado:
- El campo `name` es un `StringOrMissing`, con un valor predeterminado de `missing`
- El campo `level` es un `Int64`, con un valor predeterminado de `0`
- El campo `health` es un `Int64`, con un valor predeterminado de `100`
- El campo `mana` es un `IntOrNothing`, con un valor predeterminado de `nothing`

```julia-repl
julia> defaultplayer = Player()
Player(missing, 0, 100, nothing)

julia> wealthyplayer = Player(mana=100)
Player(missing, 0, 100, 100)

julia> namedplayer = Player(name="Guilian", level=10)
Player("Guilian", 10, 100, nothing)
```

## 3. Preséntate

Implementa la función `introduce`.

Es posible que los jugadores sigilosos estén ocultando su nombre, y en ese caso se los presentará como `"Mighty Magician"`. De lo contrario, solo usa el nombre del jugador para presentarlo.

```julia-repl
julia> introduce(Player(level=2, health=8))
"Mighty Magician"

julia> introduce(Player(name="Merlin", level=2, health=8))
"Merlin"
```

## 4. Implementa los métodos de incremento

La función auxiliar `increment` tiene dos métodos, cada uno con una firma de función distinta. El argumento de cada uno necesita una anotación de tipo para que la firma quede explícita.

El método `increment` para nombres debe recibir el `name` de un jugador.
- Si el nombre es `missing`, devuelve el título «The Great».
- De lo contrario, el título « the Great» se agrega al final del nombre.

Este método `increment` devuelve el nombre nuevo.

```julia-repl
julia> player1 = Player(name="Ogre", level=5, health=49, mana=26)
Player("Ogre", 5, 49, 26)

julia> increment(player1.name)
"Ogre the Great"

julia> player2 = Player(level=32, mana=57)
Player(missing, 32, 100, 57)

julia> increment(player2.name)
"The Great"
```

El método `increment` para el mana debe recibir el `mana` de un jugador.
- Si el mana del jugador es `missing`, devuelve un valor de `50`.
- De lo contrario, el mana se debe incrementar en `100`.

Este método `increment` devuelve el mana actualizado.

```julia-repl
julia> player3 = Player(level=3)
Player(missing, 3, 100, nothing)

julia> increment(player3.mana)
50

julia> player4 = Player("Goblin", level=15, health=49, mana=26)
Player("Goblin", 5, 49, 26)

julia> increment(player4.mana)
126
```

## 5. Implementa la función de título

El nivel más alto del juego es `42`. Para reconocer el logro de los jugadores que alcanzan este nivel, se les añade un título a sus nombres. La función `title!` actualiza el nombre de un jugador de la siguiente manera.

- Si el nivel del jugador es 42, el nombre se actualiza con la función `increment`.
- De lo contrario, el nombre no cambia.

En cualquier caso, la función `title!` devuelve el nombre del jugador.

```julia-repl
julia> player1 = Player(level=42, health=12)
Player(missing, 42, 12, nothing)

julia> title!(player1)
"The Great"

julia> player1.name
"The Great"

julia> player2 = Player(name="Svengali", level=42, health=36, mana=54)
Player("Svengali", 42, 36, 54)

julia> title!(player2)
"Svengali the Great"

julia> player2.name
"Svengali the Great"

julia> player3 = Player(name="Rasputin", level=21, health=100, mana=54)
Player("Rasputin", 21, 100, 54)

julia> title!(player3)
"Rasputin"

julia> player3.name
"Rasputin"
```

## 6. Implementa la función de revivir

La función `revive!` debe comprobar que el personaje del jugador esté realmente muerto (que su salud haya llegado a `0`).

Si el jugador está muerto:
- El jugador debe revivir con `100` de salud.
- El mana del jugador se debe incrementar con la función `increment`.

Si el jugador está vivo, no le pasa nada.

La función `revive!` debe devolver al jugador.

```julia-repl
julia> deadplayer1 = Player(level=2, health=0)
Player(missing, 2, 0, nothing)

julia> revive!(deadplayer1)
Player(missing, 2, 100, 50)

julia> deadplayer2 = Player(level=12, health=0, mana=5)
Player(missing, 12, 0, 5)

julia> revive!(deadplayer2)
Player(missing, 12, 100, 105)

julia> aliveplayer = Player(level=23, health=1)
Player(missing, 23, 1, nothing)

julia> revive!(aliveplayer)
Player(missing, 23, 1, nothing)
```
