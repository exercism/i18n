# Métodos de string

`String` tiene varios métodos que puedes usar para manipular strings.  
Estos métodos se llaman sobre el propio string y a menudo se encadenan para realizar varias operaciones sobre un string.

A continuación tienes una lista de algunos de los métodos más comunes.
Consulta la [documentación de la API de `String`][string-api] para ver la lista completa de métodos.

## String#upcase & String#downcase

El método [`upcase`][upcase] devuelve un string nuevo con todos los caracteres convertidos a mayúsculas.

```crystal
"hello".upcase
# => "HELLO"
```

El método [`downcase`][downcase] devuelve un string nuevo con todos los caracteres convertidos a minúsculas.

```crystal
"HELLO".downcase
# => "hello"
```

## String#sub & String#gsub

Crystal tiene métodos para reemplazar partes de un string.
Se conocen como [`sub`][sub] (_sustitución_) y [`gsub`][gsub] (_sustitución global_).

Estos métodos pueden recibir un string, un char o una regex como primer argumento, y un string o un char como segundo argumento.
El primer argumento es la parte del string que se va a reemplazar, y el segundo argumento es el reemplazo.
`Char` y las regex se explican en conceptos posteriores.

El método `sub` reemplaza la primera aparición del primer argumento con el segundo argumento.

```crystal
"hello".sub("l", "r")
# => "herlo"
```

El método `gsub` funciona igual que `sub`, pero reemplaza todas las apariciones del primer argumento con el segundo argumento.

```crystal
"hello".gsub("l", "r")
# => "herro"
```

## String#chomp & String#strip

Chomp y strip se pueden usar para eliminar caracteres que no quieres de un string.

El método [`chomp`][chomp] elimina por defecto los últimos caracteres `\r`, `\n` o `\r\n` de un string.
Si se llama al método con un argumento, eliminará el valor indicado del final del string, en caso de que exista allí.

```crystal
"hello\n".chomp
# => "hello"

"hello".chomp("llo")
# => "he"
```

Por defecto, el método [`strip`][strip] elimina todos los espacios en blanco del principio y el final de un string.
Si se llama al método con un argumento, eliminará ese argumento del principio y el final del string, en caso de que exista allí.

```crystal
" hello ".strip
# => "hello"
```

## String#index

Puedes usar el método [`index`][index] para encontrar el índice de un carácter en un string.
El método `index` recibe un `String`, un `Char` o una regex como argumento.
Puede recibir un segundo argumento opcional para indicar el índice desde el cual buscar.
El método `index` devuelve el índice de la primera aparición del argumento.

```crystal
"hello".index("l")
# => 2

"hello".index("l", 3)
# => 3
```

## String#delete_at

Puedes usar el método [`delete_at`][delete_at] para eliminar un carácter de un string.
El método `delete_at` recibe un índice como argumento y elimina el carácter que está en ese índice.

```crystal
"hello".delete_at(0)
# => "ello"

"hello".delete_at(3)
# => "helo"
```

## String#insert

Puedes usar el método [`insert`][insert] para insertar un string en un índice específico.
El método `insert` recibe un índice como primer argumento y un string como segundo argumento.
El método `insert` devuelve un string nuevo con el segundo argumento insertado en el índice.

```crystal
"hello".insert(0, "h")
# => "hhello"

"hello".insert(3, "l")
# => "helllo"
```
