# Acerca de

El operador ternario condicional se usa para escribir una expresión condensada que devuelve uno de dos valores alternativos según alguna condición.
Con frecuencia se le llama «el operador ternario».
El nombre proviene de que el operador tiene tres operandos: `predicate ? consequent-expression : alternative-expression`.
Se puede usar como reemplazo de sentencias if-else cortas.

Al igual que con las sentencias `if`, JavaScript realiza una conversión implícita de tipos para evaluar la condición.
Si la condición es truthy, se devolverá el operando que está a la izquierda de los dos puntos.
De lo contrario, el resultado de la expresión ternaria es el operando que está a la derecha de los dos puntos.

```javascript
const year = 2020;

year > 2000 ? 'in the past years' : 'a long time ago';
// => 'in the past years'
```
