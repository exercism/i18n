# Pistas

## 1. Determina el total de aves que has contado hasta ahora

- Consulta la introducción del ejercicio para ver un ejemplo de cómo usar un bucle `for` para recorrer un slice.
- Usa una variable auxiliar para guardar el total y ve aumentando esa variable a medida que recorres el slice.
- Piensa cuál es el valor inicial correcto para esa variable auxiliar.

## 2. Calcula el número de aves visitantes en una semana específica

- Esta tarea es similar a la primera; puedes copiar tu código como punto de partida.
- Piensa qué índices del slice tendrías que considerar para la semana 1 y la semana 2, respectivamente.
- Ahora busca una forma general de calcular el primer índice y el último índice que se deben considerar.
- Con eso puedes armar el bucle `for` para que recorra solo la sección relevante del slice.

## 3. Corrige un error de conteo

- De nuevo, necesitas armar un bucle `for` para recorrer todo el slice con el conteo de aves.
- Esta vez solo necesitas visitar cada segundo elemento del slice.
- Cambia el paso para que la variable contadora aumente en la cantidad correspondiente después de cada iteración.
- En el cuerpo del bucle `for` puedes usar el operador de incremento para cambiar el valor de un elemento del slice en el mismo lugar.
