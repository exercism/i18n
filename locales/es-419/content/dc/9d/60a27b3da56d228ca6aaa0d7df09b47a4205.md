# Acerca de

A veces, cuando una función recibe muchos argumentos, puede ser difícil recordar el orden en que se deben pasar. Para facilitar la legibilidad, Gleam permite etiquetar los argumentos con un nombre.

Para etiquetar un argumento, indica el nombre de la etiqueta antes del nombre del argumento, separados por un espacio.

```gleam
pub fn replace(
  in string: String,
  each target: String,
  with replacement: String
) -> String {
  // ...
}
```

Cuando llamas a una función con argumentos etiquetados, los argumentos se pueden pasar en cualquier orden. Todas estas llamadas a `replace` son equivalentes:

```gleam
replace(in: "🍔🍔🍔" each: "🍔", with: "🍕")

replace(each: "🍔", in: "🍔🍔🍔", with: "🍕")

replace(with: "🍕", each: "🍔", in: "🍔🍔🍔")
```

Las etiquetas siempre son opcionales. Aunque una función tenga argumentos etiquetados, se la puede seguir llamando sin etiquetas.

```gleam
replace("🍔🍔🍔", "🍔", "🍕")
```

Al definir una función con argumentos etiquetados, todos los argumentos que van después del primer argumento etiquetado también deben estar etiquetados.

```gleam
// This function is valid
pub fn valid(
  x: Int,
  label1 y: Int,
  label2 z: Int
) -> Int {
  // ...
}

// This function is invalid
pub invalid(
  x: Int,
  label1 y: Int,
  z: Int
) -> Int {
  // ...
}
```
