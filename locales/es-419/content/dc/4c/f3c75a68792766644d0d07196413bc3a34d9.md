# Introducción

Wikipedia describe una sentencia `switch` como «un tipo de mecanismo de control de selección que permite que el valor de una variable o una expresión cambie el flujo de control del programa».

El mecanismo involucra las siguientes palabras clave: `switch`, `case`, `break` y `default`.

En su forma más simple, evalúan una expresión primitiva o string y toman una decisión basada en su valor. Por ejemplo:

```csharp
string direction = GetDirection();
switch (direction)
{
    case "left":
        GoLeft();
        break;
    case "right":
        GoRight();
        break;
    default:
        MarkTime();
        break;
}
```

En su forma más sofisticada, introducen la conversión descendente `case <Type> <variable>:` y las cláusulas de guarda (`when`).

```csharp
Animal animal = GetAnimal();

switch (animal)
{
    case Dog canine:
    case Coyote canine:
        canine.Bark();
        break;
    case Cat cat when cat.HasOnly8Lives():
        cat.IsCareful();
        cat.Meow();
        break;
    case Cat cat:
        cat.Meow();
        break;
}
```
