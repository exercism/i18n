# Anexo de instrucciones

## Pruebas

Las pruebas ejecutarán algunas operaciones de forma concurrente.
Debes procurar que las operaciones sobre la `Account` la dejen en un estado consistente.
Por ejemplo: varias goroutines pueden estar depositando y retirando dinero al mismo tiempo; dos retiros que ocurren de forma concurrente no deberían poder dejar el saldo en negativo.

Cuando trabajes de forma local, puedes comprobar que tu código maneja la concurrencia correctamente y no introduce condiciones de carrera si ejecutas las pruebas con la opción `-race` activada.

```bash
cd exercism/project/directory/go/bank-account
go test -race
```
