# Introducción

JSON define un **array** (o _arreglo_) como:

> Un array es una colección ordenada de valores.
> Un array comienza con `[` corchete de apertura y termina con `]` corchete de cierre.
> Los valores se separan por una coma `,`.

Los arrays pueden contener cero o más valores JSON de _cualquier tipo_.
Los elementos de un array no tienen que ser todos del mismo tipo.

## Crear arrays

Usa corchetes para reunir elementos en un array.

```jq
[1, 2, 3]
```

Los elementos de un _flujo_ se pueden capturar en un array si lo encierras entre corchetes.

```jq
range(5)     # => a stream of 5 numbers
[range(5)]   # => the array [0, 1, 2, 3, 4]
```

## Tamaño

La función `length` devuelve el número de elementos de un array.

## Indexación y segmentación

La indexación de arrays empieza en cero.

Para obtener un elemento de un array, usa una expresión con corchetes:
`.[2]` obtiene el tercer elemento.

Los índices negativos cuentan hacia atrás desde el final del array:
`.[-1]` obtiene el último elemento; `.[-2]` es el penúltimo.

Un **segmento** es una subsecuencia del array.
`.[10:15]` devuelve 5 elementos a partir del índice 10; el índice final _no se incluye_.

Hay algunas funciones de conveniencia:

- `first` obtiene el primer elemento.
- `last` obtiene el último elemento.
- `nth(n)` obtiene el elemento en el índice `n`.

## Iteración

`jq` proporciona muchas funciones para cubrir la funcionalidad de iteración común:

- `map(expr)` devuelve un nuevo array donde `expr` se aplica a cada elemento sucesivamente.

  ```jq
  [1, 2, 3] | map(. * 10)    # => [10, 20, 30]

  ```

- `select(expr)` es una función que aplica `expr` a un _único valor_;
  si el resultado de la expresión es verdadero, se devuelve el valor;
  si el resultado es falso, _no se devuelve nada_: no `null`, en realidad nada.

  Para aplicarlo a un array, combínalo con `map`.

  ```jq
  [range(10)] | map(select(. % 2 == 0))    # => [0, 2, 4, 6, 8]
  ```

  Como alternativa, aplica `select` a un _flujo_ y reúne los resultados.

  ```jq
  [range(10) | select(. % 2 == 0)]    # => [0, 2, 4, 6, 8]
  ```

- `any(condition)` y `all(condition)` devuelven un valor Boolean que indica si algún elemento o todos los elementos del array cumplen la condición.

  ```jq
  [1, 2, 3, 4] | any(. > 4)    # false
  [1, 2, 3, 4] | any(. >= 4)   # true

  [1, 2, 3, 4] | all(. >= 4)   # false
  [1, 2, 3, 4] | all(. <= 4)   # true
  ```
