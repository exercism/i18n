# Ayuda

Si tienes problemas y necesitas ayuda, puedes usar uno de los siguientes recursos:

- [/r/php](https://www.reddit.com/r/php) es el subreddit de PHP.
- [StackOverflow](https://stackoverflow.com/questions/tagged/php) lo puedes usar para buscar tu problema y ver si ya lo respondieron antes. También puedes hacer preguntas y responderlas.
