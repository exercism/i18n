# Introducción

## Tipos genéricos

La definición de una colección suele incluir un marcador de posición entre paréntesis angulares, que por convención suele ser `T`. A ese tipo de colección se le llama tipo genérico. Esto permite que quien use la colección especifique qué tipo de elementos quiere guardar en ella. En el código de ejemplo de abajo estamos instanciando una lista de strings.

## Listas

Las listas en C# son colecciones de valores primitivos o de instancias de estructuras o clases. Se implementan en la biblioteca de clases base como `List<T>`, donde `T` es el tipo del elemento de la lista. La API expone un amplio conjunto de métodos para crear y manipular listas.

Se pueden agregar y quitar elementos de las listas. Crecen y se reducen según sea necesario.

```csharp
var listOfStrings = new List<string>();
```
