# Introducción

## Errores

Los errores son útiles para avisar cuando algo está mal o es inesperado en un programa o en un fragmento de código.

Son objetos de JavaScript.

La propiedad principal de este objeto es `message`:

```javascript
const error = new Error('Oops, something went wrong');

console.log(error.message);
// => "Oops, something went wrong"
```

Con la sintaxis `throw`, puedes lanzar un Error.

```javascript
throw new Error('Oops');
```

Cuando se lanza un error, la ejecución actual se detiene y se reanuda en el primer bloque `catch` de la pila de llamadas.

```javascript
try {
  throw new Error('Oops');
} catch (error) {
  console.log(error.message);
  // => "Oops"
}
```

## Herencia

La herencia es una forma de crear relaciones de padre e hijo entre clases.
La clase hija (a la que a veces se llama _subclase_) tiene acceso al comportamiento y a los datos que define la clase padre (a la que a veces se llama _superclase_).

```javascript
class Pet {
  constructor(name) {
    this.name = name;
  }

  introduce() {
    console.log(`This is my pet, ${this.name}.`);
  }
}

class Dog extends Pet {}

const dog = new Dog('Otis');
dog.introduce();
// => This is my pet, Otis.
```

La palabra clave `extends` en la declaración de la clase hija establece una relación con la clase padre a través de la [cadena de prototipos][prototype-chain].

Los objetos que crea el constructor de la clase hija tendrán el prototipo de la clase padre en su cadena de prototipos, lo que da acceso a cualquier método o dato que defina la clase padre.

```javascript
const dog = new Dog('Otis');

Dog.prototype.isPrototypeOf(dog); // => true
Pet.prototype.isPrototypeOf(dog); // => true
Pet.prototype.isPrototypeOf(Dog.prototype); // => true

Pet.prototype.hasOwnProperty('introduce'); // => true
Dog.prototype.hasOwnProperty('introduce'); // => false
dog.hasOwnProperty('introduce'); // => false
```

Como con cualquier clase en JavaScript, las subclases pueden heredar de `Error` para crear errores personalizados usando la palabra clave `extends`.
La sintaxis `instanceof` comprueba si el error capturado es una instancia de una subclase concreta de `Error`.

```javascript
class CustomError extends Error {}

try {
  // ... Code that may throw an error
} catch (error) {
  if (error instanceof CustomError) {
    console.log('The error thrown is an instance of the CustomError');
  }
}
```

[prototype-chain]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Inheritance_and_the_prototype_chain
