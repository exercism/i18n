# Introducción

## Sobrecarga de métodos

En Java, la sobrecarga de métodos es una funcionalidad que permite que una clase tenga más de un método con el mismo
nombre, siempre que sus listas de parámetros sean diferentes.
Está relacionada con el polimorfismo en tiempo de compilación (o estático).
Este concepto es fundamental para
crear métodos que realizan tareas similares, pero con argumentos distintos.

### ¿Por qué sobrecargar métodos?

La sobrecarga de métodos aumenta la legibilidad del programa.
Se les puede dar el mismo nombre a métodos distintos, pero con
parámetros diferentes.
Dependiendo del número de parámetros o del tipo de parámetros, se llama al método correspondiente.

### ¿Cómo sobrecargar métodos?

La clave de la sobrecarga de métodos es la firma de un método.
Dos métodos se considerarán diferentes si tienen firmas diferentes.
Hay dos formas de sobrecargar un método:

1. **Distinta cantidad de parámetros**: los métodos pueden tener el mismo nombre pero una cantidad de parámetros
   diferente.

   ```java
   public class Display {

       public void show(int x) {
           System.out.println("Show with int: " + x);
       }

       public void show(int x, int y) {
           System.out.println("Show with two ints: " + x + ", " + y);
       }
   }
   ```

2. **Distintos tipos de parámetros**: los métodos pueden tener el mismo nombre y la misma cantidad de parámetros, pero
   con tipos diferentes.

   ```java
   public class Display {

       public void show(int x) {
           System.out.println("Show with int: " + x);
       }

       public void show(String s) {
           System.out.println("Show with String: " + s);
       }
   }
   ```

### Puntos a recordar

- Los métodos sobrecargados deben cambiar la lista de argumentos.
- Los métodos sobrecargados también pueden cambiar el tipo de retorno, pero cambiar solo el tipo de retorno no
  constituye una sobrecarga de métodos.
- Los métodos se pueden sobrecargar en la misma clase o en una subclase.

En este concepto, exploraremos varios ejemplos y matices de la sobrecarga de métodos en Java.
