# Pistas

## General

- Hay tres [operadores Boolean][operators] para trabajar con valores Boolean.
- Se pueden combinar varios operadores en una sola expresión.

## 1. Verifica si se puede hacer un ataque rápido

- Los [operadores Boolean][operators] también se pueden aplicar a parámetros Boolean.
- A diferencia de muchos otros lenguajes, la negación Boolean _no_ se hace con el operador `!`.

[operators]: https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/symbol-and-operator-reference/boolean-operators
