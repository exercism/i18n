# No uses `%%` ni `/`

Como mencionan las instrucciones, el propósito de este ejercicio es construir una criba de Eratóstenes sin usar operaciones como la división o el módulo.
Consulta el [enlace a Wikipedia][wikipedia] para ver una descripción del algoritmo.

Construir la criba de Eratóstenes sin operaciones como la división o el módulo puede ser complicado,
pero es un algoritmo hermoso, inventado hace más de dos milenios, que vale la pena aprender e implementar.

[wikipedia]: https://en.wikipedia.org/wiki/Sieve_of_Eratosthenes
