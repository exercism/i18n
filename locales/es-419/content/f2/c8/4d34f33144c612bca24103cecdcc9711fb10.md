# Introducción

Un `vector` en Clojure es una colección secuencial, indexada e inmutable de cero o más valores. Esto significa que una vez que se crea un vector, no se puede modificar. Las funciones que operan sobre vectores devuelven un vector nuevo, mientras que el vector original permanece sin cambios. Los valores de un vector pueden ser de tipos heterogéneos. Los vectores se pueden definir así:

```clojure
(def empty [])
(def single-value 5)
(def single-value-alternative (vector 5))
(def three-values [a b c]
```

Los elementos se pueden obtener de un vector usando un índice. Los vectores de Clojure están basados en cero, lo que significa que el índice del primer elemento siempre es cero:

```clojure
(def numbers [2 3 5])
;; Read value from vector
(get numbers 2)
;;=> 5
;; Update value in vector
(assoc numbers 2 9)
;;=> [2 3 9]
```

El vector original no cambia:

```clojure
numbers
;;=> [2 3 5]
```

Para recordar el valor actualizado, necesitamos pasarlo o capturarlo en un `var`:

```clojure
(def updated-numbers
  (assoc numbers 2 9))
(get updated-numbers 2)
;;=> 9
```
