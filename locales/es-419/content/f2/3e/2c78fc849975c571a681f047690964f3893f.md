# Notas para este ejercicio en la pista de Python

Puedes asumir lo siguiente sobre los argumentos que las pruebas pasan a la
función `sum_of_multiples`:

- Todos los números que recibes como argumentos son **_`int` no negativos_**
  (_es decir, números naturales, incluido el cero_).
- Debes proporcionar una `list` de factores, y sus elementos son únicos
  y están ordenados de forma ascendente.
