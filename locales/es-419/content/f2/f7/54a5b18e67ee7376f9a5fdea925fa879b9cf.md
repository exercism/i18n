# Instrucciones

Te encanta observar aves y llevas la cuenta de cuántas han visitado tu jardín.
Normalmente usas marcas en un cuaderno para contar las aves, pero para trabajar mejor con tus datos, digitalizaste el conteo de aves de las últimas semanas.

## 1. Determina el número total de aves que has contado hasta ahora

Empecemos analizando los datos para tener una visión general.
Averigua cuántas aves contaste en total desde que empezaste tus registros.

Implementa una función `totalBirdCount` que acepte un array de `Int`s que contenga el conteo de aves por día.
Debe devolver el número total de aves que contaste.

```swift
let birdsPerDay = [2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1]
totalBirdCount(birdsPerDay)
// Returns 34
```

## 2. Calcula el número de aves visitantes en una semana específica

Ahora que ya tienes una idea general de tus números de conteo de aves, quieres hacer un análisis más detallado.

Implementa una función `birdsInWeek` que acepte un array de conteos de aves por día y un número de semana.

Devuelve el número total de aves que contaste en esa semana específica.
Puedes asumir que las semanas siempre se registran completas.

```swift
let birdsPerDay = [2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1]
birdsInWeek(birdsPerDay, weekNumber: 2)
// Returns 12
```

## 3. Corrige un error de conteo

Te diste cuenta de que, todo el tiempo que estuviste tratando de llevar la cuenta de las aves, había un ave que se escondía en un rincón lejano del jardín.

Descubriste que esta ave siempre pasaba en tu jardín un día sí y otro no.

No sabes exactamente dónde estaba entre esos días, pero definitivamente no estaba en tu jardín.

Tu intuición de observador de aves también te dice que el ave estaba en tu jardín el primer día que registraste en tu lista.

Con esta nueva información, escribe una función `fixBirdCountLog` que tome un array de aves contadas por día como argumento y devuelva el array después de corregir el error de conteo.

```swift
var birdsPerDay = [2, 5, 0, 7, 4, 1]
fixBirdCountLog(birdsPerDay)
// Returns [3, 5, 1, 7, 5, 1]
```
