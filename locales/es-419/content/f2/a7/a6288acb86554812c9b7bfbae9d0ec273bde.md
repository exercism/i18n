# Introducción

Cuando no se conoce de antemano el número de iteraciones de un bucle (es decir, «sigue hasta que algún predicado deje de ser verdadero»), Factor usa el combinador `while` de [`kernel`][kernel]:

```
while ( pred body -- )
```

Tanto `pred` como `body` son quotations que operan sobre la pila de datos. `while` llama a `pred`; si este deja un valor verdadero en la parte superior, `while` ejecuta `body` y repite; si no, se detiene. El estado que fluye de una iteración a la siguiente vive en la pila entre llamadas (o en variables locales con nombre cuando hay más de una pieza de estado).

```factor
USING: kernel math ;

5 [ dup 0 > ] [ dup . 1 - ] while drop
! prints 5 4 3 2 1
```

`until` es la forma simétrica: sigue avanzando *hasta* que el predicado se vuelva verdadero.

[kernel]: https://docs.factorcode.org/content/vocab-kernel.html
