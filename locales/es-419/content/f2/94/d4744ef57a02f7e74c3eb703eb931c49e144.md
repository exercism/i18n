# Instrucciones

En este ejercicio vas a implementar algunas reglas del [Blackjack][blackjack], como la forma en que se juega y se puntúa.

**Nota**: En este ejercicio, _`A`_ significa as, _`J`_ significa jota, _`Q`_ significa reina y _`K`_ significa rey.
Los comodines se descartan.
Se asume una [baraja estándar de 52 cartas con palos franceses][standard_deck], pero en la mayoría de las versiones se mezclan varias barajas juntas para jugar.

## 1. Calcula el valor de una carta

En el Blackjack, depende de cada jugador si un as vale 1 u 11 puntos (_hablaremos más de eso después_).
Las figuras (`J`, `Q`, `K`) valen 10 puntos y cualquier otra carta vale su valor «pip» (_numérico_).

Define la función `value_of_card(<card>)` con el parámetro `card`.
La función debe devolver el _valor numérico_ del string de carta que se le pasa.
Como un as puede tomar varios valores (1 **o** 11), por ahora esta función debe fijar el valor de una carta de as en 1.
Más adelante implementarás una función para determinar el valor de una carta de as, dada una mano existente.

```python
>>> value_of_card('K')
10

>>> value_of_card('4')
4

>>> value_of_card('A')
1
```

## 2. Determina qué carta tiene un valor más alto

Define la función `higher_card(<card_one>, <card_two>)` con los parámetros `card_one` y `card_two`.
Para fines de puntuación, el valor de `J`, `Q` o `K` es 10.
La función debe devolver cuál carta tiene el valor más alto para la puntuación.
Si ambas cartas tienen el mismo valor, devuelve las dos.
Puedes devolver ambas cartas usando una coma en la sentencia `return`:

```python
# Using a comma in a return creates a Tuple.  Tuples will be covered in a later exercise.
>>> def returning_two_values(value_one, value_two):
        return value_one, value_two

>>> returning_two_values('K', '3')
('K', '3')
```

Un as puede tomar varios valores, así que para esta tarea fijaremos las cartas `A` en un valor de 1.

```python
>>> higher_card('K', '10')
('K', '10')

>>> higher_card('4', '6')
'6'

>>> higher_card('K', 'A')
'K'
```

## 3. Calcula el valor de un as

Como se mencionó antes, un as puede valer _ya sea_ 1 **o** 11 puntos.
Los jugadores intentan acercarse lo más posible a una puntuación de 21, sin pasarse _de_ 21 (lo que se conoce como «bust»).

Define la función `value_of_ace(<card_one>, <card_two>)` con los parámetros `card_one` y `card_two`, que son un par de cartas que ya están en la mano _antes_ de recibir una carta de as.
Tu función tendrá que decidir si el próximo as valdrá 1 o 11, y devolver ese valor.
Recuerda: el valor de la mano con el as debe ser lo más alto posible _sin_ pasarse de 21.

**Pista**: si ya tenemos un as en la mano, el valor del próximo as sería 1.

```python
>>> value_of_ace('6', 'K')
1

>>> value_of_ace('7', '3')
11
```

## 4. Determina una mano «natural» o «blackjack»

Si a un jugador le reparten un as (`A`) y una carta de diez (10, `K`, `Q` o `J`) como sus dos primeras cartas, entonces el jugador tiene una puntuación de 21.
Esto se conoce como una mano de **blackjack**.


Define la función `is_blackjack(<card_one>, <card_two>)` con los parámetros `card_one` y `card_two`, que son un par de cartas.
Determina si la mano de dos cartas es un **blackjack** y devuelve el valor booleano `True` si lo es, o `False` en caso contrario.

**Nota**: El _cálculo_ de la puntuación se puede hacer de muchas maneras.
Pero si es posible, nos gustaría que comprobaras si hay un as y una carta de diez **_en_** la mano (_o en una posición determinada_), en lugar de _sumar_ los valores de la mano.

```python
>>> is_blackjack('A', 'K')
True

>>> is_blackjack('10', '9')
False
```

## 5. Dividir pares

Si las dos primeras cartas de una mano tienen el mismo valor (_por ejemplo, dos seises o una `Q` y una `K`_), un jugador puede elegir tratarlas como dos manos separadas.
Esto se conoce como «dividir pares».

Define la función `can_split_pairs(<card_one>, <card_two>)` con los parámetros `card_one` y `card_two`, que son un par de cartas.
Determina si esta mano de dos cartas se puede dividir en dos pares.
Si la mano se puede dividir, devuelve el valor booleano `True`; en caso contrario, devuelve `False`

```python
>>> can_split_pairs('Q', 'K')
True

>>> can_split_pairs('10', 'A')
False
```

## 6. Doblar la apuesta

Cuando las dos cartas originales repartidas suman 9, 10 u 11 puntos, un jugador puede hacer una apuesta adicional igual a su apuesta original.
Esto se conoce como «doblar la apuesta».

Define la función `can_double_down(<card_one>, <card_two>)` con los parámetros `card_one` y `card_two`, que son un par de cartas.
Determina si en esta mano de dos cartas se puede «doblar la apuesta» y devuelve el valor booleano `True` si se puede, o `False` en caso contrario.

```python
>>> can_double_down('A', '9')
True

>>> can_double_down('10', '2')
False
```
