# Aprender

Exercism ofrece ejercicios y retroalimentación, pero puede resultar difícil dar el primer paso para quienes están aprendiendo Babashka por primera vez.

Estos recursos pueden ayudarte a empezar:

## Referencias
- [Clojure.org](http://clojure.org) El sitio web oficial del lenguaje.
- [ClojureDocs](https://clojuredocs.org) Un repositorio de referencias y ejemplos del lenguaje, organizado por función o palabra clave.

## Ejercicios y tutoriales
- [4bb](https://github.com/porkostomus/4bb) 4clojure como script de Babashka.
