# Acerca de

Los condicionales en C++ son similares a los condicionales de otros lenguajes.
El tipo subyacente de cualquier operación condicional es el tipo `bool`, que puede tener el valor `true` o `false`.
Los condicionales se usan a menudo como mecanismos de control de flujo para comprobar distintas condiciones.

Se puede usar una sentencia `if`, que ejecuta su código si la condición subyacente es `true`, así:

```cpp
std::string value{"val"};

if (value == "val") {
    return "was val";
}
```

En escenarios con más de un caso, se pueden encadenar varias sentencias `if` usando las sentencias `else if` y `else`.

```cpp
int number{33};

if (number > 0) {
   return "positive";
} else if (number < 0) {
    return "negative";
} else {
   return "zero";
}
```

Desde C++17, las sentencias `if` también pueden incluir una sentencia de inicialización corta que sirve para inicializar una o más variables de la sentencia `if`.
Por ejemplo:

```cpp
int num{7};
if (int v{2 * num}; v > 10) {
    return v;
} else {
    return num;
}
// => 14
```

> Nota: no se puede acceder a ninguna de las variables creadas en la inicialización después del final de la sentencia if.
