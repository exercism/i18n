# Instrucciones

En este ejercicio vas a organizar carreras entre distintos tipos de autos controlados a distancia.
Cada auto tiene sus propias características de velocidad y de consumo de batería.

Los autos empiezan con la batería llena (100%).
Cada vez que manejas el auto con el control remoto,
avanza tantos metros como indique su velocidad y reduce el porcentaje de batería restante según su consumo de batería.

Si la batería de un auto queda por debajo de su porcentaje de consumo de batería, ya no puedes manejarlo.

Cada pista de carreras tiene su propia distancia.
Los autos se ponen a prueba verificando si pueden terminar la pista sin quedarse sin batería.

## 1. Crea un auto controlado a distancia

Define un struct `Car` con los siguientes campos de tipo `int`:

- battery
- batteryDrain
- speed
- distance

Permite crear un auto controlado a distancia definiendo una función `NewCar` que recibe como sus dos parámetros la velocidad del auto en metros y el porcentaje de consumo de batería (ambos de tipo `int`), y devuelve una instancia de `Car`:

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)
// => Car{speed: 5, batteryDrain: 2, battery:100, distance: 0}
```

## 2. Crea una pista de carreras

Define otro tipo de struct llamado `Track` con el campo `distance` de tipo entero.
Permite crear una pista de carreras definiendo una función `NewTrack` que recibe como único parámetro la distancia de la pista en metros (de tipo `int`):

```go
distance := 800
track := NewTrack(distance)
// => Track{distance: 800}
```

## 3. Maneja el auto

Implementa la función `Drive`, que actualiza la cantidad de metros recorridos según la velocidad del auto y reduce la batería de acuerdo con su consumo.
Si no hay batería suficiente para avanzar una vez más, el auto no se moverá:

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)
car = Drive(car)
// => Car{speed: 5, batteryDrain: 2, battery: 98, distance: 5}
```

## 4. Comprueba si un auto controlado a distancia puede terminar una carrera

Para terminar una carrera, un auto tiene que ser capaz de recorrer la distancia de la carrera.
Es decir, no puede quedarse sin batería antes de cruzar la línea de meta.
Implementa la función `CanFinish`, que recibe como parámetro una instancia de `Car` y una de `Track`, y devuelve `true` si el auto puede terminar la carrera; de lo contrario, devuelve `false`.

Supón que estás en la línea de salida de la carrera y que enciendes el motor del auto para arrancar.
Ten en cuenta que la batería del auto no tiene por qué estar completamente cargada al empezar la carrera:

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)

distance := 100
track := NewTrack(distance)

CanFinish(car, track)
// => true
```
