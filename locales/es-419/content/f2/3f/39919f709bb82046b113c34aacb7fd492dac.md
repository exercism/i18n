# Acerca de

Un _string_ (_cadena_) es el tipo de dato de JavaScript que sirve para almacenar datos de texto.
No existe un tipo de dato aparte para un carácter individual.

## Cómo crear un string

Para crear un [literal][literal] de string, envuelves el texto entre comillas simples o comillas dobles.
En Exercism se usan las comillas simples.

<!-- prettier-ignore-start -->
```javascript
'Hello, World!'
"Hello, World!"
```
<!-- prettier-ignore-end -->

Algunos caracteres especiales del texto deben ir precedidos por una barra invertida `\`; consulta las [secuencias de escape en MDN][mdn-escape-sequences].

<!-- prettier-ignore-start -->
```javascript
const text = 'I\'m having fun.\nWhat about you?';
console.log(text);
// => I'm having fun.
// => What about you?
```
<!-- prettier-ignore-end -->

Además de las comillas simples y dobles, también puedes crear un string envolviendo el texto entre comillas invertidas.
Esta sintaxis permite incluir comillas simples o dobles e incluso saltos de línea sin necesidad de escaparlos.
También permite insertar expresiones; consulta las [plantillas de cadena][mdn-template-strings] para más detalles.

```javascript
`A multi-line string
with 'single quotes'
and "double quotes"`;
```

## Los strings como listas de caracteres

Un string se puede tratar como una lista de caracteres en la que el primer carácter tiene el índice `0`.
Puedes acceder a un carácter individual del string usando corchetes y el índice de la letra que quieras obtener.
Como alternativa, también existe el método `charAt`.

```javascript
'cat'[1];
// => 'a'

'cat'.charAt(2);
// => 't'
```

Puedes determinar la cantidad de caracteres de un string accediendo a la propiedad `length`.

```javascript
'cat'.length;
// => 3
```

## Concatenación y métodos

La forma más sencilla de concatenar strings es usar el operador de suma `+`.

```javascript
'I like' + ' ' + 'cats.';
// => "I like cats."
```

Los strings ofrecen muchos métodos auxiliares; consulta la [documentación de MDN sobre métodos de string][mdn-string-methods] para ver la lista completa.
En la siguiente lista se muestran algunos de los más usados.

- [`toUpperCase`][mdn-to-upper-case] y [`toLowerCase`][mdn-to-lower-case]: cambian el uso de mayúsculas y minúsculas de todos los caracteres
- [`trim`][mdn-trim]: elimina los espacios en blanco del principio y del final
- [`includes`][mdn-includes], [`startsWith`][mdn-starts-with] y [`endsWith`][mdn-ends-with]: determinan si otro string forma parte del string dado
- [`slice`][mdn-slice]: extrae una sección del string

## Los strings son inmutables

Aplicar los métodos anteriores nunca cambia el string original. En su lugar se crea y se devuelve un string nuevo.
Los strings (y otros tipos de datos primitivos) son inmutables en JavaScript.
Eso también significa que no puedes asignar un carácter diferente en algún índice usando la sintaxis de corchetes mostrada arriba (como harías en los arrays).

```javascript
const str = 'cat';
str[1] = 'u'; // fails silently
console.log(str);
// => 'cat'
```
