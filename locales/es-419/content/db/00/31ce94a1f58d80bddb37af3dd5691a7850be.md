# Introducción

En Rust, los Boolean se representan con el tipo `bool`, cuyos valores pueden ser `true` o `false`.

Rust admite seis operadores de comparación: `==` (igual), `!=` (distinto de), `>` (mayor que), `<` (menor que), `>=`
(mayor o igual que), `<=` (menor o igual que). Se pueden usar para evaluar la relación entre valores que no son Boolean y obtener un valor Boolean.

```rust
1 > 0 // true
1 < 0 // false
1 == 0 // false
1 != 0 // true
1 >= 0 // true
1 <= 0 // false
```

A diferencia de otros lenguajes, `0` no es `false` y un valor distinto de cero no es `true`.

Rust admite dos operadores booleanos: `||` (o), `&&` (y). Solo se evalúan cuando el operando de la izquierda todavía no
determina el resultado de la expresión. Es decir, `||` solo evalúa su operando de la derecha cuando el operando de la izquierda se evalúa
como `false`, y `&&` solo cuando este se evalúa como `true`.
