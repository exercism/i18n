# Instrucciones

Josh está trabajando en un nuevo juego de rol y necesita tu ayuda para implementar algunas de sus mecánicas.

## 1. Preséntate

Implementa la función `introduce`.

Puede que los jugadores sigilosos estén ocultando su nombre, en cuyo caso se los presentará como `"Mighty Magician"`.
De lo contrario, solo usa el nombre del jugador para presentarlo.

```gleam
introduce(Player(name: None, level: 2, health: 8, mana: None))
// -> "Mighty Magician"

introduce(Player(name: Some("Merlin"), level: 2, health: 8, mana: None))
// -> "Merlin"
```

## 2. Implementa la mecánica de revivir

La función `revive` debe verificar que el personaje del jugador esté realmente muerto (su salud llegó a 0).
Si es así, debe devolver una nueva instancia de `Player` con 100 de salud.
De lo contrario, si el personaje del jugador no está muerto, la función `revive` devuelve `None`.

Si el nivel del jugador es 10 o mayor, también debe revivir con 100 de maná.
Si el nivel del jugador es menor que 10, su maná debe quedar intacto.
La función `revive` debe conservar el nivel del jugador.

```gleam
let dead_player = Player(name: None, level: 2, health: 0, mana: None)

revive(dead_player)
// -> Some(Player(name: None, level: 2, health: 100, mana: None))
```

Si se llama al método `revive` sobre un jugador cuya salud es 1 o mayor, la función debe devolver `None`.

```gleam
let alive_player = Player(name: None, level: 2, health: 42, mana: None)

revive(alive_player)
// -> None
```

## 3. Implementa la mecánica de lanzar hechizos

La función `cast_spell` recibe como argumentos un `Int` que indica cuánto maná cuesta el hechizo, además de un `Player`.
Devuelve el jugador actualizado, así como la cantidad de daño que hace el hechizo lanzado.
Un lanzamiento de hechizo exitoso hace un daño igual al doble del costo de maná del hechizo.
Sin embargo, si el jugador no tiene suficiente maná, no pasa nada: el jugador queda igual y no se hace daño.
Si el jugador ni siquiera tiene una reserva de maná, al intentar lanzar el hechizo su salud debe disminuir en el costo de maná del hechizo y no se hace daño.
Ten en cuenta que la salud de los jugadores no puede ser menor que cero (0).

```gleam
let wizard = Player(name: None, level: 18, health: 123, mana: Some(30))
let #(wizard, damage) = cast_spell(wizard, 14)

wizard.mana // -> Some 16
damage      // -> 28
```
