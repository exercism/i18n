# Pistas

## 1. Preséntate

La función `introduce` debe «desenvolver» el valor contenido en `player.Name`.
Considera usar la [función `Options.defaultValue`][defaultvalue] para convertir `player.Name` a su valor «envuelto» cuando es `Some`, o al valor predeterminado requerido cuando es `None`.

## 2. Implementa la mecánica de revivir

La función `revive` debe devolver `Some <player>` o `None`, donde `<player>` es un registro `Player` que posiblemente tenga algunos campos modificados.

## 3. Implementa la mecánica de lanzamiento de hechizos

Considera usar una expresión match para cubrir tanto los casos `Some` como `None`, como en el siguiente ejemplo:

```fsharp
let exists (x: int option) =
    match x with
    | Some n -> true
    | None -> false
```
