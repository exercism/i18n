# Pistas

## General

- Lee sobre los [errores][getting-started-errors] en la guía de introducción.
- Lee sobre [IO][getting-started-io] en la guía de introducción.

## 1. Abre un archivo

- Usa el _despacho dinámico_ para invocar la función de apertura. Repasa el fragmento de código de la introducción.

## 2. Intenta escribir en el archivo

- Usa la construcción try-rescue.
- Hay una [función][io-write] en el módulo `IO` que te permite escribir en un dispositivo de IO.
- Puedes usar el bloque `rescue` para hacer coincidencia de patrones con el error y devolver la tupla de error.
- Puedes usar el bloque `else` para hacer coincidencia de patrones con el valor que devuelve una escritura exitosa.

## 3. Cierra el archivo

- Puedes usar el bloque `after` para ejecutar una función, sin importar si un bloque `try` tiene éxito o se rescata.
