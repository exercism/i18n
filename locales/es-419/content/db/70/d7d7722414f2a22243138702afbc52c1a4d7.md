# Instrucciones

En este ejercicio vas a modelar una báscula con kilogramos como unidad.

Tienes 6 tareas, y cada una requiere que implementes una o más propiedades:

## 1. Permite que la báscula tenga una precisión

Para adaptarnos a distintas necesidades, permitimos personalizar cada báscula con una precisión (la cantidad de dígitos después del separador decimal).
Implementa la clase `WeighingMachine` para que tenga una propiedad `Precision` de solo lectura, establecida con el argumento `precision` del constructor:

```csharp
var wm = new WeighingMachine(precision: 3);

//  => wm.Precision == 3
```

## 2. Permite establecer el peso en la báscula

Implementa la propiedad `WeighingMachine.Weight` para permitir obtener _y_ establecer el peso:

```csharp
var wm = new WeighingMachine(precision: 3);
wm.Weight = 60.5;

//  => wm.Weight == 60.5
```

## 3. Asegúrate de que se rechace un peso de entrada negativo

Claramente, nadie puede tener un peso negativo. 
Agrega validación a la propiedad `WeighingMachine.Weight` para que lance una `ArgumentOutOfRangeException` cuando se intente asignarle un peso negativo:

```csharp
var wm = new WeighingMachine(precision: 3);
wm.Weight = -10; // Throws an ArgumentOutOfRangeException
```

## 4. Permite aplicar un ajuste de tara a la báscula

El ajuste de tara puede ser cualquier valor (incluso negativo, o un valor que haga que el peso mostrado sea negativo)
Implementa la propiedad `WeighingMachine.TareAdjustment` para permitir establecer el ajuste de tara:

```csharp
var wm = new WeighingMachine(precision: 3);
wm.TareAdjustment = -10.6;

// => wm.TareAdjustment == -10.6
```

## 5. Asegúrate de que la báscula tenga un ajuste de tara predeterminado

Después de unas pruebas exhaustivas, parece que, debido a un problema de fabricación, todas las básculas tienen una tendencia a sobreestimar el peso en `5`.
Cambia la propiedad `WeighingMachine.TareAdjustment` para que su valor predeterminado sea `5`.

```csharp
var wm = new WeighingMachine(precision: 3);

// => wm.TareAdjustment == 5.0
```

## 6. Permite obtener el peso

Implementa la propiedad `WeighingMachine.DisplayWeight`, que debe devolver un string que muestre el peso después del ajuste de tara, con la precisión correcta aplicada y la unidad agregada.
Ten en cuenta que:
``` display-weight = input-weight - tare-adjustment ```

```csharp
var wm = new WeighingMachine(precision: 3);
wm.Weight = 60.567;
wm.TareAdjustment = 10;

// => wm.DisplayWeight == "50.567 kg"
```
