# Pistas

## General

## 1. Estimar el valor después del cambio

- Puedes usar el [operador de división][division-operator] para obtener el valor de la moneda cambiada.

## 2. Calcular el dinero que queda después de un cambio

- Puedes usar el [operador de resta][subtraction-operator] para obtener la cantidad de cambio.

## 3. Calcular el valor de los billetes

- Puedes usar el [operador de multiplicación][multiplication-operator] para obtener el valor de los billetes.

## 4. Calcular la cantidad de billetes

- Necesitas dividir `amount` entre `denomination`.
- Para quitar los decimales de un número de punto flotante, puedes usar la función [`floor()`][floor].
- Necesitas un entero para obtener la cantidad exacta de billetes.
 La función `floor` puede tomar el tipo de salida deseado como parámetro.

  **Nota:** El [operador `÷`][div], o la función `div()`, también hace división entera. Sin embargo, si un operando es de punto flotante, el resultado sigue siendo de punto flotante.

## 5. Calcular el sobrante después de cambiar a billetes

- Necesitas encontrar el residuo de `amount` que no equivale a una `denomination` completa.
- El [operador de módulo][div] `%` puede ayudarte a encontrar el residuo.

## 6. Calcular el valor después del cambio

- Necesitas calcular el porcentaje `spread` de `exchange_rate` usando el operador de multiplicación y sumarlo a `exchange_rate` para obtener la tasa de cambio total (ver el ejemplo en las instrucciones).
- Una vez que tengas la tasa de cambio total a partir de `exchange_rate`, necesitas calcular el valor total de un cambio.
- Con la tasa de cambio total, el cambio se puede hacer en tres pasos en la aplicación:
    - Puedes calcular el valor intercambiable desde cero, o...
    - Puedes usar tres de tus funciones de las tareas anteriores.
- Presta atención al orden en que se procesan las funciones,
    - Empieza con una función que use una tasa de cambio.
    - La salida de una función debe darte una pista de cuál se necesita después.
