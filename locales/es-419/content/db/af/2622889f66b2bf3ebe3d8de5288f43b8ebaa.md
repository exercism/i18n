# Instrucciones

Te han tentado para que vuelvas a Hyperia (con su alta inflación) con una tarifa diaria exorbitante.

El Banco Central está considerando introducir el dólar estadounidense como segunda moneda, así que todos los sistemas de contabilidad tienen que adaptarse para manejar varias monedas.

Te han pedido que implementes el objeto de importe de moneda.

## 1. Haz que se pueda comprobar la igualdad del importe de moneda

Modifica la estructura `CurrencyAmount` para que maneje la igualdad. Si las dos estructuras de importe de moneda no tienen la misma moneda («USD» o «HD»), se debe lanzar una instancia de `ArgumentException`.

```csharp
CurrencyAmount amountA = new CurrencyAmount(55, "HD");
CurrencyAmount amountB = new CurrencyAmount(55, "HD");
CurrencyAmount amountC = new CurrencyAmount(55, "USD");
amountA == amountB
// => true
amountA != amountB
// => false
amountA == amountC
// => ArgumentException
amountA != amountC
// => ArgumentException
```

## 2. Compara importes de moneda

Modifica la estructura `CurrencyAmount` para que maneje las comparaciones (solo `>` y `<`). Si las dos estructuras de importe de moneda no tienen la misma moneda («USD» o «HD»), se debe lanzar una instancia de `ArgumentException`.

```csharp
CurrencyAmount amountA = new CurrencyAmount(55, "HD");
amountA > new CurrencyAmount(50, "HD")
// => true
amountA < new CurrencyAmount(50, "HD")
// => false
amountA > new CurrencyAmount(50, "USD")
// => ArgumentException
```

## 3. Suma y resta importes de moneda

Modifica la estructura `CurrencyAmount` para que maneje la suma y la resta aritméticas (solo `+` y `-`). Si las dos estructuras de importe de moneda no tienen la misma moneda («USD» o «HD»), se debe lanzar una instancia de `ArgumentException`.

```csharp
CurrencyAmount amountA = new CurrencyAmount(55, "HD");
CurrencyAmount amountB = new CurrencyAmount(100, "HD");
CurrencyAmount amountC = new CurrencyAmount(55, "USD");
amountA + amountB
// => {155, HD}
amountB - amountA
// => {45, HD}
amountA + amountC
// => ArgumentException
```

## 4. Multiplica y divide importes de moneda

Modifica la estructura `CurrencyAmount` para que maneje la multiplicación y la división aritméticas (solo `*` y `/`).

```csharp
CurrencyAmount amountA = new CurrencyAmount(10, "HD");
amountA * 2m
// => {20, HD}
amountA / 2m
// => {5, HD}
```

## 5. Convierte el importe de moneda a un double

Modifica la estructura `CurrencyAmount` para que una instancia se pueda convertir explícitamente a `double`.

```csharp
CurrencyAmount amountA = new CurrencyAmount(55.5m, "HD");
(double)amountA
// => 55.5d
```

## 6. Convierte el importe de moneda a un decimal

Modifica la estructura `CurrencyAmount` para que una instancia se pueda convertir implícitamente a `decimal`.

```csharp
CurrencyAmount amountA = new CurrencyAmount(55.5m, "HD");
decimal d = amountA;
// => d == 55.5m
```
