# Introducción

## Alias de tipo

### Alias de tipo

Puedes usar un alias de tipo en Gleam para dar un nombre conveniente a un tipo existente que de otro modo sería engorroso de escribir.

```gleam
pub type Headers =
  List(#(String, String))

pub fn html_headers() -> Headers {
  [
    #("content-type", "text/html"),
    #("x-frame-options", "DENY"),
  ]
}
```

Cuando se escribe con `pub type`, el alias se puede usar fuera del módulo en el que se define. Si se omite `pub`, el alias es privado y no se puede referenciar en otros módulos.

## Diccionarios

Los diccionarios en Gleam son la estructura de datos para almacenar información en pares clave-valor. En otros lenguajes, también se conocen como arreglos asociativos, hashes o diccionarios.

Se puede usar cualquier tipo para las claves y los valores en un diccionario, y no garantizan el orden de sus entradas cuando se accede a ellas o se devuelven.

### Trabajar con diccionarios

Los diccionarios se crean y manipulan usando funciones del módulo `gleam/dict`.

```gleam
// Create an empty dict
let dict1 = dict.new()

// Create a dict with some values
let dict2 = dict.from_list([
  #("name", "Gleam"),
  #("colour", "Pink"),
])

// Add a value to a dict
let dict3 = dict.insert(dict2, "website", "https://gleam.run")

// Get a value from a dict
let name = dict.get(dict3, "name")
// -> Ok("Gleam")
```
