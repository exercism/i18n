# Aprendizaje

## Aprender C++ desde cero

C++ es un lenguaje con una sintaxis amplia y expresiva que admite varios
estilos de programación distintos: procedural, orientado a objetos, funcional
y genérico, además de combinaciones de todos ellos en un mismo
programa.  Este track de lenguaje intenta presentar los problemas con una
dificultad que aumenta de forma gradual.  Sin embargo, algunos elementos de la
sintaxis del lenguaje se explican mejor de otra forma y no como una serie de
ejercicios.

En general, Exercism da por hecho que ya conoces la sintaxis y los mecanismos
del lenguaje de un track en particular.  Sin embargo, conocer la sintaxis de un
lenguaje es solo el primer paso para dominarlo.
Exercism te permite practicar la resolución de problemas y compartir
opiniones con otras personas que resolvieron el mismo problema.  Es de esa
conversación compartida de donde obtenemos experiencia y perspectiva para
convertirnos en mejores programadores.

Si el lenguaje C++ es totalmente nuevo para ti, primero deberías dedicar tiempo
a aprender lo básico del lenguaje.  Aquí tienes algunos recursos que pueden
ayudarte a empezar:

* [Learn C++](http://www.learncpp.com/)
* [C++ Koans](https://github.com/torbjoernk/CppKoans)

[Coliru](http://coliru.stacked-crooked.com/) es una interfaz web sencilla, tipo
formulario, para un compilador de C++ que te permite probar programas pequeños.
A veces, esta puede ser una forma más fácil de hacer un experimento rápido que
montar algo localmente en un entorno de desarrollo integrado.

## Desarrollo guiado por pruebas en C++

Exercism da por hecho que conoces el concepto de desarrollo guiado por
pruebas.  Cada ejercicio incluye una serie de pruebas que ya están
escritas para ti.  Avanzas por el ejercicio prueba a prueba,
escribiendo una implementación de forma incremental hasta que las pruebas
se cumplan.

Si es la primera vez que trabajas con el desarrollo guiado por pruebas, te
recomendamos que primero hagas el taller [Test-Driven Development in C++](https://github.com/boostcon/cppnow_presentations_2014/tree/master/files/test_driven)
de [C++ Now! 2014](http://cppnow.org/).  Las mismas herramientas que se usan
en ese taller se usan en el track de C++ de Exercism.
