# Introducción

## Arrays

La biblioteca central de Cairo implementa un tipo `Array`.

Es similar a los tipos de array habituales de otros lenguajes de programación, pero tiene algunas diferencias clave:

- Los elementos solo se pueden agregar de forma eficiente al final del tipo `Array`, y solo se pueden eliminar de forma eficiente desde el frente.
- Es imposible asignar un elemento manualmente usando el índice del array.

Los arrays se pueden crear con la función `ArrayTrait::new` y también con la macro `array!`:

```rust
let empty: Array<u32> = ArrayTrait::new();
let one_to_four = array![1, 2, 3, 4];
```

Los elementos se pueden agregar al array con la función `ArrayTrait::append`:

```rust
let mut num_array = array![1, 2, 3, 4];
num_array.append(5);
// -> [1, 2, 3, 4, 5]
```

Los elementos se pueden eliminar del array con la función `ArrayTrait::pop_front`:

```rust
let mut one_to_four = array![1, 2, 3, 4];

one_to_four.pop_front();
// -> [2, 3, 4]
```

Cairo también introduce un tipo `Span` que actúa como una «instantánea» del `Array`.

Cualquier `Array` se puede convertir en un `Span` con la función `ToSpanTrait::span`:

```rust
let one_to_four = array![1, 2, 3, 4];
let one_to_four_span = one_to_four.span();
// -> [1, 2, 3, 4]
```

Convertir un array en un `Span` es muy eficiente, ya que `Span` es solo una estructura de datos que le permite a Cairo «ver» una sección del array; no lo modifica de ninguna manera.

Al convertir un array en un `Span`, Cairo permite realizar más operaciones de las que se permitirían directamente sobre `Array`, como eliminar un elemento del frente del span.

```rust
let one_to_four = array![1, 2, 3, 4];
let mut one_to_four_span = one_to_four.span();
one_to_four_span.pop_back();
// -> [2, 3, 4]
```

Fíjate que tuvimos que hacer mutable `one_to_four_span` con la palabra clave `mut` para poder invocar `pop_back`, que modifica el span al acortar la sección del array que el span está «viendo».
