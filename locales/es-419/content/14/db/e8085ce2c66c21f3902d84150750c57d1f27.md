# Anexo de instrucciones

## Implementación

Deberías definir un tipo personalizado «DNA» con una función «Counts» que devuelva dos valores:

- un recuento de frecuencia para la cadena de ADN dada
- un error (si hay nucleótidos no válidos)

¿Cuál es un buen tipo para una cadena de ADN?

¿Cuáles son los mejores tipos de Go para representar los valores de salida?

Echa un vistazo a los casos de prueba para hacerte una idea de cuáles podrían ser las posibles entradas.
