# Instrucciones

Una rueda de cifrado son dos discos, uno dentro del otro, que hacen girar el alfabeto: ponla en 3 y cada letra se convierte en la que está tres posiciones más adelante, y la `z` vuelve de nuevo a la `a`. Los detectives las han usado durante siglos. Estás construyendo una.

Las cinco tareas van en la clase `CIPHER_WHEEL`.

## 1. ¿Es una letra?

```sather
CIPHER_WHEEL::is_letter('m')
-- => true
CIPHER_WHEEL::is_letter('7')
-- => false
```

## 2. Hazlo gritar

Devuelve la mayúscula de un carácter. Cualquier cosa que no sea una letra se devuelve sin cambios.

```sather
CIPHER_WHEEL::shout('m')
-- => 'M'
```

## 3. ¿Qué número es?

Devuelve el número que representa a un carácter.

```sather
CIPHER_WHEEL::code('a')
-- => 97
```

## 4. El primer carácter

Devuelve el primer carácter de un string.

```sather
CIPHER_WHEEL::first_character("Marlowe")
-- => 'M'
```

## 5. Gira la rueda

Dada una letra minúscula y un número de posiciones, devuelve la letra que está esa cantidad de posiciones más adelante en el alfabeto. Después de la `z`, vuelve de nuevo a la `a`.

```sather
CIPHER_WHEEL::turn('a', 3)
-- => 'd'
CIPHER_WHEEL::turn('z', 1)
-- => 'a'
```

Girar hacia atrás también funciona, con un número negativo de posiciones.

```sather
CIPHER_WHEEL::turn('a', -1)
-- => 'z'
```

Puedes asumir que el carácter que se recibe es una letra minúscula.
