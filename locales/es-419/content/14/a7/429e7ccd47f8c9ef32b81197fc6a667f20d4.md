# Pistas

## General

- Lee sobre [opcionales][optionals] y sobre [condicionales][conditionals] en el _A Tour of Swift_ de Apple.

## 1. Escribe una función que calcule los tamaños de las rebanadas y devuelva nil para argumentos no válidos.

- El área de un círculo es _pi_ \* _r_<sup>2</sup>, donde _r_ es la mitad del diámetro.
- Puedes usar la conversión de tipos para convertir un `Int` en un `Double`.
- Puedes usar un condicional al estilo guard para salir antes si alguno de los parámetros no es válido.

## 2. Procesa los argumentos que llegan desde tu aplicación web para determinar la rebanada más grande.

- Puedes usar el enlace de opcionales para determinar si un opcional tiene un valor y extraer ese valor si existe.
- Puedes salir de la función antes si sabes cuál debería ser el valor de retorno sin procesar nada más.
- No puedes comparar `nil` directamente con valores que no son nil.
- Puedes usar sentencias switch y patrones opcionales para comparar valores opcionales.
