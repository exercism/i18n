# Introducción

Un búfer de string es una forma eficiente de construir un string grande agregando pequeños elementos uno tras otro. A diferencia de String, una instancia de StringBuf no es inmutable, en el sentido de que se le puede pasar como argumento a funciones que la modifican agregando más valores.

```haxe
var a = new StringBuf();
a.add("Hello");
trace(a.toString()); // Hello
a.add("Haxe!");
trace(a.toString()); // HelloHaxe
```
