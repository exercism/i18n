# Instalación

Este track usa ReScript 12 y requiere [Node.js][nodejs] 22 o superior.
Muchos sistemas ya lo tendrán preinstalado, o quizás ya lo hayas instalado para otro track.

Abre una terminal y ejecuta:

```sh
node -v
```

Si Node no está instalado o aparece una versión anterior, sigue las instrucciones de [la instalación oficial de Node.js][nodejs-install] para tu plataforma.

## Instalar las dependencias

Cada ejercicio de ReScript es un proyecto de npm independiente.
Después de descargar un ejercicio con la [CLI de Exercism][exercism-cli], instala las dependencias del proyecto, incluido ReScript, y ya podrás empezar:

```sh
cd /path/to/exercise
npm install
```

## Compatibilidad con editores

El proyecto ReScript mantiene una [lista de plugins de editor, tanto oficiales como de la comunidad][rescript-plugins].
