# Asignación de combustible

## Planteamiento del problema

Cada empleado de ABC Corp recibe una asignación de combustible ilimitada. Los empleados deben enviar un registro cada vez que llenan el tanque de sus vehículos. Estos registros se agregan al mismo archivo CSV y se procesan al final del mes.

Como miembro del equipo de operaciones digitales, tu tarea es leer este archivo CSV y escribir los resultados en otro archivo CSV. El archivo de salida debe contener una entrada por cada empleado con los siguientes detalles:

- Número de empleado
- Cantidad de cargas de gasolina
- Costo total del combustible
- Total de galones
- Total de millas acumuladas

Se te dan dos argumentos de tipo `string`.

1. Ruta del archivo CSV de entrada
1. Ruta del archivo CSV de salida

El archivo CSV de entrada tiene `n` líneas, y cada línea tiene la siguiente forma.

| Nombre de la columna      | Tipo en Ballerina |
| ----------- | ----------- |
| employee_id      | `int`       |
| odometer_reading   | `int`       |
| gallons   | `decimal` |
| gas_price(USD)  |`decimal`|

El archivo de salida debe contener una entrada por cada empleado, ordenadas de forma ascendente por el `employee_id`. Cada línea tiene la siguiente forma:

| Nombre de la columna      | Tipo en Ballerina |
| ----------- | ----------- |
| employee_id      | `int`       |
| gas_fill_up_count   | `int`        |
| total_fuel_cost(USD)   | `decimal` |
| total_gallons  |`decimal`|
| total_miles_accrued  |`int`|

## Restricciones

- Número de líneas `n` en el archivo CSV de entrada:  2 <= n <= 1000
- Número de empleados en la empresa: 97
- El precio de la gasolina es por galón
- No hay registros de carga faltantes

## Ejemplo 1

- Entrada: `example01_input.csv`

```csv
2312,230,18.561,4.56
2312,500,19.345,4.89
```

- Salida: `example01_output.csv`

```csv
2312,2,179.23521,37.906,270
```
