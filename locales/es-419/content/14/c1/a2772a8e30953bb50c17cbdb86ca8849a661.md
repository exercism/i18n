# Instrucciones

Izzy es una ávida observadora de aves que lleva la cuenta de cuántas aves han visitado su jardín en un día cualquiera.

Te ha pedido que la ayudes a llevar su observación de aves a un nuevo nivel e implementar algunas herramientas que la ayuden a registrar y procesar los datos.

Has elegido almacenar los datos como un array de números enteros. El primer número del array es la cantidad de aves que visitaron tu jardín hoy, el segundo ayer, y así sucesivamente.

## 1. Comprueba cuántas aves visitaron hoy

Implementa la función `today`. Debe tomar un array de conteos diarios de aves y devolver el conteo de hoy. Si el array está vacío, debe devolver `0`.

```gleam
today([2, 5, 1])
// -> 2
```

## 2. Incrementa el conteo de hoy

Implementa la función `increment_day_count`. Debe tomar un array de conteos diarios de aves e incrementar el conteo de hoy en 1. Si el array está vacío, devuelve `[1]`.

```gleam
increment_day_count([4, 0, 2])
// -> [5, 0, 2]
```

## 3. Comprueba si hubo un día sin aves visitantes

Implementa la función `has_day_without_birds`. Debe tomar un array de conteos diarios de aves. Debe devolver `True` si hubo al menos un día en el que ninguna ave visitó el jardín, y `False` en caso contrario. Si el array está vacío, esto cuenta como que _aún_ no se ha registrado ninguna ave; devuelve `False`.

```gleam
has_day_without_birds([2, 0, 4])
// -> True

has_day_without_birds([3, 8, 1, 5])
// -> False
```

## 4. Calcula el número total de aves visitantes

Implementa la función `total`. Debe tomar un array de conteos diarios de aves y devolver el número total que visitaron tu jardín desde que empezaste a recopilar los datos.

```gleam
total([4, 0, 9, 0, 5])
// -> 18
```

## 5. Calcula el número de días ajetreados

Algunos días son más ajetreados que otros. Un día ajetreado es aquel en el que cinco o más aves han visitado tu jardín.

Implementa la función `busy_days`. Debe tomar un array de conteos diarios de aves y devolver el número de días ajetreados.

```gleam
busy_days([4, 5, 0, 0, 6])
// -> 2
```
