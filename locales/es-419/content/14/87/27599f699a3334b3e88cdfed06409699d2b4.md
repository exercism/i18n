# Instrucciones

El departamento de reclamaciones de Isaac's Asteroid Exploration Co. te ha encargado mejorar el rendimiento de su sistema de reclamación de tierras.

Cada vez que un asteroide está listo para su explotación, se invita a los especuladores a reclamar una parcela de tierra.
La tierra del asteroide se divide en parcelas rectangulares que no se superponen.
Las dimensiones varían, pero todas tienen sus lados paralelos a los ejes de coordenadas.
Los especuladores reclaman una de las parcelas especificando sus coordenadas.

Tu objetivo es desarrollar un sistema eficiente que maneje la fiebre por la tierra que en el pasado hizo que el sitio web se cayera.

La unidad de medida es de 100 metros, pero puedes ignorarla en estas tareas.

## 1. Define un punto

Define una `struct` que contenga las coordenadas `x` y `y`.
Son enteros no negativos bastante pequeños, así que usa el tipo `UInt16`.

```julia-repl
julia> Coord(7, 3)
Coord(0x0007, 0x0003)  # unsigned integers display in hex format by default
```

## 2. Define una Plot

Como todas las parcelas deben ser rectangulares, con lados horizontales y verticales, solo se necesitan dos esquinas opuestas para definirlas.

Implementa la estructura `Plot`, que recibe dos estructuras `Coord` en su constructor.

`Plot` debe ser una struct de palabras clave, con los campos `bottom_left` y `top_right`.

```julia-repl
julia> plot = Plot(bottom_left=Coord(10, 1), top_right=Coord(20, 2))
Plot(Coord(0x000a, 0x0001), Coord(0x0014, 0x0002))

julia> plot.top_right
Coord(0x0014, 0x0002)
```

## 3. Comprueba si tu reclamación ya fue presentada

Hay competencia por estas reclamaciones, así que antes de que se permita tu reclamación se comprobará con las reclamaciones existentes en el registro.

Implementa la función `is_claim_staked()` para determinar si una reclamación ya fue registrada.

```julia-repl
julia> claim = Plot(bottom_left=Coord(10, 1), top_right=Coord(20, 2));
julia> register = Set{Plot}();
julia> is_claim_staked(claim, register)
false
```

## 4. Los especuladores pueden reclamar especificando una parcela identificada por las coordenadas de sus esquinas

Implementa la función mutadora `stake_claim!()` para permitir que se registre una reclamación.

Si la misma reclamación ya fue registrada, devuelve `false`.

Si es posible una nueva reclamación, agrégala al registro y devuelve `true`.

```julia_repl
julia> claim = Plot(bottom_left=Coord(10, 1), top_right=Coord(20, 2));
julia> register = Set{Plot}();
julia> stake_claim!(claim, register)
true
```

## 5. Encuentra la longitud del lado más largo de una parcela.

Implementa la función `get_longest_side()` para obtener el lado más largo (horizontal o vertical) de una reclamación.

```julia-repl
claim = Plot(bottom_left=Coord(10, 1), top_right=Coord(20, 2));

julia> get_longest_side(claim)
0x000a
```

## 6. Encuentra la parcela reclamada que tiene el lado más largo, con fines de investigación

Implementa la función `get_claim_with_longest_side()` para examinar todas las reclamaciones registradas y devolver la reclamación o reclamaciones con el lado más largo.

```julia-repl
julia> plot1 = Plot(bottom_left=Coord(5, 3), top_right=Coord(10, 5));
julia> plot2 = Plot(bottom_left=Coord(0, 0), top_right=Coord(3, 3));
julia> register = Set{Plot}([plot1, plot2]);

julia> get_claim_with_longest_side(register)
Plot(Coord(0x0005, 0x0003), Coord(0x000a, 0x0005))
```

Devuelve las `Plot` como un `Set`, con un elemento si hay una sola parcela con el lado más largo, y varios en caso de empate.
