# Introducción

Una declaración `MACRO:` es como `:`, pero el cuerpo se ejecuta en *tiempo de compilación* y debe devolver un quotation. El compilador sustituye la llamada a la macro por ese quotation devuelto. Como el cuerpo es código Factor normal, construir el quotation resultante es simplemente manipular secuencias de palabras.

```factor
USING: kernel macros sequences ;

MACRO: twice ( quot -- compound )
    dup append ;

: shout-twice ( name -- ) [ " ahoy!" append print ] twice ;
! At compile time, the call site is replaced with
! [ " ahoy!" append print " ahoy!" append print ].
```

Los argumentos de una macro son *literales en el lugar de la llamada*. Si pasas un valor que no sea un literal, el compilador se negará a especializar, porque el cuerpo de la macro necesita el valor en tiempo de compilación y no en tiempo de ejecución.

Un pariente cercano es el bloque `<< … >>` de evaluación en tiempo de análisis, que ejecuta Factor arbitrario en tiempo de compilación sin el contrato de devolver un quotation. Ambos forman parte del mecanismo [`macros`][macros] de Factor.
