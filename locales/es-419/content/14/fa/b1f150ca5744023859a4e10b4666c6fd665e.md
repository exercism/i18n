# Pistas

## General

- [El tutorial de diccionarios de Python][dict-tutorial] puede ser un gran punto de partida.
- La documentación de Python sobre [tipos de asignación - diccionarios][dict docs] también es bastante útil.

## 1. Crea un inventario a partir de una lista

- Necesitas un [bucle `for`][for-loop] para iterar sobre la lista de elementos, luego inserta cada elemento en el diccionario si falta e incrementa el número de elementos usando el accesor del diccionario.
- Puedes usar [`dict.setdefault`][dict setdefault] para asegurarte de que el valor esté establecido antes de incrementar el número de elementos.
- Esta función debe [devolver][return-keyword] un diccionario.

## 2. Agrega elementos de una lista a un diccionario existente

- Necesitas un [bucle `for`][for-loop] para iterar sobre la lista de elementos, luego inserta cada elemento si aún no está en el diccionario e [incrementa][increment] el número de elementos usando el accesor del diccionario.
- Puedes usar [`dict.setdefault`][dict setdefault] para asegurarte de que el valor esté establecido antes de incrementar el número de elementos.
- La función `add_items` puede ser usada por la función `create_inventory` con un diccionario vacío como parámetro.
- Esta función debe [devolver][return-keyword] un diccionario.

## 3. Decrementa elementos del inventario

- Necesitas un [bucle `for`][for-loop] para iterar sobre la lista de elementos; si el número de elementos no es `0`, entonces [decrementa][decrement] el número actual de elementos.
- Puedes usar la comprobación `key in dict`, que devuelve `True` si la clave existe, para asegurarte de que el valor esté en el diccionario antes de decrementar el número de elementos.
- Esta función debe [devolver][return-keyword] un diccionario.

## 4. Elimina un elemento por completo del inventario

- Si el elemento está en el diccionario, [elimínalo][dict-pop].
- Si el elemento no está en el diccionario, no hagas nada.
- Esta función debe [devolver][return-keyword] un diccionario.

## 5. Devuelve el contenido del inventario

- Necesitas usar un [bucle `for`][for-loop] sobre el inventario y, si el número de elementos es mayor que `0`, entonces agrega la `tuple` a una `list`.
- Puedes usar [`dict.items()`][dict items] para iterar sobre el elemento y el valor al mismo tiempo; `items()` devuelve una `tuple` que puedes usar o desestructurar, si es necesario.
- Esta función debe [devolver][return-keyword] una [lista][list] de [tuplas][tuples].
