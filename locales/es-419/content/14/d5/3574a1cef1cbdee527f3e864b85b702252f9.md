# Introducción

## Listas

Las listas están integradas en el lenguaje Elixir. Se consideran un tipo básico, denotado por corchetes. Las listas pueden estar vacías o contener cualquier cantidad de elementos de cualquier tipo. Por ejemplo:

```elixir
empty_list = []
one_item_list = [1]
two_item_list = [1, 2]
multiple_type_list = [1, :pi, 3.14, "four"]
```

Elixir implementa las listas como una lista enlazada, donde cada nodo almacena dos valores: el primer elemento y otra lista con todos los elementos restantes. Al primer elemento de la lista se le llama _cabeza_ y a la lista de elementos restantes se le llama _cola_. Podemos usar esta notación en el código:

```elixir
# [1] represented in [head | tail] notation
[1 | []]

# [1, 2, 3] represented in [head | tail] notation
[1 | [2 | [3 | []]]]
```

Podemos usar la notación _`[head | tail]`_ para anteponer elementos a una lista:

```elixir
# Suppose
list = [2, 1]

[3, 2, 1] == [3 | list]
# => true
```

Hay varias funciones en el módulo `Kernel` para trabajar con listas, así como todo el módulo `List`.

```elixir
# Check if 1 is a member of the list
1 in [1, 2, 3, 4]
# => true
```
