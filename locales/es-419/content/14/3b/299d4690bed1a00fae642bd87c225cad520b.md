# Introducción

El ámbito de un valor se relaciona con el lugar del programa en el que se puede acceder a ese valor.

## Los cuatro tipos de ámbito: bloque; función; prototipo de función; archivo

### Ámbito de bloque

Solo se puede acceder a un valor con ámbito de bloque desde dentro del bloque donde se define.
Para más información sobre los bloques, consulta el [concepto de bloque](../blocks/introduction.md#Introduction).

### Ámbito de función

El ámbito de función es un tipo especial de ámbito que se aplica a las etiquetas que se usan con las sentencias `goto`.
No se pueden usar dos etiquetas con el mismo nombre en la misma función, incluso si las etiquetas se definen en bloques distintos dentro de la función.

### Ámbito de prototipo de función

El ámbito de prototipo de función es otro tipo especial de ámbito que se aplica solo a los parámetros que se nombran dentro del prototipo (también conocida como la declaración, ten en cuenta que no todas las declaraciones son prototipos).
El nombre de un parámetro normalmente es opcional en la declaración de una función.
El ámbito de un nombre solo es relevante dentro de la declaración.
Una definición de función no tiene que usar para un parámetro el mismo nombre que se usó en la declaración de la función.

### Ámbito de archivo

Se puede acceder a un valor con ámbito de archivo desde cualquier parte del archivo.
Cualquier valor de este tipo se define fuera de una función.
