# Acerca de

«Estadística» es un tema amplio y complejo con muchos aspectos.

Algunos de esos aspectos se abordaron en el concepto [`Randomness`][randomness], que es un tema aparte pero relacionado.

En su forma más simple, la estadística puede consistir en formas de resumir una colección iterable de datos en un solo valor.
A quienes recién llegan a Julia puede sorprenderles lo pocas funciones que vienen incluidas en el lenguaje de forma predeterminada:

- [`sum`][sum], para sumar números.
- [`min`][min] y [`max`][max], para obtener los valores extremos de los parámetros dados.
- [`extrema`][extrema], para obtener la tupla (min, max) de un iterable.
- [`length`][length], para contar todos los valores.
- [`count`][count], para contar solo los valores que cumplen algún criterio.

```julia-repl
julia> v = collect(1:0.2:3)
11-element Vector{Float64}:
 1.0
 1.2
 ... # display truncated
 3.0

julia> mean(v)
2.0

julia> extrema(v)
(1.0, 3.0)

julia> length(v)
11

julia> min('g', 'a', 'c')
'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)

julia> count(isodd, 1:5)  # 1, 3, and 5 are odd
3
```

Este conjunto limitado de funciones es una decisión deliberada para minimizar el exceso de código en la Julia base, moviendo otras funciones a una cascada de módulos y paquetes adicionales.

## El módulo `Statistics`

Como forma parte de la biblioteca estándar, es probable que [`Statistics`][statistics] ya esté preinstalado, así que solo necesitas agregar `using Statistics` al principio del programa para traerlo al espacio de nombres.

Este módulo contiene el siguiente nivel de funciones comunes, que probablemente sean muy usadas por una parte de quienes programan.

Muchas de las funciones de `Statistics` suponen algunos conocimientos previos sobre el tema.
Los ejemplos más simples incluyen:

- [`mean`][mean], que mucha gente llamaría el promedio (el mismo resultado que `sum / length`).
- [`median`][median], el valor central después de ordenar.
- [`std`][std], [desviación estándar][stddev]: una medida de qué tan dispersos están los valores.
- [`var`][var], varianza: el cuadrado de `std`, que por lo general es más rápido de calcular.

Cada función suele tener varias opciones, y hay _muchas_ más funciones, así que consulta la [documentación][statistics] si te interesa.
