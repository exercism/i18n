# Pistas

## General

- Un número de punto flotante se devuelve en `xmm0`.
- Los primeros 8 argumentos de punto flotante se pasan en `xmm0` hasta `xmm7`.

## 1. Calcula la tarifa diaria a partir de una tarifa por hora

- Un número de punto flotante se devuelve en `xmm0`.
- Los primeros 8 argumentos de punto flotante se pasan en `xmm0` hasta `xmm7`.
- Un entero de 64 bits se puede convertir a un número de punto flotante de doble precisión usando `cvtsi2sd`.
- Un inmediato (un número constante) se debe almacenar en un registro de propósito general antes de convertirlo a un número de punto flotante.
- Dos números de punto flotante de doble precisión se pueden multiplicar con `mulsd`.

## 2. Calcula un precio con descuento

- Un número de punto flotante se devuelve en `xmm0`.
- Los primeros 8 argumentos de punto flotante se pasan en `xmm0` hasta `xmm7`.
- Dos números de punto flotante de doble precisión se pueden dividir con `divsd`.
- Un número de punto flotante de doble precisión se puede restar de otro con `subsd`.

## 3. Calcula la tarifa mensual a partir de una tarifa por hora y un descuento

- Un número de punto flotante se devuelve en `xmm0`.
- Los primeros 8 argumentos de punto flotante se pasan en `xmm0` hasta `xmm7`.
- Puedes usar `roundsd` para redondear un número de punto flotante de doble precisión, usando un tercer operando para indicar el modo de redondeo.
- El número para redondear hacia arriba (techo) es `2`.
- Puedes usar `cvtsd2si` para convertir un número de punto flotante de doble precisión a un entero de 64 bits.

## 4. Calcula el número de días laborales a partir de un presupuesto, una tarifa por hora y un descuento

- Un número de punto flotante se devuelve en `xmm0`.
- Los primeros 8 argumentos de punto flotante se pasan en `xmm0` hasta `xmm7`.
- Puedes usar `roundsd` para redondear un número de punto flotante de doble precisión, usando un tercer operando para indicar el modo de redondeo.
- El número para redondear hacia abajo (piso) es `1`.
- Puedes usar `cvtsd2si` para convertir un número de punto flotante de doble precisión a un entero de 32 bits.
