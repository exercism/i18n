# Pistas

## General

- `MACRO:` está en [`macros`][macros]. Los bloques de construcción se encuentran en `kernel` (`dup`, `curry`), `sequences` (`append`, `concat`, `<repetition>`, `map`) y `quotations` (`>quotation`).
- El cuerpo de una macro debe dejar **una quotation** en la pila. Si tu cuerpo produce un array de código, termina con `>quotation`.
- Para comprobar tu razonamiento, ejecuta las palabras del cuerpo sobre un literal en el listener y observa la quotation que obtienes; debería ser el código lineal de la línea «compila a» de la tarea.

## 1. Dos veces

- Recibes `[ A ]` y quieres `[ A A ]`. Haz una copia y únelas: `dup append`.

## 2. N repeticiones

- Recibes `[ A ] n` y quieres `n` copias unidas.
- `<repetition>` construye las copias, pero su efecto es `( length elt -- repetition )`; el conteo debe estar arriba, así que `swap` primero.
- Luego aplana y convierte: `swap <repetition> concat >quotation`.

  ```factor
  ! stack: [ 1 + ] 3
  swap <repetition>     ! 3 copies of [ 1 + ]
  concat >quotation     ! => [ 1 + 1 + 1 + ]
  ```

## 3. Compón varias

- Ya recibes el array de quotations; solo necesitas aplanarlo hasta obtener una. `concat >quotation` es todo el cuerpo.

## 4. Iteración desenrollada

Recibes una secuencia y una quotation, por ejemplo `{ 10 20 30 } [ + ]`, y quieres `[ 10 + 20 + 30 + ]`. Constrúyelo en tres pasos.

**Un elemento.** Incorporar un elemento a la quotation es exactamente lo que hace `curry`:

```factor
10 [ + ] curry .   ! => [ 10 + ]
```

**Cada elemento.** Quieres mapear eso sobre la secuencia, pero `map` solo le entrega a la quotation de mapeo una entrada (el elemento), mientras que también necesitas `[ + ]` a mano cada vez. Así que incorpora `[ + ]` en la quotation de mapeo primero, otra vez con `curry`:

```factor
! stack: { 10 20 30 } [ + ]
[ curry ] curry    ! => { 10 20 30 } [ [ + ] curry ]
map                ! runs  10 [ + ] curry,  20 [ + ] curry, …
                   ! => { [ 10 + ] [ 20 + ] [ 30 + ] }
```

`[ curry ] curry` se lee como «empuja la pequeña quotation `[ curry ]`, luego aplica curry a `[ + ]` dentro de ella», lo que da `[ [ + ] curry ]`. Mapear eso sobre un elemento `e` ejecuta `e [ + ] curry`, que es `[ e + ]`.

**Únelas.** El mismo final que las otras tareas:

```factor
concat >quotation  ! => [ 10 + 20 + 30 + ]
```

- El cuerpo completo: `[ curry ] curry map concat >quotation`.
