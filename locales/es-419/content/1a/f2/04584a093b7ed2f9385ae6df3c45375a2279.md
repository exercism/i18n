# Instrucciones

En este ejercicio vas a escribir código para llevar un registro de un array de lenguajes de programación que quieres aprender en Exercism.
Tienes seis tareas, y todas tienen que ver con arrays.

## 1. Crea un array nuevo

Para llevar un registro de los lenguajes que quieres aprender, vas a necesitar crear un array nuevo.
Define la constante `newList`, que contenga un array nuevo y vacío.

```elm
newList
    --> []
```

## 2. Define un array existente

Por ahora tienes una hoja de papel donde anotaste los lenguajes que quieres aprender: Elm, Clojure y Haskell.
Define la constante `existingList` para representar este array.

```elm
existingList
    --> [ "Elm", "Clojure", "Haskell" ]
```

## 3. Agrega un lenguaje nuevo a un array

A medida que exploras Exercism y encuentras lenguajes más interesantes, quieres agregarlos a tu array.
Implementa la función `addLanguage` para agregar un lenguaje nuevo al principio de tu array.

```elm
addLanguage "TypeScript" [ "JavaScript", "CoffeeScript" ]
    --> [ "TypeScript", "JavaScript", "CoffeeScript" ]
```

## 4. Cuenta los lenguajes del array

Contar los lenguajes a mano es incómodo.
Implementa la función `countLanguages` para contar cuántos lenguajes hay en tu array.

```elm
countLanguages [ "C#", "Racket", "Rust", "Ruby" ]
    --> 4
```

## 5. Invierte el array

En algún momento te das cuenta de que tu array en realidad está ordenado al revés.
Implementa la función `reverseList` para invertir tu array.

```elm
reverseList [ "Prolog", "C", "Idris", "Assembly" ]
    --> [ "Assembly", "Idris", "C", "Prolog" ]
```

## 6. Verifica si el array es emocionante

Aunque te encantan todos los lenguajes, Elm ocupa un lugar especial en tu corazón.
Por eso, un array de lenguajes te emociona de verdad si:

- El primer elemento del array es Elm.
- O si el segundo elemento del array es Elm y el array contiene tres lenguajes o menos.

Implementa la función `excitingList` para verificar si un array de lenguajes es emocionante:

```elm
excitingList [ "Nim", "Elm" ]
    --> True
```
