# no compares valores Boolean con true o false

Comparar valores Boolean con true o false es redundante.
Usar `==` genera un valor Boolean, así que no es necesario compararlo con otro valor Boolean predefinido.
Si quieres invertir el valor Boolean, usa el operador `!`.

```crystal
# Rather than:
some_bool == true
some_bool == false

# Consider:
some_bool
!some_bool
```
