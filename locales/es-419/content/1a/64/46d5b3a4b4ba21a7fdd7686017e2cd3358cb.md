# Depuración

Para ayudarte con la depuración, puedes aprovechar que toda la salida de la consola se capturará y se mostrará en la ventana de resultados de los tests.
Puedes mostrar cualquier valor pasándolo a `@show`.

`@show` muestra una expresión y su resultado, a la vez que devuelve ese resultado.

```julia
@show uppercase("hello") # HELLO will be shown as debug output
```

```julia-repl
julia> function f(a, b)
           @show a b
           return (@show a^b) / 1000
       end
f (generic function with 1 method)

julia> f(3, 5)
a = 3
b = 5
a ^ b = 243
0.243
```

También puedes usar [`println`](https://docs.julialang.org/en/v1/base/io-network/#Base.println) o cualquier otro método que escriba la salida en [`stdout`](https://en.wikipedia.org/wiki/Standard_streams#Standard_output_(stdout)).
