# Instrucciones

En este ejercicio vas a implementar un programa que determina el estado de una partida de [tres en línea][tic-tac-toe].
(_También puedes conocerlo como «noughts and crosses» o «Xs and Os»._)

La partida se juega en una cuadrícula de 3×3.
Las personas que juegan se turnan para colocar `X`s y `O`s en la cuadrícula.
El juego termina cuando alguien gana al colocar tres de sus marcas en una fila, una columna o una diagonal de la cuadrícula, o cuando se llena toda la cuadrícula.

En este ejercicio supondremos que `X` empieza.

Tu tarea es determinar en qué estado se encuentra una partida dada.

Hay 3 estados posibles del juego:

- La partida está **ongoing**.
- La partida terminó en **draw**.
- La partida terminó en **win**.

Si el tablero dado no es válido, lanza un error apropiado.

Un tablero no es válido si cumple las siguientes condiciones:

- No se puede llegar al tablero dado si los turnos se toman en el orden correcto (recuerda que `X` empieza).
- Se siguió jugando después de que la partida ya había terminado.

## Ejemplos

### Partida en curso

```text
   |   |
 X |   |
___|___|___
   |   |
   | X | O
___|___|___
   |   |
 O | X |
   |   |
```

### Empate

```text
   |   |
 X | O | X
___|___|___
   |   |
 X | X | O
___|___|___
   |   |
 O | X | O
   |   |
```

### Victoria

```text
   |   |
 X | X | X
___|___|___
   |   |
   | O | O
___|___|___
   |   |
   |   |
   |   |
```

### Inválido

#### Orden de turnos incorrecto

```text
   |   |
 O | O | X
___|___|___
   |   |
   |   |
___|___|___
   |   |
   |   |
   |   |
```

#### Se siguió jugando después de la victoria

```text
   |   |
 X | X | X
___|___|___
   |   |
 O | O | O
___|___|___
   |   |
   |   |
   |   |
```
