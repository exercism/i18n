# Acerca de

El vocabulario [`calendar`][calendar] de Factor se construye alrededor de dos tuplas:

- `timestamp`: un punto en el tiempo (`year`, `month`, `day`, `hour`, `minute`, `second`, y un desplazamiento GMT).
- `duration`: un lapso de tiempo (los mismos campos, usados como cantidades).

## Marcas de tiempo

`<date>` construye una marca de tiempo de medianoche; `>date<` separa una en sus partes:

```
<date> ( year month day -- timestamp )
>date< ( timestamp -- year month day )
```

```factor
USING: calendar ;

2024 7 14 <date> >date< .   ! => 14   (2024 and 7 below it)
```

Consultas comunes:

```factor
USING: calendar calendar.english sequences ;

2024 1 8 <date> day-of-week .          ! => 1   (0 = Sunday .. 6 = Saturday)
2024 1 8 <date> day-of-week day-names nth .   ! => "Monday"
2024 leap-year? .                      ! => t
2024 2 1 <date> days-in-month .        ! => 29
```

`day-names` (y `month-names`) se encuentran en [`calendar.english`][english].

## Duraciones y aritmética

Palabras como `days`, `weeks`, `hours` y `minutes` construyen una `duration`, y `time+` / `time-` desplazan una marca de tiempo en una duración:

```
days  ( x -- duration )
time+ ( timestamp duration -- timestamp )
```

```factor
2024 2 28 <date> 1 days time+ >date< .   ! => 29   (2024-02-29)
```

La aritmética cruza los límites de mes y año, y dos marcas de tiempo que designan el mismo instante se comparan como iguales con `=`.

Más allá de esto, `calendar` ofrece horas del día (`set-time`, `+hour`), conversiones de zona horaria (`>gmt`, `>local-time`), la hora actual (`now`) y, mediante `calendar.format`, parseo y formateo.
