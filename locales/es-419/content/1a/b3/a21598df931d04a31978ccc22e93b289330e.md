# Tests

  ## Resumen rápido

  1. Haz tus cambios en el archivo `<myFileName>.u`
  2. Guarda el archivo `<myFileName>.u`
  3. Si el archivo pasa la verificación de tipos, ejecuta los comandos `add` o `update` de UCM
    * Si el archivo no pasa la verificación de tipos, haz cambios en el código de tu archivo `<myFileName>.u` hasta que compile. ¡Recuerda hacer `update` de tus funciones después de tus cambios! 
  4. Ejecuta el comando `load <myFileName>.test.u` en la CLI de UCM para traer los tests al ámbito y ejecutarlos

  ## Paso a paso

  Si estás resolviendo un ejercicio de Exercism en la línea de comandos, lo más probable es que implementes tu solución en el directorio que lleva el nombre del ejercicio correspondiente. Por ejemplo, si el ejercicio es `hello-world`, deberías abrir `ucm` desde la línea de comandos después de haber hecho `cd` a `~/exercism/unison/hello-world`. Haz los cambios de tu implementación en el archivo `hello.u` y, cuando estés conforme con tu implementación, ingresa el comando `add` o `update` en la interfaz de línea de comandos del gestor de base de código de Unison (UCM) para agregar tu trabajo desde el archivo a la base de código.

  El archivo que contiene los tests de cada ejercicio tiene el sufijo `.test.u`. Querrás usar el comando `load` del UCM para traer los tests al ámbito y ejecutarlos. El comando `load` toma una ruta de archivo como argumento. Así se vería para el ejercicio hello world:

  ```
  .> load hello.test.u
  ```

  Deberías ver un mensaje del UCM sobre los términos que se trajeron al ámbito y, lo que es más importante, el resultado de ejecutar el test:

  ```

    ⍟ These new definitions are ok to `add`:

      hello.test : Test.Test
      tests      : [Result]

  Now evaluating any watch expressions (lines starting with
  `>`)... Ctrl+C cancels.


    6 | test> tests = runAll [hello.test]

    🚫 FAILED
  ```

  Digamos que tus tests no pasaron la primera vez. Vuelve a editar tu archivo `myExercise.u` y, al guardar, puedes hacer `update`

  ```
  I found and typechecked these definitions in ~/Exercism/unison/hello-world/hello.u. If you do an
  `add` or `update`, here's how your codebase would change:

    ⍟ These names already exist. You can `update` them to your new definition:

      hello : Text

  .> update

  ⍟ I've updated these names to your new definition:

    hello : Text
  ```

  ¡Ahora podemos volver a cargar nuestros tests para ver si algo cambió!

  ```
  .> load hello.test.u
    Now evaluating any watch expressions (lines starting with `>`)... Ctrl+C cancels.


    6 | test> tests = runAll [hello.test]

    ✅ Passed : Passed 1 tests.
  ```
