# Acerca de

Para crear una instancia de una _clase_ se llama a su [_constructor_][constructors] mediante el [operador `new`][new]. Un constructor es un tipo especial de método cuyo objetivo es inicializar una instancia recién creada. [Los constructores se parecen a los métodos normales][constructor-syntax], pero sin un tipo de retorno y con un nombre que coincide con el de la clase.

```csharp
class Library
{
    private books;

    public Library()
    {
        this.books = 10;
    }
}

// This will call the constructor
var library = new Library();
```

Al igual que los métodos normales, los constructores pueden tener parámetros. Los parámetros del constructor normalmente se guardan como [campos][fields] (privados) para acceder a ellos más adelante, o bien se usan en algún cálculo puntual. Se pueden pasar argumentos a los constructores igual que se pasan argumentos a los métodos normales.

```csharp
class Building
{
    private int numberOfStories;
    private int totalHeight;

    public Building(int numberOfStories, double storyHeight)
    {
        this.numberOfStories = numberOfStories;
        this.totalHeight = numberOfStories * storyHeight;
    }
}

// Call a constructor with two arguments
var largeBuilding = new Building(55, 6.2);
```

Especificar un constructor es opcional. Si no se especifica ningún constructor, el compilador genera un [constructor sin parámetros][parameterless-constructors]:

```csharp
class Elevator
{
}

// This will call the (empty) generated constructor
var elevator = new Elevator();
```

Si los campos tienen asignado un valor inicial, el compilador generará código en el que la asignación se hace en realidad dentro del constructor. Por lo tanto, las siguientes declaraciones de clase son equivalentes (en cuanto a funcionalidad):

```csharp
class UsingFieldInitialization
{
    private int players = 5;
}

class UsingConstructorInitialization
{
    private int players;

    public UsingConstructorInitialization()
    {
        players = 5;
    }
}
```
