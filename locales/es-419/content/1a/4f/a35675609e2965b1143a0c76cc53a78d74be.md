# Introducción
## Switch

Una [sentencia switch][switch] te permite comparar un valor con varios valores posibles.
Te permite escribir código más conciso que usando varias sentencias `else-if`.
Una sentencia switch empieza con la palabra clave `switch`, seguida del valor que se va a comparar.
Después puedes definir los casos con la palabra clave `case`, seguida del valor con el que se compara.
La palabra clave `default` se usa para definir el caso predeterminado cuando ninguno de los casos coincide.
Al igual que las sentencias `else-if`, las sentencias `switch` solo ejecutan el bloque de código asociado con el primer caso que coincida.

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

Considera el siguiente ejemplo:

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

Esto también podría escribirse así:

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```

## Bucles while

Un [bucle while][while-loops] es una sentencia de flujo de control que permite ejecutar código mientras cierta condición sea verdadera.
Swift ofrece dos tipos de bucles while: el bucle while y el bucle repeat-while.
La condición del bucle while se evalúa antes de que se ejecute el cuerpo del bucle; si la condición es falsa, el cuerpo del bucle no se ejecutará en absoluto.
Los bucles while en Swift tienen la siguiente estructura:

```swift
while <#condition#> {
  <#code#>
}
```

Aquí el bucle se ejecutará mientras count sea mayor que 0, y por lo tanto imprimirá los números 2, 1 y «Liftoff!».

```swift
var count = 2
while count > 0 {
  print("\(count)…")
  count -= 1
}
print("Liftoff!")

// prints:
// 2…
// 1…
// Liftoff!
```

Un [bucle repeat-while][while-loops] es similar a un bucle while, pero la condición se evalúa después de que se ejecuta el cuerpo del bucle.
Esto significa que el cuerpo del bucle siempre se ejecutará al menos una vez, incluso si la condición es falsa.
Los bucles repeat-while en Swift tienen la siguiente estructura:

```swift
repeat {
  <#code#>
} while <#condition#>
```

Aquí el bucle solo se ejecutará una vez, ya que la condición es falsa.
Como es un bucle repeat-while, el cuerpo del bucle se ejecutará una vez antes de que se evalúe la condición.

```swift
var count = 2
repeat {
  print("\(count)…")
} while count < 0
print("Liftoff!")
```

## Transferencia de control

Swift tiene un conjunto de sentencias que se pueden usar para alterar el flujo de control normal de los bucles.
Se conocen como sentencias de transferencia de control.
Ya viste `return`; este concepto presentará otras, entre las que se incluyen `continue`, `break` y las etiquetas.
No cubriremos `fallthrough` en este concepto, pero puedes leer sobre él en el [libro de Swift][fallthrough].

### Continue

A veces es necesario saltar a la siguiente iteración de un bucle antes de tiempo, sin completar el resto de las sentencias de la iteración actual del bucle.
La palabra clave `continue` se puede usar para esto.
Cuando se ejecuta `continue`, el bucle salta a la siguiente comprobación para ver si se puede ejecutar la siguiente iteración del bucle, es decir, el `while` en los bucles while y repeat-while, o la comprobación de si hay otro elemento en la secuencia en los bucles for-in.

```swift
count = 1
while count < 6 {
  count += 1
  if count == 4 { continue }
  print(count)
}

// prints:
// 2
// 3
// 5
```

### Break

Break se usa para salir de un bucle antes de tiempo.
Cuando se ejecuta `break`, el bucle se cierra de inmediato y el programa continúa con la primera sentencia después del bucle.

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  if !fruit.count.isMultiple(of: 2) { break }
  print(fruit)
}

// prints:
// banana
// grapes
```

### Etiquetas

Cuando los bucles están anidados, hay veces en las que puedes querer usar `break` o `continue` para salir o reiniciar los bucles externos que contienen el bucle en el que se usan `break` o `continue`.
En casos como estos, se pueden usar etiquetas para especificar el bucle del que se quiere salir o que se quiere reiniciar.
Un bucle se puede etiquetar colocando un nombre seguido de dos puntos antes del `while`, `repeat` o `for` que inicia el bucle.

Para ver el efecto de usar etiquetas de esta manera, considera el siguiente bucle.

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  print("\n--- \(fruit) ---")
  for letter in fruit {
    guard letter != "n" else { break outerLoop }
    print(letter)
  }
}

// prints:
// --- banana ---
// b
// a
```
