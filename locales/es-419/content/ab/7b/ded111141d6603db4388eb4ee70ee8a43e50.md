# Instrucciones

Es el turno de noche en el muelle de Hull. El carguero *Olwen* está atracado al lado, y una cuadrilla de estibadores trabaja el manifiesto en paralelo. Cada caja debe pesarse antes de subir a bordo, y el capitán de puerto lleva una única **cuenta de tonelaje** acumulada que cada izada actualiza. El detalle: solo hay una grúa en el muelle, así que la cuenta no puede quedar a medio actualizar por dos estibadores que la actualicen al mismo tiempo.

Cada caja es un array de pesos de artículos. El peso de una caja es la suma de esos artículos.

## 1. Pesa una caja

Define `weigh-crate` para que reciba una caja y devuelva su peso total. Esto es trabajo secuencial de lo más simple: entra una caja, sale un número.

```factor
{ 12 8 15 } weigh-crate .
! => 35
```

## 2. Pesa el manifiesto completo en paralelo

Define `weigh-all` para que reciba un array de cajas y devuelva el array de sus pesos, en el mismo orden. Usa `parallel-map` para que el trabajo de cada caja ocurra de forma concurrente.

```factor
{ { 5 5 } { 10 } { 3 4 5 } } weigh-all .
! => { 10 10 12 }
```

## 3. Construye una grúa nueva

Define `<crane>` para construir una grúa nueva: una tupla con un `<lock>` nuevo y un tonelaje de `0`. La grúa es el recurso compartido que las tareas siguientes van a proteger.

```factor
<crane> tonnage>> .
! => 0
```

## 4. Iza una caja a la cuenta acumulada

Define `hoist-crate` para que reciba un `weight` y una `crane` y sume el peso al tonelaje de la grúa **bajo el bloqueo de la grúa**, de modo que la lectura-suma-escritura sea atómica frente a otros estibadores que estén izando al mismo tiempo.

```factor
<crane>
35 over hoist-crate
17 over hoist-crate
tonnage>> .
! => 52
```

## 5. Lee el tonelaje acumulado

Define `crane-tonnage` para que devuelva el tonelaje actual de la grúa, también bajo el bloqueo, así una lectura no puede ver un valor a medio escribir en plena izada.

```factor
<crane>
35 over hoist-crate
crane-tonnage .
! => 35
```

## 6. Carga el cargamento

Define `load-cargo` para que reciba un array de cajas y una grúa, y **para cada caja lance un hilo de estibador** que pese la caja e ice el peso hacia la grúa. La palabra solo devuelve cuando todos los estibadores hayan terminado. Usa `<promise>` y `?promise` para coordinar la unión de los hilos.

```factor
<crane> :> crane
{ { 5 5 } { 10 } { 3 4 5 } } crane load-cargo
crane crane-tonnage .
! => 32
```
