# Introducción

En JavaScript, la clase `Array` tiene muchos métodos integrados muy potentes para transformar arrays.
Estos métodos hacen que convertir un array en otro sea mucho más fácil de lo que sería con un simple bucle `for` o con una manipulación más directa.

Algunos métodos son [_puros_][pure-function-definition], lo que significa que no modifican el array original.
En su lugar devuelven uno nuevo.
Otros métodos, en cambio, manipulan el array sobre el que se llaman y **no** devuelven el array modificado.

A continuación se presentan algunos de los métodos más usados para transformar arrays.
Puedes encontrar una lista completa de los métodos disponibles en la [documentación de MDN][array-methods].

### map (puro)

Crea un array nuevo transformando cada elemento según una función que se pasa como argumento.
Estas funciones callback suelen escribirse como [funciones flecha][concept-arrow-functions].

```javascript
let arr = [1, 2, 3, 4];

const newArr = arr.map((value) => value - 1);
console.log(newArr);
// => [0, 1, 2, 3]
console.log(arr);
// => [1, 2, 3, 4]
```

Vale la pena notar que el array resultante siempre tendrá la misma longitud que el original.

### filter (puro)

Crea un array filtrando el actual, dada una función de filtrado (que devuelve true si el elemento debe conservarse y false si debe eliminarse).

```javascript
let arr = [1, 2, 3, 4];

arr.filter((value) => value % 2 === 0);
// => [2, 4]
```

### reduce (puro)

Reduce el array a un solo valor usando una función que toma un _acumulador_ y el elemento actual del array como parámetros.
Esta función indica cómo debe integrarse el elemento actual en el acumulador y devuelve el acumulador que se usará en la siguiente iteración.

```javascript
let arr = [1, 2, 3, 4];

// Get the sum of elements
arr.reduce((accumulator, currentValue) => accumulator + currentValue, 0);
// => 10

// Classify the numbers by whether they are odd or not
arr.reduce(
  (accumulator, currentValue) => {
    if (currentValue % 2 === 0) {
      accumulator.even.push(currentValue);
    } else {
      accumulator.odd.push(currentValue);
    }

    return accumulator;
  },
  { even: [], odd: [] },
);
// => { even: [2, 4], odd: [1, 3] }
```

### reverse

Invierte el orden de los elementos de un array.

```javascript
const arr = [1, 2, 3, 4];

arr.reverse();
// => [4, 3, 2, 1]
```

Este método modifica el array sobre el que se llama.

### slice (puro)

Dados un índice de inicio y un índice de fin, crea un subarray a partir del array sobre el que se llama.

El elemento en el índice de fin no se incluye.
Además, todos los parámetros son opcionales:
el índice de inicio toma el valor `0` de forma predeterminada, y el índice de fin toma por defecto la longitud del array.

```javascript
const arr = [1, 2, 3, 4];

arr.slice(1, 2); // [2]
arr.slice(1); // [2, 3, 4]
// You can also use negative numbers, that represent the indexes
// starting from the end of the array
arr.slice(-2); // [3, 4]
```

### splice

Elimina o reemplaza y/o agrega nuevos elementos de un array.

Recibe los siguientes parámetros:

- el índice del elemento donde se empieza a modificar el array
- el número de elementos que se van a eliminar
- los elementos que se van a insertar en el array (opcional)

`splice` devuelve los elementos que se han eliminado.

```javascript
const arr = ['1', '2', '5', '6'];

// Insert an element at index 2
arr.splice(2, 0, '3');
console.log(arr);
// => ['1', '2', '3', '5', '6']

// Remove 2 elements, starting at index 3 and insert 2 elements
const removed = arr.splice(3, 2, '4', '5');
console.log(removed);
// => ['5', '6']
console.log(arr);
// => ['1', '2', '3', '4', '5']

// Remove 1 element at index 1
arr.splice(1, 1);
console.log(arr);
// => ['1', '3', '4', '5']
```

### sort

De forma predeterminada, `sort` ordena los elementos de un array convirtiéndolos primero a strings y después aplicando una comparación de strings (ver [Comparación][concept-comparison]).
La ordenación se realiza _en el propio array_, es decir, se modifica el array original.
`sort` también devuelve ese array modificado, lo cual es útil si quieres encadenarle otros métodos.

```javascript
const arr = ['c', 'a', 'z', 'b'];
const result = arr.sort();
console.log(result);
// => ['a', 'b', 'c', 'z']
console.log(arr);
// => ['a', 'b', 'c', 'z']
```

Para personalizar el comportamiento de la ordenación, puedes pasar una función de comparación como argumento.
A la función de comparación se le pasan dos argumentos, que son dos elementos del array.
Esta debe devolver lo siguiente:

- un número negativo si el primer argumento debe ordenarse antes que el segundo
- un número positivo si el primer argumento debe ordenarse después del segundo
- `0` si el orden de los elementos debe permanecer igual

Por ejemplo, para ordenar números se puede usar la siguiente función de comparación.

```javascript
const arr = [3, 1, 2, 10];
arr.sort((a, b) => a - b);
// => [1, 2, 3, 10]
// "a - b" is negative when b is greater than a, positive when
// a is greater than b and 0 when they are equal.
```
