# Introducción

En JavaScript, las _template strings_ te permiten insertar expresiones dentro de strings, algo que también se conoce como interpolación de strings.
Esta funcionalidad amplía las capacidades del objeto global [`String`][string-reference] que ya viene integrado.

Puedes crear template strings en JavaScript envolviendo el texto entre comillas invertidas.
No solo permiten que el texto incluya saltos de línea y otros caracteres especiales, sino que también puedes insertar variables y otras expresiones.

```javascript
const num1 = 1;
const num2 = 2;

`Adding ${num1} and ${num2} gives ${num1 + num2}.`;
// => Adding 1 and 2 gives 3.
```

En el ejemplo de arriba, las comillas invertidas (<code>\`\`</code>) se usan para representar una template string. El `${...}` es el marcador que se usa para la sustitución.
Cualquier tipo que no sea un string se convierte a string de forma _implícita_.
Este tema se trata en el concepto de [conversión de tipos][type-conversion-concept].
Con las template strings puedes usar todo tipo de expresiones.

```javascript
const track = 'JavaScript';

`This track on exercism.org is ${track.toUpperCase()}.`;
// => This track on exercism.org is JAVASCRIPT.
```

Cuando necesitas que tus strings tengan formato en varias líneas:

```javascript
`This is an example of using template
strings to accomplish multiple
lines`;

/* => This is an example of using template
     strings to accomplish multiple
     lines
*/
```

Si quieres representar un salto de línea dentro de un string normal en lugar de usar una template string (es decir, sin usar comillas invertidas), puedes usar la secuencia de escape `\n`:

```javascript
'This is an example of using the newline escape sequence!\nWithout backticks';

/* => This is an example of using the newline escape sequence!
      Without backticks
*/
```

Con las capacidades de sustitución que tienes disponibles, también puedes introducir lógica en el proceso para determinar cuál debería ser el string de salida.
Una forma de manejar esa lógica es usar el [operador ternario][ternary-operator].
Esto da la misma funcionalidad condicional `if/else` en un formato un poco distinto.

Para implementar lógica en la sintaxis de las template strings:

```javascript
const grade = 95;

`You have ${grade > 90 ? 'passed' : 'failed'} the exam.`;
// => You have passed the exam.
```
