# Creando un Test Runner

Antes que nada, ¡gracias por tu interés en crear un Test Runner!

Estos son los pasos para empezar:

1. Revisa [nuestra lista de repositorios para ver si ya existe un `...-test-runner`](https://github.com/search?q=org%3Aexercism+test-runner&type=repositories) para asegurarte de que todavía no exista uno.
2. Revisa el [contenido de este directorio](/docs/building/tooling/test-runners) para asegurarte de que la idea de crear un Test Runner te resulta cómoda.
3. Inicia un tema nuevo en [el foro de Exercism][building-exercism] y cuéntanos para qué lenguaje te gustaría crear un Test Runner.
4. Cuando ya se haya creado un repositorio de Test Runner para ti, usa los documentos [la interfaz del Test Runner](/docs/building/tooling/test-runners/interface) y [Buenas prácticas](/docs/building/tooling/best-practices) como guía para tu implementación.

¡Tenemos una comunidad increíblemente amable y solidaria que estará encantada de ayudarte mientras avanzas con esto!
Si te quedas atascado, inicia un tema nuevo en [el foro de Exercism][building-exercism] o crea nuevos issues en [exercism/exercism][exercism-repo] según lo necesites 🙂
