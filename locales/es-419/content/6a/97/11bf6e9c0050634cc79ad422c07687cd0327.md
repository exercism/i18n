# Introducción

La recursión es una forma de repetir código en una función haciendo que la función se llame a sí misma.
Es otra forma de hacer un bucle o de iterar. Al igual que con los bucles, la función debe evaluar una expresión Boolean para saber cuándo terminar.
A diferencia de los bucles, una recursión que nunca termina no se ejecutará infinitamente.
Los valores usados en cada llamada a función pueden colocarse en su propio marco en la pila.
Si la cantidad de llamadas a función ocupa más espacio del que tiene la pila, se producirá un error de desbordamiento de pila.

```c
int printIncrement (int i, int maxValue){
    if (i > maxValue) return i;
    printf("The number is %i\n", i++);
    printIncrement(i, maxValue);
}

int main() {
    printIncrement(1, 2);
    printf("After recursion");
    return 0;
}
```

Esto imprimirá

```
The number is 1
The number is 2
After recursion
```

Puede haber algunas situaciones que son más legibles o más fáciles de razonar cuando se expresan mediante recursión que cuando se expresan mediante bucles.
