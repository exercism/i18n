# NuVoc

El [NuVoc][nuvoc-link] es la referencia definitiva de J.
Es un resumen muy conciso y denso en información de las primitivas y el lenguaje de J.

# Rosetta Code

Muchas tareas de Rosetta Code tienen soluciones en `J`.
Es un buen recurso para encontrar programas en J que puedas estudiar.
[Aquí](https://rosettacode.org/wiki/Sudoku#J) hay un solucionador de sudoku de Roger Hui.
