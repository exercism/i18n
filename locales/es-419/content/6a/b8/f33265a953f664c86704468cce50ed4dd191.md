# Usa `Keyword.get_values`

Las listas de palabras clave pueden contener más de un valor para una misma clave, lo que hace que obtener todos los valores de una clave sea engorroso.
El módulo `Keyword`, además de `Keyword.get` para obtener un solo valor, también ofrece `Keyword.get_values` para obtener varios valores.
Usa `Keyword.get_values` para filtrar los vinos por color.
