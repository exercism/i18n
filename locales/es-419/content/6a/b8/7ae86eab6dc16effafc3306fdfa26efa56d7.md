# Pistas

## General

- En Swift hay tres tipos principales de condicionales: las sentencias `if`, las sentencias `switch` y las sentencias `guard`.

## 1. Calcula si puedes pagar o no los pagos mensuales de un auto determinado

- Asegúrate de dividir el precio total del auto entre el número de meses para calcular el pago mensual.
- Puedes usar `+` para concatenar dos strings.

## 2. Determina el tipo de licencia de conducir que necesitarás

- Las sentencias switch son buenas para manejar una gran cantidad de casos de forma limpia.
- Puedes manejar varios casos con un solo caso de switch si el comportamiento debe ser el mismo para todos.
- El caso `default` maneja todos los casos que no se listan explícitamente.

## 3. Calcula las tarifas de registro de tu vehículo nuevo

- La sentencia `guard` se usa en situaciones en las que conviene salir antes porque no se necesita (o no es posible) seguir procesando.
- Solo necesitas hacer el cálculo con la fórmula si el vehículo tiene menos de 10 años.
