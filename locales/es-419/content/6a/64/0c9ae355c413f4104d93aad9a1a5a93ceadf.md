# Instrucciones

En este ejercicio vas a trabajar un poco más con los autos de control remoto.

Se ha desarrollado un auto experimental y la pista de pruebas necesita adaptarse para aceptar tanto los modelos de producción como los experimentales. Los dos tipos de auto ya están construidos y necesitas encontrar la manera de que ambos funcionen en la pista de pruebas.

Además, los autos de producción están empezando a tener algo de éxito. Al jefe del equipo le interesa mantener el espíritu competitivo publicando una clasificación de los autos de producción.

## 1. Haz que los autos se puedan conducir en la misma pista de pruebas

Agrega un método a la interfaz `IRemoteControlCar` para exponer las implementaciones de `Drive()` para los dos tipos de auto.

```csharp
TestTrack.Race(new ProductionRemoteControlCar());
TestTrack.Race(new ExperimentalRemoteControlCar());
// this should execute without an exception being thrown
```

## 2. Permite comparar la distancia recorrida por los distintos modelos en la pista de pruebas

Agrega una propiedad a la interfaz `IRemoteControlCar` para exponer las implementaciones de la propiedad `DistanceTravelled` para los dos tipos de auto.

```csharp
var prod = new ProductionRemoteControlCar();
TestTrack.Race(prod);
var exp = new ExperimentalRemoteControlCar();
TestTrack.Race(exp);
prod.DistanceTravelled
// => 10
exp.DistanceTravelled
// => 20
```

## 3. Permite clasificar los autos de producción

Implementa la interfaz `IComparable<T>` en la clase `ProductionRemoteControlCar`. El orden de clasificación predeterminado de los autos debe ser el orden ascendente de victorias.

Implementa el método estático `TestTrack.GetRankedCars()` para que devuelva los autos que recibe ordenados de forma ascendente por número de victorias.

```csharp
var prc1 = new ProductionRemoteControlCar();
var prc2 = new ProductionRemoteControlCar();
prc1.NumberOfVictories = 3;
prc2.NumberOfVictories = 2;
var rankings = TestTrack.GetRankedCars(prc1, prc2);
// => rankings[1] == prc1
```
