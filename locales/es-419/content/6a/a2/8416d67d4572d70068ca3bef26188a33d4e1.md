# Anexo a las instrucciones

## Implementación

En el paquete twobucket, implementa una func de Go, Solve, con la siguiente firma:

```go
func Solve(sizeBucketOne,
	sizeBucketTwo, goalAmount int, startBucket string,
) (goalBucket string, numSteps, otherBucketLevel int, e error)
```

Solve devuelve cuatro valores: el balde objetivo resultante ("one" o "two"), el número de movimientos/pasos para alcanzar la cantidad objetivo, los litros que quedan en el otro balde y un valor de error.
Devuelve un error si algún parámetro no es válido o si no es posible encontrar una solución.
