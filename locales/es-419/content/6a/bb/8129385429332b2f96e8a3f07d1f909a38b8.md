# Apéndice de instrucciones

## Instrucciones específicas del track

Phix no tiene punteros, e implementar algo como una lista enlazada, que de por sí ya es un poco complicado, por ejemplo emulando punteros con índices, no solo sería todavía más complicado, sino también completamente inútil, dado que una secuencia estándar, que es nada menos que la columna vertebral del lenguaje, maneja este tipo de cosas de una forma mucho más fácil y casi trivial.
Por eso este ejercicio es muy sencillo: busca emular el comportamiento de una lista doblemente enlazada (/de doble extremo) usando una sola secuencia (plana), sin punteros ni nada parecido.
Aunque se podrían manejar varias listas usando múltiples valores devueltos, o se podría usar el include stack/queue que se proporciona (ambos pueden recibir la instrucción de realizar una operación en su «otro» extremo), para simplificar aún más las cosas solo usaremos la única variable estática «list».
