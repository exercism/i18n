# Introducción

## Expresiones regulares

Las expresiones regulares en Elixir siguen la especificación **PCRE** (**P**erl **C**ompatible **R**egular **E**xpressions), de forma similar a otros lenguajes populares como Java, JavaScript o Ruby.

El módulo `Regex` ofrece funciones para trabajar con expresiones regulares. Algunas funciones del módulo `String` también aceptan expresiones regulares como argumentos.

~~~~exercism/note
Este ejercicio asume que ya conoces la sintaxis de las expresiones regulares, incluidas las clases de caracteres, los cuantificadores, los grupos y las capturas.

Si necesitas refrescar tus conocimientos sobre expresiones regulares, echa un vistazo a alguna de estas fuentes: [Regular-Expressions.info](https://www.regular-expressions.info), [Rex Egg](https://www.rexegg.com/), [RegexOne](https://regexone.com/), [Regular Expressions 101](https://regex101.com/), [RegExr](https://regexr.com/).

### Sigilos

La forma más común de crear expresiones regulares es usando el sigilo `~r`.

```elixir
~r/test/
```

Ten en cuenta que todos los sigilos de Elixir admiten [diferentes tipos de delimitadores][sigils], no solo `/`.

### Coincidencias

El operador `=~/2` se puede usar para realizar una coincidencia con una expresión regular que devuelve un resultado `boolean`. Como alternativa, también hay funciones `match?/2` en el módulo `Regex` y en el módulo `String`.

```elixir
"this is a test" =~ ~r/test/
# => true

String.match?("Alice has 7 apples", ~r/\d{2}/)
# => false
```

### Capturas

Si una simple comprobación booleana no es suficiente, usa la función `Regex.run/3` para obtener una lista de todas las capturas (o `nil` si no hubo coincidencia). El primer elemento de la lista devuelta siempre es una coincidencia de toda la expresión regular, y los elementos siguientes son los grupos coincidentes.

```elixir
Regex.run(~r/(\d) apples/, "Alice has 7 apples")
# => ["7 apples", "7"]
```

### Modificadores

El comportamiento de una expresión regular se puede modificar agregando banderas especiales. Cuando usas un sigilo para crear una expresión regular, agrega los modificadores después del segundo delimitador.

Los modificadores más comunes son:
- `i` - hace que la coincidencia no distinga entre mayúsculas y minúsculas.
- `u` - habilita patrones específicos de Unicode como `\p` y hace que las clases de caracteres como `\w`, `\s`, etc. también coincidan con Unicode.

```elixir
"this is a TEST" =~ ~r/test/i
# => true
```
