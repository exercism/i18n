# Apéndice de instrucciones

## Formato de entrada/salida

La función recibe un solo string de palabras, cada una con un salto de línea al final.

La primera es la palabra de la que se supone que las demás son anagramas.

Devuelve un string con todos los anagramas válidos, cada uno con un salto de línea al final.


## Direcciones reservadas

El búfer para el string de entrada usa los bytes 64-319 de la memoria lineal.

Puedes modificar este búfer in situ si quieres evitar asignaciones de memoria adicionales.
