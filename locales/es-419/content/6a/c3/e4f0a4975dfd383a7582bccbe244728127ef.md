# Instrucciones

Llamar a las API puede ser propenso a errores cuando se usa texto plano o JSON. En este ejercicio, usarás Records de Ballerina para organizar las cargas útiles de las solicitudes y asegurar una comunicación exitosa con los endpoints externos de reservas.

## Objetivos

- Modifica el código proporcionado.
- Reserva un boleto de avión para el usuario llamando al servicio de reservas de aerolíneas. Envía una solicitud POST a airlineReservationService con la carga útil adecuada y obtén una respuesta.
- Reserva una habitación de hotel para el usuario llamando al servicio de reservas de hoteles. Envía una solicitud POST a hotelReservationService con la carga útil adecuada y obtén una respuesta.
- Renta un auto para el usuario llamando al servicio de alquiler de autos. Envía una solicitud POST a carRentalService con la carga útil adecuada y verifica la respuesta.
- Si todo sale bien, devuelve un cuerpo con un atributo message de «Congratulations! Your journey is ready!!».
