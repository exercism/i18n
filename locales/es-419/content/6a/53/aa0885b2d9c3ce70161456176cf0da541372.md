## General

- Strings: específicamente, el `str` siempre es un factor aquí
- Unicode: concesiones de rendimiento/funcionalidad entre los métodos ASCII y los de unicode. Las mediciones se sesgan cuando el benchmark usa métodos de unicode y la solución usa métodos ASCII.
- Iteradores: iterar sobre la entrada o sobre fragmentos de ella.
- Colecciones: iterar sobre un `HashMap` y usar `Entry`. Comúnmente, los handles se recopilan en un `Vec`.
- Referencias
- Números: el trait `Add` específicamente
- Bucle `for`: no se pueden unir hilos en un Iterator debido a move.
- **Opt** Visibilidad: mantener los detalles de implementación no públicos
- **Opt** slices: `.chunks()` es un método muy usado para dividir la entrada entre hilos de trabajo. Alternativamente, se usan subslices.
- **Opt** Funciones de orden superior: los HashMaps se pueden fusionar con una función de orden superior junto con un Iterator.
- **Opt** Tipos: para dividir la entrada podemos convertir enteros a valores de punto flotante para aplicar redondeo
- **Opt** Crates

## Enfoque con std, con o sin canales

- Paralelismo: subtema de creación y unión de hilos.
- Iteradores: subtema de evaluación perezosa: crear y unir hilos con el mismo Iterator impide el paralelismo.
- Lifetimes: subtemas `'static lifetime` y semántica explícita de `move`
- Iteradores/lifetimes: subtema de iteradores consumidores: no se pueden unir hilos usando un Iterator.
- Tipo Option: desempaquetar los resultados de hilos o canales
- Funciones: específicamente, se requieren funciones de orden superior para crear hilos. Los closures son una opción aquí.

## Enfoque con std y canales

- Paralelismo: subtema de canales.
- Tuplas: `mpsc::channel()` devuelve una tupla
- Desestructuración: la tupla se puede desestructurar en la asignación
- Lifetimes: `drop()`

## Enfoque alternativo con variables compartidas

- Conteo de referencias: compartir datos agregados entre hilos con una colección con conteo de referencias.
- **Mención honorífica**: Paralelismo: subtema de los Mutex. No es necesario ni útil para este ejercicio, pero de todos modos es un concepto común. Relacionado: `RwLock`.

### Ejemplo con std y canales

```rust
use std::collections::HashMap;
use std::thread;
use std::sync::mpsc;

pub fn frequency(input: &[&str], worker_count: usize) -> HashMap<char, usize> {
    let (tx, rx) = mpsc::channel();

    let _handles = input.chunks((input.len() as f64 / worker_count as f64).ceil() as usize)
        .map(|slice| slice.concat())
        .map(|slice| {
            let tx = tx.clone();
            thread::spawn(move || {
                let mut map: HashMap<char, usize> = HashMap::new();
                for chr in slice.chars().filter(|c| c.is_alphabetic()) {
                    if let Some(c) = chr.to_lowercase().next() {
                        (*map.entry(c).or_insert(0)) += 1;
                    };
                }
                tx.send(map).unwrap()
            })
        }).collect::<Vec<_>>();

    drop(tx);

    let mut result: HashMap<char, usize> = HashMap::new();
    for received in rx {
        for (c, count) in received {
            *result.entry(c).or_insert(0) += count;
        }
    }

    result
}
```

### Ejemplo con un crate y Arc

```rust
use std::collections::HashMap;
use std::iter::FromIterator;
use std::sync::Arc;
use dashmap::DashMap;

pub fn frequency(input: &[&str], worker_count: usize) -> HashMap<char, usize> {
    let map: Arc<DashMap<char, usize>> = Arc::new(DashMap::new());

    let handles = input
        .chunks((input.len() as f64 / worker_count as f64).ceil() as usize)
        .map(|slice| slice.concat())
        .map(|slice| {
            let map = map.clone();
            std::thread::spawn(move || {
                for c in slice.chars().filter(|c|c.is_alphabetic())
                  .flat_map(|c| c.to_lowercase().next()) {
                    *map.entry(c).or_insert(0) += 1;
                }
            })
        }).collect::<Vec<_>>();

    for h in handles {
        h.join().unwrap();
    }

    map.iter().map(|x| (*x.key(), *x.value())).collect()
}
```
