# Bucles

Los bucles en Rust se pueden usar para ejecutar repetidamente un bloque de código hasta que le digas que se detenga o hasta que se cumpla cierta condición.

La versión más básica de un bucle usa la palabra clave `loop`:

```rust
fn main() {
    loop {
        println!("again!");
    }
}
```

El fragmento de código anterior crea un bucle infinito. Para salir de un bucle, usa la palabra clave break:

```rust
fn main() {
    let mut count = 0;
    loop {
        println!("again!");
        count += 1;
        if count > 10 { break; }
    }
}
```

## Bucles con `for` y `while`

Además de la palabra clave `loop`, también puedes crear bucles con `for` y `while`.

Un bucle `for` se usa para iterar sobre los elementos de una colección o un iterador.

```rust
fn main() {
    let a = [10, 20, 30, 40, 50];

    for x in a {
        println!("the value is: {x}");
    }
}
```

Los rangos también son iteradores, lo que hace muy cómodo recorrerlos con el bucle `for`:

```rust
fn main() {
    for x in 0..10 {
        println!("the value is: {x}");
    }
}
```

Un bucle while repite código hasta que se cumpla una condición. Podríamos reescribir el ejemplo anterior usando un bucle while de la siguiente manera:

```rust
fn main() {
    let a = [10, 20, 30, 40, 50];
    let mut index = 0;

    while index < 5 {
        println!("the value is: {}", a[index]);

        index += 1;
    }
}
```

Consulta [https://doc.rust-lang.org/book/ch03-05-control-flow.html#repetition-with-loops](repetition with loops) en el libro de Rust para obtener más información sobre los bucles.
