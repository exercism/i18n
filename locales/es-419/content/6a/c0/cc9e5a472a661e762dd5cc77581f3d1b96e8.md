# Pistas

## General

- Lee sobre los strings en la [guía de introducción][getting-started-strings] oficial.
- Explora las [funciones disponibles en el _módulo String_][string-module-functions] para descubrir qué operaciones con strings ofrece la biblioteca estándar de Elixir.

## 1. Obtén la primera letra del nombre

- Hay una [función integrada][string-first] para obtener el primer carácter de un string.
- Hay varias [funciones integradas][string-trim] para eliminar los espacios en blanco al inicio, al final, o tanto al inicio como al final de un string.

## 2. Formatea la primera letra como inicial

- Hay una [función integrada][string-upcase] para convertir todos los caracteres de un string a su variante en mayúsculas.
- Hay un [operador][kernel-concat] que concatena dos strings.

## 3. Divide el nombre completo en el nombre y el apellido

- Hay una [función integrada][string-split] que divide un string en los caracteres de espacio en blanco.
- Puedes asignar unos cuantos de los primeros elementos de un array a variables mediante pattern matching sobre el array.

## 4. Pon las iniciales dentro del corazón

- Hay una sintaxis especial para [interpolar][string-interpolation] una expresión dentro de un string.
- Hay una sintaxis especial para escribir [strings multilínea][heredoc-syntax] sin necesidad de escapar los saltos de línea.
