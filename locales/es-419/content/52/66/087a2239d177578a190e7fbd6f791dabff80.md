# Instrucciones

Haces trabajo voluntario en el centro de artes comunitario, donde están levantando un largo mosaico de azulejos cerámicos sobre la entrada principal. El equipo de diseño organizó el trabajo **fila por fila**: cada fila es un array de colores de azulejos, y el mosaico completo es un array de filas.

Mientras los voluntarios cortan, colocan y reacomodan azulejos, tú escribes pequeñas palabras reutilizables para construir, combinar y consultar partes del diseño.

## 1. Una tira de un solo azulejo

Define `tile-strip` para que tome un color y devuelva una fila de 1 elemento que contenga solo ese color.

```factor
"sky-blue" tile-strip .
! => { "sky-blue" }
```

## 2. Una fila de tres azulejos

Define `row-of-three` para que tome tres colores de la pila y devuelva una fila de 3 elementos.

```factor
"red" "white" "blue" row-of-three .
! => { "red" "white" "blue" }
```

## 3. Combina las filas en una lista plana de azulejos

El equipo de diseño necesita comprobar rápidamente los totales de colores en todas las filas del mosaico. Define `combine-rows` para que tome un array de filas y devuelva una sola secuencia con todos los azulejos en orden.

```factor
{ { "red" "white" } { "blue" "red" } } combine-rows .
! => { "red" "white" "blue" "red" }
```

## 4. Refleja una fila

Para los paneles simétricos, el equipo refleja una fila antes de colocar la copia en el lado opuesto. Define `mirror-row` para que devuelva una fila en orden inverso.

```factor
{ "red" "white" "blue" } mirror-row .
! => { "blue" "white" "red" }
```

## 5. ¿Dónde está este color en la fila?

Define `tile-position` para que tome una fila y un color y devuelva el índice (con base 0) del primer azulejo con ese color en la fila. Si el color no está presente, devuelve `f`.

```factor
{ "red" "white" "blue" } "white" tile-position .
! => 1

{ "red" "white" "blue" } "green" tile-position .
! => f
```

## 6. ¿Esta fila contiene el color?

Define `has-colour?` para que tome una fila y un color y devuelva `t` si el color aparece en cualquier parte de la fila, y `f` en caso contrario.

```factor
{ "red" "white" "blue" } "white" has-colour? .
! => t

{ "red" "white" "blue" } "green" has-colour? .
! => f
```
