# Acerca de

El tipo `Option` es el mecanismo del lenguaje F# para trabajar con valores que pueden existir o no.
Ofrece una alternativa segura en cuanto a tipos al uso de `null`, que es común en otros lenguajes para manejar este tipo de valores.
Se usa en muchas funciones de la biblioteca estándar de F#, así que entenderlo es esencial para usar la biblioteca estándar de F# de manera efectiva.

## Beneficios de usar el tipo `Option`

* __Seguridad en tiempo de compilación__: al hacer explícita la presencia o ausencia de un valor en el sistema de tipos, el compilador puede asegurarse de que manejes el caso de «sin valor», lo que previene una gran categoría de errores que podrían ocurrir con los valores nulos.

* __Seguridad en tiempo de ejecución__: en lugar de usar `null`, F# usa `None` para representar la ausencia de un valor, lo que hace imposible que ocurra una `NullReferenceException`.

* __Obliga a un manejo explícito__: el sistema de tipos exige que el código maneje explícitamente tanto el caso `Some value` como el caso `None`, lo que hace que tu código sea más robusto y predecible.

* __Funciona con la coincidencia de patrones__: los `Option` funcionan a la perfección con el idioma de coincidencia de patrones de F#, y ofrecen una manera limpia y segura de deconstruir y manejar el valor si existe, o de realizar una acción distinta si no existe.

## Uso

El tipo `Option` es un tipo genérico (tiene un tipo subyacente).  
Los valores `Option` son `Some value`, que representa un valor específico, o `None`, que representa la ausencia de valor.

La siguiente función muestra cómo crear un valor `Option`:

```fsharp
let keepIfPositive (a: int) : int option = if a > 0 then Some a else None
```

~~~~exercism/note
`T option` es la sintaxis posfija equivalente a `Option<T>`; las dos formas sintácticas se pueden usar de manera intercambiable.
Sin embargo, según la Guía de estilo de F#, se prefiere la notación posfija para los tipos Option (consulta la [sección de la Guía de estilo de F# sobre el formato de tipos y anotaciones de tipo](https://learn.microsoft.com/en-us/dotnet/fsharp/style-guide/formatting#for-types-prefer-prefix-syntax-for-generics-foot-with-some-specific-exceptions)). 
~~~~

Un caso de uso típico de un `Option` son las funciones de búsqueda. 
Por ejemplo, la función `List.tryFind` devuelve `Some index` cuando el elemento está en la lista (donde `index` es la posición del valor buscado en la lista), o `None` cuando el elemento no está en la lista.

## Leer el contenido de un valor Option

La manera idiomática de leer un valor `Option` es mediante la coincidencia de patrones, como se muestra en el siguiente ejemplo:

```fsharp
// Returns "Hello, <name>!" if the name is provided; otherwise returns "Hello, you!"
let sayHello (optionalName: string option): string = 
    match optionalName with
    | Some name -> "Hello, " + name + "!"
    | None -> "Hello, you!"

sayHello (Some "Matthieu")
// --> "Hello, Matthieu!"

sayHello None
// --> "Hello, you!"
```

## Extraer el valor de un Option con valores predeterminados

Los `Option` se pueden «desenvolver» (convertir a su tipo contenido) proporcionando valores predeterminados con la función `Option.defaultValue`. 
Esto es especialmente útil cuando quieres asegurarte de que el valor no sea `None`.
Por ejemplo:

```fsharp
Option.defaultValue "" (Some "F#")
// --> "F#"

Option.defaultValue 0 None
// --> 0
```

## Más funciones en el módulo `Option`

El módulo `Option` también incluye funciones que se corresponden con las que están disponibles para listas, arrays, secuencias y otros tipos de colecciones, como `Option.map`, `Option.iter`, `Option.forall` y `Option.count`. 
Estas funciones permiten tratar a los `Option` como una colección de cero o un elemento.
