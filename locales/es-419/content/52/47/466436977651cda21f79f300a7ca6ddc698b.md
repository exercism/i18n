## Cómo usarlo

### Compilar

`npx blueprint build` o `yarn blueprint build`

### Ejecutar los tests

`npx blueprint test` o `yarn blueprint test`

### Desplegar o ejecutar otro script

`npx blueprint run` o `yarn blueprint run`

### Agregar un nuevo contrato

`npx blueprint create ContractName` o `yarn blueprint create ContractName`
