# Condicionales

Ruby tiene lo que se conoce como expresiones de control de flujo; estas se usan para controlar la forma en que se ejecutará el programa y reciben un valor verdadero o falso.
Hay operadores que se pueden usar para crear valores verdaderos o falsos; estos se conocen como [operadores de comparación][comparison-operators].

Hay dos expresiones de control principales que se usan para controlar qué código se ejecutará y qué código no.
En otras palabras, cuál de las ramas se ejecutará.

Esas dos son: `if` y la expresión `unless`.

## Operadores de comparación

Los [operadores de comparación][comparison-operators] se usan para comparar valores y devolver un valor `true` o `false`.
Los siguientes operadores requieren dos valores del mismo tipo para compararlos.
Si los valores no son del mismo tipo, el compilador lanzará un error.
Aquí tienes una lista de los operadores y un ejemplo de cuándo dan un valor `true`:

| Método | Descripción           | Ejemplo |
| ------ | --------------------- | ------- |
| <      | menor que             | 4 < 5   |
| <=     | menor o igual que     | 4 <= 4  |
| >      | mayor que             | 3 > 1   |
| >=     | mayor o igual que     | 2 >= 2  |

Los operadores de igualdad y desigualdad se pueden usar para comparar cualquier tipo de valor, a diferencia de los operadores ya mencionados.
El operador `==` se usa para comprobar si dos valores son iguales, y eso incluye comprobar el tipo del valor.
El `!=` funciona de la misma manera, pero devolverá `true` si los valores no son iguales y `false` si son iguales.
Aquí tienes una lista de los operadores de igualdad y desigualdad, y un ejemplo de cuándo dan un valor `true`:

| Método | Descripción  | Ejemplo |
| ------ | ------------ | ------- |
| ==     | igual a      | 4 == 4  |
| !=     | distinto de  | 5 != 4  |

## El condicional `if`

El condicional [`if`][if] se usa para comprobar si una condición dada es «verdadera» o «falsa».
Si la condición es verdadera, entonces se ejecutará el código dentro del condicional `if`.
Un condicional `if` termina con la palabra clave `end`.

```ruby
value = 1
if value == 1
  "1 is equal to 1"
end
# => "1 is equal to 1"

if value > 2
  "1 is greater than 2"
end
# => nil
```

## La sentencia `unless`

La sentencia `unless` funciona de manera muy similar al condicional `if`, pero ejecutará el código dentro de la sentencia `unless` si la condición es falsa.

```ruby
value = 1
unless value == 1
  "1 is not equal to 1"
end
# => nil

unless value > 2
  "1 is not greater than 2"
end
# => "1 is not greater than 2"
```

## La sentencia `else`

La sentencia `else` se puede usar junto con el condicional `if`.
La sentencia `else` se ejecutará si no se ejecuta la rama `if`.

```ruby
value = 1
if value == 1
  "1 is equal to 1"
else
  "1 is not equal to 1"
end
# => "1 is equal to 1"

if value > 2
  "1 is greater than 2"
else
  "1 is not greater than 2"
end
# => "1 is not greater than 2"
```

## Sentencias condicionales en cascada

La sentencia `elsif` se puede usar junto con el condicional `if`.
La sentencia `elsif` se ejecutará si no se ejecuta la rama `if` y la condición de la sentencia `elsif` es verdadera.
Las sentencias `elsif` se pueden encadenar y se ejecutará la primera condición verdadera.
También puede haber una sentencia `else` al final del condicional `if`, que se ejecutará si ninguna de las sentencias anteriores fue verdadera.

```ruby
value = 1
if value == 0
  "1 is equal to 0"
elsif value > 2
  "1 is greater than 2"
else
  "1 is not equal to 0 and 1 is not greater than 2"
end
# => "1 is not equal to 0 and 1 is not greater than 2"
```
