# Anexo de instrucciones

# Argumentos

Los argumentos de este ejercicio son:

- `target`: Un string (p. ej., `'stone'`) será el _argumento izquierdo_.
- `candidates`: Un array de strings en cajas (p. ej., `'stone' ; 'tones' ; 'banana' ; 'tons' ; 'notes' ; 'Seton'`) será el _argumento derecho_.

Tu verbo se llamará así:

```j
  target     =. 'stone'
  candidates =. 'stone' ; 'tones' ; 'banana' ; 'tons' ; 'notes' ; 'Seton'
  
  subject findAnagrams candidates
```

## Salida

Tu verbo debe devolver un _array_ de cajas que contengan los strings que son anagramas del target. Si no hay anagramas, el resultado debe ser `empty`.
