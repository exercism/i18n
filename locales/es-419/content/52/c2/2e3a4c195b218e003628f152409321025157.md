# Acerca de

C# es un lenguaje de programación multiparadigma y de tipado estático, con características orientadas a objetos, declarativas, funcionales, genéricas, perezosas y de consulta integrada, además de inferencia de tipos.

**De tipado estático** significa que los identificadores tienen un [tipo](https://en.wikipedia.org/wiki/Type_system#Static_type_checking) definido en tiempo de compilación, como los de Java, C++ o Haskell, en lugar de contener datos de cualquier tipo como los de Python, Ruby o JavaScript.

**Orientado a objetos** significa que C# ofrece [objetos basados en clases](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/object-oriented-programming) imperativos, con características como la herencia simple, las interfaces y la encapsulación.

**Declarativo** significa programar [qué se debe hacer](https://stackoverflow.com/questions/1784664/what-is-the-difference-between-declarative-and-imperative-programming), en lugar de cómo se hace (también conocido como programación imperativa), que es un detalle de implementación que puede distraer del dominio o de la lógica de negocio.

**Funcional** significa que [las funciones son tipos de datos de primera clase](https://livebook.manning.com/#!/book/functional-programming-in-c-sharp/chapter-1) que se pueden pasar como argumentos a otras funciones y devolver desde ellas.

**Genérico** significa que los algoritmos se escriben en términos de tipos [que se especifican después](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/generics/generic-type-parameters) y que luego se instancian, cuando se necesitan, para los tipos concretos que se pasan como parámetros.

**Perezoso** [(también conocido como «ejecución diferida»)](https://blogs.msdn.microsoft.com/pedram/2007/06/02/lazy-evaluation-in-c/) significa que el compilador pospone la evaluación de un elemento hasta que se necesita. Esto te permite hacer con seguridad cosas raras, como operar sobre una lista infinita: el lenguaje solo crea la lista hasta el último valor necesario.

**Consulta integrada** significa la característica del lenguaje llamada [LINQ, «Language-Integrated Query»](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/linq/), que permite hacer consultas perezosas directamente dentro del lenguaje, no solo sobre sus propios objetos, sino también sobre fuentes de datos externas a través de formatos como XML, JSON, SQL, bases de datos NoSQL y flujos de eventos.

**Inferencia de tipos** significa que el compilador suele deducir por sí solo el tipo de un identificador, de modo que tú no tienes que especificarlo. Scala y F# también lo hacen.

**La sintaxis** es similar a la de otros lenguajes de estilo C, como C, C++ y Java.

**.NET** es el entorno administrado en el que se ejecuta C#, así que tienes acceso a todo el ecosistema de .NET, incluidos todos los paquetes de [nuget.org](http://www.nuget.org). Antes .NET era exclusivo de Windows, pero con el lanzamiento de [.NET Core](https://www.microsoft.com/net/core), además de [Mono](http://www.mono-project.com/), también puedes usar C# en Mac, Linux o sistemas basados en Unix, y también en plataformas móviles.

C# también tiene características, entre otras, que facilitan la programación con múltiples hilos o procesadores, la paralelización, la asincronía, el código no administrado en un entorno administrado y la interoperabilidad entre lenguajes. Microsoft lo desarrolla y lo mantiene, y ofrece la [documentación](https://docs.microsoft.com/en-us/dotnet/csharp/) oficial.
