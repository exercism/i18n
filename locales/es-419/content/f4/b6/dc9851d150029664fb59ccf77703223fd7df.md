# Formato de kernel

Además del método `format`, una forma muy común de crear strings en Ruby es usar [la interpolación de strings](http://ruby-for-beginners.rubymonstas.org/bonus/string_interpolation.html). Por ejemplo:

```ruby
# Rather than:
format("One for %%s, one for me.", %{name_variable})

# Consider:
"One for #{%{name_variable}}, one for me."
```
