# Introducción

Una tupla es un contenedor ordenado de valores. Como todos los tipos de datos de Gleam, las tuplas son inmutables. Cada elemento de una tupla puede ser de un tipo distinto, incluso pueden ser otras tuplas.

Las tuplas se definen como valores separados por comas entre `#(` y `)`: `#(1, 2.0, "Three")`.

```gleam
#("one", 2)      // Tuple pair (2 values)
#("one", 2, 3.0) // Tuple triplet (3 values)
```

Las tuplas con la misma longitud y los mismos tipos (en el mismo orden) se pueden comparar para verificar su igualdad.

```gleam
#(1, 2) == #(1, 2) // Same length, same types, same values, same order
// -> True

#(1, 2) == #(2, 1) // Same length, same types, same values, different order
// -> False

#(1, 2) == #(1, "2") // Same length, different types
// Compile error!

#(1, 2) == #(1, 2, 3) // Different length
// Compile error!
```

Hay tres formas de obtener los valores contenidos en una tupla:

- Indexación.
- Coincidencia de patrones con `let`.
- Coincidencia de patrones con `case`.

```gleam
let person = #("Jordan", 170)

// Option 1: Indexing
person.0 // -> "Jordan"
person.1 // -> 170

// Option 2: let
let #(name2, length2) = person
// -> name2 = "Jordan"
// -> length2 = 52

// Option 3: case
case person {
  #(name3, length3) -> {
    name3   // -> "Jordan"
    length3 // -> 170
  }
}
```
