# Instrucciones

Nadie se sube al trapecio en el circo hasta que pasen los controles de seguridad.
Estás anotando los controles para que las mismas reglas se apliquen a todos.

Las cinco tareas van en la clase `SAFETY_CHECK`.

## 1. ¿Está lista la colchoneta?

La colchoneta está lista solo cuando está colocada y limpia.

```sather
SAFETY_CHECK::mat_ready(true, false)
-- => false
```

## 2. ¿Hay algo donde caer?

Tiene que haber una colchoneta debajo, o una red debajo. Cualquiera de las dos sirve, y tener las dos también está bien.

```sather
SAFETY_CHECK::something_below(false, true)
-- => true
```

## 3. ¿Quién todavía necesita la instrucción?

Todo el que no haya recibido la instrucción, la necesita.

```sather
SAFETY_CHECK::needs_briefing(false)
-- => true
```

## 4. ¿Este artista tiene la edad suficiente?

El trapecio es para artistas de 13 años en adelante.

```sather
SAFETY_CHECK::old_enough(13)
-- => true
```

## 5. Ponlo todo junto

Un artista está autorizado a subir al trapecio cuando tiene la edad suficiente, ha recibido la instrucción y la colchoneta está lista.

```sather
SAFETY_CHECK::cleared(14, true, true, true)
-- => true
```

Los cuatro argumentos son la edad, si ha recibido la instrucción, si la colchoneta está colocada y si la colchoneta está limpia.
