# Introducción

Una *tupla* es el tipo de registro/estructura/clase de Factor. Cada clase de tupla tiene un conjunto fijo de ranuras con nombre, y Factor genera automáticamente getters y setters para ellas.

```factor
TUPLE: point
    { x initial: 0 }
    { y initial: 0 } ;

T{ point { x 3 } { y 4 } } x>> .   ! => 3
3 4 point boa .                    ! => T{ point { x 3 } { y 4 } }
point new .                        ! => T{ point }
```

`boa` («por orden de argumentos») llena las ranuras desde la pila, en orden de declaración. `new` construye una instancia con cada ranura en su valor `initial:` declarado (o `f` si no tiene).

El getter de cada ranura es `slot>>` y el setter es `>>slot`; el setter *muta*, así que usa `clone` primero si necesitas una actualización no destructiva:

```factor
T{ point { x 3 } { y 4 } } clone 10 >>x .
! => T{ point { x 10 } { y 4 } }
```

Los valores predeterminados de las ranuras usan `{ name initial: value }`; sin `initial:`, el valor predeterminado es `f`.
