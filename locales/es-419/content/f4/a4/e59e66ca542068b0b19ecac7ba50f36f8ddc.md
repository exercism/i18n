# Desestructuración

La desestructuración es el proceso de descomponer elementos en sus partes componentes, vinculando cada una a variables más pequeñas.

## Desestructuración de tuplas

Desestructurar tuplas es simple: solo asigna nuevos nombres de variables a cada campo de la tupla:

```rust
let (first, second) = (1, 2);
```

## Desestructuración de estructuras de tupla

Desestructurar estructuras de tupla es idéntico a desestructurar tuplas, pero con el nombre de la estructura agregado:

```rust
struct TupleStruct(&'static str, i32);
let my_tuple_struct = TupleStruct("foo", 123);
let TupleStruct(foo, num) = my_tuple_struct;
```

## Desestructuración de estructuras

Desestructurar estructuras es similar a desestructurar estructuras de tupla. Solo usa los nombres de los campos:

```rust
struct ArabianNights {
    name: String,
    stories: usize,
}
let teller = ArabianNights { name: "Scheherazade".into(), stories: 1001 };
{
    let ArabianNights { name, stories } = teller;
    println!("{name} told {stories} stories");
}
```

## Desestructuración parcial

El operador `..` se puede usar para ignorar algunos campos al desestructurar:

```rust
let ArabianNights { name, .. } = teller;
println!("{name} survived by her wits");
```

## Desestructuración condicional

Desestructurar estructuras y tuplas es infalible. Sin embargo, las enumeraciones también se pueden desestructurar, usando las construcciones del lenguaje `if let`, `while let` y `match`.

```rust
if let Some(foo) = foo {
    println!("{foo:?}");
}
```
