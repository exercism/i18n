# Aprender Visual Basic

## Sitios web

Visual Basic ha evolucionado considerablemente con los años, y muchos tutoriales de terceros hacen referencia a herramientas o funcionalidades que ya quedaron obsoletas.
La [documentación oficial de Visual Basic](https://learn.microsoft.com/en-us/dotnet/visual-basic/) es el lugar más actualizado y confiable para empezar tu recorrido.

## El ecosistema .NET

Visual Basic se ejecuta sobre el runtime de .NET y comparte gran parte de su funcionalidad central con C# y F#.
Por eso, entender cómo funciona .NET te va a convertir en un mejor desarrollador de VB.

- [¿Qué es .NET?](https://learn.microsoft.com/en-us/dotnet/core/introduction)
- [El glosario de .NET](https://learn.microsoft.com/en-us/dotnet/standard/glossary)
- [El sistema de tipos comunes (CTS)](https://learn.microsoft.com/en-us/dotnet/standard/base-types/common-type-system)
