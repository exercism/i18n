# Instrucciones

En este ejercicio vas a crear un programa muy útil para que no tengas que recordar los valores de las bandas.
El programa recibirá 1, 4 o 5 colores como argumentos y devolverá el valor correcto en ohms.
Las bandas de color se codifican así:

| Color  | Valor |
| ------ | ----- |
| Black  | 0     |
| Brown  | 1     |
| Red    | 2     |
| Orange | 3     |
| Yellow | 4     |
| Green  | 5     |
| Blue   | 6     |
| Violet | 7     |
| Gray   | 8     |
| White  | 9     |

En [`Resistor Color Trio`][resistor-color-trio-exercise] decodificaste las tres primeras bandas de color.
Por ejemplo: orange-orange-brown se traducía al valor principal `330`.
En este ejercicio tendrás que incorporar la _tolerancia_.
La tolerancia es la cantidad máxima que un valor puede estar por encima o por debajo del valor principal.
Por ejemplo, si la última banda es green, la tolerancia máxima será `±0.5%`.

La banda de tolerancia tendrá uno de estos valores:

| Color  | Tolerancia |
| ------ | --------: |
| Grey   |    ±0.05% |
| Violet |    ±0.10% |
| Blue   |    ±0.25% |
| Green  |    ±0.50% |
| Brown  |    ±1.00% |
| Red    |    ±2.00% |
| Gold   |    ±5.00% |
| Silver |   ±10.00% |

La resistencia de cuatro bandas se compone así:

| Band_1  | Band_2  | Band_3     | Band_4    |
| ------- | ------- | ---------- | --------- |
| Valor_1 | Valor_2 | Multiplicador | Tolerancia |

Ejemplos:

- orange-orange-brown-green serían `330` ohms con una tolerancia de `±0.5%`.
- orange-orange-red-grey serían `3300` ohms con una tolerancia de `±0.05%`.

La diferencia entre una resistencia de cuatro bandas y una de cinco bandas es que la de cinco bandas lleva una banda extra para indicar un valor más preciso.

| Band_1  | Band_2  | Band_3  | Band_4     | Band_5    |
| ------- | ------- | ------- | ---------- | --------- |
| Valor_1 | Valor_2 | Valor_3 | Multiplicador | Tolerancia |

Ejemplos:

- orange-orange-orange-black-green serían `333` ohms con una tolerancia de `±0.5%`.
- orange-red-orange-blue-violet serían `323 million` ohms con una tolerancia de `±0.1%`.

También existen las resistencias de una sola banda.
Las resistencias de una sola banda solo llevan el color black, con un valor de 0.

Tu programa debe traducir una `list` de entrada con los colores de las bandas de la resistencia a una etiqueta:

«... ohms ±...%»

Así que una `list` de entrada `["orange", "orange", "black", "green"]` debe devolver:

«33 ohms ±0.5%»

Cuando hay miles de ohms, decimos «kiloohms».
Es parecido a decir «kilómetro» para 1000 metros y «kilogramo» para 1000 gramos.

Así que una `list` de entrada `["orange", "orange", "orange", "grey"]` debe devolver:

«33 kiloohms ±0.05%»

Cuando hay millones de ohms, decimos «megaohms».

Así que una `list` de entrada `["orange", "orange", "blue", "red"]` debe devolver:

«33 megaohms ±2%»
