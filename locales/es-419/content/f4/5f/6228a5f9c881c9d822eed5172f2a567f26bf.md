# Introducción

Los arrays asociativos de Factor (las tablas hash y similares) comparten un [protocolo][assoc-protocol] común de [`assocs`][assocs]. El literal de tabla hash es `H{ }`:

```factor
H{ { "coal" 1 } { "wood" 2 } } .

"coal" H{ { "coal" 1 } { "wood" 2 } } at .   ! => 1
"gold" H{ { "coal" 1 } { "wood" 2 } } at .   ! => f
```

Operaciones comunes:

```
at        ( key assoc -- value/f )
key?      ( key assoc -- ? )
set-at    ( value key assoc -- )
delete-at ( key assoc -- )
inc-at    ( key assoc -- )
change-at ( key assoc quot -- )
keys      ( assoc -- keys )
values    ( assoc -- values )
>alist    ( assoc -- alist )
```

Las tablas hash son *mutables*. Aplica `clone` a un literal `H{ }` antes de modificarlo para que el literal no se comparta entre llamadas.

[assoc-protocol]: https://docs.factorcode.org/content/article-assocs-protocol.html
