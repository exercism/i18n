# Acerca de

Los bloques son pequeños grupos de sentencias que se pueden ejecutar varias veces.
Se pueden concebir como clausuras o funciones anónimas.
Los bloques se definen con la sintaxis `do...end` (arriba) o con `{}` (abajo).
Los estilos son intercambiables y hay opiniones diversas sobre cuándo conviene usar cada uno.

## Sintaxis abreviada
Cuando un bloque llama a un solo método, puedes reemplazar el bloque por `&:` seguido del nombre del método. Por ejemplo, estas dos líneas son sinónimas:

```ruby
people.sum { |person| person.age }
people.sum(&:age)
```
