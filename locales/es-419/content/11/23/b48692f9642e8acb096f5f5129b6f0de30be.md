# Pistas

## General

- Un `struct` es una secuencia de elementos con nombre, llamados campos, y cada uno tiene un nombre y un tipo.

## 1. Crea un auto a control remoto

- Instancia un nuevo [struct][struct] y llena los campos excepto `distance`.
- Crea una función que devuelva el tipo del struct recién creado y actualiza los campos como corresponda

## 2. Crea una pista de carreras

- Define un nuevo [struct][struct] con 1 campo
- Crea una función que devuelva el tipo del nuevo struct creado y actualiza los campos como corresponda

## 3. Conduce el auto

- Agrega un nuevo campo para llevar la cuenta de la distancia recorrida
- Necesitas verificar si hay suficiente batería para conducir el auto

## 4. Verifica si un auto a control remoto puede terminar una carrera

- Asume que el auto apenas está comenzando la carrera
- Necesitas calcular la distancia máxima que puede recorrer un auto con el nivel actual de batería
- La cantidad de veces que se puede conducir un auto se puede calcular con `battery / batteryDrain`.
- La distancia máxima que puede recorrer el auto es el producto de la velocidad del auto por la cantidad de veces que se puede conducir.
- Sabiendo la distancia máxima que puede recorrer el auto, compárala con la distancia de la pista de carreras
