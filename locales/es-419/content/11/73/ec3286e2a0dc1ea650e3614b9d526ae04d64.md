# Instalación

## Instalación de Dart

Puedes encontrar las instrucciones para instalar el SDK de Dart en el sitio web de Dart: [Obtén Dart][get-dart]

## Plugin de Dart para tu IDE o editor

Si usas un IDE o un editor, [agrega un plugin de Dart][editors] si existe para el editor que elijas.

[get-dart]: https://dart.dev/get-dart
[editors]:  https://dart.dev/tools#editors
