# Acerca de

`TUPLE:` declara una clase con ranuras con nombre. Factor genera
automáticamente una palabra constructora (con el sufijo `new` en el
nombre de la clase), un constructor `boa` («por orden de argumentos»),
una sintaxis literal `T{ class … }` y palabras de acceso para cada
ranura.

```factor
TUPLE: player
    { name initial: f }
    { level initial: 0 }
    { health initial: 100 } ;

player new .                                    ! T{ player }
3 100 "Merlin" player boa .                     ! by-order construction
T{ player { name "Merlin" } { health 50 } } .   ! literal syntax
```

El sistema de acceso en [`accessors`][accessors] proporciona cuatro
variantes por ranura: `name>>`, `>>name`, `change-name` y el
par mutador `[ … ] change-name`. `>>name` y `change-name` mutan la
tupla; usa `clone` primero cuando necesites dejar la original intacta.

Las tuplas admiten `=` mediante igualdad estructural y se imprimen
mostrando sus valores de ranura que no son los predeterminados.

[accessors]: https://docs.factorcode.org/content/vocab-accessors.html
