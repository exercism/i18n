# Anexo de instrucciones

La exponenciación de números complejos requiere una función exponencial, una función seno y una función coseno, y ninguna de ellas está disponible en WebAssembly. Por suerte, puedes usar una [serie de Taylor](https://en.wikipedia.org/wiki/Taylor_series) para calcularlas. Debes tener al menos una precisión de `1/26!` para coincidir con los valores esperados.

## Función exponencial

```
exp(x) ≃ 1 + x + x ^ 2 / 2! + x ^ 3 / 3! + x ^ 4 / 4! + ... + x ^ n / n!
```

## Función seno

```
sin(x) ≃ x - x ^ 3 / 3! + x ^ 5 / 5! - x ^ 7 / 7! + ... - x ^ n / n!
```

## Función coseno

```
cos(x) ≃ 1 - x ^ 2 / 2! + x ^ 4 / 4! - x ^ 6 / 6! + ... - x ^ n / n!
```
