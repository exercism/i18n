# Introducción

En Cairo, el concepto de propiedad se aplica a las _variables_ y define las reglas que rigen quién puede usar esas variables.
Cada variable declarada se puede usar una sola vez, lo que significa que, una vez que se usa una variable, esta se destruye o se mueve, según el tipo de uso.

La _destrucción_ puede ocurrir de varias maneras:

- una variable sale de su ámbito (con o sin uso).
- un struct se desestructura.
- destrucción explícita con `destruct()`

_Mover_ un valor simplemente significa pasar ese valor a otra función.

El lenguaje Cairo usa un sistema de tipos lineal, del que se vale para garantizar que todo el código sea demostrable (y verificable), al mismo tiempo que abstrae la memoria inmutable de la máquina virtual de Cairo.
