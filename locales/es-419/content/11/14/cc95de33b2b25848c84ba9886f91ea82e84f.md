# Instrucciones

Agrega el conteo de minas a un tablero de Buscaminas ya completado.

Buscaminas es un juego popular en el que el usuario tiene que encontrar las minas usando pistas numéricas que indican cuántas minas hay directamente adyacentes (en horizontal, vertical o diagonal) a una casilla.

En este ejercicio tienes que crear código que cuente la cantidad de minas adyacentes a una casilla vacía dada y reemplace esa casilla con el conteo.

El tablero es un rectángulo compuesto por caracteres de espacio en blanco (' '). Una mina se representa con un asterisco ('\*').

Si un espacio dado no tiene ninguna mina adyacente, deja esa casilla en blanco.

## Ejemplos

Por ejemplo, puedes recibir un tablero de 5 x 4 como este (los espacios vacíos se representan aquí con el carácter '·' para mostrarlos en pantalla):

```
·*·*·
··*··
··*··
·····
```

Y tu código lo transformará en esto:

```
1*3*1
13*31
·2*2·
·111·
```
