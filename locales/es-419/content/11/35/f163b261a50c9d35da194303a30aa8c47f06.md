# Apéndice de instrucciones

## Pistas

Para completar este ejercicio, necesitas crear el tipo de dato `Robot`,
como una variable mutable, y el tipo de dato `RunState`. También necesitas
implementar las siguientes funciones:

- `initialState`
- `mkRobot`
- `resetName`
- `robotName`

Encontrarás una declaración de datos ficticia y las firmas de tipo ya listas,
pero depende de ti definir las funciones y crear un tipo de dato,
un newtype o un sinónimo de tipo que tenga sentido. Para modelar el estado, este
ejercicio usa la mónada
[`State`](https://en.wikibooks.org/wiki/Haskell/Understanding_monads/State).
Más específicamente, combinamos la mónada `State` con la mónada `IO` usando
los [transformadores de mónadas `StateT`](http://book.realworldhaskell.org/read/monad-transformers.html).
Todas las pruebas se ejecutan con `initialState` como el estado que se pasa a `evalStateT`.
