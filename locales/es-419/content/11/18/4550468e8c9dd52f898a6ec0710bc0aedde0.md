# Instrucciones

Los endpoints HTTP son mejores con verificación de tipos. Agregar un tipo Record a una solicitud POST asegura que siempre se envíen los datos correctos.

## Objetivos

- Modifica el código proporcionado.
- Agrega los atributos necesarios a este tipo Record para que acepte dos operandos y un operador.
- Agrega una función de recurso HTTP que acepte una solicitud POST en la ruta '/calc'
- La función debe aceptar el tipo record Calculation como payload y devolver un objeto JSON genérico

### Acepta

```json
{ "operand1": 4, "operand2": 10.2, "operator": "+" }
```

### Devuelve

```json
{ "expression": "4+10.2", "result": 14.2 }
```
