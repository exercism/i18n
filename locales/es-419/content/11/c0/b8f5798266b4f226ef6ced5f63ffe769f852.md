## Iteración sobre arrays

Un bucle `for` permite iterar sobre un array y repetir el código para cada elemento:

```haxe
var fruitList = ["apple", "banana", "pear"];

for (fruit in fruitList) {
  trace(fruit);
}

// apple
// banana
// pear
```

En el ejemplo anterior, `fruit` es la variable que contiene el valor de un elemento individual del array `fruitList`. El compilador se asegura de que se pueda iterar sobre `fruitList`; de lo contrario, detendrá la ejecución.

## Iteración sobre rangos

Puedes iterar sobre números usando el operador de rango. El operador toma dos operandos `Int` y se escribe como `min...max`. El `min` es inclusivo y el `max` es exclusivo (`min` <= i AND `max` > i)

```haxe
for (i in 0...10) {
  trace(i); // from 0 to 9
}
```

## Iteración sobre pares clave-valor

Es posible iterar sobre colecciones de pares clave-valor. La única diferencia en la sintaxis es que, en lugar de una sola variable, se usa un identificador de variable para la clave, seguido de `=>`, seguido del identificador de variable para el valor:

```haxe
var map = [1 => 101, 2 => 202, 3 => 303];

for (k => v in map) {
  trace(key, value);
}

// 1, 101
// 2, 202
// 3, 303
```
