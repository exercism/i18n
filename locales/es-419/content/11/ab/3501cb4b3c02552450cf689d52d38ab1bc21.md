# Pistas

## 1. Define el tiempo esperado en el horno en minutos

- Necesitas definir una [var][vars] con [def].

## 2. Calcula el tiempo restante en el horno en minutos

- Necesitas definir una [función][functions] con un solo parámetro.
- Puedes usar y referirte por su nombre a la var que definiste antes.
- El resultado de evaluar la última expresión de una función se devuelve automáticamente desde la función; todas las funciones devuelven este valor.
- Puedes usar las funciones básicas para las [operaciones con números][operators] y restar valores.

## 3. Calcula el tiempo de preparación en minutos

- Necesitas definir una [función][functions] con un solo parámetro.
- Puedes usar las funciones básicas para las [operaciones con números][operators] y multiplicar valores.

## 4. Calcula el tiempo transcurrido en minutos

- Necesitas definir una [función][functions] con dos parámetros.
- Puedes [llamar][calling] a una de las otras funciones que definiste antes.
- Puedes usar las funciones básicas para las [operaciones con números][operators] y sumar valores.
