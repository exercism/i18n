# Instrucciones

Llevas un pequeño puesto meteorológico a orillas del Vltava, en Praga, y en cada
turno anotas las lecturas de temperatura en un registro de texto plano: una
lectura por línea. Cinco palabras pequeñas se encargan de la contabilidad de todo
un turno.

A cada palabra se le pasa la ruta del archivo de registro.

## 1. Lee todas las lecturas

Define `read-readings` para que devuelva todas las lecturas del registro como un
array de strings, una por línea.

```factor
"weather.log" read-readings .
! => { "21.5" "19.0" "22.3" }
```

## 2. Encuentra la lectura más reciente

Define `latest-reading` para que devuelva la lectura más reciente, es decir, la
última línea del registro.

```factor
"weather.log" latest-reading .
! => "22.3"
```

## 3. Lee el registro en bruto

Define `log-text` para que devuelva todo el archivo de registro como un único
string, exactamente como está guardado.

```factor
"weather.log" log-text .
! => "21.5\n19.0\n22.3\n"
```

## 4. Anota una lectura

Define `record-reading` para que agregue una nueva lectura al final del registro
en su propia línea, sin tocar las lecturas anteriores. No devuelve nada.

```factor
"23.1" "weather.log" record-reading
"weather.log" log-text .
! => "21.5\n19.0\n22.3\n23.1\n"
```

## 5. Reescribe el registro

Define `rewrite-log` para que reemplace todo el registro con un array nuevo de
lecturas, una por línea.

```factor
{ "10.0" "11.0" } "weather.log" rewrite-log
"weather.log" log-text .
! => "10.0\n11.0\n"
```
