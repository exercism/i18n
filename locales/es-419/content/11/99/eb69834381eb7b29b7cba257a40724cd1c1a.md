# Introducción

El tipo `enum` de C# representa un conjunto fijo de constantes con nombre (una enumeración). Su propósito principal es proporcionar una forma de interactuar con constantes numéricas que es segura en cuanto a tipos, limitando los valores disponibles a un conjunto predefinido. Un `enum` sencillo se puede definir así:

```csharp
enum Season
{
    Spring,
    Summer,
    Autumn,
    Winter
}
```

Si no se definen explícitamente, los miembros del `enum` reciben automáticamente valores enteros incrementales, y el primero de ellos es cero. También es posible asignar valores explícitamente:

```csharp
enum Answer
{
    Maybe = 1,
    Yes = 3,
    No = 5
}
```
