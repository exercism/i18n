## Instrucciones

Te contrataron en un centro de reciclaje.
Por falta de espacio, todos los productos se colocan en la misma banda transportadora, pero esto ha provocado que distintos materiales se mezclen y queden inservibles.
Para solucionarlo, te encargaron crear funciones que identifiquen el tipo de un producto.

### 1. Comprueba si un valor es un boolean

Implementa la función `isBoolean`, que comprueba si un valor es un boolean.

```javascript
isBoolean(true);
// => true

isBoolean(null);
// => false
```

### 2. Comprueba si un valor es un número.

Implementa la función `isNumber`, que comprueba si un valor es un `number` o `bigint` _finito_, es decir, que no sea `NaN` ni `Infinity`.

A veces, el dispositivo que lee los ID falla y lee un valor no numérico como `NaN` (Not a Number, es decir, «no es un número») o `Infinity`.
Tu función también debería poder manejar esto correctamente.

```javascript
isNumber(42);
// => true

isNumber('Hello, World!');
// => false

isNumber(42n);
// => true

isNumber(NaN);
// => false
```

### 3. Comprueba si un valor es un objeto

Implementa la función `isObject`, que debe comprobar si el valor es un objeto.
En la banda transportadora, `null` no es nada y no se considera un objeto.

```javascript
isObject({ greeting: 'Hello' });
// => true

isObject(25n);
// => false
```

### 4. Comprueba si un string es numérico

Implementa la función `isNumericString`, que debe comprobar si el valor es un string que solo consta de dígitos, o de un signo menos seguido de dígitos que indican un número negativo.
Solo deben considerarse los enteros; para esta comprobación del robot de reciclaje, los decimales no se consideran numéricos.

```javascript
isNumericString(42);
// => false

isNumericString('42');
// => true

isNumericString('Hi!');
// => false
```

### 5. Comprueba si un objeto es electrónico

Implementa la función `isElectronic`, que comprueba si un objeto es una instancia de la clase `ElectronicDevice` proporcionada o de una de sus clases hijas.

```javascript
class Duck {
  //...
}

class WashingMachine extends ElectronicDevice {
  //...
}

isElectronic(new Duck());
// => false

isElectronic(new WashingMachine());
// => true
```

### 6. Comprueba si un valor es un array no vacío

Implementa la función `isNonEmptyArray`, que comprueba si un valor es un array no vacío.

```javascript
isNonEmptyArray([1, 2, 3]);
// => true

isNonEmptyArray([]);
// => false
```

### 7. Comprueba si un valor es un array vacío

Implementa la función `isEmptyArray`, que comprueba si un valor es un array vacío.

```javascript
isEmptyArray([1, 2, 3]);
// => false

isEmptyArray([]);
// => true
```

### 8. Comprueba si un objeto tiene una propiedad o un método `type`

Implementa la función `hasType`, que comprueba si un objeto tiene una propiedad o un método `type`.

```javascript
class Keyboard(){
  type(){
    // ...
  }
}
hasType({ type:"car", color:"red" })
// => true

hasType({ color:"green" })
// => false

hasType(new Keyboard())
// => true
```

### 9. Lanza un error si un objeto no tiene una propiedad o un método `id`

Implementa la función `assertHasId`, que lanzará un `Error` si a un objeto le falta la propiedad `id`.

Si un objeto sí tiene la propiedad `id`, no debería devolver nada.

```javascript
assertHasId({ id: 42, color: 'red' });
// => undefined

assertHasId({ color: 'green' });
// Error: "Object is missing the 'id' property"
```

### 10. Comprueba si un objeto tiene una propiedad `id`

Implementa la función `hasIdProperty`, que comprueba si un objeto tiene una propiedad `id`.

```javascript
class SimpleData {
  constructor() {
    this.number = '42';
    this.id = 'BC269327FE1D9B95';
  }
}

class StealingData extends SimpleData {}

class MethodData {
  constructor() {
    this.number = '42';
    this._id = 'BC269327FE1D9B95';
  }

  get id() {
    return this._id;
  }
}

hasIdProperty(new SimpleData());
// => true

hasIdProperty(new MethodData());
// => false

hasIdProperty(new StealingData());
// => false
```

### 11. Comprueba si un objeto tiene una propiedad `type` definida

Implementa la función `hasDefinedType`, que comprueba si un objeto tiene una propiedad `type` que no sea `undefined`.

```javascript
hasDefinedType({ type: undefined, color: 'red' });
// => false

hasDefinedType({ type: 'car', color: 'green' });
// => true
```
