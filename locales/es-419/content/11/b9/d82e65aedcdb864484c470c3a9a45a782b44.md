# Instrucciones

Andrew, un desarrollador de su empresa, hace poco creó una utilidad ligera para generar consultas SQL para una herramienta de migración de bases de datos.
Su primera implementación, bastante ingenua, funcionaba perfectamente con conjuntos de datos pequeños.
Sin embargo, durante las migraciones grandes en producción, la aplicación empezó a consumir demasiada memoria y no daba abasto bajo cargas intensas.
Después de analizar el rendimiento de la aplicación, Andrew se dio cuenta de que la concatenación de cadenas dentro de los bucles obligaba a Go a reasignar memoria constantemente.
Ahora necesita tu ayuda para refactorizar la utilidad con `strings.Builder` de Go, de modo que la aplicación escale bien y maneje grandes volúmenes de texto sin reventar el heap de memoria.

## 1. Genera consultas SELECT

Implementa la función `BuildSelectQuery`.
Recibe el nombre de una tabla (`string`) y un slice con los nombres de las columnas (`[]string`).
Debe devolver una sentencia SQL `SELECT` completamente formada y terminada en punto y coma.
Si el slice de columnas está vacío o es `nil`, la consulta debe recurrir al comodín `*` para seleccionar todas las columnas.

```go
columns := []string{"id", "name", "email"}
BuildSelectQuery("users", columns)
// Function return: "SELECT id, name, email FROM users;"

BuildSelectQuery("orders", nil)
// Function return: "SELECT * FROM orders;"
```

## 2. Genera sentencias INSERT por lotes

Implementa la función `BuildBatchInserts`.
Recibe el nombre de una tabla (`string`) y un slice bidimensional que representa las filas de la base de datos (`[][]ColumnValue`).
Cada elemento de una fila asocia el nombre de una columna con su valor de tipo string.
La función debe devolver un slice de strings SQL `INSERT` individuales.
El formato estructurado del slice garantiza un orden de salida de las consultas predecible y estable.
Si el slice de filas de entrada está vacío, devuelve un slice vacío de strings.
Si alguna fila individual está vacía, omítela.
Los valores de tipo string dentro de la cláusula `VALUES` deben ir entre comillas simples `'`.

```go
rows := [][]ColumnValue{
    {
        {Column: "title", Value: "Book"},
        {Column: "price", Value: "100"},
    },
    {
        {Column: "title", Value: "Magazine"},
        {Column: "price", Value: "15"},
    },
}

BuildBatchInserts("products", rows)
// Function returns string slice: [
//   "INSERT INTO products (title, price) VALUES ('Book', '100');",
//   "INSERT INTO products (title, price) VALUES ('Magazine', '15');"
// ]
```
