# Pistas

## General

- Cada tarea es una capa delgada sobre una palabra del vocabulario de
  [`math.combinatorics`][math.combinatorics].
- Las palabras de conteo reciben dos enteros; las palabras de listado
  reciben una secuencia.

## 1. Cuenta las combinaciones

- `nCk ( n k -- m )` devuelve el número de formas de elegir `k`
  elementos de `n`. La pila ya está en el orden correcto, solo llámala.

## 2. Cuenta las permutaciones

- `nPk ( n k -- m )` devuelve el número de formas ordenadas de elegir
  `k` elementos de `n`.

## 3. Enumera las combinaciones

- `all-combinations ( seq k -- combinations )` devuelve cada subconjunto
  de `k` elementos de `seq`, en orden lexicográfico.

## 4. Enumera las permutaciones

- `all-permutations ( seq -- permutations )` devuelve cada ordenamiento
  de `seq`.

## 5. Combinaciones que suman un objetivo

- Empieza con cada combinación de `k` que devuelve `all-combinations`.
- Quédate solo con las cuyos elementos sumen `target`. `filter` de
  [`sequences`][sequences] recibe una quotation que devuelve un booleano;
  dentro de ella, `sum` (de [`math`][math]) suma una combinación, y
  `=` la compara con el objetivo.
- Como la tarea necesita `target` dentro de la quotation, definir la
  palabra con `::` (de [`locals`][locals]) te permite referirte a `seq`,
  `k` y `target` por su nombre.
