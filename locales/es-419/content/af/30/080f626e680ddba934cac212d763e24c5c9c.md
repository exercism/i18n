# Acerca de

Más allá de las clases de caracteres y los cuantificadores, las expresiones regulares pueden
describir la *estructura* y el *contexto* de un texto. Estas características se encuentran en
el mismo vocabulario [`regexp`][regexp], escritas con el literal `R/ /`.

## Agrupación y alternancia

Los paréntesis `( )` agrupan parte de un patrón para que un cuantificador o un `|`
(«esto o aquello») se aplique a todo el grupo. Un `?` después de un grupo lo hace
opcional:

```factor
USING: regexp ;

"abab"    R/ (ab)+/ matches? .             ! => t
"cat"     R/ cat|dog/ matches? .           ! => t
"$100.50" R/ \$\d+(\.\d{2})?/ matches? .   ! => t
"$100"    R/ \$\d+(\.\d{2})?/ matches? .   ! => t   (group optional)
```

## Anclas

```
^    ! start of the string
$    ! end of the string
\b   ! a word boundary
```

Un *límite de palabra* (`\b`) es donde un carácter de palabra (una letra, un dígito o un
guion bajo) se encuentra con un carácter que no lo es, incluidos los extremos del string. Así,
`\bcat\b` coincide con `cat` solo cuando está por sí solo:

```factor
USING: regexp ;

"cat nap" R/ \bcat\b/ re-contains? .   ! => t
"scatter" R/ \bcat\b/ re-contains? .   ! => f
```

## Búsqueda alrededor

Una *búsqueda alrededor* comprueba qué hay justo antes o después de un punto sin
hacer que esos caracteres formen parte de la coincidencia: tiene ancho cero:

```
(?=...)    ! lookahead
(?!...)    ! negative lookahead
(?<=...)   ! lookbehind
```

```factor
USING: regexp ;

"spent $100 and $25" R/ (?<=\$)\d+/ all-matching-subseqs .
! => { "100" "25" }

"up 5% then 12%" R/ \d+(?=%)/ all-matching-subseqs .
! => { "5" "12" }
```

## Opciones

Una letra de opción después del `/` de cierre cambia todo el patrón.
`i` no distingue mayúsculas de minúsculas:

```factor
USING: regexp ;

"REFUND" R/ refund/i matches? .   ! => t
```

## Transformar cada coincidencia

`map-matches` ejecuta una quotation en cada coincidencia y recoge los
resultados; `each-match` hace lo mismo solo por los efectos secundarios. Ambas le pasan
a la quotation el índice `start` de la coincidencia, el índice `end`, y el string completo,
así que `subseq` recupera el texto coincidente:

```
map-matches ( string regexp quot: ( start end string -- obj ) -- seq )
each-match  ( string regexp quot: ( start end string --     ) --     )
```

```factor
USING: math regexp sequences ;

"a1 b22 c333" R/ \d+/ [ subseq length ] map-matches .
! => { 1 2 3 }
```

## Lo que Factor no admite

El motor de regexp de Factor no tiene **extracción de grupos de captura** (un grupo
`( )` estructura el patrón, pero no puedes volver a leer el texto con el que
coincidió), ni **retrorreferencias** (`\1`), ni cuantificadores **perezosos/no
codiciosos** (`*?`, `+?`). La búsqueda alrededor es el sustituto idiomático de los
grupos de captura: haz coincidir la parte que quieres, reconocida por el contexto
que la rodea.
