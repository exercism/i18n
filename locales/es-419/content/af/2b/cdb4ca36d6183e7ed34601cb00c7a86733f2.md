# Introducción

Los tipos opacos en Gleam son tipos personalizados en los que solo el módulo que define el tipo puede construir valores del tipo o hacer coincidencia de patrones con ellos. Esto es útil para crear tipos que solo deben usarse de una forma específica.

Los tipos opacos se definen con la palabra clave `opaque`.

```gleam
pub opaque type PositiveInt {
  PositiveInt(inner: Int)
}
```

Este tipo `PositiveInt` se usa en situaciones donde se quiere un número entero, pero que sea cero o mayor. Un `Int` normal de Gleam no serviría, porque también puede ser negativo.

El módulo que define este tipo puede definir una función para obtener el valor entero interno, y una función para crear el tipo `PositiveInt` que devolverá un error si el valor no es positivo.

```gleam
pub fn from_int(i: Int) -> Result(PositiveInt, String) {
  case i {
    _ if i < 0 -> Error("Value must be positive")
    _ -> Ok(PositiveInt(i))
  }
}

pub fn to_int(i: PositiveInt) -> Int {
  i.inner
}
```

Con esta API, otros módulos no pueden construir un `PositiveInt` con un valor negativo, así que cualquier función que reciba un `PositiveInt` puede estar segura de que el valor es positivo.
