# Pruebas

Para ejecutar las pruebas hay que ejecutar `cmake -G` y luego usar el comando de compilación adecuado para tu plataforma.
Encontrarás instrucciones detalladas sobre cómo hacerlo en la página [Ejecutar las pruebas][cpp-tests-instructions] para C++ en exercism.org.

## Cómo pasar las pruebas

Cuando empiezas un ejercicio nuevo en tu computadora, los archivos están configurados para que solo se ejecute la primera prueba.
Haz que esa primera prueba compile, enlace y pase siguiendo las [tres reglas del desarrollo guiado por pruebas][three-laws-of-tdd].
Crea solo la estructura necesaria declarando espacios de nombres, funciones, clases, etc., para resolver los errores del compilador y lograr que la prueba falle.
Luego escribe solo el código necesario para que la prueba pase.
Cuando lo hayas hecho, descomenta la siguiente prueba moviendo la línea `if defined(EXERCISM_RUN_ALL_TESTS)` para que quede después de la siguiente prueba.

Mira el ejemplo de abajo del ejercicio Bob (archivo `bob_test.cpp`, línea 15):

```diff
-#if defined(EXERCISM_RUN_ALL_TESTS)
TEST_CASE("shouting")
{
    REQUIRE("Whoa, chill out!" == bob::hey("WATCH OUT!"));
}
+#if defined(EXERCISM_RUN_ALL_TESTS)
```

Mover esta línea para que quede después de la siguiente prueba puede provocar errores de compilación, ya que pueden aparecer construcciones nuevas que aún no has declarado ni definido.
De nuevo, corrige los errores de compilación lo mínimo para obtener una prueba que falle, luego cambia el código lo mínimo para que la prueba pase, refactoriza tu implementación para que sea más legible y expresiva, y después pasa a la siguiente prueba.

Procura usar las utilidades estándar de C++17 en lugar de escribir tus propios algoritmos o utilidades de bajo nivel a mano.
