# Introducción

Haxe tiene soporte integrado para expresiones regulares. Se pueden usar para verificar el formato de un string, transformar un string o extraer datos regulares de un texto dado.

Para crear una expresión regular, escribe entre `~/` y `/`:

```haxe
var r = ~/haxe/i;
```

Otra forma de hacerlo es usando la instancia de `EReg()`:

```haxe
var r = new EReg("haxe", "i");
```

Aquí la `i` es una bandera que hace que el patrón no distinga entre mayúsculas y minúsculas. Hay otras banderas, entre ellas:

- `g`: reemplazo global.
- `m`: coincidencia en varias líneas

Entre `~/` y `/`, escribes los patrones de la expresión regular. Por ejemplo, quieres buscar un string que contenga letras de la A a la Z. Aquí podemos usar el patrón de rango `[A-Z]`. Hay muchos patrones de expresión, entre ellos:

- `.`: cualquier carácter
- `*`: repetir cero o más veces
- `+`: repetir una o más veces
- `[A-Z0-9]`: rangos de caracteres
