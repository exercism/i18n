# Marcador de posición

## Implementar operaciones de List

El objetivo de este ejercicio es que implementes tú mismo algunos de los métodos de List.
Es natural usar un objeto List en el backend para guardar los datos.
No toques los métodos de List (como `where`, `map`, etc.).

Hay algunas operaciones de List «primitivas» que son inevitables, como:

* rebanado: `list[from..to]`
* agregar: `list.add(item)`

## Protocolo de iterador

Las operaciones de List que vas a implementar tienen que ver con iterar de distintas maneras.
Lee sobre [el protocolo de iterador][iter].
Después vas a poder hacer:

```wren
var list = ListOps.new([1, 2, 3, 4])
for (item in list) {
    do_something_with(item)
}
```

[iter]: https://wren.io/control-flow.html#the-iterator-protocol
