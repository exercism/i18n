# Acerca de

Los dos tipos principales de propiedades son

1. las propiedades autoimplementadas, donde los descriptores de acceso `get` y `set` no tienen cuerpo.
   Pueden estar inicializadas explícitamente o no. Por ejemplo:
   ```csharp
   public int MyProperty {get; set;} = 42;
   ```
2. aquellas donde los descriptores de acceso evalúan expresiones y ejecutan sentencias. El código puede
   ser tan simple como devolver o asignar un campo de respaldo. Por ejemplo:
   ```csharp
   private int myField;
   public int MyProperty
   {
     get { return myField; }
     set { myField = value; }
   }
   ```

Hay una superposición considerable de comportamiento y potencia entre las propiedades y los métodos.
Cuando no son autoimplementadas, las propiedades pueden contener cualquier sentencia o expresión
que pueda aparecer dentro del ámbito de la clase. En el caso común, se suele decir que envuelven
un campo de respaldo.
Aunque muchas veces es obvio si conviene programar un comportamiento como una propiedad o como un método en un caso concreto,
a menudo es una decisión de quien programa, y en particular cuánto código debería
ejecutarse dentro de los descriptores de acceso. Es común encontrar validación en un descriptor de acceso set y
cálculos simples o formateo en un descriptor de acceso get:

```csharp
private float fraction;
public float Percentage
{
  get { return fraction * 100; }
  set
  {
    if (value < 0 || value > 100)
    {
      throw new ArgumentException("Percentage must be between 0 and 100");
    }
    fraction = value / 100;
  }
}
```

De forma similar a otros miembros de la clase, las propiedades pueden tener niveles de acceso.
Con mayor frecuencia, las propiedades tendrán un nivel de acceso no privado, en línea con
su propósito esencial. A veces uno de los descriptores de acceso tendrá
un nivel de acceso distinto al de la propiedad. En el caso de `TareWeight`,
bajo la restricción de «seguridad» bastante artificial, había la oportunidad
de tener una propiedad pública con un descriptor de acceso get privado. Esto significa que el código externo
a la clase puede establecer el valor de la propiedad, pero solo el código dentro
de la clase puede leerlo (get).

```csharp
public int ConfidentialValueUsedInternally {private get; set; }
```

También se admiten descriptores de acceso set no públicos, pero un caso más común es que
el descriptor de acceso set se omita por completo. Esto puede deberse a que
el valor de la propiedad se establece en el constructor de la clase.

```csharp
class MyClass
{
  public MyClass( int importantValue)
  {
    ConstructedValue = importantValue;
  }
  public int ConstructedValue {get;}
}
```

Este ejercicio ha tratado el uso básico de las propiedades. Encontrarás temas
más avanzados en otros ejercicios:

- propiedades con cuerpo de expresión, descriptores de acceso get y set (cubiertos por miembros con cuerpo de expresión)
- propiedades en interfaces (cubiertas por Interfaces)
- propiedades y propiedades abstractas en clases abstractas (cubiertas por Herencia)
- uso de la palabra clave `readonly` con propiedades (cubierto por Inmutabilidad)
- propiedades estáticas (cubiertas por Estáticos)
- indizadores (cubiertos por Indizadores)
