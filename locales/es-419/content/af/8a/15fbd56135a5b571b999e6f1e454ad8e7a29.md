# Introducción

Este ejercicio te enseñará los componentes fundamentales de Ruby.
Cubre mucho terreno, pero no te preocupes si te parece abrumador: profundizaremos en todo con mucho más detalle a medida que avancemos por el track.

Una de las cosas clave que debes entender sobre Ruby es que es un [lenguaje orientado a objetos][object-oriented-programming] y que **todo en Ruby es un [objeto][object]**. Los números, los strings y los arrays: todos son objetos.

## Variables y constantes

Normalmente usamos los objetos asignándoles nombres, ya sea con variables o con constantes.

Las variables siempre se escriben en [snake case][snake-case].
Una variable puede hacer referencia a distintos objetos a lo largo de su vida.
Por ejemplo, `my_first_variable` se puede definir y volver a definir muchas veces con el operador `=`:

```ruby
my_first_variable = 1
my_first_variable = "Some string"
my_first_variable = SomeComplexObject.new
```

Las constantes, en cambio, están pensadas para asignarse una sola vez.
Deben empezar con una letra mayúscula y normalmente se escriben con todas sus letras en mayúscula y las palabras separadas por guiones bajos.
Por ejemplo:

```ruby
MY_FIRST_CONSTANT = 10

# Redefining not allowed
# MY_FIRST_CONSTANT = "Some String"
```

## Clases

Ruby está organizado en clases.
Las clases se definen con la palabra clave `class` seguida del nombre de la clase.
Los objetos generalmente se crean instanciando clases con el método `.new`.
Por ejemplo:

```ruby
# Define the class
class Calculator
  #...
end

# Create an instance of it and assign it to a variable
my_first_calc = Calculator.new
```

## Métodos

Las unidades de funcionalidad se encapsulan en métodos, parecidos a las _funciones_ de otros lenguajes.

Un método se puede definir con argumentos posicionales, argumentos de palabra clave (que se definen y se llaman con la sintaxis `:`) o no tener ningún argumento.

Los métodos o bien devuelven implícitamente el resultado de la última sentencia evaluada, o bien pueden devolver un objeto explícitamente con la palabra clave `return`.

```ruby
class Calculator

  # Positional arguments
  def add(num1, num2)
    return num1 + num2 # Explicit return
  end

  # Keyword arguments
  def multiply(num1:, num2:)
    num1 * num2 # Implicit return
  end
end
```

Los métodos se llaman con la sintaxis `.`:

```ruby
calc = Calculator.new
calc.add(1, 3)
calc.multiply(num1: 2, num2: 5)
```
