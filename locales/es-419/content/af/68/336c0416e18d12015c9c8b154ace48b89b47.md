# Instalación

[Godot Engine][godot-engine] se usa para ejecutar código de GDScript.
Godot Engine funciona en Windows, Linux, macOS y Android.

## Instalar Godot Engine

Godot Engine se puede descargar directamente desde [el sitio web de Godot Engine][download].
La descarga contiene una carpeta zip con dos ejecutables, ambos nombrados con la versión de Godot Engine.
Extrae esta carpeta y abre el primer ejecutable.

Si necesitas una guía en video, tienes una [aquí][video-guide]. (Debería funcionar en Godot 4.7 o en cualquier otra versión de Godot).

Este track usa la versión 4.7.2 de Godot.

[godot-engine]: https://godotengine.org/
[download]: https://godotengine.org/download/
[video-guide]: https://www.youtube.com/watch?v=wOTZo0a_Fek
