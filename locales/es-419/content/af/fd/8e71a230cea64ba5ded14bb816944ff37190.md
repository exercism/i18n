# Acerca de

El módulo `Time` se usa para mostrar fechas y horas legibles para humanos.
Aunque técnicamente es posible manipular tiempos con `Time`, existen paquetes de la comunidad de Elm mucho más adecuados para esa tarea, como [`justinmimbs/date`][date] o [`CoderDennis/elm-time-format`][elm-time-format].

## Posix

Los tiempos se representan con el tipo opaco `Posix`, que envuelve el tiempo de la época Unix, la cantidad de milisegundos transcurridos desde la medianoche UTC del 1 de enero de 1970.
Un `Posix` es un valor no ambiguo que no varía entre zonas horarias, por lo que es una buena opción para llevar el tiempo.
En una aplicación de Elm, los tiempos `Posix` normalmente los proporcionan fuentes externas, como el navegador.

Es posible transformar un `Posix` en una cantidad de milisegundos y viceversa con las siguientes funciones:

```elm
posixToMillis : Posix -> Int
millisToPosix : Int -> Posix
```

## Zonas horarias

En nuestra vida cotidiana, los humanos normalmente no leemos `Posix` y preferimos la hora local, que depende de nuestra ubicación en la Tierra y de las reglas locales del horario de verano.
En Elm, esta información está codificada en el tipo opaco `Zone`, que normalmente proporciona el navegador.

Hay una `Zone` especial que siempre está disponible:

```elm
utc : Zone
```

## Tiempos legibles

Con un `Posix` y una `Zone`, tenemos suficiente información para mostrar la hora local con cualquier nivel de detalle.
Aquí tienes una lista de las funciones que puedes usar para eso:

```elm
toYear : Zone -> Posix -> Int
toMonth : Zone -> Posix -> Month
toDay : Zone -> Posix -> Int
toWeekday : Zone -> Posix -> Weekday
toHour : Zone -> Posix -> Int
toMinute : Zone -> Posix -> Int
toSecond : Zone -> Posix -> Int
toMillis : Zone -> Posix -> Int
```

Habrás notado dos tipos personalizados más de `Time`:

```elm
type Month = Jan | Feb | Mar | Apr | May | Jun | Jul | Aug | Sep | Oct | Nov | Dec
type Weekday = Mon | Tue | Wed | Thu | Fri | Sat | Sun
```

Convertir estos tipos personalizados en valores legibles para humanos queda en manos de quien usa el código.
