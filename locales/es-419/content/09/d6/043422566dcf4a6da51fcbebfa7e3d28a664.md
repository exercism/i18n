# Introducción

El vocabulario [`random`][random] de Factor te da una sola palabra genérica, `random`, que se adapta a su argumento, además de palabras auxiliares para mezclar y muestrear secuencias.

```factor
USING: random ;

6 random .                       ! a value from 0..5
{ "rock" "paper" "scissors" } random .   ! a random element
{ 1 2 3 4 5 } randomize .        ! the same cards, reordered
{ 1 2 3 4 5 } 2 sample .         ! two distinct elements
```

`random` de un número entero `n` devuelve un valor en `[0, n)`; aplicado a una secuencia, devuelve un elemento aleatorio. `randomize` mezcla los elementos en el lugar, y `sample` extrae elementos distintos.

Por defecto, estas palabras toman valores de un generador global con semilla tomada del reloj del sistema. Para que los resultados sean reproducibles, instala un generador con semilla usando `<mersenne-twister>` (de [`random.mersenne-twister`][mt]) y `with-random`:

```factor
USING: random random.mersenne-twister ;

42 <mersenne-twister> [ 6 random ] with-random .   ! same value every run
```
