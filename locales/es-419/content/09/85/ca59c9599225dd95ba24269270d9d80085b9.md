# Pistas

## 1. Calcula el valor de cualquier carta.

- El método `Blackjack.parse_card` debe recibir un string (por ejemplo, `"ace"`) y devolver su valor (por ejemplo, 11).
- Define una [sentencia `case`][case] y asigna el valor de la carta como valor del `case`.
- King, Queen, Jack y 10 se pueden manejar con un solo case.
- El `case` puede tener un caso `else`.
  En cualquier caso, la función debe devolver `0` para las cartas desconocidas.

## 2. Nombra rangos de valores.

- Calcula la puntuación del jugador sumando los valores de sus dos cartas.
- Define una [sentencia `case`][case] y asigna el nombre del rango como valor del `case`.
- El switch puede usar objetos [`Range`][range] como casos para comprobar si un valor está dentro de un rango.

## 3. Implementa la lógica de decisión para el primer turno.

- Calcula la puntuación del jugador sumando los valores de sus dos cartas.
- Puedes usar una [sentencia `case`][case] grande sobre la puntuación del jugador
  (quizás con sentencias `if` anidadas sobre la puntuación del crupier en algunos casos),
- o puedes distinguir distintas categorías de puntuación del jugador (por ejemplo, «manos pequeñas»
  con una puntuación menor que 12, «manos medianas» con una puntuación en el rango 12..20 y
  «manos grandes» con una puntuación mayor que 20) y escribir funciones separadas para
  todas (o algunas) de esas categorías.

[case]: https://crystal-lang.org/reference/syntax_and_semantics/case.html
[range]: https://crystal-lang.org/reference/syntax_and_semantics/literals/range.html
