# Introducción

## Paquetes y módulos

### Importación

Un módulo se carga normalmente con la palabra clave `use`.
Esto lo carga y además llama a su método `import`, importando cualquier símbolo exportado.

Los símbolos del array `@EXPORT` del paquete se importan de forma predeterminada.
Los símbolos del array `@EXPORT_OK` del paquete se deben importar de forma explícita.

### Exportación

Para que un símbolo se pueda importar, primero se debe exportar.
El módulo [Exporter][Exporter] viene incluido con Perl y es una de las opciones más convenientes para exportar.

Definir el módulo:
```perl
package Foo;

use Exporter ('import');
our @EXPORT_OK = ('bar');

sub bar { ... }
```

Usar el módulo:
```perl
use Foo ('bar');

bar();
```

### Módulos del núcleo

Junto con [Exporter][Exporter], Perl tiene una gran variedad de [módulos del núcleo][perl-core-modules] disponibles para usar.
Algunos ejemplos útiles para los ejercicios que puedes encontrar aquí incluyen [List::Util][List::Util], [Time::Piece][Time::Piece] y [Math::BigRat][Math::BigRat].

### CPAN

Además de los módulos del núcleo, [CPAN][metacpan] tiene miles de módulos adicionales creados por la comunidad de Perl disponibles para instalar.
El track de Perl usa un [cpanfile][test-runner-cpanfile] para instalar una selección de módulos que se pueden usar con el test runner de Perl de Exercism.
