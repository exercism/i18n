Pero las cosas están un poco desorganizadas: las coordenadas de Aazra parecen estar formateadas y ordenadas de forma distinta a las de Rui, y tienen que estar yendo de una lista a la otra para averiguar qué tesoros van con qué ubicaciones. Como son Gleamlins en ciernes, han venido a ti para que les ayudes a escribir un pequeño programa (en realidad, un conjunto de funciones) que organice mejor la información de su búsqueda.

## 1. Convierte las ubicaciones

Implementa la función `place_location_to_treasure_location`, que toma una ubicación de lugar (como `#("C", 1)`) y la convierte en una ubicación de tesoro (como `#(1, "C")`).

```gleam
place_location_to_treasure_location(#("C", 1))
// -> #(1, "C")
```

## 2. Compara las ubicaciones de tesoros y lugares

Implementa la función `treasure_location_matches_place_location`, que toma una ubicación de lugar (como `#("C", 1)`) y devuelve `True` si coincide con una ubicación de tesoro (como `#(1, "C")`).

```gleam
treasure_location_matches_place_location(#("C", 1), #(1, "C"))
// -> True

treasure_location_matches_place_location(#("C", 1), #(2, "C"))
// -> False
```

## 3. Cuenta las ubicaciones de tesoros

Implementa la función `count_place_treasures`, que toma un lugar (como `#("Aqua Lagoon (Island of Mystery)", #("F", 1))`) y la lista de tesoros, y devuelve la cantidad de tesoros que se pueden encontrar allí.

```gleam
let place = #("Aqua Lagoon (Island of Mystery)", #("F", 1))

count_place_treasures(place, treasures)
// -> 2
```

## 4. Lugares especiales

Implementa la función `special_case_swap_possible`, que toma un tesoro (como `#("Amethyst Octopus", #(1, "F"))`), un lugar (como `#("Seaside Cottages", #("C", 1))`) y un tesoro deseado (como `#("Crystal Crab", #(6, "A"))`), y devuelve `True` para las siguientes combinaciones:

- El Brass Spyglass se puede intercambiar por cualquier otro tesoro en el Abandoned Lighthouse.
- El Amethyst Octopus se puede intercambiar por el Crystal Crab o el Glass Starfish en el Stormy Breakwater.
- El Vintage Pirate Hat se puede intercambiar por el Model Ship in Large Bottle o el Antique Glass Fishnet Float en el Harbor Managers Office.
