# no escribas en la consola

Elimina la función o las funciones que escriben en la consola, ya que los tests no las requieren y hacen que el código sea un poco más difícil de leer.

Por lo general, estas sentencias se agregan para ayudar a hacer debug del código. Sin embargo, un mejor enfoque es hacer debug del código mientras ejecutas uno o más tests unitarios. Esto tiene la ventaja adicional de que puedes concentrarte en hacer debug de un test específico. Aquí tienes algunos enlaces que explican cómo hacer debug de código Scala mientras ejecutas tests unitarios en varios IDE:

- [IntelliJ](https://www.jetbrains.com/help/idea/run-debug-and-test-scala.html)
- [Eclipse](http://scala-ide.org/docs/current-user-doc/features/scaladebugger/index.html)
