# Pistas

## General

- La tupla `plot`, los símbolos `registrations` y `next-id`, y el símbolo `not-found` ya están declarados en el archivo del ejercicio.
- Para el estado a nivel de módulo, usa `set-global`, `get-global` y `change-global`.

## 1. Abre el jardín y lista sus registros

- `V{ } clone` es el valor inicial correcto para `registrations` (usa siempre `clone` para que el literal no se comparta entre llamadas).
- `1 next-id set-global` establece el contador.
- Para `list-registrations`, basta con un solo `registrations get-global`.

## 2. Registra una parcela

- Lee `next-id` primero, luego `plot boa` para construir la parcela a partir de `id` y `name`.
- Aumenta el contador con `next-id [ 1 + ] change-global`.
- `push` (en [`sequences`][sequences]) agrega al final de un vector en el lugar: perfecto para `registrations get-global`.

## 3. Libera una parcela

- Un `:: release ( id -- )` hace que `id` esté disponible dentro del predicado del filtro.
- `[ id>> id = ] reject` conserva toda parcela cuya ranura `id` *no* coincida con el `id` local. Úsalo como el cuerpo de un `change-global`.

## 4. Obtén una parcela registrada

- `find` devuelve `( index elt/f )`. `nip` descarta el índice.
- `[ not-found ] unless*` sustituye el símbolo cuando no se encontró nada.

[sequences]: https://docs.factorcode.org/content/vocab-sequences.html
