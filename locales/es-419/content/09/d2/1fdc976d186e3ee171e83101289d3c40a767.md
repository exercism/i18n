# Pistas

## General

- Para que un nombre pueda tener varios tipos diferentes, necesitas usar un [tipo de unión][union-type].
- Para poder usar una variable de instancia en una expresión de control [`if var.is_a?(Type)`][if-is-a], primero hay que asignarla a una variable local.

## 1. Establece una contraseña

- Necesitas definir una clase con el nombre `PasswordLock`.
- Necesitas definir un método `initialize` que reciba como argumento un `String`, un `Int32` o un `Float64`.
- Necesitas definir una [variable de instancia][instance-variable] `@password` que se establece con el argumento que se le pasa al constructor.

## 2. Cifra la contraseña

- Define un método de instancia llamado `encrypt`.
- El método debe modificar la [variable de instancia][instance-variable] `@password` para que quede cifrada.
- Para lograr que una rama específica solo se pueda ejecutar si la variable es de un tipo específico, necesitas usar el método [`is_a?`][is-a] en una expresión de control.

## 3. Verifica si una contraseña es correcta

- Puedes usar los métodos ya definidos para cifrar el intento de contraseña que se te dé.
