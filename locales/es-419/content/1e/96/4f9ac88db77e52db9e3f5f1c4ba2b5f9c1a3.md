# Pistas

## General

- Los operadores de enteros y de números de punto flotante se describen en [el recorrido por el lenguaje][tour].
- Las funciones para trabajar con enteros se definen en el [módulo `gleam/int`][int].
- Las funciones para trabajar con números de punto flotante se definen en el [módulo `gleam/float`][float].
- Las funciones para trabajar con strings se definen en el [módulo `gleam/string`][string].

[tour]: https://gleam.run/book/tour/ints-and-floats.html
[int]: https://hexdocs.pm/gleam_stdlib/gleam/int.html
[float]: https://hexdocs.pm/gleam_stdlib/gleam/float.html
[string]: https://hexdocs.pm/gleam_stdlib/gleam/string.html
