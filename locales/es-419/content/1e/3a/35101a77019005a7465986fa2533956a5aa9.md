# Anexo de instrucciones

## Los traits de Rust para `.to_string()`

También tendrás que implementar `.to_string()` para la estructura `Clock`.
Vamos a usar esto para mostrar el estado del `Clock`.
Puedes hacerlo implementándolo directamente o usando el [trait Display][display-trait].

Si es así, intenta implementar el [trait Display][display-trait] para `Clock`.

Los traits permiten una forma común de implementar funcionalidad para varios tipos.

Como aprendizaje adicional, considera cómo podrías implementar `String::from` para el tipo `Clock`.
No tienes que implementarlo en realidad (es redundante con `Display`, que por lo general es la
mejor opción cuando el tipo de destino es `String`), pero es útil tener algunos traits de conversión
de tipos en tu caja de herramientas.

[display-trait]: https://doc.rust-lang.org/std/fmt/trait.Display.html
