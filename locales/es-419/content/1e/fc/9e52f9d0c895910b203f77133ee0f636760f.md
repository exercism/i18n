# Introducción

R no tiene un tipo [conjunto][wiki-set] aparte; en su lugar, usa una variedad de funciones para realizar operaciones similares sobre vectores.

El operador [`%in%`][ref-match] comprueba la pertenencia a un conjunto.
Este operador infijo es un sinónimo de la función `is.element()`.

```R
2 %in% 1:10 # TRUE
12 %in% 1:10 # FALSE
```

Entre las funciones relevantes están:

- [`unique()`][ref-unique] para eliminar duplicados.
- [`union()`][ref-sets] para combinar conjuntos (matemáticamente, `A ∪ B`).
- [`intersect()`][ref-sets] para encontrar los elementos comunes a ambos conjuntos (`A ∩ B`).
- [`setdiff()`][ref-sets] para restar un conjunto de otro (`A - B`).
- [`setequal`][ref-sets] para comprobar la igualdad de conjuntos, ignorando duplicados y el orden.

```R
> set_1 <- c("a", "b", "c", "b", "a")
> unique(set_1) # deduplicate
[1] "a" "b" "c"

> set_2 <- c('a', "c", "d")
> union(set_1, set_2) # values in either set
[1] "a" "b" "c" "d"

> intersect(set_1, set_2) # values in both sets
[1] "a" "c"

> setdiff(set_1, set_2) # values in set_1 but not set_2
[1] "b"

> setdiff(set_2, set_1) # values in set_2 but not set_1
[1] "d"

setequal(set_1, c("c", "b", "a", "b")) # are elements the same after deduplication?
[1] TRUE
```

En cada caso, la función devuelve una copia y deja los argumentos sin cambios.

## Tablas hash

Las operaciones con vectores descritas arriba forman parte de R base.
Son útiles para problemas pequeños, pero se vuelven lentas para conjuntos grandes.

Varios paquetes de terceros implementan [tablas hash][wiki-hash] para mejorar el rendimiento en algunos contextos.

Por ejemplo, el paquete [`hashtable`][ref-hashtable] proporciona implementaciones de `hashmap` y `hashset`, que escalan mejor.
Como la mayoría de los paquetes externos, este no está disponible dentro de Exercism, pero vale la pena investigarlo para problemas del mundo real.
