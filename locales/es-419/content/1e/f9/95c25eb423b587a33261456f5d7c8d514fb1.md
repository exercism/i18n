# Acerca de

Escribe código que se lea como inglés sencillo.

Visual Basic se ejecuta en el mismo runtime de .NET que C# y F#.
Tienes LINQ, genéricos y async/await, pero la sintaxis está hecha para leerse, no para descifrarse.

Si ya conoces C# o F#, el runtime y las bibliotecas de .NET te resultarán familiares.
Si conoces VB6, VBA o VBScript, esa sintaxis familiar ahora está respaldada por el runtime de .NET, probado en batalla.

Sin llaves que equilibrar, sin puntos y comas que perseguir.
