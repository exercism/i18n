# Referencias y snapshots

Cuando pasas una variable a una función, normalmente se transfiere su propiedad, lo que deja la variable original inutilizable. Esto puede resultar un poco tedioso cuando necesitas acceder a un estado más de una vez.
Cairo tiene dos funcionalidades para pasar un valor sin destruirlo ni moverlo, llamadas `references` y `snapshots`.

## Snapshots

Los snapshots ofrecen una vista inmutable de un valor en un momento determinado, lo que te permite conservar la propiedad de una variable mientras accedes a su estado.
Cualquier modificación de la variable crea una nueva celda de memoria, de modo que la vista del snapshot no cambia.

```rust
fn get_len(arr: @Array<u128>) -> u32 { // this parameter takes in a snapshot using `@` with the data-type
    arr.len()
}

fn foo(arr: Array<u128>) {
    arr.pop_front();
}

fn main() {
    let mut new_arr: Array<u128> = array![1, 2, 3, 4, 5, 6, 7, 8];
    let snapshot = @new_arr; // using `@` to create a snapshot of a variable
    let len = get_len(snapshot); // pass the snapshot as argument, retaining ownership
    foo(new_arr); // `new_arr` is still valid up until here and no further

    // let new_len = new_arr.len(); // this would throw an error if you uncommented the code because `new_arr` has been moved when it was passed into `foo()` above
}
```

## Operador desnap

Para convertir un snapshot de nuevo en una variable normal, puedes usar el operador desnap `*`, que es lo opuesto al operador `@`.
Solo se les puede aplicar el desnap a aquellos tipos que implementan el trait `Copy`.

```rust
#[derive(Drop)]
struct Rectangle {
    height: u64,
    width: u64,
}

fn main() {
    let rec = Rectangle { height: 3, width: 10 };
    let area = calculate_area(@rec);
    println!("Area: {}", area);
}

fn calculate_area(rec: @Rectangle) -> u64 {
    // We need to transform the snapshots back into values using the desnap operator `*`.
    // Here we use `*` to both multiply the height and width and to desnap the snapshots.
    *rec.height * *rec.width
}
```

## Referencias mutables

Las referencias mutables te permiten pasar valores mutables a una función y que se devuelvan de forma implícita, manteniendo la propiedad en el contexto de la llamada.
Esto se logra con el modificador `ref`, siempre que la variable se declare como mutable con la palabra clave `mut`.

```rust
fn foo(ref arr: Array<u128>) { // using `ref` marks the argument as a mutable reference
    arr.pop_front(); // modifies the state of arr
}

fn main() {
    let mut new_arr: Array<u128> = array![1, 2, 3, 4, 5, 6, 7, 8];

    foo(ref new_arr);  // use `ref` to pass a mutable reference to the function

    let new_len = new_arr.len();  // the current context retains ownership of `new_arr`, so we can still use it
}
```
