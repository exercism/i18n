## Operaciones bit a bit

Las operaciones bit a bit nos permiten manipular dígitos individuales dentro de los números binarios.
Estas operaciones son fundamentales en la informática, ya que ofrecen una forma eficiente de realizar tareas de bajo nivel, como controlar bits específicos en la memoria, optimizar cálculos matemáticos, el cifrado, las comunicaciones y la codificación y decodificación de datos.

### Cómo funcionan los enteros de 32 bits en Elm

En Elm, los enteros se almacenan como enteros de 32 bits con signo usando la representación en [complemento a dos](https://en.wikipedia.org/wiki/Two%27s_complement), lo que significa que se usan 32 dígitos binarios (_bits_) para almacenar cada valor entero.
Este límite de bits afecta el rango de enteros que Elm puede representar directamente:

Rango positivo: de 0 a 2<sup>31</sup> - 1 (o de 0 a 2,147,483,647)
Rango negativo: de -2<sup>31</sup> a -1 (o de -2,147,483,648 a -1).

Por ejemplo, el entero `5` se representa en binario como `00000000000000000000000000000101`, aunque normalmente ignoramos los ceros a la izquierda y solo decimos `101`.

### Bitwise

Elm ofrece varios operadores bit a bit en su [módulo Bitwise](https://package.elm-lang.org/packages/elm/core/latest/Bitwise)

## Operaciones básicas

Modificar los bits individuales de un número se llama _enmascaramiento_.
Una _máscara_ es un número en el que se han establecido bits específicos de una manera determinada para manipular otro número usando operadores bit a bit como `and`, `or` y `xor`.

### and

`and` combina dos números conservando solo los bits que son `1` en ambos.
Esto es útil para comprobar si un bit individual está establecido.
Por ejemplo, para comprobar si el cuarto bit de un número está establecido en `1`, aplícale `and` con una máscara de `01000` (`8` en decimal) y observa si el resultado es distinto de cero:

```elm
Bitwise.and 13 8 --> 8
--  13 = 01101
--   8 = 01000
-- and = 01000 = 8
```

### or

`or` combina dos números estableciendo en `1` cada bit que sea `1` en uno u otro número, o en ambos.
Esto es útil para establecer un bit específico en `1`.
Por ejemplo, para establecer el segundo bit de `10101` en `1`, aplícale `or` con la máscara `00010`:

```elm
Bitwise.or 21 2 --> 23
-- 21 = 10101
--  2 = 00010
-- or = 10111 = 23
```

### O exclusiva (xor)

`xor` combina dos números estableciendo en `1` cada bit que sea `1` en uno de los números pero `0` en el otro.
Esto es útil para invertir un bit a su valor opuesto:

```elm
Bitwise.xor 20 5 --> 17
--  20 = 10100
--   5 = 00101
-- xor = 10001 = 17
```

### Complemento

`complement` invierte cada bit de un número (`0` se convierte en `1` y `1` se convierte en `0`).

Ten en cuenta que esto hará que los números positivos se vuelvan negativos y los negativos se vuelvan positivos.
Esto se debe a que los números negativos en binario se representan con `1` en la posición más a la izquierda.

```elm
Bitwise.complement 21 --> -22
--         21 = 00000000000000000000000000010101
-- complement = 11111111111111111111111111101010 = -22
```

### Desplazamiento de bits

Los siguientes operadores mueven bits a la izquierda o a la derecha una cantidad determinada de posiciones, lo que equivale a multiplicar o dividir por potencias de 2.

`shiftLeftBy` mueve los bits hacia la izquierda y rellena con `0` desde el lado derecho.
Por ejemplo, para desplazar `21` tres lugares a la izquierda:

```elm
Bitwise.shiftLeftBy 3 21 --> 168
--  21 = 10101
-- shiftLeftBy 3 = 10101000 = 168
```

Esto es lo mismo que decir `21 * 2^3 = 21 * 2 * 2 * 2 = 168`

`shiftRightBy`: mueve los bits hacia la derecha:

```elm
Bitwise.shiftRightBy 2 21 --> 5
--  21 = 10101
-- shiftRightBy 2 = 00101 = 5
```

Desplazar dos lugares a la derecha es lo mismo que hacer una división entera entre 4.

Ten en cuenta que esta función duplica el valor que esté en el bit más a la izquierda.
Por eso, los números negativos siguen siendo negativos:

```elm
Bitwise.shiftRightBy 3 -21 --> -3
--  -21 = 111...101011
-- shiftRightBy 3 = 111...11101 = -3
```

Si quieres desplazar a la derecha y rellenar con ceros, usa `shiftRightZfBy`:

```elm
Bitwise.shiftRightZfBy 3 -21 --> 536870909
--  -21 = 111...101011
-- shiftRightZfBy 3 = 00111...11101 = 536870909
```
