# Acerca de

Swift ofrece tres construcciones principales de bucles:

- **Bucles `while`**: repiten un bloque de código mientras una condición especificada siga siendo `true`. La condición se evalúa antes de ejecutar el cuerpo del bucle.
- **Bucles `repeat-while`**: parecidos a los bucles `while`, pero la condición se evalúa después de ejecutar el cuerpo del bucle. Esto garantiza que el cuerpo se ejecute al menos una vez.
- **Bucles `for-in`**: ejecutan un bloque de código una vez por cada elemento de una secuencia o colección (como un rango, un array o un string).
