# Introducción

Swift ofrece una variación de su sintaxis cuando se trabaja con closures, conocida como trailing closures. Los trailing closures surgen cuando el último parámetro en la lista de parámetros de una función tiene un tipo de función. En este caso, si se pasa un closure, el closure se puede escribir _después_ del paréntesis de cierre y se omite la etiqueta de argumento. Nota que si solo hay un parámetro para la función, los paréntesis se pueden omitir por completo.

```swift
func fetchURL(_ urlString: String,
              uponReceipt handleResult: (String) -> ()
             )  -> () {
  if let url = URL(string: urlString), let htmlString = fetch(url) {
    handleResult(htmlString)
  }
}

fetchURL("https://www.swift.org") { print($0) }
// prints the fetched html string

["apple", "ball", "carrot"].sorted { $0.count < $1.count }
```
