# Instrucciones

Estás al frente de una boutique de moda en línea. Se acerca tu gran venta anual, así que necesitas hacer el inventario para asegurarte de que todo esté listo.

Cada artículo del inventario se representa con un mapa, y todo el inventario es una lista de esos mapas.

```elixir
%{
  name: "White Shirt",
  price: 40,
  quantity_by_size: %{s: 3, m: 7, l: 8, xl: 4}
}
```

## 1. Ordena los artículos por precio

Implementa la función `sort_by_price/1`. Debe recibir el inventario y devolverlo ordenado por el precio de los artículos, de forma ascendente.

```elixir
BoutiqueInventory.sort_by_price([
  %{price: 65, name: "Maxi Brown Dress", quantity_by_size: %{}},
  %{price: 50, name: "Red Short Skirt", quantity_by_size: %{}},
  %{price: 50, name: "Black Short Skirt", quantity_by_size: %{}},
  %{price: 20, name: "Bamboo Socks Cats", quantity_by_size: %{}}
])

# => [
#      %{price: 20, name: "Bamboo Socks Cats", quantity_by_size: %{}},
#      %{price: 50, name: "Red Short Skirt", quantity_by_size: %{}},
#      %{price: 50, name: "Black Short Skirt", quantity_by_size: %{}},
#      %{price: 65, name: "Maxi Brown Dress", price: 65, quantity_by_size: %{}}
#    ]
```

## 2. Encuentra todos los artículos a los que les falta el precio

Después de ordenar tu inventario por precio, notaste que debiste cometer un error cuando estabas haciendo el inventario y olvidaste anotar los precios de algunos artículos.

Implementa la función `with_missing_price/1`. Debe recibir el inventario y devolver una lista de los artículos que no tienen precio.

```elixir
BoutiqueInventory.with_missing_price([
  %{price: 40, name: "Black T-shirt", quantity_by_size: %{}},
  %{price: nil, name: "Denim Pants", quantity_by_size: %{}},
  %{price: nil, name: "Denim Skirt", quantity_by_size: %{}},
  %{price: 40, name: "Orange T-shirt", quantity_by_size: %{}}
])

# => [
#      %{price: nil, name: "Denim Pants", quantity_by_size: %{}},
#      %{price: nil, name: "Denim Skirt", quantity_by_size: %{}}
#    ]
```

## 3. Actualiza los nombres de los artículos

Notaste que algunos nombres de artículos contienen una palabra que ya no quieres usar. Ahora necesitas actualizar todos los nombres de artículos que tengan esa palabra.

Implementa la función `update_names/3`. Debe recibir el inventario, la palabra antigua que quieres quitar y una palabra nueva que quieres usar en su lugar. Debe devolver una lista de artículos con los nombres actualizados.

```elixir
BoutiqueInventory.update_names(
  [
    %{price: 40, name: "Black T-shirt", quantity_by_size: %{}},
    %{price: 70, name: "Denim Pants", quantity_by_size: %{}},
    %{price: 65, name: "Denim Skirt", quantity_by_size: %{}},
    %{price: 40, name: "Orange T-shirt", quantity_by_size: %{}}
  ],
  "T-shirt",
  "Tee"
)

# => [
#      %{price: 40, name: "Black Tee", quantity_by_size: %{}},
#      %{price: 70, name: "Denim Pants", quantity_by_size: %{}},
#      %{price: 65, name: "Denim Skirt", quantity_by_size: %{}},
#      %{price: 40, name: "Orange Tee", quantity_by_size: %{}}
#    ]
```


## 4. Aumenta la cantidad del artículo

Algunos artículos se vendían especialmente bien, así que pediste más, en todas las tallas.

Implementa la función `increase_quantity/2`. Debe recibir un solo artículo y un número `n`, y devolver ese artículo con la cantidad de cada talla aumentada en `n`.

```elixir
BoutiqueInventory.increase_quantity(
  %{
    name: "Polka Dot Skirt",
    price: 68,
    quantity_by_size: %{s: 3, m: 5, l: 3, xl: 4}
  },
  6
)

# => %{
#      name: "Polka Dot Skirt",
#      price: 68,
#      quantity_by_size: %{l: 9, m: 11, s: 9, xl: 10}
#    }
```

## 5. Calcula la cantidad total del artículo

Para saber cuánto espacio necesitas en tu almacén, necesitas saber cuántas unidades tienes en total de cada artículo.

Implementa la función `total_quantity/1`. Debe recibir un solo artículo y devolver cuántas piezas tienes en total, en cualquier talla.

```elixir
BoutiqueInventory.total_quantity(%{
  name: "Red Shirt",
  price: 62,
  quantity_by_size: %{s: 3, m: 6, l: 5, xl: 2}
})

# => 16
```
