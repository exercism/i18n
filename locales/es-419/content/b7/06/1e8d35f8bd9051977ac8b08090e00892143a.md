# Getters y setters

Los getters y setters son métodos que te permiten leer y escribir el valor de una propiedad de un objeto.
Crystal tiene macros, lo que facilita definir getters y setters para una propiedad.
Las macros son una forma de generar código en tiempo de compilación, algo que se verá más adelante en el concepto de macros.

En Ruby, estos métodos se definen con los métodos `attr_reader`, `attr_writer` y `attr_accessor`, y en apariencia son muy similares a la implementación de Crystal.
Crystal los ha definido como las macros `getter`, `setter` y `property`.

## Getters

Getter es una macro que define un método que devuelve el valor de una variable de instancia.
Esto significa que ya no tienes que escribir `@` delante de la variable de instancia cuando quieras acceder a ella (en los métodos, excepto en initialize); en su lugar, puedes llamar al método que ha definido la macro getter.

La macro getter puede aceptar varias variables de instancia si las separas con comas.

```crystal
# This:
class Person
  @name : String
  @age : Int32

  def name
    @name
  end

  def age
    @age
  end
end

# Is the same as this:
class Person
  @name : String
  @age : Int32

  getter name, :age
end
```

Como puedes ver, usar getter reduce la cantidad de código que escribes y hace que sea más fácil de leer.
Además, Ruby y Crystal se diferencian en que Crystal acepta tanto el nombre de la variable como el símbolo como argumentos para la macro getter.
Los símbolos se verán más adelante en el concepto de símbolos.

## Setters

Setter es una macro que define un método que asigna el valor de una variable de instancia.
Esta macro no se encuentra muy a menudo y, en su lugar, lo habitual es usar la macro `property`.
Los métodos que se crearán tendrán la forma `name_of_method=`; el `=` es lo que permite que la propiedad se pueda asignar.

Esta definición de método es un poco especial, ya que el argumento que recibe el método va después del signo `=`.
Otros métodos especiales de Crystal usan esta sintaxis, como el método `+`.

Al igual que con la macro getter, cuando quieras actualizar el valor de una variable de instancia después de definir un setter, puedes llamar al método que ha definido la macro setter.

```crystal
# This:
class Person
  @name : String
  @age : Int32

  def name=(name : String)
    @name = name
  end

  def age=(age : Int32)
    @age = age
  end
end

# Is the same as this:
class Person
  @name : String
  @age : Int32

  setter name, :age
end
```

## Property

Property es una macro que define tanto un getter como un setter para una variable de instancia.

```crystal
class Person
  @name : String
  @age : Int32

  property name, :age
end
```
