# Impresión

Imprimir en Cairo te permite mostrar mensajes y valores en la consola, lo que facilita depurar programas o comunicar información durante la ejecución.

El sistema de impresión es versátil y sencillo a la vez, y ofrece herramientas para dar formato y mostrar datos de distintos tipos.

## Conceptos básicos de la impresión

Cairo proporciona dos macros principales para imprimir texto en la consola:

- **`println!`**: imprime la salida en una línea nueva.
- **`print!`**: imprime la salida en línea, sin agregar una línea nueva.

Ambas macros reciben un `ByteArray` como argumento principal, que puede ser un string simple o un string con formato con marcadores de posición para valores.

```rust
// Printing a simple message
println!("Hello, Cairo!");

// Printing with values
let x = 10;
let y = 20;
println!("Values: x = {}, y = {}", x, y);
```

En el ejemplo anterior:

- Los marcadores de posición `{}` se reemplazan por los valores de `x` y `y`.
- `println!` asegura que la salida termine con una línea nueva.

## Formatear strings

A veces puede que necesites crear un string con formato sin imprimirlo de inmediato.

La macro `format!` te permite hacer esto.

Funciona de forma similar a `println!`, pero devuelve un `ByteArray` en lugar de enviar la salida a la consola.

```rust
let s1: ByteArray = "tic";
let s2: ByteArray = "tac";
let s3: ByteArray = "toe";

// Create a formatted string
let result = format!("{s1}-{s2}-{s3}");

println!("{}", result); // Output: tic-tac-toe
```

En este ejemplo:

- `format!` combina `s1`, `s2` y `s3` en un solo string, separándolos con guiones (`-`).
- El string resultante se puede reutilizar o imprimir después.

## Imprimir tipos de datos personalizados

De forma predeterminada, Cairo solo puede imprimir tipos básicos como enteros y strings.

Si intentas imprimir un tipo personalizado, como un struct, te encontrarás con un error a menos que el tipo implemente los traits `Display` o `Debug`.

### Usar `Display` para formato personalizado

El trait `Display` te permite definir cómo se debe imprimir un tipo personalizado.

Aquí tienes un ejemplo:

```rust
use core::fmt::{Display, Formatter, Error};

struct Point {
    x: u8,
    y: u8,
}

impl PointDisplay of Display<Point> {
    fn fmt(self: @Point, ref f: Formatter) -> Result<(), Error> {
        write!(f, "Point({}, {})", *self.x, *self.y)
    }
}

let p = Point { x: 3, y: 4 };
println!("{}", p); // Output: Point(3, 4)
```

En este ejemplo:

- La función `fmt` define cómo se convierte el struct `Point` en un string que se puede imprimir.
- La macro `write!` agrega el string con formato al `Formatter`.

### Depurar con `Debug`

Para fines de depuración, Cairo proporciona el trait `Debug`.

Puedes derivarlo automáticamente para la mayoría de los tipos, lo que hace que imprimir los detalles internos de tus structs sea rápido y sencillo.

```rust
#[derive(Debug)]
struct Point {
    x: u8,
    y: u8,
}

let p = Point { x: 3, y: 4 };
println!("{:?}", p); // Output: Point { x: 3, y: 4 }
```

En este ejemplo:

- `#[derive(Debug)]` genera automáticamente la implementación del trait `Debug`.
- El marcador de posición `{:?}` le indica a `println!` que use el trait `Debug` para el formato.

## Imprimir en hexadecimal

Cairo permite imprimir enteros en formato hexadecimal usando el marcador de posición `{:x}`.

```rust
let value: u32 = 255;
println!("{:x}", value); // Output: ff
```

Esto es especialmente útil cuando trabajas con representaciones de datos de bajo nivel.
