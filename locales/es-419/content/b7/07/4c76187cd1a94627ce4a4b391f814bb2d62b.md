# Pruebas

En el directorio `t/` hay un script de Perl con la extensión `.t` que se usará para probar tu solución.
Puedes ejecutar las pruebas con el comando:

```bash
`prove`
```

Puedes encontrar documentación sobre las aserciones que se usan en los archivos de prueba en [Test2::Manual::Testing::Introduction][test2-manual].

[test2-manual]: https://metacpan.org/pod/Test2::Manual::Testing::Introduction
