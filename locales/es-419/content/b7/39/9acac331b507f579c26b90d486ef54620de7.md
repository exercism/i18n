# Introducción

En Haxe, las excepciones son una forma segura de manejar los errores que ocurren al ejecutar el código. Todas las excepciones deben contener un mensaje que describa el error. Podemos _lanzar_ excepciones con la palabra clave `throw`:

```haxe
public function main(num:Int) {
  if (num < 10) {
    throw "Argument num cannot be greater than 10";
  }
  // ...
}
```

Cuando se lanza una excepción, el código busca una parte que esté asignada a manejar el error. Si no la encuentra, mostrará el mensaje de error y además detendrá la ejecución del programa.

Para manejar excepciones en Haxe, usamos el bloque `try-catch`. Esta sentencia consta de un bloque `try` y uno o más bloques `catch`. El bloque `try` _intenta_ ejecutar un fragmento de código, mientras que el bloque `catch` espera en caso de que se lance una excepción para _capturarla_, de modo que la ejecución no se detenga. Cuando el bloque `catch` captura una excepción, también ejecuta todo lo que está dentro del bloque:

```haxe
try {
  if (num < 10) {
    throw "Argument num cannot be greater than 10";
  }
} catch (e) {
  // All exceptions will be caught here
  trace(e.message); // Argument num cannot be greater than 10
}
```

El tipo del argumento del bloque `catch` debe omitirse.
