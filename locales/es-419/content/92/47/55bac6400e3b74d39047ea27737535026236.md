# Instrucciones

Se ha abierto un nuevo club de poesía en la ciudad y estás pensando en asistir.
Como ha habido incidentes en el pasado, el club tiene una política de acceso muy específica que tendrás que dominar antes de intentar entrar.

En el club de poesía hay dos puertas y ambas están vigiladas.
Para poder entrar, tendrás que averiguar la contraseña de ese día:

## 1. Divide un string en líneas individuales

Lo primero que debes hacer es dividir el poema en líneas individuales.
El guardia recitará un poema y tú tendrás que dividirlo en líneas.

Implementa la función `splitOnNewlines` que toma un string y lo divide en un array de strings, usando el carácter de salto de línea como delimitador.
La función debe devolver un array de strings, donde cada string es una línea del poema.

```swift
splitOnNewlines("Hello.\nHow are you?\n\nI'm doing fine.")
// returns ["Hello." ,"How are you?", "", "I'm doing fine"].
```

## 2. Puerta principal

1. El guardia recitará un poema.
2. Tendrás que dividir el poema en líneas individuales.
3. Tendrás que obtener la primera letra de cada línea.
   - Si la línea está vacía, debes usar `_` en su lugar.
4. Tendrás que ensamblar las letras, que formarán una palabra.

Por ejemplo, uno de sus escritores favoritos es Michael Lockwood, que escribió el siguiente poema _acróstico_, lo que significa que la primera letra de cada oración forma una palabra:

```text
Stands so high
Huge hooves too
Impatiently waits for
Reins and harness
Eager to leave
```

Cuando el guardia recite el poema, lo dividirás en líneas individuales y responderás con las primeras letras de cada línea, es decir, `["S", "H", "I", "R", "E"]`.

Luego, el guardia te dará la palabra formada por el array de letras con el que respondiste, para que la conviertas en una palabra con la primera letra en mayúscula.
Finalmente, la contraseña que devuelves es `"SHIRE"` y podrás entrar.

Implementa la función `frontDoorPassword` que toma un string que representa el poema.
La función debe devolver la contraseña que le darías al guardia.

```swift
frontDoorPassword("Stands so high\nHuge hooves too\nImpatiently waits for\nReins and harness\nEager to leave")
// returns "SHIRE"
```

## 3. Puerta trasera

En la parte trasera del club encontrarás a los poetas más famosos, algo así como el área VIP.
Como esto no es para todos, el proceso de la puerta trasera es un poco más complicado.

1. El guardia recitará un poema.
2. Tendrás que dividir el poema en líneas.
3. Tendrás que obtener la última letra de cada línea.
   - A veces la línea tendrá espacios al final, así que tendrás que quitarlos.
4. Tendrás que ensamblar las letras y luego agregar `", please"` al final de la palabra formada por las letras.

Por ejemplo, el poema mencionado antes también es _telestiquio_, lo que significa que la última letra de cada oración forma una palabra:

```text
Stands so high
Huge hooves too
Impatiently waits for
Reins and harness
Eager to leave
```

Cuando el guardia recite el poema, lo dividirás en líneas individuales, quitarás cualquier espacio al final y responderás con las primeras letras de cada línea, es decir, `["h", "o", "r", "s", "e"]`.

Luego, el guardia te dará la palabra formada por el array de letras con el que respondiste, para que la conviertas en una palabra con la primera letra en mayúscula y agregues `", please"`.
Finalmente, la contraseña que devuelves es `"horse, please"` y podrás entrar.

Implementa la función `backDoorPassword` que toma un string que representa el poema.
La función debe devolver la contraseña que le darías al guardia.

```swift
backDoorPassword("Stands so high\nHuge hooves too\nImpatiently waits for\nReins and harness\nEager to leave")
// returns "horse, please"
```

## 4. Sala secreta

Dentro de la trastienda del club hay otra puerta que lleva a la sala secreta a la que solo pueden entrar los poetas más destacados.

1. El guardia recitará un poema.
2. Tendrás que dividir el poema en líneas.
3. Tendrás que obtener la i<sup>ésima</sup> letra de la i<sup>ésima</sup> línea.
4. Tendrás que ensamblar las letras y luego agregar `"!"` al final de la palabra formada por las letras.
5. Tendrás que poner la palabra en mayúsculas.

Por ejemplo, una versión modificada del poema mencionado antes sigue este patrón:

```text
Stands so high
Huge hooves too
Impatiently waits for
Rider with harness
Eager to leave
```

Cuando el guardia recite el poema, lo dividirás en líneas individuales, quitarás cualquier espacio al final y responderás con las i<sup>ésimas</sup> letras de cada línea, es decir, ["S", "u", "p", "e", "r"].

Luego, el guardia te dará la palabra formada por el array de letras con el que respondiste, para que la conviertas en una palabra en mayúsculas y agregues `"!"`.
Finalmente, la contraseña que devuelves es `SUPER!` y podrás entrar.

Implementa la función `secretRoomPassword` que toma un string que representa el poema.
La función debe devolver la contraseña que le darías al guardia.

```swift
secretRoomPassword("Stands so high\nHuge hooves too\nImpatiently waits for\nRider with harness\nEager to leave")
// returns "SUPER!"
```
