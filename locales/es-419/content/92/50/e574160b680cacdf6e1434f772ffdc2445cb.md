# Instrucciones

En este ejercicio, necesitas traducir algunas reglas del clásico juego Pac-Man a funciones de Gleam.

Tienes cuatro reglas que traducir, todas relacionadas con los estados del juego.

> No te preocupes por cómo se obtienen los argumentos, solo concéntrate en combinarlos para devolver el resultado esperado.

## 1. Define si Pac-Man se come un fantasma

Define la función `eat_ghost`, que recibe dos argumentos (_si Pac-Man tiene activa una píldora de poder_ y _si Pac-Man está tocando un fantasma_) y devuelve un valor Boolean si Pac-Man puede comerse un fantasma. La función debe devolver `True` solo si Pac-Man tiene activa una píldora de poder y está tocando un fantasma.

```gleam
eat_ghost(False, True)
// -> False
```

## 2. Define si Pac-Man anota puntos

Define la función `score`, que recibe dos argumentos (_si Pac-Man está tocando una píldora de poder_ y _si Pac-Man está tocando un punto_) y devuelve un valor Boolean si Pac-Man anota puntos. La función debe devolver `True` si Pac-Man está tocando una píldora de poder o un punto.

```gleam
score(True, True)
// -> True
```

## 3. Define si Pac-Man pierde

Define la función `lose`, que recibe dos argumentos (_si Pac-Man tiene activa una píldora de poder_ y _si Pac-Man está tocando un fantasma_) y devuelve un valor Boolean si Pac-Man pierde. La función debe devolver `True` si Pac-Man está tocando un fantasma y no tiene activa una píldora de poder.

```gleam
lose(False, True)
// -> True
```

## 4. Define si Pac-Man gana

Define la función `win`, que recibe tres argumentos (_si Pac-Man ha comido todos los puntos_, _si Pac-Man tiene activa una píldora de poder_ y _si Pac-Man está tocando un fantasma_) y devuelve un valor Boolean si Pac-Man gana. La función debe devolver `True` si Pac-Man ha comido todos los puntos y no ha perdido según los argumentos definidos en la parte 3.

```gleam
win(False, True, False)
// -> False
```
