# Instrucciones

En este ejercicio vas a ayudar a gestionar las operaciones diarias de una pequeña panadería usando las estructuras de control de Cairo.

## 1. Calcula el total del pedido

Implementa `calculate_total`, que calcula el costo de un pedido a partir del tipo de producto y la cantidad:

- Croissant: 3 monedas cada uno
- Muffin: 2 monedas cada uno
- Cookie: 1 moneda cada uno

```rust
calculate_total(Pastry::Croissant, 4) // Returns: 12 (4 * 3)
calculate_total(Pastry::Cookie, 10)   // Returns: 10 (10 * 1)
```

## 2. Aplica descuentos por volumen

Implementa `apply_discount`, que aplica descuentos según el total del pedido.
Aplica el descuento porcentual al total y luego redondea hacia abajo a la moneda entera más cercana (floor).

- Pedidos ≥ 20 monedas: 10 % de descuento
- Pedidos ≥ 10 monedas: 5 % de descuento
- Pedidos < 10 monedas: sin descuento

```rust
apply_discount(25) // Returns: 22
apply_discount(15) // Returns: 14
apply_discount(8)  // Returns: 8
```

## 3. Crea el horario de horneado

Implementa `baking_schedule`, que crea un plan diario de horneado.
La panadería hornea en lotes de 5 pedidos por hora:

```rust
baking_schedule(18) // Returns: [5, 5, 5, 3] (3 full batches + 3 remaining)
baking_schedule(10) // Returns: [5, 5] (2 full batches)
baking_schedule(3)  // Returns: [3] (1 partial batch)
```

Usa las estructuras de control adecuadas (`if`/`else`, `loop`) para resolver cada problema de forma eficiente.
