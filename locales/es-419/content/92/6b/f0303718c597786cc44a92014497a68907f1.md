# Pistas

## 1. Verifica que el comando sea válido

- Usa la expresión [test][regex-test] para devolver un Boolean.
- Recuerda que puedes usar el argumento [flags][flags] para características adicionales, como ignorar mayúsculas y minúsculas.

## 2. Elimina los emojis cifrados

- Gracias a que todos los emojis se cifran de la misma forma, puedes usar `[0-9]` para buscar cualquier dígito después de la palabra `emoji`.
- El carácter `+` coincide con uno o más elementos consecutivos.
- Usa el método [gsub][regex-gsub] para reemplazar cada emoji con un string vacío.

## 3. Verifica que el número de teléfono sea válido

- Este [artículo][phone-validation] explica muy bien distintas formas de validar un número de teléfono.
- Usa el filtro `test` para verificar si el número de teléfono es válido o no.
- Devuelve la respuesta final con una expresión `if-then-else`.

## 4. Obtén el enlace del sitio web

- Estamos buscando palabras que están unidas por uno o más `.`.
- Puedes usar el filtro [match][regex-match] con el flag `g`.
- El filtro [scan][regex-scan] podría ser más fácil de usar.

## 5. Saluda al usuario

- Usar [grupos de captura con nombre][named-capture] resulta útil para reutilizar el texto que coincide.
- El filtro [capture][regex-capture] es ideal para referirte al grupo con nombre.

## 6. Análisis de CSV muy sencillo

- Aquí queremos usar [split][regex-split] porque conocemos el delimitador.
- El patrón es «coma seguida de cero o más espacios en blanco».
- Tienes que usar el filtro `split` de **aridad 2**; no hay que especificar ningún flag.
