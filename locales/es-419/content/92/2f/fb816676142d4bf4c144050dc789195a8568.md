# El tipo Boolean

En Cairo, el tipo Boolean es esencial para las operaciones lógicas y las sentencias condicionales.
Los Boolean en Cairo ocupan un `felt252`, lo que garantiza un uso eficiente del espacio y mantiene la simplicidad de la lógica verdadero/falso.

El tipo Boolean en Cairo se especifica con la palabra clave `bool`.
Esto permite declarar y manipular variables Boolean dentro del lenguaje.
Por ejemplo, considera el siguiente ejemplo:

```rust
fn main() {
    let t = true;
    let f: bool = false; // with explicit type annotation
}
```

En este ejemplo, se declaran dos variables Boolean.
A la variable `t` se le asigna el valor `true` y se declara implícitamente como tipo Boolean, mientras que la variable `f` se anota explícitamente con el tipo `bool` y se le asigna el valor `false`.

Un aspecto importante que hay que tener en cuenta es que, al declarar una variable Boolean en Cairo, es obligatorio usar los literales `true` o `false` como valor.
Esto significa que los literales enteros, como `0` o `1`, no se pueden usar como sustitutos de `false` o `true`.
La aplicación estricta de esta regla garantiza la seguridad de tipos y evita posibles errores lógicos en el desarrollo de contratos inteligentes.

## Operadores Boolean en Cairo

- `||` (OR lógico): Devuelve `true` si al menos uno de los operandos es `true`.
- `&&` (AND lógico): Devuelve `true` si ambos operandos son `true`.
- `!` (NOT lógico): Devuelve el valor Boolean opuesto del operando.

## Código de ejemplo

El siguiente fragmento de código muestra cómo usar los tipos Boolean en Cairo.
Muestra la declaración de variables Boolean, la asignación de expresiones Boolean y el uso de aserciones para verificar la corrección de la lógica Boolean:

```rust
fn main() {
    // Declaration of Boolean variables
    let t: bool = true;
    let f: bool = false;

    // Boolean expression evaluation
    let true_expr = 5 == 5; // true
    let false_expr = 7 == 5; // false

    // Using Boolean operators
    let or_expr = t || f; // true || false => true
    let and_expr = t && f; // true && false => false
    let not_expr = !f; // !false => true

    // Assertions to verify the correctness
    assert(t == true_expr, 'this should be true'); // t == true
    assert(f == false_expr, 'this should be false'); // f == false
    assert(or_expr == true, 'this should be true for OR'); // true
    assert(and_expr == false, 'this should be false for AND'); // false
    assert(not_expr == true, 'this should be true for NOT'); // true
}
```
