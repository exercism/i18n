# Instrucciones

Estás en la caseta de radio costera, monitoreando el parloteo del canal:
los mensajes llegan por el aire, tú los registras y envías las respuestas
de vuelta. Cinco palabritas hacen el trabajo de un turno completo.

Las pruebas te pasan entradas de `<string-reader>` (tráfico entrante)
y usan `<string-writer>` para lo saliente. Pero cada palabra de aquí
funciona igual contra un `<file-reader>` real o un socket.

## 1. Escúchalo todo

Define `hear-out` para vaciar un flujo de entrada en una sola cadena.

```factor
"all quiet on the channel" <string-reader> hear-out .
! => "all quiet on the channel"
```

## 2. Cuenta los mensajes

Define `count-messages` para leer cada línea de un flujo de entrada
y devolver cuántas había.

```factor
"alpha\nbravo\ncharlie\n" <string-reader> count-messages .
! => 3
```

## 3. Devuelve el eco de la última llamada

Define `echo-back` para leer cada línea y devolver la **última
en mayúsculas**: la respuesta estándar de radio «dijiste X».

```factor
"alpha\nbravo\n" <string-reader> echo-back .
! => "BRAVO"
```

## 4. Transmite un mensaje

Define `broadcast` para escribir un mensaje en un writer determinado
y vaciar el flujo para que salga de inmediato. No devuelve nada.

```factor
[ "mayday" output-stream get broadcast ] with-string-writer .
! => "mayday"
```

## 5. Captura la salida de una quotation

Define `capture` para ejecutar una quotation con un string-writer
nuevo como salida ambiente, y devolver lo que sea que la quotation
haya imprimido. La quotation no toma ningún argumento: solo
escribe en el flujo ambiente como siempre.

```factor
[ "test broadcast" print ] capture .
! => "test broadcast\n"
```
