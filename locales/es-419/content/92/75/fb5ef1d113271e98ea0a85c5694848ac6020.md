# Tests

Para ejecutar los tests, ejecuta el comando `v test .` desde el directorio del ejercicio.

Si quieres ver todos los tests que se ejecutaron junto con estadísticas de velocidad, usa `v -stats test .`

Para más información sobre cómo hacer tests en V, consulta [la documentación](https://github.com/vlang/v/blob/master/doc/docs.md#testing).
