# Sitio web de un equipo de baloncesto

## Historia

Estás trabajando en un sitio web para un equipo de baloncesto. El sitio web muestra muchos datos, pero, por desgracia, lo que se muestra cambia con frecuencia. Como los datos están guardados en un solo objeto, esto no es difícil de hacer, pero lleva tiempo y es aburrido. Por eso decidiste automatizar las cosas.

## Tareas

Estos son ejemplos de tareas que encajan con la historia de automatizar el sitio web:

- Tu objetivo es permitir que el equipo de contenido seleccione por sí mismo qué datos mostrar. Lo harán especificando una ruta a los datos que se mostrarán en el editor de contenido del sitio web. Tu tarea es crear una función extract que reciba un objeto y una ruta, separados por el carácter punto. Devuelve el valor que está en esa ruta, o un valor predeterminado.

## Tareas adicionales

La historia puede continuar, por ejemplo:

- El equipo de contenido está muy entusiasmado con esta nueva funcionalidad y ya ha pedido que se agregue una nueva funcionalidad. Les gustaría poder mostrar datos de elementos específicos dentro de un array.
