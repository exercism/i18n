# Instrucciones

Leslie, el alienígena de Lisp, necesita hacer unas compras. Es muy importante tener una lista de compras. Hay que agregarle cosas y quitarle cosas.

Claro que un simple lápiz y papel no sirven para un alienígena de Lisp. ¡Si hasta «list» es casi toda la palabra «Lisp»! Tienen que haber funciones escritas que ayuden a llevar el control de las compras.

¿Puedes ayudar a Leslie a llevar el control de la lista de compras?

## 1. Crear una lista nueva

Lo primero es que Leslie necesita crear una lista vacía. Una función llamada `new-list` sería perfecta para eso.

```lisp
(new-list) ; => ()
```

Ay no... Leslie ya tiene algunas cosas en mente, así que necesita una función que tome tres cosas (por suerte Leslie solo crea una lista de tres cosas. ¡Ni más ni menos!) y que cree una nueva lista de compras con esas cosas. Escribe una función, `list-of-things`, que tome tres cosas y devuelva una lista con ellas.

```lisp
(list-of-things 'bread 'milk 'butter) ; => '(bread milk butter)
```

## 2. Agregar cosas a la lista

Antes de ir a la tienda, Leslie revisa la despensa para ver qué necesita. Ayúdale escribiendo la función `add-to-list`, que agrega un elemento al principio de una lista.

```lisp
(add-to-list 'butter '(bread)) ; => '(butter bread)
```

## 3. ¿Qué sigue en la lista?

Mientras compra, Leslie quiere saber qué buscar después. También le gusta echar un vistazo a la lista para ver la segunda, la tercera o incluso la vigésima tercera cosa (su número de la suerte).

- `first-thing` se evalúa como la primera cosa de la lista
- `second-thing` se evalúa como la segunda cosa
- `third-thing` se evalúa como la tercera cosa
- `twenty-third-thing` se evalúa como la vigésima tercera cosa

```lisp
(first-thing '(bread butter milk)) ; => 'bread
(second-thing '(bread butter milk)) ; => 'butter
(third-thing '(bread butter milk)) ; => 'milk
```

## 4. Quitar una cosa de la lista

Leslie quiere encontrar la primera cosa de la lista y quitarla del estante.
Ayúdale escribiendo una función `remove-first-item` que se evalúe como una lista con todo menos la primera cosa de la lista que recibe.

```lisp
(remove-first-item '(bread butter milk)) ; => '(butter milk)
```

## 5. Listas más grandes a partir de listas más pequeñas

¡Leslie se dio cuenta de que por accidente hizo dos listas de compras, no una! Escribe una función, `list-append`, que devuelva una lista con los elementos de la primera lista seguidos por los de la segunda.

```lisp
(list-append '(bread salt) '(butter milk)) ; => '(bread salt butter milk)
```

## 6. ¿Cuánto más falta?

Leslie está empezando a preocuparse de que esta ida a la tienda tome un buen rato. ¿Cuántas cosas hay en esta lista, exactamente? Escribe una función `just-how-long` que le diga qué tan larga es su lista.

```lisp
(just-how-long '(bread milk butter salt)) ; => 4
```
