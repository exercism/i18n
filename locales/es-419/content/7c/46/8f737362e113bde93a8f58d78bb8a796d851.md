# Introducción

Las variables que se declaran con la palabra clave `final` en lugar de `var` solo pueden recibir un valor una vez.

```haxe
final a = "hello";
var b = "world";
trace(a, b); // hello, world
b = "haxe";
trace(a, b); // hello, haxe

// The following line would cause a compilation error:
// a = "bye";
```
