# Pistas

## General

- Hay varias funciones disponibles para expresiones booleanas en la biblioteca estándar. Puedes verlas en el espacio de nombres `Boolean` en [Unison share](https://share.unison-lang.org/@unison/code/latest/namespaces/public/base/latest/;/types/Boolean).
- La habilidad Each te permite operar sobre una lista de elementos como si fuera un solo elemento, aplicando la función deseada a «cada» elemento. También se puede usar para crear combinaciones de elementos, llamando a Each sobre dos listas diferentes.
- Echa un vistazo a la [función `guard` en `Each`](https://share.unison-lang.org/@unison/code/latest/namespaces/public/base/latest/;/types/abilities/Each). Puede ser útil cuando quieres devolver algo de forma condicional desde la habilidad `Each`.
- Dado el número de combinaciones únicas posibles para este problema, es probable que te topes con problemas de complejidad de espacio o de tiempo. Hay bastantes mecanismos para optimizar la búsqueda. Echa un vistazo a los algoritmos de [backtracking](https://www.geeksforgeeks.org/backtracking-algorithms/) o de [branch and bound](https://www.geeksforgeeks.org/branch-and-bound-algorithm/?ref=lbp).
