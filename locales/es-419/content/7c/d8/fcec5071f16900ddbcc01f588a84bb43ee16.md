# Instrucciones

En este ejercicio vas a escribir un poco más de código relacionado con preparar y cocinar tu brillante lasaña de tu libro de cocina favorito.

Tienes cinco tareas.
La primera está relacionada con la cocción en sí, y las otras cuatro con la preparación perfecta.

## 1. Determina si la lasaña está lista

Cuando tienes una lasaña en el horno, quieres saber si ya puedes sacarla o no.
Para asegurarte de que la lasaña no se queme en el horno, normalmente pones un temporizador.
Pero a veces se te olvida.

Escribe una función `cookingStatus` que acepte como parámetro el tiempo restante del temporizador en minutos.
La función tiene tres resultados posibles.

- Si el temporizador muestra `0`, debe devolver `'Lasagna is done.'`.
- Si el temporizador muestra cualquier otro número, el resultado debe ser `'Not done, please wait.'`.
- Si se llama a la función sin un valor de temporizador, el resultado debe ser `'You forgot to set the timer.'`.

El temporizador nunca mostrará un valor menor que 0.

```javascript
cookingStatus(12);
// => 'Not done, please wait.'

cookingStatus();
// => 'You forgot to set the timer.'
```

## 2. Calcula el tiempo de preparación

Para la próxima lasaña que prepares, quieres asegurarte de reservar suficiente tiempo para poder disfrutar de la cocción.
Ya hiciste un plan con todas las capas que tendrá tu lasaña.
Ahora quieres calcular cuánto tardará la preparación a partir de eso.

Implementa una función `preparationTime` que acepte un array de capas y el tiempo promedio de preparación por capa en minutos.
La función debe devolver la estimación del tiempo total de preparación según el número de capas.
Si se llama a la función sin proporcionar el tiempo promedio de preparación, se deben asumir `2` minutos en su lugar.

```javascript
const layers = ['sauce', 'noodles', 'sauce', 'meat', 'mozzarella', 'noodles'];
preparationTime(layers, 3);
// => 18

preparationTime(layers);
// => 12
```

## 3. Calcula las cantidades necesarias de fideos y salsa

Además de reservar el tiempo, también quieres asegurarte de tener suficiente salsa y fideos para cocinar la lasaña de tus sueños.
Por cada capa de fideos en tu lasaña, necesitarás 50 gramos de fideos.
Por cada capa de salsa en tu lasaña, necesitarás 0.2 litros de salsa.

Define la función `quantities` que toma un array de capas como parámetro.
La función determinará entonces la cantidad de fideos y salsa necesaria para preparar tu comida.
El resultado debe devolverse como un objeto con las claves `noodles` y `sauce`.

```javascript
quantities(['sauce', 'noodles', 'sauce', 'meat', 'mozzarella', 'noodles']);
// => { noodles: 100, sauce: 0.4 }
```

## 4. Agrega el ingrediente secreto

Hace un tiempo visitaste a un amigo y comiste lasaña en su casa.
Estaba increíble y tenía algo especial.
Tu amigo te envió la lista de ingredientes y te dijo que el último elemento de la lista es el «ingrediente secreto» que hizo que la comida fuera tan especial.
Ahora quieres agregar ese ingrediente secreto también a tu receta.

Escribe una función `addSecretIngredient` que acepte dos arrays de ingredientes como parámetros.
El primer parámetro es la lista que te envió tu amigo y el segundo es la lista de ingredientes de tu propia receta.
La función debe agregar el último elemento de la lista de tu amigo al final de tu lista.
El array que representa tu receta debe modificarse directamente y la función no debe devolver nada.
Sin embargo, el primer argumento no debe modificarse.

```javascript
const friendsList = ['noodles', 'sauce', 'mozzarella', 'kampot pepper'];
const myList = ['noodles', 'meat', 'sauce', 'mozzarella'];

addSecretIngredient(friendsList, myList);
// => undefined

console.log(myList);
// => ['noodles', 'meat', 'sauce', 'mozzarella', 'kampot pepper']
```

## 5. Escala la receta

Las cantidades que aparecen en tu libro de cocina solo alcanzan para dos porciones de lasaña.
Como la próxima vez quieres cocinar para más personas, quieres calcular las cantidades para distintos números de porciones.

Implementa una función `scaleRecipe` que tome dos parámetros.

- Un objeto de receta que contiene las cantidades necesarias para 2 porciones.
  El formato del objeto se puede ver en el ejemplo de abajo.
- El número de porciones que quieres cocinar.

La función debe devolver un objeto de receta con las cantidades necesarias para el número de porciones deseado.
Pero quieres conservar la receta original.
Esto significa que, en esta tarea, el argumento de la receta no debe modificarse.

```javascript
const recipe = {
  noodles: 200,
  sauce: 0.5,
  mozzarella: 1,
  meat: 100,
};

scaleRecipe(recipe, 4);
// =>
// {
//   noodles: 400,
//   sauce: 1,
//   mozzarella: 2,
//   meat: 200,
// };

console.log(recipe);
// =>
// {
//   noodles: 200,
//   sauce: 0.5,
//   mozzarella: 1,
//   meat: 100,
// };
```
