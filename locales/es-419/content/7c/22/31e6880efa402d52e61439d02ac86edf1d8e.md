# Promoción de propiedades en el constructor

En las clases que declaran muchas propiedades, declarar por separado la clase, sus propiedades y un constructor que las asigne obliga a repetir código.
Con la promoción de propiedades en el constructor podemos reducir esa repetición.

```php
<?php

class Book
{
    private string $isbn;
    private string $doi;
    private string $title;

    public function __construct(string $isbn, string, $doi, string $title)
    {
        $this->isbn = $isbn;
        $this->doi = $doi;
        $this->title = $title;
    }
}

// Using constructor property promotion
class Book
{
    public function __construct(
        private string $isbn,
        private string $doi,
        private string $title
    ) {
    }
}
