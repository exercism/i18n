# Para quienes mantienen

## Generación de pruebas: `bin/generate_tests.py`

Los archivos de prueba se generan a partir de los datos canónicos de
[exercism/problem-specifications](https://github.com/exercism/problem-specifications)
usando una plantilla de Jinja guardada en cada ejercicio en `.meta/template.j2`.

```bash
bin/generate_tests.py bob            # regenerate one exercise
bin/generate_tests.py                # regenerate every exercise that has a template
bin/generate_tests.py --no-pull bob  # skip `git pull` of problem-specifications
```

El script lee problem-specifications de la caché de configlet
(`~/.cache/exercism/configlet/problem-specifications`, que llena `bin/configlet sync`),
o de un directorio padre llamado `problem-specifications`.
Solo se generan los casos incluidos en `.meta/tests.toml`.

Los literales de string de Fortran no pueden contener escapes como `\n` y `\t`.
El filtro de plantilla `escape_quote_whitespace` los reescribe como
`" // NEWLINE // "`, `" // TAB // "` y `" // CARRIAGE_RETURN // "`,
así que la plantilla debe declarar esas constantes (ver `exercises/practice/bob/.meta/template.j2`).

### Requisitos previos

- CMake y un compilador de Fortran que funcionen
- Python 3.12+ con `jinja2`
- git

### Flujo de trabajo para agregar un ejercicio nuevo

Usando `bob` como ejemplo:

- Crea una rama nueva, por ejemplo `git checkout -b exercise-bob`
- Ejecuta `bin/add-exercise bob` (necesita `jq` y `curl`). Esto:
  - descarga configlet y ejecuta `configlet create`, que agrega el ejercicio a `config.json` y sincroniza su documentación, metadatos y `tests.toml` desde problem-specifications
  - ordena `config.json` con `bin/reorder-exercises`
  - copia `exercises/shared/CMakeLists.txt` al directorio del ejercicio
  - escribe una solución esqueleto, un `.meta/example.f90` esqueleto y un `.meta/template.j2` inicial (a partir de `exercises/shared/template.j2`)

  Te pide tu nombre de usuario de GitHub a menos que pases `-a <username>`, y establece la dificultad en 1 a menos que pases `-d <difficulty>`.

- Edita `.meta/template.j2` para que cada caso llame a la función correcta con los argumentos correctos, y luego genera las pruebas:

  ```bash
  bin/generate_tests.py bob
  ```

- Escribe una solución que funcione en `.meta/example.f90`. Reemplaza el archivo del estudiante (por ejemplo, `bob.f90`) con un esqueleto de las funciones o subrutinas que llaman las pruebas, para ayudar al estudiante a empezar
- Asegúrate de que todas las pruebas pasen, ejecutando la compilación completa desde la raíz del repositorio:

  ```bash
  mkdir -p build && cd build
  cmake ..
  cmake --build .
  ctest -V -R bob
  ```

- Ejecuta `bin/reorder-exercises` y `bin/configlet lint`
- Si todo pasa, abre un pull request con tus cambios

### Cómo cambiar `CMakeLists.txt`

Cuando cambies el archivo de cmake, actualiza la copia maestra en `exercises/shared/` y usa `bin/update-cmake-files` para copiarla a todos los directorios de ejercicios.
