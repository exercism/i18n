# Acerca de

C# es un lenguaje de tipado estático, lo que significa que todo tiene un tipo en tiempo de compilación. Elegir un nombre para una [variable][variable] se conoce como definir una variable. Una vez que se define una variable, asignarle o actualizarle un valor se llama asignación de variable. Una variable se puede definir especificando explícitamente su tipo o usando la [palabra clave `var`][var] para que el compilador de C# infiera su tipo a partir del valor asignado. El uso de `var` se conoce como _inferencia de tipos_.

```csharp
int explicitVar = 10; // Explicitly typed
var implicitVar = 10; // Implicitly typed
```

El valor de una variable se puede asignar y actualizar usando el [operador `=`][assignment]. Una vez definida, el tipo de una variable nunca puede cambiar.

```csharp
var count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning different type
// count = false;
```

C# es un lenguaje orientado a objetos y requiere que todas las [funciones][function] se definan dentro de una _clase_, las cuales se definen usando la [palabra clave `class`][classes]. Los objetos (o _instancias_) se crean usando la palabra clave `new`.

```csharp
class Calculator
{
    // ...
}

var calculator = new Calculator();
```

Una función dentro de una clase se conoce como _método_. Cada [método][methods] puede tener cero o más parámetros. Todos los parámetros deben tener un tipo explícito; no hay inferencia de tipos para los parámetros. De manera similar, el tipo de retorno también debe ser explícito. Los valores se devuelven desde los métodos usando la [palabra clave `return`][return]. Para permitir que el código en otros archivos llame a un método, se debe agregar el modificador de acceso `public`.

```csharp
class Calculator
{
    public int Add(int x, int y)
    {
        return x + y;
    }
}
```

Los métodos se invocan usando la sintaxis de punto (`.`) sobre una instancia, especificando el nombre del método que se va a llamar y pasando argumentos para cada uno de los parámetros del método. Los argumentos pueden especificar de forma opcional el nombre del parámetro correspondiente.

```csharp
var calculator = new Calculator();
var sum_v1 = calculator.Add(1, 2);
var sum_v2 = calculator.Add(x: 1, y: 2);
```

Si el método al que se quiere llamar está definido en la misma clase que el método que lo llama, se puede omitir el nombre de la clase.

Si un método no usa ningún _estado_ del objeto, el método se puede declarar como _estático_ usando el modificador `static`. Los métodos estáticos también se invocan usando la sintaxis de punto (`.`), pero se invocan sobre la clase misma en lugar de sobre una instancia de la clase.

Si una clase solo tiene métodos estáticos, ella también se puede declarar como estática usando el modificador `static`. Esto expresa la intención de la clase.

```csharp
static class Calculator
{
    public static int Multiply(int x, int y)
    {
        return x * y;
    }
}

Calculator.Multiply(2, 4); // => 8
```

El ámbito en C# se define entre los caracteres `{` y `}`.

C# admite dos tipos de [comentarios][comments]. Los comentarios de una sola línea van precedidos por `//` y los comentarios de varias líneas se insertan entre `/*` y `*/`.

Los valores enteros se definen como uno o más dígitos (consecutivos) y admiten los [operadores matemáticos predeterminados][operators].

Un nombre de variable [debe seguir algunas reglas][identifier-names], como empezar por una letra o un guion bajo, y [debe seguir las convenciones de nomenclatura de C#][naming-guidelines]. Si un nombre de variable coincide con una [palabra clave reservada de C#][csharp-keywords], se debe escapar usando `@`. No se recomienda usar esa notación, pero se puede encontrar en casos excepcionales, por ejemplo: `var @this`, `var @class` o `var @var`.

Hay un par de conceptos tan fundamentales para un lenguaje de la familia C como C# que aparecen de forma natural en casi cualquier fragmento de código no trivial. Estos son la [mutación][mutation] y el [ámbito][scope]. La mutación es la idea de que el valor de una variable puede cambiar a lo largo de la vida de un programa. El ámbito es la idea de que el valor asociado a un nombre (de un elemento del programa) solo es accesible dentro del «área» de código donde se define. Las principales áreas de código en C# son _clase/struct_ y _función_ (normalmente métodos), pero también pueden incluir los cuerpos de bucles y otras construcciones.
