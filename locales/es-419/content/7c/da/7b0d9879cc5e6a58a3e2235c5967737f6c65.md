# Introducción

Un parámetro de método se puede volver opcional si se le asigna un valor predeterminado. Cuando se llama a un método con parámetros opcionales, quien llama no necesita pasarles un valor. Si no se pasa ningún valor para un parámetro opcional, se usará su valor predeterminado.

Los parámetros opcionales deben estar al final de la lista de parámetros; no pueden ir seguidos de parámetros no opcionales.

```haxe
class Card {
  static function newYear(year = 2021):String {
    return "Happy " + year;
  }
}

Card.newYear(); // Happy 2020
Card.newYear(1990); // Happy 1990
```

El parámetro opcional se puede establecer en `null` usando el operador `?` antes del nombre de la variable:

```haxe
function newYear(?year:Int) {
  if (year != null)
    return "It's " + year;
  return "Year is null";
}

newYear(); // Year is null
```
