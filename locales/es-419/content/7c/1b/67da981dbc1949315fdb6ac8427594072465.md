# Pistas

Todas estas tareas requieren dividir la línea de registro en partes separadas.

- Consulta la función [`split()`][split] para ver las opciones.

## 1. Obtén el mensaje de una línea de registro

- La función `split()` devuelve un vector de strings.
- Necesitas obtener el elemento adecuado de este vector.
- Los espacios en blanco al inicio y al final se pueden eliminar con [`strip()`][strip].

## 2. Obtén el nivel de registro de una línea de registro

- La función [`lowercase()`][lowercase] es útil aquí.
- Se puede indexar una string ASCII con un rango.
- El índice `end` se refiere al último elemento de un vector.
- Como alternativa, puedes resolver la tarea usando [`replace()`][replace] para eliminar los caracteres que no quieras.

## 3. Reformatea una línea de registro

- La [interpolación][interpolation] de strings es quizás el enfoque más sencillo aquí.
- Como alternativa, algunas personas (con experiencia en otros lenguajes) pueden preferir [`@sprintf()`][sprintf].
