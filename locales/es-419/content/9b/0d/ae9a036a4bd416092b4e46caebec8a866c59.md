# Instrucciones

La oficina de objetos perdidos de la escuela guarda todo en cajas, y lo que va en una caja puede ser cualquier cosa: un suéter, una cantidad de cosas, un nombre.

Escribe una clase `LOST_BOX{T}`. El esqueleto te da el encabezado de la clase.

## 1. Recibe algo

`create` toma la cosa y el nombre de quien la entregó, y devuelve una caja. Una caja empieza sin reclamar.

```sather
box ::= #LOST_BOX{STR}("blue jumper", "Mia");
box.item
-- => "blue jumper"
box.handed_in_by
-- => "Mia"
box.claimed
-- => false
```

## 2. Reclámala

`claim` marca la caja como reclamada. No devuelve nada.

```sather
box.claim;
box.claimed
-- => true
```

## 3. ¿Sigue esperando?

`waiting` responde si la caja no ha sido reclamada.

```sather
box.waiting
-- => false
```

## 4. Reemplaza el contenido

`replace` toma una cosa nueva, la pone en la caja y devuelve lo que había antes. La cosa que entra y la cosa que sale son ambas `T`.

```sather
old ::= box.replace("red jumper");
old
-- => "blue jumper"
box.item
-- => "red jumper"
```

## 5. Redáctalo

`describe` devuelve una línea sobre la caja, como `"blue jumper, handed in by Mia"`.

Para poner el artículo en un string, la clase necesita saber que un `T` se puede convertir en uno. Restringe el parámetro: escribe el encabezado de la clase como `class LOST_BOX{T < $STR}`, y entonces `item.str` sí está permitido.

```sather
box.describe
-- => "blue jumper, handed in by Mia"
```
