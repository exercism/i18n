## MacOS

Primero instala Lua y [Luarocks][2] usando [Homebrew][1]:

```shell
$ brew install lua luarocks
```

Luego instala el framework de pruebas [Busted][3] para Lua:

```shell
$ luarocks install --local busted
```

Agrega `~/.luarocks/bin` al `$PATH` de tu sistema

```shell
export PATH="$HOME/.luarocks/bin:$PATH"
```

Ten en cuenta que esto es solo temporal.
Para agregarlo de forma permanente a tu `$PATH`, tendrás que añadirlo a tu `.bashrc`, `.zshrc` o `config.fish`, según el shell que uses.

Luego ejecuta tus pruebas:

```shell
$ busted
```

## Ubuntu

Primero instala Lua y [Luarocks][2] usando [Apt][6]:

```shell
$ sudo apt-get install lua5.4 liblua5.4-dev luarocks
```

Luego instala el framework de pruebas [Busted][3] para Lua:


## Windows 10: WSL

Primero debes habilitar [WSL (subsistema de Windows para Linux)][7] usando [PowerShell][8] (Administrador):

```shell
PS> Enable-WindowsOptionalFeature -Online -FeatureName Microsoft-Windows-Subsystem-Linux
```

Esto requiere un reinicio.

Luego, instala Ubuntu desde la [Microsoft Store][9], **o** descárgalo e instálalo usando PowerShell:

```shell
PS> curl.exe -L -o ubuntu1804.appx https://aka.ms/wsl-ubuntu-1804
PS> Add-AppxPackage .\ubuntu1804.appx; rm .\ubuntu1804.appx
PS> ubuntu1804
```

Luego actualiza tu lista de paquetes:

```shell
PS> wsl
$ sudo apt-get update
```

Ahora ya puedes instalar [LuaRocks][2] y [Busted][3] siguiendo las [instrucciones para Ubuntu](#ubuntu) de arriba.

Una vez hecho esto, puedes ejecutar tus pruebas directamente desde cualquier línea de comandos de Windows:

```cmd
C:\> wsl busted
```

## Windows 10: Docker

### Instalar Gitbash

Este paso es opcional. Es posible que tengas que ajustar ligeramente los siguientes pasos si prefieres usar la CLI nativa de Windows u otra CLI.

Descárgalo [aquí][10].
Instrucciones de instalación [aquí][11].

### Instalar Docker

Sigue las instrucciones para instalar [Docker for Windows][12].
Una vez que hayas terminado de instalar, puedes ejecutar el siguiente comando para asegurarte de que se instaló correctamente.

```shell
$ docker --version
```

_Es posible que encuentres un error la primera vez que intentes ejecutar Docker._

`cannot enable hyper-v service`

_Si esto ocurre, puedes seguir estas instrucciones para [habilitar Hyper V][13]. Es posible que tengas que desactivar la configuración, reiniciar tu computadora y volver a activarla después del arranque._

### Instalar busted

Una vez que tengas Gitbash y Docker instalados, podrás instalar un «contenedor» de busted.

En Gitbash, ejecuta lo siguiente:

Descarga este contenedor de Docker ampliamente usado ejecutando lo siguiente:

```shell
$ docker pull imega/busted
```

Crea una función para no tener que escribir el comando completo cada vez.
Agrega esto a tu `.bashrc`:

```shell
dbusted() { docker run --rm -t -v "/$@":/data imega/busted; }
```

Ahora, en tu CLI, puedes navegar hasta el directorio en el que quieres ejecutar tus pruebas. Ejecuta lo siguiente:

```shell
$ dbusted $PWD
```

Deberías ver la salida de tus pruebas de busted.
