# Instrucciones

Refactoriza un analizador de Markdown.

El ejercicio de Markdown es un ejercicio de refactorización.
Hay código que analiza una cadena dada con [sintaxis de Markdown][markdown] y devuelve el HTML asociado a esa cadena.
Aunque este código está escrito de forma confusa y es difícil de seguir, de alguna manera funciona y ¡todas las pruebas pasan!
Tu reto consiste en reescribir este código para que sea más fácil de leer y mantener, sin dejar de asegurarte de que todas las pruebas sigan pasando.

Te sería útil anotar en comentarios lo que hiciste en la refactorización, para que quienes revisen puedan verlo, pero no es estrictamente necesario.
¡Lo más importante es mejorar el código!

[markdown]: https://guides.github.com/features/mastering-markdown/
