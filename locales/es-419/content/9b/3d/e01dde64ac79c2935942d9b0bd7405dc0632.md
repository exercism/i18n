# Anexo de instrucciones

## Pistas

Para completar este ejercicio necesitas implementar la función `wordCount`,
que recibe un *texto* y devuelve cuántas veces aparece cada *palabra*.

Si es tu primera vez resolviendo este ejercicio, te recomendamos que te
ciñas a la firma que te damos:

```haskell
wordCount :: String -> [(String, Int)]
```

Más adelante, puede ser buena idea volver a este problema y experimentar con
otros tipos de datos y bibliotecas:

- `Text`, del paquete *text*.
- `Map`, del paquete *containers*.
- `MultiSet`, del paquete *multiset*

La suite de pruebas se diseñó a propósito para aceptar casi cualquier firma de
tipo que tenga sentido, así que te animamos a encontrar la que creas que es la
mejor.
