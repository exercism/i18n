# Ayuda

Si tienes problemas y necesitas ayuda, puedes usar uno de los siguientes recursos:

- [Crystal API](http://crystal-lang.org/api/)
- [r/crystal_programming/](https://www.reddit.com/r/crystal_programming/) es el subreddit de Crystal.
- [StackOverflow](https://stackoverflow.com/questions/tagged/crystal-lang) lo puedes usar para buscar tu problema y ver si ya lo respondieron. También puedes hacer y responder preguntas.
- [Crystal Forum](https://forum.crystal-lang.org/) es el foro oficial de Crystal.
