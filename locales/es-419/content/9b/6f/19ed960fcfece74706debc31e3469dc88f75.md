# Acerca de

En PHP, puedes llamar a una variable como función si le aplicas paréntesis [`()`]. Cuando PHP intenta llamar a la función, buscará una función con el mismo nombre que el valor de la variable.

```php
function foo(): string
{
    return "foo() invoked";
}

$func = 'foo';
$func(); // This calls foo()
```

## Llamar a funciones estáticas de clase

Las funciones estáticas de clase se pueden llamar de la misma manera:

```php
class Rocket
{
    public static function launch()
    {
        return '3, 2, 1, Liftoff!';
    }
}

$func = 'Rocket::launch';
$func(); // This calls Rocket::launch()
```

## Llamar a funciones de instancia de clase

También es posible llamar a la función de una instancia de clase:

```php
class Rocket
{
    public function openDoor()
    {
        return 'Door open.';
    }
}

$rocket = new Rocket();
$func = [$rocket, 'openDoor'];
$func(); // This calls Rocket::openDoor()
```
