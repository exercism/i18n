# Evita la función init

Evita usar la función `init`:
1) Hace más lento el arranque y quien usa el paquete no puede hacer nada al respecto, aparte de quitar la función `init`.
2) Usar la función `init` sirve sobre todo para inicializar `global variables`.
El estado global [se debe evitar](https://dave.cheney.net/practical-go/presentations/qcon-china.html#_avoid_package_level_state) cuando sea posible.
