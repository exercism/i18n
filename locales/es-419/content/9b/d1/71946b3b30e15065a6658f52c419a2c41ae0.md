## Conoce «Hello, World!»

«Hello, World!» es probablemente el programa más famoso del mundo.
Prácticamente cualquiera que haya aprendido a programar lo ha escrito al menos una vez.
Su sencillez y su mensaje amistoso suelen significar el primer paso hacia el maravilloso mundo de la programación.

En Exercism, se te da una función llamada `hello` que devuelve «Goodbye, Mars!».

```python
def hello():
    return 'Goodbye, Mars!'
```

Tu tarea es cambiarla para que devuelva «Hello, World!» en su lugar.

## El enfoque tradicional

Para empezar, tenemos el enfoque más simple, y el que Exercism espera que implementes.
Con solo cambiar el string de «Goodbye, Mars!» a «Hello, World!», ¡ahora podemos devolverlo sin problema!

```python
def hello() -> str:
    return 'Hello, World'
```

### La permutación

Pasó una fuerte tormenta eléctrica y tu pobre y desafortunada máquina recibió un rayo.
Todavía enciende, pero ahora se comporta de forma extraña.
Todos los caracteres para armar el mensaje de saludo siguen ahí, pero no están en orden, y el daño en la placa lógica hace que la máquina ya no pueda acertar con el orden del mensaje.
Y para tu suerte, la máquina pequeña, increíblemente confiable e *indestructible* que construiste antes resultó ser robable (sí, ¡ya no está!).
Así que decides dejar que tu viejo amigo pruebe todas las formas posibles de mezclar estas letras hasta dar con el mensaje correcto.
Después de todo, solo son 13 caracteres y la máquina tiene mucha memoria. Esto debería ser rápido...

```python
from itertools import permutations

def hello() -> str:
    chars = ['H', 'e', 'l', 'l', 'o', ',', ' ', 'W', 'o', 'r', 'l', 'd', '!']

    all_permutations = permutations(chars)
    for perm in all_permutations:
        if ("".join(perm) == "Hello, World!"):
            return ''.join(perm)
```

### La recursión

Por alguna razón, decidiste que sería gracioso que la máquina se retrasara un poco y solo respondiera 10 segundos más tarde. Tu hermano vuelve a preguntar cuál es la lógica detrás de esta funcionalidad, porque, según él, eres el único que usa la máquina.

```python
import time

def hello(n=10):
    if n == 0:
        return "Hello, World!"
    else:
        time.sleep(1)
        return hello(n-1)
```

### El azar

De repente, un día te cansas del mismo saludo una y otra vez, así que decides dejar que te salude una última vez y jubilar la máquina para siempre, sin volver a tocarla jamás.
Como la máquina ha estado contigo en las buenas y en las malas durante mucho tiempo, decides dejar esta reunión final entre «amigos» en manos del destino.
 La enciendes una última vez y la dejas girar...

```python
import random

def hello():
    chars = list("Helo,Wrld!")
    greeting = ""
    while (greeting != "Hello, World!"):
        greeting = "".join(random.choices(chars, k=13))
    return greeting
```
