# Introducción

Los tipos de C# se pueden definir dentro del ámbito de una clase o una estructura. El tipo externo proporciona una especie de espacio de nombres. Se accede al tipo a través del tipo externo con la sintaxis de puntos.

```csharp
class Outer
{
    public interface IInner {}
    public enum EInner {}
    public class CInner {}
    public struct SInner {}
}

var outer = new Outer();
var inner = new Outer.CInner();
```

Puedes establecer niveles de acceso para los tipos internos.

Los miembros privados del tipo externo están dentro del ámbito de los miembros del tipo interno, pero no al revés.
