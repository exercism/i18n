# Instrucciones

Administras un cine exclusivo.
Para poder ver una película, las personas deben comprar un pase anual; después pueden ver películas gratis.

Tu cine lleva un registro de las admisiones.
Quieres usar ese registro para hacer seguimiento de qué miembros usaron su pase anual este mes.
También quieres obtener información sobre la demografía de edades de tus clientes.
Te das cuenta de que puedes usar conjuntos para lograr estos objetivos.

## Conjuntos

Un conjunto es un tipo de dato perfecto para almacenar este tipo de datos.

Un conjunto es un tipo de dato que se usa para almacenar valores distintos y únicos sin un orden particular.
Que sean distintos y únicos significa que un elemento está en el conjunto o no está en el conjunto; a diferencia de lo que ocurre con un array, no puede estar en el conjunto varias veces.
Por lo general, los conjuntos no tienen orden; si listas los elementos de un conjunto, el orden que obtienes puede ser distinto del orden en que se agregaron, ¡o incluso distinto del orden que obtuviste en la lista anterior!

Una propiedad fundamental de los conjuntos son las comprobaciones de pertenencia: la capacidad de verificar si un conjunto contiene un elemento.
Las comprobaciones de pertenencia son esenciales en casi todos los usos de un conjunto.

Go no proporciona un tipo de dato de conjunto integrado.
Es común usar un `map[<type>]struct{}` o un `map[<type>]bool` en lugar de un conjunto; igual que un conjunto, un `map` permite agregar elementos distintos y únicos y admite comprobaciones de pertenencia.

## 1. Un lugar para guardar la información de los asistentes

Para hacer seguimiento de la asistencia y de la demografía de edades, quieres usar un conjunto.

No quieres escribir conjuntos separados para nombres y edades; en su lugar, puedes usar un conjunto genérico para ambos.
Define un tipo `Set` como un `map[T comparable]struct{}` para almacenar a los asistentes.
Escribe una función `NewSet[T comparable]()` que devuelva un `Set[T]` vacío.

```go
names := NewSet[string]()
```

## 2. Seguimiento de los asistentes

Ahora ya puedes registrar la información de los asistentes.

Escribe un método `Add[T]()` que agregue un elemento al conjunto.

```go
names := NewSet[string]()
names.Add("Alice")
```

## 3. Comprobar los asistentes

Ahora que tienes un conjunto de asistentes, puedes comprobar si asistieron determinados miembros y grupos de edad.
Escribe un método `Contains[T](element)` que devuelva si un miembro o un grupo de edad está en el `Set`.

```
names := NewSet[string]()
names.Add("Alice")
names.Contains("Alice")
// => true
names.Contains("Bob")
// => false
```

## 4. Comparar los asistentes

Ha pasado otro mes y tienes un nuevo `Set` de grupos de edad.
Tu gerente de marketing quiere saber si los estrenos de este mes han cambiado qué grupos de edad están asistiendo.
Escribe un método `Equals[T](other)` que determine si dos conjuntos tienen los mismos elementos.

```go
agesOne := NewSet[int]()
names.Add(25)

agesTwo := NewSet[int]()
names.Add(25)

agesOne.Equals(agesTwo)
// => true

agesThree := NewSet[int]()
names.Add(35)

agesOne.Equals(agesThree)
// => false
```
