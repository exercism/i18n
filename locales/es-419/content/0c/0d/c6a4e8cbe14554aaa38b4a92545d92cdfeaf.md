# Debug

Cuando un test falla, se muestra un mensaje que describe qué salió mal y con qué argumento. También puedes aprovechar que se mostrará cualquier [salida de consola][dotnetperls.com-console-vbnet]. Puedes escribir en la consola usando:

```vbnet
Console.WriteLine("Debug message");
```

[dotnetperls.com-console-vbnet]: https://www.dotnetperls.com/console-vbnet
