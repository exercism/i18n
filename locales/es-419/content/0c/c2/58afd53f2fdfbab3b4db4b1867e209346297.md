# Anexo de instrucciones

## Instrucciones específicas del track

### Memoria reservada

Los bytes 64 a 447 de la memoria lineal están reservados para el string de entrada.

El string de entrada se puede modificar en el mismo lugar si lo deseas.

### Formato de entrada

Cada línea contendrá el nombre del primer equipo, luego un punto y coma `;`, después el nombre del segundo equipo, otro punto y coma `;`, el resultado del partido (`"win"`, `"draw"`, `"loss"`) y luego un salto de línea `\n`.
