# Instrucciones

Tori es una periodista climática y quiere escribir un artículo sobre el clima en diferentes ciudades. Tiene datos sobre el clima en diferentes ciudades y quiere clasificarlas según su temperatura, pero algunas de las temperaturas están en Fahrenheit y otras en Celsius. Necesita tu ayuda para convertir las temperaturas a la misma unidad y clasificarlas.

## 1. Convierte Fahrenheit a Celsius

Define la función `fahrenheit_to_celsius` que recibe una temperatura en Fahrenheit como argumento y devuelve la temperatura en Celsius.

Para convertir Fahrenheit a Celsius, resta 32 al valor en Fahrenheit y luego divide el resultado entre 1.8.

```gleam
fahrenheit_to_celsius(72.5)
// -> 22.5
```

## 2. Compara dos temperaturas

Define la función `compare_temperature` que recibe dos temperaturas y devuelve un valor de tipo `Order` que indica si la primera temperatura es menor que, igual a o mayor que la segunda temperatura.

```gleam
compare_temperature(Celsius(30.5), Fahrenheit(82.1))
// -> Gt
```

## 3. Ordena las ciudades por temperatura

Define la función `sort_cities_by_temperature` que recibe una lista de ciudades y las devuelve de la más fría a la más cálida.

```gleam
sort_cities_by_temperature([
  City(name: "London", temperature: Celsius(30.5)),
  City(name: "Paris", temperature: Fahrenheit(82.1))
])
// -> [
//   City(name: "Paris", temperature: Fahrenheit(82.1)),
//   City(name: "London", temperature: Celsius(30.5)))
// ]
```
