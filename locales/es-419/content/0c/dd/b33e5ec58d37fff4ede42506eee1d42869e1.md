# No modifiques las firmas ya dadas

Como se menciona en las instrucciones, no debes modificar las firmas de `makeChest` y `makeTreasureChest`.
Deben quedar exactamente así:

```elm
makeChest : String -> treasure -> Chest treasure {}

makeTreasureChest : Chest treasure { conditions | securePassword : (), uniqueTreasure : () } -> TreasureChest treasure
```
