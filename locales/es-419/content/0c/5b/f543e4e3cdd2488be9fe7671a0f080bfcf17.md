# Acerca de

ClojureScript es un compilador de Clojure que tiene como objetivo JavaScript. Emite código JavaScript compatible con el modo de compilación avanzada del compilador optimizador Google Closure.

## ¿Por qué Clojure?

Clojure es un lenguaje de programación dinámico y de propósito general que admite el desarrollo interactivo. Clojure es un lenguaje de programación funcional que ofrece un rico conjunto de estructuras de datos inmutables y persistentes. Como dialecto de Lisp, tiene una filosofía de código como datos y un potente sistema de macros.

## ¿Por qué JavaScript?

La difusión del navegador y de las aplicaciones basadas en la web le ha dado a JavaScript un alcance exclusivo que ningún otro lenguaje iguala. Debido a su importancia, los motores de JavaScript también reciben una amplia investigación y optimización, lo que le permite a JavaScript competir en rendimiento con plataformas mucho más consolidadas, como la JVM.

## ¿Por qué Google Closure?

Como proveedores de algunas de las aplicaciones web cliente-servidor más complicadas que se usan hoy en día, Google ha invertido mucho en la creación de la biblioteca Closure y el compilador Closure, que trabajan juntos para hacer posible la optimización de todo el programa, lo que da como resultado programas con tiempos de carga mínimos incluso cuando se usan muchas bibliotecas.

## Oportunidad

ClojureScript combina el alcance de la plataforma JavaScript, la flexibilidad y el desarrollo interactivo de Clojure, y la optimización de todo el programa de Google Closure para ofrecer el lenguaje más potente para programar para la web.
