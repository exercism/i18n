# Acerca de

Además de `cond`, Elixir también proporciona la macro [`if/2`][getting-started-if], que es útil cuando necesitas comprobar solo una condición.

[`if/2`][kernel-if] acepta una condición y dos opciones. Devuelve la primera opción si la condición es _truthy_, y la segunda opción si la condición es _falsy_.

```elixir
age = 15

if age >= 16 do
  "You are allowed to drink beer in Germany."
else
  "No beer for you!"
end

# => "No beer for you!"
```

Si no se da la segunda opción, se devolverá `nil`.

```elixir
age = 15

if age >= 16 do
  "You are allowed to drink beer in Germany."
end

# => nil
```

También es posible escribir una expresión `if` en una sola línea. Fíjate en la coma que va después de la condición.

```elixir
if age >= 16, do: "beer", else: "no beer"
```

Esta sintaxis es útil para expresiones muy cortas, pero conviene evitarla si la expresión no cabe en una sola línea.

## _Truthy_ y _falsy_

En Elixir, todos los tipos de datos se evalúan como un valor _truthy_ o _falsy_ cuando aparecen en un contexto booleano (como una expresión `if`). Todos los datos se consideran _truthy_ **excepto** `false` y `nil`. En particular, los strings vacíos, el entero `0` y las listas vacías se consideran _truthy_ en Elixir. En esto, [Elixir se parece a Ruby, pero es distinto de JavaScript, Python o PHP][falsy-various-langs].

```elixir
truthy? = fn x -> if x, do: "truthy", else: "falsy" end

truthy?.(true)
# => "truthy"
truthy?.(0)
# => "truthy"
truthy?.([])
# => "truthy"

truthy?.(false)
# => "falsy"
truthy?.(nil)
# => "falsy"
```

[`&&/2`][kernel-and], [`||/2`][kernel-or] y [`!/1`][kernel-not] son operadores booleanos _truthy_ que funcionan con cualquier valor, y complementan a los operadores booleanos _estrictos_ [`and/2`][kernel-boolean-and], [`or/2`][kernel-boolean-or] y [`not/1`][kernel-boolean-not].

```elixir
0 and true
# => ** (BadBooleanError) expected a boolean on left-side of "and", got: 0

0 && true
# => true
```
