# Ayuda

Si tienes problemas y necesitas ayuda, puedes usar uno de los siguientes recursos:

- [Recursos de Raku](https://raku.org/resources/)
- [/r/rakulang](https://www.reddit.com/r/rakulang) es el subreddit de Raku.
- Puedes usar [StackOverflow](http://stackoverflow.com/questions/tagged/raku) para buscar tu problema y ver si ya se respondió. También puedes hacer y responder preguntas.
