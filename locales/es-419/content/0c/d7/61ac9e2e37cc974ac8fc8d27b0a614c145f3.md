# Introducción

Para crear una instancia de una clase, se llama a su _constructor_ mediante el operador `new`. Un constructor es un método especial dentro de una clase cuyo objetivo es inicializar la clase. En Haxe, el método constructor tiene el nombre `new()`.

```haxe
class Library {
  private var books:Int;

  public function new() {
    this.books = 10; // Initialize the books field
  }
}

var library = new Library(); // This calls the constructor
```

Igual que los métodos normales, los constructores pueden tener parámetros. Por lo general, estos parámetros se guardan en campos privados y se accede a ellos más adelante.

```haxe
class Building {
  private var numberOfStories:Int;
  private var totalHeight: Float;

  public function new(numberOfStories:Int, storyHeight:Float) {
    this.numberOfStories = numberOfStories;
    this.totalHeight = storyHeight * numberOfStories;
  }
}

var largeBuilding = new Building(55, 6.2);
```
