# Acerca de

La recursión es una forma de repetir código en una función haciendo que la función se llame a sí misma.
Es otra forma de hacer bucles o iterar. Como en los bucles, la función debe evaluar una expresión Boolean para saber cuándo terminar.
A diferencia de los bucles, la recursión que nunca termina no se ejecuta de forma infinita.
Los valores usados en cada llamada a la función pueden colocarse en su propio marco de pila.
Si la cantidad de llamadas a la función ocupa más espacio del que tiene la pila, se producirá un error de desbordamiento de pila.

```c
int printIncrement (int i, int maxValue){
    if (i > maxValue) return i;
    printf("The number is %i\n", i++);
    printIncrement(i, maxValue);
}

int main() {
    printIncrement(1, 2);
    printf("After recursion");
    return 0;
}
```

Esto imprimirá

```
The number is 1
The number is 2
After recursion
```

Puede haber algunas situaciones que sean más legibles o más fáciles de razonar cuando se expresan mediante recursión que cuando se expresan mediante bucles.


## Llamada de cola

Una llamada de cola ocurre cuando la última sentencia de una función solo se llama a sí misma y nada más.

Una llamada de cola es una forma particular de recursión que puede permitir al compilador optimizar la recursión en un bucle en el código compilado.
Eso ofrece lo mejor de ambos mundos: la legibilidad de la recursión con el rendimiento de un bucle.
La compilación de la recursión en un bucle se llama `tail call elimination` o `tail call optimization.`

Cuando una llamada de cola se compila en un bucle, no se crea un nuevo marco de pila para cada llamada a la función.
A la dirección de la función cuando se llamó originalmente se le pasan los valores actualizados, lo que ahorra espacio en la pila y mejora el rendimiento.

Este ejemplo no es una llamada de cola, ya que la función suma 1 al resultado de llamarse a sí misma

```c
int printIncrement (int i, int maxValue){
    if (i > maxValue) return 1;
    printf("The number is %i\n", i++);
    return 1 + printIncrement(i, maxValue);
}

int main() {
    int j = printIncrement(1, 2);
    printf("j is %i after recursion", j);
    return 0;
}
```

Esto imprimirá

```
The number is 1
The number is 2
j is 3 after recursion
```

Para refactorizarlo a una llamada de cola, haz que `j` sea un parámetro de `printIncrement`

```c
int printIncrement (int i, int maxValue, int j){
    if (i > maxValue) return j;
    printf("The number is %i\n", i++);
    return printIncrement(i, maxValue, ++j);
}

int main() {
    int j = printIncrement(1, 2, 1);
    printf("j is %i after recursion", j);
    return 0;
}
```

Puede que una llamada de cola te resulte más fácil de razonar que una llamada recursiva que no es una llamada de cola.
Sin embargo, los compiladores normalmente no garantizan que todas las llamadas de cola se optimicen.
Siempre es importante, al usar recursión, saber que no habrá tantas iteraciones como para que la pila se desborde.
