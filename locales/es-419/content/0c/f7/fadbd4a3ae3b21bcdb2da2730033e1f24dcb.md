# Letreros personalizados

## Historia

En este ejercicio escribirás código para ayudar a una empresa de letreros a crear mensajes personalizados para sus letreros.

## Tareas

Estos son ejemplos de tareas que encajan con la historia de un cliente que diseña un letrero personalizado:

- Crear un conjunto de strings útiles
- Crear un conjunto de caracteres útiles
- Combinar frases para armar mensajes
- Armar un letrero de graduación
- Calcular el costo de un letrero
