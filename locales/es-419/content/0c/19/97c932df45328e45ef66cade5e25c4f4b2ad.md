Raku es un lenguaje de programación increíblemente rico, flexible y potente.
Su flexibilidad permite que quienes programan escriban código expresivo que se ajusta a su propio estilo.

Raku es un lenguaje grande, con muchísima profundidad para aprender, explorar y experimentar.
Este temario busca cubrir los fundamentos para que puedas empezar.

La programación orientada a objetos está en el corazón de Raku, aunque no impone prácticas de programación orientada a objetos.
Debido a su naturaleza orientada a objetos, este temario hará referencia con frecuencia a [objetos, clases y métodos][object-orientation].

## Variables

En basics solo usaremos [variables][variables] escalares, para no complicar las cosas.

Las variables escalares son [identificadores][identifiers] precedidos por el sigilo `$`.

Las variables escalares pueden contener prácticamente cualquier cosa y tienen un tipo predeterminado: [`Any`][Any].

La mayoría de las variables que uses necesitarán una [declaración][variable-declarator].
Por ahora, quédate con [`my`][my] y [`constant`][constant].

```raku
my $foo;
constant $BAR;
```

## Subrutinas

Una subrutina se declara con el declarador [`sub`][sub-declarator].

A una declaración `sub` le sigue un [identificador][identifiers] opcional, luego una [firma][signatures] opcional y después un [bloque][blocks].

Las subrutinas pueden exportarse (entre otras cosas) agregando el rasgo [`is export`][exporting].

Se puede llamar a una subrutina con un operador [postcircunfijo `( )`][postcircumfix-()] aplicado al identificador.

```raku
sub foo ($bar) is export { ... } # Subroutine definition

foo($bar); # Subroutine call
```

## Operadores

Raku tiene una gran variedad de [operadores][operators].
En los ejercicios del concepto basics vamos a usar algunos operadores matemáticos básicos de Raku, como `+` y `-`.

```raku
say 0.1 + 0.2 - 0.3;
# Raku is not like other languages -> https://0.30000000000000004.com/#raku
```

Si quieres, puedes definir tus propios operadores en Raku fácilmente.
La mayoría de los operadores incorporados también están disponibles como subrutinas.

## Paquetes y módulos

En Raku hay varios tipos de [paquetes][package-declarator]. En basics solo usaremos `module`.

Para declarar un archivo entero como `module`, se antepone `unit` a la declaración del módulo.

```raku
unit module Foo;

sub bar () { ... }
```

## Comentarios

Raku tiene comentarios [de una sola línea][single-line-comments] y [de varias líneas o incrustados][multi-line-comments].

Los comentarios de una sola línea empiezan con `#` y continúan hasta el final de la línea.

Los comentarios de varias líneas o incrustados empiezan con una almohadilla seguida de un acento grave y un carácter de puntuación abierta de Unicode.
Terminan con el carácter de cierre correspondiente de la pareja.

```raku
# This is a single-line comment

#`(
    This is a
    multi-line/embedded comment
)
```

## Convenciones de estilo

En Raku, los [identificadores][identifiers] de variables y subrutinas se escriben en `kebab-case`.
Las constantes se escriben en `ALL-CAPS`.
Los nombres de paquetes se escriben en `PascalCase`.
