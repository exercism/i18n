# Condicionales

Un **condicional** elige entre dos cursos de acción según si algo es verdadero o falso.

```sather
   verdict(score : INT) : STR is
      if score >= 5 then
         return "Recalled";
      else
         return "Thank you";
      end;
   end;
```

Leyendo eso: `if`, luego una pregunta que responde `true` o `false`, luego `then`. Las líneas después de `then` se ejecutan cuando la respuesta es verdadera, y las líneas después de `else` se ejecutan cuando es falsa. `end;` cierra todo el conjunto.

## Más de dos caminos

`elsif` agrega otra pregunta, que se hace solo cuando las anteriores resultaron falsas.

```sather
   verdict(score : INT) : STR is
      if score >= 8 then
         return "Cast";
      elsif score >= 5 then
         return "Recalled";
      else
         return "Thank you";
      end;
   end;
```

El orden importa. Un puntaje de `9` lo captura la primera pregunta y nunca llega a la segunda, aunque `9 >= 5` también es verdadero. Escribir las condiciones en el orden equivocado es la forma habitual de cometer este error.

Se escribe `elsif`, no `elseif`, ni `else if`.

## Omitir el else

Se puede omitir `else` cuando no hay nada que hacer en ese caso.

```sather
   if late then
      apologise;
   end;
```

Una rutina que debe devolver algo necesita que todos los caminos devuelvan un valor, así que en este ejercicio todos los `if` conservan su `else`.
