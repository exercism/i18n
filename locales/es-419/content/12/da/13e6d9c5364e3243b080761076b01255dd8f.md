# El tipo tupla

Una tupla es un tipo de dato compuesto versátil y eficiente en Cairo, que te permite agrupar varios valores de distintos tipos en una sola entidad.
Las tuplas tienen una longitud fija: una vez declaradas, su tamaño no puede cambiar.

## Cómo crear tuplas

Para crear una tupla, escribes una lista de valores separados por comas entre paréntesis.
Cada posición de la tupla tiene un tipo específico, y esos tipos pueden ser distintos entre sí.

```rust
fn main() {
    let tup: (u32, u64, bool) = (10, 20, true);
}
```

Una tupla puede contener varios valores de distintos tipos de datos, incluidas otras tuplas.
Por ejemplo:

```rust
fn main() {
    let nested_tup: ((i32, u64), (u8, bool)) = ((10, 3), (5, false));
}
```

Aquí, la variable `nested_tup` es una tupla que contiene dos tuplas, lo que demuestra que las tuplas pueden tener otras tuplas como elementos.

## Cómo desestructurar tuplas

Para acceder a los valores individuales de una tupla, puedes usar la coincidencia de patrones para desestructurarla.
Esto separa la tupla en las partes que la componen.

```rust
fn main() {
    let tup = (500, 6, true);

    let (x, y, z) = tup;

    println!("x is: {x}"); // prints "x is: 500"
    println!("y is: {y}"); // prints "x is: 6"
    println!("z is: {z}"); // prints "z is: true"
}
```

## Cómo declarar y desestructurar al mismo tiempo

También puedes declarar y desestructurar una tupla al mismo tiempo.

```rust
fn main() {
    let (x, y): (felt252, felt252) = (2, 3);
}
```

## El tipo unitario `()`

El tipo unitario es un tipo especial de Cairo que tiene un solo valor: `()`.
Se representa con una tupla sin elementos.
El tamaño del tipo unitario siempre es cero, y se garantiza que no existe en el código compilado.

En Cairo, toda expresión devuelve un valor, y cuando una expresión no devuelve nada, devuelve `()` de forma implícita.
Esto puede ser útil para funciones que necesitan devolver un valor, pero no tienen ningún valor significativo que devolver.

## Cómo declarar un tipo de tupla con nombre

Una tupla con nombre te permite crear un alias de tipo más descriptivo para una tupla, lo que mejora la legibilidad del código.

```rust
type Point = (u32, u32);

fn main() {
    let point: Point = (10, 8);
    println!("{point:?}"); // prints "(10, 8)"
}
```

En este ejemplo, `Point` es un tipo de tupla con nombre que representa un par de enteros sin signo de 32 bits, lo que hace que el código sea más expresivo.
