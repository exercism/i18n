# Introducción

Un `String` en Java es un objeto que representa texto inmutable como una secuencia de caracteres Unicode (letras, dígitos, signos de puntuación, etc.).
Las comillas dobles se usan para definir una instancia de `String`:

```java
String fruit = "Apple";
```

Los strings se manipulan llamando a los métodos del string.
Una vez construido un string, su valor nunca puede cambiar.
Cualquier método que parezca modificar un string en realidad devolverá un string nuevo.
La clase `String` proporciona algunos métodos _static_ para transformar los strings.
