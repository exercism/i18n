# Acerca de

En Common Lisp, una lista de parámetros (por ejemplo, para definir una función) también se conoce como *lambda list*.
Las lambda lists también se usan para definir macros y para desestructurar.

Las lambda lists pueden contener lambda list keywords como `&rest`, `&optional`, `&key` y otros.

Aunque varios tipos de parámetros se pueden combinar con otros tipos de parámetros (parámetros opcionales y por palabra clave), esto puede ser problemático y conviene hacerlo con cuidado.
Consulta la sección «Combinar distintos tipos de parámetros» en Practical Common Lisp.
