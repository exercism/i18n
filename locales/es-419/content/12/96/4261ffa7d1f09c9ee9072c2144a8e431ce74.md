# Pistas

## 1. Calcula la suma de los números de la máquina tragamonedas

- Puedes usar [join][mdn-join] para combinar los dígitos.
  También convertirá los números a strings de forma implícita.
- Vuelve a revisar la sección de introducción para descubrir cómo convertir un string a un número.
- Suma los números después de haberlos convertido.

## 2. Determina si un número es un palíndromo

- Esta tarea se puede resolver tratando el número como un string y verificando si el string es igual a su versión invertida.
- Para hacer esto, primero necesitas convertir el número a un string.
  Vuelve a revisar la sección de introducción para descubrir cómo hacerlo.
- Para invertir el string, usa `split` para dividirlo en un array, `reverse` para invertir el array y `join` para volver a unirlo.
- Finalmente, puedes [comparar][concept-comparison] el string original con el string invertido.

## 3. Genera un mensaje de error para la entrada de usuario no válida

- Puedes usar [condicionales][mdn-if-statement] para verificar las diferentes condiciones.
- Primero, debes cubrir el caso en que el valor no contenga ningún carácter.
  Al escribir la condición para eso, aprovecha la conversión implícita a Boolean y el hecho de que `null`, `undefined` y el string vacío son todos falsy.
- Luego, aborda el caso en que la entrada no sea un número o sea `0`.
  Usa la conversión explícita a `Number` que aprendiste en la introducción.
  Después, puedes volver a apoyarte en la conversión implícita a Boolean y en el hecho de que `NaN` y `0` son falsy.
- El [operador NOT][mdn-not] lógico `!` podría serte útil para formular las condiciones.
