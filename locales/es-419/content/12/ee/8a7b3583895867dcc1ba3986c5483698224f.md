# Pistas

## General

- [Las tuplas][tuple-module] son estructuras de datos que se organizan en memoria contigua y pueden contener cualquier tipo de dato.
- Los átomos se pueden usar para denotar estados finitos, ya que este ejercicio usa `:cup`, `:fluid_ounce`, `:teaspoon`, `:tablespoon`, `:milliliter` para denotar las unidades empleadas.
- Puedes usar funciones de [`Kernel`][elem] o de [`Tuple`][tuple-module], o la coincidencia de patrones, para manipular las tuplas.

## 1. Obtén el componente numérico de un par de volumen

- Considera usar [una función del módulo `Kernel`][elem] para devolver el componente numérico del par de volumen.

## 2. Convierte el par de volumen a mililitros

- Usa [funciones con múltiples cláusulas][multi-clause] y [coincidencia de patrones][pattern-matching] para reducir la lógica de control condicional.
- Implementa la función para convertir todas las unidades a mililitros, incluyendo de mililitros a mililitros.

## 3. Convierte el par de volumen en mililitros a otra unidad

- Usa [funciones con múltiples cláusulas][multi-clause] y [coincidencia de patrones][pattern-matching] para reducir la lógica de control condicional.
- Implementa la función para convertir de mililitros a todas las unidades, incluyendo de mililitros a mililitros.

## 4. Convierte de cualquier unidad a cualquier unidad

- Reutiliza las funciones que ya creaste para realizar la conversión en la función `convert/2`.
