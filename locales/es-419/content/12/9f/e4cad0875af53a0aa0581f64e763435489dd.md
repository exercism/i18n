# Acerca de

[concept:csharp/enumerables]() se puede iterar usando un [bucle `foreach`][foreach-statement]:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // Output the vowel
    System.Console.Write(vowel);
}

// => aeiou
```

Un bucle `foreach` consta de tres partes:

1. La declaración: define la variable que contendrá el valor iterado. Esta variable puede usarse (solo) dentro del bucle.
2. El objeto iterable: el objeto sobre el que se puede iterar.
3. El cuerpo del bucle.

## Bucles `for` frente a bucles `foreach`

Sin embargo, en general un bucle `foreach` es preferible a un bucle `for` por las siguientes razones:

- Un bucle `foreach` garantiza que se itera sobre _todos_ los valores. Con un bucle `for` es fácil saltarse elementos, por ejemplo debido a un error de desfase de uno.
- Un bucle `foreach` es más _declarativo_: tu código comunica _qué_ quieres que haga, en lugar de un bucle `for` que comunica _cómo_ quieres hacerlo.
- Un bucle `foreach` es a prueba de errores, mientras que con los bucles `for` es fácil cometer un error de desfase de uno.
- Un bucle `foreach` funciona con todos los tipos de colección, incluidos aquellos que no admiten el uso de un indexador para acceder a los elementos.

Para garantizar que un bucle `foreach` itere sobre _todos_ los valores, el compilador no permitirá modificar una colección dentro de un bucle `foreach`:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // This would result in a compiler error
    // vowel = 'Y';
}
```

Un bucle `for` sí tiene algunas ventajas sobre un bucle `foreach`:

- Puedes empezar o terminar en el índice que quieras.
- Puedes usar cualquier condición de terminación (Boolean) que quieras.
- Puedes saltarte elementos personalizando el incremento de la variable del bucle.
- Puedes procesar colecciones de atrás hacia adelante contando en orden descendente.
- Puedes usar bucles `for` en escenarios que no involucran colecciones.

Temas relacionados:

- Debes tener en cuenta que C# admite [arrays multidimensionales][multi-dimensional-arrays] como `int[,] arr = new int[10, 5]`, que pueden ser muy útiles.
- También debes tener en cuenta que puedes instanciar objetos de tipo [`System.Array`][system-array-object] con `Array.CreateInstance`. Estos objetos tienen poca utilidad, principalmente para la interoperabilidad con código de VB.NET. No son intercambiables con los arrays estándar (`T[]`). Pueden tener un límite inferior distinto de cero.
