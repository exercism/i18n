# Introducción

Perl es un lenguaje de programación creado por Larry Wall, publicado por primera vez en 1987.

## Paquetes y módulos

Un paquete es una colección de código, que suele estar contenida en un archivo de módulo del mismo nombre con la extensión `.pm`.
El módulo se puede importar después en otro archivo, normalmente con la palabra clave `use`.

```perl
# Foo.pm
package Foo;

# Accessible with `Foo::bar` when module is used
# or just `bar` if the subroutine is exported.
sub bar () {
    return 1;
}
```

## Variables

Existen variables escalares (`$foo`), de array (`@bar`) y de hash (`%baz`).
Para simplificar, aquí solo se usarán variables escalares.
Un valor escalar puede ser lo siguiente: un string, un número, un Boolean o una [referencia][perlreftut] a algo.
La ausencia de un valor es `undef`.


Las palabras clave `my` y `our` declaran una variable en el ámbito léxico, por ejemplo, `my $foo;`.
Con `our`, la variable también se convierte en un alias de una variable de paquete con el mismo nombre.
Existen otras formas de declarar variables que no se cubren aquí.

Puedes asignar un valor a una variable con el operador `=`, por ejemplo, `$foo = 1;`, y eso puedes hacerlo al mismo tiempo que declaras la variable, por ejemplo, `my $foo = 1;`.

```perl
package Foo;

sub baz () {
    our $bar = 1; # Sets both $bar and $Foo::bar as 1.
    return $bar;
}

$Foo::bar = 2; # $bar is not accessible here, but $Foo::bar is.

# Both of these will print 1.
say baz;
say $Foo::bar;
```

## Subrutinas

La palabra clave `sub` declara una [subrutina][perlsub].
La palabra clave `return` sale de la subrutina y devuelve los valores especificados, o una lista vacía si no se especifica nada.
Sin un `return` especificado, el valor devuelto dependerá del contexto (escalar, de lista o vacío) en el que se use la subrutina y de su última sentencia.

```perl
sub hello () {
    return 'Hello, World!';
}
```

Las versiones recientes de Perl te permiten especificar parámetros formales en una [firma][perlsubsig].
La lista de parámetros puede contener variables escalares, de array o de hash.
Una lista de parámetros vacía significa que la subrutina no acepta ningún argumento.
Las versiones anteriores de Perl requerían obtener los argumentos de la variable especial `@_`, algo que no se cubre aquí.

## Comentarios

Los comentarios en Perl comienzan con un `#` que no forma parte de un string y terminan al final de la línea.
