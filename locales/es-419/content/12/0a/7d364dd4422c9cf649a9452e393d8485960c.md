# Anexo de instrucciones

## Registros

| Registro | Uso           | Tipo    | Descripción                              |
| -------- | ------------- | ------- | ---------------------------------------- |
| `$a0`    | entrada       | entero  | límite                                   |
| `$a1`    | entrada/salida| dirección | array de destino para los números primos |
| `$v0`    | salida        | entero  | cantidad de números primos               |
| `$t0-9`  | temporal      | cualquiera | se usa para almacenamiento temporal   |
