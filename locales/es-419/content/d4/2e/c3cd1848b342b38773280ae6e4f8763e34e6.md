# Instrucciones

Te damos la bienvenida al mundo de *ChronoRealms*, una tierra mágica donde poderosos Timekeepers controlan el flujo del tiempo.

En este reino, los Timekeepers gestionan «TimeShards», unidades especiales que se pueden sumar, restar, comparar e incluso verificar si son iguales.

Tu tarea es ayudar a los Timekeepers implementando operadores personalizados para manipular estos TimeShards.

Los Timekeepers necesitan que crees un struct personalizado `TimeShard` que admita las siguientes operaciones:

1. **Sumar y restar TimeShards**: los Timekeepers necesitan poder sumar y restar TimeShards para controlar la línea de tiempo.
2. **Comparar TimeShards**: a veces hay que comparar TimeShards para ver cuál es más grande o si son iguales.
3. **Verificar la igualdad**: los Timekeepers necesitan comprobar si dos TimeShards son idénticos en valor.

Tu misión es implementar los siguientes traits para el struct `TimeShard`:

1. **Suma (`Add`)**: permite sumar dos instancias de `TimeShard`.
2. **Resta (`Sub`)**: permite restar un `TimeShard` de otro.
3. **Igualdad (`PartialEq`)**: permite a los Timekeepers comprobar si dos instancias de `TimeShard` son la misma.
4. **Comparación (`PartialOrd`)**: permite comparar dos instancias de `TimeShard` para ver cuál es mayor o menor.

Un `TimeShard` estará representado por un struct que contiene un valor entero (`i32`).

Implementa los traits necesarios para facilitarle el trabajo a los Timekeepers.

```rust
let shard1 = TimeShard { value: 5 };
let shard2 = TimeShard { value: 3 };

// Adding TimeShards
let sum = shard1 + shard2; // TimeShard { value: 8 }

// Subtracting TimeShards
let difference = shard1 - shard2; // TimeShard { value: 2 }

// Checking equality
let are_equal = shard1 == shard2; // false

// Comparing TimeShards
let is_greater = shard1 > shard2; // true
```
