# Introducción

## Operadores de comparación

Los operadores de comparación en Julia son similares a los de muchos otros lenguajes, aunque con algunas opciones extra para los amantes de las matemáticas.

Para la igualdad, los operadores son `==` (igual) y `!=` o `≠` (distinto).

```julia
txt = "abc"
txt == "abc"  # true
txt != "abc"  # false
txt ≠ "abc"  # false (synonym for !=)
```

Además, están los distintos operadores de mayor y menor que.

```julia
1 < 3  # true
3 > 3  # false
3 <= 3  # true
3 ≤ 3  # true (synonym for <=)
4 >= 3  # true
4 ≥ 3  # true (synonym for >=)
```

Como suele pasar con Julia, un editor adecuado facilita el uso del símbolo matemático.
Escribe `\ne`, `\le` o `\ge` y luego `TAB` para obtener `≠`, `≤` o `≥`.

El ejemplo anterior usa solo números, pero veremos en otras partes del temario que varios tipos adicionales tienen una noción de orden y se pueden comparar con mayor o menor que.

Los operadores de comparación se pueden encadenar, lo que permite una sintaxis clara y concisa:

```julia
n = 3
1 ≤ n ≤ 5  # true (n "between" two limits)
```

El ejemplo anterior es sinónimo de `1 ≤ n && n ≤ 5`.

## Bifurcación con `if`

Esta es la forma completa de una sentencia `if`:

```julia
if conditional1
    statements...
elseif conditional2
    statements...
else
    statements...
end
```

No se necesitan paréntesis (`()`) ni llaves (`{}`), y la indentación es «solo» para mejorar la legibilidad _(¡pero la legibilidad es muy importante!)_.

Tanto `elseif` como `else` son opcionales, y puede haber varios bloques `elseif`.
Sin embargo, el `end` es obligatorio.

Es posible anidar sentencias `if`, aunque quizá quieras ayudar a la legibilidad con un uso cuidadoso de paréntesis, indentaciones y comentarios.

La forma más corta de una sentencia `if` sería algo así:

```julia
if n < 0
    n = 0
end
```

Como recordatorio: solo las expresiones que se evalúan a `true` o `false` se pueden usar como condicionales.
Julia evita deliberadamente cualquier concepto de «truthiness», así que los valores cero, los strings vacíos y los arrays vacíos _no_ son equivalentes a `false`. 

## Operador ternario

Una situación simple y común es elegir uno de dos valores según un condicional.

Julia, como muchos lenguajes, tiene un operador ternario para hacer esto más conciso.

La sintaxis es `conditional ? value_if_true : value_if_false`.

Así que el ejemplo anterior se puede reescribir:

```julia
n = n < 0 ? 0 : n
```

El compilador no requiere paréntesis, pero pueden mejorar la legibilidad.
