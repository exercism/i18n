# Pistas

## 1. Inserta una carta en la parte superior de la pila

- La [función `ArrayTrait::append`][append] se puede usar para agregar al final de un array.

## 2. Quita la carta de la parte superior de la pila

- Siempre puedes convertir un array en un span y luego usar la [función `SpanTrait::pop_back`][pop-back] para eliminar desde el final de un array.

## 3. Inserta una carta en la parte inferior de la pila

- No hay forma de agregar un elemento al inicio del array, pero una manera de sortear esto es crear un array nuevo de un solo elemento y agregar el anterior como un span con [`ArrayTrait::append_span`][append-span].

## 4. Quita una carta de la parte inferior de la pila

- La [función `ArrayTrait::pop_front`][pop-front] se puede usar para eliminar desde el inicio de un array.

## 5. Verifica el tamaño de la pila

- La [función `ArrayTrait::len`][len] se puede usar para obtener la longitud de un array.
