# Descripción

En este ejercicio, vas a crear un programa útil para que no tengas que recordar los valores de las bandas.
El programa recibirá 1, 4 o 5 colores y devolverá el valor correcto en ohms.
Las bandas de color se codifican de la siguiente manera:

| Color       | Valor |
|-------------|-------|
| Black       | 0     |
| Brown       | 1     |
| Red         | 2     |
| Orange      | 3     |
| Yellow      | 4     |
| Green       | 5     |
| Blue        | 6     |
| Violet      | 7     |
| Gray        | 8     |
| White       | 9     |
|-------------|-------|

En [`Resistor Color Trio`][resistor-color-trio-exercise] decodificaste las primeras tres bandas de color.
Por ejemplo: orange-orange-brown se convierte al valor principal `330`.
En este ejercicio tendrás que agregar _tolerancia_ a la mezcla.
La tolerancia es la cantidad máxima que un valor puede estar por encima o por debajo del valor principal.
Por ejemplo, si la última banda es green, la tolerancia máxima será `±0.5%`.

La banda de tolerancia tendrá uno de estos valores:

| Color  | Tolerancia |
|--------|----------:|
| Grey   | ±0.05%    |
| Violet | ±0.10%    |
| Blue   | ±0.25%    |
| Green  | ±0.50%    |
| Brown  | ±1.00%    |
| Red    | ±2.00%    |
| Gold   | ±5.00%    |
| Silver | ±10.00%   |
|--------|-----------|

La resistencia de cuatro bandas se compone así:

| Banda_1  | Banda_2  | Banda_3     | Banda_4    |
| ------- | ------- | ---------- | --------- |
| Valor_1 | Valor_2 | Multiplicador | Tolerancia |

Ejemplos:

- orange-orange-brown-green sería `330` ohms con una tolerancia de `±0.5%`.
- orange-orange-red-grey sería `3300` ohms con una tolerancia de `±0.05%`.

La diferencia entre una resistencia de cuatro y cinco bandas es que la de cinco bandas tiene una banda adicional para indicar un valor más preciso.

| Banda_1  | Banda_2  | Banda_3  | Banda_4     | Banda_5    |
| ------- | ------- | ------- | ---------- | --------- |
| Valor_1 | Valor_2 | Valor_3 | Multiplicador | Tolerancia |

Ejemplos:

- orange-orange-orange-black-green sería `333` ohms con una tolerancia de `±0.5%`.
- orange-red-orange-blue-violet sería `323 million` ohms con una tolerancia de `±0.1%`.

También hay resistencias de una banda.
Las resistencias de una banda solo tienen el color black con un valor de 0.

Tu programa debe convertir una `list` de colores de bandas de resistencia en una etiqueta:

«... ohms ±...%»

Así que una `list` de entrada de `["orange", "orange", "black", "green"]` debería devolver:

«33 ohms ±0.5%»

Cuando hay miles de ohms, decimos «kiloohms».
Eso es similar a decir «kilómetro» para 1000 metros y «kilogramos» para 1000 gramos.

Así que una `list` de entrada de `["orange", "orange", "orange", "grey"]` debería devolver:

«33 kiloohms ±0.05%»

Cuando hay millones de ohms, decimos «megaohms».

Así que una `list` de entrada de `["orange", "orange", "blue", "red"]` debería devolver:

«33 megaohms ±2%»
