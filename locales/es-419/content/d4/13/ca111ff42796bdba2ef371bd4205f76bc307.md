# Apéndice de instrucciones

## Registros

| Registro | Uso       | Tipo    | Propósito                  |
| -------- | --------- | ------- | -------------------------- |
| `$a0`    | entrada   | entero  | valor dado                 |
| `$v0`    | salida    | entero  | diferencia de cuadrados    |
| `$t0-9`  | temporal  | cualquiera | usado para almacenamiento temporal |
