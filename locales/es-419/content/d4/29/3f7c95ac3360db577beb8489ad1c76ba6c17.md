# Instrucciones

Estás construyendo una pequeña calculadora de Notación Polaca Inversa (RPN).
El estado de la calculadora es una *pila de valores*, representada como un
array de Factor, y una *operación* es una quotación que toma esa pila
y devuelve una nueva.

```factor
{ 3 4 }   ! the calculator's stack: 3 is below 4
[ ... ]   ! an operation that consumes some values and pushes a result
```

## 1. Implementa la suma

Define `add-op` para que saque los dos valores superiores de la pila, apile su
suma y devuelva la nueva pila.

```factor
{ 3 4 } add-op .
! => { 7 }

{ 1 2 3 4 } add-op .
! => { 1 2 7 }
```

## 2. Implementa la multiplicación

Define `multiply-op` de la misma manera, pero para la multiplicación.

```factor
{ 3 4 } multiply-op .
! => { 12 }
```

## 3. Aplica una sola operación

Define `apply-op` para que tome una pila y una operación (una quotación) de
la pila de datos y devuelva la nueva pila de la calculadora.

```factor
{ 3 4 } [ add-op ] apply-op .
! => { 7 }
```

## 4. Evalúa un programa

Define `evaluate` para que tome una pila inicial y un array de operaciones
y aplique cada operación en orden, devolviendo la pila final.

```factor
{ 3 4 5 } { [ add-op ] [ multiply-op ] } evaluate .
! => { 27 }
```

## 5. Evalúa por nombre

Ahora el programa es una lista de *nombres de operadores* (strings), y la
calculadora busca cada nombre en un assoc que asocia nombres con
operaciones.

Define `evaluate-named` para que tome una pila inicial, un assoc de operaciones
con nombre y un array de nombres, y devuelva la pila final.

```factor
{ 3 4 5 } H{ { "+" [ add-op ] } { "*" [ multiply-op ] } } { "+" "*" }
evaluate-named .
! => { 27 }
```

## 6. Divide con seguridad

Una calculadora real no debe producir basura en silencio cuando se le pide
dividir entre cero. La clase de error `zero-divisor-error` ya está
definida para ti. Implementa `divide-op` de forma análoga a `add-op` y
`multiply-op`, salvo que lanza con `throw` un nuevo
`zero-divisor-error` cuando el divisor en la parte superior de la pila es `0`.

```factor
{ 12 4 } divide-op .
! => { 3 }

{ 1 5 6 2 } divide-op .
! => { 1 5 3 }

{ 5 0 } divide-op
! throws zero-divisor-error
```
