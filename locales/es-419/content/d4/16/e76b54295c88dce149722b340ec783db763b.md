## 1. Identifica las líneas del registro distorsionadas

- La [función `regexp.from_string`][from-string] se puede usar para compilar una expresión regular.
- La [función `regexp.check`][check] se puede usar para comprobar si una expresión regular coincide con un string.
- No olvides escapar los caracteres que tienen un significado especial en las expresiones regulares.

## 2. Divide la línea del registro

- La [función `regexp.split`][split] se puede usar para dividir un string usando una expresión regular.
- No olvides escapar los caracteres que tienen un significado especial en las expresiones regulares.

## 3. Etiqueta las líneas con nombres de usuario

- La [función `regexp.scan`][scan] se puede usar para capturar partes de un string usando una expresión regular.
- No olvides escapar los caracteres que tienen un significado especial en las expresiones regulares.
