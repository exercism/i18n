# Instrucciones

Trabajas para un prestigioso bufete de abogados especializado en gestionar solicitudes de testamentos poco comunes.

En este ejercicio vas a abrir una bóveda misteriosa.
Eres el albacea de la herencia y vas a reunir los códigos secretos que tres familias han guardado durante mucho tiempo para obtener un número de cuenta y el código correspondiente.

Para evitar que alguna familia abra la bóveda por su cuenta, solo se puede abrir combinando sus conocimientos con un modificador secreto que conoces por la última voluntad.

Tienes tres tareas, todas relacionadas con ayudar a las familias a abrir la bóveda.

## 1. Toma asiento frente a las familias y extiende tus papeles

Define un espacio de nombres llamado `estate_executor`.
El código de las siguientes tareas debe estar definido en el cuerpo del espacio de nombres `estate_executor`.

```cpp
namespace some_name {
    // The space between the curly brackets
    // is called body of the  namespace.
}
```

## 2. Encuentra el número de cuenta secreto

Este es tu gran momento.
Solo tú tienes la clave modificadora secreta para revelar el número de cuenta secreto.

Define la función `assemble_account_number(int secret_modifier)` que recibe el modificador secreto como argumento y devuelve el número de cuenta ensamblado como un `int`.

Para obtener el número correcto, debes sumar la `bank_number_part` de cada una de las tres familias.

## 3. Último paso: ingresa el código secreto

Las instrucciones del testamento te piden que sumes primero todos los fragmentos azules y luego todos los rojos.
El código resultante se obtiene multiplicando ambas sumas.

Define la función `assemble_code()` que devuelve el código resultante combinando los fragmentos de las tres familias en un solo `integer`.
La función no tiene argumentos y se basa únicamente en la información de los espacios de nombres correspondientes de las familias.
