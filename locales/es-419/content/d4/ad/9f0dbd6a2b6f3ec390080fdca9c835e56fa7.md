# Pistas

## General

- `<min-heap>`, `heap-push`, `heap-peek` y `heap-pop-all` están en [`heaps`][heaps]; `values` está en [`assocs`][assocs].
- Un heap guarda cada elemento como un *valor* con una *clave*; la clave es la prioridad. `heap-push` los recibe así: `( value key heap -- )`.

## 1. Abre la cola

- `<min-heap>` construye un min-heap vacío: la clave más pequeña se atiende primero.

## 2. Agrega un cliente

- El nombre del cliente es el valor y la prioridad es la clave, que es exactamente el orden que `heap-push` espera.
- `heap-push` consume la cola. Usa `[ heap-push ] keep` para agregar al cliente y aun así devolver la cola.

## 3. ¿Quién sigue?

- `heap-peek` devuelve `value key` para el elemento del frente sin quitarlo. Solo quieres el nombre, así que descarta la clave con `drop`.

## 4. Atiende a todos

- `heap-pop-all` vacía el heap en una lista de asociaciones de pares `{ key value }`, ya en orden de prioridad.
- `values` conserva solo los valores, es decir, los nombres.
