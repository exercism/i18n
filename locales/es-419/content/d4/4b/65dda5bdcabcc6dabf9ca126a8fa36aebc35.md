# Apéndice de instrucciones

## Implementación

Las funciones de este ejercicio aceptan un array que contiene uno o más números, y cada uno representa un «puntaje de una partida».

Los puntajes de las partidas del jugador se pueden leer desde

| `scores`   |
|---|
| `scores[0]` |
| `scores[1]` |
| ... |
| `scores[scores_len - 1]` |

`personal_top_three()` debe escribir los mejores puntajes del jugador en

| `output`   |
|---|
| `output[0]` |
| ... |
