# Pruebas

Para probar tu solución, abre la terminal y ejecuta

```
mason test
```

en la carpeta del ejercicio (la que contiene el archivo `Mason.toml` y las carpetas `src/` y `test/`).

Si crees que el mensaje de error no es lo suficientemente informativo, puedes probar lo siguiente para obtener uno más detallado.

```
mason test --show
```
