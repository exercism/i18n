# Acerca de

En Common Lisp, las funciones globales con nombre se definen con `defun`.

Esta forma toma como primer argumento una lista de parámetros de la función que se está definiendo (la lista de parámetros también se llama «lista lambda»).
Después puede, de forma opcional, tomar un string que sirva como documentación de esa función.
Por último, hay cero o más expresiones que conforman el cuerpo de la función.

Para llamar a una función se usa el nombre de la función como primer elemento de una expresión, seguido de los parámetros de esa función.

```lisp
(defun add-one (x) (1+ x))

(add-one 3) ;; => 4
```

Las funciones también pueden tomar [parámetros opcionales][concept-optional-parameters], [parámetros de palabra clave][concept-keyword-parameters] y [parámetros rest][concept-rest-parameters].
Estos se tratarán en conceptos posteriores.

El nombre de la función está dentro del ámbito del cuerpo de la función, de manera que se puede realizar la recursión.

```lisp
(defun countdown (x)
  (if (zerop x) (print 'BLAST-OFF)
    (progn (print x) (countdown (1- x)))))

(countdown 3) ;; will print "3","2", "1" and "BLAST-OFF" to
              ;; standard output before evalutaing to 'BLAST-OFF
```
