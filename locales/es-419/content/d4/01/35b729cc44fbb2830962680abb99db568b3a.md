# Pistas

## General
- El [tipo][types] de una variable depende del valor de esa variable: *10* como `Int`, *'Hello'* como `String` o *2.0* como `double`.

## 1. Define el tiempo de horneado esperado como constante en minutos

- Necesitas definir una variable constante y asignarle un valor entero.
- Las constantes se pueden definir a través del [cmdlet New-Variable][new variable].

## 2. Calcula el tiempo de horneado restante en minutos

- Necesitas definir una [función][defining functions] con un solo parámetro.
- Usa el [operador matemático de resta][arithmetic] para restar valores.
- Esta función debe [devolver un valor][return].

## 3. Calcula el tiempo de preparación en minutos

- Necesitas definir una [función][defining functions] con un solo parámetro.
- Usa el [operador matemático de multiplicación][arithmetic] para multiplicar valores.
- Podrías definir una _constante_ adicional para el tiempo en minutos por capa en lugar de usar un «número mágico» en tu código.
- Esta función debe [devolver un valor][return] de tipo entero.

## 4. Calcula el tiempo total de cocción transcurrido (preparación + horneado) en minutos

- Define una [función][defining functions] con dos parámetros.
- Puedes _llamar_ a una función que hayas definido antes.
- Puedes usar el [operador matemático de suma][arithmetic] para sumar valores.
- Esta función debe [devolver un valor][return] de tipo entero.

## 5. Actualiza la receta con notas

- Define una función sin parámetros.
- Esta función debe devolver un valor de tipo string.
