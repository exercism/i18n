# Comentarios y problemas

El [repositorio exercism/purescript](https://github.com/exercism/purescript/)
es la fuente principal para encontrar respuestas a las preguntas más comunes
sobre la instalación, la ejecución de las pruebas, problemas comunes del lenguaje, etc.

Si no encuentras una respuesta o tienes una sugerencia que mejore el
proyecto, considera crear un [issue](https://github.com/exercism/purescript/issues).
