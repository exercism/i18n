# Pistas

## General

- No te preocupes por cómo se obtienen los argumentos; solo concéntrate en combinarlos para devolver el resultado deseado.

## 1. Define si pac-man puede comer un fantasma

- La función debe devolver un valor Boolean.
- Puedes usar el operador lógico y ([`&&`][logical operators]) para combinar los argumentos y obtener un resultado.

## 2. Define si pac-man anota puntos

- La función debe devolver un valor Boolean.
- Puedes usar el operador lógico o ([`||`][logical operators]) para combinar los argumentos y obtener un resultado.

## 3. Define si pac-man pierde

- La función debe devolver un valor Boolean.
- Puedes usar los operadores Boolean [`&&`][logical operators] y [`!`][logical operators] para combinar los argumentos y obtener un resultado.

## 4. Define si pac-man gana

- La función debe devolver un valor Boolean.
- Puedes usar los operadores Boolean [`&&`][logical operators] y [`!`][logical operators] para combinar los argumentos y los resultados de una de las funciones que implementaste antes.

[logical operators]: https://en.cppreference.com/w/cpp/language/operator_logical
