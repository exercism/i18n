## Módulos

El código de Gleam se organiza en módulos, y cada archivo es un módulo de Gleam.

Hasta ahora hemos escrito funciones con la sintaxis `pub fn`, que define una función disponible públicamente para otros módulos. Las funciones definidas con `fn` son privadas del módulo en el que se definen y no pueden usarse desde otros módulos.

```gleam
// This function is public
pub fn add(x, y) {
  x + y
}

// This function is private
fn subtract(x, y) {
  x - y
}
```

Los módulos de Gleam tienen nombre, y ese nombre se basa en la ruta del archivo dentro del directorio `src` o `test`.

Por ejemplo, un módulo definido en `src\geometry\rectangle.gleam` (en Windows) o `src/geometry/rectangle.gleam` (en sistemas operativos tipo UNIX) se llamaría `geometry/rectangle`.

## Importar funciones de otros módulos

Para acceder a las funciones definidas en otros módulos se usan las importaciones.
Al importar un módulo, se vuelven accesibles todas las funciones que ese módulo expone.
Pero la forma de acceder a ellas varía según cómo se importe el módulo.

Las importaciones calificadas son las predeterminadas, y para acceder a una función de ese módulo (por ejemplo, la función `map` del módulo `gleam/list`) se antepone el nombre del módulo (`list.map`).

```gleam
// Import the int module
import gleam/int

pub fn run(x: Int) -> String {
  // Use the to_string function from the int module
  int.to_string(x)
}
```

De forma predeterminada, el nombre que se usa para referirse al módulo es la última parte del nombre del módulo, en este caso `int`, pero esto se puede cambiar con la palabra clave `as`.

```gleam
// Import the int module and refer to it as i
import gleam/int as i

pub fn run(x: Int) -> String {
  i.to_string(x)
}
```

Las importaciones sin calificar permiten acceder directamente a las funciones expuestas de ese módulo, sin prefijo.

```gleam
// Import the to_string function from the int module
import gleam/int.{to_string}

pub fn run(x: Int) -> String {
  to_string(x)
}
```

Se prefieren las importaciones calificadas porque dejan más claro de dónde viene cada función y ayudan a evitar conflictos de nombres.
