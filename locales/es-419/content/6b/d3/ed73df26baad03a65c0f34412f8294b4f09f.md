# Instrucciones

En este ejercicio vas a escribir código para ayudar a un freelancer a comunicarse con un gerente de proyecto, dándole algunas utilidades para calcular rápidamente tarifas diarias y mensuales, opcionalmente con un descuento dado.

Primero establecemos algunas reglas entre el freelancer y el gerente de proyecto:

- La tarifa diaria es 8 veces la tarifa por hora.
- Un mes tiene 22 días facturables.

A veces, el freelancer ofrece aplicar un descuento sobre su tarifa diaria (por ejemplo, para sus clientes más leales o para clientes sin fines de lucro).

Los descuentos se modelan como números fraccionarios que representan un porcentaje, por ejemplo `25.0` (25 %).

## 1. Calcular la tarifa diaria dada una tarifa por hora

Implementa una función para calcular la tarifa diaria dada una tarifa por hora:

```haskell
dailyRate 60
-- -> 480.0
```

La tarifa diaria devuelta debe ser un double.

## 2. Calcular un precio con descuento

Implementa una función para calcular el precio después de aplicar un descuento.

```haskell
applyDiscount 150 10
-- -> 135.0
```

El valor devuelto debe ser siempre un double, sin redondearlo de ninguna manera.

## 3. Calcular la tarifa mensual, dadas una tarifa por hora y un descuento

Implementa una función para calcular la tarifa mensual y aplicar un descuento:

```haskell
monthlyRate 77 10.5
-- -> 12130
```

La tarifa mensual devuelta debe redondearse hacia arriba (tomar el techo) al entero más cercano.

## 4. Calcular el número de días de trabajo dados un presupuesto, una tarifa por hora y un descuento

Implementa una función que reciba un presupuesto, una tarifa por hora y un descuento, y calcule cuántos días de trabajo cubre eso.

```haskell
daysInBudget 20000 80 11.0
-- -> 35.1
```

El número de días devuelto debe redondearse hacia abajo (tomar el piso) a un decimal.
