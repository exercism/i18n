# Pruebas

Si descargaste un ejercicio con la herramienta CLI, deberías ver un archivo de Futhark con el nombre del ejercicio y un archivo `test.fut`.
Este archivo contiene todos los casos de prueba, que coinciden con los que ejecuta el ejecutor de pruebas cuando subes tu solución.
Puedes agregar casos de prueba adicionales para experimentar sin problema.
Sin embargo, modificar las pruebas no afecta al proceso del ejecutor de pruebas en línea.

## Pruebas locales

Para ejecutar las pruebas de un ejercicio, abre una terminal en el directorio del ejercicio y ejecuta el comando `futhark test test.fut` (o `exercism test`).

## Recursos adicionales

Para saber más sobre cómo hacer pruebas con Futhark, consulta la documentación de [`futhark test`][test-command].
