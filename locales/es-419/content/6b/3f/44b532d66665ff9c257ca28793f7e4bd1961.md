# Introducción

Trabajas para una empresa de bioingeniería que se especializa en desarrollar soluciones terapéuticas.

A tu equipo acaban de asignarle un nuevo proyecto para desarrollar una terapia dirigida contra un tipo poco común de cáncer.

~~~~exercism/note
Todo es muy complicado, pero la idea básica es que a veces el cuerpo de las personas produce demasiada cantidad de una proteína determinada.
Eso puede causar todo tipo de estragos.

Pero si logras crear una molécula muy específica (llamada microARN), esta puede evitar que la proteína se produzca.

Esta técnica se llama [interferencia de ARN][rnai].

[rnai]: https://admin.acceleratingscience.com/ask-a-scientist/what-is-rnai/
