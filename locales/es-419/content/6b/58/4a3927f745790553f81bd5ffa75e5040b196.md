# Apéndice de instrucciones

Si te llama la atención un desafío más exigente, puedes habilitar las pruebas adicionales si quitas el comentario de una línea en `rational-numbers.jl`.

Estas pruebas requieren un conocimiento bastante más avanzado de Julia y de su sistema de tipos.

El archivo `runtests.jl` contiene algunos enlaces que pueden resultarte útiles.

El archivo `rational-numbers.jl` no incluye a propósito más indicaciones para las pruebas adicionales: piensa con cuidado en las importaciones, las definiciones de tipos y las funciones adicionales.
