# Instrucciones

Tu equipo está trabajando en una aplicación de meteorología.
Han definido una API con varios tipos y constantes que representan datos meteorológicos; consulta el archivo `meteorology.go`.

Tu tarea es agregar métodos `String` adecuados a todos los tipos para que implementen la interfaz `Stringer`.

## 1. Implementa la interfaz `Stringer` para el tipo `TemperatureUnit`

Después de algunas conversaciones, el equipo acordó que la unidad de temperatura sería `Celsius` o `Fahrenheit`.
Los valores deben formatearse como se muestra en los ejemplos a continuación.

Haz que el tipo `TemperatureUnit` implemente la interfaz `Stringer` agregándole un método `String`.
Este método debe devolver el string `"°C"` si la unidad de temperatura es Celsius o `"°F"` si la unidad de temperatura es Fahrenheit.

```go
celsiusUnit := Celsius
fahrenheitUnit := Fahrenheit

celsiusUnit.String()
// => °C
fahrenheitUnit.String()
// => °F
fmt.Sprint(celsiusUnit)
// Output: °C
```

## 2. Implementa la interfaz `Stringer` para el tipo `Temperature`

Los valores de temperatura constan de un número entero y una unidad de temperatura.
Deben formatearse como en los ejemplos a continuación.

Para lograrlo, haz que el tipo `Temperature` implemente la interfaz `Stringer` agregándole un método `String`.
Este método debe devolver un string con el valor numérico de la temperatura y la unidad de temperatura separados por un espacio: `<temperature> <unit>`:

```go
celsiusTemp := Temperature{
    degree: 21,
    unit: Celsius,
}
celsiusTemp.String()
// => 21 °C
fmt.Sprint(celsiusTemp)
// Output: 21 °C

fahrenheitTemp := Temperature{
    degree: 75,
    unit: Fahrenheit,
}
fahrenheitTemp.String()
// => 75 °F
fmt.Sprint(fahrenheitTemp)
// Output: 75 °F
```

## 3. Implementa la interfaz `Stringer` para el tipo `SpeedUnit`

Después de largas discusiones, el equipo acordó que la unidad de velocidad del viento sería `KmPerHour` o `MilesPerHour`.
Los valores deben formatearse como en los ejemplos a continuación.

Para lograrlo, haz que el tipo `SpeedUnit` implemente la interfaz `Stringer` agregándole un método `String`.
Este método debe devolver el string `"km/h"` si la unidad de velocidad es kilómetros por hora o `"mph"` si la unidad de velocidad es millas por hora:

```go
mphUnit := MilesPerHour
mphUnit.String()
// => mph
fmt.Sprint(mphUnit)
// Output: mph

kmhUnit := KmPerHour
kmhUnit.String()
// => km/h

// Output: km/h
```

## 4. Implementa la interfaz `Stringer` para `Speed`

Los valores de velocidad del viento constan de un número entero y una unidad de velocidad.
Deben formatearse como en el ejemplo a continuación.

Para lograrlo, haz que el tipo `Speed` implemente la interfaz `Stringer` agregándole un método `String`.
Este método debe devolver un string con el valor numérico de la velocidad y la unidad de velocidad separados por un espacio: `<speed> <unit>`:

```go
windSpeedNow := Speed{

    unit: KmPerHour,
}
windSpeedNow.String()

// Output: 18 km/h

    magnitude: 22,

// Output: 22 mph
```

## 5. Implementa la interfaz `Stringer` para el tipo `MeteorologyData`

Los datos meteorológicos especifican la ubicación, la temperatura, la dirección del viento, la velocidad del viento y la humedad.
Deben formatearse como en el ejemplo a continuación:

Para lograrlo, haz que el tipo `MeteorologyData` implemente la interfaz `Stringer` agregándole un método `String`.
Este método debe devolver los datos meteorológicos con el siguiente formato:

```text
<location>: <temperature>, Wind <wind_direction> at <wind_speed>, <humidity>% Humidity
```

```go
sfData := MeteorologyData{
    location: "San Francisco",
    temperature: Temperature{
        degree: 57,
        unit: Fahrenheit
    },
    windDirection: "NW",
    windSpeed: Speed{
        magnitude: 19,
        unit: MilesPerHour
    },
    humidity: 60
}

sfData.String()
// => San Francisco: 57 °F, Wind NW at 19 mph, 60% Humidity
fmt.Sprint(sfData)
// Output: San Francisco: 57 °F, Wind NW at 19 mph, 60% Humidity
```
