# Acerca de

Los valores Boolean en F# se representan con el tipo `bool`, que puede tomar los valores `true` o `false`.

F# admite tres [operadores Boolean][operators]: `not` (NOT), `&&` (AND) y `||` (OR). Los operadores `&&` y `||` usan _evaluación de cortocircuito_, lo que significa que el lado derecho del operador solo se evalúa cuando es necesario.

```fsharp
true || false // => true
true && false // => false
```

Los tres operadores Boolean tienen una [_precedencia de operadores_][precedence] diferente. En consecuencia, se evalúan en este orden: `not` primero, `&&` segundo y, por último, `||`. Si quieres «escapar» de estas reglas, puedes encerrar una expresión Boolean entre paréntesis (`()`), ya que los paréntesis tienen una precedencia de operadores incluso mayor.

```fsharp
not true && false   // => false
not (true && false) // => true
```
