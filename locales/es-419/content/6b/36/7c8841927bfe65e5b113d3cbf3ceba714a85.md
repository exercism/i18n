# Anexo de instrucciones

## Pistas

Necesitas implementar las funciones `decode` y `encode`, que decodifican y codifican un `String` usando un cifrado afín.
Puedes usar la firma que te damos si tienes dudas sobre los tipos, pero no dejes que limite tu creatividad.

Este ejercicio trabaja con datos textuales.
Por razones históricas, el tipo `String` de Haskell es sinónimo de `[Char]`, una lista de caracteres.
Para manejar datos textuales de forma más eficiente, puedes usar el tipo `Text`.

Como extensión opcional de este ejercicio, puedes

- agregar `- text` a tu lista de dependencias en package.yaml.
- importar `Data.Text` [de la siguiente manera](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c):

```haskell
import qualified Data.Text as T
import           Data.Text (Text)
```

- usar el tipo `Text`, por ejemplo `decode :: Text -> Text`, y referirte a los combinadores de `Data.Text` como, por ejemplo, `T.pack`.
- consultar la documentación de [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html).
- reemplazar todas las apariciones de `String` por `Text` en Affine.hs, es decir:

```haskell
encode :: (Int, Int) -> Text -> Maybe Text
encode key plainText = ...

decode :: (Int, Int) -> Text -> Maybe Text
decode key cipherText = ...
```

Esta parte es completamente opcional.
