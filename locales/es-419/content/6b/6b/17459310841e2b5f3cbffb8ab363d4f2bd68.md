# Instrucciones

El trabajo avanza bien en _Instruments of Texas_ con la calculadora RPN. Tu equipo ahora quiere poder escribir una versión de la ecuación como string a un recurso de _IO_.

## 1. Abre un archivo

Tu equipo todavía no ha decidido a qué tipo de dispositivo escribir la ecuación, así que sugieres usar un enfoque de _despacho dinámico_ para poder inyectar el recurso en la función en lugar de codificarlo directamente. Implementa la función `write/3` para abrir un _dispositivo de IO_ usando el recurso y el nombre del archivo.

Puedes asumir que `resource` siempre será un átomo que representa un módulo que tiene una función `open/1` que devuelve `{:ok, io_device}`.

Cuando la función tenga éxito, devuelve una tupla ok con la ecuación.

```elixir
RPNCalculator.Output.write(resource, "file_to_be_written", "1 4 +")
# {:ok, "1 4 +"}
```

## 2. Intenta escribir en el dispositivo de IO

Ahora que abriste el dispositivo de IO, intenta escribir en él usando `IO.write/2`.

Extiende la función `write/3` para realizar esta acción. El intento de escritura puede lanzar un error; rescátalo y devuelve una tupla de error:

```elixir
RPNCalculator.Output.write(resource, "bad_file", "1 4 +")
# {:error, "Unable to write to resource"}
```

## 3. Cierra el dispositivo de IO

Es una buena práctica intentar siempre liberar los recursos que abriste, incluso si la función que usa el recurso lanza un error. Extiende la función `write/3` para llamar a la función de cierre del recurso y cerrar el _dispositivo de IO_.

Puedes asumir que `resource` siempre será un átomo que representa un módulo que tiene una función `close/1` que recibe un _dispositivo de IO_.
