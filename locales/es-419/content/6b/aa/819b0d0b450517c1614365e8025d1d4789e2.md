# Acerca de

Tcl, que se pronuncia «tickle» y es la abreviatura de Tool Command Language, es un lenguaje de programación dinámico y de código abierto.

Se diseñó con el objetivo de ser muy simple pero potente.
Es tan simple que toda su sintaxis se describe por completo en [solo 12 reglas][rules].
Y aun así es un lenguaje de programación completo.

Tcl convierte todo en *comandos*, incluso las asignaciones de variables, las definiciones de procedimientos y el flujo de control.
Por eso se parece tanto a los scripts de shell como a Lisp. 

Tcl soporta múltiples paradigmas de programación, entre ellos el orientado a objetos, el imperativo y el funcional.
Los casos de uso más comunes de Tcl son como entornos de ejecución de scripts embebidos en aplicaciones C, y para prototipar interfaces gráficas con el toolkit Tk.

Este track de Exercism todavía no ha implementado un temario de aprendizaje.
