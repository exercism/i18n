# Instrucciones

En este ejercicio vas a implementar un conjunto parcial de rutinas utilitarias para ayudar a un desarrollador a limpiar nombres de SqueakyClean.

A lo largo de las 4 tareas irás construyendo poco a poco el método `clean`.
Un nombre de SqueakyClean válido se compone de cero o más letras y guiones bajos.

En todos los casos, se garantiza que el string de entrada no es nulo. Ten en cuenta que el método `clean` debe tratar una cadena vacía como válida.

## 1. Reemplaza cualquier espacio que encuentres por guiones bajos

Implementa el método (_static_) `SqueakyClean.clean()` para reemplazar cualquier espacio por guiones bajos. Esto también aplica a los espacios al inicio y al final.

```java
SqueakyClean.clean("my   Id");
// => "my___Id"
```

## 2. Convierte kebab-case a camelCase

Modifica el método (_static_) `SqueakyClean.clean()` para convertir kebab-case a camelCase.

```java
SqueakyClean.clean("a-bc");
// => "aBc"
```

## 3. Convierte leetspeak a texto normal

Modifica el método (_static_) `SqueakyClean.clean()` para convertir [leetspeak][leet-speak] a texto normal.

Por simplicidad, solo reemplazaremos `4`, `3`, `0`, `1` y `7` por `a`, `e`, `o`, `l` y `t`, respectivamente.

```java
SqueakyClean.clean("H3ll0 W0rld");
// => "Hello_World"
SqueakyClean.clean("4 73s7");
// => "a_test"
```

## 4. Omite los caracteres que no sean letras

Modifica el método (_static_) `SqueakyClean.clean()` para omitir cualquier carácter que no sea una letra.

```java
SqueakyClean.clean("a$#.b");
// => "ab"
```

[leet-speak]: https://en.wikipedia.org/wiki/Leet
