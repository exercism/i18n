# Visitante del parque de diversiones

## Historia

En esta historia, trabajas con un parque de diversiones para implementar un sistema de admisión. Las personas (los visitantes) llegan al parque y, al entrar, se les mide la altura. Esto se debe a que ciertas atracciones del parque requieren que tengas cierta altura para subirte, por motivos de seguridad.

Algunos visitantes eligen comprar un pase de atracciones, y entonces se les entrega el pase. La representación real del pase no es importante para el ejercicio de Ruby, así que se representa con un Integer si existe, y con `nil` si no.

La parte 1 (el ejercicio de variables de instancia) trata de variables de instancia, getters y setters.

La parte 2 (booleanos) trata de valores booleanos, veracidad, métodos de comparación y operadores lógicos.

## Tareas

Tareas de ejemplo:

- Admitir a una persona nueva (Attendee) en el parque
- obtener el pase de atracciones y la altura
- emitir un pase
- revocar un pase
- comprobar si la persona tiene un pase
- comprobar si una persona cumple con la altura para una atracción
- comprobar si una persona tiene permitido subirse a una atracción
