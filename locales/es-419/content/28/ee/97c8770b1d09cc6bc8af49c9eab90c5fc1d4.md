# Pistas

## General

-   Un literal entero se puede definir como uno o más dígitos consecutivos.

## 1. Define el tiempo esperado de horneado en minutos

-   Necesitas definir una [función][functions] sin ningún parámetro.

## 2. Calcula el tiempo de horneado restante en minutos

-   Necesitas definir una [función][functions] con un solo parámetro.
-   Puedes usar y referirte al elemento que definiste antes por su nombre.
-   La última expresión de una función [se devuelve automáticamente][return-values] desde la función; no tienes que indicar explícitamente qué valor devolver.
-   Puedes usar el [operador matemático para la resta][operators] para restar valores.

## 3. Calcula el tiempo de preparación en minutos

-   Necesitas definir una [función][functions] con un solo parámetro.
-   Puedes usar el [operador matemático para la multiplicación][operators] para multiplicar valores.

## 4. Calcula el tiempo transcurrido en minutos

-   Necesitas definir una [función][functions] con dos parámetros.
-   Puedes [llamar][functions] a una de las otras funciones que definiste antes.
-   Puedes usar el [operador matemático para la suma][operators] para sumar valores.

[functions]: https://doc.rust-lang.org/book/ch03-03-how-functions-work.html
[return-values]: https://doc.rust-lang.org/book/ch03-03-how-functions-work.html#functions-with-return-values
[operators]: https://doc.rust-lang.org/book/appendix-02-operators.html
