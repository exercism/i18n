# Acerca de

Los Boolean en Kotlin se representan con el tipo `Boolean`, cuyos valores pueden ser `true` o `false`.

Kotlin admite tres [operadores booleanos][reference] integrados: `!` (negación, también conocida como NOT), `&&` (conjunción perezosa, también conocida como AND) y `||` (disyunción perezosa, también conocida como OR). Los operadores `&&` y `||` usan _evaluación de cortocircuito_, lo que significa que el lado derecho del operador solo se evalúa cuando es necesario.

```kotlin
true || false // => true
true && false // => false
```

Los tres operadores booleanos tienen cada uno una [_precedencia de operadores_][precedence] distinta. Como consecuencia, se evalúan en este orden: `!` primero, `&&` segundo y, por último, `||`. Si quieres «escapar» de estas reglas, puedes encerrar una expresión booleana entre paréntesis (`()`), ya que los paréntesis tienen una precedencia de operadores aún mayor.

```kotlin
!true && false   // => false
!(true && false) // => true
```

[reference]: https://kotlinlang.org/docs/reference/basic-types.html#booleans
[precedence]: https://kotlinlang.org/docs/reference/grammar.html#expressions
