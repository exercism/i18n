# Anexo a las instrucciones

## Mensajes de excepción

A veces es necesario [lanzar una excepción][raising-exceptions].
Cuando lo haces, siempre debes incluir un **mensaje de error significativo** que indique cuál es el origen del error.
Esto hace que tu código sea más legible y ayuda mucho con la depuración.
En los casos en los que sabes que el origen del error será de un tipo determinado, puedes optar por lanzar uno de los [tipos de error integrados][error-base-classes], pero aun así debes incluir un mensaje significativo.


Una partida válida de `Tic Tac Toe` termina cuando uno de los jugadores gana.
Si ambos jugadores están en un estado ganador, este ejercicio espera que uses la [sentencia raise][raise] y «lances» un `ValueError` en tu solución.
También se espera que tu código lance un `ValueError` si se determina que un jugador jugó dos turnos seguidos, o que jugó el primer movimiento cuando le correspondía jugar el segundo.


Para lanzar un `ValueError` con un mensaje, escribe el mensaje como argumento del tipo `exception`:

```python
# Example when player O goes before player X.
raise ValueError("Wrong turn order: O started")

# Example when player X goes twice.
raise ValueError("Wrong turn order: X went twice")

# Example when player X wins AND player O wins.
raise ValueError("Impossible board: game should have ended after the game was won")
```

Las pruebas verificarán que el mensaje de error coincida exactamente, así que lee con atención los resultados esperados.

[error-base-classes]: https://docs.python.org/3/library/exceptions.html#base-classes
