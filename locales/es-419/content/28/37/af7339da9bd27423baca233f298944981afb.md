# Introducción

La interpolación de string es compatible con Haxe: encierra un string entre comillas simples (`'`) y usa el signo de dólar (`$`) para activar la interpolación.

También es posible incluir expresiones completas usando `${expr}`, donde `expr` es cualquier expresión válida de Haxe.

```haxe
var x = 10;
trace('They have $x apples, of which ${x - 4} are red.');
// They have 10 apples of which 6 are red.
```
