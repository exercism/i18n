# Introducción

En Ruby, los **arreglos** son colecciones ordenadas de cualquier objeto, indexadas por números enteros.
La indexación de un array empieza en `0`.
Un índice negativo se interpreta como relativo al final del array, es decir, un índice de `-1` señala el último elemento del array, `-2` es el penúltimo elemento, y así sucesivamente.
Los arrays de Ruby incluyen el [módulo Enumerable][enumerable-module], que agrega varios métodos de recorrido y búsqueda, además de la capacidad de ordenar.

## Crear un array

- Un array en Ruby puede contener objetos de diferentes tipos.

```ruby
array = [1, "two", 3.0] #=> [1, "two", 3.0]
```

## Asignación de elementos

Se puede acceder a los elementos o cambiarlos usando índices.
Se puede acceder a subarrays especificando un índice inicial y un tamaño.

```ruby
a = ["", "", "", "", ""]

a[4] = "hello"  #=> [nil, nil, nil, nil, "hello"]
a[0, 3] = [ 'a', 'b', 'c' ] #=> ["a", "b", "c", nil, "hello"]
```

- Los índices negativos cuentan hacia atrás desde el final del array.

```ruby
a = ['a', 'b']

a[-1] = "Z"
a #=> ["a", "Z"]
```

## Referencia de elementos

- Los elementos de un array se pueden obtener con el método #[].
- Devuelve el elemento en el índice indicado, o devuelve un subarray que empieza en el índice inicial y continúa durante length elementos.

```ruby
a = [ "a", "b", "c", "d", "e" ]

a[2]    #=> "c"
a[6]    #=> nil
a[1, 2] #=> [ "b", "c" ]
```

- Los índices negativos cuentan hacia atrás desde el final del array (-1 es el último elemento)

```ruby
a = [ "a", "b", "c", "d", "e" ]

a[-2]    #=> "d"
a[-3, 3] #=> [ "c", "d", "e" ]
```

## Obtener información sobre un array

Los arrays llevan un registro de su propia longitud en todo momento.
Para consultar cuántos elementos contiene un array, usa length, count o size.

```ruby
browsers = ['Chrome', 'Firefox', 'Safari', 'Opera', 'IE']
browsers.length #=> 5
browsers.count  #=> 5
browsers.size   #=> 5
```

## Agregar elementos a un array

Puedes agregar elementos al final de un array con `push` o `<<`:

```ruby
arr = [1, 2, 3, 4]
arr.push(5) #=> [1, 2, 3, 4, 5]
arr << 6    #=> [1, 2, 3, 4, 5, 6]
```

## Eliminar elementos de un array

El método pop elimina el último elemento de un array y lo devuelve:

```ruby
arr = [1, 2, 3, 4, 5, 6]
arr.pop #=> 6
arr     #=> [1, 2, 3, 4, 5]
```
