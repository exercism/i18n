# Introducción

A veces no necesitas la sobrecarga de crear un objeto con estado.
En esos casos, puedes usar un `module`.

Un módulo es muy similar a una clase (de hecho, `Module` es un ancestro de `Class` en la jerarquía de objetos). La principal diferencia es que, en lugar de usar métodos de instancia, usamos métodos de clase.
Los métodos de clase empiezan con `self.` y se llaman directamente sobre un módulo.

Por ejemplo:

```ruby
module Speaker
  def self.echo(something)
    "#{something} ... #{something}"
  end
end

Speaker.echo("Hello")   #=> "Hello ... Hello"
```
