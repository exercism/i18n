# Acerca de

Las tuplas se usan comúnmente para agrupar información de manera informal. Un patrón común en Elixir es agrupar los valores de retorno de una función junto con un estado.

```elixir
File.read("hello.txt")
# => {:ok, "World"}

File.read("invalid.txt")
# => {:error, :enoent}
```

- Los literales de tupla se escriben entre llaves, `{}`.
- Las tuplas pueden contener cualquier tipo de datos en memoria contigua, la cual se asigna cuando se crea la tupla.
- Las tuplas permiten un acceso de lectura en tiempo constante.
- Cuando manipulas una tupla, en lugar de modificar la tupla existente, se crea una nueva.
- Las características de rendimiento de las tuplas las hacen ideales para almacenar información relacionada en conjunto, pero no para almacenar colecciones de elementos que necesiten recorrerse o que puedan crecer o encogerse. En este último caso, [una lista es más apropiada][getting-started-lists-or-tuples].
- Los módulos [`Kernel`][kernel-module] y [`Tuple`][tuple-module] tienen funciones útiles para trabajar con tuplas.
