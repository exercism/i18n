# Introducción

Además del condicional, JavaScript también tiene una sentencia `switch` para ejecutar lógica de forma condicional.
Se usa cuando es necesario comparar una sola variable con múltiples variantes.
La comparación se hace comprobando la igualdad estricta (`===`), consulta el [concepto de comparación][concept-comparison].
Para una variable cualquiera `x`, la sentencia `switch` en JavaScript tiene la siguiente sintaxis.

<!-- prettier-ignore-start -->
```javascript
switch (x) {
  case option1:
    // code that is executed when "x === option1" is true
    break;
  case option2:
    // code that is executed when "x === option2" is true
    break;
  default:
    // code that is executed when x does not equal any of the options
}
```
<!-- prettier-ignore-end -->

El caso `default` es opcional y se usa cuando quieres ejecutar algún código si ninguna de las otras opciones coincide con la variable.

Las sentencias `break` de arriba son necesarias porque, de forma predeterminada, todos los casos se ejecutan en cascada en JavaScript.
Eso significa que sin ninguna sentencia `break`, se ejecutaría todo el código de los casos que están debajo de la primera opción que coincida, aunque `x` no coincida con esas opciones.
Este comportamiento de ejecución en cascada por defecto es una trampa común al usar `switch` en JavaScript.
Dentro de una función, también se puede usar `return` en lugar de `break` para evitar este problema.
