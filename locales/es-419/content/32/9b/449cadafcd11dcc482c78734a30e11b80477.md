## 1. Sugiere una combinación

- En la comprensión de listas, usa dos _generadores_ para crear el producto cartesiano.

## 2. Filtra los conjuntos que no combinan

- Puedes usar _pattern matching_ para deconstruir en el _generador_ y así asignar los campos a una variable.
- Usa una _expresión de filtro_ para devolver false cuando los colores base coincidan.

## 3. Filtra por el precio de la combinación

- Hay varias [funciones de listas de palabras clave][kw-module] que puedes usar para obtener opciones de una lista de palabras clave.
- Usa una _expresión de filtro_ para devolver false cuando el precio combinado sea mayor que el precio máximo.
