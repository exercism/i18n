# Instrucciones

Mientras organizan una noche de juegos con amigos, el grupo decide revivir los favoritos de su infancia. Tu amigo alemán propone _Mensch ärgere Dich nicht_ (_Hombre, no te enfades_), un clásico en muchos países europeos (similar al _Ludo_ inglés o al _Parcheesi_ norteamericano).

Para prepararte para la partida, decides implementar la función para lanzar los dados en Elixir.

En _Mensch ärgere Dich nicht_, los jugadores lanzan un dado de 6 caras para determinar su siguiente movimiento. Si tienen suerte y sacan un 6, pueden volver a lanzar y mover.

## 1. Haz una tirada de un dado de 6 caras

Implementa la función `d6/0`, que elegirá aleatoriamente un número entero entre 1 y 6 en cada llamada.

```elixir
MenschAergereDichNicht.d6()
# => 1
MenschAergereDichNicht.d6()
# => 5
```

## 2. Sigue lanzando mientras saques seises

Implementa la función `roll/0`. Debe devolver un stream de tiradas de dados. Las tiradas deben seguir las reglas del juego. Si sacas un seis, puedes lanzar de nuevo. Si no, se deja de lanzar. Usa la función `d6/0` definida en el paso anterior.

```elixir
MenschAergereDichNicht.roll() |> Enum.to_list()
# => [5]
MenschAergereDichNicht.roll() |> Enum.to_list()
# => [6, 3]
```

## 3. Permite usar un dado cargado

Para que sea más fácil probar tu código, permite usar un dado cargado.

Extiende la función `roll/0`. Debe aceptar un argumento opcional: una función. Si se pasa el argumento, úsalo para hacer la tirada del dado. Si no, recurre a `MenschAergereDichNicht.d6/0`.

```elixir
MenschAergereDichNicht.roll(fn -> 3 end) |> Enum.to_list()
# => [3]
```
