# Acerca de

Al escribir funciones en Haskell, podemos hacer uso de la [coincidencia de patrones][pattern-matching].
La coincidencia de patrones es una característica muy potente de Haskell que te permite hacer coincidencia con constructores de datos y vincular variables a los valores que contienen.
Como su nombre lo indica, lo que hacemos es comparar valores con patrones y, si el valor coincide con el patrón, podemos vincular variables a los valores que están dentro de ese patrón.
La coincidencia de patrones se construye principalmente sobre estos conceptos: reconocer valores, vincular variables y descomponer valores.

~~~~exercism/note
La coincidencia de patrones en lenguajes como Elixir es un poco diferente de la coincidencia de patrones en Haskell.
En Elixir, por ejemplo, puedes vincular el mismo nombre varias veces en un patrón, mientras que en Haskell no.
~~~~


Toma esta función como ejemplo:

```haskell
lucky :: Int -> String
lucky 7 = "Lucky number seven!"
lucky x = "Sorry, you're out of luck, pal!"
```

Aquí tenemos una función `lucky` que toma un `Int` y devuelve un `String`.
Definimos dos patrones para la función: uno que coincide con el número `7` y otro que coincide con cualquier otro número. El nombre puede ser cualquiera (siempre que siga la convención de nombres de Haskell), pero aquí usamos `x`.
Si el número es `7`, la función devolverá `"Lucky number seven!"`; de lo contrario, devolverá `"Sorry, you're out of luck, pal!"`.
Es importante notar que los patrones se revisan de arriba hacia abajo, así que si hubiéramos intercambiado el orden de los patrones, la función siempre devolvería `"Lucky number seven!"`.

## Patrones con listas

Un patrón muy común es hacer coincidencia con listas, lo que consiste en tomar la cabeza y la cola de la lista.
Esto se debe a la naturaleza de las listas como listas enlazadas.
Aquí tienes un ejemplo de una función que devuelve la cabeza y la cola de una lista:

```haskell
headAndTail :: [Int] -> (Int, [Int])
headAndTail [] = error "Can't call head on an empty list"
headAndTail (x:xs) = (x, xs)
```

Aquí tenemos dos patrones: uno que coincide con una lista vacía y otro que coincide con una lista con al menos un elemento.
Esto se debe a que, si la lista está vacía, necesitamos un caso para eso; de lo contrario, obtendríamos un error en tiempo de ejecución.
Si la lista no está vacía, podemos hacer coincidir la cabeza de la lista con `x` y la cola con `xs`.
Esto se hace con el operador `:` (cons), que se usa para agregar un elemento al principio de una lista.
Pero en la coincidencia de patrones nos permite descomponer una lista en su cabeza y su cola, así que, de cierta forma, hace lo contrario.

`xs` es un nombre común para la cola de una lista; resalta que es una lista, pero si trabajaras con una lista anidada, podrías usar `xss` para resaltar que es una lista de listas.

## Patrones con tuplas

Al igual que con las listas, también podemos hacer coincidencia con tuplas.
Aquí tienes un ejemplo de una función que toma una tupla y devuelve el primer y el segundo elemento:

```haskell
sumTuple :: (Int, Int) -> Int
sumTuple (x, y) = x + y
```

Aquí tenemos un patrón que coincide con una tupla de dos elementos: el primer elemento se vincula a `x` y el segundo, a `y`.

## Patrones comodín

A veces no nos importa el valor de una variable; solo queremos hacer coincidencia con el patrón.
Aquí es donde entra el patrón comodín, que se representa con un guion bajo `_`.

Aquí tienes un ejemplo de una función que devuelve el primer elemento de una lista:

```haskell
head' :: [Int] -> Int
head' [] = error "Can't call head on an empty list"
head' (x:_) = x
```

Aquí decimos que no necesitamos la cola de la lista, así que usamos el patrón comodín para ignorarla.

## Patrones con tipos

También podemos hacer coincidencia con tipos; esto se hace usando el constructor de dicho tipo.
También podemos extraer valores del tipo, como hicimos con las tuplas.

```haskell
data AccountType = Guest | User String 

greet :: AccountType -> String
greet Guest = "Welcome, guest!"
greet (User name) = "Welcome, " ++ name ++ "!"
```

En el primer patrón hacemos coincidencia con el constructor `Guest`, y en el segundo, con el constructor `User`, y vinculamos el valor que está dentro a `name`.
