# Instrucciones

Tu nostalgia por las tarjetas Blorkemon™️ no muestra señales de disminuir; incluso comenzaste a coleccionarlas de nuevo y estás animando a tus amigos a que se unan.

En este ejercicio, una colección de tarjetas se representa con un `MapSet`, ya que las tarjetas duplicadas no importan cuando tu objetivo es conseguir todas las tarjetas que existen.

## 1. Inicia una colección

De verdad quieres que tus amigos se unan a tu locura por Blorkemon™️, y la mejor forma de arrancar su colección es regalarles una tarjeta.

Implementa `GottaSnatchEmAll.new_collection`, que transforma una tarjeta en una colección.

```elixir
GottaSnatchEmAll.new_collection("Newthree")
# => MapSet.new(["Newthree"])
```

## 2. Haz crecer la colección

Una vez que tienes una colección, esta cobra vida propia y debe crecer.

Implementa `GottaSnatchEmAll.add_card`, que recibe una tarjeta y una colección, y devuelve una tupla con dos valores: un Boolean que indica si la tarjeta ya estaba en la colección, y la colección con la tarjeta agregada.

```elixir
GottaSnatchEmAll.add_card("Scientuna", MapSet.new(["Newthree"]))
# => {false, MapSet.new(["Newthree", "Scientuna"])}
```

## 3. Empieza a intercambiar

Ahora que tus amigos volvieron a enloquecer con Blorkemon™️, puedes aprovecharlo para hacer crecer tu propia colección intercambiando tarjetas.

No todo intercambio vale la pena, ni todos son posibles.
No puedes intercambiar una tarjeta que no tienes, y no deberías dar una tarjeta a cambio de otra que ya tienes.

Implementa `GottaSnatchEmAll.trade_card`, que recibe dos tarjetas para intercambiar (la tuya y la suya) y tu colección actual.
El valor de retorno es una tupla con dos valores: un Boolean que indica si el intercambio es posible y vale la pena, y la colección que tendrías si hicieras el intercambio (aunque en realidad no sea posible).

```elixir
GottaSnatchEmAll.trade_card("Scientuna", "Newthree", MapSet.new(["Scientuna"]))
# => {true, MapSet.new(["Newthree"])}
```

## 4. Solo puede haber una de cada una

Encuentras un viejo alijo de tarjetas en un mercado de pulgas.
Debes ordenar las tarjetas y eliminar los duplicados para comparar la lista con tu colección.

Implementa `GottaSnatchEmAll.remove_duplicates`, que ordena una lista de tarjetas y devuelve una lista de tarjetas únicas y ordenadas.

```elixir
GottaSnatchEmAll.remove_duplicates(["Newthree", "Newthree", "Newthree", "Scientuna"])
# => ["Newthree", "Scientuna"]
```

## 5. Tarjetas que ellos no tienen

Es momento de sentirte bien con tu colección.

Implementa `GottaSnatchEmAll.extra_cards`, que recibe tu colección y otra colección, y devuelve el número de tarjetas que la otra colección no tiene.

```elixir
GottaSnatchEmAll.extra_cards(MapSet.new(["Scientuna"]), MapSet.new(["Newthree", "Scientuna"]))
# => 0
```

## 6. Tarjetas que todos tienen

Tú y tus amigos aficionados a Blorkemon™️ se reúnen y se preguntan cuáles tarjetas son las más comunes.

Implementa `GottaSnatchEmAll.boring_cards`, que recibe una lista de colecciones y devuelve una lista de tarjetas ordenadas que todas las colecciones tienen.

```elixir
GottaSnatchEmAll.boring_cards([MapSet.new(["Scientuna"]), MapSet.new(["Newthree", "Scientuna"])])
# => ["Scientuna"]
```

## 7. Todas las tarjetas

¿Entre tú y tus amigos tienen todas las tarjetas Blorkemon™️?

Implementa `GottaSnatchEmAll.total_cards`, que recibe una lista de colecciones y devuelve el número total de tarjetas diferentes que hay en todas las colecciones.

```elixir
GottaSnatchEmAll.total_cards([MapSet.new(["Scientuna"]), MapSet.new(["Newthree", "Scientuna"])])
# => 2
```

## 8. Brillantes para ganar

Tu sobrino viene a visitarte pronto y tienes ganas de impresionarlo.
A los niños les gustan las cosas brillantes, ¿no?
¡Las tarjetas Blorkemon™️ pueden ser brillantes!

Implementa `GottaSnatchEmAll.split_shiny_cards`, que recibe una colección y devuelve una tupla con dos listas de tarjetas ordenadas: una con todas las tarjetas que empiezan con `"Shiny"` y otra con las demás tarjetas.

```elixir
GottaSnatchEmAll.split_shiny_cards(MapSet.new(["Newthree", "Scientuna", "Shiny Scientuna"]))
# => {["Shiny Scientuna"], ["Newthree", "Scientuna"]}
```
