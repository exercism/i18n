# Introducción

## Funciones con múltiples cláusulas

Elixir facilita las prácticas del **principio de abierto-cerrado** al permitir que las funciones tengan múltiples cláusulas; así, en lugar de recurrir a una lógica de control extensa y escrita a mano, se pueden escribir funciones específicas que agreguen o quiten comportamiento con facilidad.

Elixir ofrece _múltiples cláusulas de función_ y _guardas_ que te permiten escribir:

```elixir
def number(n) when n == 7 do
  "Awesome, that's my favorite"
end

def number(_n) do
  "That's not my favorite"
end
```

En tiempo de ejecución, Elixir evalúa, de arriba hacia abajo del archivo fuente, qué cláusula de función invocar.

Las variables que no se usan deben ir precedidas por un guion bajo.

## Guardas

Las guardas se usan para evitar que Elixir invoque funciones a partir de la evaluación de los argumentos que hacen las funciones de guarda. Las guardas comienzan con la palabra clave `when`, seguida de una expresión booleana. Las funciones de guarda son funciones especiales que:

- Deben ser puras y no modificar ningún estado global.
- Deben devolver valores estrictamente `true` o `false`.

Puedes encontrar una lista de guardas comunes en la [documentación de Elixir][kernel-guards]. Incluye verificaciones de tipos, aritmética básica, comparaciones y operadores estrictamente booleanos.

## Argumentos por defecto

Las funciones pueden declarar valores por defecto para uno o más argumentos. Consideremos esta función:

```elixir
def number(n \\ 13), do: "That's not my favorite"
```

Al compilar, Elixir crea una definición de función para `number/0` (sin argumentos) y `number/1` (un argumento).

Si más de un argumento tiene valor por defecto, esos valores se aplican a la función de izquierda a derecha para completar los argumentos que faltan.

Si la función tiene más de una cláusula, los argumentos por defecto deben definirse en un encabezado de función (una función sin cuerpo) antes de las cláusulas de la función:

```elixir
def number(n \\ 13)
def number(n) when n < 10, do: "Dream bigger!"
def number(n) when n > 100, do: "Not that big..."
```
