# Pistas

## General

- Lee sobre [charlists][getting-started-charlists], [Unicode y puntos de código][getting-started-code-points] y [`case`][getting-started-case] en la guía oficial Getting Started.
- Lee sobre [charlists][elixirschool-charlists] y [`case`][elixirschool-case] en elixirschool.com.

## 1. Sanea los nombres de usuario existentes eliminando todo menos las letras minúsculas

- Usa la recursión para recorrer un charlist.
- Hay una [función incorporada][kernel-case] que permite comparar un valor dado contra muchos patrones.
- Existe una [sintaxis especial][syntax-reference-code-points] para obtener el punto de código de un carácter. Se puede usar en guards.
- Los charlists son listas de puntos de código, y los puntos de código, al ser números, se pueden [comparar][kernel-greater-than] entre sí.
- Todas las letras latinas minúsculas tienen [puntos de código consecutivos][unicode-character-reference], en orden alfabético.
- Existe [una función incorporada][kernel-concat-list] que permite concatenar dos listas.

## 2. Permite los guiones bajos

- Existe una [sintaxis especial][syntax-reference-code-points] para obtener el punto de código de un carácter. Se puede usar en guards y también funciona para los signos de puntuación.
- Existe [una función incorporada][kernel-concat-list] que permite concatenar dos listas.

## 3. Sustituye los caracteres alemanes

- Existe una [sintaxis especial][syntax-reference-code-points] para obtener el punto de código de un carácter. Se puede usar en guards y también funciona para las letras que no son ASCII.
- Existe [una función incorporada][kernel-concat-list] que permite concatenar dos listas.
