# Introducción

## Constructores

Crear una instancia de una _clase_ se hace llamando a su _constructor_ mediante el operador `new`. Un constructor es un tipo especial de método cuyo objetivo es inicializar una instancia recién creada. Los constructores se parecen a los métodos normales, pero no tienen tipo de retorno y su nombre coincide con el de la clase.

```csharp
class Library
{
    private int books;

    public Library()
    {
        // Initialize the books field
        this.books = 10;
    }
}

// This will call the constructor
var library = new Library();
```

Al igual que los métodos normales, los constructores pueden tener parámetros. Por lo general, los parámetros del constructor se guardan como campos (privados) para acceder a ellos más adelante, o bien se usan en algún cálculo puntual. Se pueden pasar argumentos a los constructores igual que se pasan argumentos a los métodos normales.

```csharp
class Building
{
    private int numberOfStories;
    private int totalHeight;

    public Building(int numberOfStories, double storyHeight)
    {
        this.numberOfStories = numberOfStories;
        this.totalHeight = numberOfStories * storyHeight;
    }
}

// Call a constructor with two arguments
var largeBuilding = new Building(55, 6.2)
```
