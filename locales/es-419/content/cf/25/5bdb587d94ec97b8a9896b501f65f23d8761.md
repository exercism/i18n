# Métodos de String

`String` tiene varios métodos que se pueden usar para manipular strings.  
Estos métodos se llaman sobre el propio string y a menudo se encadenan para realizar varias operaciones sobre un string.

A continuación tienes una lista de algunos de los métodos más comunes.
Consulta la [documentación de la API de `String`][string-api] para ver una lista completa de métodos.

## String#upcase & String#downcase

El método [`upcase`][upcase] devuelve un nuevo string con todos los caracteres convertidos a mayúsculas.

```crystal
"hello".upcase
# => "HELLO"
```

El método [`downcase`][downcase] devuelve un nuevo string con todos los caracteres convertidos a minúsculas.

```crystal
"HELLO".downcase
# => "hello"
```

## String#capitalize & String#camelcase & String#underscore & String#titleize

Varios métodos pueden hacer conversiones de mayúsculas y minúsculas más específicas.
Eso puede ser útil cuando conviertes un string a un formato específico.
Aquí tienes una lista de algunos de los métodos más comunes:

| Método                            | Descripción                                                                                                        | Ejemplo                                              |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------- |
| [`String#capitalize`][capitalize] | Convierte la primera letra a mayúscula y el resto a minúsculas                                                     | `"hEllO" # => "Hello"`                               |
| [`String#camelcase`][camel-case]  | Convierte los guiones bajos a camelcase                                                                            | `"eiffel_tower" # => "EiffelTower"`                  |
| `String#camelcase(lower: true)`   | Igual que String#camelcase, pero deja el primer carácter en minúscula                                              | `"empire_state_building" # => "empireStateBuilding"` |
| [`String#underscore`][underscore] | Convierte todos los caracteres a minúsculas y coloca un guion bajo entre una letra minúscula y una letra mayúscula | `"PartyInTheUSA" # => "party_in_the_usa"`            |
| [`String#titleize`][titleize]     | Pone la primera letra de cada palabra en mayúscula y el resto en minúscula                                         | `"the great gatsBY" # => "The Great Gatsby"`         |

## String#sub & String#gsub

Crystal tiene métodos para reemplazar partes de un string.
Se conocen como [`sub`][sub] (_sustitución_) y [`gsub`][gsub] (_sustitución global_).

Estos métodos pueden recibir un string, un char o una regex como primer argumento, y un string o un char como segundo argumento.
El primer argumento es la parte del string que se reemplazará, y el segundo argumento es el reemplazo.
`Char` y las regex se explicarán en conceptos posteriores.

El método `sub` reemplaza la primera aparición del primer argumento con el segundo argumento.

```crystal
"hello".sub("l", "r")
# => "herlo"
```

El método `gsub` funciona igual que `sub`, pero reemplaza todas las apariciones del primer argumento con el segundo argumento.

```crystal
"hello".gsub("l", "r")
# => "herro"
```

## String#chomp & String#strip

Chomp y strip se pueden usar para eliminar caracteres no deseados de un string.

De forma predeterminada, el método [`chomp`][chomp] elimina los últimos caracteres `\r`, `\n` o `\r\n` de un string.
Si se llama al método con un argumento, eliminará el valor indicado del final del string.
Siempre que ese valor exista al final del string.

```crystal
"hello\n".chomp
# => "hello"

"hello".chomp("llo")
# => "he"
```

De forma predeterminada, el método [`strip`][strip] elimina todos los espacios en blanco del principio y el final de un string.
Si se llama al método con un argumento, eliminará ese argumento del principio y el final del string.
Siempre que ese argumento exista al principio o al final del string.

```crystal
" hello ".strip
# => "hello"
```

## String#reverse

Puedes usar el método [`reverse`][reverse] para invertir un string.
Este método devuelve un nuevo string con los caracteres en orden inverso.

```crystal
"hello".reverse
# => "olleh"
```

## String#index

El método [`index`][index] se puede usar para encontrar el índice de un carácter en un string.
El método `index` recibe un `String`, un `Char` o una regex como argumento.
Puede recibir un segundo argumento opcional para especificar el índice desde el cual buscar.
El método `index` devuelve el índice de la primera aparición del argumento.

```crystal
"hello".index("l")
# => 2

"hello".index("l", 3)
# => 3
```

## String#delete_at

Puedes usar el método [`delete_at`][delete_at] para eliminar un carácter de un string.
El método `delete_at` recibe un índice como argumento y elimina el carácter en ese índice.

```crystal
"hello".delete_at(0)
# => "ello"

"hello".delete_at(3)
# => "helo"
```

## String#insert

El método [`insert`][insert] se puede usar para insertar un string en un índice específico.
El método `insert` recibe un índice como primer argumento y un string como segundo argumento.
El método `insert` devuelve un nuevo string con el segundo argumento insertado en el índice.

```crystal
"hello".insert(0, "h")
# => "hhello"

"hello".insert(3, "l")
# => "helllo"
```
