# Introducción

Un objetivo central de Julia es poder hacer cálculos sobre datos numéricos de forma rápida y eficiente.
_Muchísimos_ datos numéricos.

Por lo general, los datos se almacenarán en arrays (o en algún tipo relacionado), así que es razonable decir que los arrays son el corazón del lenguaje Julia.

Los arrays pueden tener un tamaño arbitrario (limitado solo por la memoria de tu hardware) y pueden tener cualquier número de dimensiones.

Esta introducción se centra en lo básico de los arrays de una dimensión, que se llaman vectores.

## Crear vectores

En Julia, un vector es una secuencia ordenada de valores a los que se puede acceder mediante un número de índice.

La forma más sencilla de crear un vector es enumerar los valores entre corchetes:

```julia-repl
julia> num_vec = [1, 4, 9]
3-element Vector{Int64}:
 1
 4
 9

julia> str_vec = ["arrays", "are", "important"]
3-element Vector{String}:
 "arrays"
 "are"
 "important"
```

El tipo del vector se corresponde con el tipo de cada elemento.

_¿Entonces los vectores tienen que ser homogéneos (todos los elementos del mismo tipo)?_

Hasta cierto punto, sí, y se recomienda apuntar a esto si quieres el mejor rendimiento.
Sin embargo, Julia puede sortear esta limitación (cuando sea necesario) usando el tipo `Any`:

```julia-repl
julia> mixed_vector = [1, "str", 'c']
3-element Vector{Any}:
 1
  "str"
  'c': ASCII/Unicode U+0063 (category Ll: Letter, lowercase)
```

Cuando creas un vector vacío, Julia usa por defecto el tipo de elemento `Any`, pero puedes definirlo de forma más específica anotando el array vacío con el tipo de elemento que quieras.

```julia-repl
julia> empty_vec = []
Any[]

julia> empty_int_vec = Int64[]
Int64[]
```

# Indexación

Por favor, lee y recuerda esta regla:

- ***Por defecto, la indexación en Julia empieza en 1, no en 0***.

Esto les resulta familiar a quienes han usado otros lenguajes de ciencia de datos (R, Matlab, Fortran...), pero puede parecer sorprendente a los informáticos con experiencia en lenguajes tipo C.

Por lo demás, los índices funcionan como imaginas: solo tienes que ponerlos entre corchetes:

```julia
squares = [0, 1, 4, 9, 16]
squares[1]  # 0
squares[3]  # 4
squares[begin]  # 0 ("begin" is synonym for 1)
squares[end]  # 16 ("end" is synonym for length(squares))
```

Fíjate en lo cómodo que es indexar con `end` (que es muy útil) y con `begin` (que probablemente no lo sea tanto).

Quienes programan en Python quizá se pregunten por los índices negativos.
No lo hagas: no forman parte de Julia y lanzarán un `BoundsError`, igual que cualquier índice menor que 1 o mayor que `length(squares)`.

## Operaciones con vectores

Los vectores en Julia son _mutables_: podemos cambiar el contenido de celdas individuales.

```julia-repl
julia> vals = [1, 3, 5, 7]
4-element Vector{Int64}:
 1
 3
 5
 7

julia> vals[2] = 4  # reassign the value of this element
4

# Only the value at position 2 changes:
julia> vals
4-element Vector{Int64}:
 1
 4
 5
 7
```

Hay muchas funciones disponibles para manipular vectores, aunque la documentación de Julia las generaliza a «colecciones» en lugar de vectores.

Fíjate en que, por convención, las funciones que mutan su entrada llevan `!` en el nombre.
El compilador no lo impone, pero es una convención muy _fuerte_ en el mundo de Julia.

Estas son algunas de las funciones útiles:

- Para agregar valores al final del vector, usa `push!()`.
- Para eliminar el último valor, usa `pop!()`.
- Para operar sobre el inicio del vector, las funciones correspondientes son `pushfirst!()` y `popfirst!()`.
- Para insertar o eliminar un elemento en cualquier posición, están `insert!()` y `deleteat!()`.

```julia-repl
julia> vals = [1, 3]
2-element Vector{Int64}:
 1
 3

julia> push!(vals, 5, 6)  # can add multiple values
4-element Vector{Int64}:
 1
 3
 5
 6

julia> pop!(vals)  # mutates vals, return popped value
6

julia> vals
3-element Vector{Int64}:
 1
 3
 5
```
