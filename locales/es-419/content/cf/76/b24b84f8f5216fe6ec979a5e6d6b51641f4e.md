# Instalación

## Requisitos del track de lenguaje de PowerShell

El track de lenguaje PowerShell de Exercism requiere que tengas instalado en tu sistema:

- PowerShell o Windows PowerShell Core
- El módulo del framework de pruebas y mocks Pester instalado

(PD: El soporte para PowerShell se limita a correcciones críticas. PowerShell Core recibe mantenimiento constante y tiene mayor compatibilidad entre plataformas)

### Instalación de PowerShell

PowerShell viene preinstalado en todos los sistemas operativos Windows desde Windows 7 SP1 en adelante.

Puedes encontrar la última versión de PowerShell y las instrucciones de instalación para todas las plataformas (Linux, macOS y Windows) [aquí][installation].

También está disponible el código fuente y la instalación manual de [PowerShell][source-code].

### Instalación y actualización del framework Pester

[Pester][pester] es el framework de pruebas de PowerShell.
Desde la versión 4.0.9 es compatible con PowerShell Core en Windows, Linux y MacOS (con algunas limitaciones)

Viene preinstalado en Windows 10; sin embargo, se recomienda que lo actualices ejecutando el siguiente comando de PowerShell:

```PowerShell
Install-Module -Name Pester -Force -SkipPublisherCheck
```

Para actualizaciones posteriores, ejecuta:

```PowerShell
Update-Module -Name Pester
```

Si es necesario, hay más instrucciones de instalación disponibles en: [https://github.com/pester/Pester/wiki/Installation-and-Update]()

## Uso de un IDE

Si quieres una experiencia de edición con más funciones, seguramente quieras usar un IDE.
Estos son los IDE más populares que permiten compilar proyectos de PowerShell:

### Todas las plataformas

- [PowerShell ISE (Integrated Scripting Environment)][ise], IDE gráfico integrado que viene con PowerShell (solo Windows).
  Para iniciar PowerShell ISE, escribe `powershell_ise.exe` en una consola de PowerShell.
- [Visual Studio Code][vsc] con la [extensión de PowerShell][vsc-extension].
  Visual Studio Code también te permitirá ejecutar las pruebas y depurar tu código.
- [Sublime Text 3][sublime] con el [paquete de PowerShell][sublime-package].
