# Introducción

## Enum

`Enum` es un módulo muy útil que ofrece un conjunto de algoritmos para trabajar con enumerables. Ofrece ordenar, filtrar, agrupar, contar, buscar, encontrar valores mínimos y máximos, y mucho más.

En general, un _enumerable_ es cualquier dato que se pueda iterar, una colección. En Elixir, un enumerable es cualquier tipo de dato que implemente el [protocolo][exercism-protocols] `Enumerable`. Los más comunes de esos son las [listas][exercism-lists] y los [mapas][exercism-maps].

Muchas funciones de `Enum` aceptan una función como argumento.

```elixir
Enum.all?([1, 2, 3, 4, 5], fn x -> x > 3 end)
# => false
```

Las funciones de `Enum` más comunes son `map` y `reduce`.

### `map/2`

`Enum.map/2` te permite reemplazar cada elemento de un enumerable por otro elemento. El segundo argumento de `Enum.map/2` es una función que recibe el elemento original y devuelve su reemplazo.

### `reduce/3`

`Enum.reduce/3` te permite _reducir_ todo el enumerable a un solo valor. Para lograrlo, se usa una variable especial llamada _acumulador_. El acumulador lleva el estado intermedio de la reducción entre iteraciones.

El segundo argumento de `Enum.reduce/3` es el valor inicial del acumulador. El tercer argumento es una función que recibe un elemento y un acumulador, y devuelve el nuevo valor del acumulador.

### Trabajar con mapas

Cuando usas mapas con las funciones de `Enum`, el mapa se convierte automáticamente en una lista de 2 tuplas `{key, value}`.

Para volver a transformarlo en un mapa, usa `Enum.into/2`. `Enum.into/2` es una función que transforma un enumerable en un collectable, es decir, cualquier estructura de datos que implemente el protocolo `Collectable`. Se puede pensar en ella como lo opuesto a `Enum.reduce/3`.

`Enum` también tiene `Enum.into/3`. `Enum.into/3` es una variación de `Enum.into/2` que acepta una función de transformación que se aplica mientras transforma el enumerable en un collectable.

#### Mapear mapas

En lugar de usar `Enum.into/3` o `Enum.map/2` más `Enum.into/2` para aplicar una transformación (mapeo) a un mapa, también podemos usar una función dedicada, `Map.new/2`. Funciona exactamente como `Enum.into/3`, ya que acepta un enumerable y una función de transformación, pero siempre devuelve un mapa nuevo en lugar de dejarnos elegir un collectable.
