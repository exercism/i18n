# Instalación de Java

Además de la CLI de Exercism y tu editor de texto favorito, para practicar con los ejercicios de Java de Exercism necesitas el **Java Development Kit** (JDK). El JDK incluye un Java Runtime _y también_ herramientas de desarrollo (entre las que destaca sobre todo el compilador de Java).

Hoy en día existen muchas variantes del JDK, y algunas son de código abierto. Aquí en Exercism recomendamos usar [Eclipse Temurin de Adoptium][adoptium].

## Versiones de Java compatibles

El track de Java de Exercism es compatible con Java 25 LTS y versiones anteriores.

## Instalar Eclipse Temurin

Para instalar Eclipse Temurin en tu sistema, visita sus excelentes [instrucciones de instalación][adoptium-installation-guide]. Ahí encontrarás cómo instalar el JDK con tu gestor de paquetes favorito, y también hay enlaces a instaladores descargables para todos los sistemas operativos principales.

## IDE de Java

Hay muchos IDE gratuitos disponibles para Java. Estas son algunas opciones populares:

- [IntelliJ IDEA Community Edition][intellij-idea]
- [Eclipse][eclipse]
- [Visual Studio Code con la extensión de Java][vscode-java]
