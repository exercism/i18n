# Hints

## General

- [Sobrecarga de métodos en C#][member-overloading].
- Puedes usar la [interpolación de strings][string-interpolation] para dar formato a los strings de descripción.

## 3. Describe el método de viaje

- Puedes usar un [condicional simple][if-statement] para la lógica condicional.

## 4. Describe a un personaje que viaja a un destino

- Puedes reutilizar la funcionalidad existente para describir.
- Puedes usar [expresiones en strings interpolados][string-interpolation-expressions], lo que significa que puedes llamar a métodos directamente en las partes interpoladas de un string interpolado.

## 5. Describe a un personaje que viaja a un destino sin especificar el método de viaje

- Puedes reutilizar la funcionalidad existente que sí recibe un método de viaje explícito.
- Puedes usar [parámetros opcionales][optional-arguments] para simplificar la cantidad de código que necesitas.
