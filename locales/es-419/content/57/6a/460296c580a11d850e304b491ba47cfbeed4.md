# Instrucciones

En este ejercicio vas a trabajar con cuentas de ahorro.
Cada año, el saldo de tu cuenta de ahorro se actualiza según su tasa de interés.
La tasa de interés que te da tu banco depende de la cantidad de dinero que tengas en tu cuenta (su saldo):

- 3.213% para un saldo menor que `0` dólares (el saldo se vuelve más negativo).
- 0.5% para un saldo mayor o igual que `0` dólares y menor que `1000` dólares.
- 1.621% para un saldo mayor o igual que `1000` dólares y menor que `5000` dólares.
- 2.475% para un saldo mayor o igual que `5000` dólares.

Tienes cuatro tareas, y cada una de ellas tratará el saldo y su tasa de interés.

## 1. Calcula la tasa de interés

Implementa la función `interest_rate` para calcular la tasa de interés a partir del saldo especificado:

```cpp
interest_rate(200.75);
// => 0.5
```

## 2. Calcula el interés

Implementa la función `yearly_interest` para calcular el interés a partir del saldo especificado:

```cpp
yearly_interest(200.75):
// => 1.003750
```

## 3. Calcula la actualización anual del saldo

Implementa la función `annual_balance_update` para calcular la actualización anual del saldo, teniendo en cuenta la tasa de interés:

```cpp
annual_balance_update(200.75);
// => 201.75375
```

## 4. Calcula los años que faltan para alcanzar el saldo deseado

Implementa la función `years_until_desired_balance` para calcular la cantidad mínima de años necesarios para alcanzar el saldo deseado, teniendo en cuenta que cada año se suma el interés al saldo.
Esto significa que el saldo después de un año es: saldo inicial + interés del saldo inicial.
El saldo después del segundo año es el saldo después de un año + el interés del saldo después de un año.
Y así sucesivamente, hasta que el saldo del año actual sea mayor o igual que el saldo objetivo.

```cpp
double balance {200.75};
double targetBalance {214.88};
years_until_desired_balance(balance, targetBalance)
// => 14
```

Ten en cuenta que el valor que se devuelve es un `int`.
