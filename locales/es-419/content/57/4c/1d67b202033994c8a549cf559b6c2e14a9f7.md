# Anexo de instrucciones

## Registros

| Registro | Uso      | Tipo    | Descripción                                       |
| -------- | -------- | ------- | ------------------------------------------------- |
| `$a0`    | entrada  | dirección | string de entrada terminado en nulo                |
| `$v0`    | salida   | boolean | la entrada es un isograma (`0` = `false`, `1` = `true`) |
| `$t0-9`  | temporal | cualquiera | usado para almacenamiento temporal              |
