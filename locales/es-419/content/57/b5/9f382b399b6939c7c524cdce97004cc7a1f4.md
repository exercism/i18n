# Instrucciones

Boris es un gran aficionado a los trenes a escala y ha decidido compartir su pasión con el mundo lanzando un boletín. Empezará enviando el primer número del boletín a amigos y conocidos que comparten este pasatiempo; sus direcciones de correo electrónico están guardadas en un archivo de texto.

Sugerencia: usa el módulo [simplifile](https://hexdocs.pm/simplifile/simplifile.html) para las operaciones con archivos.

## 1. Lee las direcciones de correo electrónico de un archivo

Implementa la función `read_emails`. Recibe una cadena con la ruta a un archivo de texto que contiene direcciones de correo electrónico separadas por saltos de línea, y devuelve una lista con las direcciones de correo electrónico del archivo.

```gleam
read_emails("/home/my_user/documents/model_train_friends_emails.txt")
// -> Ok(["rick@example.com", "choochoo42@example.com", "anna@example.com"])
```

## 2. Crea un archivo de registro en el que escribir

Enviar un correo electrónico es una tarea que puede fallar por muchas razones impredecibles, como un error tipográfico en la dirección de correo o problemas temporales de red. Para asegurarte de que puedes reintentar el envío de los correos a todos tus amigos sin enviar duplicados, necesitas registrar las direcciones de correo electrónico que ya recibieron el correo. Para esto, necesitarás un archivo de registro.

Implementa la función `create_log_file`. Recibe una ruta de archivo y crea un archivo nuevo y vacío en esa ubicación.

```gleam
create_log_file("/home/my_user/documents/newsletter_issue1_log.txt")
// -> Ok(Nil)
```

## 3. Registra un correo enviado

Implementa la función `log_sent_email`. Recibe la ruta de un archivo de registro y una cadena con la dirección de correo electrónico. Escribe la dirección de correo electrónico en el archivo, seguida de un salto de línea.

```gleam
log_sent_email(
  "/home/my_user/documents/newsletter_issue1_log.txt",
  "joe@example.com",
)
// -> Ok(Nil)
```

## 4. Envía el boletín

Ahora que tienes todas las piezas del procedimiento de envío de correos, necesitas combinarlas en una sola función.

Implementa la función `send_newsletter`. Recibe la ruta del archivo con las direcciones de correo electrónico, la ruta de un archivo de registro y una función anónima que envía un correo a una dirección de correo electrónico dada.

Debe leer todas las direcciones de correo electrónico del archivo dado e intentar enviar un correo a cada una de ellas. Si la función anónima que envía el correo devuelve un valor `Ok`, escribe la dirección de correo electrónico en el archivo de registro. Asegúrate de hacerlo en cuanto se envíe el correo.

```gleam
send_newsletter(
  "model_train_friends_emails.txt",
  "newsletter_issue1_log.txt",
  send_email,
)
// -> Ok(Nil)
```
