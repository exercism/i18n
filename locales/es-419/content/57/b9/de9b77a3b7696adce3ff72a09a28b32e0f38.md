# Instrucciones adicionales

## Formato de salida

Imprime el rombo como un string terminado en nulo, con un carácter de nueva línea al final de cada fila.

Un ejemplo de salida sería `"  A  \n B B \nC   C\n B B \n  A  \n"`

## Registros

| Registro | Uso          | Tipo    | Descripción                         |
| -------- | ------------ | ------- | ----------------------------------- |
| `$a0`    | entrada      | byte    | letra                               |
| `$a1`    | entrada/salida | dirección | string de resultado terminado en nulo |
| `$t0-9`  | temporal     | cualquiera | para almacenamiento temporal     |
