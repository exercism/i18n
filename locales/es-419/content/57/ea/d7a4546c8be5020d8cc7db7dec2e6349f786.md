# Introducción

`OpenStruct` te permite crear un objeto a partir de un `Hash` con facilidad.
En lugar de tener que acceder usando las claves del `Hash`, `OpenStruct` nos permite usar métodos para acceder a los valores y establecerlos.


```ruby
attributes = { name: "Jeremy Walker", age: 21, location: "Nomadic" }
person = OpenStruct.new(attributes)

person.name
#=> Jeremy Walker

person.location
#=> Nomadic

# Update the age
person.age = 35

# It sets correctly
person.age
#=> 35
```

Una ventaja adicional de este enfoque es que podemos aprovechar un atajo cuando usamos la sintaxis de bloque.
Cuando un bloque llama a un solo método, puedes reemplazar el bloque con `&:` seguido del nombre del método.
Por ejemplo, estas dos líneas son sinónimas:

```ruby
people.sum { |person| person.age }
people.sum(&:age)
```

## Biblioteca Estándar

Todas las clases que has visto en los ejercicios anteriores forman parte de la Biblioteca Principal de Ruby.

OpenStruct forma parte de la Biblioteca Estándar de Ruby (a menudo abreviada como «stdlib»), una colección de clases para trabajar con cosas como fechas, json y redes.
También ofrece algunas funcionalidades útiles para que tu código sea más fácil de manejar.

Cuando usas clases que no son de la Biblioteca Principal (tu propio código en otros archivos, clases de la stdlib o dependencias externas), necesitamos importarlas con el método `require` antes de poder usarlas.
Por ejemplo:

```ruby
require 'ostruct'

person = OpenStruct.new(name: "Jeremy Walker")
# ...
```
