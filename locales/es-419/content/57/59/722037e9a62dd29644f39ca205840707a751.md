# Mapas y conjuntos

Un array contiene valores en posiciones numeradas. A veces la etiqueta útil
no es un número.

## Mapas

Un **mapa** asocia cada **clave** con un **destino**. Busca algo por su clave
y el mapa te da lo que tiene guardado bajo ella.

`FMAP{K,T}` es un mapa de claves de tipo `K` a destinos de tipo `T`. Una guía
que asocia el nombre de un animal con el lugar donde vive es `FMAP{STR,STR}`.

```sather
   guide ::= #FMAP{STR,STR};
   guide := guide.insert("emu", "grassland");
   guide.get("emu")               -- "grassland"
```

## Siempre asigna de vuelta la respuesta

Vuelve a mirar esa línea del medio. `insert` devuelve el mapa con el par
adicional ya incluido, y hay que quedarse con esa respuesta:

```sather
   guide := guide.insert("emu", "grassland");     -- yes
   guide.insert("emu", "grassland");              -- no: the answer is lost
```

Es la misma regla que con `FSTR`, y por la misma razón. La respuesta suele
ser el mismísimo mapa que entró, modificado en el sitio; de vez en cuando,
cuando el mapa se ha quedado sin espacio, es uno más grande. Como no puedes
saber cuál de los dos casos es, **usa la respuesta y deja de usar el nombre
viejo.** Un nombre que quedó de antes de un `insert` puede estar
desactualizado o puede que ya no describa un mapa que puedas usar.

Eso también significa que un mapa que le pasas a una rutina no queda a salvo
de ella. Si el original tiene que sobrevivir, consulta `copy` en la página
del concepto.

## ¿Está ahí?

`has_ind` pregunta si una clave está en el mapa. El nombre es la forma corta
de «has index», siendo un índice lo que estos mapas llaman una clave.

```sather
   guide.has_ind("emu")           -- true
   guide.has_ind("moa")           -- false
```

Si pides una clave que no está ahí, el mapa **no** se queja. `get` devuelve
el valor vacío del tipo (cero para un `INT` y void para un `STR`), que
saldrá mal más tarde y en otro lugar. Así que revisa antes de obtener el
valor:

```sather
   if guide.has_ind(animal) then
      return guide.get(animal);
   else
      return "Unknown";
   end;
```

## Conjuntos

Un **conjunto** contiene valores sin repeticiones y sin orden. `FSET{T}` es
un conjunto de valores de tipo `T`.

```sather
   seen ::= #FSET{STR};
   seen := seen.insert("emu");
   seen := seen.insert("emu");    -- already there; nothing changes
   seen.size                      -- 1
   seen.has("emu")                -- true
```

Insertar algo dos veces deja una sola copia. Para eso sirve un conjunto:
para ir juntando cosas y olvidarte de cuántas veces apareció cada una.

`insert` sobre un conjunto devuelve el conjunto que debes usar a partir de
entonces, igual que en un mapa, así que asígnalo de vuelta cada vez.

## Cuántos

`.size` funciona en ambos: cuántos pares contiene un mapa y cuántos valores
hay en un conjunto.
