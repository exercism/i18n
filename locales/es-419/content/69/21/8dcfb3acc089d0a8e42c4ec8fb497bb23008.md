# Introducción

## Espacios de nombres

Un método importante para organizar el código es el uso de espacios de nombres.
Dos funciones podrían tener una colisión de nombres, que se puede resolver poniéndolas en espacios de nombres diferentes.
Los espacios de nombres se pueden anidar, lo que puede ayudar a estructurar grandes bases de código.
Se accede a los espacios de nombres mediante el operador de resolución de ámbito `::`.

El siguiente ejemplo muestra el uso de dos funciones `foo` diferentes.
Se usan juntas anteponiendo sus respectivos espacios de nombres.

```cpp
namespace my_ns {
    int foo() {
        return 44;
    }
    namespace my_inner_ns {
        int baz() {
            return 90;
        }
    }
}
namespace my_other_ns {
    int foo() {
        return -2;
    }
}

int myresult{my_ns::foo() + my_other_ns::foo() * my_ns::my_inner_ns::baz()};
```
