# Apéndice de las instrucciones

## Los índices en Rust empiezan en 0

Por convención, las secuencias ordenadas de valores en Rust tienen sus contenidos numerados («indexados») a partir de 0. Esto se aplica sin importar lo que diga el resto de la descripción del ejercicio en este README, como las referencias a índices que empiezan en 1, así que tendrás que restar 1 para traducir esos números de índice a los números de índice de Rust.

## Aviso sobre la eficiencia

Este ejercicio usa un _vector de vectores_ para almacenar el contenido de las matrices. Si bien este ejercicio está diseñado para ayudar a los estudiantes a entender conceptos básicos sobre los vectores, como la indexación, y que los tipos de datos anidados son válidos, el _vector de vectores_ es una opción subóptima para el álgebra de matrices de alto rendimiento y para cualquier procesamiento eficiente similar de grandes cantidades de datos.

La explicación detallada de esta ineficiencia está fuera del alcance de este ejercicio y de esta ruta de aprendizaje en general. Este aspecto se conoce como [localidad de caché](https://stackoverflow.com/questions/12065774/why-does-cache-locality-matter-for-array-performance) y puedes encontrar una buena introducción al respecto haciendo clic en ese enlace si quieres aprender más sobre los detalles de una arquitectura de computadoras moderna.
