## Instalación de Z3

### Descargar Python (si aún no está instalado)

Puedes descargar la última versión de Python [aquí.](https://python.org)

* Al instalarlo, asegúrate de marcar la casilla que agrega Python al PATH

### Descargar Visual Studio (si aún no está instalado)

Puedes descargar la última versión de Visual Studio [aquí.](https://visualstudio.microsoft.com/downloads/?utm_medium=microsoft&utm_source=docs.microsoft.com&utm_campaign=inline+link&utm_content=download+vs2019)

* Al instalarlo, selecciona la carga de trabajo **Python Development**
* Marca todas las casillas de los paquetes opcionales de desarrollo de Python en el lado derecho

Después de la instalación, abre Visual Studio y configura tus preferencias iniciales.

### Instalar los comandos de Git

Puedes encontrar las instrucciones para instalar Git [aquí.](https://git-scm.com/book/en/v2/Getting-Started-Installing-Git)

* Tendrás que [agregar Git a tus variables del sistema](https://stackoverflow.com/questions/4492979/git-is-not-recognized-as-an-internal-or-external-command)

### Clonar Z3

Ve al [repositorio de Z3 en Github](https://github.com/Z3Prover/z3) para ver el proyecto.

Abre una terminal en tu computadora y dirígete a la ubicación donde quieras clonar el repositorio de Z3 (ej.: C:\Z3).

Desde esa ubicación, ejecuta:

```bash
git clone https://github.com/z3Prover/z3.git
```

### Compilar Z3 en Windows con el símbolo del sistema de Visual Studio

Abre **Developer Command Prompt for VS 2019** desde el menú de inicio.

Dirígete a la carpeta en la que clonaste el repositorio de Z3 (ej.: C:\Z3).

Para compilaciones de 32 bits, ejecuta:

```bash
python scripts/mk_make.py
```

Para una compilación de 64 bits, ejecuta:

```bash
python scripts/mk_make.py -x
```

y luego ejecuta:

```bash
cd build
pip install z3-solver
```



Ahora deberías poder abrir Visual Studio y ejecutar Z3 con su enlace de Python.


Para probarlo, puedes ejecutar:
```python
from x3 import *
x = Real('x')
y = Real('y)
s = Solver()
s.add(x + y > 5, x > 1, y > 1)
print(s.check())
print(s.model())
```

Las dos últimas líneas deben producir `sat` y `[y = 4, x = 2]`.
