# Cómo escribir el código

Escribe tu código en `src/lib.rs`.
Los ejercicios vienen con un archivo stub en `src/lib.rs` que te muestra las firmas del código que vas a tener que escribir.

En la mayoría de los ejercicios, lo mejor es escribir todo tu código en el archivo `src/lib.rs`.
Si quieres dividir tu solución en varios archivos, consulta el [capítulo sobre módulos][chapter-modules] del libro de Rust.

[chapter-modules]: https://doc.rust-lang.org/book/ch07-02-defining-modules-to-control-scope-and-privacy.html

## Ejecutar los tests

Para ejecutar los tests, lo único que tienes que hacer es ejecutar el siguiente comando:

```bash
$ cargo test
```

Por defecto, solo el primer test está habilitado.
Cuando estés listo para pasar el siguiente test, quita el flag ignore del siguiente test (`#[ignore]`).
También puedes quitar el flag de todos los tests a la vez si lo prefieres.

No dudes en escribir la menor cantidad de código posible para que los tests pasen.
Los fallos de los tests te guiarán sobre qué deberías escribir después.

Como Rust verifica todo el código al momento de compilar, puede que tus tests no compilen hasta que escribas el código necesario.
Incluso los tests marcados con `ignore` se verifican al compilar.
Puedes [comentar][comments] los tests que no compilen empezando cada línea con `//`.
Luego, cuando estés listo para trabajar en ese test, puedes descomentarlo.
Rust también tiene una macro especial llamada `todo!()`, que puedes usar en las partes del código que aún no completaste para que tu programa compile.

[comments]: https://doc.rust-lang.org/book/ch03-04-comments.html

## Usar librerías

Deberías poder resolver la mayoría de los ejercicios sin usar librerías externas.
Sin embargo, puedes agregar librerías (la comunidad de Rust las llama **crates**) ejecutando `cargo add crate-name` en el directorio de un ejercicio.

Los tests automáticos del sitio web solo admiten un conjunto predefinido de crates, que puedes encontrar [aquí][local-registry] en la sección `[dependencies]`.
No dudes en abrir un issue o un pull request si quieres que se agregue compatibilidad con algún crate en específico.

[local-registry]: https://github.com/exercism/rust-test-runner/blob/main/local-registry/Cargo.toml
