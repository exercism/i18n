# Instrucciones

En este ejercicio vas a escribir algo de código para ayudar a Larry the Lisp Alien a analizar y formatear strings de log. Estos strings de log llegan desde distintos sistemas y hay que procesarlos para que sus mensajes se puedan mostrar en una pantalla informativa de monitoreo.

Los strings de log tienen el formato `"[<level>]: <message>"`. El nivel será uno de los siguientes valores: `info`, `warn` u `ohno`.

## 1. Extraer el mensaje

Define una función `log-message` que tome un string de log y devuelva el mensaje que contiene.

```lisp
(log-message "[ohno]: whoops!") ; => "whoops!"
```

## 2. Determinar la severidad

El nivel del string de log determina su severidad.

- un nivel de `info` significa una severidad de `:everything-ok`
- un nivel de `warn` significa una severidad de `:getting-worried`
- un nivel de `ohno` significa una severidad de `:run-for-cover`

Define una función `log-severity` que tome un string de log y devuelva la severidad correcta.

```lisp
(log-severity "[warn]: might want to get that checked") ; => :getting-worried
```

## 3. Lidiar con los caprichos de la realidad

Por desgracia, a veces los strings de log no están formateados correctamente. En concreto, puede que el nivel del log no esté todo en minúsculas como se indicó antes. Modifica `log-severity` para que se ocupe de esto.

```lisp
(log-severity "[WaRn]: string case system failing") ; => :getting-worried
```

## 4. Reformatear el mensaje de log según la severidad

Según la severidad, el mensaje se debe modificar de distintas maneras:

- una severidad de `:everything-ok` debe cambiar su mensaje a todo en minúsculas.
- una severidad de `:getting-worried` debe cambiar su mensaje para que cada palabra empiece con mayúscula.
- una severidad de `:run-for-cover` debe cambiar su mensaje a todo en mayúsculas.

Define una función `log-format` que tome un mensaje de log y devuelva un mensaje con el formato correcto.

```lisp
(log-format "[ohno]: whoops!") ; => WHOOPS!
```
