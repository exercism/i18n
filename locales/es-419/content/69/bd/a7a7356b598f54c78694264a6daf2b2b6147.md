# Acerca de

Los [atributos de módulo][module-attr] se pueden usar como [«constantes»][attr-as-const], que se evalúan en tiempo de compilación.

```elixir
defmodule Example do
  @number 2

  def number(), do: @number
end
```

Sin embargo, no se comportan estrictamente como constantes, porque se pueden sobrescribir al redefinirlos en el módulo:

```elixir
defmodule Example do
  @standard_message "Hello, World!"
  @standard_message "Overwritten!"

  def message(), do: @standard_message
end
```

[module-attr]: https://hexdocs.pm/elixir/module-attributes.html
[attr-as-const]: https://hexdocs.pm/elixir/module-attributes.html#as-constants
