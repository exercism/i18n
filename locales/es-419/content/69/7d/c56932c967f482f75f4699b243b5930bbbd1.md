# Control de flujo

Las expresiones `if` y los bucles controlan el flujo de ejecución en Cairo mediante:
`

- **Las expresiones `if`** ejecutan código condicionalmente según si una condición se evalúa a `true`.
- **Los bucles** (como `loop`, `while` y `for`) ejecutan código repetidamente mientras una condición especificada sigue siendo true o hasta que se cumpla una condición de salida.

Estas construcciones son fundamentales para implementar lógica e iteración en Cairo.

## Expresiones `if`

Las expresiones `if` en Cairo te permiten controlar el flujo de ejecución según una lógica condicional.
Siguen una estructura en la que el código se ejecuta dependiendo de si una condición de tipo Boolean se evalúa a `true` o `false`.

```rust
fn main() {
    let temperature = 30;

    if temperature > 25 {
        println!("It's hot outside!");
    }
}
```

Este ejemplo demuestra un bloque `if` simple en Cairo.
El mensaje `"It's hot outside!"` se imprime solo si la condición `temperature > 25` se evalúa a `true`.
Si la condición es `false`, no se ejecuta ningún código y el programa continúa.

```rust
fn main() {
    let number: u32 = 5;

    if number < 10 {
        println!("The number is less than 10.");
    } else {
        println!("The number is 10 or greater.");
    }
}
```

Ejecutar este código imprimirá `"The number is less than 10."` en la consola.

### Manejo de múltiples condiciones con `else if`

Puedes usar múltiples condiciones combinando `if` y `else` en una expresión `else if`.

```rust
fn main() {
    let score: u64 = 85;

    if score >= 90 {
        println!("Grade: A");
    } else if score >= 80 {
        println!("Grade: B");
    } else if score >= 70 {
        println!("Grade: C");
    } else {
        println!("Grade: F");
    }
}
```

Ejecutar este código imprimirá `"Grade: B"` en la consola.

### Uso de `if` en una sentencia `let`

La expresión `if` en Cairo se puede usar en el lado derecho de una sentencia `let` para asignar el resultado a una variable.

```rust
fn main() {
    let condition: bool = true;
    let number: felt252 = if condition {
        5
    } else {
        6
    };

    if number == 5 {
        println!("condition was true and number is {}", number);
    }
}
```

## Bucles

Los bucles son una construcción fundamental que permite la repetición de bloques de código, lo que posibilita una ejecución eficiente y controlada de tareas.
Los bucles pueden iterar sobre una secuencia o ejecutar código repetidamente según una condición.
Cairo ofrece tres tipos principales de bucles:

- **loop**: Un bucle básico que se ejecuta indefinidamente a menos que se detenga explícitamente usando una sentencia `break`.
- **while**: Sigue ejecutándose mientras una condición especificada se mantenga `true`.
  Se detiene cuando la condición se vuelve `false`.
- **for**: Itera sobre los elementos de una colección, como los arrays, ejecutando código para cada elemento.

### Repetir código con `loop`

La palabra clave `loop` le dice a Cairo que ejecute un bloque de código una y otra vez para siempre, o hasta que le indiques explícitamente que se detenga.

```rust
fn main() {
    loop {
        println!("again!");
    }
}
```

Ejecutar este código imprimirá `"again!"` indefinidamente en la consola, hasta que el programa se quede sin gas o lo detengamos manualmente.

> Nota: Cairo evita que ejecutemos un programa con bucles infinitos al incluir un medidor de gas.
> El medidor de gas es un mecanismo que limita la cantidad de cómputo que se puede realizar en un programa.
> El gas es una unidad de medida que expresa el costo de cómputo de una instrucción.
> Cuando el medidor de gas se agota, el programa se detiene.

Para salir de un bucle, coloca la palabra clave `break` dentro del bucle para indicarle al programa cuándo debe detener su ejecución.

```rust
fn main() {
    let mut i: usize = 0;
    loop {
        if i > 10 {
            break;
        }
        println!("i = {}", i);
        i += 1;
    }
}
```

La palabra clave `continue` le indica al programa que pase a la siguiente iteración del bucle y omita el resto del código en esta iteración.

```rust
fn main() {
    let mut i: usize = 0;
    loop {
        if i > 10 {
            break;
        }
        if i == 5 {
            i += 1;
            continue;
        }
        println!("i = {}", i);
        i += 1;
    }
}
```

Ejecutar este programa no imprimirá el valor de `i` cuando sea igual a `5`.

#### Devolver valores desde `loop`

Puedes devolver un valor desde un `loop` usando la palabra clave `break` seguida del valor que quieres devolver.
Esto te permite salir del `loop` y pasar un resultado al resto de tu código.

```rust
fn main() {
    let mut counter = 0;

    let result = loop {
        if counter == 10 {
            break counter * 2;
        }
        counter += 1;
    };

    println!("The result is {}", result); // prints "The result is 20"
}
```

### Bucles condicionales con `while`

`while` ejecuta código mientras una condición es `true`, y sale cuando la condición se vuelve `false`.

```rust
fn main() {
    let mut number = 3;
    while number != 0 {
        println!("{}!", number);
        number -= 1;
    }
    println!("LIFTOFF!!!");
}
```

### Recorrer una colección con `for`

`for` itera sobre cada elemento de una colección, ejecutando código para cada elemento.

```rust
fn main() {
    let a = [10, 20, 30, 40, 50].span();
    for element in a {
        println!("the value is: {}", element);
    }
}
```
