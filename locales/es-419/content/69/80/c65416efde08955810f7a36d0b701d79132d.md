# Instalación

Necesitarás el Node Package Manager (npm) para instalar Reason. Sigue las instrucciones que están [aquí](https://www.npmjs.com/get-npm)

Una vez que tengas npm, instala Reason con:
```
npm install -g bs-platform
```

Reason tiene integración con varios editores, mira [aquí](https://reasonml.github.io/docs/en/editor-plugins.html#officially-supported-editors)

Algunas herramientas de línea de comandos (incluido un REPL que te permite evaluar expresiones de Reason en un shell) las puedes encontrar [aquí](https://github.com/reasonml/reason-cli)
