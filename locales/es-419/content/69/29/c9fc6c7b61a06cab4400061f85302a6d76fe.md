# Instrucciones

En este ejercicio vas a procesar líneas de log.

Cada línea de log es un string con el siguiente formato: `"[<LEVEL>]: <MESSAGE>"`.

Hay tres niveles de log diferentes:

- `INFO`
- `WARNING`
- `ERROR`

Tienes tres tareas, y cada una de ellas recibirá una línea de log y te pedirá que hagas algo con ella.

## 1. Obtén el mensaje de una línea de log

Implementa la función `message` para devolver el mensaje de una línea de log:

```gleam
message("[ERROR]: Invalid operation")
// -> "Invalid operation"
```

Cualquier espacio en blanco al principio o al final debe eliminarse:

```gleam
message("[WARNING]:  Disk almost full\r\n")
// -> "Disk almost full"
```

## 2. Obtén el nivel de log de una línea de log

Implementa la función `log_level` para devolver el nivel de log de una línea de log, que se debe devolver en minúsculas:

```gleam
log_level("[ERROR]: Invalid operation")
// -> "error"
```

## 3. Reformatea una línea de log

Implementa la función `reformat`, que reformatea la línea de log poniendo el mensaje primero y el nivel de log después, entre paréntesis:

```gleam
reformat("[INFO]: Operation completed")
// -> "Operation completed (info)"
```
