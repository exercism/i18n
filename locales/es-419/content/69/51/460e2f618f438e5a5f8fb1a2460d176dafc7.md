# Apéndice de instrucciones

## Implementación

Además de la función _numbers_, que limpia los números de teléfono, necesitas escribir dos funciones más en la pista de Emacs Lisp: _area-code_ y _pprint_.

Cada una de las funciones adicionales recibe el número de teléfono como su único parámetro.

La primera función, _area-code_, extrae el código de área del argumento, mientras que la segunda, _pprint_, transforma el argumento en un string con el formato de
```
(NXX) NXX-XXXX
```
donde `N` y `X` son como se describen arriba.
