# Acerca de

El concepto [Pares y diccionarios][pairs-dicts] ya trató las nociones básicas del tipo de diccionario de Julia.

Como los [`Dict`s][dict] son un tipo de colección importante y muy usado, también existen muchas funciones para manipularlos.

## Obtener entradas

La forma más sencilla de recuperar una entrada es por su clave, como en muchos otros lenguajes. Sin embargo, pedir una clave que no existe da un `KeyError`.

```julia-repl
julia> d = Dict(i => ('a':'c')[i] for i in 1:3)
Dict{Int64, Char} with 3 entries:
  2 => 'b'
  3 => 'c'
  1 => 'a'

julia> d[2]
'b': ASCII/Unicode U+0062 (category Ll: Letter, lowercase)

# missing key
julia> d[4]
ERROR: KeyError: key 4 not found
```

Podríamos comprobar que la clave existe antes de intentar recuperarla (con algo como `haskey(d, 4)` o `4 ∈ keys(d)`), pero puede ser útil obtener directamente un valor predeterminado para las claves que faltan.

Para esto tenemos la función [`get()`][get] y su variante mutadora [`get!()`][get-bang]. Estas se diferencian en si la clave que «falta» se agrega al `Dict` o no.

```julia-repl
julia> get(d, 4, '!')
'!': ASCII/Unicode U+0021 (category Po: Punctuation, other)

# get() leaves Dict unchanged
julia> d
Dict{Int64, Char} with 3 entries:
  2 => 'b'
  3 => 'c'
  1 => 'a'

julia> get!(d, 4, '!')
'!': ASCII/Unicode U+0021 (category Po: Punctuation, other)

# get!() adds new key to Dict
julia> d
Dict{Int64, Char} with 4 entries:
  4 => '!'
  2 => 'b'
  3 => 'c'
  1 => 'a'
```

En el concepto anterior vimos que `delete!()` elimina una entrada por su clave. Esto se puede combinar con la obtención del valor usando la función `pop!()`.

```julia-repl
julia> d
Dict{Int64, Char} with 4 entries:
  4 => '!'
  2 => 'b'
  3 => 'c'
  1 => 'a'

# popped value is returned
julia> pop!(d, 3)
'c': ASCII/Unicode U+0063 (category Ll: Letter, lowercase)

# Dict is shrunk
julia> d
Dict{Int64, Char} with 3 entries:
  4 => '!'
  2 => 'b'
  1 => 'a'
```

## Iteración

Iterar sobre un `Dict` produce, por defecto, pares `key => value`. Se puede acceder a los componentes con la habitual nomenclatura `.first` y `.second`.

```julia-repl
# d is from the previous example
julia> [(kv.first, kv.second) for kv in d]
3-element Vector{Tuple{Int64, Char}}:
 (4, '!')
 (2, 'b')
 (1, 'a')
```

A menudo queremos usar solo las claves o solo los valores, y eso es fácil.

```juliajulia> [k for k in keys(d)]
julia> [k for k in keys(d)]
3-element Vector{Int64}:
 4
 2
 1

julia> [v for v in values(d)]
3-element Vector{Char}:
 '!': ASCII/Unicode U+0021 (category Po: Punctuation, other)
 'b': ASCII/Unicode U+0062 (category Ll: Letter, lowercase)
 'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)
```

## Fusionar

Combinar dos `Dict` puede ser útil, pero hay que tener claro qué queremos hacer con las claves que están presentes en más de uno de los diccionarios.

Las funciones [`merge()`][merge] y [`merge!()`][merge-bang] combinan cualquier cantidad de `Dict` que les pases, de izquierda a derecha.

Los valores de las claves que ya existen simplemente se sobrescriben, así que el `Dict` que está más a la derecha es el que «gana».

```julia-repl
julia> d3 = Dict("color" => "red", "shape" => "circle")
Dict{String, String} with 2 entries:
  "shape" => "circle"
  "color" => "red"

julia> d4 = Dict("color" => "blue", "coords" => (3, 2))
Dict{String, Any} with 2 entries:
  "color"  => "blue"
  "coords" => (3, 2)

# color from d3 is lost
julia> merge(d3, d4)
Dict{String, Any} with 3 entries:
  "shape"  => "circle"
  "color"  => "blue"
  "coords" => (3, 2)
```

Las funciones [`mergewith()`][mergewith] y [`mergewith!()`][mergewith-bang] nos permiten pasar una función como primer argumento para definir cómo se deben fusionar las claves repetidas. La suma es un ejemplo sencillo.

```julia-repl
julia> d5 = Dict("color" => "red", "area" => 3)
Dict{String, Any} with 2 entries:
  "area"  => 3
  "color" => "red"

julia> d6 = Dict("shape" => "circle", "area" => 5)
Dict{String, Any} with 2 entries:
  "shape" => "circle"
  "area"  => 5

# area values are added, not overwritten
julia> mergewith(+, d5, d6)
Dict{String, Any} with 3 entries:
  "shape" => "circle"
  "area"  => 8
  "color" => "red"
```

Concatenar dos vectores es otra operación muy común al fusionar. Para esto, Julia usa la función [`vcat()`][vcat], por las razones que se explican en el concepto [`Multi Dimensional Arrays`][multidim].

```julia-repl
julia> d7 = Dict("vals" => [1, 2, 3])
Dict{String, Vector{Int64}} with 1 entry:
  "vals" => [1, 2, 3]

julia> d8 = Dict("vals" => [4, 5])
Dict{String, Vector{Int64}} with 1 entry:
  "vals" => [4, 5]

julia> mergewith(vcat, d7, d8)
Dict{String, Vector{Int64}} with 1 entry:
  "vals" => [1, 2, 3, 4, 5]
```

Para varios [`Set`s][sets], la función de fusión correspondiente es [`union`][union].

Fíjate que las funciones `mergewith` son un buen ejemplo de [Funciones de orden superior][hof] en acción.
