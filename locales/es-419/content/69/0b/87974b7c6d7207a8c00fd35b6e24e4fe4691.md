# Instrucciones adicionales

## Palabras

- `<bst> ( data-seq -- tree )`: construye un árbol insertando cada
  elemento de `data-seq` en orden.
- `sorted-data ( tree -- seq )`: devuelve los elementos del árbol en
  orden ascendente (recorrido inorden).

## Jerarquía de tuplas

Un nodo en un árbol binario de búsqueda está *vacío* o *tiene datos
más dos subárboles*. Modela eso como una pequeña jerarquía de
herencia:

```factor
TUPLE: bst ;
TUPLE: leaf < bst ;
TUPLE: branch < bst data left right ;
```

`bst` es el padre abstracto; `leaf` es el caso de árbol vacío;
`branch` lleva un valor y dos hijos `bst` (cada uno de ellos es
un `leaf` o un `branch`).

## Orden

Compara los datos con `before=?` (de `math.order`), que funciona
con strings además de con números. Las pruebas usan datos que son
strings como `"1"`, `"2"`, `"3"`.
