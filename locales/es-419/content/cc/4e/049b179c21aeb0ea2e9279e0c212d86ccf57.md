# Instrucciones

En este ejercicio vas a trabajar con cuentas de ahorro.
Cada año, el saldo de tu cuenta de ahorro se actualiza según su tasa de interés.
La tasa de interés que te da tu banco depende de la cantidad de dinero que haya en tu cuenta (su saldo):

- 3.213% para un saldo negativo (el saldo se vuelve más negativo).
- 0.5% para un saldo positivo menor que `1000` dólares.
- 1.621% para un saldo positivo mayor o igual que `1000` dólares y menor que `5000` dólares.
- 2.475% para un saldo positivo mayor o igual que `5000` dólares.

Tienes cuatro tareas, y cada una se ocupará de tu saldo y su tasa de interés.

## 1. Calcula la tasa de interés

Implementa el método `SavingsAccount.interest_rate()` que recibe un saldo como argumento.
El método debe devolver la tasa de interés para el saldo dado.

```Crystal
SavingsAccount.interest_rate(200.75)
# => 0.5
```

## 2. Calcula el interés

Implementa el método `SavingsAccount.interest()` que recibe un saldo como argumento.
El método debe devolver el interés para el saldo dado.

```Crystal
SavingsAccount.interest(200.75)
# => 1.00375
```

## 3. Calcula la actualización anual del saldo

Implementa el método `SavingsAccount.annual_balance_update()` que recibe un saldo como argumento.
El método debe devolver el saldo después de un año.

```Crystal
SavingsAccount.annual_balance_update(200.75)
# => 201.75375
```

## 4. Calcula los años antes de alcanzar el saldo deseado

Implementa el método `SavingsAccount.years_before_desired_balance()` que recibe un saldo y un saldo objetivo como argumentos.
El método debe devolver la cantidad de años que tomaría alcanzar el saldo objetivo.

```Crystal
balance = 200.75
target_balance = 214.88
SavingsAccount.years_before_desired_balance(balance, target_balance)
# => 14
```

~~~~exercism/note
Al aplicar interés simple a un saldo principal, el saldo se multiplica por la tasa de interés y el producto de ambos es el monto del interés.

El interés compuesto, en cambio, se calcula aplicando el interés de forma recurrente.
En cada aplicación, se calcula el monto del interés y se suma al saldo principal, de modo que los cálculos de interés posteriores se hacen sobre un saldo principal mayor.
~~~~
