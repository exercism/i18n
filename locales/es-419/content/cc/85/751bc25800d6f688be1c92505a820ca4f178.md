# Reutilización de funciones

Reutilizar una función que ya escribiste puede ayudarte a la hora de escribir código mantenible.

Reutiliza las funciones que ya existen:
- `initial/1` puede reutilizar `first_letter/1`
- `initials/1` puede reutilizar `initial/1`
- `pair/2` puede reutilizar `initials/1`
