# Apéndice de instrucciones

## Registros

| Registro | Uso            | Tipo    | Descripción                                              |
| -------- | -------------- | ------- | -------------------------------------------------------- |
| `$a0`    | entrada        | dirección | cadena de entrada terminada en nulo                     |
| `$a1`    | entrada/salida | dirección | array de palabras con los conteos finales de nucleótidos |
| `$t0-9`  | temporal       | cualquiera | para almacenamiento temporal                          |
