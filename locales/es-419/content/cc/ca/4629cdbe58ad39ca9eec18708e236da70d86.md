# Acerca de

Las [guardas][guards] se usan como complemento de la [coincidencia de patrones][exercism-pattern-matching]. Permiten hacer comprobaciones más complejas. Se pueden usar en [algunas situaciones, pero no en todas][where-guards-can-be-used] en las que se puede usar la coincidencia de patrones, por ejemplo en cláusulas de función o en cláusulas de case.

```elixir
def empty?(list) when is_list(list) and length(list) == 0 do
  true
end
```

- Las guardas comienzan con la palabra clave `when`, seguida de una expresión booleana.
- Las expresiones de las guardas son funciones especiales que:
  - Deben ser [puras][pure-function] y no mutar ningún estado global.
  - Deben devolver valores `true` o `false` estrictos.
- En la [documentación de Elixir][kernel-guards] hay una lista de las guardas más comunes. Entre ellas están:
  - Comprobaciones de tipo: [`is_integer/1`][guard-is-integer], [`is_list/1`][guard-is-list], [`is_nil/1`][guard-is-nil], etc.
  - Operadores aritméticos: [`+/2`][guard-plus], [`-/2`][guard-minus], etc.
  - Comparaciones: [`==/2`][guard-equals], [`>/2`][guard-greater], [`</2`][guard-less], etc.
  - Operadores booleanos: [`and/2`][guard-and], [`or/2`][guard-or], [`not/1`][guard-not]
  - Operador de pertenencia: [`in/2`][guard-in]
- Puedes definir tu propia guarda con [`defguard`][defguard].

  - Según la [convención de nombres][naming] de Elixir, los nombres de las guardas deben empezar con `is_`.

    ```elixir
    defmodule HTTP do
      defguard is_success(code) when code >= 200 and code < 300

      def handle_response(code) when is_success(code) do
        :ok
      end
    end
    ```
