# Conceptos de Números de Armstrong

> Un [número de Armstrong](https://en.wikipedia.org/wiki/Narcissistic_number) es un número que es la suma de sus propios dígitos, cada uno elevado a la potencia del número de dígitos.

## Ejemplo de solución

```rust
pub fn is_armstrong_number(num: u32) -> bool {
    let digits = format!("{}", num);
    digits
        .chars()
        .map(|c| c.to_digit(10).unwrap().pow(digits.len() as u32))
        .sum::<u32>()
    == num
}
```

## Conceptos

- funciones: esenciales para verificar la solución y definir la lógica
- Suites de pruebas: necesarias para verificar la solución
- enteros: u32 para el argumento y las aserciones de identidad
- `&str`: necesario para contar la longitud del número, ya que Rust tiene tipado fuerte
- `Option<T>`: necesario para acceder al valor real de `char::to_digit`
- conversión de tipos: requerida para aplicar operaciones aritméticas
- características de los iteradores:
  - turbofish para habilitar una solución de una sola expresión
  - `map` y `sum` para reducir cómodamente la expresión a lo que necesitamos afirmar
