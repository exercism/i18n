# Introducción

PowerShell es un lenguaje de scripting de Microsoft con tipado dinámico implícito (también admite variables con tipado fuerte), enfocado principalmente en la automatización de tareas y la gestión de la configuración.

PowerShell admite programación imperativa, funcional, orientada a objetos e incluso el estilo de pipeline.

PowerShell se construyó sobre la plataforma .NET y se lanzó por primera vez en 2006.
Se incluye de forma predeterminada en todos los sistemas Windows modernos y se puede instalar en Mac y Linux.


## Variables

Hay dos formas comunes de definir una variable en PowerShell.

El nombre de una variable en PowerShell debe empezar con `$` y usa el operador de asignación `=` para vincular el nombre de la variable a un valor.

```powershell
> $intVar = 1
> $doubleVar = 2.0
> $stringVar = "Hello"

# Checking a variable type using the GetType() method
> Write-Host $doubleVar.GetType()
System.Double
```

También puedes especificar explícitamente el tipo de una variable si quieres forzar un [tipo][strong typed] específico.
PowerShell hará todo lo posible por convertir el valor de un tipo a otro cuando sea posible.

```powershell
# String represents a floating number can be converted to integer
> [int]$staticOne = "1.234"
> $staticOne
1

# String of letters can not be converted to double type
> [double]$staticTwo = "hello"
MetadataError: Cannot convert value "hello" to type "System.Double"
```


### Constantes

Las constantes en PowerShell son variables de solo lectura que no se pueden **eliminar** una vez definidas.
Esto nos lleva a la segunda forma de definir variables usando el cmdlet `New-Variable`.

```powershell
> New-Variable -Name "MyConstant" -Value 100 -Option Constant
> $MyConstant
```

Para ver una forma más detallada y avanzada de crear una variable nueva con varias opciones, consulta el cmdlet [New-Variable][New-Variable].


## Funciones

Las [funciones][functions] en PowerShell se definen con la palabra clave `function`.
Cada función puede tener cero o más [parámetros][parameters] formales entre paréntesis `()`, seguidos de su propio [ámbito][scope], que empieza con `{` y termina con `}`.

```powershell
function Greeting {
    return "Hello!"
}
```

En PowerShell, las funciones pueden devolver valores de forma explícita con la palabra clave `return`, después de llamarlas con la sintaxis `FuncName $Arg`.

```powershell
function AddTwoNumbers($NumOne, $NumTwo):
    $result = $NumOne + $NumTwo
    return $result

> AddTwoNumbers 10 20
30
```

Una mirada más avanzada sobre cómo escribir una definición de función detallada y sobre cómo las funciones pueden devolver valores de forma implícita se cubrirá en el módulo del concepto `Functions`.


## Comentarios

Un comentario de una sola línea en PowerShell empieza con `#` y termina al final de la línea.
Un bloque de comentarios en PowerShell empieza con `<#` y termina con `#>`.
Una demostración avanzada de los bloques de comentarios para crear ayuda basada en comentarios se cubrirá en el módulo del concepto `Functions`.

```powershell
function Main() {
    #This is a comment
}
```
