# Anexo de las instrucciones

## Palabras

Define una tupla `game` y un constructor `<game> ( -- game )` que devuelve un juego nuevo sin tiradas.

Proporciona estas palabras que operan sobre un juego:

- `roll ( pins game -- )`: registra que se derribaron `pins` bolos. Lanza un error cuando la tirada no es válida:
  - `"Negative roll is invalid"` para un número negativo de bolos.
  - `"Cannot roll after game is over"` una vez que se hayan tirado los diez cuadros (y las bolas de relleno que haya).
  - `"Pin count exceeds pins on the lane"` cuando se derriban más bolos de los que están en pie.
- `score ( game -- n )`: la puntuación total del juego. Lanza `"Score cannot be taken until the end of the game"` cuando el juego todavía no está completo.

Ten en cuenta que `roll` oculta la palabra de barajado `roll` del vocabulario `kernel`. La suite de pruebas lo desambigua con `FROM: bowling => roll ;`.
