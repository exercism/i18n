# Pistas

## General

- El paquete [`roc-random`](https://github.com/kili-ilo/roc-random) está disponible en el encabezado de `simple-cipher-test.roc` (con el alias `random`).
  Puedes usarlo en tu solución si quieres, por ejemplo importando `random.Random`.

- `Random.step(state, generator)` devuelve `{ value, state }`, que contiene un valor generado y el estado aleatorio actualizado.
  Devuelve ese estado actualizado desde `create_random` para que la siguiente llamada pueda continuar la secuencia.

- `Random.list` y `Random.map` pueden ayudarte a construir un generador para una clave completa.
