# Introducción

## Arreglos

Un `array` en F# es una colección mutable de cero o más valores con una longitud fija. Esto significa que una vez que se ha creado un array, su tamaño no puede cambiar, pero sus valores sí. Los valores de un array deben ser todos del mismo tipo. Los arrays se pueden definir de la siguiente manera:

```fsharp
let empty = [| |]
let emptyAlternative = Array.empty

let singleValue = [| 5 |]
let singleValueAlternative = Array.singleton 5

let threeValues = [| "a"; "b"; "c" |]
```

Se pueden asignar elementos a un array u obtenerlos de él usando un índice. Los arrays de F# están basados en cero, lo que significa que el índice del primer elemento siempre es cero:

```fsharp
let numbers = [| 2; 3; 5 |]

// Update value in array
numbers[2] <- 9

// Read value from array
numbers[2]
// => 9
```

Los arrays se manipulan ya sea con funciones y operadores definidos en el módulo `Array`, o manualmente usando coincidencia de patrones con el patrón _array_:

```fsharp
let describe array =
    match array with
    | [| |] -> "Empty"
    | [| 1; 2; three |] -> sprintf "1, 2, %d" three
    | _ -> "Other"

describe [| |]         // => "Empty"
describe [| 1; 2; 4 |] // => "1, 2, 4"
describe [| 5; 7; 9 |] // => "Other"
```

También puedes _descartar_ un valor al hacer coincidencia de patrones; cuando _no_ te importa un valor en un caso específico (es decir, no vas a _usar_ un valor) puedes usar un guion bajo (`'_'`) para indicar esto:

```fsharp
let describe array =
    match array with
    | [| |] -> "Empty array"
    | [| x |] -> "Array with one item"
    | [| _; y |] -> "Array with two items (first item ignored)"
    | _ -> "Array with many items (all items ignored)"

describe [| |]          // => "Empty array"
describe [| 1 |]        // => "Array with one item"
describe [| 5; 7 |]     // => "Array with two items (first item ignored)"
describe [| 5; 7; 9 |]  // => "Array with many items (all items ignored)"
```

El `'_'` solo debe ir siempre _al final_ al hacer coincidencia de patrones; todo valor que _no_ coincida con ninguno de los otros casos será manejado por este caso.
