# Instrucciones

Elena es la nueva gerente de calidad de una fábrica de periódicos. Como acaba de llegar a la empresa, ha decidido revisar algunos de los procesos de la fábrica para ver qué se podría mejorar.
Descubrió que los técnicos hacen muchos controles de calidad a mano.
Ve que hay una buena oportunidad para la automatización y te pide a ti, desarrollador independiente, que desarrolles un programa para monitorear algunas de las máquinas.

## 1. Monitorear el nivel de humedad de la sala

Tu primera misión es escribir un programa que monitoree el nivel de humedad de la sala de producción. Ya hay un sensor conectado al software de la empresa que devuelve periódicamente el porcentaje de humedad de la sala.

Necesitas implementar una función en el software que lance un error si el porcentaje de humedad es demasiado alto.
La función debe llamarse `checkHumidityLevel` y recibir el porcentaje de humedad como parámetro.

Debes lanzar un error (el mensaje no es importante) si el porcentaje supera el 70 %.

```javascript
checkHumidityLevel(60);
// => undefined
```

```javascript
checkHumidityLevel(100);
// Throws an error
```

## 2. Detectar el sobrecalentamiento

Elena está muy contenta con tu primera tarea y te pide que te encargues de monitorear la temperatura de las máquinas.
Mientras conversas con un técnico, Greg, te comentan que si la temperatura de una máquina supera los 500 °C, los técnicos empiezan a preocuparse por el sobrecalentamiento.

La máquina está equipada con un sensor que mide su temperatura interna.
Debes saber que el sensor es muy sensible y se rompe a menudo.
En ese caso, los técnicos tendrán que cambiarlo.

Tu tarea es implementar una función `reportOverheating` que reciba la temperatura como parámetro y lance un error si el sensor está roto o si la máquina empieza a sobrecalentarse.
Como más adelante vas a necesitar reaccionar de forma distinta según el error, necesitas un mecanismo que diferencie los dos tipos de errores.
Podrías apoyarte en los mensajes de error, pero eso haría tu código frágil, ya que se rompería si el mensaje se actualiza.
Así que, para poder hacerlo bien, lanzarás instancias de distintas clases de error.

- Si el sensor está roto, la temperatura será `null`.
  En ese caso, debes lanzar un `ArgumentError`.
- Cuando todo funciona bien, si la temperatura supera los 500 °C, debes lanzar un `OverheatingError`.
  Esta clase de error se instanciará con un argumento de temperatura.
  Asegúrate de que el `OverheatingError` que lances tenga una propiedad de temperatura.

```javascript
reportOverheating(null);
// Throws an ArgumentError
```

```javascript
reportOverheating(800);
// Throws an OverheatingError
```

## 3. Monitorear la máquina

Ahora que tu máquina puede detectar errores, vas a implementar una función que reaccione a esos errores de distintas maneras:

- Si el sensor está roto, debes avisar a un técnico
- Si la temperatura es demasiado alta, apagarás la máquina si la temperatura supera los 600 °C o encenderás una luz de advertencia si es menor que eso.
- Si ocurre otro error, lo relanzarás.

Implementa una función `monitorTheMachine` que reciba un argumento `actions`.

`actions` es un objeto que tiene 4 propiedades:

| propiedad          | descripción                                                                         |
| ------------------ | ----------------------------------------------------------------------------------- |
| `check`            | una _*función*_. Comprueba la temperatura de la máquina. Puede lanzar varios errores. |
| `alertDeadSensor`  | una _*función*_. Avisa a un técnico que el sensor de temperatura está averiado.      |
| `alertOverheating` | una _*función*_. Encenderá una luz de advertencia en la máquina.                     |
| `shutdown`         | una _*función*_. Apagará la máquina.                                                 |

La función `monitorTheMachine(actions)` debe llamar internamente a `check()`.
Si eso no lanza ningún error, la función no debe devolver nada.
Si eso lanza un error (con `throw`), se espera un comportamiento distinto:

| excepción          | comportamiento esperado              |
| ------------------ | ------------------------------------ |
| `ArgumentError`    | llama a la función `alertDeadSensor`. |
| `OverheatingError` | ejecuta el protocolo de sobrecalentamiento. |
| _(cualquier otra cosa)_ | relanza el error                 |

**Protocolo de sobrecalentamiento**
Si la temperatura es menor que 600 °C, enciende la luz de advertencia llamando a la función `alertOverheating`.
Si la temperatura supera los 600 °C, la situación es crítica, así que llama a la función `shutdown`.

```javascript
monitorTheMachine({
  check,
  alertDeadSensor,
  alertOverheating,
  shutdown,
});
```
