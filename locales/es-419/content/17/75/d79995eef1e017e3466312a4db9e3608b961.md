# Introducción

La recursión es una forma de repetir código dentro de una función haciendo que la función se llame a sí misma.
Se puede ver como otra manera de hacer un bucle o de iterar.
Al igual que con los bucles, se usa una expresión Boolean o una prueba `True`/`False` para determinar cuándo detener la ejecución recursiva.
_A diferencia_ de los bucles, la recursión sin terminación en Python no puede ejecutarse infinitamente.
Los valores que se usan en cada llamada a la función se colocan en su propio [marco][stack-frame] dentro de la [pila del intérprete][what-is-the-call-stack] de Python.
Si el número total de llamadas a la función ocupa más espacio del que la pila tiene disponible, se producirá un error.

```python
def print_increment(step, max_value):
    if step > max_value:
        return
    print(f'The step is {step}')
    print_increment(step + 1, max_value)


def main():
    print_increment(1, 2)
    print("After recursion")

if __name__ == "__main__":
    main()

```

Esto imprimirá

```
The step is 1
The step is 2
After recursion
```

Puede haber situaciones que sean más legibles o más fáciles de razonar cuando se expresan con recursión que cuando se expresan con bucles.
