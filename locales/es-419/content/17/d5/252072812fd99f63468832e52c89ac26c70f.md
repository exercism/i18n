# Anexo de instrucciones

## Implementación

Puedes usar las funcionalidades propias del lenguaje para construir y desestructurar arrays mediante la desestructuración, y usar el literal de array `[]`, pero no debes usar ninguna función de `Array.prototype`.

Para poder probar tu solución, asegúrate de que `forEach` esté implementado.

```typescript
const list = List.create(1, 2)
list.forEach((item) => console.log(item))
// =>
//    1
//    2
```
