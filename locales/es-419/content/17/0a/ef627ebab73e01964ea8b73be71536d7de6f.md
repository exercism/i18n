# Pistas

## 1. Calcula el valor de cualquier carta.

- El método `Blackjack.parse_card` debe recibir un string (por ejemplo, `"ace"`) y devolver su valor (por ejemplo, 11).
- Define una [sentencia `case`][case] y asigna el valor de la carta como el valor de ese caso.
- El rey, la reina, la jota y el 10 se pueden manejar con un solo caso.
- El `case` puede tener un `else`.
  En cualquier caso, la función debe devolver `0` para cartas desconocidas.

## 2. Nombra rangos de valores.

- Calcula la puntuación del jugador sumando los valores de las dos cartas del jugador.
- Define una [sentencia `case`][case] y asigna el nombre del rango como el valor de ese caso.
- La sentencia `case` puede usar objetos [`Range`][range] como casos para comprobar si un valor está dentro de un rango.

## 3. Implementa la lógica de decisión para el primer turno.

- Calcula la puntuación del jugador sumando los valores de las dos cartas del jugador.
- Puedes usar una gran [sentencia `case`][case] sobre la puntuación del jugador
  (quizás con sentencias `if` anidadas sobre la puntuación del crupier en algunos casos),
- o podrías distinguir distintas categorías de puntuación del jugador (por ejemplo, «manos pequeñas»
  con una puntuación menor que 12, «manos medianas» con una puntuación en el rango 12..20 y
  «manos grandes» con una puntuación mayor que 20) y escribir funciones separadas para
  todas (o algunas) de estas categorías.

[case]: https://www.rubyguides.com/2015/10/ruby-case/
[range]: https://docs.ruby-lang.org/en/master/Range.html
