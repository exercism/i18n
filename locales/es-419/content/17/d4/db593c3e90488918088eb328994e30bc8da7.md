# Prefiere el tipo de retorno explícito

Para protegerte de cambios accidentales, define siempre el tipo de `return` en las API públicas, como las funciones que están marcadas con `export`:

\`\`\`typescript
  ${'signature'}: <return-type> {}
\`\`\`

TypeScript es muy bueno para inferir tipos y les asignará un tipo de `return` a todas las funciones. Pero un cambio accidental puede modificar ese tipo inferido, y puede que eso provoque o no un error de compilación en el lugar donde se hizo el cambio. Agregar un tipo de retorno explícito puede hacer que la compilación falle ahí mismo.
