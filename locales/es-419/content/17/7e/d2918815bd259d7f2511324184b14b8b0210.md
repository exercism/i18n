## Roc API

Usa un valor `React` inmutable. Cada operación devuelve un reactor actualizado; conserva ese valor para las operaciones siguientes. Las celdas se identifican con `cell_id` y los callbacks con `callback_id`. Ambos identificadores son strings que se proporcionan cuando se registran. El registro y la eliminación de un callback reciben ambos identificadores para especificar la celda y su callback.

Una función de cómputo recibe una lista de valores de celdas en el mismo orden que su lista `inputs` de identificadores de celdas. Devuelve `Ok(value)` si tiene éxito o `Err(message)` con un string que describe un fallo, como una cantidad incorrecta de argumentos o una división por cero. Sus dependencias deben existir ya cuando se agrega la celda de cómputo. Tanto `add_compute` como `set_value` reportan los errores de cómputo como `ComputeFailed({ cell_id, message })`. Si un cómputo falla durante una actualización, no se devuelve ningún reactor actualizado ni se ejecutan callbacks; el reactor original sigue siendo utilizable.

Los callbacks son funciones puras del tipo `React.CellValue, React.CallbackLog -> React.CallbackLog`. Cada callback recibe el nuevo valor de la celda y el log actual, y luego devuelve un log actualizado. `set_value` recibe un registro que contiene `cell_id`, `value` y el `log` inicial, y devuelve tanto el reactor actualizado como el log final. Pasa el log que devuelve cada callback al siguiente callback; el orden de los callbacks no está especificado.

`React.CallbackLog` es un alias de `Dict(Str, List(I64))`: registra los valores que recibe cada identificador de callback. Los tests pasan un log vacío a cada actualización de un argumento para comprobar que los callbacks se ejecutaron exactamente una vez o no se ejecutaron en absoluto.

Registrar un callback no lo llama. Eliminar el mismo callback más de una vez está permitido y no debe afectar a otros callbacks. Todos los callbacks de una actualización deben observar los valores finales y estables de las celdas.
