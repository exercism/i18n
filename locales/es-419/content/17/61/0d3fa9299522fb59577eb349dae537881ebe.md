# Instrucciones específicas de SQLite

Las columnas **list_one** y **list_two** contienen una lista de números enteros codificada en JSON.

Ejemplo:

```json
[1, 2, 3]
```

## Esquema de la tabla

```sql
CREATE TABLE sublist (
    list_one TEXT NOT NULL,     -- json array
    list_two TEXT NOT NULL,     -- json array
    result   TEXT
);
```
