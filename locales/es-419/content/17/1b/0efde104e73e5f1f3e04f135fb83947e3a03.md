# Introducción

Una interfaz es un tipo que contiene miembros que definen un grupo de funcionalidad relacionada. Separa el uso de una clase de su implementación, lo que permite múltiples implementaciones distintas o el soporte de cierto comportamiento genérico, como el formateo, la comparación o la conversión.

La sintaxis de una interfaz es similar a la de una clase, salvo que los métodos aparecen solo como la firma y no se proporciona ningún cuerpo.

```java
public interface Language {
    String getLanguageName();
    String speak();
}

public class ItalianTraveller implements Language, Cloneable {

    // from Language interface
    public String getLanguageName() {
        return "Italiano";
    }

    // from Language interface
    public String speak() {
        return "Ciao mondo";
    }

    // from Cloneable interface
    public Object clone() {
        ItalianTraveller it = new ItalianTraveller();
        return it;
    }
}
```

Todas las operaciones que define la interfaz las debe implementar la clase que la implementa.

Por lo general, las interfaces contienen métodos de instancia.

Un ejemplo de interfaz que se encuentra en la biblioteca de clases de Java, además de `Cloneable`, que se ilustró antes, es `Comparable<T>`.
La interfaz `Comparable<T>` se puede implementar cuando se requiere un orden de clasificación genérico predeterminado en las colecciones.
