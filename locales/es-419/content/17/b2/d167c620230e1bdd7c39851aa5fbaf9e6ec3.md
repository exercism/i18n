# Instrucciones

Eres el señalero de una embarcación de patrulla costera. La mochila de hoy
necesita cinco palabras pequeñas listas antes de que empiece la guardia matutina.

## 1. Cita un valor

El cuaderno de bitácora registra cada observación en *forma fuente de Factor*,
el mismo texto que el analizador sintáctico volverá a leer. Define `quote-value`
para convertir cualquier valor en su cadena en forma fuente.

```factor
123 quote-value .   ! => "123"
"hi" quote-value .  ! => "\"hi\""
```

## 2. Quita el enmarcado de la bandera

Las banderas de señal entrantes llegan enmarcadas con un carácter marcador en
cada extremo. Define `flag-body` para devolver todo lo que está *entre* los dos
marcadores: descarta el primer carácter y descarta el último.

Devuelve un segmento (una vista) en lugar de copiar.

```factor
"#NS-1024#" flag-body .   ! => "NS-1024"
```

## 3. Divide una bandera

Cada bandera lleva un código de prefijo corto seguido de la carga útil.
Define `split-flag` para que tome una bandera y una longitud de encabezado, y
devuelva *tanto* el segmento del encabezado como el segmento del cuerpo.

```factor
"NS-1024" 2 split-flag .s
! => "NS"
! => "-1024"
```

## 4. Triangula a partir de dos lecturas

Dos lecturas de señal consecutivas dan tres mediciones derivadas: su
*diferencia* `a - b`, su *punto medio* `(a + b) / 2` y su *razón* `a / b`.
Cada medición usa ambas lecturas.

Define `triangulate` para devolver las tres a partir de un par de lecturas.

```factor
100 50 triangulate .s
! => 50
! => 75
! => 2
```

## 5. Resume tres lecturas

Tres lecturas consecutivas se resumen como su **suma**, su **producto** y su
**máximo**. Cada estadística usa las tres lecturas.

Define `triangle-stats` para devolver las tres.

```factor
5 3 8 triangle-stats .s
! => 16
! => 120
! => 8
```
