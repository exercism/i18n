# Instrucciones

Estás trabajando en la implementación de un sistema de monitoreo de salud. Como parte de eso, necesitas llevar un registro de las estadísticas de salud de los usuarios.

Empezarás con algunas funciones sin implementar en un bloque `impl`, además de la siguiente definición de struct:

```rust
pub struct User {
    name: String,
    age: u32,
    weight: f32,
}
```

Tu objetivo es implementar los métodos sin implementar de la `struct` `User` definidos en el bloque `impl`.

Por ejemplo, el método `new` debe devolver una instancia de la `struct` `User` con los valores especificados de nombre, edad y peso.

```rust
let mut bob = User::new(String::from("Bob"), 32, 155.2);
// Returns: a User with name "Bob", age 32, and weight 155.2
```

El método `weight` debe devolver el peso del `User`.

```rust
bob.weight();
// Returns: 155.2
```

El método `set_age` debe establecer la edad del `User`.

```rust
bob.set_age(33);
// Updates Bob's age to 33; happy birthday Bob!
```

¡Diviértete!
