# General

## 1. Define el tipo personalizado genérico `TreasureChest`

- El tipo personalizado `TreasureChest` solo tiene una variante.

## 2. Define el tipo personalizado genérico `UnlockResult`

- El tipo personalizado `UnlockResult` tiene 2 variantes, `Unlocked` y `WrongPassword`.

## 3. Define la función get_treasure

- Los tipos personalizados se pueden usar con coincidencia de patrones de la misma manera para acceder a sus valores.
