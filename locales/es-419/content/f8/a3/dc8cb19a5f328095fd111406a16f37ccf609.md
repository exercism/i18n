# Instrucciones específicas de SQLite

* La columna **candidates** contiene una lista de strings codificada en JSON.
  Ejemplo:
  ```json
  ["stone","tones","banana","tons","notes","Seton"]
  ```
* La columna **result** también debe contener una lista de strings codificada en JSON.

## Esquema de la tabla

```sql
CREATE TABLE anagram (
  subject    TEXT NOT NULL,
  candidates TEXT NOT NULL,     -- json array of strings
  result     TEXT               -- json array of strings
);
```
