# Introducción

JavaScript es un lenguaje dinámico que admite estilos orientados a objetos, imperativos y declarativos (por ejemplo, la programación funcional).

## Variables

Hay algunas formas principales de asignar valores a nombres en JavaScript: usar variables o constantes.
En Exercism, las variables siempre se escriben en [camelCase][wiki-camel-case]; las constantes se escriben en [SCREAMING_SNAKE_CASE][wiki-snake-case].
No hay una guía oficial que seguir, y distintas empresas y organizaciones tienen distintas guías de estilo.
_Puedes escribir las variables como prefieras_.
La ventaja de escribirlas como se preparan en los ejercicios es que se resaltarán de forma diferente en la interfaz web y en la mayoría de los IDE.

Las variables en JavaScript se pueden definir con la palabra clave [`const`][mdn-const], [`let`][mdn-let] o [`var`][mdn-var].

Una variable puede hacer referencia a distintos valores a lo largo de su vida cuando usas `let` o `var`.
Por ejemplo, `myFirstVariable` se puede definir y redefinir muchas veces con el operador de asignación `=`:

```javascript
let myFirstVariable = 1;
myFirstVariable = 'Some string';
myFirstVariable = new SomeComplexClass();
```

A diferencia de `let` y `var`, las variables que se definen con `const` solo se pueden asignar una vez.
Esto se usa para definir constantes en JavaScript.

```javascript
const MY_FIRST_CONSTANT = 10;

// Can not be re-assigned.
MY_FIRST_CONSTANT = 20;
// => TypeError: Assignment to constant variable.
```

## Declaraciones de funciones

En JavaScript, las unidades de funcionalidad se encapsulan en _funciones_, que por lo general se agrupan en el mismo archivo si van juntas.
Estas funciones tienen parámetros (así que pueden recibir argumentos) y pueden _devolver_ un valor usando la palabra clave `return`.
Las funciones se invocan con la sintaxis `()`.

```javascript
function add(num1, num2) {
  return num1 + num2;
}

add(1, 3);
// => 4
```

En este ejemplo, el nombre de la función es `add`.
Tiene dos parámetros, `num1` y `num2`.
Devuelve un valor: el resultado de la expresión `num1 + num2`.

Luego se _llama_ a la función `add` con dos argumentos: `1` y `3`.
El resultado de la función, el valor devuelto, es `4`.

```exercism/note
💡 En JavaScript hay _muchas_ formas distintas de declarar una función.
Algunas de estas otras formas se ven diferentes a usar la palabra clave `function`.
El track intenta presentarlas de forma gradual, pero si ya las conoces, puedes usar la que quieras.
En la mayoría de los casos, usar una u otra no es mejor ni peor.
```

## Exponerlas a otros archivos

Para que una `function`, una constante o una variable estén disponibles en _otros archivos_, hay que [exportarlas][mdn-export] con la palabra clave `export`.
Otro archivo puede luego [importarlas][mdn-import] con la palabra clave `import`.
Esto también se conoce como el sistema de módulos.

Un gran ejemplo es cómo funcionan todas las pruebas.
Cada ejercicio tiene al menos un archivo, por ejemplo `lasagna.js`, que contiene la _implementación_.
La _implementación_ se exporta desde el archivo con `export`, lo que la hace disponible para importarla en otro archivo.
Además, hay al menos otro archivo, por ejemplo `lasagna.spec.js`, que contiene las _pruebas_.
Este archivo importa con `import` las entidades públicas (es decir, las exportadas con `export`) para así probar la implementación:

```javascript
// file.js
export const MY_VALUE = 10;

export function add(num1, num2) {
  return num1 + num2;
}

// file.spec.js
import { MY_VALUE, add } from './file';

add(MY_VALUE, 5);
// => 15
```
