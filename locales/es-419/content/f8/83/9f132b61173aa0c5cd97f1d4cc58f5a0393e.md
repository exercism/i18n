# Introducción

## Argumentos etiquetados

A veces, cuando una función recibe muchos argumentos, puede ser difícil recordar el orden en que se deben pasar. Para facilitar la legibilidad, Gleam permite etiquetar los argumentos con un nombre.

Para etiquetar un argumento, escribe el nombre de la etiqueta antes del nombre del argumento, separados por un espacio.

```gleam
pub fn replace(
  in string: String,
  each target: String,
  with replacement: String
) -> String {
  // ...
}
```

Cuando llamas a una función con argumentos etiquetados, puedes dar los argumentos en cualquier orden. Todas estas llamadas a `replace` son equivalentes:

```gleam
replace(in: "🍔🍔🍔", each: "🍔", with: "🍕")

replace(each: "🍔", in: "🍔🍔🍔", with: "🍕")

replace(with: "🍕", each: "🍔", in: "🍔🍔🍔")
```

Las etiquetas siempre son opcionales. Aunque una función tenga argumentos etiquetados, se puede llamar sin etiquetas.

```gleam
replace("🍔🍔🍔", "🍔", "🍕")
```
