# Acerca de

Las charlists se crean usando el sigilo `~c`.

```elixir
~c"hello"
```

~~~~exercism/note
Ten en cuenta que en versiones anteriores de Elixir, las charlists se representan como `'hello'` con comillas simples.
~~~~

Una charlist es una lista de enteros. Los enteros representan los valores Unicode de un carácter dado, también conocidos como puntos de código.

```elixir
[65, 66, 67]
# => ~c"ABC"
```

## Las charlists _son_ listas

```elixir
~c"" === []
# => true

is_list(~c"hello")
# => true
```

Como las charlists son listas, puedes trabajar con ellas igual que con cualquier otra lista: usando recursión y coincidencia de patrones, o usando el módulo [`List`][list].

```elixir
[first_letter | _] = ~c"cat"
first_letter
# => 99

List.first(~c"hello")
# => 104
List.pop_at(~c"hello", 0)
# => {104, ~c"ello"}

```

Puedes concatenar dos listas usando [`++`][kernel-concat-list].

```elixir
~c"hi" ++ ~c"!"
# => ~c"hi!"
```

Cuanto más larga sea la primera lista, más lenta será la concatenación, así que evita agregar elementos repetidamente a listas de longitud arbitraria.

## Capacidad de impresión

Si una lista de enteros contiene solo enteros que son puntos de código de caracteres imprimibles, se mostrará como una charlist. Incluso si se definió usando la sintaxis `[]`.

```elixir
~c"ABC"
# => ~c"ABC"

[65, 66, 67]
# => ~c"ABC"
```

Si una lista de enteros contiene aunque sea un punto de código de un carácter no imprimible (por ejemplo, `0-6`, `14-26`, `28-31`), se mostrará como una lista. Incluso si se definió usando la sintaxis `~c""`.

```elixir
~c"ABC\0"
# => [65, 66, 67, 0]

[65, 66, 67, 0]
# => [65, 66, 67, 0]
```

La capacidad de impresión se puede verificar con [`List.ascii_printable?`][list-ascii-printable].

```elixir
List.ascii_printable?([65, 66, 67])
# => true
List.ascii_printable?([65, 66, 67, 0])
# => false
```

Ten en cuenta que esas son dos formas distintas de _mostrar_ los mismos datos. Los valores son estrictamente iguales.

```elixir
~c"ABC" === [65, 66, 67]
# => true
```

Cuando imprimes una lista con [`IO.inspect`][io-inspect], puedes usar la opción [`:charlists`][inspect-opts] para controlar cómo se imprimen las listas.

```elixir
IO.inspect(~c"ABC", charlists: :as_charlists)
# => prints ~c"ABC"

IO.inspect(~c"ABC", charlists: :as_lists)
# => prints [65, 66, 67]
```

## Puntos de código

Puedes anteponer `?` a un carácter para obtener su punto de código.

```elixir
?A
# => 65

[?:, ?)]
# => ~c":)"
```

## Charlists y strings

Las charlists y los strings compuestos por los mismos caracteres no se consideran iguales.

```elixir
~c"hello" == "hello"
false
```

Cada valor en una charlist es el [punto de código Unicode de un carácter][unicode-table], mientras que en un string los puntos de código se codifican como [UTF-8][utf8].

```elixir
IO.inspect(~c"tschüss", charlists: :as_lists)
# => prints [116, 115, 99, 104, 252, 115, 115]

IO.inspect("tschüss", binaries: :as_binaries)
# => prints <<116, 115, 99, 104, 195, 188, 115, 115>>
```

Fíjate cómo `ü`, punto de código `252`, se codifica en UTF-8 como `195` y `188`.

**En la práctica, las charlists se usan poco**. Su principal caso de uso es la comunicación con Erlang, en particular cuando se usan bibliotecas antiguas que no aceptan binarios como argumentos.

Cuando trabajes con Elixir, **usa strings para almacenar texto**. El módulo `String` ofrece una amplia variedad de funciones para procesar texto, funciones que no están disponibles para las charlists.

Las charlists se pueden convertir a strings con [`to_string`][kernel-to-string].

```elixir
to_string(~c"hello")
# => "hello"
```
