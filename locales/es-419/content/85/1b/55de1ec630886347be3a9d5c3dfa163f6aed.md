# Introducción

## Tipos de función

Si quitas todos los nombres y etiquetas de la firma de una función de Swift, te queda el tipo de la función.

```swift
func shoppingList(item: String, quantity: Int) -> String {
  "You need to buy \(quantity) \(item)."
}
// shoppingList: (String, Int) -> String

func repeater(_ phrase: String, times: Int) -> String {
  var result = ""
  for _ in 1...times {
    result += phrase
  }
  return result
}
// repeater: (String, Int) -> String

func printString(line: String) {
  print(line)
}
// printString: (String) -> ()
```

Fíjate que los tipos de las dos primeras funciones son iguales, `(String, Int) -> String`, aunque las dos firmas son distintas y las dos funciones funcionan de maneras muy diferentes. Ambas toman un `String` y un `Int` como argumentos y devuelven un `String`. Y, como se puede ver en el tipo de la tercera función, aunque el cuerpo de la función no parece devolver nada, en realidad devuelve implícitamente `()`, el único valor del tipo `Void`.

Estos tipos de función se pueden usar de la misma manera que cualquier otro tipo en Swift; por ejemplo, se pueden usar en la declaración de variables o constantes. Y como las funciones son valores en Swift, puedes asignar funciones que ya existen a esas constantes o variables:

```swift
var stringAndIntToString: (String, Int) -> String

stringAndIntToString = shoppingList
stringAndIntToString("carrots", 3)
// => "You need to buy 3 carrots."
```

Igual que con otras variables o constantes, el valor que le asignas debe ser del tipo correcto:

```swift
stringAndIntToString = printShoppingList
// Error: Cannot assign value of type '(String) -> ()' to type '(String, Int) -> String'
```

## Tipos de función como tipos de parámetro

Como los tipos de función se pueden usar en cualquier lugar donde se pueda usar otro tipo, se deduce que también se pueden usar como tipos de parámetro, pasarse a otras funciones y llamarse desde dentro de esas funciones.

```swift
func apply3(to str: String, function f: (String, Int) -> String) -> String {
  f(str,3)
}
// apply3: ([String], (String, Int) -> String) -> [String]

apply3(to: "eggs", function: shoppingList)
// => "You need to buy 3 eggs."

apply3(to: "eggs", function: repeater)
// => "eggseggseggs"
```

## Tipos de función como tipos de retorno

De forma similar, los tipos de función se pueden usar como tipos de retorno de las funciones. En otras palabras, puedes escribir funciones que crean y devuelven otras funciones. Al crear esas funciones, la función que se devuelve puede usar los otros parámetros que se pasan a la función o las variables locales creadas dentro de la función padre.

```swift
func makeAdder(base: Int) -> (Int) -> Int {
  func adder(_ i: Int) -> Int {
    base + i
  }
  return adder
}
// makeAdder: (Int) -> (Int) -> Int

let add10 = makeAdder(base: 10)
// add10: (Int) -> Int

let subtract20 = makeAdder(base: -20)
// subtract20: (Int) -> Int

add10(5)
// => 15

subtract20(5)
// => -15
```
