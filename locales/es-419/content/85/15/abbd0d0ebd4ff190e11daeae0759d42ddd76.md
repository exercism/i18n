# Anexo de instrucciones

## Registros

| Registro | Uso            | Tipo    | Descripción                              |
| -------- | -------------- | ------- | ---------------------------------------- |
| `$a0`    | entrada        | dirección | primer color como string terminado en nulo  |
| `$a1`    | entrada        | dirección | segundo color como string terminado en nulo |
| `$a2`    | entrada        | dirección | tercer color como string terminado en nulo  |
| `$a3`    | entrada/salida | dirección | string de salida terminado en nulo          |
| `$t0-9`  | temporal       | cualquiera | se usa para almacenamiento temporal        |
