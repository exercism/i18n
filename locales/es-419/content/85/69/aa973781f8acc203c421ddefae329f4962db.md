# Introducción

## Números

En Java hay dos tipos diferentes de números:

- Enteros: números sin dígitos después del separador decimal, es decir, números enteros.
  Algunos ejemplos son `-6`, `0`, `1`, `25`, `976` y `-500000`.
- Números de punto flotante: números con cero o más dígitos después del separador decimal.
  Algunos ejemplos son `-20.4`, `0.1`, `2.72`, `16.984025` y `1024.0`.

Los dos tipos numéricos más comunes en Java son `int` y `double`.
Un `int` es un entero de 32 bits y un `double` es un número de punto flotante de 64 bits.

La aritmética se realiza con los operadores aritméticos estándar.
Los números se pueden comparar con los operadores estándar de comparación numérica (por ejemplo, `5 > 4` y `4 <= 5`) y los operadores de igualdad (`==`) y desigualdad (`!=`).

Java tiene dos tipos de conversiones numéricas:

1. Conversiones implícitas: no se perderán datos y no se requiere sintaxis adicional.
2. Conversiones explícitas: se podrían perder datos y se requiere sintaxis adicional en forma de una _conversión de tipo_.

Como un `int` tiene menos precisión que un `double`, convertir de un `int` a un `double` es seguro y, por lo tanto, es una conversión implícita.
Sin embargo, convertir de un `double` a un `int` podría implicar perder datos, por lo que requiere una conversión explícita.

## Sentencias if-else

### La sentencia _if-then_

La sentencia de flujo de control más básica en Java es la sentencia _if-then_.
Esta sentencia se usa para ejecutar solo una sección de código si una condición en particular es `true`.
Una sentencia _if-then_ se define usando la cláusula `if`:

```java
class Car {
    void drive() {
        // the "if" clause: the car needs to have fuel left to drive
        if (fuel > 0) {
            // the "then" clause: the car drives, consuming fuel
            fuel--;
        }
    }
}
```

En el ejemplo anterior, si el auto se queda sin combustible, llamar al método `Car.drive` no hará nada.

### La sentencia _if-then-else_

La sentencia _if-then-else_ proporciona una ruta alternativa de ejecución para cuando la condición en la cláusula `if` se evalúa como `false`.
Esta ruta alternativa de ejecución sigue a una cláusula `if` y se define usando la cláusula `else`:

```java
class Car {
    void drive() {
        if (fuel > 0) {
            fuel--;
        } else {
            stop();
        }
    }
}
```

En el ejemplo anterior, si el auto se queda sin combustible, llamar al método `Car.drive` llamará a otro método para detener el auto.

La sentencia _if-then-else_ también admite múltiples condiciones usando la cláusula `else if`:

```java
class Car {
    void drive() {
        if (fuel > 5) {
            fuel--;
        } else if (fuel > 0) {
            turnOnFuelLight();
            fuel--;
        } else {
            stop();
        }
    }
}
```

En el ejemplo anterior, conducir el auto cuando el combustible es menor o igual a `5` hará que el auto avance, pero encenderá la luz de combustible.
Cuando el combustible llegue a `0`, el auto dejará de avanzar.
