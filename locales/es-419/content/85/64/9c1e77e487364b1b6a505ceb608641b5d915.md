# Instrucciones

En este ejercicio vas a escribir código para ayudar a un freelancer a comunicarse con sus clientes sobre los precios de ciertos proyectos.
Vas a escribir algunas funciones auxiliares para calcular rápidamente los costos para los clientes.

```exercism/note
La variable `ratePerHour` y la función `dayRate` están relacionadas con el dinero.
Las unidades de medida son dinero por unidad de tiempo: horas y días, respectivamente.
```

## 1. Calcula la tarifa diaria a partir de una tarifa por hora

Un cliente contacta al freelancer para preguntar por sus tarifas.
El freelancer explica que **_trabaja 8 horas al día._**
Sin embargo, el freelancer solo conoce su tarifa por hora para el proyecto.
Ayúdalo a estimar una tarifa diaria a partir de una tarifa por hora.

```javascript
dayRate(89);
// => 712
```

La tarifa diaria no necesita redondearse ni cambiarse a una precisión «fija».

## 2. Calcula la cantidad de días laborables a partir de un presupuesto fijo

Otro día, un gerente de proyecto le ofrece al freelancer trabajar en un proyecto con un presupuesto fijo.
Dado el presupuesto fijo y la tarifa por hora del freelancer, ayúdalo a calcular cuántos días trabajaría hasta que se agote el presupuesto.
El resultado _debe_ **redondearse hacia abajo** al número entero más cercano.

```javascript
daysInBudget(20000, 89);
// => 28
```

## 3. Calcula la tarifa con descuento para proyectos grandes

A menudo, los clientes del freelancer lo contratan para proyectos que abarcan varios meses.
En estos casos, el freelancer decide ofrecer un descuento por cada mes completo, y los días restantes se facturan a la tarifa diaria.
Tu excelente equilibrio entre trabajo y vida personal hace que solo trabajes 22 días en cada mes calendario, así que **_cada mes tiene 22 días facturables._**
Ayúdalo a estimar su costo para este tipo de proyectos, dada una tarifa por hora, la cantidad de días facturables que contiene el proyecto y una tasa de descuento mensual.
El descuento siempre se pasa como un número, donde `42%` se convierte en `0.42`. El resultado _debe_ **redondearse hacia arriba** al número entero más cercano.

```javascript
priceWithMonthlyDiscount(89, 230, 0.42);
// => 97972
```
