# Anexo de instrucciones

## Implementación

Define una única función de Go, Solve, que acepta un string de rompecabezas que puede tener cero o más operadores +, y un operador ==; Solve debe intentar resolver el rompecabezas de alfamética y devolver un map con todas las sustituciones de letras, tanto para el rompecabezas como para el resultado de la suma.

Usa la siguiente firma para func Solve:

```go
func Solve(puzzle string) (map[string]int, error) {
```

Solve debe devolver un error si no hay solución para el rompecabezas dado.

Un ejemplo de rompecabezas y de solución devuelta es:

```go
Solve("SEND + MORE == MONEY")
```

devolvería

```go
map[string]int{"M":1, "O":0, "N":6, "E":5, "Y":2, "S":9, "D":7, "R":8}, nil
```

```text
  S E N D
  M O R E +
-----------
M O N E Y
```

Si reemplazas estas letras por números válidos, obtienes:

```text
  9 5 6 7
  1 0 8 5 +
-----------
1 0 6 5 2
```
