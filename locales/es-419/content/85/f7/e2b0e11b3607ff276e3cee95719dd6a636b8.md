# Pruebas

## Ejecutar las pruebas

Para ejecutar las pruebas, ejecuta el siguiente comando:

```bash
dotnet test
```

## Cómo resolver el ejercicio

Resolver un ejercicio significa hacer que todas sus pruebas pasen. De forma predeterminada, cuando ejecutas las pruebas solo se ejecuta una (la primera). Esto es intencional, ya que te permite concentrarte en hacer que esa única prueba pase. Una vez que pase, puedes habilitar la siguiente prueba quitando `Skip = "Remove this Skip property to run this test"` del atributo `[<Fact>]` o `[<Theory>]` de la prueba. Cuando hayas habilitado todas las pruebas y tu implementación las haga pasar todas, ¡habrás resuelto el ejercicio!

Para ayudarte a empezar, cada ejercicio viene con un archivo de implementación esqueleto. Puedes usar este archivo como punto de partida para construir tu solución. No dudes en eliminar o cambiar este archivo si crees que es lo correcto.

## Usar paquetes

Deberías poder resolver la mayoría de los ejercicios sin usar paquetes externos. Sin embargo, en los ejercicios en los que sí quieras usar un paquete externo, puedes agregarlo a tu proyecto ejecutando el siguiente comando:

```bash
dotnet add package [package-name]
```
