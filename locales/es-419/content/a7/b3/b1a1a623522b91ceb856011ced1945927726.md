# Acerca de

JavaScript tiene un operador de incremento y uno de decremento.
Modifican una variable en el mismo lugar.
`++` le suma uno a un número y `--` le resta uno a un número.

```javascript
let i = 3;
i++;
// i is now 4

let j = 0;
j--;
// j is now -1
```

El ejemplo anterior muestra el operador de incremento/decremento posfijo.
En este caso, el operador se coloca después de la variable y lo que devuelve la expresión es el valor de la variable _antes_ del incremento o el decremento.

```javascript
let a = 3;
let b = a++;
// a = 4
// b = 3
```

También existe la variante prefija, en la que el operador se coloca antes de la variable.
Entonces, lo que devuelve la expresión es el valor de la variable _después_ del incremento o el decremento.

```javascript
let a = 3;
let b = ++a;
// a = 4
// b = 4
```
