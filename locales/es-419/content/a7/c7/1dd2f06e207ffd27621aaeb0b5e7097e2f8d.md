# Apéndice de instrucciones

## Cuentas bancarias en Roc

En el código de Roc, normalmente nos enfocamos en la lógica de negocio mientras que la plataforma se encarga de la concurrencia y del estado compartido.
Por eso, en este ejercicio solo necesitas implementar las operaciones de la cuenta en `BankAccount.roc` sin preocuparte por la concurrencia.
Las cuentas empiezan cerradas, volver a abrir reinicia el saldo, y los depósitos y los retiros deben ser positivos.

## Demo opcional del servidor

El archivo `bank-account-demo.roc` incluido muestra cómo se puede usar tu implementación en un pequeño servicio web.
Puedes leerlo en el editor, pero es independiente de las pruebas y no forma parte de tu solución.

Para ejecutar la demo, debes [instalar Roc](https://www.roc-lang.org/install/) en tu computadora, instalar la [CLI de Exercism](https://exercism.org/cli-walkthrough) y luego ejecutar este comando en una terminal:

```sh
exercism download --exercise=bank-account --track=roc
```

Después, implementa `BankAccount.roc` y pruébalo con el siguiente comando (cambia la ubicación de descarga que imprime la CLI si es distinta de la ruta de abajo):

```sh
cd ~/Exercism/roc/bank-account
roc test bank-account-test.roc
```

Cuando todas las pruebas pasen, puedes iniciar el servidor de la demo con el siguiente comando:

```sh
roc bank-account-demo.roc
```

El servidor usa la [plataforma basic-webserver](https://github.com/roc-lang/basic-webserver) y su soporte integrado de SQLite (Roc descarga la plataforma la primera vez que se ejecuta).
No hace falta un servidor de base de datos aparte.
El servidor escucha en `http://127.0.0.1:8000` y crea `bank-account-demo.db` en tu directorio actual (define `DB_PATH` para usar otro archivo de base de datos).
Detén el servidor con Ctrl-C.
Los datos sobreviven a los reinicios.

En otra terminal, puedes llamar al servicio web con `curl` (en Windows, usa `curl.exe` siempre para evitar el alias `curl` de PowerShell).
Por ejemplo, así puedes abrir la cuenta #123, depositar 50, retirar 10 y consultar su saldo:

```sh
curl -X POST http://127.0.0.1:8000/accounts/123/open
curl -X POST http://127.0.0.1:8000/accounts/123/deposit/50
curl -X POST http://127.0.0.1:8000/accounts/123/withdraw/10
curl http://127.0.0.1:8000/accounts/123/balance
```

El saldo es `40`.
Los ID de cuenta y los montos deben ser enteros sin signo.
Las actualizaciones devuelven `OK` si todo sale bien o un error de tu implementación de la cuenta si falla.
Para cerrar la cuenta #123:

```sh
curl -X POST http://127.0.0.1:8000/accounts/123/close
```

Para probar solicitudes concurrentes en Linux/macOS, usa un ID de cuenta nuevo y envía 100 depósitos desde ocho clientes:

```sh
curl -X POST http://127.0.0.1:8000/accounts/456/open
seq 100 | xargs -P 8 -I '{}' curl --fail --silent --show-error -X POST http://127.0.0.1:8000/accounts/456/deposit/1
curl http://127.0.0.1:8000/accounts/456/balance
```

En Windows, usa [PowerShell 7+](https://learn.microsoft.com/powershell/scripting/install/installing-powershell-on-windows) para el ejemplo en paralelo:

```powershell
curl.exe -X POST http://127.0.0.1:8000/accounts/456/open
1..100 | ForEach-Object -Parallel { curl.exe --fail --silent --show-error -X POST http://127.0.0.1:8000/accounts/456/deposit/1 } -ThrottleLimit 8
curl.exe http://127.0.0.1:8000/accounts/456/balance
```

Todos los depósitos deberían completarse y el saldo debería ser `100`.

## Cómo maneja la concurrencia la demo

Cada solicitud lee la cuenta, llama a tus funciones de Roc y guarda el resultado dentro de una transacción `Immediate` de SQLite.
Las operaciones que fallan se revierten sin cambiar la cuenta.
SQLite permite un solo escritor a la vez, lo que evita que las solicitudes concurrentes sobrescriban las actualizaciones de las demás (incluso entre cuentas distintas).

Nota: el ejercicio usa `U64`, pero la demo guarda los saldos como enteros de SQLite y rechaza las actualizaciones que superan el valor máximo de `I64` (`9223372036854775807`).

Para ver un ejemplo de cómo ejecutar cálculos independientes en paralelo, prueba el [ejercicio de frecuencia de letras en paralelo](https://exercism.org/tracks/roc/exercises/parallel-letter-frequency).
