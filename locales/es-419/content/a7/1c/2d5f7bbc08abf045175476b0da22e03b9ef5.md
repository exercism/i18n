# Instrucciones

A Lucy, la alienígena de Lisp, le gustan los números y piensa que algunos son «magníficos».

Te pide que la ayudes a escribir funciones para hacer que los números sean más magníficos.

Lo que Lucy considera que hace magnífico a un número puede cambiar, así que las funciones tendrán que ser flexibles.

## 1. Hazlos magníficos

Para convertir una lista de números en una lista de números más magníficos, tendrás que escribir una función `make-magnificent-maybe` que reciba una función para aplicarla a los números y una lista de números.
Debe evaluar a una lista de números que sean más magníficos (según la función proporcionada).

```lisp
(make-magnificent-maybe #'square '(1 2 3)) ; => (1 4 9)
(make-magnificent-maybe #'1+ '(1 2 3))     ; => (2 3 4)
```

## 2. Solo los mejores

Después de (con suerte) hacer que los números sean más magníficos, Lucy quiere ver solo los números que son verdaderamente magníficos.

Sabe con certeza que el 1 *nunca* es magnífico, así que tendrás que quitarlo.

Pero aparte de eso, Lucy cambia de opinión a veces, así que de nuevo te dará una función que te dirá si un número es magnífico o no.

Tendrás que escribir una función `only-the-best` que reciba una función y una lista de números, y devuelva solo los mejores números (no `1` y no los números para los que la función evalúe a verdadero).

```lisp
(only-the-best #'evenp '(1 2 3 4 5)) ; => (3 5)
(only-the-best #'oddp '(1 3 5))    ; => ()
```
