# Instrucciones

En este ejercicio vas a procesar líneas de registro.

Cada línea de registro es una cadena con el siguiente formato: `"[<LEVEL>]: <MESSAGE>"`.

Existen tres niveles de registro diferentes:

- `INFO`
- `WARNING`
- `ERROR`

Tienes tres tareas, y cada una recibe una línea de registro y te pide hacer algo con ella.

## 1. Obtén el mensaje de una línea de registro

Implementa la función `message` para que devuelva el mensaje de una línea de registro:

```fsharp
message "[ERROR]: Invalid operation"
// => "Invalid operation"
```

Se deben eliminar los espacios en blanco al principio y al final:

```fsharp
message "[WARNING]:  Disk almost full\r\n"
// => "Disk almost full"
```

## 2. Obtén el nivel de registro de una línea de registro

Implementa la función `logLevel` para que devuelva el nivel de registro de una línea de registro, el cual debe devolverse en minúsculas:

```fsharp
logLevel "[ERROR]: Invalid operation"
// => "error"
```

## 3. Reformatea una línea de registro

Implementa la función `reformat` que reformatea la línea de registro, poniendo el mensaje primero y el nivel de registro después, entre paréntesis:

```fsharp
reformat "[INFO]: Operation completed"
// => "Operation completed (info)"
```
