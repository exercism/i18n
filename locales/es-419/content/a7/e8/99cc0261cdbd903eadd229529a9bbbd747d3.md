# Introducción

## Herencia

La herencia es un concepto central en la POO (programación orientada a objetos).
Representa una relación ES-UN.
En programación significa literalmente lo mismo que en inglés: heredar características de un padre (en programación, esas características normalmente son funciones y variables).

Considera una clase `Animal`, como se muestra:

```java
//Creating an Animal class with bark() as a member function.
public class Animal {

    public void bark() {
        System.out.println("This is an animal");
    }

}
```

`Animal` es una clase padre, porque las propiedades que tiene esta clase se pueden extender a todos los animales en general.

Considera un animal llamado `Lion`, que tiene una clase como esta:

```java
//Lion class is a child class of Animal.
public class Lion extends Animal {

    @Override
    public void bark() {
        System.out.println("Lion here!!");
    }

}
```

~~~~exercism/note
La anotación `Override` se usa para indicar que un método de una subclase está sobrescribiendo un método de su superclase.
No es estrictamente necesaria, pero es una buena práctica usarla.
~~~~

Ahora, siempre que hacemos esto:

```java
Animal animal = new Lion(); //creating instance of Animal, of type Lion
animal.bark();
```

Nota: inicializamos la clase `Animal` con `Lion`.
La salida se verá así:

```java
Lion here!!
```

Según la POO, hay muchos tipos de herencia, pero Java solo soporta algunos de ellos (multinivel y jerárquica).
Para leer más al respecto, consulta [este artículo][java-inheritance].
