# Instalación para hackers de Linux (solo para uso avanzado de Linux)

Seguimos afinando las mejores instrucciones para esto, pero sabemos (y agradecemos) que muchos desarrolladores de Linux son muy exigentes con lo que instalan y con el lugar donde deberían ir las cosas.

_Si prefieres seguir con una instalación estándar, simplemente regresa y sigue [la configuración normal](https://exercism.io/tracks/pharo-smalltalk/installation)._

Las siguientes instrucciones están todavía en desarrollo (WIP) y se basan en ArchLinux, pero pueden servir para tu distro (y si no es así, ayúdanos a encontrar mejoras, y posiblemente también a enviar solicitudes al proyecto Pharo). _Nota: todavía no está claro si estas instrucciones funcionan de forma confiable, así que agradeceríamos cualquier ayuda para mejorarlas._

- Instala una VM de Pharo en la ubicación que prefieras. Puede que puedas usar una de AUR o su equivalente si pharo 7 aparece listado ahí, O bien descargar una desde: [https://files.pharo.org/vm/pharo-spur64/linux/] (y elegir una vm con stable-timer)
- Luego necesitas extraer un archivo Pharo.image para colocarlo en tu directorio de Exercism. Puedes obtenerlo desde: [https://files.pharo.org/image/70/] y elegir el archivo zip de 64 bits más reciente.
- Ahora prueba una prueba sencilla desde la línea de comandos para verificar si la VM y la Image funcionan: `pharo Pharo.image eval "100 factorial"`. Si todo está bien, deberías obtener una respuesta.
- Ahora prueba el «load script» que se describe en la sección de OSX. Puede que recibas un error que mencione `libgit2`; si es el caso, también deberías instalarlo y volver a intentar. También hemos recibido reportes de que instalar `libcurl-gnutls` puede ayudar (pero aún no está comprobado)
- También hemos recibido reportes de que, para algunas fallas de libgit2, hay un cambio interno en loadModule que podríamos portar desde el Pharo de desarrollo. En este caso, necesitas reemplazar el método `unixModuleName` en la clase `LGitLibrary` de la siguiente manera:
  1. Inicia un Pharo con interfaz (headfull) escribiendo `pharo-ui Pharo.image`
  1. Presiona Ctrl-Space y escribe `unixModuleName`
  1. Selecciona la entrada `LGitLibrary >> unixModuleName` y presiona enter
  1. En el navegador que aparece, reemplaza el código fuente del método `unixModuleName` por lo siguiente (cópialo y pégalo), presiona guardar (ctrl-s) y, por último, guarda y sal del Pharo.
```
LGitLibrary >> unixModuleName
	| pluginDir |
	pluginDir := Smalltalk vm binary parent.
	#('libgit2.so' 'libgit2.so.0')
		detect: [ :each | (pluginDir / each) exists ] 
		ifFound: [ :libName | ^ (pluginDir / libName) fullName ].

	self error: 'Module not found.' 
 ```

Ahora vuelve a intentar el «load script» de exercism para OSX que mencionamos antes. Si todo funciona bien, deberías ver barras de progreso de carga parpadeando en la pantalla y, luego, aparecerá una ventana del System Browser. Si no es así, visita el Discord de Pharo (como se indicó antes).

Ahora deberías regresar y seguir el resto de las [instrucciones para empezar](https://exercism.io/tracks/pharo-smalltalk/installation).
