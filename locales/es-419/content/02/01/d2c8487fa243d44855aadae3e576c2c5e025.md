# Instrucciones

En **Chrono Realms**, los Time Keepers no solo trabajan con árboles de líneas temporales, sino también con **Chrono Chains**: secuencias de **TimeNodes** enlazados, y cada uno representa un momento específico en el tiempo.
Una **Chrono Chain** es una ruta directa de momentos secuenciales, donde cada **TimeNode** se conecta con el siguiente.
Estas **Chrono Chains** son útiles cuando se viaja a través de una serie de eventos específicos, ya que permiten a los Time Keepers seguir una sola línea temporal.

Sin embargo, para manejar estas **Chrono Chains** que pueden ser muy largas, los Time Keepers usan **punteros inteligentes (Box<T>)** para gestionar y recorrer de forma segura estas listas de momentos sin provocar duplicación innecesaria de memoria ni desbordamiento.
Cada **TimeNode** guarda una referencia al siguiente nodo, formando una estructura recursiva.

Tu tarea como aprendiz es implementar una **Chrono Chain** como una estructura de lista recursiva usando punteros inteligentes.

En este ejercicio vas a:

1. Crear un enum recursivo `ChronoChain` que represente una lista de momentos.
2. Usar el puntero inteligente `Box<T>` para almacenar los nodos recursivos.
3. Implementar una función para crear una `ChronoChain` a partir de un array de valores `u32`.
4. Implementar una función para recorrer la `ChronoChain` y sumar los valores almacenados en la lista.

## 1. Define el enum recursivo `ChronoChain`

Crea un enum recursivo `ChronoChain` con dos variantes:

- `End`: representa el final de la lista.
- `Link`: contiene un valor `u32` y una referencia al siguiente nodo de la cadena dentro de un Box.

## 2. Crea una función para construir una ChronoChain

Escribe una función `ChronoChain::build` que tome un array de valores `u32` y devuelva una `ChronoChain`, enlazando los valores de forma secuencial mediante punteros inteligentes.

## 3. Implementa la función de suma

Escribe una función `ChronoChain::sum` que recorra recursivamente la `ChronoChain` y sume los valores de todos los nodos.

## Ejemplo de uso

```rust
fn main() {
    // Create a ChronoChain from an array of values
    let chrono_chain = ChronoChain::build(array![10, 20, 30]);

    // Sum the values in the ChronoChain
    let total_sum = chrono_chain.sum();

    println!("Total Time Power: {}", total_sum);
}
```
