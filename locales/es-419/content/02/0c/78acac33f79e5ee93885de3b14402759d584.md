# Manipulación de bits

Crystal tiene operadores a nivel de bits para manipular [`Int`][ints] en el plano binario.

## Operadores de desplazamiento

Crystal tiene [operadores de desplazamiento][shift] para desplazar bits a la izquierda (`<<`) o a la derecha (`>>`).

### Desplazamiento a la izquierda (`<<`)

El operador de desplazamiento a la izquierda (`<<`) desplaza los bits hacia la izquierda.
El valor que se va a desplazar se indica del lado izquierdo, y el número de posiciones que se va a desplazar, del lado derecho.

```crystal
0b0010 << 1
# => 0b0100

0b0010 << 2
# => 0b1000
```

Si el número es negativo, se desplazará hacia la derecha en su lugar.

```crystal
0b0010 << -1
# => 0b0001
```

### Desplazamiento a la derecha (`>>`)

El operador de desplazamiento a la derecha (`>>`) desplaza los bits hacia la derecha.
Al igual que el operador de desplazamiento a la izquierda, el valor que se va a desplazar se indica a la izquierda, y el número de posiciones que se va a desplazar, a la derecha.

```crystal
0b0100 >> 1
# => 0b0010

0b0100 >> 2
# => 0b0001
```

Y, de forma similar, el operador desplazará hacia la izquierda si el número es negativo.

```crystal
0b0100 >> -1
# => 0b1000
```

## Operadores binarios

Crystal tiene 3 [operadores binarios][binary] (`&`, `|`, `^`) y un operador `~` para realizar operaciones a nivel de bits.

### AND a nivel de bits (`&`)

El operador AND binario (`&`) realiza una operación AND a nivel de bits sobre dos valores.
Compara cada bit del primer valor con el bit que está en la misma posición del segundo valor.
El bit resultante se establece en 1 si ambos bits son 1.
De lo contrario, se establece en 0.

```crystal
0b0011 & 0b1010
# => 0b0010
```

### OR a nivel de bits (`|`)

El operador OR binario (`|`) realiza una operación OR a nivel de bits sobre dos valores.
También compara cada bit del primer valor con el bit que está en la misma posición del segundo valor.
Si cualquiera de los dos bits es 1, el bit resultante se establece en 1.
De lo contrario, se establece en 0.

```crystal
0b0011 | 0b1010
# => 0b1011
```

### XOR a nivel de bits (`^`)

El operador XOR binario (`^`) realiza una operación XOR a nivel de bits.
Al igual que los operadores AND y OR a nivel de bits, compara cada bit del primer valor con el bit que está en la misma posición del segundo valor.
Si _solo uno_ de ellos es 1, el bit resultante es 1.
De lo contrario, es 0.

```crystal
0b0011 ^ 0b1010
# => 0b1001
```

### NOT a nivel de bits (`~`)

Por último, el operador NOT a nivel de bits (`~`) invierte cada uno de los bits del valor.
A diferencia de los otros operadores binarios, este es un operador unario, que opera solo sobre el valor de la derecha.

```crystal
~0b1110_0010
# => 0b0001_1101
```
