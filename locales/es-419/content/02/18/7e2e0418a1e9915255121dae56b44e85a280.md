# Pistas

## General

- Lee la documentación de [MapSet][mapset]
- La documentación de [Enum][enum] también podría ser útil

## 1. Comienza una colección

- [Esta es la función de `MapSet` más apropiada][new] para resolver la tarea

## 2. Haz crecer la colección

- Usa [esta función de `MapSet`][put] para agregar cartas a tu colección
- Usa [esa función de `MapSet`][member] para verificar si tienes una carta específica en tu colección

## 3. Empieza a intercambiar

- Para verificar si puedes intercambiar una carta, usa [esta función de `MapSet`][member]
- Para actualizar tu colección, usa [esta función de `MapSet`][delete] y [esa otra][put]

## 4. Solo puede haber una de cada una

- Un `MapSet` tiene la propiedad de contener solo valores únicos
- Usa [esta función de `MapSet`][new] para crear un conjunto y [esa otra][to_list] para convertirlo de nuevo en una lista
- Los `MapSet` no tienen noción de orden, deberías usar [esta función de `Enum`][sort] para ordenar las cartas, aunque los tests pasen sin eso

## 5. Cartas que no tienen

- Usa [esta función de `MapSet`][difference] para verificar las diferencias entre colecciones
- Usa [esa función de `MapSet`][size] para obtener la cantidad de cartas en una colección

## 6. Cartas que todos tienen

- [Esta función de `Enum`][reduce] te será útil para recorrer todas las colecciones
- Usa la coincidencia de patrones en la lista para diferenciar las listas vacías de las no vacías
- [Esta función de `MapSet`][intersection] te ayudará a conservar las cartas en común
- [Esta función de `MapSet`][to_list] puede crear una lista
- Los `MapSet` no tienen noción de orden, deberías usar [esta función de `Enum`][sort] para ordenar las cartas, aunque los tests pasen sin eso

## 7. Todas las cartas

- [Esta función de `Enum`][reduce] te será útil para recorrer todas las colecciones
- Usa [esta función de `MapSet`][new_empty] como acumulador
- [Esta función de `MapSet`][union] te ayudará a acumular todas las cartas
- [Esta función de `MapSet`][size] contará cuántas cartas tienes

## 8. Brillantes para ganar

- Usa [esta función de `MapSet`][split_with] para separar tu colección
- Usa [esta función de `String`][starts_with] para detectar cartas brillantes
- [Esta función de `MapSet`][to_list] puede crear una lista
- Los `MapSet` no tienen noción de orden, deberías usar [esta función de `Enum`][sort] para ordenar las cartas, aunque los tests pasen sin eso
