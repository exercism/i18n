# Instrucciones

Toma un array anidado y devuelve un único array aplanado con todos los valores excepto nil/null.

El reto es escribir una función que acepte una estructura anidada similar a un array, de profundidad arbitraria, y devuelva una estructura aplanada sin ningún valor nil/null.

Por ejemplo

input: [1,[2,3,null,4],[null],5]

output: [1,2,3,4,5]
