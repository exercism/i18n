# Introducción

## Números

Lua usa dos representaciones para los números: números enteros de 64 bits y números de punto flotante de doble precisión. Admite el conjunto habitual de operadores aritméticos: suma, resta, multiplicación, división y negación. Además, admite la división entera, el módulo y la exponenciación.

| Operador | Ejemplo             |
| -------- | ------------------- |
| `+`      | `1 + 2 --> 3`       |
| `-`      | `2 - 1 --> 1`       |
| `*`      | `2 * 2 --> 4`       |
| `/`      | `4 / 2 --> 2.0`     |
| `//`     | `11 // 3 --> 3`     |
| `%`      | `11 % 3 --> 2`      |
| `^`      | `10 ^ 2 --> 100.0`  |
| `-`      | `-(2 * 2) --> -4`   |
