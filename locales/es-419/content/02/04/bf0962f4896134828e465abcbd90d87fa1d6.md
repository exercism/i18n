# Introducción

Gleam tiene funciones de primera clase, lo que significa que las funciones son valores normales que se pueden asignar a variables, pasar como argumentos y devolver desde otras funciones.

Se puede hacer referencia a una función con nombre definida en un módulo usando su nombre.

```gleam
pub fn main() {
  // Assign the function to a variable
  let f = add_one
  
  // Invoke the function
  f(1) // -> 2
  f(2) // -> 3
}

fn add_one(x) {
  x + 1
}
```

Gleam también tiene funciones anónimas, que se definen dentro de otras funciones.

```gleam
// Define the function
let f = fn(x) { x + 1 }

// Invoke the function
f(1) // -> 2
f(2) // -> 3
```

El tipo de una función se escribe con una sintaxis similar a la de las funciones anónimas. El tipo de una función que recibe un `Int` y un `Float` y devuelve un `Int` se escribe así:

```gleam
fn(Int, Float) -> Int
```

Las funciones anónimas pueden hacer referencia a variables que estaban en el ámbito cuando se definieron, lo que las convierte en _closures_.

```gleam
let secret_number = 42

// This function always returns 42
fn() { secret_number }
```

La sintaxis de _captura de función_ ofrece una forma abreviada y práctica de crear funciones anónimas que pasan un solo argumento a una función. Estas dos expresiones son equivalentes:

```gleam
// Anonymous function syntax
let f = fn(x) { my_function(1, 2, x) }

// Function capture syntax
let f = my_function(1, 2, _)
```
