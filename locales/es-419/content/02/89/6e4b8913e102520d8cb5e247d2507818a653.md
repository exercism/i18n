# Pistas

## 1. Crea un vector con todos los vagones

- Un bucle `for`/`while` clásico que use `push!` en un `Vector` funcionará.
- De lo contrario, la función [`collect()`][collect] puede ser más concisa.
- Como alternativa, el splatting funciona dentro de un constructor de vectores:

```julia-repl
julia> input = (1, 5, 9)
(1, 5, 9)

julia> [input...]
3-element Vector{Int64}:
 1
 5
 9
```

## 2. Corrige el vector de vagones

- Es útil separar los vagones de adelante y la locomotora de todo lo demás, para poder volver a armarlos en el orden correcto.
- La asignación múltiple con splatting puede ayudarte (consulta la introducción).

## 3. Agrega las paradas que faltan

- ¡Recuerda que esta función no modifica el argumento! Crea un nuevo `Dict`.
- Solo se necesita el nombre de la parada, no el número de la parada, así que cada par debe separarse.
- Hay varias maneras de armar el vector de nombres:
  -  Bucle `for`/`while` con `push!()` a un `Vector`.
  -  [Comprensión][comprehensions] de arrays.
  -  Aplicar una función al vector con [`map()`][map].
  -  El [broadcasting][broadcasting] de una función [anónima][anonymous] es posible:

 ```julia-repl
julia> (x -> x^4).([1, 2, 3]) == [1, 16, 81]
true
 ```

## 4. Amplía la información de ruta

- Después del slurping, `more_route_information` es una colección `Pairs()`.
- La función [`merge()`][merge] combina dos o más `Dict`, pero también acepta una colección `Pairs()`.
  La conversión explícita de la colección `Pairs()` a un `Dict` es posible, pero innecesaria.
