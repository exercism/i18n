# Lotes de pagos en la base de datos

## Planteamiento del problema

Debes insertar un lote de datos de pago en la tabla `Payment`. Tu tarea es leer los datos de pago del archivo JSON de entrada dado y usar la operación `batchExecute` del cliente JDBC para insertar los datos de pago en la tabla `Payment`. El archivo de entrada de ejemplo se da como `payments.json`.

El contenido del archivo JSON de entrada se basa en el siguiente esquema JSON.

```json
{
  "type": "array",
  "items": [
    {
      "type": "object",
      "properties": {
        "employee_id": {
          "type": "integer"
        },
        "amount": {
          "type": "number"
        },
        "reason": {
          "type": "string"
        },
        "date": {
          "type": "string"
        }
      },
      "required": [
        "employee_id",
        "amount",
        "reason",
        "date"
      ]
    }
  ]
}

```

Debes devolver como salida los IDs de pago generados automáticamente para los datos de pago insertados en el lote, sin lanzar otra consulta a la base de datos.

Puedes suponer que los `employee_id` dados en el archivo `payments.json` son válidos y ya están contenidos en la tabla `Employee`.

## Detalles de la base de datos

Usa la base de datos H2 proporcionada para este problema.

> El archivo de base de datos de ejemplo es `gofigure.mv.db`, y el nombre de la base de datos es `gofigure`. Se proporciona dentro de la carpeta `db`.

Las siguientes tablas ya están en la base de datos H2 de ejemplo con algunos datos de ejemplo. Los nombres de las columnas y los tipos de datos se muestran a continuación.

**Nombre de la tabla** : `Employee`

| **Columnas:**      | tipo |
| -----------       | ----------- |
| `employee_id`     | integer, clave primaria autoincrementada       |
| `name`            | string        |
| `city`            | string        |
| `department`      | string        |
| `age`             | integer        |

**Nombre de la tabla**: `Payment`

| **Columnas:**      | tipo |
| -----------       | ----------- |
| `payment_id`      | integer, clave primaria autoincrementada       |
| `date`            | date        |
| `amount`          | decimal        |
| `employee_id`     | integer        |
| `reason`          | string        |

* El archivo de base de datos es `gofigure.mv.db`. Usa la URL de JDBC como `jdbc:h2:file:/path/to/db/file`
* Nombre de usuario: `root`
* Contraseña: `root`

## Restricciones

* Usa el archivo de base de datos H2 proporcionado en la carpeta `db` para validar las consultas y el ejemplo de Ballerina
* Usa el enfoque de parámetros de dependencia de Maven para agregar el controlador de la base de datos H2 como dependencia de plataforma en tu Ballerina.toml
* Debes encontrar los IDs de pago generados automáticamente sin lanzar otra consulta a la base de datos.

## Entorno de pruebas

* Puedes ejecutar las pruebas con `bal test`, y se ejecutarán las pruebas contra la base de datos de ejemplo dada.

## Ejemplos

### Ejemplo 1

**Entrada:** dbFilePath: `"/path/to/file/gofigure"`, paymentFilePath: `"/path/to/file/payments.json"`

Datos del archivo `payments.json` de ejemplo:

```json
[{
        "employee_id": 4,
        "amount": 12500.50,
        "reason": "Fuel for the month January",
        "date": "2022-02-03"
    },
    {
        "employee_id": 1,
        "amount": 10500.50,
        "reason": "Medical Expenses for the month January",
        "date": "2022-02-04"
    },
    {
        "employee_id": 4,
        "amount": 500.50,
        "reason": "Fuel for the month February",
        "date": "2022-03-03"
    }
]

```

**Salida:** `[1,2,3]`

## Pistas

* Usa el módulo [ballerinax/java.jdbc](https://central.ballerina.io/ballerinax/java.jdbc) para trabajar con la base de datos
* Consulta la sección [Requisitos previos](https://lib.ballerina.io/ballerinax/java.jdbc/latest) para ver los pasos con los que agregar el controlador JDBC como dependencia
* Usa [io:fileReadJson](https://lib.ballerina.io/ballerina/io/latest/functions#fileReadJson) para leer el archivo JSON de entrada
* Convierte los valores JSON a tipos específicos de la aplicación para trabajar con los datos de forma segura en cuanto a tipos. Consulta el ejemplo [Conversión a un tipo definido por el usuario](https://ballerina.io/learn/by-example/convert-from-json-to-user-defined-type/)
* Usa [sql:ParameterizedQuery](https://lib.ballerina.io/ballerina/sql/latest#ParameterizedQuery) y el método remoto [batchExecute](https://lib.ballerina.io/ballerinax/java.jdbc/latest#Client-batchExecute) para trabajar con la base de datos
* Consulta el ejemplo [batch execute](https://ballerina.io/learn/by-example/mysql-batch-execute-operation/)
