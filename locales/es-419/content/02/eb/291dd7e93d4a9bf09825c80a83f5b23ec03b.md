## Ejercicio de ejemplo 1

La solución de [«desi-belokonska»](https://exercism.org/tracks/rust/exercises/leap/solutions/01d024321b6a491690321844aedf8b09)

```rust
pub fn is_leap_year(year: u64) -> bool {
  year % 400 == 0 || year % 4 == 0 && year % 100 != 0
}
```

## Ejercicio de ejemplo 2

[Canónica](https://github.com/exercism/rust/blob/master/exercises/leap/example.rs)

```rust
pub fn is_leap_year(year: u64) -> bool {
    let has_factor = |n| year % n == 0;
    has_factor(4) && (!has_factor(100) || has_factor(400))
}
```
