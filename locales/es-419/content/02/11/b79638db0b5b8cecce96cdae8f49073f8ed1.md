# Tarifas de freelancer

## Historia

En este ejercicio vas a escribir código para ayudar a un freelancer a comunicarse con un gerente de proyecto, ofreciendo algunas utilidades que calculen rápidamente tarifas diarias y mensuales, opcionalmente con un descuento dado.

Primero establecemos algunas reglas entre el freelancer y el gerente de proyecto:

- La tarifa diaria es 8 veces la tarifa por hora;
- Un mes tiene 22 días facturables.

El freelancer ofrece aplicar un descuento si el gerente de proyecto decide dejar que el freelancer facture por mes, lo cual puede resultar útil si hay un presupuesto determinado con el que el gerente de proyecto tenga que trabajar.

Los descuentos se modelan como números fraccionarios seguidos de un `%` (porcentaje) entre `0.0%` (sin descuento) y `90.0%` (descuento máximo).

## Tareas

Estas son tareas de ejemplo que encajan con la historia del freelancer que se comunica con un gerente de proyecto:

- Calcular la tarifa diaria a partir de una tarifa por hora
- Calcular la tarifa mensual a partir de una tarifa por hora y un descuento
- Calcular el número de días laborables a partir de un presupuesto, una tarifa y un descuento

## Terminología

Estas son recomendaciones, no reglas, sobre la terminología recurrente en las instrucciones (incluidos los comentarios del stub)

- La tarifa diaria es 8 veces la tarifa por hora; se debe mencionar
- La tarifa mensual es 22 veces la tarifa diaria; se debe mencionar
- Si el descuento se pasa como un tipo _diferente_ a los tipos numéricos, usa la terminología **los descuentos se modelan como**
