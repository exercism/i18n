# Acerca de

Los condicionales de Factor toman **quotations** como sus ramas: código escrito entre corchetes, `[ ... ]`, que se apila como un valor en lugar de ejecutarse hasta que el condicional lo selecciona. (Las quotations en sí se explican por completo en un ejercicio posterior.)

Los tres básicos están en `kernel`:

```
if      ( ? then-quot else-quot -- )
when    ( ? quot -- )
unless  ( ? quot -- )
```

Las dos variantes con asterisco tratan el Boolean como un valor que vale la pena usar cuando es verdadero: el par canónico «valor o `f`»:

```
if*     ( ? true false -- )    ! truthy: true called WITH value
unless* ( ? false      -- )    ! falsy: false runs and pushes default
```

```factor
: abs   ( x -- y ) dup 0 < [ neg ] [ ] if ;
: shout ( s -- )   dup empty? [ drop ] [ >upper print ] if ;
```

Para más de dos ramas, `cond` (en `combinators`) recorre un array de pares `{ predicate body }` y ejecuta el cuerpo del primer predicado que se cumple. El patrón convencional usa `dup` en cada predicado para que el argumento sobreviva, y el cuerpo empieza con un `drop` para descartarlo antes de apilar el resultado:

```factor
{
    { [ dup 0 <  ] [ drop "negative" ] }
    { [ dup 0 =  ] [ drop "zero"     ] }
    [ drop "positive" ]
} cond
```

Una entrada final sin predicado es la rama por defecto.
