# Introducción

Este ejercicio se basa en la aritmética de enteros de
[Las deliciosas lasañas de Leah][lasagna]. Aquí vas a trabajar con números
de punto flotante y a elegir la palabra de división correcta para cada
tarea.

## Enteros y números de punto flotante

Factor distingue los enteros (`1`, `42`, `1_000_000`) de los números de
punto flotante (`1.0`, `3.14`, `6.02e23`). Si mezclas un entero y un
número de punto flotante en un mismo cálculo, el resultado sale como un
número de punto flotante:

```factor
2 3 + .      ! => 5
2 3.0 + .    ! => 5.0
```

Puedes poner guiones bajos dentro de un número para agrupar los dígitos,
como en `1_000_000`, y Factor simplemente los ignora.

## Palabras de división

Factor tiene palabras de división separadas. Todas viven en el vocabulario
[`math`][math].

```
/    ( x y -- x/y )    ! exact: ratio for two integers, float if either is a float
/f   ( x y -- f   )    ! always a float
/i   ( x y -- q   )    ! integer division (truncates toward zero)
mod  ( x y -- r   )    ! remainder
/mod ( x y -- q r )    ! quotient and remainder together
```

```factor
1 2 / .        ! => 1/2     (a proper ratio)
16 3 / .       ! => 5+1/3   (an improper ratio, printed as a mixed numeral)
16 3 /f .      ! => 5.333333333333333
16 3 /i .      ! => 5      (truncated)
16 3 mod .     ! => 1
16 3 /mod .s   ! quotient and remainder in one pass
! => 5
! => 1
16.0 3 / .     ! => 5.333333333333333
```

`/` produce un `ratio` (el tipo racional exacto de Factor) para dos
enteros, o un `float` si alguna de las entradas es de punto flotante. `/f`
fuerza un resultado de punto flotante incluso para dos enteros. `/i`
siempre trunca hacia cero.

## Verificación

Predicados numéricos de [`math`][math], [`math.functions`][math.functions]
y [`math.primes`][math.primes]:

```
zero?    ( x       -- ? )
even?    ( x       -- ? )
odd?     ( x       -- ? )
prime?   ( x       -- ? )
divisor? ( m n     -- ? )    ! true when n divides m
integer? ( x       -- ? )    ! true for ints (fixnum or bignum)
float?   ( x       -- ? )    ! true for floats
number?  ( x       -- ? )    ! true for any numeric kind
```

```factor
0 zero? .            ! => t
0.0 zero? .          ! => t
3 zero? .            ! => f

4 even? .            ! => t
7 even? .            ! => f
7 odd? .             ! => t

7 prime? .           ! => t
9 prime? .           ! => f

15 5 divisor? .      ! => t   (5 divides 15)
15 4 divisor? .      ! => f
```

## De punto flotante a entero

`floor`, `ceiling` y `round` del vocabulario
[`math.functions`][math.functions] devuelven un número de punto flotante
(`3.0`, no `3`). Para obtener un entero de verdad, encadena `>integer`:

```factor
3.7 floor >integer .       ! => 3
3.2 ceiling >integer .     ! => 4
```

## Potencias y valor absoluto

`sq`, `^` y `abs` (en [`math.functions`][math.functions])
calculan cuadrados, potencias arbitrarias y valores absolutos:

```
sq  ( x   -- x*x )
^   ( x y -- x^y )
abs ( x   -- |x| )
```

```factor
5 sq .          ! => 25
2 10 ^ .        ! => 1024
2 0.5 ^ .       ! => 1.4142135623730951
-7 abs .        ! => 7
3 abs .         ! => 3
```

## Mínimo y máximo

`min ( x y -- z )` y `max ( x y -- z )` (en
[`math.order`][math.order]) devuelven el menor o el mayor de dos
números:

```factor
3 7 min .       ! => 3
3 7 max .       ! => 7
```

El uso más común es el *acotado*: fijar un valor a un mínimo
con `max` (por ejemplo, `0 max` mantiene un valor no negativo) o a un
máximo con `min`.

## Predicados de orden

`math.order` también ofrece `before?`, `after?`, `before=?` y
`after=?` para predicados de comparación que funcionan con cualquier
tipo ordenable: números, strings y caracteres:

```
before?  ( obj1 obj2 -- ? )   ! obj1 <  obj2
before=? ( obj1 obj2 -- ? )   ! obj1 <= obj2
after?   ( obj1 obj2 -- ? )   ! obj1 >  obj2
after=?  ( obj1 obj2 -- ? )   ! obj1 >= obj2
```

Úsalos en lugar de `<`/`<=` cuando los valores puedan ser strings:
los operadores aritméticos no se aplican a los strings.
