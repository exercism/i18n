# Pruebas

Cada ejercicio contiene un archivo de pruebas.
Ejecuta las pruebas con el programa `bats`.

```bash
bats hello_world.bats
```

Si necesitas imprimir información de depuración mientras ejecutas las pruebas de forma local, consulta [Depurar localmente][debugging].

`bats` tendrá que estar instalado.
Consulta la página [Pruebas en el track de Bash][tests] para ver las instrucciones de instalación de `bats` para tu sistema.

[tests]: https://exercism.org/docs/tracks/bash/tests
[debugging]: https://exercism.org/docs/tracks/bash/debugging

## Pruebas omitidas

Resolver un ejercicio significa hacer que todas sus pruebas pasen.
De forma predeterminada, cuando ejecutas las pruebas solo se ejecuta una (la primera).
Esto es intencional, ya que te permite enfocarte solo en hacer que esa prueba pase.
Cuando pase, puedes habilitar la siguiente prueba al comentar o eliminar la siguiente anotación:

```bash
[[ $BATS_RUN_SKIPPED == true ]] || skip
```

## Anular las omisiones

Para ejecutar todas las pruebas, incluidas las que tienen anotaciones `skip`, puedes ejecutar:

```bash
BATS_RUN_SKIPPED=true bats exercise_name.bats
```

Puede ser conveniente usar una función envoltorio para escribir menos:

```bash
bats() {
    BATS_RUN_SKIPPED=true command bats *.bats
}
```

Luego ejecuta las pruebas solo con:

```bash
bats
```
