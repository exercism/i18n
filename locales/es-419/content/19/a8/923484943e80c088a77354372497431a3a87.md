# Introducción

## Arrays de bits

Trabajar con datos binarios puede ser complicado, así que Gleam ofrece un tipo `BitArray` y una sintaxis que lo acompaña para construir datos binarios y para hacer coincidencia de patrones sobre ellos.

Los literales de array de bits se definen con la sintaxis `<<>>`. Cuando defines un literal de array de bits, lo defines por segmentos. Cada segmento tiene un valor y una anotación, separados por `:`. La anotación especifica cuántos bits se usarán para codificar el valor y se puede omitir por completo, en cuyo caso se usa por defecto un valor entero de 8 bits.

```gleam
// This defines a bit array with three segments of a single bit each
<<0:1, 1:1, 0:1>>

// This defines a bit array with three segments of 8 bits each
<<0, 1, 0>>
```

Especificar el tipo como `:1` es una forma abreviada de escribir `:size(1)`. Necesitas usar la sintaxis larga si el tamaño en bits proviene de una variable.

```gleam
let segment_size = 1
<<0:size(segment_size), 1:size(segment_size), 0:size(segment_size)>>
```

### Binario

Al escribir literales de enteros binarios, podemos escribirlos directamente en notación base 2 anteponiendo `0b` al literal. Ten en cuenta que se mostrarán como números decimales cuando se impriman en las pruebas o en tu programa.

```gleam
<<0b1011:4>> == <<11:4>>
// -> True
```

### Truncamiento

Si el valor del segmento excede la capacidad del tipo del segmento, se truncará por la izquierda.

```gleam
<<0b1011:3>> == <<0b0011:3>>
// -> True
```

### Agregar al principio y al final

Puedes agregar tanto al principio como al final de un array de bits existente usando la sintaxis de arrays de bits. La anotación `:bits` debe usarse para el array de bits existente.

```gleam
let value = <<0b110:3, 0b001:3>>
let new_value = <<0b011:3, value:bits, 0b000:3>>
// -> <<120, 8:size(4)>>
```

### Concatenación

Podemos concatenar arrays de bits guardados en variables usando la sintaxis de arrays de bits. La anotación `:bits` debe usarse al concatenar dos arrays de bits de tamaño variable.

```gleam
let first = <<0b110:3>>
let second = <<0b001:3>>
let concatenated = <<first:bits, second:bits>>
// -> <<49:size(6)>>
```

### Coincidencia de patrones

También puedes hacer coincidencia de patrones para obtener valores del array de bits. Debes saber la cantidad de bits de cada segmento que quieras capturar, con una excepción: la anotación `:bits` se puede usar para hacer coincidencia de patrones sobre un array de bits de tamaño desconocido, pero solo se puede usar en el último segmento.

```gleam
let assert <<value:4, rest:bits>> = <<0b01101001:8>>
value == 0b0110
// -> True
```

### Inspeccionar arrays de bits

~~~~exercism/note
Los arrays de bits se pueden imprimir en un formato distinto del que se usó para crearlos. Esto suele causar confusión cuando se aprenden los arrays de bits.
~~~~

De forma predeterminada, los arrays de bits se muestran en segmentos de 8 bits (un byte), incluso si los creaste con segmentos de otro tamaño.

```gleam
<<2011:11>>
// -> <<251, 3:size(3)>>
```

Si creas un array de bits que representa un string imprimible codificado en UTF-8, puede mostrarse como un string por funciones como `io.debug`. Esto se debe a un detalle de implementación de cómo Gleam representa los strings internamente.

```gleam
<<>>
// -> ""

<<65, 66, 67>>
// -> "ABC"
```
