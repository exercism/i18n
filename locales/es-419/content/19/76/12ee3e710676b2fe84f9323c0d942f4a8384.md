# Consejos

## 1. Monitorea el nivel de humedad de la habitación

- Quizás quieras usar un [condicional if...else][if-else-condition] para verificar si el porcentaje de humedad es mayor que el valor máximo permitido.

## 2. Detecta el sobrecalentamiento

- Esta función debería ser muy similar a `checkHumidityLevel`. Quizás quieras consultar [cómo construir un objeto nuevo][class-constructor] a partir de una clase.

## 3. Monitorea la máquina

- Asegúrate de manejar todos los errores en el bloque catch; deberías tener 4 casos diferentes.
