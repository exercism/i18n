# Introducción

El modificador `const` puede aplicarse (y en general debería aplicarse) a cualquier campo cuyo valor se conozca en tiempo de compilación y no cambie durante la vida del programa.

```csharp
private const int num = 1729;
public const string title = "Grand" + " Master";
```

El modificador `readonly` puede aplicarse (y en general debería aplicarse) a cualquier campo que no pueda declararse como `const`, cuyo valor no cambie durante la vida del programa y que se establezca con un inicializador en línea o durante la instanciación (por el constructor o por un método llamado desde el constructor).

```csharp
private readonly int num;
private readonly System.Random rand = new System.Random();

public MyClass(int num)
{
    this.num = num;
}
```
