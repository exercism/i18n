# Introducción

El [Zen de Python][zen-of-python] afirma que debería haber «una manera _obvia_ de hacer algo en Python».
Para Python 3.6+, la [**interpolación de strings literales**][string-interpolation] ([**`f-string`s**][f-string]) suele ser la forma obvia y preferida de dar formato a strings:

```python
>>> adjective = "easy"
>>> f"This is an {adjective} way to format strings!"
'This is an easy way to format strings!'
```

Sin embargo, dada la larga historia de Python y sus distintos casos de uso, no sorprende que haya **tres** formas comunes más de dar formato a strings en Python:

1. [`str.format()`][str-format] es versátil, muy potente y compatible tanto con [`gnu gettext`][gettext] como con la mayoría de las versiones de Python.
2. Si lo que necesitas es simplicidad, seguridad o mucha internacionalización, puedes usar [`string.Template()`][string-template] para mitigar riesgos cuando hay que manejar entradas y para envolver strings de traducción.
3. El operador `%` generalmente se considera obsoleto para código nuevo, aunque todavía funciona en Python moderno.
  Se debería usar sobre todo por compatibilidad con bases de código antiguas.
  El formateo con `%` puede causar problemas al mostrar caracteres no ASCII y Unicode, y tiene más errores y menos funcionalidad que otros métodos.
  Si piensas usarlo, consulta los detalles de compatibilidad de tu distribución específica de Python.

Si quieres ir más allá, [todo sobre el formateo][all-about-formatting] y [Buenas prácticas para dar formato a strings en Python][formatting-best-practices] son buenos puntos de partida.
