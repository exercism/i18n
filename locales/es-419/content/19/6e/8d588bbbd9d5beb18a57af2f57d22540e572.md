# Anexo de instrucciones

## Registros

| Registro | Uso      | Tipo       | Descripción                       |
| -------- | -------- | ---------- | --------------------------------- |
| `$a0`    | entrada  | dirección  | primer string terminado en nulo   |
| `$a1`    | entrada  | dirección  | segundo string terminado en nulo  |
| `$v0`    | salida   | entero     | distancia de Hamming              |
| `$t0-9`  | temporal | cualquiera | para almacenamiento temporal      |
