# Introducción

El operador condicional ternario se usa para escribir una expresión condensada que devuelve uno de dos valores alternativos según alguna condición.
A menudo se le llama «operador ternario».
Su nombre viene de que el operador tiene tres operandos: `predicate ? consequent-expression : alternative-expression`
Se puede usar como reemplazo de sentencias if-else cortas.

Al igual que las sentencias `if`, JavaScript realiza una conversión implícita de tipos para evaluar la condición.
Si la condición se evalúa como verdadera, se devolverá el operando que está a la izquierda de los dos puntos.
De lo contrario, el resultado de la expresión ternaria es el operando que está a la derecha de los dos puntos.

```javascript
const year = 2020;

year > 2000 ? 'in the past years' : 'a long time ago';
// => 'in the past years'
```
