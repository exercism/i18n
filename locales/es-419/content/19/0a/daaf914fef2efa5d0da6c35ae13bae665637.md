## Cómo hacer debug

A diferencia de muchos lenguajes, el código de WebAssembly no tiene acceso automático a recursos globales como la consola. Esa funcionalidad, en cambio, se debe proporcionar como imports.

Para ofrecer una funcionalidad similar a `console.log` y algunas otras comodidades, el track de WebAssembly de Exercism expone una biblioteca estándar de funciones en todos los ejercicios.

Estas funciones se deben importar al inicio de tu módulo de WebAssembly y luego se pueden llamar desde tu código de WebAssembly.

Las funciones `log_mem_*` esperan poder acceder a la memoria lineal de tu módulo de WebAssembly. De forma predeterminada, este es un estado privado, así que para que sea accesible, debes exportar tu memoria lineal con el nombre de exportación `mem`. Esto se logra de la siguiente manera:

```wasm
(memory (export "mem") 1)
```

## Registrar variables locales y globales

Proporcionamos funciones de registro para cada uno de los tipos primitivos de WebAssembly. Esto es útil para registrar variables globales y locales.

### log_i32_s - Registra un entero de 32 bits con signo en la consola

```wasm
(module
  (import "console" "log_i32_s" (func $log_i32_s (param i32)))
  (func $main
    ;; logs -1
    (call $log_i32_s (i32.const -1))
  )
)
```

## Registrar desde la memoria lineal

La memoria lineal de WebAssembly es un array de valores direccionable por bytes. Sirve como el equivalente de la memoria virtual para los programas de WebAssembly

Proporcionamos funciones de registro para interpretar un rango de direcciones dentro de la memoria lineal como arrays estáticos de ciertos tipos. Esto funciona de manera similar a los TypedArrays de JavaScript. Los parámetros de longitud no se miden en bytes. Se miden en la cantidad de elementos consecutivos del tipo asociado con la función.

**Para que estas funciones funcionen, tu módulo de WebAssembly debe declarar y exportar su memoria lineal usando el nombre de exportación «mem»**

```wasm
(memory (export "mem") 1)
```

### log_mem_as_utf8 - Registra una secuencia de caracteres UTF8 en la consola

```wasm
(module
  (import "console" "log_mem_as_utf8" (func $log_mem_as_utf8 (param $byteOffset i32) (param $length i32)))
  (memory (export "mem") 1)
  (data (i32.const 64) "Goodbye, Mars!")
  (func $main
    ;; Logs "Goodbye, Mars!" to console
    (call $log_mem_as_utf8 (i32.const 64) (i32.const 14))
  )
)
```

### log_mem_as_i8 - Registra una secuencia de enteros de 8 bits con signo en la consola

```wasm
(module
  (import "console" "log_mem_as_i8" (func $log_mem_as_i8 (param $byteOffset i32) (param $length i32)))
  (memory (export "mem") 1)
  (func $main
    (memory.fill (i32.const 128) (i32.const -42) (i32.const 10))
    ;; Logs an array of 10x -42 to console
    (call $log_mem_as_u8 (i32.const 128) (i32.const 10))
  )
)
```
