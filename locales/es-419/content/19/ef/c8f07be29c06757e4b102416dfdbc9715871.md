# Instrucciones

En este ejercicio vas a procesar líneas de registro.

Cada línea de registro es un string con el siguiente formato: `"[<LEVEL>]: <MESSAGE>"`.

Hay tres niveles de registro diferentes:

- `INFO`
- `WARNING`
- `ERROR`

Tienes tres tareas, cada una de las cuales tomará una línea de registro y te pedirá que hagas algo con ella.
Hay muchas maneras de resolver estas tareas. Elige tus métodos favoritos de los ejemplos anteriores y mira qué se te ocurre.

## 1. Obtener el mensaje de una línea de registro

Implementa el método `LogLineParser#message` para devolver el mensaje de una línea de registro:

```ruby
LogLineParser.new('[ERROR]: Invalid operation').message
# => "Invalid operation"
```

Se debe eliminar cualquier espacio en blanco al principio o al final:

```ruby
LogLineParser.new("[WARNING]:  Disk almost full\r\n").message
# => "Disk almost full"
```

## 2. Obtener el nivel de registro de una línea de registro

Implementa el método `LogLineParser#log_level` para devolver el nivel de registro de una línea de registro, que se debe devolver en minúsculas:

```ruby
LogLineParser.new('[ERROR]: Invalid operation').log_level
# => "error"
```

## 3. Reformatear una línea de registro

Implementa el método `LogLineParser#reformat` que reformatea la línea de registro, poniendo el mensaje primero y el nivel de registro después, entre paréntesis:

```ruby
LogLineParser.new('[INFO]: Operation completed').reformat
# => "Operation completed (info)"
```
