# Acerca de

En Swift, un `String` es una colección ordenada de valores `Character` que representan texto legible para las personas. Los strings de Swift son totalmente compatibles con los caracteres Unicode y los emojis.

Creas un string con un literal de string, encerrando el texto entre comillas dobles (`"`).
Los caracteres especiales usan secuencias de escape, por ejemplo, `\n` representa un salto de línea y `\"` representa una comilla doble escapada dentro de un literal de string.

Un string vacío se escribe como un par de comillas dobles sin nada entre ellas (`""`).

```swift
let hello = "Hello, World!"
let sausage = "Weißwurst is a tasty sausage."
var family = "This is my family: 👨‍👩‍👦‍👦, this is our dog: 🐶"
var empty = ""
```
