# Test runners

Un Test Runner es un programa que ejecuta las pruebas de un ejercicio contra el código de un estudiante.

Los Test Runners nos dan dos ventajas:

1. Habilitan la programación en el navegador, donde un estudiante puede iterar sobre una solución y ver si las pruebas pasan o fallan.
2. Nos permiten darles información a los mentores sobre si el código de un estudiante «funciona» o no.

## Cómo crear un Test Runner

Si te interesa crear un Test Runner, consulta la [documentación sobre los Test Runners](/docs/building/tooling/test-runners) para obtener más información.
