# Introducción

Además de la sentencia condicional `if`, también existe la sentencia `switch` para ejecutar lógica de forma condicional. Se usa cuando hay que comparar una sola variable con varias variantes. Para cierta variable x, la sentencia switch en Haxe tiene la siguiente sintaxis.

```haxe
var a = 2;

switch (a) {
  case 0:
    trace("a is 0");
  case 1:
    trace("a is 1");
  case 2:
    trace("a is 2");
  default:
    trace("a is something else");
}

// a is 2
```

El caso `default` se ejecuta cuando ningún otro caso coincide.
