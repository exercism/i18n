# Introducción

Un archivo no es más que un flujo con un nombre en el disco. El vocabulario [`io.files`][io.files] te da dos formas de trabajar con un archivo: palabras de conveniencia que leen o escriben todo el archivo de una sola vez, y formas de abrir un flujo para cuando quieres leer o escribir de forma incremental.

Toda palabra que toca un archivo recibe una **codificación**: el esquema que convierte bytes en caracteres y viceversa. Para texto, casi siempre es [`utf8`][utf8] de `io.encodings.utf8`.

## Leer un archivo completo

```
file-contents   ( path encoding -- str )
file-lines      ( path encoding -- seq )
```

`file-contents` devuelve el archivo completo como un solo string; `file-lines` devuelve un array con sus líneas, sin los saltos de línea.

```factor
USING: io.encodings.utf8 io.files prettyprint ;

"sunny\ncloudy\n" "forecast.txt" utf8 set-file-contents

"forecast.txt" utf8 file-contents .
! => "sunny\ncloudy\n"

"forecast.txt" utf8 file-lines .
! => { "sunny" "cloudy" }
```

## Escribir un archivo completo

```
set-file-contents   ( str path encoding -- )
set-file-lines      ( seq path encoding -- )
```

Ambas **reemplazan** el contenido del archivo (y lo crean si hace falta). `set-file-contents` escribe un string tal cual; `set-file-lines` escribe cada elemento de una secuencia en su propia línea y agrega los saltos de línea por ti.

```factor
USING: io.encodings.utf8 io.files prettyprint ;

{ "sunny" "cloudy" } "forecast.txt" utf8 set-file-lines
"forecast.txt" utf8 file-contents .
! => "sunny\ncloudy\n"
```

## Agregar contenido a un archivo

Para agregar contenido a un archivo sin borrar lo que ya está ahí, ábrelo con un combinador `with-…` y escribe en el flujo ambiente dentro de la quotation:

```
with-file-appender   ( path encoding quot -- )
with-file-reader     ( path encoding quot -- )
with-file-writer     ( path encoding quot -- )
```

```factor
USING: io io.encodings.utf8 io.files prettyprint ;

"sunny\ncloudy\n" "forecast.txt" utf8 set-file-contents
"forecast.txt" utf8 [ "rainy" print ] with-file-appender
"forecast.txt" utf8 file-contents .
! => "sunny\ncloudy\nrainy\n"
```

Como todo combinador `with-…`, estos son ámbitos de destructor: el manejador de archivo se cierra cuando termina la quotation, incluso si lanza una excepción.
