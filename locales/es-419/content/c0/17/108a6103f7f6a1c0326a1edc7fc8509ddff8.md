# Pistas

## General

- Este desafío se trata de crear una [_pila_][Baeldung: The Stack Data Structure] usando una [lista enlazada simple][singly linked list].
- A diferencia de las pilas construidas con `lists`, `collections.deque` o `queue.LifoQueue`, te pedimos que crees tus propias [`classes`][classes tutorial] `Node` y `LinkedList` para almacenar y enlazar elementos.

![Diagrama que representa una pila implementada con una lista enlazada. Un círculo con borde discontinuo llamado New_Node está en el extremo más a la izquierda, con dos líneas de flecha punteadas que apuntan hacia la derecha. New_Node dice «(becomes head) - New_Node - next = node_6». La línea de flecha punteada superior está etiquetada como «push» y apunta a Node_6, arriba y a la derecha. Node_6 dice «(current) head - Node_6 - next = node_5». La línea de flecha punteada inferior está etiquetada como «pop» y apunta a un recuadro que dice «gets removed on pop()». Node_6 tiene una flecha sólida que apunta hacia la derecha a Node_5, que dice «Node_5 - next = node_4». Node_5 tiene una flecha sólida que apunta hacia la derecha a Node_4, que dice «Node_4 - next = node_3». Este patrón continúa hasta Node_1, que dice «(current) tail - Node_1 - next = None». Node_1 tiene una flecha punteada que apunta hacia la derecha a un nodo que dice «None».](https://assets.exercism.org/images/tracks/python/simple-linked-list/linked-list.svg)

- [Real Python: Listas enlazadas][Real Python Linked Lists], [Towards Data Science: Desmitificando la lista enlazada][towards data science demystifying the linked list] y [Pila ADS en Python][Koder Dojo Coding an ADS Stack in Python] pueden ser útiles para repasar los detalles de la implementación.
- Tu `LinkedList` debe aceptar un argumento `list` en su _constructor_, pero no debe usar una `list` para almacenar nodos ni elementos.
- `len()` es una función integrada para la mayoría de los objetos de Python.
  Para que los _objetos personalizados_ admitan `len()`, se debe definir el método especial [`__len__`][__len__].
- La iteración en Python es compatible con la mayoría de los objetos de tipo secuencia, contenedor o colección.
  Para que un objeto _personalizado_ admita bucles o reordenamientos, se debe definir el método especial `__iter__`.
  [Implementar un iterador para una clase][implementing iterators] puede ayudarte a ver cómo hacerlo.
