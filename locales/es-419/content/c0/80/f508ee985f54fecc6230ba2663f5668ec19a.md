# Pistas

## General

- Revisa la [documentación de `elm/parser`][elm-parser]
- La introducción presenta todos los conceptos necesarios para resolver el ejercicio

## 1. Analiza el precio de la pizza

- El [parser `int`][int] está dedicado a analizar números enteros
- Más de un parser puede manejar el €, pero [`symbol`][symbol] es el más adecuado
- El [operador `(|.)`][(|.)] puede analizar dos cosas pero conservar solo una

## 2. Analiza el indicador de vegetariano

- El [parser `oneOf`][oneOf] puede probar diferentes posibilidades
- Hay más de una forma de analizar un string específico; en este caso, [`keyword`][keyword] o [`symbol`][symbol] son adecuados
- Hay más de una forma de devolver `True` si un parser tiene éxito; una buena es usar [`succeed`][succeed]

## 3. Analiza los nombres de la pizza y de los ingredientes

- El [parser `chompWhile`][chompWhile] está dedicado a analizar caracteres arbitrarios
- La [función `isAlpha`][isAlpha] puede validar caracteres ASCII en mayúsculas y minúsculas
- La [función `map`][map] se puede usar para modificar el contenido de un parser
- La [función `String.toLower`][toLower] puede convertir un string a minúsculas

## 4. Analiza una lista de ingredientes

- El [parser `sequence`][sequence] está dedicado a analizar listas de elementos
- Usa todas las funciones adecuadas que definiste hasta ahora

## 5. Analiza una pizza completa

- Con el [operador `(|=)`][(|=)] es bastante simple conservar más de una cosa en una pipeline
- Usa `Pizza` como constructor de tipo con [`succeed`][succeed]
- Más de un parser puede manejar «:» y «-», pero [`symbol`][symbol] es el más adecuado
- El [parser `spaces`][spaces] es útil para deshacerte de los espacios adicionales
- Usa todas las funciones adecuadas que definiste hasta ahora

## 6. Analiza el menú completo

- El [parser `sequence`][sequence] está dedicado a analizar listas de elementos
- Recuerda que `spaces` también consume caracteres de salto de línea; esto podría interferir con tu separador
- El [parser `end`][end] está dedicado a comprobar que llegaste al final de un string
- El [operador `(|.)`][(|.)] puede analizar dos cosas pero conservar solo una
- Usa todas las funciones adecuadas que definiste hasta ahora

## 7. Analiza nombres de ingredientes de varias palabras

- El [parser `chompWhile`][chompWhile] está dedicado a analizar caracteres arbitrarios
- La [función `isAlpha`][isAlpha] puede validar caracteres ASCII en mayúsculas y minúsculas
- La [función `andThen`][andThen] se puede usar para inspeccionar el contenido de un parser
- La [función `problem`][problem] devuelve un parser que llegó a un callejón sin salida
- La [función `String.toLower`][toLower] puede convertir un string a minúsculas
- La [función `String.trim`][trim] puede deshacerse de los espacios en blanco en los bordes de un string
