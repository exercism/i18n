# Introducción

Cada instancia de un struct o una clase tiene una propiedad implícita llamada `self`, que se refiere a la instancia misma.
El uso más común de `self` es distinguir entre una propiedad de la instancia y un parámetro que tiene el mismo nombre:

```swift
struct Position {
    var x = 0

    mutating func move(x: Int) {
        // Here, 'self.x' refers to the struct's property,
        // while 'x' refers to the parameter passed to the method.
        self.x = x
    }
}
```

Los tipos de Swift también ofrecen la palabra clave `Self` con inicial mayúscula, que se refiere al *tipo* de la instancia en lugar de a la instancia misma.
