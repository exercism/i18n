# Tests

## Clojure CLI

Los ejercicios de Clojure en Exercism vienen con un archivo `deps.edn` que incluye un alias `:test` para invocar el [cognitect-labs test-runner](https://github.com/cognitect-labs/test-runner):

``` bash
$ clj -X:test
```

Esto buscará en el directorio `test` de tu proyecto todos los tests definidos con `clojure.test` y los ejecutará.

## Leiningen

Para ejecutar los tests de un ejercicio con Leiningen, simplemente escribe:

``` bash
$ lein test

lein test bob-test

Ran 14 tests containing 14 assertions.
0 failures, 0 errors.
```
