# Introducción

Cairo proporciona diccionarios como parte de sus bibliotecas principales, representados por el tipo `Felt252Dict<T>`.

El tipo de las claves de un diccionario en Cairo está restringido a `felt252`, algo que difiere de otros lenguajes en los que sí es posible definir el tipo de la clave.

Para crear un diccionario, puedes usar el método `default` del trait `Default`, así:

```rust
let mut foo: Felt252Dict<u32> = Default::default();
```

Las operaciones básicas que se usan con más frecuencia son:

1. `insert(felt252, T) -> ()` para escribir valores en una instancia de diccionario y
2. `get(felt252) -> T` para leer valores de ella.

Y así es como usarías estas operaciones:

```rust
let mut foo: Felt252Dict<u32> = Default::default();
// Add a value to the dictionariy
foo.insert('bar', 42);
// Here we update the element of 'bar'
foo.insert('bar', 73);
// To retrieve a dictionary value, you can use
baz = foo.get('bar');
```

Si intentas obtener el valor de una clave que no existe en el diccionario, se devolverá el valor cero del tipo del valor.

Esto puede confundirte, sobre todo si el valor predeterminado de tu tipo de valor (por ejemplo, 0 para un entero) es un valor válido.

Esto también significa que no hay forma de eliminar datos de un diccionario.

Algo que debes tener en cuenta cuando incorpores esta estructura a tu código.
