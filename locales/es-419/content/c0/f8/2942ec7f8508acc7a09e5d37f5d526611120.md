# Instrucciones adicionales

## Manejo de errores

Para este ejercicio debes agregar un conjunto de errores `ComputationError` que contenga el error `IllegalArgument`.
¡Recuerda hacerlo público!
La función `steps` debe devolver `ComputationError.IllegalArgument` cuando su argumento sea igual a cero.

Los ejercicios posteriores normalmente omitirán instrucciones explícitas como esta.
En general, Exercism espera que leas el archivo de test cuando implementes tu solución.
