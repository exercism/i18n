# Pistas

## General

- Las [tuplas][tuple] son estructuras de datos que son inmutables, tienen un tamaño fijo y pueden contener cualquier tipo de datos.
- Los símbolos se pueden usar para denotar estados finitos: este ejercicio usa `:cup`, `:fluid_ounce`, `:teaspoon`, `:tablespoon`, `:milliliter` para denotar las unidades utilizadas.

## 1. Obtén el componente numérico de un par de volumen

- Considera indexar la tupla para devolver el componente numérico del par de volumen.

## 2. Convierte el par de volumen a mililitros

- Usa lógica de flujo de control para determinar qué lógica aplicar según la unidad.
- Implementa el método para convertir de todas las unidades a mililitros, incluyendo de mililitros a mililitros.

## 3. Convierte el par de volumen de mililitros a otra unidad

- Usa lógica de flujo de control para determinar qué lógica aplicar según la unidad.
- Implementa el método para convertir de mililitros a todas las unidades, incluyendo de mililitros a mililitros.

## 4. Convierte de cualquier unidad a cualquier unidad
