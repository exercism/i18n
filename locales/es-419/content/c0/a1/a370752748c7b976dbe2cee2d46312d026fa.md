# Acerca de

Ceylon es un lenguaje de programación de propósito general con una sintaxis similar a la de Java y C#.
Es imperativo, de tipado estático, estructurado en bloques, orientado a objetos y de orden superior.
Por _tipado estático_ queremos decir que el compilador realiza una comprobación de tipos exhaustiva,
con la ayuda de las anotaciones de tipo que aparecen en el código. Por _orientado a objetos_ queremos
decir que el lenguaje admite tipos definidos por quien programa y cuenta con un sistema de tipos
nominativo, donde un tipo es un conjunto de atributos y operaciones con nombre, y que admite la
herencia y el polimorfismo de subtipos. Por _de orden superior_ queremos decir que cada elemento
referenciable de un programa (cada atributo, cada operación y cada tipo) también es un valor. Por
_estructurado en bloques_ queremos decir que el lenguaje cuenta con ámbito léxico y una sintaxis
recursiva sumamente regular para las declaraciones y las sentencias.

Ceylon mejora el lenguaje y el sistema de tipos de Java para reducir la verbosidad y aumentar la
seguridad de tipos en comparación con Java y C#. Ceylon fomenta un estilo de programación más
funcional y algo menos imperativo, lo que da como resultado un código más fácil de razonar y de
refactorizar.
