# Apéndice de instrucciones

## Formato de salida

Devuelve las plantas del estudiante como un string terminado en nulo, usando una coma y un espacio como separadores.

## Registros

| Registro | Uso          | Tipo    | Descripción                      |
| -------- | ------------ | ------- | -------------------------------- |
| `$a0`    | entrada      | dirección | diagrama del jardín             |
| `$a1`    | entrada      | dirección | nombre del estudiante           |
| `$a2`    | entrada/salida | dirección | string de salida terminado en nulo |
| `$t0-9`  | temporal     | cualquiera | se usa para almacenamiento temporal |
