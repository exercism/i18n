# Instrucciones

En este ejercicio vas a analizar números de teléfono.

Debes implementar 2 funcionalidades.

Se garantiza que los números de teléfono que se pasan a las rutinas tienen el formato
NNN-NNN-NNNN, por ejemplo 212-515-9876, y que no son nulos.

## 1. Analiza un número de teléfono

Tu análisis debe devolver 3 datos:

1. Una indicación de si el número tiene un código de marcado de Nueva York, es decir, 212 como los primeros 3 dígitos
2. Una indicación de si el número es falso por tener 555 como código de prefijo en las posiciones 5 a 7 (contando desde 1)
3. Los últimos 4 dígitos del número.

Implementa el método (estático) `PhoneNumber.Analyze()` para producir la información del número de teléfono.

```csharp
PhoneNumber.Analyze("631-555-1234");
// => (false, true, "1234")
```

## 2. Detecta si un número de teléfono tiene un código de prefijo falso (555)

Implementa el método (estático) `PhoneNumber.IsFake()` para detectar si el número de teléfono es falso usando la información del número de teléfono producida en la tarea 1.

```csharp
PhoneNumber.IsFake(PhoneNumbers.Analyze("631-555-1234"));
// => true
```
