# Introducción

El concepto Pairs and Dicts trató los fundamentos del tipo diccionario de Julia.

Como los `Dict` son un tipo de colección importante y de uso frecuente, también existen muchas funciones para manipularlos.

## Obtener entradas

La forma más sencilla de obtener una entrada es por su clave (como en muchos lenguajes).
Sin embargo, pedir una clave que no existe produce un `KeyError`.

```julia-repl
julia> d = Dict(i => ('a':'c')[i] for i in 1:3)
Dict{Int64, Char} with 3 entries:
  2 => 'b'
  3 => 'c'
  1 => 'a'
julia> d[2]
'b': ASCII/Unicode U+0062 (category Ll: Letter, lowercase)
# missing key
julia> d[4]
ERROR: KeyError: key 4 not found
```

Podríamos comprobar si la clave existe antes de intentar obtenerla (con algo como `haskey(d, 4)`), pero puede ser útil obtener directamente un valor predeterminado para las claves que faltan.

Para eso tenemos la función `get()` y su variante mutadora `get!()`.
La diferencia entre ambas está en si una clave «faltante» se agrega o no al `Dict`.

```julia-repl
julia> get(d, 4, '!')
'!': ASCII/Unicode U+0021 (category Po: Punctuation, other)
# get() leaves Dict unchanged
julia> d
Dict{Int64, Char} with 3 entries:
  2 => 'b'
  3 => 'c'
  1 => 'a'
julia> get!(d, 4, '!')
'!': ASCII/Unicode U+0021 (category Po: Punctuation, other)
# get!() adds new key to Dict
julia> d
Dict{Int64, Char} with 4 entries:
  4 => '!'
  2 => 'b'
  3 => 'c'
  1 => 'a'
```

En el concepto anterior vimos que `delete!()` elimina una entrada por su clave.
Esto se puede combinar con la obtención del valor usando la función `pop!()`.

```julia-repl
julia> d
Dict{Int64, Char} with 4 entries:
  4 => '!'
  2 => 'b'
  3 => 'c'
  1 => 'a'
# popped value is returned
julia> pop!(d, 3)
'c': ASCII/Unicode U+0063 (category Ll: Letter, lowercase)
# Dict is shrunk
julia> d
Dict{Int64, Char} with 3 entries:
  4 => '!'
  2 => 'b'
  1 => 'a'
```

## Iteración

Al iterar sobre un `Dict`, lo que se obtiene por defecto son pares `key => value`.
Se puede acceder a sus componentes con la nomenclatura habitual `.first` y `.second`.

```julia-repl
# d is from the previous example
julia> [(kv.first, kv.second) for kv in d]
3-element Vector{Tuple{Int64, Char}}:
 (4, '!')
 (2, 'b')
 (1, 'a')
```

A menudo queremos usar solo las claves o solo los valores, y eso es fácil.

```juliajulia> [k for k in keys(d)]
julia> [k for k in keys(d)]
3-element Vector{Int64}:
 4
 2
 1
julia> [v for v in values(d)]
3-element Vector{Char}:
 '!': ASCII/Unicode U+0021 (category Po: Punctuation, other)
 'b': ASCII/Unicode U+0062 (category Ll: Letter, lowercase)
 'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)
```

## Fusión

Fusionar dos `Dict` puede ser útil, pero debemos tener claro qué queremos hacer con las claves que aparecen en más de una entrada.

Las funciones `merge()` y `merge!()` fusionan una cantidad arbitraria de `Dict` de izquierda a derecha.

Los valores de las claves que ya existen simplemente se sobrescriben, así que el `Dict` que está más a la derecha «gana».

```julia-repl
julia> d3 = Dict("color" => "red", "shape" => "circle")
Dict{String, String} with 2 entries:
  "shape" => "circle"
  "color" => "red"
julia> d4 = Dict("color" => "blue", "coords" => (3, 2))
Dict{String, Any} with 2 entries:
  "color"  => "blue"
  "coords" => (3, 2)
# color from d3 is lost
julia> merge(d3, d4)
Dict{String, Any} with 3 entries:
  "shape"  => "circle"
  "color"  => "blue"
  "coords" => (3, 2)
```

Las funciones `mergewith()` y `mergewith!()` nos permiten pasar una función como primer argumento para definir cómo se deben fusionar las claves repetidas.
La suma es un ejemplo sencillo.

```julia-repl
julia> d5 = Dict("color" => "red", "area" => 3)
Dict{String, Any} with 2 entries:
  "area"  => 3
  "color" => "red"
julia> d6 = Dict("shape" => "circle", "area" => 5)
Dict{String, Any} with 2 entries:
  "shape" => "circle"
  "area"  => 5
# area values are added, not overwritten
julia> mergewith(+, d5, d6)
Dict{String, Any} with 3 entries:
  "shape" => "circle"
  "area"  => 8
  "color" => "red"
```

Ten en cuenta que las funciones `mergewith` son un buen ejemplo de funciones de orden superior en acción.
