# Anexo a las instrucciones

Cada fila de la cuadrícula se representa como una palabra.

Por ejemplo,

```
    0 1 0
    1 0 0
    1 1 0
```

se representa como

```
0x2
0x4
0x6
```

La cuadrícula tiene como máximo 32 columnas.

## Registros

| Registro | Uso          | Tipo    | Descripción                         |
| -------- | ------------ | ------- | ----------------------------------- |
| `$a0`    | entrada      | entero  | número de filas                     |
| `$a1`    | entrada      | entero  | número de columnas                  |
| `$a2`    | entrada      | dirección | cuadrícula para la generación actual |
| `$a3`    | entrada/salida | dirección | cuadrícula para la siguiente generación |
| `$t0-9`  | temporal     | cualquiera | se usa para almacenamiento temporal |
