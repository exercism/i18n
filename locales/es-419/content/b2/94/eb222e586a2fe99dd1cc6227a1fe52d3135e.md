# Instrucciones

Un gran huerto de cerezos suele tener un pequeño inventario de árboles sobrantes que le gustaría ofrecer como madera. Esto ayuda a mantener el huerto saludable y, al mismo tiempo, genera ingresos extra. Te han pedido que ayudes a programar algunas funcionalidades para el proceso de selección de árboles cuando llama un posible cliente.

~~~~exercism/note
La biblioteca [`datasets`][ref-datasets] integrada tiene muchos conjuntos de datos de juguete, y este ejercicio usa el conjunto de datos `trees`.
Para llamar al conjunto de datos, simplemente usa el nombre `trees`.
```R
library(datasets) # loading is optional

trees |> head(3)
#>    A data.frame: 3 × 3 	
#>   Girth	Height	Volume
#>	 <dbl>	 <dbl>	 <dbl>
#> 1   8.3	    70	  10.3  
#> 2   8.6	    65	  10.3
#> 3   8.8	    63	  10.2
```
Fíjate en las tres columnas: `Girth`, `Height` y `Volume`.

El conjunto de datos está inicialmente en forma de `data.frame`, pero quizás quieras trabajar con él como un `tibble`.

[ref-datasets]: https://stat.ethz.ch/R-manual/R-devel/library/datasets/html/00Index.html
~~~~

## 1. Renombra una columna

Lamentablemente hubo un error administrativo que nunca se corrigió, y una columna del conjunto de datos se llama `Girth`, pero en realidad es el `Diameter`.

Define un data.frame/tibble llamado `tree_data` que corrija el nombre de la columna `Girth` en `trees` a `Diameter`.

```R
head(tree_data, 3)
#>     A tibble: 3 × 3 
#> Diameter	 Height	Volume
#>    <dbl>	  <dbl>	 <dbl>
#>      8.3	     70	  10.3
#>      8.6	     65	  10.3
#>      8.8	     63	  10.2
```

## 2. Agrega las columnas Girth y Weight

La circunferencia sigue siendo una medida útil, y el peso de la madera también.
La circunferencia se calcula fácilmente con `πD`, donde `D` es el diámetro.
El peso de toda la madera se puede calcular con `ρV`, donde `ρ = 35` es la densidad de la madera de cerezo y `V` es el volumen de la madera.

Define la función `girth_n_weight(data, rnd_digits)`, que toma un dataframe y argumentos numéricos.
La función debe devolver un nuevo dataframe con las dos columnas adicionales: `Girth` y `Weight`, redondeadas al número de dígitos que indique `rnd_digits`.

```R
girth_n_weight(tree_data, 1) |> head(3)
#>           A tibble: 3 × 5 
#> Diameter  Height	 Volume	 Girth	Weight
#>    <dbl>	  <dbl>	  <dbl>	 <dbl>	 <dbl>
#>      8.3	     70	   10.3	  26.1	 360.5
#>      8.6	     65	   10.3	  27.0	 360.5
#>      8.8	     63	   10.2	  27.6	 357.0
```

## 3. Copia del conjunto de datos para el huerto

Para cada posible cliente, el huerto guarda una copia especial del conjunto de datos que ayuda con la venta.
Este conjunto de datos tiene las columnas más relevantes, `Weight` y `Height`, movidas al frente y está ordenado por `Weight`.

Define la función `orchard_copy(data, important_cols)`, que toma un dataframe como argumento.
Debe devolver un nuevo dataframe con `Weight` y `Height` al frente y las filas ordenadas por `Weight`.

```R
tree_data |> girth_n_weight() |> orchard_copy() |> head(3)
#>            A tibble: 3 × 5 
#> Weight	Height	Diameter	Volume	Girth
#>  <dbl>	 <dbl>	   <dbl>	 <dbl>	<dbl>
#>    357	    63	       9	    10	   28
#>    360	    70	       8	    10	   26
#>    360	    65	       9	    10	   27
```

## 4. Copia del conjunto de datos para el cliente

Cada posible cliente recibirá una versión personal del conjunto de datos según sus preferencias.
Para eso, el cliente puede especificar: la altura mínima, la altura máxima y el peso máximo de un solo árbol.

Define la función `customer_copy(data, min_height, max_height, max_weight)`.
Devuelve una copia del dataframe para el cliente con las columnas `Height`, `Weight`, `Diameter` y `Girth`, con las filas que estén dentro de las restricciones.

```R
tree_data |> 
    girth_n_weight(1) |> 
    orchard_copy() |>
    customer_copy(65, 75, 1500) |> 
    head(3)
#>        A tibble: 3 × 4 
#> Height	Weight	Diameter	Girth
#>  <dbl>	 <dbl>	   <dbl>	<dbl>
#>     70	 360.5	     8.3	 26.1
#>     65	 360.5	     8.6	 27.0
#>     66	 546.0	    11.0	 34.6
```
