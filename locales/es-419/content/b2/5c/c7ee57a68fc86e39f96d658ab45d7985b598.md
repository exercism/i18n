# Pruebas

Todos los ejercicios usan el framework [Pester][pester] para el mocking y las pruebas.
Todas las pruebas estarán en un archivo llamado `[Exercise].tests.ps1`, que es el estándar del framework Pester.
Si estás en el directorio correcto (es decir, el que contiene `[Exercise].ps1` y `[Exercise].tests.ps1`).
Puedes ejecutar las pruebas desde PowerShell llamando a:

``` PowerShell
Invoke-Pester
```

Esto ejecutará todos los archivos `.tests.ps1` que encuentre en el directorio.

Si usas otro shell que no sea PowerShell, puedes ejecutar las pruebas llamando a:

``` PowerShell
pwsh -Command "Invoke-Pester"
```

## Cómo ejecutar las pruebas en Visual Studio Code

Debes asegurarte de tener instalada [la extensión de PowerShell][extension] en Visual Studio Code.

Puedes ejecutar las pruebas en Visual Studio Code de varias maneras:

- Ejecutar el script `.Tests.ps1` desde el menú Debug. Los atajos de teclado son: `F5` o `Shift + F5`
- Desde el propio editor, haciendo clic en el enlace «Run Tests» que está arriba de la palabra clave `Describe` en el código de la prueba
- Configurar una Task para ejecutar el framework Pester

[pester]: https://github.com/pester/Pester
[extension]: https://marketplace.visualstudio.com/items?itemName=ms-vscode.PowerShell
