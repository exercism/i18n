# Acerca de

En Swift, no puedes indexar un string usando un número entero (como `string[3]`).
Como los strings de Swift están formados por caracteres Unicode de longitud variable, para encontrar un carácter hay que recorrer los caracteres anteriores.

Para acceder a un carácter en una posición específica, debes calcular un índice de tipo `String.Index`.
Estos índices se llaman *índices opacos* porque Swift administra su estructura interna en lugar de que tú la manipules directamente como números enteros sin procesar:

```swift
let csv = "apple,pear,peach,orange,cherry,lime,gooseberry"
let index = csv.index(csv.startIndex, offsetBy: 21)
print(csv[index])
// Prints "g"

print(index)
// Prints internal representation: Index(_rawBits: ...)
```
