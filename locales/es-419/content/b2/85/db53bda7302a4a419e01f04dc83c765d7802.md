# Instrucciones

En este ejercicio vamos a simular el primer turno de una partida de [Blackjack][blackjack].

## 1. Calcula el valor de cualquier carta.

Recibirás dos cartas y podrás ver la carta boca arriba del crupier. Todas las cartas se representan con un string como «ace», «king», «three», «two», etc. Los valores de cada carta son:

| carta | valor |  carta  | valor |
| :---: | :---: | :-----: | :---: |
|  ace  |  11   |  eight  |   8   |
|  two  |   2   |  nine   |   9   |
| three |   3   |   ten   |  10   |
| four  |   4   |  jack   |  10   |
| five  |   5   |  queen  |  10   |
|  six  |   6   |  king   |  10   |
| seven |   7   | _other_ |   0   |

~~~~exercism/note
Comúnmente, los ases pueden tomar el valor de 1 o 11, pero por simplicidad asumiremos que solo pueden tomar el valor de 11.
~~~~

Implementa el método `Blackjack.parse_card`, que recibe una carta como argumento, en forma de string.
El método debe devolver el valor de la carta como un número entero.

```ruby
Blackjack.parse_card("ace")
# => 11
```

## 2. Nombra rangos de valores.

El puntaje del jugador tiene que clasificarse en rangos de valores.
El puntaje del jugador se calcula sumando los valores de las dos cartas del jugador.
Los rangos que se usan son:

|  rango   |  valor   |
| :-------: | :------: |
|    low    | [4, 11]  |
|    mid    | [12, 16] |
|   high    | [17, 20] |
| blackjack |   [21]   |

Implementa el método `Blackjack.card_range`, que recibe dos cartas como argumentos, en forma de strings.
El método debe devolver el nombre del rango de valores en el que caen las dos cartas.

```ruby
Blackjack.card_range("ten", "king")
# => "high"
```

## 3. Implementa la lógica de decisión para el primer turno.

Según tus dos cartas y la carta del crupier, existe una estrategia para el primer turno del juego, en la que tienes las siguientes opciones:

- Plantarse (S)
- Pedir carta (H)
- Dividir (P)
- Ganar automáticamente (W)

Aunque todavía no es óptima, seguirás la estrategia que tu amigo Alex ha estado desarrollando, que es la siguiente:

- Si tienes un par de ases, siempre debes dividirlos.
- Si tienes un Blackjack (dos cartas que suman un valor de 21) y el crupier no tiene un as, una figura o un diez, ganas automáticamente.
  Si el crupier sí tiene alguna de esas cartas, tendrás que plantearte y esperar a que se revele la otra carta.
- Si tus cartas suman un valor dentro del rango [17, 20], siempre debes plantearte.
- Si tus cartas suman un valor dentro del rango [12, 16], siempre debes plantearte, a menos que el crupier tenga un 7 o más, en cuyo caso siempre debes pedir carta.
- Si tus cartas suman 11 o menos, siempre debes pedir carta.

Implementa el método `Blackjack.first_turn`, que recibe tres cartas como argumentos, en forma de strings.
El método debe devolver, como string, la decisión que debes tomar.

```ruby
Blackjack.first_turn("ace", "ace", "two")
# => "P"
```
