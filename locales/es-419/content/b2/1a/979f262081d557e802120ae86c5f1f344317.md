# Instrucciones


Eres el maître de un restaurante de hotel.
Tu tarea es gestionar la distribución de los asientos del comedor de acuerdo con el número de asientos disponibles hoy, el número de reservaciones y los clientes que llegan sin reservación y que en este momento esperan a que se les asigne un lugar.
Para los fines de este ejercicio, los asientos se asignan al primer asiento vacío disponible.


Para este ejercicio, tienes 6 retos diferentes de organización del comedor por completar.


## 1. Crea el mapa de asientos de hoy

Define la función `new_seating_chart(<size=22>)` que toma un argumento `size` que representa el número de asientos que se dispondrán en el comedor hoy.
Si no se da `size`, la función debe devolver un mapa de asientos con 22 asientos.
Los valores de los asientos deben tener un marcador de posición `None` para indicar que están disponibles para asignárselos a un cliente.


## 2. Organiza las reservaciones

Define la función `arrange_reservations(<guest_names>)` con 1 parámetro para una lista de nombres de clientes.
Esto representa el número de personas que tienen lugares reservados en el comedor hoy.


Esta función debe devolver un mapa de asientos `dict` de tamaño predeterminado (22 asientos), con los clientes asignados a los asientos en el orden en que aparecen en la lista de reservaciones.
Todos los asientos sin asignar deben establecerse en `None`.
Si no hay clientes, se debe devolver un mapa de asientos «vacío» con todos los marcadores de posición en `None`.


```python
>>> arrange_reservations(guests=["Walter", "Frank", "Jenny", "Carol", "Alice", "George"])
...
{1: 'Walter', 2: 'Frank', 3: 'Jenny', 4: 'Carol', 5: 'Alice', 6: 'George', 7: None, 8: None, 9: None, 10: None, 11: None, 12: None, 13: None, 14: None, 15: None, 16: None, 17: None, 18: None, 19: None, 20: None, 21: None, 22: None}
```


## 3. Encuentra todos los asientos «vacíos»

Define la función `find_all_available_seats(<seats>)` que toma 1 parámetro (_un diccionario de mapa de asientos_) y devuelve una `list` de números de asiento que están disponibles para los clientes que esperan en este momento.
Si un asiento está vacío, tendrá el valor `None` en el diccionario. Los asientos ocupados tendrán el nombre del cliente.


```python
>>> seats = {1: None, 2: 'Frank', 3: 'Jenny', 4: None, 5: 'Alice', 6: 'George', 7: None, 8: 'Carol', 9: None, 10: None, 11: None, 12: 'Walter'}

>>> find_all_available_seats(seats)
[1,4,7,9,10,11]
```

## 4. Capacidad actual de asientos vacíos

Define la función `current_empty_seat_capacity(<seats>)` que toma 1 parámetro: el `dict` de reservaciones de asientos existentes.
La función debe devolver el número total de asientos que están vacíos.

```python
>>> curr_empty_seat_capacity({1: "Occupied", 2: None, 3: "Occupied"})
1

>>> curr_empty_seat_capacity({1: "Occupied", 2: None, 3: None})
2
```


## 5. ¿Deben esperar?

Define la función `accommodate_waiting_guests(<seats>, <guests>)` que toma dos parámetros.
El primer parámetro será un mapa de asientos `dict`.
El segundo parámetro será una `list` de clientes que llegaron sin reservación inesperadamente.
Primero tendrás que averiguar cuántos asientos hay disponibles y si es posible darle asiento a los clientes no anunciados en este momento.

Si no tienes suficientes asientos, devuelve el mapa de asientos `dict` sin cambios.

Si _sí_ hay asientos disponibles, asígnales lugares a los clientes en el mapa de asientos y devuélvelo actualizado.
**Sugerencia:** puedes usar las funciones que definiste antes para hacer los cálculos por ti.


```python
# Guests cannot be accommodated.
>>> starting_reservations = {1: 'Carol', 2: 'Alice', 3: 'George', 4: None, 5: None, 6: None, 7: 'Frank', 8: 'Walter'}
>>> accommodate_guests(starting_reservations, ["Mort", "Suze", "Phillip", "Tony"])
...
{1: 'Carol', 2: 'Alice', 3: 'George', 4: None, 5: None, 6: None, 7: 'Frank', 8: 'Walter'}


# Guests can be accommodated.
>>> starting_reservations = {1: None, 2: None, 3: None, 4: 'Carol', 5: 'Alice', 6: 'George', 7: None, 8: None, 9: None, 10: None, 11: None, 12: None, 13: None, 14: None, 15: None, 16: None, 17: None, 18: 'Frank', 19:  'Jenny', 20: None, 21: None, 22: 'Walter'}
>>> accommodate_guests(starting_reservations, ["Mort", "Suze", "Phillip", "Tony"])
...
{1: 'Mort', 2: 'Suze', 3: 'Phillip', 4: 'Carol', 5: 'Alice', 6: 'George', 7: 'Tony', 8: None, 9: None, 10: None, 11: None, 12: None, 13: None, 14: None, 15: None, 16: None, 17: None, 18: 'Frank', 19: 'Jenny', 20: None, 21: None, 22: 'Walter'}
```

## 6. Asientos vacíos

Define la función `empty_seats(<seats>, <seat_numbers>)` que toma dos parámetros.
El primer parámetro será un diccionario de mapa de asientos.
El segundo parámetro es una lista de números de asiento que necesitas «liberar» o vaciar; es decir, necesitas asignarle el valor `None` al número de asiento.

Devuelve el `dict` de asientos después de actualizar los valores de los asientos «por vaciar».

```python
>>> empty_seats(seats={1: "Alice", 2: None, 3: "Bob", 4: "George", 5: "Gloria"}, seat_numbers=[5,3,1])
{1: None, 2: None, 3: None, 4: "George", 5: None}
```
