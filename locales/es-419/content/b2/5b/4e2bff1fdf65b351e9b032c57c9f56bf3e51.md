# Pistas

## 1. Crea un nuevo visitante

- Vuelve a revisar el [concepto «Objects»][concept-objects] para descubrir cómo crear un objeto con ciertas claves y valores.

## 2. Anula el boleto

- Usa el operador de asignación `=` para asignar `null` a la propiedad `ticketId` del objeto visitante.
- Después, devuelve el objeto visitante.

## 3. Determina el estado del boleto

- Vuelve a revisar el [concepto «Conditionals»][concept-conditionals] para descubrir cómo devolver distintos valores desde la función de forma condicional.
- Usa la notación de corchetes para acceder al valor del `ticketId` dado en el objeto.
- Usa el operador de igualdad estricta `===` para comprobar `null` o `undefined`.

## 4. Mejora la respuesta del estado del boleto

- Obtén el valor de un `ticketId` dado con la notación de corchetes, como en la tarea anterior.
- No se necesita ningún condicional para resolver esta tarea.
- En su lugar, usa el [operador de coalescencia nula][mdn-nullish-coalescing] `??`.

## 5. Determina la versión de los términos y condiciones

- Vuelve a revisar el [concepto «Objects»][concept-objects] para ver cómo acceder a valores anidados y empieza por escribir la expresión que obtiene la versión.
- Luego usa el operador de [encadenamiento opcional][mdn-optional-chaining] para manejar el caso del objeto gtc que falta.
- No se necesita ningún condicional para resolver esta tarea.
