# Instrucciones

Mientras trabajas para una fábrica, surge la necesidad de crear el mensaje impreso en las credenciales de los empleados. Decides implementar esta función en JavaScript.

Una credencial requiere el `id` del empleado, el `name` del empleado, así como el departamento en el que trabaja.

## 1. Crea el texto de la credencial

Implementa una función llamada `printBadge` que devuelva el texto que se imprimirá en la credencial.

El nombre del empleado siempre se proporciona, pero el número `id` del empleado y el nombre del departamento pueden ser `null`. El número `id` del empleado, si se proporciona, debe ir entre corchetes (por ejemplo, `[20]`).

La credencial de un propietario no debe tener `id` ni `department`.

```javascript
printBadge(20, 'Bob', 'Marketing');
// => '[20] Bob - MARKETING'
```
