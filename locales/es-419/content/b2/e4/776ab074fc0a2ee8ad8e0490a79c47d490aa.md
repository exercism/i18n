# Introducción

El _operador ternario_ es una alternativa ligera y compacta para _sentencias if/else_ sencillas.
Por lo general se usa en sentencias de retorno (aunque no solo ahí), y necesita una sola línea para tomar la decisión: devuelve el valor de la izquierda si la expresión es `true` y el valor de la derecha si es `false`, así:

```java
boolean expr = 0 != 200;

// Ternary statement
int value = expr ? 22 : 33;
// => 22
```

Muchas expresiones _if/else_ sencillas se pueden simplificar con _operadores ternarios_.
