# Instrucciones

Eres una persona muy aficionada a observar aves y llevas la cuenta de cuántos pájaros han visitado tu jardín en un día cualquiera.

Decidiste llevar tu observación de aves a otro nivel e implementar algunas herramientas que te ayudarán a registrar y procesar los datos.

Elegiste guardar los datos como un array de números enteros. El primer número del array es la cantidad de pájaros que visitaron tu jardín hoy, el segundo, los de ayer, y así sucesivamente.

## 1. Verifica cuántos pájaros visitaron hoy

Implementa la función `BirdCount.today/1`. Debe recibir un array con los conteos diarios de pájaros y devolver el conteo de hoy. Si el array está vacío, debe devolver `nil`.

```elixir
BirdCount.today([2, 5, 1])
# => 2
```

## 2. Incrementa el conteo de hoy

Implementa la función `BirdCount.increment_day_count/1`. Debe recibir un array con los conteos diarios de pájaros e incrementar en 1 el conteo de hoy. Si el array está vacío, devuelve `[1]`.

```elixir
BirdCount.increment_day_count([4, 0, 2])
# => [5, 0, 2]
```

## 3. Verifica si hubo un día sin pájaros visitantes

Implementa la función `BirdCount.has_day_without_birds?/1`. Debe recibir un array con los conteos diarios de pájaros. Debe devolver `true` si hubo al menos un día en el que ningún pájaro visitó el jardín, y `false` en caso contrario.

```elixir
BirdCount.has_day_without_birds?([2, 0, 4])
# => true

BirdCount.has_day_without_birds?([3, 8, 1, 5])
# => false
```

## 4. Calcula el número total de pájaros visitantes

Implementa la función `BirdCount.total/1`. Debe recibir un array con los conteos diarios de pájaros y devolver el total que ha visitado tu jardín desde que empezaste a recopilar los datos.

```elixir
BirdCount.total([4, 0, 9, 0, 5])
# => 18
```

## 5. Calcula el número de días ajetreados

Algunos días son más ajetreados que otros. Un día ajetreado es aquel en el que cinco o más pájaros han visitado tu jardín.

Implementa la función `BirdCount.busy_days/1`. Debe recibir un array con los conteos diarios de pájaros y devolver el número de días ajetreados.

```elixir
BirdCount.busy_days([4, 5, 0, 0, 6])
# => 2
```
