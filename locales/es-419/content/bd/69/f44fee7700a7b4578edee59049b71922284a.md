# Instrucciones

En este ejercicio, vas a ayudar a unos novios de secundaria a declarar su amor en las redes sociales generando un corazón unicode con sus iniciales:

```
❤ J.  +  M. ❤
```

## 1. Limpia el nombre

Implementa el método `cleanupname`.
Debe recibir un nombre, quitar todos los caracteres `-` y reemplazarlos por un espacio.
También debe quitar los espacios en blanco del principio y del final del nombre.

```julia-repl
julia> cleanupname("Jane-Ann")
"Jane Ann"
```

## 2. Obtén la primera letra del nombre

Implementa el método `firstletter`.
Debe recibir un nombre y devolver su primera letra como string.
Asegúrate de reutilizar `cleanupname`, que definiste en el paso anterior, y de combinarla con otras funciones.

```julia-repl
julia> firstletter("Jane")
"J"
```

## 3. Formatea la primera letra como una inicial

Implementa el método `initial`.
Debe recibir un nombre y devolver su primera letra, en mayúscula, seguida de un punto.
Asegúrate de reutilizar `firstletter`, que definiste en el paso anterior.

```julia-repl
initial("Robert")
"R."
```

## 4. Coloca las iniciales dentro del corazón

Implementa el método `couple`.
Debe recibir dos nombres y devolver las iniciales rodeadas de corazones emoji.
Asegúrate de reutilizar `initial`, que definiste en el paso anterior.

```julia-repl
couple("Blake Miller", "Riley Lewis")
"❤ B.  +  R. ❤"
```
