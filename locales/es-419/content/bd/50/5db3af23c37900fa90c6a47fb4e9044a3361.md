# Anexo de instrucciones

## Crea tu propio DSL

En este ejercicio, eres completamente libre de diseñar el DSL de grafos de tus sueños.

Las pruebas solo requieren que crees unos cuantos grafos específicos; la forma de construirlos depende totalmente de ti.

Para duplicar la diversión, puedes intentar implementar, de forma opcional, una función `to_dot` que convierta tu grafo al formato DOT.

## Representación del grafo

Define tu DSL en `Graph.roc` y luego úsalo para construir los grafos que pide el stub.
Los dos identificadores de nodo de cada `EdgeId` deben estar ordenados alfabéticamente.

| Definición | Grafo que se debe construir |
| --- | --- |
| `empty_graph` | Un grafo vacío |
| `graph_with_one_node` | Un nodo |
| `graph_with_one_node_with_attribute` | Un nodo con un atributo |
| `graph_with_one_edge` | Una arista |
| `graph_with_one_attribute` | Un atributo del grafo |
| `graph_with_nodes_edges_and_attributes` | Nodos, aristas y atributos |
| `multiple_edges_on_one_line` | Varias aristas expresadas en una sola línea |
| `only_1_edge_between_nodes` | Solo una arista entre cada par de nodos |
