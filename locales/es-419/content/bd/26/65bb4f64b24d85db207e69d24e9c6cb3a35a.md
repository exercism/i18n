# Debug

Cuando falla una prueba, se muestra un mensaje que describe qué salió mal y con qué entrada. Puedes inspeccionar valores arbitrarios en tu programa pasándolos al método `debug` (disponible en `exercism/test_runner`). Esto capturará los valores y te mostrará la salida.


```gleam
import exercism/test_runner.{ debug }

let value: String = "test"
debug("The value is " <> value)
```
