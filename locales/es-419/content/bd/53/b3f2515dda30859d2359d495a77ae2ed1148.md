# se creó una variable adicional para el nombre

Crear una variable adicional para guardar el nombre es innecesario, ya que Go no pasa las variables por referencia.
Reasignar `name` no cambiará el valor fuera del ámbito de la función `ShareWith`.
Como Go no ofrece una forma de dar valores predeterminados a los parámetros de una función,
es habitual en Go reasignar el valor para proporcionar un valor predeterminado.
