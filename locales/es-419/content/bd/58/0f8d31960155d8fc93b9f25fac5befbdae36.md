# Introducción

## Primeros pasos

### Variables

Puedes almacenar y nombrar valores definiendo una [variable][constants-variables].
Después de definir una variable, puedes usar su nombre para referirte a ese valor en todo tu código.
Las variables son _mutables_, lo que significa que sus valores pueden cambiar después de definirlas.

Define una variable con la palabra clave `var`:

```swift
var variableName = 10
```

Swift es un lenguaje de tipado estático, lo que significa que cada valor tiene un tipo conocido en tiempo de compilación.
Puedes declarar un tipo explícitamente con una [anotación de tipo][type annotations], o puedes dejar que el compilador de Swift [infiera el tipo][type-inferring] a partir del valor asignado:

```swift
var explicitVar: Int = 10 // Explicitly typed
var implicitVar = 10      // Implicitly typed (inferred as Int)
```

Puedes actualizar el valor de una variable con el operador de asignación (`=`):

~~~~exercism/note
El tipo de una variable no puede cambiar después de declararla.

```swift
variableName = 13 // Allowed: same type (Int)

// Compiler error: cannot assign a different type
variableName = "Hello, world!" // Cannot assign value of type 'String' to type 'Int'
```
~~~~

Puedes declarar una variable sin un valor inicial si especificas su tipo, pero debes asignarle un valor antes de usarla:

```swift
var someInt: Int

// This triggers a compiler error:
// print(someInt) // Variable 'someInt' used before being initialized

// Assign a value first
someInt = 169
print(someInt) // Prints 169
```

### Constantes

Las [constantes][constants-variables] también asocian un nombre con un valor, pero sus valores no pueden cambiarse después de asignarlos.
Son _inmutables_.
Define una constante con la palabra clave `let`:

```swift
let constantName = 10          // Inferred constant
let explicitConstant: Int = 10 // Explicitly typed constant
```

### Operadores aritméticos

Swift ofrece [operadores aritméticos][arithmetical-operators] estándar para las matemáticas básicas:

- Suma: `+`
- Resta: `-`
- Multiplicación: `*`

```swift
print(1 + 1) // Prints 2
print(2 - 1) // Prints 1
print(2 * 2) // Prints 4
```

### Funciones

En Swift, las [funciones][functions] son bloques de código autocontenidos que realizan una tarea específica.
Las funciones pueden aceptar argumentos, devolver un valor y pasarse como valores a otras funciones.
Define una función con la palabra clave `func`, seguida del nombre de la función, una lista de parámetros entre paréntesis y un tipo de retorno opcional:

```swift
func functionName(argumentLabel parameterName: ParameterType) -> ReturnType {
    // Function body
}
```

Las funciones de Swift usan [etiquetas de argumento][argument-labels], que hacen que el código se lea como oraciones naturales:

- La **etiqueta de argumento** se usa cuando llamas a la función.
- El **nombre del parámetro** se usa dentro del cuerpo de la función para acceder al valor.

Si especificas solo un nombre, Swift lo usa tanto como etiqueta de argumento como nombre de parámetro:

```swift
func greet(name: String) {
    print("Hello, \(name)!")
}

greet(name: "Alice")
```

Si no quieres una etiqueta de argumento al llamar a la función, escribe un guion bajo (`_`) antes del nombre del parámetro:

```swift
func square(_ number: Int) -> Int {
    return number * number
}

square(5) // Called without an argument label
```

Todos los parámetros de una función son constantes (`let`) de forma predeterminada, lo que significa que sus valores no pueden modificarse dentro del cuerpo de la función.

Para devolver un valor desde una función, especifica el tipo de retorno después de `->` y usa la palabra clave `return`:

```swift
func addTen(to value: Int) -> Int {
    return value + 10
}

addTen(to: 10) // Returns 20
```

Cuando una función no devuelve un valor, su tipo de retorno es `Void` (equivalente a una tupla vacía, `()`).
En esas funciones puedes omitir tanto el tipo de retorno `-> Void` como la sentencia `return`.

### Comentarios

Swift admite dos formas de [comentarios][comments]:

- **Los comentarios de una sola línea** comienzan con `//` y continúan hasta el final de la línea.
- **Los comentarios multilínea** van encerrados entre `/*` y `*/`.

```swift
// This is a single-line comment

/* This is a comment
   that spans multiple lines */
```
