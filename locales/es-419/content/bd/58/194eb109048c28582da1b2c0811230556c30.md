# Introducción

Un _string_, o _cadena_, es el tipo de dato de JavaScript que se usa para almacenar texto.

## Crear un string

Creas un string cuando envuelves el texto entre comillas simples o comillas dobles.
En Exercism se usan comillas simples.

<!-- prettier-ignore-start -->
```javascript
'Hello, World!'
"Hello, World!"
```
<!-- prettier-ignore-end -->

## Los strings como listas de caracteres

Un string se puede tratar como una lista de caracteres, donde el primer carácter tiene el índice `0`.
Puedes acceder a un carácter individual del string usando corchetes y el índice de la letra que quieras obtener.

```javascript
'cat'[1];
// => 'a'
```

Puedes saber cuántos caracteres tiene un string si accedes a la propiedad `length`.

```javascript
'cat'.length;
// => 3
```

## Concatenación y métodos

La forma más sencilla de concatenar strings es usar el operador de suma `+`.

```javascript
'I like' + ' ' + 'cats.';
// => "I like cats."
```

Los strings ofrecen muchos métodos auxiliares; consulta la [documentación de MDN sobre los métodos de string][mdn-string-methods] para ver la lista completa.
La siguiente lista muestra algunos de los métodos auxiliares más usados.

- [`toUpperCase`][mdn-to-upper-case] y [`toLowerCase`][mdn-to-lower-case] - cambian las mayúsculas y minúsculas de todos los caracteres
- [`trim`][mdn-trim] - elimina los espacios en blanco al principio y al final
- [`includes`][mdn-includes], [`startsWith`][mdn-starts-with] y [`endsWith`][mdn-ends-with] - determinan si otro string forma parte del string dado
- [`slice`][mdn-slice] - extrae una sección del string

Los strings son inmutables en JavaScript. Así que una «modificación», por ejemplo con alguno de los métodos anteriores, siempre creará un string nuevo en su lugar.
