# CLI

Puedes ejecutar las pruebas abriendo una terminal en el directorio del ejercicio y luego ejecutando el [comando `stack test`][docs-stack-test]. Si tu código compila, este comando te mostrará qué pruebas pasaron y cuáles fallaron. Cuando una prueba falle, intenta hacer que pase y ejecuta las pruebas otra vez.

Una vez que todas las pruebas pasen, puedes enviar tu solución abriendo una terminal en el directorio del ejercicio y ejecutando el [comando `exercism submit`][docs-exercism-cli].

[docs-stack-test]: https://docs.haskellstack.org/en/stable/build_command/
[docs-exercism-cli]: https://exercism.io/cli
