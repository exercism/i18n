# Introducción

Una [lista][list] es una colección mutable de elementos en _secuencia_.
 Son una estructura de datos extremadamente flexible y útil que muchos métodos y operaciones `built-in` de Python producen como resultado.
 Las listas pueden contener referencias a cualquier tipo de dato (o a varios), incluidas otras listas u otras estructuras de datos como [tuplas][tuples], [conjuntos][sets] o [diccionarios][dicts].
 El contenido se puede recorrer con la construcción `for item in <list>`.
 Si necesitas los índices junto con el contenido, puedes usar `for index, item in enumerate(<list>)`.
 A los elementos dentro de una `list` se puede acceder con un `0-based index` desde la izquierda, o con un `-1-based index` desde la derecha.
 Las listas se pueden copiar total o parcialmente usando la _notación de rebanadas_ o `<list>.copy()`.
