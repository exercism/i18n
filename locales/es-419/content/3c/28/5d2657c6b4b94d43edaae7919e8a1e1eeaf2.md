# Introducción

## Recursión

Las funciones recursivas son funciones que se llaman a sí mismas.

Una función recursiva necesita tener al menos un _caso base_ y al menos un _caso recursivo_.

Un _caso base_ devuelve un valor sin volver a llamar a la función. Un _caso recursivo_ vuelve a llamar a la función y modifica el argumento para que en algún momento coincida con el caso base.

Muy a menudo, cada caso se escribe en su propia cláusula de función.

```elixir
# base case
def count([]), do: 0

# recursive case
def count([_head | tail]), do: 1 + count(tail)
```
