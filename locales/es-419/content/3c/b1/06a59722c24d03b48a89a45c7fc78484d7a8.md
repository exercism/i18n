# Introducción

La expresión `let` se usa para crear un ámbito local y resulta útil en varias situaciones:

- Para simplificar expresiones
- Para nombrar los resultados de expresiones intermedias
- Para dividir una expresión en partes más pequeñas cuando se está volviendo muy grande

Puedes hacer casi cualquier cosa dentro de una expresión `let`, incluida la desestructuración (hablaremos de esto con más detalle en ejercicios posteriores), pero no es posible definir un nuevo Custom Type ni un Type Alias.

```elm
let
  cube x = x * x * x
in
  cube a + cube b + cube c
```

```elm
beginWithPattern : Size -> Padding -> Pattern -> GameOfLife
beginWithPattern minimumSize padding pattern =
    let
        size = calculateSize minimumSize padding pattern

        center = Size.center size

        centeredPattern = Pattern.centerAt center pattern

        dimensions = { width = size, height = size }

        deadCells = Matrix.create dimensions Dead
    in
    GameOfLife (bringPatternToLife deadCells centeredPattern)
```
