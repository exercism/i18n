# Introducción

Los objetos pueden guardar su propio estado si definen _variables de instancia_, que se crean anteponiendo `@` a un nombre de variable.

```ruby
@name = 2
```

Por lo general, los objetos establecen su estado inicial en un método `initialize`, que se llama automáticamente cuando llamas a `new` en una clase.

```ruby
class Airplane
  def initialize
    @wings = 2
  end
end
```

El método `initialize` también puede recibir argumentos, de modo que cada instancia pueda empezar con un estado personalizado:

```ruby
class Suitcase
  def initialize(locked)
    @locked = locked
  end
end
```

Considera que las _variables de instancia_ son privadas frente a las lecturas y escrituras externas. Para obtener y establecer variables de instancia conviene usar _métodos de instancia_:

```ruby
class Suitcase
  #...

  def locked? # Query methods should be named with a trailing `?`
    @locked
  end

  def unlock! # Methods which mutate state should have trailing `!`
    @locked = false
  end
end
```
