# Pistas

## General

- La sintaxis `0b00` se puede usar para especificar un int en sintaxis binaria en lugar de sintaxis decimal.

## 1. Codifica el ácido nucleico a un valor binario

- Se puede aplicar coincidencia de patrones al tipo de nucleótido con una expresión case.

## 2. Decodifica el valor binario al ácido nucleico

- La sintaxis binaria de int se puede usar en los patrones.
- Devuelve `Error(Nil)` si el int no es un nucleótido válido.

## 3. Codifica una lista de ADN

- La función `encode_nucleotide` se puede usar para codificar un solo nucleótido.

## 4. Decodifica un array de bits de ADN

- La sintaxis binaria de int se puede usar dentro de un patrón de array de bits.
- Devuelve `Error(Nil)` si el array de bits restante no es lo bastante largo para contener un nucleótido.
