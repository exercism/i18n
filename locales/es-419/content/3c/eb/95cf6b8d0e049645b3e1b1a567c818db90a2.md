# Pistas

## 1. Calcula el valor de cualquier carta

- Un [`switch`][ref-switch] al estilo antiguo funciona bien aquí, ya que en cada llamada solo necesita manejar una sola carta.
- Usar [`case_match`][ref-case_match] es otra opción, pero en este caso no se pueden omitir las comillas alrededor de los strings.

## 2. Implementa la lógica de decisión para el primer turno

- [`case_when`][ref-case_when] es útil en esta tarea.
- La tarea se puede resolver en R base usando una serie de condicionales, pero de forma menos elegante.

[ref-switch]: https://stat.ethz.ch/R-manual/R-devel/library/base/html/switch.html
[ref-case_match]: https://dplyr.tidyverse.org/reference/case_match.html
[ref-case_when]: https://dplyr.tidyverse.org/reference/case_when.html
