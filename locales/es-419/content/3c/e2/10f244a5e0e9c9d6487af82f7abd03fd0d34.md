# Valores predeterminados de los parámetros

Los [valores predeterminados de los parámetros][default-parameter-values] se pueden proporcionar para cualquiera de los parámetros de una función asignando un valor al parámetro en la lista de parámetros, después de la anotación de tipo del parámetro. Cuando se especifica un valor predeterminado para un parámetro, quien llama a la función puede omitir ese parámetro al llamar a la función y, en su lugar, se usará el valor predeterminado.

```swift
func greeting(name: String = "guest", duration: Int = 2) -> String {
  "Welcome, \(name). Enjoy your \(duration) night stay."
}

greeting(name: "Bobo", duration: 7)
// Returns "Welcome, Bobo. Enjoy your 7 night stay."
greeting(duration: 3)
// Returns "Welcome, guest. Enjoy your 3 night stay."
greeting(name: "Wynona")
// Returns "Welcome, Wynona. Enjoy your 2 night stay."
greeting()
// Returns "Welcome, guest. Enjoy your 2 night stay."
```

[default-parameter-values]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/functions/#Default-Parameter-Values
