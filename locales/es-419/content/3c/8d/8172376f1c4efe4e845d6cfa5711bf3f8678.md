# Introducción

Un método es una función con un argumento _receptor_ especial.
El receptor aparece en su propia lista de argumentos, entre la palabra clave `func` y el nombre del método.

```go
func (receiver type) MethodName(parameters) (returnTypes) {
}
```

Solo puedes definir un método con un receptor cuyo tipo esté definido en el mismo paquete que el método.

```go
package person 

type Person struct {
	Name string
}

func (p Person) Greetings() string {
	return fmt.Sprintf("Welcome %s!", p.Name)
}
```

El método del struct se puede llamar con la notación de punto.

```go
p := Person{Name: "Bronson"}
fmt.Println(p.Greetings())
// Output: Welcome Bronson!
```

Fíjate en la forma en que llamamos al método `Greetings()` sobre la instancia `p` de `Person`.
Es exactamente igual a como llamas a los métodos en un lenguaje de programación orientado a objetos.

Recuerda: un método es solo una función con un argumento receptor.
Los métodos ayudan a evitar conflictos de nombres: como un método está ligado a un tipo de receptor en particular, puedes tener el mismo nombre de método en tipos distintos.

```go
import "math"

type rect struct {
	width, height int
}
func (r rect) area() int {
	return r.width * r.height
}

type circle struct {
	radius int
}
func (c circle) area() float64 {
	return math.Pow(float64(c.radius), 2) * math.Pi
}
```

Hay dos tipos de receptores: los receptores de valor y los receptores de puntero.

Todos los métodos que hemos visto hasta ahora tienen un receptor de valor, lo que significa que reciben una copia del valor que se pasa al método. Por eso, cualquier modificación que se haga al receptor dentro del método no es visible para quien lo llama.

Puedes declarar métodos con receptores de puntero para modificar el valor al que apunta el receptor.
Esto se hace anteponiendo un `*` al nombre del tipo.
Por ejemplo, con el tipo `rect`, un receptor de puntero se declararía como `*rect`.
Esas modificaciones también son visibles para quien llama al método.

```go
type rect struct {
	width, height int
}
func (r *rect) squareIt() {
	r.height = r.width
}

r := rect{width: 10, height: 20}
fmt.Printf("Width: %d, Height: %d\n", r.width, r.height)
// Output: Width: 10, Height: 20

r.squareIt()
fmt.Printf("Width: %d, Height: %d\n", r.width, r.height)
// Output: Width: 10, Height: 10
```
