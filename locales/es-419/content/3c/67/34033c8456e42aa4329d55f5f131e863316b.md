# Acerca de

Un búfer de string es una forma eficiente de construir una cadena grande agregando pequeños elementos entre sí. A diferencia de String, una instancia de StringBuf no es inmutable, en el sentido de que se puede pasar como argumento a funciones que la modifican al agregarle más valores.

```haxe
var a = new StringBuf();
a.add("Hello");
trace(a.toString()); // Hello
a.add("Haxe!");
trace(a.toString()); // HelloHaxe
```
