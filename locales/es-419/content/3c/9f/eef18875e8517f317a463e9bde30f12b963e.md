# Introducción

El hashmap es una colección que se usa para almacenar pares clave-valor. Permite usar tipos arbitrarios como claves y valores. Los hashmaps tienen funciones de inserción y recuperación rápidas y son muy útiles, por ejemplo, para hacer conteos de frecuencia, almacenar relaciones, etc. El hashmap también incluye la potente API `entry`, que hace que su uso sea muy ergonómico.
