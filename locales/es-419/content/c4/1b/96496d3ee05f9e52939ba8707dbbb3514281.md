# Anexo de instrucciones

## Registros

| Registro | Uso            | Tipo    | Descripción                                      |
| -------- | -------------- | ------- | ------------------------------------------------ |
| `$a0`    | entrada        | entero  | cantidad de dígitos de entrada                   |
| `$a1`    | entrada        | entero  | base de los dígitos de entrada                   |
| `$a2`    | entrada        | entero  | base de los dígitos de salida                    |
| `$a3`    | entrada/salida | dirección | array de palabras de dígitos que se puede sobrescribir |
| `$v0`    | salida         | entero  | cantidad de dígitos de salida, -1 si la entrada no es válida |
| `$t0-9`  | temporal       | cualquiera | se usa para almacenamiento temporal           |
