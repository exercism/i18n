# Pruebas

Ejecuta las pruebas con:

```shell
corepack pnpm test
```

Asegúrate de que tu código siga las buenas prácticas y los estilos de código, como lo hacen otros usuarios, con ESLint, una herramienta que hace análisis estático de tu código.
A veces, herramientas como esta te ahorran tiempo al detectar errores de escritura o descuidos en tu código de JavaScript:

```shell
corepack pnpm lint
```

También puedes ejecutar Jest en modo «watch», que vuelve a ejecutar tus pruebas automáticamente cuando guardas cambios en el código o en el módulo de pruebas:

```shell
corepack pnpm watch
```

## Cómo entender las pruebas omitidas

El método skip le indica al conjunto de pruebas que no ejecute una prueba. Esta función también se puede usar con los alias: `it.skip(name, fn)` o `xit(name, fn)` o `xtest(name, fn)`

- ¿Por qué se omiten?

Para que puedas concentrarte en una prueba a la vez y habilitarlas una por una a medida que evoluciona tu solución.

- ¿Cómo habilitarlas?

Cambia `xtest` por `test`.

```javascript
test('title cased phrases', () => {
  expect(Acronyms.parse('Portable Network Graphics')).toEqual('PNG');
});
```

## Cómo crear tu primer módulo de JavaScript 2015

Por lo general, las pruebas de este track cargan tu implementación importándola como un módulo de JavaScript: `import { Bob } from './bob.js';`.
Solo tienes que exportar tu implementación desde el archivo referenciado, `bob.js`:

```javascript
export function hey(message) {}
```

Puedes encontrar más información sobre los módulos en la [documentación de Babel](https://babeljs.io/docs/learn-es2015/#modules).
Para que te sea más fácil empezar, hay un archivo JavaScript _esqueleto_ en el directorio.
