# Introducción

## Números

ABAP tiene varios tipos numéricos. En este ejercicio, usarás dos de ellos:

- `i` para valores enteros, como un número de días.
- `p` para valores decimales empaquetados, como una tarifa por hora o un descuento.

```abap
DATA billable_days TYPE i VALUE 22.
DATA rate_per_hour TYPE p LENGTH 8 DECIMALS 2 VALUE '89.89'.
```

Los números empaquetados definen su longitud máxima y su número de decimales.
Por lo general, los literales decimales se escriben como valores de texto y el compilador los convierte al tipo decimal de destino, o se convierten con `CONV`.

```abap
TYPES discount_rate TYPE p LENGTH 8 DECIMALS 6.

DATA discount TYPE discount_rate.
discount = CONV discount_rate( '0.15' ).
```

### Redondeo

ABAP incluye funciones numéricas integradas para el redondeo.
La función `floor` redondea hacia abajo al número entero más cercano, y `ceil` redondea hacia arriba al número entero más cercano.

```abap
DATA full_months TYPE i.
full_months = floor( 70 / 22 ).

DATA rounded_cost TYPE i.
rounded_cost = ceil( '14527.2' ).
```

## Operadores aritméticos

ABAP admite operadores aritméticos para hacer cálculos con valores numéricos.

```abap
DATA day_rate TYPE p LENGTH 8 DECIMALS 2.
day_rate = rate_per_hour * 8.
```

Los operadores básicos son:

- `+` para la suma.
- `-` para la resta.
- `*` para la multiplicación.
- `/` para la división.
- `MOD` para el residuo de una división entera.

```abap
DATA remaining_days TYPE i.
remaining_days = num_days MOD 22.
```

ABAP evalúa la multiplicación y la división antes que la suma y la resta.
Puedes usar paréntesis para dejar explícito el orden deseado.

```abap
DATA discounted_rate TYPE p LENGTH 8 DECIMALS 2.
discounted_rate = monthly_rate * ( 1 - discount ).
```
