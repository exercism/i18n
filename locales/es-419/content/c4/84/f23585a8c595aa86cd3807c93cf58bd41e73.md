# CLI

## Enviar la solución

Cuando ya no quede ningún test omitido y todos pasen, puedes enviar tu solución con `exercism submit numbers.js`.

## Enviar soluciones incompletas

Puedes enviar una solución incompleta para ver cómo otras personas resolvieron el ejercicio.
