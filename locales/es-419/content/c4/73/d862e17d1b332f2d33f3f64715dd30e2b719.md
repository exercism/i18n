# Acerca de

Cuando los tipos no se pueden convertir de forma implícita, debes usar un [operador][cast-operator] de conversión explícita.
El operador de conversión no es más que el tipo de destino entre paréntesis antes del valor que quieres convertir:

```csharp

int i = 7;
byte b = (byte)i; // Explicit cast from int to byte
```

Usar una conversión explícita puede ser peligroso. Los dos errores más comunes son:

- Convertir a un tipo incompatible. Esto lanzará una excepción en tiempo de ejecución.
- Convertir a un valor numérico que no sea lo suficientemente «ancho». Esto puede provocar un conflicto de signo o que se lance una excepción de desbordamiento en el caso de los enteros

Nota: una expresión de tipo `int` se puede convertir explícitamente a `char`. Esto puede dar como resultado un `char` no válido.

[cast-operator]: https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/operators/type-testing-and-cast#cast-expression
