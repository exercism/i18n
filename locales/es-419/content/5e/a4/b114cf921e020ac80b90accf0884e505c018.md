# Referencia de Rust

## Conceptos

Los ejercicios de conceptos de Rust enseñan conceptos que van desde los fundamentos hasta el dominio del lenguaje. A continuación se clasifican y se enumeran.

Los conceptos de Exercism existen para servir a quienes aprenden de maneras prácticas, por lo que difieren de las ideas abstractas. Este documento define qué significan estos conceptos en Rust. Abajo agregamos una agrupación visual para ayudar a quienes mantienen el track a crear un documento de referencia útil. Esas agrupaciones _no_ constituyen divisiones pedagógicas. Así que, por favor, no las tomes como referencia cuando enseñes.

Las casillas de verificación indican si los conceptos ya se enseñan en la lista de mapeo de ejercicios.

## Mapeo de ejercicios de conceptos

Aunque lo ideal sería tener un único ejercicio de conceptos para cada uno de los conceptos enumerados arriba, que enseñe exactamente un concepto y solo requiera sus requisitos previos, hacerlo no es del todo práctico. Por ejemplo, sería difícil diseñar un ejercicio que enseñara qué son las funciones sin requerir ningún conocimiento de los primitivos; del mismo modo, sería difícil enseñar los primitivos, con una suite de pruebas, sin ningún conocimiento de funciones.

Los ejercicios de esta tabla deberían formar un DAG que con el tiempo cubra todos los conceptos enumerados arriba.

| ejercicio                | requisitos previos                           | enseña                                                   | narrativa                                                                        |
| ------------------------ | -------------------------------------------- | -------------------------------------------------------- | -------------------------------------------------------------------------------- |
| `hello-world`            | -                                            | funciones, suites de pruebas                             | devolver el literal `&str` `"hello world"`                                       |
| `compiled-calculator`    | `hello-world`                                | enteros, asignación de variables                         | realizar un conjunto de operaciones matemáticas y devolver el resultado de forma implícita |
| `conditionals`           | `hello-world`                                | condicionales                                            | conviene estructurarlo con 3 ramas `if` / `else if` / `else`; retorno implícito  |
| `slices`                 | `hello-world`, `compiled-calculator`         | slices                                                   | extraer un slice de un parámetro que es un slice de enteros                      |
| `loops`                  | `slices`                                     | bucle básico sobre un slice                              | idealmente con un retorno temprano, para que sea engorroso expresarlo como un iterador |
| `iterator-use`           | `slices`                                     | uso de iteradores, `collect`                             |
| `integer-sizes`          | `compiled-calculator`                        | enteros que no son `i32`, conversión de tipos            | aún todos con signo                                                              |
| `unsigned-ints`          | `integer-sizes`                              | enteros sin signo                                        |
| `indexing`               | `integer-sizes`, `slices`                    | indexación, `usize`                                      |
| `floats`                 | `compiled-calculator`                        | números de punto flotante                                | probablemente el mismo ejercicio de calculadora compilada, con resultados que no son enteros |
| `bools`                  | `compiled-calculator`                        | Boolean, operadores booleanos                            |
| `char`                   | `compiled-calculator`                        | tipo de dato `char`                                      | debería incluir algunos ejemplos de caracteres anchos                            |
| `str-use`                | `char`, `slices`                             | `&str`                                                   | nota: ¡inmutable!                                                                |
| `string-use`             | `str-use`                                    | `String`                                                 | nota: con ownership, mutable                                                     |
| `format-macro`           | `string-use`                                 | macro `format!`                                          |
| `str-vs-string`          | `str-use`, `string-use`                      | combinar, convertir, costos, etc.                        |
| `generics-basics`        | `integer-sizes`, `floats`                    | usar traits externos como límites, genéricos básicos     | probablemente sigue siendo la calculadora compilada, solo que genérica          |
| `structs`                | `string-use`, `unsigned-ints`, `floats`      | crear y usar un struct para gestionar datos              | `Person` tiene nombre, altura y cantidad de zapatos que posee                    |
| `implicit-return`        | `compiled-calculator`                        | ámbitos, expresiones, retorno implícito                  |
| `explicit-return`        | `implicit-return`, `conditionals`            | sentencia `return` explícita                             |
| `methods`                | `structs`, `explicit-return`                 | bloques `impl`, métodos                                  |
| `tuples`                 | `structs`                                    | tuplas                                                   | enseñarlas como structs anónimos; enseñar la sintaxis `.0`                       |
| `tuple-structs`          | `tuples`, `structs`                          | structs de tupla (tuplas con nombre)                     |
| `basic-enums`            | `unsigned-ints`                              | enums básicos (sin campos), `match`                      |
| `enums`                  | `basic-enums`, `tuple-structs`               | sintaxis de tupla para las variantes de un enum          |
| `option`                 | `enums`                                      | `Option<T>`                                              |
| `result`                 | `enums`                                      | `Result<T, E>`                                           |
| `mutability`             | `compiled-calculator`                        | inmutabilidad por defecto; mutabilidad explícita         |
| `let-expressions`        | `loops`, `option`, `result`                  | `if let`, `while let`                                    | probablemente solo dependerá de `option` o de `result` según la implementación |
| `vectors`                | `slices`                                     | `Vec<T>`                                                 |
| `hashmaps`               | `vectors`                                    | `Hashmap<K, V>`                                          |
| `entry-api`              | `hashmaps`                                   | Entry API                                                |
| `hashsets`               | `hashmaps`                                   | `HashSet<K>`                                             |
| `btreemaps`              | `hashmaps`                                   | `BTreeMap<K, V>`                                         |
| `deriving-traits`        | `structs`                                    | `PartialEq`, `PartialOrd`, `Debug`, `Display`, `Default` |
| `implementing-traits`    | `deriving-traits`                            | implementar un trait manualmente                         | probablemente implementar `Iterator`                                             |
| `collection-conversions` | `vectors`, `hashsets`, `implementing-traits` | `FromIterator`, `IntoIterator`                           |
