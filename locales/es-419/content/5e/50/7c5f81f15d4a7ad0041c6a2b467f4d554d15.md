# Acerca de

[`fold`][fold] es un [adaptador de iterador que consume][consuming iterator adaptor] que aplica una función a cada elemento de la iteración y acumula el resultado en un valor nuevo.

Cada iteración de `fold` toma dos argumentos. El primero es un valor inicial para el acumulador. El segundo es un closure que a su vez toma dos argumentos: el acumulador y un elemento. El valor que devuelve el closure es el valor siguiente del acumulador. Una vez que el iterador se agota, se devuelve el valor final del acumulador.

`fold` se puede usar cuando quieres transformar una colección en un solo valor. Por ejemplo, si quieres la suma de todos los números pares

```rust
pub fn main() {
    let even_sum = (1..=10).fold(0, |acc, num| if num % 2 == 0 { acc + num } else { acc });
    println!("{even_sum:?}");
}
```

Imprime `30`.

Lo que se puede hacer con `fold` a menudo se puede hacer con otra función o con varias. Para el ejemplo anterior, hacer `filter` sobre `(1..=10)` y luego `sum` sería menos verboso y daría el mismo resultado, así:

```rust
(0..=10).filter(|n| *n % 2 == 0).sum()
```

Otras funciones que se usan más que `fold` son `product` y `collect`.

Un acumulador también se puede usar con valores que no son numéricos. Por ejemplo

```rust
pub fn giant_grunts(initial: char) -> String {
    ["Bee", "Fee", "Gee", "Fi", "Hi", "Fo", "Mo", "Fum", "Tum"].iter().fold(
        String::new(),
        |acc, grunt| if grunt.starts_with(initial) { acc + grunt } else { acc },
    )
}

pub fn main() {
    let song = giant_grunts('F');
    println!("{song:?}");
}
```

Imprime `FeeFiFoFum`
