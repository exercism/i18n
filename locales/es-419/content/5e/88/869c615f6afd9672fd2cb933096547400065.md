# Instrucciones

Te encanta observar aves y llevas un conteo diario de las aves que visitan tu jardín. Los conteos se guardan en un array, con el día más antiguo primero.

## 1. El conteo de hoy

Define `today` para que tome el array de conteos diarios de la pila y devuelva el conteo de hoy.

```factor
{ 2 5 0 7 4 1 } today .
! => 1
```

## 2. Incrementa el conteo de hoy

Define `increment-todays-count` para que devuelva un array nuevo con el conteo de hoy aumentado en uno. El array original no debe modificarse.

```factor
{ 2 5 0 7 4 1 } increment-todays-count .
! => { 2 5 0 7 4 2 }
```

## 3. ¿Hubo algún día sin aves?

Define `has-day-without-birds?` para que devuelva `t` si al menos un día registró cero aves, y `f` en caso contrario.

```factor
{ 2 5 0 7 4 1 } has-day-without-birds? .
! => t

{ 2 5 1 } has-day-without-birds? .
! => f
```

## 4. Suma los primeros días

Define `count-for-first-days` para que tome un array de conteos y un número `n`, y devuelva la suma de los primeros `n` conteos.

```factor
{ 2 5 0 7 4 1 } 4 count-for-first-days .
! => 14
```

## 5. Cuenta los días concurridos

Un día concurrido es uno con cinco aves o más. Define `busy-days` para que devuelva el número de días concurridos en el array.

```factor
{ 2 5 0 7 4 1 } busy-days .
! => 2
```

## 6. Rellena los días faltantes

Si no observaste todos los días de un tramo de `n` días, rellena con `0` los días faltantes al final. Define `pad-missing-days` para que tome un array de conteos y una longitud objetivo `n`, y devuelva un array de longitud al menos `n` cuyas posiciones extra sean `0`. Los conteos existentes deben conservarse sin cambios; si el argumento ya tiene una longitud de al menos `n`, devuélvelo sin cambios.

```factor
{ 2 5 0 } 7 pad-missing-days .
! => { 2 5 0 0 0 0 0 }

{ 4 1 6 8 } 3 pad-missing-days .
! => { 4 1 6 8 }
```
