# Tests en la pista de MoonScript

Hacer tests en la pista de MoonScript es exactamente igual que [hacer tests en la pista de Lua][lua-tests].
Desde el directorio de un ejercicio, escribe:

```console
$ busted
```

## Tests pendientes

Esta pista sigue la metodología de [desarrollo guiado por tests][tdd] de Exercism.
Se te da una suite de tests completa, pero solo el primer test está «activo».

Para habilitar los tests, cambia el comando de un test de `pending` a `it`.

Si eres de quienes prefieren ejecutar todos los tests todo el tiempo, puedes usar una herramienta de línea de comandos para cambiarlos todos de una vez.
Aquí tienes un ejemplo con perl (que está instalado en casi todas partes):

```console
$ perl -i -pe 's/^\s+\Kpending\b/it/' two_fer_spec.moon
```

Cuando trabajas en el editor en línea, el test runner ejecuta automáticamente todos los tests.

## Usar LuaRocks

Lua por sí solo es un lenguaje muy pequeño.
[LuaRocks][luarocks] es el gestor de paquetes para los módulos de Lua.

Eres libre de usar cualquier módulo en tus soluciones, pero no todos estarán disponibles en el test runner en línea.
El test runner incluye estos:

**Ya disponibles como dependencias de `busted`**

* [penlight][penlight-home]
* [dkjson][dkjson-home]

**Ya disponibles como dependencias de MoonScript**

* [LPeg][lpeg-home]
* [LuaFileSystem][lfs-home]

**Fecha y hora**

* [date][date-home]
* [lua-tz][lua-tz-home]
* [luatz][luatz-home]
