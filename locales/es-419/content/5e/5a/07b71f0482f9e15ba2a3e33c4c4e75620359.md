# Introducción

`when` es la palabra clave para filtrar excepciones. Se coloca después de la sentencia `catch` y puede tomar una expresión Boolean que contenga cualquier valor que esté en el ámbito en ese momento. Si la expresión se evalúa como verdadera, entonces se ejecuta el bloque asociado a esa sentencia `catch`; de lo contrario, se comprueba la siguiente sentencia `catch`, si la hay.

```csharp
try
{
    // do stuff
}
catch (Exception ex) when (ex.Message != "")
{
    // output the message when it is not empty
}
catch (Exception ex)
{
    // show stack trace or something.
}
```
