# Acerca de

Una [sentencia `switch`][switch] compara un valor con varios patrones de coincidencia posibles.
Ofrece una alternativa más limpia y legible que encadenar varias sentencias `if-else`.

Una sentencia `switch` empieza con la palabra clave `switch`, seguida del valor que se quiere comprobar.
Cada posible coincidencia se introduce con la palabra clave `case`.
La palabra clave `default` define un caso de reserva que se ejecuta si ninguno de los casos explícitos coincide.
Al igual que las cadenas `if-else`, una sentencia `switch` solo ejecuta el bloque de código asociado con el primer caso que coincida.

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

Considera la siguiente cadena `if-else`:

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

Esto se puede escribir de forma más clara con una sentencia `switch`:

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```

## Vinculación de valores y cláusulas `where`

Un caso de `switch` puede vincular los valores que coinciden a constantes o variables temporales para usarlas en el cuerpo de ese caso.
Los casos también pueden incluir una cláusula `where` para comprobar condiciones Boolean adicionales antes de coincidir:

```swift
let x = 1337
switch sumOfDivisors(of: x) {
case let total where total == x:
    print(total, "is a perfect number")
default:
    print(x, "is not a perfect number")
}
```
