# Ejecutar las pruebas

Elige tu sistema operativo:

- [Windows](#windows)
- [macOS](#macos)
- [Linux](#linux)

## Windows

1. Abre una ventana de Command Prompt.
2. Descarga el primer ejercicio:

   ```batchfile
   C:\Users\JohnDoe>exercism download --exercise hello-world --track java
   ```

3. Cambia al directorio del ejercicio:

   ```batchfile
   C:\Users\JohnDoe>cd C:\Users\JohnDoe\exercism\java\hello-world
   ```

4. Ejecuta las pruebas:

   ```batchfile
   C:\Users\JohnDoe>gradlew.bat test
   ```

   _(No te preocupes si las pruebas fallan al principio, así es como empiezas cada ejercicio.)_

5. Resuelve el ejercicio. Busca la guía `instructions.append.md` y trabájala ([ver en GitHub][hello-world-tutorial]).

¡Mucha suerte! ¡Diviértete!

## macOS

1. En la ventana de la terminal, descarga el primer ejercicio:

   ```sh
   exercism download --exercise hello-world --track java
   ```

2. Cambia al directorio del ejercicio:

   ```sh
   cd /Users/johndoe/exercism/java/hello-world
   ```

3. Ejecuta las pruebas:

   ```sh
   ./gradlew test
   ```

   _(No te preocupes si las pruebas fallan al principio, así es como empiezas cada ejercicio.)_

4. Resuelve el ejercicio. Busca la guía `instructions.append.md` y trabájala ([ver en GitHub][hello-world-tutorial]).

¡Mucha suerte! ¡Diviértete!

## Linux

1. En la ventana de la terminal, descarga el primer ejercicio:

   ```sh
   exercism download --exercise hello-world --track java
   ```

2. Cambia al directorio del ejercicio:

   ```sh
   cd /home/johndoe/exercism/java/hello-world
   ```

3. Ejecuta las pruebas:

   ```sh
   ./gradlew test
   ```

   _(No te preocupes si las pruebas fallan al principio, así es como empiezas cada ejercicio.)_

   Si obtienes el siguiente error:

   ```sh
   ./gradlew: Permission denied
   ```

   Entonces al archivo le faltan los permisos de ejecución. Para solucionarlo, ejecuta:

   ```sh
   chmod +x ./gradlew
   ```

   Y ahora deberías poder ejecutar el comando anterior.

4. Resuelve el ejercicio. Busca la guía `instructions.append.md` y trabájala ([ver en GitHub][hello-world-tutorial]).

¡Mucha suerte! ¡Diviértete!
