# Acerca de

Una función es un bloque de código organizado y reutilizable que se usa para realizar alguna acción.
Hay varias formas de definir funciones en JavaScript.
Aquí veremos las _declaraciones de función_ y las _expresiones de función_.
Otras posibilidades, como las [funciones flecha][concept-arrow-functions], se verán en otros conceptos.

## Declaración de función

La forma estándar de definir una función en JavaScript es una _declaración de función_, también llamada _definición de función_ o _sentencia de función_.

Consiste en la palabra clave `function`, el nombre de la función y una lista de parámetros separados por comas y encerrada entre paréntesis.
A esto le sigue el cuerpo de la función (el conjunto de sentencias que define lo que hace una función), encerrado entre llaves.

```javascript
function someName(param1, param2, param3) {
  // ...
}
```

## Usar una función

En JavaScript, una función se invoca (se llama) escribiendo el nombre de la función seguido de paréntesis que contienen los argumentos.

```javascript
someName(arg1, arg2, arg3);
```

Escribir solo el nombre de la función **no** llama a la función en JavaScript.

```javascript
function sayHello() {
  console.log('Hello, World!');
}

sayHello;
// => [Function: sayHello]
// The text representations varies between environments.

sayHello();
// => 'Hello, World!'
```

## Parámetros

Cuando trabajas con parámetros dentro del cuerpo de la función, ten en cuenta los posibles efectos secundarios sobre el valor original que se pasó a la función.
En JavaScript, un argumento es una copia de una referencia al valor original.
Lo que esto significa en la práctica depende del tipo de dato del argumento.

- Los valores de los [tipos de datos primitivos][mdn-primitives] son _inmutables_.
  Todas las «modificaciones» siempre crean un nuevo valor primitivo.
  Por eso, el valor original nunca se ve afectado por lo que le ocurra al argumento dentro del cuerpo de la función.

  ```javascript
  const num = 0;

  function increase(number) {
    number = number + 1;
  }

  increase(num);
  num;
  // => 0
  ```

- Es distinto con valores como los _objetos_, los _arrays_ y las _funciones_.
  Como se copia la referencia, una reasignación no afectará al valor original.
  Sin embargo, como estás tratando con una [copia superficial][wikipedia-shalllow-copy], modificar el argumento dentro del cuerpo de la función también cambiará el valor original que se pasó.

  ```javascript
  const nums = [0, 1, 2, 3, 4];

  function pushFive(arr) {
    arr.push(5);
  }

  pushFive(nums);
  nums;
  // => [0, 1, 2, 3, 4, 5]
  ```

De forma predeterminada, todos los parámetros definidos en la declaración de función son opcionales en JavaScript.
Si a una función se le pasan menos argumentos que parámetros, los argumentos que faltan serán `undefined` dentro del cuerpo de la función; consulta [Null y Undefined][concept-null-undefined].
En muchos casos, tiene más sentido inicializar un parámetro con un valor _predeterminado_ si no se pasa ningún valor o se pasa un `undefined`.
Esto se puede hacer especificando parámetros predeterminados directamente en la definición de la función.

```javascript
function someName(param1 = defaultValue1, param2 = defaultValue2) {
  // ...
}
```

Se puede invocar (llamar) a una función con más argumentos que parámetros había en la definición de la función.
Todos los argumentos, incluidos esos argumentos de más, se pueden encontrar en el [el «array» de arguments][mdn-arguments-object].

También es posible definir funciones que aceptan una cantidad arbitraria de argumentos (funciones variádicas); consulta los parámetros rest en [Operadores Rest y Spread][concept-rest-and-spread] para más detalles.

## Sentencia `return`

Una sentencia `return` termina la ejecución de la función y especifica un valor que se devolverá a quien llamó a la función. Una función puede tener varias sentencias `return`.

```javascript
function checkNumber(num) {
  if (num === 0) {
    return 'You passed 0, please provide another number.';
  }

  return 'Thanks for passing such a nice number.';
}
```

Una función que no devuelve ningún valor con `return`, o que no tiene una sentencia `return`, da como resultado `undefined`.
En JavaScript no hay `return` implícitos.

```javascript
function nakedReturn(a) {
  a * 2;
  return;
}

nakedReturn(1);
// => undefined

function noReturn(a) {
  a * 2;
}

noReturn(1);
// => undefined
```

En JavaScript, solo puedes devolver exactamente un valor.
Si quieres pasar más información, primero debes combinarla en una sola entidad, normalmente en un [objeto][concept-objects] o en un [array][concept-arrays].

```javascript
function divide(a, b) {
  return {
    quotient: Math.floor(a / b),
    remainder: a % b,
  };
}
```

## Expresión de función

Una declaración de función es una sentencia independiente.
Pero a veces es útil definir una función como parte de otra expresión, por ejemplo, en una asignación, como parámetro de una función ([callback][concept-callbacks]) o como valor en un [objeto][concept-objects].
Esto se puede hacer con una expresión de función.
Tiene la misma sintaxis que una declaración de función, solo que se puede omitir el nombre de la función para crear una _función anónima_.

```javascript
const someFunction = function (param) {
  // ...
};

someOtherFunction(function (param) {
  // ...
});

const obj = {
  someFunction: function (param) {
    // ...
  },
};
```

## Ámbito

Una función introduce un nuevo contexto de ejecución en JavaScript.
Las variables definidas dentro de una función no son accesibles fuera de esa función.
Pero las variables definidas en el ámbito padre (el ámbito donde se definió la función) son accesibles dentro de la función.
La [documentación de MDN sobre el ámbito][mdn-scope] muestra ejemplos de este comportamiento.

Echa un vistazo a las [closures][concept-closures] para aprender más sobre el ámbito de las variables en JavaScript.
