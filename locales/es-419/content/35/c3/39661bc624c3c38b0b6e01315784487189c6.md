# Instrucciones

En este ejercicio, escribirás un poco de código para ayudarte a prepararte para comprar un vehículo.

Tienes tres tareas: determinar si vas a necesitar una licencia; elegir entre dos vehículos; y estimar el precio aceptable de un vehículo usado.

## 1. Determina si vas a necesitar una licencia de conducir

Algunos tipos de vehículos requieren una licencia de conducir para poder conducirlos.
Asume que solo los tipos `"car"` y `"truck"` requieren una licencia; todo lo demás se puede conducir sin una.

Implementa la función `needs_license` que recibe el tipo de vehículo y devuelve un valor Boolean que indica si necesitas una licencia para ese tipo de vehículo.

```jq
"car" | needs_license
# => true

"bike" | needs_license
# => false
```

## 2. Elige entre dos posibles vehículos para comprar

Has evaluado tus opciones de vehículos disponibles.
Lograste reducirlas a dos opciones, pero necesitas ayuda para tomar la decisión final.
Implementa la función `choose_vehicle` que recibe un array de dos vehículos como argumento y devuelve una decisión, que es la opción que aparece primero en el orden del diccionario.

```jq
["Wuling Hongguang", "Toyota Corolla"] | choose_vehicle
# =>  "Toyota Corolla is clearly the better choice."

["Volkswagen Beetle", "Volkswagen Golf"] | choose_vehicle
# =>  "Volkswagen Beetle is clearly the better choice."
```

## 3. Calcula una estimación del precio de un vehículo usado

Ahora que has tomado tu decisión, quieres asegurarte de obtener un precio justo en la concesionaria.
Como te interesa comprar un vehículo usado, el precio depende de la edad del vehículo.
Para una estimación aproximada, supón que si el vehículo tiene menos de 3 años, cuesta el 80% del precio original que tenía cuando era nuevo.
Si tiene más de 10 años, cuesta el 50%.
Si el vehículo tiene al menos 3 años pero no más de 10, cuesta el 70% del precio original.

Implementa la función `resell_price` que aplica esta lógica usando `if`, `elif` y `else`.
Recibe un objeto que contiene el precio original y la edad del vehículo, y devuelve el precio estimado en la concesionaria.

```jq
{"original_price": 1000, "age": 1} | resell_price
# => 800

{"original_price": 1000, "age": 5} | resell_price
# => 700

{"original_price": 1000, "age": 15} | resell_price
# => 500
```
