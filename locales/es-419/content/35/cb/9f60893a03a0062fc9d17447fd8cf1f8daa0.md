# Operador ternario

El operador ternario ofrece una sintaxis alternativa para hacer una comparación `if..else..` y devolver un valor.

## Sintaxis

PHP ofrece una sentencia condicional en la que se puede evaluar una acción según la «veracidad» de una condición.

```php
if ($condition) {
  $value = 1;
} else {
  $value = 2
}
```

Como alternativa, el operador ternario puede representar la misma operación:

```php
$value = $condition
  ? 1  // True branch
  : 2; // False branch
```

La sintaxis de comparación es corta y se representa con `(condition) ? (evaluate if true) : (evaluate if false);`.
