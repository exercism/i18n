# Instrucciones

En este ejercicio es el Día de San Valentín, y tú y tu pareja están planeando hacer algo lindo juntos. Tu pareja tiene muchas ideas y ahora te pide que las califiques para encontrar la actividad que van a hacer.

Tu pareja propone las siguientes ideas:

- Jugar un juego de mesa
- Relajarse
- Ver una película
- Ir a un restaurante

Tienes seis tareas para ayudarte a elegir tu actividad del Día de San Valentín.

## 1. Define la aprobación

Para cada idea que propone tu pareja, respondes con una de tres opciones: sí, no o tal vez.

Define el tipo personalizado `Approval` para representar estas opciones con los siguientes tres casos: `Yes`, `No` y `Maybe`.

## 2. Define las cocinas

Tu pareja eligió dos restaurantes posibles: uno de cocina coreana y el otro de cocina turca.

Define el tipo personalizado `Cuisine` para representar estas cocinas con los siguientes dos casos: `Korean` y `Turkish`.

## 3. Define los géneros de películas

Hay muchísimas películas entre las que elegir, así que, para reducir las opciones, tu pareja también indica su género.

Define el tipo personalizado `Genre` para representar los siguientes géneros como casos: `Crime`, `Horror`, `Romance` y `Thriller`.

## 4. Define la actividad

Como ya se dijo, tu pareja propuso cinco actividades diferentes: jugar un juego de mesa, relajarse, ver una película e ir a un restaurante.

Define el tipo personalizado `Activity` para representar estos tipos de actividad:

- `BoardGame`: sin datos asociados.
- `Chill`: sin datos asociados.
- `Movie`: tiene su `Genre` como dato asociado.
- `Restaurant`: tiene su `Cuisine` como dato asociado.

## 5. Califica la actividad

Por último, ya puedes calificar las ideas de tu pareja. Esto es lo que piensas de cada idea:

- Jugar un juego de mesa: no.
- Relajarse: no.
- Ver una película: sí si es una película romántica; si no, no.
- Ir a un restaurante: sí si la cocina es coreana, tal vez si es turca.

Implementa una función llamada `rateActivity` que recibe un valor `Activity` y devuelve el `Approval` según los sentimientos anteriores:

```elm
rateActivity (Restaurant Turkish)
-- => Maybe
```
