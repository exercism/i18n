# Introducción

Cuando una quotation necesita *recordar* valores de su entorno, lo que otros lenguajes llaman un *closure*, Factor usa dos herramientas: la palabra `curry` y la sintaxis *fry* `'[ ]`.

## `curry`: cómo capturar un valor

`curry` (en [`kernel`][kernel]) toma un valor y una quotation y devuelve una nueva quotation con ese valor ya incorporado:

```
curry ( value quot -- newquot )
```

```factor
3 [ + ] curry .
! => [ 3 + ]

10 3 [ + ] curry call .
! => 13
```

Aplica `curry` dos veces para capturar dos valores:

```factor
2 3 [ + + ] curry curry .
! => [ 2 3 + + ]
```

## `compose`: unir dos quotations

`compose` (en [`kernel`][kernel]) une dos quotations:

```
compose ( quot1 quot2 -- quot )
```

```factor
[ 1 + ] [ 2 * ] compose .
! => [ 1 + 2 * ]

5 [ 1 + ] [ 2 * ] compose call .
! => 12
```

## Las fry quotations: capturar varios valores

Cuando hay más de una o dos capturas, las llamadas encadenadas a `curry` se vuelven difíciles de leer. *Fry* usa `'[ … ]` con uno o más marcadores de posición `_`; cada `_` se reemplaza por un valor tomado de la pila de datos, en orden:

```factor
2 3 '[ _ _ + + ] .
! => [ 2 3 + + ]
```

Tanto `curry` como fry *consumen* sus valores de la pila en el momento en que se construye el closure. La línea anterior no deja nada en la pila y es un reemplazo directo de `[ + + ] curry curry`.

Los marcadores de posición se llenan de izquierda a derecha con los valores de la pila de abajo hacia arriba: `2 3 '[ _ _ ]` es `[ 2 3 ]`, no `[ 3 2 ]`.

Fry también llega *dentro* de quotations anidadas, lo que te permite colocar los valores capturados exactamente donde los quieras:

```factor
2 '[ [ _ > ] filter ] { 1 2 3 4 5 } swap call( s -- s ) .
! => { 3 4 5 }
```

El `_` está dentro del `[ … ]` interno, pero fry igual lo llena.

## `call` con un efecto declarado

Cuando finalmente ejecutes una quotation almacenada, declara su efecto de pila en `call` para que el compilador pueda verificar sus tipos:

```factor
{ 3 4 5 } [ first2 + ] call( p -- n ) .
! => 7

{ 3 4 5 } [ first ] call( p -- n ) .
! => 3
```

## Aritmética de vectores

El vocabulario [`math.vectors`][math.vectors] combina dos secuencias de la misma longitud elemento por elemento. `v+` y `v*` las suman o las multiplican; `vmax` y `vmin` conservan el mayor o el menor de cada componente. Cada uno devuelve un array de dos elementos:

```factor
{ 1 1 } { 3 4 } v+ .    ! => { 4 5 }
{ 2 5 } { 3 -1 } v* .   ! => { 6 -5 }
{ 1 9 } { 4 4 } vmax .  ! => { 4 9 }
{ 1 9 } { 4 4 } vmin .  ! => { 1 4 }
```
