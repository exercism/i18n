# Integraciones de Babashka con editores de texto

## nREPL

### Emacs: [CIDER](https://cider.mx/)

Este es el que lo empezó todo, y su ecosistema [Orchard](https://metaredux.com/posts/2018/11/09/ciders-orchard-the-heart.html) impulsa muchos de los otros complementos.

1. Instala [Emacs](https://www.gnu.org/software/emacs/download.html) para tu plataforma.

2. Elige una distribución de Emacs ya existente ([Prelude](https://prelude.emacsredux.com/), [Spacemacs](https://www.spacemacs.org/) y [Doom Emacs](https://github.com/hlissner/doom-emacs) son excelentes) o agrega esto a tu `init.el`:

```elisp
(unless (package-installed-p 'cider)
  (package-install 'cider))
  
(add-hook 'clojure-mode-hook #'cider-mode)
```

Resumen de la [documentación de CIDER](https://docs.cider.mx/cider/platforms/babashka.html):

Inicia el servidor nREPL desde el directorio del proyecto:

```bash
$ bb --nrepl-server
```

Crea o abre cualquier archivo de Clojure (`.clj`) con `C-x C-f` y conéctate a él usando `C-c C-x c j` (cider-connect-clj).

Los [atajos de teclado básicos de CIDER](https://docs.cider.mx/cider/usage/cider_mode.html#key-reference):

* `cider-load-buffer` - `C-c C-k`
* `cider-eval-last-sexp` - `C-x C-e` o `C-c C-e`
* `cider-eval-defun-at-point` - `C-M-x` o `C-c C-c`

### VSCode: [Calva](https://github.com/BetterThanTomorrow/calva)

1. Instala [VSCode](https://code.visualstudio.com/).

2. Instala [Calva](https://marketplace.visualstudio.com/items?itemName=betterthantomorrow.calva).

Actualmente, Calva interpreta que tu código fuente está en el contexto de una carpeta, es decir, un proyecto de Clojure. Una buena forma de crear uno es con [clj-new](https://github.com/seancorfield/clj-new):

```bash
$ clj -A:new lib myorg/bbtest
Generating a project called bbtest based on the 'lib' template.
The lib template is intended for library projects, not applications.
```
3. Inicia el servidor nREPL desde el directorio del proyecto:

```bash
$ cd bbtest
bbtest$ bb --nrepl-server 1667
Started nREPL server at localhost:1667
For more info visit https://github.com/borkdude/babashka/blob/master/doc/repl.md#nrepl.
```

Abre la carpeta del proyecto en VSCode (Ctrl+K Ctrl+O) o desde otra terminal:

```bash
$ cd bbtest
bbtest$ code .
```

4. En VSCode, ejecuta el comando de Calva `Connect to a running REPL` (ctrl+alt+c ctrl+alt+c). Cuando se te pida, elige el proyecto `Generic` e ingresa `localhost:1667`.

Comandos del REPL:

* `Load Current File and Dependencies` ctrl+alt+c enter
* `Evaluate Current Form Inline` ctrl+alt+c e
* `Evaluate Current Top Level Form (defun)` ctrl+alt+c space

### IntelliJ: [Cursive](https://cursive-ide.com/)

1. Descarga IntelliJ [aquí](https://www.jetbrains.com/idea/download/index.html).
2. Instala Cursive siguiendo la [guía de usuario](https://cursive-ide.com/userguide/) y [configura las dependencias](https://cursive-ide.com/userguide/deps.html).
3. Consulta [Cursive: Working with Babashka](https://cursive-ide.com/userguide/babashka.html) para más información.

## Socket REPL

### Atom: [chlorine](https://github.com/mauricioszabo/atom-chlorine)

1. Instala [atom](https://flight-manual.atom.io/getting-started/sections/installing-atom/)

2. Instala el paquete `chlorine`

3. Inicia el REPL de socket:

 ```
$ bb --socket-repl 1666
Babashka socket REPL started at localhost:1666
 ```

4. Abre la paleta de comandos de Atom (ctrl+shift+p) y ejecuta el comando `Connect Clojure Socket REPL` con `localhost` `1666`

5. Edita los atajos de teclado en keymap.cson desde el menú `Edit` -> `Keymap...`:

```
'atom-text-editor[data-grammar="source clojure"]':
  'ctrl-; y':       'chlorine:connect-clojure-socket-repl'
  'ctrl-; e':       'chlorine:disconnect'
  'ctrl-; k':       'chlorine:clear-console'
  'ctrl-shift-enter':       'chlorine:load-file'
  'ctrl-enter':       'chlorine:evaluate-block'
  'shift-enter':       'chlorine:evaluate-top-block'
  'ctrl-; i':       'chlorine:inspect-block'
  'ctrl-; I':       'chlorine:inspect-top-block'
  'ctrl-; s':       'chlorine:evaluate-selection'
  'ctrl-; c':       'chlorine:break-evaluation'
  'ctrl-; S':       'chlorine:source-for-var'
  'ctrl-; d':       'chlorine:doc-for-var'
  'ctrl-; x':       'chlorine:run-tests-in-ns'
  'ctrl-; t':       'chlorine:run-test-for-var'
```

### Emacs: [inf-clojure](https://github.com/clojure-emacs/inf-clojure)

Para Emacs, instala [inf-clojure](https://github.com/clojure-emacs/inf-clojure) agregando esto a tu `init.el`:

```
(unless (package-installed-p 'inf-clojure)
  (package-refresh-contents)
  (package-install 'inf-clojure))

(add-hook 'clojure-mode-hook #'inf-clojure-minor-mode)
```

Inicia el REPL de socket como se indicó antes y, en Emacs, ejecuta `M-x inf-clojure-connect` (C-c M-c).

Evalúa las formas con C-c C-e. Para ver una lista de todos los comandos disponibles en inf-clojure-mode (también conocido como el REPL) y en inf-clojure-minor-mode, puedes invocar C-h f RET inf-clojure-mode y C-h f RET inf-clojure-minor-mode, o simplemente explorar sus menús.

### Vim: [vim-iced](https://github.com/liquidz/vim-iced)

Descarga el [appimage de Neovim](https://github.com/neovim/neovim/releases/download/v0.4.3/nvim.appimage) y asígnale el alias `vim`.

* Instala [vim-plug](https://github.com/junegunn/vim-plug):

```
$ curl -fLo ~/.local/share/nvim/site/autoload/plug.vim --create-dirs \
    https://raw.githubusercontent.com/junegunn/vim-plug/master/plug.vim
```

Crea `~/.config/nvim/init.vim`:

```
call plug#begin('~/.vim/plugged')

Plug 'liuchengxu/vim-clap'
Plug 'guns/vim-sexp',    {'for': 'clojure'}
Plug 'liquidz/vim-iced', {'for': 'clojure'}

call plug#end()

" Enable vim-iced's default key mapping
" This is recommended for newbies
let g:iced_enable_default_key_mappings = v:true
```

Abre Neovim y ejecuta el comando `:PlugInstall`.

Agrega el comando `iced` al $PATH:

`$ export PATH=$PATH:~/.vim/plugged/vim-iced/bin`

* Inicia el servidor de REPL de socket, abre el archivo fuente y ejecuta `:IcedConnectSocketRepl 1666`.

Comandos predeterminados del REPL (el `<Leader>` predeterminado es `\`):

- `<Leader>ei` : Evalúa el elemento interno
- `<Leader>ee` : Evalúa la lista externa
- `<Leader>et` : Evalúa la lista superior externa
