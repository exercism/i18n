# Introducción

## Comprensiones de listas

Las comprensiones ofrecen un mecanismo para transformar _Enumerables_ de forma fácil y declarativa.

Para declarar una comprensión muy simple, podemos usar la palabra clave `for` seguida de un _generador_ y un _bloque do_ que crea los nuevos valores a partir de los valores enumerados.

```elixir
for n <- [0, 1, 2, 3], do: n + 1
# => [1, 2, 3, 4]
```

Las comprensiones también pueden tener _filtros_. Los valores que no pasan el filtro se eliminan de la lista final:

```elixir
for n <- [0, 1, 2, 3], n > 1, do: n + 1
# => [3, 4]
```

Podemos declarar comprensiones más complicadas en varias líneas:

```elixir
for {atom, number} <- [a: 1, b: 2, c: 3, d: 4],
    rem(number, 2) == 0 do
  atom
end

# => [:b, :d]
```

Se puede crear un _producto cartesiano_ usando varios generadores. Eso significa que cada valor generado por el primer generador se emparejará una vez con cada valor generado por el segundo generador:

```elixir
for x <- [0, 1],
    y <- [0, 1] do
  {x, y}
end

# => [{0, 0}, {0, 1}, {1, 0}, {1, 1}]
```
