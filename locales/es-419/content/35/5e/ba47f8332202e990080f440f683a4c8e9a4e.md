# Instrucciones

Trabajas en una tienda de moda en línea.
Se te ocurre la idea de una funcionalidad del sitio web en la que se le sugieren conjuntos al usuario.
Lo que interesa son los posibles conjuntos, sus precios y eliminar las opciones que no combinan.

~~~~exercism/note
Aunque puede haber distintas maneras de resolver los siguientes problemas, todos se pueden resolver con una comprensión.
~~~~

## 1. Crea un artículo de ropa


Implementa `clothingitem()` para que reciba dos `Tuple`, uno de `categories` y el otro de sus respectivas `qualities`.
La función debe devolver un `Dict` con las `categories` como claves y las `qualities` como valores.

```julia-repl
julia> categories = ("item_name", "price", "color", "base_color");

julia> qualities = ("Descriptive Name", 99.00, "Ochre Red", "red");

julia> clothingitem(categories, qualities)
Dict{String, Any} with 4 entries:
  "price"      => 99.0
  "item_name"  => "Descriptive Name"
  "base_color" => "red"
  "color"      => "Ochre Red"
```

Tu función debe poder manejar cualquier cantidad de `categories`.

## 2. Sugiere combinaciones

Implementa `get_combinations()` para que reciba un `Tuple` de prendas de arriba y un `Tuple` de prendas de abajo.
La función debe devolver el `cartesian product` de las tuplas como un array bidimensional (es decir, una `Matrix`).
Cada entrada es una combinación `(top, bottom)` como `Tuple`.
Las prendas de arriba cambian al bajar por las filas y las prendas de abajo cambian al avanzar por las columnas.

```julia-repl
julia> tops = (
        Dict("item_name" => "Dress shirt"),
        Dict("item_name" => "Casual shirt")
        );

julia> bottoms = (
        Dict("item_name" => "Jeans"),
        Dict("item_name" => "Dress trousers")
       );

julia> get_combinations(tops, bottoms)
2×2 Matrix{Tuple{Dict{String, String}, Dict{String, String}}}:
 (Dict("item_name"=>"Dress shirt"), Dict("item_name"=>"Jeans"))   (Dict("item_name"=>"Dress shirt"), Dict("item_name"=>"Dress trousers"))
 (Dict("item_name"=>"Casual shirt"), Dict("item_name"=>"Jeans"))  (Dict("item_name"=>"Casual shirt"), Dict("item_name"=>"Dress trousers"))
```

## 3. Suma los precios de los conjuntos

Cada prenda de ropa tiene un campo `price` asociado, así que podría ser útil poder comparar el precio total de los conjuntos.
Implementa `get_prices()`, que recibe un array de combinaciones de prendas.
La función debe devolver un array con la misma forma, con los precios de los conjuntos en sus respectivas posiciones.

```julia-repl
julia> tops = (
        Dict("item_name" => "Dress shirt", "base_color" => "blue", "price" => 35),
        Dict("item_name" => "Casual shirt", "base_color" => "black", "price" => 20)
       );

julia> bottoms = (
        Dict("item_name" => "Jeans", "base_color" => "blue", "price" => 30),
        Dict("item_name" => "Dress trousers", "base_color" => "black", "price" => 75)
       );

julia> combomatrix = get_combinations(tops, bottoms);

julia> get_prices(combomatrix)
2×2 Matrix{Int}::
 65  110
 50   95

julia> filteredmatrix = filter_clashing(combomatrix)
1-element Vector{Tuple{Dict{String, Any}, Dict{String, Any}}}:
 (Dict("price" => 20, "item_name" => "Casual shirt", "base_color" => "black"), Dict("price" => 30, "item_name" => "Jeans", "base_color" => "blue"))

julia> get_prices(filteredmatrix)
1-element Vector{Int}:
 50
```

## 4. Filtra los conjuntos que no combinan

Cada prenda de ropa tiene un campo `base_color`.
Usa este campo para eliminar todas las combinaciones en las que la prenda de arriba y la de abajo tienen el mismo color base.
Implementa `filter_clashing()` para que reciba un array de combinaciones de prendas.
Devuelve un array unidimensional (es decir, un `Vector`) con las combinaciones que pasan el filtro.

```julia-repl
julia> tops = (
        Dict("item_name" => "Dress shirt", "base_color" => "blue", "price" => 35),
        Dict("item_name" => "Casual shirt", "base_color" => "black", "price" => 20)
       );

julia> bottoms = (
        Dict("item_name" => "Jeans", "base_color" => "blue", "price" => 30),
        Dict("item_name" => "Dress trousers", "base_color" => "black", "price" => 75)
       );

julia> combos = get_combinations(tops, bottoms);

julia> filter_clashing(combos)
1-element Vector{Tuple{Dict{String, Any}, Dict{String, Any}}}:
 (Dict("price" => 20, "item_name" => "Casual shirt", "base_color" => "black"), Dict("price" => 30, "item_name" => "Jeans", "base_color" => "blue"))
```
