# Instrucciones

En este ejercicio vas a procesar líneas de log.

Cada línea de log es un string con el formato `"[<LEVEL>]: <MESSAGE>"`.

Hay tres niveles de log: `INFO`, `WARNING` y `ERROR`.

Tienes tres tareas. Cada una toma una sola línea de log de la pila.

## 1. Obtén el mensaje de una línea de log

Define `message` para que devuelva el mensaje de la línea de log. Hay que eliminar los espacios en blanco al principio o al final.

```factor
"[ERROR]: Invalid operation" message .
! => "Invalid operation"

"[WARNING]:  Disk almost full\r\n" message .
! => "Disk almost full"
```

## 2. Obtén el nivel de log de una línea de log

Define `log-level` para que devuelva el nivel de la línea de log, en minúsculas.

```factor
"[ERROR]: Invalid operation" log-level .
! => "error"
```

## 3. Reformatea una línea de log

Define `reformat` para que ponga el mensaje primero y, después, el nivel de log en minúsculas entre paréntesis.

```factor
"[INFO]: Operation completed" reformat .
! => "Operation completed (info)"
```

----

***Nota:*** Todos los strings de este ejercicio son ASCII. Los ejercicios posteriores abordarán el manejo de strings que tenga en cuenta Unicode.
