# Introducción

## Reducción

La reducción es la aplicación repetida de una función a cada elemento de una secuencia, acumulando de alguna manera los resultados.
La función que se aplica toma dos parámetros: el valor acumulado actual y el elemento a procesar.
Debe dar como resultado el nuevo valor acumulado.

En Common Lisp, el proceso se hace con la función `reduce`.
En su forma más simple, se ve así:

`(reduce #'function-to-apply sequence :initial-value value)`

Fíjate que se proporciona un valor inicial: este será el «valor acumulado actual» que se pasa a la función cuando se procesa el primer elemento.

Aquí hay un ejemplo que suma entre sí los números del array, empezando con un valor inicial de 10:

`(reduce #'+ '(1 2 3 4) :initial-value 10) ; => 20`

Nota que si la secuencia está vacía, la función nunca se llama y la forma evalúa al valor inicial.
