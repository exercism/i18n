# Instrucciones

Te encanta observar aves y llevas la cuenta de cuántas han visitado tu jardín en los últimos siete días.

Tienes seis tareas, todas relacionadas con el número de aves que visitaron tu jardín.

## 1. Comprueba cuántas aves visitaron hoy

Implementa la función `today()` para que devuelva cuántas aves visitaron tu jardín hoy. Los conteos de aves están ordenados por día: el primer elemento es el conteo del día más antiguo y el último es el conteo de hoy.

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
today(birds_per_day)
# => 1
```

## 2. Incrementa el conteo de hoy

Implementa la función `increment_todays_count()` para incrementar el conteo de hoy:

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
increment_todays_count(birds_per_day)
# => c(2, 5, 0, 7, 4, 2)
```

## 3. Comprueba si hubo un día sin aves visitantes

Implementa la función `has_day_without_birds()` que devuelve `TRUE` si hubo un día en el que cero aves visitaron el jardín; de lo contrario, devuelve `FALSE`:

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
has_day_without_birds(birds_per_day)
# => true
```

## 4. Calcula el número de aves visitantes durante los primeros días

Implementa la función `count_for_first_days()` que devuelve el número de aves que han visitado tu jardín desde el inicio de la semana, pero limita el conteo al número de días especificado desde el inicio de la semana.

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
count_for_first_days(birds_per_day, 4)
# => 14
```

## 5. Calcula el número de días ajetreados

Algunos días son más ajetreados que otros. Un día ajetreado es aquel en el que cinco o más aves han visitado tu jardín.
Implementa la función `busy_days()` para que devuelva el número de días ajetreados:

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
busy_days(birds_per_day)
# => 2
```

## 6. Calcula el total acumulado de visitas de aves durante la última semana

Tienes curiosidad por saber cuántas aves han visitado en total lo que va de la semana.
Calcula los totales acumulados para cada día.

```R
running_total(c(7, 6, 5, 4, 3, 2, 1))
#> [1]  7 13 18 22 25 27 28
```

## 7. Ordena los nombres de los días según qué tan ajetreados son

Sospechas que las visitas de aves se ven afectadas por los patrones del tráfico de las carreteras cercanas, que son distintos los fines de semana y entre semana.

Ordena las abreviaturas de los días en orden _descendente_ según cuántas aves visitaron.

```R
day_names <- c("Mon", "Tue", "Wed", "Thu", "Fri", "Sat", "Sun")
birds_per_day <- c(5, 2, 4, 6, 0, 9, 8)
busy_days_of_week(birds_per_day, day_names)
#> [1] "Sat" "Sun" "Thu" "Mon" "Wed" "Tue" "Fri"
```
