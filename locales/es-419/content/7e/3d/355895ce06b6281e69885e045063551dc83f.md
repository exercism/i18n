Diseña un conjunto de pruebas para una herramienta que cuente líneas, letras y caracteres.

Este es un ejercicio especial.
En lugar de crear código que funcione con un conjunto de pruebas existente, tú defines el conjunto de pruebas.
Para ayudarte, se han proporcionado varias variaciones del código bajo prueba; tu conjunto de pruebas debería ser capaz al menos de detectar los problemas (o la ausencia de ellos) en ellas.

Se supone que el sistema bajo prueba es un sistema que cuenta el número de líneas, letras y caracteres totales en los strings que se le pasan.
La idea es que realices la operación «add string» varias veces, pasando strings, y que después llames a las funciones «lines», «letters» y «characters» para obtener los totales.
