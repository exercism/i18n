# El operador ternario

Un operador ternario es una forma más corta de escribir sentencias `if/else` simples.
Si una sentencia `if/else` contiene solo dos ramas, una para cuando la condición es true y otra para cuando es false, se puede reescribir como un operador ternario.

Los operadores ternarios usan una combinación de los símbolos `?` y `:` para dividir una condicional:
```ruby
condition ? true_branch : false_branch
```

El código a la izquierda del `?` es la condición y el código a la derecha contiene las dos ramas posibles, separadas por `:`.
Si la condición es _true_, se ejecuta el código a la _izquierda_ del `:`.
Si la condición es _false_, se ejecuta el código a la _derecha_ del `:`.

Por ejemplo:

```ruby
if traffic_light == 'green'
  cross_the_road
else
  wait
end
```

se puede reescribir como:

```ruby
traffic_light == 'green' ? cross_the_road : wait
```
