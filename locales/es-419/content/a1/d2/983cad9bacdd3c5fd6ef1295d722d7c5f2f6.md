# Introducción

## Definir variables

Definir una variable significa asignarle un valor a un nombre. En Scala hay dos tipos de variables: vals y vars.

Un `val` es inmutable, así que su valor ya no se puede cambiar después de la primera asignación:

```scala
val numberTen = 10

numberTen = 11
// --> raises a compile error "reassignment to val"
```

Un `var`, en cambio, se puede reasignar a un nuevo valor del mismo tipo:

```scala
var someNumber = 10

someNumber = 11
// now someNumber has been reassigned
```

Scala es un lenguaje de tipado estático, lo que significa que todo tiene un tipo en tiempo de compilación. Una variable se puede definir especificando explícitamente su tipo o dejando que el compilador de Scala infiera su tipo a partir del valor asignado (lo que se conoce como inferencia de tipos). Por lo tanto, las siguientes dos definiciones de variable son equivalentes:

```scala
val explicitNumber: Int = 10; // Explicitly typed
val implicitNumber = 10; // Implicitly typed
```

Una vez definida, el tipo de una variable nunca puede cambiar.

```scala
var count = 1; // Assigning an initial value of type Int
count = 2;     // Updating to new value is possible, because it is defined as var

count = false;
// --> raises a compile error "type mismatch"
```

## Definir métodos dentro de clases

Scala es un _lenguaje orientado a objetos_ y requiere que todos los métodos se definan dentro de una _clase_. La palabra clave `class` se usa para definir una clase.

```scala
class Calculator {
  // ...
}
```

Dentro de una clase, los métodos se definen empezando con la palabra clave `def`, seguida de un nombre. Cada método puede tener cero o más parámetros, que se enumeran separados por comas dentro de paréntesis. Todos los parámetros deben tener un tipo explícito: para los parámetros no hay inferencia de tipos. Después de la lista de parámetros, se define el tipo de retorno del método, separado por otros dos puntos.

A la definición del método le sigue un signo `=`, con el que empieza el cuerpo del método. En el siguiente ejemplo, el cuerpo del método consta de dos sentencias, que van encerradas entre llaves.

El método devolverá el valor de la última expresión; en este caso, el método `add` devuelve el valor de la variable `sum`:

```scala
class Calculator {
  // long form
  def add(x: Int, y: Int): Int = {
    val sum = x + y
    sum
  }
}
```

Hay algunas mejoras que se pueden hacer para acortar ese método y mejorar su legibilidad:

- como solo se accede a la variable `sum` una vez para devolver el valor, se puede omitir
- los métodos que constan de una sola sentencia no necesitan llaves
- el tipo de retorno del método se puede inferir igual que el tipo de las variables

Esto da como resultado el siguiente método de una sola línea con la misma funcionalidad:

```scala
class Calculator {
  // shortened form
  def add(x: Int, y: Int) = x + y
}
```

## Instanciar clases y llamar a métodos

Para invocar un método, primero se crea una instancia de una clase y luego se llama al método en esa instancia con argumentos:

```scala
val calculator = new Calculator()
val sum = calculator.add(5, 7)
// sum is of type Int with assigned value of 12
```

## Comentarios

Scala admite dos tipos de comentarios: los de una sola línea y los de varias líneas:

```scala
// this is a single line comment

/*
This comment spans across
multiple lines.
*/
```
