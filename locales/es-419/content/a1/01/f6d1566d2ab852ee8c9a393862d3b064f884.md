# Pistas

## General

En este ejercicio vas a escribir filtros de `jq` para cuatro tareas.
Como un programa de `jq` es _una sola expresión_, esos cuatro filtros deben unirse con comas.
Usa paréntesis alrededor de las subexpresiones para controlar el orden de las operaciones.

## 1. Extrae el nombre de la lista de compras

- Se puede acceder al contenido del archivo con el filtro `.`.
- Se puede acceder a la propiedad de un objeto con la notación de punto o la notación de corchetes.

## 2. Cuenta cuántos ingredientes se necesitan

- Necesitas producir la longitud de un array.

## 3. ¿Cuánta azúcar?

- Necesitas seleccionar el ingrediente llamado «sugar».
- Necesitas acceder a una de sus propiedades.

## 4. Mapea los ingredientes que se pueden sustituir

- Necesitas concatenar dos arrays.
- Necesitas seleccionar elementos específicos del array resultante.
- Necesitas generar un objeto clave:valor para cada uno de estos elementos.
- Necesitas combinar estos objetos en un solo objeto.
