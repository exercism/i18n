# Instrucciones

Estás ejecutando un sistema que consta de unas cuantas aplicaciones que producen muchos logs. Quieres escribir un pequeño programa que agrupe esos logs y les asigne etiquetas según su nivel de gravedad. Todas las aplicaciones de tu sistema usan los mismos códigos de log, pero algunas de las aplicaciones heredadas no admiten todos los códigos.

| Log code              | Log label | Supported in legacy apps? |
|-----------------------| --------- | ------------------------- |
| 0                     | trace     | no                        |
| 1                     | debug     | sí                        |
| 2                     | info      | sí                        |
| 3                     | warning   | sí                        |
| 4                     | error     | sí                        |
| 5                     | fatal     | no                        |
| other / not supported | unknown   | -                         |

## 1. Determina la etiqueta del log

Implementa la función `LogLevel.to_label/2`. Debe recibir un código entero y un valor de tipo Boolean que te indica si el log proviene de una aplicación heredada, y devolver la etiqueta de una línea de log como un átomo.

Los códigos de log que no se especifican en la tabla deben devolver la etiqueta _unknown_. Los códigos de log que la tabla indica como no compatibles con las aplicaciones heredadas también deben devolver la etiqueta _unknown_ si el log proviene de una aplicación heredada.

```elixir
LogLevel.to_label(0, false)
# => :trace

LogLevel.to_label(0, true)
# => :unknown
```

## 2. Envía una alerta

Hay que notificar a alguien cuando ocurren cosas inesperadas.

Implementa la función `LogLevel.alert_recipient/2` para determinar a quién se debe enviar la alerta. La función debe recibir un código entero y un valor de tipo Boolean que te indica si el log proviene de una aplicación heredada, y devolver el nombre del destinatario como un átomo.

Usa la función `LogLevel.to_label/2` de la tarea anterior. Si la etiqueta del log es _error_ o _fatal_, envía la alerta al equipo _ops_. Si recibes un log con la etiqueta _unknown_ de un sistema heredado, envía la alerta al equipo _dev1_; las demás etiquetas unknown deben enviarse al equipo _dev2_. Todas las demás etiquetas de log se pueden ignorar sin problema devolviendo _false_.

```elixir
LogLevel.alert_recipient(-1, true)
# => :dev1

LogLevel.alert_recipient(0, false)
# => false
```
