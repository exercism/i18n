# Tests

## Ejecutar tests

Ejecuta la especificación de tests con:

```bash
$ gradle test
```

## Habilitar más tests

Una vez que tu código pase todos los tests activos, habilita otro test quitando el `@Ignore` que precede al siguiente test que te interese. Hazlo eliminando la línea `@Ignore` o coméntala agregando dos barras al inicio de la línea.

```Groovy
//@Ignore
def 'outputs "Hello, Alice!" when given the name "Alice"'() {
    expect: hello.hello('Alice') == 'Hello, Alice!'
}
```
