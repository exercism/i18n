# Tests

## Ejecutar los tests

Una vez completados los [pasos de instalación][test-installation-steps], ya puedes empezar desde el directorio de cualquier ejercicio (por ejemplo, `~/exercism/gdscript/two-fer`) y ejecutar el script (que está un nivel más arriba, en `../`) para probar tu solución local de ese ejercicio:

```sh
../test-local-gdscript-solution.sh
```

## Resolver un ejercicio

Resolver un ejercicio significa lograr que todos sus tests pasen.

Para ayudarte a empezar, cada ejercicio incluye un archivo GDScript con el nombre del ejercicio (por ejemplo, `exercism/gdscript/two-fer/two_fer.gd`).
Puedes usar este archivo como punto de partida para construir tu solución.
No dudes en cambiarlo según lo necesites, pero los tests esperan que los nombres de las funciones sean los que se proporcionaron originalmente.

[test-installation-steps]: https://exercism.org/docs/tracks/gdscript/tests
