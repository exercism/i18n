# Instrucciones

Vas a ayudar a unas parejas de secundaria a declarar su amor en las
redes sociales generando un corazón unicode con sus iniciales:

```
❤ J.  +  M. ❤
```

## 1. Limpia el nombre

Define `cleanupname`, que toma un nombre de la pila. Reemplaza cada `-`
por un espacio y luego elimina los espacios en blanco al principio y al final.

```factor
"Jane-Ann" cleanupname .
! => "Jane Ann"
```

## 2. Obtén la primera letra del nombre

Define `firstletter`, que toma un nombre. Reutiliza `cleanupname` de la
tarea anterior, luego toma el primer carácter del resultado y devuélvelo
como un string de un solo carácter.

```factor
"Jane" firstletter .
! => "J"
```

## 3. Formatea la primera letra como una inicial

Define `initial`, que toma un nombre. Reutiliza `firstletter` de la tarea
anterior, conviértela a mayúscula y luego agrégale un `.`.

```factor
"Robert" initial .
! => "R."
```

## 4. Coloca las iniciales dentro del corazón

Define `couple`, que toma dos nombres de la pila. Reutiliza `initial` de
la tarea anterior en cada nombre y luego arma el resultado:

```factor
"Blake Miller" "Riley Lewis" couple .
! => "❤ B.  +  R. ❤"
```
