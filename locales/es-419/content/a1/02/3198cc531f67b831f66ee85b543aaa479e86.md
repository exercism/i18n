# Pistas

## 1. Categorizar un número

* Las funciones `evenp` u `oddp` se pueden usar para determinar si un número es par o impar.
* La función `append` se puede usar para agregar un elemento al principio de una lista.
* Las funciones `car` y `cdr` son útiles para obtener el primer o el segundo elemento de un par.

## 2. Categorizar muchos números

* El primer parámetro de `reduce` es una función que recibe dos argumentos: el valor acumulado actual y el elemento que se va a procesar.
* `reduce` recibe un parámetro `:initial-value`, cuyo valor será el primer valor acumulado que se le pase a la función.
