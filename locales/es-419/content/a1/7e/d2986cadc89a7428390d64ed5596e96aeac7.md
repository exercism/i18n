# Pruebas

Usamos [PonyTest](https://stdlib.ponylang.io/pony_test--index/), de la biblioteca estándar, para escribir las pruebas que verifican tu solución. Para probar tu solución, compila y ejecuta tu código.

Por ejemplo, tu sesión para «Hello World» puede verse así:

```text
[red@apophenia:~/exercism/pony/hello-world]$ ponyc
Generating
 Reachability
 Selector painting
 Data prototypes
 Data types
 Function prototypes
 Functions
 Descriptors
Optimising
Writing ./hello-world.o
Linking ./hello-world

[red@apophenia:~/exercism/pony/hello-world]$ ./hello-world 
1 test started, 0 complete: hello-world/HelloWorld started
1 test started, 1 complete: hello-world/HelloWorld complete
---- Passed: hello-world/HelloWorld
----
---- 1 test ran.
---- Passed: 1
```
