# Apéndice de instrucciones

## Ejemplo de argumentos

```j
  INPUTS=: 2 ; 1 0 0 1 0 1 ; 10
```

Esto significa que tus argumentos son:
```
  0{INPUTS NB. is the input base.
  1{INPUTS NB. is the digits.
  2{INPUTS NB. is the output base.
```
## Cómo manejar argumentos no válidos

Si alguno de los argumentos no es válido, tu verbo debe devolver un `empty` (por ejemplo, `0$0` o `''`).

### Ejemplos

- Si la _base de entrada_ es menor que 2:
    ```j
      '' -: rebase 10 ; 0 0 0 0 ; 1
    ```

- Si la _base de salida_ es menor que 2:
    ```j
      '' -: rebase 1 ; 0 0 0 0 ; _7
    ```

- Si los _dígitos_ contienen valores mayores o iguales que la base de entrada:
    ```j
      '' -: rebase 10 ; 1 0 2 0 ; 2
    ```
