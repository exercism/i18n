# Introducción

Las palabras de secuencia más útiles toman una *quotation* como uno de sus argumentos para dirigir la operación:

```
each   ( seq quot -- )
map    ( seq quot -- newseq )
filter ( seq quot -- newseq )
reject ( seq quot -- newseq )
count  ( seq quot -- n )
any?   ( seq quot -- ? )
all?   ( seq quot -- ? )
```

```factor
{ 1 2 3 4 5 } [ even? ] filter .   ! => { 2 4 }
{ 1 2 3 4 5 } [ sq ] map .         ! => { 1 4 9 16 25 }
{ 1 2 3 4 5 } [ 2 > ] count .      ! => 3
```

`map-sum` (también en `sequences`) aplica una *quotation* sobre toda la secuencia y suma los resultados en una sola pasada. El mismo patrón está detrás de `sort-by` (en [`sorting`][sorting]) y de `minimum-by` / `maximum-by` (en `sequences`).

[sorting]: https://docs.factorcode.org/content/vocab-sorting.html
