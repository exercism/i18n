# Instrucciones

Eres un gran admirador del [canal de YouTube Numberphile](https://www.youtube.com/watch?v=PeUbRXnbmms) y acabas de ver un video muy interesante sobre la _sucesión de números de Lucas_. Quieres crear esta sucesión usando Elixir.

Mientras diseñas tu función, quieres hacer uso de la _evaluación perezosa_, para poder generar tantos números como quieras, pero solo si los necesitas. Así que decides usar un stream.

## 1. Detecta los argumentos no válidos

Agrega una cláusula de guarda para lanzar un error si se usa algo que no es un entero, o un entero menor que 1, para generar la sucesión. Hacer esto como primer paso evitará errores de recursión infinita en los pasos siguientes.

```elixir
LucasNumbers.generate("Hello World")
# => ** (ArgumentError) count must be specified as an integer >= 1
```

## 2. Genera los casos base

Sabes que la sucesión tiene dos números iniciales que no siguen la misma regla. Escribe dos cláusulas de caso base para devolver estos números:

```elixir
LucasNumbers.generate(1)
# => [2]

LucasNumbers.generate(2)
# => [2, 1]
```

## 3. Crea el caso generalizado

Para cualquier sucesión de más de 2 elementos, sabes que debes sumar los dos números anteriores para obtener el siguiente, y así sucesivamente. Escribe el caso generalizado.

```elixir
LucasNumbers.generate(3)
# => [2, 1, 3]

LucasNumbers.generate(4)
# => [2, 1, 3, 4]
```
