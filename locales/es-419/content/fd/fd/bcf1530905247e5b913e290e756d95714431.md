# Introducción

Un *heap* es una colección que siempre conoce su elemento más pequeño y te permite quitarlo rápidamente: la implementación natural de una *cola de prioridad*. Los heaps viven en el vocabulario [`heaps`][heaps].

`<min-heap>` construye un heap vacío cuya clave más pequeña sale primero; `<max-heap>` es su imagen espejo. Cada elemento es un *valor* que se guarda bajo una *clave*, y la clave es la prioridad:

```
<min-heap> ( -- min-heap )
heap-push  ( value key heap -- )
```

```factor
USING: heaps ;

<min-heap>
"alice" 5 pick heap-push
"bob"   2 pick heap-push
```

Un heap es *mutable*: `heap-push` lo modifica directamente. `heap-peek` devuelve el valor y la clave del frente sin quitarlos, `heap-pop` los quita y los devuelve, y `heap-pop-all` vacía el heap en una lista asociativa de pares `{ key value }` en orden de prioridad:

```
heap-peek    ( heap -- value key )
heap-pop     ( heap -- value key )
heap-pop-all ( heap -- alist )
```

```factor
USING: heaps kernel prettyprint ;

<min-heap>
"alice" 5 pick heap-push
"bob"   2 pick heap-push
dup heap-peek drop .     ! => "bob"
heap-pop-all .           ! => { { 2 "bob" } { 5 "alice" } }
```
