# Recursos

* [The Rust Programming Language](https://doc.rust-lang.org/book/) es un excelente recurso tanto para empezar con Rust como para profundizar en funcionalidades específicas del lenguaje.
* [Rust by Example](https://doc.rust-lang.org/stable/rust-by-example/) te muestra ejemplos de las cosas más comunes que vas a escribir en Rust.
* Puedes usar la [Rust API Documentation](http://doc.rust-lang.org/std/) para descubrir nuevos métodos y ver cómo funcionan.
* Puedes usar [Stack Overflow](http://stackoverflow.com/questions/tagged/rust) para buscar tu problema y ver si ya lo respondieron. También puedes hacer preguntas y responderlas.
* El [Rust User Forum](http://users.rust-lang.org) es para conversaciones generales sobre Rust.
* [/r/rust](http://www.reddit.com/r/rust/) es el subreddit oficial de Rust.
* El servidor oficial de [The Rust Programming Language](https://discord.gg/rust-lang) en [Discord](https://discordapp.com/) te sirve para hacer consultas rápidas y conversar sobre el lenguaje.
