# Instalación

## Instalar .NET

El track de C# se construye sobre la plataforma [.NET](https://dotnet.microsoft.com/learn/dotnet/what-is-dotnet), que funciona en Windows, Linux y macOS.
Para compilar proyectos de .NET, puedes usar la interfaz de línea de comandos (CLI) de .NET.
Esta CLI forma parte del .NET SDK, que puedes instalar siguiendo las [instrucciones de instalación](https://dotnet.microsoft.com/download/dotnet/8.0).
Nota: el track de C# requiere la versión 9.0 o superior del SDK.

Cuando termines la instalación, puedes verificar si la CLI se instaló correctamente ejecutando este comando en una terminal:

```bash
dotnet --version
```

Si la salida es una versión mayor o igual a `9.0.100`, el .NET SDK se instaló correctamente.

## Usar un IDE

Si quieres una experiencia de edición con más funcionalidades, probablemente te convenga usar un [IDE o entorno de desarrollo integrado](https://en.wikipedia.org/wiki/Integrated_development_environment).
Estos son los IDE más populares que admiten la compilación de proyectos de .NET:

- [Visual Studio 2022](https://www.visualstudio.com/downloads/)
- [Visual Studio Code](https://code.visualstudio.com/download) con la [extensión de C#](https://marketplace.visualstudio.com/items?itemName=ms-dotnettools.csharp)
- [Visual Studio for Mac](https://www.visualstudio.com/vs/visual-studio-mac/)
- [Project Rider](https://www.jetbrains.com/rider/download/)

Nota: como el formato de proyecto de .NET es muy distinto al de versiones anteriores, los IDE más antiguos (como Visual Studio 2015) no son compatibles.
