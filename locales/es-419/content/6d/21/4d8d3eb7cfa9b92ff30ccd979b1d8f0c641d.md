# Introducción

En Gleam hay dos tipos diferentes de números: los enteros y los números de punto flotante.

Los enteros son números sin parte decimal.

```gleam
let integer = 3
// -> 3
```

Gleam tiene varios operadores que funcionan con enteros.

```gleam
1 + 1 // -> 2
5 - 1 // -> 4
5 / 2 // -> 2
3 * 3 // -> 9
5 % 2 // -> 1

2 > 1  // -> True
2 < 1  // -> False
2 >= 1 // -> True
2 <= 1 // -> False
```
