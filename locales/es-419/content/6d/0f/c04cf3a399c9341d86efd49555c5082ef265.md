# Introducción

## IO

El módulo `IO` proporciona las funciones para manejar la entrada y la salida.

### Salida

Para escribir una string en la salida estándar, usa `IO.puts`. `IO.puts` siempre agrega una nueva línea al final de la string. Si no quieres ese comportamiento, usa `IO.write` en su lugar. Ambas funciones devuelven el átomo `:ok` si tienen éxito.

```elixir
IO.puts("Hi!")
# > Hi!
# => :ok
```

`IO.puts` es útil para escribir strings, pero no mucho más. Si necesitas una herramienta para depurar que te permita escribir cualquier valor en la salida estándar, usa `IO.inspect` en su lugar. `IO.inspect` devuelve el valor que recibió, sin cambios, así que puedes insertarlo en cualquier punto de tu código. También acepta muchas opciones, por ejemplo `:label`, que te permiten distinguirlo de otras llamadas a `IO.inspect`.

### Entrada

Para leer una línea de la entrada estándar, usa `IO.gets`. `IO.gets` acepta un argumento: una string que imprimirá como indicador para la entrada. `IO.gets` no agrega una nueva línea después del indicador, inclúyela si la necesitas.

```elixir
IO.gets("What's your name?\n")
# > What's your name?
# < Mary
# => "Mary\n"
```
