# Anexo de instrucciones

## Crea tu propio DSL

En este ejercicio, eres completamente libre de diseñar el DSL de grafos de tus sueños.

Tal vez te gustaría crear un DSL basado en listas de etiquetas y registros, así:

```roc
my_graph =
    Graph.new([
        Title("My Graph"),
        Node("a", { color: Green }),
        Node("b", { color: Blue }),
        Edge("a", "b", { style: Dotted }),
    ])
```

O quizá preferirías un DSL basado en cadenas de llamadas a funciones, así:

```roc
my_graph =
    Graph.new
        .with_title("My Graph")
        .add_node("a", Attr.new.with_color(Green))
        ...
```

¿O tal vez tengas un plan muy distinto? ¡Adelante! Las pruebas solo requieren que crees unos cuantos grafos específicos; la forma de construirlos depende totalmente de ti.

Dicho esto, un DSL suele ser mejor si es claro, conciso y no demasiado sorprendente (por ejemplo, la función `minus` está pensada para restar, no para construir una arista entre dos nodos, como en `node("a") - node("b")`).

Para duplicar la diversión, puedes intentar implementar, de forma opcional, una función `to_dot` que convierta tu grafo al formato DOT?
