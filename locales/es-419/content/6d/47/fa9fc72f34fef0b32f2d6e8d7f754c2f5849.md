# Instalación

Las soluciones de este track están escritas en ensamblador RISC-V de 32 bits y se ejecutan mediante emulación, así que no necesitas hardware RISC-V.
Cada ejercicio incluye un Makefile que compila las pruebas y las ejecuta.
Para usarlo, necesitas tres herramientas:

- [Zig][zig], que proporciona el ensamblador de RISC-V, el compilador de C y el enlazador a través de `zig cc`.
- [Make][make], que ejecuta la compilación.
- `qemu-riscv32` de [QEMU][qemu], que ejecuta el programa resultante.

## macOS

Inicia una máquina virtual de Linux con cualquier solución de virtualización que te sirva (por ejemplo, [Lima][lima]) y sigue una de las secciones sobre distribuciones de Linux que aparecen más abajo.

## Windows

Usa [Windows Subsystem for Linux][wsl] y sigue una de las secciones sobre distribuciones de Linux que aparecen más abajo.
También puedes configurar una máquina virtual de Linux.

## Debian / Ubuntu

Instala Make y los emuladores en modo usuario de QEMU:

```shell
sudo apt install make qemu-user
```

Después instala Zig 0.15.2 o posterior como se describe en [Descarga directa][zig-install].

## Fedora

Instala las tres herramientas con:

```shell
sudo dnf install zig make qemu-user
```

## Arch Linux

Instala las tres herramientas con:

```shell
sudo pacman -S zig make qemu-user
```

## openSUSE Tumbleweed

Instala las tres herramientas con:

```shell
sudo zypper install zig make qemu-linux-user
```

## Comprobar tu instalación

Confirma que se encuentren las tres herramientas:

```shell
zig version
make --version
qemu-riscv32 --version
```

Luego descarga un ejercicio con la CLI de Exercism y ejecuta sus pruebas:

```shell
exercism download --track=risc-v --exercise=hello-world
cd ~/exercism/risc-v/hello-world/
make
```
