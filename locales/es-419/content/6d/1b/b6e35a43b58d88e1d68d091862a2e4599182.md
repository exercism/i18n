# no uses funciones de listas

Por favor, no uses ningún módulo externo (como List, Enum o Stream) en tu implementación. El objetivo de este ejercicio es que crees tú mismo estas funciones básicas. Puedes usar funciones básicas de Kernel (como `Kernel.+/2` para sumar números), pero por favor no uses funciones de Kernel para listas como `++`, `--`, `hd`, `tl`, `in`, `for` y `length`.
