# Aprendizaje

## Primeros pasos con Emacs

Ya instalaste Emacs. ¿Y ahora qué?

Bueno, puedes empezar el tutorial presionando `C-h t`, y no es un mal punto de partida. El tutorial te enseñará lo básico de edición, búsqueda y navegación en Emacs.

Si nunca has usado Emacs, puede tener sentido usar un kit de inicio, que ya viene con un conjunto de configuraciones y paquetes listos para usar.

El paquete [Emacs Prelude](http://batsov.com/prelude/) ofrece un buen conjunto de valores predeterminados sensatos y paquetes.

Para instalar Emacs Prelude, ejecuta lo siguiente en una terminal:

```
curl -L https://github.com/bbatsov/prelude/raw/master/utils/installer.sh | sh
```

y asegúrate de revisar la [guía de instalación](https://prelude.emacsredux.com/en/latest/installation/) para más instrucciones.


Si conoces vim, quizás te interese el kit de inicio [Doom Emacs](https://github.com/doomemacs/doomemacs), que integra una emulación de vim impulsada por [evil-mode](https://github.com/emacs-evil/evil).

Para instalar Doom Emacs, ejecuta lo siguiente en una terminal:

```
git clone --depth 1 https://github.com/doomemacs/doomemacs ~/.emacs.d
~/.emacs.d/bin/doom install
```

y asegúrate de revisar la [guía de instalación](https://github.com/doomemacs/doomemacs#install) para más instrucciones.

## Configurar la verificación de sintaxis y el linting

Se recomienda configurar la verificación de sintaxis y el linting con [Flycheck](https://www.flycheck.org/en/latest/).

Si todavía no has agregado el repositorio [MELPA](https://melpa.org/) a tu Emacs, hazlo agregando lo siguiente a tu [archivo de inicialización](https://www.flycheck.org/en/latest/glossary.html#term-init-file)

```elisp
(require 'package)

(add-to-list 'package-archives
             '("MELPA Stable" . "https://stable.melpa.org/packages/") t)
(package-initialize)
(package-refresh-contents)
```

La instalación y configuración de Flycheck sin [use-package](https://github.com/jwiegley/use-package) se hace agregando lo siguiente a tu [archivo de inicialización](https://www.flycheck.org/en/latest/glossary.html#term-init-file)

```elisp
(package-install 'flycheck)
(add-hook 'after-init-hook #'global-flycheck-mode)
```

La instalación y configuración de Flycheck con [use-package](https://github.com/jwiegley/use-package) se hace agregando lo siguiente a tu [archivo de inicialización](https://www.flycheck.org/en/latest/glossary.html#term-init-file)

```elisp
(use-package flycheck
  :ensure t
  :init (global-flycheck-mode))
```

Para más información y solución de problemas, consulta la [documentación de Flycheck](https://www.flycheck.org/en/latest/user/troubleshooting.html).

## Aprender Emacs Lisp

La mejor documentación sobre Emacs Lisp es... ¡la que viene incluida con el propio Emacs!
para acceder a la
[Referencia de Emacs Lisp](https://www.gnu.org/software/emacs/manual/elisp.html),
escribe `C-h i` y busca la entrada de Elisp, o selecciona Help &rarr; More Manuals
&rarr; Emacs Lisp Reference.  Ten en cuenta que el manual puede faltar en algunas
distribuciones, en cuyo caso puedes encontrarlo
[en línea](https://www.gnu.org/software/emacs/manual/elisp.html).

Si nunca has usado Elisp, puedes leer la
[Introducción a Emacs Lisp](http://www.emacswiki.org/emacs/EmacsLispIntro),
que se abre de la misma manera.

## Buenas prácticas y convenciones de Emacs Lisp

El Manual de Emacs contiene una sección sobre las [Convenciones de código](https://www.gnu.org/software/emacs/manual/html_node/elisp/Coding-Conventions.html) de Emacs Lisp.
También hay una [Guía de estilo](https://github.com/bbatsov/emacs-lisp-style-guide) mantenida por la comunidad en GitHub.
