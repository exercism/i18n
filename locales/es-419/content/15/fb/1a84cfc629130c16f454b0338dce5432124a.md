# Acerca de

Un [`Array`][array] en Elm es un _arreglo_: una colección inmutable y rápida de cero o más valores del mismo tipo.
Como los arrays son inmutables, una vez que se ha construido un array, su valor nunca puede cambiar.
No existe una sintaxis literal para los arrays (como sí la hay para `List`), así que en su lugar se usa la sintaxis Array.fromList.
Por ejemplo, un `Array` con «a», «b» y «c» dentro normalmente se muestra como `Array.fromList ["a", "b", "c"]`.
Verás esto en la salida de la consola, en el depurador y en otros lugares por el estilo.

A diferencia de `List`, que es una [importación predeterminada][default-imports], el módulo `Array` se debe importar explícitamente, con `import Array` o algo similar.

Las anotaciones de tipo para `List` se pueden definir de la siguiente manera

```elm
Array String --> an array of String
Array Int --> an array of Int
```

Los arrays se pueden definir de la siguiente manera:

```elm
import Array exposing (Array)

empty : Array Char
empty = Array.empty

singleValue = Array.fromList [ 5 ] --> Array Int

repeatSingleValue = Array.repeat 2 5 --> Array.fromList [ 5, 5 ]

initialiseFromIndex = Array.initialise 3 (\index -> index * 2) --> Array.fromList [ 0, 2, 4 ]

initialisefromList = Array.fromList [ "a", "b", "c" ] --> Array.fromList [ "a", "b", "c" ]
```

Los elementos se agregan a un `Array` con `Array.push`:

```elm
twoToFour = Array.fromList [ 2, 3, 4 ]
oneToFour = Array.push 1 twoToFour --> Array.fromList [ 1, 2, 3, 4 ]
```

Para unir arrays se usa `Array.append`:

```elm
sixSeven = Array.fromList [ 6, 7 ]
eightNine = Array.fromList [ 8, 9 ]
Array.append sixSeven eightNine --> Array.fromList [ 6, 7, 8, 9 ]
```

Un elemento de un `Array` se obtiene con `Array.get`:

```elm
sixSeven = Array.fromList [ 6, 7 ]
Array.get 0 sixSeven --> Just 6
```

Un elemento de un `Array` se establece con `Array.set`:

```elm
sixSeven = Array.fromList [ 6, 7 ]
Array.set 1 8 sixSeven --> Array.fromList [ 6, 8 ]
```

Los arrays se manipulan con funciones definidas en el [módulo `Array`][array-module].

```elm
oneTwo = Array.fromList [ 1, 2 ]
Array.length oneTwo --> 2
```

Cualquier función u operador que parezca modificar un `Array` (como agregar un elemento) en realidad devolverá un `Array` nuevo.
Sin embargo, el rendimiento por lo general no es un problema, ya que la implementación de `Array` evita asignaciones y copias innecesarias.
