# Introducción

El módulo [`fractions`][fractions] nos permite crear y trabajar con [`rational numbers`][rational]: fracciones con un numerador entero dividido por un denominador entero.
Por ejemplo, podemos guardar `2/3` como una fracción exacta en lugar del valor aproximado `0.6666...` de tipo `float`.

A diferencia de los números `int`, `float` y `complex`, las fracciones no tienen una forma literal.
Sin embargo, el constructor de fracciones es bastante flexible.

Lo más obvio es que puede recibir dos enteros como argumentos.
Los factores comunes se eliminan automáticamente, lo que convierte la fracción a su «forma más simple» (_los enteros más pequeños que representan la fracción con exactitud_):

```python
>>> from fractions import Fraction

>>> f1 = Fraction(2, 3) # 2/3
>>> f1
Fraction(2, 3)

>>> f2 = Fraction(6, 9)
>>> f2
Fraction(2, 3)  # automatically simplified

>>> f1 == f2
True
```

El constructor de fracciones también puede interpretar una representación en forma de string:

```python
>>> f3 = Fraction('2/3')
>>> f3
Fraction(2, 3)
```

Las fracciones también pueden trabajar con parámetros `float`, pero esto puede traer problemas debido a la naturaleza aproximada de representar el valor decimal internamente en binario.
Para saber más sobre este problema de representación, consulta el sitio web [0.30000000000000004][0.30000000000000004] y [Floating Point Arithmetic: Issues and Limitations ][fp-issues] en la documentación de Python.

Para obtener un resultado más confiable al usar números de punto flotante con fracciones, existe el método `<fraction>.limit_denominator()`.


## Aritmética con fracciones

Los [`arithmetic operators`][operators] habituales `+ - * / **` funcionan con las fracciones, igual que con otros tipos numéricos.

Los enteros y otras `Fraction` pueden incluirse en la operación y dar como resultado una `Fraction`.
Incluir un `float` en la expresión da como resultado un `float`, con una consecuente (posible) pérdida de precisión:

```python
>>> Fraction(2, 3) + Fraction(1, 4) # addition
Fraction(11, 12)

>>> Fraction(2, 3) * Fraction(6, 5) # multiply fractions
Fraction(4, 5)

>>> Fraction(2, 3) * 6 / 5 # fraction with integers
Fraction(4, 5)

>>> Fraction(2, 3) * 1.2  # fraction with float -> float
0.7999999999999999

>>> Fraction(2, 3) ** 2  # exponentiation with integer
Fraction(4, 9)
```

Varias funciones numéricas estándar de Python también dan el resultado que esperarías al trabajar con los tipos `int` y `float`:

```python
>>> round(Fraction(11, 3))
4

>>> from math import floor, ceil
>>> floor(Fraction(11, 3))
3
>>> ceil(Fraction(11, 3))
4

>>> float(Fraction(11, 3))
3.6666666666666665
```
