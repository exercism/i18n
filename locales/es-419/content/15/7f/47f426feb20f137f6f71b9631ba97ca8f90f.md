# Pistas

## General

- Para acceder a las variables de instancia y definirlas, escribes `@` seguido del nombre de la variable.

## 1. Inicializa `TaskHandler`

- Para crear un `Proc` usa la sintaxis `-> (args) { block }`.
- Cuando defines un `Proc` para una variable de instancia, hay que indicar su tipo de forma explícita.
  Esto se puede hacer agregando `: Proc(<arg_type>, <return_type>)` después del nombre de la variable.
  O con la sintaxis `-> (arg_1 : <arg_type>) : <return_type> { block }`.
- El `Proc` debe comparar si el argumento es mayor o igual que 0.

## 2. Actualiza la lógica de la condición de la tarea

- El método debe recibir un bloque como argumento y asignarlo a la variable de instancia `@task_condition_logic`.

## 3. Ejecuta la siguiente tarea

- Para ejecutar un `Proc` puedes usar el método `call`, que acepta los argumentos del proc.
