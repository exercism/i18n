# Normalizaciones del representer

El [representer de JavaScript][github-javascript-representer] aplica las siguientes normalizaciones:

## Eliminar los comentarios

Se eliminan todos los comentarios.
Los siguientes ejemplos son equivalentes:

### Ejemplo con comentarios

```javascript
/**
 * Returns the string literal 'hi there' just to say hello
 * @return [String]
 */
function hello(/* nothing*/) {
  // just return it
  return 'hi there';
}
```

### Ejemplo sin comentarios

```javascript
function hello() {
  return 'hi there';
}
```

## Normalizar los espacios en blanco

Cuando se representa el código, su _orden_ es significativo, pero su ubicación física no lo es.
Esto significa que los espacios en blanco se normalizan.
Los siguientes ejemplos son equivalentes:

### Ejemplo con indentación de dos espacios

```javascript
function hello() {
  return 'hello world';
}
```

### Ejemplo con indentación de cuatro espacios

```javascript
function hello() {
  return 'hello world';
}
```

### Ejemplo con una indentación interesante

```javascript
function hello() {
  return 'hello world';
}
```

## Normalizar los identificadores

Los identificadores se normalizan a un valor de marcador de posición.

### Antes

```javascript
const MY_CONSTANT = 42;

function answer(multiplier, addition = 1) {
  return MY_CONSTANT * multiplier + addition;
}
```

### Después

```javascript
const PLACEHOLDER_1 = 42;

function PLACEHOLDER_2(PLACEHOLDER_3, PLACEHOLDER_4 = 1) {
  return PLACEHOLDER_1 * PLACEHOLDER_3 + PLACEHOLDER_4;
}
```
