# Introducción

Python tiene tres tipos diferentes de números integrados: enteros ([`int`][int]), de punto flotante ([`float`][float]) y complejos ([`complex`][complex]).
Las fracciones ([`fractions.Fraction`][fractions]) y los decimales ([`decimal.Decimal`][decimals]) también están disponibles al importarlos desde la biblioteca estándar.

Los números enteros, incluidos los hexadecimales ([_`hex()`_][hex]), octales ([_`oct()`_][oct]) y binarios ([_`bin()`_][bin]) **sin** decimales, también se identifican como `ints`:

```python
# Ints are whole numbers.
>>> 1234
1234
>>> type(1234)
<class 'int'>

>>> -12
-12
```

Los números que contienen un punto decimal (con o sin parte fraccionaria) se identifican como `floats`:

```python
>>> 3.45
3.45
>>> type(3.45)
<class 'float'>
```

## Aritmética

Python admite por completo la aritmética entre estos distintos tipos de números, y convertirá los números más estrechos para que coincidan con sus equivalentes menos estrechos cuando se usan con los operadores aritméticos binarios (`+`, `-`, `*`, `/`, `//` y `%`).

### Suma y resta

Los operadores de suma y resta se comportan como en las matemáticas normales.
Si uno o más de los operandos es un `float`, los `int` restantes también se convertirán en `float`:

```python
>>> 5 - 3
2
# The int is widened to a float here, and a float is returned.
>>> 3 + 4.0
7.0
```

### Multiplicación

Al igual que con la suma y la resta, la multiplicación convertirá los números más estrechos para que coincidan con sus equivalentes menos estrechos:

```python
>>> 3 * 2
6

>>> 3 * 2.0
6.0
```

### División

La división siempre devuelve un `float`, incluso si el resultado es un número entero:

```python
>>> 6/5
1.2

>>> 6/2
3.0
```

### División entera

Si necesitas un resultado `int`, puedes usar la división entera para truncar el resultado.
La división entera se realiza con el operador `//`:

```python
>>> 6//5
1

>>> 6//2
3
```

### Módulo

El operador módulo (`%`) devuelve el residuo de la división de los dos operandos:

```python
# The result of % is zero here, because dividing 8 by 2 leaves no remainder
>>> 8 % 2
0

# The result of % is 2 here, because 3 only goes into 5 once, with 2 leftover
>>> 5 % 3
2
```

Otra forma de ver 5 % 3:

```python
>>> whole_part = int(5/3)
1

>>> decimal_part = 5/3 - whole_part
0.6666666666666667

>>> whole_remainder = decimal_part * 3
2.0
```

## Redondeo

Python proporciona una función integrada [`round(number, <decimal_places>)`][round] para redondear un número de punto flotante a una cantidad determinada de decimales.
Si no se especifica una cantidad de decimales, el número se redondea al entero más cercano y devolverá un `int`:

```python
>>> round(3.1415926535, 2)
3.14

>>> round(3.1415926535)
3
```

## Prioridad y paréntesis

Python te permite usar paréntesis para agrupar expresiones.
Esto es útil cuando quieres anular el orden de operaciones predeterminado.

```python
>>> 2 + 3 * 4
14

>>> (2 + 3) * 4
20
```

Python sigue la regla [PEMDAS][pemdas] para la precedencia de operadores.
Esto significa que los cálculos dentro de `()` tienen la prioridad más alta, seguidos de `**`, luego `*`, `/`, `//`, `%`, `+` y `-`:

```python
>>> 2 + 3 - 4 * 4
-11

>>> (2 + 3 - 4) * 4
4

# In the following example, the `**` operator has the highest priority, then `*`, then `+`
# Meaning we first do 4 ** 4, then 3 * 64, then 2 + 192
>>> 2 + 3 * 4 ** 4
770
```

## Precisión y representación

Los enteros en Python tienen [precisión arbitraria][arbitrary-precision]: la cantidad de dígitos está limitada solo por la memoria disponible del sistema anfitrión.

Los números de punto flotante generalmente se implementan usando un `double` en C (_15 decimales de precisión_), pero su representación varía según el sistema anfitrión.
Los números complejos tienen una parte `real` y una parte `imaginary`, y ambas se representan con números de punto flotante.

Para un análisis más detallado de los problemas y las limitaciones de la aritmética de punto flotante en los distintos lenguajes de programación, echa un vistazo a [0.30000000000000004.com][0.30000000000000004.com] y [el tutorial de Python][floating point math].
