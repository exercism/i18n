# Métodos de array

Los arrays son una estructura de datos muy común con la que vas a trabajar. Por eso existe una colección de métodos que puedes usar para manejarlos, entre los que se incluyen ordenar, invertir, insertar y muchos más.

Algunos de estos métodos son destructivos, lo que significa que modifican el array original. Otros no son destructivos, es decir, devuelven un nuevo array y no modifican el original.

Estos son algunos de los métodos más comunes que puedes usar cuando trabajas con arrays:

## insert

Cuando insertas un elemento en un array, puedes usar el método [`insert`][insert], que recibe un índice y un elemento como argumentos.
El elemento se insertará en el índice especificado y el resto del array se desplazará a la derecha.
Si el índice está fuera de los límites, se lanzará un `IndexError`.

```crystal
numbers = [1, 2, 3]
numbers.insert(1, 4)
numbers # => [1, 4, 2, 3]

numbers.insert(5, 5) # => Error: Index out of bounds (IndexError)
```

## delete

Cuando quieres eliminar un elemento específico de un array, puedes usar el método [`delete`][delete], que recibe un elemento como argumento.
El método devuelve el elemento que se eliminó.
Si el elemento no existe en el array, se devolverá `nil`.

```crystal
numbers = [1, 2, 3]
numbers.delete(2) # => 2
numbers           # => [1, 3]
```

## first y last

Cuando quieres obtener el primer o el último elemento de un array, puedes usar los métodos [`first`][first] y [`last`][last].
Estos métodos reciben un argumento opcional que especifica cuántos elementos devolver.
Pueden mejorar la legibilidad en comparación con usar el índice `0` o `-1`, o usar un rango.
Si el array está vacío, se lanzará un `Enumerable::EmptyError`.

```crystal
numbers = [1, 2, 3]
numbers.first # => 1
numbers.last  # => 3

numbers.first(2) # => [1, 2]
numbers.last(2)  # => [2, 3]

empty_array = [] of Int32
empty_array.last # => Error: Empty enumerable (Enumerable::EmptyError)
```

## reverse

Cuando quieres invertir un array, puedes usar el método [`reverse`][reverse], que devuelve un nuevo array con los elementos en orden inverso.
Es importante tener en cuenta que `reverse` devuelve un nuevo array y no modifica el array original.
Si quieres modificar el array original, agrega un `!` al final del nombre del método.

```crystal
numbers = [1, 2, 3]
numbers.reverse # => [3, 2, 1]
numbers         # => [1, 2, 3]

numbers.reverse! # => [3, 2, 1]
numbers          # => [3, 2, 1]
```

## flatten y compact y transpose y uniq

Los siguientes métodos son útiles para realizar operaciones como convertir un array en unidimensional, eliminar elementos `nil`, eliminar duplicados o transponer un array de arrays.
Al igual que `reverse`, estos métodos devuelven un nuevo array y no modifican el array original.

| Método | Descripción | Ejemplo |
| ------ | ----------- | ------- |
| [`flatten`][flatten] | Devuelve un nuevo array que es un aplanamiento unidimensional de este array (de forma recursiva). Es decir, para cada elemento del array, extrae sus elementos en el nuevo array. | `[[1, 2], [3, 4]].flatten # => [1, 2, 3, 4]` |
| [`compact`][compact] | Devuelve una copia del propio array con todos los elementos nil eliminados. | `[1, nil, 2, nil, 3].compact # => [1, 2, 3]` |
| [`transpose`][transpose] | Asume que el propio array es un array de arrays y [transpone][transpose] las filas y las columnas. | `[[1, 2], [3, 4]].transpose # => [[1, 3], [2, 4]]` |
| [`uniq`][uniq] | Devuelve un nuevo array eliminando los valores duplicados del propio array. | `[1, 2, 1, 3, 1].uniq # => [1, 2, 3]` |

## Concatenación(`+`)

El método append (`<<`) es útil cuando quieres agregar objetos a un array.
Sin embargo, cuando combinas dos arrays, puedes usar el operador [`+`][concat], que devuelve un nuevo array con los elementos de ambos arrays.

```crystal
[1, 2] + [3, 4] # => [1, 2, 3, 4]
```

Si agregas un array a otro array, el array se agregará como un solo elemento.

```crystal
[1, 2] << [3, 4] # => [1, 2, [3, 4]]
```

## empty?

Cuando quieres comprobar si un array está vacío, puedes usar el método [`empty?`][empty?], que devuelve `true` si el array está vacío y `false` en caso contrario.
Esto mejora la legibilidad en comparación con comprobar la longitud del array contra `0`.

```crystal
[].empty? # => true
[1, 2, 3].empty? # => false
```

## index

Cuando quieres obtener el índice de un elemento en un array, puedes usar el método [`index`][index], que recibe un elemento como argumento.
Si el elemento no existe en el array, se devolverá `nil`.

```crystal
numbers = [1, 2, 3]
numbers.index(2) # => 1
```

## size

Cuando quieres saber la cantidad de elementos de un array, puedes usar el método [`size`][size].

```crystal
numbers = [1, 2, 3]
numbers.size # => 3
```

## count

Cuando quieres contar la cantidad de veces que un elemento está presente en un array, puedes usar el método [`count`][count].

```crystal
fruits = ["apple", "banana", "apple"]
fruits.count("apple")      # => 2
fruits.count("banana")     # => 1
fruits.count("watermelon") # => 0
```

## sort

Cuando quieres ordenar un array, puedes usar el método [`sort`][sort], que devuelve un nuevo array con los elementos ordenados.
Al igual que `reverse`, este método devuelve un nuevo array y no modifica el array original.

```crystal
numbers = [3, 2, 1]
numbers.sort # => [1, 2, 3]
numbers      # => [3, 2, 1]

numbers.sort! # => [1, 2, 3]
numbers       # => [1, 2, 3]
```
