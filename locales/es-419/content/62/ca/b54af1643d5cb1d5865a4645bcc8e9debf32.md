# Introducción

## With

La [forma especial with][with] ofrece una manera de concentrarte en el «camino feliz» de una serie de pasos que pueden fallar y de ocuparte de los errores más adelante.

```elixir
with {:ok, id} <- get_id(username),
     {:ok, avatar} <- fetch_avatar(id),
     {:ok, image_type} <- check_valid_image_type(avatar) do
  {:ok, image_type, avatar}
else
  :not_found ->
    {:error, "invalid username"}

  {:error, "not an image"} ->
    {:error, "avatar associated to #{username} is not an image"}

  err ->
    err
end
```

En cada paso, si una cláusula coincide, la cadena continúa hasta que se ejecuta el bloque `do`. Si alguna coincidencia falla, la cadena se detiene y se devuelve la cláusula que no coincidió. Tienes la opción de usar un bloque `else` para capturar las coincidencias fallidas y modificar el valor de retorno.

[with]: https://hexdocs.pm/elixir/Kernel.SpecialForms.html#with/1
