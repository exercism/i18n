# Pistas

## 1. Desplaza los bits hacia atrás

- Hay dos operadores para desplazar a la derecha, pero solo uno siempre insertará un 0.

## 2. Establece algunos bits

- Uno de los operadores bit a bit siempre establece un bit a 1 donde los bits de ambos valores son 1.

## 3. Invierte bits específicos

- Hay una operación de bits que invierte un bit donde la máscara es 1.

## 4. Borra bits específicos

- Una de las operaciones de bits borra los bits donde el bit de la máscara es 0.
- Pero puede que necesites combinarla con otro operador para borrar los bits donde la máscara es 1.
