# Introducción

## Ajustadores temporales

Cuando trabajas con objetos de `java.time` como `LocalDate`, muchas veces necesitas hacer ajustes de fechas más complejos, como encontrar «el segundo martes del mes».
En lugar de calcularlo a mano, puedes usar **`TemporalAdjusters`**.

La clase de utilidades `java.time.temporal.TemporalAdjusters` (fíjate en la «s» del plural) ofrece métodos estáticos para muchos ajustes de fechas habituales.
Estos ajustes los aplicas con el método `.with()` sobre un objeto temporal (como `LocalDate`).

```exercism/note
Usar `with(TemporalAdjuster)` devuelve una instancia _nueva_ y no actualiza la instancia existente, ya que los objetos de `java.time` son inmutables.
```

```java
import java.time.LocalDate;
import java.time.Month;
import java.time.DayOfWeek;
import java.time.temporal.TemporalAdjusters;

LocalDate date = LocalDate.of(2024, Month.AUGUST, 15); // 2024-08-15 (a Thursday)

// Use a predefined adjuster: find the last day of the month
LocalDate lastDay = date.with(TemporalAdjusters.lastDayOfMonth());
// => 2024-08-31
```

Estos son algunos ajustadores clave que resultan útiles para calcular programaciones:

### Encontrar el enésimo día de la semana

Usa `dayOfWeekInMonth(int ordinal, DayOfWeek dayOfWeek)` para encontrar la enésima aparición de un día de la semana.

```java
// Find the second Tuesday of August 2024
LocalDate secondTuesday = date.with(TemporalAdjusters.dayOfWeekInMonth(2, DayOfWeek.TUESDAY));
// => 2024-08-13
```

### Encontrar el primer o el último día de la semana en el mes

Usa `firstInMonth(DayOfWeek dayOfWeek)` o `lastInMonth(DayOfWeek dayOfWeek)`.

```java
// Find the last Monday of August 2024
LocalDate lastMonday = date.with(TemporalAdjusters.lastInMonth(DayOfWeek.MONDAY));
// => 2024-08-26
```

### Ajustes relativos (siguiente/anterior)

Ajustadores como `next()`, `previous()`, `nextOrSame()` y `previousOrSame()` encuentran la aparición siguiente o anterior de un día de la semana dado, tomando como referencia la fecha actual.

- `next()`/`previous()`: excluyen la fecha actual si coincide.
- `nextOrSame()`/`previousOrSame()`: incluyen la fecha actual si coincide.

```java
LocalDate thursday = LocalDate.of(2024, Month.AUGUST, 15); // A Thursday

// Find the next Thursday (exclusive)
LocalDate nextThursday = thursday.with(TemporalAdjusters.next(DayOfWeek.THURSDAY));
// => 2024-08-22

// Find the next Thursday (inclusive) - returns the same date
LocalDate nextOrSameThursday = thursday.with(TemporalAdjusters.nextOrSame(DayOfWeek.THURSDAY));
// => 2024-08-15

// Find the previous Monday (exclusive)
LocalDate previousMonday = thursday.with(TemporalAdjusters.previous(DayOfWeek.MONDAY));
// => 2024-08-12
```

### Ajustadores personalizados

`TemporalAdjuster` es una interfaz funcional, así que puedes escribir tu propio ajustador como una lambda que recibe el objeto temporal que hay que ajustar y devuelve el ya ajustado.
Se aplica con `.with()` igual que los ajustadores predefinidos, y puede usarlos internamente.

```java
import java.time.temporal.TemporalAdjuster;

// An adjuster that moves a weekend date to the following Monday
TemporalAdjuster skipWeekend = temporal -> {
    DayOfWeek day = DayOfWeek.from(temporal);
    if (day == DayOfWeek.SATURDAY || day == DayOfWeek.SUNDAY) {
        return temporal.with(TemporalAdjusters.next(DayOfWeek.MONDAY));
    }
    return temporal;
};

LocalDate saturday = LocalDate.of(2024, Month.AUGUST, 17);
LocalDate monday = saturday.with(skipWeekend);
// => 2024-08-19
```

Usar estos ajustadores de la clase `TemporalAdjusters` puede simplificar muchísimo las tareas de manipulación de fechas.
