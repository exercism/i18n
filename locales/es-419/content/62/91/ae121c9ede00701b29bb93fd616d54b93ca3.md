## 1. Verifica que el comando sea válido

Además de ser inteligente, el chatbot también es un asistente leal.

Para pedirle algo al chatbot, el usuario debe decir la palabra «**Chatbot**» en la primera posición del comando.

No importa si la palabra clave está en MAYÚSCULAS o minúsculas. Lo importante aquí es la posición de la palabra.

Implementa la función `is_valid_command()` que ayuda al chatbot a reconocer cuándo el usuario está dando un comando.

```julia-repl
julia> is_valid_command("Chatbot, play a song from the 80's.")
True

julia> is_valid_command("Hey Chatbot, where is the closest pharmacy?")
False

julia> is_valid_command("CHATBOT, do you have a solution for this challenge?")
True
```

## 2. Elimina los emojis cifrados

Al chatbot le cuesta entender cómo las personas usan los emojis para expresar sus emociones.

Cuando el chatbot recibe mensajes de los usuarios, cada emoji se representa como «_emoji_» seguido de su número _id_.

Implementa el método `remove_emoji()` para que tome un string y elimine todo el cifrado de los emojis a lo largo del mensaje.

Las líneas que no contengan el texto de emojis deben devolverse sin modificar.

Solo elimina el string del emoji. No intentes ajustar los espacios en blanco.

```julia-repl
julia> remove_emoji("I love playing videogames emoji3465 it's one of my hobbies")
"I love playing videogames  it's one of my hobbies"
```

## 3. Verifica que el número de teléfono sea válido

Dado que las funcionalidades del chatbot se descargan en una app móvil, se espera que el usuario escriba un número de teléfono durante la conversación.

El problema es que el chatbot solo puede leer y validar un número con un formato específico.

Si el número es válido (coincide con la secuencia de caracteres especificada por la **expresión regular**), el chatbot responde con un mensaje que agradece al usuario y confirma el número. Si el número no es válido, la función le informa al usuario que el número de teléfono no es válido.

El formato esperado es: (+##) ###-###-###

```julia-repl
julia> check_phone_number("(+34) 659-771-594")
"Thanks! You can now download me to your phone."

julia> check_phone_number("659-771-594")
"Oops, it seems like I can't reach out to 659-771-594"
```

## 4. Obtén el enlace del sitio web

El chatbot es un software muy curioso. Aunque puede buscar en internet sobre un tema en particular, le gusta preguntar a los usuarios por sitios web interesantes o URL para encontrar información relevante.

Ejemplo de conversación:

- **Chatbot**: Hola username, me gustaría aprender a programar en JavaScript, ¿conoces algún sitio web interesante donde pueda aprender?
- **Usuario**: Aprendí mucho en [exercism.org](http://exercism.org)

Implementa la función `getURL()` que puede devolver un array con solo el enlace de cada sitio web.

```julia-repl
julia> getURL("I learned a lot from exercism.org")
["exercism.org"]
```

## 5. Saluda al usuario

Para guardar los datos de todas las personas que han conversado con él, el chatbot puede obtener el nombre completo del perfil del usuario con este estilo: **«smith, john»**.

De esta forma, queremos que nuestro chatbot sea realmente educado y cause una buena impresión.

Escribe la función `nice_to_meet_you()` que toma un string con el nombre completo del usuario y devuelve el string **«Nice to meet you, John Smith»**

```julia-repl
julia> str = "Smith, John"

julia> nice_to_meet_you(str)
"Nice to meet you, John Smith"
```
