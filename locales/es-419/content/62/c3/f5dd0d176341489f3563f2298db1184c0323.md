# Apéndice de instrucciones

## Implementación

En Pharo, las clases son objetos que pueden tener métodos de instancia y métodos de clase; sin embargo, a diferencia de HelloWorld, las pruebas de TwoFer se escribieron para llamar a métodos de instancia.
Por lo general, los métodos de clase se usan para construir objetos nuevos (como un constructor en otros lenguajes).

Al hablar de métodos, es útil saber que un método que no tiene parámetros se llama método unario, y un método que recibe varios parámetros, cada uno delimitado por una palabra que termina en «:», se llama método de palabra clave.

También existe un tercer tipo de método, el binario, que recibe solo 1 parámetro y usa uno o varios símbolos como nombre (normalmente uno matemático como: +, -, &, etc.).
