# PowerShell

¡Automatiza todo!
Escribe scripts en cualquier sistema operativo para administrar archivos, procesos, un centro de datos o servicios en la nube.
Explora de forma interactiva datos estructurados como JSON, XML y CSV; trabaja con cualquier interfaz de administración, desde API web y CIM hasta aplicaciones de línea de comandos.

# Acerca de PowerShell

PowerShell es un lenguaje de scripting, shell y framework de administración de configuración de .NET, de código abierto y multiplataforma, que ayuda a profesionales de TI y usuarios avanzados a controlar y automatizar casi cualquier cosa.

PowerShell se construye sobre .NET Framework y transforma el clásico concepto de pipe de Unix: lo extiende de simplemente pasar flujos de texto o binarios a permitir pasar instancias de objetos que incluyen información de tipo (por ejemplo, fechas y horas) y estado complejo con sus datos estructurados.
Mientras que en un shell tradicional podrías usar procesamiento de texto para extraer determinada información de la salida de un comando, en PowerShell tienes acceso a propiedades y métodos (incluidas formas de inspeccionar objetos para determinar qué propiedades y métodos están disponibles).
Puedes trabajar con archivos CSV, convertir JSON en tablas hash, navegar por documentos XML y mucho más, lo que permite componer fácilmente muchas tareas que serían difíciles o poco prácticas de lograr con el análisis de texto.

PowerShell es extensible.
No solo mediante herramientas de línea de comandos independientes, a la manera en que son extensibles otros shells, sino mediante scripts, funciones y cmdlets distribuidos en módulos que de verdad se integran por completo con el sistema de ayuda de PowerShell, su editor de línea de comandos con resaltado de sintaxis, el descubrimiento automático de parámetros y el autocompletado con el tabulador.
¡Incluso puedes extender la sencilla y explorable sintaxis de propiedad + contenido del sistema de archivos a almacenes de datos como el registro de Windows y el almacén de certificados, SQL Server y hasta Azure!

PowerShell incluye muchas funcionalidades adicionales:

- «cmdlets» integrados para tareas comunes de administración del sistema, como administrar archivos, servicios, procesos y hasta el registro, los registros de eventos y el modelo de información común (CIM), solicitudes web y mucho más.
- Compatibilidad con scripts y herramientas de línea de comandos existentes.
- Interfaces extensibles, y módulos y comandos fáciles de descubrir.
- Acceso completo a .NET Framework y extensibilidad mediante ensamblados de .NET provenientes de NuGet.
- Un historial de comandos enriquecido con información sobre el éxito y la duración de la ejecución de un comando.
- Potentes capacidades de manipulación de objetos. Los objetos se pueden manipular directamente, serializar e incluso enviar a otras herramientas o bases de datos.

Encontrarás documentación detallada sobre PowerShell, el lenguaje, sus conceptos centrales y sus funcionalidades junto con los instaladores en https://docs.microsoft.com/en-us/powershell.
