# Instrucciones

En este ejercicio, implementarás un conjunto parcial de rutinas de utilidad para ayudar a un desarrollador a limpiar nombres de identificadores.
En las 5 tareas irás construyendo poco a poco la rutina `Clean`.
Un identificador válido se compone de cero o más letras y guiones bajos.
En todos los casos, se garantiza que el string de entrada no es nulo.
Si se pasa un string vacío a la función `Clean`, se debe devolver un string vacío.
Ten en cuenta que quien llama debe evitar llamar a la rutina `Clean` con un identificador vacío, ya que ese tipo de identificadores no tienen efecto alguno.

## 1. Reemplaza los espacios que encuentres con guiones bajos

Implementa el método (_static_) `Identifier.Clean()` para reemplazar los espacios con guiones bajos.
Esto también se aplica a los espacios al principio y al final.

```csharp
Identifier.Clean("my   Id");
// => "my___Id"
```

## 2. Reemplaza los caracteres de control con el string en mayúsculas «CTRL»

Modifica el método (_static_) `Identifier.Clean()` para reemplazar los caracteres de control con el string en mayúsculas `"CTRL"`.

```csharp
Identifier.Clean("my\0Id");
// => "myCTRLId",
```

## 3. Convierte kebab-case a camelCase

Modifica el método (_static_) `Identifier.Clean()` para convertir kebab-case a camelCase.

```csharp
Identifier.Clean("à-ḃç");
// => "àḂç"
```

## 4. Omite los caracteres que no sean letras

Modifica el método (_static_) `Identifier.Clean()` para omitir cualquier carácter que no sea una letra.

```csharp
Identifier.Clean("1😀2😀3😀");
// => ""
```

## 5. Omite las letras griegas minúsculas

Modifica el método (_static_) `Identifier.Clean()` para omitir cualquier letra griega en el rango de 'α' a 'ω'.

```csharp
Identifier.Clean("MyΟβιεγτFinder");
// => "MyΟFinder"
```
