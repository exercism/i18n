# Instrucciones

En este ejercicio, juegas con un amigo a adivinar un número. Las reglas son simples: eliges en secreto un número entre `1` y `100`, y tu amigo intenta adivinar qué número elegiste. Para ayudarlo, respondes de manera distinta según qué tan cerca esté el intento del número que elegiste (`42`). Estas son las reglas para las diferentes respuestas:

- Si el intento es `42`: «Correct»
- Si el intento es `41` o `43`: «So close»
- Si el intento es menor que `41`: «Too low»
- Si el intento es mayor que `43`: «Too high»

Tienes cuatro tareas para escribir las respuestas a los intentos.

## 1. Responde a un intento correcto

Implementa la función `reply` para responder a un intento correcto:

```fsharp
reply 42
// => "Correct"
```

## 2. Responde a un intento cercano

Modifica la función `reply` para responder a los intentos cercanos:

```fsharp
reply 41
// => "So close"
```

## 3. Responde a los intentos demasiado bajos

Modifica la función `reply` para responder a los intentos demasiado bajos:

```fsharp
reply 25
// => "Too low"
```

## 4. Responde a los intentos demasiado altos

Modifica la función `reply` para responder a los intentos demasiado altos:

```fsharp
reply 88
// => "Too high"
```
