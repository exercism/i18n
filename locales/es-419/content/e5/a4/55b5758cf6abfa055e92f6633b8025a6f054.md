# Apéndice de instrucciones

## Registros

| Registro | Uso       | Tipo    | Descripción                                  |
| -------- | --------- | ------- | -------------------------------------------- |
| `$a0`    | entrada   | dirección | string de caracteres binarios terminado en nulo |
| `$v0`    | salida    | entero  | valor decimal del string de entrada          |
| `$t0-9`  | temporal  | cualquiera | se usa para almacenamiento temporal       |
