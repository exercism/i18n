# Introducción

## Sintaxis general

El bucle `for` es una de las sentencias más usadas para ejecutar cierta lógica de forma repetida.
En Go consta de la palabra clave `for`, un encabezado y un bloque de código que contiene el cuerpo del bucle encerrado entre llaves.
El encabezado consta de 3 componentes separados por puntos y coma (`;`): init, condition y post.

```go
for init; condition; post {
  // loop body - code that is executed repeatedly as long as the condition is true
}
```

- El componente **init** es código que se ejecuta solo una vez antes de que empiece el bucle.
- El componente **condition** debe ser una expresión que se evalúe a un Boolean y que controle cuándo debe detenerse el bucle.
  El código dentro del bucle se ejecutará mientras esta condición se evalúe como verdadera.
  En cuanto esta expresión se evalúe como falsa, el bucle dejará de ejecutar iteraciones.
- El componente **post** es código que se ejecuta al final de cada iteración.

**Nota:** A diferencia de otros lenguajes, no hay paréntesis `()` que rodeen los tres componentes del encabezado.
De hecho, agregar esos paréntesis es un error de compilación.
Sin embargo, las llaves `{ }` que rodean el cuerpo del bucle siempre son obligatorias.

## Bucles `for`: un ejemplo

El componente init por lo general prepara una variable contadora, el componente condition verifica si el bucle debe continuar o detenerse, y el componente post suele incrementar el contador al final de cada repetición.

```go
for i := 1; i < 10; i++ {
  fmt.Println(i)
}
```

Este bucle imprimirá los números del `1` al `9` (incluido el `9`).
Por lo general, el paso se define con una sentencia de incremento o decremento, como se muestra en el ejemplo anterior.
