# Pistas

A menos que tengas mucha confianza en tus habilidades con las expresiones regulares, puede ayudarte practicar la sintaxis en un entorno de pruebas en línea como [Regex101][regex101].

Recuerda configurar el dialecto a PCRE2.

Predefinir cada expresión regular como una `const` puede ser un buen estilo (por claridad y rendimiento).

## 1. Comprobar si el comando es válido

- El carácter de anclaje para el inicio del string es `^`.
- Solo necesitas un true/false de la búsqueda con la expresión regular.
- Esto se podría resolver sin usar una expresión regular, pero mantente, por favor, dentro del espíritu de un ejercicio de concepto.

## 2. Eliminar los emojis cifrados

- Un simple [`replace()`][replace].

## 3. Comprobar si el número de teléfono es válido

- Necesita una expresión regular más larga, pero bastante repetitiva.
- Las `n` ocurrencias consecutivas se pueden especificar con la sintaxis `{n}`.
- Solo necesitamos un true/false para la coincidencia.

## 4. Obtener el enlace del sitio web

- Recuerda escapar el punto con `\.`
- Captura la parte antes del punto en un [match][match].

## 5. Saludar al usuario

- Un `replace()` con capturas con nombre tiene el formato `r"(?<name>...) " => s"\g<name>... "`
- De nuevo, un `split()` podría resolver la tarea, pero practicar expresiones regulares es útil.
