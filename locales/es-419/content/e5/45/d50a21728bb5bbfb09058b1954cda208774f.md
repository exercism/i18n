# Anexo de instrucciones

## Pistas

Para que el reto tenga la dificultad adecuada, solo deberías usar funcionalidad que esté presente en Prelude. Trata de no usar Data.List, Data.Char, Data.Bits ni Numeric.

Intenta usar seq, $! o BangPatterns de forma adecuada para asegurarte de que la solución sea eficiente.

No es necesario manejar entradas inválidas.

Si ya hiciste el ejercicio Octal, tal vez deberías generalizarlo.
