# Pruebas

Para cada ejemplo, se requieren los siguientes pasos generales.

Primero, cambia al directorio del ejercicio que quieres practicar, en
este caso `bob`.

```bash
$ cd </path/to/exercism>/lfe/bob
```

Luego ejecuta las pruebas.  El objetivo `test` de make depende de `compile`,
así que ejecutar `make test` garantizará que tu código fuente se compile
 y después pasará a ejecutar las pruebas.


```bash
$ make test
```

¡Felicidades! ¡Tienes pruebas que fallan!

Ahora lee `README.md` para saber qué necesitas hacer y lograr que todas
tus pruebas pasen.


Corrige el primer error que reporta la prueba y ejecuta las pruebas de nuevo.

```bash
$ make test
```

Continúa corrigiendo la siguiente prueba que falla en tu código fuente y
ejecuta tus pruebas hasta que todas pasen.

Cuando todas tus pruebas pasen, dale un último vistazo a tu código en el
directorio `src` para asegurarte de que estás conforme con tu código y envíalo a revisión.

Recibe comentarios, revisa tu solución, envíala, prueba el siguiente ejercicio y repite
hasta alcanzar la iluminación de LFE.
