# Apéndice de instrucciones

~~~~exercism/note

La descripción anterior menciona [_conjuntos matemáticos_][math-sets], pero también que una tripleta pitagórica {a, b, c} _**debe**_ estar ordenada de manera que a < b < c (_orden ascendente_). 

Esto hace que el [tipo `set`][python-sets] de Python no sea adecuado para este ejercicio, ya que es inherentemente _desordenado_. 
En su lugar, deberías devolver una [`list`][python-list] de `list`s (_p. ej. `[[a, b, c]]`_). 
Puedes generar las tripletas en el orden que quieras, ya que el orden de la `list` que las contiene se ignorará en las pruebas. 

[math-sets]: https://en.wikipedia.org/wiki/Set_(mathematics)
[python-sets]: https://docs.python.org/3/tutorial/datastructures.html#sets
[python-list]: https://docs.python.org/3/tutorial/datastructures.html#more-on-lists
