# Instrucciones

En este ejercicio, vas a implementar la lógica de la misión de un nuevo juego de rol que un amigo está desarrollando. La protagonista del juego es Annalyn, una chica valiente con un perro feroz y leal. Lamentablemente, todo se complica: su mejor amiga fue secuestrada mientras buscaba bayas en el bosque. Annalyn intentará encontrar y liberar a su mejor amiga, y puede llevar a su perro con ella en esta misión.

Después de pasar un tiempo siguiendo el rastro de su mejor amiga, encuentra el campamento en el que su mejor amiga está prisionera. Resulta que hay dos secuestradores: un caballero poderoso y un arquero astuto.

Una vez que encuentra a los secuestradores, Annalyn considera cuáles de las siguientes acciones puede llevar a cabo:

- Ataque rápido: se puede hacer un ataque rápido si el caballero está durmiendo, ya que tarda en ponerse la armadura, así que estará vulnerable.
- Espiar: se puede espiar al grupo si al menos uno de ellos está despierto. De lo contrario, espiar es una pérdida de tiempo.
- Hacer señales al prisionero: se le pueden hacer señales usando sonidos de aves si el prisionero está despierto y el arquero está durmiendo, ya que los arqueros están entrenados en el uso de sonidos de aves, así que podrían interceptar el mensaje.
- _Liberar al prisionero_: Annalyn puede intentar colarse en el campamento para liberar al prisionero.
  Es algo arriesgado y solo puede salir bien de una de dos maneras:
  - Si Annalyn lleva a su perro, puede rescatar al prisionero si el arquero está dormido.
    El caballero le tiene miedo al perro y el arquero no tendrá tiempo de prepararse antes de que Annalyn y el prisionero puedan escapar.
  - Si Annalyn no lleva a su perro, ¡ella y el prisionero tendrán que ser muy sigilosos!
    Annalyn puede liberar al prisionero si el prisionero está despierto y el caballero y el arquero están ambos dormidos, pero si el prisionero está durmiendo no se le puede rescatar: el prisionero se asustaría por la aparición repentina de Annalyn y despertaría al caballero y al arquero.

Tienes cuatro tareas: implementar la lógica para determinar si las acciones anteriores están disponibles según el estado de los tres personajes que se encuentran en el bosque y según si el perro de Annalyn está presente o no.

## 1. Comprobar si se puede hacer un ataque rápido

Implementa el método `canFastAttack()` que recibe un valor booleano que indica si el caballero está despierto. Este método devuelve `true` si se puede hacer un ataque rápido según el estado del caballero. De lo contrario, devuelve `false`:

```kotlin
val knightIsAwake = true

canFastAttack(knightIsAwake)
// => false
```

## 2. Comprobar si se puede espiar al grupo

Implementa el método `canSpy()` que recibe tres valores booleanos que indican si el caballero, el arquero y el prisionero, respectivamente, están despiertos. El método devuelve `true` si se puede espiar al grupo, según el estado de los tres personajes. De lo contrario, devuelve `false`:

```kotlin
val knightIsAwake = false
val archerIsAwake = true
val prisonerIsAwake = false

canSpy(knightIsAwake, archerIsAwake, prisonerIsAwake)
// => true
```

## 3. Comprobar si se le pueden hacer señales al prisionero

Implementa el método `canSignalPrisoner()` que recibe dos valores booleanos que indican si el arquero y el prisionero, respectivamente, están despiertos. El método devuelve `true` si se le pueden hacer señales al prisionero, según el estado de los dos personajes. De lo contrario, devuelve `false`:

```kotlin
val archerIsAwake = false
val prisonerIsAwake = true

canSignalPrisoner(archerIsAwake, prisonerIsAwake)
// => true
```

## 4. Comprobar si se puede liberar al prisionero

Implementa el método `canFreePrisoner()` que recibe cuatro valores booleanos. Los tres primeros parámetros indican si el caballero, el arquero y el prisionero, respectivamente, están despiertos. El último parámetro indica si el perro de Annalyn está presente. El método devuelve `true` si se puede liberar al prisionero según el estado de los tres personajes y la presencia del perro de Annalyn. De lo contrario, devuelve `false`:

```kotlin
val knightIsAwake = false
val archerIsAwake = true
val prisonerIsAwake = false
val petDogIsPresent = false

canFreePrisoner(knightIsAwake, archerIsAwake, prisonerIsAwake, petDogIsPresent)
// => false
```
