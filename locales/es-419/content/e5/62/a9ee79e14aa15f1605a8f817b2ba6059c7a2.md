# Introducción

Una *expresión regular* (regex) es un patrón pequeño que describe cómo debería verse cierto texto. En lugar de revisar tú mismo un string carácter por carácter, escribes una sola vez la forma que buscas y dejas que Factor se encargue de buscar las coincidencias. Las herramientas de regex de Factor viven en el vocabulario [`regexp`][regexp].

## Cómo escribir un patrón

En Factor, escribes una regex entre `R/ ` y `/`:

```factor
R/ cat/      ! the pattern that matches the letters c, a, t
```

La mayoría de los caracteres en un patrón simplemente se representan a sí mismos: `R/ cat/` coincide con el texto `cat`. La potencia viene de unas cuantas piezas especiales que representan *tipos* de caracteres o *cuántos* de ellos.

### Clases de caracteres: «un carácter de un conjunto»

```
\d        ! any digit, 0–9
\D        ! any NON-digit (the opposite of \d)
\s        ! any space, tab, or newline
\S        ! any NON-space character (the opposite of \s)
\w        ! a "word" character: a letter, a digit, or an underscore
\W        ! any NON-word character (the opposite of \w)
[A-Z]     ! any one capital letter A to Z
[a-z]     ! any one lowercase letter
[0-9]     ! any one digit (same as \d)
.         ! any single character at all
```

Una clase coincide con exactamente *un* carácter. `[A-Z]` coincide con `Q`, pero no con `QQ`.

### Cuantificadores: «cuántas veces»

Pon uno de estos *después* de una pieza para indicar cuántas veces puede repetirse:

```
{4}       ! exactly 4 times
{2,5}     ! between 2 and 5 times
+         ! one or more
*         ! zero or more
?         ! zero or one (optional)
```

Así, `\d{4}` significa cuatro dígitos seguidos, y `[A-Z]+` significa una o más letras mayúsculas. Si lo juntamos, `R/ [A-Z]+-\d+/` describe «una o más mayúsculas, un guion y luego uno o más dígitos», texto como `SALE-2024`. El `-` aquí es un carácter normal: fuera de `[ ]`, un guion solo coincide con un guion (dentro de una clase, como en `[A-Z]`, marca un rango).

## Hacer coincidir un string completo

`matches?` responde a la pregunta «¿este string *completo* encaja con el patrón?»: el patrón tiene que dar cuenta de todos los caracteres, de principio a fin:

```
matches? ( string regexp -- ? )
```

```factor
USING: regexp ;

"SALE-2024"     R/ [A-Z]+-\d+/ matches? .   ! => t
"GET SALE-2024" R/ [A-Z]+-\d+/ matches? .   ! => f   (extra text before)
"SALE-2024 NOW" R/ [A-Z]+-\d+/ matches? .   ! => f   (extra text after)
"sale-2024"     R/ [A-Z]+-\d+/ matches? .   ! => f   (lowercase letters)
```

Aunque `SALE-2024` esté dentro de `"GET SALE-2024"`, `matches?` igual devuelve `f`: los caracteres extra son parte del string y no encajan con el patrón. Cuando lo único que te importa es si el patrón aparece *en algún lugar*, usa `re-contains?`: devuelve `t` justo donde `matches?` devolvió `f`:

```
re-contains? ( string regexp -- ? )
```

```factor
USING: regexp ;

"GET SALE-2024" R/ [A-Z]+-\d+/ matches? .      ! => f
"GET SALE-2024" R/ [A-Z]+-\d+/ re-contains? .  ! => t
```

## Encontrar coincidencias dentro de un texto más largo

`re-contains?` solo te dice *si* el patrón está ahí. Estas siguientes palabras buscan dentro y reportan *qué* coincidió: `all-matching-subseqs` devuelve cada lugar donde el patrón coincide, como una secuencia de strings, y `count-matches` solo los cuenta:

```
all-matching-subseqs ( string regexp -- seq )
count-matches        ( string regexp -- n )
```

```factor
USING: regexp ;

"3 cats, 12 dogs, 1 fish" R/ \d+/ all-matching-subseqs .
! => { "3" "12" "1" }            (every run of digits)

"the quick fox" R/ \S+/ all-matching-subseqs .
! => { "the" "quick" "fox" }     (every run of non-space characters)

"id_7!" R/ \w/ count-matches .   ! => 4   (i, d, _ and 7 count; ! does not)
```

## Reemplazar coincidencias

`re-replace` cambia cada coincidencia por un texto de reemplazo y devuelve el nuevo string:

```
re-replace ( string regexp replacement -- result )
```

```factor
USING: regexp ;

"page 7 of 12" R/ \d+/ "N" re-replace .
! => "page N of N"
```

El vocabulario `regexp` tiene más palabras que vale la pena conocer. Sigue los enlaces para ver los detalles: [`first-match`][first-match] (solo la primera coincidencia) y [`re-split`][re-split] (divide un string donde coincida el patrón).
