# Aprendizaje de Batch

## Sitios web

- La [documentación oficial de archivos Batch](https://learn.microsoft.com/en-us/previous-versions/windows/it-pro/windows-xp/bb490869(v=technet.10)?redirectedfrom=MSDN) es un gran lugar para ver algunos ejemplos y aprender sobre el lenguaje.
- La [documentación de comandos de SS64](https://ss64.com/nt/) es probablemente la documentación más completa sobre los comandos de Batch y también incluye ejemplos desde básicos hasta avanzados.
- Las [páginas de scripting de Rob van der Woude](https://www.robvanderwoude.com/) son un recurso increíblemente útil para el scripting de Batch, con muchos ejemplos y explicaciones; lo más interesante de este sitio es que comparte el código de herramientas realmente únicas y explica todo de una forma comprensible. (Puede que al principio el sitio te resulte un poco confuso, pero vale la pena).
- El [foro DosTips](https://www.dostips.com/forum/) es un gran lugar para hacer preguntas y conseguir ayuda con tus scripts de Batch.
- [Batch-Man](https://batch-man.com/) comparte muchas herramientas y scripts útiles, y además los explica de una forma muy comprensible: cada script tiene una explicación detallada en formato de blog, tiene un repositorio de GitHub, muchos ejemplos y un video de YouTube.

## Videos

- [Tutoriales de Batch de John Hammond](https://www.youtube.com/playlist?list=PL69BE3BF7D0BB69C4) están muy bien explicados para principiantes.
- El canal de [Batch-Man](https://www.youtube.com/@batch-man/videos) también crea contenido con regularidad y muestra técnicas.
