# Acerca de

El enlazado describe desde dónde se puede acceder a un identificador en el código.
Los valores con ámbito de bloque, de función o de prototipo de función no tienen enlazado.
Esto significa que no se puede acceder a ellos desde fuera de su ámbito.
Para más información sobre el ámbito, consulta el [concepto de ámbito](../scope/introduction.md#Introduction).

## Enlazado externo

Los identificadores con ámbito de archivo tienen enlazado externo de forma predeterminada.
Se puede llamar a un identificador con enlazado externo desde cualquier archivo del programa.

## Enlazado interno

Se puede hacer que un identificador con ámbito de archivo tenga enlazado interno usando el especificador `static`.
Un identificador con enlazado interno solo se puede usar dentro de su archivo.

Por ejemplo

```c
int public_count = 0; // file scope, external linkage by default
static int private_count = 0;  // file scope, internal linkage 

// file scope, internal linkage
static void some_function()
{
    // code snipped
}

// file scope, external linkage by default
int main()
{
    // code snipped
}
```

El enlazado estático no debe confundirse con la duración de almacenamiento estática.
Para más información sobre la duración de almacenamiento estática, consulta el [concepto de duración de almacenamiento](https://github.com/exercism/c/blob/main/concepts/storage-class-specifiers/about.md#static-the-storage-specifier-not-to-be-confused-with-the-static-linkage-type).

Si un valor (a diferencia de una función) se declara en un encabezado pero se define en el archivo fuente como un identificador `static` con ámbito de archivo y con un valor inicializado, su valor inicializado no será accesible desde fuera de su archivo fuente.
Puede que compile, enlace y se ejecute sin errores, pero el valor será el valor cero del identificador, incluso si el valor se declara con `extern`.
(Para más información sobre `extern`, consulta el [concepto de extern](https://github.com/exercism/c/blob/main/concepts/storage-class-specifiers/about.md#extern-how-to-access-a-variable-in-another-translation-unit).)
Un identificador con ámbito de archivo marcado como `static` en un archivo fuente no debe declararse en su archivo de encabezado.
