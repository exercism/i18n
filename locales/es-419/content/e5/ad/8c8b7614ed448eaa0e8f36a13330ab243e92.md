# Pruebas

Ejecuta las pruebas con:

```shell
npm run test
```

También puedes ejecutar Jest en modo «watch», que volverá a ejecutar tus pruebas automáticamente cuando guardes cambios en el código o en el módulo de pruebas:

```shell
npm run watch
```

## Cómo entender las pruebas omitidas

El método skip le indica a la suite de pruebas que no ejecute una prueba; esta función también se puede usar con los alias: `it.skip(name, fn)`, `xit(name, fn)` o `xtest(name, fn)`

- ¿Por qué se omiten?

Para que puedas concentrarte en una prueba a la vez y habilitarlas una por una a medida que desarrollas la solución.

- ¿Cómo habilitarlas?

Cambia `xtest` por `test`.

```javascript
test("title cased phrases", () => {
  expect(Acronyms.parse("Portable Network Graphics")).toEqual("PNG");
});
```
