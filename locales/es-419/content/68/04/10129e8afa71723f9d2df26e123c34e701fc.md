# Introducción

Las enumeraciones en Cairo te permiten definir un tipo que puede ser una de varias variantes con nombre.

## Fundamentos

Las enumeraciones, o enums para abreviar, limitan todos los valores posibles de un dato a un conjunto predefinido. Los valores posibles de un `enum` se llaman variantes:

```rust
#[derive(Drop)]
enum Direction {
    North,
    South,
    East,
    West,
}
```

Crea valores de enumeración especificando la variante:

```rust
let my_direction = Direction::North;
let another_direction = Direction::West;
```

## Coincidencia de patrones

Usa match para manejar las distintas variantes de una enumeración:

```rust
match my_direction {
    Direction::North => println!("Going north!"),
    Direction::South => println!("Going south!"),
    Direction::East => println!("Going east!"),
    Direction::West => println!("Going west!"),
}
```

Cada brazo del match se encarga de una variante de la enumeración.

## Enumeraciones con datos

Las variantes de una enumeración pueden contener datos adicionales:

```rust
struct Location {
    x: u32,
    y: u32,
}

enum Message {
    Text: ByteArray,
    Number: u32,
    Location: Location,
}
```

Usa la coincidencia de patrones para extraer los datos:

```rust
match msg {
    Message::Text(content) => println!("Text: {}", content),
    Message::Number(val) => println!("Number: {}", val),
    Message::Location(Location { x, y }) => println!("Position: ({}, {})", x, y),
}
```
