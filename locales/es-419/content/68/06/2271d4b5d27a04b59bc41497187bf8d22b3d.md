# Pistas

## 1. Define el rango de filas y columnas

- Necesitas definir dos [constantes][constants] que deben contener un [`Range`][range] de filas y columnas.
- Las filas deben ser un `range` de [`Integer`][integers] del 1 al 8.
- Las columnas deben ser un `Range` de [`String`][string] de 'A' a 'H'.
- La constante debe definirse en el [módulo][module] `Chess`.

## 2. Verifica si la casilla es válida

- Necesitas verificar si un valor está dentro de un rango.
- Hay [un método][include] que puedes usar para verificar si un valor está dentro de un rango.

## 3. Obtén el apodo del jugador

- Puedes obtener una porción usando un `Range` como argumento.
- Hay [un método][upcase] que puedes usar para convertir un string a mayúsculas.

## 4. Crea el mensaje de la jugada

- Puedes indexar el string de la casilla para obtener la fila y la columna.
- Puedes usar los métodos ya definidos para obtener el apodo del jugador y para verificar si la jugada es válida.
