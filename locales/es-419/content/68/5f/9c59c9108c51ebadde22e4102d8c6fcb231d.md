# Instrucciones

Tu amigo Linus es un ingeniero de locomotoras que conduce trenes de carga entre ciudades.
Aunque es increíble manejando trenes, no lo es tanto con la logística ni con las computadoras.
Le gustaría contar con tu ayuda como programador para organizar los detalles de los trenes y corregir errores en los datos de las rutas.

~~~~exercism/note
Este ejercicio se podría resolver fácilmente usando slicing, indexación y varios métodos de `hash`.
Sin embargo, queremos que practiques el empaquetado, el desempaquetado y la asignación múltiple al resolver cada una de las tareas a continuación.
~~~~

## 1. Crea un array con todos los vagones

Tu amigo ha estado llevando un registro del identificador (ID) de cada vagón, pero nunca está seguro de cuántos vagones tendrá que procesar el sistema en un momento dado.
Para el resto del programa de logística sería mucho más fácil tener estos datos empaquetados en un único **array**.

Implementa un método `generate_list_of_wagons()` que acepte una cantidad arbitraria de IDs de vagones.
Cada ID será un número entero positivo.
El método debe entonces hacer `return` de los IDs dados como un único **array**.

```ruby
LocomotiveEngineer.generate_list_of_wagons(1, 7, 12, 3, 14, 8, 5)
# => [1, 7, 12, 3, 14, 8, 5]
```

## 2. Corrige la lista de vagones

En este punto, ya empiezas a tener una idea de los datos y de cómo se usan en el programa de logística.
El sistema de IDs siempre asigna a la locomotora el ID **1**, y al resto de los vagones del tren les asigna un ID elegido al azar mayor que **1**.

¡Tu amigo tuvo que conectar dos vagones nuevos al tren y olvidó actualizar el sistema!
Ahora, los dos primeros vagones del **array** del tren deben moverse al final, o todo quedará desordenado.

Para complicar más las cosas, tu amigo acaba de descubrir un segundo **array** que parece contener IDs de vagones faltantes.
Lo único que recuerda es que, una vez que se muevan los vagones nuevos, los IDs de este segundo **array** deben colocarse justo después de la locomotora designada.

Linus te agradecería mucho que corrigieras sus errores y consolidaras los datos.

Implementa un método `fix_list_of_wagons()` que reciba dos **arrays** con IDs de vagones.
Debe mover los dos primeros elementos del primer **array** al final, e insertar los valores del segundo **array** detrás (_a la derecha_) del ID de la locomotora (**1**).
El método debe entonces hacer `return` de un **array** con las modificaciones.

```ruby
LocomotiveEngineer.fix_list_of_wagons([2, 5, 1, 7, 4, 12, 6, 3, 13], [3, 17, 6, 15])
# => [1, 3, 17, 6, 15, 7, 4, 12, 6, 3, 13, 2, 5]
```

## 3. Agrega las paradas faltantes

Ahora que todos los datos de los vagones son correctos, Linus quiere que actualices la información de rutas del sistema.
A lo largo de una ruta de transporte, un tren puede hacer paradas en varias estaciones diferentes para recoger y/o dejar carga.
Cada viaje podría tener una cantidad diferente de estos puntos intermedios de entrega.
Tu amigo quiere que actualices el **hash** de rutas del sistema con cualquier información de entrega que falte o sea adicional.

Implementa un método `add_missing_stops()` que acepte un **hash** de rutas seguido de una cantidad variable de argumentos de palabra clave.
Estos argumentos pueden tener la forma de un **hash** que contenga una o más paradas, o cualquier cantidad de pares de palabra clave `stop_<number>: "city"`.
Tu método debe entonces devolver el **hash** de rutas actualizado con una **clave** adicional que contenga un **array** con todas las paradas agregadas en orden.

```ruby
LocomotiveEngineer.add_missing_stops({from: "New York", to: "Miami"},
                    stop_1: "Washington, DC", stop_2: "Charlotte", stop_3: "Atlanta",
                    stop_4: "Jacksonville", stop_5: "Orlando")
# => {from: "New York", to: "Miami", stops: ["Washington, DC", "Charlotte", "Atlanta", "Jacksonville", "Orlando"]}
```

~~~~exercism/note
Las paradas siempre se pasarán en el orden correcto, así que no tienes que preocuparte por ordenarlas.
~~~~

## 4. Amplía la información de rutas

Linus ha estado trabajando en el programa de rutas y ha notado que ciertas rutas carecen de algunos detalles importantes.
La información inicial de la ruta se ha construido como un **hash**, y tu amigo quiere que actualices ese **hash** con lo que pueda faltar.
Cada ruta del sistema requiere detalles un poco diferentes, así que Linus preferiría claramente una solución genérica.

Implementa un método llamado `extend_route_information()` que acepte dos **hashes**.
El primer **hash** contiene las ciudades de origen y destino entre las que circula la ruta del tren.

El segundo **hash** contiene otros detalles de la ruta, como la velocidad, la longitud o la temperatura del tren.
El método debe devolver un **hash** consolidado con toda la información de la ruta.

~~~~exercism/note
El segundo **hash** puede contener propiedades diferentes o más que las que se muestran en el ejemplo.
~~~~

```ruby
LocomotiveEngineer.extend_route_information({"from": "Berlin", "to": "Hamburg"}, {"length": "100", "speed": "50"})
# => {"from": "Berlin", "to": "Hamburg", "length": "100", "speed": "50"}
```
