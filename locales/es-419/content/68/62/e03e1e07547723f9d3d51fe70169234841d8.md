# Acerca de

`call` es la primitiva universal para «ejecutar esta quotation ahora». Cuando
el compilador puede ver la quotation de forma literal, puede inferir el
efecto; cuando la quotation viene de una variable, un array o un
parámetro, tienes que declarar el efecto:

```factor
: apply-binary ( a b op -- c )
    call( a b -- c ) ;

5 3 [ - ] apply-binary .   ! => 2
5 3 [ + ] apply-binary .   ! => 8
```

La declaración `call( a b -- c )` se compila a una comprobación en tiempo de
ejecución de que la quotation realmente tiene el efecto declarado. Una
discrepancia produce un error claro en lugar de un estado de la pila
corrupto.

Tratar las quotations como datos (ponerlas en la pila, guardarlas en arrays,
devolverlas desde words) es una de las cosas que hace que el código
concatenativo sea tan compacto. Un «programa» puede ser una simple secuencia,
y `each` junto con `call` basta para interpretarlo.
