# Tests

En MacOS/Linux, ejecuta:

```sh
$ chmod +x gradlew
```

Ejecuta los tests con:

```sh
$ ./gradlew test
```

> Usa `gradlew.bat` si estás en Windows

## Tests omitidos

Después de que pase el primer test (o los primeros), continúa comentando o eliminando las anotaciones `@Ignore` que preceden a los demás tests.
