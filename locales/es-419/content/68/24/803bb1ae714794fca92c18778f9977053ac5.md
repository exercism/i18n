# Pistas

## General

- La [guía de strings de rubymostas][ruby-for-beginners.rubymonstas.org-strings] tiene una buena introducción a los strings de Ruby.
- El objeto `String` tiene muchos [métodos integrados][docs-string-methods] muy útiles.

## 1. Obtener el mensaje de una línea de registro

- Hay distintas maneras de buscar texto en un string, que puedes encontrar en la [documentación oficial del lenguaje Ruby][docs-string-methods].
- Hay [métodos integrados][strip-white-space] para eliminar los espacios en blanco.

## 2. Obtener el nivel de registro de una línea de registro

- Los objetos `String` de Ruby tienen un [método][downcase] para hacer esta operación.

## 3. Reformatear una línea de registro

- Hay varias maneras de [concatenar strings][ruby-for-beginners.rubymonstas.org-strings], pero normalmente se prefiere la [interpolación de strings][ruby-for-beginners.rubymonstas.org-strings]
