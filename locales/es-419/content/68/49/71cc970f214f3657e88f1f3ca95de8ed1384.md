# Anexo de instrucciones

## Formato de entrada y salida

Cada conjunto de palabras se representa como un string terminado en nulo, con un carácter de salto de línea al final de cada palabra.

Debes devolver los anagramas en el mismo orden en que aparecen en las palabras candidatas.

Un ejemplo sería `"tones\nnotes\nSeton\n"`

## Registros

| Registro | Uso          | Tipo    | Descripción                                                     |
| -------- | ------------ | ------- | --------------------------------------------------------------- |
| `$a0`    | entrada      | dirección | string objetivo terminado en nulo, sin salto de línea           |
| `$a1`    | entrada      | dirección | string de candidatos terminado en nulo, con un salto de línea después de cada palabra |
| `$a2`    | entrada/salida | dirección | string de salida terminado en nulo, con un salto de línea después de cada palabra |
| `$t0-9`  | temporal     | cualquiera | para almacenamiento temporal                                    |
