# Ejecutar las pruebas

Con `sbt` instalado, puedes ejecutar las pruebas desde la línea de comandos con:

```bash
$ sbt test
```

Ten en cuenta que ejecutar `sbt test` cada vez será lento, ya que reinicializa `sbt` en cada invocación.

`sbt` funciona como una shell: una vez que lo inicias, puedes ejecutar comandos dentro de él.

Por ejemplo, puedes usar `sbt` para volver a ejecutar tus pruebas cada vez que cambien los archivos fuente:
```bash
$ sbt
>~ test
```

Ten en cuenta que todas las pruebas están deshabilitadas excepto la primera, para que trabajes en ella. Para continuar, solo elimina la palabra clave `pending` del inicio de cada caso de prueba.

Ve [aquí](https://www.scala-sbt.org/) para aprender más sobre `sbt`.


Las pruebas también se pueden ejecutar dentro de los siguientes IDE

* [Metals](https://scalameta.org/metals/docs/#running-tests)
* [IntelliJ IDEA con el plugin de Scala](https://www.jetbrains.com/idea/)
