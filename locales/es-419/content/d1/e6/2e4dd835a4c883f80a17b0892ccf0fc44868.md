# Case

[`case`][case] (al que en otros lenguajes se suele llamar switch) es una forma de expresión de control, similar a if-else.
`case` permite encadenar varias sentencias if-else-if, puede ser más legible y permite construir estructuras potentes.

Un `case` se define con la palabra clave `case` seguida de una expresión opcional.
Luego, para cada caso se usa la palabra clave `when` seguida de una expresión que se compara con la expresión del `case`.
La palabra clave `when` no debe tener más sangría que la palabra clave `case`.
Después de la palabra clave `when` va el código que debe ejecutarse si la expresión del `case` coincide con la expresión del `when`.
`case` permite una sentencia `else` opcional que se ejecuta si ningún otro caso coincide.

La expresión del `case` se evalúa y luego se compara con cada expresión del `when`.
La comparación se hace con el [operador de subsunción de `case` (`===`)][case-subsumption].

```Crystal
case 1
when 1
  puts "One"
when 2
  puts "Two"
else
  puts "Other"
end
# => One

# This is the same as:
tmp = 1
if 1 === tmp
  puts "One"
elsif 2 === tmp
  puts "Two"
else
  puts "Other"
end
```

## Operador de subsunción de `case` (`===`)

El operador de subsunción de `case` (`===`) es un poco diferente del operador de igualdad (`==`).
El operador comprueba si el lado derecho es un miembro del conjunto que describe el lado izquierdo.
Esto significa que sí importa dónde se coloca cada operando.
Cómo funciona depende del tipo del lado izquierdo; por ejemplo, un `Range` comprobaría si el lado derecho está dentro del rango, o un `Object` comprobaría si el lado derecho es una instancia de `Object`.

```Crystal
(1..3) == 1  # => false
(1..3) === 1 # => true

String == "foo"  # => false
String === "foo" # => true
```

## `case` con varias expresiones

Los `case` permiten hacer coincidir varias expresiones en un solo caso, con cada valor posible separado por una coma.
Ejecutará el código si alguna de las expresiones coincide.
Esto puede ser útil para un solo caso con varios valores posibles.

```Crystal
case 1
when 1, 2
  puts "One or two"
else
  puts "Other"
end
```

## `case` con rangos

Los `case` también pueden comprobar si un valor está dentro de un rango.
Esto se hace usando un rango como expresión del `when`.

```Crystal
case var
when 1..3
  puts "One to three"
else
  puts "Other"
end
```

## `case` sin expresión de `case`

Cuando no se necesita una expresión de `case`, es posible omitirla.
Al hacerlo, cada expresión se evalúa según su veracidad.
Y hace que se comporten como sentencias if-else-if.

```Crystal
case
when 1 == 1
  puts "One is equal to one"
when 1 > 2
  puts "One is greater than two"
else
  puts "Other"
end
```

## `when` en una sola línea

Crystal permite sentencias `case` de una sola línea.
Esto se puede usar cuando tienes una sentencia simple de una sola línea.
El `when` de una sola línea se escribe como `when <expression> then <statement>.`
Y cuando se usa en la sentencia `else`, se escribe como `else <statement>`.

```Crystal
case var
when 1 then puts "One"
when 2 then puts "Two"
else puts "Other"
end
```

## `case` con tipos

`case` permite hacer coincidir con tipos.
La comparación usará el operador `is_a?` para comprobar el tipo de la variable.
Por ejemplo, esto permite una rama para cada tipo en un tipo unión.

```Crystal
case var
when Int32
  puts "Int32"
when String
  puts "String"
else
  puts "Other"
end
```

## Objeto implícito

`case` permite usar un objeto implícito.
Esto permite, por ejemplo, que una expresión del `when` sea una llamada a un método sobre la expresión del `case`.
Según si el método devuelve un valor verdadero o falso, el caso coincidirá o no.

```Crystal
case 1
when .odd?
  puts "Odd"
when .even?
  puts "Even"
end
```
