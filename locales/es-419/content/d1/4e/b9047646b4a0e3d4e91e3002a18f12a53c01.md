# Introducción

En Common Lisp, una función puede tener parámetros con nombre (a los que se llama «keyword parameters»). Estos se designan en la lista lambda con la palabra clave de lista lambda `&key`. Los keyword parameters no son parámetros obligatorios. Al igual que los parámetros opcionales, pueden recibir valores predeterminados y símbolos a los que enlazar su estado de «suministrado o no».

Cuando se llama a una función con keyword parameters, delante del valor del parámetro se escribe el nombre del parámetro como palabra clave. Quien llama a la función puede especificar los keyword parameters en cualquier orden.

```lisp
(defun keyword-parameters (&key x (y 'default) (z nil z-supplied-p))
  (list x y (if z-supplied-p (list :z-was-supplied z)
                             (list :z-was-not-supplied z))))

(keyword-parameters)            ; => (NIL DEFAULT (:Z-WAS-NOT-SUPPLIED NIL))
(keyword-parameters :y 5)       ; => (NIL 5 (:Z-WAS-NOT-SUPPLIED NIL))
(keyword-parameters :z 10 :x 5) ; => (5 DEFAULT (:Z-WAS-SUPPLIED 10))
```

Hay que tener cuidado al combinar parámetros opcionales y keyword parameters, ya que los parámetros opcionales podrían consumir el nombre de la palabra clave y el argumento:

```lisp
(defun could-be-confusing (&optional x y &key z) (list x y z))
(could-be-confusing :z 'huh?) ; => (:Z HUH? NIL)
```
