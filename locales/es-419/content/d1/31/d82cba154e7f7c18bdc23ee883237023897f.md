# Cómo contribuir a Exercism

Esta sección de la documentación explica cómo contribuir a Exercism.
Contiene información y especificaciones para todas las distintas áreas de Exercism, así como guías sobre temas como convertirte en mantenedor y elegir una historia para un ejercicio.

Para hacerte una idea de dónde podrías ayudar, echa un vistazo a nuestra [lista de tareas][tasks].

Las contribuciones a la base de código se hacen mediante [GitHub][github].

[tasks]: https://exercism.org/contributing/tasks
[github]: /docs/building/github
