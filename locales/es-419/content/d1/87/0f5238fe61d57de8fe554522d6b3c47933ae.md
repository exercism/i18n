# Ayuda

Si tienes problemas, puedes usar uno de los siguientes recursos para obtener ayuda:

- [DRefLanguage](https://dlang.org/spec/spec.html) contiene la especificación del lenguaje D
- [DReference](https://dlang.org/phobos/index.html) contiene la documentación de la biblioteca estándar de D
- [/r/dlang](https://www.reddit.com/r/dlang) es el subreddit de D.
- [StackOverflow](http://stackoverflow.com/questions/tagged/d) puedes usarlo para buscar tu problema y ver si ya lo respondieron. También puedes hacer y responder preguntas.
