# Anexo de instrucciones

## Pistas

Necesitas implementar la función `responseFor` que devuelve la respuesta de Bob para un argumento dado. Puedes usar la firma proporcionada si tienes dudas sobre los tipos, pero no dejes que restrinja tu creatividad:

```haskell
responseFor :: String -> String
```

Para resolver este ejercicio, puedes leer sobre:

- [Guardas][guards]

[guards]: https://www.futurelearn.com/courses/functional-programming-haskell/0/steps/27226

Este ejercicio trabaja con datos textuales. Por razones históricas, el tipo `String` de Haskell es sinónimo de `[Char]`, una lista de caracteres. Para un manejo más eficiente de datos textuales, se puede usar el tipo `Text`.

Como una extensión opcional de este ejercicio, puedes

- Leer sobre los [tipos de string](https://haskell-lang.org/tutorial/string-types) en Haskell.
- Agregar `- text` a tu lista de dependencias en package.yaml.
- Importar `Data.Text` de [la siguiente manera](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c):

    ```haskell
    import qualified Data.Text as T
    import           Data.Text (Text)
    ```

- Ahora puedes escribir, por ejemplo, `responseFor :: Text -> Text` y referirte a los combinadores de `Data.Text` como, por ejemplo, `T.isSuffixOf`.
- Consulta la documentación de [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html),
- Luego puedes reemplazar todas las apariciones de `String` con `Text` en Bob.hs:

    ```haskell
    responseFor :: Text -> Text
    ```

Esta parte es totalmente opcional.
