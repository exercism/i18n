# Strings

Un **string** (o *cadena*) es un fragmento de texto. El tipo de Sather para un string es `STR`, y un string se escribe entre comillas dobles.

```sather
   composer : STR is
      return "Sibelius";
   end;
```

## Unir strings

`+` une dos strings de principio a fin.

```sather
"Jean" + " " + "Sibelius"      -- "Jean Sibelius"
```

No se pone nada entre ellos, así que el espacio hay que pedirlo aparte. Si lo dejas fuera, obtienes `"JeanSibelius"`.

## ¿Cuánto mide?

`.size` es cuántos caracteres tiene un string. Es un número entero, así que su tipo es `INT`.

```sather
"Sibelius".size      -- 8
```

No hay paréntesis después de `.size`, igual que en una rutina que no recibe argumentos.

## Tomar un fragmento

`.head(n)` son los primeros `n` caracteres. `.tail(n)` son los últimos `n`.

```sather
"Sibelius".head(3)   -- "Sib"
"Sibelius".tail(4)   -- "lius"
```

`head` cuenta desde el principio y `tail` desde el final. Ambos dejan intacto el string original y devuelven uno nuevo.
