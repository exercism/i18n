# Introducción

Una expresión switch puede comparar un valor con uno de los casos de un conjunto de patrones y devolver el valor asociado o ejecutar la acción asociada. La asociación se indica con el símbolo `=>`. Además, cada patrón puede tener una guarda de caso opcional que se introduce con la palabra clave `when`. La expresión de la guarda de caso debe evaluarse como verdadera para que se seleccione esa rama del switch. Los casos (también conocidos como _ramas del switch_) se evalúan en el orden en que aparecen en el texto y, en cuanto se encuentra una coincidencia, el proceso se interrumpe y se devuelve el valor asociado.

```csharp
double xx = 42d;

string interesting = xx switch
{
    0 => "I suppose zero is interesting",
    3.14 when DateTime.Now.Day == 14 && DateTime.Now.Month == 3 => "Mmm pie!",
    3.14 => "π",
    42 => "a bit of a cliché",
    1729 => "only if you are a pure mathematician",
    _ => "not interesting"
};

// => interesting == "a bit of a cliché"
```
