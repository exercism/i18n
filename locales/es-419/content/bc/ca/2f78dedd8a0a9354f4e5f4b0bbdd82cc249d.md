# Descripción

Las macros son una parte poderosa del conjunto de herramientas de quien programa en Rust, y las [macros por ejemplo](https://doc.rust-lang.org/reference/macros-by-example.html) son una forma relativamente sencilla de acceder a ese poder. ¡Escribamos una!

## Contexto

¿Qué es una macro? [Wikipedia](https://en.wikipedia.org/wiki/Macro_(computer_science)) la describe así:

> Una macro (abreviatura de «macroinstrucción», del griego μακρός, 'largo') en ciencias de la computación es una regla o patrón que especifica cómo debe mapearse una determinada secuencia de entrada (a menudo una secuencia de caracteres) a una secuencia de salida de reemplazo (también a menudo una secuencia de caracteres) de acuerdo con un procedimiento definido. El proceso de mapeo que instancia (transforma) el uso de una macro en una secuencia específica se conoce como expansión de macros.

¡Iluminador! Pero para ser más concretos, las macros son una sintaxis especial que te permite generar código en tiempo de compilación. Las macros se pueden usar para hacer cálculos en tiempo de compilación, pero con más frecuencia son solo otra forma de abstraer tu código. Por ejemplo, probablemente ya usaste `println!()` y `vec![]`. Cada una recibe una cantidad arbitraria de argumentos, así que no puedes expresarlas como funciones simples. Por otro lado, siempre se expanden a cierta cantidad de código Rust absolutamente estándar. Si te interesa, puedes usar el subcomando [cargo expand](https://github.com/dtolnay/cargo-expand) para ver los resultados de la expansión de macros en tu código.

Para más información sobre las macros en Rust, The Rust Book tiene un [buen capítulo](https://doc.rust-lang.org/book/ch19-06-macros.html) al respecto.

## Planteamiento del problema

Puedes producir un `Vec` de longitud arbitraria en línea usando la macro `vec![]`. Sin embargo, Rust no incluye una forma de producir un [`HashMap`](https://doc.rust-lang.org/std/collections/struct.HashMap.html) en línea. Soluciona esto escribiendo una macro `hashmap!()`.

Por ejemplo, alguien que use tu biblioteca podría escribir `hashmap!('a' => 3, 'b' => 11, 'z' => 32)`. Esto debería expandirse al siguiente código:

```rust
{
   let mut hm = HashMap::new();
   hm.insert('a', 3);
   hm.insert('b', 11);
   hm.insert('z', 32);
   hm
}
```

Ten en cuenta que el [`maplit` crate](https://crates.io/crates/maplit) proporciona una macro que resuelve este ejercicio a la perfección. En lugar de usar ese crate, implementa tu propia solución; haz el intento por tu cuenta antes de mirar su código fuente.
