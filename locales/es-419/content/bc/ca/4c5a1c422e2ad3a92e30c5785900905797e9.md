# Permisos del repositorio para mantenedores

Un mantenedor de track es alguien que es miembro del equipo de GitHub de ese track.
Convertirse en miembro del equipo de un track es _solo por invitación_.

```exercism/note
Si te gustaría convertirte en mantenedor de un track, abre un tema en el [foro](https://forum.exercism.org/c/exercism/building-exercism/125).
```

## Categoría de mantenimiento

Existen cinco categorías de mantenimiento:

1. `wip-track`
2. `unmaintained`
3. `maintained-solitary`
4. `maintained-autonomous`
5. `maintained`

La categoría de mantenimiento de un track se determina por tres variables:

1. Si el track está activo (es decir, si los estudiantes pueden unirse al track en el sitio web)
2. El número de mantenedores del track
3. El número de mantenedores del track que también están en el equipo de GitHub `cross-track-maintainers`

Para determinar la categoría de mantenimiento, busca en esta tabla la primera categoría que coincida con el track:

| Categoría             | ¿Activa? | Número de mantenedores | Número de mantenedores cross-track |
| --------------------- | -------- | ---------------------- | ---------------------------------- |
| wip-track             | No       | Cualquiera             | Cualquiera                         |
| unmaintained          | Sí       | 0                      | 0                                  |
| maintained-autonomous | Sí       | > 0                    | = Número de mantenedores           |
| maintained-solitary   | Sí       | 1                      | 0                                  |
| maintained            | Sí       | > 1                    | < Número de mantenedores           |

## Permisos del repositorio

La categoría de mantenimiento se usa para establecer los permisos del repositorio (o repositorios) de GitHub del track.

| Categoría             | ¿Requiere PR? | ¿Requiere aprobación de PR? | Revisiones del equipo cross-track |
| --------------------- | ------------- | --------------------------- | --------------------------------- |
| wip-track             | No            | No                          | No                                |
| unmaintained          | Sí            | Sí                          | Sí                                |
| maintained-solitary   | Sí            | Sí                          | Sí                                |
| maintained-autonomous | Sí            | No                          | No                                |
| maintained            | Sí            | No                          | No                                |

```exercism/caution
La categoría `wip-track` es la única categoría que permite a los mantenedores hacer push a `main`.
```

```exercism/caution
Los repositorios de herramientas _siempre_ requerirán aprobación de PR, ya que su contenido está protegido mediante un [archivo CODEOWNERS](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/about-code-owners).
```
