# Acerca de

En Elixir hay dos tipos diferentes de números: los enteros y los números de punto flotante.

Los enteros son números que no tienen decimales.

```elixir
integer = 3
# => 3
```

Puedes encontrar algunas funciones útiles para trabajar con enteros en el módulo [`Integer`][integer].

```elixir
Integer.digits(123)
# => [1, 2, 3]
```

Los enteros grandes (y también los números de punto flotante) suelen formatearse separando cada 3 dígitos en grupos con un guion bajo.

```elixir
1_000_000
# => 1000000
```

El tamaño máximo de los números en Elixir solo está limitado por la memoria disponible en el sistema, porque Elixir usa [aritmética de precisión arbitraria][arbitrary-precision-arithmetic].

Elixir también admite notaciones abreviadas para escribir [enteros binarios, octales y hexadecimales][integers-in-other-bases].

```elixir
0b0100
# => 4

0o555
# => 365

0xFF
# => 255
```

## Comparación

Los enteros y los números de punto flotante pueden considerarse iguales ([`==`][kernel-equal]) si tienen el mismo valor. Sin embargo, como son de tipos diferentes, nunca son estrictamente iguales ([`===`][kernel-strictly-equal]).

```elixir
1 == 1.0
# => true

1 === 1.0
# => false
```
