# Pistas

## General

- Hay tres operadores Boolean para trabajar con valores Boolean: `not`, `&&` y `||`.
- Puedes combinar varios operadores en una sola expresión.

## 1. Define si pac-man puede comerse un fantasma

- La función debe devolver un valor `Bool`.
- Puedes usar el operador Boolean `&&` para combinar los argumentos y obtener un resultado.

## 2. Define si pac-man suma puntos

- La función debe devolver un valor `Bool`.
- Puedes usar el operador Boolean `||` para combinar los argumentos y obtener un resultado.

## 3. Define si pac-man pierde

- La función debe devolver un valor `Bool`.
- Puedes usar los operadores Boolean `&&` y `not` para combinar los argumentos y obtener un resultado.

## 4. Define si pac-man gana

- La función debe devolver un valor `Bool`.
- Puedes usar los operadores Boolean `&&` y `not` para combinar los argumentos y el resultado de una de las funciones que implementaste antes.
