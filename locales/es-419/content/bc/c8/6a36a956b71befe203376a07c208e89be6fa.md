# Introducción

Unison representa los valores verdadero y falso con el tipo `Boolean`. Solo hay dos valores: `true` y `false`.

```unison
trueVariable = true
falseVariable = false
```

Podemos evaluar expresiones de tipo `Boolean` usando los operadores and (representado con `&&`), or (representado con `||`) y not (representado con `not`).

```unison
trueVariable = true && true
falseVariable = true && false

trueVariable = false || true
falseVariable = false || false

trueVariable = not false
falseVariable = not true
```

Las expresiones de tipo `Boolean` de Unison permiten la evaluación de cortocircuito: si el primer argumento de una expresión `&&` es `false`, no hay razón para seguir evaluando el segundo argumento.
De igual manera, si el primer argumento de una expresión `||` es `true`, la expresión devolverá `true` de inmediato.

```unison
> false && (base.bug "oh no")
  ⧩
  false
```

```unison
> true || (base.bug "oh no")
  ⧩
  true
```
