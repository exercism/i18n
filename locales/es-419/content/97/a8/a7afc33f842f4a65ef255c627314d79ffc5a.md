# Anexo de las instrucciones

## Información específica de Arturo

En este ejercicio, se espera que devuelvas las edades usando una [cantidad física][physical-quantities] con una unidad personalizada que represente la duración de un solo año en ese planeta.
En Arturo, una cantidad consta de un valor numérico y una [unidad de medida][unit-of-measurement] asociada.

```arturo
length: 10`m
units length ; `m
scalar length ; 10

10`m * 10`m ; 100 m²
```

~~~~exercism/caution
La unidad `yr integrada de Arturo se convierte a 31556952 segundos.
Por lo tanto, tendrás que definir y usar tu propia unidad de año en términos del número de segundos mencionado anteriormente en las instrucciones.
~~~~

Las cantidades se pueden [convertir][convert] a otra unidad compatible.
```arturo
convert 1`m `ft ; 1250/381 ft
convert 100`m2 `ft2 ; 156250000/145161 ft²

property `m  ; length
property `m2 ; area

convert 1`m `m2 ; conversion error results
```

~~~~exercism/note
Debido a las limitaciones de precisión de los números de punto flotante, Arturo a veces almacena el valor escalar como un número racional.
La [función `to`][to] se puede usar para obtener el valor como un número de punto flotante aproximado.

```arturo
length: convert 1`m `ft ; 1250/381 ft
to :floating length ; 3.280839895013123
```

[to]: https://arturo-lang.io/documentation/library/types/to/
~~~~

Arturo también nos permite [especificar][specify] nuestras propias unidades para las cantidades.

```arturo
specify 'nauMile 1.151`mi
property `nauMile length
specify 'lea 3.00579`nauMile
property `lea ; length
depth: 20000`lea
convert depth `km ; 111355.7993425152 km
```
