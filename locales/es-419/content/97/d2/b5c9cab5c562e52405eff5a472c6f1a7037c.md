# Instrucciones

En este ejercicio vas a organizar carreras entre varios tipos de autos a control remoto. Cada auto tiene sus propias características de velocidad y de consumo de batería.

Los autos empiezan con la batería llena (100%). Cada vez que manejas el auto con el control remoto, este recorre en metros lo que indica su velocidad y el porcentaje de batería restante disminuye según su consumo de batería.

Si la batería de un auto está por debajo de su porcentaje de consumo de batería, ya no puedes manejar el auto.

Cada pista de carreras tiene su propia longitud. Los autos se prueban comprobando si pueden terminar la pista sin quedarse sin batería.

## 1. Crea un auto a control remoto

Define un array `car` con los siguientes elementos:

- speed
- battery_drain
- battery
- distance_traveled

Permite crear un auto a control remoto definiendo una función `new_car` que recibe la velocidad del auto en metros y el porcentaje de consumo de batería como sus dos parámetros, y devuelve un array `car`.

En un auto nuevo, la batería está al 100% y la distancia recorrida es cero.

```R
speed <- 5
battery_drain <- 2
car <- new_car(speed, battery_drain)
str(car)
#> List of 4
#>  $ speed             : num 5
#>  $ battery_drain     : num 2
#>  $ battery           : num 100
#>  $ distance_traveled : num 0
```

## 2. Crea una pista de carreras

Define otro array llamado `track` con el único elemento `track_length`. Permite crear una pista de carreras definiendo una función `new_track` que recibe la distancia de la pista en metros:

```R
track_length <- 800
track <- new_track(track_length)
str(track)
#> List of 1
#>  $ track_length: num 800
```

## 3. Comprueba si la batería se agotó

Implementa la función `battery_drained()` que indica si la batería está agotada. Se considera que una batería está agotada si no queda suficiente para avanzar una vez más.

```R
speed <- 5;
battery_drain <- 2;
car <- new_car(speed, battery_drain);
car <- drive(car);

battery_drained(car);
#> [1] FALSE
```

## 4. Maneja el auto

Implementa la función `drive` que actualiza la cantidad de metros recorridos según la velocidad del auto y reduce la batería de acuerdo con su consumo de batería. Si no queda batería suficiente para avanzar una vez más, el auto no se mueve.

```R
speed <- 5
battery_drain <- 2
car <- new_car(speed, battery_drain)
car <- drive(car)
str(car)
#> List of 4
#>  $ speed             : num 5
#>  $ battery_drain     : num 2
#>  $ battery           : num 98
#>  $ distance_traveled : num 5
```

## 5. Comprueba si un auto a control remoto puede terminar una carrera

Para terminar una carrera, un auto tiene que poder recorrer la longitud de la pista. Esto significa no agotar su batería antes de cruzar la línea de meta.

Implementa la función `can_finish` que recibe un `car` y un `track` como parámetros y devuelve `TRUE` si el auto puede terminar la carrera; de lo contrario, devuelve `FALSE`.

Supón que estás en la línea de salida de la carrera y enciendes el motor del auto para la carrera. Ten en cuenta que es posible que la batería del auto no esté completamente cargada al empezar la carrera.

```R
speed <- 5
battery_drain <- 5
car <- new_car(speed, battery_drain)

name <- "track1"
track_length <- 100
track <- new_track(track_length)

can_finish(car, track)
#> [1] TRUE

# partial battery charge
car$battery <- 50
can_finish(car, track)
#> [1] FALSE
```

## 6. Guarda si el auto puede terminar una pista con la batería llena

Creaste varias pistas de diferentes longitudes y necesitas guardar si tu auto puede completarlas con la batería llena.

Implementa la función `store_track` que recibe un auto, una pista y un nombre de pista, y devuelve un auto actualizado con un elemento adicional. Este elemento debe tener el `name` de la pista, y el valor debe ser un array anidado que contenga el `track_length` y si el auto puede `complete` la pista.

Es posible que el auto que se pasa como argumento no esté completamente cargado, así que asegúrate de restablecer la batería y la distancia recorrida antes de usarlo.

```R
speed <- 5
battery_drain <- 5
car <- new_car(speed, battery_drain)
car$battery <- 50

name <- "track1"
track_length <- 100
track <- new_track(track_length)

track1 <- store_track(car, track, "Imola")
str(track1)
#> List of 5
#>  $ speed             : num 5
#>  $ battery_drain     : num 5
#>  $ battery           : num 100
#>  $ distance_traveled : num 0
#>  $ Imola             :List of 2
#>   ..$ track_length: num 100
#>   ..$ complete    : logi TRUE
```
