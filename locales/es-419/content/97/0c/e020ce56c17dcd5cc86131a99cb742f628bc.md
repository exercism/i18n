# Apéndice de instrucciones

## Implementación

La pista de Crystal agrega una prueba opcional para comprobar que las letras posibles pueden ser cualquier carácter Unicode, no solo caracteres alfabéticos ASCII.
Estas no están accesibles desde el editor web, pero se ejecutan por defecto de forma local.

Para deshabilitar estas pruebas, cuando invoques el ejecutor de pruebas, agrega el siguiente flag: `--tag "~optional"`
