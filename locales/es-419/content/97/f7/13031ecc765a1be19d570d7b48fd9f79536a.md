# Tests

Para ejecutar el test con DrRacket, simplemente abre el archivo de test y haz clic en el botón «Run» de la esquina superior derecha.

Para ejecutar el test desde la línea de comandos, ejecútalo desde el directorio del ejercicio con el siguiente comando:

```
raco test <exercise>-test.rkt
```

donde `<exercise>` se debe reemplazar por el slug del ejercicio.
