# Introducción

## Números de punto flotante

Un número de punto flotante es un número con cero o más dígitos detrás del separador decimal. Algunos ejemplos son `-2.4`, `0.1`, `3.14`, `16.984025` y `1024.0`.

Los distintos tipos de punto flotante pueden almacenar diferentes cantidades de dígitos después del separador decimal; a esto se le llama su precisión.

C# tiene tres tipos de punto flotante:

- `float`: 4 bytes (~6-9 dígitos de precisión). Se escribe como `2.45f`.
- `double`: 8 bytes (~15-17 dígitos de precisión). Este es el tipo más común. Se escribe como `2.45` o `2.45d`.
- `decimal`: 16 bytes (28-29 dígitos de precisión). Normalmente se usa cuando se trabaja con datos monetarios, ya que su precisión reduce la posibilidad de errores de redondeo. Se escribe como `2.45m`.

Como se puede ver, cada tipo puede almacenar una cantidad diferente de dígitos. Por ejemplo, si intentas almacenar PI en un `float`, solo se guardarán los primeros 6 decimales (con el último dígito almacenado redondeado).

## Bucles `while`

En este ejercicio quizás quieras usar un bucle. Hay varias formas de escribir bucles en C#, pero el bucle `while` es el más apropiado aquí:

```csharp
int x = 23;

while (x > 10)
{
    // Execute logic if x > 10
    x = x - 2;
}
```

## Bucles `do`/`while`

Si el código dentro de un bucle siempre debe ejecutarse al menos una vez, se puede usar un bucle `do`/`while`:

```csharp
int x = 23;

do
{
    // Execute body, repeating only if x > 10
    x = x - 2;
} while (x > 10);
```
