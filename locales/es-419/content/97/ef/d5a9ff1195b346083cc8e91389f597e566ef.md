## Herramientas interactivas para jq

Ingresa algunos datos y experimenta con varios filtros de jq para ver qué resulta.

- [jq playground][jqplay], una experiencia para «probarlo en línea».
- [ijq][ijq], herramienta interactiva de jq, como jqplay para la línea de comandos.
- [jqp][jqp] es otra herramienta de línea de comandos: usa gojq como backend, que no es 100% compatible con el jq original.

## Otras herramientas para procesar JSON

- [gron][gron]: «aplana» JSON en una secuencia de asignaciones individuales, lo que permite usar herramientas orientadas a líneas (grep, etc.) para procesarlo.
- [jo][jo]: una pequeña utilidad para crear objetos JSON a partir de variables del shell.
- [jello][jello]: jello es similar a jq, salvo que jello usa la sintaxis estándar de diccionarios y listas de Python.
