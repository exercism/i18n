# Aprende PowerShell

Un excelente punto de partida para aprender PowerShell es elegir un recurso de aprendizaje en la [sección de aprendizaje][learning section] del sitio web de PowerShell.
Ahí hay una enorme cantidad de información y enlaces a una amplia variedad de temas de PowerShell.

PowerShell también tiene un sistema de ayuda autodocumentado muy completo.
Puedes explorar gran parte de lo que ofrece PowerShell con el cmdlet `Get-Help`.
Desde PowerShell, prueba lo siguiente:

```PowerShell
Get-Help about
```

Verás unas 3 páginas de temas que puedes explorar.
Otras dos funciones que te serán de gran utilidad son:

- Get-Command
- Get-Member

¿Quieres saber qué hacen?
Prueba `Get-Help Get-Command` y `Get-Help Get-Member`, por supuesto.

## Verbos y sustantivos en PowerShell

PowerShell sigue un esquema bastante estricto de verbo-sustantivo para nombrar sus cmdlets.
Al principio, esto puede resultar chocante para programadores con experiencia.
Aunque puedes nombrar tus funciones como quieras, familiarizarte con los verbos estándar y adoptarlos mejorará tu forma de programar en PowerShell.

Para ver una lista de todos los verbos aprobados, simplemente ejecuta:

```PowerShell
Get-Verb
```
