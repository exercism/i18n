# Apéndice de instrucciones

## Implementación

Para completar este ejercicio, debes crear el tipo de dato `LinkedList` e implementar las siguientes funciones:

- `new`
- `cons`
- `nil`
- `fromList`
- `head`
- `tail`
- `isNil`
- `reverseLinkedList`
- `toList`

Encontrarás una declaración de tipo ficticia y las firmas de tipo ya incluidas, pero te toca a ti definir las funciones y crear un tipo de dato que tenga sentido.
