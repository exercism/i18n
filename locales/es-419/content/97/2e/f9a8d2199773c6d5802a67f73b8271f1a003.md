# Acerca de

Para ejecutar lógica de forma repetida, puedes usar bucles. Uno de los tipos de bucle más comunes en C# es el bucle `while`, que se repite una y otra vez hasta que una condición Boolean se evalúe como `false`.

```csharp
int x = 23;

while (x > 10)
{
    // Execute logic if x > 10
    x = x - 1;
}
```
