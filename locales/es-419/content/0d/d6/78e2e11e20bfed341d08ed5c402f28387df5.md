# Instrucciones

El regidor de escena quiere que se transcriba el guion de ensayo, y varias de sus partes se construyen repitiendo o uniendo cosas.

Las cuatro tareas van en la clase `REHEARSAL_SCRIPT`.

## 1. Repite una señal

Dada una señal y un número, devuelve la señal repetida esa cantidad de veces, sin nada entre medio.

```sather
REHEARSAL_SCRIPT::repeat_cue("Ha", 3)
-- => "HaHaHa"
```

Repetir algo cero veces da el string vacío.

## 2. Las iniciales del elenco

Dada la lista del elenco, devuelve la primera letra de cada nombre, todas juntas.

```sather
REHEARSAL_SCRIPT::initials(|"Mia", "Ana", "Ben"|)
-- => "MAB"
```

## 3. Numera las líneas

Dadas las líneas de una escena, numéralas desde uno, cada una en su propia línea.

```sather
REHEARSAL_SCRIPT::numbered_lines(|"Enter", "Exit"|)
-- => "1. Enter\n2. Exit"
```

Hay un salto de línea *entre* las líneas y ninguno después de la última. Una escena sin líneas es el string vacío.

## 4. Grita una línea

Devuelve una línea con cada letra convertida en mayúscula.

```sather
REHEARSAL_SCRIPT::shout("quiet please")
-- => "QUIET PLEASE"
```
