# Anexo de instrucciones

## Implementación

Para completar este ejercicio necesitas definir el tipo de dato `stopwatch` e implementar las funciones:

- newStopwatch
- start
- stop
- lap
- reset
- advanceTime
- getState
- currentLap
- total
- previousLaps

Ya encontrarás una definición de tipo de ejemplo en su lugar, pero depende de ti definir las funciones y crear un tipo de dato que tenga sentido.
