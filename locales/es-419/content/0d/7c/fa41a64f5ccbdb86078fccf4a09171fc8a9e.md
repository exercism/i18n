# Acerca de

Cualquier valor puede ser un error. `throw` (en `kernel`) señala; se abandona el efecto de pila de la palabra actual y el control se desenrolla hasta el `recover` envolvente más cercano.

```factor
[ 0 1 / ] [ "div by zero" prepend ] recover
```

`ERROR:` es una palabra de análisis sintáctico que define de una sola vez una clase de tupla de error *y* una palabra constructora:

```factor
ERROR: not-found path ;
! defines:
!   TUPLE: not-found path ;
!   : not-found ( path -- * ) \ not-found boa throw ;
!   : not-found? ( object -- ? ) … class predicate
```

Eso le da a cada error personalizado una clase única, una palabra constructora amigable para lanzarlo y un predicado de clase (`name?`) con el que probar los errores capturados:

```factor
[ "/missing" not-found ]
[ dup not-found? [ path>> "missing: " prepend ] [ drop "other" ] if ]
recover
```

Para una limpieza estilo `finally`, consulta `cleanup` en `continuations`. Para condiciones reiniciables, consulta `condition`.
