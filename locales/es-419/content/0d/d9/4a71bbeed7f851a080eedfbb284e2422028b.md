# Instrucciones

Te contrataron como especialista en expresiones regulares en una empresa que está desarrollando un chatbot.

Está en una fase de desarrollo muy básica, así que tu misión es usar expresiones regulares para mejorar la capacidad del chatbot de entender y generar lenguaje natural.

## Verifica que el comando sea válido

Además de ser inteligente, el chatbot también es un asistente leal.

Para preguntarle algo al chatbot, el usuario debe decir la palabra «**Chatbot**» en la primera posición del comando.

No importa si la palabra clave está en MAYÚSCULAS o en minúsculas. Lo importante aquí es la posición de la palabra.

Implementa la función `isValidCommand()` que ayuda al chatbot a reconocer cuándo el usuario está dando un comando.

```javascript
isValidCommand("Chatbot, play a song from the 80's.";
// => True
isValidCommand("Hey Chatbot, where is the closest pharmacy?";
// => False
isValidCommand("CHATBOT, do you have a solution for this challenge?";
// => True
```

## Elimina los emojis cifrados

El chatbot tiene dificultades para entender cómo las personas usan los emojis para expresar sus emociones.

Cuando el chatbot recibe mensajes del usuario, cada emoji se representa como «_emoji_» seguido de su número _id_.

Implementa el método `removeEmoji()` para que reciba un string y elimine todo el cifrado de los emojis a lo largo del mensaje.

Las líneas que no contengan el texto del emoji deben devolverse sin modificar.

Solo elimina el texto del emoji. No intentes ajustar los espacios en blanco.

Para este reto en particular, usa la sintaxis de constructor para crear la expresión regular.

```javascript
removeEmoji("I love playing videogames emoji3465 it's one of my hobbies");
// => "I love playing videogames  it's one of my hobbies"
```

## Verifica que el número de teléfono sea válido

Debido a la descarga de funcionalidades del chatbot en una app móvil, se espera que el usuario escriba un número de teléfono durante la conversación.

El problema es que el chatbot solo puede leer y validar un número con un formato específico.

Si el número es válido (coincide con la secuencia de caracteres especificada por la **expresión regular**), el chatbot responde con un mensaje en el que agradece al usuario y confirma el número. Si el número no es válido, la función informa al usuario de que el número de teléfono no es válido.

El formato esperado es: (+##) ###-###-###

```javascript
checkPhoneNumber('(+34) 659-771-594');
// => "Thanks! You can now download me to your phone."
checkPhoneNumber('659-771-594');
// => "Oops, it seems like I can't reach out to 659-771-594"
```

## Obtén el enlace del sitio web

El chatbot es un software muy curioso. Aunque puede buscar en internet sobre un tema en particular, le gusta preguntar a los usuarios por sitios web interesantes o URLs donde encontrar información relevante.

Ejemplo de conversación:

- **Chatbot**: Hey username, I would like to learn how to code in JavaScript, do you know any cool website where I could learn?
- **Usuario**: I learned a lot from [exercism.org](http://exercism.org)

Implementa la función `getURL()` que sea capaz de devolver un array con solo el enlace de cada sitio web. Escribir una regex para reconocer cualquier URL sería muy complicado, pero el chatbot solo necesita leer URLs simples. Para este ejercicio, una URL es cualquier secuencia de palabras delimitada por `"."`.

```javascript
getURL(
  'I learned a lot from exercism.org and developer.mozilla.org, but I found ts39.es very boring!',
);
// => ["exercism.org", "developer.mozilla.org", "ts39.es"];
```

## Saluda al usuario

Para almacenar los datos de todas las personas con las que ha conversado, el chatbot puede obtener el nombre completo del perfil del usuario con este estilo: **«smith, john»**.

De esta forma, queremos que nuestro chatbot sea muy cortés y cause una buena impresión.

Escribe la función `niceToMeetYou()` que recibe un string con el nombre completo del usuario y devuelve el string **«Nice to meet you, John Smith»**

Con fines de aprendizaje, implementa la función usando un **método de reemplazo** de las expresiones regulares.

```javascript
let str = 'Smith, John';

niceToMeetYou(str);
// => "Nice to meet you, John Smith"
```
