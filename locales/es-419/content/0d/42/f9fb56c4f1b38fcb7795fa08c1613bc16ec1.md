# Acerca de

Las clases son un pilar fundamental de los programas en Swift.
Te permiten agrupar propiedades (datos) y métodos (funciones) relacionados en unidades de funcionalidad autocontenidas.

### Definir clases

Para definir una clase, usa la palabra clave `class` seguida del nombre de la clase, con la definición de la clase encerrada entre llaves:

```swift
class GameCharacter {
    var characterClass: String?
    var name: String?
    var active = false
    let id = makeRandomID()
}
```

El cuerpo de una clase puede contener propiedades almacenadas, que se definen y se comportan como constantes (`let`) o variables (`var`) normales.

### Instancias

Una definición de clase sirve como un plano: define un nuevo tipo y describe cómo son sus valores, pero no crea ninguna instancia por sí sola.

Para crear una *instancia* de una clase, llama a su inicializador escribiendo el nombre de la clase seguido de paréntesis:

```swift
let someCharacter = GameCharacter()
```

Esto crea una nueva instancia cuyas propiedades se inicializan con los valores predeterminados especificados en la definición de la clase.
En el caso de las propiedades opcionales sin valores predeterminados explícitos (como `name`), Swift les asigna `nil` por defecto.

### Acceder a las propiedades

Accedes a las propiedades de una instancia mediante la *notación de punto*: escribe el nombre de la instancia, un punto (`.`) y el nombre de la propiedad.
La notación de punto también funciona para propiedades anidadas.

Puedes usar la notación de punto para leer valores y, si la propiedad es mutable (`var`), asignar nuevos valores:

```swift
someCharacter.name
// => nil

someCharacter.name = "Luther"
someCharacter.name
// => "Luther"

someCharacter.id = "new id"
// Error: Cannot assign to property: 'id' is a 'let' constant
```

### Métodos

Además de propiedades, las clases pueden definir *métodos*: funciones asociadas con la clase.

Define métodos dentro del cuerpo de la clase usando la sintaxis estándar de `func`.
Si un método modifica una propiedad, esa propiedad debe declararse con `var`:

```swift
class GameCharacter {
    var characterClass: String?
    var name: String?
    var active = false
    let id: String = makeRandomID()

    func takesDamage(_ damage: Double) {
        if damage > 100 {
            active = false
        }
    }

    func sayName() -> String {
        return "My name is \(name ?? "no one"), my class is \(characterClass ?? "undetermined")"
    }
}
```

Llama a los métodos de una instancia usando la notación de punto, igual que con las propiedades:

```swift
var myChar = GameCharacter()
myChar.active = true
myChar.takesDamage(200)
myChar.active
// => false
```

### Self

Cada instancia de una clase tiene una propiedad implícita llamada `self`, que hace referencia a la instancia misma.
Aunque a menudo se omite al referirse a propiedades o métodos, `self` se usa con frecuencia para distinguir entre nombres de propiedades y nombres de parámetros de métodos cuando comparten el mismo nombre.
