# Números

Crystal tiene un tipo, `Number`, que es el tipo base de todos los tipos numéricos.
Dentro del tipo Number hay dos subtipos principales: [`Int`][int] y [`Float`][float].

`Int` es la abreviatura de integer y representa números enteros.
`Int` puede ser tanto negativo como positivo, sin punto decimal.

```crystal
1.class
# => Int32

-1.class
# => Int32
```

`Float` representa números con punto decimal.
Los `Float` pueden ser tanto negativos como positivos.

```crystal
10.5.class
# => Float64
```

## Conversión entre `Int` y `Float`

Usando los métodos 'to_i' y 'to_f', puedes convertir entre `Int` y `Float`.
El número se redondea hacia abajo cuando conviertes de `Float` a `Int`.

```crystal
1.to_f
# => 1.0

1.0.to_i
# => 1

1.9.to_i
# => 1
```

## Operadores aritméticos

Puedes usar los [operadores aritméticos básicos][math] con `Int` y `Float`.
Los operadores son `+`, `-`, `*`, `/` y `%`.
Cuando usas estos operadores, puedes mezclar `Int` y `Float`.

### Suma, resta y multiplicación

El operador `+` se usa para la suma, el operador `-` se usa para la resta y el operador `*` se usa para la multiplicación.

| Operador | Ejemplo        |
| -------- | -------------- |
| `+`      | `4 + 6 => 10`  |
| `-`      | `15 - 10 => 5` |
| `*`      | `2 * 3 => 6`   |

### División

La división se usa para dividir números.
El operador `/` se usa para la división.
El resultado siempre será un Float.

```crystal
4 / 2
# => 2.0

4.0 / 2
# => 2.0
```

~~~~exercism/caution
En algunos lenguajes de programación, cuando se divide entre cero, el resultado es un error.

En Crystal, cuando se divide entre cero, el resultado es `Infinity` o `-Infinity`.
La única excepción es dividir cero entre cero, lo que da como resultado `NaN` (Not a Number).
`Infinity` y `NaN` son valores particulares del tipo `Float`.

```crystal
1 / 0
# => Infinity

-1 / 0
# => -Infinity

0 / 0
# => NaN
```
~~~~

## División de enteros

La división de enteros se usa para dividir números y obtener la parte entera del resultado.
El resultado siempre se redondea hacia abajo a un Int.

```crystal
4.0 // 2
# => 2

4.5 // 2
# => 2
```

~~~~exercism/caution
Dividir entre cero cuando usas la división de enteros da como resultado un `DivisionByZeroError`.
Esto es diferente de la división normal.
~~~~

### Módulo

El módulo se usa para obtener el residuo de una división.
El operador `%` se usa para el módulo.

```crystal
5 % 2
# => 1

5.0 % 2
# => 1.0

5 % 3
# => 2
```

~~~~exercism/caution
Dividir entre cero cuando usas el módulo da como resultado un DivisionByZeroError.
Esto es diferente de la división normal.

```crystal
1 % 0
# Error: Unhandled exception: Division by 0 (DivisionByZeroError)
```
~~~~

## Exponenciación

La exponenciación se usa para elevar un número a una potencia.
El operador `**` se usa para la exponenciación.
El resultado de una operación con un `Float` y un `Int` será un `Float`.

```crystal
2 ** 2
# => 4

2.0 ** 2
# => 4.0
```

## Redondeo

El método `round` toma un argumento opcional: el número de decimales a los que redondear.
El número de decimales predeterminado es 0.

```crystal
1.0.round
# => 1

1.5.round
# => 2

1.234.round(2)
# => 1.23
```

### Redondear hacia arriba y hacia abajo

También puedes redondear hacia arriba o hacia abajo a un `Int` usando los métodos `ceil` y `floor`.
El método `ceil` redondea hacia arriba y el método `floor` redondea hacia abajo.

```crystal
1.0.ceil
# => 1

1.2.ceil
# => 2

1.7.floor
# => 1
```

## Prioridad y paréntesis

Crystal permite paréntesis (`()`), que se pueden usar para agrupar expresiones.
Esto es útil cuando quieres cambiar el orden de las operaciones.

Cuando usas varios operadores aritméticos, el orden de las operaciones es el mismo que en matemáticas, también conocido como [PEMDAS][pemdas].
Sigue el orden de paréntesis (`()`), exponentes (`**`), multiplicación (`*`) y división (`/`), y suma (`+`) y resta (`-`).

```crystal
2 + 3 - 4 * 4
# => -11

(2 + 3 - 4) * 4
# => 4
```
