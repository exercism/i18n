# Instrucciones

Larry es un alienígena de Lisp al que le gusta escribir código para jugar.
Hoy quiere escribir unas cuantas funciones que le ayuden con un juego muy parecido al tres en línea.

Al igual que el tres en línea, este juego se juega en un tablero que es una cuadrícula de 3x3.

## 1. Empezar desde cero

Primero Larry necesita una función para crear un tablero vacío, `make-empty-board`.
Todas las celdas del tablero deben ser `NIL`.

```lisp
(make-empty-board) ; => #2A((NIL NIL NIL) (NIL NIL NIL) (NIL NIL NIL))
```

## 2. Comenzar a partir de un tablero existente

Después Larry necesita una función para crear un tablero a partir de una lista de filas.
Por ejemplo:

```lisp
(make-board-from-list '((A B C) (D E F) (G H I))) ; => #2A((A B C) (D E F) (G H I))
```

## 3. La condición de victoria

Si hay un caso en el que hay 3 del mismo símbolo en una fila, entonces ese jugador ha ganado.
Larry necesitará una función, `all-the-same-p`, que dado un array de 3 elementos dé como resultado `T` si todos los elementos son el mismo símbolo.
(Puedes usar `eq` para determinar si dos símbolos son iguales).

```lisp
(all-the-same-p #(A A A)) ; => T
(all-the-same-p #(A B C)) ; => NIL
```

## 4. En una fila

Ahora Larry necesita una forma de obtener los elementos de una fila.
La función `row` recibe un tablero y un número de fila y debe devolver un array con los elementos de esa fila.

```lisp
(row #2A((1 2 3) (4 5 6) (7 8 9)) 1) ; => #(4 5 6)
```

## 5. En una columna

Por último, Larry necesita una forma de obtener los elementos de una columna.
La función `column` recibe un tablero y un número de columna y debe devolver un array con los elementos de esa columna.

```lisp
(column #2A((1 2 3) (4 5 6) (7 8 9)) 1) ; => #(2 5 8)
```
