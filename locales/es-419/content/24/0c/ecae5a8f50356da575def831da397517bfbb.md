# Introducción

Los números enteros pueden verse no solo como valores numéricos, sino como patrones de bits. El vocabulario [`math`][math] de Factor tiene las operaciones de bajo nivel estándar sobre esos patrones de bits, y el vocabulario [`math.bitwise`][bitwise] agrega algunos ayudantes para trabajar con valores de ancho fijo.

## Desplazamientos de bits

`shift ( m n -- m' )` desplaza los bits de `m`. Un `n` *positivo* desplaza hacia la izquierda (multiplicando por 2 en cada paso); un `n` *negativo* desplaza hacia la derecha (dividiendo entre 2 en cada paso):

```factor
3 2 shift .     ! => 12   (3 << 2)
24 -3 shift .   ! => 3    (24 >> 3)
```

Para los números enteros positivos, el desplazamiento a la derecha descarta bits por abajo y rellena con ceros. Para los números enteros *negativos*, el `shift` de Factor es aritmético: conserva el bit de signo y, conceptualmente, rellena desde la izquierda con copias del bit de signo. (Los enteros de Factor son de precisión arbitraria, así que «la izquierda» se extiende tanto como haga falta.)

## Lógica de bits

Las cuatro operaciones lógicas básicas son:

```
bitor  ( x y -- z )   ! 1 in either operand
bitand ( x y -- z )   ! 1 in both operands
bitxor ( x y -- z )   ! 1 in exactly one operand
bitnot ( x   -- z )   ! flip every bit
bit?   ( x n -- ? )   ! true when bit at position n is set
```

```factor
0b1011 0b0010 bitor .    ! => 11  (0b1011)
0b1011 0b0010 bitand .   ! => 2   (0b0010)
0b1011 0b0010 bitxor .   ! => 9   (0b1001)
0b1011 bitnot .          ! => -12
0b1011 0 bit? .          ! => t   (low bit is set)
0b1011 2 bit? .          ! => f   (bit 2 is clear)
```

El `bitnot` de `0b1011` es `-12` porque los enteros de Factor son de precisión arbitraria: invertir los bits de `0b1011` es, conceptualmente, «todos unos con los cuatro bits más bajos invertidos a `0100`», lo que, leído como un entero grande con signo, es `-12`.

## Tratar un valor como N bits

`bits ( x n -- y )` de `math.bitwise` enmascara `x` a sus `n` bits bajos. Esta es la forma que tiene Factor de «reinterpretar un valor como un número entero sin signo de N bits»:

```factor
-1 8 bits .              ! => 255   (lowest 8 bits of -1 are all 1)
-2144333657 32 bits .    ! => 2150633639
```

Ese segundo ejemplo es importante para este ejercicio. Si empiezas con un valor Int32 negativo en complemento a dos y quieres desplazarlo a la derecha «lógicamente» (rellenando con ceros desde la izquierda) en `amount`, el modismo de Factor es:

```
( value -- shifted )
32 bits  amount neg  shift
```

Enmascara primero a 32 bits para pasar a la interpretación sin signo, y luego desplaza. Como el valor enmascarado no es negativo, `shift` simplemente descarta bits por abajo y rellena con ceros.
