# Ayuda

Si tienes problemas y necesitas ayuda, puedes usar uno de los siguientes recursos:

- [Oracle - PL/SQL Language Reference](http://docs.oracle.com/cd/E11882_01/appdev.112/e25519/toc.htm)
- [Builtin Function Reference](http://psoug.org/reference/builtin_functions.html)
- [Ask Tom](https://asktom.oracle.com/) - Consejos del gurú de PL/SQL
- [/r/plsql](https://www.reddit.com/r/plsql) es el subreddit de C#.
- [StackOverflow](http://stackoverflow.com/questions/tagged/plsql) puedes usarlo para buscar tu problema y ver si ya lo respondieron. También puedes hacer y responder preguntas.
