# Instrucciones

En este ejercicio vas a documentar el código que acabas de escribir para ayudarte a cocinar una lasaña espectacular. Es poco probable que vuelvas a mirar este código relacionado con la lasaña, pero documentar el código es muy útil si quieres que cualquier proyecto más grande sea comprensible para los demás (¡o incluso para ti!).

Para documentar tu código, escribe un «docstring» para cada una de las tres funciones. Así es como se hace:

- Revisa la sección [Documentación][doc] del manual de Julia.
- Empieza con la firma de la función indentada con 4 espacios.
- Incluye una sola oración de una línea que describa qué hace la función, con tus propias palabras.

Se te proporciona la solución modelo del [ejercicio anterior](https://exercism.lol/tracks/julia/exercises/lasagna).
También puedes elegir tu propia solución de ese ejercicio como punto de partida, si lo prefieres.
~~~~

## 1. Documenta preptime

## 2. Documenta remaining_time

La segunda función que escribiste fue `remaining_time`, que calcula cuánto falta para que la lasaña esté lista.
