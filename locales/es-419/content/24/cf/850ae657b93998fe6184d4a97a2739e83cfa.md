# Introducción

La memoria dinámica se implementa con funciones de biblioteca que el programador usa para asignar y liberar memoria en tiempo de ejecución.
Como el programador controla la asignación y la liberación de memoria, la memoria dinámica es tan segura como libre de errores humanos sea el programador.
Por eso, la memoria dinámica es una de las principales fuentes de bugs de programación y un blanco importante de ataques de hackers.

## malloc

`malloc` es una función declarada en `stdlib.h` que se usa para asignar memoria dinámica.
Si la asignación es exitosa, se devuelve un puntero que apunta a la dirección del primer byte de la memoria asignada.
Si la asignación no es exitosa, se devuelve `NULL`.
Es prudente verificar si el resultado de `malloc` es `NULL` y manejarlo de forma adecuada si falla.
El puntero que se devuelve es de tipo `pointer-to-void`, que a grandes rasgos se puede considerar un puntero «genérico» que se puede convertir al tipo específico que usa la memoria.
`malloc` tiene un parámetro, que es el tamaño de la memoria deseada en bytes.
El tamaño total para asignar un array es el tamaño del tipo de dato de cada elemento multiplicado por la cantidad de elementos.
El operador `sizeof` se usa comúnmente para obtener el tamaño del tipo de dato de cada elemento.
El siguiente ejemplo lo demuestra

```c
#include <stdio.h>
#include <stdlib.h>

int * my_function(int count) {
    // pointer-to-void from malloc is converted to a pointer-to-int
    int * numbers = malloc(sizeof(int) * count);
    return numbers;
}

int main() {
    int * numbers = my_function(3);
    if (!numbers) return -1;
    // printed The size of numbers is 8 bytes (can vary by system)
    printf("The size of numbers is %zu bytes\n", sizeof(numbers));
    numbers[0] = 1;
    numbers[1] = 2;
    numbers[2] = 3;
    // prints The first element of the array is 1
    printf("The first element of the array is %d\n", numbers[0]);
    // prints The second element of the array is 2
    printf("The second element of the array is %d\n", numbers[1]);
    // prints The third element of the array is 3
    printf("The third element of the array is %d\n", numbers[2]);
    free(numbers);
    numbers = NULL;
}
```

Es importante recordar que la memoria que `malloc` acaba de asignar no se inicializa, pero puede contener valores basura.
Ten en cuenta que el `sizeof` del puntero `numbers` no es la cantidad de elementos del array ni la cantidad total de memoria asignada.
El tamaño del puntero que devuelve `malloc` es el tamaño de cualquier puntero en ese sistema en particular.
El código de ejemplo se ejecutó en un sistema de 64 bits, así que el tamaño del puntero era de 8 bytes (multiplicado por 8 bits por byte = 64 bits).
El tipo del puntero se convirtió implícitamente de puntero a void a puntero a int.
También se podría haber convertido explícitamente así: `int * numbers = (int *) malloc(sizeof(int) * count);`.
Si los valores se van a escribir definitivamente antes de leerlos, usar `malloc` puede ser una forma eficiente de asignar memoria.
Pero si existe la posibilidad de que los valores se lean antes de inicializarse, usar `malloc` es riesgoso.
Una forma más segura de asignar memoria es usar `calloc`, que inicializa en cero la memoria recién asignada.

Fíjate que en los ejemplos anteriores se usó `free(numbers)`.

## free

`free` es una función declarada en `stdlib.h` que se usa para liberar memoria que se asignó dinámicamente.
La memoria asignada dinámicamente permanece reservada hasta que `free` la libera.
Algunos sistemas operativos pueden liberar automáticamente la memoria asignada dinámicamente cuando el programa termina, pero es una buena práctica no depender de eso.
`free` tiene un parámetro, que es un puntero a la memoria que se asignó dinámicamente.
Un puntero que no se establece en `NULL` después de liberarlo se conoce como puntero colgante.
Un puntero colgante puede referirse a otra memoria distinta de la que se pretendía.
Por lo tanto, un puntero colgante puede provocar corrupción de datos y la sustitución y ejecución de código arbitrario.
Un puntero a memoria asignada que no se ha limpiado estableciéndolo en `NULL` se puede usar para hackear el programa.
Es una buena práctica establecer un puntero en `NULL` después de pasarlo a `free`.

## calloc

`calloc` es una función declarada en `stdlib.h` que se usa tanto para asignar memoria dinámica como para inicializar en cero la memoria recién asignada.
Si la asignación es exitosa, se devuelve un puntero que apunta a la dirección del primer byte de la memoria asignada.
Si la asignación no es exitosa, se devuelve `NULL`.
Es prudente verificar si el resultado de `calloc` es `NULL` y manejarlo de forma adecuada si falla.
El puntero que se devuelve es de tipo `pointer-to-void`, que a grandes rasgos se puede considerar un puntero «genérico» que se puede convertir al tipo específico que usa la memoria.
`calloc` tiene dos parámetros.
El primer parámetro indica cuántos elementos del tipo de dato especificado se van a asignar.
El segundo parámetro indica el tamaño del tipo de dato especificado que se va a asignar.

En el siguiente ejemplo, todas las sentencias `printf` siempre deben mostrar `0`, ya que `calloc` garantiza poner en cero los valores recién asignados.

```c
#include <stdio.h>
#include <stdlib.h>

int * my_function(int count) {
    // allocates the amount of bytes in an int, multiplied by count
    int * numbers = calloc(count, sizeof(int));
    return numbers;
}

int main() {
    int * numbers = my_function(3);
    if (!numbers) return -1;
    // prints The first element of the array is 0
    printf("The first element of the array is %d\n", numbers[0]);
    // prints The second element of the array is 0
    printf("The second element of the array is %d\n", numbers[1]);
    // prints The third element of the array is 0
    printf("The third element of the array is %d\n", numbers[2]);
    free(numbers);
    numbers = NULL;
}
```

## realloc

`realloc` es una función declarada en `stdlib.h` que se usa para expandir o reducir memoria ya asignada.
Si la reasignación es exitosa, se devuelve un puntero que apunta a la dirección del primer byte de la memoria reasignada.
Si la reasignación no es exitosa, se devuelve `NULL`.
Es prudente verificar si el resultado de `realloc` es `NULL` y manejarlo de forma adecuada si falla.
`realloc` tiene dos parámetros.
El primer parámetro es un puntero a la memoria existente que se va a reasignar.
El segundo parámetro es el tamaño en bytes de la memoria reasignada.
Los valores que se establecieron antes de expandir la memoria se conservan.
Es importante recordar que la memoria que se agrega al expandir no se inicializa en cero y sus valores pueden ser cualquier cosa.
Además, la memoria que se elimina al reducir tampoco se inicializa y podría conservar los valores.
El siguiente ejemplo muestra cómo expandir y reducir un array

```c
#include <stdio.h>
#include <stdlib.h>

int * my_function(int count) {
    // allocates the amount of bytes in an int, multiplied by count
    int * numbers = calloc(count, sizeof(int));
    return numbers;
}

int * my_function_2 (int * ptr , int count) {
    // reallocates the memory to the size of an int multiplied by count
    int * numbers = realloc(ptr, sizeof(int) * count);
    // if realloc fails, exit the program
    if (!numbers) exit(-1);
    return numbers;
}

int main() {
    int * numbers = my_function(3);
    if (!numbers) return -1;
    numbers[0] = 1;
    numbers[1] = 2;
    numbers[2] = 3;
    // expand the size of the array
    numbers = my_function_2(numbers, 6);
    // prints The first element of the array is 1
    printf("The first element of the array is %d\n", numbers[0]);
    // prints The sixth element of the array is [whatever is there]
    // the additional memory is not initialized, so it could be
    // 0 or it could be 18728 or anything else
    printf("The sixth element of the array is %d\n", numbers[5]);
    numbers[5] = 6;
    // shrink the size of the array
    numbers = my_function_2(numbers, 3);
    // prints The sixth element of the array is [whatever is there]
    // the removed memory is not initialized, so it could be
    // 6 or it could be 43164 or anything else
    printf("The sixth element of the array is %d\n", numbers[5]);
}
```
