# Introducción

## Desestructuración de arrays

La sintaxis de desestructuración de arrays de JavaScript es una manera concisa de extraer valores de un array y asignarlos a variables distintas.

En este ejemplo, cada valor del array `numberOfMoons` se asigna a su planeta correspondiente:

```javascript
const numberOfMoons = [0, 2, 14];
const [venus, mars, neptune] = numberOfMoons;

neptune;
// => 14
```

En resumen:

- La sintaxis permite nombrar elementos _según su posición_ en un array, además de intercambiar variables mediante reasignación.
- La sintaxis de desestructuración está disponible dentro de los parámetros de función y en cualquier iterable.
- Dejar una posición sin nombre (al no escribir _ningún_ nombre de variable) ignora esa posición de forma silenciosa.

## Desestructuración de objetos

En JavaScript, también existe la sintaxis de desestructuración para extraer propiedades de un objeto y asignarlas a variables distintas.

En este ejemplo, se extraen símbolos meteorológicos del objeto `weather`:

```javascript
const weather = {
  sun: '☀️',
  sun_behind_small_cloud: '🌤️',
  sun_behind_cloud: '⛅',
  sun_behind_large_cloud: '🌥️',
  sun_behind_rain_cloud: '🌦️',
  cloud: '☁️',
  cloud_with_rain: '🌧️',
  cloud_with_snow: '🌨️',
  cloud_with_lightning: '🌩️',
  cloud_with_lightning_and_rain: '⛈️',
};

const { sun, cloud, cloud_with_lightning: thunder } = weather;

sun;
// => '☀️'

cloud;
// => '☁️'

thunder;
// => '🌩️'
```

En resumen:

- La sintaxis permite tanto extraer propiedades como extraerlas y cambiarles el nombre.
- La sintaxis de desestructuración está disponible dentro de los parámetros de función.
