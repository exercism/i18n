# Instalación

## Instalar tclsh

La única herramienta que necesitas es el intérprete de TCL, `tclsh`.

Para Windows, el mejor lugar para obtener Tcl es [el instalador de Tcl de Magicsplat][magicsplat].

En MacOS y en sistemas operativos tipo Unix, `tclsh` ya vendrá instalado.
Por lo general, la versión instalada será 8.6.*algo*.
Para instalar la versión estable actual, la 9.0:
 - en MacOS, usa [Homebrew][brew].
 - en Linux, revisa tu gestor de paquetes.
 - o [descarga el código fuente][download] y [compílalo][build].

Para resolver ejercicios con la interfaz web de Exercism, el ejecutor de pruebas (a febrero de 2023) usa la versión 8.7a4 de Tcl.

## Usar la shell interactiva de tclsh

Es común iniciar una sesión interactiva de [`tclsh`][tclsh] para probar comandos mientras programas.
Sin embargo, tclsh solo ofrece un intérprete REPL muy básico, sin edición de línea de comandos ni historial de comandos.
Para una mejor experiencia, existe un programa llamado `rlwrap` que agrega la funcionalidad de readline:

```bash
rlwrap tclsh
```

Para instalar rlwrap:
 - en MacOS, usa [Homebrew][brew].
 - en Linux, revisa tu gestor de paquetes.
 - o [descarga el código fuente][rlwrap-download] y [compílalo][rlwrap-build].

Es tan útil que vas a querer usarlo siempre: agrega esto a tu ~/.bashrc

```bash
command -v rlwrap && alias tclsh='rlwrap tclsh'
```

## ¿Qué versión usar?

La versión estable actual es la 9.0.
Como se indicó antes, la versión 8.6 todavía se usa ampliamente.

Puedes comprobar qué versión de `tclsh` tienes instalada ejecutando el siguiente comando:

```bash
echo 'puts [info patchlevel]' | tclsh
```
