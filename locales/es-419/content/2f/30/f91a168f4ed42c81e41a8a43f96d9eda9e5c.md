# Introducción

Recuerda, del concepto Fundamentos, que un programa AWK se compone de **pares de patrón y acción**.

```awk
pattern1 { action1 }
pattern2 { action2 }
...
```

## ¿A qué nos referimos con «patrón»?

El «patrón» es cualquier expresión de AWK.
Si el resultado de la expresión se evalúa como verdadero, se ejecuta la acción.

## El patrón vacío

El patrón se puede omitir.
En ese caso, la acción se ejecuta para cada registro.

Podemos imprimir todos los nombres de usuario del archivo passwd.

```sh
awk -F: '{print $1}' /etc/passwd
```

## Expresiones regulares

AWK puede comparar strings con expresiones regulares para obtener un resultado Boolean.

Usa el operador de coincidencia de expresiones regulares `~` para hacer coincidir un campo en particular.
Este operador toma un string como operando izquierdo y una expresión regular como operando derecho.
Un literal de expresión regular se encierra entre barras (`/`).

Para encontrar los usuarios del archivo passwd que inician sesión con bash:

```sh
awk -F: '$7 ~ /bash/ {print $1}' /etc/passwd
```

`!~` es el operador «la expresión regular **no** coincide».

Para hacer coincidir una expresión regular con el registro actual, puedes usar `$0 ~ /regex/`.
Esto es tan común que existe una forma abreviada: puedes omitir el `$0` y el `~` y simplemente escribir `/regex/`.

```sh
awk '/regex/' data.txt
```

~~~~exercism/note
Compara ese comando de una línea de AWK con el comando grep equivalente

```sh
grep 'regex' data.txt
```

## Expresiones

Las expresiones de AWK (aritméticas, lógicas o de cualquier otro tipo) se pueden usar como patrones.

Para extraer todos los usuarios con UID 1000 o superior:

```sh
awk -F: '$3 >= 1000' /etc/passwd
```

Recuerda que los valores falsos de AWK son el número cero y el string vacío, y que todos los demás números o strings son verdaderos.
Cualquier expresión que se evalúe como un número o un string se puede usar como patrón.

## Funciones

Cualquier función [integrada][builtins] o [definida por el usuario][user-defined] se puede usar en una expresión y, por lo tanto, en el patrón.
Un par de ejemplos:

```awk
length($1) {print "first field is not empty"}
```
```awk
toupper(substr($1, 1, 1)) ~ /[AEIOU]/ {print "starts with a vowel"}
```

## Patrones constantes

Una expresión típica de AWK es:

```sh
{
    xyz()   # some code that transforms each record
}
1
```

`1` es un patrón que se evalúa como verdadero y no tiene acción asociada.
Esto significa «imprime el registro actual».
