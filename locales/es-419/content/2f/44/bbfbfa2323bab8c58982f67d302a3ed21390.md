# golint no está satisfecho

Existe una gran herramienta llamada [`golint`](https://github.com/golang/lint) que examina el código en busca de problemas comunes y cuestiones de estilo.
Ejecuta `golint` sobre la solución, por ejemplo: `golint two_fer.go`; te hará algunas sugerencias útiles.

Siempre es buena idea revisar el código con `golint`.
Cuando escribes software de Go para producción, muchas canalizaciones de compilación fallan automáticamente si el código no pasa `golint`.

Si quieres recibir muchos más comentarios de linters de código, existe el proyecto [golangci-lint](https://github.com/golangci/golangci-lint),
que te permite ejecutar un montón de linters con un solo comando.
Un archivo de configuración del proyecto puede ajustar el comportamiento a las necesidades de cada proyecto.

```
> golint
%{golint}
```
