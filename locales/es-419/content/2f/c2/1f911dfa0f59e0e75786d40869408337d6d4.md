# Introducción

Clojure usa el tipo subyacente `java.lang.Character`, que es una cantidad de 16 bits para representar los componentes más pequeños y direccionables del texto.
Varios `char`s pueden componer un string como `"word"`, o los `char`s se pueden
procesar de forma independiente. Sus literales se escriben así: `\a \b \c`.

Los `char`s de Clojure admiten la codificación Unicode UTF-16, así que además del conjunto de caracteres latinos
se puede representar prácticamente cualquier sistema de escritura que se use en el mundo,
por ejemplo la letra griega `'β'`.

Hay muchos métodos de biblioteca para inspeccionar y manipular `char`s. Se
puede acceder a ellos mediante interoperabilidad, como los métodos de la clase `Character`. Clojure también incluye una biblioteca de utilidades para strings integrada, `clojure.string`, que ofrece muchas funciones potentes para operar con caracteres.
