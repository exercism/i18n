## Argumentos opcionales

```julia-repl
julia> f(a, b=1) = a + b
f (generic function with 2 methods)
```

es equivalente a

```julia-repl
julia> f(a, b) = a + b
f (generic function with 1 method)

julia> f(a) = f(a, 1)
f (generic function with 2 methods)
```

En la respuesta del REPL puedes ver que la primera definición define dos métodos a la vez.
