# Apéndice de instrucciones

## Formato del tablero

El tablero se representa como un string terminado en nulo, con un carácter de salto de línea al final de cada fila.

Un ejemplo sería `"X  \n XO\nOX \n"`

## Registros

| Registro | Uso        | Tipo    | Descripción                                                             |
| -------- | ---------- | ------- | ----------------------------------------------------------------------- |
| `$a0`    | entrada    | dirección | string de entrada terminado en nulo                                    |
| `$v0`    | salida     | entero  | estado del juego (`1` = `ongoing`, `2` = `draw`, `3` = `win`, `-1` = `error`) |
| `$t0-9`  | temporal   | cualquiera | para almacenamiento temporal                                         |
