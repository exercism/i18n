# Introducción

## Strings

Un `string` en C# es un objeto que representa texto inmutable como una secuencia de caracteres Unicode (letras, dígitos, signos de puntuación, etc.). Las comillas dobles se usan para definir una instancia de `string`:

```csharp
string fruit = "Apple";
```

### Métodos

Los strings se manipulan llamando a los [métodos integrados][docs-string-methods] del string.
Por ejemplo, para eliminar los espacios en blanco de un string, puedes usar el [método Trim][tutorial-docs.microsoft.com-trim-white-space] así:

```csharp
string name = " Jane "
name.Trim()
// => "Jane"
```

Una vez que se ha construido un string, su valor nunca puede cambiar.
Cualquier método que parezca modificar un string en realidad devolverá un string nuevo.

### Concatenación

Se pueden concatenar (sumar) varios strings. La forma más sencilla de lograrlo es usando el operador `+`.

```csharp
string name = "Jane";
"Hello " + name + "!";
// => "Hello Jane!"
```

### Formato

Para cualquier formato de string más complejo que una simple concatenación, se prefiere la interpolación de strings. Para usar la interpolación en un string, anteponle el símbolo de dólar (`$`). Luego puedes usar llaves (`{}`) para acceder a cualquier variable dentro de tu string.

```csharp
string name = "Jane";
$"Hello {name}!";
// => "Hello Jane!"
```
