# Acerca de

- Pony tiene tipado estático. Esto significa que *debes* definir los tipos de datos en tus programas de antemano. Si le dices a Pony que la variable `x` es un entero, no puedes asignarle un string.
- El sistema de tipos de Pony es lo que permite las garantías de Pony.
  - Si tu programa compila, no fallará.
  - Nunca habrá una excepción no capturada.
  - No existe `null` como tal, así que tu programa nunca intentará desreferenciar `null`.
  - Nunca habrá una carrera de datos.
  - Nunca habrá un interbloqueo.
  - Tu código siempre tendrá seguridad de capacidades (protección contra ataques de cadena de suministro).
- Pony no te permite convertir tipos. Todos los cambios de tipo deben ocurrir a través de una función que crea una nueva instancia del nuevo tipo.
- El sistema de tipos de Pony es diferente al de casi cualquier otro lenguaje, así que vamos a cubrirlo en partes pequeñas.

## Primitivos

- Los primitivos son la forma más simple de organización del código en Pony.
  - Puedes pensar en ellos como un contenedor o espacio de nombres para funciones.
  - No tienen campos (para eso tenemos las clases).
  - Se definen con la palabra clave `primitive`.

## Funciones

- Las funciones se definen con la palabra clave `fun`.
  - Las funciones deben vivir en un `primitive` (o una `class` o un `actor`), pero eso vendrá después).
  - Las funciones pueden tener argumentos de entrada y un valor de retorno. Deben estar tipadas.
  - Si defines un tipo de retorno, tu función *debe* devolver un valor de ese tipo. Pony no tiene el concepto de Null.

```pony
primitive Greeter
  // A Function that takes a String, and returns a different String
  fun hello(name: String): String =>
    "Hello " + name + "!"
```

## Comentarios

Los comentarios se pueden usar para dejar notas, recordatorios o simplemente eliminar temporalmente código del código fuente. Como ya viste arriba, los comentarios de una sola línea usan `//`. Los comentarios de varias líneas usan el estilo de C: `/*` y `*/`.

## Variables

- Las variables siempre empiezan con una letra minúscula.
  - Las declararemos usando `var`. (`let` y `embed` vienen después).
  - Si Pony puede determinar el tipo de la variable, lo hará por ti.
  - El tipo de la variable se verifica en tiempo de compilación y nunca puede cambiar.
  - Cuando empiezas con Pony, te recomendamos indicar el tipo de forma explícita.

```pony
var name: "Bob"
var bettername: String = "Bobby"
```
