# Introducción

C es un lenguaje de tipado estático, lo que significa que todo tiene un tipo en tiempo de compilación.
Elegir un nombre para una variable y establecer su tipo se conoce como declarar una variable.

Una variable se declara especificando su tipo de forma explícita.
El nombre de una variable debe empezar con una letra o un guion bajo.
Algunos nombres no se pueden usar, ya que están reservados [para palabras clave][reserved-keywords] u [otros identificadores][reserved-identifiers].

Establecer o actualizar la variable se hace mediante una asignación.
Establecer el valor define esa variable.
Definir la variable también se conoce como inicialización.

```c
int foo;      // Declare an integer named var
foo = 10;     // Define the variable

int bar = 15; // Both can also be done in a single statement
```

El valor de una variable se puede asignar y actualizar con el operador de asignación simple `=`.
Una vez definida, el tipo de una variable nunca puede cambiar.

```c
int foo = 10; // Assign initial value
foo = 25;     // Update to new value

foo = false;  // Compiler error when assigning value of a different type
```

C es un lenguaje imperativo y procedimental.
Toda la computación se lleva a cabo mediante una serie de sentencias que forman parte de una función o de varias funciones.

Cada función puede tener cero o más parámetros.
Al definir una función, tanto los parámetros como el valor devuelto deben tener un tipo explícito.
Los valores se devuelven desde las funciones con la palabra clave `return`.
Por defecto, las funciones tienen clase de almacenamiento externa, lo que significa que existen durante toda la vida del programa y pueden ser visibles desde fuera del archivo.
Para evitarlo, se puede añadir la palabra clave `static` y así especificar visibilidad interna.

```c
static int add(int x, int y) {
  return x + y;
}
```

En el ejemplo anterior, las variables `x` y `y` solo se pueden usar dentro de la función, es decir, tienen ámbito de función.
El ámbito es la idea de que el valor asociado a un nombre (de un elemento del programa) solo es accesible dentro del «área» de código donde se define.
Las principales áreas de código en C son:

- archivo
- función
- bloque (por ejemplo, dentro de bucles y otras construcciones)

Las funciones se invocan especificando el nombre de la función y pasando argumentos para cada uno de sus parámetros.

```c
int sum = add(1, 2);
```

C admite dos tipos de comentarios.
Los comentarios de una sola línea van precedidos por `//` (desde C99) y los comentarios de varias líneas se insertan entre `/*` y `*/`.
