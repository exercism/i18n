# Pistas

## General

- Lee sobre el [comportamiento `Access`][access-behaviour] en la documentación.

## 1. Extrae datos de una estructura de mapas anidados

- Primero, tokeniza el string de la ruta hasta un estado usable. Puedes usar las [funciones del módulo `String`][string-module].
- Escribe una función recursiva que recorra la estructura de mapas anidados para obtener el valor o devolver `nil`.

## 2. Refactoriza usando las funciones incluidas

- Revisa las distintas [funciones del módulo `Kernel`][kernel-module] para encontrar una que pueda acortar o simplificar tu enfoque.
