# Instrucciones

La ESA (Exercism Space Agency) está a toda marcha planificando una nueva misión a [Fobos][phobos], una luna de Marte.
El objetivo de la misión es aterrizar una sonda en la superficie de Fobos y enviar datos sobre esa superficie.
La ESA solicita tu ayuda para construir la computadora de navegación de la sonda.
La computadora de navegación tiene memoria limitada, así que necesitamos mantener el uso de memoria lo más bajo posible.
Por lo tanto, necesitamos usar los tipos de datos adecuados.

## 1. Constantes de navegación

La computadora de navegación necesita conocer la distancia entre algunos objetos del espacio para hacer los cálculos correctos; la distancia se mide en km.

Define las siguientes constantes:

- `NEPTUNE_DISTANCE` con el valor `4_400_000_000`, que debe almacenarse como un `Int64`
- `MARS_DISTANCE` con el valor `227_940_000`, que debe almacenarse como un `Int32`
- `ATMOSPHERE_DISTANCE` con el valor `10_000`, que debe almacenarse como un `Int16`

## 2. Análisis correcto del área

La computadora de navegación necesita conocer el área de algunos objetos del espacio para hacer los cálculos correctos.
Un área **NO** puede ser negativa.
Los ingenieros planearon que el programa generara un error de desbordamiento cuando el área fuera negativa.
Sin embargo, los ingenieros olvidaron cambiar el entero con signo por un entero sin signo.

Por lo tanto, los ingenieros quieren un programa que convierta un entero con signo en un entero sin signo.

Implementa el método `Navigation#correct_area_analysis`, que recibe `measurement` como argumento y devuelve el área como un entero sin signo de 32 bits.

~~~~exercism/note
El área dada siempre cabrá como un entero sin signo de 32 bits.
~~~~

```crystal
measurement = 52554
measurement.class
# => Int32

Navigation.new.correct_area_analysis(measurement)
# => 52554

Navigation.new.correct_area_analysis(measurement).class
# => UInt32
```

## 3. Calcula la velocidad

La computadora de navegación necesita conocer la velocidad de la sonda.
La velocidad se mide en m/s.

Para calcular la velocidad, necesitamos conocer la distancia recorrida y el tiempo que tomó recorrer esa distancia.
Luego, toma la distancia y divídela por el tiempo.

La velocidad puede no ser exacta y nunca será un número considerable.
Por lo tanto, podemos usar un `Float32`.

Implementa el método `Navigation#calculate_velocity`, que recibe `distance` y `time` como argumentos y devuelve la velocidad como un `Float` de 32 bits.

```crystal
distance = 52554
time = 2.5

Navigation.new.calculate_velocity(distance, time)
# => 21021.6

Navigation.new.calculate_velocity(distance, time).class
# => Float32
```
