## 1. Trae a los humanos al mundo de Troya

- El núcleo de este ejercicio es el uso de `unique_ptr` y `shared_ptr`.
  ¿Qué tipo de puntero inteligente se debe usar para cada una de las variables `human`?
- `artifacts` no se comparten, pero `powers` se necesitan para hacer seguimiento de las personas influenciadas.
- el puntero `possession` debe ser único, y los punteros de los poderes deben ser compartidos.

## 2. Trae los artefactos a Troya

- Necesitas crear un puntero inteligente y asignarlo a la variable `possession`
- Usa _referencias_ para cambiar el objeto fuera de la función.
- Consulta [`std::make_unique`][make_unique] para ver algunas pistas.
- El tipo del objeto al que apunta el puntero debe ponerse entre los paréntesis angulares y otra vez dentro de los paréntesis para definir el objeto.
- Aquí tienes un ejemplo completo: `variable = std::make_unique<int>(int{23});`
