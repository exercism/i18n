# Introducción

## Operadores ternarios

El _operador ternario_ es una alternativa ligera y compacta para sentencias _if/else_ simples.
Por lo general se usa en las sentencias que devuelven un valor (aunque no está limitado a ellas), y necesita una sola línea para tomar la decisión: devuelve el valor de la izquierda si la expresión es `true` y el de la derecha si es `false`, así:

```java
boolean expr = 0 != 200;

// Ternary statement
int value = expr ? 22 : 33;
// => 22
```

Muchas expresiones _if/else_ simples se pueden simplificar usando _operadores ternarios_.
