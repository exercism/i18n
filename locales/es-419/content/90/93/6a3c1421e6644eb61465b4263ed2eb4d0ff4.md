# Acerca de

Un [registro][records] es una colección de campos (que pueden ser de distintos tipos) que van juntos. Para [definir un registro][define] se usa la palabra clave `type`. Los campos de un registro se definen entre los caracteres `{` y `}` y cada campo tiene un nombre _y_ un tipo.

```fsharp
type Address =
    { Street: string
      HouseNumber: int }
```

Para [crear un registro][create], especifica los nombres de los campos y asígnales un valor entre los caracteres `{` y `}`. Todos los campos de un registro deben tener asignado un valor cuando lo creas. Los campos se pueden especificar en cualquier orden, no tienen que coincidir con el orden de la definición del tipo de registro. Para acceder a los valores de los campos de una instancia de registro se usa la notación de punto.

```fsharp
let oldAddress: Address =
    { Street = "Main Street"
      HouseNumber = 17 }

oldAddress.Street      // => "Main Street"
oldAddress.HouseNumber // 17
```

Al definir o crear un registro, cada campo debe estar en una línea aparte o separado por punto y coma (`;`) cuando están en una sola línea:

```fsharp
type Address = { Street: string; HouseNumber: int }

let oldAddress: Address = { Street = "Main Street"; HouseNumber = 17 }
```

Si los nombres de los campos de un registro son únicos, las anotaciones de tipo son opcionales, ya que el compilador podrá inferir el tipo automáticamente. Si la combinación de nombres de campos _no_ es única, puedes ayudar al compilador a elegir el registro correcto usando un tipo explícito para el enlace del registro o anteponiendo el tipo del registro a uno o más de los campos:

```fsharp
type Boat = { Weight: int; Length: int }
type Car = { Weight: int; Length: int }

// Let compiler infer type. As there are multiple matching record types,
// the last matching type is used (Car)
let typeEqualsLastMatch = { Weight = 5000; Length = 15 }

// Use type annotation on binding to force type to Boat
let typeAnnotation: Boat = { Weight = 5000; Length = 15 }

// Use fully qualified name for field to force type to Boat
let fullyQualifiedField = { Boat.Weight = 5000; Length = 15}
```

Como los registros son inmutables, una vez que se ha construido un registro, los valores de sus campos nunca pueden cambiar. Si quieres cambiar los valores de un registro, la palabra clave `with` te permite [crear una copia de un registro existente, pero con valores nuevos para uno o más campos][create].

```fsharp
// Copy the old address but change the house number
let newAddress = { oldAddress with HouseNumber = 86 }
newAddress.Street      // => "Main Street"
newAddress.HouseNumber // => 86
```

Los registros tienen [_igualdad estructural_][equality], lo que significa que dos instancias del mismo registro con valores idénticos son equivalentes:

```fsharp
let address1 = { Street = "Main Street"; HouseNumber = 17 }
let address2 = { Street = "Main Street"; HouseNumber = 17 }
let address3 = { Street = "Broadway"; HouseNumber = 17 }

address1 = address2 // => true
address1 = address3 // => false
```

Además de poder usar la notación de punto para acceder a los campos de un registro, los registros también se pueden _deconstruir_ en enlaces y en coincidencia de patrones usando el [patrón de registro][record-patterns]:

```fsharp
let myAddress = { Street = "Broadway"; HouseNumber = 123 }
let { Street = myStreet; HouseNumber = myHouseNumber } = myAddress

match myAddress with
| { HouseNumber = 1 } -> printfn "First house"
| { HouseNumber = houseNumber; Street = street } -> printfn "House number %d on %s" houseNumber street
// => "House number 123 on Broadway
```
