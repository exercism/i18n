# Instrucciones

Los dos objetivos de este ejercicio son:

1. Implementa una función `promisify` que convierta una función que usa el «patrón de callback» en una función que devuelve una `Promise`. Mira el ejemplo a continuación.

```javascript
function fetchProduct(productId, function(error, data) {
    if (error) {
        // Handle the error
    } else {
        // Make something with your data
    }
})

const fetchProductAsPromise = promisify(fetchProduct);

// Now you got a function `fetchProductAsPromise`
// that returns a promise
fetchProductAsPromise(productId)
    .then((data) => {})
    .catch((error) => {});
```

2. Reimplementa los siguientes métodos integrados de `Promise` (sin usarlos)

- `all`: recibe un array de promesas y se resuelve cuando _todas_ ellas se resuelven, o se rechaza cuando _una_ de ellas se rechaza.
- `allSettled`: recibe un array de promesas y se resuelve cuando _todas_ ellas se resuelven o se rechazan.
- `race`: recibe un array de promesas y se resuelve o se rechaza con el valor de la _primera_ promesa que se resuelva o se rechace.
- `any`: recibe un array de promesas y se resuelve cuando _una_ de ellas se resuelve, o se rechaza cuando _todas_ ellas se rechazan.
