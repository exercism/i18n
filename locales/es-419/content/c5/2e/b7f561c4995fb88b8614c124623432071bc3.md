# Instrucciones

En este ejercicio vas a generar mensajes de log semiestructurados.

## Emite mensajes semiestructurados

Empezarás con algunas funciones sin implementar y el siguiente enum:

```rust
#[derive(Drop, Clone, PartialEq, Debug)]
pub enum LogLevel {
    Info,
    Warning,
    Error,
    Debug
}
```

Tu objetivo es emitir un mensaje de log con este formato: `"[<LEVEL>]: <MESSAGE>"`.
Vas a tener que implementar funciones que se correspondan con los niveles de log.

Por ejemplo, el siguiente fragmento muestra una salida esperada para la función `log`.

```rust
log(LogLevel::Error, "Stack overflow")
// Returns: "[ERROR]: Stack overflow"
```

Y para `info`:

```rust
info("Timezone changed")
// Returns: "[INFO]: Timezone changed"
```

¡Diviértete!
