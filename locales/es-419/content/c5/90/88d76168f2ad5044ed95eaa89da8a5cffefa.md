# Instrucciones

Una escuela local cerca de ti tiene una asociación estudiantil muy activa.
La asociación estudiantil es dirigida por un presidente y cada 2 años
se realizan elecciones para elegir a un nuevo presidente.

En las elecciones de este año, se decidió que se necesitaba un nuevo sistema digital para contar los votos.
La escuela necesita tu ayuda para construir este nuevo sistema.

## 1. Crea un contador de votos

Una de las primeras cosas que necesita el nuevo sistema de votación es un contador de votos.
Este contador es una forma de llevar un registro de los votos que tiene un candidato en particular.

Crea una función `NewVoteCounter` que acepte el número de votos iniciales de un candidato y devuelva un puntero que apunte a un `int`, inicializado con el número de votos iniciales dado.

```go
var initialVotes int
initialVotes = 2

var counter *int
counter = NewVoteCounter(initialVotes)
*counter == initialVotes // true
```

## 2. Obtén el número de votos de un contador

¡Ya tienes una forma de crear nuevos contadores! Pero ahora te das cuenta de que el nuevo sistema también necesitará una forma de obtener el número de votos de un contador.

Crea una función `VoteCount` que tome un contador (`*int`) como argumento y devuelva el número de votos del contador.
Si el contador es `nil`, debes asumir que el contador no tiene votos:

```go
var votes int
votes = 3

var voteCounter *int
voteCounter = &votes

VoteCount(voteCounter)
// => 3

var nilVoteCounter *int
VoteCount(nilVoteCounter)
// => 0
```

## 3. Incrementa los votos de un contador

¡Por fin es hora de contar los votos! Ahora necesitas una forma de incrementar los votos de un contador.

Crea una función `IncrementVoteCount` que tome un contador (`*int`) como argumento y un número de votos, e incremente el contador en ese número de votos.
Puedes asumir que el puntero que se pasa nunca será `nil`.

```go
var votes int
votes = 3

var voteCounter *int
voteCounter = &votes

IncrementVoteCount(voteCounter, 2)

votes == 5          // true
*voteCounter == 5   // true
```

## 4. Crea los resultados de la elección

Con todos los votos contados, es hora de preparar el anuncio de los resultados para toda la escuela.
Para esto, te das cuenta de que tener solo contadores de votos no es suficiente.
Se necesita una forma de asociar el número de votos con un candidato en particular.

Crea una función `NewElectionResult` que reciba el nombre de un candidato y su número de votos y
devuelva un nuevo resultado de la elección.

```go
var result *ElectionResult
result = NewElectionResult("Peter", 3)

result.Name == "Peter"  // true
result.Votes == 3       // true
```

La estructura del resultado de la elección ya está creada para ti y se define así:

```go
type ElectionResult struct {
    // Name of the candidate
    Name    string
    // Votes of votes the candidate had
    Votes   int
}
```

## 5. Anuncia los resultados

¡Es hora de anunciar al nuevo presidente a la escuela!
El presidente será anunciado en los pequeños tableros de mensajes digitales que tiene la escuela.
El mensaje debe mostrar el nombre del nuevo presidente y los votos que tuvo, en el siguiente formato: `<candidate_name> (<votes>)`.
Este es un ejemplo de tal mensaje: `"Peter (51)"`.

Crea una función `DisplayResult` que reciba un `*ElectionResult` como argumento y devuelva una cadena con el mensaje que se debe mostrar.

```go
var result *ElectionResult
result = &ElectionResult{
    Name: "John",
    Votes: 32,
}

DisplayResult(result)
// => John (32)
```

## 6. Recuento de votos

Para asegurarte de que los resultados finales fueran precisos, se volvieron a contar los votos.
En el recuento, se encontró que el número de votos de algunos candidatos estaba desviado por uno.

Crea una función `DecrementVotesOfCandidate` que reciba los resultados finales y el nombre de un candidato cuyo número de votos debes disminuir.
Los resultados finales se dan en forma de un `map[string]int`, donde las claves son los nombres de los candidatos y los valores son su total de votos.

```go
var finalResults = map[string]int{
    "Mary":  10,
    "John":  51,
}

DecrementVotesOfCandidate(finalResults, "Mary")

finalResults["Mary"]
// => 9
```
