# Introducción

## Conversión de tipos

Go requiere una conversión explícita entre tipos diferentes.
La conversión entre tipos (también conocida como **casting**) se hace mediante una función con el nombre del tipo al que quieres convertir.
Por ejemplo, para convertir un `int` a un `float64` tendrías que hacer lo siguiente:

```go
var x int = 42 // x has type int
f := float64(x) // f has type float64 (ie. 42.0)
```

## Conversión entre tipos primitivos y strings

Existe un paquete `strconv` para convertir entre tipos primitivos (como `int`) y `string`.

```go
import "strconv"

var intString string = "42"
var i, err = strconv.Atoi(intString)

var number int = 12
var s string = strconv.Itoa(number)
```

## Aserciones de tipo

Las interfaces en Go pueden introducir ambigüedad sobre el tipo subyacente.
Una aserción de tipo nos permite extraer el valor concreto subyacente del valor de la interfaz usando esta sintaxis: `interfaceVariable.(concreteType)`.

Por ejemplo:

```go
var input any = 12
number := input.(int)
```

NOTA: esto provocará un panic si la variable de interfaz no contiene un valor del tipo concreto.

Podemos comprobar si un valor de interfaz contiene un tipo concreto específico usando los dos valores de retorno de la aserción de tipo: el valor subyacente y un valor Boolean que indica si la aserción tuvo éxito.
Por ejemplo:

```go
str, ok := input.(string) // no panic if input is not a string
```

Si `input` contiene un `string`, entonces `str` será el valor subyacente y `ok` será true.
Si `input` no contiene un `string`, entonces `str` será el valor cero del tipo `string` (es decir, `""`, el string vacío) y `ok` será false.
En ningún caso ocurre un panic.

## Type switch

Un **type switch** puede realizar varias aserciones de tipo en serie.
Tiene la misma sintaxis que una aserción de tipo (`interfaceVariable.(concreteType)`), pero `concreteType` se reemplaza por la palabra clave `type`.
Aquí tienes un ejemplo:

```go
var i any = 12 // try: 12.3, true, int64(12), []int{}, map[string]int{}

switch v := i.(type) {
case int:
    fmt.Printf("the integer %d\n", v)
case string:
    fmt.Printf("the string %s\n", v)
default:
    fmt.Printf("type, %T, not handled explicitly: %#v\n", v, v)
}
```
