# Introducción

Common Lisp tiene muchos predicados de igualdad distintos.
Esto es diferente de otros lenguajes de programación, que quizás solo tengan uno o dos (por ejemplo, `==` y `===`).
Algunos de estos predicados en Common Lisp son específicos de ciertos tipos, mientras que otros son genéricos.
Estos últimos son los que veremos aquí.

Hay cuatro predicados de igualdad genéricos y se diferencian en qué tan restrictivos son respecto a lo que consideran «igual».
Son, en orden del más restrictivo al menos restrictivo: `eq`, `eql`, `equal` y `equalp`.

Un conjunto rápido de definiciones (dejando fuera algunos detalles) es el siguiente:

- `eq`: define la igualdad como que los dos objetos son idénticos.
  _por ejemplo:_:

```lisp
(eq 'a 'a)                 ; => T
(eq (list 1 2) (list 1 2)) ; => NIL
```

- `eql`: define la igualdad como: dos números con el mismo tipo y valor, dos caracteres que son iguales,
  o, para cualquier otra cosa, si son `eq`.
  _por ejemplo:_:

```lisp
(eql 1 1)     ; => T
(eql #\a #\a) ; => T
(eql 1 1.0)   ; => NIL
(eql #\a #\A) ; => NIL
```

- `equal`: define la igualdad como: dos listas son `equal` si cada elemento también es `equal`; dos strings son `equal` si cada elemento es `eql`; dos arrays son `equal` si son `eq`; todo lo demás es `equal` si es `eql`.
  _por ejemplo:_:

```lisp
(equal (list 1 2) (list 1 2)) ; => T
(equal #(1 2) #(1 2))         ; => NIL
(equal "foo" "foo")           ; => T
```

- `equalp`: define la igualdad como: los strings y los caracteres se comparan sin distinguir mayúsculas y minúsculas; los números se comparan con cierta conversión de tipos; las listas y los arrays son `equalp` si cada elemento también es `equalp`, las estructuras si son del mismo tipo y todas sus ranuras son `equalp`, y las tablas hash si sus claves y valores son `equalp`
  _por ejemplo:_:

```lisp
(equalp "foo" "FoO")                          ; => T
(equalp 3 3.0)                                ; => T
(equalp (make-a-structure :slot1 1 :slot2 2) 
        (make-a-structure :slot1 1 :slot2 2)) ; => T
```
