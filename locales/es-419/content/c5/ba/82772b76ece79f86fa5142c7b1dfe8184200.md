# Acerca de

En Haxe, un **array** es una colección de elementos (normalmente) del mismo tipo. Hay tres formas de crear un array en Haxe; ya sea con un constructor o con una sintaxis de declaración. En Haxe, el primer elemento de un array tiene un índice de cero:

```haxe
var a = [1, 2, 3];
trace(a); // [1,2,3]

// Here the second element is called by index
trace(a[1]); // 2

// The actual first element's index is 0
trace(a[0]); // 1
```

Para crear un array con un constructor, debes pasar el tipo de los elementos que se van a incluir en el array:

```haxe
var a:Array<Int> = [0, 1, 2, 3];
a[1] = "Hello"; // Error: the array a takes integers only
```

Como el acceso a los arrays en Haxe no tiene límites, es decir, se garantiza que no lanza una excepción, esto requiere una explicación más detallada:

- Si se hace un acceso de lectura a un índice que no existe, se devuelve un valor que depende del target.
- Si se hace un acceso de escritura con un índice positivo que está fuera de los límites, se inserta `null` (o el valor predeterminado para los tipos básicos en los targets estáticos) en todas las posiciones entre el último índice definido y el recién escrito.
- Si se hace un acceso de escritura con un índice negativo, el resultado no está especificado.

Si queremos que un array contenga varios tipos de elementos, agregamos el tipo `Dynamic` al indicador de tipo:

```haxe
var a:Array<Dynamic> = [10, "Bob", true]
```

## Iteración

Los arrays se pueden iterar con un bucle `for`:

```haxe
var nums = [2, 3, 5];
var sum = 0;
for (num in nums) {
  sum += num;
}
trace(sum); // 10
```
