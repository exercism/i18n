# Introducción

Swift tiene un conjunto de sentencias que se pueden usar para alterar el flujo de control normal de los bucles.
Estas se conocen como sentencias de transferencia de control.
Ya viste `return`; en este concepto conocerás otras, entre las que se incluyen `continue`, `break` y las etiquetas.

## Continue

A veces es necesario saltar anticipadamente a la siguiente iteración de un bucle, sin completar el resto de las sentencias de la iteración actual del bucle.
La palabra clave `continue` se puede usar para esto.
Cuando se ejecuta `continue`, el bucle salta a la siguiente comprobación para ver si se puede ejecutar la siguiente iteración, es decir, el `while` en los bucles while y repeat-while, o la comprobación de si hay otro elemento en la secuencia en los bucles for-in.

```swift
count = 1
while count < 6 {
  count += 1
  if count == 4 { continue }
  print(count)
}

// prints:
// 2
// 3
// 5
```

## Break

Break se usa para salir de un bucle anticipadamente.
Cuando se ejecuta `break`, el bucle se cierra de inmediato y el programa continúa con la primera sentencia después del bucle.

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  if !fruit.count.isMultiple(of: 2) { break }
  print(fruit)
}

// prints:
// banana
// grapes
```

## Etiquetas

Cuando los bucles están anidados, hay veces en que uno puede querer usar `break` o `continue` para salir o reiniciar los bucles externos que contienen el bucle en el que se usan `break` o `continue`.
En casos como estos, se pueden usar etiquetas para especificar el bucle que se va a cerrar o reiniciar.
Un bucle se puede etiquetar colocando un nombre seguido de dos puntos antes del `while`, `repeat` o `for` que inicia el bucle.

Para ver el efecto de usar etiquetas de esta manera, considera el siguiente bucle.

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  print("\n--- \(fruit) ---")
  for letter in fruit {
    guard letter != "n" else { break outerLoop }
    print(letter)
  }
}

// prints:
// --- banana ---
// b
// a
```

## Fallthrough

La palabra clave `fallthrough` se usa para pasar al siguiente caso de una sentencia switch.
Esto significa que el código dentro del siguiente caso se ejecutará sin comprobar su(s) condición(es).
Esto hará que la sentencia switch se comporte como en otros lenguajes de programación, donde la sentencia `break` no es necesaria para salir de la sentencia switch después de que coincida un caso.
Puedes leer más sobre `fallthrough` en el [libro de Swift][fallthrough].

```swift
let value = 1
switch value {
case 1:
  print("One")
  fallthrough
case 2:
  print("Two")
}

// prints:
// One
// Two
```
