# Pruebas

Para ejecutar las pruebas, ejecuta el comando `bal test --offline` desde el directorio del ejercicio.

## Pruebas omitidas

Al principio, solo la primera prueba estará habilitada.
Esto es para animarte a resolver el ejercicio paso a paso.
Una vez que logres que la primera prueba pase, elimina la propiedad `enable: false` de la siguiente prueba y trabaja para que esa prueba también pase.
