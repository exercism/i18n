# Introducción

Haxe es fuertemente tipado, pero el sistema de tipos se puede subvertir cuando sea necesario. Asignar un valor a un nombre se conoce como definir una variable. Una variable se puede definir ya sea especificando su tipo explícitamente, o dejando que el compilador de Haxe infiera el tipo. Por lo tanto, las siguientes dos definiciones de variable son equivalentes:

```haxe
var explicitVariable:Int = 10; // Explicitly typed
var implicitVariable = 10; // Implicit typed
```

Para actualizar una variable, puedes usar el operador `=`:

```haxe
var number = 0; // Initial value
number = 1; // Updated value
```

El compilador lanzará un error al intentar asignar un valor cuyo tipo sea distinto al de la variable:

```haxe
var number = 1; // Variable number is of integer type
number = "Hello" // Error trying to assign a string to an integer variable
```

Una función que está dentro de una clase se llama _método_. Los métodos pueden tener cero o más parámetros. Todos los parámetros deben tener su tipo especificado explícitamente. Al igual que los parámetros, el tipo que devuelve un método no se puede inferir y debe especificarse. Los valores se devuelven de los métodos con la palabra clave `return`:

```haxe
function add(x:Int, y:Int):Int {
  return x + y;
}
```

Para invocar un método, especificas su clase y el nombre del método, y pasas argumentos:

```haxe
var sum = add(1, 2) // sum = 3
```

El ámbito en Haxe se define entre los caracteres `{` y `}`.

Haxe admite dos tipos de comentarios. Los de una sola línea van precedidos por `//` y los comentarios multilínea se insertan entre `/*` y `*/`.
