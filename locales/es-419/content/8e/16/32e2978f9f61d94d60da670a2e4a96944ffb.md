# Paquetes

En la pista de F# se admiten los siguientes paquetes:

| Paquete         | Versión |
| --------------- | ------- |
| Aether          | 8.3.1   |
| BenchmarkDotNet | 0.12.1  |
| FParsec         | 1.1.1   |

```exercism/caution
Si tu código usa una combinación de paquete y versión no admitida, las pruebas en el sitio web fallarán.
```
