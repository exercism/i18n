# Instrucciones

Cuenta los rectángulos en un diagrama ASCII como el de abajo.

```text
   +--+
  ++  |
+-++--+
|  |  |
+--+--+
```

El diagrama de arriba contiene estos 6 rectángulos:

```text


+-----+
|     |
+-----+
```

```text
   +--+
   |  |
   |  |
   |  |
   +--+
```

```text
   +--+
   |  |
   +--+


```

```text


   +--+
   |  |
   +--+
```

```text


+--+
|  |
+--+
```

```text

  ++
  ++


```

Puedes suponer que la entrada siempre es un rectángulo bien formado (es decir, la longitud de cada línea es igual a la longitud de la primera línea).
