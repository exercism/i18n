# Pruebas

## Clojure CLI

Los ejercicios de Clojure en Exercism vienen con un archivo `deps.edn` con un alias `:test` para invocar el [cognitect-labs test-runner](https://github.com/cognitect-labs/test-runner):

``` bash
$ clj -X:test
```

## Leiningen

También se puede usar Leiningen para ejecutar las pruebas del ejercicio ejecutando el siguiente comando desde el directorio del ejercicio:

```bash
lein test
```

## REPL

Para usar el REPL y ejecutar las pruebas del ejercicio, ejecuta el siguiente comando desde el directorio del ejercicio:

```bash
$ clj
```

-o-

```bash
$ lein repl
```

Luego, `require` el espacio de nombres de prueba del ejercicio y el espacio de nombres de prueba de Clojure):

```clojure
;; replace <exercise> with the exercise's name
=> (require '<exercise>-test)
```

Luego, llama a `run-tests` en `<exercise>-test`:

```clojure
;; replace <exercise> with the exercise's name
=> (clojure.test/run-tests '<exercise>-test)
```
