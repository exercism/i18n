# Anexo de las instrucciones

## Implementación

Es posible que se agoten los nombres de robots: una vez que se hayan asignado todos los nombres posibles, se debe devolver un error.

## Test adicional

Una vez que logres que `go test` pase, verás que hay un test en la suite de tests llamado `TestCollisions` que se omite de forma predeterminada, ya que puede tardar mucho.
Este test crea nuevos robots hasta que ya no se puedan asignar más nombres nuevos al robot.

Para que el test se ejecute, elimina esta línea:

```go
t.Skip("skipping test as it can take a long time to run if solution is sub-optimal.")
```

Para que este test pase, tendrás que asegurarte de que el nombre de un robot no se haya usado antes y de que los nombres se puedan asignar de forma eficiente.
