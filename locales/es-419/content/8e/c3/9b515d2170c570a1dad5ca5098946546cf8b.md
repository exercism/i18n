# Apéndice de instrucciones

## Notas de implementación

`Range` debe devolver un array de todas las ternas pitagóricas con lados en el rango de `min` a `max`, inclusive.

`Sum` debe devolver un array de todas las ternas pitagóricas cuya suma `a+b+c` (el perímetro) sea igual a `p`.
Los tres elementos de cada terna devuelta deben estar en orden, `t[0] <= t[1] <= t[2]`, y el array de ternas debe estar en orden lexicográfico.
