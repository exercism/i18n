# Instrucciones

En este ejercicio escribirás código para ayudar a un freelancer a comunicarse con sus clientes sobre los precios de ciertos proyectos.
Escribirás algunos métodos de utilidad para calcular rápidamente los costos para los clientes.

```exercism/note
El parámetro `rate_per_hour` y el método `day_rate` están relacionados con el dinero.
Las unidades de medida son dinero por unidad de tiempo: horas y días, respectivamente.
```

## 1. Calcula la tarifa diaria a partir de una tarifa por hora

Un cliente contacta al freelancer para preguntar por sus tarifas.
El freelancer explica que **_trabaja 8 horas al día._**
Sin embargo, el freelancer solo conoce sus tarifas por hora del proyecto.
Ayuda al freelancer a estimar una tarifa diaria a partir de una tarifa por hora.

```abap
DATA(freelancer_rates) = NEW zcl_freelancer_rates( ).

freelancer_rates->day_rate( 89 ).
// => 712
```

La tarifa diaria no necesita redondearse ni cambiarse a una precisión «fija».

## 2. Calcula la cantidad de días laborables a partir de un presupuesto fijo

Otro día, un gerente de proyecto le ofrece al freelancer trabajar en un proyecto con un presupuesto fijo.
Dados el presupuesto fijo y la tarifa por hora del freelancer, ayuda al freelancer a calcular la cantidad de días que trabajaría hasta agotar el presupuesto.
El resultado _debe_ **redondearse hacia abajo** al número entero más cercano.

```abap
freelancer_rates->days_in_budget(
  budget        = 20000
  rate_per_hour = 89 ).
// => 28
```

## 3. Calcula la tarifa con descuento para proyectos grandes

A menudo, los clientes del freelancer lo contratan para proyectos que se extienden a lo largo de varios meses.
En estos casos, el freelancer decide ofrecer un descuento por cada mes completo, y los días restantes se facturan a la tarifa diaria.
Tu excelente equilibrio entre el trabajo y la vida personal hace que solo trabajes 22 días en cada mes calendario, así que **_cada mes tiene 22 días facturables._**
Ayuda al freelancer a estimar su costo para este tipo de proyectos, a partir de una tarifa por hora, la cantidad de días facturables que contiene el proyecto y una tasa de descuento mensual.
El descuento siempre se pasa como un número, donde `42%` se convierte en `0.42`. El resultado _debe_ **redondearse hacia arriba** al número entero más cercano.

```abap
freelancer_rates->price_with_monthly_discount(
  rate_per_hour = 89
  num_days      = 230
  discount      = '0.42' ).
// => 97972
```
