# Pistas

## General

- No olvides el `;` después de cada sentencia.
- Puedes definir un entero con `int myInteger = 44;`.

## 1. Obtén el tiempo de horneado.

- Las instrucciones tienen información sobre el tiempo de la receta.
- Una función puede devolver un valor con la forma `return 2;`

## 2. Obtén el tiempo de preparación.

- Puedes acceder al número de capas usando el parámetro correspondiente.
- Puedes hacer cálculos cuando defines un entero: `int myInteger = 3 + myOtherInteger;`

## 3. Calcula el tiempo que queda en el horno

- Puedes llamar a otras funciones y usar el valor devuelto como si fueran variables: `return 22 * myOtherCalculation();`

## 4. Calcula el tiempo total que se dedica a la lasaña

- El resultado debe combinar el tiempo de preparación con el tiempo que la lasaña ya lleva en el horno.
