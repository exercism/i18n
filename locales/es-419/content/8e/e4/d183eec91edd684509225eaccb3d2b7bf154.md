# Pistas

## General

- Lee sobre las listas de palabras clave en la [guía oficial de introducción][getting-started-keyword-lists].
- Lee sobre las listas de palabras clave en [elixirschool.com][elixir-school-keyword-lists].
- Echa un vistazo a la [documentación del módulo `Keyword`][keyword].

## 1. Explica los colores de los vinos

- Debes escribir la información que aparece en la tabla como una lista de palabras clave.
- Echa un vistazo a algunos [ejemplos][keyword-examples] de cómo definir una lista de palabras clave.

## 2. Obtén todos los vinos de un color dado

- Hay una [función incorporada][keyword-get-values] para obtener la lista de todos los valores de una clave dada.

## 3. Obtén todos los vinos de un color dado embotellados en un año dado

- Hay una [función incorporada][keyword-get] para obtener un único valor de una clave dada.
- No necesitas implementar el filtrado de botellas por tu cuenta. Solo necesitas usar de forma condicional la función `filter_by_year/2`, que ya está implementada.

## 4. Obtén todos los vinos de un color dado embotellados en un país dado

- Hay una [función incorporada][keyword-get] para obtener un único valor de una clave dada.
- No necesitas implementar el filtrado de botellas por tu cuenta. Solo necesitas usar de forma condicional la función `filter_by_country/2`, que ya está implementada.
