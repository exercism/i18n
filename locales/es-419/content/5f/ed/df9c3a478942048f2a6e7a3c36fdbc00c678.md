# Acerca de

Los [operadores ternarios][ternary-operators] permiten definir condicionales `if` dentro de expresiones en lugar de en bloques de sentencia. Esto se asemeja a los enfoques de la programación funcional y a menudo puede hacer que el código sea más expresivo y menos propenso a errores.

El operador ternario combina 3 expresiones: una condición seguida de una expresión que se evalúa y se devuelve si la condición es verdadera (la parte `if`, introducida por `?`) y una expresión que se evalúa y se devuelve si la condición es falsa (la parte `else`, introducida por `:`).

```csharp
int a = 3, b = 4;
int max = a > b ? a : b;
// => 4
```
