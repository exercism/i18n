# Anexo de instrucciones

## Instrucciones específicas del track

Tu tarea es escribir tres funciones

- `latest`: que recibe un array de puntuaciones y devuelve la última.
- `personalBest`: que recibe un array de puntuaciones y devuelve la mejor puntuación.
- `personalTopThree`: que recibe un array de puntuaciones y devuelve las tres mejores puntuaciones en orden descendente.
