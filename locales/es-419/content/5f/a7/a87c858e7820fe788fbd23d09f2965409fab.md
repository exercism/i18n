## Escribir el código

Escribe tu código en `src/lib.cairo`.
Los ejercicios vienen con un archivo stub en `src/lib.cairo` que te mostrará las firmas del código que necesitarás escribir.

En la mayoría de los ejercicios, lo mejor es escribir todo tu código en el archivo `src/lib.cairo`.
Si quieres dividir tu solución en varios archivos, consulta el [capítulo sobre módulos][chapter-modules] de The Cairo Book.

[chapter-modules]: https://book.cairo-lang.org/ch07-02-defining-modules-to-control-scope.html

## Ejecutar las pruebas

Para ejecutar las pruebas, primero necesitas cambiar tu directorio de trabajo al directorio del ejercicio que quieres probar:

```bash
cd path/to/exercise
```

Y después ejecuta el siguiente comando:

```bash
scarb cairo-test
```

Solo la primera prueba está habilitada de forma predeterminada.
Cuando estés listo para pasar la siguiente prueba, quita el indicador ignore de la siguiente prueba (`#[ignore]`).

Para ejecutar todas las pruebas, incluidas las ignoradas, puedes quitar el indicador `ignore` de todas las pruebas, o simplemente ejecutar:

```bash
scarb cairo-test --include-ignored
```

No dudes en escribir la menor cantidad de código posible para que las pruebas pasen.
Los errores en las pruebas te guiarán sobre qué escribir a continuación.

Como Cairo verifica todo el código en tiempo de compilación, puede que tus pruebas no compilen hasta que escribas el código requerido.
Incluso las pruebas marcadas con `ignore` se verifican en tiempo de compilación.
Puedes [comentar][comments] las pruebas que no compilen empezando cada línea con un `//`.
Después, cuando estés listo para trabajar en esa prueba, puedes quitar el comentario.
Cairo también tiene una macro especial llamada `panic!()`, que puedes usar en partes del código sin terminar para que tu programa compile.

[comments]: https://book.cairo-lang.org/ch02-04-comments.html
