# Acerca de

C# tiene varios operadores para manipular bits:

- [`&`][and-operator]: AND bit a bit
- [`|`][or-operator]: OR bit a bit
- [`~`][complement-operator]: complemento bit a bit
- [`<<`][left-shift-operator]: desplazamiento a la izquierda bit a bit
- [`>>`][right-shift-operator]: desplazamiento a la derecha bit a bit
