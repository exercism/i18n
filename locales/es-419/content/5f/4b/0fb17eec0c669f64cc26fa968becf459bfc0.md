# Anexo de instrucciones

## Implementación

Este ejercicio requiere que llames a una función que se pasa como argumento.
En Uiua, puedes hacerlo con [macros](https://www.uiua.org/tutorial/macros), que es como este ejercicio espera que lo resuelvas.

```exercism/note
Puedes ver de inmediato que un binding es una macro gracias al sufijo `!`.
```
