# Pistas

## 1. Comprueba si es posible la acción «ataque rápido»

- El operador lógico NOT (`!`) se puede colocar antes de una expresión para negar su valor.
- Consulta [este documento][logical-operators] sobre los operadores lógicos.

## 2. Comprueba si es posible la acción «espía»

- Las expresiones lógicas se evalúan de izquierda a derecha y se comprueban posibles «cortocircuitos».
- Para entender bien el mecanismo de izquierda a derecha, echa un vistazo a [este artículo][operator-precedence].

## 3. Comprueba si es posible la acción «hacer señales al prisionero»

- Los operadores lógicos, en orden de precedencia (de mayor a menor): `!`, `&&`, `||`.
- Consulta [este artículo][operator-precedence] sobre la precedencia de operadores.

## 4. Comprueba si es posible la acción «liberar al prisionero»

- `()` es el operador con la mayor precedencia. Úsalo para agrupar expresiones lógicas.
