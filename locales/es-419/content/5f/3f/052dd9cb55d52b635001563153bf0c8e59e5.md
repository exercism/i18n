# Introducción

## Registros

Un registro es una colección de campos (que pueden ser de diferentes tipos) que van juntos. Para definir un registro se usa la palabra clave `type`. Los campos de un registro se definen entre los caracteres `{` y `}`, y cada campo tiene un nombre _y_ un tipo. Para crear un registro, especifica los nombres de los campos y asígnales un valor entre los caracteres `{` y `}`. Todos los campos deben tener un valor asignado al crear un registro. Se puede acceder a los valores de los campos de una instancia de registro usando la notación de punto.

Al definir o crear un registro, cada campo debe ir en una línea separada o, cuando varios campos comparten una línea, deben separarse con punto y coma (`;`).

```fsharp
// Define a record
type Address =
    { Street: string
      HouseNumber: int }

// Create a record
let oldAddress: Address =
    { Street = "Main Street"
      HouseNumber = 17 }

// Single-line alternative
type ConciseAddress = { Street: string; HouseNumber: int }
let conciseAddress: ConciseAddress = { Street = "Main Street"; HouseNumber = 17 }
```

Como los registros son inmutables, una vez que se ha construido un registro, los valores de sus campos nunca pueden cambiar. Si quieres cambiar los valores de un registro, la palabra clave `with` te permite crear una copia de un registro existente, pero con valores nuevos para uno o más campos.

```fsharp
// Copy the old address but change the house number
let newAddress: Address = { oldAddress with HouseNumber = 86 }
newAddress.Street      // => "Main Street"
newAddress.HouseNumber // => 86
```

Los registros tienen _igualdad estructural_, lo que significa que dos instancias del mismo registro con valores idénticos son equivalentes.

Además de poder usar la notación de punto para acceder a los campos de un registro, los registros también se pueden _deconstruir_ en enlaces y en coincidencia de patrones:

```fsharp
let myAddress: Address = { Street = "Broadway"; HouseNumber = 123 }
let { Street = myStreet; HouseNumber = myHouseNumber } = myAddress

match myAddress with
| { HouseNumber = 1 } -> printfn "First house"
| { HouseNumber = houseNumber; Street = street } -> printfn "House number %d on %s" houseNumber street
// => "House number 123 on Broadway
```
