# Instalación

## Linux

Bash, como shell de GNU, se encuentra en cualquier sistema GNU/Linux. 
BSD y otras derivadas de UNIX probablemente requieran que el usuario las instale.
Si usas BSD, AIX o una distribución de Linux que no venga con bash, consulta los recursos de tu sistema operativo sobre la instalación de paquetes que no forman parte del núcleo.

En la interfaz gráfica que prefieras, busca una aplicación llamada «Terminal»: puede que esté en una sección «Administrative/System Tools».

Para verificar la versión de Bash disponible, desde la línea de comandos o el terminal, ejecuta:

    echo $BASH_VERSION

Si tu shell es `bash`, debería mostrar algo como:

    4.4.19(1)-release

No deberías necesitar hacer nada más; en este punto, bash debería estar instalado y en tu PATH, ya que es tu shell actual.

Si tu shell no es bash, no hay razón para cambiarlo.
Puedes escribir y ejecutar scripts de bash sin estar en un shell de bash.

Para verificar la versión de bash instalada, ejecuta:

```plain
bash --version
```

Mostrará algo como esto:

```
GNU bash, version 4.4.19(1)-release (x86_64-pc-linux-gnu)
Copyright (C) 2016 Free Software Foundation, Inc.
License GPLv3+: GNU GPL version 3 or later <http://gnu.org/licenses/gpl.html>

This is free software; you are free to change and redistribute it.
There is NO WARRANTY, to the extent permitted by law.
```

Si no es así, es posible que no tengas bash instalado.
Deberías instalarlo usando el gestor de paquetes de tu distribución.

## Windows

Para Windows 10, puedes instalar [WSL](https://docs.microsoft.com/en-us/windows/wsl/about). 
Esto instala una distribución Linux completa (bueno, los componentes sin interfaz gráfica) que se ejecuta de forma nativa en Windows.

Como alternativa, puedes instalar:

* [Cygwin](https://cygwin.com/)
* [git for windows](https://gitforwindows.org/)
* [MinGW](http://mingw.org/)
* una distribución Linux completa en [una máquina virtual](https://docs.microsoft.com/en-us/virtualization/hyper-v-on-windows/about/)

## MacOS

Para Apple OSX:

* abre Finder,
* abre tu carpeta Aplicaciones,
* abre la carpeta Utilidades,
* finalmente, abre la aplicación `Terminal`.

Ten en cuenta que la versión de bash instalada en MacOS es muy antigua, la versión 3.2. 
Esto se debe a (i) que las versiones más recientes de bash tienen licencia GPLv3 y (ii) que Apple no quiere que se le obligue a cumplir con los términos de esa licencia.
Además, Apple ha indicado que bash desaparecerá de MacOS: recientemente, el shell de inicio de sesión predeterminado [cambió de bash a zsh](https://support.apple.com/en-us/HT208050).

Para obtener una versión actualizada de bash en tu Mac:

1. instala [Homebrew](https://brew.sh)
1. en el Terminal, escribe: `brew install bash`

Esto instala un bash actualizado en (creo) `/usr/local/bin/bash` (para que no se sobrescriba el bash predeterminado del sistema; otras herramientas pueden depender de /bin/bash). 

Si quieres que se inicie el bash de Homebrew cuando escribas `bash`, edita tu archivo ~/.bash_profile (o ~/.profile) para poner /usr/local/bin *antes* que /bin en el PATH:

    PATH=/usr/local/bin:$PATH
