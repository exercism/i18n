# Introducción

## Strings

Los caracteres y los strings son la base de la representación de texto en Elm.
Los strings se pueden pensar como listas de caracteres, y la mayoría de las funciones de `List` tienen su equivalente en el módulo `String`.

### Caracteres

El tipo `Char` representa un único carácter de unicode y se escribe entre comillas simples, por ejemplo, `'a'`. 
El módulo `Char` proporciona funciones de predicado (`Char -> Bool`) para comprobar cualidades de un carácter: `isUpper`, `isLower`, `isAlpha` e `isAlphaNum`.
El módulo también proporciona funciones para convertir un carácter (`toUpper`, `toLower`, `toLocaleUpper`, `toLocaleLower`), así como para obtener su valor numérico de unicode (`Int`) y viceversa, con `toCode` y `fromCode`.

### Strings

El tipo `String` proporciona una representación integrada para manipular strings de forma eficiente y puede representar cualquier secuencia de caracteres de unicode, por ejemplo, "this is an Elm string."
Los strings multilínea se representan con comillas dobles triples y pueden contener comillas y saltos de línea sin escapar.
```elm
"""
    This is a multiline string.
All line-breaks and whitespace,
are preserved. 
"""
```

### Funciones de String

El módulo `String` contiene todas las funciones resumidas en la tabla a continuación.
Algunas de las funciones más usadas son:

`cons : Char -> String -> String` agrega un carácter al inicio de un string.
```elm
cons 'T' "he truth is out there" 
    --> "The truth is out there"
```

`(++): String -> String -> String` concatena dos strings.
```elm
"butter" ++ "fly" 
    --> "butterfly"
```

`split : String -> String -> List String` divide un string en una lista de strings usando el separador dado.
```elm
split ";" "cat;dog;cow" 
    --> ["cat", "dog", "cow"]
```

`join : String -> List String -> String` concatena una lista de strings usando el separador dado.
```elm
join "a" ["H", "w", "ii", "n"] 
    --> "Hawaiian"
```
`replace : String -> String -> String -> String` reemplaza todas las apariciones de una subcadena dada.
```elm
replace "Hello" "Goodbye cruel" "Hello world." 
    --> "Goodbye cruel world."
```

`length : String -> Int` devuelve el número de caracteres de un string.
```elm 
length "Hello world." 
    --> 12
```

`toInt : String -> Maybe Int` intenta convertir un string en `Just Int` y devuelve `Nothing` para strings con formato incorrecto.
```elm
toInt "-42" 
    --> Just -42
```    

`contains : String -> String -> Bool` comprueba si el segundo string contiene al primero.
```elm
contains "the" "theory" 
    --> True
```

`map : (Char -> Char) -> String -> String` aplica una función dada a cada `Char` del string.
Ten en cuenta que la función que proporciones debe transformar de `Char` a `Char`.
```elm
map (\c -> if c == '/' then '.' else c) "a/b/c" 
    --> "a.b.c"
```
