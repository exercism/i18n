# Acerca de

`Enum` es un módulo muy útil que proporciona un conjunto de algoritmos para trabajar con enumerables. Ofrece:

- ordenar ([`sort/2`][enum-sort/2], [`sort_by/2`][enum-sort_by/2]),
- filtrar ([`filter/2`][enum-filter/2]),
- agrupar ([`group_by/3`][enum-group_by/3]),
- contar ([`count/2`][enum-count/2])
- buscar ([`find/3`][enum-find/3]),
- encontrar valores mínimos y máximos ([`min/3`][enum-min/3], [`max/3`][enum-max/3]),
- reducir ([`reduce/3`][enum-reduce/3], [`reduce_while/3`][enum-reduce_while/3]),

¡Y mucho más! Consulta la [documentación del módulo `Enum`][enum-functions] para ver la lista completa.

## Enumerable

En general, un _enumerable_ es cualquier dato sobre el que se puede iterar, es decir, una colección. En Elixir, un enumerable es cualquier tipo de dato que implemente el [protocolo][exercism-protocols] `Enumerable`. Estos son:

- [`List`][list]
- [`Map`][map]
- [`Range`][range]
- [`Stream`][stream]
- [`MapSet`][mapset]
- [`Function`][function]
- [`Date.Range`][date-range]
- [`IO.Stream`][io-stream]
- [`File.Stream`][file-stream]

No te preocupes si todavía no los conoces todos.

Cualquiera puede implementar el protocolo `Enumerable` para su propia estructura de datos personalizada.

## Reduce

`Enum.reduce/2` te permite _reducir_ todo el enumerable a un solo valor. Para lograrlo, se usa una variable especial llamada el _acumulador_. El acumulador lleva el estado intermedio de la reducción entre iteraciones. Esto lo convierte en una de las funciones más poderosas para trabajar con enumerables. Muchas otras funciones especializadas podrían reemplazarse por la más general `reduce`. Por ejemplo...

Encontrar el valor máximo:

```elixir
Enum.max([4, 20, 31, 9, 2])
# => 31

Enum.reduce([4, 20, 31, 9, 2], nil, fn x, acc ->
  cond do
    acc == nil -> x
    x > acc -> x
    x <= acc -> acc
  end
end)

# => 31
```

E incluso el mapeo (pero requiere invertir el resultado después):

```elixir
Enum.map([1, 2, 3, 4, 5], fn x -> x + 10 end)
# => [11, 12, 13, 14, 15]

Enum.reduce([1, 2, 3, 4, 5], [], fn x, acc -> [x + 10 | acc] end)
# => [15, 14, 13, 12, 11]
```

## Mapear maps

- Con [`Map.new/2`][map-new]:
  ```elixir
  %{a: 1, b: 2}
  |> Map.new(fn {key, value} -> {key, value * 10} end)
  ```

- Con [`Enum.into/3`][enum-into]:
  ```elixir
  %{a: 1, b: 2}
  |> Enum.into(%{}, fn {key, value} -> {key, value * 10} end)
  ```

- Con [`Enum.map/2`][enum-map]:
  ```elixir
  %{a: 1, b: 2}
  |> Enum.map(fn {key, value} -> {key, value * 10} end)
  |> Enum.into(%{})
  ```
