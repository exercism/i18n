# Aprendizaje

## Aprender C desde cero

En general, Exercism asume que ya conoces la sintaxis y los mecanismos de un lenguaje en un track determinado.
Sin embargo, conocer la sintaxis de un lenguaje es apenas el primer paso para dominarlo.
Exercism te permite practicar la resolución de problemas y compartir conversaciones con otros programadores que resolvieron el mismo problema.
Es de esas conversaciones compartidas de donde sacamos experiencia y perspectiva para convertirnos en mejores programadores.

Si eres nuevo por completo en el lenguaje C, conviene que primero le dediques tiempo a aprender lo básico del lenguaje.
Aquí tienes algunos recursos que pueden ayudarte a empezar:

* [Learn C][]
* [CS50x][]

[CodeChef][] es una interfaz web sencilla con un formulario para un compilador de C que te permite probar programas pequeños.
A veces, esta puede ser una manera más fácil de hacer un experimento rápido que armar algo localmente en un entorno de desarrollo integrado.

## Desarrollo guiado por pruebas en C

Exercism asume que ya conoces el concepto de desarrollo guiado por pruebas.
Cada ejercicio incluye una serie de pruebas que ya están escritas para ti.
Avanzas por el ejercicio prueba tras prueba, escribiendo una implementación de forma incremental hasta cumplir con las pruebas.

Si eres nuevo en el desarrollo guiado por pruebas, te recomendamos encarecidamente que primero revises una [introducción rápida a algunos frameworks de prueba para C][test-frameworks] o leas el libro [Test-Driven Development for Embedded C][tdd] de James Grenning.
Estos recursos cubren [Unity][] y [CppUTest][]; este track usa Unity.
