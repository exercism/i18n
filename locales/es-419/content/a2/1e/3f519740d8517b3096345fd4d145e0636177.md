# Introducción

Las tuplas son una forma ligera de agrupar un conjunto fijo de datos de tipos arbitrarios.
Una tupla no tiene un nombre en particular; darle un nombre a una estructura de datos la convierte en un `struct`.
Los campos de una tupla no tienen nombres; se accede a ellos mediante desestructuración o por posición.

## Creación

Las tuplas siempre se crean con una expresión de tupla:

```rust
// pointless but legal
let unit = ();
// single element
let single_element = ("note the comma",);
// two element
let two_element = (123, "elements can be of differing types");
```

Las tuplas pueden tener una cantidad arbitraria de elementos.

## Acceso por desestructuración

Es posible acceder a los elementos de una tupla mediante desestructuración.
Esto solo significa asignar nombres de variables a cada uno de los elementos de la tupla, lo que la consume.

```rust
let (elem1, _elem2) = two_element;
assert_eq!(elem1, 123);
```
