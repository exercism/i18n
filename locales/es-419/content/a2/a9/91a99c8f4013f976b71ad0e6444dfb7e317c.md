# Acerca de

Como lenguaje funcional, las funciones en Clojure son ciudadanos de primera clase. Esto significa que se pueden pasar a otras funciones y generar a partir de ellas igual que si fueran datos. Clojure, en particular, viene con un amplio conjunto de funciones de orden superior que derivan funciones nuevas a partir de funciones existentes. Aquí exploraremos cuatro casos importantes: `partial`, `comp`, `memoize` y `juxt`. Estas funciones que generan funciones forman parte de una categoría más amplia de funciones de orden superior, como `map`, `reduce`, `apply` y `complement`, por mencionar solo algunas, que operan sobre funciones existentes.

## partial

En general, dada una función existente `my-function` con parámetros `p1, p2, ..., pN`, podemos fijar algunos de sus parámetros `p1, p2, ..., pM` para que tengan valores constantes `v1, v2, ..., vM`. Lo hacemos aplicando `partial` de la siguiente manera: `(partial my-function v1 v2 ... vM)`.

El resultado es una función nueva que aplica la original, `my-function`, fijando `p1=v1, p2=v2, ..., pM=vM`. Nuestra nueva función recibe como argumentos los parámetros restantes `pM+1, pM+2, ..., pN`, cuyos valores no se indicaron al aplicar `partial`:

```clojure
(def my-new-function 
  (partial my-function v1 v2 ... vM))
(my-new-function xM+1 xM+2 ... xN)
; => equivalent to (my-function v1 v2 ... vM xM+1 xM+2 ... xN)
```

Como ejemplo sencillo, definamos una función `inc-by-9` que aumenta en 9, una cantidad fija, sin importar lo que le pasemos. Podríamos implementar esa función así:

```clojure
(def inc-by-9 (partial + 9))
(inc-by-9 5)
; => 14
```

Como segundo ejemplo, tenemos una función `generic-greetings` que usa el nombre de la persona a la que queremos saludar junto con un mensaje de texto inicial y uno final:

```clojure
(defn generic-greetings
  [initial-text final-text name]
  (println (str initial-text name final-text)))
```

Y usamos `partial` para usar siempre un mensaje de saludo específico:

```clojure
(def say-hello-and-how-are-you-doing 
  (partial generic-greetings "Hello " ", how are you doing?"))
(say-hello-and-how-are-you-doing "Mary")
; => Hello Mary, how are you doing?
```

## comp

`comp` se puede usar para crear una composición de cualquier número de funciones que queramos componer. En general, componer `N` funciones `f1, f2, ..., fN` significa aplicarlas en orden secuencial, pasando el resultado de la función anterior a la siguiente. En notación matemática, esto se expresa así:

```
f1 (f2 (... fN(x)))
```

En Clojure, esto equivale a hacer lo siguiente:
```clojure
(f1 (f2 (... (fN x))))
```

Usando comp, podemos crear una función nueva que realice esta composición por nosotros:

```clojure
(def my-function-composition 
  (comp f1 f2 ... fN))
(my-function-composition x)
; equivalent to
(f1 (f2 (... (fN x))))
```

Como ejemplo, supongamos que queremos sumar una serie de números y luego multiplicar el resultado por 6. Podemos hacerlo así:


```clojure
(def six-times-result-sum 
  (comp (partial * 6) +))
(six-times-result-sum 3 2)
; = ((partial * 6) (+ 3 2))
; = (* 6 (+ 3 2))
; = 30
```

## memoize

`memoize` permite reutilizar resultados calculados previamente y asociados a un argumento dado. Dado el mismo argumento, la función *memoizada* devuelve el mismo resultado sin tener que volver a calcularlo. Aprovecha el hecho de que las funciones de `clojure` son, por defecto, *referencialmente transparentes*: dado el mismo argumento, siempre producen el mismo resultado, lo que permite reutilizar cálculos previos con facilidad.

Para ver cómo funciona esto, usemos un caso sintético en el que la función duerme dos segundos antes de producir el resultado, para que podamos comparar fácilmente el *tiempo de cómputo* antes y después de usar `memoize`.

```clojure
(defn my-time-consuming-fn
    "Original, time-consuming function"
    [x]
    (Thread/sleep 2000)
    (* x 2)
)

; We measure the time it takes for the original function
(time (my-time-consuming-fn 3))
; => "Elapsed time: 2007.785622 msecs"
; => 6

; We define a memoized function
(def my-memoized-fn 
  (memoize my-time-consuming-fn) )

; We call the memoized function and measure its execution time. 
; The first execution actually runs the function, taking
; similar time as the original.
(time (my-memoized-fn 3))
; => "Elapsed time: 2001.364052 msecs"
; => 6

; Subsequent calls reuse the previous computation, taking less
; time. Time is further reduced in additional calls.
(time (my-memoized-fn 3))
; => "Elapsed time: 1.190291 msecs"
; => 6

(time (my-memoized-fn 3))
; => "Elapsed time: 0.043701 msecs"
; => 6

; Changing the input makes the function be executed, so that
; we observe a similar computation time as the original 
(time (my-memoized-fn 4))
; => "Elapsed time: 2000.29306 msecs"
; => 8

; Again, repeating the same input will make the 
; execution be skipped, and the associated output returned
(time (my-memoized-fn 4))
; => "Elapsed time: 0.043701 msecs"
; => 8
```

## juxt

`juxt` genera una función que aplica, en orden de izquierda a derecha, las funciones que se le pasan. El resultado es un vector con los resultados individuales de cada función como componentes del vector:

```clojure
((juxt f g h) x) ; => [(f x) (g x) (h x)]
```

Como ejemplo sencillo, generamos una función que calcula el producto de x por factores sucesivos, del 2 al 5:
```clojure
((juxt (partial * 2) (partial * 3) (partial * 4) (partial * 5)) 10) ; => [20 30 40 50]
```
