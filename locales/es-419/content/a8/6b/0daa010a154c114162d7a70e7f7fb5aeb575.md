# Pistas

## General

- Para extraer varios argumentos en los parámetros de la función, puedes empaquetarlos con el operador `*arguments` para **array** o `**keyword_arguments` para argumentos de palabra clave.
- Para empaquetar o desempaquetar, usa los operadores splat (`*` o `**`).

## 1. Crea una lista de todos los vagones

- Varios argumentos en los parámetros de la función se pueden empaquetar con el operador `*arguments`.

## 2. Corrige la lista de vagones

- Usar el desempaquetado con el operador splat (`*`) te permite extraer los dos primeros elementos de un **array** y mantener el resto intacto.
- Para agregar otro **array** dentro de un **array** existente, puedes usar el operador splat (`*`) para «expandir» el **array**.

## 3. Agrega las paradas que faltan

- Usar `**keyword_arguments` como argumento de método permite pasar cualquier cantidad de argumentos de palabra clave.
- Usar `**<hash>` como argumento desempaqueta un `Hash` en argumentos de palabra clave.
- Puedes poner los argumentos de palabra clave dentro de `{}`, que es otra forma de crear un `Hash`.
- Para obtener los valores de un `Hash`, puedes usar el método `Hash#values`.

## 4. Amplía la información de rutas

- Usar `**{some_hash: value}` como argumento desempaqueta el `Hash` en argumentos de palabra clave.
