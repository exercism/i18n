# retorno explícito

Elimina el `return` explícito para simplificar el método.

En Ruby, un método devuelve el resultado de la última sentencia evaluada. Por lo tanto, usar explícitamente la palabra clave `return` es innecesario, salvo cuando quieres salir del método antes de tiempo.

Por ejemplo, esto imprime `16`, ya que el método `multiply` devuelve el resultado de `a * b`, su expresión final.

```ruby
def multiple(a, b)
  a * b
end

print multiple(2, 8)
```
