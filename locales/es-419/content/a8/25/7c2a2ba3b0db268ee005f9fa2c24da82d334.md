# Instrucciones

En este ejercicio, escribirás código para ayudar a un freelancer a comunicarse con un gerente de proyecto.
Tu tarea es proporcionar algunas utilidades para calcular rápidamente tarifas diarias y mensuales, opcionalmente con un descuento dado.

Primero, establecemos algunas reglas entre el freelancer y el gerente de proyecto:

- La tarifa diaria es 8 veces la tarifa por hora.
- Un mes tiene 22 días facturables.

A veces, el freelancer ofrece aplicar un descuento sobre su tarifa diaria (por ejemplo, para sus clientes más leales o para clientes sin fines de lucro).

Los descuentos se modelan como números fraccionarios que representan porcentajes; por ejemplo, `25.0` (25%).

~~~~exercism/note
Estos son los sufijos de las instrucciones de punto flotante:

| Sufijo | Tamaño del operando |
|--------|--------------|
| `ss`   | 32 bits      |
| `sd`   | 64 bits      |

Estas son algunas de las instrucciones mencionadas en este concepto:

| Instrucción       | Descripción                                                  |
|-------------------------|--------------------------------------------------------|
| movss/movsd a, b        | copia b en a                                          |
| addss/addsd a, b        | a = a + b                                              |
| subss/subsd a, b        | a = a - b                                              |
| mulss/mulsd a, b        | a = a * b                                              |
| divss/divsd a, b        | a = a / b                                              |
| cvtsi2ss/cvtsi2sd a, b  | convierte el entero b en el número de punto flotante a                 |
| roundss/roundsd a, b, c | redondea el número de punto flotante b según c y lo almacena en a |
| cvtss2si/cvtsd2si a, b  | convierte el punto flotante b en el entero a                 |
| comiss/comisd a, b      | hace una comparación entre a y b; excepción si es `NaN` |
| ucomiss/ucomisd a, b    | hace una comparación entre a y b; establece `PF` si es `NaN` |

Estos son los números de control de redondeo en `roundss` y `roundsd`:

| Número | Modo         |
|:-------|:-------------|
| 0      | Más cercano      |
| 1      | Suelo (hacia abajo) |
| 2      | Techo (hacia arriba)    |
| 3      | Truncar     |
~~~~

## 1. Calcula la tarifa diaria dada una tarifa por hora

Implementa una función llamada `daily_rate` para calcular la tarifa diaria dado como parámetro una tarifa por hora, como un número de punto flotante de 64 bits.
El contrato define que un día tiene 8 horas facturables.

```c
daily_rate(60)
// => 480.0
```

La tarifa diaria devuelta debe ser un número de punto flotante de 64 bits.

## 2. Calcula un precio con descuento

Implementa una función `apply_discount` para calcular el precio después de un descuento.
Debe aceptar dos parámetros: el precio original y la tasa de descuento en porcentaje, ambos como un número de punto flotante de 64 bits.

```c
apply_discount(150.0, 10.0)
// => 135.0
```

El valor devuelto siempre debe ser un número de punto flotante de 64 bits.

## 3. Calcula la tarifa mensual, dada una tarifa por hora y un descuento

Implementa una función `monthly_rate` para calcular la tarifa mensual con descuento.
Toma dos parámetros, una tarifa por hora y el descuento en porcentaje, ambos como un número de punto flotante de 64 bits.

```c
monthly_rate(77.0, 10.5)
// => 12130
```

La tarifa mensual devuelta debe redondearse hacia arriba (tomar el techo) al entero de 64 bits más cercano.

## 4. Calcula el número de días laborables completos dados un presupuesto, una tarifa por hora y un descuento

Implementa una función `days_in_budget` que toma como parámetros:

1. Un presupuesto, como un entero sin signo de 64 bits.
2. Una tarifa por hora, como un número de punto flotante de 64 bits.
3. Un descuento en porcentaje, como un número de punto flotante de 64 bits.

Esta función debe devolver el número de días completos de trabajo que cubre el presupuesto.

```c
days_in_budget(20000, 80, 11.0)
// => 35
```

El número de días devuelto debe redondearse hacia abajo (tomar el suelo) al entero de 32 bits más cercano.
