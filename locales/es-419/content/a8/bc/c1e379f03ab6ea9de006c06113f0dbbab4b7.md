# Sin rescue

No uses excepciones para controlar el flujo del programa.
Intenta resolver este ejercicio sin usar `rescue`.

Si estás usando una función de la biblioteca estándar cuyo nombre termina en `!` (lanza errores), busca una función equivalente sin el `!` (a menudo devuelven `{:ok, result}` o `{:error, message}`).

Nota: si estás viendo este comentario automático en tu solución, es posible que otros comentarios automáticos no sean precisos.
¡Corrige este problema primero!

```elixir
# preferred: for example `case`

case Date.new(1999, 13, 1) do
  {:ok, date} -> date
  {:error, _} -> nil
end

# discouraged: rescuing exceptions

try do
  Date.new!(1999, 13, 1)
rescue
  ArgumentError ->
    nil
end
```
