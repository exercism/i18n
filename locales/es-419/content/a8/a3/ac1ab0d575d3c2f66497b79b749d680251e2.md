# Introducción

El bucle `for` es una de las sentencias que más se usan para ejecutar alguna lógica de forma repetida.
En JavaScript, se compone de la palabra clave `for`, un _encabezado_ entre paréntesis y un bloque de código que contiene el _cuerpo_ del bucle, encerrado entre llaves.

```javascript
for (initialization; condition; step) {
  // code that is executed repeatedly as long as the condition is true
}
```

La inicialización normalmente configura una variable contadora, la condición verifica si el bucle debe continuar o detenerse, y el paso incrementa el contador al final de cada repetición.
Las partes individuales del encabezado se separan con puntos y coma.

```javascript
const list = ['a', 'b', 'c'];
for (let i = 0; i < list.length; i++) {
  // code that should be executed for each item list[i]
}
```

Definir el paso suele hacerse con el operador de incremento o decremento de JavaScript, como se muestra en el ejemplo anterior.
Estos operadores modifican una variable en el lugar.
`++` le suma uno a un número y `--` le resta uno.

```javascript
let i = 3;
i++;
// i is now 4

let j = 0;
j--;
// j is now -1
```
