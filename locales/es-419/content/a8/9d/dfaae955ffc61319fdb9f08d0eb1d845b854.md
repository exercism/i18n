# Instrucciones

Estás en proceso de desarrollar el nuevo y muy apreciado juego **Wings Quest**.
En el juego eres un pájaro que se mueve de un lado a otro y recoge semillas.
El jugador gana al recoger todas las semillas.
Si el jugador entra en contacto con un águila, perderá todas sus semillas y perderá el juego.
Hay una excepción a esta regla: el jugador puede tener un potenciador activo que lo hace volar más alto que los demás pájaros.

Tu objetivo es escribir algunas reglas que se usarán en el juego.

## 1. Define si el pájaro obtiene puntos extra

En el juego, el pájaro obtiene puntos extra si toca un águila mientras tiene un potenciador.

Define la función `bonusPoints(powerUpActive:touchingEagle:)`, que toma dos argumentos: `powerUpActive`, que indica si el pájaro tiene un potenciador activo, y el argumento `touchingEagle`, que indica si el pájaro está tocando un águila.
La función debe devolver `true` solo si el pájaro tiene un potenciador activo y está tocando un águila, y `false` en caso contrario.

```Swift
bonusPoints(powerUpActive: false, touchingEagle: true)
// Returns false
```

## 2. Define si el pájaro anota puntos

En el juego, el jugador obtiene puntos al recoger una semilla o un potenciador.

Define la función `score(touchingPowerUp:touchingSeed:)`, que toma dos argumentos: `touchingPowerUp`, que indica si el pájaro está tocando un potenciador, y el argumento `touchingSeed`, que indica si el pájaro está tocando una semilla.
La función debe devolver `true` si el pájaro está tocando un potenciador o una semilla, y devolver `false` en caso contrario.

```Swift
score(touchingPowerUp: true, touchingSeed: true)
// Returns true
```

## 3. Define si el pájaro pierde

Define la función `lose(powerUpActive:touchingEagle:)`, que toma dos argumentos: `powerUpActive`, que indica si el pájaro tiene un potenciador activo, y el argumento `touchingEagle`, que indica si el pájaro está tocando un águila.
La función debe devolver `true` si el pájaro está tocando un águila y no tiene un potenciador activo, y devolver `false` en caso contrario.

```Swift
lose(powerUpActive: false, touchingEagle: true)
// Returns true
```

## 4. Define si el pájaro gana

Define la función `win(hasPickedUpAllSeeds:powerUpActive:touchingEagle:)`, que toma los argumentos:

- `hasPickedUpAllSeeds` si el pájaro ha recogido todas las semillas.
- `powerUpActive` si el pájaro tiene un potenciador activo.
- `touchingEagle` si el pájaro está tocando un águila.

La función debe devolver `true` si el pájaro ha reunido todas las semillas y no ha perdido según los argumentos definidos en la parte 3, y devolver `false` en caso contrario.

```Swift
win(hasPickedUpAllSeeds: false, powerUpActive: true, touchingEagle: false)
// Returns false
```
