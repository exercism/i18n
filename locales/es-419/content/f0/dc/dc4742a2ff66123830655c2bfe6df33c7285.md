# Introducción

En Factor, defines una palabra nueva con `: name ( stack-effect ) body ;`.
El cuerpo es una secuencia de palabras; al llamar a tu palabra nueva, se
ejecutan en orden.

```factor
USING: kernel ;
IN: my-vocab

: shout ( str -- str ) "!" append ;
```

Cuando una rutina se hace grande, puedes (y debes) *factorizarla*: extrae
grupos de palabras en palabras más pequeñas con nombre, cada una con una sola
tarea. De ahí el nombre del lenguaje.

## Vocabularios

Cada archivo `.factor` declara un vocabulario con `IN:`. Las palabras de un
vocabulario pueden llamar a palabras de otro si se lista el otro vocabulario
en `USING:`.

```factor
! file: my-vocab/helpers/helpers.factor
USING: kernel ;
IN: my-vocab.helpers

: shout-line ( str -- str ) "!" append ;
```

```factor
! file: my-vocab/my-vocab.factor
USING: kernel my-vocab.helpers sequences ;
IN: my-vocab

: announce ( names -- strs )
    [ shout-line ] map ;
```

La estructura de directorios sigue el nombre del vocabulario con puntos: el
vocabulario `my-vocab` se encuentra en `my-vocab/my-vocab.factor`; el
vocabulario `my-vocab.helpers` se encuentra en
`my-vocab/helpers/helpers.factor`. El cargador de Factor sigue las
declaraciones `USING:` de forma transitiva y carga cada vocabulario cuando se
necesita.
