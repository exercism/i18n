# Instrucciones

Mientras te preparabas para hornear galletas para tus amistades, has descubierto que tienes que convertir algunas de las medidas que usa la receta.
Como solo conoces el sistema métrico, necesitas encontrar la manera de convertir las medidas de repostería estadounidenses más comunes a mililitros (mL) para tu comodidad.

Usa esta tabla de conversión para tu solución:

| Unidad por convertir | volumen | en mililitros (mL) |
| --------------- | ------ | ------------------- |
| mL              | 1      | 1                   |
| taza estadounidense          | 1      | 240                 |
| onza líquida estadounidense  | 1      | 30                  |
| cucharadita estadounidense     | 1      | 5                   |
| cucharada estadounidense   | 1      | 15                  |

Como tienes talento para la programación y estás en formación, decides usar los mililitros como unidad de transición para facilitar la conversión de cualquier unidad de la lista a cualquier otra (incluso a sí misma).

## 1. Obtén el componente numérico de un par de volumen

Implementa la función `getVolume`. Dada una tupla de par de volumen, debe devolver solo el componente numérico.

```haskell
getVolume (Cup, 2.0)
-- -> 2.0
```

## 2. Convierte el par de volumen a mililitros

Implementa la función `toMilliliter`. Dada una tupla de par de volumen, debe convertir el volumen a mililitros usando la tabla de conversión.

Usa múltiples cláusulas de función y coincidencia de patrones para crear las funciones de cada unidad. Los átomos que se usan para denotar cada unidad son: `Cup`, `FluidOunce`, `Teaspoon`, `Tablespoon`, `Milliliter`.
Devuelve el resultado de la conversión envuelto en una tupla.

```haskell
toMilliliter (Cup, 2.5)
-- -> (Milliliter, 600.0)
```

## 3. Convierte el par de volumen en mililitros a otra unidad

Implementa la función `fromMilliliter`. Dada una tupla de par de volumen y la unidad deseada, debe convertir el volumen a la unidad deseada usando la tabla de conversión.

Usa múltiples cláusulas de función y coincidencia de patrones para crear las funciones de cada unidad. Los átomos que se usan para denotar cada unidad son: `Cup`, `FluidOunce`, `Teaspoon`, `Tablespoon`, `Milliliter`.

```haskell
fromMilliliter (Milliliter, 1320.0) Cup
-- -> (Cup, 5.5)
```

## 4. Convierte de cualquier unidad a cualquier unidad

Implementa la función `convert`. Dada una tupla de par de volumen y la unidad deseada, debe convertir el volumen dado a la unidad deseada.

```haskell
convert (Teaspoon, 9.0) Tablespoon
-- -> (Tablespoon, 3.0)
```
