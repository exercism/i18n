## Números y operadores numéricos

Todos los **números**, sean enteros o no, son números de punto flotante de doble precisión IEEE754.
La implementación de `jq` usa el tipo `double` de C.
Esto nos limita a 53 bits de precisión.

Con los números puedes usar los operadores habituales:

- aritméticos: `+`, `-`, `*`, `/`, `%`
- de comparación: `==`, `!=`, `<`, `<=`, `>=`, `>`
- las [funciones matemáticas][man-math] estándar

  Para las funciones de un solo argumento, pasa el valor a la función mediante una tubería

  ```sh
  $ jq -n '(1 | atan) * 4'
  3.141592653589793
  ```

  En el caso de las funciones de dos argumentos, estas ignorarán el argumento y esperarán los
  argumentos como parámetros

  ```sh
  $ jq -n 'pow(2; 10)'
  1024
  ```

  El punto y coma es el separador de los argumentos de las funciones, no la coma.

~~~~exercism/caution
¿Qué significa decir «Esto nos limita a 53 bits de precisión»?

Una demostración:

```sh
$ jq -n 'pow(2;52) as $n | [$n, $n+1]'
[
  4503599627370496,
  4503599627370497
]
```

Eso se ve bien. ¿Y si aumentamos el exponente?

```sh
$ jq -n 'pow(2;53) as $n | [$n, $n+1]'
[
  9007199254740992,
  9007199254740992
]
```

Esos números no deberían ser iguales.
Así se ve la «pérdida de precisión».
Esto significa que `jq` no puede manejar números arbitrariamente grandes.
~~~~

## Expresiones condicionales

`jq` usa una [expresión `if-then-else`][if-then-else] para las **expresiones condicionales**.
Como es una _expresión_, se coloca en una tubería.

La sintaxis es: `if CONDTITION then TRUE_EXPR else FALSE_EXPR end`.

La cláusula `else` es opcional.

```jq
42 | if . < 33 then "small" else "larger" end
# => "larger"
```

Las condiciones adicionales usan `elif`

```jq
42 | if . < 33 then "small"
     elif . < 67 then "medium"
     else "large"
     end
# => "medium"
```
