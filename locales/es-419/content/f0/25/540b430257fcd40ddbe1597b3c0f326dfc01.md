# Acerca de

Una [`List`][lists] en Elm es una colección inmutable de cero o más valores del mismo tipo.
Como las listas son inmutables, una vez que se ha construido una lista, su valor nunca puede cambiar.
Las listas de Elm tienen una _cabeza_ (el primer elemento) y una _cola_ (todo lo que viene después del primer elemento).
La cola de una lista es en sí misma una lista.

Las anotaciones de tipo para las listas se pueden definir de la siguiente manera

```elm
List String --> a list of String
List Int --> a list of Int
```

Las listas se pueden definir de la siguiente manera:

```elm
empty : List Char
empty = []

singleValue = [ 5 ] --> List Int
singleValueAlternative = List.singleton 5 --> List Int

threeValues = [ "a", "b", "c" ] --> List String
```

La forma más común de añadir un elemento a una lista es mediante el operador `::` (cons):

```elm
twoToFour = [ 2, 3, 4 ]
oneToFour = 1 :: twoToFour --> [1; 2; 3; 4]
```

Se puede añadir a una lista usando el operador `++` o `List.append`:

```elm
[ 6, 7 ] ++ [ 8, 9 ]           --> [6, 7, 8, 9]
List.append [ 6, 7 ] [ 8, 9 ]  --> [6, 7, 8, 9]
```

Las listas se manipulan con funciones y operadores definidos en el [módulo `List`][list-module].

```elm
List.length [ 7, 8 ] --> 2
```

Cualquier función u operador que parezca modificar una lista (como añadir un elemento) en realidad devuelve una nueva lista.
Sin embargo, por lo general el rendimiento no es un problema, ya que la implementación de las listas evita asignaciones y copias innecesarias.

Las listas también se pueden procesar usando la [coincidencia de patrones][list-destructuring].

```elm
describe : List String -> String
describe list =
    case list of
        [] ->
            "Empty list"

        [ "hello" ] ->
            "Singleton list with: hello"

        x :: xs ->
            "Non-empty list with head: " ++ x

describe []                   --> "Empty list"
describe [ "hello" ]          --> "Singleton list with: hello"
describe [ "hello", "world" ] --> "Non-empty list with head: hello"
```
