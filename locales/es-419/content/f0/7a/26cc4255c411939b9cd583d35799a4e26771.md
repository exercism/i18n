# Retorno

En Crystal, la última expresión de un método devuelve su valor.
Sin embargo, a veces necesitas devolver un valor antes de la última expresión.
Para eso puedes usar la palabra clave `return`, que devuelve el valor de la expresión que le sigue.
El código que escribas después de una palabra clave `return` no se ejecutará.

```crystal
def speed_limit(road_number)
    if road_number == 1
        return 50
        puts "This will not be executed"
    elsif road_number == 2
        return 80
        puts "This will not be executed"
    end
    100
end

p speed_limit(1) # => 50
p speed_limit(2) # => 80
p speed_limit(3) # => 100
```

~~~~exercism/note
La palabra clave `return` se debe omitir cuando la última expresión de un método es el valor que se debe devolver.
~~~~
