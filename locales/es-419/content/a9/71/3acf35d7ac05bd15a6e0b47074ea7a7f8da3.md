# Introducción

Un string en Factor es una secuencia de caracteres. La mayoría de las palabras del vocabulario [`sequences`][sequences] funcionan con strings, además de las palabras dedicadas al manejo de strings en [`splitting`][splitting], [`ascii`][ascii] y similares.

## Literales de string

Los strings se escriben entre comillas dobles. Se admiten los escapes habituales: `\n`, `\t`, `\r`, `\\`, `\"`:

```factor
"hello, world" .                 ! => "hello, world"
"first\nsecond" print            ! prints two lines
```

## Longitud e indexación

Como un string es una secuencia, las palabras `length` y `nth` de [`sequences`][sequences] funcionan directamente sobre él.

`length` devuelve la cantidad de caracteres:

```factor
"hello" length .    ! => 5
```

`nth` toma un índice con base 0 y la secuencia, y devuelve el elemento en esa posición. En el caso de un string, el elemento es un *carácter*, un punto de código (un entero), no un substring de un solo carácter:

```factor
0 "hello" nth .     ! => 104   (CHAR: h)
4 "hello" nth .     ! => 111   (CHAR: o)
```

## De un carácter de vuelta a un string

Para convertir un solo punto de código en un string de un carácter, usa `1string ( char -- str )` del vocabulario [`strings`][strings]. `CHAR:` es la forma que toma un punto de código literal en tiempo de análisis sintáctico:

```factor
CHAR: A 1string .                ! => "A"
0 "hello" nth 1string .          ! => "h"
```

## División

El vocabulario [`splitting`][splitting] corta un string en pedazos.

`split1` corta en la *primera* aparición de un separador y devuelve ambas mitades:

```
split1 ( seq subseq -- before after )
```

```factor
"foo: bar" ": " split1 .s
! => "foo"
! => "bar"
```

`split` corta por *cualquiera* de los caracteres de un conjunto de separadores, y puede producir pedazos vacíos:

```factor
"[ERROR]: Stack overflow" "[]" split .
! => { "" "ERROR" ": Stack overflow" }
```

`harvest` (en [`sequences`][sequences]) descarta los pedazos vacíos:

```factor
"[ERROR]: Stack overflow" "[]" split harvest .
! => { "ERROR" ": Stack overflow" }
```

## Seleccionar un pedazo

Una vez que un string se divide en un array de pedazos, `first`, `second`, `third` y `fourth` (en [`sequences`][sequences]) devuelven el pedazo en esa posición:

```factor
"apple,bee,carrot,duck" "," split first .    ! => "apple"
"apple,bee,carrot,duck" "," split second .   ! => "bee"
"apple,bee,carrot,duck" "," split third .    ! => "carrot"
"apple,bee,carrot,duck" "," split fourth .   ! => "duck"
```

Cuando quieres todos los primeros pedazos en la pila a la vez, `first2` y `first3` desempaquetan dos o tres de ellos en un solo paso:

```factor
"apple,bee,carrot,duck" "," split first2 .s
! => "apple"
! => "bee"

"apple,bee,carrot,duck" "," split first3 .s
! => "apple"
! => "bee"
! => "carrot"
```

Sobre un string mismo, `first` devuelve el primer **carácter** (un punto de código) en lugar de un substring:

```factor
"hello" first .                         ! => 104   (CHAR: h)
```

## Recorte

`[ blank? ] trim` (de [`sequences`][sequences], con `blank?` del vocabulario [`ascii`][ascii]) elimina los espacios en blanco al principio y al final:

```factor
"  Disk full \r\n" [ blank? ] trim .
! => "Disk full"
```

## Conversión de mayúsculas y minúsculas

`>lower` y `>upper` (de [`ascii`][ascii]) devuelven un string nuevo con las mayúsculas y minúsculas cambiadas:

```factor
"WARNING" >lower .    ! => "warning"
"hello" >upper .      ! => "HELLO"
```

## Unión

Dos palabras de [`sequences`][sequences] ensamblan strings:

`surround` envuelve un string con un prefijo y un sufijo:

```
surround ( seq pre post -- new-seq )
```

```factor
"warning" "(" ")" surround .    ! => "(warning)"
```

`glue` une dos strings con un separador entre ellos:

```
glue ( s1 s2 sep -- s )
```

```factor
"Disk full" "(error)" " " glue .    ! => "Disk full (error)"
```
