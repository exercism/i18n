# Pistas

## General

- Las [estructuras y clases][structs-and-classes] comparten una sintaxis de definición similar.

## 1. Define una estructura Size

- Las propiedades se deben definir con `var` si se pueden cambiar.
- A las propiedades de altura y ancho se les deben asignar los valores predeterminados de 80 y 60, respectivamente.
- Los métodos de una estructura deben marcarse como `mutating` si cambian propiedades de la estructura.

## 2. Define una estructura Position

- Las propiedades se deben definir con `var` si se pueden cambiar.
- A las propiedades x e y se les debe asignar el valor predeterminado de 0.
- Los métodos de una estructura deben marcarse como `mutating` si cambian propiedades de la estructura.

## 3. Define una clase Window

- Las estructuras se pueden inicializar con distintos valores de propiedades usando los [inicializadores por miembros][memberwise-initializers].
- Las propiedades constantes se deben definir con `let`.
- La propiedad `contents` debe ser opcional, ya que puede que no tenga un valor.
- Debes definir un inicializador vacío para la clase (`init() {}`).

## 4. Agrega un método para cambiar el tamaño de las ventanas

- El método debe recibir un parámetro `to` de tipo `Size`.
- Es posible extraer el ancho y la altura del parámetro `to` usando la notación de punto.

## 5. Agrega un método para mover las ventanas

- El método debe recibir un parámetro `to` de tipo `Position`.
- Es posible extraer la x y la y del parámetro `to` usando la notación de punto.

## 6. Agrega un método para establecer el contenido de una ventana

- En Swift es posible tener dos métodos con el mismo nombre pero con distintos parámetros.
- Define un método con el parámetro `title` que establezca la propiedad `title`.
- Define un método con el parámetro `text` que establezca la propiedad `contents`.
- Define un método de visualización que imprima el título y el contenido de la ventana.

## 7. Crea un inicializador para la clase Window

- La clase debe tener dos inicializadores, uno que no recibe parámetros y otro que sí los recibe.
- El nuevo inicializador debe tener los parámetros `title` y `contents`, y también debe permitir los parámetros opcionales `size` y `position`
    Si no se proporcionan parámetros, se deben usar los valores predeterminados.
- Los parámetros opcionales se pueden lograr usando los [valores predeterminados de los parámetros][default-parameters-vales].
