# Introducción

Los dict de Gleam son la estructura de datos para almacenar información en pares clave-valor. En otros lenguajes también se los conoce como arrays asociativos, hashes o diccionarios.

Cualquier tipo se puede usar para las claves y los valores de un dict, y no garantizan el orden de sus entradas al acceder a ellas o al devolverlas.

## Trabajar con los dict

Los dict se crean y se manipulan con funciones del módulo `gleam/dict`.

```gleam
// Create an empty dict
let dict1 = dict.new()

// Create a dict with some values
let dict2 = dict.from_list([
  #("name", "Gleam"),
  #("colour", "Pink"),
])

// Add a value to a dict
let dict3 = dict.insert(dict2, "website", "https://gleam.run")

// Get a value from a dict
let name = dict.get(dict3, "name")
// -> Ok("Gleam")
```
