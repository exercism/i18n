## 1. Error de división por cero

Dividir un número por cero produce un resultado indefinido, que el equipo decide que se representa mejor con un error.

Implementa el módulo `DivisionByZeroError` para que tenga el mensaje de error: `"division by zero occurred"`

```elixir
raise DivisionByZeroError
# => ** (DivisionByZeroError) division by zero occurred
```

## 2. Error de subdesbordamiento de pila

Las calculadoras RPN usan una _pila_ para llevar un registro de los números antes de que se sumen. El equipo representa esta _pila_ con una lista de números (enteros y de punto flotante), por ejemplo: `[3, 4.0]`. Cada operación necesita una cantidad específica de números en la pila para poder realizar su cálculo. Cuando no hay suficientes números en la pila, esto se llama error de subdesbordamiento de pila. Implementa la excepción `StackUnderflowError` que proporciona un mensaje predeterminado y contexto adicional opcional

```elixir
raise StackUnderflowError
# => ** (StackUnderflowError) stack underflow occurred

raise StackUnderflowError, "when dividing"
# => ** (StackUnderflowError) stack underflow occurred, context: when dividing
```

## 3. Escribe una función que divida

Implementa la función `divide/1` que toma una pila _(una lista de dos números)_ y:

- lanza _subdesbordamiento de pila_ cuando la pila no contiene suficientes números
- lanza _división por cero_ cuando el divisor es 0 (ten en cuenta que la pila de números se almacena en orden inverso)
- realiza la división cuando no se lanzan errores

```elixir
RPNCalculator.Exception.divide([])
# => ** (StackUnderflowError) stack underflow occurred, context: when dividing

RPNCalculator.Exception.divide([0, 100])
# => ** (DivisionByZeroError) division by zero occurred

RPNCalculator.Exception.divide([4, 16])
# => 4
```

> ¡Nota que el orden de la lista está invertido!
