# Introducción

## Tuplas

Una tupla es una agrupación _inmutable_ de valores sin nombre pero ordenados.
Las tuplas pueden contener cualquier tipo de dato (o varios), incluidas otras tuplas.

Las tuplas se definen como valores separados por comas entre los caracteres `(` y `)`: `(<element_1>, ... , <element_n>)`.

```fsharp
("one", 2) // Tuple pair (2 values)
("one", 2, true) // Tuple triplet (3 values)
```

Solo se pueden comparar las tuplas que tienen la misma longitud y los mismos tipos (en el mismo orden).
Las tuplas tienen igualdad estructural, lo que significa que son iguales _solo_ si todos sus valores son iguales.

```fsharp
(1, 2) = (1, 2) // Same length, same types, same values, same order
// => true

(1, 2) = (2, 1) // Same length, same types, same values, different order
// => false

(1, 2) = (1, "2") // Same length, different types
// compiler error

(1, 2) = (1, 2, 3) // Different length
// compiler error
```

Hay tres maneras de extraer valores de una tupla:

- Las funciones `fst` y `snd`
- La deconstrucción de tuplas
- La coincidencia de patrones

```fsharp
let person = ("Jordan", 170)

// Option 1: fst/snd
let name1 = fst person
let length2 = snd person

// Option 2: deconstruction
let (name2, length2) = person
// => name2 = "Jordan"
// => length2 = 170

// Option 3: pattern matching
match person with
| name3, length3 -> printf "%s: %d" name3 length3
```
