# Anexo a las instrucciones

## Estructura del proyecto

Los ejercicios de Clojure en Exercism usan [leiningen](http://leiningen.org/) para configurar y ejecutar tu código, y siguen la [estructura de directorios estándar de leiningen](https://github.com/technomancy/leiningen/blob/master/doc/TUTORIAL.md#directory-layout).

Encontrarás un archivo de prueba llamado `hello_world_test.clj` dentro del directorio `test`.
Escribe tu código en `src/hello_world.clj`. Debe usar el espacio de nombres `hello-world` para que las pruebas puedan encontrarlo.

## Ejecutar las pruebas

Ejecuta las pruebas con el comando `lein test` y haz que pasen:

```
$ lein test

lein test hello-world-test

Ran 3 tests containing 3 assertions.
0 failures, 0 errors.
```

Luego envía el ejercicio con:

```
$ exercism submit src/hello_world.clj
```

Para obtener instrucciones más detalladas y recursos de aprendizaje, consulta la [página del lenguaje Clojure de Exercism](http://exercism.io/languages/clojure).
