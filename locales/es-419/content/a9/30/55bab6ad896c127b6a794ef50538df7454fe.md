# Acerca de

En Haxe, los iteradores se usan para iterar sobre un valor con un bucle `for`. Hay dos tipos de iteradores:

- `Iterator`, que itera sobre un valor.
- `Iterable`, datos que hacen posible iterar sobre un tipo de dato.

Ambos conceptos están representados por `Iterator<T>` y `Iterable<T>`:

```haxe
typedef Iterator<T> = {
  function hasNext():Bool;
  function next():T;
}

typedef Iterable<T> = {
  function iterator():Iterator<T>;
}
```

Cualquier clase que unifique con uno de estos tipos se puede iterar con un bucle `for`. Si una clase define los métodos `hasNext` y `next`, se considera un iterador; si define un método `iterator`, se considera un tipo iterable:

```haxe
class MyStringIterator {
  var str:String;
  var i:Int;

  public function new(str:String) {
    this.str = str;
    i = 0;
  }

  public function hasNext():Bool {
    return i < str.length;
  }

  public function next():String {
    return str.charAt(i++);
  }
}
```

En el ejemplo anterior, la clase `MyStringIterator` se considera un iterador, ya que implementa los métodos `hasNext` y `next`, lo que la hace compatible con `Iterator<String>`.

```haxe
class MyArrayWrap<T> {
  var arr:Array<T>;

  public function new(a:Array<T>) {
    this.a = a;
  }

  public function iterator() {
    return a.iterator();
  }
}
```

Aquí, la clase `MyArrayWrap` se considera un tipo de dato iterable, ya que es compatible con `Iterable<Array<T>>`.
