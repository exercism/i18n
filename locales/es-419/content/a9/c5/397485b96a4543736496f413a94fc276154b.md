# Acerca de

Los principales operadores aritméticos y de comparación se pueden adaptar para que los usen tus propias clases y structs. Esto se conoce como _sobrecarga de operadores_.

Este [artículo][operator-overloading] es un análisis detallado de la sintaxis, además de qué operadores se pueden sobrecargar y cuáles no.

La mayoría de los operadores tienen la forma:

```csharp
static <return type> operaator <operator symbols>(<parameters>);
```

Los [operadores de conversión][ud-conversion-operators] tienen la forma:

```csharp
static (explicit|implicit) operator <cast-to-type>(<cast-from-type> <parameter name>);
```

Los operadores se comportan igual que los métodos estáticos.

- Un símbolo de operador ocupa el lugar de un identificador de método, y tienen parámetros y un tipo de retorno. Las reglas de tipos para los parámetros y el tipo de retorno siguen tu intuición, y puedes confiar en que el compilador te dará una guía detallada.
- En las operaciones binarias, el primer parámetro toma el argumento de la izquierda de la operación.
- Los operadores tienen una firma que consta de dos parámetros (en el caso de las operaciones binarias) y un tipo de retorno, o bien un solo parámetro y un tipo de retorno en el caso de los operadores unarios.
- En los operadores binarios, uno de los tipos de parámetro debe ser el de la clase declarante.
- En el caso de las conversiones de tipo, ya sea el parámetro o el tipo de retorno debe ser el tipo de la clase declarante.
- En los operadores de incremento y decremento, tanto el parámetro como el tipo de retorno deben ser el de la clase declarante.

Ejemplos de sintaxis:

```csharp
struct Point
{
    decimal x;
    decimal y;

    public static bool operator ==(Point pt, Point ptOther)
    {
        return pt.x == ptOther.x && pt.y == ptOther.y;
    }

    public static bool operator !=(Point pt, Point ptOther)
    {
        return !(pt == ptOther);
    }

    public static Point operator *(Point pt, decimal scale)
    {
        var ptNew = new Point();
        ptNew.x = pt.x * scale;
        ptNew.y = pt.y * scale;
        return ptNew;
    }

    public static implicit operator Point((decimal x, decimal y) xy)
    {
        var pt = new Point();
        pt.x = xy.x;
        pt.y = xy.y;
        return pt;
    }

    public static explicit operator (decimal x, decimal y)(Point pt)
    {
        return (pt.x, pt.y);
    }
}
```

A menudo resulta productivo implementar un método [`Equals()`][equals] y llamarlo desde el operador `==`. De manera similar, para las comparaciones puedes implementar la interfaz [`IComparable`][icomparable]. En ambos casos, matas dos pájaros con algo más de una piedra.

Ten en cuenta que no puedes crear operadores a partir de símbolos que no formen parte del conjunto estándar de operadores. Solo puedes usar símbolos existentes para aquellas operaciones en las que la documentación especifica que se pueden sobrecargar. Los operadores que se pueden sobrecargar están listados [aquí][overloadable-operators].

Observa que el orden de los parámetros es importante cuando difieren en tipo. En el código de ejemplo anterior, `pt * 10m` es una expresión válida, mientras que `10m * pt` no compila.
