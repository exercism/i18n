# Acerca de

Un bucle es una manera de ejecutar repetidamente una o más sentencias en conjunto.
Cada ejecución de un conjunto de sentencias se llama una iteración.

## Bucle `while`

Un bucle `while` ejecuta un conjunto de sentencias mientras una expresión Boolean en la parte superior del bucle sea verdadera.
Cuando la expresión Boolean es falsa, el bucle deja de ejecutarse y la ejecución continúa en la siguiente línea de código después del bucle.

Si la expresión Boolean se evalúa como falsa desde el principio, el bucle `while` no se ejecutará en absoluto y la ejecución continuará en la siguiente línea de código después del bucle.

```c
int main() {
    int i = 0;
    while (i < 5) {
        printf("Number is %i\n", i++);
    }    
    return 0;
}
```

Es importante que haya una condición para terminar el bucle; de lo contrario, se trata de un bucle infinito que bloqueará todo avance del código.
Si al código anterior se le quitara el `++` de `i`, sería un bucle infinito.

## Bucle `do`

Un bucle `do` evalúa su expresión Boolean en la parte inferior del bucle.
Un bucle `do` siempre se ejecutará al menos una vez, como en el siguiente ejemplo

```c
do {
    printf("Enter the Answer to the Ultimate Question of Life: ");
    scanf("%d", &answer);
} while (answer != 42); 
// Note that a semicolon is needed after the Boolean expression.
```

Con un bucle `while`, esto sería más verboso

```c
printf(""Enter the Answer to the Ultimate Question of Life: ");
scanf("%d", &answer);
while (answer != 42) {
    printf(""Enter the Answer to the Ultimate Question of Life: ");
    scanf("%d", &answer);
}
```

## Bucle `for`

A menudo, un bucle actualiza una variable y termina cuando la variable alcanza cierto valor.
Un bucle `for` es una manera de inicializar, actualizar y comprobar una o más variables en una sola línea dentro de paréntesis.
La primera sección sirve para inicializar la variable, la segunda para comprobarla y la tercera para actualizar el valor de la variable.

```c
for (int i = 0; i < 5; i++) {
    printf("Number is %i\n", i);
}
```

Esto es menos verboso que el bucle `while` equivalente y, aun así, sigue siendo legible.

Las secciones de inicialización y actualización del bucle `for` pueden manejar más de una variable usando el operador coma para separar las expresiones dentro de las condiciones.

```c
    int i, j;
    for (i = 0, j = 5; i < 5 && j > 2; i++, j--) {
        printf("i is %i\n", i);
        printf("j is %i\n", j);
    }
    printf("After the loop");
```

Esto imprimirá

```
i is 0
j is 5
i is 1
j is 4
i is 2
j is 3
After the loop
```

Ninguna de las secciones del bucle `for` necesita definirse.
Una expresión de comprobación vacía se evalúa como verdadera, así que un bucle `for` podría usarse para definir un bucle infinito así

```c
int i = 0;
for (;;) {
    printf("Number is %i\n", i++);
    if (i == 5) break;
}
```

Esto es similar al bucle `while`, ya que `i` se inicializa antes del bucle y se incrementa dentro de él.
Además, `i` se comprueba dentro del bucle y el bucle termina con la sentencia `break`.

## Sentencia `break`

En ocasiones, un bucle puede necesitar terminar ante una condición especial que no se comprueba en su expresión Boolean.
La sentencia `break` termina el bucle y la ejecución continúa en la siguiente línea de código después del bucle.

```c
int i, j, k;
for (int i = 0, j = 5, k = 3; i < 5 && j > 2; i++, j--) {
    printf("i is %i\n", i);
    printf("j is %i\n", j);
    if (k == 3) break;
}
printf("After the loop");
```

Esto imprimirá

```
i is 0
j is 5
After the loop
```

## Sentencia `continue`

En ocasiones, un bucle puede necesitar comenzar su siguiente iteración sin completar la iteración actual.
La sentencia `continue` detiene la ejecución de la iteración actual y continúa la ejecución al inicio de la siguiente iteración.

```c
int i, j;
for (int i = 0, j = 4; i < 4 && j > 0; i++, j--) {
    if (i == j) continue;
    printf("i is %i\n", i);
    printf("j is %i\n", j);
}
printf("After the loop");
```

Esto imprimirá

```
i is 0
j is 4
i is 1
j is 3
i is 3
j is 1
After the loop
```

No imprime los valores de `i` y `j` cuando ambos son `2`.
