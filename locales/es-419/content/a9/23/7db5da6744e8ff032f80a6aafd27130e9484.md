# Introducción

## Arrays

En Ruby, los **arrays** son colecciones ordenadas de cualquier objeto, indexadas por números enteros.
La indexación de los arrays empieza en `0`.
Un índice negativo se interpreta en relación con el final del array. Por ejemplo, un índice de `-1` indica el último elemento del array, `-2` es el penúltimo elemento del array, y así sucesivamente.

### Creación de arrays

Los arrays se crean normalmente con la notación `[]`.
Pueden contener objetos de cualquier tipo.

```ruby
array = [1, "two", 3.0]
```

### Referencia a elementos

Los elementos de un array se pueden obtener por su índice con el método `#[]`.
Esto devuelve el elemento que está en ese índice, o devuelve un subarray que empieza en el índice inicial y continúa durante una longitud determinada.
Los índices negativos cuentan hacia atrás desde el final del array.

```ruby
a = [ "a", "b", "c", "d", "e" ]

a[2]       #=> "c"
a[6]       #=> nil
a[1, 3]    #=> [ "b", "c", "d" ]

a[-1]      #=> "e"
a[-2]      #=> "d"
a[-3, 2]   #=> ["c", "d"]
```

### Métodos auxiliares

Hay muchos métodos auxiliares útiles en los arrays.
Aquí tienes algunos de los más comunes:

```ruby
fibonacci = [0, 1, 1, 2, 3, 5, 8, 13]

fibonacci.size      #=> 8
fibonacci.sum       #=> 33
fibonacci.reverse   #=> [13, 8, 5, 3, 2, 1, 1, 0]
```

## Enumeración

En lugar de usar bucles para recorrer colecciones, en Ruby usamos la enumeración.

La enumeración es el acto de recorrer una colección (en este caso, un array) y realizar alguna acción con cada objeto. La enumeración es un concepto clave en Ruby y se usa para cosas como ordenar, agrupar, mapear, reducir y mucho más.

Una enumeración para imprimir cada palabra de un array se vería así:

```ruby
words = ["the", "cat", "sat"]
words.each do |word|
  puts word
end

# Output:
# the
# cat
# sat
```

En este ejemplo, llamamos al método `.each` en nuestro array y le pasamos un _bloque_ que recibe un parámetro (`word`) y lo imprime.

Veremos los _bloques_ con mucho más detalle más adelante en el Track, pero por ahora piensa en ellos como funciones anónimas que pueden recibir cero o más argumentos.
Se pueden definir con la sintaxis `do...end` (arriba) o con la sintaxis `{}` (abajo).

Aquí tienes otros ejemplos de métodos de array que usan bloques:

```ruby
fibonacci = [0, 1, 1, 2, 3, 5, 8, 13]

fibonacci.count  { |number| number == 1 }   #=> 2
fibonacci.any?   { |number| number == 6 }   #=> false
fibonacci.select { |number| number.odd? }   #=> [1, 1, 3, 5, 13]
fibonacci.all?   { |number| number < 20 }   #=> true
fibonacci.map    { |number| number * 2  }   #=> [0, 2, 2, 4, 6, 10, 16, 26]
```
