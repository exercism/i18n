# Introducción

El operador `|>` se llama operador pipe. Se puede usar para encadenar llamadas a funciones de forma que el valor que devuelve la llamada anterior se pase a la siguiente llamada.

```gleam
"hello"
|> string.uppercase
|> string.append("?!")
// -> "HELLO?!"
```

El código anterior es equivalente al siguiente:

```gleam
string.append(string.uppercase("hello"), "?!")
```

El operador pipe pasa el valor como primer argumento de la llamada a la función, o como el único argumento de una nueva llamada, según cuál de las dos opciones dé como resultado el tipo correcto.

```gleam
100
|> function_that_takes_two_arguments(1)

// Is equivalent to
function_that_takes_two_arguments(100, 1)
```

```gleam
100
|> function_that_returns_a_function(1)

// Is equivalent to
function_that_returns_a_function(1)(100)
```

A veces queremos pasar el valor a otra posición. En ese caso podemos usar el marcador de posición `_` para indicar dónde se debe insertar el valor.

```gleam
100
|> some_function(1, _, 2)
```
