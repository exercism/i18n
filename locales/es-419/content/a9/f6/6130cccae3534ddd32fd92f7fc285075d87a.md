# Acerca de

Elm es un lenguaje encantador para crear aplicaciones web confiables.
Tiene mensajes de error amigables, un gran rendimiento, recursos ligeros y ninguna excepción en tiempo de ejecución.

Probablemente la parte más famosa y más copiada de Elm es la arquitectura Elm, que es un patrón simple para estructurar aplicaciones web y es como se escriben todas las aplicaciones web en Elm.

La idea central es que tu código se construye alrededor de un `Model` del estado de tu aplicación, una forma de `update` tu modelo y una forma de `view` tu modelo.

El `Model` contiene el estado de la aplicación, es decir, todos los datos que la aplicación necesita.
Si imaginas una aplicación simple con una caja de texto y un texto que muestra ese texto al revés, el modelo se vería como se muestra a continuación.
También puedes ver este ejemplo en la [Guía de Elm][elm-guide-text-fields].

```elm
type alias Model =
  { text : String
  }
```

`update` es una función que se llama con un `Msg` cuando hay un cambio (como que el usuario haga clic en un botón).
Recibe el `Msg` y el `Model` actual, y devuelve un nuevo `Model`.

```elm
type Msg
  = TextChanged String

update : Msg -> Model -> Model
update msg model =
  case msg of
    TextChanged newText ->
      { model | text = newText }
```

`view` es una función que devuelve HTML para mostrarle al usuario en el navegador.
Recibe el `Model` actual y devuelve un `Html Msg` (el tipo que Elm usa para representar HTML).

```elm
view : Model -> Html Msg
view model =
  Html.div []
    [ Html.input
      [ Html.Attributes.placeholder "Text to reverse"
      , Html.Attributes.value model.text
      , Html.Events.onInput TextChanged
      ]
      []
    , Html.div [] [ Html.text (String.reverse model.text) ]
    ]
```
