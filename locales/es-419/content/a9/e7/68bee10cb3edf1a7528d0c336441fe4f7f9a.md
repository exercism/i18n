# Acerca de

Las [estructuras][structs-and-classes] (llamadas comúnmente *structs*) son uno de los principales bloques de construcción de los programas en Swift.
Las estructuras te permiten crear tipos personalizados que agrupan propiedades (datos) y métodos (comportamiento) relacionados.
De hecho, los tipos estándar de Swift, como `Int`, `Double`, `Bool`, `String`, `Array` y `Dictionary`, están todos implementados como estructuras.

## Definir estructuras

Define una estructura con la palabra clave `struct`, seguida del nombre del tipo y llaves que contienen su definición.
Por convención de Swift, los nombres de las estructuras usan `UpperCamelCase`:

```swift
struct CharacterStats {
    var health = 0.0
    var speed = 0
    var strength = 0
}
```

## Crear instancias

La definición de una estructura es un plano.
Para crear una *instancia* de una estructura, llama a su inicializador escribiendo el nombre del tipo seguido de paréntesis:

```swift
var someStats = CharacterStats()
```

Esto crea una instancia con los valores predeterminados de las propiedades de la definición.

Swift también genera automáticamente un **inicializador por miembros** para las estructuras, que te permite inicializar las propiedades por nombre:

```swift
let customStats = CharacterStats(health: 100.0, speed: 6, strength: 18)
```

## Acceder y modificar propiedades

Accedes y modificas las propiedades de una instancia con la *notación de punto*:

```swift
var stats = CharacterStats()

print(stats.health) // Prints 0.0

stats.health = 87.3
print(stats.health) // Prints 87.3
```

Como las estructuras son tipos de valor, para modificar las propiedades de una instancia, la instancia misma debe declararse con `var`.
Si la instancia se declara con `let`, todas sus propiedades se vuelven inmutables.
