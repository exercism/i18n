# Instrucciones

En este ejercicio escribirás código para ayudar a un freelancer a comunicarse con un gerente de proyecto, proporcionando algunas herramientas para calcular rápidamente tarifas diarias y mensuales, opcionalmente con un descuento dado.

Primero establecemos algunas reglas entre el freelancer y el gerente de proyecto:

La tarifa diaria es 8 veces la tarifa por hora.
Un mes tiene 22 días facturables.
El freelancer ofrece aplicar un descuento si el gerente de proyecto decide dejar que el freelancer facture por mes, lo cual puede resultar útil si el gerente de proyecto tiene que trabajar con un presupuesto determinado.

Los descuentos se modelan como números fraccionarios que representan un porcentaje, por ejemplo 25.0 (25 %).

## 1. Calcular la tarifa diaria a partir de una tarifa por hora

Implementa una función para calcular la tarifa diaria a partir de una tarifa por hora:

```gleam
freelancer_rates.daily_rate(60)
# => 480.0
```

La tarifa diaria devuelta debe ser un número de punto flotante.

## 2. Calcular un precio con descuento

Implementa una función para calcular el precio después de un descuento.

```gleam
freelancer_rates.apply_discount(150, 10)
# => 135.0
```

El valor devuelto siempre debe ser un número de punto flotante, sin redondear de ninguna manera.

## 3. Calcular la tarifa mensual a partir de una tarifa por hora y un descuento

Implementa una función para calcular la tarifa mensual y aplicar un descuento:

```gleam
freelancer_rates.monthly_rate(77, 10.5)
# => 12130
```

La tarifa mensual devuelta debe redondearse hacia arriba (aplicar el techo) al número entero más cercano.

## 4. Calcular la cantidad de días laborables a partir de un presupuesto, una tarifa por hora y un descuento

Implementa una función que recibe un presupuesto, una tarifa por hora y un descuento, y calcula cuántos días de trabajo cubre.

```gleam
freelancer_rates.days_in_budget(20000, 80, 11.0)
# => 35
```

El número de días devuelto debe redondearse hacia abajo (aplicar el suelo) a un decimal.
