# Marcador de posición

## Cómo resolverlo con bash

`bash` no tiene ninguna forma integrada de **parsear** strings de fecha y hora.
Este ejercicio requiere que llames a una utilidad externa.

* La opción `-d` del comando `date` de GNU puede parsear [una amplia variedad de formatos][gnu-date].
* Si usas Mac, consulta el [comando `date` de BSD][bsd-date] y su opción `-f`.
* Perl está ampliamente disponible, y su [módulo `Time::Piece`][time-piece] se puede usar para parsear marcas de tiempo.

bash puede **formatear** fechas sin ninguna herramienta externa.
Dado un valor de tiempo entero (segundos desde la época), [el formateador `%()T` de `printf`][bash-printf] puede aplicar un formato estilo «strftime».

```bash
epoch=1234567890

printf '%(%Y-%m-%d %H:%M:%S)T\n' "$epoch"
# ==> 2009-02-13 18:31:30

# bash uses the `TZ` environment variable for the timezone.

TZ=Asia/Kolkata printf '%(%Y-%m-%d %H:%M:%S)T\n' "$epoch"
# ==> 2009-02-14 05:01:30
```

[bsd-date]: https://manpage.me/index.cgi?apropos=0&q=date&sektion=0&manpath=FreeBSD+12-CURRENT+and+Ports&arch=default&format=html
