# Expresiones de coincidencia

Una expresión de coincidencia evalúa un valor y una condición para devolver una expresión que se evaluará. Al igual que un operador ternario, si la condición no coincide, la expresión de retorno no se evalúa. Para que una condición coincida, se realiza una comprobación de identidad [igualdad estricta o `===`].

```php
<?php
$some_value = 42;

$return_value = match($some_value) {
    0 => 'number is 0',
    1 => 'number is 1',
    default => 'number is something else'
}
```

Para hacer una comprobación de igualdad [`==`], puedes reorganizar la condición:

```php
<?php
$some_value = 42;

$return_value = match(true) {
    $some_value < 100 => 'number is less than 100',
    $some_value > 100 => 'number is greater than 100',
    $some_value == 100 => 'number is 100',
}
```

En una expresión de coincidencia, si no coincide ninguna condición, se lanzará un `UnhandledMatchError`.
