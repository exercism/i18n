# Pruebas

Para ejecutar las pruebas, ejecuta el siguiente comando:

```bash
make
```

## Pruebas omitidas

Resolver un ejercicio significa hacer que todas sus pruebas pasen.
De forma predeterminada, cuando ejecutas las pruebas solo se ejecuta una (la primera).
Esto es intencional, ya que te permite concentrarte solo en hacer que esa prueba pase.
Cuando esa prueba pase, puedes habilitar la siguiente si eliminas la línea `TEST_IGNORE()`.
Cuando hayas habilitado todas las pruebas y tu implementación las haga pasar todas, ¡habrás resuelto el ejercicio!
