# Pistas

## General

- Necesitas usar distintas formas de [flujo de control][control-flow] para resolver este ejercicio.

## 1. Verifica la criticidad

- Necesitas usar sentencias [if][if] o [unless][unless] para resolver este ejercicio.
- Necesitas usar [operadores de comparación][equality-and-comparison] para resolver este ejercicio.
- Para combinar varias condiciones puedes usar [`&&`][and] y [`||`][or].

## 2. Determina el rango de potencia de salida

- Puedes crear varias ramas usando `if` y `elsif`.

## 3. Mecanismo a prueba de fallos

- Puedes usar `if` y `elsif` para crear varias ramas.
