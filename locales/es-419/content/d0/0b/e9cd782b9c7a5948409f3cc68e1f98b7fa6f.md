# Instalación

## Mac

Instálalo con homebrew usando `brew install swi-prolog`.
También puedes descargar el código fuente para tu computadora desde el [sitio web de SWI Prolog](http://www.swi-prolog.org/download/devel).

## Windows

Descarga el código fuente para tu computadora desde el [sitio web de SWI Prolog](http://www.swi-prolog.org/download/devel).

## Linux

Sigue las instrucciones para tu distribución desde [aquí](http://www.swi-prolog.org/build/unix.html).
