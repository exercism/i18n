# Anexo de instrucciones

## Registros

| Registro | Uso       | Tipo    | Descripción                      |
| -------- | --------- | ------- | -------------------------------- |
| `$a0`    | entrada   | entero  | número de casilla en el rango 1..64 |
| `$v0`    | salida    | entero  | 32 bits bajos de la salida       |
| `$v1`    | salida    | entero  | 32 bits altos de la salida       |
| `$t0-9`  | temporal  | cualquiera | para almacenamiento temporal  |
