# Introducción

## Malabares de tipos

Los malabares de tipos también se conocen como coerción de tipos.
Los malabares de tipos ocurren cuando dos valores de tipos distintos se convierten al mismo tipo para realizar una operación.

```php
$baskets = 5 // int
$apples_per_basket = "3" // string
$baskets * $apples_per_basket
# => 15
```

Esto se puede hacer de forma implícita (como en el ejemplo de arriba) o de forma explícita con una conversión de tipos al estilo de `C`:

```php
$apples_per_basket = "3" // string
$my_number = (int) $apples_per_basket // cast string to int
# => 3 // int
```

Los tipos permitidos para la conversión de tipos manual son: `bool`, `int`, `float`, `string`, `array`, `object`.
Lo más común es usar la conversión de tipos para cambiar un entero (`int`) a un número de punto flotante (`float`) o viceversa.
