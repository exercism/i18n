# Instrucciones

Se te ha encargado crear una biblioteca de registros que ayude a gestionar los registros de tu organización.
Esta biblioteca permitirá a los usuarios identificar qué aplicación emitió un registro determinado, corregir registros corruptos y determinar si una línea de registro está dentro de cierto límite de caracteres.

## 1. Identifica qué aplicación emitió un registro

Los registros provienen de múltiples aplicaciones, y cada una usa su propio formato de registro propietario.
La aplicación que emite un registro debe identificarse antes de poder almacenarlo en un sistema de agregación de registros.

Implementa la función `Application` que recibe una línea de registro y devuelve la aplicación que emitió esa línea de registro.

Para identificar qué aplicación emitió una línea de registro dada, busca en la línea de registro un carácter específico, según lo indicado en la siguiente tabla:

| Aplicación       | Carácter  | Punto de código Unicode |
|------------------|-----------|-------------------------|
| `recommendation` | ❗        | `U+2757`                |
| `search`         | 🔍        | `U+1F50D`               |
| `weather`        | ☀         | `U+2600`                |

Si una línea de registro no contiene ninguno de los caracteres de la tabla anterior, devuelve `default` a quien hizo la llamada.
Si una línea de registro contiene más de un carácter de la tabla anterior, devuelve la aplicación correspondiente al primer carácter que aparezca en la línea de registro, de izquierda a derecha.

```go
Application("❗ recommended search product 🔍")
// => recommendation
```

## 2. Corrige registros corruptos

Debido a un error poco frecuente pero persistente en la infraestructura de registro, ciertos caracteres de los registros pueden corromperse.
Después de dedicar tiempo a identificar los caracteres corruptos y su valor original, decides actualizar la biblioteca de registros para ayudar a corregir los registros corruptos.

Implementa la función `Replace` que recibe una línea de registro, un carácter corrupto y el valor original, y devuelve una línea de registro modificada en la que todas las apariciones del carácter corrupto se reemplazaron por el valor original.

```go
log := "please replace '👎' with '👍'"

Replace(log, '👎', '👍')
// => please replace '👍' with '👍'"
```

## 3. Determina si un registro se puede mostrar

Los sistemas encargados de mostrar los registros tienen un límite en la cantidad de caracteres que se pueden mostrar por línea de registro.
Por eso, los usuarios piden que esta biblioteca incluya una función auxiliar que determine si una línea de registro está dentro de un límite de caracteres específico.

Implementa la función `WithinLimit` que recibe una línea de registro y un límite de caracteres, y devuelve si la línea de registro está dentro de ese límite de caracteres o no.

```go
WithinLimit("hello❗", 6)
// => true
```
