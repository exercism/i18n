# Instrucciones

En este ejercicio te apasionan los deportes y acabas de descubrir tu pasión por el básquetbol de la NBA.
Como eres nuevo en el básquetbol de la NBA, te estás sumergiendo en la historia de la NBA, llevando un registro de equipos, entrenadores y sus estadísticas de victorias y derrotas, y comparándolos entre sí.

Como todavía no tienes un equipo favorito, también vas a desarrollar un algoritmo para determinar si deberías apoyar a un equipo en particular.
Tienes siete tareas que te ayudarán a desarrollar tu propio algoritmo _root-for-a-team_.

## 1. Define el modelo

Define el alias de tipo `Coach` para un registro con los siguientes dos campos, en el siguiente orden:

- `name`: el nombre del entrenador, de tipo `String`.
- `formerPlayer`: indica si el entrenador fue jugador anteriormente, de tipo `Bool`.

Define el alias de tipo `Stats` para un registro con los siguientes dos campos, en el siguiente orden:

- `wins`: la cantidad de victorias, de tipo `Int`.
- `losses`: la cantidad de derrotas, de tipo `Int`.

Define el alias de tipo `Team` para un registro con los siguientes tres campos, en el siguiente orden:

- `name`: el nombre del equipo, de tipo `String`.
- `coach`: el entrenador del equipo, de tipo `Coach`.
- `stats`: las estadísticas del equipo, de tipo `Stats`.

## 2. Crea un equipo

Quieres interactuar con código de terceros que tiene el concepto de equipo, pero que llama a tu código con los parámetros en un orden diferente. Agrega una función `createTeam` con la siguiente firma `String -> Stats -> Coach -> Team`.

## 3. Reemplaza al entrenador

Como los dueños de la NBA son impacientes, descubriste que los malos resultados del equipo a menudo hacían que se reemplazara al entrenador.
Implementa la función `replaceCoach` que toma el nuevo entrenador y el equipo como parámetros, y devuelve el equipo pero con el nuevo entrenador:

```elm
let
    coach = { name = "Larry Bird", formerPlayer = True }
    stats = { wins = 58, losses =  24 }
    team = { name = "Indiana Pacers", coach = coach, stats =  stats }
    newCoach = { name = "Isiah Thomas", formerPlayer = True }
in
replaceCoach newCoach team
--> { name = "Indiana Pacers"
--  , coach = { name = "Isiah Thomas", formerPlayer = True }
--  , stats = { wins = 58, losses = 24 } }
```

## 4. Comprueba si deberías apoyar a un equipo

En el futuro planeas crear un algoritmo complicado para decidir si apoyar a un equipo o no, pero para el primer intento has decidido que deberías apoyar a cualquier equipo que tenga más victorias que derrotas.

Quieres que esta función sea reutilizable en otros contextos, así que usa un registro extensible en la firma de tipo para aceptar cualquier registro que tenga los campos relevantes.
Para que la función sea lo más concisa posible, quieres usar coincidencia de patrones para obtener los `stats` del parámetro de la función.
Implementa la función `rootForTeam` que toma un equipo y devuelve `True` si deberías apoyar a ese equipo; de lo contrario, devuelve `False`.

```elm
let
    spursCoach = { name = "Gregg Popovich", formerPlayer =  False }
    spursStats = { wins = 56, losses = 26 }
    spursTeam = { name = "San Antonio Spurs", coach = spursCoach, stats = spursStats }
in
rootForTeam spursTeam
--> True
```
