# Debug

Toda la salida de tu script de Red es visible en la consola cuando ejecutas cada test. Puedes usar `print` para lo que quieras, por ejemplo, los valores de las palabras:

```red
print ["x =" x]
```

Además, la función `probe` es muy útil. Cuando se evalúa, evalúa su argumento, imprime el resultado de una forma que refleja su tipo y lo devuelve. Así que en la mayoría de los casos es «transparente», y puedes insertarla dentro de expresiones:

```red
x: 10
y: probe x + 5
```

A veces, la función llamada `type?` (¡sí, tiene un signo de interrogación en su nombre!) puede ser útil para verificar el tipo de un valor:

```red
print ["x type:" type? x]
```

También hay algunas técnicas de depuración más avanzadas [enumeradas en la Wiki de Red](https://github.com/red/red/wiki/%5BDOC%5D-Debugging).
