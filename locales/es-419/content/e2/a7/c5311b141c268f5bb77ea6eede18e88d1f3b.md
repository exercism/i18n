# Pistas

## General

- Un [valor entero][integers] se puede definir como uno o más dígitos consecutivos.
- Si ves un error de `panic:` al ejecutar las pruebas, se debe a que no implementaste una de las funciones (debería decir cuál) o a que dejaste la plantilla sin cambios. Tienes que eliminar la línea `panic(...)` del código que te dieron y reemplazarla por una implementación real.

## 1. Define el tiempo esperado en el horno en minutos

- Tienes que definir una [constante][constants] y asignarle el tiempo esperado en el horno en minutos.
- Si ves un error `undefined: OvenTime`, revisa bien que hayas definido la constante.
- Si ves un error `invalid operation: got != tc.expected (mismatched types float64 and int)`, probablemente pusiste un punto decimal en `OvenTime`, lo que hace que Go infiera el tipo como un número de punto flotante. Quita el decimal y el tipo se inferirá como un `int`.
- Si ves un error `syntax error: non-declaration statement outside function body`, es probable que hayas olvidado la palabra clave `const`.
- Si ves un error `syntax error: unexpected :=, expecting =`, es probable que estés intentando asignar la constante con `:=` como si fuera una variable; las constantes se asignan con `=`, no con `:=`.

## 2. Calcula el tiempo restante en el horno en minutos

- Tienes que definir una [función][functions] con un solo parámetro.
- Tienes que [devolver explícitamente un entero][return] desde una función.
- El parámetro de la función es un [entero][integers].
- Puedes [llamar][calls] a una de las otras funciones que definiste antes.
- Puedes usar el [operador matemático de resta][operators] para restar valores.

## 3. Calcula el tiempo de preparación en minutos

- Tienes que definir una [función][functions] con un solo parámetro.
- Tienes que [devolver explícitamente un entero][return] desde una función.
- El parámetro de la función es un [entero][integers].
- Puedes usar el [operador matemático de multiplicación][operators] para multiplicar valores.

## 4. Calcula el tiempo de trabajo transcurrido en minutos

- Tienes que definir una [función][functions] con dos parámetros.
- Tienes que [devolver explícitamente un entero][return] desde una función.
- El parámetro de la función es un [entero][integers].
- Puedes [llamar][calls] a una de las otras funciones que definiste antes.
- Puedes usar el [operador matemático de suma][operators] para sumar valores.
