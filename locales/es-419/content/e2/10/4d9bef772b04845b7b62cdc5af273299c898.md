# Anexo a las instrucciones

## Palabras

Define una tupla `cmplx` con las ranuras `real` e `imaginary`. Los
accesores de ranura `real>>` e `imaginary>>` vienen incluidos con la
definición de la tupla y son los que usan los tests para leer los componentes.

- `<cmplx> ( real imag -- cmplx )`: construye un número complejo.
- `>cmplx ( pair -- cmplx )`: construye un `cmplx` a partir de
  `{ real imaginary }`.
- `cmplx>pair ( cmplx -- pair )`: devuelve `{ real imaginary }`.
- `c+ ( a b -- c )`, `c- ( a b -- c )`, `c* ( a b -- c )`,
  `c/ ( a b -- c )`: aritmética entre dos números complejos.
- `c-abs ( a -- |a| )`: valor absoluto (un número real).
- `c-conj ( a -- a* )`: conjugado complejo.
- `c-exp ( z -- e^z )`: exponencial compleja.

Los genéricos `MATH:` de Factor (`+`, `-`, `*`, `/`) solo se despachan sobre
la jerarquía matemática incorporada, así que este ejercicio define palabras
con nombres específicos en lugar de métodos sobre esos genéricos.

Los tests de aritmética que mezcla números reales con números complejos
quedan excluidos: aquí todas las operaciones son entre dos valores
`cmplx`.
