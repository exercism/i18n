# Nil

Crystal tiene un tipo llamado [`Nil`][nil], que solo puede tener un valor: `nil`.
Se usa para representar la ausencia de un valor y es similar a `null` o `None` en otros lenguajes.

Los valores `nil` se pueden devolver desde varios métodos; por ejemplo, [`String#[]?`][string-index], que devuelve `nil` si el índice está fuera de rango.

```crystal
"foo"[10]? # => nil
```

Crystal tiene lo que se conoce como **verificación de referencias nulas**, lo que significa que, por defecto, ningún tipo puede ser `nil`.
Esto quiere decir que no puedes asignar `nil` a una variable a menos que la declares explícitamente como de tipo `Nil`.
A su vez, esto significa que el compilador verificará automáticamente las referencias nulas.

## Valor falsey

Existen varios enfoques para manejar los valores `nil`.
`nil` es un valor [falsey][truthy-falsey], al igual que `false`.
Esto significa que, en sentencias y en otros lugares donde se espera un valor falsey o truthy, se tratará igual que `false`.

```crystal
if nil
  puts "nil is truthy"
else
  puts "nil is falsey"
end

# => nil is falsey
```

Esto significa que no se tomará la rama truthy si una variable que puede ser `nil` tiene el valor `nil`.

```crystal
foo = "boo"[2]? # It is possible that foo is nil
if foo
  p foo.class # => Char
end
```

## Comprobar si un valor es nil

Crystal tiene un método que se puede usar para comprobar si un valor es `nil`.
Se llama [`nil?`][nil?] y está disponible en todos los objetos.

```crystal
foo = "boo"[2]?
if foo.nil?
  puts "foo is nil"
else
  puts "foo is not nil"
end
```

Esto es un poco distinto cuando solo usas el valor en un condicional, ya que en los ejemplos anteriores tanto `false` como `nil` se trataban como falsos.
Aquí solo `nil` se trata como falsey, porque si el valor fuera `false` no sería nil y, por lo tanto, sería truthy.

## Operador or

La forma más fácil de lidiar con los valores `nil` es asegurarte de que nunca lleguen a ser `nil` en primer lugar.
El operador or ([`||`][or]) se usa a menudo cuando se trabaja con `Bools`, pero, si se entiende bien, también se puede usar para trabajar con valores `nil`.
El operador or comprueba si el primer valor es truthy; si no lo es, se usa el segundo valor.
Esto se puede aprovechar para que, si el valor es `nil`, sea falsey y, por lo tanto, se use el segundo valor.

```crystal
"foo"[10]? || "bar" # => "bar"
```
