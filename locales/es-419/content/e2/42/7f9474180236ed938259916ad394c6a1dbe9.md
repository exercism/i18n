# Anexo de instrucciones

La dirección a la que apunta el robot se expresará como uno de los siguientes números:

- Norte = 0
- Este = 1
- Sur = 2
- Oeste = 3

Cuando la entrada no sea válida, devuelve una dirección de -1 (los demás valores se ignorarán).

## Memoria reservada

El búfer para el string de entrada usa los bytes 64-319 de la memoria lineal.

El string de entrada se puede modificar si lo deseas.
