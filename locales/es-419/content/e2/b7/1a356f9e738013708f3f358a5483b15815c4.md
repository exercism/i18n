# Pistas

## General

- Los slices en Go están basados en cero.
  El primer índice de un slice es `0`.
- La función integrada [`append`][append-builtin] es [`variadic`][variadic-gobyexample]
- Puedes agregar los elementos de un slice a otro usando la notación de tres puntos:

```go
a := []int{1, 3}
b := []int{4, 2, 6}
c := append(a, b...)
fmt.Println(c)
// Output: [1 3 4 2 6]
```

## 1. Crea un slice con ciertas cartas

- Para crear un slice precargado con algunos datos, usa la notación de literal de slice: `s := []T{x1, x2, ..., xn}`.

## 2. Recupera una carta de la pila

- Para obtener el elemento número `n` de un slice, [usa un índice][go-slices].
- Para verificar si un elemento existe en un slice, usa un condicional y compara el índice con la [longitud del slice][len-builtin].

## 3. Intercambia una carta en la pila

- Para establecer el elemento número `n` de un slice, [usa un índice][go-slices] y asígnale un valor nuevo.
- Para añadir un elemento nuevo al final de un slice, usa la función `append`.

## 4. Agrega cartas a la parte superior de la pila

- Agregar elementos al frente de un slice se puede hacer agregando los elementos del slice original al slice del argumento `value`.

## 5. Elimina una carta de la pila

- Quitar un elemento de un slice se puede hacer agregando la parte que está después de `index` a la parte que está antes de index.
