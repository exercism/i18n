# Acerca de

Los hashes son un tipo de datos en Perl que contienen una colección desordenada de claves de tipo string emparejadas con valores escalares.

Una variable hash normalmente se llena asignándole una lista, por ejemplo, `my %scores = (Alice => 10, Bob => 15, Charlie => 20);`.

Las listas normalmente se separan con comas, pero es común ver lo que se conoce como la «coma gorda» `=>` para separar claves y valores en una lista.
Su comportamiento es casi idéntico al de una coma, pero tiene el beneficio adicional de interpretar el elemento del lado izquierdo como un string.

Los hashes se pueden llenar asignando a claves individuales, por ejemplo, `$scores{Alice} = 10;`.

Se puede acceder a los valores de un hash especificando claves mediante un subíndice, por ejemplo, `$scores{Bob} # 15`.

Las claves en un hash son únicas.
Si una clave se proporciona varias veces, solo se conservará el último valor proporcionado.

## Funciones

Las funciones para trabajar con hashes incluyen [keys][keys] y [values][values], para recuperar esas partes respectivas de un hash como una lista.
Las listas devueltas por las funciones [keys][keys] y [values][values] pueden ser útiles para funciones de lista como [grep][grep], [map][map] y [sort][sort], así como para bucles [for][for].

Otras funciones de hash incluyen [exists][exists], para verificar si una clave existe en un hash (incluso si su valor es `undef`), y [delete][delete], para eliminar una clave de un hash.

## Variación de sigilos

Al obtener valores de un hash, el sigilo dado determina el resultado.
El subíndice `{}` al final del nombre de la variable es lo que le indica a Perl que estás accediendo a un hash con ese nombre.

```perl
my %names = (Alice => 10, Bob => 15, Charlie => 20);

$names{Alice}; # 10            <- A scalar
@names{Alice}; # (10)          <- A slice (with only one key, this probably isn't what you want. There will be a warning.)
%names{Alice}; # ('Alice', 10) <- A key/index + value slice

$names{'Bob', 'Charlie'}; #                            <- An error (disabled syntax for an ancient feature.)
@names{'Bob', 'Charlie'}; # (15, 20)                   <- A slice
%names{'Bob', 'Charlie'}; # ('Bob', 15, 'Charlie', 20) <- A key/index + value slice
```

Si bien está permitido, se recomienda que distintos tipos de variables no compartan el mismo nombre para facilitar la legibilidad.
