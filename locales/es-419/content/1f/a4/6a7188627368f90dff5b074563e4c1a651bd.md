# Fundamentos de la sintaxis de Haskell

## Constantes y funciones

Los programas en Haskell se componen de definiciones y expresiones.

Un valor constante se define con `name = expression`.

```haskell
five = 5

six = 3 + 3
```

Las funciones se definen con `name parameters... = expression`, y los parámetros se separan solo con espacios.

```haskell
add number1 number2 = number1 + number2
```

Llamar a una función también es una expresión, y se hace escribiendo su nombre y pasando argumentos para cada uno de los parámetros de la función, separados por espacios, igual que en las definiciones de funciones.

```haskell
five = add 2 3
```

Los paréntesis se pueden usar para especificar el orden de evaluación de una expresión.

```haskell
six = add 2 (1 * 4)

twelve = add 2 1 * 4
```

## Indentación / espacios en blanco significativos

Haskell usa espacios en blanco e indentación para delimitar el código.
***El código que forma parte de alguna expresión debe estar indentado más adentro que el inicio de esa expresión.***

- Las definiciones de módulos, importaciones y funciones de nivel superior deben empezar en la columna más a la izquierda.
- Si una expresión se divide en varias líneas, el código que forma parte de esa expresión debe estar indentado bajo esa expresión con al menos un espacio.
- Las partes de la expresión que están agrupadas deben estar indentadas con la misma cantidad de espacios.

```haskell
-- A function split over multiple lines, so subsequent lines must be indented
add number1 number2 =
    number1 + number2
```

https://en.wikibooks.org/wiki/Haskell/Indentation

## Módulos

Los módulos exportan funciones.
Eso significa que puedes usar las funciones que el módulo pone a disposición en su declaración de exportación.
Un módulo también puede definir funciones solo para uso interno.
Por defecto, las funciones que no se exportan explícitamente no se pueden usar desde fuera del módulo.

Al inicio de un módulo, especificamos el nombre del módulo.
Si tenemos un archivo llamado Calculator.hs, entonces debemos nombrar nuestro módulo Calculator.
Luego especificamos las funciones que exporta y, después de eso, podemos empezar a escribir las funciones.
Así que empezaremos con esto.

```haskell
module Calculator ( add ) where
```

https://learnyouahaskell.github.io/modules#making-our-own-modules

## Comentarios

Un comentario es un texto dentro del archivo de Haskell que no se interpreta como código.
Está pensado principalmente para que lo lean tú y otros programadores.
Hay una sintaxis ligera para los comentarios de una sola línea, basada en guiones dobles.
También es posible escribir comentarios de varias líneas con el par de delimitadores de apertura y cierre `{-` y `-}`.

```haskell
-- a single line comment
-- another single line comment

{- a multiline comment
   spanning multiple lines
-}
```
