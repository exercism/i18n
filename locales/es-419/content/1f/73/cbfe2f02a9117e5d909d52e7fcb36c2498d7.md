# Acerca de

`while` y `until` (en [`kernel`][kernel]) son combinadores de bucle basados en quotations para el caso en el que no conoces la cantidad de iteraciones de antemano:

```
while ( pred: ( -- ? ) body: ( -- ) -- )
until ( pred: ( -- ? ) body: ( -- ) -- )
```

`while` sigue iterando mientras `pred` deje un valor verdadero; `until` sigue iterando mientras `pred` deje `f`. Ambos se detienen y devuelven cuando su predicado se invierte.

```factor
USING: kernel math ;

! Halve down to 1
16 [ dup 1 > ] [ 2 / ] while .   ! => 1

! Double up to 100
1 [ dup 100 >= ] [ 2 * ] until .   ! => 128
```

Cuando un solo valor que fluye por la pila no es suficiente estado (por ejemplo, una lista restante, un total acumulado y un contador al mismo tiempo), el patrón más limpio es usar *locals* con nombre para mayor claridad. Los *locals* se presentan con más detalle más adelante en el plan de estudios; aquí basta con saber que `:: word ( a b -- c )` declara los valores que recibe como *locals* con nombre, y que `:> name!` agrega un *local* mutable que el cuerpo puede actualizar con `value name!`.

```factor
USING: kernel locals math sequences ;

! Sum a sequence by hand
:: sum-by-hand ( seq -- total )
    seq :> rest!
    0 :> running!
    [ rest length 0 > ] [
        rest unclip [ rest! ] dip
        running + running!
    ] while
    running ;
```

[kernel]: https://docs.factorcode.org/content/vocab-kernel.html
