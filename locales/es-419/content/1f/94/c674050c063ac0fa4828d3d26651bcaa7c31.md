# Instrucciones

Llamar a las APIs es una parte importante de escribir código en internet. En este ejercicio, necesitarás obtener datos de un endpoint y asegurarte de que se hayan recuperado correctamente.

## Objetivos

- Modifica el código proporcionado.
- Invoca el cliente HTTP e intenta obtener una cita. Ese resultado debe ser un tipo unión que consiste en `string` y `error`.
- Si recibes la cita, imprímela en la consola (usando `io:println()`).
- Si ocurrió un `error`, imprime el mensaje de error en la consola.
