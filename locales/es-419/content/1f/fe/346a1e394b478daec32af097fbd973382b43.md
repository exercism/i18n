# Pistas

## General

- Explora las [funciones disponibles en el _módulo string_][string-module-functions] para descubrir qué operaciones con strings ofrece la biblioteca estándar de Gleam.

## 1. Obtén la primera letra del nombre

- Hay una [función][string-first] para obtener el primer carácter de un string.
- Hay varias [funciones][string-trim] para eliminar los espacios en blanco al inicio, al final, o tanto al inicio como al final de un string.

## 2. Formatea la primera letra como una inicial

- Hay una [función][string-upcase] para convertir todos los caracteres de un string a su variante en mayúsculas.
- El operador `<>` se puede usar para concatenar strings.

## 3. Divide el nombre completo en el nombre y el apellido

- Hay una [función][string-split] que divide un string por los caracteres de espacio en blanco.
- Los primeros elementos de un array se pueden asignar a variables mediante la coincidencia de patrones sobre el array.

## 4. Coloca las iniciales dentro del corazón

- El operador `<>` se puede usar para concatenar strings.
