# Null

Null es un tipo de valor primitivo con un solo valor: `null`.
A menudo se usa para representar la nada.
Se considera «falsey», pero es distinto de `false` y de otros valores falsey.

```php
<?php

is_null(null); // => true
isset(null); // => false

null == true; // => false
null === true; // => false

null == false; // => true
null === false; // => false
```

## Cómo trabajar con valores null

En PHP, los valores null pueden ser una causa común de errores, ya que a menudo se devuelven en lugar de un estado de error o para representar la nada.
Para evitar que aparezcan errores, muchas veces hay que «verificar el null»: asegurarte de que el valor no sea null antes de operar con él.

Verificar el null una y otra vez puede ser propenso a errores, así que PHP ofrece dos operadores para trabajar con valores null: el operador de acceso seguro a null `?->` y el operador de fusión de null `??`.
