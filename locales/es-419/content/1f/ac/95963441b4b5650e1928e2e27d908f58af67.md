# formato con porcentaje o «estilo antiguo»

Esta solución usa `%%-formatting` o el [formato al estilo antiguo][old-style formatting] para strings.

Aunque `%%-formatting` es un enfoque totalmente válido, puede crear problemas de representación o de legibilidad.
Usar el método [str.format()][str.format()] o los [f-strings][f-strings] (_también conocidos como «formatted string literals» o «interpolated strings»_) puede ofrecer opciones que mejoran la legibilidad y hacen más clara la sustitución de variables dentro de los strings.

La entrada de blog [String Formatting in Python][string formatting in python] es un buen punto de partida para entender todas las opciones de formato de strings de Python, y [Newer Python String Format Techniques][newer python string format techniques] también ofrece buenos consejos y trucos para usar `str.format()` y `f-strings`.
