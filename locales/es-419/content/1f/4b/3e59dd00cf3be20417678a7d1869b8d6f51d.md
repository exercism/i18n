# Introducción

## Átomos

El tipo `atom` de Elixir representa una constante fija. El valor de un átomo es simplemente su propio nombre. Esto nos da una forma segura en cuanto a tipos de interactuar con los datos. Los átomos se pueden definir de la siguiente manera:

```elixir
# All atoms are preceded with a ':' then follow with alphanumeric snake-cased characters
variable = :an_atom
```

Los _átomos_ se representan internamente mediante un número entero en una tabla de búsqueda, que se establece automáticamente. No es posible cambiar este valor interno.

## Cond

A menudo queremos escribir código que pueda ramificarse según una condición. Aunque hay muchas formas de hacer esto en Elixir, una de las más sencillas es usar `cond/1`.

En su forma más simple, `cond` sigue el primer camino que se evalúa como `true`, con una o más ramas:

```elixir
cond do
  x > 10 -> :this_might_be_the_way
  y < 7 -> :or_that_might_be_the_way
  true -> :this_is_the_default_way
end
```

Si ningún camino se evalúa como `true`, el entorno de ejecución lanza un error.
