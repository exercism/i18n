# Introducción

En SQL, una sentencia `SELECT` te permite recuperar datos de una base de datos.
El resultado de una sentencia `SELECT` es un conjunto de resultados.
Un conjunto de resultados contiene valores organizados en filas y columnas.
Cada columna es un atributo particular de los datos.
Cada fila contiene un valor para cada columna.

Una forma de pensarlo es que un conjunto de columnas representa una estructura de datos, donde cada columna representa un campo de esa estructura y cada fila representa una instancia de la estructura.

Con una sentencia `SELECT` puedes especificar los datos que quieres recuperar.
Además, de forma opcional, puedes transformar, filtrar o modificar la forma de los datos de salida.

## Lo básico

La anatomía de una sentencia `SELECT` básica es la siguiente:

```sql
SELECT <columns>
FROM <source>
WHERE <criteria>;
```

~~~~exercism/note
Las cláusulas `FROM` y `WHERE` son opcionales.
Por ejemplo, una sentencia como `SELECT "Hello, world.";` es perfectamente válida.

Fíjate también en que los saltos de línea no son obligatorios; cualquier espaciado sirve para separar las distintas cláusulas (es decir, las partes) de la sentencia `SELECT`.
~~~~

Justo después de la palabra clave `SELECT` va una lista de las columnas que quieres en el resultado.
La cláusula `FROM` identifica el origen de los datos, que normalmente es una tabla de la base de datos.
La cláusula `WHERE` filtra los datos de salida según uno o más criterios.

## Filtrar datos con la cláusula WHERE

La cláusula `WHERE` te permite filtrar los datos que recupera una sentencia `SELECT`.
Por ejemplo, si solo queremos los de la categoría Appliances, podemos hacer lo siguiente:

```sql
SELECT * FROM inventory
WHERE category = "Appliances";
```

Resultado:
```
upc           category    supplier        brand      product_name                 weight  stock
------------  ----------  --------------  ---------  ---------------------------  ------  -----
899001234556  Appliances  Culinary Depot  QuickBrew  Single-Serve Coffee Maker    4.2     18   
880012349876  Appliances  Culinary Depot  HeatWave   Compact Toaster Oven         7.5     14   
844110220987  Appliances  Culinary Depot  BlendPro   High-Speed Personal Blender  3.1     16   
```

O tal vez solo queremos los datos cuyo peso esté entre 2.0 y 6.0:

```sql
SELECT * FROM inventory
WHERE weight BETWEEN 2.0 AND 6.0;
```

Resultado:
```
upc           category    supplier        brand      product_name                  weight  stock
------------  ----------  --------------  ---------  ----------------------------  ------  -----
899001234556  Appliances  Culinary Depot  QuickBrew  Single-Serve Coffee Maker     4.2     18   
823450987112  Cookware    KitchenCo       FreshKeep  12-Piece Glass Container Set  6       33   
899998877665  Cookware    KitchenCo       IronCraft  Cast-Iron Grill Pan           5.3     21   
844110220987  Appliances  Culinary Depot  BlendPro   High-Speed Personal Blender   3.1     16   
```

Además de `=` y `BETWEEN...AND`, la cláusula `WHERE` admite una amplia variedad de expresiones, como las comparaciones (`<`, `<=`, `>`, `>=`), la coincidencia de patrones (`LIKE`, `GLOB`, `REGEXP`, `MATCH`) y la comprobación de pertenencia a una lista (`IN`, `NOT IN`).
Consulta [Expresiones del lenguaje SQL](sql-expr) para ver la documentación completa.
