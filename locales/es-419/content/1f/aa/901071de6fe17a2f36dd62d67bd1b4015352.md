Los jugadores recorrerán el mapa y recogerán tesoros a medida que avanzan.
Las ubicaciones de los tesoros y de los lugares tienen formatos distintos, para añadir un desafío adicional.
También hay algunos lugares especiales, donde ciertos tesoros se pueden intercambiar por otros, para darle un giro adicional al juego.
Tu tarea es escribir funciones que les ayuden con su juego.

## 1. Convertir ubicaciones

Implementa la función `placeLocationToTreasureLocation`, que recibe una ubicación de lugar (como `('C', 1)`) y la convierte en una ubicación de tesoro (como `(1, 'C')`).

```elm
placeLocationToTreasureLocation ('C', 1)
--> (1,'C')
```

## 2. Comparar ubicaciones de tesoros y de lugares

Implementa la función `treasureLocationMatchesPlaceLocation`, que recibe una `PlaceLocation` (como `('C', 1)`) y devuelve true si coincide con una `TreasureLocation` (como `(1, 'C')`).

```elm
treasureLocationMatchesPlaceLocation ('C', 1) (1, 'C')
--> true

treasureLocationMatchesPlaceLocation ('C', 1) (2, 'C')
--> false
```

## 3. Contar ubicaciones de tesoros

Implementa la función `countPlaceTreasures`, que recibe un lugar (como `("Aqua Lagoon (Island of Mystery)", ('F', 1))`) y la lista de tesoros, y devuelve la cantidad de tesoros que se pueden encontrar allí.

```elm
place = ("Aqua Lagoon (Island of Mystery)", ('F', 1))

countPlaceTreasures place treasures =
--> 2
```

## 4. Lugares especiales

Implementa la función `specialCaseSwapPossible`, que recibe un tesoro (como `("Amethyst Octopus", (1, 'F'))`) y un lugar (como `("Seaside Cottages ", ('C', 1))`), y devuelve true para las siguientes combinaciones:

- El Brass Spyglass se puede intercambiar por cualquier otro tesoro en el Abandoned Lighthouse
- El Amethyst Octopus se puede intercambiar por el Crystal Crab o el Glass Starfish en el Stormy Breakwater
- El Vintage Pirate Hat se puede intercambiar por el Model Ship in Large Bottle o el Antique Glass Fishnet Float en el Harbor Managers Office

Intenta implementar esta función como una sentencia case con una tupla ad hoc, en lugar de usar condicionales if (este es un modismo común en Elm).
