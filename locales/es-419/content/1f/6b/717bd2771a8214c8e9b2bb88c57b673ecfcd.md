# Instrucciones

La biblioteca de Luton es una biblioteca grande con una gran colección de literatura, que va desde libros hasta arte.
La biblioteca tiene una sección donde se estudia literatura y se agregan libros al sistema informático.

Ciertas partes buscan automatizarse y te piden que les ayudes.
Esto incluye desde automatizar los formularios del proceso de inscripción hasta ayudar a descifrar textos.

## 1. Obtén la primera letra del título

Se supone que los libros de una biblioteca deben ser fáciles de encontrar, así que se ordenan por la primera letra del título.

Implementa el método `Library.first_letter`, que recibe un argumento `title`, el cual contiene el título del libro.
El método debe devolver la primera letra del título.

```Crystal
Library.first_letter("Mystery of the Crystal Skull")
# => 'M'
```

## 2. Obtén las iniciales del autor

La biblioteca tiene muchos libros escritos por autores diferentes.
A los autores se les suele mencionar por sus iniciales, así que la biblioteca pidió un sistema que genere las iniciales del autor al ingresar el nombre y el apellido del autor.
Las iniciales deben tener el siguiente formato: `{first_letter_of_first_name}.{first_letter_of_last_name}`

Implementa el método `Library.initials`, que recibe dos argumentos, `first_name` y `last_name`, los cuales contienen el nombre y el apellido del autor.
El método debe devolver las iniciales del autor.

```Crystal
Library.initials("William", "Shakespeare")
# => "W.S"
```

## 3. Descifra una letra

Parte de la literatura está cifrada y la biblioteca tiene muchos textos cifrados.
A la biblioteca le gustaría tener un nuevo sistema de descifrado para un cifrado especial.

El cifrado funciona tomando la letra y reemplazándola por la letra que la precede en el alfabeto.
Por ejemplo, `a` se convierte en `z`, `b` se convierte en `a`, `c` se convierte en `b`, y así sucesivamente.

A la biblioteca le gustaría que pueda descifrar tanto letras mayúsculas como minúsculas y que conserve el mismo uso de mayúsculas y minúsculas que la letra original.

Implementa el método `Library.decrypt_character`, que recibe un argumento `character`, el cual contiene la letra que se va a descifrar.
El método debe devolver la letra descifrada.

```Crystal
Library.decrypt_character('a')
# => 'z'
```

## 4. Descifra un texto

A la biblioteca también le gustaría poder descifrar un texto completo con este cifrado, que reemplaza cada letra por la que la precede en el alfabeto.

El descifrador solo debe descifrar letras y dejar todos los demás caracteres tal como están.

Implementa el método `Library.decrypt_text`, que recibe un argumento `text`, el cual contiene el texto que se va a descifrar.
El método debe devolver el texto descifrado.

```Crystal
Library.decrypt_text("Ifmmp Xpsme!")
# => "Hello World!"
```
