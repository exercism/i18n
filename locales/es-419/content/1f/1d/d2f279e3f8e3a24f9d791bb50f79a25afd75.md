# Acerca de

PHP es un lenguaje del lado del servidor orientado al desarrollo web. Su acrónimo es recursivo: significa _PHP: Hypertext Preprocessor_.

Mucho más versátil que los scripts CGI, PHP se usa a menudo para agregar interactividad a HTML plano y reforzar frameworks web.

El lenguaje se puede usar en cualquier sistema operativo. PHP es compatible con la mayoría de los servidores web comunes y a menudo se maneja a través de un módulo intérprete. Esto combina el código web estático con inclusiones dinámicas.

PHP no es solo un framework de servidor web. También es útil para crear scripts de línea de comandos (análisis sin interfaz gráfica) y para desarrollar interfaces gráficas de usuario.

Deberías aprender PHP porque:

- es un lenguaje de código abierto
- está bien documentado y tiene buen soporte
- es compatible con la mayoría de los servidores web comunes
- es fácil de empezar y aprender
- es muy escalable y extensible
