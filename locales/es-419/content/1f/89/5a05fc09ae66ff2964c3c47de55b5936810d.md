# Recursos

## Cómo crear tu primer módulo de Coffee

Para crear un módulo que se pueda cargar con `Bob = require './bob'`, pon este código en `bob.coffee`:

```coffeescript
class Bob

module.exports = Bob
```

Puedes encontrar más información sobre módulos en la [documentación de Node](http://nodejs.org/api/modules.html#modules_module_exports).

## Visual Studio en Windows

Si tienes una versión paga de Visual Studio, puedes descargar una solución de Visual Studio que ya está configurada para funcionar con CoffeeScript y los demás lenguajes que Visual Studio admite.

![Solution Explorer](https://raw.githubusercontent.com/exercism/coffeescript/main/docs/img/SolutionExplorer.png)

1. Descarga la [Exercism.io Visual Studio Template](https://github.com/rprouse/Exercism.VisualStudio) desde GitHub haciendo clic en el botón Download Zip de la página.
2. Descomprime la plantilla en tu directorio de ejercicios, por ejemplo `C:\src\exercises`
2. Instala la [Exercism CLI](http://exercism.io/cli)
3. Abre un símbolo del sistema en tu directorio de ejercicios
4. Agrega tu clave de API a exercism `exercism configure --key=YOUR_API_KEY`
5. Configura tu directorio de origen en exercism `exercism configure --dir=C:\src\exercises`
6. [Obtén tu primer ejercicio](http://exercism.io/languages/coffeescript) `exercism fetch coffeescript`
7. Abre la solución de Exercism en Visual Studio
8. Expande el proyecto Exercism.coffeescript
9. Haz clic en **Show All Files** en Solution Explorer (ver más abajo)
10. El ejercicio que acabas de obtener aparecerá atenuado. Haz clic derecho en la carpeta y selecciona **Include In Project**
11. A programar...

![Agregar archivos](https://raw.githubusercontent.com/exercism/coffeescript/main/docs/img/AddFiles.png)

Para trabajar con CoffeeScript en Visual Studio, te recomendamos instalar la extensión [Web Essentials](http://vswebessentials.com/). También hará mucho más fácil trabajar con Javascript.

Puedes ejecutar las pruebas unitarias desde una línea de comandos de node.js usando el archivo por lotes del proyecto.

```bash
C:\Src\exercises\coffeescript> test example\bob_test.spec.coffee
.................

Finished in 0.02 seconds
17 tests, 17 assertions, 0 failures, 0 skipped
```

Si no ves ningún resultado al ejecutar las pruebas, es probable que no estés en un símbolo del sistema de Node.js.
