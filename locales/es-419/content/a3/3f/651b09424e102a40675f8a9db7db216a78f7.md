# Instrucciones

En este ejercicio, implementarás reglas para calcular el salario total de un empleado en un mes.
La International Siderurgy Company (ISC) necesita ayuda para calcular los salarios de sus empleados, teniendo en cuenta diversos factores que pueden afectar el salario final.

Tienes tres tareas y, para implementarlas, debes usar el operador ternario en lugar de sentencias if/else.

## 1. Determina el multiplicador del salario

Implementa el método `salaryMultiplier`, que devuelve el multiplicador del salario según la cantidad de días que un empleado faltó al trabajo.
Aplica una penalización del 15% si el empleado faltó al menos cinco días.

```java
int daysSkipped = 3;
salaryMultiplier(daysSkipped);
// => 1.0

daysSkipped = 7;
salaryMultiplier(daysSkipped);
// => 0.85
```

## 2. Calcula el bono por los productos vendidos

Implementa los métodos `bonusMultiplier` y `bonusForProductsSold`.
La ISC paga diez unidades monetarias por cada producto vendido y, si un empleado vende veinte productos o más, el multiplicador sube a trece.
`bonusMultiplier` debe determinar qué multiplicador aplicar, y `bonusForProductSold` debe devolver el bono total en unidades monetarias.

```java
int productsSold = 21;
bonusMultiplier(productsSold);
// => 13
bonusForProductsSold(productsSold);
// => 273

productsSold = 5;
bonusMultiplier(productsSold);
// => 10
bonusForProductsSold(productsSold);
// => 50
```

## 3. Calcula el salario final del empleado

Implementa el método `finalSalary`.
Debe multiplicar el salario base de `1000.00` por el multiplicador del salario, sumar el bono y devolver el resultado.
Sin embargo, los salarios deben estar limitados a `2000.00`.

```java
int daysSkipped = 2;
int productsSold = 3;
finalSalary(daysSkipped, productsSold);
// => 1030.00

productsSold = 90;
finalSalary(daysSkipped, productsSold);
// => 2000.00
```
