# Acerca de

En Swift, los closures y las funciones pueden acceder a constantes y variables de su ámbito circundante.
También pueden conservar el acceso a esos valores incluso después de que el ámbito circundante haya terminado de ejecutarse.
Este comportamiento se llama [_capturar valores_][capturing-values].

```swift
func makeAdder(base: Int) -> (Int) -> Int {
    func adder(_ i: Int) -> Int {
        base + i
    }
    return adder
}
// makeAdder: (Int) -> (Int) -> Int

let add10 = makeAdder(base: 10)
// add10: (Int) -> Int

let subtract20 = makeAdder(base: -20)
// subtract20: (Int) -> Int

add10(5)
// => 15

subtract20(5)
// => -15

func makeLogger(logLevel: String) -> (String) -> Void {
    let logHeader = "[\(logLevel)]: "
    return { msg in print(logHeader, msg) }
}
// makeLogger: (String) -> (String) -> Void

let infoLogger = makeLogger(logLevel: "info")
// infoLogger: (String) -> Void

infoLogger("This is a log message")
// prints "[info]: This is a log message"
```

En los ejemplos anteriores, tanto `makeAdder(base:)` como `makeLogger(logLevel:)` devuelven funciones o closures que capturan valores de su ámbito circundante.
Las funciones devueltas siguen haciendo referencia a `base` y `logHeader` incluso después de que `makeAdder(base:)` y `makeLogger(logLevel:)` hayan devuelto.

[capturing-values]: https://docs.swift.org/swift-book/LanguageGuide/Closures.html#ID103
