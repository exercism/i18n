# Instrucciones

En este ejercicio, implementarás las mecánicas de un juego de rol.
El personaje de un jugador se representa con el siguiente tipo:

```fsharp
type Player = {
    Name: string option
    Level: int
    Health: int
    Mana: int option
}
```

Los jugadores de este juego deben alcanzar el nivel 10 antes de desbloquear una reserva de maná, para que puedan empezar a lanzar hechizos.
Trabajarás en dos funcionalidades de este juego: la mecánica de revivir y la mecánica de lanzamiento de hechizos.

## 1. Preséntate

Escribe el contenido de la función `introduce`.
Fíjate que el campo `Name` del registro `Player` es un `Option`.
Los jugadores sigilosos podrían querer ocultar su nombre dejándolo en `None`: esos jugadores se presentarán como `"Mighty Magician"`.
De lo contrario, solo usa tu nombre para presentarte.

```fsharp
introduce { Name = None; Level = 2; Health = 8; Mana = None }
    --> "Mighty Magician"

introduce { Name = Some "Merlin"; Level = 2; Health = 8; Mana = None }
    --> "Merlin"
```

## 2. Implementa la mecánica de revivir

La función `revive` debe verificar que el personaje del jugador esté realmente muerto (su salud llegó a 0).
Si lo está, debe devolver una nueva instancia de `Player` con 100 de salud.
De lo contrario, si el personaje del jugador no está muerto, la función `revive` devuelve `None`.

Si el nivel del jugador es 10 o más, también debe revivir con 100 de maná.
Si el nivel del jugador es menor que 10, su maná debe ser `None`.
La función `revive` debe conservar el nivel del jugador.

```fsharp
let deadPlayer = { Name = None; Level = 2; Health = 0; Mana = None }

revive deadPlayer
    --> Some { Name = None; Level = 2; Health = 100; Mana = None }
```

Si se llama al método `revive` con un jugador cuya salud es 1 o más, la función debe devolver `None`.

```fsharp
let alivePlayer = { Name = None; Level = 2; Health = 42; Mana = None }

revive alivePlayer
    --> None
```

## 3. Implementa la mecánica de lanzamiento de hechizos

La función `castSpell` recibe como argumentos un `int` que indica cuánto maná cuesta el hechizo, además de un `Player`.
Devuelve el jugador actualizado, además de la cantidad de daño que inflige el hechizo lanzado.
Un lanzamiento exitoso de un hechizo hace un daño igual a dos veces el costo de maná del hechizo.
Sin embargo, si el jugador no tiene suficiente maná, no pasa nada: el jugador queda igual y no se hace ningún daño.
Si el jugador ni siquiera tiene una reserva de maná, intentar lanzar el hechizo debe reducir su salud en el costo de maná del hechizo y no hace ningún daño.

```fsharp
let wizard = { Name = None; Level = 18; Health = 123; Mana = Some 30 }

let updatedWizard, damage = castSpell 14 wizard

updatedWizard.Mana --> Some 16
damage             --> 28
```
