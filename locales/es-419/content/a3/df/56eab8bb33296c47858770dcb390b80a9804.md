# Acerca de

Los [strings][getting-started-strings] en Elixir se delimitan con comillas dobles y están codificados en UTF-8:

```elixir
"Hi!"
```

Los strings se pueden concatenar con el operador [`<>/2`][kernel-concat]:

```elixir
"Welcome to" <> " " <> "New York"
# => "Welcome to New York"
```

Los strings en Elixir admiten [interpolación][string-interpolation] con la sintaxis `#{}`:

```elixir
"6 * 7 = #{6 * 7}"
# => "6 * 7 = 42"
```

Cualquier expresión de Elixir es válida dentro de la interpolación. Si se le da un string, el string se interpola tal cual. Si se le da cualquier otro valor, Elixir intentará convertirlo en un string.

```elixir
"Elixir can convert booleans to strings: #{true}"
# => "Elixir can convert booleans to strings: true"

"And #{["lists", ", ", "too!"]}"
# => "And lists, too!"

"But not functions: #{fn x -> x end}"

# => ** (Protocol.UndefinedError) protocol String.Chars not implemented for #Function<7.126501267/1 in :erl_eval.expr/5> of type Function
#        (elixir 1.10.1) lib/string/chars.ex:3: String.Chars.impl_for!/1
#        (elixir 1.10.1) lib/string/chars.ex:22: String.Chars.to_string/1
```

Elixir ofrece muchas funciones para trabajar con strings en el módulo `String`. Si no tienes claro cómo procesar un string como lo necesitas, asegúrate de revisar [las funciones disponibles en el módulo `String`][string-module-functions] y muy probablemente encontrarás lo que buscas.

```elixir
String.downcase("PLEASE NO SHOUTING")
# => "please no shouting"

String.split("hello", "", trim: true)
# => ["h", "e", "l", "l", "o"]

String.replace("Do I enjoy Elixir? Maybe...", "Maybe...", "Definitely!")
# => "Do I enjoy Elixir? Definitely!"

String.at("12345", 2)
# => "3"
```

Al usar algunas de esas funciones, recuerda que el primer carácter de un string tiene el índice `0`.

Algunos caracteres necesitan [escaparse][escape-characters] para poder incluirlos en un string, por ejemplo los saltos de línea, las comillas dobles o el carácter `#`:

```elixir
"\"A\" is the \#1st letter of the alphabet.\n"
```

Para trabajar cómodamente con textos que tienen muchos saltos de línea, usa la [sintaxis heredoc de comillas dobles triples][heredoc-syntax]:

```elixir
"""
1
2
3
"""
```

Muy a menudo encontrarás esta sintaxis usada para documentar código:

```elixir
defmodule MyApp.Hello do
  @moduledoc """
  This is the Hello module.
  """

  @doc """
  Says hello to the given `name`.

  Returns `:ok`.

  ## Examples

      iex> MyApp.Hello.world(:john)
      :ok

  """
  def world(name) do
    IO.puts("hello #{name}")
  end
end
```
