# Introducción

## Cadenas

Las cadenas en Elixir se delimitan con comillas dobles y están codificadas en UTF-8:

```elixir
"Hi!"
```

Los strings se pueden concatenar usando el operador `<>/2`:

```elixir
"Welcome to" <> " " <> "New York"
# => "Welcome to New York"
```

Los strings en Elixir soportan interpolación usando la sintaxis `#{}`:

```elixir
"6 * 7 = #{6 * 7}"
# => "6 * 7 = 42"
```

Para poner un carácter de salto de línea en un string, usa el código de escape `\n`:

```elixir
"1\n2\n3\n"
```

Para trabajar cómodamente con textos con muchos saltos de línea, usa la sintaxis heredoc de triple comilla doble en su lugar:

```elixir
"""
1
2
3
"""
```

Elixir proporciona muchas funciones para trabajar con strings en el módulo `String`.

## Operador de tubería

El operador `|>` se llama operador de tubería. Se puede usar para encadenar llamadas a funciones de tal manera que el valor devuelto por la llamada a la función anterior se pasa como primer argumento a la siguiente llamada a función.

```elixir
"hello"
|> String.upcase()
|> Kernel.<>("?!")

# => "HELLO?!"
```
