# Introducción

Un bucle `for` permite iterar sobre un array y repetir el código para cada elemento:

```haxe
var fruitList = ["apple", "banana", "pear"];

for (fruit in fruitList) {
  trace(fruit);
}

// apple
// banana
// pear
```

En el ejemplo anterior, `fruit` es la variable que guarda el valor de un elemento individual del array `fruitList`. El compilador verifica que se pueda iterar sobre `fruitList`; de lo contrario, detendrá la ejecución.

Puedes iterar sobre números usando el operador de rango. Este operador toma dos operandos de tipo `Int` y se escribe como `min...max`:

```haxe
for (i in 0...10) {
  trace(i); // from 0 to 9
}
```
