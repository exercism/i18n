# Acerca de

Los diccionarios, al igual que sus equivalentes en otros lenguajes como los mapas o los arrays asociativos, almacenan pares clave/valor de manera que un valor se puede recuperar o cambiar directamente pasando la clave a la propiedad de indexador del diccionario.

Además, se pueden agregar y quitar pares clave/valor del diccionario. Se pueden enumerar las claves, los valores y los pares clave/valor.

Los valores pueden ser objetos de cualquier tipo de C#, lo que incluye primitivos, structs _y_ clases.

El objeto Dictionary permite que las claves sean objetos de cualquier tipo. Sin embargo, para garantizar un comportamiento correcto en tiempo de ejecución, las claves deben tener un código hash adecuado, como el que devuelve [GetHashCode][gethashcode].

No se puede acceder de forma segura a una instancia de diccionario desde más de un hilo (no es seguro para hilos). [ConcurrentDictionary][concurrent-dictionary] está disponible para situaciones de multihilo.

Consulta también [HashSet][hashset], [ConcurrentDictionary][concurrent-dictionary], [SortedDictionary][sorted-dictionary].

Aunque no existe una versión no genérica de Dictionary, quedan varias clases en la biblioteca para admitir un mapa no genérico. Conviene que conozcas IDictionary y Hashtable no genéricos, sobre todo para reconocerlos cuando los veas. Es poco probable que tengas que usarlos, salvo para mantener una base de código antigua.

A menudo querrás exponer y acceder al diccionario mediante su interfaz [`IDictionary<TKey, TValue>`][idictionary].

Ten en cuenta que, debido a la naturaleza de las [propiedades de indexador][indexer-properties], los valores primitivos se pueden modificar en el mismo lugar, por ejemplo:

```csharp
nums["some-number"] = 3;
nums["some-number"]++;
// nums["some-number"] == 4

```
