# Funciones

En JavaScript, las funciones son _objetos de primera clase_, lo que significa que se pueden asignar a variables y propiedades, pasar a otras funciones y devolver desde funciones. Pueden tener propiedades y métodos, igual que cualquier otro _objeto_.

## Entrada: pasar argumentos

Las funciones de JavaScript te permiten pasar argumentos cuando se llaman. Los argumentos siempre se [pasan por valor](https://dev.to/xpbytes/javascript-ruby-and-c-are-not-call-by-reference-23f7). En otras palabras, si una función reasigna un parámetro dentro de la función, el valor no cambiará fuera de la función. Eso no significa que los objetos que se pasan no puedan modificarse.

> [!TIP]
> Cuando se pasa un objeto, lo que se pasa por valor es la referencia a ese objeto. Esto hace que _parezca_ que los objetos que se pasan se manejan de forma distinta, pero no es así.

Un ejemplo de una función que toma dos argumentos y los multiplica es:

```javascript
function multiply(a, b) {
  return a * b;
}

multiply(2, 3);
// => 6
```

## Salida: valor de retorno

JavaScript puede devolver un solo valor desde una función usando la palabra clave `return`, seguida de una expresión. Cuando no se devuelve nada desde una función, el valor devuelto es `undefined`.

Un ejemplo de una función que devuelve un valor es:

```javascript
function multiply(a, b) {
  return a * b;
}

multiply(2, 3);
// => 6
```

## Definir funciones

Hay cuatro tipos de funciones en JavaScript:

1. Funciones normales, que pueden devolver cualquier cosa y siempre se ejecutan hasta el final;
2. Funciones async, que siempre devuelven una `Promise` y se pueden pausar y reanudar con el operador `await`;
3. Funciones generadoras, que siempre devuelven un objeto `Generator` y se pueden pausar y reanudar con el operador `yield`;
4. Funciones generadoras async, que siempre devuelven un objeto `AsyncGenerator` y se pueden pausar y reanudar con _ambos_ operadores, `yield` y `await`.

Para cada uno de estos cuatro tipos, hay tres formas de definirlos:

1. usando una declaración
2. usando una expresión
3. usando el constructor

Por último, hay una sintaxis especial para definir _funciones flecha y métodos_.
