# Introducción

El código de Elixir se ejecuta en la máquina virtual BEAM. BEAM es parte del sistema de ejecución de Erlang. Al estar inspirado en Erlang y compartir su entorno de ejecución, Elixir ofrece una gran interoperabilidad con las bibliotecas de Erlang. Esto significa que los desarrolladores de Elixir pueden usar bibliotecas de Erlang desde dentro de su código de Elixir. De hecho, en la comunidad de Elixir se desaconseja escribir bibliotecas de Elixir para funcionalidad que ya proporcionan las bibliotecas de Erlang.

Como resultado, cierta funcionalidad, como las operaciones matemáticas o las funciones de temporizador, solo está disponible en Elixir a través de Erlang.

La biblioteca estándar de Erlang está disponible para usarla en nuestro código de Elixir sin necesidad de pasos adicionales.

Las funciones de Erlang se pueden llamar de la misma manera en que llamamos a las funciones de Elixir, con una pequeña diferencia. Los nombres de los módulos de Erlang son átomos en `snake_case`. Por ejemplo, para llamar a la función `pi/0` de Erlang del módulo `math`, se escribiría:

```elixir
:math.pi()
# => 3.141592653589793
```

Las funciones de Erlang más usadas que no tienen un equivalente en Elixir son:

- `:timer.sleep/1`, que suspende un proceso durante la cantidad de milisegundos indicada.
- `:rand.uniform/0`, que genera un número de punto flotante aleatorio `x`, donde `0.0 <= x < 1.0`.
- `:io_lib.format/2`, que proporciona formato de string al estilo de C (usando secuencias de control). Con esta función, podrías, por ejemplo, imprimir un entero en cualquier base entre 2 y 36 o dar formato a un número de punto flotante con la precisión deseada. Ten en cuenta que esta función, como muchas funciones de Erlang, devuelve una charlist.
- El módulo `math`, que proporciona funciones matemáticas como `sin/1`, `cos/1`, `log2/1`, `log10/1`, `pow/2`, y más.

Para descubrir la biblioteca estándar de Erlang, explora el [STDLIB Reference Manual][erl-stdlib-ref].

[erl-stdlib-ref]: https://www.erlang.org/doc/apps/stdlib/index.html
