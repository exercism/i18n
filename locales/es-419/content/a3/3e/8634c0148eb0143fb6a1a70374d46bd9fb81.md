# Binario, octal y hexadecimal

El binario, el octal y el hexadecimal (_también conocido como hex_) son distintos [sistemas de numeración][numeral-systems] con bases diferentes.
El binario es base 2, el octal es base 8 y el hexadecimal es base 16.
Los enteros normales son base 10 en Crystal.
El binario, el octal y el hexadecimal son representaciones de números enteros.
Esto significa que representan números positivos y negativos (_incluido el cero_) sin fracciones ni decimales, y admiten todas las operaciones que podemos hacer con números enteros.

## Binario

El [binario][binary] es un sistema de numeración de base 2 que usa solo los dígitos 0 y 1.
Suele representar los estados 0 («apagado») y 1 («encendido») del flujo eléctrico a través de transistores e interruptores en las computadoras, así como las cargas positiva y negativa en los medios de almacenamiento magnético.
El binario puede representar todos los números enteros que se usan en base 10.

Un fragmento del sistema de base 2 se ve así, aunque continúa infinitamente y no se detiene en 128:

| 128      | 64       | 32       | 16       | 8        | 4        | 2        | 1        |
| -------- | -------- | -------- | -------- | -------- | -------- | -------- | -------- |
| 2 \*\* 7 | 2 \*\* 6 | 2 \*\* 5 | 2 \*\* 4 | 2 \*\* 3 | 2 \*\* 2 | 2 \*\* 1 | 2 \*\* 0 |

Entonces, si queremos representar el número 6, en binario sería: 110

| Valor posicional | 4   | 2   | 1   |
| ---------------- | --- | --- | --- |
| Número binario   | 1   | 1   | 0   |

Y la operación sería: `4 + 2 + 0 = 6`

Otro ejemplo: 19

| Valor posicional | 16  | 8   | 4   | 2   | 1   |
| ---------------- | --- | --- | --- | --- | --- |
| Número binario   | 1   | 0   | 0   | 1   | 1   |

El número binario sería: 10011
Y la operación sería: `16 + 0 + 0 + 2 + 1 = 19`

## Binario en Crystal

En Crystal, podemos representar literales binarios usando el prefijo `0b`.
Si escribimos `0b10011`, Crystal lo interpretará como un número binario y lo convertirá a base 10.

```crystal
0b10011
# => 19

typeof(0b10011)
# => Int32
```

Si escribes un número con el prefijo `0b` que no esté en el sistema binario, se generará un error de compilación.

```crystal
0b10211
# => Error: unexpected token: "211"
```

### Operaciones con números binarios

Como los números binarios son enteros, podemos realizar con ellos todas las operaciones que podemos hacer con enteros.

```crystal
0b10011 + 0b10011
# => 38

0b10011 * 0b10011
# => 361

0b10011 / 3
# => 6.333333333333333
```

### Convertir a y desde la representación binaria

Crystal convertirá automáticamente un literal binario a `Int32`.
Para convertir un `Int32` a una representación binaria, usa el método [`<int>.to_s(base)`][to_s] con el argumento base establecido en 2.
El método devolverá una representación en string del número binario:

```crystal
19.to_s(2)
# => "10011"
```

Para convertir una representación en string de un binario a un entero, podemos usar el método [`<int>.to_i(base)`][to_i], pasando la base (2) como argumento:

```crystal
"10011".to_i(2)
# => 19
```

Dar la base incorrecta (_o una representación binaria no válida_) generará un `ArgumentError`:

```crystal
"011021".to_i(2)
# => Invalid Int32: "011021" (ArgumentError)
```

### Métodos binarios

Hay ciertos métodos que se pueden usar en los enteros para obtener información sobre la representación binaria del número.

[`<int>.bit_length`][bit_length] devolverá la cantidad de bits que se necesitan para representar el número:

```crystal
19.bit_length
# => 5
```

[`<int>.bit(index)`][bit] devolverá el bit en el índice dado, empezando por la derecha (_el bit menos significativo_):

```crystal
19.bit(0)
# => 1

0b10011.bit(1)
# => 1
```

## Octal

El [octal][octal] es un sistema de numeración de base 8.
Usa los dígitos 0, 1, 2, 3, 4, 5, 6 y 7.

En Crystal, podemos representar números octales usando el prefijo `0o`.
Al igual que con el binario, Crystal convierte automáticamente una representación octal a un `Int32`.

```crystal
0o123
# => 83
```

Poner el prefijo `0o` a un número que no esté en el sistema octal generará un error de compilación.

### Convertir a y desde la representación octal

Al igual que con el binario, podemos usar el método [`<int>.to_s(base)`][to_s] para convertir un `Int32` a una representación octal.
Y podemos usar el método [`<int>.to_i(base)`][to_s] para convertir una representación octal a un `Int32`.

```crystal
83.to_s(8)
# => "123"

"123".to_i(8)
# => 83
```

Al igual que con el binario, dar la base incorrecta generará un `ArgumentError`.

## Hexadecimal

El [hexadecimal][hexadecimal] es un sistema de numeración de base 16.
Usa los dígitos 0 - 9 y las letras A, B, C, D, E y F.
A es 10, B es 11, C es 12, D es 13, E es 14 y F es 15.

Podemos representar números hexadecimales en Crystal usando el prefijo `0x`.
Al igual que con el binario y el octal, Crystal convertirá automáticamente los literales hexadecimales a `Int32`.

```crystal
#=> 0x123
291
```
 
Poner el prefijo `0x` a un número que no sea hexadecimal generará un error de compilación.

### Convertir a y desde la representación hexadecimal

Al igual que con el binario, podemos usar el método [`<int>.to_s(base)`][to_i] para convertir un `Int32` a una representación hexadecimal.
Y podemos usar el método [`<int>.to_i(base)`][to_s] para convertir una representación hexadecimal a un `Int32`.

```crystal
291.to_s(16)
# => "123"

"123".to_i(16)
# => 291
```

Al igual que con el binario y el octal, dar la base incorrecta generará un `ArgumentError`.

## Precisión

Al convertir un número a una representación en string, podemos especificar la precisión del número.
Es decir, la cantidad **mínima** de números usados para representar el número.
Si el número tiene menos dígitos que la precisión, se agregarán ceros a la izquierda a la representación en string.
Esto se hace pasando el argumento `precision` al método [`<int>.to_s(<base>, precision: <value>)`][to_s].

```crystal
291.to_s(16, precision: 5)
# => "00123"

543.to_s(precision: 2)
# => "543"
```
