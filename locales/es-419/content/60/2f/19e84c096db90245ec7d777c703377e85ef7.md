# Pistas

## General

- Lee sobre los [errores][errors] en la guía de primeros pasos.
- Lee sobre [`try`][docs-try] en la documentación.

## 1. Advierte al equipo

- Permite que la función de la operación lance su error.
- Para invocar una función que está en una variable, usa el operador `.`.

## 2. Envuelve el error

- Usa try .. rescue para devolver el resultado esperado.

## 3. Pasa el mensaje

- Usa try .. rescue para devolver el resultado esperado.
- El bloque rescue te permite hacer pattern matching con el nombre de módulo del error y también vincular el error a una variable.
