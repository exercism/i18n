# Introducción

## Comparación

En Go, los números se pueden comparar con los siguientes operadores relacionales y de igualdad.

| Comparación       | Operador  |
| ------------------| --------- |
| igual             | `==`      |
| distinto          | `!=`      |
| menor             | `<`       |
| menor o igual     | `<=`      |
| mayor             | `>`       |
| mayor o igual     | `>=`      |

El resultado de la comparación siempre es un valor booleano, es decir, `true` o `false`.

```go
a := 3

a != 4 // true
a > 5  // false
```

Los operadores de comparación anteriores también se pueden usar para comparar strings.
En ese caso se aplica un orden lexicográfico (de diccionario).
Por ejemplo:

```Go
	"apple" < "banana"  // true
	"apple" > "banana"  // false
```

## Condicionales

Los condicionales en Go son similares a los condicionales de otros lenguajes.
El tipo subyacente de cualquier operación condicional es el tipo `bool`, que puede tener el valor `true` o `false`.
Los condicionales se usan a menudo como mecanismos de control de flujo para comprobar distintas condiciones.

Para comprobar un caso en particular se puede usar una sentencia `if`, que ejecuta su código si la condición subyacente es `true`, así:

```go
var value string

if value == "val" {
    return "was val"
}
```

En escenarios con más de un caso, se pueden encadenar varias sentencias `if` usando las sentencias `else if` y `else`.

```go
var number int
result := "This number is "

if number > 0 {
    result += "positive"
} else if number < 0 {
    result += "negative"
} else {
    result += "zero"
}
```

Las sentencias `if` también pueden incluir una sentencia corta de inicialización que se puede usar para inicializar una o más variables para la sentencia `if`.
Por ejemplo:

```go
num := 7
if v := 2 * num; v > 10 {
    fmt.Println(v)
} else {
    fmt.Println(num)
}
// Output: 14
```

> Nota: las variables que se crean en la sentencia de inicialización salen del ámbito al terminar la sentencia `if`.
