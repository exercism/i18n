# Acerca de

Batch scripting es un lenguaje de scripting que se usa principalmente para ejecutar comandos en el Command Prompt de Windows (cmd.exe).
Permite automatizar tareas, gestionar archivos y controlar el entorno del sistema mediante una serie de instrucciones de línea de comandos.

Aunque Batch scripting es sencillo, puede encargarse de una amplia variedad de tareas, desde operaciones básicas con archivos hasta procesos de automatización más complejos.

Los archivos Batch tienen la extensión `.bat` o `.cmd` y se pueden ejecutar directamente con el intérprete de comandos de Windows.

La flexibilidad de Batch scripting lo convierte en una herramienta poderosa para administradores de sistemas, desarrolladores y usuarios avanzados que necesitan automatizar tareas rutinarias o crear herramientas de línea de comandos personalizadas.
