# Pistas

## General

- Las palabras para leer viven en [`io`][io]; los constructores de
  string-streams y `with-string-writer` están en
  [`io.streams.string`][io.streams.string].
- Para la tarea de vaciado del writer, las variables locales (`::` y `:>`)
  mantienen el cuerpo legible cuando necesitas tocar el mismo stream dos veces.

## 1. Escúchalo todo

- Una sola palabra: `stream-contents`.

## 2. Cuenta los mensajes

- `stream-lines` separa el stream en un array de líneas;
  `length` devuelve la cantidad.

## 3. Haz eco de la última llamada

- El mismo `stream-lines` de antes, luego `last`, luego `>upper` (de
  `ascii`).

## 4. Transmite un mensaje

- `stream-write` escribe el mensaje y `stream-flush` lo envía hacia
  afuera. El writer se usa dos veces, así que recurre a las variables locales `::`:
  `:: broadcast ( message writer -- ) message writer stream-write
  writer stream-flush ;`.

## 5. Captura la salida de una quotation

- Una sola palabra: `with-string-writer`. Agrega `inline` después del `;`
  de cierre para que el compilador pueda ver a través del argumento quotation:
  `: capture ( quot -- captured ) with-string-writer ; inline`.
