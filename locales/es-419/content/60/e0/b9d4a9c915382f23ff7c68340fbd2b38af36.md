# Palabras clave estáticas de clase

Una clase es una unidad de organización del código en PHP y, a menudo, representa una instancia de una cosa, un servicio o un procedimiento.
Con las palabras clave `static` y `self`, las propiedades y los métodos pueden existir en referencia a la clase para todas las instancias (o para ninguna).

```php
<?php

class Book
{
    static $genre = 'Adventure';

    static function getGenre()
    {
        return self::$genre;
    }
}

// Usage
$genre = Book::$genre;
$genre = Book::getGenre();
```

## Limitación

Los métodos estáticos de una clase solo pueden llamar a propiedades estáticas o a métodos estáticos de su propia clase.

```php
<?php

class Book
{
    $name = 'Treasure Island';

    static function getName()
    {
        // This static method cannot access the instance variable
        return $this->name;
    }
}
```
