# Pistas

## General

- Lee sobre los protocolos en la [guía oficial de introducción][getting-started-protocols] o en [elixirschool.com][elixir-school-protocols].

## 1. Define la comestibilidad

- Hay una [macro especial][kernel-defprotocol] para definir protocolos.
- Los protocolos consisten en uno o más encabezados de función.
- Un encabezado de función es como una definición de función, pero sin el bloque `do`. Define el nombre de la función y sus argumentos, pero no lo que hace.

## 2. Haz que las hogazas de pan sean comestibles

- Hay una [macro especial][kernel-defimpl] para implementar un protocolo para un tipo de dato dado.
- Implementar un protocolo significa escribir una definición de función para cada encabezado de función del protocolo.

## 3. Haz que las pociones de maná sean comestibles

- Hay una [macro especial][kernel-defimpl] para implementar un protocolo para un tipo de dato dado.
- Implementar un protocolo significa escribir una definición de función para cada encabezado de función del protocolo.

## 4. Haz que los venenos sean comestibles

- Hay una [macro especial][kernel-defimpl] para implementar un protocolo para un tipo de dato dado.
- Implementar un protocolo significa escribir una definición de función para cada encabezado de función del protocolo.
