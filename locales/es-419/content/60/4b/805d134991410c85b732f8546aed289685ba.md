# Acerca de

La enumeración es el acto de recorrer una colección (`Array`, `Hash`, etc.) y realizar alguna acción en cada objeto.

La enumeración es un concepto clave en Ruby y se usa para ordenar (`sort_by`), agrupar (`group_by`), mapear (`map`), reducir (`reduce`) y mucho más.
Con frecuencia verás la enumeración como la forma idiomática de iterar sobre colecciones en lugar de usar bucles.

Una enumeración sencilla para imprimir cada palabra de un array se vería así:

```ruby
words = %w[the cat sat on the mat]
words.each do |word|
  puts word
end

# Output:
# the
# cat
# sat
# on
# the
# mat
```

En este ejemplo, llamamos al método `Array#each` y le pasamos un _bloque_, que recibe un parámetro (`word`) y lo imprime.

También podemos encadenar métodos de enumeración.
Por ejemplo, podemos encadenar `.with_index` a `each` para imprimir tanto el índice de un objeto como su valor:

```ruby
words = %w[the cat sat on the mat]
list = words.map.with_index { |word, index| "#{index}. #{word}" }
puts list

# Output:
# 0. the
# 1. cat
# ...
# 5. mat
```

Enumerar objetos `Hash` es exactamente igual que enumerar objetos `Array`, salvo que el bloque recibe dos argumentos: la clave y el valor:

```ruby
pet_names = {cat: "bob", horse: "caris", mouse: "arya"}
words.each { |animal, name| ... }

# The two arguments should be put in brackets when chaining
words.each.with_index { |(animal, name), index| ... }
```

Los métodos descritos arriba forman parte del [módulo `Enumerable`][enumerable-module], que está incluido en `Array`, `Hash` y otras clases que necesitan la capacidad de enumerar.

[enumerable-module]: https://docs.ruby-lang.org/en/master/Enumerable.html
