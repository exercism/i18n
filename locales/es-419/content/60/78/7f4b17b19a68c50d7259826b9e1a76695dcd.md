# Pistas

## General

- Lee la documentación oficial de [los rangos][range].

## 1. Define el rango de filas

- Existe un [operador especial][range-creation-operator] para crear rangos.

## 2. Define el rango de columnas

- Existe un [operador especial][range-creation-operator] para crear rangos.
- Existe una [sintaxis especial][unicode-code-points] para escribir el punto de código de un carácter sin conocer su valor explícitamente.

## 3. Transforma el rango de filas en una lista de filas

- Los rangos implementan el protocolo `Enumerable`.
- Existe una [función incorporada][enum-to-list] para convertir una estructura de datos enumerable en una lista.

## 4. Transforma el rango de columnas en una lista de columnas

- Los rangos implementan el protocolo `Enumerable`.
- Existe una [función incorporada][enum-map] para convertir una estructura de datos enumerable en una lista mientras modificas sus elementos.
- Puedes usar la [forma especial de bitstring][bitstring-special-form] para convertir un punto de código en un string.
