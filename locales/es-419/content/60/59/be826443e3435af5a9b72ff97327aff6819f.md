# Tests

Si tienes el binario de phix en tu PATH, ingresa el comando:

```bash
p test 
```
Esto ejecutará el archivo de tests (test.exw).

Si el binario de phix no está en el PATH, en Windows ingresa

```cmd
\path\to\p.exe test
```

Linux:

```bash
/path/to/p test
```

## Tests omitidos

Resolver un ejercicio significa hacer que todos sus tests pasen.
De forma predeterminada, se ejecutan todos los tests del archivo test.exw.
Para omitir un test, coloca dos guiones (el marcador de comentario estándar de Phix) al principio de la línea.

Ten en cuenta que los tests no respetan ninguna bandera include=false en tests.toml; más bien, es responsabilidad de quien escribe test.exw mantenerlas manualmente en ese archivo para reflejar la realidad en beneficio del sitio de Exercism (por ejemplo, para recopilar estadísticas del track), pero nada en el track mismo las usa en absoluto, incluyendo específicamente al generador de tests y al test runner.
