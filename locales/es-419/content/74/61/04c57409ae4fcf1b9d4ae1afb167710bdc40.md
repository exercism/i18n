# Introducción

Una función de orden superior es una función que cumple al menos una de estas dos condiciones:

- Recibe una función como argumento
- Devuelve una función

Un argumento que es una función es simplemente un argumento normal, solo que puedes invocarlo.

```fsharp
let double = fun x -> x * 2

let apply f x = f x

apply double 3
// => 6
```
