# Instrucciones

En este ejercicio, necesitas traducir algunas reglas del clásico juego Pac-Man a funciones de C++.

Tienes cuatro reglas que traducir, todas relacionadas con los estados del juego.

> No te preocupes por cómo se obtienen los argumentos; concéntrate en combinar los argumentos para devolver el resultado esperado.

## 1. Define si Pac-Man se come un fantasma

Define la función `can_eat_ghost`, que recibe dos argumentos (_si Pac-Man tiene una píldora de poder activa_ y _si Pac-Man está tocando un fantasma_) y devuelve un valor Boolean si Pac-Man puede comerse un fantasma. La función debe devolver true solo si Pac-Man tiene una píldora de poder activa y está tocando un fantasma.

```cpp
can_eat_ghost(false, true);
// => false
```

## 2. Define si Pac-Man anota

Define la función `scored`, que recibe dos argumentos (_si Pac-Man está tocando una píldora de poder_ y _si Pac-Man está tocando un punto_) y devuelve un valor Boolean si Pac-Man anotó. La función debe devolver true si Pac-Man está tocando una píldora de poder o un punto.

```cpp
scored(true, true);
// => true
```

## 3. Define si Pac-Man pierde

Define la función `lost`, que recibe dos argumentos (_si Pac-Man tiene una píldora de poder activa_ y _si Pac-Man está tocando un fantasma_) y devuelve un valor Boolean si Pac-Man pierde. La función debe devolver true si Pac-Man está tocando un fantasma y no tiene una píldora de poder activa.

```cpp
lost(false, true);
// => true
```

## 4. Define si Pac-Man gana

Define la función `won`, que recibe tres argumentos (_si Pac-Man se comió todos los puntos_, _si Pac-Man tiene una píldora de poder activa_ y _si Pac-Man está tocando un fantasma_) y devuelve un valor Boolean si Pac-Man gana. La función debe devolver true si Pac-Man se comió todos los puntos y no perdió según los argumentos definidos en la parte 3.

```cpp
won(false, true, false);
// => false
```
