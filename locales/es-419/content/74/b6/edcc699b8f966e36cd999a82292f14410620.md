# Instrucciones

Te apasiona observar aves y llevas un registro de cuántas han visitado tu jardín.
Por lo general, usas marcas en un cuaderno para contar las aves, pero para trabajar mejor con tus datos, has digitalizado los conteos de aves de las últimas semanas.

## 1. Determina el total de aves que has contado hasta ahora

Empecemos a analizar los datos con una vista general.
Averigua cuántas aves has contado en total desde que empezaste tus registros.

Implementa una función `TotalBirdCount` que acepte un slice de `int` que contenga el conteo de aves por día.
Debe devolver el total de aves que contaste.

```go
birdsPerDay := []int{2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1}
TotalBirdCount(birdsPerDay)
// => 34
```

## 2. Calcula el número de aves visitantes en una semana específica

Ahora que ya tienes una idea general de tus números de conteo de aves, quieres hacer un análisis más detallado.

Implementa una función `BirdsInWeek` que acepte un slice de conteos de aves por día y un número de semana.

Devuelve el total de aves que contaste en esa semana específica.
Puedes asumir que las semanas siempre se registran completas.

```go
birdsPerDay := []int{2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1}
BirdsInWeek(birdsPerDay, 2)
// => 12
```

## 3. Corrige un error de conteo

Te diste cuenta de que, todo el tiempo que estuviste intentando llevar la cuenta de las aves, había una que se escondía en un rincón lejano del jardín.

Descubriste que esta ave siempre pasaba un día sí y otro no en tu jardín.

No sabes exactamente dónde estaba entre esos días, pero definitivamente no en tu jardín.

Tu intuición de observador de aves también te dice que el ave estaba en tu jardín el primer día que registraste en tu lista.

Con esta nueva información, escribe una función `FixBirdCountLog` que tome un slice de aves contadas por día como argumento y devuelva el slice después de corregir el error de conteo.

```go
birdsPerDay := []int{2, 5, 0, 7, 4, 1}
FixBirdCountLog(birdsPerDay)
// => [3 5 1 7 5 1]
```
