# Introducción a los bucles for

El [bucle for](https://docs.oracle.com/javase/tutorial/java/nutsandbolts/for.html) proporciona un mecanismo para ejecutar un grupo de sentencias repetidamente hasta que se cumpla alguna condición.
El bucle consta de cuatro partes:

```java
for (initialization; test; update) {
    body;
}
```

La `initialization` establece un estado inicial para el bucle y se ejecuta exactamente una vez al comienzo del bucle.
Por lo general, declara y asigna una variable que se usa en la expresión de prueba y en la sentencia de actualización.
Por ejemplo:

```java
int i = 1
```

La expresión `test` evalúa si el bucle debe terminar.
Si se evalúa como `true`, se ejecutarán el cuerpo y luego la expresión de actualización.
Si se evalúa como `false`, no se ejecutará ni el cuerpo ni la sentencia de actualización, y la ejecución continúa después de la llave de cierre del bucle.
Por lo general, comprueba la variable asignada en el bloque de inicialización.
Por ejemplo:

```java
i <= 10
```

Después de ejecutar el cuerpo del bucle, se ejecuta la expresión `update`.
Por lo general, incrementa o decrementa la variable del bucle en algún valor.
Por ejemplo:

```java
i++
```

Un bucle `for` que imprima los primeros cuatro cuadrados se vería así:

```java
for (int i = 1; i <= 4; i++) {
    System.out.println("square of " + i + " is " + i * i);
}
```

La salida sería:

```text
square of 1 is 1
square of 2 is 4
square of 3 is 9
square of 4 is 16
```

Si vas a recorrer cada elemento de una colección, es preferible un bucle `for-each`, pero también se puede hacer con un bucle `for` así:

```java
for (int i = 0; i < array.length; i++) {
    System.out.print(array[i]);
}
```

Un bucle `for` sí tiene algunas ventajas sobre un bucle `for-each`:

- Puedes empezar o terminar en el índice que quieras.
- Puedes usar la condición de terminación (booleana) que quieras.
- Puedes omitir elementos personalizando el incremento de la variable del bucle.
- Puedes procesar colecciones de atrás hacia adelante contando hacia atrás.
- Puedes usar bucles `for` en escenarios que no involucran colecciones.
