# PaySwitch - Conversor de salarios

## Enunciado del problema

Una empresa llamada **Insure Everyone** les paga a sus empleados en monedas extranjeras. Pero, debido a requisitos legislativos, el salario debe convertirse a la moneda local. Sus empleados están repartidos por todo el mundo.
El departamento de Recursos Humanos de Insure Everyone busca la ayuda de un desarrollador con talento para crear un programa que convierta el salario de cada empleado a su moneda local correspondiente. Insure Everyone depende de los tipos de cambio que proporciona una API externa.

Dada la API externa de tipos de cambio, debes escribir una función que reciba una `source currency`, un `salary` (en la moneda de origen) y la `local currency` del empleado, y que devuelva el salario en la moneda local.

## Restricciones

* 500 <= `salary` <= 10000
* `sourceCurrency` y `targetCurrency` son [códigos de moneda ISO (alfabéticos)](https://en.wikipedia.org/wiki/ISO_4217#Active_codes). La entrada de las pruebas puede contener códigos de moneda no válidos.
* La precisión del tipo de cambio devuelto se medirá hasta `5` decimales.
