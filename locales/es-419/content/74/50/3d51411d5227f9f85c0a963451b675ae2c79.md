# Acerca de

Las estructuras de datos que pueden contener cero o más elementos se conocen como _colecciones_. Un **array** (también llamado _arreglo_) es una colección que tiene un tamaño o longitud fijo y cuyos elementos deben ser todos del mismo tipo. Puedes asignar elementos a un array o recuperarlos de él usando un índice. Los arrays de C# están basados en cero, lo que significa que el índice del primer elemento siempre es cero:

```csharp
// Declare array with explicit size (size is 2)
int[] twoInts = new int[2];

// Assign second element by index
twoInts[1] = 8;

// Retrieve the second element by index
twoInts[1] == 8; // => true

// Check the length of the array
twoInts.Length == 2; // => true
```

También puedes definir arrays con una notación abreviada que te permite crear el array y asignarle su valor a la vez. Como ahora el compilador puede saber cuántos elementos tendrá el array, se puede omitir la longitud:

```csharp
// Three equivalent ways to declare and initialize an array (size is 3)
int[] threeIntsV1 = new int[] { 4, 9, 7 };
int[] threeIntsV2 = new[] { 4, 9, 7 };
int[] threeIntsV3 = { 4, 9, 7 };
```

Puedes manipular los arrays llamando a los [métodos][array-methods] o a las [propiedades][array-properties] de una instancia de array, o usando los métodos estáticos definidos en la [clase `Array`][array-class].

## Iteración

Un array también es una _colección_, lo que significa que puedes recorrer _todos_ sus valores con un [bucle `foreach`][foreach-statement]:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // Output the vowel
    System.Console.Write(vowel);
}

// => aeiou
```

También puedes usar un [bucle `for`][for-statement] para recorrer un array:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

for (int i = 0; i < vowels.Length; i++)
{
    // Output the vowel
    System.Console.Write(vowels[i]);
}

// => aeiou
```

Sin embargo, en general es preferible un bucle `foreach` a un bucle `for` por las siguientes razones:

- Un bucle `foreach` garantiza que se recorran _todos_ los valores. Con un bucle `for`, es fácil saltarse elementos, por ejemplo por un error de desfase de uno.
- Un bucle `foreach` es más _declarativo_: tu código comunica _qué_ quieres hacer, en lugar de un bucle `for` que comunica _cómo_ quieres hacerlo.
- Un bucle `foreach` es a prueba de errores, mientras que con los bucles `for` es fácil cometer un error de desfase de uno.
- Un bucle `foreach` funciona con todos los tipos de colección, incluidos los que no permiten usar un indexador para acceder a los elementos.

Para garantizar que un bucle `foreach` recorra _todos_ los valores, el compilador no permite modificar una colección dentro de un bucle `foreach`:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // This would result in a compiler error
    // vowel = 'Y';
}
```

Un bucle `for` sí tiene algunas ventajas sobre un bucle `foreach`:

- Puedes empezar o terminar en el índice que quieras.
- Puedes usar cualquier condición de terminación (Boolean) que quieras.
- Puedes saltarte elementos personalizando el incremento de la variable del bucle.
- Puedes procesar colecciones de atrás hacia adelante contando hacia atrás.
- Puedes usar bucles `for` en escenarios que no involucran colecciones.

Temas relacionados:

- Ten en cuenta que C# admite [arrays multidimensionales][multi-dimensional-arrays] como `int[,] arr = new int[10, 5]`, que pueden ser muy útiles.
- También ten en cuenta que puedes instanciar objetos de tipo [`System.Array`][system-array-object] con `Array.CreateInstance`. Estos objetos sirven para poco: principalmente para la interoperabilidad con código VB.NET. No son intercambiables con los arrays estándar (`T[]`). Pueden tener un límite inferior distinto de cero.
