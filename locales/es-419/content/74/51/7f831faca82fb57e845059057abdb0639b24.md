# Apéndice de las instrucciones

## Registros

| Registro | Uso          | Tipo      | Descripción                                        |
| -------- | ------------ | --------- | -------------------------------------------------- |
| `$a0`    | entrada      | dirección | array de palabras con las capacidades de los baldes |
| `$a1`    | entrada      | entero    | balde inicial (1 o 2)                              |
| `$a2`    | entrada      | entero    | volumen objetivo                                   |
| `$a3`    | entrada/salida | dirección | array de palabras con el contenido final de los baldes |
| `$v0`    | salida       | entero    | cantidad de acciones necesarias, -1 si no es posible |
| `$t0-9`  | temporal     | cualquiera | se usa para almacenamiento temporal               |
