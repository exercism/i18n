# Instrucciones

En este ejercicio, vas a aplicar las [reglas del juego de Go](https://matmoore.github.io/learngo/). Las reglas ya están escritas; solo tienes que aplicarlas para actualizar el Game y para manejar los errores o las violaciones de las reglas.

El juego se representa así:

```elm
type Player
    = Black
    | White


type alias Game =
    { whiteCapturedStones : Int
    , blackCapturedStones : Int
    , player : Player
    , error : String
    }
```

Hay 4 reglas en el juego:

- Cada punto solo puede tener una piedra (`oneStonePerPointRule`)
- ¡Las piedras del oponente se pueden capturar! (`captureRule`)
- No puedes colocar una piedra donde se capturaría a sí misma (`libertyRule`)
- No puedes usar el mismo punto dos veces (`koRule`)

## 1. Aplica las reglas

Escribe el contenido de la función `applyRules`, que toma un `Game` inicial y un conjunto de reglas, y devuelve el nuevo `Game` después de que se hayan aplicado las reglas.

`oneStonePerPointRule`, `libertyRule` y `koRule` verifican si hay violaciones de las reglas y pueden devolver un error, así que tienen el tipo de retorno `Result String Game`. Si alguna de estas reglas falla, se debe devolver el juego original, pero con el campo `error` actualizado con el error correspondiente.

`captureRule` no verifica si hay violaciones, así que no puede fallar (aunque puede devolver un `Game` modificado) y por eso tiene el tipo de retorno `Game`.

Si todas las reglas pasan, se deben conservar los cambios que hayan hecho al `Game` y se debe cambiar el jugador. La función `changePlayer` se proporciona para hacer esto.

```elm
applyRules : Game -> Rule -> NonValidatingRule -> Rule -> Rule -> Game
applyRules game oneStonePerPointRule captureRule libertyRule koRule =
--> If all rules pass, return a `Game` with all changes from the rules applied, and changePlayer
--> If any rule fails, return the original Game, but with the error field set
```
