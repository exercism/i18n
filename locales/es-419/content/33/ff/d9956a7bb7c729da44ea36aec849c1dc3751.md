# Pruebas

Para descargar un ejercicio, por ejemplo `hello-world`, abre una terminal y ejecuta:

```bash
exercism download --track roc --exercise hello-world
```

Luego ve al directorio del ejercicio y edita el código para resolver el ejercicio. Por ejemplo:

```bash
cd {your Exercism folder}/roc/hello-world
edit HelloWorld.roc
```

Cada ejercicio viene con un conjunto de pruebas. Puedes ejecutar las pruebas con el comando `roc test`, por ejemplo:

```
roc test hello-world-test.roc
```

Si ya resolviste el ejercicio, deberías ver 0 pruebas fallidas, por ejemplo:

```
All (5) tests passed in 123.4 ms.
```

Sin embargo, si tu código tiene algún error, se verá así:

```
── EXPECT FAILED in hello-world-test.roc ───────────────────────────────────────

This expectation failed:

6│  expect hello == "Hello, World!"
    ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^


1 failed and 0 passed in 123.4 ms.
```

Esto debería ayudarte a corregir tu código. Cuando tu código funcione, puedes enviarlo con el comando `exercism submit` (consulta `HELP.md` en el directorio del ejercicio para más detalles).
