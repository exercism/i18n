# Acerca de

Una [`list`][lists] en F# es una colección inmutable de cero o más valores. Los valores de una lista deben tener todos el mismo tipo. Como las listas son inmutables, una vez que se ha construido una lista, su valor nunca puede cambiar. Las listas de F# tienen una _cabeza_ (el primer elemento) y una _cola_ (todo lo que va después del primer elemento). La cola de una lista es, a su vez, otra lista.

Las listas se pueden definir de la siguiente manera:

```fsharp
let empty = []
let emptyAlternative = List.empty

let singleValue = [5]
let singleValueAlternative = List.singleton 5

let threeValues = ["a"; "b"; "c"]
```

La forma más común de agregar un elemento a una lista es mediante el operador `::` (cons):

```fsharp
let twoToFour = [2; 3; 4]
let oneToFour = 1 :: twoToFour
// => [1; 2; 3; 4]
```

Las listas se pueden concatenar con el operador `@` o con `List.append`:

```fsharp
[6; 7] @ [8; 9]           // => [6; 7; 8; 9]
List.append [6; 7] [8; 9] // => [6; 7; 8; 9]
```

Las listas se manipulan con funciones y operadores definidos en el [módulo `List`][list-module]. Algunas de estas funciones también están disponibles como [propiedades][list-properties] de una instancia de `list`:

```fsharp
List.length [7; 8] // => 2
[7; 8].Length      // => 2
```

Aquí no hay una opción correcta ni incorrecta. En general, las funciones del módulo `List` se llevan mejor con la inferencia de tipos, mientras que las propiedades permiten un código más conciso.

Cualquier función u operador que parezca modificar una lista (por ejemplo, agregar un elemento) en realidad devuelve una lista nueva. Sin embargo, el rendimiento normalmente no es un problema, ya que la implementación de las listas evita asignaciones y copias innecesarias.

Como las listas se implementan como listas enlazadas simples, anteponer un elemento (con el operador `::`) es muy rápido, mientras que acceder a un elemento por su índice puede ser relativamente lento.

Las listas también se pueden procesar mediante la coincidencia de patrones con los patrones [_list_][list-pattern] y [_cons_][cons-pattern]:

```fsharp
let describe list =
    match list with
    | [] -> "Empty list"
    | [ 1 ] -> "Singleton list with 1"
    | head::tail -> sprintf "Non-empty list with head: %d" head

describe []        // => "Empty list"
describe [1]       // => "Singleton list with 1"
describe [5; 7; 9] // => "Non-empty with head: 5"
```

También puedes _descartar_ un valor cuando haces coincidencia de patrones; cuando _no_ te importa un valor en un caso específico (es decir, no vas a _usar_ ese valor), puedes usar un guion bajo (`'_'`) para indicarlo:

```fsharp
let describe list =
    match list with
    | [] -> "Empty list"
    | [x] -> "List with one item"
    | [_; y] -> "List with two items (first item ignored)"
    | _ -> "List with many items (all items ignored)"

describe []        // => "Empty list"
describe [1]       // => "List with one item"
describe [5; 7]     // => "List with two items (first item ignored)"
describe [5; 7; 9] // => "List with many items (all items ignored)"
```

El `'_'` siempre debe ir _al final_ cuando haces coincidencia de patrones; todo valor que _no_ coincida con ninguno de los otros casos será manejado por este caso.
