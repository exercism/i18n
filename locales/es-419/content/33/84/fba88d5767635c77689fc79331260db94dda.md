# Instrucciones

Es la final de temporada en el club local. Estás a cargo de la tabla de posiciones en la línea de meta: los corredores cruzan en orden, los carriles necesitan etiquetas y hay que anotar el registro oficial antes de la siguiente ronda.

Los nombres de los corredores llegan como un array, en orden de llegada: el nombre 0 es el ganador, el 1 es el segundo lugar, y así sucesivamente.

## 1. Asigna los dorsales

Define `assign-bibs` para que tome un array de nombres de corredores y devuelva un array de pares `{ position name }`, con la posición primero.

```factor
{ "Bolt" "Comet" "Spirit" } assign-bibs .
! => { { 0 "Bolt" } { 1 "Comet" } { 2 "Spirit" } }
```

## 2. Rótulos de carril

Define `lane-labels` para que tome un array de nombres de corredores y devuelva strings como `"Lane 0: Bolt"`.

```factor
{ "Bolt" "Comet" } lane-labels .
! => { "Lane 0: Bolt" "Lane 1: Comet" }
```

## 3. Etiqueta a los corredores

Define `tag-racers` para que tome un array de nombres de corredores *y* un string de etiqueta, y devuelva rótulos de la forma `"<tag>/<index>: <name>"`. La misma etiqueta se incrusta en cada rótulo.

```factor
{ "Bolt" "Comet" } "Green" tag-racers .
! => { "Green/0: Bolt" "Green/1: Comet" }
```

## 4. Registra las llegadas

Define `record-finishes` para que tome un array de nombres de corredores y un registro (un vector). Para cada corredor, agrega un string de la forma `"<index>: <name>"` al registro, en el lugar. No devuelve nada.

```factor
V{ } clone   ! a fresh empty ledger
{ "Bolt" "Comet" } over record-finishes
.
! => V{ "0: Bolt" "1: Comet" }
```

## 5. Campanas de vuelta

Define `lap-bells` para que tome un número `laps` y devuelva un string formado por `"ding "` repetido `laps` veces.

```factor
0 lap-bells .   ! => ""
3 lap-bells .   ! => "ding ding ding "
```
