# Anexo a las instrucciones

## Implementación

En este ejercicio vas a implementar un procedimiento que debe reservar la memoria del string que devuelve. Liberar el string es responsabilidad de quien llama al procedimiento.

```odin
// The procedure will be called like that:
formatted := format("Gianna", 4)
// ...
// and eventually the caller will delete the string
delete(formatted)
```
