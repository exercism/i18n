# Importación

La [forma especial `import`][import] te permite usar funciones y macros de un módulo externo sin usar el nombre del módulo.

Importar un módulo externo completo podría crear conflictos con las funciones locales existentes. Para evitar esto, tienes dos opciones: `:except` y `:only`. Ambas esperan una lista de palabras clave, en la que la clave es el nombre de la función y el valor es la aridad de la función.

```elixir
defmodule Square do
  import Integer, only: [pow: 2]

  def area(a), do: pow(a, 2)
end
```

Por lo general, las importaciones se agregan al principio de la definición del módulo, pero pueden agregarse en cualquier parte. Tienen ámbito léxico, lo que significa que una importación agregada dentro de la definición de una función no estará disponible en otra función.

Las importaciones que no se usan provocan advertencias del compilador.

[import]: https://hexdocs.pm/elixir/Kernel.SpecialForms.html#import/2
