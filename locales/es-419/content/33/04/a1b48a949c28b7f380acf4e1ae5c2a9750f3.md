# Apéndice de instrucciones

## Operadores de números complejos

Las funciones aritméticas admiten llamadas a función normales, despacho estático (también conocido como sintaxis de llamada a método) y operadores:

| Llamada a función | Llamada a método | Operador |
| --- | --- | --- |
| `plus(z1, z2)` | `z1.plus(z2)` | `z1 + z2` |
| `minus(z1, z2)` | `z1.minus(z2)` | `z1 - z2` |
| `times(z1, z2)` | `z1.times(z2)` | `z1 * z2` |
| `div_by(z1, z2)` | `z1.div_by(z2)` | `z1 / z2` |
