# Acerca de

El tipo `Maybe` es la solución del lenguaje Elm para los valores opcionales. Por eso aparece en las firmas de tipo de una gran cantidad de funciones centrales de Elm, y entenderlo es fundamental.

## Definición y variable de tipo

El tipo `Maybe` se define de la siguiente manera:

```elm
type Maybe a = Nothing | Just a
```

Esto se conoce como una definición de "tipo personalizado" en la terminología de Elm. Los tipos personalizados se presentan en detalle en otro concepto de este track, pero no los necesitaremos para entender `Maybe` en concreto. La `a` en `Maybe a` y `Just a` representa una variable de tipo, lo que significa que puede ser cualquier tipo, como `Int`, `Bool` o `String`. Así, un `Maybe String` es una variable que contiene opcionalmente un `String`, mientras que un `Maybe Int` contendría opcionalmente un `Int`.

```elm
name : Maybe String
name = Just "Matthieu"

age : Maybe Int
age = Just 29
```

La barra vertical `|` en la definición de tipo de `Maybe` significa «o». Indica que un valor de este tipo puede ser `Nothing` o ser `Just` algo de tipo `a`. Entonces, imagina que esa persona no completó el nombre ni la edad; tendríamos lo siguiente.

```elm
name : Maybe String
name = Nothing

age : Maybe Int
age = Nothing
```

## Cómo leer el contenido de un valor Maybe

Leer el contenido de un valor `Maybe` se hace mediante la «coincidencia de patrones». La coincidencia de patrones también se presenta con más detalle en otro concepto, así que nos enfocamos solo en cómo funciona la coincidencia de patrones con un `Maybe`.

```elm
-- This function returns "Hello, <name>!" if the name was provided.
-- Otherwise, it just says "Hello, World!".
sayHello : Maybe String -> String
sayHello maybeName =
    case maybeName of
        Nothing -> "Hello, World!"
        Just someName -> "Hello, " ++ someName ++ "!"

sayHello (Just "Matthieu")
    --> "Hello, Matthieu!"

sayHello Nothing
    --> "Hello, World!"
```

Cada vez que usas un valor `Maybe`, el compilador de Elm verificará que tu código contemple todas las posibilidades, así que nunca puedes hacer coincidencia de patrones con un `Maybe` y contemplar solo el caso en el que hay un `Just someValue`. Esto puede parecer molesto al principio, pero es una de las mayores fortalezas del lenguaje Elm. Evitará cientos de bugs y hace que la refactorización guiada por el compilador sea una experiencia sin miedo y gratificante.

## Más funciones para manipular `Maybe`

También hay varias funciones útiles en el módulo `Maybe` para manipular tipos `Maybe`.

```elm
sayHelloAgain : Maybe String -> String
sayHelloAgain name = "Hello, " ++ Maybe.withDefault "World" name ++ "!"

capitalizeName : Maybe String -> Maybe String
capitalizeName name = Maybe.map String.toUpper name

capitalizeName matthieu
    --> Just "MATTHIEU"

capitalizeName anon
    --> Nothing
```
