# Acerca de

ABAP tiene varios tipos numéricos. Los más comunes para ejercicios introductorios pequeños son `i` para valores enteros y `p` para valores decimales empaquetados.

Usa `i` cuando un valor deba ser un número entero, como un número de días. Usa un tipo decimal cuando un valor pueda contener decimales, como una tarifa por hora.

```abap
DATA hours_per_day TYPE i VALUE 8.
DATA rate_per_hour TYPE p LENGTH 8 DECIMALS 2 VALUE '89.89'.

DATA day_rate TYPE p LENGTH 8 DECIMALS 2.
day_rate = hours_per_day * rate_per_hour.
```

Los números empaquetados se usan a menudo en aplicaciones empresariales cuando se requiere un número fijo de posiciones decimales. ABAP también tiene números de punto flotante decimales (`decfloat16` y `decfloat34`) y números de punto flotante binarios (`f`). Los números de punto flotante binarios pueden ser útiles para cálculos científicos, pero no son una buena opción predeterminada para ejemplos relacionados con dinero, porque muchas fracciones decimales no se pueden representar de forma exacta.
