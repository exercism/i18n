# Pistas

## 1. Eliminar las canciones duplicadas

- Puedes ver un ejemplo de cómo crear un set a partir de un array en la [documentación de MDN][mdn-relation-to-arrays].
- Asegúrate de convertir tu set de nuevo en un array antes de devolverlo.
- Vuelve al [concepto de desestructuración de arrays][concept-array-destructuring] para repasar cómo usar el operador de propagación.

## 2. Comprobar si ya se agregó una canción

- Hay un [método integrado][mdn-set-has] para comprobar si un elemento está en un set.

## 3. Agregar una canción

- Hay un [método integrado][mdn-set-add] para agregar un elemento a un set.
- Asegúrate de no llamar manualmente a `Set.has()` para comprobar si el elemento está presente antes de agregarlo; ¡`Set.add()` se encarga de eso por ti!

## 4. Borrar una canción

- Hay un [método integrado][mdn-set-delete] para quitar un elemento de un set.
- Asegúrate de no llamar manualmente a `Set.has()` para comprobar si el elemento está presente antes de borrarlo; ¡`Set.delete()` se encarga de eso por ti!

## 5. Listar los artistas únicos

- Hay [varias formas distintas][mdn-set-iteration] de iterar sobre un set.
- Hay un [método integrado][mdn-string-split] para dividir un string en subcadenas.
- Vuelve al [concepto de desestructuración de arrays][concept-array-destructuring] para repasar cómo omitir un elemento al desestructurar un array.
