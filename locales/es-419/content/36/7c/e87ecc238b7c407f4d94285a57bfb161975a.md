# Pistas

## 1. Define el tiempo esperado en el horno en minutos

- Necesitas asignar el valor correcto a la constante `$EXPECTED-MINUTES-IN-OVEN`.

## 2. Calcula el tiempo restante en el horno en minutos

- Puedes restar números entre sí usando el [operador infijo `-`][&infix:<->].

## 3. Calcula el tiempo de preparación en minutos

- Puedes multiplicar números usando los [operadores infijos `*` o `×`][&infix:<*>].

## 4. Calcula el tiempo total de trabajo en minutos

- Puedes llamar a otras funciones definidas que te puedan resultar útiles, por ejemplo, `function($arg)`.
- Puedes sumar números entre sí usando el [operador infijo `+`][&infix:<+>].

## 5. Crea una notificación de que la lasaña está lista

- Puedes crear un string encerrando texto entre comillas simples `'foo'` o dobles `"bar"`.
  Consulta [Construcciones de entrecomillado][quoting].

[&infix:<*>]: https://docs.raku.org/language/operators#infix_*
[&infix:<->]: https://docs.raku.org/language/operators#infix_-
