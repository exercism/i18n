# Instrucciones

En este ejercicio juegas un juego de rol llamado «Wizard and Warriors» con tus mejores amigos.
Tú eres el Game Master, la persona encargada de hacer que el mundo del juego cobre vida para los jugadores.
Un aspecto clave de esto es describir el juego a los jugadores: cuál es el estado de un personaje, cómo se ve el pueblo que están visitando, etc.

Tienes cinco tareas en las que describes partes del juego a los jugadores.

## 1. Describe un personaje

Cada personaje tiene una clase, un nivel y una cantidad de puntos de vida, y se describe así: `"You're a level <LEVEL> <CLASS> with <HIT_POINTS> hit points."`.
Implementa el método `GameMaster.describe` que recibe un `Character` como único parámetro y devuelve su descripción.

```java
Character character = new Character();
character.setCharacterClass("Wizard");
character.setLevel(4);
character.setHitPoints(28);

new GameMaster().describe(character);
// => "You're a level 4 Wizard with 28 hit points."
```

## 2. Describe un destino

Cada destino tiene un nombre y un número de habitantes, y se describe así: `"You've arrived at <NAME>, which has <INHABITANTS> inhabitants."`.
Implementa el método `GameMaster.describe` que recibe un `Destination` como único parámetro y devuelve su descripción.

```java
Destination destination = new Destination();
destination.setName("Muros");
destination.setInhabitants(732);

new GameMaster().describe(destination);
// => "You've arrived at Muros, which has 732 inhabitants."
```

## 3. Describe el método de viaje

Los personajes pueden viajar a un destino usando una de dos opciones:

- A pie, descrito así: `"You're traveling to your destination by walking."`
- A caballo, descrito así: `"You're traveling to your destination on horseback."`

Implementa el método `GameMaster.describe` que recibe un `TravelMethod` como único parámetro y devuelve su descripción.

```java
new GameMaster().describe(TravelMethod.HORSEBACK);
// => "You're traveling to your destination on horseback."
```

## 4. Describe un personaje que viaja a un destino

Cuando un personaje viaja a un destino, esto se describe como una combinación de las descripciones individuales: `"<CHARACTER> <TRAVEL_METHOD> <DESTINATION>"`.
Implementa el método `GameMaster.describe` que recibe un `Character`, un `Destination` y un `TravelMethod` como parámetros y devuelve su descripción.

```java
Character character = new Character();
character.setCharacterClass("Wizard");
character.setLevel(4);
character.setHitPoints(28);

Destination destination = new Destination();
destination.setName("Muros");
destination.setInhabitants(732);

new GameMaster().describe(character, destination, TravelMethod.HORSEBACK);
// => "You're a level 4 Wizard with 28 hit points. You're traveling to your destination on horseback. You've arrived at Muros, which has 732 inhabitants."
```

## 5. Describe un personaje que viaja a un destino sin especificar el método de viaje

En la mayoría de los casos, los personajes viajan a un destino a pie.
Por conveniencia, los jugadores pueden omitir su método de viaje, en cuyo caso se asumirá que el método de viaje es caminar.
Implementa el método `GameMaster.describe` que recibe un `Character` y un `Destination` como parámetros y devuelve su descripción.

```java
Character character = new Character();
character.setCharacterClass("Wizard");
character.setLevel(4);
character.setHitPoints(28);

Destination destination = new Destination();
destination.setName("Muros");
destination.setInhabitants(732);

new GameMaster().describe(character, destination);
// => "You're a level 4 Wizard with 28 hit points. You're traveling to your destination by walking. You've arrived at Muros, which has 732 inhabitants."
```
