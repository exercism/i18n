# se usó la división de strings

Usa el tipo integrado `rune` para trabajar con caracteres individuales en Go.
Un `string` se puede convertir en un `[]rune` (slice de runes) con:

```go
aRunes := []rune(a)
```

Dividir el string en muchos strings pequeños (uno por cada rune) funciona, pero es ineficiente.
