# Introducción

## Mapeo

El mapeo se refiere a la aplicación de una función a cada elemento de una secuencia para producir una nueva secuencia.

Esto se puede hacer fácilmente en una lista con la función `mapcar`.
Supongamos que tenemos una función `double` que multiplica su argumento por `2`:

```lisp
(mapcar #'double '(1 2 3 4)) ; => (2 4 6 8)
```

Fíjate que el primer argumento es una función que se debe llamar. El `#'` es una sintaxis especial de citación para especificar una función.

Se llamó a `double` primero con el primer elemento, luego con el segundo, etc.
Los resultados se recolectaron en una lista, que es el valor al que evalúa la expresión.

## Filtrado

El filtrado es el proceso de crear una secuencia a partir de otra secuencia copiando todos los elementos excepto algunos de la secuencia original.
La elección de qué elementos incluir en la nueva secuencia se puede hacer mediante una función predicado (una función que evalúa a un valor Boolean), o mediante la igualdad con un objeto específico.

### Eliminar mediante un predicado

`remove-if` es una función que toma una función predicado y una secuencia como argumentos, y devuelve una secuencia solo con aquellos elementos para los que el predicado evaluó a un valor falso.
En otras palabras, «elimina» todos los elementos de la secuencia para los que el predicado evalúa a verdadero. Sin embargo, ¡fíjate que esta función no modifica la secuencia original!
En su lugar, devuelve una nueva secuencia sin los elementos correspondientes. Si el predicado fue verdadero para todos los valores, se devuelve una secuencia vacía.

```lisp
(remove-if #'evenp '(1 2 3 4 5)) ; => (1 3 5)
(remove-if #'oddp '(1 3 5))      ; => ()
```

### Eliminar un elemento específico

Si quieres eliminar un elemento específico de una secuencia, puedes usar `remove`, que toma el elemento a eliminar y una secuencia.
Se devuelven todos los valores de la secuencia que no sean iguales al elemento a eliminar.
NOTA: La igualdad se verifica con el `eql` [predicado de igualdad genérico][concept-equality] de forma predeterminada.

```lisp
(remove 1 '(1 2 1 3 1 4)) ; => (2 3 4)
(remove #\l "hello")      ; => "heo"
```
