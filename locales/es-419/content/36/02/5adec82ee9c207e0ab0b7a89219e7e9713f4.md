# Anexo de instrucciones

## Formato de salida

Devuelve la secuencia de acciones como una string terminada en nulo, usando una coma y un espacio como separadores.

## Registros

| Registro | Uso            | Tipo       | Descripción                        |
| -------- | -------------- | ---------- | ---------------------------------- |
| `$a0`    | entrada        | entero     | número entre 1 y 31                |
| `$a1`    | entrada/salida | dirección  | string de salida terminada en nulo |
| `$t0-9`  | temporal       | cualquiera | se usa para almacenamiento temporal |
