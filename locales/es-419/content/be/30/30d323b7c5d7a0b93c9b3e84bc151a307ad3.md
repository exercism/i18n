# Acerca de

Disponibles a partir de `PHP 8.0.0`, las **declaraciones de tipos de unión** aceptan valores de varios tipos diferentes, en lugar de un solo tipo. Las definiciones de tipos de unión se crean usando la barra vertical (`|`) para separar los tipos.

```php
function add(int|float $a, int|float $b): int|float
{
    return $a + $b;
}
```

## Matices

- Los tipos `null` se pueden declarar _nullable_ usando `?Type` o `Type1|Type2|null`.
- los tipos duplicados o redundantes declarados provocarán un error en tiempo de compilación.
- `void` no se puede usar como parte de una declaración de tipo de unión.
