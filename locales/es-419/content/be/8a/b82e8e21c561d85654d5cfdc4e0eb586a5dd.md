# Pistas

## General

- Revisa la referencia de [conversión de tipos][ref-type-juggling].
- Revisa la referencia de conversión de tipos a [Integer][ref-type-cast-int] y [String][ref-type-cast-string].
- Revisa la referencia de [strings numéricos][ref-numeric-strings].

## 1. Calcula la suma de los números de la máquina tragamonedas

- Puedes usar [`implode`][ref-implode] para combinar los dígitos.
  `implode` convertirá implícitamente los dígitos del array a strings y devolverá un string.
- Para sumar los números, consulta el concepto de [operaciones aritméticas][ref-arithmetic-ops].
  Los operadores aritméticos convertirán implícitamente los strings a enteros o números de punto flotante.

## 2. Determina si un número es un palíndromo

- Esta tarea se puede resolver comparando el número dado con su versión invertida.
  Para hacerlo, primero debes invertir el número dado.
  Luego devuelve el resultado de comparar ambas versiones.
- Puedes usar [`strrev`][ref-strrev] para obtener el número invertido.
  `strrev` convertirá implícitamente el número a un string y devolverá un string.
- Por último, puedes [comparar][ref-comparison-ops] el número dado con el string invertido.
  Cuando escribas la condición para eso, usa la [comparación][ref-comparison-ops] que hace conversión de tipos.
  PHP convertirá el string invertido a un número para esta comparación.
- El resultado de la comparación es un `bool`, que es el tipo que debes devolver.

## 3. Genera un mensaje de error para una entrada de usuario no válida

- Puedes usar [sentencias if][ref-if-statement] para comprobar las distintas condiciones.
- Primero, debes cubrir el caso en que el valor no contiene ningún carácter.
- Luego, aborda el caso en que la entrada no sea un número o `0`.
  Las reglas de conversión de tipos de los [operadores de comparación][ref-comparison-ops] juegan en tu contra en este caso.
  Hacen que PHP compare strings en algunos casos, y eso da resultados incorrectos.
  Usa la conversión explícita a `int` que aprendiste en la introducción.
  Después puedes confiar en los [operadores de comparación][ref-comparison-ops] para un número mayor que `0`.
