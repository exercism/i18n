## Descripciones generales

### Fortran
- Iniciado por John Backus en IBM en la década de 1950 para desarrollar una alternativa más práctica al lenguaje ensamblador para programar su computadora central IBM 704
- Diseñado para ser bueno construyendo aplicaciones científicas y de ingeniería (el nombre es la abreviatura de Formula Translating System)
- El primer lenguaje de programación de alto nivel (reduce las líneas de código en un factor de aproximadamente 20)
- También el primer compilador optimizador (los clientes eran reacios a usar un lenguaje de programación de alto nivel a menos que su compilador pudiera generar código con un rendimiento cercano al del lenguaje ensamblador escrito a mano)
- Lenguaje de tipado estático y fuerte
- Al principio solo soportaba programación imperativa, pero poco después se añadió la programación procedimental. Extensiones posteriores añadieron soporte para otros paradigmas, como la programación orientada a objetos y la programación con arrays
- Estandarizado, primero en 1966 con Fortran 66, ¡y actualizado por última vez en 2018!
- Muy influyente, desde Basic hasta ALGOL, inspiración para muchos lenguajes. Gran parte de la investigación temprana sobre lenguajes de programación tenía como objetivo ayudar a mejorar Fortran

- Todavía se desarrolla activamente, con nuevas características que se van añadiendo, y aún mantiene sólidas garantías de compatibilidad con versiones anteriores (el código antiguo normalmente sigue compilándose y ejecutándose)
- Paralelismo integrado mediante coarrays, un método seguro y eficiente de expresar paralelismo. Las funciones se pueden marcar como puras, lo que ayuda al compilador a optimizar para la computación en paralelo
- Manejo seguro de memoria mediante variables asignables, donde el compilador se encarga de liberar la memoria.
- Interoperabilidad integrada con C

### COBOL
- Diseñado en 1959 por el consorcio CODASYL (¡patrocinado por el Departamento de Defensa!) en un esfuerzo por reducir los costos de desarrollar aplicaciones empresariales (el nombre significa Common Business-Oriented Language)
- Se convirtió en estándar en 1968, con la última revisión de 2014
- Diferentes implementaciones, como IBM COBOL, GnuCOBOL (que compila a C) y Micro Focus™ Visual COBOL, que se ejecuta tanto en la JVM como en el runtime de .NET
- Lenguaje de tipado estático
- Multiparadigma, soporta programación imperativa y orientada a objetos

- Sintaxis verbosa (muchas palabras clave) pero muy legible para los humanos. Favorece la legibilidad y el mantenimiento
- Buena compatibilidad con versiones anteriores, con una especificación estable. Probado en batalla
- Buen rendimiento (se usa en finanzas)

### Visual Basic
- Desarrollado por Microsoft como sucesor de Visual Basic que se ejecuta en el runtime de .NET (el sufijo .NET se eliminó después de Visual Basic 2003)
- La primera versión se lanzó en 2002 y el lenguaje se marcó como «estable» en 2023. Esto significa que no se añadirá nueva sintaxis al lenguaje, pero sigue siendo un lenguaje soportado
- Comparte en gran medida la sintaxis con Visual Basic, pero se hicieron algunos cambios
- Lenguaje de tipado estático que soporta tipado fuerte y débil
- Lenguaje multiparadigma: principalmente orientado a objetos, pero también programación imperativa y dirigida por eventos

- Fácil de aprender (Visual Basic fue diseñado para ser fácil de aprender)
- Excelente soporte para la programación orientada a objetos
- Se ejecuta en el probado runtime de .NET, con acceso a todas las bibliotecas de .NET
- Despliegue sencillo con la implementación ClickOnce

## Casos de uso

### Fortran
Se usa en escenarios de computación de alto rendimiento (supercomputadoras), como la predicción del tiempo, la astronomía y la ingeniería estructural. También se usa en software CAD y muchas aplicaciones se construyen sobre FORTRAN, por ejemplo, varios módulos de NumPy usan bibliotecas de FORTRAN 77

### COBOL
Se usa mucho en finanzas, y muchos sistemas financieros todavía funcionan en gran parte con software COBOL (se estima que alrededor del 80% de las transacciones financieras funcionan con COBOL), aunque hoy en día es sobre todo mantenimiento. También se usa en muchas aplicaciones empresariales e incluso en un almacén de clave/valor que se usa en Walmart.

### Visual Basic
Se usa para GUIs (por ejemplo, interfaces a bases de datos) y sitios web generados en el servidor. Entre las empresas están Boeing, Wells Fargo y General Electric

## Características destacadas

### Fortran
- Rendimiento. El lenguaje Fortran y sus tipos y estructuras de datos están diseñados para ser eficientes y tener un gran rendimiento. Por eso se usa en supercomputadoras
- De forma predeterminada, soporta muchas funciones matemáticas
- La programación con arrays es una forma muy elegante de aplicar operaciones sobre arrays y secciones de arrays sin tener que hacer ninguna iteración manual ni especificar los límites de los arrays

### COBOL
- La aritmética de punto fijo no tiene errores de redondeo, a diferencia de los números de punto flotante. Esto lo hace ideal para las finanzas
- Excelente para leer y escribir archivos (registros)
- COBOL tiene soporte integrado para generar informes (que es otra razón por la que ha sido popular en las aplicaciones empresariales)

### Visual Basic
- Excelente para construir aplicaciones con GUI usando Windows Forms. Editor WYSIWYG de arrastrar y soltar
- Gran soporte de IDE, con refactorizaciones, autocompletado de código y mucho más

## ¿Cuál probar?

- Si te interesa la computación científica o el alto rendimiento, Fortran es una excelente opción
- Si quieres hacerte una idea de cómo se construían antes las aplicaciones empresariales, COBOL es genial
- Si te interesa construir aplicaciones con GUI o ya estás en la plataforma .NET, Visual Basic funciona muy bien
- Si te interesa la historia de la programación, COBOL y Fortran son dos buenos tracks para explorar
