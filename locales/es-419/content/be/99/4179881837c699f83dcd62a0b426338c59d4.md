# Instalación

Puedes instalar Cairo simplemente descargando Scarb. Scarb incluye el compilador de Cairo y el servidor de lenguaje de Cairo en un solo paquete fácil de instalar, para que puedas empezar a escribir código en Cairo de inmediato. Scarb también es el gestor de paquetes de Cairo.

Para obtener las instrucciones de instalación recomendadas para tu plataforma, visita [el sitio web oficial de Cairo](https://www.cairo-lang.org/tutorials/getting-started-with-cairo/).

Por sistema operativo:

- Linux/MacOS
    1. Instala [asdf](https://asdf-vm.com/guide/getting-started.html)
    2. Instala [scarb](https://docs.swmansion.com/scarb/download#install-via-asdf)
    3. Verifica la instalación en una nueva sesión de terminal con `scarb --version`
- Windows
    1. Instala [scarb](https://docs.swmansion.com/scarb/download#windows)
    2. Verifica la instalación en una nueva sesión de terminal con `scarb --version`

¡Tener instalado el conjunto de herramientas no lo es todo! El soporte del IDE es un gran impulso de productividad que la mayoría de los desarrolladores ya espera.
Si usas Visual Studio Code, te recomendamos instalar la [extensión de Cairo](https://marketplace.visualstudio.com/items?itemName=starkware.cairo1), que ofrece resaltado de sintaxis, autocompletado de código y otras funcionalidades útiles.
