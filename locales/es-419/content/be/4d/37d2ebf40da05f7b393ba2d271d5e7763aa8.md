# Instrucciones

En este ejercicio vas a trabajar con cuentas de ahorro. Cada año, el saldo de una cuenta de ahorro se actualiza según la tasa de interés. La tasa de interés que da el banco depende de la cantidad de dinero que hay en la cuenta (su saldo):

- 0.5% para un saldo no negativo menor que `1000` dólares.
- 1.621% para un saldo positivo mayor o igual que `1000` dólares y menor que `5000` dólares.
- 2.475% para un saldo positivo mayor o igual que `5000` dólares.
- 3.213% para un saldo negativo (da como resultado un interés negativo).

Tienes tres tareas, y cada una trata sobre el saldo y su tasa de interés.

## 1. Calcula la tasa de interés

Implementa el método `SavingsAccount.interest_rate` para calcular la tasa de interés según el saldo indicado:

```ruby
SavingsAccount.interest_rate(200.75)
#=> 0.5
```

Ten en cuenta que el valor devuelto es una instancia de `Float`.

## 2. Calcula la actualización anual del saldo

Implementa el método `SavingsAccount.annual_balance_update` para calcular la actualización anual del saldo, teniendo en cuenta la tasa de interés:

```ruby
SavingsAccount.annual_balance_update(200.75)
#=> 201.75375
```

Ten en cuenta que el valor devuelto es una instancia de `Float`.

## 3. Calcula los años antes de alcanzar el saldo deseado

Implementa el método `SavingsAccount.years_before_desired_balance` para calcular la cantidad mínima de años necesarios para alcanzar el saldo deseado:

```ruby
SavingsAccount.years_before_desired_balance(200.75, 214.88)
#=> 14
```

Ten en cuenta que el valor devuelto es una instancia de `Integer`.
