# Acerca de

Una *expresión regular* (regex) es un patrón pequeño que describe la forma de un texto. Las herramientas de regex de Factor viven en el vocabulario [`regexp`][regexp], y un patrón se escribe como un literal entre `R/ ` y `/`.

La mayoría de los caracteres de un patrón coinciden consigo mismos. La potencia expresiva viene de las clases de caracteres y los cuantificadores:

```
\d        ! a digit 0–9            \s   ! whitespace
\D        ! any non-digit          \S   ! non-whitespace
[A-Z]     ! one capital letter     .    ! any one character
[^0-9]    ! any char except a digit

{4}       ! exactly 4              +    ! one or more
{2,5}     ! between 2 and 5        *    ! zero or more
?         ! optional               |    ! either side (alternation)
```

Así, `R/ [A-Z]{2}-\d{4}/` coincide con «dos mayúsculas, un guion, cuatro dígitos».

## Coincidencia de toda la cadena vs. búsqueda

`matches?` tiene éxito solo cuando el string *completo* encaja con el patrón. Las demás palabras buscan *dentro* de un string:

```
matches?             ( string regexp -- ? )
re-contains?         ( string regexp -- ? )
count-matches        ( string regexp -- n )
all-matching-subseqs ( string regexp -- seq )
first-match          ( string regexp -- slice/f )
re-split             ( string regexp -- seq )
re-replace           ( string regexp replacement -- result )
```

```factor
USING: regexp ;

"NS-1024" R/ [A-Z]{2}-\d{4}/ matches? .         ! => t
"id NS-1024 ok" R/ [A-Z]{2}-\d{4}/ matches? .   ! => f   (extra text)
"id NS-1024 ok" R/ [A-Z]{2}-\d{4}/ re-contains? .   ! => t

"a1b2c3" R/ \d/ count-matches .   ! => 3
"a1b2c3" R/ \d/ re-replace .      ! NOTE: see re-replace below
```

## Slices

`first-match` y `re-split` devuelven objetos `slice`, que son vistas ligeras sobre el string original en lugar de strings nuevos. Convierte un slice con `>string` cuando necesites un string independiente (por ejemplo, para compararlo con un literal de string). `all-matching-subseqs` ya devuelve strings.

## Reemplazo

`re-replace` sustituye cada coincidencia por un string de reemplazo y devuelve el resultado:

```factor
USING: regexp ;

"user=alice pass=hunter2" R/ pass=\S+/ "pass=****" re-replace .
! => "user=alice pass=****"
```

## Construir un patrón en tiempo de ejecución

`R/ /` se analiza cuando se carga el archivo. Para construir un patrón a partir de un string calculado en tiempo de ejecución, usa `<regexp>`:

```
<regexp> ( string -- regexp )
```

[regexp]: https://docs.factorcode.org/content/vocab-regexp.html
