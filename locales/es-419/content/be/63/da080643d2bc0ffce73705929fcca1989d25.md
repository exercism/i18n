# Acerca de

Una `List` es muy similar a un [`Array`][array]. Sin embargo, hay diferencias importantes que no querrás saltarte:

1. Una lista no se puede indexar usando corchetes (`[]`), es decir, `[0]`.
2. Una lista no se puede inicializar.
3. No existen las comprensiones de listas.
4. Una lista puede modificar libremente sus elementos mientras se itera sobre ellos.

`List` es un miembro del paquete `haxe.ds`, así que cada vez que quieras usar listas, necesitas importar su paquete:

```haxe
import haxe.ds.List;

class Main {
  static function main() {
    var myList = List<Int>();

    for (i in 0...5) {
      myList.add(i);
    }

    trace(myList); // {0, 1, 2, 3, 4}
  }
}
```

[array]: https://haxe.org/manual/std-Array.html
