# https://www.php.net/manual/en/language.basic-syntax.phptags.php"Operador de resolución de ámbito

El operador de resolución de ámbito (`::`) nos permite hacer referencia a una clase para acceder a sus constantes, propiedades estáticas o métodos estáticos.

```php
class MyClass
{
  public const MY_VALUE = 1;
}

// MyClass::class => "MyClass"
// MyClass::MY_VALUE => 1
```

## Usar `self` y `static` con el operador de resolución de ámbito

Puede que un objeto necesite hacer referencia a su propio ámbito. Para facilitarlo, la palabra clave `self` permite que una clase haga referencia a su propio ámbito. Usar la palabra clave `self` desacopla la clase de su propio nombre, lo que hace que el código sea más fácil de mantener con el tiempo.

```php
class MyClass
{
  public const MY_VALUE = 1;

  public function getMyValue(): int
  {
    return self::MY_VALUE;
  }
}

// (new MyClass)->getMyValue() => 1
```

Sin embargo, `self` está ligado lexicográficamente a la clase en la que aparece.

```php
class MyOtherClass extends MyClass
{
  public const MY_VALUE = 99;
}

// (new MyOtherClass)->getMyValue() => 1
```

Evaluar `MyOtherClass::getMyValue` sigue dando como resultado `1` en lugar de `99`. Para solucionar esto, usa la palabra clave `static` junto con el operador de resolución de ámbito para «vincular tardíamente» la referencia a la clase descendiente actual.

```php
// Update MyClass:
class MyClass
{
  public const MY_VALUE = 1;

  public function getMyValue(): int
  {
    return static::MY_VALUE;
  }
}
```

## Usar `parent` con el operador de resolución de ámbito

Puede que necesites hacer referencia específicamente a una constante, propiedad o método disponibles desde el ámbito de la clase padre:

```php
class MyClass
{
  public function getMaximum(): int
  {
    return 5;
  }
}

class AnotherClass extends MyClass
{
  public function getMaximum(): int
  {
    return parent::getMaximum() * 2;
  }
}

// (new AnotherClass())->getMaximum() => 10
```

Lo más común en la programación orientada a objetos es usar `parent` para llamar al constructor de la clase padre cuando se instancia un objeto:

```php
class ChildClass extends ParentClass
{
  public function __construct(): void
  {
    parent::__construct();
  }
}
```

## Advertencias

### Visibilidad de constantes, propiedades y métodos

El operador de resolución de ámbito sigue las reglas establecidas por los modificadores de visibilidad `public`, `private` y `protected`.
