# Introducción

En Haxe, un tipo abstracto es un tipo que es un tipo diferente en tiempo de ejecución. Es una funcionalidad de tiempo de compilación que define tipos «sobre» tipos concretos para modificar o ampliar su comportamiento:

```haxe
abstract AbstractInt(Int) {
    inline public function new(i:Int) {
        this = i;
    }
}
```

Aquí declaramos el tipo `AbstractInt` con la palabra clave `abstract`. Su sintaxis es muy similar a la de `class`. Y, al igual que las clases, los tipos abstractos pueden tener métodos. También se pueden instanciar y usar igual que las clases:

```haxe
class Main {
    static public function main() {
        var a = new AbstractInt(12);
        trace(a); // 12
    }
}
```
