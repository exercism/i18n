Te han encargado escribir un servicio que recibe eventos. Cada evento tiene una fecha asociada, pero notas que se están enviando 3 formatos diferentes al endpoint de tu servicio:

- `"01/01/1970"`
- `"January 1, 1970"`
- `"Thursday, January 1, 1970"`

Puedes ver que hay algunas similitudes entre ellos y decides escribir algunos patrones de expresiones regulares que puedas componer.

## 1. Haz coincidir el día, el mes y el año de una fecha

Implementa `day`, `month` y `year` para que devuelvan un patrón de string que, al ejecutarse, coincida con los componentes numéricos de `"01/01/1970"` (`dd/mm/yyyy`). El día y el mes pueden aparecer como `1` o `01` (con ceros a la izquierda).

No te preocupes por la verificación de errores. Puedes asumir que siempre te pasarán un componente numérico válido.

```clojure
(day "31")
;;=> "31"
(month "12")
;;=> "12"
(year "1970")
;;=> "1970"
```

## 2. Haz coincidir el día de la semana y el mes del año

Implementa `day-name` y `month-name` para que devuelvan un patrón de string que, al ejecutarse, coincida con cualquier día de la semana con nombre y con el mes del año con nombre, respectivamente.

```clojure
(day-name "Tuesday")
;;=> "Tuesday"
(month-name "June")
;;=> "June"
```

## 3. Captura el día, el mes y el año

Implementa `capture-day`, `capture-month`, `capture-year`, `capture-day-name` y `capture-month-name` para que devuelvan un mapa que asocie los componentes respectivos con los nombres: `"day"`, `"month"`, `"year"`, `"day-name"`, `"month-name"`.

```clojure
(capture-month-name "December")
;;=> {:month-name "December"}
```

## 4. Combina las capturas para capturar la fecha completa

Implementa `capture-numeric-date`, `capture-month-name-date` y `capture-day-month-name-date` para que devuelvan un mapa con los componentes de la parte 3 usando el formato de fecha correspondiente.

```clojure
(capture-numeric-date "01/01/1970")
;;=> {:day "01", :month "01", :year "1970"}
```
