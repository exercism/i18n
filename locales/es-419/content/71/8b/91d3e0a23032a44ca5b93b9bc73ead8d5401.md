# Instrucciones

En este ejercicio, vas a administrar un sistema de inventario.

El inventario debe estar organizado por el nombre del artículo y debe llevar un registro de la cantidad de artículos disponibles.

Tendrás que encargarte de agregar artículos a un inventario.
Cada vez que un artículo aparece en una lista dada, la cantidad de ese artículo en el inventario debe aumentar en `1`.
También tendrás que encargarte de eliminar artículos de un inventario disminuyendo las cantidades en `1` cuando se te pida.

Finalmente, tendrás que implementar una función que devuelva todos los pares clave-valor de un inventario dado como una `list` de `tuples`.


## 1. Crea un inventario a partir de una lista

Implementa la función `create_inventory(<input list>)` que crea un «inventario» a partir de una lista de artículos de entrada.
Debe devolver un `dict` que contenga cada nombre de artículo junto con su cantidad respectiva.

```python
>>> create_inventory(["coal", "wood", "wood", "diamond", "diamond", "diamond"])
{"coal":1, "wood":2, "diamond":3}
```

## 2. Agrega artículos de una lista a un diccionario existente

Implementa la función `add_items(<inventory dict>, <item list>)` que agrega una lista de artículos al inventario que recibe:

```python
>>> add_items({"coal":1}, ["wood", "iron", "coal", "wood"])
{"coal":2, "wood":2, "iron":1}
```

## 3. Decrementa artículos del inventario

Implementa la función `decrement_items(<inventory dict>, <items list>)` que recibe una `list` de artículos.
Tu función debe quitar `1` al conteo de un artículo por cada vez que ese artículo aparezca en la `list`:

```python
>>> decrement_items({"coal":3, "diamond":1, "iron":5}, ["diamond", "coal", "iron", "iron"])
{"coal":2, "diamond":0, "iron":3}
```

No se debe permitir que los conteos de artículos en el inventario caigan por debajo de 0.
 Si el número de veces que un artículo aparece en la `list` de entrada supera el conteo disponible, la cantidad registrada para ese artículo debe permanecer en 0.
 Las solicitudes adicionales para quitar conteos deben ignorarse una vez que el conteo llegue a cero.

```python
>>> decrement_items({"coal":2, "wood":1, "diamond":2}, ["coal", "coal", "wood", "wood", "diamond"])
{"coal":0, "wood":0, "diamond":1}
```

## 4. Elimina una entrada del inventario por completo

Implementa la función `remove_item(<inventory dict>, <item>)` que elimina por completo un artículo y su conteo de un inventario:

```python
>>> remove_item({"coal":2, "wood":1, "diamond":2}, "coal")
{"wood":1, "diamond":2}
```

Si el artículo no se encuentra en el inventario, la función debe devolver el inventario original sin cambios.

```python
>>> remove_item({"coal":2, "wood":1, "diamond":2}, "gold")
{"coal":2, "wood":1, "diamond":2}
```

## 5. Devuelve todo el contenido del inventario

Implementa la función `list_inventory(<inventory dict>)` que recibe un inventario y devuelve una lista de tuplas `(item, quantity)`.
La lista solo debe incluir los artículos _disponibles_ (_con una cantidad mayor que cero_):

```python
>>> list_inventory({"coal":7, "wood":11, "diamond":2, "iron":7, "silver":0})
[('coal', 7), ('diamond', 2), ('iron', 7), ('wood', 11)]
```
