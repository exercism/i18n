# Tests

## Ejecutar los tests

Cuando estás en el directorio de un ejercicio, deberías ver dos subdirectorios:

* `Sources/<Exercise>` contiene tu solución al ejercicio
* `Tests/<Exercise>Tests` contiene los tests que hay que ejecutar para el ejercicio

Si estás en el directorio correcto (es decir, el que contiene `Sources` y `Tests`), puedes ejecutar los tests de ese ejercicio con `swift test`:

```bash
$ pwd
/Users/johndoe/Code/exercism/swift/hello-world

$ ls
HELP.md  Package.swift  README.md  Sources  Tests

$ swift test
```

Cuando consigas que un test pase, elimina `.enabled(if: RUNALL)` en la sentencia `@Test` para habilitar el siguiente test; como alternativa, puedes ejecutar todos los tests con la variable de entorno `RUNALL` establecida en `true` en Linux o macOS:

```bash
$ export RUNALL=true
```

O si estás usando PowerShell en Windows:

```powershell
set RUNALL=true
```

## Enviar tu solución

Para subir una solución a Exercism, tienes que estar en el directorio que contiene los directorios `Sources` y `Tests`.

```bash
$ exercism submit 
```
