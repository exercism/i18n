# Acerca de

Haxe tiene tipado fuerte, pero su sistema de tipos se puede subvertir cuando sea necesario. Asignar un valor a un nombre se conoce como definir una variable. Una variable se puede definir especificando su tipo de forma explícita, o dejando que el compilador de Haxe infiera el tipo usando la [palabra clave `var`](var). Por lo tanto, las siguientes dos definiciones de variable son equivalentes:

```haxe
var explicitVariable:Int = 10; // Explicitly typed
var implicitVariable = 10; // Implicit typed
```

Actualizar una variable se puede hacer con el operador `=`:

```haxe
var number = 0; // Initial value
number = 1; // Updated value
```

El compilador lanzará un error al intentar asignar un valor cuyo tipo sea distinto al de la variable:

```haxe
var number = 1; // Variable number is of integer type
number = "Hello" // Error trying to assign a string to an integer variable
```

En Haxe, el código normalmente se escribe dentro de una _función_, también llamada [_método_](method). Estas funciones pueden recibir parámetros (argumentos) y devolver valores usando la palabra clave `return`. Las funciones se invocan usando la sintaxis `()`. Todas las funciones deben tener un tipo de retorno.

```haxe
function add(x:Int, y:Int):Int {
  return x + y;
}
```

El ámbito en Haxe se define entre los caracteres `{` y `}`.

Haxe admite dos tipos de comentarios. Los de una sola línea van precedidos por `//`, y los comentarios multilínea se insertan entre `/*` y `*/`.
