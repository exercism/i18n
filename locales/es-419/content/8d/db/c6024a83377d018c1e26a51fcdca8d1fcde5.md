# Instructions

Dada una cadena de dígitos, calcula el producto más grande para una subcadena contigua de dígitos de longitud n.

Por ejemplo, para la entrada `'1027839564'`, el producto más grande para una serie de 3 dígitos es 270 (9 * 5 * 6), y el producto más grande para una serie de 5 dígitos es 7560 (7 * 8 * 3 * 9 * 5).

Ten en cuenta que estas series solo deben ocupar *posiciones adyacentes* en la entrada; los dígitos no tienen que ser *consecutivos numéricamente*.

Para la entrada `'73167176531330624919225119674426574742355349194934'`, el producto más grande para una serie de 6 dígitos es 23520.
