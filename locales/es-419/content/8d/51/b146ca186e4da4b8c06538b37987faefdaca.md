# Introducción

Un conjunto es una colección inmutable y sin orden de valores únicos. Todos los elementos de un conjunto deben ser del mismo tipo.

El módulo `gleam/set` define el tipo `Set` y proporciona funciones para trabajar con conjuntos.

Puedes transformar listas y conjuntos entre sí con `set.to_list` y `set.from_list`. El orden de los elementos de un conjunto no está garantizado.

```gleam
set.from_list([2, 3, 3, 3, 1, 1, 2])
// -> set.from_list([1, 2, 3])

set.to_list(set.from_list([2, 3, 3, 3, 1, 1, 2]))
// -> [1, 2, 3]
```

Puedes crear y poblar conjuntos con `set.new`, `set.insert` y `set.delete`.

```gleam
set.new()
// -> set.from_list([])

let eighty_eight = set.from_list([88])

set.insert(eighty_eight, 88)
// -> set.from_list([88])

set.insert(eighty_eight, 89)
// -> set.from_list([88, 89])

set.delete(eighty_eight, 88)
// -> set.from_list([])

set.delete(eighty_eight, 89)
// -> set.from_list([88])
```

Puedes consultar el contenido de un conjunto con las funciones `set.contains` y `set.size`.

```gleam
set.contains(eighty_eight, 88)
// -> True

set.size(eighty_eight)
// -> 1
```

Puedes combinar conjuntos con `set.union` y `set.intersect`.

```gleam
let a = set.from_list([1, 5, 10])
let b = set.from_list([1, 2, 3, 4, 5])

set.union(a, b)
// -> set.from_list([1, 2, 3, 4, 5, 10])

set.intersection(a, b)
// -> set.from_list([1, 5])
```

Puedes filtrar conjuntos.

```gleam
let is_small = fn(n) { x <= 3 }

set.filter(b, is_small)
// -> set.from_list([1, 2, 3])
```
