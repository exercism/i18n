# Instrucciones

Te encanta observar aves y llevas la cuenta de cuántas han visitado tu jardín en un día cualquiera.

Decidiste llevar tu observación de aves a otro nivel e implementar algunas herramientas que te ayuden a rastrear y procesar los datos.

Elegiste guardar los datos como un array de números enteros.
El primer número del array es la cantidad de aves que visitaron tu jardín hoy, el segundo la de ayer, y así sucesivamente.

```exercism/note
En aplicaciones del mundo real, siempre deberías usar los módulos del núcleo cuando sea posible; sin embargo, con el propósito de aprender sobre recursión, no uses ninguna de las funciones de `List` en este ejercicio.
```

## 1. Revisa cuántas aves visitaron hoy

Implementa la función `today`.
Debe tomar un array con el conteo diario de aves y devolver el conteo de hoy.
Si el array está vacío, debe devolver `Nothing`; de lo contrario, el conteo vendrá envuelto en un `Just`.

```elm
BirdCount.today [2, 5, 1]
    -- Just 2
```

## 2. Incrementa el conteo de hoy

Implementa la función `incrementDayCount`.
Debe tomar un array con el conteo diario de aves e incrementar el conteo de hoy en 1.
Si el array está vacío, devuelve `[1]`.

```elm
BirdCount.incrementDayCount [4, 0, 2]
    -- [5, 0, 2]
```

## 3. Revisa si hubo un día sin aves visitantes

Implementa la función `hasDayWithoutBirds`.
Debe tomar un array con el conteo diario de aves.
Debe devolver `True` si hubo al menos un día en que ninguna ave visitó el jardín, y `False` en caso contrario.

```elm
BirdCount.hasDayWithoutBirds [2, 0, 4]
    -- True

BirdCount.hasDayWithoutBirds [3, 8, 1, 5]
    -- False
```

## 4. Calcula la cantidad total de aves visitantes

Implementa la función `total`.
Debe tomar un array con el conteo diario de aves y devolver la cantidad total que visitaron tu jardín desde que empezaste a recopilar los datos.

```elm
BirdCount.total [4, 0, 9, 0, 5]
    -- 18
```

## 5. Calcula la cantidad de días ajetreados

Algunos días son más ajetreados que otros.
Un día ajetreado es aquel en el que cinco o más aves visitaron tu jardín.

Implementa la función `busyDays`.
Debe tomar un array con el conteo diario de aves y devolver la cantidad de días ajetreados.

```elm
BirdCount.busyDays [4, 5, 0, 0, 6]
    -- 2
```
