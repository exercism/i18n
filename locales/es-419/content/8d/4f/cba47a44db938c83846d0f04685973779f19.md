# Introducción

Todas las funciones del [módulo `Enum`][exercism-enum] son _inmediatas_. Cuando realizas varias operaciones sobre enumerables con el módulo `Enum`, cada operación va a generar un resultado intermedio.

El módulo `Stream` es una alternativa _perezosa_ al módulo `Enum`, que es _inmediato_. Ofrece muchas de las mismas funciones que `Enum`, pero en lugar de generar resultados intermedios, construye una serie de cálculos que solo se ejecutan una vez que el stream se pasa a una función del módulo `Enum`.

Los streams implementan el _[protocolo][exercism-protocols] Enumerable_ y son componibles: puedes encadenarlos para crear funcionalidades más complejas.

[exercism-enum]: https://exercism.org/tracks/elixir/concepts/enum
[exercism-protocols]: https://exercism.org/tracks/elixir/concepts/protocols
