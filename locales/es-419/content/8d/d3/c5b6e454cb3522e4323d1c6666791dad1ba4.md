# Instrucciones

En este ejercicio implementarás la lógica de la misión de un nuevo juego de rol que está desarrollando un amigo.
El personaje principal del juego es Annalyn, una chica valiente con una mascota feroz y leal, el perro Kazak.
En un momento dado los embosca un monstruo, al que atacan.

## 1. Define attackWithSword1

Define `attackWithSword1`.
Esta debe recibir un `MonsterDamage` (un `String` que describe el daño al monstruo) y un `Int` que indica cuán fuerte es el ataque.
Debe devolver el string existente, con «Attacked with sword of strength {strength}.» agregado al final.

## 2. Define attackWithClaw1

Define `attackWithClaw1`.
Esta debe recibir un `MonsterDamage` y un `Int` que indica cuán fuerte es el ataque.
Debe devolver el string existente, con «Attacked with claw of strength {strength}.» agregado al final.

## 3. Define attack1

Annalyn ataca con una espada y tiene una fuerza de 5.

Su fiel mascota, el perro Kazak, ataca con sus garras y tiene una fuerza de 1.

Define `attack1`. Esta debe recibir un `MonsterDamage` y realizar los siguientes ataques, en el orden correcto:

- Annalyn
- Kazak
- Kazak
- Annalyn

La implementación de esta función será un poco engorrosa, ya que `attackWithSword1` y `attackWithClaw1` no tienen la estructura de datos principal (`MonsterDamage`) como último parámetro (no lo hacen de la manera recomendada).
No es posible ni recomendable usar la aplicación parcial en este caso inicial.

## 4. Define attackWithSword2

Define `attackWithSword2`.
Es lo mismo que `attackWithSword1`, salvo que los parámetros están intercambiados.

## 5. Define attackWithClaw2

Define `attackWithClaw2`.
Es lo mismo que `attackWithClaw2`, salvo que los parámetros están intercambiados.

## 6. Define attack2

Define `attack2`.

Esto es lo mismo que `attack1`, pero debe usar `attackWithSword2` y `attackWithClaw2`.

Implementa la función usando [aplicación parcial][partial-application] y el [operador de tubería `(|>)`][pipe-operator].
Ahora la implementación debería ser más elegante, ya que `attackWithSword2` y `attackWithClaw2` tienen `MonsterDamage` (la estructura de datos principal) como último parámetro, tal como se recomienda.

## 7. Define attack3

Define `attack3`.

Esto es lo mismo que `attack2`, pero debe implementarse usando composición de funciones / el operador [`(>>)`][forward-composition].

Esta implementación también debería ser elegante y más pequeña que `attack2`, aunque posiblemente más difícil de entender.
