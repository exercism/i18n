# Pistas

## 1. Crea un nuevo residente

- Vuelve a consultar el [concepto de struct](/tracks/go/concepts/structs) para saber cómo crear structs.

## 2. Valida la información del residente

- El valor cero de un string es `""`.
- El valor cero de un map es `nil`.
- Vuelve a consultar el [concepto de maps](/tracks/go/concepts/maps) para saber cómo determinar si existe una clave en un map.

## 3. Elimina la información del residente

- Se considera que un residente está eliminado cuando todos sus campos se establecen en su valor cero.
- Vuelve a consultar el [concepto de valores cero](/tracks/go/concepts/zero-values) para conocer el valor cero de cada tipo de Go.

## 4. Cuenta a los residentes

- Vuelve a consultar el [concepto de iteración con range](/tracks/go/concepts/range-iteration) para saber cómo recorrer un slice con range.
