# Instrucciones

En este ejercicio vas a jugar con un auto a control remoto, para el que por fin ahorraste suficiente dinero para comprarlo.

Los autos empiezan con la batería llena (100%). Cada vez que conduces el auto con el control remoto, recorre 20 metros y consume uno por ciento de la batería. El apodo del auto no se conoce hasta que se crea.

El auto a control remoto tiene una elegante pantalla LED que muestra dos datos:

- La distancia total que ha recorrido, mostrada como: `"<METERS> meters"`.
- La carga restante de la batería, mostrada como: `"Battery at <PERCENTAGE>%"`.

Si la batería está al 0%, ya no puedes conducir el auto y la pantalla de la batería mostrará `"Battery empty"`.

## 1. Crea un auto a control remoto totalmente nuevo

Implementa la función `RemoteControlCar.new/0` para que devuelva un struct de auto a control remoto totalmente nuevo:

```elixir
RemoteControlCar.new()
# => %RemoteControlCar{
#      battery_percentage: 100,
#      distance_driven_in_meters: 0,
#      nickname: "none"
#    }
```

El struct requiere el apodo; asegúrate de inicializar un valor en la función `new`, pero no en el struct.

## 2. Crea un auto a control remoto totalmente nuevo con un apodo

Implementa la función `RemoteControlCar.new/1` para que devuelva un struct de auto a control remoto totalmente nuevo con un apodo proporcionado:

```elixir
RemoteControlCar.new("Blue")
# => %RemoteControlCar{
#      battery_percentage: 100,
#      distance_driven_in_meters: 0,
#      nickname: "Blue"
#    }
```

## 3. Muestra la distancia

Implementa la función `RemoteControlCar.display_distance/1` para que devuelva la distancia tal como se muestra en la pantalla LED:

```elixir
car = RemoteControlCar.new()
RemoteControlCar.display_distance(car)
# => "0 meters"
```

Asegúrate de que la función solo acepte un struct `RemoteControlCar` como argumento.

## 4. Muestra el porcentaje de batería

Implementa la función `RemoteControlCar.display_battery/1` para que devuelva el porcentaje de batería tal como se muestra en la pantalla LED:

```elixir
car = RemoteControlCar.new()
RemoteControlCar.display_battery(car)
# => "Battery at 100%"
```

Asegúrate de que la función solo acepte un struct `RemoteControlCar` como argumento. Si la batería está al 0%, la pantalla de la batería mostrará "Battery empty".

## 5. Conducir cambia la batería y la distancia recorrida

Implementa la función `RemoteControlCar.drive/1` que:

- aumente en 20 la cantidad de metros recorridos
- consuma el 1% de la batería

```elixir
RemoteControlCar.new("Red")
|> RemoteControlCar.drive()

# => %RemoteControlCar{
#      battery_percentage: 99,
#      distance_driven_in_meters: 20,
#      nickname: "Red"
#    }
```

Asegúrate de que la función solo acepte un struct `RemoteControlCar` como argumento.

## 6. Ten en cuenta la conducción con la batería agotada

Actualiza la función `RemoteControlCar.drive/1` para que no aumente la distancia recorrida ni disminuya el porcentaje de batería cuando la batería esté descargada (al 0%):

```elixir
%RemoteControlCar{
  battery_percentage: 0,
  distance_driven_in_meters: 1980,
  nickname: "Red"
}
|> RemoteControlCar.drive()

# => %RemoteControlCar{
#      battery_percentage: 0,
#      distance_driven_in_meters: 1980,
#      nickname: "Red"
#    }
```
