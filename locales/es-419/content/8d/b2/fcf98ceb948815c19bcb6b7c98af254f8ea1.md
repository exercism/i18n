# Instrucciones

Tu amigo Linus es ingeniero de locomotoras y conduce trenes de carga entre ciudades. Aunque es increíble manejando trenes, no se le dan tan bien la logística ni las computadoras. Le gustaría contar con tu ayuda como programador para organizar los detalles de los trenes y corregir errores en los datos de las rutas.

~~~~exercism/note
Este ejercicio podría resolverse fácilmente usando slicing, indexación y varios métodos de `Dict`. Sin embargo, nos gustaría que practiques el empaquetado (es decir, *slurping*), el desempaquetado (es decir, *splatting*) y la asignación múltiple al resolver cada una de las tareas a continuación.
~~~~

## 1. Crea un vector con todos los vagones

Tu amigo ha estado llevando un registro del identificador (ID) de cada vagón, pero nunca está seguro de cuántos vagones tendrá que procesar el sistema en un momento dado. Sería mucho más fácil para el resto del programa de logística tener estos datos empaquetados en un único `Vector`.

Implementa una función `get_vector_of_wagons(args...)` que acepte una cantidad arbitraria de IDs de vagones.
Cada ID será un número entero positivo.
La función debe entonces devolver (`return`) los IDs dados como un único `Vector`.

```julia-repl
julia> get_vector_of_wagons(1, 7, 12, 3, 14, 8, 5)
7-element Vector{Int64}:
  1
  7
 12
  3
 14
  8
  5
```

## 2. Corrige el vector de vagones

En este punto, ya empiezas a familiarizarte con los datos y con cómo se usan en el programa de logística.
El sistema de IDs siempre le asigna a la locomotora el ID **1**, y al resto de los vagones del tren les asigna un ID elegido al azar mayor que **1**.

¡Tu amigo tuvo que conectar dos vagones nuevos al tren y olvidó actualizar el sistema!
Ahora, los dos primeros vagones del `Vector` del tren deben moverse al final, o todo quedará fuera de orden.

Para complicar más las cosas, tu amigo acaba de encontrar un segundo `Vector` que parece contener los IDs de vagones que faltan.
Lo único que recuerda es que, una vez movidos los vagones nuevos, los IDs de este segundo `Vector` deben colocarse justo después de la locomotora designada.

Linus te estaría muy agradecido por corregir sus errores y consolidar los datos.

Implementa una función `fix_vector_of_wagons(each_wagons_id, missing_wagons)` que reciba dos `Vectors` con IDs de vagones.
Debe reubicar los dos primeros elementos del primer `Vector` al final, e insertar los valores del segundo `Vector` detrás (_a la derecha_) del ID de la locomotora (**1**).
La función debe entonces devolver (`return`) un `Vector` con las modificaciones.

```julia-repl
julia> fix_vector_of_wagons([2, 5, 1, 7, 4, 12, 6, 3, 13], [3, 17, 6, 15])
13-element Vector{Int64}:
  1
  3
 17
  6
 15
  7
  4
 12
  6
  3
 13
  2
  5
```

## 3. Agrega las paradas que faltan

Ahora que todos los datos de los vagones son correctos, a Linus le gustaría que actualices la información de rutas del sistema.
A lo largo de una ruta de transporte, un tren puede hacer paradas en varias estaciones distintas para recoger o dejar carga.
Cada viaje podría tener una cantidad diferente de estos puntos intermedios de entrega.
A tu amigo le gustaría que actualices el `Dict` de rutas del sistema con cualquier información de entrega que falte o que sea adicional.

Implementa una función `add_missing_stops(route, stops...)` que acepte un `Dict` de rutas seguido de una cantidad variable de Pares `stop_number => city`.
Tu función debe entonces devolver el `Dict` de rutas actualizado con un `key` adicional que contenga un `Vector` con todas las paradas agregadas, en orden.

```julia-repl
julia> add_missing_stops(Dict("from" => "New York", "to" => "Miami"), :stop_1 => "Washington, DC", :stop_2 => "Charlotte", :stop_3 => "Atlanta", :stop_4 => "Jacksonville")
Dict{String, Any} with 3 entries:
  "stops" => ["Washington, DC", "Charlotte", "Atlanta", "Jacksonville"]
  "to"    => "Miami"
  "from"  => "New York"
```

## 4. Extiende la información de rutas

Linus ha estado trabajando en el programa de rutas y se ha dado cuenta de que a ciertas rutas les faltan algunos detalles importantes.
La información inicial de la ruta se ha construido como un `Dict` y a tu amigo le gustaría que actualices ese `Dict` con lo que pueda faltar.
Cada ruta del sistema requiere detalles un poco distintos, así que Linus preferiría mucho una solución genérica.

Implementa una función llamada `extend_route_information(route; more_route_information...)` que acepte un `Dict` que contenga las ciudades de origen y destino entre las que corre la ruta del tren, además de una cantidad variable de argumentos de palabra clave que contengan detalles de la ruta, como la velocidad del tren, la longitud o la temperatura.
La función debe devolver un `Dict` consolidado con toda la información de la ruta.

```julia-repl
julia> extend_route_information(Dict("from" => "Berlin", "to" => "Hamburg"); length = "100", speed = "50")
Dict{Any, String} with 4 entries:
  :speed  => "50"
  "to"    => "Hamburg"
  "from"  => "Berlin"
  :length => "100"


julia> extend_route_information(Dict("from" => "Paris", "to" => "London"), length = "15", temperature = "20", timeOfArrival = "10:30")
Dict{Any, String} with 5 entries:
  :temperature   => "20"
  :timeOfArrival => "10:30"
  "to"           => "London"
  "from"         => "Paris"
  :length        => "15"
```
