# Instrucciones

Eres un elfo que trabaja en la división de logística de Santa Claus y el jefe te ha encargado un par de tareas para actualizar el software del sistema.

## 1. Obtener el nombre del juguete

El sistema necesita poder obtener el nombre de un juguete de la base de datos.
La base de datos está hecha de tuplas de tipo `(name: String, quantity: Int)`.

Implementa la función `getName(_:)`, que recibe un argumento que contiene una tupla de tipo `(name: String, quantity: Int)`.

```swift
let toy = (name: "Doll", quantity: 10)
getName(toy)
// Returns "Doll"
```

## 2. Agregar un nuevo juguete a la base de datos

El mercado de juguetes es un mercado rápido y cambiante; lo que es popular cambia muy rápido.
Por eso se necesita una función que cree un nuevo juguete.

Implementa la función `createToy(name:amount:)`, que recibe un argumento `name` que contiene el nombre del juguete y `amount` que contiene la cantidad del juguete.

```swift
createToy(name: "Doll", amount: 10)
// Returns (name: "Doll", amount: 10)
```

## 3. Actualizar la cantidad de un juguete

Los elfos en el taller de Santa están constantemente haciendo más juguetes, y Santa necesita llevar un registro de la cantidad de cada juguete.
Para hacerlo, el sistema necesita poder actualizar la cantidad de un juguete en la base de datos.

Implementa la función `updateQuantity(_:toy:Amount:)`, que recibe los argumentos:
- `toys`, que contiene un array de tuplas de tipo `(name: String, quantity: Int)`.
- `toy`, que contiene el nombre del juguete a actualizar.
- `amount`, que contiene la nueva cantidad del juguete.

Puedes asumir que el juguete ya está en la base de datos y no necesitas verificarlo.

```swift
let toys = [(name: "Doll", quantity: 10), (name: "Car", quantity: 5), (name: "Train", quantity: 3)]
updateQuantity(toys, toy: "Doll", amount: 15)
// Returns [(name: "Doll", quantity: 15), (name: "Car", quantity: 5), (name: "Train", quantity: 3)]
```

## 4. Agregar la clave de categoría a un juguete

Santa quiere poder categorizar los juguetes en la base de datos.
Esto es para que puedan encontrar fácilmente los juguetes cuando necesiten hacer una entrega, y para poder ordenar los juguetes en la base de datos.

Sin embargo, cuando el sistema se implementó por primera vez, se olvidó la clave de categoría.
Ahora el sistema necesita poder agregar una clave de categoría a un juguete en la base de datos.

Implementa la función `addCategory(_:category:)`, que recibe los argumentos:
- `toys`, que contiene un array de tuplas de tipo `(name: String, quantity: Int)`.
- `category`, que contiene la clave de categoría que se agregará a los juguetes.

Puedes asumir que el juguete ya está en la base de datos y no necesitas verificarlo.
También puedes asumir que todavía no hay una clave de categoría en el juguete.

```swift
let toys = [(name: "Car", quantity: 5), (name: "Train", quantity: 3)]
addCategory(toys, category: "Vehicle")
// Returns [(name: "Car", quantity: 5, category: "Vehicle"), (name: "Train", quantity: 3, category: "Vehicle")]
```
