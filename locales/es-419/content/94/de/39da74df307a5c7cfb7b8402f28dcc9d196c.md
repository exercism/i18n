# Instrucciones

En este ejercicio, implementarás la lógica de la misión de un nuevo juego de rol que un amigo está desarrollando.

La protagonista del juego es Annalyn, una chica valiente que tiene un perro feroz y leal. Lamentablemente, todo se complica: su mejor amigo fue secuestrado mientras buscaba bayas en el bosque.

Annalyn intentará encontrar y liberar a su mejor amigo, y para ello puede llevar consigo a su perro.

Después de pasar un tiempo siguiendo el rastro de su mejor amigo, encuentra el campamento donde está prisionero. Resulta que hay dos secuestradores: un caballero poderoso y un arquero astuto.

Una vez que encuentra a los secuestradores, Annalyn piensa en cuál de las siguientes acciones puede realizar:

- _Ataque rápido_: se puede hacer un ataque rápido si el caballero está dormido, ya que tarda un tiempo en ponerse la armadura, así que estará vulnerable.
- _Espiar_: se puede espiar al grupo si al menos uno de ellos está despierto. De lo contrario, espiar es una pérdida de tiempo.
- _Hacer señales al prisionero_: se le pueden hacer señales al prisionero usando sonidos de aves si el prisionero está despierto y el arquero está dormido, ya que los arqueros están entrenados en las señales con aves, así que podrían interceptar el mensaje.
- _Liberar al prisionero_: Annalyn puede intentar colarse en el campamento para liberar al prisionero.
  Es una acción arriesgada y solo puede salir bien de una de dos maneras:
  - Si Annalyn lleva consigo a su perro, puede rescatar al prisionero si el arquero está dormido.
    El caballero le tiene miedo al perro y el arquero no tendrá tiempo de prepararse antes de que Annalyn y el prisionero escapen.
  - Si Annalyn no lleva a su perro, ¡ella y el prisionero tendrán que ser muy sigilosos!
    Annalyn puede liberar al prisionero si el prisionero está despierto y el caballero y el arquero están dormidos, pero si el prisionero está dormido no se lo puede rescatar: el prisionero se asustaría con la aparición repentina de Annalyn y despertaría al caballero y al arquero.

Tienes cuatro tareas: implementar la lógica para determinar si las acciones anteriores están disponibles según el estado de los tres personajes que se encuentran en el bosque y según si el perro de Annalyn está presente o no.

## 1. Comprobar si se puede hacer un ataque rápido

Implementa el método `canFastAttack()` que toma un valor Boolean que indica si el caballero está despierto. Este método devuelve `true` si se puede hacer un ataque rápido según el estado del caballero. De lo contrario, devuelve `false`:

```haxe
var knightIsAwake = true;
canFastAttack(knightIsAwake);
// => false
```

## 2. Comprobar si se puede espiar al grupo

Implementa el método `canSpy()` que toma tres valores Boolean que indican si el caballero, el arquero y el prisionero, respectivamente, están despiertos. El método devuelve `true` si se puede espiar al grupo, según el estado de los tres personajes. De lo contrario, devuelve `false`:

```haxe
var knightIsAwake = false;
var archerIsAwake = true;
var prisonerIsAwake = false;
canSpy(knightIsAwake, archerIsAwake, prisonerIsAwake);
// => true
```

## 3. Comprobar si se le pueden hacer señales al prisionero

Implementa el método `canSignalPrisoner()` que toma dos valores Boolean que indican si el arquero y el prisionero, respectivamente, están despiertos. El método devuelve `true` si se le pueden hacer señales al prisionero, según el estado de los dos personajes. De lo contrario, devuelve `false`:

```haxe
var archerIsAwake = false;
var prisonerIsAwake = true;
canSignalPrisoner(archerIsAwake, prisonerIsAwake);
// => true
```

## 4. Comprobar si se puede liberar al prisionero

Implementa el método `canFreePrisoner()` que toma cuatro valores Boolean. Los primeros tres parámetros indican si el caballero, el arquero y el prisionero, respectivamente, están despiertos. El último parámetro indica si el perro de Annalyn está presente. El método devuelve `true` si se puede liberar al prisionero según el estado de los tres personajes y la presencia del perro de Annalyn. De lo contrario, devuelve `false`:

```haxe
var knightIsAwake = false;
var archerIsAwake = true;
var prisonerIsAwake = false;
var petDogIsPresent = false;
canFreePrisoner(knightIsAwake, archerIsAwake, prisonerIsAwake, petDogIsPresent);
// => false
```
