# Introducción

En el concepto `Types`, aprendimos que:

- Los tipos en Julia forman una jerarquía.
- Cada tipo tiene un supertipo.
- `Any` está en la cima de la jerarquía y es su propio supertipo.
- Los tipos _pueden_ tener subtipos, y aquellos que los tienen se llaman `abstract types`.
- Los tipos sin subtipos (nodos hoja del árbol) se llaman `concrete types`.
- Los tipos indivisibles, como `Char` o `Int64`, se llaman `primitive types`.

Solo los tipos `primitive` siguen el patrón de abstracto versus concreto en su forma simple.
`Vector` es una colección, separable en elementos con su propio tipo.

```julia-repl
julia> isprimitivetype(Int)
true

julia> isprimitivetype(Vector)
false
```

_¿Una colección de qué?_

Cada vector (o conjunto) es una colección de elementos con algún tipo uniforme, que se puede especificar con un _parámetro_ entre llaves `{ }`, u omitir para que la inferencia de tipos lo determine.

```julia-repl
julia> v = [1, 2, 3]
3-element Vector{Int64}:
 1
 2
 3

julia> v8 = Vector{Int8}([2, 4, 6])
3-element Vector{Int8}:
 2
 4
 6
```

Estos `parametric types` son una forma de `generic programming`, y muchos lenguajes modernos tienen algo más o menos equivalente, aunque con muchas diferencias en los detalles.

## Tipos compuestos paramétricos

A veces queremos crear un tipo compuesto lo bastante flexible (genérico) como para manejar distintos tipos de campos.

Esto se puede lograr con un tipo ficticio en la definición, que normalmente se llama `T`.

```julia-repl
julia> struct Point{T}
               x::T
               y::T
       end

# high definition version

julia> real_point = Point(7.3, 4.2)
Point{Float64}(7.3, 4.2)

julia> typeof(real_point)
Point{Float64}

# low definition version

julia> int8point = Point{Int8}(17, 23)
Point{Int8}(17, 23)

julia> typeof(int8point)
Point{Int8}

julia> Point(Int8(17), Int8(23))
Point{Int8}(17, 23)
```

Naturalmente, este enfoque también funciona con colecciones en los campos:

```julia-repl
julia> struct Record{T}
           data::Vector{T}
           comment::String
       end

julia> rec = Record{Float64}([1.3, 5.2], "some data")
Record{Float64}([1.3, 5.2], "some data")

julia> rec.data
2-element Vector{Float64}:
 1.3
 5.2

julia> rec2 = Record{Int32}([3, 5], "more data")
Record{Int32}(Int32[3, 5], "more data")

julia> rec2.data
2-element Vector{Int32}:
 3
 5
```
