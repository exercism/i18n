# Introducción

En Cairo, los Boolean se representan con el tipo Boolean predeclarado `bool`, que puede tomar los valores `true` o `false`.

```rust
let speeding = true;   // Boolean variable 'speeding' set to 'true'
let has_error = false; // Boolean variable 'has_error' set to 'false' 
```

Cairo admite tres operadores lógicos que pueden evaluar expresiones hasta reducirlas a valores Boolean, y devuelven `true` o `false`.

| Operador    | Qué significa                                  |
| ----------- | --------------------------------------------- |
| `&&` (y)    | Es verdadero si ambas afirmaciones son verdaderas. |
| `\|\|` (o)  | Es verdadero si al menos una afirmación es verdadera. |
| `!` (no)    | Es verdadero solo si la afirmación es falsa.   |
