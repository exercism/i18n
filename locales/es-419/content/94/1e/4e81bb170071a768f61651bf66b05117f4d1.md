# Introducción

Un `str` en Python es una [secuencia inmutable][text sequence] de [puntos de código Unicode][unicode code points].
Estos pueden incluir letras, signos diacríticos, caracteres de posicionamiento, números, símbolos de moneda, emoji, puntuación, distintos tipos de espacios, saltos de línea y más.

Los strings implementan todas las [operaciones comunes de secuencias][common sequence operations] y se pueden recorrer con la sintaxis `for item in <str>` o `for index, item in enumerate(<str>)`.
Se pueden concatenar con `<str> + <other str>` o `<str>.join(<iterable>)`, dividir con `<str>.split(<separator>)`, y ofrecen varias opciones de formato y ensamblado.

Para trabajar aún más con los strings, Python ofrece un amplio conjunto de [métodos de string][str-methods] que pueden ayudar con la búsqueda, la limpieza, la transformación, la traducción y muchas otras operaciones.

Como es _inmutable_, el valor de un objeto `str` en memoria no cambia; los métodos que parecen modificar un string devuelven una nueva copia o instancia de ese objeto `str`.
