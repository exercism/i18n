# Anexo de instrucciones

Este ejercicio requiere que manejes excepciones. Una [excepción](https://docs.oracle.com/javase/tutorial/essential/exceptions/definition.html) es un evento que ocurre durante la ejecución de un programa y que interrumpe el flujo normal de las instrucciones del programa.

En Java existen dos tipos de excepciones: las comprobadas y las no comprobadas.

- [Excepciones comprobadas vs. no comprobadas en Java](https://www.geeksforgeeks.org/checked-vs-unchecked-exceptions-in-java/)

- [Excepciones no comprobadas: la controversia](https://docs.oracle.com/javase/tutorial/essential/exceptions/runtime.html)

## Excepciones comprobadas

Las excepciones comprobadas son las que se comprueban en [tiempo de compilación](https://en.wikipedia.org/wiki/Compile_time).

### Implicaciones prácticas

Tienes que declararlas en la [firma del método](https://docs.oracle.com/javase/tutorial/java/javaOO/methods.html) de cualquier método que pueda [lanzar](https://docs.oracle.com/javase/tutorial/essential/exceptions/throwing.html) una excepción comprobada, y manejarlas o volver a lanzarlas cuando llamas a cualquier método que pueda lanzar una excepción comprobada.

Esto se debe a que las excepciones comprobadas están pensadas para manejarse en tiempo de ejecución, es decir, son errores de los que puedes recuperarte.

### Ejemplos de dónde se usan

Suelen usarse cuando un método no puede devolver ningún resultado válido; por ejemplo, un método de búsqueda que no encontró el elemento que estaba buscando.

Son una alternativa a devolver null o un código de error. Una excepción comprobada es mejor que esas alternativas porque obliga a quien usa el método a considerar el caso de error.

## Excepciones no comprobadas

Las excepciones no comprobadas son las que no se comprueban en [tiempo de compilación](https://en.wikipedia.org/wiki/Compile_time).

### Implicaciones prácticas

No tienes que declararlas en la [firma del método](https://docs.oracle.com/javase/tutorial/java/javaOO/methods.html) de los métodos que puedan [lanzar](https://docs.oracle.com/javase/tutorial/essential/exceptions/throwing.html) una excepción no comprobada, ni manejarlas o volver a lanzarlas cuando llamas a cualquier método que pueda lanzar una excepción no comprobada.

### Ejemplos de dónde se usan

Las excepciones no comprobadas suelen deberse a defectos en el programa y pueden evitarse escribiendo bien el código. Ejemplo: ArrayIndexOutOfBoundsException puede evitarse asegurándose de que los índices del array estén entre 0 y la longitud del array.
