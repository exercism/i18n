# Introducción

En JavaScript, un arreglo es una estructura similar a una lista, sin longitud fija, que puede contener cualquier tipo de primitivas u objetos, incluso tipos mezclados.

Para crear un array, agrega elementos entre corchetes `[]`.
Para leer del array, coloca el índice entre corchetes `[]` después del identificador.
Los índices de un array empiezan en cero.

Por ejemplo:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers[2];
// => 3
```

Para obtener la cantidad de elementos que hay en un array, usa la propiedad `length`:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.length;
// => 4
```

Para cambiar un elemento del array, asignas un valor en el índice:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers[0] = 'one';
numbers;
// => ['one', 'two', 3, 'four']
```

## Métodos

Algunos de los [métodos][mdn-array] disponibles en todo objeto Array se pueden usar para agregar o quitar elementos del array.
Estos son algunos para tener en cuenta al resolver este ejercicio:

### push

Un `value` se puede _agregar_ al final de un array con `.push(value)`.
El método devuelve la nueva longitud del array.

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.push(5); // => 5
numbers;
// => [1, 'two', 3, 'four', 5]
```

### pop

El _último_ `value` se puede _quitar_ de un array con `.pop()`.
El método devuelve el valor eliminado.
La longitud del array disminuirá por este cambio.

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.pop(); // => four
numbers;
// => [1, 'two', 3]
```

### shift

El _primer_ `value` se puede _quitar_ de un array con `.shift()`.
El método devuelve el valor eliminado.
La longitud del array disminuirá por este cambio.

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.shift(); // => 1
numbers;
// => ['two', 3, 'four']
```

### unshift

Un `value` se puede _agregar_ al principio de un array con `.unshift(value)`.
El método devuelve la nueva longitud del array.

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.unshift('one'); // => 5
numbers;
// => ['one', 1, 'two', 3, 'four']
```

### splice

Un `value` en un `index` específico se puede _quitar_ de un array con `.splice(index, 1)`.
El método devuelve el o los elementos eliminados.

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.splice(2, 1, 'one'); // => [3]
numbers;
// => [1, 'two', 'one', 'four']
```

~~~exercism/advanced
Estos métodos son más potentes de lo que se describe aquí:

- Tanto `push` como `unshift` te permiten agregar varios valores a la vez, si agregas más argumentos.
  Eso no es necesario para completar este ejercicio.
- Splice puede quitar varios valores si aumentas el segundo argumento.
  Eso no es necesario para completar este ejercicio.
- Splice también puede agregar varios valores si los agregas como argumentos después del `deleteCount`.
  Esto se puede usar para reemplazar valores o insertar valores en medio de un array (por ejemplo, quitando 0 elementos).
  Eso no es necesario para completar este ejercicio.
~~~
