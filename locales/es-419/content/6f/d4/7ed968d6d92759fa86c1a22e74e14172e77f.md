# Pistas

## General

- Lee la documentación de [conjuntos][set]
- La documentación de [arrays][lists] también podría resultarte útil

## 1. Inicia una colección

- La función de `Set` más adecuada es [`Set.singleton`][singleton]

## 2. Haz crecer la colección

- Usa la [función `Set.insert`][insert]
- Usa la [función `Set.member`][member]

## 3. Empieza a intercambiar

- Usa la [función `Set.member`][member]
- Usa la [función `Set.insert`][insert]
- Usa la [función `Set.remove`][remove]

## 4. Solo puede haber uno de cada uno

- Un `Set` tiene la propiedad de contener solo valores únicos
- Usa la [función `Set.fromList`][fromList]
- Usa la [función `Set.toList`][toList]
- `Set.toList` garantiza devolver un array ordenado

## 5. Cartas que no tienen

- Usa la [función `Set.diff`][diff]
- Usa la [función `Set.size`][size]

## 6. Cartas que todos tienen

- Usa las [funciones `List.foldl` o `List.foldr`][fold]
- Usa coincidencia de patrones sobre el array para diferenciar los arrays vacíos de los no vacíos
- Usa la [función `Set.intersect`][intersect]
- Usa la [función `Set.toList`][toList]
- `Set.toList` garantiza devolver un array ordenado

## 7. Todas las cartas

- Usa las [funciones `List.foldl` o `List.foldr`][fold]
- Usa [`Set.empty`][empty] como acumulador
- Usa la [función `Set.union`][union]
- Usa la [función `Set.size`][size]

## 8. Brillantes para ganar

- Usa la [función `Set.partition`][partition]
- Usa la [función `String.startsWith`][startsWith]
- Usa la [función `Set.toList`][toList]
- `Set.toList` garantiza devolver un array ordenado
