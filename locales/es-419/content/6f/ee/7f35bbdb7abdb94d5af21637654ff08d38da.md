# Introducción

Un [`Set`][set] es una colección de elementos con las siguientes propiedades:

- Sin orden.
- Los elementos son únicos, por lo que los intentos de agregar duplicados se ignoran silenciosamente.
- Admite muchas de las operaciones habituales de los conjuntos matemáticos.

Créalos con el constructor `Set()`, usando cualquier iterador como parámetro.

```julia-repl
julia> s1 = Set(1:4)
Set([4, 2, 3, 1])
```

Agrega nuevos elementos con `push!()` (igual que con los arrays) y elimínalos con `delete!()`.

```julia-repl
julia> push!(s1, 5)
Set([5, 4, 2, 3, 1])

# Duplicates are ignored
julia> push!(s1, 3)
Set([5, 4, 2, 3, 1])

julia> delete!(s1, 5)
Set([4, 2, 3, 1])

julia> length(s1)  # length counts entries, despite the non-sequential type
4
```

## Operaciones con conjuntos

Al igual que con otros tipos de colecciones, comprueba la pertenencia con el operador `in` o `∈` (usa `\in` y luego tab para obtener el símbolo).

```julia-repl
julia> 3 ∈ s1
true
```

Se admiten las siguientes operaciones sobre pares de Sets (los atajos para el símbolo del operador se muestran entre paréntesis).

- `union(A, B)` o `A ∪ B` (`\cup`): todos los elementos que están en A, en B o en ambos.
- `intersect(A, B)` o `A ∩ B` (`\cap`): todos los elementos comunes a A y B.
- `setdiff(A, B)` (sin símbolo): los elementos que están en A pero no en B.
- `symdiff(A, B)` (sin símbolo): los elementos que están en A o en B, pero no en ambos.
- `issubset(A, B)` o `A ⊆ B` (`\subseteq`) o `B ⊇ A` (`\supseteq`): `true` si todos los elementos de A también están en B.
- `issetequal(A, B)` (sin símbolo): `true` si A y B contienen exactamente los mismos elementos.
- `isdisjoint(A, B)` (sin símbolo): `true` si A y B no tienen elementos en común (es decir, la intersección está vacía).

```julia-repl
julia> s1 = Set(1:4);
julia> s2 = Set(3:6);
julia> s1 ∪ s2  # union
Set([5, 4, 6, 2, 3, 1])

julia> s1 ∩ s2  # intersect
Set([4, 3])
  
julia> setdiff(s1, s2)
Set([2, 1])

julia> symdiff(s1, s2)
Set([5, 6, 2, 1])
  
julia> s1 ⊇ s2  # issubset
false
```

También existen versiones mutables de muchas de estas, con `!` agregado al nombre de la función.
Consulta el [manual][set] para ver la lista completa de funciones.
