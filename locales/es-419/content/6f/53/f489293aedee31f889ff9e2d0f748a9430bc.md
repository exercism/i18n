# Hints

## General

- No te preocupes por cómo se _derivan_ los argumentos; concéntrate en combinar los argumentos para devolver el resultado esperado.

## 0. Define un estado de la máquina

- Define una variable llamada `PowerOn` con un valor [Boolean][booleans] verdadero.

## 1. Define si Pac-Man puede comerse un fantasma

- Puedes usar el [operador][logical-operators] `-and` para combinar argumentos y obtener un resultado.


## 2. Define si Pac-Man anota

- Puedes usar el [operador][logical-operators] `-or` para combinar argumentos y obtener un resultado.


## 3. Define si Pac-Man pierde

- Puedes usar el [operador][logical-operators] `-not` para combinar argumentos y obtener un resultado.


## 4. Define si Pac-Man gana

- Combina los [operadores][logical-operators] anteriores para obtener el resultado.


## 5. Escribe SYNOPSIS para la condición de victoria

- Escribe una breve descripción en el bloque de comentarios de la última función `Win` usando la [palabra clave][keywords] `SYNOPSIS`.
