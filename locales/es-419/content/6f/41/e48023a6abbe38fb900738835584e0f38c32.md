# Instalación

## Instalar .NET

El track de F# se construye sobre la plataforma [.NET](https://dotnet.microsoft.com/learn/dotnet/what-is-dotnet), que se ejecuta en Windows, Linux y macOS. Para compilar proyectos de .NET, puedes usar la interfaz de línea de comandos (CLI) de .NET. Esta CLI forma parte del SDK de .NET, que puedes instalar siguiendo las [instrucciones de instalación](https://dotnet.microsoft.com/download). Nota: el track de F# requiere la versión 8.0 o superior del SDK.

Cuando termines la instalación, puedes verificar si la CLI se instaló correctamente ejecutando este comando en una terminal:

```bash
dotnet --version
```

Si la salida es una versión mayor o igual a `8.0.100`, el SDK de .NET se instaló correctamente.

## Usar un IDE

Si quieres una experiencia de edición más completa, probablemente quieras usar un IDE. Estos son los IDE más populares que admiten compilar proyectos de .NET:

- [Visual Studio 2022](https://www.visualstudio.com/downloads/)
- [Visual Studio Code](https://code.visualstudio.com/download) con la [extensión Ionide-fsharp](https://marketplace.visualstudio.com/items?itemName=Ionide.Ionide-fsharp)
- [Visual Studio for Mac](https://www.visualstudio.com/vs/visual-studio-mac/)
- [Project Rider](https://www.jetbrains.com/rider/download/)

Nota: como el formato de proyecto de .NET difiere bastante del de las versiones anteriores, los IDE más antiguos (como Visual Studio 2015) no son compatibles.
