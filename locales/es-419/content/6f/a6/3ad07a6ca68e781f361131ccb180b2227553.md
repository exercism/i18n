# Introducción

## Strings

Un `String` en Java es un objeto que representa una cadena de texto inmutable como una secuencia de caracteres Unicode (letras, dígitos, signos de puntuación, etc.).
Para definir una instancia de `String` se usan comillas dobles:

```java
String fruit = "Apple";
```

Los strings se manipulan llamando a los métodos del string.
Una vez que se ha construido un string, su valor nunca puede cambiar.
Cualquier método que parezca modificar un string en realidad devuelve un nuevo string.
La clase `String` proporciona algunos métodos _static_ para transformar los strings.
