# Introducción

## Boolean

Los booleanos en Java se representan con el tipo `boolean`, cuyos valores pueden ser `true` o `false`.

Java admite tres operadores booleanos:  

- `!` (NO): niega el valor booleano  
- `&&` (Y): toma dos valores booleanos y devuelve `true` si ambos son `true`
- `||` (O): devuelve `true` si cualquiera de los dos valores booleanos es `true`

### Ejemplos

```java
!true // => false
!false // => true
true && false // => false
true && true // => true
false || false // => false
false || true // => true
```
