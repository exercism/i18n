# Instalación

## Requisitos

* Una CPU x86 de 64 bits
* Un compilador de C moderno
* La herramienta de compilación Make
* El Netwide Assembler (NASM)

Ten en cuenta que este track solo admite la convención de llamada de la ABI System
V AMD64. Quienes usen Windows tendrán que instalar Windows Subsystem for Linux
(WSL), o bien configurar una máquina virtual de Linux.

## Linux

Instala el software necesario con el gestor de paquetes de tu sistema:

* Ubuntu, Debian: `$ sudo apt-get install gcc make nasm`
* Fedora: `$ sudo dnf install gcc make nasm`
* CentOS, RHEL: `$ sudo yum install gcc make nasm`
* Arch Linux: `$ sudo pacman -S gcc make nasm`
* OpenSUSE: `$ sudo zypper install gcc make nasm`

## macOS

Instala las Xcode Command Line Tools:

```bash
$ xcode-select --install
```

Instala NASM con [Homebrew](http://brew.sh/):

```bash
$ brew install nasm
```

## Windows

Para instalar WSL, consulta https://docs.microsoft.com/en-us/windows/wsl/install-win10.
