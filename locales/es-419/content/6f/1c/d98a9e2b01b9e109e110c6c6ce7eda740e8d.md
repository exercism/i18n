# Números de punto flotante

`FLTD` guarda un número que puede tener una fracción. Un literal necesita un punto decimal y una `d`:

```sather
   440.0d
   0.5d
   -2.25d
```

`FLT` es la misma idea con la mitad de la precisión. Este track usa `FLTD` en todo el contenido; no hay razón para recurrir a `FLT` a menos que la memoria sea escasa.

## Aritmética

| Operador | Significado |
| --- | --- |
| `+` `-` `*` | igual que para `INT` |
| `/` | división, conservando la fracción |

No hay un `%` para `FLTD`.

Ambos operandos deben ser `FLTD`. Mezclar un `INT` es un error de compilación, no una conversión silenciosa, lo cual es una funcionalidad: el único lugar donde esto pasa factura es justo donde la gente se equivoca.

## Conversión

```sather
   7.fltd            -- 7.0, an INT made into an FLTD
   7.5d.int          -- 7, the fraction thrown away
   7.5d.round        -- 8, to the nearest whole number
   7.5d.floor        -- 7.0, down to a whole number
   7.5d.ceiling      -- 8.0, up to a whole number
```

Convierte antes de dividir, nunca después: `n.fltd / 2.0d` conserva la mitad, `(n / 2).fltd` ya la perdió.

## Rutinas útiles

```sather
   (-2.5d).abs       -- 2.5
   2.0d.sqrt         -- 1.41421
   (2.0d).max(3.0d)  -- 3.0
```

## El punto flotante es aproximado

Un `FLTD` guarda una aproximación muy cercana, no el valor exacto. La mayoría de las fracciones decimales no se pueden almacenar de forma exacta, del mismo modo que un tercio no se puede escribir de forma exacta en decimal. Así que:

```sather
0.1d + 0.2d          -- very nearly 0.3, but not exactly
```

Dos consecuencias que vale la pena recordar:

**No compares con `=`.** Dos cálculos que deberían dar el mismo resultado a menudo difieren en los últimos dígitos. Mejor pregúntate si son cercanos:

```sather
   (a - b).abs < 0.0001d
```

**Sumar muchos valores pequeños pierde precisión.** Cada suma redondea un poco, y los errores se van acumulando.

Cuando los valores deban ser exactos, en particular el dinero, cuenta en unidades enteras con `INT` (centavos en lugar de dólares).

## Impresión

`.str` muestra unos seis dígitos significativos, que es menos que la precisión que en realidad se guarda:

```sather
   #OUT + (1.0d / 3.0d).str;      -- 0.333333
```
