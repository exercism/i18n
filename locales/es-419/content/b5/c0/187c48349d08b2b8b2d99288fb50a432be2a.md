# Instrucciones

Tu tarea es tomar una lista de anotadores de un partido y contar cuántos goles anotó cada jugador.

`PlayerName` es un alias de tipo para `String`, para que el código sea más fácil de leer y para distinguir este uso de `String` de otros usos de `String`.

## 1. Acumula los anotadores

Primero implementa `updateGoalCountForPlayer` para inicializar o incrementar el recuento de goles de un jugador.
Luego implementa la función `aggregateScorers` para contar cuántos goles anotó cada jugador, usando `updateGoalCountForPlayer`.
Esta función recibe una `List PlayerName` (los nombres de los jugadores que anotaron los goles, que puede contener nombres de jugadores duplicados) y devuelve un `Dict PlayerName Int` con todos los jugadores de la lista junto con cuántos goles anotaron.

```elm
aggregateScorers [ "Betty", "Cedd", "Betty" ]
--> Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ]
```

## 2. Elimina los jugadores insignificantes

Implementa la función `removeInsignificantPlayers` para filtrar los jugadores que hayan anotado menos goles que el umbral.

```elm
removeInsignificantPlayers 2 (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
--> Dict.fromList [ ( "Betty", 2 ) ]
```

## 3. Restablece el recuento de goles de un jugador

Implementa la función `resetPlayerGoalCount` para restablecer a cero los goles anotados por un jugador.

```elm
resetPlayerGoalCount "Cedd" (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
--> Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 0 ) ]
```

## 4. Formatea el recuento de goles de un solo jugador

Implementa la función `formatPlayer` para formatear como una cadena el recuento de goles de un solo jugador. Si el jugador no existe en el diccionario, asume que su recuento de goles es cero.

```elm
formatPlayer "Betty" (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
--> "Betty: 2"
```

## 5. Formatea el recuento de goles de todos los jugadores

Implementa la función `formatPlayers` para formatear como una cadena el recuento de goles de todos los jugadores. Los jugadores deben estar ordenados por su nombre.

```elm
formatPlayers (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
--> "Betty: 2, Cedd: 1"
```

## 6. Combina los partidos

Implementa la función `combineGames`, que cuenta el total de goles que anotó cada jugador en ambos partidos.

```elm
combine Games
  (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
  (Dict.fromList [ ( "Betty", 2 ), ( "Mario", 3 ) ] )
--> Dict.fromList [ ( "Betty", 4 ), ( "Cedd", 1 ), ( "Mario", 3 ) ]
```
