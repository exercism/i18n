# Introducción

En Common Lisp, la lista de argumentos de una función se conoce como «[lista lambda][lambda-list]».
Una lista lambda puede tener argumentos de diferentes tipos.
Estos distintos tipos se designan con el uso de «[palabras clave de lista lambda][lambda-list-keyword]», que todas comienzan con `&`.
Los tipos de argumentos más usados son los opcionales, los de palabra clave y los rest.
Cada parámetro de la lista lambda que aparezca después de una palabra clave de lista lambda determinada será de ese tipo.
Una palabra clave de lista lambda solo se puede usar una vez en una lista lambda.

Las listas lambda también se usan en otras construcciones que discutiremos más adelante, como la desestructuración y las macros.
