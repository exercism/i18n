# Tests

Para ejecutar los tests, ejecuta el siguiente comando en el directorio del ejercicio:

```shell
make
```

## Tests omitidos

Resolver un ejercicio significa hacer que todos sus tests pasen.
De forma predeterminada, solo se ejecuta un test (el primero) cuando ejecutas los tests.
Esto es intencional, ya que te permite concentrarte solo en hacer que ese único test pase.
Una vez que pase, puedes habilitar el siguiente test eliminando la línea `TEST_IGNORE();`.
Cuando hayas habilitado todos los tests y tu implementación los haga pasar todos, ¡habrás resuelto el ejercicio!
