# Introducción

Para que un objeto se pueda comparar con otro objeto, debe implementar la interfaz `IComparable<T>`.
Esta interfaz tiene un único método que se debe implementar: `int CompareTo(T other)`.

El método `CompareTo` puede devolver tres valores distintos:

- Un valor menor que cero: el objeto actual es menor que el otro objeto.
- Un valor mayor que cero: el objeto actual es mayor que el otro objeto.
- Un valor igual a cero: el objeto actual es igual al otro objeto.
