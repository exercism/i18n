# Instrucciones

Toma un array anidado de cualquier profundidad y devuelve un array completamente aplanado.

Ten en cuenta que algunos tracks de lenguaje pueden incluir valores similares a null en el array de entrada, y la forma en que se representan estos valores varía según el track.
Esos valores deben excluirse del array aplanado.

Además, la entrada puede ser de un tipo de dato diferente y contener tipos distintos, según el track.

Revisa el conjunto de pruebas para más detalles.

## Ejemplo

entrada: `[1, [2, 6, null], [[null, [4]], 5]]`

salida: `[1, 2, 6, 4, 5]`
