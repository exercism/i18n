# Acerca de

Los *string* (cadenas) en Gleam son texto inmutable rodeado de comillas dobles. Admiten caracteres unicode y pueden ocupar varias líneas.

```gleam
let greeting = "Hello, Joe! 📞"

let multi_line_string = "one
two
three"
```

Los *string* se pueden unir con el operador `<>`:

```gleam
let name = "Mike"
"Hello, " <> name <> "!"
// -> "Hello, Mike!"
```

El módulo [`gleam/string`][stdlib] de la biblioteca estándar ofrece funciones para trabajar con *string*.

Los *string* se pueden usar en patrones dentro de expresiones `case`:

```gleam
pub fn on_an_excellent_adventure(name: String) -> Bool {
  case name {
    "Bill" -> True
    "Ted" -> True
    _ -> False
  }
}
```

Si quieres hacer coincidir el inicio de un *string* y asignar el resto a una variable, puedes usar el patrón del operador `<>`:

```gleam
pub fn profession(name: String) -> String {
  case name {
    "Dr " <> rest -> rest <> " is a doctor"
    _ -> "I'm not sure what " <> name <> " does"
  }
}
```

[stdlib]: https://hexdocs.pm/gleam_stdlib/gleam/string.html
