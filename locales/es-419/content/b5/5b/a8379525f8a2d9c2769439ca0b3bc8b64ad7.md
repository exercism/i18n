# Acerca de

Haxe admite la reflexión en tiempo de ejecución de tipos y campos. Para usar la reflexión correctamente, es necesario entender qué tipo de operaciones se admiten y cuáles no. Dada la naturaleza dinámica de la reflexión, esto no siempre se puede determinar en tiempo de compilación.

La API de reflexión consta de dos clases:

- `Reflect`: una API ligera que funciona mejor con estructuras anónimas, con soporte limitado para clases.
- `Type`: una API más robusta para trabajar con clases y enumeraciones.

Los métodos disponibles se detallan en la API de [Reflect][reflect] y [Type][type].

Para el siguiente ejemplo, usamos el target de JavaScript:

```haxe
class Main {
  public static function main() {
    trace(Type.resolveClass("Main"));
  }
}

// This outputs
// class Test { static main() { console.log("Test.hx:3:",$hxClasses["Test"]); } }
```

[reflect]: https://api.haxe.org/Reflect.html
[type]: https://api.haxe.org/Type.html
