# Introducción

## Arrays

JSON define un **array** (_arreglo_) como:

> Un array es una colección ordenada de valores.
> Un array comienza con el corchete de apertura `[` y termina con el corchete de cierre `]`.
> Los valores se separan con una coma `,`.

Los arrays pueden contener cero o más valores JSON de _cualquier tipo_.
Los elementos del array no tienen que ser todos del mismo tipo.

### Crear arrays

Usa corchetes para reunir elementos en un array.

```jq
[1, 2, 3]
```

Puedes capturar los elementos de un _stream_ en un array si lo encierras entre corchetes.

```jq
range(5)     # => a stream of 5 numbers
[range(5)]   # => the array [0, 1, 2, 3, 4]
```

### Tamaño

La función `length` devuelve la cantidad de elementos de un array.

### Indexación y segmentación

Los índices de un array empiezan en cero.

Para obtener un elemento de un array, usa una expresión con corchetes:
`.[2]` obtiene el tercer elemento.

Los índices negativos cuentan hacia atrás desde el final del array:
`.[-1]` obtiene el último elemento; `.[-2]` es el penúltimo.

Un **segmento** es una subsecuencia del array.
`.[10:15]` devuelve 5 elementos a partir del índice 10; el índice final _no se incluye_.

Hay algunas funciones que te facilitan la tarea:

- `first` obtiene el primer elemento.
- `last` obtiene el último elemento.
- `nth(n)` obtiene el elemento en el índice `n`.

### Iterar

`jq` ofrece muchas funciones para cubrir las necesidades de iteración más comunes:

- `map(expr)` devuelve un nuevo array en el que se aplica `expr` a cada elemento, uno tras otro.

  ```jq
  [1, 2, 3] | map(. * 10)    # => [10, 20, 30]

  ```

- `select(expr)` es una función que aplica `expr` a un _solo valor_;
  si el resultado de la expresión es verdadero, se devuelve el valor;
  si el resultado es falso, _no se devuelve nada_: no `null`, literalmente nada.

  Para aplicarlo a un array, combínalo con `map`.

  ```jq
  [range(10)] | map(select(. % 2 == 0))    # => [0, 2, 4, 6, 8]
  ```

  Como alternativa, aplica `select` a un _stream_ y recoge los resultados.

  ```jq
  [range(10) | select(. % 2 == 0)]    # => [0, 2, 4, 6, 8]
  ```

- `any(condition)` y `all(condition)` devuelven un valor Boolean que indica si alguno o todos los elementos del array cumplen la condición.

  ```jq
  [1, 2, 3, 4] | any(. > 4)    # false
  [1, 2, 3, 4] | any(. >= 4)   # true

  [1, 2, 3, 4] | all(. >= 4)   # false
  [1, 2, 3, 4] | all(. <= 4)   # true
  ```
