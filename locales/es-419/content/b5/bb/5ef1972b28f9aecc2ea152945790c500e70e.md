# Instrucciones

El proyecto del carro de control remoto que pusiste en marcha en el ejercicio `classes` ha salido bien (¡felicidades!) y, gracias a varios acuerdos de patrocinio recientes, hay dinero en el presupuesto para mejoras.

Parte del presupuesto se destina a ofrecer un poco de telemetría.

Para mantener contentos a los patrocinadores, se ha instalado un panel en el carro para mostrar los nombres de los patrocinadores mientras da vueltas a la pista.

Notarás que la incorporación de estas nuevas tecnologías tan sofisticadas ha reducido drásticamente la duración de la batería del carro.

## 1. Haz que el carro de control remoto muestre los nombres de los patrocinadores

Implementa `SetSponsors()` para que reciba uno o más nombres de patrocinadores y los guarde en el carro.

Ten en cuenta que se garantiza que el argumento del método `SetSponsors()` no es nulo.

Implementa `DisplaySponsor()` para mostrar el patrocinador seleccionado. El primer patrocinador que se pasa tiene un `sponsorNum` de 0, el segundo, 1, etc.

```csharp
var car = RemoteControlCar.Buy();
car.SetSponsors("Exercism", "Walker Industries", "Acme Co.");
var sp2 = car.DisplaySponsor(sponsorNum: 1);
// => "Walker Industries"
```

## 2. Obtén los datos de telemetría del carro

Implementa el método `RemoteControlCar.GetTelemetryData()`.

`GetTelemetryData()` debe dejar disponibles el porcentaje de batería y la distancia recorrida en metros a través de parámetros `out`.

`GetTelemetryData()` debe devolver `false` si el argumento serialNum es menor que el valor recibido anteriormente. (Hay algún problema relacionado con que intervienen varios nodos de telemetría). En este caso, `serialNum` se establecerá en el `serialNum` anterior más alto, y tanto el porcentaje de batería como los metros recorridos se establecerán en `-1`. Cuando la llamada tiene éxito, `serialNum` permanece sin cambios.

```csharp
var car = RemoteControlCar.Buy();
car.Drive();
car.Drive();
int serialNum = 4;
car.GetTelemetryData(ref serialNum, out int batteryPercentage, out int distanceDrivenInMeters);
// => true, 4L, 80, 4

serialNum = 1;
car.GetTelemetryData(ref serialNum, out batteryPercentage, out distanceDrivenInMeters);
// => false, 4L, -1, -1
```

## 3. Agrega funcionalidad para que el sistema de telemetría pueda obtener el uso de batería por metro

Implementa el método `TelemetryClient.GetBatteryUsagePerMeter()`.

Este llamará a `RemoteControlCar.GetTelemetryData()`. Si `GetTelemetryData()` devuelve `false` o el carro no se ha conducido, esta rutina debe devolver «no data». Si `GetTelemetryData()` devuelve `true`, debe devolver un mensaje con la siguiente forma: «usage-per-meter=BATTERY-USAGE-PER-METER». El cálculo es (100 - el porcentaje de batería actual) dividido entre la distancia recorrida en metros hasta el momento.

```csharp
var car = RemoteControlCar.Buy();
car.Drive();
car.Drive();
var tc = new TelemetryClient(car);
int serialNum = 4;
tc.GetBatteryUsagePerMeter(serialNum);
// => "usage-per-meter=5"

serialNum = 1;
tc.GetBatteryUsagePerMeter(serialNum);
// => "no data"
```
