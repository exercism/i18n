# Pistas

## 1. Calcula el valor de una carta cualquiera

- La función `ParseCard` debe recibir el `card` (un `string`, por ejemplo `ace`) y devolver su valor (por ejemplo, 11).
- Usa una sentencia `switch` grande sobre la variable `card`.
- King, Queen, Jack y 10 se pueden manejar con un solo caso.
- La sentencia `switch` puede tener un caso `default`.
  En cualquier caso, la función debe devolver `0` para cartas desconocidas.

## 2. Implementa la lógica de decisión para el primer turno

- Usa la función `ParseCard` para determinar el valor de cada carta.
- Calcula el puntaje del jugador sumando los valores de las dos cartas del jugador.
- Puedes usar una sentencia `switch` grande sobre el puntaje del jugador (quizás con sentencias `if` anidadas sobre el puntaje del crupier en algunos casos).
- Como alternativa, podrías distinguir categorías separadas del puntaje del jugador (digamos «manos pequeñas» con un puntaje menor que 12, «manos medianas» con un puntaje en el rango 12..20 y «manos grandes» con un puntaje mayor que 20) y escribir funciones separadas para todas (o algunas) de estas categorías.
