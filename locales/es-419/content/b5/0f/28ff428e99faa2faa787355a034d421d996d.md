# Pistas

## 1. Cambia el nombre de una columna

- Recuerda que necesitas modificar el dataset `trees`, que está disponible si se llama a `library(datasets)`.
- Puede que quieras (o no) convertir el `data.frame` inicial en un `tibble`.
- Consulta la Introducción para ver cómo cambiar el nombre de una columna.

## 2. Agrega las columnas girth y weight

- Consulta la Introducción para ver cómo agregar columnas.
- Las columnas nuevas se pueden calcular a partir de las columnas existentes.
- No olvides redondear a la precisión requerida.

## 3. Copia del dataset para el huerto

- Necesitas cambiar las columnas de lugar y ordenar las filas (consulta la Introducción).

## 4. Copia del dataset para el cliente

- Necesitarás tomar un subconjunto de las columnas.
- Solo deben estar en la copia los árboles que estén entre los valores mínimo y máximo de height *y* por debajo del valor máximo de weight.
