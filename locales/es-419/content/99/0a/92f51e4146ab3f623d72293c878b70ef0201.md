# usa la interpolación de string

[comment]: # (Esta advertencia se muestra cuando la solución no usa la interpolación de string)

Usa la [interpolación de string](https://github.com/elixir-lang/elixir/blob/9cac52833e91b5ebac0d322b20e39605d8dafad9/lib/elixir/lib/string.ex#L20) para insertar el parámetro `name` en el string de salida.

- Cuando sea posible, en el track de Elixir de Exercism se recomienda usar la interpolación de string en lugar de la concatenación de strings para mejorar la legibilidad.

```elixir
def hello(what) do
  "Hello, #{what}"
end
```

- [Cualquier expresión de Elixir](https://github.com/elixir-lang/elixir/blob/9cac52833e91b5ebac0d322b20e39605d8dafad9/lib/elixir/lib/string.ex#L30) puede ir dentro de la sintaxis de interpolación de string

```elixir
def pluralize_apple(n) when n >= 1 do
  "apple#{if n > 1, do: "s"}"
end
```
