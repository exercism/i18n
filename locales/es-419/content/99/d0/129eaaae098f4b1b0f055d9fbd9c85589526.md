# Instrucciones

Tu amigo Linus es ingeniero de locomotoras y conduce trenes de carga entre ciudades.
Aunque es increíble manejando trenes, no se le dan tan bien la logística ni las computadoras.
Le gustaría contar con tu ayuda como programador para organizar los detalles de los trenes y corregir errores en los datos de las rutas.

~~~~exercism/note
Este ejercicio se podría resolver fácilmente usando slicing, indexación y varios métodos de `dict`.
Sin embargo, nos gustaría que practiques el empaquetado, el desempaquetado y la asignación múltiple al resolver cada una de las tareas a continuación.
~~~~

## 1. Crea una lista con todos los vagones

Tu amigo ha estado llevando un registro del identificador (ID) de cada vagón, pero nunca está seguro de cuántos vagones tendrá que procesar el sistema en un momento dado.
Para el resto del programa de logística sería mucho más fácil tener estos datos empaquetados en un único `list`.

Implementa una función `get_list_of_wagons()` que acepte una cantidad arbitraria de IDs de vagones.
Cada ID será un número entero positivo.
La función debe entonces usar `return` para devolver los IDs dados como un único `list`.

```python
>>> get_list_of_wagons(1, 7, 12, 3, 14, 8, 5)
[1, 7, 12, 3, 14, 8, 5]
```

## 2. Corrige la lista de vagones

En este punto, ya empiezas a tener una idea de los datos y de cómo se usan en el programa de logística.
El sistema de IDs siempre asigna a la locomotora el ID **1**, y al resto de los vagones del tren les asigna un ID elegido al azar mayor que **1**.

¡Tu amigo tuvo que conectar dos vagones nuevos al tren y olvidó actualizar el sistema!
Ahora, los dos primeros vagones del `list` del tren tienen que moverse al final, o todo quedará desordenado.

Para complicar más las cosas, tu amigo acaba de encontrar un segundo `list` que parece contener los IDs de vagones que faltan.
Lo único que recuerda es que, una vez que se muevan los vagones nuevos, los IDs de este segundo `list` deben colocarse justo después de la locomotora designada.

Linus te estaría muy agradecido si corriges sus errores y consolidas los datos.

Implementa una función `fix_list_of_wagons()` que reciba dos `lists` con IDs de vagones.
Debe reposicionar los dos primeros elementos del primer `list` al final, e insertar los valores del segundo `list` detrás (_a la derecha_) del ID de la locomotora (**1**).
La función debe entonces usar `return` para devolver un `list` con las modificaciones.

```python
>>> fix_list_of_wagons([2, 5, 1, 7, 4, 12, 6, 3, 13], [3, 17, 6, 15])
[1, 3, 17, 6, 15, 7, 4, 12, 6, 3, 13, 2, 5]
```

## 3. Agrega las paradas que faltan

Ahora que todos los datos de los vagones son correctos, a Linus le gustaría que actualices la información de rutas del sistema.
A lo largo de una ruta de transporte, un tren puede hacer paradas en distintas estaciones para recoger o dejar carga.
Cada viaje puede tener una cantidad diferente de estos puntos intermedios de entrega.
Tu amigo quiere que actualices el `dict` de rutas del sistema con cualquier información de entrega que falte o sea adicional.

Implementa una función `add_missing_stops()` que acepte un `dict` de rutas seguido de una cantidad variable de argumentos de palabra clave.
Estos argumentos pueden tener la forma de un `dict` que contenga una o más paradas, o bien cualquier cantidad de pares de palabra clave `stop_number=city`.
Tu función debe entonces devolver el `dict` de rutas actualizado con una `key` adicional que contenga un `list` con todas las paradas agregadas, en orden.

```python
>>> add_missing_stops({"from": "New York", "to": "Miami"},
                      stop_1="Washington, DC", stop_2="Charlotte", stop_3="Atlanta",
                      stop_4="Jacksonville", stop_5="Orlando")

{"from": "New York", "to": "Miami", "stops": ["Washington, DC", "Charlotte", "Atlanta", "Jacksonville", "Orlando"]}
```

## 4. Extiende la información de rutas

Linus ha estado trabajando en el programa de rutas y ha notado que a ciertas rutas les faltan algunos detalles importantes.
La información inicial de la ruta se ha construido como un `dict`, y tu amigo quiere que actualices ese `dict` con todo lo que pueda faltar.
Cada ruta del sistema requiere detalles un poco distintos, así que Linus preferiría mucho una solución genérica.

Implementa una función llamada `extend_route_information()` que acepte dos `dicts`.
El primer `dict` contiene las ciudades de origen y destino entre las que va la ruta del tren.

El segundo `dict` contiene otros detalles de la ruta, como la velocidad, la longitud o la temperatura del tren.
La función debe devolver un `dict` consolidado con toda la información de la ruta.

~~~~exercism/note
El segundo `dict` puede contener propiedades diferentes o más de las que se muestran en el ejemplo.
~~~~

```python
>>> extend_route_information({"from": "Berlin", "to": "Hamburg"}, {"length": "100", "speed": "50"})
{"from": "Berlin", "to": "Hamburg", "length": "100", "speed": "50"}
```

## 5. Corrige el depósito de vagones

Cuando Linus estaba inspeccionando el depósito de vagones, notó que los vagones no se estaban guardando en el orden correcto.
Además de un ID, cada vagón tiene un color que corresponde al tipo de carga que lleva.
Los vagones se guardan en el depósito en cuadrículas, donde cada columna de la cuadrícula tiene vagones del mismo color.

Sin embargo, el sistema de logística muestra que los `lists` de vagones que se van a guardar en el depósito tienen sus _filas_ agrupadas por color.
Pero para que la cuadrícula de almacenamiento funcione correctamente, cada _fila_ debe tener tres colores diferentes, de modo que las _columnas_ queden alineadas por color.
Tu amigo quiere que ordenes los `lists` del depósito de vagones, para que los vagones se guarden correctamente.

Implementa una función llamada `fix_wagon_depot()` que acepte un `list` de tres elementos.
Cada elemento del `list` es una sublista (o «fila») que contiene tres `tuples`.
Cada `tuple` es un par `(<wagon ID>, <wagon color>)`.

Tu función debe devolver un `list` con los tres `lists` de «fila» reordenados para que los vagones queden intercambiados en sus posiciones correctas.

```python
>>> fix_wagon_depot([
                    [(2, "red"), (4, "red"), (8, "red")],
                    [(5, "blue"), (9, "blue"), (13,"blue")],
                    [(3, "orange"), (7, "orange"), (11, "orange")],
                    ])

[
[(2, "red"), (5, "blue"), (3, "orange")],
[(4, "red"), (9, "blue"), (7, "orange")],
[(8, "red"), (13,"blue"), (11, "orange")]
]
```
