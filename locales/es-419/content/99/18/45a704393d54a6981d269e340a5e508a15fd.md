# Instrucciones

Estás ayudando a tu hermana menor con su tarea de vocabulario de inglés, que le está resultando muy tediosa.
 Su clase está aprendiendo a crear palabras nuevas agregando _prefijos_ y _sufijos_.
 Dado un conjunto de palabras, la maestra busca palabras transformadas correctamente y con la ortografía correcta, agregando el prefijo al principio o el sufijo al final.

La tarea tiene cuatro actividades, cada una con un conjunto de texto o palabras con las que trabajar.


## 1. Agrega un prefijo a una palabra

Uno de los prefijos más comunes en inglés es `un`, que significa «no».
 En esta actividad, tu hermana necesita formar palabras negativas, o «no», agregándoles `un`.

Implementa la función `add_prefix_un(<word>)` que toma `word` como parámetro y devuelve una palabra nueva con el prefijo `un`:


```python
>>> add_prefix_un("happy")
'unhappy'

>>> add_prefix_un("manageable")
'unmanageable'
```


## 2. Agrega prefijos a grupos de palabras

Hay otros cuatro prefijos comunes que está estudiando la clase de tu hermana:
 `en` (_que significa «poner dentro» o «cubrir con»_),
 `pre` (_que significa «antes» o «adelante»_),
 `auto` (_que significa «propio» o «mismo»_),
  y `inter` (_que significa «entre»_).

 En este ejercicio, la clase está creando grupos de palabras de vocabulario usando estos prefijos, para poder estudiarlas juntas.
 Cada prefijo viene en una lista con palabras comunes con las que se usa.
 Los estudiantes necesitan aplicar el prefijo y producir un string que muestre el prefijo aplicado a todas las palabras.

Implementa la función `make_word_groups(<vocab_words>)` que toma `vocab_words` como parámetro con la siguiente forma:
 `[<prefix>, <word_1>, <word_2> .... <word_n>]`, y devuelve un string con el prefijo aplicado a cada palabra que se ve así:
  `'<prefix> :: <prefix><word_1> :: <prefix><word_2> :: <prefix><word_n>'`.

No es necesario crear un bucle `for` o `while` para procesar los argumentos aquí.
Piensa bien qué métodos de string (y delimitadores) podrías usar en su lugar.


```python
>>> make_word_groups(['en', 'close', 'joy', 'lighten'])
'en :: enclose :: enjoy :: enlighten'

>>> make_word_groups(['pre', 'serve', 'dispose', 'position'])
'pre :: preserve :: predispose :: preposition'

>> make_word_groups(['auto', 'didactic', 'graph', 'mate'])
'auto :: autodidactic :: autograph :: automate'

>>> make_word_groups(['inter', 'twine', 'connected', 'dependent'])
'inter :: intertwine :: interconnected :: interdependent'
```


## 3. Quita un sufijo de una palabra

`ness` es un sufijo común que significa _«estado de ser»_.
 En esta actividad, tu hermana necesita encontrar la palabra raíz original quitando el sufijo `ness`.
  Pero, por supuesto, hay reglas de ortografía molestas: si la palabra raíz originalmente terminaba en una consonante seguida de una «y», entonces la «y» se cambió a «i».
 Al quitar «ness» hay que restaurar la «y» en esas palabras raíz. Por ejemplo, `happiness` --> `happi` --> `happy`.

Implementa la función `remove_suffix_ness(<word>)` que recibe una `word` y devuelve la palabra raíz sin el sufijo `ness`.


```python
>>> remove_suffix_ness("heaviness")
'heavy'

>>> remove_suffix_ness("sadness")
'sad'
```

## 4. Extrae y transforma una palabra

Los sufijos suelen usarse para cambiar la categoría gramatical a la que pertenece una palabra.
 Una práctica común en inglés es la «verbalización», donde un adjetivo _se convierte_ en un verbo agregando un sufijo `en`.

En esta tarea, tu hermana va a practicar la «verbalización» de palabras extrayendo un adjetivo de una oración y convirtiéndolo en un verbo.
 Por suerte, todas las palabras que hay que transformar aquí son «regulares»: no necesitan cambios de ortografía para agregar el sufijo.

Implementa la función `adjective_to_verb(<sentence>, <index>)` que toma dos parámetros.
 Una `sentence` que usa la palabra de vocabulario, y el `index` de la palabra, una vez que esa oración se separa.
 La función debe devolver el adjetivo extraído como un verbo.


```python
>>> adjective_to_verb('I need to make that bright.', -1 )
'brighten'

>>> adjective_to_verb('It got dark as the sun set.', 2)
'darken'
```
