# Instalación de Kotlin

Además de la CLI de Exercism y tu editor de texto favorito, para practicar con los ejercicios de Exercism en Kotlin necesitas

* el **Java Development Kit** (JDK): Kotlin compila a bytecode de Java, así que necesitas instalar el JDK, que incluye tanto un Java Runtime *como* herramientas de desarrollo (sobre todo, el compilador de Java); y
* **Gradle**: una herramienta de compilación pensada específicamente para proyectos basados en JVM, que además es compatible con Kotlin.

Elige tu sistema operativo:

* [Windows](#h-windows)
* [macOS](#h-macos)
* [Linux](#h-linux)

... o ...
* si prefieres no usar un gestor de paquetes, puedes [instalar manualmente](#h-install-manually).

Opcionalmente, también puedes usar un [IDE de Java](#h-java-ides).

----

## Windows

Abre un símbolo del sistema como administrador. (Si necesitas ayuda para abrir un símbolo del sistema con privilegios administrativos, consulta [cómo abrir un símbolo del sistema elevado en Windows 8+](http://www.howtogeek.com/194041/how-to-open-the-command-prompt-as-administrator-in-windows-8.1/) (o [Windows 7](http://www.howtogeek.com/howto/windows-vista/run-a-command-as-administrator-from-the-windows-vista-run-box/)).

1. Si aún no has instalado Chocolatey, hazlo ahora:

      ```batchfile
        C:\Windows\system32> @powershell -NoProfile -ExecutionPolicy unrestricted -Command "iex ((new-object net.webclient).DownloadString('https://chocolatey.org/install.ps1'))" && SET PATH=%PATH%;%ALLUSERSPROFILE%\chocolatey\bin
      ```

2.  Instala el JDK:

       ```batchfile
        C:\Windows\system32> choco install openjdk11
        ...
        C:\Windows\system32> refreshenv
        ...
       ```

Te recomendamos cerrar el símbolo del sistema administrativo y abrir uno nuevo; no necesitas privilegios de administrador para practicar los ejercicios de Exercism.

¡Ya tienes todo listo para empezar con la pista de Kotlin de Exercism!

Para empezar, consulta «[Ejecutar las pruebas](https://exercism.org/docs/tracks/kotlin/tests)».

## macOS

A continuación hay instrucciones para instalar usando el método más común: con Homebrew. Si lo prefieres, también puedes [instalar en macOS sin Homebrew](#h-installing-on-macos-without-homebrew).

### Instalación

1. Si aún no has instalado [Homebrew](http://brew.sh), hazlo ahora:

      ```sh
        $ /usr/bin/ruby -e "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/master/install)"
      ```

2. Agrega el tap de [Homebrew Cask](https://caskroom.github.io/): esto nos permite instalar binarios precompilados como el JDK.

      ```
        $ brew tap adoptopenjdk/openjdk
      ```

3.  Instala el JDK:

       ```
        $ brew install --cask adoptopenjdk11
       ```

Para empezar, consulta «[Ejecutar las pruebas](https://exercism.org/docs/tracks/kotlin/tests)».

### Debian

Si usas Debian o sus derivados (como Ubuntu o Linux Mint), usa APT:

*(verificado en: Ubuntu 14, 16 y 18)*

1. Instala el JDK:

      ```sh
        $ sudo apt-get update
        $ sudo apt-get install software-properties-common
        $ sudo add-apt-repository ppa:openjdk-r/ppa
        $ sudo apt-get update
        $ sudo apt-get install openjdk-11-jdk
      ```

### Otras distribuciones de Linux

Hay muchas formas de instalar el JDK 11, pero una de las más sencillas es usar SDKMAN, 
que te permite instalar OpenJDK 11 sin complicaciones. Sigue estos pasos:

1. Instala SDKMAN:
    ```sh
    $ curl -s "https://get.sdkman.io" | bash
    ``` 
    (si eso no funciona, mira las instrucciones que están aquí: https://sdkman.io/install )
1. Instala OpenJDK 11:
    ```
    $ sdk install java 11.0.2-open
    ```

### Instalación manual en Windows

*NOTA: estas instrucciones están pensadas para usuarios experimentados de Windows.  Si aún no sabes cómo establecer variables de entorno o no te sientes cómodo administrando la estructura de directorios, te recomendamos mucho que uses la instalación con Chocolatey, [más arriba](#h-windows).*

1. Instala el JDK:
   1. Descarga «**OpenJDK 11 (LTS)**» de [AdoptOpenJDK](https://adoptopenjdk.net/releases.html?variant=openjdk11#x64_win) (elige **«Install JDK»**).
   -  Ejecuta el instalador, usando todos los valores predeterminados.

¡Ya tienes todo listo para empezar con la pista de Kotlin de Exercism!

Para empezar, consulta «[Ejecutar las pruebas](https://exercism.org/docs/tracks/kotlin/tests)».

## IDE de Java

Hay muchos IDE de Java disponibles.  Los tres más populares son:

* [IntelliJ IDEA](https://www.jetbrains.com/idea/download/) (descarga la edición «Community»)
  - de los creadores de Kotlin, este IDE ofrece el mejor soporte para el lenguaje.
- [Eclipse](https://www.eclipse.org/downloads/)
- [NetBeans](https://netbeans.org/downloads/) (descarga el paquete «Java SE»)

y hay [otros](https://en.wikibooks.org/wiki/Java_Programming/Java_IDEs).
