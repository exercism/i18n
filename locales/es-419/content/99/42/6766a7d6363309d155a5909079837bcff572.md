# Anexo de instrucciones

## Consejo

Una función con un *tipo de retorno* solo puede devolver datos de ese *tipo* y `null`.
Sin embargo, quien llama a la función solo espera un tipo de datos.

Ejemplo:
```dart
String hello(int a){
    if ( a == 0){
        return "a";
    } else {
        return null;
    }
}
```
Para dejar más claro que esta función también puede devolver `null` o más tipos de datos, usa `dynamic`.
```dart
dynamic hello(int a){
    if ( a == 0){
        return "a";
    } else {
        return null;
    }
}
