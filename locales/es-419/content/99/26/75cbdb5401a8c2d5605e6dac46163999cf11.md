# Resolver ejercicios localmente

Resolver ejercicios en tu computadora te permite escribir todo el código en un entorno que ya conoces.

## Instalar la CLI

Para resolver un ejercicio en tu computadora, primero necesitas instalar y configurar la interfaz de línea de comandos de Exercism siguiendo [estas instrucciones](https://exercism.org/cli-walkthrough).

### Configuración

Necesitas decirle a la CLI quién eres para que podamos descargar las cosas correctamente.
Puedes encontrar tu token en tu [página de configuración](/settings/api_cli).
Después puedes configurar la CLI con lo siguiente, reemplazando `<your-api-token>` por el valor de la página de configuración:

```
exercism configure --token=<your-api-token>
```

## Descargar el ejercicio

Una vez instalada, puedes usar la CLI para descargar el ejercicio a tu computadora con el siguiente comando, reemplazando `<exercise-slug>` y `<track-slug>` por los valores correspondientes:

```
exercism download --exercise=<exercise-slug> --track=<track-slug>
```

No tienes que memorizar esta estructura de comando, ya que la página del ejercicio muestra el comando correspondiente.

Cuando termine el comando de descarga, los archivos del ejercicio se descargarán en tu computadora.

## Resolver el ejercicio

El objetivo de cada ejercicio es crear una implementación que pase todos los tests.
A esa implementación se le llama _solución_.

Para ayudarte con eso, cada ejercicio incluye los siguientes archivos:

- README.md: las instrucciones que explican qué se espera de ti
- HELP.md: información sobre cómo ejecutar los tests y cómo obtener ayuda cuando te bloqueas
- HINTS.md (opcional): pistas que te ayudan a resolver el ejercicio
- Archivo(s) de tests: contienen los tests que verifican que tu solución sea correcta
- Archivo(s) stub: te dan un punto de partida para empezar a construir tu implementación

Según la pista, puede haber otros archivos que las herramientas de la pista necesiten para ejecutar los tests.

## Enviar tu solución

Cuando tu solución pase todos los tests, puedes enviarla con el siguiente comando:

```
exercism submit <implementation_file_paths>
```

Este comando sube tu solución al sitio web de Exercism e imprime la URL de la página de la solución.

Una vez más, no tienes que memorizar este comando, ya que el archivo `HELP.md` del ejercicio muestra el comando correcto.

Puedes enviar una solución incompleta, lo que te permite:

- Ver cómo otras personas resolvieron el ejercicio
- Pedir ayuda a un mentor

## Otras funcionalidades de la CLI

### Ver todos los comandos

Ejecuta el subcomando help para obtener la lista completa de comandos disponibles.

```bash
exercism help
```

### Solución de problemas

Asegúrate de tener la versión más reciente.

Verifica qué versión tienes:

```bash
exercism version
```

Compárala con la última versión publicada y actualiza si la tuya no es la más reciente.

Después de actualizar, verifica de nuevo la versión. Si la versión no cambió, asegúrate de estar ejecutando el binario actualizado.

```bash
which exercism
```

Si sigues teniendo problemas, abre un issue en exercism/cli en GitHub con la salida del comando troubleshoot.

```bash
exercism troubleshoot
```

Puedes abrir issues en [nuestro gestor de issues](https://github.com/exercism/exercism/issues) y la comunidad intentará ayudarte. **Asegúrate de haber completado el [Recorrido interactivo](https://exercism.org/cli-walkthrough) antes de abrir cualquier issue.**
