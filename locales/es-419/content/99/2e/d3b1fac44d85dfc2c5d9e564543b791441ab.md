# Apéndice de instrucciones

## Registros

| Registro | Uso            | Tipo       | Descripción                        |
| -------- | ------------ | ------- | ---------------------------- |
| `$a0`    | entrada        | entero     | N, suma de los lados del triángulo |
| `$a1`    | entrada/salida | dirección  | valores de a                       |
| `$a2`    | entrada/salida | dirección  | valores de b                       |
| `$a3`    | entrada/salida | dirección  | valores de c                       |
| `$v0`    | salida         | entero     | número de tripletas                |
| `$t0-9`  | temporal       | cualquiera | para almacenamiento temporal       |
