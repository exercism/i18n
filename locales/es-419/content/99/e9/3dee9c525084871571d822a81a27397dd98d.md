# Instrucciones

Un pirata traza una ruta por un mapa de calas ocultas.
El mapa es una tabla hash con el nombre de la cala como clave; cada valor es un
array de las calas a las que puedes llegar directamente desde esa.

## 1. Vacía la cola de marea

Define `tide-queue` para que tome un array de elementos, meta cada uno en una
deque nueva (en orden) y después los saque todos de vuelta a un array
que conserve el orden original. Esta es la forma FIFO:
se mete por el final y se saca por el frente.

```factor
{ "alpha" "bravo" "charlie" } tide-queue .
! => { "alpha" "bravo" "charlie" }
```

## 2. Calas alcanzables

Define `coves-reachable` para que tome una cala inicial y un mapa,
y devuelva un conjunto hash con todas las calas alcanzables desde `start`,
incluida la propia `start`.

```factor
"Skull Bay" H{
    { "Skull Bay"   { "Hidden Cove" } }
    { "Hidden Cove" { "Reef Point"  } }
    { "Reef Point"  { } }
} coves-reachable .
! => HS{ "Skull Bay" "Hidden Cove" "Reef Point" }
```

Usa un `<dlist>` como frontera del BFS y un `HS{ }` para el
conjunto de calas visitadas.

## 3. Conteo de saltos

Define `hop-count` para que tome una cala inicial, una cala objetivo y un
mapa, y devuelva el número mínimo de saltos entre ellas, o
`f` si no se puede llegar a la cala objetivo.

```factor
"Skull Bay" "Hidden Cove"
H{
    { "Skull Bay"   { "Hidden Cove" } }
    { "Hidden Cove" { } }
} hop-count .
! => 1
```

Lleva cada cala junto con su distancia desde el inicio dentro de la
deque (un array de 2 elementos sirve).

## 4. Conteo de oro

El esqueleto declara `gold-count` con `:`. Cámbialo a `MEMO:`
(no `:`) para que el resultado de cada cala se calcule una sola vez y
se guarde en caché. Busca el oro de la cala en la constante
`gold-distribution` que proporciona el ejercicio.
Una cala que no esté en la distribución tiene cero oro.

```factor
"Smuggler's Hollow" gold-count .   ! => 200
"Davy Jones' Locker" gold-count .  ! => 0
```

## 5. Ruta del tesoro

Define `treasure-route` para que tome una cala inicial y un mapa, y
devuelva la cala alcanzable con más oro. Usa
`coves-reachable` de la tarea 2 y `gold-count` de la tarea 4.

```factor
"Skull Bay" some-chart treasure-route .
! => "Smuggler's Hollow"   (the richest reachable cove)
```

El `gold-count` memoizado mantiene gratis las búsquedas repetidas, algo
útil cuando varias partes del algoritmo consultan la misma cala.
