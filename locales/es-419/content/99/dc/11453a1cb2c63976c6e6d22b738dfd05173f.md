# Recursos recomendados

## Documentación

* [Groovy Language Documentation](http://docs.groovy-lang.org/docs/latest/html/documentation/)
* [Groovy JDK API Documentation](http://groovy-lang.org/gdk.html)
* La [Groovy Documentation](http://www.groovy-lang.org/documentation.html) de Apache, que incluye la gran sección [Learn Groovy](http://www.groovy-lang.org/learn.html)

## Herramientas

* [SDKman](http://sdkman.io/)
* [Groovy Eclipse](https://github.com/groovy/groovy-eclipse/wiki)
* [IntelliJ Idea](https://www.jetbrains.com/idea/download/)

## Tecnologías

* [Gradle](https://gradle.org/), una herramienta de compilación para gobernarlas a todas
* [Spock](http://spockframework.org/), la nueva generación de pruebas para lenguajes de la JVM
* [Ratpack](https://ratpack.io/), microservicios mini con martinis
* [Grails](https://grails.org/), «Debes elegir, pero elige con sabiduría.»

## Colaboración
