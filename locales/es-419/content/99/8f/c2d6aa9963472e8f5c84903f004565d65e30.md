# Pistas

## 1. Crea un conjunto de strings útiles

- Los [strings][strings-and-characters] se definen como literales al encerrar cero o más caracteres entre comillas dobles (`"`).

## 2. Crea un conjunto de caracteres útiles

- Los [caracteres][strings-and-characters] se definen como literales al encerrar exactamente un carácter entre comillas dobles (`"`).
- A los caracteres definidos como literales hay que darles explícitamente una anotación de tipo `Character` para evitar que el compilador los interprete como Strings.

## 3. Combina frases para construir mensajes

- Los strings se pueden concatenar usando [el operador de strings correspondiente][string-docs].
- Los caracteres no se pueden concatenar con Strings.
  Primero hay que convertirlos en Strings.

## 4. Construye un cartel de graduación

- La [interpolación de strings][string-interpolation] se realiza colocando la expresión cuyo valor quieres poner en el string dentro de un par de paréntesis precedidos por una barra invertida.

## 5. Calcula el costo de un cartel

- Swift tiene [una propiedad de string][string-count-docs] que devuelve el número de caracteres de un string.
