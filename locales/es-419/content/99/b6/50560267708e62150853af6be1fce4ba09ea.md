# Instalación

Usa el binario `full` para tu plataforma desde [la página oficial de lanzamientos][official-releases].
Por el momento, el track apunta a la versión Arturo 0.10.0 Arizona Bark.

~~~~exercism/caution
Homebrew es un método popular de terceros para instalar software en las plataformas macOS y Linux.
Sin embargo, su receta para Arturo apunta a la compilación `mini`, que es incompatible con este track.
~~~~

Si necesitas más ayuda para instalar Arturo, consulta el [Discord oficial de Arturo][discord].

## Ejecutar código de Arturo

¡Con esto ya puedes empezar a escribir código de Arturo!
Para acceder al REPL de Arturo, ejecuta `arturo` en la línea de comandos.
Para ejecutar un script de Arturo, ejecuta `arturo <file>` en la línea de comandos.

[official-releases]: https://arturo-lang.io/#download
