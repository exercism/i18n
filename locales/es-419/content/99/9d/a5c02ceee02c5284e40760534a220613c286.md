# Acerca de

JavaScript es un lenguaje de programación que permite que las páginas web sean dinámicas. Es un lenguaje interpretado, lo que significa que no necesita compilarse: en su lugar, el intérprete (como un navegador web) analiza el código y lo convierte en código que su máquina puede ejecutar. ¡Es ideal para crear sitios web dinámicos que puedan funcionar en cualquier navegador _en cualquier computadora_!

JavaScript no solo se usa en el navegador. Los entornos de ejecución de JavaScript, como [Node.js][web-nodejs] y [Deno][web-deno], te permiten escribir, lanzar y atender solicitudes en servidores web.
Otros frameworks, como [Electron][web-electron], usan JavaScript para escribir _aplicaciones multiplataforma_ para Windows, Linux y macOS.
El desarrollo de aplicaciones móviles también es posible, con [React Native][web-react-native], [Ionic][web-ionic] y varios otros; ahora [Expo][web-expo] permite apuntar a Android, iOS y la web, todo a la vez.

ECMAScript es el [estándar][web-ecma] que define JavaScript.

> «ECMAScript se ha convertido en uno de los lenguajes de programación de propósito general más ampliamente utilizados del mundo.
> Se le conoce sobre todo como el lenguaje integrado en los navegadores web, pero también se ha adoptado ampliamente para aplicaciones de servidor y embebidas.»
> [ECMA International Language Specification][web-ecma-2019]

A partir de la sexta edición (conocida comúnmente como ES2015 o ES6) en 2015, cada año se publica una nueva edición del estándar.
La sexta edición fue una actualización importante que trajo muchas mejoras respecto a ES5, entre ellas, notablemente, los template strings, una expresiva sintaxis de funciones flecha y una sintaxis más limpia para definir clases.

Pero como cada año llegan nuevas sintaxis y funcionalidades a JavaScript, el soporte para estos cambios suele ser incompleto en los [navegadores actuales][web-compat-browsers] y en [la última versión de Node.js][web-compat-node].
Esto no significa que no podamos usarlo.
Herramientas como [Babel][web-babel] ofrecen [transpilación][wiki-transpilation] para la mayoría de las funcionalidades, lo que nos permite _escribir_ como si ya fuera el futuro.

**Nota**: Este track admite la sintaxis más reciente de ECMAScript mediante Babel y el plugin [@babel/preset-env][web-babel-preset-env], y las nuevas funcionalidades experimentales se habilitan con cada actualización de ese plugin, coincidiendo con el lanzamiento de las especificaciones.
Se adapta automáticamente a _tu instalación local de Node.js_.
Esto significa que no necesitas preocuparte por saber qué está soportado y qué no.
