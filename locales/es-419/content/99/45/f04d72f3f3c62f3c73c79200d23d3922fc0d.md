# Instrucciones

Nota: este ejercicio es una continuación del ejercicio `need-for-speed`.

En este ejercicio organizarás carreras entre distintos tipos de autos a control remoto.
Cada auto tiene sus propias características de velocidad y de drenaje de batería.

Los autos comienzan con la batería llena (100%).
Cada vez que conduces el auto con el control remoto, este recorre en metros su velocidad y reduce el porcentaje restante de batería según su drenaje de batería.

Si la batería de un auto está por debajo del porcentaje de su drenaje de batería, ya no puedes conducirlo.

El auto a control remoto tiene una elegante pantalla LED que muestra dos datos:

- La distancia total que ha recorrido, que se muestra así: `"Driven <METERS> meters"`.
- La carga de batería restante, que se muestra así: `"Battery at <PERCENTAGE>%"`.

Cada pista de carreras tiene su propia distancia.
Los autos se ponen a prueba comprobando si pueden terminar la pista sin quedarse sin batería.

## 1. Conduce el auto

Implementa el método `Drive` en el `Car` que actualiza la cantidad de metros recorridos según la velocidad del auto y reduce la batería de acuerdo con el drenaje de batería:

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)
car.Drive()
// car is now Car{speed: 5, batteryDrain: 2, battery: 98, distance: 5}
```

Nota: no intentes conducir el auto si al hacerlo la batería del auto quedará por debajo de 0.

## 2. Muestra la distancia recorrida

Implementa un método `DisplayDistance` en `Car` que devuelva la distancia tal como se muestra en la pantalla LED, como un `string`:

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)

fmt.Println(car.DisplayDistance())
// Output: "Driven 0 meters"
```

## 3. Muestra el porcentaje de batería

Implementa el método `DisplayBattery` en `Car` que devuelva el porcentaje de batería tal como se muestra en la pantalla LED, como un `string`:

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)

fmt.Println(car.DisplayBattery())
// Output: "Battery at 100%"
```

## 4. Comprueba si un auto a control remoto puede terminar una carrera

Para terminar una carrera, un auto debe poder recorrer la distancia de la carrera.
Esto significa no agotar su batería antes de cruzar la línea de meta.
Implementa el método `CanFinish` que recibe un `trackDistance int` como parámetro y devuelve `true` si el auto puede terminar la carrera; de lo contrario, devuelve `false`:

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)

trackDistance := 100

car.CanFinish(trackDistance)
// => true
```
