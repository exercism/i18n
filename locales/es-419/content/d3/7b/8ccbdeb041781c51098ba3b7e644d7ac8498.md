# Pistas

## 1. Seguimiento de las rondas de póker

- La función [`list`][list] devuelve una lista que consiste en los argumentos que recibe.

## 2. Mantener todas las rondas en el mismo lugar

- La función [`concat`][concat] se puede usar para concatenar dos listas.

## 3. Encontrar las rondas anteriores

- La función [`some`][some] devuelve el primer valor lógicamente verdadero de una colección.
- La función [`boolean`][boolean] es útil cuando una función devuelve un valor, pero las pruebas esperan un boolean.

## 4. Promediar los valores de las cartas

- Recuerda los operadores aritméticos básicos, como [`/`][division] y [`+`][addition].
- Una colección de números se puede sumar con [`apply`][apply] o con [`reduce`][reduce].
- La función [`count`][count] devuelve el número de elementos de una colección.
- La función [`/`][division] devuelve un tipo ratio cuando opera con enteros. Puedes usar [`double`][double] para convertir una razón a un decimal.

## 5. Promedios alternativos

- Existen funciones de secuencia para obtener el primer o el último elemento de una colección secuencial: [`first`][first] y [`last`][last].
- Para encontrar la carta de en medio, puedes dividir el número de cartas entre 2, redondear al entero más bajo con [`int`][int] y obtener la carta en ese índice con [`nth`][nth].
- Usa [`or`][or] para determinar si alguna de las condiciones es verdadera.

## 6. Más técnicas de promedio

- Una forma de obtener las cartas en índices pares/impares sería aplicar [`map`][map] a una función que use [`nth`][nth] sobre un [`range`][range], que acepta un argumento `step` opcional.

## 7. Reglas de la ronda de bonificación

- Recuerda cómo usar [`if`][if] del ejercicio sobre condicionales.
- Puedes devolver todos los elementos de una colección excepto el último con [`butlast`][butlast].
