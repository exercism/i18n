# Acerca de

ColdFusion (CFML) es un lenguaje de scripting para la JVM cuya sintaxis es similar a la de C o JavaScript. 
Se compila JIT a código de bytes que se ejecuta en la JVM, pero es dinámico y de tipado flexible, lo que lo hace rápido y fácil para desarrollar. 
CF es un lenguaje multiparadigma, que admite tanto la programación orientada a objetos clásica como la programación funcional.

CFML también cuenta con un lenguaje de plantillas basado en etiquetas, incorporado en el propio lenguaje, que lo hace ideal para aplicaciones web. 
Se ejecuta en un contenedor J2EE con muchas bibliotecas incluidas que lo hacen muy productivo, sin necesidad de instalar un montón de paquetes. 
CFML tiene soporte nativo para archivos zip, generación de PDF y Excel, correos electrónicos, FTP, HTTP, sistemas de archivos S3, bibliotecas de seguridad ESAPI, controladores JDBC, JSON y API REST.  

CFML también puede sacarle provecho a cualquier proyecto de Java: basta con colocar los jars en el proyecto e instanciar objetos de Java directamente en tu código. 
Puedes aprender más sobre la sintaxis básica y los tipos de datos primitivos en esta guía: [Modern ColdFusion (CFML) in 100 Minutes](https://modern-cfml.ortusbooks.com/)
