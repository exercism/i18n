# Usa la interpolación de string, no la concatenación de string

Usa la [interpolación de string](https://csharp.net-tutorials.com/operators/the-string-interpolation-operator/) para construir un string de forma dinámica, en lugar de usar la concatenación de string. La principal ventaja es que hay menos «ruido»; mientras que la concatenación de string requiere agregar `+` entre cada string, la interpolación de string no tiene esa limitación. Como resultado, el código con interpolación de string suele ser un poco más fácil de leer.
