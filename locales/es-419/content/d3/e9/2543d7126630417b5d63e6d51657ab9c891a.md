# Instrucciones

El nuevo aeropuerto de Berlín te contrató como desarrollador para su laboratorio de robots.
Tienen robots torpes, de aspecto un tanto humanoide, que están tratando de usar para mejorar la atención al cliente.

Tu primera tarea en el trabajo es programar el robot para que salude a las personas en su idioma nativo después de que escaneen sus pasaportes en el mostrador de auto check-in.

El robot está orgulloso de sus habilidades, así que siempre dirá primero qué idioma puede hablar y luego saludará a la persona.
Por ejemplo, si alguien escanea un pasaporte alemán, el robot diría:

```txt
I can speak German: Hallo Dietrich!
```

## 1. Crea la funcionalidad abstracta de saludo

Necesitas estructurar tu código para que tú y otros desarrolladores puedan agregar idiomas fácilmente.

Como primer paso, define un trait `Greeter` con dos funciones.

- `language_name`, que devuelve el idioma (un `ByteArray`) que el robot usará para saludar al visitante.
- `greet`, que acepta el nombre de un visitante (un `ByteArray`) y devuelve el mensaje de saludo en un idioma específico (un `ByteArray`).

Luego, implementa una función `say_hello` que acepta el nombre del visitante y algo que implementa el trait `Greeter`, y que devuelve el saludo deseado (un `ByteArray`).
Por ejemplo, imagina una implementación alemana de `Greeter` para la cual `language_name` devuelve `"German"` y `greet` devuelve `"Hallo {name}!"`:

```rust
say_hello("Dietrich", germanGreeter)
// => "I can speak German: Hallo Dietrich!"
```

## 2. Implementa el italiano

Ahora haz que el robot funcione para las personas que escanean pasaportes italianos.

Crea una struct `Italian` e implementa las dos funciones para cumplir con el trait `Greeter` de la tarea 1.
Puedes saludar a alguien en italiano con `"Ciao {name}!"`.

## 3. Implementa el francés

Antes de dar por terminado el día, se supone que debes agregar la funcionalidad para saludar a las personas en francés.

Crea una struct `French` e implementa las dos funciones para cumplir con el trait `Greeter`.
Puedes saludar a alguien en francés con `"Bonjour {name}!"`.
