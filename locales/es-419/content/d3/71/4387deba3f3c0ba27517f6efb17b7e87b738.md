# Introducción

Pyret tiene dos primitivas Boolean distintas, `true` y `false`.
Estos dos valores representan si una afirmación o condición es válida o no.

```pyret
"a" == "a" # true
"a" == "b" # false
```

Pyret proporciona los operadores `and` y `or` que pueden combinar valores Boolean.

El operador and devuelve true si ambos lados son true y false para todas las demás combinaciones.

```pyret
true and true # true
true and false # true
false and true # false
false and false # false
```

El operador or devuelve true si al menos un lado es true y false si ambos lados son false.

```pyret
true or true # true
true or false # true
false or true # true
false or false # false
```

`not()` es una función incorporada que invierte un true a false o un false a true.

```pyret
not(true) # false
not(false) # true
```
