# Instalación

## Windows (Recomendado)

¿Usas un sistema operativo Windows?

Presiona `Windows Key`, escribe `cmd` y presiona `enter`.

> Batch ya está instalado en tu sistema si tu sistema operativo es Windows.

Si usas un sistema operativo diferente, puedes instalar Batch siguiendo las instrucciones de abajo.

## Mac OS

1. Gatekeeper no debe estar configurado para bloquear paquetes sin firma.
2. Abre la aplicación Terminal.
3. Ejecuta el siguiente comando para instalar Batch:

```bash
brew install --cask --no-quarantine wine-stable
```

## Ubuntu

1. Si tu sistema es de 64 bits, habilita la arquitectura de 32 bits (si aún no lo has hecho):

```bash
sudo dpkg --add-architecture i386
```

2. Agrega el repositorio de WineHQ:

```bash
sudo mkdir -pm755 /etc/apt/keyrings
sudo wget -O /etc/apt/keyrings/winehq-archive.key https://dl.winehq.org/wine-builds/winehq.key
sudo apt update
```

3. Instala WineHQ:

```bash
sudo apt install --install-recommends winehq-stable
```

## Fedora

1. Habilita el repositorio de Wine:

```bash
# Fedore 39
dnf config-manager --add-repo https://dl.winehq.org/wine-builds/fedora/39/winehq.repo

# Fedora 40
dnf config-manager --add-repo https://dl.winehq.org/wine-builds/fedora/40/winehq.repo
```

2. Instala WineHQ:

```bash
dnf install winehq-stable
```
