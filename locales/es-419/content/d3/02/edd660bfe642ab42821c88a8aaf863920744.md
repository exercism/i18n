# Introducción

Los métodos pueden tener un parámetro varargs, lo que permite a quien llama especificar cero o más argumentos como si fueran parámetros normales. El método recibe esos argumentos en un solo array.

Para que un parámetro sea un parámetro varargs, agrega la palabra clave `params` a la declaración del parámetro:

```csharp
public static void PrintNumbers(params int[] numbers)
{
    foreach (var number in numbers)
    {
        Console.Write(number)
    }
}

// No values for a varags parameter is allowed
PrintNumbers();

PrintNumbers(1);
// => 1

PrintNumbers(1, 2, 3);
// => 123
```
