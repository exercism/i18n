# Instrucciones

Mientras te preparabas para hornear galletas para tus amigos, descubriste que tienes que convertir algunas de las medidas que usa la receta. Como solo conoces el sistema métrico, necesitas idear una forma de convertir las medidas de repostería estadounidenses comunes a mililitros (mL) para que te resulte más fácil.

Usa esta tabla de conversión para tu solución:

| Unidad a convertir | volumen | en mililitros (mL) |
| --------------- | ------ | ------------------- |
| mL              | 1      | 1                   |
| taza estadounidense | 1  | 240                 |
| onza líquida estadounidense | 1 | 30          |
| cucharadita estadounidense | 1 | 5            |
| cucharada estadounidense | 1  | 15                  |

Como eres un programador talentoso en formación, decides usar los mililitros como unidad intermedia para facilitar la conversión de cualquier unidad de la lista a cualquier otra (incluso a sí misma).

## 1. Obtén el componente numérico de un par de volumen

Implementa la función `KitchenCalculator.get_volume/1`. Dada una tupla de par de volumen, debe devolver solo el componente numérico.

```elixir
KitchenCalculator.get_volume({:cup, 2.0})
# => 2.0
```

## 2. Convierte el par de volumen a mililitros

Implementa la función `KitchenCalculator.to_milliliter/1`. Dada una tupla de par de volumen, debe convertir el volumen a mililitros usando la tabla de conversión.

Usa múltiples cláusulas de función y coincidencia de patrones para crear las funciones de cada unidad. Los átomos que se usan para denotar cada unidad son: `:cup`, `:fluid_ounce`, `:teaspoon`, `:tablespoon`, `:milliliter`. Devuelve el resultado de la conversión envuelto en una tupla.

```elixir
KitchenCalculator.to_milliliter({:cup, 2.5})
# => {:milliliter, 600.0}
```

## 3. Convierte el par de volumen en mililitros a otra unidad

Implementa la función `KitchenCalculator.from_milliliter/2`. Dada una tupla de par de volumen y la unidad deseada, debe convertir el volumen a la unidad deseada usando la tabla de conversión.

Usa múltiples cláusulas de función y coincidencia de patrones para crear las funciones de cada unidad. Los átomos que se usan para denotar cada unidad son: `:cup`, `:fluid_ounce`, `:teaspoon`, `:tablespoon`, `:milliliter`

```elixir
KitchenCalculator.from_milliliter({:milliliter, 1320.0}, :cup)
# => {:cup, 5.5}
```

## 4. Convierte de cualquier unidad a cualquier unidad

Implementa la función `KitchenCalculator.convert/2`. Dada una tupla de par de volumen y la unidad deseada, debe convertir el volumen dado a la unidad deseada.

```elixir
KitchenCalculator.convert({:teaspoon, 9.0}, :tablespoon)
# => {:tablespoon, 3.0}
```
