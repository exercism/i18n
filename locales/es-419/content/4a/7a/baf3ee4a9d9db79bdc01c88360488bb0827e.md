# Aprendizaje

Exercism ofrece ejercicios y retroalimentación, pero puede ser difícil empezar para quienes aprenden Pascal por primera vez. Estos recursos pueden ayudarte a dar los primeros pasos:

* [Pascal Tutorial](https://www.tutorialspoint.com/pascal/index.htm) parece un buen lugar para empezar con Pascal si no tienes ninguna experiencia con este lenguaje. No necesitas Delphi para completar los ejercicios que cubre este tutorial. Puede ser un buen lugar para practicar antes de lanzarte a los ejercicios de aquí, que sí requieren Delphi para completarlos.
* [Pascal-Programming.info](http://www.pascal-programming.info/index.php) también parece tener un buen tutorial para quienes recién empiezan con el lenguaje.
* También hay muchas más fuentes en internet para aprender Pascal, demasiadas para enumerarlas aquí.
