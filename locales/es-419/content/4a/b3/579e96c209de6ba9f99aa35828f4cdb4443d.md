# Introducción

A menudo es útil agrupar una colección de elementos y manejar esos grupos como unidades. En Rust, llamamos a ese grupo un struct, y a cada elemento uno de los campos del struct. Un struct define el conjunto general de campos disponibles, pero un ejemplo particular de un struct se llama instancia.

Además, los structs pueden tener métodos definidos en ellos, que tienen acceso a los campos. En ese caso, se hace referencia al propio struct como `self`. Cuando un método usa `&mut self`, los campos se pueden cambiar, o mutar. Cuando un método usa `&self`, los campos no se pueden cambiar: son inmutables. Controlar la mutabilidad ayuda al borrow checker a garantizar que clases enteras de bugs de concurrencia simplemente no ocurran en Rust.

En este ejercicio, vas a implementar dos tipos de métodos en un struct. Los primeros se conocen generalmente como getters: exponen los campos del struct al mundo, sin dejar que nadie más mute ese valor. En Rust, estos métodos comparten idiomáticamente el nombre del campo que exponen; es decir, si tenemos un método getter que obtiene un campo del struct llamado `name`, el método simplemente se llamaría `name()`.

También vas a implementar métodos de otro tipo, conocidos generalmente como setters. Estos cambian el valor del campo. Los setters no son muy comunes en Rust (si un campo se puede modificar libremente, es más común simplemente hacerlo público), pero son útiles si actualizar el campo debería tener efectos secundarios, o para el control de acceso: un setter marcado como `pub(crate)` permite que otros módulos dentro del mismo crate actualicen un campo privado, que no puede ser afectado por el mundo exterior.

Los structs vienen en tres variantes: structs con campos con nombre, structs de tupla y structs unitarios. Para este ejercicio de concepto, vamos a explorar la primera variante: structs con campos con nombre.

Los structs se definen con la palabra clave `struct`, seguida del nombre del tipo que describe el struct, con mayúscula inicial:

```rust
struct Item {}
```

Luego se incorporan tipos adicionales al cuerpo del struct como _campos_ del struct, cada uno con su propio tipo:

```rust
struct Item {
    name: String,
    weight: f32,
    worth: u32,
}
```

Por último, se pueden definir métodos en los structs dentro de un bloque `impl`:

```rust
impl Item {
    // initializes and returns a new instance of our Item struct
    fn new() -> Self {
        todo!()
    }
}
```
