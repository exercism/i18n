# Anexo a las instrucciones

## Pistas

Las pruebas de este ejercicio son diferentes de las pruebas habituales. Normalmente, una prueba comprueba si, para una entrada dada, la salida coincide con el valor esperado. A esto se le llama _pruebas basadas en valores_. Sin embargo, este ejercicio usa _pruebas basadas en propiedades_, en las que las pruebas comprueban si, para un rango de entradas, la salida tiene una propiedad específica. Las dos diferencias clave que distinguen las pruebas basadas en propiedades de las pruebas basadas en valores son:

1. Una prueba basada en propiedades no trabaja con un solo valor de entrada, sino con muchos.
1. Una prueba basada en propiedades verifica propiedades, no valores concretos.

En este ejercicio, todas las pruebas verifican una propiedad de la forma de diamante que tu código debe producir. Además, todas las pruebas comprueban si la propiedad que verifican se cumple para todas las letras de entrada válidas ('A' a 'Z').

Para facilitar las pruebas basadas en propiedades, las pruebas de este ejercicio hacen uso de los paquetes [FsCheck](https://www.nuget.org/packages/FsCheck) y [FsCheck.Xunit](https://packages.nuget.org/packages/FsCheck.Xunit/2.2.0). Para aprender más sobre FsCheck, puedes encontrar la documentación del framework [aquí](https://fscheck.github.io/FsCheck/).

Si quieres más información sobre las pruebas basadas en propiedades, consulta [este artículo](http://www.erikschierboom.com/2016/02/22/property-based-testing/).
