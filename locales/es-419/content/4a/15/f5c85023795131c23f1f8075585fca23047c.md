# Acerca de

Muchos operadores también se pueden usar como [asignaciones compuestas][compound-assignment], que son una notación abreviada en la que `x = op y` se puede escribir como `x op= y`:

```csharp
var features = PhoneFeatures.Call;
features |= PhoneFeatures.Text;
features &= ~PhoneFeatures.Call;
```
