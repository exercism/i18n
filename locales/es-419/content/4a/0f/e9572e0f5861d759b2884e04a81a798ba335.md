# Instrucciones

Te han contratado como especialista en expresiones regulares en una empresa que está desarrollando un chatbot.

Está en una fase de desarrollo muy básica, así que tu misión es usar expresiones regulares para mejorar la capacidad del chatbot de entender y generar lenguaje natural.

~~~~exercism/note
Con fines de aprendizaje, resuelve estas tareas usando expresiones regulares.

Sabemos que a veces son posibles otras alternativas (¡y que incluso pueden ser más eficientes!)
~~~~

## 1. Verifica si un comando es válido

Aparte de ser inteligente, el chatbot también es un asistente leal.

Para pedirle algo al chatbot, el usuario debe decir la palabra «**Chatbot**» en la primera posición del comando.

No importa si la palabra clave está en MAYÚSCULAS o minúsculas.
Lo importante aquí es la posición de la palabra.

Implementa la función `is_valid_command()` que ayuda al chatbot a reconocer cuándo el usuario está dando un comando.

```R
is_valid_command("Chatbot, play a song from the 80's.")
[1] TRUE
> is_valid_command("Hey Chatbot, where is the closest pharmacy?")
[1] FALSE
> is_valid_command("CHATBOT, do you have a solution for this challenge?")
[1] TRUE
```

## 2. Elimina los emojis cifrados

Al chatbot le cuesta entender cómo las personas usan los emojis para expresar sus emociones.

Cuando el chatbot recibe mensajes del usuario, cada emoji se representa como «_emoji_» seguido de su número _id_.

Implementa el método `remove_emoji()` para tomar un string y eliminar todo el cifrado de los emojis en el mensaje.

Las líneas que no contengan el texto del emoji deben devolverse sin modificar.

Solo elimina el string del emoji. No intentes ajustar los espacios en blanco.

```R
remove_emoji("I love playing videogames emoji3465 it's one of my hobbies")
[1] "I love playing videogames  it's one of my hobbies"
```

## 3. Verifica si un número de teléfono es válido

Dado que las funcionalidades del chatbot se descargan en una app móvil, se espera que el usuario escriba un número de teléfono durante la conversación.

El problema es que el chatbot solo puede leer y validar un número con un formato específico.

Si el número es válido (coincide con la secuencia de caracteres especificada por la **expresión regular**), el chatbot responde con un mensaje que agradece al usuario y confirma el número. Si el número no es válido, la función le informa al usuario que el número de teléfono no es válido.

El formato esperado es: (+##) ###-###-###

```R
check_phone_number("(+34) 659-771-594")
[1] "Thanks! You can now download me to your phone."
> check_phone_number("659-771-594")
[1] "Oops, it seems like I can't reach out to 659-771-594"
```

## 4. Saluda al usuario

Para almacenar los datos de todas las personas que han conversado con él, el chatbot puede obtener el nombre completo del perfil del usuario con este estilo: **«Smith, John»**.

De esta manera, queremos que nuestro chatbot sea realmente cortés y cause una buena impresión.

Escribe la función `nice_to_meet_you()` que toma un string con el nombre completo del usuario y devuelve el string **«Nice to meet you, John Smith»**

```R
nice_to_meet_you("Smith, John")
#> Nice to meet you, John Smith
```

## 5. Obtén el enlace del sitio web

El chatbot es un software muy curioso. Aunque puede buscar en internet sobre un tema en particular, le gusta preguntar a los usuarios sobre sitios web interesantes o URLs para encontrar información relevante.

Ejemplo de conversación:

- **Chatbot**: Hola, nombre de usuario, me gustaría aprender a programar en JavaScript, ¿conoces algún sitio web interesante donde pueda aprender?
- **Usuario**: Aprendí mucho de [exercism.org](http://exercism.org)

Implementa la función `get_URL()` que puede devolver un array con solo el enlace de cada sitio web.

```R
get_URL("I learned a lot from exercism.org")
[1] "exercism.org"
```
