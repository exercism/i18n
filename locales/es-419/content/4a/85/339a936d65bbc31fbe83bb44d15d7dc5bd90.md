# Aprendizaje

## Aprender Python desde cero
Python es (_como [dice Wikipedia][wikipython]_), un *lenguaje de programación de alto nivel y de propósito general*.
Se puede usar para escribir una gran variedad de tipos distintos de software, desde videojuegos hasta servidores HTTP y herramientas de línea de comandos, y muchísimas cosas más.
Es especialmente bueno para «pegar» distintos sistemas y programas entre sí.


Y creemos que la mejor forma de aprender es _jugar_ y _practicar_ con proyectos de programación grandes y pequeños, o con problemas pequeños como los que encontrarás aquí en Exercism.
