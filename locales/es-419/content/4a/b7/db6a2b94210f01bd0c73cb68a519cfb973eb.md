# Introducción

## Uniones discriminadas

El tipo de unión discriminada representa una cantidad fija de casos con nombre. Cada valor de una unión discriminada corresponde exactamente a uno de los casos con nombre.

Una unión discriminada se define con la palabra clave `type`, con los casos separados por el carácter de barra vertical (`|`):

```fsharp
type Season =
    | Spring
    | Summer
    | Autumn
    | Winter
```

Cada caso de una unión discriminada puede tener datos asociados de forma opcional, y distintos casos pueden tener distintos tipos de datos. Si ninguno de los casos tiene datos asociados, la unión discriminada se parece a lo que en otros lenguajes suele llamarse una _enumeración_ (o _enum_).

```fsharp
type Number =
    | Integer of int
    | Float of float
    | Invalid
```

Para crear un valor de un caso específico, puedes hacer referencia a su nombre (por ejemplo, `Success`). Como los nombres de los casos son solo funciones constructoras, los datos asociados se pueden pasar como un argumento normal de función. Si otra unión discriminada definió un caso con el mismo nombre, vas a tener que usar su nombre completo (por ejemplo, `Result.Success`).

```fsharp
let byName = Integer 2
let byFullName = Number.Invalid
```

Las uniones discriminadas tienen _igualdad estructural_, lo que significa que dos valores del mismo caso y con los mismos datos (opcionales) son equivalentes.

Aunque puedes usar expresiones `if/elif/else` para trabajar con uniones discriminadas, la forma recomendada de trabajar con ellas es mediante la coincidencia de patrones con el _patrón de identificador_:

```fsharp
let describe number =
    match number with
    | Integer i -> sprintf "Integer: %d" i
    | Float d  -> sprintf "Float: %f" d
    | Invalid   -> "Invalid"
```
