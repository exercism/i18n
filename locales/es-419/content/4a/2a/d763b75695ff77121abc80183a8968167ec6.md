# Instrucciones

Te contrataron como especialista en expresiones regulares en una empresa que está desarrollando un Chatbot.

Está en una fase de desarrollo muy básica.
Tu misión es usar expresiones regulares para mejorar la capacidad del Chatbot de entender y generar lenguaje natural.

## 1. Verifica si un comando es válido

Además de ser inteligente, el Chatbot también es un asistente leal.
Para preguntarle algo al Chatbot, el usuario debe decir la palabra «**Chatbot**» en la primera posición del comando.
No importa si la palabra clave está en MAYÚSCULAS o minúsculas.
Lo importante es la posición de la palabra.

Implementa la función `is_valid_command`, que ayuda al Chatbot a reconocer cuándo el usuario le está dando un comando.

```jq
"Chatbot, play a song from the 80's." | is_valid_command
# => true
"Hey Chatbot, where is the closest pharmacy?" | is_valid_command
# => false
"CHATBOT, do you have a solution for this challenge?" | is_valid_command
# => true
```

## 2. Elimina los emojis cifrados

Al Chatbot le cuesta entender cómo las personas usan los emojis para expresar sus emociones.
Cuando el Chatbot recibe mensajes de los usuarios, cada emoji se representa como el string «emoji» seguido de un _número de id_.

Implementa el método `remove_emoji`, que recibe un string y elimina todos los emojis a lo largo del mensaje.

Las líneas que no contengan emojis se deben devolver sin modificaciones.
Solo elimina el string del emoji.
No ajustes los espacios en blanco.

```jq
"I love playing videogames emoji3465 it's one of my hobbies" | remove_emoji
# => "I love playing videogames  it's one of my hobbies"
```

## 3. Verifica si un número de teléfono es válido

En algún momento de la interacción con el Chatbot, el usuario proporcionará un número de teléfono.
El Chatbot solo puede llamar a un número con un formato específico.

Implementa la función `check_phone_number`.

Si el número es válido, el Chatbot responde con un mensaje que le agradece al usuario y confirma el número.
Si el número no es válido, el Chatbot le informa al usuario que el número de teléfono no es válido.

El formato esperado es `(+NN) NNN-NNN-NNN`, donde N es un dígito.

```jq
"chatbot my phone number is (+34) 659-771-594" | check_phone_number
# => "Thanks! Your phone number is OK."
"chatbot, call me at 659-771-594" | check_phone_number
# => "Oops, it seems like I can't reach out to 659-771-594."
```

## 4. Obtén el enlace de un sitio web

El Chatbot es un programa realmente curioso.
Aunque puede buscar en internet sobre un tema en particular, le gusta preguntarles a los usuarios por sitios web interesantes que visitar para encontrar información relevante.

Conversación de ejemplo:

> **Chatbot**: Hola, usuario. Me gustaría aprender a programar en JavaScript. ¿Conoces algún sitio web interesante donde pueda aprender?

> **Usuario**: Aprendí mucho en exercism.org, hay un montón de cosas geniales ahí.

Implementa la función `get_domains`, que devuelve un array de dominios de sitios web.

```jq
"I learned a lot from exercism.org and google.com" | get_domains
# => ["exercism.org", "google.com"]
```

## 5. Saluda al usuario

Un Chatbot educado se dirige a los usuarios por su nombre.
Cuando un usuario se presenta, nuestro Chatbot detecta su nombre y responde con un saludo amistoso.

Escribe la función `nice_to_meet_you`.

Si el string de entrada contiene «My name is Someone.», captura el nombre y devuelve el string «Nice to meet you, Someone.».

```jq
"My name is Jean-Luc" | nice_to_meet_you
# => "Nice to meet you, Jean-Luc"
```

## 6. Análisis de CSV muy sencillo

Cediendo a la tentación de agregar cada vez más funcionalidades, vamos a agregarle una función de análisis de CSV al Chatbot.

Implementa la función `parse_csv`, que recibe un string y devuelve un array con los campos resultantes.
El separador de campos debe ser «coma más espacio en blanco opcional».

No nos vamos a preocupar por los casos límite del formato CSV (como campos que contengan comas).

```jq
"first, second,third,   fourth" | parse_csv
# => ["first", "second", "third", "fourth"]
```
