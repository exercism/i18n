# Pruebas

Puedes usar el editor en línea del sitio web de Exercism para resolver los ejercicios.
O bien, descarga los ejercicios a tu computadora, resuélvelos localmente y luego envíalos a Exercism.

Si quieres trabajar localmente, necesitarás el programa [`bats`][bats].
Consulta la página [Pruebas en el track de Bash][test-bash] para las instrucciones de instalación.

Tu código se probará con el test runner de jq de Exercism usando [`jq` versión **1.8**][jq].

[bats]: https://github.com/bats-core/bats-core
[test-bash]: https://exercism.org/docs/tracks/bash/tests
[jq]: https://jqlang.org/manual/
