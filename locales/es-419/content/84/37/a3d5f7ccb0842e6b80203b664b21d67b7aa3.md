# Pistas

## 1. Hazlo magnífico

- El mapeo es el proceso correcto para aplicar una función a cada elemento de una secuencia.
- `mapcar` es una buena función para aplicar una función a cada elemento de una lista.

## 2. Solo lo mejor

- El filtrado es el proceso correcto para eliminar uno o más elementos de una secuencia, lo que da como resultado una nueva secuencia.
- `remove` puede eliminar de una secuencia los valores que son iguales a un elemento específico.
- `remove-if` puede eliminar los valores para los cuales una función de predicado se evalúa como un valor verdadero.
