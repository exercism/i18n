# Acerca de

## Variables y asignación

R es un lenguaje de [tipado dinámico][wiki-dynamic], así que en general no es necesario especificar el tipo de una variable. El tipo predeterminado es [`numeric`][ref-numeric], que normalmente se implementa como un número de punto flotante de doble precisión. Para forzar el uso de enteros de 32 bits, usa el sufijo `L` (abreviatura de `Long`).

Obtener el «tipo» de un objeto es, por razones históricas, potencialmente confuso.
Las funciones [`typeof()`][ref-typeof] y [`class()`][ref-class] son similares, pero pueden devolver resultados ligeramente distintos:

```R
typeof(50)
#> [1] "double"  # more specific: an implementation detail
typeof(50L)
##> [1] "integer"

class(50)
#> [1] "numeric"  # less specific: ignores implementation details
class(50L)
#> [1] "integer"
```

~~~~exercism/advanced
También es posible que veas referencias a `mode()`, que es similar a `typeof()`.

Ignora `mode()` y `storage.mode()`.
Solo se incluyen por compatibilidad con versiones anteriores.
~~~~

El operador de asignación preferido es `<-`.
Si trabajas en RStudio, puedes ingresarlo con el atajo de teclado `Alt-minus`.

```R
x <- 42
avogadro <- 6.02e23
mystr <- "Hello, World!"
```

Usar `=` en lugar de `<-` a menudo funciona, pero no siempre, y se desaconseja por ser un estilo pobre.

Los operadores son en su mayoría similares a los de muchos otros lenguajes, aunque `%%` y `%/%` son más inusuales.
Esta sintaxis con `%` es una forma de llamar a operadores infijos implementados como macros.

```R
2 + 3   # 5
2 - 3   # -1
2 * 3   # 6
2 / 3   # 0.6666667
8 %/% 3 # 2 (integer division)
8 %% 3  # 2 (remainder)
2 ^ 3   # 8 (exponential)
```

En R, `#` inicia un comentario de una sola línea.
No hay una sintaxis separada para comentarios multilínea.

## Funciones

Para definir una función:

```R
squareit <- function(x) {
    x * x
}
```

Las funciones pueden tener cero o más argumentos, separados por comas.
Los paréntesis `()` son necesarios con `function()`, incluso si no hay parámetros.

Se pueden especificar valores predeterminados para los argumentos de una función, aunque estos deben ir después de cualquier argumento sin valor predeterminado, y se usa `=` en lugar de `<-` para asignar el valor predeterminado.
Como un ejemplo bastante inútil:

```R
squareit <- function(x = 42) {
    x * x
}

squareit()
#> [1] 1764
```

Las llaves `{ }` no son estrictamente necesarias para cuerpos de función de una sola línea, pero incluirlas se considera un buen estilo.

R devolverá automáticamente el valor final de una función, como en los ejemplos anteriores.

`return()` se puede usar en cualquier parte del cuerpo de la función para hacer explícito un valor de retorno.
Devolverá el valor especificado de inmediato y terminará la función sin ejecutar ninguna de las expresiones restantes del cuerpo.

Una llamada explícita a `return()` normalmente solo es necesaria si se quiere salir de la función antes de tiempo y devolver un valor específico por alguna razón.
Un ejemplo podría ser dentro de una [cláusula `if-else`][concept-conditionals].

Sin embargo, algunos desarrolladores prefieren escribir `return()` de forma explícita, como cuestión de estilo de código.

Llamar a una función es igual que en muchos otros lenguajes:

```R
squareit(3)
#> [1] 9
```

En conceptos futuros veremos que el resultado `9` en realidad es un vector de longitud 1 y no un número escalar.
De ahí la inclusión de `[1]` para indicar que este es el comienzo del vector.

```R
is.vector(9)
#> [1] TRUE
```

_¡La mayoría de las cosas en R son algún tipo de vector!_
