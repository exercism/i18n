# Introducción

En Haxe, se puede definir una jerarquía de clases usando _herencia_, lo que permite que una clase derivada (`Car`) herede el comportamiento y los datos de su clase padre (`Vehicle`).

En la clase padre, puedes:

- Métodos que se pueden sobrescribir
- Métodos abstractos que deben implementar las clases derivadas

```haxe
abstract class Vehicle {
  public function new() {}

  // Can be overridden
  public function drive() {
    // ...
  }

  // Must be implemented
  public abstract function getSpeed():Int;
}

class Car extends Vehicle {
  public function new() {
    super(); // Runs the parent class' constructor
  }

  public override function drive() {
    // ...
  }

  public function getSpeed():Int {
    // ...
  }
}
```

Si la clase padre tiene un constructor, usamos `super()` para llamarlo:

```haxe
abstract class Vehicle {
  var wheels:Int;

  public function new(wheels:Int) {
    this.wheels = wheels
  }
}

class Car extends Vehicle {
  var color:String;

  public function new(wheels:Int, color:String) {
    super(wheels);
    this.color = color;
  }
}

```
