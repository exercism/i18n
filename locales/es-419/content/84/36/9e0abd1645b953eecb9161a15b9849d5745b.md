# Fundamentos

## Primeros pasos

### Variables

Para declarar una [variable][variables], usa el operador de asignación `=`.
En Crystal, las variables deben usar el formato [snake_case][snake-case].

```crystal
number = 1
puts number # => 1

number = 2
puts number # => 2
```

### Constantes

Las [constantes][constants] se declaran con el mismo operador de asignación `=`, pero usan todas las letras en mayúscula, lo que se conoce como SCREAMING_SNAKE_CASE.

```crystal
NUMBER = 1
puts NUMBER # => 1
```

Asignar un valor a una constante ya definida produce un error en tiempo de compilación.

```crystal
NUMBER = 1

NUMBER = 2
# Error: already initialized constant NUMBER
```

### Tipos

Crystal es un lenguaje compilado, lo que significa que a cada variable o argumento de un método se le asigna un tipo en tiempo de compilación.
El compilador es capaz de inferir el tipo de una variable o de un argumento de un método.
Sin embargo, en algunos casos es necesario especificar el tipo.
Los casos que requieren especificar un tipo se explican en conceptos posteriores.

### Métodos

Los [métodos][methods] son una forma de agrupar un conjunto de instrucciones que se pueden reutilizar.
En Crystal, los métodos suelen definirse dentro de una clase, un módulo o una estructura.
Sin embargo, los métodos también se pueden definir fuera de una clase, un módulo o una estructura.
Los métodos se declaran con la palabra clave `def`, seguida del nombre del método.
En Crystal, los nombres de los métodos deben escribirse en snake_case.
Puedes omitir los paréntesis cuando un método no tiene argumentos.
Para marcar el final de un método, debes usar la palabra clave `end`.

```crystal
def hello
  puts "Hello World!"
end
```

Usar un método que no existe para el tipo de una variable o de un argumento de un método produce un error en tiempo de compilación.

```crystal
number = 1
number + "1"
# Error: no overload matches 'Int32#+' with type String
```

### Argumentos

Los métodos pueden tener [argumentos][arguments].
Los argumentos son datos que se pasan a un método.
Para poder pasarle argumentos a un método, debes especificar el nombre del argumento.
En Crystal, los argumentos deben escribirse en snake_case.
Un método puede tener varios argumentos, pero deben separarse con una coma.

```crystal
def hello(name)
  puts "Hello #{name}!"
end
```

Los métodos también pueden tener varios argumentos.
En ese caso, los argumentos deben separarse con una coma.

```crystal
def hello(name, language)
  puts "Hello #{name}! You are learning #{language}."
end
```

### Llamar a métodos

Cuando llamas a un método que pertenece a una clase, un módulo o una estructura, debes usar el operador punto (`.`).
El formato debe ser: `<ClassName>.<method_name>`.
Cuando un método no pertenece a una clase, un módulo o una estructura, basta con llamarlo escribiendo su nombre.
Los métodos siempre devuelven de forma implícita el valor de la última expresión.

Cuando un método tiene argumentos, puedes usar paréntesis al especificarlos tanto en la llamada como en la definición del método, así: `<method_name>(<argument_1>, <argument_2>, ...)`.
Cuando un método no tiene argumentos, deben omitirse los paréntesis.

```crystal
def hello(name)
  "Hello #{name}!"
end

hello("Crystal")
# => Hello Crystal!
```

Al llamar a un método con varios argumentos, estos deben separarse con una coma.
Los argumentos deben indicarse en el mismo orden que los argumentos del método.

```crystal
def hello_language(name, language)
  "Hello #{name}! You are learning #{language}."
end

hello_language("World", "Crystal")
# => Hello World! You are learning Crystal.
```

Llamar a un método con un número incorrecto de argumentos produce un error en tiempo de compilación.

```crystal
hello_language("Crystal")
# wrong number of arguments for 'hello_language' (given 1, expected 2)
```

### Suma, resta y multiplicación

En Crystal, puedes usar el operador `+` para sumar dos números.
También puedes usar el operador `-` para restar dos números.
Y puedes usar el operador `*` para multiplicar dos números.

```crystal
1 + 1
# => 2

2 - 1
# => 1

2 * 2
# => 4
```

### Comentarios

En Crystal, los [comentarios][comments] se escriben con el carácter `#`, seguido de un espacio y luego el comentario.
Los comentarios se usan para documentar el código.
El compilador no ejecuta los comentarios.

```crystal
# This is a comment
```
