# Apéndice de instrucciones

## Formato de entrada

Cada ficha de dominó se almacena como un solo byte, con la mitad izquierda en el
[nibble] alto y la mitad derecha en el [nibble] bajo. Por ejemplo,
las piedras `[2|1]`, `[2|3]` y `[1|3]` se representan como los bytes
`0x21 0x23 0x13`.

## Registros

| Registro | Uso        | Tipo       | Descripción                                      |
| -------- | ---------- | ---------- | ------------------------------------------------ |
| `$a0`    | entrada    | dirección  | array de bytes de piedras                        |
| `$a1`    | entrada    | entero     | cantidad de piedras                              |
| `$v0`    | salida     | boolean    | las fichas de dominó se pueden encadenar (`0` = `false`, `1` = `true`) |
| `$t0-9`  | temporal   | cualquiera | se usan para almacenamiento temporal             |


[nibble]: https://en.wikipedia.org/wiki/Nibble
