# Instrucciones

En este ejercicio vas a ayudar a unas parejas de secundaria a declarar su amor en las redes sociales generando un corazón en ASCII con su inicial:

```
❤ J.  +  M. ❤
```

## 1. Limpia el nombre

Implementa el método `HighSchoolSweetheart.clean_up_name`.
Debe recibir un nombre, quitar todos los caracteres `-` y reemplazarlos por un espacio.
También debe quitar los espacios en blanco del principio y del final del nombre.

```crystal
HighSchoolSweetheart.clean_up_name("Jane-Ann")
# => "Jane Ann"
```

## 2. Obtén la primera letra del nombre

Implementa el método `HighSchoolSweetheart.first_letter`.
Debe recibir un nombre y devolver su primera letra.
Asegúrate de reutilizar `HighSchoolSweetheart.clean_up_name`, que definiste en el paso anterior.

```crystal
HighSchoolSweetheart.first_letter("Jane")
# => "J"
```

## 3. Da formato a la primera letra como inicial

Implementa el método `HighSchoolSweetheart.initial`.
Debe recibir un nombre y devolver su primera letra en mayúscula, seguida de un punto.
Asegúrate de reutilizar `HighSchoolSweetheart.first_letter`, que definiste en el paso anterior.

```crystal
HighSchoolSweetheart.initial("Robert")
# => "R."
```

## 4. Coloca las iniciales dentro del corazón

Implementa el método `HighSchoolSweetheart.pair`.
Debe recibir dos nombres y devolver las iniciales rodeadas de corazones emoji.
Asegúrate de reutilizar `HighSchoolSweetheart.initial`, que definiste en el paso anterior.

```crystal
HighSchoolSweetheart.pair("Blake Miller", "Riley Lewis")
# => "❤ B.  +  R. ❤"
```
