# Acerca de

Haskell tiene un tipo, `Num`, que es el tipo base de todos los tipos numéricos.
Hay cuatro subtipos principales dentro del tipo numérico: [`Int`][int], [`Integer`][integer], [`Double`][double] y [`Float`][float].

En Haskell hay dos tipos de enteros, que representan números enteros.
`Int` es un entero de tamaño fijo, mientras que `Integer` es un entero de precisión arbitraria.

Los `Integer` pueden contener cualquier número, sin importar lo grande que sea, hasta el límite de la memoria de tu computadora, mientras que `Int` corresponde al conjunto de los enteros positivos y negativos que se pueden expresar en 32 o 64 bits (garantizado al menos de -2^29 a 2^29 - 1).

Ten en cuenta que, al escribir números negativos, conviene usar paréntesis para evitar ambigüedades.

```haskell
1

(-1)
```

`Float` corresponde al conjunto de los números reales, limitado por la precisión de la computadora.
Las operaciones definidas sobre números suelen funcionar con un tipo o con el otro, pero no con ambos.

`Double` es un número de punto flotante de precisión doble.

```haskell
10.5
```

## Conversión entre enteros y números de punto flotante

Con la función `toFloat` puedes convertir un `Int` o un `Integer` a un `Float`.

```haskell
toFloat 1
-- -> 1.0
```

También existe `fromIntegral`, que convierte cualquier tipo numérico al tipo numérico inferido que se necesite.

```haskell
fromIntegral 1
-- -> 1.0
```

Para convertir un `Float` a un `Int`, puedes usar las funciones [`round`][round], [`floor`][floor] o [`ceiling`][ceiling].
La función `round` redondea al entero más cercano, `floor` redondea hacia abajo y `ceiling` redondea hacia arriba.

```haskell
round 1.5
-- -> 2

floor 1.5
-- -> 1

ceiling 1.5
-- -> 2
```

## Operadores aritméticos

Puedes usar los [operadores aritméticos básicos][math] con los tipos numéricos.
Los operadores son `+`, `-`, `*`, `/` y `%`.
Al usar estos operadores, los tipos de los números deben coincidir.
La función `fromIntegral` hace la conversión para que los tipos coincidan.

### Suma, resta y multiplicación

El operador `+` se usa para la suma, el operador `-` para la resta y el operador `*` para la multiplicación.

| Operador | Ejemplo        |
| -------- | -------------- |
| `+`      | `4 + 6 => 10`  |
| `-`      | `15 - 10 => 5` |
| `*`      | `2 * 3 => 6`   |

### División

La división se usa para dividir números.
El operador `/` se usa para la división.
El resultado siempre será un número de punto flotante.

```haskell
4.0 / 2.5
-- -> 1.6

4 / 2
-- -> 2.0
```

~~~~exercism/caution
En algunos lenguajes de programación, al dividir entre cero el resultado es un error.

En Haskell, al dividir entre cero el resultado es `Infinity` o `-Infinity`.
La única excepción es dividir cero entre cero, que da `NaN` (Not a Number).

```haskell
1 / 0
-- -> Infinity

(-1) / 0
-- -> -Infinity

0 / 0
-- -> NaN
```
~~~~

## División entera

La división entera se usa para dividir números enteros y obtener la parte entera del resultado.
Haskell tiene dos funciones de división entera, que difieren en cómo redondean cuando el resultado es negativo:

- `div` redondea hacia abajo, hacia el infinito negativo.
- `quot` redondea hacia cero.

```haskell
6 `div` 2
-- -> 3

5 `div` 2
-- -> 2

(-5) `div` 2
-- -> -3

5 `quot` 2
-- -> 2

(-5) `quot` 2
-- -> -2
```

~~~~exercism/caution
Dividir entre cero al usar la división entera produce una excepción.
Esto es distinto de la división normal.
~~~~

### Residuo

El residuo de una división entera se puede obtener con `mod` o `rem`.
Difieren en el signo del resultado cuando uno de los números es negativo:

- `mod` va de la mano con `div`, y su resultado tiene el mismo signo que el divisor.
- `rem` va de la mano con `quot`, y su resultado tiene el mismo signo que el dividendo.

```haskell
5 `mod` 3
-- -> 2

(-5) `mod` 3
-- -> 1

5 `mod` (-3)
-- -> -1

5 `rem` 3
-- -> 2

(-5) `rem` 3
-- -> -2

5 `rem` (-3)
-- -> 2
```

Para cualquier `x` e `y` (con `y` distinto de cero), se cumplen estas leyes:

```haskell
(x `div` y) * y + (x `mod` y) == x
(x `quot` y) * y + (x `rem` y) == x
```

~~~~exercism/note
Cuando ambos números son positivos, `div` y `quot` dan el mismo resultado, igual que `mod` y `rem`.
En ese caso, `quot` y `rem` pueden ser un poco más eficientes, ya que `div` y `mod` necesitan pasos adicionales para manejar los números negativos.
~~~~

~~~~exercism/caution
Dividir entre cero al usar `mod` o `rem` produce una excepción.
Esto es distinto de la división normal.

```haskell
1 `mod` 0
-- Exception: divide by zero
```
~~~~

## Potenciación

Haskell tiene tres operadores para «elevar a una potencia», que funcionan de manera distinta y aceptan diferentes tipos de argumentos.

- `**` Toma dos **números de punto flotante** y usa logaritmos para calcular la potencia.
- `^^` Toma un **número de punto flotante** y lo eleva a una potencia **entera** positiva o negativa.
- `^` Toma **cualquier tipo numérico** y lo eleva a una potencia **entera positiva**.

```haskell
3.0 ** 2.1
-- -> 10.04510856630514

2.5 ^^ 2
-- -> 6.25

2 ^ 3
-- -> 8
```

## Prioridad y paréntesis

Haskell permite usar paréntesis (`()`), que sirven para agrupar expresiones.
Esto es útil cuando quieres cambiar el orden de las operaciones.

Al usar varios operadores aritméticos, el orden de las operaciones es el mismo que en matemáticas, también conocido como [PEMDAS][pemdas].
Sigue el orden de paréntesis (`()`), exponentes (`**`), multiplicación (`*`) y división (`/`), y suma (`+`) y resta (`-`).

```haskell
2 + 3 - 4 * 4
-- -> -11

(2 + 3 - 4) * 4
-- -> 4
```
