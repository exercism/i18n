# Anexo de instrucciones

## Implementación

Define una función, `cost`, que calcule el costo de una lista de libros dada, según los descuentos definidos.

`cost` devolverá el costo total (después de los descuentos) en centavos.
Por ejemplo, para un solo libro, el costo es de 800 centavos, que equivalen a $8.00.
Para este ejercicio solo se necesitan cálculos con números enteros.
