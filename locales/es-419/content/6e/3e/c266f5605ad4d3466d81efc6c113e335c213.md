# Instalación

## Instalación

La forma más sencilla de instalar [Pharo](http://pharo.org) es usar una descarga [zero conf](http://pharo.org/download#//*[@id="main"]/div/h2[3]) desde la línea de comandos de una terminal.
<br/>_Nota: si intentas actualizar una instalación existente, consulta las [instrucciones de actualización](https://github.com/exercism/pharo-smalltalk/blob/main/docs/UPGRADE.md)._

Si usas Windows y no tienes instalado un shell estilo UNIX, salta a las instrucciones de [instalación en Windows](#windows-installation-skip-for-osxlinux) (más abajo).<br/>
Si eres un usuario de Linux más avanzado, quizá quieras consultar la [instalación para hackers de Linux](https://github.com/exercism/pharo-smalltalk/blob/main/docs/LINUX.md).

### Instalación en Linux/OSX

Para Linux/OSX (suponiendo que ya [instalaste Exercism](https://exercism.io/getting-started) y te uniste al [track de Pharo](https://exercism.io/my/tracks/pharo-smalltalk)), navega a tu directorio `/Exercism/pharo-smalltalk` y escribe:

```bash
curl https://get.pharo.org/64/ | bash
```

y lanza Pharo con las herramientas de Exercism pegando el siguiente «script de carga»:

```smalltalk
./pharo-ui Pharo.image eval "
Iceberg remoteTypeSelector: #httpsUrl.
Metacello new
 baseline: 'Exercism';
 repository: 'github://exercism/pharo-smalltalk:main/releases/latest';
 load.
#ExercismManager asClass welcome.
"
```

Si tienes algún problema de TIMEOUT al cargar las herramientas, sal de Pharo y limpia la caché de git escribiendo:

```rm -rf pharo-local/iceberg/```

Y después repite el ejemplo ```./pharo-ui ...``` de arriba.

Si sigues teniendo problemas, visita el canal de Discord de Pharo que se describe en la página de la [comunidad de Pharo](http://pharo.org/community).

Si todo funciona bien, verás barras de progreso de carga parpadear en la pantalla y luego aparecerá una ventana de System Browser.

**CONSEJO:** Cuando vayas a salir de Pharo, guarda tus cambios (elige el menú de Pharo y selecciona "Save and Quit").
Ahora puedes iniciar Pharo con Exercism ya cargado simplemente escribiendo:

```bash
./pharo-ui Pharo.image
```

### Instalación en Windows (omite esta sección si usas OSX/Linux)

Todavía estamos definiendo cuáles son los mejores requisitos de herramientas de línea de comandos para Windows, pero también puedes instalar Pharo de forma gráfica con el [Windows Pharo Launcher](https://files.pharo.org/pharo-launcher/windows) (una herramienta práctica para administrar varias imágenes de Pharo). Este lanzador también está [disponible](http://pharo.org/download) para OSX y Linux si prefieres una interfaz gráfica.

1. Ejecuta el archivo .msi que descargaste para instalar el Pharo Launcher.  
2. Ejecuta el lanzador de Pharo.  
3. En la esquina superior izquierda, haz clic en "New". 
4. En la ventana, selecciona "Official distributions" en las categorías de plantillas.  
5. Para los ejercicios de Exercism, elige de la lista de plantillas de imágenes de Pharo la última versión estable (actualmente "Pharo 10.0 64-bit (stable)", que es la recomendada). 
6. Haz clic para resaltar una plantilla de imagen, dale un nombre y luego haz clic en el botón de crear imagen que está abajo (una forma de engranaje naranja).  
![Crear imagen desde el lanzador](https://github.com/exercism/pharo-smalltalk/raw/main/docs/images/Create-image-from-launcher.png)
7. Una vez que se descargue la plantilla, aparecerá a la derecha en la tabla Existing Images. Haz clic en ella y luego haz clic en el botón de lanzar que está arriba (una flecha verde de _play_).  
![Lanzar imagen](https://github.com/exercism/pharo-smalltalk/raw/main/docs/images/Launch-image.png)


8. Cuando la imagen de Pharo se haya iniciado, abre un Playground eligiendo el menú _Browse_ y seleccionando _Playground_, o usa
`ctrl + o + w`.  
![Abrir Playground](https://github.com/exercism/pharo-smalltalk/raw/main/docs/images/Open-Playground.png)


9. Por último, copia y pega el siguiente fragmento en el playground:
```smalltalk
Iceberg remoteTypeSelector: #httpsUrl.
Metacello new
 baseline: 'Exercism';
 repository: 'github://exercism/pharo-smalltalk:main/releases/latest';
 load.
#ExercismManager asClass welcome.
```

Luego evalúa el código pegado seleccionándolo todo, haciendo clic derecho y seleccionando _Do it_ en el menú (o usando `ctrl + d`).

**Si todo funciona bien**, verás barras de progreso de carga parpadear en la pantalla y luego aparecerá una ventana de System Browser.


## Primeros pasos (TODOS)

Cuando inicies Pharo, verás un proyecto Welcome, en un [System Browser](https://medium.com/@richardeng/pharo-quick-start-5bab70944ce2#3099) (_consejo:_ si alguna vez pierdes esta ventana, puedes abrir una nueva desde el menú Tools|System Browser).


![Pantalla de bienvenida de Pharo](https://github.com/exercism/pharo-smalltalk/raw/main/docs/images/PharoWelcomeScreen.png)

El panel superior izquierdo del System Browser muestra los paquetes de tu entorno, y notarás que el script de instalación ya configuró
un paquete llamado `Exercism`, que contiene una etiqueta de subproyecto llamada `Welcome`. El segundo panel muestra las clases, y también hay una clase llamada `Welcome`. Debajo del panel de clases hay 4 botones de opción: "Flat" (muestra las clases del paquete), "Hier." (muestra una jerarquía de clases), "Inst. side" (muestra los métodos de instancia) y "Class side" (muestra los métodos y constructores de clase).

Si haces clic en la pestaña Comment, puedes ver las instrucciones más recientes para usar Pharo Exercism. Lee los comentarios e intenta ejecutar tu primera prueba.

En otros lenguajes basados en archivos, normalmente irías a una terminal en este punto y usarías la CLI de Exercism para obtener el
siguiente ejercicio. Aunque Pharo puede trabajar con archivos de forma similar, el entorno está en realidad ajustado para trabajar con objetos vivos. Las clases, los métodos y el código fuente son, curiosamente, objetos como todo lo demás en Pharo. Aprenderás más sobre esto a lo largo de este track.

## Cargar ejercicios

Para Exercism, incluimos un plugin que te permite obtener y enviar ejercicios de Pharo desde dentro del IDE.
Todo lo que necesitas hacer es hacer clic derecho en un paquete de ejercicio (en este caso, el paquete Welcome en el panel superior izquierdo) y seleccionar el
elemento de menú `Exercism | Fetch Exercise`. Esto te pedirá el nombre de un ejercicio (por ejemplo, hello-world) y, cuando lo escribas, lo obtendrá automáticamente por ti.

Los nombres de los ejercicios aparecen en la descripción de cada ejercicio en tu página del [track de Pharo](https://exercism.io/my/tracks/pharo) (a la derecha del todo).
Hay una instrucción *Download* con una cadena de CLI que contiene la clave de cada ejercicio. También puedes usar el botón de copiar que está junto a las instrucciones de la CLI y pegar la cadena completa en el mensaje de búsqueda (y extraeremos la clave automáticamente).

Cuando hayas introducido un ejercicio válido, el plugin obtendrá el código correspondiente y lo mostrará en el System Browser, listo para que empieces a [programar con pruebas](tests.md).

Cuando todas tus pruebas pasen, puedes enviar tu solución usando el mismo menú contextual de tu paquete de ejercicio (haz clic derecho en la etiqueta del paquete y selecciona `Exercism | Submit Exercise...`)

![Menú de envío de Exercism](https://github.com/exercism/pharo-smalltalk/raw/main/docs/images/SubmitExercise.png)

Por último, usa el menú `Exercism | View Track Progress` para visitar el sitio web de Exercism y ver qué otros ejercicios se han desbloqueado para ti, además de publicar preguntas sobre tu envío para que los mentores las lean.

<br/>

**¿Sabías que...?** *Cuando inicias Pharo, en realidad estás restaurando una instantánea de una imagen de ejecución, similar a una imagen de sistema operativo de VMWare. Es un concepto poderoso que te permite suspender el trabajo a mitad de una operación, incluso mientras depuras algo. Cuando vuelvas a iniciar Pharo, podrás seguir recorriendo el código en el depurador restaurado o continuar un paso de refactorización.*

## Cómo restablecer tu token de la CLI

Si alguna vez necesitas restablecer tu token de la CLI por un problema de seguridad, visita tu página de [configuración de Exercism](https://exercism.io/my/settings)
y usa el botón de restablecer token. Cuando lo hayas hecho, debes borrar tu token anterior en Pharo Exercism evaluando el siguiente código en un Playground:

```smalltalk
ExercismHttpClient
    reset;
    promptForToken.
```
