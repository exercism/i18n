# Instrucciones

En este ejercicio implementarás un conjunto parcial de rutinas auxiliares para ayudar a limpiar nombres de identificadores.

A lo largo de las 6 tareas irás construyendo poco a poco las funciones `transform`, para convertir caracteres individuales, y `clean`, para convertir strings.

Un identificador válido se compone de cero o más letras, guiones bajos, guiones, signos de interrogación y emojis.

Si se pasa un string vacío a la función `clean`, se debe devolver un string vacío.

## 1. Reemplaza los guiones que encuentres por guiones bajos

Implementa la función `transform` para reemplazar los guiones por guiones bajos.

```fsharp
transform '-'  // => "_"
```

## 2. Elimina todos los espacios en blanco

Elimina todos los caracteres de espacio en blanco.
Esto incluye los espacios en blanco al inicio y al final.

```fsharp
transform ' '  // => ""
```

## 3. Convierte camelCase a kebab-case

Modifica la función `transform` para convertir camelCase a kebab-case.

```fsharp
transform 'D'  // => "-d"
```

## 4. Omite los caracteres que sean dígitos

Modifica la función `transform` para omitir cualquier carácter que sea numérico.

```fsharp
transform '7'  // => ""
```

## 5. Reemplaza las letras griegas minúsculas por signos de interrogación

Modifica la función `transform` para reemplazar cualquier letra griega en el rango de 'α' a 'ω'.

```fsharp
transform 'β' // => "?"
```

## 6. Combina estas operaciones para trabajar con un string

Implementa la función `clean` para aplicar estas operaciones a un string completo.

Los caracteres que quedan fuera de las reglas deben pasar sin cambios.

```fsharp
clean "  a2b Cd-ω😀  " //  => "ab-cd_?😀"
```

## Cómo armar un string a partir de caracteres

Este tema se tratará en detalle más adelante en el temario.

Por ahora, puede ser útil saber que existe una [función de orden superior][higher-order-function] llamada [`String.collect`][string-collect] que convierte una colección de `char`s en un string, usando una función que tú proporcionas.

```fsharp
let transform ch = $"{ch}_"
String.collect transform "abc"  // =>  "a_b_c_"
```
