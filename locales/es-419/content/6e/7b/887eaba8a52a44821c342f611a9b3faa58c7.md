# Instrucciones

Implementa una función que, dados dos puntos en el plano de coordenadas 2D, produzca un tercer punto tal que al conectar estos puntos se forme un triángulo equilátero. La función devolverá dos puntos, porque hay dos posibles «terceros» puntos que forman un triángulo equilátero a partir de los dos puntos iniciales. Vale la pena señalar que un triángulo equilátero se define como una figura de tres lados en la que los tres lados tienen la misma longitud.

La función recibe como entrada dos tuplas de Python, cada una especifica las coordenadas x e y de cada punto, como números de punto flotante. Por ejemplo, (0.0, 0.0) y (1.0, 1.0) podrían ser las entradas.

La función debe devolver una tupla que consta de dos tuplas, cada una especifica las coordenadas x e y de cada punto, como números de punto flotante. Por ejemplo, ((0.0, 0.0), (1.0, 1.0)) podría ser una posible salida.

La función debe lanzar una excepción ArithmeticError integrada de Python si el solucionador Z3 produce un resultado que no es satisfacible. También se debe lanzar un ArithmeticError si ambos puntos de entrada son iguales.

La función no debe usar la función «set_option()» de la biblioteca z3 para establecer parámetros globales. Esto se hace dentro de los casos de prueba para garantizar que los números de punto flotante tengan la precisión esperada (cantidad de decimales).

Dado que la interpretación del modelo de una variable Real de Z3 es una instancia de AlgebraicNumRef, IntNumRef o RatNumRef, se proporciona una función para convertir esta instancia a un número de punto flotante.
