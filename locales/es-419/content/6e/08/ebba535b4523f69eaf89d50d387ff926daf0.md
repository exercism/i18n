# Instrucciones

El ejercicio introductorio clásico. Solo di "Hello, World!".

["Hello, World!"](http://en.wikipedia.org/wiki/%22Hello,_world!%22_program) es el programa tradicional para iniciarse en la programación en un lenguaje o entorno nuevos.

Los objetivos son simples:

- Escribe una función que devuelva el string "Hello, World!".
- Ejecuta la suite de tests y asegúrate de que pase.
- Envía tu solución y revísala en el sitio web.

Si todo sale bien, ya podrás obtener tu primer ejercicio real.
