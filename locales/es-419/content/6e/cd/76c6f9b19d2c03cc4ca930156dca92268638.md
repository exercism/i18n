# Introducción

A menudo queremos escribir código que pueda ramificar según una condición. Aunque hay muchas formas de hacerlo en Elixir, una de las más sencillas es usar `cond/1`.

En su forma más simple, `cond` sigue la primera de una o más ramas que se evalúe como `true`:

```elixir
cond do
  x > 10 -> :this_might_be_the_way
  y < 7 -> :or_that_might_be_the_way
  true -> :this_is_the_default_way
end
```

Si ninguna rama se evalúa como `true`, el entorno de ejecución lanza un error.
