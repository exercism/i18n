# Introducción

Un `String` en Julia es una secuencia ordenada de caracteres. Como señala el manual: «Por supuesto, el verdadero problema aparece cuando uno se pregunta qué es un carácter».

Gran parte de esta complejidad se cubrirá con más detalle en el concepto `Chars`, pero en resumen:

- Todos los strings en Julia son Unicode.
- Los strings que además son ASCII (letras inglesas de la A a la Z en mayúsculas y minúsculas, dígitos y algunos caracteres de puntuación) son _fáciles_ de manejar.
- La mayoría de los demás sistemas de escritura del mundo _se pueden_ manejar, pero requieren más cuidado.

## Literales de string

En general, los strings se encierran entre comillas dobles `" "`.
Las comillas simples `' '` solo se usan para `Chars`.

También es posible usar comillas dobles triples `""" """`, lo que permite usar `"` dentro del string sin escaparlo.
Más importante aún, se elimina la indentación adicional no deseada de los strings multilínea.

```julia-repl
julia> """
       Multiline
       String
       """
"Multiline\nString\n"
```

### Escapar caracteres

Como la mayoría de los lenguajes desde C en adelante, Julia usa una barra invertida `\` para escapar:

1. Para introducir caracteres no imprimibles, como el salto de línea `\n` del ejemplo anterior.
2. Para proteger caracteres que de otro modo tendrían un significado especial, como `\$` (ver más abajo).

## Indexación

En principio, los strings se pueden indexar exactamente igual que los vectores:

```julia-repl
julia> s[1], s[5]
('J', 'a')
```

Esto claramente funciona para un string ASCII como «Julia», pero ignora la mayoría de los idiomas del mundo.

Considera uno de los caracteres de Beowulf, escrito en inglés antiguo hace unos 15 siglos.

«Hrōðgār» claramente tiene 7 caracteres, pero no todos son ASCII.

```julia-repl
julia> king = "Hrōðgār"
"Hrōðgār"

julia> length(king)
7

julia> isascii(king)
false

# collect() converts to a Char vector:
julia> collect(king)
7-element Vector{Char}:
 'H': ASCII/Unicode U+0048 (category Lu: Letter, uppercase)
 'r': ASCII/Unicode U+0072 (category Ll: Letter, lowercase)
 'ō': Unicode U+014D (category Ll: Letter, lowercase)
 'ð': Unicode U+00F0 (category Ll: Letter, lowercase)
 'g': ASCII/Unicode U+0067 (category Ll: Letter, lowercase)
 'ā': Unicode U+0101 (category Ll: Letter, lowercase)
 'r': ASCII/Unicode U+0072 (category Ll: Letter, lowercase)
```

Indexar un string como este empieza bien, pero en algún punto se rompe:

```julia-repl
julia> king[3]
'ō': Unicode U+014D (category Ll: Letter, lowercase)

julia> king[4]
ERROR: StringIndexError: invalid index [4], valid nearby indices [3]=>'ō', [5]=>'ð'
```

El problema es que indexar de esta forma cuenta _bytes_, que para strings no ASCII no tienen una relación 1:1 con los caracteres.
Un carácter Unicode/UTF-8 puede necesitar hasta 4 bytes para representarse, y el concepto `Chars` explorará esto con más detalle.

## Construcción de strings

### Concatenación

Muchos lenguajes usan `+` como operador de concatenación de strings, pero Julia no.
Al menos, el mensaje de error es útil.

```julia-repl
julia> "s1 " + "s2"
ERROR: MethodError: no method matching +(::String, ::String)
The function `+` exists, but no method is defined for this combination of argument types.
String concatenation is performed with * 

julia> "s1 " * "s2"
"s1 s2"
```

La función `string()` concatenará una cantidad arbitraria de strings.

```julia-repl
julia> string("lots ", "of ", "bits")
"lots of bits"
```

La función `join()` hará lo mismo, y también tomará un vector de strings y los concatenará con un separador dado (por defecto `""`).

```julia-repl
julia> join(["lots", "of", "bits"], "_")
"lots_of_bits"
```

Ten en cuenta que los strings son inmutables y que la concatenación implica copiar.
Por eso, las concatenaciones repetidas dentro de un bucle son ineficientes, y es mejor reunir los fragmentos en un vector y unirlos todos al final.

### Repetición

Simple:

```julia-repl
julia> repeat("Abc", 5)
"AbcAbcAbcAbcAbc"
```

### Interpolación

Muchos lenguajes tienen una forma de insertar valores calculados en strings, aunque hay un desacuerdo extraordinario sobre la mejor sintaxis que se debe usar.

En Julia, los valores interpolados van precedidos por `$`.

```julia-repl
julia> myvar = 42
42

julia> "myvar evaluates to $myvar"
"myvar evaluates to 42"

julia> r = 5.3
5.3

julia> "A circle of radius $r has area $(π * r^2)"
"A circle of radius 5.3 has area 88.24733763933729"
```

Los paréntesis son obligatorios cuando omitirlos sería ambiguo, pero son opcionales para un único identificador seguido de un espacio en blanco.

Para incluir un $ en el string, escápalo como `\$`.

Ten en cuenta la limitación de que la interpolación actualmente no permite dar formato, como la cantidad de decimales que se deben mostrar.

### `@sprintf()`

Para un control más fino sobre el ensamblado de strings, Julia copia la función `sprintf` de C (y de varios lenguajes posteriores: Wikipedia enumera alrededor de 30).

En Julia, esto se implementa como una `macro` dentro del módulo `Printf`, de ahí el prefijo `@`.

```julia-repl
julia> using Printf

julia> r = 5.3
5.3

julia> @sprintf("A circle of radius %.1f has area %.2f", r, π * r^2)
"A circle of radius 5.3 has area 88.25"
```

## Funciones de string

Por simplicidad, esta sección se concentrará en funciones que devuelven un nuevo string y dejan el argumento sin cambios.
Muchas tienen una equivalente, nombrada con el sufijo `!`, que modifica el argumento en el lugar.

### Longitud

¿Qué tan largo es un string?
A veces, depende de cómo cuentes.

El caso simple son los strings ASCII, donde cada carácter ocupa 1 byte.

```julia-repl
julia> string_asc = "Julia"
"Julia"

julia> length(string_asc)
5

julia> sizeof(string_asc)
5
```

La función `length()` devuelve la cantidad de _caracteres_, y la función `sizeof()` la cantidad de _bytes_.

Esta distinción se vuelve importante con otros conjuntos de caracteres:

```julia-repl
julia> king = "Hrōðgār"
"Hrōðgār"

julia> length(king)
7

julia> sizeof(king)
10
```

### Separación

Una operación común en programación es tomar un string largo y dividirlo en partes, según un string separador de uno o más caracteres.

En general, usamos la función `split()`.
El separador por defecto es (cualquier) espacio en blanco, pero se pueden especificar otros.

```julia-repl
julia> split("my little string")
3-element Vector{SubString{String}}:
 "my"
 "little"
 "string"

julia> split("My_snake_case_string", "_")
4-element Vector{SubString{String}}:
 "My"
 "snake"
 "case"
 "string"
```

Estos ejemplos dividen un string en _strings_ más pequeños.
Dividir un string en _caracteres_ es una operación diferente.

### Buscar y reemplazar

¿Un string contiene un substring especificado?
Curiosamente, hay dos funciones para probar esto: `occursin()` y `contains()` difieren solo en el orden de sus argumentos.

```julia-repl
julia> needle = "Julia"
"Julia"

julia> haystack = "Python, Julia and R"
"Python, Julia and R"

julia> occursin(needle, haystack)
true

julia> contains(haystack, needle)
true
```

Para ser más específico sobre la posición:

```julia-repl
julia> startswith(haystack, "Python")
true

julia> endswith(haystack, "Python")
false
```

Para obtener los índices de inicio:fin de un substring, tenemos varias funciones:

- `findfirst()`
- `findlast()`
- `findprev()`
- `findnext()`

```julia-repl
julia> findfirst(needle, haystack)
9:13
```

Para reemplazar substrings, enumera los cambios usando la sintaxis `x => y`.

```julia-repl
julia> replace("abc", "a"=>"b", "b"=>"c", "c"=>"a")
"bca"
```

Desde Julia 1.7, la función `replace` puede tomar una cantidad arbitraria de cambios, con la garantía de que ningún carácter se cambiará más de una vez durante el reemplazo.

La sintaxis `x => y` se llama `pair`, un tipo importante en Julia que se cubre con más detalle en el concepto `Dicts and Pairs`.

### Espacios en blanco

A menudo necesitamos eliminar los espacios en blanco al inicio y/o al final de un string.

Las funciones para esto son `lstrip()` (izquierda), `rstrip()` (derecha), `strip()` (ambos lados).

```julia-repl
julia> strip("\n\t  useful_bit\n\n")
"useful_bit"
```

### Cambiar mayúsculas y minúsculas

Estas funciones tienen nombres bastante autoexplicativos:

```julia-repl
julia> s = repeat("aBcD ", 5)
"aBcD aBcD aBcD aBcD aBcD "

julia> uppercase(s)
"ABCD ABCD ABCD ABCD ABCD "

julia> lowercase(s)
"abcd abcd abcd abcd abcd "

julia> titlecase(s)  # Initial letter of each word uppercase
"Abcd Abcd Abcd Abcd Abcd "
```
