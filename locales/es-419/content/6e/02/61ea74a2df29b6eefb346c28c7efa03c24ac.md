# Introducción

En Common Lisp una función puede tener algunos argumentos que son opcionales.
Estos se designan en la lista lambda con la palabra clave de lista lambda `&optional`.
Un parámetro se vinculará al valor `nil` si no se especifica.
Si hay varios parámetros opcionales, se vinculan en orden.
Se pueden especificar valores predeterminados para los parámetros opcionales.
Por último, se puede especificar un símbolo para cada parámetro opcional, el cual se vinculará a verdadero o falso según si quien llama a la función proporcionó ese parámetro (a esto se le llama «supplied-p parameter»).

```lisp
(defun optional-parameters (&optional x (y 'default) (z nil z-supplied-p))
  (list x y (if z-supplied-p (list :z-was-supplied z)
                             (list :z-was-not-supplied z))))

(optional-parameters)          ; => (NIL DEFAULT (:Z-WAS-NOT-SUPPLIED NIL))
(optional-parameters 5 nil 10) ; => (5 NIL (:Z-WAS-SUPPLIED 10))
```
