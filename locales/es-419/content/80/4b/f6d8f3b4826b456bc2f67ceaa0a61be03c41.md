# Pistas

## 1. Reemplaza los espacios que encuentres por guiones bajos

- [Este tutorial][chars-tutorial] es útil.
- Puedes obtener `char`s de un string usando el método [charAt][char-at].
- Deberías usar un [`StringBuilder`][string-builder] para construir el string de salida.
- Revisa la documentación de [Character][chars-docs] para encontrar un método que detecte espacios en blanco. Recuerda que es un método estático.
- Los literales de `char` se encierran entre comillas simples.

## 2. Convierte kebab-case a camel-case

- Revisa la documentación de [Character][chars-docs] para encontrar un método que convierta un carácter a mayúscula. Recuerda que es un método estático.

## 3. Convierte leetspeak a texto normal

- Revisa la documentación de [Character][chars-docs] para encontrar un método que detecte cuándo un carácter es un dígito. Recuerda que es un método estático.

## 4. Omite los caracteres que no sean letras

- Revisa la documentación de [Character][chars-docs] para encontrar un método que detecte cuándo un carácter es una letra. Recuerda que es un método estático.
