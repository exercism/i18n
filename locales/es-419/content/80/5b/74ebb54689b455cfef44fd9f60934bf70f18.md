# Caracteres

`CHAR` es un carácter, escrito entre comillas simples.

```sather
   c : CHAR := 'M';
```

## Caracteres especiales

Algunos caracteres no se pueden escribir directamente y se escriben con una barra invertida:

| Escrito | Es |
| --- | --- |
| `'\n'` | un salto de línea |
| `'\t'` | un tabulador |
| `'\''` | una comilla simple |
| `'\\'` | una barra invertida |

## Preguntas

```sather
'M'.is_alpha      -- true
'7'.is_digit      -- true
'M'.is_upper      -- true
' '.is_space      -- true
'M'.is_alphanum   -- true, a letter or a digit
```

## Mayúsculas y minúsculas

`.upper` y `.lower` convierten una letra a mayúscula o a minúscula y dejan todo lo demás intacto, así que es seguro aplicarlos a un carácter que no hayas comprobado.

## Números

```sather
'a'.int           -- 97
97.char           -- 'a'
```

`.int` y `.char` son opuestos exactos. Los datos útiles sobre la numeración son que `'a'` a `'z'` van consecutivos, `'A'` a `'Z'` van consecutivos, y `'0'` a `'9'` van consecutivos, así que:

```sather
   c.int - 'a'.int          -- how far c is along the alphabet
   ('a'.int + n).char       -- the letter n places along
   d.int - '0'.int          -- the value of a digit character
```

## Dar la vuelta

Una rueda de cifrado gira más allá de `z` y vuelve a `a`. `%` hace exactamente eso:

```sather
   ('a'.int + (c.int - 'a'.int + places) % 26).char
```

El `%` de Sather nunca da un resultado negativo cuando el lado derecho es positivo, así que esto funciona tanto para girar la rueda hacia atrás como hacia adelante.

## Caracteres y strings

Un `STR` es una fila de bytes, y un `CHAR` es un byte. Para texto en inglés un byte es una letra, así que `"Marlowe".size` es 7 y `"Marlowe"[0]` es `'M'`. Para texto con acentos u otro alfabeto, una letra puede ocupar varios bytes, y ninguna de esas dos cosas se cumple.
