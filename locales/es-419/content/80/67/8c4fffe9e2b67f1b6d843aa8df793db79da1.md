# Introducción

## Boolean en R

Los valores verdadero o falso se representan con el tipo `logical`.
Contiene solo dos valores: `TRUE` y `FALSE`.

```R
TRUE
#> [1] TRUE
FALSE
#> [1] FALSE
typeof(TRUE)
#> [1] "logical"
```

## Operadores Boolean

Hay cinco operadores Boolean en R, pero solo tres son relevantes en esta etapa del temario.
Los otros dos serán importantes cuando trabajes con vectores, que se cubren en varios conceptos posteriores.

`&&` es el «y» Boolean.
Se evalúa como `TRUE` si las expresiones a *ambos* lados de `&&` son `TRUE`.

```R
TRUE && TRUE
#> [1] TRUE
TRUE && FALSE
#> [1] FALSE
```

`||` es el «o» Boolean.
Se evalúa como `TRUE` si una expresión en *cualquiera* de los lados de `||` es `TRUE`.

```R
TRUE || TRUE
#> [1] TRUE
FALSE || TRUE
#> [1] TRUE
```

`!` es el «no» Boolean.
Intercambia los valores `TRUE` y `FALSE`.

```R
!TRUE
#> [1] FALSE
!FALSE
#> [1] TRUE
```

Para expresiones más largas y complicadas, es mejor usar paréntesis para dejar clara tu intención.

```R
(TRUE || FALSE) && (FALSE && TRUE)
#> [1] FALSE
```
