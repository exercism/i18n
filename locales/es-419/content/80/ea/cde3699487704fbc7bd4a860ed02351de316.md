# Introducción

Los `Rational numbers` son fracciones con un numerador entero dividido por un denominador entero.

Por ejemplo, podemos guardar `2//3` como una fracción exacta en lugar del valor aproximado de `Float64` `0.6666...`

La ventaja es que (salvo en el caso extremo del *desbordamiento de enteros*) un número racional se mantiene exacto, lo que evita los errores de redondeo que a menudo son inevitables con los números de punto flotante.

Los números racionales son un tipo numérico bastante simple y están pensados para funcionar tal como esperarías.
Como han sido un tipo estándar en Julia desde las primeras versiones, la mayoría de las funciones los aceptan como argumento igual que los enteros y los números de punto flotante.

## Crear números racionales

Crearlos es tan simple como usar `//` entre dos enteros.

```julia-repl
julia> 3//4
3//4

julia> a = 3; b = 4;

julia> a//b
3//4
```

Los factores comunes se eliminan automáticamente, lo que convierte la fracción a su «mínima expresión»: los enteros más pequeños que representan la fracción con exactitud y con un denominador no negativo.

```julia-repl
julia> 5//15
1//3

julia> 5//-15
-1//3
```

## Aritmética con números racionales

Los `arithmetic operators` habituales `+ - * / ^ %` funcionan con los racionales, esencialmente igual que con otros tipos numéricos.

Se pueden incluir enteros y otros `Rational`s en la expresión y el resultado será un `Rational`.
Si incluyes un `float` en la expresión, el resultado será un `float`, con la consiguiente (posible) pérdida de precisión.

Si quieres un `float`, solo usa la función `float()` para convertir un racional.
Es bastante normal usar números racionales para conservar la precisión a lo largo de un cálculo largo y luego convertir a número de punto flotante al final.

```julia-repl
julia> 3//4 + 1//3  # addition
13//12

julia> 3//4 * 1//3  # multiplication
1//4

julia> 3//4 / 1//3  # division
9//4

julia> 3//4 ^ 2  # exponentiation
3//16

julia> 3//4 + 5  # rational and int => rational
23//4

julia> 3//4 + 5.3  # rational and float => float
6.05

julia> float(3//4)  # casting
0.75
```

## Otras operaciones

En Julia, los números racionales son solo números.
Por lo general, el compilador convierte los tipos según sea necesario.

Sin embargo, ten en cuenta que las comparaciones funcionan para fracciones con una representación decimal finita:

```julia-repl
julia> 3//4 == 0.75
true

julia> 3//4 < 0.74
false
```

Pero, en caso contrario, conviene convertir un `Rational` a `Float` para hacer comparaciones:

```julia-repl
julia> 1//3 == 1/3
false

julia> float(1//3) == 1/3
true
```

Las funciones matemáticas aceptan racionales como argumento, pero pueden dar un resultado de punto flotante:

```julia-repl
julia> sqrt(9//16)
0.75
```
