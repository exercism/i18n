# Anexo de instrucciones

## Notas de implementación

La definición de la interfaz Cipher se encuentra en `cipher.go`.

Tus implementaciones deben ajustarse a la interfaz Cipher.

```go
type Cipher interface {
    Encode(string) string
    Decode(string) string
}
```

Se espera que `Encode` ignore todos los valores en el string que no sean A-Za-z; no se representarán en la salida.
La salida también se normalizará a minúsculas.

Las funciones que se usan para obtener los cifrados son:

```go
func NewCaesar() Cipher { }

func NewShift(distance int) Cipher { }

func NewVigenere(key string) Cipher { }
```

El argumento para `NewShift` debe estar en el rango de 1 a 25 o de -1 a -25.
No se permite el cero.
Para argumentos inválidos, `NewShift` devuelve nil.

El argumento para `NewVigenere` debe consistir únicamente en letras minúsculas de la a a la z.
No se permiten los valores que consistan enteramente en la letra 'a'.
Para argumentos inválidos, `NewVigenere` devuelve `nil`.
