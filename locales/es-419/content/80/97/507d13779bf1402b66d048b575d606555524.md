# Pistas

Para ayudarte a conceptualizar: el ejercicio usa números complejos para codificar intersecciones en una cuadrícula.
Como los números complejos se pueden pensar como un par de dos números, esto también se puede reimaginar como el plano bidimensional x-y, donde el eje x es el eje real y el eje y es el eje imaginario.

## 1. Número complejo simple

- Esta es una función envoltorio sencilla.
- Consulta la Introducción para ver cómo crear un número complejo usando variables.
- Ten en cuenta que, si no usas los argumentos de palabra clave, los argumentos posicionales de `complex()` podrían no ser lo que esperas.

## 2. Obtener las direcciones del conductor

- Esta función requiere una sola operación matemática.
- El orden de la operación importa (es decir, no es simétrica).

## 3. Obtener la distancia Manhattan

- Recuerda que esta es la cantidad total de intersecciones (sin contar la intersección de inicio) por las que pasa el taxi mientras sigue las líneas de la cuadrícula.
- Tu función `driver_directions` puede ser útil.
- Otras funciones que pueden ser útiles son [`Re()` y `Im()`][complex-ref].

## 4. Obtener la distancia «a vuelo de pájaro»

- Esta es la distancia en línea recta entre las dos intersecciones.
- Puedes pensar en esto como la hipotenusa del recorrido que traza una distancia Manhattan con un solo giro.
- También se conoce como [distancia euclidiana][euclid-ref] o norma L2.
- Tu función `driver_directions` puede ser útil.
- Consulta la Introducción para ver otra función de números complejos que puedes usar opcionalmente para hallar la magnitud.

## 5. Obtener las direcciones del cuervo

- Tu función `driver_directions` puede ser útil.
- Esta función invierte las direcciones norte/sur de las direcciones del conductor.
- Esto invierte la ubicación percibida sobre el «eje x».
- Consulta la Introducción para ver otra función que puedes usar opcionalmente.
