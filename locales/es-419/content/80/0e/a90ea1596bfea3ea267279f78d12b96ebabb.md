# Pruebas

Para ejecutar las pruebas, primero instala el paquete `z3-solver`:

```
pip install z3-solver
```

Luego puedes ejecutar las pruebas con el siguiente comando desde el directorio del ejercicio:

```
python <snake_case_exercise>_test.py
```

donde `<snake_case_exercise>` se reemplaza por el nombre del ejercicio.
