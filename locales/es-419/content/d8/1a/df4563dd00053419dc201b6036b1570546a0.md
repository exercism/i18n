# Introducción

Common Lisp ofrece varias expresiones condicionales distintas; la principal diferencia entre ellas es la cantidad de ramas que admiten.

- `when` y `unless` permiten una sola rama:

```lisp
(when (= 2 2) "All is well")      ; => "All is well"
(unless (= 2 2) "Time to panic!") ; => NIL
```

La parte que va después de la expresión de prueba puede tener más de una expresión.

- `if` ofrece la clásica estructura if-then-else:

```lisp
(if (= 2 2) 'how-honest 'you-liar) ; => HOW-HONEST
```

Ten en cuenta que tanto la cláusula then como la cláusula else solo pueden contener una única expresión.

- `cond` permite tener varias ramas sin anidar expresiones `if`:

```lisp
(cond ((= 0 2) 'nope)
      ((= 1 2) 'try-again)
      ((= 2 2) 'quite-true)
      ((= 3 2) 'too-far)
      (t 'something-else))
; => QUITE-TRUE
```

Ten en cuenta que no hay límite en la cantidad de expresiones que van después de la expresión de prueba.

- `case` ofrece una clásica construcción estilo «switch»: compara un único valor con varias ramas:

```lisp
(case 'elder-beast
  (cat "Meow")
  (bird "Chirp")
  (dog "Bark")
  (otherwise "???"))
; => "???"
```

Ten en cuenta que, al igual que con `cond`, no hay límite en la cantidad de expresiones que van después de la expresión de prueba.
