# Pistas

## General

- Las direcciones de memoria en x86-64 son números de 64 bits (8 bytes).
- Debes usar `rel` para formar direcciones relativas válidas en memoria.

## 1. Obtén el valor RGB de un color

- Las direcciones de memoria en x86-64 son números de 64 bits (8 bytes).
- Debes usar `rel` para formar direcciones relativas válidas en memoria.
- Para acceder al contenido almacenado en una dirección de memoria, necesitas desreferenciarla usando `[]`.
- Los enteros de 32 bits (4 bytes) se devuelven en `eax`.

## 2. Suma el color base

- Las direcciones de memoria en x86-64 son números de 64 bits (8 bytes).
- Debes usar `rel` para formar direcciones relativas válidas en memoria.
- Las variables inicializadas se definen en _section .data_.
- Una variable debe declararse `global` para que sea visible en otros archivos fuente.
- Puedes reutilizar la función `get_color_value` que ya está implementada.

## 3. Define constantes para los colores primarios

- Las direcciones de memoria en x86-64 son números de 64 bits (8 bytes).
- Debes usar `rel` para formar direcciones relativas válidas en memoria.
- Las constantes inicializadas se definen en _section .rodata_.
- Una constante debe declararse `global` para que sea visible en otros archivos fuente.

## 4. Combina los colores

- Las direcciones de memoria en x86-64 son números de 64 bits (8 bytes).
- Debes usar `rel` para formar direcciones relativas válidas en memoria.
- Para acceder al contenido almacenado en una dirección de memoria, necesitas desreferenciarla usando `[]`.
- Una función o dato externo debe declararse `extern` en la sección correspondiente.
- Una función externa puede modificar cualquiera de los registros habituales que estés usando, así que necesitas guardar las variables en memoria antes de llamarla.
- `combining_function` recibe el valor de 32 bits (no la dirección) del color base en `rdi` y el valor de 32 bits (no la dirección) del color secundario en `rsi`.
