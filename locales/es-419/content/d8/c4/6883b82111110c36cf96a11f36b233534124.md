# Apéndice de instrucciones

## Formato de salida

Devuelve las plantas del estudiante como un string, usando una coma y un espacio como separadores.

## Memoria reservada

El buffer para el string del diagrama usa los bytes 1024-2047 de la memoria lineal.
El buffer para el string del estudiante usa los bytes 2048-3071 de la memoria lineal.

Los strings de entrada se pueden modificar en el mismo lugar si lo deseas.
