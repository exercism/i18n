# Instrucciones

Estás de excursión en Nueva Zelanda y tomas rumbos con una brújula. Un rumbo es un número entero de grados, y es un valor: girar 20 grados no cambia el rumbo que tomaste, sino que te da uno distinto.

Escribe una `immutable class BEARING`. El stub te da el encabezado de la clase y su atributo.

## 1. Toma un rumbo

`create` toma una cantidad de grados y devuelve un rumbo. Los grados van de 0 a 359, así que todo lo que quede fuera de ese rango da la vuelta: 370 es 10, y -10 es 350.

```sather
#BEARING(370).degrees
-- => 10
#BEARING(-10).degrees
-- => 350
```

## 2. Gira

`turned` toma una cantidad de grados para girar y responde con el nuevo rumbo. Girar con un número negativo gira hacia el otro lado. El rumbo sobre el que se llamó queda sin cambios.

```sather
#BEARING(350).turned(20).degrees
-- => 10
```

## 3. Compara

`is_eq` toma otro rumbo y responde si son el mismo. Una vez que existe, `=` funciona con los rumbos.

```sather
#BEARING(10) = #BEARING(370)
-- => true
```

## 4. Nombra el punto cardinal

`point` responde con el punto cardinal más cercano al rumbo, como uno de `"N"`, `"NE"`, `"E"`, `"SE"`, `"S"`, `"SW"`, `"W"`, `"NW"`.

Cada punto abarca 45 grados, centrado en su rumbo exacto: el norte va de 337.5 pasando por 0 hasta 22.5, el noreste de 22.5 a 67.5, y así sucesivamente. Como los rumbos aquí son números enteros, un rumbo de 22 es `"N"` y 23 es `"NE"`.

```sather
#BEARING(0).point
-- => "N"
#BEARING(90).point
-- => "E"
#BEARING(225).point
-- => "SW"
```

## 5. Anótalo

`str` responde con los grados y el punto, como `"90 degrees (E)"`.

```sather
#BEARING(90).str
-- => "90 degrees (E)"
```
