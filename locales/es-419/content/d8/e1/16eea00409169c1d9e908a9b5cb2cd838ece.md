# Instrucciones

Te pidieron que hagas un poco más de trabajo en el sistema de autenticación de red.

Además de que la identidad del administrador esté codificada de forma fija en el sistema durante el desarrollo, los que están al mando también quieren que a los desarrolladores senior se les dé el mismo trato.

## 1. Almacena los datos del administrador del sistema codificados de forma fija en el sistema y ponlos a disposición de quienes los llamen.

Los datos del administrador son los siguientes:

| Correo electrónico | Color de ojos | Ancho del filtrum | Nombre   | Dirección 1 | Dirección 2 |
| ------------------ | ------------- | ----------------- | -------- | ----------- | ----------- |
| admin@ex.ism       | green         | 0.9               | Chanakya | Mumbai      | India       |

Implementa la propiedad `Authenticator.Admin` para que devuelva los datos de identidad del administrador del sistema. El nombre y cada parte de la dirección deben estar en un elemento separado del array `NameAndAddress`.

```csharp
var authenticator = new Authenticator();
authenticator.Admin;
// => {"admin@ex.ism", {"green", 0.9m}, ["Chanakya", "Mumbai", "India"]}
```

## 2. Almacena los datos de los desarrolladores codificados de forma fija en el sistema y ponlos a disposición en forma de diccionario

Los datos de los desarrolladores son los siguientes:

| Correo electrónico | Color de ojos | Ancho del filtrum | Nombre   | Dirección 1 | Dirección 2 |
| ------------------ | ------------- | ----------------- | -------- | ----------- | ----------- |
| bert@ex.ism        | blue          | 0.8               | Bertrand | Paris       | France      |
| anders@ex.ism      | brown         | 0.85              | Anders   | Redmond     | USA         |

Implementa la propiedad `Authenticator.Developers` para que devuelva los datos de identidad de los desarrolladores. La clave del diccionario es el nombre del desarrollador.

```csharp
var authenticator = new Authenticator();
authenticator.Developers;
// => ["Bertrand"] = {"bert@ex.ism", {"blue", 0.8m}, ["Bertrand", "Paris", "France"]},
// ["Anders"] = {"anders@ex.ism", {"brown", 0.85m}, ["Anders", "Redmond", "USA"]},

```
