# Apéndice de instrucciones

## Manejo de casos límite

En Exercism, cada lenguaje tiene sus propias expectativas sobre cuál debería ser el resultado si la longitud de las subcadenas es cero.
En el track de Rust no tenemos una prueba para ese caso, así que eres libre de hacer lo que te parezca más apropiado.

Considera las ventajas y desventajas de las siguientes posibilidades:
- Hacer que el programa se caiga con `panic!`.
- Devolver un `Result::Err`. (Aquí no es posible, porque la firma de la función ya está dada)
- Devolver un vector vacío.
- Devolver un vector que contenga tantos strings vacíos como la longitud del string «digits» **más uno**. (¡esto tiene unas propiedades matemáticas muy interesantes!)
