# Introducción a los fundamentos

[Go](https://golang.org) es un lenguaje de programación compilado y con tipado estático.
Su sintaxis es similar a la de C.
A menudo se le llama Golang por su antiguo nombre de dominio, golang.org, pero su nombre correcto es Go.

El concepto Fundamentos presenta tres características importantes del lenguaje: paquetes, funciones y variables.

## Paquetes

Las aplicaciones de Go se organizan en paquetes.
Un paquete es un conjunto de archivos fuente que están en el mismo directorio.
Todos los archivos fuente de un directorio deben compartir el mismo nombre de paquete.
Por convención, el nombre del paquete es el último directorio de la ruta de importación.
Por ejemplo, los archivos del [paquete «math/rand»](https://golang.org/src/math/rand/) comienzan con la sentencia `package rand`.
Cuando importas un paquete, solo puedes usar o acceder a las entidades (funciones, tipos, variables, constantes) cuyos nombres empiecen con letra mayúscula.
El estilo de nombres recomendado en Go es usar `camelCase` para los identificadores, salvo los que deben ser accesibles desde otros paquetes, que deben usar `PascalCase`.

```go
package lasagna
```

## Variables

Go tiene tipado estático, lo que significa que todas las variables [deben tener un tipo definido](https://en.wikipedia.org/wiki/Type_system) en tiempo de compilación.

Puedes definir variables si especificas un tipo de forma explícita:

```go
var explicit int // Explicitly typed
```

También puedes usar un inicializador, y el compilador le asignará a la variable el tipo que corresponda al del inicializador.

```go
implicit := 10   // Implicitly typed as an int
```

Una vez declarada, puedes asignarle valores a una variable con el operador `=`.
Una vez declarada, el tipo de una variable nunca cambia.

```go
count := 1 // Assign initial value
count = 2  // Update to new value

count = false // This throws a compiler error due to assigning a non `int` type
```

## Constantes

Las constantes contienen un dato igual que las variables, pero su valor no puede cambiar durante la ejecución del programa.

Las constantes se definen con la palabra clave `const` y pueden ser números, caracteres, strings o valores Boolean:

```go
const Age = 21 // Defines a numeric constant 'Age' with the value of 21
```

## Funciones

Las funciones de Go aceptan cero o más parámetros.
Los parámetros deben llevar un tipo explícito; no hay inferencia de tipos.

Los valores se devuelven desde las funciones con la palabra clave `return`.

Para llamar a una función, escribes su nombre y pasas un argumento por cada uno de sus parámetros.

Ten en cuenta que Go admite dos tipos de comentarios.
Los comentarios de una sola línea van precedidos por `//` y los comentarios de varias líneas se escriben entre `/*` y `*/`.

```go
package greeting

// Hello is a public function.
func Hello (name string) string {
    return hi(name)
}

// hi is a private function.
func hi (name string) string {
    return "hi " + name
}
```
