# Anexo de instrucciones

## Algunas notas sobre los strings de Arturo

Verás en los tests una sintaxis que puede resultarte nueva: strings de varias líneas encerrados entre `{ braces }`.

### Referencias

* El tipo [`:string`][string] en la referencia del lenguaje.
* La documentación de [Uso básico][usage] en el módulo Strings.

[string]: https://arturo-lang.io/documentation/language/#string
[usage]: https://arturo-lang.io/documentation/library/strings/#basic-usage

### Literales de string en Arturo

Arturo tiene varias formas de escribir literales de string:

1. Strings de una sola línea encerrados entre comillas dobles

    ```arturo
    greeting: "Hello, World!"

    print express greeting     ; => "Hello, World!"
    ```

1. Strings de fin de línea que usan una «comilla inteligente» `«`

    ```arturo
    farewell: « Goodbye, Mars!

    print express farewell     ; => "Goodbye, Mars!"
    ```

   Pueden leerse muy bien si tienes una lista de strings cortos:

    ```arturo
    numberWords: [
        « one
        « two
        « three
        « four, and so on
    ]
 
    print express numberWords    ; => ["one" "two" "three" "four, and so on"]
    ```

1. Strings de varias líneas encerrados entre llaves.
   Se elimina la indentación «común».
   Se eliminan los saltos de línea al inicio y al final.

    ```arturo
    multiline: {
        First line
        Second line
            Third line keeps indentation
        Last line!


    }

    print express first multiline   ; => 'F'
    print express last multiline    ; => '!'
    lines: split.lines multiline
    print size lines                ; => 4
    print express lines\2           ; => "    Third line keeps indentation"
    ```

1. Los strings textuales se conservan exactamente, incluidos los espacios en blanco al inicio y al final

    ```arturo
    code: {:
        greet: function [name][
            print ~"Hello, |name|~"

        greet "World""
    :}

    print ">" ++ code ++ "<"
    print express first code
        ; => prints a literal newline character between single quotes
    print express (split.lines code | get 1)
        ; => "    greet: function [name]["
    ```

1. Los strings al estilo heredoc se colocan debajo de una línea de 3 o más guiones, hasta el final del archivo.
   Esto funciona igual que la palabra clave `__DATA__` de Perl.
   Este estilo puede ser útil en un módulo, donde podrías guardar la documentación o el texto de la licencia en una variable al final del archivo.

    Si esto está en un archivo llamado «mymodule.art»

    ```arturo
    myLicense:
    ---------
    This text has been placed in the public domain.
    Do with it what you will.
    ```

    Entonces

    ```arturo
    import {mymodule}!
    print ~">|myLicense|<"  ; => >This text has been placed in the public domain.
                            ; => Do with it what you will.<
    ```
