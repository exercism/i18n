# Instrucciones

En este ejercicio vas a generar mensajes de registro semiestructurados.

## 1. Emite mensajes semiestructurados

Empezarás con algunas funciones sin implementar y la siguiente enumeración:

```rust
#[derive(Clone, PartialEq, Debug)]
pub enum LogLevel {
    Info,
    Warning,
    Error,
}
```

Tu objetivo es emitir un mensaje de registro con este formato: `"[<LEVEL>]: <MESSAGE>"`.
Tendrás que implementar las funciones que corresponden a cada nivel de registro.

Por ejemplo, el siguiente fragmento muestra una salida esperada para la función `log`.

```rust
log(LogLevel::Error, "Stack overflow")
// Returns: "[ERROR]: Stack overflow"
```

Y para `info`:

```rust
info("Timezone changed")
// Returns: "[INFO]: Timezone changed"
```

¡Diviértete!

## 2. Práctica adicional opcional

En este conjunto de pruebas hay una prueba condicionada por una feature.
Las feature gates desactivan por completo la compilación de ciertas secciones de tu programa.
Las veremos más adelante.
Por ahora, solo ten en cuenta que hay una prueba que solo se compila y se ejecuta cuando usas una invocación de prueba especial:

```sh
cargo test --features add-a-variant
```

Esta prueba pretende mostrarte cómo agregar una variante a tu enumeración.
