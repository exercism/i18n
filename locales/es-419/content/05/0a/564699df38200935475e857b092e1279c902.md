# Pistas

## 1. General

- Lee sobre los archivos en la [guía oficial de primeros pasos][getting-started-file].
- Lee sobre los archivos en [joyofelixir.com][joy-of-elixir-file].
- Echa un vistazo a la [documentación del módulo `File`][file].

## 1. Lee direcciones de correo electrónico de un archivo

- Hay una [función integrada][file-read] para leer el contenido de un archivo de una sola vez.

## 2. Abre un archivo de registro para escribir en él

- Hay una [función integrada][file-open] para abrir un archivo.
- El segundo argumento de esa función es una lista de modos que permite especificar que el archivo se abra para escribir en él.

## 3. Registra un correo enviado

- Las funciones para leer y escribir en un archivo abierto con [`File.open!/1`][file-open] se encuentran en el módulo [`IO`][io].
- Hay una [función integrada][io-puts] para escribir un string en un archivo, seguido de un salto de línea.

## 4. Cierra el archivo de registro

- Hay una [función integrada][file-close] para cerrar un archivo.

## 5. Envía el boletín

- Todas las operaciones necesarias sobre archivos ya se implementaron en los pasos anteriores.
- Antes de escribir en un archivo, hay que abrir el archivo.
- Después de que terminen todas las operaciones de escritura en un archivo, hay que cerrar el archivo.
