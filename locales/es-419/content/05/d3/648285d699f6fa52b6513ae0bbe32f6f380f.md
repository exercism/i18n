## GNU awk y aritmética de precisión arbitraria

Por defecto, los números en `awk` se representan como números de punto flotante de doble precisión. Esto brinda 53 bits de precisión (ver la [tabla 16.3][table-16.3] del manual). Lamentablemente, no alcanza para completar este ejercicio (alerta de spoiler: una prueba requiere 63 bits de precisión).

«Precisión insuficiente» se ve así:
```sh
$ gawk 'BEGIN {
  n = 2 ^ 54
  if (n == n + 1)
    print "not enough precision"
  else
    print "OK"
}'
```
```none
not enough precision
```

GNU `awk` puede usar números de precisión arbitraria si las bibliotecas correspondientes se compilaron en el ejecutable de `awk`. Verifica tu versión de awk y busca «GNU MPFR»:
```sh
$ gawk --version
GNU Awk 5.0.1, API: 2.0 (GNU MPFR 4.0.2, GNU MP 6.2.0)
...
```

Si está presente, habilita esa capacidad con la opción `-M`:
```sh
$ gawk -M 'BEGIN {
  n = 2 ^ 54
  if (n == n + 1)
    print "not enough precision"
  else
    print "OK"
}'
```
```none
OK
```

¿Y si mi `awk` no tiene `-M`? Vas a tener que llamar a un programa externo que pueda hacer aritmética de precisión arbitraria, como `bc`. Consulta la sección [Usar getline hacia una variable desde una tubería][getline-pipe] para ver un ejemplo de cómo hacerlo.


Para leer más: [Aritmética de precisión arbitraria][arbitrary]
