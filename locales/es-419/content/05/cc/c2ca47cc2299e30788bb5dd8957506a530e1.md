# Pruebas

## Probar de forma interactiva

Inicia el REPL desde el directorio en el que descargaste el ejercicio.

Puedes ejecutar las pruebas cargando el archivo de pruebas en el REPL con `(load "exercise-test")` (reemplazando «exercise» por el nombre correspondiente). Luego evalúa `(exercise-test:run-tests)` para ejecutar todas las pruebas.

Si escribes tu código directamente en el REPL, simplemente evalúa `(exercise-test:run-tests)`.

Si escribes tu código en el archivo lisp del ejercicio, cárgalo con `(load "exercise")` y luego evalúa `(exercise-test:run-tests)`.

## Probar desde la línea de comandos

Puedes iniciar las pruebas con esta invocación de línea de comandos (de nuevo, reemplaza «exercise» por el nombre correspondiente en los dos lugares)

```sh
ros run --load exercise-test.lisp --eval '(uiop:quit (if (exercise-test:run-tests) 0 1))'
```
