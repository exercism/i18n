# Pistas

## 1. Crea un nuevo tablero de puntajes máximos

- Crea un objeto nuevo usando llaves.
- Escribe la clave como un string para que pueda contener espacios.
- Separa la clave y el valor con dos puntos.

## 2. Agrega jugadores a un tablero de puntajes

- Usa la notación de corchetes para agregar una clave cuyo nombre está guardado en una variable (el argumento).
- Usa el operador de asignación (`=`) para establecer un valor para la nueva clave.
- Como alternativa, usa el [operador `+`][man-plus] para combinar el objeto entrante con uno nuevo.
- Recuerda que se necesitan paréntesis alrededor de las expresiones para las claves de un objeto.

## 3. Elimina jugadores de un tablero de puntajes

- Usa la [expresión del][man-del].
- Haz referencia a la clave como lo hiciste en la tarea anterior (notación de corchetes).
- Recuerda que el argumento de `del` es una _expresión de índice_, no solo un string.

## 4. Aumenta el puntaje de un jugador

- Primero piensa cómo expresar el nuevo valor que quieres asignar.
- Luego usa el operador de asignación como en la tarea 2 para establecer ese nuevo valor.
- Si aún no lo has hecho, puedes usar el [operador aritmético de actualización y asignación][man-update-assignment] `+=`.

## 5. Aplica los puntos extra del lunes

- Este es un buen lugar para usar `to_entries`/`from_entries`, o `with_entries` para iterar sobre el objeto
- Para cada clave, establece el nuevo valor como lo hiciste en la tarea 4.

## 6. Encuentra el puntaje total

- Queremos iterar sobre los _valores_ del objeto.
  Podemos usar [`map_values`][man-map_values], o [`.[]`][man-brackets] para generar un flujo de valores.
- La expresión `add` se puede usar para encontrar la suma de un array de números.
