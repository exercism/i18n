# Condicionales

Crystal tiene lo que se conoce como expresiones de control; estas se usan para controlar la forma en que se ejecutará el programa y toman un valor verdadero o falso.
Hay operadores que se pueden usar para crear valores verdaderos o falsos; estos se conocen como [operadores de igualdad y comparación][equality-and-comparison].

Hay dos expresiones de control principales que se usan para controlar qué código se ejecutará y qué código no.
También conocidas como qué rama dada se ejecutará.

Esas dos son: la expresión `if` y la expresión `unless`.

## Operadores de comparación

Los operadores de comparación se usan para comparar valores y devolver un valor `true` o `false`.
Estos operadores requieren que se comparen dos valores del mismo tipo.
Si los valores no son del mismo tipo, el compilador lanzará un error.
Aquí tienes una lista de los operadores de comparación y un ejemplo de cuándo dan un valor `true`:

| Método | Descripción           | Ejemplo |
| ------ | --------------------- | ------- |
| <      | less than             | 4 < 5   |
| <=     | less than or equal    | 4 <= 4  |
| >      | greater than          | 3 > 1   |
| >=     | greater than or equal | 2 >= 2  |

## Operadores de igualdad

Los operadores de igualdad son similares a los operadores de comparación, pero se usan para comprobar si dos valores son iguales o no.

El operador `==` comprueba si dos valores son iguales, incluido el tipo del valor.
Si los valores son iguales, devolverá `true`; de lo contrario, devolverá `false`.
El operador `==` puede comparar cualquier tipo de valor con cualquier otro tipo de valor.
El `!=` funciona de la misma manera, pero devolverá `true` si los valores no son iguales y `false` si son iguales.

## Operador nave espacial

El operador nave espacial es un operador de comparación único, y su nombre se deriva de cómo se ve.
Es único en el sentido de que no devuelve un valor verdadero o falso, sino que devuelve un número.
Se escribe como `<=>` y se usa para comparar dos valores.
Devolverá `1` si el valor de la izquierda es mayor que el de la derecha, `-1` si el valor de la izquierda es menor que el de la derecha, y `0` si los valores son iguales.

```crystal
1 <=> 2 # => -1
2 <=> 2 # => 0
3 <=> 2 # => 1
```

## La sentencia `if`

La sentencia [`if`][if] se usa para comprobar si una condición dada es verdadera o falsa.
Si la condición es verdadera, se ejecutará el código dentro de la sentencia `if`.
Una sentencia `if` termina con la palabra clave `end`.

```crystal
if 1 == 1
  puts "1 is equal to 1"
end
# => 1 is equal to 1

if 1 > 2
  puts "1 is greater than 2"
end
# => no output
```

## La sentencia `unless`

La sentencia [`unless`][unless] funciona de manera muy similar a la sentencia `if`, pero ejecutará el código dentro de la sentencia `unless` si la condición es falsa.

```crystal
unless 1 == 1
  puts "1 is not equal to 1"
end
# => no output

unless 1 > 2
  puts "1 is not greater than 2"
end
# => 1 is not greater than 2
```

## La sentencia `else`

La sentencia `else` se puede usar junto con las sentencias `if` y `unless`.
La sentencia `else` se ejecutará si la rama `if` o la rama `unless` no se ejecuta.

~~~~exercism/warning
Aunque se puede usar una rama `else` junto con `unless,` no se recomienda hacerlo porque perjudica la legibilidad.
En su lugar, se recomienda usar `if !condition` con una rama `else`.
~~~~

```crystal
if 1 == 1
  puts "1 is equal to 1"
else
  puts "1 is not equal to 1"
end
# => 1 is equal to 1

unless 1 < 2
  puts "1 is not greater than 2"
else
  puts "1 is greater than 2"
end
# => 1 is greater than 2
```

## Sentencias `if` en cascada

La sentencia `elsif` se puede usar junto con la sentencia `if`.
La sentencia `elsif` se ejecutará si la rama `if` no se ejecuta y la condición de la sentencia `elsif` es verdadera.
Las sentencias `elsif` se pueden encadenar y se ejecutará la primera condición verdadera.
También puede haber una sentencia `else` al final de la sentencia `if`, que se ejecutará si ninguna de las sentencias anteriores resultó verdadera.

```crystal
if 1 != 1
  puts "1 is not equal to 1"
elsif 1 > 2
  puts "1 is greater than 2"
else
  puts "1 is not equal to 1 and 1 is not greater than 2"
end
# => 1 is not equal to 1 and 1 is not greater than 2
```

## Operador ternario

Crystal tiene un operador ternario, una sentencia `if`-`else` de una sola línea: `condition ? expression_if_truthy : expression_if_falsey`

```crystal
1 == 1 ? puts("1 is equal to 1") : puts("1 is not equal to 1")
# => 1 is equal to 1
```

## `if` y `unless` como sufijo

La sentencia `if` y la sentencia `unless` también se pueden usar como [sufijo][if-as-suffix]; esto es útil cuando quieres ejecutar una sola línea de código si una condición es verdadera.
Se hace poniendo la sentencia `if` o `unless` después del código que quieres ejecutar.

```crystal
puts "1 is equal to 1" if 1 == 1
# => 1 is equal to 1

puts "1 is not equal to 1" unless 1 == 1
# => no output
```

## Tipos con condicionales

Cuando se asigna a tipos diferentes, la variable llevará ambos tipos.
Esto se debe a que el compilador no sabe qué rama se ejecutará.
Esta asignación múltiple, también conocida como unión, se explicará en conceptos posteriores.
Esto se puede ver en el siguiente ejemplo:

```crystal
if 1 == 1
  a = 1
else
  a = "1"
end

typeof(a) # => Int32 | String
```
