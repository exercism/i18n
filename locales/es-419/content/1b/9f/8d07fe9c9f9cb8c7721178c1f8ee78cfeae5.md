# Apéndice de las instrucciones

## Acerca de Enum

La sentencia enum te permite crear un conjunto de etiquetas fuertemente tipado.
Puedes usar esa enumeración en el código sin tener que analizarla ni revisar errores de ortografía.

Las enumeraciones se representan internamente como números enteros con un valor inicial de cero.
De forma predeterminada, PowerShell asigna el valor cero a la primera etiqueta de la lista y asigna a las etiquetas restantes números enteros consecutivos.

Ejemplo:
```pwsh
Enum Fruits {
    APPLE       #default internal value 0
    ORANGE      #default internal value 1
    MANGO       #default internal value 2
}

$myFavFruit = [Fruits]::APPLE
Write-host $myFavFruit => APPLE
``````

Para saber más sobre Enum en PowerShell, consulta el [módulo Enum.](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.core/about/about_enum)
