# Pistas

## 1. Crea un nuevo array

- Un array vacío se puede crear con la sintaxis `[]`.

## 2. Define un array existente

- Los arrays con varios elementos se pueden crear con la sintaxis `["a", "b", "c"]`.

## 3. Agrega un nuevo lenguaje a un array

- La sintaxis de propagación (`[x, ..list]`) se puede usar para agregar un elemento al principio de un array.

## 4. Cuenta los lenguajes del array

- Hay una función en el módulo `gleam/list` para [contar los elementos de un array][length].

## 5. Invierte el array

- Hay una función en el módulo `gleam/list` para [invertir un array][reverse].

## 6. Comprueba si el array es emocionante

- Puedes usar la coincidencia de patrones, con los patrones de array y de propagación de array, para hacer coincidir estructuras de array específicas.

[reverse]: https://hexdocs.pm/gleam_stdlib/gleam/list.html#reverse
[length]: https://hexdocs.pm/gleam_stdlib/gleam/list.html#length
