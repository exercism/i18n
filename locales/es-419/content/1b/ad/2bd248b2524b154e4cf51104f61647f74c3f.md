# Marcador de posición

## Funciones de tiempo

Este ejercicio requiere usar las [funciones de tiempo][time-func] de GNU awk.

Para las funciones de análisis y formato de fecha y hora, asegúrate de **establecer el indicador UTC**. Para demostrarlo:

```sh
export TZ=Asia/Kolkata
gawk 'BEGIN {
    time = 1234567890
    print strftime("%Y-%m-%d %T", time)     # format for local timezone
    print strftime("%Y-%m-%d %T", time, 1)  # format for UTC
}'
```

produce:

```none
2009-02-14 05:01:30
2009-02-13 23:31:30
```

[time-func]: https://www.gnu.org/software/gawk/manual/html_node/Time-Functions.html
