# Herramientas para colaboradores

Los estudiantes solo necesitan las herramientas de [INSTALLATION.md](INSTALLATION.md).
Los colaboradores necesitan algunas más, porque los scripts del track las usan:

- `git`, para clonar el repositorio y abrir pull requests.
- `jq`, que usan `bin/verify-exercises` y `bin/add-practice-exercise`.
- `curl`, que usa `bin/fetch-configlet`.
- Python 3.11 o posterior, para el generador de tests.
- `clang-format`, que el generador de tests ejecuta en los archivos que escribe.
- `pre-commit`, que ejecuta las comprobaciones del repositorio antes de cada commit.

Instálalas con el comando para tu distribución y luego sigue los pasos de «Configura el repositorio».

## Debian / Ubuntu

```shell
sudo apt install git jq curl clang-format pre-commit
```

## Fedora

```shell
sudo dnf install git jq curl pre-commit clang-tools-extra diffutils
```

## Arch Linux

```shell
sudo pacman -S git jq curl pre-commit clang diffutils
```

## openSUSE Tumbleweed

```shell
sudo zypper install git jq curl python3-pre-commit clang-tools diffutils
```

## Configura el repositorio

Desde la raíz del repositorio:

```shell
bin/fetch-configlet
bin/configlet info
pre-commit install
pre-commit run --all-files
```
