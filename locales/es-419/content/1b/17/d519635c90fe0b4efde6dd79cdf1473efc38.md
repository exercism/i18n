# Instrucciones

En este ejercicio, vas a escribir un programa que te ayude a prepararte para comprar un vehículo.

Tienes dos tareas: determinar si vas a necesitar obtener una licencia de conducir y estimar el precio aceptable de un vehículo usado.

## 1. Determina si vas a necesitar una licencia de conducir

Algunos tipos de vehículos requieren una licencia de conducir para manejarlos.
Supón que solo los vehículos que contienen `car` o `truck` requieren una licencia; todos los demás se pueden manejar sin licencia.

Implementa un par `pattern {action}` que coincida cuando el primer campo sea `needs_license`.
Debe obtener el tipo de vehículo del segundo campo e imprimir «true» si necesitas una licencia para ese tipo de vehículo.
Si no necesitas una licencia, no necesitas imprimir nada.

```sh
echo "needs_license,dumptruck" | gawk -f vehicle-purchase.awk
# => true

echo "needs_license,bike" | gawk -f vehicle-purchase.awk
# => (empty output)
```

## 2. Calcula una estimación del precio de un vehículo usado

Ahora que ya tomaste tu decisión, quieres asegurarte de conseguir un precio justo en el concesionario.
Como te interesa comprar un vehículo usado, el precio depende de la antigüedad del vehículo.
Como estimación aproximada, supón que si el vehículo tiene menos de 3 años, cuesta el 80 % del precio original que tenía cuando era nuevo.
Si tiene más de 10 años, cuesta el 50 %.
Si el vehículo tiene al menos 3 años pero no más de 10, cuesta el 70 % del precio original.

Implementa un par `pattern {action}` que coincida cuando el primer campo sea `resell_price`.
Debe obtener el precio original del vehículo del segundo campo y la antigüedad del tercer campo.
La acción debe imprimir el precio estimado.

```sh
echo "resell_price,1000,1" | gawk -f vehicle-purchase.awk
# => 800

echo "resell_price,1000,5" | gawk -f vehicle-purchase.awk
# => 700

echo "resell_price,1000,15" | gawk -f vehicle-purchase.awk
# => 500
```
