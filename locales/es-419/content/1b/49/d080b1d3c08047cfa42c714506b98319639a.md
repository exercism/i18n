# Pruebas

Elige tu sistema operativo actual:

* [Windows](##windows)
* [macOS](##macos)
* [Linux](##linux)

# Ejecutar las pruebas

## Windows

1. Abre un Command Prompt.

2. Obtén el primer ejercicio:

    ```batchfile
     C:\Users\USERNAME> exercism download --exercise hello-world --track cobol
    ```

3. Cambia de directorio a la carpeta del ejercicio:

    ```batchfile
     C:\Users\USERNAME> cd C:\Users\USERNAME\exercism\cobol\hello-world
    ```
   
4. Ejecuta las pruebas:

    ```batchfile
     C:\Users\USERNAME\exercism\cobol\hello-world> test.ps1
    ```
    *(No te preocupes si las pruebas fallan la primera vez que las ejecutas, así empiezas cada ejercicio.)*

5. Resuelve el ejercicio.
    Lee el `instructions.md` y mira cómo resolver el ejercicio ([ver en GitHub](https://github.com/exercism/cobol/blob/main/exercises/practice/hello-world/.docs/instructions.md)).


¡Mucha suerte, diviértete y te damos la bienvenida al track de COBOL!

## macOS

1. Abre una ventana de Terminal.

2. Obtén el primer ejercicio:

    ```
     $ exercism download --exercise hello-world --track cobol
    ```

3. Cambia de directorio a la carpeta del ejercicio:

    ```
     $ cd /Users/USERNAME/exercism/cobol/hello-world
    ```

4. Ejecuta las pruebas:

    ```
     $ bash test.sh
    ```
    *(No te preocupes si las pruebas fallan la primera vez que las ejecutas, así empiezas cada ejercicio.)*

    Sugerencia: si recibes un mensaje de que falta `basename`, puedes usar [brew](https://brew.sh/) para instalar coreutils. (`brew install coreutils`)

5. Resuelve el ejercicio.

    Lee el `instructions.md` y mira cómo resolver el ejercicio ([ver en GitHub](https://github.com/exercism/cobol/blob/main/exercises/practice/hello-world/.docs/instructions.md)).


¡Mucha suerte, diviértete y te damos la bienvenida al track de COBOL!
