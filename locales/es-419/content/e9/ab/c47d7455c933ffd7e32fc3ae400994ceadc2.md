# Recursos

## Referencia

- La [tarjeta de referencia de RISC-V][reference-card] enumera las instrucciones, las pseudoinstrucciones y los registros.
- La [convención de llamadas de RISC-V][psabi] describe qué registros contienen los argumentos y los resultados de una función, y cuáles debe preservar una función.
- Las [especificaciones de RISC-V][isa-manual] describen exactamente qué hace cada instrucción.
- El [manual del ensamblador de GNU][gas-directives] describe directivas como `.section`, `.string`, `.word` y `.global`.

## Herramientas

- [Compiler Explorer][godbolt] muestra el código ensamblador que produce un compilador a partir de un fragmento de código en C.
  El enlace lo abre con un compilador de RISC-V de 32 bits, para que puedas comparar tus propias soluciones con lo que escribiría un compilador.

## Comunidad

- [RISC-V International][riscv-org] es la organización que se encarga del estándar de RISC-V.
- [r/RISCV][reddit] es una comunidad de Reddit que comparte noticias sobre chips, placas y software de RISC-V.
- [Stack Overflow][stack-overflow] tiene preguntas y respuestas sobre el lenguaje ensamblador de RISC-V.
