# Instrucciones

Eres el telegrafista inalámbrico de un carguero. La señal llega por una línea ruidosa (la maquinaria del barco, la estática del clima, algún parloteo extranjero ocasional), intercalada con el Morse que de verdad estás escuchando. Para captar el mensaje, pasas el cable por un dispositivo de *cinta* que elimina todo excepto los símbolos Morse válidos (`.`, `-` y el espacio que separa las letras).

Tu trabajo es construir la cinta como un flujo de entrada personalizado de Factor.

## 1. Define la cinta

Define un tuple `tape` que extiende `disposable` y guarda un slot, `wire`, para el flujo de entrada subyacente.

```factor
TUPLE: tape < disposable wire ;
```

Luego escribe el constructor `<tape> ( wire -- tape )`. Usa `new-disposable` (no `new`) para que el framework del destructor registre la cinta, y guarda el flujo subyacente en el slot `wire`.

## 2. Únete al mixin input-stream

Declara que `tape` es un `input-stream`:

```factor
INSTANCE: tape input-stream
```

Eso hace que los combinadores predeterminados del protocolo despachen a tu clase.

## 3. Lee un símbolo Morse

Implementa `M: tape stream-read1 ( tape -- elt/f )`. Lee bytes del cable subyacente hasta que encuentres uno de `CHAR: .`, `CHAR: -` o `CHAR: \s` (espacio). Devuelve ese byte. Si el cable devuelve `f` (fin del flujo), devuelve `f` también: la cinta terminó.

```factor
"x.y -ab cz" <string-reader> <tape>
[ stream-read1 ] [ stream-read1 ] [ stream-read1 ] tri
! => CHAR: . CHAR: - CHAR: \s
```

## 4. Delega el tipo de elemento

Implementa `M: tape stream-element-type ( tape -- type )` delegando en el cable: la cinta no cambia el tipo de elementos que se leen.

## 5. Limpia

Implementa `M: tape dispose* ( tape -- )`. El framework llama a tu método exactamente una vez por cada `dispose`; solo libera el cable subyacente.

Con esas cinco piezas en su lugar, la cinta funciona como un flujo de entrada normal: `with-input-stream`, `stream-read` y las demás palabras del protocolo despachan a tus métodos automáticamente.
