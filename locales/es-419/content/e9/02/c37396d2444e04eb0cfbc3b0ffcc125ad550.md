# Pistas

## 1. Define los tipos `Usd`, `Eur` y `Jpy`

- Los tipos `Usd`, `Eur` y `Jpy` se pueden definir sin constructores usando la sintaxis `pub type TypeName`.

## 2. Define el tipo `Money`

- El tipo `Money` debería tener un parámetro de tipo fantasma para la moneda.

## 3. Define las funciones `dollar`, `euro` y `yen`

- La anotación de retorno de las funciones `dollar`, `euro` y `yen` debería ser `Money(currency)`, donde `currency` es el parámetro de tipo adecuado del tipo `Money`.

## 4. Define la función `total`

- La anotación de retorno de la función `total` debería usar el mismo parámetro de tipo que el argumento.
