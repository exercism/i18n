# Anexo a las instrucciones

## ¿Debería usar `random` o `secrets` aquí?

A partir de Python 3.6, existen dos módulos diferentes para producir números «aleatorios»:

El módulo llamado [`random`][random] es [_pseudoaleatorio_][pseudo-random], lo que significa que **no** genera aleatoriedad verdadera, sino que sigue un algoritmo que _simula_ la aleatoriedad.
Como estos «números aleatorios» se generan mediante un algoritmo conocido, no son verdaderamente aleatorios.
Por eso, el módulo `random` no es adecuado para la criptografía y no deberías usarlo, precisamente porque es pseudoaleatorio.


El módulo llamado [`secrets`][secrets] genera números «aleatorios» [criptográficamente seguros][crypto-strong] que ofrecen la seguridad adicional que exige la criptografía.
En el sentido más estricto, siguen siendo pseudoaleatorios, pero tienen garantías de que los números que producen son absolutamente impredecibles.


Como este es solo un ejercicio de práctica, usar el módulo `random` está bien, pero ten en cuenta que **sería muy inseguro si de verdad se usara para criptografía.**

[pseudo-random]: https://en.wikipedia.org/wiki/Pseudorandomness
[random]: https://docs.python.org/3/library/random.html
[secrets]: https://docs.python.org/3/library/secrets.html
