# Pruebas

Para ejecutar las pruebas incluidas, necesitarás la gema Minitest. Abre una
ventana de terminal y ejecuta el siguiente comando para instalar minitest:

```
gem install minitest
```


Ejecuta las pruebas desde el directorio del ejercicio con el siguiente comando:

```
ruby <snake-case-exercise>_test.rb
```

Reemplaza `<snake-case-exercise>` por el nombre de tu ejercicio en snake_case.

## Salida con color

Puedes usar `require 'minitest/pride'` o ejecutar el siguiente comando para obtener salida con color:

```
ruby -r minitest/pride <snake-case-exercise>_test.rb
```
