# Introducción

Para ver lo básico sobre los argumentos de función, consulta el [concepto de función][function concept].

## Nombres de parámetros

Los [nombres de parámetros][parameters], al igual que los nombres de variables, deben empezar con una letra o un guion bajo, y pueden contener letras, guiones bajos o números.
Los nombres de parámetros no deben contener espacios ni signos de puntuación.


## Argumentos posicionales

Los argumentos posicionales son valores que se pasan a una función en el mismo orden que los parámetros a los que se vinculan.
De manera opcional, se pueden pasar usando el nombre de su parámetro:


```python
def concat(greeting, name):
    return f"{greeting}{name}"
 
# Passing data to the function by position.
print(concat("Hello, ", "Judy"))
#->  Hello, Judy

# Passing data to the function using the parameter name.
print(concat(name="Sally", greeting="Hello, "))
#-> Hello, Sally
```

La primera llamada a concat pasa los argumentos por posición.
La segunda llamada a concat pasa los argumentos por _nombre_, lo que permite cambiar sus posiciones.

Ten en cuenta que los argumentos posicionales no pueden ir después de los argumentos pasados por nombre (_también llamados [argumentos de palabra clave][keyword-arguments]. **No** hay que confundirlos con los parámetros var-positional ni con [**kwargs][kwargs]_).

Este conjunto de argumentos:

```python
>>> print(concat(greeting="Hello, ", "Zed"))
```

dará como resultado este error:

```
SyntaxError: positional argument follows keyword argument
```

## Valores predeterminados de los argumentos

Los [valores predeterminados][default arguments] de uno o más argumentos se pueden indicar en la lista de parámetros.
Esto permite llamar a la función con _menos_ argumentos si es necesario.
Los valores predeterminados se pueden reemplazar llamando a la función con nuevos argumentos en lugar de los predeterminados:


```python
# Note the default arguments for both greeting and name.
def concat(greeting="Hello, ", name="you"):
    return f"{greeting}{name}"
 
# Function call overriding the defaults
print(concat(name="Jerry", greeting="Hello, "))
#-> Hello, Jerry

# Function call without arguments resulting in the defaults being used.
print(concat())
#-> Hello, you
```

## Argumentos de palabra clave

Los argumentos de palabra clave usan el nombre del parámetro al pasar argumentos a una función.
De manera opcional, se pueden indicar por posición:


```python
# Note the default arguments for both greeting and name.
def concat(greeting="Hello, ", name="you"):
    return f"{greeting}{name}"

# Function call using parameter names as argument keywords.
print(concat(name="Jerry", greeting="Hello, "))
#-> Hello, Jerry

# Function call with positional data as arguments.
print(concat("Hello, ", "Isaac"))
#-> Hello, Isaac
```
