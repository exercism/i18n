# Ejecutar las pruebas de Ceylon

Antes de poder ejecutar las pruebas, debes compilar tu código con [`ceylon compile`](https://ceylon-lang.org/documentation/current/reference/tool/ceylon/subcommands/ceylon-compile.html).

Ejecutamos las pruebas con el comando [`ceylon test`](https://ceylon-lang.org/documentation/reference/tool/ceylon/subcommands/ceylon-test.html).

`ceylon test` espera un nombre de módulo sobre el cual ejecutar las pruebas.
En el track de Ceylon, cada ejercicio tiene un solo módulo.

Por lo tanto, puedes ejecutar las pruebas con:

```bash
ceylon compile && ceylon test $(basename source/*)
```
