# Acerca de

El concepto básico de `try .. rescue` se puede extender para admitir las cláusulas `else` y `after`:

- El bloque `else`:
  - Donde ocurre una coincidencia de patrones con el resultado exitoso del bloque try.
- El bloque `after`:
  - Donde se invocan funciones ya sea que el bloque try tenga éxito o sea rescatado, siempre que el programa se esté ejecutando.
  - El resultado del bloque `after` no se devuelve al ámbito que hizo la llamada.

```elixir
try do
  :a
rescue
  _ -> :error
else
  :a -> :success
after
  :some_action
end

# => :success
```
