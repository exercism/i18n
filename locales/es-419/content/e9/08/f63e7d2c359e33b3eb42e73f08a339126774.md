# Acerca de

- El tipo [binary][binary] es una especialización del tipo [bitstring][bitstring].
- Los binarios están compuestos por [bytes][wiki-byte].
  - Un byte son 8 [bits][wiki-bit].
  - Los bytes pueden representar números desde `0` hasta `255`.
  - Los valores enteros [hexadecimales][wiki-hexadecimal] son comunes cuando trabajas con bytes: de `0x00` a `0xFF`.
- Los literales binarios se definen usando la [forma especial `<<>>`][special-form].
  - Si usas un entero mayor que `255` para un byte, solo se usan los últimos 8 bits, a menos que especifiques la [unidad y/o el tamaño a usar][bin-size] con el operador [`::`][type-operator].
- Se puede usar [`<>/2`][bin-concat] para concatenar bitstrings, binarios o strings.

```elixir
<<255>> == <<0xFF>>
# Overflowing bits are truncated
<<256>> == <<0>>
<<256::size(16)>> == <<1, 0>>

<<"Hello">> == <<72, 101, 108, 108, 111>>
```

Un _byte nulo_ es otro nombre para `<<0>>`.

## Los strings son datos binarios codificados

- Los strings son datos binarios codificados en formato [UTF-8][wiki-utf8].
  - Se codifican en bloques de 8 bits (un byte), usando hasta 4 bytes para representar más de 255 caracteres.
  - La [longitud de un string][string-length] puede no ser la misma que su [tamaño en bytes][byte-size].

```elixir
# This string has a string length of 5, but is made up of 7 bytes
string = "cześć"
String.length(string) != byte_size(string)

# Even emoji strings are encoded binaries
"👍" == <<240, 159, 145, 141>>
```

## Coincidencia de patrones en datos binarios

- Con los binarios se puede hacer [coincidencia de patrones como un todo o usando la forma especial][special-form] para hacer coincidir solo una parte.
  - Solo la última parte de una coincidencia de patrones puede tener un tamaño variable.

```elixir
# Ignore the first 8 bytes, bind the remaining variable sized binary to `body`
<<_::binary-size(8), body::binary>>
```

Esto también se puede hacer con strings:

```elixir
# bind the first 5 bytes to `name`,
# match the string literal " the ",
# bind remaining bytes to `species`
<<name::binary-size(5), " the ", species::binary>> = <<"Frank the Walrus">>
{name, species}
# => {"Frank", "Walrus"}
```
