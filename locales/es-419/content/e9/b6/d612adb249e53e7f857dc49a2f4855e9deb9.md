* [Comandos del paquete Thread](https://tcl.tk/man/tcl8.6/ThreadCmd/contents.htm) de la documentación de Tcl.

## Instalación

Algunas distribuciones de Tcl no incluyen el paquete Thread de Tcl de forma predeterminada: puede que sea necesario instalarlo por separado.
Verifícalo con
```bash
$ echo 'package require Thread' | tclsh
```
Si eso _no produce ninguna salida_, entonces el paquete Thread ya está instalado.

Ejecuta `apt install tcl-thread` (o `dnf install tcl-thread`) según sea necesario.
