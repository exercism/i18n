# Instrucciones

Hay una tienda de electrodomésticos llamada «Tech Palace» cerca de aquí.
El dueño de la tienda instaló recientemente una gran pantalla para usarla en mensajes publicitarios y para mostrar un saludo especial cuando los clientes escanean sus llamadas tarjetas de lealtad en la entrada.
La pantalla consta de muchas luces LED pequeñas y puede mostrar varias líneas de texto.

El dueño de la tienda necesita tu ayuda con el código que se usa para generar el texto de la nueva pantalla.

## 1. Crea el mensaje de bienvenida

Para la mayoría de los clientes que escanean sus tarjetas de lealtad, el dueño de la tienda quiere ver `Welcome to the Tech Palace, ` seguido del nombre del cliente en mayúsculas en la pantalla.

Implementa la función `welcome` que acepta el nombre del cliente y devuelve el mensaje deseado como un string.

```julia-repl
julia> welcome("Judy")
"Welcome to the Tech Palace, JUDY"
```

## 2. Agrega un borde elegante

Para los clientes leales que compran mucho en la tienda, el dueño quiere que la pantalla de bienvenida sea más llamativa agregando una línea de estrellas antes y después del mensaje de bienvenida.
Todavía no está seguro de cuántas estrellas debería haber en las líneas, así que quiere que eso sea configurable.

Escribe una función `add_border` que acepta un mensaje de bienvenida y el número de estrellas por línea como argumentos.
Debería devolver un string que consta de 3 líneas: una línea con el número deseado de estrellas, luego el mensaje de bienvenida tal como se pasó, y después otra línea de estrellas.

```julia-repl
julia> add_border("Welcome!", 10)
"**********\nWelcome!\n**********"
```

## 3. Limpia los antiguos mensajes publicitarios

Antes de instalar esta nueva pantalla, la tienda tenía una pantalla similar que solo podía mostrar líneas estáticas no configurables.
El dueño quiere reutilizar algunos de los antiguos mensajes publicitarios en la nueva pantalla.
Sin embargo, los datos ya incluyen algunos espacios en blanco desafortunados que se usaron para alinear el texto entre varias pantallas apiladas una encima de otra.
Tu tarea es limpiar los mensajes para que se puedan reutilizar.

Implementa una función `clean` que acepta el antiguo mensaje publicitario.
La función debe primero eliminar todos los espacios en blanco al inicio y al final del texto y devolverlo.

```julia-repl
julia> clean("    BUY NOW, SAVE 10%   ")
"BUY NOW, SAVE 10%"
```
