# Introducción

La *combinatoria* es la matemática de contar y enumerar las maneras en que se puede elegir u ordenar un conjunto de elementos. El vocabulary [`math.combinatorics`][math.combinatorics] de Factor cubre las dos preguntas básicas:

- **Combinaciones**: selecciones en las que el orden *no* importa.
- **Permutaciones**: ordenamientos en los que el orden *sí* importa.

Cada pregunta tiene una *word* de conteo que devuelve un número y una *word* de listado que devuelve las selecciones en sí, además de una variante *streaming* con prefijo `each-` que llama a una quotation con cada una de ellas:

```
nCk              ( n k -- m )              ! count of k-combinations
nPk              ( n k -- m )              ! count of k-permutations
all-combinations ( seq k -- combinations )
all-permutations ( seq -- permutations )
each-combination ( seq k quot -- )
each-permutation ( seq quot -- )
```

```factor
USING: math.combinatorics prettyprint ;

5 2 nCk .                        ! => 10
{ 1 2 3 } 2 all-combinations .   ! => { { 1 2 } { 1 3 } { 2 3 } }
{ 1 2 } all-permutations .       ! => { { 1 2 } { 2 1 } }
```
