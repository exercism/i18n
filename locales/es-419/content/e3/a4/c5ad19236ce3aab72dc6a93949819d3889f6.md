# Apéndice de instrucciones

## Implementación

Para construir un programa concurrente/paralelo en Crystal, [quizás te resulte útil este recurso][resource].
En Crystal 1.19 se agregó una nueva biblioteca [Sync][sync], que añade varias primitivas para facilitar la creación de programas concurrentes/paralelos de alto rendimiento.

El entorno en línea de este ejercicio es un poco diferente al de la mayoría de los demás ejercicios.
En lugar de compilar Crystal en un binario de un solo hilo, este ejercicio usa las capacidades experimentales de multihilo de Crystal.
Por eso, la ejecución podría comportarse de manera distinta a la esperada en algunos entornos.

Para el desarrollo local, se recomienda tener instalada la versión 1.19.0 de Crystal o una posterior, y agregar el flag `-Dpreview_mt` al compilar o ejecutar tu código para habilitar el soporte de multihilo.

[resource]: https://crystal-lang.org/reference/latest/guides/concurrency.html
[sync]: https://crystal-lang.org/api/latest/Sync.html
