# Pistas

## General

- El [tipo átomo se describe aquí][atom].

## 1. Determina la etiqueta del log

- Puedes usar la [forma especial `cond/1`][cond] para manejar de forma elegante los distintos códigos de log.
- Puedes usar los [operadores de igualdad][equality] para comparar enteros y verificar su igualdad estricta de tipo.
- Hay una [forma de especificar una rama predeterminada][cond] en una expresión cond que puedes usar para capturar los casos no especificados.

## 2. Envía una alerta

- Puedes usar la [forma especial `cond/1`][cond] para decidir si se debe enviar una alerta.
- Puedes usar los [operadores de igualdad][equality] para comparar átomos y verificar si son iguales.
