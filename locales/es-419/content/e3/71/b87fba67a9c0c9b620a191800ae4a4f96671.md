# Pistas

## General

- Lee sobre el uso de las bibliotecas de Erlang en la [guía oficial de primeros pasos][getting-started-erlang-libraries] y, en particular, sobre [formatear strings][getting-started-formatted-text-output].

## 1. Genera un planeta aleatorio

- Usa el atributo de módulo que se proporciona con una lista de letras que representan las clases planetarias.
- Hay una [función integrada][enum-random] para elegir un elemento de una lista al azar.

## 2. Genera un número de registro de nave estelar aleatorio

- Hay una [función integrada][enum-random] para elegir un elemento de un rango al azar.

## 3. Genera una fecha estelar aleatoria

- No hay ninguna función de Elixir que devuelva un número de punto flotante aleatorio.
- Hay una [función integrada de Erlang][erl-rand-uniform] que devuelve un número de punto flotante aleatorio x, donde `0.0 <= x < 1.0`.
- Si `x` pertenece a un rango `0.0 <= x < 1.0`, pero necesitas un número de un rango diferente `a <= x < b`, puedes desplazar el rango de x multiplicándolo por el ancho del rango (`b - a`) y sumándole el inicio del rango (`a`). Es decir: `x * (b - a) + a`.

## 4. Formatea la fecha estelar

- No hay ninguna función de Elixir que sea capaz de formatear un número de punto flotante como un string con una precisión dada en un solo paso.
- Hay una [función integrada de Erlang][erl-io-lib-format] que recibe un string de formato y una lista de datos, y devuelve un charlist.
- Hay una [función integrada][to-string] que convierte un charlist en un string.
- El string de formato de esa función contiene secuencias de control.
- Una secuencia de control empieza con `~` y tiene el patrón `~F.P.PadModC`, donde `F` representa el ancho de la salida, `P` representa la precisión, `Pad` representa el carácter de relleno, `Mod` representa el modificador de la secuencia de control y `C` es el tipo de la secuencia de control.
- Para formatear un número de punto flotante con la precisión deseada, basta con una secuencia de control con el patrón `~.PC`.
- El tipo de secuencia de control para números de punto flotante es `f`.
- El string de formato exacto que necesitas es `~.1f`.
