# Aprender

Exercism ofrece ejercicios y retroalimentación, pero puede ser difícil empezar para quienes aprenden Common Lisp por primera vez.
Estos recursos te pueden ayudar a comenzar:

* [A Road to Common Lisp][road-to-cl], una entrada de blog que explica el camino que siguió una persona hacia Common Lisp y sus opiniones sobre cómo empezar con él
* [Practical Common Lisp][practical-cl], un libro completo para aprender Common Lisp, disponible gratis en línea (además de en versión impresa)
* [Common Lisp Cookbook][cl-cookbook]
* [Cliki.net Getting Start Started Page][cliki-getting-started]
* [Wikibooks book of Common Lisp, First steps][wikibooks-cl-first-steps]
  por varios colaboradores
* [Awesome Common Lisp Learning][awesome-cl]

Consulta también, dentro de este track de Common Lisp de Exercism: [Recursos importantes][track-resources].
