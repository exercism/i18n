# Instalación

## Versión objetivo

Las pruebas de este track usan la imagen de Docker `alpine:3.24.1` que, a partir de septiembre de 2026, usa `sqlite3 version 3.53.4`.
Nos esforzamos por garantizar que las herramientas que ofrece este track funcionen en la última versión LTS de Ubuntu.
Aunque es posible que tengas instaladas versiones más recientes, debes tener en cuenta que algunas funcionalidades podrían no funcionar con nuestro ejecutor de pruebas.
Puedes comparar las funcionalidades en el [historial de versiones de SQLite][version-history].

## Windows

Para instalar SQLite en Windows, sigue estos pasos:

1. Descarga los binarios precompilados para Windows desde la [página de descarga oficial][sqlite-download].
2. Extrae el archivo ZIP que descargaste en el directorio que quieras.
   Por ejemplo, `C:\Program Files\sqlite3`.
3. Agrega el directorio que contiene `sqlite3.exe` a la variable de entorno PATH del sistema.
   El proceso es un poco distinto en cada versión de Windows, pero la información debería ser fácil de encontrar.
   Por ejemplo, [instrucciones para Windows 11][windows-11-install] y [para Windows 10][windows-10-install].

## macOS

En macOS, SQLite viene preinstalado.
Sin embargo, si necesitas una versión más reciente, puedes usar [Homebrew][homebrew]:

```bash
brew install sqlite
```

## Ubuntu / Debian

En Ubuntu y en los sistemas basados en Debian, puedes instalar SQLite con apt:

```bash
sudo apt install sqlite3
```

## CentOS / Fedora / RHEL

En CentOS, Fedora y los sistemas basados en Red Hat, puedes instalar SQLite con yum o dnf:

```bash
sudo yum install sqlite3
# OR
sudo dnf install sqlite3
```

## Arch Linux

En Arch Linux, puedes instalar SQLite con pacman:

```bash
sudo pacman -S sqlite
```

## Otras formas de instalación y versiones anteriores

Consulta la [página de descarga de SQLite][sqlite-download] para obtener más información y conocer métodos de instalación alternativos.
La sección `Build Product Names and Info` incluye la plantilla de nombres de las distintas versiones de SQLite, así que deberías poder buscar la versión que quieras con tu motor de búsqueda favorito.
