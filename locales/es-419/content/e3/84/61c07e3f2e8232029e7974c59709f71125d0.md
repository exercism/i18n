# Introducción

Java es un lenguaje de tipado estático, lo que significa que el tipo de una variable se conoce en tiempo de compilación.
Asignar un valor a un nombre se conoce como definir una variable.
Una variable se define especificando su tipo de forma explícita.

```java
int explicitVar = 10;
```

Actualizar el valor de una variable se hace mediante el operador `=`.
Aquí, `=` no representa una igualdad matemática.
Simplemente asigna un valor a una variable.
Una vez definida, el tipo de una variable nunca puede cambiar.

```java
int count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning a different type
// count = false;
```

Java es un [lenguaje orientado a objetos][object-oriented-programming] y exige que todas las funciones se definan dentro de una _clase_.
La palabra clave `class` se usa para definir una clase.

```java
class Calculator {
    // ...
}
```

Una función dentro de una clase se conoce como _método_.
Cada método puede tener cero o más parámetros.
Todos los parámetros deben tener su tipo explícito; no hay inferencia de tipos para los parámetros.
De forma similar, el tipo de retorno también debe ser explícito.
Los valores se devuelven desde los métodos con la palabra clave `return`.
Para que otras clases puedan llamar a un método, hay que añadir el modificador de acceso `public`.

```java
class Calculator {
    public int add(int x, int y) {
        return x + y;
    }
}
```

Para invocar o llamar a un método, se especifica su clase y el nombre del método, y se pasan argumentos para cada uno de los parámetros del método.

```java
int sum = new Calculator().add(1, 2);  // here the  "add" method has been called to perform the task of addition
```

El ámbito en Java se define entre los caracteres `{` y `}`.

Java admite dos tipos de comentarios.
Los comentarios de una sola línea van precedidos por `//`, y los comentarios multilínea se insertan entre `/*` y `*/`.

[object-oriented-programming]: https://docs.oracle.com/javase/tutorial/java/javaOO/index.html
