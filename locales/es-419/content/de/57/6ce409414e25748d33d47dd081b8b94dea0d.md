# Introducción

Los genéricos te permiten escribir código que funciona con varios tipos sin duplicarlo.
Define tipos genéricos con paréntesis angulares `<T>`, donde `T` es un marcador de posición para cualquier tipo.

```rust
fn largest_list<T>(l1: Array<T>, l2: Array<T>) -> Array<T> {
    if l1.len() > l2.len() {
        l1
    } else {
        l2
    }
}
```

Cairo requiere límites de trait para especificar qué operaciones debe soportar el tipo genérico.
Puedes agregar restricciones usando la sintaxis `+`:

```rust
fn process_data<T, +Drop<T>, +Copy<T>>(value: T) -> T {
    // Function body
}
```

Las estructuras también pueden ser genéricas:

```rust
#[derive(Drop)]
struct Container<T> {
    value: T,
}
```

Los traits también pueden ser genéricos, lo que les permite funcionar con distintos tipos:

```rust
trait Processor<T> {
    fn process(self: @T) -> ByteArray;
}

impl MyProcessor<T, +Drop<T>> of Processor<T> {
    fn process(self: @T) -> ByteArray {
        "processed"
    }
}
```

Las funciones pueden aceptar parámetros genéricos con límites de trait, lo que les permite funcionar con cualquier tipo que implemente el trait requerido:

```rust
fn use_processor<T, +Processor<T>, +Drop<T>>(item: T) -> ByteArray {
    item.process()
}
```
