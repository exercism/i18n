# Acerca de

Un `bit` es el valor más granular de la computación.
La palabra `bit` significa «dígito binario».
Es una unidad de almacenamiento de datos en el entorno de ejecución, lo bastante grande como para contener un objeto que puede tener uno de dos valores.
Como tal, tiene un valor binario de `1` o `0`.
Todos los demás tipos de datos están compuestos por múltiples `bits`.
Por ejemplo, un `byte` normalmente está compuesto por ocho `bits`.

## Cómo escribir valores de bits

Los `Bits` conforman un sistema de numeración de base 2.
Cada múltiplo de `2` se coloca en lo que consideramos la posición de las decenas, centenas, millares, etc., solo que «decenas» sería «dos», «centenas» sería «cuatro», «millares» sería «ocho», y así sucesivamente.
Entonces, el valor decimal `2` sería el valor binario `10`, `4` sería `100` y `8` sería `1000`.
Al igual que los números decimales, los valores aumentan a medida que van de derecha a izquierda.
Podemos pensar que el valor decimal `5` se representa con `101` en binario, con un `1` en la posición de las unidades y un `1` en la posición del cuatro.
Sin embargo, los literales binarios no forman parte del estándar del lenguaje C.
Los únicos valores binarios que admite el estándar del lenguaje C son un único `1` o `0`.
Los literales binarios _sí_ son compatibles con algunas extensiones de compilador no estándar, como el compilador gnu, anteponiendo `0b` al literal.

```c
#include <stdio.h>

int main() {
    int binary_five = 0b101;
    printf("%d", binary_five);
    return 0;
}
```

Es importante recordar que esa notación no es compatible con todos los compiladores y podría ser un obstáculo para la portabilidad del código entre distintos compiladores.

Una forma común de escribir valores binarios es usar la notación hexadecimal, que es un sistema de numeración de base 16.
La notación hexadecimal del lenguaje C antepone `0x` o `0X` al literal.
Como el valor decimal `16` se representa con `1` en la posición de las decenas, el valor decimal `10` se representa con `0xA` en hexadecimal, `11` con `0xB`, `12` con `0xC`, `13` con `0xD`, `14` con `0xE` y `15` con `0xF`.
Así, por ejemplo, el valor decimal `42` se escribiría como `0x2A`: `2` por `16` (= `32`) más `10` (= `42`).

En binario, podemos pensar en `42` como `00101010`: `32` más `8` más `2`.
Diríamos que el segundo, cuarto y sexto bit desde la derecha están «activados», es decir, que son `1` en lugar de `0`.
El segundo bit es `2`, el cuarto bit es `8` y el sexto bit es `32`.
Activar esos tres bits define un valor de `42`.

## Máscaras de bits

Una máscara de bits puede ser cualquier valor que se use para activar bits individuales.
Por ejemplo, el alfabeto inglés tiene veintiséis letras.
Un valor de al menos veintiséis bits, como un entero sin signo de 32 bits, podría usarse como máscara de bits para establecer una condición `true` o `false` para cada letra del alfabeto inglés.
Cualquier valor con suficientes bits para manejar un conjunto requerido de condiciones `true` o `false` puede servir como máscara de bits.
Activar y leer los bits individuales se hace mediante el uso de operadores a nivel de bits.

## Operadores a nivel de bits

Supongamos que queremos llevar un registro de qué letras aparecen en un `string`.
Para nuestro ejemplo, usaremos solo las veintiséis letras del alfabeto inglés.
Nuestra máscara de bits será un entero sin signo de 32 bits.
Un `0` representará que la letra no aparece.
Un `1` representará que la letra aparece una o más veces.
Al principio, la representación en bits de nuestra máscara de bits serán 32 `0s` seguidos: `00000000000000000000000000000000`.
La posición más a la derecha será para `A`.
La segunda desde la izquierda será para `B`, y así sucesivamente.
Supongamos que procesamos todas las letras del string en un bucle, así que queremos una línea de código que sirva para activar cualquier letra.

### Operador de desplazamiento a la izquierda: una forma de posicionar un bit

`<<` es el operador a nivel de bits para desplazar a la izquierda.

Si nuestra letra es `A` no queremos desplazar a la izquierda, pero si nuestra letra es `B` queremos desplazar una posición a la izquierda, y si nuestra letra es `C` queremos desplazar dos posiciones a la izquierda, y así sucesivamente.
Aunque podemos percibir los `chars` como letras como `A` o `B`, un `char` se implementa como un tipo entero en memoria, así que podemos hacer operaciones matemáticas simples con un `char`.
Dada una variable llamada `letter` que representa el `char` que estamos procesando, podemos desplazar a la izquierda la cantidad de posiciones necesaria desplazando `1` a la izquierda la diferencia entre `letter` y el `char` `A`, así: `1 << letter - 'A'`.
`A` - `A` es `0`, así que desplazaría `0` posiciones a la izquierda si `letter` es `A`.
`B` - `A` es `1`, así que desplazaría `1` posición a la izquierda si `letter` es `B`, y así sucesivamente.

### Operador OR inclusivo a nivel de bits: una forma de activar un bit

Una vez que sabemos _dónde_ queremos activar un bit, podemos activarlo usando el operador OR inclusivo a nivel de bits, que es `|`.
El resultado del operador `|` será `1` en cada posición donde el operando izquierdo o el derecho tenga un bit activado.
Así, el resultado de `0010 | 0001` sería `0011`.
(Es importante recordar que el valor es `11` en binario, pero es `3` en decimal).
Para asignar el resultado a un valor, el operador `|` se puede combinar con el operador de asignación para activar los bits así: `|=`.
Para simplificar, el siguiente ejemplo no usa un bucle, pero demuestra cómo podríamos procesar las letras `ABA` en una máscara de bits.

```c
#include <stdio.h>
#include <stdint.h>

int main() {
    // it's important to initialize the mask to 0 so we don't get garbage values
    uint32_t mask = 0;
    char letter_A = 'A';
    char letter_B = 'B';
    char letter_A_again = 'A';
    mask |= 1 << letter_A - 'A';
    mask |= 1 << letter_B - 'A';
    mask |= 1 << letter_A_again - 'A';
    // prints 3
    printf("%d", mask);
}
```

Establecemos la parte más a la derecha de nuestra máscara en `0001` para `A`, y luego establecemos la máscara en `0011` para `B`.
Activar otra `A` no produce ningún cambio en la máscara existente.
Podríamos haber evitado activar el bit de nuevo comprobando si `A` ya estaba activado.

### Operador AND a nivel de bits: una forma de leer un bit

`&` es el operador AND a nivel de bits.
El resultado del operador `&` será `1` en cada posición donde tanto el operando izquierdo como el derecho tengan un bit activado.
Así, el resultado de `0011 & 0001` sería `0001`.
Podemos ver esto en acción en el siguiente ejemplo.

```c
#include <stdio.h>
#include <stdint.h>

int main() {
    uint32_t mask = 0;
    char letter_A = 'A';
    char letter_B = 'B';
    char letter_A_again = 'A';
    mask |= 1 << letter_A - 'A';
    mask |= 1 << letter_B - 'A';
    // prints A already set
    if (mask & 1 << letter_A_again - 'A')
        printf("A already set\n");
    else
        mask |= 1 << letter_A_again - 'A';
    printf("%d", mask);
}
```

### Operador OR exclusivo a nivel de bits: una forma de invertir un bit

`^` es el operador OR exclusivo a nivel de bits.
Un operador OR _inclusivo_ implica que existe un operador OR _exclusivo_ con un comportamiento diferente.
El resultado del operador `^` será `1` en cada posición donde _solo uno_ de los operandos izquierdo o derecho tenga un bit activado.
Así, el resultado de `0001 ^ 0011` sería `0010`.
El bit más a la derecha no se activará porque _ambos_ operandos tienen `1` en la posición más a la derecha.
La operación OR exclusiva a veces se denota como XOR.
Si al resultado de un valor al que se le aplica XOR se le aplica XOR de nuevo, devolverá el valor original.
Esto se puede usar para un cifrado muy simple donde se usa la misma clave tanto para cifrar como para descifrar los datos.
Por ejemplo

```c
#include <stdio.h>

int main() {
    char a = 'a';
    char b = 'b';
    char c = 'c';
    // we will use "a" for the "key"
    char first = a ^ 'a';
    char second = b ^ 'a';
    char third = c ^ 'a';
    // prints three "dots" for unprintable characters
    printf("%c %c %c\n", first, second, third);
    // prints the ascii values 0 3 2
    printf("%d %d %d\n", first, second, third);
    first = first ^ 'a';
    second = second ^ 'a';
    third = third ^ 'a';
    // prints a b c
    printf("%c %c %c\n", first, second, third);
    // prints the ascii values 97 98 99
    printf("%d %d %d\n", first, second, third);
}
```

### Operador de desplazamiento a la derecha: una forma de dividir un valor a la mitad

`>>` es el operador a nivel de bits para desplazar a la derecha.
Por lo general, por cada posición que se desplazan a la derecha los bits de un valor, el resultado es el valor dividido entre dos.
Por ejemplo

```c
#include <stdio.h>

int main() {
    int number = 16;
    number >>= 2;
    // prints 4, or 16 / 2 = 8 / 2 = 4
    printf("%d\n", number);
}
```

Si el valor del operando derecho es negativo o es mayor o igual que el ancho del operando izquierdo promovido, el comportamiento no está definido.
Eso también se aplica al operador de desplazamiento a la izquierda.
Cuando se usa un entero con signo en lugar de un entero sin signo, el signo también puede influir.
El siguiente ejemplo muestra el comportamiento en un sistema al desplazar demasiado a la izquierda o a la derecha un entero con signo.

```c
#include <stdio.h>

int main() {
    int number = 16;
    number <<= 250;
    // prints 1073741824
    printf("%d\n", number);
    number <<= 1;
    // prints -2147483648
    printf("%d\n", number);
    number <<= 1;
    // prints 0
    printf("%d\n", number);
    // total shifts are now 256, done incrementally
    number <<= 4;
    // prints 0
    printf("%d\n", number);
    number = 16;
    // prints 16 when 256 total shifts done at once
    printf("%d\n", number << 256);
    // prints 0 when bits shifted right far enough
    printf("%d\n", number >> 5);    
    // still prints 0
    printf("%d\n", number >> 255);
    // prints 16 when shifted right far enough to "wrap around"
    printf("%d\n", number >> 256);
}
```

Dado que el comportamiento no está definido, un sistema diferente puede dar resultados distintos.
Al desplazar bits, es importante entender los límites del tipo de datos que se usa.

## Campos de bits

Hemos visto cómo los bits empaquetados en un tipo de datos simple se pueden direccionar por su posición.
Los bits empaquetados en un `struct` se pueden direccionar por nombre.
Ese tipo de datos se llama `bit field`.
Un caso de uso de los `bit fields` puede ser cuando se necesita una colección de indicadores de encendido/apagado y se quiere minimizar el uso de memoria.

```c
#include <stdio.h>

int main() {

    struct lights {
        unsigned int number_of_lights;
        unsigned int red   : 1;
        unsigned int green : 1;
        unsigned int blue  : 1;
    };
    struct lights lightboard = {3, 0, 0, 0};
     
    //  prints 000
    printf("%d", lightboard.red);
    printf("%d", lightboard.green);
    printf("%d\n", lightboard.blue);
    
    lightboard.green = 1;

    //  prints 010
    printf("%d", lightboard.red);
    printf("%d", lightboard.green);
    printf("%d\n", lightboard.blue);
    
    // prints 3
    printf("%d\n", lightboard.number_of_lights);
}
```

La sintaxis de `unsigned int variable_name : 1;` crea un campo de `1` bit dentro de un `unsigned int` colocado dentro del struct.
En lugar de un `unsigned int` se podría usar un `signed int` o, a partir de C99 o posterior, se podría usar un tipo `bool`.
Un struct que contiene campos de bits también puede contener campos de otros tipos de datos, como `number_of_lights` en el ejemplo anterior.
