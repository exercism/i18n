# Introducción

Haxe tiene dos tipos de números: enteros y números de punto flotante:

- `Int`: representa un número entero.
- `Float`: representa un número de punto flotante de doble precisión de 64 bits.

```haxe
var integer:Int = 10;
var floating:Float = 5.4;
```

Aunque todo `Int` se puede usar donde se espera un `Float` (es decir, `Int` **es asignable a** o **se unifica con** `Float`), lo contrario no es cierto: asignar un `Float` a un `Int` puede causar pérdida de precisión y, por eso, no se permite implícitamente.
