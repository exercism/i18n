# Pistas

## General

- Usa el tipo de lista integrado [(con enlace)][list].

## 1. Define una función que devuelva una lista de lenguajes vacía

- La función debe devolver `[]`.

## 2. Define una función para agregar un lenguaje a la lista

- Puedes agregar un elemento al principio de una lista usando `:`.

## 3. Define una función para eliminar un lenguaje de la lista

- Haskell [proporciona una función][tail] que devuelve una lista con el primer elemento eliminado.

## 4. Define una función que devuelva el primer elemento de la lista

- Haskell [proporciona una función][head] para obtener el primer elemento de una lista.

## 5. Define una función que devuelva cuántos lenguajes hay en la lista

- Haskell [proporciona una función][length] para contar la longitud de una lista.

## 6. Define una función que determine si la lista incluye un lenguaje funcional

- Tu función debe devolver un valor booleano que indique si `"Haskell"` es un miembro de la lista. 
  Haskell [proporciona una función][elem] para comprobar si un elemento pertenece a la lista.
