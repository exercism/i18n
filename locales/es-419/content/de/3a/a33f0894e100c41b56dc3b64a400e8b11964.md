# Acerca de

Los dicts en Gleam son la estructura de datos para almacenar información en pares clave-valor. En otros lenguajes, también se los conoce como arrays asociativos, hashes o diccionarios.

Se puede usar cualquier tipo para las claves y los valores de un dict, y no garantizan el orden de sus entradas cuando se accede a ellas o se devuelven.

## Trabajar con dicts

Los dicts se crean y se manipulan usando funciones del módulo `gleam/dict`.

```gleam
// Create an empty dict
let dict1 = dict.new()

// Create a dict with some values
let dict2 = dict.from_list([
  #("name", "Gleam"),
  #("colour", "Pink"),
])

// Add a value to a dict
let dict3 = dict.insert(dict2, "website", "https://gleam.run")

// Get a value from a dict
let name = dict.get(dict3, "name")
// -> Ok("Gleam")
```
