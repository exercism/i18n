# Introducción

Al igual que otros lenguajes, C++ también proporciona una sentencia `switch`.
Las sentencias `switch` son una forma más corta de escribir largas sentencias `if ... else if`.
Para crear un `switch`, comenzamos usando la palabra clave `switch` seguida de un entero.
Luego declaramos cada una de las condiciones con la palabra clave `case`.
También podemos declarar un caso `default`, que se ejecutará cuando ninguna de las condiciones `case` anteriores coincida.
Cada caso debe terminar con una sentencia `break` (o `return`).

```cpp
int price{0};
int adults{3};
int kids{2};

switch (int group_size{adults + kids}) {
    case 1:
        price = 50;
        break;
    case 2:
        price = 70;
        break;
    default:
        price = group_size * 30;
}
```

## Caída

Una cosa importante sobre la construcción `switch` es que el código seguirá ejecutándose hasta que se detenga con una sentencia `break` (o `return`).
Esto puede provocar un comportamiento inesperado.

```cpp
int adults{1};
int kids{0};
switch (int group_size{adults + kids}) {
    case 1:
        price = 50;
    case 2:
        price = 70;
    default:
        price = group_size * 30;
}
// price will be 30!
```

El principal caso de uso de esta característica de ejecución continua es una sentencia que tiene varias etiquetas.
Varios resultados del `switch` pueden corresponder al mismo fragmento de código a ejecutar.
De esta forma, en una aplicación de reservas, por ejemplo, la función llamada para tamaños de grupo 2 y 3 puede ser la misma:
```cpp
switch (group_size) {
case 1:
    book_room();
    break;
case 2:
case 3:
    book_apartment(group_size);
    break;
default:
    book_house(group_size);
}
// book_apartment happens when group_size is 2 or 3
```
