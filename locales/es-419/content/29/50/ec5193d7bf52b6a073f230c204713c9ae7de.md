# Rutinas vinculadas

Todo lo que hemos visto hasta ahora pasa *valores* de un lado a otro: números, strings, objetos. Una **rutina vinculada** te permite pasar la rutina misma: algo que se llamará más tarde, desde un código que no sabe qué es.

Un suplente es exactamente esa idea: el regidor de escena guarda una forma de interpretar el papel, sin saber quién es ni qué hará.

## Cómo crear una

`bind` recibe una llamada con huecos, marcados con `_`:

```sather
   shout(line : STR) : STR is return line.upper; end;

   ...

   part ::= bind(shout(_));
```

Ahora `part` es un valor como cualquier otro. Se llama más tarde:

```sather
   part.call("who's there")      -- "WHO'S THERE"
```

## El tipo

El tipo de una rutina vinculada es `ROUT`, con los tipos de los argumentos entre llaves y el tipo que devuelve después de dos puntos:

```sather
   part : ROUT{STR}:STR := bind(shout(_));
```

Lee `ROUT{STR}:STR` como «una rutina que recibe un `STR` y devuelve un `STR`».

| Escrito | Significa |
| --- | --- |
| `ROUT{STR}:STR` | recibe un `STR`, devuelve un `STR` |
| `ROUT{INT,INT}:BOOL` | recibe dos `INT`, devuelve un `BOOL` |
| `ROUT{STR}` | recibe un `STR`, no devuelve nada |
| `ROUT:INT` | no recibe nada, devuelve un `INT` |

Como es un tipo, puede ser un argumento:

```sather
   rehearse(line : STR, part : ROUT{STR}:STR) : STR is
      return part.call(line);
   end;
```

`rehearse` no tiene idea de qué hace `part`. De eso se trata: se le puede pasar `shout`, `whisper` o cualquier otra cosa de esa forma.

## Rellenar algunos de los argumentos

No todos los argumentos tienen que ser un hueco. Todo lo que se escribe queda fijo en el momento de vincular:

```sather
   repeat(times : INT, line : STR) : STR is ... end;

   twice ::= bind(repeat(2, _));      -- ROUT{STR}:STR
```

`twice` solo recibe la línea, porque el `2` ya está decidido. El valor se calcula en el momento de vincular y se conserva, así que cambiar después la variable de la que salió no hace ninguna diferencia.

Así es como una rutina general se convierte en muchas rutinas específicas.

## Vincular también el objeto

En una rutina de un objeto, el objeto es lo primero en la llamada y puede quedar fijo o dejarse como un hueco:

```sather
   bind(board.home_goal)      -- this board's, always
   bind(_.home_goal)          -- whichever board is handed in later
```
