# Pistas

## General

- Intenta dividir un problema en un caso base y un caso recursivo. Por ejemplo, supongamos que quieres contar cuántas galletas hay en el frasco de galletas con un enfoque recursivo. El caso base es un frasco vacío: tiene cero galletas. Si el frasco no está vacío, entonces el número de galletas que hay en el frasco es igual a una galleta más el número de galletas que quedan en el frasco después de quitar una galleta.

## 1. Verifica cuántos pájaros visitaron hoy

- Esta tarea no necesita recursión.
- Acceder al primer elemento de un array se puede hacer con una expresión case.

## 2. Incrementa el conteo de hoy

- Esta tarea no necesita recursión.
- Acceder al primer elemento de un array y al resto del array se puede hacer con una expresión case.

## 3. Verifica si hubo un día sin pájaros visitantes

- Usa recursión para iterar sobre los elementos del array hasta encontrar un día sin pájaros visitantes.
- El caso base es un array vacío.

## 4. Calcula el número total de pájaros visitantes

- Usa recursión para iterar sobre cada elemento del array.
- El caso base es un array vacío.

## 5. Calcula el número de días ocupados

- Usa recursión para iterar sobre cada elemento del array.
- El caso base es un array vacío.
- Usa una guarda para una de las cláusulas de la expresión case.
