# Pruebas

## Ejecutar las pruebas

Para ejecutar las pruebas, ejecuta el siguiente comando:

```bash
bats test-<exercise-slug>.bats
```

### bats está implementado en bash

El archivo de bats es un script de bash, con algunas funciones especiales que reconoce el comando `bats`.
Verás algunas pruebas que se ven así:

```bash
sed -E -f <exercise-slug>.sed <<< "$input"
```

Esa sintaxis `<<<` es un *Here String* de bash.
Envía el string del lado derecho a la entrada estándar del programa del lado izquierdo.
Es más o menos lo mismo que

```bash
echo "$input" | sed -E -f <exercise-slug>.sed
```

## Pruebas omitidas

Resolver un ejercicio significa hacer que todas sus pruebas pasen.
De forma predeterminada, solo se ejecuta una prueba (la primera) cuando ejecutas las pruebas.
Esto es intencional, ya que te permite concentrarte solo en hacer que esa prueba pase.
Una vez que pase, puedes habilitar la siguiente prueba comentando o eliminando las

    [[ $BATS_RUN_SKIPPED == true ]] || skip

anotaciones que anteceden a las demás pruebas.

## Anular las omisiones

Para ejecutar todas las pruebas, incluidas las que tienen anotaciones `skip`, puedes ejecutar:

```bash
BATS_RUN_SKIPPED=true bats test-<exercise-slug>.bats
```

o puedes comentar o eliminar la línea:

```bash
[[ $BATS_RUN_SKIPPED == "true" ]] || skip
```

del archivo de pruebas.
