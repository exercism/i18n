# Acerca de

Las cadenas de F# son objetos inmutables que representan texto como una secuencia de caracteres Unicode (letras, dígitos, signos de puntuación, etc.). Las comillas dobles se usan para definir una instancia de `string`:

```fsharp
let fruit = "Apple"
```

Puedes manipular un string llamando a uno de sus [métodos][methods] o [propiedades][properties], o usando una de las funciones del [módulo `String`][string-module]. Como los valores de tipo string nunca cambian después de haberse definido, todos los métodos y funciones de manipulación de strings devuelven un string nuevo.

Un string se delimita con comillas dobles (`"`). Algunos caracteres especiales necesitan [escaparse][escaping] con el carácter de barra invertida (`\`). También puedes prefijar los strings con el símbolo arroba (`@`), lo que los convierte en un [string textual][verbatim] que ignora cualquier carácter escapado.

```fsharp
let escaped = "c:\\test.txt"
let verbatim = @"c:\test.txt"
escaped = verbatim
// => true
```

Como alternativa, puedes definir strings con [comillas triples][triple-quoted] (`"""`), lo que permite usar una comilla doble dentro del string sin escaparla.

```fsharp
let tripledQuoted = """<movie title="Se7en" />"""
// => "<movie title="Se7en" />
```

Por último, puedes concatenar strings con el [operador `+`][plus-operator]:

```fsharp
let name = "Jane"
"Hello " + name + "!"
// => "Hello Jane!"
```
