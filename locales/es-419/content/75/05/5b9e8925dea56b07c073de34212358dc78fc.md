# Instrucciones

Arma una cadena de dominó.

Calcula una forma de ordenar un conjunto dado de fichas de dominó para que formen una cadena de dominó correcta.
En la cadena, los puntos de una mitad de una ficha deben coincidir con los puntos de la mitad vecina de una ficha adyacente.
Además, los puntos de las mitades de las fichas que no tienen vecinos (la primera y la última ficha) deben coincidir entre sí.

Por ejemplo, dadas las fichas `[2|1]`, `[2|3]` y `[1|3]`, debes calcular algo
como `[1|2] [2|3] [3|1]` o `[3|2] [2|1] [1|3]` o `[1|3] [3|2] [2|1]`, etc., donde el primer y el último número son iguales.

Para las fichas `[1|2]`, `[4|1]` y `[2|3]` la cadena resultante no es válida: el primer y el último número de `[4|1] [1|2] [2|3]` no son iguales.
4 != 3

Es posible que algunos casos de prueba usen fichas duplicadas en la solución de una cadena; asume que se están usando varios juegos de dominó.
