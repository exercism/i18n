# Instrucciones

Conda Airlines es la aerolínea más grande del mundo de la programación, ¡con más de 10,000 vuelos al día!

Actualmente asignan todos los asientos a los pasajeros a mano; esto tendrá que automatizarse.

Te han pedido _a ti_ que crees software para automatizar la asignación de asientos a los pasajeros.
Requieren que tu software sea eficiente en memoria y con buen rendimiento.

## 1. Genera las letras de los asientos

Conda quiere generar las letras de los asientos de sus aviones.
Un avión está hecho de filas de asientos.
Cada fila tiene _4 asientos_.
Los asientos de cada fila siempre se llaman `A`, `B`, `C` y `D`.
El primer asiento de la fila es `A`, el segundo asiento de la fila es `B`, y así sucesivamente.
Después de llegar a `D`, debe empezar de nuevo con `A`.

Implementa una función `generate_seat_letters(<number>)` que acepte un `int` que indique cuántas letras de asiento se van a generar.
La función debe devolver un _iterable_ de letras de asiento.

```python
>>> letters = generate_seat_letters(4)
>>> next(letters)
"A"
>>> next(letters)
"B"
```

## 2. Genera los asientos

Conda quiere un sistema que pueda generar una cantidad determinada de asientos para sus aviones.
Cada avión tiene _4 asientos_ en cada fila.
Las filas se definen con números, empezando desde `1` y subiendo.
Los asientos deben ordenarse así: `1A`, `1B`, `1C`, `1D`, `2A`, `2B`, `2C`, `2D`, `3A`, `3B`, `3C`, `3D`, ...

Aquí tienes un ejemplo:

|      x      |  1  |  2  |
| :---------: | :-: | :-: |
|     Fila    |  5  | 21  |
| Letra del asiento |  A  |  D  |
|  Resultado  | 5A  | 21D |

Muchas aerolíneas no tienen la _fila_ número 13 en sus vuelos, debido a la superstición de los pasajeros.
Conda Airlines también sigue esta convención, así que asegúrate de _no_ generar asientos para la _fila_ número 13.

Implementa una función `generate_seats(<number>)` que acepte un `int` que indique cuántos asientos se van a generar.
La función debe devolver un _iterable_ con los asientos generados.

```python
>>> seats = generate_seats(10)
>>> next(seats)
"1A"
>>> next(seats)
"1B"
```

## 3. Asigna los asientos a los pasajeros

Ahora que tienes una función que genera asientos, puedes usarla para asignar asientos a los pasajeros.

Implementa una función `assign_seats(<passengers>)` que acepte una `list` con los nombres de los pasajeros.
La función debe devolver un _diccionario_ con `passenger` como _clave_ y `seat_number` como _valor_.

```python
>>> passengers = ['Jerimiah', 'Eric', 'Bethany', 'Byte', 'SqueekyBoots', 'Bob']

>>> assign_seats(passengers)
{'Jerimiah': '1A', 'Eric': '1B', 'Bethany': '1C', 'Byte': '1D', 'SqueekyBoots': '2A', 'Bob': '2B'}
```

## 4. Códigos de los boletos

A Conda Airlines le gustaría tener un código único para cada boleto.
Como son una aerolínea grande, tienen muchos vuelos.
Esto significa que hay varios vuelos con el mismo número de asiento.
Quieren que crees un sistema que formule un boleto único, que sea un string de _12_ caracteres de longitud.

Este código empieza con el `assigned_seat` seguido del `flight_id`.
El resto del código se rellena con `0s`.

Implementa una función `generate_codes(<seat_numbers>, <flight_id>)` que acepte una `list` de `seat_numbers` y un `string` con el número de vuelo.
La función debe devolver un `generator` que produzca un `ticket_number`.

```python
>>> seat_numbers = ['1A', '17D']
>>> flight_id = 'CO1234'
>>> ticket_ids = generate_codes(seat_numbers, flight_id)

>>> next(ticket_ids)
'1ACO12340000'
>>> next(ticket_ids)
'17DCO1234000'
```
