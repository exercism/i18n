# Entry API

La Entry API suele ser la forma más idiomática de manipular el contenido de una estructura de mapa. Sin embargo, de forma poco habitual en Rust, no se ha formalizado como un trait; es solo un conjunto de tipos y métodos que están implementados en los tipos de mapa de la biblioteca estándar.

En esencia, el método `map.entry()` proporciona un `enum`:

```rust
enum Entry {
    Occupied(_),
    Vacant(_),
}
```

Su utilidad proviene de otros métodos implementados en ese enum. Por ejemplo, si quieres obtener y posiblemente modificar el valor de una clave en particular, y el valor por defecto del tipo es adecuado, puedes simplemente hacer:

```rust
// `entry` has type `&mut Value` for the value type of the map
let entry = map.entry(key).or_default();
```

Para aplicaciones como un contador, esto te facilita mucho la vida:

```rust
let counts: HashMap<_, usize> = HashMap::new();
for item in sequence {
    *counts.entry(item).or_default() += 1;
}
```

En caso de que el valor por defecto del tipo no sea adecuado para tu aplicación, puedes proporcionar tu propio valor por defecto constante con `or_insert`, o calcular uno con `or_insert_with`.

En ciertos casos, quizás quieras hacer un cálculo sobre un valor existente antes de cualquier posible inserción. En esos casos, `and_modify` lo permite. Sin embargo, este uso es algo poco frecuente. `and_modify` se usa más comúnmente para evitar la necesidad de desreferenciar:

```rust
map.entry(key).and_modify(|v| *v += 1).or_default();
```

En ocasiones, resulta útil hacer match directamente con la entry. Esto es válido:

```rust
match map.entry(key) {
    Entry::Occupied(occupied) => println!("removed from the map: {:?}", occupied.remove_entry()),
    Entry::Vacant(vacant) => println!("key not present in map: {:?}", vacant.key()),
}
```

Para más información, consulta [`std::collections::hash_map::Entry`](https://doc.rust-lang.org/std/collections/hash_map/enum.Entry.html) y [`std::collections::btree_map::Entry`](https://doc.rust-lang.org/std/collections/btree_map/enum.Entry.html).
