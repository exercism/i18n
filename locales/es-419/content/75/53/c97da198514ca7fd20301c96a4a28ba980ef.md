# Anexo de instrucciones

## Apéndice

~~~~exercism/note
Las instrucciones anteriores se sincronizan con un repositorio compartido para garantizar la consistencia en todos los tracks de lenguajes.
Este apéndice ofrece aclaraciones adicionales o modifica las instrucciones según sea necesario para alinearlas mejor con los objetivos del track de Clojure.
~~~~

Para este ejercicio en el track de Clojure, **asume que tanto la entrada como la salida son vectores**, como indican las pruebas.
Como objetivo adicional, piensa en cómo implementar un enfoque que no use listas para los pasos intermedios.

Es importante no reutilizar funciones integradas de Clojure que ya existen y tienen una funcionalidad similar, ya que hacerlo reduciría el valor de aprendizaje que se busca con este ejercicio.
Algunas funciones clave del espacio de nombres `clojure.core` que debes evitar son `into`, `concat`, `cat`, `lazy-cat`, `mapcat`, `flatten`, `filter`, `filterv`, `remove`, `count`, `map`, `mapv`, `reduce`, `transduce`, `reverse` y `rseq`.

### Objetivos opcionales

El objetivo opcional es para quienes buscan un desafío extra, y está pensado suponiendo que ya completaste el objetivo principal.

Intenta pasar las pruebas ideando un enfoque que suponga lo siguiente:

* Que tanto la entrada como la salida son listas en lugar de vectores.
  Ten en cuenta que, como siempre, no es necesario modificar las pruebas.
* Que no se pueden usar vectores para los pasos intermedios.

Si decides publicar esto, asegúrate de incluir un comentario que indique que resuelve el objetivo opcional de usar listas.
¡No olvides actualizar los docstrings!
