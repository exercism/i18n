# Pistas

## General

- Vuelve a revisar el [concepto de objetos][concept-class-basics] si necesitas repasar lo básico.
- Lee con atención las instrucciones sobre la posición de los parámetros `x`, `y`, `width` y `height`. Es fácil confundirlos.

## 1. Define una clase ProgramWindow

- Recuerda usar la [sintaxis de clases][php-class] para esta tarea.
- Define las [propiedades][php-properties] agregándolas a la declaración de la clase.

## 2. Define una función constructora para la clase ProgramWindow

- Verifica que tu función constructora no acepte ningún argumento.
- Verifica que cada propiedad se esté asignando al valor entero esperado.

## 3. Agrega un método para redimensionar la ventana

- Recuerda usar una nueva [clase][php-class] en el archivo `Size.php` para esta tarea.
  - Por convención, los archivos normalmente solo contienen una única clase.
- El constructor de `Size` debe aceptar argumentos para los valores iniciales de las [propiedades][php-properties] de la clase.
- Crea un método `resize` del objeto `ProgramWindow` para aplicar el cambio usando una instancia de `Size`.

## 4. Agrega un método para mover la ventana

- Recuerda usar una nueva [clase][php-class] en el archivo `Position.php` para esta tarea.
  - Por convención, los archivos normalmente solo contienen una única clase.
- El constructor de `Position` debe aceptar argumentos para los valores iniciales de las [propiedades][php-properties] de la clase.
- Crea un método `move` del objeto `ProgramWindow` para aplicar el cambio usando una instancia de `Position`.
