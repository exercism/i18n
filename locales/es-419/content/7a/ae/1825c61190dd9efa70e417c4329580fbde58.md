# Pruebas

Para ejecutar la suite de pruebas:
```bash
tclsh exercise.test
```

## Pruebas omitidas

Resolver un ejercicio significa lograr que todas sus pruebas pasen. De forma predeterminada, solo se ejecuta una prueba (la primera) cuando las ejecutas. Esto es intencional, ya que te permite concentrarte en lograr que esa única prueba pase. Una vez que pase, puedes habilitar la siguiente prueba comentando o eliminando el comando `skip` que la precede.

También puedes ejecutar todas las pruebas sin importar su estado de «omitidas»:
```bash
RUN_ALL=1 tclsh exercise.test
```
