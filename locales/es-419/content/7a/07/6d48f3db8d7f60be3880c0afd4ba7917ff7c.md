# Pistas

## General

- Un [valor entero][integer-value] se puede definir como uno o más dígitos consecutivos.

## 1. Define el tiempo esperado de horneado en minutos

- Necesitas [definir una constante][constant].

## 2. Calcula el tiempo de horneado restante en minutos

- Necesitas [definir una función][function] con un solo parámetro.
- Puedes usar la constante que definiste antes y referirte a ella por su nombre.
- Puedes usar el [operador matemático de resta][arithmetical-operators] para restar valores.

## 3. Calcula el tiempo de preparación en minutos

- Necesitas [definir una función][function] con un solo parámetro.
- Puedes usar el [operador matemático de multiplicación][arithmetical-operators] para multiplicar valores.

## 4. Calcula el tiempo total de trabajo en minutos

- Necesitas definir [una función con dos parámetros][multiple-parameters].
- Puedes [llamar a una de las otras funciones][function] que definiste antes.
- Puedes usar el [operador matemático de suma][arithmetical-operators] para sumar valores.
