# Introducción

Los hash son un tipo de dato en Perl que contiene una colección no ordenada de claves de string emparejadas con valores escalares.

Por lo general, una variable hash se llena asignándole una lista, por ejemplo: `my %scores = (Alice => 10, Bob => 15, Charlie => 20);`.

Los elementos de una lista se separan normalmente con comas, pero es común ver lo que se conoce como la «coma gorda» (`=>`) para separar claves y valores dentro de una lista.
Su comportamiento es casi idéntico al de una coma, pero tiene la ventaja adicional de interpretar el elemento de la izquierda como un string.

Los hash también se pueden llenar asignando a claves individuales, por ejemplo: `$scores{Alice} = 10;`.

Se puede acceder a los valores de un hash especificando claves mediante un subíndice, por ejemplo: `$scores{Bob} # 15`.

Las claves de un hash son únicas.
Si una clave aparece varias veces, solo se conserva el último valor que se le asigne.

## Funciones

Entre las funciones para trabajar con hash están [keys][keys] y [values][values], que permiten obtener esas partes de un hash como una lista.
Las listas que devuelven las funciones [keys][keys] y [values][values] pueden ser útiles para funciones de listas como [grep][grep], [map][map] y [sort][sort], así como para bucles [for][for].

Otras funciones para hash incluyen [exists][exists], que verifica si una clave existe en un hash (incluso si su valor es `undef`), y [delete][delete], que elimina una clave de un hash.

## Variación del sigilo

Cuando obtienes valores de un hash, el sigilo que uses determina el resultado.
El subíndice `{}` al final del nombre de la variable es lo que le indica a Perl que estás accediendo a un hash con ese nombre.

```perl
my %names = (Alice => 10, Bob => 15, Charlie => 20);

$names{Alice}; # 10            <- A scalar
@names{Alice}; # (10)          <- A slice (with only one key, this probably isn't what you want. There will be a warning.)
%names{Alice}; # ('Alice', 10) <- A key/index + value slice

$names{'Bob', 'Charlie'}; #                            <- An error (disabled syntax for an ancient feature.)
@names{'Bob', 'Charlie'}; # (15, 20)                   <- A slice
%names{'Bob', 'Charlie'}; # ('Bob', 15, 'Charlie', 20) <- A key/index + value slice
```

Aunque está permitido, por legibilidad se recomienda no hacer que distintos tipos de variables compartan el mismo nombre.
