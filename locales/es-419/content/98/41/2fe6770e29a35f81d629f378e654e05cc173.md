# Constructores de strings

Un `STR` nunca cambia. Así que `+` no puede agregarle nada: tiene que crear un
string nuevo con el contenido de ambos.

Eso está bien una vez. Dentro de un bucle, no:

```sather
   -- don't
   script ::= "";
   loop
      script := script + lines.elt!;
   end;
```

En cada vuelta se copia todo lo construido hasta ese momento a un string nuevo
y se desecha el anterior. Diez líneas son diez copias, cada una más larga que
la anterior. Cien líneas son cien copias. El trabajo crece con el *cuadrado*
del número de líneas, y un bucle que parece inofensivo se vuelve la parte
lenta del programa.

## FSTR

`FSTR` es un string que *sí* se puede cambiar: un **constructor de strings**.
Agregarle contenido normalmente solo escribe en el espacio que ya tiene, así
que un bucle de cien líneas hace más o menos el trabajo de cien líneas en vez
de cien copias.

```sather
   script ::= #FSTR;
   loop
      script := script + lines.elt!;
   end;
   return script.str;
```

Tres cosas a las que prestar atención.

**`#FSTR` crea uno vacío.** `#FSTR(100)` crea uno con espacio ya reservado
para cien caracteres, algo que vale la pena hacer cuando se conoce el tamaño.

**Debes volver a asignar el resultado.** `script := script + ...`, nunca
`script + ...` por sí solo. Normalmente el resultado es el mismo constructor
con el que empezaste, pero cuando se le acaba el espacio es uno nuevo y más
grande, y si descartas el resultado terminarías escribiendo en el viejo.

**`.str` al final.** Una rutina que promete `: STR` tiene que devolver un
`STR`, y `.str` crea uno a partir del constructor.

## Qué se puede agregar

El `+` sobre un `FSTR` acepta un string, un carácter, un número entero o un
boolean, así que normalmente no hace falta convertir antes:

```sather
   line ::= #FSTR;
   line := line + 1 + ". " + "Enter" + '!';   -- "1. Enter!"
```

## Líneas nuevas

`"\n"` dentro de un string es una línea nueva: un solo carácter, escrito con
dos.

```sather
   script := script + "Enter" + "\n" + "Exit";
```
