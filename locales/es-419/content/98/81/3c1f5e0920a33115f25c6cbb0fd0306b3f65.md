# Anexo de instrucciones

## Palabras

Define una tupla `custom-set` y declárala como una instancia del mixin `set` con `INSTANCE: custom-set set`.

- `<custom-set> ( -- set )`: crea un conjunto vacío.
- `>custom-set ( seq -- set )`: construye un conjunto a partir de una secuencia y descarta los duplicados en silencio.

Después, define métodos `M:` (de `sets`) para `members`, `in?`, `adjoin` y `set-like` en `custom-set`. Con la declaración `INSTANCE:` y esos cuatro métodos en su lugar, `null?`, `union`, `intersect`, `diff`, `subset?`, `set=` e `intersects?` del vocabulario `sets` funcionan sobre tu conjunto a través de las implementaciones predeterminadas del protocolo: los tests llaman directamente a esas palabras.

`adjoin ( elt set -- )` es mutante: agrega `elt` a `set` en el mismo lugar si aún no está presente.
