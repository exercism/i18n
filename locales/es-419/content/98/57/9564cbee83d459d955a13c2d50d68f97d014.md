# Pistas

## 1. Define la aprobación

- Los tipos personalizados se pueden definir con la sintaxis `pub type Name { Variant1 }`.

## 4. Define la actividad

- Los tipos personalizados que contienen datos se pueden definir con la sintaxis `pub type Name { Variant1(SomeType) }`.

## 5. Califica la actividad

- Se puede hacer coincidencia de patrones sobre las variantes de un tipo personalizado usando expresiones case.
- Si quieres agregar una condición adicional a un patrón, puedes agregar un guard al patrón usando la palabra clave `if`.
