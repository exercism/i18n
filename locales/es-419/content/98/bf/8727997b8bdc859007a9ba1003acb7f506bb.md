# Instrucciones

En este ejercicio, vas a escribir algo de código que te ayude a prepararte para comprar un vehículo.

Tienes tres tareas: una para determinar si necesitas una licencia, otra para ayudarte a elegir entre dos vehículos y otra para estimar el precio aceptable de un vehículo usado.

## 1. Determina si vas a necesitar una licencia de conducir

Algunos tipos de vehículo requieren una licencia de conducir para manejarlos.
Supón que solo los tipos `"car"` y `"truck"` requieren licencia; todo lo demás se puede manejar sin licencia.

Implementa la función `needsLicense(kind)` que recibe el tipo de vehículo y devuelve un boolean que indica si necesitas una licencia para ese tipo de vehículo.

```kotlin
needsLicense("car")
// => true

needsLicense("bike")
// => false

needsLicense("truck")
// => true
```

## 2. Elige entre dos posibles vehículos para comprar

Evalúas tus opciones de vehículos disponibles.
Logras reducirlas a dos opciones, pero necesitas ayuda para tomar la decisión final.
Para eso, implementa la función `chooseVehicle(option1, option2)` que recibe dos vehículos como argumentos y devuelve una decisión que incluye la opción que aparece primero en el [orden lexicográfico][lexicographical-order].

```kotlin
chooseVehicle("Wuling Hongguang", "Toyota Corolla")
// => "Toyota Corolla is clearly the better choice."

chooseVehicle("Volkswagen Beetle", "Volkswagen Golf")
// => "Volkswagen Beetle is clearly the better choice."
```

## 3. Calcula una estimación del precio de un vehículo usado

Ahora que tomaste una decisión, quieres asegurarte de que obtengas un precio justo en la concesionaria.
Como te interesa comprar un vehículo usado, el precio depende de qué tan viejo sea el vehículo.
Para una estimación aproximada, supón que si el vehículo tiene menos de 3 años, cuesta el 80 % del precio original que tenía cuando era nuevo.
Si tiene al menos 10 años, cuesta el 50 %.
Si el vehículo tiene al menos 3 años pero menos de 10, cuesta el 70 % del precio original.

Implementa la función `calculateResellPrice(originalPrice, age)` que aplica esta lógica usando `if`, `else if` y `else` (hay otras formas si quieres practicar).
Recibe el precio original y la edad del vehículo como argumentos y devuelve el precio estimado en la concesionaria.

```kotlin
calculateResellPrice(1000, 1)
// => 800

calculateResellPrice(1000, 5)
// => 700

calculateResellPrice(1000, 15)
// => 500
```

[lexicographical-order]: https://en.wikipedia.org/wiki/Lexicographic_order
