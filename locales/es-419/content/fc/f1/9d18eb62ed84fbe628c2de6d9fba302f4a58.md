# Instrucciones

Cada rutina que presenta la compañía de baile se construye sobre el mismo calentamiento y después sigue su propio camino.

El stub te da `WARM_UP`. Escribe tres clases más debajo de él.

## 1. La rutina de jazz

`JAZZ_ROUTINE` toma todo de `WARM_UP` sin cambios y no añade nada.

```sather
JAZZ_ROUTINE::counts
-- => 8
JAZZ_ROUTINE::describe
-- => "8 counts"
```

## 2. La rutina de tap

`TAP_ROUTINE` toma `counts` de `WARM_UP`, pero se describe a su propia manera. Deja `describe` fuera del include y escribe uno nuevo.

```sather
TAP_ROUTINE::counts
-- => 8
TAP_ROUTINE::describe
-- => "Tap: 8 counts"
```

## 3. El final

`FINALE` toma `counts` de `WARM_UP` con el nombre `warm_up_counts` y deja `describe` fuera. Después tiene su propio `counts`, que es el doble del del calentamiento, y su propio `describe`.

```sather
FINALE::warm_up_counts
-- => 8
FINALE::counts
-- => 16
FINALE::describe
-- => "Finale: 16 counts"
```

Fíjate en lo que esto muestra: `FINALE::counts` no es `WARM_UP::counts`, y ambos están disponibles con nombres distintos en la misma clase.
