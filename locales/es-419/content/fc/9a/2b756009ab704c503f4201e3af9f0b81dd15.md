# Introducción

## Caracteres

El tipo `char` de C# es una cantidad de 16 bits que representa los componentes de texto más pequeños direccionables.
Varios `char` pueden componer un string como `"word"`, o los `char` se pueden
procesar de forma independiente. Sus literales se escriben entre comillas simples, por ejemplo `'A'`.

Los `char` de C# admiten la codificación Unicode UTF-16, así que, además del conjunto de caracteres
latinos, se puede representar prácticamente cualquier sistema de escritura que se use en el mundo,
por ejemplo la letra griega `'β'`.

Hay muchos métodos de biblioteca integrados para inspeccionar y manipular `char`. Los
encontrarás como métodos estáticos de la clase `System.Char`.

## Constructor de strings

A veces los `char` se usan junto con un objeto `StringBuilder`.
Este objeto tiene métodos que permiten construir un string
carácter por carácter y manipularlo. Al final del proceso
se puede llamar a `ToString` para obtener un string completo.
