# Pistas

## General

- Para extraer múltiples argumentos en los parámetros de la función, puedes empaquetarlos con `...<args>`.
- Para usar rest y spread, usa el operador `...`.

## 1. Crea una lista de todos los vagones

- Los múltiples argumentos en los parámetros de la función se pueden empaquetar con la [sintaxis `...<args>` (spread)][spread-syntax].

## 2. Mueve los dos primeros elementos al final del array

- Puedes desempaquetar una serie de parámetros usando [una asignación por desestructuración (`...`)][destructuring-assignment].
  Esto te permite extraer los dos primeros elementos de un `array` mientras mantienes el resto intacto.
- Para agregar otro `array` dentro de un `array` existente, puedes usar el operador `...` para «spread» el `array`.

## 3. Agrega los valores que faltan

- Usando el desempaquetado con el operador rest (`...`), puedes extraer el primer elemento de un `array` mientras mantienes el resto intacto.
- Para agregar otro `array` dentro de un `array` existente, puedes usar el operador `...` para «spread» el `array`.

## 4. Extiende la información de enrutamiento

- Para agregar otro `object` dentro de un `object` existente, puedes usar el operador `...` para «spread» el `object`.

## 5. Separa la hora de llegada de la información de enrutamiento

- Para extraer un valor de un `object` mientras mantienes el resto intacto, puedes usar el operador rest (`...`).
