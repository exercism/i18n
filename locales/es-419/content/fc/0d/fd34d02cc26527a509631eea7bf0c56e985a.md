# Caracteres

Un **carácter** es una sola letra, dígito, espacio o marca. El tipo de Sather para
uno es `CHAR`, y un carácter se escribe entre comillas simples.

```sather
   initial : CHAR is
      return 'M';
   end;
```

Comillas simples para un carácter, comillas dobles para un string. `'M'` y
`"M"` son tipos distintos y no se pueden intercambiar.

## Caracteres a partir de un string

Un string es una fila de caracteres, y los corchetes alcanzan uno por posición,
contando desde cero, igual que en un array.

```sather
"Marlowe"[0]      -- 'M'
"Marlowe"[3]      -- 'l'
```

## Preguntar sobre un carácter

| Llamada | Respuestas |
| --- | --- |
| `c.is_alpha` | ¿es una letra? |
| `c.is_digit` | ¿es uno de `0`–`9`? |
| `c.is_upper` | ¿es una mayúscula? |
| `c.is_lower` | ¿es una minúscula? |

Cada una responde `true` o `false`.

```sather
'M'.is_alpha      -- true
'7'.is_alpha      -- false
'7'.is_digit      -- true
```

## Cambiar entre mayúsculas y minúsculas

`.upper` da la mayúscula de una letra, y `.lower` la minúscula.
Todo lo que no sea una letra se devuelve sin cambios.

```sather
'm'.upper         -- 'M'
'M'.lower         -- 'm'
'7'.upper         -- '7'
```

## Caracteres como números

Cada carácter tiene un número. `.int` lo da, y `.char` convierte un número
de vuelta en un carácter.

```sather
'a'.int           -- 97
'b'.int           -- 98
98.char           -- 'b'
```

Los números exactos rara vez importan. Lo que importa es que las letras `a` a
`z` estén en orden y una junto a otra, así que `'c'.int - 'a'.int` es 2, es
decir, qué tan avanzada está la `c` en el alfabeto. Eso es lo que hace
funcionar una rueda de cifrado.
