# Usa funciones con múltiples cláusulas

[comment]: # (La intención detrás de este comentario es decirle a la gente que use funciones con múltiples cláusulas, pero como es muy difícil escribir un buen análisis para eso, en su lugar comprueba si se usan if, case y cond)

El propósito de este ejercicio es enseñar las funciones con múltiples cláusulas. Resuélvelo sin usar `if`, `case` ni `cond`. En su lugar, define varias cláusulas de la función `compare`.
