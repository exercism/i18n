# Pistas

**Recuerda**: Las pruebas de este ejercicio son indiferentes a si mutas los datos, pero los nombres de las funciones indican que estas no deberían mutar.
Si quieres usar funciones de la introducción sin mutar el argumento, la función `copy()` te será útil.

## 1. Crea un inventario a partir de un vector

- Puede ayudarte mirar la tarea 2 antes de empezar con esta.

## 2. Agrega elementos de un vector a un diccionario existente

- Lo más sencillo es recorrer el vector que recibes elemento por elemento.
- La función [`haskey(dict, key)`][haskey] te será útil.

## 3. Decrementa elementos del inventario

- El código es muy similar al de la tarea 2, con un cambio de signo.
- Recuerda no dejar que la cantidad de elementos baje de cero.
- La lógica `if...else` funciona, pero la función [`max()`][max] permite escribir un código conciso e idiomático.

## 4. Elimina por completo una entrada del inventario

- Julia tiene una función que hace exactamente esto: lee la Introducción.

## 5. Devuelve todo el contenido del inventario

- Recuerda eliminar los elementos cuya cantidad sea cero.
- A quienes recién empiezan les puede resultar más fácil recorrer los elementos y usar [`push!()`][push] cuando corresponda.
- Una comprensión de listas al estilo de Python es mucho más concisa, y se permite agregar una cláusula `if` al final.
- Aunque requiere conocer conceptos posteriores, quienes ya conozcan la programación funcional quizá quieran explorar la función [`filter()`][filter].
- Se requiere que el resultado esté ordenado, y [`sort()`][sort] por defecto ordena por la primera parte de un par.
