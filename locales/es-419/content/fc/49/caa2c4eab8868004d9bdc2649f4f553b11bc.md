# Pistas

## General

- Cada archivo empieza con una línea `USING:` que enumera los vocabularios
  de los que toma prestado, y una línea `IN:` que declara su propio
  vocabulario. El nombre que va después de `IN:` debe coincidir con la ruta
  del archivo dentro de la raíz del ejercicio: `bosuns-briefing.helpers` para
  `helpers/helpers.factor`, `bosuns-briefing` para el archivo principal.
- Siempre que llames a una palabra de otro vocabulario, agrega ese
  vocabulario a la línea `USING:`.

## 1. `greeting`

- `greeting` no recibe nada y devuelve un string literal. El
  cuerpo es solo ese string literal.

## 2. `crew-line`

- `prepend` (en `sequences`) toma `( seq1 seq2 -- newseq )` y
  devuelve `seq2` seguido de `seq1`. Así,
  `"Lopez" "  - " prepend` produce `"  - Lopez"`.

## 3. `closing`

- Tiene la misma forma que `greeting`.

## 4. `roster`

- `[ crew-line ] map` (de `sequences`) aplica `crew-line` a
  cada elemento del array que recibe, y devuelve un array de
  strings con formato.
- `"\n" join` (de `splitting`) concatena un array de strings,
  e inserta `"\n"` entre cada par.

## 5. `briefing`

- El resultado son tres strings unidos por `"\n"`: el saludo, la
  lista de los nombres recibidos y el cierre.
- `3array` (de `arrays`) agrupa los tres valores en un solo
  array, listo para `"\n" join`.
- Usa `[ greeting ] dip` para colocar el saludo *por debajo* de
  los nombres que ya están en la pila, luego ejecuta `roster`
  sobre los nombres y `closing` después. Así quedan tres strings
  listos para `3array`.
