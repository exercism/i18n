# Depurar

Cuando una prueba falla, se muestra un mensaje que describe qué salió mal y con qué argumento.

Imprimir los valores y el contenido de las variables también puede ayudarte a entender qué pasa.
PHP puede imprimir valores con:

- `echo 'Debug message';` para imprimir un string de tu elección
- `var_dump($variable);` para obtener más información sobre un valor, por ejemplo, el tipo que PHP ve
