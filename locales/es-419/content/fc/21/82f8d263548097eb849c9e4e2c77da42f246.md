# Instrucciones

Estamos creando un club del queso, que usará aprendizaje automático para seleccionar nuevos quesos que ofrecer a nuestros clientes amantes del queso, según sus historiales y gustos.

Los nuevos miembros deben completar una encuesta inicial para que podamos reunir algunos datos básicos con los que empezar.
A partir de esto, se ha descubierto que hay un subconjunto de clientes enfáticos que carecen de matices en sus críticas.
Como esto puede llegar a sesgar de forma irrevocable un algoritmo más matizado, hay un algoritmo aparte configurado para atender sus necesidades.
Se te pide que proporciones algunas funciones auxiliares para manejar sus datos.

~~~~exercism/note
Aunque puede haber distintas formas de resolver las siguientes tareas, cada una se puede resolver con no más de dos funciones de orden superior.
~~~~

## 1. Clasifica a los clientes

El sistema de calificaciones tiene una base de cinco estrellas, que simplemente consiste en los números enteros `1:5`.
Los clientes enfáticos solo darán calificaciones de `1` o `5`, y queremos saber si un cliente muestra este comportamiento.

Implementa `all_15()`, que recibe un vector de calificaciones y devuelve `true` si todas las calificaciones son `1` o `5`, y false en caso contrario.

```R
all_15(c(2, 3, 4, 4, 1))
#> [1] FALSE

all_15(c(1, 5, 5, 1, 5))
#> [1] TRUE
```

## 2. Nombra a los clientes

Necesitamos asociar el nombre del cliente (o su ID) con sus calificaciones.

Implementa `name_customers()`, que recibe un vector de nombres y una lista de calificaciones, y los «combina» en una lista de listas.

Los elementos de las listas internas deben tener los nombres `name` y `rating`.

```R
names <- c("c1", "c2")
ratings <- list(c(2, 3, 5), c(1, 1, 5))
name_customers(names, ratings)
#> [[1]]
#> [[1]]$name
#> [1] "c1"

#> [[1]]$rating
#> [1] 2 3 5

#> [[2]]
#> [[2]]$name
#> [1] "c2"

#> [[2]]$rating
#> [1] 1 1 5
```

## 3. Separa a los clientes enfáticos

Necesitamos separar a los clientes más enfáticos de los demás.

Implementa `emphatics()`, que recibe clientes y calificaciones.
Devuelve una lista restringida a quienes solo usan calificaciones de `1` o `5` estrellas.`

```R
# names and ratings as in the task 2 example

emphatics(names, ratings)
#> [[1]]
#> [[1]]$name
#> [1] "c2"

#> [[1]]$rating
#> [1] 1 1 5
```

## 4. Convierte las calificaciones a binario

Como los clientes enfáticos solo usan calificaciones de `1` y `5`, será más conveniente desde el punto de vista computacional cambiarlas a `0` y `1`.

Implementa `to_binary()`, que recibe un vector de calificaciones enfáticas.
Devuelve las calificaciones en binario, donde `1` se ha cambiado a `0` y `5` se ha cambiado a `1`.

```R
to_binary(c(1, 1, 5, 5, 1))
#> [1] 0 0 1 1 0
```

## 5. Calcula el promedio de calificaciones a lo largo del tiempo

Quieres seguir mejorando las recomendaciones para cada cliente (no solo para los enfáticos) con el tiempo, a medida que entiendes mejor sus gustos.

Implementa `satisfactions()`, que recibe un vector de calificaciones.
Devuelve un vector de promedios acumulados hasta ese punto.
Redondea los resultados a 2 decimales.

¡Ojalá los números sigan creciendo, para tener clientes felices!

```R
satisfactions(c(1, 2, 2, 3))
#> [1] 1.00 1.50 1.67 2.00
```
