# Introducción

La sentencia `guard` de Swift se usa para hacer retornos anticipados desde funciones de Swift cuando no se cumple una condición necesaria que debe cumplirse para que continúe el procesamiento, por ejemplo:

```swift
guard myValue >= 0 else { return 0 }
let root = myValue.squareRoot()
```

Aquí, `guard` verifica si la expresión de tipo Boolean que sigue a la palabra clave `guard` se evalúa como true. Si es así, el procesamiento continúa con el código que sigue a la sentencia `guard` (aquí `let root = myValue.squareRoot()`). De lo contrario, se ejecutará el código de la cláusula else. A diferencia de una sentencia `if`, una sentencia `guard` _debe_ tener una cláusula else y, a diferencia de la cláusula else de un if-else, la cláusula else de un `guard` _debe_ salir del ámbito de la sentencia `guard`. Es decir, debe usar una sentencia de transferencia de control como `return`, `continue` o `break`, o bien lanzar un error o salir del programa.
