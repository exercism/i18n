# Juego de adivinar números

## Historia

En este ejercicio, juegas a un juego de adivinar números con un amigo. Las reglas son sencillas: eliges en secreto un número entre `1` y `100` y tu amigo intenta adivinar qué número elegiste. Para ayudar a tu amigo, respondes de forma diferente según qué tan cerca estuvo el intento del número que elegiste (`42`). Estas son las reglas para las distintas respuestas:

- Si el intento es `42`: «Correct»
- Si el intento es `41` o `43`: «So close»
- Si el intento es menor que `41`: «Too low»
- Si el intento es mayor que `43`: «Too high»

## Tareas

Estas son tareas de ejemplo que encajan con el ejercicio del juego de adivinar números:

- Responder a un intento correcto
- Responder a un intento cercano
- Responder a intentos demasiado bajos
- Responder a intentos demasiado altos
