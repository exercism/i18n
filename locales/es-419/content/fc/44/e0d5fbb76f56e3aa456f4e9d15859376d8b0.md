# Acerca de

[Groovy](http://www.groovy-lang.org/) es el lenguaje dinámico y potente de la Apache Foundation, con tipado opcional, que además tiene capacidades de tipado estático y compilación estática.

Groovy busca mejorar la productividad de los desarrolladores gracias a una sintaxis concisa y fácil de aprender.
Facilita la creación de scripts, la escritura de lenguajes específicos de dominio, la metaprogramación en tiempo de ejecución y en tiempo de compilación, y la programación funcional.

Permite acceder a todo el ecosistema de bibliotecas de Java y se integra sin problemas con aplicaciones Java.

Se puede usar como un lenguaje de scripting sencillo o incorporar a frameworks de Java complicados. 
Impulsa tecnologías como: 
* Gradle, 
* Spock, 
* Ratpack, 
* Grails, 
* y el uso de scripts en Jenkins.

Además, es divertido.
