# Descripción

Un triplete pitagórico es un conjunto de tres números naturales, {a, b, c}, para el que

```text
a² + b² = c²
```

y tal que

```text
a < b < c
```

Por ejemplo,

```text
3² + 4² = 5².
```

Dado un número entero de entrada N, encuentra todos los tripletes pitagóricos para los que `a + b + c = N`.

Por ejemplo, con N = 1000, hay exactamente un triplete pitagórico para el que `a + b + c = 1000`: `{200, 375, 425}`.
