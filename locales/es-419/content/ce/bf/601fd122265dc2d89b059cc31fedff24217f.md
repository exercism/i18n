# Introduction

Un `String` en Haxe es un objeto que representa texto inmutable como una secuencia de caracteres Unicode (letras, dígitos, signos de puntuación, etc.). Para definir una instancia de `String` se usan comillas dobles:

```haxe
var fruit:String = "Apple";
```

Los strings se manipulan llamando a los métodos del string. Una vez que se ha construido un string, su valor nunca puede cambiar. Cualquier método que parezca modificar un string en realidad devolverá un string nuevo.

Se pueden concatenar (sumar) varios strings entre sí. La forma más sencilla de lograrlo es usar el operador `+`.

```haxe
var name:String = "Jane";
trace("Hello " + name + "!");
// => "Hello Jane!"
```

Para cualquier formato de string más complejo que una simple concatenación, es preferible la interpolación de strings. Para usar interpolación en un string, enciérralo entre comillas simples (`'`). Luego puedes usar el signo de dólar (`$`) para activar la interpolación:

```haxe
var name:String = "Jane";
trace('Hello $name!');
// => "Hello Jane!"
```
