# Introducción

Hacer malabares con la pila está bien para palabras cortas. Cuando una palabra tiene varios
argumentos y necesitas referirte a ellos por su nombre, Factor ofrece
*locals*, enlaces con nombre que se introducen con `::` (para
definiciones de palabras) o `[| | ]` (para lambdas en línea), ambos de
[`locals`][locals].

```factor
USING: locals ;

:: hypotenuse ( a b -- c )
    a a *
    b b *
    + sqrt ;
```

Dentro de una quotation, `[| inputs | body ]` es una lambda con
argumentos con nombre:

```factor
USING: assocs locals ;

H{ { "a" 1 } { "b" 2 } }
[| key value | key value 10 * ] assoc-map .
! => H{ { "a" 10 } { "b" 20 } }
```

[locals]: https://docs.factorcode.org/content/vocab-locals.html
