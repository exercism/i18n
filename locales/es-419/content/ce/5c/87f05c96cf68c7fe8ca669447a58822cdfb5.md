# Introducción

El sistema de errores de Factor tiene tres piezas: `throw` (en [`kernel`][kernel]) lanza un error, `recover` (en [`continuations`][continuations]) atrapa uno, y `ERROR:` define una clase de error de tipo tupla.

```factor
! "file not found" throw          (raises a string as the error)

[ "boom" throw ] [ drop "caught" ] recover .
! => "caught"
```

`recover ( try recovery -- )` ejecuta la quotation *try*; si esta lanza un error, se apila el error y se ejecuta la quotation *recovery*.

`ERROR:` declara tanto la clase *como* una palabra constructora que lanza una instancia nueva:

```factor
! DOCTEST: SKIP
ERROR: not-found path ;

"/missing" not-found
! throws T{ not-found { path "/missing" } }
```

[continuations]: https://docs.factorcode.org/content/vocab-continuations.html
