# Acerca de las funciones de orden superior

Las funciones en Kotlin son ciudadanos de primera clase.
Esto significa que se pueden guardar en variables, pasar como argumentos e incluso devolver desde otras funciones.
Por ejemplo, asignar una función a la variable `addOne`:

```kotlin
val addOne = fun (num : Int) : Int {
    return num + 1
}
```

Una función también puede devolver otra función:

```kotlin
fun makeAddOne() : (Int) -> Int {
    return fun(num : Int) : Int {
        return num + 1
    }
}
```

Una vez asignada, puedes llamar a la función a través de la variable como si fuera cualquier otra función:
```kotlin
addOne(3)
// => 4
```

## Declarar tipos de función

Puedes declarar el tipo de una variable o de un parámetro con la sintaxis `(parameter types) -> return type`.
Por ejemplo, para declarar una variable:

```kotlin
val addOne : (Int) -> Int = fun (num : Int) : Int {
    return num + 1
}
```

Y para el parámetro de una función:

```kotlin
fun perform(operation : (Int) -> Int) {
    operation(3)
}
```

## Expresiones lambda

Una expresión lambda es una forma más corta de definir una función.
Se escriben con la forma `{ parameters -> body }`.
La expresión devuelve el último valor de la última sentencia del cuerpo.
Por ejemplo:

```kotlin
// Assigning to a variable
val addOne = { num : Int -> num +  1}

// In a function call
perform({ num : Int -> num + 1 })
```

Kotlin puede inferir los tipos cuando hay suficiente información.
Por ejemplo, los ejemplos anteriores también se pueden escribir así:

```kotlin
// Assigning to a variable
val addOne : (Int) -> Int = { num -> num + 1 }

// Or ...
val addOne  = { num : Int -> num + 1 }

// Using in a function
perform({ num -> num + 1 })
```

## `it` para lambdas de un solo parámetro

Cuando la expresión tiene un solo parámetro, puedes omitirlo.
Entonces Kotlin pone a tu disposición un parámetro llamado `it` en el cuerpo.
Por ejemplo:

```kotlin
val addOne : (Int) -> Int = { it +  1 }
```

## Pasar lambdas al final

Cuando el último argumento de una función es una lambda, la expresión lambda se escribe directamente _después_ de los paréntesis.
Por ejemplo:

```kotlin
// Function that takes a function as last argument
fun calculateFrom(from : Int, operation : (Int) -> Int) : Int {
    return operation(from)
}

// Call the calculateFrom function
calculateFrom(2) { it * 3 }
// => 6
```
