# Pistas

## 1. Analiza la fecha de la cita

- La clase `LocalDateTime` tiene un método para [analizar][localdatetime-parse] un `String` y convertirlo en un `LocalDateTime`.
- Usa un [`DateTimeFormatter`][datetimeformatter-docs] con un patrón personalizado para analizar un formato de fecha y hora no estándar.

## 2. Verifica si una cita ya pasó

- Las instancias de `LocalDateTime` tienen [métodos][localdatetime-methods] para compararlas con otras `LocalDateTime`.
- Hay un [método][localdatetime-methods] para obtener la fecha y la hora actuales.

## 3. Verifica si la cita es por la tarde

- Se puede acceder a la parte correspondiente a la hora de una instancia de `LocalDateTime` mediante uno de sus [métodos][localdatetime-methods].

## 4. Describe la hora y la fecha de la cita

- Usa un [`DateTimeFormatter`][datetimeformatter-docs] con un patrón personalizado para dar formato al `LocalDateTime`.
- Las pruebas se ejecutan como si se ejecutaran en una máquina en Estados Unidos, así que asegúrate de que el formateador [use la configuración regional correcta][datetimeformatter-ofpattern-with-locale].

## 5. Devuelve la fecha del aniversario

- La clase `LocalDate` tiene un [método][localdate-methods] para obtener la fecha actual.
- Se puede acceder al año de una instancia de `LocalDate` mediante uno de sus [métodos][localdate-methods].
