# API de Exercism

## Descripción

La mayoría de los tracks de lenguajes de Exercism usan la herramienta de línea de comandos `exercism` para obtener y enviar ejercicios, la cual se comunica con `exercism.io` mediante una API REST. El track del lenguaje Pharo Smalltalk, en cambio, usa esa misma API REST para meter y sacar ejercicios de la imagen de Pharo sin necesidad de ninguna herramienta intermedia. Este documento detalla la API de Exercism y se centra en cómo la usa el track del lenguaje Pharo Smalltalk. Está dirigido a quienes mantienen las herramientas de Pharo Smalltalk.

## Encabezados

Todos los endpoints requieren que los encabezados de la solicitud tengan los siguientes valores:

```
Authorization: Bearer <token>
```

El valor `<token>` es el token de autenticación de la CLI del usuario, disponible en `https://exercism.io/my/settings`.

## Obtener ejercicios

```
Content-Type: application/json
```

`GET api.exercism.io/v1/solutions/latest?exercise_id=<slug>&track_id<language> HTTP/1.1`

En la URL anterior, `<slug>` es el nombre del ejercicio, por ejemplo `hello-world`, y `<language>` es el track del lenguaje, por ejemplo `pharo-smalltalk`.

### Respuesta

#### 200

Una solicitud exitosa enviará una respuesta que contiene un payload en JSON. Dentro del JSON encontrarás información sobre el ejercicio y una URL desde la que descargar los archivos del ejercicio.

```json
"solution":{
	"id":"<id-string>",
	"url":"https://exercism.io/my/solutions/<id-string>",
	"team":null,
	"user":{
		"handle":"<exercism-user-name>",
		"is_requester":true
		},
		"exercise":{
			"id":"isogram",
			"instructions_url":"https://exercism.io/my/solutions/<id-string>",
			"auto_approve":false,
			"track":{
				"id":"pharo-smalltalk",
				"language":"Pharo"
				}
			},
			"file_download_base_url":"https://api.exercism.io/v1/solutions/<id-string>/files/",
			"files":[
				"IsogramTest.class.st",
				"README.md"
				],
			"iteration":null
		}
	}
```

#### 400

El nombre del track del lenguaje es ambiguo, o los archivos del ejercicio enviados no han cambiado.

#### 403

La solución no está desbloqueada para el usuario, o el usuario no se ha unido al track del lenguaje.

#### 404

No se encontró el track del lenguaje o el ejercicio.

## Enviar ejercicios

```
Content-Type: application/octet-stream
```

`PATCH api.exercism.io//v1/solutions/<some-kind-of-token-or-hash> HTTP/1.1`

### Respuesta

#### 201

El envío se realizó correctamente.

#### 400

Un archivo enviado es demasiado grande (más de un megabyte), o la solución está duplicada.

#### 403

El usuario no tiene acceso a la solución. El ID de usuario de la solución y el ID del usuario actual no coinciden.

#### 404

No se encontró el ID de la solución.
