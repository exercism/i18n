# Apéndice de instrucciones

## Notas adicionales para la implementación en C++

Este ejercicio usa el [`unordered_set`][set]
Probablemente necesites la función [`emplace`][emplace] para agregar elementos al conjunto.

Puede que te topes con [`const`][const] porque todavía no ha aparecido en el temario.
Cuando precede a una variable, funciona como una salvaguarda.
Las variables `const` no se pueden cambiar.
Este ejercicio también incluye la palabra clave [`unsigned`][unsigned].
Esto duplica el rango del entero al que precede, pero no permite que se vuelva negativo.

[emplace]: https://en.cppreference.com/w/cpp/container/vector/emplace
[const]: https://www.learncpp.com/cpp-tutorial/const-variables-and-symbolic-constants/
