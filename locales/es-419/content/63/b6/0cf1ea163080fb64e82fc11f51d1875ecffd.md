# Introducción

El tipo `Result` permite que una función devuelva un único valor que indique todas las siguientes cosas:
- Si la operación tuvo éxito o falló
- En caso de éxito, el valor resultante de la operación
- En caso de fallo, la razón del fallo

## Uso

El tipo `Result` es un tipo genérico que contiene dos tipos subyacentes:
- El tipo del valor resultante en una operación exitosa
- El tipo de error en caso de fallo

El tipo `Result` también es una [unión discriminada][discriminated-union] con los siguientes casos posibles:
* `Ok <value>` que representa un resultado exitoso
* `Error <reason>` que representa un fallo

La siguiente función demuestra cómo crear un valor `Result`:

```fsharp
let validateName (name: string) : Result<string, string> = 
    match name with
    | null -> Error "Name not found."
    | "" -> Error "Name is empty."
    | _ -> Ok name
```

En este ejemplo, el valor `Ok` es un string (el nombre dado), y el valor `Error` también es un string (la causa del error, en formato legible para humanos).

## Leer el contenido de un valor `Result`

Considera la siguiente definición de tipo y firma de función:

```
type FileOpenError = 
| NotFound
| AccessDenied
| FileLocked

let openFile (filename: string) : Result<int, FileOpenError> =
```

El código que llama a la función `openFile` puede usar la coincidencia de patrones para manejar los casos de éxito y de fallo, como en el siguiente ejemplo:

```fsharp
match openFile(filename) with
| Ok handle -> doSomethingWithFile(handle)
| Error NotFound -> printfn $"Error: file {filename} was not found."
| Error AccessDenied -> printfn $"Error: you do not have permission to open the file {filename}."
| Error FileLocked -> printfn $"Error: file {filename} is already in use."
```
