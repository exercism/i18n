# Introducción

A partir de `PHP 8.0.0`, las **declaraciones de tipos de unión** aceptan valores de múltiples tipos diferentes, en lugar de un solo tipo. Las definiciones de tipos de unión se hacen usando la barra vertical (`|`) para separar los tipos.

```php
function add(int|float $a, int|float $b): int|float
{
    return $a + $b;
}
```

PHP lanzará un `TypeError` en modo estricto si los parámetros de entrada no son ni un `float` ni un `int`. En modo no estricto, se lanzará un error de tipo si los parámetros de entrada no se pueden convertir en un `float` o un `int`.

De manera similar, si la función no devuelve uno de los tipos declarados, PHP lanzará un `TypeError` en tiempo de ejecución.
