# Anexo a las instrucciones

## Especificación del lenguaje DOT

Aunque el lenguaje DOT tiene una [especificación formal][DOT-spec], las pruebas de este ejercicio no esperan que se implemente toda la especificación.

La wiki de Tcl tiene [algunas notas sobre lenguajes de dominio específico][DSL-wiki].

[DOT-spec]: https://www.graphviz.org/doc/info/lang.html
[DSL-wiki]: https://wiki.tcl-lang.org/page/domain-specific+language
