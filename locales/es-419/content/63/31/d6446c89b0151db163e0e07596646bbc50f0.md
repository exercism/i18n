# Recursos

## Cómo obtener ayuda

1. [The Emacs Wiki](http://emacswiki.org/) es invaluable. Dedícale mucho tiempo.
2. [The Emacs Editor](http://www.gnu.org/software/emacs/manual/html_node/emacs/index.html) es el manual oficial de GNU Emacs.
3. IRC: hay canales de [Libera.Chat](https://libera.chat/) para `#emacs`, `#org-mode` y muchos paquetes de Emacs, y un montón de gente dispuesta a ayudar. Y con emacs, IRC está tan cerca como
   `M-x erc`.
4. Matrix: en [Matrix](https://matrix.org/) hay salas para [emacs](https://matrix.to/#/#emacs:matrix.org), [org-mode](https://matrix.to/#/#org-mode:matrix.org) y otros paquetes de Emacs.
   Puedes [unirte al espacio de Emacs en Matrix](https://matrix.to/#/#emacs-space:matrix.org) para hacerte una idea de los canales disponibles.
   Para unirte a Matrix desde dentro de Emacs, puedes usar el paquete [Ement.el](https://github.com/alphapapa/ement.el).
5. [StackOverflow](http://stackoverflow.com/questions/tagged/elisp) y [Emacs StackExchange](https://emacs.stackexchange.com/questions/tagged/elisp) te sirven para buscar tu problema y ver si ya lo han respondido. También puedes preguntar y responder preguntas.
