# Instrucciones

Los tranvías de Melbourne cobran por zona, y el centro de la ciudad es gratis. Estás escribiendo las reglas de tarifas para la máquina expendedora de boletos. Todas las tarifas están en centavos.

Las cuatro tareas van en la clase `TRAM_FARES`.

## 1. La tarifa de una zona

La zona 0 es la Free Tram Zone y no cuesta nada. La zona 1 cuesta 550. La zona 2, 370. Cualquier otro número no es una zona de tranvía y no cuesta nada.

```sather
TRAM_FARES::zone_fare(1)
-- => 550
TRAM_FARES::zone_fare(7)
-- => 0
```

## 2. ¿Qué tipo de boleto es?

Los boletos llevan una letra. `'f'` es tarifa completa. Tanto `'c'` como `'s'` son concesiones, una para niños y otra para estudiantes. `'x'` es un pase gratis. Cualquier otra cosa es desconocida.

```sather
TRAM_FARES::ticket_kind('s')
-- => "Concession"
TRAM_FARES::ticket_kind('q')
-- => "Unknown"
```

Las cuatro respuestas son `"Full fare"`, `"Concession"`, `"Free pass"` y `"Unknown"`.

## 3. ¿Qué tipo de día es?

`"Sat"` y `"Sun"` son fin de semana. De `"Mon"` a `"Fri"` son días de semana. Cualquier otra cosa es desconocida.

```sather
TRAM_FARES::day_type("Sun")
-- => "Weekend"
```

Las tres respuestas son `"Weekend"`, `"Weekday"` y `"Unknown"`.

## 4. El tope diario

No importa cuántos tranvías tomes, nunca pagas más que el tope de ese día: 1100 en un día de semana y 700 el fin de semana. Un día que nadie reconoce no tiene tope, es decir, es cero.

```sather
TRAM_FARES::daily_cap("Sat")
-- => 700
```
