# Fundamentos de la sintaxis de Elm 2

## Exportar funciones

Ya cubrimos cómo exportar funciones en el primer concepto; aquí tienes un repaso rápido.

Cada archivo en Elm es un módulo y debe contener una sentencia `module` antes que cualquier otro código.

Los nombres de los módulos deben coincidir con el nombre de su archivo, así que el módulo `Calculator` debe estar en el archivo Calculator.elm, y el módulo `Parser.Utils` debe estar en el archivo Parser/Utils.elm.

Todo lo que se define dentro de un módulo tiene ámbito privado dentro de él y no se puede acceder desde fuera, a menos que aparezca en `exposing`.

```elm
-- Calculator.elm
-- Define the Calculator module, and expose the `add` function
module Calculator exposing (add)

six = 3 + 3

add number1 number2 = number1 + number2
```

```elm
-- Calculator.elm
-- Define the Calculator module, and expose everything within: `six` and `add`
module Calculator exposing (..)

six = 3 + 3

add number1 number2 = number1 + number2
```

https://elm-lang.org/docs/syntax#modules

## Importar funciones de otros módulos

Para acceder a las funciones definidas en otros módulos se usan las importaciones.
Cuando importas un módulo, todas las funciones que ese módulo expuso quedan accesibles.
Pero la forma de acceder a ellas cambia según cómo se importó el módulo.

Las importaciones calificadas son las que se usan por defecto, y para acceder a una función de un módulo así (por ejemplo, la función `map` del módulo `List`) se antepone el nombre del módulo (`List.map`).

Las importaciones abiertas permiten acceder directamente a las funciones expuestas de ese módulo, sin anteponer nada. Se hacen con la palabra clave `exposing`, como un espejo de la que se usa al exportar. Puedes exponer todas las funciones disponibles (con `..`) o solo algunas (por ejemplo, `map`).

También puedes importar tipos y sus constructores desde otros módulos, pero eso es un concepto que veremos más adelante.

Se prefieren las importaciones calificadas porque ayudan a la claridad y evitan conflictos de nombres.

```elm
-- qualified imports
import List                            -- List.map, List.foldl
import List as L                       -- L.map, L.foldl

-- open imports
import List exposing (..)              -- map, foldl, concat, ...
import List exposing ( map, foldl )    -- map, foldl, List.concat
```

https://elm-lang.org/docs/syntax#modules

## Anotaciones de tipo

Las anotaciones de tipo se definen con `name : parameter types -> return type`, y los tipos de los parámetros también se separan con `->`.

```elm
add : Int -> Int -> Int
add number1 number2 = number1 + number2
```

Se pueden usar paréntesis para definir los parámetros de una función (que a su vez se definen con la misma sintaxis, de ahí la necesidad de los paréntesis).

```elm
-- Transform every character in a string
map : (Char -> Char) -> String -> String
map charMapperFunction string =
    -- ...
```

https://elm-lang.org/docs/syntax#type-annotations

## Números

En Elm hay dos tipos de números, definidos por los tipos `Int` y `Float`.
`Int` corresponde al conjunto de los números enteros positivos y negativos.
`Float` corresponde al conjunto de los números reales, limitado por la precisión de la computadora.
Las operaciones definidas sobre números suelen funcionar con uno u otro tipo, pero no los mezclan.
Existen funciones para convertir entre ambos, como `toFloat`, que convierte un `Int` en un `Float`, y `round`, `floor`, `ceiling` o `truncate`, que convierten un `Float` en un `Int` con semánticas diferentes.

https://package.elm-lang.org/packages/elm/core/latest/Basics#Int

## Operaciones con strings

Para describir palabras y oraciones en el código, Elm tiene un tipo nativo `String`.
Los literales de string se escriben entre comillas dobles, como `"Hello World!"`.
El operador de concatenación de strings `++` y el operador de igualdad `==` están disponibles por defecto.

```elm
hello : String -> String
hello subject = "Hello " ++ subject

hello "World!" --> "Hello World!"
```

La mayoría de las demás funciones de string están en el módulo `String`, que hay que importar.

https://package.elm-lang.org/packages/elm/core/latest/String
