# Instrucciones

Vas a llevar una guía de campo: un mapa que va del nombre de un animal al hábitat en el que vive.

Las cinco tareas van en la clase `FIELD_GUIDE`.

## 1. ¿Está en la guía?

```sather
FIELD_GUIDE::is_listed(guide, "emu")
-- => true
```

## 2. ¿Dónde vive?

Devuelve el hábitat registrado para un animal. Si la guía nunca ha oído hablar de él, devuelve `"Unknown"`.

```sather
FIELD_GUIDE::habitat_of(guide, "emu")
-- => "grassland"
FIELD_GUIDE::habitat_of(guide, "moa")
-- => "Unknown"
```

## 3. Agrega una entrada

Devuelve la guía con un animal más. Si un animal ya está en la lista, su hábitat se reemplaza.

```sather
FIELD_GUIDE::add_entry(guide, "wombat", "forest")
-- => the guide, now with wombat in it
```

Lo que esto devuelva es la guía que debes usar de ahí en adelante. Agregar a una guía que está completamente vacía funciona y da como resultado una guía con un animal.

## 4. ¿Cuántos animales hay?

```sather
FIELD_GUIDE::entry_count(guide)
-- => 3
```

## 5. ¿Cuáles hábitats?

Devuelve el conjunto de hábitats que menciona la guía. Varios animales pueden compartir un hábitat, y este debe aparecer una sola vez.

```sather
FIELD_GUIDE::all_habitats(guide)
-- => a set holding "grassland" and "forest"
```
