# Instrucciones

En este ejercicio, tienes que traducir algunas reglas del clásico juego Pac-Man a funciones de Haskell.

Tienes cuatro reglas que traducir, todas relacionadas con los estados del juego.

> No te preocupes por cómo se obtienen los argumentos; solo concéntrate en combinarlos para devolver el resultado esperado.

## 1. Define si Pac-Man se come a un fantasma

Define la función `eatsGhost`, que recibe dos argumentos (_si Pac-Man tiene una píldora de energía activa_ y _si Pac-Man está tocando a un fantasma_) y devuelve un valor `Bool` cuando Pac-Man puede comerse al fantasma.
La función debe devolver `True` solo cuando Pac-Man tiene una píldora de energía activa y está tocando a un fantasma.

```haskell
eatsGhost False True
-- -> False
```

## 2. Define si Pac-Man anota

Define la función `scores`, que recibe dos argumentos (_si Pac-Man está tocando una píldora de energía_ y _si Pac-Man está tocando un punto_) y devuelve un valor `Bool` si Pac-Man anota.
La función debe devolver `True` cuando Pac-Man está tocando una píldora de energía o un punto.

```haskell
scores True True
-- -> True
```

## 3. Define si Pac-Man pierde

Define la función `loses`, que recibe dos argumentos (_si Pac-Man tiene una píldora de energía activa_ y _si Pac-Man está tocando a un fantasma_) y devuelve un valor `Bool` si Pac-Man pierde.
La función debe devolver `True` cuando Pac-Man está tocando a un fantasma y no tiene una píldora de energía activa.

```haskell
loses False True
-- -> True
```

## 4. Define si Pac-Man gana

Define la función `wins`, que recibe tres argumentos (_si Pac-Man se comió todos los puntos_, _si Pac-Man tiene una píldora de energía activa_ y _si Pac-Man está tocando a un fantasma_) y devuelve un valor `Bool` si Pac-Man gana.
La función debe devolver `True` cuando Pac-Man se comió todos los puntos _y_ no ha perdido según los argumentos definidos en la parte 3.

```haskell
wins False True False
-- -> False
```
