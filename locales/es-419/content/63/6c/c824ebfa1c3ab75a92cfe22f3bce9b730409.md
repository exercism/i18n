# Boolean

Algunas preguntas solo tienen dos respuestas: sí o no. El tipo de Sather para esa respuesta es `BOOL`, y las dos respuestas se escriben `true` y `false`.

```sather
   ready : BOOL is
      return true;
   end;
```

## Comparar

Comparar dos números da un `BOOL`.

| Operador | Pregunta |
| --- | --- |
| `=` | ¿son iguales? |
| `/=` | ¿son diferentes? |
| `<` | ¿el de la izquierda es menor? |
| `<=` | ¿es menor o igual? |
| `>` | ¿el de la izquierda es mayor? |
| `>=` | ¿es mayor o igual? |

```sather
   old_enough(age : INT) : BOOL is
      return age >= 13;
   end;
```

Fíjate que `=` hace una pregunta. Poner un valor *dentro de* algo es `:=`, que ya viste, y los dos no son lo mismo.

## Combinar

Tres operadores construyen preguntas más grandes a partir de otras más pequeñas.

`and` es verdadero cuando **ambos** lados son verdaderos.

```sather
harness_on and rope_checked
```

`or` es verdadero cuando **cualquiera** de los dos lados es verdadero, o ambos.

```sather
mat_below or net_below
```

`~` invierte una respuesta: convierte verdadero en falso y falso en verdadero.

```sather
~ready       -- true exactly when ready is false
```

`and` y `or` van entre dos respuestas; `~` va delante de una.
