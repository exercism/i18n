# Instrucciones

Tu amigo te acaba de enviar un mensaje con un secreto importante. Como no quería que a otros les resultara fácil leerlo, el mensaje se cifró mediante una serie de manipulaciones de bits. Tendrás que escribir las palabras que ayuden a descifrar el mensaje.

## 1. Desplaza los bits de vuelta

El primer paso para descifrar el mensaje es deshacer el desplazamiento del proceso de cifrado desplazando los bits de vuelta a la derecha. Los pasos posteriores suponen que se insertan ceros desde la izquierda.

Define `shift-back`, que toma un valor de 32 bits y una cantidad, y devuelve el valor desplazado a la derecha esa cantidad con relleno de ceros.

```factor
0b1001 2 shift-back .
! => 0b0010
```

## 2. Pon en 1 algunos bits

A continuación, hay algunos bits que deben ponerse en 1.

Define `set-bits`, que toma un valor y una máscara. Cada bit de `value` cuyo bit correspondiente en `mask` sea 1 debe ponerse en 1; los demás bits se dejan sin cambios.

```factor
0b0110 0b0101 set-bits .
! => 0b0111
```

## 3. Invierte bits específicos

Algunos bits se invierten durante el cifrado. Habrá que invertirlos de vuelta para descifrar el mensaje.

Define `flip-bits`, que toma un valor y una máscara. Cada bit de `value` cuyo bit correspondiente en `mask` sea 1 debe invertirse; los demás bits se dejan sin cambios.

```factor
0b1100 0b0101 flip-bits .
! => 0b1001
```

## 4. Borra bits específicos

Por último, también hay ciertos bits que siempre se descifran como 0.

Define `clear-bits`, que toma un valor y una máscara. Cada bit de `value` cuyo bit correspondiente en `mask` sea 1 debe borrarse a 0; los demás bits se dejan sin cambios.

```factor
0b0110 0b0101 clear-bits .
! => 0b0010
```
