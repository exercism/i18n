# Introducción

Un [`string`][ref-string] (una _cadena_) en Kotlin es una secuencia inmutable de caracteres Unicode.

[`Immutable`][wiki-immutable] significa que cualquier operación sobre un string debe devolver un nuevo string: el string original nunca puede cambiar.

[`Unicode`][wiki-unicode] significa que se pueden representar la mayoría de los sistemas de escritura del mundo, pero (a diferencia de lenguajes más antiguos como C) no existe una correspondencia 1:1 entre caracteres y bytes.

Un string normalmente va entre comillas dobles `" "`.

Algunos caracteres necesitan escaparse: `\'`, `\\`, además de los habituales caracteres no imprimibles como `\t` (tabulador) y `\n` (salto de línea).

```kotlin
val s = "Escape apostrophe \' and backslash \\."
// Escape apostrophe ' and backslash \.
```

Los strings multilínea van entre 3 comillas dobles y pueden contener texto arbitrario (no hace falta escapar nada).

```kotlin
val multi = """I'm a
    multi-line
    string with special characters \ \t """
//I'm a
//    multi-line
//    string with special characters  \ \t 
```

Usa [trimIndent][trimIndent-doc] para eliminar la indentación común de las líneas.
Esto es útil para dar formato al string:

```kotlin
val multi = """
    I'm a
      multi-line
    string""".trimIndent()

//I'm a
//  multi-line
//string
```

Como alternativa, [trimMargin][trimMargin-doc] te permite especificar un delimitador.
Cada línea del `String` entonces comienza después del delimitador.
El delimitador por defecto es `|`, pero puedes especificar un delimitador diferente como parámetro.
Por ejemplo:

```kotlin
val multi = """
    |I'm a
    |  multi-line
    |string""".trimMargin()

//I'm a
//  multi-line
//string

val multi2 = """
    start>I'm a
    start>  multi-line
    start>string""".trimMargin("start>")

//I'm a
//  multi-line
//string
```

Los strings se pueden concatenar con `+`, pero es mejor limitarse a casos cortos y simples.
Existen otras opciones que a menudo son mejores.

## Plantillas de string

Esto se refiere a lo que en otros lenguajes se llama «interpolación».

Si un string contiene un signo de dólar `$` seguido de un identificador, o contiene llaves (`{expression}`) que rodean una expresión, esos se sustituyen por el valor o el resultado de la expresión, respectivamente.

```kotlin
val x = 42
val st = "x is $x, x squared is {x * x}"
// x is 42, x squared is 1764
```

Las llaves `{ }` son necesarias alrededor de las expresiones cuando el análisis sería ambiguo de otro modo.

En general, usar plantillas de string es una forma más eficiente e idiomática de combinar strings que usar `+`.

## Funciones de string

Kotlin ofrece _muchas_ [`functions`][ref-string-functions] para manipular strings.

En su mayoría, son [`extensions functions`][ref-extensions] en lugar de miembros de la clase `String`, aunque esto tiene poco efecto en cómo las usamos.

~~~~exercism/note
Las páginas de [documentación][ref-string-functions] de Kotlin, bastante complejas, ocultan las funciones de extensión en la vista por defecto.
Asegúrate de hacer clic en `Members & Extensions` para expandir esta sección.

[ref-string-functions]: https://kotlinlang.org/api/core/kotlin-stdlib/kotlin/-string/
~~~~

Los siguientes ejemplos muestran solo una pequeña selección de lo que está disponible:

```kotlin
val str = "Hello World!"

str.length              // => 12 (a property, not a function)
str.elementAt(6)        // => W
str.elementAtOrNull(20) // => null (index out of range)
str.substring(6, 11)    // => "World"
str.substringAfter(" ") // => "World!"

str.lowercase()         // => "hello world!"
str.uppercase()         // => "HELLO WORLD!"

str.startsWith("Hel")   // => true
str.endsWith("xyz")     // => false
str.indexOf("0")        // => 4

str.toCharArray()       // => [H, e, l, l, o,  , W, o, r, l, d, !]
"42".toInt() + 1        // => 43  (parsing; see also toFloat)

"Howdy!  ".trim()       // => "Howdy"
```
