# Instalación

Usaremos *PolyML* como nuestra implementación de Standard ML.

Si usas Windows, puedes descargar un instalador desde [https://github.com/polyml/polyml/releases](https://github.com/polyml/polyml/releases).
Puedes encontrar instrucciones generales para Linux/OS X/Free BSD en [https://github.com/polyml/polyml#readme](https://github.com/polyml/polyml#readme).

Si quieres instalar desde el código fuente, el proceso es bastante sencillo:

```sh
$ git clone https://github.com/polyml/polyml.git
$ cd polyml
$ ./configure
```

Si quieres instalarlo en una ubicación personalizada, por ejemplo `$HOME/.local`:

```sh
$ ./configure --prefix=$HOME/.local
```

Último paso:

```sh
$ make compiler
$ make install
```

Verifica que se haya instalado correctamente:

```sh
$ poly
```

Si ves el intérprete, ¡ya está todo listo!
Si no, probablemente tengas que agregar `$HOME/.local/bin` (o `<you prefix>/bin`) a tu `$PATH`.
