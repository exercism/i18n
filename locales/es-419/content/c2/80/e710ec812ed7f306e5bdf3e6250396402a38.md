# Pistas

## 1. Genera un planeta aleatorio

- Esto se parece a [tomar una muestra][ref-sample] de un vector de entrada.
- Puede haber duplicados, así que toma la muestra con reemplazo.

## 2. Genera un número de registro aleatorio de nave estelar

- La parte numérica es un muestreo de un rango.
- Hay varias formas de construir el string, entre ellas [`sprintf()`][ref-sprintf] y [`str_glue()`][ref-str_glue].

## 3. Genera aleatoriamente una flota de naves estelares

- La Introducción habla sobre mezclar.

## 4. Genera una fecha estelar aleatoria

- Queremos un número de punto flotante con [distribución uniforme][ref-runif] entre un límite inferior y uno superior.
- Los matices sobre límites inclusivos o exclusivos se pueden ignorar en esta tarea.
