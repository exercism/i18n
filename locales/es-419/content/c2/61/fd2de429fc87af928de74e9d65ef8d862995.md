# Pruebas

Consigue que la primera prueba compile, se enlace y pase siguiendo las [tres reglas del desarrollo guiado por pruebas][3-tdd-rules].

El makefile incluido se puede usar para crear y ejecutar las pruebas con la tarea `test`.

```console
$ make test
```

Crea solo las funciones que necesites para resolver los errores del compilador y haz que la prueba falle.
Luego escribe solo el código suficiente para que la prueba pase.
Cuando lo hayas hecho, pasa a la siguiente prueba.

A medida que avanzas por las pruebas, tómate el tiempo de refactorizar tu implementación para que sea más legible y expresiva, y después pasa a la siguiente prueba.

Procura usar las herramientas estándar de C99 en lugar de escribir tus propios algoritmos o herramientas de bajo nivel a mano.

## Cómo detectar fugas de memoria

El makefile también incluye una compilación que revisa algunos errores comunes relacionados con fugas de memoria y accesos fuera de los límites de un array.
Para ejecutar estas comprobaciones, usa lo siguiente en la línea de comandos:

```console
$ make memcheck
```
