# Introducción

## Números

Los dos tipos de números más comunes en Ruby son:

- **Enteros:** números sin dígitos después del separador decimal (números enteros). Por ejemplo, `-6`, `0`, `1`, `25`, `976` y `500000`.
- **Números de punto flotante:** números con uno o más dígitos después del separador decimal. Por ejemplo, `-2.4`, `0.1`, `3.14`, `16.984025` y `1024.0`.

Se implementan mediante las clases `Integer` y `Float`.

Estas clases tienen métodos que convierten valores de un tipo al otro. Los números `Integer` son precisos a una unidad entera, mientras que `Float` tiene una precisión fraccionaria respecto de un número entero:
- `Integer#to_f`: convierte a un nuevo float
- `Float#ceil`: redondea hacia arriba al entero más cercano
- `Float#floor`: redondea hacia abajo al entero más cercano
- `Float#round`: redondea al entero más cercano
- `Float#to_i`: trunca al entero más cercano

## Condicionales

Ruby tiene lo que se conoce como expresiones de control de flujo; estas se usan para controlar la forma en que se ejecutará el programa y toman un valor verdadero o falso.
Existen operadores que se pueden usar para crear valores verdaderos o falsos; estos se conocen como [operadores de comparación][comparison-operators].

Hay dos expresiones de control principales que se usan para controlar qué código se ejecutará y qué código no.
Es decir, qué rama en particular se ejecutará.

Esas dos son: `if` y la expresión `unless`.

## Operadores de comparación

Los [operadores de comparación][comparison-operators] se usan para comparar valores y devolver un valor `true` o `false`.
Los siguientes operadores requieren que los dos valores que se comparan sean del mismo tipo.
Si los valores no son del mismo tipo, el compilador arrojará un error.
Aquí tienes una lista de los operadores y un ejemplo de cuándo dan un valor `true`:

| Método | Descripción           | Ejemplo |
| ------ | --------------------- | ------- |
| <      | menor que             | 4 < 5   |
| <=     | menor o igual que     | 4 <= 4  |
| >      | mayor que             | 3 > 1   |
| >=     | mayor o igual que     | 2 >= 2  |

Los operadores de igualdad y desigualdad se pueden usar para comparar cualquier tipo de valor, a diferencia de los operadores ya mencionados.
El operador `==` se usa para comprobar si dos valores son iguales, y eso incluye comprobar el tipo del valor.
El `!=` funciona de la misma manera, pero devolverá `true` si los valores no son iguales y `false` si son iguales.
Aquí tienes una lista de los operadores de igualdad y desigualdad, y un ejemplo de cuándo dan un valor `true`:

| Método | Descripción  | Ejemplo |
| ------ | ------------ | ------- |
| ==     | igual        | 4 == 4  |
| !=     | distinto     | 5 != 4  |

## Sentencia if

La sentencia [`if`][if] se usa para comprobar si una condición dada es «verdadera» o «falsa».
Si la condición es verdadera, el código dentro de la sentencia if se ejecutará.
Una sentencia `if` termina con la palabra clave `end`.

```ruby
value = 1
if value == 1
  "1 is equal to 1"
end
# => "1 is equal to 1"

if value > 2
  "1 is greater than 2"
end
# => nil
```

## Sentencia unless

La sentencia `unless` funciona de manera muy similar a la sentencia `if`, pero ejecutará el código dentro de la sentencia `unless` si la condición es falsa.

```ruby
value = 1
unless value == 1
  "1 is not equal to 1"
end
# => nil

unless value > 2
  "1 is not greater than 2"
end
# => "1 is not greater than 2"
```

## Sentencia else

La sentencia `else` se puede usar junto con la sentencia `if`.
La sentencia `else` se ejecutará si la rama `if` no se ejecuta.

```ruby
value = 1
if value == 1
  "1 is equal to 1"
else
  "1 is not equal to 1"
end
# => "1 is equal to 1"
```

## Sentencias if en cascada

La sentencia `elsif` se puede usar junto con la sentencia if.
La sentencia `elsif` se ejecutará si la rama if no se ejecuta y la condición de la sentencia elsif es verdadera.
Las sentencias elsif se pueden encadenar y se ejecutará la primera condición verdadera.
También puede haber una sentencia else al final de la sentencia if, que se ejecutará si ninguna de las sentencias anteriores fue verdadera.

```ruby
value = 1
if value != 1
  "1 is not equal to 1"
elsif value > 2
  "1 is greater than 2"
else
  "1 is not equal to 1 and 1 is not greater than 2"
end
# => "1 is not equal to 1 and 1 is not greater than 2"
```
