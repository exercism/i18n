# Instrucciones

Implementa la operación `accumulate`, que, dada una colección y una operación que se debe aplicar a cada elemento de la colección, devuelve una nueva colección con el resultado de aplicar esa operación a cada elemento de la colección de entrada.

Dada la colección de números:

- 1, 2, 3, 4, 5

Y la operación:

- elevar un número al cuadrado (`x => x * x`)

Tu código debería poder producir la colección de cuadrados:

- 1, 4, 9, 16, 25

Revisa la suite de pruebas para ver la firma de función esperada.

## Restricciones

¡No toques esa funcionalidad de collect/map/fmap/whatchamacallit que te ofrece tu biblioteca estándar! Resuelve este ejercicio por tu cuenta usando otras herramientas básicas.
