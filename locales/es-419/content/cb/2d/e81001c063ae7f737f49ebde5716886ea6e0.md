# Anexo a las instrucciones

## Implementar tus propias operaciones de lista

Rust tiene un sistema de iteradores muy completo, y usarlos para resolver este ejercicio es trivial.
Intenta resolver el ejercicio sin recurrir a métodos de iterador como `map()`, `flatten()`, `filter()`, `count()`, `fold()`, `chain()`, `rev()` y similares.
Los métodos `next()` y `next_back()` no cuentan.

## Evitar asignaciones de memoria

El ejercicio se puede resolver sin introducir asignaciones de memoria adicionales en la solución.
Fíjate si puedes crear tu propio tipo de iterador en lugar de crear un iterador a partir de una colección.
