# Instrucciones

Como te gusta el ajedrez, quieres escribir tu propia versión del juego.
Sí, puede que ya haya muchas implementaciones de ajedrez disponibles en línea, pero la tuya será única?

Empiezas implementando un tablero de ajedrez.

El juego de ajedrez se jugará en un tablero de ocho casillas de ancho y ocho casillas de largo.
Las casillas se identifican con una letra y un número.

## 1. Define el rango de filas y columnas

El juego tendrá que almacenar las filas del tablero.
Las filas son las líneas horizontales del tablero y se numeran del 1 al 8.

El juego también tendrá que almacenar las columnas del tablero.
Las columnas son las líneas verticales del tablero y se identifican con las letras de la A a la H.

Define las constantes `ranks` y `files` que almacenan el rango de filas y columnas, respectivamente.

```swift
ranks
// Returns 1..8

files
// Returns "A".."H"
```

## 2. Comprueba si la casilla es válida

El juego tendrá que comprobar si una casilla es válida.
Una casilla es válida si la fila y la columna están dentro de los rangos de filas y columnas.

Define el método `isValidSquare(rank:file:)` que toma los argumentos `rank`, que contiene un `Int` de la fila, y `file`, que contiene un `String` de la columna.
El método debe devolver `true` si la fila y la columna están dentro del rango de filas y columnas, y devolver `false` en caso contrario.

```swift
isValidSquare(rank: 1, file: "A")
// Returns true
```

## 3. Obtén la fila

El juego almacenará todas las casillas del tablero en un array unidimensional.
Las casillas se forman como un string de la fila y la columna, por ejemplo, «1A», «8B», «4G», etc.
Para obtener la fila de una casilla, el juego tendrá que calcular el índice de la primera casilla de la fila.

Define el método `getRow(rank:)` que toma el argumento `rank` que contiene un `Int` de la fila.
El método debe devolver un array de strings que representan las casillas de la fila.

```swift
let board = ["1A", "1B", "1C", "1D", "1E", "1F", "1G", "1H", "2A", ..., "8H"]
getRow(board, rank: 1)
// Returns ["1A", "1B", "1C", "1D", "1E", "1F", "1G", "1H"]
```
