# Instrucciones

¡Los estudiantes más observadores habrán notado que el tipo `TreasureChest` del ejercicio anterior no era tan seguro!

Si usabas la función `get_treasure`, tenías que proporcionar la contraseña, pero aun así podías desestructurar el tipo `TreasureChest` para obtener el tesoro sin necesidad de conocer la contraseña.

Vamos a arreglarlo usando un tipo opaco.

## 1. Define el tipo opaco `TreasureChest`.

El `TreasureChest` contiene dos campos:
- Una contraseña que es un `String`.
- Un tesoro que es un tipo genérico.

El tipo `TreasureChest` debe ser opaco.

## 2. Define la función `create`.

Esta función recibe dos argumentos:
- Una contraseña `String`.
- Un tesoro de cualquier tipo.

La función devuelve un `TreasureChest` que contiene la contraseña y el valor.

Si la contraseña tiene menos de 8 caracteres, la función debe devolver un error que diga `Password must be at least 8 characters long`.

## 3. Define la función `open`.

Esta función recibe dos argumentos:

- Un `TreasureChest`.
- Una contraseña `String`.

Si la contraseña coincide con la contraseña del `TreasureChest`, la función debe devolver el tesoro; de lo contrario, debe devolver un error que diga `Incorrect password`.
