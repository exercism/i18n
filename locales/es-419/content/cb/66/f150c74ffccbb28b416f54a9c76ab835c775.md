# Instrucciones

En este ejercicio vas a definir algunas constantes que se usarán en el funcionamiento de un banco.

Tienes cinco tareas:

## 1. Representa la tasa de interés fija de un préstamo

Crea la constante numérica sin tipo `FixedInterestRate` que almacene el valor de 5% (5/100), luego implementa la función `GetFixedInterestRate` para que lo devuelva:

```go
GetFixedInterestRate()
// => 0.05
```

## 2. Representa el número de días de un año

Crea la constante `DaysPerYear` de tipo `int` que almacene el valor 365, luego implementa la función `GetDaysPerYear` para que lo devuelva:

```go
GetDaysPerYear()
// => 365
```

## 3. Representa los meses del año

En un bloque, usa el enumerador de Go para crear doce constantes numéricas sin tipo que almacenen los valores del 1 al 12 para los meses del año.
Nómbralas `Jan`, `Feb`, `Mar`, etc., luego implementa la función `GetMonth` para que devuelva el valor de un mes dado:

```go
GetMonth(Jan)
// => 1
```

## 4. Representa un número de cuenta

Crea la constante `AccountNo` de tipo string sin tipo que almacene el valor XF348IJ, luego implementa la función `GetAccountNumber` para que lo devuelva:

```go
GetAccountNumber()
// => "XF348IJ"
```
