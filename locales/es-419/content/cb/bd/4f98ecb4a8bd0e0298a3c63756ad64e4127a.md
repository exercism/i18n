# Luhn: uso de un trait personalizado

Antes de hacer este ejercicio, probablemente deberías hacer el ejercicio original de Luhn y su sucesor, «Luhn: uso del trait From».

Para obtener el ejercicio original de Luhn, ejecuta

```shell
exercism download --exercise=luhn --track=rust
```

Para obtener el ejercicio «Luhn: uso del trait From», ejecuta

```shell
exercism download --exercise=luhn-from --track=rust
```

En el ejercicio original de Luhn solo validabas strings, pero el algoritmo de Luhn también se puede aplicar a números enteros.

En «Luhn: uso del trait From» implementaste un trait From, lo que además requería que crearas un struct Luhn.

En lugar de crear un struct solo para hacer la validación, ¿qué tal si validaras los propios tipos primitivos (es decir, String, u8, etc.)?

En este ejercicio vas a crear e implementar un [trait](https://doc.rust-lang.org/book/ch10-02-traits.html) personalizado que se encargue de la validación.
