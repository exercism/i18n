# usa el operador de fusión de nulos en lugar de `string.IsNullOrEmpty`

En lugar de usar `string.IsNullOrEmpty` para determinar si se debe usar el nombre predeterminado, considera probar el [operador de fusión de nulos](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/operators/null-coalescing-operator) para simplificar el código y ten en cuenta la diferencia de comportamiento.
