# Instrucciones

En este ejercicio vas a jugar con un carro a control remoto, para el que por fin ahorraste suficiente dinero y pudiste comprarlo.

Los carros comienzan con la batería llena (100%). Cada vez que conduces el carro usando el control remoto, recorre 20 metros y consume uno por ciento de la batería.

El carro a control remoto tiene una vistosa pantalla LED que muestra dos datos:

- La distancia total que ha recorrido, mostrada como: `"Driven <METERS> meters"`.
- La carga restante de la batería, mostrada como: `"Battery at <PERCENTAGE>%"`.

Si la batería está al 0%, ya no puedes conducir el carro y la pantalla de la batería mostrará `"Battery empty"`.

Tienes seis tareas, y cada una trabajará con instancias del carro a control remoto.

## 1. Compra un carro a control remoto nuevo

Implementa el método (_estático_) `JedliksToyCar.buy()` para que devuelva una instancia nueva del carro a control remoto:

```java
JedliksToyCar car = JedliksToyCar.buy();
```

## 2. Muestra la distancia recorrida

Implementa el método `JedliksToyCar.distanceDisplay()` para que devuelva la distancia tal como se muestra en la pantalla LED:

```java
JedliksToyCar car = JedliksToyCar.buy();
car.distanceDisplay();
// => "Driven 0 meters"
```

## 3. Muestra el porcentaje de batería

Implementa el método `JedliksToyCar.batteryDisplay()` para que devuelva el porcentaje de batería tal como se muestra en la pantalla LED:

```java
JedliksToyCar car = JedliksToyCar.buy();
car.batteryDisplay();
// => "Battery at 100%"
```

## 4. Actualiza el número de metros recorridos al conducir

Implementa el método `JedliksToyCar.drive()` que actualiza el número de metros recorridos:

```java
JedliksToyCar car = JedliksToyCar.buy();
car.drive();
car.drive();
car.distanceDisplay();
// => "Driven 40 meters"
```

## 5. Actualiza el porcentaje de batería al conducir

Actualiza el método `JedliksToyCar.drive()` para que actualice el porcentaje de batería:

```java
JedliksToyCar car = JedliksToyCar.buy();
car.drive();
car.drive();
car.batteryDisplay();
// => "Battery at 98%"
```

## 6. Evita conducir cuando la batería esté agotada

Actualiza el método `JedliksToyCar.drive()` para que no aumente la distancia recorrida ni reduzca el porcentaje de batería cuando la batería esté agotada (al 0%):

```java
JedliksToyCar car = JedliksToyCar.buy();

// Drain the battery
// ...

car.distanceDisplay();
// => "Driven 2000 meters"

car.batteryDisplay();
// => "Battery empty"
```
