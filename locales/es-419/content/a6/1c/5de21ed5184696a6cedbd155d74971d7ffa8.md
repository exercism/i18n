# Introducción

## Campos etiquetados

Cuando una variante de un tipo personalizado contiene datos, se le llama registro, y cada valor que contiene reside en un _campo_.

```gleam
pub type Rectangle {
  Rectangle(
    Float, // The first field
    Float, // The second field
  )
}
```

Para facilitar la lectura, Gleam permite etiquetar los campos con un nombre.

```gleam
pub type Rectangle {
  Rectangle(
    width: Float,
    height: Float,
  )
}
```

Las etiquetas se pueden usar para dar argumentos en cualquier orden al constructor de un registro.

```gleam
let a = Rectangle(height: 10.0, width: 20.0)
let b = Rectangle(width: 20.0, height: 10.0)

a == b
// -> True
```

Cuando un tipo personalizado tiene solo una variante, se puede usar la sintaxis de acceso `.label` para obtener los campos de un registro.

```gleam
let rect = Rectangle(height: 10.0, width: 20.0)

rect.height // -> 10.0
rect.width  // -> 20.0
```

La sintaxis de actualización de registros se puede usar cuando un tipo personalizado tiene una sola variante para crear un registro nuevo a partir de uno existente, pero con algunos de los campos reemplazados por valores nuevos.

```gleam
let rect = Rectangle(height: 10.0, width: 20.0)
let tall_rect = Rectangle(..rect, height: 50.0)

tall_rect.height // -> 50.0
tall_rect.width  // -> 20.0
```

Las etiquetas también se pueden usar al hacer coincidencia de patrones para extraer valores de los registros.

```gleam
pub fn is_tall(rect: Rectangle) {
  case rect {
    Rectangle(height: h, width: _) if h >. 20.0 -> True
    _ -> False
  }
}
```

Si solo queremos hacer coincidir algunos de los campos, podemos usar el operador de propagación `..` para ignorar los campos restantes.

```gleam
pub fn is_tall(rect: Rectangle) {
  case rect {
    Rectangle(height: h, ..) if h >. 20.0 -> True
    _ -> False
  }
}
```
