# Introducción

Una propiedad en Haxe es un miembro de una clase que proporciona acceso a los datos dentro de esa clase. El código que llama puede establecer o recuperar (get) los datos. Se componen de un accesor de escritura y/o un accesor de lectura.

Las propiedades tienen modificadores de acceso (public, private, etc.) igual que otros miembros de la clase, pero el accesor de escritura puede tener un nivel de acceso independiente del accesor de lectura (get) y viceversa. Una propiedad no tiene que tener ambos accesores; puede tener solo uno (ya sea de lectura o de escritura).

El acceso de lectura y el acceso de escritura se reflejan directamente en la sintaxis, como muestra el siguiente ejemplo:

```haxe
class Main {
  public var x(default, null):Int;
}
```

Tanto `default` como `null` son **identificadores de acceso** especiales. Los identificadores de acceso establecen el comportamiento para cuando se lee el campo (primer identificador) y para cuando se escribe el campo (segundo identificador). Los valores aceptados son:

- `default`: Permite el acceso normal al campo si el campo es public.
- `null`: Permite el acceso solo desde dentro de la clase que lo define.
- `get/set`: El acceso se genera como una llamada a un método de acceso (`get_x()`).
- `dynamic`: Igual que `get/set`, pero no se puede verificar la existencia de un método de acceso.
- `never`: No permite ningún tipo de acceso.

Aquí tienes un ejemplo completo:

```haxe
class Main {
  public var x(default, set):Int;

  public function set_x(x:Int):Int {
    return this.x = x + 2;
  }

  public function main() {
    trace(x); // null
    x = 2;
    trace(x); // 4
  }
}
```
