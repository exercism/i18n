# Anexo de instrucciones

## Implementación

Se agregó una prueba opcional que verifica que las posibles letras puedan ser cualquier carácter Unicode, no solo caracteres alfabéticos ASCII.
No puedes acceder a ellas desde el editor web, pero se ejecutan de forma predeterminada cuando las ejecutas localmente.

Para desactivar estas pruebas, al llamar al comando de pruebas (`crystal spec`), agrega el siguiente flag: `--tag "~optional"`
