# Acerca de

Gleam puede ejecutarse en la máquina virtual de Erlang (BEAM) o en entornos de ejecución de JavaScript. Hay muchos otros lenguajes que usan estos entornos de ejecución, y a menudo resulta útil poder llamar desde Gleam a código escrito en esos lenguajes.

La funcionalidad de _funciones externas_ de Gleam permite importar funciones de otros lenguajes a Gleam y llamarlas sin sobrecarga en tiempo de ejecución.

Si tu proyecto de Gleam se ejecuta en la máquina virtual de Erlang y quieres llamar a la función `reverse` del módulo `lists` de Erlang, puedes hacerlo agregando el atributo `@external` a la cabecera de una función de Gleam así:

```gleam
@external(erlang, "lists", "reverse")
pub fn reverse_list(x: List(a)) -> List(a)
```

Luego se puede llamar como una función normal de Gleam:

```gleam
let reversed = reverse_list([1, 2, 3])
// -> [3, 2, 1]
```

Si intentas compilar este código para entornos de ejecución de JavaScript, fallará con un mensaje de error, ya que no hay una implementación para JavaScript. Se puede especificar otra implementación para los entornos de ejecución de JavaScript así:

```gleam
@external(erlang, "lists", "reverse")
@external(javascript, "./my_module.mjs", "reverse")
pub fn reverse_list(x: List(a)) -> List(a)
```

También es posible escribir una implementación en Gleam que se use cuando no haya una implementación externa para el objetivo de compilación actual:

```gleam
@external(erlang, "lists", "reverse")
pub fn reverse_list(x: List(a)) -> List(a) {
  tail_recursive_reverse(x, [])
}

fn tail_recursive_reverse(list, reversed) {
  case list {
    [] -> reversed
    [x, ..xs] -> tail_recursive_reverse(xs, [x, ..reversed])
  }
}
```
