# Pistas

Para todas estas tareas, vas a necesitar el comando `print`:
```awk
{print "something", "something else"}
```

## 1. Enumera los nombres de usuario

* Usa [la variable `FS`][var-fs] para definir el separador de campos.

## 2. Imprime los números de línea

* Usa la [variable integrada `NR`][var-nr] para obtener el número de línea.

## 3. Imprime los registros con directorios de inicio no válidos

* El directorio de inicio es el sexto campo.
* Usa la función `startsWith` que se te proporcionó.
* Usa [operadores booleanos][boolean-ops]: `&&`, `||`, `!`.

## 4. Imprime el número de usuarios válidos que usan bash

* El shell de inicio de sesión es el último campo; puedes usar [la variable `NF`][var-nf].
