# Consejos

## General

- Lee la documentación oficial sobre [typespecs][typespecs].
- Lee la documentación oficial sobre [cómo escribir documentación][writing-documentation].
- Lee sobre el uso de atributos de módulo como anotaciones en la [guía oficial de introducción][getting-started-module-attributes].
- Lee sobre el uso de typespecs en la [guía oficial de introducción][getting-started-typespecs].

## 1. Documenta el propósito de las herramientas del formulario

- El atributo de módulo `@moduledoc` se puede usar para escribir la documentación de un módulo.

## 2. Documenta cómo llenar campos con valores en blanco

- El atributo de módulo `@doc` se puede usar para escribir la documentación de una función.
- El atributo de módulo `@spec` se puede usar para escribir un typespec de una función.
- Coloca los atributos `@doc` y `@spec` justo antes de la primera cláusula de la función que esos atributos describen.
- Consulta la [documentación de typespecs][typespecs-types] para ver una lista de todos los tipos disponibles.
- El tipo correcto para strings es el [definido en el módulo `String`][string-t].

## 3. Documenta cómo dividir valores en listas de letras mayúsculas

- El atributo de módulo `@doc` se puede usar para escribir la documentación de una función.
- El atributo de módulo `@spec` se puede usar para escribir un typespec de una función.
- Coloca los atributos `@doc` y `@spec` justo antes de la primera cláusula de la función que esos atributos describen.
- Consulta la [documentación de typespecs][typespecs-types] para ver una lista de todos los tipos disponibles.
- El tipo correcto para strings es el [definido en el módulo `String`][string-t].
- Una lista es un tipo parametrizado.

## 4. Documenta cómo verificar si un valor cabe en un campo con una longitud máxima

- El atributo de módulo `@doc` se puede usar para escribir la documentación de una función.
- El atributo de módulo `@spec` se puede usar para escribir un typespec de una función.
- Coloca los atributos `@doc` y `@spec` justo antes de la primera cláusula de la función que esos atributos describen.
- Consulta la [documentación de typespecs][typespecs-types] para ver una lista de todos los tipos disponibles.
- El tipo correcto para strings es el [definido en el módulo `String`][string-t].
- Se pueden usar valores literales en un typespec.
- La barra vertical `|` se puede usar para representar una unión de tipos.

## 5. Documenta los diferentes formatos de dirección

- El atributo de módulo `@type` se puede usar para definir un tipo público personalizado.
- Los tipos pueden ser compuestos; por ejemplo, al especificar un tipo que es un mapa, también puedes especificar los tipos de los valores bajo claves específicas.
- [El operador de tipo `::`][type-operator] también se puede usar para anteponer un nombre de variable a un tipo.
- Los tipos personalizados se pueden usar para definir otros tipos personalizados.

## 6. Documenta cómo dar formato a la dirección

- El atributo de módulo `@doc` se puede usar para escribir la documentación de una función.
- El atributo de módulo `@spec` se puede usar para escribir un typespec de una función.
- Coloca los atributos `@doc` y `@spec` justo antes de la primera cláusula de la función que esos atributos describen.
- Consulta la [documentación de typespecs][typespecs-types] para ver una lista de todos los tipos disponibles.
- El tipo correcto para strings es el [definido en el módulo `String`][string-t].
- Los tipos personalizados se pueden usar en un typespec.
