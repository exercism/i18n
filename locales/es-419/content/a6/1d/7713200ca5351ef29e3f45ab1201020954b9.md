# Iteración

En programación, la [iteración][iteration] se refiere al proceso de repetir un bloque de código varias veces.
Esto se puede hacer usando conceptos como los bucles while y los bucles until.
También se puede hacer usando recursión, que es una función que se llama a sí misma.

Sin embargo, lo más común es que quieras iterar sobre una colección de elementos, como un `Array`, un `Range` o un `String`.
Tanto la clase `Array` como la clase `Range` de Crystal incluyen el módulo [`Enumerable`][enumerable], que ofrece varios métodos para iterar sobre los elementos.
Por su parte, la clase `String` tiene su propio conjunto de métodos para iterar sobre los caracteres.

Además, Crystal no tiene una sentencia for como la tienen otros lenguajes.
En su lugar, tiene varios métodos que puedes usar para iterar.

## Iterar

La forma más común de iterar sobre una colección es usar el método [`each`][each], que entrega cada elemento de la colección a un bloque.
Esto se puede hacer fácilmente con un `Range`.
Digamos que quieres iterar entre 1 y 3; puedes usar el método `each` para recorrer el rango.

```crystal
(1..3).each do |n|
  puts n
end

# Output:
# 1
# 2
# 3
```

Aún más simple, si solo quieres iterar una cantidad de veces, puedes usar el método [`times`][times], que existe en la clase `Int`.

```crystal
3.times do |n|
  puts n
end

# Output:
# 0
# 1
# 2
```

## Iterar sobre un `String`

Un `String` es una secuencia de caracteres y no pertenece al módulo `Enumerable`. Por eso tiene su propio conjunto de métodos para iterar sobre los caracteres.
La forma más común de iterar sobre un `String` es usar el método [`each_char`][each_char], que entrega cada carácter del `String` a un bloque.

~~~~exercism/note
El método `each_char` le pasa al bloque un objeto `Char` y no un objeto `String`.
~~~~

```crystal
str = "hello"
str.each_char { |char| puts char }

# Output:
# h
# e
# l
# l
# o
```

Otra forma de iterar sobre un `String` es usar el método [`each_line`][each_line].
Este método se usa sobre todo cuando se lee un archivo línea por línea.

```crystal
str = "hello\nworld"
str.each_line do |line|
  puts line
end

# Output:
# hello
# world
```

## Iterar sobre un objeto que incluye el módulo `Enumerable`

El módulo [`Enumerable`][enumerable] ofrece varios métodos para iterar sobre los elementos de una colección.
Las colecciones que incluyen el módulo `Enumerable` son `Array`, `Range`, `Hash`, `Set` y otras; estas últimas se verán en conceptos posteriores.

La forma más común de iterar sobre un `Array` es usar el método [`each`][each], que entrega cada elemento del `Array` a un bloque.

```crystal
arr = [5, 2, 3]
arr.each do |element|
  puts element
end

# Output:
# 5
# 2
# 3
```

### Map

El método [`map`][map] es otra forma de iterar sobre un `Array`: devuelve un `Array` nuevo que contiene los resultados de aplicar el bloque a cada elemento.
Es similar al método `each`, pero devuelve un `Array` nuevo con los elementos transformados.
La transformación es muy útil cuando quieres aplicar una función a cada elemento de la colección, algo que se hace con frecuencia.

```crystal
arr = [1, 2, 3]
new_arr = arr.map do |element|
  element * 2
end

new_arr
# => [2, 4, 6]
```

Con un flujo de control como `if`, puedes filtrar qué elementos transformar.

```crystal
arr = [1, 2, 3]
new_arr = arr.map do |element|
  if element.odd?
    element * 2
  else
    element
  end
end

new_arr
# => [2, 2, 6]
```

## Sintaxis abreviada

En Crystal existe una sintaxis abreviada para iterar y aplicar un método a cada elemento de una colección.
Esto es útil cuando trabajas con lógica simple que solo necesita transformarse con un método.
Se hace usando la sintaxis `&.` seguida del nombre del método.

```crystal
arr = [1, 2, 3]
arr.map(&.to_s)
# => ["1", "2", "3"]
```

### Con índice

A veces necesitas saber el índice del elemento sobre el que estás iterando; para eso puedes usar el método [`each_with_index`][each_with_index] o [`map_with_index`][map_with_index].
Entrega cada elemento y su índice a un bloque, y el método también acepta un argumento opcional para especificar el índice inicial.

```crystal
arr = [1, 2, 3]
arr.each_with_index(4) do |element, index|
  puts "Element: #{element}, Index: #{index}"
end

# Output:
# Element: 1, Index: 4
# Element: 2, Index: 5
# Element: 3, Index: 6
```

Ten en cuenta que el método [`each_char_with_index`][each_char_with_index] también está disponible para objetos `String`.

### sum

El método [`sum`][sum] devuelve la suma de todos los elementos de la colección; también acepta un bloque opcional para transformar los elementos antes de sumarlos.
Además, acepta un argumento opcional para especificar el valor inicial de la suma.

```crystal
arr = [1, 2, 3]
arr.sum
# => 6

arr.sum(2) { |n| n * 2 }
# => 14
```

### reduce

[`reduce`][reduce], o fold como se conoce en otros lenguajes, es un método que, junto con un método de combinación y un valor inicial, combina todos los elementos de la colección.
El método `reduce` tiene un acumulador que se pasa al bloque; el acumulador es el resultado de la iteración anterior.
Esto se convierte en un proceso recursivo que combina todos los elementos de la colección.

```crystal
arr = [1, 2, 3]
arr.reduce(0) do |acc, n|
  acc + n
end
# => 6
```

`reduce` puede parecer similar a `sum`, pero `reduce` es más flexible porque te permite especificar el valor inicial del acumulador y el método de combinación.
`reduce` se puede usar para implementar `sum`, `count` y otros métodos.
