# Cómo ejecutar los tests en la línea de comandos

Roc viene con sus propias herramientas integradas para ejecutar tests, así que no necesitas instalar nada más.

Para probar tu solución de un ejercicio, abre una terminal, ve al directorio del ejercicio, ejecuta `roc test <exercise-name>-test.roc`, por ejemplo `roc test hello-world-test.roc`, y asegúrate de que todos los tests pasen. No edites el propio `*-test.roc`, solo el o los demás archivos `*.roc`.
