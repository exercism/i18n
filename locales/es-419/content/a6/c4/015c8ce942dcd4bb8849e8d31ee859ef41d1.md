## 3. Define la función multiply_treasure

- El valor de retorno será un `TreasureChest{Vector{T}}`, donde `T` es el tipo del tesoro del cofre que se proporciona.
  - Siguiendo el espíritu del concepto, podrías obtener el tipo del tesoro y crear un cofre paramétrico con el parámetro establecido en un `Vector` del tipo original.
  - De forma mucho más sencilla (aunque quizá sientas que es _un poquito_ hacer trampa), podrías ignorar el parámetro y dejar que la inferencia de tipos se encargue.
- Para crear un vector con elementos repetidos, hay dos funciones entre las que puedes elegir:
  - [`fill(value, multiplier)`][fill] toma un valor escalar y lo repite.
  - [`repeat([value,], multiplier)`][repeat] repite el vector dado.
