# Introducción

## Valores verdaderos y falsos

En Common Lisp todos los valores son «verdaderos», excepto `()`, que es «falso».
Hay dos símbolos constantes especiales, `t` y `nil`, cuyos valores son verdadero y falso, respectivamente.

## Condicionales

Common Lisp ofrece varias expresiones condicionales diferentes; la principal diferencia es la cantidad de ramas que admiten.

- `when` y `unless` permiten una sola rama:

```lisp
(when (= 2 2) "All is well")      ; => "All is well"
(unless (= 2 2) "Time to panic!") ; => NIL
```

La parte que sigue a la expresión de prueba puede contener más de una expresión.

- `if` ofrece la clásica construcción if-then-else:

```lisp
(if (= 2 2) 'how-honest 'you-liar) ; => HOW-HONEST
```

Ten en cuenta que tanto la cláusula then como la else solo pueden ser una única expresión.

- `cond` ofrece una forma de tener varias ramas sin anidar expresiones `if`:

```lisp
(cond ((= 0 2) 'nope)
      ((= 1 2) 'try-again)
      ((= 2 2) 'quite-true)
      ((= 3 2) 'too-far)
      (t 'something-else))
; => QUITE-TRUE
```

Ten en cuenta que no hay límite en la cantidad de expresiones que siguen a la expresión de prueba.

- `case` ofrece una construcción clásica al estilo «switch»: compara un único valor contra varias ramas:

```lisp
(case 'elder-beast
  (cat "Meow")
  (bird "Chirp")
  (dog "Bark")
  (otherwise "???"))
; => "???"
```

Ten en cuenta que, igual que con `cond`, no hay límite en la cantidad de expresiones que siguen a la expresión de prueba.
