# Introducción

La forma más común de ejecutar código de manera condicional en F# es usar una expresión `if/elif/else`:

```fsharp
if x = 5 then
    printfn "Expression to evaluate when x equals 5"
elif x > 7 then
    printfn "Expression to evaluate when x greater than 7"
else
    printfn "Expression to evaluate in all other cases"
```

Las condiciones que se usan en una expresión `if/elif/else` deben ser de tipo `bool`. F# no tiene el concepto de valores _truthy_.
