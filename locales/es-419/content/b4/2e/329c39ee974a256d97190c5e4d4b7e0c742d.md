# Pistas

## General

- No te preocupes por cómo se obtienen los argumentos, solo concéntrate en combinarlos para devolver el resultado esperado.

## 1. Define si pac-man puede comer un fantasma

- La función debe devolver un valor [Boolean][boolean].
- Puedes usar el operador [Boolean][boolean] [`and/2`][boolean-and] para combinar los argumentos y obtener un resultado.

## 2. Define si pac-man anota puntos

- La función debe devolver un valor [Boolean][boolean].
- Puedes usar el operador [Boolean][boolean] [`or/2`][boolean-or] para combinar los argumentos y obtener un resultado.

## 3. Define si pac-man pierde

- La función debe devolver un valor [Boolean][boolean].
- Puedes usar los operadores [Boolean][boolean] [`and/2`][boolean-and] y [`not/1`][boolean-not] para combinar los argumentos y obtener un resultado.

## 4. Define si pac-man gana

- La función debe devolver un valor [Boolean][boolean].
- Puedes usar los operadores [Boolean][boolean] [`and/2`][boolean-and] y [`not/1`][boolean-not] para combinar los argumentos y los resultados de una de las funciones que implementaste antes.

[boolean]: https://hexdocs.pm/elixir/basic-types.html#booleans-and-nil
[boolean-and]: https://hexdocs.pm/elixir/Kernel.html#and/2
[boolean-or]: https://hexdocs.pm/elixir/Kernel.html#or/2
[boolean-not]: https://hexdocs.pm/elixir/Kernel.html#not/1
