# Apéndice de instrucciones

## Pistas

Necesitas implementar las funciones `label` y `ohms`. Puedes usar la firma que te damos para `label`, pero no dejes que limite tu creatividad.

Este ejercicio trabaja con datos textuales. Por razones históricas, el tipo `String` de Haskell es sinónimo de `[Char]`, una lista de caracteres. Para manejar datos textuales de forma más eficiente, puedes usar el tipo `Text`.

Como extensión opcional de este ejercicio, puedes

- Leer sobre los [tipos string](https://haskell-lang.org/tutorial/string-types) en Haskell.
- Agregar `- text` a tu lista de dependencias en package.yaml.
- Importar `Data.Text` [de la siguiente manera](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c):

    ```haskell
    import qualified Data.Text as T
    import           Data.Text (Text)
    ```

- Ahora puedes escribir, por ejemplo, `label :: Resistor -> Text` y referirte a los combinadores de `Data.Text` como, por ejemplo, `T.pack`.
- Consultar la documentación de [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html),

Esta parte es totalmente opcional.
