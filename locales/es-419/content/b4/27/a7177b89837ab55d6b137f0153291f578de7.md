## Variables

Las variables son nombres simbólicos que se refieren a valores o a contenedores.
Los nombres de las variables pueden empezar con o sin un carácter especial llamado [sigil][sigils], seguido de un identificador.
Después de un sigil también puede venir un [twigil][twigils].

Las distintas variables con sigil contienen distintos tipos de estructuras de datos.

```raku
my $scalar; # Assigned value will be stored as-is
my @array;  # Assigned value will be coerced into an array
my %hash;   # Assigned value will be coerced into a hash
my &code;   # Assigned value must be a code object
```

Los twigils que verás con más frecuencia son `^` y `:`, que funcionan como atajos para las signaturas de los bloques de código.
El `^` es para los parámetros posicionales.
El `:` es para los parámetros con nombre.

```raku
{ $^a + $^b }; #`[same as] ->  $a,  $b { $a + $b }; # Called with (1, 2)
{ $:a + $:b }; #`[same as] -> :$a, :$b { $a + $b }; # Called with (a => 1, b => 2)
```

## Contenedores

Los contenedores son lo que permite modificar una variable.

Las variables declaradas con `constant`, y las variables sin sigil (declaradas con un `\` antes del identificador), no tienen contenedores y se refieren directamente a valores.

```raku
my $foo = 1;
$foo = 2;

constant $bar = 3;
my \baz = 4;

# The following will fail
$bar = 5;
baz  = 6;
```

## Tipos

Las variables se pueden declarar con una restricción de tipo.
Las restricciones de tipo también pueden tener coerciones, si pasas un tipo aceptado como argumento al tipo deseado.

```raku
my Bool   $foo = True; # Booleans only.
my Bool() $bar = 0;    # Accepts type `Any`. Coerced to False.

my Str(Bool(Int)) $baz;
$baz = 1;   # "True"
$baz = "1"; # "1"
```

Usar restricciones de tipo es una forma de aprovechar las rutinas de despacho múltiple.

```raku
multi foo (Int $bar) { say 'Type of arg to $bar is Int!' }
multi foo (Str $bar) { say 'Type of arg to $bar is Str!' }
```

En Raku, los tipos son simplemente otro tipo de objeto.
Declarar una `class`, un `role` o un `enum` son formas de crear tus propios objetos de tipo.
Por ejemplo, el tipo incorporado `Bool` se construye con un enum: `enum Bool <False True>`.

También puedes crear restricciones de tipo simples a partir de otros tipos con la palabra clave `subset`.
Puedes restringir aún más este nuevo tipo usando una cláusula `where`.
Una cláusula `where` también se puede usar en una signatura.

```raku
subset PositiveInt of Int where * > 0;

sub is-even (PositiveInt $n where  %% 2) { say "$n is even!" }
```
