# Apéndice de instrucciones

## Estructuras de datos con estado

En los lenguajes funcionales, como Lean, la mayoría de los valores son inmutables por diseño.
Esto significa que las actualizaciones normalmente se hacen produciendo un valor nuevo.
Tanto el valor viejo como el nuevo coexisten y se pueden referenciar y usar.

Sin embargo, hay muchas situaciones en las que se desea un valor _con estado_, o incluso es necesario.
Un valor con estado se actualiza mediante mutación, _reemplazando_ el valor viejo en lugar de crear uno nuevo.
Después de una mutación, solo el valor actualizado sigue siendo accesible.

Fíjate que las mutaciones pueden romper algunas garantías del lenguaje.
Una función pura siempre debe devolver el mismo resultado para el mismo conjunto de argumentos, pero si un argumento puede cambiar con el tiempo, entonces la función puede devolver resultados diferentes incluso cuando se llama con los mismos argumentos.
De manera similar, si una función puede producir cambios externos además de devolver un resultado, o puede leer de fuentes distintas de sus parámetros, entonces dos llamadas a la misma función pueden tener resultados diferentes y a veces impredecibles.

Para manejar este comportamiento con estado, Lean, como otros lenguajes funcionales, requiere que las funciones con efectos se envuelvan en un tipo especial de estructura que las distinga de las funciones puras.
Estas estructuras se llaman _mónadas_.

Es importante notar que, aunque todo valor con estado vive dentro de alguna mónada con efectos, no toda mónada representa estado mutable.
Ejemplos notables de mónadas «puras» son `Option`, `Except` e `Id`.

En este ejercicio, vas a definir una estructura de datos con estado llamada `LinkedList`.
Las instancias de esta estructura de datos se actualizan por mutación.

Para lograr esto, todas las funciones se envuelven dentro de la mónada `ST`.
En esta mónada, el estado mutable es el único efecto secundario, y las referencias mutables no pueden escapar.
Para más información, puedes consultar la [referencia][reference].
