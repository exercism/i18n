# Introducción

AWK es un lenguaje muy pequeño y solo tiene unos pocos tipos de datos básicos.
En esta lección veremos números y strings.

## Números

Los números en AWK se implementan como números de punto flotante de doble precisión.
No hay distinción entre enteros, flotantes y dobles.

AWK entiende constantes numéricas octales (que empiezan con `0`) y constantes numéricas hexadecimales (que empiezan con `0x` o `0X`).

### Operaciones numéricas

Puedes usar los [operadores aritméticos estándar][ops-arith] `+`, `-`, `*`, `/`, `%`.
El operador de exponenciación es `^` (así lo especifica POSIX), aunque también se puede usar `**`.
Hay algunas [funciones numéricas integradas][funcs-numeric], entre ellas las funciones trigonométricas, la generación de números aleatorios y `int(x)` para truncar un número al entero más cercano entre _x_ y cero.

No existen _operadores_ bit a bit.
gawk los implementa como funciones.
Los argumentos deben ser números no negativos.

| función            | operación                                      |
| ------------------- | ---------------------------------------------- |
| `and(a, b [, ...])` | AND bit a bit de los argumentos                   |
| `or(a, b [, ...])`  | OR bit a bit de los argumentos                   |
| `xor(a, b [, ...])` | XOR bit a bit de los argumentos                   |
| `lshift(v, count)`  | el valor de _v_ desplazado _count_ bits a la izquierda  |
| `rshift(v, count)`  | el valor de _v_ desplazado _count_ bits a la derecha |
| `compl(v, count)`   | complemento bit a bit de _v_                      |

## Strings

Los strings en AWK son secuencias de caracteres.
Especifica una constante de string usando comillas dobles.

~~~~exercism/caution
GNU awk permite caracteres Unicode en los strings; otras implementaciones de awk puede que no.
Si comparamos `gawk` con `mawk`, otra implementación popular de AWK:

```sh
$ echo "Hi friend 😀!" | gawk '{print length($3)}'
2
$ echo "Hi friend 😀!" | mawk '{print length($3)}'
5
```
~~~~

### Operaciones con strings

Solo hay una operación con strings: la concatenación.
La concatenación no tiene un operador especial;
basta con poner dos strings uno al lado del otro para concatenarlos:

```awk
BEGIN {
    hw = "Hello" "World"
    print hw
}
# => HelloWorld
```

~~~~exercism/note
`print` es una **sentencia**, no una función.
`print` no requiere paréntesis.
~~~~

AWK tiene un montón de [funciones para manipular strings][funcs-string].
Las iremos viendo en profundidad a medida que avanzamos por el track.

## Conversión entre números y strings

No existen operadores explícitos para convertir entre números y strings.
AWK lo hace de forma implícita según el contexto del programa.
Esto hace que trabajar con los valores de los campos de entrada sea muy sencillo: por lo general, AWK simplemente hace lo que quieres que haga.

* `print x + y` convertirá los valores de las variables `x` y `y` a números gracias a la operación numérica `+`.
* `print x y` convertirá los valores de las variables `x` y `y` a strings gracias a la operación de concatenación.

Si quieres ser explícito, `0 + x` da la representación numérica de _x_ y `"" x` da la representación como string de _x_.

### De strings a números

La forma en que AWK convierte un string a un número puede resultar confusa.
Una manera sencilla de pensarlo es que AWK lee «caracteres numéricos» desde el inicio de un string hasta que encuentra un carácter «no numérico».
Algunos ejemplos son:

* `"2.5"` se convierte en el número `2.5`;
* `"1e3"` se convierte en el número `1000` (notación científica);
* `"456abc"` se convierte en el número `456` (porque `a` no es un «numeral», la conversión se detiene ahí).
* `"abc789"` se convierte en el número `0` (no hay números al **inicio** del string).

Todos los detalles están [en el manual][str-to-num].

## Cómo determinar el tipo de una variable

La [función `typeof(var)`][func-typeof] devuelve el tipo como un string.

```awk
BEGIN {
    x = "42"
    print x, typeof(x)
    x = x + 1           # type conversion
    print x, typeof(x)
}
```
produce
```none
42 string
43 number
```
