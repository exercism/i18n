# Ayuda

Para obtener ayuda si tienes problemas, puedes usar uno de los siguientes recursos:

- [etiqueta `c++-faq` en StackOverflow](https://stackoverflow.com/tags/c%2b%2b-faq/info)
- [Preguntas frecuentes de C++ de isocpp.com](https://isocpp.org/faq)
- [CppReference](http://en.cppreference.com/) es una wiki de referencia sobre el lenguaje C++ y la biblioteca estándar
- [C traps and pitfalls](http://www.slideshare.net/LegalizeAdulthood/c-traps-and-pitfalls-for-c-programmers) es útil si eres principiante en C++, pero ya has programado en C
