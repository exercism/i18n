# Instrucciones

Eres el sobrecargo del barco y te encargas del inventario de la despensa. El inventario es un hashtable en el que cada clave es el nombre de un artículo y el valor es la cantidad disponible.

## 1. Construye un inventario a partir de una lista

Define `create-inventory` para que reciba una secuencia de nombres de artículos y devuelva un hashtable que asocie cada nombre único con su cantidad.

```factor
{ "coal" "wood" "wood" "diamond" "diamond" "diamond" } create-inventory .
! => H{ { "coal" 1 } { "wood" 2 } { "diamond" 3 } }
```

## 2. Agrega más artículos

Define `add-items` para que reciba un inventario y una secuencia de artículos y devuelva un inventario nuevo con las cantidades incrementadas por cada artículo de la lista. El inventario original no debe modificarse.

```factor
H{ { "coal" 1 } } { "wood" "iron" "coal" "wood" } add-items .
! => H{ { "coal" 2 } { "wood" 2 } { "iron" 1 } }
```

## 3. Disminuye las cantidades

Define `decrement-items` para que reciba un inventario y una secuencia de artículos y devuelva un inventario nuevo con las cantidades disminuidas en uno por cada artículo de la lista. Las cantidades nunca deben quedar por debajo de cero, y los artículos que todavía no estén en el inventario deben omitirse (no se insertan entradas negativas).

```factor
H{ { "coal" 3 } { "diamond" 1 } { "iron" 5 } }
{ "diamond" "coal" "iron" "iron" } decrement-items .
! => H{ { "coal" 2 } { "diamond" 0 } { "iron" 3 } }
```

## 4. Elimina un artículo por completo

Define `remove-item` para que reciba un inventario y un artículo y devuelva un inventario nuevo con ese artículo eliminado. Si el artículo no está presente, devuelve una copia sin cambios.

```factor
H{ { "coal" 2 } { "wood" 1 } { "diamond" 2 } } "coal" remove-item .
! => H{ { "wood" 1 } { "diamond" 2 } }
```

## 5. Enumera los artículos disponibles

Define `list-inventory` para que reciba un inventario y devuelva un array de pares `{ name quantity }` que contenga solo los artículos cuya cantidad sea mayor que cero, ordenados alfabéticamente por nombre.

```factor
H{ { "coal" 7 } { "wood" 11 } { "diamond" 2 } { "iron" 7 } { "silver" 0 } }
list-inventory .
! => { { "coal" 7 } { "diamond" 2 } { "iron" 7 } { "wood" 11 } }
```
