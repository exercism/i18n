# Acerca de los operadores aritméticos

## Operadores

Go admite los siguientes operadores aritméticos:

| Operador | Ejemplo        |
| -------- | -------------- |
| `+`      | `4 + 6 == 10`  |
| `-`      | `15 - 10 == 5` |
| `*`      | `2 * 3 == 6`   |
| `/`      | `13 / 3 == 4`  |
| `%`      | `13 % 3 == 1`  |

En la división entera, el residuo se descarta (por ejemplo, `5 / 2 == 2`).

El operador `+` también concatena strings: `"foo" + "bar" == "foobar"`.

## Aritmética de tipos mixtos

Go no permite operaciones aritméticas entre tipos numéricos diferentes:

```go
x := 42
n := 2.0
value := n * x // invalid operation: n * x (mismatched types float64 and int)
```

Los operandos deben ser del mismo tipo, lo que a veces requiere una conversión explícita:

```go
x := float64(42)
n := 2.0
value := n * x 
```

## Asignaciones abreviadas

Cada operador tiene una forma de asignación abreviada que actualiza la variable en su lugar:

```go
a := 1
a += 2 // same as a = a + 2 == 3

b := 2
b -= 2 // same as b = b - 2 == 0

c := 4
c *= 2 // same as c = c * 2 == 8

d := 8
d /= 2 // same as d = d / 2 == 4

e := 16
e %= 2 // same as e = e % 2 == 0
```

## Incremento y decremento

Cuando se colocan después de una variable, las sentencias de incremento (`++`) y decremento (`--`) aumentan o disminuyen en 1 su valor numérico almacenado.
Colocarlas antes de una variable es un error de sintaxis.

```go
a := 10
a++ // same as a += 1, a == 11

b := 10
b-- // same as b -= 1, b == 9
```

Como son sentencias, no devuelven un valor.
