# Acerca de

Las constantes en Gleam son una forma de darle nombres a valores. Se definen con la palabra clave `const`.

```gleam
pub const pi: Float = 3.14159

pub fn circle_area(radius: Float) -> Float {
  radius *. radius *. pi
}
```

Cuando se definen con la palabra clave `pub`, se puede acceder a las constantes del módulo desde otros módulos; de lo contrario, solo se puede acceder a ellas desde el módulo en el que se definen.
