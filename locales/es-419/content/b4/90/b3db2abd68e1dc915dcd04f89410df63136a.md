# Introducción

## Propiedades

Una propiedad en C# es un miembro de una clase que da acceso a los datos dentro de esa clase. Quienes la llaman pueden establecer o recuperar (get) los datos. Las propiedades pueden ser autoimplementadas o tener un campo de respaldo. Se componen de un descriptor de acceso set y/o un descriptor de acceso get. En algunos otros lenguajes, un «mutator» es más o menos equivalente a un descriptor de acceso set y un «accessor» es más o menos equivalente a un descriptor de acceso get, aunque la composición de la sintaxis es completamente diferente.

Al establecer una propiedad, el argumento se puede validar, formatear o manipular de alguna otra manera y, de hecho, se puede ejecutar cualquier operación programática a la que tenga acceso el código de la clase.

De manera similar, al recuperar una propiedad los datos se pueden calcular o formatear y, de nuevo, se puede ejecutar cualquier operación programática disponible para la clase.

Las propiedades tienen modificadores de acceso (`public`, `private`, etc.) igual que otros miembros de la clase, pero el descriptor de acceso set puede tener un nivel de acceso independiente del descriptor de acceso get y viceversa. Una propiedad no tiene que tener ambos descriptores de acceso, puede tener solo uno (ya sea get o set).

La sintaxis básica para expresar propiedades puede tomar dos formas:

### Propiedades respaldadas por campo o expresión:

```csharp
private int myField;
public int MyProperty
{
    get { return myField; }
    set { myField = value; }
}
```

### Propiedades autoimplementadas

```
public int MyProperty { get; private set; } = 42;
```

La inicialización es opcional.
