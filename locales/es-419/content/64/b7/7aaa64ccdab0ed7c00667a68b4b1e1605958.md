# Introducción

## Aleatoriedad

En Elixir, para elegir un elemento aleatorio de una estructura de datos enumerable (por ejemplo, una lista o un rango), usamos `Enum.random`. Esta función elige un solo elemento, y cada elemento tiene la misma probabilidad de ser elegido.

Elixir no tiene funciones propias para elegir un número de punto flotante aleatorio. Para lograrlo, tenemos que usar Erlang directamente.

## Bibliotecas de Erlang

El código de Elixir se ejecuta en la máquina virtual BEAM. BEAM forma parte del sistema de ejecución de Erlang. Inspirado por Erlang y compartiendo su entorno de ejecución, Elixir ofrece una gran interoperabilidad con las bibliotecas de Erlang. Esto significa que puedes usar bibliotecas de Erlang dentro de tu propio código de Elixir. De hecho, en la comunidad de Elixir se desaconseja escribir bibliotecas de Elixir para funcionalidades que las bibliotecas de Erlang ya ofrecen.

Como resultado, cierta funcionalidad, como las operaciones matemáticas o las funciones de temporizador, solo está disponible en Elixir a través de Erlang.

La biblioteca estándar de Erlang está disponible para usarse en nuestro código de Elixir sin necesidad de pasos adicionales.

Las funciones de Erlang se pueden llamar de la misma manera en que llamamos a las funciones de Elixir, con una pequeña diferencia. Los nombres de los módulos de Erlang son átomos en `snake_case`. Por ejemplo, para llamar a la función `pi/0` de Erlang desde el módulo `math`, se escribiría:

```elixir
:math.pi()
# => 3.141592653589793
```

Las funciones de Erlang que se usan con más frecuencia y que no tienen un equivalente en Elixir son:

- `:timer.sleep/1`, que suspende un proceso durante la cantidad de milisegundos indicada.
- `:rand.uniform/0`, que genera un número de punto flotante aleatorio `x`, donde `0.0 <= x < 1.0`.
- `:io_lib.format/2`, que ofrece formato de string al estilo de C (usando secuencias de control). Con esta función, por ejemplo, podríamos imprimir un número entero en cualquier base entre 2 y 36 o dar formato a un número de punto flotante con la precisión deseada. Ten en cuenta que esta función, como muchas funciones de Erlang, devuelve un charlist.
- El módulo `math`, que ofrece funciones matemáticas como `sin/1`, `cos/1`, `log2/1`, `log10/1`, `pow/2`, y más.

Para descubrir la biblioteca estándar de Erlang, explora el [manual de referencia de STDLIB][erl-stdlib-ref].

[erl-stdlib-ref]: https://www.erlang.org/doc/apps/stdlib/index.html
