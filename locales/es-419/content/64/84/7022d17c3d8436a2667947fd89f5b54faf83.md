# Clases abstractas

Un espectáculo de circo es una lista de actos. Los malabares, el trapecio y las acrobacias son cosas distintas con interiores distintos, pero quien arma el orden del programa solo necesita dos cosas de cada uno: cómo se llama y cuánto dura.

Una **clase abstracta** describe eso y nada más.

```sather
abstract class $ACT is
   name : STR;
   minutes : INT;
end; -- abstract class $ACT
```

Su nombre empieza con `$`. Enumera rutinas sin cuerpo: solo firmas, cada una terminando en el punto y coma. No se puede crear nada a partir de ella: no hay `create` ni `new`.

## Conformidad

Una clase real promete ser un `$ACT` al nombrarlo después de `<`:

```sather
class JUGGLING < $ACT is

   create : SAME is return new; end;

   name : STR is return "Juggling"; end;

   minutes : INT is return 5; end;

end; -- class JUGGLING
```

`<` se lee «es un». La clase debe proporcionar cada rutina que la clase abstracta enumera, con los mismos argumentos y el mismo tipo de retorno. Omitir una es un error de compilación, no una sorpresa en tiempo de ejecución.

Una clase puede agregar todo lo demás que quiera. `TRAPEZE` puede guardar una altura que ningún otro acto tiene; a la clase abstracta ni le consta ni le importa.

## Usar el tipo

`$ACT` es un tipo, así que cualquier cosa se puede declarar con él:

```sather
   acts : ARRAY{$ACT} := |#JUGGLING, #TRAPEZE(4), #TUMBLING|;
```

Ese array contiene objetos de tres clases distintas a la vez, algo que un `ARRAY{JUGGLING}` no podría.

## Despacho

```sather
   loop
      total := total + acts.elt!.minutes;
   end;
```

`acts.elt!` es un `$ACT`. Cuál `minutes` se ejecuta se decide cuando se ejecuta la línea, según lo que el objeto realmente es: `JUGGLING::minutes` para los malabares, `TRAPEZE::minutes` para el trapecio. Esa elección se llama **despacho**.

La rutina que hace la suma nunca pregunta qué tipo de acto tiene. Agregar un cuarto tipo de acto significa escribir una nueva clase y no cambiar nada más, que es la razón misma de hacerlo así.
