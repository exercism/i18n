# Instrucciones

Tu tarea es convertir descripciones de fechas de entrega en fechas de entrega _reales_, según cuándo comenzó la reunión.

Hay dos tipos de descripciones de fechas de entrega:

1. Fijas: un conjunto predefinido de palabras.
2. Variables: palabras que tienen un componente variable, pero que siguen un conjunto predefinido de patrones.

## Descripciones fijas de fechas de entrega

Hay tres descripciones fijas de fechas de entrega:

- `"NOW"`
- `"ASAP"` (lo antes posible)
- `"EOW"` (final de la semana)

La siguiente tabla muestra cómo convertirlas:

| Descripción | Inicio de la reunión          | Fecha de entrega                    |
| ----------- | ----------------------------- | ----------------------------------- |
| `"NOW"`     | -                             | Dos horas después de que comenzó la reunión |
| `"ASAP"`    | Antes de las 13:00            | Hoy a las 17:00                     |
| `"ASAP"`    | A las 13:00 o después         | Mañana a las 13:00                  |
| `"EOW"`     | Lunes, martes o miércoles     | Viernes a las 17:00                 |
| `"EOW"`     | Jueves o viernes              | Domingo a las 20:00                 |

## Descripciones variables de fechas de entrega

Hay dos patrones de descripciones variables de fechas de entrega:

- `"<N>M"` (el mes N)
- `"Q<N>"` (el trimestre N)

| Descripción | Inicio de la reunión      | Fecha de entrega                                          |
| ----------- | ------------------------- | --------------------------------------------------------- |
| `"<N>M"`    | Antes del mes N           | A las 8:00 del _primer_ día laborable del mes N de este año  |
| `"<N>M"`    | En el mes N o después     | A las 8:00 del _primer_ día laborable del mes N del próximo año |
| `"Q<N>"`    | En el trimestre N o antes | A las 8:00 del _último_ día laborable del trimestre N de este año |
| `"Q<N>"`    | Después del trimestre N   | A las 8:00 del _último_ día laborable del trimestre N del próximo año |

~~~~exercism/note
Un día laborable es lunes, martes, miércoles, jueves o viernes.

Un año tiene cuatro trimestres, cada uno con tres meses:
1. Enero/febrero/marzo
2. Abril/mayo/junio
3. Julio/agosto/septiembre
4. Octubre/noviembre/diciembre.
~~~~
