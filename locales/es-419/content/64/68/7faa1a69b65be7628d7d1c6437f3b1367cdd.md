# Anexo a las instrucciones

## Implementación

Define una única función de Go, Cost, que calcula el costo de un array de libros dado a partir de los descuentos definidos.

Usa la siguiente firma para func Cost:

```go
func Cost(books []int) int
```

Cost devolverá el costo total (después de los descuentos) en centavos.
Por ejemplo, para un solo libro, el costo es de 800 centavos, que equivalen a $8.00.
Para este ejercicio, solo se necesitan cálculos con números enteros.
