# Descripción

El ejercicio introductorio clásico.
Solo di «Hello, World!».

«Hello, World!» es el tradicional primer programa para quienes empiezan a programar en un nuevo lenguaje o entorno.

Los objetivos son simples:

- Modifica el código que te damos para que produzca el string «Hello, World!».
- Ejecuta la suite de pruebas y asegúrate de que pase.
- Envía tu solución y compruébala en el sitio web.

Si todo sale bien, estarás listo para obtener tu primer ejercicio real.
