# Apéndice de instrucciones

## Formato de salida

Imprime la secuencia de proteínas como un string terminado en nulo, con un carácter de nueva línea después de cada proteína.

Un ejemplo de salida sería `"Methionine\nPhenylalanine\nSerine\n"`

Si la entrada no es válida, imprime un string vacío.

## Registros

| Registro | Uso          | Tipo        | Descripción                             |
| -------- | ------------ | ----------- | --------------------------------------- |
| `$a0`    | entrada      | dirección   | string de entrada terminado en nulo      |
| `$a1`    | entrada/salida | dirección | string de salida terminado en nulo       |
| `$t0-9`  | temporal     | cualquiera  | se usa para almacenamiento temporal      |
