# Introducción

## Tiempo

El concepto de _tiempo_ se maneja en .NET con la estructura `DateTime`. Hay rutinas para convertir entre la hora local y UTC. Puedes realizar operaciones aritméticas con la ayuda de `TimeSpan`.

## Zona horaria

La clase `TimeZoneInfo` proporciona rutinas para manejar las diferencias entre zonas horarias. La clase `TimeZoneInfo` también contiene métodos que facilitan el trabajo con el horario de verano.

La clase `CultureInfo` admite formatos de fecha y hora que dependen de la configuración regional.

Para admitir la programación multiplataforma, la clase `RuntimeInformation` te permite detectar en qué sistema operativo se ejecuta tu código: Linux, Windows u OSX.
