# Contribuir a través de GitHub

Las contribuciones a la base de código de Exercism se hacen a través de [GitHub][github].

Como indica su nombre, GitHub usa [git][git] como sistema de control de versiones.
Si no conoces Git, el mejor recurso en línea es [Pro Git][pro-git].

Si aún no conoces GitHub ni el flujo de trabajo para contribuir, aquí tienes algunos recursos que pueden ayudarte a empezar:

- [Introducción a GitHub: curso interactivo][github-course]
- [Cómo crear un pull request en GitHub: tutorial][pr-tutorial]
- [Cómo hacer un pull request sencillo en GitHub: video de anthonywritescode][anthonywritescode]

## Guías

Puedes leer más sobre cómo asegurarte de que tu contribución sea bienvenida en la guía [Cómo hacer un gran pull request][great-pr].

También tenemos varias guías de pull request específicas de Exercism:

- [Cómo hacer un gran pull request][how-to-make-a-great-pr]
- [Guía de pull requests para colaboradores][contributors-pr-guide]
- [Guía de pull requests para mantenedores][maintainers-pr-guide]
- [Permisos de repositorio para mantenedores][maintainers-repo-permissions]
