# Introducción

En Gleam puedes usar una expresión `case` para ejecutar código de forma condicional. Con una expresión `case` puedes probar un valor contra uno o más _patrones_. Un ejemplo de esos patrones es el _patrón literal_, que hace coincidir un valor con un valor literal (por ejemplo, `1` o `"hello"`).

Las expresiones `case` se escriben con la palabra clave `case`:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    1 -> "One"
  }
}
```

Aunque esto pueda parecerse a las sentencias `switch` de otros lenguajes, la coincidencia de patrones empieza a brillar cuando también usas otros patrones. Uno de esos patrones es el _patrón de variable_, que te permite asignar un valor a una variable. En este ejemplo, a la variable `i` se le asigna el valor de `number` si no es `0`:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i -> "Non zero"
  }
}
```

En algunos casos, quizás quieras agregar una condición adicional a un patrón. Esto se conoce como _guarda_ (cláusula), que puedes agregar usando la palabra clave `if`:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i if i < 0 -> "Negative number"
  }
}
```

Por razones de rendimiento, en las guardas solo se permiten operadores matemáticos y booleanos básicos; no se pueden usar otras funciones en las guardas.

En el ejemplo anterior, no todos los valores posibles van a coincidir con un patrón. El compilador lo detectará y mostrará un error. Esto se conoce como _verificación exhaustiva_. Para resolver la advertencia, hay que manejar todos los casos. Para eso puedes usar el _patrón de descarte_, que es un patrón que coincide con cualquier valor:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i if i < 0 -> "Negative number"
    _ -> "Positive number"
  }
}

// No compiler error
```

Las expresiones `case` prueban un valor contra cada patrón de arriba a abajo, hasta encontrar un patrón que coincida y ejecutar la lógica asociada a ese patrón. ¡El orden de los patrones importa!
