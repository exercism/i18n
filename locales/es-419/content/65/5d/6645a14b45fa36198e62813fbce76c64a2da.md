# Acerca de

Un [método][methods] es una función con un argumento especial llamado _receptor_.
El receptor aparece en su propia lista de argumentos, entre la palabra clave `func` y el nombre del método.

```go
func (receiver type) MethodName(parameters) (returnTypes) {

}
```

Solo puedes definir un método con un receptor cuyo tipo esté definido en el mismo paquete que el método.

```go
type Person struct {
	Name string
}

func (p Person) Greetings() string {
	return fmt.Sprintf("Welcome %s!", p.Name)
}

s := Person{Name: "Bronson"}
fmt.Println(s.Greetings())
// Output: Welcome Bronson!

```

Hay dos tipos de receptores: los receptores de valor y los receptores de puntero.

Los métodos con un receptor de valor operan sobre una copia del valor que se les pasa, lo que significa que cualquier modificación que se haga al receptor dentro del método no es visible para quien llama al método.

Puedes declarar métodos con receptores de puntero para modificar el valor al que apunta el receptor.
Esas modificaciones también son visibles para quien llama al método.

```go
type rect struct {
	width, height int
}

func (r *rect) squareIt() {
	r.height = r.width
}

r := rect{width: 10, height: 20}
fmt.Printf("Width: %d, Height: %d\n", r.width, r.height)
// Output: Width: 10, Height: 20

r.squareIt()
fmt.Printf("Width: %d, Height: %d\n", r.width, r.height)
// Output: Width: 10, Height: 10
```

Recuerda: un método no es más que una función con un argumento receptor.
