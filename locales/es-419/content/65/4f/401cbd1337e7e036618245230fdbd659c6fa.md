# Acerca de

Puede ser difícil encontrar un lenguaje de programación más expresivo. [Raku](https://raku.org/) es un lenguaje moderno y multiparadigma. Raku ofrece metodologías [procedurales](https://docs.raku.org/language/functions), [orientadas a objetos](https://docs.raku.org/language/objects) y de [programación funcional](https://docs.raku.org/language/functions#Functions_are_first-class_objects).

[¿Tienes curiosidad?](https://raku.org/) Profundiza en la [documentación](https://docs.raku.org/) o en el [repositorio](https://raku.land/) de módulos (como pypi o CPAN).

Es un lenguaje sumamente [flexible](https://docs.raku.org/language/operators), que se [adapta](https://docs.raku.org/language/glossary#gradual_typing) a tu estilo de programación, ya sean one-liners rápidos para administradores de sistemas, scripts para gestionar la importación de una base de datos, o la pila completa de módulos necesaria para realizar todo un [sitio web](https://cro.services/).

Raku aprende de otros lenguajes:

* Mejora el atractivo de Perl a largo plazo con un sistema de objetos apropiado que incluye [roles](https://docs.raku.org/language/typesystem#role), [hilos](https://docs.raku.org/language/concurrency) y despacho de [multimétodos](https://docs.raku.org/language/glossary#Multi-dispatch).
* Toma el manejo de hilos de Java y lo [simplifica](https://docs.raku.org/language/concurrency) a un puñado de métodos.
* Usar [interfaces de funciones externas](https://docs.raku.org/language/nativecall) de Lisp hace que acceder a las bibliotecas sea tan simple como una línea de código.
* Las [expresiones regulares](https://docs.raku.org/language/regexes) ahora llegan al 11, con la introducción de las [gramáticas](https://docs.raku.org/language/grammars) de expresiones de analizador, que te permiten abordar enormes tareas de análisis.
* Las restricciones y advertencias ahora son automáticas, lo que elimina enormes cantidades de errores potenciales.
* ... y sabe hacer [matemáticas](https://docs.raku.org/language/math): ```1/10 * 3 == 0.3 ```, ¡intenta hacer eso en tu lenguaje favorito!

Los lemas de Raku:
* «Raku está diseñado para que las tareas fáciles sean fáciles, sin hacer imposibles las difíciles.»
* «Hay más de una forma de hacerlo, ahora con aún más -Ofun (optimizado para la diversión) añadido.»
