# Clases y propiedades de solo lectura

Las clases y propiedades de solo lectura permiten que las clases especifiquen propiedades públicas para acceder a ellas con facilidad, pero impiden que se modifiquen.
Para declarar una propiedad como de solo lectura, hay que agregar `readonly` antes de la especificación del tipo.
La propiedad se puede asignar una vez, pero cualquier intento de reasignarla o de modificar el valor dará como resultado un Error.

```php
<?php

class Block
{
    public function __construct(
        public readonly int $length,
        public readonly int $width,
    ) {
    }
}
```

Las clases de solo lectura se basan en este comportamiento, y si se declaran como `readonly`, aplican la declaración de solo lectura a cada propiedad.
Además, impiden que se agreguen propiedades dinámicas.

```php
<?php

readonly class Block
{
    public function __construct(
        public int $length,
        public int $width,
    ) {
    }
}
```
