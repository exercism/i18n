# Anexo de instrucciones

## Palabras

Define una tupla `triangle` con los campos `a`, `b` y `c`.

- `<triangle> ( a b c -- triangle )`: construye un triángulo a partir de tres longitudes de lado.
- `equilateral? ( triangle -- ? )`
- `isosceles? ( triangle -- ? )`
- `scalene? ( triangle -- ? )`

Cada predicado devuelve `f` para los triángulos que no cumplen la desigualdad triangular o que tienen un lado no positivo.
