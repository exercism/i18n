# Acerca de

En Common Lisp, los valores falsos se representan con la lista vacía, `()`, o con el símbolo `nil`.
Estos valores se pueden citar o dejar sin citar.

```lisp
;; Equivalent False Values
()   ; => NIL
nil  ; => NIL
'()  ; => NIL
'nil ; => NIL
```

Todos los demás valores de Lisp representan la verdad.
También existe el símbolo constante especial `t`, que siempre es igual a `t` (y por lo tanto siempre es verdadero).

```lisp
;; Some Different True Values
42                        ; => 42
"this statement is false" ; => "this statement is false"
t                         ; => T
't                        ; => T
```
