# Acerca de

Un [`Set`][set-docs] es una colección no ordenada que, a diferencia de `List`, garantiza no contener valores duplicados.

El parámetro de tipo genérico de la interfaz `Set` denota el tipo de los elementos que contiene el `Set`:

```java
Set<Integer> ints = Set.of(1, 2, 3);
Set<String> strings = Set.of("alpha", "beta", "gamma");
Set<Object> mixed = Set.of(1, false, "foo");
```

Ten en cuenta que el método `Set.of()` crea una instancia de `Set` [_no modificable_][unmodifiable-set-docs].
Si intentas llamar a métodos como `add` y `remove` en esta instancia, obtendrás una excepción en tiempo de ejecución.

Para crear un `Set` modificable, necesitas instanciar una clase que implemente la interfaz `Set`.
La clase integrada que más se usa para implementar esta interfaz es la clase [`HashSet`][hashset-docs].

```java
Set<Integer> ints = new HashSet<>();
```

La interfaz `Set` extiende las interfaces [`Collection`][collection-docs] e [`Iterable`][iterable-docs], y por eso comparte muchos métodos con otros tipos de colecciones.
Sin embargo, una diferencia notable con la interfaz `Collection` es que métodos como `add` y `remove` devuelven un `boolean` (en lugar de `void`), que indica si el elemento ya estaba en el `Set` cuando se llamó a ese método:

```java
Set<Integer> set = new HashSet<>();
set.add(1);
// => true
set.add(2);
// => true
set.add(1);
// => false
set.size();
// => 2
set.contains(1);
// => true
set.contains(3);
// => false
set.remove(3);
// => false
set.remove(2);
// => true
set.size();
// => 1
```
