# Instrucciones

En este ejercicio vas a organizar carreras entre distintos tipos de autos a control remoto.
Cada auto tiene sus propias características y compite en muchas pistas diferentes en carreras a lo largo de la temporada del torneo.

~~~~exercism/note
Las funciones de este ejercicio se declaran en un archivo fuente de C con las firmas proporcionadas.
Tu código de ensamblador x86-64 debe seguir esas especificaciones.
~~~~

## 1. Crea un auto a control remoto

Has definido una struct `car_t` para representar un auto a control remoto:

```c
struct car_t {
    char name[10];
    int16_t speed;
    float battery;
};
```

Define una función `new_car` en ensamblador x86-64 para crear un auto a control remoto.
El campo `battery` siempre empieza con el valor `100.0`.

```c
struct car_t new_car(short speed, const char name[]);
```

## 2. Crea una pista nueva

Las pistas se representan con una struct `track_t`:

```c
struct track_t {
    enum surface_t surface;
    size_t distance;
};
```

La `enum surface_t` registra los distintos tipos de superficie de una pista:

```c
enum surface_t {
    ASPHALT,
    SAND,
    ICE,
    CLAY
};
```

Define una función `new_track` en ensamblador x86-64 para crear una pista nueva.

```c
struct track_t new_track(enum surface_t surface, size_t distance);
```

## 3. Crea un evento de carreras

Hasta 6 autos participan en cada carrera, dando un número determinado de vueltas en una pista.
Las carreras se representan con una struct `race_t`:

```c
struct race_t {
    struct track_t track;
    uint8_t num_of_laps;
    struct car_t cars[6];
    uint8_t num_of_running_cars;
};
```

Define una función `new_race` en ensamblador x86-64.
Al principio, no hay autos confirmados para participar en la carrera:

```c
struct race_t new_race(struct track_t track, uint8_t num_of_laps);
```

## 4. Confirma un auto para la carrera

Cuando el dueño de un auto pide que participe en una carrera, su participación solo se confirma si la lista aún no está llena.

Define una función `add_participant` en ensamblador x86-64.
Si hay espacio para un participante más en la carrera, el auto se agrega a la lista, se actualiza el contador y su participación queda confirmada.
De lo contrario, los organizadores de la carrera deben informarle al dueño del auto que esta vez no puede participar.

```c
bool add_participant(struct race_t *race, struct car_t car);
```

## 5. Crea un torneo

Llevas un registro de las carreras programadas para la temporada en una struct `tournament_t`:

```c
struct tournament_t {
    struct race_t races[20];
    size_t num_of_races;
};
```

Define una función `add_race` en ensamblador x86, para agregar una carrera al array del torneo y también actualizar su contador.
Puedes dar por hecho que siempre habrá espacio suficiente en el array `races` para la nueva carrera.

```c
void add_race(struct tournament_t *tournament, struct race_t race);
```
