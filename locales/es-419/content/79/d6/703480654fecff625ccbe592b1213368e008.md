Tu trabajo es escribir el código que te permita desarmar la bomba fétida del baile antes de que estalle.

## 1. Escribe un closure para intercambiar dos cables

Cada bomba fétida tiene tres cables de distintos colores.
Escribe un closure que reciba una tupla `(String, String, String)` y devuelva la tupla con el orden de los dos primeros elementos invertido.
Asigna este closure al nombre `flip`.

Es importante tener en cuenta que el tipo debe ser `ChangeClosure` (o un tipo sendable); la definición del tipo está en el archivo stub.
De lo contrario, el código no compilará.

```swift
flip(("red", "yellow", "blue"))
// Returns ("yellow", "red", "blue")
```

## 2. Escribe un closure para rotar los cables

Escribe un closure que reciba una tupla `(String, String, String)` y devuelva la tupla con el orden de los cables rotado hacia la izquierda.
Asigna este closure al nombre `rotate`.

Es importante tener en cuenta que el tipo debe ser `ChangeClosure` (o un tipo sendable); la definición del tipo está en el archivo stub.

```swift
rotate(("red", "yellow", "blue"))
// Returns ("yellow", "blue", "red")
```

## 3. Implementa un generador de mezcla de cables

Para determinar el orden en que hay que cortar los cables de la bomba fétida, tendrás que implementar una función que genere la función de mezcla adecuada a partir del número de identificación de la bomba fétida.

Implementa la función:

```swift
makeShuffle(
  flipper: @escaping ((String, String, String)) -> (String, String, String),
  rotator: @escaping ((String, String, String)) -> (String, String, String)
) -> ([UInt8], (String, String, String)) -> (String, String, String)
```

que recibe como entrada un closure que intercambia dos cables y un closure que rota los tres cables, y devuelve un closure.
Este closure devuelto recibe el número de identificación de la bomba fétida y el orden de los tres cables, y luego calcula el orden en que hay que cortarlos.
El número de identificación está formado por ocho bits, y cada bit determinará si se deben intercambiar o rotar los cables.

Para cada bit del número de identificación, empezando por el bit de la derecha, aplicarás el closure `flipper` a la tupla de cables si el bit es 0, y aplicarás el closure `rotator` si es 1, lo que da el nuevo estado de los cables.
Después de aplicar los closures correspondientes a los ocho bits del número de identificación, el estado final de los cables es el orden en que hay que cortarlos.

```swift
let shuffler = makeShuffle(flipper: flip, rotator: rotate)
// Returns ([UInt8], (String, String, String)) -> (String, String, String)
shuffler([1, 0, 0, 1, 1, 0, 1, 1], ("red", "yellow", "blue"))
// Returns ("red", "blue", "yellow")
```
