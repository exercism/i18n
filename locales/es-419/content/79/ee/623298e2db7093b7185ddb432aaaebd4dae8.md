# Anexo de instrucciones

## Formatos de salida

Se espera que la función `treeFromTraversals` devuelva un objeto con 3 propiedades:

- `value`: el valor del nodo actual
- `left`: un objeto que contiene el hijo izquierdo del nodo
- `right`: un objeto que contiene el hijo derecho del nodo

```javascript
{
    value: 'a',
    left: { value: 'i', left: {}, right: {} },
    right: { value: 'x', left: {}, right: {} },
}
```

Si el árbol está vacío, se debe devolver un objeto vacío.
