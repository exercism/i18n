# Anexo a las instrucciones

## Mensajes de excepción

En ocasiones es necesario [lanzar una excepción](https://docs.python.org/3/tutorial/errors.html#raising-exceptions). Cuando lo hagas, siempre debes incluir un **mensaje de error significativo** para indicar cuál es el origen del error. Esto hace que tu código sea más legible y ayuda mucho con la depuración. Para situaciones en las que sabes que el origen del error será de un tipo determinado, puedes elegir lanzar uno de los [tipos de error integrados](https://docs.python.org/3/library/exceptions.html#base-classes), pero aún así debes incluir un mensaje significativo.

Este ejercicio en particular requiere que uses la [sentencia raise](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement) para «lanzar» múltiples `ValueErrors` si se le pasa a la clase `Tree()` un árbol que no se puede reorientar, o si no se puede encontrar una ruta entre un `start node` y un `end node`. 
Las pruebas solo pasarán si tanto usas `raise` para el tipo de `exception` esperado como incluyes el mensaje esperado con él.

Por favor, revisa con cuidado las pruebas y sus resultados esperados.
