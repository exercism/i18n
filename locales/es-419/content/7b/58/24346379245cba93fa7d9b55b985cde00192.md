# Introducción

Los bucles repeat-while son similares a los bucles `while`, pero con una diferencia clave: la condición se evalúa *después* de que se ejecuta el cuerpo del bucle, no antes.
Por eso, un bucle `repeat-while` garantiza que su bloque de código se ejecute al menos una vez.

```swift
repeat {
    print("This runs at least once")
} while false

print("Loop done")

// Prints:
// This runs at least once
// Loop done
```
