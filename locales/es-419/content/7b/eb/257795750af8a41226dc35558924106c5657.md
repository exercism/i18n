# Instrucciones

Dada una cuadrícula de 3 x 4 de barras verticales, guiones bajos y espacios, determina qué número se representa o si está distorsionada.

## Paso uno

Para empezar, convierte una fuente binaria simple en un string que contenga 0 o 1.

La fuente binaria usa barras verticales y guiones bajos, tiene cuatro filas de altura y tres columnas de ancho.

```text
     _   #
    | |  # zero.
    |_|  #
         # the fourth row is always blank
```

Se convierte en «0».

```text
         #
      |  # one.
      |  #
         # (blank fourth row)
```

Se convierte en «1».

Si el argumento tiene el tamaño correcto, pero no es reconocible, tu programa debe devolver «?».

Si el argumento no tiene el tamaño correcto, tu programa debe devolver un error.

## Paso dos

Actualiza tu programa para que reconozca strings binarios de varios caracteres, reemplazando los números distorsionados con «?».

## Paso tres

Actualiza tu programa para que reconozca todos los números del 0 al 9, ya sea de forma individual o como parte de un string más grande.

```text
 _
 _|
|_

```

Se convierte en «2».

```text
      _  _     _  _  _  _  _  _  #
    | _| _||_||_ |_   ||_||_|| | # decimal numbers.
    ||_  _|  | _||_|  ||_| _||_| #
                                 # fourth line is always blank
```

Se convierte en «1234567890».

## Paso cuatro

Actualiza tu programa para que maneje varios números, uno por línea. Cuando conviertas varias líneas, únelas con comas.

```text
    _  _
  | _| _|
  ||_  _|

    _  _
|_||_ |_
  | _||_|

 _  _  _
  ||_||_|
  ||_| _|

```

Se convierte en «123,456,789».
