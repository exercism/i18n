Elixir tiene convenciones de nombres específicas que incluyen cómo nombrar las [funciones que devuelven un Boolean](https://hexdocs.pm/elixir/naming-conventions.html#trailing-question-mark-foo):

> Las funciones que devuelven un Boolean se nombran con un signo de interrogación al final.

```elixir
# this is the expected name of functions that return a boolean

%{expected}

# this is the current name

%{actual}
```

Ten en cuenta que las guardas, algunas funciones integradas y macros que devuelven Boolean y que son válidas en guardas siguen otra convención y se nombran con el prefijo `is_` (`def is_integer`, `defguard is_foo`, `defmacro is_foo`). Ambas convenciones no deben mezclarse.
