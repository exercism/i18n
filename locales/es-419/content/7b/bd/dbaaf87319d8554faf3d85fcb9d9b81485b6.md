# Introducción

Cairo no tiene un tipo nativo para strings, pero ofrece dos formas de manejarlos: strings cortos con comillas simples y `ByteArray` con comillas dobles.

Un string corto es una cadena de caracteres ASCII donde cada carácter se codifica en un byte.

El tipo que Cairo usa para los strings cortos por defecto es `felt252`, lo que hace que su longitud máxima sea de solo 31 caracteres.

```rust
// below are different ways to write the same value
let name: felt252 = 'Jane';     // short string format
let name: felt252 = 0x4a616e65; // byte format
let name: felt252 = 1247899237; // decimal format
```

Técnicamente, cualquier tipo entero menor que `felt252` se puede representar usando el formato de string corto.

```rust
// all of the below are equal u8 values, they are just written using different formats!
let lowercase_a_in_ascii: u8 = 'a';  // short string format
let lowercase_a_in_ascii: u8 = 0x61; // byte format
let lowercase_a_in_ascii: u8 = 97;   // decimal format
```

Para strings de más de 31 caracteres, Cairo ofrece `ByteArray`, que tiene una longitud ilimitada.

```rust
let long_string: ByteArray = "this is a string which has more than 31 characters";
```

Los ByteArrays se pueden concatenar con el operador `+`:

```rust
"Jane" + " " + "Austen"
// => "Jane Austen"
```

Algunos caracteres especiales necesitan escaparse con una barra invertida al inicio, como `\t` para un tabulador y `\n` para un salto de línea en los strings.

```rust
"How is the weather today?\nIt's sunny"  
// =>
// How is the weather today?
// It's sunny
```

Incluso puedes acceder a bytes individuales dentro de un ByteArray usando su índice.

¡Pero ten cuidado, el tipo del byte devuelto es `u8` y no `ByteArray`!

```rust
let hello: ByteArray = "Hello World!";
let exclamation_mark: u8 = hello[11];
// => 33
```

La biblioteca core ofrece muchos métodos y operadores útiles para trabajar con ByteArrays.

Para más información sobre los métodos de ByteArray, consulta la [documentación de ByteArrayTrait][docs].

Aquí tienes algunos ejemplos:

```rust
let name: felt252 = 'Jane';
let mut greeting: ByteArray = "Welcome ";

// append_word appends a single word of a given number of bytes to the end of the ByteArray 
greeting.append_word(name, 4);
// => "Welcome Jane"

// rev returns a ByteArray with the all characters reversed
let rev_greeting = greeting.rev();
// => "enaJ emocleW"
```

[docs]: https://docs.swmansion.com/scarb/corelib/core-byte_array-ByteArrayTrait.html
