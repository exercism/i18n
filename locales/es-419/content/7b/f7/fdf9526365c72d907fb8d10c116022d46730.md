# Apéndice de instrucciones

## Pistas

Necesitas implementar la función `recite`, que produce la letra de
«The Twelve Days of Christmas». Puedes usar la signatura que te damos
si tienes dudas sobre los tipos, pero no dejes que limite tu creatividad.

Este ejercicio trabaja con datos textuales. Por razones históricas, el tipo
`String` de Haskell es sinónimo de `[Char]`, una lista de caracteres. Para
manejar datos textuales de forma más eficiente, se puede usar el tipo `Text`.

Como extensión opcional de este ejercicio, puedes

- leer sobre los [tipos string](https://haskell-lang.org/tutorial/string-types) en
  Haskell.
- agregar `- text` a tu lista de dependencias en package.yaml.
- importar `Data.Text` [de la siguiente
  manera](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c):

```haskell
import qualified Data.Text as T
import           Data.Text (Text)
```

- escribir, por ejemplo, `recite :: Int -> Int -> [Text]` y referirte a los
  combinadores de `Data.Text` como, por ejemplo, `T.pack`.
- buscar la documentación de
  [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html).
- reemplazar todas las apariciones de `String` por `Text` en TwelveDays.hs, es decir:

```haskell
recite :: Int -> Int -> [Text]
```

Esta parte es totalmente opcional.
