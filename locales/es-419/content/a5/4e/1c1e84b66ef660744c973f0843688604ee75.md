# Introducción

JavaScript es un lenguaje dinámico que admite estilos orientados a objetos, imperativos y declarativos (por ejemplo, la programación funcional).

## Asignación y reasignación

En JavaScript hay algunas formas principales de asignar valores a nombres: usar variables o constantes. En Exercism, las variables siempre se escriben en [camelCase][wiki-camel-case] y las constantes en [SCREAMING_SNAKE_CASE][wiki-snake-case]. No hay una guía oficial que seguir, y distintas empresas y organizaciones tienen distintas guías de estilo. _No dudes en escribir las variables como quieras_. La ventaja de escribirlas como están preparados los ejercicios es que se resaltarán de forma diferente en la interfaz web y en la mayoría de los IDE.

Las variables en JavaScript se pueden definir con la palabra clave [`const`][mdn-const], [`let`][mdn-let] o [`var`][mdn-var].

Una variable puede referenciar distintos valores a lo largo de su vida útil cuando usas `let` o `var`. Por ejemplo, `myFirstVariable` se puede definir y redefinir muchas veces con el operador de asignación `=`:

```javascript
let myFirstVariable = 1;
myFirstVariable = 'Some string';
myFirstVariable = new SomeComplexClass();
```

A diferencia de `let` y `var`, las variables que se definen con `const` solo se pueden asignar una vez. Esto se usa para definir constantes en JavaScript.

```javascript
const MY_FIRST_CONSTANT = 10;

// Cannot be re-assigned.
MY_FIRST_CONSTANT = 20;
// => TypeError: Assignment to constant variable.
```

> 💡 En un ejercicio de aprendizaje posterior, se explora y se explica la diferencia entre la asignación o vinculación de una _constante_ y el valor de una _constante_.

## Declaración de funciones

En JavaScript, las unidades de funcionalidad se encapsulan en _funciones_, que normalmente se agrupan en el mismo archivo si van juntas. Estas funciones pueden recibir parámetros (argumentos) y pueden _devolver_ un valor con la palabra clave `return`. Las funciones se llaman con la sintaxis `()`.

```javascript
function add(num1, num2) {
  return num1 + num2;
}

add(1, 3);
// => 4
```

> 💡 En JavaScript hay _muchas_ formas distintas de declarar una función. Esas otras formas se ven diferentes a usar la palabra clave `function`. El track intenta presentarlas de forma gradual, pero si ya las conoces, no dudes en usar la que quieras. En la mayoría de los casos, usar una u otra no es mejor ni peor.

## Exponer a otros archivos

Para que una `function`, una constante o una variable estén disponibles en _otros archivos_, hay que [exportarlas][mdn-export] con la palabra clave `export`. Otro archivo puede entonces [importarlas][mdn-import] con la palabra clave `import`. A esto también se le conoce como el sistema de módulos. Un gran ejemplo es cómo funcionan todas las pruebas. Cada ejercicio tiene al menos un archivo, por ejemplo `lasagna.js`, que contiene la _implementación_. Además, hay al menos otro archivo, por ejemplo `lasagna.spec.js`, que contiene las _pruebas_. Este archivo _importa_ las entidades públicas (es decir, exportadas) para probar la implementación:

```javascript
// file.js
export const MY_VALUE = 10;

export function add(num1, num2) {
  return num1 + num2;
}

// file.spec.js
import { MY_VALUE, add } from './file';

add(MY_VALUE, 5);
// => 15
```
