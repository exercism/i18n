# Introducción

Los caracteres en Factor son enteros (puntos de código Unicode), así que los `<`, `>`, `=` numéricos te dan directamente un orden sensible a mayúsculas y minúsculas. El vocabulario [`unicode`][unicode] agrega predicados que entienden Unicode y la conversión de mayúsculas y minúsculas de un solo carácter.

## Predicados de caracteres

```
LETTER?  ( c -- ? )    ! uppercase letter
letter?  ( c -- ? )    ! lowercase letter
Letter?  ( c -- ? )    ! letter, either case
digit?   ( c -- ? )    ! decimal digit
digit>   ( c -- n )    ! the integer value of a digit char
blank?   ( c -- ? )    ! whitespace
```

```factor
USING: unicode ;

CHAR: A LETTER? .    ! => t
CHAR: a letter? .    ! => t
CHAR: 7 digit?  .    ! => t
CHAR: 7 digit>  .    ! => 7
```

## Conversión de mayúsculas y minúsculas

`ch>upper` y `ch>lower` cambian un solo carácter. Las versiones para cadenas, `>upper` y `>lower`, las aplican a cada carácter de una cadena.

```factor
CHAR: a ch>upper .   ! => 65   (which is CHAR: A)
"Hello" >upper .     ! => "HELLO"
```

`capitalize` convierte toda una cadena a minúsculas y luego pone en mayúscula su primer carácter, es decir, el formato de título de una sola palabra:

```factor
"hELLO" capitalize .   ! => "Hello"
```

## Literales de caracteres

`CHAR: A` se interpreta como el punto de código entero de `A`. Para caracteres con nombre, usa los nombres `space`, `tab`, `\n`, etc.:

```factor
CHAR: A .        ! => 65
CHAR: space .    ! => 32
CHAR: \n .       ! => 10
```

## Símbolos

Cuando una palabra necesita devolver una etiqueta en lugar de un valor (por ejemplo, `yes`/`no`/`maybe` en lugar de un Boolean), declara cada etiqueta como un *símbolo*. Un símbolo es una palabra que se empuja a sí misma cuando se llama, y dos símbolos se consideran iguales solo cuando son el mismo nombre.

```factor
USING: kernel ;

SYMBOLS: yes no maybe ;

yes .    ! => yes
yes yes = .    ! => t
yes no = .     ! => f
```

`SYMBOL: name` declara uno; `SYMBOLS: a b c ;` declara varios.
