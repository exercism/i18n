# Acerca de

Las funciones para manejar la entrada y la salida las proporciona el [módulo `IO`][module-io].

- [`IO.puts/2`][io-puts] escribe un string en la salida estándar, seguido de un salto de línea. Devuelve `:ok`.
- [`IO.write/2`][io-write] escribe un string en la salida estándar, sin agregar un salto de línea. Devuelve `:ok`.
- [`IO.gets/2`][io-gets] lee una línea de la entrada estándar.
- [`IO.inspect/2`][io-inspect] escribe cualquier cosa en la salida estándar y acepta opciones útiles como `:label`. Devuelve sin cambios el valor que recibió. Es útil para depurar.

## El protocolo `String.Chars`

Si intentas pasarle a [`IO.puts/2`][io-puts] un valor que no puede imprimir, verás un error `Protocol.UndefinedError`.

```elixir
IO.puts({:ok, 7})
# ** (Protocol.UndefinedError) protocol String.Chars not implemented for {:ok, 7} of type Tuple
```

Cuando esto ocurra, quizá quieras usar [`IO.inspect/2`][io-inspect] en su lugar.

## `IO.inspect/2` para depurar

[`IO.inspect/2`][io-inspect] es perfecto para depurar porque devuelve su argumento sin cambios, puede imprimir cualquier cosa y ofrece una opción `:label`.

```elixir
"HELLO\n"
|> String.trim()
|> IO.inspect(label: "step 1")
|> String.downcase()
|> IO.inspect(label: "step 2")

# > step 1: "HELLO"
# > step 2: "hello"
# => "hello"
```

## Dispositivos de IO

El primer argumento de todas esas funciones es un [dispositivo de IO][io-devices], cuyo valor predeterminado es `:stdio` (entrada/salida estándar). Para escribir en el dispositivo de error estándar, usa `:stderr` en su lugar. Un dispositivo de IO también puede ser un proceso, por ejemplo uno creado al llamar a [`File.open/2`][file-open], lo que permitiría escribir en un archivo.
