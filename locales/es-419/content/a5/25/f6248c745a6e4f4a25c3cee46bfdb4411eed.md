# Acerca de

Un diccionario (`dict`) en Python es una estructura de datos que asocia _claves_ [hashables][term-hashable] con _valores_ y se conoce en otros lenguajes de programación como [tabla hash][hashtable-wikipedia] redimensionable, hashmap o [array asociativo][associative-array].
Los diccionarios son el único [tipo de mapeo][mapping-types-dict] integrado de Python.

Las `keys` deben ser hashables y únicas en todo el diccionario.
Los tipos de clave pueden incluir `number`s, `str`s o `tuple`s (de valores _inmutables_).
No pueden contener estructuras de datos _mutables_ como `list`s, `dict`s o `set`s.
A partir de Python 3.7, se garantiza que el orden de las claves de un `dict` es el orden en que se insertan las entradas.

Los `values` pueden ser de cualquier tipo o estructura de datos.
Los valores también pueden anidarse _de forma arbitraria_, por lo que pueden incluir arrays de arrays, subdiccionarios y otras estructuras de datos personalizadas o compuestas.

Dada una `key`, los diccionarios pueden recuperar un `value` en tiempo constante (en promedio), _sin importar el número de entradas_.
En comparación con buscar un valor dentro de un `list` o un `array` (_sin conocer la posición del `index`_), un `dict` usa bastante más memoria, pero su recuperación es muy rápida.

Los diccionarios son especialmente útiles en escenarios donde la colección de elementos es grande y se debe acceder a ella y actualizarla con frecuencia.

## Construcción de diccionarios

Los diccionarios se pueden crear de muchas maneras distintas, entre ellas:
 - Usar el método de clase [`fromkeys()`][fromkeys].
 - Usar [comprensiones de diccionarios][dict-comprehensions].
 - Fusionar dos diccionarios mediante desempaquetado (`**`).
 - Fusionar diccionarios con el operador `|` (_update_).
 - Usar un bucle para agregar entradas de forma iterativa a un `dict` vacío creado antes.

Los dos métodos más directos son el _constructor_ de diccionarios y el _literal_ de diccionario.

### El constructor de diccionarios

`dict()` (_el constructor de la clase `dict`_) se puede usar con cualquier iterable de pares `key`, `value`.
También se puede llamar con una serie de _argumentos_ `<name>=<value>`:

```python
# Passing a list of key,value tuples.
>>> wombat = dict([('name', 'Wombat'),
...              ('speed', 23),
...              ('land_animal', True)])
{'name': 'Wombat', 'speed': 23, 'land_animal': True}


# Using key=value arguments.
>>> bear = dict(name="Black Bear",
...             speed=40,
...             land_animal=True)
{'name': 'Black Bear', 'speed': 40, 'land_animal': True}
```

La [documentación sobre los `dict`s][dicts-docs] describe variaciones y opciones adicionales en el uso del constructor.

### Literales de diccionario

Un diccionario también se puede escribir directamente como un _literal de diccionario_, usando llaves (`{}`) que encierran pares `key : value`.
Las entradas que van dentro de las `{}` también pueden aparecer en líneas separadas:

```python
>>> whale = {"name": "Blue Whale", 
             "speed": 35, 
             "land_animal": False}
{'name': 'Blue Whale', 'speed': 35, 'land_animal': False}

>>> wombat = {'name': 'Wombat',
              'speed': 23,
              'land_animal': True,
              'color': 'Brindle'}

>>> wombat
{'name': 'Wombat', 'speed': 23, 'land_animal': True, 'color': 'Brindle'}
```

### Diccionarios anidados

Los diccionarios se pueden anidar de forma arbitraria:

```python
animals = {
    "Real" : {
        "Winged" : {
            "Sparrow" : {'name': 'sparrow','speed': 12, 'land_animal': True},
            "Kestrel" : {'name': 'kestrel', 'speed': 15, 'land_animal': True}
           },
        "Legged" : {
            "Wombat" : {'name': 'Wombat', 'speed': 23, 'land_animal': True},
            "Black Bear": {'name': 'Black Bear', 'speed': 40, 'land_animal': True},
            "Polecat" : {'name': 'Polecat', 'speed': 15, 'land_animal': True}
           },
        "Other" :  {
            "Whale" : {'name': 'Blue Whale', 'speed': 35, 'land_animal': False},
            "Orca" : {'name': 'Orca', 'speed': 45, 'land_animal': False},
            "Snake" : {'name': 'Python', 'speed': 25, 'land_animal': True}
            }
        },
        
    "Imaginary": {
        "Winged" : {
            "Dragon" : {'name': 'Fire Dragon','speed': 100, 'land_animal': True},
            "Phoenix" : {'name': 'Phoenix', 'speed': 1500, 'land_animal': True}
            },
        "Legged" : {
            "Sphinx" : {'name': 'Sphinx','speed': 10, 'land_animal': True},
            "Minotaur" : {'name': 'Minotaur', 'speed': 5, 'land_animal': True}
            },
        "Other" :  {}
        }
   }
```

## Acceder a los valores de un `dict`

Puedes acceder a un `value` de un diccionario usando una _key_ entre corchetes.
Si una clave no existe en el diccionario, se lanza un `KeyError`:

```python
>>> bear["speed"]
40

>>> bear["color"]
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
KeyError: 'color'
```

Acceder a una entrada con el método `get(<key>, <default value>)` puede evitar el `KeyError`:

```python
>>> bear.get("color", 'not found')
'not found'
```

### Acceder a entradas de diccionarios anidados

Para acceder a entradas en diccionarios anidados, usa corchetes sucesivos.
Si falta una clave determinada, se lanzará el KeyError habitual:

```python
# Using the animals nested dictionary.
>>> animals["Real"]["winged"]["Kestrel"]["speed"]
15

>>> animals["Imaginary"]["winged"]["Kestrel"]["speed"]
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
KeyError: 'Kestrel'
```

Para evitar el `KeyError`, se puede usar `.get()`, pero las llamadas a `.get()` deben estar _encadenadas_:

```python
# Using the animals nested dictionary.
# Note the use of parenthesis to enable placing the 
# .get() calls on separate lines.
>>> (animals.get("Imaginary", {})
            .get("Legged", {})
            .get("Sphinx", {})
            .get("Color", "I have no idea!"))
'I have no idea!'
```

## Cambiar o agregar valores de un diccionario

Puedes cambiar el `value` de una entrada asignando a su _key_:

```python
# Assigning the value "Grizzly Bear" to the name key.
>>> bear["name"] = "Grizzly Bear"
{'name': 'Grizzly Bear', 'speed': 40, 'land_animal': True}

>>> whale["speed"] = 25
{'name': 'Blue Whale', 'speed': 25, 'land_animal': False}
```

Los nuevos pares `key`:`value` se pueden _agregar_ de la misma forma:

```python
# Adding a new "color" key with a new "tawney" value.
>>> bear["color"] = 'tawney'
{'name': 'Grizzly Bear', 'speed': 40, 'land_animal': True, 'color': 'tawney'}

>>> whale["blowholes"] = 1
{'name': 'Blue Whale', 'speed': 25, 'land_animal': False, 'blowholes': 1}
```

## Eliminar entradas de un diccionario (pop y del)

Puedes usar el método `<dict>.pop(<key>)` para eliminar una entrada del diccionario.
`<dict>.pop()` elimina el par (`key`, `value`) y devuelve el `value` para que lo uses.
Al igual que `<dict>.get()`, `<dict>.pop(<key>)` acepta un segundo argumento (_`<dict>.pop(<key>, <default value>)`_) que se devolverá si no se encuentra la `key`.
Esto evita que se lance un `KeyError`:

```python
# Using .pop() removes both the key and value, returning the value.
>>> bear.pop("name")
'Grizzly Bear'


# The "name" key is now removed from the dictionary.
# Attempting .pop() a second time will throw a KeyError.
>>> bear.pop("name")
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
KeyError: 'name'


# Using a default argument with .pop() will 
# prevent a KeyError from a missing key.
>>> bear.pop("name", "Unknown")
'Unknown'
```

También puedes usar la sentencia `del` para eliminar una o más entradas.
Se lanza un `KeyError` si la entrada que se quiere eliminar no se encuentra en el diccionario:

```python
>>> wombat = {'name': 'Wombat',
              'speed': 23,
              'land_animal': True,
              'color': 'Brindle',
              'talent': 'Singing',
              'size': 'small'}

# Remove a single entry from the dictionary.
>>> del wombat["color"]
>>> wombat
{'name': 'Wombat', 'speed': 23, 'land_animal': True, 'talent': 'Singing', 'size': 'small'}


# Remove multiple entries from the dictionary.
>>> del wombat["talent"], wombat["size"]
>>> wombat
{'name': 'Wombat', 'speed': 23, 'land_animal': True}


# Attempting a deletion of a non-existent key raises a KeyError
>>> del wombat["number_of_legs"]
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
KeyError: 'number_of_legs'
```

## Recorrer o iterar sobre un diccionario

Recorrer un diccionario con `for item in dict` o `while item` itera sobre las _keys_ de forma predeterminada.
Puedes acceder a los _values_ dentro del mismo bucle usando _corchetes_:

```python
>>> for key in bear:
...     print((key, bear[key])) # <--This prints a tuple of (key, value).
('name', 'Black Bear')
('speed', 40)
('land_animal', True)
```

También puedes usar el método `.items()`, que devuelve tuplas (`key`, `value`):

```python
# dict.items() forms (key, value tuples) that can be 
# unpacked and iterated over.
>>> for key, value in whale.items():
...     print(key, ":", value)
name : Blue Whale
speed : 25
land_animal : False
blowholes : 1
```

De manera similar, `.keys()` devuelve las `keys` y `.values()` devuelve los `values`.

Para obtener una explicación detallada de los diccionarios en Python, la [documentación oficial][dicts-docs] es un excelente punto de partida, o también puedes consultar el tutorial de [W3-Schools][how-to-dicts].

## Ampliar la funcionalidad de los diccionarios: el módulo collections

El módulo [`collections`][collections-docs] agrega funcionalidad especializada a los tipos de datos basados en colecciones estándar de Python (`dict`, `set`, `list`, `tuple`).
Tres de las clases basadas en diccionarios más útiles son:

- [`Counter`][counter-dicts] cuenta elementos automáticamente y los devuelve en un `dict` con los elementos como claves y sus conteos como valores.
- [`OrderedDict`][ordered-dicts-docs] tiene métodos especializados para organizar el orden de las entradas del diccionario.
- [`defaultdict`][default-dicts] usa un método de fábrica para establecer un valor predeterminado si no se encuentra una `key` al intentar recuperar o asignar una entrada del diccionario.
