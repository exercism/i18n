# Apéndice de instrucciones

## Memoria reservada

El búfer para el string de entrada usa los bytes 64-191 de la memoria lineal.

## Formato de la entrada

La entrada viene formateada como un solo string de tres líneas, con un salto de línea al final de cada una. Las cruces y los círculos siempre serán `X` y `O` en mayúscula.

Entonces, el tablero

```
X··
OXO
XOX
```
se codificará como

```
"X  \nOXO\nXOX\n"
```
