# Pruebas

## Instalación del ejecutor de pruebas del track de GDScript de Exercism

Necesitarás tener [Godot instalado][installation] correctamente para usar el ejecutor de pruebas.

Para compilar y probar scripts de GDScript para Exercism, Godot se ejecutará en modo «headless» desde la CLI.
Por ahora, estas instrucciones requieren Linux y bash.

### Paso 1: Instalación de la infraestructura general del ejecutor de pruebas

Para preparar el entorno de pruebas, clona [https://github.com/exercism/gdscript-test-runner][gdscript-test-runner] y mueve su contenido a `/opt/test-runner/`:

```sh
git clone https://github.com/exercism/gdscript-test-runner.git
sudo mkdir -p /opt/
sudo mv gdscript-test-runner/ /opt/test-runner/
```

### Paso 2: Descarga del script del ejecutor de pruebas para un solo ejercicio

Suponiendo que ya tienes configurada la herramienta `exercism` y que has descargado al menos un ejercicio de GDScript, esta debería haber creado una carpeta `exercism/gdscript` para alojar los ejercicios.
Guarda [el ejecutor de pruebas][test-local-gdscript-solution] en esta carpeta y marca el archivo como ejecutable, o simplemente crea un enlace a él:

```sh
cd ~/exercism/gdscript # replace with your exercism/gdscript directory
ln /opt/test-runner/bin/test-local-gdscript-solution.sh
```

## Ejecución de las pruebas

Una vez completados los pasos de instalación, deberías poder partir de cualquier directorio de ejercicio (por ejemplo, `~/exercism/gdscript/two-fer`) y ejecutar el script (que está un nivel arriba, en `../`) para probar tu solución local a ese ejercicio:

```sh
../test-local-gdscript-solution.sh
```
