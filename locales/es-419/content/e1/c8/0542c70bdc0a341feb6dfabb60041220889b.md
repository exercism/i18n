# Pistas

## General

- Lee sobre la recursión en la [guía oficial de introducción][getting-started-recursion].
- Lee sobre la recursión en [elixirschool.com][elixir-school-recursion].
- Usa funciones de múltiples cláusulas y la coincidencia de patrones.
- Intenta dividir un problema en un caso base y un caso recursivo. Por ejemplo, supongamos que quieres contar cuántas galletas hay en el frasco de galletas con un enfoque recursivo. Un caso base es un frasco vacío: tiene cero galletas. Si el frasco no está vacío, el número de galletas en el frasco es igual a una galleta más el número de galletas en el frasco después de quitar una galleta.

## 1. Verifica cuántos pájaros visitaron hoy

- Esta tarea no necesita recursión.
- Se puede acceder al primer elemento de una lista mediante la [coincidencia de patrones][getting-started-pattern-matching].

## 2. Incrementa el conteo de hoy

- Esta tarea no necesita recursión.
- Se puede acceder al primer elemento de una lista mediante la [coincidencia de patrones][getting-started-pattern-matching].

## 3. Verifica si hubo algún día sin pájaros visitantes

- Usa la recursión para iterar sobre los elementos de la lista hasta encontrar un día sin pájaros visitantes.
- El caso base es una lista vacía.

## 4. Calcula el número total de pájaros visitantes

- Usa la recursión para iterar sobre cada elemento de la lista.
- El caso base es una lista vacía.

## 5. Calcula el número de días concurridos

- Usa la recursión para iterar sobre cada elemento de la lista.
- El caso base es una lista vacía.
- Una función puede tener más de un caso recursivo.
- Usa un [guard][kernel-equal-or-greater-than] para una de las cláusulas de la función.
