# Instrucciones

En este ejercicio vas a escribir código para ayudar a una empresa de letreros a crear mensajes personalizados para sus letreros.

## 1. Crea un letrero de ocasión

Implementa el método `build_sign( )` que acepta un string como parámetro `occasion` y un string con el nombre de alguien como parámetro `name`. Los dos parámetros se van a insertar en una plantilla de string para generar el mensaje del letrero.

```abap
build_sign( occasion = 'Birthday' 
            name     = 'Rob').
" => "Happy Birthday Rob!"
```

## 2. Crea un letrero de cumpleaños

Implementa el método `build_birthday_sign( )` que acepta una edad y, según esa edad, determina parte del mensaje del letrero. Si la edad es 50 o más, el letrero incluirá la palabra _mature_; de lo contrario, incluirá la palabra _young_.

```abap
build_birthday_sign( 45 ).
" => "Happy Birthday! What a young fellow you are."
```

## 3. Crea un letrero de graduación

Implementa el método `graduation_for( )` que recibe un nombre como parámetro de tipo string y un año como parámetro numérico, y usa plantillas de string para crear una frase para un letrero que usa un salto de línea para separar las dos líneas del mensaje.

```abap
graduation_for( name = 'Hannah' 
                year = 2022 ).
" => "Congratulations Hannah!\nClass of 2022"
```

## 4. Calcula el costo de un letrero

Implementa la función `cost_of( sign currency )` que recibe un string con el contenido del letrero y un string que representa la moneda.
El letrero tiene un precio base de 20 en la moneda dada. Además, cada letra cuesta 2. (Los espacios en blanco se incluyen en el cálculo.)
La frase que se devuelve incluye el costo de crear el letrero, escrito con dos dígitos después del punto decimal, seguido del string de la moneda.

```abap
costOf( sign     = 'Happy Birthday Rob!'
        currency = 'euros');
// => "Your sign costs 58.00 euros."
```
