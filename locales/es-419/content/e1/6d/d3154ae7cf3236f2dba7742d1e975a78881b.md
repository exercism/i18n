# Tests

Ve al directorio que contiene el archivo `${slug}_test.sql` correspondiente, donde `${slug}` es el nombre del ejercicio, escrito con guiones en lugar de espacios y todo en minúsculas (por ejemplo, `hello-world_test.sql` para el ejercicio `Hello World`).

```bash
sqlite3 -bail < ${slug}_test.sql
```

Puedes usar sentencias `SELECT` para depurar.
La salida se enviará a `user_output.md` y se mostrará en el editor web si los tests fallan.

Puedes encontrar más información en la [documentación de la track de SQLite sobre los tests](https://exercism.org/docs/tracks/sqlite/tests).
