# Pistas

## General

- Todas las palabras que necesitas están en los vocabularios [`math`][math] y
  [`math.functions`][math.functions]. Agrégalas a tu línea
  `USING:`.

## 1. Estima el valor después del intercambio

- Usa `/` (efecto de pila `( x y -- x/y )`) para dividir el presupuesto entre el tipo de cambio.

## 2. Calcula cuánto dinero queda después de un intercambio

- Usa `-` para restar.

## 3. Calcula el valor de los billetes

- Usa `*` para multiplicar.

## 4. Calcula la cantidad de billetes

- El `amount` puede ser un número de punto flotante; necesitas un resultado entero.
- Una opción: primero convierte el monto a un entero con
  `floor >integer`, y después divide con `/i`.
- Otra alternativa: usa `/i` directamente (para un denominador entero
  también trunca el número de punto flotante) y luego convierte con `>integer`.

## 5. Calcula lo que sobra después de cambiar a billetes

- Usa `mod` para el residuo.

## 6. Calcula el valor después del intercambio

- Calcula el tipo de cambio *total*: toma `spread` por ciento de
  `exchange-rate` y súmalo a `exchange-rate`.
- Después llama a `exchange-money` con el presupuesto y el tipo de cambio total.
- Después llama a `number-of-bills` para redondear hacia abajo a un número entero de
  billetes de la denominación dada.
- Después llama a `value-of-bills` para obtener el valor final.
- Los cuatro subcálculos se encadenan de forma natural; si el manejo de la pila
  empieza a resultarte incómodo, la forma de locales (`::` con parámetros con nombre)
  está bien aquí.
