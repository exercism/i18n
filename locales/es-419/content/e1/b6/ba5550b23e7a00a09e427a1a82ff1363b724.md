# Introducción

## Números

Go incluye tipos numéricos básicos que pueden representar conjuntos de valores enteros o de punto flotante.
Hay diferentes tipos según el tamaño del valor que necesites y la arquitectura de la computadora donde se ejecute la aplicación (por ejemplo, de 32 y 64 bits).

Para este ejercicio solo vas a trabajar con:

- `int`: por ejemplo, `0`, `255`, `2147483647`.
  Un entero con signo de al menos 32 bits de tamaño (rango de valores: -2147483648 a 2147483647).
  Pero esto dependerá de la arquitectura del sistema.
  La mayoría de las computadoras modernas son de 64 bits, por lo tanto `int` tendrá un tamaño de 64 bits (rango de valores: -9223372036854775808 a 9223372036854775807).

- `float64`: por ejemplo, `0.0`, `3.14`.
  Contiene el conjunto de todos los números de punto flotante de 64 bits.

- `uint`: por ejemplo, `0`, `255`.
  Un entero sin signo que tiene el mismo tamaño que `int` (rango de valores: de 0 a 4294967295 para 32 bits y de 0 a 18446744073709551615 para 64 bits).

Los números se pueden convertir a otros tipos numéricos mediante la conversión de tipos.

## Operadores aritméticos

Go admite muchos operadores aritméticos estándar:

| Operador | Ejemplo        |
| -------- | -------------- |
| `+`      | `4 + 6 == 10`  |
| `-`      | `15 - 10 == 5` |
| `*`      | `2 * 3 == 6`   |
| `/`      | `13 / 3 == 4`  |
| `%`      | `13 % 3 == 1`  |

En la división de enteros, se descarta el residuo (por ejemplo, `5 / 2 == 2`).

Go tiene asignación abreviada para los operadores anteriores (por ejemplo, `a += 5` es una forma corta de `a = a + 5`).
Go también admite las sentencias de incremento y decremento `++` y `--` (por ejemplo, `a++`).

## Conversión entre tipos

La conversión entre tipos se hace mediante una función con el nombre del tipo al que quieres convertir.
Por ejemplo:

```go
var x int = 42 // x has type int
f := float64(x) // f has type float64 (ie. 42.0)
var y float64 = 11.9 // y has type float64
i := int(y) // i has type int (ie. 11)
```

## Operaciones aritméticas entre tipos diferentes

En muchos lenguajes puedes realizar operaciones aritméticas con variables de tipos diferentes, pero en Go esto da un error.
Por ejemplo:

```go
var x int = 42

// this line produces an error
value := float32(2.0) * x // invalid operation: mismatched types float32 and int

// you must convert int type to float32 before performing arithmetic operation
value := float32(2.0) * float32(x)
```
