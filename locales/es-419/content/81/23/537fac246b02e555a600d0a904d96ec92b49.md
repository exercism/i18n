# Acerca de

Como todos los tipos de datos estándar de Clojure son inmutables, este ofrece *tipos de referencia*, que permiten una mutación controlada. Los más simples y los más usados de ellos se llaman átomos.

Los átomos se crean con la función `atom`, que recibe un valor inicial:

```clojure
(def players (atom ()))
```

El valor actual del átomo se desreferencia con `deref` o con la forma abreviada `@`:

```clojure
@players
;;=> ()
```

El valor actual del átomo `players` se puede modificar con `swap!`, que actualiza el valor al aplicar una función:

```clojure
(swap! players conj :player1)
;;=> (:player1)
```

La función `reset!` reemplaza el valor de un átomo sin tener en cuenta su valor actual:

```clojure
(reset! players ())
```
