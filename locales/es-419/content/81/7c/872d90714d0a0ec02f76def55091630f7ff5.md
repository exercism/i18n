# Instrucciones

Tu tarea es determinar si una oración es un pangrama.

Un pangrama es una oración que usa cada letra del alfabeto al menos una vez.
No distingue entre mayúsculas y minúsculas, así que no importa si una letra está en minúscula (por ejemplo, `k`) o en mayúscula (por ejemplo, `K`).

Para este ejercicio, una oración es un pangrama si contiene cada una de las 26 letras del alfabeto inglés.
