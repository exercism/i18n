# Introducción

## Enteros

En Elixir hay dos tipos diferentes de números: los enteros y los números de punto flotante.

Los enteros son números sin parte decimal.

```elixir
integer = 3
# => 3
```

## Números de punto flotante

Un número de punto flotante es un número con uno o más dígitos detrás del separador decimal. Usan el formato de punto flotante de doble precisión de 64 bits.

```elixir
float = 3.45
# => 3.45
```

### Cómo trabajar con números

En los módulos [`Integer`][integer-functions] y [`Float`][float-functions] puedes encontrar algunas funciones útiles para trabajar con esos tipos. Los operadores aritméticos básicos se definen en el módulo [`Kernel`][kernel-arithmetic-operators].

### Conversión

Los enteros y los números de punto flotante se pueden mezclar en una misma expresión aritmética. Usar un número de punto flotante en una expresión asegura que el resultado también sea un número de punto flotante.

```elixir
2 * 3
# => 6

2 * 3.0
# => 6.0
```

Sin embargo, al hacer una división, el resultado siempre será un número de punto flotante, incluso si solo se usan enteros.

```elixir
6 / 2
# => 3.0
```

Para convertir un número de punto flotante a un entero, puedes descartar la parte decimal con [`trunc/1`][trunc-1].
