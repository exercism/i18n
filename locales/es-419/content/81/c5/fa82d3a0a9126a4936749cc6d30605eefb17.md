# Instrucciones

Un nuevo club de poesía abrió en la ciudad y estás pensando en asistir.
Como ha habido incidentes en el pasado, el club tiene una política de entrada muy específica que tendrás que dominar antes de intentar entrar.

En el club de poesía hay dos puertas, una delantera y una trasera, y ambas están custodiadas.
Para poder entrar, tendrás que descubrir la contraseña del día.

La contraseña siempre se basa en un poema y se puede obtener con un proceso de dos pasos.

1. El guardia recitará el poema, una línea a la vez, y tú tendrás que responder con la letra correspondiente de esa línea.
2. Luego el guardia te dirá todas las letras con las que respondiste de una sola vez, y tú tendrás que escribirlas en un papel con un formato específico.

Los detalles del proceso dependen de a qué puerta intentes entrar.

~~~~exercism/note
Todos los strings de este ejercicio estarán codificados en ASCII y terminados en NUL.
Esto significa que todos los caracteres usan codificación ASCII y que cada string termina cuando se encuentra el '\0' (el carácter NUL, con valor `0`).
~~~~

~~~~exercism/note
Estas son las instrucciones de string mencionadas en este concepto:

| instrucción  | qué hace                                                                                                      |
|--------------|-------------------------------------------------------------------------------------------------------------------|
| `lods`       | carga un valor desde una ubicación de memoria indicada por `rsi` en `rax`                                                |
| `stos`       | almacena un valor de `rax` en una ubicación de memoria indicada por `rdi`                                               |
| `movs`       | copia un valor desde una ubicación de memoria indicada por `rsi` y lo almacena en una ubicación de memoria indicada por `rdi`    |

Todas deben llevar un sufijo que indique el tamaño de la operación:

| sufijo | tamaño             |
|--------|------------------|
| `b`    | byte             |
| `w`    | word (2 bytes)   |
| `d`    | dword (4 bytes)  |
| `q`    | qword (8 bytes)  |

Todas las instrucciones de string también modifican las direcciones de `rsi` y/o `rdi` (solo en aquellos registros que la instrucción usa).
Por defecto, incrementan las direcciones en el tamaño de la operación.

El prefijo `rep` se puede agregar a cualquiera de las instrucciones de string anteriores para repetirla una cantidad de veces igual a `rcx`.
~~~~

## 1. Obtén la primera letra de una oración

Para determinar las letras de la contraseña de la puerta delantera, debes responder con la primera letra de la línea del poema que el guardia te recite.

Para obtener una contraseña bonita, a los miembros del club de poesía les gusta usar poemas _acrósticos_.
Esto significa que la primera letra de cada oración forma una palabra.
Aquí hay un ejemplo de uno de sus escritores favoritos, Michael Lockwood.

```text
Stands so high
Huge hooves too
Impatiently waits for
Reins and harness
Eager to leave
```

Entonces, cuando el guardia recite **Stands so high**, responderás **S**; cuando recite **Huge hooves too**, responderás **H**.

Implementa la función `front_door_response` que recibe como argumento la dirección en memoria de una línea del poema y devuelve la primera letra de esa línea.
Esta letra debe devolverse como un carácter codificado en ASCII, que ocupa 1 byte.

```c
front_door_response("Stands so high");
// => 'S'
```

## 2. Capitaliza una palabra

Ya que tienes todas las letras correctas, lo único que necesitas hacer para obtener la contraseña de la puerta delantera es capitalizar correctamente la palabra.

Implementa la función `front_door_password` que recibe como argumento la dirección en memoria de un string que contiene solo las letras combinadas que encontraste en la tarea 1.
Debe modificar el string de entrada [in situ][in-place], para capitalizarlo correctamente.
Esto significa que el string correcto debe guardarse en la misma ubicación de memoria que la entrada.

La función no tiene valor de retorno.

```c
front_door_password('SHIRE');
// => buffer == "Shire"

front_door_password('shire');
// => buffer == "Shire"
```

## 3. Obtén la última letra de una oración

Para determinar las letras de la contraseña de la puerta trasera, debes responder con la última letra de la línea del poema que el guardia te recite.

Los miembros del club de poesía son muy ingeniosos.
El poema mencionado antes también es _telestico_, lo que significa que la última letra de cada oración también forma una palabra:

```text
Stands so high
Huge hooves too
Impatiently waits for
Reins and harness
Eager to leave
```

Cuando el guardia recite **Stands so high**, responderás **h**; cuando recite **Huge hooves too**, responderás **o**.

Ten en cuenta que a veces el guardia hace pausas estilísticas (en forma de puntuación o espacios en blanco) al recitar el poema.
Deberás ignorar esas pausas para obtener la letra correcta.

Implementa la función `back_door_response` que recibe como argumento la dirección en memoria de una línea del poema y devuelve la última letra de esa línea.
Esta letra debe devolverse como un carácter codificado en ASCII, que ocupa 1 byte.

```c
back_door_response('Stands so high');
// => "h"

back_door_response('Stands ... so high   ');
// => "h"
```

## 4. Sé amable

Para entrar al club de poesía por la puerta trasera, debes ser muy amable.
Así que, para obtener la contraseña, esta vez debes capitalizar correctamente la palabra y agregar `", please."` al final.

Implementa la función `back_door_password` que acepta como argumentos, en este orden:

1. La dirección en memoria de un búfer donde se almacenará el string resultante.
2. La dirección en memoria de un string que contiene las letras combinadas que encontraste en la tarea 3.

La función debe almacenar la versión amable de la contraseña capitalizada en el [búfer][buffer].
Un _búfer_ es un array que se puede usar para almacenar valores en memoria y así moverlos entre distintas funciones.

Esta función no tiene valor de retorno.

```c
back_door_password("horse");
// => "Horse, please."
```
