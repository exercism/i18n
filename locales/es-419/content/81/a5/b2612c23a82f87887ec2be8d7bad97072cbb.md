# Ayuda

Para obtener ayuda si tienes problemas, puedes usar uno de los siguientes recursos:

- [The Racket Reference](http://docs.racket-lang.org/reference/index.html)
- [/r/racket](https://www.reddit.com/r/racket) es el subreddit de Racket.
- [StackOverflow](http://stackoverflow.com/questions/tagged/racket) te sirve para buscar tu problema y ver si ya se ha respondido. También puedes hacer y responder preguntas.
