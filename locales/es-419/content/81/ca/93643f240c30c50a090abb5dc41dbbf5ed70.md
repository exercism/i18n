# Acerca de

El tipo `Bool` es uno de los bloques de construcción del lenguaje.
Su propósito es describir si algo es verdadero o falso, con los valores `True` y `False` correspondientes.
El nombre `Bool` es la forma abreviada de booleano, un campo de las matemáticas relacionado con el pensamiento lógico, que debe su nombre al trabajo de George Boole.

## Operadores Boolean

Hay dos funciones y dos operadores para manipular valores de tipo `Bool`.

- `not : Bool -> Bool`
  Esta función transforma `True` en `False` y `False` en `True`.
- `(&&) : Bool -> Bool -> Bool`
  Este operador, llamado «AND», toma dos valores Boolean y devuelve `True` si ambos son `True`.
  Por ejemplo, `True && True` devuelve `True`, pero `True && False` devuelve `False`.
- `(||) : Bool -> Bool -> Bool`
  Este operador, llamado «OR», toma dos valores Boolean y devuelve `True` si al menos uno de ellos es `True`.
  Por ejemplo, `False || False` devuelve `False`, pero `True || False` devuelve `True`.
- `xor : Bool -> Bool -> Bool`
  Esta función (no operador), llamada «XOR», toma dos valores Boolean y devuelve `True` si y solo si uno es `True` y el otro es `False`.

Los operadores `&&` y `||` no tienen la misma prioridad.
La prioridad de `&&` es mayor que la de `||`, igual que ocurre con la multiplicación `*` y la suma `+`.
Como consecuencia, la expresión `True || False && False` es equivalente a `True || (False && False)`, que es distinta de `(True || False) && False`.
Mientras que la primera devuelve `True`, la segunda devuelve `False`.

## Bifurcación condicional

Los valores Boolean son sumamente útiles para crear ramas en tu código que solo se ejecutan si se cumplen ciertas condiciones.
En Elm, esto se hace con una expresión `if-then-else`, que se usa así.

```elm
if someCondition || (someOtherCondition && anotherCondition) then
    doSomething
else
    doSomethingElse
```

El valor `someCondition` puede ser cualquier expresión que devuelva un `Bool`.
Si ese valor Boolean es `True`, el código ejecutará `doSomething`.
De lo contrario, es `False` y el código ejecutará `doSomethingElse`.
La rama `else` es obligatoria, a diferencia de lo que ocurre en otros lenguajes de programación.

Si necesitas encadenar condiciones, puedes simplemente encadenar las expresiones `if-then-else`.

```elm
if someCondition then
    doSomething
else if someOtherCondition then
    doAnotherThing
else
    doSomethingElse
```
