# Instrucciones

Eres un gran aficionado a observar aves y llevas la cuenta de cuántas aves han visitado tu jardín en los últimos siete días.

Tienes seis tareas, todas relacionadas con el número de aves que visitaron tu jardín.

## 1. Comprueba cuáles fueron los conteos de la semana pasada

Para poder comparar, siempre tienes a mano una copia de los conteos de la semana pasada, que fueron: 0, 2, 5, 3, 7, 8 y 4. Implementa el método (_static_) `BirdCount.LastWeek()` que devuelve los conteos de la semana pasada:

```csharp
BirdCount.LastWeek();
// => [0, 2, 5, 3, 7, 8, 4]
```

## 2. Comprueba cuántas aves visitaron hoy

Implementa el método `BirdCount.Today()` para que devuelva cuántas aves visitaron tu jardín hoy. Los conteos de aves están ordenados por día: el primer elemento es el conteo del día más antiguo y el último es el conteo de hoy.

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.Today();
// => 1
```

## 3. Incrementa el conteo de hoy

Implementa el método `BirdCount.IncrementTodaysCount()` para incrementar el conteo de hoy:

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.IncrementTodaysCount();
birdCount.Today();
// => 2
```

## 4. Comprueba si hubo un día sin aves visitantes

Implementa el método `BirdCount.HasDayWithoutBirds()` que devuelve `true` si hubo un día en el que cero aves visitaron el jardín; de lo contrario, devuelve `false`:

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.HasDayWithoutBirds();
// => true
```

## 5. Calcula el número de aves visitantes durante los primeros días

Implementa el método `BirdCount.CountForFirstDays()` que devuelve el número de aves que han visitado tu jardín desde el comienzo de la semana, pero limita el conteo al número de días especificado desde el comienzo de la semana.

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.CountForFirstDays(4);
// => 14
```

## 6. Calcula el número de días ajetreados

Algunos días son más ajetreados que otros. Un día ajetreado es aquel en el que cinco o más aves han visitado tu jardín.
Implementa el método `BirdCount.BusyDays()` para que devuelva el número de días ajetreados:

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.BusyDays();
// => 2
```
