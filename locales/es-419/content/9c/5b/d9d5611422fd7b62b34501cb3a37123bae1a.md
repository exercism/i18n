# Introducción

Una definición de tipo crea un tipo nuevo con nombre, distinto de cualquier otro tipo, incluso de uno que tenga el mismo tipo subyacente.

## Definir tipos

Una definición de tipo empieza con la palabra clave `type`, seguida del nombre del tipo nuevo y su tipo subyacente:

```go
type File []bool
```

Aquí `File` hace referencia a una sola columna vertical de un tablero de ajedrez, que normalmente se etiqueta de la A a la H.
Cada casilla de esta columna se representa con un valor Boolean que indica si está ocupada o no.
Ahora que `File` está definido, podemos usarlo dentro de otras definiciones:

```go
type Chessboard map[string]File

board := Chessboard{
    "A": File{true, false, true},
    "B": File{false, true, false},
}
```

`Chessboard` asigna identificadores de columna a valores `File`.
Cada `File` es un slice de Boolean que representa las casillas de una sola columna del tablero.
Sin estas definiciones de tipo, `board` sería un `map[string][]bool`, lo que haría más difícil entender qué estamos representando.
