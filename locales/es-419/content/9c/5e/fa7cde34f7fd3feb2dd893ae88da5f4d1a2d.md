# Introducción

Los bucles permiten repetir bloques de código. En Rust hay tres tipos de bucles: el bucle `for`, que permite recorrer los elementos de un iterador o de una colección (técnicamente, valores de cualquier tipo que implemente el trait `IntoIterator`), el bucle `while`, que repite un bloque de código mientras se cumpla una condición, y el bucle `loop`, que repite código indefinidamente hasta que se invoca un `break` de forma explícita.
