# Introducción

Los arrays (arreglos) son el tipo de secuencia principal de longitud fija de Factor, y se escriben `{ … }`: puedes cambiar los elementos, pero no la longitud. Juntos, los vocabularios `arrays` y `sequences` te ofrecen pequeños constructores que toman valores de la pila, además de operaciones cotidianas para unir, invertir y buscar elementos.

```factor
USING: arrays sequences ;

42 1array .                ! => { 42 }
"a" "b" "c" 3array .       ! => { "a" "b" "c" }
{ { 1 2 } { 3 4 } } concat .   ! => { 1 2 3 4 }
{ 1 2 3 } reverse .            ! => { 3 2 1 }
```
