# Introducción

En Go, toda variable tiene un valor.
Declarar una variable sin asignarle un valor la establece en el valor cero de su tipo.

Los tipos básicos, incluyendo `bool`, los tipos numéricos y `string`, tienen cada uno un valor cero fijo:

| Tipo                   | Valor cero |
| ---------------------- | ---------- |
| bool                   | `false`    |
| int, int8, int64, etc. | `0`        |
| float32, float64       | `0`        |
| complex64, complex128  | `0+0i`     |
| string                 | `""`       |

Los punteros, las funciones, las interfaces, los slices, los canales y los mapas tienen cada uno un valor cero de `nil`.

Los arrays y las estructuras nunca son `nil`, porque guardan los datos directamente, no una referencia a ellos.
Cada elemento de un array y cada campo de una estructura se inicializa con el valor cero de su propio tipo.
Por ejemplo, `var a [3]int` crea el array `[0, 0, 0]`.

## Declarar valores cero

Usa `var` para declarar:

```go
var myBool bool   // false
var mySlice []int // nil
```

Usa un literal compuesto `T{}` para las estructuras:

```go
type Person struct {
    Name string
    Age  int
}

myPerson := Person{} // Person{Name: "", Age: 0}
```
