# Pistas

## 1. Desplaza los bits hacia atrás
- Crystal tiene un [operador][shifts] para desplazar bits a la izquierda.

## 2. Aplica una máscara de bits
- Crystal tiene un operador [AND bit a bit][binary].

## 3. Establece algunos bits
- Crystal tiene un operador [OR bit a bit][binary].

## 4. Invierte el XOR
- Un XOR se puede invertir aplicando un XOR sobre el mismo valor.
- Crystal tiene operadores para [NOT bit a bit][not] y [XOR][xor] bit a bit.

[shifts]: https://crystal-lang.org/reference/syntax_and_semantics/operators.html#shifts
[binary]: https://crystal-lang.org/reference/syntax_and_semantics/operators.html#binary
[not]: https://crystal-lang.org/reference/syntax_and_semantics/operators.html#other-unary-operators
[xor]: https://crystal-lang.org/reference/syntax_and_semantics/operators.html#binary
