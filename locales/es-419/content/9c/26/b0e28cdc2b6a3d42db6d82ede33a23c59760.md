# Apéndice de instrucciones

Para entender por qué trabajar con arrays en Cairo no es tan directo como en otros lenguajes de programación, conviene tener en cuenta que Cairo usa un modelo de memoria inmutable: una vez que se escribe en una celda de memoria, ya no se puede sobrescribir nunca, solo se puede leer de ella.

El lenguaje abstrae un poco esta característica, y permite declarar y usar las variables como si fueran mutables.

Aunque esto hace que escribir código sea un poco más difícil, sobre todo el código que usa el tipo `Array` (incluido `ByteArray`, que por debajo es un «array de bytes»), permite escribir programas _demostrables_ que se pueden ejecutar con confianza incluso en máquinas que no son de confianza, por lo que bien vale la pena el sacrificio.
