# Uso de `@moduledoc`

[comment]: # (This error is raised when the submission lacks @moduledoc for the Module)

Se recomienda tener un atributo [`@moduledoc`](https://hexdocs.pm/elixir/writing-documentation.html#module-attributes) para describir la intención del módulo.

- La documentación es un [ciudadano de primera clase](https://hexdocs.pm/elixir/writing-documentation.html) en Elixir: la documentación de Elixir está diseñada para que sea fácil de leer y escribir.
- Se admite la sintaxis de Markdown dentro de los atributos de documentación `@moduledoc` y `@doc`
