# Introducción

## Arrays

En Java, los arrays (arreglos) son una forma de almacenar varios valores del mismo tipo en una sola estructura.
A diferencia de otras estructuras de datos, los arrays tienen un tamaño fijo una vez creados.
Los elementos se pueden asignar a un array o recuperar de él usando un índice.
Los arrays de Java usan índices que empiezan en cero: el índice del primer elemento es 0, el del segundo es 1, etc.

Esta es la sintaxis estándar para inicializar un array:

```java
type[] variableName = new type[size];
```

El `type` es el tipo de los elementos del array, que puede ser un tipo primitivo (por ejemplo, `int`) o una clase (por ejemplo, `String`).

El `size` es la cantidad de elementos que almacenará este array (y no se puede cambiar después).
Después de crear el array, los elementos se inicializan con sus valores predeterminados (normalmente `0`, `false` o `null`).

```java
// Declare array with explicit size (size is 2)
int[] twoInts = new int[2];
```

Los arrays también se pueden definir con una notación abreviada que te permite crear el array y establecer su valor a la vez:

```java
// Two equivalent ways to declare and initialize an array (size is 3)
int[] threeIntsV1 = new int[] { 4, 9, 7 };
int[] threeIntsV2 = { 4, 9, 7 };
```

Como el compilador ahora puede saber cuántos elementos tendrá el array, se puede omitir la longitud.

Los elementos del array se pueden asignar y consultar usando una notación de índice entre corchetes:

```java
// Assign second element by index
twoInts[1] = 8;

// Retrieve the second element by index and assign to the int element
int secondElement = twoInts[1];
```

Acceder a un índice que está fuera de los índices válidos del array produce una `IndexOutOfBoundsException`.

Los arrays se pueden manipular llamando a los métodos o propiedades de una instancia de array, o usando los métodos estáticos definidos en la clase `Arrays` (que normalmente solo se usan en código genérico).
La propiedad `length` contiene la longitud de un array.
Se puede acceder a ella así:

```java
int arrayLength = someArray.length;
```

Java también incluye una práctica clase de utilidad, [`java.util.Arrays`](https://docs.oracle.com/en/java/javase/11/docs/api/java.base/java/util/Arrays.html), que tiene muchos métodos útiles relacionados con arrays (por ejemplo, `Arrays.equals`).

Java también admite los [arrays multidimensionales](https://www.programiz.com/java-programming/multidimensional-array) como `int[][] arr = new int[3][4];`, que pueden ser muy útiles.

El hecho de que un array también sea una _colección_ significa que, además de acceder a sus valores por índice, puedes recorrer _todos_ sus valores con un bucle `for-each`:

```java
char[] vowels = { 'a', 'e', 'i', 'o', 'u' };

for(char vowel: vowels) {
    // Output the vowel
    System.out.print(vowel);
}

// => aeiou
```

Si quieres tener más control sobre qué valores recorrer, puedes usar un bucle `for`:

```java
char[] vowels = { 'a', 'e', 'i', 'o', 'u' };

for (int i = 0; i < 3; i++) {
    // Output the vowel
    System.out.print(vowels[i]);
}

// => aei
```
