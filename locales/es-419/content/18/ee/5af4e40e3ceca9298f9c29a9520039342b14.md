# Introducción

Una excepción definida por el usuario es cualquier clase definida en tu código que derive de `System.Exception`. Está sujeta a todas las reglas de la herencia de clases. Además, el compilador y el entorno de ejecución del lenguaje tratan estas clases de forma especial, lo que permite lanzar y capturar sus instancias fuera del flujo de control normal, como se explica en el ejercicio `exceptions`.

Las excepciones definidas por el usuario suelen usarse para transportar información adicional, como un mensaje y otros datos relevantes, que quede disponible para las rutinas de captura.
