# Depurar localmente

Cuando ejecutas los tests del track de Bash con [Bats](https://github.com/bats-core/bats-core), Bats captura tanto STDOUT como STDERR para las aserciones de salida.

```exercism/caution
Esto funciona localmente con `bats`, pero **no** en el editor en línea de Exercism.
```

Si quieres imprimir salida de depuración sin afectar el resultado del test, escríbela en el descriptor de archivo (fd) 3.

```bash
echo 'debug message' >&3
```

Bats muestra la salida escrita en el fd 3 durante la ejecución del test, pero no incluye esa salida en aserciones como `assert_output`.

Ejemplo de ejecución:

```none
$ bats hello_world.bats
hello_world.bats
 ✓ Say Hi!
debug message
1 test, 0 failures
```

Esto es útil cuando ejecutas los tests localmente.
