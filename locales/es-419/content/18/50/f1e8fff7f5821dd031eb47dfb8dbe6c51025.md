# Introducción

Una interfaz es un tipo que contiene miembros que definen un grupo de funcionalidad relacionada. Separa los usos de una clase de su implementación, lo que permite varias implementaciones distintas o bien admitir cierto comportamiento genérico, como dar formato, comparar o convertir.

La sintaxis de una interfaz es similar a la de una clase o una estructura, salvo que los métodos y las propiedades aparecen únicamente como la firma y no se proporciona ningún cuerpo.

```csharp
public interface ILanguage
{
    string LanguageName { get; set; }
    string Speak();
}

public class ItalianTaveller : ILanguage, ICloneable
{
    public string LanguageName { get; set; } =  "Italiano";

    public string Speak()
    {
        return "Ciao mondo";
    }

    public object Clone()
    {
        ItalianTaveller it = new ItalianTaveller();
        it.LanguageName = this.LanguageName;
        return it;
    }
}
```

Todas las operaciones definidas por la interfaz se deben implementar.

Las interfaces pueden contener métodos y propiedades de instancia, entre otros miembros
