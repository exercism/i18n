# Introducción

El tipo `atom` de Elixir representa una constante fija. El valor de un átomo es simplemente su propio nombre. Esto nos da una forma segura con respecto a los tipos para interactuar con los datos. Los átomos se pueden definir así:

```elixir
# All atoms are preceded with a ':' then follow with alphanumeric snake-cased characters
variable = :an_atom
```

Internamente, los _átomos_ se representan con un número entero en una tabla de búsqueda, que se asigna automáticamente. No es posible cambiar este valor interno.
