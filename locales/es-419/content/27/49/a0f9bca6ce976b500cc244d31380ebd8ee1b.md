# Instrucciones

En este ejercicio vas a procesar líneas de log.

Cada línea de log es un string con el siguiente formato: `"[<LVL>]: <MESSAGE>"`.

Estos son los distintos niveles de log:

- `TRC` (traza)
- `DBG` (depuración)
- `INF` (información)
- `WRN` (advertencia)
- `ERR` (error)
- `FTL` (fatal)

Tienes tres tareas.

## 1. Analiza el nivel de log

Define un enum `LogLevel` que tenga seis elementos correspondientes a los niveles de log anteriores.

- `Trace`
- `Debug`
- `Info`
- `Warning`
- `Error`
- `Fatal`

Luego, implementa el método (_static_) `LogLine.ParseLogLevel()` para analizar el nivel de log de una línea de log:

```csharp
LogLine.ParseLogLevel("[INF]: File deleted")
// => LogLevel.Info
```

## 2. Admite un nivel de log desconocido

Lamentablemente, de vez en cuando algunas líneas de log tienen un nivel de log desconocido. Para manejar estas líneas de log de forma elegante, agrega un elemento `Unknown` al enum `LogLevel`, que debe devolverse cuando se analice un nivel de log desconocido:

```csharp
LogLine.ParseLogLevel("[XYZ]: Overly specific, out of context message")
// => LogLevel.Unknown
```

## 3. Convierte una línea de log al formato corto

El nivel de log de una línea de log es bastante verboso. Para reducir el espacio en disco necesario para almacenar las líneas de log, se desarrolló un formato corto: `"[<ENCODED_LEVEL>]:<MESSAGE>"`.

El nivel de log codificado es un mapeo simple de un nivel de log a un número:

- `Unknown` - `0`
- `Trace` - `1`
- `Debug` - `2`
- `Info` - `4`
- `Warning` - `5`
- `Error` - `6`
- `Fatal` - `42`

Implementa el método (_static_) `LogLine.OutputForShortLog()` que pueda generar el formato de línea de log acortado:

```csharp
LogLine.OutputForShortLog(LogLevel.Error, "Stack overflow")
// => "6:Stack overflow"
```
