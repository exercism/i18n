# Introducción

Un `string` en F# es un objeto que representa una cadena de texto inmutable como una secuencia de caracteres Unicode (letras, dígitos, signos de puntuación, etc.) y se define de la siguiente manera:

```fsharp
let fruit = "Apple"
```

Los strings se manipulan llamando a los métodos del string o usando las funciones del módulo `String`. Una vez que se ha construido un string, su valor nunca puede cambiar. Cualquier método o función que parezca modificar un string en realidad devolverá un string nuevo.

Los strings se pueden concatenar o dar formato de varias maneras.
* Puedes usar el operador `+` para concatenar:
```fsharp
let sentence = "Apple" + " is a type of fruit."
```
* Puedes usar la función `sprintf` para dar formato al texto, donde tienes marcadores de posición en un texto de formato (`%s` para un `string`) y proporcionas los valores como argumentos:
```fsharp
let sentence = sprintf "%s is a type of %s." "Apple" "fruit"
```
