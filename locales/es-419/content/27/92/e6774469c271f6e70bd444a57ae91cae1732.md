# Introducción

Los mapas en Elixir son la estructura de datos para almacenar información en pares clave-valor. En otros lenguajes, también se conocen como arrays asociativos (PHP), hashes (Perl 5, Raku) o diccionarios (Python).

Las claves y los valores pueden ser de cualquier tipo de dato, pero si la clave es un átomo podemos usar una sintaxis abreviada. Los mapas no garantizan el orden de sus entradas cuando se accede a ellas o se devuelven.

## Formas literales

Un mapa vacío se declara simplemente con `%{}`. Si queremos agregar elementos a un mapa literal, podemos usar dos formas:

```elixir
# If the key is an atom:
%{atom_key: 1}

# If the key is a different type:
%{1 => :atom_value}

# You can even mix these if the atom form comes second:
%{"first_form" => :a, atom_form: :b}
```

Aunque no existe un formato canónico, elige una manera consistente de representar los pares de clave-valor literales.

## Funciones del módulo Map

Elixir proporciona muchas funciones para trabajar con mapas en el _módulo Map_. Algunas funciones del _módulo Map_ requieren que se pase una función _anónima_ a la función para ayudar con la transformación del mapa.
