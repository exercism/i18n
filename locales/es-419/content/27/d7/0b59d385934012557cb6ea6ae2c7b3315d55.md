# Instrucciones

En este ejercicio vas a escribir algo de código para ayudarte a cocinar una lasaña espectacular del libro de cocina que más te guste.

Tienes cuatro tareas, todas relacionadas con el tiempo que se tarda en cocinar la lasaña.

~~~~exercism/note
Estas son las instrucciones que se mencionan en este concepto:

| Instrucción | Descripción                     |
|-------------|---------------------------------|
| mov a, b    | copia el contenido de b a a     |
| add a, b    | a = a + b                       |
| sub a, b    | a = a - b                       |
| imul a, b   | a = a * b                       |
| call a      | llama a la función a            |
| ret         | regresa de una función          |
~~~~

## 1. Define el tiempo esperado en el horno, en minutos

Define la función `expected_minutes_in_oven`, que no recibe ningún parámetro y devuelve cuántos minutos debe estar la lasaña en el horno.
Según el libro de cocina, el tiempo esperado en el horno es de 40 minutos:

```c
expected_minutes_in_oven();
// => 40
```

## 2. Calcula el tiempo restante en el horno, en minutos

Define la función `remaining_minutes_in_oven`, que recibe como parámetro los minutos que la lasaña ya lleva en el horno y devuelve cuántos minutos le quedan por estar en el horno, según el tiempo esperado en el horno de la tarea anterior.

```c
remaining_minutes_in_oven(30);
// => 10
```

## 3. Calcula el tiempo de preparación, en minutos

Define la función `preparation_time_in_minutes`, que recibe como parámetro la cantidad de capas que le agregaste a la lasaña y devuelve cuántos minutos tardaste en prepararla, suponiendo que cada capa te toma 2 minutos.

```c
preparation_time_in_minutes(2);
// => 4
```

## 4. Calcula el tiempo transcurrido, en minutos

Define la función `elapsed_time_in_minutes`, que recibe dos parámetros, en este orden:

1. La cantidad de capas que le agregaste a la lasaña.
2. La cantidad de minutos que la lasaña lleva en el horno.

La función debe devolver cuántos minutos has dedicado a cocinar la lasaña.
Es la suma del tiempo de preparación, en minutos, y el tiempo, en minutos, que la lasaña lleva en el horno en ese momento.

```c
elapsed_time_in_minutes(3, 20);
// => 26
```
