# Apéndice de instrucciones

## Pistas

Para completar este ejercicio, debes implementar las siguientes funciones:

- `boardString`
- `canAttack`

Las firmas de tipo ya están puestas, pero definir las funciones depende de ti.

Las posiciones se especifican como tuplas de dos elementos:

- El primer elemento es la fila (el *rank*, en términos de ajedrez).
- El segundo elemento es la columna (el *file*, en términos de ajedrez).
- (0, 0) es la esquina superior izquierda del tablero, (0, 7) es la superior derecha,
- (7, 0) es la inferior izquierda y (7, 7) es la inferior derecha.
