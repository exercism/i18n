# Introducción

En Go, `map` es un tipo de dato integrado que asocia claves a valores.
En otros lenguajes de programación, quizá ya conozcas el concepto de `map` como diccionario, tabla hash, almacén de clave/valor o array asociativo.

Sintácticamente, `map` se ve así:

```go
map[KeyType]ElementType
```

También es importante saber que cada clave es única, lo que significa que asignar la misma clave dos veces sobrescribirá el valor de la clave correspondiente.

Para crear un map, puedes hacer:

```go
  // With map literal
  foo := map[string]int{}
```

o

```go
  // or with make function
  foo := make(map[string]int)
```

Estas son algunas operaciones que puedes hacer con un map

```go
  // Add a value in a map with the `=` operator:
  foo["bar"] = 42
  // Here we update the element of `bar`
  foo["bar"] = 73
  // To retrieve a map value, you can use
  baz := foo["bar"]
  // To delete an item from a map, you can use
  delete(foo, "bar")
```

Si intentas obtener el valor de una clave que no existe en el map, obtendrás el valor cero del tipo de valor.
Esto puede confundirte, sobre todo si el valor predeterminado de tu `ElementType` (por ejemplo, 0 para un int) es un valor válido.
Para comprobar si una clave existe en tu map, puedes usar

```go
  value, exists := foo["baz"]
  // If the key "baz" does not exist,
  // value: 0; exists: false
```
