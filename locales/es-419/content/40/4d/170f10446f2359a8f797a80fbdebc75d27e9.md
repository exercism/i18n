# Instalación

## ¿Qué versión elegir?

Te recomendamos usar una versión estable de PHP con soporte activo.
Actualmente son **PHP 8.2, 8.3 y 8.4**.
Puedes encontrar los detalles sobre las versiones actuales y sus calendarios en [la documentación oficial de PHP](https://www.php.net/supported-versions.php).

## Instalar PHP

La mayoría de los gestores de paquetes para Linux / macOS ofrecen paquetes ya compilados.
También puedes descargar PHP y compilarlo desde el código fuente, disponible en [php.net/downloads.php](https://php.net/downloads.php) o [windows.php.net/download](https://windows.php.net/download).

~~~~exercism/note
No necesitas un servidor web como nginx o Apache HTTP server para completar los ejercicios.
~~~~

### Linux

Cada distribución tiene su propio método.
Deberías poder ejecutar

```shell
yum install php
```

o

```shell
apt-get install php
```

según tu gestor de paquetes.

Para más instrucciones, consulta el manual de PHP sobre [Instalación en sistemas Unix](https://www.php.net/manual/en/install.unix.php).

### macOS

Aunque macOS suele incluir PHP, muchas veces viene desactualizado.
Recomendamos instalar PHP con [Homebrew](https://brew.sh/).
Puedes instalar Homebrew siguiendo las instrucciones [de su página principal](https://brew.sh/#install).

Para confirmar la instalación, prueba el siguiente comando; al momento de escribir esto, debería mostrar Homebrew `4.5.x`.

```shell
brew --version 
```

Instala PHP con Homebrew

```shell
brew install php@8.4
```

Esto debería mostrar la versión de PHP que acabas de instalar, al menos la versión `8.2.0`.

```shell
php -v
```

Para más instrucciones, consulta el manual sobre [Instalación en macOS](https://www.php.net/manual/en/install.macosx.php).

### Windows

Puedes descargar los binarios oficiales de PHP para Windows desde [windows.php.net/download](https://windows.php.net/download).

También hay entornos ya preconfigurados, como [WAMP](https://www.wampserver.com/en/) (Windows, Apache, MySQL, PHP) y [XAMPP](https://www.apachefriends.org/de/index.html).

Para más instrucciones, consulta el manual sobre [Instalación en sistemas Windows](https://www.php.net/manual/en/install.windows.php).

### Docker

Si prefieres soluciones en contenedores, puedes descargar la [imagen oficial de PHP desde Docker Hub](https://hub.docker.com/_/php).
También vas a necesitar [Docker](https://docs.docker.com/engine/install/).

### Otros

Si quieres usar otro sistema operativo, consulta las instrucciones en [php.net/manual/en/install](https://www.php.net/manual/en/install.php).

## Instalar PHPUnit

¡PHPUnit 12 todavía no es compatible!
~~~~

### Mediante PHP Archive (PHAR)

La forma más fácil de usar PHPUnit en los ejercicios de Exercism es descargar una distribución empaquetada como PHP Archive (PHAR), que además es la manera recomendada de usar PHPUnit.
Guarda el PHAR donde guardaste la CLI de `exercism` para poder ejecutar PHPUnit desde cualquier lugar.

Puedes descargar una versión de los paquetes de PHPUnit como archivo PHP:

```shell
wget -O phpunit.phar https://phar.phpunit.de/phpunit-11.phar
```

Luego haz que el archivo descargado sea ejecutable:

```shell
chmod +x phpunit.phar
```

Y muévelo a la misma ubicación donde moviste la CLI de `exercism`, nombrando el comando `phpunit`:

```shell
mv phpunit.phar ~/bin/phpunit
```

Ahora puedes ejecutar `phpunit` desde cualquier lugar, como se muestra en la [documentación de pruebas del track de PHP](https://exercism.org/docs/tracks/php/tests):

```shell
phpunit --version
```

La salida debería verse así:

```text
PHPUnit 11.5.45 by Sebastian Bergmann and contributors.
```

También puedes seguir las [instrucciones oficiales para instalar PHPUnit](https://docs.phpunit.de/en/11.5/installation.html#installing-phpunit) para instalar PHPUnit.

### Mediante Composer

La versión 11 de PHPUnit también se puede instalar con [Composer](https://getcomposer.org).

#### Instalar Composer

Instala [Composer](https://getcomposer.org) siguiendo las [instrucciones de instalación](https://getcomposer.org/doc/00-intro.md) del sistema operativo de tu equipo. Te recomendamos instalarlo de forma global para que sea más fácil de usar.

#### Agregar PHPUnit como herramienta global

Usa el siguiente comando:

```shell
composer global require phpunit/phpunit ^11.5
```

Asegúrate de instalar la versión 11.5 o posterior.
