# Introducción

La mayor parte de los datos en Factor vive en *secuencias*. Los arrays (`{ … }`), los vectores (`V{ … }`) y los strings comparten el mismo [protocolo][sequence-protocol] de [`sequences`][sequences].

```factor
{ 1 2 3 } length .    ! => 3
{ 1 2 3 } first .     ! => 1
{ 1 2 3 } last .      ! => 3
{ 1 2 3 4 5 } 3 head .! => { 1 2 3 }
```

Las agregaciones (`sum`, `count`, `any?`, `all?`) y los predicados como `empty?` y `member?` funcionan de forma uniforme en todos los tipos de secuencia. Construir nuevas secuencias sin mutación: `prefix`, `suffix`, `append`, `unclip`, `unclip-last`.

`>array`, `>vector` y `>string` (en [`arrays`][arrays] y los vocabularios correspondientes) convierten entre tipos de secuencia cuando necesitas recuperar uno concreto y particular a partir de una operación genérica.

[sequences]: https://docs.factorcode.org/content/vocab-sequences.html
