# Acerca de

Los tipos que implementan la interfaz [`IEnumerable<T>`][IEnumerable] se conocen como _enumerables_.
Todos los tipos de colección integrados implementan esta interfaz.

Un tipo enumerable se puede recorrer con un bucle `foreach`:

```csharp
var primes = new[] { 2, 3, 5, 7 };
foreach (var prime in primes)
{
    Console.Write(prime);
}
// => 2357
```

Para implementar `IEnumerable<T>`, un tipo tiene que implementar un método: `IEnumerator<T> GetEnumerator()`.
Como se puede ver, un enumerable delega la iteración real de una colección a un tipo `IEnumerator<T>`.
Esta interfaz tiene una propiedad y tres métodos que se deben implementar:

- `public T Current { get; }`: obtiene el elemento actual.
- `public bool MoveNext ();`: avanza al siguiente elemento y devuelve `true` si el avance al siguiente elemento fue exitoso, o `false` si no (no hay más elementos).
- `public void Reset ();`: reinicia el enumerador a su estado inicial (antes del primer elemento).

[IEnumerable]: https://docs.microsoft.com/en-us/dotnet/api/system.collections.generic.ienumerable-1
