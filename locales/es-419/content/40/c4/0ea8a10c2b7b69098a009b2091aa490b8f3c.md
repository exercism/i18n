# Introducción

Un [operador de comparación][comparisons] en Python (_también llamado operador relacional de Python_), examina los _valores_ de dos [operandos][operand] y devuelve un Boolean `True` o `False` según si se cumple o no la condición de la `comparison`.

La siguiente tabla muestra los operadores de comparación de Python más comunes:

| Operador | Operación                       | Descripción                                                                               |
| -------- | ------------------------------- | ----------------------------------------------------------------------------------------- |
| `>`      | «mayor que»                     | `a > b` es `True` si `a` es **estrictamente** mayor en valor que `b`                      |
| `<`      | «menor que»                     | `a < b` es `True` si `a` es **estrictamente** menor en valor que `b`                      |
| `==`     | «igual a»                       | `a == b` es `True` si `a` es **estrictamente** igual a `b` en valor                       |
| `>=`     | «mayor o igual que»             | `a >= b` es `True` si `a > b` O `a == b` en valor                                         |
| `<=`     | «menor o igual que»             | `a <= b` es `True` si `a < b` o `a == b` en valor                                         |
| `!=`     | «distinto de»                   | `a != b` es `True` si `a == b` es `False`                                                 |
| `is`     | «identidad»                     | `a is b` es `True` si **_y solo si_** `a` y `b` son el mismo _objeto_                     |
| `is not` | «identidad negada»              | `a is not b` es `True` si **_y solo si_** `a` y `b` **no** son el mismo _objeto_          |
| `in`     | «prueba de pertenencia»         | `a in b` es `True` si `a` es miembro, subconjunto o elemento de `b`                       |
| `not in` | «prueba de pertenencia negada»  | `a not in b` es `True` si `a` no es miembro, subconjunto o elemento de `b`                |

Todos tienen la misma prioridad (_que es mayor que la de las [operaciones booleanas][boolean operations], pero menor que la de las operaciones aritméticas o a nivel de bits_).

## Comparación entre distintos tipos de datos

Los objetos que son de tipos distintos (_excepto los tipos numéricos_) nunca se comparan como iguales de forma predeterminada.
Las instancias no idénticas de una `class` tampoco se compararán como iguales, a menos que la `class` defina métodos especiales que personalicen el comportamiento de comparación predeterminado de `object`.

Los tipos numéricos son (en su mayoría) una excepción a esta regla de coincidencia de tipos.
Un `integer` **puede** considerarse igual a un `float` (_o un [`octal`][octal] igual a un [`hexadecimal`][hex]_), siempre que los tipos puedan convertirse implícitamente para la comparación.

Para los demás tipos numéricos ([complex][complex numbers], [decimal][decimal numbers], [fractions][rational numbers]), los operadores de comparación están definidos donde «tienen sentido» (_donde la conversión implícita no cambia el resultado_), pero lanzan un `TypeError` si los objetos subyacentes no pueden convertirse con precisión para la comparación.

## Comparación de la identidad de los objetos

Los operadores `is` y `is not` comprueban la [_identidad_][object identity] de los objetos, en contraposición al _valor_ del objeto.
La identidad de un objeto nunca cambia después de su creación y puede obtenerse usando la función [`id()`][id function].

`<apple> is <orange>` se evalúa como `True` si **_y solo si_** `id(<apple>)` == `id(<orange>)`.
`<apple> is not <orange>` da el resultado inverso.

## Comparaciones de pertenencia

Los operadores `in` y `not in` comprueban la _pertenencia_.
`<fish> in <soup>` se evalúa como `True` si `<fish>` es un miembro de `<soup>` (_si `<fish>` es un subconjunto de `<soup>` o está contenido en `<soup>`_), y se evalúa como `False` en caso contrario.
`<fish> not in <soup>` devuelve la negación, o el _opuesto de_ `<fish> in <soup>`.

Para los tipos string y bytes, `<name> in <fullname>` es `True` **_si y solo si_** `<name>` es una subcadena de `<fullname>`.
