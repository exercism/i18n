# Instrucciones

Dos violinistas están ensayando un dueto. Cada parte es un array que contiene la
cantidad de notas de cada compás, y las partes no siempre tienen la misma
longitud.

Las cuatro tareas van en la clase `DUET_PRACTICE`.

## 1. ¿Cuántos compases tocan juntos?

Tocan juntos mientras a ambas partes les quede un compás.

```sather
DUET_PRACTICE::bars_together(|4, 4, 8, 8|, |4, 4|)
-- => 2
```

## 2. ¿Cuántos compases coinciden?

Cuenta los compases en los que ambas partes tienen la misma cantidad de notas.
Solo pueden coincidir los compases que ambos tienen.

```sather
DUET_PRACTICE::in_unison(|4, 4, 8|, |4, 2, 8|)
-- => 2
```

## 3. ¿Quién toca más?

Cuenta los compases en los que la primera parte tiene más notas que la segunda.

```sather
DUET_PRACTICE::louder_bars(|4, 8, 2|, |4, 2, 8|)
-- => 1
```

## 4. Pondera los compases

Los compases posteriores son más difíciles, así que cada compás cuenta tanto
como su posición: el primer compás cuenta una vez, el segundo dos veces y el
tercero tres veces. Multiplica las notas de cada compás por su número y suma
todo.

```sather
DUET_PRACTICE::weighted_total(|4, 4, 8|)
-- => 36
```

Es decir, 1×4 + 2×4 + 3×8. Los compases se numeran desde uno, no desde cero.
