# Pistas

## 1. Crea el identificador de puertos

- Necesitas definir una [constante][constants] que debe contener el valor de símbolo especificado en las instrucciones.

## 2. Obtén los identificadores de los otros puertos

- Puedes aplicar [slice][slice] a un string para obtener partes de él.
- Los `Strings` tienen un [método][upcase] para convertir las letras a mayúsculas.
- Los `Strings` tienen un [método][to_sym] para convertir un string en un símbolo.

## 3. Determina en qué terminal debe atracar un barco

- Symbol tiene un [método][to_s] para convertir un símbolo en un string.
- Puedes aplicar [slice][slice] a un string para obtener partes de él.
- Usa el condicional [`if`][doc-if] para comprobar si el barco transporta `"OIL"` o `"GAS"`.
