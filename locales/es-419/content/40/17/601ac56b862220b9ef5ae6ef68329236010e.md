# Acerca de

El tipo `Option` es un enum que proporciona la biblioteca estándar. Es útil para expresar un valor que puede que no exista.
Aunque esto suene como `null` o `nil`, es bastante diferente y especial.

`Option<T>` contiene otros tipos y tiene dos variantes: `Some(T)` y `None`.

Por ejemplo, `Option<u32>` contiene el tipo `u32`.

## Uso

### Cómo usar el `T` dentro de `Option<T>`

Hay varias formas comunes de usar el valor que podría estar presente en un `Option`:

- `if let Some(t) = optional { ... }`.

    El modismo `if let` extrae el valor de un `Option<T>` y lo vincula a la variable `t`. Esto te permite usarlo directamente en el ámbito de ese bloque.

- `match optional { Some(t) => {...}, None => {...}}`

    El operador `match` también te permite desempaquetar y manejar los casos `None` en una sola sentencia o expresión. Es una alternativa a una cadena de sentencias if y else. Usar `match` puede aumentar la legibilidad de algunas secciones de código.
- `optional.map(|t| ...)`
   `Option::map` actualiza un Option in situ, potencialmente con un nuevo tipo, a partir de la función proporcionada.

   **Nota**: opera sobre el valor contenido si está presente. El vínculo se convierte en un `Option<U>`, donde el closure dado es `FnOnce(T) -> U`.
- `optional.unwrap()`.
   Desenvolver un `Option<T>` extrae `T`, pero entrará en pánico si `T` no está ahí. Es práctico en algunos casos.

   **Importante**: desenvolver puede facilitar el desarrollo a corto plazo o en código de prueba, pero introduce la posibilidad de pánicos en tiempo de ejecución. Debería evitarse cuando sea posible.

- `optional.expect("Unexpected None found! Aborting program.)`.
   El método `expect` en `Option<T>` es muy similar a `unwrap()`, pero entrará en pánico usando el mensaje proporcionado si es `None`.

## Ejemplos

Cuando un valor existe en un `Option<u32>`:

```rust
let has_something: Option<u32> = Some(100);
assert_eq!(has_something.unwrap(), 100);
```

Cuando un valor *no* existe en un `Option<u32>`:

```rust
let has_nothing: Option<u32> = None;
assert_eq!(has_nothing, None);
```
