# Tests

Antes de intentar ejecutar los tests, asegúrate de que la carpeta de la tarea está configurada correctamente siguiendo los pasos de instalación, es decir, `corepack yarn install` y la configuración del Editor SDK.

Ejecuta los tests con:

```bash
$ corepack yarn test
```

## Tests omitidos

En las suites de tests, todos los tests excepto el primero están omitidos.

Cuando consigas que un test pase, puedes habilitar el siguiente cambiando `xit` por `it`.
Además, los tests pueden agruparse con `xdescribe`.
Habilita el grupo cambiándolo por `describe`.
Por último, algunos ejercicios pueden tener tests opcionales `it.skip`.
Elimina `.skip` para ejecutar el test opcional.
