# Introducción

Como todos los tipos de datos estándar de Clojure son inmutables, el lenguaje ofrece *tipos de referencia*, que permiten una mutación controlada. Los más simples y los más usados de ellos son los Atoms.

Los Atoms se crean con la función `atom`, que recibe un valor inicial:

```clojure
(def players (atom ()))
```

El valor actual del atom se desreferencia con `deref` o con la forma abreviada `@`:

```clojure
@players
;;=> ()
```

El valor actual del atom `players` se puede modificar con `swap!`, que actualiza el valor aplicando una función:

```clojure
(swap! players conj :player1)
;;=> (:player1)
```

La función `reset!` reemplaza el valor de un atom sin tener en cuenta su valor actual:

```clojure
(reset! players ())
```
