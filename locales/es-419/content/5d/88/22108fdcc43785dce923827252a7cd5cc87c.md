# Apéndice

## Vector2i

Este ejercicio usa el [`Vector2i` de GDScript][vector2i] para la posición y la dirección del robot.
Para la dirección, consulta las [constantes de `Vector2i`][vector2i_constants].

[vector2i]: https://docs.godotengine.org/en/stable/classes/class_vector2i.html
[vector2i_constants]: https://docs.godotengine.org/en/stable/classes/class_vector2i.html#constants
