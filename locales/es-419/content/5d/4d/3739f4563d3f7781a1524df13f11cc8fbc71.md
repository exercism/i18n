# Instrucciones

Limpia números de teléfono para que se les puedan enviar mensajes SMS.

El **Plan de Numeración de América del Norte (NANP)** es un sistema de numeración telefónica que usan muchos países de América del Norte, como Estados Unidos, Canadá o Bermudas.
Todos los países del NANP comparten el mismo código de país internacional: `1`.

Los números del NANP son números de diez dígitos que constan de un código de tres dígitos del plan de numeración, conocido comúnmente como _código de área_, seguido de un número local de siete dígitos.
Los primeros tres dígitos del número local representan el _código de central_, seguido del número único de cuatro dígitos, que es el _número de abonado_.

El formato se representa normalmente como

```text
NXX NXX-XXXX
```

donde `N` es cualquier dígito del 2 al 9 y `X` es cualquier dígito del 0 al 9.

A veces también llevan antepuesto el código de país (representado como `1` o `+1`).

Tu tarea es limpiar números de teléfono con distintos formatos, eliminando la puntuación y el código de país, si está presente.

Por ejemplo, los siguientes números

- `+1 (613)-995-0253`
- `613-995-0253`
- `1 613 995 0253`
- `613.995.0253`

deben producir todos la salida

`6139950253`

**Nota:** Como este ejercicio solo trata números de teléfono usados en países del NANP, solo el 1 se considera un código de país válido.
