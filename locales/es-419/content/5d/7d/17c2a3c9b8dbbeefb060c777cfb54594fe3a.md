# Recursos útiles de Raku

[El sitio de Raku](https://raku.org/) tiene una página para [aprender](https://raku.org/learn) y otra de [herramientas](https://raku.org/tools) con información variada sobre el lenguaje, como guías para principiantes, documentación y screencasts.

La [documentación](https://docs.raku.org/) contiene [material introductorio](https://docs.raku.org/introduction), tutoriales y guías de migración para quienes ya conocen otros lenguajes, y mucho más.
