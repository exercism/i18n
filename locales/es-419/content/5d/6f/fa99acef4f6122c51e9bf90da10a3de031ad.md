# Ejecutar las pruebas

## Descarga un ejercicio

Usa la [CLI de Exercism][cli] para descargar el ejercicio en el que quieres trabajar.

```sh
exercism download --track=dart --exercise=hello-world
```

Luego cambia al directorio del ejercicio.

```sh
cd /path/to/exercism/dart/hello-world
```

## Instala las dependencias

Antes de ejecutar las pruebas, descarga las dependencias del ejercicio.

```sh
dart pub get
```

## Ejecuta las pruebas

```sh
dart test
```

## Entender los resultados de las pruebas

`dart test` usa por defecto el reporte compacto, que muestra en una sola línea un recuento continuo de las pruebas aprobadas, omitidas y fallidas.

```sh
$ dart test

  Expected: <3>
    Actual: <0>

  package:matcher                    expect
  test/binary_search_test.dart 13:5  main.<fn>


To run this test again: dart test test/binary_search_test.dart -p vm --plain-name 'finds a value in the middle of an array'
00:00 +1 ~9 -1: Some tests failed.
```

- `+1`: 1 prueba aprobada
- `~9`: 9 pruebas omitidas

## Trabajar con las pruebas

La mayoría de los ejercicios tiene varias pruebas y, de forma predeterminada, todas están omitidas menos la primera.

```dart
void main() {
  final twoFer = TwoFer();

  group('TwoFer', () {
    test('no name given', () {
      final result = twoFer.statement();
      expect(result, equals('One for you, one for me.'));
    }, skip: false);

    test('a name given', () {
      final result = twoFer.statement('Alice');
      expect(result, equals('One for Alice, one for me.'));
    }, skip: true);

    test('another name given', () {
      final result = twoFer.statement('Bob');
      expect(result, equals('One for Bob, one for me.'));
    }, skip: true);
  });
}
```

Para trabajar con las pruebas de una en una, cambia `skip: true` por `skip: false` en cada prueba a medida que avanzas.
Otra opción es ejecutar todas las pruebas a la vez sin editar el archivo.

```sh
dart test --run-skipped
```

El ejecutor de pruebas en línea ejecuta todas las pruebas al enviar tu solución, incluidas las que están omitidas.

## Cómo manejar el error «Could not find a command named frontend_server.dart.snapshot»

Supón que tienes un ejercicio que ya resolviste y enviaste, y que vuelves a él después de un tiempo.
Es posible que te encuentres con este error cuando lo pruebes:

```sh
$ dart test
...
Could not find a command named "/path/to/frontend_server.dart.snapshot".
```

La [solución][solution] es eliminar el archivo `pubspec.lock`.
Después, vuelve a ejecutar el comando de dart.
