# Introducción

Los conceptos de covarianza y contravarianza en PHP son importantes, ya que PHP exige que se sigan estas reglas al extender clases o interfaces.

La covarianza conserva la relación entre dos tipos, mientras que la contravarianza invierte esa relación. En resumen, significa que al extender clases y sobrescribir funciones puedes permitir tipos más o menos específicos en los parámetros de tu método, y puedes devolver tipos menos o más específicos desde el método.

## Ejemplos

Considera la siguiente clase:

```php
class Calculator 
{
    public function add(int $x, int $y): int 
    {
        return $x + $y;
    }
}
```

Si extendemos la clase, podemos permitir más tipos de parámetros que los declarados originalmente, pero no podemos devolver nada que no sean los tipos de retorno originales.

```php
class Floatulator extends Calculator
{
    // This is valid
    public function add(int|float $x, int|float $y): int 
    {
        return (int)($x + $y);
    }
}
```

La siguiente clase extendida no es válida porque no se permite devolver tipos adicionales o más amplios:

```php
class BrokenCalculator extends Calculator 
{
    // This is invalid and will not compile
    public function add(int|float $x, int|float $y): int|float{
        return $x + $y;
    }
}
```
