# Introducción

Puedes hacer que un parámetro de método sea opcional si le asignas un valor predeterminado. Cuando llamas a un método con parámetros opcionales, no es obligatorio pasarles un valor. Si no pasas ningún valor para un parámetro opcional, se usa su valor predeterminado.

Los parámetros opcionales _deben_ estar al final de la lista de parámetros; no pueden ir seguidos de parámetros que no sean opcionales.

```csharp
class Card
{
    static string NewYear(int year = 2020)
    {
        return $"Happy {year}!";
    }
}

Card.NewYear();     // => "Happy 2020!"
Card.NewYear(1999); // => "Happy 1999!"
```
