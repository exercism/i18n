# Pistas

## General

- La clase `string` tiene muchos [métodos integrados][methods] que te resultarán útiles.

## 1. Obtén el mensaje de una línea de registro

- Hay [varios métodos][index-of] para encontrar el índice en el que aparece un texto dentro de un `string`.
- Eliminar los espacios en blanco también está [integrado][trim].

## 2. Obtén el nivel de registro de una línea de registro

- Un `string` se puede convertir a minúsculas con un [método integrado][to-lower].

## 3. Reformatea una línea de registro

- Hay un [operador integrado][plus-operator] para concatenar strings.
