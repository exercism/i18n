# Instrucciones

Acabas de empezar a trabajar en la recepción de un gimnasio de escalada.
Los miembros compran membresías por una cierta cantidad de meses y registran su entrada y su salida cada vez que vienen.
El gerente te pidió que escribas un asistente que responda las preguntas que los miembros hacen con más frecuencia.

## 1. Calcula cuándo termina una membresía

Una membresía que empieza en una fecha dada termina ese mismo día del mes, tantos meses después como se hayan indicado.
Cuando ese día no existe en el mes final, la membresía termina el último día de ese mes.

Implementa el método `FrontDesk.membershipEnd()` que recibe la fecha de inicio de una membresía y su cantidad de meses, y devuelve la fecha en la que termina:

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.membershipEnd(LocalDate.of(2024, 3, 10), 1);
// => LocalDate.of(2024, 4, 10)
frontDesk.membershipEnd(LocalDate.of(2025, 1, 31), 1);
// => LocalDate.of(2025, 2, 28)
```

## 2. Muestra cuánto dura una membresía

En la tarjeta de membresía, el gimnasio imprime cuánto dura la membresía en años, meses y días.

Implementa el método `FrontDesk.membershipLength()` que recibe la fecha de inicio y la fecha de fin de una membresía, y devuelve la duración de la membresía como un `Period`:

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.membershipLength(LocalDate.of(2023, 3, 10), LocalDate.of(2024, 5, 25));
// => Period.of(1, 2, 15)
```

## 3. Cuenta los días que le quedan a una membresía

Los miembros suelen preguntar cuántos días les quedan antes de que termine su membresía.

Implementa el método `FrontDesk.daysLeft()` que recibe la fecha de hoy y la fecha de fin de una membresía, y devuelve el número total de días desde hoy hasta la fecha de fin.
Cuando la fecha de fin es hoy o ya pasó, no quedan días, así que el método devuelve `0`:

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.daysLeft(LocalDate.of(2024, 1, 15), LocalDate.of(2024, 3, 20));
// => 65
frontDesk.daysLeft(LocalDate.of(2024, 4, 2), LocalDate.of(2024, 3, 20));
// => 0
```

## 4. Mide una visita

El gimnasio está abierto las 24 horas, y el torniquete registra la fecha y la hora en que un miembro entra y sale.

Implementa el método `FrontDesk.visitDuration()` que recibe la fecha y hora de entrada y de salida de una visita, y devuelve cuánto duró la visita como un `Duration`:

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.visitDuration(LocalDateTime.of(2024, 3, 10, 23, 30), LocalDateTime.of(2024, 3, 11, 1, 15));
// => Duration.ofMinutes(105)
```

## 5. Imprime una visita en el recibo

El recibo muestra la duración de una visita en horas y minutos, como `1h 35m`.
Los minutos siempre se escriben con dos dígitos, los segundos se omiten y las horas no se limitan a un solo día.

Implementa el método `FrontDesk.formatVisit()` que recibe la duración de una visita y la devuelve en este formato:

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.formatVisit(Duration.ofMinutes(95));
// => "1h 35m"
frontDesk.formatVisit(Duration.ofHours(2).plusMinutes(5));
// => "2h 05m"
frontDesk.formatVisit(Duration.ofHours(26).plusMinutes(10));
// => "26h 10m"
```
