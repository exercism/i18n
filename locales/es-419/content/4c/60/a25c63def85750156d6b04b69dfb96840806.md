# Instrucciones específicas de SQLite

- La columna **matrix** contiene la entrada, un array de arrays de enteros codificado en JSON.
- La columna **result** debe contener la salida, la lista de puntos de silla.
  La salida debe ser un array de objetos codificado en JSON; cada objeto tiene dos claves: row y column.
  Por ejemplo, `[{"row": 2, "column": 1}]`.
