# no uses condicionales anidados

Intenta reescribir los condicionales para evitar anidarlos demasiado, ya que eso puede dar lugar a código más difícil de seguir. Fíjate en los siguientes dos fragmentos de código:

```csharp
void PrintName(Person p)
{
    if (p != null)
    {
        if (p.Name != null)
        {
            if (p.Age >= 21)
            {
                Console.WriteLine(p.Name);
            }
        }
    }
}
```

Compáralo con el siguiente código:

```csharp
void PrintName(Person p)
{
  if (p == null || p.Name == null || p.Age < 21)
  {
      return;
  }

  Console.WriteLine(p.Name);
}
```

El segundo ejemplo tiene una estructura muy específica: todos los caminos que tienen que ver con errores se manejan en bloques con sangría, mientras que el «happy path» siempre queda alineado a la izquierda. Eso hace que sea muy fácil de leer, ya que uno puede ver rápidamente cuál es el camino más común y sin errores a través del código.
