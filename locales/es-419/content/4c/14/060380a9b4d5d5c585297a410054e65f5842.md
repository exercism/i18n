# Introducción

A veces, cuando recorres una secuencia, necesitas la *posición* del
elemento junto con el elemento mismo. La familia `*-index` de
[`sequences`][sequences] le entrega ambos a la quotation de cada
elemento. `times` es el primo cercano para la iteración contada
simple: te sirve cuando solo necesitas un conteo y no una secuencia.

## `each-index` y `map-index`: el índice en la quotation

```
each-index ( seq quot: ( elt index -- )       -- )
map-index  ( seq quot: ( elt index -- newelt ) -- newseq )
```

La quotation recibe el elemento debajo del índice: `index` está en
el **tope** de la pila:

```factor
USING: io kernel math.parser sequences ;

{ "alice" "bob" "carol" } [
    number>string ": " glue print
] each-index
! prints:
! alice: 0
! bob:   1
! carol: 2

{ 10 20 30 } [ + ] map-index .
! => { 10 21 32 }       (index added to each element)
```

`each-index` ejecuta la quotation por su efecto secundario y no
devuelve nada. `map-index` recoge los resultados de cada elemento
en una nueva secuencia del mismo tipo que la de entrada.

## `times`: iteración contada

`times` (en [`math`][math]) ejecuta su quotation `n` veces.

```
times ( n quot: ( -- ) -- )
```

La forma publicada `( -- )` es la *mínima*: como `times` es
`inline`, una quotation con efectos balanceados como
`( str -- str )` funciona sin problema, y la pila se va pasando de
una iteración a la siguiente. Eso te da un acumulador contado sin
ningún estado mutable:

```factor
USING: kernel sequences ;

"" 3 [ "clop " append ] times .    ! => "clop clop clop "
```

El cuerpo de cada iteración ve la cadena en curso, le agrega texto
y deja la nueva cadena en la pila para la siguiente iteración. El
mismo truco funciona con `each-index` y `map-index` cuando quieres
ir pasando un acumulador de una iteración a otra.
