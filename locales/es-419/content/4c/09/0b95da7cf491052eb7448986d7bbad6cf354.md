# Instrucciones

Un robot fiestero está colgando banderines para la gran bonanza. Cada
tira de banderines es una fila horizontal de `n` banderitas, y el
carácter de cada banderita está determinado por el lugar que ocupa en la
fila, contando desde la izquierda y empezando en `0`. Ayuda al robot a
armar los patrones de abajo.

## 1. Banderines del alfabeto

Define `alphabet-bunting` para que tome un entero no negativo `n` de la
pila y devuelva un string con las primeras `n` letras minúsculas del
alfabeto.

```factor
5 alphabet-bunting .
! => "abcde"

0 alphabet-bunting .
! => ""
```

Puedes asumir que `n` es como máximo `26`.

## 2. Banderines numéricos

Define `counting-bunting` para que tome `n` y devuelva un string de `n`
dígitos, donde la banderita en la posición `i` muestra `i mod 10`.

```factor
12 counting-bunting .
! => "012345678901"
```

## 3. Banderines a rayas

Define `stripe-bunting` para que alterne entre dos caracteres: las
posiciones pares llevan `*` y las impares llevan `-`.

```factor
6 stripe-bunting .
! => "*-*-*-"

1 stripe-bunting .
! => "*"
```

## 4. Banderines con marcadores

Una de cada cinco banderitas es un marcador especial. Define
`marker-bunting` para que las posiciones `0`, `5`, `10`, … lleven `|` y
las demás lleven `.`.

```factor
11 marker-bunting .
! => "|....|....|"
```

## 5. Banderines del valle

El robot cuelga una tira de banderines de tamaño fijo con 10 banderitas,
que se sujeta a un gancho en el centro. Contando desde la banderita más
a la izquierda, en la posición `-5`, hasta `5` (sin incluirlo), el
carácter de cada banderita es la distancia al centro, escrita como un
dígito.

Define `valley-bunting` (que no recibe argumentos) para que devuelva ese
string fijo.

```factor
valley-bunting .
! => "5432101234"
```
