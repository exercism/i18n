# Instalación

La distribución de Racket se puede descargar desde https://download.racket-lang.org

Se proporcionan instaladores para

* Windows
* Linux
* macOS

Consulta la página [Getting Started](http://docs.racket-lang.org/getting-started/) de Racket para ver materiales de orientación.

La [Guía de Racket](https://docs.racket-lang.org/guide/intro.html) te presenta cómo interactuar con Racket.

Consulta [DrRacket: el entorno de programación de Racket](https://docs.racket-lang.org/drracket/index.html) para obtener orientación sobre el uso del IDE DrRacket.

Consulta [Herramientas de línea de comandos y el editor que prefieras](https://docs.racket-lang.org/guide/other-editors.html) para una introducción a las herramientas de línea de comandos de Racket y al uso de otros editores.


## Acerca del instalador de Linux:
La compilación de Linux es lo bastante genérica como para funcionar en la mayoría de las distribuciones, incluidas las relativamente antiguas.

Después de descargar el archivo del instalador, ejecútalo con
```
sh racket-8.10-x86_64-linux-cs.sh
```

Es posible que tengas que anteponer `sudo` al inicio del comando para instalar en una ubicación que requiera acceso de administrador.

**Advertencia: es posible que Racket también esté disponible a través del gestor de paquetes de tu distribución, aunque puede ser anterior a la versión más reciente de Racket.**
Aunque puedes optar por hacer esto más adelante, como estudiante tendrás una experiencia mucho mejor si te quedas con la versión actual disponible en https://download.racket-lang.org


## Acerca del instalador de macOS:

Si tu equipo usa procesadores de la serie M1 o M2, selecciona **Apple Silicon** en el menú desplegable de plataformas antes de descargar.
