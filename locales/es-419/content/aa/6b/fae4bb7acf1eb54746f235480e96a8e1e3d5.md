# Acerca de

Los condicionales son sentencias que ejecutan código distinto según si una condición es `true` o `false`.

Una [sentencia `if`][if_statement] ejecuta su cuerpo solo cuando su condición es `true`.
Go no tiene el concepto de valores truthy o falsy, así que la condición debe ser de tipo `bool`.
Expresiones como `if mySlice { ... }` o `if 1 { ... }` son errores de compilación.

```go
func describe(val string) string {
    if val == "val" {
        return "was val"
    }
    return "was not val"
}
```

Usa `else if` para comprobar condiciones adicionales, y `else` como respaldo si ninguna coincide.
Las condiciones se evalúan de arriba abajo, y solo se ejecutará la primera rama cuya condición sea verdadera.

```go
number := 0
result := "This number is "

if number > 0 {
    result += "positive"
} else if number < 0 {
    result += "negative"
} else {
    result += "zero"
}
```

En general, Go prefiere devolver temprano desde el caso excepcional y evitar `else`.

```go
func getVal(connected bool) int {
    if !connected {
        return readLocalVal()
    }

    return readVal()
}
```

Una sentencia `if` también puede incluir una sentencia corta de inicialización.
Esto se usa comúnmente para comprobar un error inmediatamente después de una llamada:

```go
num := 7
if v := 2 * num; v > 10 {
    fmt.Println(v)
} else {
    fmt.Println(num)
}
// Output: 14
```

Las variables declaradas en la sentencia de inicialización solo están en el ámbito de toda la cadena `if`/`else`.
En particular, Go no tiene operador ternario, una decisión de diseño deliberada para mantener el código fácil de leer de un vistazo.

Para aprender más, consulta [Go by Example: If/Else][go_by_example_if].
