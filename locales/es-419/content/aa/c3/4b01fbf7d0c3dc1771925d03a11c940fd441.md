# Pruebas

Puedes ejecutar las pruebas abriendo una terminal en el directorio del ejercicio y luego ejecutando el [comando `dotnet test`](https://docs.microsoft.com/en-us/dotnet/core/tools/dotnet-test).
Como alternativa, la mayoría de los IDE tienen soporte integrado para ejecutar pruebas, incluidos [Visual Studio](https://docs.microsoft.com/en-us/visualstudio/test/run-unit-tests-with-test-explorer), [Rider](https://www.jetbrains.com/help/rider/Unit_Testing_in_Solution.html) y [Visual Studio Code](https://github.com/OmniSharp/omnisharp-vscode/wiki/How-to-run-and-debug-unit-tests).
Consulta la [página de pruebas](https://exercism.io/tracks/fsharp/tests) para obtener más información.

## Pruebas omitidas

Inicialmente, solo la primera prueba estará habilitada.
Esto es para animarte a resolver el ejercicio paso a paso.
Una vez que pases la primera prueba, elimina la propiedad `Skip` de la siguiente prueba y trabaja en lograr que esa prueba pase.
