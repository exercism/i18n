# Probar un track

_Antes_ de lanzar tu track (es decir, la clave `"active"` todavía es `false` en el `config.json` del track), es importante probarlo.
Esto ayuda a encontrar errores (comunes) y permite corregirlos _antes_ de que se lance el track, lo que significa que los estudiantes nunca se toparán con ellos.

## Cómo habilitar el track para probarlo

Para habilitar el track y poder probarlo, hay que agregarlo a nuestra base de datos, algo que solo pueden hacer los administradores del sitio.
Por favor, abre un tema en [el foro](https://forum.exercism.org/c/exercism/building-exercism/125) para solicitarlo.

Ten en cuenta que agregar el track a la base de datos _no_ lanzará el track, pero _sí_ hará que sea accesible en el sitio web para los mantenedores.

## Cómo encontrar personas que lo prueben

Los usuarios ideales para probar el track son otros mantenedores de tracks, ya que:

- Tienen experiencia creando tracks (y por lo tanto saben qué debería haberse creado)
- Pueden acceder a tracks que todavía no están activos

Para que los mantenedores prueben tu track, abre un tema en [el foro](https://forum.exercism.org/c/exercism/building-exercism/125) para solicitarlo.
