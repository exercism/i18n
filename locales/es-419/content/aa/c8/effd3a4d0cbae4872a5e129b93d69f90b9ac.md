# Acerca de

En C#, los Boolean se representan con el tipo `bool`, que puede tomar los valores `true` o `false`.

C# admite cuatro [operadores Boolean][operators]: `!` (NOT), `&&` (AND), `||` (OR) y `^` (XOR). Los operadores `&&` y `||` usan la _evaluación de cortocircuito_, lo que significa que el lado derecho del operador solo se evalúa cuando es necesario.

```csharp
true || false // => true
true && false // => false
true ^ false  // => true
true ^ true   // => false
```

Los tres operadores Boolean tienen distinta [_precedencia de operadores_][precedence]. Por eso, se evalúan en este orden: primero `not`, luego `&&`, después `^` y por último `||`. Si quieres «escapar» de estas reglas, puedes encerrar una expresión Boolean entre paréntesis (`()`), ya que los paréntesis tienen una precedencia aún mayor.

```csharp
!true && false   // => false
!(true && false) // => true
```
