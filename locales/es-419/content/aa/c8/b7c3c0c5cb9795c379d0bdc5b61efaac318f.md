# Pistas

## General

- El módulo `gleam/string` tiene muchas [funciones de string][stdlib] útiles.

## 1. Obtén el mensaje de una línea de registro

- El operador `<>` se puede usar en la coincidencia de patrones para hacer coincidir el comienzo de un string.
- El módulo `gleam/string` tiene una [función][trim] para eliminar los espacios en blanco que rodean un string.

## 2. Obtén el nivel de registro de una línea de registro

- El módulo `gleam/string` tiene una [función][lowercase] para convertir un string a minúsculas.

## 3. Reformatea una línea de registro

- El operador `<>` se puede usar para unir strings entre sí.
