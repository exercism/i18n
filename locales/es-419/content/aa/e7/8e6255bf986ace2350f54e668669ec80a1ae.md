# Tests

Un ejercicio descargado incluye estos archivos para compilar y probar tu solución:

```text
hello-world/
├── HelloWorld.vb          # Your solution
├── HelloWorldTests.vb     # The test suite
├── HelloWorld.vbproj      # Project and build configuration
└── packages.lock.json     # Resolved project dependencies
```

Los nombres de los archivos varían según el ejercicio.
Escribe tu solución en el primer archivo `.vb`.
El segundo archivo, que termina en `Tests.vb`, es el [conjunto de tests de xUnit][xunit].
Por lo general, solo editarás este archivo para habilitar los tests siguientes.
No necesitarás editar ninguno de los dos últimos archivos.
El archivo `.vbproj` contiene la configuración de compilación del proyecto y las referencias directas a paquetes.
El archivo `packages.lock.json` generado registra las versiones resueltas de los paquetes directos y transitivos.

~~~exercism/note
Los tests describen el comportamiento que debe cumplir una solución que pase.
Pueden ayudarte a aclarar detalles que no cubren las instrucciones.
~~~

## Ejecutar los tests

Abre una terminal en el directorio del ejercicio y ejecuta:

```bash
dotnet test
```

El comando restaura las dependencias del proyecto, compila el proyecto y ejecuta sus tests.
También puedes usar `dotnet watch test` para volver a ejecutar los tests cada vez que cambie un archivo fuente.

## Tests omitidos

Los ejercicios solo habilitan el primer test al principio, lo que te permite resolver el resto paso a paso.
Abre el archivo que termina en `Tests.vb` para encontrar los tests.
Cada test es una subrutina `Sub` marcada con un atributo `<Fact>` de xUnit.
Un test se omitirá mientras su atributo `<Fact>` tenga un argumento `Skip`:

```vb
<Fact(Skip:="Remove this Skip property to run this test")>
Public Sub Lowercase_words()
    Assert.Equal("ROR", Abbreviate("Ruby on Rails"))
End Sub
```

Para habilitar el test, solo quita el argumento `Skip`:

```vb
<Fact>
Public Sub Lowercase_words()
    Assert.Equal("ROR", Abbreviate("Ruby on Rails"))
End Sub
```

Después de que el test recién habilitado pase, repite este proceso con el siguiente test omitido.
Cuando todos los tests estén habilitados y pasen, habrás terminado.
