# Introducción

En Elixir, podemos definir atributos de módulo que se pueden usar como constantes en nuestras funciones.

```elixir
defmodule Example do
  # Defines the attribute as the value 1
  @constant_number 1

  def example_value() do
    # Returns the value 1
    @constant_number
  end
end
```

Cuando se usan para definir constantes de módulo, los atributos pueden ser cualquier expresión que se pueda evaluar en tiempo de compilación. Después de la compilación, los atributos de módulo no son accesibles, ya que se expanden durante la compilación, de forma similar a las macros definidas en lenguajes como C.
