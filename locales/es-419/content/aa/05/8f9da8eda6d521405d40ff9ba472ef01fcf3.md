# Pruebas en la línea de comandos

Ejecuta las pruebas con:

```bash
$ cargo test
```

Todas las pruebas, excepto la primera, están ignoradas. Cuando consigas que la primera prueba pase, abre el archivo de código fuente de las pruebas, que está en el directorio `tests`, quita la marca `#[ignore]` de la siguiente prueba y consigue que las pruebas pasen de nuevo. Cada prueba es una función con la marca `#[test]` encima. Continúa así hasta que pases todas las pruebas.

Si quieres ejecutar _solo las pruebas ignoradas_ sin editar el archivo de código fuente de las pruebas, usa:

```bash
$ cargo test -- --ignored
```

Si usas Rust 1.51 o posterior, puedes ejecutar _todas_ las pruebas con

```bash
$ cargo test -- --include-ignored
```

Para ejecutar una prueba específica, por ejemplo `some_test`, puedes usar:

```bash
$ cargo test some_test
```

Si la prueba específica está ignorada, usa:

```bash
$ cargo test some_test -- --ignored
```

Para obtener más información sobre las pruebas de Rust, consulta la [documentación de las pruebas][rust-tests] en línea.

[rust-tests]: https://doc.rust-lang.org/book/ch11-02-running-tests.html
