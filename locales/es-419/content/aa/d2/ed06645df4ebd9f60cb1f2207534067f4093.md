# Acerca de

Las [funciones anónimas][anon-fns] se usan mucho en todo Elixir por sí solas, como valores de retorno y como argumentos en funciones de orden superior como `Enum.map/2`:

```elixir
Enum.map([1, 2, 3], fn n -> n + 1 end)
# => [2, 3, 4]
```

En Elixir, las funciones se tratan como ciudadanos de primera clase:

- Las funciones con nombre y las anónimas se pueden asignar a variables.
- Las funciones con nombre y las anónimas se pueden pasar de un lado a otro como si fueran datos, ya sea como argumentos o como valores de retorno.
- Las funciones anónimas se pueden crear de forma dinámica.

Las funciones anónimas se crean con la palabra clave [`fn`][kernel-fn] y se invocan con un punto (`.`):

```elixir
function_variable = fn n -> n + 1 end

function_variable.(1)
# => 2
```

Las funciones anónimas también se pueden crear con la [forma abreviada de captura `&`][kernel-capture].

- El `&` inicial marca el inicio de la expresión de captura.
- `&1`, `&2` y así sucesivamente se refieren a los argumentos posicionales de la función anónima.

  ```elixir
  # Instead of:
  fn x, y -> abs(x) + abs(y) end

  # We can write:
  &(abs(&1) + abs(&2))
  ```

- El operador de captura `&` también se puede usar para [_capturar_ una función con nombre existente][capture]:

  ```elixir
  # Instead of:
  fn a, b -> a <= b end

  # We can capture the function using its name and arity:
  &<=/2
  ```

Las funciones anónimas en Elixir son [clausuras][closure]. Pueden acceder a las variables que están en el ámbito cuando se define la función. Las variables asignadas dentro de una función anónima no son accesibles fuera de ella:

```elixir
y = 2

square = fn ->
  x = 3
  x * y
end

square.()
# => 6

x
# => ** (CompileError): undefined function x/0
```
