# Pistas

## 1. Verifica que el comando sea válido

- Probablemente vas a necesitar [`ignore_case`][ref-regex] en la definición de la expresión regular.
- Busca solo al inicio del mensaje.

## 2. Elimina los emojis cifrados

- `stringr` tiene las funciones [`str_replace()`][ref-str_replace] y [`str_remove()`][ref-str_remove].

## 3. Verifica que el número de teléfono sea válido

- Decide qué rama tomar según si la expresión regular se [detecta][ref-str_detect] o no.
- Revisa el [concepto de cadenas][concept-strings] si tienes problemas para armar la salida.

## 4. Saluda al usuario

- Vas a necesitar varios grupos de captura.
- [`str_replace()`][ref-str_replace] funciona mejor con capturas _sin nombre_: no lo compliques.

## 5. Obtén el enlace de un sitio web

- Puede haber varias coincidencias en cada mensaje.
- Lee la introducción para ver consejos (cerca del final) sobre cómo usar `str_match_all()` y desempaquetar los resultados: _un poco confuso, pero no realmente difícil_.
