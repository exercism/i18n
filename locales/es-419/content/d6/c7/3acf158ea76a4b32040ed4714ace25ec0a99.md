# Anexo de instrucciones

## Palabras

Define una tupla `linked-list-node`.

Define una tupla `linked-list` y proporciona un método `M: linked-list length` (de `sequences`) para que los tests puedan llamar a `length` directamente en tu lista.

- `<linked-list> ( -- linked-list )`: construye una lista vacía.
- `>linked-list ( seq -- linked-list )`: agrega cada elemento de `seq` a una lista nueva, en orden.
- `linked-list>array ( linked-list -- array )`: devuelve los valores, empezando por el tope de la lista.
- `list-push ( linked-list value -- linked-list )`: agrega un valor en el tope.
- `list-pop ( linked-list -- linked-list value )`: elimina y devuelve el valor del tope.
- `list-peek ( linked-list -- value )`: devuelve el valor del tope sin eliminarlo.
- `list-reverse ( linked-list -- linked-list )`: devuelve una lista con los elementos en orden inverso.

Lanza una clase de error `list-empty` desde `list-pop` y `list-peek` cuando la lista esté vacía.
