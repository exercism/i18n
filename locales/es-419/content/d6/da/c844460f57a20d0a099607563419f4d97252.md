# Introducción

Una *quotation*, es decir, código entre corchetes (`[ ]`), es en sí misma un valor en Factor, igual que un número o un string. Puedes guardar una en una variable, ponerla en un array, pasarla a otra word y *llamarla* después.

## `call`

`call` (en [`kernel`][kernel]) ejecuta una quotation:

```factor
3 4 [ + ] call .
! => 7
```

Cuando haces `call` de una quotation en un contexto donde Factor no puede inferir su efecto de pila, debes declarar el efecto explícitamente:

```
call( stack-effect ) ! e.g. call( a b -- c )
```

```factor
: apply-binary ( a b op -- c )
    call( a b -- c ) ;

5 3 [ - ] apply-binary .
! => 2
```

Esto compila una verificación en tiempo de ejecución de que la quotation realmente tiene el efecto declarado.

## Quotations en secuencias

Como las quotations son valores, un array puede contener una mezcla de números y quotations:

```factor
{ 3 4 [ + ] }
```

Eso hace que «un programa» sea una secuencia normal, y `each` se vuelve una forma natural de ejecutar uno:

```
each ( seq quot -- )
```

```factor
{ [ 1 + ] [ 2 * ] } 5 swap [ call( x -- y ) ] each .
! 5 -> 6 -> 12
```

## Cortar el final de una secuencia

`head*` devuelve todo excepto los últimos `n` elementos; `last2` devuelve los dos últimos:

```
head* ( seq n -- headseq )
last2 ( seq -- penultimate last )
```

```factor
{ 1 2 3 4 5 } 2 head* .    ! => { 1 2 3 }
{ 1 2 3 4 5 } last2 .s
! => 4
! => 5
```

Junto con `suffix`, eso es todo lo que necesitas para escribir una operación de pila que «consume los dos de arriba y empuja un resultado».
