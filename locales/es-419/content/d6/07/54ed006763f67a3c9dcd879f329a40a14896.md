# Bools

Crystal tiene un tipo conocido como [`Bool`][bools].
Representa los valores `true` y `false`.

## Operadores lógicos

Crystal tiene tres operadores lógicos (`!`, `||`, `&&`), que combinan Bools y forman expresiones que producen valores distintos.

### And (`&&`)

El [operador _and_][and] en Crystal se representa con `&&` y devuelve `true` si ambos valores son `true`; de lo contrario, devuelve `false`.
Cuando usas el operador _and_, se coloca un Bool a la derecha del `&&` y otro a la izquierda.

```crystal
true && true
# => true

true && false
# => false
```

### Or (`||`)

El [operador _or_][or] en Crystal se representa con `||` y devuelve `true` si **al menos uno** de los valores dados es `true`.
Si ambos valores son `false`, devuelve `false`.
Cuando usas el operador _or_, debes colocar un Bool a la derecha del `||` y otro a la izquierda.

```crystal
true || true
# => true

true || false
# => true

false || false
# => false
```

### Not (`!`)

El operador _not_ en Crystal se representa con `!` y devuelve `true` si el Bool dado es `false`, y devuelve `false` si se le da `true`.
Cuando usas el operador _not_, debes colocar un Bool después del operador (`!`).

```crystal
!true
# => false

!false
# => true
```

## Uso de paréntesis (`()`)

Cuando trabajas con Bools, puedes usar paréntesis para decidir cuáles se evalúan primero.
El resultado puede variar según cómo se usen los paréntesis.
En Crystal, lo que está entre paréntesis se evalúa primero.

```crystal
true && false && false || true
# => true

true && false && (false || true)
# => false
```

Como lo que está entre paréntesis se evalúa primero, en el siguiente ejemplo el operador _not_ se aplicará a la expresión que está dentro de los paréntesis.

```crystal
!true && false
# => false

!(true && false)
# => true
```

~~~~exercism/note
Solo deberías usar paréntesis cuando afecten el resultado; de lo contrario, conviene omitirlos.
~~~~
