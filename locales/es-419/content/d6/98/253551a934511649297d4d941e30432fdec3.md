# Introducción

Una [`function`][function] es una forma de dividir el código en compartimentos para poder llamarla por su nombre desde uno o más lugares del programa.
Las funciones se usan para realizar tareas específicas y repetitivas.

De forma más formal: una función es cualquier objeto de Python al que se le puede aplicar la operación de [`function call`][calls].
Una función puede usarse para [`return`][return] uno o más valores como resultado de una o varias operaciones, o puede usarse para uno o varios [`side effects`][side effects].
Si una función no especifica un valor de retorno, igual va a devolver `None`.

A continuación, un ejemplo de una función con un efecto secundario:

```python
>>> def hello():
...     print("Hello")
...
>>> hello()
Hello

```

En el ejemplo anterior, la palabra clave [`def`][def] se usa para señalar el inicio de la definición de la función.
`hello` es el nombre de la función.
Los paréntesis vacíos indican que no se le pasa ningún valor a la función.
El cuerpo de la función es la única sentencia `print("Hello")`.
`print` también es una función.
El `"Hello"` dentro de los paréntesis de la función `print` se conoce como [`argument`][arguments].
La función `print` usa el argumento para saber qué imprimir.
Fíjate que el cuerpo de la función está indentado.
La indentación es importante porque Python se basa en ella para saber dónde termina ese bloque de código.
El cuerpo de la función termina ya sea al final del programa o justo antes de la siguiente línea de código que _no_ esté indentada.
Como `hello()` no especifica un valor de `return`, ejecuta su efecto secundario, que es llamar a `print()`, y luego devuelve `None`.
Por último, llamamos a la función usando su nombre y los paréntesis, lo que le indica al intérprete de Python que este es un nombre _invocable_.

A continuación, un ejemplo de una función con un valor de retorno:

```python
>>> def hello():
...     return "Hello"
... 
print(hello())
Hello

```

El cuerpo de esta función cambió de _llamar_ a `print` a _devolver_ el `string` "Hello".
Al final, el código igual imprime `"Hello"`, pero el efecto secundario ocurre en el _código que llama_ en lugar de en la función `hello`.
Si se omiten los paréntesis al llamar a la función `hello` (por ejemplo, `print(hello)`), `print` mostraría algo como

```
<function hello at 0x0000026E18E93E20>
```

Es importante que, aunque una función no acepte argumentos (es decir, que no tenga parámetros), se deben usar los paréntesis vacíos para _llamarla_ correctamente.
Esto es distinto de un lenguaje como Ruby, que no requiere paréntesis vacíos para llamar a una función sin argumentos.

Una función puede definir cero o más [`parameters`][parameters]. Un parámetro define qué argumento(s) acepta la función.

A continuación, un ejemplo de una función que acepta un argumento:

```python
>>> def hello(name):
...     return f"Hello, {name}"
... 
>>> print(hello("Bob"))
Hello, Bob

```

El parámetro está definido como `name`.
`"Bob"` es el argumento que el programa le pasa a la función `hello`.
La función _devuelve_ el `string` "Hello, Bob".

¿Qué pasa si alguien llama a `hello` sin pasarle un argumento?
El programa arroja un error:

```python
print(hello())
Traceback (most recent call last):

  Input In in <line: 1>
    print(hello())

TypeError: hello() missing 1 required positional argument: 'name'
```

Si no queremos que el programa dé error cuando no hay argumento (pero queremos permitir que el código que llama no lo proporcione), podemos definir un [argumento predeterminado][default arguments].
Un argumento predeterminado define qué valor usar si falta el argumento cuando se llama a la función.

A continuación, un ejemplo de una función con un argumento predeterminado:

```python
>>> def hello(name="you"):
...     return f"Hello, {name}"
... 
>>> print(hello())
Hello, you

```

Al parámetro `name` se le da el argumento predeterminado `"you"`, así que el programa muestra `Hello, you` si no se le pasa un argumento `name`.

Para obtener más información sobre los argumentos de las funciones, consulta el concepto [argumentos de funciones][function arguments].
