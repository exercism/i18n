# Anexo de las instrucciones

## Instrucciones adicionales

Se te proporcionará una tabla llamada «isogram».
La primera columna, «phrase», contiene algo de texto.
Debes determinar si la frase es un isograma.
Actualiza la segunda columna, «is_isogram», con un valor entero:

* 1 si la frase es un isograma,
* 0 si no lo es.

~~~~exercism/note
Las operaciones de comparación de SQLite devuelven valores booleanos como números 0/1

```sh
$ sqlite3
sqlite> .mode table
sqlite> SELECT 1 < 2 AS "true", 1 > 2 AS "false";
+------+-------+
| true | false |
+------+-------+
| 1    | 0     |
+------+-------+
```
