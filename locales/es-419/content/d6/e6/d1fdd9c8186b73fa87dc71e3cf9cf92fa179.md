# Instrucciones

Estás escribiendo el núcleo digital de una pequeña consola de mezclas en un estudio de grabación.

El sonido llega como un flujo de muestras. Cada muestra es un número que describe la posición del cono de un altavoz en un instante. Una consola procesa un bloque completo de muestras a la vez, aplicando la misma operación a cada una.

Tienes cinco tareas, y cada una opera sobre un bloque de muestras que está en memoria. Recibes los operandos a través de direcciones de memoria y escribes tu respuesta a través de una dirección de resultado.

~~~~exercism/note
En este ejercicio, los cálculos deben realizarse usando instrucciones SIMD, no operaciones escalares.
~~~~

## 1. Mezcla dos pistas

A veces el estudio graba los instrumentos en pistas distintas. Para reproducirlos por los mismos altavoces, sumas las dos pistas en una.

Implementa la función `mix_tracks`, que suma dos pistas, muestra por muestra. Cada pista es un bloque de 8 muestras de 16 bits con signo. Una suma que desborde el rango de 16 bits con signo debe saturarse en lugar de dar la vuelta.

Esta función recibe como argumentos, en este orden:

- `result`: dirección de memoria alineada a 16 bytes de un búfer donde se escriben las 8 muestras mezcladas.
- `track_a`: dirección de memoria alineada a 16 bytes de la primera pista, con 8 muestras de 16 bits con signo.
- `track_b`: dirección de memoria alineada a 16 bytes de la segunda pista, con 8 muestras de 16 bits con signo.

```c
track_a = {10000, 30000, 20000, -30000, -20000, -100,  100, 0}
track_b = { 5000,  5000, 20000,  -5000, -20000,  100, -100, 0}
result  = {15000, 32767, 32767, -32768, -32768,    0,    0, 0}
```

Esta función no tiene valor de retorno.

## 2. Elimina el sangrado

Cuando dos micrófonos graban a la vez, cada uno capta una copia tenue de la fuente del otro. A esta copia no deseada se le llama _sangrado_. Una vez que se mide ese sangrado, hay que restarlo para limpiar la pista.

Implementa la función `remove_bleed`, que resta el bloque de sangrado del bloque de la pista, muestra por muestra. Cada bloque tiene 8 muestras de 16 bits con signo, y la resta debe saturar.

Esta función recibe como argumentos, en este orden:

- `result`: dirección de memoria donde se escriben las 8 muestras limpias (no se garantiza la alineación).
- `track`: dirección de memoria alineada a 16 bytes de la pista grabada, 8 muestras de 16 bits con signo.
- `bleed`: dirección de memoria del sangrado que hay que eliminar, 8 muestras de 16 bits con signo (no se garantiza la alineación).

```c
track  = {10000, -30000, 5000, 32767, 0,  200, -200, 15000}
bleed  = { 2000,   5000, 5000,    -5, 0,  300,  300,  5000}
result = { 8000, -32768,    0, 32767, 0, -100, -500, 10000}
```

Esta función no tiene valor de retorno.

## 3. Combina los medidores

Encima de cada canal hay un medidor de nivel, una barrita cuyo brillo indica qué tan fuerte es ese canal. El panel frontal tiene un medidor maestro que debe brillar tanto como los dos canales combinados. Sumas los dos bloques de medidores para controlarlo.

Ten en cuenta que un medidor brillante se queda al máximo brillo en lugar de dar la vuelta hasta apagarse, así que la suma satura.

Implementa la función `combine_meters`, que suma dos bloques de medidores muestra por muestra. Esta función recibe como argumentos, en este orden:

- `result`: dirección de memoria alineada a 16 bytes donde se escriben los 16 valores combinados.
- `meter_a`: dirección de memoria alineada a 16 bytes del bloque de medidor del primer canal, con 16 valores de 8 bits sin signo empaquetados.
- `meter_b`: dirección de memoria alineada a 16 bytes del bloque de medidor del segundo canal, con 16 valores de 8 bits sin signo empaquetados.

Cada bloque tiene 16 valores de 8 bits sin signo. Hay que sumarlos, saturando al rango sin signo.

```c
meter_a = {200, 100,  50, 255, 0, 128, 10, 240, 1, 2, 3, 4, 5, 6, 7, 8}
meter_b = {100, 100, 200,   1, 0, 128, 10,  20, 1, 2, 3, 4, 5, 6, 7, 8}
result  = {255, 200, 250, 255, 0, 255, 20, 255, 2, 4, 6, 8, 10, 12, 14, 16}
```

Esta función no tiene valor de retorno.

## 4. Aplica un fundido

La canción no debe detenerse de golpe, sino desvanecerse al final. Tienes un bloque de _coeficientes de ganancia_, uno por muestra, que van bajando cada vez más de volumen.

Cada coeficiente es una fracción expresada sobre `65536`. Por ejemplo, si una muestra tiene un valor de `16384`, en realidad expresa `16384 / 65536`, que es `1 / 4`. El mayor valor utilizable, `32767`, es un poco menos de la mitad.

Como `65536` es `2^16`, multiplicar una muestra por su coeficiente y quedarte con la _mitad alta_ del producto da `sample * gain / 65536`.

Implementa la función `apply_fade`, que escala cada muestra según su coeficiente. Esta función recibe como argumentos, en este orden:

- `result`: dirección de memoria alineada a 16 bytes donde se escriben todas las muestras escaladas.
- `track`: dirección de memoria alineada a 16 bytes de la pista, con `n` muestras de 16 bits con signo.
- `gains`: dirección de memoria alineada a 16 bytes de los coeficientes de ganancia, con `n` valores de 16 bits con signo, cada uno en el rango de `0` a `32767`.
- `n`: la cantidad de muestras, que siempre es distinta de cero y múltiplo de `8`, como un entero de 64 bits sin signo.

Ten en cuenta que la pista es un array que contiene `n` muestras de 16 bits con signo, donde `n` nunca es cero y siempre es múltiplo de `8`. Para cada muestra, el resultado escalado son los 16 bits _altos_ del producto con signo: `sample * gain`.

```c
track  = {20000, 20000, 20000, 20000, -20000, -20000, -20000, -20000}
gains  = {32767, 24576, 16384,  8192,  32767,  24576,  16384,   8192}
result = { 9999,  7500,  5000,  2500, -10000,  -7500,  -5000,  -2500}
```

~~~~exercism/note
Quedarte con la mitad alta redondea hacia menos infinito.
Por eso `20000 * 32767` se escala a `9999`, mientras que `-20000 * 32767` se escala a `-10000` en lugar de `-9999`.
~~~~

Esta función no tiene valor de retorno.

## 5. Atenúa una pista

El baterista se grabó demasiado fuerte. Para bajar toda la pista, divides cada muestra entre una constante.

Implementa la función `attenuate_track`. Esta función recibe como argumentos, en este orden:

- `result`: dirección de memoria alineada a 16 bytes donde se escriben los resultados, como enteros de 32 bits con signo.
- `samples`: dirección de memoria alineada a 16 bytes de las muestras, `n` valores de 16 bits con signo.
- `divisor`: dirección de memoria alineada a 16 bytes de 4 copias idénticas del divisor, como enteros de 32 bits.
- `n` es la cantidad de muestras, que siempre es distinta de cero y múltiplo de `4`, como un entero de 64 bits sin signo.

Ten en cuenta que `samples` es un array que contiene `n` muestras de 16 bits con signo, donde `n` nunca es cero y siempre es múltiplo de `4`.

El divisor se proporciona como `4` copias del mismo entero de 32 bits, ya replicadas para que pueda llenar los cuatro carriles a la vez.

El SIMD de enteros no tiene división empaquetada, así que el trabajo se hace en punto flotante empaquetado y luego se convierte de nuevo a enteros de 32 bits empaquetados para guardarlos en `result`. Convierte de vuelta truncando hacia cero, así que un cociente de `2.3` se convierte en `2` y `-2.3` se convierte en `-2`.

```c
samples = {300, 150, 90, -120, 100, 50, -50, 7}
divisor = {3, 3, 3, 3}
result  = {100,  50, 30,  -40,  33, 16, -16, 2}
```

Esta función no tiene valor de retorno.
