# Acerca de las funciones anónimas y las clausuras

PHP permite declarar funciones dentro de otras funciones. Estas funciones no necesitan tener un nombre, pero se pueden asignar a variables o incluso pasar directamente a otra función que requiera un parámetro de tipo función.

```php
function onlyOdds(array $numbers): array
{
    return array_filter($numbers, function($num) {
        return $num % 2 === 1;
    });
}
```

La función que se define y se pasa a `array_filter` arriba es una función anónima. La función `array_filter` la usa para determinar si un valor dado de un array se devolverá en el resultado de `array_filter`. Si la función devuelve `true` para un valor, ese valor se incluirá en el array de resultado.

Las funciones anónimas también sirven para hacer referencia, desde dentro de la función, a variables que están en el ámbito de fuera de la función. Esto se conoce como que el ámbito de la función se «cierra» sobre la variable que se usa en la función, de ahí el nombre de «clausura». En algunos lenguajes, todas las variables del ámbito se pueden usar automáticamente dentro de la clausura. En el caso de PHP, `$this`, que hace referencia al objeto actual, se permite automáticamente dentro de la clausura. Todas las demás variables deben referenciarse explícitamente con la palabra clave `use`.

```php
function makeAdderFunction(int $number) {
    return function(int $x) use($number) {
        return $x + $number;
    }
}

$add5 = makeAdderFunction(5);
echo $add5(4); // echos 9
```

En la función `makeAdderFunction` de arriba, la función anónima definida internamente se «cierra» sobre el valor de `$number` que se pasa, y después esa función se devuelve. Luego, cada vez que se ejecuta esa función, sabe el valor de `$number` que se pasó. Si volvieras a llamar a esta función con otro número, devolvería una función completamente distinta. No cambiaría los valores ni la funcionalidad que devuelve la primera llamada a la función.
Si necesitas cerrarte sobre más de una variable, puedes agregarlas a la palabra clave `use` separadas por comas.

PHP también tiene una sintaxis de función más corta llamada `arrow functions`. Deben ser bastante simples. Su forma básica es:

```php
fn(arguments) => expression
```

En este estilo de función, no necesitas usar `use`. De forma automática se cerrará sobre cualquier valor del ámbito padre y lo capturará. La expresión de estas funciones flecha se devuelve automáticamente sin necesidad de usar la palabra clave `return`. Eso nos permitiría reescribir la función `onlyOdds` de arriba así:

```php
function onlyOdds(array $numbers): array
{
    return array_filter($numbers, fn($n) => $n % 2 == 1);
}
```

La `makeAdderFunction` de arriba se podría reescribir así:

```php
function makeAdderFunction(int $number) {
    return fn(int $x) => $x + $number;
}
```

**Nota:** Si la función no se puede escribir como una expresión, entonces no se puede usar la sintaxis más corta de las funciones flecha.

Las variables se pasan y se usan dentro de las funciones anónimas y las clausuras por valor. Esto significa que si cambias el valor de la variable dentro de la función, no afectará el valor de la variable fuera de la función. Si necesitas que el valor se modifique, puedes pasarlo por referencia.

```php
function positiveAverage(array $numbers): float
{
    $total = 0;
    $count = 0;
    return array_walk(
      $numbers,
      function($num) use (&$count, &$total) {
          $total += abs($num);
          $count++;
      }
    );
    return $total / $count;
}
```

En el ejemplo de arriba, `array_walk` recorre cada elemento del array y envía cada valor a la función declarada en la llamada. Lleva un total acumulado en `$total`, donde cada valor que se suma es el valor absoluto del número. También lleva la cuenta de cuántos números había. Ambos valores se usan en la clausura por referencia, lo cual se indica con el `&` delante de cada variable dentro de la sección `use`. Esto significa que los cambios que ocurren en las variables seguirán vigentes cuando `array_walk` termine, de modo que la función pueda devolver el promedio de los valores absolutos de los números del array.

Las funciones anónimas y las clausuras pueden ofrecer una forma práctica de definir una función que quizá solo se necesite en un contexto determinado, o de definir una función que devuelva una función dinámica a partir de un conjunto de parámetros que se conocen en un momento distinto al de su uso real.
