# Acerca de

El tipo primitivo `char` de Java es una representación de 16 bits de un solo carácter Unicode.

~~~~exercism/note
El tipo `char` se basa en la [especificación original de Unicode][unicode-specification], que usaba 16 bits para representar caracteres.
Eso alcanza para cubrir la mayoría de las letras comunes y abarca los caracteres en el rango de 0x0000 a 0xFFFF.
Desde entonces, la especificación amplió el rango de caracteres posibles hasta 0x01FFFF.

[unicode-specification]: https://www.unicode.org/versions/Unicode1.0.0/
~~~~

Varios `char` pueden componer un string, como `"word"`, o los `char` se pueden procesar de forma independiente.
Un literal `char` va entre comillas simples (por ejemplo, `'A'`).

```java
char lowerA = 'a';
char upperB = 'B';
```

## Cómo obtener los `char` de un `String`

El método `String.toCharArray` devuelve los caracteres de un String como un array.
Como se menciona en [arrays][concept-arrays], puedes usar un bucle `for` para iterar sobre el array.

```java
String text = "Hello";
char[] asArray = text.toCharArray();

for (char ch: asArray) {
    System.out.println(ch);
}

// Outputs:
// H
// e
// l
// l
// o
```

## La clase [Character][docs-character]

Hay muchos métodos integrados de la biblioteca para inspeccionar y manipular `char`.
Los puedes encontrar como métodos estáticos de la clase [`java.lang.Character`][docs-character].
Aquí tienes algunos ejemplos:

```java
Character.isWhitespace(' ');    // true
Character.isWhitespace('#');    // false

Character.isLetter('a');        // true
Character.isLetter('3');        // false

Character.isDigit('6');         // true
Character.isDigit('?');         // false
```

~~~~exercism/note
Algunos métodos de la clase Character tienen una sobrecarga para poder recibir un `char` o un `int`.
Por ejemplo, `isDigit` tiene una que acepta un [`char`][is-digit-char] y otra un [`int`][is-digit-int].
Como se mencionó antes, el tipo `char` solo puede representar los caracteres en el rango de 0x0000 a 0xFFFF.
El `int`, sin embargo, puede representar todos los caracteres, de ahí las sobrecargas de `int`.

[is-digit-char]: https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/lang/Character.html#isDigit(char)
[is-digit-int]: https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/lang/Character.html#isDigit(int)
~~~~

## Cómo agregar un `char` a un `String`

El operador `+` se puede usar para agregar un `char` a un `String`.

```java
'a' + " banana"     // => "a banana"
"banana " + 'a'     // => "banana a"
```

~~~~exercism/caution
¡Ten cuidado de _no_ usar `+` para unir dos `char` y formar un `String`!
¡Sumar dos `char` de esta forma da un `int`, _no_ un `String`!
Por ejemplo:

```java
'b' + 'c';
// => 197 (not the String "bc")
```

Esto se debe a que Java promueve el `char` a un `int` (consulta [4.2 Primitive Types and Values ][jls-primitives] de la [Java Language Specification][jls-main]).

[jls-main]: https://docs.oracle.com/javase/specs/jls/se21/html/
[jls-primitives]: https://docs.oracle.com/javase/specs/jls/se21/html/jls-4.html#jls-4.2
~~~~

Sin embargo, cuando hay muchos caracteres para agregar, puede ser más eficiente usar un [`StringBuilder`][docs-stringBuilder] en su lugar:

```java
StringBuilder builder = new StringBuilder();
builder.append('a');
builder.append('b');
builder.append('c');

String builtString = builder.toString();
// => abc
```
