# Instrucciones

En este ejercicio, vas a escribir código para ayudar a un freelancer a comunicarse con un gerente de proyecto.
Tu tarea es crear algunas utilidades para calcular rápidamente tarifas diarias y mensuales, opcionalmente con un descuento dado.

Primero establecemos algunas reglas entre el freelancer y el gerente del proyecto:

- La tarifa diaria es 8 veces la tarifa por hora.
- Un mes tiene 22 días facturables.

A veces, el freelancer ofrece aplicar un descuento sobre su tarifa diaria (por ejemplo, para sus clientes más leales o para clientes sin fines de lucro).

Los descuentos se modelan como números fraccionarios que representan porcentajes, por ejemplo, `25.0` (25 %).

## 1. Calcula la tarifa diaria a partir de una tarifa por hora

Implementa una función llamada `daily_rate` que calcule la tarifa diaria a partir de una tarifa por hora como parámetro.
El contrato define que un día tiene 8 horas facturables.

```cpp
daily_rate(60)
// => 480.0
```

La tarifa diaria devuelta debe ser de tipo `double`.

## 2. Calcula un precio con descuento

Implementa una función `apply_discount` que calcule el precio después de un descuento.
Debe aceptar dos parámetros: el precio original y la tasa de descuento en porcentaje.

```cpp
apply_discount(150, 10)
// => 135.0
```

El valor devuelto siempre debe ser de tipo `double`, sin redondear de ninguna forma.

## 3. Calcula la tarifa mensual a partir de una tarifa por hora y un descuento

Implementa una función `monthly_rate` que calcule la tarifa mensual con descuento.
Debe tener dos parámetros: una tarifa por hora y el descuento en porcentaje.

```cpp
monthly_rate(77, 10.5)
// => 12130
```

La tarifa mensual devuelta debe redondearse hacia arriba (tomar el techo) al entero más cercano.

## 4. Calcula el número de días de trabajo completos a partir de un presupuesto, una tarifa por hora y un descuento

Implementa una función `days_in_budget` que reciba un presupuesto, una tarifa por hora y un descuento, y calcule cuántos días completos de trabajo cubre.

```cpp
days_in_budget(20'000, 80, 11.0)
// => 35
```

El número de días devuelto debe redondearse hacia abajo (tomar el piso) al entero inferior.
