# Pruebas

Antes de intentar ejecutar las pruebas, asegúrate de que la carpeta del ejercicio esté configurada correctamente siguiendo los pasos de instalación, es decir, `corepack yarn install` y la configuración del Editor SDK.

Ejecuta las pruebas con:

```bash
$ corepack yarn test
```

Asegúrate de que tu código siga las buenas prácticas, como lo hacen otros usuarios, con eslint, una herramienta que realiza análisis estático de tu código.
Herramientas como esta te ahorran tiempo al detectar errores tipográficos o errores tontos en tu código:

```bash
$ corepack yarn lint
```

O haz ambas cosas al mismo tiempo:

```bash
$ corepack yarn test && corepack yarn lint
```

El track de TypeScript en Exercism no impone un _estilo_ de código, así que eres libre de elegir entre puntos y coma, tabulaciones o espacios, y todo lo intermedio.

## Cómo hacer tu primer módulo

Normalmente, las pruebas en este track cargarán tu implementación importándola como un módulo: `import Bob from './bob';`.
Para que funcione, necesitas exportar tu implementación desde el archivo donde las pruebas buscan tu módulo, `bob.ts`:

```typescript
export class Bob {
  public hey(message: string) {
    // Your solution here
  }
}
```

Hemos proporcionado stubs en cada ejercicio y hemos colocado este `export` allí para ti.
