# Apéndice de instrucciones

## Algunas pistas

Para la función `filelike_objects_are_closed_on_exception`, el `filelike_object`
será una instancia de una clase `FileLike` personalizada definida en el conjunto de pruebas.
Esta clase implementa los siguientes métodos:

- `open` y `close`, para abrir y cerrar de forma explícita.
- `__enter__` y `__exit__`, para abrir y cerrar de forma implícita.
- `do_something`, que puede lanzar o no una `Exception`.
