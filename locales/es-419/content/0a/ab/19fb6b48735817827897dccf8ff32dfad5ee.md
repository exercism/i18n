# Pistas

## General

- `*T` se puede usar para declarar variables que son punteros a algún tipo `T`, por ejemplo `var i *int` declara una variable `i` que es un puntero a un `int`
- Puedes obtener un puntero a una variable (su dirección de memoria) usando el operador `&`, por ejemplo `mypointer := &anIntVariable`.
- Puedes obtener el valor almacenado en un puntero usando el operador `*` sobre un puntero, por ejemplo `var i int = *aPointerToInt`.
  Esto se llama desreferenciar el puntero.
- Verifica que un puntero no sea `nil` antes de desreferenciarlo.
  Si intentas desreferenciar un puntero `nil`, obtendrás un error en tiempo de ejecución.
- Si tienes dudas sobre cómo funcionan los punteros, prueba leer [Tour of Go: Pointers][go-tour-pointers] o [Go by Example: Pointers][go-by-example-pointers]

## 1. Crea un contador de votos

- Necesitas crear un puntero a un `int`, es decir, un `*int`.
- Puedes usar el operador `&` sobre una variable para crear un puntero a ella, por ejemplo `&myInt`
- Puedes crear un puntero a una variable nueva definida por ti, o puedes usar la variable del argumento de la función

## 2. Obtén el número de votos de un contador

- Puedes usar el operador `*` sobre un puntero para desreferenciarlo y obtener su valor, por ejemplo `*myPointer`
- Desreferenciar punteros `nil` te dará un error en tiempo de ejecución.
  Siempre asegúrate de que un puntero no sea `nil` antes de desreferenciarlo.

## 3. Incrementa los votos de un contador

- Si tienes un puntero `var myPointer *int`, puedes asignar a `*myPointer` para cambiar el valor al que apunta `myPointer`
- Para obtener el valor actual del puntero, necesitas desreferenciarlo usando el operador `*`, o llamar a la función que hiciste en la tarea anterior.

## 4. Crea los resultados de la elección

- Crea un literal o una variable `ElectionResult` nueva con los campos `Name` y `Votes` llenos con los valores de los argumentos de la función.
- Puedes crear un puntero a partir de una variable o un literal usando el operador `&` antes del nombre de la variable o de la declaración del literal, por ejemplo `&myVariable` o `&ElectionResult{Name: "John", Votes: 1}`

## 5. Anuncia los resultados

- Aunque recibes un puntero a un `ElectionResult`, puedes acceder a sus campos con la notación de punto `.`, ¡como si no fuera un puntero!
- Construye el mensaje accediendo a los campos `Name` y `Value` de la estructura.
- Aunque estás accediendo a campos desde un puntero a una estructura, no necesitas desreferenciar nada.
  Go desreferenciará el puntero automáticamente por ti, como en este ejemplo:

```go
result := &ElectionResult{
    Name: "John",
    Votes: 32
}

result.Name // "John" - Go will automatically dereference the pointer
            //          and access the 'Name' field of the dereferenced struct 
```

## 6. Recuento de votos

- Puedes pensar en los mapas como si ya fueran punteros.
  Esto significa que los cambios que hagas al mapa dentro de la función serán visibles fuera de la función.
- Para incrementar el valor de una clave en un `var m map[string]int`, tienes varias opciones: `m["mykey"] = m["mykey"] + 1`, `m["mykey"] += 1` o `m["mykey"]++`.
