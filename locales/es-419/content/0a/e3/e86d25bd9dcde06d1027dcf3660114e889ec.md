# Instrucciones

En este ejercicio, implementarás la lógica de una misión para un nuevo juego de rol que está desarrollando un amigo. La protagonista del juego es Annalyn, una chica valiente con un perro feroz y leal. Por desgracia, todo se complica cuando secuestran a su mejor amigo mientras busca bayas en el bosque. Annalyn intentará encontrarlo y liberarlo, y puede que lleve a su perro con ella en esta misión.

Después de pasar un tiempo siguiendo el rastro de su mejor amigo, encuentra el campamento en el que está prisionero. Resulta que hay dos secuestradores: un caballero poderoso y un arquero astuto.

Una vez localizados los secuestradores, Annalyn se plantea cuál de las siguientes acciones puede llevar a cabo:

- Ataque rápido: se puede hacer un ataque rápido si el caballero está dormido, ya que tarda en ponerse la armadura, así que estará vulnerable.
- Espiar: se puede espiar al grupo si al menos uno de ellos está despierto. De lo contrario, espiar es una pérdida de tiempo.
- Hacer señales al prisionero: se le pueden hacer señales al prisionero usando sonidos de aves si el prisionero está despierto y el arquero está dormido, ya que los arqueros están entrenados en el lenguaje de las aves y podrían interceptar el mensaje.
- _Liberar al prisionero_: Annalyn puede intentar colarse en el campamento para liberar al prisionero.
  Es algo arriesgado y solo puede salir bien de una de estas dos maneras:
  - Si Annalyn lleva a su perro, puede rescatar al prisionero si el arquero está dormido.
    El caballero le tiene miedo al perro y el arquero no tendrá tiempo de prepararse antes de que Annalyn y el prisionero escapen.
  - Si Annalyn no lleva a su perro, ella y el prisionero tendrán que ser muy sigilosos.
    Annalyn puede liberar al prisionero si el prisionero está despierto y tanto el caballero como el arquero están dormidos; pero si el prisionero está dormido, no se lo puede rescatar: el prisionero se asustaría con la aparición repentina de Annalyn y despertaría al caballero y al arquero.

Tienes cuatro tareas: implementar la lógica para determinar si las acciones anteriores están disponibles según el estado de los tres personajes que se encuentran en el bosque y según si el perro de Annalyn está presente o no.

## 1. Comprueba si la acción «ataque rápido» es posible

Implementa una función llamada `canExecuteFastAttack` que toma un valor Boolean que indica si el caballero está despierto. Esta función devuelve `true` si la acción «ataque rápido» está disponible según el estado del personaje. De lo contrario, devuelve `false`:

```purescript
knightIsAwake :: Boolean
knightIsAwake = true

canExecuteFastAttack knightIsAwake
-- => false
```

## 2. Comprueba si la acción «espiar» es posible

Implementa una función llamada `canSpy` que toma tres valores Boolean, que indican si el caballero, el arquero y el prisionero, respectivamente, están despiertos. La función devuelve `true` si la acción «espiar» está disponible según el estado de los personajes. De lo contrario, devuelve `false`:

```purescript
knightIsAwake :: Boolean
knightIsAwake = true

archerIsAwake :: Boolean
archerIsAwake = true

prisonerIsAwake :: Boolean
prisonerIsAwake = true

canSpy knightIsAwake archerIsAwake prisonerIsAwake
-- => true
```

## 3. Comprueba si la acción «hacer señales al prisionero» es posible

Implementa una función llamada `canSignalPrisoner` que toma dos valores Boolean, que indican si el arquero y el prisionero, respectivamente, están despiertos. La función devuelve `true` si la acción «hacer señales al prisionero» está disponible según el estado de los personajes. De lo contrario, devuelve `false`:

```purescript
archerIsAwake :: Boolean
archerIsAwake = false

prisonerIsAwake :: Boolean
prisonerIsAwake = true

canSignalPrisoner archerIsAwake prisonerIsAwake -- => true
```

## 4. Comprueba si la acción «liberar al prisionero» es posible

Implementa una función llamada `canFreePrisoner` que toma cuatro valores Boolean. Los tres primeros parámetros indican si el caballero, el arquero y el prisionero, respectivamente, están despiertos. El último parámetro indica si el perro de Annalyn está presente. La función devuelve `true` si la acción «liberar al prisionero» está disponible según el estado de los personajes y la presencia del perro de Annalyn. De lo contrario, devuelve `false`:

```purescript
knightIsAwake :: Boolean
knightIsAwake = true

archerIsAwake :: Boolean
archerIsAwake = false

prisonerIsAwake :: Boolean
prisonerIsAwake = true

petDogIsPresent :: Boolean
petDogIsPresent = true

canFreePrisoner knightIsAwake archerIsAwake prisonerIsAwake petDogIsPresent
-- => false
```
