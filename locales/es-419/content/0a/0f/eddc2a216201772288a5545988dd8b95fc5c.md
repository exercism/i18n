# No uses el método main

Intenta eliminar el método `main` de tu código.
Las pruebas del ejercicio no requieren que las soluciones tengan un método `main`, y tenerlo hace que el código sea un poco más difícil de leer.

Por lo general, se agrega un método `main` para ayudar a depurar el código.
Sin embargo, un mejor enfoque es depurar el código mientras ejecutas una o varias pruebas unitarias.
Esto tiene la ventaja adicional de que puedes concentrarte en depurar un caso de prueba específico.

Aquí tienes algunos enlaces que explican cómo depurar código Java mientras ejecutas pruebas unitarias en varios IDE:

- [Ejecutar y depurar pruebas de Java en Visual Studio Code](https://code.visualstudio.com/docs/java/java-testing#_rundebug-test-cases)
- [Depurar pruebas en IntelliJ IDEA](https://www.jetbrains.com/help/idea/performing-tests.html#RedebugFailedTests)
