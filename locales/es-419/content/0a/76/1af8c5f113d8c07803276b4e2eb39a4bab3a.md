# Orden de las anotaciones de función

Por convención, las anotaciones de función `@doc` deben ir antes de las anotaciones de función `@spec`, y las anotaciones de función `@spec` deben ir directamente antes de la función. Si la función tiene varias cláusulas, las anotaciones de función deben ir antes de la primera cláusula.

Ejemplo:

```elixir
@doc """
This function counts the number elements in a list
"""
@spec count(list(any())) :: integer()
def count([]), do: 0
def count([h | t]), do: 1 + count(t)
```
