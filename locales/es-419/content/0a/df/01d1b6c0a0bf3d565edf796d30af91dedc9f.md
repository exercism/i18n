# Instrucciones

Estás implementando un sistema ORM (mapeo objeto-relacional) sobre una base de datos que otro equipo te proporcionó.

La base de datos puede manejar una sola transacción a la vez.

En esta etapa no se requiere registro ni ningún otro manejo de errores.

Ten en cuenta que, de forma interna, la base de datos pasa por varios estados: Closed, TransactionStarted, DataWritten, Invalid, Closed. Puedes confiar en que la base de datos está en un estado `Closed` al inicio de cada ejercicio.

La base de datos tiene los siguientes métodos de instancia:

- `Database.BeginTransaction()` inicia una transacción en la base de datos. Si se llama cuando la base de datos no está en un estado `Closed`, se lanzará una excepción. Si tiene éxito, el estado interno de la base de datos cambiará a `TransactionStarted`.
- `Database.Write(string data)` escribe datos en la base de datos dentro de la transacción. Si recibe datos incorrectos, se lanzará una excepción. Si intentas llamar a este método sin haber llamado antes a `BeginTransaction()`, se lanzará una excepción. Si tiene éxito, el estado interno de la base de datos cambiará a `DataWritten`.
- `Database.EndTransaction()` confirma la transacción en la base de datos. Puede lanzar una excepción si no puede cerrar la transacción o si no se había llamado a `Database.BeginTransaction()`.
- Una llamada a `Database.Dispose()` limpiará la base de datos si se lanza una excepción durante una transacción. Esto cambiará el estado de la base de datos a `Closed`.

Se puede acceder al estado de la base de datos con `database.DbState`.

El estado de la base de datos se puede establecer en uno de los siguientes:

- TransactionStarted
- DataWritten
- Invalid
- Closed

## 1. Inicia una transacción

Implementa `Orm.Begin()` para iniciar una transacción en la base de datos. Si la base de datos no comienza con un estado interno de `State.Closed`, lanzará una `InvalidOperationException`.

```csharp
var orm = new Orm(new Database());
orm.Begin();
// => database has an internal state of State.TransactionStarted
```

## 2. Escribe algunos datos en la base de datos

Implementa `Orm.Write()` para escribir algunos datos en la base de datos. Si la base de datos no comienza con un estado interno de `State.TransactionStarted` o si se escriben datos incorrectos, se lanzará una `InvalidOperationException`. Si la escritura falla, el `Orm` debe limpiar la base de datos.

```csharp
var orm = new Orm(new Database());
orm.Begin();
orm.Write("some data");
// => database has an internal state of State.DataWritten
orm.Write("bad write");
// => database has an internal state of State.Closed
```

## 3. Confirma en la base de datos los datos escritos previamente

Implementa `Orm.Commit()` para confirmar los datos. Si la confirmación falla, limpia la base de datos. Si la base de datos no comienza con un estado interno de `State.DataWritten`, se lanzará una `InvalidOperationException`.

```csharp
var orm = new Orm(new Database());
orm.Begin();
orm.Write("some data");
orm.Commit();
// => database has an internal state of State.Closed
orm.Begin();
orm.Write("bad commit");
orm.Commit();
// => database has an internal state of State.Closed
```

## 4. Asegúrate de que la base de datos se limpie correctamente si el ORM tiene que cerrarse a mitad de una transacción.

Implementa la interfaz `IDisposable` en la clase `Orm`. Se garantiza que la llamada tendrá éxito.

```csharp
var db = new Database();
var orm = new Orm(db);
orm.Begin();
orm.Write("some data");
orm.Dispose();
// => database has an internal state of State.Closed
```
