El objetivo de este ejercicio es mejorar el ejercicio Verificador de contraseñas.

Como es probable que una contraseña dada viole más de una regla a la vez, un verificador de contraseñas útil debería comunicarle al usuario todas las reglas que se violan, en lugar de solo la primera que se descubra. El verificador de contraseñas mejorado debería indicar de una sola vez todas las reglas que viola una contraseña dada.

Las reglas de este verificador de contraseñas son las mismas del ejercicio anterior, Verificador de contraseñas:

- Debe tener 12 caracteres o más
- Debe tener al menos una letra mayúscula
- Debe tener al menos una letra minúscula
- Debe tener al menos un dígito
- Debe tener al menos un símbolo del conjunto `!@#$%^&\*`

## 1. Modifica la unión discriminada `PasswordError` para permitir que los valores individuales se traten como flags

Ten en cuenta que los tests no compilarán hasta que completes este paso esencial.

## 2. Implementa la función `checkPassword`

La función `checkPassword` verifica la contraseña dada contra las reglas antes mencionadas.
La función debe devolver un valor `Result`, donde se devuelve `Ok` cuando la contraseña cumple todas las reglas, y un valor `Error` cuando no cumple una o más reglas.
Si la contraseña dada no cumple varias reglas, el valor `PasswordError` debe representar todas las reglas que no cumple.

```fsharp
checkPassword "abcdefghijk5"
// => Error (PasswordError.MissingUppercaseLetter ||| PasswordError.MissingSymbol)
```

## 3. Implementa la función ``getStatusPhrases`

La función `getStatusPhrases` devuelve un conjunto de strings, cada uno con una frase legible para las personas que corresponde a uno de los errores del resultado devuelto por `checkPassword`.

```fsharp
getStatusPhrases (Error PasswordError.MissingDigit ||| PasswordError.LessThan12Characters)
// => List ["12 characters"; "digit"]
```
