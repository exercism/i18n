# Apéndice de instrucciones

Deberías implementar este ejercicio usando una gramática de cláusulas definidas (DCG).
Las DCG no solo se pueden usar para analizar secuencias (listas), sino también para generarlas, completarlas y comprobarlas.

## Biblioteca

Los archivos de implementación inicial incluyen la siguiente línea:

```prolog
:- use_module(library(dcg/basics)).
```

Esto asegura que se pueda usar la biblioteca `dcg/basics`, lo cual debería ser suficiente para resolver este ejercicio.
