# Introducción

Un tipo es un _tipo genérico_ cuando puede contener valores de cualquier tipo usando un _parámetro de tipo_.

Por ejemplo, este tipo `Box` tiene el parámetro de tipo `a` (que se escribe con minúsculas).

```gleam
pub type Box(a) {
  Box(a)
}
```

El parámetro de tipo `a` es un marcador de posición para cualquier tipo, por lo que `Box` se puede usar con strings, con enteros o con cualquier otro tipo.

```gleam
Box("Hello, Joe!") // The type is Box(String)

Box(42) // The type is Box(Int)
```

Un tipo puede tener varios parámetros de tipo si los separas con comas.

```gleam
pub type Pair(a, b) {
  Pair(a, b)
}
```

## Funciones genéricas

Los parámetros de tipo también se pueden usar en los argumentos de las funciones.

Esta función recibe un valor de tipo `a` y llama dos veces a una función que recibe un `a` y devuelve un `b`.

```gleam
pub fn twice(value: a, f: fn(a) -> b) -> b {
  f(value)
  f(value)
}
```
```gleam
// The type is fn(String, fn(String) -> Nil) -> Nil
twice("Hello, Joe!", io.println)
```
