# Instrucciones

Estás de aprendiz en un pequeño taller de muebles. La tableta del maestro carpintero ejecuta Factor y lleva la lista de cortes: cada tabla que llega al banco de trabajo se mide con algunos valores derivados antes de hacer el primer corte.

El aprendiz anterior dejó el código convertido en una jungla de `dup`, `over`, `swap` y `rot`. Tu tarea es reescribir cinco pequeñas palabras usando *combinadores*.

Cada tabla entra al flujo de trabajo con solo su longitud en bruto (cm) en la pila.

## 1. Agrega el margen del kerf

Las hojas de sierra quitan una tira delgada de madera en cada corte: el *kerf*. El taller presupuesta un 2% de longitud extra en cada tabla para absorberlo.

Define `with-kerf` para que tome una longitud y devuelva la longitud más su margen de kerf del 2%.

```factor
100 with-kerf .
! => 102
```

## 2. Calcula los márgenes de kerf y de acabado

Después de cortar viene el acabado, es decir, el lijado y el cepillado, que quita otro 5% de la longitud original.

Define `kerf-and-finish` para que devuelva *ambos* márgenes uno junto al otro (el de kerf abajo, el de acabado arriba).

```factor
100 kerf-and-finish .s
! => 2
! => 5
```

## 3. Arma la tarjeta de corte

Cada tabla que corta el maestro lleva pegada una pequeña tarjeta que enumera la longitud en bruto, el margen de kerf y el margen de acabado: tres números, en ese orden.

Define `cut-card` para que devuelva los tres.

```factor
100 cut-card .s
! => 100
! => 2
! => 5
```

## 4. Longitud por pieza

El taller también recibe *rollos* de madera en grandes cantidades que hay que dividir en piezas iguales. El margen de kerf se suma una sola vez a la longitud del rollo y luego el resultado se divide entre el número de piezas.

Define `per-piece` para que tome la longitud del rollo y el número de piezas, con el número de piezas en la parte superior de la pila, y devuelva la longitud por pieza.

```factor
100 2 per-piece .
! => 51

100 4 per-piece .
! => 25+1/2
```

## 5. Compara dos rollos

A veces el maestro está eligiendo entre dos rollos en la maderería y quiere comparar sus márgenes de kerf de un vistazo.

Define `compare-bolts` para que tome dos longitudes de la pila y devuelva el margen de kerf de cada una (en el mismo orden).

```factor
50 100 compare-bolts .s
! => 1
! => 2
```
