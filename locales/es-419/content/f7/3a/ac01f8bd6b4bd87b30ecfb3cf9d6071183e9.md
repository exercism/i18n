# Introducción

El [tipo `enum` de C#](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/builtin-types/enum) representa un conjunto fijo de constantes con nombre (una enumeración).

Normalmente, un miembro de un `enum` solo puede referirse a exactamente una de esas constantes con nombre. Sin embargo, a veces es útil referirse a más de una constante. Para lograrlo, se puede anotar el `enum` con el [atributo `Flags`](https://docs.microsoft.com/en-us/dotnet/api/system.flagsattribute)

Un enum de flags se puede definir de la siguiente manera (usando la notación binaria `0b`):

```csharp
[Flags]
enum PhoneFeatures
{
    Call = 0b00000001,
    Text = 0b00000010
}
```

Una instancia de `PhoneFeatures` cuyo valor es `0b00000011` tiene activados sus flags `Call` _y_ `Text`.

De forma predeterminada, se usa el tipo `int` para los valores de los miembros de un enum. Se puede usar un tipo entero diferente especificando el tipo en la declaración del enum:

```csharp
[Flags]
enum PhoneFeatures : byte
{
    Call = 0b00000001,
    Text = 0b00000010
}
```
