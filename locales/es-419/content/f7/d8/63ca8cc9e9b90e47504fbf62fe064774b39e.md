# Pistas

## 1. Define si Pac-Man puede comer un fantasma

* La función debe devolver un valor Boolean.
* Puedes usar el operador lógico `and` para combinar los argumentos y obtener un resultado.

## 2. Define si Pac-Man anota

* La función debe devolver un valor Boolean.
* Puedes usar el operador Boolean `or` para combinar los argumentos y obtener un resultado.

## 3. Define si Pac-Man pierde

* La función debe devolver un valor Boolean.
* Puedes usar los operadores Boolean `and` y `not` para combinar los argumentos y obtener un resultado.

## 4. Define si Pac-Man gana

* La función debe devolver un valor Boolean.
* Puedes usar los operadores Boolean `and` y `not` para combinar los argumentos y los resultados de una de las funciones que implementaste antes.
