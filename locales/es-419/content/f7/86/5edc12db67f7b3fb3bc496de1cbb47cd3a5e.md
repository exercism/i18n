# Pistas

## General

- No te preocupes por los tipos de números específicos; por ahora usa `Int32` y `Float64`.
- Int32 y Float64 son los tipos de números predeterminados en Crystal, así que no necesitas especificarlos.

## 1. Convierte la temperatura de Celsius a Kelvin

- Puedes usar el operador aritmético (`+`) para sumar números.

## 2. Redondea la temperatura

- Puedes usar el método `round` para redondear un número a una cantidad específica de decimales.
- El método `round` toma un argumento `places` que especifica la cantidad de decimales a los que redondear.

## 3. Convierte la temperatura de Celsius a Fahrenheit

- Puedes usar el operador aritmético (`*`) para multiplicar números.
- Puedes usar paréntesis (`()`) para agrupar operaciones.

## 4. Obtén la cantidad de sensores faltantes

- Puedes usar el operador aritmético (`-`) para restar números.
- Puedes usar el operador aritmético (`%`) para obtener el residuo de una división.
