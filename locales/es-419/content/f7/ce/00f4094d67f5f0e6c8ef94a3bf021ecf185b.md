# Anexo de instrucciones

## Instrucciones específicas del track

Tendrás que implementar tu propio operador de igualdad para el objeto `ComplexNumber`.
Esto plantea el reto de comparar dos números de punto flotante.
Puede ser útil usar el método `isApproximatelyEqual(to:absoluteTolerance:)`, que se encuentra en la biblioteca [Numerics][swift-numberics].
Debido a problemas de rendimiento, solo tendrás acceso a la parte `RealModule`.
Para importarlo, simplemente escribe: `import RealModule` al inicio del archivo.
Una tolerancia de `0.00001` debería ser suficiente para pasar los tests.
La biblioteca ya está incluida en el proyecto, así que solo tienes que importarla en tu archivo.

También puedes implementar tu propio método para comparar los dos números complejos.

[swift-numberics]: https://github.com/apple/swift-numerics
