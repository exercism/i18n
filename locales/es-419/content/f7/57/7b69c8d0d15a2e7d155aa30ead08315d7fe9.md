# Instrucciones

Tienes una boutique de moda en línea. Cada artículo de tu inventario es un array de 2 elementos `{ name price }`, y todo el inventario es un array de artículos.

Un precio faltante se registra como `f`.

## 1. Ordena el inventario por precio

Define `sort-by-price` para que devuelva un array nuevo con los artículos ordenados por precio, de forma ascendente.

```factor
{ { "Maxi Brown Dress" 65 } { "Red Skirt" 50 } { "Bamboo Socks Cats" 20 } }
sort-by-price .
! => { { "Bamboo Socks Cats" 20 } { "Red Skirt" 50 } { "Maxi Brown Dress" 65 } }
```

## 2. Encuentra los artículos sin precio

Define `with-missing-price` para que devuelva un array solo con los artículos cuyo precio es `f`.

```factor
{ { "Black T-shirt" 40 } { "Denim Pants" f } { "Orange T-shirt" 40 } }
with-missing-price .
! => { { "Denim Pants" f } }
```

## 3. Cuenta los artículos caros

Define `expensive-items` para que reciba un inventario y un umbral de precio, y devuelva cuántos artículos cuestan estrictamente más que el umbral.

```factor
{ { "Skirt" 50 } { "Coat" 120 } { "Hat" 25 } { "Dress" 80 } }
50 expensive-items .
! => 2

{ { "Skirt" 50 } { "Coat" 120 } { "Hat" 25 } { "Dress" 80 } }
0 expensive-items .
! => 4
```

## 4. Encuentra el artículo más barato

Define `cheapest-item` para que devuelva el artículo con el precio más bajo. Los artículos sin precio (`f`) no aparecerán en el argumento.

```factor
{ { "Skirt" 50 } { "Coat" 120 } { "Hat" 25 } } cheapest-item .
! => { "Hat" 25 }
```

## 5. Suma todos los precios

Define `total-price` para que devuelva la suma de todos los precios. Los artículos sin precio (`f`) no aparecerán en el argumento.

```factor
{ { "Skirt" 50 } { "Coat" 120 } { "Hat" 25 } } total-price .
! => 195
```

## 6. Formatea un artículo como etiqueta de precio

Define `format-price-tag` para que devuelva un string de la forma `"name: $price"` para un artículo. Los artículos sin precio (`f`) no aparecerán aquí.

```factor
{ "Skirt" 50 } format-price-tag .
! => "Skirt: $50"
```
