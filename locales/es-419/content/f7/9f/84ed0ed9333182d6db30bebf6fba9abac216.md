# Introducción

A veces, una parte del estado necesita compartirse entre varias palabras sin tener que pasarla por sus efectos de pila cada vez. Las *variables dinámicas* de Factor, declaradas con `SYMBOL:`, le dan a cada palabra acceso a un valor almacenado en un espacio de nombres.

```factor
USING: namespaces ;

SYMBOL: counter

0 counter set-global
counter [ 1 + ] change-global
counter get-global .       ! => 1
```

`set-global` y `get-global` operan sobre el espacio de nombres global. `set` y `get` operan sobre el ámbito dinámico *actual* y normalmente se usan dentro de un bloque `with-variable` cuando quieres un enlace con un ámbito definido en lugar de uno que abarque todo el proceso.

`SYMBOLS: a b c ;` declara varios símbolos a la vez.
