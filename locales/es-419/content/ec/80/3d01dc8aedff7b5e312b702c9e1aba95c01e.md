# Representaciones

El [representer de Python][representer] procesa y normaliza las soluciones de los estudiantes a una forma más «genérica»:

- El código se convierte a un AST usando el [módulo AST de Python][python-ast].
- El árbol AST final se convierte en un string sin espacios en blanco ni sangría, y se emite como `representation.txt`.
- Para facilitar la solución de problemas, `representation.out` incluye el AST inicial, el AST editado y una representación del código con las normalizaciones aplicadas.

- Eliminaciones:
    - las anotaciones de tipo (_incluidas las anotaciones de tipo en las dataclasses, consulta Normalizaciones más abajo_)
    - las sentencias `print()`
    - los bloques `if __name__ == __main__`
    -  los comentarios
    -  los docstrings

-  Reemplazos:
    - los nombres definidos por el usuario se reemplazan con marcadores de posición (_incluidos los nombres de funciones, los parámetros y las variables en las lambdas_)

- Normalizaciones:
  - las comillas simples `'` se cambian por comillas dobles `"` (_comillas dobles_), a menos que se necesiten escapes, en cuyo caso se dejan sin cambios.
  - a los literales numéricos se les quitan los guiones bajos y la notación científica se calcula según el valor posicional:
    - **66_777_888_433** --> 66777888433
    - **1_999_878_473.66** --> 1999878473.66
    - **77_555_998_125.445_779** --> 77555998125.44579
    - **44_573_123.445_312+123_674.889_12j** --> 44573123.445312 + 123674.88912j
    - **1e6** --> 1000000.0 #1000000
    -  **1e2+.23** --> 100.0 + 0.23 #100.23
    - **1e2+1_23e0+4.4e-1** --> 100.0 + 123.0 + 0.44 #223.44
    - **7e6+7e5+5e4+9.98e2+4.45_779e-1** -->7000000.0 + 700000.0 + 50000.0 + 998.0 + 0.445779 #7750998.445779
    - **(7e6+7e5+5e4+9.98e1+4.457_79e-1)+(1e2+1.23e1+4.444_23e-1)*1*j** --> (7000000.0 + 700000.0 + 50000.0 + 99.8 + 0.445779 + (100.0 + 12.3 + 0.444423) * 1j)  #7750100.245779+112.744423j
  - las funciones y clases que quedan con el cuerpo vacío después de quitar los docstrings reciben `pass` en el cuerpo.
  - las dataclasses que tienen miembros de datos con anotación de tipo pero sin asignar reciben `None` como valor en esos miembros de datos. Consulta el docstring que comienza en la línea 153 de normalizer.py para más detalles.
