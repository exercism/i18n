# Introducción

## Mapas

Los mapas en Elixir son la estructura de datos que sirve para almacenar información en pares clave-valor. En otros lenguajes también se los conoce como arrays asociativos (PHP), hashes (Perl 5, Raku) o diccionarios (Python).

Las claves y los valores pueden ser de cualquier tipo de dato, pero si la clave es un átomo podemos usar una sintaxis abreviada. Los mapas no garantizan el orden de sus entradas al acceder a ellas o al devolverlas.

### Formas literales

Un mapa vacío simplemente se declara con `%{}`. Si queremos agregar elementos a un mapa literal, podemos usar dos formas:

```elixir
# If the key is an atom:
%{atom_key: 1}

# If the key is a different type:
%{1 => :atom_value}

# You can even mix these if the atom form comes second:
%{"first_form" => :a, atom_form: :b}
```

Aunque no existe un formato canónico, elige una forma consistente de representar los pares clave-valor literales.

### Funciones del módulo Map

Elixir ofrece muchas funciones para trabajar con mapas en el _módulo Map_. Algunas funciones del _módulo Map_ requieren que se pase una función _anónima_ para ayudar con la transformación del mapa.

## Atributos de módulo como constantes

En Elixir podemos definir atributos de módulo que se pueden usar como constantes en nuestras funciones.

```elixir
defmodule Example do
  # Defines the attribute as the value 1
  @constant_number 1

  def example_value() do
    # Returns the value 1
    @constant_number
  end
end
```

Cuando se usan para definir constantes de módulo, los atributos pueden ser cualquier expresión que se pueda evaluar en tiempo de compilación. Después de la compilación, los atributos de módulo ya no son accesibles, ya que se expanden durante la compilación, de forma similar a las macros definidas en lenguajes como C.
