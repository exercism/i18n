# Números de punto flotante

`INT` solo almacena números enteros, y dividir dos de ellos descarta el residuo:

```sather
7 / 2        -- 3, not 3.5
```

Cuando la fracción importa, el tipo es `FLTD`, un número **de punto flotante**, que puede almacenar valores entre los enteros.

## Cómo escribir uno

Un literal de punto flotante tiene un punto decimal y una `d` al final.

```sather
   concert_a : FLTD is
      return 440.0d;
   end;
```

La `d` no es opcional. `440.0` por sí solo es un tipo diferente, de menor precisión; la `d` pide el tipo que este track usa en todas partes.

Escribe `2.0d`, no `2d`: también tiene que haber un punto decimal.

## Aritmética

`+`, `-`, `*` y `/` funcionan todos, y `/` ahora conserva la fracción:

```sather
7.0d / 2.0d      -- 3.5
```

Ambos lados tienen que ser `FLTD`. Sather no mezclará los dos tipos sin avisar, así que `7 / 2.0d` es un error en lugar de una sorpresa.

## A partir de un número entero

`.fltd` convierte un `INT` en un `FLTD`:

```sather
   halve(n : INT) : FLTD is
      return n.fltd / 2.0d;
   end;
```

`halve(7)` es `3.5`. Fíjate dónde va la conversión: `(7 / 2).fltd` sería `3.0`, porque la división ya habría descartado la mitad. Convierte **antes** de dividir, no después.

## ¿Qué tan separados están?

`.abs` descarta el signo de menos, y así puedes preguntar qué tan separados están dos valores sin importar cuál es más grande:

```sather
(440.0d - 442.0d).abs      -- 2.0
```
