## Tipos struct

Ya vimos los tipos struct; para recapitular, un `struct` es una secuencia de elementos con nombre llamados _campos_, y cada campo tiene un nombre y un tipo.
El nombre de un campo debe ser único dentro del struct.
Los `Structs` se pueden comparar con la _clase_ del paradigma de programación orientada a objetos.

Creas un nuevo struct usando las palabras clave `type` y `struct`, y luego defines explícitamente el nombre y el tipo de los campos como se muestra en el ejemplo de abajo.

```go
type StructName struct{
    field1 fieldType1
    field2 fieldType2
}
```

## Tipos que no son struct

También es posible definir tipos que no son struct, que puedes usar como alias para declaraciones de tipos integrados.

```go
type Name string
func SayHello(n Name) {
  fmt.Printf("Hello %s\n", n)
}
n := Name("Fred")
SayHello(n)
// Output: Hello Fred
```

También puedes definir tipos que no son struct compuestos de arrays y mapas.

```go
type Names []string
func SayHello(n Names) {
  for _, name := range n {
    fmt.Printf("Hello %s\n", name)
  }
}
n := Names([]string{"Fred", "Bill"})
SayHello(n)
// Output:
// Hello Fred
// Hello Bill
```
