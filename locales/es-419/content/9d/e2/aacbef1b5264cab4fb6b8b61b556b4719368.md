# Pruebas

Un REPL de Clojurescript te permite ejecutar código fácilmente y obtener retroalimentación inmediata; también lo puedes usar para ejecutar pruebas.

## Leiningen
Para abrir un REPL con la CLI de Clojure, cambia al directorio que contiene el ejercicio y ejecuta:
``` bash
$ clojure -m cljs.main -re node
```

Ten en cuenta que Node debe estar instalado en tu sistema.

Cuando estés listo para trabajar en un ejercicio y hayas creado un archivo donde guardar tu solución (como `bob.cljs`), puedes ejecutar las pruebas desde tu terminal con `$ clojure -A:test`.

Primero, haz `require` del espacio de nombres de las pruebas:
``` clojure
=> (require 'bob-test)
nil
;; and the test namespace
=> (require 'cljs.test)
```

Cambia el ns al espacio de nombres de las pruebas:
```clojure
=> (ns bob-test)
nil
```

Luego llama a `run-tests` con `bob-test`:
``` clojure
=> (cljs.test/run-tests)

Testing bob-test

Ran 14 tests containing 14 assertions.
0 failures, 0 errors.
{:test 14, :pass 14, :fail 0, :error 0, :type :summary}
```

Para ejecutar las pruebas de un ejercicio con la CLI de Clojure, simplemente llama a:
``` bash
$ clojure -M:test

Testing bob-tests

Ran 14 tests containing 14 assertions.
0 failures, 0 errors.
```
