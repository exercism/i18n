# Anexo de instrucciones

## Definir un tipo inductivo

Este ejercicio espera que el valor de retorno sea un [tipo inductivo][inductive] `Classification` que debes definir.

Este tipo debe tener una instancia de [BEq][beq], es decir, admite una prueba de igualdad Boolean, y una instancia de [Repr][repr], es decir, los valores del tipo se pueden formatear para mostrarlos.

Puedes consultar [esta página][instance] sobre declaraciones de instancias.
Lean puede [generar instancias][deriving] automáticamente para muchas clases.

## Subtipos

El argumento de la función `classify` es un [subtipo][subtype] llamado `Positive`:

```
def Positive := { x : Nat // x > 0 }
```

Los subtipos representan elementos de un tipo determinado que satisfacen un predicado.
`Positive` representa elementos de `Nat` que son mayores que `0`.

Cualquier elemento de un subtipo se puede pensar como un par formado por un valor del tipo subyacente y una prueba, en el sentido matemático, de que ese valor satisface el predicado correspondiente.

Los subtipos imponen invariantes a nivel del tipo, lo que garantiza que no se puedan construir valores mal formados.
