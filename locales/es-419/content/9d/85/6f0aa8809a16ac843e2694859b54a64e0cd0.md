# Instrucciones

En este ejercicio vas a escribir código para ayudar a una empresa de letreros a crear mensajes personalizados para sus letreros.

## 1. Crea un conjunto de strings útiles

Define los siguientes strings constantes que se usarán para crear letreros:

- `birthday`: contiene el valor "Birthday"
- `valentine`: contiene el valor "Valentine's Day"
- `anniversary`: contiene el string "Anniversary"

## 2. Crea un conjunto de caracteres útiles

Define los siguientes caracteres constantes que se usarán para crear letreros:

- `space`: contiene el valor " " (un solo espacio)
- `exclamation`: contiene el valor "!"

## 3. Combina frases para construir mensajes

Implementa la función `buildSign(for:name:)`, que recibe el argumento `for`, que contiene uno de los tres strings que definiste en la primera tarea, y el argumento `name`, que es un string que contiene el nombre de la persona para quien es el letrero.
Usa concatenación para construir el mensaje del letrero y recuerda reutilizar las constantes ya definidas.
La función debe devolver el mensaje del letrero como un string.

```swift
buildSign(for: birthday, name: "Otto")
// returns "Happy Birthday Otto!"

buildSign(for: anniversary, name: "Valentina")
// returns "Happy Anniversary Valentina!"
```

## 4. Construye un letrero de graduación

Implementa la función `graduationFor(name:year:)`, que recibe el argumento `name`, que es un string que contiene el nombre de la persona para quien es el letrero, y el argumento `year`, que es un entero que contiene el año en que se gradúa la persona.
Usa strings de plantilla para construir el mensaje del letrero.
La función debe devolver el mensaje del letrero como un string.

```swift
graduationFor(name: "Padma", year: 2023)
// returns "Congratulations Padma!\nClass of 2023"
```

## 5. Calcula el costo de un letrero

Implementa la función `costOf(sign:)`, que recibe el argumento `sign`, que es un string que contiene el mensaje del letrero.
El letrero tiene un precio base de 20 en la moneda dada. Además, cada letra cuesta 2 (los espacios en blanco se incluyen en el cálculo).
La función debe devolver el costo del letrero como un entero.

```swift
costOf(sign: "Happy Birthday Grandma!")
// returns 66
```
