# Instalación

Para estos ejercicios usamos el popular simulador de MIPS [MARS](https://dpetersanderson.github.io/Help/MarsHelpIntro.html). Descarga el archivo jar de MARS desde [GitHub](https://github.com/dpetersanderson/MARS/releases) y colócalo en algún lugar de fácil acceso. Además, instala el Java SDK si aún no lo tienes.
