# Instrucciones

En este ejercicio, vas a implementar una forma de llevar un registro de los puntajes más altos del juego más popular de tu salón de arcade local.

## 1. Agrega jugadores a la tabla de puntajes altos

Para agregar un jugador a la tabla de puntajes altos, define dos métodos `add_player!` que reciben los siguientes argumentos:

- El primer argumento es el diccionario de puntajes.
- El segundo argumento es el nombre de un jugador como string.
- El tercer argumento es el puntaje como entero.
  Este argumento es opcional; cuando no se da un valor, el puntaje debe establecerse en 0.

```julia-repl
julia> scores = Dict{String, Int}()
Dict{String, Int64}()

julia> add_player!(scores, "Liselot", 486373)
Dict{String, Int64} with 1 entry:
  "Liselot" => 486373

julia> add_player!(scores, "Éimhín")
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0
```

## 2. Elimina jugadores de la tabla de puntajes

Para eliminar a un jugador de la tabla de puntajes altos, define `remove_player!`, que recibe 2 argumentos:

- El primer argumento es el diccionario de puntajes.
- El segundo argumento es el nombre del jugador como string.

```julia-repl
julia> scores = Dict(
           "Liselot" => 486373,
           "Éimhín"  => 0,
       )
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0

julia> remove_player!(scores, "Liselot")
Dict{String, Int64} with 1 entry:
  "Éimhín" => 0
```

## 3. Actualiza el puntaje de un jugador

Para actualizar el puntaje de un jugador reemplazando el puntaje anterior, define `update_score!`, que recibe 3 argumentos:

- El primer argumento es el diccionario de puntajes.
- El segundo argumento es el nombre del jugador como string, cuyo puntaje deseas actualizar.
- El tercer argumento es el puntaje que deseas establecer como el puntaje alto almacenado.

```julia-repl
julia> scores = Dict(
           "Liselot" => 486373,
           "Éimhín"  => 0,
       )
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0

julia> scores

  "Liselot" => 486373
  "Éimhín"  => 89479
```

## 4. Restablece el puntaje de un jugador

Para restablecer el puntaje de un jugador, define `reset_score!`, que recibe 2 argumentos:

- El primer argumento es el diccionario de puntajes.
- El segundo argumento es el nombre del jugador como string, cuyo puntaje deseas restablecer.

```julia-repl
julia> scores = Dict(
           "Liselot" => 486373,
           "Éimhín"  => 0,
       )
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0

julia> reset_score!(scores, "Liselot") # TODO: Should this return the dict?
0

julia> scores
Dict{String, Int64} with 2 entries:
  "Liselot" => 0
  "Éimhín"  => 0
```

## 5. Obtén una lista de jugadores

Para obtener una lista de jugadores, define `players`, que recibe 1 argumento:

- El primer argumento es el diccionario de puntajes.

```julia-repl
julia> scores = Dict(
           "Liselot" => 486373,
           "Éimhín"  => 0,
       )
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0

julia> players(scores)
2-element Vector{String}:
 "Liselot"
 "Éimhín"
```
