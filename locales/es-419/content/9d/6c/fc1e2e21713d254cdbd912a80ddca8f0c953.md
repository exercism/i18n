# Acerca de

Los [strings textuales][verbatim-strings] permiten strings de varias líneas. Se introducen con una @. Se pueden usar con interpolación de strings. Solo agrega un "\$" antes de la comilla de apertura.

```csharp
string str = @"
See no wretched
quotes everywhere
";
```

[verbatim-strings]: https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/strings/#regular-and-verbatim-string-literals
