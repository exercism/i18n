# Introducción

## Conversión explícita

La conversión explícita y la conversión de tipos son dos formas distintas de cambiar una expresión de un tipo de datos a otro.

Una expresión se puede convertir a otro tipo con el operador de conversión `(<type>)`.

```csharp
long l = 1000L;
int i = (int)l;

object o = new Random();
Random r = (Random)o;
```

Si los tipos no son compatibles, se lanza una instancia de `InvalidCastException`. En el caso de los números, esto indica que el tipo de destino no puede representar el valor convertido. En el caso de las clases, uno de los tipos debe derivar del otro (esto también se aplica, de forma trivial, a las estructuras).

Una alternativa a la _conversión explícita_ es la _conversión de tipos_ con el operador `is`. Por lo general, esta se aplica a los tipos de referencia y a los tipos anulables.

```csharp
object o = new Random();
if (o is Random rand)
{
    int ii = rand.Next();
    // now, do something random
}
```

Si necesitas detectar el tipo exacto de un objeto, `is` puede resultar un poco permisivo, ya que devolverá true para una clase y para cualquiera de las clases e interfaces de las que esta derive, directa o indirectamente. `typeof` y `Object.GetType()` son la solución en este caso.

```csharp
object o = new List<int>();

o is ICollection<int> // true
o.GetType() == typeof(ICollection<int>) // false
o is List<int> // true
o.GetType() == typeof(List<int>) // true
```
