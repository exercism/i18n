# Introducción

Las funciones y los métodos de Go pueden devolver varios valores:

```go
func GetCard() (Card, error) { ... }
```

Cada valor de retorno debe asignarse en orden y separarse con comas:

```go
card, err := GetCard()
```

Cada posición en la asignación declara una variable.
Go no compila si alguna variable declarada nunca se usa.
El identificador en blanco `_` ocupa el lugar del nombre de una variable para omitir ese valor de retorno:

```go
card, _ := GetCard()
```

`error` es una interfaz integrada.
Un `error` con valor `nil` significa que no ocurrió ningún error; cualquier valor distinto de `nil` significa que algo salió mal.
Por convención, las funciones que pueden fallar deben devolver un `error` como su último valor.
Quien llama a la función debe verificarlo antes de usar cualquier otro valor de retorno:

```go
card, err := GetCard()
if err != nil {
    return err // do not use card here
}
// safe to use card here
```
