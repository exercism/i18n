# Introducción

## Boolean

Elixir representa los valores verdadero y falso con el tipo booleano. Solo hay dos valores: `true` y `false`. Estos valores se pueden vincular a una variable:

```elixir
true_variable = true
false_variable = false
```

Podemos evaluar expresiones Boolean estrictas usando los operadores `and/2`, `or/2` y `not/1`.

```elixir
true_variable = true and true
false_variable = true and false

true_variable = false or true
false_variable = false or false

true_variable = not false
false_variable = not true
```

Cuando escribes una función que devuelve un valor Boolean, lo idiomático es terminar el nombre de la función con un `?`. La misma convención se puede usar para variables que almacenan valores Boolean.

```elixir
def either_true?(a?, b?) do
  a? or b?
end
```
