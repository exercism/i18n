# Apéndice de instrucciones

## Cómo trabajar con fechas en Prolog

El soporte de fechas que Prolog trae integrado es [bastante rudimentario][built-in-dates-support]. Aunque puedes resolver este ejercicio solo con lo que Prolog trae de fábrica, una forma mucho más cómoda de trabajar con fechas es el [paquete date_time][date-time-package].

### Cómo instalar el paquete date_time

Si tu versión instalada de Swipl es bastante reciente, puedes instalar el paquete ejecutando:

```bash
swipl pack install date_time
```

Si eso no funciona, puedes ejecutar:

```shell
swipl -g 'pack_install(date_time)'
```

~~~~exercism/note
Si usas el editor en línea, no necesitas instalar nada de forma manual.
~~~~

### Cómo usar el paquete date_time

Agrega el siguiente código al inicio de tu archivo de solución para usar el paquete `date_time`:

```prolog
:- use_module(library(date_time)).
```
