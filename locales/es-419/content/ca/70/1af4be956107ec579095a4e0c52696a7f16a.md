# Instrucciones

Trabajas en un parque de diversiones y te entregaron una especificación para diseñar un sistema que administre la asistencia y las atracciones. Tu tarea es modelar al visitante (la persona que visita el parque).

## 1. Crea nuevos visitantes

Implementa el método `Attendee#initialize` de la clase `Attendee`. Debe recibir una altura (en centímetros) y guardarla en una variable de instancia.

```ruby
Attendee.new(106)
# => #<Attendee:0x000055c33e6c7e18 @height=106>
```

## 2. ¿Qué altura tiene el visitante?

Implementa el getter `Attendee#height` de la clase `Attendee`. Debe devolver la altura de la instancia.

```ruby
Attendee.new(106).height
# => 106
```

## 3. ¿Cuál es el id del pase de atracciones?

No todos los visitantes han comprado un pase de atracciones, pero necesitamos saber si tienen uno o no. Implementa el getter `Attendee#pass_id` de la clase `Attendee`. Debe devolver el pass_id de la instancia o `nil` si el visitante no tiene uno.

```ruby
Attendee.new(106).pass_id
# => nil
```

## 4. Permite que las personas compren un pase

Implementa `Attendee#issue_pass!` para modificar el estado de la instancia y asignar el argumento a la variable de instancia del pass id. Debe devolver el pass id.

```ruby
attendee = Attendee.new(106)
attendee.issue_pass!(42)
attendee.pass_id
# => 42
```

## 5. Revoca el pase

Algunos visitantes rompen las reglas con conductas peligrosas, así que el parque quiere poder revocar los pases. Implementa `Attendee#revoke_pass!` para modificar el estado de la instancia y asignar `nil` al pass id.

```ruby
attendee = Attendee.new(106)
attendee.issue_pass!(42)
attendee.revoke_pass!
attendee.pass_id
# => nil
```
