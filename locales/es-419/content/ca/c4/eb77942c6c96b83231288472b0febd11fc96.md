# Recursos

- El recurso más importante es la [documentación oficial][docs]
- Para editar en línea, usa el [Uiua Pad][pad]
- Explora el código fuente en el [repositorio de GitHub][github] de Uiua
- Mantente al día con el [blog oficial de Uiua][blog]

El [sitio web principal][main] también incluye un enlace al servidor de Discord, donde puedes conversar sobre Uiua con otros entusiastas.

[github]: https://github.com/uiua-lang/uiua
[pad]: https://www.uiua.org/pad
[blog]: https://www.uiua.org/blog
[main]: https://www.uiua.org
