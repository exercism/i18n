# Ejecutar los tests

SWI Prolog se puede ejecutar de forma interactiva o directamente desde la línea de comandos.

## Línea de comandos

Puedes usar el siguiente comando para ejecutar los tests desde la línea de comandos:

```bash
swipl -f <exercise>.pl -s <exercise>_tests.plt -g run_tests,halt -t 'halt(1)'
```

Reemplaza `<exercise>` con el nombre del ejercicio que estás implementando.

## Modo interactivo

Para ejecutar Prolog de forma interactiva, primero ejecuta:

```bash
swipl
```

Cuando se inicie la consola de Prolog, carga tu implementación y ejecuta los tests con:

```
?- ["<exercise>.pl"].
?- ["<exercise>_tests.plt"].
?- run_tests.
```

Reemplaza `<exercise>` con el nombre del ejercicio que estás implementando.

### Recargar los cambios

Una vez que los archivos anteriores estén cargados, puedes aplicar los cambios que hayas hecho ejecutando:

```
?- make.
```

## Tests omitidos

Cuando empiezas un ejercicio, solo se ejecuta el primer test. El resto se ha omitido al agregar `condition(pending)` al objetivo `test`.
Cuando el primer test pase, deja de omitir el siguiente test cambiando `pending` por `true` en `condition(pending)`.
Repite esto con cada test hasta que todos se ejecuten y pasen.

### Línea de comandos

Agrega el argumento `-- --all` al final del comando para ejecutar también los tests pendientes:

```bash
swipl -f <exercise>.pl -s <exercise>_tests.plt -g run_tests,halt -t 'halt(1)' -- --all
```
