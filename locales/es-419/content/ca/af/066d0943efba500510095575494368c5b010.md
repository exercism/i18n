# Acerca de

Las expresiones condicionales se usan para ejecutar código en función de **si** una condición es **true** o **false**. Estas expresiones se escriben así:

```haxe
if (condition) {
  expressions
};
```

El resultado de la condición es de tipo `Bool`, así que cuando el resultado es `true` se ejecutan las expresiones.

A veces, cuando la condición en realidad es `false`, queremos que se ejecute otro fragmento de código. Ahí es donde entra la expresión `else`. `else` ejecuta las expresiones cuando la condición inicial es `false`. Pero, ¿y si queremos comprobar la condición para varias posibilidades? Entonces usamos `else if (condition)`. Aquí tienes un ejemplo completo:

```haxe
var a = 10;

if (a == 2) {
  trace("a is 2");
} else if (a == 5) {
  trace("a is 5");
} else {
  trace("a is 10");
}

// a is 10
```
