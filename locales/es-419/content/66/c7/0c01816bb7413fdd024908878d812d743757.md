# Pruebas

Ejecuta las pruebas con:

```bash
$ gradlew test
```

> Usa `gradlew.bat` si estás en Windows

## Pruebas omitidas

En las suites de pruebas, se omiten todas las pruebas excepto la primera.

Cuando logres que una prueba pase, puedes habilitar la siguiente si eliminas la anotación `@Ignore`.
