# Instrucciones

Estás a cargo del marcador en un partido de netball. A diferencia de todo lo anterior, un marcador tiene que recordar lo que ha pasado.

La clase `SCOREBOARD` necesita lo siguiente. El esqueleto te da la clase y sus dos declaraciones de atributos; agrega el resto.

## 1. Prepara el marcador

`create` recibe el nombre del equipo local y el nombre del equipo visitante, y devuelve un marcador con ambos puntajes en cero.

```sather
board ::= #SCOREBOARD("Vixens", "Magpies");
board.home_score
-- => 0
```

## 2. Anota un gol

`home_goal` suma uno al puntaje local, y `away_goal` suma uno al puntaje visitante. Ninguno de los dos devuelve nada.

```sather
board.home_goal;
board.home_score
-- => 1
```

## 3. Lee el marcador

`summary` devuelve el marcador tal como se escribiría: el equipo local, su puntaje, un guion, el puntaje visitante y, por último, el equipo visitante.

```sather
board.summary
-- => "Vixens 1 - 0 Magpies"
```

Los espacios son exactamente como se muestran, y el guion es un solo `-`.

## 4. ¿Quién va ganando?

`leader` devuelve el nombre del equipo que va adelante, o `"Draw"` cuando los puntajes están empatados.

```sather
board.leader
-- => "Vixens"
```

## 5. ¿Por cuánto van ganando?

`margin` devuelve cuántos goles separan a los equipos. Nunca es negativo, sin importar quién vaya adelante.

```sather
board.margin
-- => 1
```
