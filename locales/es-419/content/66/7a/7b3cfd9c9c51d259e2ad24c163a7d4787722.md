# Instrucciones

Como aprendiz de magia, Elyse necesita practicar algunos conceptos básicos. Tiene una pila de cartas que quiere manipular.

Para que las cosas sean un poco más fáciles, solo usa las cartas del 1 al 10, así que su pila de cartas se puede representar con un vector de números.
La posición de una carta determinada corresponde al índice en el vector.

## 1. Recupera una carta de una pila

Para elegir una carta, devuelve la carta en el índice `position` de la pila dada.

```R
stack <- c(1, 2, 4, 1)
position <- 3
get_item(stack, position)
# => 4
```

## 2. Intercambia una carta en la pila

Haz un poco de prestidigitación e intercambia la carta en el índice `position` por la carta de reemplazo que se te proporciona.
Devuelve la pila ajustada.

```R
stack <- c(1, 2, 4, 1)
position <- 3
replacement_card <- 6
set_item(stack, position, replacement_card)
# => c(1, 2, 6, 1)
```

## 3. Inserta una carta en la parte superior de la pila

Haz que aparezca una carta insertando una carta nueva en la parte superior de la pila.
Devuelve la pila ajustada.

```R
stack <- c(5, 9, 7, 1)
new_card <- 8
insert_item_at_top(stack, new_card)
# => c(5, 9, 7, 1, 8)
```

## 4. Quita una carta de la pila

Haz que desaparezca una carta quitando la carta en la `position` dada de la pila.
Devuelve la pila ajustada.

```R
stack <- c(3, 2, 6, 4, 8)
position <- 3
remove_item(stack, position)
# => c(3, 2, 4, 8)
```

## 5. Verifica el tamaño de la pila

Verifica si el tamaño de la pila es igual a `stack_size` o no.

```R
stack <- c(3, 2, 6, 4, 8)
stack_size <- 4
check_size_of_stack(stack, stack_size)
# => FALSE
```

## 6. Quita la carta superior de la pila

Haz que desaparezca una carta quitando la carta de la parte superior de la pila.
Devuelve la pila ajustada.

```R
stack <- c(3, 2, 6, 4, 8)
remove_item_from_top(stack)
# => c(3, 2, 6, 4)
```

## 7. Inserta una carta en la parte inferior de la pila

Haz que aparezca una carta insertando una carta nueva en la parte inferior de la pila.
Devuelve la pila ajustada.

```R
stack <- c(5, 9, 7, 1)
new_card <- 8
insert_item_at_bottom(stack, new_card)
# => c(8, 5, 9, 7, 1)
```

## 8. Quita una carta de la parte inferior de la pila

Haz que desaparezca una carta quitando la carta de la parte inferior de la pila.
Devuelve la pila ajustada.

```R
stack <- c(8, 5, 9, 7, 1)
remove_item_at_bottom(stack)
# => c(5, 9, 7, 1)
```
