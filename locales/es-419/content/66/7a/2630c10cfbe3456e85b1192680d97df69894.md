# Introducción

## Conceptos básicos

Para obtener información más detallada sobre estos temas, visita la [página del concepto][exercism-concept].

### Sintaxis general

La etiqueta de apertura de PHP `<?php` marca el inicio del código PHP.
Todas las sentencias deben terminar con un `;` para separar las instrucciones.

```php
<?php

$message = "Success!"; // Statement correctly ends with `;`
$message = "I fail." // PHP Parse error: syntax error, [...]
```

Para facilitar la lectura, todos los ejemplos de código omiten la etiqueta de apertura de PHP `<?php`.

### Comentarios

Los comentarios de una línea empiezan con `//`.

```php
// Single line comment
```

### Valores y variables

Con el operador de asignación `=`, puedes asignar un valor a una variable.
Los nombres de las variables deben empezar con el signo de dólar `$` y seguir las [convenciones de nomenclatura][exercism-concept-naming-conventions].

```php
$count = 1; // Assign value of 1

// Strings can be created by enclosing the characters
// within single `'` quotes or double `"` quotes.
$message = "Success!";
```

### Funciones y métodos

Puedes pasar valores y variables a las funciones.
Los argumentos de la función se convierten en nuevas variables que contienen los valores que se pasan.
Las funciones pueden devolver cualquier valor usando la palabra clave `return`.

```php
function window_height($height)
{
    return $height + 10;
}

window_height(100);
// => 110
```

Las funciones que están dentro de las clases y sus instancias se llaman métodos.
Para llamar a un método, el nombre va precedido por la instancia y `->`.
Los métodos tienen acceso a la variable especial `$this`, que hace referencia a la instancia actual.

```php
<?php

class Calculator {
    public function sub($x, $y)
    {
        return $this->add($x, -$y); // Calls the method add() of the current instance
    }

    public function add($x, $y)
    {
        return $x + $y;
    }
}

$calculator = new Calculator(); // Creates a new instance of Calculator class
$calculator->sub(3, 1); // Calls the method sub() of the instance stored in $calculator
// => 2
```
