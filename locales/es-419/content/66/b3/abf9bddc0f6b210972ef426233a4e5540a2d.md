# Instrucciones

Como futura maga, Elyse necesita practicar algunos fundamentos. Tiene una baraja de cartas que quiere manipular.

Para que sea un poco más fácil, solo usa las cartas del 1 al 10.

## 1. Recuperar una carta de una baraja

Implementa la función `getCard` que devuelve la carta en la posición `index` de la baraja dada. Si el índice no está en la baraja, devuelve Nothing.

```elm
getCard 2 ( Array.fromList [ 1, 2, 4, 1 ] )
    --> Just 4
getCard 6 ( Array.fromList [ 1, 2, 4, 1 ] )
    --> Nothing
```

## 2. Cambiar una carta en la baraja

Implementa la función `setCard` que devuelve una baraja con la carta en la posición `index` cambiada por la nueva carta proporcionada.
Si el `index` no está en la baraja, devuelve la baraja original.

```elm
setCard 2 6 ( Array.fromList [ 1, 2, 4, 1 ] )
    --> Array.fromList [ 1, 2, 6, 1 ]
setCard 6 6 ( Array.fromList [ 1, 2, 4, 1 ] )
    --> Array.fromList [ 1, 2, 4, 1 ]
```

## 3. Agregar una carta a la baraja

Implementa la función `addCard` que devuelve una baraja con la nueva carta agregada.

```elm
addCard 8 ( Array.fromList [ 5, 9, 7, 1 ] )
    --> Array.fromList [ 5, 9, 7, 1, 8 ]
```

## 4. Eliminar una carta de la baraja

Implementa la función `removeCard` que devuelve una baraja con la carta en la posición `index` eliminada.
Si el `index` proporcionado no es un índice válido en la baraja, devuelve la baraja original.

```elm
removeCard 2 ( Array.fromList [ 3, 2, 6, 4, 8 ] )
    --> Array.fromList [ 3, 2, 4, 8 ]
removeCard 2 ( Array.fromList [ 3, 2 ] )
    --> Array.fromList [ 3, 2 ]
```

## 5. Contar la cantidad de cartas pares en la baraja

Implementa la función `evenCardCount` que cuenta la cantidad de cartas pares en la baraja.

```elm
evenCardCount (Array.fromList [ 3, 8, 4, 5, 1, 6, 10 ] )
    --> 4
```
