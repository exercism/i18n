# Acerca de

Aunque las clases principales de `java.time`, como `LocalDate` y `LocalDateTime`, ofrecen métodos básicos para sumar o restar unidades de tiempo, los ajustes de fecha más complejos a menudo requieren una lógica más elaborada (por ejemplo, encontrar el «segundo martes del mes» o el «último día del año»).

El paquete `java.time.temporal` incluye la interfaz funcional [`TemporalAdjuster`][temporaladjuster-docs] para este propósito.
Representa una estrategia para ajustar un objeto temporal (como un `LocalDate`).
La clase de utilidad [`TemporalAdjusters`][temporaladjusters-docs] (fíjate en la «s» del plural) contiene métodos de fábrica estáticos que ofrecen muchas implementaciones de ajustadores comunes y predefinidas.

## Cómo usar TemporalAdjusters

Los objetos temporales como `LocalDate` y `LocalDateTime` tienen un método `with()` que acepta un `TemporalAdjuster`.
Este método devuelve un objeto temporal *nuevo* con el ajuste aplicado.

```exercism/note
Usar `with(TemporalAdjuster)` devuelve una instancia _nueva_ y no actualiza la instancia existente, ya que todas las clases temporales de `java.time` son inmutables.
```

```java
import java.time.LocalDate;
import java.time.Month;
import java.time.DayOfWeek;
import java.time.temporal.TemporalAdjusters;

LocalDate date = LocalDate.of(2024, Month.AUGUST, 15); // 2024-08-15 (a Thursday)

// Use a predefined adjuster from TemporalAdjusters
LocalDate firstDayOfNextMonth = date.with(TemporalAdjusters.firstDayOfNextMonth());
// => 2024-09-01

LocalDate nextSunday = date.with(TemporalAdjusters.next(DayOfWeek.SUNDAY));
// => 2024-08-18
```

## Ajustadores predefinidos comunes

La clase `TemporalAdjusters` ofrece muchos métodos estáticos útiles.
Aquí tienes algunos ejemplos comunes:

### Cómo encontrar el enésimo día de la semana del mes

El ajustador `dayOfWeekInMonth(int ordinal, DayOfWeek dayOfWeek)` encuentra la enésima aparición de un día de la semana concreto dentro del mes.

```java
LocalDate date = LocalDate.of(2024, Month.AUGUST, 15); // 2024-08-15

// Find the second Tuesday of August 2024
LocalDate secondTuesday = date.with(TemporalAdjusters.dayOfWeekInMonth(2, DayOfWeek.TUESDAY));
// => 2024-08-13

// Find the fourth Friday of August 2024
LocalDate fourthFriday = date.with(TemporalAdjusters.dayOfWeekInMonth(4, DayOfWeek.FRIDAY));
// => 2024-08-23
```

### Cómo encontrar el primer y el último día de la semana en el mes

Los ajustadores `firstInMonth(DayOfWeek dayOfWeek)` y `lastInMonth(DayOfWeek dayOfWeek)` encuentran la primera o la última aparición de un día de la semana dentro del mes.

```java
LocalDate date = LocalDate.of(2024, Month.AUGUST, 15); // 2024-08-15

// Find the first Sunday of August 2024
LocalDate firstSunday = date.with(TemporalAdjusters.firstInMonth(DayOfWeek.SUNDAY));
// => 2024-08-04

// Find the last Monday of August 2024
LocalDate lastMonday = date.with(TemporalAdjusters.lastInMonth(DayOfWeek.MONDAY));
// => 2024-08-26
```

### Cómo encontrar el primer y el último día del mes o del año

Hay ajustadores más simples que encuentran el primer o el último día del mes o del año actuales.

```java
LocalDate date = LocalDate.of(2024, Month.AUGUST, 15); // 2024-08-15

LocalDate firstDay = date.with(TemporalAdjusters.firstDayOfMonth());
// => 2024-08-01

LocalDate lastDay = date.with(TemporalAdjusters.lastDayOfMonth());
// => 2024-08-31

LocalDate lastDayOfYear = date.with(TemporalAdjusters.lastDayOfYear());
// => 2024-12-31
```

### Ajustes relativos (siguiente y anterior)

Ajustadores como `next()`, `previous()`, `nextOrSame()` y `previousOrSame()` encuentran la próxima aparición de un día de la semana dado, o la anterior, en relación con la fecha actual.

- `next()`/`previous()`: excluyen la fecha actual si coincide.
- `nextOrSame()`/`previousOrSame()`: incluyen la fecha actual si coincide.

```java
LocalDate thursday = LocalDate.of(2024, Month.AUGUST, 15); // A Thursday

// Find the next Sunday (exclusive)
LocalDate nextSunday = thursday.with(TemporalAdjusters.next(DayOfWeek.SUNDAY));
// => 2024-08-18

// Find the next Thursday (exclusive)
LocalDate nextThursday = thursday.with(TemporalAdjusters.next(DayOfWeek.THURSDAY));
// => 2024-08-22

// Find the next Thursday (inclusive) - returns the same date
LocalDate nextOrSameThursday = thursday.with(TemporalAdjusters.nextOrSame(DayOfWeek.THURSDAY));
// => 2024-08-15

// Find the previous Monday (exclusive)
LocalDate previousMonday = thursday.with(TemporalAdjusters.previous(DayOfWeek.MONDAY));
// => 2024-08-12
```

## Ajustadores personalizados

Como `TemporalAdjuster` es una [`@FunctionalInterface`][functionalinterface-docs], puedes crear tus propios ajustadores personalizados con expresiones lambda para la lógica que no cubren los métodos predefinidos.
La interfaz requiere implementar un único método: `Temporal adjustInto(Temporal temporal)`.

```java
// Example: An adjuster that finds the next workday (Mon-Fri), skipping weekends.
TemporalAdjuster nextWorkday = temporal -> {
    LocalDate result = (LocalDate) temporal; // Assuming input is LocalDate
    do {
        result = result.plusDays(1);
    } while (result.getDayOfWeek() == DayOfWeek.SATURDAY || result.getDayOfWeek() == DayOfWeek.SUNDAY);
    return result;
};

LocalDate friday = LocalDate.of(2024, Month.AUGUST, 16);
LocalDate nextWorkdayDate = friday.with(nextWorkday);
// => 2024-08-19 (Monday)

LocalDate sunday = LocalDate.of(2024, Month.AUGUST, 18);
LocalDate nextWorkdayFromSunday = sunday.with(nextWorkday);
// => 2024-08-19 (Monday)
```

Los ajustadores personalizados son muy potentes, pero los ajustadores predefinidos de la clase `TemporalAdjusters` cubren una amplia gama de casos de uso comunes.
