# Acerca de

Z3 es un lenguaje de Satisfacibilidad Módulo Teorías (SMT) que se usa para ver si las ecuaciones o fórmulas son satisfacibles, o si tienen una posible solución.

Z3 se encuentra con mayor frecuencia en la verificación de software, la resolución de restricciones, los problemas geométricos, la seguridad y otras aplicaciones que se benefician del cálculo matemático rápido.

Z3 fue creado por el grupo Research in Software Engineering (RiSE) de Microsoft Research y, desde 2015, es un lenguaje de código abierto. El repositorio de GitHub de código abierto de Z3 se puede encontrar en https://github.com/Z3Prover/z3.
