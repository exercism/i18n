## 1. Inicia una verificación de confiabilidad para un solo argumento

- No necesitas una tarea para este paso; un proceso vinculado normal es suficiente.
- Existe una [función integrada][spawn-link] que ejecuta una función anónima dada en un proceso nuevo y la vincula al proceso actual.

## 2. Interpreta los resultados de una verificación de confiabilidad

- Para recibir un solo mensaje, llama a [`receive`][receive] una vez. Leerá el primer mensaje que coincida con cualquiera de los patrones dados y dejará los demás mensajes en la bandeja de entrada del proceso.
- Puedes usar un guard o [el operador pin][pin-operator] para asegurarte de que solo se reciban mensajes de un proceso cuyo PID coincida con el PID que se le pasa a `await_reliability_check_result/2` como argumento.
- [`receive`][receive] acepta una cláusula `after` para manejar los tiempos de espera.

## 3. Ejecuta una verificación de confiabilidad concurrente para muchos argumentos

- El proceso actual debe empezar a capturar salidas antes de que se cree cualquier proceso vinculado nuevo.
- Capturar salidas en un proceso se logra estableciendo una bandera en ese proceso.
- Existe una [función integrada][process-flag] que establece una bandera en un proceso y devuelve el valor anterior de esa bandera.
- La bandera para capturar salidas se llama `:trap_exit` y acepta un valor Boolean.
- Usa las funciones de `Enum` para primero iniciar un proceso para cada argumento y luego esperar los mensajes de cada proceso. Usa las funciones que implementaste en los dos pasos anteriores. Ten en cuenta que el mapa que devuelve `start_reliability_check/2` coincide con el mapa que `await_reliability_check_result/2` espera como primer argumento.

## 4. Ejecuta una verificación de correctitud concurrente para muchos argumentos

- Usa una tarea asíncrona para este paso.
- Existe una [función integrada][task-async] que inicia una tarea asíncrona.
- Existe una [función integrada][task-await] que espera a que una tarea asíncrona termine de ejecutarse y devuelve su resultado. Acepta un tiempo de espera como segundo argumento.
- Usa las funciones de `Enum` para primero iniciar una tarea para cada argumento y luego esperar cada tarea.
