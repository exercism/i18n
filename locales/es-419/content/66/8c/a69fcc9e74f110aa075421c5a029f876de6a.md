# Introducción

## Rangos

Los rangos representan una secuencia de uno o varios números enteros consecutivos. Se crean al unir dos números enteros con `..`.

```elixir
1..5
```

Los rangos pueden ser ascendentes o descendentes. Siempre incluyen el primer y el último valor.

Un rango implementa el _protocolo Enumerable_, lo que significa que puedes usar las funciones del módulo `Enum` para trabajar con rangos.
