# Instrucciones

Imprime los números del 1 al n con las siguientes reglas:

1. Cuando el número sea múltiplo de 3, imprime "Fizz"
2. Cuando el número sea múltiplo de 5, imprime "Buzz"
3. Cuando el número sea múltiplo de 3 y de 5 a la vez, imprime "Fizz Buzz"
4. Cuando el número no sea múltiplo de 3 ni de 5, imprime el número

La salida debe ser un vector de strings, como por ejemplo, "1" "2" "Fizz" "4" "Buzz" ...
