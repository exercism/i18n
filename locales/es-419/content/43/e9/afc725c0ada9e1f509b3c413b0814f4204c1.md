# Introducción

Los [parámetros variádicos][variadic-parameters] permiten que una función acepte cero o más valores de un tipo especificado para un solo parámetro.
Defines un parámetro variádico agregando tres puntos (`...`) a la anotación de tipo del parámetro.

Dentro del cuerpo de la función, Swift hace que estos valores estén disponibles como un array del tipo especificado:

```swift
import Foundation

func geometricMean(_ numbers: Double...) -> Double {
    var total = 1.0
    for number in numbers {
        total *= number
    }
    return pow(total, 1.0 / Double(numbers.count))
}

let result = geometricMean(1, 2, 3, 4, 5)
// result is 2.605171084697352
```

~~~~exercism/note
Si una función incluye parámetros adicionales después de un parámetro variádico, el primer parámetro que sigue al parámetro variádico **debe** tener una etiqueta de argumento explícita para que Swift sepa dónde termina la lista de argumentos variádicos.
~~~~
