# Strings

Crystal tiene un tipo llamado [`String`][strings], que se usa para representar texto: una cadena de caracteres.
Los strings de Crystal son secuencias de caracteres Unicode.
Los strings son inmutables, lo que significa que no se pueden cambiar una vez creados.
Esto quiere decir que se crea un string nuevo cada vez que modificas un string; por lo tanto, el string original no se modifica.

Para definir un string usas comillas dobles `"`.

```crystal
"Hello World"
```

## Concatenación

Para concatenar dos strings, usa el operador `+`.
El operador `+` devuelve un string nuevo que combina los dos strings.

```crystal
hello = "Hello"
hello + " World"
# => "Hello World"
```

## Conversión entre strings y números

El método `to_i` convierte un string en un entero.
Como alternativa, puedes usar el método `to_f` para obtener un número de punto flotante.
Si el string no se puede convertir en un número, se lanzará un `ArgumentError`.

```crystal
"1".to_i
# => 1

"1.0".to_f
# => 1.0

"Hello".to_i
# => ArgumentError: Invalid integer: Hello
```

Un entero o un número de punto flotante se puede convertir en un string usando el método `to_s`.

```crystal
1.to_s
# => "1"

1.0.to_s
# => "1.0"
```

## Interpolación

La interpolación es una forma práctica de combinar strings e incrustar expresiones dentro de un string.
Para interpolar un string, puedes usar el carácter `#` seguido de llaves `{}` con la expresión dentro de las llaves.

```crystal
name = "World"
"Hello #{name}!"
# => "Hello World!"
```

Crystal convierte automáticamente el resultado de la expresión en un string.

```crystal
"Hello #{1 + 1}!"
# => "Hello 2!"
```

## Tamaño

Cuando necesitas saber cuántos caracteres tiene un string, puedes usar el método `size`, que devuelve la longitud del string como un entero.
El tamaño de un string es una propiedad almacenada del string, así que no tiene que calcular el tamaño cada vez que llamas al método, lo que lo hace muy rápido.

```crystal
"Hello World".size
# => 11
```

## Indexación

La indexación es cuando quieres obtener un carácter específico de un string.
Para obtener un carácter de un `String` puedes usar la conocida notación de corchetes.

~~~~exercism/note
`[]` está implementado como un método de instancia de String, donde el índice es el argumento del método.
~~~~

El primer carácter de un string está en el índice 0.

```crystal
"Hello World"[0]
# => 'H'

"Hello World"[6]
# => 'W'
```

Para obtener un carácter desde el final de un string, puedes tomar la longitud del string menos uno para obtener el índice del último carácter; para el penúltimo carácter, tomas la longitud del string menos dos, y así sucesivamente.
Hay un atajo para esto, y es simplemente usar un índice negativo: el último carácter está en el índice -1, el penúltimo en el índice -2, y así sucesivamente.

```crystal
name = "Hello World"
name[name.size - 1]
# => 'd'

name[-1]
# => 'd'
```

## Secuencias de escape

Algunos caracteres no se pueden escribir directamente en un string; en su lugar, tienes que usar una secuencia de escape.
Por ejemplo, si quieres usar comillas dobles dentro de un string, tienes que escapar las comillas dobles.
Puedes usar el carácter `\` para escribir una secuencia de escape, seguido del carácter que quieres escapar.

Estos son los caracteres especiales en Crystal:

| Valor    | Descripción                   |
| -------- | ----------------------------- |
| `\a`     | Alerta                        |
| `\b`     | Retroceso                     |
| `\e`     | Escape                        |
| `\f`     | Avance de página              |
| `\n`     | Salto de línea                |
| `\r`     | Retorno de carro              |
| `\t`     | Tabulación horizontal         |
| `\v`     | Tabulación vertical           |
| `\\`     | Barra invertida               |
| `\'`     | Comilla simple                |
| `\"`     | Comilla doble                 |
| `\377`   | Carácter ASCII octal          |
| `\xFF`   | Carácter ASCII hexadecimal    |
| `\uFFFF` | Carácter Unicode hexadecimal  |

```crystal
puts "Hello \"World\""
# => Hello "World"

puts "Hello \nWorld"
# => Hello
# => World
```

## Strings de varias líneas

Para escribir un string de varias líneas, usas la misma sintaxis que para un string de una sola línea, pero haces un salto de línea por cada línea que quieras incluir en el string.

```crystal
"Hello
World"
# => "Hello\nWorld"
```
