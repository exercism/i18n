# General

- [Aplicación parcial][partial-application] y [`(|>)`][pipe-operator] facilitan escribir código elegante y encadenado cuando la estructura de datos principal es el último argumento de las funciones. Todas las funciones comunes de la biblioteca estándar hacen esto, como `List.map`
- Puedes usar una sentencia Let en las funciones `attack` para aplicar parcialmente las funciones `attackWithSword` y `attachWithClaw` con la fuerza correcta para Annalyn y Kazak.

[pipe-operator]: https://package.elm-lang.org/packages/elm/core/latest/Basics#|%3E
[partial-application]: https://riptutorial.com/elm/example/7499/partial-application
[let]: "https://elmprogramming.com/let-expression.html"
