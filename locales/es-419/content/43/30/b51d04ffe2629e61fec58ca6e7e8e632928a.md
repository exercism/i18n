# Instrucciones

Una escuela local cerca de ti tiene una asociación de estudiantes muy activa.
La asociación de estudiantes es dirigida por un presidente y cada 2 años se realizan elecciones para elegir a un nuevo presidente.
En las elecciones de este año, se decidió que se necesitaba un nuevo sistema digital para contar los votos.

La escuela necesita tu ayuda para construir este nuevo sistema.

## 1. Crea un contador de votos

Una de las primeras cosas que necesita el nuevo sistema de votación es un contador de votos.
Este contador es una forma de llevar la cuenta de los votos que tiene un candidato en particular.

Crea una función `new_vote_counter` que acepte el número de votos iniciales de un candidato y devuelva una instantánea de un struct `VoteCounter`, inicializada con el número de votos iniciales dado.

```rust
let initial_votes: u32 = 2;
let counter: @VoteCounter = new_vote_counter(initial_votes);
// @VoteCounter {
//     value: 2,
// }
```

## 2. Obtén el número de votos de un contador

¡Ya tienes una forma de crear nuevos contadores!
Pero ahora te das cuenta de que el nuevo sistema también necesitará una forma de obtener el número de votos de un contador.

Crea una función `vote_count` que reciba un contador (`@VoteCounter`) como argumento y devuelva el número de votos del contador.

```rust
let initial_votes: u32 = 3;
let vote_counter: @VoteCounter = new_vote_counter(initial_votes);

let count = vote_count(vote_counter);
// => 3
```

## 3. Incrementa los votos de un contador

¡Por fin es hora de contar los votos!
Ahora necesitas una forma de incrementar los votos de un contador.

Crea una función `increment_vote_count` que reciba un contador (`@VoteCounter`) como argumento y un número de votos, e incremente el contador en ese número de votos.

```rust
let votes: u32 = 3;
let vote_counter: @VoteCounter = new_vote_counter(initial_votes);
let vote_counter: VoteCounter = increment_vote_count(vote_counter, 2);

let count = vote_count(@vote_counter);
// => 5
```

## 4. Crea los resultados de la elección

Con todos los votos ya contados, es hora de preparar el anuncio de los resultados para toda la escuela.
Para esto, te das cuenta de que tener solo contadores de votos es insuficiente.
Tiene que haber una forma de asociar el número de votos con un candidato en particular.

Crea una función `new_election_result` que reciba el nombre de un candidato y su número de votos y devuelva un nuevo resultado electoral.

```rust
let result: ElectionResult = new_election_result("Peter", 3);
// ElectionResult {
//     name: "Peter",
//     votes: @VoteCounter {
//         value: 3,
//     },
// }
```

El struct de resultado electoral ya está creado para ti y está definido así:

```rust
struct ElectionResult {
    name: ByteArray,
    counter: @VoteCounter,
}
```

## 5. Anuncia los resultados

¡Es hora de anunciar al nuevo presidente a la escuela!
El presidente se anunciará en los pequeños tableros de mensajes digitales que tiene la escuela.

El mensaje debe mostrar el nombre del nuevo presidente y los votos que obtuvo, con el siguiente formato: `<candidate_name> (<votes>)`.
Este es un ejemplo de ese mensaje: `"Peter (51)"`.

Crea una función `display_result` que reciba un `@ElectionResult` como argumento y devuelva un `ByteArray` con el mensaje que se va a mostrar.

```rust
let result = ElectionResult {
    name: "John",
    votes: @VoteCounter {
        value: 32,
    },
};

let msg = display_result(@result);
// => "John (32)"
```

## 6. Recuento de votos

Para asegurarse de que los resultados finales fueran precisos, se volvieron a contar los votos.
En el recuento, se encontró que el número de votos de algunos candidatos difería en uno.

Crea una función `decrement_votes_of_candidate` que reciba los resultados finales y el nombre de un candidato al que se le debe disminuir su número de votos.
Los resultados finales se dan en forma de un `Felt252Dict<u32>`, donde las claves son los nombres de los candidatos y los valores son sus votos totales.

```rust
let mut final_results: Felt252Dict<u32> = Default::default();
final_results.insert('Mary', 10);
final_results.insert('John', 51);

decrement_votes_of_candidate(ref final_results, 'Mary');

let decremented_votes = final_results.get('Mary');
// => 9
```
