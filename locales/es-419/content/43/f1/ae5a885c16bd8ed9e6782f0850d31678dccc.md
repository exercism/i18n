# Instrucciones

En este ejercicio, vas a implementar una forma de llevar un registro de los puntajes altos del juego más popular de la sala de arcade de tu zona.

Tienes 7 funciones por implementar, todas relacionadas con devolver y manipular un diccionario de datos de puntajes altos.

## 1. Define un nuevo diccionario de puntajes altos

Crea una función `newScoreBoard()` que no reciba parámetros y devuelva un nuevo diccionario de puntajes altos cuyas claves sean de tipo `String` y cuyos valores sean de tipo `Int`.

## 2. Agrega jugadores al diccionario de puntajes altos

Para agregar un jugador al diccionario de puntajes altos, define `addPlayer(_:_:_:)`, una función que recibe 3 parámetros:

- El primer parámetro es el diccionario de puntajes.
    Debe ser un parámetro de entrada y salida.
- El segundo parámetro es el nombre de un jugador como string.
- El tercer parámetro es el puntaje como un entero.
    El parámetro es opcional, implementa el tercer parámetro con un valor predeterminado de 0.

```swift
var highScores = newScoreBoard()
addPlayer(&highScores, "Dave Thomas")
// Returns ["Dave Thomas": 0]
addPlayer(&highScores, "José Valim", 486_373)
// Returns ["Dave Thomas": 0, "José Valim": 486_373]
```

## 3. Elimina jugadores del diccionario de puntajes

Para eliminar a un jugador del diccionario de puntajes altos, define `removePlayer(_:_:)`, que recibe 2 parámetros:

- El primer parámetro es el diccionario de puntajes.
    Debe ser un parámetro de entrada y salida.
- El segundo parámetro es el nombre del jugador como string.

Esta función debe eliminar al jugador del diccionario si está en él y no hacer nada en caso contrario.

```swift
var highScores = ["Dave Thomas": 0, "José Valim": 486_373]
removePlayer(&highScores, "Dave Thomas")
// Returns ["José Valim": 486_373]
removePlayer(&highScores, "Rose Fanaras")
// Returns ["José Valim": 486_373]
```

## 4. Restablece el puntaje de un jugador

Para restablecer el puntaje de un jugador, define `resetPlayer(_:_:)`, que recibe 2 parámetros:

- El primer parámetro es el diccionario de puntajes.
    Debe ser un parámetro de entrada y salida.
- El segundo parámetro es el nombre del jugador como string, cuyo puntaje deseas restablecer.

La función establece en 0 el puntaje del jugador.
Si el jugador no está en el diccionario, no debe pasar nada.

```swift
var highScores = ["Dave Thomas": 486_373, "José Valim": 10]
resetScore(&highScores, "Dave Thomas")
// Returns ["Dave Thomas": 0, "José Valim": 10]
```

## 5. Actualiza el puntaje de un jugador

Para actualizar el puntaje de un jugador sumando al puntaje anterior, define `updateScore`, que recibe 3 parámetros:

- El primer parámetro es el diccionario de puntajes. Debe ser un parámetro de entrada y salida.
- El segundo parámetro es el nombre del jugador como string, cuyo puntaje deseas actualizar.
- El tercer parámetro es el puntaje que deseas **sumar** al puntaje alto almacenado.

```swift
var highScores = ["Dave Thomas": 0, "José Valim": 486_373]
addPlayer(&highScores, "Freyja Ćirić", 12_771_008)
updateScore(&highScores, "Freyja Ćirić", 73)
// Returns ["Dave Thomas": 0, "José Valim": 486_373, "Freyja Ćirić": 12_771_081]
```

## 6. Obtén una lista de jugadores con sus puntajes ordenada por nombre de jugador

Define la función `orderByPlayers`, que recibe 1 parámetro:

- El primer parámetro es el diccionario de puntajes.

La función devuelve un array de tuplas `(String, Int)` que son los jugadores y sus puntajes altos, ordenado de forma ascendente por el nombre del jugador.

```swift
var highScores = ["Dave Thomas": 0, "José Valim": 486_373, "Freyja Ćirić": 12_771_091]
orderByPlayers(highScores)
// Returns [("Dave Thomas", 0), ("Freyja Ćirić", 12_771_091), ("José Valim", 486_373)]
```

## 7. Obtén una lista de jugadores ordenada por puntaje de jugador en orden descendente

Para obtener una lista de jugadores ordenada por puntaje en orden descendente, define `orderByScores`, que recibe 1 parámetro:

- El primer parámetro es el diccionario de puntajes.

La función devuelve un array de tuplas `(String, Int)` que son los jugadores y sus puntajes altos, ordenado de forma descendente por el puntaje del jugador.

```swift
var highScores = ["Dave Thomas": 0, "José Valim": 486_373, "Freyja Ćirić": 12_771_091]
orderByScores(highScores)
// Returns [("Freyja Ćirić", 12_771_091), ("José Valim", 486_373), ("Dave Thomas", 0)]
```
