# Pistas

## 1. Crea un nuevo tablero de puntuaciones máximas

- Crea un objeto nuevo usando llaves.
- Escribe la clave como un string para que pueda contener espacios.
- Separa la clave y el valor con dos puntos.

## 2. Agrega jugadores a un tablero de puntuaciones

- Usa la notación de corchetes para agregar una clave con un nombre que está guardado en una variable (el argumento).
- Usa el operador de asignación (`=`) para establecer un valor para la nueva clave.
- Devuelve el parámetro del tablero de puntuaciones después de agregar al jugador.

## 3. Elimina jugadores de un tablero de puntuaciones

- Usa el [operador delete][mdn-delete].
- Haz referencia a la clave como lo hiciste en la tarea anterior (notación de corchetes).

## 4. Aumenta la puntuación de un jugador

- Primero, piensa en cómo expresar el nuevo valor que quieres asignar.
- Luego usa el operador de asignación como en la tarea 2 para establecer ese nuevo valor.
- Si aún no lo has hecho, puedes usar el [operador de asignación abreviado][mdn-shorthand-assignment] `+=`.

## 5. Aplica los puntos de bonificación del lunes

- Usa un bucle `for...in` para recorrer todas las claves del objeto.
- Para cada clave, establece el nuevo valor como lo hiciste en la tarea 4.
