# Pruebas

Si tienes el binario de 8th en tu PATH, escribe el comando:

```bash
8th -f test.8th
```

Si el binario de 8th no está en el PATH, en Windows escribe

```cmd
\path\to\8th -f test.8th
```

Linux o macOS:

```bash
/path/to/8th -f test.8th
```

## Pruebas en el REPL

Inicia 8th, cargando test-words.8th:

```sh
8th -f test-words.8th
```

Esto iniciará una sesión de CLI en la que, una vez que hayas escrito algo de código en el archivo de tu solución, podrás cargarlo en el REPL.
Por ejemplo, para el ejercicio «word-count», escribirías:

```8th
"word-count.8th" f:include
```

Y puedes ejecutar las pruebas con
```sh
"word-count-tests.8th" f:include
```

O puedes copiar y pegar una sola prueba de ese archivo, o escribir la tuya.

## Pruebas omitidas

Resolver un ejercicio significa hacer que todas sus pruebas pasen.
De forma predeterminada, cuando ejecutas las pruebas solo se ejecuta una (la primera).
Esto es intencional, ya que te permite concentrarte solo en hacer que esa prueba pase.
Una vez que pase, puedes habilitar la siguiente prueba moviendo la palabra `SKIP-REST-OF-TESTS` después de ella.

## Anular las omisiones

Para ejecutar todas las pruebas, incluidas las que están después de la palabra `SKIP-REST-OF-TESTS`, puedes establecer la variable de entorno `RUN_ALL_TESTS` en el valor `true`.
Una forma de establecerlo solo mientras se ejecutan las pruebas es (macOS y Linux):

```bash
RUN_ALL_TESTS=true 8th -f test.8th
```
