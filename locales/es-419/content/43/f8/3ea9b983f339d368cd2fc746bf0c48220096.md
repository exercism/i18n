### Invocación dinámica de funciones

Las funciones de awk no son objetos de primera clase: no se pueden pasar de un lado a otro como sí permiten otros lenguajes.
Sin embargo, una variable puede contener el _nombre_ de una función (un string), y la función se invoca con una notación especial, `@varname(args)`.
Un ejemplo:

```awk
function greet(name) {
    print "Hello, " name
}
BEGIN {
    greet("John")       # => "Hello, John"

    f = "greet"
    f("Bill")           # => error
    @f("Bill")          # => "Hello, Bill"
}
```
Esto se describe en [Llamadas indirectas a funciones][indirect].
Esta es una extensión de `gawk`.
