# Anexo a las instrucciones

## Registros

| Registro | Uso          | Tipo      | Descripción                        |
| -------- | ------------ | --------- | ---------------------------------- |
| `$a0`    | entrada      | dirección | string de nombre terminado en nulo |
| `$a1`    | entrada      | entero    | número                             |
| `$a2`    | entrada/salida | dirección | string de resultado terminado en nulo |
| `$t0-9`  | temporal     | cualquiera | para almacenamiento temporal       |
