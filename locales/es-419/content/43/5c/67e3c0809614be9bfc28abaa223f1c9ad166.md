# Instalación

## Instalar Godot Engine

El track de GDScript se construye sobre [Godot Engine][godot-engine], que funciona en Windows, Linux, macOS y Android.
Por el momento, el test runner para [trabajar en local][working-locally] requiere Linux.
Este track requiere la versión 4.0 de Godot o superior.

Después de completar la instalación, puedes verificar si la CLI se instaló correctamente ejecutando este comando en una terminal:

```bash
godot --version
```

## Instalar el test runner del track GDScript de Exercism

Necesitarás tener [Godot instalado][installation] correctamente para usar el test runner.

Para compilar y probar scripts de GDScript para Exercism, Godot se ejecutará en modo «headless» desde la CLI.
Por ahora, estas instrucciones requieren Linux y bash.

### Paso 1: Instalar la infraestructura general del test runner

Para preparar las pruebas, clona [https://github.com/exercism/gdscript-test-runner][gdscript-test-runner] y mueve su contenido a `/opt/test-runner/`:

```sh
git clone https://github.com/exercism/gdscript-test-runner.git
sudo mv gdscript-test-runner/ /opt/test-runner/
```

### Paso 2: Descargar el script del test runner para ejercicios individuales

Suponiendo que tienes la herramienta `exercism` configurada y has descargado al menos un ejercicio de GDScript, esta debería haber creado una carpeta `gdscript` dentro de tu espacio de trabajo (como se muestra al ejecutar `exercism configure`) para alojar los ejercicios.
Guarda [el test runner][test-local-gdscript-solution] en esta carpeta y marca el archivo como ejecutable.

## Ejecutar las pruebas

Con los pasos de instalación completados, deberías poder empezar desde cualquier directorio de ejercicio (por ejemplo, `~/exercism/gdscript/two-fer`) y ejecutar el script (que está un nivel arriba, en `../`) para probar tu solución local de ese ejercicio:

```sh
../test-local-gdscript-solution.sh
```

[installation]: https://exercism.org/docs/tracks/gdscript/installation
[gdscript-test-runner]: https://github.com/exercism/gdscript-test-runner
[test-local-gdscript-solution]: https://raw.githubusercontent.com/exercism/gdscript-test-runner/refs/heads/main/bin/test-local-gdscript-solution.sh

## Usar un IDE

Para obtener resaltado de sintaxis de GDScript dentro de un editor como [Visual Studio Code][vscode], necesitarás tener instalada una extensión como [godot-tools][godot-tools], además de un servidor de depuración en ejecución.
Godot inicia este servidor de depuración automáticamente cada vez que hay un proyecto abierto en su propio editor, y lo mantiene en ejecución hasta que se cierra el proyecto o el propio Godot.
