# Introducción

Los métodos de extensión permiten agregar métodos a tipos existentes sin crear un nuevo tipo derivado, sin recompilar y sin modificar de ninguna otra forma el tipo original. Se definen como métodos estáticos, pero se llaman usando la sintaxis de un método de instancia. Su primer parámetro va precedido del modificador `this`, especifica sobre qué tipo opera el método y se incorporan al ámbito a nivel del espacio de nombres.

```csharp
public static int WordCount(this string str)
{
    return str.Split().Length;
}

"Hello World".WordCount();
// => 2
```
