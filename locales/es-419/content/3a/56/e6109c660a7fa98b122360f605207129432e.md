# Pistas

## General

- No te preocupes por cómo se obtienen los argumentos; concéntrate en combinarlos para devolver el resultado esperado.

## 1. Define si pac-man puede comerse un fantasma

- La función debe devolver un valor [bool][bool].
- Puedes usar el operador [bool][bool] `&&` para combinar los argumentos y obtener un resultado.

## 2. Define si pac-man anota puntos

- La función debe devolver un valor [bool][bool].
- Puedes usar el operador [bool][bool] `||` para combinar los argumentos y obtener un resultado.

## 3. Define si pac-man pierde

- La función debe devolver un valor [bool][bool].
- Puedes usar los operadores [bool][bool] `&&` y `!` para combinar los argumentos y obtener un resultado.

## 4. Define si pac-man gana

- La función debe devolver un valor [bool][bool].
- Puedes usar los operadores [bool][bool] `&&` y `!` para combinar los argumentos y los resultados de una de las funciones que implementaste antes.

[bool]: https://gleam.run/book/tour/bools.html
