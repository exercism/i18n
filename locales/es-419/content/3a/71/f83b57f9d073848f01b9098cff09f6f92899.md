# Introducción

Bombas, válvulas, mangueras: cualquier cosa que retenga un recurso del sistema operativo (un archivo abierto, una conexión de red) tiene que *liberarse* cuando termines con ella. El vocabulario [`destructors`][destructors] de Factor envuelve todo esto en un framework que garantiza la limpieza, incluso cuando un error interrumpe tu código a mitad de camino.

## La clase y el genérico

Una clase se une al framework extendiendo `disposable` e implementando el genérico `dispose*`:

```factor
USING: accessors destructors kernel ;

TUPLE: pump < disposable opened ;

: <pump> ( -- pump )
    pump new-disposable t >>opened ;

M: pump dispose* f >>opened drop ;
```

`new-disposable ( class -- obj )` asigna la tupla *y* la registra en el framework: una excepción entre la asignación y el siguiente punto seguro no puede provocar una fuga del recurso. El framework garantiza que `dispose*` se ejecute **como máximo una vez** por objeto, así que las llamadas repetidas a `dispose` no tienen ningún efecto.

## Las llamadas externas usan `dispose`

```
dispose          ( obj -- )                ! release; safe to call twice
with-disposal    ( disposable quot -- )    ! scope one resource
with-destructors ( quot -- )               ! open a registry scope
&dispose         ( obj -- obj )            ! dispose on normal *or* failure exit
|dispose         ( obj -- obj )            ! dispose only if the scope unwinds
```

`with-disposal` es la forma para un solo recurso: empuja el disposable para el bloque de código interior y lo libera al salir.

```factor
USING: destructors io ;

<pump> [
    "pumping" print
] with-disposal
! pump released on the way out — even if `print` had thrown
```

Para más de un recurso, abre un ámbito con `with-destructors` y registra cada adquisición. `&dispose` (ampersand) significa «liberar siempre al salir, tanto si todo va bien como si falla». `|dispose` (pipe) significa «liberar **solo** en caso de fallo», algo útil cuando el camino del éxito le pasa el recurso a quien hizo la llamada para que se haga cargo de él.

```factor
[
    <pump> &dispose
    <pump> &dispose
    ! ... use the pumps ...
] with-destructors
! both pumps released
```

Para un try/finally básico, sin registro, [`cleanup`][cleanup] (en `continuations`) es la primitiva de nivel más bajo, pero `with-destructors` es el Factor moderno e idiomático.
