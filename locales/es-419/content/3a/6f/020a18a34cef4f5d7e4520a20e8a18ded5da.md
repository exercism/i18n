# Introducción

En C++, los Boolean se representan con el tipo `bool`.
Un `bool` es `true` o `false`.

## Operadores lógicos

C++ admite tres operadores Boolean: `!` (NOT), `&&` (AND) y `||` (OR).
También puedes usar las versiones alternativas `not`, `and` y `or`.

```cpp
true || false // => true
true && false // => false
!true // => false
not false // => true
```

## Precedencia

Los tres operadores Boolean tienen cada uno una _precedencia de operadores_ distinta.
Por eso se evalúan en este orden: `!` primero, `&&` segundo y, por último, `||`.
Si quieres forzar un orden distinto, puedes encerrar una expresión Boolean entre paréntesis (es decir, `()`), ya que los paréntesis tienen una precedencia de operadores aún mayor.

```cpp
!true && false   // => false
!(true and false) // => true
```

## Conversión

Si usas `true` o `false` en un lugar donde se espera un número, se convertirán a `1` y `0`, respectivamente.
Si usas un número en una operación Boolean, todo excepto `0` se trata como `true`, incluso los valores negativos.

```cpp
!true && 0.0   // => false
true + true + false // => 2
```
