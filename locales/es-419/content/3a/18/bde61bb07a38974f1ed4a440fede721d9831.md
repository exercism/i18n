# Introducción

En situaciones donde la seguridad es clave (o incluso simplemente en una base de código grande, donde cada desarrollador tiene sus propias prioridades e intereses), debes evitar que se pueda eludir la API pública de una clase. Eso ocurre cuando aceptas y guardas los parámetros mutables de un método, o cuando expones un miembro mutable de la clase mediante un valor de retorno o como parámetro `out`.
