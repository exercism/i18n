# Introducción

ABAP tiene varios tipos numéricos. En este ejercicio, usarás dos de ellos:

- `i` para valores enteros, como una cantidad de días.
- `p` para valores decimales empaquetados, como una tarifa por hora o un descuento.

```abap
DATA billable_days TYPE i VALUE 22.
DATA rate_per_hour TYPE p LENGTH 8 DECIMALS 2 VALUE '89.89'.
```

Los números empaquetados definen su longitud máxima y su cantidad de decimales. Los literales decimales se suelen escribir como valores de texto y el compilador los convierte al tipo decimal de destino, o bien se convierten con `CONV`.

```abap
TYPES discount_rate TYPE p LENGTH 8 DECIMALS 6.

DATA discount TYPE discount_rate.
discount = CONV discount_rate( '0.15' ).
```

ABAP incluye funciones numéricas integradas para redondear. La función `floor` redondea hacia abajo al número entero más cercano, y `ceil` redondea hacia arriba al número entero más cercano.

```abap
DATA full_months TYPE i.
full_months = floor( 70 / 22 ).

DATA rounded_cost TYPE i.
rounded_cost = ceil( '14527.2' ).
```
