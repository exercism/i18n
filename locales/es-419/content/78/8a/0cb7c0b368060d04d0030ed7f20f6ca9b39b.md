# Anexo de instrucciones

## Implementación

Los elementos se representan mediante [registros](https://lfe.gitbooks.io/reference-guide/content/16.html), definidos en `item.lfe`.
Usa `item-weight` para obtener el peso y `item-value` para obtener el valor.

```
;; Create an item with weight=5, value=50
(set item (make-item weight 5 value 50))

;; Get the weight. Returns 5.
(item-weight item)

;; Get the value. Returns 50.
(item-value item)
```
