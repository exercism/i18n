# Instrucciones

En este ejercicio escribirás código para llevar un registro de un array de lenguajes de programación que quieres aprender en Exercism.

Tienes seis tareas, y todas implican trabajar con arrays.

## 1. Crea un nuevo array

Para llevar un registro de los lenguajes que quieres aprender, necesitarás crear un nuevo array. Define el enlace `newList` que contiene un array nuevo y vacío.

```fsharp
newList
// => []
```

## 2. Define un array existente

Por ahora tienes una hoja de papel donde anotaste los lenguajes que quieres aprender: F#, Clojure y Haskell. Define el enlace `existingList` para representar ese array.

```fsharp
existingList
// => ["F#"; "Clojure"; "Haskell"]
```

## 3. Agrega un nuevo lenguaje a un array

A medida que exploras Exercism y encuentras lenguajes más interesantes, quieres agregarlos a tu array. Implementa la función `addLanguage` para agregar un nuevo lenguaje al inicio de tu array.

```fsharp
addLanguage "TypeScript" ["JavaScript"; "CoffeeScript"]
// => ["TypeScript"; "JavaScript"; "CoffeeScript"]
```

## 4. Cuenta los lenguajes del array

Contar los lenguajes uno por uno es incómodo. Implementa la función `countLanguages` para contar la cantidad de lenguajes que hay en tu array.

```fsharp
countLanguages ["C#"; "Racket"; "Rust"; "Ruby"]
// => 4
```

## 5. Invierte el array

En algún momento te das cuenta de que tu array en realidad está ordenado al revés. Implementa la función `reverseList` para invertir tu array.

```fsharp
reverseList ["Prolog"; "C"; "Idris"; "Assembly"]
// => ["Assembly"; "Idris"; "C"; "Prolog"]
```

## 6. Verifica si el array es emocionante

Aunque amas todos los lenguajes, F# ocupa un lugar especial en tu corazón. Por eso, un array de lenguajes te emociona mucho si:

- El primero del array es F#.
- El segundo elemento del array es F# y el array contiene dos o tres lenguajes.

Implementa la función `excitingList` para verificar si un array de lenguajes es emocionante:

```fsharp
excitingList ["Nim"; "F#"]
// => true
```
