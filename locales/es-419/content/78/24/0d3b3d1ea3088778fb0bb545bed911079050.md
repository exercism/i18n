# Introducción

Una forma común de usar los tipos de unión discriminada en F# es representar un conjunto fijo de constantes con nombre, una estructura que en otros lenguajes se llama «enum».

Normalmente, en una unión discriminada de este tipo, cada caso solo puede referirse a exactamente una de esas constantes con nombre.
Sin embargo, a veces es útil referirse a más de una constante.
Para lograrlo, se puede anotar la unión discriminada con el atributo Flags.

Una unión discriminada con el atributo Flags se puede definir así (usando la notación binaria de enteros 0b):

```fsharp
[<Flags>]
type PhoneFeatures =
| Call = 0b00000001
| Text = 0b00000010
```

Una instancia de `PhoneFeatures` con el valor `0b00000011` tiene establecidos tanto el flag `Call` como el `Text`.
