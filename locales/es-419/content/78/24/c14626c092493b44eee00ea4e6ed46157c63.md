# Introducción

Dado que el nombre del lenguaje que estamos usando, Lisp, significa _LIST Processing_, uno podría suponer que el lenguaje tiene facilidades para manejar listas de elementos, y tienes razón.

Aunque Common Lisp tiene otras estructuras de datos además de las listas, las listas se siguen usando mucho.

Una lista en Common Lisp es una secuencia de elementos. También se le llama **cons** (principalmente por razones históricas).
Los elementos en sí no tienen que ser del mismo tipo.
Por ejemplo, puedes tener una lista de `1`, `two`, `"III"`.

## Creación de listas

Puedes simplemente escribir una lista citada así: `'(1 two "III")` y eso hará que se cree y evalúe una lista (se evalúa a `(1 two "III")`).

También hay dos funciones principales que se usan para crear listas: `list` y `cons`.

`list` toma cero o más argumentos y se evalúa a una lista creada con esos valores:

```lisp
(list 1 'two "III") ; => (1 two "III")
```

`cons` toma dos elementos y crea una lista que tiene el primer elemento como su `car` (la cabeza de la lista) y el segundo elemento como su `cdr` (el resto de la lista):

```lisp
(cons 1 2)            ; => (1 . 2) ;; (a list without `nil` as its `cdr` is printed in this way)
(cons 1 nil)          ; => (1)
(cons 1 (cons 2 nil)) ; => (1 2)
```

Las funciones `car` y `cdr` se pueden usar para acceder al `car` y al `cdr` de una lista.

(`first` y `rest` son sinónimos de `car` y `cdr` y funcionan exactamente igual.)

## Longitud y acceso aleatorio

La longitud de una lista se puede determinar con el uso de `length`.
Una lista vacía tiene longitud cero.

Se puede acceder a un elemento arbitrario con `nth` (ten en cuenta que las listas están indexadas desde cero).

_No_ es un error solicitar un índice que sea mayor que la longitud de la lista.
En su lugar, se evalúa a `nil`:

```lisp
(nth 23 '(short list)) ; => nil
```

También hay varios métodos auxiliares para acceder a los primeros elementos de una lista: `first`, `second`, `third`, hasta `tenth`. Genial, ¿no?

## Combinación de listas

Dos o más listas se pueden combinar con `append`: 

```lisp
(append '(a b c) '(1 2 3)) ; => (A B C 1 2 3)
(append '(a b c) '())     ; => (A B C)
```

Cada argumento que se le da a `append` debe ser una lista.
