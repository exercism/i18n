# Anexo a las instrucciones

## Apéndice

~~~~exercism/note
Las instrucciones anteriores están sincronizadas con un repositorio compartido para garantizar la coherencia entre todas las pistas de lenguajes.
Este apéndice ofrece aclaraciones adicionales o modifica las instrucciones según sea necesario para alinearlas mejor con los objetivos de la pista de Clojure.
~~~~

Es importante que no uses funciones integradas existentes con una funcionalidad similar a la de la función que estás implementando, ya que hacerlo reduciría el valor de aprendizaje que se busca con el ejercicio.
En Clojure no existe una función integrada para contar la cantidad de bits de un número, así que puedes usar cualquier función de Clojure en tu implementación.
Sin embargo, Java sí incluye una función para esto: `bitCount`.
