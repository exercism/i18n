# Ayuda

Si tienes problemas y necesitas ayuda, puedes usar uno de los siguientes recursos:

- [The Emacs Wiki](http://emacswiki.org/) es de un valor incalculable. Vale la pena dedicarle bastante tiempo.
- [The Emacs Editor](http://www.gnu.org/software/emacs/manual/html_node/emacs/index.html) es el manual oficial de GNU Emacs.
- IRC: hay canales de [Libera.Chat](https://libera.chat/) para `#emacs`, `#org-mode` y muchos paquetes de Emacs,
  y mucha gente dispuesta a ayudar. Además, con emacs, IRC está a un paso:
  `M-x erc`.
- Matrix: en [Matrix](https://matrix.org/) hay salas para [emacs](https://matrix.to/#/#emacs:matrix.org), [org-mode](https://matrix.to/#/#org-mode:matrix.org) y otros paquetes de Emacs.
  Puedes [unirte al espacio de Emacs en Matrix](https://matrix.to/#/#emacs-space:matrix.org) para ver un panorama general de los canales disponibles.
  Para unirte a Matrix desde Emacs, puedes usar el paquete [Ement.el](https://github.com/alphapapa/ement.el).
- [StackOverflow](http://stackoverflow.com/questions/tagged/elisp) y [Emacs StackExchange](https://emacs.stackexchange.com/questions/tagged/elisp) te sirven para buscar tu problema y ver si ya lo respondieron. También puedes hacer y responder preguntas.
