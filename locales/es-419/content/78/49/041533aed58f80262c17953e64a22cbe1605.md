# Instalación

Para trabajar en los ejercicios, vas a necesitar estos programas:

1. [`OPAM`, el gestor de paquetes de OCaml](https://opam.ocaml.org/)

   Consulta [Real World Ocaml, 2nd Ed.: Installation Instructions](https://dev.realworldocaml.org/install.html)
   para saber cómo instalar y configurar `OPAM` en tu sistema operativo.

2. El compilador de OCaml

   Consulta una lista de las versiones disponibles:

   ```bash
   opam switch
   ```

   Si ya tienes un switch para OCaml 5.1, cárgalo ejecutando `opam switch <switch-name>`, o crea un switch nuevo ejecutando:

   ```bash
   opam switch create exercism 5.4.0
   ```

   El nombre `exercism` aquí es opcional, pero darle nombre a tus switches es una buena práctica.

3. Instala las bibliotecas estándar extendidas y las bibliotecas de prueba

   Ejecuta lo siguiente para instalar las dependencias que requiere este track:

   ```bash
   opam install base core_kernel ounit qcheck
   ```

   Algunos ejercicios usan solo la biblioteca estándar de OCaml, y otros usan las bibliotecas extendidas de Jane Street llamadas Base y Core_kernel.
   La biblioteca de prueba se llama OUnit, y algunos ejercicios además usan la biblioteca QCheck para pruebas basadas en propiedades.
   Ejecutar el comando de arriba instalará estas bibliotecas.

4. Instala y usa la shell interactiva (opcional)

   Un resumen de [Setting up and using `utop`](https://dev.realworldocaml.org/install.html):

   ```bash
   opam install utop
   ```

   Crea un archivo nuevo llamado `.ocamlinit` en tu directorio home y agrégale las siguientes líneas:

   ```ocaml
   #use "topfind";;
   #require "base";;
   open Base
   ```

5. Instala herramientas en VS Code (opcional)

   Si usas VS Code:
   - Instala el servidor de lenguaje de OCaml desde [aquí](https://github.com/ocaml/ocaml-lsp).
   - Instala la extensión de OCaml para VS Code desde [aquí](https://marketplace.visualstudio.com/items?itemName=ocamllabs.ocaml-platform), o busca `OCaml Platform` de Ocaml Labs.
