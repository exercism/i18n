# Convención de Ameba

**Línea %{line_number}** :  Ameba reportó %{message}.

Lo que significa que este código no sigue las convenciones generales de [code style][code style]. Aunque este tipo de problema por lo general no afecta la forma en que el código _se ejecuta_, puede perjudicar la legibilidad o el rendimiento de herramientas automatizadas, como los generadores de documentación o los ejecutores de pruebas.

[code style]: https://crystal-lang.org/reference/latest/conventions/coding_style.html
