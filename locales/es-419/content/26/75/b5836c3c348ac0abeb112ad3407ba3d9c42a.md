# Instrucciones

Un anagrama es una reordenación de letras para formar una palabra nueva.
Dada una palabra y una lista de candidatos, selecciona la sublista de anagramas de la palabra dada.

Dada `"listen"` y una lista de candidatos como `"enlists" "google"
"inlets" "banana"`, el programa debe devolver una lista que contenga
`"inlets"`.
