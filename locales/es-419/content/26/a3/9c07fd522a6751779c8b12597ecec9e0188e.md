# Instrucciones

Como casi cualquier persona con un trabajo, Layla the Lisp Alien a veces necesita hacer reportes para dar a conocer información a los demás. Te pide que la ayudes a dar formato a los datos que tiene para estos reportes.

## 1. Dar formato a los valores trimestrales

Lo primero que Layla necesita es una función: `format-quarter-value`, que recibe dos parámetros, el trimestre del calendario y el valor, y les da formato para un reporte. Debe evaluar a un string.

```lisp
(format-quarter-value "last" 3.14) ; => "The value last quarter: 3.14"
(format-quarter-value "this" 0) ; => "The value this quarter: 0"
```

## 2. El reporte de dos trimestres

Layla te agradece por la función `format-quarter-value` y dice que será muy útil en la *siguiente* función que se necesita.

El siguiente reporte necesita mostrar el trimestre y el valor de 2 trimestres impresos en dos líneas.

Además, la salida debe ir al stream que se proporciona como primer argumento.

Por ejemplo: `(format-two-quarters t "last" 3.14 "this" 0)` producirá lo siguiente en la salida estándar:

```

The value last quarter: 3.14
The value this quarter: 0

```

Fíjate en las líneas en blanco que lo rodean.

## 3. Legible para humanos o para aliens de Lisp

Layla olvidó decirte que a los aliens de Lisp les gusta ver los valores de una forma que sea legible como datos de Lisp. Así que necesita una nueva función que pueda leerse como datos de Lisp (de nuevo, al stream especificado):

```lisp
(format-two-quarters-for-reading nil "last" 3.14 "this" 0) ; =>

"(\"The value last quarter: 3.14\" \"The value this quarter: 0\")"
```
