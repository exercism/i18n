# Pistas

## 1. Estima el tiempo de preparación

- Usa la [función integrada `len()`][len-builtin] para determinar el número de capas (la longitud del slice de capas).

## 2. Calcula las cantidades necesarias de fideos y salsa

- Primero, crea dos variables para llevar la cuenta de la cantidad de fideos y de salsa.
- Usa un bucle `for` para recorrer las capas.
- Si encuentras una capa `'noodles'` o `'sauce'` en tu bucle, aumenta la cantidad guardada en la variable correspondiente.

## 3. Agrega el ingrediente secreto

- Vuelve a revisar [slices][concept-slices] para descubrir cómo obtener un elemento de un slice y cómo reemplazar un elemento en un slice.
- El índice del último elemento en un slice `a` es `len(a) - 1`.

## 4. Escala la receta

- Primero, crea un nuevo slice del mismo tamaño que el slice que recibes
- Usa un [bucle `for`][for-loop] para recorrer el slice que recibes y generar el slice de salida
