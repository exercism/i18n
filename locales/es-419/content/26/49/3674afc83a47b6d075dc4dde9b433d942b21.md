# Instalación

Este track usa [Wren Console][wren-console] de principio a fin para ofrecer un entorno de ejecución local de Wren. Esto significa que asumimos que toda ejecución de Wren en tu computadora ocurrirá con [Wren Console][wren-console]. No confundas esto con el <abbr title="interfaz de línea de comandos">CLI</abbr> oficial de Wren. En un mundo perfecto podrías usar ese entorno, pero actualmente [tiene](https://github.com/wren-lang/wren-cli/pull/74) [varios](https://github.com/wren-lang/wren/pull/1006) [problemas](https://github.com/wren-lang/wren-cli/issues/108) [distintos](https://github.com/wren-lang/wren-cli/pull/105) que lo convierten en una opción poco óptima para aprender Wren con Exercism.

Wren Console es un fork de Wren CLI, resuelve estos problemas y añade funcionalidades para que tu experiencia de aprendizaje sea más fluida. No te preocupes: los conocimientos y conceptos del lenguaje Wren que aprenderás aquí te servirán dondequiera que quieras usar Wren en el futuro.

## Resumen de la instalación

- Instala Git para el comando `git`
- Instala [Wren Console][wren-console] para el comando `wrenc`

### Instala Git

Necesitarás el binario `git` instalado y disponible en tu path. Así es como Wren Package instala paquetes (como la suite de pruebas que necesitarás para probar tus ejercicios, etc.).

- **Windows**: la [descarga oficial de Git](https://git-scm.com/download/win) es un buen punto de partida.
- **Linux**: tu gestor de paquetes favorito debería ayudarte.
- **Mac**: todas las versiones recientes de Mac OS incluyen `git` desde el primer momento.

Puedes confirmar que Git está instalado con `git --version`:

```
$ git --version
git version 2.31.1
```

No te preocupes si la versión exacta no coincide; por lo general, eso no es tan importante.


### Instala Wren Console

#### Windows

Lo más probable es que quieras [descargar la última versión][releases] desde GitHub. Después tendrás que descomprimirla y copiar el ejecutable `wrenc` a tu path.

También puedes [compilar desde el código fuente][build-from-source] con Visual Studio.

#### Linux

Puedes [descargar la última versión][releases] desde GitHub o [compilar desde el código fuente][build-from-source].

```sh
wget -c https://github.com/joshgoebel/wren-console/releases/download/v0.3.1/wren-console-v0.3.1-linux.tar.gz
tar xzf wren-console-v0.3.1-linux.tar.gz
```

Y asegúrate de que esté disponible en tu `PATH`.

```sh
cp bin/wrenc /usr/local/bin/
```


#### Mac

La instalación más sencilla es usar el tap y la fórmula de [Homebrew][homebrew] de Exercism:

```
brew tap exercism/wren
brew install wren-console
```

Como alternativa, puedes [descargar la última versión][releases] desde GitHub e instalarla manualmente como se muestra en las instrucciones para Linux. Compilar desde el código fuente también es bastante sencillo si estás familiarizado con ese tipo de cosas.

### Prueba la instalación

Cuando creas que ya tienes el binario instalado correctamente, conviene comprobar que todo funcione.

1. Abre un _terminal_ (`Terminal`, `cmd`, `Powershell`, `bash`, ...)
2. Ejecuta `wrenc -v`

Deberías ver tanto la versión de `wrenc` como la de Wren:

```
wrenc v0.3.1 (wren v0.4.0)
```

**Nota**: es importante que abras una ventana de terminal _nueva_. Es posible que las ventanas de terminal que ya estaban abiertas no se hayan actualizado después de completarse la instalación. Esto significa que esos terminales no saben que se instaló un programa nuevo.

> _**Ayuda**_: `'wrenc' is not recognised`
>
> Es probable que no hayas colocado `wrenc` en tu PATH... En MacOS y Linux puedes modificar tu path agregando lo siguiente a `~/.bash_profile` o a `~/.zshrc`:
>
> ```bash
> export PATH=/path/to/your/wrenc/:$PATH
> ```
> **No tengo idea de si algo de esto es correcto.**
> En Windows, abre el menú de inicio y busca «environment variables». Tendrás
> que editar la entrada `PATH` y _agregar_ aquí la ruta a los binarios de `wrenc`.
> Por lo general, se encuentran en `C:\Program Files\nodejs`. Si navegas hasta ahí con
> tu `File Explorer`, deberías encontrar `node.exe`, `npm.bat` y `npx.bat`.
>
> Cierra los terminales que tengas abiertos y abre uno nuevo.

## Requisitos de los ejercicios

Sigue [estas instrucciones][cli-walkthrough] para descargar el CLI `exercism` para tu sistema operativo.

Una vez que el CLI esté instalado y configurado, descarga el primer ejercicio, `hello-world`:

```bash
$ exercism download --exercise=hello-world --track=wren
```

Después, cada ejercicio necesita algunos paquetes de Wren para ejecutar las pruebas. Puedes instalarlos ejecutando este comando dentro del directorio del ejercicio:

```bash
$ wrenc package.wren install
```
