# Acerca de

Las [expresiones `throw`][throw-expressions] son una alternativa a las sentencias `throw` y, en particular, pueden aumentar el poder de las expresiones ternarias y otras expresiones compuestas.

```csharp
string trimmed = str == null ? throw new ArgumentException() : str.Trim();
```

Si `str` es `null` en el código anterior, se lanza una excepción.

[throw-expressions]: https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/keywords/throw#the-throw-expression
