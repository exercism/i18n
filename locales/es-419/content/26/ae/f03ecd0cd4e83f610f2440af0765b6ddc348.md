# Anexo de instrucciones

## Palabras

Implementa:

- `grep ( pattern flags files -- lines )`

`pattern` es la cadena de búsqueda, `flags` es un array de cero o más de las cadenas de banderas `"-n"`, `"-l"`, `"-i"`, `"-v"` y `"-x"`, y `files` es un array de uno o más nombres de archivo. Devuelve las líneas que coincidan (con los prefijos de nombre de archivo y número de línea que se hayan pedido) como un array de strings.

Cuando se pasa la bandera `-l`, devuelve un array con los nombres de los archivos que contienen al menos una coincidencia.

## Leer archivos

Lee las líneas de un archivo con `file-lines`, pasando una codificación:

```factor
USING: io.encodings.utf8 io.files ;

"iliad.txt" utf8 file-lines
! => { "Achilles sing, O Goddess! Peleus' son;" ... }
```

Los tres archivos de prueba (`iliad.txt`, `midsummer-night.txt` y `paradise-lost.txt`) vienen con el ejercicio en el directorio de trabajo, así que leerlos por su nombre simplemente funciona.
