# Instrucciones

Un violín se afina de oído tomando como referencia una nota. Las cuerdas están muy separadas en cuanto al tono, y los números que intervienen no son enteros.

Las cinco tareas van en la clase `TUNING_THE_STRINGS`.

## 1. Subir una octava

Una nota una octava más aguda tiene el doble de frecuencia.

```sather
TUNING_THE_STRINGS::octave_up(440.0d)
-- => 880.0d
```

## 2. Bajar una octava

Una octava más abajo es la mitad.

```sather
TUNING_THE_STRINGS::octave_down(440.0d)
-- => 220.0d
```

## 3. Justo a la mitad

Dadas dos frecuencias, devuelve la que está exactamente entre ellas.

```sather
TUNING_THE_STRINGS::midpoint(440.0d, 442.0d)
-- => 441.0d
```

## 4. ¿Qué tan separadas están?

Cuando dos notas están cerca pero no son iguales, escuchas una pulsación por segundo por cada ciclo en que difieren. Devuelve qué tan separadas están las frecuencias. La respuesta nunca es negativa, sin importar cuál de las dos notas sea más aguda.

```sather
TUNING_THE_STRINGS::beats_per_second(441.5d, 440.0d)
-- => 1.5d
```

## 5. Repartir la práctica

Dados un número de minutos y un número de músicos, ¿cuántos minutos le tocan a cada uno? Los minutos y los músicos son números enteros, pero la respuesta puede no serlo.

```sather
TUNING_THE_STRINGS::minutes_each(45, 2)
-- => 22.5d
```
