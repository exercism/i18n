# Strings

`STR` contiene texto. Un _string_ se escribe entre comillas dobles.

```sather
   composer : STR is
      return "Sibelius";
   end;
```

Un `STR` nunca cambia una vez que existe. Todo lo que sigue devuelve un _string_ *nuevo* en lugar de modificar aquel sobre el que se preguntó.

## Unir

```sather
"Jean" + " " + "Sibelius"      -- "Jean Sibelius"
```

`+` también une un número a un _string_, que es como un número entra en una frase:

```sather
"Opus " + 27           -- "Opus 27"
```

## Longitud

```sather
"Sibelius".size        -- 8
"".size                -- 0
```

`.size` cuenta caracteres, y la respuesta es un `INT`.

## Partes

| Llamada | Respuesta |
| --- | --- |
| `"Sibelius".head(3)` | `"Sib"` |
| `"Sibelius".tail(4)` | `"lius"` |

Pedir más de lo que hay devuelve lo que hay, en lugar de fallar.

## Comparar

`=` pregunta si dos _strings_ son el mismo texto, y `/=` si son distintos.

```sather
"forte" = "forte"      -- true
"forte" = "Forte"      -- false
```

Las mayúsculas y las minúsculas importan. `.upper` y `.lower` devuelven una copia en un solo tipo de letra, que es la forma habitual de comparar cuando no importan las mayúsculas y minúsculas:

```sather
"Forte".lower                    -- "forte"
"Forte".lower = "forte".lower    -- true
```

## Sobre el tamaño

Un `STR` es una secuencia de bytes, y `.size` cuenta bytes. Para el texto en inglés, eso es lo mismo que contar letras. Para texto con acentos u otros alfabetos, no lo es, porque esas letras ocupan más de un byte cada una.
