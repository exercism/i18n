# Apéndice de instrucciones

## Cómo está estructurado este ejercicio para la ruta de Python

Las pruebas de este ejercicio esperan que tu solución se implemente en Python como una `class` RelativeDistance.
Si no conoces las `class`es en Python, [concept:python/classes]() y [`classes` en la documentación oficial de Python][classes in python] son buenos puntos de partida.


`RelativeDistance` debe inicializarse (_consulta [`__init__()`][init] para más información_) usando `family_tree`, un diccionario donde las `keys` son personas y los `values` son `list`s de los hijos de esa persona.
También tendrás que implementar un [método][methods] `degree_of_separation` que devolverá el grado de separación entre `person_a` y `person_b`, que son personas en el árbol genealógico que se pasa.


Se te da una implementación de esqueleto para el [método especial][special-methods] `__init__` que se usa para crear una instancia de la clase `RelativeDistance`, así como un esqueleto del método `degree_of_separation`.
Primero, tendrás que personalizar el `__init__` con un atributo apropiado en `self` (_la instancia_) para representar los datos de `family_tree`.
Después puedes agregar tu lógica al método `degree_of_separation` para calcular el grado de separación entre `person_a` y `person_b`.


## Mensajes de excepción

A veces es necesario [lanzar una excepción][raising-exceptions].
Cuando lo hagas, siempre debes incluir un **mensaje de error significativo** que indique cuál es el origen del error.
Esto hace que tu código sea más legible y ayuda mucho con la depuración.
En los casos en los que sabes que el origen del error será de cierto tipo, puedes optar por lanzar uno de los [tipos de error incorporados][base-error-classes], pero aun así debes incluir un mensaje significativo.

Este ejercicio en particular requiere que uses la [sentencia raise][raise-statement] para «lanzar» varios `ValueError`s.
En el primer escenario, tendrás que lanzar un `ValueError` cuando alguna de las dos personas que se pasan al método `RelativeDistance.degree_of_separation`, o ambas, no estén presentes en el árbol genealógico.

```python
# Example when Person A is not in the tree.
raise ValueError("Person A not in family tree.")
```

Si ambas personas están presentes en el árbol genealógico, tendrás que lanzar un `ValueError` cuando no haya una conexión válida entre ellas según lo que definen las reglas.

```python
# Example when there are no valid connections.
raise ValueError("No connection between person A and person B.")
```

Las pruebas solo pasarán si lanzas con `raise` el tipo de `exception` esperado e incluyes el mensaje esperado junto con él.
Revisa con cuidado las pruebas y sus resultados esperados, ya que estas instrucciones no son exhaustivas.
