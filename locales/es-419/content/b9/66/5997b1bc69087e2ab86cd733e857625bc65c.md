# Tests

## Configuración

Sigue las [instrucciones de configuración para WebAssembly][docs-exercism-wasm] para instalar las dependencias necesarias.

## Requisitos

Instala las dependencias del ejercicio:

```shell
# Using npm
npm install

# Alternatively using yarn
yarn
```

## Cómo hacer que pase la suite de tests

Todos los ejercicios incluyen una suite de tests para ayudarte a validar tu solución antes de enviarla.
Puedes ejecutar estos tests abriendo una terminal en el directorio del ejercicio y luego ejecutando:

```bash
# Using npm
npm test

# Alternatively using yarn
yarn test
```

En algunas suites de tests, todos los tests excepto el primero vienen omitidos.

Cuando logres que un test pase, puedes habilitar el siguiente cambiando `xtest` por `test`.

## Cómo escribir tests personalizados

Si quieres escribir tests adicionales y personalizados, crea un archivo nuevo, `custom.spec.js`, y envíalo junto con tu solución:

```shell
exercism submit numbers.wat custom.spec.js
```

[docs-exercism-wasm]: https://exercism.org/docs/tracks/wasm/installation
