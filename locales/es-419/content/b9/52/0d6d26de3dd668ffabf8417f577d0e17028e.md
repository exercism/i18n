## General

No implementes la estructura `SimpleLinkedList` como un envoltorio alrededor de un `Vec`. En su lugar, asigna los nodos en el heap.

Esto se podría implementar así:

```
pub struct SimpleLinkedList<T> {
    head: Option<Box<Node<T>>>,
}
```

El campo `head` apunta al primer elemento (Node) de esta lista enlazada.

Esta implementación también requiere una estructura `Node` con los siguientes campos:

```
struct Node<T> {
    data: T,
    next: Option<Box<Node<T>>>,
}
```

`data` contiene los datos almacenados, y `next` apunta al nodo siguiente (si existe) o a None.

## ¿Por qué `Option<Box<Node<T>>>` y no solo `Option<Node<T>>`?

Inténtalo por tu cuenta. Obtendrás el siguiente error.

```
| struct Node<T>
| ^^^^^^^^^^^^^^ recursive type has infinite size
...
|     next: Option<Node<T>>,
|     --------------------- recursive without indirection
```

El problema es que, en tiempo de compilación, el tamaño de next debe ser conocido.
Como `next` es recursivo («un nodo tiene un nodo que tiene un nodo...»), el compilador no sabe cuánta memoria hay que asignar.
En cambio, [Box](https://doc.rust-lang.org/std/boxed/) es un puntero al heap con un tamaño definido.
