# Pruebas

## Ejecutar las pruebas

Cuando estés en el directorio de un ejercicio, vas a ver dos subdirectorios:

* `src` contiene tu solución al ejercicio
* `spec` contiene las pruebas que hay que ejecutar para el ejercicio

Si estás en el directorio correcto (es decir, el que contiene `src` y `spec`), puedes ejecutar las pruebas de ese ejercicio con `crystal spec`:

```bash
$ pwd
/Users/johndoe/Code/exercism/crystal/hello-world

$ ls
GETTING_STARTED.md README.md          spec               src

$ crystal spec
```

Esto ejecuta todos los archivos de pruebas del directorio `spec`.

En cada archivo de pruebas, todas las pruebas menos la primera están omitidas.

Cuando consigas que una prueba pase, puedes dejar de omitir la siguiente cambiando `pending` por `it`.

## Formato de Crystal

Antes de enviar, se recomienda que ejecutes `crystal tool format` en tu solución.

Puedes formatear todo lo que está en tu directorio actual con:

```bash
$ crystal tool format ./
```

O puedes formatear archivos de forma selectiva con:

```bash
$ crystal tool format ./<path>/<to>/<file>
```

## Enviar tu solución

Asegúrate de enviar el archivo fuente que está en el directorio `src` cuando envíes tu solución:

```bash
$ exercism submit src/<exercise>.cr
```
