## 1. Extraer las coordenadas

Implementa la función `get_coordinate()` que toma un par `(treasure, coordinate)` de la lista de Azara y devuelve solo la coordenada del mapa extraída.


```python
>>> get_coordinate(('Scrimshawed Whale Tooth', '2A'))
2A
```

## 2. Formatear las coordenadas

Implementa la función `convert_coordinate()` que toma una coordenada con el formato «2A» y devuelve una tupla con el formato `("2", "A")`.


```python
>>> convert_coordinate("2A")
("2", "A")
```

## 3. Hacer coincidir las coordenadas

Implementa la función `compare_records()` que toma un par `(treasure, coordinate)` y un registro `(location, coordinate, quadrant)` y compara las coordenadas de cada uno.
Devuelve **`True`** si las coordenadas coinciden, y **`False`** si no.
Vuelve a formatear las coordenadas según sea necesario para hacer una comparación precisa.


```python
>>> compare_records(('Brass Spyglass', '4B'), ('Seaside Cottages', ('1', 'C'), 'blue'))
False

>>> compare_records(('Model Ship in Large Bottle', '8A'), ('Harbor Managers Office', ('8', 'A'), 'purple'))
True
```

## 4. Combinar los registros coincidentes

Implementa la función `create_record()` que toma un par `(treasure, coordinate)` de la lista de Azara y un registro `(location, coordinate, quadrant)` de la lista de Rui, y devuelve `(treasure, coordinate, location, coordinate, quadrant)` **si las coordenadas coinciden**.
Si las coordenadas _no_ coinciden, devuelve la cadena **«not a match»**.
Vuelve a formatear la coordenada según sea necesario para hacer una comparación precisa.


```python
>>> create_record(('Brass Spyglass', '4B'), ('Abandoned Lighthouse', ('4', 'B'), 'Blue'))
('Brass Spyglass', '4B', 'Abandoned Lighthouse', ('4', 'B'), 'Blue')

>>> create_record(('Brass Spyglass', '4B'), ('Seaside Cottages', ('1', 'C'), 'blue'))
"not a match"
```
