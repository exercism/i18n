# Introducción

Los comentarios te permiten dejar notas en el código sin afectar cómo se ejecuta.
Los comentarios de una sola línea empiezan con `//`, y los comentarios de varias líneas se envuelven entre `/*` y `*/`:

```go
// This is a single-line comment.

/*
This is a
multiline comment.
*/
```

Los comentarios cumplen propósitos distintos según dónde aparezcan.

## Comentarios de código

Los comentarios de código explican por qué se hace algo, no qué se hace.
Úsalos cuando la razón detrás de una decisión no sea evidente en el código:

```go
results = results[1:] // skipping the header row
```

## Comentarios de documentación

Los comentarios de documentación van justo antes de una declaración, sin ninguna línea en blanco que separe el comentario de la declaración.
[`godoc`][godoc] los analiza para generar la documentación del paquete.
Un comentario de documentación debe ser una oración completa que empiece con el nombre del identificador y termine con un punto.

Los comentarios de paquete empiezan con el nombre del paquete:

```go
// Package kelvin provides tools to convert temperatures to and from Kelvin.
package kelvin
```

Los comentarios de función empiezan con el nombre de la función:

```go
// CelsiusFreezingTemp returns an integer value equal to the temperature at which water freezes in degrees Celsius.
func CelsiusFreezingTemp() int {
	return 0
}
```

[godoc]: https://go.dev/blog/godoc
