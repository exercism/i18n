# Instrucciones

Turndit Inc. está produciendo un nuevo tocadiscos que puede saltar entre las pistas de un disco. Nadie sabe por qué eso es algo bueno, pero insisten en hacerlo de todos modos, así que deja que lo hagan. Por ahora necesitan ayuda para entender cómo dirigir la aguja a la parte correcta del disco cuando se quiera.

La configuración tiene dos partes:

La aguja está suspendida sobre el tocadiscos y puede moverse de izquierda a derecha y de adelante hacia atrás por todo el disco (¡piensa en una máquina de garra!). Como el mecanismo que controla la aguja se mueve de forma lineal, registra su posición en un par de coordenadas `(x, y)`, con el origen en el centro del disco.

Hay además un sistema óptico que registra dónde está la aguja y dónde comienza la canción anterior o la siguiente. Como el disco está girando, es más fácil registrar la diferencia radial y la separación angular entre los dos puntos, `(r, θ)`, de nuevo con el origen en el centro del disco.

Turndit necesita saber cómo encontrar las nuevas coordenadas `(x', y')` a las que se moverá la aguja cuando se seleccione una pista diferente.

~~~~exercism/note
Estas operaciones se pueden hacer con funciones trigonométricas y/o matrices de rotación, pero se pueden simplificar (y hacer más divertidas, ¡te lo aseguro!) usando números complejos mediante rotaciones y desplazamientos radiales. 
De hecho, cada función de este ejercicio se puede escribir en forma de asignación (es decir, en una sola línea) con números complejos y los métodos y funcionalidades integrados de Julia, si así lo deseas.
~~~~

## 1. Construir un número complejo a partir de coordenadas cartesianas

Implementa la función `z(x, y)`, que toma una coordenada `x` y una coordenada `y` del plano complejo y devuelve el número complejo equivalente.

```julia-repl
julia> z(1, 1)
1.0 + 1.0im

julia> z(4.5, -7.3)
4.5 - 7.3im
```

## 2. Construir un número complejo a partir de coordenadas polares

Implementa la función `euler(r, θ)`, que toma una coordenada radial `r`, un ángulo `θ` (en radianes) y devuelve el número complejo equivalente en forma rectangular.

```julia-repl
julia> euler(1, π)
-1.0 + 0.0im

julia> euler(3, π/2)
0.0 + 3.0im

julia> euler(2, -π/4)
1.4142135623730951 - 1.414213562373095im  # √2 - √2im
```

## 3. Realizar una rotación de vector en 2D

Implementa la función `rotate(x, y, θ)`, que toma una coordenada `x`, una coordenada `y` y un desplazamiento angular `θ` (en radianes).
La función debe rotar el punto alrededor del origen el ángulo `θ` dado y devolver las nuevas coordenadas como una tupla: `(x', y')`.

```julia-repl
julia> rotate(0, 1, π)
(0, -1)

julia> rotate(1, 1, -π/2)
(1, -1)
```
## 4. Realizar un desplazamiento radial

Implementa la función `rdisplace(x, y, r)`, que toma una coordenada `x`, una coordenada `y` y un desplazamiento radial `r`.
La función debe desplazar las coordenadas x-y a lo largo del radio la cantidad `r` y devolver las nuevas coordenadas como una tupla: `(x', y')`.

```julia-repl
julia> rdisplace(0, 1, 1)
(0, 2)

julia> rdisplace(1, 1, √2)
(2, 2)
```
## 5. Encontrar la canción deseada

Implementa una función `findsong(x, y, r, θ)`, que toma las coordenadas `x` e `y` de la aguja, así como el desplazamiento `r` y `θ` entre la aguja y el comienzo de la canción deseada. Las nuevas coordenadas de la aguja deben devolverse como una tupla: `(x', y')`.

```julia-repl
julia> findsong(0, 1, 3, -π/2)
(4, 0)

julia> findsong(√2, √2, 0, 3π/4)
(-2, 0)
```
