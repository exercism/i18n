# Acerca de

Un valor booleano representa si una condición es `true` o `false`.
En Go, el tipo `bool` solo puede ser uno de esos dos valores.

```go
isDoorLocked := true
hasKey := true
knowsCode := false
```

## Operadores lógicos

Los operadores lógicos trabajan sobre uno o dos valores Boolean y producen un resultado Boolean.

| Operador | Nombre | Comportamiento                                        |
| -------- | ------ | ----------------------------------------------------- |
| `!`      | NOT    | Devuelve lo opuesto de un único valor Boolean         |
| `&&`     | AND    | Devuelve `true` solo cuando ambos lados son `true`    |
| `\|\|`   | OR     | Devuelve `true` si cualquiera de los lados es `true`  |

Usa `!` (NOT) cuando necesites el opuesto de un valor Boolean:

```go
!isDoorLocked // false
```

Usa `&&` (AND) cuando ambas condiciones deban ser `true`:

```go
canUnlockDoor := isDoorLocked && hasKey // true
```

Usa `||` (OR) cuando al menos una condición deba ser `true`:

```go
canOpenDoor := canUnlockDoor || knowsCode // true
```

Los operadores lógicos se evalúan en este orden: primero `!`, luego `&&` y por último `||`.
Usa paréntesis para agrupar el código y controlar qué operaciones se realizan primero:

```go
!true && false   // false because !true is evaluated first
!(true && false) // true because true && false is evaluated first
```
