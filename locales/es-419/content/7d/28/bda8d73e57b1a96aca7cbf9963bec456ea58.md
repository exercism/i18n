# Artículos

Cada ejercicio puede tener artículos asociados, que exploran algún aspecto interesante del ejercicio.

## Temas

Posibles temas que un artículo podría explorar:

- Comparar el rendimiento de distintos enfoques
- ¡Cualquier cosa interesante que se te ocurra!

## Consideraciones generales

- Si tu artículo se basa en algún código que escribiste, considera hacer commit de ese código (dentro del directorio del artículo)
  - Un ejemplo es un artículo sobre rendimiento, para el cual se escribió código de benchmark

## ¿Para qué ejercicios escribir artículos?

Cualquier ejercicio, siempre que haya algo interesante que explorar.

## Archivos

Cada artículo debe agregar los siguientes dos archivos:

- `.articles/<article-slug>/content.md`: descripción del artículo (consulta [la documentación](/docs/building/tracks/practice-exercises#file-articles-article-slug-content-md))
- `.articles/<article-slug>/snippet.md`: fragmento que muestra el artículo (consulta [la documentación](/docs/building/tracks/practice-exercises#file-articles-article-slug-snippet-txt))

Después tendrás que agregar o actualizar:

- `.articles/config.json`: metadatos de los artículos (consulta [la documentación](/docs/building/tracks/practice-exercises#file-article-config-json))
