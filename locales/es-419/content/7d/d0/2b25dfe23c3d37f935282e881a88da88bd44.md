# Pistas

## 1. Revisa cuáles fueron los conteos la semana pasada

- Los [vectores][vectors] se representan en Clojure con corchetes (`[ ]`)

## 2. Revisa cuántas aves visitaron hoy

- La función [`peek`][peek] se puede usar para devolver el último elemento de un vector.

## 3. Incrementa el conteo de hoy

- La función [`update`][update] se puede usar para devolver un nuevo vector con un elemento diferente en un índice dado.

- La función [`count`][count] se puede usar para obtener la longitud del vector.

- Las funciones [`inc`][inc] y [`dec`][dec] se pueden usar para incrementar y decrementar valores enteros.

## 4. Revisa si hubo un día sin aves visitantes

- La función [`every?`][every?] se puede usar para comprobar si todos los elementos de una colección satisfacen un predicado dado.

- El predicado [`pos?`][pos?] devuelve `true` si un número es mayor que cero.

- La función [`not`][not] devuelve `true` si una expresión se evalúa como falsa lógica.

## 5. Calcula el número de aves visitantes durante los primeros días

- La función [`take`][take] se puede usar para devolver una secuencia de los primeros n elementos de una colección.

- La función [`reduce`][reduce] se puede usar para sumar una colección de valores.

## 6. Calcula el número de días ajetreados

- La función de orden superior [`filter`][filter] se puede usar para devolver una secuencia de los elementos de una colección que satisfacen un predicado dado.

## 7.  Revisa si es una semana impar

- La función [`=`][equality] se puede usar para comprobar la igualdad.
