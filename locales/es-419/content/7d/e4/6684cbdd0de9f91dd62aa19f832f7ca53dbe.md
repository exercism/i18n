# Introducción

## Números

De [el manual][man-types]

> jq admite el mismo conjunto de tipos de datos que JSON: números, strings, Boolean, arrays, objetos (que en el habla de JSON son hashes con solo claves de tipo string) y «null».

Vamos a centrarnos en los **números**.

### Números y operadores numéricos

Todos los números, sean enteros o no, son números de punto flotante de doble precisión IEEE754.
Esto nos limita a 53 bits de precisión.

Puedes usar con los números los operadores habituales:

- aritmética: `+`, `-`, `*`, `/`, `%`
- comparación: `==`, `!=`, `<`, `<=`, `>=`, `>`
- las [funciones matemáticas][man-math] estándar

  Para las funciones de un solo argumento, pasa el valor a la función mediante una tubería

  ```sh
  $ jq -n '(1 | atan) * 4'
  3.141592653589793
  ```

  En el caso de las funciones de dos argumentos, estas ignorarán la entrada y esperarán que
  le pases los valores como parámetros (recuerda que los parámetros se separan con punto y coma)

  ```sh
  $ jq -n 'pow(2; 10)'
  1024
  ```

  El punto y coma es el separador de los argumentos de una función, no la coma.

### Otras expresiones de `jq`

Para resolver el ejercicio, necesitas conocer las expresiones condicionales.

#### Expresiones condicionales

`jq` usa una [expresión `if-then-else`][if-then-else] para las **expresiones condicionales**.
Como _expresión_, se coloca dentro de una tubería.

La sintaxis es: `if CONDITION then TRUE_EXPR else FALSE_EXPR end`.

La cláusula `else` es opcional.

```jq
42 | if . < 33 then "small" else "larger" end
# => "larger"
```

Puedes añadir condiciones adicionales con `elif`

```jq
42 | if . < 33 then "small"
     elif . < 67 then "medium"
     else "large"
     end
# => "medium"
```
