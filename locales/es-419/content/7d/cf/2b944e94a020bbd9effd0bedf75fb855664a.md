# Acerca de

Una quotation, escrita entre `[ ]`, es el equivalente en Factor de una función anónima o un bloque de código. Es un valor de primera clase que puedes empujar a la pila, guardar o pasar de un lado a otro, y que solo se ejecuta cuando algo la *llama*.

```factor
[ 1 + ]              ! a quotation, sitting on the stack
5 [ 1 + ] call .     ! => 6
```

Las quotations son secuencias de palabras, y Factor las usa en todos los lugares donde hace falta diferir o parametrizar un comportamiento:

- las ramas de `if` / `when` / `unless` / `cond`
- el predicado de `filter`, `count`, `any?`, `all?`
- la transformación de `map`, `each`, `reduce`
- el cuerpo de `times`, `while`, `loop`

El efecto de pila de una quotation normalmente se puede inferir. Cuando no se puede (por lo general, cuando se guarda y más adelante se llama con `call`), declara el efecto de forma explícita: `call( a b -- c )`.

## Cómo combinar quotations

```
compose ( quot1 quot2 -- compound )
curry   ( value quot  -- curried )
```

`compose` concatena dos quotations de extremo a extremo en una nueva quotation que ejecuta la primera y luego la segunda. `curry` antepone un valor fijo y devuelve una quotation que empujará ese valor a la pila antes de invocar la original. Ambas producen quotations normales que puedes llamar con `call`, guardar o pasar a los combinadores.

```factor
USING: kernel math ;

3 [ 2 * ] [ 1 + ] compose call .   ! 3 2 * 1 + => 7
5 [ 1 + ] curry call .             ! 5 1 +     => 6
```
