# Instrucciones

Traduce secuencias de ARN a proteínas.

El ARN se puede dividir en secuencias de tres nucleótidos llamadas codones y luego traducirse a un polipéptido, así:

ARN: `"AUGUUUUCU"` => se traduce a

Codones: `"AUG", "UUU", "UCU"`
=> que se convierten en un polipéptido con la siguiente secuencia =>

Proteína: `"Methionine", "Phenylalanine", "Serine"`

Hay 64 codones que a su vez corresponden a 20 aminoácidos; sin embargo, en este ejercicio no todas las secuencias de codones ni los aminoácidos resultantes son importantes.
Si funciona para un codón, el programa debería funcionar para todos.
Aun así, no dudes en ampliar la lista del conjunto de pruebas para incluirlos todos.

También hay tres codones de terminación (conocidos como codones «STOP»); si el ribosoma encuentra alguno de estos codones, la traducción termina por completo y la proteína queda terminada.

Todos los codones posteriores se ignoran, así:

ARN: `"AUGUUUUCUUAAAUG"` =>

Codones: `"AUG", "UUU", "UCU", "UAA", "AUG"` =>

Proteína: `"Methionine", "Phenylalanine", "Serine"`

Observa que el codón de parada `"UAA"` termina la traducción y la metionina final no se traduce a la secuencia de proteína.

A continuación se muestran los codones y los aminoácidos resultantes que se necesitan para el ejercicio.

| Codón              | Proteína      |
| :----------------- | :------------ |
| AUG                | Methionine    |
| UUU, UUC           | Phenylalanine |
| UUA, UUG           | Leucine       |
| UCU, UCC, UCA, UCG | Serine        |
| UAU, UAC           | Tyrosine      |
| UGU, UGC           | Cysteine      |
| UGG                | Tryptophan    |
| UAA, UAG, UGA      | STOP          |

Aprende más sobre la [traducción de proteínas en Wikipedia][protein-translation].
