# Introducción

## Sobrecarga de operadores

Los principales operadores aritméticos y de comparación se pueden adaptar para que los usen tus propias clases y estructuras. Esto se conoce como _sobrecarga de operadores_.

La mayoría de los operadores tienen la forma:

```csharp
static <return type> operator <operator symbols>(<parameters>);
```

Los operadores de conversión tienen la forma:

```csharp
static (explicit|implicit) operator <cast-to-type>(<cast-from-type> <parameter name>);
```

Los operadores se comportan igual que los métodos estáticos. Un símbolo de operador ocupa el lugar del identificador de un método, y tienen parámetros y un tipo de valor devuelto. Las reglas de tipos para los parámetros y el tipo de valor devuelto siguen tu intuición, y puedes confiar en que el compilador te dará indicaciones detalladas.
