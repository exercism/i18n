# Acerca de

En Clojure hay algunas construcciones básicas de [control de flujo](https://clojure.org/guides/learn/flow). `if` es la expresión condicional más importante: consta de una condición, un "entonces" y un "si no" opcional. `if` solo evalúa la rama que selecciona la condición.

```clojure
(if (even? 2) "even" "odd")
```

`cond` es una serie de pruebas y expresiones. Cada prueba se evalúa en orden y la expresión se evalúa y se devuelve para la primera prueba verdadera.

```clojure
(cond (= x 5) "Expression to evaluate when x equals 5"
      (> x 7) "Expression to evaluate when x is greater than 7"
      :else   "Expression to evaluate in all other cases")
```
