# Introducción

Las excepciones son una forma de manejo de errores.
Se llaman excepciones porque normalmente aparecen cuando ocurre algún evento inesperado.

En cualquier punto de nuestro código, podemos «lanzar» una excepción.
Lo hacemos con el método `raise`, pasándole un objeto (normalmente un objeto Exception, aunque también podemos usar strings básicos).
Por ejemplo, en los stubs de los ejercicios verás que usamos el `RuntimeError` incorporado para decirle a Ruby que un método no se ha implementado.
También puedes usar la sintaxis abreviada de `raise(ExceptionObject, params)`.
Si se omite la clase de la excepción, se usa `RuntimeError` por defecto.
Por ejemplo:

```ruby
# These are equivalent
raise RuntimeError.new("Please implement this method")
raise RuntimeError, "Please implement this method"
raise "Please implement this method"
```

Cuando Ruby ve esto, propaga el error hasta la parte superior del programa y luego sale.
Por ejemplo, si intentas dividir algo entre cero, verás algo como esto:
```ruby
5/0

#=> Traceback (most recent call last):
#=> ...
#=> ZeroDivisionError (divided by 0)
```
