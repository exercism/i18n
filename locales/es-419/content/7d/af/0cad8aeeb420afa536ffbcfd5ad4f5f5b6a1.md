# Ayuda

Si tienes problemas y necesitas ayuda, puedes usar uno de los siguientes recursos:

- [Documentación de la API de Dart](https://api.dart.dev/)
- [Chat de Gitter de Dart](https://gitter.im/dart-lang/home)
- [Información de la comunidad](https://www.dart.dev/community)
- [/r/dartlang](https://www.reddit.com/r/dartlang) es el subreddit de Dart.
- [StackOverflow](https://stackoverflow.com/questions/tagged/dart) lo puedes usar para buscar tu problema y ver si ya lo respondieron. También puedes hacer y responder preguntas.
