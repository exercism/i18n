# Anexo de instrucciones

## Formato del jardín

El jardín se representa como un string terminado en nulo, con un carácter de nueva línea al final de cada fila.

Un ejemplo sería `"   \n * \n   \n"`

## Registros

| Registro | Uso          | Tipo    | Descripción                        |
| -------- | ------------ | ------- | ---------------------------------- |
| `$a0`    | entrada      | dirección | string de entrada terminado en nulo  |
| `$a1`    | entrada/salida | dirección | string de salida terminado en nulo |
| `$t0-9`  | temporal     | cualquiera | para almacenamiento temporal       |
