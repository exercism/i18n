# General

- Documentación de la API: [paquete regexp][package-regexp]
- Sintaxis de expresiones regulares: [regexp/syntax][regexp-syntax]
- El sitio web [regex101.com][regex101] tiene un probador de expresiones regulares en línea.
- Se recomienda escribir las expresiones regulares como [literales de string en bruto][raw-string-literals] delimitados por acentos graves.

## 1. Identifica las líneas de log ilegibles

- La función [regexp.MatchString][fun-re-match-string] o el método [MatchString][method-match-string] podrían ser útiles aquí.
- En una expresión regular, el carácter `^` coincide con el comienzo de una línea o de un string.

## 2. Divide la línea de log

- El método [Split][regexp-split] podría ser útil aquí.

## 3. Cuenta el número de líneas que contienen `password` en texto entre comillas

- Puedes hacer que la coincidencia distinga entre mayúsculas y minúsculas anteponiendo `(?i)` a la expresión regular.
  Esto activa el flag `i`.
  Consulta [este tutorial][yourbasic-i-flag].

## 4. Elimina los artefactos del log

- El método [ReplaceAllString][replace-all-string] podría ser útil aquí.

## 5. Etiqueta las líneas con nombres de usuario

- El método [FindStringSubmatch][find-string-submatch] podría ser útil aquí.
