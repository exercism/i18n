# Introducción

Por defecto, las variables están limitadas al ámbito en el que se definen. Si se definen en un archivo, fuera de una función o una clase, quedan limitadas al ámbito del archivo. Si se definen dentro de una función o una clase, quedan limitadas al ámbito de la función o la clase.

```php
<?php

$file_scoped = "I am file scoped";

function example(): void
{
  $function_scoped = "I am function scoped!";
}
```

También puedes declarar variables específicamente con ámbito `global` o `static`.
