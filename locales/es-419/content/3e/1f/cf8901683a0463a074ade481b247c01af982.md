# Instrucciones

En este ejercicio eres un gran fanático del deporte y acabas de descubrir tu pasión por el básquetbol de la NBA. Como eres nuevo en el básquetbol de la NBA, estás explorando a fondo la historia de la NBA, llevando un registro de equipos, entrenadores, sus estadísticas de victorias y derrotas, y comparándolos entre sí.

Como todavía no tienes un equipo favorito, también desarrollarás un algoritmo para determinar si conviene apoyar a un equipo en particular.

Tienes siete tareas que te ayudarán a desarrollar tu propio algoritmo _apoyar a un equipo_.

## 1. Define el modelo

Define el registro `Coach` con los siguientes dos campos:

- `name`: el nombre del entrenador, de tipo `String`.
- `former_player`: indica si el entrenador fue exjugador, de tipo `Bool`.

Define el registro `Stats` con los siguientes dos campos:

- `wins`: el número de victorias, de tipo `Int`.
- `losses`: el número de derrotas, de tipo `Int`.

Define el registro `Team` con los siguientes tres campos:

- `name`: el nombre del equipo, de tipo `String`.
- `coach`: el entrenador del equipo, de tipo `Coach`.
- `stats`: las estadísticas del equipo, de tipo `Stats`.

## 2. Crea el entrenador de un equipo

Implementa la función `create_coach`, que recibe como parámetros el nombre del entrenador y su condición de exjugador, y devuelve su registro `Coach`:

```gleam
create_coach("Larry Bird", True)
// -> Coach(name: "Larry Bird", former_player: True)
```

## 3. Crea las estadísticas de un equipo

Implementa la función `create_stats`, que recibe como parámetros el número de victorias y el número de derrotas, y devuelve su registro `Stats`:

```gleam
create_stats(58, 24)
// -> Stats(wins: 58, losses: 24)
```

## 4. Crea un equipo

Implementa la función `create_team`, que recibe como parámetros el nombre del equipo, el entrenador y el registro, y devuelve su registro `Team`:

```gleam
let coach = create_coach("Larry Bird", True)
let stats = create_stats(58, 24)
create_team("Indiana Pacers", coach, stats)
// -> Team(
//   name: "Indiana Pacers",
//   coach: Coach(name: "Larry Bird", FormerPlayer = True),
//   stats: Stats(wins: 58, losses: 24),
// ) 
```

## 5. Reemplaza al entrenador

Como los dueños de la NBA son impacientes, descubriste que los malos resultados del equipo a menudo llevaban a que se reemplazara al entrenador. Implementa la función `replace_coach`, que recibe como parámetros el equipo y su nuevo entrenador, y devuelve el equipo pero con el nuevo entrenador:

```gleam
let coach = create_coach("Larry Bird", True)
let record = create_stats(58, 24)
let team = create_team("Indiana Pacers", coach, record)

let new_coach = create_coach("Isiah Thomas", True)
replace_coach(team, new_coach)
// -> Team(
//   name: "Indiana Pacers",
//   coach: Coach(name: "Isiah Thomas", FormerPlayer = True),
//   stats: Stats(wins: 58, losses: 24),
// ) 
```

## 6. Verifica si es el mismo equipo

Mientras revisas las estadísticas, llevas listas de equipos y sus registros. A veces te equivocas y hay entradas duplicadas en tu lista. Implementa la función `is_same_team`, que recibe dos equipos y devuelve `True` si son el mismo equipo; de lo contrario, devuelve `False`:

```gleam
let pacers_coach = create_coach("Larry Bird", True)
let pacers_stats = create_stats(58, 24)
let pacers_team = create_team("Indiana Pacers", pacers_coach, pacers_stats)

let lakers_coach = create_coach("Del Harris", False)
let lakers_stats = create_stats(61, 21)
let lakers_team = create_team("LA Lakers", lakers_coach, lakers_stats)

is_same_team(pacers_team, lakers_team)
// -> False
```

## 7. Verifica si deberías apoyar a un equipo

Después de analizar muchos equipos y partidos, se te ocurrió un algoritmo. Si se cumple una de las siguientes condiciones, apoyas a ese equipo:

- El nombre del entrenador es «Gregg Popovich»
- El entrenador es exjugador
- El nombre del equipo es «Chicago Bulls»
- El equipo ha ganado 60 partidos o más
- El equipo tiene más derrotas que victorias

Implementa la función `root_for_team`, que recibe un equipo y devuelve `True` si deberías apoyar a ese equipo; de lo contrario, devuelve `False`:

```gleam
let spurs_coach = create_coach("Gregg Popovich", False)
let spurs_stats = create_stats(56, 26)
let spurs_team = create_team("San Antonio Spurs", spurs_coach, spurs_stats)
root_for_team(spurs_team)
// -> True
```
