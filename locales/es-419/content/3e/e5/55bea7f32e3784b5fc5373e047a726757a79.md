# Instrucciones

Tienes varias tiendas de rebanadas de pizza en tu ciudad y quieres escribir una aplicación web que te permita comparar dos configuraciones de pizza distintas para saber quién te dará la rebanada más grande.

## 1. Escribe una función para calcular el tamaño de las rebanadas que devuelva nil para argumentos no válidos.

Implementa la función `sliceSize(diameter: Double?, slices: Int?) -> Double?`, que, dado el diámetro de una pizza y la cantidad de rebanadas por pizza, devuelve el área de una rebanada.
Para diámetros negativos y para una cantidad de rebanadas menor que 1, devuelve `nil`, ya que no existe una pizza con diámetro negativo y no hay forma de dividir una pizza en menos de 1 rebanada.
Si cualquiera de los parámetros es `nil`, también devuelve `nil`

```swift
sliceSize(diameter: 16, slices: 12)
// Returns 16.75516081914556
sliceSize(diameter: nil, slices: 8)
// Returns nil
```

## 2. Procesa los argumentos que envía tu aplicación web para determinar la rebanada más grande.

Tu aplicación web pasará cuatro strings a tu función, `biggestSlice(diameterA: String, slicesA: String, diameterB: String, slicesB: String) -> String`.
El primer y el segundo string son el diámetro y la cantidad de rebanadas de la primera pizza, respectivamente, y el tercero y el cuarto son el diámetro y la cantidad de rebanadas de la segunda pizza, respectivamente.

Implementa `biggestSlice` para que intente convertir el diámetro y la cantidad de rebanadas de cada pizza en un `Double` y un `Int`, respectivamente.
Si ambos valores se pueden obtener de los strings, usa tu primera función para intentar calcular el área; de lo contrario, el área de esa rebanada es `nil`.
Una vez que tengas las áreas de ambas rebanadas, compara las dos áreas usando las siguientes reglas:

1. Si el área de la rebanada A es un `Double` y la de la rebanada B es `nil`, devuelve «Slice A is bigger». Si ocurre lo contrario, devuelve «Slice B is bigger».
2. Si ambas áreas son `Double`, devuelve «Slice A is bigger» o «Slice B is bigger» según cuál rebanada tenga el área mayor.
3. Si ambas áreas son `nil`, o si ambas son `Double` y son iguales, devuelve «Neither slice is bigger».

~~~~exercism/note
Aunque los argumentos den como resultado un área de rebanada de 0, la rebanada sigue considerándose válida y debe verse como más grande que una rebanada con un área de `nil`.
~~~~

```swift
biggestSlice(diameterA: "10", slicesA: "6", diameterB: "14", slicesB: "12")
// Returns "Slice A is bigger"
biggestSlice(diameterA: "10", slicesA: "6", diameterB: "12", slicesB: "8")
// Returns "Slice B is bigger"
biggestSlice(diameterA: "Pepperoni", slicesA: "6", diameterB: "Sausage", slicesB: "12")
// Returns "Neither slice is bigger"
```
