# Pruebas

Si descargaste un ejercicio con la herramienta CLI, deberías ver un archivo Uiua con el nombre del ejercicio y un archivo `tests.ua`.
Este archivo contiene todos los casos de prueba, que coinciden con los que ejecuta el ejecutor de pruebas cuando subes tu solución.
No dudes en agregar casos de prueba adicionales para experimentar.
Sin embargo, modificar las pruebas no afecta el proceso del ejecutor de pruebas en línea.

## Pruebas locales

Para ejecutar las pruebas de un ejercicio, abre una terminal en el directorio del ejercicio y ejecuta el comando `uiua test tests.ua`.

Por ejemplo, la salida de un ejercicio `hello-world` sin editar podría verse así:

```bash
$ uiua test tests.ua
Error: Goodbye, Mars!
  at tests.ua:3:1
3 | ⍤⤙≍ "Hello, World!" Hello
    ─
Test failed
```

La línea `Error` muestra la salida real de tu código.
El número de línea indica la ubicación del resultado esperado en `tests.ua`.
Una solución correcta produce:

```bash
$ uiua test tests.ua
Test passed
```
