# Introducción

Un `string` en C# es un objeto que representa una cadena de texto inmutable como una secuencia de caracteres Unicode (letras, dígitos, signos de puntuación, etc.). Para definir una instancia de `string` se usan comillas dobles:

```csharp
string fruit = "Apple";
```

Los `string` se manipulan llamando a sus métodos. Una vez que se construye un `string`, su valor nunca puede cambiar. Cualquier método que parezca modificar un `string` en realidad devolverá un `string` nuevo.

Se pueden concatenar (sumar) varios `string` entre sí. La forma más sencilla de lograrlo es con el operador `+`.

```csharp
string name = "Jane";
"Hello " + name + "!";
// => "Hello Jane!"
```

Para cualquier formato de `string` más complejo que una simple concatenación, es preferible usar la interpolación de `string`. Para usar la interpolación, antepón el símbolo de dólar (`$`) al `string`. Después puedes usar llaves (`{}`) para acceder a cualquier variable dentro de tu `string`.

```csharp
string name = "Jane";
$"Hello {name}!";
// => "Hello Jane!"
```
