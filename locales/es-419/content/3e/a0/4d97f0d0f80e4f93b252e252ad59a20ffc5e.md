# Pistas

## General

- Una comparación empaquetada escribe una **máscara**: cada carril se pone a puros unos donde se cumple la condición y a puros ceros donde no.
- Las comparaciones de punto flotante toman la condición como un inmediato, o puedes usar las pseudoinstrucciones de NASM como `cmpltps` y `cmpeqps`.
- Las comparaciones de enteros toman la condición como un sufijo: `pcmpgtd` para mayor-que con signo, `pcmpeqd` para igualdad.
- Los bloques están alineados a 16 bytes, así que `movaps` y `movdqa` son seguros.

## 1. Marca las puntuaciones por encima del umbral

- `a > b` es lo mismo que `not (a <= b)` (inmediato 6) o que `b < a` (inmediato 1, con los operandos intercambiados).
- La igualdad no debe contar como por encima.

## 2. Marca las puntuaciones perfectas

- Esta es una igualdad de punto flotante directa con `cmpeqps`.
- Compara las puntuaciones con los máximos.
  Cada carril se pone a unos donde coinciden.

## 3. Asigna un rango

- Puedes definir el umbral `50.0` y los valores de rango `1`, `2` y `3` como constantes empaquetadas en memoria, de cuatro carriles cada una.
- Puedes definir dos máscaras.
  Una para «por encima del umbral», como en la tarea 1 (pero contra la constante empaquetada `50.0`).
  Otra para «puntuación perfecta» (como en la tarea 2).
- El rango básico es `1`.
  El rango `2` se debe seleccionar para los carriles donde la máscara de por encima del umbral está activada.
  El rango `3` se debe seleccionar para los carriles donde la máscara de puntuación perfecta está activada.
- Las puntuaciones perfectas también están por encima del umbral.
  Si la máscara de por encima del umbral se aplica primero, la máscara de puntuación perfecta la sobrescribe correctamente donde hace falta.
- `blendvps` toma su máscara de `xmm0` y selecciona según el bit más alto de cada carril.
  Para los carriles donde este bit está activado, selecciona del operando fuente.
  Para los demás, conserva el carril que ya está en el operando destino.

## 4. Cuenta los fallos

- Un rango falla cuando está estrictamente por debajo del umbral, es decir, `threshold > rank`.
  Puedes usar `pcmpgtd` con el umbral como destino y los rangos como fuente.
- Para cada bloque, se puede usar `movmskps` para colapsar la máscara de fallos en un registro de propósito general, tomando el bit más alto de cada carril.
  Este registro de propósito general puede ser de 32 o 64 bits.
- Puedes usar `popcnt` para contar la cantidad de bits activados en un registro de propósito general.
- Puede haber más de un bloque, así que hace falta un bucle para recorrerlos y acumular un resultado.
- Cada bloque tiene 16 bytes.

## 5. ¿Todos aprobaron?

- «todos aprobaron» se representa como un resultado de puros ceros en la máscara de fallos.
  Un solo carril distinto de cero es un resultado falso.
- Puede haber más de un bloque, así que hace falta un bucle para recorrerlos y acumular un resultado.
- Cada bloque tiene 16 bytes.
- Se puede usar un `ptest` de un registro consigo mismo para comprobar si todo son ceros.
- Una operación OR conserva los bits activados y una operación AND conserva los bits en cero.
  Ambas se pueden usar para acumular valores lógicos en un bucle.
- Una bandera se puede transformar en un resultado `0/1` con `setcc`.
