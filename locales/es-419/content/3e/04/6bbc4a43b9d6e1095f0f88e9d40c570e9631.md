# Instrucciones

Elyse, futura maga, continúa su entrenamiento. Recibirá varias pilas de cartas con las que debe hacer sus trucos.
Para que todo sea un poco más fácil, solo usa las cartas del 1 al 10.

En este ejercicio, usa métodos integrados para analizar el contenido de un array.

## 1. Encuentra la posición de una carta

Elyse quiere saber la posición (el índice) de una carta en la pila.

```javascript
const card = 2;
getCardPosition([9, 7, 3, 2], card);
// => 3
```

## 2. Determina si una carta está presente

Elyse quiere determinar si una carta está presente en la pila; en otras palabras, si la pila contiene un `number` específico.

```javascript
const card = 3;
doesStackIncludeCard([2, 3, 4, 5], card);
// => true
```

## 3. Determina si cada carta es par

Elyse quiere saber si cada carta es par; en otras palabras, si cada número de la pila es un `number` par.

```javascript
isEachCardEven([2, 4, 6, 7]);
// => false
```

## 4. Comprueba si la pila contiene una carta de valor impar

Elyse quiere saber si hay un número impar en la pila.

```javascript
doesStackIncludeOddCard([3, 2, 6, 4, 8]);
// => true
```

## 5. Obtén la primera carta impar de la pila

Elyse quiere saber el valor de la primera carta que sea impar.

```javascript
getFirstOddCard([4, 2, 8, 7, 9]);
// => 7
```

## 6. Determina la posición de la primera carta que sea par

Elyse quiere saber la posición de la primera carta que sea par.

```javascript
getFirstEvenCardPosition([5, 2, 3, 1]);
// => 1
```
