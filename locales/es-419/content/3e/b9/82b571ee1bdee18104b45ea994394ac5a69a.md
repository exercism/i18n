# no uses funciones de `Enum`

El objetivo de este ejercicio es enseñar las listas y las funciones del módulo [`Kernel`] y del módulo [`List`]. Resuélvelo sin usar ninguna de las funciones del módulo [`Enum`].

[`List`]: https://hexdocs.pm/elixir/List.html
[`Enum`]: https://hexdocs.pm/elixir/Enum.html
