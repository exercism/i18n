# Instrucciones

En este ejercicio vas a trabajar en un sistema para agendar citas de un salón de belleza.

Tienes tres tareas, y todas tendrán que ver con las fechas de las citas.

## 1. Verifica si una cita ya pasó

Implementa la subrutina `appointment_has_passed`, que recibe un string de fecha y verifica si la cita fue en algún momento del pasado:

```perl
appointment_has_passed("2019-07-25T13:45:00")
// => true
```

Los strings de fecha se pasarán en el formato de fecha y hora ISO 8601: `YYYY-mm-ddTHH:MM:SS`

Tendrás que implementar la subrutina privada `_parse_datetime`.
Te sugerimos un par de módulos:

- [Time::Piece][time-piece] es un módulo del núcleo de Perl.
- [DateTime::Tiny][datetime-tiny] está disponible en CPAN.

## 2. Verifica si la cita es en la tarde

Implementa la función `is_afternoon_appointment`, que recibe un string de fecha y verifica si la cita es en la tarde (>= 12:00 y < 18:00):

```perl
is_afternoon_appointment("2019-07-25T13:45:00")
// => true
```

## 3. Describe la hora y la fecha de la cita

Implementa la función `describe_appointment`, que recibe un string de fecha y devuelve una descripción de esa fecha y hora:

```perl
describe_appointment("2019-07-25T13:45:00")
// => "You have an appointment on 07/25/2019 1:45 PM"
```

Fíjate que la hora está en el rango de 0 a 12 y no tiene un cero ni un espacio a la izquierda.

[time-piece]: https://perldoc.perl.org/Time::Piece
[datetime-tiny]: https://metacpan.org/pod/DateTime::Tiny
