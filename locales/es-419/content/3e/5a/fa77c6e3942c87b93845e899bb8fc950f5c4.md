# Instrucciones

Convierte un número hexadecimal, representado como un string (por ejemplo, «10af8c»), a su equivalente decimal usando principios básicos (es decir, no, no puedes usar bibliotecas integradas o externas para realizar la conversión).

En la web usamos hexadecimal para representar colores, por ejemplo, verde: 008000, verde azulado: 008080, azul marino: 000080).

El programa debe manejar strings hexadecimales inválidos.
