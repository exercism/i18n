# Anexo a las instrucciones

## Registros

| Registro | Uso       | Tipo       | Descripción                                                                        |
| -------- | --------- | ---------- | ---------------------------------------------------------------------------------- |
| `$a0`    | entrada   | entero     | lado a                                                                             |
| `$a1`    | entrada   | entero     | lado b                                                                             |
| `$a2`    | entrada   | entero     | lado c                                                                             |
| `$v0`    | salida    | entero     | tipo de triángulo (`0` = escaleno, `1` = isósceles, `2` = equilátero, `3` = inválido) |
| `$t0-9`  | temporal  | cualquiera | usado para almacenamiento temporal                                                 |
