# Pistas

## General

- Todas las direcciones de memoria de este ejercicio están alineadas a 16 bytes, así que los movimientos alineados (`movdqa` para enteros, `movaps` para números de punto flotante) son apropiados.
  Una dirección alineada también se puede usar directamente como operando fuente de memoria.

## 1. Convierte una imagen al orden de visualización

- Dentro de cada píxel de 4 bytes, la conversión intercambia el byte en el desplazamiento `0` (rojo) con el byte en el desplazamiento `2` (azul), y deja los desplazamientos `1` (verde) y `3` (alfa) en su lugar.
  El mismo patrón se repite en los cuatro píxeles.
- Se puede usar un [shuffle][pshufb] para reordenar bytes en el mismo lugar según los índices de un vector de control.
- El vector de control se puede definir en memoria.
- Puede haber más de un bloque, y cada bloque es de 16 bytes.

## 2. Llena una región con un solo color

- El color es un solo píxel de 4 bytes.
  Para almacenarlo 16 bytes a la vez, primero hay que [difundirlo][pshufd] a los cuatro carriles de un registro `xmm`.
- Un píxel de 4 bytes primero hay que [moverlo][pinsrd] a un registro `xmm` antes de difundirlo.
- Todos los bloques rellenados son idénticos, así que el registro rellenado se puede crear una sola vez y luego reutilizarlo.
- Puede haber más de un bloque, y cada bloque es de 16 bytes.

## 3. Entrelaza dos líneas de barrido

- Se pueden usar instrucciones de [desempaquetado][unpack] para intercalar los bytes de dos operandos.
- Ambas instrucciones de desempaquetado toman el primer byte de cada par del operando destino, y el segundo del operando fuente.

## 4. Empaqueta una fila aclarada

- Las instrucciones de [empaquetado][pack] se pueden usar para estrechar los carriles mientras los limitan.
- Las instrucciones de empaquetado toman los carriles bajos del operando destino, y los carriles altos del operando fuente.

## 5. Separa las coordenadas en x e y

- Los [shuffles de punto flotante][shufps] se pueden usar para seleccionar y reordenar carriles de dos operandos.
- Las coordenadas `x` están en los carriles pares (`0` y `2`) de cada entrada, y las coordenadas `y` en los carriles impares (`1` y `3`).
