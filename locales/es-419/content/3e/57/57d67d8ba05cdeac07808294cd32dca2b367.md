# Introducción

Una **palabra** es el nombre que Factor le da a una función. Partiendo de la pila de datos de `basics`, este concepto trata sobre definir tus propias palabras: hacer aritmética, nombrar valores fijos y componer palabras a partir de otras palabras.

Una definición comienza con `:`, indica un efecto de pila, después el cuerpo y por último `;`. El compilador verifica que el cuerpo coincida con el efecto declarado:

```factor
: square ( x -- x*x ) dup * ;

4 square .    ! => 16
```

Las palabras de aritmética entera `+`, `-`, `*` sacan dos números de la pila y apilan el resultado. Viven en el vocabulario `math`, así que un archivo que las use necesita `math` en su línea `USING:`. La parte superior de la pila es el operando de la derecha:

```factor
2 3 + .    ! => 5
8 3 - .    ! => 5    (8 - 3, not 3 - 8)
2 3 * .    ! => 6
```

`CONSTANT:` nombra un valor fijo. Una constante es en sí misma una palabra. Al llamarla, apila el valor:

```factor
CONSTANT: pi 3

pi pi * .    ! => 9
```

El cuerpo de una palabra puede llamar a cualquier palabra que ya esté en el ámbito, incluidas las que definiste antes en el mismo archivo:

```factor
: double    ( x -- 2x ) 2 * ;
: quadruple ( x -- 4x ) double double ;

5 quadruple .    ! => 20
```

Un `?` al final en las salidas es la convención para «un Boolean», y tanto las palabras como las constantes usan `lowercase-kebab-case`.
