# Aprendizaje

* [The Rust Programming Language](https://doc.rust-lang.org/book/) es un excelente recurso para empezar con Rust y también para profundizar en funcionalidades específicas de Rust.
* [Rust by Example](https://doc.rust-lang.org/stable/rust-by-example/) te muestra ejemplos de las cosas más comunes que vas a escribir en Rust.
* [Into_rust()](http://intorust.com/) «Screencasts para aprender Rust.»
* [Rustlings](https://github.com/carols10cents/rustlings) «Pequeños ejercicios para que te acostumbres a leer y escribir código Rust.»
* [Rust User Forum](http://users.rust-lang.org) responde preguntas de todos los niveles
