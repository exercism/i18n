# Introducción

## Nil

[Nil][nil-dictionary] es una palabra en inglés que significa «nothing» o «zero». En Elixir, `nil` es un valor especial que significa una _ausencia_ de valor.

```elixir
# I do not have a favorite color
favorite_color = nil
```

En otros lenguajes de programación, los valores `null` o `none` podrían cumplir un rol similar.

## If

Además de `cond`, Elixir también proporciona la macro [`if/2`][getting-started-if], que es útil cuando necesitas verificar una sola condición.

[`if/2`][kernel-if] acepta una condición y dos opciones. Devuelve la primera opción si la condición es _truthy_, y la segunda opción si la condición es _falsy_.

```elixir
age = 15

if age >= 16 do
  "You are allowed to drink beer in Germany."
else
  "No beer for you!"
end

# => "No beer for you!"
```

También es posible escribir una expresión `if` en una sola línea. Fíjate en la coma después de la condición.

```elixir
if age > 16, do: "beer", else: "no beer"
```

Esta sintaxis es útil para expresiones muy cortas, pero conviene evitarla si la expresión no cabe en una sola línea.

### _Truthy_ y _falsy_

En Elixir, todos los tipos de datos se evalúan como un valor _truthy_ o _falsy_ cuando aparecen en un contexto booleano (como una expresión `if`). Todos los datos se consideran _truthy_ **excepto** `false` y `nil`. En particular, los strings vacíos, el entero `0` y los arrays vacíos se consideran _truthy_ en Elixir.
