# Pistas

## 1. Crea una nueva tabla de puntuaciones

- Puedes usar las funciones [`dict.new`][new] y [`dict.from_list`][from_list] para crear un dict nuevo.

## 2. Agrega jugadores a una tabla de puntuaciones

- Puedes usar la función [`dict.insert`][insert] para agregar un nuevo par clave-valor a un dict.

## 3. Elimina jugadores de una tabla de puntuaciones

- Puedes usar la función [`dict.delete`][delete] para eliminar un par clave-valor de un dict.

## 4. Aumenta la puntuación de un jugador

- Puedes usar la función [`dict.get`][get] para obtener el valor de una clave en un dict.
- Puedes usar la función [`dict.insert`][insert] para sobrescribir un par clave-valor que ya existe en un dict.

## 5. Aplica los puntos extra del lunes

- Puedes usar la función [`dict.map_values`][map_values] para modificar todos los valores de un dict.
