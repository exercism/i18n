# Introducción

Tu amiga Eliud heredó una granja de su abuela Tigist.
Su abuelita era inventora y tenía la tendencia de construir cosas de una manera demasiado complicada.
El gallinero tiene una pantalla digital que muestra un número codificado que representa las posiciones de todos los huevos que se podrían recoger.

Eliud te pide que escribas un programa que muestre el número real de huevos que hay en el gallinero.

La codificación de la información de las posiciones se calcula así:

1. Recorre los posibles lugares donde podrían poner huevos y anota un `1` si hay un huevo o un `0` si el lugar está vacío.
2. Convierte el número de binario a decimal.
3. Muestra el resultado en la pantalla.

Ejemplo 1:

```text
Chicken Coop:
 _ _ _ _ _ _ _
|E| |E|E| | |E|

Resulting Binary:
 1 0 1 1 0 0 1

Decimal number on the display:
89

Actual eggs in the coop:
4
```

Ejemplo 2:

```text
Chicken Coop:
 _ _ _ _ _ _ _ _
| | | |E| | | | |

Resulting Binary:
 0 0 0 1 0 0 0 0

Decimal number on the display:
16

Actual eggs in the coop:
1
```
