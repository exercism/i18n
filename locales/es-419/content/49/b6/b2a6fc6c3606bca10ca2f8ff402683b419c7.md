# Instrucciones

En este ejercicio vas a jugar con alguien a adivinar un número. Las reglas son simples: eliges en secreto un número entre `1` y `100` y esa persona intenta adivinar qué número elegiste. Para ayudarla, respondes de forma distinta según qué tan cerca esté su intento del número que elegiste (`42`). Estas son las reglas para las distintas respuestas:

- Si el intento es `42`: "Correct"
- Si el intento es `41` o `43`: "So close"
- Si el intento es menor que `41`: "Too low"
- Si el intento es mayor que `43`: "Too high"

Tienes cuatro tareas para implementar las respuestas a los intentos.

## 1. Responde a un intento correcto

Implementa la función `reply` para responder a un intento correcto:

```gleam
reply(42)
// -> "Correct"
```

## 2. Responde a un intento cercano

Modifica la función `reply` para responder a intentos cercanos:

```gleam
reply(41)
// -> "So close"
```

## 3. Responde a intentos demasiado bajos

Modifica la función `reply` para responder a intentos demasiado bajos:

```gleam
reply(25)
// -> "Too low"
```

## 4. Responde a intentos demasiado altos

Modifica la función `reply` para responder a intentos demasiado altos:

```gleam
reply(88)
// -> "Too high"
```
