# Instrucciones

Estás desarrollando tu propio videojuego de rol. En tu juego hay _personajes_ y _objetos_. Una de las muchas acciones que puedes hacer con un objeto es hacer que un personaje se lo coma.

No todos los objetos son comestibles, y no todos los objetos comestibles tienen los mismos efectos en el personaje. Algunos objetos, cuando se comen, se transforman en un objeto diferente (por ejemplo, si te comes una manzana, te queda el corazón de la manzana).

Para permitir toda esa flexibilidad, decidiste crear un protocolo `Edible` que algunos de los objetos pueden implementar.

## 1. Define la comestibilidad

Crea el protocolo `RPG.Edible`. El protocolo tiene una función: `eat`. La función `eat` acepta un objeto y un personaje, y devuelve un subproducto y un personaje.

## 2. Haz que las hogazas de pan sean comestibles

Implementa el protocolo `RPG.Edible` para el objeto `RPG.LoafOfBread`. Cuando se come, una hogaza de pan le da al personaje 5 puntos de vida y no tiene subproducto.

```elixir
RPG.Edible.eat(%RPG.LoafOfBread{}, %RPG.Character{health: 31})
# => {nil, %RPG.Character{health: 36, mana: 0}}
```

## 3. Haz que las pociones de maná sean comestibles

Implementa el protocolo `RPG.Edible` para el objeto `RPG.ManaPotion`. Cuando se come, una poción de maná le da al personaje tantos puntos de maná como la fuerza de la poción, y produce una botella vacía.

```elixir
RPG.Edible.eat(%RPG.ManaPotion{strength: 13}, %RPG.Character{mana: 50})
# => {%RPG.EmptyBottle{}, %RPG.Character{health: 100, mana: 63}}
```

## 4. Haz que los venenos sean comestibles

Implementa el protocolo `RPG.Edible` para el objeto `RPG.Poison`. Cuando se come, un veneno le quita todos los puntos de vida al personaje, y produce una botella vacía.

```elixir
RPG.Edible.eat(%RPG.Poison{}, %RPG.Character{health: 3000})
# => {%RPG.EmptyBottle{}, %RPG.Character{health: 0, mana: 0}}
```
