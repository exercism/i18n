# Apéndice a las instrucciones

## Registros

| Registro | Uso       | Tipo    | Descripción                   |
| -------- | --------- | ------- | ----------------------------- |
| `$a0`    | entrada   | entero  | número de entrada             |
| `$v0`    | salida    | entero  | número de huevos              |
| `$t0-9`  | temporal  | cualquiera | se usa para almacenamiento temporal |
