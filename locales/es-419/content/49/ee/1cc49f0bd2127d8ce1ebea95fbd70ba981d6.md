# Introducción

AWK es un lenguaje muy pequeño y solo tiene unos pocos tipos de datos básicos.
En esta lección veremos los números y los strings.

## Números

Los números en AWK se implementan como números de punto flotante de doble precisión.
No hay distinción entre enteros, números de punto flotante y números de doble precisión.

AWK entiende constantes numéricas octales (que comienzan con `0`) y constantes numéricas hexadecimales (que comienzan con `0x` o `0X`).

### Operaciones numéricas

Puedes usar los operadores aritméticos estándar `+`, `-`, `*`, `/`, `%`.
El operador de exponenciación es `^`.
Hay algunas funciones numéricas integradas, entre ellas funciones trigonométricas, generación de números aleatorios, e `int(x)` para truncar un número al entero más cercano entre _x_ y cero.

## Strings

Los strings en AWK son secuencias de caracteres.
Especifica una constante de string usando comillas dobles.

### Operaciones con strings

Solo hay una operación con strings: la concatenación.
La concatenación no tiene un operador especial;
simplemente colocar dos strings uno junto al otro los concatena:

```awk
BEGIN {
    hw = "Hello" "World"
    print hw
}
# => HelloWorld
```

~~~~exercism/note
`print` es una **sentencia**, no una función.
`print` no requiere paréntesis.
~~~~

AWK tiene una gran cantidad de funciones para manipular strings.
Las conoceremos en profundidad a medida que avancemos por el track.

## Conversión entre números y strings

No hay operadores explícitos para convertir entre números y strings.
AWK hará esto de forma implícita según el contexto del programa.
Esto hace que trabajar con los valores de los campos de entrada sea muy sencillo: por lo general, AWK simplemente hace lo que quieres que haga.

* `print x + y` convertirá los valores de las variables `x` y `y` a números gracias a la operación numérica `+`.
* `print x y` convertirá los valores de las variables `x` y `y` a strings gracias a la operación de concatenación.

Si quieres ser explícito al respecto, `0 + x` da la representación numérica de _x_ y `"" x` da la representación como string de _x_.

### De strings a números

La forma en que AWK convierte un string a número puede resultar confusa.
Una forma sencilla de pensarlo es que AWK lee «caracteres numéricos» desde el inicio de un string hasta que encuentra un carácter «no numérico».
Algunos ejemplos son:

* `"2.5"` se convierte en el número `2.5`;
* `"1e3"` se convierte en el número `1000` (notación científica);
* `"456abc"` se convierte en el número `456` (porque `a` no es un «numeral», ahí se detiene la conversión).
* `"abc789"` se convierte en el número `0` (no hay números al **inicio** del string).
