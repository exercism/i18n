# Instrucciones

Ozan está armando una lista de reproducción para un próximo viaje por carretera. No quiere escuchar la misma pista más de una vez, pero la lista se ha vuelto tan larga que ya le cuesta recordar cuáles pistas ya agregó.

La API del reproductor de música de Ozan solo sabe trabajar con arrays, así que intenta escribir algo de código que use `Array.indexOf()` para comprobar si una pista ya está presente antes de agregarla a la lista de reproducción. Por desgracia, su programa tarda demasiado en ejecutarse. ¡Necesita tu ayuda!

Al acudir en ayuda de Ozan, te asombras al descubrir que su lista de reproducción contiene _medio millón_ de pistas. ¿Quizás conozcas otra estructura de datos que te permita manipular la lista de reproducción de forma más eficiente?

## 1. Eliminar las pistas duplicadas

Implementa la función `removeDuplicates`, que recibe una lista de reproducción como _parámetro_ y _devuelve_ una nueva lista de reproducción donde todas las pistas sean únicas.

```javascript
const playlist = [
  'Court and Spark - Joni Mitchell',
  'Big Yellow Taxi - Joni Mitchell',
  'Court and Spark - Joni Mitchell',
];

removeDuplicates(playlist);
//=> ['Court and Spark - Joni Mitchell', 'Big Yellow Taxi - Joni Mitchell']
```

## 2. Comprobar si ya se agregó una pista

Implementa la función `hasTrack`, que recibe una lista de reproducción y una pista como _parámetros_ y _devuelve_ un boolean que indica si la lista de reproducción contiene la pista.

```javascript
const playlist = [
  'The Fashion Show - Grace Jones',
  'Dr. Funkenstein - Parliament',
];

hasTrack(playlist, 'Dr. Funkenstein - Parliament');
//=> true

hasTrack(playlist, 'Walking in the Rain - Grace Jones');
//=> false
```

## 3. Agregar una pista

Implementa la función `addTrack`, que recibe una lista de reproducción y una pista como _parámetros_ y _devuelve_ una nueva lista de reproducción que incluye la pista.

```javascript
const playlist = ['Selma - Bijelo Dugme'];

addTrack(playlist, 'Atomic Dog - George Clinton');
//=> ['Selma - Bijelo Dugme', 'Atomic Dog - George Clinton']

addTrack(playlist, 'Selma - Bijelo Dugme');
//=> ['Selma - Bijelo Dugme', 'Atomic Dog - George Clinton']
```

## 4. Eliminar una pista

Implementa la función `deleteTrack`, que recibe una lista de reproducción y una pista como _parámetros_ y _devuelve_ una nueva lista de reproducción que no incluye la pista.

```javascript
const playlist = [
  'The Treasure - Fra Lippo Lippi',
  'After the Fall - Klaus Nomi',
];

deleteTrack(playlist, 'The Treasure - Fra Lippo Lippi');
//=> ['After the Fall - Klaus Nomi']

deleteTrack(playlist, 'I Feel the Magic - Belinda Carlisle');
//=> ['After the Fall - Klaus Nomi']
```

## 5. Listar los artistas únicos

Implementa la función `listArtists`, que recibe una lista de reproducción como _parámetro_ y _devuelve_ la lista de artistas únicos en la lista de reproducción. Ten en cuenta que los nombres de las pistas tienen el formato `<SONG> - <ARTIST>`.

```javascript
const playlist = [
  'All Mine - Portishead',
  'Sight to Behold - Devendra Banhart',
  'Sour Times - Portishead',
];

listArtists(playlist);
//=> ['Portishead', 'Devendra Banhart']
```
