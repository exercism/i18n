# Pistas

## General

- Para generar números aleatorios, `:rand.uniform` de Erlang o `Enum.random` son buenos
puntos de partida.
- Puedes usar `Integer.pow` para hallar la potencia de un número, y `rem` para
el módulo.
- Ninguna de esas dos opciones funciona especialmente bien (ni rápido) con números enteros
muy grandes. La criptografía suele trabajar con números de más de 1024 bits. El módulo
`:crypto` de Erlang tiene una función útil para hallar el módulo de una potencia,
sobre todo con enteros enormes, pero puede que necesites `:binary` para decodificarlo.
