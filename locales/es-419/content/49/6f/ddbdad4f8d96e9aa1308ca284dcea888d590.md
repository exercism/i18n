# Acerca de

Factor concentra la aleatoriedad del vocabulario [`random`][random] en torno a una sola palabra genérica:

```
random ( obj -- elt )
```

Despacha según su argumento:

- un **entero** `n` produce un entero aleatorio en `[0, n)`;
- una **secuencia** produce un elemento aleatorio;
- también se admiten assocs, hash-sets y tuplas `uniform-distribution`.

Sobre él se construyen dos auxiliares para secuencias:

```factor
USING: random ;

{ 1 2 3 4 5 } randomize .   ! shuffle in place (Fisher–Yates)
{ 1 2 3 4 5 } 3 sample .    ! 3 distinct elements; error if too many
```

`randomize` modifica la secuencia y la devuelve, así que haz `clone` primero si necesitas conservar el orden original.

## De dónde viene la aleatoriedad

`random` lee el generador que está guardado en la variable dinámica `random-generator`. Por defecto, ese es un Mersenne Twister sembrado a partir del reloj del sistema, así que cada proceso es distinto. Puedes instalar un generador distinto durante toda una quotation:

```
<mersenne-twister> ( seed -- rnd )
with-random        ( rnd quot -- )
```

```factor
USING: random random.mersenne-twister ;

42 <mersenne-twister> [ { 1 2 3 } randomize ] with-random .
! => the same ordering on every run
```

Como `with-random` solo vincula `random-generator` durante la extensión dinámica de la quotation, una palabra que lo envuelva debería marcarse como `inline`, para que la quotation pueda dejar su resultado en la pila para quien la llama.

Más allá de estas, `random` ofrece `random-bits`, `random-unit`, `uniform-random` y `normal-random` para otras distribuciones, y también `system-random-generator` y `secure-random-generator` para necesidades no reproducibles y criptográficas.

[random]: https://docs.factorcode.org/content/vocab-random.html
