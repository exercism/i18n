# Instrucciones

Convierte un número binario, representado como un string (por ejemplo, «101010»), a su equivalente decimal usando los principios básicos.

Implementa la conversión de binario a decimal. Dado un string de entrada binaria, tu programa debe producir una salida decimal. El programa debe manejar entradas no válidas.

## Nota

- Implementa la conversión por tu cuenta.
  No uses otra cosa que haga la conversión por ti.

## Acerca del binario (base 2)

El sistema decimal es de base 10.

Un número como el 23 en notación de base 10 se puede entender
como una combinación lineal de potencias de 10:

- El dígito de más a la derecha se multiplica por 10^0 = 1
- El siguiente se multiplica por 10^1 = 10
- ...
- El *n*-ésimo se multiplica por 10^_(n-1)_.
- Todos estos valores se suman.

Así: `23 => 2*10^1 + 3*10^0 => 2*10 + 3*1 = 23 base 10`

El binario es similar, pero usa potencias de 2 en lugar de potencias de 10.

Así: `101 => 1*2^2 + 0*2^1 + 1*2^0 => 1*4 + 0*2 + 1*1 => 4 + 1 => 5 base 10`.
