# Debug

Para ayudar con la depuración, puedes usar [`print` o funciones similares][cl-print] para escribir en la salida estándar, que será visible en la salida de las pruebas.

Por ejemplo, si agregas `(print "hello there")` en la función que estás escribiendo, hará que sea visible en las ejecuciones de las pruebas (siempre que la prueba ejecute esa función).

Un «truco»: si tienes varias cosas que imprimir, puedes reunirlas en una lista y luego imprimir esa lista: `(print (list :this "that" 'the-other))`.

[cl-print]: http://www.lispworks.com/documentation/HyperSpec/Body/f_wr_pr.htm
