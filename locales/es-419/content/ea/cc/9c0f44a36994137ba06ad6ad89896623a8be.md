# Instrucciones

Mecha Munch™, una empresa de automatización de compras de supermercado, acaba de contratarte para trabajar en su app de pedidos.
Tu equipo tiene la tarea de construir un MVP (_[producto mínimo viable][mvp]_) que gestione todas las actividades básicas del carrito de compras y permita a los usuarios agregar, eliminar y ordenar sus pedidos de supermercado.
Por suerte, ¡otro equipo se encarga de todo lo relacionado con el dinero y el pago!

## 1. Agrega artículo(s) al carrito de compras del usuario

El MVP debe permitir que el usuario agregue artículos a su carrito de compras.
Puede ser un solo artículo o varios a la vez.
Como se trata de un MVP, la cantidad de artículos se indica mediante _repeticiones_.
Si un usuario quiere agregar 2 «Oranges», «Oranges» aparecerá dos veces en el iterable de entrada.
Si el usuario ya tiene el artículo en su carrito, la cantidad en el carrito debe aumentarse en 1.
Si el artículo es _nuevo_ en el carrito, debe agregarse con una cantidad de 1.

Crea la función `add_items!(<cart>, <items>)` que toma un diccionario de carrito y un iterable de artículos para agregar como argumentos.
Debe devolver el diccionario del carrito de compras actualizado para el usuario.

```julia-repl
julia> additems!(Dict("Banana" => 3, "Apple" => 2, "Orange" => 1),
                 ("Apple", "Apple", "Orange", "Apple", "Banana"))
Dict{String, Int64} with 3 entries:
  "Apple"  => 5
  "Orange" => 2
  "Banana" => 4

julia> additems!(Dict("Banana" => 3, "Apple" => 2, "Orange" => 1),
                 ["Banana", "Orange", "Blueberries", "Banana"])
Dict{String, Int64} with 4 entries:
  "Blueberries" => 1
  "Apple"       => 2
  "Orange"      => 2
  "Banana"      => 5
```

## 2. Actualiza la sección de «ideas» de recetas

La app tiene una sección de «ideas» que está llena de recetas terminadas de distintas cocinas.
El usuario puede seleccionar cualquiera de estas recetas y hacer que todos sus ingredientes se agreguen automáticamente a su carrito de compras.
El gerente del proyecto te ha pedido que crees una forma de editar estas recetas de «ideas», ya que el equipo de contenido cambia constantemente los ingredientes y las cantidades.

Crea la función `update_recipes!(<ideas>, <updates>)` que toma un diccionario de «ideas» y un diccionario de actualizaciones de recetas como argumentos.

## 3. Envía el carrito de compras del usuario a la tienda para surtir el pedido

La app necesita enviar el carrito de un usuario determinado a la tienda para surtir el pedido.
Sin embargo, quienes preparan los pedidos en la tienda necesitan saber dónde se puede encontrar cada artículo usando un código de pasillo único.
El «carrito de surtido» debe ordenarse según los códigos de pasillo de los artículos para que quienes preparan los pedidos sean más eficientes.

Crea la función `send_to_store(<cart>, <aislecodes>)` que toma un carrito de compras de usuario y un diccionario que tiene los números de pasillo de la tienda.
La función debe devolver un «carrito de surtido» combinado que tenga un par `aislecode => quantity` para cada artículo que pide el cliente.
Los artículos deben aparecer en el orden de sus códigos de pasillo.

```julia-repl
julia> cart = Dict("Orange" => 1, "Milk" => 2, "Banana" => 3, "Apple" => 2, "Chocolate" => 2);

julia> aislecodes = Dict("Orange" => 2.4, "Milk" => 3.3, "Banana" => 2.6, "Apple" => 2.2, "Chocolate" => 5.7);

julia> send_to_store(cart, aislecodes)
5-element Vector{Pair{Float64, Int64}}:
 2.2 => 2
 2.4 => 1
 2.6 => 3
 3.3 => 2
 5.7 => 2
```

## 4. Actualiza el inventario de la tienda para reflejar lo que ha pedido un usuario

La app no puede simplemente hacer pedidos de clientes indefinidamente.
Tarde o temprano, la tienda se va a quedar sin varios productos.
Así que el MVP de tu app necesita actualizar el inventario de la tienda cada vez que un usuario envía su pedido a la tienda.
De lo contrario, los clientes pedirán productos que en realidad no están disponibles.

Crea la función `update_store_inventory!(<inventory>, <cart>)` que toma un `cart` y un `inventory`.
La función debe reducir las cantidades del inventario de la tienda según el número pedido en el carrito y luego devolver un diccionario de los artículos que estén agotados (es decir, los que hayan llegado a `0`).

```julia-repl
julia> inventory = Dict("Banana" => 15, "Apple" => 12, "Orange" => 1, "Milk" => 4);

julia> cart = Dict("Orange" => 1, "Milk" => 2, "Banana" => 3, "Apple" => 2);

julia> update_store_inventory!(inventory, cart)
Dict{String, Int64} with 1 entry:
  "Orange" => 0

julia> inventory
Dict{String, Int64} with 4 entries:
  "Milk"   => 2
  "Apple"  => 10
  "Orange" => 0
  "Banana" => 12
```

## 5. Vuelve a pedir los artículos agotados

Además de actualizar el inventario, tu app puede ayudar a reabastecerlo.
Tu MVP debería poder preparar un mini pedido de los artículos que estén agotados después del pedido de un cliente.
Esto ayudará a que sea más sencillo generar un pedido grande.
Además, a veces hay artículos promocionales por tiempo limitado que no están en la lista de existencias.
Si se agotan antes de que termine el período promocional, habrán demostrado ser populares y se pueden agregar a la lista de existencias.

Crea la función `reorder!(<outofstock>, <stock>)` que toma `outofstock` y `stock`.
El diccionario `stock` contiene artículos estándar en existencia y sus cantidades de reorden.
El diccionario `outofstock` es el resultado de `update_store_inventory!`, es decir, un diccionario de artículos con cantidad cero.
Las cantidades de `outofstock` deben actualizarse para reflejar las de `stock` y devolverse.
Además, cualquier artículo en `outofstock` que no esté presente en `stock` debe agregarse a `stock` con una cantidad predeterminada de `100`.

```julia-repl
julia> inventory = Dict("Banana" => 15, "Apple" => 12, "Orange" => 1, "Milk" => 4, "Chocolate" => 2);

julia> cart = Dict("Orange" => 1, "Milk" => 2, "Banana" => 3, "Apple" => 2, "Chocolate" => 2);

julia> stock = Dict("Banana" => 150, "Apple" => 120, "Orange" => 120, "Milk" => 45);

julia> outofstock = update_store_inventory!(inventory, cart)
Dict{String, Int64} with 1 entry:
  "Orange"    => 0
  "Chocolate" => 0

julia> reorder!(outofstock, stock)
Dict{String, Int64} with 1 entry:
  "Orange"    => 120
  "Chocolate" => 100

julia> stock 
Dict{String, Int64} with 5 entries:
  "Milk"      => 45
  "Apple"     => 120
  "Chocolate" => 100
  "Orange"    => 120
  "Banana"    => 150
```
