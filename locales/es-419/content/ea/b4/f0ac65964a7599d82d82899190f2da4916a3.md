# Apéndice de instrucciones

## Cómo está estructurado este ejercicio en Python


Python ofrece una gran cantidad de funciones matemáticas en forma del [módulo math][math-module] y de funciones integradas como el operador de exponenciación `**`, [`pow()`][pow] y [`sum()`][sum].
Sin embargo, nos gustaría que consideres el reto de resolver este ejercicio sin esas funciones integradas ni módulos.

Aunque existe una fórmula matemática que calcula la raíz cuadrada de _cualquier_ número, nosotros hemos tomado el camino de tener solamente [números naturales][nautral-number] (enteros positivos) como soluciones.  
Es posible calcular la raíz cuadrada de cualquier número natural usando solamente números naturales en el cálculo.
