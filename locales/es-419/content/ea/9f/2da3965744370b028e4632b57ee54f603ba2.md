# Introducción

## Constantes

El modificador `const` se puede aplicar (y por lo general se debería aplicar) a cualquier campo cuyo valor se conozca en tiempo de compilación y que no cambie durante la vida del programa.

```csharp
private const int num = 1729;
public const string title = "Grand" + " Master";
```

El modificador `readonly` se puede aplicar (y por lo general se debería aplicar) a cualquier campo que no se pueda declarar como `const`, cuyo valor no cambie durante la vida del programa y que se establezca ya sea con un inicializador en línea o durante la instanciación (mediante el constructor o un método llamado por el constructor).

```csharp
private readonly int num;
private readonly System.Random rand = new System.Random();

public MyClass(int num)
{
    this.num = num;
}
```

## Copia defensiva

En situaciones delicadas en cuanto a seguridad (o incluso simplemente en una base de código grande donde los desarrolladores tienen prioridades y objetivos distintos), deberías evitar que se pueda eludir la API pública de una clase aceptando y almacenando parámetros mutables de un método, o exponiendo un miembro mutable de una clase mediante un valor de retorno o como parámetro `out`.

## Colecciones de solo lectura

Aunque el modificador `readonly` impide que el valor o la referencia de un campo se sobrescriba, no ofrece ninguna protección para los miembros de un tipo de referencia.

```csharp
readonly List<int> ints = new List<int>();

void Foo()
{
    ints.Add(1);    // ok
    ints = new List<int>(); // fails to compile
}
```

Para garantizar que todos los miembros de un tipo de referencia estén protegidos, los campos se pueden marcar como `readonly` y se pueden definir propiedades automáticas sin un descriptor de acceso `set`.

La Biblioteca de Clases Base (BCL) ofrece algunas versiones de solo lectura de las colecciones cuando se necesita impedir que se actualicen los miembros de una colección. Estas vienen en forma de envoltorios:

- `ReadOnlyDictionary<T>` expone un `Dictionary<T>` como de solo lectura.
- `ReadOnlyCollection<T>` expone un `List<T>` como de solo lectura.
