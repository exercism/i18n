# Pistas

## General

- El [tutorial sobre cadenas][python-str-doc] de la documentación de Python ofrece una descripción general del tipo `str` de Python.
- Los métodos de cadena [`str.join()`][str-join] y [`str.split()`][str-split] son muy útiles cuando procesas cadenas.
- La documentación de Python sobre [tipos de secuencia][common sequence operations] incluye un resumen de las operaciones comunes a todas las secuencias, como `strings`, `lists`, `tuples` y `ranges`.

En la tarea hay cuatro actividades, cada una con un conjunto de textos o palabras con las que trabajar.

## 1. Agrega un prefijo a una palabra

- Las cadenas cortas se pueden concatenar con el operador `+`.

## 2. Agrega prefijos a grupos de palabras

- Aunque no lo creas, [`str.join()`][str-join] es todo lo que necesitas aquí. **No se necesita un bucle**.
- Las pruebas le pasarán una `list` a tu función. No habrá necesidad de modificar esta `list` si logras encontrar una buena cadena delimitadora.
- Recuerda que las cadenas delimitadoras van entre los elementos y los «pegan» para formar una sola cadena. Los delimitadores se insertan _sin_ espacio, aunque puedes incluir caracteres de espacio dentro de ellos.
- Al igual que [`str.split()`][str-split], `str.join()` puede procesar una cadena de longitud arbitraria, formada por cualquier punto de código unicode. _A diferencia de_ `str.split()`, también puede procesar iterables de longitud arbitraria como `list`, `tuple` y `set`.

## 3. Elimina un sufijo de una palabra

- Las cadenas se pueden indexar o rebanar desde la izquierda (empezando en 0) o desde la derecha (empezando en -1).
- Si quieres el último punto de código de una cadena de longitud arbitraria, puedes usar `[-1]`.
- Las últimas tres letras de una cadena se pueden «rebanar» con un índice negativo. Por ejemplo: `beautiful'[:-3] == 'beauti`

## 4. Extrae y transforma una palabra

- Usar [`str.split()`][str-split] devuelve una `list` de cadenas divididas por espacios en blanco.
- Las `lists` son secuencias y se pueden indexar.
- [`str.split()`][str-split] se puede indexar directamente: `'Exercism rocks!'.split()[0] == 'Exercism'`
- ¡Ten cuidado con la puntuación! Los puntos se pueden eliminar con una rebanada: `'dark.'[:-1] == 'dark'`
