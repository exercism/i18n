# Introducción

Además de las declaraciones de funciones y las expresiones de funciones, JavaScript también tiene otra sintaxis muy concisa para definir una función.
Estas funciones se llaman _funciones flecha_.

En este concepto, nos centraremos en la sintaxis que se usa para escribir una función flecha.
Hay diferencias en la forma en que funciona una función flecha, como el enlace de _this_, que se verán en otros conceptos.

Aquí tienes una comparación entre una declaración de función y una función flecha.

```javascript
function addUpTwoNumbers(num1, num2) {
  return num1 + num2;
}

// function keyword removed and => added
const addUpTwoNumbers = (num1, num2) => {
  return num1 + num2;
};
```

Arriba puedes ver que la sintaxis de la función flecha:

1. elimina la palabra clave `function`
2. declara el identificador `addUpTwoNumbers` como un `const`
3. agrega una flecha gruesa `=>`

Si el cuerpo de la función contiene solo una sentencia de retorno, como en el ejemplo de arriba, se pueden omitir las llaves `{}` y la palabra clave `return`.

<!-- prettier-ignore-start -->
```javascript
const addUpTwoNumbers = (num1, num2) => { return num1 + num2 };

// can be shortened to
const addUpTwoNumbers = (num1, num2) => num1 + num2;
// braces {} and return removed
```
<!-- prettier-ignore-end -->

En el caso especial de devolver solamente un objeto desde una función flecha, se necesitan paréntesis alrededor del objeto para poder omitir la sentencia de retorno.

```javascript
// explicit return of object
const addUpTwoNumbers = (num1, num2) => {
  return {
    num1,
    num2,
  };
};

// implicit return of object
const addUpTwoNumbers = (num1, num2) => ({ num1, num2 });
```

El uso de paréntesis alrededor de los parámetros depende del número de parámetros.

<!-- prettier-ignore-start -->
```javascript
// one parameter does not need parenthesis
const square = num => num * num;

// two or more parameters need to be wrapped in parenthesis
const addUpTwoNumbers = (num1, num2) => num1 + num2;
```
<!-- prettier-ignore-end -->
