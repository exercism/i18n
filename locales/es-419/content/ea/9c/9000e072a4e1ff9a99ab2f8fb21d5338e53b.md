# Introducción

En Python, [una enumeración](https://docs.python.org/3/library/enum.html) es un conjunto de nombres vinculados a valores `literal` o `constant` únicos. Las enumeraciones se definen heredando una clase `Enum`. Los tipos de enumeración integrados están disponibles en el módulo `enum` y la clase `Enum` se puede importar usando `from enum import Enum`.

```python
class Color(Enum):
    RED = 1
    GREEN = 2
```

Ten en cuenta que los valores de los miembros de la enumeración pueden ser de cualquier tipo de dato, como str, tuple, float, etc.

```python
class Color(Enum):
    RED = 'red'
    GREEN = 'green'
```

Cuando se asigna el mismo valor a dos miembros de una enumeración, el último miembro asignado será un alias del primero. No se permite usar el mismo nombre para dos miembros de una enumeración.

```python
class Color(Enum):
    RED = 1
    GREEN = 2
    ALIAS_OF_RED = 1

Color.ALIAS_OF_RED
#=> <Color.RED: 1>

Color.ALIAS_OF_RED.value
#=> 1
```

Se puede iterar por los miembros de la enumeración con la sintaxis estándar `for member in`:

```python
for member in Color:
    print((member.name, member.value))
#=> (RED, 1)
#=> (GREEN, 2)
```

Los miembros de la enumeración se pueden comparar usando [`is` (_operador de identidad_)](https://www.w3schools.com/python/ref_keyword_is.asp) o `is not`. Los operadores `==` o `!=` (_operadores de igualdad_) funcionan de manera similar.

```python
a = Color.RED

a is Color.RED
#=> True

a == Color.RED
#=> True
```

Para acceder a un miembro de la enumeración para un valor dado, se puede usar `EnumName(value)`:

```python
g = Color(2)

g is Color.GREEN
#=> True

g
#=> <Color.GREEN: 2>
```
