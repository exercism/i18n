# Boutique de moda

## Historia

Estás a cargo de una boutique de moda en línea. Se acerca el Black Friday, así que necesitas revisar tu inventario para asegurarte de que todo esté listo.

Un artículo del inventario se representa con un mapa/diccionario, y el inventario completo es un array de esos mapas/diccionarios.

```elixir
%{
  name: "White Shirt",
  price: 40,
  quantity_by_size: %{s: 3, m: 7, l: 8, xl: 4}
}
```

## Tareas

- Ordenar los artículos por precio
- Encontrar todos los artículos a los que les falte el precio
- Incrementar la cantidad del artículo
- Calcular la cantidad total del artículo
