# Pistas

## 1. Verifica el nivel de humedad de la habitación

- Lógica sencilla de if...else.
- Un operador ternario es suficiente.
- Esta tarea usa una función `error()`, no `throw()`.
- También se necesita la macro `@info`.
- Lee la sección de registro de la introducción para ver cómo generar mensajes de registro.

## 2. Verifica el sobrecalentamiento

- Hay dos condiciones de falla que debes comprobar.
- Cada una necesita un `throw()` si falla.
- Se necesita la macro `@info` para el caso exitoso.

## 3. Define un error personalizado

- Consulta la introducción para ver un ejemplo de cómo definir un error personalizado.
- Los campos y los mensajes de impresión personalizados son posibles, pero no son obligatorios.

## 4. Monitorea la máquina

- Puedes usar las funciones `humiditycheck` y `temperaturecheck`, pero no es estrictamente necesario.
- Si las usas, deberías poder comprobar de forma independiente si ambas funciones lanzan errores y agregar los registros correspondientes.
- Una variable definida fuera de un bloque `try...catch` se puede actualizar desde dentro del bloque si es necesario.
- Recordatorio: si una de las comprobaciones falla o fallan las dos, solo necesitas lanzar un `MachineError` después de haber agregado los registros.
