# Introducción

En Go, las funciones son valores de primera clase.
Esto significa que con las funciones puedes hacer las mismas cosas que haces con cualquier otro valor: asignarlas a variables, pasarlas como argumentos a otras funciones o incluso devolver funciones desde otras funciones.

A continuación creamos dos funciones, `engGreeting` y `espGreeting`, y las asignamos a la variable `greeting`:

```go
import "fmt"

func engGreeting(name string) string {
	return fmt.Sprintf("Hello %s, nice to meet you!", name)
}

func espGreeting(name string) string {
	return fmt.Sprintf("¡Hola %s, mucho gusto!", name)
}

greeting := engGreeting			// greeting is a variable of type func(string) string
fmt.Println(greeting("Alice"))	// Hello Alice, nice to meet you!

greeting = espGreeting
fmt.Println(greeting("Alice")) 	// ¡Hola Alice, mucho gusto!
```

Los valores de función te dan la oportunidad de parametrizar funciones no solo con datos, sino también con comportamiento.
En el siguiente ejemplo, le pasamos comportamiento a la función `dialog` mediante el parámetro `greetingFunc`:

```go
func dialog(name string, greetingFunc func(string) string) {
	fmt.Println(greetingFunc(name))
	fmt.Println("I'm a dialog bot.")
}

func espGreeting(name string) string {
	return fmt.Sprintf("¡Hola %s, mucho gusto!", name)
}

greeting := espGreeting
dialog("Alice", greeting)
// Output:
// ¡Hola Alice, mucho gusto!
// I'm a dialog bot.
```

El valor de una variable de tipo función que no está inicializada es `nil`.
Por eso, llamar a un valor de función `nil` provoca un panic.

```go
var dutchGreeting func(string) string
dutchGreeting("Alice") // panic: call of nil function
```

Los valores de función se pueden comparar con `nil`.
Esto puede ser útil para evitar panics innecesarios en el programa.

```go
var dutchGreeting func(string) string
if dutchGreeting != nil {
	dutchGreeting("Alice") // safe to call dutchGreeting
}
```

## Tipos de función

Usar valores de función es posible gracias a los tipos de función de Go.
Un tipo de función denota el conjunto de todas las funciones con la misma secuencia de tipos de parámetro y la misma secuencia de tipos de resultado.
Se pueden declarar tipos definidos por el usuario sobre tipos de función.
Por ejemplo, la función `dialog` de los ejemplos anteriores se puede actualizar así:

```go
type greetingFunc func(string) string

func dialog(name string, f greetingFunc) {
	fmt.Println(f(name))
	fmt.Println("I'm a dialog bot.")
}
```

## Funciones anónimas

Otra herramienta poderosa que está disponible gracias al soporte de funciones de primera clase son las funciones anónimas.
Las funciones anónimas se definen en el punto donde se usan, sin un nombre después de la palabra clave `func`.
Estas funciones tienen acceso a las variables de la función que las contiene.

Por ejemplo:

```go
func fib() func() int {
	var n1, n2 int

	return func() int {
		if n1 == 0 && n2 == 0 {
			n1 = 1
		} else {
			n1, n2 = n2, n1 + n2
		}
		return n2
	}
}

next := fib()
for i := 0; i < N; i++ {
  fmt.Printf("F%d\t= %4d\n", i, next())
}
```

Una llamada a `fib` declara las variables `n1` y `n2` y devuelve una función anónima que, a su vez, cambia los valores de esas variables cada vez que se llama a la función.
La enésima llamada a la función anónima devuelve el enésimo número de la sucesión de Fibonacci empezando desde 0. La función anónima interna tiene acceso a las variables locales (`n1` y `n2`) de la función que la contiene, `fib`.
Esta es una gran forma de que los valores de función conserven su estado entre llamadas.
Decimos que la función anónima es un closure de las variables `n1` y `n2`.
Los [closures][closure] se usan mucho en programación y es posible que veas otros lenguajes que los admiten.
