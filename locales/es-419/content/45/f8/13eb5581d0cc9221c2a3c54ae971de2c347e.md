# Pruebas

## Configuración

Sigue las [instrucciones de configuración para JavaScript][docs-exercism-javascript] para instalar las dependencias necesarias.

## Requisitos

Instala las dependencias del ejercicio:

```shell
corepack pnpm install
```

Si `corepack` muestra un error diciendo que no está habilitado, puedes habilitarlo ejecutando:

```bash
corepack enable pnpm
```

## Cómo hacer que la suite de pruebas pase

Todos los ejercicios incluyen una suite de pruebas que te ayuda a validar tu solución antes de enviarla.
Puedes ejecutar estas pruebas abriendo una terminal en el directorio del ejercicio y ejecutando lo siguiente:

```bash
corepack pnpm test
```

En algunas suites de pruebas, todas las pruebas excepto la primera están omitidas.

Cuando logres que una prueba pase, puedes habilitar la siguiente cambiando `xtest` por `test`.

## Cómo escribir pruebas personalizadas

Si quieres escribir pruebas adicionales o personalizadas, crea un archivo nuevo `custom.spec.js` y envíalo junto con tu solución:

```shell
exercism submit numbers.js custom.spec.js
```
