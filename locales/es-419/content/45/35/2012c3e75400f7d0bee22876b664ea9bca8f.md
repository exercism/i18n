# Declaración de tipos

PHP es un lenguaje de _tipado dinámico_, lo que significa que una variable puede contener cualquier tipo de información.
PHP sí permite declaraciones de tipo fuerte _opcionales_ para las propiedades de una clase, los argumentos de una función y los valores de retorno de una función.
Las declaraciones de tipo fuerte en PHP proporcionan aserciones de tipo en tiempo de ejecución; sin embargo, PHP intentará forzar los tipos escalares para que coincidan con la declaración siempre que sea posible.
El comportamiento de coerción se puede desactivar usando la declaración `strict_types` al inicio del archivo.

```php
<?php
declare(strict_types=1);
```

Además, las funciones pueden devolver un tipo de retorno `void` para indicar que no se debe devolver ningún valor desde la función.

```php
<?php
declare(strict_types=1);

class Driver
{
    string $serial_number;

    function setSerialNumber(string $number): void
    {
        $this->serial_number = $number;
    }

    function getSerialNumber(): string
    {
        return $this->serial_number; 
    }
}

$driver = new Driver(); 
$driver->setSerialNumber(1234);
// => This will throw a TypeError with strict_types=1
```

## Uniones de tipos

Si un argumento de una función, un valor de retorno o una propiedad de una clase puede ser más de un tipo, se puede declarar una unión de tipos.

```php
<?php

class IdentityCard
{
    private int|float $id = 0;

    public function assign(int|float $id): void
    {
        $this->id = intval($id);
    }
}

$card = new IdentityCard();
$card->assign(5.0);
```

## Tipos mixtos

Cuando trabajamos con código, es posible que no podamos especificar un tipo.
A partir de PHP 8.0, se proporciona un tipo de escape llamado `mixed`.
Mixed es equivalente a una unión de tipos de `object|resource|array|string|float|int|bool|null`.
