# Instrucciones

En este ejercicio vas a procesar líneas de registro.

Cada línea de registro es un string con el siguiente formato: `"[<LEVEL>]: <MESSAGE>"`.

Existen tres niveles de registro diferentes:

- `INFO`
- `WARNING`
- `ERROR`

Tienes tres tareas, y cada una recibe una línea de registro y te pide hacer algo con ella.

## 1. Obtén el mensaje de una línea de registro

Implementa la función `message` para que devuelva el mensaje de una línea de registro:

```clojure
(message "[ERROR]: Invalid operation")
;;=> "Invalid operation"
```

Cualquier espacio en blanco al inicio o al final debe eliminarse:

```clojure
(message "[WARNING]:  Disk almost full\r\n")
;;=> "Disk almost full"
```

## 2. Obtén el nivel de registro de una línea de registro

Implementa la función `log-level` para que devuelva el nivel de registro de una línea de registro, en minúsculas:

```clojure
(log-level "[ERROR]: Invalid operation")
;;=> "error"
```

## 3. Reformatea una línea de registro

Implementa la función `reformat` que reformatea la línea de registro, colocando el mensaje primero y el nivel de registro después, entre paréntesis:

```clojure
(reformat "[INFO]: Operation completed")
;;=> "Operation completed (info)"
```
