# Instrucciones

Dados dos arrays, determina si el primer array está contenido dentro del segundo, si el segundo array está contenido dentro del primero, si ambos arrays están contenidos uno dentro del otro o si nada de esto es cierto.

En concreto, un array A es un subarray del array B si al eliminar 0 o más elementos del principio de B y 0 o más elementos del final de B obtienes un array completamente igual a A.

Ejemplos:

 * A = [1, 2, 3], B = [1, 2, 3, 4, 5], A es un subarray de B
 * A = [3, 4, 5], B = [1, 2, 3, 4, 5], A es un subarray de B
 * A = [3, 4], B = [1, 2, 3, 4, 5], A es un subarray de B
 * A = [1, 2, 3], B = [1, 2, 3], A es igual a B
 * A = [1, 2, 3, 4, 5], B = [2, 3, 4], A es un superarray de B
 * A = [1, 2, 4], B = [1, 2, 3, 4, 5], A no es un superarray de B, ni un subarray de B, ni es igual a B
