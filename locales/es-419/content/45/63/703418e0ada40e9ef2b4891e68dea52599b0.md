# Acerca de

En Elixir, para elegir un elemento aleatorio de una estructura de datos enumerable (por ejemplo, una lista, un rango), usamos [`Enum.random/1`][enum-random]. Esta función elige un solo elemento, y cada elemento tiene la misma probabilidad de ser elegido. Elegir un valor aleatorio de un rango se ejecuta en tiempo constante, sin recorrer todo el rango.

## Enteros y letras aleatorios

- Elegir un entero aleatorio
  ```elixir
  Enum.random(1..10)
  # => 7
  ```
- Elegir una letra aleatoria como string
  ```elixir
  <<Enum.random(?A..?Z)>>
  # => "K"
  ```
- Elegir una letra aleatoria como charlist
  ```elixir
  [Enum.random(?A..?Z)]
  # => ~c"J"
  ```

Para elegir más de un elemento de una estructura de datos enumerable, usa [`Enum.take_random/2`][enum-take-random]. Para ordenar una estructura de datos enumerable en un orden aleatorio, usa [`Enum.shuffle/1`][enum-shuffle].

## Números de punto flotante aleatorios

Elixir no tiene sus propias funciones para elegir un número de punto flotante aleatorio. Para hacer eso, tenemos que usar el módulo [`rand`][erl-rand] de Erlang, que además resulta ser lo que `Enum.random` usa por debajo.

- Elegir un número de punto flotante aleatorio (mayor o igual que 0.0 y menor que 1.0):

  ```elixir
  :rand.uniform()
  # => 0.275329955448815
  ```

- Elegir un número de punto flotante aleatorio (mayor o igual que `a` y menor que `b`):
  ```elixir
  a = 13
  b = 20
  :rand.uniform() * (b - a) + a
  # => 18.96815556890448
  ```

## Distribución normal

Todas las funciones mencionadas antes eligen un valor aleatorio, y cada valor posible tiene la misma probabilidad de ser elegido. A eso se le llama una _distribución uniforme_. El módulo `rand` también ofrece las funciones [`normal/0`][erl-rand-normal-0] y [`normal/2`][erl-rand-normal-2], que eligen un número de punto flotante aleatorio con una [distribución normal][normal-distribution].

## Semilla

Es importante entender que los valores «aleatorios» son generados por un [generador de números _pseudoaleatorios_][prng]. Un PRNG es un algoritmo que, dado un valor inicial llamado _semilla_, genera una secuencia de números que parece aleatoria, pero que no lo es en absoluto.

Este hecho puede ser útil para hacer debug. Puedes forzar al generador de números pseudoaleatorios de Erlang (y por lo tanto al de Elixir) a producir la misma secuencia de valores si reinicias su semilla con [`:rand.seed/2`][rand-seed-2]. El primer argumento es un algoritmo PRNG específico, y el segundo es una tupla de tres enteros: la semilla.

```elixir
:rand.seed(:exsss, {1, 2, 3})
Enum.take_random(100..999, 3)
# => [680, 127, 622]

:rand.seed(:exsss, {1, 2, 3})
Enum.take_random(100..999, 3)
# => [680, 127, 622]
```

## Criptografía

Los valores aleatorios que devuelven `Enum.random` y el módulo `rand` de Erlang no son [criptográficamente seguros][cryptographically-secure-rng]. No los uses para generar claves criptográficas, contraseñas ni nonces. Para este caso de uso, existe [`:crypto.strong_rand_bytes/1`][erl-crypto-strong-rand-bytes] de Erlang.
