# Anexo de instrucciones

## Instrucciones específicas del track

Implementa una función llamada `slices` que devuelva un array de strings como se describe arriba.
Tu función debe lanzar un `IllegalArgumentError` con un mensaje de error apropiado como el siguiente.
- Si el string dado está vacío, da error con el mensaje `series cannot be empty`.
- Si la longitud del slice es negativa, da error con el mensaje `slice length cannot be negative`.
- Si la longitud del slice es cero, da error con el mensaje `slice length cannot be zero`.
- Si la longitud del slice supera la longitud del string, da error con el mensaje `slice length can not be greater than series length`.
