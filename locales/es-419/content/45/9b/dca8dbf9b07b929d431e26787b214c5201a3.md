# Tests

El track de Factor usa **Factor 0.101**. Cada ejercicio viene con un vocabulario `exercism-tools` incluido que define las palabras de análisis `STOP-HERE` y `TASK:`, además de un ejecutor de tests. Desde el directorio del ejercicio, ejecuta:

```
factor -roots=. -run=exercism-tools <exercise>
```

Por ejemplo, para el ejercicio `hello-world`:

```
factor -roots=. -run=exercism-tools hello-world
```

El ejecutor termina con estado 0 cuando pasan todos los tests, y con un estado distinto de cero y salida de diagnóstico cuando falla algún test.

## Tests omitidos

Resolver un ejercicio significa hacer que pasen todos sus tests.
De forma predeterminada, solo se ejecuta un test (el primero) cuando ejecutas los tests.
Esto es intencional, ya que te permite concentrarte solo en hacer que pase ese único test.

El mecanismo es la línea `STOP-HERE` del archivo de test: en el momento del análisis, le indica a Factor que ignore todo lo que está debajo, así que el ejecutor solo ve los tests que están arriba. Cuando pase tu primer test, puedes habilitar más tests de dos maneras:

- **Borra la línea `STOP-HERE`** para habilitar de una vez todos los tests restantes.
- **Mueve la línea `STOP-HERE` más abajo** para habilitar los tests de a uno, o de una tarea a la vez. Los ejercicios de conceptos agrupan los tests bajo marcadores `TASK:`. Mover `STOP-HERE` justo antes del siguiente `TASK:` es un paso natural.

¡Cuando hayas habilitado todos los tests y tu implementación los haga pasar todos, habrás resuelto el ejercicio!
