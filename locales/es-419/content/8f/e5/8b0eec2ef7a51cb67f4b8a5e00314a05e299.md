# Incorporación de empleados en la base de datos

## Enunciado del problema

ABC Corp planea mantener en una base de datos toda la información sobre los pagos de caja chica a los empleados. Estás ayudando al departamento de finanzas de ABC Corp a implementarlo. Como ABC Corp está expandiendo sus operaciones, agregar nuevos empleados al sistema es un requisito común debido a las nuevas contrataciones.

Tu tarea es agregar los datos del nuevo empleado proporcionados a la tabla `Employee` de la base de datos y devolver el valor de la columna `employee_id` generada automáticamente, sin hacer otra consulta a la base de datos para encontrarlo. Si ocurre un error durante la ejecución, se debe devolver `-1`.

## Detalles de la base de datos

Usa la base de datos H2 proporcionada para este problema.

> El archivo de base de datos de ejemplo es `gofigure.mv.db`, y el nombre de la base de datos es `gofigure`. Se proporciona dentro de la carpeta `db`.

Las siguientes tablas ya están en la base de datos H2 de ejemplo con algunos datos de muestra. Los nombres de las columnas y los tipos de datos están a continuación.

**Nombre de la tabla** : `Employee`

| **Columnas:**      | tipo |
| -----------       | ----------- |
| `employee_id`     | entero, clave primaria autoincrementada       |
| `name`            | string        |
| `city`            | string        |
| `department`      | string        |
| `age`             | entero        |

**Nombre de la tabla**: `Payment`

| **Columnas:**      | tipo |
| -----------       | ----------- |
| `payment_id`      | entero, clave primaria autoincrementada       |
| `date`            | fecha        |
| `amount`          | decimal        |
| `employee_id`     | entero        |
| `reason`          | string        |

* El archivo de base de datos es `gofigure.mv.db`. Usa la URL de JDBC como `jdbc:h2:file:/path/to/db/file`
* Nombre de usuario: `root`
* Contraseña: `root`

## Restricciones

* Usa el archivo de base de datos H2 proporcionado en la carpeta `db` para validar las consultas y el ejemplo de Ballerina
* Usa el enfoque de parámetros de dependencia de Maven para agregar el controlador de la base de datos H2 como dependencia de plataforma en tu Ballerina.toml
* No hagas otra consulta a la base de datos para encontrar el id generado automáticamente


## Entorno de pruebas

* Puedes ejecutar las pruebas con `bal test`, y ejecutará las pruebas contra la base de datos de ejemplo proporcionada.
