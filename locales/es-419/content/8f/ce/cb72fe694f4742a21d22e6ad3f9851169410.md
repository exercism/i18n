# Instrucciones

En este ejercicio, se te ha encargado escribir el software para un dispositivo de cifrado que funciona realizando transformaciones sobre los datos.
Necesitas una forma de crear funciones complicadas de manera flexible, combinando funciones más simples.

Para cada tarea, devuelve un bloque que se pueda invocar desde el ámbito que hace la llamada.

## 1. Crea un sumador

Implementa `secret-add`.
Debe devolver una función que reciba un argumento y le sume el argumento que se le pasó a `secret-add`.

## 2. Crea un restador

Implementa `secret-subtract`.
Debe devolver una función que reciba un argumento y le reste a ese argumento el secreto que se le pasó a `secret-subtract`.

## 3. Crea un multiplicador

Implementa `secret-multiply`.
Debe devolver una función que reciba un argumento y lo multiplique por el secreto que se le pasó a `secret-multiply`.

## 4. Crea un divisor

Implementa `secret-divide`.
Debe devolver una función que reciba un argumento y lo divida entre el secreto que se le pasó a `secret-divide`.

## 5. Crea un combinador de funciones

Implementa `secret-combine`.
Debe devolver una función que reciba un argumento y le aplique, en orden, las dos funciones que se le pasaron a `secret-combine`.
