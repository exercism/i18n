# Introducción

Usar `try..rescue` es una construcción poderosa para capturar errores cuando ocurren. Rescatar errores permite que las funciones devuelvan valores definidos cuando es necesario. La construcción `try..rescue` también nos ofrece dos características adicionales que podemos aprovechar:

- el bloque `else`
  - Cuando el bloque `try` tiene éxito, el resultado se hace coincidir con este bloque.
- el bloque `after`
  - Ya sea que el bloque `try` tenga éxito o lance un error, el código del bloque `after` siempre se ejecuta, siempre que el programa se esté ejecutando en ese punto.
  - El resultado del bloque `after` no se devuelve al ámbito de quien llama.

```elixir
try do
  :a
rescue
  _ -> :error
else
  :a -> :success
after
  :some_action
end

# => :success
```
