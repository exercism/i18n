## Instrucciones

Tu tarea es generar los laberintos perfectos para Mickey y Minerva, esos que tienen una sola solución y ninguna sección aislada.
Esto es lo que necesitas saber:

- El laberinto tiene forma rectangular con una abertura al inicio y al final.
- El laberinto tiene salas y pasillos, que se cruzan en ángulos rectos.
- El programa debe aceptar dos parámetros: filas y columnas. El laberinto debe tener entre 5 y 100 celdas de tamaño.
- Un laberinto que tiene `x` columnas de ancho y `y` filas de alto debe tener `2x + 1` caracteres de ancho y `2y + 1` caracteres de alto.
- Si no se proporciona una semilla, genera un laberinto aleatorio. Si se proporciona la misma semilla varias veces, el laberinto resultante debe ser el mismo cada vez.
- Usa caracteres de [dibujo de cajas][Box-drawing] para dibujar las paredes, y un símbolo de flecha (⇨) para la entrada a la izquierda y la salida a la derecha.

¡Es hora de crear algunos laberintos perfectos para estos ratones aventureros!

### Ejemplos

1. El laberinto cuadrado pequeño de 5x5 celdas (o 11x11 caracteres)
```text
	┌───────┬─┐
	│       │ │
	│ ┌─┬── │ │
	│ │ │   │ ⇨
	│ │ │ ──┤ │
	⇨ │ │   │ │
	┌─┤ └── │ │
	│ │     │ │
	│ │ ────┘ │
	│         │
	└─────────┘
```
2. El laberinto rectangular de 6x18 celdas
```text
	┌───────────┬─────────┬───────────┬─┐
	│           │         │           │ │
	│ ┌───────┐ │ ┌─┐ ──┐ └───┐ ┌───┐ │ │
	│ │       │ │ │ │   │     │ │   │   ⇨
	│ └─┐ ┌─┐ │ │ │ ├── ├───┐ │ │ ──┼── │
	│   │ │ │   │   │   │   │ │ │   │   │
	└── │ │ ├───┴───┤ ┌─┘ ┌─┘ │ ├── │ ──┤
	⇨   │   │       │ │   │   │ │   │   │
	┌─┬─┴─┐ └─┐ ┌─┐ │ └─┐ │ ┌─┘ │ ──┴─┐ │
	│ │   │   │ │ │ │   │   │   │     │ │
	│ │ │ └── │ │ │ └── │ ──┘ ┌─┘ ──┐ │ │
	│   │       │       │     │     │   │
	└───┴───────┴───────┴─────┴─────┴───┘
```
