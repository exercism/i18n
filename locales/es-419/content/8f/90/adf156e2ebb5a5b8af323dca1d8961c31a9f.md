# Anexo de instrucciones

## Algunas notas adicionales para la implementación en C++

Este ejercicio usa el [contenedor vector][vector].
Puede que te resulte útil usar el encabezado [algorithm][algorithm] para resolver este ejercicio.

Algunas de las funciones de [algorithm][algorithm] necesitan [`iterators`][iterator] como argumentos.
Se pueden ver como marcadores de dónde empieza y termina un contenedor.
Si quieres abarcar el contenedor completo, empiezas con `my_container.begin()` y terminas con `my_container.end()`.
Si solo quieres los elementos 2, 3 y 4 de un vector, podrías usar `my_vector.begin() + 2` y `my_vector.begin() + 4`.

Las últimas pruebas comprueban la [inmutabilidad][immutability].
Ninguna de las funciones que tienes que escribir debe cambiar las puntuaciones del juego.

Si quieres algo de práctica extra, puedes implementar una función que añada nuevas puntuaciones al juego.
