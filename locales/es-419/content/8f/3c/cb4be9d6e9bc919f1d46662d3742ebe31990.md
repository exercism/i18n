# Instrucciones

Es el Día de San Valentín. Tu pareja tiene algunas ideas de actividades y te pide que califiques cada una: `yes`, `no` o `maybe`.

Las actividades se representan como arrays de 2 elementos `{ tag value }`, donde `tag` es uno de `board-game`, `chill`, `movie`, `restaurant` o `walk`.

| actividad                        | forma                       |
| -------------------------------- | --------------------------- |
| Jugar un juego de mesa           | `{ board-game f }`          |
| Relajarse                        | `{ chill f }`               |
| Ver una película de `genre`      | `{ movie genre }`           |
| Comer en un lugar de `cuisine`   | `{ restaurant cuisine }`    |
| Caminar `km` kilómetros          | `{ walk km }`               |

El género es uno de `crime`, `horror`, `romance`, `thriller`. La cocina es `korean` o `turkish`.

## 1. Califica la cocina

Define `rate-restaurant` para tomar una cocina de la pila y devolver tu aprobación:

- `korean` → `yes`
- `turkish` → `maybe`

```factor
korean rate-restaurant .   ! => yes
turkish rate-restaurant .  ! => maybe
```

## 2. Califica el género de la película

Define `rate-movie` para tomar un género y devolver:

- `romance` → `yes`
- cualquier otra cosa → `no`

```factor
romance rate-movie .   ! => yes
horror rate-movie .    ! => no
```

## 3. Califica la caminata

Define `rate-walk` para tomar una cantidad de kilómetros y devolver:

- más de `11` → `yes`
- más de `6`, hasta `11` → `maybe`
- en cualquier otro caso → `no`

```factor
12 rate-walk .   ! => yes
8 rate-walk .    ! => maybe
3 rate-walk .    ! => no
```

## 4. Califica la actividad

Define `rate-activity` para tomar una actividad `{ tag value }` de la pila y devolver tu aprobación. Reutiliza las funciones auxiliares de arriba:

- `board-game`, `chill` → siempre `no`
- `movie` → delega en `rate-movie`
- `restaurant` → delega en `rate-restaurant`
- `walk` → delega en `rate-walk`

```factor
{ restaurant turkish } rate-activity .   ! => maybe
{ movie horror } rate-activity .         ! => no
{ walk 12 } rate-activity .              ! => yes
{ board-game f } rate-activity .         ! => no
```

## 5. Cuenta las aprobaciones

Define `approval-counts` para tomar una lista de actividades y devolver un array de 3 elementos `{ yes-count maybe-count no-count }` con cuántas se calificaron de cada forma.

```factor
{ { restaurant korean } { restaurant turkish } { walk 3 } { movie romance } }
approval-counts .
! => { 2 1 1 }
```
