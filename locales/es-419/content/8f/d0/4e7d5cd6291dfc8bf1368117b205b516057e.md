# Operador de resolución de ámbito

El operador de resolución de ámbito (`::`) nos permite hacer referencia a una clase para acceder a sus constantes de nombre, propiedades estáticas o métodos estáticos.

```php
class MyClass
{
  public const MY_VALUE = 1;
}

// MyClass::class => "MyClass"
// MyClass::MY_VALUE => 1
```

## Usar `self` y `static` con el operador de resolución de ámbito

Puede que un objeto necesite hacer referencia a su propio ámbito. Para facilitar esto, la palabra clave `self` permite que una clase haga referencia a su propio ámbito. Usar la palabra clave `self` desacopla la clase de su propio nombre, lo que hace más fácil mantener el código con el tiempo.

```php
class MyClass
{
  public const MY_VALUE = 1;

  public function getMyValue(): int
  {
    return self::MY_VALUE;
  }
}

// (new MyClass)->getMyValue() => 1
```

Usa la palabra clave `static` con el operador de resolución de ámbito para hacer un «enlace tardío» de la referencia a la clase descendiente actual.

```php
// Update MyClass:
class MyClass
{
  public const MY_VALUE = 1;

  public function getMyValue(): int
  {
    return static::MY_VALUE;
  }
}
```

## Usar `parent` con el operador de resolución de ámbito

La palabra clave `parent` se usa para hacer referencia a una constante, propiedad o método de la clase padre. Comúnmente se usa para llamar al constructor de la clase padre cuando se está instanciando un objeto:

```php
class ChildClass extends ParentClass
{
  public function __construct(): void
  {
    parent::__construct();
  }
}
```

## Advertencias

### Visibilidad de constantes, propiedades y métodos

El operador de resolución de ámbito sigue las reglas que establecen los modificadores de visibilidad `public`, `private` y `protected`.
