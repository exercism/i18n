# Permisos de las cuentas del sitio web

## Historia

En este ejercicio vas a comprobar los permisos de las cuentas de usuario en un foro de internet. El foro admite tres permisos distintos:

- Leer
- Escribir
- Eliminar

Hay tres tipos de cuentas, cada uno con permisos predeterminados distintos:

- Invitados: pueden leer las publicaciones.
- Usuarios: pueden leer y escribir publicaciones.
- Moderadores: pueden leer, escribir y eliminar publicaciones.

A veces se modifican permisos individuales; por ejemplo, darle a una cuenta de invitado el permiso de escribir publicaciones también.

## Tareas

Estas son tareas de ejemplo que encajan con el ejercicio de permisos del sitio web:

- Obtener los permisos predeterminados de un tipo de cuenta
- Otorgar un permiso
- Revocar un permiso
- Comprobar si se tiene un permiso
