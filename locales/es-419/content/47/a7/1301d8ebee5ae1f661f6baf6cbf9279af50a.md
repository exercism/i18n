# Pistas

## 1. Define el rango de filas y columnas

- Existe un [operador][swift-range-docs] para crear un rango, que se puede usar tanto con strings como con enteros.

## 2. Verifica si la casilla es válida

- Existe un [método][contains-docs] para verificar si un valor está dentro de un rango.

## 3. Obtén la fila

- Cada fila debe tener una longitud de 8.
- Para cada fila, empezando desde 1, tendrás que desplazar el inicio y el final en 8.
- Puedes usar un rango para obtener un subarray del array.
