# Uso de un encabezado de función

[comment]: # (Este error se muestra cuando la solución usa un encabezado de función)

Un encabezado de función (una definición de función sin cuerpo) solo es necesario para las funciones con argumentos predeterminados que tienen varias cláusulas.

```elixir
# necessary function header
def hello(what \\ "World")
def hello("Alice"), do: "Hello, darling!"
def hello(name), do: "Hello, #{name}!"
```

En las funciones con argumentos predeterminados que solo tienen una cláusula, los argumentos predeterminados se pueden especificar directamente en esa cláusula.

```elixir
# preferred
def bye(name \\ "World"), do: "See you, #{name}!"

# not preferred - unnecessary function header
def bye(what \\ "World")
def bye(name), do: "See you, #{name}!"
```

La función `two_fer/1` solo necesita una cláusula y, por lo tanto, no necesita un encabezado de función.
