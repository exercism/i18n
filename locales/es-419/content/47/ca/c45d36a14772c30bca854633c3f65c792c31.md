## General

- Las instrucciones [cmp][cmp] y [test][test] son útiles para establecer banderas según ciertas condiciones evaluadas.
- Las instrucciones [jmp][jmp] y [jcc][jcc] son útiles para saltar según las banderas que se establecieron antes.
- Cuando llamas a una función, la función llamada puede modificar un registro que estás usando.

## 1. Calcular el valor de una carta

- Las instrucciones [cmp][cmp] y [test][test] son útiles para establecer banderas según ciertas condiciones evaluadas.
- Las instrucciones [jmp][jmp] y [jcc][jcc] son útiles para saltar según las banderas que se establecieron antes.
- Cuando llamas a una función, la función llamada puede modificar un registro que estás usando.
- Puedes usar `cmp` para comparar dos cartas y establecer las banderas adecuadas.
- Puedes usar `je` o `jz` para saltar si un número es igual al otro.
- Puedes usar `jl` para saltar si un número es menor que el otro.

- Cuando llamas a una función, la función llamada puede modificar un registro que estás usando.
- Una vez que hayas definido la función `value_of_card`, puedes llamarla desde otras funciones.

- Puedes usar `jg` para saltar si un número es mayor que el otro, y `jl` para saltar si es menor.
- Si ambas cartas tienen el mismo valor, la segunda se devuelve en `rdx`. De lo contrario, `rdx` debe establecerse en 0.
