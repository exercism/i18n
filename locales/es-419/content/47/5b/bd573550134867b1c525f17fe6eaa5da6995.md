# Anexo de las instrucciones

## Pistas

Necesitas implementar la función

```haskell
value :: (Color, Color) -> Int
```

que solo acepta dos colores y produce el componente numérico del valor de la resistencia.

**Extra: pruebas de propiedades:**

Este ejercicio es una buena oportunidad para escribir algunas [pruebas de propiedades](https://en.wikipedia.org/wiki/Property_testing). Si nunca has escrito ninguna, aquí tienes algunos recursos:

1. [School of Haskell](https://www.schoolofhaskell.com/user/pbv/an-introduction-to-quickcheck-testing).
2. [Real world Haskell](http://book.realworldhaskell.org/read/testing-and-quality-assurance.html)

Hemos incluido en el archivo de pruebas un ejemplo de prueba de propiedades con QuickCheck.

Ejemplos de propiedades que se pueden probar:

- `value (x, y) >= 10` para todos los `(x, y)` donde `x` no sea `Black`

- Llamar a `show` con `value (x, y)` produce el `reverse` invertido de llamar a `show` con `value (y, x)`.

- Todos los colores tienen nombres únicos. (Para dos colores cualesquiera, si los colores son distintos, sus nombres también lo son.)
