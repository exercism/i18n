# Introducción

## Genéricos

### Introducción

Los genéricos son una característica del lenguaje que permite reutilizar código.
Por ejemplo, no debería importar de qué tipo sean los elementos que contiene una lista para calcular su longitud.
Por eso la función `length` usa un parámetro de tipo genérico `a` en su firma de tipo.

```elm
length : List a -> Int
```

### Parámetros en los tipos

Cuando un tipo es genérico sobre otro tipo, usamos un nombre en minúscula para ese otro tipo y lo llamamos parámetro de tipo.
Algunos ejemplos comunes son los tipos personalizados `List`, `Maybe` y `Result`.

```elm
-- Maybe is generic over the type a
type Maybe a
    = Nothing
    | Just a

someString : Maybe String
someString = Just "hello"

someInt : Maybe Int
someInt = Just 42
```

Una observación importante sobre los nombres de los parámetros de tipo es que pueden tener varios caracteres de longitud.
La única restricción es que deben ser nombres en minúscula.
Por eso, cuando resulta útil, tendemos a darles nombres descriptivos.

Un tipo puede ser genérico sobre varios otros tipos y, por lo tanto, tener varios parámetros de tipo.
En ese caso, cada tipo independiente recibe un nombre en minúscula diferente.
El que sean independientes no impide que lleguen a ser el mismo tipo; solo les permite ser diferentes.

```elm
-- Result is generic over the types error and value
type Result error value
    = Ok value
    | Err error
```

Los alias de tipo de registro también pueden tener parámetros de tipo, aunque es menos común.

```elm
-- Event is generic over the type a
type alias Event a =
    { at : Time
    , data : a 
    }
```

### Parámetros de tipo en las funciones

Como los tipos pueden ser genéricos, las funciones también pueden serlo.
Se pueden escribir funciones que manejen tipos genéricos, como `Maybe.withDefault`.

```elm
withDefault : a -> Maybe a -> a
withDefault default maybe =
    case maybe of
      Just value -> value
      Nothing -> default
```

Las funciones que reciben otras funciones como parámetros se llaman funciones de orden superior, y estas también pueden ser genéricas.

```elm
map : (a -> b) -> Maybe a -> Maybe b
map function maybe =
  case maybe of
    Just value ->
      Just (function value)

    Nothing ->
      Nothing
```
