# Tuplas

Las tuplas son una forma ligera de agrupar un conjunto fijo de datos de tipos arbitrarios. Una tupla no tiene
un nombre en particular; darle nombre a una estructura de datos la convierte en una `struct`. Los campos de una tupla no tienen nombres;
se accede a ellos mediante desestructuración o por posición.

## Sintaxis

Las tuplas son una lista de campos rodeada de paréntesis:

- `()` es el `unit type`, que es un [caso especial](https://doc.rust-lang.org/std/primitive.unit.html)
- **(** _expresión_ **,)** es una expresión de tupla de un solo elemento
- **(** _tipo_ **,)** es un tipo de tupla de un solo elemento
- **(** _expresión_ **,** ... **)** es una expresión de tupla general
- **(** _tipo_ **,** ... **)** es un tipo de tupla general

### Creación

Las tuplas siempre se crean con una expresión de tupla:

```rust
// pointless but legal
let unit = ();
// single element
let single_element = ("note the comma",);
// two element
let two_element = (123, "elements can be of differing types");
```

Las tuplas pueden tener cualquier cantidad de elementos.

### Acceso por desestructuración

Es posible acceder a los elementos de una tupla por desestructuración. Esto simplemente significa asignar nombres de variables
a los elementos individuales de la tupla, consumiéndola.

```rust
let (elem1, _elem2) = two_element;
assert_eq!(elem1, 123);
```

### Acceso por posición

También es posible acceder a los elementos de una tupla por índice posicional numérico. La indexación, como siempre,
comienza en 0.

```rust
let notation = single_element.0;
assert_eq!(notation, "note the comma");
```

## Structs de tupla

También se te pedirá que trabajes con structs de tupla. Al igual que los structs normales, son tipos con nombre; a diferencia
de los structs normales, tienen campos anónimos. Su sintaxis es muy similar a la sintaxis normal de las tuplas. Es
válido usar tanto la desestructuración como el acceso posicional.

```rust
struct TupleStruct(u8, i32);
let my_tuple_struct = TupleStruct(123, -321);
let borrowed_neg = &my_tuple_struct.1;
let TupleStruct(borrowed_byte, _) = &my_tuple_struct;
assert_eq!(borrowed_neg, &-321);
assert_eq!(borrowed_byte, &123);
```

### Visibilidad de los campos

Todos los campos de las tuplas anónimas son siempre públicos. Sin embargo, los campos de los structs de tupla tienen visibilidad
individual que, de forma predeterminada, es privada, igual que los campos de los structs estándar. Puedes hacer públicos los campos
con el modificador `pub`, tal como en un struct estándar.

```rust
// fails due to private fields
mod tuple { pub struct TupleStruct(u8, i32); }
fn main() { let _my_tuple_struct = tuple::TupleStruct(123, -321); }
```

```rust
// succeeds: fields are public
mod tuple { pub struct TupleStruct(pub u8, pub i32); }
fn main() { let _my_tuple_struct = tuple::TupleStruct(123, -321); }
```
