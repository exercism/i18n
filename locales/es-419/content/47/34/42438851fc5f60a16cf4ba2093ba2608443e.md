# Ayuda

Para obtener ayuda si tienes problemas, puedes usar uno de los siguientes recursos:

- [/r/csharp](https://www.reddit.com/r/csharp) es el subreddit de C#.
- [StackOverflow](http://stackoverflow.com/questions/tagged/c%23) puedes usarlo para buscar tu problema y ver si ya lo han respondido. También puedes hacer preguntas y responderlas.
