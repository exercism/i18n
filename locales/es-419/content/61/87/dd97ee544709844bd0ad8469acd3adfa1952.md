# Consejos

## General

- El conteo de aves por día se guarda en un campo llamado `birdsPerDay`.
- El conteo de aves por día es un array que contiene exactamente 7 números enteros.

## 1. Verifica cuáles fueron los conteos de la semana pasada

- Como guardamos la última semana, solo necesitamos devolver los valores de la última semana.

## 2. Verifica cuántas aves visitaron hoy

- Recuerda que los conteos están ordenados por día, del más antiguo al más reciente, y el último elemento representa hoy.
- Puedes acceder al último elemento usando su índice fijo (recuerda empezar a contar desde cero) o calculando su índice con el tamaño del array.

## 3. Incrementa el conteo de hoy

- Asigna al elemento que representa el conteo de hoy el valor del conteo de hoy más 1.

## 4. Verifica si hubo algún día sin aves visitantes

- Puedes recorrer el array con un bucle `for`.
- Otra solución es usar la Java Stream Api.

## 5. Calcula el número de aves visitantes en los primeros días

- Puedes usar una variable para guardar el conteo del número de aves visitantes.
- Puedes recorrer el array con un bucle `for`.
- Puedes actualizar la variable dentro del bucle.
- Recuerda: los arrays se indexan desde `0`.

## 6. Calcula el número de días ocupados

- Puedes usar una variable para guardar el número de días ocupados.
- Puedes recorrer el array con un bucle `foreach`.
- Puedes actualizar la variable dentro del bucle.
- Puedes usar una sentencia condicional dentro del bucle.
