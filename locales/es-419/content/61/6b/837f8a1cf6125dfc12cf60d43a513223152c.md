# Acerca de

Muchos [tipos de miembros de struct y de clase][expression-bodied-members] (siendo los campos la principal excepción) pueden usar la sintaxis de miembro con cuerpo de expresión. Definir un miembro con una expresión suele producir código más conciso y legible que los bloques o sentencias tradicionales.

```csharp
public int Times3(int input) => input * 3;

public int Interesting => 1729;
```

Los miembros con cuerpo de expresión no pueden tener bloques de varias sentencias, pero quienes tengan experiencia en programación funcional deben saber que todo lo que puede hacer un miembro tradicional se puede lograr con uno de estos miembros. La «expresión» puede ser una operación de asignación que genere efectos secundarios, o la invocación de un método, lo que significa que todo es posible.

[expression-bodied-members]: https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/statements-expressions-operators/expression-bodied-members
