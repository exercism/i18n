# Ayuda

Si tienes problemas y necesitas ayuda, puedes usar uno de los siguientes recursos:

- [/r/perl](https://www.reddit.com/r/perl) es el subreddit de Perl.
- [StackOverflow](http://stackoverflow.com/questions/tagged/perl) lo puedes usar para buscar tu problema y ver si ya se respondió. También puedes hacer y responder preguntas.
