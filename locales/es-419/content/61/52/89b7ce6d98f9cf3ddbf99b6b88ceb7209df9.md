# Introducción

## Atributos

Un [C# `Attribute`](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/attributes/) ofrece una forma de decorar una declaración para asociarle metadatos a: una clase, un método, un enum, un campo, una propiedad o cualquier [otra declaración compatible](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/attributes/#attribute-targets).

Puedes aplicar un atributo agregándolo en la línea anterior a la declaración usando un `ClassAttribute` y un `FieldAttribute`:

```csharp
[Class]
class MyClass
{
    [Field]
    int myField;
}
```

Estos metadatos declarativos solo asocian información estructurada adicional al código y no modifican su comportamiento, pero otra parte del código usa esos metadatos para cambiar cómo se comportaría su destino o para agregar, cambiar, quitar o restringir algunas de sus funcionalidades.

Existen muchos [atributos predefinidos y reservados](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/attributes/general#conditional-attribute), por ejemplo: `Flags`, `Obsolete`, `Conditional` y `Experimental`. Cada uno tiene un significado semántico específico que puedes consultar en la documentación de C#. Ten en cuenta que el nombre completo de un atributo como [`Flags`](https://docs.microsoft.com/en-us/dotnet/api/system.flagsattribute) toma la forma `<Name>Attribute` (por ejemplo, `FlagsAttribute`).

## Enums de flags

El [tipo `enum` de C#](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/builtin-types/enum) representa un conjunto fijo de constantes con nombre (una enumeración).

Normalmente, un miembro del `enum` solo puede referirse a exactamente una de esas constantes con nombre. Sin embargo, a veces es útil referirse a más de una constante. Para hacerlo, puedes anotar el `enum` con el [atributo `Flags`](https://docs.microsoft.com/en-us/dotnet/api/system.flagsattribute)

Un enum de flags se puede definir de la siguiente manera (usando la notación de enteros binarios `0b`):

```csharp
[Flags]
enum PhoneFeatures
{
    Call = 0b00000001,
    Text = 0b00000010
}
```

Una instancia de `PhoneFeatures` cuyo valor es `0b00000011` tiene activados tanto el flag `Call` _como_ el flag `Text`.

De forma predeterminada, se usa el tipo `int` para los valores de los miembros del enum. Puedes usar un tipo de entero diferente especificando el tipo en la declaración del enum:

```csharp
[Flags]
enum PhoneFeatures : byte
{
    Call = 0b00000001,
    Text = 0b00000010
}
```
