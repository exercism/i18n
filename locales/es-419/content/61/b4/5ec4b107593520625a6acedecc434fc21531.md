# Instrucciones

En este ejercicio, juegas a un juego de adivinanzas de números con un amigo.
Las reglas son simples: eliges en secreto un número entre `1` y `100` y tu amigo intenta adivinar qué número elegiste.
Para ayudar a tu amigo, respondes de manera diferente según qué tan cerca estuvo la suposición del número que elegiste (`42`).
Estas son las reglas para las diferentes suposiciones posibles:

- Si la suposición es `42`: "Correct"
- Si la suposición es `41` o `43`: "So close"
- Si la suposición es menor que `41`: "Too low"
- Si la suposición es mayor que `43`: "Too high"

Tienes cuatro tareas para implementar las respuestas a las suposiciones.

## 1. Responde a una suposición correcta

Implementa la función `reply` para responder a una suposición correcta:

```haskell
reply 42
-- -> "Correct"
```

## 2. Responde a una suposición cercana

Modifica la función `reply` para responder a suposiciones cercanas:

```haskell
reply 41
-- -> "So close"
```

## 3. Responde a suposiciones demasiado bajas

Modifica la función `reply` para responder a suposiciones demasiado bajas:

```haskell
reply 25
-- -> "Too low"
```

## 4. Responde a suposiciones demasiado altas

Modifica la función `reply` para responder a suposiciones demasiado altas:

```haskell
reply 88
-- -> "Too high"
```
