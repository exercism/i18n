# Instrucciones

Mientras trabajas en _Instruments of Texas_, tienes la tarea de trabajar en una calculadora experimental escrita en C#. Estás construyendo un arnés de pruebas para verificar varias funciones de la calculadora, empezando por la multiplicación. Verás que hay un interés especial cuando los dos operandos de la multiplicación son negativos.

La clase `Calculator` ya se te ha proporcionado y no debes modificarla.

## 1. Completa la definición de la excepción definida por el usuario `CalculationException`

Completa la definición del constructor de `CalculationException`, que deberá almacenar (envolver) cualquier excepción lanzada por la calculadora, así como los operandos que se están procesando en el momento en que se lanza la excepción.

## 2. Maneja las condiciones de desbordamiento en la calculadora y proporciona información ampliada a quien llama

Implementa el método `CalculatorTestHarness.Multiply()`, que debe llamar al método `Calculator.Multiply()` de la instancia de `Calculator` que se pasó al constructor, pasando los valores enteros x e y. Si ocurre un desbordamiento en el método `Calculator.Multiply()`, este lanzará una `OverflowException`. Esta excepción debe capturarse en el método `CalculatorTestHarness.Multiply()` y envolverse en una `CalculationException`, y los valores x e y que se están pasando deben almacenarse como los operandos de la excepción. El objeto `CalculationException` recién creado debe lanzarse. Puedes ignorar el valor que devuelve el método `Calculator.Multiply()` si tiene éxito.

```csharp
var cth = new CalculatorTestHarness(new Calculator());
cth.Multiply(Int32.MaxValue, Int32.MaxValue);
// => throws an instance of CalculationException

var cth2 = new CalculatorTestHarness(new Calculator());
cth2.Multiply(3, 2);
// => silently exits
```

## 3. Prueba la operación de multiplicación con argumentos válidos

Implementa el método `CalculatorTestHarness.TestMultiplication()`, que recibe dos enteros y llama al método `CalculatorTestHarness.Multiply()`. Se devuelve `"Multiply succeeded"`.

```csharp
var cth = new CalculatorTestHarness(new Calculator());
cth.TestMultiplication(6, 7);
// => "Multiply succeeded"
```

## 4. Prueba la operación de multiplicación con argumentos negativos

Modifica el método `CalculatorTestHarness.TestMultiplication()` para que se devuelva `"Multiply failed for negative operands. <INNER_EXCEPTION_MESSAGE>"` si ambos argumentos enteros son negativos (menores que cero).

El marcador `<INNER_EXCEPTION_MESSAGE>` debe reemplazarse con el mensaje de la excepción interna de `CalculationException`.

```csharp
var cth = new CalculatorTestHarness(new Calculator());
cth.TestMultiplication(-2, -Int32.MaxValue);
// => "Multiply failed for negative operands. " + innerException.Message
```

## 5. Prueba la operación de multiplicación con argumentos positivos

Modifica el método `CalculatorTestHarness.TestMultiplication()` para que se devuelva `"Multiply failed for mixed or positive operands. <INNER_EXCEPTION_MESSAGE>"` si al menos uno de los argumentos enteros no es negativo.

El marcador `<INNER_EXCEPTION_MESSAGE>` debe reemplazarse con el mensaje de la excepción interna de `CalculationException`.

```csharp
var cth = new CalculatorTestHarness(new Calculator());
cth.TestMultiplication(Int32.MaxValue, Int32.MaxValue);
// => "Multiply failed for mixed or positive operands. " + innerException.Message
```
