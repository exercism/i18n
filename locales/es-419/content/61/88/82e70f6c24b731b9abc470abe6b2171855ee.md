# Instalación

La forma más fácil de instalar Ceylon es, simplemente, **no** instalarlo.
Deberías poder resolver la mayoría de los ejercicios con nuestro [IDE web](http://try.ceylon-lang.org/).

Sin embargo, si lo prefieres, puedes instalar la distribución de línea de comandos; la forma más fácil de hacerlo es con [SDKMAN](http://sdkman.io/),
así que primero debes instalar eso si aún no lo tienes, y luego solo escribe `sdk install ceylon` en tu terminal.

Quienes usen OSX también pueden instalarlo con el [gestor de paquetes Homebrew](http://mxcl.github.com/homebrew/).

Las instrucciones de instalación para otras plataformas, así como para el IDE de Ceylon, un complemento para Eclipse, están disponibles en [el sitio oficial](http://ceylon-lang.org/download/).
