# Alias

La [forma especial `alias`][alias] te permite acortar o cambiar el nombre con el que haces referencia a un módulo externo. Puedes especificar un nombre personalizado con la opción `:as`.

```elixir
defmodule Square do
  alias Integer, as: I

  def area(a), do: I.pow(a, 2)
end
```

Cuando se usa sin argumentos, recorta el nombre del módulo hasta su última parte, por ejemplo:

```elixir
alias MyApp.Account.User
# is the same as
alias MyApp.Account.User, as: User
```

Puedes agrupar varios alias juntos con `{}`:

```elixir
alias MyApp.Account.{User, EmailValidation}
# is the same as
alias MyApp.Account.User
alias MyApp.Account.EmailValidation
```

Por lo general, los alias se agregan al principio de la definición del módulo, pero pueden agregarse en cualquier lugar. Tienen ámbito léxico, lo que significa que un alias agregado dentro de la definición de una función no estará disponible en otra función.

Los alias que no se usan provocan advertencias del compilador.

[alias]: https://hexdocs.pm/elixir/Kernel.SpecialForms.html#alias/2
