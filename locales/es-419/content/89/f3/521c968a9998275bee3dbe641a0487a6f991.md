# Acerca de los condicionales

## Operadores de comparación

Los [operadores de comparación][operators] son similares a los de muchos otros lenguajes, con algunas extensiones.

Para la igualdad, los operadores son `==` (igual) y `!=` (distinto).

```Kotlin
val txt = "abc"
txt == "abc" // => true
txt != "abc" // => false
```

Además, los operadores `===` y `!==` comprueban la [«igualdad referencial»][referential-equality]: `a === b` si y solo si `a` y `b` apuntan al mismo objeto.
Esto tendrá más sentido más adelante en el temario.

Los operadores de mayor y menor que también son convencionales.

```Kotlin
1 < 3 // => true
3 > 3 // => false
3 <= 3 // => true
4 >= 3 // => true
```

## Ramificación con `if`

Esta es la forma completa de una [expresión `if`][if-else]:

```Kotlin
if (conditional1) {
//    something...
} else if (conditional2) {
//    something...
} else {
//    something...
}
```

- Se requieren paréntesis `()` alrededor de cada condicional.
- Un condicional debe evaluarse a un Boolean `true` o `false`.
  Kotlin no tiene el concepto de «truthy» y «falsy» como en algunos lenguajes.
- Las llaves `{}` son opcionales si hay una sola expresión.
- Tanto `else if` como `else` son opcionales, y puede haber varios bloques `else if`.

La expresión `if` también se puede usar para «elegir» un valor:

```Kotlin
val number = 100000
val description = if (number > 100) "number is over 100" else "number is less than 100"
// => description = "number is over 100"
```

## ¿Alternativas?

Por decisión deliberada, Kotlin _no_ tiene el operador ternario `? :` que se encuentra en Java.
Se prefiere una forma concisa de `if ... else`:

```Kotlin
val result = if (isOk) goodValue else badValue

return if (isOK) goodValue else badValue
```

A diferencia de Ruby, la forma concisa de `if ... else` *siempre* necesita un `else` y, por lo tanto, no se puede usar como sentencia de guarda:

```kotlin
return 42 if (isOk)
// Syntax error: Unexpected tokens (use ';' to separate expressions on the same line).
// Syntax error: Expecting an expression.

return if (isOk) true
// 'if' must have both main and 'else' branches when used as an expression.
```

Ten en cuenta que en Kotlin, `if` es una [_expresión_][expression] que devuelve un valor.
No es una [_sentencia_][statement] como en Java.

Veremos más adelante, en otro concepto, que Kotlin tiene una potente construcción [`when`][when], pensada para reemplazar largas cadenas de cláusulas `else if` con coincidencia de patrones.
