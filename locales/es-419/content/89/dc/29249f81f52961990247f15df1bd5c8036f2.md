# Strings

Un _string_, o _cadena_, es una serie de caracteres rodeada de comillas.
Se admiten tanto las comillas simples como las dobles.

```php
<?php

$where = "Spain";
$what = 'rain';
```

## Expansión de variables en un string

En los strings con comillas dobles, si se hace referencia a una variable que está en el ámbito, su valor se inserta en el string.

```php
<?php

$answer = 42;
$expanded = "The answer to life, the universe, and everything is $answer"; 
```

## Compatibilidad con la codificación de caracteres

Históricamente, las funciones de string en PHP solo admitían caracteres ASCII y no eran compatibles con las codificaciones Unicode modernas.
Cada carácter ASCII ocupa 1 byte, mientras que los caracteres Unicode pueden medir entre 1 y 4 bytes.
Si necesitas manipular strings Unicode de forma segura, consulta las [versiones multibyte][multi-byte-fns] de las funciones históricas.

```php
<?php

$byte_length = strlen('😃'); // => 4
$string_length = mb_strlen('😃'); // => 1
```

[multi-byte-fns]: https://www.php.net/manual/en/ref.mbstring.php
