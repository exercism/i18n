# Acerca de

Un *conjunto disjunto* (una estructura union-find) mantiene una colección de valores
dividida en grupos que no se superponen, y responde con rapidez una pregunta:
¿estos dos valores están en el mismo grupo? Vive en el *vocabulary*
[`disjoint-sets`][disjoint-sets].

`<disjoint-set>` construye una estructura vacía. Los valores, o *átomos*, se
agregan con `add-atom`, o en bloque con `add-atoms`; cada uno empieza en
un grupo propio:

```
<disjoint-set> ( -- disjoint-set )
add-atom       ( atom disjoint-set -- )
add-atoms      ( seq disjoint-set -- )
```

```factor
USING: disjoint-sets ;

<disjoint-set>
{ "a" "b" "c" "d" } over add-atoms   ! four singleton groups
```

`equate` une los grupos que contienen a dos átomos. La unión es
transitiva: una vez que `a` se equipara con `b` y `b` con `c`, los tres
comparten un mismo grupo.

```
equate ( atom1 atom2 disjoint-set -- )
```

Cada grupo se identifica por un único miembro canónico, su
*representante*. `representative` lo devuelve, y dos átomos pertenecen al
mismo grupo exactamente cuando sus representantes son iguales.
`equiv?` hace esa comprobación directamente:

```
representative ( atom disjoint-set -- representative )
equiv?         ( atom1 atom2 disjoint-set -- ? )
```

```factor
USING: disjoint-sets ;

<disjoint-set>
{ "a" "b" "c" "d" } over add-atoms
"a" "b" pick equate
"b" "c" pick equate
"a" "c" pick equiv? .          ! => t   (transitively connected)
"a" "d" pick equiv? .          ! => f
"a" over representative
"c" pick representative = .     ! => t   (same representative)
```

Qué átomo se elige como representante de un grupo es un detalle
interno: puede ser cualquier miembro del grupo y puede cambiar a medida
que los grupos se fusionan. Nunca dependas de que un átomo concreto sea
el representante; solo de que dos átomos del mismo grupo coincidan.

`disjoint-set-members` devuelve todos los átomos que se han agregado.

La estructura es *mutable*: `equate` y `add-atom` cambian el conjunto
disjunto en el mismo lugar en vez de devolver uno nuevo. La
implementación usa unión por rango con compresión de caminos, así que una
serie larga de llamadas a `equate` y `representative` es, en la
práctica, de tiempo constante cada una.

[disjoint-sets]: https://docs.factorcode.org/content/vocab-disjoint-sets.html
