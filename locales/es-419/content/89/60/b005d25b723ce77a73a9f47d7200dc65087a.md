# Introducción

## Módulos

Hasta ahora, todos los ejercicios que has visto han usado clases.
A veces no necesitamos la sobrecarga de crear un objeto con estado, así que en su lugar usamos `module`.

Un módulo es muy similar a una clase (de hecho, `Module` es el padre de `Class` en la jerarquía de objetos). La principal diferencia es que, en lugar de usar métodos de instancia, usamos métodos de clase.
Los métodos de clase empiezan con `self.` y se llaman directamente en un módulo.

Por ejemplo:

```ruby
module Speaker
  def self.echo(something)
    "#{something} ... #{something}"
  end
end

Speaker.echo("Hello")   #=> "Hello ... Hello"
```

## Bucles

Hay varias formas de escribir bucles en Ruby, pero como en general tendemos a usar enumeración en lugar de bucles, el bucle que quizá veas con más frecuencia es el bucle `while`:

```ruby
counter = 0

while counter < 5
  counter += 1
end
```

También puedes usar su hermano `until`:

```ruby
counter = 0

until counter == 5
  counter += 1
end
```
