# Acerca de

Las [clausuras][closures] en Swift son bloques de código autocontenidos a los que se les pueden pasar parámetros para activar su cálculo y devolver valores.
Las clausuras también capturan valores de su entorno y los usan en sus cálculos.
Como son autocontenidas, se pueden pasar de un lado a otro en un programa como cualquier otro valor, o asignarse a constantes y variables.

Las clausuras pueden sonar muy similares a las funciones de Swift; de hecho lo son, y por una buena razón.
Las funciones en Swift son casos especiales de clausuras: se les exige tener un nombre y se definen con una sintaxis un poco distinta.

Aunque las funciones en Swift son técnicamente clausuras, cuando la gente habla de «clausuras» en Swift se refiere a las [expresiones de clausura][closure-expressions].
Las expresiones de clausura se escriben como una lista de parámetros seguida de un tipo de retorno y la palabra clave `in`, seguida del cuerpo de la clausura, todo dentro de un par de llaves:

```swift
{ (a: Double, b: Double) -> Double in
  return (a + b) / 2.0
}
```

Esto define una expresión de clausura de tipo `(Double, Double) -> Double`, y se puede ejecutar de forma similar a una función de este tipo, aplicándola a parámetros del tipo adecuado:

```swift
{ (a: Double, b: Double) -> Double in
  return (a + b) / 2.0
}(10.0, 15.0)
// returns 12.5
```

Como no es muy cómodo escribir la expresión de clausura completa cada vez que se quiere ejecutar, las clausuras se pueden asignar a nombres, como cualquier otro valor en Swift.
Después se pueden llamar aplicando el nombre a los parámetros:

```swift
let mean = { (a: Double, b: Double) -> Double in
  (a + b) / 2.0
}

mean(13.0, 100.0)
// returns 56.5
```

Como se ve arriba, las clausuras, igual que las funciones normales, pueden omitir la palabra clave `return` si el cuerpo de la clausura es una sola expresión.

La mayoría de las veces, las clausuras se usan con funciones de orden superior, ya sea pasándolas como parámetros o devolviéndolas como resultado:

```swift
[11, 75, 3, 99, 53].contains(where: { (x: Int) -> Bool in x > 100 })
// returns false

["apple", "ball", "carrot"].sorted(by: { (s1: String, s2: String) -> Bool in s1.count < s2.count })
// returns ["ball", "apple", "carrot"]

func makeAdder(base: Int) -> (Int) -> Int {
  { (x: Int) -> Int in base + x }
}
```
