# Pistas

## General

- Los lentes no se usan mucho en Roc porque la sintaxis de actualización de registros cubre bien la mayoría de los casos de uso.
  Por ejemplo, considera este registro anidado:

  ```roc
  bob = { hair: { color: Brown, length: Long }, mouth: Smiling, height: 6.0 }
  ```

  Ahora vamos a cortarle el pelo a Bob:

  ```roc
  new_bob = { ..bob, hair: { ..bob.hair, length: Short } }
  ```

  ¡No hacen falta lentes!

- Dicho esto, aunque los lentes son poco comunes en Roc, sí son habituales en otros lenguajes como Haskell y Scala, así que quizá te dé curiosidad saber cómo se podrían implementar en Roc.
  Además, es una buena forma de practicar algunas funcionalidades avanzadas de Roc, como los tipos parametrizados y los registros que contienen funciones.
  De hecho, esta es una manera de representar un lente en Roc:

  ```roc
  Lens(whole, part) := {
      get : whole -> part,
      set : whole, part -> whole,
  }
  ```

  Este es un tipo parametrizado: `whole` y `part` podrían ser cualquier tipo.
  `whole` normalmente es un registro, mientras que `part` puede ser cualquier tipo de campo.
  El campo `get` contiene una función que devuelve una `part` específica del `whole` dado, mientras que el campo `set` contiene una función que devuelve una copia del `whole` dado, pero con una `part` específica reemplazada por la `part` proporcionada.

  Por ejemplo, aquí hay un lente para obtener o establecer el pelo de una persona:

  ```roc
  hair_lens = {
      get: |person| person.hair,
      set: |person, hair| { ..person, hair },
  }
  ```

  Podemos usar este lente para enfocarnos en el pelo de Bob, así:

  ```roc
  bob_hair = bob |> hair_lens.get
  ```

  Y podemos cambiarle el pelo así:

  ```roc
  new_hair = { ..bob.hair, length: Short }
  new_bob = bob |> (hair_lens.set)(new_hair)
  ```

- Nota: los paréntesis alrededor de `hair_lens.set` son obligatorios; sin ellos, Roc buscaría una función llamada `set` en el tipo de `hair_lens`.

- Los lentes se vuelven especialmente útiles cuando empiezas a componerlos, ya que te permiten obtener y establecer partes anidadas a gran profundidad.
  Esto se puede lograr implementando una función como esta:

  ```roc
  compose : Lens(outer, inner), Lens(inner, part) -> Lens(outer, part)
  ```

  Una vez implementada esta función, puedes usarla para crear un lente de longitud del pelo así:

  ```roc
  length_lens = {
      get: |hair| hair.length,
      set: |hair, length| { ..hair, length },
  }
  hair_length_lens = compose(hair_lens, length_lens)

  ```

  Ahora puedes darle a Bob otro corte de pelo:

  ```roc
  set_hair_length = hair_length_lens.set
  new_bob = bob |> set_hair_length(Short)
  ```

- También puede que quieras implementar una función que te permita aplicar cualquier transformación a una parte anidada:

  ```roc
  over : Lens(whole, part), whole, (part -> part) -> whole
  ```

  Una vez implementada, puedes usar `over` así:

  ```roc
  cut_hair = |current_length| match current_length {
      Long => Short
      Short => Bald
      Bald => Bald
  }
  new_bob = hair_length_lens |> over(bob, cut_hair)
  ```

- Te recomendamos que primero pases las pruebas usando la sintaxis de actualización de registros de Roc y que después intentes usar lentes en su lugar.
