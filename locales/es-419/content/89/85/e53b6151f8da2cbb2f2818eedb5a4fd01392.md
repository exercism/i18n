# Introducción

En JavaScript, un array (o arreglo) es una estructura similar a una lista, con una longitud no fija, que puede contener cualquier tipo de primitivas u objetos, incluso de tipos mixtos.

Para crear un array, agrega elementos entre corchetes `[]`.
Para leer de un array, coloca el índice entre corchetes `[]` después del identificador.
Los índices de un array empiezan en cero.

Por ejemplo:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers[2];
// => 3
```

Para obtener la cantidad de elementos que hay en un array, usa la propiedad `length`:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.length;
// => 4
```

Para cambiar un elemento del array, asigna un valor en el índice:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers[0] = 'one';
numbers;
// => ['one', 'two', 3, 'four']
```

## Métodos

Algunos de los [métodos][array_methods] que están disponibles en todos los objetos Array se pueden usar para agregar o quitar elementos de un array.

### push

> El método `push()` agrega uno o más elementos al final de un array y devuelve la nueva longitud del array.[^1]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.push(5); // => 5
numbers;
// => [1, 'two', 3, 'four', 5]
```

### pop

> El método `pop()` elimina el último elemento de un array y devuelve ese elemento.
> Este método cambia la longitud del array.[^2]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.pop(); // => four
numbers;
// => [1, 'two', 3]
```

### shift

> El método `shift()` elimina el primer elemento de un array y devuelve ese elemento eliminado.
> Este método cambia la longitud del array.[^3]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.shift(); // => 1
numbers;
// => ['two', 3, 'four']
```

### unshift

> El método unshift() agrega uno o más elementos al principio de un array y devuelve la nueva longitud del array.[^4]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.unshift('one'); // => 5
numbers;
// => ['one', 1, 'two', 3, 'four']
```

### splice

> El método splice() cambia el contenido de un array eliminando o reemplazando elementos existentes y/o agregando nuevos elementos en su lugar. Este método devuelve un array que contiene los elementos eliminados.[^5]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.splice(2, 1, 'one'); // => [3]
numbers;
// => [1, 'two', 'one', 'four']
```
