# Instrucciones

Como futura maga, Elyse necesita practicar algunos conceptos básicos.
Tiene una pila de cartas que quiere manipular.

Para que las cosas sean un poco más fáciles, solo usa las cartas del 1 al 10, así que su pila de cartas se puede representar con un vector de números.
La posición de una carta determinada corresponde al índice en el vector.

## 1. Obtén una carta de la pila

Para tomar una carta, devuelve la carta que está en el índice `position` de la pila dada.

```julia-repl
julia> stack = [1, 2, 4, 1];
julia> position = 3;
julia> get_item(stack, position)
4
```

## 2. Intercambia una carta en la pila

Haz un poco de juego de manos e intercambia la carta del índice `position` con la carta de reemplazo proporcionada.
Devuelve la pila ajustada.

```julia-repl
julia> stack = [1, 2, 4, 1];
julia> position = 3;
julia> replacement_card = 6;
julia> set_item!(stack, position, replacement_card)
[1, 2, 6, 1]
```

## 3. Inserta una carta en la parte superior de la pila

Haz aparecer una carta insertando una carta nueva en la parte superior de la pila.
Devuelve la pila ajustada.

```julia-repl
julia> stack = [5, 9, 7, 1];
julia> new_card = 8;
julia> insert_item_at_top!(stack, new_card)
[5, 9, 7, 1, 8]
```

## 4. Elimina una carta de la pila

Haz desaparecer una carta eliminando de la pila la carta que está en la `position` dada.
Devuelve la pila ajustada.

```julia-repl
julia> stack = [3, 2, 6, 4, 8];
julia> position = 3;
julia> remove_item!(stack, position)
[3, 2, 4, 8]
```

## 5. Elimina la carta superior de la pila

Haz desaparecer una carta eliminando la carta que está en la parte superior de la pila.
Devuelve la pila ajustada.

```julia-repl
julia> stack = [3, 2, 6, 4, 8];
julia> remove_item_from_top!(stack)
[3, 2, 6, 4]
```

## 6. Inserta una carta en la parte inferior de la pila

Haz aparecer una carta insertando una carta nueva en la parte inferior de la pila.
Devuelve la pila ajustada.

```julia-repl
julia> stack = [5, 9, 7, 1];
julia> new_card = 8;
julia> insert_item_at_bottom!(stack, new_card)
[8, 5, 9, 7, 1]
```

## 7. Elimina una carta de la parte inferior de la pila

Haz desaparecer una carta eliminando la carta que está en la parte inferior de la pila.
Devuelve la pila ajustada.

```julia-repl
julia> stack = [8, 5, 9, 7, 1];
julia> remove_item_at_bottom!(stack)
[5, 9, 7, 1]
```

## 8. Verifica el tamaño de la pila

Verifica si el tamaño de la pila es igual a `stack_size` o no.

```julia-repl
julia> stack = [3, 2, 6, 4, 8];
julia> stack_size = 4;
julia> check_size_of_stack(stack, stack_size)
false
```
