# Pistas

## General

- [El tutorial de números de Python][python-numbers-tutorial] y [los tipos numéricos de Python][python-numeric-types] pueden ser una gran introducción.

## 1. Estima el valor después del cambio

- Puedes usar el [operador de división][division-operator] para obtener el valor de la moneda cambiada.

## 2. Calcula cuánto queda después de un cambio

- Puedes usar el [operador de resta][subtraction-operator] para obtener la cantidad de cambio.

## 3. Calcula el valor de los billetes

- Puedes usar el [operador de multiplicación][multiplication-operator] para obtener el valor de los billetes.

## 4. Calcula la cantidad de billetes

- Necesitas dividir `amount` entre `denomination`.
- Necesitas usar la conversión de tipos a `int` para obtener la cantidad exacta de billetes.
- Para quitar los decimales de un `float`, puedes convertirlo a `int`.

  **Nota:** El operador `//` también hace división entera. Pero, si el operando tiene `float`, el resultado sigue siendo `float`.

## 5. Calcula lo que sobra después de cambiar a billetes

- Necesitas encontrar el residuo de `amount` que no equivale a una `denomination` completa.
- El operador de módulo `%` puede ayudarte a encontrar el residuo.

## 6. Calcula el valor después del cambio

- Necesitas calcular el `spread` por ciento de `exchange_rate` usando el operador de multiplicación y sumarlo a `exchange_rate` para obtener la moneda cambiada.
- La tasa real debe calcularse. Recuerda sumar la _tasa_ de cambio y la _comisión_ de cambio.
- Puedes obtener el dinero cambiado afectado por la comisión usando la operación de división y la conversión de tipos a `int`.
