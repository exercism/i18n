# Pistas

## 1. Revisa cuántas aves visitaron hoy

- «Hoy» significa la última entrada del vector `birds_per_day`.
- Se puede acceder a la última entrada de `v` con el índice `length(v)`.
- La función [`tail(v, n)`][ref-tail] es útil para leer (pero no modificar) el final de un vector.
  El argumento `v` es el vector y `n` es el número de entradas que se devuelven, con un valor predeterminado de 6.

## 2. Incrementa el recuento de hoy

- Podrías usar el índice `length(v)` para acceder a la entrada de hoy.
- Otra opción es sumar el vector de longitud 7 correspondiente.
- Para construir un vector con entradas repetidas, la función [`rep()`][ref-rep] puede serte útil.
