# Pistas

## 1. Convertir las ubicaciones

- Puedes acceder a los elementos de una tupla usando coincidencia de patrones o acceso por índice.

## 2. Comparar las ubicaciones del tesoro y del lugar

- Puedes comparar tuplas para ver si son iguales, siempre que tengan la misma longitud y los mismos tipos en el mismo orden.

## 3. Contar las ubicaciones del tesoro

- Puedes usar la función `filter` del módulo `gleam/list` para eliminar elementos de una lista según una función que devuelve un bool.
