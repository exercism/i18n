# Pruebas

Como OCaml es un lenguaje compilado, necesitas compilar tu envío y el código de prueba antes de poder ejecutar las pruebas.
Usamos [`dune`](https://dune.build/) para compilar.
Cada carpeta tiene un archivo dune que especifica cómo compilar y también un Makefile que delega en dune.

Para compilar y ejecutar las pruebas, simplemente escribe desde la carpeta del ejercicio:

```bash
make
```

## Creando tu primer módulo de OCaml

Para crear un módulo que se pueda usar con la prueba en el ejercicio `bob`, pon lo siguiente en un archivo llamado `bob.ml`:

```ocaml
open Base 

let response_for input = failwith "TODO"
```
