# Apéndice de las instrucciones

## Errores

Cuando la entrada esté fuera del rango 1..64, lanza el string

```
"square must be between 1 and 64"
```

(tal cual).

## Palabras

- `square ( n -- grains )`: granos en la `n`-ésima casilla.
- `total ( -- grains )`: granos en todo el tablero de ajedrez.
