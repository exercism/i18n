# Pistas

## 1. Obtén la primera letra de una frase

- Repasa la introducción para averiguar cómo obtener una letra específica de un string.
- Los índices empiezan a contar desde 0.

## 2. Capitaliza una palabra

- Capitalizar significa tener un solo carácter _en mayúscula_, seguido de caracteres _en minúscula_.
- Entonces, primero necesitas extraer la primera letra y convertirla [a mayúscula][mdn-to-upper-case].
- Luego necesitas determinar el resto del string (todo excepto el primer carácter).
  El [método slice][mdn-slice] te puede ayudar con eso.
- Después de aplicar la conversión [a minúscula][mdn-to-lower-case], puedes combinar la primera letra con el resto usando el operador de suma `+`.

## 3. Obtén la última letra de una frase

- Repasa la introducción para averiguar cómo obtener una letra específica de un string.
- El índice de la última letra se puede derivar de la propiedad `.length` del string y del hecho de que los índices empiezan a contar en 0.
- Los strings incluyen un [método trim][mdn-trim] que elimina el espacio en blanco al inicio y al final.

## 4. Sé amable

- Reutiliza una función existente para capitalizar la palabra.
- El operador de suma `+` se puede usar para concatenar dos strings.
