# Pruebas

## Ejecutar las pruebas

El track de Haxe se apoya en el framework de pruebas [Buddy](https://github.com/ciscoheat/buddy).
Puedes instalarlo con lo siguiente:

```bash
haxelib install buddy
```

Para ejecutar las pruebas, usa el siguiente comando:

```bash
haxe test.hxml
```

En el archivo de pruebas, cada bloque describe marca una sección de las pruebas del ejercicio, y cada prueba es un bloque `it` o `xit`.
Los bloques `it` se ejecutan cuando ejecutas las pruebas, pero los bloques `xit` son pruebas que están pendientes.
Cuando envías una solución, el ejecutor de pruebas de Exercism ejecutará todos los bloques `it` o `xit`.
Cuando trabajas de forma local, solo se ejecuta la primera prueba de manera predeterminada.
Para ejecutar otras pruebas, cambia los bloques `xit` correspondientes a bloques `it` y vuelve a ejecutar `haxe test.hxml`.


Además, algunos ejercicios pueden requerir que se instalen bibliotecas adicionales con haxelib.
Cuando eso ocurra, habrá una nota en las instrucciones del ejercicio.

## Cómo resolver el ejercicio

Resolver un ejercicio significa hacer que todas sus pruebas pasen.
Para ayudarte a empezar, cada ejercicio viene con un archivo de implementación esqueleto.
Puedes usar este archivo como punto de partida para construir tu solución.
Siéntete libre de eliminar o modificar este archivo si crees que es lo correcto.
Intenta concentrarte en una sola prueba a la vez mientras avanzas hacia la solución.
