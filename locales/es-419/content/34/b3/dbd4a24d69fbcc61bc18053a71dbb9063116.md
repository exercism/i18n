# Anexo a las instrucciones

## Notas de implementación

El objeto `Tree` tiene dos atributos:

- `String` etiqueta
- `List<Tree>` hijos

El programa de prueba crea árboles aplicando repetidamente la función constructora `Tree.of`. Por ejemplo, la sentencia

```java
Tree tree = Tree.of("a", List.of(Tree.of("b"), Tree.of("c", List.of(Tree.of("d")))));
```

construye el siguiente árbol:

```text
      "a"
       |
    -------
    |     |
   "b"   "c"
          |
         "d"
```

Puedes asumir que no habrá valores duplicados en los árboles de prueba.

---

Los métodos `FromPov` y `PathTo` son la parte interesante del ejercicio.

El método `FromPov` recibe un argumento de tipo string `from`, que especifica un nodo del árbol mediante su valor. Debe devolver un árbol con el valor `from` en la raíz. Puedes modificar el árbol original y devolverlo, o crear un árbol nuevo y devolver ese. Si devuelves un árbol nuevo, puedes consumir o destruir el árbol original sin problema. Claro que es mejor dejarlo sin modificar.

El método `PathTo` recibe dos argumentos de tipo string, `from` y `to`, que especifican dos nodos del árbol mediante sus valores. Debe devolver la ruta más corta en el árbol del primer nodo al segundo.

## Mensajes de excepción

A veces es necesario [lanzar una excepción](https://docs.oracle.com/javase/tutorial/essential/exceptions/throwing.html).
Cuando lo hagas, siempre debes incluir un **mensaje de error significativo** que indique cuál es el origen del error.
Esto hace que tu código sea más legible y ayuda muchísimo con la depuración.

Este ejercicio en particular requiere que uses la [palabra clave throw](https://docs.oracle.com/javase/tutorial/essential/exceptions/throwing.html)
para «lanzar» varias `UnsupportedOperationException` si a la clase `Tree()` se le pasa un árbol que no se puede reorientar, o si no se puede encontrar una ruta entre un `start node` y un `end node`.
Las pruebas solo pasarán si haces `throw` de la `exception` e incluyes un mensaje con ella.

Para lanzar una `UnsupportedOperationException` con un mensaje, escribe el mensaje como argumento del tipo `exception`:

```java
// when a tree cannot be oriented to a new node POV
throw new UnsupportedOperationException("Tree could not be reoriented");

// when a path cannot be found between a start and end node on the tree.
throw new UnsupportedOperationException("No path found");
```
