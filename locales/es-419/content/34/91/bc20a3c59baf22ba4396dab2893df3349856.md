# Introducción

Python tiene tres tipos diferentes de números integrados: enteros ([`int`][int]), de punto flotante ([`float`][float]) y complejos ([`complex`][complex]).
Las fracciones ([`fractions.Fraction`][fractions]) y los decimales ([`decimal.Decimal`][decimals]) también están disponibles si los importas desde la biblioteca estándar.

Los números enteros, que incluyen los hexadecimales ([_`hex()`_][hex]), octales ([_`oct()`_][oct]) y binarios ([_`bin()`_][bin]) **sin** decimales, también se identifican como `ints`.

Python admite por completo la aritmética entre estos diferentes tipos de números y convertirá los números más estrechos para que coincidan con sus equivalentes menos estrechos cuando se usen con los operadores aritméticos binarios (`+`, `-`, `*`, `/`, `//` y `%`).
