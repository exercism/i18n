# Instrucciones

Sigues trabajando en el sistema de gestión de inventario que construiste antes.
Desde que descubriste `OpenStruct` y los atajos de bloque, decidiste refactorizar un poco el código.
En lugar de guardar los artículos como hashes, vas a aprovechar tus nuevas habilidades.

## 1. Permite recuperar los artículos

Quieres seguir recuperando la lista de artículos en inventario, pero esta vez deben ser objetos a los que se les puedan llamar métodos.

```ruby
inventory = BoutiqueInventory.new([
  {price: 65.00, name: "Maxi Brown Dress", quantity_by_size: {s: 3, m: 7, l: 8, xl: 4}},
  {price: 50.00, name: "Red Short Skirt", quantity_by_size: {}},
  {price: 29.99, name: "Black Short Skirt", quantity_by_size: {s: 1, xl: 4}},
  {price: 20.00, name: "Bamboo Socks Cats", quantity_by_size: {s: 7, m: 2}}
])

inventory.items.first.name
# => "Maxi Brown Dress"

inventory.items.first.price
# => 65

inventory.items.size
# => 4
```

## 2. Refactoriza `item_names`

Refactoriza `item_names` para que use el nuevo atajo de bloque que aprendiste en lugar de hashes.
Como recordatorio, el método debe devolver:

```ruby
BoutiqueInventory.new([
  {price: 65.00, name: "Maxi Brown Dress", quantity_by_size: {s: 3, m: 7, l: 8, xl: 4}},
  {price: 50.00, name: "Red Short Skirt", quantity_by_size: {}},
  {price: 29.99, name: "Black Short Skirt", quantity_by_size: {s: 1, xl: 4}},
  {price: 20.00, name: "Bamboo Socks Cats", quantity_by_size: {s: 7, m: 2}}

# => ["Bamboo Socks Cats", "Black Short Skirt", "Maxi Brown Dress", "Red Short Skirt"]
```
