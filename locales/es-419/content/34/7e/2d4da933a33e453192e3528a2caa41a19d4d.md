# Hints

## General

- En x86-64, un bucle se logra saltando a una etiqueta anterior y se puede salir de él saltando a una etiqueta que esté fuera de él.
- Para acceder al contenido almacenado en una dirección de memoria, necesitas desreferenciarla usando `[]`.
- El prefijo para acceder a valores de 4 bytes en memoria es `dword`.
- Un array se representa por su dirección, que es un valor de 8 bytes en x86-64.
- Si una función a la que llamas modifica un registro, necesitas guardar cualquier valor de ese registro que vayas a usar más adelante.

## 3. Reabastece el suministro de gajos de lima

- Puedes usar `sub` para restar el valor de un operando fuente al valor de un operando destino.
- Puedes usar `inc` para sumar 1 al valor de un operando destino.
