# Introducción

## Nil

`Nil` en Gleam es un tipo con un único valor, que también se llama `Nil`. Es similar a `void` en otros lenguajes, en el sentido de que se usa cuando una función no tiene un valor más adecuado que devolver.

```gleam
io.println("Hello, Joe!")
// -> Nil
```

Los valores en Gleam no son «nilables» ni «anulables» como en algunos otros lenguajes. Un valor solo puede ser `Nil` si su tipo es `Nil`, y un valor de cualquier otro tipo nunca puede ser `Nil`.

## IO

Como la mayoría de los lenguajes de programación, Gleam tiene «efectos secundarios», así que las funciones pueden leer y cambiar el estado del mundo, además de devolver un valor.

El módulo `gleam/io` de la biblioteca estándar de Gleam proporciona funciones para imprimir strings en la consola.

```gleam
io.println("Hello, Joe!")
// Hello, Joe!
// -> Nil
```

Otros paquetes pueden proporcionar otras funciones de IO, como `simplifile`, un paquete que proporciona funciones para leer y escribir archivos.

```gleam
simplifile.read("favourite-colour.txt")
// -> Ok("Pink\n")
```
