# Introducción

Los Boolean en Java se representan con el tipo `boolean`, cuyos valores pueden ser `true` o `false`.

Java admite tres operadores Boolean:  

- `!` (NOT): niega el Boolean  
- `&&` (AND): toma dos Boolean y da como resultado true si ambos son true  
- `||` (OR): da como resultado true si cualquiera de los dos Boolean es true  

## Ejemplos

```java
!true // => false
!false // => true
true && false // => false
true && true // => true
false || false // => false
false || true // => true
```
