# Pistas

## 1. Verifica que el comando sea válido

- Usa el método [test()][mdn-regex-test] para devolver un boolean.
- Recuerda que podemos usar [flags][mdn-flags] al final de la expresión regular para obtener funcionalidades adicionales, como que no distinga entre mayúsculas y minúsculas.

## 2. Elimina los emojis cifrados

- En este caso debemos usar el constructor [RexExp][mdn-regular-expressions] para construir nuestra expresión regular.
- Gracias a que el cifrado de cada emoji es común, podemos usar `[0-9]` para buscar cualquier dígito después de la palabra `emoji`.
- El carácter `+` coincide con uno o más elementos consecutivos.
- Usa el método [split()][mdn-regex-split] junto con la expresión regular de cada emoji para deshacerte de todo el cifrado.
- Por último, devuelve este array dividido como un string usando el método [join()][mdn-join].

## 3. Verifica que el número de teléfono sea válido

- En este ejercicio estamos jugando con `groups and ranges`. Lee esta [documentación][mdn-groups] para aprender más al respecto.
- Este [artículo][phone-validation] explica muy bien distintas formas de validar números.
- También puedes usar esta [guía rápida][mdn-regex-cheatsheet] para tener una visión amplia de las funcionalidades disponibles en las expresiones regulares.
- Usa el método `test()` para verificar si el número de teléfono es válido o no.
- Devuelve la respuesta final con un simple `if statement`.

## 4. Obtén el enlace del sitio web

- Estamos buscando palabras que están unidas por uno o más `.(dots)`.
- Recuerda poner el flag `g` al final para poder obtener todos los dominios de cualquier oración.
- Usa el método [match()][mdn-regex-match] para devolver un array con todas las coincidencias anteriores.

## 5. Saluda al usuario

- Primero, usa el método [replace()][mdn-regex-replace] directamente sobre el string dado.
- Usa [Named Capture Groups][mdn-groups] para guardar `name` y `surname` en valores distintos.
- Pasa un destructuring `(...match)` a la función de reemplazo para que puedas obtener el nombre y el apellido en el objeto dentro de los grupos coincidentes.
- Usa el método `pop()` para guardar el objeto coincidente con `name` y `surname`.
- Por último, implementa un `template String` para que puedas obtener los valores del objeto de la expresión regular. Mira [este][mdn-capturing-groups] ejemplo para saber cómo match() guarda los objetos.
