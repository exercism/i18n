# Anexo a las instrucciones

## Instrucciones específicas de la pista

Para este ejercicio necesitas definir un **locale** llamado `robot` que define los **sustantivos** `position` y `direction` y un **verbo** `move`.

- El verbo `create` de `robot` toma la posición y la dirección iniciales como un array de cajas.
    
    ```j
      r=. (0 0;'north') conew 'robot'
    ```
- `move` actualiza los valores de `position` y `direction` en la **instancia** creada.
    ```j
      r=. (0,0;'north') conew 'robot'
      
      NB. initial state
      NB. ====================================
      position__r
        0 0
      direction__r
        north
      
      NB. new states after `move` is executed 
      NB. ====================================
      move__r 'LA'
      position__r
        _1 0
      direction__r
        west      
    ```
