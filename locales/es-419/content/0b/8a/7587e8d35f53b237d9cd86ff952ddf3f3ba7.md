# Pistas

## General

- Quizás quieras echarle un vistazo a [las interfaces en el Tour of Go][interfaces-tour-of-go] para ver más ejemplos si el ejercicio se te complica.

## 1. Crea la funcionalidad abstracta de saludo

- Vuelve a mirar el ejemplo de `Counter` de la introducción para descubrir cómo definir una interfaz.
- Revisa los [conceptos de funciones][concept-functions] para repasar cómo se escriben las firmas de funciones en Go.
- El tipo abstracto `Greeter` se puede usar en la firma de una función igual que un tipo concreto normal como `string`.
- Para implementar `SayHello`, llama a los métodos del argumento de tipo `Greeter`.
  Después, usa formato de string o concatenación de strings para construir el resultado final.

## 2. Implementa el italiano

- Revisa el [concepto de structs][concept-structs] para ver cómo se define un tipo struct.
- Para resolver la tarea, el struct no necesita ningún campo en absoluto.
- Una vez que definas el struct, querrás agregarle los métodos `LanguageName` y `Greet`.
  Revisa el [concepto de métodos][concept-methods] para descubrir cómo agregar un método a un tipo.
