# tiene función Main

Elimina la función `Main`, ya que los tests no la necesitan y hace que el código sea un poco más difícil de leer.

Por lo general, la función `Main` se agrega para ayudar a hacer debug del código. Sin embargo, un mejor enfoque es hacer debug del código mientras ejecutas uno o más tests unitarios. Esto tiene la ventaja adicional de que puedes concentrarte en hacer debug de un caso de prueba específico. Aquí tienes algunos enlaces que explican cómo hacer debug de código Scala mientras ejecutas tests unitarios en distintos IDE:

- [IntelliJ](https://www.jetbrains.com/help/idea/run-debug-and-test-scala.html)
- [Eclipse](http://scala-ide.org/docs/current-user-doc/features/scaladebugger/index.html)
