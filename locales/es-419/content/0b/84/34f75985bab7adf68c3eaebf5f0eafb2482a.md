# Anexo de instrucciones

## Implementación

En este ejercicio vas a instanciar una clase y a agregar algunos métodos de instancia; puedes consultar [Cómo escribir clases en Ruby][writing-classes] para ver cómo se hace.

Un HighScore acepta un array con uno o más números, y cada uno representa una «puntuación de juego». La clase Array puede darte ideas para trabajar con arrays; consulta [ruby-docs][ruby-docs-array].
