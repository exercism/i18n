# Pistas

## General

- Vas a necesitar definir [funciones][functions] y usar [operadores aritméticos][arithmetics].

## 1. Guarda el tiempo de horneado esperado en una constante

- Define una [const][const] para guardar este valor.

## 2. Calcula el tiempo de preparación en minutos

- Usa el [operador aritmético `times`][arithmetics] para multiplicar el argumento por `2`.

## 3. Calcula el tiempo restante en el horno en minutos

- Usa el [operador aritmético `minus`][arithmetics] para restar el argumento de `60`.

## 4. Calcula el tiempo total de trabajo en minutos

- Reutiliza la función `preparation_time` definida en el primer paso.
- Usa el [operador aritmético `plus`][arithmetics] para sumar el valor que devuelve `preparation_time` al argumento.
