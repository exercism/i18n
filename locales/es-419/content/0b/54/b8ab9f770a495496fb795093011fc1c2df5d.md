# Ignorar

## Opciones adicionales de la línea de comandos de jq

Notarás opciones adicionales para `jq` en los tests.

```sh
run jq -s -R -c -f flower-field.jq << 'END_INPUT'
```

¿Qué son?

- `-s`

  Este es el modo «slurp».
  En lugar de tratar la entrada como un flujo de objetos JSON,
  toda la entrada se absorbe en un solo array.

  ```sh
  $ seq 5 | jq -c '.'
  1
  2
  3
  4
  5
  $ seq 5 | jq -s -c '.'
  [1,2,3,4,5]
  ```

- `-R`

  Es posible que ya hayas visto `-r`, que sirve para mostrar strings «raw» (sin comillas).
  Esta opción es lo contrario.
  Cada línea de la entrada se toma como un string.

  Dos ejemplos:

  ```sh
  $ seq 5 | jq -R -c .
  "1"
  "2"
  "3"
  "4"
  "5"

  $ echo 42 | jq '. * 2'      # input is a JSON number
  84
  $ echo 42 | jq -R '. * 2'   # input is a JSON string
  "4242"
  ```

Cuando combinas estas dos opciones, _no_ obtienes un array de strings:
obtienes toda la entrada como un único string, incluidos los saltos de línea al final de cada línea.

```sh
$ seq 5 | jq -s -R -c .
"1\n2\n3\n4\n5\n"
```

Manejar esto es parte del reto de este ejercicio.
