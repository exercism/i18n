# Introducción

`call` (en [`kernel`][kernel]) ejecuta una quotation. Cuando no se
puede inferir el efecto de pila de la quotation (normalmente porque
la quotation viene de otro lugar), declara el efecto en `call` de
forma explícita:

```
call( stack-effect ) ! e.g. call( a b -- c )
```

```factor
3 4 [ + ] call .                 ! => 7
3 4 [ + ] call( a b -- c ) .     ! => 7

: apply-binary ( a b op -- c )
    call( a b -- c ) ;

5 3 [ - ] apply-binary .         ! => 2
```

Como las quotations son valores, un array puede llevar una mezcla de
números y quotations, lo que hace que «un programa» sea solo otra
secuencia:

```factor
{ [ 1 + ] [ 2 * ] } 5 swap [ call( x -- y ) ] each .   ! 5 -> 6 -> 12
```

[kernel]: https://docs.factorcode.org/content/vocab-kernel.html
