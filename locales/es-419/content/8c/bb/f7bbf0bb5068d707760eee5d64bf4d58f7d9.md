# Instalación

## Instala el entorno de ejecución de R
Visita la [página principal de CRAN](https://cran.r-project.org/). Ahí encontrarás enlaces de descarga para Linux, Mac OSX y Windows. Descarga y ejecuta el instalador para tu sistema operativo.

## Instala el IDE de RStudio (recomendado)
RStudio es un entorno de desarrollo integrado (IDE) multiplataforma muy popular para programar en R (y también admite otros lenguajes como Python, JavaScript y Markdown). Usar RStudio te facilitará escribir tus soluciones y ejecutar las pruebas.

Descarga e instala la [versión estable actual de RStudio](https://www.rstudio.com/products/rstudio/download/). O, como alternativa, consigue la [versión preliminar](https://www.rstudio.com/products/rstudio/download/preview/) de una próxima versión.

## Instala la extensión de Visual Studio Code para R (alternativa)
La extensión de R para Visual Studio Code admite resaltado de sintaxis ampliado, autocompletado de código, linting, formateo, interacción con terminales de R, visualización de datos, gráficos, variables del espacio de trabajo y páginas de ayuda, además de gestionar paquetes y trabajar con documentos de R Markdown.

Descarga e instala la [versión actual de la extensión de R](https://code.visualstudio.com/docs/languages/r)

## Instala los paquetes de R para ejecutar las pruebas
El ejecutor de pruebas para las especificaciones es la biblioteca [`testthat`](https://github.com/hadley/testthat) de Hadley Wickham, que es una opción popular para quienes escriben paquetes de R.

Para instalar esta biblioteca, escribe lo siguiente en la consola de RStudio (o donde sea que uses R).

```{R}
install.packages("testthat")
```

Aunque es poco probable que _necesites_ instalar paquetes para resolver los ejercicios de Exercism, puede que quieras incorporar un paquete de utilidades de propósito general como [`tidyverse`](https://github.com/tidyverse/tidyverse) que se ajuste a tu estilo de programación. Para instalar y cargar un paquete como `tidyverse`:

```{R}
install.packages("tidyverse")
library(tidyverse)
```
