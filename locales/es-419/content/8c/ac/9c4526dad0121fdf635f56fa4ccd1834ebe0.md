# Encabezado de prueba

## Usar `grep` o no usar `grep`, esa es la cuestión

Aunque este ejercicio se puede resolver de forma trivial con solo pasarle los argumentos a `grep`, implementa este ejercicio usando únicamente bash. El objetivo de este track de Exercism es aprender a usar los comandos integrados de bash para resolver problemas.

Para resolver este ejercicio, vas a necesitar:

* analizar los argumentos de la línea de comandos: [`getopts`](https://stackoverflow.com/tags/getopts/info) es útil para esto.
* recorrer las líneas de un archivo: esto es la [pregunta frecuente número 1 de bash](https://mywiki.wooledge.org/BashFAQ/001)
* usar la coincidencia de expresiones regulares: bash puede hacerlo con el operador `=~` dentro de [`[[ ... ]]`](https://www.gnu.org/software/bash/manual/bash.html#index-_005b_005b)
