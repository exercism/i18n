# Instrucciones

Si quieres construir algo con una Raspberry Pi, probablemente uses _resistencias_.
Para este ejercicio, necesitas saber dos cosas sobre ellas:

- Cada resistencia tiene un valor de resistencia.
- Las resistencias son pequeñas, tan pequeñas que si imprimieras el valor de resistencia en ellas, sería difícil de leer.

Para solucionar este problema, los fabricantes imprimen bandas codificadas por colores en las resistencias para indicar sus valores de resistencia.
Cada banda tiene una posición y un valor numérico.

Las primeras 2 bandas de una resistencia tienen un esquema de codificación simple: cada color se asigna a un solo número.

La tercera banda es un multiplicador.

En este ejercicio vas a crear un programa útil para que no tengas que recordar los valores de las bandas.

Puedes encontrar más información sobre la codificación de colores de las resistencias en el [artículo de Wikipedia sobre el código de colores electrónico][e-color-code].

## 1. Define un vector con nombres

Los colores se codifican de la siguiente manera:

- black: 0
- brown: 1
- red: 2
- orange: 3
- yellow: 4
- green: 5
- blue: 6
- violet: 7
- grey: 8
- white: 9

Crea el vector con nombres, `resistor_bands`, que debe tener los colores como nombres y los números como valores.

## 2. Devuelve el valor asociado a una banda

Primero, querrás poder encontrar el valor único de cualquier banda de color.

Define una función `band_value(band)` que recibe un `string` con el color de una banda.
La función devuelve el valor asociado a ese color.

```R
band_value("green")
# => [1] 5

band_value("violet")
# => [1] 7
```

## 3. Devuelve el valor asociado a dos bandas

Las dos primeras bandas de una resistencia se combinan para formar un solo número.
Si las dos primeras bandas tienen como números respectivos `m` y `n`, se combinan para formar el número `mn`.

Define una función `two_band_value(bands)` que recibe un `vector` de `string`s con dos colores de banda.
La función devuelve el valor asociado a la combinación de esos dos colores.

```R
two_band_value(c("yellow", "red"))
# => [1] 42

two_band_value(c("green", "violet"))
# => [1] 57
```

## 4. Devuelve los ohmios asociados a las tres bandas

Finalmente, necesitarás encontrar el valor completo en ohmios usando las dos primeras bandas junto con la tercera.
Para hacerlo, necesitarás encontrar el valor de dos bandas y un multiplicador.
El multiplicador se puede entender como cuántos ceros se agregan al valor de dos bandas.

Define una función `ohms(bands)` que recibe un `vector` de `string`s con tres colores de banda.
La función devuelve el valor asociado en ohmios para la combinación de los tres colores.

```R
ohms(c("yellow", "red", "orange"))
# => [1] 42000

ohms(c("green", "violet", "yellow"))
# => [1] 570000
```
