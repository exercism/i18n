# Instrucciones

En este ejercicio vas a jugar con un auto a control remoto, para el que por fin ahorraste suficiente dinero para comprarlo.

Los autos empiezan con la batería llena (100%).
Cada vez que conduces el auto con el control remoto, recorre 20 metros y consume uno por ciento de la batería.
El apodo del auto no se conoce hasta que se crea.

El auto a control remoto tiene una pantalla LED muy elegante que muestra dos datos:

- La distancia total que ha recorrido, la cual se muestra así: `"<METERS> meters"`.
- La carga restante de la batería, la cual se muestra así: `"Battery at <PERCENTAGE>%"`.

Si la batería está al 0%, ya no puedes conducir el auto y la pantalla de la batería mostrará `"Battery empty"`.

## 1. Crea un auto a control remoto completamente nuevo

Implementa la función `new_remote_control_car/0` para que devuelva un objeto de auto a control remoto completamente nuevo:

```jq
new_remote_control_car
# => {
#      "battery_percentage": 100,
#      "distance_driven_in_meters": 0,
#      "nickname": null
#    }
```

## 2. Crea un auto a control remoto completamente nuevo con un apodo

Implementa la función `new_remote_control_car/1` para que devuelva un objeto de auto a control remoto completamente nuevo con un apodo proporcionado:

```jq
new_remote_control_car("Blue")
# => {
#      "battery_percentage": 100,
#      "distance_driven_in_meters": 0,
#      "nickname": "Blue"
#    }
```

## 3. Muestra la distancia

Implementa la función `display_distance/0`, que recibe como argumento un objeto de auto y devuelve el string de la distancia tal como se muestra en la pantalla LED:

```jq
new_remote_control_car | display_distance
# => "0 meters"
```

## 4. Muestra el porcentaje de batería

Implementa la función `display_battery/0`, que recibe como argumento un objeto de auto y devuelve el string del porcentaje de batería tal como se muestra en la pantalla LED:

```jq
new_remote_control_car | display_battery
# => "Battery at 100%"
```

Si la batería está al 0%, la pantalla de la batería mostrará «Battery empty».

## 5. Conducir cambia la batería y la distancia recorrida

Implementa la función `drive/0`, que:

- recibe como argumento un objeto de auto
- incrementa en 20 la cantidad de metros recorridos
- consume un 1% de la batería
- devuelve el objeto de auto modificado

```jq
new_remote_control_car("Red") | drive
# => {
#      "battery_percentage": 99,
#      "distance_driven_in_meters": 20,
#      "nickname": "Red"
#    }
```

## 6. Ten en cuenta cómo conducir con la batería agotada

Modifica la función `drive/0` para que no aumente la distancia recorrida ni disminuya el porcentaje de batería cuando la batería está agotada (al 0%):

```jq
{
  battery_percentage: 0,
  distance_driven_in_meters: 2000,
  nickname: "Red"
} | drive
# => {
#      "battery_percentage": 0,
#      "distance_driven_in_meters": 2000,
#      "nickname": "Red"
#    }
```
