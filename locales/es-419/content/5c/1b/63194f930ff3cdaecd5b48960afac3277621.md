# Introducción

Muchos programas necesitan valores (aparentemente) aleatorios para simular eventos del mundo real.

Entre los ejemplos comunes y conocidos se incluyen:

- Lanzar una moneda: un valor aleatorio que es `"H"` o `"T"`.
- La tirada de un dado: un número entero aleatorio del 1 al 6.
- Barajar una baraja de cartas: un orden aleatorio de una lista de cartas.

Generar valores verdaderamente aleatorios con una computadora es un [desafío técnico sorprendentemente difícil][web-truly-random], así que puedes ver estos resultados mencionados como «seudoaleatorios».

***Importante***: Este Concepto *no* cubre los números aleatorios criptográficamente seguros, que son un desafío mucho más difícil.

Sin embargo, R se deriva de un paquete de estadística y a menudo se usa para simulaciones, así que ofrece una gran variedad de formas de generar valores aleatorios.
Los resultados son más que suficientes para la mayoría de las aplicaciones de modelado, simulación y juegos.

## [Muestreo con o sin reemplazo][yt-sampling-with-replacement]

Imagina que tienes una bolsa con 3 bolas rojas y 4 bolas verdes, y sacas una bola al azar de la bolsa.
Para obtener una segunda bola, hay dos posibilidades:

1. Devuelves la primera bola a la bolsa y agitas bien todo antes de sacar otra.
   El número de bolas ahora es el mismo que antes (7), y *la proporción de rojas a verdes también es la misma*.
2. Dejas la primera bola sobre la mesa antes de sacar una segunda.
   Ahora solo hay 6 bolas en la bolsa, y *la proporción de rojas a verdes depende del color de la primera bola*.

El escenario 1 es con reemplazo, el escenario 2 es sin reemplazo, y *dan resultados diferentes*.

## Valores discretos con `sample`

Para elegir entre un número limitado de valores discretos, se puede usar `sample()` con o sin reemplazo.
Esto es útil para números enteros, strings, etc.

```R
sample(1:10, 5) # no repeats by default
#> [1] 8 3 4 2 6

sample(1:10, 5, replace = TRUE) # repeats are OK
#> [1] 10 10  7 10  9

languages <- c("Fortran", "R", "Python", "Julia")
sample(languages, 1)
#> [1] "Python"

sample(c("H", "T"), 5, replace = TRUE) # coin flips
#> [1] "T" "T" "H" "H" "H"

sample(c(TRUE, FALSE), 5, replace = TRUE) # alternative coin flips
#> [1] FALSE  TRUE FALSE  TRUE  TRUE
```

El muestreo encaja bien en las canalizaciones de datos.
Por ejemplo, para generar strings alfanuméricos aleatorios:

```R
library(stringr)

c(letters, LETTERS, 0:9) |> sample(50) |> str_flatten()
#> [1] "5tX71jhbM9zUmKrpENBQyGYaZdJPVAx06leSF2s8gcfw3OviIH"
```

## Barajar

Varios otros lenguajes tienen una función especial para barajar una secuencia.

R no tiene una función para barajar.
*¿Por qué?*

Para entenderlo, observa de nuevo la función `sample`.

La forma completa es `sample(x, size, replace = FALSE, prob = NULL)`, donde `x` es (normalmente) la secuencia de la que se muestrea y `size` es el número de elementos que se eligen.

Ya hablamos de `replace`, cuyo valor predeterminado es el muestreo sin reemplazo.
Por ahora, ignora `prob`, que te permite dar pesos desiguales a los distintos elementos de `x`.

¿Qué pasa si omitimos `size` y solo damos `x`?

```R
x <- letters[1:6]
x
#> [1] "a" "b" "c" "d" "e" "f"
sample(x)
#> [1] "e" "a" "f" "b" "c" "d"
```

Al estilo típico de R, el patrón es vector de entrada, vector de salida, y `size` toma como valor predeterminado `length(x)`.

«Muestrear todos los elementos de `x` sin reemplazo» es solo una forma más técnica de decir «barajar `x`».

*Por eso*, no hay una función `shuffle`, ¡porque `sample` ya hace exactamente lo que necesitamos!

## Trabajar con distribuciones

Los ejemplos anteriores describían casos en los que todos los resultados son igualmente probables.
Por ejemplo, `sample(1:100)` tiene la misma probabilidad de dar cualquier número entero del 1 al 100.

Esto se llama una distribución `uniform`.

Muchas situaciones del mundo real son mucho menos simples que esto.
Por eso, los estadísticos han creado una gran variedad de `distributions` para describir matemáticamente los resultados del «mundo real».

## Números de punto flotante

### Distribución uniforme

Para una distribución de números de punto flotante con el mismo peso, usa `runif()` (concéntrate en «**r**andom-**unif**orm» y lucha contra la tendencia natural pero *equivocada* de leerlo como «run if»).
Se pueden especificar tanto `min` como `max`, pero sus valores predeterminados son 0 y 1.

```R
runif(5)  # generate 5 values
#> [1] 0.3038506 0.3527959 0.3319309 0.4846354 0.4386279

# generate 5 non-negative values <= 100.0
runif(5, max = 100)
#> [1] 79.70762 51.62232 52.85281 71.08571 63.94380
```
