# Introducción

## Result

El tipo `Result` es la solución del lenguaje Elm para informar de errores, y además sirve como base para recuperarse de ellos. Es algo similar al tipo `Maybe`, pero mientras que `Maybe` puede ser devuelto por funciones que pueden fallar, no te dice nada sobre por qué fallaron. `Result` incluye ese contexto sobre por qué algo falló.

El tipo `Result` se define de la siguiente manera:

```elm
type Result error value
  = Ok value
  | Err error
```

Esto se conoce como una definición de «tipo personalizado» en la terminología de Elm.
El `error` y el `value` en `OK value` y `Error error` representan una variable de tipo, lo que significa que puede ser cualquier tipo, como `Int`, `Bool` o `String`.
Por eso, un `Result String Int` es una variable que se espera que contenga un `Int`, y si hay un error, este se representará como un `String`.
Existe un [módulo Result](https://package.elm-lang.org/packages/elm/core/latest/Result) con muchas funciones auxiliares útiles para Result.
