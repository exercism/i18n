# Instrucciones

En este ejercicio vas a implementar el manejo de errores para una calculadora sencilla de números enteros.
Para simplificar las cosas, se proporcionan los métodos para calcular la suma, la multiplicación y la división.

El objetivo es tener una calculadora que funcione y que devuelva un String con el siguiente patrón: `16 + 51 = 67`, cuando se le pasan los argumentos `16`, `51` y `+`.

```java
CalculatorConundrum calculator = new CalculatorConundrum();

calculator.calculate(16, 51, "+");
// => returns "16 + 51 = 67"

calculator.calculate(32, 6, "*");
// => returns "32 * 6 = 192"

calculator.calculate(512, 4, "/");
// => returns "512 / 4 = 128"
```

## 1. Implementa el método calculate para admitir algunas operaciones básicas

El método principal que implementarás en esta tarea será el método `CalculatorConundrum.calculate()`.
Recibe tres argumentos.
Los dos primeros argumentos, `operand1` y `operand2`, son números enteros sobre los que se va a realizar una operación.
El tercer argumento, `operation`, es de tipo String y para este ejercicio es necesario implementar las siguientes operaciones:

- la suma usando el String `+`
- la multiplicación usando el String `*`
- la división usando el String `/`

## 2. Maneja las operaciones ilegales

Actualiza el método `CalculatorConundrum.calculate()` para manejar las operaciones ilegales:

- Cuando el argumento `operation` sea `null`, se debe lanzar una `IllegalArgumentException` con el mensaje `Operation cannot be null`.
- Cuando el argumento `operation` sea `""`, se debe lanzar una `IllegalArgumentException` con el mensaje `Operation cannot be empty`.
- Cuando el argumento `operation` sea cualquier operación que no sea `+`, `*` o `/`, se debe lanzar una `IllegalOperationException` con el mensaje `Operation '{operation}' does not exist`.

```java
calculator.calculate(10, 1, null);
// => throws IllegalArgumentException with message "Operation cannot be null"

calculator.calculate(10, 1, "");
// => throws IllegalArgumentException with message "Operation cannot be empty"

calculator.calculate(10, 1, "-");
// => throws IllegalOperationException with message "Operation '-' does not exist"
```

## 3. Maneja la excepción que se lanza al dividir entre cero

En Java, intentar dividir entre cero lanza una `ArithmeticException`.
Actualiza el método `CalculatorConundrum.calculate()` para capturar esta excepción y luego lanzar una `IllegalOperationException` con el mensaje `Division by zero is not allowed` y la `ArithmeticException` capturada como su causa.

```java
calculator.calculate(512, 0, "/");
// => throws IllegalOperationException with message "Division by zero is not allowed"
```
