# Introducción

Que un array también sea una _colección_ significa que, además de acceder a sus valores por índice, puedes recorrer _todos_ sus valores con un bucle `foreach`:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // Output the vowel
    System.Console.Write(vowel);
}

// => aeiou
```
