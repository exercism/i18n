## Igualdad

Los tipos de Elm se pueden comparar para ver si «son lo mismo» con el [operador de igualdad][equality-operator] `(==)`.
El operador de desigualdad es `(/=)` (*no* `!=` como en muchos otros lenguajes).

```elm
1 == 2
    --> False

1 /= 2
    --> True
```

Ambos valores que se comparan tienen que ser del mismo tipo.
El operador de igualdad funciona con literales, tuplas, registros y tipos personalizados.
El operador comprueba la igualdad estructural, lo que significa que valores iguales tienen el mismo contenido y la misma estructura profunda, sin importar la anotación de tipo ni la posición en memoria.

```elm
(1, 2) == (2, 1)
    --> False

type alias MyRecord = { myInt : Int, myStrings : List String }
a : MyRecord
a = MyRecord (1 + 1) ["hello world"]

type alias MyOtherRecord = { myInt : Int, myStrings : List String }
myStrings =  (String.join " " ["hello", "world"]) :: []
b : MyOtherRecord
b = { myInt = 2, myStrings = myStrings}

a == b
    --> True
```

Ten en cuenta que *nunca deberías* comparar funciones, ya que eso hará que el programa falle en tiempo de ejecución.
Encontrarás más información sobre esa limitación [aquí][equality-operator].

## Comparaciones

Los [operadores de comparación][comparison-operators] `(<)`, `(<=)`, `(>)`, `(>=)` y las funciones `min`, `max`, `compare` funcionan con tipos `comparable`.
El tipo `comparable` es un tipo especial que agrupa todos los tipos incorporados que se pueden comparar: números, caracteres, strings, listas de cosas comparables y tuplas de cosas comparables.
Los caracteres se comparan a partir de sus [puntos de código Unicode][unicode-codepoint].

```elm
1 < 1 + 1
    --> True

'x' < 'X'
    --> False

'互' < '🙏'
    --> True
```

Los tipos similares a secuencias (strings, listas y tuplas) se comparan en [orden lexicográfico][lexicographic-order].
En pocas palabras, los elementos de una secuencia se comparan por pares en orden hasta que se encuentra un elemento menor o termina la secuencia.

```elm
"abc" < "abz"
    --> True

"abc" < "abcd"
    --> True

"abc" < "b"
    --> True

min [1 , 2, 9000] [10]
    --> [1 , 2, 9000]

min (1, "hello") (3, "bye")
    --> (1, "hello")

min (1, ['a', 'b']) (1, ['A', 'B'])
    --> (1, ['A', 'B'])
```

Los valores de otros tipos, como los registros o los tipos personalizados, no se pueden comparar directamente.

Algunos tipos incorporados requieren que su contenido sea `comparable`, como las claves de `Set` o `Dict`, ya que su estructura depende de un orden interno.
Eso implica que los tipos personalizados no se pueden guardar en un `Set`, aunque existen alternativas de la comunidad: [`AnySet`][any-set], [`AnyDict`][any-dict], [`Sort`][sort] y otras.

Las listas de valores `comparable` se pueden ordenar con `List.sort`, y las listas de valores que se pueden transformar en valores comparables se pueden ordenar con `List.sortBy`.
Si necesitas un orden jerárquico (ordenar por una propiedad y romper los empates con otra), puedes usar tuplas o listas con `List.sortBy` (entre otras [alternativas][sort-by]), ya que las tuplas y las listas se ordenan en orden lexicográfico.


```elm
List.sort ["hi", "hello", "bye", "goodbye"]
    --> ["bye", "goodbye", "hello", "hi"]

List.sortBy String.length ["hi", "hello", "bye", "goodbye"]
    --> ["hi", "bye", "hello", "goodbye"]

-- sort by length, then alphabetically
List.sortBy (\str -> (String.length str, str)) ["hi", "mum", "hello", "sis", "bye", "dad"]
    --> ["hi", "bye", "dad", "mum", "sis", "hello"]
```

La función `compare` toma dos valores `comparable` y devuelve un `Order`.
Un `Order` es un tipo que comprueba en una sola operación si un valor es mayor (`GT`), igual (`EQ`) o menor (`LT`) que otro.

```elm
compare 1 2
    --> LT

compare "" ""
    --> EQ

compare [12] []
    --> GT
```

Se pueden construir funciones de comparación para tipos arbitrarios y usarlas, por ejemplo, para ordenar con `List.sortWith`:

```elm
type Color = Red | Green | Blue

compareColors : Color -> Color -> Order
compareColors a b =
  case (a, b) of
    (Red, Red) -> EQ
    (Red, _) -> LT
    (_, Red) -> GT
    (Green, Green) -> EQ
    (Green, _) -> LT
    (_, Green) -> GT
    (Blue, Blue) -> EQ

List.sortWith compareColors [Blue, Red, Green, Green, Blue]
    --> [Red, Green, Green, Blue, Blue]
```
