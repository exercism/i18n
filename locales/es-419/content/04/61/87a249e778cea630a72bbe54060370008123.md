# Sentencia switch

La sentencia `switch` facilita una estructura de control condicional `if..elseif..else`.

```php
function getMessage(string $letter): string
{
  switch ($letter) {
    case 'a':
      $message = 'First letter of the english alphabet';
      break;
    case 'z':
      $message = 'Last letter of the english alphabet';
      break;
    case 'l':
    default:
      $message = 'A letter, neither the first nor the last of the alphabet';
  }
  return $message;
}

// getMessage('a') => 'First letter of the english alphabet'
// getMessage('z') => 'Last letter of the english alphabet'
// getMessage('l') => 'A letter, neither the first nor the last of the alphabet'
// getMessage('k') => 'A letter, neither the first nor the last of the alphabet'
```

Una característica única de las sentencias `switch` es el comportamiento de «caída» de cada `case`.
Observa en el ejemplo la ubicación específica de las sentencias `break`.
Sin una sentencia `break`, cada `case` se ejecutará desde el inicio del primer `case` hasta que se evalúe una sentencia `break`.
El orden de las sentencias `case` dentro de un `switch` es importante, ya que solo se evaluará hasta el primer case que coincida.

> Una advertencia: el comportamiento de «caída» facilita compartir código entre casos similares, aunque también puede ser una fuente de comportamiento no deseado y errores si se olvida la sentencia `break`.

Cada `case` realiza una comparación no estricta (débil):

```php
function matches($value): string
{
  switch ($value) {
    case false:
      return 'matches false';
    case true:
      return 'matches true';
  }
}

// matches([]) => 'matches false'
// matches(0) => 'matches false'
// matches(null) => 'matches false'
// matches('') => 'matches false'

// matches([1]) => 'matches true'
// matches(1) => 'matches true'
// matches('a') => 'matches true'
```

## Patrón de switch sin break

Supón que la función de ejemplo anterior se reescribe:

```php
function getMessage(string $letter): string
{
  switch ($letter) {
    case 'a':
      return 'First letter of the english alphabet';
    case 'z':
      return 'Last letter of the english alphabet';
    case 'l':
    default:
      return 'A letter, neither the first nor the last of the alphabet';
  }
}

// getMessage('a') => 'First letter of the english alphabet'
// getMessage('z') => 'Last letter of the english alphabet'
// getMessage('l') => 'A letter, neither the first nor the last of the alphabet'
// getMessage('k') => 'A letter, neither the first nor the last of the alphabet'
```

El comportamiento de la función sigue siendo el mismo, pero devolver directamente desde la sentencia switch evita la posible omisión de la sentencia `break`.

## Patrón de switch con expresión condicional

Otro patrón de uso de la sentencia switch es comparar cada case usando una expresión:

```php
function compareSum(int $sum): string
{
  switch (true) {
    case $sum < 10:
      return 'Less than 10';
    case $sum > 10:
      return 'More than 10';
    default:
      return 'Sum is 10';
  }
}
```

Esto brinda cierta flexibilidad para escribir expresiones más variadas y componer funciones al evaluar qué rama `case` ejecutar.
