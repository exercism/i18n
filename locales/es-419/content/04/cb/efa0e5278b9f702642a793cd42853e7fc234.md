# Anexo a las instrucciones

## Personalizar y lanzar excepciones

A veces es necesario tanto [personalizar](https://docs.python.org/3/tutorial/errors.html#user-defined-exceptions) como hacer [`raise`](https://docs.python.org/3/tutorial/errors.html#raising-exceptions) de excepciones en tu código. Cuando lo hagas, siempre debes incluir un **mensaje de error significativo** que indique cuál es el origen del error. Esto hace que tu código sea más legible y ayuda mucho a la hora de depurar.

Las excepciones personalizadas se pueden crear mediante nuevas clases de excepción (consulta [`classes`](https://docs.python.org/3/tutorial/classes.html#tut-classes) para más detalles.) que normalmente son subclases de [`Exception`](https://docs.python.org/3/library/exceptions.html#Exception).

En los casos en los que sabes que el origen del error será una derivación de cierto tipo de excepción, puedes optar por heredar de uno de los [`built in error types`](https://docs.python.org/3/library/exceptions.html#base-classes) que están bajo la clase _Exception_. Al lanzar el error, de todas formas debes incluir un mensaje significativo.

Este ejercicio en particular requiere que crees dos _excepciones personalizadas_. Una excepción que se debe [lanzar](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement) / «arrojar» cuando tu búfer circular esté **lleno**, y otra para cuando esté **vacío**. Las pruebas solo pasarán si personalizas las excepciones adecuadas, las lanzas con `raise` e incluyes los mensajes de error adecuados.

Para personalizar una `built-in exception`, crea una `class` que herede de esa excepción. Cuando lances la excepción personalizada con un mensaje, escribe el mensaje como argumento del tipo `exception`:

```python
# subclassing the built-in BufferError to create BufferFullException
class BufferFullException(BufferError):
    """Exception raised when CircularBuffer is full.

    message: explanation of the error.

    """
    def __init__(self, message):
        self.message = message

        
# raising a BufferFullException
raise BufferFullException("Circular buffer is full")
```
