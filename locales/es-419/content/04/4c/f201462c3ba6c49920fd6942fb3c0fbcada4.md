# Importar ANSI con :except

Las instrucciones mencionan «piensas agregar compatibilidad con otros colores de auto, así que quieres importar todo el módulo», salvo la función `color`, que genera el conflicto. Para hacerlo, usa la opción `:except` de esta forma:

```elixir
import IO.ANSI, except: [color: 1]
```
