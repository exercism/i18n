# Números

`INT` guarda un número entero. En este Sather son exactamente 32 bits, así que
cuenta desde -2147483648 hasta 2147483647.

```sather
   goals : INT is
      return 42;
   end;
```

## Argumentos

Una rutina recibe argumentos entre paréntesis, cada uno con un tipo:

```sather
   total(first : INT, second : INT) : INT is
      return first + second;
   end;
```

Los argumentos que comparten un tipo pueden compartir la declaración, que es el
estilo habitual:

```sather
   total(first, second : INT) : INT is
```

## Aritmética

| Operador | Significado |
| --- | --- |
| `+` | suma |
| `-` | resta, y cambia de signo |
| `*` | multiplicación |
| `/` | división, descartando el residuo |
| `%` | el residuo de esa división |

La `/` entre dos `INT`s nunca produce una fracción:

```sather
7 / 2      -- 3
7 % 2      -- 1
```

Si quieres una fracción, necesitas `FLTD`, que viene más adelante.

La multiplicación y la división tienen mayor precedencia que la suma y la resta,
como en la aritmética normal. Los paréntesis agrupan cuando necesitas otra cosa:

```sather
2 + 3 * 4        -- 14
(2 + 3) * 4      -- 20
```

## Rutinas útiles de INT

```sather
7.max(3)     -- 7
7.min(3)     -- 3
(-7).abs     -- 7
7.str        -- "7", the number written as text
```

`.str` es la forma en que un número pasa a formar parte de una oración, una vez
que hayas visto los strings.
