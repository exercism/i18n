# Ignórame

## Entrada

Tu script recibirá el rompecabezas alfamético como un solo string a través de
la entrada estándar (stdin). El string del rompecabezas sigue el formato
`WORD1 + WORD2 + ... == RESULT`.

Por ejemplo:

```text
SEND + MORE == MONEY
```

## Salida

Si el rompecabezas tiene solución, imprime una sola línea que consista en
pares `LETTER=DIGIT` separados por espacios, ordenados alfabéticamente por letra.

Para el ejemplo de arriba, la salida debería ser:

```text
D=7 E=5 M=1 N=6 O=0 R=8 S=9 Y=2
```

Si el rompecabezas tiene varias soluciones válidas, puedes imprimir cualquiera
de ellas.

Si el rompecabezas no tiene solución, no imprimas nada (una línea vacía).
