# Instrucciones

Eres el contramaestre de un carguero costero. La sentina, el compartimento más bajo del casco, recoge aguas residuales, y en cada turno el equipo de la sentina debe abrirse, ponerse en marcha y guardarse. Pase lo que pase durante el bombeo, el equipo *debe* terminar de vuelta en su estado guardado.

Las pruebas te dan `<test-pump>` para obtener bombas nuevas. Cada bomba tiene una ranura `opened>>` que lee `t` mientras está abierta y `f` una vez que se ha liberado.

## 1. Drena la sentina

Define `drain-bilge` para liberar una sola bomba. Llamar a `drain-bilge` sobre la misma bomba dos veces debería ser inofensivo; el framework se encarga de eso por ti.

```factor
<test-pump> dup drain-bilge opened>> .   ! => f
```

## 2. Rutina de bombeo

Define `pump-out` para que tome una bomba y una quotation, empuje la bomba a la pila para que la quotation la use, y libere la bomba después, *incluso si la quotation lanza una excepción*.

```factor
<test-pump> [ drop ] pump-out   ! pump released
```

## 3. Rutina de turno completo

Define `shift-routine` para que tome dos bombas y una quotation. Abre un ámbito de destructores, registra *ambas* bombas para liberación incondicional, y luego llama a la quotation. Ambas bombas terminan liberadas, ya sea que la quotation termine normalmente o lance una excepción.

La quotation recibe ambas bombas en la pila como argumentos.

```factor
<test-pump> <test-pump> [ 2drop ] shift-routine
! both pumps released
```

## 4. Bombeo riesgoso

A veces una bomba está prestada. Solo quieres desecharla si algo sale mal; de lo contrario, la siguiente guardia necesita que quede abierta. Define `risky-pump-out` para que tome una bomba y una quotation, registre la bomba para liberación **solo en caso de fallo**, y llame a la quotation con la bomba en la pila.

Si la quotation tiene éxito, la bomba permanece abierta. Si la quotation lanza una excepción, la bomba se libera y la excepción se propaga.

```factor
<test-pump> [ drop ] risky-pump-out                ! stays open
<test-pump> [ drop "boom" throw ] risky-pump-out   ! pump released, throws
```

## 5. Un desechable personalizado: la válvula

Completa el conjunto de herramientas con un desechable completamente nuevo: una `valve`. La tupla está declarada para ti:

```factor
TUPLE: valve < disposable is-open ;
```

- Define `<valve> ( -- valve )` para construir una válvula nueva mediante `new-disposable`, con `is-open` en `t`.
- Implementa `M: valve dispose*` para cambiar `is-open` a `f`.

```factor
<valve> is-open>> .                ! => t
<valve> dup dispose is-open>> .    ! => f
```
