# Anexo de instrucciones

## Pistas

Para que el test pase, vas a necesitar crear algunos tipos con los que tu código pueda trabajar: necesitas un objeto para `School` que contenga una secuencia de tipo `Student`, que será una tupla de `string` e `int` para guardar el nombre y la calificación de los estudiantes.

Aquí tienes un poco de código para los tipos que te puede servir para empezar

```nim
type
  Student* = tuple[name: string, grade: int]
  School* = object
    students*: seq[Student]
```
