# Acerca de

El atributo Flags permite que los valores definidos en una unión discriminada se representen como posiciones de bits (es decir, como flags).
Como flags, esos valores se pueden combinar, lo que permite representar varias condiciones booleanas en un solo valor.

```fsharp
[<Flags>]
type PhoneFeatures =
| Call = 1
| Text = 2
```

```fsharp
[<Flags>]
type PhoneFeaturesBinary =
| Call = 0b00000001
| Text = 0b00000010
```

Para establecer un flag puedes usar el operador OR bit a bit (`|||`); para quitarlo, una combinación del operador AND bit a bit (`&&&`) y el operador de negación bit a bit (`~~~`).
Si bien puedes comprobar el estado de un flag con el operador AND bit a bit, también puedes usar el método HasFlag().

```fsharp
let features = PhoneFeatures.Call

// Set the Text flag
let moreFeatures = features ||| PhoneFeatures.Text

moreFeatures.HasFlag(PhoneFeatures.Call) // => true
moreFeatures.HasFlag(PhoneFeatures.Text) // => true

// Unset the Call flag
let lessFeatures = features &&& ~~~PhoneFeatures.Call

lessFeatures.HasFlag(PhoneFeatures.Call) // => false
lessFeatures.HasFlag(PhoneFeatures.Text) // => true
```

Consulta [Resumen de los operadores bit a bit][bitwise-operators] para ver una lista completa de los operadores bit a bit disponibles en el lenguaje F#.
