# Pistas

`i32` tiene un ancho de cuatro bytes.

«Una instancia de memoria... contiene un vector de bytes. La longitud del vector siempre es un múltiplo del tamaño de página de WebAssembly, que se define como la constante 65536»

[Especificación de WebAssembly: instancias de memoria](https://webassembly.github.io/spec/core/exec/runtime.html#page-size)

«La instrucción `memory.size` devuelve el tamaño actual de una memoria. La instrucción `memory.grow` aumenta la memoria en un delta dado y devuelve el tamaño anterior, o -1 si no se puede asignar suficiente memoria. Ambas instrucciones operan en unidades de tamaño de página.»

[Especificación de WebAssembly: instrucciones de memoria](https://webassembly.github.io/spec/core/syntax/instructions.html#syntax-instr-memory)
