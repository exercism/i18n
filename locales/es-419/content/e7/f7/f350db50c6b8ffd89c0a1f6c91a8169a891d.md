# Pistas

## 1. Determina si vas a necesitar una licencia de conducir

- Usa el [operador de comparación de igualdad][comparison-operators] para verificar si tu argumento es igual a cierto string.
- Usa uno de los dos [operadores lógicos][logical-operators] que aprendiste en el concepto de Boolean para combinar los dos requisitos.
- **No** necesitas un condicional para resolver esta tarea.
  Puedes devolver directamente la expresión booleana que construyas.

## 2. Elige entre dos vehículos posibles para comprar

- Usa un [operador de comparación][comparison-operators] para determinar qué opción va primero en el orden lexicográfico.
- Luego asigna el valor de una variable auxiliar según el resultado de esa comparación, con la ayuda de un [condicional if-else][if-statement].
- Por último, construye la frase de recomendación.
  Para eso puedes usar el operador `+` para concatenar los dos strings.

## 3. Calcula una estimación del precio de un vehículo usado

- Empieza por determinar el porcentaje del precio original según la edad del vehículo.
  Guárdalo en una variable auxiliar.
  Usa un [condicional if-else if-else][if-statement] como se menciona en las instrucciones.
- En las dos condiciones `if`, usa [operadores de comparación][comparison-operators] para comparar la edad del auto con los valores umbral.
- Para calcular el resultado, aplica el porcentaje al precio original.
  Por ejemplo, `30% of x` se puede calcular dividiendo `30` entre `100` y multiplicando por `x`.

[comparison-operators]: https://golang.org/ref/spec#Comparison_operators
[logical-operators]: https://golang.org/ref/spec#Logical_operators
[if-statement]: https://golang.org/ref/spec#If_statements
