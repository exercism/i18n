# Pistas

## General

Este ejercicio tiene muchas soluciones posibles y muchos caminos que puedes tomar en el proceso.
Ninguno es manifiestamente «mejor» que otro, aunque puede que un camino en particular te resulte más interesante o se ajuste mejor a lo que quieres aprender o explorar ahora mismo.
Algunos caminos quizá sacrifiquen velocidad por claridad; otros ocuparán más memoria, pero serán más escalables o más fáciles de mantener.
Te animamos a probar más de una estrategia para ver qué pasa.

_______
-  Python tiene un conjunto sólido de herramientas para trabajar con strings. [`str.split`][str.split], [`str.replace`][str.replace], [`str.lower`][str.lower] y [`str.strip`][str.strip] pueden ser particularmente útiles para este ejercicio.
-  Los métodos de string se pueden encadenar (_siempre que el método devuelva un `str`_))
-  Si bien `str.split()` es muy _específico_, `str.strip()` se comporta de otra manera y permite múltiples combinaciones.
-  El módulo [`string`][string] (a diferencia de `str`) tiene algunas constantes que pueden ser útiles para filtrar y comparar cuando procesas strings.
________

-  Los [diccionarios][dict] pueden ser útiles para llevar la cuenta de cuándo los elementos (las claves) aparecen más de una vez en un string.
-  [`dict.setdefault()`][dict.setdefault] puede ayudar al procesar cuando puede que falte una clave en un diccionario.
-  El módulo [Collections][collections] implementa algunos subtipos muy útiles del `dict` (diccionario) básico, creados a propósito para hacer cosas como [contar][collections.counter].
________
-  Explorar el módulo [`re`][re] y las expresiones regulares puede ser divertido, pero no es en absoluto necesario para resolver este ejercicio.
-  [Regex101][regex101] es muy útil para experimentar con la lógica de las expresiones regulares.
-  Tanto [`re.sub`][re.sub] como [`re.findall`][re.findall] pueden ser estrategias interesantes que puedes usar.
________
-  Las [comprensiones][comprehensions] a menudo pueden «aplanar» bucles donde se agregan elementos a una lista o se insertan en un diccionario.
-  Las [expresiones generadoras][generator expressions] a menudo pueden «sustituir» a una comprensión de listas cuando se necesita un iterable.
  Las expresiones generadoras se evalúan de forma «perezosa» y ocupan menos espacio en memoria que una comprensión de listas equivalente.
