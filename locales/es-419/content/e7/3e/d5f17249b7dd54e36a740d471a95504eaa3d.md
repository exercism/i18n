# Instrucciones

Estás trabajando en la implementación de un juego de rol.
El personaje del jugador está representado por lo siguiente:

```rust
pub struct Player {
    health: u32,
    mana: Option<u32>,
    level: u32,
}
```

Los jugadores de este juego deben alcanzar el nivel 10 antes de desbloquear una reserva de maná, que pueden usar para lanzar hechizos.
Antes de ese punto, el maná del jugador es `Option::None`.

Estás trabajando en dos funcionalidades de este juego: la mecánica de reanimación y la mecánica de lanzamiento de hechizos.

El método `revive` debe verificar que el jugador esté realmente muerto (su salud llegó a 0) y, si lo está, debe devolver una nueva instancia de Player con 100 de salud.
El método `revive` debe conservar el nivel del jugador.
Si el nivel del jugador es 10 o más, debe reanimarse con 100 de maná.
Si el nivel del jugador es menor que 10, su maná debe ser `Option::None`.

```rust
let dead_player = Player { health: 0, mana: Option::None, level: 2 };
dead_player.revive()
// Returns Player { health: 100, mana: Option::None, level: 2 }
```

Si se llama al método `revive` sobre un jugador cuya salud es 1 o más, el método debe devolver `Option::None`.

```rust
let alive_player = Player { health: 1, mana: Option::Some(15), level: 11 };
alive_player.revive()
// Returns Option::None
```

El método `cast_spell` recibe una referencia mutable al jugador y también un parámetro `mana_cost` que indica cuánto maná cuesta el hechizo.
Devuelve la cantidad de daño que produce el hechizo lanzado.

- Si el jugador no tiene acceso a una reserva de maná, intentar lanzar el hechizo debe reducir su salud en el costo de maná del hechizo.
  El daño devuelto debe ser 0.

  ```rust
  let not_a_wizard_yet = Player { health: 79, mana: Option::None, level: 9 };
  assert_eq!(not_a_wizard_yet.cast_spell(5), 0)
  assert_eq!(not_a_wizard_yet.health, 74);
  assert_eq!(not_a_wizard_yet.mana, Option::None);
  ```

- Si el jugador tiene una reserva de maná pero maná insuficiente, el método no debe afectar la reserva.
El daño devuelto debe ser 0.

  ```rust
  let low_mana_wizard = Player { health: 93, mana: Option::Some(3), level: 12 };
  assert_eq!(low_mana_wizard.cast_spell(10), 0);
  assert_eq!(low_mana_wizard.health, 93);
  assert_eq!(low_mana_wizard.mana, Option::Some(3));
  ```

- En caso contrario, el hechizo se lanza con éxito.
  El `mana_cost` debe deducirse de la reserva de maná del jugador.
  El daño devuelto debe ser el doble del costo de maná del hechizo.

  ```rust
  let wizard = Player { health: 123, mana: Option::Some(30), level: 18 };
  assert_eq!(wizard.cast_spell(10), 20);
  assert_eq!(wizard.health, 123);
  assert_eq!(wizard.mana, Option::Some(20));
  ```
