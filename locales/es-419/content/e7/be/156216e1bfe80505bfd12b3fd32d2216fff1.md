# Instrucciones

En este ejercicio vas a escribir un poco más de código para ayudarte a cocinar esa estupenda lasaña de tu libro de cocina favorito.

Tienes cinco tareas, todas relacionadas con el tiempo que pasas cocinando la lasaña.

## 1. Permitir cambiar el tiempo esperado en el horno

Quieres escribir una versión mejorada de la función `remainingMinutesInOven` que tome como parámetro el número de minutos transcurridos que la lasaña ha estado en el horno y devuelva cuántos minutos aún debe permanecer la lasaña en el horno, según el tiempo esperado en minutos de la tarea anterior.
Antes, dependías de un valor constante, `expectedMinutesInOven`, que venía de fuera de la función `remainingMinutesInOven`.
Eso era un poco demasiado desordenado para tu gusto y no lo bastante flexible, ya que no te permitía cambiar el tiempo esperado en el horno.

Para ordenar un poco las cosas, define la función `remainingMinutesInOven` que toma como parámetro el número de minutos transcurridos que la lasaña ha estado en el horno, así como un parámetro `expectedMinutesInOven` que tiene un valor predeterminado de 40.
Tu función debe devolver cuántos minutos aún debe permanecer la lasaña en el horno, según el tiempo esperado en minutos de la tarea anterior.

```swift
remainingMinutesInOven(elapsedMinutes: 30)
// Returns 10
remainingMinutesInOven(elapsedMinutes: 30, expectedMinutesInOven: 75)
// Returns 45
```

## 2. Permitir números diferentes de capas

Antes habías escrito una función `preparationTimeInMinutes` que toma como parámetro el número de capas que le agregaste a la lasaña y devuelve cuántos minutos pasaste preparando la lasaña, suponiendo que cada capa te toma 2 minutos preparar.
Sin embargo, no te convence del todo esta función, ya que tienes que contar tú mismo el número de capas de tu lasaña antes de poder llamar a esta función, y ¿quién tiene tiempo para todo eso?

Para facilitarte las cosas, escribe una función, `preparationTimeInMinutes`, que tome un parámetro variádico `String`, `layers`, donde enumeras las diferentes capas de tu lasaña.
Luego, la función contará el número de capas de tu lasaña y devolverá la cantidad de tiempo de preparación necesaria.

```swift
preparationTimeInMinutes(layers: "sauce", "noodles")
// Returns 4
preparationTimeInMinutes(layers: "sauce", "noodles", "sauce", "meat", "mozzarella", "noodles", "sauce", "eggplant", "béchamel", "noodles", "sauce", "mozzarella")
// Returns 24
```

## 3. Calcular cantidades de fideos y salsa

Antes de empezar a armar tu lasaña, quieres asegurarte de tener suficiente salsa y fideos para construir la lasaña de tus sueños.
Por cada capa de fideos en tu lasaña, necesitarás 3 fideos.
Por cada capa de salsa en tu lasaña, necesitarás 0.2 litros de salsa.

Define la función `quantities` que toma un parámetro variádico `String`, `layers`, donde enumeras las diferentes capas de tu lasaña.
Luego, la función determinará la cantidad de fideos y salsa necesarias para preparar tu comida. El resultado debe devolverse en una tupla de tipo `(noodles: Int, sauce: Double)`.

```swift
quantities(layers: "sauce", "noodles", "sauce", "meat", "mozzarella", "noodles", "sauce", "eggplant", "béchamel", "noodles", "sauce", "mozzarella")
// Returns (noodles: 9, sauce: 0.8)
quantities(layers: "sauce", "noodles", "sauce", "noodles", "meat", "noodles", "mozzarella")
// Returns (noodles: 9, sauce: 0.4)
```

## 4. Convertir litros a onzas líquidas en el mismo lugar

Lamentablemente, la salsa que tienes a mano tiene el volumen indicado en onzas líquidas en lugar de litros.
Para ayudarte a saber si tienes suficiente salsa a mano, escribe una función, `toOz`, que toma un parámetro de tupla de entrada y salida, `(noodles: Int, sauce: Double)`, y convierte la cantidad de salsa a onzas líquidas.
Ten en cuenta que hay 33.814 onzas líquidas por litro.

```swift
var amount = (noodles: 9, sauce: 0.8)
toOz(&amount)

amount
// Returns (noodles: 9, sauce: 27.0512)
```

## 5. Determinar el mejor vino para servir

Finalmente, quieres saber qué tipo de vino servir con tu lasaña.
Has oído que deberías servir vino blanco si hay más mozzarella, ricota y bechamel en la lasaña que carne y salsa, y vino tinto de lo contrario.
Escribe una función `redWine` que tome un parámetro variádico `String`, `layers`, donde enumeras las diferentes capas de tu lasaña.
La función usará cinco funciones anidadas para determinar el número de capas de mozzarella, ricota, bechamel, salsa y carne en la lasaña, y comparar los números de capas para determinar si se debe servir vino tinto, devolviendo `true` si es así y `false` si no.

```swift
redWine(layers: "sauce", "noodles", "sauce", "meat", "mozzarella", "noodles", "sauce", "eggplant", "béchamel", "noodles", "sauce", "mozzarella")
// Returns true
redWine(layers: "sauce", "noodles", "béchamel", "meat", "mozzarella", "noodles", "ricotta", "eggplant", "béchamel", "noodles", "sauce", "mozzarella")
// Returns false
```
