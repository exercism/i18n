# Introduction

Un [array][list] es una colección mutable de elementos en _secuencia_.
 Los arrays pueden contener referencias a cualquier tipo de dato (o a varios), incluidos otros arrays u otras estructuras de datos como [tuplas][tuples], [conjuntos][sets] o [diccionarios][dicts].
 Se puede iterar sobre el contenido con la construcción `for item in <list>`.
 Si necesitas los índices junto con el contenido, puedes usar `for index, item in enumerate(<list>)`.
 Se puede acceder a los elementos dentro de un `list` mediante un `0-based index` desde la izquierda, o un `-1-based index` desde la derecha.
 Los arrays se pueden copiar total o parcialmente usando la _notación de rebanadas_ o `<list>.copy()`.
 Python ofrece muchos [métodos][list-methods] útiles y prácticos para trabajar con arrays.
