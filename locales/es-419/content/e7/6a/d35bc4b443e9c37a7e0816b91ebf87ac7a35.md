# Apéndice de instrucciones

## Asigna a `errno` un valor especial

Si el búfer está vacío durante un intento de lectura, se lanza un error para alertar al cliente.

Estos valores de error se pueden encontrar en el archivo de encabezado [`errno.h`][errno.h].

[errno.h]: https://en.wikipedia.org/wiki/Errno.h
