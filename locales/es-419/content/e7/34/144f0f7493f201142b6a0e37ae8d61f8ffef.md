# to_i{bit}

Usar el método `to_i{bit}` es una forma válida de convertir un valor a cierta base.
Pero cuando defines un [literal numérico][int], es más idiomático usar el sufijo `_i{bit}`.

```crystal
# Rather than:
500034214414.to_i64

# Consider:
500034214414_i64
```

[int]: https://crystal-lang.org/reference/latest/syntax_and_semantics/literals/integers.html
