# Introducción

## Coincidencia de patrones con literales

Aunque las expresiones `if/else` sirven para ejecutar lógica condicional, Haskell también ofrece una forma más potente de hacerlo: la [coincidencia de patrones][pattern-matching].
Con la coincidencia de patrones, un valor se puede comparar con uno o varios _patrones_.
Un ejemplo de patrón es el _patrón constante_, que compara un valor con una constante (por ejemplo, `1` o `"hello"`).

Al definir funciones, puedes definir cuerpos de función distintos para patrones distintos.
Esto da como resultado un código limpio, sencillo y fácil de leer.
Puedes hacer coincidir patrones con cualquier tipo de datos: números, caracteres, listas, tuplas, etc.

Por ejemplo, una función trivial que toma un número entero (`Int`) y lo acerca _1_ a _0_ se podría expresar así:

```haskell
closerToZero :: Int -> Int
closerToZero 0 = 0
closerToZero 1 = 0
```

La coincidencia de patrones empieza a brillar cuando se usa junto con otros patrones, por ejemplo el _patrón de variable_:

```haskell
closerToZero :: Int -> Int
closerToZero 0 = 0
closerToZero n = n - 1
```

El ejemplo anterior trata todos los valores de entrada distintos de _0_ de la misma forma, y produciría resultados incorrectos para números negativos.
Esto se puede resolver con patrones condicionales, conocidos como _guardas_, que se expresan con el símbolo `|`:

```haskell
closerToZero :: Int -> Int
closerToZero n
    | n < 0 = n + 1
    | n > 0 = n - 1
```

En los ejemplos anteriores, no todos los valores de entrada posibles tienen un patrón que coincida.
El compilador lo detectará y mostrará una advertencia.
Esta es una característica muy útil de Haskell, que ayuda a garantizar que se cubran todos los caminos posibles para evitar errores en tiempo de ejecución.
Se conoce como _comprobación exhaustiva_.
Para resolver la advertencia, debes manejar todos los casos.
Dentro de las _guardas_ puedes usar la expresión `otherwise` como azúcar sintáctico para `True` y así capturar todos los patrones restantes.

```haskell
closerToZero :: Int -> Int
closerToZero n
    | n < 0 = n + 1
    | n > 0 = n - 1
    | otherwise = 0
```

La coincidencia de patrones compara un valor con cada patrón, de arriba hacia abajo, hasta encontrar un patrón que coincida y ejecutar la lógica asociada a ese patrón.
**¡El orden de los patrones importa!**
