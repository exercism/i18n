# no hay export con nombre

No se encontró ningún [export](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/export) con el nombre `%{export.name}`. Las pruebas no pasarán sin él.

Asegúrate de que `%{export.name}` exista y agrega `export` delante de él:
```javascript
// exporting a "const"
export const %{export.name} = /*...*/

// exporting a named function declaration
export function %{export.name}() { /* ... */ }
```
