# Anexo de instrucciones

## Memoria reservada

El buffer para el string de entrada usa los bytes 64-191 de la memoria lineal.

## Arrays

WebAssembly no tiene el concepto de arrays.
Para el test de colores, devuelve un buffer de caracteres delimitado por comas con la forma: `black,brown,red,orange,yellow,green,blue,violet,grey,white`

Luego tendrás que construir internamente un array de estructuras usando desplazamientos y longitudes para dar estructura a este buffer.
