# Anexo de las instrucciones

## Trabajar con fechas en Prolog

El soporte integrado de Prolog para fechas es [bastante rudimentario][built-in-dates-support].
Una forma mucho más agradable de trabajar con fechas es mediante el [paquete date_time][date_time-package].

### Instalar el paquete date_time

Si la versión de Swipl que tienes instalada es bastante reciente, puedes instalar el paquete ejecutando:

```bash
swipl pack install date_time
```

Si eso no funciona, puedes ejecutar:

```shell
swipl -g 'pack_install(date_time)'
```

~~~~exercism/note
Si usas el editor en línea, no necesitas instalar nada manualmente.
~~~~

### Usar el paquete date_time

Agrega el siguiente código al inicio de tu archivo de solución para usar el paquete `date_time`:

```prolog
:- use_module(library(date_time)).
```

~~~~exercism/note
Consejo: el [código fuente del paquete date_time][https://www.swi-prolog.org/pack/file_details/date_time/prolog/date_time.pl?show=src] está bien documentado y puede serte de gran ayuda.
~~~~
