# Instrucciones

Te encanta observar aves y llevas un registro de cuántas han visitado tu jardín.
Normalmente, usas anotaciones en un cuaderno para contar las aves, pero quieres trabajar mejor con tus datos.
Ya digitalizaste los conteos de aves por día de las últimas semanas que llevabas en el cuaderno.

Ahora quieres determinar el número total de aves que contaste, calcular el conteo de aves de una semana específica y corregir un error de conteo.

~~~~exercism/note
Para practicar, usa un bucle `for` para resolver cada una de las tareas a continuación.
~~~~

## 1. Determina el número total de aves que has contado hasta ahora

Empecemos por analizar los datos con una vista general.
Averigua cuántas aves contaste en total desde que empezaste tus registros.

Implementa una función `totalBirdCount` que acepte un objeto similar a un array que contenga el conteo de aves por día.
Debe devolver el número total de aves que contaste.

```javascript
birdsPerDay = [2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1];
totalBirdCount(birdsPerDay);
// => 34
```

## 2. Calcula el número de aves visitantes en una semana específica

Ahora que tienes una idea general de tus cifras de conteo de aves, quieres hacer un análisis más detallado.

Implementa una función `birdsInWeek` que acepte un objeto similar a un array con el conteo de aves por día y un número de semana.
Devuelve el número total de aves que contaste en esa semana específica.
Puedes asumir que las semanas siempre se registran completas.

```javascript
birdsPerDay = [2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1];
birdsInWeek(birdsPerDay, 2);
// => 12
```

## 3. Corrige un error de conteo

Te diste cuenta de que, durante todo el tiempo que estuviste tratando de llevar la cuenta de las aves, había una escondida en un rincón lejano del jardín.
Descubriste que esta ave siempre pasaba un día sí y otro no en tu jardín.
No sabes exactamente dónde estaba entre esos días, pero definitivamente no estaba en tu jardín.
Tu intuición de observador de aves también te dice que el ave estuvo en tu jardín el primer día que registraste en tu lista.

Con esta nueva información, escribe una función `fixBirdCountLog` que tome como argumento un objeto similar a un array con las aves contadas por día. Debe corregir el error de conteo modificando el array dado.

```javascript
birdsPerDay = [2, 5, 0, 7, 4, 1];
fixBirdCountLog(birdsPerDay);
// => [3, 5, 1, 7, 5, 1]
```
