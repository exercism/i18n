# Apéndice de instrucciones

## Instrucciones específicas del track

Tu lista también debe implementar la siguiente interfaz:

- `delete` (elimina la primera aparición de un valor especificado)
- `count` (cuenta la cantidad de elementos de la lista)

Los stubs en `linked-list.v` proporcionan el conjunto _mínimo_ de interfaces. Puede que quieras agregar tus propias definiciones, como una estructura que represente un elemento de la lista.

Sin embargo, _no_ uses una biblioteca para implementar este ejercicio y _no_ uses un array.
