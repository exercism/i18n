# Anexo de instrucciones

## Registros

| Registro | Uso           | Tipo    | Descripción                                |
| -------- | ------------- | ------- | ------------------------------------------ |
| `$a0`    | entrada       | dirección | string de entrada terminado en null      |
| `$a1`    | entrada       | entero  | clave de desplazamiento                    |
| `$a2`    | entrada/salida | dirección | string de resultado terminado en null   |
| `$t0-9`  | temporal      | cualquiera | para almacenamiento temporal            |
