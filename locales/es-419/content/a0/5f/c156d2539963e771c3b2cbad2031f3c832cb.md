# Introducción

## Módulos

Los módulos son una forma de agrupar código relacionado y de evitar conflictos de nombres, y en general están presentes en todos los proyectos de código, salvo en los más triviales.

La sintaxis es la siguiente:

```rust
mod my_module {
    pub struct MyStruct {}

    pub struct OtherClass {}
}
```

Fuera del ámbito del módulo, se hace referencia a los tipos que están encerrados en módulos anteponiendo al nombre del tipo la sintaxis de dos puntos dobles `::`.
Como alternativa, y de forma más habitual, puedes colocar una directiva `use` al inicio del archivo (o dentro de un módulo) y entonces podrás usar los tipos sin el prefijo.
Dentro del mismo módulo no hace falta calificar los nombres de los tipos.

```rust
mod my_module {
    #[derive(Drop)]
    pub struct MyStruct {}

    pub struct Foo {}

    #[generate_trait]
    pub impl FooImpl of FooTrait {
        fn bar() {
            let baz = MyStruct {};
        }
    }
}

#[derive(Drop)]
pub struct Qux {}

#[generate_trait]
impl QuxImpl of QuxTrait {
    fn box() {
        let nux = my_module::MyStruct {};
    }
}

mod other_module {
    use super::my_module::*;

    #[derive(Drop)]
    pub struct Tix {}

    #[generate_trait]
    pub impl TixImpl of TixTrait {
        fn jeg() {
            let lor = MyStruct {};
        }
    }
}
```

Puedes darle un alias a un módulo o a un tipo con la sintaxis `use core::array::ArrayTrait as Arr;` y luego usar el alias en cualquier lugar donde pudieras usar el módulo o el tipo.
