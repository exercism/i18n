# Instrucciones

Cerca hay una tienda de electrodomésticos llamada «Tech Palace».
El dueño de la tienda instaló hace poco una gran pantalla para mostrar mensajes publicitarios y para dar un saludo especial cuando los clientes escanean sus tarjetas de fidelidad en la entrada.
La pantalla se compone de muchas luces LED pequeñas y puede mostrar varias líneas de texto.

El dueño de la tienda necesita tu ayuda con el código que se usa para generar el texto de la nueva pantalla.

## 1. Crea el mensaje de bienvenida

<!-- markdownlint-disable-next-line MD038 -->
Para la mayoría de los clientes que escanean sus tarjetas de fidelidad, el dueño de la tienda quiere ver en la pantalla `Welcome to the Tech Palace, ` seguido del nombre del cliente en letras mayúsculas.

Implementa la función `welcome_message` que acepta el nombre del cliente como un argumento string corto (`felt252`) y devuelve el mensaje deseado como un `ByteArray`.

```rust
welcome_message("Judy")
// => Welcome to the Tech Palace, JUDY
```

## 2. Agrega un borde llamativo

Para los clientes leales que compran mucho en la tienda, el dueño quiere que la pantalla de bienvenida sea más vistosa agregando una línea de estrellas antes y después del mensaje de bienvenida.
Todavía no se ha decidido cuántas estrellas deben ir en las líneas, así que quiere que eso sea configurable.

Escribe una función `add_border` que acepta un mensaje de bienvenida (un `ByteArray`) y la cantidad de estrellas por línea (de tipo `u32`) como argumentos.
Debe devolver un `ByteArray` que consta de 3 líneas: una línea con la cantidad de estrellas deseada, luego el mensaje de bienvenida tal como se recibió y, por último, otra línea de estrellas.

```rust
add_border("Welcome!", 10)
```

Debe devolver lo siguiente:

```bash
**********
Welcome!
**********
```

## 3. Limpia los antiguos mensajes publicitarios

Antes de instalar esta nueva pantalla, la tienda tenía una pantalla parecida que solo podía mostrar líneas estáticas y no configurables.
El dueño quiere reutilizar algunos de los antiguos mensajes publicitarios en la nueva pantalla.
Sin embargo, los datos ya incluyen un borde de estrellas y algunos espacios en blanco indeseados.
Tu tarea es limpiar los mensajes para que se puedan reutilizar.

Implementa una función `clean_up_message` que acepta el antiguo mensaje publicitario como un `ByteArray`.
La función debe eliminar primero todas las estrellas del texto y, después, quitar los espacios en blanco al principio y al final del texto restante.
Luego, la función debe devolver el mensaje ya limpio.

```rust
let message: ByteArray = "
**************************
*    BUY NOW, SAVE 10%   *
**************************
";

clean_up_message(message)
// => BUY NOW, SAVE 10%
```
