# Acerca de

`when` es la palabra clave para filtrar excepciones. Se coloca después de la sentencia catch y puede tomar una expresión Boolean que contenga cualquier valor que esté en el ámbito en ese momento. No tienen que ser solo miembros de la excepción misma. Si el tipo de la excepción coincide y la expresión se evalúa como true, entonces se ejecuta el bloque asociado a esa sentencia `catch`; de lo contrario, se revisa la siguiente sentencia catch, si es que hay alguna.

```csharp
try
{
    // do stuff
}
catch (Exception ex) when (ex.Message != "")
{
    // output the message when it is not empty
}
catch (Exception ex)
{
    // show stack trace or something.
}
```
