# Introducción

En Haxe, un **array** es una colección de elementos (normalmente) del mismo tipo. Hay tres formas de crear un array en Haxe; ya sea mediante un constructor o mediante una sintaxis de declaración. En Haxe, el primer elemento de un array tiene un índice de cero:

```haxe
var a = [1, 2, 3];
trace(a); // [1,2,3]

// Here the second element is called by index
trace(a[1]); // 2

// The actual first element's index is 0
trace(a[0]); // 1
```

Para crear un array usando un constructor, necesitas pasar el tipo de los elementos que se van a incluir en el array:

```haxe
var a:Array<Int> = [0, 1, 2, 3];
a[1] = "Hello"; // Error: the array a takes integers only
```

Si queremos que un array contenga varios tipos de elementos, agregamos el tipo `Dynamic` al indicador de tipo:

```haxe
var a:Array<Dynamic> = [10, "Bob", true]
```
