# Recursos

Existen muchos recursos en línea gratuitos y excelentes para Lua, entre ellos:

1.  [lua.org][8]
2.  Una introducción detallada y autorizada, muy recomendada, a todos los aspectos de la programación en Lua, escrita por el arquitecto principal de Lua: [Programming in Lua, by Roberto Ierusalimschy][6]
3.  Para consultar una definición oficial del lenguaje Lua, revisa el [Lua 5.4 Reference Manual][7], de R. Ierusalimschy, L. H. de Figueiredo, W. Celes.
4.  [Lua Style Guide][4]
5.  [Learn Lua in 15 minutes][5]
6.  Aunque no se ve muy bonito, el wiki de [lua-users.org][14] contiene mucha información y conocimientos útiles.
7.  Algunas opciones para el linting
    -   [luacheck][12]
    -   [Detecting Undefined Variables][13]
8.  Implementaciones del Language Server Protocol para Lua
    -   [Lua Language Server][9]
    -   [EmmyLua-LanguageServer][10]
