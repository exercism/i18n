# Pistas

## General

- Los bucles `while` se usan para iteración _indefinida_ (no contada).
- Los bucles `for` se usan para iteración _definida_ (contada).
- Las palabras clave `break` y `continue` ayudan a personalizar el comportamiento del bucle.
- `std::to_string()` de la biblioteca `string` se puede usar para convertir un entero a string.

Conocer lo siguiente también te puede ayudar a completar las tareas:

- [`vectors`][vectors]: indexación, tamaño, [`<vector>.emplace_back`][emplace], [`<vector>.pop_back()`][pop].
- [`string`][string]: usar el `+` para concatenar strings, conversión de entero a string, [`to_string`][to\_string].

## 1. Redondear puntajes

- Los bucles `While` seguirán ejecutándose hasta que su condición de prueba se evalúe como `False`.
- `<vector>.back()` devuelve el último elemento de un `vector`.
- `<vector>.pop_back()` elimina el último elemento de un `vector`.

## 2. Estudiantes que no aprueban

- Sí necesitas configurar un contador de resultados e _incrementarlo_; querrás usar `return` para devolver la cantidad de estudiantes que no aprueban cuando termine el bucle.

## 3. Calcular calificaciones con letras

- La puntuación necesaria para no reprobar siempre es 41, ya que una «F» es **<= 40**. El rango de puntajes restante, de 41 al puntaje más alto, debe dividirse en cuatro intervalos iguales, uno por cada calificación con letra.
- Resta 40 al puntaje más alto para obtener el rango total de puntajes que califican para calificaciones con letra (A a D).
- Divide este rango total entre 4 para obtener el tamaño de cada intervalo de calificación.
- Suma este tamaño de intervalo a 40 repetidamente para calcular los límites inferiores de cada calificación con letra.
- `static_cast<int>` sin parámetros debería redondear los incrementos de forma adecuada.
- Se espera que devuelvas un array, no un vector.

## 4. Relacionar nombres con puntajes

- Si ambos contenedores tienen la misma longitud y están ordenados de la misma manera, ¿podrías usar el `index` de uno para obtener un `value` del otro?
- `std::to_string(int)` se puede usar para convertir un número a string.
- No olvides seguir el formato de la salida del ejemplo.

## 5. Un puntaje «perfecto»

- Puede que haya o no un estudiante con un puntaje de 100, y no puedes devolver un string vacío sin revisar **todos** los puntajes.
- Las sentencias de `control flow` `continue` y `break` pueden ser útiles aquí para saltar valores no deseados.
