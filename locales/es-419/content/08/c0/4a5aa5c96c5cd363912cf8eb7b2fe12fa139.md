# Introducción

La construcción orientada a objetos principal en Java es la _clase_, que combina datos (_campos_) y comportamiento (_métodos_).
Los campos y los métodos de una clase se conocen como sus _miembros_.

El acceso a los miembros se puede controlar mediante modificadores de acceso, y los dos más comunes son:

- `public`: cualquier código puede acceder al miembro (sin restricciones).
- `private`: solo el código de la misma clase puede acceder al miembro.

Puedes pensar en una clase como una plantilla para crear instancias de esa clase.
Para crear una instancia de una clase (también conocida como _objeto_), se usa la palabra clave `new`:

```java
class Car {
}

// Create two car instances
Car myCar = new Car();
Car yourCar = new Car();
```

Los campos tienen un tipo y un nombre (definido en camelCase) y se pueden definir en cualquier parte de una clase (por convención, se escriben en PascalCase):

```java
class Car {
    // Accessible by anyone
    public int weight;

    // Only accessible by code in this class
    private String color;
}
```

Opcionalmente, puedes asignarle un valor inicial a un campo.
Si un campo _no_ especifica un valor inicial, se le asigna el valor predeterminado de su tipo.
Los valores de los campos de una instancia se pueden consultar y actualizar con la notación de punto.

```java
class Car {
    // Will be set to specified value
    public int weight = 2500;

    // Will be set to default value (0)
    public int year;
}

Car newCar = new Car();
newCar.weight; // => 2500
newCar.year;   // => 0

// Update value of the field
newCar.year = 2018;
```

Por lo general, los campos privados se actualizan como efecto secundario de llamar a un método.
Esos métodos normalmente no devuelven ningún valor, y en ese caso el tipo de retorno debe ser `void`:

```java
class CarImporter {
    private int carsImported;

    public void importCars(int numberOfCars)
    {
        // Update private field from public method
        carsImported = carsImported + numberOfCars;
    }
}
```
