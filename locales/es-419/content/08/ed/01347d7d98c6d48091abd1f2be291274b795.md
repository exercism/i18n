# Instalación


## Instala GHCup

La forma recomendada de instalar las herramientas de Haskell es a través de [GHCup][ghcup].

Con GHCup puedes gestionar los compiladores que tengas instalados, los gestores de proyectos y paquetes, y el servidor de lenguaje.


## Instala Stack

Para hacer los ejercicios de Exercism solo necesitas Stack.

Para instalar Stack, ejecuta el comando o el script de instalación de GHCup.
Acepta los valores predeterminados, pero indica que también quieres que se instale Stack.

¿Omitiste la instalación de Stack sin querer?
No te preocupes: solo ejecuta `ghcup install stack` después.

GHCup instalará

- **Un compilador** (GHC: el Glasgow Haskell Compiler)

  En rigor, no lo necesitas para Exercism, pero te viene bien cuando quieres experimentar con [GHCi][ghc-guide-ghci] fuera de los directorios de los ejercicios.

- **Cabal**

  Un gestor de proyectos y paquetes.
  No lo necesitas para Exercism.

- **Stack**

  El gestor de proyectos y paquetes que usarás para Exercism.
  Se asegurará de que tengas el compilador y las bibliotecas correctas para cada proyecto (ejercicio) en particular.

Para comprobar que la instalación fue exitosa, ejecuta cualquiera de los dos comandos

- `ghcup list`: si todo salió bien, verás una larga lista de versiones de herramientas, con Stack marcado como instalado
- `stack --version`: si todo salió bien, verás algo como `Version 2.7.5, Git revision ...`


## Consigue la versión correcta de GHC

Stack descargará e instalará GHC automáticamente cuando sea necesario.
Puedes iniciar la instalación y verificarla ejecutando los siguientes comandos en una terminal:

```bash
# Note: it only makes sense to run Stack
# inside projects, so navigate into an
# exercise directory first!
exercism download --exercise=hello-world --track=haskell
cd ~/Exercism/haskell/hello-world
stack ghc -- --version
```

Si esto muestra algo como

```
The Glorious Glasgow Haskell Compilation System, version 8.8.4
```

entonces GHC está instalado correctamente.


## Configura tu editor para trabajar con Haskell

El soporte para Haskell lo proporciona el Haskell Language Server (HLS).
El soporte del lenguaje no es obligatorio, pero es muy recomendable.


### Visual Studio Code (recomendado)

Solo tienes que instalar la [extensión de Haskell para Visual Studio Code][vscode-haskell].
Usará GHCup para instalar HLS automáticamente y, con eso, ya estarás listo.

**Nota:** con ejercicios recién descargados, HLS puede tener problemas para iniciarse.
Si eso pasa, ejecuta `stack test` y reinicia el servidor de lenguaje.


### Otros editores

Consulta la [documentación de HLS sobre la configuración del editor][hls-editor-config].
Puede que necesites instalar HLS manualmente.
Para hacerlo, ejecuta `ghcup install hls`.
