# Acerca de

En Go, podemos comparar valores usando los operadores de igualdad y de orden.
Tenemos 6 de estos operadores:

| Comparación       | Operador  |
| ------------------| --------- |
| igual             | `==`      |
| no es igual       | `!=`      |
| menor             | `<`       |
| menor o igual     | `<=`      |
| mayor             | `>`       |
| mayor o igual     | `>=`      |

El resultado de una comparación siempre es un valor Boolean:

```go
a := 3

a != 4 // true
a > 5  // false
```

## Operadores de igualdad

Los operadores de igualdad `==` y `!=` verifican, respectivamente, si un valor es igual a otro o no.
Podemos usar los operadores de igualdad con la mayoría de los tipos en Go.
Aquí hay algunos ejemplos comunes:

```go
2 == 3 // false, integer comparison

2.1 != 2.2 // true, float comparison 

"hello" == "hello" // true, string comparison

'a' != 'b' // true, rune/byte comparison
```

## Operadores de orden

Los operadores de orden verifican si un valor es mayor que (`>`), mayor o igual que (`>=`), menor que (`<`) y menor o igual que (`<=`) que otro valor.
Este tipo de comparación está disponible para números, bytes, runes y strings.
Al comparar strings, se sigue el orden del diccionario (también conocido como orden lexicográfico).

```go
2 > 3 // false, integer comparison

1.2 < 1.3 // true, float comparison

'a' > 'b' // false, rune/byte comparison

"Hello" < "World" // true, string comparison
```
