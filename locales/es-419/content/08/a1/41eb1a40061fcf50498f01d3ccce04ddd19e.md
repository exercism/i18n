# Introducción

El control de flujo en Cairo te permite controlar la ruta de ejecución de tus programas según condiciones y repetición.

## Ejecución condicional

Usa expresiones `if` para ejecutar código según condiciones:

```rust
let number = 42;
if number > 0 {
    println!("Positive number");
} else if number < 0 {
    println!("Negative number");  
} else {
    println!("Zero");
}
```

`if` es una expresión, por lo que puede devolver valores:

```rust
let result = if condition { 5 } else { 10 };
```

## Bucles

Usa `loop` para repetir código.
Un bucle se ejecuta indefinidamente a menos que lo detengas; usa `break` para salir del bucle cuando se cumpla una condición.

```rust
let mut counter = 0;
loop {
    if counter == 5 {
        break;
    }
    println!("Counter: {}", counter);
    counter += 1;
}
```

Los bucles pueden devolver valores usando `break`:

```rust
let result = loop {
    counter += 1;
    if counter == 10 {
        break counter * 2; // Returns 20
    }
};
```

Usa `continue` para saltar a la siguiente iteración:

```rust
let mut i = 0;
loop {
    i += 1;
    if i % 2 == 0 {
        continue; // Skip even numbers
    }
    if i > 10 {
        break;
    }
    println!("{}", i); // Only prints odd numbers
}
```
