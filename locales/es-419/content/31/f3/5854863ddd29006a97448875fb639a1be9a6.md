# Instrucciones

Eres un gran aficionado a los trenes a escala y has decidido compartir tu pasión con el mundo lanzando un boletín. Empezarás enviando el primer número de tu boletín a tus amigos y conocidos que comparten tu afición. Tienes un archivo de texto con una lista de sus direcciones de correo electrónico.

## 1. Lee las direcciones de correo electrónico desde un archivo

Implementa la función `Newsletter.read_emails/1`. Debe recibir una ruta de archivo. El archivo es un archivo de texto que contiene direcciones de correo electrónico separadas por saltos de línea. La función debe devolver una lista con las direcciones de correo electrónico del archivo.

```elixir
Newsletter.read_emails("/home/my_user/documents/model_train_friends_emails.txt")
# => ["rick@example.com", "choochoo42@example.com", "anna@example.com"]
```

## 2. Abre un archivo de registro para escribir en él

Enviar un correo electrónico es una tarea que puede fallar por muchas razones impredecibles, como un error de escritura en la dirección de correo o problemas temporales de red. Para asegurarte de que puedes reintentar el envío de los correos a todos tus amigos sin enviar duplicados, necesitas registrar las direcciones de correo que ya recibieron el correo. Para esto, necesitarás un archivo de registro.

Implementa la función `Newsletter.open_log/1`. Debe recibir una ruta de archivo, abrir el archivo para escribir en él y devolver el PID del proceso que maneja el archivo.

```elixir
Newsletter.open_log("/home/my_user/documents/newsletter_issue1_log.txt")
# => #PID<0.145.0>
```

## 3. Registra un correo electrónico enviado

Implementa la función `Newsletter.log_sent_email/2`. Debe recibir un PID del proceso que maneja el archivo y una cadena con la dirección de correo electrónico. Debe escribir la dirección de correo en el archivo, seguida de un salto de línea.

```elixir
Newsletter.log_sent_email(pid, "joe@example.com")
# => :ok
```

## 4. Cierra el archivo de registro

Implementa la función `Newsletter.close_log/1`. Debe recibir un PID del proceso que maneja el archivo y cerrar el archivo.

```elixir
Newsletter.close_log(pid)
# => :ok
```

## 5. Envía el boletín

Ahora que tienes todas las piezas del procedimiento de envío de correos, necesitas combinarlas en una sola función.

Implementa la función `Newsletter.send_newsletter/3`. Debe recibir una ruta del archivo con las direcciones de correo electrónico, una ruta de un archivo de registro y una función anónima que envía un correo electrónico a una dirección de correo dada. Debe leer todas las direcciones de correo del archivo dado e intentar enviar un correo a cada una de ellas. Si la función anónima que envía el correo devuelve `:ok`, escribe la dirección de correo en el archivo de registro, seguida de un salto de línea. Asegúrate de hacerlo en cuanto se envíe el correo. Cuando termines de enviar todo, cierra el archivo de registro.

```elixir
Newsletter.send_newsletter(
  "model_train_friends_emails.txt",
  "newsletter_issue1_log.txt",
  fn email -> :ok end
)

# => :ok
```
