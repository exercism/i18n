# Apéndice de instrucciones

## Implementación

Define una sola función, SolvePuzzle, que devuelve una solución con dos strings, cuyos valores son las respuestas a las preguntas del rompecabezas de la cebra «¿Quién bebe agua?» y «¿Quién es el dueño de la cebra?». Cada respuesta será una de las nacionalidades de los residentes: Englishman, Spaniard, Ukrainian, Norwegian o Japanese.

Obviamente, podrías simplemente escribir una función de una sola línea si le echas un vistazo al programa de pruebas para ver la solución esperada. Pero el objetivo es desarrollar un algoritmo que use los datos y las restricciones que se dan para el rompecabezas y determine las dos respuestas correctas.
