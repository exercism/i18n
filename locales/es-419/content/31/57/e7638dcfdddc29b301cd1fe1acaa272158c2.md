# Pistas

## General

- Lee sobre [la recursión de la mano del creador de Elm][recursion].
- Usa la coincidencia de patrones con expresiones `case`.
- Intenta dividir un problema en un caso base y un caso recursivo. Por ejemplo, supongamos que quieres contar cuántas galletas hay en el frasco de galletas con un enfoque recursivo. Un caso base es un frasco vacío: tiene cero galletas. Si el frasco no está vacío, entonces la cantidad de galletas que hay en él es igual a una galleta más la cantidad de galletas que quedan en el frasco después de sacar una galleta.

## 1. Verifica cuántos pájaros visitaron hoy

- Esta tarea no necesita recursión.
- Puedes acceder al primer elemento de una lista con coincidencia de patrones y una expresión `case`.
- Recuerda envolver el resultado en `Just` cuando devuelvas un valor.

## 2. Incrementa el conteo de hoy

- Esta tarea no necesita recursión.
- Puedes acceder al primer elemento de una lista con coincidencia de patrones y una expresión `case`.
- Usa el [operador `::`][list-cons] para desarmar y volver a armar la nueva lista.

## 3. Verifica si hubo un día sin pájaros visitantes

- Usa recursión para iterar sobre los elementos de la lista hasta encontrar un día sin pájaros visitantes.
- Los casos base son una lista vacía o un día sin pájaros.
- Usa coincidencia de patrones para verificar si hay un `0` en la lista.

## 4. Calcula el total de pájaros visitantes

- Usa recursión para iterar sobre cada elemento de la lista.
- El caso base es una lista vacía.
- Usa el operador `+` para sumar el elemento actual al total del resto.

## 5. Calcula la cantidad de días ocupados

- Usa recursión para iterar sobre cada elemento de la lista.
- El caso base es una lista vacía.
- Usa una expresión `if` para verificar si el día actual es un día ocupado (5 pájaros o más).
- Suma 1 al conteo de días ocupados del resto de la lista cuando encuentres un día ocupado.
