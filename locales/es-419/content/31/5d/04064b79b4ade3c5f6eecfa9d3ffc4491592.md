# usa el marcador de posición de fmt para un string

En Go, se suele preferir marcadores de posición específicos de tipo en lugar del genérico `%%v`.
Hay dos razones para esto. La primera es que los marcadores más específicos a menudo tienen opciones adicionales;
por ejemplo, el formato `%%f` para valores `float` también puede especificar la precisión: `%%.2f`.
La segunda razón es que `%%v` acepta cualquier tipo de valor. Si el tipo de una variable cambia durante una refactorización,
`%%v` imprimirá el valor predeterminado de ese tipo, que puede que no sea el comportamiento deseado.
Un marcador de posición específico de tipo hará que el linter se queje, y así detecta el error antes de que llegue a producción.
