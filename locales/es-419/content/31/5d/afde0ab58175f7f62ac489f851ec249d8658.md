# Acerca de

Las [clases](https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/classes) son la construcción principal para hacer programación orientada a objetos en F#.

Una clase en F# está formada por sus campos y sus métodos. Los campos y los métodos de una clase se conocen como sus _miembros_.

Las clases en F# se definen con la palabra clave `type`. Los métodos se definen con la palabra clave `member` y siempre son públicos. Para definir campos (privados), se pueden usar enlaces `let`.

```fsharp
type Shoe() =
    let size = 8

    member this.Describe() = $"This is a size {size} shoe"
```

Las clases son plantillas para crear objetos. Para crear una instancia de una clase, invoca el nombre de la clase como si fuera una función. Una instancia de una clase también se conoce como _objeto_.

Se puede acceder a los miembros de un objeto con la notación de punto.

```fsharp
let myShoe = Shoe()
myShoe.Describe()
// => "This is a size 8 shoe"
```
