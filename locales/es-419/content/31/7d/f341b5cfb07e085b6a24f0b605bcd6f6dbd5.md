# Instalación

## Instala Node.js

**Usuarios de Windows y OS X**: instala [Node.js][node] [a través del gestor de paquetes][node-download].

**Usuarios de Linux**: instala [Node.js][node] con las instrucciones que encuentres para tu distribución en el [gestor de paquetes de Node.js][linstall].

## Instala `jasmine-node` y `coffeescript`

Para la mayoría de los usuarios esto será tan simple como ejecutar el siguiente comando:

```bash
$ npm install -g jasmine-node coffeescript
```

Según tu configuración, es posible que necesites privilegios de superusuario para instalar un módulo de `npm` de forma global.
Ese es el caso si usaste el instalador oficial enlazado arriba.
Si NPM te da un error diciendo que no tienes acceso, agrega `sudo` al comando de arriba:

```bash
$ sudo npm install -g jasmine-node coffeescript
```

Si usaste el instalador oficial, tu `PATH` debería haberse configurado automáticamente, pero si tu shell tiene problemas para localizar tus módulos instalados globalmente, o si compilaste Node.js desde el código fuente, actualiza tu `PATH` para incluir los binarios de `npm` agregando lo siguiente a `~/.bash_profile` o a `~/.zshrc`:

```bash
$ export PATH=/usr/local/share/npm/bin:$PATH
```
