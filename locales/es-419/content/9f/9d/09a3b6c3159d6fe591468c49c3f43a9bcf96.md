# Estructuras

Las estructuras son tipos de datos personalizados que te permiten nombrar y agrupar varios valores relacionados.
Son similares a las tuplas, pero más flexibles y te permiten nombrar cada dato, lo que hace que tu código sea más claro.
Las estructuras en Cairo tienen estas propiedades:

- Cada tipo de estructura tiene un nombre particular.
- Cada miembro de una estructura se llama **campo**.
- Cada campo de una estructura tiene un nombre particular.
- La visibilidad se controla a nivel de campo: cada campo puede ser público o privado de forma independiente.

## Definición e instanciación de estructuras

Para definir una estructura, usa la palabra clave `struct` seguida de un nombre y llaves que contengan los campos con sus nombres y tipos:

```rust
#[derive(Drop)]
struct User {
    active: bool,
    username: ByteArray,
    email: ByteArray,
    sign_in_count: u64,
}
```

Para crear una instancia de una `struct`, especifica el nombre de la `struct` y usa llaves con pares clave-valor para los campos.
Ten en cuenta que puedes listar los campos en cualquier orden al crear una instancia:

```rust
let user1 = User {
   active: true, username: "someusername123", email: "someone@example.com", sign_in_count: 1
};

let user2 = User {
    sign_in_count: 1, username: "someusername123", active: true, email: "someone@example.com"
};
```

## Interacción con una instancia de una estructura

Usa la notación de punto para acceder a los campos de una instancia de `struct` o modificarlos.
Ten en cuenta que, para modificar un campo, la instancia debe ser mutable:

```rust
let mut user1 = User {
    active: true, username: "someusername123", email: "someone@example.com", sign_in_count: 1
};
user1.email = "anotheremail@example.com";
```

Como con cualquier expresión, podemos construir una nueva instancia de la `struct` como la última expresión del cuerpo de la función para devolver implícitamente esa nueva instancia:

```rust
fn build_user(email: ByteArray, username: ByteArray) -> User {
    User {
        email: email,
        username: username,
        active: true,
        sign_in_count: 1,
    }
}
```

## Inicialización abreviada de campos

En el último ejemplo tenía sentido nombrar los parámetros `email` y `username` de la función con los mismos nombres que los campos de la `struct`, pero tener que repetirlos al asignarlos a los campos de la estructura es un poco tedioso.
Por suerte, existe una forma abreviada conveniente para inicializar los campos de una estructura a partir de variables con los mismos nombres:

```rust
fn build_user_short(email: ByteArray, username: ByteArray) -> User {
    User { email, username, active: true, sign_in_count: 1, }
}
```

## Creación de instancias a partir de otras instancias con la sintaxis de actualización de estructuras

Usa la sintaxis de actualización de estructuras para crear una nueva instancia a partir de una existente, cambiando algunos de los campos y manteniendo el resto igual.
Esto se logra usando el operador `..`.

Sin la sintaxis de actualización:

```rust
let user2 = User {
    active: user1.active,
    username: user1.username,
    email: "another@example.com",
    sign_in_count: user1.sign_in_count,
};
```

Con la sintaxis de actualización:

```rust
let user2 = User { email: "another@example.com", ..user1 };
```

La sintaxis `..user1` copia los campos restantes de `user1` a `user2`.
Ten en cuenta que esto mueve los datos de `user1` a `user2`, así que `user1` no se puede usar después si contiene tipos no copiables.
