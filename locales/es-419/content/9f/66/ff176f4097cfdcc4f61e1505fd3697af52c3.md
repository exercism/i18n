# Instrucciones

En este ejercicio vas a procesar líneas de log.

Cada línea de log es un string con el siguiente formato: `"[<LEVEL>]: <MESSAGE>"`.

Hay tres niveles de log diferentes:

- `INFO`
- `WARNING`
- `ERROR`

Tienes tres tareas; cada una recibe una línea de log y te pide hacer algo con ella.

## 1. Obtén el mensaje de una línea de log

Implementa el método (_static_) `LogLevels.message()` para devolver el mensaje de una línea de log:

```java
LogLevels.message("[ERROR]: Invalid operation")
// => "Invalid operation"
```

Los espacios en blanco al inicio o al final se deben eliminar:

```java
LogLevels.message("[WARNING]:  Disk almost full\r\n")
// => "Disk almost full"
```

## 2. Obtén el nivel de log de una línea de log

Implementa el método (_static_) `LogLevels.logLevel()` para devolver el nivel de log de una línea de log, que debe devolverse en minúsculas:

```java
LogLevels.logLevel("[ERROR]: Invalid operation")
// => "error"
```

## 3. Reformatea una línea de log

Implementa el método (_static_) `LogLevels.reformat()` que reformatea la línea de log, poniendo el mensaje primero y el nivel de log después, entre paréntesis:

```java
LogLevels.reformat("[INFO]: Operation completed")
// => "Operation completed (info)"
```
