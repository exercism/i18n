# Pistas

## 1. Obtén todos los vinos de un color dado

- Los argumentos de palabra clave se especifican escribiendo un nombre antes del nombre del argumento, separados por un espacio.
- La función [`list.filter`][list-filter] se puede usar para seleccionar de una lista los elementos que cumplan con un predicado dado.

## 2. Obtén todos los vinos de un color dado embotellados en un año dado

- Los argumentos de palabra clave se especifican escribiendo un nombre antes del nombre del argumento, separados por un espacio.
- La función [`list.filter`][list-filter] se puede usar para seleccionar de una lista los elementos que cumplan con un predicado dado.

## 3. Obtén todos los vinos de un color dado embotellados en un país dado

- Esta función se puede implementar llamando a `wines_from_country` y después a `wines_of_color` sobre el resultado.

[list-filter]: https://hexdocs.pm/gleam_stdlib/gleam/list.html#filter
