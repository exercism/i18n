# Instrucciones

Continuando con tu trabajo en el parque de diversiones, tu tarea es escribir algunos métodos de utilidad que ayuden a comprobar si un visitante puede usar una atracción.

## 1. Comprueba si un visitante tiene un pase para la atracción

Implementa el método `Attendee#has_pass?` para que devuelva un valor Boolean (`true`/`false`) según la presencia de un pase para la atracción.

```ruby
Attendee.new(100).has_pass?
# => false
```

## 2. Comprueba si un visitante cumple con la altura requerida para la atracción

Implementa el método `Attendee#fits_ride?` para ver si un visitante cumple con la altura requerida para la atracción según su altura.
La altura mínima requerida para la atracción se proporciona como argumento.
La altura de un visitante debe ser mayor o igual a la altura mínima requerida para la atracción.

```ruby
Attendee.new(140).fits_ride?(100)
# => true
```

## 3. Comprueba si un visitante puede subirse a la atracción

Implementa el método `Attendee#allowed_to_ride?` para ver si un visitante puede subirse a una atracción. La altura mínima requerida para la atracción se proporciona como argumento. Un visitante debe tener un pase para la atracción y cumplir con la altura requerida.

```ruby
attendee = Attendee.new(100)
attendee.issue_pass!(42)
attendee.allowed_to_ride?(120)
# => false
```
