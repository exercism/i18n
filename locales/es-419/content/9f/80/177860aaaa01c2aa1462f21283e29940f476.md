# Instrucciones

Estás ayudando a un amigo a generar un informe a partir de las lecturas que tomó en distintos rincones de su jardín.
Lamentablemente, tu amigo guardó los datos en un formato extraño.
Cada lectura es un conjunto de campos separados por comas.
Sin embargo, guardó los números de dos dígitos repartidos en dos columnas.

| número del campo | significado |
| --- | --- |
| 1 | número de ID |
| 2 | ubicación |
| 3 | primera lectura, valor de las decenas |
| 4 | primera lectura, valor de las unidades |
| 5 | segunda lectura, valor de las decenas |
| 6 | segunda lectura, valor de las unidades |

Para una fila de entrada como `101,house,4,2,5,4`
- la primera lectura es `42`,
- la segunda lectura es `54`.

## Tarea 1: Genera el informe

Tu tarea es encontrar el promedio de las dos lecturas y mostrar los resultados de cada fila en el siguiente formato

```none
#<id>, <label> = <average>
```

Como el promedio de 42 y 54 es 48, el resultado de la fila de ejemplo debería ser:

```none
#101, house = 48
```
