# Apéndice de instrucciones

## Implementación

Define
`type Classification`
para contener los valores de clasificación de los números naturales.
Puedes elegir cualquier representación para este tipo.

Define tres constantes Classification llamadas

```text
	ClassificationDeficient
	ClassificationPerfect
	ClassificationAbundant
```

Implementa una función llamada Classify que acepta
un argumento de tipo int64 y devuelve una Classification y un valor de error.

Crea un error llamado ErrOnlyPositive
que se devuelve cuando el argumento no es un número entero positivo.
