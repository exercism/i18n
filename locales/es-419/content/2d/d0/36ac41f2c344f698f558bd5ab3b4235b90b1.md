# Instrucciones

Estás ayudando con un estudio de aves. Cada día alguien se sienta en un observatorio y cuenta lo que pasa volando, y los conteos del día llegan en un array.

Las cinco tareas van en la clase `BIRD_SURVEY`.

## 1. El total

Suma el conteo de cada día.

```sather
BIRD_SURVEY::total_seen(|3, 0, 7|)
-- => 10
```

Un estudio sin ningún día cuenta cero aves.

## 2. El mejor día

Devuelve el conteo más grande. Si no hubo días, la respuesta es cero.

```sather
BIRD_SURVEY::busiest_day(|3, 0, 7|)
-- => 7
```

## 3. Los días con más actividad

¿Cuántos días tuvieron un conteo por encima de cierto número?

```sather
BIRD_SURVEY::days_over(|3, 0, 7|, 2)
-- => 2
```

Por encima significa por encima: un conteo de exactamente 2 no se cuenta.

## 4. Observatorios por revisar

El primer día del estudio revisas un observatorio, el segundo día dos, y así sucesivamente. ¿Cuántas revisiones de observatorios son en total?

```sather
BIRD_SURVEY::hides_to_check(4)
-- => 10
```

Eso es 1 + 2 + 3 + 4.

## 5. El primer día con más actividad

¿Cuál fue el primer día con un conteo por encima de cierto número? Los días se numeran desde cero, igual que las posiciones de un array. Si ningún día tuvo tanta actividad, la respuesta es `-1`.

```sather
BIRD_SURVEY::first_busy_day(|3, 0, 7|, 5)
-- => 2
BIRD_SURVEY::first_busy_day(|3, 0, 7|, 9)
-- => -1
```
