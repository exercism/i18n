# Agencia de diseño web

## Historia

Tu empresa de diseño ha estado trabajando principalmente con transformaciones CSS para crear páginas web. Después de algunas conversaciones, se decide empezar a usar JavaScript para realizar algunos de los cálculos de forma dinámica. Algunos de tus compañeros de equipo tienen menos experiencia con JavaScript, así que decides usar un closure de función para crear una transformación reutilizable para pares de coordenadas `{x, y}`.

## Tareas

- Crea una función cuyos argumentos se usen como closure en la función que esta devuelve.

  - Una función para una traslación 2D, donde la función externa especifica cuánto trasladar y la función que devuelve acepta una coordenada x, y y devuelve las coordenadas trasladadas.
  - Una función para un escalado 2D, donde la función externa especifica cuánto escalar y la función que devuelve acepta una coordenada x, y y devuelve las coordenadas trasladadas.
  - Una función que devuelve una función que compone dos funciones; en efecto, una función para `g(f(x))`

- Crea una función que memorice a otra función.
