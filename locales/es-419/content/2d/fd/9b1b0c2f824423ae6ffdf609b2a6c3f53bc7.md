# Instrucciones

Estás trabajando en un juego dirigido a un sistema embebido de bajo consumo y necesitas escribir varias funciones de utilidad que usarán otras partes del juego.

## 1. Calcula el cociente y el residuo de una división

Un cociente es el resultado de una división.

```rust
fn divmod(dividend: i16, divisor: i16) -> (i16, i16)
```

Ejemplo:

```rust
assert_eq!(divmod(10, 3), (3, 1));
```

## 2. Elige los elementos en posiciones pares de un iterador

Tu jefe promete que esto te ayudará a habilitar una optimización del búfer de pantalla.

Los iteradores son elementos que exponen los métodos definidos por el trait [`Iterator`](https://doc.rust-lang.org/std/iter/trait.Iterator.html). Esa documentación es bastante extensa, porque ofrecen muchos métodos; estas son las propiedades más relevantes:

- Un iterador es un flujo de elementos de longitud arbitraria
- Tienen un [método `enumerate`](https://doc.rust-lang.org/std/iter/trait.Iterator.html#method.enumerate) que devuelve una tupla `(i, val)` para cada valor
- Tienen un [método `filter`](https://doc.rust-lang.org/std/iter/trait.Iterator.html#method.filter) que usa un closure para determinar si se debe producir un elemento del iterador
- Tienen un [método `map`](https://doc.rust-lang.org/std/iter/trait.Iterator.html#method.map) que usa un closure para modificar los elementos del iterador

Como tu función puede ejecutarse con cualquier tipo de iterador, usa `impl` para indicar que esto es una instancia de un trait en lugar de un elemento simple. De igual manera, la sintaxis `<Item=T>` solo significa que no importa qué tipo de elemento produzca el iterador; tu función puede producir los elementos en posición par de cualquier iterador.

```rust
fn evens<T>(iter: impl Iterator<Item=T>) -> impl Iterator<Item=T>
```

Ejemplos:

```rust
let mut even_ints = evens(0_u8..);
assert_eq!(even_ints.next(), Some(0));
assert_eq!(even_ints.next(), Some(2));
assert_eq!(even_ints.next(), Some(4));
assert_eq!(even_ints.next(), Some(6));
```

```rust
let mut evens_from_odds = evens(1_i16..);
assert_eq!(evens_from_odds.next(), Some(1));
assert_eq!(evens_from_odds.next(), Some(3));
assert_eq!(evens_from_odds.next(), Some(5));
assert_eq!(evens_from_odds.next(), Some(7));
```

## 3. Calcula la distancia Manhattan de una posición respecto al origen

Por comodidad para el mapeo, tienes una estructura de tupla `Position`:

```rust
struct Position(i16, i16);
```

Necesitas implementar un método `manhattan` en `Position` que devuelve la [distancia Manhattan](https://en.wikipedia.org/wiki/Taxicab_geometry) de esa posición respecto al origen (`Position(0, 0)`).

```rust
impl Position {
    fn manhattan(&self) -> i16
}
```

Ejemplo:

```rust
assert_eq!(Position(3, 4).manhattan(), 7);
```
