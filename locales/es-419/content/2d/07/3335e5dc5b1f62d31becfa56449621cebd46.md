# Introducción

## Fundamentos

Nos referiremos al _lenguaje_ como **AWK** y al _ejecutable_ que interpreta los programas de AWK como **`awk`** o **`gawk`**.

### Patrones y acciones

Un programa de AWK se compone de **pares de patrón y acción**

```awk
pattern1 { action1 }
pattern2 { action2 }
...
```

Un **patrón** puede ser un patrón de expresión regular con el que se compara la entrada.
También puede ser cualquier expresión que dé como resultado un valor verdadero o falso.

Una **acción** es uno o más comandos de AWK.
Las llaves que la encierran son obligatorias.

Si el resultado del patrón es _verdadero_, entonces se evalúa la acción correspondiente.

### Registros y campos

AWK analiza la entrada como una serie de **registros**.
Cada registro se divide en cero o más **campos**.

El comportamiento predeterminado es:

- dividir la entrada en registros usando el salto de línea como «separador de registros», así que cada _línea_ es un registro.
- dividir el registro en campos usando los espacios en blanco como «separador de campos», así que cada _palabra_ es un campo.

### Patrones y acciones (continuación)

El patrón se puede omitir, en cuyo caso la acción se evalúa _para cada registro de entrada_.

La acción se puede omitir, en cuyo caso la acción predeterminada es imprimir el registro actual.

#### Patrones especiales

Hay dos patrones especiales que se usan con frecuencia.

- `BEGIN` evaluará la acción asociada antes de que se consuma cualquier entrada.
- `END` evaluará la acción asociada después de que se consuma toda la entrada.

### Variables de campo

Te refieres a los campos como `$1`, `$2`, `$3`, etc.

El registro actual es `$0`.

Aquí tienes otras variables integradas que se usan con frecuencia.

#### Variables integradas que controlan el análisis de la entrada

- `RS` es el separador de registros de la entrada.
  Como se mencionó, su valor predeterminado es un salto de línea.
- `FS` es el separador de campos de la entrada.

Estas variables con frecuencia se establecen en el bloque de acción `BEGIN`.

#### Variables integradas que transmiten información

AWK establece estas variables automáticamente durante la ejecución del programa.

- `NF` guarda el número de campos del registro actual.
  - Para obtener el valor del último campo, usa `$NF`.
- `NR` guarda el número del registro actual.
  - Cuando se procesan varios archivos de entrada, `NR` contendrá el número total de registros procesados hasta el momento.
- `FNR` guarda el número del registro actual del archivo de entrada actual.
  - Para ilustrar la diferencia entre NR y FNR, aquí tienes un modismo común de AWK.
    ```awk
    NR == FNR {action}
    ```
    Esto significa «si el número de registro acumulado es igual al número de registro del archivo actual».
    Esto solo puede ser verdadero para los registros del _primer archivo de entrada_.

### Veracidad

AWK usa el mismo concepto de veracidad que C.

- El número `0` es falso.
- Cualquier otro número es verdadero.

Como AWK es un lenguaje de procesamiento de texto, los valores de verdad se extienden a los string.

- Un string vacío `""` es falso.
- Cualquier string no vacío es verdadero.

### Comentarios

Los comentarios comienzan con el carácter `#` y se extienden hasta el final de la línea.

### Ejemplos

En los sistemas tipo Unix, `/etc/passwd` contiene información sobre los usuarios.
Cada usuario se describe en una línea aparte, con los campos separados por dos puntos.

Para listar los nombres de usuario:

```sh
awk '
    BEGIN { FS = ":" }
    { print $1 }
' /etc/passwd
```

Fíjate que la acción `{print $1}` no tiene patrón, así que se ejecuta para cada registro.

Si queremos limitar la salida a solo los usuarios que usan bash como su shell de inicio de sesión, podemos hacer:

```sh
awk '
    BEGIN { FS = ":" }
    $7 == "/bin/bash" { print $1 }
' /etc/passwd
```
