# Pistas

## General

Las funciones devuelven valores de un tipo específico, así que presta atención.

## 1. Define un vector con nombres

- La información necesaria para los nombres y los valores está en las instrucciones.
- La forma de construir un vector con nombres se explica en detalle en la introducción.

## 2. Devuelve el valor asociado a una banda

- Puedes usar tu vector con nombres `resistor_bands` para lograr esto fácilmente.
- Necesitas devolver únicamente un valor numérico.

## 3. Devuelve el valor asociado a dos bandas

- Tu función `band_value` puede resultarte útil aquí.
- Las pistas sobre indexación de vectores con nombres están en la introducción.
- Hay varias formas de construir el número, las más comunes mediante manipulación de strings o de forma numérica.
- El número devuelto debe ser únicamente un valor numérico.

## 4. Devuelve los ohmios asociados a las tres bandas

- Tanto `band_value` como `two_band_value` son útiles aquí.
- Los dos primeros valores del vector corresponden al valor de dos bandas, mientras que el tercero es el multiplicador.
- De nuevo, es posible usar manipulación de strings o medios numéricos para obtener el número.
- El número devuelto debe ser únicamente un valor numérico.
