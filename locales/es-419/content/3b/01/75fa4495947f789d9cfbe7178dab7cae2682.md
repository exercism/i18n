# Instrucciones

Daphne ha estado trabajando en un sistema para ejecutar y registrar los resultados de sus experimentos. Parte del código se ha vuelto un poco verboso y repetitivo, así que te ha pedido que escribas algunas expresiones `use` para ayudarla a limpiarlo.

## 1. Define la función `with_retry`

A veces los experimentos pueden fallar por un error puntual, así que si un experimento falla, Daphne quiere reintentarlo para ver si funciona la segunda vez.

Define la función `with_retry`, que recibe como argumento una función que devuelve un resultado.

Si la función devuelve un valor `Ok`, `with_retry` debe devolver ese valor.

Si la función devuelve un valor `Error`, `with_retry` debe llamar a la función de nuevo y devolver el resultado de esa llamada.

Daphne usará la función así:

```gleam
pub fn main() {
  use <- with_retry
  // Perform the experiment here
}
```

## 2. Define la función `record_timing`

Daphne registra cuánto tarda cada experimento en ejecutarse llamando a una función de registro de tiempo antes y después de cada experimento.

Define la función `record_timing`, que recibe dos argumentos:
- Una función de registro de tiempo que no recibe argumentos y devuelve `Nil`.
- Una función de experimento que no recibe argumentos y devuelve un resultado.

`record_timing` debe llamar a la función de registro de tiempo, luego llamar a la función de experimento, después llamar de nuevo a la función de registro de tiempo y, por último, devolver el resultado de la función de experimento.

Daphne usará la función así:

```gleam
pub fn main() {
  use <- record_timing(time_logger)
  // Perform the experiment here
}
```

## 3. Define la función `run_experiment`

Los experimentos se componen de tres fases. La configuración, la acción y el registro. Las tres fases devuelven resultados, y cada fase necesita el resultado exitoso de la fase anterior para ejecutarse.

Define la función `run_experiment`, que recibe cuatro argumentos:
- El nombre del experimento como `String`.
- Una función de configuración que no recibe argumentos y devuelve un resultado.
- Una función de acción que recibe como argumento el valor `Ok` de la función de configuración y devuelve un resultado.
- Una función de registro que recibe como argumentos el valor `Ok` de las funciones de configuración y de acción y devuelve un resultado.

Si las tres funciones tienen éxito, `run_experiment` debe devolver `Ok(#(experiment_name, recording_data))`.

Si alguna de las funciones devuelve un valor `Error`, `run_experiment` debe devolver ese valor.

Daphne usará la función así:

```gleam
pub fn main() {
  use setup_data, action_data <- run_experiment("Test 1", setup, action)
  // Record the results here
}
```
