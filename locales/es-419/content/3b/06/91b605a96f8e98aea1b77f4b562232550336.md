# Sentencias `case`

```sather
   case zone
   when 0 then return 0;
   when 1, 2 then return 550;
   else return 920;
   end;
```

## Cómo se compara

El valor que va después de `case` se compara con cada valor de `when` usando `=`, de arriba hacia abajo. La primera coincidencia se ejecuta, y solo esa. Las demás partes `when` se omiten, y la ejecución continúa después del `end`.

Se puede usar cualquier tipo que admita `=`: `INT`, `CHAR`, `STR`, `BOOL`.

## El `else`

Un `case` sin coincidencia y sin `else` genera un error fatal en tiempo de ejecución. Escribe siempre uno. Cuando los casos restantes de verdad no deberían ocurrir, dilo ahí en lugar de omitirlo:

```sather
   else
      raise "unknown zone: " + zone;
   end;
```

`raise` viene después; hasta entonces, devolver un valor predeterminado razonable está bien.

## Cuándo preferir `if`

`case` compara un valor con constantes. Cualquier otra cosa pide `if`:

```sather
   -- ranges
   if age < 13 then ... elsif age < 16 then ... end;

   -- more than one value at a time
   if score >= 8 and sings then ... end;
```

Intentar forzar un rango dentro de un `case` produce algo más largo y peor que el `if` al que reemplaza.

## `case` como expresión

`case` es una sentencia, no una expresión, así que esto no es Sather:

```sather
   -- wrong
   fare := case zone when 1 then 550 else 920 end;
```

Devuelve desde dentro de cada rama, o asigna a una variable dentro de cada rama.
