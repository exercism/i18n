# Instrucciones

En este ejercicio vamos a simular el primer turno de una partida de [Blackjack](https://en.wikipedia.org/wiki/Blackjack).

Recibirás dos cartas y podrás ver la carta descubierta del crupier. Todas las cartas se representan con un string como «ace», «king», «three», «two», etc. Los valores de cada carta son:

| carta | valor | carta | valor |
| :---: | :---: | :---: | :---: |
|  ace  |  11   | eight |   8   |
|  two  |   2   | nine  |   9   |
| three |   3   |  ten  |  10   |
| four  |   4   | jack  |  10   |
| five  |   5   | queen |  10   |
|  six  |   6   | king  |  10   |
| seven |   7   | other |   0   |

**Nota**: Por lo general, los ases pueden tomar el valor de 1 o 11, pero por simplicidad asumiremos que solo pueden tomar el valor de 11.

Según tus dos cartas y la carta del crupier, existe una estrategia para el primer turno del juego, en la que tienes las siguientes opciones:

    - Plantarse (S)
    - Pedir (H)
    - Separar (P)
    - Ganar automáticamente (W)

Aunque todavía no es óptima, vas a seguir la estrategia que tu amigo Alex ha estado desarrollando, que es la siguiente:

Categoría: Mano grande

- Si tienes un par de ases, siempre debes separarlos.
- Si tienes un Blackjack (dos cartas que suman un valor de 21) y el crupier no tiene un as, una figura o un diez, ganas automáticamente. Si el crupier tiene alguna de esas cartas, tendrás que plantarte y esperar a que se revele la otra carta.

Categoría: Mano pequeña

- Si tus cartas suman 17 o más, siempre debes plantearte.
- Si tus cartas suman 11 o menos, siempre debes pedir carta.
- Si tus cartas suman un valor dentro del rango [12, 16], siempre debes plantearte, a menos que el crupier tenga un 7 o más; en ese caso, siempre debes pedir carta.

La lógica general ya está implementada. Tienes cuatro tareas:

## 1. Calcula el puntaje de cualquier carta.

Implementa una función que calcule el valor numérico de una carta a partir de su nombre, usando condicionales.

```java
parseCard("ace")
// returns 11
```

## 2. Determina si dos cartas forman un Blackjack.

Implementa una función que devuelva `true` si dos cartas forman un Blackjack y `false` en caso contrario.

```java
isBlackjack("queen", "ace")
// returns true
```

## 3. Implementa la lógica de decisión para puntajes de mano mayores a 20 puntos.

Implementa una función que devuelva la representación en string de una decisión dadas tus cartas. Esta función solo se llama si el `handScore` es mayor que 20. Recibirá 2 argumentos: `isBlackJack` y `dealerScore`. Debe implementar los puntos enumerados en la categoría «Mano grande» de arriba.

```java
isBlackJack = true
dealerScore = 7
largeHand(isBlackJack, dealerScore)
// returns "W"
```

## 4. Implementa la lógica de decisión para puntajes de mano menores a 21 puntos.

Implementa una función que devuelva la representación en string de una decisión dadas tus cartas. Esta función solo se llama si el `handScore` es menor que 21. Recibirá 2 argumentos: `handScore` y `dealerScore`. Debe implementar los puntos enumerados en la categoría «Mano pequeña» de arriba.

```java
handScore = 15
dealerScore = 12
SmallHand(handScore, dealerScore)
// returns "H"
```
