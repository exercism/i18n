# Pistas

## 1. Crea un array nuevo

- Puedes encontrar cómo definir un array vacío en [esta página][create-and-initialize].

## 2. Define un array existente

- Puedes encontrar cómo definir e inicializar un array con varios elementos en [esta página][create-and-initialize].

## 3. Agrega un lenguaje nuevo a un array

- Existe un [operador integrado][cons] para agregar un elemento al inicio de un array.

## 4. Cuenta los lenguajes del array

- Hay una función en el módulo `List` para [contar los elementos de un array][length].

## 5. Invierte el array

- Hay una función en el módulo `List` para [invertir un array][reverse].

## 6. Comprueba si el array es emocionante

- Puedes usar la coincidencia de patrones con los patrones [cons][cons-pattern] y [array][list-pattern] para hacer coincidir estructuras de array específicas.
