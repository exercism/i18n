# Acerca de

Uno de los aspectos clave al trabajar con números en C# es la distinción entre números enteros (números sin dígitos después del separador decimal) y números de punto flotante (números con cero o más dígitos después del separador decimal).

Los dos tipos numéricos más usados en C# son `int` (un entero de 32 bits) y `double` (un número de punto flotante de 64 bits).

```csharp
int i = 123;
double d = 54.29;
```

Tanto los números enteros como los de punto flotante pueden usar el carácter `_` como _separador de dígitos_, lo que puede ayudar al definir números grandes:

```csharp
int largeInt = 1_000_000;
// => 1000000

double largeDouble = 9_876_543.21;
// => 9876543.21
```

La aritmética se realiza con los [operadores aritméticos][arithmetic-operators] estándar (`+`, `-`, `*`, etc.). Los números se pueden comparar con los [operadores de comparación][comparison-operators] estándar (`<`, `>=`, etc.) y el operador de [igualdad][equality-operators] (`==`) y el operador de [desigualdad][equality-operators] (`!=`).

```csharp
5 * 6;
// => 30

1.2 > 0.8
// => true

2 != 4
// => true
```

Al convertir entre tipos numéricos, hay dos tipos de conversiones numéricas:

1. Conversiones implícitas: no se pierden datos y no se requiere sintaxis adicional.
2. Conversiones explícitas: se podrían perder datos y se requiere sintaxis adicional en forma de un _cast_.

Como un `int` tiene menos precisión que un `double`, convertir de un `int` a un `double` es seguro y por lo tanto es una conversión implícita. Sin embargo, convertir de un `double` a un `int` podría significar perder datos, así que requiere una conversión explícita.

```csharp
int i = 9;
double d = 2.66;

// Safe conversion, thus implicit conversion
double fromInt = i;

// Potentially unsafe conversion, thus explicit conversion
int fromDouble = (int)d;
```
