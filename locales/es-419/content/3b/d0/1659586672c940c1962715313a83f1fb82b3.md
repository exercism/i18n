# Instrucciones

Una amistad tuya te acaba de enviar un mensaje con un secreto importante.
Como no quería que a otras personas les resultara fácil leerlo, el mensaje se cifró mediante una serie de manipulaciones de bits.
Vas a tener que escribir las funciones que ayuden a descifrar el mensaje.

## 1. Desplaza los bits hacia atrás

El primer paso para descifrar el mensaje es deshacer el desplazamiento que hizo el proceso de cifrado, desplazando los bits de vuelta hacia la derecha.
Más adelante, el proceso de descifrado tendrá otros pasos que dan por hecho que se insertan ceros desde el lado izquierdo.

Implementa la función `shift_back()` que recibe un valor y el número de posiciones que hay que desplazar, y realiza el desplazamiento.

```julia
shift_back(0b1001, 2) # => 0b0010
```

## 2. Establece algunos bits

Luego, hay algunos bits que deben establecerse en 1.

Implementa la función `set_bits()` que recibe un valor y una máscara, y devuelve el resultado de establecer en 1 los bits del valor.
Un bit de `value` debe establecerse en 1 cuando el bit correspondiente de la `mask` también es 1.
Todos los demás bits deben quedar sin cambios.

```julia
set_bits(0b0110, 0b0101) # => 0b0111
```

## 3. Invierte bits específicos

Algunos bits se invierten durante el cifrado.
Habrá que invertirlos de nuevo para descifrar el mensaje.

Implementa la función `flip_bits()` que recibe un valor y la máscara.
La máscara indica cuáles bits del valor hay que invertir.
Si el bit es 1 en `mask`, el bit se invierte en el `value`.
Todos los demás bits quedan sin cambios.

```julia
flip_bits(0b1100, 0b0101) # => 0b1001
```

## 4. Limpia bits específicos

Por último, también hay ciertos bits que siempre se descifran como 0.

Implementa la función `clear_bits()` que recibe un valor y una máscara.
Los bits del `value` deben establecerse en 0 cuando el bit correspondiente de la máscara es 1.
Todos los demás bits deben quedar sin cambios.

```julia
clear_bits(0b0110, 0b0101) # => 0b0010
```
