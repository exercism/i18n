# Introducción

## Strings

Recuerda que `jq` admite los mismos tipos de datos que JSON.
JSON describe las **strings** como:

> Una cadena es una secuencia de cero o más caracteres Unicode, encerrada entre comillas dobles y que usa escapes con barra invertida.

### Secuencias de escape

Dentro de una string, usa el carácter de barra invertida para incrustar caracteres "especiales":

- `\"` una comilla doble literal,
- `\\` una barra invertida literal,
- caracteres de espacio en blanco `\n`, `\t`, `\r`, `\f`, `\b`
- caracteres Unicode `\uAAAA` donde `A` es un dígito hexadecimal

### Longitud de una string

Para encontrar el número de caracteres, usa la función `length`.

```sh
$ jq -cn --args  '$ARGS.positional[] | length' "Hello world!" "❄🌡🤧🤒🏥🕰😀"
12
7
```

### Subcadenas

La notación de **rebanada** se puede usar para extraer subcadenas.
La sintaxis es `.[i:j]`.
La subcadena devuelta tiene longitud `j - i` y va desde el índice `i` (incluido) hasta el índice `j` (excluido).
Cualquiera de los índices puede ser negativo, y en ese caso se cuenta hacia atrás desde el final de la string.
Cualquiera de los índices se puede omitir, y en ese caso hace referencia al inicio o al final de la string.
Los índices empiezan en cero.

```jq
"abcdefghij"[3:6]   # => "def"
"abcdefghij"[3:]    # => "defghij"
"abcdefghij"[:-2]   # => "abcdefgh"
```

### Concatenación

Usa `+` para unir strings:

```jq
"Hello" + " " + "world!"
# => "Hello world!"
```

Usa `add` cuando tengas un array de strings:

```jq
["Hello", " ", "world!"] | add
# => "Hello world!"
```

### Dividir y unir

Para dividir se usa la función `split/1` o el operador `/`:

```jq
"Hello beautiful world!" | split(" ")   # => ["Hello", "beautiful", "world!"]
```

```jq
"Hello beautiful world!" / " "          # => ["Hello", "beautiful", "world!"]
```

La inversa de `split/1` es `join/1`.

Convertir una string en un array de caracteres es algo que se necesita con frecuencia.
Hay dos formas de hacerlo:

1. dividir por una string vacía

   ```jq
   "Hi friend 😀" / ""   # => ["H","i"," ","f","r","i","e","n","d"," ","😀"]
   ```

1. usar `explode` para obtener un array de _puntos de código_

   ```jq
   "Hi friend 😀" | explode   # => [72,105,32,102,114,105,101,110,100,32,128512]
   ```

   `implode` es la inversa de `explode`.

### Encontrar el índice de una subcadena

Usa la función `index/1`; el índice empieza en cero.

```jq
"hello" | index("el")'   # => 1
```

Si la subcadena no está en la string, el resultado es `null`

```jq
"hello" | index("elk")   # => null
```

### Interpolación de strings

Dentro de una string, la secuencia `\(expression)` incrusta el _resultado_ de esa expresión [en la string][interpolate]:

```jq
"The current datetime is \(now | strflocaltime("%c"))"   # => "The current datetime is Wed Nov 16 17:06:33 2022"
```

### Conversión de mayúsculas y minúsculas

Usa las funciones `ascii_downcase` y `ascii_upcase`.
