# Recursos de aprendizaje recomendados

Exercism ofrece ejercicios y retroalimentación, pero puede ser difícil empezar para quienes están aprendiendo ABAP por primera vez. Estos recursos gratuitos pueden ayudarte a dar los primeros pasos:

* SAP Learning Journey [Learning the Basics of ABAP Programming](https://learning.sap.com/courses/learn-the-basics-of-abap-programming-on-sap-btp)
* [ABAP for Newbies Community](https://pages.community.sap.com/topics/abap/abap-for-newbies)
* [ABAP Language Documentation](https://help.sap.com/doc/abapdocu_latest_index_htm/latest/en-US/index.htm)
* [ABAP Starter](https://github.com/Keller-Michael/ABAP_starter)
* [ABAP Cheat Sheets](https://github.com/SAP-samples/abap-cheat-sheets)

Si estás empezando con ABAP, te recomendamos completar las siguientes unidades del SAP Learning Journey:

- Getting Started
- ABAP Language Basics
- Local Classes 

Después de eso, ya tendrás lo necesario para resolver ejercicios de ABAP en Exercism.

Si llegas a ejercicios más complejos, te sugerimos que también repases las siguientes unidades:

- Structures
- Complex Internal Tables

Estos temas pueden serte útiles para resolver ejercicios más difíciles en Exercism.
