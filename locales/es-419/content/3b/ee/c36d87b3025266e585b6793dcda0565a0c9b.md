# Instrucciones

Como futura maga, Elyse necesita practicar algunos conceptos básicos.

Tiene una pila de cartas que quiere manipular.

Para que todo sea un poco más fácil, solo usa las cartas del 1 al 10.

La pila de cartas se representa con un `Array`, con la parte inferior de la pila al principio del array y la parte superior al final.

## 1. Inserta una carta en la parte superior de la pila

Implementa la función `insert_top`, que devuelve una copia de la pila con la nueva carta proporcionada agregada en la parte superior de la pila.

```rust
let stack = array![5, 9, 7, 1];
insert_top(stack, 8);
// -> [5, 9, 7, 1, 8]
```

## 2. Quita la carta superior de la pila

Implementa la función `remove_top_card`, que devuelve una copia de la pila después de quitarle la carta superior.

Si la pila dada está vacía, se debe devolver la pila original, sin cambios.

```rust
let stack = array![3, 2, 6, 4, 8];
remove_top_card(stack);
// -> [3, 2, 6, 4]
```

## 3. Inserta una carta en la parte inferior de la pila

Implementa la función `insert_bottom`, que devuelve una copia de la pila con la nueva carta proporcionada agregada en la parte inferior de la pila.

```rust
let stack = array![5, 9, 7, 1];
insert_bottom(stack, 8);
// -> [8, 5, 9, 7, 1]
```

## 4. Quita una carta de la parte inferior de la pila

Implementa la función `remove_bottom_card`, que devuelve una copia de la pila después de quitarle la carta inferior.

Si la pila dada está vacía, se debe devolver la pila original, sin cambios.

```rust
let stack = array![8, 5, 9, 7, 1];
remove_bottom_card(stack);
// -> [5, 9, 7, 1]
```

## 5. Comprueba el tamaño de la pila

Implementa la función `check_size_of_stack`, que comprueba si el tamaño de la pila es igual a un `stack_size` dado o no.

```rust
let stack = array![3, 2, 6, 4, 8];
check_size_of_stack(stack, 4);
// -> false
```
