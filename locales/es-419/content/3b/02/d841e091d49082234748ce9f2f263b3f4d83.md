# Hints

## General

- Hay tres [operadores Boolean][boolean-operators] para trabajar con valores Boolean.
- Se pueden combinar varios operadores en una sola expresión.

## 1. Comprobar si se puede hacer un ataque rápido

- El operador lógico de negación (`!`) se puede colocar delante de una expresión para negar su valor.

## 2. Comprobar si se puede espiar al grupo

- Los operadores Boolean se suelen usar para evaluar si dos o más expresiones son verdaderas o no lo son.

## 3. Comprobar si se le pueden hacer señales a la prisionera

- Los operadores Boolean se ejecutan según su precedencia (de mayor a menor): `!`, `&&`, `||`.
- En general, se recomienda usar paréntesis para que tu intención quede más clara.
- Para más detalles, consulta la sección de precedencia de operadores en la [documentación oficial de Julia][operator-precedence].

## 4. Comprobar si se debe mostrar la opción 'Free Prisoner'

- Los operadores Boolean se ejecutan según su precedencia (de mayor a menor): `!`, `&&`, `||`.
- En general, se recomienda usar paréntesis para que tu intención quede más clara.
