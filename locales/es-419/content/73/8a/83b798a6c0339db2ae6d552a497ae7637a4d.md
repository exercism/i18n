# Introducción

Básicamente hay dos tipos de bucles:

1. Repetir hasta que se cumpla una condición.
2. Recorrer los elementos de una colección.

Ambos son posibles en R, aunque el primero puede ser más común.

## `while` y `repeat`

Para problemas abiertos en los que no se sabe de antemano cuántas veces se repetirá el bucle, R tiene el bucle `while` con una condición y el bucle `repeat` sin condición (equivalente a `while (TRUE)`).

La forma básica es bastante simple:

```R
while (condition) {
  do_something()
}
```

En este caso, el programa seguirá repitiendo el bucle hasta que `condition` ya no sea `TRUE`.

Tienes dos formas de salir del bucle antes de tiempo:

- Un `break` hace que el bucle termine, y la ejecución continúa en la siguiente línea después de la llave de cierre del bucle `}`.
- Un `return(x)` detiene la ejecución de la función actual y devuelve el valor de retorno `x` a quien la llamó.

Con estas opciones disponibles, a veces puede ser conveniente crear un bucle «infinito» con `repeat { ... }`, y luego confiar en encontrar una condición de parada dentro del cuerpo del bucle para provocar un `break` o un `return`.

Estas tres variantes son equivalentes y todas terminan con `x == 0.4444...`

```R
x <- 12
while (x > 1) {
  x <- x / 3
}

x <- 12
while (TRUE) {
  x <- x/3
  if (x <= 1) break
}

x <- 12
# no boolean clause 
repeat { 
  x <- x/3
  if (x <= 1) break
}
```

## Iterar sobre un vector

Esto suele ser innecesario en R.
Como se explicó en otros conceptos, muchas funciones operan sobre vectores completos.

Sin embargo, a veces los bucles explícitos son inevitables.
Esto es especialmente cierto cuando:

- El cuerpo del bucle tiene efectos secundarios, como imprimir o hacer entrada/salida de archivos.
- El bucle continúa hasta alcanzar algún criterio, después de un número impredecible de iteraciones.

La condición del bucle debe ir entre paréntesis.
Como ocurre con los cuerpos de las funciones, las llaves son opcionales (aunque a menudo se incluyen) para cuerpos de bucle de una sola línea.

```R
words <- c("This", "is", "a", "loop")
for (w in words) { print(w) } # the braces are optional here
#> [1] "This"
#> [1] "is"
#> [1] "a"
#> [1] "loop"
```

Si la iteración actual no cumple alguna condición, es posible saltar de inmediato a la siguiente iteración con un `next`:

```R
for (n in 1:10) {
    if (is_useless(n)) next
     
    # we decided this iteration could be useful
    do_something_slow(n)
}
```

Si necesitas el índice numérico, usa `seq_along()`.

```R
v <- LETTERS[1:3]
v
#> [1] "A" "B" "C"

for (i in seq_along(v)) { print(sprintf("%s%i", v[i], i)) }
#> [1] "A1"
#> [1] "B2"
#> [1] "C3"
```

Usar `i in 1:length(v)` _no_ es recomendado, ya que puede causar problemas cuando `length(v)` es cero.
El rango `1:0` es equivalente a `c(1, 0)`, así que el cuerpo del bucle se ejecutará y probablemente fallará.
La función `seq_along()` está diseñada para manejar este caso correctamente.
