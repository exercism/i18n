# Instrucciones

Trabajas como administrador de sistemas para una gran empresa en Múnich, Alemania. Una de tus responsabilidades es gestionar cuentas de correo electrónico.

Has estado escuchando quejas de personas que dicen que no pueden enviar correos al Sr. Müller. Rápidamente te das cuenta de que la mayoría de la empresa usa un cliente de correo electrónico antiguo que no reconoce `müller@firma.de` como una dirección de correo válida debido al carácter no ASCII.

Decirle a la gente que abandone su antiguo cliente de correo favorito es una batalla perdida, así que decides crear alias saneados para todas las cuentas de correo.

## 1. Sanea los nombres de usuario existentes eliminando todo excepto las letras minúsculas

Implementa la función `sanitize/1`. Debe aceptar un nombre de usuario como charlist y devolver el nombre de usuario con todos los caracteres eliminados excepto las letras minúsculas.

```elixir
Username.sanitize(~c"schmidt1985")
# => ~c"schmidt"
```

## 2. Permite guiones bajos

Extiende la función `sanitize/1`. No debe eliminar los guiones bajos del nombre de usuario.

```elixir
Username.sanitize(~c"mark_fischer$$$")
# => ~c"mark_fischer"
```

## 3. Sustituye los caracteres alemanes

Hay 4 caracteres no ASCII en el alfabeto alemán, y todos tienen sustitutos ASCII comúnmente reconocidos.

| Carácter alemán | Sustituto ASCII |
| ---------------- | ---------------- |
| ä                | ae               |
| ö                | oe               |
| ü                | ue               |
| ß                | ss               |

Extiende la función `sanitize/1`. Debe sustituir los caracteres alemanes según la tabla. Puedes asumir sin problema que todos los nombres de usuario ya están en minúsculas.

```elixir
Username.sanitize(~c"cäcilie_weiß")
# => ~c"caecilie_weiss"
```
