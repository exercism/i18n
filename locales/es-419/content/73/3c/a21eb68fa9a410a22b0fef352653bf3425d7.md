# Pruebas

Puedes usar el editor en línea del sitio web de Exercism para resolver los ejercicios.
O bien, descarga los ejercicios a tu computadora, resuélvelos de forma local y luego envíalos a Exercism.
El resto de este documento trata sobre cómo trabajar de forma local.

## Exercism CLI

Necesitarás la herramienta de línea de comandos `exercism` para descargar y enviar ejercicios.
Consulta [la documentación del CLI de exercism][exercism-cli] para saber cómo descargarlo y configurarlo.

Para descargar un ejercicio, haz lo siguiente:

```bash
exercism download --track 8th --exercise hello-world
```

Y cámbiate al directorio del ejercicio:

```bash
cd /path/to/your/exercism_workspace/8th/hello-world
```

o, si usas Windows:

```cmd
cd \path\to\your\exercism_workspace\8th\hello-world
```

Ten en cuenta que puedes obtener tu espacio de trabajo de exercism con el comando `exercism configure`.

## Probar de forma local

Para ejecutar las pruebas de un ejercicio, debes estar en el directorio correcto del ejercicio.
Luego inicia las pruebas con este comando:

```bash
8th -f test.8th
```

## Pruebas omitidas

Resolver un ejercicio significa hacer que todas sus pruebas pasen.
De forma predeterminada, solo se ejecuta una prueba (la primera) cuando ejecutas las pruebas.
Esto es intencional, ya que te permite concentrarte solo en hacer que esa prueba pase.
Una vez que pase, puedes habilitar la siguiente prueba moviendo la línea `SKIP-REST-OF-TESTS` debajo de ella.

### Anular las omisiones

Para ejecutar todas las pruebas, incluidas las que están después de la palabra `SKIP-REST-OF-TESTS`, puedes establecer la variable de entorno `RUN_ALL_TESTS` en el valor `true`. 
Una forma de establecerlo solo mientras se ejecutan las pruebas es (macOS y Linux):

```bash
RUN_ALL_TESTS=true 8th -f test.8th
```

## Envía tu solución

Para subir tu solución al sitio web de Exercism con la herramienta exercism:

```bash
exercism submit
```

Ten en cuenta que puedes subir tu código aunque no pase todas las pruebas.
Esto es útil si te atascas y necesitas ayuda de un mentor.
