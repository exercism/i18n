# Acerca de

Las [expresiones switch][switch-expressions] se comportan de manera similar a las [sentencias switch][switch-statements] que vimos en [concept:csharp/switch-statements](). Admiten una especie de tabla de decisión que asigna condiciones de entrada a acciones o valores.

En el centro de la expresión switch está la _coincidencia de patrones_. En el ejercicio de programación hicimos coincidir valores con patrones `const`. En este caso, las entradas del `switch` son una _expresión de rango_ que se hace coincidir con valores constantes y los valores que usan las _guardas de caso_.

Los casos (también conocidos como _brazos del switch_) se evalúan en el orden del texto, y el proceso se interrumpe y se devuelve el valor asociado en cuanto se encuentra una coincidencia.

El caso `_`, que es el último de la lista, es útil para asegurar que la coincidencia sea exhaustiva y para evitar posibles errores en tiempo de ejecución.

```csharp
double xx = 42d;

string interesting = xx switch
{
    0 => "I suppose zero is interesting",
    3.14 when DateTime.Now.Day == 14 && DateTime.Now.Month == 3 => "Mmm pie!",
    3.14 => "π",
    42 => "a bit of a cliché",
    1729 => "only if you are a pure mathematician",
    _ => "not interesting"
};

// => interesting == "a bit of a cliché"
```

Se selecciona un «brazo» del `switch` cuando el patrón coincide con la variable de rango y cualquier guarda de caso se evalúa como verdadera.

Las expresiones switch también admiten [patrones de tipo][pattern-matching] y coincidencia recursiva.
