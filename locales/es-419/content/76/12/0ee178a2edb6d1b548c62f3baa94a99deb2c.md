# Acerca de

Como los strings son [vectores][concept-vectors], que son secuencias (ambos se tratan en otros conceptos), todas las funciones que operan sobre secuencias también funcionan con strings, como `position`, `map`, `remove`, `concatenate`, _etc._.

También hay funciones más específicas para strings, que sirven para cosas como comparar strings y ver cuál es alfabéticamente menor o mayor con `string<` y `string>`; también hay funciones para recortar caracteres del lado izquierdo, del derecho o de ambos lados de un string (`string-trim`). Consulta la [sección de la Hyperspec sobre strings][hyper-string] para ver todos los detalles.
