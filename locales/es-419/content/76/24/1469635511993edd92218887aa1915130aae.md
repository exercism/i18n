# Acerca de

La [forma especial with][with] ofrece una manera de concentrarte en el «camino feliz» de una serie de pasos que podrían fallar y de ocuparte de los fallos más adelante.

Digamos que quieres validar un nombre de usuario con varias comprobaciones. Quizás recurras a `case`:

```elixir
case check_ascii(username) do
  {:ok, username} ->
    case check_starts_with_letter(username) do
      {:ok, username} ->
        {:ok, username}

      {:error, "usernames may only start with a letter"} = err ->
        err
    end

  {:error, "usernames may only contain ascii letters"} = err ->
    err
end
```

Puede que ahora sea legible, pero si agregas más comprobaciones anidadas, se volverá más enredado. En esta situación, usa `with`:


```elixir
with {:ok, username} <- check_ascii(username),
     {:ok, username} <- check_starts_with_letter(username),
     {:ok, username} <- check_not_a_joke_name(username),
     {:ok, username} <- check_if_available(username) do
  {:ok, "#{username} is a fine username and you deserve it!"}
end
```

En cada paso, si una cláusula coincide, la cadena continuará hasta que se ejecute el bloque `do`. Si alguna coincidencia falla, la cadena se detiene y se devuelve la cláusula que no coincidió.

Puedes usar guardas en la cadena, así como el operador `=` para las coincidencias normales.

```elixir
with {:ok, id} <- get_id(username),
     {:ok, avatar} when is_bitstring(avatar) <- fetch_avatar(id),
     avatar_size = bit_size(avatar),
     {:ok, image_type} <- check_valid_image_type(avatar) do
  {:ok, image_type, avatar_size, avatar}
end
```

Por último, tienes la opción de usar un bloque `else` para capturar las coincidencias fallidas y modificar el valor devuelto.

```elixir
with {:ok, id} <- get_id(username),
     {:ok, avatar} when is_bitstring(avatar) <- fetch_avatar(id),
     avatar_size = bit_size(avatar),
     {:ok, image_type} <- check_valid_image_type(avatar) do
  {:ok, image_type, avatar_size, avatar}
else
  :not_found ->
    {:error, "invalid username"}

  {:error, "not an image"} ->
    {:error, "avatar associated to #{username} is not an image"}

  err ->
    err
end
```

El `else` es como una sentencia `case` para cualquier valor que no coincida con la cláusula `with`. Se usará el primer valor que coincida.
