# Pistas

## General

- Un valor entero se puede definir como uno o más dígitos consecutivos.

## 1. Define el tiempo esperado en el horno, en minutos

- Necesitas definir un [método][methods] sin ningún argumento.
- Necesitas devolver un valor entero (ver [tipos integrados]).

## 2. Calcula el tiempo restante en el horno, en minutos

- Necesitas definir un [método][methods] con un solo parámetro.
- El parámetro del método es un entero.
- Necesitas devolver un valor entero (ver [tipos integrados]).
- Puedes usar el operador `-` para restar valores.

## 3. Calcula el tiempo de preparación, en minutos

- Necesitas definir un [método][methods] con un solo parámetro.
- El parámetro del método es un entero.
- Necesitas devolver un valor entero (ver [tipos integrados]).
- Puedes usar el operador `*` para multiplicar valores.

## 4. Calcula el tiempo transcurrido, en minutos

- Necesitas definir un [método][methods] con dos parámetros.
- Los parámetros del método son de tipo entero.
- Necesitas devolver un valor entero (ver [tipos integrados]).
- [Puedes llamar][invocation] a uno de los otros métodos que definiste anteriormente.
- Puedes usar el operador `+` para sumar valores.

[built-in types]: https://docs.scala-lang.org/overviews/scala-book/built-in-types.html
