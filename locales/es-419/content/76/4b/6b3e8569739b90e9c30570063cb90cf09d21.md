# Acerca de

Para comenzar el viaje de C++, empezamos con variables, llamadas a funciones y comentarios.

## Comentarios

Hay dos tipos de comentarios: de una sola línea y de varias líneas.
El compilador ignora todo lo que viene después de `//` en la misma línea.
Los comentarios de varias líneas también se conocen como comentarios al estilo C.
Se encierran entre `/*` y `*/`.
Todo lo que quede entre ellos también se ignora.

## Variables

C++ es un lenguaje tipado.
Todos los tipos deben conocerse en tiempo de compilación y, por lo general, debes indicarlos explícitamente.
El tipo de una variable no puede cambiar.
Una variable entera con el nombre `years` se puede declarar así:

```cpp
int years;
```

Es una buena práctica inicializar las variables al declararlas.
C++ ofrece distintos mecanismos para hacerlo.
La versión con llaves está más en línea con el C++ moderno, pero la versión con el signo igual también es muy común.

```cpp
int tomatoes{80};
int potatoes = 40;
```

~~~~exercism/caution
C++ sí permite usar variables sin inicializar.
Hasta que la variable se establece de forma deliberada, está indefinida y puede contener cualquier cosa.
Para evitar errores de uso antes de la asignación y el comportamiento indefinido, es recomendable **inicializar siempre**.
El comportamiento indefinido puede hacer que tu programa falle en el peor momento posible, aunque antes funcionaba sin problemas.
No se insistirá lo suficiente: evita el comportamiento indefinido a toda costa.
~~~~

## Operaciones aritméticas

Los operadores aritméticos como `*`, `+` o `-` pueden formar parte de una expresión como `3 * 2` o `tomatoes + potatoes`.

## Actualizar variables

Puedes reasignar variables, siempre que conserven su tipo:

```cpp
tomatoes = tomatoes - 5; // tomatoes is now 75
potatoes = (32 * 2) + 11; // potatoes is now 75 as well
```

## Funciones

Las funciones tienen un nombre, un tipo de retorno y una lista de parámetros (que puede estar vacía).
Un ejemplo de una función llamada `always_fortyseven` que siempre devolvería 47 se vería así:

```cpp
int always_fortyseven() {
    return 47;
}
```

Aquí está `vip_fee`, que tiene un parámetro:
```cpp
int vip_fee(int standard_fee) {
    /*
    vip_fee calculates the vip fee based on the standard_fee.
    */
    int vip_multi{3};
    return standard_fee * vip_multi;
}
```

O `total_fee`, una función con tres parámetros y una llamada a otra función.

```cpp
int total_fee(int vips, int adults, int kids) {
    /*
    total_fee calculates the total price for a group of VIP and adult guests with kids.
    Kids get a flat discount on the standard fee.
    VIP guest fees are calculated by calling vip_fee.
    */
    int standard_fee{30};
    int kids_discount{15};

    int kids_total_fee = kids  * (standard_fee - kids_discount);
    int vips_total_fee = vips * vip_fee(standard_fee);
    int adult_total_fee = adults * standard_fee;

    return vips_total_fee + adult_total_fee + kids_total_fee;
}
```

Las funciones en C++ no devuelven el valor de la última sentencia como en otros lenguajes.
La palabra clave `return` es obligatoria para que el código compile.

### Espacios en blanco

Los espacios en blanco se usan para dar formato al código fuente e incluyen espacios, tabulaciones y saltos de línea.
Como el compilador ignora los espacios en blanco innecesarios, puedes usarlos para estructurar tu código.
Un uso inteligente de los espacios en blanco puede mejorar la legibilidad de tu código.
Existen distintos estándares de formato, pero todos son convenciones y el compilador no los impone.

```cpp
// Formatting makes it easier to find bugs

int eggs_yolks =  3;
int      yeast = 15;

int flour=500;int sugar=200;// compact, but difficult to read
```
