# Pistas

## 1. Implementa la interfaz `Stringer` para el tipo `TemperatureUnit`

- El tipo `TemperatureUnit` ya está creado para ti y representa una unidad de temperatura
- Fíjate que ya hay 2 constantes creadas para ti que son de este tipo: `Celsius` y `Fahrenheit`, que representan una temperatura en grados Celsius y Fahrenheit, respectivamente
- Agrega un método `String()` al tipo `TemperatureUnit` para que cumpla con la interfaz `Stringer`.
  Este método debe devolver el string `"°C"` si la unidad de temperatura es Celsius o `"°F"` si la unidad de temperatura es Fahrenheit

## 2. Implementa la interfaz `Stringer` para el tipo `Temperature`

- Agrega un método `String()` al tipo `Temperature` para que cumpla con la interfaz `Stringer`
- El método `String()` debe devolver un string con el valor numérico de la temperatura y la unidad de temperatura separados por un espacio (`<temperature> <unit>`)
- La estructura `Temperature` contiene un `TemperatureUnit` y un `int`.
  Puedes usar [fmt.Sprintf][sprintf] para ayudarte a formatear este string
- Como `TemperatureUnit` ya implementa la interfaz `Stringer` (de la tarea 1), las funciones del paquete `fmt` como [fmt.Sprintf][sprintf] sabrán cómo formatearlo cuando uses los [verbos de formato][fmt] `%v` o `%s`

## 3. Implementa la interfaz `Stringer` para el tipo `SpeedUnit`

- El tipo `SpeedUnit` ya está creado para ti y representa una unidad de temperatura
- Fíjate que ya hay 2 constantes creadas para ti que son de este tipo: `KmPerHour` y `MilesPerHour`, que representan una velocidad en kilómetros por hora y millas por hora, respectivamente
- Agrega un método `String()` al tipo `SpeedUnit` para que cumpla con la interfaz `Stringer`.
  Este método debe devolver el string `"km/h"` si la unidad de velocidad es kilómetros por hora o `"mph"` si la unidad de velocidad es millas por hora.

## 4. Implementa la interfaz `Stringer` para `Speed`

- Agrega un método `String()` al tipo `Speed` para que cumpla con la interfaz `Stringer`
- El método `String()` debe devolver un string con el valor numérico de la velocidad y la unidad de velocidad separados por un espacio (`<speed> <unit>`)
- `Speed` contiene un `SpeedUnit` y un `int`.
  Puedes usar [fmt.Sprintf][sprintf] para ayudarte a formatear este string
- Como la estructura `TemperatureUnit` ya implementa la interfaz `Stringer` (de la tarea 3), las funciones del paquete `fmt` como [fmt.Sprintf][sprintf] sabrán cómo formatearla cuando uses los [verbos de formato][fmt] `%v` o `%s`
- Para insertar un `%` en el string final cuando uses [fmt.Sprintf][sprintf], usa `%%` en el string de formato.

## 5. Implementa la interfaz `Stringer` para el tipo `MeteorologyData`

- `Speed` contiene un campo `Temperature` y un campo `Speed`, entre otros campos.
  Puedes usar [fmt.Sprintf][sprintf] para ayudarte a formatear este string
- El método `String` debe devolver los datos meteorológicos en el siguiente formato: `"<location>: <temperature>, Wind <wind_direction> at <wind_speed>, <humidity>% Humidity"`
- Como los tipos `Temperature` y `Speed` ya implementan la interfaz `Stringer` (de las tareas 2 y 4), las funciones del paquete `fmt` como [fmt.Sprintf][sprintf] sabrán cómo formatearlos cuando uses los [verbos de formato][fmt] `%v` o `%s`

[fmt]: https://pkg.go.dev/fmt
