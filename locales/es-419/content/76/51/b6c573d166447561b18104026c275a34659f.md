# General

## 1. Define el tipo opaco Password, usando el patrón «Parse, don't validate»

- La guía de Elm tiene una sección sobre [tipos personalizados][custom-types].
- El tipo personalizado `Password` solo tiene una variante.
- Por convención en Elm, cuando un tipo personalizado tiene una sola variante, la variante y el tipo llevan el mismo nombre (en este caso, ambos se llamarían `Password`).
- La guía de Elm tiene una sección sobre [Maybe][maybe] por si necesitas repasar.
