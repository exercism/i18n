# Acerca de

Un [bucle while][while-loops] es una sentencia de control de flujo que permite ejecutar código mientras se cumple una condición.
Swift ofrece dos tipos de bucles while: los bucles while y los bucles repeat-while.
La condición del bucle while se evalúa antes de que se ejecute el cuerpo del bucle; si la condición es falsa, el cuerpo del bucle no se ejecutará en absoluto.
Los bucles while en Swift tienen la siguiente estructura:

```swift
while <#condition#> {
  <#code#>
}
```

Aquí el bucle se ejecutará mientras count sea mayor que 0 y, por lo tanto, imprimirá los números 2, 1 y «Liftoff!».

```swift
var count = 2
while count > 0 {
  print("\(count)…")
  count -= 1
}
print("Liftoff!")

// prints:
// 2…
// 1…
// Liftoff!
```

Un [bucle repeat-while][while-loops] es similar a un bucle while, pero la condición se evalúa después de que se ejecute el cuerpo del bucle.
Esto significa que el cuerpo del bucle siempre se ejecutará al menos una vez, incluso si la condición es falsa.
Los bucles repeat-while en Swift tienen la siguiente estructura:

```swift
repeat {
  <#code#>
} while <#condition#>
```

Aquí el bucle se ejecutará solo una vez, ya que la condición es falsa.
Como es un bucle repeat-while, el cuerpo del bucle se ejecutará una vez antes de que se evalúe la condición.

```swift
var count = 2
repeat {
  print("\(count)…")
} while count < 0
print("Liftoff!")
```

## Bucles de enlace opcional

Una variante común de los bucles while en Swift es el bucle while de enlace opcional.
Estos bucles se repiten mientras la llamada a alguna función que devuelve un valor opcional devuelva un valor distinto de `nil`.
Ese valor (no opcional) se vincula entonces a un nombre que tú elijas y se puede usar en el cuerpo del bucle.

```swift
var arr = [1,2]
while let count = arr.popLast() {
  print("\(count)…")
}
print("Liftoff!")

// prints:
// 2…
// 1…
// Liftoff!
```
