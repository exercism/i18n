# Introducción

## Agent

El módulo `Agent` facilita una abstracción para lanzar [procesos y el bucle _receive-send_][exercism-processes]. De aquí en adelante, llamaremos _procesos agente_ a los procesos iniciados con el módulo `Agent`. Se puede elegir un _proceso agente_ para representar un estado compartido central.

Para iniciar un _proceso agente_, `Agent` ofrece la función `start/2`. La función que se proporciona al _iniciar_ el _proceso agente_ con `start` devuelve el estado inicial del proceso:

```elixir
# Start an agent process with an initial value of an empty list
{:ok, agent_pid} = Agent.start(fn -> [] end)
```

Al igual que `Map` o `List`, `Agent` ofrece muchas funciones para trabajar con _procesos agente_.

Es costumbre organizar y encapsular toda la funcionalidad relacionada con `Agent` en un módulo para el dominio que se está modelando.

[exercism-processes]: https://exercism.org/tracks/elixir/concepts/processes
