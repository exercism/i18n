# Introducción

## Try/Rescue/Else/After

Usar `try..rescue` es una construcción poderosa para capturar errores cuando ocurren. Capturar errores permite que las funciones devuelvan valores definidos cuando es necesario. La construcción `try..rescue` también nos ofrece dos funcionalidades adicionales que podemos aprovechar:

- el bloque `else`
  - Cuando el bloque `try` tiene éxito, el resultado se hace coincidir con este bloque.
- el bloque `after`
  - Ya sea que el bloque `try` tenga éxito o lance una excepción, el código del bloque `after` siempre se ejecuta, siempre que el programa siga en ejecución en ese punto.
  - El resultado del bloque `after` no se devuelve al ámbito que hizo la llamada.

```elixir
try do
  :a
rescue
  _ -> :error
else
  :a -> :success
after
  :some_action
end

# => :success
```

## Despacho dinámico

Cuando Elixir resuelve la función que se va a invocar, usa el nombre del módulo para hacer una búsqueda. La búsqueda se puede hacer de forma dinámica si el nombre del módulo está vinculado a una variable.

```elixir
defmodule MyModule do
  def message(), do: "My message"
end

atom = MyModule
atom.message()
# => "My message"
```

Internamente, el nombre de un módulo es un átomo. Todos los átomos de módulos de Elixir llevan automáticamente el prefijo `Elixir.`

```elixir
is_atom(Enum)
# => true
Enum == Elixir.Enum
# => true
```
