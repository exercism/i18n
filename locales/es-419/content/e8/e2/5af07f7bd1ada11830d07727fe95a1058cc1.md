# Instrucciones

En este ejercicio necesitas implementar algunas funciones para manipular una lista de lenguajes de programación.

## 1. Define una función para devolver una lista de lenguajes vacía

Define la función `new/0` que no toma argumentos y devuelve una lista vacía.

```elixir
LanguageList.new()
# => []
```

## 2. Define una función para agregar un lenguaje a la lista

Define la función `add/2` que toma 2 argumentos (una _lista de lenguajes_ y un literal de cadena de un _lenguaje_). Debe devolver la lista resultante con el nuevo lenguaje antepuesto a la lista dada.

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Clojure")
# => ["Clojure"]
language_list = LanguageList.add(language_list, "Haskell")
# => ["Haskell", "Clojure"]
```

## 3. Define una función para eliminar un lenguaje de la lista

Define la función `remove/1` que toma 1 argumento (una _lista de lenguajes_). Debe devolver la lista sin el primer elemento. Supón que la lista siempre tendrá al menos un elemento.

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Clojure")
# => ["Clojure"]
language_list = LanguageList.add(language_list, "Haskell")
# => ["Haskell", "Clojure"]
language_list = LanguageList.remove(language_list)
# => ["Clojure"]
```

## 4. Define una función para devolver el primer elemento de la lista

Define la función `first/1` que toma 1 argumento (una _lista de lenguajes_). Debe devolver el primer lenguaje de la lista. Supón que la lista siempre tendrá al menos un elemento.

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Elm")
# => ["Elm"]
language_list = LanguageList.add(language_list, "Prolog")
# => ["Prolog", "Elm"]
LanguageList.first(language_list)
# => "Prolog"
```

## 5. Define una función para devolver cuántos lenguajes hay en la lista

Define la función `count/1` que toma 1 argumento (una _lista de lenguajes_). Debe devolver la cantidad de lenguajes en la lista.

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Elm")
# => ["Elm"]
language_list = LanguageList.add(language_list, "Prolog")
# => ["Prolog", "Elm"]
LanguageList.count(language_list)
# => 2
```

## 6. Define una función para determinar si la lista incluye un lenguaje funcional

Define la función `functional_list?/1` que toma 1 argumento (una _lista de lenguajes_). Debe devolver un valor booleano. Debe devolver true si _«Elixir»_ es uno de los lenguajes de la lista.

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Elixir")
# => ["Elixir"]
LanguageList.functional_list?(language_list)
# => true
```
