# Pistas

## 1. Crea un auto a control remoto

- Devuelve una lista con 4 elementos con nombre.
- `speed` y `battery_drain` se pasan como argumentos.
- `battery` y `distance_traveled` toman valores por defecto.

## 2. Crea una pista de carreras

- Devuelve una lista de longitud 1.

## 3. Verifica si la batería está descargada

- Para que cuente como «descargada», la carga de la batería no tiene que ser cero; basta con que sea lo suficientemente baja como para que no se pueda completar otro turno.
- El control del auto funciona por pasos discretos. Cuando hablamos de «turno», queremos decir «cada vez que se llama a `drive()`».

## 4. Conduce el auto

- ¿La batería está descargada? Si es así, ¿debería actualizarse el auto?
- `battery_drain` es el porcentaje de carga que se pierde en cada turno.
- `speed` es la distancia recorrida en cada turno.
- Devuelve un auto actualizado, según corresponda.

## 5. Verifica si un auto a control remoto puede terminar una carrera

- ¿Cuántos turnos más puede completar el auto?
- No hay turnos parciales, así que la función [`floor`][ref-round] puede ser útil. Como alternativa, la división entera `%/%` también funciona con números de punto flotante, truncando el resultado.
- ¿Qué distancia puede recorrer el auto en ese número de turnos?
- ¿Es suficiente?

## 6. Guarda si el auto puede terminar una pista con la batería llena

- Reinicia `battery` y `distance_traveled` a los valores de un auto nuevo antes de hacer cualquier cálculo.
- Las listas son vectores _recursivos_, así que pueden contener otras listas.
- El nombre del nuevo elemento se pasa en tiempo de ejecución, así que la notación `$` no funcionará. La introducción sugiere alternativas.
- El valor del nuevo elemento es una `list` de longitud 2. No puede ser un `vector`, porque mezcla elementos numéricos y lógicos.
- Devuelve el auto actualizado.
- Asume que se pueden agregar varios elementos de pista, con nombres diferentes.
