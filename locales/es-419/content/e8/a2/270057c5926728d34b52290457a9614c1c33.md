# tiene errores de compilación

El código tiene uno o más errores de compilación, lo que impide que se ejecute la suite de pruebas. Un buen primer paso para averiguar cómo corregir el error o los errores es examinar los mensajes de error que aparecen al intentar compilar el código. Estos mensajes contienen un número y una descripción del error, lo que ayuda a identificar con exactitud cuál es el problema.
