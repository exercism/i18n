# Anexo de instrucciones

## Implementación

Si el último elemento del array es un `object` en lugar de un `string`, contendrá un calificador que modifica la última línea del proverbio.

```javascript
proverb('nail', 'shoe', { qualifier: 'horseshoe' });
// => For want of a nail the shoe was lost.
//    And all for the want of a horseshoe nail.
```
