# Dispositivo secreto

## Historia

Esta historia usa el contexto de crear un dispositivo para cifrar mensajes de forma confiable y repetida usando [funciones anónimas][concepts-anonymous_functions].

Conceptos que se exploran:

- [Funciones anónimas][concepts-anonymous_functions]
- [Composición de funciones][concepts-function_composition]
- [Funciones de orden superior][concepts-higher_order_functions]

La historia también se adapta bien a la [manipulación de bits][concepts-bitwise_manipulation], el tipo [bit][types-bit] y la composición de funciones.
