# Residuo

En matemáticas, el **residuo** es la cantidad que «sobra» después de hacer un cálculo. Por ejemplo, el residuo de `5 / 3` es `2`.

Muchos lenguajes de programación usan el signo de porcentaje (`%`) como operador para calcular el residuo. Por ejemplo:
```javascript
5 % 3 == 2
```

A menudo, el residuo se puede calcular tanto con números enteros como con números de punto flotante. Por ejemplo,
```javascript
5.3 % 3 == 2.3
```

Cuando trabajas con números negativos, el resultado siempre tiene el mismo signo que el dividendo (el número que está a la izquierda, el que se divide). Por ejemplo:
```javascript
-5 % 3 == -2
5 % -3 == 2
-5 % -3 == -2
```

Algunos lenguajes (como Python) usan el operador `%` para calcular el módulo, no el residuo. Eso trata los números negativos de otra forma. Puedes aprender más sobre esto [en Wikipedia](https://en.wikipedia.org/wiki/Modulo).
