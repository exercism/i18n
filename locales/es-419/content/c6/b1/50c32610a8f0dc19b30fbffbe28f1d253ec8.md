# Introducción

En JavaScript, los _template strings_ permiten incrustar expresiones dentro de strings, lo que también se conoce como interpolación de strings.
Esta característica amplía las capacidades del objeto global [`String`][string-reference] integrado.

Puedes crear template strings en JavaScript si envuelves el texto entre comillas invertidas.
No solo permiten que el texto incluya saltos de línea y otros caracteres especiales, sino que también puedes incrustar variables y otras expresiones.

```javascript
const num1 = 1;
const num2 = 2;

`Adding ${num1} and ${num2} gives ${num1 + num2}.`;
// => Adding 1 and 2 gives 3.
```

En el ejemplo anterior, las comillas invertidas (<code>\`\`</code>) se usan para representar un template string. El `${...}` es el marcador de posición que se usa para la sustitución.
Cualquier tipo que no sea string se convierte _implícitamente_ en string.
Este tema se trata en el concepto de [conversión de tipos][type-conversion-concept].
Con los template strings se puede usar todo tipo de expresiones.

```javascript
const track = 'JavaScript';

`This track on exercism.org is ${track.toUpperCase()}.`;
// => This track on exercism.org is JAVASCRIPT.
```

Cuando necesitas que los strings tengan formato de varias líneas:

```javascript
`This is an example of using template
strings to accomplish multiple
lines`;
```

Con las capacidades de sustitución disponibles, también puedes introducir lógica en el proceso para determinar cuál debe ser el string de salida.

Un ejemplo de esto es incrustar un [operador ternario][ternary-operator].
Este operador es una forma corta de escribir una sentencia `if/else`.
La sintaxis es `condition ? consequent-expression : alternative-expression`.
Si la condición es truthy, se devuelve el operando que está a la izquierda de los dos puntos.
De lo contrario, el resultado de la expresión ternaria es el operando que está a la derecha de los dos puntos.

```javascript
const grade = 95;

`You have ${grade > 90 ? 'passed' : 'failed'} the exam.`;
// => You have passed the exam.
```
