# Introducción

## Métodos de extensión

Los métodos de extensión permiten agregar métodos a tipos existentes sin crear un nuevo tipo derivado, sin recompilar ni modificar de otro modo el tipo original. Se definen como métodos estáticos, pero se llaman usando la sintaxis de método de instancia. Su primer parámetro va precedido del modificador `this` y especifica sobre qué tipo opera el método, y se incorporan al ámbito a nivel del espacio de nombres.

```csharp
public static int WordCount(this string str)
{
    return str.Split().Length;
}

"Hello World".WordCount();
// => 2
```
