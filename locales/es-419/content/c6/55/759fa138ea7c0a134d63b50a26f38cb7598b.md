# Rebanadas de pizza

## Historia

Tienes varias tiendas de rebanadas de pizza en tu ciudad y quieres escribir una aplicación web que te permita comparar dos configuraciones de pizza diferentes para saber quién te dará la rebanada más grande.

## Tareas

La historia facilita la exploración de los [tipos opcionales][types-option-types], que se pueden usar para representar un valor o la ausencia de un valor.

- Escribe una función que calcule los tamaños de las rebanadas y que devuelva nil cuando los argumentos no sean válidos
- Procesa los datos que recibe tu aplicación web para determinar cuál es la rebanada más grande
