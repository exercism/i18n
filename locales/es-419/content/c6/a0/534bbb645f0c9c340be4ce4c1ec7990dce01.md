# Instrucciones

La empresa para la que trabajas está a punto de lanzar su nuevo teléfono inteligente, llamado **Smarty 5**, con un sistema de cámara totalmente nuevo, un diseño nuevo y un procesador revolucionario que funciona con un sistema operativo nuevo llamado **smartyOS**.

El nuevo procesador tiene la capacidad de manejar contraseñas más seguras que nunca, y la empresa ha decidido aprovecharlo.
Te han pedido que implementes un sistema de bloqueo por contraseña para el teléfono que permita al usuario establecer una contraseña y luego comprobar si una contraseña dada es correcta.

~~~~exercism/caution
El sistema de contraseñas que se practica en este ejercicio no es seguro y solo se usa con fines educativos.
**NO** se debe usar en ninguna aplicación del mundo real.
~~~~

## 1. Establece una contraseña

El teléfono permite a los usuarios usar varios tipos de contraseñas diferentes, desde una simple contraseña numérica hasta una contraseña alfanumérica más segura e incluso una contraseña que almacena su huella digital.

Estos diferentes tipos de contraseñas usan tipos distintos: la contraseña numérica usa un `Int32`, la contraseña alfanumérica usa un `String` y la contraseña de huella digital usa un `Float64`.

Implementa la clase `PasswordLock` con un inicializador que recibe cualquiera de los tres tipos de contraseñas como argumento y la almacena en una variable de instancia llamada `@password`.

```crystal
password_lock = PasswordLock.new(1234)
# => #<PasswordLock:0x7f8e1b8c0b80 @password=1234>
```

## 2. Cifra la contraseña

La empresa ha decidido cifrar la contraseña para que no se almacene en texto plano y te ha pedido que implementes un método para cifrarla.

Cada tipo de contraseña tiene su forma única de cifrarse:

- Contraseña `Int32`: La contraseña se divide entre dos y se redondea al entero más cercano.
- Contraseña `String`: La contraseña se invierte.
- Contraseña `Float64`: La contraseña se multiplica por cuatro.

Implementa un método de instancia llamado `encrypt` que no recibe argumentos y modifica la variable de instancia `@password` para que quede cifrada.

```crystal
password_lock = PasswordLock.new(1234)
# => #<PasswordLock:0x7f8e1b8c0b80 @password=1234>

password_lock.encrypt
# => #<PasswordLock:0x7f8e1b8c0b80 @password=617>
```

## 3. Comprueba si una contraseña es correcta

La empresa también te ha pedido que implementes un método que compruebe si una contraseña dada es correcta.

Quieren que el método devuelva `nil` si la contraseña es incorrecta y `"Unlocked"` si la contraseña es correcta.

Implementa un método de instancia llamado `unlock?` que recibe la contraseña que se va a comprobar como argumento.
El método debe devolver `nil` si la contraseña es incorrecta y `"Unlocked"` si la contraseña es correcta.

```crystal
password_lock = PasswordLock.new(1234)
password_lock.encrypt
password_lock.unlock?(1234)
# => "Unlocked"
```
