# Pistas

## General

- Kotlin ofrece muchas [funciones][ref-strings] para trabajar con String. ¡Asegúrate de revisar la pestaña `Members & Extensions`!

## 1. Obtén el mensaje de una línea de log

- Hay una [función][ref-string-substringAfter] para extraer la parte de un `String` que está después de un delimitador dado.
- Quitar los espacios en blanco de un `String` se explora en [Eliminar todos los espacios en blanco de un String en Kotlin][tutorial-trim-white-space].

## 2. Obtén el nivel de log de una línea de log

- También hay una [función][ref-string-substringBefore] para extraer la parte de un `String` que está _antes_ de un delimitador dado.
- Hay una [forma][ref-string-lowercase] de convertir un `String` a minúsculas.

## 3. Reformatea una línea de log

- Las [plantillas de String][docs-string-template] se pueden hacer con un [String multilínea][docs-string-multiline].
