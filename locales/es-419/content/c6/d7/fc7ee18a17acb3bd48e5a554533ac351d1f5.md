# Pistas

## 1. Estima el tiempo de preparación

- Usa [`size()`][size-func] del vector para determinar la cantidad de capas (la longitud del slice de capas).

## 2. Calcula las cantidades de noodles y sauce que se necesitan

- Primero, crea un objeto `amount` para llevar la cuenta de la cantidad de noodles y sauce.
- Usa un [bucle `for`][for-loop] para recorrer las capas.
- Si encuentras una capa `"noodles"` o `"sauce"` en tu bucle, aumenta en consecuencia la cantidad almacenada en el objeto `amount`.

## 3. Agrega el ingrediente secreto

- Vuelve a revisar los [vectores][concept-vector] para descubrir cómo obtener un elemento de un vector y cómo reemplazar un elemento en un vector.
- El índice del último elemento de un vector `a` es `a.size() - 1`, o puedes usar `a.back()` directamente.

## 4. Escala la receta

- Primero, crea un nuevo slice del mismo tamaño que el slice que recibes.
- Usa un [bucle `for`][for-loop] para recorrer el slice que recibes y generar el slice de salida.

## 5. Desbloquea el secreto de la familia

- Puedes reutilizar tu código de la tarea 3.
- Esta tarea necesita [sobrecarga de funciones][function overloading].
