# no uses la división ni el módulo

Como se menciona en las instrucciones, el objetivo de este ejercicio es construir una criba de Eratóstenes sin usar operaciones como la división o el módulo.
Consulta el [enlace de Wikipedia](https://en.wikipedia.org/wiki/Sieve_of_Eratosthenes) para ver una descripción del algoritmo.

Construir la criba de Eratóstenes en un lenguaje inmutable como Elm puede resultar algo extraño, pero es un algoritmo hermoso, inventado hace más de dos milenios, que vale la pena aprender e implementar correctamente.
