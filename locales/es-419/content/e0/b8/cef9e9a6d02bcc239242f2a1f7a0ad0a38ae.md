# Pistas

## General

- Los primeros seis argumentos enteros se pasan a una función en `rdi`, `rsi`, `rdx`, `rcx`, `r8` y `r9`.
- Las direcciones en memoria son valores de 64 bits (8 bytes).

## 1. Crea una entrada para cada ítem

- Los primeros seis argumentos enteros se pasan a una función en `rdi`, `rsi`, `rdx`, `rcx`, `r8` y `r9`.
- Las direcciones en memoria son valores de 64 bits (8 bytes).
- Todos los argumentos enteros después del sexto se pasan en la pila, y el primero está en `rsp + 8`.
- La cantidad de argumentos adicionales es igual a la cantidad de categorías, que se pasa en `r9`.
- Puedes usar un bucle para agregar los argumentos adicionales uno por uno, o puedes usar [movsq][movs] junto con [rep][rep].

## 2. Reserva espacio para una lista mensual de ítems

- Los primeros seis argumentos enteros se pasan a una función en `rdi`, `rsi`, `rdx`, `rcx`, `r8` y `r9`.
- Las direcciones en memoria son valores de 64 bits (8 bytes).
- Necesitas conocer el tamaño del array para poder limpiar sus bytes después de llamar a la función que asigna la memoria.
- Cuando llamas a una función externa, esta puede modificar el valor de cualquier _registro que el llamador deba guardar_.
- Puedes preservar el valor de un registro en la pila usando [push][push] o manipulando `rsp` directamente.
- Cualquier modificación de `rsp`, incluso con `push`, debe revertirse antes de que la función termine, ya sea con [pop][pop] o cambiando `rsp` directamente.

## 3. Inserta un ítem en la lista mensual

- Los primeros seis argumentos enteros se pasan a una función en `rdi`, `rsi`, `rdx`, `rcx`, `r8` y `r9`.
- Las direcciones en memoria son valores de 64 bits (8 bytes).
- Un valor que no cabe en un registro se pasa a una función en la pila.
- Cada entrada de un ítem ocupa 120 bytes de espacio, mucho más que el tamaño máximo de un registro (8 bytes).
- Los argumentos que se pasan en la pila se encuentran en direcciones que comienzan en `rsp + 8`.
- Puedes usar un bucle para agregar los valores en la ubicación de memoria de destino, o puedes usar [movsb][movs] junto con [rep][rep].

## 4. Imprime un ítem

- Los primeros seis argumentos enteros se pasan a una función en `rdi`, `rsi`, `rdx`, `rcx`, `r8` y `r9`.
- Las direcciones en memoria son valores de 64 bits (8 bytes).
- El string introductorio es opcional; en su lugar, puedes llamar a la función de impresión con `0`.
- Si se pasa el string introductorio a la función de impresión, debe tener como máximo 50 caracteres ASCII, incluyendo ya el terminador NUL (el valor `0`).
- Siempre que llamas a una función, debes reservar espacio en la pila para cualquier argumento después del sexto.
- La ABI de System V establece que la pila debe estar alineada a 16 bytes antes de llamar a una función, lo cual es especialmente importante en el caso de las funciones externas.
- Cada entrada de un ítem en la lista ocupa 120 bytes de espacio.
