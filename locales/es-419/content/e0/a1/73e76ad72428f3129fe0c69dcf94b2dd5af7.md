# Acerca de

La construcción orientada a objetos principal en Java es la _clase_, que es una combinación de datos ([_campos_][fields]), también conocidos como variables de instancia, y comportamiento ([_métodos_][methods]).
Los campos y métodos de una clase se conocen como sus _miembros_.

El acceso a los miembros se puede controlar mediante modificadores de acceso, siendo los dos más comunes:

- [`public`][public]: se puede acceder al miembro desde cualquier código (sin restricciones).
- [`private`][private]: solo se puede acceder al miembro desde código en la misma clase.

En Java, si no se especifica ningún modificador de acceso, el valor predeterminado es la _visibilidad de paquete_.
En este caso, el miembro es visible para todas las clases definidas en el mismo paquete.

Esta agrupación de datos y comportamiento relacionados, junto con la restricción del acceso a los miembros, se conoce como [_encapsulación_][encapsulation], que es uno de los conceptos centrales de la orientación a objetos.

Puedes pensar en una clase como una plantilla para crear instancias de esa clase.
Para [crear una instancia de una clase][creating-objects] (también conocida como _objeto_), se usa la [palabra clave `new`][new]:

```java
class Car {
}

// Create two car instances
Car myCar = new Car();
Car yourCar = new Car();
```

Los [campos][fields] tienen un tipo y un nombre (escrito con [camelCase][camel-case]) y se pueden definir en cualquier parte de una clase (cuyo nombre va en [PascalCase][pascal-case]).

```java
class Car {
    // Accessible by anyone
    public int weight;

    // Only accessible by code in this class
    private String color;
}
```

Opcionalmente, se puede asignar un valor inicial a un campo.
Si un campo _no_ especifica un valor inicial, se establecerá en el [valor predeterminado][default-values] de su tipo.
Se puede acceder a los valores de los campos de una instancia y actualizarlos usando la notación de punto.

```java
class Car {
    // Will be set to specified value
    public int weight = 2500;

    // Will be set to default value (0)
    public int year;
}

Car newCar = new Car();
newCar.weight; // => 2500
newCar.year;   // => 0

// Update value of the field
newCar.year = 2018;
```

Los campos privados normalmente se actualizan como efecto secundario de llamar a un método.
Estos métodos normalmente no devuelven ningún valor, en cuyo caso el tipo de retorno debe ser [`void`][void]:

```java
class CarImporter {
    private int carsImported;

    public void importCars(int numberOfCars)
    {
        // Update private field
        carsImported = carsImported + numberOfCars;
    }
}
```

Ten en cuenta que no es costumbre usar campos públicos en las clases de Java.
Normalmente se usan campos privados, a los que se accede mediante [_getters_ y _setters_][so-getters-setters].

Dentro de una clase, la [palabra clave `this`][this] hará referencia a la clase actual.
Esto es especialmente útil si un parámetro tiene el mismo nombre que un campo:

```java
class CarImporter {
    private int carsImported;

    public void setImportedCars(int carsImported)
    {
        // Update private field from public method
        this.carsImported = carsImported;
    }
}
```
