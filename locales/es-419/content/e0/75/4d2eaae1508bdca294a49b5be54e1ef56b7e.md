# Anexo de instrucciones

## Instrucciones específicas del track

Para este ejercicio, tu verbo recibirá dos argumentos:

- **Argumento izquierdo**: una lista de números enteros que representa el conjunto de ítems mágicos recolectados.
- **Argumento derecho**: un número entero que representa el nivel que se completó.

Tu verbo debe definirse para manejar estos argumentos de la siguiente manera:

```j
  factors =. 3 5
  limit   =. 20
  
  multiplesList sum upperLimit
```
