# Instructions

En este ejercicio comprobarás los permisos de cuentas de usuario en un foro de internet. El foro admite tres permisos diferentes:

- Read
- Write
- Delete

Hay tres tipos de cuentas, cada uno con diferentes permisos predeterminados:

- Guest: puede leer publicaciones.
- User: puede leer y escribir publicaciones.
- Moderator: puede leer, escribir y eliminar publicaciones, y tiene todos los permisos.

A veces se pueden modificar los permisos individuales. Por ejemplo, es posible darle a una cuenta de tipo Guest el permiso para escribir publicaciones también. Revocar todos los permisos de una cuenta daría como resultado que no tenga ninguno de los permisos.

## 1. Obtener los permisos predeterminados para un tipo de cuenta

Primero, define una enumeración `AccountType` para representar los tres tipos de cuenta: `Guest`, `User` y `Moderator`.

Luego, define una enumeración `Permission` para representar los tres tipos de permisos: `Read`, `Write`, `Delete`, y dos adicionales: `All` para tener todos los permisos y `None` para no tener ninguno de los permisos.

Después, implementa el método (_estático_) `Permissions.Default()` para devolver los permisos predeterminados de un tipo de cuenta específico:

```csharp
Permissions.Default(AccountType.Guest)
// => Permission.Read
```

## 2. Conceder un permiso

Implementa el método (_estático_) `Permissions.Grant()` que concede (agrega) un permiso:

```csharp
Permissions.Grant(current: Permission.None, grant: Permission.Read)
// => Permission.Read
```

## 3. Revocar un permiso

Implementa el método (_estático_) `Permissions.Revoke()` que revoca (elimina) un permiso:

```csharp
Permissions.Revoke(current: Permission.Read, revoke: Permission.Read)
// => Permission.None
```

## 4. Comprobar un permiso

Implementa el método (_estático_) `Permissions.Check()` que toma los permisos actuales de la cuenta y comprueba si la cuenta está autorizada para un permiso dado:

```csharp
Permissions.Check(current: Permission.Write, check: Permission.Read)
// => false
```
