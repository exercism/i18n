## 1. Verifica si hay criticidad

- Los operadores de comparación ([repaso de comparaciones][comparisons review]) y las operaciones con Boolean ([concept:python/bools]()) se pueden combinar y usar con condicionales.
- Las expresiones condicionales deben evaluarse a `True` o `False`.
- Puedes usar `else` para un bloque de código que se ejecutará cuando todas las pruebas condicionales devuelvan `False`.

  ```python
     >>> item = 'blue'
     >>> item_2 = 'green'
     
     >>>  if len(item) >= 3 and len(item_2) < 5:
            print('Both pass the test!')
          elif len(item) >= 3 or len(item_2) < 5:
            print('One passes the test!')
          else:
            print('None pass the test!')
    ...
    One passes the test!
  ```

## 2. Determina el rango de potencia de salida

- Los operadores de comparación se pueden combinar y usar con condicionales.
- Puedes usar cualquier cantidad de sentencias `elif` como «ramas» de decisión.
- Cada «rama» puede tener su propio `return`, aunque las herramientas de linting podrían considerarlo «mala práctica».
- Si el linter se queja, considera asignar el resultado de una rama a una variable común y luego hacer `return` de esa variable.
