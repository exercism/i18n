# Introducción

## La interfaz como un conjunto de métodos

En su forma más simple, un **tipo de interfaz** es un conjunto de firmas de métodos.
Aquí tienes un ejemplo de una definición de interfaz que incluye dos métodos, `Add` y `Value`:

```go
type Counter interface {
    Add(increment int)
    Value() int
}
```

Los nombres de los parámetros como `increment` se pueden omitir de la definición de la interfaz, pero a menudo aumentan la legibilidad.

Los nombres de las interfaces en Go no contienen la palabra `Interface` ni `I`.
En cambio, a menudo terminan en `er`, por ejemplo `Reader` y `Stringer`.

## Implementar una interfaz

Cualquier tipo que defina los métodos de la interfaz automáticamente «implementa» la interfaz de forma implícita.
En Go no existe la palabra clave `implements`.

El siguiente tipo implementa la interfaz `Counter` que vimos antes.

```go
type Stats struct {
    value int
    // ...
}

func (s Stats) Add(v int) {
    s.value += v
}

func (s Stats) Value() int {
    return s.value
}

func (s Stats) SomeOtherMethod() {
    // The type can have additional methods not mentioned in the interface.
}
```

Para implementar la interfaz, no importa si el método tiene un receptor de valor o un receptor de puntero.
(Vuelve a revisar los [conceptos de métodos][concept-methods] si tienes dudas sobre esto.)

> Un valor de tipo interfaz puede contener cualquier valor que implemente esos métodos. [^1]

Eso significa que ahora puedes usar `Stats` en todos los lugares que esperan la interfaz `Counter`.

```go
func SetUpAnalytics(counter Counter) {
    // ...
}

stats := Stats{}
SetUpAnalytics(stats)
// works because Stats implements Counter
```

Como las interfaces se implementan de forma implícita, un tipo puede implementar varias interfaces con facilidad.
Solo necesita tener definidos todos los métodos necesarios.

## La interfaz vacía

En Go hay un tipo de interfaz muy especial: el **tipo de interfaz vacía**, que no contiene ningún método.
La interfaz vacía se escribe así: `interface{}`.
`any` es un alias de `interface{}` y es lo que más se usa.

Como la interfaz vacía no tiene métodos, todos los tipos la implementan de forma implícita.
Esto es útil para definir una función que pueda aceptar cualquier valor de forma genérica.
En ese caso, el parámetro de la función usa el tipo de interfaz vacía.
