# Introducción

El tipo `Bool` es uno de los bloques de construcción del lenguaje. Su propósito es describir si algo es verdadero o falso, con los valores `True` y `False` respectivamente.

Los Boolean se pueden combinar con los operadores `&&` («AND») y `||` («OR»), y negar con la función `not`.

Los Boolean también son sumamente útiles para crear ramas en tu código que solo se ejecutan si se cumplen ciertas condiciones. En Elm, esto se hace con una expresión `if-then-else`, que se usa de la siguiente manera.

```elm
if someCondition || (someOtherCondition && anotherCondition) then
    doSomething
else
    doSomethingElse
```
