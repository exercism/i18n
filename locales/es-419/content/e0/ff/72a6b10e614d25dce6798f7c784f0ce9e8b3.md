# Introducción

Un bucle `for` te permite ejecutar código repetidamente hasta que se cumpla una condición.

```csharp
for (int i = 0; i < 5; i++)
{
    System.Console.Write(i);
}

// => 01234
```

Un bucle `for` consta de cuatro partes:

1. El inicializador: se ejecuta una vez antes de entrar al bucle. Normalmente se usa para definir las variables que se usan dentro del bucle.
2. La condición: se ejecuta antes de cada iteración del bucle. El bucle sigue ejecutándose mientras esto se evalúe como `true`.
3. El iterador: se ejecuta después de cada iteración del bucle. Normalmente se usa para modificar (a menudo, incrementar o decrementar) las variables del bucle.
4. El cuerpo: el código que se ejecuta en cada iteración del bucle.
