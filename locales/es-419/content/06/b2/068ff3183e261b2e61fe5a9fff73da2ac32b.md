# If, Elseif, Else

Las sentencias condicionales que usan `if`, `elseif` y `else` son una parte fundamental del flujo de control de un programa.
La sentencia `if` evalúa una expresión y, si es `true`, ejecuta la rama de código.

```php
<?php

if ($expression) {
    // .. executed if $expression is true
}
```

Si la expresión no es un valor Boolean, la evaluación determina la «veracidad» o la «no falsedad» del valor.
En PHP, los siguientes valores se consideran falsos:

- boolean `false`
- entero `0`
- número de punto flotante `0.0` y `-0.0`
- un array vacío `[]`
- una cadena vacía `""` o una cadena numérica `"0"`
- `null`

Todos los demás valores se consideran verdaderos.

## Cómo responder a varias condiciones

Después de una sentencia `if`, puedes encadenar varias condiciones con `elseif` y `else`.

```php
<?php

if ($value === 0) {
    // .. do something
} elseif ($value === 1) {
    // .. do something else
} else {
    // ,, do this if nothing else
}
```

Solo se ejecutará una sentencia condicional que se evalúe como verdadera.
Así que, si varias condiciones pueden evaluarse como verdaderas, el orden en que se escriben es importante.

```php
<?php

if (true) {
    // .. always do something
} elseif (true)
    // .. will never be executed
} else {
    // .. will never be executed
}
```
