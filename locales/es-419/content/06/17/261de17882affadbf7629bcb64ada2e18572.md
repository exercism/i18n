# Introducción

En Swift, un `String` es una colección ordenada de valores `Character` que representa texto legible para las personas. Los strings de Swift admiten totalmente los caracteres Unicode y los emojis.

Creas un string usando un literal de string al encerrar texto entre comillas dobles (`"`).
Los caracteres especiales usan secuencias de escape; por ejemplo, `\n` representa un salto de línea y `\"` representa una comilla doble escapada dentro de un literal de string.

Un string vacío se escribe como un par de comillas dobles sin contenido entre ellas (`""`).

```swift
let hello = "Hello, World!"
let sausage = "Weißwurst is a tasty sausage."
var family = "This is my family: 👨‍👩‍👦‍👦, this is our dog: 🐶"
var empty = ""
```
