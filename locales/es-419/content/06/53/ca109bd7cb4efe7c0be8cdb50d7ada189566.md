# Instrucciones

Escribe una función que convierta números normales en [números ordinales](https://en.wikipedia.org/wiki/Ordinal_numeral). Para el cero (0), solo devuelve "0" como string.

Los números ordinales son números que describen la posición de algo en una lista. Es en este contexto donde se usarán los números ordinales, con el nombre de un número ordinal escrito en inglés.

Los números ordinales son (al menos, una de sus formas):

```
1st 2nd 3rd 4th 5th... 9th 10th 11th 12th... 20th 21st 22nd 23rd 24th... etc.
```

Así, al ingresar un número normal se obtiene su equivalente ordinal:

```
1 -> 1st
2 -> 2nd
3 -> 3rd
(and so on...)
```
