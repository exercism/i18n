# Anexo de las instrucciones

## Cómo está estructurado este ejercicio en la pista de Python

Las pruebas de este ejercicio esperan que tu programa se implemente como una [`class`][classes in python] Garden (mira también [concept:python/classes]()).
Si aún no conoces las clases en Python, este [tutorial de Real Python][how-to-make-a-class] puede ser un buen punto de partida adicional.

Tu `class` debe implementar un [`method`][methods] llamado `plants`, que recibe el nombre de un estudiante como argumento y devuelve la `list` de nombres de plantas que le pertenecen a ese estudiante.


## Constructores

Crear el jardín de ejemplo:

```python
[window][window][window]
VRCGVVRVCGGCCGVRGCVCGCGV
VRCCCGCRRGVCGCRVVCVGCGCV
```

se representaría, en las pruebas, como `Garden("VRCGVVRVCGGCCGVRGCVCGCGV\nVRCCCGCRRGVCGCRVVCVGCGCV")`.

Para que esta representación funcione, tu `class` tendrá que implementar un [método especial][special-methods] [`__init__()`][init].
Si no conoces `__init__()` o los [_constructores_][what-is-a-constructor], [objetos de clase y de instancia][class vs instance objects in python] de la documentación de Python ofrece una explicación más detallada.


## Parámetros predeterminados

En algunas pruebas, se pasa una `list` de estudiantes como argumento a `__init__()`.
Esto debe reemplazar la lista de doce estudiantes que se proporciona en el enunciado del problema.
Ambas sentencias deben funcionar con tu método `__init__()`:


```Python
# Make a garden based on the default 12-student roster.
Garden("VRCGVVRVCGGCCGVRGCVCGCGV\nVRCCCGCRRGVCGCRVVCVGCGCV") 

# Make a garden based on a 2-student roster.
Garden("VRCC\nVCGG", students=["Valorie", "Raven"]) 
```

Un enfoque es hacer que la `list` de estudiantes sea un [argumento predeterminado][default argument values]; la documentación de Python describe los `default parameters` en profundidad al explicar las [definiciones de funciones][function definitions].
