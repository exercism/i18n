# Instrucciones

En este ejercicio vas a escribir un TreasureChest genérico (¡y mágico!) para guardar algo de tesoro.

## 1. Define el tipo TreasureChest

Define un tipo paramétrico `TreasureChest{T}` con dos campos.

- Un campo `password` de tipo `String`, que se usará para almacenar la contraseña del cofre del tesoro.
- Un campo `treasure` de tipo `T`, que se usará para almacenar el tesoro.
Este valor es genérico, así que el tesoro puede ser cualquier cosa.

```julia-repl
julia> chest = TreasureChest{String}("password", "gold")
TreasureChest{String}("password", "gold")
```



## 2. Define la función get_treasure()

Esta función debe recibir dos argumentos.

- Un `String` (para intentar una contraseña)
- Un tipo `TreasureChest`

Esta función debe comparar el intento de contraseña proporcionado con la `password` del `TreasureChest`.

- Si las contraseñas coinciden, devuelve el tesoro.
- Si las contraseñas no coinciden, devuelve `nothing`.

```julia-repl
julia> get_treasure("password", chest)
"gold"

julia> get_treasure("wrong", chest)
# no output

julia> isnothing(get_treasure("wrong", chest))
true
```

## 3. Define la función multiply_treasure()

Esta función debe recibir dos argumentos.

- Un multiplicador entero `n`.
- Un tipo `TreasureChest{T}`.

La función debe devolver un nuevo `TreasureChest{Vector{T}}`, con 
- La misma contraseña que el original
- El tesoro multiplicado como un `Vector{T}` de longitud `n`, con el tesoro original repetido `n` veces.

```julia-repl
julia> multiply_treasure(3, chest)
TreasureChest{Vector{String}}("password", ["gold", "gold", "gold"])
```
