# Pistas

## 1. Define un nuevo diccionario de puntajes

- Los [diccionarios vacíos][empty-dictionary] se pueden inicializar escribiendo el nombre del tipo seguido de un par de paréntesis vacíos o, si el tipo se puede determinar por el contexto, usando el literal de diccionario vacío.

## 2. Agrega jugadores al diccionario de puntajes

- Un diccionario se debe declarar como una variable para poder agregarle elementos.
- Puedes agregar elementos a un diccionario usando la [sintaxis de subíndices de diccionario][dictionary-subscripts].

## 3. Elimina jugadores del diccionario de puntajes

- Un diccionario se debe declarar como una variable para poder eliminar elementos de él.
- Puedes eliminar elementos de un diccionario usando el [método adecuado][dictionary-docs].

## 4. Restablece el puntaje de un jugador

- Un diccionario se debe declarar como una variable para poder cambiar los valores que contiene.
- Puedes actualizar los valores de un diccionario usando la [sintaxis de subíndices de diccionario][dictionary-subscripts].

## 5. Actualiza el puntaje de un jugador

- Un diccionario se debe declarar como una variable para poder cambiar los valores que contiene.
- Puedes actualizar los valores de un diccionario usando la [sintaxis de subíndices de diccionario][dictionary-subscripts].

## 6. Obtén una lista de jugadores con sus puntajes ordenados por nombre del jugador

- Puedes ordenar los elementos de un diccionario usando el [método adecuado][dictionary-docs].
- Necesitarás definir una función de ordenamiento de tipo `((String, Int), (String, Int)) -> Bool` para pasarla al método `sorted(by:)`.
- La función de ordenamiento debe devolver `true` si el par clave/valor de la izquierda debe aparecer _antes_ que el par clave/valor de la derecha en el resultado ordenado.

## 7. Obtén una lista de jugadores ordenados por el puntaje del jugador en orden descendente

- Puedes ordenar los elementos de un diccionario usando el [método adecuado][dictionary-docs].
- Necesitarás definir una función de ordenamiento de tipo `((String, Int), (String, Int)) -> Bool` para pasarla al método `sorted(by:)`.
- La función de ordenamiento debe devolver `true` si el par clave/valor de la izquierda debe aparecer _antes_ que el par clave/valor de la derecha en el resultado ordenado.
