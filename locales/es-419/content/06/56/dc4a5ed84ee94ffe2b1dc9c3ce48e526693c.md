# Introducción

PHP ofrece varios operadores para realizar operaciones aritméticas. PHP sigue el orden de operaciones matemático estándar para sus operadores aritméticos. Los operadores que proporciona PHP son:

* Identidad (+)
* Negación (-)
* Suma (+)
* Resta (-)
* Multiplicación (*)
* División (/)
* Módulo (%)
* Exponenciación (**)

```php
$moles = +'10';
$aLotOfMoles = 6.022 * 10**23 * $moles;
```
