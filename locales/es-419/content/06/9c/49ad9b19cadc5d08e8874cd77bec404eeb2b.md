# Pruebas

Puedes implementar un ejercicio en tu propio sistema SAP. Sigue estos pasos:

1. Crear un paquete SAP para todos los ejercicios de Exercism en tu sistema (nombre recomendado: `$EXERCISM`)
2. Crear un paquete SAP para cada ejercicio como subpaquete (nombre recomendado: `$EXERCISM_<name-of-exercise>`, ejemplo: `$EXERCISM_HELLO-WORLD`)
3. Crear una clase ABAP correspondiente al ejercicio (ejemplo: `ZCL_HELLO_WORLD`)
4. Copiar el código de la plantilla de Exercism a la clase
5. Mantener las clases de prueba y copiar el código de Exercism a la clase de prueba

Ahora puedes completar la implementación de la clase y ejecutar la prueba unitaria para ver si tu solución funciona correctamente.

Nota: Esta configuración de paquetes te permitirá respaldar todo tu trabajo usando [abapGit](https://abapgit.org) al crear un repositorio para el paquete `$EXERCISM`.

Para más detalles, consulta la [documentación de ABAP de Exercism](https://exercism.org/docs/tracks/abap).
