# Acerca de

Una definición de colección normalmente incluye un marcador de posición entre paréntesis angulares, al que por convención se suele llamar T. A una colección así se le llama tipo genérico. Esto permite que quien use la colección especifique qué tipo de elementos se guardan en ella. En el ejemplo de código anterior estamos creando una instancia de una lista de strings.

Una clase o una función se vuelve **genérica** mediante el atributo `@:generic`. Esto hace que el compilador identifique la clase o la función como genérica:

```haxe
@:generic
class MyValue<T> {
  public var value:T;

  public function new(value:T) {
    this.value = value;
  }
}

var a = MyValue<String>("Hello");
trace(a.value); // Hello
```
