## General

- Lee sobre los [bitstrings][bitstring] en la guía de introducción.
- Revisa la documentación de la [forma especial bitstring][bitstring-form].
- Revisa [cómo convertir números decimales a números binarios][decimal-to-binary-youtube].
- Elixir admite [distintas formas de escribir números enteros][integer-literal], incluida la notación binaria.

## 1. Calcula el tamaño de bits de la paleta

- Esta tarea no usa el tipo de dato bitstring.
- Encuentra el número positivo más pequeño `n` tal que 2 elevado a la potencia `n` sea mayor o igual que el número de colores que necesitamos representar.
- Crea una función recursiva para esto.
- Elige un tamaño de bits inicial de 1. Si 2 elevado al tamaño de bits es mayor o igual que la cantidad de colores, ya encontramos nuestro tamaño de bits. Si no, suma 1 al tamaño de bits y vuelve a comprobar (recursión).
- Usa el [operador de potencia `**`][power-operator] para elevar 2 a una potencia dada.

## 2. Crea una imagen vacía

- Usa la [forma especial bitstring][bitstring-form] para crear un bitstring nuevo.

## 3. Crea una imagen de prueba

- Usa la [forma especial bitstring][bitstring-form] para crear un bitstring nuevo.
- Usa el [operador de tipo][type-operator] para especificar el tamaño de bits de cada fragmento.

## 4. Agrega un píxel al inicio de una imagen

- La [forma especial bitstring][bitstring-form] se puede usar para agregar un fragmento nuevo a un bitstring existente.
- Usa el [operador de tipo][type-operator] para especificar el tamaño de bits del fragmento nuevo y también del bitstring existente.
- Usa la función `PaintByNumber.palette_bit_size/1` que implementaste antes para obtener el tamaño de bits del fragmento nuevo.
- Usa el tipo especial `::bitstring` para especificar que el fragmento antiguo es de tamaño desconocido.

## 5. Obtén el primer píxel de una imagen

- La [forma especial bitstring][bitstring-form] se puede usar para [hacer pattern matching sobre bitstrings][bitstring-matching].
- Usa la función `PaintByNumber.palette_bit_size/1` que implementaste antes para obtener el tamaño de bits de un píxel.
- Usa el tipo especial `::bitstring` para especificar que el resto del bitstring es de tamaño desconocido.

## 6. Quita el primer píxel de una imagen

- La [forma especial bitstring][bitstring-form] se puede usar para [hacer pattern matching sobre bitstrings][bitstring-matching].
- Usa la función `PaintByNumber.palette_bit_size/1` que implementaste antes para obtener el tamaño de bits de un píxel.
- Usa el tipo especial `::bitstring` para especificar que el resto del bitstring es de tamaño desconocido.

## 7. Concatena dos imágenes

- La [forma especial bitstring][bitstring-form] se puede usar para concatenar dos bitstrings.
- Usa el tipo especial `::bitstring` para especificar que cada uno de los fragmentos de bitstring es de tamaño desconocido.
