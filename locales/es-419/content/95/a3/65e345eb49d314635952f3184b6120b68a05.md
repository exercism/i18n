# Introducción

## Excepciones

Las excepciones en C# ofrecen una forma estructurada, uniforme y con seguridad de tipos de manejar las condiciones de error que ocurren durante la ejecución. Manejar bien las excepciones y los errores es importante cuando se intenta evitar que la aplicación se bloquee.

En C#, todas las excepciones tienen la clase `System.Exception` como su tipo base. Esta contiene propiedades importantes, como `Message`, que contiene una descripción legible de la razón por la que se lanza la excepción.

Para indicar que debe haber un error en cierta parte del código, hay que crear un nuevo objeto de excepción y luego lanzarlo, usando la palabra clave `throw`:

```csharp
using System;
static int Square(int number)
{
    if (number >= 46341)
    {
        throw new ArgumentException($"Argument {number} cannot be higher than 46340 as its' square doesn't fit into int type.");
    }
    return number * number;
}
```

Cuando se lanza una excepción, el entorno de ejecución tiene la tarea de encontrar un fragmento de código que se encargue de manejar esa excepción. Si no se encuentra un controlador adecuado, el entorno de ejecución muestra el mensaje de excepción no controlada, además de detener la ejecución del programa.

Para crear un controlador para una excepción, C# usa la sentencia try-catch, que consta de un bloque `try` y una o más cláusulas `catch`. El bloque `try` debe contener y proteger el código que puede provocar que se lance la excepción. Las cláusulas `catch` deben contener el código que maneja el comportamiento del programa después de que haya ocurrido el error. Es importante tener en cuenta que el orden de las excepciones importa después del bloque `try`, ya que, cuando se enumeran varias excepciones, se ejecuta la primera cláusula `catch` que coincida.

```csharp
try
{
   if (number == 42)
   {
       throw new ArgumentException("The number cannot be equal to 42.", "number");
   }

   if (number < 0)
   {
      throw new ArgumentOutOfRangeException("number", "The number cannot be negative.");
   }

    // Process number ...
}
catch (ArgumentOutOfRangeException e)
{
    Console.WriteLine($"Number is out of range: {e.Message}.");
}
catch (ArgumentException)
{
    Console.WriteLine("Invalid number.");
}
```
