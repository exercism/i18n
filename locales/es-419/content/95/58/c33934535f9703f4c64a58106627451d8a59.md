# Apéndice de instrucciones

## Cómo está estructurado este ejercicio en Python

Este ejercicio se resuelve mejor con el operador `%` de Python ([módulo][modulo]), que devuelve el residuo de la división entera de números positivos.
Tiene un método equivalente, `operator.mod()`, en el [módulo operator][operator-mod].


Python también ofrece métodos adicionales de «remainder» en el [módulo math][math-module].
[`math.fmod()`][fmod] se comporta como `%`, pero opera sobre números de punto flotante.
[`math.remainder()`][remainder] implementa un algoritmo de «paso más cercano a cero» para el residuo de la división.
Aunque te animamos a familiarizarte con estos métodos, ninguno de los dos coincidirá exactamente con el resultado de `%`, y no se recomiendan para este ejercicio.

La función integrada [`divmod()`][divmod] también dará un residuo que coincide con `%` si se usa con dos enteros positivos, pero devuelve una `tuple` que hay que desempaquetar.
