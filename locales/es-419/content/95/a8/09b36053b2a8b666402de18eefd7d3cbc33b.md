# Pistas

## General

- Para declarar un numeral con un tipo específico, se agrega el tipo al numeral, por ejemplo `42_u8` para un entero sin signo de 8 bits.
- Para convertir entre tipos diferentes, se llama al método `to_<type>` del numeral, por ejemplo `42u8.to_u16` para un entero sin signo de 16 bits.

## 1. Constantes de navegación

- Necesitas definir [constantes][constants] que deben contener un [número entero][integers].
- La constante debe declararse dentro de la clase `Navigation`.
- La constante debe declararse fuera de cualquier método.

## 2. Análisis correcto del área

- Necesitas convertir el argumento a un entero sin signo.

## 3. Calcula la velocidad

- Para obtener la velocidad, divide la distancia entre el tiempo.
- El resultado de una operación numérica será del tipo de mayor precisión, así que necesitas convertir el resultado al tipo correcto.
