# Instalación

## Usuarios de Windows

Instala el [Subsistema de Windows para Linux][wsl-link] y consulta la siguiente sección.

## Usuarios de Linux/Mac

### Instalación con brew

Esta es la forma más sencilla de instalar Chapel.
Te dará una instalación básica que funciona, adecuada para trabajar en el track de Exercism.
Los usuarios más avanzados quizá prefieran compilar Chapel desde el código fuente (siguiente sección).

0. Si aún no lo has hecho, instala el gestor de paquetes [brew][brew-link].
1. Primero, asegúrate de que brew esté actualizado ejecutando `brew update`
2. Instala Chapel ejecutando `brew install chapel`
3. Verifica que la instalación fue exitosa ejecutando `chpl --version`

Esto instalará el compilador de Chapel (`chpl`), el gestor de paquetes `mason`, que usaremos para ejecutar las pruebas, y la herramienta de generación de documentación `chpldoc`. No la necesitas para Exercism, pero es bueno tenerla por si (cuando :) ) quieres desarrollar tus propias bibliotecas en Chapel.

### Compilar Chapel desde el código fuente

Los usuarios más avanzados quizá quieran compilar Chapel desde el código fuente por su cuenta. Para hacerlo:

1. Instala los [requisitos previos][prereqs-link]
2. [Descarga][download-link] el archivo de la última versión de Chapel y extráelo.
3. Primero, debes preparar la instalación y la configuración en el lugar donde quieres instalar Chapel.
Esto puedes hacerlo ejecutando el script `configure` que se proporciona.
Simplemente ejecuta

```
./configure
```

Esto instalará los binarios, las bibliotecas y los archivos compartidos en `/usr/local/`; puedes cambiar esto con la opción `--prefix`.
Por ejemplo, si quieres instalar Chapel en `~/.chapel`, puedes hacer

```
./configure --prefix=~/.chapel
```

4. Para instalar el compilador y las herramientas, ejecuta

```
make
make mason
make chpldoc
make install
```

5. Asegúrate de que la carpeta `/dir/for/install/bin` esté en tu variable `PATH`.

Para obtener más información sobre las distintas formas de instalar Chapel y trabajar desde el código fuente, consulta la página [Compilar Chapel][building-link] de la documentación.
