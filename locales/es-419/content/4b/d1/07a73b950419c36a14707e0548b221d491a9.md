# Acerca de

PHP ofrece varios operadores para realizar operaciones aritméticas. PHP sigue el orden de operaciones matemático estándar para sus operadores aritméticos. Los operadores que ofrece PHP son:

* Identidad (+)
* Negación (-)
* Suma (+)
* Resta (-)
* Multiplicación (*)
* División (/)
* Módulo (%)
* Exponenciación (**)

Veamos cada uno y cómo se pueden usar:

## Identidad (+)

El operador de identidad (+) trabaja sobre un solo valor (operador unario). Se resuelve al valor `float` o `int` de la variable.

```php
$value = '42';
$answer = +$value; // 42 (int)
```

## Negación (-)

El operador de negación trabaja sobre un solo valor (operador unario) y devuelve el opuesto del valor numérico.

```php
$forward = 65;
$reverse = -$forward; // -65
```

## Suma (+) y resta (-)

El operador de suma suma los dos valores que están a cada lado, mientras que el operador de resta resta el valor de la derecha al valor de la izquierda.

```php
$apples = 5;
$yourApples = 0;

$apples = $apples - 2; // 3
$yourApples = $yourApples + 2; 2
```

## División (/)

El operador de división da el resultado de dividir el valor de la izquierda entre el valor de la derecha. Si el valor de la derecha es 0, provocará un error `DivisionByZeroError`.

```php
$slicesOfPizza = 8;
$people = 4;
$slicesPerPerson = $slicesOfPizza / $people; // 2
```

## Multiplicación (*)

El operador de multiplicación devuelve el resultado de multiplicar el valor de la izquierda por el de la derecha.

```php
$tires = 4;
$priceOfTire = 250;
$totalCost = $tires * $priceOfTire; // 1000
```

## Módulo (%)

El operador módulo devuelve el residuo cuando el valor de la izquierda se divide entre el valor de la derecha. Este operador es muy útil para determinar si un número divide exactamente a otro, para saber si un valor es par o impar y para mucho más.

```php
$value = 3;
$isOdd = $value % 2;
if ($isOdd === 1) {
    echo 'Yes, it is odd!';
} else {
    echo 'It is even.';
}
```

## Exponenciación (**)

El operador de exponenciación se usa para elevar el valor de la izquierda a la potencia del valor de la derecha. Antes de PHP 5.6 tenías que usar la función `pow` para lograr lo mismo.

```php
$sideLength = 13;
$areaOfSquare = $sideLength ** 2; // 169
```

El operador de exponenciación admite enteros y números de punto flotante en ambos lados, así que puedes usarlo para calcular raíces cuadradas (u otras raíces) o valores exponenciales más complejos.

```php
$squareArea = 144;
$side = $squareArea ** .5; // 12
```

## Orden de las operaciones

PHP sigue el orden de operaciones estándar de las matemáticas. Esto significa que, en lugar de realizar las operaciones de izquierda a derecha, cada operador tiene una precedencia y las operaciones se resuelven según esa precedencia. El orden de las operaciones es:

* paréntesis
* exponenciación
* multiplicación, división
* suma, resta

La multiplicación y la división tienen el mismo nivel de precedencia entre sí. De forma similar, la suma y la resta tienen el mismo nivel de precedencia.

Esto significa que el valor de abajo sería 17 en lugar de 10, ya que la multiplicación tiene mayor precedencia que la suma:

```php
$value = 2 + 3 * 5;
```

PHP también ofrece varios operadores de asignación útiles que combinan los operadores aritméticos con la asignación cuando realizas una operación sobre una variable y asignas el resultado de vuelta a ella misma. Estos se explican en el concepto `Assignment Operators`.
