# Introducción

## Verdadero y falso

Los estados lógicos verdadero y falso se representan con `true` y `false` en Ruby.

```ruby
happy = true
sad = false
```

## Igualdad y comparación

Ruby te permite comparar objetos entre sí con los símbolos de igualdad habituales:
- Usa `==` para ver si dos objetos son iguales
- Usa `>` para ver si el objeto de la izquierda es **mayor que** el objeto de la derecha
- Usa `<` para ver si el objeto de la izquierda es **menor que** el objeto de la derecha.
- Usa `>=` o `<=` para comprobar si es «mayor o igual que» y «menor o igual que», respectivamente.

También puedes usar lógica booleana con los operadores habituales:
- Usa `&&` o `and` para comprobar si `x and y` son verdaderos
- Usa `||` o `or` para comprobar si `x or y` es verdadero.
- Usa `!` o `not` para invertir la igualdad, por ejemplo `x != y` (x no es igual a y)

Aquí tienes algunos ejemplos:
```ruby
# Is "true equal to false"? 
true == false # false

# Is "true not equal to false"
true != false # true

# Is 5 greater than 4?
5 > 4 # true

# Is 3 less than or equal to 2?
3 <= 2 # false
```
