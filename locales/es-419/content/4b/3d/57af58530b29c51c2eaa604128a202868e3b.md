# Instrucciones

Vas a inicializar buffers vacíos y a listar los primeros cinco números, o elementos, de la secuencia de Fibonacci.

La secuencia de Fibonacci es un conjunto de números en el que el siguiente elemento es la suma de los dos anteriores. Empezamos la secuencia en uno. Así, los primeros dos elementos son 1 y 1.

## 1. Crea un buffer de `count` ceros.

Crea una función que cree un buffer de `count` ceros.

```rust
let my_buffer = create_buffer(5);
// [0, 0, 0, 0, 0]
```

## 2. Lista los primeros cinco elementos de la secuencia de Fibonacci

Crea una función que devuelva los primeros cinco números de la secuencia de Fibonacci.
Sus primeros cinco elementos son `1, 1, 2, 3, 5`

```rust
let first_five = fibonacci();
// [1, 1, 2, 3, 5]
```
