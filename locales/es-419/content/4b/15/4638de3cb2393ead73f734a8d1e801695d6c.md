# Acerca de la conversión de tipos

Go requiere una conversión explícita entre tipos diferentes.
Por ejemplo, esto provoca un error del compilador:

```go
var x int = 42
var f float64 = x // compiler error x is an int not a float64
```

La conversión entre tipos (también conocida como **casting**) se hace mediante una función con el nombre del tipo al que quieres convertir.
Un valor `v` se convierte al tipo `T` usando `T(v)`.
Por ejemplo, para convertir un `int` a un `float64` tendrías que hacer lo siguiente:

```go
var x int = 42 // x has type int
f := float64(x) // f has type float64 (ie. 42.0)
```

Lo mismo aplica a cualquier tipo personalizado:

```go
type Id int
var number int = 121 // number has type int
userId := Id(number) // userId now has type Id
```

## Conversión entre tipos primitivos y strings

Existe un paquete `strconv` para convertir entre tipos primitivos (como `int`) y `string`.

```go
import "strconv"

var intString string = "42"
var i, err = strconv.Atoi(intString)

var number int = 12
var s string = strconv.Itoa(number)
```

ADVERTENCIA: usar el método de conversión estándar no tiene este comportamiento.
Por ejemplo:

```go
var num int = 65
str := string(num) // str is now "A" not "65"
```

Estos son algunos de los otros métodos de conversión más comunes:

| Método      | Propósito                        |
| ----------- | -------------------------------- |
| ParseBool   | Convierte `string` a `bool`      |
| FormatBool  | Convierte `bool` a `string`      |
| ParseFloat  | Convierte `string` a `float`     |
| FormatFloat | Convierte `float` a `string`     |
| ParseInt    | Convierte `string` a `int`       |
| FormatInt   | Convierte `int` a `string`       |
