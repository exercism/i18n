# Anexo de instrucciones

## Agregar un método a la struct Int

Este ejercicio se centra en agregar métodos a la struct `Int` en Crystal.
Para lograrlo, tendrás que definir una struct con el nombre `Int`
y poner el método dentro de esta struct.

```crystal
struct Int
  # your solution here
end
```

Puedes encontrar el código fuente de la clase `Int` [aquí][int].
