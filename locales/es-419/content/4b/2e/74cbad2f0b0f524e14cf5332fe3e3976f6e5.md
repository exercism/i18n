# Acerca de

Un `generator` es una función o expresión que devuelve un tipo especial de [iterador][iterator] llamado [iterador generador][generator-iterator].
Los `Generator-iterators` son [perezosos][lazy iterator]: no almacenan sus `values` en memoria, sino que _generan_ sus valores cuando se necesitan.

Una función generadora se ve como cualquier otra función, pero contiene una o más [expresiones yield][yield expression].
Cada `yield` suspenderá la ejecución del código, guardando el estado actual de ejecución (_incluidas todas las variables locales y las sentencias try_).
Cuando el generador se reanuda, retoma el estado desde donde se suspendió, a diferencia de las funciones normales, que se reinician en cada llamada.


## Cómo construir un generador

Los generadores se construyen de forma muy similar a otras funciones iterativas o recursivas, pero requieren una [expresión `yield`](#the-yield-expression), que exploraremos con más detalle un poco más adelante.

Un ejemplo es una función que devuelve los _cuadrados_ de una lista de números dada.  
Tal como está escrita, debe procesarse toda la entrada antes de que se pueda devolver algún valor:

```python
>>> def squares(list_of_numbers):
...     squares = []
...     for number in list_of_numbers:
...         squares.append(number ** 2)
...     return squares
```

Puedes convertir esa función en un generador así:

```python
>>> def squares_generator(list_of_numbers):
...     for number in list_of_numbers:
...         yield number ** 2
```

La razón de esto es que usas un generador cuando no necesitas todos los valores _a la vez_.

Esto ahorra memoria y capacidad de procesamiento, ya que solo se calcula el valor con el que estás _trabajando en ese momento_.


## Cómo usar un generador

Los generadores (_técnicamente, [`generator-iterator`s][generator-iterator]; consulta la nota a continuación._) son un tipo de `iterator` y pueden usarse en cualquier lugar de Python donde se espere un `iterator` o un `iterable`.
Esto incluye _funciones_ u _objetos_ que requieren un `iterable`/`iterator` como argumento.
Para profundizar más, consulta [Cómo crear un iterador en Python][how-to-iterator].


~~~~exercism/note

Los iteradores generadores son un subconjunto especial de [iteradores][iterator].
Los `Iterators` son el mecanismo o protocolo que permite iterar sobre _iterables_.
Los iteradores generadores y los iteradores que devuelven los [`iterables`][iterables] comunes de Python se comportan de forma muy similar, pero hay algunas diferencias importantes que conviene tener en cuenta:

- Se _[evalúan de forma perezosa][lazy evaluation]_; la iteración es _unidireccional_ y no hay forma de «retroceder» a un valor anterior.
- Se _consumen_ al iterar sobre los valores devueltos; no se reinician ni se guardan en memoria.
- No se pueden ordenar ni invertir.
- No son tipos de secuencia y _no_ tienen `indexes`. 
  No puedes referenciar un valor anterior o futuro mediante suma o resta, y no puedes usar la notación de corchetes (`[]`) ni el slicing.
- No se pueden usar con la función `len()`, ya que no tienen longitud.
- Pueden ser _finitos_ o _infinitos_; ¡ten cuidado al recopilar todos los valores de un `generator-iterator` _infinito_!

Para usar el generador `squares_generator()`:

```python
>>> squared_numbers = squares_generator([1, 2, 3, 4])

>>> for square in squared_numbers:
...     print(square)
...
1
4
9
16
```

Los valores dentro de un generador también se pueden producir o acceder mediante la función `next()`.
`next()` llama al método `__next__()` de un objeto generador, «avanzando» o evaluando el código del generador hasta su expresión `yield`, que entonces «produce» o devuelve el valor.

```python
>>> squared_numbers = squares_generator([1, 2])

>>> next(squared_numbers)
1
>>> next(squared_numbers)
4
```

Cuando un `generator` se consume por completo y no le quedan más valores por devolver, lanza un error `StopIteration`.

```python
>>> next(squared_numbers)
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
StopIteration
```

### Diferencia entre iterables y generadores

Los generadores son un subconjunto especial de _iteradores_.
Los `Iterators` son el mecanismo o protocolo que permite iterar sobre _iterables_.
Los generadores y los iteradores que devuelven los [`iterables`][iterables] comunes de Python se comportan de forma muy similar, pero hay algunas diferencias importantes que conviene tener en cuenta:

- Los generadores son _unidireccionales_; no hay forma de «retroceder» a un valor anterior.

- Iterar sobre los generadores consume los valores devueltos; no se reinician.

- Los generadores (_al evaluarse de forma perezosa_) no se pueden ordenar ni invertir.

- Los generadores _no_ tienen `indexes`, así que no puedes referenciar un valor anterior o futuro mediante suma o resta.

- Los generadores no se pueden usar con la función `len()`.

- Los generadores pueden ser _finitos_ o _infinitos_; ten cuidado al recopilar todos los valores de un generador _infinito_.

## La expresión yield

La [expresión yield][yield expression] es muy similar a la expresión `return`.

_A diferencia_ de la expresión `return`, `yield` entrega valores a quien la llama en un _punto específico_, suspendiendo la evaluación o el retorno de cualquier valor adicional hasta que se soliciten.

Cuando se evalúa `yield`, se pausa la ejecución de la función que la contiene y se devuelven los valores de la función _en ese momento_.

La función entonces _permanece en el ámbito_, y cuando se llama a `__next__()`, la ejecución se reanuda hasta que se encuentra `yield` de nuevo.

~~~~exercism/note
El uso de expresiones `yield` está prohibido fuera de las funciones.
~~~~

```python
>>> def infinite_sequence():
...     current_number = 0
...     while True:
...         yield current_number
...         current_number += 1

>>> lets_try = infinite_sequence()
>>> lets_try.__next__()
0
>>> lets_try.__next__()
1
```

## ¿Por qué usar generadores?

Los generadores son útiles en muchas aplicaciones.

Cuando trabajas con una colección grande, quizás no quieras poner todos sus valores en `memory`.
Un generador se puede usar para trabajar con datos más grandes poco a poco, ahorrando memoria y mejorando el rendimiento.

Los generadores también son muy útiles cuando un proceso o cálculo es _complejo_, _costoso_ o _infinito_:

```python
>>> def infinite_sequence():
...     current_number = 0
...     while True:
...         yield current_number
...         current_number += 1
```

Ahora, cada vez que se llama a `__next__()` en el objeto `infinite_sequence`, devolverá el _número anterior_ + 1.
