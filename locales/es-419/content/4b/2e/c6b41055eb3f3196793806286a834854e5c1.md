# Pausar las contribuciones de la comunidad

Algunos repositorios no tienen los recursos para clasificar/revisar los issues o pull requests de usuarios que no son mantenedores.
La pausa de las soluciones de la comunidad
Si un repositorio tiene habilitado este workflow, comentará automáticamente en un issue o pull request recién abierto si quien lo abrió _no_ es miembro de la organización de GitHub de Exercism.
El comentario le sugerirá al usuario que primero abra un tema en el foro de Exercism.

## Habilitar el workflow

Agrega el [archivo .github/workflows/pause-community-contributions.yml](https://github.com/exercism/github-actions/blob/b5424c17f661f5529493258a1ad480013351aa9e/.github/workflows/pause-community-contributions.yml) a tu repositorio.

## Deshabilitar el workflow

Elimina el archivo del workflow de tu repositorio.

## Origen

El workflow se define en el archivo `.github/workflows/pause-community-contributions.yml`.
