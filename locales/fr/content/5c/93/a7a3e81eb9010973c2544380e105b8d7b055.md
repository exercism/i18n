# Boucles

En Swift, il existe trois principaux types de boucles : les boucles _while_, qui répètent un bloc de code tant qu'une condition donnée est vraie, les boucles _repeat-while_, qui sont similaires aux boucles _while_ mais qui ont la garantie d'exécuter le bloc de code au moins une fois, et les boucles _for-in_, qui exécutent un bloc de code une fois pour chaque élément d'une collection.
