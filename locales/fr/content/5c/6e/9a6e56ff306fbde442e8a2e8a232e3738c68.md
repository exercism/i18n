# Introduction

Le fait qu'un tableau soit aussi une _collection_ signifie que, en plus d'accéder aux valeurs par leur indice, on peut itérer sur _toutes_ ses valeurs à l'aide d'une boucle `foreach` :

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // Output the vowel
    System.Console.Write(vowel);
}

// => aeiou
```
