# Instructions

Dans cet exercice, on va jouer avec une voiture télécommandée, que tu as enfin réussi à t'offrir après avoir économisé assez d'argent.

Les voitures démarrent avec une batterie pleine (100 %).
Chaque fois que tu conduis la voiture avec la télécommande, elle parcourt 20 mètres et consomme un pour cent de la batterie.
Le surnom de la voiture n'est connu qu'au moment où elle est créée.

La voiture télécommandée possède un bel affichage LED qui montre deux informations :

- La distance totale qu'elle a parcourue, affichée sous la forme : `"<METERS> meters"`.
- La charge restante de la batterie, affichée sous la forme : `"Battery at <PERCENTAGE>%"`.

Si la batterie est à 0 %, tu ne peux plus conduire la voiture et l'affichage de la batterie indiquera `"Battery empty"`.

## 1. Crée une voiture télécommandée toute neuve

Implémente la fonction `new_remote_control_car/0` pour renvoyer un objet voiture télécommandée toute neuve :

```jq
new_remote_control_car
# => {
#      "battery_percentage": 100,
#      "distance_driven_in_meters": 0,
#      "nickname": null
#    }
```

## 2. Crée une voiture télécommandée toute neuve avec un surnom

Implémente la fonction `new_remote_control_car/1` pour renvoyer un objet voiture télécommandée toute neuve avec un surnom fourni :

```jq
new_remote_control_car("Blue")
# => {
#      "battery_percentage": 100,
#      "distance_driven_in_meters": 0,
#      "nickname": "Blue"
#    }
```

## 3. Affiche la distance

Implémente la fonction `display_distance/0` qui prend un objet voiture en entrée et renvoie la _string_ de distance telle qu'affichée sur l'écran LED :

```jq
new_remote_control_car | display_distance
# => "0 meters"
```

## 4. Affiche le pourcentage de batterie

Implémente la fonction `display_battery/0` qui prend un objet voiture en entrée et renvoie la _string_ du pourcentage de batterie telle qu'affichée sur l'écran LED :

```jq
new_remote_control_car | display_battery
# => "Battery at 100%"
```

Si la batterie est à 0 %, l'affichage de la batterie indique « Battery empty ».

## 5. La conduite modifie la batterie et la distance parcourue

Implémente la fonction `drive/0` qui :

- prend un objet voiture en entrée
- augmente de 20 le nombre de mètres parcourus
- consomme 1 % de la batterie
- renvoie l'objet voiture modifié

```jq
new_remote_control_car("Red") | drive
# => {
#      "battery_percentage": 99,
#      "distance_driven_in_meters": 20,
#      "nickname": "Red"
#    }
```

## 6. Prends en compte la conduite avec une batterie à plat

Modifie la fonction `drive/0` pour qu'elle n'augmente pas la distance parcourue et ne diminue pas le pourcentage de batterie lorsque la batterie est à plat (à 0 %) :

```jq
{
  battery_percentage: 0,
  distance_driven_in_meters: 2000,
  nickname: "Red"
} | drive
# => {
#      "battery_percentage": 0,
#      "distance_driven_in_meters": 2000,
#      "nickname": "Red"
#    }
```
