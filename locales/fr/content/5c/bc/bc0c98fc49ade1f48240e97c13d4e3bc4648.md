# Introduction

## Result

Le type `Result` est la solution proposée par le langage Elm pour signaler les erreurs, et un moyen de s'en remettre. Il ressemble un peu au type `Maybe`, mais là où Maybe peut être renvoyé par des fonctions qui peuvent échouer, il ne dit rien sur la raison de cet échec. Result inclut ce contexte sur les raisons de l'échec.

Le type `Result` se définit comme suit :

```elm
type Result error value
  = Ok value
  | Err error
```

On parle de définition de « type personnalisé » dans la terminologie Elm.
Les `error` et `value` dans `OK value` et `Error error` représentent une variable de type, ce qui signifie qu'elle peut être de n'importe quel type, comme `Int`, `Bool` ou `String`.
Ainsi, un `Result String Int` est une variable censée contenir un `Int`, et en cas d'erreur, celle-ci sera représentée par une `String`.
Il existe un [module Result](https://package.elm-lang.org/packages/elm/core/latest/Result) avec plein de fonctions utilitaires bien pratiques pour Result.
