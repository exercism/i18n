# Instructions

Dans cet exercice, tu vas mettre en place la gestion des erreurs d'une calculatrice d'entiers simple.
Pour simplifier les choses, des méthodes permettant de calculer l'addition, la multiplication et la division sont fournies.

L'objectif est d'obtenir une calculatrice fonctionnelle qui renvoie une `String` selon le format suivant : `16 + 51 = 67`, lorsqu'on lui fournit les arguments `16`, `51` et `+`.

```java
CalculatorConundrum calculator = new CalculatorConundrum();

calculator.calculate(16, 51, "+");
// => returns "16 + 51 = 67"

calculator.calculate(32, 6, "*");
// => returns "32 * 6 = 192"

calculator.calculate(512, 4, "/");
// => returns "512 / 4 = 128"
```

## 1. Implémente la méthode calculate pour prendre en charge quelques opérations de base

La méthode principale à implémenter dans cette tâche sera la méthode `CalculatorConundrum.calculate()`.
Elle prend trois arguments.
Les deux premiers arguments `operand1` et `operand2` sont les nombres entiers sur lesquels porte l'opération.
Le troisième argument `operation` est de type `String` et, pour cet exercice, il est nécessaire d'implémenter les opérations suivantes :

- l'addition à l'aide de la `String` `+`
- la multiplication à l'aide de la `String` `*`
- la division à l'aide de la `String` `/`

## 2. Gère les opérations invalides

Modifie la méthode `CalculatorConundrum.calculate()` pour gérer les opérations invalides :

- Lorsque l'argument `operation` vaut `null`, une `IllegalArgumentException` doit être levée avec le message `Operation cannot be null`.
- Lorsque l'argument `operation` vaut `""`, une `IllegalArgumentException` doit être levée avec le message `Operation cannot be empty`.
- Lorsque l'argument `operation` est une opération autre que `+`, `*` ou `/`, une `IllegalOperationException` doit être levée avec le message `Operation '{operation}' does not exist`.

```java
calculator.calculate(10, 1, null);
// => throws IllegalArgumentException with message "Operation cannot be null"

calculator.calculate(10, 1, "");
// => throws IllegalArgumentException with message "Operation cannot be empty"

calculator.calculate(10, 1, "-");
// => throws IllegalOperationException with message "Operation '-' does not exist"
```

## 3. Gère l'exception levée lors d'une division par zéro

En Java, une tentative de division par zéro lève une `ArithmeticException`.
Modifie la méthode `CalculatorConundrum.calculate()` pour intercepter cette exception, puis lever une `IllegalOperationException` avec le message `Division by zero is not allowed` et l'`ArithmeticException` interceptée comme cause.

```java
calculator.calculate(512, 0, "/");
// => throws IllegalOperationException with message "Division by zero is not allowed"
```
