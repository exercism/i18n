# Tests

On peut exécuter les suites de tests des exercices PureScript depuis le répertoire de l'exercice à l'aide de l'outil spago :

    cd <exercism-workspace>/purescript/<exercise name>
    spago test

où <exercism-workspace> désigne le répertoire de travail de la CLI.

Par exemple :

    cd ~/exercism/purescript/accumulate
    spago test
