# Description

Implémente les opérations de base de la capacité `Stream`.

Dans les langages fonctionnels, les fonctions comme `filter`, `map` et
`reduce` sont très courantes. Implémente une série de combinateurs fonctionnels de base pour une capacité de flux, sans utiliser de fonctions existantes. Pour cela, tu devras écrire tes propres [gestionnaires de capacités](https://www.unison-lang.org/learn/fundamentals/abilities/writing-abilities/).

💡 On va appeler cette capacité `MyStream` pour éviter les conflits avec la capacité `Stream` qui existe déjà dans la bibliothèque standard.

Les opérations que tu devras implémenter sont :

* `MyStream.fromList` (*à partir d'un tableau d'éléments, crée un flux d'éléments* )
* `MyStream.toList` (*à partir d'un flux d'éléments, le matérialise en un tableau*)
* `MyStream.toListWithResult` (*à partir d'un flux d'éléments, le matérialise en un tableau accompagné du résultat de la fonction de flux*)
* `MyStream.ignore` (*à partir d'un flux d'éléments, ignore les valeurs émises et renvoie le résultat de la fonction de flux*)
* `MyStream.filter` (*à partir d'un prédicat et d'un `MyStream`, renvoie le `MyStream` de tous les éléments pour lesquels `predicate(item)` est vrai*) ;
* `MyStream.map` (*à partir d'une fonction et d'un `MyStream`, renvoie le `MyStream` des résultats de l'application de `function(item)` à tous les éléments*) ;
* `MyStream.flatMap` (*à partir d'une fonction qui produit un `MyStream` et d'un `MyStream`, renvoie le `MyStream` des résultats de l'application de `function(item)` à tous les éléments*)
