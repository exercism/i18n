# Installation

## Utilisateurs de Windows

Installe [Windows Subsystem for Linux][wsl-link] puis consulte la section suivante.

## Utilisateurs de Linux et de Mac

### Installe avec brew

C'est la façon la plus simple d'installer Chapel.
Cela te donnera une installation de base fonctionnelle, suffisante pour travailler sur le parcours Exercism.
Les utilisateurs plus avancés voudront peut-être compiler Chapel à partir du code source (section suivante).

0. Si ce n'est pas déjà fait, installe le gestionnaire de paquets [brew][brew-link].
1. Tout d'abord, assure-toi que brew est à jour en exécutant `brew update`
2. Installe Chapel en exécutant `brew install chapel`
3. Vérifie que l'installation a réussi en exécutant `chpl --version`

Cela va installer le compilateur Chapel (`chpl`), le gestionnaire de paquets `mason`, que l'on utilisera pour exécuter les tests, ainsi que l'outil de génération de documentation `chpldoc`. Ce dernier n'est pas nécessaire pour Exercism, mais c'est bien de l'avoir si (quand :) ) tu veux développer tes propres bibliothèques en Chapel.

### Compile Chapel à partir du code source

Les utilisateurs plus avancés voudront peut-être compiler Chapel eux-mêmes à partir du code source. Pour cela :

1. Installe les [prérequis][prereqs-link]
2. [Télécharge][download-link] l'archive de la dernière version de Chapel et extrais-la.
3. Tout d'abord, tu dois préparer l'installation et configurer l'emplacement où tu veux installer Chapel.
Pour cela, exécute le script `configure` fourni.
Il suffit de lancer

```
./configure
```

pour installer les binaires, les bibliothèques et les fichiers partagés dans `/usr/local/`. Tu peux modifier ce chemin avec l'option `--prefix`.
Par exemple, si tu veux installer Chapel dans `~/.chapel`, tu peux faire

```
./configure --prefix=~/.chapel
```

4. Pour installer le compilateur et les outils, exécute 

```
make
make mason
make chpldoc
make install
```

5. Vérifie que le dossier `/dir/for/install/bin` figure bien dans ta variable `PATH`. 

Pour en savoir plus sur les différentes façons d'installer Chapel et de travailler à partir du code source, consulte la page [Compiler Chapel][building-link] de la documentation.
