# Introduction

## Les booléens en Julia

Les valeurs vrai ou faux sont représentées par le type `Bool`.
Il ne contient que deux valeurs : `true` et `false`.

```julia-repl
julia> true
true

julia> false
false
```

## Opérateurs booléens

Il existe trois opérateurs booléens en Julia.

`&&` est l'opérateur booléen « et ».
Il renvoie `true` si les expressions des *deux* côtés de `&&` valent `true`.

```julia-repl
julia> true && true
true

julia> true && false
false
```

`||` est l'opérateur booléen « ou ».
Il renvoie `true` si une expression de *l'un ou l'autre* côté de `||` vaut `true`.

```julia-repl
julia> true || true
true

julia> false || true
true
```

`!` est l'opérateur booléen « non ».
Il échange les valeurs `true` et `false`.

```julia-repl
julia> !true
false

julia> !false
true
```

Pour les expressions plus longues et plus compliquées, il vaut mieux utiliser des parenthèses pour que ton intention soit claire.

```julia-repl
julia> (true || false) && (false && true)
false
```
