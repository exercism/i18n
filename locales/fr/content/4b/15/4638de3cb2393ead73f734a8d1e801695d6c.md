# À propos de la conversion de types

Go exige une conversion explicite entre les différents types.
Par exemple, ceci provoque une erreur de compilation :

```go
var x int = 42
var f float64 = x // compiler error x is an int not a float64
```

La conversion entre types (aussi appelée **cast de type**) se fait au moyen d'une fonction qui porte le nom du type vers lequel on convertit.
Une valeur `v` est convertie en type `T` avec `T(v)`.
Par exemple, pour convertir un `int` en `float64`, il faut procéder ainsi :

```go
var x int = 42 // x has type int
f := float64(x) // f has type float64 (ie. 42.0)
```

Il en va de même pour les types personnalisés :

```go
type Id int
var number int = 121 // number has type int
userId := Id(number) // userId now has type Id
```

## Convertis entre types primitifs et _strings_

Il existe un paquet `strconv` pour convertir entre types primitifs (comme `int`) et `string`.

```go
import "strconv"

var intString string = "42"
var i, err = strconv.Atoi(intString)

var number int = 12
var s string = strconv.Itoa(number)
```

ATTENTION : utiliser la méthode de conversion standard ne produit pas ce comportement.
Par exemple :

```go
var num int = 65
str := string(num) // str is now "A" not "65"
```

Voici quelques-unes des autres méthodes de conversion courantes :

| Méthode     | Objectif                    |
| ----------- | --------------------------- |
| ParseBool   | Convertir `string` en `bool`  |
| FormatBool  | Convertir `bool` en `string`  |
| ParseFloat  | Convertir `string` en `float` |
| FormatFloat | Convertir `float` en `string` |
| ParseInt    | Convertir `string` en `int`   |
| FormatInt   | Convertir `int` en `string`   |
