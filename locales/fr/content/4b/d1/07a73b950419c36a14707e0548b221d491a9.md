# À propos

PHP fournit un certain nombre d'opérateurs pour effectuer des opérations arithmétiques. PHP suit l'ordre de priorité mathématique standard pour ses opérateurs arithmétiques. Les opérateurs fournis par PHP sont :

* Identité (+)
* Négation (-)
* Addition (+)
* Soustraction (-)
* Multiplication (*)
* Division (/)
* Modulo (%)
* Exponentiation (**)

Voyons maintenant chacun d'entre eux et comment ils peuvent être utilisés :

## Identité (+)

L'opérateur d'identité (+) s'applique à une seule valeur (opérateur unaire). Il renvoie la valeur `float` ou `int` de la variable.

```php
$value = '42';
$answer = +$value; // 42 (int)
```

## Négation (-)

L'opérateur de négation s'applique à une seule valeur (opérateur unaire) et renvoie l'opposé de la valeur numérique.

```php
$forward = 65;
$reverse = -$forward; // -65
```

## Addition (+) et soustraction (-)

L'opérateur d'addition additionne les deux valeurs situées de part et d'autre de lui, tandis que l'opérateur de soustraction soustrait la valeur de droite à celle de gauche.

```php
$apples = 5;
$yourApples = 0;

$apples = $apples - 2; // 3
$yourApples = $yourApples + 2; 2
```

## Division (/)

L'opérateur de division donne le résultat de la division de la valeur de gauche par la valeur de droite. Si la valeur de droite vaut 0, cela provoque une erreur `DivisionByZeroError`.

```php
$slicesOfPizza = 8;
$people = 4;
$slicesPerPerson = $slicesOfPizza / $people; // 2
```

## Multiplication (*)

L'opérateur de multiplication renvoie le résultat de la multiplication des valeurs de gauche et de droite.

```php
$tires = 4;
$priceOfTire = 250;
$totalCost = $tires * $priceOfTire; // 1000
```

## Modulo (%)

L'opérateur modulo renvoie le reste de la division de la valeur de gauche par la valeur de droite. Cet opérateur est très utile pour déterminer si un nombre en divise un autre de façon exacte, pour savoir si une valeur est paire ou impaire, et bien plus encore.

```php
$value = 3;
$isOdd = $value % 2;
if ($isOdd === 1) {
    echo 'Yes, it is odd!';
} else {
    echo 'It is even.';
}
```

## Exponentiation (**)

L'opérateur d'exponentiation permet d'élever la valeur de gauche à la puissance de la valeur de droite. Avant PHP 5.6, il fallait utiliser la fonction `pow` pour obtenir le même résultat.

```php
$sideLength = 13;
$areaOfSquare = $sideLength ** 2; // 169
```

L'opérateur d'exponentiation prend en charge les entiers et les nombres décimaux des deux côtés, ce qui permet de calculer des racines carrées (ou d'autres racines) ou des valeurs exponentielles plus complexes.

```php
$squareArea = 144;
$side = $squareArea ** .5; // 12
```

## Priorité des opérations

PHP suit l'ordre de priorité standard des opérations mathématiques. Cela signifie qu'au lieu d'effectuer les opérations de gauche à droite, chaque opérateur a une priorité et les opérations sont résolues en fonction de cette priorité. L'ordre de priorité est le suivant :

* les parenthèses
* l'exponentiation
* la multiplication, la division
* l'addition, la soustraction

La multiplication et la division ont le même niveau de priorité. De même, l'addition et la soustraction ont le même niveau de priorité.

Cela signifie que la valeur ci-dessous vaut 17 et non 10, car la multiplication a une priorité plus élevée que l'addition :

```php
$value = 2 + 3 * 5;
```

PHP fournit également un certain nombre d'opérateurs d'affectation pratiques qui combinent les opérateurs arithmétiques avec l'affectation, lorsque tu effectues une opération sur une variable et que tu réassignes le résultat à cette même variable. Ces opérateurs seront abordés dans le concept `Assignment Operators`.
