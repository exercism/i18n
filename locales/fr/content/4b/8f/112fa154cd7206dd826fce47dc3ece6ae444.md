# À propos

Les structures de données qui peuvent contenir zéro ou plusieurs éléments sont appelées _collections_.
Un **tableau** en Ruby est une collection qui conserve l'ordre dans lequel ses objets sont ajoutés.
Un tableau peut contenir n'importe quel objet.
On peut ajouter des objets à un tableau ou les récupérer à l'aide d'un indice.
En Ruby, l'indexation des tableaux commence à zéro, ce qui signifie que l'indice du premier élément est toujours zéro :

```ruby
# Declare an array containing two values
two_ints = [1,2]

# Assign first and second element by index
two_ints[0] = 7
two_ints[1] = 8

# Retrieve the second element by index
two_ints[1] # => 8

# Check the length of the array
two_ints.size # => 2
```

En Ruby, il existe plusieurs façons de créer un tableau :

- En utilisant le constructeur littéral `[]` _(la plus courante)_
- En appelant explicitement `Array.new`
- En appelant la méthode `Array()` du module Kernel

La méthode `Array.new` accepte deux arguments facultatifs : la taille initiale du tableau et un objet par défaut.

Lorsqu'on fournit une taille et un objet par défaut, le tableau est rempli avec `size` copies de cet objet par défaut.

```ruby
a = Array.new(2, Hash.new)
# => [{}, {}]
```

Comme tous les éléments du tableau stockent le même _hash_, modifier l'un d'eux affecte tous les autres.

```ruby
a[0]['cat'] = 'feline'
a # => [{"cat"=>"feline"}, {"cat"=>"feline"}]

a[1]['cat'] = 'Felix'
a # => [{"cat"=>"Felix"}, {"cat"=>"Felix"}]
```

Si tu veux vraiment obtenir plusieurs copies distinctes, utilise la version avec un bloc, qui utilise le résultat de ce bloc chaque fois qu'un élément du tableau doit être initialisé :

```ruby
a = Array.new(2) {Hash.new}
a[0]['cat'] = 'feline'
a # => [{"cat"=>"feline"}, {}]
```

Une autre caractéristique des tableaux en Ruby est qu'ils incluent le module [Enumerable][enumerable-module], qui ajoute de nombreuses méthodes pratiques pour itérer, rechercher, trier, filtrer, etc. les éléments d'un tableau.

[enumerable-module]: https://docs.ruby-lang.org/en/master/Enumerable.html
[for-loop]: https://launchschool.com/books/ruby/read/loops_iterators#forloops
