# Instructions

Tu vas initialiser des tampons vides, puis lister les cinq premiers nombres, ou éléments, de la suite de Fibonacci.

La suite de Fibonacci est une suite de nombres dont chaque élément est la somme des deux précédents. On commence la suite à 1, donc les deux premiers éléments sont 1 et 1.

## 1. Crée un tampon de `count` zéros.

Crée une fonction qui crée un tampon de `count` zéros.

```rust
let my_buffer = create_buffer(5);
// [0, 0, 0, 0, 0]
```

## 2. Liste les cinq premiers éléments de la suite de Fibonacci

Crée une fonction qui renvoie les cinq premiers nombres de la suite de Fibonacci.
Ses cinq premiers éléments sont `1, 1, 2, 3, 5`

```rust
let first_five = fibonacci();
// [1, 1, 2, 3, 5]
```
