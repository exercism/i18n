# À propos

Il existe deux types de nombres différents en Elixir : les nombres entiers et les nombres décimaux.

Les nombres décimaux sont des nombres avec un ou plusieurs chiffres après le séparateur décimal. Ils utilisent le format à virgule flottante double précision sur 64 bits.

```elixir
float = 3.45
# => 3.45
```

Elixir prend aussi en charge la notation scientifique pour les nombres décimaux.

```elixir
1.25e-2
# => 0.0125
```

## Erreurs d'arrondi

Les nombres décimaux sont tristement célèbres pour leurs erreurs d'arrondi.

```elixir
0.1 + 0.2
# => 0.30000000000000004
```

Cependant, ce genre d'erreurs n'est pas propre à Elixir. Elles se produisent dans tous les langages de programmation. En effet, toutes les données de nos ordinateurs sont stockées et traitées sous forme de code binaire. En binaire, seules les fractions dont le dénominateur peut s'écrire sous la forme `2^n` (par exemple `1/4`, `3/8`, `5/16`) peuvent être représentées exactement. Les autres fractions ne sont représentées que par des approximations.

```elixir
# 3/4
Float.ratio(0.75)
# => {3, 4}

# 3/5
Float.ratio(0.6)
# => {5404319552844595, 9007199254740992}
```

Tu peux en apprendre plus sur ce problème sur [0.30000000000000004.com][0.30000000000000004.com]. La [page Float Toy][evanw.github.io-float-toy] propose une belle explication graphique de la façon dont les bits d'un nombre à virgule flottante sont convertis en une valeur à virgule flottante concrète.

## Comparaison

Un nombre entier et un nombre décimal peuvent être considérés comme égaux ([`==`][kernel-equal]) s'ils ont la même valeur. Cependant, comme ce sont des types différents, ils ne sont jamais strictement égaux ([`===`][kernel-strictly-equal]).

```elixir
1 == 1.0
# => true

1 === 1.0
# => false
```

## Conversion

Les nombres entiers et les nombres décimaux peuvent être mélangés dans une même expression arithmétique. Utiliser un nombre décimal dans une expression garantit que le résultat sera lui aussi un nombre décimal.

```elixir
2 * 3
# => 6

2 * 3.0
# => 6.0
```

On peut arrondir un nombre décimal (`round`), l'arrondir au supérieur (`ceil`) ou l'arrondir à l'inférieur (`floor`).

Pour arrondir un nombre décimal en un nombre décimal, utilise les fonctions du module `Float` ([`Float.round`][float-round], [`Float.ceil`][float-ceil], [`Float.floor`][float-floor]). Pour obtenir plutôt un entier, utilise les fonctions du module `Kernel` ([`round`][kernel-round], [`ceil`][kernel-ceil], [`floor`][kernel-floor]).

Une autre méthode pour transformer un nombre décimal en entier consiste à couper sa partie décimale avec [`trunc`][kernel-trunc].

```elixir
Float.ceil(5.2)
# => 6.0

ceil(5.2)
# => 6

trunc(5.2)
# => 5
```
