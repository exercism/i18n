# Mets en pause les contributions de la communauté

Certains dépôts n'ont pas les ressources nécessaires pour trier et examiner les _issues_ ou les _pull requests_ ouvertes par des utilisateurs qui ne font pas partie des mainteneurs.
Les solutions de la communauté en pause
Si un dépôt a activé ce workflow, il commentera automatiquement toute _issue_ ou _pull request_ nouvellement ouverte si son auteur n'est _pas_ membre de l'organisation GitHub d'Exercism.
Le commentaire suggérera à l'utilisateur d'ouvrir d'abord un sujet sur le forum d'Exercism.

## Active le workflow

Ajoute le [fichier .github/workflows/pause-community-contributions.yml](https://github.com/exercism/github-actions/blob/b5424c17f661f5529493258a1ad480013351aa9e/.github/workflows/pause-community-contributions.yml) à ton dépôt.

## Désactive le workflow

Supprime le fichier de workflow de ton dépôt.

## Source

Le workflow est défini dans le fichier `.github/workflows/pause-community-contributions.yml`.
