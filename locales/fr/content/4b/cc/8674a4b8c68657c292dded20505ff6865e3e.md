# Instructions supplémentaires

## Messages d'exception

Il est parfois nécessaire de [lever une exception](https://docs.python.org/3/tutorial/errors.html#raising-exceptions). Dans ce cas, tu dois toujours inclure un **message d'erreur explicite** pour indiquer l'origine de l'erreur. Cela rend le code plus lisible et facilite grandement le débogage. Si tu sais que l'erreur sera d'un type donné, tu peux choisir de lever l'un des [types d'erreur intégrés](https://docs.python.org/3/library/exceptions.html#base-classes), mais tu dois tout de même y joindre un message explicite.

Cet exercice en particulier te demande de réécrire la manière dont l'[instruction `raise`](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement) est utilisée, et à quel endroit, pour « lever » un `ValueError` lorsque l'arbre fourni en entrée n'est pas valide. Les tests ne réussiront que si le code lève l'`exception` appropriée et y joint un message approprié.
