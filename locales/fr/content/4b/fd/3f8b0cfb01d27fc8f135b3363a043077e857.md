# Introduction

## Vrai et faux

Les états logiques vrai et faux sont représentés par `true` et `false` en Ruby.

```ruby
happy = true
sad = false
```

## Égalité et comparaison

Ruby te permet de comparer des objets entre eux à l'aide des symboles d'égalité habituels :
- Utilise `==` pour vérifier si deux objets sont égaux
- Utilise `>` pour vérifier si l'objet à gauche est **supérieur à** l'objet à droite
- Utilise `<` pour vérifier si l'objet à gauche est **inférieur à** l'objet à droite.
- Utilise `>=` ou `<=` pour tester respectivement « supérieur ou égal à » et « inférieur ou égal à ».

Tu peux aussi utiliser la logique booléenne avec les opérateurs habituels :
- Utilise `&&` ou `and` pour vérifier si `x and y` sont vrais
- Utilise `||` ou `or` pour vérifier si `x or y` est vrai.
- Utilise `!` ou `not` pour inverser l'égalité, par exemple `x != y` (x n'est pas égal à y)

Voici quelques exemples :
```ruby
# Is "true equal to false"? 
true == false # false

# Is "true not equal to false"
true != false # true

# Is 5 greater than 4?
5 > 4 # true

# Is 3 less than or equal to 2?
3 <= 2 # false
```
