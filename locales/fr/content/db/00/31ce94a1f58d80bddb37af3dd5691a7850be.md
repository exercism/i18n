# Introduction

En Rust, les booléens sont représentés par le type `bool`, dont les valeurs peuvent être soit `true`, soit `false`.

Rust prend en charge six opérateurs de comparaison : `==` (égal), `!=` (différent), `>` (supérieur à), `<` (inférieur à), `>=`
(supérieur ou égal à), `<=` (inférieur ou égal à). Ils permettent d'évaluer la relation entre des valeurs non booléennes
pour obtenir une valeur booléenne.

```rust
1 > 0 // true
1 < 0 // false
1 == 0 // false
1 != 0 // true
1 >= 0 // true
1 <= 0 // false
```

Contrairement à certains autres langages, `0` n'est pas `false`, et une valeur non nulle n'est pas `true`.

Rust prend en charge deux opérateurs booléens : `||` (ou), `&&` (et). Ils ne sont évalués que lorsque l'opérande gauche ne détermine pas déjà
le résultat de l'expression. Autrement dit, `||` n'évalue son opérande droit que lorsque l'opérande gauche vaut
`false`, et `&&` seulement lorsqu'il vaut `true`.
