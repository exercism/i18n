# Apprentissage

## Apprends le C++ à partir de zéro

Le C++ est un langage doté d'une syntaxe riche et expressive, qui prend en charge plusieurs styles de programmation différents : procédural, orienté objet, fonctionnel et générique, ainsi que des combinaisons de tous ces styles dans un même programme. Ce parcours s'attache à proposer des problèmes dont la difficulté augmente progressivement. Certains éléments de la syntaxe du langage gagnent toutefois à être présentés autrement que sous la forme d'une série d'exercices.

De manière générale, Exercism part du principe que tu connais déjà la syntaxe et les mécanismes d'un langage dans un parcours donné. Or, connaître la syntaxe d'un langage ne représente que la première étape vers une véritable expertise. Exercism te permet de t'entraîner à résoudre des problèmes et d'échanger avec d'autres programmeurs qui ont résolu le même problème. C'est de ces discussions partagées que l'on tire l'expertise et les perspectives qui font de nous de meilleurs programmeurs.

Si tu débutes complètement avec le langage C++, tu devrais d'abord prendre le temps d'en apprendre les bases. Voici quelques ressources qui peuvent t'aider à démarrer :

* [Learn C++](http://www.learncpp.com/)
* [C++ Koans](https://github.com/torbjoernk/CppKoans)

[Coliru](http://coliru.stacked-crooked.com/) est une interface web simple, sous forme de formulaire, vers un compilateur C++ qui te permet d'essayer de petits programmes. C'est parfois plus facile pour faire une expérience rapide que de tout construire en local dans un environnement de développement intégré.

## Le développement piloté par les tests en C++

Exercism part du principe que tu connais le concept de développement piloté par les tests. Chaque exercice est accompagné d'une série de tests déjà écrits pour toi. Tu progresses dans l'exercice test après test, en écrivant l'implémentation petit à petit pour satisfaire les tests.

Si tu débutes avec le développement piloté par les tests, il est vivement recommandé de commencer par l'atelier [développement piloté par les tests en C++](https://github.com/boostcon/cppnow_presentations_2014/tree/master/files/test_driven) de [C++ Now! 2014](http://cppnow.org/). Les mêmes outils que dans cet atelier sont utilisés dans le parcours C++ sur Exercism.
