# Ajout aux instructions

## Mots

Définis un tuple `stopwatch` et un constructeur `<stopwatch> ( -- stopwatch )` qui renvoie un nouveau chronomètre dans l'état `"ready"`, sans temps écoulé ni tour précédent.

Fournis ces mots qui opèrent sur un chronomètre :

- `state ( stopwatch -- str )` : `"ready"`, `"running"` ou `"stopped"`.
- `current-lap ( stopwatch -- str )` : le temps écoulé du tour en cours sous forme de _string_ `"HH:MM:SS"`.
- `total ( stopwatch -- str )` : le temps écoulé cumulé du tour en cours et de tous les tours précédents, sous forme de _string_ `"HH:MM:SS"`.
- `previous-laps ( stopwatch -- seq )` : un tableau des tours enregistrés précédemment, chacun sous forme de _string_ `"HH:MM:SS"`.
- `start ( stopwatch -- )`, `stop ( stopwatch -- )`, `reset ( stopwatch -- )` et `lap ( stopwatch -- )` : les quatre commandes du tableau ci-dessus. Appeler l'une d'elles depuis un état qui ne l'autorise pas doit lever une erreur avec `throw`.

On fait avancer le temps avec :

- `advance-time ( str stopwatch -- )` : ajoute la durée `"HH:MM:SS"` au tour en cours. Cela n'a d'effet que tant que le chronomètre est en marche.
