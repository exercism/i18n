# Indices

## 1. Présente-toi

La fonction `introduce` doit « déballer » la valeur contenue dans `player.Name`.
Pense à utiliser la [fonction `Options.defaultValue`][defaultvalue] pour convertir `player.Name` en sa valeur « encapsulée » lorsqu'il vaut `Some`, ou en la valeur par défaut requise lorsqu'il vaut `None`.

## 2. Implémente la mécanique de réanimation

La fonction `revive` doit renvoyer soit `Some <player>`, soit `None`, où `<player>` est un enregistrement `Player` avec éventuellement certains champs modifiés.

## 3. Implémente la mécanique de lancer de sorts

Pense à utiliser une expression match pour couvrir les deux cas `Some` et `None`, comme dans l'exemple suivant :

```fsharp
let exists (x: int option) =
    match x with
    | Some n -> true
    | None -> false
```
