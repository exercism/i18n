# Instructions

Josh travaille sur un nouveau jeu de rôle et a besoin de ton aide pour implémenter certaines mécaniques.

## 1. Présente-toi

Implémente la fonction `introduce`.

Les joueurs furtifs peuvent cacher leur nom et seront alors présentés sous le nom de `"Mighty Magician"`. Sinon, utilise simplement le nom du joueur pour le présenter.

```gleam
introduce(Player(name: None, level: 2, health: 8, mana: None))
// -> "Mighty Magician"

introduce(Player(name: Some("Merlin"), level: 2, health: 8, mana: None))
// -> "Merlin"
```

## 2. Implémente la mécanique de réanimation

La fonction `revive` doit vérifier que le personnage du joueur est bien mort (sa santé a atteint 0).
Si c'est le cas, elle doit renvoyer une nouvelle instance de `Player` avec 100 points de santé.
Sinon, si le personnage du joueur n'est pas mort, la fonction `revive` renvoie `None`.

Si le niveau du joueur est supérieur ou égal à 10, il doit également être réanimé avec 100 points de mana.
Si le niveau du joueur est inférieur à 10, son mana ne doit pas être modifié.
La fonction `revive` doit préserver le niveau du joueur.

```gleam
let dead_player = Player(name: None, level: 2, health: 0, mana: None)

revive(dead_player)
// -> Some(Player(name: None, level: 2, health: 100, mana: None))
```

Si la méthode `revive` est appelée sur un joueur dont la santé est supérieure ou égale à 1, la fonction doit renvoyer `None`.

```gleam
let alive_player = Player(name: None, level: 2, health: 42, mana: None)

revive(alive_player)
// -> None
```

## 3. Implémente la mécanique de lancement de sorts

La fonction `cast_spell` prend en arguments un `Int` indiquant combien de mana coûte le sort, ainsi qu'un `Player`.
Elle renvoie le joueur mis à jour, ainsi que la quantité de dégâts infligés par le sort lancé.
Un sort lancé avec succès inflige des dégâts égaux à deux fois le coût en mana du sort.
Cependant, si le joueur n'a pas assez de mana, rien ne se passe : le joueur reste inchangé et aucun dégât n'est infligé.
Si le joueur ne dispose même pas d'une réserve de mana, tenter de lancer le sort doit réduire sa santé du coût en mana du sort et n'inflige aucun dégât.
Attention, la santé du joueur ne peut pas être inférieure à zéro (0).

```gleam
let wizard = Player(name: None, level: 18, health: 123, mana: Some(30))
let #(wizard, damage) = cast_spell(wizard, 14)

wizard.mana // -> Some 16
damage      // -> 28
```
