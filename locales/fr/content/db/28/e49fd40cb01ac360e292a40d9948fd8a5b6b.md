# Introduction

## Tableaux

La bibliothèque de base de Cairo implémente un type `Array`.

Il est similaire aux tableaux que l'on trouve habituellement dans d'autres langages de programmation, mais avec quelques différences importantes :

- On ne peut ajouter des éléments efficacement qu'à la fin du type `Array`, et on ne peut les retirer efficacement qu'au début.
- Il est impossible de définir manuellement un élément en utilisant l'indice du tableau.

On peut créer des tableaux avec la fonction `ArrayTrait::new` et aussi avec la macro `array!` :

```rust
let empty: Array<u32> = ArrayTrait::new();
let one_to_four = array![1, 2, 3, 4];
```

On peut ajouter des éléments au tableau avec la fonction `ArrayTrait::append` :

```rust
let mut num_array = array![1, 2, 3, 4];
num_array.append(5);
// -> [1, 2, 3, 4, 5]
```

On peut retirer des éléments du tableau avec la fonction `ArrayTrait::pop_front` :

```rust
let mut one_to_four = array![1, 2, 3, 4];

one_to_four.pop_front();
// -> [2, 3, 4]
```

Cairo introduit aussi un type `Span` qui agit comme un « instantané » du `Array`.

On peut convertir n'importe quel `Array` en `Span` avec la fonction `ToSpanTrait::span` :

```rust
let one_to_four = array![1, 2, 3, 4];
let one_to_four_span = one_to_four.span();
// -> [1, 2, 3, 4]
```

Convertir un tableau en `Span` est très efficace, car `Span` n'est qu'une structure de données qui permet à Cairo de « voir » une section du tableau, sans la modifier d'aucune façon.

En convertissant un tableau en `Span`, Cairo autorise davantage d'opérations que ce qui serait permis directement sur `Array`, comme retirer un élément au début du span.

```rust
let one_to_four = array![1, 2, 3, 4];
let mut one_to_four_span = one_to_four.span();
one_to_four_span.pop_back();
// -> [2, 3, 4]
```

Note qu'on a dû rendre `one_to_four_span` mutable avec le mot-clé `mut` pour pouvoir appeler `pop_back`, qui modifie le span en raccourcissant la section du tableau que le span « voit ».
