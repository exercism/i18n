# Instructions

Dans cet exercice, tu vas modéliser une balance avec le kilogramme comme unité.

Tu as 6 tâches, chacune te demandant d'implémenter une ou plusieurs propriétés :

## 1. Permets à la balance d'avoir une précision

Pour répondre à des besoins différents, chaque balance peut être personnalisée avec une précision (le nombre de chiffres après le séparateur décimal).
Implémente la classe `WeighingMachine` avec une propriété `Precision` en lecture seule, initialisée avec l'argument `precision` du constructeur :

```csharp
var wm = new WeighingMachine(precision: 3);

//  => wm.Precision == 3
```

## 2. Permets de définir le poids sur la balance

Implémente la propriété `WeighingMachine.Weight` pour permettre de lire _et_ de définir le poids :

```csharp
var wm = new WeighingMachine(precision: 3);
wm.Weight = 60.5;

//  => wm.Weight == 60.5
```

## 3. Vérifie qu'un poids négatif en entrée est rejeté

De toute évidence, une personne ne peut pas avoir un poids négatif.
Ajoute une validation à la propriété `WeighingMachine.Weight` pour lever une `ArgumentOutOfRangeException` lorsqu'on essaie de lui affecter un poids négatif :

```csharp
var wm = new WeighingMachine(precision: 3);
wm.Weight = -10; // Throws an ArgumentOutOfRangeException
```

## 4. Permets d'appliquer un réglage de tare à la balance

Le réglage de tare peut prendre n'importe quelle valeur (même négative, ou une valeur qui rend le poids affiché négatif).
Implémente la propriété `WeighingMachine.TareAdjustment` pour permettre de définir le réglage de tare :

```csharp
var wm = new WeighingMachine(precision: 3);
wm.TareAdjustment = -10.6;

// => wm.TareAdjustment == -10.6
```

## 5. Vérifie que la balance a un réglage de tare par défaut

Après des tests approfondis, il s'avère qu'en raison d'un problème de fabrication, toutes les balances ont tendance à surestimer le poids de `5`.
Modifie la propriété `WeighingMachine.TareAdjustment` pour que sa valeur par défaut soit `5`.

```csharp
var wm = new WeighingMachine(precision: 3);

// => wm.TareAdjustment == 5.0
```

## 6. Permets de récupérer le poids

Implémente la propriété `WeighingMachine.DisplayWeight` qui doit renvoyer une _string_ affichant le poids après réglage de tare, avec la précision correcte appliquée et l'unité ajoutée.
Note que :
``` display-weight = input-weight - tare-adjustment ```

```csharp
var wm = new WeighingMachine(precision: 3);
wm.Weight = 60.567;
wm.TareAdjustment = 10;

// => wm.DisplayWeight == "50.567 kg"
```
