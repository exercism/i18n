# Introduction

## Alias de type

### Alias de type

En Gleam, un alias de type permet de donner un nom pratique à un type existant qui serait autrement pénible à écrire.

```gleam
pub type Headers =
  List(#(String, String))

pub fn html_headers() -> Headers {
  [
    #("content-type", "text/html"),
    #("x-frame-options", "DENY"),
  ]
}
```

Lorsqu'il est écrit avec `pub type`, l'alias peut être utilisé en dehors du module dans lequel il est défini. Si l'on omet `pub`, l'alias est privé et ne peut pas être référencé dans d'autres modules.

## Dictionnaires

Les dictionnaires en Gleam sont la structure de données qui permet de stocker des informations sous forme de paires clé-valeur. Dans d'autres langages, on les connaît aussi sous le nom de tableaux associatifs, de tables de hachage ou de dictionnaires.

N'importe quel type peut être utilisé pour les clés et les valeurs d'un dictionnaire, et les dictionnaires ne garantissent pas l'ordre de leurs entrées lorsqu'on y accède ou qu'on les renvoie.

### Manipule les dictionnaires

Les dictionnaires se créent et se manipulent à l'aide des fonctions du module `gleam/dict`.

```gleam
// Create an empty dict
let dict1 = dict.new()

// Create a dict with some values
let dict2 = dict.from_list([
  #("name", "Gleam"),
  #("colour", "Pink"),
])

// Add a value to a dict
let dict3 = dict.insert(dict2, "website", "https://gleam.run")

// Get a value from a dict
let name = dict.get(dict3, "name")
// -> Ok("Gleam")
```
