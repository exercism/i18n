# Instructions

Tu t'es laissé tenter par un retour à Hyperia (avec sa forte inflation), pour un tarif journalier exorbitant.

La Banque centrale envisage d'introduire le dollar américain comme seconde devise, si bien que tous les systèmes comptables doivent être adaptés pour gérer plusieurs devises.

On t'a demandé d'implémenter l'objet de montant monétaire.

## 1. Permets de tester l'égalité du montant monétaire

Modifie la structure `CurrencyAmount` pour gérer l'égalité. Si les deux structures de montant monétaire n'ont pas la même devise ("USD" ou "HD"), une instance de `ArgumentException` doit être levée.

```csharp
CurrencyAmount amountA = new CurrencyAmount(55, "HD");
CurrencyAmount amountB = new CurrencyAmount(55, "HD");
CurrencyAmount amountC = new CurrencyAmount(55, "USD");
amountA == amountB
// => true
amountA != amountB
// => false
amountA == amountC
// => ArgumentException
amountA != amountC
// => ArgumentException
```

## 2. Compare des montants monétaires

Modifie la structure `CurrencyAmount` pour gérer les comparaisons (`>` et `<` uniquement). Si les deux structures de montant monétaire n'ont pas la même devise ("USD" ou "HD"), une instance de `ArgumentException` doit être levée.

```csharp
CurrencyAmount amountA = new CurrencyAmount(55, "HD");
amountA > new CurrencyAmount(50, "HD")
// => true
amountA < new CurrencyAmount(50, "HD")
// => false
amountA > new CurrencyAmount(50, "USD")
// => ArgumentException
```

## 3. Additionne et soustrais des montants monétaires

Modifie la structure `CurrencyAmount` pour gérer l'addition et la soustraction arithmétiques (`+` et `-` uniquement). Si les deux structures de montant monétaire n'ont pas la même devise ("USD" ou "HD"), une instance de `ArgumentException` doit être levée.

```csharp
CurrencyAmount amountA = new CurrencyAmount(55, "HD");
CurrencyAmount amountB = new CurrencyAmount(100, "HD");
CurrencyAmount amountC = new CurrencyAmount(55, "USD");
amountA + amountB
// => {155, HD}
amountB - amountA
// => {45, HD}
amountA + amountC
// => ArgumentException
```

## 4. Multiplie et divise des montants monétaires

Modifie la structure `CurrencyAmount` pour gérer la multiplication et la division arithmétiques (`*` et `/` uniquement).

```csharp
CurrencyAmount amountA = new CurrencyAmount(10, "HD");
amountA * 2m
// => {20, HD}
amountA / 2m
// => {5, HD}
```

## 5. Convertis le montant monétaire en `double`

Modifie la structure `CurrencyAmount` pour qu'une instance puisse être convertie explicitement en `double`.

```csharp
CurrencyAmount amountA = new CurrencyAmount(55.5m, "HD");
(double)amountA
// => 55.5d
```

## 6. Convertis le montant monétaire en `decimal`

Modifie la structure `CurrencyAmount` pour qu'une instance puisse être convertie implicitement en `decimal`.

```csharp
CurrencyAmount amountA = new CurrencyAmount(55.5m, "HD");
decimal d = amountA;
// => d == 55.5m
```
