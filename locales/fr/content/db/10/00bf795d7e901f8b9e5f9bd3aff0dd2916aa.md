# Indices

## Général

- Lis la section sur les [erreurs][getting-started-errors] dans le guide de démarrage.
- Lis la section sur [IO][getting-started-io] dans le guide de démarrage.

## 1. Ouvre un fichier

- Utilise le _dynamic dispatch_ pour appeler la fonction d'ouverture. Revois l'extrait de code de l'introduction.

## 2. Essaie d'écrire dans le fichier

- Utilise la construction try-rescue.
- Il existe une [fonction][io-write] dans le module `IO` qui permet d'écrire dans un périphérique IO.
- Tu peux utiliser le bloc `rescue` pour faire du _pattern matching_ sur l'erreur et renvoyer le tuple d'erreur.
- Tu peux utiliser le bloc `else` pour faire du _pattern matching_ sur la valeur de retour d'une écriture réussie.

## 3. Ferme le fichier

- Tu peux utiliser le bloc `after` pour exécuter une fonction, que le bloc `try` réussisse ou qu'une exception y soit rattrapée.
