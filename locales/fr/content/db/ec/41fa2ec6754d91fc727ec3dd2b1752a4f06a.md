# Déclaration de type

En PHP, les déclarations de type fournissent, à l'exécution, des assertions de type pour les arguments de fonction, les valeurs de retour et les propriétés de classe.
Sur les fonctions, on peut ajouter un type de retour `void` pour indiquer que la fonction ne renvoie aucune valeur.
Les types déclarés servent aussi d'assertions à l'exécution : elles garantissent que les fonctions renvoient une réponse correctement typée.

```php
<?php

class Driver
{
    private int $serial_number;

    public function setSerialNumber(int $number): void
    {
        $this->serial_number = $number;
    }

    public function getSerialNumber(): int
    {
        return $this->serial_number; 
    }
}

$driver = new Driver();
$driver->setSerialNumber("Version 1b"); // This will throw a TypeError
```

## Types union

Si un argument de fonction, une valeur de retour ou une propriété de classe peut avoir plusieurs types, on peut déclarer un type union.

```php
<?php

class IdentityCard
{
    private int|null $id = null;

    public function assign(int|float $id): void
    {
        $this->id = intval($id);
    }
}

$card = new IdentityCard();
$card->assign(5.0);
```

## Types mixtes

En écrivant du code, il n'est pas toujours possible de préciser un type.
Depuis PHP 8.0, un type de secours nommé `mixed` est fourni.
Mixed est équivalent à un type union `object|resource|array|string|float|int|bool|null`.
