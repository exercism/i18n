# Indices

## Général

- Chaque tâche construit du texte dans une boucle, donc chacune commence par `#FSTR` et se termine par `.str`.
- Affecte à nouveau le résultat de chaque `+` au constructeur : `script := script + ...`.

## 1. Répète un signal

- `1.upto!(times)` fait tourner la boucle le bon nombre de fois. La valeur renvoyée n'est pas nécessaire, on peut donc la mettre directement dans une variable qui ne sert jamais, ou bien utiliser `times.times!`, qui ne renvoie rien du tout.
- Zéro répétition ne demande aucun traitement particulier : la boucle ne s'exécute tout simplement pas.

## 2. Les initiales de la distribution

- `names.elt!` donne chaque nom ; `[0]` en prend le premier caractère.
- `FSTR` accepte directement un `CHAR`, donc pas besoin de le convertir d'abord en _string_.

## 3. Numérote les lignes

- Deux itérateurs dans une même boucle, comme dans l'exercice précédent : `1.up!` pour le numéro et `lines.elt!` pour le texte.
- Le saut de ligne se place *avant* chaque ligne, sauf la première. Le plus simple est de tester le numéro : `if number > 1 then ... end`.
- `FSTR` accepte directement le nombre, donc `script + number + ". "` fonctionne sans conversion.

## 4. Crie une ligne

- `line.elt!` parcourt une _string_ caractère par caractère.
- `.upper` ne touche pas à tout ce qui n'est pas une lettre, donc l'espace ne demande aucun traitement particulier.
