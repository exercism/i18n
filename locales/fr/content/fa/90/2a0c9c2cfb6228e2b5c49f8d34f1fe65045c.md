# Introduction

Un enregistrement regroupe un ensemble de champs (qui peuvent être de types différents) qui vont ensemble. Pour définir un enregistrement, on utilise le mot-clé `type`. Les champs d'un enregistrement se définissent entre les caractères `{` et `}`, et chaque champ possède un nom _et_ un type. Pour créer un enregistrement, on précise le nom des champs et on leur affecte une valeur entre les caractères `{` et `}`. Lors de la création d'un enregistrement, il faut affecter une valeur à tous les champs. On peut accéder aux valeurs des champs d'une instance d'enregistrement avec la notation pointée.

Quand on définit ou qu'on crée un enregistrement, chaque champ doit soit être placé sur une ligne distincte, soit être séparé par des points-virgules (`;`) s'il se trouve sur une seule ligne.

```fsharp
// Define a record
type Address =
    { Street: string
      HouseNumber: int }

// Create a record
let oldAddress: Address =
    { Street = "Main Street"
      HouseNumber = 17 }

// Single-line alternative
type ConciseAddress = { Street: string; HouseNumber: int }
let conciseAddress: ConciseAddress = { Street = "Main Street"; HouseNumber = 17 }
```

Les enregistrements étant immuables, une fois qu'un enregistrement a été construit, les valeurs de ses champs ne peuvent plus jamais changer. Si tu veux modifier les valeurs d'un enregistrement, le mot-clé `with` te permet de créer une copie d'un enregistrement existant, mais avec de nouvelles valeurs pour un ou plusieurs champs.

```fsharp
// Copy the old address but change the house number
let newAddress: Address = { oldAddress with HouseNumber = 86 }
newAddress.Street      // => "Main Street"
newAddress.HouseNumber // => 86
```

Les enregistrements ont une _égalité structurelle_, ce qui signifie que deux instances du même enregistrement avec des valeurs identiques sont équivalentes.

En plus de pouvoir accéder aux champs d'un enregistrement avec la notation pointée, on peut aussi _décomposer_ les enregistrements dans des liaisons et dans les critères spéciaux :

```fsharp
let myAddress: Address = { Street = "Broadway"; HouseNumber = 123 }
let { Street = myStreet; HouseNumber = myHouseNumber } = myAddress

match myAddress with
| { HouseNumber = 1 } -> printfn "First house"
| { HouseNumber = houseNumber; Street = street } -> printfn "House number %d on %s" houseNumber street
// => "House number 123 on Broadway
```
