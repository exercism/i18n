# Pour les mainteneurs

## Script utilitaire pour créer des tests Fortran : create_fortran_test.py

Un moyen simple de créer un test d'exercice est d'utiliser le script
`bin/create\_fortran\_test.py`

Utilise ce script pour créer un fichier initial <exercise>\_test.f90 qui pourra servir de modèle pour ton test.
En général, tu devras remplacer la fonction « response » du fichier généré par le bon appel de fonction.

Note aussi que Fortran a du mal avec certains caractères spéciaux comme `\n` et `\t`, alors fais particulièrement attention à la façon de les gérer.

### Prérequis

- CMake et un compilateur Fortran fonctionnels
- Python 3.x (tu peux peut-être le faire fonctionner avec Python 2, mais je n'ai pas fait
  l'effort de le rendre rétrocompatible)
- la dernière version de https://github.com/exercism/problem-specifications.git
- git

### Workflow pour créer un nouveau test

- récupère les dernières modifications depuis `exercism/problem-specifications`, par ex. git clone git@github.com:exercism/problem-specifications.git
- crée une nouvelle branche pour créer un nouvel exercice, par ex. git checkout -b exercise-bob
- lance ce script pour l'exemple que tu veux créer
- copie `config/CMakeLists.txt` dans le répertoire de l'exercice (tu peux utiliser `bin/update-cmake-files` pour cela)
- implémente un exercice qui fonctionne
- corrige les éventuels tests problématiques (voir par ex. exercise/bob « Test 20 » et « Test 24 »)
- vérifie que la commande `ctest` valide sans erreur
- copie ta solution dans .meta/example.f90 et supprime l'implémentation réelle du fichier de l'exercice, par ex. bob.f90
- mets à jour les répertoires .docs et .meta
  - cp ../problem-specifications/exercises/bob/description.md exercises/practice/bob/.docs/instructions.md
    - remplace « # Description » par « # Instructions »
  - remplis .meta/tests.toml manuellement (jusqu'à ce qu'une méthode automatisée existe)
  - remplis .meta/config.json manuellement (jusqu'à ce qu'une méthode automatisée existe)
    - utilise ../problem-specifications/exercises/bob/metadata.yml
- ouvre une pull request avec tes modifications

Pour l'exemple bob :

```bash
$ python bin/create_fortran_test.py -j ../problem-specifications/main/exercises/bob/canonical-data.json -t exercises/practice/bob/bob_test.f90
Namespace(json='../problem-specifications/main/exercises/bob/canonical-data.json', target='exercises/practice/bob/bob_test.f90')
Wrote : exercises/practice/bob/bob_test.f90
$ cp config/CMakeLists.txt exercises/practice/bob/.
$ cd exercises/practice/bob
$ touch bob.f90
$ mkdir build
$ cd build
$ cmake ..
$ make
$ ctest -V
```

### Modifie `CMakeLists.txt`

Quand tu modifies le fichier cmake, mets à jour la copie principale dans `config/` et utilise `bin/update-cmake-files` pour la copier dans tous les répertoires d'exercices.

## Solution

Quand tu as une solution, copie-la dans le répertoire « .meta » sous le nom « example.f90 ».

Tu voudras peut-être laisser une implémentation squelette de la fonction ou de la sous-routine qui aide l'apprenant, et laisser dans le répertoire de l'exercice le fichier portant le nom de l'exercice.
