# Instructions

Le problème des huit dames est une question classique posée lors des entretiens de programmation. Heureusement, Z3 permet de le résoudre facilement.
Le problème est le suivant : dispose 8 dames sur un échiquier de façon à ce qu'aucune dame ne puisse en capturer une autre. Aux échecs, les dames peuvent se déplacer d'un nombre quelconque de cases dans une seule direction (vers l'avant, vers l'arrière, vers la gauche, vers la droite ou en diagonale). Écris une fonction qui renvoie un tableau de tuples Python qui donne les positions des 8 dames.
