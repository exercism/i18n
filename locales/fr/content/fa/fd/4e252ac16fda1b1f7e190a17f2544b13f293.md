# Instructions

D'« autres » développeurs ont travaillé sur le projet de voiture télécommandée [exercise:csharp/remote-control-competition](). On t'a appelé pour nettoyer le code.

## 1. Sépare les préoccupations entre la voiture elle-même et le système de télémétrie

Réécris la classe `RemoteControlCar` pour séparer les méthodes et les propriétés de télémétrie, accessibles via une propriété `Telemetry`.

```csharp
var car = new RemoteControlCar();
car.Telemetry.Calibrate();
car.Telemetry.SelfTest();
car.Telemetry.ShowSponsor("Walker Industries Inc.");
car.CurrentSponsor
// => "Walker Industries Inc."
car.Telemetry.SetSpeed(100, "cps");
car.GetSpeed()
// => "100 centimeters per second"
```

## 2. Empêche le reste du code de dépendre excessivement du type `Telemetry`

Fais en sorte que l'instance `Telemetry` ne puisse pas être créée en dehors de la portée de la voiture.

## 3. Empêche le reste du code de dépendre de la structure `Speed`

Fais en sorte que la structure `Speed` ne puisse pas être utilisée en dehors de la portée de la classe `RemoteControlCar`.

## 4. Empêche le reste du code de dépendre de l'énumération `SpeedUnits`

Fais en sorte que l'énumération `SpeedUnits` ne puisse pas être utilisée en dehors de la portée de la classe `RemoteControlCar`.
