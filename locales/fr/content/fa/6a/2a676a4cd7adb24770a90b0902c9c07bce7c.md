# Installation

Le moyen le plus simple d'installer PureScript est de passer par Node.js et NPM.

Si Node.js n'est pas déjà installé sur ton ordinateur, tu peux le télécharger depuis le [site de Node.js](https://nodejs.org/). Une fois que Node.js est opérationnel, saisis cette commande dans le terminal pour installer le compilateur PureScript et l'outil de build Spago :

    npm install --global purescript spago

Tu trouveras plus d'informations dans le [dépôt PureScript](https://github.com/purescript/purescript/blob/master/INSTALL.md).
