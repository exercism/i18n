# Les entiers

Les entiers sont les nombres sans partie décimale qui appartiennent à l'ensemble `{..., -2, -1, 0, 1, 2, ...}`.
Les valeurs maximale et minimale d'un entier dépendent du système sur lequel PHP s'exécute.
En général, sur la plupart des systèmes modernes, un entier est une valeur de 64 bits, ce qui signifie qu'il peut représenter les valeurs allant de `-9_223_372_036_854_775_808` à `9_223_372_036_854_775_807`, bornes comprises.

```php
<?php

$a = 1234;
$a = 1_234_567;
```

On peut écrire des valeurs littérales entières dans une base autre que la base 10 en utilisant un préfixe de base :

```php
<?php

$a = 0123; // octal number (equivalent to 83 decimal)
$a = 0o123; // octal number (as of PHP 8.1.0)
$a = 0x1A; // hexadecimal number (equivalent to 26 decimal)
$a = 0b11111111; // binary number (equivalent to 255 decimal)
```
