# Ajout aux instructions

## Implémentation

Dans cet exercice, tu vas instancier une classe et ajouter quelques méthodes d'instance. Pour savoir comment faire, tu peux consulter [Écrire des classes en Ruby][writing-classes].

Un HighScore accepte un tableau avec un ou plusieurs nombres, chacun représentant un « score de jeu ».
La classe Array peut t'inspirer pour travailler avec les tableaux, voir [la documentation Ruby][ruby-docs-array].

[ruby-docs-array]: https://docs.ruby-lang.org/en/master/Array.html
