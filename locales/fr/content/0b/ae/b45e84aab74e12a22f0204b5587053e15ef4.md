# À propos

`Nil` en Gleam est un type avec une seule valeur, également appelée `Nil`. Il est similaire à `void` dans d'autres langages, en ce qu'il est utilisé lorsqu'une fonction n'a pas de valeur plus appropriée à renvoyer.

```gleam
io.println("Hello, Joe!")
// -> Nil
```

En Gleam, contrairement à certains autres langages, les valeurs ne sont pas « _nil-able_ » ou « _nullable_ ». Une valeur ne peut être `Nil` que si son type est `Nil`, et une valeur de tout autre type ne peut jamais être `Nil`.
