# fonction main

Supprime la fonction `Main`, car les tests n'en ont pas besoin et sa présence rend le code un peu plus difficile à lire.

En général, la fonction `Main` est ajoutée pour faciliter le débogage du code. Cependant, une meilleure approche consiste à déboguer le code en exécutant un ou plusieurs tests unitaires. Cela présente l'avantage supplémentaire de pouvoir se concentrer sur le débogage d'un cas de test précis. Voici quelques liens qui expliquent comment déboguer du code Scala en exécutant des tests unitaires dans différents IDE :

- [IntelliJ](https://www.jetbrains.com/help/idea/run-debug-and-test-scala.html)
- [Eclipse](http://scala-ide.org/docs/current-user-doc/features/scaladebugger/index.html)
