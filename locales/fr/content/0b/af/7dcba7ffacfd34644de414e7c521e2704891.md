# Indices

## 1. Vérifie que la commande est valide

- Utilise la méthode [test()][mdn-regex-test] pour renvoyer un booléen.
- N'oublie pas que l'on peut utiliser des [drapeaux][mdn-flags] à la fin de l'expression régulière pour des options supplémentaires, comme l'insensibilité à la casse.

## 2. Supprime les émojis chiffrés

- Dans ce cas, on doit utiliser le constructeur [RexExp][mdn-regular-expressions] pour construire notre expression régulière.
- Grâce au chiffrement commun à chaque émoji, on peut utiliser `[0-9]` pour rechercher n'importe quel chiffre après le mot `emoji`.
- Le caractère `+` correspond à un ou plusieurs éléments consécutifs.
- Utilise la méthode [split()][mdn-regex-split] avec l'expression régulière de chaque émoji pour supprimer tout le chiffrement.
- Enfin, renvoie ce tableau découpé sous forme de _string_ en utilisant la méthode [join()][mdn-join].

## 3. Vérifie qu'un numéro de téléphone est valide

- Dans cet exercice, on joue avec les `groups and ranges`. Lis cette [documentation][mdn-groups] pour en savoir plus.
- Cet [article][phone-validation] explique très bien les différentes façons de valider un numéro.
- Tu peux aussi utiliser cet [aide-mémoire][mdn-regex-cheatsheet] pour avoir une vue d'ensemble des fonctionnalités disponibles dans les expressions régulières.
- Utilise la méthode `test()` pour vérifier si le numéro de téléphone est valide ou non.
- Renvoie la réponse finale à l'aide d'une simple `if statement`.

## 4. Récupère le lien du site web

- On cible les mots reliés par un ou plusieurs `.(dots)`.
- N'oublie pas de mettre le drapeau `g` à la fin pour récupérer tous les domaines dans n'importe quelle phrase.
- Utilise la méthode [match()][mdn-regex-match] pour renvoyer un tableau contenant toutes les correspondances précédentes.

## 5. Salue l'utilisateur

- D'abord, utilise la méthode [replace()][mdn-regex-replace] directement sur la _string_ donnée.
- Utilise les [groupes de capture nommés][mdn-groups] pour stocker `name` et `surname` dans des valeurs distinctes.
- Passe une déstructuration `(...match)` à la fonction de remplacement pour récupérer le nom et le nom de famille dans l'objet des groupes correspondants.
- Utilise la méthode `pop()` pour récupérer l'objet correspondant contenant `name` et `surname`.
- Enfin, utilise un `template String` pour récupérer les valeurs depuis l'objet de l'expression régulière. Regarde cet [exemple][mdn-capturing-groups] pour comprendre comment match() stocke les objets.
