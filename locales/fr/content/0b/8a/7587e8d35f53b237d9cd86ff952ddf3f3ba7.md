# Indices

## Général

- Tu peux peut-être jeter un œil aux [interfaces dans le Tour of Go][interfaces-tour-of-go] pour voir d'autres exemples si tu bloques sur cet exercice.

## 1. Créer la fonctionnalité abstraite de salutation

- Reviens à l'exemple `Counter` de l'introduction pour découvrir comment définir une interface.
- Replonge dans [les concepts de fonctions][concept-functions] pour revoir comment écrire des signatures de fonctions en Go.
- Le type abstrait `Greeter` peut s'utiliser dans une signature de fonction exactement comme un type concret ordinaire tel que `string`.
- Pour implémenter `SayHello`, appelle les méthodes de l'argument de type `Greeter`.
  Utilise ensuite le formatage ou la concaténation de chaînes de caractères pour construire le résultat final.

## 2. Implémenter l'italien

- Replonge dans [le concept de structures][concept-structs] pour voir comment définir une structure.
- Pour résoudre la tâche, la structure n'a besoin d'aucun champ.
- Une fois la structure définie, tu voudras lui ajouter les méthodes `LanguageName` et `Greet`.
  Replonge dans [le concept de méthodes][concept-methods] pour découvrir comment ajouter une méthode à un type.
