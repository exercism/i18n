# Instructions

La mosaïque du centre d'arts communautaire a fini d'être installée le mois dernier, et voilà que Magpie Marg vient de la découvrir. La plupart du temps, elle échange une tuile ou deux contre des plus brillantes de son **butin** tout proche, ou bien elle arrache une tuile et disparaît pendant une heure.

Tu es le bénévole qui consigne chaque changement. La mosaïque elle-même est un **tableau de taille fixe** : une case par position de tuile, qui contient une _string_ de couleur ou `f` pour « manquant ». Le butin de Magpie Marg est un **vecteur** de tuiles détachées qu'elle a volées.

## 1. Dispose une nouvelle rangée

Définis `fresh-mosaic` pour qu'il prenne une longueur `n` et renvoie un tableau de `n` cases vides (chacune valant `f`).

```factor
4 fresh-mosaic .
! => { f f f f }
```

## 2. Place une tuile

Définis `place-tile` pour qu'il prenne une rangée, une position et une couleur, et qu'il modifie la rangée sur place pour que la position indiquée contienne cette couleur. Le mot ne renvoie rien.

```factor
5 fresh-mosaic   ! { f f f f f }
dup 2 "ruby" place-tile
.
! => { f f "ruby" f f }
```

## 3. Détache une tuile

Définis `chip-tile` pour qu'il prenne une rangée et une position, et qu'il modifie la rangée sur place pour que la position indiquée redevienne `f`.

```factor
{ "ruby" "lapis" "jade" } 1 chip-tile .
! => { "ruby" f "jade" }
```

## 4. Recolore une tuile

Définis `recolour-tile` pour qu'il prenne une rangée, une position et une _quotation_ à un argument, et qu'il modifie la rangée sur place en appliquant la _quotation_ à la tuile située à cette position.

```factor
{ "RUBY" "LAPIS" "JADE" } 1 [ >lower ] recolour-tile .
! => { "RUBY" "lapis" "JADE" }
```

## 5. Prends un instantané avant l'arrivée de Marg

Définis `snapshot-mosaic` pour qu'il prenne une rangée et renvoie une copie indépendante qui ne sera pas affectée par les modifications ultérieures de l'original.

```factor
{ "ruby" "lapis" "jade" } dup snapshot-mosaic    ! two equal but independent copies
swap 0 "amber" place-tile                        ! mutate the first
.s
! => { "ruby" "lapis" "jade" }                   (the snapshot)
! => { "amber" "lapis" "jade" }                  (the mutated original)
```

## 6. Marg empoche une tuile

Définis `stash-tile` pour qu'il prenne le butin de Marg (un vecteur) et une couleur, et qu'il ajoute la couleur au butin. Ne renvoie rien.

```factor
V{ } clone   ! a fresh empty hoard
dup "ruby"  stash-tile
dup "lapis" stash-tile
.
! => V{ "ruby" "lapis" }
```

## 7. Marg rend une tuile

Définis `return-tile` pour qu'il prenne le butin de Marg et retire et renvoie la tuile empilée le plus récemment (celle du dessus).

```factor
V{ "ruby" "lapis" "jade" } clone
dup return-tile .
! => "jade"
.
! => V{ "ruby" "lapis" }
```
