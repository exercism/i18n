# À propos

Swift est un langage de programmation compilé et multi-paradigme, conçu autour de trois objectifs principaux :

- **Sûreté** : des fonctionnalités intégrées au langage aident à détecter et à prévenir les bugs avant que le code ne s'exécute en production.
- **Vitesse** : des performances optimisées, comparables à celles des langages basés sur C.
- **Expressivité** : une syntaxe moderne et épurée, agréable et facile à lire et à écrire.

Apple a introduit Swift en 2014 comme un remplacement moderne d'Objective-C, le langage utilisé jusque-là pour le développement sur iOS et macOS.
Aujourd'hui, Swift est open source et fonctionne sur les plateformes Apple, Linux et Windows.

## Pour commencer

### Variables

On peut stocker des valeurs et leur donner un nom en définissant une [variable][constants-variables].
Après avoir défini une variable, tu peux utiliser son nom pour désigner cette valeur dans tout le code.
Les variables sont _mutables_, ce qui signifie que leur valeur peut être modifiée après leur définition.

On définit une variable à l'aide du mot-clé `var` :

```swift
var variableName = 10
```

Swift est un langage à typage statique, ce qui signifie que chaque valeur a un type connu au moment de la compilation.
Tu peux déclarer explicitement un type à l'aide d'une [annotation de type][type annotations], ou laisser le compilateur Swift [inférer le type][type-inferring] à partir de la valeur affectée :

```swift
var explicitVar: Int = 10 // Explicitly typed
var implicitVar = 10      // Implicitly typed (inferred as Int)
```

Tu peux modifier la valeur d'une variable à l'aide de l'opérateur d'affectation (`=`) :

~~~~exercism/note
Le type d'une variable ne peut pas changer après sa déclaration.

```swift
variableName = 13 // Allowed: same type (Int)

// Compiler error: cannot assign a different type
variableName = "Hello, world!" // Cannot assign value of type 'String' to type 'Int'
```
~~~~

Tu peux déclarer une variable sans valeur initiale en précisant son type, mais il faut lui affecter une valeur avant de l'utiliser :

```swift
var someInt: Int

// This triggers a compiler error:
// print(someInt) // Variable 'someInt' used before being initialized

// Assign a value first
someInt = 169
print(someInt) // Prints 169
```

### Constantes

Les [constantes][constants-variables] associent elles aussi un nom à une valeur, mais leur valeur ne peut pas être modifiée après l'affectation.
Elles sont _immuables_.
On définit une constante à l'aide du mot-clé `let` :

```swift
let constantName = 10          // Inferred constant
let explicitConstant: Int = 10 // Explicitly typed constant
```

### Opérateurs arithmétiques

Swift fournit des [opérateurs arithmétiques][arithmetical-operators] standards pour les calculs de base :

- Addition : `+`
- Soustraction : `-`
- Multiplication : `*`

```swift
print(1 + 1) // Prints 2
print(2 - 1) // Prints 1
print(2 * 2) // Prints 4
```

### Fonctions

En Swift, les [fonctions][functions] sont des blocs de code autonomes qui accomplissent une tâche précise.
Les fonctions peuvent prendre des entrées, renvoyer une valeur et être transmises comme des valeurs à d'autres fonctions.
On définit une fonction à l'aide du mot-clé `func`, suivi du nom de la fonction, d'une liste de paramètres entre parenthèses et d'un type de retour facultatif :

```swift
func functionName(argumentLabel parameterName: ParameterType) -> ReturnType {
    // Function body
}
```

Les fonctions Swift utilisent des [étiquettes d'argument][argument-labels], qui rendent le code aussi lisible qu'une phrase naturelle :

- L'**étiquette d'argument** sert lors de l'appel de la fonction.
- Le **nom de paramètre** sert à l'intérieur du corps de la fonction à accéder à la valeur.

Si tu ne précises qu'un seul nom, Swift l'utilise à la fois comme étiquette d'argument et comme nom de paramètre :

```swift
func greet(name: String) {
    print("Hello, \(name)!")
}

greet(name: "Alice")
```

Si tu ne veux pas d'étiquette d'argument lors de l'appel de la fonction, écris un tiret bas (`_`) avant le nom du paramètre :

```swift
func square(_ number: Int) -> Int {
    return number * number
}

square(5) // Called without an argument label
```

Par défaut, tous les paramètres de fonction sont des constantes (`let`), ce qui signifie que leur valeur ne peut pas être modifiée à l'intérieur du corps de la fonction.

Pour renvoyer une valeur depuis une fonction, précise le type de retour après `->` et utilise le mot-clé `return` :

```swift
func addTen(to value: Int) -> Int {
    return value + 10
}

addTen(to: 10) // Returns 20
```

Quand une fonction ne renvoie pas de valeur, son type de retour est `Void` (équivalent à un tuple vide, `()`).
Dans ce cas, tu peux omettre à la fois le type de retour `-> Void` et l'instruction `return`.

### Commentaires

Swift prend en charge deux formes de [commentaires][comments] :

- Les **commentaires sur une seule ligne** commencent par `//` et vont jusqu'à la fin de la ligne.
- Les **commentaires multilignes** sont encadrés par `/*` et `*/`.

```swift
// This is a single-line comment

/* This is a comment
   that spans multiple lines */
```
