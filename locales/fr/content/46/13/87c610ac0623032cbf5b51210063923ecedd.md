# À propos

Les fonctions **définies par l'utilisateur** sont créées à l'aide du mot-clé `function`. Celui-ci doit ensuite être suivi du nom de la fonction et d'une liste d'arguments.

```php
function alarm($hour, $minute, $second)
{
    return 'Alarm!';
}
```

Les fonctions peuvent être appelées dans un fichier avant d'être définies, car elles sont hissées en haut de leur portée.

## Nommage

En PHP, les noms de fonctions suivent les règles des autres identifiants : ils doivent commencer par un tiret bas ou une lettre, puis peuvent être suivis d'un nombre quelconque de lettres, de chiffres ou de tirets bas.
