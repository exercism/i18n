# Compteur de lignes de code

Le compteur de lignes de code (LoC) prend une solution et compte ses lignes de code.

Par défaut, seules les lignes de code des fichiers soumis par l'apprenant sont comptées. Si l'apprenant a soumis un fichier de tests, celui-ci est ignoré.

Si cela fonctionne bien pour la plupart des soumissions, certains parcours peuvent avoir besoin d'ignorer des fichiers supplémentaires. Pour cela, on permet de [personnaliser le compteur de lignes de code pour chaque parcours][lines-of-code-counter-customize].

## Implémentation

On utilise la bibliothèque [tokei][tokei] pour effectuer le comptage proprement dit. Comme les pull requests ne sont souvent pas fusionnées rapidement, on a créé notre propre [fork][tokei-fork]. Cela nous permet d'itérer plus vite et d'ajouter la prise en charge de n'importe quel langage.

## Langages pris en charge

Tu peux vérifier si ton langage est pris en charge nativement en le cherchant dans le fichier [languages.json][languages.json].

### Ajouter un nouveau langage

Si ton langage n'est **pas** pris en charge, tu peux ajouter sa prise en charge de la façon suivante :

1. Ajouter une entrée pour ton langage dans le fichier [languages.json]. Consulte la [documentation sur l'ajout de langages][adding-language] pour plus d'informations.
2. Ajouter des tests pour vérifier que le comptage fonctionne correctement pour ton langage. Consulte la [documentation sur l'ajout de tests][adding-tests] pour plus d'informations.

Une fois ces modifications faites, ouvre une pull request sur le [dépôt exercism/tokei][tokei-fork]. Voici une [pull request d'exemple][example-pr] qui ajoute la prise en charge du langage Arturo.
