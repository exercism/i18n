# Indices

## 1. Partir de zéro

- Pour créer un tableau, tu peux utiliser `make-array`.
- Les dimensions d'un tableau sont spécifiées sous la forme d'une liste passée à `make-array`.
- Pour donner à tous les éléments une valeur initiale, utilise le paramètre mot-clé `:inital-element`.

## 2. Partir d'un plateau existant

- Pour définir le contenu initial d'un tableau, utilise le paramètre mot-clé `:initial-contents`.

## 3. Condition de victoire

- On peut utiliser `aref` pour obtenir la valeur d'une cellule d'un tableau.
- On peut utiliser `eq` pour déterminer si deux symboles sont identiques.
- On peut utiliser `and` pour combiner deux expressions `eq` afin de comparer trois éléments.

## 4. Dans une ligne

- Les arguments de `aref` (pour un tableau à deux dimensions) sont « ligne » et « colonne ».

## 5. Dans une colonne

- Les arguments de `aref` (pour un tableau à deux dimensions) sont « ligne » et « colonne ».
