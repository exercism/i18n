# Indices

## Programmation orientée objet

* `reset_names` est une **méthode de classe**.
  Voir [les variables de classe][class-vars] dans le guide du langage MoonScript.
* Tu devras suivre l'état de toutes les instances de robot (quels noms ont été affectés).
  Les variables de classe sont parfaites pour ça, mais réfléchis aussi aux autres approches qui pourraient fonctionner.

## Indices de performance

* Une bonne stratégie pour affecter des noms à tous les robots consiste à générer d'abord les 676 000 noms, puis à mélanger cette liste.
  Chaque nouveau robot peut alors simplement prendre le nom suivant dans la liste mélangée.

[class-vars]: https://moonscript.org/reference/#the-language/object-oriented-programming/class-variables
