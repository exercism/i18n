# Introduction

Un dictionnaire (`dict`) en Python est une structure de données qui associe des _clés_ [hachables][term-hashable] à des _valeurs_, et que l'on connaît dans d'autres langages de programmation sous les noms de [table de hachage][hashtable-wikipedia] redimensionnable, de _hashmap_ ou de [tableau associatif][associative-array].
Les dictionnaires sont le seul [type de correspondance][mapping-types-dict] intégré à Python.


`Keys` doivent être hachables et uniques au sein du dictionnaire.
Les types de clés peuvent inclure des `numbers`, des `str` ou des `tuples` (de valeurs _immuables_).
Elles ne peuvent pas contenir de structures de données _mutables_ telles que des `lists`, des `dict` ou des `set`.
Depuis Python 3.7, l'ordre des clés d'un `dict` correspond à l'ordre d'insertion des entrées.

Les `values` peuvent être de n'importe quel type ou structure de données.
Les valeurs peuvent aussi s'imbriquer _arbitrairement_, et donc contenir des listes de listes, des sous-dictionnaires et d'autres structures de données personnalisées ou composites.

Étant donné une `key`, un dictionnaire peut retrouver une `value` en temps constant (en moyenne), _indépendamment du nombre d'entrées_.
Comparé à la recherche d'une valeur dans une `list` ou un `array` (_sans connaître la position de l'`index`_), un `dict` utilise nettement plus de mémoire, mais la récupération est très rapide.
Les dictionnaires sont particulièrement utiles lorsque la collection d'éléments est volumineuse et doit être consultée et mise à jour fréquemment.


## Construction d'un dictionnaire

On peut créer un dictionnaire de bien des façons.
Les deux plus directes consistent à utiliser le constructeur `dict()` ou à déclarer un _littéral_ `dict`.

### Le constructeur de la classe `dict()`

`dict()` (_le constructeur de la classe dictionnaire_) peut s'utiliser avec n'importe quel itérable de paires `key`, `value`, ou avec une série d'_arguments_ `<name>=<value>` :

```python
#Passing a list of key,value tuples.
>>> wombat = dict([('name', 'Wombat'),('speed', 23),('land_animal', True)])
{'name': 'Wombat', 'speed': 23, 'land_animal': True}


#Using key=value arguments.
>>> bear = dict(name="Black Bear", speed=40, land_animal=True)
{'name': 'Black Bear', 'speed': 40, 'land_animal': True}
```

### Les littéraux de dictionnaire

Un `dict` peut aussi s'écrire directement sous forme de _littéral de dictionnaire_, à l'aide d'accolades (`{}`) encadrant des paires `key : value` :

```python
>>> whale = {"name": "Blue Whale", "speed": 35, "land_animal": False}
{'name': 'Blue Whale', 'speed': 35, 'land_animal': False}
```

## Accéder aux valeurs d'un dictionnaire

On accède à une entrée d'un dictionnaire à l'aide d'une _clé_ entre crochets (`[]`).
Si une `key` n'existe pas dans le `dict`, une `KeyError` est levée :

```python
>>> bear["speed"]
40

>>> bear["color"]
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
KeyError: 'color'
```

Accéder à une entrée via la méthode `.get(<key>, <default value>)` permet d'éviter la `KeyError` :

```python
>>> bear.get("color", 'not found')
'not found'
```

## Modifier ou ajouter des valeurs dans un dictionnaire

On peut modifier la `value` d'une entrée en affectant à sa _clé_ :

```python
#Assigning the value "Grizzly Bear" to the name key.
>>> bear["name"] = "Grizzly Bear"
{'name': 'Grizzly Bear', 'speed': 40, 'land_animal': True}

>>> whale["speed"] = 25
{'name': 'Blue Whale', 'speed': 25, 'land_animal': False}
```

De nouvelles paires `key`:`value` peuvent être _ajoutées_ de la même manière :

```python
# Adding a new "color" key with a new "tawney" value.
>>> bear["color"] = 'tawney'
{'name': 'Grizzly Bear', 'speed': 40, 'land_animal': True, 'color': 'tawney'}

>>> whale["blowholes"] = 1
{'name': 'Blue Whale', 'speed': 25, 'land_animal': False, 'blowholes': 1}
```

## Supprimer (`pop`) des entrées d'un dictionnaire

On peut utiliser la méthode `.pop(<key>)` pour supprimer une entrée d'un dictionnaire.
`.pop()` retire la paire (`key`, `value`) et renvoie la `value` pour utilisation.
Comme `.get()`, `.pop(<key>)` accepte un second argument (_`dict.pop(<key>, <default value>)`_) qui sera renvoyé si la `key` est introuvable.
Cela évite qu'une `KeyError` soit levée :

```python
#Using .pop() removes both the key and value, returning the value.
>>> bear.pop("name")
'Grizzly Bear'


#The "name" key is now removed from the dictionary.
#Attempting .pop() a second time will throw a KeyError.
>>> bear.pop("name")
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
KeyError: 'name'


#Using a default argument with .pop() will prevent a KeyError from a missing key.
>>> bear.pop("name", "Unknown")
'Unknown'
```

## Parcourir un dictionnaire en boucle

Parcourir un dictionnaire avec `for item in dict` ou `while item` n'itère que sur les _clés_ par défaut.
On peut accéder aux _valeurs_ dans la même boucle en utilisant des _crochets_ :

```python
>>> for key in bear:
>>>     print((key, bear[key])) #this forms a tuple of (key, value) and prints it.
('name', 'Black Bear')
('speed', 40)
('land_animal', True)
```

On peut aussi utiliser la méthode `.items()`, qui renvoie automatiquement des tuples (`key`, `value`) :

```python
#dict.items() forms (key, value tuples) that can be unpacked and iterated over.
>>> for key, value in whale.items():
>>>     print(key, ":", value)
name : Blue Whale
speed : 25
land_animal : False
blowholes : 1
```

De même, la méthode `.keys()` renvoie les `keys` et la méthode `.values()` renvoie les `values`.
