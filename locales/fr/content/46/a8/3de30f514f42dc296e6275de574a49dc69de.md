# Modules et chemins en Cairo

Cairo utilise des **modules** pour organiser le code.

Les modules aident à structurer les projets et à contrôler la visibilité d'éléments comme les fonctions, les structures et les _traits_.

## Définis des modules

Les modules sont définis avec `mod` et peuvent être imbriqués :

```rust
mod front_of_house {
    pub mod hosting {
        pub fn add_to_waitlist() {}
    }
}
```

Les fonctions, les structures et les _traits_ sont **privés par défaut**.

Utilise `pub` pour les rendre accessibles en dehors de leur module.

## Chemins : absolus ou relatifs

Pour faire référence à un élément d'un autre module, on peut utiliser :

- **Chemins absolus** (qui partent de `crate::`) :

  ```rust
  crate::front_of_house::hosting::add_to_waitlist();
  ```

- **Chemins relatifs** (qui partent du module courant) :

  ```rust
  front_of_house::hosting::add_to_waitlist();
  ```

  Cela fonctionne si `front_of_house` se trouve dans le même module.

## Fais entrer des modules dans la portée avec `use`

Écrire des chemins complets à répétition n'est pas pratique.

Le mot-clé `use` permet des références plus courtes :

```rust
use crate::front_of_house::hosting;

pub fn eat_at_restaurant() {
    hosting::add_to_waitlist(); // Shorter path
}
```

`use` ne s'applique **qu'à la portée où il apparaît** ; s'il est nécessaire ailleurs, il faut le répéter.

### Utilisation idiomatique de `use`

- Fais entrer des **modules** dans la portée, pas des fonctions :

  ```rust
  use crate::front_of_house::hosting; // ✅
  hosting::add_to_waitlist();
  ```

  Au lieu de :

  ```rust
  use crate::front_of_house::hosting::add_to_waitlist; // ❌
  add_to_waitlist();
  ```

- Pour les **_traits_, structures et énumérations**, utilise le chemin complet :

  ```rust
  use core::num::traits::BitSize;
  ```

### Alias avec `as`

Renomme les imports si nécessaire :

```rust
use core::array::ArrayTrait as Arr;

fn main() {
    let mut arr = Arr::new();
    arr.append(1);
}
```

### Importe plusieurs éléments

Au lieu de plusieurs instructions `use`, regroupe les imports :

```rust
use shapes::{Square, Circle, Triangle};
```

## Réexporte avec `pub use`

Pour exposer un module dans une structure différente, utilise `pub use` :

```rust
pub use crate::front_of_house::hosting;
```

Maintenant, le code externe peut utiliser `restaurant::hosting::add_to_waitlist()` au lieu de `restaurant::front_of_house::hosting::add_to_waitlist()`.

## Utilise des paquets externes avec Scarb

Pour ajouter une dépendance, mets à jour `Scarb.toml` :

```toml
[dependencies]
alexandria_math = { git = "https://github.com/keep-starknet-strange/alexandria.git" }
```

Utilise `scarb add <package>` pour ajouter des dépendances et `scarb rm <package>` pour les supprimer.

## L'opérateur glob (`*`)

Pour tout importer depuis un module :

```rust
use core::num::traits::*;
```

Il faut l'utiliser avec précaution, car cela peut rendre le code plus difficile à lire.
