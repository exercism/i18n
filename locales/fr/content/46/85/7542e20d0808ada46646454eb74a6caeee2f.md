# Introduction

En Cairo, les méthodes et les fonctions associées permettent d’organiser les fonctionnalités autour de types spécifiques, ce qui rend ton code modulaire et intuitif. Les méthodes agissent sur une instance d’un type et prennent toujours `self` comme premier paramètre, tandis que les fonctions associées, comme les constructeurs, n’ont pas besoin d’une instance. Ensemble, elles offrent une approche claire et structurée pour définir le comportement et les fonctions utilitaires de tes types.
