# Instructions

Tu tiens l'horaire des traversées d'un petit ferry insulaire. Les départs sont enregistrés sous forme de dates, et tu as besoin de quelques fonctions auxiliaires pour les manipuler.

## 1. Enregistre une date de traversée

Définis `make-date` pour qu'elle prenne une année, un mois et un jour, et renvoie l'horodatage correspondant.

```factor
2024 7 14 make-date .
! => T{ timestamp { year 2024 } { month 7 } { day 14 } ... }
```

## 2. Nomme le jour de la semaine

Définis `weekday-name` pour qu'elle prenne l'horodatage d'une traversée et renvoie le nom du jour de la semaine correspondant.

```factor
2024 1 8 make-date weekday-name .
! => "Monday"
```

## 3. Les années bissextiles

Définis `leap?` pour qu'elle prenne une année et renvoie si l'année est bissextile.

```factor
2024 leap? .   ! => t
2023 leap? .   ! => f
```

## 4. Nombre de jours dans un mois

Définis `month-length` pour qu'elle prenne une année et un mois et renvoie le nombre de jours de ce mois (pense à février).

```factor
2024 2 month-length .   ! => 29
2023 2 month-length .   ! => 28
```

## 5. Jours plus tard

Définis `add-days` pour qu'elle prenne un horodatage et un nombre de jours, et renvoie l'horodatage décalé de ce nombre de jours.

```factor
2024 2 28 make-date 1 add-days >date< .
! => 29   (2024-02-29)
```
