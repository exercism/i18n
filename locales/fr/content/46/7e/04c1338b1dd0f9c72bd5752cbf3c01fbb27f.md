# Introduction

## Listes de mots-clés

Les listes de mots-clés sont une structure de données clé-valeur.

```elixir
[month: "April", year: 2018]
```

Les listes de mots-clés sont des listes de [tuples][exercism-tuples] `{key, value}`, que l'on peut aussi écrire sous cette forme, même si la syntaxe plus courte est la plus répandue.

```elixir
[month: "April"] == [{:month, "April"}]
# => true
```

Les clés d'une liste de mots-clés doivent être des [atomes][exercism-atoms], mais les valeurs peuvent être de n'importe quel type. Une même clé peut être utilisée plusieurs fois. Les paires clé-valeur d'une liste de mots-clés sont ordonnées.

On peut manipuler les listes de mots-clés de la même manière que les listes, ou bien utiliser le module `Keyword`.

[exercism-tuples]: https://exercism.org/tracks/elixir/concepts/tuples
[exercism-atoms]: https://exercism.org/tracks/elixir/concepts/atoms
