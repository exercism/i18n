# Ajout aux instructions

## Registres

| Registre | Utilisation | Type       | Description                                                |
| -------- | ----------- | ---------- | ---------------------------------------------------------- |
| `$a0`    | entrée      | entier     | catégorie : `0` = choice, `1` = ones, `2` = twos, `3` = threes, `4` = fours, `5` = fives, `6` = sixes, `7` = little_straight, `8` = big_straight, `9` = full_house, `10` = four_of_a_kind, `11` = yacht |
| `$a2`    | entrée      | adresse    | dés (tableau de mots)                                      |
| `$v0`    | sortie      | entier     | score obtenu                                               |
| `$t0-9`  | temporaire  | quelconque | utilisés pour le stockage temporaire                       |
