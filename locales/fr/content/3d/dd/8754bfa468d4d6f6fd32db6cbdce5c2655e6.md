# Instructions

Le carnet d'un détective se remplit au fil d'une affaire, puis se vide de nouveau à mesure que des pistes sont écartées.

Les cinq tâches sont à réaliser dans la classe `CASE_NOTES`.

## 1. Ouvre une affaire

Renvoie un nouveau carnet vide.

```sather
notes ::= CASE_NOTES::new_case;
notes.size
-- => 0
```

## 2. Note un indice

Ajoute un indice à la fin du carnet. Cette méthode ne renvoie rien : elle modifie le carnet qu'elle reçoit en argument.

```sather
CASE_NOTES::add_clue(notes, "muddy boots");
notes.size
-- => 1
```

## 3. Combien d'indices ?

```sather
CASE_NOTES::clue_count(notes)
-- => 1
```

## 4. Écarte un indice

Retire du carnet l'indice qui se trouve à une position donnée. Tout ce qui suit remonte d'une position. Cette méthode ne renvoie rien non plus.

```sather
CASE_NOTES::rule_out(notes, 0);
```

## 5. Relis l'affaire

Renvoie tous les indices du carnet, joints par `"; "`. Un carnet vide donne la chaîne vide.

```sather
CASE_NOTES::summary(notes)
-- => "muddy boots; broken window"
```
