# Introduction

Haxe prend en charge la réflexion à l'exécution sur les types et les champs. Pour l'utiliser correctement, il faut comprendre quels types d'opérations sont pris en charge et lesquels ne le sont pas. Vu la nature dynamique de la réflexion, on ne peut pas toujours le déterminer à la compilation.

L'API de réflexion se compose de deux classes :

- `Reflect` : une API légère qui fonctionne mieux sur les structures anonymes, avec une prise en charge limitée des classes.
- `Type` : une API plus robuste pour manipuler les classes et les énumérations.

Pour l'exemple suivant, on utilise la cible JavaScript :

```haxe
class Main {
  public static function main() {
    trace(Type.resolveClass("Main"));
  }
}

// This outputs
// class Test { static main() { console.log("Test.hx:3:",$hxClasses["Test"]); } }
```
