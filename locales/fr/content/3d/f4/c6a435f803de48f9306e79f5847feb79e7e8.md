# Instructions complémentaires

## Format de sortie

Affiche la séquence de protéines sous la forme d'une _string_ terminée par un caractère nul, avec un saut de ligne après chaque protéine.

Un exemple de sortie serait `"Methionine\nPhenylalanine\nSerine\n"`

Si l'entrée est invalide, affiche une _string_ vide.
