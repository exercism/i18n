# Introduction


## Booléens

PowerShell dispose du type [`bool`][booleans] pour représenter les valeurs vrai et faux.
Dans ce type, il n'y a que deux valeurs : `True` et `False`.
On peut affecter ces valeurs à des variables grâce au préfixe `$` :

```powershell
> $TrueVar  = $true
> $FalseVar = $FALSE
#Case senstitivity doesn't matter here
```

On peut utiliser des [opérateurs logiques][logical-operators] comme `-and`, `-or` et `-not` pour combiner et évaluer des expressions booléennes.

```powershell
> $TrueVar  = $true -and $true
> $FalseVar = $true -and $false

> $TrueVar  = $true -or $false
> $FalseVar = $false -or $false

> $TrueVar  = -not $false
> $FalseVar = -not $true
```


## Aide basée sur les commentaires

Dans PowerShell, [`Comment-based help`][comment-based help] permet de fournir des informations détaillées pour les fonctions et les scripts écrits dans des commentaires.
Elle utilise des mots-clés d'aide spéciaux pour préciser les thèmes concernés, par exemple `.SYNOPSIS`, `.EXAMPLE` ou `.NOTES`.

```powershell
function ExampleFunction($Arg) {
    <#
    .DESCRIPTION
    A detailed description of the function or script. This keyword can be used only once in each topic.

    .PARAMETER Arg
    The description of a parameter, it must be follow with the parameter name.
    #>
}
```

On peut afficher les informations de l'aide basée sur les commentaires grâce à l'applet de commande `Get-Help`.

```powershell
> Get-Help -Name "ExampleFunction"
```
