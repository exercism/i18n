# Introduction

## Les bases

En F#, affecter une valeur à un nom s'appelle une _liaison_. Les liaisons sont immuables, ce qui les rend similaires aux constantes dans d'autres langages. Comme F# est un langage à typage statique, chaque liaison a un type au moment de la compilation.

Les liaisons sont définies à l'aide du mot-clé `let`. Spécifier le type d'une liaison est optionnel pour la plupart des liaisons, car l'_inférence de type_ de F# peut généralement déduire le type à partir de sa valeur. Une liaison ressemble à ceci :

```fsharp
// Automatically inferred type
let fingers = 10
```

Les fonctions sont aussi des liaisons régulières, mais avec un ou plusieurs paramètres. Une fonction renvoie automatiquement sa dernière expression. L'inférence de type fonctionne aussi pour la plupart des fonctions, en analysant avec quelles valeurs la fonction est appelée et quelle valeur elle renvoie.

```fsharp
// Automatically inferred types for parameters and return type
let add x y = x + y
```

Appeler une fonction se fait en spécifiant son nom et en passant des arguments pour chacun de ses paramètres.

```fsharp
let five = add 2 3
```

Si le type d'une liaison ne peut pas être inféré, le compilateur signalera une erreur. Pour corriger cela, ajoutez une annotation de type explicite à la liaison.

```fsharp
// Explicit type annotation
let fingers: int = 10

// Explicit type annotation (also for parameters)
let add (x: int) (y: int): int = x + y
```

Les liaisons en F# ne peuvent être utilisées qu'_après_ avoir été définies. Utiliser une liaison avant qu'elle ne soit définie entraîne une erreur de compilation.

```fsharp
// Compile error as the add binding has not yet been defined
// let seven = add 3 4

let add x y = x + y
```

F# utilise les espaces significatifs pour définir la portée. Cela signifie que la portée est définie en indentant le code avec des espaces, par rapport à la ligne déclarant la liaison. La convention par défaut est d'utiliser quatre espaces pour l'indentation :

```fsharp
let toes =
    let left = 5
    let right = 5
    left + right

let multiplyPlusTwo x y =
    let product = x * y
    product + 2

// Trying to access the left, right or product bindings
// here would result in a compile error
```

Les liaisons F# (qui incluent les fonctions) sont généralement organisées en modules. Un module regroupe des fonctionnalités liées et est défini à l'aide du mot-clé `module`. La définition du module doit précéder ses liaisons :

```fsharp
module Calculator

let pi = 3.14

let add x y = x + y
```

F# prend en charge deux types de commentaires. Les commentaires sur une seule ligne sont précédés de `//` et les commentaires multilignes sont insérés entre `(*` et `*)`.
