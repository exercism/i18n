# Apprentissage

Vim est fourni avec une excellente documentation intégrée. On accède à cette documentation avec la commande `:help`.

Pour une introduction, consulte `:h user-manual`.

Presque toutes les installations de Vim incluent aussi un tutoriel interactif :

```
$ vimtutor
```

Vim existe depuis des décennies et reste très populaire. On trouve beaucoup de ressources à son sujet sur le web, certaines meilleures que d'autres. Les bonnes sont répertoriées [ici](https://exercism.org/docs/tracks/vimscript/resources).
