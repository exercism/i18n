# Instructions

Tu es un passionné d'observation des oiseaux qui note combien d'oiseaux ont visité ton jardin au cours des sept derniers jours.

Tu as cinq tâches, qui portent toutes sur le nombre d'oiseaux ayant visité ton jardin.

## 1. Vérifie les comptages de la semaine dernière

Pour pouvoir comparer, tu gardes toujours à portée de main une copie des comptages de la semaine dernière, qui étaient : 0, 2, 5, 3, 7, 8 et 4. Implémente la méthode `BirdCount.last_week` qui renvoie les comptages de la semaine dernière :

```ruby
BirdCount.last_week
# => [0, 2, 5, 3, 7, 8, 4]
```

## 2. Vérifie combien d'oiseaux ont visité ton jardin hier

Implémente la méthode `BirdCount#yesterday` pour renvoyer combien d'oiseaux ont visité ton jardin hier. Les comptages sont classés par jour, le premier élément étant le comptage du jour le plus ancien et le dernier, celui d'aujourd'hui.

```ruby
birds_per_day = [2, 5, 0, 7, 4, 1]
bird_count = BirdCount.new(birds_per_day)
bird_count.yesterday
# => 4
```

## 3. Calcule le nombre total d'oiseaux visiteurs

Implémente la méthode `BirdCount#total` pour renvoyer le nombre total d'oiseaux qui ont visité ton jardin :

```ruby
birds_per_day = [2, 5, 0, 7, 4, 1]
bird_count = BirdCount.new(birds_per_day)
bird_count.total
# => 19
```

## 4. Calcule le nombre de jours chargés

Certains jours sont plus chargés que d'autres. Un jour chargé est un jour où cinq oiseaux ou plus ont visité ton jardin.
Implémente la méthode `BirdCount#busy_days` pour renvoyer le nombre de jours chargés :

```ruby
birds_per_day = [2, 5, 0, 7, 4, 1]
bird_count = BirdCount.new(birds_per_day)
bird_count.busy_days
# => 2
```

## 5. Vérifie s'il y a eu un jour sans aucun oiseau

Implémente la méthode `BirdCount#day_without_birds?` qui renvoie `true` s'il y a eu un jour où aucun oiseau n'a visité le jardin ; sinon, renvoie `false` :

```ruby
birds_per_day = [2, 5, 0, 7, 4, 1]
bird_count = BirdCount.new(birds_per_day)
bird_count.day_without_birds?
# => true
```
