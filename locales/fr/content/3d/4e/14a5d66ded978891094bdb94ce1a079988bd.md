# Tests

## clojure.test

Babashka est fourni avec clojure.test. Une fois que tu es prêt à travailler sur un exercice et que tu as créé un fichier pour contenir ta solution (comme `bob.clj`), tu peux exécuter les tests avec `clojure.test/run-tests` [comme décrit ici](http://clojure.github.io/clojure/clojure.test-api.html#clojure.test/run-tests).


Le REPL te permet d'exécuter du code facilement et d'obtenir un retour immédiat, et il peut aussi servir à lancer les tests. Il est recommandé d'utiliser `rlwrap` pour activer l'édition de ligne et l'historique des commandes avec les flèches haut et bas. Pour tester un exercice, place-toi dans son dossier et ouvre un REPL socket en ajoutant les dossiers `src` et `test` au classpath :
``` bash
/bob $ rlwrap bb --classpath src:test socket-repl 1666
```

Commence par faire un `require` de l'espace de noms de test :
``` clojure
=> (require 'bob-test)
nil
```

Appelle ensuite `run-tests` sur `bob-test` :
``` clojure
=> (clojure.test/run-tests 'bob-test)

Testing bob-test

Ran 25 tests containing 25 assertions.
0 failures, 0 errors.
{:test 25, :pass 25, :fail 0, :error 0, :type :summary}
```

Pour créer un exécuteur de tests sous forme de script :

``` clojure
#!/usr/bin/env bb

(require '[clojure.test :as t]
         '[babashka.classpath :as cp])

(cp/add-classpath "src:test")                        

(require 'bob-test)                  

(def test-results
  (t/run-tests 'bob-test))           

(def failures-and-errors
  (let [{:keys [:fail :error]} test-results]
    (+ fail error)))                                 

(System/exit failures-and-errors)
```
