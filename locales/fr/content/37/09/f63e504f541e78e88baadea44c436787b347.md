# Les _strings_

Crystal possède un type appelé [`String`][strings], qui sert à représenter du texte.
Les _strings_ de Crystal sont des séquences de caractères Unicode.
Les _strings_ sont immuables, ce qui signifie qu'elles ne peuvent pas être modifiées une fois créées.
Ainsi, une nouvelle _string_ est créée à chaque modification, et la _string_ d'origine reste donc inchangée.

Pour définir une _string_, on utilise des guillemets doubles `"`.

```crystal
"Hello World"
```

## Concaténation

Pour concaténer deux _strings_, on utilise l'opérateur `+`.
L'opérateur `+` renvoie une nouvelle _string_ qui combine les deux _strings_.

```crystal
hello = "Hello"
hello + " World"
# => "Hello World"
```

## Conversion entre les _strings_ et les nombres

La méthode `to_i` convertit une _string_ en entier.
On peut aussi utiliser la méthode `to_f` pour obtenir un nombre à virgule flottante.
Si la _string_ ne peut pas être convertie en nombre, une `ArgumentError` est levée.

```crystal
"1".to_i
# => 1

"1.0".to_f
# => 1.0

"Hello".to_i
# => ArgumentError: Invalid integer: Hello
```

Un entier ou un nombre à virgule flottante peut être converti en _string_ à l'aide de la méthode `to_s`.

```crystal
1.to_s
# => "1"

1.0.to_s
# => "1.0"
```

## Interpolation

L'interpolation est un moyen pratique de combiner des _strings_ et d'y intégrer des expressions.
Pour interpoler une _string_, on utilise le caractère `#` suivi d'accolades `{}`, avec l'expression à l'intérieur des accolades.

```crystal
name = "World"
"Hello #{name}!"
# => "Hello World!"
```

Crystal convertit automatiquement le résultat de l'expression en _string_.

```crystal
"Hello #{1 + 1}!"
# => "Hello 2!"
```

## Taille

Quand on a besoin de connaître le nombre de caractères d'une _string_, on peut utiliser la méthode `size`, qui renvoie la longueur de la _string_ sous forme d'entier.
La taille d'une _string_ est une propriété stockée de cette _string_, ce qui évite d'avoir à la calculer à chaque appel de la méthode et rend celle-ci très rapide.

```crystal
"Hello World".size
# => 11
```

## Indexation

L'indexation sert à obtenir un caractère précis dans une _string_.
Pour obtenir un caractère d'une `String`, on utilise la notation habituelle avec des crochets.

~~~~exercism/note
`[]` est implémenté comme une méthode d'instance de `String`, où l'indice est l'argument de la méthode.
~~~~

Le premier caractère d'une _string_ se trouve à l'indice 0.

```crystal
"Hello World"[0]
# => 'H'

"Hello World"[6]
# => 'W'
```

Pour obtenir un caractère depuis la fin d'une _string_, on peut prendre la longueur de la _string_ moins un pour obtenir l'indice du dernier caractère, puis la longueur moins deux pour l'avant-dernier caractère, et ainsi de suite.
Il existe un raccourci pour cela : il suffit d'utiliser un indice négatif, où le dernier caractère se trouve à l'indice -1, l'avant-dernier à l'indice -2, et ainsi de suite.

```crystal
name = "Hello World"
name[name.size - 1]
# => 'd'

name[-1]
# => 'd'
```

### Test de sous-chaîne

Crystal permet de tester si une _string_ contient une sous-chaîne grâce à l'indexation.
On utilise la même notation avec des crochets, mais au lieu d'un indice, on fournit une sous-chaîne.
Si la sous-chaîne est présente dans la _string_, elle est renvoyée ; sinon, une `NilAssertionError` est levée.

```crystal
"Hello World"["Hello"]
# => "Hello"

"Hello World"["Goodbye"]
# => NilAssertionError
```

Si tu veux une valeur `Bool` indiquant si la sous-chaîne est présente, tu peux utiliser la méthode `includes?`.

```crystal
"Hello World".includes?("Hello")
# => true

"Hello World".includes?("Goodbye")
# => false
```

## Échappement

Certains caractères ne peuvent pas s'écrire directement dans une _string_ ; il faut alors utiliser une séquence d'échappement.
Par exemple, si tu veux utiliser des guillemets doubles dans une _string_, tu dois les échapper.
On utilise le caractère `\` pour écrire une séquence d'échappement, suivie du caractère à échapper.

Voici les caractères spéciaux de Crystal :

| Value    | Description                   |
| -------- | ----------------------------- |
| `\a`     | Alerte                        |
| `\b`     | Retour arrière                |
| `\e`     | Échappement                   |
| `\f`     | Saut de page                  |
| `\n`     | Saut de ligne ou nouvelle ligne |
| `\r`     | Retour chariot                |
| `\t`     | Tabulation horizontale        |
| `\v`     | Tabulation verticale          |
| `\\`     | Barre oblique inversée        |
| `\'`     | Guillemet simple              |
| `\"`     | Guillemet double              |
| `\377`   | Caractère ASCII octal         |
| `\xFF`   | Caractère ASCII hexadécimal   |
| `\uFFFF` | Caractère Unicode hexadécimal |

```crystal
puts "Hello \"World\""
# => Hello "World"

puts "Hello \nWorld"
# => Hello
# => World
```

## _Strings_ multilignes

Pour écrire une _string_ sur plusieurs lignes, on utilise la même syntaxe que pour une _string_ d'une seule ligne, mais on crée une nouvelle ligne pour chaque ligne que l'on veut dans la _string_.

```crystal
"Hello
World"
# => "Hello\nWorld"
```

## Unicode

[Unicode][unicode] est une norme d'encodage, de représentation et de traitement de texte dans différents systèmes d'écriture.
Unicode prend en charge plus de 100 000 caractères, notamment des lettres, de la ponctuation, des symboles et des emoji.

Comme Crystal utilise Unicode pour les _strings_, tu peux par exemple y mettre des emoji.

```crystal
"Hello 🌍"
# => "Hello 🌍"
```

Il arrive que tu veuilles utiliser un caractère qui n'est pas disponible dans ton éditeur ou ton système, par exemple.
Dans ce cas, tu peux utiliser la séquence d'échappement Unicode pour écrire ce caractère.

```crystal
"\u{1F310}"
# => "🌐"
```
