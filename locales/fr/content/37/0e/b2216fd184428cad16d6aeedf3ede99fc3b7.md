# Instructions

Implémente les opérations `keep` et `discard` sur des collections. Étant donné une collection et un prédicat portant sur les éléments de cette collection, `keep` renvoie une nouvelle collection contenant les éléments pour lesquels le prédicat est vrai, tandis que `discard` renvoie une nouvelle collection contenant les éléments pour lesquels le prédicat est faux.

Par exemple, étant donné la collection de nombres :

- 1, 2, 3, 4, 5

Et le prédicat :

- le nombre est-il pair ?

Alors ton opération `keep` devrait produire :

- 2, 4

Tandis que ton opération `discard` devrait produire :

- 1, 3, 5

Note que l'union de `keep` et `discard` regroupe tous les éléments.

Les fonctions peuvent s'appeler `keep` et `discard`, ou bien avoir besoin d'autres noms pour ne pas entrer en conflit avec des fonctions ou des concepts déjà présents dans ton langage.

## Restrictions

Ne touche pas à cette fonctionnalité filter/reject/machin-truc fournie par ta bibliothèque standard ! Résous cet exercice toi-même, avec d'autres outils de base à la place.
