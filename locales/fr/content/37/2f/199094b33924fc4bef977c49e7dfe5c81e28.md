# Instructions

Bonjour, agent Double-Null0111.

Ta mission, si tu l'acceptes, est d'écrire une paire d'outils pour t'aider à infiltrer le quartier général d'UMBRA (United Minions Being Really Awful) et à récupérer les plans de leur dernier projet vraiment ignoble.
Trois outils te seront nécessaires pour mener à bien cette mission.

## 1. Génère un numéro d'identification

Chaque sbire possède un identifiant unique qui change chaque jour et qui dépend du nombre de secrets qu'il détient et du nombre d'heures qu'il dort.
Tu vas devoir écrire une fonction qui prend le jour (sous forme d'un `Int`) et qui crée une fonction génératrice d'identifiant pour ce jour.
La fonction génératrice d'identifiant prend deux paramètres :

1. le nombre de secrets détenus
2. le nombre d'heures de sommeil du sbire

L'identifiant se calcule ainsi :

1. multiplier le nombre de secrets détenus par le nombre d'heures qu'il dort
2. ajouter le jour (représenté par un `Int`) au résultat

```kotlin
val idGenerator = makeIdGenerator(4)
idGenerator(3, 6)
// => 22

idGenerator(11, 5)
//  => 59
```

## 2. Protège les plans secrets récupérés avec un mot de passe secret

Une fois que tu as les plans secrets, tu vas devoir les protéger afin que seules les personnes qui connaissent le mot de passe puissent les récupérer.
Pour ce faire, tu vas devoir implémenter la fonction `protectSecret(secret: String, password: String) : (String) -> String`.
Cette fonction renvoie une autre fonction qui prend en entrée des _strings_ représentant des mots de passe possibles.
Si le mot de passe saisi est correct, la nouvelle fonction renvoie le secret caché, mais si le mot de passe est incorrect, la fonction renvoie « Sorry. No hidden secrets here. »

```kotlin
val secretFunction = protectSecret("Steal the world's supply of french fries!", "5up3r53cr37")

secretFunction("Open sesame")
// Returns "Sorry. No hidden secrets here."

secretFunction("5up3r53cr37")
// Returns "Steal the world's supply of french fries!"
```

## 3. Trouve le mot de passe secret

La base d'UMBRA compte un certain nombre de salles gardées par un agent de sécurité qui te demandera le mot de passe secret.
Le mot de passe secret dépend du numéro de la salle.
Malheureusement, nous ne connaissons que la moitié de l'algorithme qui permet de trouver le mot de passe.
L'autre moitié peut être obtenue en demandant à l'un des sbires.

Implémente la fonction `getPassword` qui prend les éléments suivants et renvoie le mot de passe :

1. le numéro de la salle
2. la fonction du sbire et renvoie le mot de passe secret

Le mot de passe secret s'obtient en appelant la fonction du sbire avec une autre fonction représentant l'algorithme que nous connaissons.
Notre partie de l'algorithme :

1. prend deux nombres et les additionne
2. multiplie le résultat par l'identifiant de la salle

```kotlin
val minionFunction = { yourFunc : (Int, Int) -> Int ->
    "Password=${yourFunc(1, 3)}"
}

getPassword(5, minionFunction)
// Returns "Password=20"
```
