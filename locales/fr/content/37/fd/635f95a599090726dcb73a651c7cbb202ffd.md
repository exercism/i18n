# Ajout aux instructions

## Affiche l'arbre

Cet exercice fournit quelques méthodes de classe prédéfinies pour t'aider à afficher l'arbre dans un format agréable.
Leur principal objectif est de faciliter le débogage et d'apporter un peu plus de clarté.
Si tu implémentes correctement le reste de la classe, elles devraient afficher l'arbre pour toi.

```powershell
.Example
$tree = [BinarySearchTree]::new(@(50, 76, 1, 34, 89, 44, 25, 6, 26, 100, 13))
$tree.ToString()

Return:
@"
50
├──L:1
│   └──R:34
│       ├──L:25
│       │   ├──L:6
│       │   │   └──R:13    
│       │   └──R:26        
│       └──R:44
└──R:76
    └──R:89
        └──R:100
"@
```
