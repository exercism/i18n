## 1. Repérer les lignes de log brouillées

- Utilise le [sigil `r`][sigil-r] pour créer une expression régulière.
- Il existe [un opérateur][match-operator] qui permet de tester une _string_ par rapport à une expression régulière. Il existe aussi une [fonction de `Regex`][regex-match] et une [fonction de `String`][string-match] qui font la même chose.
- N'oublie pas d'échapper les caractères qui ont un sens particulier dans les expressions régulières.

## 2. Découper la ligne de log

- Il existe une [fonction de `Regex`][regex-split] ainsi qu'une [fonction de `String`][string-split] qui permettent de découper une _string_ en un tableau de _strings_ à partir d'une expression régulière.
- N'oublie pas d'échapper les caractères qui ont un sens particulier dans les expressions régulières.

## 3. Supprimer les artefacts du log

- Il existe une [fonction de `Regex`][regex-replace] ainsi qu'une [fonction de `String`][string-replace] qui permettent de remplacer par une autre _string_ la partie d'une _string_ qui correspond à une expression régulière donnée.
- Il existe un [modificateur][regex-modifiers] qui peut rendre toute l'expression régulière insensible à la casse.

## 4. Étiqueter les lignes avec les noms d'utilisateur

- Il existe une [fonction de `Regex`][regex-run] qui exécute une expression régulière sur une _string_ et renvoie toutes les captures.
