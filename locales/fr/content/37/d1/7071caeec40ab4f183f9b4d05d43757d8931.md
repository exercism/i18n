# À propos

En Haxe, un type abstrait est un type qui est un type différent à l'exécution. C'est une fonctionnalité de compilation qui définit des types « au-dessus » de types concrets afin de modifier ou d'enrichir leur comportement :

```haxe
abstract AbstractInt(Int) {
    inline public function new(i:Int) {
        this = i;
    }
}
```

Ici, on déclare le type `AbstractInt` à l'aide du mot-clé `abstract`. Sa syntaxe est très proche de celle de `class`. Et tout comme les classes, les types abstraits peuvent avoir des méthodes. On peut aussi les instancier et les utiliser exactement comme des classes :

```haxe
class Main {
    static public function main() {
        var a = new AbstractInt(12);
        trace(a); // 12
    }
}
```

Comme évoqué plus haut, les types abstraits sont une fonctionnalité de compilation. Compiler l'exemple ci-dessus vers JavaScript donne ce qui suit :

```javascript
var a = 12;
console.log(a)
```

Le type abstrait `AbstractInt` disparaît complètement de la sortie. C'est parce que le constructeur d'`Abstract` est [inliné][inline], comme on le verra plus loin.

[inline]: https://haxe.org/manual/class-field-inline.html
