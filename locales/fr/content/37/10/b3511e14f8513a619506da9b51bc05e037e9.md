# Introduction

Go n'a pas de notion de vide, de _null_ ou d'_undefined_ pour la valeur des variables.
Les variables déclarées sans valeur initiale explicite prennent par défaut la valeur zéro de leur type respectif.

La valeur zéro des types primitifs, comme les booléens, les types numériques et les _strings_, est respectivement `false`, `0` et `""`.

L'identifiant `nil`, qui signifie zéro, est la valeur zéro des types plus complexes, comme les pointeurs, les fonctions, les interfaces, les _slices_, les _channels_ et les _maps_.

Le tableau suivant détaille la valeur zéro des types de Go.

| Type      | Valeur zéro |
| --------- | ----------- |
| booléen   | `false`     |
| numérique | `0`         |
| _string_  | `""`        |
| pointeur  | `nil`       |
| fonction  | `nil`       |
| interface | `nil`       |
| _slice_   | `nil`       |
| _channel_ | `nil`       |
| _map_     | `nil`       |

Tu as peut-être remarqué que les types structure sont absents du tableau ci-dessus.
C'est parce que la valeur zéro d'une structure dépend de ses champs.
Une structure est mise à sa valeur zéro lorsque tous ses champs sont mis à leur valeur zéro respective.
