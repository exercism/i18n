# Introduction

Chaque fichier source Factor déclare un *vocabulaire* avec `IN:` et importe
tous ceux qu'il utilise avec `USING:`.

```factor
USING: kernel sequences ;
IN: my-vocab

: shout ( str -- str ) "!" append ;
```

L'arborescence des répertoires reprend le nom du vocabulaire, points compris :

- le vocabulaire `my-vocab` se trouve dans `my-vocab/my-vocab.factor`
- le vocabulaire `my-vocab.helpers` se trouve dans `my-vocab/helpers/helpers.factor`

Le chargeur de vocabulaires de Factor suit les déclarations `USING:` de
manière transitive. Ainsi, quand un fichier que tu charges importe un autre
vocabulaire, ce vocabulaire est chargé automatiquement.

Tu seras souvent amené à répartir une grande routine sur deux vocabulaires :
un vocabulaire d'aide avec de petits mots réutilisables, et un vocabulaire
principal qui les importe et compose le résultat.
