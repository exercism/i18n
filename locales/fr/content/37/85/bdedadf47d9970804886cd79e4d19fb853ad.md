# Coloration syntaxique

Il existe deux types de coloration syntaxique sur le site :

1. La coloration du code _statique_ (extraits de code, itérations, etc.).
   Consulte la [documentation sur la coloration syntaxique statique](/docs/building/tracks/new/syntax-highlighting/static) pour plus d'informations.
2. La coloration du code _dynamique_ (l'éditeur en ligne).
   Consulte la [documentation sur la coloration syntaxique dynamique](/docs/building/tracks/new/syntax-highlighting/dynamic) pour plus d'informations.

```exercism/note
Les exigences pour la coloration syntaxique statique et dynamique sont _très_ différentes, c'est pourquoi elles font appel à des bibliothèques distinctes.
```
