# Instructions supplémentaires

## Instructions spécifiques au parcours

Les fonctions sont censées renvoyer le produit, ainsi que l'_offset_ et la longueur du tableau de facteurs.
Les facteurs sont simplement écrits en mémoire sous forme de paires d'i32 :

```
Return value:
[u32 $product] [u32 $factorsOffset] [u32 $factorsLength]

Memory at $factorsOffset
[u32 firstFactor] [u32 firstCofactor] [u32 secondFactor] [u32 secondCofactor] ...
```

Pour le plus grand produit palindrome à un chiffre, cela ressemblerait à ceci :

```
Return value
0009 0000 0004

Memory at offset 0
0001 0009 0003 0003
```
