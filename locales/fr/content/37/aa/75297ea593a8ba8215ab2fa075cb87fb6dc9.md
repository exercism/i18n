# Instructions

Ta tâche consiste à déterminer ce que tu diras en offrant le cookie supplémentaire.

Si ton ami aime les cookies et s'appelle Do-yun, tu diras :

```text
One for Do-yun, one for me.
```

Si ton ami n'aime pas les cookies, tu donnes le cookie à la personne suivante dans la file d'attente à la boulangerie.
Comme tu ne connais pas son nom, tu diras _you_ à la place.

```text
One for you, one for me.
```

Voici quelques exemples :

| Nom    | Dialogue                    |
| :----- | :-------------------------- |
| Alice  | One for Alice, one for me.  |
| Bohdan | One for Bohdan, one for me. |
|        | One for you, one for me.    |
| Zaphod | One for Zaphod, one for me. |
