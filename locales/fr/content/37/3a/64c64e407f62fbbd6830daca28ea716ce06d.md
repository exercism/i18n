# À propos

## Fermetures de fin

Swift propose une autre variante de sa syntaxe lorsqu'il s'agit de fermetures, appelée [fermetures de fin][trailing-closures]. Les fermetures de fin apparaissent lorsque le dernier paramètre de la liste des paramètres d'une fonction a un type de fonction. Dans ce cas, si l'on passe une fermeture, celle-ci peut être écrite _après_ la parenthèse fermante et l'étiquette d'argument est omise. Note que s'il n'y a qu'un seul paramètre pour la fonction, les parenthèses peuvent être omises entièrement.

```swift
func fetchURL(_ urlString: String,
              uponReceipt handleResult: (String) -> ()
             )  -> () {
  if let url = URL(string: urlString), let htmlString = fetch(url) {
    handleResult(htmlString)
  }
}

fetchURL("https://www.swift.org") { print($0) }
// prints the fetched html string

["apple", "ball", "carrot"].sorted { $0.count < $1.count }
```

## Fermetures de fin multiples

Alors que les versions antérieures de Swift ne prenaient en charge qu'une seule fermeture de fin, à partir de la version 5.2.4, Swift prend en charge plusieurs fermetures de fin.

Si une fonction a plus d'une fermeture à la fin de sa liste de paramètres, la syntaxe des fermetures de fin peut être utilisée pour toutes les déplacer en dehors des parenthèses. Cependant, seule la première étiquette d'argument est omise, les autres doivent être étiquetées : 

```swift
func fetchURL(_ urlString: String,
              uponReceipt handleResult: (String) -> (),
              onFailure handleFailure: () -> ()
             )  -> () {
  if let url = URL(string: urlString), let htmlString = fetch(url) {
    handleResult(htmlString)
  } else {
    handleFailure()
  }
}

fetchURL("https://www.swift.org") {
  print($0)
} onFailure: {
  print("Error: https://www.swift.org could not be fetched")
}
// prints the fetched html string on successful fetch or prints error message on failure
```

[trailing-closures]: https://docs.swift.org/swift-book/LanguageGuide/Closures.html#ID102
