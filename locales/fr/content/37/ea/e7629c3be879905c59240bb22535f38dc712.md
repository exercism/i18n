# Instructions

[La peinture par numéros][paint-by-number] (aussi appelée _coloriage par numéros_)
désigne des images en noir et blanc destinées à être coloriées.
Les différentes zones de l'image sont annotées avec des numéros différents,
et ces numéros correspondent à des couleurs précises dans une palette de couleurs prédéfinie.
Le but est de remplir les zones avec les bonnes couleurs,
pour révéler au final une magnifique image haute en couleur.
C'est une activité relaxante, pour les enfants comme pour les adultes.

Tu dois écrire une application de peinture par numéros en Elixir.
Tu veux que ton application puisse importer et exporter des images dans un format de données personnalisé.
Tu as donc décidé d'utiliser des [fichiers binaires][binary-file] pour stocker les données de tes images.

~~~~exercism/note
Cet exercice suppose que tu connaisses les [nombres binaires](https://en.wikipedia.org/wiki/Binary_number)
et que tu comprennes les principes qui permettent de convertir des nombres binaires en nombres décimaux
et des nombres décimaux en nombres binaires.
~~~~

Imaginons que tu aies une image de smiley, comme celle ci-dessous.
L'image a un fond blanc. Le smiley a un contour noir et une couleur de remplissage jaune.

Cette image utilise 3 couleurs.
Disons que l'on attribue des indices à ces couleurs :
- `0` (binaire : `0b00`) pour le blanc,
- `1` (binaire : `0b01`) pour le noir,
- `2` (binaire : `0b10`) pour le jaune.

On peut maintenant utiliser ces indices de couleur pour représenter la couleur de chaque pixel.

## 1. Calcule la taille en bits de la palette

Implémente la fonction `PaintByNumber.palette_bit_size/1`. Elle doit prendre le nombre de couleurs de la palette et renvoyer combien de bits sont nécessaires pour représenter autant d'indices de couleur en binaire. Les indices de couleur commencent toujours à 0 et sont des entiers consécutifs croissants.

Par exemple, représenter 13 couleurs différentes nécessite 4 bits. 4 bits peuvent stocker jusqu'à 16 indices de couleur (2^4). 3 bits ne suffiraient pas, car 3 bits ne peuvent stocker que jusqu'à 8 indices de couleur (2^3).

```elixir
PaintByNumber.palette_bit_size(13)
# => 4
```

Remarque : il n'existe pas de fonction `log2` dans la bibliothèque standard d'Elixir. Tu apprendras plus tard comment utiliser les [bibliothèques Erlang][erlang-libraries] depuis Elixir, où tu trouveras cette fonction. Pour le moment, résous cette tâche avec la récursion et l'[opérateur de puissance `**`][power-operator] à la place.

## 2. Crée une image vide

Implémente la fonction `PaintByNumber.empty_picture/0`. Elle doit renvoyer un bitstring vide.

## 3. Crée une image de test

Une image de test prédéfinie sera utilisée pour tester manuellement les fonctionnalités de base de ton application.
Cette image de test est composée de 4 pixels de 4 couleurs différentes.

Implémente la fonction `PaintByNumber.test_picture/0`. Elle doit renvoyer un bitstring composé de 4 segments.
Chaque segment doit avoir une taille de 2 bits. Les segments doivent avoir pour valeurs 0, 1, 2 et 3.

## 4. Ajoute un pixel au début d'une image

Implémente la fonction `PaintByNumber.prepend_pixel/3`. Elle doit prendre trois arguments : un bitstring contenant l'image à laquelle on ajoute un pixel au début, le nombre de couleurs de la palette et l'indice de la couleur du nouveau pixel. Elle doit renvoyer un bitstring contenant l'image avec le nouveau pixel ajouté au début.

```elixir
picture = <<2::4, 0::4>>
color_count = 13
pixel_color_index = 11

PaintByNumber.prepend_pixel(picture, color_count, pixel_color_index)
# => <<178, 0::size(4)>>
# (which is equal to <<11::4, 2::4, 0::4>>)
```

## 5. Récupère le premier pixel d'une image

Implémente la fonction `PaintByNumber.get_first_pixel/2`. Elle doit prendre deux arguments : un bitstring contenant l'image dans laquelle on lit, et le nombre de couleurs de la palette. Elle doit renvoyer l'indice de couleur du premier pixel de l'image donnée. Si on lui donne une image vide, elle doit renvoyer `nil`.

```elixir
picture = <<19::5, 2::5, 18::5>>
color_count = 20

PaintByNumber.get_first_pixel(picture, color_count)
# => 19
```

## 6. Supprime le premier pixel d'une image

Implémente la fonction `PaintByNumber.drop_first_pixel/2`. Elle doit prendre deux arguments : un bitstring contenant l'image de laquelle on retire un pixel, et le nombre de couleurs de la palette. Elle doit renvoyer l'image sans le premier pixel. Si on lui donne une image vide, elle doit renvoyer une image vide.

```elixir
picture = <<2::3, 5::3, 5::3, 0::3>>
color_count = 6

PaintByNumber.drop_first_pixel(picture, color_count)
# => <<180, 0::size(1)>>
# (which is equal to <<5::3, 5::3, 0::3>>)
```

## 7. Concatène deux images

Implémente la fonction `PaintByNumber.concat_pictures/2`. Elle doit prendre deux arguments, deux bitstrings. Elle doit renvoyer un bitstring qui est le résultat de l'ajout du premier argument au début du second.

```elixir
picture1 = <<52::6, 51::6>>
picture2 = <<0::6, 34::6, 12::6>>

PaintByNumber.concat_pictures(picture1, picture2)
# => <<211, 48, 34, 12::size(6)>>
# (which is equal to <<52::6, 51::6, 0::6, 34::6, 12::6>>)
```
