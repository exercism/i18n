# Exécute les tests

Pour exécuter les tests d'un exercice, exécute le script `<exercise>.test` situé dans le répertoire de l'exercice :

```bash
tclsh <exercise>.test
```

Pour la plupart des exercices, tous les tests sauf le premier seront « skipped ».
Cela te permet, en tant que développeur, de pratiquer le développement piloté par les tests : n'écrire que le strict nécessaire pour faire passer chaque test, un à un.
Pour passer outre les commandes de saut, définis la variable d'environnement `RUN_ALL` sur une valeur vraie de Tcl valide \[1\] avant d'exécuter la suite de tests :

```bash
RUN_ALL=yes tclsh <exercise>.test
```

\[1\] : les valeurs vrai/faux de Tcl sont documentées dans la page de manuel de la fonction de la bibliothèque C [Tcl_GetBoolean][bool].

[bool]: https://www.tcl-lang.org/man/tcl8.6/TclLib/GetInt.htm
