# Installer Swift

Swift est disponible sur macOS, Linux et Windows.
Le processus d'installation varie selon le système d'exploitation que tu utilises.
Un point important à noter concernant la prise en charge de Linux : Swift n'est (officiellement) pris en charge que sur les distributions suivantes :
- Ubuntu
- Debian
- RedHat
- Fedora
- Amazon Linux

Si tu utilises une autre distribution de Linux, tu devras trouver toi-même un moyen d'installer Swift.

## Xcode (macOS)

Swift est inclus avec Xcode, l'IDE d'Apple pour le développement sur macOS et iOS.
Pour le parcours Exercism, tu devras avoir installé Xcode version 16.0 ou supérieure.
Xcode est disponible gratuitement sur le [Mac App Store][xcode].
D'autres versions de Xcode (dont la dernière bêta) sont disponibles sur le [centre de développement d'Apple][apple-developer-center].

## macOS et Linux

Pour macOS et Linux, il existe un gestionnaire d'installation de Swift appelé [swiftly][swiftly].
C'est un outil en ligne de commande qui te permet d'installer et de gérer plusieurs versions de Swift sur ton système.
La commande pour installer swiftly sur macOS se trouve [ici][swiftly-macos], et [ici][swiftly-linux] pour Linux.

Une autre méthode d'installation pour macOS est [Homebrew][homebrew].
Pour Linux, tu peux installer à partir de l'archive tar du [site officiel de Swift][tarball].

## Windows

La méthode recommandée pour installer Swift sur Windows est d'utiliser [l'installateur WinGet][winget-windows].
Il est également possible d'installer Swift avec le gestionnaire de paquets Scoop ou en faisant une installation manuelle.
Pour toutes les options, consulte la page [Installer Swift pour Windows][swift-windows].
