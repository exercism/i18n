# À propos

## Opérateurs de comparaison

Les [opérateurs de comparaison][comparison-operators] comparent deux valeurs du même type et renvoient une valeur `Bool` (`true` ou `false`).
Si tu essaies de comparer des valeurs de types différents, le compilateur produit une erreur.

Voici les opérateurs de comparaison standard en Swift :

| Opérateur | Description | Exemple |
| -------- | ------------------------ | --------------- |
| `==`     | Égal à | `1 == 1` (vrai) |
| `!=`     | Différent de | `1 != 2` (vrai) |
| `<`      | Inférieur à | `4 < 5`  (vrai) |
| `<=`     | Inférieur ou égal à | `4 <= 4` (vrai) |
| `>`      | Supérieur à | `3 > 1`  (vrai) |
| `>=`     | Supérieur ou égal à | `2 >= 2` (vrai) |

## Les instructions `if` et `else`

Une [instruction conditionnelle][conditional-statement] exécute du code selon qu'une condition vaut `true` ou `false`.
La plus courante est l'[instruction `if`][if], qui exécute un bloc de code uniquement lorsque sa condition vaut `true`.
Pour écrire une instruction `if`, on utilise le mot-clé `if`, suivi de la condition et du bloc de code entre accolades :

```swift
let wheelCount = 4
if wheelCount == 4 {
    print("Your vehicle is a car")
}
// Prints "Your vehicle is a car"
```

Tu peux associer `if` à une clause `else` pour exécuter un autre code lorsque la condition vaut `false` :

```swift
let precipitationInMM = 0.5
if precipitationInMM > 0.5 {
    print("You will need an umbrella")
} else {
    print("You will not need an umbrella")
}
// Prints "You will not need an umbrella"
```

Pour tester plusieurs conditions à la suite, on enchaîne les instructions avec `else if`.
Une instruction `if` n'a pas besoin d'une branche `else`, mais tu peux en ajouter une pour gérer les cas où aucune des conditions ne correspond :

```swift
let favoriteFruit = "Apple"

if favoriteFruit == "Banana" {
    print("Your favorite fruit is a banana")
} else if favoriteFruit == "Orange" {
    print("Your favorite fruit is an orange")
} else if favoriteFruit == "Apple" {
    print("Your favorite fruit is an apple")
} else {
    print("Your favorite fruit is not a banana, orange, or apple")
}
// Prints "Your favorite fruit is an apple"
```

## Les expressions `if`

Dans les versions modernes de Swift, les instructions `if` peuvent aussi servir d'expressions qui produisent une valeur.
Chaque branche s'évalue en une valeur, ce qui facilite l'affectation conditionnelle d'un résultat :

```swift
let cpuBits = 32
let architecture = if cpuBits == 64 {
    "x86_64"
} else {
    "x86_32"
}

print(architecture)
// Prints "x86_32"
```
