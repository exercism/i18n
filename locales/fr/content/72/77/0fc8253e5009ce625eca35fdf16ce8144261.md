# Instructions

Tu tiens les jeux de hasard de la salle d'arcade du bord de mer. Les joueurs lancent les dés, la machine à pince attrape un lot, et la table de cartes a besoin qu'on mélange son paquet et qu'on distribue les mains, le tout grâce au hasard. À la fin de la soirée, tu veux aussi une fonctionnalité de « rejeu » pour pouvoir rejouer une partie contestée à partir de la même graine.

## 1. Lance un dé

Définis `roll-die` pour qu'il prenne le nombre de faces et renvoie un lancer compris entre `1` et `sides`, bornes incluses.

```factor
6 roll-die .
! => 4   (some value from 1..6)
```

## 2. Récupère un lot

Définis `pick-prize` pour qu'il prenne une séquence de lots et en renvoie un au hasard.

```factor
{ "teddy" "goldfish" "keyring" } pick-prize .
! => "goldfish"
```

## 3. Mélange le paquet

Définis `shuffle-deck` pour qu'il prenne un paquet (une séquence) et le renvoie avec les cartes dans un ordre aléatoire.

```factor
{ 1 2 3 4 5 } shuffle-deck .
! => { 3 1 5 2 4 }
```

## 4. Distribue une main

Définis `deal-hand` pour qu'il prenne un paquet et un nombre `n`, et renvoie `n` cartes *distinctes* du paquet.

```factor
{ 10 20 30 40 50 } 3 deal-hand .
! => { 40 10 30 }
```

## 5. Rejoue à partir d'une graine

Définis `play-seeded` pour qu'il prenne une graine et une _quotation_, et exécute la _quotation_ avec un générateur initialisé à partir de cet entier, afin que la même graine reproduise toujours le même résultat. Le résultat de la _quotation_ doit être renvoyé à l'appelant.

```factor
42 [ 6 roll-die ] play-seeded .
! => the same value every time for seed 42

! Same seed, same game:
99 [ 5 deal-hand ] play-seeded   99 [ 5 deal-hand ] play-seeded   =  .
! => t
```
