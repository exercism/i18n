# Installation

## Options d'installation

La version actuelle d'Unison est disponible pour Mac OS X, Linux 64 bits et Windows ! Si tu essaies Unison, nous espérons que tu viendras nous parler sur le forum Exercism ou sur le [Discord d'Unison](https://unison-lang.org/discord). Viens poser des questions et signaler les problèmes que tu pourrais rencontrer ! Nous voulons que tes premiers pas soient accueillants et positifs ! 😊

Unison peut être téléchargé avec [homebrew](https://brew.sh/), [Nix](https://github.com/ceedubs/unison-nix/#usage), ou directement via des binaires packagés. Toutes ces options de téléchargement sont décrites sur la [page des instructions d'installation de notre site web](https://www.unison-lang.org/learn/quickstart/#installation-options). Une fois l'UCM installé, reviens ici !

### Option 1 : utilise Homebrew

Commence par [installer homebrew](https://brew.sh/) si ce n'est pas déjà fait.

Ensuite, saisis ces commandes en ligne de commande :

```
brew tap unisonweb/unison
brew install unison-language
```

Cela installe l'exécutable du gestionnaire de base de code Unison, `ucm`. Si tu passes d'une version précédente, il te suffit de faire

```
brew upgrade unison-language.
```

Remarque : si on te demande un nom d'utilisateur et un mot de passe GitHub à ce stade, vérifie que tu as bien orthographié unisonweb/unison.

### Option 2 : installe manuellement pour les utilisateurs de Mac et Linux

Les [liens d'installation manuelle pour Linux et Mac se trouvent ici](https://www.unison-lang.org/learn/quickstart/#installation-options), dans la section de téléchargement manuel correspondante pour Linux et Mac.

Tu vas exécuter dans ton shell une commande qui ressemble à peu près à ceci, mais le lien ci-dessus contient le binaire le plus à jour :

```
mkdir unisonlanguage
curl -L https://github.com/unisonweb/unison/releases/download/release_VERSION_NAME/ucm-YOUR_PLATFORM.tar.gz --output unisonlanguage/ucm.tar.gz
tar -xzf unisonlanguage/ucm.tar.gz -C unisonlanguage
./unisonlanguage/ucm
```

### Option 3 : installe manuellement pour les utilisateurs de Windows

1. Pour de meilleurs résultats, définis « Windows Terminal » comme application de terminal par défaut. Cherche « Terminal » dans Settings, ou suis [ce guide pratique.](https://bit.ly/3IXwdlY)
2. Si tu n'es pas sûr de l'avoir déjà, installe Git :
  * Avec winget : `winget install --id Git.Git -e --source winget`
  * Si tu es sous Windows 10 et que tu n'as pas winget, tu peux l'installer depuis [le Microsoft Store](https://www.microsoft.com/en-us/p/app-installer/9nblggh4nns1), puis exécuter la commande ci-dessus.
3. [Télécharge le UCM grâce au lien fourni ici](https://www.unison-lang.org/learn/quickstart/#installation-options) et extrais-le à l'endroit de ton choix.
4. Exécute `ucm.exe`

### Option 4 : installation avec Nix

Rends-toi sur [https://github.com/ceedubs/unison-nix/#usage](https://github.com/ceedubs/unison-nix/#usage) et suis les instructions du readme.

## Crée ta base de code Unison

Exécute `ucm` pour initialiser une base de code Unison dans `$HOME/.unison`. C'est là qu'Unison stockera les définitions de fonctions, les types, les espaces de noms, etc. Par défaut, le gestionnaire de base de code Unison (abrégé en « UCM ») commence à télécharger la bibliothèque standard, appelée `base`, que tu utiliseras pour écrire du code Unison. Cela peut prendre un moment ! 🕰

## Workflow Unison

Quand tu veux écrire du code Unison, tu lances la commande `ucm` pour démarrer le gestionnaire de base de code. L'UCM observe alors les modifications de tout fichier avec le suffixe `.u` dans le répertoire depuis lequel il est lancé. Par exemple, tu pourrais implémenter des fonctions dans un fichier appelé `scratch.u`, dans un répertoire appelé `~/exercism/unison/my-exercise/`. Tu dois faire `cd` dans `~/exercism/unison/my-exercise/` puis lancer `ucm`. Ainsi, l'UCM surveillera bien les modifications de ton fichier `scratch.u`.

Si tu as un doute sur le répertoire dans lequel `ucm` surveille les modifications de fichiers, il est affiché sur l'écran d'accueil au démarrage de la CLI.

```
👀 I'm watching for changes to .u files under /Users/myUser/exercism/unison/my-exercise
```

[Voir d'autres astuces de workflow ici !](https://exercism.org/docs/tracks/unison/workflow)

## Prise en charge des éditeurs

Tu peux utiliser n'importe quel éditeur de texte pour écrire tes fichiers `.u`. Unison dispose d'une [prise en charge du LSP](https://github.com/unisonweb/unison/blob/trunk/docs/language-server.markdown), donc ton IDE préféré peut t'aider pour des choses comme les types au survol et l'auto-complétion. Voici quelques éditeurs populaires qui prennent en charge Unison :

### Vim

Avec [vim-plug](https://github.com/junegunn/vim-plug) :

1. Installe [`vim-plug`](https://github.com/junegunn/vim-plug) si ce n'est pas déjà fait.
2. Ajoute la ligne suivante à ton .vimrc : `Plug 'unisonweb/unison', { 'branch': 'trunk', 'rtp': 'editor-support/vim' }`
3. Lance la commande vim `:PlugInstall`.

Pour plus d'informations, lance `:help unison` depuis vim ou consulte la [documentation d'aide en ligne](https://github.com/unisonweb/unison/blob/trunk/editor-support/vim/doc/unison.txt).

### Atom
Depuis la console, lance :

```
apm install unisonweb/atom-unison
```

### VS Code

1. Ouvre la vue Extensions en cliquant sur l'icône Extensions dans l'_Activity Bar_ sur le côté de VS Code, ou avec ⇧⌘X.
2. Cherche « unison »
3. Installe l'[extension Unison pour VS Code](https://marketplace.visualstudio.com/items?itemName=unison-lang.unison)

### Emacs
Installe [`unison-mode`](https://github.com/dariooddenino/unison-mode-emacs).
