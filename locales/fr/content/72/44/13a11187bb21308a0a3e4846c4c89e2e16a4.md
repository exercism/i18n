# Introduction

En Python, `None` est fréquemment utilisé pour représenter l'absence d'une valeur : une valeur de remplacement servant à définir une variable, un objet ou un argument `null` (vide).

Si tu as déjà entendu parler d'un type `NULL` ou `nil` dans un autre langage de programmation, ou si tu l'as déjà utilisé, alors cet usage de `None` en Python ne te sera pas étranger. `None` t'aide à déclarer des variables ou des arguments de fonction pour lesquels tu n'as pas encore de valeur. On peut ensuite leur affecter des valeurs précises quand c'est nécessaire.

```python
a = None
print(a)
#=> None
type(a)
#=> <class 'NoneType'>

# Adding a Default Argument with `None`
def add_to_todos(new_task, todo_list=None):
  if todo_list is None:
    todo_list = []
    todo_list.append(new_task)
  return todo_list

```

`None` est évalué à `False` lorsqu'il est utilisé dans un test conditionnel, ce qui est utile pour vérifier la « présence » ou l'« absence » d'une valeur, _n'importe quelle_ valeur. C'est un schéma fréquemment utilisé quand une fonction ou un processus est susceptible de renvoyer un objet ou un message d'erreur.

```python
a = None
if a: #=> a will be evaluated to False when its used in a conditional check.
    print("This will not be printed")
```
