# Tests

Pour exécuter le test de l'exercice avec la CLI, lance la commande suivante depuis le répertoire de l'exercice :

```bash
clojure -M:test
```

## REPL

Pour exécuter le test de l'exercice avec le REPL, lance la commande suivante depuis le répertoire de l'exercice :

```bash
$ clojure -m cljs.main -re node
```

Ensuite, fais un `require` sur l'espace de noms de test de l'exercice et sur l'espace de noms de test de Clojure) :

```clojure
;; replace <exercise> with the exercise's name
=> (require '<exercise>-test)
nil
;; and the test namespace
=> (require 'cljs.test)
```

Change l'espace de noms pour celui du test :

```clojure
;; replace <exercise> with the exercise's name
=> (ns <exercise>-test)
nil
```

Ensuite, appelle `run-tests` :

```clojure
=> (cljs.test/run-tests)
```
