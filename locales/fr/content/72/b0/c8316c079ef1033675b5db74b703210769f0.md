# Instructions

Dans cet exercice, tu vas travailler avec des comptes d'épargne.
Chaque année, le solde du compte d'épargne est mis à jour en fonction de son taux d'intérêt.
Le taux d'intérêt que ta banque t'accorde dépend de la somme d'argent présente sur le compte (son solde) :

- 3,213 % pour un solde inférieur à `0` dollar (le solde devient plus négatif).
- 0,5 % pour un solde supérieur ou égal à `0` dollar et inférieur à `1000` dollars.
- 1,621 % pour un solde supérieur ou égal à `1000` dollars et inférieur à `5000` dollars.
- 2,475 % pour un solde supérieur ou égal à `5000` dollars.

Tu as quatre tâches à accomplir, qui portent chacune sur le solde et son taux d'intérêt.

## 1. Calcule le taux d'intérêt

Implémente la fonction `InterestRate()` pour calculer le taux d'intérêt correspondant au solde indiqué :

```go
InterestRate(200.75)
// => 0.5
```

Note que la valeur renvoyée est de type `float32`.

## 2. Calcule les intérêts

Implémente la fonction `Interest()` pour calculer les intérêts correspondant au solde indiqué :

```go
Interest(200.75)
// => 1.003750
```

Note que la valeur renvoyée est de type `float64`.

## 3. Calcule la mise à jour annuelle du solde

Implémente la fonction `AnnualBalanceUpdate()` pour calculer la mise à jour annuelle du solde, en tenant compte du taux d'intérêt :

```go
AnnualBalanceUpdate(200.75)
// => 201.75375
```

Note que la valeur renvoyée est de type `float64`.

## 4. Calcule le nombre d'années nécessaires pour atteindre le solde souhaité

Implémente la fonction `YearsBeforeDesiredBalance()` pour calculer le nombre minimum d'années nécessaires pour atteindre le solde souhaité, sachant que chaque année, les intérêts s'ajoutent au solde.
Cela signifie que le solde après un an est : solde de départ + intérêts sur le solde de départ.
Le solde après la deuxième année est : solde après un an + intérêts sur le solde après un an.
Et ainsi de suite, jusqu'à ce que le solde de l'année en cours soit supérieur ou égal au solde cible.

```go
balance := 200.75
targetBalance := 214.88
YearsBeforeDesiredBalance(balance, targetBalance)
// => 14
```

Note que la valeur renvoyée est de type `int`.
