# Instructions

Dans cet exercice, tu vas écrire du code pour t'aider à te préparer à acheter un véhicule.

Tu as trois tâches : l'une pour déterminer si tu peux assumer les mensualités d'une voiture, l'une pour déterminer le type de permis de conduire dont tu auras besoin, et l'une pour estimer le prix acceptable d'un véhicule d'occasion.

## 1. Détermine si tu peux assumer les mensualités d'une voiture donnée

Les concessionnaires automobiles de ta ville proposent tous une promotion sur cinq ans à 0 % d'intérêt dont tu aimerais profiter.
Mais tu n'es pas sûr de pouvoir assumer les mensualités de la voiture que tu veux.

La mensualité correspond au prix total de la voiture divisé par le nombre de mois de la période de cinq ans.

Implémente la fonction `canIBuy(vehicle:price:monthlyBudget:)` qui prend les arguments suivants :
- `vehicle` : le nom du véhicule que tu veux acheter.
- `price` : le prix du véhicule que tu veux acheter.
- `monthlyBudget` : le montant que tu peux te permettre de payer chaque mois.

La fonction doit renvoyer le message suivant selon les conditions suivantes :
- Si la mensualité du véhicule est inférieure ou égale au budget mensuel, renvoie le message `"Yes! I'm getting a <vehicle>"`.
- Si la mensualité du véhicule dépasse ton budget mensuel de 10 % au maximum (borne incluse), renvoie le message `"I'll have to be frugal if I want a <vehicle>"`.
- Si la mensualité du véhicule dépasse ton budget mensuel de plus de 10 %, renvoie le message `"Darn! No <vehicle> for me"`.

```swift
canIBuy(vehicle: "1974 Ford Pinto", price: 516.32, monthlyBudget: 100.00)
// returns "Yes! I'm getting a 1974 Ford Pinto"
canIBuy(vehicle: "2011 Bugatti Veyron", price: 2_250_880.00, monthlyBudget: 10000.00)
// returns "Darn! No 2011 Bugatti Veyron for me"
canIBuy(vehicle: "2020 Indian FTR 1200", price: 12_500, monthlyBudget: 200)
// returns "I'll have to be frugal if I want a 2020 Indian FTR 1200"
```

## 2. Détermine le type de permis de conduire dont tu auras besoin

Tu as décidé d'acheter un véhicule d'occasion et tu dois déterminer quel type de permis de conduire il te faudra pour le conduire.

Implémente la fonction `licenseType(numberOfWheels:)` qui prend l'argument `numberOfWheels`, le nombre de roues du véhicule que tu veux acheter.

La fonction doit renvoyer le message suivant selon les conditions suivantes :
- Si le nombre de roues vaut 2 ou 3, renvoie le message `"You will need a motorcycle license for your vehicle"`.
- Si le nombre de roues vaut 4 ou 6, renvoie le message `"You will need an automobile license for your vehicle"`.
- Si le nombre de roues vaut 18, renvoie le message `"You will need a commercial trucking license for your vehicle"`.
- Pour tout autre nombre, renvoie le message `"We do not issue licenses for those types of vehicles"`.

```swift
licenseType(numberOfWheels: 2)
// returns "You will need a motorcycle license for your vehicle"
licenseType(numberOfWheels: 6)
// returns "You will need an automobile license for your vehicle"
licenseType(numberOfWheels: 18)
// returns "You will need a commercial trucking license for your vehicle"
licenseType(numberOfWheels: 0)
// returns "We do not issue licenses for those types of vehicles"
```

## 3. Estime le prix d'un véhicule d'occasion

Maintenant que tu as pris ta décision, tu veux t'assurer d'obtenir un prix correct chez le concessionnaire.
Comme tu envisages d'acheter un véhicule d'occasion, le prix dépend de l'âge du véhicule.
Pour une estimation approximative, considère que si le véhicule a moins de 3 ans, il coûte 80 % de son prix d'origine à l'état neuf.
S'il a au moins 10 ans, il coûte 50 %.
Si le véhicule a au moins 3 ans mais pas plus de 10 ans, il coûte 70 % de son prix d'origine.

Implémente la fonction `calculateResellPrice(originalPrice:yearsOld:)` qui prend les arguments `originalPrice`, le prix d'origine du véhicule, et `yearsOld`, l'âge du véhicule en années.
La fonction doit renvoyer le prix de revente du véhicule.

```swift
calculateResellPrice(originalPrice: 1000, yearsOld: 1)
// returns 800
calculateResellPrice(originalPrice: 1000, yearsOld: 5)
// returns 700
calculateResellPrice(originalPrice: 1000, yearsOld: 15)
// returns 500
```
