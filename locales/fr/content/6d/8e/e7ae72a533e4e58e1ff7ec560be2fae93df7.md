# Ressources

* [The Rust Programming Language](https://doc.rust-lang.org/book/) est une excellente ressource pour débuter avec Rust et pour approfondir des fonctionnalités spécifiques de Rust.
* [Rust by Example](https://doc.rust-lang.org/stable/rust-by-example/) te montre des exemples des choses les plus courantes que tu écriras en Rust.
* La [Rust API Documentation](http://doc.rust-lang.org/std/) peut être utilisée pour découvrir de nouvelles méthodes et leur fonctionnement.
* [Stack Overflow](http://stackoverflow.com/questions/tagged/rust) peut être utilisé pour rechercher ton problème et voir s'il a déjà reçu une réponse. Tu peux aussi poser et répondre à des questions.
* Le [Rust User Forum](http://users.rust-lang.org) est destiné aux discussions générales sur Rust.
* [/r/rust](http://www.reddit.com/r/rust/) est le subreddit officiel de Rust.
* Le serveur officiel [The Rust Programming Language](https://discord.gg/rust-lang) sur [Discord](https://discordapp.com/) peut être utilisé pour des questions rapides et des discussions sur le langage.
