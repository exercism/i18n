# À propos

Bien que Swift inclue de nombreuses fonctionnalités dans sa bibliothèque standard, il en existe bien davantage sous la forme de bibliothèques externes.
Ces bibliothèques peuvent provenir du projet Swift lui-même, comme le [Swift Argument Parser][argument-parser], être des bibliothèques à code source fermé fournies par des entreprises, comme le [Network Framework][network-framework] d'Apple, ou être des bibliothèques tierces, comme [Swifty Beaver][swifty-beaver].

Certains de ces modules, comme le Network Framework ou [Foundation][apple-foundation] (qui est probablement la bibliothèque la plus utilisée en Swift), sont fournis avec la distribution de Swift.
Les bibliothèques tierces externes doivent, elles, être ajoutées à ton projet avant de pouvoir être importées, mais cela sort du cadre de cet exercice.

Pour importer un module, on écrit le mot-clé `import` suivi du nom du module. Ainsi, on peut importer Foundation en ajoutant la ligne suivante à son programme.

```swift
import Foundation
```

Cela donne accès à tous les types, valeurs et fonctionnalités de ce module ; par exemple, si on souhaite utiliser la méthode `components(separatedBy:)` de `String`, cette méthode devient disponible pour `String` avec cet import.

Même s'il est possible de placer les instructions `import` n'importe où dans le code, avant un passage qui utilise l'un des éléments du module, on les place généralement au début du fichier qui les utilise, pour une meilleure lisibilité.

[argument-parser]: https://apple.github.io/swift-argument-parser/documentation/argumentparser/
[network-framework]: https://developer.apple.com/documentation/network
[swifty-beaver]: https://github.com/SwiftyBeaver/SwiftyBeaver
[apple-foundation]: https://developer.apple.com/documentation/foundation
