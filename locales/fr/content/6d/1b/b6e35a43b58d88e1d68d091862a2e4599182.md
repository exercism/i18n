# Ne pas utiliser les fonctions de liste

Le but de cet exercice étant de créer toi-même ces fonctions de base, n'utilise aucun module externe (comme List, Enum ou Stream) dans ton implémentation. Tu peux utiliser les fonctions de base de Kernel (comme `Kernel.+/2` pour additionner des nombres), mais évite les fonctions de Kernel dédiées aux listes, comme `++`, `--`, `hd`, `tl`, `in`, `for` et `length`.
