# Indices

## 1. Vérifie si une attaque rapide est possible

On doit vérifier si le chevalier est éveillé et _inverser_ sa valeur de vérité. On peut le faire avec la fonction [`not`][not].

## 2. Vérifie si on peut espionner le groupe

On veut que la fonction renvoie `true` si _au moins une_ des assertions fournies est vraie. On peut le faire avec la fonction [`or`][or].

## 3. Vérifie si on peut prévenir le prisonnier

On veut renvoyer `true` si et seulement si _toutes_ les assertions fournies sont vraies. On peut le faire avec la fonction [`and`][and].

## 4. Vérifie si on peut libérer le prisonnier

Ici, il faut combiner les trois opérateurs logiques de base, [`and`][and], [`or`][or] et [`not`][not].

[not]: https://clojuredocs.org/clojure.core/not
[or]: https://clojuredocs.org/clojure.core/or
[and]: https://clojuredocs.org/clojure.core/and
