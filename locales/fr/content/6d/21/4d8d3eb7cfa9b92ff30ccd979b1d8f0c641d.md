# Introduction

Il existe deux types de nombres en Gleam : les entiers et les nombres décimaux.

Les entiers sont des nombres sans partie décimale.

```gleam
let integer = 3
// -> 3
```

Gleam dispose de plusieurs opérateurs qui fonctionnent avec les entiers.

```gleam
1 + 1 // -> 2
5 - 1 // -> 4
5 / 2 // -> 2
3 * 3 // -> 9
5 % 2 // -> 1

2 > 1  // -> True
2 < 1  // -> False
2 >= 1 // -> True
2 <= 1 // -> False
```
