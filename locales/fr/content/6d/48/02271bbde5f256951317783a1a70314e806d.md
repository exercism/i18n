# Installation

## Installe .NET

Le parcours C# s'appuie sur la plateforme [.NET](https://dotnet.microsoft.com/learn/dotnet/what-is-dotnet), qui fonctionne sous Windows, Linux et macOS.
Pour construire des projets .NET, on peut utiliser l'interface en ligne de commande (CLI) de .NET.
Cette CLI fait partie du SDK .NET, que tu peux installer en suivant les [instructions d'installation](https://dotnet.microsoft.com/download/dotnet/8.0).
Remarque : le parcours C# nécessite la version 9.0 ou supérieure du SDK.

Une fois l'installation terminée, tu peux vérifier que la CLI a bien été installée en exécutant cette commande dans un terminal :

```bash
dotnet --version
```

Si la sortie est une version supérieure ou égale à `9.0.100`, le SDK .NET a bien été installé.

## Utilise un IDE

Si tu veux une expérience d'édition plus complète, tu voudras probablement utiliser un [IDE ou environnement de développement intégré)](https://en.wikipedia.org/wiki/Integrated_development_environment).
Voici les IDE les plus populaires qui prennent en charge la construction de projets .NET :

- [Visual Studio 2022](https://www.visualstudio.com/downloads/)
- [Visual Studio Code](https://code.visualstudio.com/download) avec l'[extension C#](https://marketplace.visualstudio.com/items?itemName=ms-dotnettools.csharp)
- [Visual Studio for Mac](https://www.visualstudio.com/vs/visual-studio-mac/)
- [Project Rider](https://www.jetbrains.com/rider/download/)

Remarque : comme le format de projet .NET diffère sensiblement des versions précédentes, les IDE plus anciens (comme Visual Studio 2015) ne sont pas pris en charge.
