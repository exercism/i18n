# Ajout aux instructions

## Avantages et inconvénients de `from_quote`

La fonction `DateOfBirth.from_quote` analyse une chaîne de caractères au format `"YYYY-MM-DD"` et la transforme en `DateOfBirth`. Cela permet d'écrire du code comme ceci :

```roc
birthdate : DateOfBirth
birthdate = "2019-01-20"
```

Ce code appelle implicitement `DateOfBirth.from_quote("2019-01-20")` à la compilation. Cela peut potentiellement accélérer le programme, puisqu'il n'a pas besoin de gérer l'analyse à l'exécution, et cela garantit que les dates rejetées par `from_quote` sont détectées à la compilation plutôt qu'à l'exécution. De plus, cela rend le code agréable et lisible. Par exemple, voici l'un des tests de cet exercice :

```roc
# multiple birthdates with one shared birthday
expect {
	shared_birthday(["1966-07-29", "1977-02-12", "2001-07-29", "1980-11-10"])
}
```

Cependant, une personne qui lit ce code pourrait penser que la fonction `shared_birthday` prend une `List(Str)`, alors qu'en réalité elle prend une `List(DateOfBirth)`. Cela peut prêter à confusion et provoquer des erreurs. Pour cette raison, tu préféreras peut-être la syntaxe un peu plus longue mais plus explicite : `"2019-01-20".DateOfBirth`, qui appelle aussi `from_quote` à la compilation.

Dans tes propres programmes, tu préféreras peut-être fournir un constructeur pratique, comme celui-ci :

```roc
DateOfBirth := { year : I64, month : U8, day : U8 }.{
    from_ymd : I64, U8, U8 -> Try(DateOfBirth, [InvalidMonth, InvalidDay])
    from_ymd = |year, month, day| ...
}
```

Tu peux aussi appeler ce constructeur à la compilation, comme ceci :

```roc
Ok(birthdate) = DateOfBirth.from_ymd(2019, 1, 20)
```

Remarque : placer cette définition au niveau supérieur la fait s'exécuter à la compilation (la fonction étant pure et les entrées connues à la compilation). À l'intérieur d'une fonction, tu peux utiliser le même constructeur à l'exécution.

## La bibliothèque random

Le paquet [`roc-random`](https://github.com/kili-ilo/roc-random) est disponible sous l'alias `random` dans l'application de test. Le squelette importe `random.Random`.

## Indices

<details>
<summary>Afficher les indices</summary>

Un `Random.Generator(a)` décrit comment générer une valeur de type `a`. Utilise `Random.list` pour combiner les tirages et `Random.map` pour transformer leurs résultats. `Random.step(state, generator)` renvoie `{ value, state }` ; transporte l'état mis à jour d'un groupe simulé à l'autre pour ne pas répéter le même échantillon.
