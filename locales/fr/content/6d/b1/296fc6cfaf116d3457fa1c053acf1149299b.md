# Introduction

Comme beaucoup d'autres langages, le C++ dispose de _pointeurs_.
Tu sais déjà que les _références_ et les _pointeurs_ se ressemblent, mais vois-les comme un niveau plus proche du fonctionnement interne de ton ordinateur.
Les _pointeurs_ sont des variables qui contiennent l'adresse d'un objet.
On les utilise pour interagir directement avec les objets, ce qui permet l'allocation dynamique de mémoire et une manipulation efficace des données en C++.

Si tu découvres les _pointeurs_, ils peuvent sembler un peu mystérieux, mais une fois que tu t'y es habitué, ils sont assez simples.

Ils sont une partie cruciale du C++, alors prends le temps de bien les comprendre.
La version basique de ce concept est aussi appelée _pointeur idiot_ ou _pointeur brut_.
Avec le C++ moderne, il existe aussi des _pointeurs intelligents_ ; le type de base n'a rien d'intelligent et tu dois gérer tout le travail manuellement.

Avant d'entrer dans les détails, il vaut la peine de comprendre à quoi servent les _pointeurs_.
Les _pointeurs_ permettent de partager l'adresse d'un objet avec d'autres parties de notre programme, ce qui est utile pour deux raisons principales :

1. Comme les _références_, les pointeurs évitent les copies et aident à réduire l'empreinte en ressources de ton programme.
1. Contrairement aux _références_, les pointeurs peuvent être réaffectés à d'autres objets.
1. Les pointeurs peuvent aussi pointer vers une valeur nulle, pour indiquer qu'ils ne pointent actuellement vers aucun objet.

## Syntaxe générale

La déclaration d'un pointeur en C++ consiste à préciser le type de données vers lequel le pointeur pointe, suivi d'un astérisque (`*`) et du nom du pointeur.
Lorsqu'on déclare un pointeur, il n'est pas initialisé automatiquement.
Sans affectation explicite, un pointeur contient généralement une valeur indéterminée, souvent appelée «\u00A0adresse parasite\u00A0».
Bien que certains compilateurs initialisent les pointeurs à `nullptr`, ce comportement n'est pas garanti d'un compilateur à l'autre, il est donc essentiel de ne pas compter dessus.
La bonne pratique consiste à initialiser explicitement les pointeurs bruts et à vérifier qu'ils ne sont pas nuls avant de les utiliser, afin d'éviter d'éventuels problèmes.

```cpp
int* ptr{nullptr}; // Declares a pointer and makes sure it is not invalid
```

Pour affecter l'adresse d'une variable à un pointeur, on utilise l'opérateur d'adresse (`&`).
Le déréférencement d'un pointeur se fait à l'aide de l'_opérateur d'indirection_ (`*`).

```cpp
std::string opponent{"Solomon Lane"};
// 'ethan' points to the address of the string opponent
std::string* ethan{&opponent};
// Instead of ethan's, the opponent's name address is given to the passPort
std::string passportName{*ethan};
```

Attention : le déréférencement doit se faire explicitement, alors qu'une _référence_ fonctionne simplement comme un alias.

## Arithmétique des pointeurs

L'_arithmétique des pointeurs_ permet d'effectuer des opérations arithmétiques sur des pointeurs, ce qui est particulièrement utile lorsqu'on travaille avec des tableaux.
Ajouter un entier à un pointeur le fait pointer vers un autre élément.

```cpp
// Stargate Coordinate Code
int gateCode[] = {462, 753, 218, 611, 977};
// 'ptr' points to the first element of 'gateCode'
int* ptr{&gateCode[0]};
// Accesses the third Stargate address through pointer arithmetic
int dialedAddress{*(ptr + 2)};
// Chevron encoded! Dialing Stargate address:
openStarGate(dialedAddress);
```

~~~~exercism/caution
L'arithmétique des pointeurs en C++ peut facilement mener à un __comportement indéfini__ si elle n'est pas manipulée avec précaution.
Un comportement indéfini peut se manifester par des résultats inattendus, des plantages, voire des failles de sécurité.
Un exemple tristement célèbre des conséquences d'un comportement indéfini est l'[explosion de la fusée Ariane 5][ariane-flight-v88] en 1996, où une exception logicielle provoquée par la conversion d'un nombre à virgule flottante de 64 bits en un entier signé de 16 bits a entraîné une défaillance catastrophique.

[ariane-flight-v88]: https://en.wikipedia.org/wiki/Ariane_flight_V88
~~~~

## Accède aux variables membres

En C++, l'opérateur `->` sert à accéder aux membres d'un objet à travers un pointeur vers cet objet.
C'est une notation abrégée qui simplifie l'accès aux membres des objets pointés par des pointeurs.
Par exemple, si `ptr` est un pointeur vers un objet qui possède une variable membre `x`, au lieu d'écrire `(*ptr).x`, tu peux directement écrire `ptr->x`.
Cet opérateur améliore la lisibilité du code et réduit la verbosité lorsqu'on travaille avec des pointeurs vers des objets.

Voici un petit exemple, avec une _struct_ `Superhero` qui possède une variable membre `superpower`.
La fonction `main` crée un pointeur `dianaPrince` vers un objet `Superhero` (qui représente Wonder Woman).
L'opérateur `->` sert à accéder à la variable membre `superpower`, ce qui met en valeur le légendaire «\u00A0Lasso of Truth\u00A0» de Wonder Woman.

```cpp
struct Superhero {
    std::string superpower;
};
Superhero wonder_woman{};
Superhero* dianaPrince = &wonder_woman;
dianaPrince->superpower = "Lasso of Truth";
// Using the -> operator to access member variable superpower:
std::cout << "Wonder Woman, possesses the mighty " << dianaPrince->superpower;
// Memory cleanup:
delete dianaPrince;
```

## Pointeurs et références

Les pointeurs comme les références permettent un accès indirect aux objets, mais ils diffèrent par leurs capacités et leurs considérations de sécurité.
Les pointeurs offrent la souplesse de changer l'objet visé et peuvent recevoir la valeur nulle.
Cependant, cette souplesse introduit des risques, comme déréférencer un pointeur nul ou créer des pointeurs suspendus.
Les références, quant à elles, ne peuvent pas être nulles et sont liées à des objets valides dès leur création, ce qui évite ces risques.
Comme elles sont plus sûres, il faut préférer les références aux pointeurs, sauf si les fonctionnalités supplémentaires offertes par les pointeurs sont nécessaires.
