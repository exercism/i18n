# Installation

Sur ce parcours, les solutions sont écrites en assembleur RISC-V 32 bits et s'exécutent sous émulation, donc aucun matériel RISC-V n'est nécessaire.
Chaque exercice est fourni avec un Makefile qui compile les tests et les exécute.
Pour l'utiliser, il te faut trois outils :

- [Zig][zig], qui fournit l'assembleur RISC-V, le compilateur C et l'éditeur de liens via `zig cc`.
- [Make][make], qui lance la compilation.
- `qemu-riscv32` de [QEMU][qemu], qui exécute le programme produit.

## macOS

Lance une machine virtuelle Linux avec la solution de virtualisation de ton choix (par exemple [Lima][lima]), puis suis la section consacrée à ta distribution Linux ci-dessous.

## Windows

Utilise [Windows Subsystem for Linux][wsl], puis suis la section consacrée à ta distribution Linux ci-dessous.
Sinon, tu peux aussi installer une machine virtuelle Linux.

## Debian / Ubuntu

Installe Make et les émulateurs en mode utilisateur de QEMU :

```shell
sudo apt install make qemu-user
```

Installe ensuite Zig 0.15.2 ou une version plus récente, comme expliqué dans la section [Téléchargement direct][zig-install].

## Fedora

Installe les trois outils avec :

```shell
sudo dnf install zig make qemu-user
```

## Arch Linux

Installe les trois outils avec :

```shell
sudo pacman -S zig make qemu-user
```

## openSUSE Tumbleweed

Installe les trois outils avec :

```shell
sudo zypper install zig make qemu-linux-user
```

## Vérifie ton installation

Vérifie que les trois outils sont bien trouvés :

```shell
zig version
make --version
qemu-riscv32 --version
```

Télécharge ensuite un exercice avec l'Exercism CLI et lance ses tests :

```shell
exercism download --track=risc-v --exercise=hello-world
cd ~/exercism/risc-v/hello-world/
make
```
