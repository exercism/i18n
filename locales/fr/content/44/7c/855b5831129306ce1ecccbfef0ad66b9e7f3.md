# À propos

En Clojure, une `string` est une _string_ Java, c'est-à-dire un objet qui représente du texte immuable sous la forme d'une séquence de caractères Unicode (lettres, chiffres, ponctuation, etc.) et qui se définit comme suit :

```clojure
(def fruit "Apple")
```

La bibliothèque `clojure.string` fournit de nombreuses fonctions standard pour manipuler et traiter les _strings_. En outre, toutes les méthodes Java habituelles pour travailler avec les _strings_ sont accessibles via l'interopérabilité.
