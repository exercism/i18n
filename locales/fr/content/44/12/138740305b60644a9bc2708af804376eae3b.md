# Introduction

Pour créer une instance d'une classe, on appelle son [_constructeur_][constructor] via l'opérateur `new`. Un constructeur est une méthode spéciale au sein d'une classe, dont le but est d'initialiser cette classe. En Haxe, la méthode constructeur porte le nom de `new()`.

```haxe
class Library {
  private var books:Int;

  public function new() {
    this.books = 10; // Initialize the books field
  }
}

var library = new Library(); // This calls the constructor
```

Comme les méthodes normales, les constructeurs peuvent prendre des paramètres. Ces paramètres sont (en général) stockés dans des champs privés, puis utilisés plus tard.

```haxe
class Building {
  private var numberOfStories:Int;
  private var totalHeight: Float;

  public function new(numberOfStories:Int, storyHeight:Float) {
    this.numberOfStories = numberOfStories;
    this.totalHeight = storyHeight * numberOfStories;
  }
}

var largeBuilding = new Building(55, 6.2);
```

Tu **ne peux pas** créer une nouvelle instance d'une classe si celle-ci n'a pas de constructeur. La seule solution est donc d'utiliser un constructeur vide.

```haxe
class Car {
  public var weight:Int = 1000;

  public function new() {}
}

var myCar = new Car();
```
