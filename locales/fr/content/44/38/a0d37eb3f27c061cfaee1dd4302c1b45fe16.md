# À propos

Les arguments d'une fonction peuvent être définis de telle sorte qu'elle puisse prendre un nombre quelconque d'arguments :

```php
<?php

function actOnItems(...$items) {
  // $items is an array containing 0 or more values
  // used to call the function.
}

actOnItems(1, 2, 3, 4); // $items => [1, 2, 3, 4]
```

Si l'on définit un argument de longueur variable en plus des autres, il doit être le dernier argument.

```php
<?php

function writeLines($file_handle, ...$lines)
{
    put_file_contents($file_handle, implode("\n", $lines));
}

writeLines('file.txt', "a", "b", "c");
```
