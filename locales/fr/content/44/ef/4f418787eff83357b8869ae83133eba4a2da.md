# À propos

Un `vector` en Clojure est une collection séquentielle, indexée et immuable de zéro ou plusieurs valeurs. Autrement dit, une fois qu'un vector a été créé, on ne peut plus le modifier. Les fonctions qui manipulent les vectors renvoient un nouveau vector, tandis que le vector d'origine reste inchangé. Les valeurs d'un vector peuvent être de types hétérogènes. On peut définir des vectors comme ceci :

```clojure
(def empty [])
(def single-value [5])
(def single-value-alternative (vector 5))
(def three-values [1 "a" "b"])
```

On peut récupérer les éléments d'un vector à l'aide d'un indice. Les vectors de Clojure sont indexés à partir de zéro, ce qui signifie que l'indice du premier élément est toujours zéro :

```clojure
(def numbers [2 3 5])
;; Read value from vector
(get numbers 2)
;;=> 5
;; Update value in vector
(assoc numbers 2 9)
;;=> [2 3 9]
```

Le vector d'origine reste inchangé :

```clojure
numbers
;;=> [2 3 5]
```

Pour conserver la valeur mise à jour, il faut la transmettre ou la capturer dans une var :

```clojure
(def updated-numbers
  (assoc numbers 2 9))
(get updated-numbers 2)
;;=> 9
```
