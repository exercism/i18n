# À propos

Les classes sont une brique de base essentielle de la programmation Swift. Elles offrent un moyen de regrouper des données et des fonctions liées dans des unités de fonctionnalité autonomes.

### Définir des classes

Pour définir une classe, commence par le mot-clé `class` suivi du nom du type que l'on définit, puis vient le corps de la classe, placé entre accolades.

Le corps peut être constitué de propriétés stockées, qui se définissent et se comportent exactement comme des constantes ou des variables ordinaires.

```swift
class GameCharacter {
  var characterClass: String?
  var name: String?
  var active = false
  let id = makeRandomID()
}
```

### Les instances

Comme indiqué plus haut, définir une classe revient simplement à définir un nouveau _type_. Ce n'est qu'un plan de ce à quoi ressembleront les valeurs de ce type, mais cela ne crée en réalité aucune valeur de ce type avec laquelle travailler.

Pour créer une _instance_ de ce type, tu dois écrire le nom du type suivi de parenthèses.

```swift
let someCharacter = GameCharacter()
```

Cela crée des valeurs de ces types, dont les propriétés sont remplies avec les valeurs par défaut fournies dans la définition. Note que dans les cas optionnels comme la propriété `name` de GameCharacter, sauf si une valeur est fournie, la propriété vaudra nil par défaut, exactement comme lorsqu'on définit des types optionnels ordinaires sans fournir immédiatement de valeur.

### Accéder aux propriétés

On peut accéder aux propriétés d'une classe à l'aide de la _notation par points_, où le nom de la valeur est suivi d'un point (`.`) puis du nom de la propriété. Si une propriété d'une classe possède elle-même des propriétés, cette notation par points permet aussi d'accéder à ces propriétés imbriquées.

Cette notation permet à la fois de récupérer la valeur de la propriété et, quand c'est autorisé, de la modifier.

```swift
someCharacter.name
// => nil
someCharacter.name = "Luther"
someCharacter.name
// => "Luther"

someCharacter.id  = "new id"
// Error: Cannot assign to property: 'id' is a 'let' constant
```

### Les méthodes

Tout comme les propriétés, qui stockent des données dans tes classes, tu peux aussi définir des _méthodes_, qui stockent des fonctions dans ta classe.

Les méthodes se définissent de la même manière qu'une fonction ordinaire, mais à l'intérieur du corps de la classe. De plus, si une méthode peut modifier une propriété, cette propriété doit être définie avec `var` plutôt qu'avec `let`, exactement comme pour les variables ordinaires.

```swift

class GameCharacter {
  var characterClass: String?
  var name: String?
  var active = false
  let id: String = makeRandomID()

  func takesDamage(_ damage: Double) {
    if damage > 100 {
      active = false
    }
  }
  func sayName() -> String {
    return "My name is \(name ?? "no one"), my class is \(characterClass ?? "undetermined")"
  }
}
```

Ces méthodes s'appellent à l'aide de la notation par points, exactement comme les propriétés.

```swift
var myChar = GameCharacter()
myChar.active = true
myChar.takesDamage(200)
myChar.active
// => false
```

### Self

Les instances de classes possèdent chacune une valeur implicite nommée `self` qui désigne l'instance elle-même. `self` a plusieurs usages, mais on l'utilise le plus souvent pour lever l'ambiguïté sur les noms des propriétés et des méthodes de la structure ou de la classe lorsqu'il risque d'y avoir une confusion.
