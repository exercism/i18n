# Installation

Consulte [System/Installation][install-link] pour savoir comment mettre en place les choses sur ton système.

~~~exercism/caution
Si tu as installé le Java Development Kit (JDK), l'exécutable `jconsole` pourrait entrer en conflit avec Java Console, qui porte le même nom.

Voici quelques pistes de solution :

- Renomme l'exécutable `jconsole` du langage de programmation J pour lui donner un nom unique (par exemple `jconsole-jlang`).

- Modifie les variables d'environnement de ton système ou le PATH afin de donner la priorité au `jconsole` du langage de programmation J.

- **Pour les utilisateurs de Linux**, il existe un script bash situé dans `bin/install.sh` qui crée un **lien symbolique** nommé `ijconsole` dans le répertoire `/usr/`. Tu peux utiliser ce lien en tapant `ijconsole` dans ton terminal.
~~~

Une fois J installé, ouvre une console J dans ton terminal et saisis les commandes suivantes pour installer le _framework_ de tests unitaires :

```j
  load 'pacman'
  'update' jpkg ''
  'install' jpkg 'general/unittest'
  exit 0
```
