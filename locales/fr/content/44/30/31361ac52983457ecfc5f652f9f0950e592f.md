# À propos

La capacité d'une chose à se définir en termes de soi-même s'appelle la récursion. En Gleam, on rencontre le plus souvent la récursion dans les fonctions récursives, c'est-à-dire des fonctions qui s'appellent elles-mêmes.

Une fonction récursive doit avoir au moins un _cas de base_ et au moins un _cas récursif_. Un _cas de base_ renvoie une valeur sans rappeler la fonction. Un _cas récursif_ rappelle la fonction en modifiant l'entrée, pour qu'elle finisse par correspondre au cas de base.

```gleam
pub fn factorial(x: Int) -> Int {
  case x {
    // Base case
    1 -> 1

    // Recursive case
    _ -> x * factorial(x - 1)
  }
}
```

Gleam n'a pas de syntaxe dédiée aux boucles : toutes les boucles s'écrivent avec la récursion.

```gleam
pub fn list_length(list: List(String)) -> Int {
  case list {
    [] -> 0
    [_, ..rest] -> 1 + list_length(rest)
  }
}
```

Gleam prend également en charge les _custom types_ récursifs. Un _custom type_ récursif a une ou plusieurs de ses variantes qui se réfèrent à ce type dans les données qu'elles contiennent.

```gleam
pub type RussianDoll {
  Child               // Base case
  Mother(RussianDoll) // Recursive case
}
```
```gleam
let very_big_doll = Mother(Mother(Mother(Child)))
let small_doll = Mother(Child)
```
