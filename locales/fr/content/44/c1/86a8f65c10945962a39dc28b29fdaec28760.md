# Introduction

En Go, les booléens sont représentés par le type booléen prédéclaré `bool`, dont les valeurs peuvent être soit `true`, soit `false`.
C'est un type défini.

```go
var closed bool    // boolean variable 'closed' implicitly initialized with 'false'
speeding := true   // boolean variable 'speeding' initialized with 'true'
hasError := false  // boolean variable 'hasError' initialized with 'false' 
```

Go prend en charge trois opérateurs logiques, qui évaluent des expressions en valeurs booléennes et renvoient soit `true`, soit `false`.

| Opérateur   | Ce que cela signifie                          |
| ----------- | --------------------------------------------- |
| `&&` (et)   | L'expression est vraie si les deux assertions sont vraies. |
| `\|\|` (ou) | L'expression est vraie si au moins une assertion est vraie. |
| `!` (pas)   | L'expression est vraie seulement si l'assertion est fausse. |
