# Complément aux instructions

## Format de sortie

Produis les plantes de l'apprenant sous la forme d'une _string_ terminée par un caractère nul, en utilisant une virgule et un espace comme séparateurs.

## Registres

| Registre | Utilisation   | Type       | Description                                   |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | entrée        | adresse | diagramme du jardin                            |
| `$a1`    | entrée        | adresse | nom de l'apprenant                             |
| `$a2`    | entrée/sortie | adresse | _string_ de sortie terminée par un caractère nul |
| `$t0-9`  | temporaire    | quelconque | utilisé pour le stockage temporaire         |
