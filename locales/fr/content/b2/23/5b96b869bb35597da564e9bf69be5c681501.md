# Instructions complémentaires

## Instructions spécifiques au parcours

Cet exercice porte sur l'ajout de méthodes à la structure `Array` en Swift.
Le plus simple est de passer par des [extensions][extensions].

```swift
extension Array {
  // Write your code for the 'Strain' exercise in this file.
}
```

La documentation de `Array` se trouve [ici][array].

[array]: https://developer.apple.com/documentation/swift/array
[extensions]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/extensions/
