# Instructions supplémentaires

Chaque ligne de la grille est représentée par un mot.

Par exemple,

```
    0 1 0
    1 0 0
    1 1 0
```

est représenté par

```
0x2
0x4
0x6
```

La grille comporte au plus 32 colonnes.

## Registres

| Registre | Usage         | Type    | Description                          |
| -------- | ------------- | ------- | ------------------------------------ |
| `$a0`    | entrée        | entier  | nombre de lignes                     |
| `$a1`    | entrée        | entier  | nombre de colonnes                   |
| `$a2`    | entrée        | adresse | grille pour la génération courante   |
| `$a3`    | entrée/sortie | adresse | grille pour la génération suivante   |
| `$t0-9`  | temporaire    | quelconque | utilisé pour le stockage temporaire |
