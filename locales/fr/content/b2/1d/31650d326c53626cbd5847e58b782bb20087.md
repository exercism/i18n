# Instructions

Tu travailles dans une usine, et le besoin se fait sentir de créer le message imprimé sur les badges des employés. Tu décides d'implémenter cette fonction en JavaScript.

Un badge nécessite l'`id` de l'employé, le `name` de l'employé, ainsi que le service dans lequel il travaille.

## 1. Crée le texte du badge

Implémente une fonction nommée `printBadge` qui renvoie le texte à imprimer sur le badge.

Le nom de l'employé est toujours fourni, mais le numéro `id` de l'employé et le nom du service peuvent être `null`. Le numéro `id` de l'employé, s'il est fourni, doit être placé entre crochets (par exemple `[20]`).

Le badge d'un propriétaire ne doit comporter ni `id` ni `department`.

```javascript
printBadge(20, 'Bob', 'Marketing');
// => '[20] Bob - MARKETING'
```
