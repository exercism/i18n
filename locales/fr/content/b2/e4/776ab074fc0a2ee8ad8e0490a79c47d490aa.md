# Introduction

L'_opérateur ternaire_ est une alternative légère et compacte aux instructions _if/else_ simples.
Il s'utilise généralement dans les instructions de retour (mais pas uniquement) et tient sur une seule ligne pour prendre la décision : il renvoie la valeur de gauche si l'expression est `true`, et celle de droite si elle est `false`, comme ceci :

```java
boolean expr = 0 != 200;

// Ternary statement
int value = expr ? 22 : 33;
// => 22
```

Bon nombre d'expressions _if/else_ simples peuvent être simplifiées à l'aide de l'_opérateur ternaire_.
