# Instructions


Tu es le maître d'hôtel d'un restaurant d'hôtel.
Ta tâche consiste à gérer le placement des clients dans la salle en fonction du nombre de places disponibles aujourd'hui, du nombre de réservations et des clients venus sans réservation qui attendent d'être installés.
Pour les besoins de cet exercice, les places sont attribuées en prenant la première place libre.


Pour cet exercice, tu as 6 défis d'organisation de la salle à relever.


## 1. Crée le plan de salle du jour

Définis la fonction `new_seating_chart(<size=22>)` qui prend un argument `size` représentant le nombre de places qui seront installées dans la salle aujourd'hui.
Si aucun argument `size` n'est fourni, la fonction doit renvoyer un plan de salle de 22 places.
Les places doivent avoir `None` comme valeur temporaire pour indiquer qu'elles sont libres et peuvent être attribuées à un client.


## 2. Place les réservations

Définis la fonction `arrange_reservations(<guest_names>)` avec 1 paramètre, une liste de noms de clients.
Il représente le nombre de personnes qui ont réservé une place dans la salle aujourd'hui.


Cette fonction doit renvoyer un plan de salle de type `dict` à la taille par défaut (22 places), les clients étant attribués aux places dans l'ordre où ils apparaissent dans la liste des réservations.
Toutes les places non attribuées doivent être à `None`.
S'il n'y a aucun client, il faut renvoyer un plan de salle « vide » où toutes les valeurs sont `None`.


```python
>>> arrange_reservations(guests=["Walter", "Frank", "Jenny", "Carol", "Alice", "George"])
...
{1: 'Walter', 2: 'Frank', 3: 'Jenny', 4: 'Carol', 5: 'Alice', 6: 'George', 7: None, 8: None, 9: None, 10: None, 11: None, 12: None, 13: None, 14: None, 15: None, 16: None, 17: None, 18: None, 19: None, 20: None, 21: None, 22: None}
```


## 3. Trouve toutes les places « vides »

Définis la fonction `find_all_available_seats(<seats>)` qui prend 1 paramètre (_un dictionnaire représentant le plan de salle_) et renvoie une `list` des numéros de places disponibles pour les clients qui attendent actuellement.
Si une place est vide, sa valeur dans le dictionnaire sera `None`. Les places occupées contiennent le nom du client.


```python
>>> seats = {1: None, 2: 'Frank', 3: 'Jenny', 4: None, 5: 'Alice', 6: 'George', 7: None, 8: 'Carol', 9: None, 10: None, 11: None, 12: 'Walter'}

>>> find_all_available_seats(seats)
[1,4,7,9,10,11]
```

## 4. Capacité actuelle de places libres

Définis la fonction `current_empty_seat_capacity(<seats>)` qui prend 1 paramètre : le `dict` des réservations de places existantes.
La fonction doit renvoyer le nombre total de places libres.

```python
>>> curr_empty_seat_capacity({1: "Occupied", 2: None, 3: "Occupied"})
1

>>> curr_empty_seat_capacity({1: "Occupied", 2: None, 3: None})
2
```


## 5. Faut-il les faire patienter ?

Définis la fonction `accommodate_waiting_guests(<seats>, <guests>)` qui prend deux paramètres.
Le premier paramètre est un plan de salle, un `dict`.
Le second paramètre est une `list` de clients venus sans réservation, à l'improviste.
Tu dois d'abord déterminer combien de places sont disponibles et si tu peux accueillir ces clients imprévus pour le moment.

Si tu n'as pas assez de places, renvoie le plan de salle `dict` sans le modifier.

Si des places _sont_ disponibles, attribue des places à ces clients dans le plan de salle, puis renvoie le plan mis à jour.
**Astuce :** tu peux utiliser les fonctions définies précédemment pour faire les calculs à ta place.


```python
# Guests cannot be accommodated.
>>> starting_reservations = {1: 'Carol', 2: 'Alice', 3: 'George', 4: None, 5: None, 6: None, 7: 'Frank', 8: 'Walter'}
>>> accommodate_guests(starting_reservations, ["Mort", "Suze", "Phillip", "Tony"])
...
{1: 'Carol', 2: 'Alice', 3: 'George', 4: None, 5: None, 6: None, 7: 'Frank', 8: 'Walter'}


# Guests can be accommodated.
>>> starting_reservations = {1: None, 2: None, 3: None, 4: 'Carol', 5: 'Alice', 6: 'George', 7: None, 8: None, 9: None, 10: None, 11: None, 12: None, 13: None, 14: None, 15: None, 16: None, 17: None, 18: 'Frank', 19:  'Jenny', 20: None, 21: None, 22: 'Walter'}
>>> accommodate_guests(starting_reservations, ["Mort", "Suze", "Phillip", "Tony"])
...
{1: 'Mort', 2: 'Suze', 3: 'Phillip', 4: 'Carol', 5: 'Alice', 6: 'George', 7: 'Tony', 8: None, 9: None, 10: None, 11: None, 12: None, 13: None, 14: None, 15: None, 16: None, 17: None, 18: 'Frank', 19: 'Jenny', 20: None, 21: None, 22: 'Walter'}
```

## 6. Libère des places

Définis la fonction `empty_seats(<seats>, <seat_numbers>)` qui prend deux paramètres.
Le premier paramètre est un plan de salle sous forme de dictionnaire.
Le second paramètre est une liste de numéros de places que tu dois « libérer », c'est-à-dire vider : tu dois attribuer la valeur `None` à ces numéros de places.

Renvoie le `dict` des places après avoir mis à jour les valeurs des places à vider.

```python
>>> empty_seats(seats={1: "Alice", 2: None, 3: "Bob", 4: "George", 5: "Gloria"}, seat_numbers=[5,3,1])
{1: None, 2: None, 3: None, 4: "George", 5: None}
```
