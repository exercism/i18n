# Hints

## 1. Crée un nouveau visiteur

- Reviens sur le [concept « Objets »][concept-objects] pour découvrir comment créer un objet avec certaines clés et valeurs.

## 2. Révoque le ticket

- Utilise l'opérateur d'affectation `=` pour affecter `null` à la propriété `ticketId` de l'objet visiteur.
- Renvoie ensuite l'objet visiteur.

## 3. Détermine le statut du ticket

- Reviens sur le [concept « Conditionnels »][concept-conditionals] pour découvrir comment renvoyer différentes valeurs depuis la fonction selon les conditions.
- Utilise la notation entre crochets pour accéder à la valeur du `ticketId` donné dans l'objet.
- Utilise l'opérateur d'égalité stricte `===` pour vérifier si la valeur vaut `null` ou `undefined`.

## 4. Améliore la réponse du statut du ticket

- Récupère la valeur d'un `ticketId` donné avec la notation entre crochets, comme dans la tâche précédente.
- Aucune instruction `if` n'est nécessaire pour résoudre cette tâche.
- Utilise plutôt l'[opérateur de coalescence des nuls][mdn-nullish-coalescing] `??`.

## 5. Détermine la version des conditions générales

- Reviens sur le [concept « Objets »][concept-objects] pour voir comment accéder à des valeurs imbriquées, et commence par écrire l'expression qui permet de récupérer la version.
- Utilise ensuite l'opérateur de [chaînage optionnel][mdn-optional-chaining] pour gérer le cas où l'objet gtc est absent.
- Aucune instruction `if` n'est nécessaire pour résoudre cette tâche.
