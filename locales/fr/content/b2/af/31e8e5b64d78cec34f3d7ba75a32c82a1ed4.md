# Instructions

Dans cet exercice, tu vas analyser des numéros de téléphone.

Tu dois implémenter 2 fonctionnalités.

Les numéros de téléphone transmis aux routines sont garantis être de la forme
NNN-NNN-NNNN, par exemple 212-515-9876, et ne jamais être nuls.

## 1. Analyse un numéro de téléphone

Ton analyse doit renvoyer 3 informations :

1. Une indication précisant si le numéro possède un indicatif téléphonique de New York, c'est-à-dire 212 comme 3 premiers chiffres
2. Une indication précisant si le numéro est factice, avec 555 comme préfixe aux positions 5 à 7 (en numérotant à partir de 1)
3. Les 4 derniers chiffres du numéro.

Implémente la méthode (statique) `PhoneNumber.Analyze()` pour produire les informations sur le numéro de téléphone.

```csharp
PhoneNumber.Analyze("631-555-1234");
// => (false, true, "1234")
```

## 2. Détecte si un numéro de téléphone a un préfixe factice (555)

Implémente la méthode (statique) `PhoneNumber.IsFake()` pour détecter si le numéro de téléphone est factice, en utilisant les informations produites dans la tâche 1.

```csharp
PhoneNumber.IsFake(PhoneNumbers.Analyze("631-555-1234"));
// => true
```
