# Introduction

Le concept Pairs and Dicts a présenté les bases du type dictionnaire de Julia.

Comme les `Dict` sont un type de collection important et très utilisé, il existe aussi de nombreuses fonctions pour les manipuler.

## Récupère les entrées

La façon la plus simple de récupérer une entrée est de passer par sa clé (comme dans beaucoup de langages).
Cependant, demander une clé qui n'existe pas déclenche une `KeyError`.

```julia-repl
julia> d = Dict(i => ('a':'c')[i] for i in 1:3)
Dict{Int64, Char} with 3 entries:
  2 => 'b'
  3 => 'c'
  1 => 'a'
julia> d[2]
'b': ASCII/Unicode U+0062 (category Ll: Letter, lowercase)
# missing key
julia> d[4]
ERROR: KeyError: key 4 not found
```

On pourrait vérifier la présence de la clé avant d'essayer de la récupérer (avec quelque chose comme `haskey(d, 4)`), mais il peut être utile d'obtenir directement une valeur par défaut pour les clés absentes.

Pour cela, on dispose de la fonction `get()` et de sa variante mutante `get!()`.
La différence entre les deux tient au fait d'ajouter ou non la clé « manquante » au `Dict`.

```julia-repl
julia> get(d, 4, '!')
'!': ASCII/Unicode U+0021 (category Po: Punctuation, other)
# get() leaves Dict unchanged
julia> d
Dict{Int64, Char} with 3 entries:
  2 => 'b'
  3 => 'c'
  1 => 'a'
julia> get!(d, 4, '!')
'!': ASCII/Unicode U+0021 (category Po: Punctuation, other)
# get!() adds new key to Dict
julia> d
Dict{Int64, Char} with 4 entries:
  4 => '!'
  2 => 'b'
  3 => 'c'
  1 => 'a'
```

On a vu dans le concept précédent que `delete!()` supprime une entrée par sa clé.
On peut combiner cela avec la récupération de la valeur, grâce à la fonction `pop!()`.

```julia-repl
julia> d
Dict{Int64, Char} with 4 entries:
  4 => '!'
  2 => 'b'
  3 => 'c'
  1 => 'a'
# popped value is returned
julia> pop!(d, 3)
'c': ASCII/Unicode U+0063 (category Ll: Letter, lowercase)
# Dict is shrunk
julia> d
Dict{Int64, Char} with 3 entries:
  4 => '!'
  2 => 'b'
  1 => 'a'
```

## Itération

Quand on itère sur un `Dict`, on obtient par défaut des paires `key => value`.
On accède aux composants avec la nomenclature habituelle `.first` et `.second`.

```julia-repl
# d is from the previous example
julia> [(kv.first, kv.second) for kv in d]
3-element Vector{Tuple{Int64, Char}}:
 (4, '!')
 (2, 'b')
 (1, 'a')
```

Souvent, on veut utiliser seulement les clés ou seulement les valeurs, ce qui est facile.

```juliajulia> [k for k in keys(d)]
julia> [k for k in keys(d)]
3-element Vector{Int64}:
 4
 2
 1
julia> [v for v in values(d)]
3-element Vector{Char}:
 '!': ASCII/Unicode U+0021 (category Po: Punctuation, other)
 'b': ASCII/Unicode U+0062 (category Ll: Letter, lowercase)
 'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)
```

## Fusionne

Combiner deux `Dict` peut être utile, mais il faut être clair sur ce qu'on veut faire des clés présentes dans plusieurs dictionnaires en entrée.

Les fonctions `merge()` et `merge!()` combinent un nombre arbitraire de `Dict` fournis, de gauche à droite.

Les valeurs des clés existantes sont simplement écrasées, donc c'est le `Dict` le plus à droite qui « gagne ».

```julia-repl
julia> d3 = Dict("color" => "red", "shape" => "circle")
Dict{String, String} with 2 entries:
  "shape" => "circle"
  "color" => "red"
julia> d4 = Dict("color" => "blue", "coords" => (3, 2))
Dict{String, Any} with 2 entries:
  "color"  => "blue"
  "coords" => (3, 2)
# color from d3 is lost
julia> merge(d3, d4)
Dict{String, Any} with 3 entries:
  "shape"  => "circle"
  "color"  => "blue"
  "coords" => (3, 2)
```

Les fonctions `mergewith()` et `mergewith!()` permettent de fournir une fonction en premier argument, pour définir comment fusionner les clés répétées.
L'addition en est un exemple simple.

```julia-repl
julia> d5 = Dict("color" => "red", "area" => 3)
Dict{String, Any} with 2 entries:
  "area"  => 3
  "color" => "red"
julia> d6 = Dict("shape" => "circle", "area" => 5)
Dict{String, Any} with 2 entries:
  "shape" => "circle"
  "area"  => 5
# area values are added, not overwritten
julia> mergewith(+, d5, d6)
Dict{String, Any} with 3 entries:
  "shape" => "circle"
  "area"  => 8
  "color" => "red"
```

À noter que les fonctions `mergewith` sont un bon exemple de fonctions d'ordre supérieur en action.
