# Tests

Tous les exercices utilisent le framework [Pester][pester] pour la simulation et les tests.
Tous les tests se trouvent dans un fichier nommé `[Exercise].tests.ps1`, comme le veut la convention du framework Pester.
Si tu es dans le bon dossier (c'est-à-dire celui qui contient `[Exercise].ps1` et `[Exercise].tests.ps1`).
Tu peux exécuter les tests depuis PowerShell en appelant :

``` PowerShell
Invoke-Pester
```

Cela exécutera tous les fichiers `.tests.ps1` qu'il trouvera dans le dossier.

Si tu utilises un autre shell que PowerShell, tu peux exécuter les tests en appelant :

``` PowerShell
pwsh -Command "Invoke-Pester"
```

## Exécute les tests dans Visual Studio Code

Assure-toi d'avoir installé [l'extension PowerShell][extension] dans Visual Studio Code.

Tu peux exécuter les tests dans Visual Studio Code de plusieurs façons :

- En exécutant le script `.Tests.ps1` depuis le menu Debug. Les raccourcis clavier sont : `F5` ou `Shift + F5`
- Depuis l'éditeur, en cliquant sur le lien « Run Tests » au-dessus du mot-clé `Describe` dans le code du test lui-même
- En configurant une _Task_ pour exécuter le framework Pester

[pester]: https://github.com/pester/Pester
[extension]: https://marketplace.visualstudio.com/items?itemName=ms-vscode.PowerShell
