# Ajout aux instructions

## Indices

Pour terminer cet exercice, tu dois créer le type de données `School`
et implémenter les fonctions suivantes :

- `add`
- `empty`
- `grade`
- `sorted`

Tu trouveras une déclaration de données factice et des signatures de type déjà en
place, mais c'est à toi de définir les fonctions et de créer un type de données, un
newtype ou un synonyme de type qui soit pertinent.
