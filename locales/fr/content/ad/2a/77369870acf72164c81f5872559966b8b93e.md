# Introduction

## Alias de type

Un alias de type peut être utilisé en Gleam pour donner un nom pratique à un type existant qui serait autrement fastidieux à écrire.

```gleam
pub type Headers =
  List(#(String, String))

pub fn html_headers() -> Headers {
  [
    #("content-type", "text/html"),
    #("x-frame-options", "DENY"),
  ]
}
```

Lorsqu'il est écrit avec `pub type`, l'alias peut être utilisé en dehors du module où il est défini. Si `pub` est omis, l'alias est privé et ne peut pas être référencé dans d'autres modules.
