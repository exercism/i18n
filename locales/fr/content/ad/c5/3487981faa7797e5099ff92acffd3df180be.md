# Instructions

Ta tâche consiste à déterminer ce que tu diras au moment de donner le cookie en trop.

Si tu connais le nom de la personne (par exemple si elle s'appelle Do-yun), tu diras :

```text
One for Do-yun, one for me.
```

Si tu ne connais pas le nom de la personne, tu diras _you_ à la place.

```text
One for you, one for me.
```

Voici quelques exemples :

| Nom    | Dialogue                    |
| :----- | :-------------------------- |
| Alice  | One for Alice, one for me.  |
| Bohdan | One for Bohdan, one for me. |
|        | One for you, one for me.    |
| Zaphod | One for Zaphod, one for me. |
