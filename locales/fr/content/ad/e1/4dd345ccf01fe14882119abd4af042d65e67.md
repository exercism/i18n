# Exécute les tests

Choisis ton système d'exploitation :

- [Windows](#windows)
- [macOS](#macos)
- [Linux](#linux)

## Windows

1. Ouvre Command Prompt.
2. Récupère le premier exercice :

   ```batchfile
   C:\Users\JohnDoe>exercism download --exercise hello-world --track java
   ```

3. Déplace-toi dans le répertoire de l'exercice :

   ```batchfile
   C:\Users\JohnDoe>cd C:\Users\JohnDoe\exercism\java\hello-world
   ```

4. Exécute les tests :

   ```batchfile
   C:\Users\JohnDoe>gradlew.bat test
   ```

   _(Ne t'inquiète pas si les tests échouent au début, c'est ainsi que tu commences chaque exercice.)_

5. Résous l'exercice. Trouve le guide `instructions.append.md` et suis-le ([voir sur GitHub](https://github.com/exercism/java/blob/main/exercises/practice/hello-world/.docs/instructions.append.md#tutorial)).

Bonne chance ! Amuse-toi bien !

## macOS

1. Dans la fenêtre du terminal, récupère le premier exercice :

   ```sh
   exercism download --exercise hello-world --track java
   ```

2. Déplace-toi dans le répertoire de l'exercice :

   ```sh
   cd /Users/johndoe/exercism/java/hello-world
   ```

3. Exécute les tests :

   ```sh
   ./gradlew test
   ```

   _(Ne t'inquiète pas si les tests échouent au début, c'est ainsi que tu commences chaque exercice.)_

4. Résous l'exercice. Trouve le guide `instructions.append.md` et suis-le ([voir sur GitHub](https://github.com/exercism/java/blob/main/exercises/practice/hello-world/.docs/instructions.append.md#tutorial)).

Bonne chance ! Amuse-toi bien !
