# Introduction

## Structs

Les _structs_ sont une extension construite au-dessus des [_maps_][exercism-maps], qui apportent des vérifications à la compilation et des valeurs par défaut. Un _struct_ porte le nom du module dans lequel il est défini. Pour définir un _struct_, on utilise la construction `defstruct`. Celle-ci suit généralement immédiatement la définition du module. `defstruct` accepte soit une liste d'atomes (pour des valeurs par défaut à `nil`), soit une liste de mots-clés (pour des valeurs par défaut spécifiques). Les champs sans valeur par défaut doivent venir avant ceux qui en ont une.

```elixir
defmodule Plane do
  defstruct [:engine, wings: 2]
end

plane = %Plane{}
# => %Plane{engine: nil, wings: 2}
```

### Accède aux champs et mets-les à jour

Comme les _structs_ sont construits sur des _maps_, on peut utiliser la plupart des fonctions associées aux _maps_ pour obtenir et manipuler des valeurs. Le _comportement Access_ n'est **pas** implémenté pour les _structs_. Il est recommandé d'utiliser plutôt l'_opérateur d'accès statique_ `.` pour accéder aux champs d'un _struct_.

- obtenir/récupérer les valeurs des champs :

  ```elixir
  plane = %Plane{}
  plane.engine
  # => nil
  Map.fetch(plane, :wings)
  # => {:ok, 2}
  ```

- mettre à jour les valeurs des champs

  ```elixir
  plane = %Plane{}
  %{plane | wings: 4}
  # => %Plane{engine: nil, wings: 4}
  ```

### Filtrage par motif

Les _structs_ peuvent être utilisés en filtrage par motif, avec ou sans le nom du _struct_.

```elixir
plane = %Plane{}
%Plane{wings: wings} = plane
%{wings: wings} = plane
```

En incluant le nom du _struct_ dans le motif, on s'assure que le côté gauche et le côté droit sont bien des _structs_ du même type.

```elixir
defmodule Helicopter do
  defstruct [:engine, rotors: 1]
end

%Plane{} = %Helicopter{}
# => (MatchError) no match of right hand side value: %Helicopter{engine: nil, rotors: 1}
```

### Impose l'initialisation des valeurs des champs

On peut utiliser l'attribut de module `@enforce_keys` avec une liste des clés de champ pour s'assurer que les valeurs sont initialisées à la création du _struct_. Si une clé n'est pas listée, sa valeur sera `nil`, comme dans l'exemple ci-dessus. Si une clé soumise à `@enforce_keys` n'est pas initialisée, une erreur est levée.

```elixir
defmodule User do
  @enforce_keys [:username]
  defstruct [:username]
end

%User{}
# => (ArgumentError) the following keys must also be given when building struct User: [:username]
```
