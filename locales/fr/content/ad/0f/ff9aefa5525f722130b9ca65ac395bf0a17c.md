# Installation

## Ce qu'il faut

Les éléments de base nécessaires pour développer en Common Lisp sont :

- Une « implémentation » de Lisp, qui te permet de compiler et d'exécuter du code, et de disposer d'un REPL.
- Un éditeur de texte avec des fonctionnalités pour le code Lisp. 
- (Un plus) La référence souvent utilisée pour le langage Common Lisp, le [« Common Lisp Hyperspec »][hyperspec].

## Roswell

[Roswell][roswell] est une commande pour installer et gérer des implémentations de Common Lisp, avec de nombreuses fonctionnalités qui facilitent le développement et la distribution d'applications Lisp.
On l'utilise pour simplifier les étapes d'installation et de test.

### Installer Roswell

Consulte le [guide d'installation][ros-inst] et suis les instructions pour ta plateforme.
Pour la plupart des utilisateurs, ce qui suit suffira :

* Pour MacOS et Linux, [Homebrew][brew] rend la chose simple :
  ```sh
  brew install roswell
  ```
* Pour Windows, utilise [Scoop][scoop] :
  ```powershell
  scoop install roswell
  ```

La première fois que tu utilises Roswell, il va récupérer et installer SBCL et Quicklisp.
Il suffit de lancer ceci :
```sh
ros help
```

Lance le REPL avec
```sh
ros run
```

## Configurer ton éditeur de texte

Si tu débutes en Common Lisp, et surtout si tu as déjà l'habitude d'Emacs, tu peux démarrer rapidement et facilement en installant [Portacle, l'environnement Common Lisp portable][portacle]. 
Gratuit et complet, il fonctionne sur toutes les plateformes courantes et arrive préconfiguré « prêt à l'emploi ». Il fournit :

- Une implémentation de Lisp : SBCL, avec Quicklisp et ASDF.
- Un éditeur de texte : Emacs

... avec de nombreux modules complémentaires pour écrire du code Lisp : 
- SLIME, le « Superior Lisp Interaction Mode for Emacs », transforme Emacs en IDE Common Lisp
- ParEdit, qui simplifie le travail avec les parenthèses. 

Tout est déjà configuré et prêt à l'emploi. Pour installer Portacle, télécharge-le depuis la [page d'accueil][portacle].

Remarque : Emacs (l'éditeur de texte) peut dérouter au début si tu n'y es pas habitué. Heureusement, on trouve en ligne de nombreux guides d'introduction à Emacs et SLIME. 

## Démarrage traditionnel

Si tu préfères installer les outils nécessaires séparément, tu devras installer et configurer :

- un éditeur de texte compatible Lisp : [Emacs][emacs] avec le paquet [Slime][slime] ou [Sly][sly] est un choix courant, mais [VIM][vim] avec [SLIMV][slimv], [Atom][atom] avec [SLIMA][slima] ou [VSCode][vscode] avec une [extension Common Lisp][vscode-plugin] sont aussi de bons choix.
- une implémentation de Common Lisp : [SBCL][sbcl] est un choix « sûr » qui fonctionne sous Linux, MacOS et Windows. Comme le langage repose sur une norme, d'autres [implémentations conformes][awesome-cl-implementations] fonctionneront aussi.
- [Quicklisp][quicklisp] pour gérer les bibliothèques. Après l'avoir téléchargé, suis les [instructions][quicklisp-install] pour t'assurer qu'il est bien intégré à ton implémentation de Common Lisp.
