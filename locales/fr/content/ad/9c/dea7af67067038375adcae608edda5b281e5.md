# Introduction

Quand tu as besoin d'une séquence de `n` valeurs dont chacune dépend de
son indice, Factor te donne `<iota>`, une séquence virtuelle des
entiers `0, 1, …, n-1`, et `map` :

```factor
USING: math sequences ;

5 <iota> [ 2 * ] map .   ! => { 0 2 4 6 8 }
```

`<iota>` n'alloue pas les entiers à l'avance ; `map` les parcourt
dans l'ordre, en appliquant la _quotation_ à chacun.

Si le résultat de chaque position est un code de caractère, `>string`
transforme le résultat en _string_, la manière naturelle d'assembler
une ligne de caractères à partir de décisions guidées par l'indice :

```factor
USING: strings ;

5 <iota> [ CHAR: a + ] map >string .   ! => "abcde"
```

[strings]: https://docs.factorcode.org/content/article-strings.html
