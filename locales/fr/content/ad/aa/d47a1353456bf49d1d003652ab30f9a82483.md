# Prérequis

Le parcours D nécessite que les logiciels suivants soient installés sur ton système :

* un compilateur D version 2
* (facultatif mais recommandé) DUB

## Prérequis : compilateur D version 2

Sur le site du langage D, [dlang.org](https://dlang.org), tu peux télécharger et installer la version la plus récente du compilateur de référence DMD (Digital Mars D) pour plusieurs plateformes.
Consulte la [page officielle de téléchargement](https://dlang.org/download.html) pour plus d'informations.
Sous Windows, une autre solution consiste à [utiliser Chocolatey](https://chocolatey.org/packages/dmd).
Sur les Mac à processeur Intel, une autre solution consiste à [utiliser Homebrew](https://formulae.brew.sh/formula/dmd).

### Autres compilateurs
Outre le compilateur de référence DMD, qui utilise son propre backend, deux autres compilateurs peuvent être récupérés depuis la section de téléchargement de dlang.org :

* [GDC](http://gdcproject.org/downloads), qui utilise le backend GCC
* [LDC](https://github.com/ldc-developers/ldc#installation), basé sur le backend LLVM

GDC et LDC ne sont pas toujours alignés sur les versions les plus récentes du frontend de DMD, mais ils offrent de meilleurs niveaux d'optimisation ainsi que la prise en charge d'autres plateformes comme ARM.

Consulte le wiki pour [plus d'informations](https://wiki.dlang.org/Compilers).

### Prise en charge des IDE

Le langage D est également pris en charge dans divers IDE, par exemple [VisualD](http://rainers.github.io/visuald/visuald/StartPage.html) pour Visual Studio et le [plugin D](https://plugins.jetbrains.com/plugin/7727?pr=clion) pour CLion d'IntelliJ.
Consulte le wiki pour [plus d'informations](https://wiki.dlang.org/IDEs).

### Prérequis : DUB

[DUB](https://github.com/dlang/dub) est un gestionnaire de compilation pour D.

On te le recommande pour simplifier l'exécution des tests, mais il reste possible de s'en passer si tu ne peux pas ou ne veux pas l'installer.

La [page de téléchargement du site de DUB](https://code.dlang.org/download) propose un installateur Windows.
