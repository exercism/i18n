# Ajout aux instructions

## Mémoire réservée

Le tampon de la _string_ d'entrée occupe les octets 64 à 191 de la mémoire linéaire.

## Format d'entrée

L'entrée se présente sous la forme d'une seule _string_ de trois lignes, avec un saut de ligne à la fin de chacune. Les croix et les ronds seront toujours les caractères `X` et `O` en majuscule.

Ainsi, le plateau

```
X··
OXO
XOX
```
sera encodé comme ceci :

```
"X  \nOXO\nXOX\n"
```
