# Instructions

Réécris un programme qui imprime un relevé de compte.

L'exercice sur le relevé de compte est un exercice de réécriture. Il existe du code qui imprime un relevé de compte mis en forme, à partir d'une locale (américaine ou néerlandaise) et d'une devise (dollar américain ou euro). Ce code, toutefois, est plutôt mal écrit, même s'il passe systématiquement la suite de tests, ce qui est assez étonnant.

Réécris ce code. Rappelle-toi que, pour réécrire du code, l'astuce est de procéder par petits pas afin que les tests continuent de passer. Ainsi, tu peux toujours revenir rapidement à une version qui fonctionne. Les outils de gestion de versions comme git peuvent aussi t'aider ici.

Pense à tenir un journal des modifications que tu as faites et à laisser un commentaire sur l'exercice qui contient ce journal : cela aidera les relecteurs.
