## 1. Définis le comportement d'animation

- Utilise l'attribut de module `@callback` pour définir les fonctions voulues.
- Chaque _callback_ doit préciser le nom de la fonction, la liste des arguments (leurs types) et la valeur de retour (son type).
- Utilise les types personnalisés fournis `dot`, `opts`, `error` et `frame_number` dans la définition des _callbacks_.
- Rafraîchis tes connaissances sur les [typespecs][typespec] pour t'aider à définir les _callbacks_.

## 2. Fournis une implémentation par défaut du _callback_ `init/1`

- Définis une macro `__using__/1` dans le module `DancingDots.Animation`.
- L'argument de la macro peut être ignoré.
- La macro doit renvoyer une [expression quotée][quote].
- Dans l'expression quotée, utilise `@behaviour` pour que l'appel à `use DancingDots.Animation` définisse `DancingDots.Animation` comme comportement du module appelant.
- Dans l'expression quotée, implémente la fonction `init/1`.
- L'implémentation par défaut de la fonction `init/1` doit envelopper l'argument `opts` reçu dans un tuple `:ok`.
- Il existe [une macro][defoverridable] qui permet de marquer une fonction comme redéfinissable.

## 3. Implémente l'animation `Flicker`

- Utilise la macro `__using__/1` de `DancingDots.Animation` en appelant [cette macro un peu spéciale][doc-use] dans le module `DancingDots.Flicker`.
- Tu n'as pas besoin d'implémenter la fonction `init/1`. Son implémentation par défaut suffit.
- Tu dois implémenter la fonction `handle_frame/3`.
- Pour détecter « une image sur quatre », tu peux vérifier si le [reste][rem] de la division par 4 est égal à 0.

## 4. Implémente l'animation `Zoom`

- Utilise la macro `__using__/1` de `DancingDots.Animation` en appelant [cette macro un peu spéciale][doc-use] dans le module `DancingDots.Zoom`.
- Tu dois implémenter à la fois la fonction `init/1` et la fonction `handle_frame/3`.
- Utilise le module [`Keyword`][keyword] pour manipuler la liste de mots-clés d'options.
- Il existe [une garde intégrée][is_number] pour vérifier qu'une valeur est un nombre.
