# Introduction

JavaScript est un langage dynamique, qui prend en charge les styles orienté objet, impératif et déclaratif (par exemple la programmation fonctionnelle).

## (Ré)affectation

Il existe plusieurs façons principales d'affecter des valeurs à des noms en JavaScript : avec des variables ou des constantes. Sur Exercism, les variables s'écrivent toujours en [camelCase][wiki-camel-case] ; les constantes s'écrivent en [SCREAMING_SNAKE_CASE][wiki-snake-case]. Il n'existe pas de guide officiel à suivre, et chaque entreprise ou organisation a son propre guide de style. _Tu peux tout à fait nommer tes variables comme tu veux_. L'avantage de les écrire comme les exercices les préparent, c'est qu'elles seront mises en évidence différemment dans l'interface web et dans la plupart des IDE.

En JavaScript, on peut définir une variable avec le mot-clé [`const`][mdn-const], [`let`][mdn-let] ou [`var`][mdn-var].

Avec `let` ou `var`, une variable peut référencer différentes valeurs au cours de sa vie. Par exemple, `myFirstVariable` peut être définie et redéfinie plusieurs fois à l'aide de l'opérateur d'affectation `=` :

```javascript
let myFirstVariable = 1;
myFirstVariable = 'Some string';
myFirstVariable = new SomeComplexClass();
```

Contrairement à `let` et `var`, une variable définie avec `const` ne peut être affectée qu'une seule fois. C'est ce qu'on utilise pour définir des constantes en JavaScript.

```javascript
const MY_FIRST_CONSTANT = 10;

// Cannot be re-assigned.
MY_FIRST_CONSTANT = 20;
// => TypeError: Assignment to constant variable.
```

> 💡 Dans un prochain exercice d'apprentissage, on explore et on explique la différence entre l'_affectation_ (ou la _liaison_) d'une _constante_ et la _valeur_ de cette constante.

## Déclarations de fonctions

En JavaScript, les unités de fonctionnalité sont encapsulées dans des _fonctions_, que l'on regroupe généralement dans un même fichier lorsqu'elles vont ensemble. Ces fonctions peuvent prendre des paramètres (des arguments) et _renvoyer_ une valeur à l'aide du mot-clé `return`. On appelle une fonction avec la syntaxe `()`.

```javascript
function add(num1, num2) {
  return num1 + num2;
}

add(1, 3);
// => 4
```

> 💡 En JavaScript, il existe _de nombreuses_ façons de déclarer une fonction. Ces autres façons sont différentes de l'utilisation du mot-clé `function`. Le parcours essaie de les introduire progressivement, mais si tu les connais déjà, n'hésite pas à utiliser l'une ou l'autre. Dans la plupart des cas, utiliser l'une plutôt que l'autre n'est ni mieux ni pire.

## Exposer aux autres fichiers

Pour rendre une `function`, une constante ou une variable disponible dans _d'autres fichiers_, il faut les [exporter][mdn-export] à l'aide du mot-clé `export`. Un autre fichier peut ensuite les [importer][mdn-import] à l'aide du mot-clé `import`. C'est ce qu'on appelle aussi le système de modules. Le fonctionnement de tous les tests en est un excellent exemple. Chaque exercice possède au moins un fichier, par exemple `lasagna.js`, qui contient l'_implémentation_. Il y a en plus au moins un autre fichier, par exemple `lasagna.spec.js`, qui contient les _tests_. Ce fichier _importe_ les entités publiques (c'est-à-dire exportées) afin de tester l'implémentation :

```javascript
// file.js
export const MY_VALUE = 10;

export function add(num1, num2) {
  return num1 + num2;
}

// file.spec.js
import { MY_VALUE, add } from './file';

add(MY_VALUE, 5);
// => 15
```
