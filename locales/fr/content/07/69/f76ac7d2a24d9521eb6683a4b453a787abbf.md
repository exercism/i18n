# Comment écrire une bonne demande d'assistance

Tu veux de l'aide pour un exercice sur Exercism ?
Apprends à rédiger une bonne demande d'assistance et encourage notre communauté à t'aider : tu mettras toutes les chances de ton côté pour obtenir une bonne réponse.

Voici quelques conseils essentiels.

## Utilise des blocs de code, pas des images

Quand tu veux partager du code (celui que tu as écrit ou des instructions), utilise un bloc de code, pas une image.

En tant que développeurs, on lit le code bien plus vite qu'en devant zoomer sur une image pour voir les choses.
Et beaucoup de nos utilisateurs ont recours à des lecteurs d'écran, qui ne savent pas lire les images.
Alors si tu veux être un bon membre de la communauté, encourager nos bénévoles à t'aider et avoir l'air d'un pro, partage ton code sous forme de texte plutôt que d'image !

Par exemple, tu peux taper ceci :

````
```
for number in range(10):
  total += number;
```
````

Ce qui s'affichera comme ceci :

```
for number in range(10):
  total += number;
```

Tu peux même obtenir une coloration syntaxique en précisant le langage à l'ouverture du bloc de code :

````
```python
for number in range(10):
  total += number;
```
````

ce qui donne :

```python
for number in range(10):
  total += number;
```

## Utilise un langage inclusif

Exercism réunit des personnes de genres différents.
Si tu débarques sur notre Discord et que tu dis des choses comme « Hey boys », tu exclus d'emblée la moitié de notre communauté.
Ces personnes seront donc moins enclines à t'aider, et le reste de la communauté le sera aussi, car nous tenons à l'inclusivité chez Exercism.

Donc si tu veux obtenir de l'aide, et si tu veux être quelqu'un de sympathique, n'emploie pas de langage genré.
Essaie « Hey folks », « Hey everyone » ou, pour les plus audacieux, « Hey fellow Exercists ! »

Pour en savoir plus, lis notre article sur [les mots que nous employons](./the-words-that-we-use).
