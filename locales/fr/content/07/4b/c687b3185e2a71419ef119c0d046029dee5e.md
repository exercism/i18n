# Annexe

## Le « null » en Tcl

Tcl n'a pas de valeur `null` ni `nil`.
En pratique, la chaîne vide est souvent utilisée pour indiquer « pas de valeur ».
Mais cela peut être délicat dans les situations où une chaîne vide est en fait une valeur valide, par exemple dans un tableau représentant une ligne de données CSV.

Pour cet exercice, traite la chaîne vide comme une valeur nulle à écarter.
