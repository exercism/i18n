# Test des exercices

Suis les étapes ci-dessous pour développer une solution à un exercice et la tester en local.

## Télécharge l'exercice

Ouvre Command Prompt et exécute la commande ci-dessous avec le nom de l'exercice voulu pour le télécharger.

```sh
exercism download --track ballerina --exercise <exercise-name>
```

## Développe ta solution

1. Exécute la commande ci-dessous pour te rendre dans le répertoire de l'exercice que tu viens de télécharger.

     >**Astuce :** L'emplacement du répertoire dans la commande ci-dessous dépend de ton système d'exploitation et de l'espace de travail Exercism que tu as configuré. Tu peux connaître l'emplacement de ton espace de travail en exécutant la commande `exercism configure`.

     ```sh
     cd ~/exercism/ballerina/hello-world/
     ```

2. Suis les instructions fournies et développe une solution pour l'exercice.

## Teste ta solution

Certains exercices Ballerina n'ont qu'un seul test, tandis que d'autres en ont plusieurs. Les tests se trouvent dans le fichier de test correspondant, dans le répertoire `/tests` à la racine de l'exercice.

### Teste un exercice avec un seul test

Exécute la commande ci-dessous pour lancer le test de l'exercice.

Par défaut, seul le premier test est activé. C'est volontaire, car cela te permet de te concentrer uniquement sur la réussite de ce seul test. 
     
```sh
bal test
```

### Teste un exercice avec plusieurs tests

Suis les étapes ci-dessous pour tester un exercice comportant plusieurs tests.

1. Une fois que le premier test passe, active le test suivant en supprimant la propriété `enable: false` de l'annotation `@test:Config`.

     ```ballerina
     @test:Config {
       enable: false
     }
     function nextTestCase() {
     }
     ``` 

2.  Exécute la commande ci-dessous pour lancer le test activé.

   ```sh
     bal test
   ```

3. Répète les deux étapes ci-dessus pour activer les tests restants.

Tu as terminé l'exercice avec succès lorsque tu as activé tous les tests et vérifié que ton implémentation passe chacun d'eux.
