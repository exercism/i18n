# Indices

## Généralités

- Il n'y a pas de `new` dans une classe immuable. `create` commence par une variable
  de la classe, qui existe déjà :

  ```sather
     create(d : INT) : SAME is
        b : SAME;
        return b.degrees(...);
     end;
  ```

- `b.degrees(x)` ne modifie pas `b`. Il renvoie un nouveau relèvement, c'est pourquoi
  c'est ce qui est renvoyé.

## 1. Prends un relèvement

- `%` ramène un nombre dans l'intervalle, mais `-10 % 360` vaut `350` seulement parce que
  le `%` de Sather ne renvoie jamais de résultat négatif pour un membre de droite positif. Donc
  `d % 360` suffit à lui seul.

## 2. Tourne

- Ajoute la rotation aux degrés et crée un nouveau relèvement à partir du total :
  `#BEARING(degrees + by)`.
- `create` ramène déjà la réponse dans l'intervalle, donc il n'y a rien à faire pour
  un virage qui dépasse le nord.

## 3. Compare

- Une seule ligne : compare les deux `degrees`.
- Le type de l'argument est `SAME`, et on lit son attribut de la manière habituelle :
  `other.degrees`.

## 4. Nomme le point

- L'astuce consiste à décaler d'un demi-segment avant de diviser, pour que ce soit le
  *centre* de chaque point qui serve de référence pour la mesure :
  `((degrees + 22) / 45) % 8` donne 0 pour le nord, 1 pour le nord-est, et ainsi
  de suite.
- Ensuite, un `case` sur ce nombre, avec les huit noms, et un `else`, dont `case` a
  toujours besoin même lorsque les huit branches couvrent toutes les valeurs possibles.

## 5. Écris-le

- `+` assemble les morceaux, mais on ne peut ajouter des choses qu'à une _string_. Le
  nombre vient en premier ici, il a donc besoin de `degrees.str` pour amorcer
  l'assemblage. `"a" + 1` fonctionne ; `1 + "a"` ne compile pas.
- Appelle `point` plutôt que de recalculer le nom.
