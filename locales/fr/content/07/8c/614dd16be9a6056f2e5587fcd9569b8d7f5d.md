# Instructions

Détermine si un ensemble donné de trois dominos peut être disposé de façon à former une chaîne de dominos correcte (les points sur une moitié d'un domino correspondent aux points sur la moitié voisine d'un domino adjacent) et si les points des moitiés des dominos qui n'ont pas de voisin (le premier et le dernier domino) correspondent entre eux. Certains cas de test peuvent utiliser des dominos en double dans une solution de chaîne. Renvoie `True` si une chaîne de dominos correcte peut être disposée et `False` sinon.

```text
For example, given: [(2,1),(2,3),(1,3)]
    True

For example, given: [(1,2),(4,1),(2,3)]
    False
```
