# Introduction

## Les nombres

ABAP possède plusieurs types numériques. Dans cet exercice, tu en utiliseras deux :

- `i` pour les valeurs entières, comme un nombre de jours.
- `p` pour les valeurs décimales compressées, comme un taux horaire ou une remise.

```abap
DATA billable_days TYPE i VALUE 22.
DATA rate_per_hour TYPE p LENGTH 8 DECIMALS 2 VALUE '89.89'.
```

Les nombres compressés définissent leur longueur maximale et leur nombre de décimales.
Les littéraux décimaux s'écrivent couramment sous forme de valeurs textuelles et sont convertis vers le type décimal cible par le compilateur ou avec `CONV`.

```abap
TYPES discount_rate TYPE p LENGTH 8 DECIMALS 6.

DATA discount TYPE discount_rate.
discount = CONV discount_rate( '0.15' ).
```

### Arrondi

ABAP fournit des fonctions numériques intégrées pour l'arrondi.
La fonction `floor` arrondit à l'entier inférieur, et `ceil` arrondit à l'entier supérieur.

```abap
DATA full_months TYPE i.
full_months = floor( 70 / 22 ).

DATA rounded_cost TYPE i.
rounded_cost = ceil( '14527.2' ).
```

## Les opérateurs arithmétiques

ABAP prend en charge des opérateurs arithmétiques pour effectuer des calculs avec des valeurs numériques.

```abap
DATA day_rate TYPE p LENGTH 8 DECIMALS 2.
day_rate = rate_per_hour * 8.
```

Les opérateurs de base sont :

- `+` pour l'addition.
- `-` pour la soustraction.
- `*` pour la multiplication.
- `/` pour la division.
- `MOD` pour le reste d'une division entière.

```abap
DATA remaining_days TYPE i.
remaining_days = num_days MOD 22.
```

ABAP évalue la multiplication et la division avant l'addition et la soustraction.
On peut utiliser des parenthèses pour expliciter l'ordre voulu.

```abap
DATA discounted_rate TYPE p LENGTH 8 DECIMALS 2.
discounted_rate = monthly_rate * ( 1 - discount ).
```
