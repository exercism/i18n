# À propos

Lorsque les types ne peuvent pas être convertis implicitement, tu dois utiliser un [opérateur][cast-operator] de conversion explicite. L'opérateur de conversion n'est rien d'autre que le type cible entre parenthèses devant la valeur à convertir :

```csharp

int i = 7;
byte b = (byte)i; // Explicit cast from int to byte
```

Recourir à une conversion explicite est potentiellement dangereux. Les deux erreurs les plus courantes sont :

- Convertir vers un type incompatible. Cela lève une exception à l'exécution.
- Convertir vers une valeur numérique qui n'est pas suffisamment « large ». Cela peut provoquer un conflit de signe ou, dans le cas des entiers, la levée d'une exception de dépassement

Remarque : une expression de type `int` peut être convertie explicitement en `char`. Cela peut produire un `char` non valide.

[cast-operator]: https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/operators/type-testing-and-cast#cast-expression
