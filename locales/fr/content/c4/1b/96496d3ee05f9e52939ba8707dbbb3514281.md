# Instructions supplémentaires

## Registres

| Registre | Utilisation | Type | Description |
| -------- | ------------ | ------- | -------------------------------------------- |
| `$a0` | entrée | entier | nombre de chiffres d'entrée |
| `$a1` | entrée | entier | base des chiffres d'entrée |
| `$a2` | entrée | entier | base des chiffres de sortie |
| `$a3` | entrée/sortie | adresse | tableau écrasable de mots pour les chiffres |
| `$v0` | sortie | entier | nombre de chiffres de sortie, -1 si l'entrée est invalide |
| `$t0-9` | temporaire | quelconque | utilisé pour le stockage temporaire |
