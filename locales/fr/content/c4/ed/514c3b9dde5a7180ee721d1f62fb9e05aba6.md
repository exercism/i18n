# Introduction

La _surcharge de méthodes_ permet à plusieurs méthodes d'une même classe de porter le même nom. Les méthodes surchargées doivent se distinguer les unes des autres par l'un des critères suivants :

- Le nombre de paramètres
- Le type des paramètres

Il n'existe pas de surcharge de méthodes basée sur le type de retour.

Le compilateur déduira automatiquement quelle méthode surchargée appeler, en fonction du nombre de paramètres et de leur type.
