# Introduction

## Maps

Une **Map** est une structure de données qui stocke des paires clé-valeur.
Elle ressemble aux dictionnaires d'autres langages de programmation.
L'interface [Map][map-javadoc] définit les opérations applicables à une Map.

Java propose différentes implémentations de Map.
[HashMap][hashmap-javadoc] est l'une des plus utilisées.

```java
// Make an instance
Map<String, Integer> fruitPrices = new HashMap<>();
```

Pour ajouter des entrées à la Map, utilise [put][map-put-javadoc].

```java
fruitPrices.put("apple", 100);
fruitPrices.put("pear", 80);
// => { "apple" => 100, "pear" => 80 }
```

Une seule valeur peut être associée à chaque clé.
Appeler `put` avec la même clé met à jour la valeur associée à cette clé.

```java
fruitPrices.put("pear", 40);
// => { "apple" => 100, "pear" => 40 }
```

Pour obtenir la valeur associée à une clé, utilise [get][map-get-javadoc].

```java
fruitPrices.get("apple"); // => 100
```

Pour savoir si la Map contient une clé donnée, utilise [containsKey][map-containskey-javadoc].

```java
fruitPrices.containsKey("apple");  // => true
fruitPrices.containsKey("orange"); // => false
```

Pour supprimer des entrées, utilise [remove][map-remove-javadoc].

```java
fruitPrices.put("plum", 90);  // Add plum to map
fruitPrices.remove("plum");   // Removes plum from map
```

La méthode [size][map-size-javadoc] renvoie le nombre d'entrées.

```java
fruitPrices.size();  // Returns 2
```

Tu peux utiliser les méthodes [keySet][map-keyset-javadoc] ou [values][map-values-javadoc] pour obtenir respectivement les clés ou les valeurs d'une Map sous forme d'un Set ou d'une collection.

```java
fruitPrices.keySet();  // Returns "apple" and "pear" in a set
fruitPrices.values();  // Returns 100 and 80, in a Collection
```
