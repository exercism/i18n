# Introduction

Les énumérations en Cairo permettent de définir un type qui peut être l'une de plusieurs variantes nommées.

## Les bases

Les énumérations, abréviation du mot anglais _enumerations_, limitent toutes les valeurs possibles d'une donnée à un ensemble prédéfini. Les valeurs possibles d'un `enum` sont appelées des variantes :

```rust
#[derive(Drop)]
enum Direction {
    North,
    South,
    East,
    West,
}
```

Crée des valeurs d'énumération en précisant la variante :

```rust
let my_direction = Direction::North;
let another_direction = Direction::West;
```

## Filtrage par motif

Utilise match pour gérer les différentes variantes d'une énumération :

```rust
match my_direction {
    Direction::North => println!("Going north!"),
    Direction::South => println!("Going south!"),
    Direction::East => println!("Going east!"),
    Direction::West => println!("Going west!"),
}
```

Chaque branche du match traite une variante de l'énumération.

## Des énumérations avec des données

Les variantes d'une énumération peuvent contenir des données supplémentaires :

```rust
struct Location {
    x: u32,
    y: u32,
}

enum Message {
    Text: ByteArray,
    Number: u32,
    Location: Location,
}
```

Utilise le filtrage par motif pour extraire les données :

```rust
match msg {
    Message::Text(content) => println!("Text: {}", content),
    Message::Number(val) => println!("Number: {}", val),
    Message::Location(Location { x, y }) => println!("Position: ({}, {})", x, y),
}
```
