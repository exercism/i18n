# À propos

[concept:csharp/resource-cleanup]() utilise l'interface `IDispose` pour signaler aux appelants d'une classe qu'il existe des ressources ou un état de programme à libérer ou à réinitialiser en temps voulu lorsque l'objet en question n'est plus nécessaire. Dans cet exercice, on a introduit un peu de sucre syntaxique, avec le mot-clé `using`, qui rend le code moins verbeux et réduit le risque d'oublier des appels importants.

On peut voir `using` comme un remplacement de [`try/finally`][try-finally] dans certains cas d'usage.

```csharp
File file = null;
try
{
    file = new File("myStuff.txt");
    file.Write("more stuff");
}
finally
{
    file.Dispose();
}
```

Cette syntaxe est remplacée par la version plus compacte et infaillible :

```csharp
using (var file = new File("myStuff.txt")
{
    file.Write("more stuff");
}
```

Note que plusieurs ressources peuvent être combinées facilement en suivant les règles standard des blocs sur une seule ligne :

```csharp
using (var file = new File("mystuff.txt")
using (var fileWriter = new StreamWriter(file)
{
     ...
}
```

En C# 8, une variante a été introduite où l'instruction `using` se place au début d'un bloc :

```csharp
using var file = new File("myStuff.txt");
file.Write("more stuff");
```

Cela te permet d'avoir plusieurs objets jetables dans le même bloc et de gérer plus naturellement [`try/catch`][try-catch] :

```csharp
using var fileIn = new File("myStuff.txt");
using var fileOut = new File("yourStuff.txt");
try
{
    var stuff = fileIn.Read();
    fileOut.Write(stuff);
}
catch (Exception)
{
    LogStuff();
}
```

Les règles qui régissent l'utilisation du mot-clé `using` et les types d'instances concernés sont détaillées [ici][using-statement].

## Note pour les développeurs Java

Les développeurs Java y reconnaîtront peut-être un analogue du mécanisme de [_gestion automatique des ressources_][automatic-resource-management] introduit dans Java 7. Ils se ressemblent beaucoup. La syntaxe de Java, qui réutilise `try` à d'autres fins, a l'avantage d'intégrer les blocs `catch` plus naturellement que ne le fait `using` en C#.

## Versions

Note que la version plus souple de `using`, celle qui n'a pas son propre bloc syntaxique, a été introduite en C# 8 ; tu devras donc peut-être vérifier si la base de code sur laquelle tu travailles utilise C# 8 ou une version ultérieure.
