# Indices

## 1. Import d'une bibliothèque avec un préfixe

- Remarque que le script de test (test/pig_latin_test.dart) importe le fichier de solution avec un préfixe :

  ```dart
  import 'package:pig_latin/pig_latin.dart' as pigLatin;
  ```
- En savoir plus : [Spécifier un préfixe de bibliothèque
](https://dart.dev/guides/language/language-tour#specifying-a-library-prefix)
