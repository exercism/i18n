# À propos

Les créateurs de Julia veulent le beurre et l'argent du beurre. Comme ils l'expliquent dans l'article de blog « [Why We Created Julia](http://julialang.org/blog/2012/02/why-we-created-julia) », ils veulent la vitesse du C, le dynamisme de Ruby et la notation mathématique familière de Matlab. Ils veulent qu'il réunisse ce qu'ils préfèrent dans leurs langages préférés. Le traitement des chaînes de caractères comme Perl. La colle, comme le shell. Puissant, mais sans complexité impénétrable.

Julia dispose d'un [système de types](http://docs.julialang.org/en/v1/manual/types/) dynamique, puissant mais clair et intuitif. Il permet d'écrire du code dynamique et de préciser les types lorsqu'une expressivité supplémentaire est nécessaire pour simplifier le code ou gagner en performances. Le langage prend en charge le _multiple dispatch_, ce qui signifie qu'il choisit la méthode appelée en fonction des types de chaque argument. Cela te permet d'écrire des méthodes spécifiques pour certains types tout en proposant des solutions génériques de repli, ce qui est particulièrement utile pour le code mathématique, où l'on ne voit pas clairement pourquoi une opération devrait appartenir à un argument plutôt qu'à un autre.

La [métaprogrammation](http://docs.julialang.org/en/v1/manual/metaprogramming/) est simple en Julia. Le code peut être représenté comme une structure de données en Julia même, si bien qu'un programme peut transformer et générer son propre code, à la manière de Lisp. De grandes parties de la [bibliothèque de base et de la bibliothèque standard de Julia](https://github.com/julialang/julia) sont d'ailleurs écrites en Julia. Pour les comprendre et les modifier, nul besoin de connaître un autre langage. Si une bibliothèque que tu dois utiliser est écrite dans un autre langage, comme le [C ou Fortran](http://docs.julialang.org/en/v1/manual/calling-c-and-fortran-code/) ou [Python](https://github.com/JuliaPy/PyCall.jl), tu peux utiliser des interfaces simples pour l'appeler directement depuis ton code.

Malgré son jeune âge, Julia s'utilise déjà dans le monde réel, dans des domaines variés comme la finance, la science des données et le calcul scientifique, entre autres. Tu trouveras de nombreuses applications de démonstration sur le [Julia Blog Aggregator](https://www.juliabloggers.com/), des études de cas d'utilisation commerciale sur [juliacomputing.com](https://juliacomputing.com/case-studies/), et une liste de publications sur le langage et ses applications en recherche [ici](https://julialang.org/research/).
