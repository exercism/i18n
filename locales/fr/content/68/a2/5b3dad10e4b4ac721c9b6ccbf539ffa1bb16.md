# Tests

Sous MacOS/Linux, exécute la commande suivante :

```sh
$ chmod +x gradlew
```

Exécute les tests avec :

```sh
$ ./gradlew test
```

> Utilise `gradlew.bat` si tu es sous Windows

## Tests ignorés

Une fois le ou les premiers tests réussis, continue en commentant ou en supprimant les annotations `@Ignore` qui précèdent les autres tests.
