# Instructions

Ton entreprise de design a surtout travaillé avec des transformations CSS pour construire des pages web. Après quelques discussions, il est décidé de commencer à utiliser Clojure pour effectuer certains calculs de façon dynamique. Certains de tes collègues connaissent moins bien Clojure, tu décides donc d'utiliser une fermeture de fonction pour créer des transformations réutilisables pour des paires de coordonnées `{x, y}`.

## 1. Translater les coordonnées

Implémente la fonction `translate2d`, qui renvoie une fonction utilisant une fermeture pour effectuer une translation 2D répétable d'une paire de coordonnées.

```clojure
(def move-coordinates-right-2px (translate2d 2 0))
(def result (move-coordinates-right-2px 4 8))
;; result => [6 8]
```

## 2. Mettre les coordonnées à l'échelle

Implémente la fonction `scale2d`, qui renvoie une fonction utilisant une fermeture pour mettre une paire de coordonnées à l'échelle de façon répétable.

> Pour cet exercice, suppose que les valeurs de mise à l'échelle sont toujours positives.

```clojure
(def double-scale (scale2d 2 2))
(def result (double-scale 6 -3))
;; result => [12 -6]
```

## 3. Composer des fonctions de transformation

Combine deux fonctions de transformation pour effectuer une transformation répétable. On appelle souvent cela la _composition de fonctions_ : le résultat de la première fonction _'f(x)'_ sert d'entrée à la seconde fonction _'g(x)'_.

```clojure
(def move-coordinates-right-2px (translate2d 2 0))
(def double-coordinates (scale2d 2 2))
(def composed-transformations 
  (compose-transform move-coordinates-right-2px 
                     double-coordinates))
(def result (composed-transformations 0 1))
;; result => [4 2]
```

## 4. Enregistrer les résultats des fonctions

Implémente la fonction `memoize-transform`. Elle prend une fonction à _memoize_, puis renvoie une nouvelle fonction qui se souvient des entrées de la fonction fournie, de sorte que la dernière valeur de retour puisse être « mémorisée » et ne soit calculée qu'une seule fois si on l'appelle à nouveau avec les mêmes arguments.

> La mémorisation est parfois appelée _programmation dynamique_ ; elle permet de n'effectuer qu'une seule fois des opérations coûteuses, puisque leur résultat est mémorisé.

```clojure
(def triple-scale (scale2d 3 3))
(def memoized-scale (memoize-transform triple-scale))

(memoized-scale 4 3)
;; => [12, 9], this is computed since it hasn't been computed before for the arguments

(memoized-scale 4 3)
;; => [12, 9], this is remembered, since it was computed already
```
