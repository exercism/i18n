# Indices

## Général

- Le [guide des _strings_ de rubymostas][ruby-for-beginners.rubymonstas.org-strings] propose une bonne introduction aux _strings_ Ruby.
- L'objet `String` possède de nombreuses [méthodes intégrées][docs-string-methods] très utiles.

## 1. Récupère le message d'une ligne de log

- Il existe plusieurs façons de rechercher du texte dans une _string_ ; tu les trouveras dans la [documentation officielle du langage Ruby][docs-string-methods].
- Il existe des [méthodes intégrées][strip-white-space] pour supprimer les espaces blancs.

## 2. Récupère le niveau de log d'une ligne de log

- Les objets `String` de Ruby ont une [méthode][downcase] pour effectuer cette opération.

## 3. Reformate une ligne de log

- Il existe plusieurs façons de [concaténer des _strings_][ruby-for-beginners.rubymonstas.org-strings], mais celle que l'on privilégie est généralement [l'interpolation de _strings_][ruby-for-beginners.rubymonstas.org-strings]
