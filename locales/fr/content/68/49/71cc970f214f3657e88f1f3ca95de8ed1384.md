# Complément d'instructions

## Format d'entrée/sortie

Chaque ensemble de mots est représenté par une _string_ terminée par un caractère nul, avec un caractère de nouvelle ligne à la fin de chaque mot.

Tu dois renvoyer les anagrammes dans l'ordre où elles figurent parmi les mots candidats.

Par exemple : `"tones\nnotes\nSeton\n"`

## Registres

| Registre | Usage        | Type    | Description                                                    |
| -------- | ------------ | ------- | -------------------------------------------------------------- |
| `$a0`    | entrée       | adresse | _string_ cible terminée par un caractère nul, sans nouvelle ligne |
| `$a1`    | entrée       | adresse | _string_ des candidats terminée par un caractère nul, avec une nouvelle ligne après chaque mot |
| `$a2`    | entrée/sortie | adresse | _string_ de sortie terminée par un caractère nul, avec une nouvelle ligne après chaque mot |
| `$t0-9`  | temporaire   | quelconque | pour le stockage temporaire                                  |
