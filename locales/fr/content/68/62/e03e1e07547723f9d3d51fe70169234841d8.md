# À propos

`call` est la primitive universelle « exécute cette quotation maintenant ». Quand le compilateur voit la quotation littéralement, il peut en inférer l'effet ; quand la quotation vient d'une variable, d'un tableau ou d'un paramètre, il faut déclarer l'effet :

```factor
: apply-binary ( a b op -- c )
    call( a b -- c ) ;

5 3 [ - ] apply-binary .   ! => 2
5 3 [ + ] apply-binary .   ! => 8
```

La déclaration `call( a b -- c )` se compile en une vérification à l'exécution que la quotation a bien l'effet déclaré : une incohérence devient une erreur claire plutôt qu'un état de pile corrompu.

Traiter les quotations comme des données (les empiler, les mettre dans des tableaux, les renvoyer depuis des mots) est l'une des choses qui rendent le code concaténatif si compact. Un « programme » peut n'être qu'une simple séquence, et `each` avec `call` suffit à l'interpréter.
