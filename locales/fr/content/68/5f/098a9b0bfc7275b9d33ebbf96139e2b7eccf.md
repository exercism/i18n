# À propos

Le code Elixir s'exécute dans la [machine virtuelle BEAM][beam]. BEAM fait partie du [système d'exécution d'Erlang][erlang]. Comme Elixir s'inspire d'Erlang et partage son environnement d'exécution, il offre une excellente interopérabilité avec les bibliothèques Erlang. Cela signifie que les développeurs Elixir peuvent utiliser les bibliothèques Erlang directement depuis leur code Elixir. En effet, la communauté Elixir décourage l'écriture de bibliothèques Elixir pour des fonctionnalités déjà fournies par les bibliothèques Erlang.

Par conséquent, certaines fonctionnalités, comme les opérations mathématiques ou les fonctions de minuterie, ne sont disponibles en Elixir que via Erlang.

Cette relation étroite entre Elixir et Erlang signifie que, pour devenir un développeur Elixir confirmé, tu as tout intérêt à consacrer un peu de temps à l'apprentissage de la syntaxe de base d'Erlang.

## Comment les utiliser

La bibliothèque standard d'Erlang est directement utilisable dans notre code Elixir, sans aucune étape supplémentaire.

On peut appeler les fonctions Erlang de la même manière que les fonctions Elixir, à une petite différence près. Les noms de modules Erlang sont des atomes en `snake_case`. Par exemple, pour appeler la fonction Erlang `pi/0` du module `math`, on écrirait :

```elixir
:math.pi()
# => 3.141592653589793
```

## Les modules Erlang les plus utilisés

Les modules Erlang les plus utilisés apportent des fonctionnalités qui manquent à la bibliothèque standard d'Elixir. En voici quelques-uns :

- Le module `timer`, qui fournit des fonctions telles que [`sleep/1`][erl-timer-sleep], [`send_after/2`][erl-timer-send-after] et [`send_interval/2`][erl-timer-send-interval].
- Le module `rand`, qui fournit des fonctions telles que [`uniform/0`][erl-rand-uniform], [`normal/0`][erl-rand-normal] et [`seed/2`][erl-rand-seed-2].
- [`:io_lib.format/2`][erl-io-lib-format], qui permet de formater des _strings_ à la manière du C (à l'aide de séquences de contrôle).
- Le module `math`, qui fournit des fonctions mathématiques telles que [`sin/1`][erl-math-sin], [`cos/1`][erl-math-cos], [`log2/1`][erl-math-log2], [`log10/1`][erl-math-log10], [`pow/2`][erl-math-pow], entre autres.
- Le module [`queue`][erl-queue], qui fournit une structure de données de type file.
- Le module [`crypto`][erl-crypto], qui fournit des fonctions cryptographiques.
- Le module [`zip`][erl-zip], qui fournit des fonctions pour manipuler des archives zip.
- Le module [`calendar`][erl-calendar], qui fournit des fonctions pour manipuler les dates et les heures, comme [`iso_week_number/1`][erl-calendar-iso-week-number]. Pour passer une structure `Date`, `Time` ou `NaiveDateTime` à l'une des fonctions Erlang, il faut la convertir au format Erlang avec une fonction `to_erl` du module correspondant.

Pour découvrir la bibliothèque standard d'Erlang, explore le [manuel de référence STDLIB][erl-stdlib-ref].

L'interopérabilité d'Elixir avec les bibliothèques Erlang ne se limite pas à la bibliothèque standard d'Erlang. N'importe quelle bibliothèque Erlang peut être utilisée dans du code Elixir.
