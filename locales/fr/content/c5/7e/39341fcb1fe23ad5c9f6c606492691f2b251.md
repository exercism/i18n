# Introduction

Les boucles `for` sont le type de boucle le plus complexe en PHP. Elles se comportent comme les boucles `for` en `C`, en `Java` et en `JavaScript`. Leur forme de base est la suivante :

```php
for (expr1; expr2; expr3) {
  // statements
}
```

La première expression (_expr1_) est évaluée avant le début de la boucle. La deuxième expression (_expr2_) est évaluée avant chaque itération ; si elle s'évalue à une valeur _truthy_, les instructions sont exécutées. Une fois les instructions exécutées, la troisième expression (_expr3_) est évaluée.
