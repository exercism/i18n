# Introduction

Common Lisp dispose de nombreux prédicats d'égalité différents.
Cela le distingue d'autres langages de programmation, qui n'en ont parfois qu'un ou deux (par exemple `==` et `===`).
Certains de ces prédicats en Common Lisp sont spécifiques à certains types, tandis que d'autres sont génériques.
Ce sont ces derniers que l'on va aborder ici.

Il existe quatre prédicats d'égalité génériques, qui se distinguent par leur caractère plus ou moins restrictif sur ce qu'ils considèrent comme « égal ».
Les voici, du plus restrictif au moins restrictif : `eq`, `eql`, `equal` et `equalp`.

En voici quelques définitions rapides (en laissant de côté certains détails) :

- `eq` : définit l'égalité comme signifiant que les deux objets sont identiques.
  _p. ex._ :

```lisp
(eq 'a 'a)                 ; => T
(eq (list 1 2) (list 1 2)) ; => NIL
```

- `eql` : définit l'égalité comme signifiant que deux nombres ont le même type et la même valeur, que deux caractères sont identiques, ou, pour tout le reste, qu'ils sont `eq`.
  _p. ex._ :

```lisp
(eql 1 1)     ; => T
(eql #\a #\a) ; => T
(eql 1 1.0)   ; => NIL
(eql #\a #\A) ; => NIL
```

- `equal` : définit l'égalité comme signifiant que deux listes sont `equal` si chaque élément est aussi `equal` ; que deux _strings_ sont `equal` si chaque élément est `eql` ; que deux tableaux sont `equal` s'ils sont `eq` ; et que tout le reste est `equal` s'il est `eql`.
  _p. ex._ :

```lisp
(equal (list 1 2) (list 1 2)) ; => T
(equal #(1 2) #(1 2))         ; => NIL
(equal "foo" "foo")           ; => T
```

- `equalp` : définit l'égalité comme signifiant que les _strings_ et les caractères sont comparés sans tenir compte de la casse ; que les nombres sont comparés avec une certaine conversion de type ; que les listes et les tableaux sont `equalp` si chaque élément est aussi `equalp`, les structures si elles sont du même type et que tous leurs emplacements sont `equalp`, et les tables de hachage si leurs clés et leurs valeurs sont `equalp`
  _p. ex._ :

```lisp
(equalp "foo" "FoO")                          ; => T
(equalp 3 3.0)                                ; => T
(equalp (make-a-structure :slot1 1 :slot2 2) 
        (make-a-structure :slot1 1 :slot2 2)) ; => T
```
