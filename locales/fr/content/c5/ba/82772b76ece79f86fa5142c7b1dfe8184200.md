# À propos

En Haxe, un **tableau** est une collection d'éléments (généralement) du même type. Il existe trois façons de créer un tableau en Haxe : avec un constructeur ou avec une syntaxe de déclaration. En Haxe, le premier élément d'un tableau a un indice zéro :

```haxe
var a = [1, 2, 3];
trace(a); // [1,2,3]

// Here the second element is called by index
trace(a[1]); // 2

// The actual first element's index is 0
trace(a[0]); // 1
```

Pour créer un tableau avec un constructeur, il faut passer le type des éléments qui seront inclus dans le tableau :

```haxe
var a:Array<Int> = [0, 1, 2, 3];
a[1] = "Hello"; // Error: the array a takes integers only
```

Étant donné que l'accès à un tableau en Haxe n'est pas borné, c'est-à-dire qu'il est garanti qu'il ne lèvera pas d'exception, ce point mérite quelques explications :

- Si on lit un indice qui n'existe pas, la valeur renvoyée dépend de la cible.
- Si on écrit à un indice positif qui sort des limites du tableau, `null` (ou la valeur par défaut des types de base sur les cibles statiques) est inséré à toutes les positions entre le dernier indice défini et celui que l'on vient d'écrire.
- Si on écrit à un indice négatif, le résultat n'est pas spécifié.

Si on veut qu'un tableau contienne des éléments de plusieurs types, on ajoute le type `Dynamic` à l'indicateur de type :

```haxe
var a:Array<Dynamic> = [10, "Bob", true]
```

## Itération

On peut parcourir un tableau avec une boucle `for` :

```haxe
var nums = [2, 3, 5];
var sum = 0;
for (num in nums) {
  sum += num;
}
trace(sum); // 10
```
