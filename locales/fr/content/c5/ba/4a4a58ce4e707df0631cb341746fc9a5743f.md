# Introduction

## Les tuples

Un tuple est un conteneur ordonné de valeurs. Comme tous les types de données de Gleam, les tuples sont immuables. Chaque élément d'un tuple peut être d'un type différent, et peut même être un autre tuple.

Un tuple s'écrit sous la forme de valeurs séparées par des virgules entre `#(` et `)` : `#(1, 2.0, "Three")`.

```gleam
#("one", 2)      // Tuple pair (2 values)
#("one", 2, 3.0) // Tuple triplet (3 values)
```

Les tuples de même longueur et de mêmes types (dans le même ordre) peuvent être comparés pour vérifier leur égalité.

```gleam
#(1, 2) == #(1, 2) // Same length, same types, same values, same order
// -> True

#(1, 2) == #(2, 1) // Same length, same types, same values, different order
// -> False

#(1, 2) == #(1, "2") // Same length, different types
// Compile error!

#(1, 2) == #(1, 2, 3) // Different length
// Compile error!
```

Il existe trois façons de récupérer les valeurs contenues dans un tuple :

- L'accès par indice.
- Le filtrage par motif avec `let`.
- Le filtrage par motif avec `case`.

```gleam
let person = #("Jordan", 170)

// Option 1: Indexing
person.0 // -> "Jordan"
person.1 // -> 170

// Option 2: let
let #(name2, length2) = person
// -> name2 = "Jordan"
// -> length2 = 170

// Option 3: case
case person {
  #(name3, length3) -> {
    name3   // -> "Jordan"
    length3 // -> 170
  }
}
```
