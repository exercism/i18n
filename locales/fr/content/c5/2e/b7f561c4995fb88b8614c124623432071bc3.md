# Instructions

Dans cet exercice, tu vas générer des messages de _log_ semi-structurés.

## Émets des messages semi-structurés

Tu partiras de quelques fonctions vides et de l'énumération suivante :

```rust
#[derive(Drop, Clone, PartialEq, Debug)]
pub enum LogLevel {
    Info,
    Warning,
    Error,
    Debug
}
```

Ton objectif est d'émettre un message de _log_ sous la forme suivante : `"[<LEVEL>]: <MESSAGE>"`.
Tu devras implémenter des fonctions qui correspondent aux niveaux de _log_.

Par exemple, l'extrait ci-dessous montre la sortie attendue de la fonction `log`.

```rust
log(LogLevel::Error, "Stack overflow")
// Returns: "[ERROR]: Stack overflow"
```

Et pour `info` :

```rust
info("Timezone changed")
// Returns: "[INFO]: Timezone changed"
```

Amuse-toi bien !
