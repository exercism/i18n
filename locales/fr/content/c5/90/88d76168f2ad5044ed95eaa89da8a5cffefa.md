# Instructions

Une école locale près de chez toi possède une association d'élèves très active.
L'association d'élèves est gérée par un président et, tous les 2 ans, des élections sont organisées pour élire un nouveau président.

Lors de l'élection de cette année, il a été décidé qu'un nouveau système numérique de comptage des votes était nécessaire.
L'école a besoin de ton aide pour construire ce nouveau système.

## 1. Crée un compteur de votes

L'une des premières choses dont le nouveau système de vote a besoin est un compteur de votes.
Ce compteur permet de suivre les votes d'un candidat en particulier.

Crée une fonction `NewVoteCounter` qui accepte le nombre de votes initiaux d'un candidat et renvoie un pointeur vers un `int`, initialisé avec le nombre de votes initiaux donné.

```go
var initialVotes int
initialVotes = 2

var counter *int
counter = NewVoteCounter(initialVotes)
*counter == initialVotes // true
```

## 2. Récupère le nombre de votes d'un compteur

Tu disposes maintenant d'un moyen de créer de nouveaux compteurs ! Mais tu réalises que le nouveau système aura aussi besoin d'un moyen de récupérer le nombre de votes d'un compteur.

Crée une fonction `VoteCount` qui prend un compteur (`*int`) en argument et renvoie le nombre de votes du compteur.
Si le compteur vaut `nil`, tu dois considérer qu'il n'a aucun vote :

```go
var votes int
votes = 3

var voteCounter *int
voteCounter = &votes

VoteCount(voteCounter)
// => 3

var nilVoteCounter *int
VoteCount(nilVoteCounter)
// => 0
```

## 3. Incrémente les votes d'un compteur

C'est enfin le moment de compter les votes ! Tu as maintenant besoin d'un moyen d'incrémenter les votes d'un compteur.

Crée une fonction `IncrementVoteCount` qui prend un compteur (`*int`) en argument et un nombre de votes, et incrémente le compteur de ce nombre de votes.
Tu peux supposer que le pointeur passé ne sera jamais `nil`.

```go
var votes int
votes = 3

var voteCounter *int
voteCounter = &votes

IncrementVoteCount(voteCounter, 2)

votes == 5          // true
*voteCounter == 5   // true
```

## 4. Crée les résultats de l'élection

Maintenant que tous les votes sont comptés, il est temps de préparer l'annonce des résultats pour toute l'école.
Pour cela, tu remarques qu'avoir uniquement des compteurs de votes ne suffit pas.
Il faut un moyen d'associer le nombre de votes à un candidat en particulier.

Crée une fonction `NewElectionResult` qui reçoit le nom d'un candidat et son nombre de votes et renvoie un nouveau résultat d'élection.

```go
var result *ElectionResult
result = NewElectionResult("Peter", 3)

result.Name == "Peter"  // true
result.Votes == 3       // true
```

La structure de résultat d'élection est déjà créée pour toi et est définie ainsi :

```go
type ElectionResult struct {
    // Name of the candidate
    Name    string
    // Votes of votes the candidate had
    Votes   int
}
```

## 5. Annonce les résultats

Il est temps d'annoncer le nouveau président à l'école !
Le président sera annoncé sur les petits panneaux d'affichage numériques de l'école.
Le message doit indiquer le nom du nouveau président et les votes qu'il a obtenus, au format suivant : `<candidate_name> (<votes>)`.
Voici un exemple d'un tel message : `"Peter (51)"`.

Crée une fonction `DisplayResult` qui recevra un `*ElectionResult` en argument et renverra une _string_ avec le message à afficher.

```go
var result *ElectionResult
result = &ElectionResult{
    Name: "John",
    Votes: 32,
}

DisplayResult(result)
// => John (32)
```

## 6. Le recomptage des votes

Pour s'assurer que les résultats finaux étaient exacts, les votes ont été recomptés.
Lors du recomptage, il s'est avéré que le nombre de votes de certains candidats était décalé de un.

Crée une fonction `DecrementVotesOfCandidate` qui reçoit les résultats finaux et le nom d'un candidat dont tu dois décrémenter le nombre de votes.
Les résultats finaux sont donnés sous la forme d'une `map[string]int`, où les clés sont les noms des candidats et les valeurs leur nombre total de votes.

```go
var finalResults = map[string]int{
    "Mary":  10,
    "John":  51,
}

DecrementVotesOfCandidate(finalResults, "Mary")

finalResults["Mary"]
// => 9
```
