# Introduction

En Clojure, les nombres incluent :

- Entiers : nombres sans chiffre après le séparateur décimal (nombres entiers). Par exemple `-6`, `0`, `1`, `25`, `976` et `500000`.
- Nombres à virgule flottante : nombres avec zéro ou plusieurs chiffres après le séparateur décimal. Par exemple `-2.4`, `0.1`, `3.14`, `16.984025` et `1024.0`.

Deux types numériques courants sont `int` et `float`. Un `int` est un entier de 32 bits et un `float` est un nombre à virgule flottante de 64 bits.

Les opérations arithmétiques se font avec les opérateurs arithmétiques standard. On peut comparer les nombres avec les opérateurs de comparaison numériques standard, ainsi qu'avec les opérateurs d'égalité (`=`) et d'inégalité (`<>`).
