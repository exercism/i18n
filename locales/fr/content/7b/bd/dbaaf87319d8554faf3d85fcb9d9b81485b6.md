# Introduction

Cairo ne dispose pas d'un type natif pour les _strings_, mais propose deux façons de les gérer : les _strings_ courtes entre guillemets simples et `ByteArray` entre guillemets doubles.

Une _string_ courte est une _string_ ASCII dans laquelle chaque caractère est encodé sur un octet.

Le type que Cairo utilise par défaut pour les _strings_ courtes est `felt252`, ce qui limite leur longueur maximale à 31 caractères.

```rust
// below are different ways to write the same value
let name: felt252 = 'Jane';     // short string format
let name: felt252 = 0x4a616e65; // byte format
let name: felt252 = 1247899237; // decimal format
```

Techniquement, tout type entier plus petit que `felt252` peut être représenté au format _string_ courte.

```rust
// all of the below are equal u8 values, they are just written using different formats!
let lowercase_a_in_ascii: u8 = 'a';  // short string format
let lowercase_a_in_ascii: u8 = 0x61; // byte format
let lowercase_a_in_ascii: u8 = 97;   // decimal format
```

Pour les _strings_ de plus de 31 caractères, Cairo fournit `ByteArray`, dont la longueur est illimitée.

```rust
let long_string: ByteArray = "this is a string which has more than 31 characters";
```

Les ByteArrays peuvent être concaténés à l'aide de l'opérateur `+` :

```rust
"Jane" + " " + "Austen"
// => "Jane Austen"
```

Certains caractères spéciaux doivent être échappés avec une barre oblique inverse, comme `\t` pour une tabulation et `\n` pour un retour à la ligne dans les _strings_.

```rust
"How is the weather today?\nIt's sunny"  
// =>
// How is the weather today?
// It's sunny
```

Tu peux même accéder à des octets individuels dans un ByteArray en utilisant son indice.

Attention cependant : le type de l'octet renvoyé est `u8`, et non `ByteArray` !

```rust
let hello: ByteArray = "Hello World!";
let exclamation_mark: u8 = hello[11];
// => 33
```

La bibliothèque standard fournit de nombreuses méthodes et opérateurs utiles pour travailler sur les ByteArrays.

Pour en savoir plus sur les méthodes de ByteArray, consulte la [documentation de ByteArrayTrait][docs].

Voici quelques exemples :

```rust
let name: felt252 = 'Jane';
let mut greeting: ByteArray = "Welcome ";

// append_word appends a single word of a given number of bytes to the end of the ByteArray 
greeting.append_word(name, 4);
// => "Welcome Jane"

// rev returns a ByteArray with the all characters reversed
let rev_greeting = greeting.rev();
// => "enaJ emocleW"
```

[docs]: https://docs.swmansion.com/scarb/corelib/core-byte_array-ByteArrayTrait.html
