# Ajout aux instructions

## Indices

Tu dois implémenter la fonction `recite` qui produit les paroles de « The Twelve Days of Christmas ». Tu peux utiliser la signature fournie si tu as un doute sur les types, mais ne la laisse pas brider ta créativité.

Cet exercice travaille sur des données textuelles. Pour des raisons historiques, le type `String` de Haskell est synonyme de `[Char]`, une liste de caractères. Pour manipuler plus efficacement des données textuelles, on peut utiliser le type `Text`.

Comme prolongement facultatif à cet exercice, tu peux

- te renseigner sur les [types de _string_](https://haskell-lang.org/tutorial/string-types) en
  Haskell.
- ajouter `- text` à ta liste de dépendances dans package.yaml.
- importer `Data.Text` de [la façon
  suivante](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c) :

```haskell
import qualified Data.Text as T
import           Data.Text (Text)
```

- écrire par exemple `recite :: Int -> Int -> [Text]` et faire référence aux
  combinateurs de `Data.Text` comme par exemple `T.pack`.
- consulter la documentation de
  [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html).
- remplacer toutes les occurrences de `String` par `Text` dans TwelveDays.hs, c'est-à-dire :

```haskell
recite :: Int -> Int -> [Text]
```

Cette partie est entièrement facultative.
