Elixir a des conventions de nommage bien précises, notamment pour nommer les [fonctions qui renvoient un booléen](https://hexdocs.pm/elixir/naming-conventions.html#trailing-question-mark-foo) :

> Les fonctions qui renvoient un booléen sont nommées avec un point d'interrogation à la fin.

```elixir
# this is the expected name of functions that return a boolean

%{expected}

# this is the current name

%{actual}
```

À noter que les gardes, ainsi que certaines fonctions intégrées et macros qui renvoient des booléens et sont valides dans les gardes, suivent une autre convention : leur nom commence par le préfixe `is_` (`def is_integer`, `defguard is_foo`, `defmacro is_foo`). Les deux conventions ne doivent pas se mélanger.
