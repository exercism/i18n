# Introduction

Une façon courante d'utiliser un type union discriminée en F# consiste à représenter un ensemble fixe de constantes nommées, une structure que d'autres langages appellent « énumération ».

Normalement, dans une telle union discriminée, chaque cas ne peut faire référence qu'à exactement une de ces constantes nommées.
Cependant, il est parfois utile de faire référence à plus d'une constante.
Pour ce faire, on peut annoter l'union discriminée avec l'attribut Flags.

Une union discriminée avec l'attribut Flags peut se définir comme ceci (en notation binaire des entiers, 0b) :

```fsharp
[<Flags>]
type PhoneFeatures =
| Call = 0b00000001
| Text = 0b00000010
```

Une instance de `PhoneFeatures` avec la valeur `0b00000011` a ses deux drapeaux `Call` et `Text` définis.
