# Introduction

## Nombres

Il existe deux types de nombres différents en C# :

- Les entiers : des nombres sans chiffre après la virgule (nombres entiers). Par exemple `-6`, `0`, `1`, `25`, `976` et `500000`.
- Les nombres à virgule flottante : des nombres avec zéro ou plusieurs chiffres après la virgule. Par exemple `-2.4`, `0.1`, `3.14`, `16.984025` et `1024.0`.

Les deux types numériques les plus courants en C# sont `int` et `double`. Un `int` est un entier de 32 bits et un `double` est un nombre à virgule flottante de 64 bits.

Les opérations arithmétiques se font avec les opérateurs arithmétiques standards. On peut comparer des nombres avec les opérateurs de comparaison numériques standards, ainsi qu'avec les opérateurs d'égalité (`==`) et d'inégalité (`!=`).

C# propose deux types de conversions numériques :

1. Les conversions implicites : aucune donnée ne sera perdue et aucune syntaxe supplémentaire n'est nécessaire.
2. Les conversions explicites : des données peuvent être perdues et une syntaxe supplémentaire, sous la forme d'un _cast_, est nécessaire.

Comme un `int` a moins de précision qu'un `double`, convertir un `int` en `double` est sans risque et constitue donc une conversion implicite. En revanche, convertir un `double` en `int` peut entraîner une perte de données, ce qui exige une conversion explicite.

```csharp
int softCool = 1358938113;
double notLost = 4.8151623;

// implicit cast: no loss of information
double macDebug = softCool;         // 1358938113.0

// explicit cast: possible loss of information 
int somethingLost = (int)notLost;   // 4
```

## Les instructions `if`

Dans cet exercice, tu dois exécuter de la logique de manière conditionnelle. En C#, la façon la plus courante de le faire est d'utiliser une instruction `if/else` :

```csharp
int x = 6;

if (x == 5)
{
    // Execute logic if x equals 5
}
else if (x > 7)
{
    // Execute logic if x greater than 7
}
else
{
    // Execute logic in all other cases
}
```

La condition d'une instruction `if` doit être de type `bool`. C# ne connaît pas la notion de valeurs _truthy_.
