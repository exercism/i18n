# Ajout aux instructions

## Implémentation

Les objets sont représentés par des [*records*](https://lfe.gitbooks.io/reference-guide/content/16.html), définis dans `item.lfe`.
Utilise `item-weight` pour obtenir le poids et `item-value` pour obtenir la valeur.

```
;; Create an item with weight=5, value=50
(set item (make-item weight 5 value 50))

;; Get the weight. Returns 5.
(item-weight item)

;; Get the value. Returns 50.
(item-value item)
```
