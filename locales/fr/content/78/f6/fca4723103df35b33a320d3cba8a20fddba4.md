# Astuces

## Général

- Les six premiers arguments entiers sont passés à une fonction dans `rdi`, `rsi`, `rdx`, `rcx`, `r8` et `r9`.
- Pour accéder à moins de 64 bits d'un registre, tu peux consulter [le manuel d'AMD][manual] pour connaître le nom approprié.

## 1. Définis `get_box_weight`

- Les six premiers arguments entiers sont passés à une fonction dans `rdi`, `rsi`, `rdx`, `rcx`, `r8` et `r9`.
- Pour accéder à moins de 64 bits d'un registre, tu peux consulter [le manuel d'AMD][manual] pour connaître le nom approprié.
- Tu peux faire un retour anticipé pour vérifier chaque étape.
- Il existe une [instruction][movzx] pour étendre des valeurs avec des zéros.

## 2. Définis `max_number_of_boxes`

- Les six premiers arguments entiers sont passés à une fonction dans `rdi`, `rsi`, `rdx`, `rcx`, `r8` et `r9`.
- Pour accéder à moins de 64 bits d'un registre, tu peux consulter [le manuel d'AMD][manual] pour connaître le nom approprié.
- Tu peux faire un retour anticipé pour vérifier chaque étape.
- Il existe une [instruction][div] pour la division non signée.

## 3. Définis `items_to_be_moved`

- Les six premiers arguments entiers sont passés à une fonction dans `rdi`, `rsi`, `rdx`, `rcx`, `r8` et `r9`.
- Pour accéder à moins de 64 bits d'un registre, tu peux consulter [le manuel d'AMD][manual] pour connaître le nom approprié.
- Tu peux faire un retour anticipé pour vérifier chaque étape.
- La soustraction fonctionne de la même manière pour les nombres non signés et signés.

## 4. Définis `calculate_payment`

- Les six premiers arguments entiers sont passés à une fonction dans `rdi`, `rsi`, `rdx`, `rcx`, `r8` et `r9`.
- Pour accéder à moins de 64 bits d'un registre, tu peux consulter [le manuel d'AMD][manual] pour connaître le nom approprié.
- Tu peux faire un retour anticipé pour vérifier chaque étape.
- Si tu obtiens des résultats énormes alors qu'on attend un nombre négatif, il est probable que le signe de l'un des nombres soit incorrect.
- Il existe une [instruction][cqo] pour étendre des valeurs avec leur signe de `rax` vers `rdx`.
- Il existe une [instruction][idiv] pour la division signée.
- Le paiement est partagé entre toi et un certain nombre de travailleurs, et tu récupères aussi le reste.
- Le reste d'une division est stocké dans `rdx`.
