# Introduction

ABAP dispose de plusieurs types numériques. Dans cet exercice, on en utilisera deux :

- `i` pour les valeurs entières, comme un nombre de jours.
- `p` pour les valeurs décimales packées, comme un taux horaire ou une remise.

```abap
DATA billable_days TYPE i VALUE 22.
DATA rate_per_hour TYPE p LENGTH 8 DECIMALS 2 VALUE '89.89'.
```

Les nombres packés définissent leur longueur maximale et le nombre de décimales. Les littéraux décimaux sont couramment écrits sous forme de valeurs textuelles et convertis vers le type décimal cible par le compilateur ou avec `CONV`.

```abap
TYPES discount_rate TYPE p LENGTH 8 DECIMALS 6.

DATA discount TYPE discount_rate.
discount = CONV discount_rate( '0.15' ).
```

ABAP fournit des fonctions numériques intégrées pour l'arrondi. La fonction `floor` arrondit vers le bas au nombre entier le plus proche, et `ceil` arrondit vers le haut au nombre entier le plus proche.

```abap
DATA full_months TYPE i.
full_months = floor( 70 / 22 ).

DATA rounded_cost TYPE i.
rounded_cost = ceil( '14527.2' ).
```
