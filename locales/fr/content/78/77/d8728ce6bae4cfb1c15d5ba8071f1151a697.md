# Instructions

Dans cet exercice, tu vas écrire du code pour garder la trace d'un tableau de langages de programmation que tu veux apprendre sur Exercism.

Tu as six tâches, qui consistent toutes à manipuler des tableaux.

## 1. Crée un nouveau tableau

Pour garder la trace des langages que tu veux apprendre, tu vas devoir créer un nouveau tableau. Définis la liaison `newList` qui contient un nouveau tableau vide.

```fsharp
newList
// => []
```

## 2. Définis un tableau existant

Pour l'instant, tu as une feuille de papier sur laquelle sont listés les langages que tu veux apprendre : F#, Clojure et Haskell. Définis la liaison `existingList` pour représenter ce tableau.

```fsharp
existingList
// => ["F#"; "Clojure"; "Haskell"]
```

## 3. Ajoute un nouveau langage à un tableau

Au fur et à mesure que tu explores Exercism et que tu découvres des langages plus intéressants, tu veux les ajouter à ton tableau. Implémente la fonction `addLanguage` pour ajouter un nouveau langage au début de ton tableau.

```fsharp
addLanguage "TypeScript" ["JavaScript"; "CoffeeScript"]
// => ["TypeScript"; "JavaScript"; "CoffeeScript"]
```

## 4. Compte les langages du tableau

Compter les langages un par un n'est pas pratique. Implémente la fonction `countLanguages` pour compter le nombre de langages de ton tableau.

```fsharp
countLanguages ["C#"; "Racket"; "Rust"; "Ruby"]
// => 4
```

## 5. Inverse le tableau

À un moment donné, tu réalises que ton tableau est en fait dans l'ordre inverse ! Implémente la fonction `reverseList` pour inverser ton tableau.

```fsharp
reverseList ["Prolog"; "C"; "Idris"; "Assembly"]
// => ["Assembly"; "Idris"; "C"; "Prolog"]
```

## 6. Vérifie si un tableau est passionnant

Même si tu aimes tous les langages, F# occupe une place particulière dans ton cœur. À ce titre, un tableau de langages te passionne vraiment si :

- Le premier élément du tableau est F#.
- Le deuxième élément du tableau est F# et le tableau contient soit deux, soit trois langages.

Implémente la fonction `excitingList` pour vérifier si un tableau de langages est passionnant :

```fsharp
excitingList ["Nim"; "F#"]
// => true
```
