# À propos

Le langage d'assemblage ARM64/AArch64 est la version 64 bits du jeu d'instructions ARM.
Il s'appuie sur le jeu d'instructions ARMv7, lui-même librement inspiré des anciens jeux d'instructions ARM Classic.

Ce parcours porte sur la programmation en langage d'assemblage ARM64 : le code est assemblé puis exécuté sur un simulateur multiplateforme.
