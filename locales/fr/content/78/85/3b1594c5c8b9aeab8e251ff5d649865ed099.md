# Instructions supplémentaires

## Callable

En PHP, il existe un concept appelé [callable](https://www.php.net/manual/en/language.types.callable.php).

Celles-ci peuvent prendre plusieurs formes, mais on va se concentrer sur les [fonctions anonymes](https://www.php.net/manual/en/functions.anonymous.php).

Il est possible de stocker une fonction anonyme dans une variable et de l'appeler avec des paramètres :

```php
$double = function ($number) {
    return $number * 2;
};

$double(2); // returns 4
$double(4); // returns 8
```
