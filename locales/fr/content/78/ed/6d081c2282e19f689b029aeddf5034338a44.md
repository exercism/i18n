# utiliser l'annotation override

Même si ce n'est pas strictement nécessaire, c'est une bonne pratique d'utiliser l'annotation `@Override` quand on redéfinit des méthodes d'une superclasse.

Cela peut aider à éviter des erreurs : si une méthode marquée avec `@Override` ne redéfinit pas correctement une méthode de l'une de ses superclasses, le compilateur génère une erreur.
