# Introduction

## Les _strings_

En Gleam, les chaînes de caractères sont du texte immuable entouré de guillemets doubles. Elles prennent en charge les caractères Unicode et peuvent s'étendre sur plusieurs lignes.

```gleam
let greeting = "Hello, Joe! 📞"

let multi_line_string = "one
two
three"
```

On peut concaténer des _strings_ à l'aide de l'opérateur `<>` :

```gleam
let name = "Mike"
"Hello, " <> name <> "!"
// -> "Hello, Mike!"
```

Le module [`gleam/string`][stdlib] de la bibliothèque standard fournit des fonctions pour manipuler les _strings_.

On peut faire du filtrage par motif sur les _strings_ dans les expressions `case` :

```gleam
pub fn on_an_excellent_adventure(name: String) -> Bool {
  case name {
    "Bill" -> True
    "Ted" -> True
    _ -> False
  }
}
```

Si tu veux filtrer sur le début d'une _string_ et affecter le reste à une variable, tu peux utiliser le motif basé sur l'opérateur `<>` :

```gleam
pub fn profession(name: String) -> String {
  case name {
    "Dr " <> rest -> rest <> " is a doctor"
    _ -> "I'm not sure what " <> name <> " does"
  }
}
```

[stdlib]: https://hexdocs.pm/gleam_stdlib/gleam/string.html
