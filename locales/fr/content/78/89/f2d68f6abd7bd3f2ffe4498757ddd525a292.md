# Indices

## Généralités

- Un arbre est une structure de données récursive qui prend deux cas :
  - `nil` : un nœud feuille, qui n'a pas de valeur
  - `node(Left, Value, Right)` : un nœud ordinaire, qui possède une valeur, un nœud gauche et un nœud droit
- Pour le parcours préfixe comme pour le parcours infixe, tu devras définir des règles qui gèrent les deux cas de figure d'un arbre
