# Installation

Pour travailler sur les exercices, tu auras besoin des logiciels suivants :

1. [`OPAM`, le gestionnaire de paquets OCaml](https://opam.ocaml.org/)

   Consulte [Real World Ocaml, 2nd Ed.: Installation Instructions](https://dev.realworldocaml.org/install.html)
   pour savoir comment installer et configurer `OPAM` sur ton système d'exploitation.

2. Le compilateur OCaml

   Pour afficher la liste des versions disponibles :

   ```bash
   opam switch
   ```

   Si tu as déjà un _switch_ pour OCaml 5.1, tu peux soit le charger en exécutant `opam switch <switch-name>`, soit créer un nouveau _switch_ en exécutant :

   ```bash
   opam switch create exercism 5.4.0
   ```

   Le nom `exercism` est ici facultatif, mais donner un nom à tes _switches_ est une bonne pratique.

3. Installe les bibliothèques standard étendues et les bibliothèques de test

   Exécute la commande suivante pour installer les dépendances requises par ce parcours :

   ```bash
   opam install base core_kernel ounit qcheck
   ```

   Certains exercices n'utilisent que la bibliothèque standard d'OCaml, et d'autres utilisent les bibliothèques étendues de Jane Street appelées Base et Core_kernel.
   La bibliothèque de test s'appelle OUnit, et certains exercices utilisent en plus la bibliothèque QCheck pour les tests basés sur les propriétés.
   Exécuter la commande ci-dessus installera ces bibliothèques.

4. Installe et utilise un shell interactif (facultatif)

   Un résumé de [Setting up and using `utop`](https://dev.realworldocaml.org/install.html) :

   ```bash
   opam install utop
   ```

   Crée un nouveau fichier nommé `.ocamlinit` dans ton répertoire personnel et ajoutes-y les lignes suivantes :

   ```ocaml
   #use "topfind";;
   #require "base";;
   open Base
   ```

5. Installe les outils dans VS Code (facultatif)

   Si tu utilises VS Code :
   - Installe le serveur de langage OCaml depuis [ici](https://github.com/ocaml/ocaml-lsp).
   - Installe l'extension OCaml pour VS Code depuis [ici](https://marketplace.visualstudio.com/items?itemName=ocamllabs.ocaml-platform), ou recherche `OCaml Platform` d'Ocaml Labs.
