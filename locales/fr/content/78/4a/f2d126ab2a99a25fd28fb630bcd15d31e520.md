# Instructions

Tu travailles au bureau municipal depuis un moment, et tu as développé un ensemble d'outils qui accélèrent ton travail quotidien, par exemple pour remplir des formulaires.

Maintenant, un nouveau collègue te rejoint, et tu as réalisé que tes outils n'étaient peut-être pas auto-explicatifs. Il y a beaucoup de conventions étranges dans ton bureau, comme toujours remplir les formulaires en lettres majuscules et éviter de laisser des champs vides.

Tu décides d'écrire de la documentation pour que ton nouveau collègue puisse se lancer directement et commencer à utiliser tes outils.

## 1. Documente l'objectif des outils de formulaire

Ajoute de la documentation au module `Form` qui décrit son objectif. Elle doit dire :

```
A collection of loosely related functions helpful for filling out various forms at the city office.
```

## 2. Documente le remplissage de champs avec des valeurs vides

Ajoute de la documentation et une spécification de type à la fonction `Form.blanks/1`. La documentation doit dire :

```
Generates a string of a given length.

This string can be used to fill out a form field that is supposed to have no value.
Such fields cannot be left empty because a malicious third party could fill them out with false data.
```

La spécification de type doit expliquer que la fonction accepte un seul argument, un entier non négatif, et renvoie une _string_.

## 3. Documente le découpage de valeurs en tableaux de lettres majuscules

Ajoute de la documentation et une spécification de type à la fonction `Form.letters/1`. La documentation doit dire :

```
Splits the string into a list of uppercase letters.

This is needed for form fields that don't offer a single input for the whole string,
but instead require splitting the string into a predefined number of single-letter inputs.
```

La spécification de type doit expliquer que la fonction accepte un seul argument, une _string_, et renvoie un tableau de _strings_.

## 4. Documente la vérification qu'une valeur tient dans un champ avec une longueur maximale

Ajoute de la documentation et une spécification de type à la fonction `Form.check_length/2`. La documentation doit dire :

```
Checks if the value has no more than the maximum allowed number of letters.

This is needed to check that the values of fields do not exceed the maximum allowed length.
It also tells you by how much the value exceeds the maximum.
```

La spécification de type doit expliquer que la fonction accepte deux arguments, une _string_ et un entier non négatif, et renvoie l'une de deux valeurs possibles. Elle renvoie soit l'atome `:ok`, soit un tuple de 2 éléments dont le premier est l'atome `:error` et le second un entier positif.

## 5. Documente les différents formats d'adresse

Pour une raison qui t'échappe, le système interne du bureau municipal utilise deux façons différentes de représenter les adresses : soit sous forme de _map_, soit sous forme de tuple.

Documente ce fait en définissant trois types publics personnalisés :
- `address_map` - un _map_ avec les clés `:street`, `:postal_code` et `:city`. Chaque clé contient une valeur de type _string_.
- `address_tuple` - un tuple avec trois valeurs : `street`, `postal_code` et `city`. Chaque valeur est de type _string_. Différencie les valeurs en leur donnant des noms dans la spécification de type.
- `address` - peut être soit un `address_map`, soit un `address_tuple`.

## 6. Documente le formatage de l'adresse

Ajoute de la documentation et une spécification de type à la fonction `Form.format_address/1`. La documentation doit dire :

```
Formats the address as an uppercase multiline string.
```

La spécification de type doit expliquer que la fonction accepte un argument, une adresse, et renvoie une _string_.
