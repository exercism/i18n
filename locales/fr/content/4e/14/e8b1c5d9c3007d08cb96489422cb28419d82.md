# À propos

Swift est un langage compilé et multi-paradigme.
Avec les objectifs suivants :

- Disposer de fonctionnalités de sûreté pour éviter les erreurs en production

- Avoir une vitesse comparable à celle des langages basés sur C

- Avoir une syntaxe agréable à lire et à écrire

Swift a été développé pour remplacer Objective-C, qui était le langage principal utilisé pour développer des applications iOS et macOS.
Swift a été développé par Apple Inc.
Le langage a connu sa première version en 2014.
Il est aujourd'hui open source et disponible sur tous les appareils Apple, ainsi que sur Linux et Windows.

## Pour commencer

### Variables

On peut associer des valeurs à des noms en définissant une [variable][constants-variables] et en lui affectant une valeur.
Ce nom peut ensuite servir à désigner cette valeur dans tout le programme.
Les variables sont _mutables_, ce qui signifie que leur valeur peut être modifiée à tout moment.

Les variables se définissent à l'aide du mot-clé `var`.

```swift
var variableName = 10
```

Swift est un langage à typage statique qui garantit la sûreté des types, ce qui signifie que toutes les valeurs ont un type au moment de la compilation.
Tu peux soit préciser explicitement le type d'une variable à l'aide d'[annotations de type][type annotations], soit laisser le compilateur [inférer le type][type-inferring].
```swift
var explicitVar: Int = 10 // Explicitly typed
var implicitVar = 10      // Implicitly typed
```

Pour modifier la valeur d'une variable, on utilise l'opérateur `=`.

~~~~exercism/note
Le type d'une variable est fixé une fois qu'elle a été définie pour la première fois.

```swift
variableName = 13 // update to new value

// compiler error when assigning a different type
variableName = "Hello, world!" // Cannot assign value of type 'String' to type 'Int'
```
~~~~

On peut déclarer une variable sans lui affecter de valeur, en précisant son nom et son type, mais elle ne peut pas être utilisée avant qu'une valeur ne lui ait été affectée.

```swift
var someInt: Int

// This would trigger a compiler error
// print(someInt) // Variable 'someInt' used before being initialized

// Assign a value to the names
someInt = 169

print(someInt) // Prints '169'
```

### Constantes

Les [constantes][constants-variables] sont similaires aux variables en ce qu'elles sont associées à un nom et à une valeur, mais la valeur d'une constante ne peut pas être modifiée une fois qu'elle a été affectée : elle est donc _immuable_.
Les constantes se définissent à l'aide du mot-clé `let`.

```swift
let constantName = 10          // constant
let explicitConstant: Int = 10 // Explicitly typed constant
```

### Addition, soustraction et multiplication

Swift dispose d'[opérateurs][arithmetical-operators] pour l'addition, la soustraction et la multiplication.
Ces opérateurs sont respectivement `+`, `-` et `*`.

```swift
print(1 + 1) // Prints 2
print(2 - 1) // Prints 1
print(2 * 2) // Prints 4
```

### Fonctions

En Swift, les [fonctions][functions] sont un morceau de code qui accomplit une tâche.
Une fonction possède un type de retour et peut donc être utilisée comme une valeur et passée en argument à d'autres fonctions.
En Swift, les fonctions se définissent à l'aide du mot-clé `func`, suivi du nom de la fonction, des arguments séparés par des virgules, puis d'un type de retour.

Les arguments sont définis par une étiquette d'argument, un nom de paramètre suivi de deux-points, puis d'un type.
Le type de retour est défini par `->` suivi du type de la valeur renvoyée.

```swift
func functionName(argumentName parameterName: ArgumentType) -> ReturnType {
  // function body
}
```

Les arguments en Swift sont un peu particuliers par rapport à d'autres langages : ils utilisent des [étiquettes d'argument][argument-labels].
L'étiquette d'argument sert lors de l'appel de la fonction.
Le nom de paramètre sert à l'intérieur du corps de la fonction à désigner la valeur de l'argument.
Si tu n'attribues qu'un seul nom à l'argument, il servira à la fois d'étiquette d'argument et de nom de paramètre.
Si tu définis l'étiquette d'argument comme `_`, l'argument n'aura pas d'étiquette lors de l'appel de la fonction, par exemple : `functionName(argumentValue)`

Pour appeler une fonction, on utilise le nom de la fonction suivi de l'étiquette d'argument et de la valeur de l'argument, comme ceci :

```swift
func functionName(argumentLabel parameterName: ArgumentType) -> ReturnType {
  // function body
}

// calling the function
functionName(argumentLabel: argumentValue)
```

Par défaut, tous les arguments sont immuables et ne peuvent pas être modifiés à l'intérieur de la fonction.
Lorsqu'une fonction possède un type de retour, veille à renvoyer une valeur de ce type.
Pour cela, on utilise le mot-clé `return` suivi de la valeur à renvoyer.

```swift
func addTen(number value: Int) -> Int {
  return value + 10
}

// calling the function
addTen(number: 10) // Returns 20
```

Quand une fonction ne renvoie pas de valeur, son type de retour est `Void`, ce qui équivaut à `()`, mais dans ce cas le type de retour peut aussi être omis.

### Commentaires

Swift prend en charge deux types de [commentaires][comments].
Les commentaires sur une seule ligne sont précédés de `//` et les commentaires multilignes s'insèrent entre `/*` et `*/`.
