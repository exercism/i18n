# Introduction

## Interfaces

Une interface est un type qui contient des membres définissant un ensemble de fonctionnalités liées. Elle sépare les utilisations d'une classe de son implémentation, ce qui permet plusieurs implémentations différentes ou la prise en charge d'un comportement générique tel que le formatage, la comparaison ou la conversion.

La syntaxe d'une interface est semblable à celle d'une classe ou d'un struct, à ceci près que les méthodes et les propriétés n'y apparaissent que sous forme de signature et qu'aucun corps n'est fourni.

```csharp
public interface ILanguage
{
    string LanguageName { get; set; }
    string Speak();
}

public class ItalianTaveller : ILanguage, ICloneable
{
    public string LanguageName { get; set; } =  "Italiano";

    public string Speak()
    {
        return "Ciao mondo";
    }

    public object Clone()
    {
        ItalianTaveller it = new ItalianTaveller();
        it.LanguageName = this.LanguageName;
        return it;
    }
}
```

Toutes les opérations définies par l'interface doivent être implémentées.

Les interfaces peuvent contenir, entre autres membres, des méthodes et des propriétés d'instance.

## Comparaison

Pour qu'un objet puisse être comparé à un autre objet, il doit implémenter l'interface `IComparable<T>`.
Cette interface prend une seule méthode à implémenter : `int CompareTo(T other)`.

La méthode `CompareTo` peut renvoyer trois valeurs possibles :

- Une valeur inférieure à zéro : l'objet courant est plus petit que l'autre objet.
- Une valeur supérieure à zéro : l'objet courant est plus grand que l'autre objet.
- Une valeur égale à zéro : l'objet courant est égal à l'autre objet.
