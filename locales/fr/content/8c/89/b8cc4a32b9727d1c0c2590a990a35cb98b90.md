## 1. Ajoute une personne à la file d'attente

- Il existe [une méthode][append] pour ajouter un élément à un tableau.

## 2. Où sont mes amis ?

- Il existe [une méthode][index] pour obtenir l'indice d'un élément dans un tableau.

## 3. Est-ce que je peux les rejoindre ?

- Tu peux utiliser les méthodes déjà définies pour obtenir l'indice de l'ami et insérer la personne à cet indice.
- Il existe [une méthode][insert] pour insérer un élément à un indice précis dans un tableau.

## 4. Personne malveillante dans la file d'attente

- Il existe [une méthode][delete] pour supprimer un élément d'un tableau.

## 5. Trie la liste de la file d'attente

- Il existe [une méthode][sort] pour trier un tableau.
