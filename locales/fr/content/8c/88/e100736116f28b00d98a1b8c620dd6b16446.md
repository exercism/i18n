# Instructions

Si tu veux construire quelque chose avec un Raspberry Pi, tu utiliseras probablement des _résistances_.
Pour cet exercice, tu dois savoir deux choses à leur sujet :

- Chaque résistance a une valeur de résistance.
- Les résistances sont minuscules, à tel point que si l'on y imprimait la valeur de résistance, elle serait difficile à lire.

Pour contourner ce problème, les fabricants impriment sur les résistances des bandes colorées qui indiquent leur valeur de résistance.
Chaque bande a une position et une valeur numérique.

Les 2 premières bandes d'une résistance suivent un système d'encodage simple : chaque couleur correspond à un seul nombre.

La troisième bande est un multiplicateur.

Dans cet exercice, tu vas créer un programme bien utile pour ne plus avoir à mémoriser les valeurs des bandes.

Tu trouveras plus d'informations sur le codage des couleurs des résistances dans [l'article Wikipédia sur le code des couleurs électronique][e-color-code].

## 1. Définis un vecteur nommé

Les couleurs sont encodées comme suit :

- black : 0
- brown : 1
- red : 2
- orange : 3
- yellow : 4
- green : 5
- blue : 6
- violet : 7
- grey : 8
- white : 9

Crée le vecteur nommé, `resistor_bands`, qui doit avoir les couleurs comme noms et les nombres comme valeurs.

## 2. Renvoie la valeur associée à une bande

Tout d'abord, tu vas avoir besoin de trouver la valeur unique associée à n'importe quelle bande colorée.

Définis une fonction `band_value(band)` qui prend une `string` avec la couleur d'une bande.
La fonction renvoie la valeur associée à cette couleur.

```R
band_value("green")
# => [1] 5

band_value("violet")
# => [1] 7
```

## 3. Renvoie la valeur associée à deux bandes

Les deux premières bandes d'une résistance se combinent pour former un seul nombre.
Si les deux premières bandes ont pour nombres respectifs `m` et `n`, elles se combinent pour former le nombre `mn`.

Définis une fonction `two_band_value(bands)` qui prend un `vector` de `string`s avec deux couleurs de bande.
La fonction renvoie la valeur associée à la combinaison de ces deux couleurs.

```R
two_band_value(c("yellow", "red"))
# => [1] 42

two_band_value(c("green", "violet"))
# => [1] 57
```

## 4. Renvoie les ohms associés aux trois bandes

Enfin, tu vas devoir déterminer la valeur complète en ohms en combinant les deux premières bandes avec la troisième.
Pour cela, tu devras trouver la valeur des deux premières bandes ainsi qu'un multiplicateur.
On peut voir le multiplicateur comme le nombre de zéros que l'on ajoute à la valeur des deux bandes.

Définis une fonction `ohms(bands)` qui prend un `vector` de `string`s avec trois couleurs de bande.
La fonction renvoie la valeur en ohms associée à la combinaison de ces trois couleurs.

```R
ohms(c("yellow", "red", "orange"))
# => [1] 42000

ohms(c("green", "violet", "yellow"))
# => [1] 570000
```
