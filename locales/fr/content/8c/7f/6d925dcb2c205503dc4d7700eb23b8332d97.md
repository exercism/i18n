# Introduction

`call` (dans [`kernel`][kernel]) exécute une _quotation_. Quand
l'effet de pile d'une _quotation_ ne peut pas être déduit (généralement
parce que la _quotation_ vient d'ailleurs), il faut déclarer
explicitement l'effet sur `call` :

```
call( stack-effect ) ! e.g. call( a b -- c )
```

```factor
3 4 [ + ] call .                 ! => 7
3 4 [ + ] call( a b -- c ) .     ! => 7

: apply-binary ( a b op -- c )
    call( a b -- c ) ;

5 3 [ - ] apply-binary .         ! => 2
```

Comme les _quotations_ sont des valeurs, un tableau peut contenir un
mélange de nombres et de _quotations_, ce qui fait d'« un programme »
une simple séquence comme une autre :

```factor
{ [ 1 + ] [ 2 * ] } 5 swap [ call( x -- y ) ] each .   ! 5 -> 6 -> 12
```
