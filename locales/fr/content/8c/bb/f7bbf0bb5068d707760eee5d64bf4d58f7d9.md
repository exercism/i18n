# Installation

## Installe l'environnement d'exécution R
Rends-toi sur la [page d'accueil de CRAN](https://cran.r-project.org/). Tu y trouveras des liens de téléchargement pour Linux, Mac OSX et Windows. Télécharge et lance l'installateur correspondant à ton système d'exploitation.

## Installe l'IDE RStudio (recommandé)
RStudio est un environnement de développement intégré (IDE) multiplateforme très populaire pour programmer en R (il prend aussi en charge d'autres langages comme Python, JavaScript et Markdown). Avec RStudio, écrire tes solutions de code et exécuter les tests devient plus facile.

Télécharge et installe la [version stable actuelle de RStudio](https://www.rstudio.com/products/rstudio/download/). Ou bien, récupère la [version d'aperçu](https://www.rstudio.com/products/rstudio/download/preview/) d'une prochaine version.

## Installe l'extension Visual Studio Code pour R (alternative)
L'extension R pour Visual Studio Code prend en charge la coloration syntaxique étendue, la complétion de code, l'analyse statique, le formatage, l'interaction avec les terminaux R, l'affichage des données, des graphiques, des variables d'espace de travail et des pages d'aide, la gestion des _packages_ et le travail avec les documents R Markdown.

Télécharge et installe la [version actuelle de l'extension R](https://code.visualstudio.com/docs/languages/r)

## Installe les _packages_ R pour exécuter les tests
L'exécuteur de tests utilisé pour les spécifications est la bibliothèque [`testthat`](https://github.com/hadley/testthat) de Hadley Wickham, un choix très populaire chez les auteurs de _packages_ R.

Pour installer cette bibliothèque, saisis la commande suivante dans la console de RStudio (ou partout où tu utilises R).

```{R}
install.packages("testthat")
```

Même s'il est peu probable que tu aies _besoin_ d'installer des _packages_ pour résoudre les exercices Exercism, tu voudras peut-être ajouter un _package_ utilitaire polyvalent comme [`tidyverse`](https://github.com/tidyverse/tidyverse), adapté à ton style de programmation. Pour installer et charger un _package_ comme `tidyverse` :

```{R}
install.packages("tidyverse")
library(tidyverse)
```
