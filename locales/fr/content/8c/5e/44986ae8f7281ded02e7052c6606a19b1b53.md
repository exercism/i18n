# Introduction

## Les nombres

Haskell possède un type, `Num`, qui est le type de base de tous les types numériques.
Il existe quatre sous-types principaux parmi les types numériques : [`Int`][int], [`Integer`][integer], [`Double`][double] et [`Float`][float].

Il existe deux types d'entiers en Haskell, qui représentent des nombres entiers.
`Int` est un entier de taille fixe, tandis qu'`Integer` est un entier à précision arbitraire.
Un `Integer` peut contenir n'importe quel nombre, aussi grand soit-il, dans la limite de la mémoire de ta machine, tandis que `Int` correspond à l'ensemble des entiers positifs et négatifs représentables sur 32 ou 64 bits (avec une garantie d'au moins -2^29 à 2^29 - 1).

Note que pour écrire un nombre négatif, il vaut mieux utiliser des parenthèses afin d'éviter toute ambiguïté.

```haskell
1

(-1)
```

`Float` correspond à l'ensemble des nombres réels, limité par la précision de l'ordinateur.
Les opérations définies sur les nombres fonctionnent généralement sur l'un ou l'autre de ces types, mais pas sur les deux.
`Double` est un nombre à virgule flottante en double précision.

```haskell
10.5
```

### Convertir entre entiers et nombres à virgule flottante

La fonction `toFloat` permet de convertir un `Int` ou un `Integer` en `Float`.

```haskell
toFloat 1
-- -> 1.0
```

Il existe aussi `fromIntegral`, qui convertit n'importe quel type numérique vers le type numérique déduit dont on a besoin.

```haskell
fromIntegral 1
-- -> 1.0
```

Pour convertir un `Float` en `Int`, tu peux utiliser les fonctions [`round`][round], [`floor`][floor] ou [`ceiling`][ceiling].
La fonction `round` arrondit à l'entier le plus proche, `floor` arrondit vers le bas et `ceiling` arrondit vers le haut.

```haskell
round 1.5
-- -> 2

floor 1.5
-- -> 1

ceiling 1.5
-- -> 2
```

### Les opérateurs arithmétiques

Tu peux utiliser les [opérateurs arithmétiques de base][math] sur les types numériques.
Ces opérateurs sont `+`, `-`, `*`, `/` et `%`.
Lorsque tu utilises ces opérateurs, les types des nombres doivent correspondre.
La fonction `fromIntegral` effectue la conversion pour que les types correspondent.

#### Addition, soustraction et multiplication

L'opérateur `+` sert à l'addition, l'opérateur `-` à la soustraction et l'opérateur `*` à la multiplication.

| Opérateur | Exemple        |
| --------- | -------------- |
| `+`       | `4 + 6 => 10`  |
| `-`       | `15 - 10 => 5` |
| `*`       | `2 * 3 => 6`   |

#### La division

La division permet de diviser des nombres.
L'opérateur `/` sert à la division.
Le résultat est toujours un nombre à virgule flottante.

```haskell
4.0 / 2.5
-- -> 1.6

4 / 2
-- -> 2.0
```

~~~~exercism/caution
Dans certains langages de programmation, diviser par zéro provoque une erreur.

En Haskell, diviser par zéro donne `Infinity` ou `-Infinity`.
La seule exception est la division de zéro par zéro, qui donne `NaN` (Not a Number).

```haskell
1 / 0
-- -> Infinity

(-1) / 0
-- -> -Infinity

0 / 0
-- -> NaN
```
~~~~

### La division entière

La division entière permet de diviser des nombres entiers et d'obtenir la partie entière du résultat.
Haskell propose deux fonctions de division entière, qui diffèrent dans leur façon d'arrondir lorsque le résultat est négatif :

- `div` arrondit vers le bas, vers moins l'infini.
- `quot` arrondit vers zéro.

```haskell
6 `div` 2
-- -> 3

5 `div` 2
-- -> 2

(-5) `div` 2
-- -> -3

5 `quot` 2
-- -> 2

(-5) `quot` 2
-- -> -2
```

~~~~exercism/caution
Diviser par zéro avec la division entière lève une exception.
C'est différent de la division normale.
~~~~

#### Le reste

On peut obtenir le reste d'une division entière avec `mod` ou `rem`.
Ces deux fonctions diffèrent par le signe du résultat lorsqu'un des nombres est négatif :

- `mod` va de pair avec `div`, et son résultat a le même signe que le diviseur.
- `rem` va de pair avec `quot`, et son résultat a le même signe que le dividende.

```haskell
5 `mod` 3
-- -> 2

(-5) `mod` 3
-- -> 1

5 `mod` (-3)
-- -> -1

5 `rem` 3
-- -> 2

(-5) `rem` 3
-- -> -2

5 `rem` (-3)
-- -> 2
```

Pour tous `x` et `y` (avec `y` non nul), ces égalités sont vérifiées :

```haskell
(x `div` y) * y + (x `mod` y) == x
(x `quot` y) * y + (x `rem` y) == x
```

~~~~exercism/note
Lorsque les deux nombres sont positifs, `div` et `quot` donnent le même résultat, tout comme `mod` et `rem`.
Dans ce cas, `quot` et `rem` peuvent être légèrement plus efficaces, car `div` et `mod` ont besoin d'étapes supplémentaires pour gérer les nombres négatifs.
~~~~

~~~~exercism/caution
Diviser par zéro avec `mod` ou `rem` lève une exception.
C'est différent de la division normale.

```haskell
1 `mod` 0
-- Exception: divide by zero
```
~~~~

### L'exponentiation

Haskell dispose de trois opérateurs d'« élévation à la puissance », qui fonctionnent différemment et acceptent des types d'arguments différents.

- `**` prend deux **nombres à virgule flottante** et utilise des logarithmes pour calculer la puissance.
- `^^` prend un **nombre à virgule flottante** et l'élève à une puissance **entière** positive ou négative.
- `^` prend **n'importe quel type numérique** et l'élève à une puissance **entière positive**.

```haskell
3.0 ** 2.1
-- -> 10.04510856630514

2.5 ^^ 2
-- -> 6.25

2 ^ 3
-- -> 8
```

### Priorité et parenthèses

Haskell autorise les parenthèses (`()`), qui permettent de regrouper des expressions.
C'est utile lorsque tu veux changer l'ordre des opérations.

Lorsque tu utilises plusieurs opérateurs arithmétiques, l'ordre des opérations est le même qu'en mathématiques, aussi appelé [PEMDAS][pemdas].
Il suit l'ordre suivant : les parenthèses (`()`), les exposants (`**`), la multiplication (`*`) et la division (`/`), puis l'addition (`+`) et la soustraction (`-`).

```haskell
2 + 3 - 4 * 4
-- -> -11

(2 + 3 - 4) * 4
-- -> 4
```
