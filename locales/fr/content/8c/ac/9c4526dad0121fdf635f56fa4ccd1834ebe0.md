# En-tête factice

## Utiliser `grep` ou ne pas utiliser `grep`, telle est la question

Bien que cet exercice puisse être résolu trivialement en passant simplement les arguments à `grep`, implémente-le en n’utilisant que bash. L’objectif de ce parcours Exercism est d’apprendre à utiliser les commandes intégrées de bash pour résoudre des problèmes.

Pour résoudre cet exercice, tu devras :

* analyser les arguments de la ligne de commande : [`getopts`](https://stackoverflow.com/tags/getopts/info) est utile pour cela.
* parcourir les lignes d’un fichier : c’est la [FAQ bash n°1](https://mywiki.wooledge.org/BashFAQ/001).
* utiliser la correspondance par expression régulière : bash peut le faire grâce à l’opérateur `=~` au sein de [`[[ ... ]]`](https://www.gnu.org/software/bash/manual/bash.html#index-_005b_005b).
