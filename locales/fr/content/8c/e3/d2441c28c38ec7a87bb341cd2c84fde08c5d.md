# Instructions supplémentaires

## Dépréciation de `String.lowercase`

Selon la version d'OCaml que tu as installée, il est mal vu d'utiliser `String.lowercase`.
Depuis la version 4.03.0, `String.lowercase` est dépréciée au profit de `String.lowercase_ascii`.
Ainsi, au lieu d'écrire

```ocaml
String.lowercase "Hello, World!"
```

utilise

```ocaml
String.lowercase_ascii "Hello, World!"
```

Consulte la [documentation de String][string] pour découvrir d'autres fonctions utiles.

[string]: http://caml.inria.fr/pub/docs/manual-ocaml/libref/String.html
