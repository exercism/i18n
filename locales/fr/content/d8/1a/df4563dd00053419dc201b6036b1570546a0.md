# Introduction

Common Lisp propose plusieurs expressions conditionnelles différentes, dont la principale différence réside dans le nombre de branches qu'elles prennent en charge.

- `when` et `unless` permettent d'avoir une seule branche :

```lisp
(when (= 2 2) "All is well")      ; => "All is well"
(unless (= 2 2) "Time to panic!") ; => NIL
```

La partie qui suit l'expression de test peut comporter plusieurs expressions.

- `if` fournit la construction classique _if-then-else_ :

```lisp
(if (= 2 2) 'how-honest 'you-liar) ; => HOW-HONEST
```

Note que les clauses _then_ et _else_ ne peuvent contenir qu'une seule expression.

- `cond` permet d'avoir plusieurs branches sans imbriquer d'expressions `if` :

```lisp
(cond ((= 0 2) 'nope)
      ((= 1 2) 'try-again)
      ((= 2 2) 'quite-true)
      ((= 3 2) 'too-far)
      (t 'something-else))
; => QUITE-TRUE
```

Note qu'il n'y a pas de limite au nombre d'expressions qui suivent l'expression de test.

- `case` fournit une construction classique de type _switch_, qui teste une seule valeur par rapport à plusieurs branches :

```lisp
(case 'elder-beast
  (cat "Meow")
  (bird "Chirp")
  (dog "Bark")
  (otherwise "???"))
; => "???"
```

Note que, comme pour `cond`, le nombre d'expressions qui suivent l'expression de test est illimité.
