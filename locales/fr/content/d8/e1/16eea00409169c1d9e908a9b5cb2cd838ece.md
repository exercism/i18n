# Instructions

On t'a demandé de poursuivre le travail sur le système d'authentification réseau.

En plus de l'identité de l'administrateur, qui est « en dur » dans le système pendant le développement (une valeur fixe écrite directement dans le code plutôt qu'une variable que l'on peut modifier), les décideurs veulent que les développeurs seniors bénéficient du même traitement.

## 1. Enregistre les informations de l'administrateur du système « en dur » dans le système et rends-les accessibles aux appelants.

Les informations de l'administrateur sont les suivantes :

| E-mail       | Couleur des yeux | Largeur du philtrum | Nom      | Adresse 1 | Adresse 2 |
| ------------ | ---------------- | ------------------- | -------- | --------- | --------- |
| admin@ex.ism | green            | 0.9                 | Chanakya | Mumbai    | India     |

Implémente la propriété `Authenticator.Admin` pour renvoyer les informations d'identité de l'administrateur du système. Le nom et chaque partie de l'adresse doivent se trouver dans un élément distinct de la liste `NameAndAddress`.

```csharp
var authenticator = new Authenticator();
authenticator.Admin;
// => {"admin@ex.ism", {"green", 0.9m}, ["Chanakya", "Mumbai", "India"]}
```

## 2. Enregistre les informations des développeurs « en dur » dans le système et rends-les disponibles sous forme de dictionnaire

Les informations des développeurs sont les suivantes :

| E-mail        | Couleur des yeux | Largeur du philtrum | Nom      | Adresse 1 | Adresse 2 |
| ------------- | ---------------- | ------------------- | -------- | --------- | --------- |
| bert@ex.ism   | blue             | 0.8                 | Bertrand | Paris     | France    |
| anders@ex.ism | brown            | 0.85                | Anders   | Redmond   | USA       |

Implémente la propriété `Authenticator.Developers` pour renvoyer les informations d'identité des développeurs. La clé du dictionnaire est le nom du développeur.

```csharp
var authenticator = new Authenticator();
authenticator.Developers;
// => ["Bertrand"] = {"bert@ex.ism", {"blue", 0.8m}, ["Bertrand", "Paris", "France"]},
// ["Anders"] = {"anders@ex.ism", {"brown", 0.85m}, ["Anders", "Redmond", "USA"]},

```
