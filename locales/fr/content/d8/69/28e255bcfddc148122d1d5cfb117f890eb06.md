# Instructions

Tu fais de la randonnée en Nouvelle-Zélande et tu prends des relèvements à la boussole. Un relèvement est un nombre entier de degrés, et c'est une valeur : tourner de 20 degrés ne change pas le relèvement que tu as pris, ça t'en donne un autre.

Écris une `immutable class BEARING`. Le squelette te donne l'en-tête de la classe et son attribut.

## 1. Prends un relèvement

`create` prend un nombre de degrés et donne un relèvement. Les degrés vont de 0 à 359, donc tout ce qui en sort revient au début : 370 donne 10, et -10 donne 350.

```sather
#BEARING(370).degrees
-- => 10
#BEARING(-10).degrees
-- => 350
```

## 2. Tourne

`turned` prend un nombre de degrés de rotation et renvoie le nouveau relèvement. Tourner d'un nombre négatif fait tourner dans l'autre sens. Le relèvement sur lequel la méthode a été appelée ne change pas.

```sather
#BEARING(350).turned(20).degrees
-- => 10
```

## 3. Compare

`is_eq` prend un autre relèvement et renvoie s'ils sont identiques. Une fois qu'elle existe, `=` fonctionne sur les relèvements.

```sather
#BEARING(10) = #BEARING(370)
-- => true
```

## 4. Nomme le point

`point` renvoie le point cardinal dont le relèvement est le plus proche, parmi `"N"`, `"NE"`, `"E"`, `"SE"`, `"S"`, `"SW"`, `"W"`, `"NW"`.

Chaque point couvre 45 degrés, centré sur son relèvement exact : le nord va de 337,5 à 22,5 en passant par 0, le nord-est de 22,5 à 67,5, et ainsi de suite. Comme les relèvements ici sont des nombres entiers, un relèvement de 22 vaut `"N"` et 23 vaut `"NE"`.

```sather
#BEARING(0).point
-- => "N"
#BEARING(90).point
-- => "E"
#BEARING(225).point
-- => "SW"
```

## 5. Note-le

`str` renvoie les degrés et le point, comme `"90 degrees (E)"`.

```sather
#BEARING(90).str
-- => "90 degrees (E)"
```
