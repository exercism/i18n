# Instructions

Tu vas écrire du code pour gérer le tableau des scores d'un jeu.
Ce tableau des scores sera un _hash_ appelé `%HighScoreBoard::Scores`.
Les clés du _hash_ seront les noms des joueurs, et les valeurs seront leurs scores.

## 1. Définis le score d'un joueur dans le _hash_ `%Scores`

Modifie le sous-programme `HighScoreBoard::set_player_scores`, qui prend des noms de joueurs et des scores en arguments, pour définir les scores des joueurs dans le _hash_ `%HighScoreBoard::Scores`.

## 2. Récupère le score d'un joueur depuis le _hash_ `%Scores`

Modifie le sous-programme `HighScoreBoard::get_player_score`, qui prend un nom de joueur en argument, pour qu'il renvoie le score du joueur depuis le _hash_ `%HighScoreBoard::Scores`.

## 3. Augmente le score d'un joueur dans le _hash_ `%Scores`

Modifie le sous-programme `HighScoreBoard::increase_player_scores`, qui prend des noms de joueurs et des scores en arguments, pour augmenter les scores des joueurs dans le _hash_ `%HighScoreBoard::Scores` du score donné.

## 4. Trie les joueurs du _hash_ `%Scores` par leur nom

Modifie le sous-programme `HighScoreBoard::sort_players_by_name` pour qu'il renvoie les noms des joueurs du _hash_ `%HighScoreBoard::Scores` triés par nom.

## 5. Trie les joueurs du _hash_ `%Scores` par leur score

Modifie le sous-programme `HighScoreBoard::sort_players_by_score` pour qu'il renvoie les noms des joueurs du _hash_ `%HighScoreBoard::Scores` triés par score.

## 6. Supprime un joueur du _hash_ `%Scores`

Modifie le sous-programme `HighScoreBoard::delete_player`, qui prend un nom de joueur en argument, pour supprimer le joueur du _hash_ `%HighScoreBoard::Scores`.
