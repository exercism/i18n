# Instructions

Dans cet exercice, on joue à un jeu de rôle où différents types de combattants peuvent s'affronter.
Le jeu a des règles différentes pour chaque type de combattant.
On va se concentrer sur deux types bien précis : les Wizards et les Warriors.

Pour un Warrior, voici les règles :

- Un Warrior n'est jamais vulnérable.
- Un Warrior inflige `6` points de dégâts si le combattant qu'il attaque n'est pas vulnérable.
- Un Warrior inflige `10` points de dégâts si le combattant qu'il attaque est vulnérable.

Pour un Wizard, voici les règles :

- Un Wizard peut préparer un sort à l'avance.
- Un Wizard est vulnérable à moins d'avoir préparé un sort à l'avance.
- Un Wizard inflige `12` points de dégâts s'il a préparé un sort à l'avance.
- Un Wizard inflige `3` points de dégâts s'il n'a pas préparé de sort à l'avance.

## 1. Crée la classe Warrior

Crée une nouvelle classe appelée `Warrior`.
Cette classe doit hériter de la classe `Fighter` existante.

## 2. Décris un Warrior

Mets à jour la classe `Warrior` pour que sa méthode `toString()` décrive le type de combattant qu'il représente.
La méthode doit renvoyer la _string_ `"Fighter is a Warrior"`.

```java
Warrior warrior = new Warrior();
warrior.toString();
// => "Fighter is a Warrior"
```

## 3. Rends les Warriors invulnérables

Mets à jour la classe `Warrior` pour que sa méthode `isVulnerable()` renvoie toujours `false`.

```java
Warrior warrior = new Warrior();
warrior.isVulnerable();
// => false
```

## 4. Calcule les points de dégâts d'un Warrior

Mets à jour la classe `Warrior` pour que sa méthode `getDamagePoints(Fighter)` calcule les dégâts infligés par un Warrior selon les règles ci-dessus.

```java
Warrior warrior = new Warrior();
Wizard wizard = new Wizard();

warrior.getDamagePoints(wizard);
// => 10
```

## 5. Crée la classe Wizard

Crée une autre nouvelle classe appelée `Wizard`.
Cette classe doit aussi hériter de la classe `Fighter` existante.

## 6. Décris un Wizard

Mets à jour la classe `Wizard` pour que sa méthode `toString()` décrive le type de combattant qu'il représente.
La méthode doit renvoyer la _string_ `"Fighter is a Wizard"`.

```java
Wizard wizard = new Wizard();
wizard.toString();
// => "Fighter is a Wizard"
```

## 7. Permets aux Wizards de préparer un sort et rends-les vulnérables lorsqu'ils n'ont pas préparé de sort

Mets à jour la classe `Wizard` pour ajouter une méthode appelée `prepareSpell()`.
La classe doit se souvenir du moment où cette méthode est appelée et faire en sorte que sa méthode `isVulnerable()` ne renvoie `false` que lorsqu'un sort est préparé.

```java
Wizard wizard = new Wizard();
wizard.prepareSpell();
wizard.isVulnerable();
// => false
```

## 8. Calcule les points de dégâts d'un Wizard

Mets à jour la classe `Wizard` pour que sa méthode `getDamagePoints(Fighter)` calcule les dégâts infligés par un Wizard selon les règles ci-dessus.

```java
Wizard wizard = new Wizard();
Warrior warrior = new Warrior();

wizard.prepareSpell();
wizard.getDamagePoints(warrior);
// => 12
```
