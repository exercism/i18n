# Instructions

Elaine travaille sur un nouveau jeu pour enfants qui met en scène des animaux et des baguettes magiques.
Il est temps de coder des fonctions pour lancer un dé, générer de l'énergie de baguette aléatoire et mélanger une tranche.

## 1. Lance un dé

Implémente une fonction `RollADie`.

Ce sera le dé traditionnel à vingt faces, numéroté de 1 à 20.

```go
d := RollADie() // d will be assigned a random int, 1 <= d <= 20
```

## 2. Génère l'énergie de la baguette

Implémente une fonction `GenerateWandEnergy`.
L'énergie de la baguette doit être un nombre à virgule flottante aléatoire supérieur ou égal à 0,0 et inférieur à 12,0.

```go
f := GenerateWandEnergy()  // f will be assigned a random float64, 0.0 <= f < 12.0
```

## 3. Mélange une tranche

Le jeu met en scène huit animaux différents :

- ant
- beaver
- cat
- dog
- elephant
- fox
- giraffe
- hedgehog

Écris une fonction `ShuffleAnimals` qui renvoie une tranche avec les huit animaux dans un ordre aléatoire.
