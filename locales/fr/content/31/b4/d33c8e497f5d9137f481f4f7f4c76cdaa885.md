# Introduction

## Filtrage des exceptions

`when` est le mot-clé qui permet de filtrer les exceptions. Il se place après l'instruction `catch` et peut prendre une expression booléenne contenant toutes les valeurs qui sont dans la portée à ce moment-là. Si l'expression est évaluée à vrai, le bloc associé à cette instruction `catch` est exécuté, sinon l'instruction `catch` suivante, s'il y en a une, est vérifiée.

```csharp
try
{
    // do stuff
}
catch (Exception ex) when (ex.Message != "")
{
    // output the message when it is not empty
}
catch (Exception ex)
{
    // show stack trace or something.
}
```

## Exceptions définies par l'utilisateur

Une exception définie par l'utilisateur est toute classe définie dans ton code qui dérive de `System.Exception`. Elle est soumise à toutes les règles de l'héritage de classe, mais en plus le compilateur et l'environnement d'exécution du langage traitent ces classes d'une manière particulière, ce qui permet de lever et d'intercepter leurs instances en dehors du flux de contrôle normal, comme expliqué dans l'exercice `exceptions`.

Les exceptions définies par l'utilisateur servent souvent à transporter des informations supplémentaires, comme un message et d'autres données pertinentes, à mettre à la disposition des routines qui les interceptent.
