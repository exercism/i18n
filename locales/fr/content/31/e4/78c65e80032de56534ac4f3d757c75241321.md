# Introduction

En Go, une application est organisée en packages.
Un package est un ensemble de fichiers source situés dans le même dossier.
Tous les fichiers source d'un dossier doivent déclarer le même nom de package en haut du fichier.
Par convention, un package porte le nom du dossier dans lequel il se trouve.

```go
package greeting
```

Go fournit une vaste bibliothèque standard de packages que l'on peut utiliser dans son programme grâce au mot-clé `import`.
Les packages de la bibliothèque standard s'importent avec leur nom.

```go
package greeting

import "fmt"
```

Un package importé est ensuite désigné par son nom :

```go
world := "World"
fmt.Sprintf("Hello %s", world)
```

Go détermine si un élément peut être appelé par du code situé dans d'autres packages en fonction de sa déclaration.
Pour qu'une fonction, un type, une variable, une constante ou un champ de structure soit visible depuis l'extérieur (on dit alors qu'il est _exported_), son nom doit commencer par une majuscule.
Cela ressemble à ce que font d'autres langages de programmation comme Java, qui utilisent des modificateurs d'accès tels que `public` et `private`.

```go
package greeting

// Hello is a public function (callable from other packages).
func Hello(name string) string {
    return "Hello " + name
}

// hello is a private function (not callable from other packages).
func hello(name string) string {
    return "Hello " + name
}
```
