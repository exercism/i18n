# Installation

## Installe Node.js

**Utilisateurs de Windows et OS X** : installe [Node.js][node] [via le gestionnaire de paquets][node-download].

**Utilisateurs de Linux** : installe [Node.js][node] en suivant les instructions pour ta distribution sur le [gestionnaire de paquets Node.js][linstall].

## Installe `jasmine-node` et `coffeescript`

Pour la plupart des utilisateurs, il suffit d'exécuter la commande suivante :

```bash
$ npm install -g jasmine-node coffeescript
```

Selon ta configuration, tu devras peut-être disposer des privilèges de superutilisateur pour installer un module `npm` globalement.
C'est le cas si tu as utilisé l'installateur officiel lié plus haut.
Si NPM te renvoie une erreur indiquant que tu n'as pas les droits d'accès, ajoute `sudo` à la commande ci-dessus :

```bash
$ sudo npm install -g jasmine-node coffeescript
```

Si tu as utilisé l'installateur officiel, ton `PATH` devrait avoir été configuré automatiquement, mais si ton shell a du mal à localiser tes modules installés globalement, ou si tu compiles Node.js depuis les sources.
Dans ce cas, mets à jour ton `PATH` pour inclure les binaires `npm` en ajoutant ce qui suit à `~/.bash_profile` ou à `~/.zshrc` :

```bash
$ export PATH=/usr/local/share/npm/bin:$PATH
```
