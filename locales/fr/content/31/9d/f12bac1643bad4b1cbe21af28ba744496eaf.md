# Opérateurs de comparaison

PHP dispose de dix opérateurs de comparaison intégrés :

| Nom  | Exemple    | Résultat                                             |
| ----- | ---------- | -------------------------------------------------- |
| Égal | `$a == $b` | vrai si `$a` est égal à `$b` après jonglage de type. |
| Identique | `$a === $b` | vrai si `$a` est égal à `$b` et qu'ils sont du même type. |
| Différent | `$a != $b` | vrai si `$a` n'est pas égal à `$b` après jonglage de type. |
| Différent | `$a <> $b` | vrai si `$a` n'est pas égal à `$b` après jonglage de type. |
| Non identique | `$a !== $b` | vrai si `$a` n'est pas égal à `$b` ou n'est pas du même type. |
| Inférieur à | `$a < $b` | vrai si `$a` est strictement inférieur à `$b`. |
| Supérieur à | `$a > $b` | vrai si `$a` est strictement supérieur à `$b`. |
| Inférieur ou égal à | `$a <= $b` | vrai si `$a` est inférieur ou égal à `$b`. |
| Supérieur ou égal à | `$a >= $b` | vrai si `$a` est supérieur ou égal à `$b`. |
| Vaisseau spatial | `$a <=> $b` | renvoie un entier inférieur à, égal à, ou supérieur à `0`i quand `$a`. |

PHP a des définitions distinctes qui différencient `equal` de `identical`.
On désigne aussi parfois `identical` sous le nom de `strictly equal`.

```php
<?php

// Comparisons between integer and numeric string values
1 == "1"; // => true, equal
1 === "1"; // => false, not identical

// Comparisons between integers and floating point values
1 == 1.0; // => true
1 === 1.0; // => false

// Comparisons between object instances
new stdClass() == new stdClass(); // => true, properties are equal
new stdClass() === new stdClass(); // => false, references are not identical
```
