# Convertir directement un point de code en _string_

La façon la plus simple de transformer le point de code d'un caractère en une _string_ contenant ce caractère est d'utiliser la forme spéciale `<<>>`. Pas besoin de passer par une _charlist_ comme étape intermédiaire.

```elixir
# instead of:
to_string([?A])
# => "A"

# use:
<<?A>>
# => "A"
```
