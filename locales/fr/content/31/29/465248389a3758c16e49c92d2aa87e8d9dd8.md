# Éviter les instructions d'affichage

Essaie de retirer de ton code des instructions telles que `System.out.println()`.
Les tests de l'exercice attendent de la solution qu'elle _renvoie_ des valeurs depuis les méthodes plutôt que de les afficher.

En général, on ajoute ce genre d'instruction pour aider à déboguer le code.
Cependant, une meilleure approche consiste à déboguer le code pendant que l'on exécute un ou plusieurs tests unitaires.
Cela présente l'avantage supplémentaire de permettre de se concentrer sur le débogage d'un cas de test précis.

Voici quelques liens qui expliquent comment déboguer du code Java pendant que l'on exécute des tests unitaires dans différents IDE :

- [Exécuter et déboguer des tests Java dans Visual Studio Code](https://code.visualstudio.com/docs/java/java-testing#_rundebug-test-cases)
- [Déboguer des tests dans IntelliJ IDEA](https://www.jetbrains.com/help/idea/performing-tests.html#RedebugFailedTests)
