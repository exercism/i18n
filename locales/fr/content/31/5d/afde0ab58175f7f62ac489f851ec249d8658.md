# À propos

Les [classes](https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/classes) sont la principale construction qui permet de faire de la programmation orientée objet en F#.

Une classe en F# est composée de ses champs et de ses méthodes. Les champs et les méthodes d'une classe sont appelés ses _membres_.

En F#, les classes se définissent avec le mot-clé `type`. Les méthodes se définissent avec le mot-clé `member` et sont toujours publiques. Pour définir des champs (privés), on peut utiliser des liaisons `let`.

```fsharp
type Shoe() =
    let size = 8

    member this.Describe() = $"This is a size {size} shoe"
```

Les classes sont des modèles qui servent à créer des objets. Pour créer une instance d'une classe, on appelle le nom de la classe comme une fonction. Une instance d'une classe est aussi appelée un _objet_.

On peut accéder aux membres d'un objet avec la notation pointée.

```fsharp
let myShoe = Shoe()
myShoe.Describe()
// => "This is a size 8 shoe"
```
