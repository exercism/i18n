# Utilise un verbe de formatage de fmt pour les chaînes

En Go, on préfère généralement les verbes de formatage propres à un type plutôt que le générique `%%v`.
Il y a deux raisons à cela. D'abord, les verbes de formatage plus spécifiques offrent souvent des options supplémentaires : par exemple, le format `%%f` pour les valeurs de type `float` permet aussi de régler la précision : `%%.2f`.
La seconde raison, c'est que `%%v` accepte n'importe quel type de valeur. Si le type d'une variable change lors d'une réécriture, `%%v` affichera la valeur par défaut de ce type, ce qui n'est peut-être pas le comportement souhaité.
Un verbe de formatage propre à un type fera réagir le linter, ce qui permet de repérer l'erreur avant qu'elle n'arrive en production.
