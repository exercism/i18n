# Visiteur d'un parc d'attractions

## Histoire

Dans cette histoire, tu travailles avec un parc d'attractions pour mettre en place un système d'admission. Les visiteurs arrivent au parc et on mesure leur taille à leur arrivée. En effet, certaines attractions du parc exigent une certaine taille pour des raisons de sécurité.

Certains visiteurs choisissent d'acheter un pass d'attractions, qui leur est alors délivré. La représentation concrète de ce pass n'a pas d'importance pour l'exercice Ruby : s'il existe, il est représenté par un Integer, et par `nil` sinon.

La partie 1 (exercice sur les variables d'instance) porte sur les variables d'instance, les *getters* et les *setters*.

La partie 2 (booléens) porte sur les valeurs booléennes, la véracité, les méthodes de comparaison et les opérateurs logiques.

## Tâches

Exemples de tâches :

- Admets une nouvelle personne (Attendee) dans le parc
- Récupère le pass d'attractions et la taille
- Délivre un pass
- Révoque un pass
- Vérifie si la personne a un pass
- Vérifie si une personne peut monter dans une attraction
- Vérifie si une personne est autorisée à monter dans une attraction
