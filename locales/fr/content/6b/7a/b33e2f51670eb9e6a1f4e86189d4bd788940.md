# Tests

Si tu as téléchargé un exercice avec l'outil CLI, tu devrais voir un fichier Futhark portant le nom de l'exercice ainsi qu'un fichier `test.fut`.
Ce fichier contient tous les cas de test, qui correspondent à ceux exécutés par l'exécuteur de tests lorsque tu téléverses ta solution.
N'hésite pas à ajouter des cas de test supplémentaires pour faire tes expériences.
Cependant, modifier les tests n'a aucune incidence sur le processus d'exécution des tests en ligne.

## Tests en local

Pour lancer les tests d'un exercice, ouvre un terminal dans le répertoire de l'exercice et exécute la commande `futhark test test.fut` (ou `exercism test`).

## Ressources supplémentaires

Pour en savoir plus sur les tests avec Futhark, consulte la documentation de [`futhark test`][test-command].
