# Instructions

Dans cet exercice, tu vas implémenter un ensemble partiel de routines utilitaires pour aider un développeur à nettoyer des noms SqueakyClean.

Au fil des 4 tâches, tu vas construire progressivement la méthode `clean`.
Un nom SqueakyClean valide est composé de zéro ou plusieurs lettres et tirets bas.

Dans tous les cas, la _string_ en entrée est garantie non nulle. Note que la méthode `clean` doit considérer une _string_ vide comme valide.

## 1. Remplace tous les espaces rencontrés par des tirets bas

Implémente la méthode (_static_) `SqueakyClean.clean()` pour remplacer les espaces par des tirets bas. Cela vaut aussi pour les espaces en début et en fin de chaîne.

```java
SqueakyClean.clean("my   Id");
// => "my___Id"
```

## 2. Convertis le `kebab-case` en `camelCase`

Modifie la méthode (_static_) `SqueakyClean.clean()` pour convertir le `kebab-case` en `camelCase`.

```java
SqueakyClean.clean("a-bc");
// => "aBc"
```

## 3. Convertis le leetspeak en texte normal

Modifie la méthode (_static_) `SqueakyClean.clean()` pour convertir le [leetspeak][leet-speak] en texte normal.

Pour simplifier, on ne remplacera que `4`, `3`, `0`, `1` et `7` par `a`, `e`, `o`, `l` et `t`, respectivement.

```java
SqueakyClean.clean("H3ll0 W0rld");
// => "Hello_World"
SqueakyClean.clean("4 73s7");
// => "a_test"
```

## 4. Omets les caractères qui ne sont pas des lettres

Modifie la méthode (_static_) `SqueakyClean.clean()` pour omettre tous les caractères qui ne sont pas des lettres.

```java
SqueakyClean.clean("a$#.b");
// => "ab"
```

[leet-speak]: https://en.wikipedia.org/wiki/Leet
