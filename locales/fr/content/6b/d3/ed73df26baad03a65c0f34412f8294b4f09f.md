# Instructions

Dans cet exercice, tu vas écrire du code pour aider une personne freelance à communiquer avec un chef de projet, en fournissant quelques outils qui calculent rapidement des taux journaliers et mensuels, éventuellement avec une remise donnée.

On commence par établir quelques règles entre la personne freelance et le chef de projet :

- Le taux journalier est 8 fois le taux horaire.
- Un mois compte 22 jours facturables.

Il arrive que la personne freelance applique une remise sur son taux journalier (par exemple pour ses clients les plus fidèles ou pour des clients à but non lucratif).

Les remises sont modélisées par des nombres décimaux représentant un pourcentage, par exemple `25.0` (25 %).

## 1. Calculer le taux journalier à partir d'un taux horaire

Implémente une fonction qui calcule le taux journalier à partir d'un taux horaire :

```haskell
dailyRate 60
-- -> 480.0
```

Le taux journalier renvoyé doit être un double.

## 2. Calculer un prix avec remise

Implémente une fonction qui calcule le prix après une remise.

```haskell
applyDiscount 150 10
-- -> 135.0
```

La valeur renvoyée doit toujours être un double, sans aucun arrondi.

## 3. Calculer le taux mensuel à partir d'un taux horaire et d'une remise

Implémente une fonction qui calcule le taux mensuel et applique une remise :

```haskell
monthlyRate 77 10.5
-- -> 12130
```

Le taux mensuel renvoyé doit être arrondi à l'entier supérieur (on prend le plafond).

## 4. Calculer le nombre de jours travaillés à partir d'un budget, d'un taux horaire et d'une remise

Implémente une fonction qui prend un budget, un taux horaire et une remise, et calcule combien de jours de travail cela couvre.

```haskell
daysInBudget 20000 80 11.0
-- -> 35.1
```

Le nombre de jours renvoyé doit être arrondi par défaut (on prend le plancher) à une décimale.
