# Instructions

Ton équipe travaille sur une application de météorologie.
Elle a défini une API avec différents types et constantes représentant des données météorologiques, voir le fichier `meteorology.go`.

Ta tâche consiste à ajouter des méthodes `String` appropriées à tous les types afin qu'ils implémentent l'interface `Stringer`.

## 1. Implémente l'interface `Stringer` pour le type `TemperatureUnit`

Après quelques discussions, l'équipe a convenu que l'unité de température serait soit `Celsius`, soit `Fahrenheit`.
Les valeurs doivent être formatées comme dans les exemples ci-dessous.

Fais en sorte que le type `TemperatureUnit` implémente l'interface `Stringer` en lui ajoutant une méthode `String`.
Cette méthode doit renvoyer la _string_ `"°C"` si l'unité de température est Celsius ou `"°F"` si l'unité de température est Fahrenheit.

```go
celsiusUnit := Celsius
fahrenheitUnit := Fahrenheit

celsiusUnit.String()
// => °C
fahrenheitUnit.String()
// => °F
fmt.Sprint(celsiusUnit)
// Output: °C
```

## 2. Implémente l'interface `Stringer` pour le type `Temperature`

Les valeurs de température sont composées d'un entier et d'une unité de température.
Elles doivent être formatées comme dans les exemples ci-dessous.

Pour cela, fais en sorte que le type `Temperature` implémente l'interface `Stringer` en lui ajoutant une méthode `String`.
Cette méthode doit renvoyer une _string_ contenant la valeur numérique de la température et l'unité de température séparées par un espace : `<temperature> <unit>` :

```go
celsiusTemp := Temperature{
    degree: 21,
    unit: Celsius,
}
celsiusTemp.String()
// => 21 °C
fmt.Sprint(celsiusTemp)
// Output: 21 °C

fahrenheitTemp := Temperature{
    degree: 75,
    unit: Fahrenheit,
}
fahrenheitTemp.String()
// => 75 °F
fmt.Sprint(fahrenheitTemp)
// Output: 75 °F
```

## 3. Implémente l'interface `Stringer` pour le type `SpeedUnit`

Après de longues discussions, l'équipe a convenu que l'unité de vitesse du vent serait soit `KmPerHour`, soit `MilesPerHour`.
Les valeurs doivent être formatées comme dans les exemples ci-dessous.

Pour cela, fais en sorte que le type `SpeedUnit` implémente l'interface `Stringer` en lui ajoutant une méthode `String`.
Cette méthode doit renvoyer la _string_ `"km/h"` si l'unité de vitesse est exprimée en kilomètres par heure ou `"mph"` si l'unité de vitesse est exprimée en miles par heure :

```go
mphUnit := MilesPerHour
mphUnit.String()
// => mph
fmt.Sprint(mphUnit)
// Output: mph

kmhUnit := KmPerHour
kmhUnit.String()
// => km/h
fmt.Sprint(kmhUnit)
// Output: km/h
```

## 4. Implémente l'interface `Stringer` pour `Speed`

Les valeurs de vitesse du vent sont composées d'un entier et d'une unité de vitesse.
Elles doivent être formatées comme dans l'exemple ci-dessous.

Pour cela, fais en sorte que le type `Speed` implémente l'interface `Stringer` en lui ajoutant une méthode `String`.
Cette méthode doit renvoyer une _string_ contenant la valeur numérique de la vitesse et l'unité de vitesse séparées par un espace : `<speed> <unit>` :

```go
windSpeedNow := Speed{
    magnitude: 18,
    unit: KmPerHour,
}
windSpeedNow.String()
// => 18 km/h
fmt.Sprintf(windSpeedNow)
// Output: 18 km/h

windSpeedYesterday := Speed{
    magnitude: 22,
    unit: MilesPerHour,
}
windSpeedYesterday.String()
// => 22 mph
fmt.Sprint(windSpeedYesterday)
// Output: 22 mph
```

## 5. Implémente l'interface `Stringer` pour le type `MeteorologyData`

Les données météorologiques précisent l'emplacement, la température, la direction du vent, la vitesse du vent et l'humidité.
Elles doivent être formatées comme dans l'exemple ci-dessous :

Pour cela, fais en sorte que le type `MeteorologyData` implémente l'interface `Stringer` en lui ajoutant une méthode `String`.
Cette méthode doit renvoyer les données météorologiques dans le format suivant :

```text
<location>: <temperature>, Wind <wind_direction> at <wind_speed>, <humidity>% Humidity
```

```go
sfData := MeteorologyData{
    location: "San Francisco",
    temperature: Temperature{
        degree: 57,
        unit: Fahrenheit
    },
    windDirection: "NW",
    windSpeed: Speed{
        magnitude: 19,
        unit: MilesPerHour
    },
    humidity: 60
}

sfData.String()
// => San Francisco: 57 °F, Wind NW at 19 mph, 60% Humidity
fmt.Sprint(sfData)
// Output: San Francisco: 57 °F, Wind NW at 19 mph, 60% Humidity
```
