# À propos

## Modules

Le code Gleam est organisé en modules, et chaque fichier correspond à un module Gleam.

Jusqu'ici, on a écrit des fonctions avec la syntaxe `pub fn`, qui définit une fonction accessible publiquement aux autres modules. Les fonctions définies avec `fn` sont privées : elles ne sont accessibles qu'au module dans lequel elles sont définies et ne peuvent pas être utilisées par les autres modules.

```gleam
// This function is public
pub fn add(x, y) {
  x + y
}

// This function is private
fn subtract(x, y) {
  x - y
}
```

Les modules Gleam ont un nom, et ce nom est fondé sur le chemin de leur fichier dans le répertoire `src` ou `test`.

Par exemple, un module défini dans `src\geometry\rectangle.gleam` (sous Windows) ou `src/geometry/rectangle.gleam` (sur les systèmes d'exploitation de type UNIX) s'appellerait `geometry/rectangle`.

## Importe des fonctions depuis d'autres modules

L'accès aux fonctions définies dans d'autres modules se fait par des imports. Toutes les fonctions exposées par un module deviennent accessibles lorsqu'on importe ce module. Mais la façon d'y accéder dépend de la manière dont le module est importé.

Les imports qualifiés sont la valeur par défaut, et pour accéder à une fonction d'un tel module (par exemple la fonction `map` du module `gleam/list`), on préfixe le nom du module (`list.map`).

```gleam
// Import the int module
import gleam/int

pub fn run(x: Int) -> String {
  // Use the to_string function from the int module
  int.to_string(x)
}
```

Par défaut, le nom utilisé pour faire référence au module est la dernière partie de son nom, ici `int`, mais on peut le changer avec le mot-clé `as`.

```gleam
// Import the int module and refer to it as i
import gleam/int as i

pub fn run(x: Int) -> String {
  i.to_string(x)
}
```

Les imports non qualifiés permettent d'accéder directement aux fonctions exposées par ce module, sans préfixe.

```gleam
// Import the to_string function from the int module
import gleam/int.{to_string}

pub fn run(x: Int) -> String {
  to_string(x)
}
```

On préfère les imports qualifiés, car ils montrent plus clairement au lecteur d'où vient une fonction et évitent les conflits de noms.
