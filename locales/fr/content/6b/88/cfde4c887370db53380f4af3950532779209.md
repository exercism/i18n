# Introduction

Unison représente les valeurs vrai et faux avec le type `Boolean`. Il n'y a que deux valeurs : `true` et `false`.

```unison
trueVariable = true
falseVariable = false
```

On peut évaluer des expressions booléennes à l'aide des opérateurs et, ou et non, représentés respectivement par `&&`, `||` et `not`.

```unison
trueVariable = true && true
falseVariable = true && false

trueVariable = false || true
falseVariable = false || false

trueVariable = not false
falseVariable = not true
```
