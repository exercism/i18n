# À propos

En F#, les booléens sont représentés par le type `bool`, dont les valeurs peuvent être soit `true`, soit `false`.

F# prend en charge trois [opérateurs booléens][operators] : `not` (pas), `&&` (ET) et `||` (OU). Les opérateurs `&&` et `||` utilisent une _évaluation en court-circuit_, ce qui signifie que le côté droit de l'opérateur n'est évalué que si nécessaire.

```fsharp
true || false // => true
true && false // => false
```

Les trois opérateurs booléens ont chacun une [_priorité des opérateurs_][precedence] différente. Par conséquent, ils sont évalués dans cet ordre : `not` d'abord, `&&` ensuite, et enfin `||`. Si tu veux « contourner » ces règles, tu peux entourer une expression booléenne de parenthèses (`()`), car les parenthèses ont une priorité encore plus élevée.

```fsharp
not true && false   // => false
not (true && false) // => true
```
