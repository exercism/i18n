# Ajout aux instructions

## Indices

Tu dois implémenter les fonctions `decode` et `encode`, qui décodent et encodent une `String` à l'aide d'un chiffrement affine.
Tu peux utiliser la signature fournie si tu as un doute sur les types, mais ne la laisse pas brider ta créativité.

Cet exercice manipule des données textuelles.
Pour des raisons historiques, le type `String` de Haskell est synonyme de `[Char]`, une liste de caractères.
Pour traiter les données textuelles de façon plus efficace, on peut utiliser le type `Text`.

Comme extension facultative à cet exercice, tu peux

- ajouter `- text` à ta liste de dépendances dans package.yaml.
- importer `Data.Text` [de la manière suivante](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c) :

```haskell
import qualified Data.Text as T
import           Data.Text (Text)
```

- utiliser le type `Text`, par exemple `decode :: Text -> Text`, et faire appel aux combinateurs de `Data.Text` comme `T.pack`.
- consulter la documentation de [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html).
- remplacer toutes les occurrences de `String` par `Text` dans Affine.hs, c'est-à-dire :

```haskell
encode :: (Int, Int) -> Text -> Maybe Text
encode key plainText = ...

decode :: (Int, Int) -> Text -> Maybe Text
decode key cipherText = ...
```

Cette partie est entièrement facultative.
