# À propos

En plus de l'instruction `if`, il existe aussi une instruction `switch` qui permet d'exécuter du code de façon conditionnelle. On l'utilise quand une même variable doit être comparée à plusieurs variantes. Pour une variable x donnée, l'instruction `switch` en Haxe s'écrit de la façon suivante :

```haxe
var a = 2;

switch (a) {
  case 0:
    trace("a is 0");
  case 1:
    trace("a is 1");
  case 2:
    trace("a is 2");
  default:
    trace("a is something else");
}

// a is 2
```

Le cas `default` s'exécute quand aucun autre cas ne correspond.
