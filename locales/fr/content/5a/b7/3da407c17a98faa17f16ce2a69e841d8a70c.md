# Char

`Char` est un type de données en Crystal qui représente un point de code [Unicode][unicode] sur 32 bits.
Sa taille le rend économe en mémoire et lui confère des propriétés spécifiques que les _strings_ n'ont pas.
On les crée avec des guillemets simples (`'`) et ils ne peuvent contenir qu'un seul point de code Unicode.

```crystal
'a' # => 'a'
'a'.class # => Char
```

Il est assez courant de manipuler des `Char` lorsqu'on travaille avec des _strings_ en Crystal, car un certain nombre de méthodes de la classe `String` renvoient des `Char` ou prennent des `Char` en argument.
Par exemple, la méthode [`String#[]`][index] renvoie un `Char`, et la méthode [`String#chars`][chars] renvoie une collection de `Char`.

## Incrémentation et décrémentation

Comme un `Char` est un point Unicode sur 32 bits, il prend en charge l'incrémentation et la décrémentation : si tu as `'a'`, tu peux obtenir `'b'` en ajoutant 1.

```crystal
'a' + 5
# => 'f'

'z' - 25
# => 'a'
```

Il existe aussi une méthode appelée [`Char#succ`][succ], qui renvoie le `Char` suivant dans la table Unicode, et [`Char#pred`][pred], qui renvoie le `Char` précédent dans la table Unicode.

```crystal
'a'.succ
# => 'b'

'z'.pred
# => 'y'
```

## Concaténation

Comme un `Char` ne représente qu'un point Unicode sur 32 bits, deux `Char` ne peuvent pas être concaténés.
Un `Char` ne peut donc être concaténé qu'avec une _string_.

```Crystal
'a' + "bc"
# => "abc"

'a' + 'b'
# => error: expected argument #1 to 'Char#+' to be Int or String, not Char
```

## Méthodes de propriété

Crystal propose quelques méthodes pour obtenir des informations sur un caractère, par exemple pour savoir s'il s'agit d'un chiffre ou d'une lettre, ou s'il est en majuscule ou en minuscule.
Voici une liste de quelques méthodes ; pour une liste complète, consulte l'[API `Char`][char-api] :

| Méthode                          | Description                                                     |
| -------------------------------- | --------------------------------------------------------------- |
| [`Char#number?`][number]         | Renvoie `true` si le `Char` est un chiffre                      |
| [`Char#letter?`][letter]         | Renvoie `true` si le `Char` est une lettre                      |
| [`Char#lowercase?`][lowercase]   | Renvoie `true` si le `Char` est en minuscule                    |
| [`Char#uppercase?`][uppercase]   | Renvoie `true` si le `Char` est en majuscule                    |
| [`Char#ascii?`][ascii]           | Renvoie `true` si le `Char` est un caractère ASCII              |
| [`Char#whitespace?`][whitespace] | Renvoie `true` si le `Char` est un caractère d'espacement       |

## Conversion

### Convertir entre points de code et `Char`

Comme un `Char` est un point Unicode sur 32 bits, tu peux convertir un `Char` en point de code (`Int`) et inversement.
Pour cela, utilise la méthode [`Char#ord`][ord], qui renvoie le point de code du `Char`, ou la méthode [`Int#chr`][chr], qui renvoie le `Char` correspondant au point de code.

```crystal
'a'.ord
# => 97

97.chr
# => 'a'
```

### Convertir entre types

Comme pour les autres types de données, les `Char` disposent de quelques méthodes pour convertir d'un type à l'autre.
La plus courante est la méthode `Char#to_s`, qui convertit le `Char` en `String`. Il existe aussi la méthode `Char#to_i`, qui convertit le `Char` en `Int`, et la méthode `Char#to_f`, qui convertit le `Char` en `Float`.

```crystal
'a'.to_s
# => "a"

'4'.to_i
# => 4

'a'.to_i
# => Error: Invalid integer: a (ArgumentError)
```

## Échappement

Comme pour les _strings_, certains caractères ne peuvent pas s'écrire directement : pour les écrire, il faut les échapper.
On utilise le caractère `\` pour écrire une séquence d'échappement suivie du caractère à échapper.

Voici les caractères spéciaux en Crystal :

| Valeur   | Description                    |
| -------- | ------------------------------ |
| `\a`     | Alerte                         |
| `\b`     | Retour arrière                 |
| `\e`     | Échappement                    |
| `\f`     | Saut de page                   |
| `\n`     | Saut de ligne                  |
| `\r`     | Retour chariot                 |
| `\t`     | Tabulation horizontale         |
| `\v`     | Tabulation verticale           |
| `\\`     | Barre oblique inversée         |
| `\'`     | Guillemet simple               |
| `\"`     | Guillemet double               |
| `\377`   | Caractère ASCII octal          |
| `\xFF`   | Caractère ASCII hexadécimal    |
| `\uFFFF` | Caractère Unicode hexadécimal  |
