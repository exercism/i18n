# Introduction

## Les booléens en R

Les valeurs vraies ou fausses sont représentées par le type `logical`.
Celui-ci ne contient que deux valeurs : `TRUE` et `FALSE`.

```R
TRUE
#> [1] TRUE
FALSE
#> [1] FALSE
typeof(TRUE)
#> [1] "logical"
```

## Les opérateurs booléens

R possède cinq opérateurs booléens, mais seuls trois sont pertinents à ce stade du programme.
Les deux autres deviendront importants lorsqu'on travaillera avec des vecteurs, un sujet abordé dans plusieurs concepts ultérieurs.

`&&` est le « et » booléen.
Il vaut `TRUE` si les expressions des *deux* côtés de `&&` valent `TRUE`.

```R
TRUE && TRUE
#> [1] TRUE
TRUE && FALSE
#> [1] FALSE
```

`||` est le « ou » booléen.
Il vaut `TRUE` si une expression de *l'un ou l'autre* côté de `||` vaut `TRUE`.

```R
TRUE || TRUE
#> [1] TRUE
FALSE || TRUE
#> [1] TRUE
```

`!` est le « non » booléen.
Il échange les valeurs `TRUE` et `FALSE`.

```R
!TRUE
#> [1] FALSE
!FALSE
#> [1] TRUE
```

Pour des expressions plus longues et plus compliquées, il vaut mieux utiliser des parenthèses pour que ton intention soit claire.

```R
(TRUE || FALSE) && (FALSE && TRUE)
#> [1] FALSE

TRUE || FALSE && (FALSE && TRUE)
#> [1] TRUE
```
