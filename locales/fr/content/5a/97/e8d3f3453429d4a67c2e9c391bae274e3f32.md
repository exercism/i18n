# Instructions spécifiques à SQLite

* La colonne **digits** contient une liste d'entiers encodée en JSON.
  Exemple :
  ```json
  [1,0,1,0,1,0]
  ```
* La colonne **result** doit contenir des données encodées en JSON : un objet avec les chiffres sous forme d'entiers ou une description des éventuelles erreurs.
  Exemples :
  ```json
  {"digits":[1,0,1,0,1,0]}
  ```
  ou
  ```json
  {"error":"some error description"}
  ```

## Schéma de la table

```sql
CREATE TABLE IF NOT EXISTS "all-your-base" (
  input_base  INTEGER NOT NULL,
  digits      TEXT    NOT NULL, -- json array
  output_base INTEGER NOT NULL,
  result      TEXT              -- json object
);
```
