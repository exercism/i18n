# À propos

Les fonctions peuvent déclarer des [valeurs par défaut][default-arguments] pour un ou plusieurs arguments.

```elixir
def number(n \\ 13), do: "That's not my favorite"
```

- Quand on compile l'exemple ci-dessus, Elixir crée une définition de fonction pour `number/0` (aucun argument) et `number/1` (un argument).
- Si plusieurs arguments ont des valeurs par défaut, ces valeurs sont appliquées à la fonction de gauche à droite pour combler les arguments manquants.
- Si la fonction prend plusieurs clauses, il est nécessaire d'écrire un [en-tête de fonction][function-header] pour les arguments par défaut.
- N'importe quelle expression peut servir de valeur par défaut.
- Les fonctions anonymes ne peuvent pas avoir d'arguments par défaut.

```elixir
def guess(number \\ 5)
def guess(number) when number != 5, do: false
def guess(number) when number == 5, do: true

guess()
# => true
```
