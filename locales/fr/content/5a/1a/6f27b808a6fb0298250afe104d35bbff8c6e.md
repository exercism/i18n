# Clone le parcours ABAP

## Prérequis

1. Un système ABAP en version 7.4 ou supérieure
2. abapGit v1.115.0 ou supérieur
3. Les autorisations nécessaires pour créer des packages, des programmes et des classes ABAP

## Installe abapGit

Le parcours ABAP avec tous ses exercices est implémenté sous forme de dépôt abapGit. Pour cloner le parcours sur ton système, il faut d'abord installer abapGit.

1. Rends-toi sur [https://github.com/abapGit/abapGit](https://github.com/abapGit/abapGit)
2. Télécharge le fichier `zabapgit_standalone.prog.abap` 
3. Crée le programme `zabapgit_standalone` sur ton système
4. Importe le code source de `zabapgit_standalone.prog.abap` dans le programme `zabapgit_standalone`
5. Active le programme

## Installe le parcours ABAP d'Exercism

### Dépôt en ligne

Utilise cette méthode si ton système est connecté à Internet et a accès à GitHub.com (approche recommandée).

1. Lance abapGit

![Dépôt en ligne abapGit](https://github.com/exercism/abap/blob/main/docs/clone_01.png?raw=true)

2. Dans « Repository Overview », sélectionne « New Online »
3. Saisis les valeurs suivantes
- URL : `https://github.com/exercism/abap`
- Package : `$exer`
- Display Name : `Exercism - ABAP Track`

Remarque : si le nom du package est trop long, comme `$exercism`, tu obtiendras une erreur en essayant d'importer le dépôt. Garde un nom court comme indiqué ci-dessus.

![Dépôt en ligne abapGit](https://github.com/exercism/abap/blob/main/docs/clone_02.png?raw=true)

4. Sélectionne « Create Online Repository ». Tu devrais voir une liste d'objets avec le statut « A » :

![Dépôt en ligne abapGit](https://github.com/exercism/abap/blob/main/docs/clone_03.png?raw=true)

5. Sélectionne « Pull » pour cloner tous les objets sur ton système. Une fois l'opération terminée, tous les objets devraient avoir un statut vide

![Dépôt en ligne abapGit](https://github.com/exercism/abap/blob/main/docs/clone_04.png?raw=true)

### Dépôt hors ligne

Utilise cette méthode si ton système *n'est pas* connecté à Internet.

1. Rends-toi sur [https://github.com/exercism/abap](https://github.com/exercism/abap)
2. Télécharge le fichier ZIP du dépôt 

![Dépôt hors ligne abapGit](https://github.com/exercism/abap/blob/main/docs/clone_10.png?raw=true)

3. Lance abapGit
4. Dans « Repository Overview », sélectionne « New Offline »
5. Saisis les valeurs suivantes
- Repository Name : `Exercism - ABAP Track`
- Package : `$exer`

![Dépôt hors ligne abapGit](https://github.com/exercism/abap/blob/main/docs/clone_11.png?raw=true)

6. Sélectionne « Create Offline Repository »

![Dépôt hors ligne abapGit](https://github.com/exercism/abap/blob/main/docs/clone_12.png?raw=true)

7. Sélectionne « Import ZIP » et choisis le fichier ZIP téléchargé. Tu devrais voir une liste d'objets avec le statut « A » :

![Dépôt hors ligne abapGit](https://github.com/exercism/abap/blob/main/docs/clone_13.png?raw=true)

8. Sélectionne « Pull ZIP » pour cloner tous les objets sur ton système. Une fois l'opération terminée, tous les objets devraient avoir un statut vide

![Dépôt hors ligne abapGit](https://github.com/exercism/abap/blob/main/docs/clone_14.png?raw=true)

## Désinstalle le parcours ABAP d'Exercism

Tu peux supprimer tous les objets de ton système de la façon suivante :

1. Lance abapGit
2. Va dans le dépôt `Execism - ABAP Track`
3. Sélectionne « Advanced > Uninstall »
4. Confirme la suppression de tous les objets et du dépôt

## Dépannage

- En cas de problème de connexion, consulte [SSL Setup](https://docs.abapgit.org/user-guide/setup/ssl-setup.html)
- En cas d'erreur `Package $EXERCISM_DIFFERENCE-OF-SQUARES exceeds ABAP 30-characters name limit`, utilise un nom de package plus court comme `$exer`.
- Après un pull dans ton système ABAP, certains fichiers afficheront des différences. Les différences liées aux caractères de fin de fichier ou aux marques d'ordre des octets peuvent être ignorées.
