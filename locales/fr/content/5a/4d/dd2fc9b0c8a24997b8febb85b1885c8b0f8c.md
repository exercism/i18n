# Introduction

Un bloc est un ensemble d'instructions et de déclarations qui forment une seule unité syntaxique.
Les blocs sont souvent, mais pas toujours, définis entre accolades.
Un bloc peut être imbriqué dans une fonction ou dans un autre bloc.

Une fonction se comporte un peu comme un bloc.
L'identifiant d'une variable définie dans une fonction n'est pas visible en dehors de cette fonction, tout comme l'identifiant d'une variable définie dans un bloc n'est pas visible en dehors de ce bloc.
Deux variables appartenant à deux fonctions différentes peuvent porter le même nom, puisque les deux fonctions ne voient pas l'une dans l'autre, tout comme deux variables appartenant à deux blocs différents peuvent porter le même nom, puisque les deux blocs ne voient pas l'un dans l'autre.
Mais fonctions et blocs ne sont pas identiques.
Une fonction ne peut pas être imbriquée dans une autre fonction, alors qu'un bloc peut être imbriqué dans un autre bloc.

Dans l'exemple suivant, `number` est définie dans la fonction `main`.
`flag` est définie dans le bloc `if`, lui-même imbriqué dans la fonction `main`.
Les variables définies dans un bloc ne sont valides que dans ce bloc.
Ainsi, une tentative de compilation du code produit une erreur de compilation.

```c
#include <stdio.h>

int main() {

  int number = 1;

  if (number == 1) {
      int flag = 1;
      printf("%d", flag);
  }

  // this line generates a compilation error
  // error: 'flag' undeclared (first use in this function)
  printf("%d", flag);
    
}
```

Le message d'erreur peut être déroutant, car `flag` _est_ utilisée plus haut dans la fonction.
Cependant, `flag` est définie dans un bloc à l'intérieur de la fonction.
Le bloc interne peut « voir » la variable `number` de la fonction externe, mais la fonction externe ne peut pas « voir » la variable `flag` définie dans son bloc interne.
Une fois que l'exécution quitte le bloc, la variable `flag` est automatiquement détruite et n'est plus disponible pour le programme.
La fonction `main` elle-même voit l'identifiant `flag` pour la première fois dans la dernière instruction `printf`.
Si la dernière instruction `printf` est supprimée, le programme se compilera et affichera `1` à l'exécution.
En effet, la variable `flag` est valide dans le bloc qui contient la première instruction `printf`.

Depuis `C99`, les instructions `if`, `for`, `while` et `do` sur une seule ligne sont également considérées comme des blocs.
Dans l'exemple suivant, bien que `i` ne soit pas définie entre accolades, elle n'existe que dans le bloc défini par l'instruction `for` et n'est pas visible depuis la fonction `main` externe.

```c
#include <stdio.h>

int main() {

    for (int i = 0, j = 11; i < j; i+=2)
        printf("%d", i);

    // this line generates a compilation error
    // error: 'i' undeclared (first use in this function)
    printf("%d", i);
    
}
```

Si la dernière instruction `printf` est supprimée, le programme se compilera et affichera `0 2 4 6 8 10 ` à l'exécution.
Certains langages, comme Go et Rust, affirment explicitement que les instructions conditionnelles et les boucles sur une seule ligne constituent un bloc.
Ils exigent que ces instructions sur une seule ligne soient quand même entourées d'accolades.
