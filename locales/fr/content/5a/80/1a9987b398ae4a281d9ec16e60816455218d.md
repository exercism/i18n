# Introduction

Elixir propose de nombreuses fonctions pour manipuler les bits, que l'on trouve dans le _module Bitwise_.

- `band/2` : ET bit à bit
- `bsl/2` : décalage à gauche bit à bit
- `bsr/2` : décalage à droite bit à bit
- `bxor/2` : OU exclusif bit à bit
- `bor/2` : OU bit à bit
- `bnot/1` : NON bit à bit

Voici un exemple d'utilisation d'une fonction bit à bit :

```elixir
Bitwise.bsl(1, 3)
# => 8
```

Toutes les fonctions bit à bit ne fonctionnent que sur des entiers.

Si tu utilises Elixir 1.9 ou une version antérieure, il te faudra appeler `require Bitwise` au début de la définition du module pour pouvoir utiliser le module _Bitwise_.
