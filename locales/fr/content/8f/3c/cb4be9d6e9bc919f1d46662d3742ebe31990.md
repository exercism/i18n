# Instructions

C'est la Saint-Valentin. Ton ou ta partenaire a quelques idées d'activités et te demande de les noter : `yes`, `no` ou `maybe`.

Les activités sont représentées par des tableaux de 2 éléments `{ tag value }`, où `tag` vaut l'un de `board-game`, `chill`, `movie`, `restaurant` ou `walk`.

| activité                        | forme                          |
| ------------------------------- | ------------------------------ |
| Jouer à un jeu de société       | `{ board-game f }`             |
| Se détendre                     | `{ chill f }`                  |
| Regarder un film du genre `genre` | `{ movie genre }`            |
| Manger dans un restaurant de type `cuisine` | `{ restaurant cuisine }` |
| Marcher `km` kilomètres         | `{ walk km }`                  |

Le genre fait partie de `crime`, `horror`, `romance` ou `thriller`. La cuisine est `korean` ou `turkish`.

## 1. Évalue la cuisine

Définis `rate-restaurant` pour qu'elle retire une cuisine de la pile et renvoie ton approbation :

- `korean` → `yes`
- `turkish` → `maybe`

```factor
korean rate-restaurant .   ! => yes
turkish rate-restaurant .  ! => maybe
```

## 2. Évalue le genre du film

Définis `rate-movie` pour qu'elle prenne un genre et renvoie :

- `romance` → `yes`
- tout le reste → `no`

```factor
romance rate-movie .   ! => yes
horror rate-movie .    ! => no
```

## 3. Évalue la promenade

Définis `rate-walk` pour qu'elle prenne un nombre de kilomètres et renvoie :

- plus de `11` → `yes`
- plus de `6`, jusqu'à `11` → `maybe`
- sinon → `no`

```factor
12 rate-walk .   ! => yes
8 rate-walk .    ! => maybe
3 rate-walk .    ! => no
```

## 4. Évalue l'activité

Définis `rate-activity` pour qu'elle retire de la pile une activité `{ tag value }` et renvoie ton approbation. Réutilise les fonctions auxiliaires ci-dessus :

- `board-game`, `chill` → toujours `no`
- `movie` → délègue à `rate-movie`
- `restaurant` → délègue à `rate-restaurant`
- `walk` → délègue à `rate-walk`

```factor
{ restaurant turkish } rate-activity .   ! => maybe
{ movie horror } rate-activity .         ! => no
{ walk 12 } rate-activity .              ! => yes
{ board-game f } rate-activity .         ! => no
```

## 5. Compte les approbations

Définis `approval-counts` pour qu'elle prenne un tableau d'activités et renvoie un tableau `{ yes-count maybe-count no-count }` de 3 éléments indiquant combien d'activités ont été notées de chaque façon.

```factor
{ { restaurant korean } { restaurant turkish } { walk 3 } { movie romance } }
approval-counts .
! => { 2 1 1 }
```
