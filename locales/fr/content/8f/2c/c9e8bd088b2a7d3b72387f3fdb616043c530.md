# Indices

## 1. Configure les types d'utilisateur et les permissions.

- Pour traiter chaque énumérateur `AccountStatus`, tu peux utiliser une instruction `if`, mais une [instruction `switch`][switch] est une excellente alternative.


## 2. Ne fais la promotion des trolls que vers d'autres trolls.

- Tu peux comparer les énumérations comme n'importe quel autre type avec les opérateurs `!=` et `==`.

## 3. Vérifie les permissions des différents utilisateurs.

- Si tu résous la tâche avec une instruction `switch`, les [enchaînements de cas][fallthrough] peuvent t'être utiles.
- Tu peux utiliser des [étiquettes séquentielles][fallthrough] et l'étiquette [`default`][switch] pour regrouper les permissions.

## 4. Accorde l'accès au jeu et associe les joueurs.

- Ce qui t'importe avant tout, ce sont les comptes `guest` et `troll` ; pour les autres combinaisons, tu n'as pas besoin de scinder la logique.

## 5. Mets en place une file de priorité.

- Si tu ordonnes correctement ton énumération `AccountStatus`, tu peux utiliser `static_cast<int>` pour comparer les énumérateurs de façon compacte.

[switch]: https://www.learncpp.com/cpp-tutorial/switch-statement-basics/
