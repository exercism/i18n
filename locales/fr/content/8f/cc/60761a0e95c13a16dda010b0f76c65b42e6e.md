# Permissions des comptes sur le site

## Histoire

Dans cet exercice, tu vérifieras les permissions des comptes utilisateurs d'un forum internet. Le forum prend en charge trois permissions différentes :

- Lire
- Écrire
- Supprimer

Il existe trois types de comptes, chacun avec des permissions par défaut différentes :

- Invités : peuvent lire les publications.
- Utilisateurs : peuvent lire et écrire des publications.
- Modérateurs : peuvent lire, écrire et supprimer des publications.

Il arrive parfois que des permissions individuelles soient modifiées, par exemple pour donner à un compte invité la permission d'écrire aussi des publications.

## Tâches

Voici des exemples de tâches qui correspondent à l'exercice sur les permissions du site :

- Obtenir les permissions par défaut d'un type de compte
- Accorder une permission
- Révoquer une permission
- Vérifier une permission
