# Introduction

Utiliser `try..rescue` est une construction puissante pour intercepter les erreurs lorsqu'elles se produisent. Intercepter les erreurs permet aux fonctions de renvoyer des valeurs définies quand c'est nécessaire. La construction `try..rescue` nous offre aussi deux fonctionnalités supplémentaires que l'on peut utiliser :

- le bloc `else`
  - Quand le bloc try réussit, le résultat est comparé à ce bloc.
- le bloc `after`
  - Que le bloc try réussisse ou lève une erreur, le code du bloc `after` est toujours exécuté tant que le programme tourne à ce moment-là.
  - Le résultat du bloc `after` n'est pas renvoyé à la portée appelante.

```elixir
try do
  :a
rescue
  _ -> :error
else
  :a -> :success
after
  :some_action
end

# => :success
```
