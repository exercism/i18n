## Instructions

Ta tâche consiste à générer les labyrinthes parfaits pour Mickey et Minerva, c'est-à-dire ceux qui n'ont qu'une seule solution et aucune section isolée.
Voici ce que tu dois savoir :

- Le labyrinthe a une forme rectangulaire, avec une ouverture au début et à la fin.
- Le labyrinthe comporte des salles et des passages, qui se croisent à angle droit.
- Le programme doit accepter deux paramètres : rows et columns. La taille du labyrinthe doit être comprise entre 5 et 100 cellules.
- Un labyrinthe de `x` colonnes de large et `y` lignes de haut doit faire `2x + 1` caractères de large et `2y + 1` caractères de haut.
- Si aucun seed n'est fourni, génère un labyrinthe aléatoire. Si le même seed est fourni plusieurs fois, le labyrinthe obtenu doit être identique à chaque fois.
- Utilise des [caractères de dessin de cadre][Box-drawing] pour dessiner les murs, et un symbole de flèche (⇨) pour l'entrée à gauche et la sortie à droite.

Il est temps de créer des labyrinthes parfaits pour ces souris aventurières !

### Exemples

1. Le petit labyrinthe carré de 5x5 cellules (ou 11x11 caractères)
```text
	┌───────┬─┐
	│       │ │
	│ ┌─┬── │ │
	│ │ │   │ ⇨
	│ │ │ ──┤ │
	⇨ │ │   │ │
	┌─┤ └── │ │
	│ │     │ │
	│ │ ────┘ │
	│         │
	└─────────┘
```
2. Le labyrinthe rectangulaire de 6x18 cellules
```text
	┌───────────┬─────────┬───────────┬─┐
	│           │         │           │ │
	│ ┌───────┐ │ ┌─┐ ──┐ └───┐ ┌───┐ │ │
	│ │       │ │ │ │   │     │ │   │   ⇨
	│ └─┐ ┌─┐ │ │ │ ├── ├───┐ │ │ ──┼── │
	│   │ │ │   │   │   │   │ │ │   │   │
	└── │ │ ├───┴───┤ ┌─┘ ┌─┘ │ ├── │ ──┤
	⇨   │   │       │ │   │   │ │   │   │
	┌─┬─┴─┐ └─┐ ┌─┐ │ └─┐ │ ┌─┘ │ ──┴─┐ │
	│ │   │   │ │ │ │   │   │   │     │ │
	│ │ │ └── │ │ │ └── │ ──┘ ┌─┘ ──┐ │ │
	│   │       │       │     │     │   │
	└───┴───────┴───────┴─────┴─────┴───┘
```
