# Indices

## Général

Ce sont toutes des tâches courtes et simples.
Si tu te retrouves à écrire plusieurs lignes de code dans une fonction, arrête-toi et lis l'introduction.

## 1. Supprime les pistes en double

- Rappelle-toi que supprimer les doublons ne laisse que les entrées uniques.

## 2. Vérifie si une piste a déjà été ajoutée

- Il s'agit ici de vérifier l'appartenance, ce que l'on a déjà vu dans les concepts précédents.

## 3. Ajoute des pistes

- Renvoie les pistes qui se trouvent dans la playlist ou dans les pistes à ajouter.

## 4. Supprime des pistes

- Les pistes qui se trouvent dans la playlist mais pas dans les pistes à supprimer.

## 5. Compare les playlists

- Les pistes qui se trouvent dans les deux playlists.
