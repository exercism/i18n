# Intégration des employés dans la base de données

## Énoncé du problème

ABC Corp prévoit de conserver dans une base de données toutes les informations sur les paiements de menues dépenses effectués auprès des employés. Tu aides le service financier d'ABC Corp à mettre cela en place. Comme ABC Corp développe ses activités, l'ajout de nouveaux employés au système est une exigence courante en raison des nouvelles embauches.

Ta tâche consiste à ajouter les détails du nouvel employé fournis à la table `Employee` de la base de données, puis à renvoyer la valeur de la colonne `employee_id` générée automatiquement, sans exécuter une autre requête sur la base de données pour la retrouver. Si une erreur se produit pendant l'exécution, la valeur `-1` doit être renvoyée.

## Détails de la base de données

Utilise la base de données H2 fournie pour ce problème.

> Le fichier de base de données d'exemple est `gofigure.mv.db`, et le nom de la base de données est `gofigure`. Il se trouve dans le dossier `db`.

Les tables suivantes sont déjà présentes dans la base de données H2 d'exemple, avec quelques données d'exemple. Les noms de colonnes et les types de données sont indiqués ci-dessous.

**Nom de la table** : `Employee`

| **Colonnes :**      | type |
| -----------       | ----------- |
| `employee_id`     | entier, clé primaire auto-incrémentée       |
| `name`            | chaîne de caractères        |
| `city`            | chaîne de caractères        |
| `department`      | chaîne de caractères        |
| `age`             | entier        |

**Nom de la table** : `Payment`

| **Colonnes :**      | type |
| -----------       | ----------- |
| `payment_id`      | entier, clé primaire auto-incrémentée       |
| `date`            | date        |
| `amount`          | décimal        |
| `employee_id`     | entier        |
| `reason`          | chaîne de caractères        |

* Le fichier de base de données est `gofigure.mv.db`. Utilise l'URL JDBC suivante : `jdbc:h2:file:/path/to/db/file`
* Nom d'utilisateur : `root`
* Mot de passe : `root`

## Contraintes

* Utilise le fichier de base de données H2 fourni dans le dossier `db` pour valider les requêtes et l'exemple Ballerina
* Utilise l'approche des _params_ de dépendance Maven pour ajouter le pilote de base de données H2 comme dépendance de plateforme dans ton Ballerina.toml
* N'exécute pas une autre requête sur la base de données pour retrouver l'identifiant généré automatiquement


## Environnement de test

* Tu peux lancer les tests avec `bal test`, ce qui exécutera les tests sur la base de données d'exemple fournie.
