# L'opérateur de résolution de portée

L'opérateur de résolution de portée (`::`) permet de référencer une classe afin d'accéder à ses constantes de nom, à ses propriétés statiques ou à ses méthodes statiques.

```php
class MyClass
{
  public const MY_VALUE = 1;
}

// MyClass::class => "MyClass"
// MyClass::MY_VALUE => 1
```

## Utilise `self` et `static` avec l'opérateur de résolution de portée

Il peut arriver qu'un objet ait besoin de référencer sa propre portée. Pour faciliter cela, le mot-clé `self` permet à une classe de référencer sa propre portée. L'usage du mot-clé `self` découple la classe de son propre nom, ce qui facilite la maintenance du code au fil du temps.

```php
class MyClass
{
  public const MY_VALUE = 1;

  public function getMyValue(): int
  {
    return self::MY_VALUE;
  }
}

// (new MyClass)->getMyValue() => 1
```

Utilise le mot-clé `static` avec l'opérateur de résolution de portée pour effectuer une « liaison tardive » de la référence vers la classe descendante courante.

```php
// Update MyClass:
class MyClass
{
  public const MY_VALUE = 1;

  public function getMyValue(): int
  {
    return static::MY_VALUE;
  }
}
```

## Utilise `parent` avec l'opérateur de résolution de portée

Le mot-clé `parent` sert à référencer une constante, une propriété ou une méthode de la classe parente. On l'utilise couramment pour appeler le constructeur parent lorsqu'un objet est instancié :

```php
class ChildClass extends ParentClass
{
  public function __construct(): void
  {
    parent::__construct();
  }
}
```

## Mises en garde

### Visibilité des constantes, des propriétés et des méthodes

L'opérateur de résolution de portée suit toujours les règles définies par les modificateurs de visibilité `public`, `private` et `protected`.
