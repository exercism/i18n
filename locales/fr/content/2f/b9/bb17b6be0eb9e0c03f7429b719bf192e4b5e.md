# Exécuteurs de tests

Un exécuteur de tests est un logiciel qui exécute les tests d'un exercice sur le code d'un apprenant.

Les exécuteurs de tests nous apportent deux avantages :

1. Ils permettent d'écrire du code directement dans le navigateur, où l'apprenant peut itérer sur une solution en voyant si les tests réussissent ou échouent.
2. Ils nous permettent d'indiquer aux mentors si le code d'un apprenant « fonctionne » ou non.

## Contribue aux exécuteurs de tests

Chaque langage possède son propre exécuteur de tests, écrit dans ce langage.
Le site web joue le rôle d'orchestrateur entre les exécuteurs de tests et les soumissions des apprenants.

Chaque exécuteur de tests se trouve dans l'organisation GitHub d'Exercism, dans un dépôt nommé `<track_slug>-test-runner` (par exemple [`exercism/ruby-test-runner`](https://github.com/exercism/ruby-test-runner)).
Tu peux consulter les exécuteurs de tests existants [ici](https://github.com/search?q=topic%3Aexercism-test-runner&type=repositories).

Si tu souhaites t'impliquer pour aider sur un exécuteur de tests existant, ouvre une _issue_ dans son dépôt en demandant où tu peux apporter ton aide.
Si tu souhaites créer un exécuteur de tests pour un langage qui n'en a pas encore, suis les instructions pour [créer un exécuteur de tests](/docs/building/tooling/test-runners/creating-from-scratch).
