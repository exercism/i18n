# Instructions complémentaires

## Format du plateau

Le plateau est représenté par une _string_ terminée par un caractère nul, avec un caractère de saut de ligne à la fin de chaque ligne.

Voici un exemple : `"X  \n XO\nOX \n"`

## Registres

| Registre | Utilisation | Type       | Description                                                              |
| -------- | ----------- | ---------- | ------------------------------------------------------------------------ |
| `$a0`    | entrée      | adresse    | _string_ d'entrée terminée par un caractère nul                          |
| `$v0`    | sortie      | entier     | état de la partie (`1` = `ongoing`, `2` = `draw`, `3` = `win`, `-1` = `error`) |
| `$t0-9`  | temporaire  | quelconque | pour le stockage temporaire                                              |
