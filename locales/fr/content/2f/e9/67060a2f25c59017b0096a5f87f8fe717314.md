# Installation

## Installe tclsh

Le seul outil nécessaire est l'interprète TCL, `tclsh`.

Pour Windows, le meilleur endroit pour récupérer Tcl est [l'installateur Tcl de Magicsplat][magicsplat].

Pour MacOS et les systèmes d'exploitation de type Unix, `tclsh` est déjà installé.
En général, la version installée sera 8.6.*quelque chose*.
Pour installer la version stable actuelle, la 9.0 :
 - avec MacOS, utilise [Homebrew][brew].
 - sous Linux, vérifie ton gestionnaire de paquets.
 - ou [télécharge les sources][download] et [compile-les][build].

Pour résoudre les exercices via l'interface web d'Exercism, l'exécuteur de tests (en février 2023) utilise la version 8.7a4 de Tcl.

## Utilise le shell interactif tclsh

Il est courant de lancer une session interactive [`tclsh`][tclsh] pour tester des commandes pendant que tu écris du code.
Cependant, tclsh ne fournit qu'un interprète REPL très basique, sans édition de ligne de commande ni historique des commandes.
Pour une expérience améliorée, il existe un programme appelé `rlwrap` qui ajoute les fonctionnalités de readline :

```bash
rlwrap tclsh
```

C'est tellement pratique que tu voudras l'utiliser tout le temps : ajoute ceci à ton ~/.bashrc

```bash
command -v rlwrap && alias tclsh='rlwrap tclsh'
```

Pour installer rlwrap :
 - avec MacOS, utilise [Homebrew][brew].
 - sous Linux, vérifie ton gestionnaire de paquets.
 - ou [télécharge les sources][rlwrap-download] et [compile-les][rlwrap-build].

## Quelle version utiliser ?

La version stable actuelle est la 9.0.
Comme indiqué plus haut, la version 8.6 est encore largement déployée.

Tu peux vérifier quelle version de `tclsh` tu as installée en exécutant la commande suivante :

```bash
echo 'puts [info patchlevel]' | tclsh
```
