# Introduction

Clojure utilise le type `java.lang.Character` sous-jacent, une quantité de 16 bits qui représente les plus petites composantes adressables du texte.
Plusieurs `char` peuvent composer une _string_ comme `"word"`, ou bien les `char` peuvent être traités indépendamment. Leurs littéraux s'écrivent comme `\a \b \c`.

Les `char` de Clojure prennent en charge l'encodage Unicode UTF-16, donc en plus du jeu de caractères latins, pratiquement tous les systèmes d'écriture utilisés dans le monde peuvent être représentés, par exemple la lettre grecque `'β'`.

Il existe de nombreuses méthodes de bibliothèque pour inspecter et manipuler les `char`. Elles sont accessibles par interop en tant que méthodes de la classe `Character`. Clojure inclut aussi une bibliothèque d'utilitaires pour les _strings_ intégrée, `clojure.string`, qui offre de nombreuses fonctions puissantes pour manipuler les caractères.
