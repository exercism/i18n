# Introduction

Les listes de mots-clés sont une structure de données clé-valeur.

```elixir
[month: "April", year: 2018]
```

Les listes de mots-clés sont des listes de [tuples][exercism-tuples] `{key, value}`, et on peut aussi les écrire sous cette forme, mais la syntaxe plus courte est plus répandue.

```elixir
[month: "April"] == [{:month, "April"}]
# => true
```

Les clés d'une liste de mots-clés doivent être des [atomes][exercism-atoms], mais les valeurs peuvent être n'importe quoi. Chaque clé peut être utilisée plusieurs fois. Les paires clé-valeur d'une liste de mots-clés sont ordonnées.

On peut manipuler les listes de mots-clés avec les mêmes approches que pour les listes, ou utiliser le module `Keyword`.

[exercism-tuples]: https://exercism.org/tracks/elixir/concepts/tuples
[exercism-atoms]: https://exercism.org/tracks/elixir/concepts/atoms
