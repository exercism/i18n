## Arguments optionnels

```julia-repl
julia> f(a, b=1) = a + b
f (generic function with 2 methods)
```

est équivalent à

```julia-repl
julia> f(a, b) = a + b
f (generic function with 1 method)

julia> f(a) = f(a, 1)
f (generic function with 2 methods)
```

Dans la réponse de la REPL, on peut voir que la première définition définit deux méthodes à la fois.
