# Instructions supplémentaires

## Registres

| Registre | Utilisation | Type       | Description                                                        |
| -------- | ----------- | ---------- | ------------------------------------------------------------------ |
| `$a0`    | entrée      | adresse    | _string_ d'entrée terminée par un caractère nul                     |
| `$v0`    | sortie      | booléen    | validité de la _string_ d'entrée (`0` = `false`, `1` = `true`)      |
| `$t0-9`  | temporaire  | quelconque | utilisé pour le stockage temporaire                                 |
