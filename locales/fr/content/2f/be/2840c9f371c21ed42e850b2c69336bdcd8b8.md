# Introduction

## _Strings_

En C#, `string` est un objet qui représente du texte immuable sous la forme d'une séquence de caractères Unicode (lettres, chiffres, ponctuation, etc.). Les guillemets doubles servent à définir une instance de `string` :

```csharp
string fruit = "Apple";
```

### Méthodes

On manipule les _strings_ en appelant leurs [méthodes intégrées][docs-string-methods].
Par exemple, pour supprimer les espaces blancs d'une _string_, tu peux utiliser la [méthode Trim][tutorial-docs.microsoft.com-trim-white-space] comme ceci :

```csharp
string name = " Jane "
name.Trim()
// => "Jane"
```

Une fois qu'une _string_ a été construite, sa valeur ne peut plus jamais changer.
Toutes les méthodes qui semblent modifier une _string_ renvoient en réalité une nouvelle _string_.

### Concaténation

On peut concaténer (ajouter) plusieurs _strings_ ensemble. La façon la plus simple d'y parvenir est d'utiliser l'opérateur `+`.

```csharp
string name = "Jane";
"Hello " + name + "!";
// => "Hello Jane!"
```

### Formatage

Pour tout formatage de _string_ plus complexe qu'une simple concaténation, l'interpolation de _string_ est préférée. Pour utiliser l'interpolation dans une _string_, fais-la précéder du symbole dollar (`$`). Tu peux ensuite utiliser des accolades (`{}`) pour accéder aux variables à l'intérieur de ta _string_.

```csharp
string name = "Jane";
$"Hello {name}!";
// => "Hello Jane!"
```
