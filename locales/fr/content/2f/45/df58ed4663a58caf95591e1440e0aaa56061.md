# Réutilise le code de Describe two params

La méthode `describe(Character, Destination)` devrait réutiliser la logique implémentée dans `describe(Character, Destination, TravelMethod)` ou dans les méthodes individuelles `describe(Character)`, `describe(Destination)` et `describe(TravelMethod)`.
Réutiliser des méthodes existantes peut aider à rendre le code plus facile à maintenir.
