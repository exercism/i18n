# Introduction

Le C est un langage à typage statique, ce qui signifie que tout possède un type au moment de la compilation.
Choisir un nom pour une variable et lui donner un type s'appelle déclarer une variable.

Une variable se déclare en spécifiant explicitement son type.
Le nom d'une variable commence par une lettre ou un tiret bas.
Certains noms ne peuvent pas être utilisés, car ils sont réservés [pour les mots-clés][reserved-keywords] ou [pour d'autres identifiants][reserved-identifiers].

Définir ou mettre à jour la variable se fait par affectation.
Lui affecter une valeur définit cette variable.
Définir la variable est aussi appelé initialisation.

```c
int foo;      // Declare an integer named var
foo = 10;     // Define the variable

int bar = 15; // Both can also be done in a single statement
```

La valeur d'une variable peut être affectée et mise à jour à l'aide de l'opérateur d'affectation simple `=`.
Une fois définie, le type d'une variable ne peut plus jamais changer.

```c
int foo = 10; // Assign initial value
foo = 25;     // Update to new value

foo = false;  // Compiler error when assigning value of a different type
```

Le C est un langage procédural impératif.
Tout calcul s'effectue sous la forme d'une série d'instructions qui font partie d'une fonction ou de plusieurs fonctions.

Chaque fonction peut prendre zéro ou plusieurs paramètres.
Lorsque l'on définit une fonction, tous les paramètres ainsi que la valeur de retour doivent être typés explicitement.
Les valeurs sont renvoyées par les fonctions à l'aide du mot-clé `return`.
Par défaut, les fonctions ont une classe de stockage externe, ce qui signifie qu'elles existent pendant toute la durée de vie du programme et peuvent être visibles à l'extérieur du fichier.
Pour éviter cela, on peut ajouter le mot-clé `static` afin de spécifier une visibilité interne.

```c
static int add(int x, int y) {
  return x + y;
}
```

Dans l'exemple ci-dessus, les variables `x` et `y` ne peuvent être utilisées qu'à l'intérieur de la fonction, c'est-à-dire qu'elles ont une portée de fonction.
La portée est l'idée que la valeur associée à un nom (d'un élément de programme) n'est accessible que dans la « zone » de code où elle est définie.
Les principales zones de code en C sont :

- fichier
- fonction
- bloc (comme dans les boucles et les autres constructions)

On appelle une fonction en spécifiant son nom et en passant des arguments pour chacun de ses paramètres.

```c
int sum = add(1, 2);
```

Le C prend en charge deux types de commentaires.
Les commentaires sur une seule ligne sont précédés de `//` (depuis C99) et les commentaires multi-lignes sont insérés entre `/*` et `*/`.
