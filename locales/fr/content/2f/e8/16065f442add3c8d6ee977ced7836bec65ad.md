# Indices

## Général

- Lis la documentation sur le [comportement `Access`][access-behaviour].

## 1. Extrais des données d'une structure imbriquée de _maps_

- Commence par tokeniser le chemin, qui est une _string_, pour le rendre exploitable. Tu peux t'aider des [fonctions du module `String`][string-module].
- Écris une fonction récursive qui parcourt la structure imbriquée de _maps_ pour récupérer la valeur ou renvoyer `nil`.

## 2. Réécris en utilisant les fonctions incluses

- Parcours les différentes [fonctions du module `Kernel`][kernel-module] pour en trouver une qui pourrait raccourcir ou simplifier ton approche.

[string-module]: https://hexdocs.pm/elixir/String.html#functions
