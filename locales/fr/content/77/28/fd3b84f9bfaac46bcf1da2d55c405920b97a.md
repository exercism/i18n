# Instructions supplémentaires

## Instructions spécifiques au parcours

Tu dois définir deux verbes appelés `allergic_to` et `list`.

## Entrées

1. Le verbe `allergic_to` est une **dyade** où :

    - **Argument gauche** : une _string_ qui contient le nom de l'allergène.
    - **Argument droit** : le score obtenu.

1. Le verbe `list` est une **monade** où :

    - L'unique argument est le score obtenu.

Tes verbes seront appelés avec ces arguments, comme ceci :

```j
  'cats' allergic_to 255
  list 5
```

## Sorties

La sortie du verbe `allergic_to` est un **booléen**

La sortie de `list` est une **liste de boîtes**
