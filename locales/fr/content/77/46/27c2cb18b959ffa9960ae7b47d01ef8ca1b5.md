# Indices

## Général

- Le paquet [`roc-random`](https://github.com/kili-ilo/roc-random) est disponible sous l'alias `random` dans l'application de test.
  Le _stub_ importe `random.Random`.

- Un `Random.Generator(a)` décrit comment générer une valeur de type `a`.

- Utilise `Random.list` pour combiner les tirages et `Random.map` pour transformer leurs résultats.

- `Random.step(state, generator)` renvoie `{ value, state }` ; fais passer l'état mis à jour d'un groupe simulé à l'autre pour ne pas répéter le même échantillon.
