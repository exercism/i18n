# Introduction

## Fonctions

En Gleam, on définit les fonctions avec la syntaxe `pub fn`.

```gleam
pub fn add(x: Int, y: Int) -> Int {
  x + y
}
```

Cette fonction prend deux arguments, tous deux de type `Int`, et renvoie une valeur de type `Int`. Il n'existe pas de mot-clé `return` en Gleam : la valeur de la dernière expression d'une fonction est toujours renvoyée _implicitement_.

Les annotations de type des arguments et le type de retour sont facultatifs, et Gleam vérifiera toujours entièrement les types de ton code. En général, les développeurs Gleam ajoutent des annotations de type à leurs fonctions par souci de clarté, mais tu peux les omettre si tu le souhaites.

```gleam
pub fn add(x, y) {
  x + y
}
```

On peut appeler une fonction avec la syntaxe `function_name(argument1, argument2)`.

```gleam
pub fn double(x: Int) -> Int {
  // Call the add function defined above
  add(x, x)
}
```

## Variables

En Gleam, on définit les variables avec la syntaxe `let name = expression`.

```gleam
pub fn main() {
  let count = 1
}
```

Les variables peuvent être déclarées avec des annotations de type. Comme pour les arguments de fonction, celles-ci sont facultatives, même si la plupart des développeurs Gleam omettent les annotations de type des variables par souci de concision.

```gleam
pub fn main() {
  let count: Int = 1
}
```

## Littéraux de chaîne de caractères

En Gleam, les _strings_ s'écrivent entre guillemets doubles.

```gleam
pub fn greeting() {
  "Hello, world!"
}
```

## Commentaires dans le code

Les commentaires permettent de laisser des notes aux autres développeurs qui lisent le code source. En Gleam, les commentaires tiennent sur une seule ligne et sont précédés de `//`.

```gleam
pub fn main() {
  // This is a comment
  let x = 1
}
```
