# À propos

En Elixir, les fonctions peuvent être appelées dynamiquement.

Tous les noms de modules sont des atomes. Tous les noms de modules Elixir sont automatiquement préfixés par `Elixir.` lors de la compilation.

```elixir
is_atom(Enum)
# => true
Enum == Elixir.Enum
# => true
```

Elixir peut déterminer la fonction à appeler au moment de l'exécution, en se servant du nom du module pour effectuer une recherche. La recherche peut se faire dynamiquement si le nom du module est lié à une variable.

```elixir
defmodule MyModule do
  def message(), do: "My message"
end

atom = MyModule
atom.message()
# => "My message"
```
