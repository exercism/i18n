# Introduction

Il arrive que l'on ait besoin de voir une séquence comme une série de *morceaux* plutôt qu'élément par élément. Les vocabulaires [`grouping`][grouping], [`splitting`][splitting] et [`splitting.monotonic`][splitting.monotonic] t'offrent quatre façons de faire.

## `group` : des morceaux disjoints de taille *n*

```
group ( seq n -- groups )
```

```factor
USING: grouping ;

{ 1 2 3 4 5 6 7 } 3 group .
! => { { 1 2 3 } { 4 5 6 } { 7 } }
```

Si la longueur de la séquence n'est pas un multiple de *n*, le dernier groupe est plus court que *n*.

## `clump` : une fenêtre glissante avec chevauchement, de taille *n*

```
clump ( seq n -- clumps )
```

```factor
USING: grouping ;

{ 1 2 3 4 5 } 2 clump .
! => { { 1 2 } { 2 3 } { 3 4 } { 4 5 } }
```

Si la séquence est plus courte que *n*, le résultat est vide.

## `split-when` : découpe là où un prédicat se déclenche

```
split-when ( seq quot: ( elt -- ? ) -- pieces )
```

```factor
USING: splitting ;

{ 1 2 0 3 4 0 5 } [ zero? ] split-when .
! => { { 1 2 } { 3 4 } { 5 } }
```

Chaque élément fait l'objet de son propre appel au prédicat ; les éléments qui renvoient vrai sont les *points de rupture* et ne sont pas conservés dans le résultat.

## `monotonic-split` : découpe les séries là où le test sur une paire adjacente échoue

```
monotonic-split ( seq quot: ( a b -- ? ) -- pieces )
```

```factor
USING: splitting.monotonic ;

{ 1 1 2 2 2 3 } [ = ] monotonic-split .
! => { { 1 1 } { 2 2 2 } { 3 } }
```

Le prédicat s'applique à des *paires adjacentes*. Tant qu'il renvoie vrai, la série se poursuit ; dès qu'il renvoie `f`, une nouvelle pièce commence. Avec `[ = ]`, tu obtiens des séries d'éléments égaux ; avec `[ <= ]`, des séries non décroissantes ; et ainsi de suite.

## Quand utiliser l'un plutôt que l'autre

- **`group`/`clump`** : tu connais la *taille* que tu veux.
- **`split-when`** : tu sais à quoi ressemble un *élément de rupture*.
- **`monotonic-split`** : tu sais ce qui fait que deux éléments adjacents *vont encore ensemble*.
