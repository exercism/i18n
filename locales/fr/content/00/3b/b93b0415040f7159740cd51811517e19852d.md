# Tests

Pour utiliser l'exécuteur de tests, tu dois avoir correctement [installé Godot][installation].

## Lance les tests

L'[exécuteur de tests][test runner] sert à charger et à tester les solutions.
Pour t'en servir, télécharge-le en local puis lance-le avec `godot`.
À l'avenir, l'exécuteur de tests sera téléchargé automatiquement en même temps que les exercices quand tu utilises `exercism download`.

### Récupère l'exécuteur de tests

L'extrait de shell suivant permet de télécharger l'exécuteur de tests.

```bash
exercism download --track gdscript --exercise hello-world
cd "$(exercism workspace)/gdscript"
curl --remote-name https://raw.githubusercontent.com/exercism/gdscript-test-runner/refs/heads/main/bin/test_runner.gd
```

### Lance l'exécuteur de tests

L'exécuteur de tests s'exécute avec `godot` en mode _headless_ (sans IDE).
`-s` ou `--script` indique à Godot d'exécuter le script de l'exécuteur de tests.
L'exécuteur de tests attend deux arguments : le _slug_ et le chemin du dossier de la solution.

```bash
godot --headless -s to/test_runner.gd -- <solution-slug> <path/to/solution>
```

Par exemple,

```bash
godot --headless -s "$(exercism workspace)/gdscript/test_runner.gd" -- hello-world "$(exercism workspace)/gdscript/hello-world
```
