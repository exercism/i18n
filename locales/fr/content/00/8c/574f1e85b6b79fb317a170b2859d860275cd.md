# Les bases

Un programme Sather est constitué de **classes**. Une classe est une boîte nommée qui contient des routines. Une **routine** est une unité de travail nommée qui produit une réponse.

```sather
class GREETER is

   hello : STR is
      return "Hello!";
   end;

end; -- class GREETER
```

Lisons ce code depuis le début :

- `class GREETER is` ouvre la boîte et lui donne un nom. Les noms de classes s'écrivent en majuscules.
- `hello : STR is` démarre une routine appelée `hello` qui produit un `STR`, un morceau de texte appelé une _string_. Le `: STR` est une promesse sur le type de réponse renvoyée.
- `return "Hello!";` renvoie la réponse. Le texte s'écrit entre guillemets.
- `end;` ferme la routine, et le second `end;` ferme la classe.

Tout ce qui suit `--` sur une ligne est un **commentaire**. Sather l'ignore ; il est là pour les humains.

```sather
-- This line is for the reader, not the computer.
```

Pour utiliser une routine depuis un autre endroit, écris le nom de la classe, deux deux-points, puis le nom de la routine :

```sather
GREETER::hello        -- this is "Hello!"
```

À l'intérieur de la même classe, tu peux omettre le nom de la classe :

```sather
class GREETER is

   hello : STR is
      return "Hello!";
   end;

   greeting_again : STR is
      return hello;      -- calls the routine just above
   end;

end; -- class GREETER
```

Une routine qui ne prend aucun argument s'appelle sans parenthèses : `hello`, et non `hello()`.
