# Indices

Ton code doit contenir une fonction frequency :: Int -> [Text] -> Map Char Int
qui prend un nombre de _workers_ à utiliser en parallèle et une liste de textes,
puis renvoie la fréquence totale de chaque lettre dans le texte.

## Benchmark

Lance le benchmark pour voir comment le nombre de _workers_ influe sur les performances de ta solution. Utilise `stack bench` pour l'exécuter. N'hésite pas à modifier `bench/Benchmark.hs` pour explorer les performances de ta solution sur différentes entrées.
