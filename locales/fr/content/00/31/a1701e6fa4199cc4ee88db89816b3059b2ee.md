# Introduction

Une `string` en Go est une séquence immuable d'octets, qui ne représentent pas nécessairement des caractères.

Un littéral de chaîne de caractères se définit entre guillemets doubles :

```go
const name = "Jane"
```

Les _strings_ peuvent être concaténées via l'opérateur `+` :

```go
"Jane" + " " + "Austen"
// => "Jane Austen"
```

Certains caractères spéciaux doivent être échappés à l'aide d'un antislash placé devant, comme `\t` pour une tabulation et `\n` pour un saut de ligne dans les _strings_.

```go
"How is the weather today?\nIt's sunny"  
// =>
// How is the weather today?
// It's sunny
```

Le paquet `strings` contient de nombreuses fonctions utiles pour travailler sur les _strings_.
Pour plus d'informations sur les fonctions qui manipulent les _strings_, consulte la [documentation du paquet strings](https://pkg.go.dev/strings).
Voici quelques exemples :

```go
import "strings"

// strings.ToLower returns the string given as argument with all its characters lowercased
strings.ToLower("MaKEmeLoweRCase")
// => "makemelowercase"

// strings.Repeat returns a string with a substring given as argument repeated many times
strings.Repeat("Go", 3)
// => "GoGoGo"
```
