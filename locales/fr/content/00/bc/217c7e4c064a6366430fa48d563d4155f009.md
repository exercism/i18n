# Introduction

Une façon courante d'exécuter du code de manière conditionnelle en JavaScript est l'instruction `if`.
Elle se compose du mot-clé `if`, d'une condition entre parenthèses (``) et d'un bloc de code entre accolades (`{}`).
Le bloc de code ne sera exécuté que si la condition vaut `true`.

```javascript
if (condition) {
  // code that is executed if "condition" is true
}
```

On peut l'utiliser seul ou la combiner avec le mot-clé `else`.

```javascript
if (condition) {
  // code that is executed if "condition" is true
} else {
  // code that is executed otherwise
}
```

Pour imbriquer une autre condition dans l'instruction `else`, on peut utiliser `else if`.

```javascript
if (condition1) {
  // code that is executed if "condition1" is true
} else if (condition2) {
  // code that is executed if "condition2" is true
  // but "condition1" was false
} else {
  // code that is executed otherwise
}
```
