# Introduction

Une *expression régulière* (regex) est un petit motif qui décrit à quoi
un texte doit ressembler. Les outils regex de Factor se trouvent dans le
vocabulaire [`regexp`][regexp], et un motif s'écrit entre `R/ ` et `/`.

La plupart des caractères d'un motif ont leur propre sens. Quelques
éléments spéciaux désignent des *types* de caractère ou *combien* en
attendre :

```
\d        ! any digit 0–9
\s        ! any whitespace; \S means any non-whitespace
[A-Z]     ! any one capital letter
.         ! any single character

{4}       ! exactly 4 times       +   ! one or more
{2,5}     ! 2 to 5 times          *   ! zero or more
?         ! optional (0 or 1)
```

Donc `R/ [A-Z]{2}-\d{4}/` signifie « deux majuscules, un tiret, quatre chiffres ».

`matches?` vérifie si une _string_ *entière* correspond au motif :

```
matches? ( string regexp -- ? )
```

```factor
USING: regexp ;

"NS-1024" R/ [A-Z]{2}-\d{4}/ matches? .   ! => t
"NS-10"   R/ [A-Z]{2}-\d{4}/ matches? .   ! => f
```

D'autres mots regardent *à l'intérieur* d'une _string_ : `all-matching-subseqs`
renvoie toutes les correspondances, `count-matches` les compte,
`re-contains?` indique s'il y a une correspondance, et `re-replace`
remplace chaque correspondance par un nouveau texte :

```
all-matching-subseqs ( string regexp -- seq )
count-matches        ( string regexp -- n )
re-contains?         ( string regexp -- ? )
re-replace           ( string regexp replacement -- result )
```

```factor
USING: regexp ;

"seen NS-1024 then AB-0007" R/ [A-Z]{2}-\d{4}/ all-matching-subseqs .
! => { "NS-1024" "AB-0007" }

"user=alice pass=hunter2" R/ pass=\S+/ "pass=****" re-replace .
! => "user=alice pass=****"
```

[regexp]: https://docs.factorcode.org/content/vocab-regexp.html
