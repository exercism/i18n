# remplacer les commentaires provisoires

Remplace les commentaires provisoires par une description brève mais utile du _package_, ainsi qu'une ou deux phrases expliquant ce que fait la fonction, quels paramètres elle prend et ce qu'elle renvoie.
Des commentaires précis et utiles sur la façon d'utiliser le code sont très importants pour les développeurs Go.
Voici un excellent guide pour écrire de bons commentaires : [Effective Go: Commentary](https://golang.org/doc/effective_go.html#commentary).
L'outil `godoc` produit automatiquement la documentation à partir des commentaires du code, lorsqu'on l'exécute.
Va voir [godoc.org](https://godoc.org) pour des exemples de ce que ça donne.
