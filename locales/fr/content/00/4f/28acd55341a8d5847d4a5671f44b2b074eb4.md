# Instructions

Recherche dans des fichiers les lignes qui correspondent à une chaîne recherchée et renvoie toutes les lignes correspondantes.

La commande Unix [`grep`][grep] recherche dans des fichiers les lignes qui correspondent à une expression régulière.
Ta tâche consiste à implémenter une version simplifiée de la commande `grep`, qui prend en charge la recherche de chaînes fixes.

La commande `grep` prend trois arguments :

1. La chaîne à rechercher.
2. Zéro ou plusieurs options pour personnaliser le comportement de la commande.
3. Un ou plusieurs fichiers dans lesquels chercher.

Elle lit ensuite le contenu des fichiers indiqués (dans l'ordre indiqué), trouve les lignes qui contiennent la chaîne recherchée, puis renvoie enfin ces lignes dans l'ordre dans lequel elles ont été trouvées.
Lors d'une recherche dans plusieurs fichiers, chaque ligne correspondante est précédée du nom du fichier et d'un deux-points (':').

## Options

La commande `grep` prend en charge les options suivantes :

- `-n` Fait précéder chaque ligne de la sortie du numéro de ligne et d'un deux-points (':'), en plaçant le numéro après le nom du fichier (s'il est présent).
- `-l` Affiche uniquement les noms des fichiers qui contiennent au moins une ligne correspondante.
- `-i` Effectue la correspondance sans tenir compte de la casse.
- `-v` Inverse le programme : recueille toutes les lignes qui ne correspondent pas.
- `-x` Recherche uniquement les lignes pour lesquelles la chaîne recherchée correspond à la ligne entière.

[grep]: https://pubs.opengroup.org/onlinepubs/9699919799/utilities/grep.html
