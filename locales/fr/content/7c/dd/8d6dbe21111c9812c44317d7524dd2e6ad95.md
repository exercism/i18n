# À propos

## Les optionnels

Swift utilise les [_optionnels_][optionals] pour permettre aux programmeurs de représenter l'absence éventuelle d'une valeur.
Un optionnel est un type qui peut soit contenir une valeur, soit être [`nil`][nil], ce qui représente l'absence d'une valeur.
Utiliser un optionnel exige qu'un programme vérifie si une valeur existe avant de l'utiliser après l'avoir déballé.

N'importe quel type peut être transformé en optionnel en ajoutant un `?` à la fin du nom du type.
Ainsi, un entier optionnel aurait le type `Int?` et une _string_ optionnelle aurait le type `String?`.
Définir des constantes ou des variables de type optionnel et leur affecter des valeurs se fait de la même manière que pour des valeurs de types non optionnels.

```swift
let x: Int? = 42
var y: String? = "Hello"
y = "Goodbye"
```

Tu peux affecter l'absence de valeur à une variable de type optionnel en lui affectant la valeur spéciale `nil`.
`nil` peut être utilisé avec tous les types optionnels, mais des `nil` affectés à deux types optionnels différents n'ont pas le même type et ne peuvent pas être échangés ni même comparés.

```swift
let intOpt: Int? = nil
let stringOpt: String? = nil

intOpt = stringOpt
// Compiler error: Cannot assign value of type 'String?' to type 'Int?'

intOpt == stringOpt
// Compiler error: Binary operator '==' cannot be applied to operands of type 'Int?' and 'String?'
```

Note aussi que même si `nil` peut être affecté à n'importe quel type optionnel, il ne peut pas être affecté à un type non optionnel (même s'il ne contient pas réellement `nil`).
Et on ne peut pas passer un type optionnel à une méthode qui attend un type non optionnel sans l'avoir déballé au préalable.

```swift
var x: Int = 42
var y: Int? = 42

y = x
// Works fine
x = y
// error: value of optional type 'Int?' must be unwrapped to a value of type 'Int'
x + y
// error: value of optional type 'Int?' must be unwrapped to a value of type 'Int'
```

## Utilise les optionnels

Comme les types optionnels ne sont pas les mêmes types que leurs types de base, les deux types ne peuvent pas être utilisés de la même façon.
Par exemple : `Int("123") + 1` produit une erreur de compilation « Value of optional type 'Int?' must be unwrapped to a value of type 'Int' ».
C'est parce que `Int("123")` renvoie un type optionnel `Int?`, et non un type `Int`, car si la _string_ ne peut pas être convertie en entier, le résultat sera `nil`.
Pour accéder à l'`Int` obtenu par la conversion, il faut d'abord le « déballer ».

Cela se fait le plus souvent en Swift avec les constructions `if-let` et `guard-let` pour la [_liaison optionnelle_][optional-binding], qui vérifient la présence de `nil` et empruntent un chemin de code avec la valeur déballée liée à un nom fourni si une valeur existe, et un autre chemin si `nil` a été trouvé.

```swift
if let safeNum = Int("123") {
	let sum = safeNum + 1
	…
} else {
  // code for the case where nil was found -- may be left out
}
```

Il est utile de noter que la variable `safeNum` a le type `Int` et non `Int?`.
Dans l'exemple ci-dessous, `num` est de type `Int?` et `safeNum` est de type `Int`.

```swift
let num = Int("123")
if let safeNum = num {
  // num is of type Int
}
```

Cette _liaison optionnelle_ est importante car elle déballe (ou « retire ») le type optionnel de la valeur, ce qui permet de l'utiliser comme une valeur non optionnelle.
Si tu te contentais de faire un simple test conditionnel pour savoir si la valeur est `nil`, la valeur resterait de type optionnel :

```swift
let num = Int("123")
if num != nil {
  // num is of type Int?
}
```

L'option `guard-let` peut aussi être utilisée dans les cas où un retour anticipé est souhaité :

```swift
guard let num = Int("123") else { return nil }
let sum = num + 1
…
```

## Compare les optionnels

Note que même si le type de base d'une paire d'optionnels peut être comparé à l'aide des opérateurs de comparaison standard, les optionnels eux-mêmes ne peuvent pas être comparés.
On peut seulement vérifier leur égalité.
Deux optionnels sont égaux s'ils sont tous les deux `nil` ou si les valeurs qu'ils contiennent sont égales au sein de leurs types de base.

Cependant, on peut écrire du code pour effectuer une comparaison personnalisée de deux valeurs optionnelles.
Voici un exemple d'instruction `switch` qui renverra `true` uniquement si les deux valeurs optionnelles ne sont pas `nil` et que la première valeur est inférieure à la seconde.
Pour ce faire, elle utilise le _motif optionnel_ `varName?`, qui ne correspond qu'aux optionnels non nuls, en liant la valeur à l'intérieur de l'optionnel au nom `varName`.

```swift
switch (optionalA, optionalB) {
case let (valA?, valB?): return valA < valB
default: return false
}
```
