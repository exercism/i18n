# À propos

Les [symboles][symbols] sont des identifiants nommés qui permettent de faire référence à une valeur.
On crée un symbole à partir d'un littéral de symbole, c'est-à-dire en faisant précéder un nom du caractère `:`, par exemple `:foo`.
Ils peuvent aussi s'écrire entre guillemets, par exemple `:"foo"`, ce qui autorise, par exemple, les espaces dans le nom.

```crystal
:foo           # => :foo
:"foo boo"     # => :"foo boo"
:foo == :"foo" # => true
```

Les symboles sont utilisés à de nombreux endroits dans le langage, notamment comme clés dans les _namedtuples_ et pour représenter les noms de méthodes et de variables.

## Les symboles en Crystal

Les symboles en Crystal sont assez différents de ceux de Ruby.
En Crystal, un symbole est un type de constante et il est donc affecté au moment de la compilation.
Cela signifie que les symboles ne peuvent pas être créés dynamiquement, ce qui est possible en Ruby.

Les symboles en Crystal sont représentés par des `Int32`, ce qui les rend très efficaces.

## Conversion

Les symboles peuvent être convertis en _strings_, mais pas l'inverse.
En effet, les symboles sont créés au moment de la compilation et les _strings_ sont créées à l'exécution.

```crystal
:foo.to_s # => "foo"
```
