# En bref

Une extension statique permet de pseudo-étendre des types existants sans modifier leur code source. On y parvient grâce à l'instruction `using`. Les extensions statiques peuvent être un outil puissant, qui permet d'enrichir des types sans réellement les modifier.

```haxe
using Main.IntExtender;

class Main {
  public static function main() {
    trace(2.triple()); // 6
  }
}

class IntExtender {
  public static function triple(i:Int):Int {
    return i * 3;
  }
}
```
