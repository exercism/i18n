# Promotion des propriétés dans le constructeur

Dans les classes qui déclarent de nombreuses propriétés, le fait de déclarer séparément la classe, ses propriétés et un constructeur pour leur affecter une valeur oblige à beaucoup de répétition.
La promotion des propriétés dans le constructeur permet de réduire cette répétition.

```php
<?php

class Book
{
    private string $isbn;
    private string $doi;
    private string $title;

    public function __construct(string $isbn, string, $doi, string $title)
    {
        $this->isbn = $isbn;
        $this->doi = $doi;
        $this->title = $title;
    }
}

// Using constructor property promotion
class Book
{
    public function __construct(
        private string $isbn,
        private string $doi,
        private string $title
    ) {
    }
}
