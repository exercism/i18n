# Introduction

On peut rendre un paramètre de méthode facultatif en lui affectant une valeur par défaut. Lorsqu'on appelle une méthode avec des paramètres facultatifs, l'appelant n'est pas obligé de leur passer une valeur. Si aucune valeur n'est passée pour un paramètre facultatif, sa valeur par défaut est utilisée.

Les paramètres facultatifs doivent se trouver à la fin de la liste des paramètres ; ils ne peuvent pas être suivis de paramètres obligatoires.

```haxe
class Card {
  static function newYear(year = 2021):String {
    return "Happy " + year;
  }
}

Card.newYear(); // Happy 2020
Card.newYear(1990); // Happy 1990
```

On peut définir le paramètre facultatif sur `null` en plaçant l'opérateur `?` devant le nom de la variable :

```haxe
function newYear(?year:Int) {
  if (year != null)
    return "It's " + year;
  return "Year is null";
}

newYear(); // Year is null
```
