# Instructions

Ta tâche consiste à ajouter le décompte des mines aux cases vides d'un plateau de Minesweeper terminé.
Le plateau lui-même est un rectangle composé de cases, qui sont soit vides (`' '`), soit des mines (`'*'`).

Pour chaque case vide, compte le nombre de mines adjacentes (horizontalement, verticalement, en diagonale).
Si la case vide n'a aucune mine adjacente, laisse-la vide.
Sinon, remplace-la par le nombre de mines adjacentes.

Par exemple, tu peux recevoir un plateau de 5 x 4 comme celui-ci (les cases vides sont ici représentées par le caractère « · » pour l'affichage à l'écran) :

```text
·*·*·
··*··
··*··
·····
```

Ton code doit le transformer en ceci :

```text
1*3*1
13*31
·2*2·
·111·
```
