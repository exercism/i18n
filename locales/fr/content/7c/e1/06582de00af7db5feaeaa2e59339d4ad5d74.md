# Introduction

Bien que les expressions `if/else` permettent d'exécuter une logique conditionnelle, Haskell dispose d'une façon plus puissante encore de le faire : le [filtrage par motif][pattern-matching].
Avec le filtrage par motif, on peut tester une valeur contre un ou plusieurs _motifs_.
Un exemple d'un tel motif est le _motif constant_, qui compare une valeur à une constante (par exemple `1` ou `"hello"`).

Lorsqu'on définit des fonctions, on peut définir un corps de fonction distinct pour chaque motif.
On obtient ainsi du code propre, simple et lisible.
On peut filtrer par motif sur n'importe quel type de données : des nombres, des caractères, des listes, des tuples, etc.

Par exemple, une fonction triviale qui prend un nombre entier (`Int`) et le rend plus proche de _0_ de _1_ pourrait s'écrire ainsi :

```haskell
closerToZero :: Int -> Int
closerToZero 0 = 0
closerToZero 1 = 0
```

Le filtrage par motif révèle tout son intérêt lorsqu'on l'utilise avec d'autres motifs, comme le _motif variable_ :

```haskell
closerToZero :: Int -> Int
closerToZero 0 = 0
closerToZero n = n - 1
```

L'exemple ci-dessus traite toutes les entrées autres que _0_ de la même façon, et produirait des résultats incorrects pour les nombres négatifs.
On peut résoudre ce problème à l'aide de motifs conditionnels, appelés _gardes_, que l'on exprime avec le symbole `|` :

```haskell
closerToZero :: Int -> Int
closerToZero n
    | n < 0 = n + 1
    | n > 0 = n - 1
```

Dans les exemples ci-dessus, toutes les entrées possibles n'ont pas de motif correspondant.
Le compilateur le détecte et émet un avertissement.
C'est une fonctionnalité très utile de Haskell, qui aide à garantir que tous les chemins possibles sont couverts afin d'éviter les erreurs à l'exécution.
On appelle cela la _vérification exhaustive_.
Pour faire disparaître l'avertissement, il faut traiter tous les cas.
Dans les _gardes_, on peut utiliser l'expression `otherwise` comme sucre syntaxique pour `True`, afin d'attraper tous les motifs restants.

```haskell
closerToZero :: Int -> Int
closerToZero n
    | n < 0 = n + 1
    | n > 0 = n - 1
    | otherwise = 0
```

Le filtrage par motif teste une valeur contre chaque motif, de haut en bas, jusqu'à ce qu'il trouve un motif correspondant et exécute la logique associée à ce motif.
**L'ordre des motifs a son importance !**
