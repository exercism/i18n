# Introduction

Les variables déclarées avec le mot-clé `final` au lieu de `var` ne peuvent se voir affecter une valeur qu'une seule fois.

```haxe
final a = "hello";
var b = "world";
trace(a, b); // hello, world
b = "haxe";
trace(a, b); // hello, haxe

// The following line would cause a compilation error:
// a = "bye";
```
