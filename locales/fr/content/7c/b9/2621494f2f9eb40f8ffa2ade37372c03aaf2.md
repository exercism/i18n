# Instructions

Leslie, l'extraterrestre Lisp, a des courses à faire. Il est très important d'avoir une liste de courses. On doit pouvoir y ajouter des choses, et en retirer d'autres.

Bien sûr, un simple stylo et du papier ne suffisent pas pour un extraterrestre Lisp. Le mot _List_ constitue d'ailleurs la majeure partie du mot _Lisp_ ! Il faut donc écrire quelques fonctions pour aider à suivre les courses.

Peux-tu aider Leslie à suivre la liste de courses ?

## 1. Crée une nouvelle liste

Pour commencer, Leslie doit créer une liste vide. Une fonction appelée `new-list` serait parfaite pour ça.

```lisp
(new-list) ; => ()
```

Oh non... Leslie a déjà quelques choses en tête, il leur faut donc une fonction qui prend trois éléments (heureusement, Leslie ne crée que des listes de trois éléments. Ni plus, ni moins !) et qui crée une nouvelle liste de courses avec ces éléments. Écris une fonction `list-of-things` qui prend trois éléments et renvoie une liste de ces éléments.

```lisp
(list-of-things 'bread 'milk 'butter) ; => '(bread milk butter)
```

## 2. Ajoute des choses à la liste.

Avant d'aller au magasin, Leslie regarde dans le garde-manger pour voir ce qu'il leur faut. Aide Leslie en écrivant la fonction `add-to-list`, qui ajoute un élément au début d'une liste.

```lisp
(add-to-list 'butter '(bread)) ; => '(butter bread)
```

## 3. Quelles sont les prochaines choses sur la liste ?

Pendant les courses, Leslie veut savoir quoi chercher ensuite. Leslie aime aussi regarder plus loin dans la liste pour voir le deuxième, le troisième, ou même le 23e élément (le nombre porte-bonheur de Leslie).

- `first-thing` renvoie le premier élément de la liste
- `second-thing` renvoie le deuxième élément
- `third-thing` renvoie le troisième élément
- `twenty-third-thing` renvoie le vingt-troisième élément

```lisp
(first-thing '(bread butter milk)) ; => 'bread
(second-thing '(bread butter milk)) ; => 'butter
(third-thing '(bread butter milk)) ; => 'milk
```

## 4. Retire une chose de la liste

Leslie veut trouver le premier élément de la liste et le retirer de l'étagère. Aide Leslie en écrivant une fonction `remove-first-item` qui renvoie une liste contenant tout sauf le premier élément de la liste d'entrée.

```lisp
(remove-first-item '(bread butter milk)) ; => '(butter milk)
```

## 5. Construis de grandes listes à partir de plus petites

Leslie vient de s'apercevoir que deux listes de courses ont été créées par accident, au lieu d'une seule ! Écris une fonction `list-append` qui renvoie une liste composée des éléments de la première liste suivis de ceux de la seconde.

```lisp
(list-append '(bread salt) '(butter milk)) ; => '(bread salt butter milk)
```

## 6. Combien de temps encore ?

Leslie commence à s'inquiéter : les courses risquent de prendre du temps. Mais combien y a-t-il de choses sur cette liste ? Écris une fonction `just-how-long` qui lui indique la longueur de la liste.

```lisp
(just-how-long '(bread milk butter salt)) ; => 4
```
