# Indices

Toutes ces tâches nécessitent de découper la ligne de log en plusieurs parties.

- Regarde la fonction [`split()`][split] pour voir les options disponibles.

## 1. Récupère le message d'une ligne de log

- La fonction `split()` renvoie un vecteur de _strings_.
- Il te faut récupérer l'élément approprié dans ce vecteur.
- Les espaces en début et en fin peuvent être supprimés avec [`strip()`][strip].

## 2. Récupère le niveau de log d'une ligne de log

- La fonction [`lowercase()`][lowercase] est utile ici.
- Une _string_ ASCII peut être indexée avec un intervalle.
- L'indice `end` désigne le dernier élément d'un vecteur.
- Sinon, on peut résoudre la tâche en utilisant [`replace()`][replace] pour supprimer les caractères indésirables.

## 3. Reformate une ligne de log

- L'[interpolation][interpolation] de _strings_ est peut-être l'approche la plus simple ici.
- Sinon, certaines personnes (qui ont l'expérience d'autres langages) peuvent préférer [`@sprintf()`][sprintf].
