# À propos

C# est un langage à typage statique, ce qui signifie que tout a un type à la compilation. Choisir un nom pour une [variable][variable] s'appelle définir une variable. Une fois qu'une variable est définie, définir ou mettre à jour sa valeur s'appelle une affectation de variable. Une variable peut être définie soit en spécifiant explicitement son type, soit en utilisant [le mot-clé `var`][var] pour que le compilateur C# déduise son type à partir de la valeur affectée. L'utilisation de `var` s'appelle l'_inférence de type_.

```csharp
int explicitVar = 10; // Explicitly typed
var implicitVar = 10; // Implicitly typed
```

La valeur d'une variable peut être affectée et mise à jour à l'aide de [l'opérateur `=`][assignment]. Une fois définie, le type d'une variable ne peut plus jamais changer.

```csharp
var count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning different type
// count = false;
```

C# est un langage orienté objet et exige que toutes les [fonctions][function] soient définies dans une _classe_, elle-même définie à l'aide [du mot-clé `class`][classes]. Les objets (ou _instances_) sont créés à l'aide du mot-clé `new`.

```csharp
class Calculator
{
    // ...
}

var calculator = new Calculator();
```

Une fonction à l'intérieur d'une classe s'appelle une _méthode_. Chaque [méthode][methods] peut prendre zéro ou plusieurs paramètres. Tous les paramètres doivent être typés explicitement, il n'y a pas d'inférence de type pour les paramètres. De même, le type de retour doit aussi être explicite. Les valeurs sont renvoyées par les méthodes à l'aide [du mot-clé `return`][return]. Pour qu'une méthode puisse être appelée par du code dans d'autres fichiers, il faut ajouter le modificateur d'accès `public`.

```csharp
class Calculator
{
    public int Add(int x, int y)
    {
        return x + y;
    }
}
```

Les méthodes s'appellent en utilisant la syntaxe point (`.`) sur une instance, en spécifiant le nom de la méthode à appeler et en passant les arguments pour chacun de ses paramètres. Les arguments peuvent, si on le souhaite, spécifier le nom du paramètre correspondant.

```csharp
var calculator = new Calculator();
var sum_v1 = calculator.Add(1, 2);
var sum_v2 = calculator.Add(x: 1, y: 2);
```

Si la méthode à appeler est définie dans la même classe que la méthode qui l'appelle, le nom de la classe peut être omis.

Si une méthode n'utilise aucun _état_ d'objet, elle peut être rendue _statique_ à l'aide du modificateur `static`. Les méthodes statiques s'appellent aussi avec la syntaxe point (`.`), mais elles sont invoquées sur la classe elle-même plutôt que sur une instance de celle-ci.

Si une classe ne contient que des méthodes statiques, elle peut elle aussi être rendue statique à l'aide du modificateur `static`. Cela exprime l'intention de la classe.

```csharp
static class Calculator
{
    public static int Multiply(int x, int y)
    {
        return x * y;
    }
}

Calculator.Multiply(2, 4); // => 8
```

En C#, la portée est définie entre les caractères `{` et `}`.

C# prend en charge deux types de [commentaires][comments]. Les commentaires sur une seule ligne sont précédés de `//` et les commentaires multilignes sont insérés entre `/*` et `*/`.

Les valeurs entières sont définies comme un ou plusieurs chiffres (consécutifs) et prennent en charge [les opérateurs mathématiques par défaut][operators].

Un nom de variable [doit suivre certaines règles][identifier-names], comme commencer par une lettre ou un tiret bas, et [devrait suivre les conventions de nommage de C#][naming-guidelines]. Si un nom de variable entre en conflit avec un [mot-clé C# réservé][csharp-keywords], il doit être échappé à l'aide de `@`. L'utilisation de cette notation n'est pas recommandée, mais on peut la rencontrer dans des cas exceptionnels, par exemple : `var @this`, `var @class` ou `var @var`.

Il y a deux concepts si fondamentaux pour un langage de la famille C comme C# qu'ils apparaissent naturellement dans presque tout morceau de code non trivial. Ce sont la [mutation][mutation] et la [portée][scope]. La mutation est l'idée qu'une variable peut voir sa valeur changée au cours de la durée de vie d'un programme. La portée est l'idée que la valeur associée à un nom (d'un élément de programme) n'est accessible que dans la « zone » de code où elle est définie. Les principales zones de code en C# sont _classe/struct_ et _fonction_ (généralement les méthodes), mais elles peuvent aussi inclure le corps de boucles et d'autres constructions.
