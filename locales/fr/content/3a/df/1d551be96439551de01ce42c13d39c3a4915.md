# Instructions

Ta tâche est de créer un programme qui met en œuvre l'algorithme du crible d'Ératosthène pour trouver les nombres premiers.

Un nombre premier est un nombre qui n'est divisible que par 1 et par lui-même.
Par exemple, 2, 3, 5, 7, 11 et 13 sont des nombres premiers.

Le crible d'Ératosthène est un algorithme ancien qui consiste à prendre un tableau de nombres et à rayer tous les nombres qui ne sont pas premiers.

Un nombre qui n'est **pas** premier est appelé « nombre composé ».

Pour utiliser le crible d'Ératosthène, on commence par créer un tableau de tous les nombres entre 2 et le nombre donné.
Ensuite, on répète les étapes suivantes :

1. Trouve le prochain nombre non marqué dans le tableau. C'est un nombre premier.
2. Marque tous les multiples de ce nombre premier comme composés (non premiers).

On répète ces étapes jusqu'à avoir parcouru tous les nombres du tableau.
À la fin, tous les nombres non marqués sont premiers.
