# Indices

## Général

- Ne te soucie pas de la façon dont les arguments sont obtenus, concentre-toi plutôt sur leur combinaison afin de renvoyer le résultat attendu.

## 1. Définis si pac-man peut manger un fantôme

- La fonction doit renvoyer une valeur [booléenne][bool].
- Tu peux utiliser l'opérateur [booléen][bool] `&&` pour combiner les arguments afin d'obtenir un résultat.

## 2. Définis si pac-man marque des points

- La fonction doit renvoyer une valeur [booléenne][bool].
- Tu peux utiliser l'opérateur [booléen][bool] `||` pour combiner les arguments afin d'obtenir un résultat.

## 3. Définis si pac-man perd

- La fonction doit renvoyer une valeur [booléenne][bool].
- Tu peux utiliser les opérateurs [booléens][bool] `&&` et `!` pour combiner les arguments afin d'obtenir un résultat.

## 4. Définis si pac-man gagne

- La fonction doit renvoyer une valeur [booléenne][bool].
- Tu peux utiliser les opérateurs [booléens][bool] `&&` et `!` pour combiner les arguments et les résultats de l'une des fonctions déjà implémentées.

[bool]: https://gleam.run/book/tour/bools.html
