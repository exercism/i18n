# À propos

PureScript est un langage de programmation purement fonctionnel et à typage statique, doté d'une inférence globale de types.

**Fonctionnel** signifie que les fonctions sont des valeurs de première classe.
Les fonctions sont un outil d'abstraction important et puissant.
En PureScript, le calcul est modélisé comme l'évaluation d'expressions composées d'applications de fonctions, plutôt que comme l'exécution d'une séquence d'instructions.

**Purement fonctionnel** signifie qu'il est possible de dire si un calcul a des effets de bord ou non : si un calcul modifie une variable globale, lit une entrée, écrit dans une socket, etc., cela se reflétera dans le type du calcul.

**À typage statique** signifie que tous les calculs ont un type connu avant l'exécution du programme.

**Inférence globale de types** signifie que le compilateur peut déterminer le type des calculs dans l'ensemble du programme sans que le programmeur ait besoin de préciser le type.
