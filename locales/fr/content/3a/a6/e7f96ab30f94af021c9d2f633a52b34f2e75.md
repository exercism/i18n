# Introduction

[`Inheritance`][inheritance] est l'un des [« quatre piliers »][four-pillars] de la programmation orientée objet (`OOP`).
Quand il n'y a qu'une petite partie du comportement à personnaliser pour une nouvelle `class`, `inheritance` permet de réutiliser le code d'une ou plusieurs `class` parentes, ce qui aide à rendre les programmes plus propres et plus faciles à maintenir.


`Inheritance` décrit une relation de type [« est une sorte de »][is-a] entre deux `class` ou plus.
Les caractéristiques communes ou les plus « génériques » sont extraites dans une `super class` (aussi appelée _classe de base_ ou _classe parente_), tandis que les détails, les comportements et les données plus spécifiques sont détaillés ou étendus dans une ou plusieurs `subclass`es (aussi appelées _classes dérivées_ ou _classes enfants_).
