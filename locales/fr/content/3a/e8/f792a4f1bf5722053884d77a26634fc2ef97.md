# À propos

Les [_structs_][getting-started] sont des [_maps_][maps] particuliers, avec un ensemble de clés défini.

- Les _structs_ offrent des vérifications à la compilation et des valeurs par défaut.
- Un _struct_ porte le nom du module dans lequel il est défini.
- Pour définir un _struct_, on utilise la construction [`defstruct`][docs-defstruct].
  - Cette construction suit généralement immédiatement la définition du module.
- `defstruct` accepte soit une liste d'[atomes][atom] (pour des valeurs par défaut à nil), soit des listes de mots-clés (pour des valeurs par défaut explicites).
  - Les champs sans valeur par défaut doivent précéder les champs avec valeur par défaut.

```elixir
defmodule Plane do
  defstruct [:engine, wings: 2]
end

plane = %Plane{}
# => %Plane{engine: nil, wings: 2}
```

## Accède aux champs et mets-les à jour

- La plupart des fonctions qui manipulent des [_maps_][maps] fonctionnent aussi avec les _structs_.
  - Le [_comportement Access_][access-behaviour] fait exception et n'est **pas** implémenté pour les _structs_.
- Pour accéder aux champs d'un _struct_, il est recommandé d'utiliser l'_opérateur d'accès statique_ `.`.

- Lire et récupérer les valeurs des champs :

  ```elixir
  plane = %Plane{}
  plane.engine
  # => nil
  Map.fetch(plane, :wings)
  # => {:ok, 2}
  ```

- Mettre à jour les valeurs des champs

  ```elixir
  plane = %Plane{}
  %{plane | wings: 4}
  # => %Plane{engine: nil, wings: 4}
  ```

## Impose l'initialisation des valeurs des champs

- L'[attribut de module `@enforce_keys`][enforcing-keys] crée une vérification à l'exécution : les champs concernés doivent être initialisés à une valeur qui n'est **pas** `nil` au moment de la création du _struct_.
- `@enforce_keys` est suivi d'une liste de clés de champs (qui sont des [atomes][atom]).
- Si une clé imposée n'est pas initialisée, une erreur est levée.

```elixir
defmodule User do
  @enforce_keys [:username]
  defstruct [:username]
end

%User{}
# => (ArgumentError) the following keys must also be given when building struct User: [:username]
```
