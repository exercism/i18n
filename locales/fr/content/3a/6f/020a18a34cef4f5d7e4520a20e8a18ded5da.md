# Introduction

En C++, les booléens sont représentés par le type `bool`.
Un `bool` vaut soit `true`, soit `false`.

## Opérateurs logiques

C++ prend en charge trois opérateurs booléens : `!` (NON), `&&` (ET) et `||` (OU).
Tu peux aussi utiliser les versions alternatives `not`, `and` et `or`.

```cpp
true || false // => true
true && false // => false
!true // => false
not false // => true
```

## Priorité

Les trois opérateurs booléens ont chacun une _priorité_ différente.
Par conséquent, ils sont évalués dans cet ordre : `!` d'abord, `&&` ensuite, et enfin `||`.
Si tu veux imposer un ordre différent, tu peux mettre une expression booléenne entre parenthèses (c'est-à-dire `()`), car les parenthèses ont une priorité d'opérateur encore plus élevée.

```cpp
!true && false   // => false
!(true and false) // => true
```

## Conversion

Si tu utilises `true` ou `false` à un endroit où un nombre est attendu, ils seront convertis respectivement en `1` et `0`.
Si tu utilises un nombre dans une opération booléenne, tout sauf `0` est traité comme `true`, même les valeurs négatives.

```cpp
!true && 0.0   // => false
true + true + false // => 2
```
