# Instructions complémentaires

## Registres

| Registre | Utilisation | Type | Description |
| -------- | --------- | ------- | ------------------------------- |
| `$a0`    | entrée    | adresse | couleur sous forme de chaîne de caractères terminée par un caractère nul |
| `$v0`    | sortie    | entier  | valeur de la résistance |
| `$t0-9`  | temporaire | quelconque | pour le stockage temporaire |
