# Ajout aux instructions

## Format du champ de mines

Le champ de mines est représenté sous la forme d'une _string_ terminée par un caractère nul, avec un caractère de nouvelle ligne à la fin de chaque rangée.

Un exemple serait `"   \n * \n   \n"`

## Registres

| Registre | Utilisation | Type | Description |
| -------- | ----------- | ---- | ----------- |
| `$a0`    | entrée      | adresse | _string_ d'entrée terminée par un caractère nul |
| `$a1`    | entrée/sortie | adresse | _string_ de sortie terminée par un caractère nul |
| `$t0-9`  | temporaire  | quelconque | pour un stockage temporaire |
