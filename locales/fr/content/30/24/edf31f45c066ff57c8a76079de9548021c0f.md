# Instructions

Dans cet exercice, tu vas écrire un `SecureTreasureChest` générique (et même magique !) pour y ranger un trésor.
Les élèves les plus observateurs auront remarqué que le `TreasureChest` précédent n'était pas si sûr que ça !
Si tu utilisais la fonction `getTreasure`, il fallait fournir le mot de passe, mais tu pouvais quand même simplement déstructurer le type `TreasureChest` pour récupérer le trésor, sans avoir à connaître le mot de passe.
Pire encore, tu pouvais même récupérer le mot de passe de la même façon !
Corrigeons cela en utilisant un type opaque.

## 1. Définis le type opaque Password, avec le motif « Parse, don't validate »

Définis un type personnalisé `Password` avec une seule variante.

Cette variante doit avoir une valeur `String` associée, pour le mot de passe.

Tu dois exposer le type `Password`, mais pas sa variante.
Cela fait de `Password` un type opaque, et signifie que tu ne peux plus utiliser la déstructuration pour obtenir le mot de passe.
Il n'est pas possible de vérifier si un type est opaque ou non ; en production, tu utiliserais [elm-review][elm-review] (un outil d'analyse statique) pour le garantir.

Définis et expose une fonction `createPassword`, avec une annotation de type, qui prend une `String` et renvoie un `Maybe Password`.

Owasp recommande que [les mots de passe comportent au moins 8 caractères][owasp-password-length], alors utilisons le motif [Parse, don't validate][parse-dont-validate] pour faire respecter cet invariant.

Si le mot de passe fait moins de 8 caractères, `createPassword` doit renvoyer `Nothing`, sinon elle doit renvoyer `Just Password`.

## 2. Expose SecureTreasureChest, mais pas sa variante

Tu dois exposer le type `SecureTreasureChest`, mais pas sa variante.
Cela fait de `SecureTreasureChest` un type opaque, et signifie que tu ne peux plus utiliser la déstructuration pour obtenir le mot de passe ou le trésor.

## 3. Définis la fonction createTreasure

Cette fonction doit prendre deux paramètres et avoir une annotation de type.

- un type générique (pour le trésor)
- un `Password` (pour le mot de passe)

La fonction doit renvoyer un `SecureTreasureChest`.

Expose cette fonction, pour que d'autres modules puissent créer des instances de `SecureTreasureChest`.

## 4. Définis la fonction getTreasure

Cette fonction doit prendre deux paramètres et avoir une annotation de type.

- une `String` (pour le mot de passe)
- un type personnalisé générique `SecureTreasureChest`

Cette fonction doit vérifier la tentative de mot de passe fournie par rapport au `Password` contenu dans le `SecureTreasureChest`.

La fonction doit renvoyer un `Maybe`.

Si les mots de passe correspondent, renvoie `Just` avec la valeur générique du `SecureTreasureChest` (le trésor !)

Si les mots de passe ne correspondent pas, renvoie `Nothing`.

Expose cette fonction, pour que d'autres modules puissent récupérer le trésor dans un `SecureTreasureChest`, à condition de fournir le bon mot de passe.
