# Indices

## Généralités

- Chaque routine prend des nombres entiers et renvoie un nombre entier, donc les arguments comme la valeur de retour sont de type `INT`.
- Deux arguments de même type peuvent partager une déclaration : `ladder_points(wins, draws : INT) : INT`.

## 1. Points du classement

- Multiplie chaque résultat par les points qu'il rapporte, puis additionne.

## 2. Différence de buts

- Une soustraction. Sather accepte volontiers une réponse négative.

## 3. Quarts-temps joués en entier

- L'opérateur `/` entre deux `INT` élimine déjà le reste, donc aucun arrondi n'est nécessaire.

## 4. Minutes écoulées dans le quart-temps

- L'opérateur `%` donne exactement ce que `/` a écarté.
