# Ajout aux instructions

## Indices

Pour terminer cet exercice, tu dois implémenter la fonction `score`, qui prend une suite de *lancers* au bowling et renvoie le score final ou l'erreur appropriée :

```haskell
score :: [Int] -> Either BowlingError Int

data BowlingError = IncompleteGame
                  | InvalidRoll { rollIndex :: Int, rollValue :: Int }
                  deriving (Eq, Show)
```

Tu trouveras ces définitions déjà en place, mais c'est à toi de définir la fonction.

Garde en tête que la suite de tests s'attend à ce que les lancers soient numérotés à partir de zéro.
