# Instructions

Ta mission est de construire un chronomètre pour suivre précisément les temps au tour.

Le chronomètre utilise quatre commandes (start, stop, lap et reset) pour suivre :

1. Le temps mesuré du tour en cours
2. Les temps au tour enregistrés précédemment

Les commandes que l'on peut utiliser dépendent de l'état dans lequel se trouve le chronomètre :

1. Prêt : état initial
2. En marche : le temps est mesuré
3. Arrêté : le temps n'est pas mesuré

| Commande | État initial | État final | Effet                                                   |
| ------- | ----------- | --------- | -------------------------------------------------------- |
| Start   | Prêt       | En marche   | Commence à mesurer le temps                              |
| Start   | Arrêté     | En marche   | Reprend la mesure du temps                               |
| Stop    | En marche     | Arrêté   | Arrête la mesure du temps                                |
| Lap     | En marche     | En marche   | Ajoute le tour en cours aux tours précédents, puis réinitialise le tour en cours |
| Reset   | Arrêté     | Prêt     | Réinitialise le tour en cours et efface les tours précédents                |
