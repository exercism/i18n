# À propos

Un [`Array`][array] en Elm est une collection immuable et rapide de zéro ou plusieurs valeurs du même type.
Les tableaux étant immuables, une fois qu'un tableau a été construit, sa valeur ne peut plus jamais changer.
Il n'existe pas de syntaxe littérale pour les tableaux (contrairement aux listes)  : on utilise donc la syntaxe Array.fromList.
Par exemple, un `Array` contenant "a", "b" et "c" s'écrit habituellement `Array.fromList ["a", "b", "c"]`.
On le voit dans la sortie de la console, dans le débogueur et à d'autres endroits du même genre.

Contrairement à `List`, qui est un [import par défaut][default-imports], le module `Array` doit être importé explicitement, avec `import Array` ou équivalent.

Les annotations de type pour les tableaux peuvent s'écrire comme suit  :

```elm
Array String --> an array of String
Array Int --> an array of Int
```

Les tableaux peuvent se définir comme suit  :

```elm
import Array exposing (Array)

empty : Array Char
empty = Array.empty

singleValue = Array.fromList [ 5 ] --> Array Int

repeatSingleValue = Array.repeat 2 5 --> Array.fromList [ 5, 5 ]

initialiseFromIndex = Array.initialise 3 (\index -> index * 2) --> Array.fromList [ 0, 2, 4 ]

initialisefromList = Array.fromList [ "a", "b", "c" ] --> Array.fromList [ "a", "b", "c" ]
```

On ajoute des éléments à un tableau avec `Array.push`  :

```elm
twoToFour = Array.fromList [ 2, 3, 4 ]
oneToFour = Array.push 1 twoToFour --> Array.fromList [ 1, 2, 3, 4 ]
```

On concatène deux tableaux avec `Array.append`  :

```elm
sixSeven = Array.fromList [ 6, 7 ]
eightNine = Array.fromList [ 8, 9 ]
Array.append sixSeven eightNine --> Array.fromList [ 6, 7, 8, 9 ]
```

On récupère un élément d'un tableau avec `Array.get`  :

```elm
sixSeven = Array.fromList [ 6, 7 ]
Array.get 0 sixSeven --> Just 6
```

On remplace un élément d'un tableau avec `Array.set`  :

```elm
sixSeven = Array.fromList [ 6, 7 ]
Array.set 1 8 sixSeven --> Array.fromList [ 6, 8 ]
```

Les tableaux se manipulent à l'aide des fonctions définies dans le module [`Array`][array-module].

```elm
oneTwo = Array.fromList [ 1, 2 ]
Array.length oneTwo --> 2
```

Toute fonction ou tout opérateur qui semble modifier un `Array`` (such as adding an element), will actually return a new `Array`.
Performance is usually not an issue though, as the implementation of `Array` évite les allocations et les copies inutiles.
