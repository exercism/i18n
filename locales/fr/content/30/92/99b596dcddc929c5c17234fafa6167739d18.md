# Instructions

Dans cet exercice, tu vas travailler sur un planificateur de rendez-vous pour un salon de beauté à New York, ouvert le 15 septembre 2012.

Tu as cinq tâches, qui portent toutes sur des dates de rendez-vous.
Les horaires sont au format 24 heures (sans AM/PM).

## 1. Analyse une date de rendez-vous entièrement numérique

Implémente la fonction `schedule_appointment()` pour analyser une représentation textuelle d'une date de rendez-vous et la convertir au format `DateTime` correspondant.

Note que l'entrée suit l'ordre américain mois/jour/année.

```julia-repl
julia> schedule_appointment("07/25/2023 13:45:00")
2023-07-25T13:45:00
```

## 2. Vérifie si un rendez-vous est déjà passé

Implémente la fonction `has_passed()` qui prend une date de rendez-vous et vérifie si le rendez-vous se situe dans le passé :

```julia-repl
julia> has_passed(DateTime(1999, 12, 31, 9, 0, 0))
true
```

## 3. Vérifie si un rendez-vous a lieu l'après-midi

Implémente la fonction `is_afternoon_appointment()` qui prend une date de rendez-vous et vérifie si le rendez-vous a lieu l'après-midi (>= 12:00 et < 18:00) :

```julia-repl
julia> is_afternoon_appointment(DateTime(2023, 3, 29, 15, 0, 0))
true
```

## 4. Décris la date et l'heure du rendez-vous

Implémente la fonction `description()` qui prend une date de rendez-vous et renvoie une description de cette date et de cette heure :

```julia-repl
julia> describe(DateTime(2023, 3, 29, 15, 0, 0))
"You have an appointment on Wednesday, March 29, 2023 at 15:00"
```

## 5. Renvoie la date d'anniversaire

Implémente la fonction `anniversary_date()` qui renvoie la date d'anniversaire de cette année, à savoir le 15 septembre :

```julia-repl
julia> anniversary_date()  # run during 2025
2025-09-15
```
