# À propos

Les initialiseurs d'objet sont une alternative aux constructeurs. La syntaxe est une liste de paires nom=valeur séparées par des virgules, comme illustré ci-dessous :

```csharp
public class Person
{
    public string Name;
    public string Address;
}

var person = new Person{Name="The President", Address = "Élysée Palace"};
```

Les collections peuvent aussi être initialisées de cette façon. En général, on y parvient avec des listes séparées par des virgules, comme ici :

```csharp
IList<Person> people = new List<Person>{ new Person(), new Person{Name="Joe Shmo"}};
```

Cette approche (et cette syntaxe) peut être utilisée avec n'importe quelle classe qui implémente `IEnumerable` et qui possède une méthode `Add()`.

Les champs peuvent être listés dans n'importe quel ordre, ou bien être omis complètement.

Les dictionnaires utilisent la syntaxe suivante :

```csharp
IDictionary<int, string> numbers = new Dictionary<int, string>{ [0] = "zero", [1] = "one"...};

// or

IDictionary<int, string> numbers = new Dictionary<int, string>{ {0, "zero" }, {1,  "one"}...};
```

Les champs initialisés doivent être accessibles à l'appelant. En général, cela signifie qu'ils doivent être `public` ou `internal`.

L'immuabilité est fortement encouragée par les concepteurs du langage et par les praticiens les plus reconnus, si bien que le caractère mutable des objets initialisés de cette façon est perçu comme un inconvénient. Des propositions visent à introduire une clause `init` dans la prochaine version du langage, C# 9, ce qui pourrait répondre à cette préoccupation.

- La documentation sur les [initialiseurs d'objet][object-initializers] décrit comment utiliser les initialiseurs.
- La documentation sur les [initialiseurs de collection][collection-initializers] donne un aperçu de la façon dont les initialiseurs peuvent être utilisés avec des collections comme les dictionnaires et les listes.
