# Introduction

En Clojure, lier une valeur à un nom s'appelle une _var_. Les vars de premier niveau (globales) sont semblables aux constantes d'autres langages, mais on les redéfinit souvent pour faciliter le développement dynamique.

Les vars de premier niveau se définissent avec `def` :

```clojure
(def fingers 10)
```

La macro `defn` permet de définir une fonction qui prend zéro ou plusieurs arguments. Une fonction renvoie toujours le résultat de la dernière expression de son corps.

```clojure
(defn add [x y]
  (+ x y))
```

Pour appeler une fonction, on indique son nom et on passe des arguments pour chacun de ses paramètres.

```clojure
(def five (add 2 3))
```

En Clojure, on ne peut utiliser les fonctions et les valeurs qu'_après_ les avoir définies. Les utiliser avant de les avoir définies provoque une erreur de compilation.

```clojure
;; Compile error as `add` has not yet been defined
(def seven (add 3 4))

(defn add [x y]
  (+ x y))
```

En Clojure, les espaces n'ont pas d'autre rôle que la mise en forme.

Les fonctions et les vars de Clojure sont organisées en espaces de noms. Un espace de noms regroupe des fonctionnalités liées et se définit avec la macro `ns` :

```clojure
(ns calculator)

(def pi 3.14)

(defn add [x y]
  (+ x y))
```

Clojure prend en charge deux types de commentaires. Les commentaires sur une seule ligne sont précédés d'un `;` et la forme `comment` sert à empêcher l'évaluation de tout ce qui se trouve entre `(comment` et `)`.
