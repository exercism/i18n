# Tests

Tu peux exécuter les tests fournis depuis DrRacket ou en ligne de commande.

Pour lancer le test depuis DrRacket, il suffit d'ouvrir le fichier de test et de cliquer sur le bouton « Run » en haut à droite.

Pour lancer le test en ligne de commande, exécute-le simplement depuis le répertoire de l'exercice. Par exemple, si la suite de tests s'appelle `hello-world-test.rkt`, tu peux exécuter la commande suivante :

```
raco test hello-world-test.rkt
```

ce qui affiche ce qui suit :

```
raco test: (submod "hello-world-test.rkt" test)
2 success(es) 0 failure(s) 0 error(s) 2 test(s) run
0
2 tests passed
```
