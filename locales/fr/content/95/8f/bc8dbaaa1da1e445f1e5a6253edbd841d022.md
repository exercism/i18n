# À propos

Une définition de collection comporte généralement un espace réservé entre chevrons, souvent `T` par convention. Une telle collection est appelée un type générique. Cela permet à l'utilisateur de la collection de préciser le type d'éléments à y stocker. Dans l'exemple de code ci-dessus, on instancie un tableau de _strings_.

On rend une classe ou une fonction **générique** en utilisant l'attribut `@:generic`. Cela amène le compilateur à identifier la classe ou la fonction comme générique :

```haxe
@:generic
class MyValue<T> {
  public var value:T;

  public function new(value:T) {
    this.value = value;
  }
}

var a = MyValue<String>("Hello");
trace(a.value); // Hello
```
