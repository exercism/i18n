# Indices

## Généralités

- Pour déclarer un nombre avec un type précis, on ajoute le type au nombre, par exemple `42_u8` pour un entier non signé sur 8 bits.
- Pour convertir entre différents types, on appelle la méthode `to_<type>` sur le nombre, par exemple `42u8.to_u16` pour un entier non signé sur 16 bits.

## 1. Constantes de navigation

- Tu dois définir des [constantes][constants] qui doivent contenir un [entier][integers].
- La constante doit être déclarée à l'intérieur de la classe `Navigation`.
- La constante doit être déclarée en dehors de toute méthode.

## 2. Analyse correcte de l'aire

- Tu dois convertir l'entrée en un entier non signé.

## 3. Calcule la vitesse

- Pour obtenir la vitesse, divise la distance par le temps.
- Le résultat d'une opération numérique est du type de la plus haute précision ; il faut donc convertir le résultat vers le type correct.
