# Introduction

## Exceptions

Les exceptions en C# offrent une façon structurée, uniforme et sûre au niveau des types de gérer les conditions d'erreur qui surviennent pendant l'exécution. Une gestion correcte des exceptions et des erreurs est importante pour éviter que l'application ne plante.

En C#, toutes les exceptions ont la classe `System.Exception` pour type de base. Elle définit des propriétés importantes telles que `Message`, qui contient une description lisible par un humain de la raison pour laquelle l'exception est levée.

Pour signaler qu'il doit y avoir une erreur à un certain endroit du code, il faut créer un nouvel objet exception, puis le lever, à l'aide du mot-clé `throw` :

```csharp
using System;
static int Square(int number)
{
    if (number >= 46341)
    {
        throw new ArgumentException($"Argument {number} cannot be higher than 46340 as its' square doesn't fit into int type.");
    }
    return number * number;
}
```

Quand une exception est levée, le _runtime_ a pour tâche de trouver un bout de code chargé de gérer cette exception. Si aucun gestionnaire approprié n'est trouvé, le _runtime_ affiche le message de l'exception non gérée et arrête l'exécution du programme.

Pour créer un gestionnaire d'exception, C# utilise l'instruction try-catch, qui se compose d'un bloc `try` et d'une ou plusieurs clauses `catch`. Le bloc `try` doit contenir et protéger du code susceptible de lever l'exception. Les clauses `catch` doivent contenir le code qui gère le comportement du programme après que l'erreur s'est produite. Il est important de noter que l'ordre des exceptions compte après le bloc `try` : comme plusieurs exceptions peuvent être listées, c'est la première clause `catch` correspondante qui s'exécute.

```csharp
try
{
   if (number == 42)
   {
       throw new ArgumentException("The number cannot be equal to 42.", "number");
   }

   if (number < 0)
   {
      throw new ArgumentOutOfRangeException("number", "The number cannot be negative.");
   }

    // Process number ...
}
catch (ArgumentOutOfRangeException e)
{
    Console.WriteLine($"Number is out of range: {e.Message}.");
}
catch (ArgumentException)
{
    Console.WriteLine("Invalid number.");
}
```
