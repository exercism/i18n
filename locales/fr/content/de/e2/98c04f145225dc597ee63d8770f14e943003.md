# À propos

Un `bit` est la valeur la plus élémentaire en informatique.
Le mot `bit` est la contraction de « binary digit ».
C'est une unité de stockage de données dans l'environnement d'exécution, assez grande pour contenir un objet pouvant prendre l'une de deux valeurs.
En tant que tel, sa valeur binaire est soit `1`, soit `0`.
Tous les autres types de données sont composés de plusieurs `bits`.
Par exemple, un `byte` est généralement composé de huit `bits`.

## Comment écrire des valeurs binaires

`Bits` constituent un système de numération en base 2.
Chaque multiple de `2` occupe la position que l'on associe aux dizaines, aux centaines, aux milliers, etc., sauf que les « dizaines » deviennent des « deux », les « centaines » des « quatre », les « milliers » des « huit », et ainsi de suite.
Ainsi, la valeur décimale `2` correspond à la valeur binaire `10`, `4` à `100` et `8` à `1000`.
Comme pour les nombres décimaux, les valeurs augmentent à mesure que l'on va de la droite vers la gauche.
On peut considérer que la valeur décimale `5` est représentée par `101` en binaire, avec un `1` à la position des « unités » et un `1` à la position des « quatre ».
Cependant, les littéraux binaires ne font pas partie du standard du langage C.
Les seules valeurs binaires prises en charge par le standard du langage C sont un `1` ou un `0` seuls.
Les littéraux binaires _sont_ pris en charge par certaines extensions non standard de compilateurs, comme le compilateur gnu, en faisant précéder le littéral de `0b`.

```c
#include <stdio.h>

int main() {
    int binary_five = 0b101;
    printf("%d", binary_five);
    return 0;
}
```

Il est important de garder à l'esprit qu'une telle notation n'est pas prise en charge par tous les compilateurs et qu'elle peut constituer un obstacle à la portabilité du code entre différents compilateurs.

Une façon courante d'écrire des valeurs binaires consiste à utiliser la notation hexadécimale, qui est un système de numération en base 16.
En langage C, la notation hexadécimale fait précéder le littéral de `0x` ou `0X`.
Comme la valeur décimale `16` est représentée par `1` à la position des dizaines, la valeur décimale `10` s'écrit `0xA` en hexadécimal, `11` s'écrit `0xB`, `12` s'écrit `0xC`, `13` s'écrit `0xD`, `14` s'écrit `0xE` et `15` s'écrit `0xF`.
Ainsi, par exemple, la valeur décimale `42` s'écrirait `0x2A` : `2` fois `16` (= `32`) plus `10` (= `42`).

En binaire, on peut considérer `42` comme `00101010` : `32` plus `8` plus `2`.
On dit que les deuxième, quatrième et sixième bits en partant de la droite sont « à 1 », c'est-à-dire qu'ils valent `1` et non `0`.
Le deuxième bit vaut `2`, le quatrième bit vaut `8` et le sixième bit vaut `32`.
Définir ces trois bits donne une valeur de `42`.

## Masques de bits

Un masque de bits peut être n'importe quelle valeur utilisée pour définir des bits individuels.
Par exemple, l'alphabet anglais compte vingt-six lettres.
Une valeur d'au moins vingt-six bits, comme un entier non signé de 32 bits, pourrait servir de masque de bits pour définir une condition `true` ou `false` pour chaque lettre de l'alphabet anglais.
N'importe quelle valeur disposant d'assez de bits pour gérer l'ensemble de conditions `true` ou `false` nécessaires peut servir de masque de bits.
Définir et lire les bits individuels se fait à l'aide des opérateurs bit à bit.

## Opérateurs bit à bit

Imaginons que l'on veuille savoir quelles lettres apparaissent dans une `string`.
Pour notre exemple, on utilisera uniquement les vingt-six lettres de l'alphabet anglais.
Notre masque de bits sera un entier non signé de 32 bits.
Un `0` indiquera que la lettre n'est pas présente.
Un `1` indiquera que la lettre apparaît une ou plusieurs fois.
Au départ, la représentation binaire de notre masque de bits sera une suite de 32 `0s` : `00000000000000000000000000000000`.
La position la plus à droite correspondra à `A`.
La deuxième en partant de la gauche correspondra à `B`, et ainsi de suite.
Supposons que l'on parcoure toutes les lettres de la _string_ dans une boucle : on veut donc une seule ligne de code qui fonctionne pour définir n'importe quelle lettre.

### Opérateur de décalage à gauche bit à bit : un moyen de positionner un bit

`<<` est l'opérateur bit à bit de décalage à gauche.

Si notre lettre est `A`, on ne souhaite pas décaler vers la gauche, mais si notre lettre est `B`, on souhaite décaler d'une position vers la gauche, et si notre lettre est `C`, on souhaite décaler de deux positions, et ainsi de suite.
Bien que l'on puisse percevoir les `chars` comme des lettres telles que `A` ou `B`, un `char` est implémenté comme un type entier en mémoire, ce qui permet de faire de simples calculs avec un `char`.
Étant donné une variable nommée `letter` qui représente le `char` en cours de traitement, on peut décaler vers la gauche du nombre de positions nécessaires en décalant `1` vers la gauche de la différence entre `letter` et le `char` `A`, comme ceci : `1 << letter - 'A'`.
`A` - `A` vaut `0`, donc on décale vers la gauche de `0` position si `letter` vaut `A`.
`B` - `A` vaut `1`, donc on décale vers la gauche de `1` position si `letter` vaut `B`, et ainsi de suite.

### Opérateur OU inclusif bit à bit : un moyen de mettre un bit à 1

Une fois que l'on sait _où_ l'on veut mettre un bit à 1, on peut effectivement le faire grâce à l'opérateur OU inclusif bit à bit, qui est `|`.
Le résultat de l'opérateur `|` vaut `1` à chaque position où l'opérande gauche ou l'opérande droit a un bit à 1.
Ainsi, le résultat de `0010 | 0001` est `0011`.
(Il est important de garder à l'esprit que la valeur vaut `11` en binaire, mais `3` en décimal.)
Pour affecter le résultat à une valeur, on peut combiner l'opérateur `|` avec l'opérateur d'affectation afin de définir les bits comme ceci : `|=`.
Pour rester simple, l'exemple suivant n'utilise pas de boucle, mais il montre comment on pourrait traiter les lettres `ABA` dans un masque de bits.

```c
#include <stdio.h>
#include <stdint.h>

int main() {
    // it's important to initialize the mask to 0 so we don't get garbage values
    uint32_t mask = 0;
    char letter_A = 'A';
    char letter_B = 'B';
    char letter_A_again = 'A';
    mask |= 1 << letter_A - 'A';
    mask |= 1 << letter_B - 'A';
    mask |= 1 << letter_A_again - 'A';
    // prints 3
    printf("%d", mask);
}
```

On met la partie la plus à droite de notre masque à `0001` pour `A`, puis on met le masque à `0011` pour `B`.
Définir un autre `A` n'entraîne aucun changement du masque existant.
On aurait pu éviter de définir le bit une nouvelle fois en vérifiant si `A` avait déjà été défini.

### Opérateur ET bit à bit : un moyen de lire un bit

`&` est l'opérateur ET bit à bit.
Le résultat de l'opérateur `&` vaut `1` à chaque position où l'opérande gauche et l'opérande droit ont tous les deux un bit à 1.
Ainsi, le résultat de `0011 & 0001` est `0001`.
On peut le voir en action dans l'exemple suivant.

```c
#include <stdio.h>
#include <stdint.h>

int main() {
    uint32_t mask = 0;
    char letter_A = 'A';
    char letter_B = 'B';
    char letter_A_again = 'A';
    mask |= 1 << letter_A - 'A';
    mask |= 1 << letter_B - 'A';
    // prints A already set
    if (mask & 1 << letter_A_again - 'A')
        printf("A already set\n");
    else
        mask |= 1 << letter_A_again - 'A';
    printf("%d", mask);
}
```

### Opérateur OU exclusif bit à bit : un moyen d'inverser un bit

`^` est l'opérateur OU exclusif bit à bit.
Un opérateur OU _inclusif_ implique qu'il existe un opérateur OU _exclusif_ au comportement différent.
Le résultat de l'opérateur `^` vaut `1` à chaque position où _un seul_ des opérandes gauche ou droit a un bit à 1.
Ainsi, le résultat de `0001 ^ 0011` est `0010`.
Le bit le plus à droite ne sera pas défini, car _les deux_ opérandes ont `1` à la position la plus à droite.
L'opération OU exclusif est parfois notée XOR.
Si le résultat d'une valeur à laquelle on a appliqué un XOR est lui-même soumis à un XOR, on obtient la valeur d'origine.
On peut s'en servir pour un chiffrement très simple, où la même clé sert à la fois à chiffrer et à déchiffrer les données.
Par exemple

```c
#include <stdio.h>

int main() {
    char a = 'a';
    char b = 'b';
    char c = 'c';
    // we will use "a" for the "key"
    char first = a ^ 'a';
    char second = b ^ 'a';
    char third = c ^ 'a';
    // prints three "dots" for unprintable characters
    printf("%c %c %c\n", first, second, third);
    // prints the ascii values 0 3 2
    printf("%d %d %d\n", first, second, third);
    first = first ^ 'a';
    second = second ^ 'a';
    third = third ^ 'a';
    // prints a b c
    printf("%c %c %c\n", first, second, third);
    // prints the ascii values 97 98 99
    printf("%d %d %d\n", first, second, third);
}
```

### Opérateur de décalage à droite bit à bit : un moyen de diviser une valeur par deux

`>>` est l'opérateur bit à bit de décalage à droite.
En général, chaque position de décalage des bits d'une valeur vers la droite divise cette valeur par deux.
Par exemple

```c
#include <stdio.h>

int main() {
    int number = 16;
    number >>= 2;
    // prints 4, or 16 / 2 = 8 / 2 = 4
    printf("%d\n", number);
}
```

Si la valeur de l'opérande droit est négative ou supérieure ou égale à la largeur de l'opérande gauche promu, le comportement est indéfini.
Cela vaut également pour l'opérateur de décalage à gauche.
Lorsqu'on utilise un entier signé plutôt qu'un entier non signé, le caractère signé peut aussi entrer en jeu.
L'exemple suivant montre le comportement d'un système lorsqu'on décale trop loin vers la gauche ou vers la droite pour un entier signé.

```c
#include <stdio.h>

int main() {
    int number = 16;
    number <<= 250;
    // prints 1073741824
    printf("%d\n", number);
    number <<= 1;
    // prints -2147483648
    printf("%d\n", number);
    number <<= 1;
    // prints 0
    printf("%d\n", number);
    // total shifts are now 256, done incrementally
    number <<= 4;
    // prints 0
    printf("%d\n", number);
    number = 16;
    // prints 16 when 256 total shifts done at once
    printf("%d\n", number << 256);
    // prints 0 when bits shifted right far enough
    printf("%d\n", number >> 5);    
    // still prints 0
    printf("%d\n", number >> 255);
    // prints 16 when shifted right far enough to "wrap around"
    printf("%d\n", number >> 256);
}
```

Comme le comportement est indéfini, un autre système peut produire des résultats différents.
Lorsque l'on décale des bits, il est important de bien comprendre les limites du type de données utilisé.

## Champs de bits

On a vu comment des bits regroupés dans un type de données simple peuvent être adressés par leur position.
Les bits regroupés dans une `struct` peuvent être adressés par leur nom.
Un tel type de données s'appelle un `bit field`.
Un cas d'usage des `bit fields` est lorsqu'on a besoin d'une collection de drapeaux ON/OFF et que l'on souhaite minimiser l'utilisation de la mémoire.

```c
#include <stdio.h>

int main() {

    struct lights {
        unsigned int number_of_lights;
        unsigned int red   : 1;
        unsigned int green : 1;
        unsigned int blue  : 1;
    };
    struct lights lightboard = {3, 0, 0, 0};
     
    //  prints 000
    printf("%d", lightboard.red);
    printf("%d", lightboard.green);
    printf("%d\n", lightboard.blue);
    
    lightboard.green = 1;

    //  prints 010
    printf("%d", lightboard.red);
    printf("%d", lightboard.green);
    printf("%d\n", lightboard.blue);
    
    // prints 3
    printf("%d\n", lightboard.number_of_lights);
}
```

La syntaxe `unsigned int variable_name : 1;` crée un champ de `1` bit dans un `unsigned int` placé à l'intérieur de la structure.
Au lieu d'un `unsigned int`, on pourrait utiliser un `signed int`, ou, à partir de C99, un type `bool`.
Une structure contenant des champs de bits peut aussi contenir des champs d'autres types de données, tels que `number_of_lights` dans l'exemple ci-dessus.
