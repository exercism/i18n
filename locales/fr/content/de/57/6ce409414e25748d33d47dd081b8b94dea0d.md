# Introduction

Les génériques permettent d'écrire du code qui fonctionne avec plusieurs types sans duplication. Définis des types génériques en utilisant des chevrons `<T>`, où `T` est un espace réservé pour n'importe quel type.

```rust
fn largest_list<T>(l1: Array<T>, l2: Array<T>) -> Array<T> {
    if l1.len() > l2.len() {
        l1
    } else {
        l2
    }
}
```

Cairo exige des bornes de _trait_ pour spécifier quelles opérations le type générique doit prendre en charge. Tu peux ajouter des contraintes avec la syntaxe `+` :

```rust
fn process_data<T, +Drop<T>, +Copy<T>>(value: T) -> T {
    // Function body
}
```

Les structures peuvent aussi être génériques :

```rust
#[derive(Drop)]
struct Container<T> {
    value: T,
}
```

Les _traits_ peuvent aussi être génériques, ce qui leur permet de fonctionner avec différents types :

```rust
trait Processor<T> {
    fn process(self: @T) -> ByteArray;
}

impl MyProcessor<T, +Drop<T>> of Processor<T> {
    fn process(self: @T) -> ByteArray {
        "processed"
    }
}
```

Les fonctions peuvent accepter des paramètres génériques avec des bornes de _trait_, ce qui leur permet de fonctionner avec tout type qui implémente le _trait_ requis :

```rust
fn use_processor<T, +Processor<T>, +Drop<T>>(item: T) -> ByteArray {
    item.process()
}
```
