# À propos

En Gleam, les dicts sont la structure de données qui permet de stocker des informations sous forme de paires clé-valeur. Dans d'autres langages, ces structures portent aussi le nom de tableaux associatifs, tables de hachage ou dictionnaires.

Un dict accepte n'importe quel type pour ses clés comme pour ses valeurs, et il ne garantit pas l'ordre de ses entrées lorsqu'on y accède ou qu'on le récupère.

## Manipule les dicts

On crée et on manipule les dicts à l'aide des fonctions du module `gleam/dict`.

```gleam
// Create an empty dict
let dict1 = dict.new()

// Create a dict with some values
let dict2 = dict.from_list([
  #("name", "Gleam"),
  #("colour", "Pink"),
])

// Add a value to a dict
let dict3 = dict.insert(dict2, "website", "https://gleam.run")

// Get a value from a dict
let name = dict.get(dict3, "name")
// -> Ok("Gleam")
```
