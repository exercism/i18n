# Indices

## Général

- Utilise le [type tableau (chaîné)][list] intégré.

## 1. Définis une fonction qui renvoie un tableau de langages vide

- La fonction doit renvoyer `[]`.

## 2. Définis une fonction qui ajoute un langage au tableau

- On peut ajouter un élément en tête d'un tableau avec `:`.

## 3. Définis une fonction qui retire un langage du tableau

- Haskell [fournit une fonction][tail] qui renvoie un tableau sans le premier élément.

## 4. Définis une fonction qui renvoie le premier élément du tableau

- Haskell [fournit une fonction][head] pour récupérer le premier élément d'un tableau.

## 5. Définis une fonction qui renvoie le nombre de langages dans le tableau

- Haskell [fournit une fonction][length] pour compter la longueur d'un tableau.

## 6. Définis une fonction qui détermine si le tableau contient un langage fonctionnel

- Ta fonction doit renvoyer une valeur booléenne indiquant si `"Haskell"` fait partie du tableau. 
  Haskell [fournit une fonction][elem] pour tester l'appartenance à un tableau.
