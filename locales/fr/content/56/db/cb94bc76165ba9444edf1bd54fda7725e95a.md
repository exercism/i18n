# Instructions

Ton ami vient de t'envoyer un message contenant un secret important.
Pour ne pas en faciliter la lecture aux autres, le message a été chiffré au moyen d'une série de manipulations de bits.
Tu vas devoir écrire les fonctions qui permettent de déchiffrer le message.

## 1. Décale les bits vers la droite

La première étape du déchiffrement consiste à annuler le décalage effectué lors du chiffrement, en décalant les bits vers la droite.
Les étapes suivantes du déchiffrement supposent que des `0` sont insérés par la gauche.

Implémente la fonction `shiftBack` qui prend un nombre de positions de décalage et une valeur, puis effectue le décalage.

```elm
shiftBack 2 42 --> 10
```

## 2. Mets certains bits à 1

Ensuite, certains bits doivent être mis à `1`.

Implémente la fonction `setBits` qui prend un masque et une valeur, et renvoie le résultat de la mise à `1` des bits de la valeur.
Un bit de la valeur doit être mis à `1` là où le bit correspondant du masque vaut lui aussi `1`.
Tous les autres bits doivent rester inchangés.

```elm
setBits 66 212 --> 64
```

## 3. Inverse des bits spécifiques

Certains bits sont inversés lors du chiffrement.
Il faudra les inverser à nouveau pour déchiffrer le message.

Implémente la fonction `flipBits` qui prend un masque et une valeur.
Le masque indique quels bits de la valeur doivent être inversés.
Si le bit vaut `1` dans le masque, le bit correspondant est inversé dans la valeur.
Tous les autres bits restent inchangés.

```elm
flipBits 23 157 --> 138
```

## 4. Mets des bits spécifiques à zéro

Il y a aussi des bits qui se déchiffrent toujours en 0.

Implémente la fonction `clearBits` qui prend un masque et une valeur.
Les bits de `value` doivent être mis à 0 là où le bit du masque vaut 1.
Tous les autres bits doivent rester inchangés.

```elm
clearBits 2 15 --> 13
```

## 5. Déchiffre un message

Maintenant que tu disposes de toutes les fonctions nécessaires, tu peux décoder le message de ton ami.
Implémente la fonction `decrypt` qui effectue les opérations suivantes :

1. Mets à 1 les bits de l'année de naissance de ton ami (1996)
2. Inverse le résultat avec l'année de ta première rencontre avec ton ami (2009)
3. Décale les bits vers la droite du nombre de cours que tu suis avec ton ami (5)
4. Mets à zéro le premier et le cinquième bit.

```elm
decrypt 380182 --> 11840
```

Implémente `decrypt` à l'aide de toutes les fonctions que tu as implémentées dans les tâches précédentes.
