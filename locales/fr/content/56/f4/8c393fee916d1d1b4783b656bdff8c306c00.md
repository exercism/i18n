# Instructions

Dans cet exercice, tu vas écrire du code pour imprimer des badges nominatifs pour les employés d'une usine. Les employés ont un identifiant, un nom et un nom de département. Les étiquettes des badges des employés sont formatées comme suit : `"[id] - name - DEPARTMENT"`.

## 1. Imprime un badge pour un employé

Implémente la fonction `NameBadge.print/3`. Elle prend un identifiant, un nom et un département. Elle doit renvoyer l'étiquette du badge, avec le nom du département en majuscules.

```elixir
NameBadge.print(67, "Katherine Williams", "Strategic Communication")
# => "[67] - Katherine Williams - STRATEGIC COMMUNICATION"
```

## 2. Imprime un badge pour un nouvel employé

En raison d'une bizarrerie du système informatique, il arrive que les nouveaux employés n'aient pas encore d'identifiant lorsqu'ils commencent à travailler à l'usine. Comme les badges sont obligatoires, ils reçoivent un badge temporaire sans le préfixe d'identifiant.

Étends la fonction `NameBadge.print/3`. Lorsque l'identifiant est absent, elle doit imprimer un badge sans celui-ci.

```elixir
NameBadge.print(nil, "Robert Johnson", "Procurement")
# => "Robert Johnson - PROCUREMENT"
```

## 3. Imprime un badge pour le propriétaire

Même le propriétaire de l'usine doit porter un badge en permanence. Cependant, un propriétaire n'a pas de département. Dans ce cas, l'étiquette doit imprimer `"OWNER"` à la place du nom du département.

Étends la fonction `NameBadge.print/3`. Lorsque le département est absent, considère que le badge appartient au propriétaire de l'entreprise.

```elixir
NameBadge.print(204, "Rachel Miller", nil)
# => "[204] - Rachel Miller - OWNER"
```

Note qu'il est possible que le propriétaire soit aussi un nouvel employé.

```elixir
NameBadge.print(nil, "Rachel Miller", nil)
# => "Rachel Miller - OWNER"
```
