# À propos

[Les tableaux][list] sont un type de données de base en Haskell qui permet de stocker une collection de valeurs.
Les tableaux sont _immuables_, ce qui signifie qu'on ne peut pas les modifier.
Toute opération qui modifie un tableau renvoie un nouveau tableau.
Le Prelude propose plusieurs fonctions qui te permettent de travailler avec les tableaux.

En Haskell, les tableaux sont implémentés sous forme de [tableaux chaînés][linked-list-wiki], et non sous forme de tableaux de zones mémoire contiguës.
Par conséquent, accéder à un élément d'un tableau prend un temps linéaire qui dépend de la longueur du tableau.

Les tableaux peuvent s'écrire sous forme littérale, en notation tête-queue (qui utilise l'opérateur `cons` `:`) ou par une combinaison des deux :

```haskell
-- Literal Form
[]
[1]
[1, 2, 3]

-- Head-tail Notation
[]
-- same as [1]
1 : []
-- same as [1, 2, 3]
1 : (2 : (3 : []))

-- Mixed
-- same as [1, 2, 3]
1 : [2, 3]
```

La notation tête-queue permet d'ajouter des éléments à un tableau.

```haskell
list = [2, 1]

[3, 2, 1] == 3 : list
-- -> True
```

Ajouter des éléments à un tableau pendant qu'on l'itère est considéré comme un _anti-pattern_.
Ajouter un élément oblige à parcourir tout le tableau pour le placer à la fin ; par conséquent, ajouter un nouvel élément à chaque itération obligerait à parcourir tout le tableau à chaque itération.

On obtient le même résultat en ajoutant l'élément en tête d'un tableau inversé, puis en inversant le résultat. L'ajout en tête est une opération rapide, qui se fait en temps constant.

```haskell
-- Appending to the end of a list (potentially slow)
[1, 2, 3] ++ [4] ++ [5] ++ [6]

-- Prepend to the start of a list (faster, due to the nature of linked lists)
6 : (5 : (4 : [3, 2, 1]))
-- then reverse!
```

Voici quelques fonctions courantes du Prelude pour les tableaux :

- [`head`][head] renvoie la _tête_ d'un tableau, c'est-à-dire le _premier_ élément du tableau.
- [`tail`][tail] renvoie la _queue_ du tableau, c'est-à-dire le tableau _privé_ de son _premier_ élément.
- [`length`][length] renvoie le nombre d'éléments du tableau.
- [`elem`][elem] renvoie une valeur booléenne qui indique si l'élément figure dans le tableau.

Il existe aussi le [module `Data.List`][list].

## Types de tableaux

En Haskell, les tableaux sont **homogènes**.
Cela signifie que tous les éléments d'un tableau ont le même type.
Si tu essaies de mettre des éléments de types différents dans le même tableau, tu obtiendras une erreur de type.

```haskell
list = [1, "string"]
-- Error: No instance for (Num String) arising from the literal ‘1’
```

L'annotation de type d'un tableau est `[a]`, où `a` désigne le type que le tableau contient, par exemple `String` ou `Int`.

``` haskell
a :: [Int] 
a = [1, 2, 3]
```
