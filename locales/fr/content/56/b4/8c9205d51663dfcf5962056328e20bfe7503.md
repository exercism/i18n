# Instructions

La Bellebrook Basketball League est une ligue composée de plusieurs équipes, chacune avec un effectif de joueurs.
Une nouvelle saison est sur le point de commencer et la ligue doit créer un nouveau système de billetterie pour vendre des billets pour les matchs.
La saison dernière, elle vendait les billets à l'entrée du stade, mais sa popularité a explosé et elle a décidé de vendre les billets en ligne cette saison pour faire face à la demande accrue.

La ligue t'a contacté et t'a demandé de créer un système pour gérer la vente des billets.

## 1. Crée un système de billetterie

Pour commencer, tu dois créer un système de billetterie pour gérer la vente des billets.
Le système de billetterie doit indiquer combien de billets sont disponibles pour un match.

Une instance d'une classe appelée `TicketSystem` doit être créée pour chaque match.
L'état initialisé doit contenir les informations suivantes :

1. Le nombre de billets disponibles pour le match.
2. Le stade dans lequel le match est joué.

Construis un état initialisé à partir d'arguments indiquant le nombre de billets disponibles et le stade dans lequel le match est joué.
L'état initialisé doit être composé des variables d'instance `@tickets_available` et `@stadium`.
Celles-ci doivent contenir respectivement le premier et le deuxième argument fournis.

```crystal
TicketSystem.new(100, "Bellebrook")
# => #<TicketSystem:0x10f0b8 @tickets_available=100, @stadium="Bellebrook">
```

## 2. Obtiens le nombre de billets disponibles

Pour commencer, tu dois créer une méthode qui renvoie le nombre de billets disponibles pour un match donné.

Définis un module appelé `TicketingReservation` au-dessus de la classe déjà définie.
Ce module doit être inclus dans la classe `TicketSystem`.

À l'intérieur du module, définis une méthode appelée `tickets_available`.
Cette méthode doit renvoyer le nombre de billets disponibles.

```crystal
ticket_system = TicketSystem.new(100)
ticket_system.tickets_available
#=> 100
```

## 3. Commande des billets

Tu dois créer une méthode qui vérifie si des billets sont disponibles pour un match donné.
Le match doit avoir 100 billets en réserve.
Cela permet de garantir qu'il y a toujours des billets disponibles pour les personnes qui achètent leurs billets à l'entrée du stade.

À l'intérieur du module `TicketingReservation,`, définis une méthode appelée `order_ticket?`.
La méthode doit renvoyer `true` si au moins 100 billets sont disponibles et `false` sinon.
Si au moins 100 billets sont disponibles, la méthode doit aussi diminuer de 1 le nombre de billets disponibles.

```crystal
ticket_system = TicketSystem.new(100)
ticket_system.order_ticket?
#=> true
```

## 4. Message de commande

Le système de billetterie doit avoir des messages faciles à comprendre pour les utilisateurs.
Et ces messages doivent être personnels, ils doivent donc inclure le nom de l'utilisateur.

Si l'achat du billet a réussi, l'utilisateur doit recevoir un message lui indiquant que l'achat a réussi, son numéro de billet et le stade dans lequel le match est joué.
Le numéro de billet doit être le nombre de billets disponibles avant la commande.

Si l'achat a réussi, le message doit ressembler à ceci : `{name}, your purchase was successful, your ticket number is #{ticket_number}, and the game is played at the {stadium_name} stadium.`.
Si l'achat a échoué, le message doit ressembler à ceci : `{name}, your purchase was unsuccessful, there are not enough tickets available.`.

À l'intérieur du module `TicketingReservation,`, définis une méthode appelée `order_message` qui prend un argument `name` contenant le nom de l'acheteur.
La méthode doit renvoyer une _string_ avec le message.

```crystal
ticket_system = TicketSystem.new(100, "Bellebrook")
ticket_system.order_message("John")
#=> "John, your purchase was successful, your ticket number is #100, and the game is played at the Bellebrook stadium."
```
