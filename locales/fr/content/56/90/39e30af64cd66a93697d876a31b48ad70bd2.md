# Installe `testthat`

Les tests de ce parcours utilisent le paquet `testthat`.

Pour installer le paquet, il suffit d'ouvrir R et d'exécuter :

`install.packages("testthat")`

Tu peux vérifier que le paquet est bien installé en exécutant :

`library(testthat)`

# Lance les tests

Chaque problème comporte un script nommé `test_<exercise-name>.R` (par exemple `test_hello-world.R`).

Pour lancer les tests d'un exercice, il suffit d'exécuter ce script R.

Dans RStudio, il suffit d'ouvrir le script de test et de cliquer sur _« Source »_ en haut à droite du volet source. Cela charge le code de ta solution via la commande `source` présente sur la première ligne du script de test, puis exécute la série de tests `testthat` qui suit.

Note cependant que la commande `source()` de la première ligne du script de test ne fonctionne que si le script de ta solution (`<exercise-name>.R`) se trouve dans ton répertoire de travail. Si ce n'est pas le cas, tu devras soit :
- changer de répertoire de travail, par exemple `setwd('exercism/r/hello-world/')`, soit
- modifier la première ligne du script de test, par exemple `source('exercism/r/hello-world/hello-world.R')`

Si tu préfères, tu peux aussi lancer les tests depuis la ligne de commande avec `Rscript path_to_exercise_directory/test_<exercise-name>.R` (par exemple `Rscript hello-world/test_hello-world.R`)

Une autre façon pratique de lancer ces tests est d'utiliser [la fonction `auto_test` de testthat](https://www.rdocumentation.org/packages/testthat/topics/auto_test). Comme le code et les tests d'Exercism se trouvent dans le même dossier, utilise ce même chemin pour les paramètres `code_path` et `test_path`. Après avoir lancé `auto_test()`, les tests de l'exercice seront exécutés automatiquement chaque fois que tu mettras à jour ou enregistreras ton code R pour l'exercice. Cela peut faciliter une itération rapide pendant que tu travailles sur ta solution.
