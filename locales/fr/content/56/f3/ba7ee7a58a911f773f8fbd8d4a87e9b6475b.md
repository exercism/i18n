# Introduction

Common Lisp permet au programmeur d'écrire des «\u00a0commentaires\u00a0» que l'ordinateur ignore.
Les commentaires sur une seule ligne commencent par un ou plusieurs points-virgules (`;`) et, parfois, on peut voir ce qui suit\u00a0:

```lisp
(code...) ; => value
```

Ici, le commentaire sert à indiquer la valeur renvoyée par Common Lisp après l'exécution du code de cette ligne.

Il est idiomatique d'utiliser un seul point-virgule pour un commentaire court en fin de ligne, deux pour un commentaire plus long au-dessus d'une section de code, trois pour un commentaire long décrivant quelque chose comme une fonction, et quatre pour un commentaire tel qu'un en-tête en haut d'un fichier source.
