# Installation

Phix pour Windows ou Linux peut être téléchargé depuis [le site officiel][Download].

Après l'installation, l'arborescence des répertoires doit correspondre à celle donnée dans la [documentation][Installation].

Teste en exécutant 'p -test'.

[Installation]: http://phix.x10.mx/docs/html/installation.htm
[Download]: http://phix.x10.mx/download.php
