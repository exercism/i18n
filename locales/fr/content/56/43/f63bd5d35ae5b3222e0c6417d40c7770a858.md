# Introduction

## Chaînes de caractères

Une _chaîne de caractères_ est une suite de caractères, entourée de guillemets.
Les guillemets simples comme les guillemets doubles sont pris en charge.

```php
<?php

$where = "Spain";
$what = 'rain';
```

### Interpolation de variables dans les chaînes

Dans les _strings_ entre guillemets doubles, si une variable est référencée alors qu'elle se trouve dans la portée, sa valeur est insérée dans la _string_.

```php
<?php

$answer = 42;
$expanded = "The answer to life, the universe, and everything is $answer"; 
```

### Prise en charge de l'encodage des caractères

Historiquement, les fonctions de gestion des chaînes en PHP ne prenaient en charge que les caractères ASCII et ne géraient pas les encodages Unicode modernes.
Chaque caractère ASCII fait 1 octet, tandis qu'un caractère Unicode peut faire de 1 à 4 octets.
Si tu as besoin de manipuler des _strings_ Unicode en toute sécurité, consulte les [versions multi-octets][multi-byte-fns] des fonctions historiques.

```php
<?php

$byte_length = strlen('😃'); // => 4
$string_length = mb_strlen('😃'); // => 1
```

[multi-byte-fns]: https://www.php.net/manual/en/ref.mbstring.php
