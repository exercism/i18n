# Indices

## Généralités

- `matches?`, `all-matching-subseqs`, `count-matches` et `re-replace` se trouvent tous dans [`regexp`][regexp]. Écris chaque motif sous forme de littéral entre `R/ ` et `/`.
- Un code de badge valide se compose de deux majuscules, d'un tiret et de quatre chiffres : `R/ [A-Z]{2}-\d{4}/`.

## 1. Vérifie un code de badge

- `matches?` teste la _string_ *entière*, ce qui est exactement ce qu'exige la question « est-ce un code de badge valide ? » : `R/ [A-Z]{2}-\d{4}/ matches?`.

## 2. Extrais tous les codes d'une ligne de journal

- `all-matching-subseqs` renvoie chaque correspondance sous la forme d'une séquence de _strings_. Passe-lui le même motif de code de badge.

## 3. Compte les chiffres d'un code

- `\d` correspond à un chiffre ; `count-matches` compte combien de fois le motif correspond : `R/ \d/ count-matches`.

## 4. Masque les mots de passe

- `\S` signifie « un caractère qui n'est pas un espace », donc `R/ pass=\S+/` correspond à `pass=` suivi du secret.
- `re-replace` prend la _string_, le motif et le texte de remplacement `"pass=****"`.

[regexp]: https://docs.factorcode.org/content/vocab-regexp.html
