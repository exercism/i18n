# À propos

En Haxe, les exceptions sont un moyen sûr de gérer les erreurs qui se produisent lors de l'exécution du code. Toutes les exceptions doivent contenir un message décrivant l'erreur. On peut _lancer_ des exceptions à l'aide du mot-clé `throw` :

```haxe
public function main(num:Int) {
  if (num < 10) {
    throw "Argument num cannot be greater than 10";
  }
  // ...
}
```

Quand une exception est lancée, le code cherche la portion qui est chargée de gérer l'erreur. S'il n'en trouve pas, il affiche le message d'erreur tout en arrêtant l'exécution du programme.

Pour gérer les exceptions en Haxe, on utilise le bloc `try-catch`. Cette structure se compose d'un bloc `try` et d'un ou plusieurs blocs `catch`. Le bloc `try` _essaie_ d'exécuter un morceau de code, tandis que le bloc `catch` attend qu'une exception soit lancée pour l'_attraper_, afin que l'exécution ne soit pas interrompue. Lorsque le bloc `catch` attrape une exception, il exécute aussi tout ce qui se trouve à l'intérieur du bloc :

```haxe
try {
  if (num < 10) {
    throw "Argument num cannot be greater than 10";
  }
} catch (e) {
  // All exceptions will be caught here
  trace(e.message); // Argument num cannot be greater than 10
}
```

Le type de l'argument du bloc `catch` doit être omis.

Il est important de noter que les exceptions doivent être utilisées dans les cas où quelque chose d'exceptionnel se produit, une erreur qui nécessite un traitement particulier. Il ne faut pas les utiliser pour le flux de contrôle d'un programme, car cela est considéré comme une mauvaise conception, ce qui nuit souvent aux performances et à la maintenabilité.
