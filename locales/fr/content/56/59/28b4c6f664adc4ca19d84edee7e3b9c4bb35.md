# Paramètres variadiques

Les [_paramètres variadiques_][variadic-parameters] en Swift permettent de passer zéro ou plusieurs valeurs du même type dans un seul paramètre d'une fonction. Cela se note en ajoutant `...` à l'annotation de type du paramètre.

Ces valeurs sont automatiquement regroupées dans un tableau dont les éléments ont le même type que le paramètre variadique.

```swift
func geometricMean(_ numbers: Double...) -> Double {
  var total = 1.0
  for number in numbers {
      total *= number
  }
  return pow(total, 1.0 / Double(numbers.count))
}

geometricMean(1, 2, 3, 4, 5)
// => 2.605171084697352
```

À noter que, lorsqu'on utilise des paramètres variadiques, Swift présente une limitation.
Si une fonction a des paramètres qui suivent le paramètre variadique dans sa définition, le premier paramètre qui suit le paramètre variadique _doit_ avoir une étiquette d'argument.

[variadic-parameters]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/functions/#Variadic-Parameters
