# À propos

Par défaut, les valeurs en C# sont _mutables_, c'est-à-dire qu'elles peuvent changer au fil du temps. Pour rendre une valeur _immuable_, deux options existent :

1. Ajouter le [modificateur `const`][const-modifier].
2. Ajouter le [modificateur `readonly`][readonly-modifier].

Le modificateur `const` présente quelques restrictions :

1. Il ne peut s'appliquer qu'aux types « constants » : les _strings_, les booléens et les nombres.
2. La valeur `const` doit être initialisée immédiatement.

Voir [définir des constantes][defining-constants] pour plus d'informations.

Si la valeur est d'un type non constant ou qu'il faut l'initialiser dans un constructeur, on peut utiliser `readonly` pour garantir son immutabilité.
