# Introduction

Une expression booléenne est une question posée à une ou plusieurs valeurs, à laquelle on peut répondre par `true` ou `false`.
Une expression vraie renvoie `1` ; une expression fausse renvoie `0`.
De plus, les nombres ont aussi une valeur de vérité. Zéro vaut `false` ; tout nombre différent de zéro vaut `true`.

Dans l'ancien code C, soit on utilisait directement le type `int` pour les valeurs booléennes, soit le programmeur avait défini des constantes comme `TRUE` et `FALSE` pour faire correspondre `1` et `0` à une représentation booléenne.

Avec la version C99, le type `_Bool` a été ajouté.
Le fichier d'en-tête `stdbool.h` définit trois nouveaux symboles booléens : `bool`, `true` et `false`.
`true` correspond à `1` ; `false` correspond à `0` ; et `bool` correspond à `_Bool`.
Désormais, au lieu d'utiliser directement des `int` ou de créer eux-mêmes leurs propres correspondances booléennes, les programmeurs peuvent inclure `stdbool.h` et obtenir automatiquement des symboles booléens dans leur code.

## Opérateurs de comparaison

C prend en charge six opérateurs de comparaison : `==` (égal à), `!=` (différent de), `>` (supérieur à), `<` (inférieur à), `>=` (supérieur ou égal à) et `<=` (inférieur ou égal à).
Ces opérateurs comparent les relations entre les valeurs et les résolvent en valeurs booléennes.

```c
0 == 0 // true. Although 0 is false, 0 equals 0 is true.
0 != 0 // false
1 > 0 // true
1 < 0 // false
1 >= 0 // true
1 <= 0 // false
```

## Opérateurs booléens

C prend en charge trois opérateurs booléens : `||` (OU), `&&` (ET) et `!` (PAS).

L'opérateur `!` s'utilise avec un seul opérande.
Il inverse la valeur booléenne de l'opérande.
Par exemple, `0` vaut `false`, mais `!0` vaut `true`.

Les opérateurs `||` et `&&` s'utilisent avec deux opérandes.
L'opérande de droite n'est évalué que lorsque l'opérande de gauche ne détermine pas déjà le résultat de l'expression.
Autrement dit, `||` n'évalue son opérande de droite que lorsque son opérande de gauche vaut `false`.
`&&` n'évalue son opérande de droite que lorsque son opérande de gauche vaut `true`.
