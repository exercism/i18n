# Instructions

Dans cet exercice, tu vas appliquer les [règles du jeu de Go](https://matmoore.github.io/learngo/). Les règles elles-mêmes sont déjà écrites, tu n'as plus qu'à les appliquer pour mettre à jour la partie et gérer les éventuelles erreurs ou violations des règles.

La partie est représentée de la façon suivante :

```gleam
pub type Player {
  Black
  White
}


pub type Game {
  Game(
    white_captured_stones: Int,
    black_captured_stones: Int,
    player: Player,
    error: String,
  )
}
```

Le jeu comporte 4 règles :

- Chaque point ne peut porter qu'une seule pierre.
- Les pierres adverses peuvent être capturées.
- Tu ne peux pas poser une pierre là où elle se capturerait elle-même.
- Tu ne peux pas utiliser le même point deux fois.

## 1. Applique les règles

Écris le contenu de la fonction `apply_rules`, qui prend une `Game` initiale et un ensemble de règles, et qui renvoie la nouvelle `Game` une fois les règles appliquées.

Trois de ces règles vérifient qu'il n'y a pas de violation des règles et peuvent renvoyer une erreur ; elles ont donc pour type de retour `Result(Game, String)`. Si l'une de ces règles échoue, la partie d'origine doit être renvoyée, mais avec le champ `error` mis à jour avec l'erreur correspondante.

L'autre règle ne vérifie pas les violations et ne peut donc pas échouer (même si elle peut renvoyer une `Game` modifiée) ; elle a donc pour type de retour `Game`.

Si toutes les règles passent, les modifications apportées à la `Game` par les règles doivent être conservées, et le joueur doit être changé.

```gleam
pub fn apply_rules(
  game: Game,
  rule1: fn(Game) -> Result(Game, String),
  rule2: fn(Game) -> Game,
  rule3: fn(Game) -> Result(Game, String),
  rule4: fn(Game) -> Result(Game, String),
) -> Game {
  // -> If all rules pass, return a `Game` with all changes from the rules applied, and change player
  // -> If any rule fails, return the original Game, but with the error field set
}
```
