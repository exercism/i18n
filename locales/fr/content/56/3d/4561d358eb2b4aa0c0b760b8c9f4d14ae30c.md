# Apprentissage

Si tu veux apprendre TypeScript, jette un œil aux ressources suivantes.

- [TS Tutorial](https://www.typescriptlang.org/docs/handbook/release-notes/overview.html)
- [TS Playground](https://www.typescriptlang.org/play)

TypeScript est un sur-ensemble de JS.
TypeScript offre toutes les fonctionnalités de JavaScript, et une couche supplémentaire par-dessus : le système de types de TypeScript.

- [Exploring ES6](https://leanpub.com/exploring-es6) book, by Axel Rauschmayer
- [ES6 Katas](https://jskatas.org/#bundle-es6-katas) website
- [Babel compiler](https://github.com/babel/babel)
