# Analyseurs

Les analyseurs d'Exercism évaluent automatiquement les soumissions des apprenants et fournissent des commentaires dans le style d'un mentor.

## Contribue aux analyseurs

Chaque langage a son propre analyseur, écrit dans ce langage.
Le site web joue le rôle d'orchestrateur entre les analyseurs et les soumissions des apprenants.

Chaque analyseur vit dans l'organisation GitHub d'Exercism, dans un dépôt nommé `<track_slug>-analyzer` (par exemple [`exercism/ruby-analyzer`](https://github.com/exercism/ruby-analyzer)).
Tu peux consulter les analyseurs existants [ici](https://github.com/search?q=topic%3Aexercism-analyzer&type=repositories).

Si tu souhaites t'impliquer dans un analyseur existant, ouvre une _issue_ dans son dépôt en demandant où tu peux aider.
Si tu souhaites créer un analyseur pour un langage qui n'en a pas encore, suis les instructions de la page [Créer un analyseur](/docs/building/tooling/analyzers/creating-from-scratch).
