# À propos

Si les types des paramètres peuvent être déduits, Swift permet aussi d'omettre les noms des paramètres et le mot-clé `in` de la définition de la fermeture. On peut alors faire référence aux paramètres à l'aide d'une [syntaxe abrégée spéciale][shorthand-argument-names], où `$0` désigne le premier paramètre, `$1` le deuxième, et ainsi de suite.

```swift
let mean: (Double, Double) -> Double = { $0 + $1 / 2.0 }

["apple", "ball", "carrot"].sorted(by: { $0.count < $1.count })
```

Ce style est le plus souvent utilisé lorsqu'on passe des fermetures à des fonctions d'ordre supérieur et que la concision est de mise.

[shorthand-argument-names]: https://docs.swift.org/swift-book/LanguageGuide/Closures.html#ID100
