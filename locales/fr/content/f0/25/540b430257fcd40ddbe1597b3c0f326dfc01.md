# À propos

Une [`List`][lists] en Elm est une collection immuable de zéro ou plusieurs valeurs de même type.
Comme les listes sont immuables, une fois qu'une liste est construite, sa valeur ne peut jamais changer.
Les listes en Elm ont une _tête_ (le premier élément) et une _queue_ (tout ce qui suit le premier élément).
La queue d'une liste est elle-même une liste.

Les annotations de type des listes peuvent s'écrire comme suit :

```elm
List String --> a list of String
List Int --> a list of Int
```

On peut définir des listes comme suit :

```elm
empty : List Char
empty = []

singleValue = [ 5 ] --> List Int
singleValueAlternative = List.singleton 5 --> List Int

threeValues = [ "a", "b", "c" ] --> List String
```

La façon la plus courante d'ajouter un élément à une liste est d'utiliser l'opérateur `::` (_cons_) :

```elm
twoToFour = [ 2, 3, 4 ]
oneToFour = 1 :: twoToFour --> [1; 2; 3; 4]
```

On peut concaténer des listes avec l'opérateur `++` ou `List.append` :

```elm
[ 6, 7 ] ++ [ 8, 9 ]           --> [6, 7, 8, 9]
List.append [ 6, 7 ] [ 8, 9 ]  --> [6, 7, 8, 9]
```

Les listes se manipulent à l'aide des fonctions et des opérateurs définis dans le [module `List`][list-module].

```elm
List.length [ 7, 8 ] --> 2
```

Toute fonction ou tout opérateur qui semble modifier une liste (par exemple en ajoutant un élément) renvoie en réalité une nouvelle liste.
Les performances ne sont généralement pas un problème, car l'implémentation des listes évite les allocations et les copies inutiles.

On peut aussi traiter les listes à l'aide du [filtrage par motif][list-destructuring].

```elm
describe : List String -> String
describe list =
    case list of
        [] ->
            "Empty list"

        [ "hello" ] ->
            "Singleton list with: hello"

        x :: xs ->
            "Non-empty list with head: " ++ x

describe []                   --> "Empty list"
describe [ "hello" ]          --> "Singleton list with: hello"
describe [ "hello", "world" ] --> "Non-empty list with head: hello"
```
