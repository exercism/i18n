# Introduction

En Factor, on définit un nouveau mot avec `: name ( stack-effect ) body ;`.
Le corps est une suite de mots ; appeler ton nouveau mot les exécute dans
l'ordre.

```factor
USING: kernel ;
IN: my-vocab

: shout ( str -- str ) "!" append ;
```

Quand une routine devient longue, tu peux, et tu devrais même, la *factoriser* :
extraire des groupes de mots pour en faire des mots plus petits et nommés,
chacun avec une seule tâche. C'est de là que le langage tire son nom.

## Vocabularies

Chaque fichier `.factor` déclare un vocabulaire avec `IN:`. Les mots d'un
vocabulaire peuvent appeler les mots d'un autre en listant cet autre
vocabulaire dans `USING:`.

```factor
! file: my-vocab/helpers/helpers.factor
USING: kernel ;
IN: my-vocab.helpers

: shout-line ( str -- str ) "!" append ;
```

```factor
! file: my-vocab/my-vocab.factor
USING: kernel my-vocab.helpers sequences ;
IN: my-vocab

: announce ( names -- strs )
    [ shout-line ] map ;
```

L'arborescence des répertoires suit le nom du vocabulaire, avec ses points :
le vocabulaire `my-vocab` se trouve dans `my-vocab/my-vocab.factor` ; le
vocabulaire `my-vocab.helpers` se trouve dans
`my-vocab/helpers/helpers.factor`. Le chargeur de Factor suit les
déclarations `USING:` de façon transitive, et charge chaque vocabulaire à la
demande.
