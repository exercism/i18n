# Généralités

La [documentation sur l'instruction `switch`][switch-statement] constitue une introduction aux instructions `switch`.

## 1. Décris les joueurs en fonction de leur numéro de maillot

- L'instruction [`break`][break] est utile.

## 2. Gère les numéros de maillot inconnus

- L'instruction [`default`][default] est utile.

## 3. Étends la couverture aux activités hors terrain

- Le [filtrage par motif sur les types][switch-pattern-matching] est la clé de cette tâche.
- Utilise l'instruction [`default`][default] pour capturer tout autre type.

## 5. Fais un rapport sur les entraîneurs de club

- Consulte cette [documentation][switch-when] pour le mot-clé `when`.
