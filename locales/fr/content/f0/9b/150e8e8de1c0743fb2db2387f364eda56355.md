# Debug

```pyret
fun print-forty-two():
  print(42) # 42
end
```

```pyret
fun return-forty-two() block:
  print(42) # 42
  42
end
```

[print][print] est une expression qui renvoie une valeur.
Pyret n'autorise qu'une seule expression dans un bloc de code donné, sauf si le bloc extérieur est marqué avec `block`.
Dans le deuxième exemple, ajouter `block` à la déclaration de la fonction permet d'afficher 42 avant de le renvoyer.

## Espions

```pyret
fun do-something():
    x = "foo"
    y = "bar"
    spy "strings": x, y end
    a = 1
    b = 2
    spy "numbers": a, b end
end
do-something();

# Spying "strings" (at <clipped>/example.arr:4:4-4:27)
#  x: "foo"
#  y: "bar"
# Spying "numbers" (at <clipped>/example.arr:7:4-7:27)
#  a: 1
#  b: 2
```

Une instruction `spy` prend un libellé facultatif ainsi qu'une ou plusieurs variables, et affiche chaque variable et sa valeur.
Comme ce n'est pas une expression, on peut utiliser `spy` dans un bloc sans devoir marquer le bloc extérieur avec `block`.

[spy]: https://pyret.org/docs/latest/s_spies.html
