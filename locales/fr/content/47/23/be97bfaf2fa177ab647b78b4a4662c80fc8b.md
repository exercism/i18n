# Ajout aux instructions

## Indices

Cet exercice porte sur des données textuelles. Pour des raisons historiques, le type `String` de Haskell est synonyme de `[Char]`, une liste de caractères. Pour un traitement plus efficace des données textuelles, on peut utiliser le type `Text`.

Comme prolongement facultatif à cet exercice, tu peux

- Lire la page sur [les types de chaînes de caractères](https://haskell-lang.org/tutorial/string-types) en Haskell.
- Ajouter `- text` à ta liste de dépendances dans package.yaml.
- Importer `Data.Text` [de la manière suivante](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c) :

        import qualified Data.Text as T
        import           Data.Text (Text)

- Tu peux maintenant écrire par exemple `isIsogram :: Text -> Bool` et désigner les combinateurs de `Data.Text` par exemple par `T.toLower`.
- Consulter la documentation de [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html).

Cette partie est entièrement facultative.
