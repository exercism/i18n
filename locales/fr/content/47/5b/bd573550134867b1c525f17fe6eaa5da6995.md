# Ajout aux instructions

## Indices

Tu dois implémenter la fonction

```haskell
value :: (Color, Color) -> Int
```

qui n'accepte que deux couleurs et produit la composante numérique de la valeur de sa résistance.

**Bonus : tests de propriétés**

Cet exercice est une bonne occasion d'écrire des [tests de propriétés](https://en.wikipedia.org/wiki/Property_testing). Si tu n'en as jamais écrit, voici quelques ressources :

1. [School of Haskell](https://www.schoolofhaskell.com/user/pbv/an-introduction-to-quickcheck-testing).
2. [Real world Haskell](http://book.realworldhaskell.org/read/testing-and-quality-assurance.html)

On a fourni un exemple de test de propriété QuickCheck dans le fichier de test.

Exemples de propriétés que l'on peut tester :

- `value (x, y) >= 10` pour tous les `(x, y)` où `x` n'est pas `Black`

- L'appel de `show` sur `value (x, y)` produit la `reverse` inversée de l'appel de `show` sur `value (y, x)`.

- Toutes les couleurs ont des noms uniques. (Pour deux couleurs quelconques, si les couleurs sont différentes, leurs noms le sont aussi.)
