# utilisation d'un en-tête de fonction

[comment]: # (Cette erreur est levée quand la solution utilise un en-tête de fonction)

Un en-tête de fonction (une définition de fonction sans corps) n'est nécessaire que pour les fonctions avec des arguments par défaut qui ont plusieurs clauses.

```elixir
# necessary function header
def hello(what \\ "World")
def hello("Alice"), do: "Hello, darling!"
def hello(name), do: "Hello, #{name}!"
```

Pour les fonctions avec des arguments par défaut qui n'ont qu'une seule clause, on peut spécifier les arguments par défaut directement dans cette clause.

```elixir
# preferred
def bye(name \\ "World"), do: "See you, #{name}!"

# not preferred - unnecessary function header
def bye(what \\ "World")
def bye(name), do: "See you, #{name}!"
```

La fonction `two_fer/1` n'a besoin que d'une seule clause, et n'a donc pas besoin d'un en-tête de fonction.
