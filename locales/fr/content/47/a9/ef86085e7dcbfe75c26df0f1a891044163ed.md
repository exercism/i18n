# Introduction

L'opérateur `|>` est appelé opérateur _pipe_. Il permet d'enchaîner des appels de fonctions de telle sorte que la valeur renvoyée par l'appel de fonction précédent est passée comme premier argument à l'appel de fonction suivant.

```elixir
"hello"
|> String.upcase()
|> Kernel.<>("?!")

# => "HELLO?!"
```
