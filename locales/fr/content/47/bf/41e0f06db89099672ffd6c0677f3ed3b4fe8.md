# Installation

La version actuelle d'elm est 0.19.1.
Les instructions d'installation changent au fil de l'évolution du langage.
Pour obtenir des instructions d'installation à jour, rends-toi sur
[les instructions d'installation du guide elm][elm-install].

[elm-install]: https://guide.elm-lang.org/install/elm.html

## Outils supplémentaires

**elm-test**

L'outil qui sert à exécuter les tests en ligne de commande s'appelle elm-test.
Actuellement, elm-test nécessite Node.js et npm, donc si ce n'est pas déjà fait,
[installe d'abord Node.js et npm][npm-install].
Une fois npm installé, tu peux installer elm-test avec :

```shell
npm install --global elm-test@latest-0.19.1
```

Plus d'informations sont disponibles sur [la page npm d'elm-test][elm-test].

[npm-install]: https://www.npmjs.com/get-npm
[elm-test]: https://www.npmjs.com/package/elm-test

**elm-format**

La plupart des développeurs elm utilisent elm-format pour formater leur code elm.
C'est un outil de formatage de code sans configuration.
Ça peut sembler un peu frustrant au début quand on n'a pas l'habitude
des outils de formatage automatique, mais une fois qu'on y est habitué,
on se demande comment on pouvait coder sans auparavant.
Il peut aussi s'installer avec npm :

```shell
npm install --global elm-format@latest-0.19.1
```

Plus d'informations sont disponibles sur [la page d'accueil d'elm-format sur GitHub][elm-format].

[elm-format]: https://github.com/avh4/elm-format

**Éditeur de texte**

La prise en charge d'Elm est bonne au moins pour [IntelliJ][intellij],
ainsi que pour les éditeurs de texte compatibles avec le [serveur de langage elm][els],
comme VS Code, Sublime Text ou Vim.

[els]: https://github.com/elm-tooling/elm-language-server
[intellij]: https://github.com/klazuka/intellij-elm

## Erreurs de permission avec npm

Il est possible que tu rencontres une erreur de permissions EACCESS avec npm
lors de l'installation d'elm-test ou d'elm-format.
Si c'est le cas, suis les instructions sur le site de npm.
[Résoudre les erreurs de permissions EACCES lors de l'installation globale de paquets][eaccess].

[eaccess]: https://docs.npmjs.com/resolving-eacces-permissions-errors-when-installing-packages-globally
