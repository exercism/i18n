# Aide

## Installation de Rust

Consulte la [page d'aide d'Exercism][help-page] pour l'installation de Rust et les ressources d'apprentissage.

## Soumettre la solution

En règle générale, soumets tous les fichiers dans lesquels tu as implémenté la solution (`src/lib.rs` dans la plupart des cas). Si tu utilises des _crates_ externes, pense à soumettre le fichier `Cargo.toml`. Cela rendra le processus de revue plus rapide et plus clair.

## Retours, problèmes et _pull requests_

Rends-toi sur [le forum](https://forum.exercism.org/c/programming/rust/) et publie un message pour donner ton retour sur un exercice, ou si tu veux aider à implémenter de nouveaux exercices.
Les membres de l'équipe du parcours Rust se feront un plaisir de t'aider !

Le [dépôt du parcours][github] sur GitHub regroupe tous les exercices Rust.

Si tu veux en savoir plus sur Exercism, jette un œil au [guide de contribution].

## Soumettre des solutions incomplètes
Il est possible de soumettre une solution incomplète pour voir comment d'autres personnes ont résolu l'exercice.
