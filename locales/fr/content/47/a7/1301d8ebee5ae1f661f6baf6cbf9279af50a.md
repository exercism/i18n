# Indices

## 1. Définis l'intervalle des rangées et des colonnes

- Il existe un [opérateur][swift-range-docs] pour créer un intervalle, qui peut être utilisé aussi bien pour les _strings_ que pour les entiers.

## 2. Vérifie si une case est valide

- Il existe une [méthode][contains-docs] pour vérifier si une valeur se trouve dans un intervalle.

## 3. Récupère la ligne

- Chaque ligne doit avoir une longueur de 8.
- Pour chaque ligne à partir de 1, il faut décaler le début et la fin de 8.
- Tu peux utiliser un intervalle pour obtenir un sous-tableau du tableau.
