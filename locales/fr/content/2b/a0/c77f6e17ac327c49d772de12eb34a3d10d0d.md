# Instructions

Dans cet exercice, tu vas écrire du code pour afficher des badges nominatifs pour les employés d'une usine. 
Les employés ont un identifiant, un nom et un nom de département. 
Les étiquettes des badges des employés sont formatées comme suit : `"[id] - name - DEPARTMENT"`.

## 1. Affiche un badge pour un employé

Implémente la fonction `print_name_badge`. Elle prend un identifiant, un nom et un département.
Elle doit renvoyer l'étiquette du badge, avec le nom du département en majuscules.

```R
print_name_badge(67, "Katherine Williams", "Strategic Communication")
# => "[67] - Katherine Williams - STRATEGIC COMMUNICATION"
```

## 2. Affiche un badge pour un nouvel employé

En raison d'une bizarrerie du système informatique, les nouveaux employés n'ont parfois pas encore d'identifiant lorsqu'ils commencent à travailler à l'usine. 
Comme les badges sont obligatoires, ils reçoivent un badge temporaire sans le préfixe d'identifiant.

Étends la fonction `print_name_badge`. Lorsque l'identifiant est manquant, elle doit renvoyer un badge sans celui-ci.

```R
print_name_badge(NA, "Robert Johnson", "Procurement")
# => "Robert Johnson - PROCUREMENT"
```

## 3. Affiche un badge pour le propriétaire

Même le propriétaire de l'usine doit porter un badge en permanence. 
Cependant, un propriétaire n'a pas de département et n'en aura jamais : il est au-dessus de tous les départements. 
Dans ce cas, l'étiquette doit afficher `"OWNER"` à la place du nom du département.

Étends la fonction `print_name_badge`. Lorsque le département vaut `NULL`, considère que le badge appartient au propriétaire de l'entreprise.

```R
print_name_badge(204, "Rachel Miller", NULL)
# => "[204] - Rachel Miller - OWNER"
```

Note qu'il est possible que le propriétaire soit aussi un nouvel employé.

```R
print_name_badge(NA, "Rachel Miller", NULL)
# => "Rachel Miller - OWNER"
```

## 4. Calcule le salaire total des employés sans identifiant

Pour te faire une idée approximative de la qualité de l'attribution des identifiants, tu veux voir le salaire cumulé des employés qui n'en ont pas. 
Une valeur élevée signifie que beaucoup de personnes attendent leur badge, ou que le problème touche des employés expérimentés : dans les deux cas, ce n'est pas bon.

Implémente la fonction `salaries_no_id` qui prend un vecteur d'identifiants et un vecteur de salaires correspondant, et renvoie la somme des salaires des personnes qui n'ont pas encore d'identifiant. 
Les deux vecteurs ont la même longueur.

```R
ids <- c(204, NA, 210, 352, NA, 263)
salaries <- c(23, 21, 47, 35, 17, 101) * 1000
salaries_no_id(ids, salaries)
# => 38,000
```

_Pour aller plus loin, sans être testé :_ S'il n'y a aucun employé sans identifiant, quel est le « vecteur vide » que tu additionnes ?
