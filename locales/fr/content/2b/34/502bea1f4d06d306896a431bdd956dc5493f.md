# signature de fonction modifiée

Corrige la signature de la fonction `%{function}`. La signature attendue est `%{signature}`.
Exercism repose sur le principe du TDD ([développement piloté par les tests](http://testfirst.org/about#tdd)).
Les tests existent déjà et définissent l'interface exposée, ainsi que le comportement du code à implémenter.
Modifier la signature fait échouer les tests.
