# Introduction

## Tableaux

En Common Lisp, comme dans d'autres langages, un tableau est un ensemble d'éléments auxquels on accède par des indices entiers.
Les types des éléments peuvent être hétérogènes.
Un tableau peut être multidimensionnel (et pas simplement à une dimension).

### Création

`make-array` permet de créer des tableaux.
Elle prend de nombreuses options, mais ses formes les plus simples permettent de créer des tableaux à N dimensions dont tous les éléments sont initialisés à une même valeur, ou dont le tableau est initialisé avec les valeurs d'une autre séquence (comme une liste). 
Son premier argument est une liste donnant la taille de chaque dimension.

```lisp
(make-array '(4) :initial-element 3)    ; => #(3 3 3 3)
(make-array '(2 2) :initial-element 'x) ; => #2A((X X) (X X))
```

(Remarque : les tableaux à N dimensions sont imprimés avec leur nombre de dimensions.)

On peut aussi créer des tableaux en utilisant le même format que celui dans lequel ils sont imprimés : 

```lisp
#(x y z)         ; => #(X Y Z)
#2A((1 2) (3 4)) ; => #2A((1 2) (3 4))
```

### Accès aux éléments

Pour accéder aux éléments d'un vecteur, utilise `aref` ; les indices commencent à zéro. 
Le nombre d'indices fournis doit correspondre au rang du tableau.

```lisp
(aref #2A((1 2 3) (3 4 5)) 
       1 0)           ; => 3
(aref #3A(((a b) (c d)) 
           ((e f) (g h)) 
           ((t u) (v w))) 
       2 0 1)         ; => U
(aref #2A((1) (2)) 0) ; => ERROR (because not enough indexes provided)
```
