# Instructions complémentaires

Une solution possible pour cet exercice consiste à implémenter ta propre fonction d'exponentiation modulaire.
Pour en savoir plus, consulte la [page suivante](https://en.wikipedia.org/wiki/Modular_exponentiation).

## Pour gagner des points bonus

De nombreuses implémentations ne fonctionnent pas pour tout le domaine des entrées.
Il existe des tests supplémentaires facultatifs qui aident à vérifier que toutes les entrées valides produisent des résultats valides.

Pour exécuter les tests bonus, retire l'attribut `#[ignore]` et lance les tests avec la fonctionnalité `big-primes`, comme ceci :

```bash
$ cargo test --features big-primes
```
