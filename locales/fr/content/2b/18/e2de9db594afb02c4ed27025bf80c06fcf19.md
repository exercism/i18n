# Installation

Pour exécuter ces exercices, tout ce dont tu as besoin, c'est d'installer [CommandBox CLI](https://commandbox.ortusbooks.com/getting-started-guide) et [Java 8](https://java.com/en/download/). CommandBox CLI est pris en charge sur Mac, Linux et Windows, et le guide d'installation se trouve ici :

[https://commandbox.ortusbooks.com/setup/installation](https://commandbox.ortusbooks.com/setup/installation)

Voici un exemple d'installation de CommandBox CLI si tu utilises Homebrew sur Mac :

```bash
brew install commandbox
```

Une fois la CLI installée, tu peux t'amuser avec le REPL :

```bash
box repl
```

Tu peux exécuter directement des pages .cfm :

```bash
box exec myTest.cfm
```

Et tu peux même démarrer un serveur web dans n'importe quel dossier de ton disque dur :

```bash
box server start
```

CommandBox dispose d'un shell interactif avec une autocomplétion par tabulation améliorée et qui s'exécute plus rapidement. Pour y entrer, lance simplement le binaire `box` sans argument.

```bash
box
```
