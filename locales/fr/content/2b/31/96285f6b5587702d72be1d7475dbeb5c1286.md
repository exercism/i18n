# Instructions

Dans cet exercice, tu vas écrire un TreasureChest générique (et magique !), pour y ranger un trésor.

## 1. Définis le type personnalisé générique `TreasureChest`

Définis un type personnalisé `TreasureChest` avec une seule variante.

Cette variante doit avoir une valeur `String` associée, qui servira à stocker le mot de passe du coffre au trésor.

Elle doit aussi avoir une valeur générique associée, qui servira à stocker le trésor.
Cette valeur est générique pour que le trésor puisse être n'importe quoi.

## 2. Définis le type `UnlockResult`

Définis un type personnalisé `UnlockResult` avec deux variantes.

La première variante est `Unlocked` et contient une valeur générique, qui servira à stocker le trésor.

La deuxième variante est `WrongPassword`, qui ne contient aucune valeur.

## 3. Définis la fonction `get_treasure`

Cette fonction prend deux paramètres

- un type personnalisé générique `TreasureChest`
- une `String` (pour essayer un mot de passe)

Cette fonction doit comparer le mot de passe fourni avec la `String` contenue dans le `TreasureChest`.

La fonction doit renvoyer un `UnlockResult`.

Si les mots de passe correspondent, renvoie `Unlocked` avec la valeur générique du `TreasureChest` (le trésor !)

Si les mots de passe ne correspondent pas, renvoie `WrongPassword`.
