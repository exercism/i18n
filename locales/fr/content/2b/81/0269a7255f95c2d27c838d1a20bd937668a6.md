# À propos

Lua utilise deux représentations pour les nombres : des nombres entiers de 64 bits et des nombres à virgule flottante en double précision.

~~~exercism/note
Avant la version 5.3, Lua représentait tous les nombres au format à virgule flottante en double précision.
~~~

On peut écrire les nombres avec une partie décimale facultative, ainsi qu'un exposant décimal facultatif.
```lua
1               --> 1
0.2             --> 0.2
0.3e4           --> 3000.0
4.0e-3          --> 0.004
5.0e+20         --> 5e+20
```

Un nombre comportant un point décimal ou un exposant est considéré comme un nombre décimal ; sans l'un ou l'autre, il est traité comme un entier, mais les deux ont le type 'number'.
```lua
type(1)         --> number
type(2.0)       --> number
```

Si on veut distinguer les nombres décimaux des nombres entiers, on peut utiliser la fonction `type` du module `math`.
```lua
math.type(1)    --> integer
math.type(2.0)  --> float
```

## Comparaison

Les entiers et les nombres décimaux de même valeur sont considérés comme égaux :
```lua
1 == 1.0        --> true
-2 == -2.0      --> true
0.3e3 == 300    --> true
```

## Arithmétique

Lua prend en charge l'ensemble habituel des opérateurs arithmétiques : l'addition, la soustraction, la multiplication, la division et la négation. Il prend également en charge la division entière, le modulo et l'exponentiation.

### Addition, soustraction, multiplication et négation

Si les deux opérandes sont des entiers, le résultat de l'opération est un entier. Il en va de même pour les nombres décimaux.
```lua
1 + 2     --> 3
1.0 + 2.0 --> 3.0
```

Si l'un des opérandes est un nombre décimal, les autres entiers sont eux aussi convertis en nombres décimaux et l'opération donne un nombre décimal.
```lua
1.0 + 2   --> 3.0
```

### Division

La division opère toujours sur des nombres décimaux et renvoie un nombre décimal.
```lua
1.0 / 2.0 --> 0.5
2 / 1     --> 2.0
```

Diviser par zéro donne `inf` ou `-inf`. Diviser zéro par zéro donne `-nan`.
```lua
1 / 0     --> inf
-1 / 0    --> -inf
0 / 0     --> -nan
```

### Division entière

Si on a besoin d'un résultat entier, on peut utiliser la division entière. La division entière arrondit toujours le quotient vers moins l'infini, ce qui garantit un résultat entier pour tous les opérandes.

~~~exercism/note
Avant la version 5.3, Lua n'avait pas d'opérateur arithmétique pour la division entière.
~~~

```lua
3 // 2    --> 1
6 // 2    --> 3
```

La division entière suit les mêmes règles que les opérateurs d'addition, de soustraction, de multiplication et de négation : si les deux opérandes sont des entiers, le résultat de l'opération est un entier, sinon le résultat est un nombre décimal.

```lua
3.0 // 2   --> 1.0
6.0 // 2.0 --> 3.0
```

Lorsqu'on divise par zéro avec la division entière, Lua lève une erreur.
```lua
3 // 0     --> stdin:1: attempt to divide by zero
```

### Modulo

Le modulo permet d'obtenir le reste de la division de deux opérandes.
```lua
8 % 2      --> 0
13 % 9     --> 4
-13 % -9   --> -4
-13 % 9    --> 5
13 % -9    --> -5
0.3 % 0.2  --> 0.1
```

### Exponentiation

Comme la division, l'exponentiation opère sur des nombres décimaux et renvoie des nombres décimaux.
```lua
10 ^ 2    --> 100.0
```

## Priorité

Toutes les opérations sont évaluées selon la [priorité des opérateurs](https://www.lua.org/manual/5.4/manual.html#3.4.8). On peut utiliser des parenthèses pour modifier la priorité d'une expression.

```lua
1 + 2 * 3   --> 7
(1 + 2) * 3 --> 9
```

## Arrondi

Le module `math` fournit trois fonctions d'arrondi : `floor` arrondit « vers le bas » (vers moins l'infini), `ceil` arrondit « vers le haut » (vers plus l'infini) et `modf` arrondit vers zéro.

### `math.floor`

`floor` arrondit vers moins l'infini.
```lua
math.floor(1.3)    --> 1
math.floor(-1.3)   --> -2
```

### `math.ceil`

`ceil` arrondit vers plus l'infini.
```lua
math.ceil(1.3)    --> 2
math.ceil(-1.3)   --> -1
```

### `math.modf`

`modf` arrondit vers zéro. La fonction renvoie la valeur arrondie ainsi que la partie fractionnaire du nombre, qui est toujours un nombre décimal.
```lua
math.modf(1.3)    --> 1    0.3
math.modf(-1.3)   --> -1   -0.3
```

## Conversion

Si on veut convertir un entier en nombre décimal, on peut lui ajouter `0.0`.
```lua
1 + 0.0         --> 1.0
```

Si on veut convertir un nombre décimal en entier, on peut lui appliquer un OU bit à bit avec zéro ou utiliser la fonction `tointeger` du module `math`.
```lua
1.0 | 0              --> 1
math.tointeger(1.0)  --> 1
```

Si le nombre ne peut pas être converti en entier, l'opérateur OU lève une erreur et la fonction `tointeger` renvoie `nil`.
```lua
1.1 | 0              --> stdin:1: number has no integer representation
math.tointeger(1.1)  --> nil
```

## Hexadécimal

Comme beaucoup d'autres langages de programmation, Lua prend en charge les nombres hexadécimaux en les préfixant par `0x`, mais contrairement à beaucoup d'autres langages de programmation, Lua prend aussi en charge les nombres hexadécimaux à virgule flottante. Ils peuvent comporter une partie fractionnaire et un exposant binaire, préfixé par 'p' ou 'P'.
```lua
0xff            --> 255
0x0.2           --> 0.125
0x3p-1          --> 1.5
0xa.bp2         --> 42.75
```
