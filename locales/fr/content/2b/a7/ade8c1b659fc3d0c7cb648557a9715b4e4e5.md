# Instructions

Tu travailles sur un projet qui permet aux utilisateurs de téléverser des fichiers sur le serveur pour les partager avec d'autres utilisateurs. On t'a chargé d'écrire une fonction pour vérifier qu'un fichier téléversé correspond à son [type de média][mimetype]. Après quelques recherches, tu découvres que les premiers octets d'un fichier sont généralement propres à ce type de fichier, ce qui lui donne une sorte de signature.

Utilise le tableau suivant comme référence :

| Type de fichier | Extension courante | Type de média                | « signature » binaire                            |
| --------- | ---------------- | ---------------------------- | ------------------------------------------------ |
| ELF       | `"exe"`          | `"application/octet-stream"` | `0x7F, 0x45, 0x4C, 0x46`                         |
| BMP       | `"bmp"`          | `"image/bmp"`                | `0x42, 0x4D`                                     |
| PNG       | `"png"`          | `"image/png"`                | `0x89, 0x50, 0x4E, 0x47, 0x0D, 0x0A, 0x1A, 0x0A` |
| JPG       | `"jpg"`          | `"image/jpg"`                | `0xFF, 0xD8, 0xFF`                               |
| GIF       | `"gif"`          | `"image/gif"`                | `0x47, 0x49, 0x46`                               |

## 1. À partir d'une extension, renvoie le type de média attendu

Implémente la fonction `type_from_extension/1`. Elle prend une extension de fichier (une _string_) et renvoie le type de média (_string_), ou nil si l'extension ne correspond pas à celles attendues.

```elixir
FileSniffer.type_from_extension("exe")
# => "application/octet-stream"

FileSniffer.type_from_extension("txt")
# => nil
```

## 2. À partir d'un fichier binaire, renvoie le type de média attendu

Implémente la fonction `type_from_binary/1`. Elle prend un fichier (binaire) et renvoie le type de média (_string_), ou nil si la signature du fichier ne correspond pas à celles attendues.

```elixir
file = File.read!("application.exe")
FileSniffer.type_from_binary(file)
# => "application/octet-stream"

file = File.read!("example.txt")
FileSniffer.type_from_binary(file)
# => nil
```

Ne te soucie pas de lire le fichier en binaire. Considère que c'est déjà fait et que les tests te le passent en argument.

## 3. À partir d'une extension et d'un fichier binaire, vérifie que le fichier correspond au type attendu

Implémente la fonction `verify/2`. Elle prend un fichier (binaire) et une extension (_string_), et renvoie un tuple `:ok` ou `:error`.

```elixir
file = File.read!("application.exe")

FileSniffer.verify(file, "exe")
# => {:ok, "application/octet-stream"}

FileSniffer.verify(file, "png")
# => {:error, "Warning, file format and file extension do not match."}
```

[mimetype]: https://en.wikipedia.org/wiki/Media_type
