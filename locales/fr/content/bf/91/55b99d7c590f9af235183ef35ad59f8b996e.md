# Exécute les tests

Les exercices récupérés avec le [client en ligne de commande d'Exercism](https://exercism.io/cli) sont livrés avec au minimum trois fichiers : un fichier `readme.md`, un fichier `.dpr` et un fichier `.pas`. Le fichier `.dpr` est le fichier de projet Delphi, tandis que le fichier `.pas` est l'exécuteur de tests. Charge le projet Delphi soit en double-cliquant sur le fichier `.dpr`, soit en ouvrant le projet depuis Delphi. C'est à toi de créer un nouveau fichier `.pas` qui contiendra le code de ta solution, celui sur lequel les tests seront exécutés. Consulte le fichier `readme.md` pour savoir comment compiler et exécuter ton code.

Tous les tests sont ignorés, sauf le premier, pour que tu puisses travailler dessus. Pour continuer, il te suffit de commenter l'attribut `[Ignore]` du test pour t'y mettre.

Assure-toi que [DUnitX](https://github.com/VSoftTechnologies/DUnitX) est installé, s'il ne l'est pas déjà depuis l'installation ci-dessus.
