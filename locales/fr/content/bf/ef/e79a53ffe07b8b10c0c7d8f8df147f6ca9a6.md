# Instructions

Dans cet exercice, on va écrire du code pour aider un freelance à communiquer avec un chef de projet, en lui fournissant quelques outils qui calculent rapidement des tarifs journaliers et mensuels, avec éventuellement une réduction donnée.

On commence par établir quelques règles entre le freelance et le chef de projet :

- Le tarif journalier correspond à 8 fois le tarif horaire.
- Un mois compte 22 jours facturables.

Il arrive que le freelance propose d'appliquer une réduction sur son tarif journalier (par exemple pour ses clients les plus fidèles ou pour des clients à but non lucratif).

Les réductions sont modélisées par des nombres décimaux représentant un pourcentage, par exemple `25.0` (25 %).

## 1. Calcule le tarif journalier à partir d'un tarif horaire

Implémente une fonction qui calcule le tarif journalier à partir d'un tarif horaire :

```elixir
FreelancerRates.daily_rate(60)
# => 480.0
```

Le tarif journalier renvoyé doit être un nombre décimal.

## 2. Calcule un prix après réduction

Implémente une fonction qui calcule le prix après une réduction.

```elixir
FreelancerRates.apply_discount(150, 10)
# => 135.0
```

La valeur renvoyée doit toujours être un nombre décimal, sans aucun arrondi.

## 3. Calcule le tarif mensuel à partir d'un tarif horaire et d'une réduction

Implémente une fonction qui calcule le tarif mensuel et applique une réduction :

```elixir
FreelancerRates.monthly_rate(77, 10.5)
# => 12130
```

Le tarif mensuel renvoyé doit être arrondi à l'entier supérieur (on prend l'entier du dessus).

## 4. Calcule le nombre de jours travaillés à partir d'un budget, d'un tarif horaire et d'une réduction

Implémente une fonction qui prend un budget, un tarif horaire et une réduction, et qui calcule combien de jours de travail cela couvre.

```elixir
FreelancerRates.days_in_budget(20000, 80, 11.0)
# => 35.1
```

Le nombre de jours renvoyé doit être arrondi à l'inférieur (arrondi par défaut) à une décimale.
