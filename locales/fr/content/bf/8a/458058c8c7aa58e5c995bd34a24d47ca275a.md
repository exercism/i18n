# Introduction

Jusqu'à présent, on a vu que les arguments passés à une méthode sont associés aux paramètres déclarés de la méthode en fonction de leur position. Une autre approche, en particulier lorsqu'une routine prend un grand nombre d'arguments, permet à l'appelant d'associer les arguments en spécifiant l'identifiant du paramètre déclaré.

L'exemple suivant illustre la syntaxe :

```csharp
class Card
{
    static string NewYear(int year, int month, int day)
    {
        return $"Happy {year}-{month}-{day}!";
    }
}

Card.NewYear(month: 1, day: 1, year: 2020);  // => "Happy 2020-1-1!"
```
