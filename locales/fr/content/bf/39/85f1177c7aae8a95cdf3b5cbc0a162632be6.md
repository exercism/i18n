# CLI

## Installation

La façon la plus simple d'installer PureScript passe par Node.js et NPM.

Si tu n'as pas déjà installé Node.js sur ton ordinateur, tu peux le télécharger depuis le [site web de Node.js][nodejs-website]. Une fois que Node.js est installé et fonctionnel, saisis cette commande dans le terminal pour installer le compilateur PureScript et le gestionnaire de paquets et outil de compilation Spago.

```shell
npm install -g purescript spago
```

Tu trouveras plus d'informations dans le [dépôt PureScript][purescript-repository].

## Prérequis

Installe les dépendances de l'exercice :

```shell
spago install
spago build
```

## Fais passer la suite de tests

Exécute les tests avec :

```shell
spago test
```

Dans les suites de tests, tous les tests sauf le premier sont ignorés. C'est pour t'encourager à résoudre l'exercice une étape à la fois.

Une fois qu'un test passe, tu peux activer le suivant en remplaçant `xit` par `it`.

## Soumets la solution

Une fois qu'aucun test n'est ignoré et qu'ils passent tous, tu peux soumettre ta solution avec :

```shell
exercism submit src/<NAME>.purs
```

## Écris des tests personnalisés

Si tu souhaites écrire des tests supplémentaires et personnalisés, crée un nouveau fichier `test/Custom.purs`, et soumets-le avec ta solution, en même temps que le nouveau fichier :

```shell
exercism submit src/<NAME>.purs test/Custom.purs
```
