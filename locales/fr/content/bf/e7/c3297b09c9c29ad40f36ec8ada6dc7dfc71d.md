# Ajout aux instructions

## Indices

Pour cet exercice, la fonctionnalité C# suivante s'avère bien pratique :
les _Enumerables_ sont évalués paresseusement. Ils permettent de travailler avec une séquence infinie de valeurs.
Voir [cet article](https://blogs.msdn.microsoft.com/pedram/2007/06/02/lazy-evaluation-in-c/).

Remarque : pour accélérer le calcul, tu ne dois pas vérifier les nombres dont tu sais d'avance qu'ils ne seront jamais premiers. Pour plus d'informations, voir le [crible d'Ératosthène](https://en.wikipedia.org/wiki/Sieve_of_Eratosthenes).
