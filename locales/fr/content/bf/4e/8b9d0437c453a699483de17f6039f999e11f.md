# Introduction

En Python, [un `enum`][enum-docs] est un ensemble de noms associés à des valeurs `literal` uniques, ou `constant`.
Les `Enums` sont définis en héritant ou en créant une sous-classe d'une classe `Enum`.
Les types `enum` intégrés sont disponibles dans le module `enum` et la classe `Enum` peut être importée avec `from enum import Enum`.


```python
from enum import Enum

class Color(Enum):
    RED = 1
    GREEN = 2
```

Note que les valeurs des membres d'un `enum` peuvent être de n'importe quel type de données, comme `str`, `tuple`, `float`, etc.

```python
class Color(Enum):
    RED = 'red'
    GREEN = 'green'
```

Lorsque l'on affecte la même valeur à deux membres d'un `enum`, le membre affecté en second devient un alias du premier. Il n'est pas permis d'utiliser le même nom pour deux membres différents d'un `enum`.

```python
class Color(Enum):
    RED = 1
    GREEN = 2
    ALIAS_OF_RED = 1

Color.ALIAS_OF_RED
#=> <Color.RED: 1>

Color.ALIAS_OF_RED.value
#=> 1
```

On peut itérer sur les membres de l'`enum` avec la syntaxe standard `for member in` :

```python
for member in Color:
    print((member.name, member.value))
#=> (RED, 1)
#=> (GREEN, 2)
```

Les membres d'un `Enum` peuvent être comparés avec [`is` (_opérateur d'identité_)][identity-keyword] ou `is not`. Les opérateurs `==` ou `!=` (_opérateurs d'égalité_) fonctionnent de la même manière :

```python
a = Color.RED

a is Color.RED
#=> True

a == Color.RED
#=> True
```

Pour accéder à un membre d'un `enum` pour une valeur donnée, on peut utiliser `<EnumName>(<value>)` :

```python
g = Color(2)

g is Color.GREEN
#=> True

g
#=> <Color.GREEN: 2>
```
