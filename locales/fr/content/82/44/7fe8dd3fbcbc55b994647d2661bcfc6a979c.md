# À propos

Scala est un langage de programmation qui évolue avec toi : des petits scripts aux grandes applications multiplateformes.

Scala combine la programmation orientée objet et la programmation fonctionnelle dans un seul langage concis et de haut niveau. Les types statiques de Scala aident à éviter les bugs dans les applications complexes, et ses environnements d'exécution JVM, JavaScript et Native te permettent de construire des systèmes à hautes performances, avec un accès facile à de vastes écosystèmes de bibliothèques.

* Fonctionnalités
    * Interopérabilité JVM : Scala s'exécute sur la JVM, donc les technologies Java et Scala peuvent se mélanger pour une intégration transparente.
    * Interopérabilité JS et Native : Scala peut s'exécuter dans le navigateur et sur des appareils natifs, grâce à [Scala.js](https://www.scala-js.org/) et [Scala Native](https://github.com/scala-native/scala-native)
    * Inférence de type : Scala est statiquement typé. Cependant, Scala propose l'inférence de type pour alléger la charge qu'impose un système de types avancé.
    * Orienté objet : Scala est un langage purement orienté objet, en ce sens que toute valeur est un objet. Les types de données et les comportements des objets sont décrits par des classes et des traits. Les abstractions de classes sont étendues par héritage et par un mécanisme de composition souple fondé sur des mixins, ce qui évite les problèmes de l'héritage multiple.
    * Fonctionnel : Scala est aussi un langage fonctionnel, en ce sens que toute fonction est une valeur. Scala propose une syntaxe légère pour définir des fonctions anonymes, prend en charge les fonctions d'ordre supérieur, permet d'imbriquer des fonctions et prend en charge le currying. Les case classes de Scala et sa prise en charge native du filtrage par motif modélisent les types algébriques utilisés dans de nombreux langages de programmation fonctionnelle. Les objets singleton offrent un moyen pratique de regrouper des fonctions qui ne sont pas membres d'une classe.
    * Concurrence et distribution : utilise des opérations parallèles sur les collections, des acteurs pour la concurrence et la distribution, ou des futures pour la programmation asynchrone.
