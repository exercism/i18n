# Introduction

En C#, les structures de données qui peuvent contenir zéro ou plusieurs éléments sont appelées des _collections_. Un **tableau** est une collection dont la taille (ou la longueur) est fixe et dont tous les éléments doivent être du même type. On peut affecter des éléments à un tableau ou les récupérer à l'aide d'un indice. Les tableaux en C# sont indexés à partir de zéro, ce qui signifie que l'indice du premier élément est toujours zéro :

```csharp
// Declare array with explicit size (size is 2)
int[] twoInts = new int[2];

// Assign second element by index
twoInts[1] = 8;

// Retrieve the second element by index
twoInts[1] == 8; // => true
```

On peut aussi définir des tableaux à l'aide d'une notation abrégée qui permet à la fois de créer le tableau et de définir sa valeur. Comme le compilateur peut désormais déterminer combien d'éléments le tableau contiendra, on peut omettre la longueur :

```csharp
// Three equivalent ways to declare and initialize an array (size is 3)
int[] threeIntsV1 = new int[] { 4, 9, 7 };
int[] threeIntsV2 = new[] { 4, 9, 7 };
int[] threeIntsV3 = { 4, 9, 7 };
```

On peut manipuler les tableaux en appelant les méthodes ou les propriétés d'une instance de tableau, ou en utilisant les méthodes statiques définies dans la classe `Array`.
