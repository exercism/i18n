# Introduction

Le filtrage par motif consiste à créer des branchements selon qu'une valeur correspond à des motifs donnés, éventuellement profonds. En Haxe, le **filtrage par motif** s'effectue à l'aide d'une expression `switch` et d'expressions `case` individuelles.

Prenons cette structure de données :

```haxe
enum Tree<T> {
  Leaf(v:T);
  Node(l:Tree<T>, r:Tree<T>);
}
```

- Les motifs sont toujours testés du haut vers le bas.
- Le premier motif qui correspond à la valeur d'entrée est celui dont l'expression est exécutée.
- Un motif `_` correspond à n'importe quoi, donc `case _:` est équivalent à `default:`

## Filtrage des enums

On peut filtrer les _enums_ par leur constructeur, naturellement :

```haxe
var myTree = Node(Leaf("foo"), Node(Leaf("bar"), Leaf("foobar")));

var match = switch (myTree) {
  // Matches any Leaf
  case Leaf(_):
    "0";

  // Matches any Node that has r = Leaf
  case Node(_, Leaf(_)):
    "1";

  // Matches any Node that has
  // r = another Node which has
  // l = Leaf("bar")
  case Node(_, Node(Leaf("bar", _))):
    "2";

  // Matches anything
  case _:
    "3";
}

trace(match); // 2
```
