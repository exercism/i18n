# Instructions

Mika, l'organisatrice d'événements, a obtenu une promotion au travail, et dans le cadre de ses nouvelles responsabilités, elle s'occupe de la base de données des événements. Elle a rapidement remarqué qu'une grande partie des données est stockée d'une manière qui les rend difficiles à manipuler, alors on fait équipe pour les nettoyer avec un script à usage unique.

Comme le script ne sera exécuté qu'une seule fois, et que tu es sûr de la structure des données, tu peux considérer que c'est un bon endroit pour utiliser les _let assertions_ de Gleam.

## 1. Extrais les erreurs

Chaque événement passé contient une liste de problèmes qui se sont produits pendant l'événement. Ils ont été stockés sous forme de résultats, mais ils sont toujours de la variante `Error`.

Implémente la fonction `extract_error`, qui prend un résultat dont on s'attend à ce qu'il soit toujours un `Error` et qui renvoie la valeur d'erreur qu'il contient.

```gleam
extract_error(Error("Not enough coffee"))
// -> "Not enough coffee"
```

## 2. Supprime le préfixe d'équipe

Les noms d'équipe ont été préfixés par le mot « Team », mais ce n'est pas nécessaire. Implémente la fonction `remove_team_prefix` pour retirer le préfixe d'un nom d'équipe.

```gleam
remove_team_prefix("Team Turtle")
// -> "Turtle"
```

## 3. Sépare la région et l'équipe

Chaque événement est organisé par une équipe, et chaque équipe appartient à une région. Dans la base de données, elles sont stockées dans une seule _string_, séparées par une virgule.

Implémente la fonction `split_region_and_team` pour découper la _string_ en un tuple de deux _strings_, l'une pour la région et l'autre pour l'équipe. Le préfixe « Team » doit être retiré du nom de l'équipe.

```gleam
split_region_and_team("East,Team Orange")
// -> #("East", "Orange")
```
