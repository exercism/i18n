## Mise en forme

Common Lisp se moque de l'indentation et de la disposition du code, et peu importe que tu utilises des espaces ou des tabulations, mais c'est un point important pour tes soumissions sur Exercism.
L'éditeur de code d'Exercism.org gère mal le mélange de tabulations et d'espaces, il est donc recommandé de n'utiliser que des espaces pour rendre le code plus lisible pour les relecteurs humains.
Pense à vérifier les réglages de ton éditeur pour savoir comment faire.
Ci-dessous, les instructions pour les éditeurs les plus utilisés avec Common Lisp.

### VIM

Utilise les commandes suivantes pour que VIM n'utilise que des espaces pour l'indentation :

```vimscript
:set tabstop=2
:set shiftwidth=2
:set expandtab
```

(ou en une seule ligne `:set tabstop=2 shiftwidth=2 expandtab`). Tu peux l'ajouter à ton fichier `~/.vimrc` pour l'utiliser tout le temps.

### Emacs

Emacs est particulièrement bien adapté à l'édition de Common Lisp et propose de nombreux modules complémentaires puissants. Avec un Emacs d'origine, la seule chose à faire pour qu'il fonctionne bien avec exercism.org est d'évaluer le code suivant :

`(setq-default indent-tabs-mode nil)`

Tu peux le placer dans ton `~/.emacs` (ou `~/.emacs.d/init.el`) pour qu'il soit chargé à chaque lancement d'Emacs.

Un module complémentaire suggéré pour Emacs et Common Lisp est [SLIME][slime], qui s'intègre étroitement avec le REPL, ce qui rend le codage et les tests itératifs très faciles.
