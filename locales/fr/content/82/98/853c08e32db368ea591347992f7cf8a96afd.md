# Instructions

En apprentie magicienne, Elyse doit s'entraîner sur quelques bases. Elle a une pile de cartes qu'elle veut manipuler.

Pour simplifier un peu les choses, elle n'utilise que les cartes de 1 à 10, si bien que sa pile de cartes peut être représentée par un tableau de nombres. La position d'une carte donnée correspond à l'indice dans le tableau. Ainsi, la position 0 désigne la première carte, la position 1 la deuxième, et ainsi de suite.

<!-- prettier-ignore-start -->
~~~~exercism/note
Toutes les fonctions, à deux exceptions près, doivent mettre à jour le tableau de cartes puis renvoyer le tableau modifié. C'est une façon courante de travailler, appelée le _Builder pattern_, qui permet d'enchaîner joliment les fonctions les unes aux autres.

Les deux exceptions sont `getItem`, qui doit renvoyer la carte à la position donnée, et `checkSizeOfStack`, qui doit renvoyer `true` si la taille donnée correspond.
~~~~
<!-- prettier-ignore-end -->

## 1. Récupère une carte dans une pile

Pour piocher une carte, renvoie la carte à l'indice `position` de la pile donnée.

```javascript
const position = 2;
getItem([1, 2, 4, 1], position);
// => 4
```

## 2. Échange une carte dans la pile

Fais un tour de passe-passe et échange la carte à l'indice `position` avec la carte de remplacement fournie.
Renvoie la pile modifiée.

```javascript
const position = 2;
const replacementCard = 6;
setItem([1, 2, 4, 1], position, replacementCard);
// => [1, 2, 6, 1]
```

## 3. Insère une carte au sommet de la pile

Fais apparaître une carte en insérant une nouvelle carte au sommet de la pile.
Renvoie la pile modifiée.

```javascript
const newCard = 8;
insertItemAtTop([5, 9, 7, 1], newCard);
// => [5, 9, 7, 1, 8]
```

## 4. Retire une carte de la pile

Fais disparaître une carte en retirant de la pile la carte à la `position` donnée.
Renvoie la pile modifiée.

```javascript
const position = 2;
removeItem([3, 2, 6, 4, 8], position);
// => [3, 2, 4, 8]
```

## 5. Retire la carte du sommet de la pile

Fais disparaître une carte en retirant la carte au sommet de la pile.
Renvoie la pile modifiée.

```javascript
removeItemFromTop([3, 2, 6, 4, 8]);
// => [3, 2, 6, 4]
```

## 6. Insère une carte au bas de la pile

Fais apparaître une carte en insérant une nouvelle carte au bas de la pile.
Renvoie la pile modifiée.

```javascript
const newCard = 8;
insertItemAtBottom([5, 9, 7, 1], newCard);
// => [8, 5, 9, 7, 1]
```

## 7. Retire une carte du bas de la pile

Fais disparaître une carte en retirant la carte au bas de la pile.
Renvoie la pile modifiée.

```javascript
removeItemAtBottom([8, 5, 9, 7, 1]);
// => [5, 9, 7, 1]
```

## 8. Vérifie la taille de la pile

Vérifie si la taille de la pile est égale à `stackSize` ou non.

```javascript
const stackSize = 4;
checkSizeOfStack([3, 2, 6, 4, 8], stackSize);
// => false
```
