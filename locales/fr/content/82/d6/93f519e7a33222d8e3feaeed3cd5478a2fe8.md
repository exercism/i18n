# Instructions complémentaires

## Implémentation

Hypothèses :

1. Un zéro est toujours représenté dans les sorties par [0] et non par [].
2. Dans aucun autre cas, les sorties ne comportent de zéros non significatifs.
3. Les zéros non significatifs sont acceptés dans les entrées.
4. Une séquence vide de chiffres d'entrée est considérée comme valant zéro, et non comme une erreur.

Pour gérer les cas problématiques, renvoie une erreur dont la méthode Error() renvoie l'un des messages suivants :

- input base must be >= 2
- output base must be >= 2
- all digits must satisfy 0 <= d < input base
