# Instructions supplémentaires

## Registres

| Registre | Utilisation | Type       | Description                                                                                  |
| -------- | ----------- | ---------- | -------------------------------------------------------------------------------------------- |
| `$a0`    | entrée      | adresse    | première couleur sous forme de _string_ terminée par un caractère nul                         |
| `$a1`    | entrée      | adresse    | deuxième couleur sous forme de _string_ terminée par un caractère nul                         |
| `$a2`    | entrée      | adresse    | troisième couleur sous forme de _string_ terminée par un caractère nul (éventuellement vide)  |
| `$v0`    | sortie      | entier     | valeur de la résistance                                                                       |
| `$t0-9`  | temporaire  | quelconque | pour un stockage temporaire                                                                   |
