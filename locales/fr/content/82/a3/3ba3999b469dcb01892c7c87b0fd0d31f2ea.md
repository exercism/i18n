# Les classes immuables

```sather
immutable class BEARING is
   readonly attr degrees : INT;
   create(d : INT) : SAME is
      b : SAME;
      return b.degrees(d);
   end;
end;
```

## Ce qui change

| | classe ordinaire | classe immuable |
| --- | --- | --- |
| affectation | partage l'objet | copie la valeur |
| peut être _void_ | oui | non |
| écriture de `attr` | `x.a := v` | `x := x.a(v)` |
| `new` | oui | non ; `x : SAME` existe déjà |

Un objet immuable ne peut pas être _void_, donc `void(b)` est toujours faux, et aucune routine sur un tel objet ne peut échouer faute d'objet. Cela élimine toute une catégorie d'erreurs, au prix de ne jamais pouvoir dire « pas encore de bearing ».

## Où vit la valeur

La valeur est stockée là où se trouve la variable, dans un autre objet ou sur la pile, plutôt que d'être atteinte par une référence. Ainsi, un `ARRAY{BEARING}` contient les bearings eux-mêmes, et non des pointeurs vers eux, ce qui est plus compact et plus rapide à parcourir.

Le coût, c'est la copie : passer un gros objet immuable le copie à chaque fois. Mieux vaut donc les garder petits.

## Les routines d'attribut

`readonly attr degrees : INT` fournit deux routines :

```sather
   b.degrees          -- read: INT
   b.degrees(90)      -- answer a new BEARING with degrees changed
```

La seconde existe même sous `readonly`, parce qu'elle ne change rien : elle construit une nouvelle valeur. Sous un simple `attr`, elle est publique ; sous `private attr`, elle ne l'est pas.

## is_eq et str

Ni l'une ni l'autre n'est fournie. Écris `is_eq` pour `=`, et `str` pour que l'objet puisse être affiché et concaténé à des _strings_ :

```sather
   is_eq(other : SAME) : BOOL is return degrees = other.degrees; end;
   str : STR is return degrees.str + " degrees"; end;
```

Écrire `str` fait que la classe se conforme à `$STR`, ce qui permet à `+` et à `#OUT` de l'accepter.

## Les classes intégrées

`INT`, `BOOL`, `CHAR`, `FLTD` et `TUP` sont toutes des classes immuables. Elles n'ont rien de particulier : elles sont écrites en Sather, dans la bibliothèque, de la même façon, et se comportent comme elles le font pour les raisons ci-dessus.
