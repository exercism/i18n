# Les vecteurs comme pile

Une pile est une structure de données linéaire optimisée pour l'accès à partir d'une seule extrémité. Une bonne métaphore est une pile de feuilles de papier enfilées sur une tige : les nouvelles feuilles sont toujours ajoutées du même côté, et les feuilles sont retirées dans l'ordre inverse de leur ajout. Les feuilles ajoutées en premier sont retirées en dernier, et celles ajoutées en dernier sont retirées en premier.

La structure de données `Vec` de Rust convient parfaitement pour servir de pile. La [méthode `push`](https://doc.rust-lang.org/std/vec/struct.Vec.html#method.push) ajoute des éléments à la fin du vecteur. La [méthode `pop`](https://doc.rust-lang.org/std/vec/struct.Vec.html#method.pop) retire le dernier élément du vecteur. `push` et `pop` ne prennent tous les deux qu'un temps amorti `O(1)`.

## Exemple

Dans cet exemple, on utilise un vecteur comme pile pour une calculatrice [RPN](https://en.wikipedia.org/wiki/Reverse_Polish_notation) simple. Le code source complet se trouve sur le [playground](https://play.rust-lang.org/?version=stable&mode=debug&edition=2018&gist=b40514e282cb753d0c3272778f92d736).

```rust
#[derive(Default)]
pub struct RpnCalculator {
    stack: Vec<Value>,
}

impl RpnCalculator {
    pub fn evaluate(&mut self, argument: Argument) -> Result<(), Error> {
        match argument {
            Argument::Value(value) => self.stack.push(value),
            Argument::Operator(operator) => {
                let b = self.stack.pop().ok_or(Error::StackUnderflow)?;
                let a = self.stack.pop().ok_or(Error::StackUnderflow)?;
                let output = operator.execute()(a, b);
                self.stack.push(output);
            }
        }
        Ok(())
    }

    pub fn conclude(self) -> Result<Value, Error> {
        if self.stack.len() == 1 {
            Ok(self.stack[0])
        } else {
            Err(Error::IncompleteCalculation)
        }
    }
}
```
