# À propos

Les conditionnels de Factor prennent tous des **_quotations_** comme branches : du code écrit entre crochets, `[ ... ]`, qui est empilé comme une valeur au lieu d'être exécuté, et qui ne s'exécute qu'au moment où le conditionnel le sélectionne. (Les *quotations* elles-mêmes sont traitées en détail dans un exercice ultérieur.)

Les trois formes de base se trouvent dans `kernel` :

```
if      ( ? then-quot else-quot -- )
when    ( ? quot -- )
unless  ( ? quot -- )
```

Deux variantes étoilées traitent le booléen comme une valeur qu'il vaut la peine d'utiliser lorsqu'il est vrai : la paire canonique « valeur ou `f` ».

```
if*     ( ? true false -- )    ! truthy: true called WITH value
unless* ( ? false      -- )    ! falsy: false runs and pushes default
```

```factor
: abs   ( x -- y ) dup 0 < [ neg ] [ ] if ;
: shout ( s -- )   dup empty? [ drop ] [ >upper print ] if ;
```

Pour plus de deux branches, `cond` (dans `combinators`) parcourt un tableau de paires `{ predicate body }` et exécute le corps du premier prédicat qui est vrai. Le schéma classique utilise `dup` dans chaque prédicat pour que l'entrée soit préservée, et le corps commence par un `drop` pour la jeter avant d'empiler le résultat :

```factor
{
    { [ dup 0 <  ] [ drop "negative" ] }
    { [ dup 0 =  ] [ drop "zero"     ] }
    [ drop "positive" ]
} cond
```

Une entrée finale sans prédicat est la branche par défaut.
