# Tests

Chaque exercice contient un fichier de test.
Exécute les tests avec le programme `bats`.

```bash
bats hello_world.bats
```

Si tu as besoin d'afficher une sortie de débogage pendant que tu lances les tests en local, consulte [Débogage en local][debugging].

`bats` doit être installé.
Consulte la page [Tests sur le parcours Bash][tests] pour savoir comment installer `bats` sur ton système.

[tests]: https://exercism.org/docs/tracks/bash/tests
[debugging]: https://exercism.org/docs/tracks/bash/debugging

## Tests ignorés

Résoudre un exercice signifie faire passer tous ses tests.
Par défaut, un seul test (le premier) est exécuté quand tu lances les tests.
C'est volontaire : cela te permet de te concentrer uniquement sur la réussite de ce test.
Une fois qu'il passe, tu peux activer le test suivant en commentant ou en supprimant l'annotation suivante :

```bash
[[ $BATS_RUN_SKIPPED == true ]] || skip
```

## Forcer l'exécution des tests ignorés

Pour lancer tous les tests, y compris ceux qui portent une annotation `skip`, tu peux exécuter :

```bash
BATS_RUN_SKIPPED=true bats exercise_name.bats
```

Il peut être pratique d'utiliser une fonction enveloppe pour taper moins :

```bash
bats() {
    BATS_RUN_SKIPPED=true command bats *.bats
}
```

Ensuite, il te suffit de lancer les tests avec :

```bash
bats
```
