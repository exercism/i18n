# À propos

Pour exécuter plusieurs fois la même logique, on peut utiliser des boucles. Si le code d'une boucle doit toujours être exécuté au moins une fois, on peut utiliser une boucle `do`/`while` :

```csharp
int x = 0;

do
{
    x = GetX();
    // do something with x
}
while (x != 0);
```

Cette boucle est utilisée moins souvent qu'une boucle `while`, mais dans certains cas elle donne un code qui semble plus naturel.
