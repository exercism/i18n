# Introduction

Cet exercice s'appuie sur l'arithmétique des nombres entiers de [Les lasagnes délicieuses de Leah][lasagna]. Ici, tu vas travailler avec des nombres à virgule flottante et choisir le mot de division adapté à la situation.

## Entiers et nombres à virgule flottante

Factor distingue les nombres entiers (`1`, `42`, `1_000_000`) des nombres à virgule flottante (`1.0`, `3.14`, `6.02e23`). Si tu mélanges un entier et un nombre à virgule flottante dans un même calcul, le résultat est un nombre à virgule flottante :

```factor
2 3 + .      ! => 5
2 3.0 + .    ! => 5.0
```

Tu peux insérer des tirets bas à l'intérieur d'un nombre pour regrouper les chiffres, comme dans `1_000_000`, et Factor les ignore tout simplement.

## Les mots de division

Factor dispose de mots de division distincts. Ils vivent tous dans le vocabulaire [`math`][math].

```
/    ( x y -- x/y )    ! exact: ratio for two integers, float if either is a float
/f   ( x y -- f   )    ! always a float
/i   ( x y -- q   )    ! integer division (truncates toward zero)
mod  ( x y -- r   )    ! remainder
/mod ( x y -- q r )    ! quotient and remainder together
```

```factor
1 2 / .        ! => 1/2     (a proper ratio)
16 3 / .       ! => 5+1/3   (an improper ratio, printed as a mixed numeral)
16 3 /f .      ! => 5.333333333333333
16 3 /i .      ! => 5      (truncated)
16 3 mod .     ! => 1
16 3 /mod .s   ! quotient and remainder in one pass
! => 5
! => 1
16.0 3 / .     ! => 5.333333333333333
```

`/` produit un `ratio` (le type rationnel exact de Factor) à partir de deux entiers, ou un `float` si l'une des entrées est un flottant. `/f` force un résultat flottant, même pour deux entiers. `/i` tronque toujours vers zéro.

## Vérification

Les prédicats numériques de [`math`][math], [`math.functions`][math.functions] et [`math.primes`][math.primes] :

```
zero?    ( x       -- ? )
even?    ( x       -- ? )
odd?     ( x       -- ? )
prime?   ( x       -- ? )
divisor? ( m n     -- ? )    ! true when n divides m
integer? ( x       -- ? )    ! true for ints (fixnum or bignum)
float?   ( x       -- ? )    ! true for floats
number?  ( x       -- ? )    ! true for any numeric kind
```

```factor
0 zero? .            ! => t
0.0 zero? .          ! => t
3 zero? .            ! => f

4 even? .            ! => t
7 even? .            ! => f
7 odd? .             ! => t

7 prime? .           ! => t
9 prime? .           ! => f

15 5 divisor? .      ! => t   (5 divides 15)
15 4 divisor? .      ! => f
```

## Du flottant vers l'entier

Les mots `floor`, `ceiling` et `round` du vocabulaire [`math.functions`][math.functions] renvoient tous un flottant (`3.0`, et non `3`). Pour obtenir un véritable entier, enchaîne avec `>integer` :

```factor
3.7 floor >integer .       ! => 3
3.2 ceiling >integer .     ! => 4
```

## Puissances et valeur absolue

Les mots `sq`, `^` et `abs` (dans [`math.functions`][math.functions]) calculent les carrés, les puissances quelconques et les valeurs absolues :

```
sq  ( x   -- x*x )
^   ( x y -- x^y )
abs ( x   -- |x| )
```

```factor
5 sq .          ! => 25
2 10 ^ .        ! => 1024
2 0.5 ^ .       ! => 1.4142135623730951
-7 abs .        ! => 7
3 abs .         ! => 3
```

## Minimum et maximum

Les mots `min ( x y -- z )` et `max ( x y -- z )` (dans [`math.order`][math.order]) renvoient le plus petit ou le plus grand de deux nombres :

```factor
3 7 min .       ! => 3
3 7 max .       ! => 7
```

L'usage le plus courant est le *clamping* : on fixe une valeur à un plancher avec `max` (par exemple, `0 max` garde une valeur positive ou nulle) ou à un plafond avec `min`.

## Prédicats d'ordre

`math.order` fournit aussi `before?`, `after?`, `before=?` et `after=?`, des prédicats de comparaison qui fonctionnent sur tout type ordonnable, qu'il s'agisse de nombres, de _strings_ ou de caractères :

```
before?  ( obj1 obj2 -- ? )   ! obj1 <  obj2
before=? ( obj1 obj2 -- ? )   ! obj1 <= obj2
after?   ( obj1 obj2 -- ? )   ! obj1 >  obj2
after=?  ( obj1 obj2 -- ? )   ! obj1 >= obj2
```

Utilise-les plutôt que `<`/`<=` quand les valeurs peuvent être des _strings_ : les opérateurs arithmétiques ne prennent pas en charge les _strings_.
