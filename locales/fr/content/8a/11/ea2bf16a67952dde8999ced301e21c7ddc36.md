# Instructions

Dans cet exercice, tu vas écrire du code pour analyser la production d'une chaîne de montage dans une usine de voitures. La vitesse de la chaîne de montage peut aller de `0` (à l'arrêt) à `10` (maximum).

À sa vitesse la plus basse (`1`), `221` voitures sont produites chaque heure. La production augmente linéairement avec la vitesse. Ainsi, avec la vitesse réglée sur `4`, elle devrait produire `4 * 221 = 884` voitures par heure. Cependant, des vitesses plus élevées augmentent la probabilité que des voitures défectueuses soient produites, et celles-ci doivent ensuite être écartées. Le tableau suivant montre comment la vitesse influence le taux de réussite :

- `0` : 0 % de réussite.
- `1` à `4` : 100 % de réussite.
- `5` à `8` : 90 % de réussite.
- `9` : 80 % de réussite.
- `10` : 77 % de réussite.

Tu as deux tâches à accomplir.

## 1. Calcule le taux de production par heure

Implémente la fonction `production-rate` pour calculer le taux de production horaire de la chaîne de montage, en tenant compte de son taux de réussite :

```clojure
(production-rate 6)
;;=> 1193.4
```

Note que la valeur renvoyée est un `float`.

## 2. Calcule le nombre d'éléments fonctionnels produits par minute

Implémente la fonction `working-items` pour calculer combien de voitures fonctionnelles sont produites par minute :

```clojure
(working-items 6)
;;=> 19
```

Note que la valeur renvoyée est un `int`.
