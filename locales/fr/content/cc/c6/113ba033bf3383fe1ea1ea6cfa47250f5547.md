# Introduction

Comme tout ce qui existe en Ruby, une `String` est un objet.
Les _strings_ sont constituées d'une suite arbitraire d'octets (normalement des caractères) et s'initialisent et se manipulent comme n'importe quel autre objet.
En fait, l'un des grands atouts de Ruby, ce sont les nombreuses méthodes que l'on peut appeler sur les _strings_ (et sur d'autres objets), qui te font gagner un temps précieux quand tu écris du code.
Dans cet exercice, on va explorer et manipuler quelques-unes de ces méthodes utilitaires.

## Crée une _string_

Même si tu peux utiliser `String.new(...)` pour créer une _string_, il est bien plus courant d'utiliser un littéral.
Il existe beaucoup de littéraux différents, et ils se répartissent en deux catégories : ceux qui permettent l'interpolation et ceux qui ne la permettent pas.

Les littéraux les plus courants sont les guillemets simples et doubles (`'...'` et `"..."`).
Les guillemets simples ne permettent pas l'interpolation, contrairement aux guillemets doubles.
L'interpolation consiste à inclure une _string_ dans une autre à l'aide de la syntaxe `#{}`.

```
# Use single quotes when not interpolated
location = 'World'

# And double quotes when interpolated
puts "Hello, #{location}!"   #=> "Hello, World!"
```

Tu peux aussi utiliser d'autres littéraux, comme `%{... }` pour les _strings_ interpolées et `%q{...}` pour les chaînes non interpolées.
Ces littéraux sont pratiques si tes _strings_ contiennent les caractères `'` ou `"`.

_Remarque : rien ne t'oblige à utiliser une chaîne de caractères non interpolée si elle ne contient pas d'interpolation._

## Interagis avec les _strings_

Il est utile de considérer les _strings_ de Ruby un peu comme des tableaux.
Elles ont une taille et leurs caractères sont indexés (le premier indice étant `0`) :

```ruby
my_string = "Some string"

my_string.size   #=> 11

my_string[0]    #=> 'S'
my_string[1]    #=> 'o'
my_string[-1]   #=> 'g'

# Find the first index of a character
my_string.index('m')   #=> 2
```

On peut extraire des parties d'une _string_ à l'aide d'indices ou de `slice` :
```ruby
my_string = "Some string"

# Find three characters starting with the second character (index 1)
my_string[1, 3]         #=> "ome"
my_string.slice(1, 3)   #=> "ome"
```

On peut aussi manipuler la valeur sémantique des _strings_.
Ça vaut le coup d'explorer la [documentation Ruby][docs-string] pour découvrir toutes ces méthodes, mais voici quelques exemples d'usage courant :
```
"hello".capitalize   #=> "Hello"
"HELLO".downcase     #=> "hello"
"hello".center(9)    #=> "  hello  "
"  hello  ".strip    #=> "hello"

"hello world".split(" ")   #=> ["hello", "world"]
```

Tu peux aussi utiliser des méthodes comme `gsub` pour remplacer des caractères :
```
# Replace one character with another
"noob".gsub("o","0")   #=> "n00b"

# (Advanced) Replace a regular expression
"Ruby really rocks".gsub(/[aieou]/,'')   #=> "Rby rlly rcks"
```

Dans tous les exemples ci-dessus, une nouvelle `String` est renvoyée.
Cependant, beaucoup de méthodes ont un équivalent qui se termine par `!` et qui modifie réellement la _string_ elle-même.

```
# Use normal methods to return new strings
my_string = "hello"
my_string.capitalize   #=> "Hello"
puts my_string         #=> "hello"

# And bang-methods (...!) to modify the object
my_string = "hello"
my_string.capitalize!  #=> "Hello"
puts my_string         #=> "Hello"
```

[docs-string]: https://docs.ruby-lang.org/en/master/String.html
