# Introduction

## Une interface comme ensemble de méthodes

Dans sa forme la plus simple, un **type interface** est un ensemble de signatures de méthodes.
Voici un exemple de définition d'interface qui comprend deux méthodes `Add` et `Value` :

```go
type Counter interface {
    Add(increment int)
    Value() int
}
```

Les noms de paramètres comme `increment` peuvent être omis dans la définition de l'interface, mais ils améliorent souvent la lisibilité.

En Go, les noms d'interface ne contiennent pas le mot `Interface` ni `I`.
En revanche, ils se terminent souvent par `er`, comme `Reader` ou `Stringer`.

## Implémente une interface

Tout type qui définit les méthodes de l'interface « implémente » automatiquement et implicitement cette interface.
Il n'existe pas de mot-clé `implements` en Go.

Le type suivant implémente l'interface `Counter` vue plus haut.

```go
type Stats struct {
    value int
    // ...
}

func (s Stats) Add(v int) {
    s.value += v
}

func (s Stats) Value() int {
    return s.value
}

func (s Stats) SomeOtherMethod() {
    // The type can have additional methods not mentioned in the interface.
}
```

Pour implémenter l'interface, le fait que la méthode ait un récepteur de valeur ou un récepteur de pointeur n'a pas d'importance.
(Reviens sur les [concepts des méthodes][concept-methods] si tu as un doute à ce sujet.)

> Une valeur de type interface peut contenir n'importe quelle valeur qui implémente ces méthodes. [^1]

Cela signifie que `Stats` peut désormais être utilisé partout où l'on attend l'interface `Counter`.

```go
func SetUpAnalytics(counter Counter) {
    // ...
}

stats := Stats{}
SetUpAnalytics(stats)
// works because Stats implements Counter
```

Comme les interfaces sont implémentées implicitement, un type peut facilement implémenter plusieurs interfaces.
Il lui suffit de définir toutes les méthodes nécessaires.

## L'interface vide

Il existe un type d'interface très particulier en Go : le type **interface vide**, qui ne contient aucune méthode.
L'interface vide s'écrit comme ceci : `interface{}`.
Depuis Go 1.18, `any` est un alias de `interface{}`, et il est plus couramment utilisé.

Comme l'interface vide n'a aucune méthode, tout type l'implémente implicitement.
C'est utile pour définir une fonction qui peut accepter n'importe quelle valeur de façon générique.
Dans ce cas, le paramètre de la fonction utilise le type interface vide.
