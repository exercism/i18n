# Instructions

Dans cet exercice, on va travailler sur quelques fonctions pour gérer des rendez-vous.
Le système stocke tout dans des _strings_ au format ISO 8601, mais ce n'est pas ainsi que les gens utilisent le calendrier.
Différentes fonctions sont nécessaires pour convertir d'un format à l'autre.

## 1. Crée un rendez-vous

Crée un rendez-vous dans `n` jours, à l'heure actuelle.
La fonction prend `n` jours et renvoie l'heure du rendez-vous `n` jours plus tard.

```javascript
createAppointment(4, now);
// Given now is Sun Oct 05 2022 23:28:43 GMT+0600 (Bangladesh Standard Time)
// => Sun Oct 09 2022 23:28:43 GMT+0600 (Bangladesh Standard Time)
```

Si le second paramètre `now` n'est pas utilisé, c'est l'heure actuelle qui est utilisée à la place.

## 2. Convertis une date en horodatage

De nombreux outils ne fonctionnent qu'avec le format ISO 8601, normalisé au niveau international.
Écris la fonction `getAppointmentTimestamp`, qui prend une date et renvoie une _string_ dans ce format.

```javascript
const appointment = new Date(Date.UTC(2010, 6, 16, 12, 42, 0, 0));

getAppointmentTimestamp(appointment);
// => '2010-07-16T12:42:00.000Z'
```

## 3. Récupère les détails d'un rendez-vous

Les horodatages sont difficiles à lire ; une fonction qui récupère les détails du rendez-vous devrait aider.
La fonction `getAppointmentDetails` prend un horodatage au format ISO 8601 et renvoie l'année, le mois, le jour, l'heure et les minutes.

```javascript
getAppointmentDetails('2022-04-24T08:15:00.000');
// => { year: 2022, month: 3, date: 24, hour: 8, minute: 15 }
```

## 4. Mets à jour un rendez-vous avec les options données

La fonction reçoit en premier argument l'heure du rendez-vous et en second argument un objet contenant des options.
Tu dois mettre à jour le rendez-vous en fonction des options de l'objet et renvoyer la nouvelle date du rendez-vous.
L'objet d'options peut contenir plusieurs options.

```javascript
updateAppointment('2022-02-09T09:20:00.000', { month: 6 });
// => { year: 2022, month: 6, date: 9, hour: 10, minute: 20 }
```

## 5. Récupère le temps disponible entre deux rendez-vous

La fonction reçoit deux rendez-vous (des horodatages) comme arguments.
Tu dois renvoyer la différence entre ces deux instants, en secondes.

Comme une demi-seconde n'a presque aucun sens, arrondis le nombre avant de le renvoyer.

```javascript
timeBetween('2022-12-12T09:20:00.000', '2022-12-18T08:30:00.000');
// => 515400
```

## 6. Vérifie si un rendez-vous est valide ou non

Enfin, une fois le rendez-vous créé, le système doit vérifier s'il est valide.
Autrement dit, le rendez-vous doit être dans le futur, et non dans le passé.

Écris la fonction `isValid`, qui prend deux arguments, l'horodatage d'un rendez-vous (_string_) et l'heure actuelle sous forme d'horodatage (_string_), et qui renvoie `true` si le rendez-vous est dans le futur, compte tenu de l'heure actuelle.

```javascript
isValid('2022-02-11T23:00:00.000', '2022-02-08T23:00:00.000');
// => true
```
