# Complément d'instructions

## Mots

Définis un tuple `game` ainsi qu'un constructeur `<game> ( -- game )` qui renvoie une
nouvelle partie sans lancers.

Fournis ces mots, qui opèrent sur une partie :

- `roll ( pins game -- )` : enregistre que `pins` quilles ont été renversées. Lève une
  erreur quand le lancer est invalide :
  - `"Negative roll is invalid"` pour un nombre de quilles négatif.
  - `"Cannot roll after game is over"` une fois que les dix frames (et les éventuelles
    boules de remplissage) ont été lancées.
  - `"Pin count exceeds pins on the lane"` quand plus de quilles sont renversées qu'il
    n'y en a debout.
- `score ( game -- n )` : le score total de la partie. Lève
  `"Score cannot be taken until the end of the game"` quand la partie n'est pas encore
  terminée.

Note que `roll` masque le mot `roll` de manipulation de la pile, du vocabulaire `kernel`.
La suite de tests lève l'ambiguïté avec `FROM: bowling => roll ;`.
