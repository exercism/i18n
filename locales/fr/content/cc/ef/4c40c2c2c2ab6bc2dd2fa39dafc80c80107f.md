# Concepts des nombres d'Armstrong

> Un [nombre d'Armstrong](https://en.wikipedia.org/wiki/Narcissistic_number) est un nombre qui est la somme de ses propres chiffres, chacun élevé à la puissance du nombre de chiffres.

## Exemple de solution

```rust
pub fn is_armstrong_number(num: u32) -> bool {
    let digits = format!("{}", num);
    digits
        .chars()
        .map(|c| c.to_digit(10).unwrap().pow(digits.len() as u32))
        .sum::<u32>()
    == num
}
```

## Concepts

- fonctions : essentielles pour vérifier la solution et définir la logique
- suites de tests : nécessaires pour vérifier la solution
- entiers : `u32` pour l'argument et les assertions d'identité
- `&str` : nécessaire pour compter la longueur du nombre, car Rust est fortement typé
- `Option<T>` : nécessaire pour accéder à la valeur réelle de `char::to_digit`
- conversion de type : nécessaire pour appliquer des opérations arithmétiques
- fonctionnalités des itérateurs :
  - turbofish pour permettre une solution en une seule expression
  - `map` et `sum` pour réduire commodément l'expression à ce que l'on doit vérifier
