# Introduction

PowerShell est un langage de script à typage implicite dynamique (il prend aussi en charge les variables à typage fort) de Microsoft, principalement axé sur l'automatisation des tâches et la gestion de configuration.

PowerShell prend en charge la programmation impérative, fonctionnelle, orientée objet, et même le style pipeline.

PowerShell est construit sur la plateforme .NET et a été publié pour la première fois en 2006.
Il est inclus par défaut dans tous les systèmes Windows modernes et peut être installé sur Mac et Linux.


## Variables

Il existe deux façons courantes de définir une variable en PowerShell.

Le nom d'une variable en PowerShell doit commencer par `$` et l'on utilise l'opérateur d'affectation `=` pour lier le nom de la variable à une valeur.

```powershell
> $intVar = 1
> $doubleVar = 2.0
> $stringVar = "Hello"

# Checking a variable type using the GetType() method
> Write-Host $doubleVar.GetType()
System.Double
```

Tu peux aussi préciser explicitement le type d'une variable si tu veux imposer un [type][strong typed] donné.
PowerShell fera de son mieux pour convertir la valeur d'un type à un autre si possible.

```powershell
# String represents a floating number can be converted to integer
> [int]$staticOne = "1.234"
> $staticOne
1

# String of letters can not be converted to double type
> [double]$staticTwo = "hello"
MetadataError: Cannot convert value "hello" to type "System.Double"
```


### Constantes

Les constantes en PowerShell sont des variables en lecture seule qui ne peuvent pas être **supprimées** après avoir été définies.
Cela nous amène à la seconde façon de définir des variables, à l'aide de la cmdlet `New-Variable`.

```powershell
> New-Variable -Name "MyConstant" -Value 100 -Option Constant
> $MyConstant
```

Pour une manière plus détaillée et plus avancée de créer une variable avec diverses options, consulte la cmdlet [New-Variable][New-Variable].


## Fonctions

Les [fonctions][functions] en PowerShell se définissent à l'aide du mot-clé `function`.
Chaque fonction peut avoir zéro ou plusieurs [paramètres][parameters] formels entre les parenthèses `()`, suivis de sa propre [portée][scope] qui commence par `{` et se termine par `}`.

```powershell
function Greeting {
    return "Hello!"
}
```

Les fonctions en PowerShell peuvent renvoyer des valeurs explicitement via le mot-clé `return`, après avoir été appelées avec la syntaxe `FuncName $Arg`.

```powershell
function AddTwoNumbers($NumOne, $NumTwo):
    $result = $NumOne + $NumTwo
    return $result

> AddTwoNumbers 10 20
30
```

Un examen plus avancé de la façon d'écrire une définition de fonction détaillée, et de la manière dont les fonctions peuvent renvoyer des valeurs implicitement, sera abordé dans le module du concept `Functions`.


## Commentaires

Un commentaire sur une seule ligne en PowerShell commence par `#` et se termine à la fin de la ligne.
Un bloc de commentaire en PowerShell commence par `<#` et se termine par `#>`.
Une présentation avancée du bloc de commentaire pour créer de l'aide basée sur les commentaires sera abordée dans le module du concept `Functions`.

```powershell
function Main() {
    #This is a comment
}
```
