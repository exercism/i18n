# Instructions

Dans cet exercice, tu vas travailler avec des comptes d'épargne.
Chaque année, le solde de ton compte d'épargne est mis à jour en fonction de son taux d'intérêt.
Le taux d'intérêt que ta banque t'accorde dépend de la somme d'argent présente sur ton compte (son solde) :

- 3,213 % pour un solde négatif (le solde devient encore plus négatif).
- 0,5 % pour un solde positif inférieur à `1000` dollars.
- 1,621 % pour un solde positif supérieur ou égal à `1000` dollars et inférieur à `5000` dollars.
- 2,475 % pour un solde positif supérieur ou égal à `5000` dollars.

Tu as quatre tâches, chacune portant sur ton solde et son taux d'intérêt.

## 1. Calcule le taux d'intérêt

Implémente la méthode `SavingsAccount.interest_rate()` qui prend un solde en argument.
La méthode doit renvoyer le taux d'intérêt pour le solde donné.

```Crystal
SavingsAccount.interest_rate(200.75)
# => 0.5
```

## 2. Calcule les intérêts

Implémente la méthode `SavingsAccount.interest()` qui prend un solde en argument.
La méthode doit renvoyer les intérêts pour le solde donné.

```Crystal
SavingsAccount.interest(200.75)
# => 1.00375
```

## 3. Calcule la mise à jour annuelle du solde

Implémente la méthode `SavingsAccount.annual_balance_update()` qui prend un solde en argument.
La méthode doit renvoyer le solde après un an.

```Crystal
SavingsAccount.annual_balance_update(200.75)
# => 201.75375
```

## 4. Calcule le nombre d'années avant d'atteindre le solde souhaité

Implémente la méthode `SavingsAccount.years_before_desired_balance()` qui prend un solde et un solde cible en arguments.
La méthode doit renvoyer le nombre d'années qu'il faudrait pour atteindre le solde cible.

```Crystal
balance = 200.75
target_balance = 214.88
SavingsAccount.years_before_desired_balance(balance, target_balance)
# => 14
```

~~~~exercism/note
Quand on applique un intérêt simple à un capital de départ, le solde est multiplié par le taux d'intérêt et le produit des deux donne le montant des intérêts.

Les intérêts composés, quant à eux, s'obtiennent en appliquant les intérêts de façon récurrente.
À chaque application, le montant des intérêts est calculé puis ajouté au capital, de sorte que les calculs d'intérêts suivants portent sur un capital plus élevé.
~~~~
