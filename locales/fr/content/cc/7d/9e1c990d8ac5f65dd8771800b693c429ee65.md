# Ajout aux instructions

## Registres

| Registre | Utilisation  | Type    | Description                             |
| -------- | ------------ | ------- | --------------------------------------- |
| `$a0`    | entrée       | adresse | chaîne d'entrée terminée par un caractère nul |
| `$a1`    | entrée/sortie | adresse | tableau de mots avec le décompte final des nucléotides |
| `$t0-9`  | temporaire   | quelconque | pour un stockage temporaire          |
