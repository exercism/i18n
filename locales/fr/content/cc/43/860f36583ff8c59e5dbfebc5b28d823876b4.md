# Introduction

## Tableaux

Un `array` en F# est une collection modifiable de zéro ou plusieurs valeurs et de longueur fixe. Cela signifie qu'une fois qu'un tableau a été créé, sa taille ne peut plus changer, mais que ses valeurs, elles, peuvent être modifiées. Toutes les valeurs d'un tableau doivent avoir le même type. Les tableaux peuvent être définis comme suit :

```fsharp
let empty = [| |]
let emptyAlternative = Array.empty

let singleValue = [| 5 |]
let singleValueAlternative = Array.singleton 5

let threeValues = [| "a"; "b"; "c" |]
```

On peut affecter une valeur à un élément d'un tableau ou récupérer cet élément à l'aide d'un indice. Les tableaux F# sont indexés à partir de zéro, ce qui signifie que l'indice du premier élément est toujours zéro :

```fsharp
let numbers = [| 2; 3; 5 |]

// Update value in array
numbers[2] <- 9

// Read value from array
numbers[2]
// => 9
```

Les tableaux sont soit manipulés par des fonctions et des opérateurs définis dans le module `Array`, soit manuellement par correspondance de motifs, avec le motif _tableau_ :

```fsharp
let describe array =
    match array with
    | [| |] -> "Empty"
    | [| 1; 2; three |] -> sprintf "1, 2, %d" three
    | _ -> "Other"

describe [| |]         // => "Empty"
describe [| 1; 2; 4 |] // => "1, 2, 4"
describe [| 5; 7; 9 |] // => "Other"
```

On peut aussi _ignorer_ une valeur lors d'une correspondance de motifs ; quand on ne se soucie pas d'une valeur dans un cas précis (c'est-à-dire qu'on ne va pas _utiliser_ cette valeur), on peut utiliser un tiret bas (`'_'`) pour l'indiquer :

```fsharp
let describe array =
    match array with
    | [| |] -> "Empty array"
    | [| x |] -> "Array with one item"
    | [| _; y |] -> "Array with two items (first item ignored)"
    | _ -> "Array with many items (all items ignored)"

describe [| |]          // => "Empty array"
describe [| 1 |]        // => "Array with one item"
describe [| 5; 7 |]     // => "Array with two items (first item ignored)"
describe [| 5; 7; 9 |]  // => "Array with many items (all items ignored)"
```

Le `'_'` seul doit toujours venir _en dernier_ lors d'une correspondance de motifs ; toute valeur qui _ne correspond_ à aucun des autres cas sera traitée par ce cas.
