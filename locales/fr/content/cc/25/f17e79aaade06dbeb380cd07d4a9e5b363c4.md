# Instructions

Cette voiture télécommandée que tu as achetée récemment est devenue un tout nouveau passe-temps. Tu organises des courses de voitures télécommandées.

Tu avais presque fini d'écrire un programme qui devait permettre de lancer des simulations de course quand ton chat a sauté sur ton clavier et supprimé quelques lignes de code. Maintenant, ton programme ne compile plus...

## 1. Corrige l'erreur de compilation `Race.__struct__/0 is undefined`

Ajoute un alias pour que le module `NeedForSpeed.Race` puisse être référencé par le nom plus court `Race`.

## 2. Corrige l'erreur de compilation `Car.__struct__/0 is undefined`

Ajoute un alias pour que le module `NeedForSpeed.RemoteControlCar` puisse être référencé par le nom plus court `Car`.

## 3. Corrige l'erreur de compilation `undefined function puts/1`

La fonction `puts/1` vient du module `IO`. Importe-la pour pouvoir l'utiliser sans référencer le module.

## 4. Corrige l'erreur de compilation `undefined function default_color/0`

Les fonctions `default_color/0`, `red/0`, `cyan/0` et `green/0` viennent toutes du module `IO.ANSI`. Tu prévois d'ajouter la prise en charge d'autres couleurs de voiture, donc tu veux importer tout le module. Malheureusement, la fonction `color/1` du module `IO.ANSI` entre en conflit avec l'une de tes fonctions locales. Importe tout le module `IO.ANSI` sauf cette fonction.
