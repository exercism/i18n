# Introduction

Travailler avec des données binaires peut s'avérer délicat, c'est pourquoi Gleam fournit un type `BitArray` et une syntaxe associée pour construire des données binaires et les filtrer par motif.

Les littéraux de tableau de bits se définissent avec la syntaxe `<<>>`. Un littéral de tableau de bits se définit par segments. Chaque segment comporte une valeur et une annotation, séparées par un `:`. L'annotation indique combien de bits seront utilisés pour encoder la valeur ; on peut aussi l'omettre complètement, auquel cas la valeur par défaut est un entier de 8 bits.

```gleam
// This defines a bit array with three segments of a single bit each
<<0:1, 1:1, 0:1>>

// This defines a bit array with three segments of 8 bits each
<<0, 1, 0>>
```

Écrire le type sous la forme `:1` est un raccourci pour `:size(1)`. Il faut utiliser la syntaxe longue si la taille en bits provient d'une variable.

```gleam
let segment_size = 1
<<0:size(segment_size), 1:size(segment_size), 0:size(segment_size)>>
```

## Binaire

Pour écrire des littéraux d'entiers binaires, on peut les écrire directement en base 2 en préfixant le littéral par `0b`. À noter qu'ils seront affichés en notation décimale lorsqu'on les imprime dans les tests ou dans le programme.

```gleam
<<0b1011:4>> == <<11:4>>
// -> True
```

## Troncature

Si la valeur du segment dépasse la capacité du type du segment, elle est tronquée par la gauche.

```gleam
<<0b1011:3>> == <<0b0011:3>>
// -> True
```

## Ajout au début et à la fin

On peut à la fois ajouter au début et à la fin d'un tableau de bits existant grâce à la syntaxe des tableaux de bits. L'annotation `:bits` doit être utilisée pour le tableau de bits existant.

```gleam
let value = <<0b110:3, 0b001:3>>
let new_value = <<0b011:3, value:bits, 0b000:3>>
// -> <<120, 8:size(4)>>
```

## Concaténation

On peut concaténer des tableaux de bits stockés dans des variables grâce à cette syntaxe. L'annotation `:bits` est obligatoire lorsqu'on concatène deux tableaux de bits de tailles variables.

```gleam
let first = <<0b110:3>>
let second = <<0b001:3>>
let concatenated = <<first:bits, second:bits>>
// -> <<49:size(6)>>
```

## Filtrage par motif

On peut aussi faire du filtrage par motif pour obtenir des valeurs à partir du tableau de bits. Il faut connaître le nombre de bits de chaque fragment que l'on veut capturer, à une exception près : l'annotation `:bits` permet de faire du filtrage par motif sur un tableau de bits de taille inconnue, mais uniquement pour le dernier fragment.

```gleam
let assert <<value:4, rest:bits>> = <<0b01101001:8>>
value == 0b0110
// -> true
```

## Inspection des tableaux de bits

~~~~exercism/note
Il se peut que les tableaux de bits soient affichés dans un format différent de celui utilisé pour les créer. Cela prête souvent à confusion lorsqu'on apprend les tableaux de bits.
~~~~

Par défaut, les tableaux de bits sont affichés par fragments de 8 bits (un octet), même si on les a créés avec des fragments d'une autre taille.

```gleam
<<2011:11>>
// -> <<251, 3:size(3)>>
```

Si on crée un tableau de bits qui représente une _string_ encodée en UTF-8 imprimable, il peut être affiché comme une _string_ par des fonctions telles que `io.debug`. Cela vient d'un détail d'implémentation de la façon dont Gleam représente les _strings_ en interne.

```gleam
<<>>
// -> ""

<<65, 66, 67>>
// -> "ABC"
```
