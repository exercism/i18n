# Introduction

Les tuples en Elm peuvent contenir deux ou trois valeurs, et chaque valeur peut être de n'importe quel type.
En Elm, les tuples servent surtout à des types transitoires simples.
C'est pourquoi les tuples ont un maximum de 3 valeurs, et pour t'encourager encore plus, des fonctions pratiques ne sont fournies que pour 2 valeurs.
Pour des données plus complexes, il vaut mieux passer aux enregistrements.

```elm
type alias IntStringTuple = (Int, String)

aTuple : IntStringTuple
aTuple = (123, "elements can be of differing types")

anotherTuple : (String, String)
anotherTuple = Tuple.pair "this time it's" "two strings"
    --> ("this time it's", "two strings")

Tuple.first aTuple
    --> 123

Tuple.second aTuple
    --> "elements can be of differing types"
```

Les tuples peuvent être _déstructurés_ dans des liaisons à l'aide du filtrage par motif sur les tuples.
La déstructuration peut se faire dans les expressions let, les déclarations de fonctions et les expressions case.

```elm
repeatString : (Int, String) -> Bool
repeatString aTuple =
let
    (aNumber, aString) = aTuple
in
    String.repeat aNumber aString

repeatStringAgain : (Int, String) -> Bool
repeatStringAgain (aNumber, aString) = String.repeat aNumber aString

has123 : (Int, String, Bool) -> Bool
has123 aTuple =
    case aTuple of
        (123, _, _) ->
            True
        (_, "123", _) ->
            True
        (_, _, True) ->
            True
        _ ->
            False
```
