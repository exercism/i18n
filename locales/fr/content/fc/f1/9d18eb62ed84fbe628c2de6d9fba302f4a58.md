# Instructions

Chaque routine que la troupe de danse interprète repose sur le même échauffement, puis prend sa propre direction.

Le code de départ te donne `WARM_UP`. Écris trois autres classes en dessous.

## 1. La routine jazz

`JAZZ_ROUTINE` reprend tout de `WARM_UP` tel quel, et n'ajoute rien.

```sather
JAZZ_ROUTINE::counts
-- => 8
JAZZ_ROUTINE::describe
-- => "8 counts"
```

## 2. La routine de claquettes

`TAP_ROUTINE` reprend `counts` de `WARM_UP` mais se décrit à sa manière. Ne mets pas `describe` dans l'include et écris-en une nouvelle.

```sather
TAP_ROUTINE::counts
-- => 8
TAP_ROUTINE::describe
-- => "Tap: 8 counts"
```

## 3. Le final

`FINALE` reprend `counts` de `WARM_UP` sous le nom `warm_up_counts`, et laisse `describe` de côté. Elle a ensuite son propre `counts`, qui vaut le double de celui de l'échauffement, et son propre `describe`.

```sather
FINALE::warm_up_counts
-- => 8
FINALE::counts
-- => 16
FINALE::describe
-- => "Finale: 16 counts"
```

Remarque ce que cela montre : `FINALE::counts` n'est pas `WARM_UP::counts`, et les deux sont disponibles sous des noms différents dans la même classe.
