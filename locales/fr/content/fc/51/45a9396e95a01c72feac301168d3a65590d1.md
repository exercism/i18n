# Indices

## Général

- Pour extraire plusieurs arguments dans les paramètres d'une fonction, tu peux les regrouper avec `...<args>`.
- Pour utiliser le _rest_ et le _spread_, utilise l'opérateur `...`.

## 1. Crée une liste de tous les wagons

- Plusieurs arguments dans les paramètres de la fonction peuvent être regroupés avec la [syntaxe `...<args>` (spread)][spread-syntax].

## 2. Déplace les deux premiers éléments à la fin du tableau

- Tu peux décomposer une série de paramètres avec [une affectation par déstructuration (`...`)][destructuring-assignment].
  Cela te permet d'extraire les deux premiers éléments d'un `array` tout en gardant le reste intact.
- Pour ajouter un autre `array` dans un `array` existant, tu peux utiliser l'opérateur `...` pour _spread_ le `array`.

## 3. Ajoute les valeurs manquantes

- En utilisant le dépaquetage avec l'opérateur rest (`...`), tu peux extraire le premier élément d'un `array` tout en gardant le reste intact.
- Pour ajouter un autre `array` dans un `array` existant, tu peux utiliser l'opérateur `...` pour _spread_ le `array`.

## 4. Étends les informations d'itinéraire

- Pour ajouter un autre `object` dans un `object` existant, tu peux utiliser l'opérateur `...` pour _spread_ le `object`.

## 5. Sépare l'heure d'arrivée des informations d'itinéraire

- Pour extraire une valeur d'un `object` tout en gardant le reste intact, tu peux utiliser l'opérateur rest (`...`).
