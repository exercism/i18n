# Char

`Char` est un type de données en Crystal qui représente un point de code [Unicode][unicode] sur 32 bits.
Leur taille les rend économes en mémoire et leur confère des propriétés spécifiques que les `String` n'ont pas.
On les crée à l'aide de guillemets simples (`'`) et ils n'acceptent qu'un seul point de code Unicode à l'intérieur.

```crystal
'a' # => 'a'
'a'.class # => Char
```

Il est assez courant de manipuler des `Char` quand on travaille avec des `String` en Crystal, car un certain nombre de méthodes de la classe `String` renvoient des `Char` ou prennent des `Char` en argument.
Par exemple, la méthode [`String#[]`][index] renvoie un `Char`, ou la méthode [`String#chars`][chars] renvoie une collection de `Char`.

## Incrémentation / Décrémentation

Comme un char représente un point Unicode sur 32 bits, il prend en charge l'incrémentation et la décrémentation, ce qui permet, si tu as `'a'`, d'obtenir `'b'` en ajoutant un.

```crystal
'a' + 5
# => 'f'

'z' - 25
# => 'a'
```

Il existe aussi une méthode appelée [`Char#succ`][succ], qui renvoie le char suivant dans la table Unicode, et [`Char#pred`][pred], qui renvoie le char précédent dans la table Unicode.

```crystal
'a'.succ
# => 'b'

'z'.pred
# => 'y'
```

## Concaténation

Comme les `Char` ne sont censés représenter qu'un point Unicode sur 32 bits, deux char ne peuvent pas être concaténés.
Par conséquent, un `Char` ne peut être concaténé qu'avec des `String`.

```Crystal
'a' + "bc"
# => "abc"

'a' + 'b'
# => error: expected argument #1 to 'Char#+' to be Int or String, not Char
```

## Méthodes de propriété

Crystal propose quelques méthodes pour obtenir des informations sur un caractère, par exemple s'il s'agit d'un nombre ou d'une lettre, ou s'il est en majuscule ou en minuscule.
Voici une liste de quelques-unes de ces méthodes ; pour la liste complète, consulte l'[API de Char][char-api] :

| Method                           | Description                                          |
| -------------------------------- | ---------------------------------------------------- |
| [`Char#number?`][number]         | Renvoie `true` si le char est un nombre              |
| [`Char#letter?`][letter]         | Renvoie `true` si le char est une lettre             |
| [`Char#lowercase?`][lowercase]   | Renvoie `true` si le char est en minuscule           |
| [`Char#uppercase?`][uppercase]   | Renvoie `true` si le char est en majuscule           |
| [`Char#ascii?`][ascii]           | Renvoie `true` si le char est un caractère ASCII     |
| [`Char#whitespace?`][whitespace] | Renvoie `true` si le char est un caractère d'espacement |

## Conversion

### Conversion entre points de code et Char

Comme un `Char` est un point Unicode sur 32 bits, on peut convertir un `Char` en point de code (un `Int`), et inversement.
Pour cela, on peut utiliser la méthode [`Char#ord`][ord], qui renvoie le point de code du char, ou la méthode [`Int#chr`][chr], qui renvoie le char correspondant au point de code.

```crystal
'a'.ord
# => 97

97.chr
# => 'a'
```

### Conversion entre types

Comme pour les autres types de données, les char disposent de quelques méthodes pour convertir d'un type à un autre.
La plus courante est la méthode `Char#to_s`, qui convertit le char en `String`. Il existe cependant aussi la méthode `Char#to_i`, qui convertit le char en `Int`, et la méthode `Char#to_f`, qui convertit le char en `Float`.

```crystal
'a'.to_s
# => "a"

'4'.to_i
# => 4

'a'.to_i
# => Error: Invalid integer: a (ArgumentError)
```
