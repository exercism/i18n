# Introduction

## Bases

### Fonctions

En Gleam, les fonctions se définissent avec la syntaxe `pub fn`.

```gleam
pub fn add(x: Int, y: Int) -> Int {
  x + y
}
```

Cette fonction prend deux arguments, tous deux de type `Int`, et renvoie une valeur de type `Int`. Il n'y a pas de mot-clé `return` en Gleam : la valeur de la dernière expression d'une fonction est toujours _renvoyée implicitement_.

Les annotations de type des arguments et le type de retour sont facultatifs, et Gleam vérifiera toujours entièrement le typage de ton code. En général, les développeurs Gleam annotent leurs fonctions avec des types pour plus de clarté, mais tu peux les omettre si tu le souhaites.

```gleam
pub fn add(x, y) {
  x + y
}
```

On peut appeler une fonction avec la syntaxe `function_name(argument1, argument2)`.

```gleam
pub fn double(x: Int) -> Int {
  // Call the add function defined above
  add(x, x)
}
```

### Variables

En Gleam, les variables se définissent avec la syntaxe `let name = expression`.

```gleam
pub fn main() {
  let count = 1
}
```

Les variables peuvent être déclarées avec des annotations de type. Comme pour les arguments de fonction, elles sont facultatives, même si la plupart des développeurs Gleam omettent les annotations de type des variables pour aller à l'essentiel.

```gleam
pub fn main() {
  let count: Int = 1
}
```

### Littéraux de _string_

En Gleam, les _strings_ s'écrivent avec des guillemets doubles.

```gleam
pub fn greeting() {
  "Hello, world!"
}
```

### Commentaires de code

Les commentaires permettent de laisser des notes aux autres développeurs qui lisent le code source. En Gleam, les commentaires tiennent sur une seule ligne et sont précédés de `//`.

```gleam
pub fn main() {
  // This is a comment
  let x = 1
}
```
