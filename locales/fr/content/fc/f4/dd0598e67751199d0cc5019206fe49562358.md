# Introduction

Les closures en Swift sont des blocs de code autonomes auxquels on peut passer des paramètres pour déclencher leur calcul et renvoyer des valeurs. Les closures capturent aussi des valeurs de leur environnement et les utilisent dans leurs calculs. Comme elles sont autonomes, elles peuvent circuler dans un programme comme n'importe quelle autre valeur, ou être affectées à des constantes et à des variables.

Les closures peuvent beaucoup ressembler aux fonctions Swift ; c'est le cas, et pour une bonne raison. Les fonctions en Swift ne sont que des cas particuliers de closures, auxquelles il est imposé d'avoir un nom et qui sont définies à l'aide d'une syntaxe légèrement différente.

Bien que les fonctions en Swift soient techniquement des closures, quand on parle de « closures » en Swift, on désigne les expressions de closure. Une expression de closure s'écrit comme une liste de paramètres suivie d'un type de retour et du mot-clé `in`, lui-même suivi du corps de la closure, le tout entre accolades :

```swift
{ (a: Double, b: Double) -> Double in
  return a + b / 2.0
}
```

Cela définit une expression de closure de type `(Double, Double) -> Double`, et on peut l'exécuter d'une manière similaire à une fonction de ce type, en l'appliquant à des paramètres du type approprié :

```swift
{ (a: Double, b: Double) -> Double in
  return a + b / 2.0
}(10.0, 15.0)
// => 12.5
```

Comme on le voit ci-dessus, les closures, comme les fonctions ordinaires, peuvent omettre le mot-clé `return` si le corps de la closure est une seule expression.
