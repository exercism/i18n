# Introduction

En Swift, l'instruction `guard` sert à sortir plus tôt d'une fonction lorsqu'une condition indispensable à la poursuite du traitement n'est pas remplie, par exemple :

```swift
guard myValue >= 0 else { return 0 }
let root = myValue.squareRoot()
```

Ici, le `guard` vérifie si l'expression booléenne qui suit le mot-clé `guard` s'évalue à vrai. Si c'est le cas, le traitement se poursuit avec le code qui suit l'instruction `guard` (ici `let root = myValue.squareRoot()`. Sinon, c'est le code de la clause `else` qui sera exécuté. Contrairement à une instruction `if`, une instruction `guard` _doit_ comporter une clause `else`, et contrairement à la clause `else` d'un `if`-`else`, la clause `else` d'un `guard` _doit_ sortir de la portée de l'instruction `guard`. Autrement dit, elle doit utiliser une instruction de transfert de contrôle comme `return`, `continue` ou `break`, ou bien lever une erreur ou quitter le programme.
