# Caractères

Un **caractère** est une seule lettre, un chiffre, un espace ou un signe. Le type de Sather pour un caractère est `CHAR`, et un caractère s'écrit entre guillemets simples.

```sather
   initial : CHAR is
      return 'M';
   end;
```

Guillemets simples pour un caractère, guillemets doubles pour une _string_. `'M'` et `"M"` sont deux types différents et ne peuvent pas être échangés.

## Extraire un caractère d'une _string_

Une _string_ est une suite de caractères, et les crochets (`[]`) permettent d'en atteindre un par sa position, en comptant à partir de zéro, comme pour un tableau.

```sather
"Marlowe"[0]      -- 'M'
"Marlowe"[3]      -- 'l'
```

## Interroger un caractère

| Appel | Réponses |
| --- | --- |
| `c.is_alpha` | est-ce une lettre ? |
| `c.is_digit` | est-ce l'un des chiffres de `0` à `9` ? |
| `c.is_upper` | est-ce une majuscule ? |
| `c.is_lower` | est-ce une minuscule ? |

Chacune renvoie `true` ou `false`.

```sather
'M'.is_alpha      -- true
'7'.is_alpha      -- false
'7'.is_digit      -- true
```

## Changer la casse

`.upper` donne la majuscule d'une lettre, et `.lower` la minuscule. Tout ce qui n'est pas une lettre est renvoyé tel quel.

```sather
'm'.upper         -- 'M'
'M'.lower         -- 'm'
'7'.upper         -- '7'
```

## Les caractères en tant que nombres

À chaque caractère correspond un nombre. `.int` le renvoie, et `.char` transforme un nombre en caractère.

```sather
'a'.int           -- 97
'b'.int           -- 98
98.char           -- 'b'
```

Les nombres exacts importent rarement. Ce qui compte, c'est que les lettres `a` à `z` soient dans l'ordre et à la suite les unes des autres, si bien que `'c'.int - 'a'.int` vaut 2, soit la position de `c` dans l'alphabet. C'est ce qui fait fonctionner une roue de chiffrement.
