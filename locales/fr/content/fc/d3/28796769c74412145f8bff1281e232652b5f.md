# Ajout aux instructions

## Remarque

Construis cet exercice pièce par pièce, et n'aie pas peur d'extraire les concepts utiles dans une nouvelle classe.
Les exercices précédents devraient te fournir la base d'une solution élégante.

Il peut aussi être utile de revoir les chapitres sur la pensée orientée objet, par exemple [Inside Smalltalk - chapitre 1](http://sdmeta.gforge.inria.fr/FreeBooks/InsideST/InsideSmalltalk.pdf) ou [Smalltalk by Example - chapitre 9](http://sdmeta.gforge.inria.fr/FreeBooks/ByExample/11%20-%20Chapter%209%20-%20Object-Oriente.pdf)
