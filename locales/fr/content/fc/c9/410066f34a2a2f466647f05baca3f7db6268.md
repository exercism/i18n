# Debug

Lorsqu'un test échoue, un message s'affiche décrivant ce qui n'a pas fonctionné et pour quelle entrée.

Afficher les valeurs et le contenu des variables peut aussi aider à comprendre ce qui se passe.
PHP peut afficher des valeurs avec :

- `echo 'Debug message';` pour afficher une _string_ de ton choix
- `var_dump($variable);` pour en savoir plus sur une valeur, par exemple le type que PHP voit
