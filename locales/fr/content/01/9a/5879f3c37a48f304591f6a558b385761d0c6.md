# Introduction

La documentation en Elixir est un citoyen de première classe.

Deux attributs de module sont couramment utilisés pour documenter le code : `@moduledoc` pour documenter un module et `@doc` pour documenter une fonction qui suit l'attribut. L'attribut `@moduledoc` apparaît généralement sur la première ligne du module, et l'attribut `@doc` apparaît généralement juste avant la définition d'une fonction, ou le _typespec_ de la fonction s'il y en a un. La documentation est généralement écrite dans une _string_ multiligne en utilisant la syntaxe _heredoc_.

La documentation Elixir est écrite en [**Markdown**][markdown].

```elixir
defmodule String do
  @moduledoc """
  Strings in Elixir are UTF-8 encoded binaries.
  """

  @doc """
  Converts all characters in the given string to uppercase according to `mode`.

  ## Examples

      iex> String.upcase("abcd")
      "ABCD"

      iex> String.upcase("olá")
      "OLÁ"
  """
  def upcase(string, mode \\ :default)
end
```

[markdown]: https://docs.github.com/en/github/writing-on-github/basic-writing-and-formatting-syntax
