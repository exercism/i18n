# Introduction

## Les _strings_

En F#, une `string` est un objet qui représente du texte immuable sous la forme d'une séquence de caractères Unicode (lettres, chiffres, ponctuation, etc.) et se définit comme suit :

```fsharp
let fruit = "Apple"
```

Les _strings_ se manipulent soit en appelant les méthodes de la _string_, soit en utilisant les fonctions du module `String`. Une fois qu'une _string_ a été construite, sa valeur ne peut plus jamais changer. Toute méthode ou fonction qui semble modifier une _string_ renvoie en réalité une nouvelle _string_.

Les _strings_ peuvent être concaténées ou formatées de plusieurs façons différentes.
* On peut utiliser l'opérateur `+` pour la concaténation :
```fsharp
let sentence = "Apple" + " is a type of fruit."
```
* On peut utiliser la fonction `sprintf` pour formater du texte en plaçant des marqueurs de position dans un texte de format (`%s` pour une `string`) et en fournissant les valeurs en arguments :
```fsharp
let sentence = sprintf "%s is a type of %s." "Apple" "fruit"
```
