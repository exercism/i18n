# Introduction

## Les `char`

### Les `char`

Le type primitif `char` de Java est une représentation sur 16 bits d'un seul caractère.
Plusieurs `char` peuvent constituer une _string_, comme `"word"`, ou bien les `char` peuvent être traités indépendamment.
Un littéral `char` est entouré de guillemets simples (par exemple `'A'`).

```java
char lowerA = 'a';
char upperB = 'B';
```

### Obtiens les `char` d'une `String`

La méthode `String.toCharArray` renvoie les `char` d'une _string_ sous forme de tableau.
Comme mentionné dans la partie sur les tableaux, on peut utiliser une boucle `for` pour parcourir le tableau.

```java
String text = "Hello";
char[] asArray = text.toCharArray();

for (char ch: asArray) {
    System.out.println(ch);
}

// Outputs:
// H
// e
// l
// l
// o
```

### La classe Character

Il existe de nombreuses méthodes intégrées à la bibliothèque pour inspecter et manipuler des `char`.
On les trouve sous forme de méthodes statiques de la classe `java.lang.Character`.
Voici quelques exemples :

```java
Character.isWhitespace(' ');    // true
Character.isWhitespace('#');    // false

Character.isLetter('a');        // true
Character.isLetter('3');        // false

Character.isDigit('6');         // true
Character.isDigit('?');         // false
```

### Ajoute un `char` à une `String`

L'opérateur `+` peut servir à ajouter un `char` à une _string_.

```java
'a' + " banana"     // => "a banana"
"banana " + 'a'     // => "banana a"
```

~~~~exercism/caution
Fais bien attention à _ne pas_ utiliser `+` pour joindre deux `char` afin de former une _string_ !
Additionner deux `char` de cette façon donne un `int`, _pas_ une _string_ !
Par exemple :

```java
'b' + 'c';
// => 197 (not the String "bc")
```

En effet, Java promeut le `char` en `int` (voir [4.2 Primitive Types and Values ][jls-primitives] de la [Java Language Specification][jls-main]).

[jls-main]: https://docs.oracle.com/javase/specs/jls/se21/html/
[jls-primitives]: https://docs.oracle.com/javase/specs/jls/se21/html/jls-4.html#jls-4.2
~~~~

Cependant, lorsqu'il y a beaucoup de caractères à ajouter, il peut être plus efficace d'utiliser un `StringBuilder` à la place :

```java
StringBuilder builder = new StringBuilder();
builder.append('a');
builder.append('b');
builder.append('c');

String builtString = builder.toString();
// => abc
```
