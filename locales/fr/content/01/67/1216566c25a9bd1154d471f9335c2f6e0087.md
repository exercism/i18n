# Introduction

## Lance-toi

### Variables

On peut associer des valeurs à des noms en définissant une [variable][constants-variables] et en affectant une valeur à cette variable.
Ce nom peut ensuite être utilisé pour faire référence à cette valeur dans tout le programme.
Les variables sont _modifiables_, ce qui signifie que la valeur peut être changée à tout moment.

Les variables sont définies à l'aide du mot-clé `var`.

```swift
var variableName = 10
```

Swift est un langage à typage statique et sûr au niveau des types, ce qui signifie que toutes les valeurs ont un type au moment de la compilation.
On peut soit spécifier explicitement le type d'une variable avec des [annotations de type][type annotations], soit laisser le compilateur [inférer le type][type-inferring].

```swift
var explicitVar: Int = 10 // Explicitly typed
var implicitVar = 10      // Implicitly typed
```

On met à jour la valeur d'une variable à l'aide de l'opérateur `=`.

~~~~exercism/note
Le type d'une variable est fixé une fois qu'elle est définie initialement.

```swift
variableName = 13 // update to new value

// compiler error when assigning a different type
variableName = "Hello, world!" // Cannot assign value of type 'String' to type 'Int'
```
~~~~

On peut déclarer des variables sans affecter de valeur en spécifiant le nom et le type, mais elles ne peuvent pas être utilisées avant qu'une valeur ne leur soit affectée.

```swift
var someInt: Int

// This would trigger a compiler error
// print(someInt) // Variable 'someInt' used before being initialized

// Assign a value to the names
someInt = 169

print(someInt) // Prints '169'
```

### Constantes

Les [constantes][constants-variables] sont semblables aux variables : elles sont associées à un nom et à une valeur, mais la valeur d'une constante ne peut pas être modifiée une fois qu'elle a été affectée initialement, ce qui la rend _immuable_.
Les constantes sont définies à l'aide du mot-clé `let`.

```swift
let constantName = 10          // constant
let explicitConstant: Int = 10 // Explicitly typed constant
```

### Addition, soustraction et multiplication

Swift dispose d'[opérateurs][arithmetical-operators] pour l'addition, la soustraction et la multiplication.
Les opérateurs sont respectivement `+`, `-` et `*`.

```swift
print(1 + 1) // Prints 2
print(2 - 1) // Prints 1
print(2 * 2) // Prints 4
```

### Fonctions

En Swift, les [fonctions][functions] sont un morceau de code qui effectue une tâche.
Une fonction a un type de retour et peut donc être utilisée comme une valeur et passée comme argument à d'autres fonctions.
En Swift, les fonctions sont définies à l'aide du mot-clé `func` suivi du nom de la fonction, d'arguments séparés par des virgules et d'un type de retour.

Les arguments sont définis par une étiquette d'argument, un nom de paramètre suivi de deux-points puis d'un type.
Le type de retour est défini par un `->` suivi du type de la valeur de retour.

```swift
func functionName(argumentName parameterName: ArgumentType) -> ReturnType {
  // function body
}
```

Les arguments en Swift sont un peu spéciaux par rapport à d'autres langages : ils utilisent des [étiquettes d'argument][argument-labels].
L'étiquette d'argument est utilisée lors de l'appel de la fonction.
Le nom de paramètre est utilisé à l'intérieur du corps de la fonction pour faire référence à la valeur de l'argument.
Si tu n'attribues qu'un seul nom à l'argument, il sera utilisé à la fois comme étiquette d'argument et comme nom de paramètre.
Lorsque tu attribues le nom d'étiquette d'argument `_`, l'argument n'aura pas d'étiquette lors de l'appel de la fonction, par exemple : `functionName(argumentValue)`

Pour appeler une fonction, on utilise le nom de la fonction suivi de l'étiquette d'argument et de la valeur de l'argument, comme ceci :

```swift
func functionName(argumentLabel parameterName: ArgumentType) -> ReturnType {
  // function body
}

// calling the function
functionName(argumentLabel: argumentValue)
```

Tous les arguments sont immuables par défaut et ne peuvent pas être modifiés à l'intérieur de la fonction.
Lorsqu'une fonction a un type de retour, assure-toi de renvoyer une valeur de ce type.
Cela se fait à l'aide du mot-clé `return` suivi de la valeur à renvoyer.

```swift
func addTen(number value: Int) -> Int {
  return value + 10
}

// calling the function
addTen(number: 10) // Returns 20
```

Lorsqu'une fonction ne renvoie pas de valeur, elle a un type de retour `Void`, qui est identique à `()`, mais le type de retour peut aussi être omis dans ces cas.

### Commentaires

Swift prend en charge deux types de [commentaires][comments].
Les commentaires sur une seule ligne sont précédés de `//` et les commentaires multilignes sont insérés entre `/*` et `*/`.
