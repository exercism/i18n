# Fonctions

Les fonctions sont fondamentales en Cairo.

Par convention, Cairo utilise le **`snake_case`** pour les noms de fonctions et de variables, où les mots sont en minuscules et séparés par des underscores.

Voici un exemple :

```rust
fn another_function() {
    println!("Another function.");
}

fn main() {
    println!("Hello, world!");
    another_function();
}
```

Les fonctions sont définies avec `fn`, suivi d'un nom, de parenthèses pour les paramètres (le cas échéant), et d'un corps entouré d'accolades.

On peut appeler une fonction par son nom, suivi de parenthèses.

L'ordre des fonctions n'a pas d'importance tant qu'elles sont dans la portée.

## Paramètres

Les fonctions peuvent prendre des **paramètres**, qui sont des variables définies dans la signature de la fonction.

Lors de l'appel de la fonction, on fournit des **arguments**, les valeurs passées à ces paramètres.

```rust
fn main() {
    another_function(5);
}

fn another_function(x: felt252) {
    println!("The value of x is: {}", x);
}
```

Ici, `x` est un paramètre de type `felt252`.

Lorsqu'on l'appelle avec `5`, la fonction affiche « The value of x is: 5 ».

Les paramètres multiples sont séparés par des virgules :

```rust
fn main() {
    print_labeled_measurement(5, "h");
}

fn print_labeled_measurement(value: u128, unit_label: ByteArray) {
    println!("The measurement is: {value}{unit_label}");
}
```

Cela affiche : `The measurement is: 5h`.

## Instructions et expressions

Les fonctions en Cairo sont composées d'**instructions** et d'**expressions** :

- **Les instructions** effectuent des actions mais ne renvoient pas de valeur.
Par exemple, `let x = 3;` est une instruction.
- **Les expressions** s'évaluent en une valeur.
Par exemple, `5 + 6` s'évalue en `11`.

Les blocs entre accolades sont aussi des expressions, et leur valeur finale est renvoyée :

```rust
fn main() {
    let y = {
        let x = 3;
        x + 1
    };
    println!("The value of y is: {}", y);
}
```

Ici, on affecte la valeur `4` à `y`.

## Valeurs de retour

Les fonctions peuvent renvoyer des valeurs en utilisant la syntaxe `->` pour spécifier le type de retour.

Par défaut, une fonction renvoie la valeur de son expression finale :

```rust
fn five() -> u32 {
    5
}

fn main() {
    let x = five();
    println!("The value of x is: {}", x);
}
```

Cela produit : `The value of x is: 5`.

Pour des cas plus complexes :

```rust
fn plus_one(x: u32) -> u32 {
    x + 1
}

fn main() {
    let x = plus_one(5);
    println!("The value of x is: {}", x);
}
```

Cela affiche : `The value of x is: 6`.

Fais attention à ne pas ajouter de point-virgule à la fin de l'expression finale, car cela transformerait l'expression en instruction, ce qui ferait que la fonction renverrait `()` (type unité) au lieu de la valeur attendue.
