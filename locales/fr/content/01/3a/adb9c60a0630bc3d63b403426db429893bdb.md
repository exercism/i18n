# À propos

On peut voir une interface comme la signature d'une classe, car elle décrit les champs publics de cette classe. Une classe _implémente_ une `interface` grâce au mot-clé `implments`.

Sa syntaxe est très proche de celle d'une classe, à ceci près que les méthodes y apparaissent sous forme de signatures, sans corps :

```haxe
interface Language {
  private var languageName:String;

  public function speak():String;
}

class FrenchSpeaker implements Language {
  var languageName = "French";

  public function speak():String {
    return "Bonjour!";
  }
}
```

Les champs issus d'une interface **doivent** toujours utiliser le même modificateur de visibilité. Par exemple, si la variable `a` est `public` dans une interface, son implémentation doit elle aussi être `public`.
