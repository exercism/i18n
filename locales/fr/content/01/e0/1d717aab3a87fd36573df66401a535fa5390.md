# Annexe aux instructions

## Format de sortie

Écris les paroles sous la forme d'une _string_ terminée par un caractère nul.

## Registres

| Registre | Utilisation  | Type    | Description                   |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | entrée       | entier  | couplet de début              |
| `$a1`    | entrée       | entier  | couplet de fin                |
| `$a2`    | entrée/sortie | adresse | _string_ de sortie terminée par un caractère nul |
| `$t0-9`  | temporaire   | quelconque | pour un stockage temporaire    |
