# Boucles _while_ et _until_

Une boucle est une structure de contrôle qui permet d'exécuter du code de manière répétée en fonction d'une condition donnée.

## Boucles _while_

Une boucle _while_ est une structure de contrôle qui permet d'exécuter du code de manière répétée en fonction d'une condition donnée.
Le code contenu dans une boucle _while_ continue de s'exécuter tant que la condition s'évalue comme vraie.
On utilise souvent les boucles _while_ quand on ne connaît pas à l'avance le nombre d'itérations ; elles peuvent servir dans n'importe quelle situation où une boucle est nécessaire.

La condition est évaluée avant que le code de la boucle ne soit exécuté, ce qui signifie que si la condition est fausse, le code de la boucle ne sera jamais exécuté.

```crystal
i = 0
while i < 3
  puts i
  i += 1
end

# Output:
# 0
# 1
# 2
```

Pour parcourir une _string_, on peut itérer sur sa longueur.

```crystal
str = "Hello"
i = 0
while i < str.size
  puts str[i]
  i += 1
end

# Output:
# H
# e
# l
# l
# o
```

## Boucles _until_

Les boucles _until_ fonctionnent comme les boucles _while_, à ceci près que le code de la boucle continue de s'exécuter jusqu'à ce que la condition s'évalue comme vraie.
C'est la même différence qu'entre `if` et `unless`.

```crystal
i = 0
until i == 3
  puts i
  i += 1
end
```

### Boucles infinies

Une erreur fréquente avec les boucles _while_ est d'entrer dans une « boucle infinie », qui ne se termine jamais.
Une boucle infinie peut être causée par une condition qui ne s'évalue _jamais_ comme vraie ou comme fausse.
C'est souvent une erreur de programmation ; par exemple, oublier d'incrémenter la variable de la boucle.
Mais parfois, une boucle infinie est la façon la plus claire d'implémenter la logique du programme.
Ou alors, il est indispensable de boucler sans fin ; par exemple, un serveur HTTP attend une connexion entrante, la traite, puis attend la connexion suivante.

## L'instruction _break_

On peut utiliser le mot-clé `break` pour sortir d'une boucle plus tôt.
C'est pratique quand on veut sortir d'une boucle plus tôt dans certaines conditions.

```crystal
i = 0
while i <= 3
  puts i
  i += 1
  if i == 2
    break
  end
end

# Output:
# 0
# 1
```

## L'instruction _next_

On peut utiliser le mot-clé `next` pour passer à l'itération suivante d'une boucle.
C'est pratique quand on veut sauter certaines itérations d'une boucle.

```crystal
i = 0
while i <= 3
  i += 1
  if i == 2
    next
  end
  puts i
end

# Output:
# 1
# 3
```

## Les types dans les boucles

Le type de la variable peut changer dans une boucle.
Dans l'exemple suivant, le type de `a` est `Int32 | String`, car il peut être `Int32` ou `String` dans la première partie de la boucle.
La variable `a` ne porte le type `Int32 | String` que dans la première partie de la boucle, puisque au démarrage de la boucle elle contient un `Int32` et qu'à la deuxième itération elle contient un `String`.
Ce système de types multiples sera expliqué en détail plus tard.
Mais comme nous sommes certains que la deuxième partie de la boucle ne contiendra qu'un `String`, le type de `a' is `String` under the second part of the loop.
At runtime, it will never simultaneously hold `Int32` and `String` en même temps.

```crystal
i = 0
a = 4
while i < 3
  p typeof(a)
  # => Int32 | String
  a = "4"
  p typeof(a)
  # => String
  i += 1
end
```
