# Introduction

Les conditionnelles sont des instructions qui exécutent un code différent selon qu'une condition est `true` ou `false`.

Une instruction `if` n'exécute son corps que lorsque sa condition est `true`.
Go ne connaît pas la notion de valeurs _truthy_ ou _falsy_, donc la condition doit être de type `bool`.
Des expressions comme `if mySlice { ... }` ou `if 1 { ... }` provoquent des erreurs de compilation.

```go
func describe(val string) string {
    if val == "val" {
        return "was val"
    }
    return "was not val"
}
```

Utilise `else if` pour vérifier d'autres conditions, et `else` comme solution de repli si aucune ne correspond.
Les conditions sont évaluées de haut en bas, et seule la première branche dont la condition est vraie sera exécutée.

```go
number := 0
result := "This number is "

if number > 0 {
    result += "positive"
} else if number < 0 {
    result += "negative"
} else {
    result += "zero"
}
```

Une instruction `if` peut aussi comporter une courte instruction d'initialisation.
Les variables déclarées de cette façon n'ont de portée que dans l'ensemble de la chaîne `if`/`else`.

```go
num := 7
if v := 2 * num; v > 10 {
    fmt.Println(v)
} else {
    fmt.Println(num)
}
// Output: 14
```
