# Utilise la récursion terminale

Le but de cet exercice est d'enseigner la récursion terminale. Résous-le sans utiliser de fonctions récursives qui ne sont pas terminales.

Fonctions récursives terminales trouvées dans ta solution : %{tail_call_recursive_functions}. Autres fonctions récursives trouvées dans ta solution : %{non_tail_call_recursive_functions}.

Rappelle-toi : la récursion terminale se produit quand la _dernière_ expression évaluée par la fonction est un appel à elle-même.

```elixir
# this is tail call recursion,
# the last expression is a call to `do_encode`
defp do_encode([n | rest], acc) do
  do_encode(rest, <<acc::bitstring, encode_nucleotide(n)::4>>)
end

# this is not tail call recursion,
# the last expression is a call to `<<>>`
def encode([head | tail]) do
  <<encode_nucleotide(head)::4, encode(tail)::bitstring>>
end
```
