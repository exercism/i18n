# Debug

Tu peux utiliser [Debug.log](https://package.elm-lang.org/packages/elm/core/latest/Debug#log) pour associer des messages à des tests qui échouent, comme ceci :

```elm
hoursToSeconds : Int -> Int
hoursToSeconds hours =
    let
        secondsInOneHour =
            Debug.log "secondsInOneHour" (60 * 60)
    in
    hours * secondsInOneHour
```

Quand un test échoue, le _log_ associé sera `secondsInOneHour: 3600`.

Il y a toutefois une mise en garde : les constantes de premier niveau ne sont évaluées qu'une seule fois, avant que les tests ne commencent à s'exécuter, ce qui fait que les tests ne peuvent pas capturer leurs messages de _log_. Par exemple :

```elm
secondsInOneHour : Int
secondsInOneHour =
    Debug.log "secondsInOneHour" (60 * 60)
```

ne produira aucun _log_ pendant les tests, car la variable JavaScript associée à `secondsInOneHour` a déjà été évaluée à la valeur 3600.
