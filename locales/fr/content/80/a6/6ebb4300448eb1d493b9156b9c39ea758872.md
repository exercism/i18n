# Indices

## Généralités

- Dans le squelette, `FamilyTree.(family_tree)` déballe le type nominal et te donne le `Dict(Str, List(Str))` sous-jacent.

- `Dict.to_list` expose ses entrées sous forme de tuples `(parent, children)`.

- Un `Set(Str)` peut t'aider à ne pas revenir sur une personne déjà vue pendant que tu explores les relations.
