# Introduction

`Rational numbers` sont des fractions avec un numérateur entier divisé par un dénominateur entier.

Par exemple, on peut stocker `2//3` comme une fraction exacte au lieu de la valeur approximative `Float64` `0.6666...`

L'avantage est que (sauf dans le cas extrême du *débordement d'entier*) un nombre rationnel restera exact, ce qui évite les erreurs d'arrondi souvent inévitables avec les nombres à virgule flottante.

Les nombres rationnels sont un type numérique assez simple et se comportent globalement comme on peut s'y attendre.
Comme ils font partie des types standard de Julia depuis les premières versions, la plupart des fonctions les acceptent en entrée de la même manière que les entiers et les nombres à virgule flottante.

## Crée des nombres rationnels

La création est aussi simple que d'utiliser `//` entre deux entiers.

```julia-repl
julia> 3//4
3//4

julia> a = 3; b = 4;

julia> a//b
3//4
```

Les facteurs communs sont automatiquement supprimés, ce qui réduit la fraction à sa « forme irréductible » : les plus petits entiers qui représentent exactement la fraction, avec un dénominateur positif ou nul.

```julia-repl
julia> 5//15
1//3

julia> 5//-15
-1//3
```

## Arithmétique avec les nombres rationnels

Les `arithmetic operators` habituels `+ - * / ^ %` fonctionnent avec les rationnels, essentiellement de la même manière qu'avec les autres types numériques.

On peut inclure des entiers et d'autres `Rational` et obtenir un résultat de type `Rational`.
Inclure un `float` dans l'expression produit une sortie de type `float`, avec une perte de précision (possible) en conséquence.

Si l'on souhaite un `float`, il suffit d'utiliser la fonction `float()` pour convertir un rationnel.
Il est tout à fait normal d'utiliser des nombres rationnels pour préserver la précision pendant un long calcul, puis de convertir en nombre à virgule flottante à la fin.

```julia-repl
julia> 3//4 + 1//3  # addition
13//12

julia> 3//4 * 1//3  # multiplication
1//4

julia> 3//4 / 1//3  # division
9//4

julia> 3//4 ^ 2  # exponentiation
3//16

julia> 3//4 + 5  # rational and int => rational
23//4

julia> 3//4 + 5.3  # rational and float => float
6.05

julia> float(3//4)  # casting
0.75
```

## Autres opérations

En Julia, les nombres rationnels sont des nombres comme les autres.
Le compilateur convertit en général les types si nécessaire.

Cependant, attention : les comparaisons ne fonctionnent que pour les fractions ayant une représentation décimale finie :

```julia-repl
julia> 3//4 == 0.75
true

julia> 3//4 < 0.74
false
```

Mais, sinon, il faut convertir un `Rational` en `Float` pour les comparaisons :

```julia-repl
julia> 1//3 == 1/3
false

julia> float(1//3) == 1/3
true
```

Les fonctions mathématiques prennent des rationnels en entrée, mais peuvent donner un résultat à virgule flottante :

```julia-repl
julia> sqrt(9//16)
0.75
```
