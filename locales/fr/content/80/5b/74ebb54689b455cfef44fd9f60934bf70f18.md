# Caractères

`CHAR` est un caractère, que l'on écrit entre guillemets simples.

```sather
   c : CHAR := 'M';
```

## Caractères spéciaux

Certains caractères ne peuvent pas être saisis directement et s'écrivent avec une barre oblique inversée :

| Écrit | Est |
| --- | --- |
| `'\n'` | un saut de ligne |
| `'\t'` | une tabulation |
| `'\''` | un guillemet simple |
| `'\\'` | une barre oblique inversée |

## Questions

```sather
'M'.is_alpha      -- true
'7'.is_digit      -- true
'M'.is_upper      -- true
' '.is_space      -- true
'M'.is_alphanum   -- true, a letter or a digit
```

## Casse

`.upper` et `.lower` changent la casse d'une lettre et ne touchent à rien d'autre, ce qui signifie qu'on peut les appliquer sans risque à un caractère que l'on n'a pas vérifié.

## Nombres

```sather
'a'.int           -- 97
97.char           -- 'a'
```

`.int` et `.char` sont exactement opposés. Ce qu'il est utile de retenir de cette numérotation, c'est que les caractères de `'a'` à `'z'` se suivent, que ceux de `'A'` à `'Z'` se suivent aussi, et qu'il en va de même de `'0'` à `'9'`, donc :

```sather
   c.int - 'a'.int          -- how far c is along the alphabet
   ('a'.int + n).char       -- the letter n places along
   d.int - '0'.int          -- the value of a digit character
```

## Reviens au début

Une roue de chiffrement dépasse `z` et revient à `a`. L'opérateur `%` fait exactement cela :

```sather
   ('a'.int + (c.int - 'a'.int + places) % 26).char
```

En Sather, `%` ne renvoie jamais un résultat négatif quand l'opérande de droite est positif, ce qui permet de faire tourner la roue dans les deux sens, en arrière comme en avant.

## Caractères et _strings_

Un `STR` est une suite d'octets, et un `CHAR` est un seul octet. Pour du texte anglais, un octet correspond à une lettre, donc `"Marlowe".size` vaut 7 et `"Marlowe"[0]` vaut `'M'`. Pour du texte comportant des accents ou un autre alphabet, une lettre peut occuper plusieurs octets, et aucune de ces deux affirmations ne tient plus.
