# Tests

Pour exécuter les tests, commence par installer le paquet `z3-solver` :

```
pip install z3-solver
```

Tu peux ensuite exécuter les tests en lançant la commande suivante depuis le répertoire de l'exercice :

```
python <snake_case_exercise>_test.py
```

où `<snake_case_exercise>` est remplacé par le nom de l'exercice.
