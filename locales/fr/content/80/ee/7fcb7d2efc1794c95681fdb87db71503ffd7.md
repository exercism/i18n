# Indices pour l'exercice Champ de fleurs en Bash

Cet exercice semble nécessiter un tableau à deux dimensions.
Bash ne propose que des [tableaux][array] indexés ou associatifs à une dimension.

On peut simuler des tableaux multidimensionnels à l'aide de tableaux associatifs : il suffit d'encoder les indices dans une _string_ séparée par des virgules, que l'on utilise ensuite comme clé du tableau.

```bash
# store this matrix:
#   a b
#   c d
declare -A array2d
array2d["0,0"]="a"
array2d["0,1"]="b"
array2d["1,0"]="c"
array2d["1,1"]="d"
```

[array]: https://www.gnu.org/software/bash/manual/bash.html#Arrays
