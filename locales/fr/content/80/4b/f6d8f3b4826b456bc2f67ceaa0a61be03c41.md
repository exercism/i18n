# Astuces

## 1. Remplace tous les espaces par des tirets bas

- Ce [tutoriel][chars-tutorial] est utile.
- Tu peux récupérer des `char` dans une _string_ avec la méthode [charAt][char-at].
- Tu devrais utiliser un [`StringBuilder`][string-builder] pour construire la _string_ de sortie.
- Consulte la documentation de [Character][chars-docs] pour trouver une méthode qui détecte les espaces blancs. Rappelle-toi que c'est une méthode statique.
- Les littéraux `char` s'écrivent entre guillemets simples.

## 2. Convertis le `kebab-case` en `camelCase`

- Consulte la documentation de [Character][chars-docs] pour trouver une méthode qui convertit un caractère en majuscule. Rappelle-toi que c'est une méthode statique.

## 3. Convertis le _leetspeak_ en texte normal

- Consulte la documentation de [Character][chars-docs] pour trouver une méthode qui détecte si un caractère est un chiffre. Rappelle-toi que c'est une méthode statique.

## 4. Ignore les caractères qui ne sont pas des lettres

- Consulte la documentation de [Character][chars-docs] pour trouver une méthode qui détecte si un caractère est une lettre. Rappelle-toi que c'est une méthode statique.
