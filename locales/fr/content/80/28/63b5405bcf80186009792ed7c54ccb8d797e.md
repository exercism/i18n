# Instructions

Ta tâche consiste à modifier le format des données des lettres et de leurs valeurs en points dans le jeu.

Pour l'instant, les lettres sont stockées en groupes selon leur score, dans une correspondance un-à-plusieurs.

- 1 point : « A », « E », « I », « O », « U », « L », « N », « R », « S », « T »,
- 2 points : « D », « G »,
- 3 points : « B », « C », « M », « P »,
- 4 points : « F », « H », « V », « W », « Y »,
- 5 points : « K »,
- 8 points : « J », « X »,
- 10 points : « Q », « Z »,

Il faut maintenant stocker chaque lettre individuellement avec son score, dans une correspondance un-à-un.

- « a » vaut 1 point.
- « b » vaut 3 points.
- « c » vaut 3 points.
- « d » vaut 2 points.
- etc.

Dans le cadre de ce changement, l'équipe a aussi décidé de passer les lettres en minuscules plutôt qu'en majuscules.
