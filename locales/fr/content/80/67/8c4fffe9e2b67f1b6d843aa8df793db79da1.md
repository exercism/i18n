# Introduction

## Les booléens en R

Les valeurs vraies ou fausses sont représentées par le type `logical`.
Il ne contient que deux valeurs : `TRUE` et `FALSE`.

```R
TRUE
#> [1] TRUE
FALSE
#> [1] FALSE
typeof(TRUE)
#> [1] "logical"
```

## Les opérateurs booléens

Il existe cinq opérateurs booléens en R, mais seuls trois sont pertinents à ce stade du programme.
Les deux autres seront importants lorsqu'on travaillera avec des vecteurs, ce qui est abordé dans plusieurs concepts ultérieurs.

`&&` est le « et » booléen.
Il vaut `TRUE` si les expressions des *deux* côtés de `&&` sont `TRUE`.

```R
TRUE && TRUE
#> [1] TRUE
TRUE && FALSE
#> [1] FALSE
```

`||` est le « ou » booléen.
Il vaut `TRUE` si une expression de *l'un ou l'autre* côté de `||` est `TRUE`.

```R
TRUE || TRUE
#> [1] TRUE
FALSE || TRUE
#> [1] TRUE
```

`!` est le « non » booléen.
Il échange les valeurs `TRUE` et `FALSE`.

```R
!TRUE
#> [1] FALSE
!FALSE
#> [1] TRUE
```

Pour les expressions plus longues et plus compliquées, il vaut mieux utiliser des parenthèses pour rendre ton intention explicite.

```R
(TRUE || FALSE) && (FALSE && TRUE)
#> [1] FALSE
```
