## Notes d'implémentation

La définition de l'interface Cipher se trouve dans `cipher.go`.

Tes implémentations doivent être conformes à l'interface Cipher.

```go
type Cipher interface {
    Encode(string) string
    Decode(string) string
}
```

On s'attend à ce que `Encode` ignore tous les caractères de la _string_ qui ne sont pas A-Za-z ; ils ne seront pas représentés dans la sortie.
La sortie sera également normalisée en minuscules.

Les fonctions utilisées pour obtenir les chiffrements sont :

```go
func NewCaesar() Cipher { }

func NewShift(distance int) Cipher { }

func NewVigenere(key string) Cipher { }
```

L'argument de `NewShift` doit être compris entre 1 et 25 ou entre -1 et -25.
Zéro n'est pas autorisé.
Pour des arguments invalides, `NewShift` renvoie nil.

L'argument de `NewVigenere` ne doit contenir que des lettres minuscules, de a à z.
Les valeurs composées uniquement de la lettre « a » ne sont pas autorisées.
Pour des arguments invalides, `NewVigenere` renvoie `nil`.
