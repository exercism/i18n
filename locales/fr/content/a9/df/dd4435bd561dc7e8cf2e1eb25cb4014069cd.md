# Introduction

En Gleam, les dictionnaires sont la structure de données qui permet de stocker des informations sous forme de paires clé-valeur. Dans d'autres langages, on les connaît aussi sous le nom de tableaux associatifs, de tables de hachage ou de dictionnaires.

N'importe quel type peut servir pour les clés et les valeurs d'un dictionnaire, et celui-ci ne garantit pas l'ordre de ses entrées lorsqu'on y accède ou qu'on les renvoie.

## Travaille avec les dictionnaires

Les dictionnaires se créent et se manipulent à l'aide des fonctions du module `gleam/dict`.

```gleam
// Create an empty dict
let dict1 = dict.new()

// Create a dict with some values
let dict2 = dict.from_list([
  #("name", "Gleam"),
  #("colour", "Pink"),
])

// Add a value to a dict
let dict3 = dict.insert(dict2, "website", "https://gleam.run")

// Get a value from a dict
let name = dict.get(dict3, "name")
// -> Ok("Gleam")
```
