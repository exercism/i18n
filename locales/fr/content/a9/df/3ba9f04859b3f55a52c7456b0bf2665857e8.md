# Instructions

Alors que tu poursuis ton travail chez _Instruments of Texas_, des progrès sont en cours sur l'implémentation en Elixir de la calculatrice RPN. Ton équipe aimerait pouvoir lever des erreurs plus spécifiques que les erreurs génériques fournies par la bibliothèque standard. Tu fais quelques recherches, mais tu as décidé de créer deux nouvelles erreurs qui implémentent le comportement `Exception`.

## 1. Erreur de division par zéro

Diviser un nombre par zéro produit un résultat indéfini, que l'équipe décide de représenter au mieux par une erreur.

Implémente le module `DivisionByZeroError` avec le message d'erreur : `"division by zero occurred"`

```elixir
raise DivisionByZeroError
# => ** (DivisionByZeroError) division by zero occurred
```

## 2. Erreur en cas de _stack underflow_

Les calculatrices RPN utilisent une _stack_ pour garder la trace des nombres avant de les additionner. L'équipe représente cette _stack_ par une liste de nombres (entiers et à virgule flottante), par exemple : `[3, 4.0]`. Chaque opération prend un nombre précis de valeurs sur la pile pour effectuer son calcul. Quand il n'y a pas assez de nombres sur la pile, on parle d'une erreur de _stack underflow_. Implémente l'exception `StackUnderflowError`, qui fournit un message par défaut ainsi qu'un contexte supplémentaire facultatif

```elixir
raise StackUnderflowError
# => ** (StackUnderflowError) stack underflow occurred

raise StackUnderflowError, "when dividing"
# => ** (StackUnderflowError) stack underflow occurred, context: when dividing
```

## 3. Écris une fonction de division

Implémente la fonction `divide/1` qui prend une pile _(une liste de deux nombres)_ et :

- lève une erreur de _stack underflow_ quand la pile ne contient pas assez de nombres
- lève une erreur de division par zéro quand le diviseur vaut 0 (attention, la pile de nombres est stockée dans l'ordre inverse)
- effectue la division quand aucune erreur n'est levée

```elixir
RPNCalculator.Exception.divide([])
# => ** (StackUnderflowError) stack underflow occurred, context: when dividing

RPNCalculator.Exception.divide([0, 100])
# => ** (DivisionByZeroError) division by zero occurred

RPNCalculator.Exception.divide([4, 16])
# => 4
```

> Attention, l'ordre de la liste est inversé !
