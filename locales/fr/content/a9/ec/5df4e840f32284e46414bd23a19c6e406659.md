# Supprime les commentaires TODO

On dirait que tu as laissé quelques commentaires `// TODO: ...` dans ton code, qui faisaient partie du squelette de la solution.

Ton code réussit les tests, ce qui signifie que ces commentaires ne sont plus d'actualité : tu as déjà implémenté tout le nécessaire.

Veille à toujours supprimer les commentaires obsolètes de ton code.
