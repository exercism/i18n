# Indices

## Généralités

- Les [structures et les classes][structs-and-classes] partagent une syntaxe de définition similaire.

## 1. Définis une structure Size

- Les propriétés doivent être définies avec `var`s si elles peuvent être modifiées.
- Les propriétés height et width doivent prendre les valeurs par défaut de 80 et 60, respectivement.
- Les méthodes d'une structure doivent être marquées `mutating` si elles modifient les propriétés de la structure.

## 2. Définis une structure Position

- Les propriétés doivent être définies avec `var`s si elles peuvent être modifiées.
- Les propriétés x et y doivent prendre la valeur par défaut de 0.
- Les méthodes d'une structure doivent être marquées `mutating` si elles modifient les propriétés de la structure.

## 3. Définis une classe Window

- Les structures peuvent être initialisées avec différentes valeurs de propriétés grâce aux [initialiseurs par membre][memberwise-initializers].
- Les propriétés constantes doivent être définies avec `let`.
- La propriété `contents` doit être optionnelle, car elle peut ne pas avoir de valeur.
- Tu dois définir un initialiseur vide pour la classe (`init() {}`).

## 4. Ajoute une méthode pour redimensionner les fenêtres

- La méthode doit prendre un paramètre `to` de type `Size`.
- Il est possible d'extraire la largeur et la hauteur du paramètre `to` en utilisant la notation pointée.

## 5. Ajoute une méthode pour déplacer les fenêtres

- La méthode doit prendre un paramètre `to` de type `Position`.
- Il est possible d'extraire x et y du paramètre `to` en utilisant la notation pointée.

## 6. Ajoute une méthode pour définir le contenu d'une fenêtre

- En Swift, il est possible d'avoir deux méthodes portant le même nom mais avec des paramètres différents.
- Définis une méthode avec le paramètre `title` qui définit la propriété `title`.
- Définis une méthode avec le paramètre `text` qui définit la propriété `contents`.
- Définis une méthode d'affichage qui affiche le titre et le contenu de la fenêtre.

## 7. Crée un initialiseur pour la classe Window

- La classe doit avoir deux initialiseurs, un qui ne prend aucun paramètre et un qui prend des paramètres.
- Le nouvel initialiseur doit avoir les paramètres `title` et `contents`, et doit aussi accepter les paramètres optionnels `size` et `position`
    Si aucun paramètre n'est fourni, les valeurs par défaut doivent être utilisées.
- Les paramètres optionnels peuvent être obtenus en utilisant des [valeurs de paramètres par défaut][default-parameters-vales].
