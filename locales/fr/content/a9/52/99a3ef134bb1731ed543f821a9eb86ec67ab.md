# Introduction

L'opérateur `|>` s'appelle l'opérateur pipe. Il permet d'enchaîner des appels de fonctions de sorte que la valeur renvoyée par l'appel précédent soit transmise à l'appel suivant.

```gleam
"hello"
|> string.uppercase
|> string.append("?!")
// -> "HELLO?!"
```

Le code ci-dessus est équivalent au suivant :

```gleam
string.append(string.uppercase("hello"), "?!")
```

L'opérateur pipe transmet la valeur soit comme premier argument de l'appel de fonction, soit comme unique argument d'un nouvel appel, en choisissant celle des deux positions qui donne le type correct.

```gleam
100
|> function_that_takes_two_arguments(1)

// Is equivalent to
function_that_takes_two_arguments(100, 1)
```

```gleam
100
|> function_that_returns_a_function(1)

// Is equivalent to
function_that_returns_a_function(1)(100)
```

Il arrive qu'on veuille placer la valeur à une autre position ; dans ce cas, on peut utiliser le _placeholder_ `_` pour indiquer où la valeur doit être insérée.

```gleam
100
|> some_function(1, _, 2)
```
