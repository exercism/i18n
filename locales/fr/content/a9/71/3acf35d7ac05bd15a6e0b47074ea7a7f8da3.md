# Introduction

En Factor, une _string_ est une séquence de caractères. La plupart des mots du vocabulaire [`sequences`][sequences] fonctionnent sur les _strings_, en plus des mots dédiés à la manipulation des chaînes dans [`splitting`][splitting], [`ascii`][ascii] et compagnie.

## Littéraux de chaîne

Les _strings_ s'écrivent entre guillemets doubles. Les séquences d'échappement habituelles sont prises en charge : `\n`, `\t`, `\r`, `\\`, `\"` :

```factor
"hello, world" .                 ! => "hello, world"
"first\nsecond" print            ! prints two lines
```

## Longueur et indexation

Comme une _string_ est une séquence, les mots `length` et `nth` de [`sequences`][sequences] fonctionnent directement dessus.

`length` renvoie le nombre de caractères :

```factor
"hello" length .    ! => 5
```

`nth` prend un indice commençant à 0 et la séquence, et renvoie l'élément situé à cette position. Pour une _string_, l'élément est un *caractère*, à savoir un point de code (un entier), et non une sous-chaîne d'un seul caractère :

```factor
0 "hello" nth .     ! => 104   (CHAR: h)
4 "hello" nth .     ! => 111   (CHAR: o)
```

## D'un caractère vers une _string_

Pour transformer un seul point de code en une _string_ d'un seul caractère, utilise `1string ( char -- str )` du vocabulaire [`strings`][strings]. `CHAR:` est la forme prise par un point de code littéral au moment de l'analyse :

```factor
CHAR: A 1string .                ! => "A"
0 "hello" nth 1string .          ! => "h"
```

## Découpe

Le vocabulaire [`splitting`][splitting] découpe une _string_ en morceaux.

`split1` découpe au niveau de la *première* occurrence d'un séparateur et renvoie les deux moitiés :

```
split1 ( seq subseq -- before after )
```

```factor
"foo: bar" ": " split1 .s
! => "foo"
! => "bar"
```

`split` découpe au niveau de *n'importe lequel* des caractères d'un ensemble de séparateurs, ce qui peut produire des morceaux vides :

```factor
"[ERROR]: Stack overflow" "[]" split .
! => { "" "ERROR" ": Stack overflow" }
```

`harvest` (dans [`sequences`][sequences]) supprime les morceaux vides :

```factor
"[ERROR]: Stack overflow" "[]" split harvest .
! => { "ERROR" ": Stack overflow" }
```

## Extrais un morceau

Une fois qu'une _string_ est découpée en un tableau de morceaux, `first`, `second`, `third` et `fourth` (dans [`sequences`][sequences]) renvoient le morceau situé à cette position :

```factor
"apple,bee,carrot,duck" "," split first .    ! => "apple"
"apple,bee,carrot,duck" "," split second .   ! => "bee"
"apple,bee,carrot,duck" "," split third .    ! => "carrot"
"apple,bee,carrot,duck" "," split fourth .   ! => "duck"
```

Quand tu veux tous les premiers morceaux sur la pile d'un coup, `first2` et `first3` en extraient deux ou trois en une seule étape :

```factor
"apple,bee,carrot,duck" "," split first2 .s
! => "apple"
! => "bee"

"apple,bee,carrot,duck" "," split first3 .s
! => "apple"
! => "bee"
! => "carrot"
```

Sur une _string_ elle-même, `first` renvoie le premier **caractère**, un point de code, et non une sous-chaîne :

```factor
"hello" first .                         ! => 104   (CHAR: h)
```

## Supprime les espaces

`[ blank? ] trim` (de [`sequences`][sequences], avec `blank?` du vocabulaire [`ascii`][ascii]) supprime les espaces au début et à la fin :

```factor
"  Disk full \r\n" [ blank? ] trim .
! => "Disk full"
```

## Conversion de casse

`>lower` et `>upper` (de [`ascii`][ascii]) renvoient une nouvelle _string_ avec la casse modifiée :

```factor
"WARNING" >lower .    ! => "warning"
"hello" >upper .      ! => "HELLO"
```

## Assemble

Deux mots de [`sequences`][sequences] assemblent des _strings_ :

`surround` entoure une _string_ d'un préfixe et d'un suffixe :

```
surround ( seq pre post -- new-seq )
```

```factor
"warning" "(" ")" surround .    ! => "(warning)"
```

`glue` assemble deux _strings_ avec un séparateur entre elles :

```
glue ( s1 s2 sep -- s )
```

```factor
"Disk full" "(error)" " " glue .    ! => "Disk full (error)"
```
