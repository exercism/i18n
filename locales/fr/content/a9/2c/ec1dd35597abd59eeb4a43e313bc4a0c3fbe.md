# Installation

Le [Godot Engine][godot-engine] sert à exécuter du code GDScript.
Le Godot Engine fonctionne sous Windows, Linux, macOS et Android.



## Installe Godot Engine

Le Godot Engine peut être téléchargé directement depuis [le site web de Godot Engine][godot-engine].
Le téléchargement contient un seul exécutable, nommé d'après la version du Godot Engine.
Ce fichier doit être renommé `godot` et placé dans l'un des dossiers de `$PATH`.
Une fois l'installation terminée, tu peux vérifier que la CLI a bien été installée en exécutant cette commande dans un terminal :

```bash
godot --version
```

Ce parcours utilise Godot en version 4.7.2.
