# À propos

[Structures][structs-and-classes] (souvent appelées _structs_) sont l'une des principales briques de base des programmes Swift.
Les structures permettent de créer des types personnalisés qui rassemblent des propriétés (les données) et des méthodes (le comportement) associées.
En fait, les types standard de Swift, notamment `Int`, `Double`, `Bool`, `String`, `Array` et `Dictionary`, sont tous implémentés sous forme de structures.

## Définis des structures

On définit une structure à l'aide du mot-clé `struct`, suivi du nom du type, puis d'accolades contenant sa définition.
Par convention Swift, les noms de structures s'écrivent en `UpperCamelCase` :

```swift
struct CharacterStats {
    var health = 0.0
    var speed = 0
    var strength = 0
}
```

## Crée des instances

La définition d'une structure est un plan.
Pour créer une _instance_ d'une structure, on appelle son initialiseur en écrivant le nom du type suivi de parenthèses :

```swift
var someStats = CharacterStats()
```

Cela crée une instance remplie avec les valeurs par défaut des propriétés fournies dans la définition.

Swift génère aussi automatiquement un **initialiseur membre à membre** pour les structures, qui permet d'initialiser les propriétés par leur nom :

```swift
let customStats = CharacterStats(health: 100.0, speed: 6, strength: 18)
```

## Accède aux propriétés et modifie-les

On accède aux propriétés d'une instance et on les modifie à l'aide de la _notation pointée_ :

```swift
var stats = CharacterStats()

print(stats.health) // Prints 0.0

stats.health = 87.3
print(stats.health) // Prints 87.3
```

Comme les structures sont des types valeur, modifier les propriétés d'une instance exige que l'instance elle-même soit déclarée avec `var`.
Si l'instance est déclarée avec `let`, toutes ses propriétés deviennent immuables.
