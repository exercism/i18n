# À propos

Le type `Option` sert à représenter des valeurs qui peuvent être absentes ou présentes.

Il est défini dans le module `gleam/option` comme suit :

```gleam
type Option(a) {
  Some(a)
  None
}
```

Le constructeur `Some` sert à envelopper une valeur lorsqu'elle est présente, et le constructeur `None` sert à représenter l'absence de valeur.

Accéder au contenu d'un `Option` se fait souvent à l'aide du filtrage par motif.

```gleam
import gleam/option.{type Option, None, Some}

pub fn say_hello(person: Option(String)) -> String {
  case person {
    Some(name) -> "Hello, " <> name <> "!"
    None -> "Hello, Friend!"
  }
}
```

```gleam
say_hello(Some("Matthieu"))
// -> "Hello, Matthieu!"

say_hello(None)
// -> "Hello, Friend!"
```

Le module `gleam/option` définit aussi plusieurs fonctions utiles pour manipuler les types `Option`, comme `unwrap`, qui renvoie le contenu d'un `Option` ou une valeur par défaut s'il vaut `None`.

```gleam
import gleam/option.{type Option}

pub fn say_hello_again(person: Option(String)) -> String {
  let name = option.unwrap(person, "Friend")
  "Hello, " <> name <> "!"
}
```
