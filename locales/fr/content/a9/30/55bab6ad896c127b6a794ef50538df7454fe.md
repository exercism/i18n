# À propos

En Haxe, les itérateurs servent à parcourir une valeur à l'aide d'une boucle `for`. Il existe deux types d'itérateurs :

- `Iterator`, qui parcourt une valeur.
- Les données `Iterable`, qui permettent de parcourir un type de données.

Ces deux concepts sont représentés par `Iterator<T>` et `Iterable<T>` :

```haxe
typedef Iterator<T> = {
  function hasNext():Bool;
  function next():T;
}

typedef Iterable<T> = {
  function iterator():Iterator<T>;
}
```

Toute classe qui s'unifie avec l'un de ces types peut être parcourue à l'aide d'une boucle `for`. Si une classe définit les méthodes `hasNext` et `next`, elle est considérée comme un itérateur ; sinon, si elle définit une méthode `iterator`, elle est considérée comme un type itérable :

```haxe
class MyStringIterator {
  var str:String;
  var i:Int;

  public function new(str:String) {
    this.str = str;
    i = 0;
  }

  public function hasNext():Bool {
    return i < str.length;
  }

  public function next():String {
    return str.charAt(i++);
  }
}
```

Dans l'exemple ci-dessus, la classe `MyStringIterator` est considérée comme un itérateur puisqu'elle implémente à la fois les méthodes `hasNext` et `next`, ce qui la rend compatible avec `Iterator<String>`.

```haxe
class MyArrayWrap<T> {
  var arr:Array<T>;

  public function new(a:Array<T>) {
    this.a = a;
  }

  public function iterator() {
    return a.iterator();
  }
}
```

Ici, la classe `MyArrayWrap` est considérée comme un type de données itérable puisqu'elle est compatible avec `Iterable<Array<T>>`.
