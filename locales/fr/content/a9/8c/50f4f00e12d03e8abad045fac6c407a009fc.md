# À propos

Une boucle permet de répéter un ensemble d'une ou plusieurs instructions.
Chaque exécution de cet ensemble d'instructions s'appelle une itération.

## La boucle `while`

Une boucle `while` exécute un ensemble d'instructions tant qu'une expression booléenne placée en haut de la boucle est vraie.
Quand l'expression booléenne devient fausse, la boucle s'arrête et l'exécution se poursuit à la ligne de code suivante, après la boucle.

Si l'expression booléenne est fausse dès le départ, la boucle `while` ne s'exécute pas du tout et l'exécution passe directement à la ligne de code suivante, après la boucle.

```c
int main() {
    int i = 0;
    while (i < 5) {
        printf("Number is %i\n", i++);
    }    
    return 0;
}
```

Il est important qu'une condition permette de mettre fin à la boucle ; sinon, il s'agit d'une boucle infinie qui bloque toute progression du code.
Si l'on retirait le `++` de `i` dans le code ci-dessus, ce serait une boucle infinie.

## La boucle `do`

Dans une boucle `do`, l'expression booléenne est évaluée en bas de la boucle.
Une boucle `do` s'exécute toujours au moins une fois, comme dans l'exemple suivant :

```c
do {
    printf("Enter the Answer to the Ultimate Question of Life: ");
    scanf("%d", &answer);
} while (answer != 42); 
// Note that a semicolon is needed after the Boolean expression.
```

Avec une boucle `while`, ce serait plus verbeux :

```c
printf(""Enter the Answer to the Ultimate Question of Life: ");
scanf("%d", &answer);
while (answer != 42) {
    printf(""Enter the Answer to the Ultimate Question of Life: ");
    scanf("%d", &answer);
}
```

## La boucle `for`

Souvent, une boucle met à jour une variable et se termine lorsque celle-ci atteint une certaine valeur.
Une boucle `for` permet d'initialiser, de mettre à jour et de tester une ou plusieurs variables sur une seule ligne, entre parenthèses.
La première section sert à initialiser la variable, la deuxième à tester la variable, et la troisième à mettre à jour la valeur de la variable.

```c
for (int i = 0; i < 5; i++) {
    printf("Number is %i\n", i);
}
```

C'est moins verbeux que l'équivalent avec une boucle `while`, et pourtant cela reste lisible.

Les sections d'initialisation et de mise à jour de la boucle `for` peuvent gérer plusieurs variables en utilisant l'opérateur virgule pour séparer les expressions à l'intérieur des conditions.

```c
    int i, j;
    for (i = 0, j = 5; i < 5 && j > 2; i++, j--) {
        printf("i is %i\n", i);
        printf("j is %i\n", j);
    }
    printf("After the loop");
```

Cela affiche

```
i is 0
j is 5
i is 1
j is 4
i is 2
j is 3
After the loop
```

Aucune des sections de la boucle `for` n'a besoin d'être définie.
Une expression de test vide est évaluée à vrai, on peut donc utiliser une boucle `for` pour définir une boucle infinie comme ceci :

```c
int i = 0;
for (;;) {
    printf("Number is %i\n", i++);
    if (i == 5) break;
}
```

Cela ressemble à la boucle `while` : `i` est initialisée avant la boucle et incrémentée à l'intérieur de celle-ci.
De plus, `i` est testée à l'intérieur de la boucle et la boucle se termine avec l'instruction `break`.

## L'instruction `break`

Il arrive qu'une boucle doive se terminer sur une condition particulière qui n'est pas testée dans son expression booléenne.
L'instruction `break` met fin à la boucle et l'exécution se poursuit à la ligne de code suivante, après la boucle.

```c
int i, j, k;
for (int i = 0, j = 5, k = 3; i < 5 && j > 2; i++, j--) {
    printf("i is %i\n", i);
    printf("j is %i\n", j);
    if (k == 3) break;
}
printf("After the loop");
```

Cela affiche

```
i is 0
j is 5
After the loop
```

## L'instruction `continue`

Il arrive qu'une boucle doive commencer son itération suivante sans terminer l'itération en cours.
L'instruction `continue` interrompt l'exécution de l'itération en cours et reprend l'exécution au début de l'itération suivante.

```c
int i, j;
for (int i = 0, j = 4; i < 4 && j > 0; i++, j--) {
    if (i == j) continue;
    printf("i is %i\n", i);
    printf("j is %i\n", j);
}
printf("After the loop");
```

Cela affiche

```
i is 0
j is 4
i is 1
j is 3
i is 3
j is 1
After the loop
```

Elle n'affiche pas les valeurs de `i` et de `j` lorsqu'elles valent toutes les deux `2`.
