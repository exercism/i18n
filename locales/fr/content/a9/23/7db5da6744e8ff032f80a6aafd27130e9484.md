# Introduction

## Les tableaux

En Ruby, les **tableaux** sont des collections ordonnées de n'importe quel objet, indexées par des entiers.
Les indices d'un tableau commencent à `0`.
Un indice négatif est considéré comme relatif à la fin du tableau. Par exemple, un indice de `-1` désigne le dernier élément du tableau, `-2` l'avant-dernier, et ainsi de suite.

### Crée des tableaux

Les tableaux sont normalement créés avec la notation `[]`.
Ils peuvent contenir n'importe quel type d'objet.

```ruby
array = [1, "two", 3.0]
```

### Accès aux éléments

Les éléments d'un tableau peuvent être récupérés par leur indice avec la méthode `#[]`.
Elle renvoie l'élément situé à cet indice, ou un sous-tableau qui commence à l'indice de départ et continue sur une longueur donnée.
Les indices négatifs se comptent à rebours depuis la fin du tableau.

```ruby
a = [ "a", "b", "c", "d", "e" ]

a[2]       #=> "c"
a[6]       #=> nil
a[1, 3]    #=> [ "b", "c", "d" ]

a[-1]      #=> "e"
a[-2]      #=> "d"
a[-3, 2]   #=> ["c", "d"]
```

### Méthodes utilitaires

Il existe de nombreuses méthodes utilitaires bien pratiques sur les tableaux.
Voici quelques-unes des plus courantes :

```ruby
fibonacci = [0, 1, 1, 2, 3, 5, 8, 13]

fibonacci.size      #=> 8
fibonacci.sum       #=> 33
fibonacci.reverse   #=> [13, 8, 5, 3, 2, 1, 1, 0]
```

## L'énumération

Plutôt que d'utiliser des boucles pour parcourir les collections, en Ruby, on utilise l'énumération.

L'énumération consiste à parcourir une collection (ici un tableau) et à effectuer une action sur chaque objet. C'est un concept clé en Ruby, qui sert notamment à trier, regrouper, transformer, réduire, et bien d'autres choses encore.

Une énumération qui affiche chaque mot d'un tableau ressemblerait à ceci :

```ruby
words = ["the", "cat", "sat"]
words.each do |word|
  puts word
end

# Output:
# the
# cat
# sat
```

Dans cet exemple, on a appelé la méthode `.each` sur notre tableau et on lui a passé un _bloc_ qui prend un paramètre (`word`) et l'affiche.

On étudiera les _blocs_ bien plus en détail plus loin dans le parcours, mais pour l'instant, vois-les comme des fonctions anonymes qui peuvent prendre zéro argument ou plus.
Ils peuvent être définis avec la syntaxe `do...end` (ci-dessus) ou la syntaxe `{}` (ci-dessous).

Voici d'autres exemples de méthodes de tableau qui utilisent des blocs :

```ruby
fibonacci = [0, 1, 1, 2, 3, 5, 8, 13]

fibonacci.count  { |number| number == 1 }   #=> 2
fibonacci.any?   { |number| number == 6 }   #=> false
fibonacci.select { |number| number.odd? }   #=> [1, 1, 3, 5, 13]
fibonacci.all?   { |number| number < 20 }   #=> true
fibonacci.map    { |number| number * 2  }   #=> [0, 2, 2, 4, 6, 10, 16, 26]
```
