# Instructions complémentaires

## Structure du projet

Les exercices Clojure d'Exercism utilisent [Leiningen](http://leiningen.org/) pour configurer et exécuter ton code, et s'appuient sur la [structure de répertoires standard de Leiningen](https://github.com/technomancy/leiningen/blob/master/doc/TUTORIAL.md#directory-layout).

Tu trouveras un fichier de test nommé `hello_world_test.clj` dans le répertoire `test`.
Écris ton code dans `src/hello_world.clj`. Il doit utiliser l'espace de noms `hello-world` pour que les tests puissent le trouver.

## Exécute les tests

Exécute les tests avec la commande `lein test` et fais-les passer :

```
$ lein test

lein test hello-world-test

Ran 3 tests containing 3 assertions.
0 failures, 0 errors.
```

Ensuite, soumets l'exercice avec :

```
$ exercism submit src/hello_world.clj
```

Pour des instructions plus détaillées et des ressources d'apprentissage, consulte [la page du langage Clojure d'Exercism](http://exercism.io/languages/clojure).
