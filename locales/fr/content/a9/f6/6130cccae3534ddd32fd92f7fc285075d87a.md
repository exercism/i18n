# À propos

Elm est un langage agréable pour construire des applications web fiables.
Il propose des messages d'erreur bienveillants, d'excellentes performances, des ressources légères et aucune exception à l'exécution.

La partie la plus célèbre d'Elm, et sans doute la plus copiée, est The Elm Architecture : un motif simple pour structurer les applications web, et la façon dont toutes les applications web en Elm sont écrites.

L'idée centrale est que ton code s'articule autour d'un `Model` qui contient l'état de ton application, d'une fonction `update` pour le mettre à jour, et d'une fonction `view` pour l'afficher.

Le `Model` contient l'état de l'application, c'est-à-dire toutes les données dont l'application a besoin.
Si tu imagines une application simple avec un champ de texte, et un texte qui affiche ce texte à l'envers, le modèle ressemblerait à ceci.
Tu peux aussi retrouver cet exemple dans le [guide d'Elm][elm-guide-text-fields].

```elm
type alias Model =
  { text : String
  }
```

`update` est une fonction qui est appelée avec un `Msg` lorsqu'il y a un changement (par exemple quand l'utilisateur clique sur un bouton).
Elle prend le `Msg` et le `Model` actuel, et renvoie un nouveau `Model`.

```elm
type Msg
  = TextChanged String

update : Msg -> Model -> Model
update msg model =
  case msg of
    TextChanged newText ->
      { model | text = newText }
```

`view` est une fonction qui renvoie du HTML à montrer à l'utilisateur dans le navigateur.
Elle prend le `Model` actuel et renvoie un `Html Msg` (le type qu'Elm utilise pour représenter le HTML).

```elm
view : Model -> Html Msg
view model =
  Html.div []
    [ Html.input
      [ Html.Attributes.placeholder "Text to reverse"
      , Html.Attributes.value model.text
      , Html.Events.onInput TextChanged
      ]
      []
    , Html.div [] [ Html.text (String.reverse model.text) ]
    ]
```
