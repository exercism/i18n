# À propos

Une boucle `do-while` est une alternative à une boucle `while`, la seule différence étant qu'une boucle `do-while` s'exécute au moins une fois :

```haxe
var i = 0;

do {
  trace("Hello");
} while (i < 10);
```

Les cas où une boucle `do-while` s'impose sont très rares ; c'est pourquoi on utilise le plus souvent une simple boucle `while`.
