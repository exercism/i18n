# Instructions

Tu es un passionné d'observation des oiseaux et tu tiens le compte du nombre d'oiseaux qui ont visité ton jardin au cours des sept derniers jours.

Tu as six tâches, toutes liées au nombre d'oiseaux qui ont visité ton jardin.

## 1. Vérifie quels étaient les comptages la semaine dernière

À des fins de comparaison, tu gardes toujours une copie des comptages de la semaine dernière à portée de main, dont voici les valeurs : 0, 2, 5, 3, 7, 8 et 4. Implémente la méthode (_static_) `BirdCount.LastWeek()` qui renvoie les comptages de la semaine dernière :

```csharp
BirdCount.LastWeek();
// => [0, 2, 5, 3, 7, 8, 4]
```

## 2. Vérifie combien d'oiseaux ont visité aujourd'hui

Implémente la méthode `BirdCount.Today()` pour renvoyer combien d'oiseaux ont visité ton jardin aujourd'hui. Les comptages d'oiseaux sont ordonnés par jour : le premier élément correspond au comptage du jour le plus ancien, et le dernier élément au comptage d'aujourd'hui.

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.Today();
// => 1
```

## 3. Incrémente le comptage d'aujourd'hui

Implémente la méthode `BirdCount.IncrementTodaysCount()` pour incrémenter le comptage d'aujourd'hui :

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.IncrementTodaysCount();
birdCount.Today();
// => 2
```

## 4. Vérifie s'il y a eu un jour sans aucun oiseau

Implémente la méthode `BirdCount.HasDayWithoutBirds()` qui renvoie `true` s'il y a eu un jour où aucun oiseau n'a visité le jardin ; sinon, elle renvoie `false` :

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.HasDayWithoutBirds();
// => true
```

## 5. Calcule le nombre d'oiseaux qui ont visité le jardin sur les premiers jours

Implémente la méthode `BirdCount.CountForFirstDays()` qui renvoie le nombre d'oiseaux qui ont visité ton jardin depuis le début de la semaine, mais limite ce comptage au nombre de jours spécifié à partir du début de la semaine.

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.CountForFirstDays(4);
// => 14
```

## 6. Calcule le nombre de jours chargés

Certains jours sont plus chargés que d'autres. Un jour chargé est un jour où cinq oiseaux ou plus ont visité ton jardin.
Implémente la méthode `BirdCount.BusyDays()` pour renvoyer le nombre de jours chargés :

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.BusyDays();
// => 2
```
