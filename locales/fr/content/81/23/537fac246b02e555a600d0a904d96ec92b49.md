# À propos

Comme tous les types de données standard de Clojure sont immuables, celui-ci propose des *types de référence* qui offrent une mutation contrôlée. Les plus simples et les plus couramment utilisés d'entre eux sont les *atoms*.

Les *atoms* se créent avec la fonction `atom`, qui prend une valeur initiale :

```clojure
(def players (atom ()))
```

On obtient la valeur actuelle d'un *atom* en le déréférençant avec `deref` ou le raccourci `@` :

```clojure
@players
;;=> ()
```

On peut modifier la valeur actuelle de l'*atom* `players` avec `swap!`, qui met à jour la valeur en appliquant une fonction :

```clojure
(swap! players conj :player1)
;;=> (:player1)
```

La fonction `reset!` remplace la valeur d'un *atom* sans tenir compte de sa valeur actuelle :

```clojure
(reset! players ())
```
