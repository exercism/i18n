# nettoyage des espaces avec strings.TrimSpace

Pas besoin de nettoyer le code, par exemple avec `strings.TrimSpace`.

Pour tous les exercices Exercism, on peut supposer que le code fait partie d'une bibliothèque interne et qu'il existe du code à la périphérie de l'application qui se charge de nettoyer les entrées lorsqu'elles arrivent dans le système.
