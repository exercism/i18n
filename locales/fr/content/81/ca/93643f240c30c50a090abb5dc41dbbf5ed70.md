# À propos

Le type `Bool` est l'une des briques de base du langage.
Il sert à décrire si quelque chose est vrai ou faux, avec les valeurs `True` et `False` correspondantes.
Le nom `Bool` est l'abréviation de booléen, un domaine des mathématiques lié au raisonnement logique, nommé d'après les travaux de George Boole.

## Les opérateurs booléens

Il existe deux fonctions et deux opérateurs pour manipuler des valeurs de type `Bool`.

- `not : Bool -> Bool`
  Cette fonction transforme `True` en `False` et `False` en `True`.
- `(&&) : Bool -> Bool -> Bool`
  Cet opérateur, appelé « ET », prend deux booléens et renvoie `True` s'ils sont tous les deux `True`.
  Par exemple, `True && True` renvoie `True`, mais `True && False` renvoie `False`.
- `(||) : Bool -> Bool -> Bool`
  Cet opérateur, appelé « OU », prend deux booléens et renvoie `True` si au moins l'un d'eux est `True`.
  Par exemple, `False || False` renvoie `False`, mais `True || False` renvoie `True`.
- `xor : Bool -> Bool -> Bool`
  Cette fonction (et non un opérateur), appelée « OU exclusif », prend deux booléens et renvoie `True` si et seulement si l'un vaut `True` et l'autre `False`.

Les opérateurs `&&` et `||` n'ont pas la même priorité.
La priorité de `&&` est plus élevée que celle de `||`, exactement comme pour la multiplication `*` et l'addition `+`.
Par conséquent, l'expression `True || False && False` est équivalente à `True || (False && False)`, qui est différente de `(True || False) && False`.
La première renvoie `True`, tandis que la seconde renvoie `False`.

## Les branchements conditionnels

Les booléens sont extrêmement utiles pour créer des branches dans le code, qui ne s'exécutent que si certaines conditions sont remplies.
En Elm, on y parvient avec une expression `if-then-else`, utilisée comme suit.

```elm
if someCondition || (someOtherCondition && anotherCondition) then
    doSomething
else
    doSomethingElse
```

La valeur `someCondition` peut être n'importe quelle expression qui renvoie un `Bool`.
Si cette valeur booléenne est `True`, le code exécute `doSomething`.
Sinon, elle est `False` et le code exécute `doSomethingElse`.
La branche `else` est obligatoire, contrairement à certains autres langages de programmation.

Si tu as besoin d'enchaîner des conditions, il te suffit d'enchaîner les expressions `if-then-else`.

```elm
if someCondition then
    doSomething
else if someOtherCondition then
    doAnotherThing
else
    doSomethingElse
```
