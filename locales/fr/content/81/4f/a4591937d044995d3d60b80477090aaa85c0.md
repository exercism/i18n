# Introduction

## Les nombres entiers

Il existe deux types de nombres en Elixir : les entiers et les nombres décimaux.

Les entiers sont des nombres sans partie décimale.

```elixir
integer = 3
# => 3
```

## Les nombres décimaux

Les nombres décimaux comportent un ou plusieurs chiffres après le séparateur décimal. Ils utilisent le format à virgule flottante à double précision sur 64 bits.

```elixir
float = 3.45
# => 3.45
```

### Travaille avec les nombres

Dans les modules [`Integer`][integer-functions] et [`Float`][float-functions], on trouve des fonctions utiles pour manipuler ces types. Les opérateurs arithmétiques de base sont définis dans le module [`Kernel`][kernel-arithmetic-operators].

### Conversion

Les entiers et les nombres décimaux peuvent être mélangés dans une même expression arithmétique. Si un nombre décimal intervient dans une expression, le résultat sera lui aussi un nombre décimal.

```elixir
2 * 3
# => 6

2 * 3.0
# => 6.0
```

En revanche, dans une division, le résultat est toujours un nombre décimal, même si seuls des entiers sont utilisés.

```elixir
6 / 2
# => 3.0
```

Pour convertir un nombre décimal en entier, on peut supprimer la partie décimale avec [`trunc/1`][trunc-1].
