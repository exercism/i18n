# Introduction

Une *quotation* est un morceau de code entre crochets (`[ ]`). C'est une valeur : on peut la pousser sur la pile, la passer à un autre mot, ou la stocker dans un tableau.

```factor
[ 1 + ] .          ! => [ 1 + ]
5 [ 1 + ] call .   ! => 6
```

La plupart des mots d'ordre supérieur prennent une *quotation* comme deuxième argument :

```factor
{ 1 2 3 } [ sq ] map .    ! => { 1 4 9 }
{ 1 2 3 } [ even? ] filter .  ! => { 2 }
```

Le corps d'une *quotation* est simplement du code Factor ordinaire, avec les mêmes opérateurs et les mêmes effets de pile que partout ailleurs.

Quand on construit du code à partir de données, en concaténant des fragments ou en associant des jetons à des opérations, le résultat est une séquence ; il suffit de la passer par `>quotation` pour la rendre appelable :

```factor
{ [ 1 ] [ 2 + ] [ 3 * ] } concat >quotation call .   ! => 9
```
