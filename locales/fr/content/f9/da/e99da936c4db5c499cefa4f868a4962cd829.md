# Introduction

Cet exercice s'appuie sur la pile de données et la notation d'effet de pile que tu as découvertes dans [Cargo Shuffle][cargo-shuffle]. Ici, tu vas écrire des mots qui combinent des valeurs booléennes.

## Les mots de réorganisation

Les mots de réorganisation les plus courants se trouvent dans [`kernel`][kernel] :

```
dup    ( x -- x x )
dupd   ( x y -- x x y )
drop   ( x -- )
swap   ( x y -- y x )
swapd  ( x y z -- y x z )
over   ( x y -- x y x )
pick   ( x y z -- x y z x )
rot    ( x y z -- y z x )
-rot   ( x y z -- z x y )
rotd   ( w x y z -- w y z x )
spin   ( x y z -- z y x )
nip    ( x y -- y )
tuck   ( x y -- y x y )

2dup   ( x y -- x y x y )
3dup   ( x y z -- x y z x y z )
4dup   ( w x y z -- w x y z w x y z )
2drop  ( x y -- )
3drop  ( x y z -- )
4drop  ( w x y z -- )
2nip   ( x y z -- z )
2swap  ( x y z w -- z w x y )
```

## Les booléens

Les deux littéraux booléens sont `t` et `f`. `f` est la seule valeur fausse de Factor ; tout le reste, y compris `0` et les collections vides, est vrai.

```factor
t .    ! => t
f .    ! => f
```

## Les mots booléens

Ces trois mots booléens viennent du vocabulaire `kernel` :

```
and ( x y -- ? )    ! true when both inputs are truthy
or  ( x y -- ? )    ! true when either input is truthy
not ( x   -- ? )    ! inverts its argument
```

```factor
t t and .    ! => t
t f and .    ! => f
f t or .     ! => t
t not .      ! => f
```

Le `?` dans chaque sortie est la convention de notation d'effet de pile pour « un booléen ».

Tu auras besoin de `swap` pour l'une des tâches ci-dessous.
