# À propos

Une expression booléenne est une question posée à une ou plusieurs valeurs, à laquelle on peut répondre par `true` ou `false`.
Une expression vraie renvoie `1` ; une expression fausse renvoie `0`.
Par ailleurs, les nombres ont aussi une valeur booléenne. Zéro est `false` ; tout nombre non nul est `true`.

Dans l'ancien code C, soit on utilisait directement le type `int` pour représenter des valeurs booléennes, soit le programmeur avait défini des constantes comme `TRUE` et `FALSE` pour faire correspondre `1` et `0` à une représentation booléenne.

Avec la version C99, le type `_Bool` a été ajouté.
Le fichier d'en-tête `stdbool.h` définit trois nouveaux symboles booléens : `bool`, `true` et `false`.
`true` correspond à `1`, `false` correspond à `0`, et `bool` correspond à `_Bool`.
Désormais, au lieu d'utiliser directement des `int` ou de créer leurs propres correspondances booléennes, les programmeurs peuvent inclure `stdbool.h` et obtenir automatiquement des symboles booléens dans leur code.

## Opérateurs de comparaison

C prend en charge six opérateurs de comparaison : `==` (égal à), `!=` (différent de), `>` (supérieur à), `<` (inférieur à), `>=` (supérieur ou égal à), `<=` (inférieur ou égal à).
Ces opérateurs comparent les relations entre les valeurs et les traduisent en valeurs booléennes.

```c
0 == 0 // true. Although 0 is false, 0 equals 0 is true.
0 != 0 // false
1 > 0 // true
1 < 0 // false
1 >= 0 // true
1 <= 0 // false
```

## Opérateurs booléens

C prend en charge trois opérateurs booléens : `||` (OU), `&&` (ET) et `!` (PAS).

`!` s'utilise avec un seul opérande.
Il inverse la valeur booléenne de cet opérande.
Par exemple, `0` est `false`, mais `!0` est `true`.

`||` et `&&` s'utilisent avec deux opérandes.
L'opérande de droite n'est évalué que si l'opérande de gauche ne détermine pas déjà le résultat de l'expression.
Autrement dit, `||` n'évalue son opérande de droite que si son opérande de gauche vaut `false`.
`&&` n'évalue son opérande de droite que si son opérande de gauche vaut `true`.


## L'évaluation en court-circuit

Le fait de ne pas évaluer tous les opérandes s'appelle l'« évaluation en court-circuit ».
L'évaluation en court-circuit est un moyen concis et puissant de gérer certaines situations.
Par exemple, un idiome courant consiste à vérifier qu'un pointeur n'est pas `NULL` et (&&), s'il n'est pas `NULL`, à le déréférencer, ce qui évite de déréférencer un pointeur `NULL`.
Mais l'évaluation en court-circuit peut aussi être source de bugs.
Il arrive qu'un programmeur oublie que l'opérande de droite de `||` ou de `&&` n'est pas toujours évalué.
Si l'opérande de droite est une expression dont l'effet de bord est censé se produire systématiquement, alors ce sera un bug selon la valeur booléenne de l'opérande de gauche.


## Renvoyer une expression booléenne

Le résultat d'une expression booléenne peut être renvoyé directement.
Par exemple, cette instruction `if`

```c
if (count > 0)
    return true;
else
    return false;
end
```

peut être remplacée par

```c
return count > 0;
```
