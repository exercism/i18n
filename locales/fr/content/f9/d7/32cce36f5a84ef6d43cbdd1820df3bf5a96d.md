# Indices

## 1. Définis l'intervalle des rangées et des colonnes

- Tu dois définir deux [constantes][constants] destinées à contenir un [intervalle][range] de rangées et de colonnes.
- Les rangées doivent être un intervalle d'[entiers][integers] allant de 1 à 8.
- Les colonnes doivent être un intervalle de [caractères][characters] allant de 'A' à 'H'.
- La constante doit être définie dans le [module][module] `Chess`.

## 2. Vérifie si une case est valide

- Tu dois vérifier si une valeur se trouve dans un intervalle.
- Il existe [une méthode][include] qui permet de vérifier si une valeur se trouve dans un intervalle. 

## 3. Récupère le surnom du joueur

- Tu peux obtenir une sous-chaîne en utilisant l'[opérateur d'intervalle][range-operator] comme indice.
- Il existe une [méthode][upcase] qui permet de mettre une _string_ en majuscules.

## 4. Crée le message de déplacement

- Tu peux indexer la _string_ d'une case pour obtenir la rangée et la colonne.
- Tu peux utiliser les méthodes déjà définies pour obtenir le surnom du joueur et pour vérifier si le déplacement est valide.
