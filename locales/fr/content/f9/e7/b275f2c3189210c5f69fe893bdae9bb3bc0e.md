# Introduction

Comme une instruction _if/else_, une instruction `switch` permet de modifier le déroulement du programme en exécutant du code de manière conditionnelle.
La différence, c'est qu'une instruction `switch` ne peut comparer la valeur d'une expression de type primitif ou de type _string_ qu'à des valeurs constantes prédéfinies.

Certains mots-clés sont utiles lorsqu'on utilise une instruction `switch`.

- `switch` : ce mot-clé permet de déclarer la structure du `switch`.
  Il est suivi de l'expression ou de la variable qui fera varier le résultat.
- `case` : on utilise ce mot-clé pour déclarer les différentes possibilités de résultat.
- `break` : le mot-clé `break` est très utile pour arrêter l'exécution du `switch` à la fin du déroulement souhaité.
  Si on l'oublie, le programme continue et peut produire des résultats inattendus.
- `default` : comme son nom l'indique, il sert de résultat par défaut quand aucun autre `case` ne correspond au résultat de ton expression.

Dans leur forme la plus simple, ils évaluent une expression de type primitif ou de type _string_ et prennent une décision en fonction de sa valeur.
Par exemple :

```java
String direction = getDirection();
switch (direction) {
    case "left":
        goLeft();
        break;
    case "right":
        goRight();
        break;
    default:
        // otherwise
        markTime();
        break;
}
```
