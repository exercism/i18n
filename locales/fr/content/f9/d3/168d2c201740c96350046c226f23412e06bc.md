# À propos

En Go, les _strings_ sont immuables.
Concaténer des _strings_ avec `+` dans une boucle provoque de fréquentes allocations et copie les données plusieurs fois.
Le [paquet `strings`](https://pkg.go.dev/strings) fournit [`Builder`](https://pkg.go.dev/strings#Builder) pour minimiser la surcharge mémoire en assemblant les _strings_ de façon efficace.

## Construis des _strings_

La valeur zéro d'un `strings.Builder` est prête à l'emploi immédiatement, sans initialisation ni allocation explicite.
On peut ajouter de nouvelles données au _builder_ à l'aide de méthodes d'écriture dédiées.
Chaque méthode d'écriture renvoie une valeur d'erreur pour satisfaire les interfaces standard de Go, mais cette valeur est garantie d'être toujours `nil` et elle est généralement ignorée dans le code de tous les jours.

Les méthodes les plus utilisées sont :

- `WriteString(s string) (int, error)` : ajoute une _string_ au tampon.
- `WriteRune(r rune) (int, error)` : ajoute l'encodage UTF-8 d'une rune.
- `WriteByte(c byte) error` : ajoute un seul octet.

```go
var sb strings.Builder

sb.WriteString("Hello")
var r rune = ' '
sb.WriteRune(r)
var b byte = '.'
sb.WriteByte(b)
```

## Récupère et réinitialise

Une fois que tu as terminé d'assembler ton texte, tu peux récupérer le contenu accumulé sous forme de _string_ Go standard en appelant la méthode `String()`.
Appeler `String()` est une opération très peu coûteuse, car elle renvoie directement la tranche d'octets sous-jacente sous forme de _string_, sans copier les données accumulées.

Si tu as besoin de réutiliser la même instance de _builder_ pour assembler une nouvelle _string_ (par exemple dans une boucle), tu peux appeler la méthode `Reset()`.
Elle vide le tampon interne, ce qui te permet de repartir de zéro et de construire la _string_ suivante tout en conservant la capacité mémoire déjà allouée en interne.

```go
var sb strings.Builder

sb.WriteString("Task One")
fmt.Println(sb.String()) // Output: Task One

// Clear the buffer for resource reuse
sb.Reset()

sb.WriteString("Task Two")
fmt.Println(sb.String()) // Output: Task Two
```
