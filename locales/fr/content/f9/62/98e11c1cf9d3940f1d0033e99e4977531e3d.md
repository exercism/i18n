# À propos

La valeur `null` sert à indiquer l'_absence_ d'une valeur. Un type **_nullable_** est un type qui permet à une variable de prendre la valeur `null`. Pour rendre un type nullable, on l'enveloppe dans `Null<T>` :

```haxe
var a:Int = null; // Error
var b:Null<Int> = null; // Allowed
```

Pour vérifier si une valeur vaut actuellement `null`, il suffit d'utiliser une expression `if` :

```haxe
var a:Null<Int> = 10;

if (a != null) {
  trace("a is not null"); // a is not null
}
```
