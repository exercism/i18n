# Introduction

## Opérateurs de comparaison

R dispose d'un ensemble d'opérateurs identique à celui de nombreux autres langages :

```R
1 == 2 # FALSE
1 != 2 # TRUE
1 < 2 # TRUE
1 > 2 # FALSE
1 <= 2 # TRUE
1 >= 2 # FALSE
```

## Branchement

La forme de base d'une structure _if-else_ est

```R
if (x > 10) {
    y <- "big"
} else if (x > 2) {
    y <- "medium"
} else {
    y <- "tiny"
}
```

Dans ce cas, les parenthèses `()` autour du booléen et les accolades `{}` autour de l'instruction sont toutes les deux obligatoires.
Une instruction `if` simple peut être raccourcie :

```R
if (x == 0) return("success")
```
