# Instructions

Dans cet exercice, tu vas jouer avec une voiture télécommandée, que tu as enfin les moyens de t'offrir après avoir économisé.

Les voitures démarrent avec une batterie pleine (100 %). Chaque fois que tu fais avancer la voiture avec la télécommande, elle parcourt 20 mètres et consomme un pour cent de la batterie.

La voiture télécommandée possède un bel écran LED qui affiche deux informations :

- La distance totale parcourue, affichée sous la forme : `"Driven <METERS> meters"`.
- La charge restante de la batterie, affichée sous la forme : `"Battery at <PERCENTAGE>%"`.

Si la batterie est à 0 %, tu ne peux plus conduire la voiture et l'affichage de la batterie indique `"Battery empty"`.

Tu as six tâches, chacune portant sur des instances de voiture télécommandée.

## 1. Achète une toute nouvelle voiture télécommandée

Implémente la méthode (_static_) `RemoteControlCar.Buy()` pour renvoyer une toute nouvelle instance de voiture télécommandée :

```csharp
RemoteControlCar car = RemoteControlCar.Buy();
```

## 2. Affiche la distance parcourue

Implémente la méthode `RemoteControlCar.DistanceDisplay()` pour renvoyer la distance telle qu'elle est affichée sur l'écran LED :

```csharp
var car = RemoteControlCar.Buy();
car.DistanceDisplay();
// => "Driven 0 meters"
```

## 3. Affiche le pourcentage de batterie

Implémente la méthode `RemoteControlCar.BatteryDisplay()` pour renvoyer le pourcentage de batterie tel qu'il est affiché sur l'écran LED :

```csharp
var car = RemoteControlCar.Buy();
car.BatteryDisplay();
// => "Battery at 100%"
```

## 4. Mets à jour le nombre de mètres parcourus quand tu conduis

Implémente la méthode `RemoteControlCar.Drive()` qui met à jour le nombre de mètres parcourus :

```csharp
var car = RemoteControlCar.Buy();
car.Drive();
car.Drive();
car.DistanceDisplay();
// => "Driven 40 meters"
```

## 5. Mets à jour le pourcentage de batterie quand tu conduis

Modifie la méthode `RemoteControlCar.Drive()` pour qu'elle mette à jour le pourcentage de batterie :

```csharp
var car = RemoteControlCar.Buy();
car.Drive();
car.Drive();
car.BatteryDisplay();
// => "Battery at 98%"
```

## 6. Empêche de conduire quand la batterie est vide

Modifie la méthode `RemoteControlCar.Drive()` pour qu'elle n'augmente pas la distance parcourue et ne diminue pas le pourcentage de batterie lorsque la batterie est vide (à 0 %) :

```csharp
var car = RemoteControlCar.Buy();

// Drain the battery
// ...

car.DistanceDisplay();
// => "Driven 2000 meters"

car.BatteryDisplay();
// => "Battery empty"
```
