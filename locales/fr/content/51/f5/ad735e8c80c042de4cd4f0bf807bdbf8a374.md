# Indices

## Général

- Utilise le [type liste (chaînée)][list] intégré.
- Utilise les fonctions du module [`Stream`][stream] intégré pour créer un flux.

## 1. Intercepte les arguments invalides

- Utilise une [garde][guards] pour intercepter les cas où un entier n'est pas passé comme argument à `generate/1`.

## 2. Génère les cas de base

- Tu peux utiliser plusieurs [clauses de fonction][multiple-fn-clauses] et le [filtrage par motif][pattern-matching] pour créer les fonctions des cas de base.

## 3. Crée le cas généralisé

- Utilise la fonction [`Stream.iterate/2`][stream-iterate] pour générer une suite de nombres, chaque nombre suivant étant créé à partir du précédent.
- Les nombres de départ sont `2` puis `1`, que tu peux passer ensemble dans un _tuple_ pour former une paire `{2, 1}`
- Vérifie que le nombre suivant est la somme des deux nombres qui le précèdent.
- Pour évaluer le flux en une liste, utilise une fonction du module [`Enum`][enum].
