# Aide

Voici quelques ressources pour obtenir de l'aide si tu rencontres des difficultés

* La [documentation officielle][official-docs] couvre la syntaxe, les fonctionnalités du langage et les modules de la bibliothèque standard.
* Le [Discord d'Arturo][discord] est le serveur Discord officiel d'Arturo.
* [Rosetta Code][rosetta-code] propose plus de 770 exemples de code Arturo pour de nombreuses tâches différentes.

[official-docs]: https://arturo-lang.io/documentation
[discord]: https://discord.gg/YdVK2CB
[rosetta-code]: https://rosettacode.org/wiki/Category:Arturo
