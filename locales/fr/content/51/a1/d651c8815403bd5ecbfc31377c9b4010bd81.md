# À propos

Les principaux opérateurs arithmétiques et de comparaison peuvent être adaptés pour être utilisés par vos propres **abstract**. C'est ce qu'on appelle la surcharge d'opérateurs.

Utilise le champ de classe de métadonnées `@:op()` pour surcharger un opérateur :

```haxe
abstract MyAbstract(String) {
  public inline function new(s:String) {
    this = s;
  }

  @:op(A * B)
  public function repeat(rhs:Int):MyAbstract {
    var s:StringBuf = new StringBuf();
    for (i in 0...rhs)
      s.add(this);
    return new MyAbstract(s.toString());
  }
}

class Main {
  static public function main() {
    var a = new MyAbstract("foo");
    trace(a * 3); // foofoofoo
  }
}
```
