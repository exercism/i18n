# Instructions

Dans cet exercice, tu vas écrire du code pour imprimer des badges nominatifs pour les employés d'une usine.

## 1. Imprime un badge pour un employé

Les employés ont un identifiant, un nom et un service.
Les libellés des badges des employés sont formatés comme suit : `"[id] - name - DEPARTMENT"`.
Implémente la méthode `printBadge()` pour renvoyer le libellé du badge d'un employé :

```kotlin
printBadge(734, "Ernest Johnny Payne", "Strategic Communication")
// => "[734] - Ernest Johnny Payne - STRATEGIC COMMUNICATION"
```

~~~~exercism/note
Note que le nom du service doit être en majuscules sur le libellé.
~~~~

## 2. Imprime un badge pour un nouvel employé

À cause d'une bizarrerie du système informatique, il arrive que les nouveaux employés n'aient pas encore d'identifiant lorsqu'ils commencent à travailler à l'usine.
Comme les badges sont obligatoires, ils reçoivent un badge temporaire sans le préfixe d'identifiant.
Modifie la méthode `printBadge()` pour prendre en charge les nouveaux employés qui n'ont pas encore d'identifiant :

```kotlin
printBadge(null, "Jane Johnson", "Procurement")
// => "Jane Johnson - PROCUREMENT"
```

## 3. Imprime un badge pour le propriétaire

Même le propriétaire de l'usine doit porter un badge en permanence.
Cependant, un propriétaire n'a pas de service.
Dans ce cas, le libellé doit afficher `"OWNER"` à la place du nom du service.
Modifie la méthode `printBadge()` pour afficher un libellé pour le propriétaire :

```kotlin
printBadge(254, "Charlotte Hale", null)
// => "[254] - Charlotte Hale - OWNER"
```

~~~~exercism/note
Note qu'il est possible que le propriétaire soit aussi un nouvel employé :

```kotlin
printBadge(null, "Charlotte Hale", null)
// => "Charlotte Hale - OWNER"
```
~~~~
