# Introduction

## Nullabilité

En Java, le littéral `null` sert à représenter l'absence de valeur.

Les types primitifs en Java ont tous une valeur par défaut et ne peuvent donc jamais être `null`.
Par convention, ils commencent par une lettre minuscule, par exemple `int`.

Les types de référence contiennent l'adresse mémoire d'un objet et peuvent avoir la valeur `null`.
Ils commencent généralement par une lettre majuscule, par exemple `String`.

Tenter d'affecter la valeur `null` à une variable primitive provoque une erreur de compilation, car cette variable contient toujours une valeur primitive du type qui lui a été attribué.

```java
//Throws compile time error stating the required type is int, but null was provided
int number = null;
```

Affecter la valeur `null` à une variable de référence ne provoque pas d'erreur de compilation, car les variables de référence peuvent être nulles.

```java
//No error will occur as the String variable str is nullable
String str = null;
```
