# Instructions

Prends un tableau imbriqué et renvoie un seul tableau aplati contenant toutes les valeurs sauf nil/null.

Le défi consiste à écrire une fonction qui accepte une structure imbriquée de type tableau et de profondeur arbitraire, puis qui renvoie une structure aplatie sans aucune valeur nil/null.

Par exemple :

entrée : [1,[2,3,null,4],[null],5]

sortie : [1,2,3,4,5]
