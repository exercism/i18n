# Introduction

Une boucle est un moyen de répéter l'exécution d'une ou de plusieurs instructions d'un même bloc.
Chaque passage dans un bloc d'instructions s'appelle une itération.

## La boucle `while`

Une boucle `while` exécute un bloc d'instructions tant qu'une expression booléenne placée en haut de la boucle est vraie.
Dès que l'expression booléenne devient fausse, la boucle s'arrête et l'exécution se poursuit à la ligne de code qui suit la boucle.

Si l'expression booléenne est fausse dès le départ, la boucle `while` ne s'exécute pas du tout et l'exécution passe directement à la ligne de code qui suit la boucle.

```c
int main() {
    int i = 0;
    while (i < 5) {
        printf("Number is %i\n", i++);
    }    
    return 0;
}
```

Il est important de prévoir une condition qui met fin à la boucle ; sinon, on obtient une boucle infinie qui bloque toute progression du code.
Si, dans le code ci-dessus, on retirait le `++` de `i`, ce serait une boucle infinie.

## La boucle `do`

Une boucle `do` teste son expression booléenne à la fin de la boucle.
Elle s'exécute donc toujours au moins une fois, comme dans l'exemple suivant

```c
do {
    printf("Enter the Answer to the Ultimate Question of Life: ");
    scanf("%d", &answer);
} while (answer != 42); 
// Note that a semicolon is needed after the Boolean expression.
```

Avec une boucle `while`, ce serait plus verbeux

```c
printf(""Enter the Answer to the Ultimate Question of Life: ");
scanf("%d", &answer);
while (answer != 42) {
    printf(""Enter the Answer to the Ultimate Question of Life: ");
    scanf("%d", &answer);
}
```

## La boucle `for`

Souvent, une boucle met à jour une variable et s'arrête lorsque cette variable atteint une certaine valeur.
Une boucle `for` permet d'initialiser, de mettre à jour et de tester une ou plusieurs variables sur une seule ligne, entre parenthèses.
La première section sert à initialiser la variable, la deuxième à la tester, et la troisième à mettre à jour sa valeur.

```c
for (int i = 0; i < 5; i++) {
    printf("Number is %i\n", i);
}
```

C'est moins verbeux que l'équivalent avec une boucle `while`, et pourtant tout aussi lisible.
