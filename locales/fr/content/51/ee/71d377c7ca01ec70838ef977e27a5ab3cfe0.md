# get_in

Assure-toi de n'utiliser `get_in/2` que dans `BasketballWebsite.get_in_path/2` et non dans `BasketballWebsite.extract_from_path/2`. Le but de cet exercice est de t'entraîner à utiliser le comportement Access de deux manières différentes : d'abord directement avec la syntaxe `data[key]`, puis indirectement avec `get_in_path/2`.
