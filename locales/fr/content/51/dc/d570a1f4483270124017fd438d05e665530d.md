# Introduction

Les _charlists_ se créent à l'aide du sigil `~c`.

```elixir
~c"hello"
```

~~~~exercism/note
Dans les versions plus anciennes d'Elixir, les _charlists_ s'écrivent avec des guillemets simples : `'hello'`.
~~~~

Bien qu'ils ressemblent beaucoup à des _strings_, ces deux types de données sont très différents l'un de l'autre. Un _charlist_ est une liste d'entiers. Ces entiers représentent les valeurs Unicode d'un caractère donné, aussi appelées points de code.

```elixir
[65, 66, 67]
# => ~c"ABC"
```

On peut faire précéder un caractère d'un `?` pour obtenir son point de code.

```elixir
?A
# => 65

[?:, ?)]
# => ~c":)"
```

Comme les _charlists_ sont des listes, on peut les manipuler comme n'importe quelle autre liste, en utilisant la récursion et le filtrage par motif.

```elixir
[first_letter | _] = ~c"cat"
first_letter
# => 99
```

On peut concaténer deux listes avec `++`.

```elixir
~c"hi" ++ ~c"!"
# => ~c"hi!"
```

Plus la première liste est longue, plus la concaténation est lente, donc évite d'ajouter à plusieurs reprises des éléments à des listes de longueur arbitraire.
