# Instruction

Ta tâche est de résoudre un casse-tête binaire.
Chaque casse-tête binaire possède exactement _une_ solution, que l'on peut trouver en appliquant ces règles :

1. Chaque case doit contenir soit un 0, soit un 1.
2. Plus de deux chiffres identiques ne peuvent pas être adjacents. Ainsi, si deux cases adjacentes contiennent le même chiffre, les cases situées de part et d'autre doivent contenir l'autre chiffre.
3. Chaque ligne et chaque colonne doit contenir autant de 0 que de 1.
4. Chaque ligne et chaque colonne est unique.

On te passe un casse-tête incomplet sous forme de lignes de 0 et de 1, avec des emplacements réservés (`_`) pour les valeurs inconnues.
Le but est de définir les règles du casse-tête binaire, ce qui permettra aux tests de déterminer les valeurs des emplacements réservés (ce n'est pas à toi de le faire).
Ton implémentation doit utiliser la [programmation logique par contraintes sur domaines finis (CLP(FD))](https://www.swi-prolog.org/man/clpfd.html) de Prolog, qui est parfaite pour ce genre de tâche.
