# Indices

## 1. Conduis une voiture

- Ajoute un champ à la structure `Car` qui garde la trace de la distance parcourue
- Crée une [méthode][method] dont le récepteur est de type `Car` et qui met à jour la distance parcourue

## 2. Affiche la distance parcourue

- Crée une [méthode][method] dont le récepteur est de type `Car`
- Affiche la valeur du champ _distance_

## 3. Affiche le pourcentage de batterie

- Crée une [méthode][method] dont le récepteur est de type `Car`
- Affiche la valeur du champ _battery_

## 4. Vérifie si une voiture télécommandée peut terminer une course

- Rappelle-toi que la voiture dispose d'une [méthode][method] pour récupérer la distance qu'elle a parcourue
- Demande-toi quoi faire lorsque la batterie est épuisée avant d'atteindre la ligne d'arrivée

[method]: https://tour.golang.org/methods/1
