# À propos

Les séquences Factor se déclinent en deux variantes lorsque tu as besoin de les *modifier* :

- **Les tableaux** (`{ … }`) ont une longueur fixe. Tu peux modifier ce qui se trouve *à* chaque position avec `set-nth` / `change-nth`, mais tu ne peux pas les allonger ni les raccourcir.
- **Les vecteurs** (`V{ … }`) sont de longueur variable. `push` ajoute à la fin, `pop` supprime et renvoie le dernier élément.

```factor
USING: arrays kernel sequences ;

! Fixed-length: build a counter array of zeros, then bump one slot.
3 0 <array>            ! { 0 0 0 }
dup [ 1 + ] 1 rot change-nth
.                      ! { 0 1 0 }

! Variable-length: build a vector of names by pushing.
V{ } clone
"alice" over push
"bob" over push
dup pop drop           ! removes "bob"
.                      ! V{ "alice" }
```

| mot             | effet                                          |
|-----------------|------------------------------------------------|
| `<array>`       | `( n elt -- array )` : tableau de `n` copies de `elt` |
| `<vector>`      | `( n -- vector )` : vecteur vide de capacité `n` |
| `V{ }`          | littéral de vecteur vide                       |
| `set-nth`       | `( elt n seq -- )` : affecter l'élément à l'indice `n` |
| `change-nth`    | `( i seq quot -- )` : appliquer `quot` à l'élément à l'indice `i` |
| `push`          | `( elt seq -- )` : ajouter à la fin d'un vecteur |
| `suffix!`       | `( seq elt -- seq )` : ajouter sur place, renvoie le vecteur |
| `pop`           | `( seq -- elt )` : supprimer et renvoyer le dernier |
| `pop*`          | `( seq -- )` : supprimer le dernier sans le renvoyer |
| `clone`         | `( obj -- copy )` : nouvelle copie indépendante |
| `new-sequence`  | `( n exemplar -- newseq )` : nouvelle séquence de la même classe que `exemplar` |
| `new-resizable` | `( n exemplar -- newseq )` : nouvelle variante redimensionnable |

Quand tu modifies une séquence passée par l'appelant, la modification lui est visible : il tient le même objet. Si ce n'est pas ce que tu veux, appelle d'abord `clone` pour obtenir une copie indépendante.
