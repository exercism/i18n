# À propos

En Clojure, lier une valeur à un nom s'appelle une [_var_][vars]. Les _vars_ de premier niveau (globales) sont semblables aux constantes d'autres langages, mais on les redéfinit couramment pour faciliter le développement dynamique.

Les _vars_ de premier niveau se définissent avec [`def`][def] :

```clojure
(def fingers 10)
```

On peut utiliser les fonctions du cœur du langage pour effectuer des [opérations sur les nombres][operators] sur des valeurs.

La macro `defn` permet de définir une [fonction][functions] qui prend zéro argument ou plus. Une fonction renvoie toujours le résultat de la dernière expression de son corps.

```clojure
(defn add [x y]
  (+ x y))
```

Pour appeler une fonction, on écrit son nom et on passe un argument pour chacun de ses paramètres.

```clojure
(def five (add 2 3))
```

En Clojure, les fonctions et les valeurs ne peuvent être utilisées qu'_après_ avoir été définies. Les utiliser avant leur définition provoque une erreur de compilation.

```clojure
;; Compile error as `add` has not yet been defined
(def seven (add 3 4))

(defn add [x y]
  (+ x y))
```

En Clojure, les espaces n'ont pas d'autre rôle que la mise en forme.

Les fonctions et les _vars_ de Clojure sont organisées dans des espaces de noms. Un espace de noms regroupe des fonctionnalités liées et se définit avec la macro `ns` :

```clojure
(ns calculator)

(def pi 3.14)

(defn add [x y]
  (+ x y))
```

Clojure prend en charge deux types de commentaires. Un commentaire sur une seule ligne est précédé d'un `;`, et la forme `comment` sert à empêcher l'évaluation de tout ce qui se trouve entre `(comment` et `)`.
