# Indices

## 1. Crée un nouveau dictionnaire

Un dictionnaire est comme n'importe quelle autre classe : il suffit de l'instancier avec `new` pour créer une instance vide.

## 2. Crée un dictionnaire prérempli

Bien qu'il soit possible de remplir un dictionnaire en y ajoutant des éléments les uns après les autres, on peut aussi l'initialiser de façon statique.

Voir [cet article][dictionary_static_initialization].

## 3. Ajoute un pays à un dictionnaire vide

Voir [Add][dictionary_add]. Passe le dictionnaire renvoyé par la tâche 1 en paramètre.

## 4. Ajoute un pays à un dictionnaire existant

Il n'y a pas de différence notable entre ajouter un élément à un dictionnaire vide et à un dictionnaire déjà initialisé. Passe le dictionnaire renvoyé par la tâche 2 en paramètre.

## 5. Récupère le nom du pays qui correspond à un code de pays

Voir [cet article][dictionary_item].

## 6. Tente d'obtenir le nom du pays pour un code de pays inexistant

Tu dois [détecter][dictionary_contains_key] si le pays est présent dans le dictionnaire.

## 7. Tente d'obtenir le nom du pays pour un code de pays inexistant

Tu peux combiner ce que tu as appris dans les tâches 5 et 6 pour résoudre celle-ci.

## 8. Mets à jour le nom d'un pays

Là encore, [cet article][dictionary_item] s'applique.

## 9. Tente de mettre à jour le nom d'un pays qui n'est pas dans le dictionnaire

C'est très similaire à la tâche 7.

## 10. Supprime un pays du dictionnaire

Voir [cet article][dictionary_remove].

## 11. Trouve le pays dont le nom est le plus long

Voir la [collection de valeurs][dictionary_values], la [longueur d'une chaîne][string_length] et [foreach][foreach].
