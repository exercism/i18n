# À propos

[Structures et classes][structs-and-classes] sont deux des principales briques de base de la programmation Swift. Toutes deux permettent de regrouper des données et des fonctions liées au sein d'unités de fonctionnalité autonomes. Tous les types de base que tu as utilisés jusqu'ici, comme `Int`, `Double` et `Character`, ainsi que les types de collection tels que `Array`, `String` et `Dictionary`, sont en réalité des structures. Et quand on définit une structure ou une classe, on définit un nouveau type à utiliser dans Swift, exactement comme on a utilisé ces types-là.

Les structures et les classes présentent de nombreuses similitudes en Swift. Entre autres points communs, toutes deux peuvent stocker des valeurs dans des _propriétés_ et fournir des fonctionnalités au moyen de _méthodes_.

Chacune apporte en plus des fonctionnalités supplémentaires, qui sortent du cadre de cet exercice.

## Définis des structures

Une structure se définit à l'aide du mot-clé `struct`, suivi du nom du type que l'on définit, puis du corps, placé entre accolades.

Le corps peut être composé de propriétés stockées, qui se définissent et se comportent exactement comme des constantes ou des variables ordinaires.

```swift
struct CharacterStats {
  var health = 0.0
  var speed = 0
  var strength = 0
}
```

## Instances

Comme indiqué plus haut, définir une structure revient simplement à définir un nouveau _type_. Ce n'est qu'un plan décrivant à quoi ressembleront les valeurs de ce type, mais cela ne crée aucune valeur de ce type avec laquelle travailler.

Pour créer une _instance_ de ce type, il faut écrire le nom du type suivi de parenthèses.

```swift
let someStats = CharacterStats()
```

Cela crée des valeurs de ce type, dont les propriétés sont remplies avec les valeurs par défaut fournies dans la définition.

Avec les structures, Swift fournit automatiquement ce que l'on appelle un _initialiseur membre à membre_, qui permet de fournir entre les parenthèses des valeurs pour les propriétés de la structure, lesquelles viennent remplacer les valeurs par défaut de la définition.

```swift
let differentStats = CharacterStats(health: 100.0, speed: 6, strength: 18)
```

## Accède aux propriétés

On peut accéder aux propriétés d'une structure grâce à la _notation pointée_ : le nom de la valeur, suivi d'un point (`.`) et du nom de la propriété. Si une propriété d'une structure possède elle-même des propriétés, cette notation pointée permet aussi d'accéder à ces propriétés imbriquées.

Cette notation permet à la fois de lire la valeur de la propriété et, lorsque c'est autorisé, de la modifier.

```swift
someStats.health
// => 0
someStats.health = 87.3
someStats.health
// => 87.3
```
