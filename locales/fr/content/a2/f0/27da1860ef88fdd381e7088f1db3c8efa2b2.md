# Apprentissage

## Apprends le C à partir de zéro

De manière générale, Exercism part du principe que tu connais déjà la syntaxe et les mécanismes d'un langage dans un parcours donné.
Cependant, connaître la syntaxe d'un langage n'est que la première étape pour le maîtriser.
Exercism te permet de t'exercer à résoudre des problèmes et d'échanger avec d'autres programmeurs qui ont résolu le même problème.
C'est de ces échanges que l'on tire de l'expertise et du recul pour devenir de meilleurs programmeurs.

Si tu débutes complètement en C, prends d'abord le temps d'apprendre les bases du langage.
Voici quelques ressources qui peuvent t'aider à démarrer :

* [Learn C][]
* [CS50x][]

[CodeChef][] est une interface web simple vers un compilateur C qui te permet de tester de petits programmes.
C'est parfois plus simple pour faire un essai rapide que de construire quelque chose en local dans un environnement de développement intégré.

## Le développement piloté par les tests en C

Exercism part du principe que tu connais le concept de développement piloté par les tests.
Chaque exercice est livré avec une série de tests déjà écrits pour toi.
Tu progresses dans l'exercice un test à la fois, en écrivant une implémentation petit à petit pour satisfaire les tests.

Si tu débutes avec le développement piloté par les tests, il est vivement recommandé de commencer par parcourir un [aperçu rapide de quelques frameworks de tests pour le C][test-frameworks] ou de lire le livre [Test-Driven Development for Embedded C][tdd] de James Grenning.
Ces ressources couvrent [Unity][] et [CppUTest][] ; ce parcours utilise Unity.
