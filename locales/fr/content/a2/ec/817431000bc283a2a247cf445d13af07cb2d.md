# À propos

PowerShell est un langage de script dynamique et à typage implicite (_qui prend aussi en charge les [variables à typage fort][strong typed]_) développé par Microsoft, principalement axé sur l'automatisation des tâches et la gestion de la configuration.

PowerShell prend en charge la programmation impérative, fonctionnelle, orientée objet et même en pipeline.

PowerShell a été construit sur la plateforme .NET et sa première version date de 2006.
Il est inclus par défaut dans tous les systèmes Windows modernes, et peut aussi être installé sur Mac et Linux.


## Variables

Il existe deux façons courantes de définir une variable en PowerShell.

Les noms de variables en PowerShell doivent commencer par un `$` et utiliser l'opérateur d'affectation `=` pour lier le nom de la variable à une valeur.

```powershell
> $intVar = 1
> $doubleVar = 2.0
> $stringVar = "Hello"

# Checking a variable type using the GetType() method
> Write-Host $doubleVar.GetType()
System.Double
```

Tu peux aussi préciser explicitement le type d'une variable, si tu veux imposer ou exiger que la valeur soit d'un certain type.
PowerShell fera de son mieux pour convertir la valeur d'un type à un autre lorsque c'est possible.

```powershell
# String represents a floating number can be converted to integer
> [int]$staticOne = "1.234"
> $staticOne
1

# String of letters can not be converted to double type
> [double]$staticTwo = "hello"
MetadataError: Cannot convert value "hello" to type "System.Double"
```

### Constantes

Les constantes en PowerShell sont des variables qui ne peuvent être **modifiées** ni **supprimées** après leur définition.
Cela nous amène à la seconde façon de définir des variables : utiliser l'applet de commande `New-Variable`.

```powershell
> New-Variable -Name "MyConstant" -Value 100 -Option Constant
> $MyConstant
100
```


## Fonctions

En PowerShell, les fonctions se définissent avec le mot-clé `function`.
Chaque fonction peut prendre zéro ou plusieurs paramètres formels entre des parenthèses `()`, suivis de la portée de la fonction, qui commence par `{` et se termine par `}`.

```powershell
function Greeting {
    return "Hello!"
}
```

Les fonctions en PowerShell peuvent renvoyer des valeurs explicitement avec le mot-clé `return`, une fois appelées selon la syntaxe `FuncName $Arg`.

```powershell
function AddTwoNumbers($NumOne, $NumTwo):
    $result = $NumOne + $NumTwo
    return $result

> AddTwoNumbers 10 20
30
```

## Commentaires

Les commentaires simples en PowerShell commencent par un `#` et se terminent à la fin de la ligne.
Les blocs de commentaires en PowerShell commencent par `<#` et se terminent par `#>`.

```powershell
function Main() {
    #This is a comment
    <#
    And this is a comment block
    that can span multiple lines
    #>
}
```
