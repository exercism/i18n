# Introduction

## Chaînes de caractères

En Elm, les caractères et les chaînes de caractères constituent la base de la représentation du texte.
On peut voir une chaîne de caractères comme un tableau de caractères, et la plupart des fonctions de `List` ont leur équivalent dans le module `String`.

### Caractères

Le type `Char` représente un seul caractère unicode, entouré d'apostrophes, par exemple `'a'`.
Le module `Char` fournit des fonctions de prédicat (`Char -> Bool`) pour tester les propriétés d'un caractère : `isUpper`, `isLower`, `isAlpha` et `isAlphaNum`
Le module fournit aussi des fonctions pour convertir un caractère avec `toUpper`, `toLower`, `toLocaleUpper` et `toLocaleLower`, ainsi que pour obtenir sa valeur unicode numérique (`Int`) ou la reconvertir en caractère, avec `toCode` et `fromCode`.

### Chaînes de caractères

Le type `String` fournit une représentation intégrée pour manipuler efficacement les chaînes de caractères et peut représenter n'importe quelle séquence de caractères unicode, par exemple "this is an Elm string."
Les chaînes multilignes sont représentées par des triples guillemets doubles et peuvent contenir des guillemets et des retours à la ligne non échappés.
```elm
"""
    This is a multiline string.
All line-breaks and whitespace,
are preserved. 
"""
```

### Fonctions sur les chaînes de caractères

Le module `String` contient toutes les fonctions résumées dans le tableau ci-dessous.
Parmi les fonctions les plus couramment utilisées, on trouve :

`cons : Char -> String -> String` ajoute un caractère au début d'une _string_.
```elm
cons 'T' "he truth is out there" 
    --> "The truth is out there"
```

`(++): String -> String -> String` ajoute deux _strings_ bout à bout.
```elm
"butter" ++ "fly" 
    --> "butterfly"
```

`split : String -> String -> List String` découpe une _string_ en un tableau de _strings_ au niveau du séparateur donné.
```elm
split ";" "cat;dog;cow" 
    --> ["cat", "dog", "cow"]
```

`join : String -> List String -> String` concatène un tableau de _strings_ avec un séparateur donné.
```elm
join "a" ["H", "w", "ii", "n"] 
    --> "Hawaiian"
```
`replace : String -> String -> String -> String` remplace toutes les occurrences d'une sous-chaîne donnée.
```elm
replace "Hello" "Goodbye cruel" "Hello world." 
    --> "Goodbye cruel world."
```

`length : String -> Int` renvoie le nombre de caractères d'une _string_.
```elm 
length "Hello world." 
    --> 12
```

`toInt : String -> Maybe Int` essaie de convertir une _string_ en `Just Int`, et renvoie `Nothing` quand le format de la _string_ est incorrect.
```elm
toInt "-42" 
    --> Just -42
```    

`contains : String -> String -> Bool` vérifie si la deuxième _string_ contient la première.
```elm
contains "the" "theory" 
    --> True
```

`map : (Char -> Char) -> String -> String` applique une fonction donnée à chaque `Char` de la _string_.
À noter que la fonction fournie doit être une correspondance de `Char` vers `Char`.
```elm
map (\c -> if c == '/' then '.' else c) "a/b/c" 
    --> "a.b.c"
```
