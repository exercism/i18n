# À propos

Clojure étant un langage fonctionnel, les fonctions y sont des citoyens de première classe. Cela signifie qu'on peut les passer à d'autres fonctions, et qu'elles peuvent être générées par d'autres fonctions, exactement comme des données. Clojure en particulier fournit un riche ensemble de fonctions d'ordre supérieur qui créent de nouvelles fonctions à partir de fonctions existantes. On va explorer ici quatre cas importants : `partial`, `comp`, `memoize` et `juxt`. Ces fonctions qui génèrent des fonctions appartiennent à une catégorie plus large, celle des fonctions d'ordre supérieur, comme `map`, `reduce`, `apply` ou `complement`, pour n'en citer que quelques-unes, qui opèrent sur des fonctions existantes.

## partial

En général, étant donné une fonction existante `my-function`, avec les paramètres `p1, p2, ..., pN`, on peut fixer certains de ses paramètres `p1, p2, ..., pM` à des valeurs constantes `v1, v2, ..., vM`. Pour cela, on applique `partial` de la façon suivante : `(partial my-function v1 v2 ... vM)`.

Le résultat est une nouvelle fonction qui applique la fonction d'origine `my-function` en fixant `p1=v1, p2=v2, ..., pM=vM`. Notre nouvelle fonction prend en entrée les paramètres restants `pM+1, pM+2, ..., pN`, dont les valeurs n'ont pas été indiquées lors de l'application de `partial` :

```clojure
(def my-new-function 
  (partial my-function v1 v2 ... vM))
(my-new-function xM+1 xM+2 ... xN)
; => equivalent to (my-function v1 v2 ... vM xM+1 xM+2 ... xN)
```

Prenons un exemple simple : définissons une fonction `inc-by-9` qui augmente de 9, une quantité fixe, quoi qu'on lui passe. On peut implémenter une telle fonction comme ceci :

```clojure
(def inc-by-9 (partial + 9))
(inc-by-9 5)
; => 14
```

Deuxième exemple : on a une fonction `generic-greetings` qui utilise le nom de la personne que l'on souhaite saluer, ainsi qu'un texte d'introduction et un texte de fin :

```clojure
(defn generic-greetings
  [initial-text final-text name]
  (println (str initial-text name final-text)))
```

Puis on utilise `partial` pour toujours employer un message de salutation spécifique :

```clojure
(def say-hello-and-how-are-you-doing 
  (partial generic-greetings "Hello " ", how are you doing?"))
(say-hello-and-how-are-you-doing "Mary")
; => Hello Mary, how are you doing?
```

## comp

On peut utiliser `comp` pour créer une composition d'autant de fonctions que l'on souhaite composer. En général, composer `N` fonctions `f1, f2, ..., fN` signifie appliquer ces fonctions dans l'ordre, en passant la sortie de la fonction précédente à la suivante. En notation mathématique, cela s'écrit :

```
f1 (f2 (... fN(x)))
```

En Clojure, cela équivaut à :

```clojure
(f1 (f2 (... (fN x))))
```

En utilisant comp, on peut créer une nouvelle fonction qui effectue cette composition à notre place :

```clojure
(def my-function-composition 
  (comp f1 f2 ... fN))
(my-function-composition x)
; equivalent to
(f1 (f2 (... (fN x))))
```

Par exemple, imaginons que l'on veuille additionner une série de nombres puis multiplier le résultat par 6. On peut procéder comme ceci :


```clojure
(def six-times-result-sum 
  (comp (partial * 6) +))
(six-times-result-sum 3 2)
; = ((partial * 6) (+ 3 2))
; = (* 6 (+ 3 2))
; = 30
```

## memoize

`memoize` permet de réutiliser des résultats calculés précédemment et associés à une entrée donnée. Pour une même entrée, la fonction *mémoïsée* renvoie le même résultat sans avoir à le recalculer. Elle tire parti du fait que les fonctions `clojure` sont, par défaut, *transparentes référentiellement* : pour une même entrée, elles produisent toujours la même sortie, ce qui permet de réutiliser facilement les calculs précédents.

Pour voir comment cela fonctionne, prenons un cas artificiel où la fonction dort pendant deux secondes avant de produire le résultat, ce qui nous permet de comparer facilement le *temps de calcul* avant et après l'utilisation de `memoize`.

```clojure
(defn my-time-consuming-fn
    "Original, time-consuming function"
    [x]
    (Thread/sleep 2000)
    (* x 2)
)

; We measure the time it takes for the original function
(time (my-time-consuming-fn 3))
; => "Elapsed time: 2007.785622 msecs"
; => 6

; We define a memoized function
(def my-memoized-fn 
  (memoize my-time-consuming-fn) )

; We call the memoized function and measure its execution time. 
; The first execution actually runs the function, taking
; similar time as the original.
(time (my-memoized-fn 3))
; => "Elapsed time: 2001.364052 msecs"
; => 6

; Subsequent calls reuse the previous computation, taking less
; time. Time is further reduced in additional calls.
(time (my-memoized-fn 3))
; => "Elapsed time: 1.190291 msecs"
; => 6

(time (my-memoized-fn 3))
; => "Elapsed time: 0.043701 msecs"
; => 6

; Changing the input makes the function be executed, so that
; we observe a similar computation time as the original 
(time (my-memoized-fn 4))
; => "Elapsed time: 2000.29306 msecs"
; => 8

; Again, repeating the same input will make the 
; execution be skipped, and the associated output returned
(time (my-memoized-fn 4))
; => "Elapsed time: 0.043701 msecs"
; => 8
```

## juxt

`juxt` génère une fonction qui applique, de gauche à droite, les fonctions qu'on lui passe. Le résultat est un vecteur dont les composants sont les résultats individuels de chaque fonction :

```clojure
((juxt f g h) x) ; => [(f x) (g x) (h x)]
```

Prenons un exemple simple : on génère une fonction qui calcule le produit de x par des facteurs successifs, de 2 à 5 :
```clojure
((juxt (partial * 2) (partial * 3) (partial * 4) (partial * 5)) 10) ; => [20 30 40 50]
```
