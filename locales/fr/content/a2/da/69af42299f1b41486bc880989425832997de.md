# Lance les tests

## Télécharge un exercice

Utilise [l'Exercism CLI][cli] pour télécharger l'exercice sur lequel tu veux travailler.

```sh
exercism download --track=dart --exercise=hello-world
```

Ensuite, place-toi dans le répertoire de l'exercice.

```sh
cd /path/to/exercism/dart/hello-world
```

## Installe les dépendances

Avant de lancer les tests, télécharge les dépendances de l'exercice.

```sh
dart pub get
```

## Lance les tests

```sh
dart test
```

## Comprends les résultats des tests

Par défaut, `dart test` utilise le _reporter_ compact, qui affiche sur une seule ligne le décompte des tests réussis, ignorés et échoués au fur et à mesure.

```sh
$ dart test

  Expected: <3>
    Actual: <0>

  package:matcher                    expect
  test/binary_search_test.dart 13:5  main.<fn>


To run this test again: dart test test/binary_search_test.dart -p vm --plain-name 'finds a value in the middle of an array'
00:00 +1 ~9 -1: Some tests failed.
```

- `+1` : 1 test réussi
- `~9` : 9 tests ignorés
- `-1` : 1 test échoué

## Passe les tests un par un

La plupart des exercices comportent plusieurs tests, et tous sauf le premier sont ignorés par défaut.

```dart
void main() {
  final twoFer = TwoFer();

  group('TwoFer', () {
    test('no name given', () {
      final result = twoFer.statement();
      expect(result, equals('One for you, one for me.'));
    }, skip: false);

    test('a name given', () {
      final result = twoFer.statement('Alice');
      expect(result, equals('One for Alice, one for me.'));
    }, skip: true);

    test('another name given', () {
      final result = twoFer.statement('Bob');
      expect(result, equals('One for Bob, one for me.'));
    }, skip: true);
  });
}
```

Pour traiter les tests un par un, remplace `skip: true` par `skip: false` sur chaque test au fur et à mesure. Tu peux aussi lancer tous les tests d'un coup sans modifier le fichier.

```sh
dart test --run-skipped
```

Lors de la soumission, l'exécuteur de tests en ligne exécute tous les tests, y compris ceux qui sont ignorés.
