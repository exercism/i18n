# Tests

Tu peux lancer les tests en exécutant la commande suivante dans le répertoire de l'exercice :

```bash
dub test
```

## Réussis les tests

Fais compiler, lier et passer le premier test en suivant les [trois règles du développement piloté par les tests](http://butunclebob.com/ArticleS.UncleBob.TheThreeRulesOfTdd). Crée juste assez de structure, en déclarant des espaces de noms, des fonctions, des classes, etc., pour satisfaire le compilateur et faire échouer le test. Écris ensuite juste assez de code pour que le test passe. Une fois que c'est fait, décommente le test suivant en déplaçant la ligne suivante juste après lui.

```D
static if (all_tests_enabled)
```

Cela peut provoquer des erreurs de compilation, car de nouvelles constructions peuvent être appelées alors que tu ne les as pas encore déclarées ni définies. Là encore, corrige les erreurs de compilation de façon minimale pour obtenir un test qui échoue, puis modifie le code de façon minimale pour que le test passe, réécris ton implémentation pour la rendre plus lisible et plus expressive, et passe au test suivant.

Essaie d'utiliser les fonctionnalités standard de D plutôt que d'écrire à la main tes propres algorithmes ou fonctionnalités de bas niveau.
