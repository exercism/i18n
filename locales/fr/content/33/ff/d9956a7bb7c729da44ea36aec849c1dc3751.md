# Tests

Pour télécharger un exercice, par exemple `hello-world`, ouvre un terminal et exécute :

```bash
exercism download --track roc --exercise hello-world
```

Rends-toi ensuite dans le répertoire de l'exercice et modifie le code pour résoudre l'exercice. Par exemple :

```bash
cd {your Exercism folder}/roc/hello-world
edit HelloWorld.roc
```

Chaque exercice est livré avec une suite de tests. Tu peux exécuter les tests avec la commande `roc test`, par exemple :

```
roc test hello-world-test.roc
```

Si tu as résolu l'exercice, tu devrais voir 0 test échoué, par exemple :

```
All (5) tests passed in 123.4 ms.
```

En revanche, si le code contient des erreurs, elles ressembleront à ceci :

```
── EXPECT FAILED in hello-world-test.roc ───────────────────────────────────────

This expectation failed:

6│  expect hello == "Hello, World!"
    ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^


1 failed and 0 passed in 123.4 ms.
```

Cela devrait t'aider à corriger le code. Une fois que celui-ci fonctionne, tu peux le soumettre avec la commande `exercism submit` (voir `HELP.md` dans le répertoire de l'exercice pour plus de détails).
