# Indices

## Général

- Les opérateurs de base sur les entiers sont décrits dans la [documentation du module Basics][basics-int] d'Elm.
- Les opérateurs de base sur les nombres à virgule flottante sont décrits dans la [documentation du module Basics][basics-float] d'Elm.
- Les fonctionnalités liées aux _strings_ sont décrites dans le [chapitre String de Beginning Elm][string-beginning-elm] et dans la [documentation du module String][string-module] d'Elm.
