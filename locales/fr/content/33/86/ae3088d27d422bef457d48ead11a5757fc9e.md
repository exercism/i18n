# Introduction

Il arrive qu'une fonction d'ordre supérieur prenne une autre fonction en paramètre et l'utilise d'une manière telle que la fonction passée soit appelée _après_ la fin de la fonction d'ordre supérieur. On dit alors que la fonction passée s'échappe de la fonction d'ordre supérieur, et on la qualifie de _fonction qui s'échappe_.

Cela se produit le plus souvent dans du code asynchrone, mais peut aussi arriver dans des fonctions d'ordre supérieur qui renvoient la fonction passée (ou une fonction qui l'appelle). Par exemple :

```swift
func emptyKitchen(_ order: String) -> String {
  "Sorry, we're all out of \(order)."
}

func prepare(order: String, kitchen: (String) -> String) -> (String) -> String {
  func newKitchen(_ newOrder: String) -> String {
    if newOrder == order {
      return "One \(order) coming up!"
    } else {
      return kitchen(newOrder)
    }
  }
  return newKitchen
}
```

Ici, la fonction `prepare` prend une fonction pour son paramètre `kitchen`, puis construit une nouvelle fonction `newKitchen` qui peut appeler `kitchen`. Cette fonction `newKitchen` est ensuite renvoyée à l'appelant. Si on essaie d'écrire cette fonction en Swift, on obtient l'erreur : _Escaping local function captures non-escaping parameter 'kitchen'_

Swift lève une erreur dans ce cas, car il existe des situations où la fonction imbriquée ou passée peut capturer une valeur, ce qui peut entraîner des fuites de mémoire. La façon dont cela se produit et la manière d'éviter ces fuites dépassent le cadre de cet exercice. Cependant, on peut faire disparaître cette erreur en plaçant l'attribut `@escaping` devant la signature de type de la fonction passée.

```swift
func prepare(order: String, kitchen: @escaping (String) -> String) -> (String) -> String {
  func newKitchen(_ newOrder: String) -> String {
    if newOrder == order {
      return "One \(order) coming up!"
    } else {
      return kitchen(newOrder)
    }
  }
  return newKitchen
}

let restaurant =
  prepare(order: "sandwich",
          kitchen: prepare(order: "chicken",
                           kitchen: prepare(order: "steak",
                                            kitchen: emptyKitchen)))

restaurant("pork chop")
// => "Sorry, we're all out of pork chop."
restaurant("chicken")
// => "One chicken coming up!"
```

Cet attribut indique au compilateur Swift que l'auteur a conscience que des fuites de mémoire peuvent survenir en autorisant cette fonction à s'échapper.
