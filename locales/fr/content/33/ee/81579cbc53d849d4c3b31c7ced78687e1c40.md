# Instructions

Dans cet exercice, tu vas écrire du code pour garder la trace des langages de programmation que tu veux apprendre sur Exercism.

Tu as neuf tâches, qui consistent toutes à manipuler des tableaux.

## 1. Crée un nouveau tableau

Pour garder la trace des langages que tu veux apprendre, tu vas devoir créer un nouveau tableau.

Implémente la méthode statique `Languages.NewList()` qui renvoie un nouveau tableau vide.

```csharp
Languages.NewList()
// => empty list
```

## 2. Définis un tableau existant

Pour l'instant, tu as une feuille de papier sur laquelle figurent les langages que tu veux apprendre : C#, Clojure et Elm.

Implémente la méthode statique `Languages.GetExistingLanguages()` pour renvoyer ce tableau.

```csharp
Languages.GetExistingLanguages();
// => {"C#", "Clojure", "Elm"}
```

## 3. Ajoute un nouveau langage à un tableau

Au fur et à mesure que tu explores Exercism et que tu découvres des langages plus intéressants, tu veux les ajouter à ton tableau.

Implémente la fonction statique `Languages.AddLanguage()` pour ajouter un nouveau langage à la fin de ton tableau.

```csharp
Languages.AddLanguage(Languages.GetExistingLanguages(), "VBA");
// => {"C#", "Clojure", "Elm", "VBA"}
```

## 4. Compte les langages du tableau

Compter les langages un par un n'est pas pratique.

Implémente la méthode statique `Languages.CountLanguages()` pour compter le nombre de langages de ton tableau.

```csharp
Languages.CountLanguages(Languages.GetExistingLanguages())
// => 3
```

## 5. Vérifie si un langage figure dans le tableau

Implémente la méthode statique `Languages.HasLanguage()` pour vérifier si un langage est présent.

```csharp
Languages.HasLanguage(Languages.GetExistingLanguages(), "Elm")
// => true
```

## 6. Inverse le tableau

À un moment donné, tu te rends compte que ton tableau est en fait rangé à l'envers ! 

Implémente la méthode statique `Languages.ReverseList()` pour inverser ton tableau.

```csharp
Languages.ReverseList(Languages.GetExistingLanguages())
// => {"Elm", "Clojure", "C#"}
```

## 7. Vérifie si le tableau est enthousiasmant

Même si tu aimes tous les langages, C# occupe une place particulière dans ton cœur. C'est pourquoi un tableau de langages te passionne vraiment si l'une des conditions suivantes est vraie :

- Le premier élément du tableau est C#.
- Le deuxième élément du tableau est C# et le tableau contient deux ou trois langages.

Implémente la méthode statique `Languages.IsExciting()` pour vérifier si un tableau de langages est enthousiasmant :

```csharp
Languages.IsExciting(Languages.GetExistingLanguages())
// => true
```

## 8.Supprime un langage

Implémente la méthode statique `Languages.RemoveLanguage()` pour supprimer un langage donné du tableau.

```csharp
Languages.RemoveLanguage(Languages.GetExistingLanguages(), "Clojure")
// => { "C#", "Elm" }
```

## 9. Vérifie si tous les langages du tableau sont uniques

Implémente la méthode statique `Languages.IsUnique()` pour vérifier si l'un des langages est répété dans le tableau.

Le tableau de langages (c'est-à-dire le paramètre) est garanti non vide lorsque cette méthode est appelée, et peu importe si le tableau est modifié.

```csharp
Languages.IsUnique(Languages.GetExistingLanguages())
// => true
```
