# Import

La [forme spéciale `import`][import] te permet d'utiliser les fonctions et les macros d'un module externe sans utiliser le nom de ce module.

Importer un module entier peut créer des conflits avec les fonctions locales existantes. Pour les éviter, deux options sont disponibles : `:except` et `:only`. Toutes deux attendent une liste de mots-clés, où la clé est le nom de la fonction et la valeur son arité.

```elixir
defmodule Square do
  import Integer, only: [pow: 2]

  def area(a), do: pow(a, 2)
end
```

En général, les imports sont ajoutés au début de la définition du module, mais ils peuvent l'être n'importe où. Ils ont une portée lexicale, ce qui signifie qu'un import ajouté à l'intérieur d'une définition de fonction ne sera pas disponible dans une autre fonction.

Les imports inutilisés génèrent des avertissements du compilateur.

[import]: https://hexdocs.pm/elixir/Kernel.SpecialForms.html#import/2
