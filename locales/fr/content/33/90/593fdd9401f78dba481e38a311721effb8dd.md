# Ajout aux instructions

## Implémentation

Dans cet exercice, tu vas implémenter une procédure qui doit allouer la _string_ qu'elle renvoie. La libération de la _string_ incombe à l'appelant de la procédure.

```odin
// The procedure will be called like that:
formatted := format("Gianna", 4)
// ...
// and eventually the caller will delete the string
delete(formatted)
```
