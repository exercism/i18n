# Instructions

C'est la finale de la saison au club du coin. Tu tiens le classement à la ligne d'arrivée : les coureurs franchissent la ligne dans l'ordre, les couloirs ont besoin d'étiquettes, et le registre officiel doit être annoté avant la manche suivante.

Les noms des coureurs arrivent dans un tableau, dans l'ordre d'arrivée : le nom d'indice 0 est le vainqueur, celui d'indice 1 est le deuxième, et ainsi de suite.

## 1. Attribue les dossards

Définis `assign-bibs` pour qu'il prenne un tableau de noms de coureurs et renvoie un tableau de paires `{ position name }`, la position en premier.

```factor
{ "Bolt" "Comet" "Spirit" } assign-bibs .
! => { { 0 "Bolt" } { 1 "Comet" } { 2 "Spirit" } }
```

## 2. Étiquettes de couloir

Définis `lane-labels` pour qu'il prenne un tableau de noms de coureurs et renvoie des _strings_ comme `"Lane 0: Bolt"`.

```factor
{ "Bolt" "Comet" } lane-labels .
! => { "Lane 0: Bolt" "Lane 1: Comet" }
```

## 3. Marque les coureurs

Définis `tag-racers` pour qu'il prenne un tableau de noms de coureurs *et* une _string_ de marque, et renvoie des étiquettes de la forme `"<tag>/<index>: <name>"`. La même marque est intégrée dans chaque étiquette.

```factor
{ "Bolt" "Comet" } "Green" tag-racers .
! => { "Green/0: Bolt" "Green/1: Comet" }
```

## 4. Enregistre les arrivées

Définis `record-finishes` pour qu'il prenne un tableau de noms de coureurs et un registre (un vecteur). Pour chaque coureur, ajoute sur place au registre une _string_ de la forme `"<index>: <name>"`. Ne renvoie rien.

```factor
V{ } clone   ! a fresh empty ledger
{ "Bolt" "Comet" } over record-finishes
.
! => V{ "0: Bolt" "1: Comet" }
```

## 5. Cloches de tour

Définis `lap-bells` pour qu'il prenne un nombre `laps` et renvoie une _string_ composée de `"ding "` répété `laps` fois.

```factor
0 lap-bells .   ! => ""
3 lap-bells .   ! => "ding ding ding "
```
