# Indices

## Général

## 1. Calcule le taux de production par heure

- On peut déterminer le taux de réussite à l'aide d'une [instruction conditionnelle][if-else-unless].
- On peut multiplier des instances de `Integer` et de `Float` entre elles. Le résultat sera toujours une instance de `Float`.
- On peut comparer des nombres à l'aide des [opérateurs de comparaison][comparison-operators] intégrés.

## 2. Calcule le nombre d'articles fonctionnels produits par minute

- La classe `Float` implémente une [méthode][to_i] qui renvoie une instance de `Integer`.
- La classe `Integer` implémente une [méthode][to_f] qui renvoie une instance de `Float`.
