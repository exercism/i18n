# Introduction

Python propose trois types de nombres natifs différents : les entiers ([`int`][int]), les nombres à virgule flottante ([`float`][float]) et les nombres complexes ([`complex`][complex]).
On peut aussi importer les fractions ([`fractions.Fraction`][fractions]) et les décimaux ([`decimal.Decimal`][decimals]) depuis la bibliothèque standard.

Les nombres entiers, y compris les nombres hexadécimaux ([_`hex()`_][hex]), octaux ([_`oct()`_][oct]) et binaires ([_`bin()`_][bin]) **sans** décimales, sont eux aussi identifiés comme des `ints`.

Python prend entièrement en charge l'arithmétique entre ces différents types de nombres, et convertit les nombres plus étroits pour les aligner sur leurs équivalents plus larges lorsqu'on les utilise avec les opérateurs arithmétiques binaires (`+`, `-`, `*`, `/`, `//` et `%`).
