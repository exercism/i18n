# Introduction

En Java, les booléens sont représentés par le type `boolean`, dont les valeurs peuvent être `true` ou `false`.

Java prend en charge trois opérateurs booléens :  

- `!` (NON) : inverse le booléen  
- `&&` (ET) : prend deux booléens et renvoie vrai s'ils sont tous les deux vrais  
- `||` (OU) : renvoie vrai si l'un des deux booléens est vrai  

## Exemples

```java
!true // => false
!false // => true
true && false // => false
true && true // => true
false || false // => false
false || true // => true
```
