# Instructions complémentaires

## Notes d'implémentation

L'objet Tree possède deux attributs :

- un label de type `String`
- des enfants de type `List<Tree>`

Le programme de test crée des arbres par applications successives de la fonction de construction `Tree.of`. Par exemple, l'instruction

```java
Tree tree = Tree.of("a", List.of(Tree.of("b"), Tree.of("c", List.of(Tree.of("d")))));
```

construit l'arbre suivant :

```text
      "a"
       |
    -------
    |     |
   "b"   "c"
          |
         "d"
```

Tu peux supposer qu'il n'y aura pas de valeurs dupliquées dans les arbres de test.

---

Les méthodes `FromPov` et `PathTo` sont la partie intéressante de l'exercice.

La méthode `FromPov` prend un argument de type _string_ `from`, qui désigne un nœud de l'arbre par sa valeur. Elle doit renvoyer un arbre dont la racine porte la valeur `from`. Tu peux modifier l'arbre d'origine et le renvoyer, ou bien créer un nouvel arbre et renvoyer celui-ci. Si tu renvoies un nouvel arbre, tu es libre de consommer ou de détruire l'arbre d'origine. Bien sûr, il est préférable de le laisser intact.

La méthode `PathTo` prend deux arguments de type _string_, `from` et `to`, qui désignent deux nœuds de l'arbre par leur valeur. Elle doit renvoyer le plus court chemin dans l'arbre entre le premier et le second nœud.

## Messages d'exception

Il est parfois nécessaire de [lever une exception](https://docs.oracle.com/javase/tutorial/essential/exceptions/throwing.html).
Quand tu le fais, tu dois toujours inclure un **message d'erreur explicite** qui indique l'origine de l'erreur.
Cela rend le code plus lisible et aide beaucoup au débogage.

Cet exercice en particulier exige que tu utilises le [mot-clé `throw`](https://docs.oracle.com/javase/tutorial/essential/exceptions/throwing.html)
pour « lever » plusieurs `UnsupportedOperationException` si l'on passe à la classe `Tree()` un arbre qui ne peut pas être réorienté, ou si aucun chemin ne peut être trouvé entre un `start node` et un `end node`.
Les tests ne seront réussis que si tu `throw` l'`exception` en y joignant un message.

Pour lever une `UnsupportedOperationException` avec un message, écris le message comme argument du type d'`exception` :

```java
// when a tree cannot be oriented to a new node POV
throw new UnsupportedOperationException("Tree could not be reoriented");

// when a path cannot be found between a start and end node on the tree.
throw new UnsupportedOperationException("No path found");
```
