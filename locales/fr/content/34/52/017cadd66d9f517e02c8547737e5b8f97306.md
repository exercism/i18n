# Indices

## Général

- Tu dois définir toutes les méthodes en dehors de `initialize`, dans le `module` `TicketingReservation`.
- Le module doit être placé au-dessus de la classe `TicketSystem`.

## 1. Crée un système de billetterie

- Crée une classe appelée `TicketSystem`.
- Crée un [constructeur][new-initialize] pour la classe `TicketSystem`.
- Crée une [variable d'instance][instance-variable] `@tickets_available` initialisée avec la valeur du premier argument passé au constructeur.
- Crée une [variable d'instance][instance-variable] `@stadium` initialisée avec le nom du deuxième argument passé au constructeur.

## 2. Récupère le nombre de billets disponibles

- Crée un module au-dessus de la classe `TicketSystem`, appelé `TicketingReservation`.
- Relie le module à la classe à l'aide du mot-clé [include][include].
- Crée une méthode appelée `tickets_available` dans le module, qui renvoie le nombre de billets disponibles.

## 3. Commande des billets

- Crée une méthode appelée `order_ticket?` dans le module.
- Utilise un [opérateur de comparaison][equality-and-comparison] pour vérifier qu'au moins 100 billets sont disponibles.
- S'il y a au moins 100 billets disponibles, soustrais 1 à la [variable d'instance][instance-variable] `@tickets_available`.
- Renvoie `true` si au moins 100 billets sont disponibles, sinon renvoie `false`.

## 4. Message de commande

- Crée une méthode appelée `order_message` dans le module.
- Tu peux utiliser les méthodes déjà définies pour vérifier qu'il y a assez de billets disponibles.
- Pour former le message, tu peux utiliser l'[interpolation de chaînes][string-interpolation].
