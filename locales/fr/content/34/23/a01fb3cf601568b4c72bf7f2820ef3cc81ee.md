# Tests

## Exécute les tests

Le parcours Haxe s'appuie sur le framework de tests [Buddy](https://github.com/ciscoheat/buddy).
Tu peux l'installer comme ceci :

```bash
haxelib install buddy
```

Pour exécuter les tests, lance la commande suivante :

```bash
haxe test.hxml
```

Dans le fichier de test, chaque bloc describe marque une section de tests de l'exercice, et chaque test est un bloc `it` ou `xit`.
Les blocs `it` s'exécutent quand tu lances les tests, mais les blocs `xit` sont des tests en attente.
Quand tu soumets une solution, l'exécuteur de tests d'Exercism exécute tous les blocs `it` ou `xit`.
Quand tu travailles en local, seul le premier test est exécuté par défaut.
Pour exécuter les autres tests, remplace les blocs `xit` correspondants par des blocs `it`, puis relance `haxe test.hxml`.


De plus, certains exercices peuvent nécessiter l'installation de bibliothèques supplémentaires via haxelib.
Le cas échéant, une note le signale dans les instructions de l'exercice.

## Résous l'exercice

Résoudre un exercice, c'est faire passer tous ses tests.
Pour t'aider à démarrer, chaque exercice est livré avec un fichier d'implémentation à compléter.
Tu peux t'en servir comme point de départ pour construire ta solution.
N'hésite pas à supprimer ou à modifier ce fichier si tu estimes que c'est la bonne chose à faire.
Essaie de te concentrer sur un seul test à la fois au fur et à mesure que tu progresses vers la solution.
