# À propos

Haxe est un langage de programmation et un compilateur open source, de haut niveau, fortement typé, multiplateforme et orienté objet, capable de produire des applications et du code source pour de nombreuses plateformes différentes à partir d'une seule base de code.

Plusieurs langages cibles sont pris en charge, ce qui permet de couvrir des cas d'usage différents : [Langages cibles pris en charge][supported-target-languages]

[Les types][types] présente les sept catégories de types de Haxe et la façon dont ils interagissent entre eux. La discussion sur les types se poursuit dans [Le système de types][type-system], où sont expliquées des notions comme l'unification, les paramètres de type et l'inférence de type.

[Les champs de classe][class-fields] porte sur la structure des classes Haxe et aborde, entre autres sujets, les propriétés, les champs `inline` et les fonctions génériques.

Dans [Les expressions][expressions], on voit comment amener concrètement un programme à faire quelque chose grâce aux expressions.

[Les fonctionnalités du langage][language-features] conclut la référence du langage Haxe en décrivant en détail certaines fonctionnalités comme le filtrage par motif, l'interpolation de chaînes de caractères et l'élimination de code mort.
