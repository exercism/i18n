# Introduction

## Nil

`Nil` est en Gleam un type qui ne comporte qu'une seule valeur, elle aussi appelée `Nil`. Il est semblable à `void` dans d'autres langages, en ce sens qu'on l'utilise quand une fonction n'a pas de valeur plus pertinente à renvoyer.

```gleam
io.println("Hello, Joe!")
// -> Nil
```

En Gleam, les valeurs ne sont pas « nil-ables » ou « nullables » comme dans certains autres langages. Une valeur ne peut être `Nil` que si son type est `Nil`, et une valeur de tout autre type ne peut jamais être `Nil`.

## IO

Comme la plupart des langages de programmation, Gleam a des « effets de bord », ce qui signifie que les fonctions peuvent lire et modifier l'état du monde, tout en renvoyant une valeur.

Le module `gleam/io` de la bibliothèque standard de Gleam fournit des fonctions pour afficher des _strings_ dans la console.

```gleam
io.println("Hello, Joe!")
// Hello, Joe!
// -> Nil
```

D'autres paquets peuvent fournir d'autres fonctions d'entrée-sortie, comme `simplifile`, un paquet qui propose des fonctions pour lire et écrire des fichiers.

```gleam
simplifile.read("favourite-colour.txt")
// -> Ok("Pink\n")
```
