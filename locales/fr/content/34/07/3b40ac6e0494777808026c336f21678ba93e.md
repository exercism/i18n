# Introduction

On t'a embauché pour développer **Noble Knots**, la nouvelle application de rencontre pour la noblesse dont tout le monde parle ! Avec des siècles de mariages royaux entre familles, les choses sont devenues… _compliquées_. Pour éviter les situations _oups, on est jumeaux_, ton travail consiste à construire un système qui vérifie à quel point deux personnes sont apparentées.

Noble Knots s'inspire de l'« [Islendinga-App][islendiga-app] » islandaise, qui s'appuie sur une base de données retraçant tous les liens familiaux connus entre les Islandais depuis le peuplement de l'Islande.
Ton algorithme déterminera le **degré de séparation** entre deux individus de l'arbre généalogique royal.

Ton application aidera-t-elle à couronner un match parfait ?
