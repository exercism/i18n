# Instructions

Dans cet exercice, tu vas écrire du code pour analyser la production d'une chaîne de montage dans une usine de voitures.
La vitesse de la chaîne de montage peut aller de `0` (arrêt) à `10` (maximum).

À sa vitesse minimale (`1`), `221` voitures sont produites chaque heure.
La production augmente linéairement avec la vitesse.
Ainsi, avec une vitesse réglée sur `4`, elle devrait produire `4 * 221 = 884` voitures par heure.
Cependant, des vitesses plus élevées augmentent la probabilité que des voitures défectueuses soient produites, et celles-ci doivent alors être écartées.

Tu as trois tâches.

## 1. Calcule le taux de réussite

Implémente la méthode (_static_) `AssemblyLine.SuccessRate()` pour calculer la proportion d'objets fabriqués sans erreur pour une vitesse donnée.
Le tableau suivant montre comment la vitesse influence le taux de réussite :

- `0` : taux de réussite de 0 %.
- `1` à `4` : taux de réussite de 100 %.
- `5` à `8` : taux de réussite de 90 %.
- `9` : taux de réussite de 80 %.
- `10` : taux de réussite de 77 %.

```csharp
AssemblyLine.SuccessRate(10)
// => 0.77
```

## 2. Calcule le taux de production par heure

Implémente la méthode (_static_) `AssemblyLine.ProductionRatePerHour()` pour calculer le taux de production horaire de la chaîne de montage, en tenant compte de son taux de réussite :

```csharp
AssemblyLine.ProductionRatePerHour(6)
// => 1193.4
```

Note que la valeur renvoyée est un `double`.

## 3. Calcule le nombre de voitures fonctionnelles produites par minute

Implémente la méthode (_static_) `AssemblyLine.WorkingItemsPerMinute()` pour calculer combien de voitures fonctionnelles sont produites par minute :

```csharp
AssemblyLine.WorkingItemsPerMinute(6)
// => 19
```

Note que la valeur renvoyée est un `int`.
