# Instructions

Te revoilà dans la cuisine, où tu affines la recette de lasagnes tirée de [Les lasagnes succulentes de Leah][lasagna]. Les tâches qui suivent te demandent de jongler avec plusieurs entrées à la fois, et c'est exactement dans ces cas-là que les _locals_, les liaisons nommées de Factor, gagnent leur place.

## 1. Détermine l'état de cuisson

Définis `cooking-status` pour qu'il récupère une lecture de minuterie sur la pile et renvoie une _string_ indiquant l'état.

- `0` → `"Lasagna is done."`
- `f` (la minuterie n'a jamais été réglée) → `"You forgot to set the timer."`
- tout autre nombre → `"Not done, please wait."`

```factor
12 cooking-status .   ! => "Not done, please wait."
0 cooking-status .    ! => "Lasagna is done."
f cooking-status .    ! => "You forgot to set the timer."
```

## 2. Estime le temps de préparation

Définis `preparation-time` pour qu'il prenne un tableau de noms de couches et un nombre moyen de minutes par couche, et renvoie le temps de préparation total.

```factor
{ "sauce" "noodles" "sauce" "meat" "mozzarella" "noodles" } 3 preparation-time .
! => 18
```

## 3. Calcule les nouilles et la sauce nécessaires

Définis `quantities` pour qu'il prenne un tableau de noms de couches et renvoie *deux* valeurs : les grammes de nouilles nécessaires (50 g par couche de nouilles) et les litres de sauce nécessaires (`1/5` litre par couche de sauce).

```factor
{ "sauce" "noodles" "sauce" "meat" "mozzarella" "noodles" } quantities .s
! => 100
! => 2/5
```

## 4. Ajoute l'ingrédient secret

Un ami t'envoie une liste d'ingrédients ; le *dernier* élément est son secret. Définis `add-secret-ingredient` pour qu'il prenne sa liste et la tienne, et renvoie ta liste avec le secret ajouté à la fin.

```factor
{ "noodles" "sauce" "mozzarella" "kampot pepper" }
{ "noodles" "meat" "sauce" "mozzarella" }
add-secret-ingredient .
! => { "noodles" "meat" "sauce" "mozzarella" "kampot pepper" }
```

## 5. Adapte les proportions de la recette

La recette du livre donne deux portions. Définis `scale-recipe` pour qu'il prenne une recette (une table de hachage associant le nom d'un ingrédient à une quantité) et un nombre de portions cible, et renvoie une nouvelle recette adaptée en conséquence.

```factor
H{ { "noodles" 200 } { "sauce" 1/2 } { "mozzarella" 1 } { "meat" 100 } }
4 scale-recipe .
! => H{ { "noodles" 400 } { "sauce" 1 } { "mozzarella" 2 } { "meat" 200 } }
```
