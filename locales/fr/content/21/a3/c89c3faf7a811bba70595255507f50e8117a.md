# Dictionnaires

Les dictionnaires en Cairo sont des stockages clé-valeur, semblables aux _maps_ ou aux tables de hachage d'autres langages.

Cependant, ils possèdent quelques caractéristiques uniques en raison du modèle de mémoire immuable de Cairo.

## Principe de base

Le type `Felt252Dict<T>` fournit les fonctionnalités d'un dictionnaire en Cairo, avec `felt252` comme type de clé et n'importe quel type pris en charge `T` comme type de valeur.

```rust
use core::dict::Felt252Dict;

fn main() {
    let mut balances: Felt252Dict<u64> = Default::default();
    balances.insert('Alice', 100);
    let balance = balances.get('Alice'); // Returns 100
}
```

## Caractéristiques importantes

Contrairement aux dictionnaires d'autres langages, les dictionnaires de Cairo ont quelques propriétés particulières :

1. Les clés doivent être des valeurs `felt252`.
2. Toutes les clés commencent implicitement avec une valeur de zéro.
3. On ne peut pas supprimer d'entrées, on peut seulement mettre à jour des valeurs.
4. Les valeurs doivent implémenter le trait `Felt252DictValue`.

## Remarque sur les performances

En raison du modèle de mémoire immuable de Cairo, les opérations sur les dictionnaires ont une complexité $O(n)$, où $n$ est le nombre d'opérations effectuées sur le dictionnaire.

Chaque opération crée une nouvelle entrée qui enregistre la modification.

## Travaille avec des types complexes

Pour les types qui n'implémentent pas `Felt252DictValue` (comme les tableaux ou les structures), tu peux les envelopper dans `Nullable<T>` :

```rust
let mut dict: Felt252Dict<Nullable<Span<felt252>>> = Default::default();
dict.insert(0, NullableTrait::new(array![1, 2, 3].span()));
```

## Gestion de la mémoire

Les dictionnaires implémentent le trait `Destruct`, ce qui signifie qu'ils sont automatiquement « _squashed_ » (validés et optimisés) lorsqu'ils sortent de leur portée.

Cela fait partie du système de preuve de Cairo et se déroule en arrière-plan.

Rappelle-toi : bien que les dictionnaires puissent sembler moins efficaces que dans d'autres langages, ils sont conçus ainsi pour fonctionner avec le modèle de mémoire unique de Cairo et les exigences de son système de preuve.
