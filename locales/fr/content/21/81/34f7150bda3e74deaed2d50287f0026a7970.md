# Indices

## 1. Détermine combien de temps il faut pour préparer un jus

- Mets en place une [instruction `switch`][mdn-switch] pour la variable `name`.
- Les différents cas doivent représenter les différents noms de jus.
- Utilise le cas `default` pour couvrir tous les autres noms.
- N'oublie pas que les cas s'enchaînent [par défaut][mdn-fallthrough], donc assure-toi d'avoir fait quelque chose pour éviter ce comportement.

## 2. Réapprovisionne la réserve de quartiers de citron vert

- Utilise une [boucle `while`][mdn-while] pour couper les citrons verts un par un.
- Reviens sur le [concept des tableaux][concept-arrays] pour trouver comment retirer les citrons verts de la liste dans le bon ordre.
- Mets en place une [instruction `switch`][mdn-switch] pour obtenir le nombre de quartiers en fonction de la taille d'un citron vert.
- Tu dois garder une trace de deux choses : combien de citrons verts ont déjà été coupés et combien de quartiers manquent encore.
- Tu peux combiner deux conditions pour la boucle à l'aide des [opérateurs logiques][concept-booleans].

## 3. Termine le service

- Utilise une [boucle `do-while`][mdn-do-while] pour traiter les commandes une par une.
- Reviens sur le [concept des tableaux][concept-arrays] pour trouver comment retirer les boissons de la liste dans le bon ordre.
- Tu disposes déjà d'une fonction qui détermine le temps nécessaire pour préparer une boisson : utilise-la pour réduire d'autant le temps restant.
- Tu peux combiner deux conditions pour la boucle à l'aide des [opérateurs logiques][concept-booleans].
