# Introduction

Gleam peut s'exécuter sur la machine virtuelle Erlang (BEAM) ou dans des environnements d'exécution JavaScript. De nombreux autres langages utilisent ces environnements, et il est souvent utile de pouvoir appeler depuis Gleam du code écrit dans ces langages.

La fonctionnalité des _fonctions externes_ de Gleam permet d'importer des fonctions écrites dans d'autres langages et de les appeler sans surcoût à l'exécution.

Si ton projet Gleam s'exécute sur la machine virtuelle Erlang et que tu souhaites appeler la fonction `reverse` du module `lists` d'Erlang, tu peux le faire en ajoutant l'attribut `@external` à un en-tête de fonction Gleam, comme ceci :

```gleam
@external(erlang, "lists", "reverse")
pub fn reverse_list(x: List(a)) -> List(a)
```

Cette fonction peut ensuite être appelée comme n'importe quelle fonction Gleam :

```gleam
let reversed = reverse_list([1, 2, 3])
// -> [3, 2, 1]
```

Si tu essaies de compiler ce code pour les environnements d'exécution JavaScript, la compilation échouera avec un message d'erreur, car il n'existe pas d'implémentation pour JavaScript. On peut spécifier une autre implémentation pour les environnements d'exécution JavaScript, comme ceci :

```gleam
@external(erlang, "lists", "reverse")
@external(javascript, "./my_module.mjs", "reverse")
pub fn reverse_list(x: List(a)) -> List(a)
```

Il est aussi possible d'écrire une implémentation en Gleam, qui sera utilisée lorsqu'il n'existe pas d'implémentation externe pour la cible de compilation actuelle :

```gleam
@external(erlang, "lists", "reverse")
pub fn reverse_list(x: List(a)) -> List(a) {
  tail_recursive_reverse(x, [])
}

fn tail_recursive_reverse(list, reversed) {
  case list {
    [] -> reversed
    [x, ..xs] -> tail_recursive_reverse(xs, [x, ..reversed])
  }
}
```
