# À propos

Un [`Option`][option] est un [enum][enum] qui sert à vérifier la validité de la valeur de retour d'une fonction. Il se définit comme suit :

```haxe
enum Option<T> {
  Some(v:T);
  None;
}
```

Il fait partie du paquet [`haxe.ds`][haxeDs] :

```haxe
import haxe.ds.Option;

class Main {
  static public function main() {
    var result = trySomething();

    switch (result) {
      case None:
        trace("Nothing");
      case Some(s):
        trace("Got: " + s);
    }
  }

  static public function trySomething():Option<String> {
    if (Math.random() > 0.5) {
      return None;
    } else {
      return Some("Success");
    }
  }
}
```
