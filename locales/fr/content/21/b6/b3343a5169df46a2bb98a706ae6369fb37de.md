En tant que future magicienne, Elyse doit s'entraîner sur quelques bases.
Elle a un paquet de cartes qu'elle souhaite manipuler.

Pour lui simplifier un peu les choses, elle n'utilise que les cartes de 1 à 10.

## 1. Récupère une carte du paquet

Renvoie la carte à la position `idx` du paquet donné.

```julia-repl
julia> idx = 2;

julia> card([1, 3, 4, 1], idx)
3
```

## 2. Échange une carte dans le paquet

Échange la carte à la position `idx` avec la nouvelle carte fournie, puis renvoie le paquet ajusté.
Note que cela va muter (modifier) le vecteur d'entrée, et ce n'est pas un problème.

```julia-repl
julia> idx = 2; new_card = 6;

julia> replace_card!([1, 3, 4, 1], idx => new_card)
[1, 6, 4, 1]
```

## 3. Insère une carte au sommet du paquet

Insère une nouvelle carte au sommet du paquet et renvoie le paquet.

```julia-repl
julia> new_card = 8;

julia> insert_card_at_top!([1, 3, 4, 1], new_card)
[1, 3, 4, 1, 8]
```

## 4. Retire une carte du paquet

Retire la carte à la position `idx` du paquet et renvoie le paquet.

```julia-repl
julia> idx = 2;

julia> remove_card!([1, 3, 4, 1], idx)
[1, 4, 1]
```

## 5. Retire la carte du sommet du paquet

Retire la carte au sommet du paquet et renvoie le paquet.

```julia-repl
julia> remove_card_from_top!([1, 3, 4, 1])
[1, 3, 4]
```

## 6. Insère une carte en bas du paquet

Insère une nouvelle carte en bas du paquet et renvoie le paquet.

```julia-repl
julia> new_card = 8;

julia> insert_card_at_bottom!([1, 3, 4, 1], new_card)
[8, 1, 3, 4, 1]
```

## 7. Retire une carte en bas du paquet

Retire la carte en bas du paquet et renvoie le paquet.

```julia-repl
julia> remove_card_at_bottom!([1, 3, 4, 1])
[3, 4, 1]
```

## 8. Vérifie la taille du paquet

Vérifie si la taille du paquet est égale à un `deck_size` donné ou non.

```julia-repl
julia> deck_size = 4;

julia> check_deck_size([1, 3, 4, 1], deck_size)
true

julia> check_deck_size([1, 3, 4, 1, 5], deck_size)
false
```
