# Indices

## Généralités

- Lis la documentation de [MapSet][mapset]
- La documentation d'[Enum][enum] pourrait aussi t'être utile

## 1. Commence une collection

- [Voici la fonction de `MapSet` la plus appropriée][new] pour résoudre la tâche

## 2. Agrandis la collection

- Utilise [cette fonction de `MapSet`][put] pour ajouter des cartes à ta collection
- Utilise [cette autre fonction de `MapSet`][member] pour vérifier si tu as une carte précise dans ta collection

## 3. Commence à échanger

- Pour vérifier si tu peux échanger une carte, utilise [cette fonction de `MapSet`][member]
- Pour mettre à jour ta collection, utilise [cette fonction de `MapSet`][delete] et [celle-ci][put]

## 4. Il ne peut y en avoir qu'un de chaque

- Un `MapSet` a la particularité de ne contenir que des valeurs uniques
- Utilise [cette fonction de `MapSet`][new] pour créer un ensemble et [celle-ci][to_list] pour le retransformer en liste
- Les `MapSet` n'ont pas de notion d'ordre : tu devrais utiliser [cette fonction d'`Enum`][sort] pour trier les cartes, même si les tests passent sans ça

## 5. Les cartes qu'ils n'ont pas

- Utilise [cette fonction de `MapSet`][difference] pour vérifier les différences entre les collections
- Utilise [cette autre fonction de `MapSet`][size] pour obtenir le nombre de cartes dans une collection

## 6. Les cartes qu'ils ont tous

- [Cette fonction d'`Enum`][reduce] te sera utile pour parcourir toutes les collections
- Utilise le _pattern matching_ sur la liste pour distinguer les listes vides des listes non vides
- [Cette fonction de `MapSet`][intersection] t'aidera à garder les cartes communes
- [Cette fonction de `MapSet`][to_list] permet de créer une liste
- Les `MapSet` n'ont pas de notion d'ordre : tu devrais utiliser [cette fonction d'`Enum`][sort] pour trier les cartes, même si les tests passent sans ça

## 7. Toutes les cartes

- [Cette fonction d'`Enum`][reduce] te sera utile pour parcourir toutes les collections
- Utilise [cette fonction de `MapSet`][new_empty] comme accumulateur
- [Cette fonction de `MapSet`][union] t'aidera à accumuler toutes les cartes
- [Cette fonction de `MapSet`][size] comptera combien de cartes tu as

## 8. Un shiny pour la victoire

- Utilise [cette fonction de `MapSet`][split_with] pour séparer ta collection
- Utilise [cette fonction de `String`][starts_with] pour détecter les cartes shiny
- [Cette fonction de `MapSet`][to_list] permet de créer une liste
- Les `MapSet` n'ont pas de notion d'ordre : tu devrais utiliser [cette fonction d'`Enum`][sort] pour trier les cartes, même si les tests passent sans ça
