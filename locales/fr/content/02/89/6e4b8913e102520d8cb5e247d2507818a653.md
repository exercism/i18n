# Indices

## 1. Crée un vecteur de tous les wagons

- Une boucle for/while classique avec `push!` dans un `Vector` fonctionnera.
- Sinon, la fonction [`collect()`][collect] peut être plus concise.
- Autrement, le _splatting_ fonctionne dans un constructeur de vecteur :

```julia-repl
julia> input = (1, 5, 9)
(1, 5, 9)

julia> [input...]
3-element Vector{Int64}:
 1
 5
 9
```

## 2. Corrige le vecteur de wagons

- Il est utile de séparer les wagons de tête et la locomotive du reste, afin de pouvoir les réassembler dans le bon ordre.
- L'affectation multiple avec _splatting_ peut t'aider (voir l'introduction).

## 3. Ajoute les arrêts manquants

- N'oublie pas que cette fonction ne modifie pas l'entrée ! Crée un nouveau `Dict`.
- Seul le nom de l'arrêt est nécessaire, pas le numéro d'arrêt, donc chaque paire doit être séparée.
- Il existe plusieurs façons d'assembler le vecteur de noms :
  -  Une boucle for/while avec `push!()` dans un `Vector`.
  -  Une [compréhension de tableau][comprehensions]
  -  L'application de [`map()`][map] à une fonction sur le vecteur.
  -  La [diffusion][broadcasting] d'une fonction [anonyme][anonymous] est possible :

 ```julia-repl
julia> (x -> x^4).([1, 2, 3]) == [1, 16, 81]
true
 ```

## 4. Étends les informations d'itinéraire

- Après le _slurping_, `more_route_information` est une collection `Pairs()`.
- La fonction [`merge()`][merge] combine deux `Dict` ou plus, mais accepte aussi une collection `Pairs()`.
  La conversion explicite de la collection `Pairs()` en `Dict` est possible, mais inutile.
