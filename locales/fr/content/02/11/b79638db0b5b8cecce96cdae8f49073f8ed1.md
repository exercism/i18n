# Tarifs d'un freelance

## Histoire

Dans cet exercice, tu vas écrire du code pour aider un freelance à communiquer avec un chef de projet. Pour cela, tu fourniras quelques outils qui calculent rapidement des tarifs journaliers et mensuels, éventuellement avec une remise donnée.

On établit d'abord quelques règles entre le freelance et le chef de projet :

- Le tarif journalier vaut 8 fois le tarif horaire ;
- Un mois compte 22 jours facturables.

Le freelance propose d'appliquer une remise si le chef de projet choisit de le laisser facturer au mois, ce qui peut s'avérer utile lorsqu'il y a un budget précis avec lequel le chef de projet doit composer.

Les remises sont modélisées comme des nombres fractionnaires suivis d'un `%` (pourcentage) compris entre `0.0%` (aucune remise) et `90.0%` (remise maximale).

## Tâches

Voici des exemples de tâches qui s'inscrivent dans l'histoire du freelance qui communique avec un chef de projet :

- Calculer le tarif journalier à partir d'un tarif horaire
- Calculer le tarif mensuel, à partir d'un tarif horaire et d'une remise
- Calculer le nombre de jours travaillés à partir d'un budget, d'un tarif et d'une remise

## Terminologie

Ce sont des recommandations, et non des règles, pour la terminologie récurrente des instructions (y compris les commentaires du stub) :

- Le tarif journalier vaut 8 fois le tarif horaire ; il faut le mentionner
- Le tarif mensuel vaut 22 fois le tarif journalier ; il faut le mentionner
- Si la remise est fournie sous un type _différent_ des types numériques, utilise la terminologie **les remises sont modélisées comme**
