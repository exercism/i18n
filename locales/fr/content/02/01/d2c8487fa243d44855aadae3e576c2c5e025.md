# Instructions

Dans **Chrono Realms**, les Time Keepers n'ont pas affaire qu'à des arbres de lignes temporelles, mais aussi à des **Chrono Chains**, des séquences de **TimeNodes** liés, chacun représentant un moment précis dans le temps.
Une **Chrono Chain** est un chemin rectiligne de moments successifs, où chaque **TimeNode** se connecte au suivant.
Ces **Chrono Chains** sont utiles lorsqu'on voyage à travers une série d'événements précis, car elles permettent aux Time Keepers de suivre une seule ligne temporelle.

Cependant, pour gérer ces **Chrono Chains** potentiellement longues, les Time Keepers utilisent des **pointeurs intelligents (Box<T>)** afin de manipuler et de parcourir en toute sécurité ces listes de moments sans causer de duplication ni de débordement de mémoire inutiles.
Chaque **TimeNode** contient une référence vers le nœud suivant, ce qui forme une structure récursive.

Ta tâche, en tant qu'apprenti, consiste à implémenter une **Chrono Chain** sous la forme d'une structure de liste récursive à l'aide de pointeurs intelligents.

Dans cet exercice, tu vas :

1. Créer une énumération `ChronoChain` récursive, qui représente une liste de moments.
2. Utiliser le pointeur intelligent `Box<T>` pour stocker les nœuds récursifs.
3. Implémenter une fonction qui crée une `ChronoChain` à partir d'un tableau de valeurs `u32`.
4. Implémenter une fonction qui parcourt la `ChronoChain` et additionne les valeurs stockées dans la liste.

## 1. Définis l'énumération récursive `ChronoChain`

Crée une énumération récursive `ChronoChain` avec deux variantes :

- `End` : représente la fin de la liste.
- `Link` : contient une valeur `u32` et une référence vers le nœud suivant dans la chaîne, encapsulée dans un pointeur intelligent.

## 2. Crée une fonction pour construire une ChronoChain

Écris une fonction `ChronoChain::build` qui prend un tableau de valeurs `u32` et renvoie une `ChronoChain`, en reliant les valeurs les unes à la suite des autres à l'aide de pointeurs intelligents.

## 3. Implémente la fonction de somme

Écris une fonction `ChronoChain::sum` qui parcourt récursivement la `ChronoChain` et additionne les valeurs de tous les nœuds.

## Exemple d'utilisation

```rust
fn main() {
    // Create a ChronoChain from an array of values
    let chrono_chain = ChronoChain::build(array![10, 20, 30]);

    // Sum the values in the ChronoChain
    let total_sum = chrono_chain.sum();

    println!("Total Time Power: {}", total_sum);
}
```
