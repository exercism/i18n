# Lots de paiements en base de données

## Énoncé du problème

Tu dois insérer un lot de données de paiement dans la table `Payment`. Ta tâche consiste à lire les données de paiement depuis le fichier JSON d'entrée fourni, puis à utiliser l'opération `batchExecute` du client JDBC pour insérer ces données dans la table `Payment`. Le fichier d'entrée d'exemple est fourni sous le nom `payments.json`.

Le contenu du fichier JSON d'entrée suit le schéma JSON suivant :

```json
{
  "type": "array",
  "items": [
    {
      "type": "object",
      "properties": {
        "employee_id": {
          "type": "integer"
        },
        "amount": {
          "type": "number"
        },
        "reason": {
          "type": "string"
        },
        "date": {
          "type": "string"
        }
      },
      "required": [
        "employee_id",
        "amount",
        "reason",
        "date"
      ]
    }
  ]
}

```

Tu dois renvoyer en sortie les identifiants de paiement générés automatiquement pour les données de paiement insérées dans le lot, sans exécuter une nouvelle requête sur la base de données.

Tu peux considérer que les `employee_id` fournis dans le fichier `payments.json` sont valides et déjà présents dans la table `Employee`.

## Détails de la base de données

Utilise la base de données H2 fournie pour ce problème.

> Le fichier de base de données d'exemple est `gofigure.mv.db`, et le nom de la base de données est `gofigure`. Il se trouve dans le dossier `db`.

Les tables suivantes sont déjà présentes dans la base de données H2 d'exemple, avec quelques données d'exemple. Les noms de colonnes et les types de données sont indiqués ci-dessous.

**Nom de la table** : `Employee`

| **Colonnes :**      | type |
| -----------       | ----------- |
| `employee_id`     | entier, clé primaire auto-incrémentée       |
| `name`            | chaîne de caractères        |
| `city`            | chaîne de caractères        |
| `department`      | chaîne de caractères        |
| `age`             | entier        |

**Nom de la table** : `Payment`

| **Colonnes :**      | type |
| -----------       | ----------- |
| `payment_id`      | entier, clé primaire auto-incrémentée       |
| `date`            | date        |
| `amount`          | nombre décimal        |
| `employee_id`     | entier        |
| `reason`          | chaîne de caractères        |

* Le fichier de base de données est `gofigure.mv.db`. Utilise l'URL JDBC `jdbc:h2:file:/path/to/db/file`
* Nom d'utilisateur : `root`
* Mot de passe : `root`

## Contraintes

* Utilise le fichier de base de données H2 fourni dans le dossier `db` pour valider les requêtes et l'exemple Ballerina
* Utilise l'approche des paramètres de dépendance Maven pour ajouter le pilote de base de données H2 comme dépendance de plateforme dans ton Ballerina.toml
* Tu dois trouver les identifiants de paiement générés automatiquement sans exécuter une nouvelle requête sur la base de données.

## Environnement de test

* Tu peux lancer les tests avec `bal test`, ce qui exécutera les tests sur la base de données d'exemple fournie.

## Exemples

### Exemple 1

**Entrée :** dbFilePath : `"/path/to/file/gofigure"`, paymentFilePath : `"/path/to/file/payments.json"`

Données du fichier `payments.json` d'exemple :

```json
[{
        "employee_id": 4,
        "amount": 12500.50,
        "reason": "Fuel for the month January",
        "date": "2022-02-03"
    },
    {
        "employee_id": 1,
        "amount": 10500.50,
        "reason": "Medical Expenses for the month January",
        "date": "2022-02-04"
    },
    {
        "employee_id": 4,
        "amount": 500.50,
        "reason": "Fuel for the month February",
        "date": "2022-03-03"
    }
]

```

**Sortie :** `[1,2,3]`

## Indices

* Utilise le module [ballerinax/java.jdbc](https://central.ballerina.io/ballerinax/java.jdbc) pour interagir avec la base de données
* Consulte la section [Prérequis](https://lib.ballerina.io/ballerinax/java.jdbc/latest) pour savoir comment ajouter le pilote JDBC comme dépendance
* Utilise [io:fileReadJson](https://lib.ballerina.io/ballerina/io/latest/functions#fileReadJson) pour lire le fichier JSON d'entrée
* Convertis les valeurs JSON en types propres à ton application afin de manipuler les données de manière sûre du point de vue des types. Consulte l'exemple [Conversion en un type défini par l'utilisateur](https://ballerina.io/learn/by-example/convert-from-json-to-user-defined-type/)
* Utilise [sql:ParameterizedQuery](https://lib.ballerina.io/ballerina/sql/latest#ParameterizedQuery) et la méthode distante [batchExecute](https://lib.ballerina.io/ballerinax/java.jdbc/latest#Client-batchExecute) pour interagir avec la base de données
* Consulte l'exemple [exécution par lots](https://ballerina.io/learn/by-example/mysql-batch-execute-operation/)
