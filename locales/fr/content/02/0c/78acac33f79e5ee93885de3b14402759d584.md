# Manipulation de bits

Crystal dispose d'opérateurs bit à bit pour manipuler [`Int`][ints] au niveau binaire.

## Opérateurs de décalage

Crystal dispose d'[opérateurs de décalage][shift] pour décaler les bits vers la gauche (`<<`) ou vers la droite (`>>`).

### Décalage à gauche (`<<`)

L'opérateur de décalage à gauche (`<<`) décale les bits vers la gauche.
La valeur à décaler est indiquée à gauche et le nombre de positions de décalage à droite.

```crystal
0b0010 << 1
# => 0b0100

0b0010 << 2
# => 0b1000
```

Si le nombre est négatif, le décalage se fait vers la droite à la place.

```crystal
0b0010 << -1
# => 0b0001
```

### Décalage à droite (`>>`)

L'opérateur de décalage à droite (`>>`) décale les bits vers la droite.
Comme pour l'opérateur de décalage à gauche, la valeur à décaler est indiquée à gauche et le nombre de positions de décalage à droite.

```crystal
0b0100 >> 1
# => 0b0010

0b0100 >> 2
# => 0b0001
```

Et de la même manière, l'opérateur décale vers la gauche si le nombre est négatif.

```crystal
0b0100 >> -1
# => 0b1000
```

## Opérateurs binaires

Crystal dispose de 3 [opérateurs binaires][binary] (`&`, `|`, `^`) et d'un opérateur `~` pour effectuer des opérations bit à bit.

### ET bit à bit (`&`)

L'opérateur ET binaire (`&`) effectue un ET bit à bit sur deux valeurs.
Il compare chaque bit de la première valeur au bit à la même position dans la seconde valeur.
Le bit résultant vaut 1 si les deux bits valent 1.
Sinon, il vaut 0.

```crystal
0b0011 & 0b1010
# => 0b0010
```

### OU bit à bit (`|`)

L'opérateur OU binaire (`|`) effectue un OU bit à bit sur deux valeurs.
Il compare également chaque bit de la première valeur au bit à la même position dans la seconde valeur.
Si l'un des deux bits vaut 1, le bit résultant vaut 1.
Sinon, il vaut 0.

```crystal
0b0011 | 0b1010
# => 0b1011
```

### OU exclusif bit à bit (`^`)

L'opérateur OU exclusif binaire (`^`) effectue un OU exclusif bit à bit.
Comme les opérateurs ET bit à bit et OU bit à bit, il compare chaque bit de la première valeur au bit à la même position dans la seconde valeur.
Si _un seul_ d'entre eux vaut 1, le bit résultant vaut 1.
Sinon, il vaut 0.

```crystal
0b0011 ^ 0b1010
# => 0b1001
```

### NON bit à bit (`~`)

Enfin, l'opérateur NON bit à bit (`~`) inverse chacun des bits de la valeur.
Contrairement aux autres opérateurs binaires, il s'agit d'un opérateur unaire, qui agit uniquement sur la valeur à droite.

```crystal
~0b1110_0010
# => 0b0001_1101
```
