# Introduction

Avec une boucle _while_, on peut exécuter du code de manière répétée tant qu'une certaine condition est remplie.
Elle s'écrit avec le mot-clé `while`, suivi d'une condition entre parenthèses, puis d'un bloc de code contenant le _corps_ de la boucle entre accolades.

```javascript
while (condition) {
  // code that is executed repeatedly as long as the condition is true
}
```

JavaScript propose aussi la boucle `do-while`.
Ici, la condition est vérifiée après l'exécution du corps de la boucle.
C'est utile lorsque la condition dépend du résultat du code du corps.

```javascript
do {
  // The code here will always be executed once and then
  // repeatedly while the condition is true.
} while (condition);
```

À l'intérieur du corps d'une boucle, tu peux utiliser le mot-clé `break` pour arrêter complètement l'exécution de la boucle.
À l'inverse, le mot-clé `continue` arrête seulement l'exécution de l'itération en cours et passe à la suivante.
Avec `continue`, on peut souvent éviter d'envelopper une grande partie du corps de la boucle dans une instruction `if`.

```javascript
let i = 0;

while (i < 100) {
  i = i + 2;

  if (i % 3 === 0) {
    continue;
  }

  // The code here will only be executed when i was not divisible
  // by 3 in the check above.
}
```
