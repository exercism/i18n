# À propos

Une [instruction `switch`][switch] permet de comparer une valeur à plusieurs valeurs possibles.
Elle permet d'écrire du code plus concis qu'avec une succession d'instructions `else-if`.
Une instruction `switch` commence par le mot-clé `switch`, suivi de la valeur à comparer.
On peut ensuite définir les cas à l'aide du mot-clé `case`, suivi de la valeur à laquelle comparer.
Le mot-clé `default` sert à définir le cas par défaut, lorsque aucun des cas ne correspond.
Comme les instructions `else-if`, les instructions `switch` n'exécutent que le bloc de code associé au premier cas qui correspond.

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

Prenons l'exemple suivant :

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

On pourrait plutôt l'écrire ainsi :

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```

## Liaison et clauses `where`

Les valeurs comparées dans une instruction `switch` peuvent aussi être liées à des noms, que l'on peut utiliser dans le corps du cas.
Ces noms peuvent également servir dans des clauses `where`, qui sont des expressions booléennes supplémentaires devant valoir `true` pour que le cas corresponde.

```swift
let x = 1337
switch sumOfDivisors(of: x) {
case let total where total == x:
  print(total, "is a perfect number")
default:
  print(x, "is not a perfect number")
}
```
