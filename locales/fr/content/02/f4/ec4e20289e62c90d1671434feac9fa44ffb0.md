# Normalisations du representer

Le [representer][representer] utilise [`read`][cl-read] pour lire la soumission et [`write`][cl-write] pour écrire la représentation, et applique en plus quelques normalisations supplémentaires.
Chaque soumission subit les normalisations suivantes :

## Supprime les commentaires

Comme [`read`][cl-read] est utilisé pour charger la soumission, les commentaires sont supprimés.

## Supprime les _strings_ de documentation

Plutôt que de normaliser les noms qui pourraient être présents dans la _string_ de documentation, celle-ci est supprimée.
La représentation note toutefois si une _string_ de documentation était présente ou non.

## Normalise la casse du texte

Comme [`read`][cl-read] est utilisé pour charger la soumission, tous les symboles sont normalisés en majuscules.

## Normalise le formatage du texte

La représentation est écrite avec [`write`][cl-write], donc les particularités de formatage de la soumission (comme l'indentation, l'espacement ou les parenthèses fermantes laissées sur des lignes vides) ne sont pas conservées dans la représentation.

## Normalise les noms de symboles

Les symboles tels que les noms de fonctions, de variables et de macros, ainsi que les paquets, sont associés à des [`gensyms`][cl-gensym] qui sont utilisés dans la représentation.
