# À propos

[TypeScript](https://www.typescriptlang.org/) (TS) est un sur-ensemble de JavaScript (JS), créé chez Microsoft en réponse aux frustrations que suscite le développement d'applications à grande échelle en JS. Dans un gros projet JS, il peut devenir difficile de savoir quelles propriétés possèdent tes propres objets et quels arguments prennent tes fonctions (et de quel type ils doivent être). De même, comme il est impossible d'inspecter intelligemment du code JS, quand on inclut un paquet (par exemple depuis `npm`), on doit tenir la documentation à jour pour savoir quelles méthodes sont disponibles et quels arguments elles prennent. TS résout ces problèmes. C'est aujourd'hui un projet open source hébergé sur GitHub. Il prend en charge des outils pour n'importe quel navigateur ainsi que pour Node, sur n'importe quel hôte comme sous n'importe quel OS. TS compile en un JavaScript lisible et conforme aux standards.

TS ajoute à JS un système de types flexible, ainsi que des interfaces (des types personnalisés), et il modifie la syntaxe de certaines fonctionnalités d'ECMAScript comme les classes. Les types sont facultatifs et flexibles (on peut par exemple préciser qu'un argument est une _string_ ou un nombre). Les types permettent à l'outillage présent dans la plupart des éditeurs de code d'améliorer l'expérience de développement, par exemple l'autocomplétion et la détection de méthodes, aussi bien dans ton propre code que dans les paquets que tu utilises. Il prend en charge de nombreuses fonctionnalités d'ECMAScript à venir (comme async/await). On peut écrire du TS dans un style orienté objet ou fonctionnel. Il est compatible avec tous les paquets JS existants. TS transpile vers du JS propre et lisible.

Essaie-le dans le [_playground_](https://www.typescriptlang.org/play), et reste à jour grâce au [blog TypeScript](https://devblogs.microsoft.com/typescript/) et au [compte Twitter](https://twitter.com/typescript).
