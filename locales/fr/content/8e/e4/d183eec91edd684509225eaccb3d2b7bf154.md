# Astuces

## Général

- Renseigne-toi sur les listes de mots-clés dans le [guide de démarrage officiel][getting-started-keyword-lists].
- Renseigne-toi sur les listes de mots-clés sur [elixirschool.com][elixir-school-keyword-lists].
- Jette un coup d'œil à la [documentation du module `Keyword`][keyword].

## 1. Explique les couleurs des vins

- Tu dois écrire les informations données dans le tableau sous forme de liste de mots-clés.
- Jette un coup d'œil à quelques [exemples][keyword-examples] qui montrent comment définir une liste de mots-clés.

## 2. Récupère tous les vins d'une couleur donnée

- Il existe une [fonction intégrée][keyword-get-values] pour récupérer la liste de toutes les valeurs pour une clé donnée.

## 3. Récupère tous les vins d'une couleur donnée mis en bouteille une année donnée

- Il existe une [fonction intégrée][keyword-get] pour récupérer une seule valeur pour une clé donnée.
- Tu n'as pas besoin d'implémenter toi-même le filtrage des bouteilles. Il te suffit d'utiliser conditionnellement la fonction `filter_by_year/2` déjà implémentée.

## 4. Récupère tous les vins d'une couleur donnée mis en bouteille dans un pays donné

- Il existe une [fonction intégrée][keyword-get] pour récupérer une seule valeur pour une clé donnée.
- Tu n'as pas besoin d'implémenter toi-même le filtrage des bouteilles. Il te suffit d'utiliser conditionnellement la fonction `filter_by_country/2` déjà implémentée.
