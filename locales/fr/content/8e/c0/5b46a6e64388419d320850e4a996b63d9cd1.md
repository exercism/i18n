# Ajout aux instructions

## Implémentation

Il est possible d'épuiser les noms de robots : une fois que tous les noms de robots possibles ont été attribués, une erreur doit être renvoyée.

## Test bonus

Une fois que `go test` passe, tu verras que la suite de tests contient un test nommé `TestCollisions`, qui est ignoré par défaut car il peut prendre beaucoup de temps.
Ce test crée de nouveaux robots jusqu'à ce qu'il ne soit plus possible d'attribuer un nouveau nom à un robot.

Pour que le test s'exécute, supprime cette ligne :

```go
t.Skip("skipping test as it can take a long time to run if solution is sub-optimal.")
```

Pour que ce test passe, tu devras t'assurer que le nom d'un robot n'a pas déjà été utilisé et que les noms peuvent être attribués efficacement.
