# Instructions

Dans cet exercice, tu vas écrire du code pour aider un freelance à communiquer avec ses clients au sujet du prix de certains projets.
Tu vas écrire quelques méthodes utilitaires pour calculer rapidement les coûts pour les clients.

```exercism/note
Le paramètre `rate_per_hour` et la méthode `day_rate` sont liés à de l'argent.
Les unités de mesure sont de l'argent pour une unité de temps : des heures et des jours, respectivement.
```

## 1. Calcule le tarif journalier à partir d'un tarif horaire

Un client contacte le freelance pour se renseigner sur ses tarifs.
Le freelance explique qu'il **_travaille 8 heures par jour._**
Cependant, le freelance ne connaît que son tarif horaire pour le projet.
Aide-le à estimer un tarif journalier à partir d'un tarif horaire.

```abap
DATA(freelancer_rates) = NEW zcl_freelancer_rates( ).

freelancer_rates->day_rate( 89 ).
// => 712
```

Le tarif journalier n'a pas besoin d'être arrondi ni converti en une précision « fixe ».

## 2. Calcule le nombre de jours travaillés à partir d'un budget fixe

Un autre jour, un chef de projet propose au freelance de travailler sur un projet avec un budget fixe.
À partir du budget fixe et du tarif horaire du freelance, aide-le à calculer le nombre de jours qu'il travaillerait jusqu'à épuisement du budget.
Le résultat _doit_ être **arrondi à l'entier inférieur**.

```abap
freelancer_rates->days_in_budget(
  budget        = 20000
  rate_per_hour = 89 ).
// => 28
```

## 3. Calcule le tarif avec remise pour les grands projets

Souvent, les clients du freelance font appel à lui pour des projets qui s'étalent sur plusieurs mois.
Dans ces cas-là, le freelance décide d'offrir une remise pour chaque mois complet, et les jours restants sont facturés au tarif journalier.
Grâce à ton excellent équilibre entre vie professionnelle et vie personnelle, tu ne travailles que 22 jours par mois calendaire, donc **_chaque mois compte 22 jours facturables._**
Aide-le à estimer le coût de tels projets, à partir d'un tarif horaire, du nombre de jours facturables que contient le projet et d'un taux de remise mensuel.
La remise est toujours donnée sous forme de nombre, où `42%` devient `0.42`. Le résultat _doit_ être **arrondi à l'entier supérieur**.

```abap
freelancer_rates->price_with_monthly_discount(
  rate_per_hour = 89
  num_days      = 230
  discount      = '0.42' ).
// => 97972
```
