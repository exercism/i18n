# Introduction

Swift dispose d'un ensemble d'instructions qui permettent de modifier le déroulement normal des boucles.
On les appelle les instructions de transfert de contrôle.
Tu as déjà vu `return` ; ce concept t'en présente d'autres, notamment `continue`, `break` et les étiquettes.

## Continue

Il est parfois nécessaire de passer directement à l'itération suivante d'une boucle, sans exécuter le reste des instructions de l'itération en cours.
Le mot-clé `continue` sert à cela.
Quand `continue` est exécuté, la boucle passe directement à la vérification suivante, celle qui détermine si l'itération d'après peut être lancée, c'est-à-dire le `while` dans les boucles _while_ et _repeat-while_, ou le test de présence d'un autre élément dans la séquence pour les boucles _for-in_.

```swift
count = 1
while count < 6 {
  count += 1
  if count == 4 { continue }
  print(count)
}

// prints:
// 2
// 3
// 5
```

## Break

`break` permet de sortir d'une boucle de façon anticipée.
Quand `break` est exécuté, la boucle se termine immédiatement et le programme poursuit avec la première instruction qui suit la boucle.

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  if !fruit.count.isMultiple(of: 2) { break }
  print(fruit)
}

// prints:
// banana
// grapes
```

## Étiquettes

Quand des boucles sont imbriquées, il arrive que l'on veuille utiliser `break` ou `continue` pour sortir ou relancer les boucles externes qui contiennent la boucle dans laquelle on utilise `break` ou `continue`.
Dans ce cas, on peut utiliser des étiquettes pour préciser la boucle à quitter ou à relancer.
On étiquette une boucle en plaçant un nom suivi de deux-points avant le `while`, le `repeat` ou le `for` qui démarre la boucle.

Pour voir l'effet des étiquettes utilisées de cette façon, observe la boucle suivante.

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  print("\n--- \(fruit) ---")
  for letter in fruit {
    guard letter != "n" else { break outerLoop }
    print(letter)
  }
}

// prints:
// --- banana ---
// b
// a
```

## Fallthrough

Le mot-clé `fallthrough` permet de passer au cas suivant dans une instruction `switch`.
Cela signifie que le code du cas suivant sera exécuté sans que sa ou ses conditions soient vérifiées.
L'instruction `switch` se comporte alors comme dans d'autres langages de programmation, où l'instruction `break` n'est pas nécessaire pour sortir de l'instruction `switch` une fois qu'un cas correspond.
Tu peux en savoir plus sur `fallthrough` dans le [livre Swift][fallthrough].

```swift
let value = 1
switch value {
case 1:
  print("One")
  fallthrough
case 2:
  print("Two")
}

// prints:
// One
// Two
```
