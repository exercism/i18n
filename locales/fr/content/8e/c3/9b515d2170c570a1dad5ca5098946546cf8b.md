# Instructions supplémentaires

## Notes d'implémentation

`Range` doit renvoyer un tableau de tous les triplets pythagoriciens dont les côtés sont compris entre `min` et `max`, bornes incluses.

`Sum` doit renvoyer un tableau de tous les triplets pythagoriciens dont la somme `a+b+c` (le périmètre) est égale à `p`.
Les trois éléments de chaque triplet renvoyé doivent être dans l'ordre, `t[0] <= t[1] <= t[2]`, et le tableau de triplets doit être en ordre lexicographique.
