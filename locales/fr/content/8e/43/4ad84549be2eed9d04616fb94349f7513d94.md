# Tests

Pour exécuter les tests, lance la commande `bal test --offline` depuis le répertoire de l'exercice.

## Tests ignorés

Initialement, seul le premier test sera activé.
C'est pour t'encourager à résoudre l'exercice étape par étape.
Une fois que tu as réussi le premier test, supprime la propriété `enable: false` du test suivant et efforce-toi de le faire passer.
