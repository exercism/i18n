# Surcharge d'opérateurs

La surcharge d'opérateurs est une fonctionnalité de certains langages de programmation qui permet de redéfinir les opérateurs standard, comme l'addition (`+`), la soustraction (`-`), la multiplication (`*`) et la division (`/`), afin qu'ils fonctionnent avec des types définis par l'utilisateur.

Cela peut rendre la syntaxe du code plus intuitive, en permettant d'exprimer les opérations sur des types définis par l'utilisateur de la même façon que les opérations sur les types primitifs.

En Cairo, la surcharge d'opérateurs passe par l'implémentation de _traits_ spécifiques.

Chaque opérateur est associé à un _trait_, et surcharger cet opérateur implique de fournir une implémentation de ce _trait_ pour un type personnalisé.
Cependant, il est essentiel d'utiliser la surcharge d'opérateurs avec discernement.

Un mauvais usage peut prêter à confusion et rendre le code plus difficile à maintenir, par exemple lorsque l'opérateur surchargé n'a aucun sens sémantique.

Prenons l'exemple de deux `Potions` que l'on doit combiner.

Une `Potion` possède deux champs de données, la santé et le mana.

Combiner deux `Potions` doit additionner leurs champs respectifs.

```rust
struct Potion {
    health: felt252,
    mana: felt252,
}

impl PotionAdd of Add<Potion> {
    fn add(lhs: Potion, rhs: Potion) -> Potion {
        Potion { health: lhs.health + rhs.health, mana: lhs.mana + rhs.mana }
    }
}

fn main() {
    let health_potion: Potion = Potion { health: 100, mana: 0 };
    let mana_potion: Potion = Potion { health: 0, mana: 100 };
    let super_potion: Potion = health_potion + mana_potion;
    // Both potions were combined with the `+` operator.
    assert(super_potion.health == 100, '');
    assert(super_potion.mana == 100, '');
}
```

Dans le code ci-dessus, on implémente le _trait_ `Add` pour le type `Potion`.

La fonction add prend deux arguments : `lhs` et `rhs` (côté gauche et côté droit).

Le corps de la fonction renvoie une nouvelle instance de `Potion`, dont les valeurs des champs sont une combinaison de `lhs` et `rhs`.

Comme l'illustre l'exemple, surcharger un opérateur nécessite de préciser le type concret surchargé.

Le _trait_ générique surchargé est `Add<T>`, et on définit une implémentation concrète pour le type `Potion` avec `Add<Potion>`.
