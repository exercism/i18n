# Introduction

Haxe est un langage fortement typé, mais son système de typage peut être contourné lorsque c'est nécessaire. Affecter une valeur à un nom s'appelle définir une variable. On peut définir une variable soit en spécifiant explicitement son type, soit en laissant le compilateur Haxe inférer le type. Par conséquent, les deux définitions de variable suivantes sont équivalentes :

```haxe
var explicitVariable:Int = 10; // Explicitly typed
var implicitVariable = 10; // Implicit typed
```

On peut mettre à jour une variable à l'aide de l'opérateur `=` :

```haxe
var number = 0; // Initial value
number = 1; // Updated value
```

Le compilateur lèvera une erreur si l'on essaie d'affecter une valeur dont le type est différent de celui de la variable :

```haxe
var number = 1; // Variable number is of integer type
number = "Hello" // Error trying to assign a string to an integer variable
```

Une fonction qui se trouve à l'intérieur d'une classe s'appelle une _méthode_. Les méthodes peuvent prendre zéro ou plusieurs paramètres. Tous les paramètres doivent être typés explicitement. Tout comme les paramètres, le type de retour d'une méthode ne peut pas être inféré et doit être typé. Les valeurs sont renvoyées par les méthodes à l'aide du mot-clé `return` :

```haxe
function add(x:Int, y:Int):Int {
  return x + y;
}
```

Pour invoquer une méthode, on indique le nom de sa classe et de la méthode, puis on passe les arguments :

```haxe
var sum = add(1, 2) // sum = 3
```

En Haxe, la portée est définie entre les caractères `{` et `}`.

Haxe prend en charge deux types de commentaires. Les commentaires sur une ligne sont précédés de `//` et les commentaires multilignes s'insèrent entre `/*` et `*/`.
