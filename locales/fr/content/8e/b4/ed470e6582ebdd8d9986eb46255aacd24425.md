```text

+-++--+
|  |  |
+--+--+
```

```text

|     |
+-----+
```

```text

   +--+
```

```text
   +--+
   |  |
   +--+


```

```text


   +--+
   |  |
   +--+
```

```text


+--+
|  |
+--+
```

```text

  ++
  ++


```

Tu peux supposer que l'entrée est toujours un rectangle bien formé (c'est-à-dire que la longueur de chaque ligne est égale à la longueur de la première ligne).
