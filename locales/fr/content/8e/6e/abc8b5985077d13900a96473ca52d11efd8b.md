# Tests

## Clojure CLI

Les exercices Clojure d'Exercism sont fournis avec un fichier `deps.edn` qui contient un alias `:test` permettant d'invoquer le [cognitect-labs test-runner](https://github.com/cognitect-labs/test-runner) :

``` bash
$ clj -X:test
```

## Leiningen

On peut aussi utiliser Leiningen pour exécuter les tests de l'exercice, en lançant la commande suivante depuis le répertoire de l'exercice :

```bash
lein test
```

## REPL

Pour exécuter les tests de l'exercice avec le REPL, lance la commande suivante depuis le répertoire de l'exercice :

```bash
$ clj
```

-ou-

```bash
$ lein repl
```

Ensuite, fais un `require` sur l'espace de noms de test de l'exercice et sur celui de test de Clojure :

```clojure
;; replace <exercise> with the exercise's name
=> (require '<exercise>-test)
```

Appelle ensuite `run-tests` sur `<exercise>-test` :

```clojure
;; replace <exercise> with the exercise's name
=> (clojure.test/run-tests '<exercise>-test)
```
