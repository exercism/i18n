# À propos

Manipuler des _strings_ est une tâche courante en programmation.
C'est pourquoi Swift propose tout un éventail de méthodes pour manipuler les _strings_.
Ce document présente quelques-unes des méthodes et propriétés les plus courantes ; certaines d'entre elles nécessitent d'importer le _framework_ Foundation.

## [`components(separatedBy:)`][components]

Pour découper une _string_ en un tableau de sous-chaînes, tu peux utiliser la méthode `components(separatedBy:)`.
Ainsi, si tu veux récupérer chaque mot d'une phrase, tu peux utiliser l'espace comme séparateur.

```swift
let sentence = "Hello, world!"
let words = sentence.components(separatedBy: " ")
print(words) // Prints ["Hello,", "world!"]
```

## [`hasPrefix(_:)`][hasPrefix], [`hasSuffix(_:)`][hasSuffix]

Pour vérifier si une _string_ commence ou se termine par une certaine sous-chaîne, tu peux utiliser les méthodes `hasPrefix(_:)` et `hasSuffix(_:)`.
Ces deux méthodes prennent une _string_ en argument et renvoient une valeur booléenne indiquant si la _string_ commence ou se termine par la sous-chaîne spécifiée.

```swift
let greeting = "Hello, world!"
print(greeting.hasPrefix("Hello"))  // Prints true
print(greeting.hasSuffix("world!")) // Prints true
```

## [`lowercased`][lowercased], [`uppercased`][uppercased], [`capitalized`][capitalized]

Pour changer la casse d'une _string_, tu peux utiliser les propriétés `lowercased`, `uppercased` et `capitalized`.
La propriété `lowercased` renvoie une nouvelle _string_ dont tous les caractères sont en minuscules, la propriété `uppercased` renvoie une nouvelle _string_ dont tous les caractères sont en majuscules, et la propriété `capitalized` renvoie une nouvelle _string_ dont le premier caractère de chaque mot est en majuscule.

```swift
let greeting = "hello, world!"
print(greeting.lowercased)  // Prints "hello, world!"
print(greeting.uppercased)  // Prints "HELLO, WORLD!"
print(greeting.capitalized) // Prints "Hello, World!"
```

## [`replacingOccurrences(of:with:)`][replacingOccurrences]

Pour remplacer toutes les occurrences d'une sous-chaîne dans une _string_ par une autre sous-chaîne, tu peux utiliser la méthode `replacingOccurrences(of:with:)`.
Cette méthode prend deux _strings_ en arguments : la sous-chaîne à remplacer et la sous-chaîne de remplacement. Elle renvoie une nouvelle _string_ dans laquelle toutes les occurrences de la sous-chaîne spécifiée ont été remplacées.

```swift
let greeting = "Hello, world!"
let newGreeting = greeting.replacingOccurrences(of: "world", with: "Swift")
print(newGreeting) // Prints "Hello, Swift!"
```

## [`joined(separator:)`][joined]

Il ne s'agit pas d'une méthode du type String, mais du type Array.
Pour assembler un tableau de _strings_ en une seule _string_ avec un séparateur donné, tu peux utiliser la méthode `joined(separator:)`.
Cette méthode prend une _string_ en argument et renvoie une nouvelle _string_ qui rassemble tous les éléments du tableau, séparés par la _string_ spécifiée.

```swift
let words = ["Hello", "world"]
let sentence = words.joined(separator: ", ")
print(sentence) // Prints "Hello, world"
```
