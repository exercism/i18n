# Introduction

Les intervalles représentent une séquence d'un ou plusieurs entiers consécutifs. On les crée en reliant deux entiers avec `..`.

```elixir
1..5
```

Les intervalles peuvent être croissants ou décroissants. Ils incluent toujours la première et la dernière valeur.

Un intervalle implémente le _protocole Enumerable_, ce qui signifie que les fonctions du module `Enum` peuvent être utilisées pour manipuler des intervalles.
