# Instructions

C'est l'équipe de nuit sur les quais de Hull. Le cargo *Olwen* est amarré le long du quai, et une équipe de débardeurs traite le manifeste en parallèle. Chaque caisse doit être pesée avant de monter à bord, et le capitaine de port tient un unique **compte du tonnage** que chaque levage met à jour. Le hic : il n'y a qu'une seule grue sur le quai, donc le compte ne peut pas être déchiré par deux débardeurs qui le mettent à jour en même temps.

Chaque caisse est un tableau de poids d'articles. Le poids d'une caisse est la somme de ces articles.

## 1. Pèse une caisse

Définis `weigh-crate` pour qu'elle prenne une caisse et renvoie son poids total. C'est un simple travail séquentiel : une caisse, un nombre en sortie.

```factor
{ 12 8 15 } weigh-crate .
! => 35
```

## 2. Pèse tout le manifeste en parallèle

Définis `weigh-all` pour qu'elle prenne un tableau de caisses et renvoie le tableau de leurs poids, dans le même ordre. Utilise `parallel-map` pour que le travail sur chaque caisse se fasse en parallèle.

```factor
{ { 5 5 } { 10 } { 3 4 5 } } weigh-all .
! => { 10 10 12 }
```

## 3. Construis une nouvelle grue

Définis `<crane>` pour construire une nouvelle grue : un tuple avec un `<lock>` neuf et un tonnage de `0`. La grue est la ressource partagée que les tâches suivantes vont protéger.

```factor
<crane> tonnage>> .
! => 0
```

## 4. Hisse une caisse sur le compte en cours

Définis `hoist-crate` pour qu'elle prenne en paramètres `weight` et `crane`, et ajoute le poids au tonnage de la grue **sous le verrou de la grue**, afin que la lecture-ajout-écriture soit atomique face aux autres débardeurs qui hissent en même temps.

```factor
<crane>
35 over hoist-crate
17 over hoist-crate
tonnage>> .
! => 52
```

## 5. Lis le tonnage en cours

Définis `crane-tonnage` pour qu'elle renvoie le tonnage actuel de la grue, également sous le verrou, afin que la lecture ne voie pas de valeur déchirée en plein levage.

```factor
<crane>
35 over hoist-crate
crane-tonnage .
! => 35
```

## 6. Charge la cargaison

Définis `load-cargo` pour qu'elle prenne un tableau de caisses et une grue, et **pour chaque caisse, lance un _thread_ de débardeur** qui pèse la caisse et hisse le poids sur la grue. Le mot ne se termine qu'une fois que tous les débardeurs ont fini. Utilise `<promise>` et `?promise` pour coordonner la jonction.

```factor
<crane> :> crane
{ { 5 5 } { 10 } { 3 4 5 } } crane load-cargo
crane crane-tonnage .
! => 32
```
