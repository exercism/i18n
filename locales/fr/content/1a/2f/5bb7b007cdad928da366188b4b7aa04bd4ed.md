# Introduction

Factor a deux valeurs booléennes : `t` (vrai) et `f` (faux). Partout où une réponse «\u00A0oui/non\u00A0» est nécessaire, les mots en empilent une sur la pile.

Les opérateurs booléens se trouvent dans [`kernel`][kernel]\u00A0:

```
and ( a b -- ? )
or  ( a b -- ? )
not ( a -- ? )
```

```factor
t f and .   ! => f
t f or .    ! => t
f not .     ! => t
```

`f` est aussi la seule valeur *falsy* de Factor. Toutes les autres valeurs (chaînes de caractères vides, zéro, tableaux vides) sont considérées comme *truthy*.

[kernel]: https://docs.factorcode.org/content/vocab-kernel.html
