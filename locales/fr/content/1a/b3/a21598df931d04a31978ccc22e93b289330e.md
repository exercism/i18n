# Tests

  ## Aperçu rapide

  1. Fais tes modifications dans le fichier `<myFileName>.u`
  2. Enregistre le fichier `<myFileName>.u`
  3. Si le fichier passe la vérification de types, exécute les commandes `add` ou `update` de l'UCM
    * Si le fichier ne passe pas la vérification de types, modifie le code de ton fichier `<myFileName>.u` jusqu'à ce qu'il compile. N'oublie pas de faire `update` de tes fonctions après tes modifications !
  4. Exécute la commande `load <myFileName>.test.u` dans la CLI de l'UCM pour faire entrer les tests dans la portée et les exécuter

  ## Pas à pas

  Si tu travailles sur un problème Exercism en ligne de commande, tu implémenteras très probablement ta solution dans le répertoire portant le nom de l'exercice donné. Par exemple, si l'exercice est `hello-world`, tu dois lancer `ucm` depuis la ligne de commande après avoir fait `cd` dans `~/exercism/unison/hello-world`. Fais tes modifications dans le fichier `hello.u` et, quand ta solution te convient, saisis la commande `add` ou `update` dans la CLI du gestionnaire de base de code Unison (UCM) pour ajouter ton travail depuis le fichier dans la base de code.

  Le fichier qui contient les tests de chaque exercice a le suffixe `.test.u`. Tu voudras utiliser la commande `load` de l'UCM pour faire entrer les tests dans la portée et les exécuter. La commande `load` prend un chemin de fichier comme argument. Voici à quoi cela pourrait ressembler pour l'exercice hello world :

  ```
  .> load hello.test.u
  ```

  Tu devrais voir un message de l'UCM à propos des termes qui ont été amenés dans la portée et, surtout, le résultat de l'exécution du test :

  ```

    ⍟ These new definitions are ok to `add`:

      hello.test : Test.Test
      tests      : [Result]

  Now evaluating any watch expressions (lines starting with
  `>`)... Ctrl+C cancels.


    6 | test> tests = runAll [hello.test]

    🚫 FAILED
  ```

  Imaginons que tes tests n'ont pas réussi du premier coup. Reviens modifier ton fichier `myExercise.u` et, une fois le fichier enregistré, tu peux lancer `update` :

  ```
  I found and typechecked these definitions in ~/Exercism/unison/hello-world/hello.u. If you do an
  `add` or `update`, here's how your codebase would change:

    ⍟ These names already exist. You can `update` them to your new definition:

      hello : Text

  .> update

  ⍟ I've updated these names to your new definition:

    hello : Text
  ```

  Ensuite, on peut recharger nos tests pour voir si quelque chose a changé !

  ```
  .> load hello.test.u
    Now evaluating any watch expressions (lines starting with `>`)... Ctrl+C cancels.


    6 | test> tests = runAll [hello.test]

    ✅ Passed : Passed 1 tests.
  ```
