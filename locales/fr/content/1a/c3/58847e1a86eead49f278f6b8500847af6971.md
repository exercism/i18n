# Indices

## Général

- `MACRO:` se trouve dans [`macros`][macros]. Les briques de base se trouvent dans `kernel` (`dup`, `curry`), `sequences` (`append`, `concat`, `<repetition>`, `map`) et `quotations` (`>quotation`).
- Le corps d'une macro doit laisser **une seule _quotation_** sur la pile. Si ton corps produit un tableau de code, termine par `>quotation`.
- Pour vérifier ton raisonnement, exécute les mots du corps sur un littéral dans le _listener_ et regarde la _quotation_ que tu obtiens : elle doit correspondre au code linéaire de la ligne « se compile en » de la tâche.

## 1. En double

- Tu reçois `[ A ]` et tu veux `[ A A ]`. Fais une copie et joins-les : `dup append`.

## 2. N répétitions

- Tu reçois `[ A ] n` et tu veux `n` copies mises bout à bout.
- `<repetition>` construit les copies, mais son effet est `( length elt -- repetition )` : le compte doit être au sommet de la pile, donc `swap` d'abord.
- Ensuite, aplatis et convertis : `swap <repetition> concat >quotation`.

  ```factor
  ! stack: [ 1 + ] 3
  swap <repetition>     ! 3 copies of [ 1 + ]
  concat >quotation     ! => [ 1 + 1 + 1 + ]
  ```

## 3. Compose plusieurs

- Tu reçois déjà le tableau de _quotations_ ; il te suffit de l'aplatir en une seule. `concat >quotation` constitue tout le corps.

## 4. Itération déroulée

Tu reçois une séquence et une _quotation_, par exemple `{ 10 20 30 } [ + ]`, et tu veux `[ 10 + 20 + 30 + ]`. Construis-la en trois étapes.

**Un élément.** Intégrer un élément dans la _quotation_, c'est exactement ce que fait `curry` :

```factor
10 [ + ] curry .   ! => [ 10 + ]
```

**Chaque élément.** Tu veux appliquer ce `map` à la séquence, mais `map` ne transmet qu'une seule entrée à la _quotation_ de mappage (l'élément), alors qu'il te faut aussi `[ + ]` sous la main à chaque fois. Alors intègre d'abord `[ + ]` dans la _quotation_ de mappage, là encore avec `curry` :

```factor
! stack: { 10 20 30 } [ + ]
[ curry ] curry    ! => { 10 20 30 } [ [ + ] curry ]
map                ! runs  10 [ + ] curry,  20 [ + ] curry, …
                   ! => { [ 10 + ] [ 20 + ] [ 30 + ] }
```

`[ curry ] curry` se lit « pousse la petite _quotation_ `[ curry ]`, puis y intègre `[ + ]` avec `curry` », ce qui donne `[ [ + ] curry ]`. Appliquer ce mappage à un élément `e` exécute `e [ + ] curry`, ce qui équivaut à `[ e + ]`.

**Joins-les.** Même fin que pour les autres tâches :

```factor
concat >quotation  ! => [ 10 + 20 + 30 + ]
```

- Le corps complet : `[ curry ] curry map concat >quotation`.
