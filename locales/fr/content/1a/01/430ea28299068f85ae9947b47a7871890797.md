# Ne compare pas les valeurs booléennes à `true` ou `false`

Comparer des valeurs booléennes à `true` ou `false` est redondant.
L'utilisation de `==` produit une valeur booléenne, il est donc inutile de la comparer à une autre valeur booléenne « en dur », c'est-à-dire écrite directement dans le code.
Si tu veux inverser la valeur booléenne, utilise l'opérateur `!`.

```crystal
# Rather than:
some_bool == true
some_bool == false

# Consider:
some_bool
!some_bool
```
