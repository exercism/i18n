# Indices

## Général

- Un nombre à virgule flottante est renvoyé dans `xmm0`.
- Les 8 premiers arguments à virgule flottante sont passés dans les registres `xmm0` à `xmm7`.

## 1. Calcule le tarif journalier à partir d'un tarif horaire

- Un nombre à virgule flottante est renvoyé dans `xmm0`.
- Les 8 premiers arguments à virgule flottante sont passés dans les registres `xmm0` à `xmm7`.
- Un entier 64 bits peut être converti en un nombre à virgule flottante en double précision à l'aide de `cvtsi2sd`.
- Une valeur immédiate (un nombre constant) doit être stockée dans un registre à usage général avant d'être convertie en nombre à virgule flottante.
- Deux nombres à virgule flottante en double précision peuvent être multipliés avec `mulsd`.

## 2. Calcule un prix avec remise

- Un nombre à virgule flottante est renvoyé dans `xmm0`.
- Les 8 premiers arguments à virgule flottante sont passés dans les registres `xmm0` à `xmm7`.
- Deux nombres à virgule flottante en double précision peuvent être divisés avec `divsd`.
- Un nombre à virgule flottante en double précision peut être soustrait à un autre avec `subsd`.

## 3. Calcule le tarif mensuel à partir d'un tarif horaire et d'une remise

- Un nombre à virgule flottante est renvoyé dans `xmm0`.
- Les 8 premiers arguments à virgule flottante sont passés dans les registres `xmm0` à `xmm7`.
- On peut utiliser `roundsd` pour arrondir un nombre à virgule flottante en double précision, avec un troisième opérande qui indique le mode d'arrondi.
- Le nombre pour un arrondi vers le haut (plafond) est `2`.
- On peut utiliser `cvtsd2si` pour obtenir un entier 64 bits à partir d'un nombre à virgule flottante en double précision.

## 4. Calcule le nombre de jours travaillés à partir d'un budget, d'un tarif horaire et d'une remise

- Un nombre à virgule flottante est renvoyé dans `xmm0`.
- Les 8 premiers arguments à virgule flottante sont passés dans les registres `xmm0` à `xmm7`.
- On peut utiliser `roundsd` pour arrondir un nombre à virgule flottante en double précision, avec un troisième opérande qui indique le mode d'arrondi.
- Le nombre pour un arrondi vers le bas (plancher) est `1`.
- On peut utiliser `cvtsd2si` pour obtenir un entier 32 bits à partir d'un nombre à virgule flottante en double précision.
