# Instructions

Dans cet exercice, tu vas écrire du code pour garder une trace des langages de programmation que tu veux apprendre sur Exercism.
Tu as six tâches, qui vont toutes te demander de manipuler des tableaux.

## 1. Crée un nouveau tableau

Pour garder une trace des langages que tu veux apprendre, tu vas devoir créer un nouveau tableau.
Définis la constante `newList` qui contient un nouveau tableau vide.

```elm
newList
    --> []
```

## 2. Définis un tableau existant

Pour l'instant, tu as une feuille de papier sur laquelle sont listés les langages que tu veux apprendre : Elm, Clojure et Haskell.
Définis la constante `existingList` pour représenter ce tableau.

```elm
existingList
    --> [ "Elm", "Clojure", "Haskell" ]
```

## 3. Ajoute un nouveau langage à un tableau

Au fur et à mesure que tu explores Exercism et que tu découvres des langages plus intéressants, tu vas vouloir les ajouter à ton tableau.
Implémente la fonction `addLanguage` pour ajouter un nouveau langage au début du tableau.

```elm
addLanguage "TypeScript" [ "JavaScript", "CoffeeScript" ]
    --> [ "TypeScript", "JavaScript", "CoffeeScript" ]
```

## 4. Compte les langages du tableau

Compter les langages à la main n'est pas pratique.
Implémente la fonction `countLanguages` pour compter le nombre de langages dans le tableau.

```elm
countLanguages [ "C#", "Racket", "Rust", "Ruby" ]
    --> 4
```

## 5. Inverse le tableau

À un moment donné, tu te rends compte que ton tableau est en fait rangé à l'envers !
Implémente la fonction `reverseList` pour inverser ton tableau.

```elm
reverseList [ "Prolog", "C", "Idris", "Assembly" ]
    --> [ "Assembly", "Idris", "C", "Prolog" ]
```

## 6. Vérifie si un tableau est passionnant

Même si tu aimes tous les langages, Elm occupe une place particulière dans ton cœur.
Pour cette raison, un tableau de langages te passionne vraiment si :

- Le premier élément du tableau est Elm.
- Ou bien si le deuxième élément du tableau est Elm et que le tableau contient trois langages ou moins.

Implémente la fonction `excitingList` pour vérifier si un tableau de langages est passionnant :

```elm
excitingList [ "Nim", "Elm" ]
    --> True
```
