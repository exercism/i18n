# Débogue

Pour t'aider à déboguer, sache que toute la sortie de la console est capturée et affichée dans la fenêtre des résultats des tests.
Tu peux afficher n'importe quelle valeur en la passant à `@show`.

`@show` affiche une expression et son résultat, tout en renvoyant ce résultat.

```julia
@show uppercase("hello") # HELLO will be shown as debug output
```

```julia-repl
julia> function f(a, b)
           @show a b
           return (@show a^b) / 1000
       end
f (generic function with 1 method)

julia> f(3, 5)
a = 3
b = 5
a ^ b = 243
0.243
```

Tu peux aussi utiliser [`println`](https://docs.julialang.org/en/v1/base/io-network/#Base.println) ou toute autre méthode qui écrit sa sortie vers [`stdout`](https://en.wikipedia.org/wiki/Standard_streams#Standard_output_(stdout)).
