# Introduction

C# dispose d'opérateurs intégrés pour les opérations mathématiques habituelles :

- `+` : addition
- `-` soustraction
- `/` : division
- `*` : multiplication
- `%` : modulo

Il existe également deux opérateurs spéciaux :

- `++` : incrémentation
- `--` : décrémentation

Ces deux opérateurs ajoutent et retranchent respectivement un à une valeur.
