# Introduction
## L'instruction `switch`

Une [instruction `switch`][switch] permet de comparer une valeur à plusieurs valeurs correspondantes possibles.
Elle permet d'écrire du code plus concis qu'en enchaînant plusieurs instructions `else-if`.
Une instruction `switch` commence par le mot-clé `switch`, suivi de la valeur à comparer.
On définit ensuite les cas avec le mot-clé `case`, suivi de la valeur à laquelle se comparer.
Le mot-clé `default` sert à définir le cas par défaut, lorsque aucun des cas ne correspond.
Comme les instructions `else-if`, les instructions `switch` n'exécutent que le bloc de code associé au premier cas qui correspond.

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

Prenons l'exemple suivant :

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

On pourrait plutôt l'écrire comme ceci :

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```

## Les boucles _while_

Une [boucle _while_][while-loops] est une instruction de contrôle de flux qui permet d'exécuter du code tant qu'une certaine condition est vraie.
Swift propose deux sortes de boucles _while_ : les boucles _while_ et les boucles _repeat-while_.
La condition d'une boucle _while_ est évaluée avant l'exécution du corps de la boucle ; si la condition est fausse, le corps de la boucle ne sera pas exécuté du tout.
Les boucles _while_ en Swift ont la structure suivante :

```swift
while <#condition#> {
  <#code#>
}
```

Ici, la boucle s'exécute tant que count est supérieur à 0, et affiche donc les nombres 2, 1 et « Liftoff! ».

```swift
var count = 2
while count > 0 {
  print("\(count)…")
  count -= 1
}
print("Liftoff!")

// prints:
// 2…
// 1…
// Liftoff!
```

Une [boucle _repeat-while_][while-loops] est semblable à une boucle _while_, mais la condition est évaluée après l'exécution du corps de la boucle.
Cela signifie que le corps de la boucle s'exécute toujours au moins une fois, même si la condition est fausse.
Les boucles _repeat-while_ en Swift ont la structure suivante :

```swift
repeat {
  <#code#>
} while <#condition#>
```

Ici, la boucle ne s'exécute qu'une seule fois, puisque la condition est fausse.
Comme il s'agit d'une boucle _repeat-while_, le corps de la boucle s'exécute une fois avant que la condition ne soit évaluée.

```swift
var count = 2
repeat {
  print("\(count)…")
} while count < 0
print("Liftoff!")
```

## Le transfert de contrôle

Swift dispose d'un ensemble d'instructions qui permettent de modifier le déroulement normal des boucles.
On les appelle les instructions de transfert de contrôle.
Tu as déjà vu `return` ; ce concept en présente d'autres, notamment `continue`, `break` et les étiquettes.
On ne traite pas de `fallthrough` dans ce concept, mais tu peux en lire plus dans le [livre Swift][fallthrough].

### Continue

Il est parfois nécessaire de passer directement à l'itération suivante d'une boucle, sans exécuter le reste des instructions de l'itération en cours.
Le mot-clé `continue` permet de le faire.
Lorsque `continue` est exécuté, la boucle passe à la vérification suivante pour savoir si l'itération suivante peut avoir lieu, c'est-à-dire le `while` des boucles _while_ et _repeat-while_, ou la vérification de la présence d'un autre élément dans la séquence, pour les boucles _for-in_.

```swift
count = 1
while count < 6 {
  count += 1
  if count == 4 { continue }
  print(count)
}

// prints:
// 2
// 3
// 5
```

### Break

L'instruction `break` sert à sortir d'une boucle de façon anticipée.
Lorsque `break` est exécuté, la boucle se termine immédiatement et le programme poursuit avec la première instruction qui suit la boucle.

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  if !fruit.count.isMultiple(of: 2) { break }
  print(fruit)
}

// prints:
// banana
// grapes
```

### Étiquettes

Lorsque des boucles sont imbriquées, il arrive que l'on veuille utiliser `break` ou `continue` pour sortir ou redémarrer une boucle externe qui contient la boucle dans laquelle `break` ou `continue` est utilisé.
Dans ce genre de cas, on peut utiliser des étiquettes pour préciser la boucle à quitter ou à redémarrer.
On peut étiqueter une boucle en plaçant un nom suivi de deux-points devant le `while`, le `repeat` ou le `for` qui débute la boucle.

Pour voir l'effet d'étiquettes utilisées de cette façon, considère la boucle suivante.

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  print("\n--- \(fruit) ---")
  for letter in fruit {
    guard letter != "n" else { break outerLoop }
    print(letter)
  }
}

// prints:
// --- banana ---
// b
// a
```
