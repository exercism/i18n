# Introduction

PowerShell est un langage de script dynamique et à typage implicite _(mais qui prend aussi en charge les variables [fortement typées][strong typed])_, développé par Microsoft, principalement axé sur l'automatisation des tâches et la gestion de la configuration.

PowerShell prend en charge la programmation impérative, fonctionnelle, orientée objet, et même le style _pipeline_.

PowerShell repose sur la plateforme .NET et a été publié pour la première fois en 2006.
Il est inclus par défaut dans tous les systèmes Windows modernes, et peut aussi être installé sur Mac et Linux.


## Variables

Il existe deux façons courantes de définir une variable en PowerShell.

Les noms de variables en PowerShell doivent commencer par un `$`, et utilisent l'opérateur d'affectation `=` pour lier le nom de la variable à une valeur.

```powershell
> $intVar = 1
> $doubleVar = 2.0
> $stringVar = "Hello"

# Checking a variable type using the GetType() method
> Write-Host $doubleVar.GetType()
System.Double
```

On peut aussi préciser explicitement le type d'une variable, pour imposer ou exiger que sa valeur soit d'un certain type.
PowerShell fera de son mieux pour convertir la valeur d'un type à un autre quand c'est possible.

```powershell
# String represents a floating number can be converted to integer
> [int]$staticOne = "1.234"
> $staticOne
1

# String of letters can not be converted to double type
> [double]$staticTwo = "hello"
MetadataError: Cannot convert value "hello" to type "System.Double"
```


### Constantes

En PowerShell, les constantes sont des variables qui ne peuvent être ni **modifiées** ni **supprimées** après leur définition.
Cela nous amène à la seconde façon de définir des variables : utiliser la cmdlet `New-Variable`.

```powershell
> New-Variable -Name "MyConstant" -Value 100 -Option Constant
> $MyConstant
```

Pour des méthodes plus détaillées et avancées de création d'une variable, consulte [New-Variable][New-Variable].


## Fonctions

Les [fonctions][functions] en PowerShell se définissent avec le mot-clé `function`.
Chaque fonction peut prendre zéro ou plusieurs paramètres formels entre parenthèses `()`, suivis de la portée de la fonction, qui commence par `{` et se termine par `}`.

```powershell
function Greeting {
    return "Hello!"
}
```

En PowerShell, les fonctions peuvent renvoyer des valeurs explicitement avec le mot-clé `return`, une fois appelées avec la syntaxe `FuncName $Arg`.

```powershell
function AddTwoNumbers($NumOne, $NumTwo):
    $result = $NumOne + $NumTwo
    return $result

> AddTwoNumbers 10 20
30
```

Un aperçu plus avancé de la façon d'écrire une définition de fonction détaillée, et de la manière dont les fonctions peuvent renvoyer des valeurs implicitement, sera abordé dans le module de concept `Functions`.


## Commentaires

Les commentaires d'une seule ligne en PowerShell commencent par un `#` et se terminent en fin de ligne.
Les blocs de commentaires en PowerShell commencent par `<#` et se terminent par `#>`.
Un exemple avancé de bloc de commentaires servant à créer de l'aide basée sur les commentaires sera abordé dans le module de concept `Functions`.

```powershell
function Main() {
    #This is a comment
    <#
    And this is a comment block
    that can span multiple lines
    #>
}
```
