# Introduction

## Constantes et fonctions

Une valeur constante se définit avec `name = expression`, puisqu'en Elm, tout ce qui n'est pas une définition est une expression.

```elm
five = 5

six = 3 + 3
```

Les fonctions se définissent avec `name parameters... = expression`, les paramètres étant uniquement séparés par des espaces.

```elm
add number1 number2 = number1 + number2
```

Appeler une fonction est aussi une expression : on écrit son nom, puis on passe des arguments pour chacun des paramètres de la fonction, séparés par des espaces, exactement comme pour la définition d'une fonction.

```elm
five = add 2 3
```

Les parenthèses permettent de préciser l'ordre d'évaluation d'une expression.

```elm
six = add 2 (1 * 4)

twelve = add 2 1 * 4
```

## Indentation / espaces significatifs

Elm n'utilise pas de marqueurs syntaxiques comme les accolades, les parenthèses ou les points-virgules pour délimiter le code. À la place, il utilise les espaces et les indentations.

- Les définitions de module, d'import et de fonction de premier niveau doivent commencer à la colonne la plus à gauche.
- Si une expression est répartie sur plusieurs lignes, le code qui fait partie de cette expression doit être indenté sous cette expression d'au moins un espace.
- Les parties de l'expression qui vont ensemble doivent être indentées avec le même nombre d'espaces.

```elm
-- A function split over multiple lines, so subsequent lines must be indented
add number1 number2 =
    number1 + number2
```

https://elmprogramming.com/indentation.html

## Modules

Chaque fichier en Elm est un module et doit contenir une instruction `module` avant tout autre code.
Le nom des modules doit correspondre au nom de leur fichier : le module `Calculator` doit donc se trouver dans le fichier Calculator.elm.
Tout ce qui est défini dans un module a une portée privée à ce module et n'est pas accessible depuis l'extérieur, à moins d'être listé dans `exposing`.

```elm
-- Define the Calculator module, and expose the `add` function
module Calculator exposing (add)

six = 3 + 3

add number1 number2 = number1 + number2
```

```elm
-- Define the Calculator module, and expose everything within: `six` and `add`
module Calculator exposing (..)

six = 3 + 3

add number1 number2 = number1 + number2
```

https://elm-lang.org/docs/syntax#modules

## Commentaires

Un commentaire est un texte dans le fichier Elm qui n'est pas interprété comme du code.
Il est principalement destiné à être lu par toi-même et par les autres programmeurs.
Il existe une syntaxe légère pour les commentaires sur une seule ligne, basée sur les doubles tirets.
Les commentaires multilignes sont aussi possibles avec la paire de délimiteurs d'ouverture et de fermeture `{-` et `-}`.

```elm
-- a single line comment
-- another single line comment

{- a multiline comment
   spawning multiple lines
-}
```
