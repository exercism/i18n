# Indices

## Général

- Tu peux accomplir toutes ces tâches sans utiliser d'instruction `if`.

## 1. Détermine si tu auras besoin d'un permis de conduire

- Utilise l'[opérateur d'égalité][cmp] pour vérifier si le premier champ est égal à une _string_ donnée.
- Utilise une expression régulière pour vérifier si le second champ contient les sous-chaînes requises.
- Utilise l'un des deux [opérateurs booléens][bool] pour combiner les deux conditions.

## 2. Calcule une estimation du prix d'un véhicule d'occasion

- Utilise les [opérateurs de comparaison][cmp] pour déterminer quelle réduction appliquer.

[cmp]: https://www.gnu.org/software/gawk/manual/html_node/Comparison-Operators.html
[bool]: https://www.gnu.org/software/gawk/manual/html_node/Boolean-Ops.html
