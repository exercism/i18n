# Instructions

Dans cet exercice, on va simuler un système informatique à base de fenêtres.
Tu vas créer des fenêtres que l'on peut déplacer et redimensionner.
L'image suivante illustre les valeurs avec lesquelles tu vas travailler ci-dessous.


## 1. Définis les propriétés de la fenêtre de programme

À l'aide du squelette de classe fourni, définis les propriétés correspondant aux valeurs `y`, `x`, `height` et `width`.

```php
<?php

$window = new ProgramWindow();
$window->y; // => null
$window->x; // => null
$window->height; // => null
$window->width; // => null
```

## 2. Définis les valeurs initiales de la fenêtre de programme

Définis une fonction constructeur pour `ProgramWindow`.
Elle ne doit prendre aucun argument, mais pendant l'exécution du constructeur, définis les valeurs par défaut de ses propriétés.
Elle doit initialiser les valeurs `y` et `x` à `0`.
Elle doit initialiser `height` et `width` à une taille d'écran de `600x800`.

```php
<?php

$window = new ProgramWindow();
$window->y; // => 0 
$window->x; // => 0
$window->height; // => 600
$window->width; // => 800
```

## 3. Définis une fonction pour redimensionner la fenêtre

Définis une nouvelle classe dans `Size.php` pour une classe Size.
Elle doit prendre des arguments de constructeur pour définir les propriétés `height` et `width`.
De plus, `ProgramWindow` nécessite une fonction de redimensionnement, qui reçoit l'instance de l'objet `Size` et met à jour ses propres propriétés.

```php
<?php 

$window = new ProgramWindow();
$size = new Size(764, 1080);
$window->resize($size)

$window->height;
// => 764
$window->width;
// => 1080
```

## 4. Définis une fonction pour déplacer la fenêtre

Définis une nouvelle classe dans `Position.php` pour une classe Position.
Elle doit prendre des arguments de constructeur pour définir les propriétés `y` et `x`.
De plus, `ProgramWindow` nécessite une fonction de déplacement, qui reçoit l'instance de l'objet `Position` et met à jour ses propres propriétés.

```php
<?php 

$window = new ProgramWindow();
$position = new Position(80, 313);
$window->move($position)

$window->y;
// => 80
$window->x;
// => 313
```
