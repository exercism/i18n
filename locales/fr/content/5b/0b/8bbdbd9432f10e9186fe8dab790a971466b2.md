# Instructions

Le nouvel aéroport de Berlin a recruté des développeurs pour son laboratoire de robotique, et tu y commences ton travail.
Il dispose de robots maladroits, à l'allure quelque peu humanoïde, qu'il essaie d'utiliser pour améliorer le service client.

Ta première mission consiste à écrire un programme pour que le robot puisse saluer les gens dans leur langue maternelle après qu'ils ont scanné leur passeport à la borne d'enregistrement automatique.

Le robot est fier de ses capacités, alors il annonce toujours d'abord la langue qu'il parle, puis il salue la personne.
Par exemple, si quelqu'un scanne un passeport allemand, le robot dira :

```txt
I can speak German: Hallo Dietrich!
```

## 1. Crée la fonctionnalité de salutation abstraite

Tu n'écriras pas toi-même le code des différentes langues, tu dois donc structurer le code du robot pour que d'autres développeurs puissent facilement ajouter d'autres langues par la suite.

Pour commencer, définis une interface `Greeter` avec deux méthodes.

- `LanguageName`, qui renvoie le nom de la langue (une `string`) dans laquelle le robot est censé accueillir le visiteur.
- `Greet`, qui prend le nom d'un visiteur (une `string`) et renvoie une `string` contenant le message de salutation dans une langue spécifique.

Ensuite, implémente une fonction `SayHello` qui prend en arguments le nom du visiteur et tout ce qui implémente l'interface `Greeter`, et qui renvoie la `string` de salutation souhaitée.
Par exemple, imagine une implémentation de `Greeter` en allemand pour laquelle `LanguageName` renvoie `"German"` et `Greet` renvoie `"Hallo {name}!"` :

```go
SayHello("Dietrich", germanGreeter)
// => "I can speak German: Hallo Dietrich!"
```

## 2. Implémente l'italien

Maintenant, ton travail consiste à faire fonctionner le robot pour les personnes qui scannent un passeport italien.

Pour cela, crée une structure `Italian` et implémente les deux méthodes nécessaires pour que cette structure satisfasse l'interface `Greeter` que tu as mise en place dans la tâche 1.
Tu peux saluer quelqu'un en italien avec `"Ciao {name}!"`.

## 3. Implémente le portugais

Avant de terminer ta journée, tu dois aussi finir la fonctionnalité qui permet de saluer les gens en portugais.

Pour cela, crée une structure `Portuguese` et implémente ici aussi les deux méthodes nécessaires pour que cette structure satisfasse l'interface `Greeter`.
Tu peux saluer quelqu'un en portugais avec `"Olá {name}!"`.
