# Introduction

Factor modélise les dates et les heures avec le vocabulaire [`calendar`][calendar]. Un instant précis est un `timestamp` ; une durée est un `duration`.

## Construis une date

`<date>` (dans [`calendar`][calendar]) construit un `timestamp` à minuit le jour donné :

```
<date> ( year month day -- timestamp )
```

```factor
USING: calendar ;

1904 11 16 <date> .
! a timestamp at midnight on 1904-11-16
```

`>date<` décompose un timestamp en ses différentes parties :

```
>date< ( timestamp -- year month day )
```

```factor
1904 11 16 <date> >date< .   ! => 16   (with 1904 and 11 below it)
```

## Inspecte une date

`day-of-week` renvoie le jour de la semaine sous forme d'un entier, `0` pour dimanche jusqu'à `6` pour samedi. `day-names` (dans [`calendar.english`][english]) est la liste de noms correspondante, donc `day-names nth` transforme le nombre en un mot :

```factor
USING: calendar calendar.english sequences ;

2024 1 8 <date> day-of-week .          ! => 1
day-names .   ! { "Sunday" "Monday" ... "Saturday" } — Sunday first
```

`leap-year?` accepte une année (ou un timestamp) et `days-in-month` renvoie la longueur du mois d'un timestamp, en tenant déjà compte des années bissextiles :

```
leap-year?    ( obj -- ? )
days-in-month ( timestamp -- n )
```

```factor
2024 leap-year? .                ! => t
2024 2 1 <date> days-in-month .  ! => 29
```

## Arithmétique des dates

Des mots comme `days`, `weeks` et `hours` construisent une `duration`, et `time+` décale un timestamp de cette durée :

```
days  ( x -- duration )
time+ ( timestamp duration -- timestamp )
```

```factor
2024 2 28 <date> 1 days time+ >date< .
! => 29   (2024-02-29, with 2024 and 2 below it)
```

L'arithmétique se propage correctement à travers les limites de mois et d'année, et deux timestamps qui désignent le même instant sont égaux avec `=`.

## Heures de la journée

`<timestamp>` construit un timestamp complet, jusqu'à la seconde près. Son dernier argument est le décalage par rapport à UTC ; `instant` (une `duration` nulle) garde le timestamp à UTC :

```
<timestamp> ( year month day hour minute second gmt-offset -- timestamp )
```

```factor
USING: calendar ;

1969 7 21 2 56 15 instant <timestamp> .
! a timestamp at 02:56:15 on 1969-07-21
```

`>time<` est le pendant de `>date<`, il décompose un timestamp en heure, minute et seconde :

```
>time< ( timestamp -- hour minute second )
```

```factor
1969 7 21 2 56 15 instant <timestamp> >time< .   ! => 15   (with 2 and 56 below it)
```

`seconds` et `minutes` construisent une `duration` exactement comme `days`, `weeks` et `hours`, donc n'importe lequel d'entre eux peut être passé à `time+` :

```
seconds ( x -- duration )
minutes ( x -- duration )
```

Les champs individuels d'un timestamp se lisent avec les accesseurs `year>>`, `month>>`, `day>>`, `hour>>`, `minute>>` et `second>>` :

```factor
1969 7 21 2 56 15 instant <timestamp> hour>> .   ! => 2
```
