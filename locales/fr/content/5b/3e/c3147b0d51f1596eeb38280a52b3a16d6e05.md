# Indices

## Généralités

- Lis la section sur le [filtrage par motif][pattern-matching] dans le guide officiel.
- Jette un œil à cette antisèche sur la [déstructuration][destructuring].
- Le filtrage par motif sur les enregistrements est [expliqué plus en détail ici][records-pattern-matching].

## 1. Détecte les commentaires vides

- Tu peux utiliser `(a, b)` directement comme argument de la fonction si cet argument est un couple.
- Tu peux remplacer les valeurs que tu reçois mais que tu n'utilises pas par le joker `_`.
- Pour vérifier si une _string_ est vide, consulte la [documentation de `String`][string-docs].

## 2. Compte le nombre de commentaires du créateur

- Tu peux déstructurer un type personnalisé à une seule variante `type Box = Box AB` directement dans un argument de fonction, comme ceci : `(Box ab)`.
- Tu peux faire un filtrage par motif sur le champ `a` d'un enregistrement `{a : A, b : B}` en écrivant : `{ a }`.
- Tu peux utiliser les deux techniques ci-dessus en même temps pour les types personnalisés qui contiennent un enregistrement.
- Tu ne peux pas faire directement un filtrage par motif sur le couple `ab` d'un enregistrement `{ ab : (A, B) }`. Tu dois d'abord faire un filtrage par motif sur `{ ab }`, puis utiliser `( a, b) = ab` dans une liaison `let`.
- Pour trouver le nombre d'éléments d'un tableau qui satisfont une condition, utilise les [fonctions de `List`][list-docs].
- Tu peux déstructurer des couples directement dans les arguments d'une fonction anonyme.

## 3. Détecte les tickets assignés à la Dev Team

- Comme dans la tâche 2, tu peux faire correspondre les champs pertinents d'un enregistrement « encapsulé » dans l'argument de la fonction.
- Tu peux faire du filtrage par motif de façon récursive pour faire correspondre une valeur imbriquée comme `Just (Box "42")`.
- Tu peux utiliser le joker `_` pour faire correspondre n'importe quoi dans une instruction `case`.

## 4. Assigne les tickets aux employés de l'IT

- Comme dans les tâches 2 et 3, tu peux faire correspondre les champs pertinents d'un enregistrement « encapsulé » dans l'argument de la fonction.
- De plus, tu peux utiliser le mot-clé `as` pour faire un filtrage par motif sur un champ et lier en même temps l'enregistrement entier : `(Box ({ a } as ab))`.
- Tu peux faire un filtrage par motif sur les valeurs d'un type personnalisé avec une instruction `case`.
- Utilise le constructeur de type `Ticket` pour renvoyer un ticket.
- Utilise la [syntaxe de mise à jour d'enregistrement][record-update] pour modifier des enregistrements.
