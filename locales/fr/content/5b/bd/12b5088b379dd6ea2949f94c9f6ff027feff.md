# Instructions

Dans cet exercice, tu vas écrire un coffre au trésor générique (et magique !) pour y ranger quelques trésors.

## 1. Définis le type personnalisé générique TreasureChest

Définis un type personnalisé `TreasureChest` avec une seule variante.

Cette variante doit avoir une valeur `String` associée, qui servira à stocker le mot de passe du coffre au trésor.

La variante doit aussi avoir une valeur générique associée, qui servira à stocker le trésor.
Cette valeur est générique pour que le trésor puisse être n'importe quoi.

## 2. Définis la fonction getTreasure

Cette fonction prend deux paramètres

- une `String` (pour essayer un mot de passe)
- un type personnalisé générique `TreasureChest`

Cette fonction doit vérifier la tentative de mot de passe fournie par rapport à la `String` contenue dans le `TreasureChest`.

La fonction renvoie un `Maybe`.

Si les mots de passe correspondent, renvoie `Just` avec la valeur générique du `TreasureChest` (le trésor !)

Si les mots de passe ne correspondent pas, renvoie `Nothing`.

## 3. Définis la fonction multiplyTreasure

Cette fonction (d'ordre supérieur) prend deux paramètres

- une fonction de multiplication qui prend un paramètre générique et renvoie un tableau du même type générique
- un type personnalisé générique `TreasureChest`, également avec le même type générique

Cette fonction doit appeler la fonction de multiplication avec le trésor qui se trouve dans le coffre.

La fonction renvoie un nouveau TreasureChest, avec le même mot de passe que l'original et avec le trésor multiplié (la valeur de retour)
