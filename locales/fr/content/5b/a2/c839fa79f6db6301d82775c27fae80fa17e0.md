# Instructions (suite)

## Indices

Dans cet exercice, on a fourni la définition du
[type de données algébrique](https://learnyouahaskell.github.io/making-our-own-types-and-typeclasses)
nommé `Planet`.
Tu dois implémenter la fonction `ageOn`, qui calcule quel âge aurait une personne
sur une `Planet`, à partir d'un âge en secondes.

Tu peux utiliser la signature fournie si tu as un doute sur les types, mais
ne la laisse pas brider ta créativité :

```haskell
ageOn :: Planet -> Float -> Float
```
