# À propos

En Haxe, une `class` est la principale structure de données : elle encapsule des données (les champs) et un comportement (les méthodes). Les champs et les méthodes sont aussi appelés les membres d'une classe.

L'accès aux membres peut être restreint à l'aide de [modificateurs d'accès][visibility], qui sont :

- `public` : le membre est accessible depuis n'importe où.
- `private` : le membre n'est accessible que depuis la même classe.

On peut voir les classes comme des modèles servant à créer des instances. Pour créer une [instance][class-instance], il suffit d'utiliser le mot-clé `new` :

```haxe
class Car {
  public function new() {}
}

var myCar = new Car();
var yourCar = new Car();
```

Pour définir un champ, on utilise un modificateur d'accès suivi du nom et du type de la variable :

```haxe
class Car {
  public var weight:Int; // Accessable by anyone

  private var color:String; // Accessable only within this class
}
```

Il est aussi possible de définir une valeur initiale au moment de déclarer un champ. Si un champ n'a pas de valeur initiale, il prend la valeur `null`. On accède à un champ à l'aide de la notation pointée :

```haxe
class Car {
  public var weight:Int = 2500; // Weight will be set to 2500
  public var year:Int; // year will be null

  public function new() {}
}

var newCar = new Car();
newCar.weight; // 2500
newCar.year; // null

// Update value of field
newCar.year = 2020;
```
