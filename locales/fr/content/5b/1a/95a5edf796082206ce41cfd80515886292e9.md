# Introduction

Factor est un langage *concaténatif* : chaque mot lit ses entrées depuis une **pile de données** partagée et y renvoie ses sorties. Il n'y a pas d'autre façon de faire circuler des valeurs.

Écrire un littéral le pousse au sommet de la pile ; le code se lit de gauche à droite :

```factor
1 2 3    ! stack (bottom → top): 1 2 3
```

Une déclaration d'*effet de pile* documente le contrat d'un mot :

```factor
: restow ( a b -- b a ) swap ;
```

`( a b -- b a )` indique que le mot dépile deux valeurs et en laisse deux dans l'autre ordre. Les noms relèvent de la documentation, seul le *nombre* d'entrées et de sorties est vérifié par le compilateur, et le sommet de la pile correspond au nom de droite.

Les **mots de réorganisation** du `kernel`, ceux que l'on utilise tous les jours, réarrangent le sommet de la pile :

```
dup  ( x   -- x x   )
drop ( x   --       )
swap ( x y -- y x   )
over ( x y -- x y x )
nip  ( x y -- y     )
rot  ( x y z -- y z x )
```

Les mots se définissent avec `:` et se terminent par `;` ; le compilateur refuse une définition dont le corps ne correspond pas à l'effet déclaré.
