# Introduction

Les énumérations en Swift sont un mécanisme qui permet de créer de nouveaux types dont les valeurs possibles sont un nombre fini de valeurs nommées, lesquelles peuvent porter des informations associées supplémentaires, et auxquelles on peut attacher des propriétés et des méthodes.

## Définis des énumérations

Les énumérations les plus simples se définissent comme ci-dessous.

```swift
enum NESButton {
  case up
  case down
  case left
  case right
  case a
  case b
  case select
  case start
}
```

Pour plus de concision, plusieurs cas peuvent aussi être écrits sur une seule ligne, séparés par des virgules, avec un seul mot-clé `case`.

```swift
enum NESButton {
  case up, down, left, right, a, b, select, start
}
```

Cela définit un nouveau type nommé `NESButton` avec les valeurs possibles `up`, `down`, `left`, `right`, `a`, `b`, `select` et `start`. Ces valeurs peuvent être désignées en faisant suivre le nom du type d'un point (`.`) et de la valeur. Lorsque le nom du type peut être déduit, seuls le point et la valeur sont nécessaires.

## Méthodes

Comme les autres types en Swift, les énumérations peuvent contenir des méthodes qui leur permettent de fournir des fonctionnalités en fonction de leur valeur actuelle.

Les méthodes sont analogues à des fonctions, à ceci près qu'elles sont définies à l'intérieur du corps de l'énumération et qu'elles sont liées à la valeur actuelle de l'énumération. On y accède via la notation pointée, où le nom de la valeur de l'énumération est suivi d'un point (`.`) puis du nom de la méthode et de ses paramètres.

À l'intérieur de la méthode, la valeur de l'énumération peut être désignée par `self`, et dans la signature de type, si l'on accepte en paramètre ou renvoie une valeur de cette énumération, on peut désigner le type par `Self`.

### Initialiseurs

Les initialiseurs sont des méthodes spéciales qui servent à initialiser une valeur de l'énumération. Leur définition ressemble beaucoup à celle d'une méthode, sauf qu'il n'y a pas de mot-clé `func`, pas de type de retour, et que le nom doit être `init`, et que l'initialiseur _doit_ affecter une valeur de l'énumération à `self`. Les initialiseurs s'appellent soit via la notation pointée, soit en passant les paramètres de l'initialiseur au nom de l'énumération.

```swift
enum Coin {
  case heads
  case tails

  init(_ i: Int) {
    if i.isMultiple(of: 2) {
      self = .heads
    } else {
      self = .tails
    }
  }

  func flip() -> Self {
    switch self {
    case .heads: return .tails
    case .tails: return .heads
    }
  }
}

let tails = Coin.init(13)
// .tails
let heads = Coin(0)
// .heads
let anotherTails = heads.flip()
// .tails
```

### Valeurs brutes

Les énumérations peuvent aussi porter une valeur interne appelée _valeur brute_. Les valeurs brutes doivent toutes être du même type, qui est déclaré dans la définition de l'énumération. On pourrait donc affecter, par exemple, des valeurs de type Character à notre énumération `NESButton` en modifiant la définition :

```swift
enum NESButton: Character {
  case up = "⬆️"
  case down = "⬇️"
  case left = "⬅️"
  case right = "➡️"
  case a = "🅰️"
  case b = "🅱️"
  case select = "✅"
  case start = "🚦"
}
```

Ici, `: Character` indique au compilateur que les valeurs brutes seront de type `Character` et que l'affectation de la valeur brute suit chaque valeur.

On peut accéder aux valeurs brutes via la propriété `rawValue` générée automatiquement pour chaque valeur.

```swift
NESButton.left.rawValue
// => "⬅️"
NESButton.b.rawValue
// => "🅱️"
```

Swift peut affecter implicitement des valeurs brutes pour les valeurs brutes de type `String` et `Int`. Si un type de valeur brute `String` est spécifié, la valeur brute sera implicitement affectée au nom de la valeur, sous forme de String, à moins que la valeur implicite ne soit remplacée par une affectation explicite.

Si un type de valeur brute `Int` est spécifié, la valeur brute sera implicitement affectée à un entier supérieur de 1 à la valeur brute du cas précédent, à moins d'être remplacée par une affectation explicite. La valeur brute par défaut du premier cas est 0, sauf indication contraire.

```swift
enum Coin: String {
  case heads
  case tails = "eagle"
}

Coin.heads.rawValue
// => "heads"
Coin.tails.rawValue
// => "eagle"

enum Dwarf: Int {
  case grumpy, sleepy, sneezy, happy = 8, bashful, dopey, doc
}

Dwarf.grumpy.rawValue
// => 0
Dwarf.sneezy.rawValue
// => 2
Dwarf.happy.rawValue
// => 8
Dwarf.bashful.rawValue
// => 9
```
