# Getters et setters

Les getters et les setters sont des méthodes qui permettent de lire et d'écrire la valeur d'une propriété d'un objet.
Crystal dispose de macros, ce qui facilite la définition de getters et de setters pour une propriété.
Les macros permettent de générer du code à la compilation, un sujet que nous aborderons plus tard dans le concept sur les macros.

En Ruby, ces méthodes se définissent avec les méthodes `attr_reader`, `attr_writer` et `attr_accessor`, et elles ressemblent beaucoup, en apparence, à l'implémentation qu'en fait Crystal.
Crystal les a définies sous forme de macros `getter`, `setter` et `property`.

## Getters

`getter` est une macro qui définit une méthode renvoyant la valeur d'une variable d'instance.
On n'a donc plus besoin d'écrire `@` devant la variable d'instance pour y accéder (dans les méthodes, sauf initialize), il suffit d'appeler la méthode définie par la macro `getter`.

La macro `getter` accepte plusieurs variables d'instance, à séparer par des virgules.

```crystal
# This:
class Person
  @name : String
  @age : Int32

  def name
    @name
  end

  def age
    @age
  end
end

# Is the same as this:
class Person
  @name : String
  @age : Int32

  getter name, :age
end
```

Comme tu peux le voir, utiliser `getter` réduit la quantité de code à écrire et le rend plus facile à lire.
Autre différence entre Ruby et Crystal : Crystal accepte aussi bien le nom de la variable que le symbole comme arguments de la macro `getter`.
Les symboles seront traités plus tard, dans le concept sur les symboles.

## Setters

`setter` est une macro qui définit une méthode chargée d'affecter une valeur à une variable d'instance.
Cette macro est assez rare : c'est en général la macro `property` que l'on utilise à la place.
Les méthodes ainsi créées ressemblent à `name_of_method=` ; c'est le `=` qui permet de définir la propriété.

Cette définition de méthode est un peu particulière, car l'argument reçu par la méthode vient après le signe `=`.
Plusieurs autres méthodes particulières de Crystal utilisent cette syntaxe, comme la méthode `+`.

Comme pour la macro `getter`, une fois le `setter` défini, tu peux appeler la méthode créée par cette macro pour mettre à jour la valeur d'une variable d'instance.

```crystal
# This:
class Person
  @name : String
  @age : Int32

  def name=(name : String)
    @name = name
  end

  def age=(age : Int32)
    @age = age
  end
end

# Is the same as this:
class Person
  @name : String
  @age : Int32

  setter name, :age
end
```

## Property

`property` est une macro qui définit à la fois un getter et un setter pour une variable d'instance.

```crystal
class Person
  @name : String
  @age : Int32

  property name, :age
end
```
