# Debug

Quand un test échoue, un message s'affiche pour décrire ce qui a mal tourné et pour quelle entrée.
Tu peux aussi tirer parti du fait que tout ce qui est écrit sur la « sortie standard » sera affiché lui aussi.
On peut écrire sur la sortie standard avec `println!` :

```rust
println!("Debug message");
```

Utilise des accolades `{}` pour afficher la valeur d'une variable ou d'une expression :

```rust
let secret_number = 4321;
println!("My banking password is {}, which is better than {}.", secret_number, 1200 + 34);
```

Note que tous les types ne peuvent pas être affichés de cette façon, seulement ceux que l'on peut présenter aux utilisateurs sans ambiguïté.
Par exemple, les vecteurs (listes) ne peuvent pas être affichés ainsi, car on ne voit pas clairement comment un vecteur devrait être présenté aux utilisateurs !
Pour ces autres types, tu peux demander à la macro `println!` d'utiliser le _formatage de débogage_ avec `{:?}`.
Cette représentation n'est destinée qu'aux développeurs.
Un exemple :

```rust
let words = vec!["hello", "world"];
println!("words that are often combined: {:?}", words);
```

Il existe même la très pratique macro `dbg!`, qui permet de déboguer de grandes expressions en ligne, sans avoir à les découper en déclarations de variables séparées.

Supposons que l'on ait l'expression suivante :

```rust
"hello world".split(' ').collect::<Vec<_>>().join("-")
```

Maintenant, on aimerait voir ce que renvoie l'appel à `collect`.
On pourrait faire ceci :

```rust
let my_temporary_debug_variable = "hello world".split(' ').collect::<Vec<_>>();
println!("{:?}", my_temporary_debug_variable);
my_temporary_debug_variable.join("-")
```

Mais c'est fastidieux !
On ne veut pas réécrire nos belles expressions juste pour pouvoir les déboguer.
Accueillons sur scène : `dbg!`

```rust
dbg!(
    "hello world".split(' ').collect::<Vec<_>>()
).join("-")
```

L'espacement n'est là que pour la clarté.
Tu peux envelopper n'importe quelle expression dans `dbg!()`, ce qui affichera cette valeur (avec le formatage de débogage).
Ensuite, tu peux continuer à utiliser la valeur dans une expression plus grande, comme si le `dbg!` n'avait jamais été là.

Bon débogage !
