# Instructions

Dans cet exercice, tu dois implémenter quelques règles de [Pac-Man][Pac-Man], le jeu d'arcade classique des années 1980.

Il y a six tâches au total, dont quatre portent sur des règles liées aux états du jeu.

> _Ne te préoccupe pas de la façon dont les arguments sont obtenus dans les fonctions, concentre-toi simplement sur la combinaison des arguments pour renvoyer le résultat attendu._


## 0. Définis un état d'énergie

Définis une variable nommée `PowerOn` avec une valeur qui représente le fait que l'énergie est bien activée.

```powershell
> $PowerOn
True
```

## 1. Définis si Pac-Man mange un fantôme

Définis la fonction `EatGhost` qui prend deux paramètres (_si Pac-Man a une pastille d'énergie active_ et _si Pac-Man touche un fantôme_) et qui renvoie une valeur booléenne indiquant si Pac-Man est capable de manger le fantôme.
La fonction doit renvoyer `True` uniquement si Pac-Man a une pastille d'énergie active et touche un fantôme.

```powershell
> EatGhost -ActivePower $false -TouchingGhost $true
False
```

## 2. Définis si Pac-Man marque des points

Définis la fonction `Score` qui prend deux paramètres (_si Pac-Man touche une pastille d'énergie_ et _si Pac-Man touche un point_) et qui renvoie une valeur booléenne indiquant si Pac-Man a marqué.
La fonction doit renvoyer `True` si Pac-Man touche une pastille d'énergie ou un point.

```powershell
> Score -TouchDot $true -TouchPowerPellet $true
4
```

## 3. Définis si Pac-Man perd

Définis la fonction `Lose` qui prend deux paramètres (_si Pac-Man a une pastille d'énergie active_ et _si Pac-Man touche un fantôme_) et qui renvoie une valeur booléenne indiquant si Pac-Man perd.
La fonction doit renvoyer `True` si Pac-Man touche un fantôme et n'a pas de pastille d'énergie active.

```powershell
> Lose -ActivePower $false -TouchingGhost $true
True
```

## 4. Définis si Pac-Man gagne

Définis la fonction `Win` qui prend trois paramètres (_si Pac-Man a mangé tous les points_, _si Pac-Man a une pastille d'énergie active_ et _si Pac-Man touche un fantôme_) et qui renvoie une valeur booléenne indiquant si Pac-Man gagne.
La fonction doit renvoyer `True` si Pac-Man a mangé tous les points et n'a pas perdu d'après les paramètres définis dans la partie 3.

```powershell
> Win -EatenAllDots $false -ActivePower $true -TouchingGhost $false
False
```

## 5. Écris un synopsis pour la condition de victoire

Reviens à la dernière fonction et ajoute une section `Synopsis` au bloc de commentaires, sous forme de brève description de la façon de gagner la partie.
La description doit faire au moins dix caractères.

```powershell
function MyFunc($Arg) {
    <#
    .DESCRIPTION
    This is a demonstration of the comment-based help with the description keyword.
    #>
}
```
