# Indices

## Général

- Fais bien attention à la syntaxe des pointeurs.
  Tu vas utiliser `*` (opérateur de déréférencement) et `->` (accès aux membres via un pointeur).
- Pense à vérifier les pointeurs nuls (`nullptr`) lorsque c'est nécessaire, pour éviter d'accéder à une mémoire invalide.
- Tu peux exécuter les tests même si ton code n'est pas terminé ; une structure sommaire suffit pour voir les résultats des tests.
- Toutes les fonctions utilisées par les tests doivent être déclarées dans le fichier d'en-tête.
- Si ton programme plante ou se comporte de façon inattendue, c'est souvent dû à un déréférencement de pointeur nul.
  Vérifie bien que tu gères correctement `nullptr`.
- Lorsque tu utilises l'arithmétique des pointeurs, assure-toi de rester dans les limites du tableau de capteurs.
  Dépasser la capacité du tableau peut entraîner des problèmes de mémoire.

## 1. Vérifie la connexion du capteur (`connection_check`)

- Cette tâche consiste principalement à vérifier si un pointeur est nul ou non.
- Utilise l'opérateur de comparaison `!=` pour vérifier si un pointeur est valide.
- Si tu n'es pas sûr de vérifier correctement le pointeur, demande-toi ce que `nullptr` représente (l'absence d'adresse mémoire valide).


## 2. Compte l'activité des capteurs (`activity_counter`)

- Tu dois parcourir le tableau de capteurs.
  En C++, un tableau peut être traité comme un pointeur vers son premier élément.
- Utilise l'arithmétique des pointeurs (`sensor_array + i`) pour accéder au capteur à l'indice `i`.
- L'opérateur `->` permet d'accéder à un membre de la structure via un pointeur.

### Exemple

```cpp
int sum = (sensor_array + i)->activity; // Access activity using pointer arithmetic
```

## 3. Contrôle de l'alarme (`alarm_control`)

- Tout d'abord, vérifie si le pointeur est nul avant d'accéder au capteur.
- Utilise l'opérateur `->` pour accéder au membre `activity` de la structure `pillar_men_sensor`.
- Réfléchis bien à ce qui doit se passer si le niveau d'activité du capteur est `0`.
  L'alarme doit-elle se déclencher ?

## 4. Vérifie les données pour détecter des anomalies avec la fonction `uv_alarm`

- Utilise l'opérateur `&` pour passer un pointeur vers le tableau de données du capteur à la fonction `uv_light_heuristic`.
- Assure-toi de vérifier correctement qu'il n'y a pas de pointeur nul avant d'accéder aux données du capteur.
- Compare le résultat de `uv_light_heuristic` avec la valeur `activity` du capteur pour déterminer si l'alarme doit se déclencher.
