# Introduction

Les expressions régulières en Gleam suivent la spécification **PCRE** (**P**erl **C**ompatible **R**egular **E**xpressions), comme dans d'autres langages populaires tels que Java, JavaScript ou Ruby.

Le module `gleam/regex` propose des fonctions pour travailler avec les expressions régulières.

~~~~exercism/note
Cet exercice part du principe que tu connais déjà la syntaxe des expressions régulières, notamment les classes de caractères, les quantificateurs, les groupes et les captures.

Si tu as besoin de rafraîchir tes connaissances en expressions régulières, consulte l'une de ces sources : [Regular-Expressions.info](https://www.regular-expressions.info), [Rex Egg](https://www.rexegg.com/), [RegexOne](https://regexone.com/), [Regular Expressions 101](https://regex101.com/), [RegExr](https://regexr.com/).
~~~~

La façon la plus courante de créer des expressions régulières est d'utiliser la fonction `regex.from_string`.

```gleam
let assert Ok(re) = regex.from_string("test")
```

La fonction `regex.from_string` renvoie une `Error` si la syntaxe de l'expression régulière n'est pas valide, c'est pourquoi on a utilisé ici une _let-assertion_ pour s'assurer que l'expression régulière est valide.

La fonction `regex.check` permet de vérifier si une expression régulière correspond à une _string_.

```gleam
let assert Ok(re) = regex.from_string("test")

regex.check(re, "this is a test")
// -> True

regex.check(re, "this is too")
// -> False
```


## Captures

Si tu souhaites capturer des sous-chaînes à l'aide d'une expression régulière, la fonction `regex.scan` permet de renvoyer un tableau de correspondances.

```gleam
let assert Ok(re) = regex.from_string("[oi]n a (\\w+)")
regex.scan(with: re, content: "I am on a boat in a lake.")
// -> [
//   Match(
//     content: "on a boat",
//     submatches: [Some("boat")]
//   ),
//   Match(
//     content: "in a lake",
//     submatches: [Some("lake")]
//   )
// ]
```

## Modificateurs

Le comportement d'une expression régulière peut être modifié en la créant avec la fonction `regex.compile` et en lui passant des options.

```gleam
let options = regex.Options(case_insensitive: True, multi_line: False)
let assert Ok(re) = regex.compile("[A-Z]", with: options)
regex.check(re, "abc123")
// -> True
```
