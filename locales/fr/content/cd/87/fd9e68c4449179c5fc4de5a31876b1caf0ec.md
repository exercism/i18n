# Espace réservé

## Général

- La [fonction numérique][rand-func] `rand` peut générer des nombres aléatoires.
- La [fonction numérique][srand-func] `srand` sera utile pour définir la graine de `rand`.

## Génération de labyrinthe

Tu peux utiliser n'importe quel algorithme pour générer un labyrinthe parfait. Le [retour sur trace récursif][recursive-backtracker] est un bon choix.
