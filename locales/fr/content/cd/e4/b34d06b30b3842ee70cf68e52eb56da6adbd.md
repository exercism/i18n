# Instructions supplémentaires

## Indices

La valeur de retour de `countWords` peut être n'importe quel type de table de hachage avec une clé de type `string` et une valeur de type `int`.

Les tables de hachage (aussi appelées « dictionnaires » ou « _maps_ » dans d'autres langages de programmation) sont implémentées par le module `tables`. Voir la [documentation]

Par exemple, `countWords` pourrait renvoyer un `TableRef[string, int]`

```nim
proc countWords*(sentence: string): TableRef[string, int] =
  ...
```

[documentation]: https://nim-lang.org/docs/tables.html
