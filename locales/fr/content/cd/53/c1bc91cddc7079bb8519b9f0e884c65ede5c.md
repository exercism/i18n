# Introduction

En Kotlin, `when` est une expression conditionnelle qui permet de choisir entre plusieurs options.
Elle ressemble au `switch` de Java et se montre plus souple qu'une chaîne de `if` ... `else if` ... `else`.

Comme `if`, `when` peut aussi s'utiliser comme une expression qui produit une valeur.

## Correspondance d'une valeur

On donne à `when` une valeur à comparer entre parenthèses.
Chaque branche compare cette valeur jusqu'à ce que l'une d'elles corresponde :

```kotlin
val animal = "chicken"
val type = when (animal) {
    "chicken" -> "bird"
    "poodle" -> "dog"
    else -> "unknown"
}
// type => "bird"
```

- Chaque branche s'écrit `pattern -> result`.
- Les branches sont testées de haut en bas jusqu'à ce qu'une correspondance soit trouvée.
  Seule la première branche s'exécute.
- Utilise `else` pour toute valeur qui n'est pas listée plus haut (comme le `else` final d'une chaîne de `if`).

Cela ressemble au [filtrage par motif][pattern-matching].
Le `pattern` peut être une valeur à comparer, ou bien on peut utiliser `is` pour comparer par type :

```kotlin
fun typeText(subject: Any): String {
    return when(subject) {
        is Animal -> "Animal"
        is Fruit -> "Fruit"
        is String -> "Text"
        else -> "Unknown"
    }
}
```

ou `in` pour vérifier que la valeur est contenue dans un intervalle, une collection, une _string_ ou n'importe quoi d'autre qui possède une méthode `contains` :

```kotlin
fun describe(number: Int, position: String) {
    // Range
    when(number) {
        in 1..10 -> println("From 1 to 10")
        in 11..20 -> println("From 11 to 20")
    }

    // Collection
    when(number) {
        in listOf(2, 4, 6) -> println("small even")
        in listOf(3, 5, 7) -> println("small odd")
    }

    // String
    when(position) {
        in "center middle" -> println("inner")
        in "left right boundary" -> println("outer")
    }
}
```

## Conditions de garde

Lorsqu'on compare une valeur, on peut ajouter des conditions supplémentaires dans un `if` placé après le motif.
Ces conditions sont appelées conditions de garde.

```kotlin
val x = 5
val y = 10
val description = when (x) {
    5 if y % 2 == 0 -> "x is 5, y is even"
    else -> "other"
}
// description => "x is 5, y is even"
```

On peut même utiliser `else if`.

```kotlin
val x = 7
val y = 10
val description = when (x) {
    5 if y % 2 == 0 -> "x is 5, y is even"
    else if y % 2 == 0 -> "y is an even number"
    else -> "other"
}
// description => "y is an even number"
```


## Correspondance de conditions

Autrement, on peut omettre la valeur et placer une condition booléenne sur chaque branche :

```kotlin
val x = 5
val y = 8
val description = when {
    x % 2 != 0 -> "x is odd"
    y % 2 == 0 -> "y is even"
    else -> "neither condition matched first"
}
// description => "x is odd"
```

Là encore, les branches sont examinées de haut en bas et seule la première dont la condition est `true` s'exécute.

## Utiliser `when` comme expression

Quand on utilise `when` pour son résultat (affectation à une variable, valeur renvoyée par une fonction, etc.), il faut couvrir tous les cas possibles.

- Quand on compare une valeur, ajoute `else` sauf si toutes les valeurs possibles sont déjà gérées (par exemple toutes les valeurs d'un `Boolean` ou d'un `enum`).
- Quand on compare des conditions, une branche `else` est obligatoire, car le compilateur ne peut pas savoir que tes conditions couvrent tous les cas.

```kotlin
fun label(n: Int): String = when (n) {
    0 -> "zero"
    1 -> "one"
    else -> "other"
}
```
