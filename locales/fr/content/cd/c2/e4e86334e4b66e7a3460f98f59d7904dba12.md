# Indices

## 1. Capture les informations nécessaires pour générer les cartes avec une expression régulière

- `\p{L}` correspond à n'importe quelle lettre, quelle que soit la langue.
- Tu peux utiliser l'expression suivante pour capturer les informations :
  ```julia
  re = r"""»(.*)«                     # title
           \ –\ (.*?)                 # name
           (?:\ \((.*?)\)|)           # optional pronouns
           (?:,\ from\ (.*?)|).       # optional organisation
           \ Start:\ (.*?),\          # start time
           (?:Q&A:\ (.*?),\ |)        # optional Q&A time
           End:\ (.*)                 # end time
        """x
  ```
