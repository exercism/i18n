# Introduction

JSON définit un **tableau** ainsi :

> Un tableau est une collection ordonnée de valeurs.
> Un tableau commence par un crochet ouvrant `[` et se termine par un crochet fermant `]`.
> Les valeurs sont séparées par une virgule `,`.

Un tableau peut contenir zéro ou plusieurs valeurs JSON, _de tout type_.
Les éléments d'un tableau ne sont pas forcément tous du même type.

## Crée des tableaux

On utilise des crochets pour rassembler des éléments dans un tableau.

```jq
[1, 2, 3]
```

Les éléments d'un _flux_ peuvent être capturés dans un tableau en l'entourant de crochets.

```jq
range(5)     # => a stream of 5 numbers
[range(5)]   # => the array [0, 1, 2, 3, 4]
```

## Taille

La fonction `length` renvoie le nombre d'éléments d'un tableau.

## Indexe et découpe

Les indices d'un tableau commencent à zéro.

On récupère un élément d'un tableau avec une expression entre crochets :
`.[2]` donne le troisième élément.

Les indices négatifs se comptent à rebours depuis la fin du tableau :
`.[-1]` donne le dernier élément ; `.[-2]` l'avant-dernier.

Une **tranche** est une sous-séquence du tableau.
`.[10:15]` renvoie 5 éléments à partir de l'indice 10 ; l'indice de fin n'est _pas inclus_.

Il existe quelques fonctions utilitaires :

- `first` donne le premier élément.
- `last` donne le dernier élément.
- `nth(n)` donne l'élément situé à l'indice `n`.

## Itère

`jq` fournit de nombreuses fonctions qui couvrent les besoins courants d'itération :

- `map(expr)` renvoie un nouveau tableau où `expr` est appliqué tour à tour à chaque élément.

  ```jq
  [1, 2, 3] | map(. * 10)    # => [10, 20, 30]

  ```

- `select(expr)` est une fonction qui applique `expr` à une _valeur unique_ ;
  si le résultat de l'expression est vrai, la valeur est renvoyée ;
  si le résultat est faux, _rien_ n'est renvoyé, pas `null`, vraiment rien.

  Pour l'appliquer à un tableau, combine-la avec `map`.

  ```jq
  [range(10)] | map(select(. % 2 == 0))    # => [0, 2, 4, 6, 8]
  ```

  Autrement, on peut appliquer `select` à un _flux_ et rassembler les résultats.

  ```jq
  [range(10) | select(. % 2 == 0)]    # => [0, 2, 4, 6, 8]
  ```

- `any(condition)` et `all(condition)` renvoient une valeur booléenne indiquant si un élément, ou tous les éléments, du tableau satisfont la condition.

  ```jq
  [1, 2, 3, 4] | any(. > 4)    # false
  [1, 2, 3, 4] | any(. >= 4)   # true

  [1, 2, 3, 4] | all(. >= 4)   # false
  [1, 2, 3, 4] | all(. <= 4)   # true
  ```
