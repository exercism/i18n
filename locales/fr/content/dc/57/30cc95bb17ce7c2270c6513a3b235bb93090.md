# Introduction

## Types génériques

La définition d'une collection comporte généralement un espace réservé entre chevrons, souvent `T` par convention. On parle alors de type générique. Cela permet à celui qui utilise la collection de préciser le type des éléments qu'elle contient. Dans l'exemple de code ci-dessous, on instancie une liste de _strings_.

## Listes

En C#, les listes sont des collections de valeurs primitives ou d'instances de structures ou de classes. Elles sont implémentées dans la bibliothèque de classes de base sous la forme `List<T>`, où `T` est le type des éléments de la liste. L'API met à disposition un ensemble riche de méthodes pour créer et manipuler des listes.

Les listes permettent d'ajouter et de retirer des éléments ; elles grandissent et rétrécissent au besoin.

```csharp
var listOfStrings = new List<string>();
```
