# Instructions

Dans cet exercice, on va faire un peu d'ingénierie de données en prétraitant des notes. Une école avec beaucoup, beaucoup, beaucoup (trop ?) d'élèves cherche à faire une analyse des notes reçues par les élèves et veut le faire efficacement, l'idée étant donc de réduire et d'organiser les données.

La notation va généralement de 0 à 10, il est donc plus efficace d'utiliser un type de données de seulement huit bits par note.
- Certains professeurs utilisent des nombres réels (car ils tiennent à la précision), et tu devras les convertir vers le type de données `UInt8`.
- D'autres professeurs utilisent des entiers avec des nombres négatifs (pour punir les élèves particulièrement turbulents), et dans ce cas tu devras les convertir vers le type de données `Int8`.

Une fois que tu as implémenté la fonction qui convertit les notes, tu devras en écrire une autre pour traiter les collections qui les contiennent, en abaissant les notes et en les renvoyant dans l'ordre décroissant.
- Certains professeurs utilisent des `Vector`s triés par ordre croissant pour stocker leurs notes, parce qu'ils sont méticuleux avec leurs données.
- D'autres professeurs utilisent des `Set`s, qui ne sont pas triés, pour stocker leurs notes, parce qu'ils sont un peu plus paresseux.

Dans les deux fonctions, tu devras gérer les entrées invalides en levant une MethodError.

~~~~exercism/note
La gestion des exceptions sera abordée dans un concept ultérieur, donc pour les besoins de cet exercice, tu peux utiliser la syntaxe suivante :
```julia
throw(MethodError(f, args))
```
Où `f` est la fonction et `args` est un tuple des arguments passés à la fonction.
Pour la fonction `demote(n)`, `f` est `demote` et `args` est `(n,)` :
```julia
throw(MethodError(demote, (n,)))
```
~~~~

## 1. Abaisse les notes

Implémente la méthode `demote(n)`.
- Avec une entrée de type `Float64`, elle doit arrondir à l'entier supérieur et renvoyer un type de données `UInt8`.
- Avec un `Integer` quelconque, elle doit renvoyer le même entier dans un type de données `Int8`.
- Toutes les autres entrées doivent lever une MethodError.

```julia-repl
julia> demote(4.2)::UInt8
5

julia> demote(4)::Int8
4

julia> demote("hi")
MethodError: no method matching demote(::String)     #output truncated
```

## 2. Prétraite les données

Implémente la méthode `preprocess(coll)`.
- Avec une entrée de type `Vector`, elle doit abaisser tous les nombres et inverser le vecteur.
- Avec une entrée de type `Set`, elle doit abaisser tous les nombres et renvoyer un vecteur trié par ordre décroissant.
- Toutes les autres entrées doivent lever une MethodError.

```julia-repl
julia> preprocess([1, 2, 3])
3-element Vector{Int8}:
 3
 2
 1

julia> preprocess(Set([2.2, 5.8, 3.4]))
3-element Vector{UInt8}:
 6
 4
 3

julia> preprocess(42)
MethodError: no method matching preprocess(::Int64)     #output truncated
```
