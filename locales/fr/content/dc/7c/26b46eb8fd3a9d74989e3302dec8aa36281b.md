# Instructions supplémentaires

## Tests

Les tests exécutent certaines opérations de manière concurrente.
Efforce-toi de faire en sorte que les opérations effectuées sur Account le laissent dans un état cohérent.
Par exemple : plusieurs goroutines peuvent déposer et retirer de l'argent en même temps, et deux retraits simultanés ne doivent pas pouvoir faire passer le solde dans le négatif.

Quand tu travailles en local, tu peux vérifier que ton code gère correctement la concurrence et n'entraîne pas de course de données en lançant les tests avec l'option `-race`.

```bash
cd exercism/project/directory/go/bank-account
go test -race
```
