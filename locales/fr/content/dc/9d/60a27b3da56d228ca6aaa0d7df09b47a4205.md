# À propos

Quand une fonction prend beaucoup d'arguments, il peut être difficile de se souvenir de l'ordre dans lequel il faut les passer. Pour faciliter la lecture, Gleam permet d'étiqueter les arguments avec un nom.

Pour étiqueter un argument, indique le nom de l'étiquette avant le nom de l'argument, séparés par un espace.

```gleam
pub fn replace(
  in string: String,
  each target: String,
  with replacement: String
) -> String {
  // ...
}
```

Quand on appelle une fonction avec des arguments étiquetés, on peut passer les arguments dans n'importe quel ordre. Ces appels à `replace` sont tous équivalents :

```gleam
replace(in: "🍔🍔🍔" each: "🍔", with: "🍕")

replace(each: "🍔", in: "🍔🍔🍔", with: "🍕")

replace(with: "🍕", each: "🍔", in: "🍔🍔🍔")
```

Les étiquettes sont toujours facultatives. Même si une fonction prend des arguments étiquetés, on peut quand même l'appeler sans étiquettes.

```gleam
replace("🍔🍔🍔", "🍔", "🍕")
```

Quand on définit une fonction avec des arguments étiquetés, tous les arguments qui suivent le premier argument étiqueté doivent aussi être étiquetés.

```gleam
// This function is valid
pub fn valid(
  x: Int,
  label1 y: Int,
  label2 z: Int
) -> Int {
  // ...
}

// This function is invalid
pub invalid(
  x: Int,
  label1 y: Int,
  z: Int
) -> Int {
  // ...
}
```
