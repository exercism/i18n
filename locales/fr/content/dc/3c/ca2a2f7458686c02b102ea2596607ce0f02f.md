# Installation

Contrairement à beaucoup d'autres langages, Pyret ne nécessite pas d'installer le langage globalement.
À la place, les développeurs de Pyret ont rendu leur compilateur disponible sous la forme d'un [paquet npm][pyret-npm].
Tu installeras Pyret avec `npm` pour chaque exercice :
tu trouveras plus de détails sur la page [Tests][tests].

Tu dois installer Node.js, un environnement d'exécution JavaScript.
Sur la page de [téléchargement de Node.js][download], veille à sélectionner `npm` comme gestionnaire de paquets.

~~~~exercism/note
Pour le moment, le paquet pyret-npm n'est compatible qu'avec Linux et MacOS.
Les utilisateurs de Windows devront installer pyret-npm avec WSL ou une machine virtuelle.
~~~~
