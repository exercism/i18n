## 2. Écris un adaptateur d'itérateur `evens` qui renvoie les éléments pairs d'un itérateur quelconque

- Il suffit d'enchaîner les méthodes suggérées pour que tout fonctionne
- Un nombre `n` est pair si `n % 2 == 0`
- Une fermeture est une fonction à la syntaxe abrégée : le ou les noms des arguments se placent entre une paire de symboles `|`, et l'expression suit. Contrairement aux fonctions normales, il n'est pas toujours nécessaire d'indiquer explicitement le type de chaque argument, seulement son nom. Par exemple, voici comment construire un itérateur de carrés impairs : `(0..).map(|n| 2 * n + 1).map(|n| n * n)`.
