# À propos

Une structure ou une classe peut définir des **propriétés stockées** pour stocker des données dans une instance. Les propriétés stockées peuvent être déclarées comme des variables (avec `var`) si leurs valeurs peuvent changer, ou comme des constantes (avec `let`) si leurs valeurs restent fixes une fois initialisées :

```swift
class GameCharacter {
    var health = 10
    let id = makeRandomID()
}

let character1 = GameCharacter()
let character2 = GameCharacter()

print(character1.health) // Prints 10
print(character2.health) // Prints 10

character1.health = 25

print(character1.health) // Prints 25
print(character2.health) // Prints 10

// The following line triggers a compiler error because 'id' is a constant:
// character2.id = 2
```
