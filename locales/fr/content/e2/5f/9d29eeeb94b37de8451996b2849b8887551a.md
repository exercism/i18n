# Debug

Toute la sortie de ton script Red est visible dans la console, lorsque tu exécutes chaque test. Tu peux `print` ce que tu veux, par exemple les valeurs des mots :

```red
print ["x =" x]
```

De plus, la fonction `probe` est très utile. Lorsqu'on l'évalue, elle évalue son entrée, affiche le résultat d'une manière qui reflète son type, puis la renvoie. Elle est donc dans la plupart des cas « transparente », et tu peux l'insérer à l'intérieur d'expressions :

```red
x: 10
y: probe x + 5
```

Parfois, la fonction appelée `type?` (oui, elle a un point d'interrogation dans son nom !) peut être utile pour vérifier le type d'une valeur :

```red
print ["x type:" type? x]
```

Il existe aussi des techniques de débogage plus avancées [listées sur le wiki de Red](https://github.com/red/red/wiki/%5BDOC%5D-Debugging).
