# Introduction

Les [structures][structs-and-classes], communément appelées *structs*, sont l'un des principaux éléments constitutifs des programmes Swift.
Les structs permettent de créer des types personnalisés qui rassemblent des propriétés (données) et des méthodes (comportement) liées.
En fait, les types standard de Swift, notamment `Int`, `Double`, `Bool`, `String`, `Array` et `Dictionary`, sont tous implémentés sous forme de structs.

## Définis des structs

Définis un struct à l'aide du mot-clé `struct`, suivi du nom du type et d'accolades contenant sa définition.
Par convention en Swift, les noms de structs utilisent `UpperCamelCase` :

```swift
struct CharacterStats {
    var health = 0.0
    var speed = 0
    var strength = 0
}
```

## Crée des instances

La définition d'un struct est un plan.
Pour créer une *instance* d'un struct, appelle son initialiseur en écrivant le nom du type suivi de parenthèses :

```swift
var someStats = CharacterStats()
```

Cela crée une instance dont les propriétés sont initialisées avec les valeurs par défaut de la définition.

Swift génère aussi automatiquement un **initialiseur membre par membre** pour les structs, qui permet d'initialiser les propriétés par leur nom :

```swift
let customStats = CharacterStats(health: 100.0, speed: 6, strength: 18)
```

## Accède aux propriétés et modifie-les

On accède aux propriétés d'une instance et on les modifie à l'aide de la *notation pointée* :

```swift
var stats = CharacterStats()

print(stats.health) // Prints 0.0

stats.health = 87.3
print(stats.health) // Prints 87.3
```

Comme les structs sont des types valeur, pour modifier les propriétés d'une instance, il faut que l'instance elle-même soit déclarée avec `var`.
Si l'instance est déclarée avec `let`, toutes ses propriétés deviennent immuables.
