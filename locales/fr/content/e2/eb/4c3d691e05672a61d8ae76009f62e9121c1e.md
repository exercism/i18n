# Introduction

## Jonglage de types

Le jonglage de types, aussi appelé coercition de types, se produit quand deux valeurs de types différents sont converties vers un même type pour effectuer une opération.

```php
$baskets = 5 // int
$apples_per_basket = "3" // string
$baskets * $apples_per_basket
# => 15
```

Cette conversion peut se faire de manière implicite (comme dans l'exemple ci-dessus) ou explicite, à l'aide d'un transtypage à la manière du `C` :

```php
$apples_per_basket = "3" // string
$my_number = (int) $apples_per_basket // cast string to int
# => 3 // int
```

Les types autorisés pour le transtypage manuel sont : `bool`, `int`, `float`, `string`, `array`, `object`.
Le plus souvent, le transtypage sert à convertir un entier (`int`) en nombre décimal (`float`), ou l'inverse.
