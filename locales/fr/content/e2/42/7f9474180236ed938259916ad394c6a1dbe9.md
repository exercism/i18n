# Instructions supplémentaires

La direction vers laquelle le robot regarde est exprimée par l'un des nombres suivants :

- Nord = 0
- Est = 1
- Sud = 2
- Ouest = 3

Lorsque l'entrée est invalide, renvoie une direction de -1 (les autres valeurs seront ignorées).

## Mémoire réservée

Le tampon de la _string_ d'entrée utilise les octets 64-319 de la mémoire linéaire.

La _string_ d'entrée peut être modifiée si on le souhaite.
