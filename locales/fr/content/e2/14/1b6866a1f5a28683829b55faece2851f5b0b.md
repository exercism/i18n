# À propos

Les _hashes_ sont un type de données en Perl. Ils contiennent une collection non ordonnée de clés de type _string_ associées à des valeurs scalaires.

On remplit généralement une variable _hash_ en lui affectant une liste, par exemple `my %scores = (Alice => 10, Bob => 15, Charlie => 20);`.

Les éléments d'une liste sont généralement séparés par des virgules, mais on rencontre très souvent la « virgule grasse » `=>`, qui sert à séparer les clés des valeurs dans une liste.
Son comportement est presque identique à celui d'une virgule, mais elle a l'avantage supplémentaire d'interpréter l'élément situé à sa gauche comme une _string_.

On peut aussi remplir un _hash_ en affectant chacune de ses clés individuellement, par exemple `$scores{Alice} = 10;`.

On accède aux valeurs d'un _hash_ en indiquant les clés par un indice, par exemple `$scores{Bob} # 15`.

Les clés d'un _hash_ sont uniques.
Si une même clé est donnée plusieurs fois, seule la dernière valeur fournie est conservée.

## Fonctions

Parmi les fonctions qui permettent de manipuler les _hashes_, on trouve [keys][keys] et [values][values], qui renvoient ces parties du _hash_ sous forme de liste.
Les listes renvoyées par les fonctions [keys][keys] et [values][values] sont utiles à des fonctions de liste comme [grep][grep], [map][map] et [sort][sort], ainsi qu'aux boucles [for][for].

Citons aussi [exists][exists], qui permet de vérifier si une clé existe dans un _hash_ (même si sa valeur est `undef`), et [delete][delete], qui supprime une clé d'un _hash_.

## Variantes de sigil

Quand on récupère des valeurs dans un _hash_, le _sigil_ utilisé détermine le résultat.
C'est l'indice `{}` placé à la fin du nom de la variable qui indique à Perl que l'on manipule le _hash_ portant ce nom.

```perl
my %names = (Alice => 10, Bob => 15, Charlie => 20);

$names{Alice}; # 10            <- A scalar
@names{Alice}; # (10)          <- A slice (with only one key, this probably isn't what you want. There will be a warning.)
%names{Alice}; # ('Alice', 10) <- A key/index + value slice

$names{'Bob', 'Charlie'}; #                            <- An error (disabled syntax for an ancient feature.)
@names{'Bob', 'Charlie'}; # (15, 20)                   <- A slice
%names{'Bob', 'Charlie'}; # ('Bob', 15, 'Charlie', 20) <- A key/index + value slice
```

Même si c'est autorisé, il est recommandé, pour la lisibilité, de ne pas donner le même nom à des variables de types différents.
