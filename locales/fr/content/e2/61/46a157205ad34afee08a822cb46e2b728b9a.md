# Instructions

Dans cet exercice, tu es un grand fan de sport et tu viens de découvrir une passion pour le basketball de la NBA.
Comme tu débutes dans le basketball NBA, tu te plonges dans l'histoire de la NBA en suivant les équipes, les entraîneurs et leurs statistiques de victoires et de défaites, et en les comparant entre elles.

Comme tu n'as pas encore d'équipe favorite, tu vas aussi développer un algorithme pour déterminer s'il faut encourager une équipe en particulier.
Tu as sept tâches pour t'aider à mettre au point ton algorithme _root-for-a-team_ maison.

## 1. Définis le modèle

Définis l'alias de type `Coach` pour un enregistrement avec les deux champs suivants, dans cet ordre :

- `name` : le nom de l'entraîneur, de type `String`.
- `formerPlayer` : indique si l'entraîneur était un ancien joueur, de type `Bool`.

Définis l'alias de type `Stats` pour un enregistrement avec les deux champs suivants, dans cet ordre :

- `wins` : le nombre de victoires, de type `Int`.
- `losses` : le nombre de défaites, de type `Int`.

Définis l'alias de type `Team` pour un enregistrement avec les trois champs suivants, dans cet ordre :

- `name` : le nom de l'équipe, de type `String`.
- `coach` : l'entraîneur de l'équipe, de type `Coach`.
- `stats` : les statistiques de l'équipe, de type `Stats`.

## 2. Crée une équipe

Tu veux communiquer avec du code tiers qui a la notion d'équipe, mais qui appelle ton code avec les paramètres dans un ordre différent. Ajoute une fonction `createTeam` avec la signature suivante `String -> Stats -> Coach -> Team`.

## 3. Remplace l'entraîneur

Les propriétaires de NBA étant impatients, tu as constaté que de mauvais résultats d'équipe entraînaient souvent le remplacement de l'entraîneur.
Implémente la fonction `replaceCoach` qui prend le nouvel entraîneur et l'équipe en paramètres, et qui renvoie l'équipe avec le nouvel entraîneur :

```elm
let
    coach = { name = "Larry Bird", formerPlayer = True }
    stats = { wins = 58, losses =  24 }
    team = { name = "Indiana Pacers", coach = coach, stats =  stats }
    newCoach = { name = "Isiah Thomas", formerPlayer = True }
in
replaceCoach newCoach team
--> { name = "Indiana Pacers"
--  , coach = { name = "Isiah Thomas", formerPlayer = True }
--  , stats = { wins = 58, losses = 24 } }
```

## 4. Vérifie si tu dois encourager une équipe

À l'avenir, tu prévois de concevoir un algorithme compliqué pour savoir s'il faut encourager une équipe ou non, mais pour cette première tentative, tu as décidé qu'il faut encourager toute équipe qui a plus de victoires que de défaites.

Tu veux que cette fonction soit réutilisable dans d'autres contextes, alors utilise un enregistrement extensible dans la signature de type pour accepter n'importe quel enregistrement qui possède les champs pertinents.
Pour que la fonction reste aussi concise que possible, tu veux utiliser le _pattern matching_ pour récupérer les `stats` à partir du paramètre de la fonction.
Implémente la fonction `rootForTeam` qui prend une équipe et renvoie `True` si tu dois encourager cette équipe ; sinon, renvoie `False`.

```elm
let
    spursCoach = { name = "Gregg Popovich", formerPlayer =  False }
    spursStats = { wins = 56, losses = 26 }
    spursTeam = { name = "San Antonio Spurs", coach = spursCoach, stats = spursStats }
in
rootForTeam spursTeam
--> True
```
