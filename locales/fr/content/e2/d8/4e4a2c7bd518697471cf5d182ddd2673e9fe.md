# Instructions supplémentaires

## Format de sortie

Chaque nationalité est indiquée par une seule lettre. (`E` = `Englishman`, `J` = `Japanese`, `N` = `Norwegian`, `S` = `Spaniard`, `U` = `Ukrainian`)

## Registres

| Registre | Utilisation | Type       | Description                              |
| -------- | ----------- | ---------- | ---------------------------------------- |
| `$v0`    | sortie      | octet      | nationalité de la personne qui boit de l'eau |
| `$v1`    | sortie      | octet      | nationalité du propriétaire du zèbre     |
| `$t0-9`  | temporaire  | quelconque | pour le stockage temporaire              |
