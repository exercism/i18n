# Introduction

## Expressions régulières

En Elixir, les expressions régulières suivent la spécification **PCRE** (**P**erl **C**ompatible **R**egular **E**xpressions), comme dans d'autres langages populaires tels que Java, JavaScript ou Ruby.

Le module `Regex` offre des fonctions pour travailler avec les expressions régulières. Certaines fonctions du module `String` acceptent également des expressions régulières en argument.

### Sigils

La façon la plus courante de créer des expressions régulières est d'utiliser le sigil `~r`.

```elixir
~r/test/
```

Note que tous les sigils d'Elixir prennent en charge [différents types de délimiteurs][sigils], pas seulement `/`.

### Correspondance

L'opérateur `=~/2` permet d'effectuer une correspondance d'expression régulière qui renvoie un résultat `boolean`. Il existe aussi, en alternative, des fonctions `match?/2` dans le module `Regex` ainsi que dans le module `String`.

```elixir
"this is a test" =~ ~r/test/
# => true

String.match?("Alice has 7 apples", ~r/\d{2}/)
# => false
```

### Capture

Si une simple vérification booléenne ne suffit pas, utilise la fonction `Regex.run/3` pour obtenir un tableau de toutes les captures (ou `nil` s'il n'y a pas de correspondance). Le premier élément du tableau renvoyé correspond toujours à l'expression régulière entière, et les éléments suivants sont les groupes correspondants.

```elixir
Regex.run(~r/(\d) apples/, "Alice has 7 apples")
# => ["7 apples", "7"]
```

### Modificateurs

Le comportement d'une expression régulière peut être modifié en ajoutant des options spéciales. Pour créer une expression régulière avec un sigil, ajoute les modificateurs après le second délimiteur.

Les modificateurs courants sont :
- `i` : la correspondance ne tient pas compte de la casse.
- `u` : active les motifs propres à Unicode comme `\p` et fait que les classes de caractères telles que `\w`, `\s`, etc. correspondent aussi aux caractères Unicode.

```elixir
"this is a TEST" =~ ~r/test/i
# => true
```
