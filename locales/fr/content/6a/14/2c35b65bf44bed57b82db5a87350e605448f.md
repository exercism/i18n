# Les bases du `match`

L'opérateur `match` compare une valeur à une série de motifs, puis exécute du code en fonction du motif qui correspond.

## Comparaison avec des littéraux

Dans son usage le plus fondamental, `match` compare une valeur à plusieurs motifs possibles et choisit la première branche qui correspond. Une seule branche est choisie, jamais plus, et le contrôle ne « passe » jamais à une autre branche. `match` est une expression, ce qui signifie qu'elle peut produire une valeur.

```rust
enum TrollNumber {
    One,
    Two,
    Many,
    Lots,
}

fn estimated_value(troll_number: TrollNumber) -> u32 {
    match troll_number {
        TrollNumber::One => 1,
        TrollNumber::Two => 2,
        TrollNumber::Many => 10,
        TrollNumber::Lots => 100,
    }
}
```

## Exhaustivité

La comparaison est toujours exhaustive : Rust refuse de compiler un programme s'il est possible qu'une valeur passe entre les mailles du filet. Pour faciliter les choses, `_` est un joker qui correspond à n'importe quoi.

```rust
fn ordinal(n: u32) -> String {
    let ordinal = match n % 10 {
        1 => "st",
        2 => "nd",
        3 => "rd",
        _ => "th",
    };
    format!("{n}{ordinal}")
}
```

## Le `match` comme structure de contrôle

Si `match` peut s'utiliser comme une expression pour produire une valeur, on peut aussi l'employer comme instruction, uniquement pour contrôler le flux d'exécution.

```rust
// pretend that we've already filtered the key events relevant to the space bar (we don't want a keylogger)
fn space_timer(&mut self, event: Event) {
    match event {
        Event::KeyDown => self.timer = Some(Instant::now()),
        Event::KeyUp => {
            let duration = Instant::now() - self.timer.take().expect("can't have KeyUp without KeyDown");
            self.durations.push(duration);
        }
        // we don't care about any other events; the empty scope is a no-op
        _ => {}
    }
}
```

## Comparaison avec des plages

Les branches d'un `match` ne sont pas forcément des valeurs uniques ; elles peuvent aussi être des plages.

```rust
fn ascii_type(ch: u8) -> &'static str {
    match ch {
        0..=31 => "non-printable control code",
        32..=126 => "printable character",
        127 => "DEL",
        _ => "extended ASCII; region-specific",
    }
}
```

## Les motifs alternatifs

Une branche de `match` peut correspondre à l'une de plusieurs options possibles en utilisant le jeton `|` comme séparateur.

```rust
fn should_retry(error: std::io::Error) -> bool {
    use std::io::ErrorKind;

    match error.kind() {
        ErrorKind::TimedOut | ErrorKind::Interrupted => true,
        _ => false,
    }
}
```

## Comparaison structurelle et liaison

La comparaison peut créer une liaison qui n'est valable qu'à l'intérieur d'une branche donnée. C'est particulièrement utile pour extraire le contenu des énumérations dont les variantes portent des données.

```rust
/// Consume a result and proceed, logging any errors.
trait OrLog {
    fn or_log(self);
}

impl<E: std::fmt::Display> OrLog for Result<(), E> {
    fn or_log(self) {
        match self {
            // discard Ok results
            Ok(()) => {},
            // log errors
            Err(err) => println!("ERROR: {err}"),
        }
    }
}
```

Pour en savoir plus sur ce sujet, consulte le concept `match-advanced`.
