# Introduction

La récursion est une façon de répéter du code dans une fonction, en faisant en sorte que la fonction s'appelle elle-même.
C'est une autre manière de faire une boucle, autrement dit d'itérer. Comme pour une boucle, la fonction doit évaluer une expression booléenne pour savoir quand s'arrêter.
Contrairement à une boucle, une récursion qui ne se termine jamais ne tournera pas indéfiniment.
Les valeurs utilisées dans chaque appel de fonction peuvent être placées dans leur propre cadre sur la pile.
Si le nombre d'appels de fonction occupe plus d'espace que la pile n'en dispose, cela provoque une erreur de débordement de pile.

```c
int printIncrement (int i, int maxValue){
    if (i > maxValue) return i;
    printf("The number is %i\n", i++);
    printIncrement(i, maxValue);
}

int main() {
    printIncrement(1, 2);
    printf("After recursion");
    return 0;
}
```

Cela affiche

```
The number is 1
The number is 2
After recursion
```

Il existe parfois des situations qui sont plus lisibles et/ou plus faciles à appréhender lorsqu'elles sont exprimées par la récursion plutôt que par une boucle.
