# Les boucles

En Rust, les boucles permettent d'exécuter un bloc de code de façon répétée jusqu'à ce que tu lui dises de s'arrêter ou qu'une certaine condition soit remplie.

La version la plus simple d'une boucle utilise le mot-clé `loop` :

```rust
fn main() {
    loop {
        println!("again!");
    }
}
```

L'extrait de code ci-dessus crée une boucle infinie. Pour sortir d'une boucle, utilise l'instruction `break` :

```rust
fn main() {
    let mut count = 0;
    loop {
        println!("again!");
        count += 1;
        if count > 10 { break; }
    }
}
```

## Les boucles avec `for` et `while`

En plus du mot-clé `loop`, tu peux aussi créer des boucles avec `for` et `while`.

Une boucle `for` sert à parcourir les éléments d'une collection ou d'un itérateur.

```rust
fn main() {
    let a = [10, 20, 30, 40, 50];

    for x in a {
        println!("the value is: {x}");
    }
}
```

Les intervalles sont eux aussi des itérateurs, ce qui rend très pratique leur parcours avec la boucle `for` :

```rust
fn main() {
    for x in 0..10 {
        println!("the value is: {x}");
    }
}
```

Une boucle `while` répète du code jusqu'à ce qu'une condition soit remplie. On pourrait réécrire l'exemple précédent avec une boucle `while` de la façon suivante :

```rust
fn main() {
    let a = [10, 20, 30, 40, 50];
    let mut index = 0;

    while index < 5 {
        println!("the value is: {}", a[index]);

        index += 1;
    }
}
```

Voir [https://doc.rust-lang.org/book/ch03-05-control-flow.html#repetition-with-loops](repetition with loops) dans le livre sur Rust pour plus d'informations sur les boucles.
