# Indices

## Général

- Il existe trois principaux types de structures conditionnelles en Swift : les instructions `if`, les instructions `switch` et les instructions `guard`.

## 1. Détermine si tu peux te permettre les mensualités d'une voiture donnée

- Pense à diviser le prix total de la voiture par le nombre de mois pour calculer la mensualité.
- Tu peux utiliser `+` pour concaténer deux _strings_.

## 2. Détermine le type de permis de conduire dont tu auras besoin

- Les instructions `switch` sont bien adaptées pour traiter proprement un grand nombre de cas.
- Tu peux gérer plusieurs cas avec un seul cas de `switch` lorsque le comportement doit être identique pour tous.
- Le cas `default` gère tous les cas qui ne sont pas explicitement listés.

## 3. Calcule les frais d'immatriculation de ton nouveau véhicule

- L'instruction `guard` s'utilise dans les situations où une sortie anticipée est souhaitable, car le traitement qui suit n'est pas nécessaire (ou pas possible).
- Tu n'as besoin de faire le calcul avec la formule que si le véhicule a moins de 10 ans.
