# Utilise `Keyword.get_values`

Les listes de mots-clés peuvent contenir plusieurs valeurs pour une même clé, ce qui rend fastidieux la récupération de toutes ces valeurs. Le module `Keyword`, en plus de `Keyword.get` qui permet d'obtenir une seule valeur, fournit aussi `Keyword.get_values` pour en obtenir plusieurs.
Utilise `Keyword.get_values` pour filtrer les vins par couleur.
