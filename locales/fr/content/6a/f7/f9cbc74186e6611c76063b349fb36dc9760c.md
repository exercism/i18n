# Introduction

En JavaScript, les _template strings_ permettent d'intégrer des expressions dans des chaînes de caractères, ce que l'on appelle aussi l'interpolation de chaînes. Cette fonctionnalité étend les possibilités de l'objet global [`String`][string-reference] intégré au langage.

Tu peux créer des _template strings_ en JavaScript en entourant le texte de _backticks_. Elles permettent non seulement au texte de contenir des retours à la ligne et d'autres caractères spéciaux, mais tu peux aussi y intégrer des variables et d'autres expressions.

```javascript
const num1 = 1;
const num2 = 2;

`Adding ${num1} and ${num2} gives ${num1 + num2}.`;
// => Adding 1 and 2 gives 3.
```

Dans l'exemple ci-dessus, les _backticks_ (<code>\`\`</code>) servent à représenter une _template string_. Le `${...}` est l'espace réservé qui sert à la substitution.
Tous les types qui ne sont pas des _strings_ sont convertis _implicitement_ en _strings_.
Ce sujet est abordé dans le concept [conversion de types][type-conversion-concept].
Tous les types d'expressions peuvent être utilisés avec les _template strings_.

```javascript
const track = 'JavaScript';

`This track on exercism.org is ${track.toUpperCase()}.`;
// => This track on exercism.org is JAVASCRIPT.
```

Quand tu as besoin de mettre en forme des _strings_ sur plusieurs lignes :

```javascript
`This is an example of using template
strings to accomplish multiple
lines`;

/* => This is an example of using template
     strings to accomplish multiple
     lines
*/
```

Si tu veux représenter un retour à la ligne dans une _string_ classique plutôt que d'utiliser une _template string_ (c'est-à-dire sans _backticks_), tu peux utiliser la séquence d'échappement `\n` :

```javascript
'This is an example of using the newline escape sequence!\nWithout backticks';

/* => This is an example of using the newline escape sequence!
      Without backticks
*/
```

Grâce aux possibilités de substitution disponibles, tu peux aussi introduire de la logique dans le processus pour déterminer ce que doit être la _string_ de sortie.
Une façon de gérer cette logique consiste à utiliser l'[opérateur ternaire][ternary-operator].
Cela offre la même fonctionnalité conditionnelle `if/else` dans un format légèrement différent.

Pour intégrer de la logique dans la syntaxe des _template strings_ :

```javascript
const grade = 95;

`You have ${grade > 90 ? 'passed' : 'failed'} the exam.`;
// => You have passed the exam.
```
