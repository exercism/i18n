# Ajout aux instructions

## Implémentation

Dans le paquet twobucket, implémente une _func_ Go, Solve, avec la signature suivante :

```go
func Solve(sizeBucketOne,
	sizeBucketTwo, goalAmount int, startBucket string,
) (goalBucket string, numSteps, otherBucketLevel int, e error)
```

Solve renvoie quatre valeurs : le seau cible (« one » ou « two »), le nombre de coups/étapes pour atteindre la quantité visée, les litres restants dans l'autre seau et une valeur d'erreur.
Renvoie une erreur si un paramètre est invalide ou si aucune solution n'est possible.
