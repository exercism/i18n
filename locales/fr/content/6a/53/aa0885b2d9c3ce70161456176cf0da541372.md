## Généralités

- _Strings_ : le `str` en particulier est toujours un facteur ici
- Unicode : compromis de performance et de fonctionnalités entre les méthodes ASCII et les méthodes Unicode. Les _benchmarks_ sont faussés quand le _benchmark_ utilise des méthodes Unicode et que la solution utilise des méthodes ASCII.
- Itérateurs : parcourir l'entrée ou des morceaux de celle-ci.
- Collections : parcourir un `HashMap` et utiliser `Entry`. Les _handles_ sont généralement rassemblés dans un `Vec`.
- Références
- Nombres : le trait `Add` en particulier
- Boucle `for` : impossible de joindre des threads dans un itérateur à cause de `move`.
- **Opt** Visibilité : garder les détails d'implémentation non publics
- **Opt** tranches : `.chunks()` est une méthode souvent utilisée pour découper l'entrée entre les threads de travail. On utilise sinon des sous-tranches.
- **Opt** Fonctions d'ordre supérieur : les `HashMap` peuvent être fusionnés par une fonction d'ordre supérieur avec un itérateur.
- **Opt** Types : pour diviser l'entrée, on peut convertir des entiers en nombres à virgule flottante afin d'appliquer un arrondi
- **Opt** _Crates_

## Approche std avec ou sans canaux

- Parallélisme : sous-thème, le lancement et la jonction de threads.
- Itérateurs : sous-thème, l'évaluation paresseuse ; lancer et joindre des threads avec un même itérateur empêche le parallélisme.
- Durées de vie : sous-thèmes, la `'static lifetime` et la sémantique explicite de `move`
- Itérateurs/durées de vie : sous-thème, les itérateurs consommateurs ; on ne peut pas joindre des threads avec un itérateur.
- Type `Option` : déballer le résultat d'un thread ou d'un canal
- Fonctions : les fonctions d'ordre supérieur sont spécifiquement nécessaires pour lancer des threads. Les _closures_ sont ici une option.

## Approche std avec canaux

- Parallélisme : sous-thème, les canaux.
- Tuples : `mpsc::channel()` renvoie un tuple
- Déstructuration : un tuple peut être déstructuré à l'affectation
- Durées de vie : `drop()`

## Approche alternative avec des variables partagées

- Comptage de références : partager des données agrégées entre threads avec une collection à comptage de références.
- **Mention honorable** : parallélisme, sous-thème des mutex. Pas nécessaire ni utile pour cet exercice, mais un concept courant malgré tout. Lié : `RwLock`.

### Exemple avec std et des canaux

```rust
use std::collections::HashMap;
use std::thread;
use std::sync::mpsc;

pub fn frequency(input: &[&str], worker_count: usize) -> HashMap<char, usize> {
    let (tx, rx) = mpsc::channel();

    let _handles = input.chunks((input.len() as f64 / worker_count as f64).ceil() as usize)
        .map(|slice| slice.concat())
        .map(|slice| {
            let tx = tx.clone();
            thread::spawn(move || {
                let mut map: HashMap<char, usize> = HashMap::new();
                for chr in slice.chars().filter(|c| c.is_alphabetic()) {
                    if let Some(c) = chr.to_lowercase().next() {
                        (*map.entry(c).or_insert(0)) += 1;
                    };
                }
                tx.send(map).unwrap()
            })
        }).collect::<Vec<_>>();

    drop(tx);

    let mut result: HashMap<char, usize> = HashMap::new();
    for received in rx {
        for (c, count) in received {
            *result.entry(c).or_insert(0) += count;
        }
    }

    result
}
```

### Exemple de _crate_ avec `Arc`

```rust
use std::collections::HashMap;
use std::iter::FromIterator;
use std::sync::Arc;
use dashmap::DashMap;

pub fn frequency(input: &[&str], worker_count: usize) -> HashMap<char, usize> {
    let map: Arc<DashMap<char, usize>> = Arc::new(DashMap::new());

    let handles = input
        .chunks((input.len() as f64 / worker_count as f64).ceil() as usize)
        .map(|slice| slice.concat())
        .map(|slice| {
            let map = map.clone();
            std::thread::spawn(move || {
                for c in slice.chars().filter(|c|c.is_alphabetic())
                  .flat_map(|c| c.to_lowercase().next()) {
                    *map.entry(c).or_insert(0) += 1;
                }
            })
        }).collect::<Vec<_>>();

    for h in handles {
        h.join().unwrap();
    }

    map.iter().map(|x| (*x.key(), *x.value())).collect()
}
```
