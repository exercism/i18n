# Indices

## 1. Deux façons de dire une ligne

- `.upper` et `.lower` fonctionnent sur une _string_ entière, pas seulement sur un caractère.
- `whisper` ajoute `"..."` à chaque extrémité de la ligne mise en minuscules.

## 2. Répète une ligne

- Le type de l'argument s'écrit `ROUT{STR}:STR` : les types des arguments entre accolades, la réponse après le deux-points.
- Le corps tient en une ligne : `return part.call(line);`
- `rehearse` ne doit pas mentionner `shout` ni `whisper`. Ne pas savoir, c'est tout l'intérêt de prendre une routine liée.

## 3. La scène entière

- Une boucle et un `FSTR`, comme dans `rehearsal-script`.
- Appelle `part.call(...)` sur chaque ligne, et place le `" "` devant chaque ligne sauf la première.

## 4. Renvoie une façon de dire les choses

- Le type de retour est `ROUT{STR}:STR`, exactement comme le type de l'argument dans la tâche 2.
- `bind(shout(_))` à l'intérieur de la classe : aucun nom de classe n'est nécessaire, comme pour toute routine appelée depuis sa propre classe.
- `return bind(...)` ne passe pas l'analyse syntaxique. Un `bind` doit d'abord se trouver à droite d'une affectation :

  ```sather
     part : ROUT{STR}:STR;
     if ... then part := bind(shout(_)); else ... end;
     return part;
  ```

- Deux cas, donc un `if`, ou un `case` avec son `else`.

## 5. Fixe un argument

- `repeat` est elle-même une routine ordinaire : une boucle, un `FSTR`, et `1.upto!(times)`.
- `doubler` la lie en écrivant le nombre explicitement et en laissant la ligne sous forme de trou : `bind(repeat(2, _))`. Comme dans la tâche 4, place-la dans une variable et renvoie celle-ci.
- Seul le `_` devient un argument de la routine liée, c'est pourquoi `bind(repeat(2, _))` a le type `ROUT{STR}:STR` et non `ROUT{INT,STR}:STR`.
