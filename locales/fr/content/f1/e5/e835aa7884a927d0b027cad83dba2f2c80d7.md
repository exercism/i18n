# préférer une constante extraite au niveau supérieur

Pense à extraire la constante vers la portée de niveau supérieur :

```javascript
const %{name} = %{value}

// the rest of your code below it
export %{method.signature}
```

Seules les fonctions, les classes et les constantes qui sont `export`ées sont visibles et accessibles depuis l'extérieur.
Ces constantes peuvent rester dans le même fichier sans être exposées au reste du code.
De plus, extraire les constantes économise de la mémoire, car cela évite les allocations répétées dans les fonctions quand ces mêmes constantes sont réutilisées.
