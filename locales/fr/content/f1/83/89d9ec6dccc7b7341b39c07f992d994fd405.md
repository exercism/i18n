# Instructions

Une banque bien occupée sert les clients qui attendent par *priorité*, plutôt que dans l'ordre d'arrivée. Chaque client reçoit un numéro de priorité au moment où il prend un ticket, et le guichetier sert toujours le numéro le plus bas (`1` est le plus urgent). Un tas min est la file d'attente idéale.

## 1. Ouvre la file

Définis `new-queue`, qui ne prend rien et renvoie une nouvelle file de priorité vide.

```factor
new-queue
! => an empty priority queue
```

## 2. Ajoute un client

Définis `join-queue`, qui prend un nom de client, un numéro de priorité et une file. Il ajoute le client à la file et renvoie la file, ce qui permet d'ajouter les clients les uns après les autres.

```factor
new-queue "alice" 5 rot join-queue "bob" 2 rot join-queue
! => the queue, now holding alice (5) and bob (2)
```

## 3. Qui est le suivant ?

Définis `next-name`, qui prend une file et renvoie le nom du client qui doit être servi ensuite, celui dont le numéro de priorité est le plus bas, *sans* le retirer.

```factor
new-queue "alice" 5 rot join-queue "bob" 2 rot join-queue next-name .
! => "bob"
```

## 4. Sers tout le monde

Définis `serve-all`, qui prend une file et renvoie les noms de tous les clients en attente, dans l'ordre dans lequel ils seraient servis.

```factor
new-queue "alice" 5 rot join-queue "bob" 2 rot join-queue
"carol" 9 rot join-queue serve-all .
! => { "bob" "alice" "carol" }
```
