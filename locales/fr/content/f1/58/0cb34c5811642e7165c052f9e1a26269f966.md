### Introduction

Bienvenue dans le premier exercice du parcours Java !

Ce document est un guide pas à pas pour résoudre cet exercice.
Les instructions devraient fonctionner aussi bien sous Windows, macOS et Linux.

Même si tu connais déjà les bases de Java, parcourir ce guide peut t'être utile, car il t'aidera à comprendre la sortie de l'outil que nous utilisons pour compiler et tester le code, Gradle, et il te fera découvrir quelques-uns des schémas communs à tous les exercices de ce parcours.

### Structure de l'exercice

Quand tu récupères un nouvel exercice Java, tu reçois :

- __un ou plusieurs fichiers de test__ (toujours).
Ils se trouvent dans le répertoire `src/test/java` et définissent un ensemble de tests que ta solution doit satisfaire avant que tu puisses affirmer qu'elle fonctionne.
- __un ou plusieurs fichiers de départ__ (au début).
S'ils sont fournis, ils se trouvent dans le répertoire `src/main/java` et définissent les squelettes des classes dont tu auras besoin pour résoudre le problème en cours.

### Étape 1 : corrige la solution

Que tu travailles en local ou dans l'éditeur en ligne, tu devrais trouver le code suivant :

```java
String getGreeting() {
    return "Goodbye, Mars!";
}
```

L'objectif est de modifier le code fourni pour qu'il produise le texte `"Hello, World!"` au lieu de `"Goodbye, Mars!"`.

### Étape 2 : lance les tests

Une fois tes corrections faites et ta solution implémentée, relance les tests.
Tu peux lancer les tests depuis l'éditeur en ligne ou en local sur ta machine :

- Pour lancer les tests dans l'éditeur en ligne, clique sur le bouton _« Exécuter les tests »_.
- Pour lancer les tests en local, consulte [Tester en local sur le parcours Java][Testing locally on the java track] Si les tests échouent, ce n'est pas grave ! Regarde ce que t'indique le message d'erreur, modifie ton code et relance les tests ; quand tes tests passent, passe à l'étape suivante.

### Étape 3 : soumets ta première itération

Une fois ta solution fonctionnelle et relue, tu peux la soumettre sur exercism.org.
Tu peux soumettre la solution depuis l'éditeur en ligne ou en local avec [l'Exercism CLI][Working Locally] :

- Pour soumettre l'exercice en local, commence par [installer l'Exercism CLI][Working Locally] si ce n'est pas déjà fait, puis soumets les fichiers de ta solution, par exemple :

  ```sh
  exercism submit <file location>
  ```

- Remplace `<file location>` par le chemin relatif de ton fichier `Greeter.java` ; ainsi, si tu travailles dans `C:\exercism\java\hello-world`, la commande sera

  ```sh
  exercism submit .\src\main\java\Greeter.java
  ```

- Si tu veux utiliser l'éditeur en ligne pour soumettre ta solution, clique simplement sur le bouton _« Soumettre »_ !

Pour en savoir plus sur la soumission d'une solution en local :

- [Soumettre en local][Working Locally]

### Deviens mentor

Le cœur d'Exercism, ce sont les conversations sur les pratiques de programmation.
C'est vraiment amusant de s'entraîner, mais c'est en échangeant avec les autres, sur leurs tentatives comme sur les tiennes, que tu obtiens des retours.
Ces retours peuvent t'aider à voir ce que tu fais bien et ce que tu pourrais améliorer.

Certaines soumissions seront presque identiques à la tienne, d'autres seront complètement différentes.
Voir les deux peut être instructif et intéressant.

Les mentors relisent les solutions soumises dans le parcours qu'ils ont choisi de mentorer, pour aider les apprenants à apprendre autant que possible.

Pour en savoir plus sur le mentorat, consulte [la documentation d'Exercism][Mentoring].
