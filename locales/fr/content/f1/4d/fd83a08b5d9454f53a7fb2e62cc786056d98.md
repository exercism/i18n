# Indices

## Généralités

- Déclare les quatre symboles cardinaux et les quatre symboles de relèvement relatif avec une seule ligne `SYMBOLS:` : `SYMBOLS: north east south west ahead starboard behind port ;`
- Chaque tuple se déclare avec `TUPLE: <class> <slot1> <slot2> ;`.
- Une ligne `GENERIC:` déclare le mot ; chaque ligne `M:` ajoute une méthode pour une classe. Utilise `M::` si tu veux des variables locales nommées dans le corps de la méthode.

## 1. `>cartesian` pour les points cardinaux

- Un petit `case` sur les quatre symboles de direction suffit.
- `{ north [ 0 1 ] }` : le corps empile simplement les deux valeurs ; le test attend `x` sous `y` sur la pile.

## 2. `>cartesian` pour les coordonnées polaires

- Convertis les degrés en radians : `bearing pi * 180 /`.
- `sin` et `cos` se trouvent dans `math.functions`.
- Empile `magnitude * sin(rad)` puis `magnitude * cos(rad)`.

## 3. `>cartesian` pour les relèvements relatifs

- Déclare une variable dynamique : `SYMBOL: heading`.
- Lis-la dans ta méthode avec `heading get`.
- Associe `ahead/starboard/behind/port` à un décalage `0/90/180/270` avec un `case`, puis ajoute le cap. À partir de là, c'est la même conversion polaire que pour la tâche 2 : pense à extraire une fonction auxiliaire `: deg>cartesian ( magnitude bearing -- x y ) ... ;`.

## 4. `flip`

- `change-direction` sur un `cardinal`, et `change-bearing` sur un `polar` ou un `relative`, construisent un nouveau tuple dont un seul slot est modifié, les autres restant inchangés : `[ <transformation-quotation> ] change-bearing`.
- Pour la rotation du `polar` : `[ 180 + 360 mod ] change-bearing`.

## 5. `add-bearings`

- Appelle `>cartesian` sur chaque entrée, puis additionne les composantes X et les composantes Y. Les variables locales rendent cela lisible :
  ```factor
  :: add-bearings ( a b -- x y )
      a >cartesian :> ay :> ax
      b >cartesian :> by :> bx
      ax bx +
      ay by + ;
  ```
