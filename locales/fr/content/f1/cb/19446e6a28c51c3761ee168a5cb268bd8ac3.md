# Introduction

Contrairement à beaucoup d'autres langages, JavaScript possède deux entités différentes qui représentent l'absence d'une valeur (significative) : `null` et `undefined`.

## Null

La valeur primitive `null` sert de « valeur vide » intentionnelle pour les variables de tout type.

```javascript
let name = null;
// name is intentionally set to "empty" because it is not
// available
```

Pour vérifier si une variable vaut `null`, utilise l'[opérateur d'égalité stricte][mdn-strict-equality] `===`.

```javascript
let name = null;

name === null;
// => true
```

## Undefined

> Une variable à laquelle aucune valeur n'a été affectée est de type `undefined`.[^1]

Cela signifie que `null` représente une valeur vide (mais qui reste une valeur), tandis que `undefined` représente l'absence totale de valeur. 🤯

`undefined` apparaît dans différents contextes.

- Si une variable est déclarée sans valeur (initialisation), elle vaut `undefined`.

  ```js
  let name;
  console.log(name); // => undefined
  ```

- Si tu essaies d'accéder à la valeur associée à une clé qui n'existe pas dans un objet, tu obtiens `undefined`.

  ```js
  let obj = {
    name: 'John',
  };
  console.log(obj.age); // => undefined
  ```

- Si une fonction ne renvoie pas de valeur, le résultat est `undefined`.

  ```js
  function printName(name) {
    'My name is ' + name;
  }
  console.log(printName('John')); // => undefined
  ```

- Si aucun argument n'est passé à une fonction, il vaut `undefined`, sauf si cet argument a une valeur par défaut.

  ```js
  function printName(name) {
    return name;
  }
  console.log(printName()); // => undefined
  ```

Pour vérifier si une variable vaut `undefined`, utilise l'opérateur d'égalité stricte `===`.

```javascript
let name;

name === undefined;
// => true
```

## Chaînage optionnel

Si tu essaies de récupérer une valeur imbriquée dans un objet alors que la clé parente n'existe pas, JavaScript lève une erreur.
Pour éviter ça facilement, le chaînage optionnel a été ajouté à la spécification du langage en 2020.
Avec l'opérateur de chaînage optionnel `?.`, tu peux t'assurer que JavaScript n'essaie d'accéder à la clé imbriquée que si la clé parente n'était pas `null` ou `undefined`.
Sinon, `undefined` est renvoyé.

```javascript
const obj = {
  address: {
    street: 'Trincomalee Highway',
    city: 'Batticaloa',
  },
};

obj.address.zipCode;
// => undefined

obj.residence.street;
// => TypeError: Cannot read property 'street' of undefined

obj.residence?.street;
// => undefined
```

## Coalescence des nuls

Il y a des situations où tu veux appliquer une valeur par défaut au cas où une variable vaut `null` ou `undefined` (mais seulement dans ce cas).
Pour répondre à ce besoin, l'opérateur de coalescence des nuls `??` a été introduit en 2020.
Il renvoie l'opérande de droite uniquement lorsque l'opérande de gauche vaut `null` ou `undefined`.
Sinon, c'est l'opérande de gauche qui est renvoyé.

```javascript
let amount = null;
amount = amount ?? 1;
// => 1

amount = 0;
amount = amount ?? 1;
// => 0
```
