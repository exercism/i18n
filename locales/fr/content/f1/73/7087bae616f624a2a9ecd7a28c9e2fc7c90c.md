# Instructions

Il était une fois une ville animée appelée Cyberspace.
Cyberspace était une métropole numérique, où des millions d'habitants se connectaient et se déconnectaient chaque jour.
Pour garder la trace de tous ces utilisateurs, Cyberspace disposait d'un fichier spécial appelé /etc/passwd.

Le fichier /etc/passwd était comme un annuaire téléphonique pour la ville.
Il listait chaque utilisateur possédant un compte sur le système, ainsi que quelques informations importantes sur chacun d'eux :

| n   | champ |
| --- | --- |
| 1   | nom d'utilisateur |
| 2   | mot de passe (« x » indique que le mot de passe réel est stocké ailleurs, pour des raisons de sécurité) |
| 3   | UID, un identifiant utilisateur numérique unique |
| 4   | GID, un identifiant de groupe numérique unique (généralement identique à l'UID) |
| 5   | infos utilisateur (généralement le nom complet de l'utilisateur, mais peut contenir d'autres informations) |
| 6   | répertoire personnel |
| 7   | shell de connexion |

Les champs sont séparés par le caractère deux-points.
Voici une entrée typique :

```none
glennj:x:1010:1010:Glenn Jackman:/home/glennj:/usr/local/bin/fish
```

Le fichier était géré par une équipe d'administrateurs système, chargés de créer de nouveaux comptes, de mettre à jour les comptes existants et de supprimer les anciens comptes.
Les administrateurs système étaient les gardiens de Cyberspace, veillant à ce que seuls les utilisateurs autorisés puissent accéder au système.

Un jour, un nouvel administrateur système nommé Alex fut recruté pour rejoindre l'équipe.
Alex, enthousiaste à l'idée de prendre ce poste, a rapidement appris les rouages du fichier /etc/passwd.
Alex a appris à ajouter de nouveaux utilisateurs au système, à mettre à jour les informations des utilisateurs et à supprimer les anciens comptes.

Alors qu'Alex travaillait sur le fichier /etc/passwd, quelque chose d'étrange a été remarqué.
Certains utilisateurs avaient des répertoires personnels étranges ou inhabituels.
Pour certains, le répertoire personnel était défini sur /dev/null, tandis que pour d'autres, il pointait vers des chemins étranges qui n'existaient pas.

Alex a compris que ces utilisateurs n'étaient pas de vraies personnes, mais plutôt des faux comptes créés par des pirates informatiques.
Les pirates avaient trouvé un moyen d'exploiter une faille du système et avaient créé ces faux comptes pour accéder à Cyberspace.

Alex savait qu'il fallait agir.
Alex a utilisé awk pour analyser le fichier /etc/passwd et a écrit un script pour identifier tous les faux comptes.
Alex a ensuite travaillé avec le reste de l'équipe pour supprimer ces comptes et pour corriger la faille qui avait permis aux pirates de les créer au départ.

Grâce à l'utilisation d'awk par Alex, l'équipe a pu identifier et supprimer les faux comptes, et faire de Cyberspace un endroit plus sûr pour tout le monde.
Les administrateurs système ont continué à gérer le fichier /etc/passwd, en le maintenant à jour et sécurisé, et en veillant à ce que seuls les utilisateurs autorisés puissent accéder au système.

Maintenant, c'est à ton tour d'être un administrateur système comme Alex.

~~~~exercism/note
Voici quelques éléments de syntaxe AWK supplémentaires dont tu auras besoin pour résoudre cet exercice.

* Les opérateurs booléens sont similaires à ceux d'autres langages :

    | opération | exemple            |
    | --------- | ------------------ |
    | ET        | `expr1 && expr2`   |
    | OU        | `expr1 \|\| expr2` |
    | PAS       | `! expr`           |

* Appeler une fonction utilise une syntaxe familière :

    ```awk
    function greet(name) {

    }

    }
    ```

## 1. Liste les noms d'utilisateur

Écris un programme awk qui affiche le premier champ séparé par des deux-points de chaque ligne du fichier passwd.

## 2. Affiche les numéros de ligne

Écris une commande awk qui affiche le numéro de ligne de chaque enregistrement du fichier d'entrée.
N'affiche que le numéro de ligne, aucune autre information.

## 3. Affiche les enregistrements dont le répertoire personnel n'est pas valide.

Dans Cyberspace, un répertoire personnel « valide » commence par `/home` ou `/root`.
Affiche les enregistrements du fichier d'entrée dont le répertoire personnel n'est **pas valide**.

## 4. Affiche les utilisateurs valides qui utilisent bash

Affiche les enregistrements pour lesquels le répertoire personnel est valide **et** le shell de connexion est `bash`.
