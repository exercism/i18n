# À propos

[Java](https://go.java/index.html) est l'un des langages de programmation les plus populaires qui soient, grâce à sa polyvalence et à sa compatibilité.
Il est largement utilisé pour le développement logiciel, les applications mobiles et la conception de systèmes plus importants.

Java est né en 1995 et est maintenu par [Oracle](https://www.oracle.com/index.html).
Même s'il n'est pas aussi jeune que certains langages récents, Java reste extrêmement populaire.
Il a été conçu pour être rapide, sûr, fiable, accessible aux débutants et très portable.
Cet avantage de portabilité existe parce que Java s'exécute sur une [machine virtuelle Java (JVM)](https://en.wikipedia.org/wiki/Java_virtual_machine) compatible multiplateforme.
Les applications Android sont elles aussi développées en Java, puisque le [système d'exploitation Android](<https://en.wikipedia.org/wiki/Android_(operating_system)>) fonctionne dans un environnement Java.

La communauté Java est immense !
GitHub, par exemple, compte plus de 1,5 million de projets Java.
Il faut aussi mentionner que Java possède la deuxième plus grande communauté sur [StackOverflow](https://stackoverflow.com/questions/tagged/java) !
C'est important, car plus la communauté d'un langage de programmation est grande, plus on a de chances d'obtenir de l'aide.

Java dispose aussi d'un ensemble puissant et bien conçu d'[API (interfaces de programmation d'application)](https://docs.oracle.com/en/java/javase/11/docs/api/index.html) intégrées, qui peuvent servir à des activités variées comme la connexion à des bases de données, la mise en réseau, les entrées-sorties, l'analyse XML, les utilitaires, et bien plus encore.

Des ordinateurs portables aux centres de données, des consoles de jeux aux superordinateurs scientifiques, des téléphones mobiles à Internet, [Java est partout](https://en.wikipedia.org/wiki/Write_once,_run_anywhere) !
