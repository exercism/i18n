# Introduction

## Comparer

### Comparer des nombres

En `jq`, les nombres peuvent être comparés à l'aide des opérateurs relationnels et d'égalité suivants.

| Comparaison           | Opérateur |
| --------------------- | --------- |
| Supérieur à           | `a > b`   |
| Supérieur ou égal à   | `a >= b`  |
| Inférieur à           | `a < b`   |
| Inférieur ou égal à   | `a <= b`  |
| Égal à                | `a == b`  |
| Différent de          | `a != b`  |

Le résultat de la comparaison est toujours une valeur booléenne, donc soit `true`, soit `false`.

```jq
1 < 3,      # => true
2 != 2,     # => false
1 == 1.0    # => true
            # All numbers are floating-points, so this is different syntax
            # for the exact same value.
```

### Comparer des _strings_

Les opérateurs de comparaison ci-dessus peuvent aussi servir à comparer des _strings_.
Dans ce cas, c'est un ordre lexicographique (de dictionnaire) qui s'applique.
Le classement se fait _par valeur de point de code Unicode_.

```jq
"Apple" > "Pear",   # => false
"a" < "above",      # => true
"a" == "A"          # => false
```

Il faut faire attention quand on compare deux variables qui semblent contenir des valeurs numériques mais qui sont de type _string_.
À cause de l'ordre lexicographique, le résultat ne sera pas le même que si l'on comparait des valeurs de type nombre.

```jq
10 < 2,     # => false
"10" < "2"  # => true (because "1" comes before "2")
```

### L'égalité « stricte »

L'opérateur `==` de `jq` est comme le `===` de JavaScript en ce sens que des choses qui « se ressemblent » mais qui sont de types différents ne sont pas égales.

```jq
"3" == 3    # => false
            # the value on the left has type string,
            # the value on the right has type number.
```

### Comparer des tableaux

Deux tableaux sont égaux si tous les éléments correspondants sont égaux.

```jq
[1, 2, 3] == [1, 2, 3]      # => true
[1, 2, 3] == [1, 3, 2]      # => false, different order
[1, 2, 3] == [1, 2, "3"]    # => false, different types
```

### Comparer des objets

Deux objets sont égaux s'ils ont les mêmes paires clé-valeur.

```jq
{name: "Joe", age: 42} == {age: 42, name: "Joe"}                # => true
{name: "Joe", age: 42} == {age: 42, name: "Jane"}               # => false
{name: "Joe", age: 42} == {age: "42", name: "Joe"}              # => false
{name: "Joe", age: 42} == {age: 42, name: "Joe", height: 175}   # => false

# comparisons will drill down as deeply as required
{a: {b: {c: [1, 2]}}} == {a: {b: {c: [1, 2]}}}                  # => true
{a: {b: {c: [1, 2]}}} == {a: {b: {c: [1, 2, 3]}}}               # => false
```

## Les conditions

### L'expression `if`

L'**expression conditionnelle** de `jq` s'écrit `if A then B else C end`.

`if-then-else` est un filtre, comme toutes les fonctions natives de `jq` : il prend une entrée et produit une sortie.

Si l'expression `A` produit une valeur considérée comme vraie, le filtre `if` évalue `B`.
Sinon, il évalue `C`.
L'entrée du filtre `if` est transmise à `B` ou à `C`.

```jq
42 | if . < 50 then "small" else "big" end      # => "small"
```

```jq
5 | if . % 2 == 0 then . / 2 else . * 4 end     # => 20
```

~~~~exercism/note
La clause `else` est **facultative** ; les deux instructions suivantes sont équivalentes.

```jq
if A then B else . end
if A then B end
```
~~~~

### Les instructions `if` imbriquées

On peut ajouter d'autres conditions avec `elif`.

```jq
42 | if . < 33 then "small"
     elif . < 66 then "medium"
     else "big"
     end
# => "medium"
```

Utilise autant de clauses `elif` que nécessaire.

### Valeurs vraies et fausses

Les seules valeurs « fausses » en `jq` sont : `false` et `null`.
Tout le reste est « vrai », même le nombre zéro, la chaîne vide, le tableau vide et l'objet vide.

### Les opérateurs booléens

Les **opérateurs booléens** `and` et `or` permettent de construire des requêtes complexes.

```jq
42 | if . < 33 or . > 66 then "big or small"
     else "medium"
     end
```

Pour nier, utilise `not`. C'est un **filtre**, pas un opérateur.

```jq
42 | if (. < 33 or . > 66 | not) then "medium"
     else "big or small"
     end
```

### L'opérateur alternatif

L'**opérateur alternatif** permet de spécifier une valeur « par défaut » quand une expression est fausse ou nulle.

```jq
A // B

# This is identical to
if A then A else B end
```

Pour illustrer

```jq
[3, 5, 18] | add / 2       # => 13
[]         | add / 2       # => error: null (null) and number (2) cannot be divided
[]         | add // 0 / 2  # => 0
```
