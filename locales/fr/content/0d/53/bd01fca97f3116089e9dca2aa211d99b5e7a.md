# Introduction

En Cairo, les modules aident à organiser le code en regroupant les fonctions, les structures et les traits qui vont ensemble dans des espaces de noms séparés.
Le mot-clé `use` simplifie l'accès à ces éléments en les faisant entrer dans la portée, ce qui réduit les répétitions lors de l'appel de fonctions ou de l'utilisation de types.
Cette section présente les bonnes pratiques pour structurer des modules, importer efficacement des éléments et réexporter, afin d'obtenir un code plus propre et plus facile à maintenir.
