# Instructions

Le régisseur veut qu'on tape le script de répétition, dont plusieurs parties se construisent en répétant ou en assemblant des éléments.

Les quatre tâches vont dans la classe `REHEARSAL_SCRIPT`.

## 1. Répète un signal

Étant donné un signal et un nombre, renvoie ce signal répété autant de fois, sans rien entre les répétitions.

```sather
REHEARSAL_SCRIPT::repeat_cue("Ha", 3)
-- => "HaHaHa"
```

Répéter quelque chose zéro fois donne la _string_ vide.

## 2. Les initiales de la distribution

Étant donné la distribution, renvoie la première lettre de chaque nom, mises bout à bout.

```sather
REHEARSAL_SCRIPT::initials(|"Mia", "Ana", "Ben"|)
-- => "MAB"
```

## 3. Numérote les répliques

Étant donné les répliques d'une scène, numérote-les à partir de 1, chacune sur sa propre ligne.

```sather
REHEARSAL_SCRIPT::numbered_lines(|"Enter", "Exit"|)
-- => "1. Enter\n2. Exit"
```

Il y a un retour à la ligne *entre* les répliques et aucun après la dernière. Une scène sans réplique donne la _string_ vide.

## 4. Crie une réplique

Renvoie une réplique dont chaque lettre est passée en majuscule.

```sather
REHEARSAL_SCRIPT::shout("quiet please")
-- => "QUIET PLEASE"
```
