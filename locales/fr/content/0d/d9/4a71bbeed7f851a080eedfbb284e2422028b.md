# Instructions

Tu as été recruté comme spécialiste des expressions régulières dans une entreprise qui développe un Chatbot.

Le projet n'en est qu'à une phase très basique de son développement, aussi ta mission consiste-t-elle à utiliser les expressions régulières pour améliorer la capacité du chatbot à comprendre et à générer du langage naturel.

## Vérifie une commande valide

En plus d'être intelligent, le Chatbot est aussi un assistant fidèle.

Pour poser une question au chatbot, l'utilisateur doit dire le mot « **Chatbot** » en première position de la commande.

Peu importe que le mot-clé soit en majuscules ou en minuscules. Ce qui compte ici, c'est la position du mot.

Implémente la fonction `isValidCommand()` qui aide le Chatbot à reconnaître le moment où l'utilisateur donne une commande.

```javascript
isValidCommand("Chatbot, play a song from the 80's.";
// => True
isValidCommand("Hey Chatbot, where is the closest pharmacy?";
// => False
isValidCommand("CHATBOT, do you have a solution for this challenge?";
// => True
```

## Supprime les emojis chiffrés

Le Chatbot a du mal à comprendre comment les humains utilisent les emojis pour exprimer leurs émotions.

Quand le chatbot reçoit des messages d'utilisateurs, chaque emoji est représenté par « _emoji_ » suivi de son numéro _id_.

Implémente la méthode `removeEmoji()` qui prend une _string_ et supprime tout le chiffrement des emojis dans le message.

Les lignes qui ne contiennent pas de texte d'emoji doivent être renvoyées sans modification.

Supprime simplement le texte de l'emoji. N'essaie pas d'ajuster les espaces.

Pour ce défi en particulier, utilise la syntaxe de constructeur pour créer l'expression régulière.

```javascript
removeEmoji("I love playing videogames emoji3465 it's one of my hobbies");
// => "I love playing videogames  it's one of my hobbies"
```

## Vérifie un numéro de téléphone valide

Comme les fonctionnalités du chatbot se téléchargent sur une application mobile, l'utilisateur est amené à saisir un numéro de téléphone pendant la conversation.

Le problème, c'est que le chatbot ne peut lire et valider qu'un numéro au format spécifique.

Si le numéro est valide (s'il correspond à la séquence de caractères spécifiée par l'**expression régulière**), le chatbot répond par un message qui remercie l'utilisateur et confirme le numéro. Si le numéro n'est pas valide, la fonction informe l'utilisateur que le numéro de téléphone n'est pas valide.

Le format attendu est : (+##) ###-###-###

```javascript
checkPhoneNumber('(+34) 659-771-594');
// => "Thanks! You can now download me to your phone."
checkPhoneNumber('659-771-594');
// => "Oops, it seems like I can't reach out to 659-771-594"
```

## Récupère le lien d'un site web

Le Chatbot est un logiciel vraiment curieux. Même s'il peut faire des recherches sur internet à propos d'un sujet précis, il aime demander aux utilisateurs des sites web sympas ou des URL pour aller trouver des informations pertinentes.

Exemple de conversation :

- **Chatbot** : Salut username, j'aimerais apprendre à coder en JavaScript, tu connais un site web sympa où je pourrais apprendre ?
- **Utilisateur** : J'ai beaucoup appris sur [exercism.org](http://exercism.org)

Implémente la fonction `getURL()` capable de renvoyer un tableau contenant uniquement le lien de chaque site web. Écrire une regex capable de reconnaître n'importe quelle URL serait très compliqué, mais le Chatbot n'a besoin de lire que des URL simples. Pour cet exercice, une URL est toute suite de mots délimitée par des `"."`.

```javascript
getURL(
  'I learned a lot from exercism.org and developer.mozilla.org, but I found ts39.es very boring!',
);
// => ["exercism.org", "developer.mozilla.org", "ts39.es"];
```

## Salue l'utilisateur

Pour stocker les données de toutes les personnes avec qui il a discuté, le chatbot est capable de récupérer le nom complet depuis le profil de l'utilisateur, sous cette forme : **« smith, john »**.

De cette façon, on veut que notre chatbot soit vraiment poli et fasse bonne impression.

Écris la fonction `niceToMeetYou()` qui prend une _string_ contenant le nom complet de l'utilisateur et renvoie la _string_ **« Nice to meet you, John Smith »**

Dans un but pédagogique, implémente la fonction en utilisant une **méthode de remplacement** des expressions régulières.

```javascript
let str = 'Smith, John';

niceToMeetYou(str);
// => "Nice to meet you, John Smith"
```
