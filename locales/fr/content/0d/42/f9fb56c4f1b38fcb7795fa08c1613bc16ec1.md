# À propos

Les classes sont une brique de base essentielle des programmes Swift.
Elles permettent de regrouper des propriétés (des données) et des méthodes (des fonctions) liées dans des unités de fonctionnalité autonomes.

### Définir des classes

Pour définir une classe, utilise le mot-clé `class` suivi du nom de la classe, la définition de la classe étant placée entre accolades :

```swift
class GameCharacter {
    var characterClass: String?
    var name: String?
    var active = false
    let id = makeRandomID()
}
```

Le corps d'une classe peut contenir des propriétés stockées, qui se définissent et se comportent comme des constantes (`let`) ou des variables (`var`) ordinaires.

### Les instances

La définition d'une classe sert de plan : elle définit un nouveau type et décrit à quoi ressemblent ses valeurs, mais elle ne crée à elle seule aucune instance.

Pour créer une *instance* d'une classe, appelle son initialiseur en écrivant le nom de la classe suivi de parenthèses :

```swift
let someCharacter = GameCharacter()
```

Cela crée une nouvelle instance dont les propriétés sont initialisées avec les valeurs par défaut spécifiées dans la définition de la classe.
Pour les propriétés optionnelles sans valeur par défaut explicite (comme `name`), Swift leur attribue `nil` par défaut.

### Accéder aux propriétés

On accède aux propriétés d'une instance à l'aide de la *notation par points* : écris le nom de l'instance, un point (`.`), puis le nom de la propriété.
La notation par points fonctionne aussi pour les propriétés imbriquées.

Tu peux utiliser la notation par points pour lire des valeurs et, si la propriété est modifiable (`var`), lui affecter de nouvelles valeurs :

```swift
someCharacter.name
// => nil

someCharacter.name = "Luther"
someCharacter.name
// => "Luther"

someCharacter.id = "new id"
// Error: Cannot assign to property: 'id' is a 'let' constant
```

### Les méthodes

En plus des propriétés, les classes peuvent définir des *méthodes*, c'est-à-dire des fonctions associées à la classe.

On définit les méthodes à l'intérieur du corps de la classe, avec la syntaxe `func` habituelle.
Si une méthode modifie une propriété, cette propriété doit être déclarée avec `var` :

```swift
class GameCharacter {
    var characterClass: String?
    var name: String?
    var active = false
    let id: String = makeRandomID()

    func takesDamage(_ damage: Double) {
        if damage > 100 {
            active = false
        }
    }

    func sayName() -> String {
        return "My name is \(name ?? "no one"), my class is \(characterClass ?? "undetermined")"
    }
}
```

On appelle les méthodes d'une instance à l'aide de la notation par points, exactement comme les propriétés :

```swift
var myChar = GameCharacter()
myChar.active = true
myChar.takesDamage(200)
myChar.active
// => false
```

### Self

Chaque instance d'une classe possède une propriété implicite nommée `self`, qui désigne l'instance elle-même.
Bien qu'on l'omette souvent lorsqu'on fait référence à des propriétés ou à des méthodes, `self` sert couramment à distinguer les noms de propriétés des noms de paramètres de méthodes lorsqu'ils sont identiques.
