# Introduction

Les fonctions peuvent déclarer des valeurs par défaut pour un ou plusieurs arguments. Prenons cette fonction :

```elixir
def number(n \\ 13), do: "That's not my favorite"
```

Lors de la compilation, Elixir crée une définition de fonction pour `number/0` (sans argument) et `number/1` (un argument).

Si plusieurs arguments ont une valeur par défaut, les valeurs par défaut seront appliquées à la fonction de gauche à droite pour combler les arguments manquants.

Si la fonction a plusieurs clauses, les arguments par défaut doivent être définis dans un en-tête de fonction (une fonction sans corps) avant les clauses de la fonction :

```elixir
def number(n \\ 13)
def number(n) when n < 10, do: "Dream bigger!"
def number(n) when n > 100, do: "Not that big..."
```
