# À propos

N'importe quelle valeur peut être une erreur. `throw` (dans `kernel`) émet un signal ; l'effet de pile du _word_ courant est alors abandonné et le contrôle remonte jusqu'au `recover` englobant le plus proche.

```factor
[ 0 1 / ] [ "div by zero" prepend ] recover
```

`ERROR:` est un _parsing word_ qui définit d'un seul coup une classe de tuple d'erreur *et* un _word_ constructeur :

```factor
ERROR: not-found path ;
! defines:
!   TUPLE: not-found path ;
!   : not-found ( path -- * ) \ not-found boa throw ;
!   : not-found? ( object -- ? ) … class predicate
```

Chaque erreur personnalisée dispose ainsi d'une classe unique, d'un constructeur pratique pour la lever, et d'un prédicat de classe (`name?`) pour tester les erreurs interceptées :

```factor
[ "/missing" not-found ]
[ dup not-found? [ path>> "missing: " prepend ] [ drop "other" ] if ]
recover
```

Pour un nettoyage de type _finally_, voir `cleanup` dans `continuations`. Pour les conditions redémarrables, voir `condition`.
