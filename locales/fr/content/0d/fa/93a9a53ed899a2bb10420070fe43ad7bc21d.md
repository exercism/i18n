# Introduction

## Tableaux

En C#, les structures de données qui peuvent contenir zéro élément ou plus sont appelées _collections_. Un **tableau** est une collection dont la taille/la longueur est fixe et dont tous les éléments doivent être du même type. On peut affecter des éléments à un tableau ou les récupérer depuis celui-ci à l'aide d'un indice. Les tableaux en C# sont indexés à partir de zéro, ce qui signifie que l'indice du premier élément est toujours zéro :

```csharp
// Declare array with explicit size (size is 2)
int[] twoInts = new int[2];

// Assign second element by index
twoInts[1] = 8;

// Retrieve the second element by index
twoInts[1] == 8; // => true
```

On peut aussi définir des tableaux à l'aide d'une notation abrégée qui permet à la fois de créer le tableau et de définir sa valeur. Comme le compilateur peut désormais déterminer le nombre d'éléments que le tableau contiendra, la longueur peut être omise :

```csharp
// Three equivalent ways to declare and initialize an array (size is 3)
int[] threeIntsV1 = new int[] { 4, 9, 7 };
int[] threeIntsV2 = new[] { 4, 9, 7 };
int[] threeIntsV3 = { 4, 9, 7 };
```

On peut manipuler les tableaux soit en appelant les méthodes ou les propriétés d'une instance de tableau, soit en utilisant les méthodes statiques définies dans la classe `Array`.

## Boucles for

Une boucle `for` permet d'exécuter du code de manière répétée jusqu'à ce qu'une condition soit remplie.

```csharp
for (int i = 0; i < 5; i++)
{
    System.Console.Write(i);
}

// => 01234
```

Une boucle `for` se compose de quatre parties :

1. L'initialiseur : exécuté une fois avant d'entrer dans la boucle. Sert généralement à définir les variables utilisées dans la boucle.
2. La condition : évaluée avant chaque itération de la boucle. La boucle continue de s'exécuter tant que cette condition vaut `true`.
3. L'itérateur : exécuté après chaque itération de la boucle. Sert généralement à modifier (souvent : incrémenter/décrémenter) la ou les variables de la boucle.
4. Le corps : le code qui est exécuté à chaque itération de la boucle.

## Boucles foreach

Le fait qu'un tableau soit aussi une _collection_ signifie qu'en plus d'accéder aux valeurs par leur indice, tu peux parcourir _toutes_ ses valeurs à l'aide d'une boucle `foreach` :

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // Output the vowel
    System.Console.Write(vowel);
}

// => aeiou
```
