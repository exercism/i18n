# Complément aux instructions

## Implémentation

Pour terminer cet exercice, tu dois définir le type de données `stopwatch` et implémenter les fonctions :

- newStopwatch
- start
- stop
- lap
- reset
- advanceTime
- getState
- currentLap
- total
- previousLaps

Tu trouveras déjà une définition de type factice en place, mais c'est à toi de définir les fonctions et de créer un type de données qui a du sens.
