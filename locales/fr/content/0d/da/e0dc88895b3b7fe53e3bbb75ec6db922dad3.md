# Introduction

## Les bases

On suppose que tu connais la syntaxe et les types de données JSON.

jq fonctionne en faisant passer les données JSON entrantes à travers une _expression unique_ (écrite sous la forme d'un _enchaînement de filtres_) pour obtenir les données transformées souhaitées.

<!-- prettier-ignore -->
~~~~exercism/note
Le langage `jq` est implémenté par le _programme_ `jq`.
Ce programme fournit plusieurs options en ligne de commande bien pratiques pour contrôler la façon dont l'entrée est consommée et dont la sortie est présentée.

Dans les exemples ci-dessous, tu rencontreras :

- `-n` ou `--null-input`

    Normalement, on donne au programme `jq` un fichier à lire, ou bien on lui envoie des données sur son entrée.
    L'option `--null-input` permet de générer des données JSON sans aucune entrée.

- `-c` ou `--compact-output`

    Par défaut, `jq` met en forme sa sortie de manière lisible.
    C'est extrêmement utile pour les humains de voir les données bien formatées.
    En revanche, ce n'est pas nécessaire pour les machines : l'option `--compact-output` supprime les espaces de formatage afin de réduire la taille du JSON obtenu.

- `-f filename` ou `--from-file filename`

    Lire le programme `jq` depuis `filename` au lieu de le fournir sur la ligne de commande.
    `sed` et `awk` utilisent tous les deux l'option `-f` dans le même but.
    Tu verras cette option utilisée dans les scripts de test des exercices d'entraînement.

La suite de cette leçon se concentrera sur le _langage_ `jq`.
~~~~

<!-- prettier-ignore-end -->

### Filtres et tubes

Les **filtres** sont aussi appelés **expressions**.

Un _filtre_ prend une entrée et produit une sortie.
Comme dans un shell Unix, on peut relier des _filtres_ avec un tube `|` pour connecter la sortie d'un _filtre_ à l'entrée d'un autre.

### Le filtre identité : `.`

C'est le _filtre_ le plus simple.
Il transmet simplement son entrée à sa sortie.

```sh
$ echo '[1, 2, 3]' | jq '.'
[
  1,
  2,
  3
]
```

### Les tableaux

Voici une introduction rapide à la manipulation des **tableaux**.
On verra ce sujet plus en détail plus loin.

On accède aux éléments d'un _tableau_ avec des crochets, et l'indexation commence à zéro.

```sh
$ echo '[10, 20, 30]' | jq '.[1]'
20
```

Un _filtre_ peut construire un _tableau_ en entourant une expression de `[` et `]`

- avec une liste connue d'éléments :

  ```sh
  jq -n '[1, 2, 3]'
  ```

- pour rassembler un flux d'éléments : par exemple, `range` est une fonction qui produit un flux de nombres

  ```sh
  $ jq -n 'range(10; 70; 15)'
  10
  25
  40
  55
  ```

  L'utilisation de `[]` rassemble les résultats de l'expression dans un tableau

  ```sh
  $ jq -c -n '[range(10; 70; 15)]'
  [10,25,40,55]
  ```

### La virgule est un opérateur

La _virgule_ n'est pas seulement une syntaxe qui sépare les éléments d'un _tableau_.
La **virgule** est un **opérateur** qui assemble des flux.

Par exemple, `[1, 2, 3]` est un _filtre_ qui utilise le constructeur de _tableau_ `[]` pour rassembler le résultat de l'assemblage des trois expressions `1`, `2` et `3`.

Tu as remarqué les points-virgules dans `range(10; 70; 15)` ci-dessus ?
Comme les _virgules_ ont un rôle spécifique dans le langage `jq`, les fonctions qui prennent plusieurs arguments utilisent des points-virgules pour séparer les arguments.

### Les objets

Une introduction rapide aux **objets**.

Comme dans beaucoup de langages de programmation, on utilise des points pour accéder aux propriétés d'un _objet_

```sh
$ echo '{"foo": {"bar": "qux"}}' | jq '.foo.bar'
"qux"
```

<!-- prettier-ignore -->
~~~~exercism/note
On peut aussi utiliser des crochets pour les _objets_, mais il faut alors des guillemets pour les littéraux _string_.
C'est une façon de travailler avec des clés contenant des espaces.

```sh
$ echo '{"foo bar": "qux"}' | jq '.["foo bar"]'
"qux"
```
~~~~

<!-- prettier-ignore-end -->

Tu peux construire un _objet_ avec `{}` et des paires `key: value`.
Les guillemets ne sont pas nécessaires autour des _clés_ qui sont des _strings_ « simples ».

```sh
jq -n '{question: (6 * 9), answer: 42}'
```

produit

```none
{
  "question": 54,
  "answer": 42
}
```

Pour traiter la _clé_ comme une _expression_, il faut l'entourer de parenthèses (l'exemple suivant produit lui aussi le même résultat que ci-dessus).

```sh
echo '[{"key":"question", "value":54}, {"key":"answer", "value":42}]' \
| jq '{(.[0].key): .[0].value, (.[1].key): .[1].value}'
```

### Enchaînements de filtres

Par exemple, avec un fichier `file.json` contenant

```json
{
  "key1": "value1",
  "key2": [5, 15, 25]
}
```

Calculons la longueur du _tableau_ key2 :

```sh
$ jq '.key2 | length' file.json
3
```

On envoie la sortie de l'expression `.key2` en entrée de `length`, qui, sans surprise, produit le nombre d'éléments du _tableau_.

### Un filtre peut ignorer son entrée

Dans cet exemple, les données JSON d'entrée sont ignorées et n'ont aucun impact sur la sortie :

```sh
$ echo '{"answer": 42}' | jq '6 * 9'
54
```

### Un filtre peut produire des flux de données

Un _filtre_ peut produire plusieurs valeurs.
Par exemple, le _filtre_ `.[]` produit chaque élément d'un _tableau_ comme une valeur distincte :

```sh
$ jq -n -c '[1, 2, 3]'
[1,2,3]

$ jq -n -c '[1, 2, 3] | .[]'
1
2
3
```

En enchaînant un tel _filtre_ avec un autre, le deuxième _filtre_ sera exécuté **_pour chaque valeur_** :

```sh
$ jq -n -c '[1, 2, 3] | .[] | . * 2'
2
4
6
```

C'est une sorte d'itération implicite.
Une fois que tu as compris cette technique, tu réalises que des _filtres_ `jq` très puissants peuvent être très concis.

### Les parenthèses

Les **parenthèses** servent à regrouper des sous-expressions pour imposer l'ordre des opérations, comme dans d'autres langages.
En `jq`, le besoin de parenthèses peut sembler un peu surprenant.

Par exemple, imaginons que l'on veuille construire un _tableau_ à 2 éléments : la racine carrée de 9, et _e_ élevé à la puissance 1.
Les deux expressions individuelles sont `9 | sqrt` et `1 | exp`.
On s'attend à ce que la sortie soit le _tableau_ `[3, 2.7...]`

```jq
$ jq -n '[ 9|sqrt, 1|exp ]'
[
  20.085536923187668,
  2.718281828459045
]
```

Pourquoi n'a-t-on pas obtenu ce qu'on attendait ? `jq` interprète cela comme ceci :

```jq
[ ((9|sqrt), 1) | exp ]
```

`jq` construit un flux de deux éléments (`3` et `1`) qui sont chacun donnés à `exp`.

Il faut s'assurer que `exp` ne prend qu'un seul nombre en entrée.
Autrement dit, il faut imposer que le tube soit évalué avant la virgule.

```jq
$ jq -n '[ 9|sqrt, (1|exp) ]'
[
  3,
  2.718281828459045
]
```

### Fonctions et opérateurs

Sans entrer dans les détails (les fonctions feront l'objet d'un autre exercice), voici quelques fonctions intégrées utiles :

- `length`

  Étant donné un tableau en entrée, produit le nombre d'éléments du tableau.

  ```sh
  $ jq -n '[10, 20, 30, 40] | length'
  4
  ```

- `+`

  Cet opérateur fait des choses différentes selon le type de ses opérandes :
  il additionne des nombres,
  il concatène des _strings_,
  il ajoute des tableaux,
  il fusionne des objets.

  ```sh
  $ jq -c -n '
      3 + 4,
      "foo" + "bar",
      ["a", "b"] + ["c"],
      {"m": 10} + {"n": 20}
  '
  7
  "foobar"
  ["a","b","c"]
  {"m":10,"n":20}
  ```

  `add` est une fonction qui prend un tableau et renvoie un élément obtenu en additionnant tous les éléments selon les règles de `+`.
  `[1, 2, 3] | add` produit `6`.

- `map`

  Étant donné un tableau en entrée et un filtre en argument, produit un tableau où le filtre est appliqué à chaque élément

  ```sh
  $ jq -c -n '[10, 20, 30, 40] | map(. / 5)'
  [2,4,6,8]
  ```

- `select`

  Étant donné _une_ entrée et un filtre en argument :
  - si le filtre appliqué à l'argument donne une valeur _vraie_, produit l'entrée inchangée
  - sinon, ne produit _rien_ (pas la valeur `null`, vraiment aucune sortie)

  Par exemple, étant donné quelques nombres, on sélectionne ceux qui sont divisibles par 3

  ```sh
  $ jq -n 'range(10) | select(. % 3 == 0)'
  0
  3
  6
  9
  ```

  Rappelle-toi que `range` produit un _flux_ de nombres.
  `select` sera appelé une fois pour chaque nombre.
  Seuls les nombres qui « passent » l'expression sont produits.

  On a souvent besoin de sélectionner des éléments d'un tableau.
  Il y a plusieurs façons de procéder.

  Avec l'entrée `["Anne", "Bob", "Cathy", "Dave"]`, sélectionne les noms de longueur 4.
  - utilise `map` et `select` ensemble

    ```jq
    map(select(length == 4))
    ```

  - éclate le tableau en éléments, applique `select` sur ce flux, puis rassemble les résultats

    ```jq
    [ .[] | select(length == 4) ]
    ```
