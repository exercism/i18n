# Installation

Ce parcours s'appuie sur [Node.js][web-nodejs] pour fournir un environnement d'exécution à JavaScript.
Cela signifie que nous partons du principe que toute exécution de JavaScript sur ton ordinateur se fera avec [Node.js][web-nodejs].

## Prérequis du parcours

De nombreuses machines sont livrées avec [Node.js][web-nodejs] préinstallé, ou bien il a peut-être été installé auparavant, ou encore comme dépendance.
Avant de faire quoi que ce soit, on vérifie donc s'il est déjà présent :

1. Ouvre un _terminal_ (`Terminal`, `cmd`, `Powershell`, `bash`, ...)
1. `node -v`

Si [Node.js][web-nodejs] est installé, une version s'affiche.
Note cette version.
Si [Node.js][web-nodejs] n'est _pas_ installé, un message d'erreur apparaît.
En général, quelque chose comme `'node' is not recognised`.

## Node.js

### Si Node.js est déjà installé

Rends-toi sur [le site de Node.js][web-nodejs].
Il affiche _deux_ versions (s'il détecte ton système d'exploitation. Sinon, sélectionne d'abord le tien).
Si la version affichée par `node -v` correspond à l'une d'elles, tout va bien.
Sinon, on te recommande d'utiliser Node.js LTS.
Si tu crains qu'une mise à jour ne casse quelque chose sur ton système, tu peux continuer comme si tout allait bien ;
il se peut que nous ne puissions pas t'apporter d'aide si quelque chose d'inattendu se produit.

### Si Node.js n'est pas installé

Il existe plusieurs façons d'installer [Node.js][web-nodejs] :

- via un [installeur ou un binaire][web-nodejs-download]
- via un [gestionnaire de paquets][web-nodejs-package]

Les deux options prennent en charge Windows, macOS et Linux. Si tu ne sais pas quoi faire, le plus simple est d'utiliser un installeur.

- On te recommande d'utiliser la version **LTS**. C'est aussi celle indiquée comme _recommandée_ sur le site de [Node.js][web-nodejs] « pour la plupart des utilisateurs ».
- Suis les instructions de la page web et/ou de l'installeur, puis installe [Node.js][web-nodejs].

## Tester l'installation

Une fois l'installeur terminé, le gestionnaire de paquets arrivé au bout, ou le binaire copié et les instructions suivies, il est bon de vérifier que tout va bien.

1. Ouvre un _terminal_ (`Terminal`, `cmd`, `Powershell`, `bash`, ...)
1. `node -v`

La version affichée devrait correspondre à celle du site web.

> [!NOTE]
> Il est important d'ouvrir une _nouvelle_ fenêtre de terminal.
> Les fenêtres de terminal déjà ouvertes n'ont peut-être pas été actualisées une fois l'installation terminée.
> Cela signifie que ces terminaux ne savent pas qu'un nouveau programme a été installé.

> [!IMPORTANT] > _**Aide**_ : `'node' is not recognised`
>
> Si tu as utilisé l'installeur officiel, ton `PATH` a normalement été configuré automatiquement, mais si ton shell a du mal à localiser tes modules installés globalement, ou si tu compiles Node.js depuis les sources, mets à jour ton `PATH` pour y inclure les binaires de `npm`.
>
> Sous macOS et Linux, tu peux y parvenir en ajoutant ce qui suit à `~/.bash_profile` ou `~/.zshrc` :
>
> ```shell
> export PATH=/usr/local/share/npm/bin:$PATH
> ```
>
> Sous Windows, ouvre le menu Démarrer et recherche « environment variables ».
> Tu devras modifier l'entrée `PATH` et y _ajouter_ le chemin vers les binaires de `npm`.
> En général, ceux-ci se trouvent dans `C:\Program Files\nodejs`.
> Si tu y navigues avec ton `File Explorer`, tu devrais y trouver `node.exe`, `npm.bat` et `npx.bat`.
>
> Ferme toutes les fenêtres de terminal ouvertes, puis ouvres-en une nouvelle.

## Activer corepack

Pour utiliser un gestionnaire de paquets versionné et compatible avec ce parcours, `corepack` doit être activé une fois :

```shell
corepack enable pnpm
```

## Prérequis des exercices

Suis [ces instructions][cli-walkthrough] pour télécharger l'Exercism CLI correspondant à ton système d'exploitation.

Une fois la CLI installée et configurée, télécharge le premier exercice, `hello-world` :

```shell
exercism download --exercise=hello-world --track=javascript
```

Chaque exercice a ensuite besoin de quelques outils pour exécuter les tests.
Tu peux les installer en lançant cette commande dans le dossier de chaque exercice :

```shell
corepack pnpm install
```

Comme ce parcours est passé à pnpm, tu n'as pas à te soucier de l'espace disque.
Jette un œil à [pnpm](https://pnpm.io/), qui garantit qu'une seule copie de chaque version de paquet est installée sur le disque.

> **Mais qu'est-ce que corepack, et pourquoi ça fonctionne ?**
>
> Tu n'as pas besoin de ces informations pour terminer le parcours JavaScript, mais si tu veux absolument comprendre ce qui vient de se passer, les paragraphes suivants sont pour toi :
>
> Cela fonctionne parce que `corepack` est un outil fourni avec Node.js, que tu as installé en suivant les étapes ci-dessus.
> Il peut installer le gestionnaire de paquets `pnpm`. Il configure le système
> La commande `corepack` cherche un fichier `package.json`, présent dans _chaque_ dossier d'exercice.
> Elle vérifie ensuite `packageManager`, qui correspond à `pnpm`, et peut donc continuer. Si nécessaire, elle met d'abord `pnpm` à jour.
> Ce fichier liste aussi les `"dependencies"` ci-dessus, que `pnpm` télécharge alors et place dans un cache local.
>
> Les scripts du `package.json` utilisent les binaires du cache local, et ce sont ces scripts qui servent à exécuter les tests, comme indiqué dans la description de l'`exercise`.
