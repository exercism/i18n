# Indices

## 1. Génère un numéro d'immatriculation aléatoire pour un vaisseau spatial

- Pour générer un nombre aléatoire dans l'intervalle allant de _min_ (inclus) à _max_ (exclu), tu peux utiliser l'extrait de code `min + Math.random()*(max - min)`.
- Il existe une [fonction intégrée][floor] pour transformer un nombre à virgule flottante en un entier.

## 2.Génère une date stellaire aléatoire

- Pour générer un nombre aléatoire dans l'intervalle allant de _min_ (inclus) à _max_ (exclu), tu peux utiliser l'extrait de code `min + Math.random()*(max - min)`.

## 3. Génère une planète aléatoire

- Tu peux utiliser un entier généré aléatoirement comme indice de tableau.

[floor]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Math/floor
