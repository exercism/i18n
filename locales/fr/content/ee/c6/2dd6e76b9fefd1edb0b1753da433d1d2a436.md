# Les boucles `for`

Les boucles sont un concept fondamental en programmation, qui permet d'exécuter un bloc de code plusieurs fois.
En Swift, il existe deux types de boucles : les [boucles `for-in`][for-loops] et les boucles `while`.
Dans ce chapitre, tu vas découvrir les boucles `for-in`.

Les boucles `for` permettent de parcourir une séquence de valeurs : elles prennent chaque élément l'un après l'autre et le lient à une variable de ton choix.
Swift permet de parcourir toutes sortes de séquences, comme les intervalles, les tableaux et les _strings_ (et d'autres types qui seront abordés plus tard).
Une fois que chaque élément de la séquence a été parcouru, la boucle se termine.

On déclare une boucle `for` avec le mot-clé `for`, suivi d'un nom de variable, du mot-clé `in`, puis d'une séquence de valeurs à parcourir.
La variable donnée dans la boucle `for-in` est immuable, ce qui signifie que tu ne peux pas modifier sa valeur à l'intérieur de la boucle.
Voici un exemple de boucle `for-in` qui parcourt un tableau de nombres :

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
  print(number)
}
print("Done with numbers")

// prints:
// 3
// 10
// 7
// 11
// Done with numbers
```

~~~~exercism/note
La variable `number` est déclarée dans la boucle `for-in` et n'est disponible que dans la portée de la boucle.

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
    number + 1
}
number + 1
// Error: Use of unresolved identifier 'number'
```
~~~~

## Parcours un intervalle

Tu peux aussi parcourir un intervalle de nombres avec une boucle `for-in`.
Cela te permet d'exécuter un bloc de code un nombre précis de fois. Par exemple, l'intervalle `1...5` parcourt les nombres 1, 2, 3, 4 et 5, donc la boucle s'exécute 5 fois.
Il peut aussi t'arriver de vouloir parcourir les indices d'une structure de données comme un tableau ; dans ce cas, tu peux utiliser un intervalle `0..<array.count`.

```swift
let numbers = [3, 10, 7, 11]

for i in 0..<numbers.count {
  print(numbers[i])
}

// prints:
// 3
// 10
// 7
// 11
```

## Parcours une _string_

Tu peux aussi parcourir une _string_ avec une boucle `for-in`.
Cela te permet de parcourir chaque caractère de la _string_, et remarque bien que le type donné dans la boucle est un `Character`.

```swift
let message = "Hello!"

for character in message {
  print(character)
}

// prints:
// H
// e
// l
// l
// o
// !
```

## Variables inutilisées

Si tu n'as pas besoin de la valeur de la variable dans la boucle, tu peux utiliser un _underscore_ `_` pour l'ignorer.

```swift
let numbers = [3, 10, 7, 11]

for _ in numbers {
  print("Hello!")
}
```

## stride

Swift fournit aussi une fonction `stride` qui permet de créer une séquence sur un intervalle avec un pas donné.
Cette séquence peut ensuite être parcourue avec une boucle `for-in`.
`stride` se définit sous la forme [`stride(from:to:by:)`][stride-to] ou [`stride(from:through:by:)`][stride-through] : la première est exclusive, la seconde inclusive.

```swift
for i in stride(from: 0, to: 10, by: 2) {
  print(i)
}

// prints:
// 0
// 2
// 4
// 6
// 8
```

Remarque que le paramètre `to` est exclusif, donc la boucle itère jusqu'au nombre qui précède la valeur de `to`, tandis que le paramètre `through` est inclusif, si bien qu'ici, le `10` serait également inclus.

[stride-to]: https://developer.apple.com/documentation/swift/stride(from:to:by:)
[stride-through]: https://developer.apple.com/documentation/swift/stride(from:through:by:)
[for-loops]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#For-In-Loops
