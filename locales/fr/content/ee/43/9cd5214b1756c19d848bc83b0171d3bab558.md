# Types de nombres

Crystal dispose de divers types de nombres pour des usages variés.
Par exemple, certains types sont plus rapides, mais couvrent une plage de valeurs possibles plus petite que d'autres.
D'autres couvrent une plage de valeurs plus étendue, mais sont plus lents.

En Crystal, il existe à la fois des types entiers signés et des types entiers non signés.
Les types entiers signés peuvent être positifs ou négatifs.
Les types entiers non signés ne peuvent être que positifs.

## Les types entiers signés

Voici les [types entiers signés][int] en Crystal :

| Type     | Taille (bits) | Plage                                                                                                       |
| -------- | ------------- | ----------------------------------------------------------------------------------------------------------- |
| `Int8`   | 8             | -128 à 127                                                                                                  |
| `Int16`  | 16            | -32_768 à 32_767                                                                                            |
| `Int32`  | 32            | -2_147_483_648 à 2_147_483_647                                                                              |
| `Int64`  | 64            | -9_223_372_036_854_775_808 à 9_223_372_036_854_775_807                                                      |
| `Int128` | 128           | -170_141_183_460_469_231_731_687_303_715_884_105_728 à 170_141_183_460_469_231_731_687_303_715_884_105_727 |

Les types les plus petits utilisent moins de mémoire et sont plus rapides que les plus grands, mais leur plage de valeurs possibles est plus restreinte.

Quand on sait que les valeurs resteront dans une certaine plage, le mieux est d'utiliser le plus petit type possible, afin d'économiser de la mémoire et d'améliorer les performances.

Le type entier par défaut est `Int32`.
Pour déclarer un entier d'un type précis, tu peux utiliser le nom du type comme suffixe en ajoutant `<number>_I <bit>`.

```crystal
1_i8.class
# => Int8
```

Tu peux utiliser la méthode `to_i<bit>` pour convertir un type entier en un autre.
La méthode `to_i` convertit vers le type entier par défaut, `Int32`.

```crystal
1_i8.to_i16.class
# => Int16

2_i16.to_i.class
# => Int32
```

## Les types entiers non signés

Voici les [types entiers non signés][uint] en Crystal :

`UInt8`, `UInt16`, `UInt32`, `UInt64`, `UInt128`

La seule différence entre les entiers signés et les entiers non signés est que les entiers non signés ne peuvent être que positifs.
Pour déclarer un entier non signé d'un type précis, tu peux utiliser le nom du type comme suffixe en ajoutant `<number>_u<bit>`.
Tu peux utiliser la méthode `to_u<bit>` pour convertir un type entier non signé en un autre.
La méthode `to_u` convertit vers le type entier non signé par défaut, `UInt32`.

```crystal
1_u8.to_u16.class
# => UInt16
```

## Les types à virgule flottante

Voici les types à virgule flottante en Crystal :

| Type      | Taille (bits) | Plage                |
| --------- | ------------- | -------------------- |
| `Float32` | 32            | 1.2E-38 à 3.4E+38    |
| `Float64` | 64            | 2.3E-308 à 1.7E+308  |

Il existe deux [types à virgule flottante][float] différents, l'un étant plus précis que l'autre.

Le type à virgule flottante par défaut est `Float64`.

Tu peux utiliser la méthode `to_f<bit>` pour convertir un type à virgule flottante en un autre.
La méthode `to_f` convertit vers le type à virgule flottante par défaut, `Float64`.

[float]: https://crystal-lang.org/api/latest/Float.html
[int]: https://crystal-lang.org/api/latest/Int.html
[uint]: https://crystal-lang.org/api/latest/UInt32.html
