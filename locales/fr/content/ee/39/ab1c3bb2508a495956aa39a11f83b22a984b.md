# Indices

## Général

Quand on manipule des arbres, la [récursivité][recursion] est souvent ton amie.

- L'essentiel ici est de trouver un moyen de décomposer le problème en sous-problèmes de même structure.
- Un indice dans les instructions indique où cela peut se faire.
- Les deux parcours sont nécessaires pour résoudre le problème.
- Quel est le lien entre les deux parcours ? La position de `root` peut donner un indice.
- Quel est le cas de base ? Le premier test pointe vers une bonne réponse.

[recursion]: https://en.wikipedia.org/wiki/Recursion
