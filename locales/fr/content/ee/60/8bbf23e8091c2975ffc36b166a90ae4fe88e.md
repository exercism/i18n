# Introduction

Elixir utilise des _comportements_ pour fournir des interfaces génériques communes, tout en facilitant des implémentations spécifiques pour chaque module qui les implémente. Un exemple courant est le _comportement Access_.

Le _comportement Access_ fournit une interface commune pour récupérer des données dans une structure de données à clés. Il est implémenté pour les maps et les listes de mots-clés, mais voyons comment il s'utilise avec les maps pour nous en faire une idée. Le _comportement Access_ prévoit que, quand on a une map, on peut la faire suivre de _crochets_, puis utiliser la clé pour récupérer la valeur associée.

```elixir
# Suppose we have these two maps defined (note the difference in the key type)
my_map = %{key: "my value"}
your_map = %{"key" => "your value"}

# Obtain the value using the Access Behaviour
my_map[:key] == "my value"
your_map[:key] == nil
your_map["key"] == "your value"
```

Si la clé n'existe pas dans la structure de données, c'est `nil` qui est renvoyé. Cela peut être une source de comportement inattendu, car aucune erreur n'est levée. À noter que `nil` implémente lui-même le _comportement Access_ et renvoie toujours `nil` pour n'importe quelle clé.
