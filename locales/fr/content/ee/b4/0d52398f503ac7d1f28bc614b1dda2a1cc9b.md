# Indices

## 1. Ajouter un langage au tableau `@Languages`

- Tu veux modifier le tableau `@Languages` pour ajouter un nouveau langage à la fin.

## 2. Supprimer un langage du tableau `@Languages`

- Tu veux modifier le tableau `@Languages` pour en supprimer le dernier langage.

## 3. Récupérer le premier langage du tableau `@Languages`

- Tu veux utiliser `return` pour renvoyer le premier élément du tableau `@Languages`.

## 4. Récupérer le dernier langage du tableau `@Languages`

- Tu veux utiliser `return` pour renvoyer le dernier élément du tableau `@Languages`.

## 5. Récupérer une tranche de langages du tableau `@Languages`

- Tu veux obtenir une tranche du tableau `@Languages`.
- N'oublie pas que les indices commencent à 0. L'élément `1` a pour indice `0`.

## 6. Vérifier si un langage existe dans le tableau `@Languages`

- Tu veux renvoyer une valeur vraie, par exemple `1`, ou fausse, par exemple `0`, si le langage donné se trouve dans le tableau `@Languages`.
