# Indices

## Général

- [Introduction aux types numériques à virgule flottante][docs.microsoft.com-floating_point_numeric_types].

## 1. Calcule le taux d'intérêt

- Par défaut, tout nombre à virgule flottante défini dans du code C# est traité comme un `double`. Pour utiliser un autre type à virgule flottante (comme `float` ou `decimal`), il faut ajouter le [suffixe][docs.microsoft.com-real_literals] approprié au nombre.

## 2. Calcule les intérêts

- Quand on calcule les intérêts, il peut être utile de remarquer que `InterestRate` renvoie un pourcentage.

## 3. Calcule la mise à jour annuelle du solde

- Pour calculer la mise à jour annuelle du solde, on peut utiliser les méthodes que l'on a définies dans les étapes précédentes.

## 4. Calcule le nombre d'années avant d'atteindre le solde souhaité

- Pour calculer le nombre d'années, on peut répéter une boucle jusqu'à atteindre le solde souhaité. C# propose plusieurs [constructions de boucles][docs.microsoft.com-loops].
- Il existe un [opérateur][increment-operator] spécial pour incrémenter une valeur de 1.
