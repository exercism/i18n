# Workflow de synchronisation des étiquettes

Le workflow de synchronisation des étiquettes synchronise les [étiquettes GitHub](https://docs.github.com/en/issues/using-labels-and-milestones-to-track-work/managing-labels) d'un dépôt avec le contenu du fichier `.github/labels.yml`.
Chaque fois que le fichier `.github/labels.yml` change, le workflow de synchronisation des étiquettes met automatiquement à jour les étiquettes du dépôt.

## Personnalise les étiquettes

Les étiquettes définies dans `.github/labels.yml` se présentent sous deux formes :

- Étiquettes partagées : ce sont des étiquettes utilisées par _tous_ les dépôts Exercism, et elles sont définies dans le [dépôt org-wide-files](https://github.com/exercism/org-wide-files/blob/main/global-files/.github/labels.yml)
- Étiquettes spécifiques à un parcours : elles sont définies dans un fichier `.appends/.github/labels.yml`

Pour ajouter des étiquettes spécifiques à un parcours, tu devras les ajouter au fichier `.appends/.github/labels.yml` (voir [cet exemple](https://github.com/exercism/python/blob/main/.appends/.github/labels.yml)).
Une fois que tu as fusionné les modifications dans `main`, une _pull request_ sera automatiquement ouverte pour modifier le fichier `.github/labels.yml`.
Après avoir fusionné cette PR, les étiquettes seront automatiquement mises à jour (voir la description ci-dessus).

```exercism/caution
Ne modifie jamais manuellement le fichier `.github/labels.yml`, car ces modifications seront écrasées lors de la prochaine synchronisation des étiquettes.
```

## Source

Le workflow est défini dans le fichier `.github/workflows/sync-labels.yml`.
