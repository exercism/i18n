# Instructions supplémentaires

## Registres

| Registre | Utilisation  | Type    | Description                                       |
| -------- | ------------ | ------- | ------------------------------------------------- |
| `$a0`    | entrée       | adresse | chaîne de chiffres terminée par un caractère nul  |
| `$a1`    | entrée       | entier  | _span_                                            |
| `$v0`    | sortie       | entier  | produit de la plus grande série                   |
| `$t0-9`  | temporaire   | quelconque | pour le stockage temporaire                    |
