# Introduction

En F#, affecter une valeur à un nom s'appelle une _liaison_. Les liaisons sont immuables, ce qui les rapproche des constantes d'autres langages. Comme F# est un langage typé statiquement, chaque liaison a un type dès la compilation.

Les liaisons se définissent avec le mot-clé `let`. Pour la plupart des liaisons, préciser le type est facultatif, car l'_inférence de type_ de F# peut généralement le déduire à partir de la valeur. Une liaison ressemble à ceci :

```fsharp
// Automatically inferred type
let fingers = 10
```

Les fonctions sont aussi des liaisons ordinaires, mais avec un ou plusieurs paramètres. Une fonction renvoie automatiquement sa dernière expression. L'inférence de type fonctionne aussi pour la plupart des fonctions : elle analyse avec quelles valeurs la fonction est appelée et quelle valeur elle renvoie.

```fsharp
// Automatically inferred types for parameters and return type
let add x y = x + y
```

Pour appeler une fonction, on indique son nom et on passe un argument pour chacun de ses paramètres.

```fsharp
let five = add 2 3
```

Si le type d'une liaison ne peut pas être inféré, le compilateur signale une erreur. Pour corriger cela, ajoute une annotation de type explicite à la liaison.

```fsharp
// Explicit type annotation
let fingers: int = 10

// Explicit type annotation (also for parameters)
let add (x: int) (y: int): int = x + y
```

En F#, une liaison ne peut être utilisée qu'_après_ avoir été définie. Utiliser une liaison avant qu'elle ne soit définie provoque une erreur de compilation.

```fsharp
// Compile error as the add binding has not yet been defined
// let seven = add 3 4

let add x y = x + y
```

F# utilise les espaces significatifs pour définir la portée. Cela signifie que la portée se définit en indentant le code avec des espaces, par rapport à la ligne qui déclare la liaison. Par convention, on utilise quatre espaces pour l'indentation :

```fsharp
let toes =
    let left = 5
    let right = 5
    left + right

let multiplyPlusTwo x y =
    let product = x * y
    product + 2

// Trying to access the left, right or product bindings
// here would result in a compile error
```

En F#, les liaisons (y compris les fonctions) sont généralement organisées en modules. Un module regroupe des fonctionnalités liées et se définit avec le mot-clé `module`. La définition du module doit précéder ses liaisons :

```fsharp
module Calculator

let pi = 3.14

let add x y = x + y
```

F# prend en charge deux types de commentaires. Les commentaires sur une seule ligne sont précédés de `//`, et les commentaires multilignes s'insèrent entre `(*` et `*)`.
