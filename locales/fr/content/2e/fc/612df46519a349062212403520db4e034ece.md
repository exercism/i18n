# Introduction

## Explication

Outre les types de données primitifs comme `number` et `string`, il existe en JavaScript un autre type de données important, appelé `object`.
Les objets sont des collections de paires clé-valeur.
À ce titre, on peut les utiliser comme ce que l'on appelle souvent des dictionnaires ou des tables associatives dans d'autres langages.

Dans d'autres langages, toutes les valeurs d'une table associative doivent souvent avoir le même type de données.
En JavaScript, seul le type de la clé est restreint : il doit être une _string_.
Les valeurs d'un même objet peuvent avoir des types différents.
Elles peuvent être de types primitifs comme les nombres, mais aussi des tableaux, d'autres objets ou même des fonctions.
Cela rend les objets très polyvalents, ce qui en fait aussi des entités essentielles pour la [programmation orientée objet][oop] (POO) en JavaScript.

Dans ce qui suit, on se concentrera sur les objets en tant que collections ou tables associatives. D'autres cas d'utilisation des objets seront abordés dans d'autres concepts, voir par exemple les [classes][concept-classes].

## Crée un objet

On crée un objet à l'aide d'accolades.
On peut aussi y inclure directement des entrées.
Pour cela, indique d'abord la clé, suivie de deux-points et de la valeur.

```javascript
const emptyObject = {};

const obj = {
  favoriteNumber: 42,
  greeting: 'Hello World',
  useGreeting: true,
  address: {
    street: 'Trincomalee Highway',
    city: 'Batticaloa',
  },
  fruits: ['melon', 'papaya'],
  addNumbers: function (a, b) {
    return a + b;
  },
};
```

La virgule finale après la dernière entrée est facultative en JavaScript.

Tu te demandes peut-être pourquoi les clés ne sont pas entourées de guillemets alors qu'elles sont censées être des _strings_.
Il s'agit d'une notation abrégée.
Si la clé respecte les règles de nommage d'un [identifiant][mdn-identifier] JavaScript, on peut omettre les guillemets.
Pour les clés dont le nom contient des caractères spéciaux, il faut alors utiliser la notation habituelle avec des guillemets.

```javascript
const obj = {
  '1keyStartsWithNumber': '...',
  'key/with/slashes': '...',
  'key-with-dashes': '...',
  'key with spaces': '...',
  '#&()[]{}èä樹keyWithSpecialChars': '...',
};
```

## Récupère une valeur

Il y a deux façons de récupérer la valeur associée à une clé donnée : la notation pointée et la notation entre crochets.

```javascript
const obj = { greeting: 'hello world' };

obj.greeting;
// => hello world

obj['greeting'];
// => hello world

// Bracket notation also works with variables.
const key = 'greeting';
obj[key];
// => hello world
```

Utiliser la notation pointée comme raccourci impose la même restriction que l'omission des guillemets.
Elle ne fonctionne que si la clé respecte les règles de nommage des identifiants.
Autrement dit, si ta clé n'est pas un seul mot composé uniquement de lettres, tu dois utiliser la notation entre crochets.

## Ajoute ou modifie une valeur

On peut ajouter ou modifier une valeur à l'aide de l'opérateur d'affectation `=`.
Là encore, la notation pointée et la notation entre crochets sont disponibles.

```javascript
const obj = { greeting: 'hello world' };

obj.greeting = 'Hi there!';
obj['greeting'] = 'Welcome.';

obj.newKey1 = 'new value 1';
obj['new key 2'] = 'new value 2';

const key = 'new key 3';
obj[key] = 'new value 3';
```

## Supprime une entrée

On peut supprimer une paire clé-valeur d'un objet à l'aide du mot-clé `delete`.

```javascript
const obj = {
  key1: 'value1',
  key2: 'value2',
};

delete obj.key1;
delete obj['key2'];
```

## Vérifie si une clé existe

On peut vérifier si une clé donnée existe dans un objet avec la méthode `hasOwnProperty`.

```javascript
const obj = { greeting: 'hello world' };

obj.hasOwnProperty('greeting');
// => true

obj.hasOwnProperty('age');
// => false
```

## Parcours un objet

Il existe une boucle `for...in` spéciale pour itérer sur toutes les clés d'un objet.

```javascript
const obj = {
  name: 'Ali',
  age: 65,
};

for (let key in obj) {
  console.log(key, obj[key]);
}
// name Ali
// age 65
```

Pour éviter des erreurs subtiles, il faut toujours considérer que la boucle `for...in` parcourt les clés dans un ordre arbitraire.
Sache aussi que `for...in` inclut les [clés héritées][concept-inheritance] dans son itération.
