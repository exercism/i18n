# Instructions complémentaires

## Messages d'exception

Il est parfois nécessaire de [lever une exception](https://docs.python.org/3/tutorial/errors.html#raising-exceptions). Dans ce cas, il faut toujours inclure un **message d'erreur explicite** qui indique l'origine de l'erreur. Cela rend le code plus lisible et facilite grandement le débogage. Lorsqu'on sait que l'origine de l'erreur sera d'un type donné, on peut lever l'un des [types d'erreur intégrés](https://docs.python.org/3/library/exceptions.html#base-classes), mais il faut quand même inclure un message explicite.

Cet exercice demande en particulier d'utiliser l'[instruction `raise`](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement) pour « lever » une `ValueError` lorsque la fonction `board()` reçoit une entrée mal formée. Les tests ne réussiront que si tu `raise` l'`exception` en y joignant un message.

Pour lever une `ValueError` accompagnée d'un message, écris ce message comme argument du type `exception` :

```python
# when the board receives malformed input
raise ValueError("The board is invalid with current input.")
```
