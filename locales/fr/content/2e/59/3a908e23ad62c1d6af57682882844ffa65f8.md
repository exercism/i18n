# Introduction

Bien que le modificateur `readonly` empêche que la valeur ou la référence d'un champ soit écrasée, il n'offre aucune protection pour les membres d'un type référence.

```csharp
readonly List<int> ints = new List<int>();

void Foo()
{
    ints.Add(1);    // ok
    ints = new List<int>(); // fails to compile
}
```

Pour garantir que tous les membres d'un type référence sont protégés, on peut déclarer les champs `readonly` et définir des propriétés automatiques sans accesseur `set`.

La bibliothèque de classes de base (BCL) fournit des versions en lecture seule de certaines collections lorsqu'il faut empêcher la mise à jour de leurs membres. Ces versions prennent la forme de _wrappers_ :

- `ReadOnlyDictionary<T>` expose un `Dictionary<T>` en lecture seule.
- `ReadOnlyCollection<T>` expose un `List<T>` en lecture seule.
