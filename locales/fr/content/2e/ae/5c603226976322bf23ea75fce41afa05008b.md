# Instructions supplémentaires

## Indications

Tu dois implémenter les fonctions `decode` et `encode`, qui décodent et encodent une `String` à l'aide d'un chiffrement Atbash.
Tu peux utiliser la signature fournie si tu as un doute sur les types, mais ne la laisse pas brider ta créativité.

Cet exercice manipule des données textuelles. Pour des raisons historiques, le type `String` de Haskell est synonyme de `[Char]`, un tableau de caractères. Pour manipuler plus efficacement des données textuelles, on peut utiliser le type `Text`.

Comme prolongement facultatif à cet exercice, tu peux

- te renseigner sur les [types _string_](https://haskell-lang.org/tutorial/string-types) en Haskell.
- ajouter `- text` à ta liste de dépendances dans package.yaml.
- importer `Data.Text` de [la manière suivante](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c) :

```haskell
import qualified Data.Text as T
import           Data.Text (Text)
```

- utiliser le type `Text`, par exemple `decode :: Text -> Text`, et désigner les combinateurs de `Data.Text` comme par exemple `T.pack`.
- consulter la documentation de [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html).
- remplacer toutes les occurrences de `String` par `Text` dans Atbash.hs, c'est-à-dire :

```haskell
decode :: Text -> Text
decode cipherText = ...

encode :: Text -> Text
encode plainText = ...
```

Cette partie est entièrement facultative.
