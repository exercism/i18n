# Instructions

Détermine si un mot ou une phrase est un isogramme.

Un isogramme (aussi appelé « mot sans motif ») est un mot ou une phrase dans lequel aucune lettre ne se répète ; les espaces et les traits d'union, eux, peuvent apparaître plusieurs fois.

Exemples d'isogrammes :

- lumberjacks
- background
- downstream
- six-year-old

Le mot _isograms_, en revanche, n'est pas un isogramme, car le s se répète.
