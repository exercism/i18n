# Workflow configlet

Le _workflow_ `configlet` utilise l'[outil configlet](/docs/building/configlet) pour vérifier que les fichiers (de configuration) d'un parcours sont correctement structurés, tant sur le plan syntaxique que sémantique.
Pour ce faire, il exécute [`configlet lint`](/docs/building/configlet/lint).

## Active la vérification du formatage des fichiers

Les parcours peuvent utiliser [`configlet fmt`](/docs/building/configlet/format) pour formater les différents fichiers de configuration du parcours.
La même commande permet aussi de vérifier que tous les fichiers de configuration sont correctement formatés.

Le _workflow_ `configlet` permet de vérifier si les fichiers de configuration sont correctement formatés, mais cette vérification est facultative et désactivée par défaut.
Pour activer la vérification du formatage des fichiers de configuration, suis ces étapes :

1. Crée un fichier `.github/org-wide-files-config.toml` avec le contenu suivant

```toml
[configlet]
fmt = true
```

2. Une fois ce fichier fusionné dans `main`, une PR est automatiquement ouverte pour modifier le _workflow_ `configlet.yml` comme suit :

```diff
  jobs:
    configlet:
      uses: exercism/github-actions/.github/workflows/configlet.yml@main
+     with:
+       fmt: true
```

3. Une fois cette PR fusionnée, le _workflow_ `configlet` vérifiera aussi le formatage des fichiers de configuration du parcours.

## Source

Le _workflow_ est défini dans le fichier `.github/workflows/configlet.yml`.
