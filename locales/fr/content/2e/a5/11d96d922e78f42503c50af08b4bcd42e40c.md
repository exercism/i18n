# Instructions

Dans cet exercice, tu vas écrire du code pour garder une trace des langages de programmation que tu veux apprendre sur Exercism.

Tu as six tâches, qui consistent toutes à manipuler des tableaux.

## 1. Crée un nouveau tableau

Pour garder une trace des langages que tu veux apprendre, tu vas devoir créer un nouveau tableau. Définis la fonction `new_list` qui renvoie un nouveau tableau vide.

```gleam
new_list()
// -> []
```

## 2. Définis un tableau existant

Pour l'instant, tu as une feuille de papier sur laquelle sont inscrits les langages que tu veux apprendre : Gleam, Go et TypeScript. Définis la fonction `existing_list` pour renvoyer ce tableau.

```gleam
existing_list()
// -> ["Gleam", "Go", "TypeScript"]
```

## 3. Ajoute un nouveau langage à un tableau

Au fur et à mesure que tu explores Exercism et que tu découvres des langages plus intéressants, tu veux les ajouter à ton tableau. Implémente la fonction `add_language` pour ajouter un nouveau langage au début de ton tableau.

```gleam
add_language(["OCaml", "Elixir"], "Scheme")
// -> ["Scheme", "OCaml", "Elixir"]
```

## 4. Compte les langages du tableau

Compter les langages un par un n'est pas pratique. Implémente la fonction `count_languages` pour compter le nombre de langages de ton tableau.

```gleam
count_languages(["jq", "Elm", "Rust", "Kotlin"])
// -> 4
```

## 5. Inverse le tableau

À un moment donné, tu réalises que ton tableau est en fait dans l'ordre inverse ! Implémente la fonction `reverse_list` pour inverser ton tableau.

```gleam
reverse_list(["Python", "Julia", "Idris", "COBOL"])
// -> ["COBOL", "Idris", "Julia", "Python"]
```

## 6. Vérifie si un tableau est intéressant

Même si tu aimes tous les langages, Gleam occupe une place particulière dans ton cœur. Ainsi, un tableau de langages te passionne vraiment si :

- Le premier élément du tableau est Gleam.
- Le deuxième élément du tableau est Gleam et le tableau contient deux ou trois langages.

Implémente la fonction `exciting_list` pour vérifier si un tableau de langages est intéressant :

```gleam
exciting_list(["Lua", "Gleam"])
// -> True
```
