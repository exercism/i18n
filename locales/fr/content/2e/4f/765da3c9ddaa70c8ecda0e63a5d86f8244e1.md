# À propos

## Compare des nombres

En `jq`, on peut comparer les nombres avec les opérateurs relationnels et d'égalité suivants :

| Comparaison         | Opérateur |
| ------------------- | --------- |
| Supérieur à         | `a > b`   |
| Supérieur ou égal à | `a >= b`  |
| Inférieur à         | `a < b`   |
| Inférieur ou égal à | `a <= b`  |
| Égal à              | `a == b`  |
| Différent de        | `a != b`  |

Le résultat de la comparaison est toujours une valeur booléenne, donc soit `true`, soit `false`.

```jq
1 < 3,      # => true
2 != 2,     # => false
1 == 1.0    # => true
            # All numbers are floating-points, so this is different syntax
            # for the exact same value.
```

## Compare des _strings_

Les opérateurs de comparaison ci-dessus peuvent aussi servir à comparer des _strings_.
Dans ce cas, c'est l'ordre du dictionnaire (lexicographique) qui s'applique.
Le classement se fait [par valeur de point de code Unicode][sort].

[sort]: https://jqlang.org/manual/#sort-sort_by

```jq
"Apple" > "Pear",   # => false
"a" < "above",      # => true
"a" == "A"          # => false
```

Il faut être prudent quand on compare deux variables qui semblent contenir des valeurs numériques mais qui sont de type _string_.
À cause de l'ordre du dictionnaire, le résultat ne sera pas le même que si l'on compare des valeurs de type nombre.

```jq
10 < 2,     # => false
"10" < "2"  # => true (because "1" comes before "2")
```

## Égalité « stricte »

L'opérateur `==` de `jq` est comme le `===` de JavaScript, en ce sens que des éléments qui « se ressemblent » mais qui sont de types différents ne sont pas égaux.

```jq
"3" == 3    # => false
            # the value on the left has type string,
            # the value on the right has type number.
```

## Compare des tableaux

Deux tableaux sont égaux si tous les éléments correspondants sont égaux.

```jq
[1, 2, 3] == [1, 2, 3]      # => true
[1, 2, 3] == [1, 3, 2]      # => false, different order
[1, 2, 3] == [1, 2, "3"]    # => false, different types
```

## Compare des objets

Deux objets sont égaux s'ils ont les mêmes paires clé-valeur.

```jq
{name: "Joe", age: 42} == {age: 42, name: "Joe"}                # => true
{name: "Joe", age: 42} == {age: 42, name: "Jane"}               # => false
{name: "Joe", age: 42} == {age: "42", name: "Joe"}              # => false
{name: "Joe", age: 42} == {age: 42, name: "Joe", height: 175}   # => false

# comparisons will drill down as deeply as required
{a: {b: {c: [1, 2]}}} == {a: {b: {c: [1, 2]}}}                  # => true
{a: {b: {c: [1, 2]}}} == {a: {b: {c: [1, 2, 3]}}}               # => false
```
