# Introduction

La classe Lambda est un ensemble de méthodes fonctionnelles permettant d'utiliser la programmation de style fonctionnel avec Haxe. Elle permet d'agir sur un Iterable entier en une seule fois. C'est souvent préférable aux boucles, car c'est moins source d'erreurs et plus facile à lire. Pour plus de commodité, les classes Array et List contiennent certaines des méthodes les plus utilisées de la classe Lambda.

Voici quelques-unes des fonctions de la classe `Lambda` :

- `Lambda.array`, `Lambda.list` convertissent un Iterable en Array ou en List, en renvoyant toujours une nouvelle instance.
- `Lambda.count` compte le nombre d'éléments. Si l'Iterable est un Array ou une List, il est plus rapide d'utiliser sa propriété length.
- `Lambda.has` détermine si l'élément spécifié se trouve dans l'Iterable.
- `Lambda.indexOf` détermine l'indice de l'élément spécifié.
- `Lambda.find` trouve le premier élément correspondant à la fonction de recherche donnée.
- `Lambda.concat` fusionne deux Iterables et renvoie une nouvelle List.
- `Lambda.filter` trouve les éléments qui satisfont un critère et renvoie une nouvelle List.

Un exemple illustrant quelques-unes de ces fonctions :

```haxe
using Lambda;

class Main {
  static function main() {
    var words = ["boat", "dog", "phone", "cat", "food"];

    var isThreeLetters = function(word) return word.length == 3;

    trace(words.filter(isThreeLetters)); // [dog,cat]
  }
}
```
