# Introduction

Le type `char` de F# est une valeur de 16 bits qui représente les plus petites composantes adressables du texte, immuable par défaut.

On peut définir des `char` comme littéraux à l'aide de guillemets simples :

```fsharp
let ch = 'A'
// => val ch: char = 'A'
```

Les _strings_ sont une séquence de `char`.

On peut extraire un `char` d'une _string_ grâce à son indice (en partant de zéro) :

```fsharp
"Exercism"[4] //  =>  'c'
```

Parcourir une _string_ renvoie un `char` à chaque étape.

L'exemple suivant utilise une fonction d'ordre supérieur et une fonction anonyme, par commodité.
Elles seront vues en détail plus tard dans le programme, mais pour l'instant il s'agit essentiellement d'une façon concise d'écrire une boucle sur les caractères d'une _string_.

```fsharp
Seq.map (fun c -> c, int c) "F#"  //  =>  [('F', 70); ('#', 35)]
```

Comme montré ci-dessus, on peut convertir un `char` en sa valeur `int`.
Cela fonctionne aussi (*au moins dans certains cas*) pour d'autres écritures :

```fsharp
Seq.map (fun c -> c, int c) "東京"  //  =>  [('東', 26481); ('京', 20140)]
```

C'est l'Int16 sous-jacent qui est utilisé pour comparer des caractères :

```fsharp
'A' < 'D'  // =>  true
```

De plus, on peut convertir un `int` en `char` :

```fsharp
char 77  // => 'M'
```

La bibliothèque `System.Char` contient l'ensemble complet des méthodes attendues pour un langage .NET, comme les conversions majuscule/minuscule :

```fsharp
'a' |> System.Char.ToUpper  // =>  'A'

'Q' |> System.Char.ToLower  // =>  'q'
```
