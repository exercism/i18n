# Nombres entiers

Un nombre entier est un nombre sans partie décimale qui appartient à l'ensemble `{..., -2, -1, 0, 1, 2, ...}`.
La valeur maximale et la valeur minimale d'un entier dépendent du système sur lequel PHP s'exécute.
Sur la plupart des systèmes modernes, un entier est une valeur de 64 bits, ce qui signifie qu'il peut représenter `-9_223_372_036_854_775_808` jusqu'à `9_223_372_036_854_775_807` inclus.

```php
<?php

$a = 1234;
$a = 1_234_567;
```

On peut écrire des valeurs littérales entières dans une base autre que 10 en utilisant un préfixe de base :

```php
<?php

$a = 0123; // octal number (equivalent to 83 decimal)
$a = 0o123; // octal number (as of PHP 8.1.0)
$a = 0x1A; // hexadecimal number (equivalent to 26 decimal)
$a = 0b11111111; // binary number (equivalent to 255 decimal)
```
