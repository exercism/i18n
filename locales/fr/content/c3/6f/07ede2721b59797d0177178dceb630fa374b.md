# Installation

## Installe la CLI Clojure
Clojure fournit des outils en ligne de commande qui permettent de lancer un REPL Clojure, d'utiliser les bibliothèques Clojure et Java, et de démarrer des programmes Clojure.

Si tu as besoin d'installer Java, on te recommande [Adoptium Temurin 17](https://adoptium.net/).

### Linux
Vérifie que les dépendances suivantes sont installées : `bash`, `curl`, `rlwrap` et `Java`.
Tu peux installer Clojure de deux façons différentes :

1. LinuxBrew, qui nécessite [Homebrew](https://brew.sh/)

```bash
brew install clojure/tools/clojure
```

2. Installation par script

```bash
curl -O https://download.clojure.org/install/linux-install-1.11.1.1347.sh
chmod +x linux-install-1.11.1.1347.sh
sudo ./linux-install-1.11.1.1347.sh
```

### Homebrew pour macOS
Installe les outils en ligne de commande avec brew depuis le _tap_ [clojure/tools](https://github.com/clojure/homebrew-tools) :

```bash
brew install clojure/tools/clojure
```

#### Java

N'importe quelle distribution de Java fait l'affaire. Au besoin, tu peux installer Temurin avec brew :

```bash
brew tap homebrew/cask-versions
brew install --cask temurin17
```

### Windows

Clojure sous Windows s'est beaucoup amélioré récemment. On recommandait auparavant d'utiliser WSL2, qui fonctionne très bien, mais il existe désormais un installeur PowerShell. Clojure sous Windows est actuellement en phase alpha ; consulte [clj-on-windows](https://github.com/clojure/tools.deps.alpha/wiki/clj-on-Windows#known-issues) pour connaître les problèmes connus.

Vérifie que Java est installé et que la variable d'environnement `JAVA_HOME` est définie, puis exécute :

```powershell
iwr -useb download.clojure.org/install/win-install-1.11.1.1165.ps1 | iex
```

Une autre façon d'installer Clojure sous Windows consiste à utiliser le gestionnaire de paquets [Scoop](https://scoop.sh/). Pour installer Scoop, ouvre PowerShell et exécute ces deux commandes, l'une après l'autre :

 ```sh
 iwr -useb get.scoop.sh | iex
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser -Force
```

Pour installer Clojure avec Scoop, tu dois d'abord ajouter deux _buckets_ importants :

```sh
# if you don't have git version control system installed
# it is required for adding new external buckets to your scoop installer
# you can skip this step otherwise
scoop install git

# add scoop bucket for Java 
scoop bucket add java

# add scoop bucket for clojure build
scoop bucket add scoop-clojure https://github.com/littleli/scoop-clojure
```

On est maintenant prêt à installer Java et Clojure en exécutant les commandes suivantes :

```sh
# install Java runtime and compiler
scoop install adoptopenjdk-lts-hotspot

# install official clojure tools
scoop install clojure

# update to the newest version
scoop update clojure
```

Après avoir exécuté les étapes ci-dessus avec succès, tu devrais pouvoir lancer Clojure avec la commande suivante :

```sh
clj
```

## Installe Leiningen (facultatif)

Bien qu'il ne soit plus indispensable, on prend toujours en charge l'outil complet de gestion de projet [Leiningen](https://leiningen.org/). Il propose toutes sortes de tâches utiles comme des tests pratiques, des _builds_ et un REPL amélioré.

1. Télécharge le [script lein](https://raw.githubusercontent.com/technomancy/leiningen/stable/bin/lein) ou [lein.bat](https://raw.githubusercontent.com/technomancy/leiningen/stable/bin/lein.bat) (Windows)
2. Place-le dans ton `$PATH` là où ton shell peut le trouver (par ex. `/usr/local/bin/`)
3. Rends-le exécutable (`sudo chmod a+x /usr/local/bin/lein`)
4. Exécute `lein`.
