# Introduction

L'attribut Flags permet de représenter les valeurs définies dans une union discriminée sous forme de positions de bits (c'est-à-dire de drapeaux).
En tant que drapeaux, ces valeurs peuvent être combinées, ce qui permet de représenter plusieurs conditions booléennes dans une seule valeur.

```fsharp
[<Flags>]
type PhoneFeatures =
| Call = 1
| Text = 2
```

```fsharp
[<Flags>]
type PhoneFeaturesBinary =
| Call = 0b00000001
| Text = 0b00000010
```

Activer un drapeau se fait avec l'opérateur OR bit à bit (`|||`) ; désactiver un drapeau se fait en combinant l'opérateur AND bit à bit (`&&&`) et l'opérateur de négation bit à bit (`~~~`).
Pour vérifier l'état d'un drapeau, on peut utiliser l'opérateur AND bit à bit, mais aussi la méthode `HasFlag()`.

```fsharp
let features = PhoneFeatures.Call

// Set the Text flag
let moreFeatures = features ||| PhoneFeatures.Text

moreFeatures.HasFlag(PhoneFeatures.Call) // => true
moreFeatures.HasFlag(PhoneFeatures.Text) // => true
```
