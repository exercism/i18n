# Instructions

Convertis un nombre, représenté par une suite de chiffres dans une base donnée, vers n'importe quelle autre base.

Implémente une conversion de base générale. Étant donné un nombre en base **a**, représenté par une suite de chiffres, convertis-le en base **b**.

## Remarque

- Essaie d'implémenter la conversion toi-même.
  N'utilise pas autre chose pour faire la conversion à ta place.

## À propos de la [notation positionnelle](https://en.wikipedia.org/wiki/Positional_notation)

Dans la notation positionnelle, un nombre en base **b** peut être compris comme une combinaison linéaire des puissances de **b**.

Le nombre 42, *en base 10*, signifie :

(4 * 10^1) + (2 * 10^0)

Le nombre 101010, *en base 2*, signifie :

(1 * 2^5) + (0 * 2^4) + (1 * 2^3) + (0 * 2^2) + (1 * 2^1) + (0 * 2^0)

Le nombre 1120, *en base 3*, signifie :

(1 * 3^3) + (1 * 3^2) + (2 * 3^1) + (0 * 3^0)
