# Espace réservé

## Astuces pour `jq`

Cet exercice consiste à prendre un objet en entrée et à le transformer en un nouvel objet.
Quelques fonctions natives qui peuvent t'aider :

- [`to_entries`][x_entries]
  - cette fonction prend un objet en entrée
  - elle produit un tableau : chaque élément du tableau est un objet `{"key": "K", "value": V}`
    - chaque `K` est une clé de l'objet d'entrée
    - chaque `V` est la valeur correspondante de `K`.
- [`from_entries`][x_entries]
  - l'opération inverse
  - prend un tableau d'objets `{"key": K, "value": V}` et construit un objet

Un exemple :

```sh
jq -n '
    {
        "username": "glennj",
        "tracks": ["bash", "awk", "jq"],
        "reputation": 123
    }
    | to_entries
'
```

affiche

```json
[
  {
    "key": "username",
    "value": "glennj"
  },
  {
    "key": "tracks",
    "value": ["bash", "awk", "jq"]
  },
  {
    "key": "reputation",
    "value": 123
  }
]
```

[x_entries]: https://jqlang.org/manual/#to_entries-from_entries-with_entries
