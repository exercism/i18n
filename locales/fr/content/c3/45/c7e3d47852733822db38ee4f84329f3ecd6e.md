# Introduction

La plupart du temps, Factor gère l'itération au moyen de combinateurs comme `each`, `map` et `count`. Parfois, cependant, la façon la plus élégante d'exprimer un calcul est la **récursivité** : un mot qui s'appelle lui-même.

## Définis un mot récursif

Une définition `:` peut s'appeler elle-même directement :

```factor
: count-down ( n -- )
    dup 0 = [ drop ] [ dup . 1 - count-down ] if ;

5 count-down
! prints 5 4 3 2 1
```

## Branchement vide ou non

`if-empty` (dans [`sequences`][sequences]) est le cas de base naturel de la récursivité :

```
if-empty ( seq emptyquot nonemptyquot -- )
```

```factor
{ 4 0 9 } [ "empty" ] [ "got data" ] if-empty .
! => "got data"
```

`emptyquot` s'exécute avec la séquence (vide) déjà consommée ; `nonemptyquot` s'exécute avec la séquence encore sur la pile.

## `cond` : une chaîne de branches gardées

Quand la récursivité comporte plus de deux cas, `cond` (dans [`combinators`][combinators]) garde le code lisible :

```factor
: classify ( n -- label )
    {
        { [ dup 0 < ] [ drop "negative" ] }
        { [ dup 0 = ] [ drop "zero"     ] }
        [ drop "positive" ]
    } cond ;
```

## Références anticipées avec `DEFER:`

Une définition `:` peut s'appeler elle-même directement, mais quand deux mots s'appellent *l'un l'autre*, l'analyseur syntaxique voit le premier avant que le second n'existe. `DEFER:` réserve un nom pour que la première définition puisse se compiler :

```factor
DEFER: even?

: odd? ( n -- ? ) dup 0 = [ drop f ] [ 1 - even? ] if ;
: even? ( n -- ? ) dup 0 = [ drop t ] [ 1 - odd? ] if ;
```

`DEFER:` est aussi pratique quand un mot auxiliaire se lit plus naturellement *après* le mot qui l'utilise.
