# Instructions

Tu vas écrire du code pour gérer un tableau de langages de programmation à apprendre.
Les langages seront stockés dans un tableau appelé `@LanguageList::Languages`.

## 1. Ajoute un langage au tableau @Languages

Modifie le sous-programme `LanguageList::add_language`, qui prend un nom de langage en argument, pour ajouter le langage à la fin du tableau `@LanguageList::Languages`.

## 2. Supprime un langage du tableau @Languages

Modifie le sous-programme `LanguageList::remove_language` pour supprimer le dernier langage du tableau `@LanguageList::Languages`.

## 3. Récupère le premier langage du tableau @Languages

Modifie le sous-programme `LanguageList::first_language` pour renvoyer le premier langage du tableau `@LanguageList::Languages`.

## 4. Récupère le dernier langage du tableau @Languages

Modifie le sous-programme `LanguageList::last_language` pour renvoyer le dernier langage du tableau `@LanguageList::Languages`.

## 5. Récupère une tranche de langages du tableau @Languages

Modifie le sous-programme `LanguageList::get_languages`, qui prend un tableau de nombres correspondant aux éléments souhaités, pour renvoyer une tranche du tableau `@LanguageList::Languages`.

## 6. Vérifie si un langage existe dans le tableau @Languages

Modifie le sous-programme `LanguageList::has_language`, qui prend un nom de langage en argument, pour renvoyer une valeur vraie ou fausse qui indique si le langage existe dans le tableau `@LanguageList::Languages`.
