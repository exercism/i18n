# Tests

## TLDR

- Rends-toi dans le répertoire de l'exercice (par ex. `~/Exercism/hello-world`).
- Lance une session `jconsole` dans un terminal.
- Charge le fichier de ta solution (par ex. `load 'hello-world.ijs'`).
- Charge le _framework_ de tests unitaires en saisissant `load  'general/unittest'`.
- Teste ta solution en saisissant `unittest 'test.ijs'`.
<br></br>
- Sinon, tu peux aussi lancer les tests sur une seule ligne, comme ceci : `jconsole -js "load 'hello-world.ijs'" "echo unittest 'test.ijs'" "exit 0"`.

## Session jconsole

La configuration des tests de ce parcours se veut aussi simple que possible.
Si tu travailles sur un exercice, disons `hamming.ijs`, voici comment le travail devrait se dérouler.
Modifie `hamming.ijs` en y écrivant ta solution.
Construis-la de façon interactive en saisissant d'abord :

```j
NB. your j terminal binary may be ijconsole (eg. on Debian)
jconsole 'hamming.ijs' NB. start a J console session with definitions loaded hamming.ijs
```

Ensuite, depuis la console J, recharge-la en saisissant :

```j
load 'hamming.ijs'
```

L'étape suivante consiste à charger le _framework_ de tests unitaires en saisissant :

```j
load 'general/unittest'
```

Pour lancer les tests (après avoir chargé ta solution), saisis :

```j
unittest 'test.ijs'
```

Puis observe les résultats.

## En ligne de commande

Tu peux lancer les tests avec une commande sur une seule ligne dans le terminal, à l'aide de l'option -js :

```j
jconsole  -js "load 'hamming.ijs'" "echo unittest 'test.ijs'" "exit 0"
```
où chaque argument représente une commande qui sera exécutée séquentiellement.
