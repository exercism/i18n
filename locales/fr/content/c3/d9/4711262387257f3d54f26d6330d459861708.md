# Tableaux

Un **tableau** contient une suite de valeurs, toutes du même type, dans l'ordre.

Le type s'écrit `ARRAY{T}`, où `T` est ce qu'il contient. Un tableau de _strings_ est `ARRAY{STR}` ; un tableau de nombres entiers est `ARRAY{INT}`.

```sather
   row : ARRAY{STR} := |"Mia", "Ana", "Ben"|;
```

Les valeurs entre les deux marques `|` forment le **littéral de tableau**. Sather en déduit la taille à partir de leur nombre.

## Récupère une valeur

Les crochets contiennent la position :

```sather
row[0]      -- "Mia"
row[1]      -- "Ana"
row[2]      -- "Ben"
```

Le comptage commence à **zéro**, pas à un. La première valeur est donc à `0`, et la dernière d'une suite de trois est à `2`.

## Combien ?

`.size` donne le nombre de valeurs que contient le tableau.

```sather
row.size    -- 3
```

Comme le comptage commence à zéro, la dernière position est toujours `.size - 1` :

```sather
row[row.size - 1]     -- "Ben"
```

Demander une position qui n'existe pas (`row[3]`, ou `row[-1]`) est une erreur que Sather ne détectera pas à ta place, donc mieux vaut écrire `.size - 1` plutôt que de compter les valeurs à l'œil.

## Parcours un tableau

Un tableau et une boucle vont de pair. Fais progresser une variable sur les positions et sers-t'en pour accéder à chaque valeur :

```sather
   total ::= 0;
   i ::= 0;
   loop
      until!(i >= scores.size);
      total := total + scores[i];
      i := i + 1;
   end;
```
