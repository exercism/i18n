# Tests

## Exécute les tests

1. Récupère un exercice :

    ```bash
    $ exercism download -track=kotlin --exercise=hello-world
    ```

2. Place-toi dans le dossier de l'exercice :

    ```bash
    $ cd <path_to_exercise_directory>
    ```

3. Lance les tests :

    ```bash
    $ ./gradlew test
    ```

Dans la plupart des exercices, seul le premier test est exécuté par défaut.
Les autres tests portent l'annotation `@Ignore`, qui les fait ignorer.
Au fur et à mesure que tu résous chaque test, retire le `@Ignore` du suivant pour avancer.

C'est une pratique courante dans le développement piloté par les tests (ou TDD pour faire court).
Elle sert à garantir que tu travailles sur un seul problème à la fois.
