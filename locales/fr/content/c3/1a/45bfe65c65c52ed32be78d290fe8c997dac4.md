# Indices

## Général

- L'espace de noms `clojure.string` contient de nombreuses [fonctions de manipulation de chaînes de caractères][string-ns].

## 1. Récupère le message d'une ligne de log

- La fonction [`split`][split] permet de découper une chaîne de caractères selon une expression régulière.
- La fonction [`trim`][trim] permet de supprimer les espaces aux extrémités d'une chaîne de caractères.

## 2. Récupère le niveau de log d'une ligne de log

- On peut convertir une `string` en minuscules à l'aide de [`lower-case`][lower-case].

## 3. Reformate une ligne de log

- La fonction [`str`][str] permet de concaténer des chaînes de caractères.
