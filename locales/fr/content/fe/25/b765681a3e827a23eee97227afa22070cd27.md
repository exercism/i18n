# Nombres à virgule flottante

Les nombres à virgule flottante sont utilisés en PHP pour représenter un sous-ensemble des nombres réels.
Ils commencent par un ou plusieurs chiffres séparés par un séparateur décimal.

```php
<?php

$a = 1.234; 
$b = 1.2e3; 
$c = 7E-10;
$d = 1_234.567; // as of PHP 7.4.0
```

## Pièges courants

Les nombres à virgule flottante ne permettent pas de représenter tous les nombres ni d'effectuer toutes les opérations arithmétiques.
Utiliser des nombres à virgule flottante pour représenter des dollars et des cents peut souvent entraîner des erreurs d'arrondi.

```php
<?php

$result = 0.1 + 0.2; // => 0.30000000000000004
```
