# Introduction

Lua utilise deux représentations pour les nombres : les nombres entiers sur 64 bits et les nombres à virgule flottante en double précision. Il prend en charge l'ensemble habituel des opérateurs arithmétiques : l'addition, la soustraction, la multiplication, la division et la négation. Il prend également en charge la division entière, le modulo et l'exponentiation.

| Opérateur | Exemple             |
| --------- | ------------------- |
| `+`       | `1 + 2 --> 3`       |
| `-`       | `2 - 1 --> 1`       |
| `*`       | `2 * 2 --> 4`       |
| `/`       | `4 / 2 --> 2.0`     |
| `//`      | `11 // 3 --> 3`     |
| `%`       | `11 % 3 --> 2`      |
| `^`       | `10 ^ 2 --> 100.0`  |
| `-`       | `-(2 * 2) --> -4`   |
