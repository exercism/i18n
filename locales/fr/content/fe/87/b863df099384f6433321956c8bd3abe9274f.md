# Astuces

## 1. Affiche un badge pour un employé

- Pour construire les _strings_ en Base R, la fonction [`sprintf`][ref-sprintf] est utile.
- Pour une approche Tidyverse, on peut utiliser [`str_glue`][ref-str_glue], de la bibliothèque `stringr`.

## 2. Affiche un badge pour un nouvel employé

- Fais un branchement sur [`is.na`][ref-isna].

## 3. Affiche un badge pour le propriétaire

- Fais un branchement sur [`is.null`][ref-isnull].

## 4. Calcule le salaire total des employés sans identifiant

- Tu peux [filtrer][concept-vector-filtering] sur [`is.na`][ref-isna], puis utiliser [`sum`][ref-sum].
- Que vaut `salaries[is.na(ids)]` s'il n'y a aucun employé sans identifiant ? Il serait utile de vérifier cela dans une console R. Si R n'est pas installé sur ton ordinateur, des consoles en ligne comme [rdrr.io][web-rdrr] peuvent t'aider.
