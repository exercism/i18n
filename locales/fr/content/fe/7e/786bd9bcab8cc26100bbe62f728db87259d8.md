# Instructions

Dans cet exercice, tu vas implémenter un moyen de garder la trace des meilleurs scores du jeu le plus populaire de la salle d'arcade près de chez toi.

Tu as 6 fonctions à implémenter, qui servent principalement à manipuler un objet contenant les meilleurs scores.

## 1. Crée un nouveau tableau des meilleurs scores

Écris une fonction `create_score_board` qui crée un objet qui sert de tableau des meilleurs scores.
Les clés de cet objet seront les noms des joueurs, et les valeurs, leurs scores.
Pour les besoins des tests, on souhaite inclure directement une entrée dans l'objet.
Cette entrée initiale doit être composée de `"The Best Ever"` comme nom de joueur et de `1000000` comme score.

```jq
create_score_board
# returns an object with one initial entry
```

## 2. Ajoute des joueurs à un tableau des meilleurs scores

Pour ajouter un joueur au tableau des meilleurs scores, implémente la fonction `add_player`.
Elle prend un tableau des meilleurs scores en entrée et nécessite deux paramètres : le nom du joueur et le score du joueur.
La fonction renvoie le tableau des meilleurs scores avec le nouveau joueur ajouté.

```jq
{"José Valim", 486373}
| add_player("Dave Thomas"; 0)
# => {"Dave Thomas": 0, "José Valim": 486373} -- in some order
```

Si le joueur est déjà sur le tableau, renvoie le tableau inchangé.

## 3. Retire des joueurs d'un tableau des meilleurs scores

Si des joueurs enfreignent les règles de la salle d'arcade, ils sont retirés manuellement du tableau des meilleurs scores.
Implémente `remove_player`, qui prend un tableau en entrée et un paramètre : le nom du joueur à retirer.
Cette fonction doit supprimer du tableau l'entrée du joueur donné et renvoyer le nouveau tableau.
Si le joueur n'était pas déjà sur le tableau, rien ne doit changer : le tableau doit être renvoyé tel quel.

```q
{"Dave Thomas": 0} | remove_player("Dave Thomas")
# => {}

{"Dave Thomas": 0} | remove_player("Rose Fanaras")
# => {"Dave Thomas": 0}
```

## 4. Augmente le score d'un joueur

Si un joueur termine une autre partie à la salle d'arcade, un certain nombre de points s'ajoutent au score précédent du tableau.
Implémente `update_score`, qui prend un tableau des meilleurs scores en entrée et nécessite deux paramètres : le nom du joueur et le nombre de points à ajouter.
La fonction doit renvoyer le tableau des meilleurs scores une fois la mise à jour effectuée.

```jq
{"Freyja Ćirić": 12771000} | update_score("Freyja Ćirić"; 73)
# => {"Freyja Ćirić": 12771073}
```

Cette fonction doit ajouter le joueur au tableau s'il n'y était pas déjà.

## 5. Applique les points bonus du lundi

La salle d'arcade tient un tableau des scores séparé le lundi.
À la fin de la journée, chaque joueur de ce tableau reçoit 100 points supplémentaires.

Implémente la fonction `apply_monday_bonus`.
La fonction ajoute les points bonus à chaque joueur inscrit sur ce tableau.

```jq
{
  "Dave Thomas": 44,
  "Freyja Ćirić": 539,
  "José Valim": 265
}
| apply_monday_bonus
# => {"Dave Thomas": 144, "Freyja Ćirić": 639, "José Valim": 365}
```

## 6. Trouve le score total

Différentes salles d'arcade s'affrontent pour déterminer qui a les meilleurs joueurs.
La salle d'arcade avec le score total le plus élevé remporte l'honneur.

Écris une fonction `total_score`.
Elle prend un tableau des meilleurs scores en entrée et renvoie la somme des scores de tous les joueurs.

```jq
{
  "Dave Thomas": 44,
  "Freyja Ćirić": 539,
  "José Valim": 265
}
| total_score
# => 848
```
