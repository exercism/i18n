# Permissions du dépôt des mainteneurs

Un mainteneur de parcours est une personne membre de l'équipe GitHub du parcours.
Devenir membre d'une équipe de parcours se fait _sur invitation uniquement_.

```exercism/note
Si tu souhaites devenir mainteneur de parcours, ouvre un sujet sur le [forum](https://forum.exercism.org/c/exercism/building-exercism/125).
```

## Catégorie de maintenance

Il existe cinq catégories de maintenance :

1. `wip-track`
2. `unmaintained`
3. `maintained-solitary`
4. `maintained-autonomous`
5. `maintained`

La catégorie de maintenance d'un parcours est déterminée par trois variables :

1. Si le parcours est actif (c'est-à-dire que les apprenants peuvent rejoindre le parcours sur le site)
2. Le nombre de mainteneurs du parcours
3. Le nombre de mainteneurs du parcours qui font aussi partie de l'équipe GitHub `cross-track-maintainers`

Pour déterminer la catégorie de maintenance, cherche dans ce tableau la première catégorie qui correspond au parcours :

| Catégorie             | Actif ? | Nombre de mainteneurs | Nombre de mainteneurs inter-parcours |
| --------------------- | ------- | --------------------- | ------------------------------------ |
| wip-track             | Non     | Peu importe           | Peu importe                          |
| unmaintained          | Oui     | 0                     | 0                                    |
| maintained-autonomous | Oui     | > 0                   | = Nombre de mainteneurs              |
| maintained-solitary   | Oui     | 1                     | 0                                    |
| maintained            | Oui     | > 1                   | < Nombre de mainteneurs              |

## Permissions du dépôt

La catégorie de maintenance sert à définir les permissions du ou des dépôts GitHub du parcours.

| Catégorie             | PR requise | Approbation de PR requise | Revues de l'équipe inter-parcours |
| --------------------- | ---------- | ------------------------- | --------------------------------- |
| wip-track             | Non        | Non                       | Non                               |
| unmaintained          | Oui        | Oui                       | Oui                               |
| maintained-solitary   | Oui        | Oui                       | Oui                               |
| maintained-autonomous | Oui        | Non                       | Non                               |
| maintained            | Oui        | Non                       | Non                               |

```exercism/caution
La catégorie `wip-track` est la seule qui autorise les mainteneurs à pousser vers `main`.
```

```exercism/caution
Les dépôts d'outillage nécessitent _toujours_ l'approbation d'une PR, car leur contenu est protégé par un [fichier CODEOWNERS](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/about-code-owners).
```
