# À propos

Il existe deux types de nombres différents en Elixir : les entiers et les nombres décimaux.

Les entiers sont des nombres sans partie fractionnaire.

```elixir
integer = 3
# => 3
```

Quelques fonctions utiles pour manipuler les entiers se trouvent dans le module [`Integer`][integer].

```elixir
Integer.digits(123)
# => [1, 2, 3]
```

Les grands entiers (mais aussi les nombres décimaux) s'écrivent généralement en regroupant les chiffres par trois à l'aide d'un tiret bas.

```elixir
1_000_000
# => 1000000
```

La taille maximale des nombres en Elixir n'est limitée que par la mémoire disponible sur le système, car Elixir utilise l'[arithmétique de précision arbitraire][arbitrary-precision-arithmetic].

Elixir prend également en charge des notations raccourcies pour saisir des [entiers binaires, octaux et hexadécimaux][integers-in-other-bases].

```elixir
0b0100
# => 4

0o555
# => 365

0xFF
# => 255
```

## Comparaison

Deux nombres, l'un entier et l'autre décimal, peuvent être considérés comme égaux ([`==`][kernel-equal]) s'ils ont la même valeur. Cependant, comme ce sont des types différents, ils ne sont jamais strictement égaux ([`===`][kernel-strictly-equal]).

```elixir
1 == 1.0
# => true

1 === 1.0
# => false
```
