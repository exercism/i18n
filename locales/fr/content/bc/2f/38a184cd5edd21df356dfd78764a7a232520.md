# Installation

## Installe Godot Engine

Le parcours GDScript repose sur [Godot Engine][godot-engine], qui fonctionne sous Windows, Linux, macOS et Android.
Pour le moment, l'exécuteur de tests qui sert à [travailler en local][working-locally] nécessite Linux.
Ce parcours requiert Godot en version 4.0 ou supérieure.

Une fois l'installation terminée, tu peux vérifier que la CLI a bien été installée en exécutant cette commande dans un terminal :

```bash
godot --version
```

## Installe l'exécuteur de tests du parcours GDScript d'Exercism

Tu dois avoir correctement [installé Godot][installation] pour pouvoir utiliser l'exécuteur de tests.

Pour compiler et tester des scripts GDScript pour Exercism, Godot sera lancé en mode « _headless_ » depuis la CLI.
Ces instructions nécessitent actuellement Linux et bash.

### Étape 1 : Installe l'infrastructure globale de l'exécuteur de tests

Pour préparer le test, clone [https://github.com/exercism/gdscript-test-runner][gdscript-test-runner] et déplace son contenu vers `/opt/exercism/gdscript/test-runner/` :

```sh
git clone https://github.com/exercism/gdscript-test-runner.git
sudo mv gdscript-test-runner/ /opt/exercism/gdscript/test-runner/
```

### Étape 2 : Télécharge le script de l'exécuteur de tests d'un exercice

Si tu as installé et configuré l'outil `exercism` et téléchargé au moins un exercice GDScript, celui-ci a normalement créé un dossier `gdscript` dans ton espace de travail (comme le montre la commande `exercism configure`) pour y héberger les exercices.
Enregistre [l'exécuteur de tests][test-local-gdscript-solution] dans ce dossier et rends le fichier exécutable.

## Lance les tests

Une fois les étapes d'installation terminées, tu devrais pouvoir partir de n'importe quel dossier d'exercice (par ex. `~/exercism/gdscript/two-fer`) et lancer le script (situé un niveau au-dessus, dans `../`) pour tester ta solution locale de cet exercice :

```sh
../test-local-gdscript-solution.sh
```

[gdscript-test-runner]: https://github.com/exercism/gdscript-test-runner

## Utilise un IDE

Pour bénéficier de la coloration syntaxique GDScript dans un éditeur comme [Visual Studio Code][vscode], tu dois installer une extension telle que [godot-tools][godot-tools] et disposer d'un serveur de débogage en cours d'exécution.
Godot démarre ce serveur de débogage automatiquement dès qu'un projet est ouvert dans son propre éditeur, et le laisse tourner jusqu'à ce que le projet ou Godot lui-même soit fermé.
