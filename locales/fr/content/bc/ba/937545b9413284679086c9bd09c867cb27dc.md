# À propos

[ABAP][abap] est un langage de programmation développé par SAP pour la création d'applications de gestion avec l'environnement de développement ABAP d'une ABAP Platform.

ABAP prend en charge les éléments suivants :

- Un modèle de programmation orienté objet, qui repose sur les classes et les interfaces d'ABAP Objects.
- Un modèle de programmation procédural, qui repose sur les modules fonctionnels et les sous-programmes.

Les deux modèles sont interopérables ; toutefois, sur Exercism, l'accent porte uniquement sur le modèle de programmation orienté objet.

Tu peux trouver plus d'informations dans la documentation du [parcours ABAP][docs].
