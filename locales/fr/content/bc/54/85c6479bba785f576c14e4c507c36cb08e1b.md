# Introduction

## Fonctions anonymes

Gleam a des fonctions de première classe, ce qui signifie que les fonctions sont des valeurs comme les autres : on peut les affecter à des variables, les passer en arguments et les renvoyer depuis d'autres fonctions.

Une fonction nommée définie dans un module peut être référencée par son nom.

```gleam
pub fn main() {
  // Assign the function to a variable
  let f = add_one
  
  // Invoke the function
  f(1) // -> 2
  f(2) // -> 3
}

fn add_one(x) {
  x + 1
}
```

Gleam dispose aussi de fonctions anonymes, qui se définissent à l'intérieur d'autres fonctions.

```gleam
// Define the function
let f = fn(x) { x + 1 }

// Invoke the function
f(1) // -> 2
f(2) // -> 3
```

Le type d'une fonction s'écrit avec une syntaxe semblable à celle des fonctions anonymes. Le type d'une fonction qui prend un `Int` et un `Float` et renvoie un `Int` s'écrit comme ceci :

```gleam
fn(Int, Float) -> Int
```

Les fonctions anonymes peuvent référencer des variables qui étaient dans leur portée au moment de leur définition, ce qui en fait des _closures_.

```gleam
let secret_number = 42

// This function always returns 42
fn() { secret_number }
```

La syntaxe de _capture de fonction_ offre un raccourci pratique pour créer des fonctions anonymes qui passent un seul argument à une fonction. Ces deux expressions sont équivalentes :

```gleam
// Anonymous function syntax
let f = fn(x) { my_function(1, 2, x) }

// Function capture syntax
let f = my_function(1, 2, _)
```
