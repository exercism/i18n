# Débloque les exercices

Le déblocage des exercices varie selon le type de parcours :

1. Parcours sans exercices d'apprentissage : tous les exercices d'entraînement sont déverrouillés dès le départ.
2. Parcours avec exercices d'apprentissage : termine les exercices d'apprentissage pour débloquer d'autres exercices d'apprentissage et d'entraînement.

## Mode apprentissage ou mode entraînement

Le fait d'exiger que les exercices d'apprentissage soient terminés pour débloquer d'autres exercices s'appelle le mode apprentissage (introduit avec Exercism 3.0).
Le mode apprentissage est le mode par défaut de tout utilisateur qui rejoint un parcours comportant des exercices d'apprentissage, mais aussi de tout utilisateur venant de l'ancien site.
Le mode entraînement est l'inverse : tous les exercices y sont déverrouillés dès le départ.

À noter que, que ce soit en mode entraînement ou en mode apprentissage, on peut demander du mentorat sur un exercice précis.

### Utilisateur de retour

Si tu es un utilisateur de retour et que tu as utilisé une version précédente d'Exercism, tu peux constater que des exercices qui étaient auparavant disponibles sont désormais verrouillés.
Même si on te recommande de rester en mode apprentissage et de résoudre les exercices d'apprentissage pour débloquer les autres exercices (chacun devrait te prendre environ 5 minutes à résoudre si tu maîtrises un langage), tu peux aussi passer du mode apprentissage au mode entraînement.

### Change de mode

Pour changer de mode, va sur la page du parcours que tu as rejoint, puis clique sur l'icône « ... » en haut à droite.
Ensuite, selon ton mode actuel, sélectionne soit _« Désactiver le mode apprentissage »_, soit _« Activer le mode apprentissage »_, et confirme que tu veux changer de mode.

À noter qu'il faut actuellement un certain temps avant que ton mode actuel soit indiqué sur ta page Parcours.
