# Introduction

Unison représente les valeurs vrai et faux avec le type `Boolean`. Il n'existe que deux valeurs : `true` et `false`.

```unison
trueVariable = true
falseVariable = false
```

On peut évaluer des expressions booléennes à l'aide des opérateurs et, représenté par `&&`, ou, représenté par `||`, et non, représenté par `not`.

```unison
trueVariable = true && true
falseVariable = true && false

trueVariable = false || true
falseVariable = false || false

trueVariable = not false
falseVariable = not true
```

Les expressions booléennes d'Unison permettent une évaluation en court-circuit : si le premier argument d'une expression `&&` vaut `false`, il n'y a aucune raison de continuer à évaluer le second argument. De même, si le premier argument d'une expression `||` vaut `true`, l'expression renvoie immédiatement `true`.

```unison
> false && (base.bug "oh no")
  ⧩
  false
```

```unison
> true || (base.bug "oh no")
  ⧩
  true
```
