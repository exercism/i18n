# Les _strings_

Une **chaîne de caractères** est un morceau de texte. Le type de Sather correspondant est `STR`, et une _string_ s'écrit entre guillemets doubles.

```sather
   composer : STR is
      return "Sibelius";
   end;
```

## Concatène des _strings_

L'opérateur `+` met deux _strings_ bout à bout.

```sather
"Jean" + " " + "Sibelius"      -- "Jean Sibelius"
```

Rien n'est placé entre elles, il faut donc demander un espace explicitement. Si on l'oublie, on obtient `"JeanSibelius"`.

## Quelle est sa longueur ?

`.size` donne le nombre de caractères que contient une _string_. C'est un nombre entier, donc son type est `INT`.

```sather
"Sibelius".size      -- 8
```

Il n'y a pas de parenthèses après `.size`, comme pour une routine qui ne prend aucun argument.

## Prends un morceau

`.head(n)` renvoie les `n` premiers caractères. `.tail(n)` renvoie les `n` derniers.

```sather
"Sibelius".head(3)   -- "Sib"
"Sibelius".tail(4)   -- "lius"
```

`head` compte depuis le début, `tail` compte depuis la fin. Toutes deux laissent la _string_ d'origine intacte et en renvoient une nouvelle.
