# Introduction

Une expression `switch` permet de mettre en correspondance une valeur avec un cas parmi un ensemble de modèles, puis de renvoyer la valeur associée ou d'effectuer l'action associée. L'association est indiquée par le symbole `=>`. De plus, chaque modèle peut comporter une garde de cas facultative, introduite par le mot-clé `when`. L'expression de cette garde de cas doit être vraie pour que ce « bras » du switch soit sélectionné. Les cas (aussi appelés _bras de switch_) sont évalués dans l'ordre du texte, et le processus est interrompu dès qu'une correspondance est trouvée, la valeur associée étant alors renvoyée.

```csharp
double xx = 42d;

string interesting = xx switch
{
    0 => "I suppose zero is interesting",
    3.14 when DateTime.Now.Day == 14 && DateTime.Now.Month == 3 => "Mmm pie!",
    3.14 => "π",
    42 => "a bit of a cliché",
    1729 => "only if you are a pure mathematician",
    _ => "not interesting"
};

// => interesting == "a bit of a cliché"
```
