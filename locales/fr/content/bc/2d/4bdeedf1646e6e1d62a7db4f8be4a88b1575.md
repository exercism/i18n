# Indices

## Général

- Il existe trois opérateurs booléens pour manipuler des valeurs booléennes : `not`, `&&` et `||`.
- On peut combiner plusieurs opérateurs dans une seule expression.

## 1. Définis si pac-man peut manger un fantôme

- La fonction doit renvoyer une valeur `Bool`.
- Tu peux utiliser l'opérateur booléen `&&` pour combiner les arguments et obtenir un résultat.

## 2. Définis si pac-man marque des points

- La fonction doit renvoyer une valeur `Bool`.
- Tu peux utiliser l'opérateur booléen `||` pour combiner les arguments et obtenir un résultat.

## 3. Définis si pac-man perd

- La fonction doit renvoyer une valeur `Bool`.
- Tu peux utiliser les opérateurs booléens `&&` et `not` pour combiner les arguments et obtenir un résultat.

## 4. Définis si pac-man gagne

- La fonction doit renvoyer une valeur `Bool`.
- Tu peux utiliser les opérateurs booléens `&&` et `not` pour combiner les arguments et le résultat de l'une des fonctions implémentées précédemment.
