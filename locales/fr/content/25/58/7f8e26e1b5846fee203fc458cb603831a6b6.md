# Instructions

Tu travailles avec une équipe de développement web pour maintenir le site web d'une équipe locale de basket-ball. L'équipe de développement web connaît moins bien Elixir et te demande une fonction capable d'extraire des données d'une série de _maps_ imbriquées, afin de faciliter un développement rapide.

## 1. Extrais des données d'une structure de _maps_ imbriquées

Implémente la fonction `extract_from_path/2` qui prend deux arguments :

- `data` : une structure de _maps_ imbriquées contenant des données sur l'équipe de basket-ball.
- `path` : une _string_ composée de clés séparées par des points, qui permet d'obtenir la valeur associée à la dernière clé.

Si la valeur ou la clé n'existe à aucun moment du chemin, la fonction doit renvoyer `nil`.

```elixir
data = %{
  "team_mascot" => %{
    "animal" => "bear",
    "actor" => %{
      "first_name" => "Noel"
    }
  }
}

BasketballWebsite.extract_from_path(data, "team_mascot.animal")
# => "bear"
BasketballWebsite.extract_from_path(data, "team_mascot.colors")
# => nil
```

Utilise l'_Access Behaviour_ pour implémenter cette fonction.

N'utilise aucune fonction des modules `Map` ou `Kernel` pour manipuler la structure de _maps_ imbriquées.

## 2. Réécris en utilisant les fonctions incluses

En relisant ton code, une personne de ton équipe te parle d'une fonction du module `Kernel` qui fait quelque chose de très similaire à ton implémentation.

Implémente `get_in_path/2` en utilisant cette fonction du module `Kernel`.

Les arguments attendus sont les mêmes que dans la partie 1.

```elixir
BasketballWebsite.get_in_path(data, "team_mascot.actor.first_name")
# => "Noel"
```
