# Introduction

## Variables d'instance

Les objets peuvent conserver leur propre état en définissant des _variables d'instance_.
Ces variables vivent à l'intérieur d'un objet et servent normalement à stocker un état interne.

Les variables d'instance commencent toujours par un `@`.
On peut créer une nouvelle variable d'instance en affectant une variable qui commence par un `@`.
Par exemple :

```ruby
class Repeater
  def hear(something)
    # Save what's been heard into a new instance variable called @heard
    @heard = something
  end

  def repeat
    # Return the value of the instance variable
    @heard
  end
end

repeater = Repeater.new
repeater.hear("Hello, friend!")
print repeater.repeat # Prints "Hello, friend!"
```

Les objets définissent généralement leur état initial dans une méthode `initialize`, qui est automatiquement appelée lorsqu'on appelle `new` sur une classe.

```ruby
class Airplane
  def initialize
    @wings = 2
  end

  def wings
    @wings
  end
end

plane = Airplane.new
plane.wings # returns 2
```

La méthode `initialize` peut aussi prendre des arguments, afin que chaque instance puisse démarrer avec un état personnalisé :

```ruby
class Suitcase
  def initialize(locked)
    @locked = locked
  end
end
```

C'est une bonne pratique de considérer les _variables d'instance_ comme privées vis-à-vis des lectures et des écritures externes.
On définit plutôt des méthodes pour lire et écrire leurs valeurs.
Par exemple :

```ruby
class Suitcase
  def initialize
    @locked = false
  end

  def locked? # Query methods should be named with a trailing `?`
    @locked
  end

  def lock! # Methods which mutate state should have trailing `!`
    @locked = true
  end
end

suitcase = Suitcase.new
suitcase.locked? # false
suitcase.lock!
suitcase.locked? # true
```

## Nil

[Nil][nil-dictionary] est un mot anglais qui signifie « rien » ou « zéro ».
En Ruby, `nil` sert à exprimer l'_absence_ d'un objet.
Dans d'autres langages de programmation, les valeurs `null` ou `none` peuvent jouer un rôle similaire.

```ruby
# I do not have a favorite color
favorite_color = nil
```

Ruby donne à toute variable d'instance la valeur par défaut `nil` lors de sa première utilisation, jusqu'à ce qu'une valeur lui soit affectée.

```ruby
print @favourite_color # prints nil
@favourite_color = "blue"
print @favourite_color # prints "blue"
```
