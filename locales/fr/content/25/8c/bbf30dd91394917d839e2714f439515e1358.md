# Tests

## Exécute les tests

Depuis le répertoire de l'exercice, exécute `exercism test` ou `eutest`.
Euphoria lance alors `t_<exercise>.e` sur ta solution.

## Lis la sortie

Au début d'un exercice, ton fichier de solution n'a pas de valeur de retour et plante à l'exécution.

```shell
C:\path\to\leap.ex:3
<0120>:: no value returned from function
end function
           ^

FAILURE: t_leap.e EUPHORIA error with status 1

Test results summary:
    FAIL: t_leap.e
Files (run: 1) (failed: 1) (0% success)
```

C'est normal.
Implémente la fonction, puis relance pour voir quels tests réussissent et lesquels échouent.

```shell
interpreting t_leap.e:
  passed: year not divisible by 4 in common year
  failed: year divisible by 2, not divisible by 4 in common year, expected: FALSE but got: TRUE
  failed: year divisible by 4, not divisible by 100 in leap year, expected: TRUE but got: FALSE
  ...
  9 tests run, 6 passed, 3 failed, 67% success
FAILURE: t_leap.e program died with status 1

Test results summary:
    FAIL: t_leap.e
Files (run: 1) (failed: 1) (0% success)
```

## Avance dans les tests progressivement

Une bonne façon de commencer est de commenter tous les tests sauf le premier dans `t_<exercise>.e`.

```euphoria
test_false("year not divisible by 4 in common year", leap(1800))
-- test_false("year divisible by 100 but not by 3 is still not a leap year", leap(1900))
-- test_false("year divisible by 2, not divisible by 4 in common year", leap(1970))
```

Traite-les un par un, en décommentant le test suivant dès que le test courant réussit.
Quand tous les tests réussissent, tu as terminé l'exercice.
