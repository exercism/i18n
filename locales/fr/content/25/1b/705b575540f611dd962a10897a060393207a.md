# À propos

Un [tuple](https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/tuples) est un regroupement _immuable_ de valeurs non nommées mais ordonnées.
Les tuples peuvent contenir n'importe quel type de données (ou plusieurs), y compris d'autres tuples.

Les tuples sont définis comme des valeurs séparées par des virgules entre les caractères `(` et `)` : `(<element_1>, ... , <element_n>)`.

```fsharp
("one", 2) // Tuple pair (2 values)
("one", 2, true) // Tuple triplet (3 values)
```

Seuls les tuples ayant la même longueur et les mêmes types (dans le même ordre) peuvent être comparés.
Les tuples ont une égalité structurelle, ce qui signifie qu'ils sont égaux _uniquement_ si toutes leurs valeurs sont égales.

```fsharp
(1, 2) = (1, 2) // Same length, same types, same values, same order
// => true

(1, 2) = (2, 1) // Same length, same types, same values, different order
// => false

(1, 2) = (1, "2") // Same length, different types
// compiler error

(1, 2) = (1, 2, 3) // Different length
// compiler error
```

Il y a [trois façons d'extraire des valeurs d'un tuple](https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/tuples#obtaining-individual-values) :

- Les fonctions `fst` et `snd`
- La déconstruction de tuple
- Le filtrage par motif

```fsharp
let person = ("Jordan", 170)

// Option 1: fst/snd
let name1 = fst person
let length1 = snd person

// Option 2: deconstruction
let (name2, length2) = person

// Option 3: pattern matching
match person with
| name3, length3 -> printf "%s: %d" name3 length3
```

~~~~exercism/note
Techniquement, on peut accéder à la valeur d'un tuple en utilisant ses propriétés `.Item1`, `.Item2`, ..., mais ce n'est pas recommandé et cela entraîne un avertissement du compilateur.
~~~~

## Points clés sur les tuples

Voici quelques points clés à connaître sur les tuples :

- Une instance particulière d'un type tuple est un objet unique, semblable à un tableau à deux éléments en C#, par exemple. Lorsqu'on les utilise avec des fonctions, ils comptent comme un seul paramètre. La seule exception est l'appel de code non F# avec plusieurs paramètres : dans ce cas, on passe un tuple et ses valeurs sont automatiquement extraites vers la valeur du paramètre correspondant.
- On ne peut pas donner de noms explicites aux types tuples. Le « nom » du type tuple est déterminé par la combinaison des types qui sont multipliés entre eux.
- La virgule est le symbole essentiel qui définit les tuples, et non les parenthèses. On peut définir des tuples sans les parenthèses, même si cela peut parfois prêter à confusion. En F#, si tu vois une virgule, elle fait probablement partie d'un tuple.
- Les tuples peuvent être utilisés comme arguments d'une fonction et comme valeur de retour d'une fonction.
