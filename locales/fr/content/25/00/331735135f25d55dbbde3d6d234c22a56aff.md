# À propos

L'essentiel à retenir sur les _strings_ en C# est qu'il s'agit d'objets immuables qui représentent du texte sous forme de suite de caractères Unicode (lettres, chiffres, ponctuation, etc.). On utilise des guillemets doubles pour définir une instance de `string` :

```csharp
string fruit = "Apple";
```

Pour manipuler une _string_, il suffit d'appeler l'une de ses [méthodes][methods] ou l'une de ses [propriétés][properties]. Comme la valeur d'une _string_ ne peut jamais changer une fois qu'elle a été définie, toutes les méthodes de manipulation de _string_ renvoient une nouvelle _string_.

Une _string_ est délimitée par des guillemets doubles (`"`). Certains caractères spéciaux nécessitent un [échappement][escaping] à l'aide de la barre oblique inverse (`\`). Une _string_ peut aussi être préfixée par l'arobase (`@`), ce qui en fait une [_string_ verbatim][verbatim] qui ignore les caractères échappés.

```csharp
string escaped = "c:\\test.txt";
string verbatim = @"c:\test.txt";
escaped == verbatim;
// => true
```

Si tu n'as besoin que d'une partie d'une _string_, tu peux utiliser la [méthode `Substring()`][substring] pour en extraire uniquement ce morceau :

```csharp
string sentence = "Frank chases the bus.";
string name = sentence.Substring(0, 5);
// => "Frank"
```

La [méthode `IndexOf`][indexof] permet de trouver l'indice de la première occurrence d'une `string` dans une `string`, et renvoie `-1` si la valeur indiquée est introuvable :

```csharp
"continuous-integration".IndexOf("integration")
// => 11

"continuous-integration".IndexOf("deployment")
// => -1
```

Enfin, il existe [de nombreuses façons de concaténer une _string_][concatenation]. La plus simple consiste à utiliser l'[opérateur `+`][plus-operator].

```csharp
string name = "Jane";
"Hello " + name + "!";
// => "Hello Jane!"
```

Pour toute mise en forme de _string_ plus complexe qu'une simple concaténation, l'[interpolation de _strings_][interpolation] est préférable. Pour activer l'interpolation dans une _string_, fais-la précéder du symbole dollar (`$`).

```csharp
string name = "Jane";
$"Hello {name}!";
// => "Hello Jane!"
```
