# Exécuter les tests

Pour compiler et exécuter les tests, lance simplement les commandes suivantes dans le répertoire de ton exercice :
```bash
$ ponyc
$ ./exercise-name
```

(Remplace `exercise-name` par le nom du répertoire de l'exercice)

Le binaire compilé exécute les tests dans son actor Main, donc lance simplement le binaire et regarde si tes tests sont réussis. Pony vérifie tout le code à la compilation, tu peux donc constater que tes tests ne compilent pas tant que tu n'as pas écrit le code requis. Tu peux mettre en commentaire les tests qui ne compilent pas en commençant chaque ligne par `//`. Ensuite, quand tu es prêt à travailler sur ce test, tu peux le décommenter.
