## Exécute les tests

1. Rends-toi à la racine du répertoire de ton exercice PHP, qui est `<EXERCISM_WORKSPACE>/php`.
   Pour trouver l'espace de travail Exercism, exécute

   ```shell
   exercism workspace
   ```

2. Installe [PHPUnit] si tu ne l'as pas déjà.
3. Exécute les tests avec :

   ```shell
   phpunit test_file.php
   ```

   Par exemple, pour exécuter les tests de l'exercice Hello World, tu lancerais :

   ```shell
   phpunit HelloWorldTest.php
   ```

[PHPUnit]: https://exercism.org/docs/tracks/php/installation#h-via-php-archive-phar
