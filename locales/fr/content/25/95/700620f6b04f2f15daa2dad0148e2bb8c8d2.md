# Introduction

## Les _slices_

Les _slices_ en Go sont similaires aux tableaux dans d'autres langages.
Ils contiennent plusieurs éléments d'un type spécifique (ou d'une interface).

Les _slices_ en Go sont basés sur les tableaux.
Les tableaux ont une taille fixe.
Un _slice_, quant à lui, est une vue flexible et de taille dynamique des éléments d'un tableau.

Un _slice_ s'écrit comme `[]T`, où `T` est le type des éléments du _slice_ :

```go
var empty []int                 // an empty slice
withData := []int{0,1,2,3,4,5}  // a slice pre-filled with some data
```

On peut obtenir ou définir un élément à un indice donné (en partant de zéro) en utilisant la notation entre crochets :

```go
withData[1] = 5
x := withData[1] // x is now 5
```

On peut créer un nouveau _slice_ à partir d'un _slice_ existant en récupérant une plage d'éléments.
Là encore, on utilise la notation entre crochets, mais en précisant un indice de début (inclus) et un indice de fin (exclu).
Si l'on ne précise pas d'indice de début, il vaut 0 par défaut.
Si l'on ne précise pas d'indice de fin, il vaut par défaut la longueur du _slice_.

```go
newSlice := withData[2:4]
// => []int{2,3}
newSlice := withData[:2]
// => []int{0,1}
newSlice := withData[2:]
// => []int{2,3,4,5}
newSlice := withData[:]
// => []int{0,1,2,3,4,5}
```

On peut ajouter des éléments à un _slice_ avec la fonction `append`.
Ci-dessous, on ajoute `4` et `2` au _slice_ `a`.

```go
a := []int{1, 3}
a = append(a, 4, 2)
// => []int{1,3,4,2}
```

`append` renvoie toujours un nouveau _slice_, et lorsqu'on veut simplement ajouter des éléments à un _slice_ existant, il est courant de le réaffecter à la variable de _slice_ que l'on passe en premier argument, comme ci-dessus.

`append` peut aussi servir à fusionner deux _slices_ :

```go
nextSlice := []int{100,101,102}
newSlice  := append(withData, nextSlice...)
// => []int{0,1,2,3,4,5,100,101,102}
```

## Fonctions variadiques

En général, les fonctions en Go n'acceptent qu'un nombre fixe d'arguments.
Il est toutefois possible d'écrire des fonctions variadiques en Go.

Une fonction variadique est une fonction qui accepte un nombre variable d'arguments.

Si le type du dernier paramètre dans la définition d'une fonction est précédé de points de suspension `...`, alors la fonction peut accepter n'importe quel nombre d'arguments pour ce paramètre.

```go
func find(a int, b ...int) {
    // ...
}
```

Dans la fonction ci-dessus, le paramètre `b` est variadique et on peut passer 0 argument ou plus à `b`.

```go
find(5, 6)
find(5, 6, 7)
find(5)
```

~~~~exercism/caution
Le paramètre variadique doit être le dernier paramètre de la fonction.
~~~~

Les fonctions variadiques fonctionnent en convertissant le nombre variable d'arguments en un _slice_ du type du paramètre variadique.

Voici un exemple d'implémentation d'une fonction variadique.

```go
func find(num int, nums ...int) {
    fmt.Printf("type of nums is %T\n", nums)

    for i, v := range nums {
        if v == num {
            fmt.Println(num, "found at index", i, "in", nums)
            return
        }
    }

    fmt.Println(num, "not found in ", nums)
}

func main() {
    find(89, 90, 91, 95)
    // =>
    // type of nums is []int
    // 89 not found in  [90 91 95]

    find(45, 56, 67, 45, 90, 109)
    // =>
    // type of nums is []int
    // 45 found at index 2 in [56 67 45 90 109]

    find(87)
    // =>
    // type of nums is []int
    // 87 not found in  []
}
```

À la ligne `find(89, 90, 91, 95)` du programme ci-dessus, les arguments en nombre variable passés à la fonction find sont `90`, `91` et `95`.
La fonction `find` attend un paramètre int variadique après `num`.
Par conséquent, ces trois arguments seront convertis par le compilateur en un _slice_ de type `int`, `[]int{90, 91, 95}`, puis passés à la fonction find sous le nom `nums`.

Parfois, on a déjà un _slice_ et on veut le passer à une fonction variadique.
On y parvient en passant le _slice_ suivi de `...`.
Cela indique au compilateur d'utiliser le _slice_ tel quel à l'intérieur de la fonction variadique.
L'étape décrite ci-dessus, où un _slice_ est créé, est simplement omise dans ce cas.

```go
list := []int{1, 2, 3}
find(1, list...) // "find" defined as shown above
```
