# Instructions

Tu tiens le compte quotidien du nombre d'oiseaux qui visitent ton jardin. Les données sont stockées dans un tableau d'entiers, avec **le compte du jour en premier**.

## 1. Le compte du jour

Définis `today` pour qu'elle récupère un tableau de comptes quotidiens depuis la pile et renvoie le compte du jour, ou `f` si le tableau est vide.

```factor
{ 2 5 1 } today .
! => 2

{ } today .
! => f
```

## 2. Incrémente le compte du jour

Définis `increment-day-count` pour qu'elle renvoie un nouveau tableau où le compte du jour est augmenté de un. Si l'entrée est vide, renvoie `{ 1 }`.

```factor
{ 4 0 2 } increment-day-count .
! => { 5 0 2 }

{ } increment-day-count .
! => { 1 }
```

## 3. Y a-t-il eu un jour sans oiseau ?

Définis `has-day-without-birds?` pour qu'elle renvoie `t` si au moins un jour a enregistré zéro oiseau, sinon `f`.

**Utilise la récursion** plutôt que `any?` ou d'autres mots de séquence d'ordre supérieur.

```factor
{ 2 0 4 } has-day-without-birds? .   ! => t
{ 3 8 1 5 } has-day-without-birds? . ! => f
```

## 4. Le total d'oiseaux depuis le début

Définis `total` pour qu'elle renvoie la somme de tous les comptes.

**Utilise la récursion** plutôt que `sum`.

```factor
{ 4 0 9 0 5 } total .
! => 18
```

## 5. Les jours chargés

Un jour chargé est un jour avec cinq oiseaux ou plus. Définis `busy-days` pour qu'elle renvoie le nombre de jours chargés.

**Utilise la récursion** plutôt que `count`.

```factor
{ 4 5 0 0 6 } busy-days .
! => 2
```
