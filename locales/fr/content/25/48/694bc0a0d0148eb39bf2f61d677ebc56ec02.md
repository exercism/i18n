# Instructions

Tu fais partie du service d'assistance informatique, et tu veux améliorer le système de tickets pour le rendre plus efficace et fournir des statistiques à ta hiérarchie.

Un ticket a un statut (nouveau, en cours...), un créateur (identifié par un nom d'utilisateur et un identifiant d'employé), peut être affecté à un employé de l'informatique et contient un historique de commentaires.

Voici quatre tâches qui vont améliorer le système de tickets actuel.

## 1. Détecte les commentaires vides

Les commentaires vides encombrent l'interface et n'apportent aucune information ; tu veux les filtrer.

Définis une fonction auxiliaire `emptyComment` qui prend une paire utilisateur/commentaire et renvoie `True` pour les commentaires vides.

Utilise la déstructuration pour extraire l'utilisateur et le commentaire directement dans l'argument de la fonction. Ignore l'utilisateur, car tu n'as pas besoin de cette information.

```elm
emptyComment ( User "Alice", "" )
-- => True
```

## 2. Compte le nombre de commentaires du créateur

Ta hiérarchie veut des statistiques sur l'implication des utilisateurs dans le processus de traitement des tickets. 
Elle te demande de vérifier combien de commentaires sont ajoutés par le créateur du ticket.

Définis `numberOfCreatorComments` qui prend un ticket et renvoie le nombre de commentaires ajoutés par le créateur du ticket.

Utilise la déstructuration dans l'argument de la fonction pour extraire l'enregistrement du type `Ticket` en même temps que les champs dont tu as besoin dans cet enregistrement. 
Ensuite, déstructure `createdBy` dans une liaison `let` pour pouvoir compter les commentaires pertinents.
Utilise les fonctions de `List` pour faire le comptage et la déstructuration dans l'argument d'une fonction anonyme pour séparer la paire utilisateur/commentaire.

```elm
numberOfCreatorComments
numberOfCreatorComments
    (Ticket
        { status = Closed
        , createdBy = ( User "Chiaki", 1 )
        , assignedTo = Nothing
        , comments = [ ( User "Chiaki", "Never mind, fixed it." ) ]
        }
    )
-- => 1
```

## 3. Détecte les tickets affectés à l'équipe de développement

Certains tickets doivent être escaladés à Alice, Bob ou Charlie de l'équipe de développement.
Il est important de garder un œil sur eux pour s'assurer qu'ils progressent.

Définis une fonction auxiliaire `assignedToDevTeam` qui vérifie si un ticket est affecté à l'un des membres de l'équipe de développement.

Utilise la déstructuration dans l'argument de la fonction pour extraire l'enregistrement du type `Ticket` ainsi que le champ dont tu as besoin.
Ensuite, utilise une seule instruction `case` pour vérifier si le ticket est affecté à Alice, Bob ou Charlie, en utilisant le filtrage par motif récursif pour extraire leurs noms d'utilisateur et le filtrage par motif littéral pour les reconnaître. 

```elm
assignedToDevTeam
    (Ticket
        { status = InProgress
        , createdBy = ( User "Bill", 2 )
        , assignedTo = Just (User "Alice")
        , comments = [ ( User "Bill", "What's an 'undefined'?" ) ]
        }
    )
-- => True
```

## 4. Affecte les tickets aux employés de l'informatique

Il arrive qu'un ensemble de tickets doive être réaffecté à d'autres employés de l'informatique.

Définis une fonction `assignTicketTo` pour t'aider à le faire. La fonction reçoit deux arguments : un utilisateur à qui affecter le ticket et un ticket. 
Si le statut du ticket est `New`, affecte-le au nouvel utilisateur et change le statut pour `InProgress`. 
Pour les autres statuts, réaffecte simplement le ticket aux nouveaux utilisateurs, sauf pour les tickets dont le statut est `Archived`, qui ne doivent pas être modifiés du tout.

Utilise la déstructuration dans l'argument de la fonction pour extraire l'enregistrement du type `Ticket` ainsi que le champ dont tu as besoin, et utilise aussi le mot-clé `as` pour capturer l'enregistrement entier tel quel. 
Utilise une seule instruction `case` pour filtrer par motif sur le statut et renvoyer le ticket approprié, créé en modifiant l'enregistrement d'origine que tu as capturé avec le mot-clé `as`.

```elm
assignTicketTo (User "Danny")
    (Ticket
        { status = New
        , createdBy = ( User "Jesse", 3 )
        , assignedTo = Just (User "Alice")
        , comments = [ ( User "Jesse", "I've been waiting for 6 months!!" ) ]
        }
    )
-- => Ticket
```
