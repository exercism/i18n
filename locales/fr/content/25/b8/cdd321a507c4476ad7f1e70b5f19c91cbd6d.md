# Introduction

## Les tableaux

En PHP, les tableaux sont des tableaux associatifs ordonnés.
Un tableau associatif est une structure de données qui associe une clé à une valeur.
Les tableaux sont polyvalents et peuvent être traités comme un tableau linéaire (comme en `C` ou en `Java`), une liste [vecteur], une table de hachage, un dictionnaire, une collection, une pile ou une file.

Une clé est facultative, mais si elle est précisée, elle doit être soit un `int`, soit un `string`.
Lorsqu'aucune clé n'est fournie, PHP utilise par défaut des clés entières dans l'ordre croissant, à partir de `0`.

```php
$no_keys = ["my", "first", "array"];
$integer_keys = [0 => "my", 1 => "first", 2 => "array"];

$no_keys == $integer_keys // => equal returns true
$no_keys === $integer_keys // => strictly equal returns true
```

Un tableau peut stocker des valeurs de tous les types.
Chaque valeur peut avoir un type différent.

### Utilise les tableaux

Les tableaux peuvent être déclarés sous forme de littéral (écrit dans le code, comme ci-dessus) ou créés et manipulés à l'aide de fonctions.
On accède aux valeurs, on les affecte et on les ajoute à l'aide de l'opérateur d'indice :

```php
$prime_numbers = [2, 3, 5, 6];

$prime_numbers[3] = 7; // replace 6 with 7

$prime_numbers[] = 11; // array now contains [2, 3, 5, 7, 11]
```

## Les arguments de longueur variable

On peut déclarer les arguments d'une fonction de telle sorte qu'elle puisse prendre un nombre quelconque d'arguments :

```php
<?php

function actOnItems(...$items) {
  // $items is an array containing 0 or more values
  // used to call the function.
}

actOnItems(1, 2, 3, 4); // $items => [1, 2, 3, 4]
```
