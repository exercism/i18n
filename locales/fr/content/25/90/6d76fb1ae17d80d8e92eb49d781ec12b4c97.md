# Indices

## Général

- La fonction `delivery_date()` prend deux arguments de type `String` et renvoie un `String`.
- Toutes les chaînes de date sont au format [ISO 8601][iso], qui est la représentation par défaut de Julia.
- La documentation utile pour le module `Dates` inclut :
  - Le [parcours d'apprentissage][dates-times] d'Exercism.
  - Le [manuel de Julia][Dates].
  - Le [Wikibook][Wikibook].
- Au minimum, il te faudra te familiariser avec les constructeurs de [DateTime][datetime] et avec l'addition ou la soustraction de [Periods][period].
- Parmi les fonctions utiles, on trouve [`dayofweek()`][dayofweek] et, éventuellement, [`lastdayofmonth()`][lastdayofmonth] ou [`lastdayofquarter()`][lastdayofquarter].
- Pour extraire des nombres entiers à partir de chaînes de caractères, la fonction [`parse()`][parse] sera importante.
- Les fonctions [`tonext()`][tonext] et [`toprev()`][toprev] pourraient être utiles dans une approche qui fait appel à des fonctions d'ordre supérieur.
