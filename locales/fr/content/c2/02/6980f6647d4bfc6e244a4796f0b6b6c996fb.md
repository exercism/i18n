# Installation

On va utiliser *PolyML* comme implémentation de Standard ML.

Si tu utilises Windows, tu peux télécharger un programme d'installation depuis [https://github.com/polyml/polyml/releases](https://github.com/polyml/polyml/releases).
Tu trouveras des instructions générales pour Linux/OS X/Free BSD sur [https://github.com/polyml/polyml#readme](https://github.com/polyml/polyml#readme).

Si tu veux installer depuis les sources, la procédure est plutôt simple :

```sh
$ git clone https://github.com/polyml/polyml.git
$ cd polyml
$ ./configure
```

Si tu veux l'installer à un emplacement personnalisé, par exemple `$HOME/.local` :

```sh
$ ./configure --prefix=$HOME/.local
```

Dernière étape :

```sh
$ make compiler
$ make install
```

Vérifie que l'installation s'est bien déroulée :

```sh
$ poly
```

Si tu vois l'interprète, tu es prêt !
Sinon, il te faudra probablement ajouter `$HOME/.local/bin` (ou `<you prefix>/bin`) à ton `$PATH`.
