# Introduction

Une [`string`][ref-string] en Kotlin est une séquence immuable de caractères Unicode.

[`Immutable`][wiki-immutable] signifie que toute opération sur une _string_ doit renvoyer une nouvelle _string_ : la _string_ d'origine ne peut jamais changer.

[`Unicode`][wiki-unicode] signifie que la plupart des systèmes d'écriture du monde peuvent être représentés, mais (contrairement à des langages plus anciens comme le C) il n'existe pas de correspondance 1:1 entre les caractères et les octets.

Une _string_ est généralement entourée de guillemets doubles `" "`.

Certains caractères doivent être échappés : `\'`, `\\`, ainsi que les caractères non imprimables habituels comme `\t` (tabulation) et `\n` (saut de ligne).

```kotlin
val s = "Escape apostrophe \' and backslash \\."
// Escape apostrophe ' and backslash \.
```

Les _strings_ multilignes sont entourées de 3 guillemets doubles et peuvent contenir n'importe quel texte (aucun échappement n'est nécessaire).

```kotlin
val multi = """I'm a
    multi-line
    string with special characters \ \t """
//I'm a
//    multi-line
//    string with special characters  \ \t 
```

Utilise [trimIndent][trimIndent-doc] pour supprimer l'indentation commune des lignes.
C'est utile pour formater la _string_ :

```kotlin
val multi = """
    I'm a
      multi-line
    string""".trimIndent()

//I'm a
//  multi-line
//string
```

Sinon, [trimMargin][trimMargin-doc] permet de spécifier un délimiteur.
Chaque ligne de la `String` commence alors après le délimiteur.
Le délimiteur vaut `|` par défaut, mais tu peux en spécifier un autre en paramètre.
Par exemple :

```kotlin
val multi = """
    |I'm a
    |  multi-line
    |string""".trimMargin()

//I'm a
//  multi-line
//string

val multi2 = """
    start>I'm a
    start>  multi-line
    start>string""".trimMargin("start>")

//I'm a
//  multi-line
//string
```

Les _strings_ peuvent être concaténées avec `+`, mais mieux vaut réserver cela aux cas courts et simples.
Il existe d'autres options, souvent meilleures.

## Les _templates_ de _string_

Il s'agit de ce que certains autres langages appellent « interpolation ».

Si une _string_ contient un signe dollar `$` suivi d'un identifiant, ou contient des accolades (`{expression}`) autour d'une expression, ceux-ci sont remplacés respectivement par la valeur ou le résultat de l'expression.

```kotlin
val x = 42
val st = "x is $x, x squared is {x * x}"
// x is 42, x squared is 1764
```

Les accolades `{ }` sont nécessaires autour des expressions quand l'analyse serait sinon ambiguë.

En général, utiliser des _templates_ de _string_ est un moyen plus efficace et plus idiomatique de combiner des _strings_ que d'utiliser `+`.

## Les fonctions de _string_

Kotlin fournit _de nombreuses_ [`functions`][ref-string-functions] pour manipuler les _strings_.

Pour l'essentiel, ce sont des [`extensions functions`][ref-extensions] plutôt que des membres de la classe `String`, même si cela a peu d'incidence sur la façon dont on les utilise.

~~~~exercism/note
Les pages de [documentation][ref-string-functions] de Kotlin, assez complexes, masquent les fonctions d'extension dans la vue par défaut.
Pense à cliquer sur `Members & Extensions` pour déplier cette section.

[ref-string-functions]: https://kotlinlang.org/api/core/kotlin-stdlib/kotlin/-string/
~~~~

Les exemples suivants ne montrent qu'une petite sélection de ce qui est disponible :

```kotlin
val str = "Hello World!"

str.length              // => 12 (a property, not a function)
str.elementAt(6)        // => W
str.elementAtOrNull(20) // => null (index out of range)
str.substring(6, 11)    // => "World"
str.substringAfter(" ") // => "World!"

str.lowercase()         // => "hello world!"
str.uppercase()         // => "HELLO WORLD!"

str.startsWith("Hel")   // => true
str.endsWith("xyz")     // => false
str.indexOf("0")        // => 4

str.toCharArray()       // => [H, e, l, l, o,  , W, o, r, l, d, !]
"42".toInt() + 1        // => 43  (parsing; see also toFloat)

"Howdy!  ".trim()       // => "Howdy"
```
