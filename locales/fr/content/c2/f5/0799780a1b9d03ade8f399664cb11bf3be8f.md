# Introduction

Felt est l'un des types scalaires de Cairo, au même titre que les nombres entiers et les booléens, et il est représenté par le mot-clé `felt252`.
`felt252` est un type de données fondamental de Cairo, dont tous les autres types de données sont dérivés.
`felt252` peut aussi servir à stocker des [représentations de chaînes de caractères courtes][felts] d'une longueur maximale de 31 caractères.

Par exemple :

```rust
    let felt: felt252 = 100;
    let felt_as_str: felt252 = 'Hello Starknet!';

    let _felt = felt + felt_as_str;
```

[felts]: https://starknet-by-example.voyager.online/getting-started/basics/bytearrays-strings.html#short-strings
