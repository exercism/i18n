# Introduction

Elixir est un langage à typage dynamique, ce qui signifie qu'il ne vérifie pas les types à la compilation. On peut néanmoins se servir des spécifications de type comme d'une forme de documentation.

Une spécification de type peut être ajoutée à une fonction à l'aide de l'attribut de module `@spec`, juste avant la définition de la fonction. `@spec` est suivi du nom de la fonction et de la liste des types de tous ses arguments, entre parenthèses et séparés par des virgules. Le type de la valeur de retour est séparé des arguments de la fonction par un double deux-points `::`.

```elixir
@spec longer_than?(String.t(), non_neg_integer()) :: boolean()
def longer_than?(string, length), do: String.length(string) > length
```

## Types

Les types les plus courants sont les suivants :

- booléens : `boolean()`
- _strings_ : `String.t()`
- nombres : `integer()`, `non_neg_integer()`, `pos_integer()`, `float()`
- tableaux : `list()`
- une valeur de n'importe quel type : `any()`

Certains types peuvent aussi être paramétrés : par exemple, `list(integer)` est un tableau d'entiers.

On peut également utiliser des valeurs littérales comme types.

Une union de types peut s'écrire à l'aide de la barre verticale `|`. Par exemple, `integer() | :error` signifie soit un entier, soit le littéral d'atome `:error`.

La liste complète de tous les types se trouve dans la [section « Typespecs » de la documentation officielle][types].

## Nomme les arguments

On peut aussi nommer les arguments dans la spécification de type, ce qui est utile pour distinguer plusieurs arguments du même type. Le nom de l'argument, suivi d'un double deux-points, se place avant le type de l'argument.

```elixir
@spec to_hex({hue :: integer, saturation :: integer, lightness :: integer}) :: String.t()
```

## Types personnalisés

Les spécifications de type ne se limitent pas aux types intégrés. On peut définir des types personnalisés à l'aide de l'attribut de module `@type`. La définition d'un type personnalisé commence par le nom du type, suivi d'un double deux-points, puis du type lui-même.

```elixir
@type color :: {hue :: integer, saturation :: integer, lightness :: integer}

@spec to_hex(color()) :: String.t()
```

Un type personnalisé peut être utilisé depuis le module dans lequel il est défini, ou depuis un autre module.
