# Installation

Euphoria est disponible au téléchargement pour différentes plateformes sur [OpenEuphoria.org][Download].

Euphoria v4.1 peut être installé sous 
 * [Windows][Windows Installation], 
 * [Linux et FreeBSD][Linux and FreeBSD Installation] et 
 * [MacOS][MacOS Installation]

Euphoria v3.1.1 pour [Windows (Vista/XP/NT/2000/ME/98/95) et DOS][DOS Installation] est également disponible

Après l'installation, l'arborescence des répertoires doit correspondre à celle décrite dans la documentation [Post Install][Post Install].

Enfin, des instructions sont disponibles pour ajuster le [fichier de configuration d'Euphoria][Euphoria Configuration].
