# Instructions

Tu crées un petit jeu en ligne où un ami doit deviner un nombre secret. Tu veux lui donner un retour, mais sans dévoiler la réponse à travers une proposition. Tu dois donc concevoir une fonction qui produit des réponses différentes selon la façon dont la proposition se situe par rapport au nombre secret.

| Condition                                                     | Réponse        |
| ------------------------------------------------------------- | -------------- |
| Quand la proposition correspond au nombre secret              | "Correct"      |
| Quand la proposition vaut un de plus ou un de moins que le nombre secret | "So close"     |
| Quand la proposition est supérieure au nombre secret          | "Too high"     |
| Quand la proposition est inférieure au nombre secret          | "Too low"      |
| Quand aucune proposition n'est faite                          | "Make a guess" |

Toutes les propositions et tous les nombres secrets sont des nombres entiers.

## 1. Produis la réponse quand la proposition correspond au nombre secret

Implémente la fonction `compare/2` qui prend deux arguments, `secret_number` et `guess`, tous deux des nombres entiers.

```elixir
GuessingGame.compare(5, 5)
# => "Correct"
```

## 2. Produis la réponse quand la proposition est supérieure au nombre secret

Modifie la fonction `compare` pour qu'elle réponde aux propositions supérieures au nombre secret.

```elixir
GuessingGame.compare(5, 8)
# => "Too high"
```

## 3. Produis la réponse quand la proposition est inférieure au nombre secret

Modifie la fonction `compare` pour qu'elle réponde aux propositions inférieures au nombre secret.

```elixir
GuessingGame.compare(5, 2)
# => "Too low"
```

## 4. Produis les réponses quand la proposition vaut un de plus ou un de moins que le nombre secret

Modifie la fonction `compare` pour qu'elle réponde aux propositions proches du nombre secret.

```elixir
GuessingGame.compare(5, 6)
# => "So close"
GuessingGame.compare(5, 4)
# => "So close"
```

## 5. Produis la réponse quand il n'y a pas de proposition

Modifie la fonction `compare` pour qu'elle réponde à l'absence de proposition.

```elixir
GuessingGame.compare(5)
# => "Make a guess"

GuessingGame.compare(5, :no_guess)
# => "Make a guess"
```
