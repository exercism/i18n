# Introduction

Une fonction permet de regrouper du code en une unité réutilisable.
Elle se compose du mot-clé `func`, du nom de la fonction et d'une liste, séparée par des virgules, de zéro ou plusieurs paramètres et types entre parenthèses.

## Paramètres de fonction

Tous les paramètres doivent avoir un type explicite ; il n'y a pas d'inférence de type pour les paramètres.
Les paramètres n'ont pas de valeur par défaut, donc tous les paramètres d'une fonction sont obligatoires.

```go
import "fmt"

// No parameters
func PrintHello() {
    fmt.Println("Hello")
}

// One parameter
func PrintHelloName(name string) {
  fmt.Println("Hello " + name)
}
```

Les paramètres de même type peuvent être déclarés ensemble, suivis d'une seule déclaration de type.

```go
import "fmt"

func PrintGreetingName(greeting, name string) {
  fmt.Println(greeting + " " + name)
}
```

## Paramètres et arguments

Voyons rapidement deux termes souvent confondus : `parameters` et `arguments`.
Les paramètres d'une fonction sont les noms définis dans la signature de la fonction, comme `greeting` et `name` dans la fonction `PrintGreetingName` ci-dessus.
Les arguments d'une fonction sont les valeurs concrètes transmises aux paramètres de la fonction lorsqu'on appelle la fonction.
Par exemple, dans l'exemple ci-dessous, `"Hello"` et `"Katrina"` sont les arguments transmis aux paramètres `greeting` et `name` :

```go
PrintGreetingName("Hello", "Katrina")
```

## Valeurs de retour

Les paramètres de la fonction sont suivis de zéro ou plusieurs valeurs de retour, qui doivent elles aussi avoir un type explicite.
Une seule valeur de retour s'écrit sans parenthèses, plusieurs valeurs de retour sont encadrées par des parenthèses.
Les valeurs sont renvoyées au code appelant par les fonctions grâce au mot-clé `return`.
Une fonction peut contenir plusieurs instructions `return`.
L'exécution de la fonction se termine dès qu'elle atteint l'une de ces instructions `return`.
Si une fonction doit renvoyer plusieurs valeurs, celles-ci sont séparées par des virgules.

```go
func Hello(name string) string {
  return "Hello " + name
}

func HelloAndGoodbye(name string) (string, string) {
  return "Hello " + name, "Goodbye " + name
}
```

## Comment appeler une fonction

Pour appeler une fonction, on écrit le nom de la fonction et on passe un argument pour chacun de ses paramètres, entre parenthèses.

```go
import "fmt"

// No parameters, no return value
func PrintHello() {
    fmt.Println("Hello")
}
// Called like this:
PrintHello()

// One parameter, one return value
func Hello(name string) string {
  return "Hello " + name
}
// Called like this:
greeting := Hello("Dave")

// Multiple parameters, multiple return values
func SumAndMultiply(a, b int) (int, int) {
    return a+b, a*b
}
// Called like this:
aplusb, atimesb := SumAndMultiply(a, b)
```

## Valeurs de retour nommées et retour nu

Comme les paramètres, les valeurs de retour peuvent être nommées, si on le souhaite.
Si des valeurs de retour nommées sont utilisées, une instruction `return` sans argument renvoie ces valeurs.
C'est ce qu'on appelle un retour « nu ».

```go
func SumAndMultiplyThenMinus(a, b, c int) (sum, mult int) {
    sum, mult = a+b, a*b
    sum -= c
    mult -= c
    return
}
```
