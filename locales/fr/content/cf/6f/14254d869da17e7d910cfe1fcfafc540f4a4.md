# Introduction

L'un des objectifs centraux de Julia est de pouvoir effectuer des calculs sur des données numériques, rapidement et efficacement.
_Beaucoup_ de données numériques.

En général, ces données sont stockées dans des tableaux (ou dans un type apparenté), ce qui permet de dire que les tableaux sont au cœur du langage Julia.

La taille d'un tableau peut être arbitraire (seules les contraintes de mémoire de ta machine s'appliquent) et il peut avoir un nombre arbitraire de dimensions.

Ce concept d'introduction se concentre sur les bases des tableaux à une dimension, que l'on appelle des vecteurs.

## Crée des vecteurs

En Julia, un vecteur est une séquence ordonnée de valeurs auxquelles on accède par un indice.

La façon la plus simple de créer un vecteur est de lister les valeurs entre crochets :

```julia-repl
julia> num_vec = [1, 4, 9]
3-element Vector{Int64}:
 1
 4
 9

julia> str_vec = ["arrays", "are", "important"]
3-element Vector{String}:
 "arrays"
 "are"
 "important"
```

Le type du vecteur correspond au type de chaque élément.

_Et donc les vecteurs doivent être homogènes (tous les éléments du même type) ?_

Dans une certaine mesure, oui, et il est recommandé de viser cela si tu veux les meilleures performances.
Cependant, Julia peut contourner cette limitation (quand c'est nécessaire) en utilisant le type `Any` :

```julia-repl
julia> mixed_vector = [1, "str", 'c']
3-element Vector{Any}:
 1
  "str"
  'c': ASCII/Unicode U+0063 (category Ll: Letter, lowercase)
```

Lorsque l'on crée un vecteur vide, Julia utilise par défaut le type d'élément `Any`, mais on peut le préciser en annotant le tableau vide avec le type d'élément souhaité.

```julia-repl
julia> empty_vec = []
Any[]

julia> empty_int_vec = Int64[]
Int64[]
```

# Indexation

Lis et retiens bien cette règle :

- ***Par défaut, l'indexation en Julia commence à 1, et non à 0***.

Cela ne surprendra personne ayant déjà utilisé d'autres langages de _data science_ (R, Matlab, Fortran...), mais peut sembler choquant aux informaticiens venus des langages de la famille du C.

À part cela, les indices fonctionnent comme tu peux l'imaginer : il suffit de les mettre entre crochets :

```julia
squares = [0, 1, 4, 9, 16]
squares[1]  # 0
squares[3]  # 4
squares[begin]  # 0 ("begin" is synonym for 1)
squares[end]  # 16 ("end" is synonym for length(squares))
```

Remarque la commodité de l'indexation avec `end` (très utile) et `begin` (probablement moins).

Les programmeurs Python se demandent peut-être ce qu'il en est des indices négatifs.
Mauvaise idée : ils ne font pas partie de Julia et déclencheront une `BoundsError`, comme n'importe quel indice inférieur à 1 ou supérieur à `length(squares)`.

## Opérations sur les vecteurs

Les vecteurs en Julia sont _mutables_ : on peut modifier le contenu de chaque cellule.

```julia-repl
julia> vals = [1, 3, 5, 7]
4-element Vector{Int64}:
 1
 3
 5
 7

julia> vals[2] = 4  # reassign the value of this element
4

# Only the value at position 2 changes:
julia> vals
4-element Vector{Int64}:
 1
 4
 5
 7
```

De nombreuses fonctions permettent de manipuler les vecteurs, même si la documentation de Julia les généralise sous le terme de « collections » plutôt que de vecteurs.

Remarque que, par convention, les fonctions qui mutent leur entrée ont un `!` dans leur nom.
Le compilateur ne l'imposera pas, mais c'est une convention très _forte_ dans le monde Julia.

Voici quelques-unes des fonctions utiles :

- Pour ajouter des valeurs à la fin du vecteur, utilise `push!()`.
- Pour supprimer la dernière valeur, utilise `pop!()`.
- Pour agir sur le début du vecteur, les fonctions correspondantes sont `pushfirst!()` et `popfirst!()`.
- Pour insérer ou supprimer un élément à n'importe quelle position, il y a `insert!()` et `deleteat!()`.

```julia-repl
julia> vals = [1, 3]
2-element Vector{Int64}:
 1
 3

julia> push!(vals, 5, 6)  # can add multiple values
4-element Vector{Int64}:
 1
 3
 5
 6

julia> pop!(vals)  # mutates vals, return popped value
6

julia> vals
3-element Vector{Int64}:
 1
 3
 5
```
