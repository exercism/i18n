# Introduction

## Fonctions à plusieurs clauses

Elixir facilite la mise en œuvre du **principe ouvert/fermé** en permettant aux fonctions d'avoir plusieurs clauses. Ainsi, au lieu d'étaler une logique de contrôle « en dur », c'est-à-dire une logique qui fige les valeurs dans le code plutôt que de les rendre modifiables à tout moment, on peut écrire des fonctions ciblées auxquelles il est facile d'ajouter ou de retirer un comportement.

Elixir propose les _clauses de fonction multiples_ et les _gardes_ pour écrire :

```elixir
def number(n) when n == 7 do
  "Awesome, that's my favorite"
end

def number(_n) do
  "That's not my favorite"
end
```

À l'exécution, Elixir teste, du haut vers le bas du fichier source, la clause de fonction à invoquer.

Les variables inutilisées doivent être préfixées par un _underscore_.

## Gardes

Les gardes servent à empêcher Elixir d'appeler une fonction selon le résultat de l'évaluation des arguments par les fonctions de garde. Une garde commence par le mot-clé `when`, suivi d'une expression booléenne. Les fonctions de garde sont des fonctions spéciales qui :

- doivent être pures et ne modifier aucun état global ;
- doivent renvoyer strictement `true` ou `false`.

Tu trouveras une liste des gardes courantes dans la [documentation d'Elixir][kernel-guards]. Elle comprend des vérifications de type, de l'arithmétique de base, des comparaisons et des opérateurs strictement booléens.

## Arguments par défaut

Les fonctions peuvent déclarer des valeurs par défaut pour un ou plusieurs arguments. Prenons cette fonction :

```elixir
def number(n \\ 13), do: "That's not my favorite"
```

À la compilation, Elixir crée une définition de fonction pour `number/0` (sans argument) et `number/1` (avec un argument).

Si plusieurs arguments ont des valeurs par défaut, celles-ci sont appliquées à la fonction de gauche à droite pour combler les arguments manquants.

Si la fonction comporte plusieurs clauses, les arguments par défaut doivent être définis dans un en-tête de fonction (une fonction sans corps) avant les clauses de la fonction :

```elixir
def number(n \\ 13)
def number(n) when n < 10, do: "Dream bigger!"
def number(n) when n > 100, do: "Not that big..."
```

[kernel-guards]: https://hexdocs.pm/elixir/Kernel.html#guards
