# Introduction

Dans cet exercice, tu dois exécuter de la logique de manière conditionnelle. En C#, la façon la plus courante de faire cela est d'utiliser une instruction `if/else` :

```csharp
int x = 6;

if (x == 5)
{
    // Execute logic if x equals 5
}
else if (x > 7)
{
    // Execute logic if x greater than 7
}
else
{
    // Execute logic in all other cases
}
```

La condition d'une instruction `if` doit être de type `bool`. C# ne connaît pas la notion de valeurs _truthy_.
