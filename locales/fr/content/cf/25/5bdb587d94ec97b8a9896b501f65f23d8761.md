# Méthodes de chaîne de caractères

`String` possède plusieurs méthodes qui permettent de manipuler des _strings_.  
Ces méthodes s'appellent sur la _string_ elle-même et sont souvent enchaînées pour effectuer plusieurs opérations.

Voici une liste de quelques-unes des méthodes les plus courantes.
Consulte la [documentation de l'API de `String`][string-api] pour obtenir la liste complète des méthodes.

## String#upcase & String#downcase

La méthode [`upcase`][upcase] renvoie une nouvelle _string_ dont tous les caractères sont convertis en majuscules.

```crystal
"hello".upcase
# => "HELLO"
```

La méthode [`downcase`][downcase] renvoie une nouvelle _string_ dont tous les caractères sont convertis en minuscules.

```crystal
"HELLO".downcase
# => "hello"
```

## String#capitalize & String#camelcase & String#underscore & String#titleize

Plusieurs méthodes permettent des conversions de casse plus précises.
C'est utile lorsqu'on veut convertir une _string_ dans un format particulier.
Voici une liste de quelques-unes des méthodes les plus courantes :

| Méthode                           | Description                                                                                                        | Exemple                                              |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------- |
| [`String#capitalize`][capitalize] | Convertit la première lettre en majuscule et le reste en minuscules                                                | `"hEllO" # => "Hello"`                               |
| [`String#camelcase`][camel-case]  | Convertit les tirets bas en `camelCase`                                                                            | `"eiffel_tower" # => "EiffelTower"`                  |
| `String#camelcase(lower: true)`   | Identique à String#camelcase, mais laisse le premier caractère en minuscule                                        | `"empire_state_building" # => "empireStateBuilding"` |
| [`String#underscore`][underscore] | Convertit tous les caractères en minuscules et place un tiret bas entre une lettre minuscule et une lettre majuscule | `"PartyInTheUSA" # => "party_in_the_usa"`            |
| [`String#titleize`][titleize]     | Met la première lettre de chaque mot en majuscule et le reste en minuscules                                        | `"the great gatsBY" # => "The Great Gatsby"`         |

## String#sub & String#gsub

Crystal dispose de méthodes pour remplacer des parties d'une _string_.
Ce sont [`sub`][sub] (_substitution_) et [`gsub`][gsub] (_substitution globale_).

Ces méthodes prennent en premier argument une _string_, un caractère ou une expression régulière, et en second argument une _string_ ou un caractère.
Le premier argument est la partie de la _string_ qui sera remplacée, et le second est le remplacement.
Les `Char` et les expressions régulières seront expliqués dans de prochains concepts.

La méthode `sub` remplace la première occurrence du premier argument par le second.

```crystal
"hello".sub("l", "r")
# => "herlo"
```

La méthode `gsub` fonctionne comme `sub`, mais remplace toutes les occurrences du premier argument par le second.

```crystal
"hello".gsub("l", "r")
# => "herro"
```

## String#chomp & String#strip

`chomp` et `strip` permettent de supprimer des caractères indésirables d'une _string_.

Par défaut, la méthode [`chomp`][chomp] supprime les derniers caractères `\r`, `\n` ou `\r\n` d'une _string_.
Si la méthode est appelée avec un argument, elle supprime la valeur donnée à la fin de la _string_, si elle s'y trouve.

```crystal
"hello\n".chomp
# => "hello"

"hello".chomp("llo")
# => "he"
```

Par défaut, la méthode [`strip`][strip] supprime tous les espaces au début et à la fin d'une _string_.
Si la méthode est appelée avec un argument, elle supprime cet argument au début et à la fin de la _string_, s'il s'y trouve.

```crystal
" hello ".strip
# => "hello"
```

## String#reverse

La méthode [`reverse`][reverse] permet d'inverser une _string_.
Elle renvoie une nouvelle _string_ dont les caractères sont dans l'ordre inverse.

```crystal
"hello".reverse
# => "olleh"
```

## String#index

La méthode [`index`][index] permet de trouver l'indice d'un caractère dans une _string_.
La méthode `index` prend en argument une `String`, un `Char` ou une expression régulière.
Elle accepte un second argument facultatif qui précise l'indice à partir duquel chercher.
La méthode `index` renvoie l'indice de la première occurrence de l'argument.

```crystal
"hello".index("l")
# => 2

"hello".index("l", 3)
# => 3
```

## String#delete_at

La méthode [`delete_at`][delete_at] permet de supprimer un caractère d'une _string_.
Elle prend un indice en argument et supprime le caractère situé à cet indice.

```crystal
"hello".delete_at(0)
# => "ello"

"hello".delete_at(3)
# => "helo"
```

## String#insert

La méthode [`insert`][insert] permet d'insérer une _string_ à un indice précis.
Elle prend un indice en premier argument et une _string_ en second argument.
Elle renvoie une nouvelle _string_ où le second argument est inséré à cet indice.

```crystal
"hello".insert(0, "h")
# => "hhello"

"hello".insert(3, "l")
# => "helllo"
```
