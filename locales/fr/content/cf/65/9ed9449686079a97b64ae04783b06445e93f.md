# Indices

## Généralités

- Renseigne-toi sur les [charlists][getting-started-charlists], sur [Unicode et les points de code][getting-started-code-points] et sur [`case`][getting-started-case] dans le guide officiel Getting Started.
- Renseigne-toi sur les [charlists][elixirschool-charlists] et sur [`case`][elixirschool-case] sur elixirschool.com.

## 1. Assainis les noms d'utilisateur existants en supprimant tout sauf les lettres minuscules

- Utilise la récursion pour parcourir une charlist.
- Il existe une [fonction intégrée][kernel-case] qui permet de comparer une valeur donnée à de nombreux motifs.
- Il existe une [syntaxe spéciale][syntax-reference-code-points] pour obtenir le point de code d'un caractère. Elle peut être utilisée dans les gardes.
- Les charlists sont des listes de points de code, et les points de code, étant des nombres, peuvent être [comparés][kernel-greater-than] entre eux.
- Les lettres latines minuscules ont toutes des [points de code consécutifs][unicode-character-reference], dans l'ordre alphabétique.
- Il existe une [fonction intégrée][kernel-concat-list] qui permet de concaténer deux listes.

## 2. Autorise les tirets bas

- Il existe une [syntaxe spéciale][syntax-reference-code-points] pour obtenir le point de code d'un caractère. Elle peut être utilisée dans les gardes et fonctionne aussi pour les caractères de ponctuation.
- Il existe une [fonction intégrée][kernel-concat-list] qui permet de concaténer deux listes.

## 3. Remplace les caractères allemands

- Il existe une [syntaxe spéciale][syntax-reference-code-points] pour obtenir le point de code d'un caractère. Elle peut être utilisée dans les gardes et fonctionne aussi pour les lettres non ASCII.
- Il existe une [fonction intégrée][kernel-concat-list] qui permet de concaténer deux listes.
