# Introduction

## Instructions `switch`

Wikipédia décrit une instruction `switch` comme « un type de mécanisme de contrôle de sélection qui permet à la valeur d'une variable ou d'une expression de modifier le déroulement du programme ».

Ce mécanisme fait intervenir les mots-clés suivants : `switch`, `case`, `break` et `default`.

Dans leur forme la plus simple, ils évaluent une expression primitive ou une _string_ et prennent une décision en fonction de sa valeur. Par exemple :

```csharp
string direction = GetDirection();
switch (direction)
{
    case "left":
        GoLeft();
        break;
    case "right":
        GoRight();
        break;
    default:
        MarkTime();
        break;
}
```

Dans leur forme la plus élaborée, ils introduisent le _downcast_, avec la syntaxe `case <Type> <variable>:`, ainsi que les gardes (`when`).

```csharp
Animal animal = GetAnimal();

switch (animal)
{
    case Dog canine:
    case Coyote canine:
        canine.Bark();
        break;
    case Cat cat when cat.HasOnly8Lives():
        cat.IsCareful();
        cat.Meow();
        break;
    case Cat cat:
        cat.Meow();
        break;
}
```
