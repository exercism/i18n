# Installation

## Prérequis du parcours PowerShell

Le parcours PowerShell d'Exercism nécessite que les éléments suivants soient installés sur ton système :

- PowerShell ou Windows PowerShell Core
- le module framework Pester pour les tests et les mocks, installé

(PS : la prise en charge de PowerShell se limite aux correctifs critiques. PowerShell Core est maintenu de façon continue et bénéficie d'une meilleure prise en charge multiplateforme)

### Installe PowerShell

PowerShell est préinstallé sur tous les systèmes d'exploitation Windows à partir de Windows 7 SP1.

Tu trouveras la dernière version de PowerShell et les instructions d'installation pour toutes les plateformes (Linux, macOS et Windows) [ici][installation].

Le code source et une procédure d'installation manuelle de [PowerShell][source-code] sont également disponibles.

### Installe et mets à jour le framework Pester

[Pester][pester] est le framework de tests de PowerShell.
Depuis la version 4.0.9, il est compatible avec PowerShell Core sous Windows, Linux et macOS (avec quelques limitations)

Il est préinstallé sur Windows 10, mais il est recommandé de le mettre à jour en exécutant la commande PowerShell suivante :

```PowerShell
Install-Module -Name Pester -Force -SkipPublisherCheck
```

Pour les mises à jour suivantes, exécute :

```PowerShell
Update-Module -Name Pester
```

Si nécessaire, tu trouveras des instructions d'installation plus détaillées à l'adresse : [https://github.com/pester/Pester/wiki/Installation-and-Update]()

## Utilise un IDE

Si tu veux une expérience d'édition plus complète, tu as sans doute intérêt à utiliser un IDE.
Voici les IDE les plus populaires qui prennent en charge les projets PowerShell :

### Toutes les plateformes

- [PowerShell ISE (Integrated Scripting Environment)][ise], un IDE graphique intégré fourni avec PowerShell (Windows uniquement).
  Pour lancer PowerShell ISE, tape `powershell_ise.exe` dans une console PowerShell.
- [Visual Studio Code][vsc] avec l'[extension PowerShell][vsc-extension].
  Visual Studio Code te permet aussi d'exécuter les tests et de déboguer ton code.
- [Sublime Text 3][sublime] avec le [paquet PowerShell][sublime-package].
