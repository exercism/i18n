# Indices

## 1. Double chaque carte

- Il existe une méthode native particulièrement adaptée aux [transformations simples][map_method_docs] comme celle-ci.

## 2. Crée plusieurs copies de chaque 3 présent dans le paquet

- Il existe une méthode native parfaite pour les transformations personnalisées ou les [accumulations][reduce_method_docs] (comme la somme d'un tableau, etc.).

## 3. Trouve deux cartes exactement au milieu du paquet

- Il existe une méthode native pour [découper][slice_method_docs] un tableau en segments plus petits.

## 4. Les deux cartes extérieures réapparaissent au milieu du paquet

- Il existe une méthode native pour [insérer ou supprimer][splice_method_docs] des éléments au milieu d'un tableau.
- Un tableau dispose aussi de méthodes natives pour supprimer le premier et le dernier élément, voir la [documentation MDN sur les tableaux][array_docs].

## 5. Toutes les cartes autres que 2 disparaissent

- Il existe une méthode native pour [filtrer][filter_method_docs] ou exclure des éléments d'un tableau.

## 6. Convertis un paquet mélangé en un paquet parfaitement ordonné

- Il existe une méthode native pour [trier][sort_method_docs].

## 7. Réordonne le paquet

- Il existe une méthode native pour [inverser][reverse_method_docs] un tableau.
