# Introduction

Une [instruction `switch`][switch] compare une valeur à plusieurs motifs correspondants possibles.
Elle constitue une alternative plus propre et plus lisible à l'enchaînement de plusieurs instructions `if-else`.

Une instruction `switch` commence par le mot-clé `switch`, suivi de la valeur à tester.
Chaque correspondance possible est introduite par le mot-clé `case`.
Le mot-clé `default` définit un cas de repli, qui s'exécute si aucun des cas explicites ne correspond.
Comme les chaînes `if-else`, une instruction `switch` n'exécute que le bloc de code associé au premier cas qui correspond.

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

Prenons la chaîne `if-else` suivante :

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

On peut l'écrire plus clairement avec une instruction `switch` :

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```
