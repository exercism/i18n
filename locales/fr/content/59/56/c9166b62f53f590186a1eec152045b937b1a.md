# Instructions supplémentaires

## Remarques

Cet exercice a pour but d'explorer certains des parallèles entre une instance d'un module WebAssembly et une instance d'une classe dans les langages orientés objet.

Dans ta solution, une instance WebAssembly doit être considérée comme une instance de compte bancaire, et des variables globales mutables de WebAssembly doivent servir à modéliser des états privés, comme dans une classe.

Aucune mémoire linéaire ne devrait être nécessaire !
