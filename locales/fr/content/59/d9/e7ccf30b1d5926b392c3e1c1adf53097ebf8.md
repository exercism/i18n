# Instructions

Dans cet exercice, tu joues à un jeu de rôle nommé « Wizard and Warriors », qui te permet d'incarner soit un Wizard, soit un Warrior.

Les règles diffèrent entre les Warriors et les Wizards pour déterminer le nombre de points de dégâts qu'ils infligent.

Pour un Warrior, les règles sont les suivantes :

- Infliger 6 points de dégâts si le personnage qu'il attaque n'est pas vulnérable
- Infliger 10 points de dégâts si le personnage qu'il attaque est vulnérable

Pour un Wizard, les règles sont les suivantes :

- Infliger 12 points de dégâts si le Wizard a préparé un sort à l'avance
- Infliger 3 points de dégâts si le Wizard n'a pas préparé de sort à l'avance

En général, les personnages ne sont jamais vulnérables. Cependant, les Wizards _sont_ vulnérables s'ils n'ont pas préparé de sort.

Tu as six tâches à réaliser avec les personnages Warrior et Wizard.

## 1. Décris un personnage

Redéfinis la méthode `ToString()` de la classe `Character` pour renvoyer une description du personnage, au format `"Character is a <CHARACTER_TYPE>"`.

```csharp
var warrior = new Warrior();
warrior.ToString();
// => "Character is a Warrior"
```

## 2. Fais en sorte que les personnages ne soient pas vulnérables par défaut

Assure-toi que la méthode `Character.Vulnerable()` renvoie toujours `false`.

```csharp
var warrior = new Warrior();
warrior.Vulnerable();
// => false
```

## 3. Permets aux Wizards de préparer un sort

Implémente la méthode `Wizard.PrepareSpell()` pour permettre à un Wizard de préparer un sort à l'avance.

```csharp
var wizard = new Wizard();
wizard.PrepareSpell();
```

## 4. Rends les Wizards vulnérables lorsqu'ils n'ont pas préparé de sort

Assure-toi que la méthode `Vulnerable()` renvoie `true` si le Wizard n'a pas préparé de sort, et `false` sinon.

```csharp
var wizard = new Wizard();
wizard.Vulnerable();
// => true
```

## 5. Calcule les points de dégâts d'un Wizard

Implémente la méthode `Wizard.DamagePoints()` pour renvoyer les points de dégâts infligés : 12 points de dégâts lorsqu'un sort a été préparé, 3 points de dégâts sinon.

```csharp
var wizard = new Wizard();
var warrior = new Warrior();

wizard.PrepareSpell();
wizard.DamagePoints(warrior);
// => 12
```

## 6. Calcule les points de dégâts d'un Warrior

Implémente la méthode `Warrior.DamagePoints()` pour renvoyer les points de dégâts infligés : 10 points de dégâts lorsque la cible est vulnérable, 6 points de dégâts sinon.

```csharp
var warrior = new Warrior();
var wizard = new Wizard();

warrior.DamagePoints(wizard);
// => 10
```
