# Introduction

## Dates et heures

La bibliothèque standard d'Elixir propose 4 modules différents pour manipuler les dates et les heures, chacun avec sa propre structure.

- Le module `Date`. Une structure `Date` peut être créée avec le sigil `~D`.

  ```elixir
  ~D[2021-01-01]
  ```

- Le module `Time`. Une structure `Time` peut être créée avec le sigil `~T`.

  ```elixir
  ~T[12:00:00]
  ```

- Le module `NaiveDateTime` pour les dates et heures sans fuseau horaire. Une structure `NaiveDateTime` peut être créée avec le sigil `~N`.

  ```elixir
  ~N[2021-01-01 12:00:00]
  ```

- Le module `DateTime` pour les dates et heures avec fuseau horaire. Utiliser ce module pour des fuseaux horaires autres qu'UTC nécessite une dépendance externe, une base de données de fuseaux horaires.

### Comparaisons

Pour comparer des dates ou des heures entre elles, cherche une fonction `compare` ou `diff` dans le module correspondant. Les opérateurs de comparaison tels que `==`, `>` et `<` _semblent_ fonctionner, mais ils n'effectuent pas une comparaison sémantique correcte pour ces structures.
