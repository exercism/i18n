# Indices

## Général

- Pense à te référer au tableau des instructions.

## 1. À partir d'une extension, renvoie le type de média attendu

- Utilise le [pattern matching][pattern-matching] pour renvoyer le type de média correct.
- Tu peux utiliser [plusieurs clauses de fonction][mfc].

## 2. À partir d'un fichier binaire, renvoie le type de média attendu

- Utilise la [forme spéciale des binaires][special-forms] à ta disposition pour écrire un littéral binaire.
- Utilise le [pattern matching][binary-matching] pour filtrer les premiers octets du binaire du fichier.

## 3. À partir d'une extension et d'un fichier binaire, vérifie que le fichier correspond au type attendu

- Réutilise les fonctions que tu as créées pour les parties 1 et 2.
- Compare la valeur de retour de chaque fonction, puis renvoie la valeur appropriée.
  - Tu peux utiliser la [macro conditionnelle `if`][if] pour les conditions binaires.
