# À propos

Les [attributs de module][module-attr] peuvent être utilisés comme des [« constantes »][attr-as-const] qui sont évaluées à la compilation.

```elixir
defmodule Example do
  @number 2

  def number(), do: @number
end
```

Cependant, ils ne se comportent pas vraiment comme des constantes, car on peut les écraser en les redéfinissant dans le module :

```elixir
defmodule Example do
  @standard_message "Hello, World!"
  @standard_message "Overwritten!"

  def message(), do: @standard_message
end
```

[module-attr]: https://hexdocs.pm/elixir/module-attributes.html
[attr-as-const]: https://hexdocs.pm/elixir/module-attributes.html#as-constants
