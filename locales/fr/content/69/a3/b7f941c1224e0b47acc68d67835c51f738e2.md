# Écris le code

Écris ton code dans `src/lib.rs`.
Les exercices sont livrés avec un fichier squelette dans `src/lib.rs` qui te montre les signatures du code que tu devras écrire.

Pour la plupart des exercices, le mieux est d'écrire tout ton code dans le fichier `src/lib.rs`.
Si tu souhaites découper ta solution en plusieurs fichiers, consulte le [chapitre sur les modules][chapter-modules] du livre Rust.

[chapter-modules]: https://doc.rust-lang.org/book/ch07-02-defining-modules-to-control-scope-and-privacy.html

## Exécute les tests

Pour exécuter les tests, il te suffit de lancer la commande suivante :

```bash
$ cargo test
```

Seul le premier test est activé par défaut.
Quand tu es prêt à passer au test suivant, retire l'attribut ignore du test suivant (`#[ignore]`).
Tu peux aussi le retirer de tous les tests d'un coup si tu préfères.

N'hésite pas à écrire le moins de code possible pour faire passer les tests.
Les échecs des tests te guideront vers ce qu'il faut écrire ensuite.

Comme Rust vérifie tout le code à la compilation, il se peut que tes tests ne compilent pas tant que tu n'as pas écrit le code nécessaire.
Même les tests marqués `ignore` sont vérifiés à la compilation.
Tu peux [mettre en commentaire][comments] les tests qui ne compilent pas en faisant commencer chaque ligne par `//`.
Ensuite, quand tu es prêt à travailler sur ce test, tu peux le décommenter.
Rust possède aussi une macro spéciale appelée `todo!()`, que tu peux utiliser sur les branches de code inachevées pour que ton programme compile.

[comments]: https://doc.rust-lang.org/book/ch03-04-comments.html

## Utilise des bibliothèques

Tu devrais pouvoir résoudre la plupart des exercices sans utiliser de bibliothèques externes.
Tu peux néanmoins ajouter des bibliothèques (la communauté Rust les appelle des **crates**) en lançant `cargo add crate-name` dans le répertoire d'un exercice.

Les tests automatiques du site ne prennent en charge qu'un ensemble prédéfini de _crates_, que tu trouveras [ici][local-registry] dans la section `[dependencies]`.
N'hésite pas à ouvrir une _issue_ ou une _pull request_ si tu souhaites que la prise en charge d'une _crate_ spécifique soit ajoutée.

[local-registry]: https://github.com/exercism/rust-test-runner/blob/main/local-registry/Cargo.toml
