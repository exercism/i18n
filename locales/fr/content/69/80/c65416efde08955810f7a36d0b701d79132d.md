# Installation

Pour installer Reason, tu auras besoin du Node Package Manager (npm). Suis les instructions [ici](https://www.npmjs.com/get-npm).

Une fois npm installé, installe Reason avec la commande suivante :
```
npm install -g bs-platform
```

Reason s'intègre à un certain nombre d'éditeurs, voir [ici](https://reasonml.github.io/docs/en/editor-plugins.html#officially-supported-editors).

Tu trouveras [ici](https://github.com/reasonml/reason-cli) quelques outils en ligne de commande (dont un REPL qui permet d'évaluer des expressions Reason dans un shell).
