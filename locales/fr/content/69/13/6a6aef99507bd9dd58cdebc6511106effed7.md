# Instructions

Dans cet exercice, tu vas écrire du code pour aider Larry the Lisp Alien à analyser et à formater des _strings_ de log. Ces _strings_ de log arrivent de systèmes divers et doivent être traitées pour que leurs messages puissent être affichés sur un écran de supervision informatif.

Les _strings_ de log se présentent sous la forme `"[<level>]: <message>"`. Le niveau est l'une des valeurs suivantes : `info`, `warn` ou `ohno`.

## 1. Extrais le message

Définis une fonction `log-message` qui prend une _string_ de log et renvoie le message qu'elle contient.

```lisp
(log-message "[ohno]: whoops!") ; => "whoops!"
```

## 2. Détermine la sévérité

Le niveau de la _string_ de log détermine sa sévérité.

- un niveau `info` correspond à une sévérité `:everything-ok`
- un niveau `warn` correspond à une sévérité `:getting-worried`
- un niveau `ohno` correspond à une sévérité `:run-for-cover`

Définis une fonction `log-severity` qui prend une _string_ de log et renvoie la sévérité correspondante.

```lisp
(log-severity "[warn]: might want to get that checked") ; => :getting-worried
```

## 3. Fais face aux aléas de la réalité

Malheureusement, il arrive que les _strings_ de log ne soient pas toujours formatées correctement. En particulier, le niveau de log peut ne pas être entièrement en minuscules comme indiqué ci-dessus. Modifie `log-severity` pour gérer ce cas.

```lisp
(log-severity "[WaRn]: string case system failing") ; => :getting-worried
```

## 4. Reformate le message de log selon la sévérité

Selon la sévérité, le message doit être modifié de différentes manières :

- une sévérité `:everything-ok` : le message doit être mis en minuscules.
- une sévérité `:getting-worried` : chaque mot du message doit commencer par une majuscule.
- une sévérité `:run-for-cover` : le message doit être mis en majuscules.

Définis une fonction `log-format` qui prend un message de log et renvoie un message correctement formaté.

```lisp
(log-format "[ohno]: whoops!") ; => WHOOPS!
```
