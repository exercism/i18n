# Introduction

Comme les propriétés, qui stockent des données dans les structures et les classes, tu peux aussi définir des _méthodes_, qui stockent des fonctions dans ta structure ou ta classe.

Les méthodes se définissent de la même manière qu'une fonction classique, mais à l'intérieur du corps de la structure ou de la classe. Note que si une fonction modifie la valeur d'une propriété d'une structure, elle doit être précédée du mot-clé `mutating`. De plus, si une propriété peut être modifiée par une méthode, elle doit être définie avec `var` plutôt qu'avec `let`, comme n'importe quelle autre variable.

```swift
struct CharacterStats {
  var health = 0.0
  var speed = 0
  var strength = 0

  mutating func takeHit(_ damage: Double) {
    health = max(0.0, health - damage)
  }
  func canLift(_ weight: Int) -> Bool {
    weight < strength * 100
  }
}
```

On peut appeler ces méthodes avec la notation pointée, tout comme les propriétés.

```swift
var stats = CharacterStats(health: 72.8, speed: 19, strength: 6)
stats.canLift(500)
// => true
```
