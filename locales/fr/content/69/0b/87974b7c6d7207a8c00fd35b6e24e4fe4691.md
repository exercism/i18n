# Ajout aux instructions

## Mots

- `<bst> ( data-seq -- tree )` : construit un arbre en insérant chaque élément de `data-seq` dans l'ordre.
- `sorted-data ( tree -- seq )` : renvoie les éléments de l'arbre par ordre croissant (parcours infixe).

## Hiérarchie des tuples

Un nœud d'un arbre binaire de recherche est soit *vide*, soit *porteur d'une donnée et de deux sous-arbres*. Modélise cela sous la forme d'une petite hiérarchie d'héritage :

```factor
TUPLE: bst ;
TUPLE: leaf < bst ;
TUPLE: branch < bst data left right ;
```

`bst` est le parent abstrait ; `leaf` correspond au cas de l'arbre vide ; `branch` porte une valeur et deux enfants `bst` (chacun étant lui-même soit un `leaf`, soit un `branch`).

## Ordre

Compare les données avec `before=?` (de `math.order`), qui fonctionne aussi bien sur les _strings_ que sur les nombres ; les tests utilisent d'ailleurs des _strings_ comme `"1"`, `"2"`, `"3"`.
