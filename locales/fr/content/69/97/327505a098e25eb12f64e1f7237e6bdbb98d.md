# Instructions

Dans cet exercice, tu vas traiter les lignes d'un rapport de journalisation.
Chaque ligne de journal est une _string_ au format suivant : `"[<LEVEL>]: <MESSAGE>"`.

Il existe trois niveaux de journalisation différents :

- `INFO`
- `WARNING`
- `ERROR`

Tu as trois tâches, chacune prenant une ligne de journal et te demandant d'en faire quelque chose.

## 1. Récupère le message d'une ligne de journal

Implémente la méthode `log_line::message` pour renvoyer le message d'une ligne de journal :

```cpp
log_line::message("[ERROR]: Invalid operation")
// => "Invalid operation"
```

## 2. Récupère le niveau de journalisation d'une ligne de journal

Implémente la méthode `log_line::log_level` pour renvoyer le niveau de journalisation d'une ligne de journal, qui doit être renvoyé en majuscules :

```cpp
log_line::log_level("[ERROR]: Invalid operation")
// => "ERROR"
```

## 3. Reformate une ligne de journal

Implémente la méthode `log_line::reformat` qui reformate la ligne de journal, en plaçant le message en premier et le niveau de journalisation après, entre parenthèses :

```cpp
log_line::reformat("[INFO]: Operation completed")
// => "Operation completed (INFO)"
```
