# Ajout aux instructions

## En Rust, les indices commencent à 0

Par convention, les séquences ordonnées de valeurs en Rust ont leur contenu numéroté (« indexé ») à partir de 0. Cela s'applique indépendamment de ce que le reste de la description de l'exercice dans ce README indique, comme les références à des indices qui commencent à 1 ; tu devras donc soustraire 1 pour convertir ces numéros d'indice en indices Rust.

## Remarque sur l'efficacité

Cet exercice utilise un _vecteur de vecteurs_ pour stocker le contenu de matrices. Bien que cet exercice soit conçu pour aider les apprenants à comprendre les concepts de base des vecteurs, comme l'indexation, ainsi que le fait que les types de données imbriqués sont autorisés, un _vecteur de vecteurs_ est un choix sous-optimal pour le calcul matriciel haute performance et tout traitement efficace similaire de grandes quantités de données.

L'explication détaillée de cette inefficacité dépasse le cadre de cet exercice et de ce parcours d'apprentissage en général. Cet aspect est connu sous le nom de [localité de cache](https://stackoverflow.com/questions/12065774/why-does-cache-locality-matter-for-array-performance) et tu peux en trouver une bonne introduction en cliquant sur ce lien si tu veux en apprendre davantage sur les détails d'une architecture informatique moderne.
