# Introduction

## Espaces de noms

Une méthode importante d'organisation du code est l'utilisation d'espaces de noms.
Deux fonctions peuvent entrer en collision de noms, ce qui peut se résoudre en les plaçant dans des espaces de noms différents.
Les espaces de noms peuvent être imbriqués, ce qui peut aider à structurer de grandes bases de code.
L'accès aux espaces de noms se fait via l'opérateur de résolution de portée `::`.

L'exemple ci-dessous montre l'utilisation de deux fonctions `foo` différentes.
Elles sont utilisées ensemble en les préfixant par leur espace de noms respectif.

```cpp
namespace my_ns {
    int foo() {
        return 44;
    }
    namespace my_inner_ns {
        int baz() {
            return 90;
        }
    }
}
namespace my_other_ns {
    int foo() {
        return -2;
    }
}

int myresult{my_ns::foo() + my_other_ns::foo() * my_ns::my_inner_ns::baz()};
```
