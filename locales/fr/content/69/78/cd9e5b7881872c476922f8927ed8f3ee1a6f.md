## Installe Z3

### Télécharge Python (si ce n'est pas déjà installé)

La dernière version de Python peut être téléchargée [ici.](https://python.org)

* Lors de l'installation, veille à cocher la case qui ajoute Python au PATH

### Télécharge Visual Studio (si ce n'est pas déjà installé)

La dernière version de Visual Studio peut être téléchargée [ici.](https://visualstudio.microsoft.com/downloads/?utm_medium=microsoft&utm_source=docs.microsoft.com&utm_campaign=inline+link&utm_content=download+vs2019)

* Lors de l'installation, sélectionne la charge de travail **Python Development**
* Coche toutes les cases à cocher des packages de développement Python facultatifs sur le côté droit

Après l'installation, ouvre Visual Studio et configure tes préférences initiales.

### Installe les commandes Git

Les instructions d'installation de Git se trouvent [ici.](https://git-scm.com/book/en/v2/Getting-Started-Installing-Git)

* Tu devras [ajouter Git à tes variables système](https://stackoverflow.com/questions/4492979/git-is-not-recognized-as-an-internal-or-external-command)

### Clone Z3

Rends-toi sur le [dépôt Z3 sur GitHub](https://github.com/Z3Prover/z3) pour consulter le projet.

Ouvre un terminal sur ton ordinateur et place-toi là où tu veux cloner le dépôt Z3 (ex. : C:\Z3).

À partir de cet emplacement, exécute :

```bash
git clone https://github.com/z3Prover/z3.git
```

### Compile Z3 sous Windows avec l'invite de commandes Visual Studio

Ouvre **Developer Command Prompt for VS 2019** depuis le menu Démarrer.

Place-toi dans le dossier dans lequel tu as cloné le dépôt Z3 (ex. : C:\Z3).

Pour les compilations 32 bits, exécute :

```bash
python scripts/mk_make.py
```

Pour une compilation 64 bits, exécute :

```bash
python scripts/mk_make.py -x
```

puis exécute :

```bash
cd build
pip install z3-solver
```



Tu devrais maintenant pouvoir ouvrir Visual Studio et exécuter Z3 avec sa liaison Python.


Pour tester, tu peux exécuter :
```python
from x3 import *
x = Real('x')
y = Real('y)
s = Solver()
s.add(x + y > 5, x > 1, y > 1)
print(s.check())
print(s.model())
```

Les deux dernières lignes devraient produire `sat` et `[y = 4, x = 2]`.
