# Structures de contrôle

Les expressions `if` et les boucles contrôlent le flux d'exécution en Cairo de la façon suivante :
`

- **Les expressions `if`** exécutent du code de façon conditionnelle, selon qu'une condition s'évalue à `true`.
- **Les boucles** (comme `loop`, `while` et `for`) exécutent du code de façon répétée tant qu'une condition donnée reste vraie, ou jusqu'à ce qu'une condition d'arrêt soit remplie.

Ces constructions sont fondamentales pour implémenter de la logique et des itérations en Cairo.

## Les expressions `if`

En Cairo, les expressions `if` permettent de contrôler le flux d'exécution en fonction d'une logique conditionnelle.
Elles suivent une structure où le code est exécuté selon qu'une condition booléenne s'évalue à `true` ou `false`.

```rust
fn main() {
    let temperature = 30;

    if temperature > 25 {
        println!("It's hot outside!");
    }
}
```

Cet exemple montre un bloc `if` simple en Cairo.
Le message `"It's hot outside!"` n'est affiché que si la condition `temperature > 25` s'évalue à `true`.
Si la condition vaut `false`, aucun code n'est exécuté et le programme continue.

```rust
fn main() {
    let number: u32 = 5;

    if number < 10 {
        println!("The number is less than 10.");
    } else {
        println!("The number is 10 or greater.");
    }
}
```

L'exécution de ce code affiche `"The number is less than 10."` dans la console.

### Gère plusieurs conditions avec `else if`

Tu peux utiliser plusieurs conditions en combinant `if` et `else` dans une expression `else if`.

```rust
fn main() {
    let score: u64 = 85;

    if score >= 90 {
        println!("Grade: A");
    } else if score >= 80 {
        println!("Grade: B");
    } else if score >= 70 {
        println!("Grade: C");
    } else {
        println!("Grade: F");
    }
}
```

L'exécution de ce code affiche `"Grade: B"` dans la console.

### Utilise `if` dans une instruction `let`

En Cairo, une expression `if` peut s'utiliser à droite d'une instruction `let` pour affecter le résultat à une variable.

```rust
fn main() {
    let condition: bool = true;
    let number: felt252 = if condition {
        5
    } else {
        6
    };

    if number == 5 {
        println!("condition was true and number is {}", number);
    }
}
```

## Les boucles

Les boucles sont une construction fondamentale qui permet de répéter des blocs de code, ce qui rend l'exécution des tâches à la fois efficace et contrôlée.
Une boucle peut parcourir une séquence ou exécuter du code de façon répétée en fonction d'une condition.
Cairo propose trois principaux types de boucles :

- **`loop`** : une boucle de base qui tourne indéfiniment, sauf si on l'arrête explicitement avec une instruction `break`.
- **`while`** : continue de s'exécuter tant qu'une condition donnée reste `true`.
  Elle s'arrête quand la condition devient `false`.
- **`for`** : parcourt les éléments d'une collection, comme les tableaux, en exécutant du code pour chaque élément.

### Répète du code avec `loop`

Le mot-clé `loop` demande à Cairo d'exécuter un bloc de code encore et encore, indéfiniment, jusqu'à ce que tu lui dises explicitement de s'arrêter.

```rust
fn main() {
    loop {
        println!("again!");
    }
}
```

L'exécution de ce code affiche `"again!"` indéfiniment dans la console, jusqu'à ce que le programme tombe à court de gas ou qu'on l'arrête manuellement.

> Remarque : Cairo nous empêche d'exécuter un programme contenant des boucles infinies en y intégrant un compteur de gas.
> Le compteur de gas est un mécanisme qui limite la quantité de calcul qu'un programme peut effectuer.
> Le gas est une unité de mesure qui exprime le coût de calcul d'une instruction.
> Quand le compteur de gas arrive à zéro, le programme s'arrête.

Pour sortir d'une boucle, place le mot-clé `break` à l'intérieur de celle-ci pour indiquer au programme quand arrêter son exécution.

```rust
fn main() {
    let mut i: usize = 0;
    loop {
        if i > 10 {
            break;
        }
        println!("i = {}", i);
        i += 1;
    }
}
```

Le mot-clé `continue` demande au programme de passer à l'itération suivante de la boucle et d'ignorer le reste du code de l'itération en cours.

```rust
fn main() {
    let mut i: usize = 0;
    loop {
        if i > 10 {
            break;
        }
        if i == 5 {
            i += 1;
            continue;
        }
        println!("i = {}", i);
        i += 1;
    }
}
```

L'exécution de ce programme n'affiche pas la valeur de `i` lorsqu'elle est égale à `5`.

#### Renvoie des valeurs depuis `loop`

Tu peux renvoyer une valeur depuis une boucle `loop` en utilisant le mot-clé `break` suivi de la valeur à renvoyer.
Cela te permet de sortir de la boucle `loop` et de transmettre un résultat au reste de ton code.

```rust
fn main() {
    let mut counter = 0;

    let result = loop {
        if counter == 10 {
            break counter * 2;
        }
        counter += 1;
    };

    println!("The result is {}", result); // prints "The result is 20"
}
```

### Les boucles conditionnelles avec `while`

`while` exécute du code tant qu'une condition vaut `true`, et s'arrête quand la condition devient `false`.

```rust
fn main() {
    let mut number = 3;
    while number != 0 {
        println!("{}!", number);
        number -= 1;
    }
    println!("LIFTOFF!!!");
}
```

### Parcours une collection avec `for`

`for` parcourt chaque élément d'une collection et exécute du code pour chacun d'eux.

```rust
fn main() {
    let a = [10, 20, 30, 40, 50].span();
    for element in a {
        println!("the value is: {}", element);
    }
}
```
