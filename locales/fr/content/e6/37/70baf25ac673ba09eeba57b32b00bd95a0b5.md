# Introduction

Lorsqu'une _quotation_ doit *mémoriser* des valeurs de son environnement, Factor propose deux outils : `curry`/`compose` de [`kernel`][kernel], et la syntaxe fry `'[ … ]` de [`fry`][fry].

`curry` intègre une valeur au début d'une _quotation_ :

```
curry ( value quot -- newquot )
```

```factor
3 [ + ] curry .          ! => [ 3 + ]
10 3 [ + ] curry call .  ! => 13
```

`compose` colle deux _quotations_ ensemble :

```factor
[ 1 + ] [ 2 * ] compose .       ! => [ 1 + 2 * ]
5 [ 1 + ] [ 2 * ] compose call . ! => 12
```

Au-delà d'une ou deux captures, fry est plus lisible. Chaque marqueur `_` est rempli, dans l'ordre, par une valeur prise sur la pile :

```factor
2 3 '[ _ _ + + ] .    ! => [ 2 3 + + ]
```

fry va aussi chercher à l'intérieur des _quotations_ imbriquées.

[kernel]: https://docs.factorcode.org/content/vocab-kernel.html
[fry]: https://docs.factorcode.org/content/vocab-fry.html
