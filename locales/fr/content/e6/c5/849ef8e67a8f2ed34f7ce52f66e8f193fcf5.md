# Installation

## Démarrage rapide

``` shellsession
$ bash <(curl -s https://raw.githubusercontent.com/borkdude/babashka/master/install)
```

Par défaut, l'installation se fait dans `/usr/local/bin`. Pour changer cela, indique le nom du répertoire :

``` shellsession
$ bash <(curl -s https://raw.githubusercontent.com/borkdude/babashka/master/install) /tmp
```

## Brew

Les binaires Linux et macOS sont fournis via brew.

Pour installer :

    brew install borkdude/brew/babashka

Pour mettre à niveau :

    brew upgrade babashka

## Arch (Linux)

`babashka` est [disponible](https://aur.archlinux.org/packages/babashka-bin/) dans l'[Arch User Repository](https://aur.archlinux.org). Tu peux l'installer avec ton assistant [AUR](https://aur.archlinux.org) préféré, comme
[yay](https://github.com/Jguer/yay), [yaourt](https://github.com/archlinuxfr/yaourt), [apacman](https://github.com/oshazard/apacman) ou [pacaur](https://github.com/rmarquis/pacaur). Voici un exemple avec `yay` :

    yay -S babashka-bin

## Windows

Sous Windows, tu peux installer avec [scoop](https://scoop.sh/) et le _bucket_
[scoop-clojure](https://github.com/littleli/scoop-clojure).

## Téléchargement

Tu peux aussi télécharger un binaire depuis
[Github](https://github.com/borkdude/babashka/releases). Pour Linux, un binaire
statique est disponible et peut être utilisé sur Alpine.

## Docker

Jette un œil à l'image sur [Docker hub](https://hub.docker.com/r/borkdude/babashka/).
