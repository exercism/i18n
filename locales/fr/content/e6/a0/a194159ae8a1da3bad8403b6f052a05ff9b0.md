# Introduction

Les tableaux en C# sont des collections de valeurs primitives ou d'instances de structures ou de classes. Ils sont implémentés dans la bibliothèque de classes de base sous la forme de `List<T>`, où `T` est le type de l'élément du tableau. L'API expose un ensemble riche de méthodes pour créer et manipuler les tableaux.

On peut ajouter et retirer des éléments à un tableau. Les tableaux grandissent et rétrécissent selon les besoins.

```csharp
var listOfStrings = new List<string>();
```
