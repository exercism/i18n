# Indices

Utiliser les nombres complexes pour les rotations en 2D permet d'obtenir un code plus propre et numériquement plus précis.

## 1. Construis un nombre complexe à partir de coordonnées cartésiennes

- La méthode intégrée [`complex(x, y)`][complex] est plus efficace que de passer par une affectation `x + im*y`.
- Revois l'introduction pour un rappel.

## 2. Construis un nombre complexe à partir de coordonnées polaires

- Il existe plusieurs façons équivalentes de faire ça (par exemple `exp`, `cis`, `cispi`).
- Revois l'introduction et les instructions pour aller plus loin.

## 3. Effectue une rotation de vecteur en 2D

- La [formule d'Euler][euler] est ton alliée ici, et tu peux utiliser ta fonction `euler`.
- Il existe des méthodes pour récupérer la partie [réelle][real] et la partie [imaginaire][imaginary] d'un nombre complexe, ou les deux !

## 4. Effectue un déplacement radial

- Ta fonction `euler` peut être utile, ou pas...
- La méthode intégrée [`angle`][angle] peut servir à trouver rapidement l'argument d'un nombre complexe.
- La méthode [`abs`][abs] permet de trouver le module d'un nombre complexe.

## 5. Trouve la chanson souhaitée

- C'est l'occasion de combiner tes fonctions `rotate` et `rdisplace`.
