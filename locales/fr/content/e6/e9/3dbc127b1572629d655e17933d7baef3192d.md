# À propos

CoffeeScript est un langage qui se transpile en JavaScript, utilisé pour créer des sites web dynamiques (aussi bien dans le navigateur que sur le serveur).
Le transpileur transforme le code CoffeeScript en JavaScript avant l'exécution, afin de conserver la compatibilité et les mêmes performances que JavaScript, tout en offrant de nombreuses nouvelles fonctionnalités !

CoffeeScript a été créé pour offrir une façon simplifiée d'écrire du JavaScript, en s'appuyant sur un mélange des langages Ruby et Python.
L'une des différences réside dans l'utilisation de l'indentation et des flèches pour remplacer le code verbeux des fonctions JavaScript, ainsi que dans l'introduction de fonctionnalités utiles venues des langages fonctionnels, dont le filtrage par motif.

CoffeeScript fait partie des nombreux nouveaux langages qui se transpilent en JavaScript, à l'image de TypeScript et Flow. La communauté s'agrandit, et ce type de langage est très populaire.
