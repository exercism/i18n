# Tableaux

À Cairo, un tableau est une structure de données qui permet de stocker une collection d'éléments du même type.
Les tableaux de Cairo n'offrent que des possibilités de modification limitées.
On peut uniquement ajouter des éléments à la fin d'un tableau et en retirer depuis le début.
En fait, les tableaux sont des files dont les valeurs ne peuvent pas être modifiées.

## Construction d'un tableau

Les tableaux sont principalement construits à l'aide du trait `ArrayTrait`, et on peut utiliser l'une des 4 façons suivantes pour construire un tableau d'éléments `[1, 2]` :

```rust
// 1. Passing the type to the `ArrayTrait`
let mut arr_type_in_trait = ArrayTrait::<felt252>::new();
arr_type_in_trait.append(1);
arr_type_in_trait.append(2);

// 2. Setting the type on the variable itself
let mut arr_explicit_type: Array<felt252> = ArrayTrait::new();
arr_explicit_type.append(1);
arr_explicit_type.append(2);

// 3. Using the `array!` macro
let mut arr_from_macro: Array<felt252> = array![1, 2]; // assign values in-line

// 4. Allowing the compiler to infer the type from the type of values being assigned to it
let mut arr_implicit_type = ArrayTrait::new(); // compiler "knows" this is a `felt252` array
arr_implicit_type.append(1);
arr_implicit_type.append(2);
```

> Chaque appel à `append()` place un nouveau nombre à la fin du tableau.

## Supprime des éléments d'un tableau

La seule façon de retirer des éléments d'un tableau à Cairo est de le faire depuis le début.
Cette opération est assurée par la méthode `pop_front()`, qui renvoie une `Option` que l'on peut déballer, contenant l'élément retiré, ou `Option::None` si le tableau est vide.

```rust
fn main() {
    let mut a = array![10, 1, 2];
    let first_value = a.pop_front().unwrap(); // `unwrap()` is used to get the value from `Option`
    println!("The first value is {}", first_value); // prints "The first value is 10"
}
```

## Accède aux valeurs d'un tableau

Pour accéder aux éléments d'un tableau, on peut utiliser les méthodes `get()` ou `at()`, qui renvoient des types différents.
L'opérateur d'indice `arr[index]` est équivalent à `arr.at(index)`.

### Utilise la méthode get()

La méthode `get()` revient à rechercher un élément dans un tableau par son numéro.
Voici comment ça marche :

- `arr.get(index)` permet de récupérer un élément à une position précise (l'indice) dans le tableau.
- Elle renvoie `Option::Some(value)` si l'élément à l'indice donné existe, ou `Option::None` si l'indice est hors limites.

Cette méthode est idéale lorsqu'on veut gérer les cas où l'indice pourrait être invalide sans faire planter le programme.

```rust
fn main() {
    let arr: Array<u32> = array![1, 2, 3];

    let index = 1;

    match arr.get(index) {
        Option::Some(value) => { println!("Element at index {}: {}", index, value.unbox()); },
        Option::None => { println!("Index {} is out of bounds!", index); }
    }
}
```

### Utilise la méthode at()

La méthode `at()` donne directement un instantané de l'élément à un indice précis, en utilisant l'opération `unbox()` pour extraire la valeur stockée de la boîte.
L'opérateur d'indice `arr[index]` est une notation abrégée de cette méthode.
Si tu essaies d'accéder à un indice qui n'existe pas (hors limites), le programme paniquera avec une erreur.

```rust
fn main() {
    let a: Array<u32> = array![5, 8];

    println!("First: {}", *a.at(0)); // prints "First: 5"
    println!("Second: {}", a[1]); // prints "Second: 8"
    println!("Third: {}", a[2]); // panics with 'Index out of bounds'
}
```

## Méthodes liées à la taille

Pour déterminer le nombre d'éléments d'un tableau, utilise la méthode `len()`.
La valeur de retour est de type `usize`.

Si tu veux vérifier si un tableau est vide ou non, tu peux utiliser la méthode `is_empty()`, qui renvoie `true` si le tableau est vide et `false` sinon.

## `Span`

`Span` est une structure qui représente un instantané d'un `Array`.
Il est conçu pour offrir un accès sûr et contrôlé aux éléments d'un tableau sans modifier le tableau d'origine.
`Span` est particulièrement utile pour garantir l'intégrité des données et éviter les problèmes d'emprunt lorsqu'on passe des tableaux entre des fonctions ou qu'on effectue des opérations en lecture seule.

> Toutes les méthodes fournies par `Array` peuvent aussi être utilisées avec `Span`, à l'exception de la méthode `append()`.

Pour créer un `Span` à partir d'un `Array`, appelle la méthode `span()` :

```rust
let my_array: Array<u32> = array![1, 2, 3];
let my_span: Span<u32> = my_array.span();
```

## Le type `Array` à taille fixe

On écrit les valeurs d'un tableau à taille fixe sous forme de liste séparée par des virgules entre crochets.
Le type du tableau s'écrit entre crochets, avec le type de chaque élément, un point-virgule, puis le nombre d'éléments du tableau.

```rust
let arr: [u64; 5] = [1, 2, 3, 4, 5];
```

> Remarque : seuls les tableaux à taille fixe peuvent être utilisés comme constantes

On peut accéder aux éléments d'un tableau à taille fixe soit en déstructurant le tableau, soit en le convertissant en `Span`, qui prend en charge l'indexation.

```rust
fn main() {
    let arr = [1, 2, 3, 4, 5]; // implicit `felt252` array type

    // Accessing elements of a fixed-size array by deconstruction
    let [a, b, c, _, _] = arr;
    println!("c: {}", c); // c: 3
    
    // Accessing elements of a fixed-size array by index
    let my_span = arr.span();
    println!("my_span[2]: {}", my_span[2]); // my_span[2]: 3
}
```
