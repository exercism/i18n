# Indices

## 1. Rends `preparation-time-in-minutes` plus facile à utiliser

- Un « paramètre rest » rassemble dans une liste tous les arguments qui ne sont pas consommés par les autres paramètres.
- Un « paramètre rest » se désigne dans la liste de paramètres lambda par le mot-clé de liste lambda `&rest`.
- La fonction `length` permet d'obtenir le nombre d'éléments d'une liste.

## 2. Permets de modifier le temps de cuisson attendu

- Un paramètre optionnel peut être fourni ou non.
- Un paramètre optionnel peut avoir une valeur par défaut.
- Les paramètres optionnels se désignent par le mot-clé de liste lambda `&optional`.

## 3. Lilly se souvient d'un autre mode de cuisson préféré

- Un « paramètre supplied-p » peut être spécifié avec le paramètre optionnel pour déterminer si l'appelant a bien fourni ce paramètre.

## 4. Répartis les restes

- Les paramètres à mot-clé portent un nom et sont optionnels.
- Les paramètres à mot-clé se désignent par le mot-clé de liste lambda `&key`.

## 5. Fais des suppositions

- Les paramètres à mot-clé peuvent avoir des valeurs par défaut.

## 6. Quantité standard de restes

- Les paramètres à mot-clé peuvent avoir un « paramètre supplied-p », comme les paramètres optionnels.
