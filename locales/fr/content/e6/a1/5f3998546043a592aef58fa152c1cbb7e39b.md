# Instructions

Les auditions pour la pièce de théâtre de l'école sont terminées et le metteur en scène a besoin que les décisions soient consignées par écrit.

Les quatre tâches se font dans la classe `CASTING_CALL`.

## 1. Le verdict

Chaque interprète est noté sur dix. À partir de huit, la personne est retenue ; de cinq à sept, elle est rappelée ; en dessous de cinq, elle est remerciée.

```sather
CASTING_CALL::audition_outcome(8)
-- => "Cast"
CASTING_CALL::audition_outcome(6)
-- => "Recalled"
CASTING_CALL::audition_outcome(2)
-- => "Thank you"
```

## 2. Quel groupe ?

Les interprètes de moins de 13 ans sont des _Juniors_. De 13 à 15 ans, ce sont des _Middles_. À partir de 16 ans, des _Seniors_.

```sather
CASTING_CALL::age_group(13)
-- => "Middles"
```

## 3. Quand revenir

Les _Juniors_ sont rappelés à quatre heures, les _Middles_ à cinq heures, et tous les autres à six heures.

```sather
CASTING_CALL::callback_time("Middles")
-- => "5pm"
```

L'argument est le nom d'un groupe, orthographié exactement comme dans la tâche 2.

## 4. Ce qu'il faut écrire sur la feuille

Une personne qui a obtenu au moins huit et qui sait chanter obtient `"Lead"`. Au moins huit sans savoir chanter, c'est `"Speaking part"`. Dans tous les autres cas, c'est `"Chorus"`.

```sather
CASTING_CALL::casting_note(9, true)
-- => "Lead"
CASTING_CALL::casting_note(9, false)
-- => "Speaking part"
CASTING_CALL::casting_note(4, true)
-- => "Chorus"
```
