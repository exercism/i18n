# Introduction

[Les intervalles][range] représentent une plage de valeurs comprise entre deux bornes.
On les utilise couramment avec des types comme `Int`, `String` et `Character` pour itérer sur des séquences, découper des collections ou vérifier si une valeur se situe dans les limites.

Swift fournit deux opérateurs d'intervalle principaux :

- **Opérateur d'intervalle fermé (`...`)** : inclut la valeur de début et la valeur de fin (`1...5` inclut 1, 2, 3, 4 et 5).
- **Opérateur d'intervalle semi-ouvert (`..<`)** : inclut la valeur de début mais exclut la valeur de fin (`1..<5` inclut 1, 2, 3 et 4).

```swift
let closed = 1...5
let halfOpen = 1..<5
```

~~~~exercism/note
Quand on appelle une méthode directement sur un littéral d'intervalle, il faut entourer l'expression d'intervalle de parenthèses pour que le compilateur évalue d'abord l'intervalle :

```swift
(1...5).contains(3) // Returns true
// 1...5.contains(3) // Error: value of type 'Int' has no member 'contains'
```
~~~~

## Convertis un intervalle en tableau

On peut convertir un intervalle de nombres en `Array` à l'aide de l'initialiseur `Array(_:)` :

```swift
let range = 1...5
let numbers = Array(range)
// numbers is [1, 2, 3, 4, 5]
```

## Découpe un tableau avec des intervalles

On peut utiliser les intervalles pour découper des sous-sections d'un tableau :

```swift
let array = [10, 20, 30, 40, 50]
let slice = array[1...3]
// slice contains [20, 30, 40]
```

## Propriétés et méthodes des intervalles

Les opérations courantes sur les intervalles incluent :

| Membre                  | Description                                                | Exemple                              |
| ----------------------- | ---------------------------------------------------------- | ------------------------------------ |
| `count`                 | Renvoie le nombre d'éléments de l'intervalle               | `(1...5).count` renvoie `5`          |
| [`contains(_:)`][contains] | Renvoie `true` si l'intervalle contient la valeur spécifiée, sinon `false` | `(1...5).contains(3)` renvoie `true` |

## Intervalles unilatéraux

Swift prend aussi en charge les intervalles unilatéraux (partiels), où l'on omet soit la valeur de début, soit la valeur de fin :

- `array[2...]` : de l'indice 2 jusqu'à la fin de la collection.
- `array[...2]` : du début de la collection jusqu'à l'indice 2 inclus.
- `array[..<2]` : du début de la collection jusqu'à l'indice 2, non compris.

## Intervalles de _strings_ et de caractères

On peut aussi créer des intervalles entre des caractères ou des _strings_ qui se conforment à `Comparable` :

```swift
let letters = "a"..."z"
print(letters.contains("m")) // Prints true
print(letters.contains("A")) // Prints false
```
