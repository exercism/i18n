# Instructions

Dans cet exercice, on va implémenter la logique de quête d'un nouveau jeu de rôle qu'un ami développe.

Le personnage principal du jeu est Annalyn, une jeune fille courageuse accompagnée d'un chien féroce et fidèle. Malheureusement, le malheur frappe : son meilleur ami a été enlevé alors qu'il cherchait des baies dans la forêt.

Annalyn va tenter de retrouver son meilleur ami et de le libérer, en emmenant éventuellement son chien avec elle pour cette quête.

Après avoir suivi un moment la piste de son meilleur ami, elle trouve le camp où celui-ci est retenu prisonnier. Il s'avère qu'il y a deux ravisseurs : un chevalier puissant et un archer rusé.

Ayant trouvé les ravisseurs, Annalyn se demande lesquelles des actions suivantes elle peut entreprendre :

- _Attaque rapide_ : une attaque rapide est possible si le chevalier dort, car il lui faut du temps pour enfiler son armure et il est donc vulnérable.
- _Espionnage_ : on peut espionner le groupe si au moins l'un d'eux est éveillé. Sinon, espionner est une perte de temps.
- _Signale le prisonnier_ : on peut signaler sa présence au prisonnier à l'aide de cris d'oiseaux si le prisonnier est éveillé et que l'archer dort, car les archers sont entraînés à imiter les cris d'oiseaux et pourraient donc intercepter le message.
- _Libère le prisonnier_ : Annalyn peut tenter de se faufiler dans le camp pour libérer le prisonnier.
  C'est une action risquée, qui ne peut réussir que de deux manières :
  - Si Annalyn a son chien avec elle, elle peut délivrer le prisonnier lorsque l'archer est endormi.
    Le chevalier a peur du chien, et l'archer n'aura pas le temps de se préparer avant qu'Annalyn et le prisonnier ne s'échappent.
  - Si Annalyn n'a pas son chien, elle et le prisonnier doivent se montrer très discrets !
    Annalyn peut libérer le prisonnier si celui-ci est éveillé et que le chevalier et l'archer dorment tous les deux, mais si le prisonnier dort, impossible de le délivrer : il serait surpris par l'apparition soudaine d'Annalyn et réveillerait le chevalier et l'archer.

Tu as quatre tâches : implémenter la logique qui détermine si les actions ci-dessus sont possibles, en fonction de l'état des trois personnages rencontrés dans la forêt et de la présence ou non du chien d'Annalyn.

## 1. Vérifie si une attaque rapide est possible

Implémente la méthode `can_fast_attack()` qui prend une valeur booléenne indiquant si le chevalier est éveillé. Cette méthode renvoie `TRUE` si une attaque rapide est possible d'après l'état du chevalier, et `FALSE` sinon :

```R
knight_is_awake <- TRUE
can_fast_attack(knight_is_awake)
# => FALSE
```

## 2. Vérifie si le groupe peut être espionné

Implémente la méthode `can_spy()` qui prend trois valeurs booléennes indiquant respectivement si le chevalier, l'archer et le prisonnier sont éveillés. La méthode renvoie `TRUE` si le groupe peut être espionné d'après l'état des trois personnages, et `FALSE` sinon :

```R
knight_is_awake <- FALSE
archer_is_awake <- TRUE
prisoner_is_awake <- FALSE
can_spy(knight_is_awake, archer_is_awake, prisoner_is_awake)
# => TRUE
```

## 3. Vérifie si l'on peut signaler le prisonnier

Implémente la méthode `can_signal_prisoner()` qui prend deux valeurs booléennes indiquant respectivement si l'archer et le prisonnier sont éveillés. La méthode renvoie `TRUE` si l'on peut signaler le prisonnier d'après l'état des deux personnages, et `FALSE` sinon :

```R
archer_is_awake <- FALSE
prisoner_is_awake <- TRUE
can_signal_prisoner(archer_is_awake, prisoner_is_awake)
# => TRUE
```

## 4. Vérifie si le prisonnier peut être libéré

Implémente la méthode `can_free_prisoner()` qui prend quatre valeurs booléennes. Les trois premiers paramètres indiquent respectivement si le chevalier, l'archer et le prisonnier sont éveillés. Le dernier paramètre indique si le chien d'Annalyn est présent. La méthode renvoie `TRUE` si le prisonnier peut être libéré d'après l'état des trois personnages et la présence du chien d'Annalyn, et `FALSE` sinon :

```R
knight_is_awake <- FALSE
archer_is_awake <- TRUE
prisoner_is_awake <- FALSE
pet_dog_is_present <- FALSE
can_free_prisoner(knight_is_awake, archer_is_awake, prisoner_is_awake, pet_dog_is_present)
# => FALSE
```
