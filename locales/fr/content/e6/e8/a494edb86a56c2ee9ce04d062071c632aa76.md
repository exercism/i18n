# Introduction

## Les _bitstrings_

Manipuler des données binaires est un concept important dans n'importe quel langage, et Elixir offre une syntaxe élégante pour écrire, faire correspondre et construire des données binaires.

En Elixir, les données binaires portent le nom de type _bitstring_. Le _type_ de données binaires (à ne pas confondre avec les données binaires en général) est une forme particulière de _bitstring_, que l'on verra dans un exercice ultérieur.

Les littéraux de _bitstring_ se définissent à l'aide de la forme spéciale `<<>>`. Quand on définit un littéral de _bitstring_, on le décrit en segments. Chaque segment possède une valeur et un type, séparés par l'opérateur `::`. Le type précise combien de bits serviront à encoder la valeur. On peut omettre complètement le type, ce qui donne par défaut une valeur entière de 8 bits.

```elixir
# This defines a bitstring with three segments of a single bit each
<<0::1, 1::1, 0::1>>
```

Spécifier le type `::1` est un raccourci pour écrire `::size(1)`. Il faut utiliser la syntaxe plus longue si la taille en bits provient d'une variable.

### Le binaire

Lorsqu'on écrit des littéraux d'entiers binaires, on peut les écrire directement en notation en base 2 en faisant précéder le littéral de `0b`. À noter qu'ils seront de toute façon affichés sous forme de nombres décimaux dans les résultats de tests ou quand on utilise iex.

```elixir
<<0b1011::4>> == <<11::4>>
# => true
```

### Tronque

Si la valeur du segment dépasse la capacité du type de ce segment, elle est tronquée à partir de la gauche.

```elixir
<<0b1011::3>> == <<0b0011::3>>
# => true
```

### Ajoute au début et à la fin

On peut à la fois ajouter au début et à la fin d'un _bitstring_ existant à l'aide de la forme spéciale. Le type `::bitstring` doit être utilisé sur le _bitstring_ existant s'il est de taille inconnue.

```elixir
value = <<0b110::3, 0b001::3>>
new_value = <<0b011::3, value::bitstring, 0b000::3>>
# => <<120, 8::size(4)>>
```

### Concatène

On peut concaténer des _bitstrings_ stockés dans des variables à l'aide de la forme spéciale. Le type `::bitstring` doit être utilisé lorsqu'on concatène deux _bitstrings_ de tailles inconnues.

```elixir
first = <<0b110::3>>
second = <<0b001::3>>
concatenated = <<first::bitstring, second::bitstring>>
# => <<49::size(6)>>
```

### Fais correspondre des motifs

On peut aussi faire de la correspondance de motifs pour obtenir des valeurs à partir de la forme spéciale. Il faut connaître le nombre de bits de chaque fragment que l'on veut capturer, à une exception près : le type `::bitstring` permet de faire correspondre un motif sur un _bitstring_ de taille inconnue, mais uniquement pour le dernier fragment.

```elixir
<<value::4, rest::bitstring>> = <<0b01101001::8>>
value == 0b0110
# => true
```

### Inspecte les _bitstrings_

~~~~exercism/note
Les _bitstrings_ peuvent être affichés (par l'exécuteur de tests ou dans iex)
dans un format différent de celui qui a servi à les créer. Cela
prête souvent à confusion lorsqu'on apprend les _bitstrings_.
~~~~

Par défaut, les _bitstrings_ sont affichés par fragments de 8 bits (un octet), même si on les a créés avec des fragments d'une taille différente.

```elixir
<<2011::11>>
# => <<251, 3::size(3)>>
```

Si on crée un _bitstring_ qui représente une _string_ encodée en UTF-8 et imprimable, il s'affiche comme une _string_.

```elixir
<<>>
# => ""

<<65, 66, 67>>
# => "ABC"
```
