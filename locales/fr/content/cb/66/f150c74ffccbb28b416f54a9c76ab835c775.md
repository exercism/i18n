# Instructions

Dans cet exercice, tu vas définir des constantes qui serviront au fonctionnement d'une banque.

Tu as cinq tâches :

## 1. Représente le taux d'intérêt fixe d'un prêt

Crée la constante numérique non typée `FixedInterestRate` pour stocker la valeur de 5 % (5/100), puis implémente la fonction `GetFixedInterestRate` pour la renvoyer :

```go
GetFixedInterestRate()
// => 0.05
```

## 2. Représente le nombre de jours dans une année

Crée la constante `DaysPerYear` de type `int` pour stocker la valeur 365, puis implémente la fonction `GetDaysPerYear` pour la renvoyer :

```go
GetDaysPerYear()
// => 365
```

## 3. Représente les mois de l'année

Dans un bloc, utilise l'énumérateur de Go pour créer douze constantes numériques non typées contenant les valeurs de 1 à 12 pour les mois de l'année.
Nomme-les `Jan`, `Feb`, `Mar`, etc., puis implémente la fonction `GetMonth` pour renvoyer la valeur d'un mois donné :

```go
GetMonth(Jan)
// => 1
```

## 4. Représente un numéro de compte

Crée la constante _string_ non typée `AccountNo` pour stocker la valeur XF348IJ, puis implémente la fonction `GetAccountNumber` pour la renvoyer :

```go
GetAccountNumber()
// => "XF348IJ"
```
