# Instructions

Les apprenants les plus observateurs auront remarqué que le type `TreasureChest` de l'exercice précédent n'était pas si sécurisé que ça !

Si tu utilisais la fonction `get_treasure`, tu devais fournir le mot de passe, mais tu pouvais quand même déstructurer le type `TreasureChest` pour récupérer le trésor sans avoir à connaître le mot de passe.

Corrigeons cela en utilisant un type opaque.

## 1. Définis le type opaque `TreasureChest`.

Le `TreasureChest` contient deux champs :
- Un mot de passe de type `String`.
- Un trésor, qui est d'un type générique.

Le type `TreasureChest` doit être opaque.

## 2. Définis la fonction `create`.

Cette fonction prend deux arguments :
- Un mot de passe `String`.
- Une valeur de trésor de n'importe quel type.

La fonction renvoie un `TreasureChest` contenant le mot de passe et la valeur.

Si le mot de passe fait moins de 8 caractères, la fonction doit renvoyer une erreur indiquant `Password must be at least 8 characters long`.

## 3. Définis la fonction `open`.

Cette fonction prend deux arguments :

- Un `TreasureChest`.
- Un mot de passe `String`.

Si le mot de passe correspond à celui du `TreasureChest`, la fonction doit renvoyer le trésor ; sinon, elle doit renvoyer une erreur indiquant `Incorrect password`.
