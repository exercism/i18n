# Instructions

En tant qu'amateur d'échecs, tu veux écrire ta propre version du jeu.
Certes, il existe déjà plein d'implémentations d'échecs disponibles en ligne, mais la tienne sera unique !

Tu commences par implémenter un échiquier.

La partie d'échecs se jouera sur un échiquier de huit cases de large sur huit cases de long.
Les cases sont identifiées par une lettre et un nombre.

## 1. Définis la plage des rangées et des colonnes

Le jeu devra stocker les rangées de l'échiquier.
Les rangées correspondent aux lignes de l'échiquier et sont numérotées de 1 à 8.

Le jeu devra aussi stocker les colonnes de l'échiquier.
Les colonnes de l'échiquier sont identifiées par les lettres A à H.

Définis les constantes `ranks` et `files` qui stockent respectivement la plage des rangées et celle des colonnes.

```swift
ranks
// Returns 1..8

files
// Returns "A".."H"
```

## 2. Vérifie si une case est valide

Le jeu devra vérifier si une case est valide.
Une case est valide si sa rangée et sa colonne se trouvent dans les plages des rangées et des colonnes.

Définis la méthode `isValidSquare(rank:file:)` qui prend les arguments `rank`, contenant un `Int` pour la rangée, et `file`, contenant une `String` pour la colonne.
La méthode doit renvoyer `true` si la rangée et la colonne se trouvent dans la plage des rangées et des colonnes, et renvoyer `false` sinon.

```swift
isValidSquare(rank: 1, file: "A")
// Returns true
```

## 3. Récupère la ligne

Le jeu stockera toutes les cases de l'échiquier dans un tableau à une dimension.
Les cases sont formées d'une chaîne de caractères composée de la rangée et de la colonne, par exemple « 1A », « 8B », « 4G », etc.
Pour obtenir la ligne d'une case, le jeu devra calculer l'indice de la première case de la ligne.

Définis la méthode `getRow(rank:)` qui prend l'argument `rank`, contenant un `Int` pour la rangée.
La méthode doit renvoyer un tableau de chaînes de caractères qui représentent les cases de la ligne.

```swift
let board = ["1A", "1B", "1C", "1D", "1E", "1F", "1G", "1H", "2A", ..., "8H"]
getRow(board, rank: 1)
// Returns ["1A", "1B", "1C", "1D", "1E", "1F", "1G", "1H"]
```
