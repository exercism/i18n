# utiliser l'opérateur de coalescence nulle plutôt que IsNullOrEmpty

Au lieu d'utiliser `string.IsNullOrEmpty` pour déterminer s'il faut utiliser le nom par défaut, essaie d'utiliser l'[opérateur de coalescence nulle](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/operators/null-coalescing-operator) pour simplifier le code, et garde à l'esprit la différence de comportement.
