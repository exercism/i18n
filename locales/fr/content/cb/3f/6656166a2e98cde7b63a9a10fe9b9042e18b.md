# Instructions

Dans cet exercice, tu vas jouer avec une voiture télécommandée, que tu as enfin pu t'offrir après avoir économisé assez d'argent.

Les voitures commencent avec une batterie pleine (100 %). Chaque fois que tu fais rouler la voiture avec la télécommande, elle parcourt 20 mètres et vide un pour cent de la batterie.

La voiture télécommandée dispose d'un écran LED sophistiqué qui affiche deux informations :

- La distance totale parcourue, affichée sous la forme : `"Driven <METERS> meters"`.
- La charge restante de la batterie, affichée sous la forme : `"Battery at <PERCENTAGE>%"`.

Si la batterie est à 0 %, tu ne peux plus faire rouler la voiture et l'écran de la batterie affiche `"Battery empty"`.

Tu as six tâches, chacune d'elles portant sur des instances de voiture télécommandée.

## 1. Achète une voiture télécommandée toute neuve

Implémente la méthode (_statique_) `JedliksToyCar.buy()` pour renvoyer une instance de voiture télécommandée toute neuve :

```java
JedliksToyCar car = JedliksToyCar.buy();
```

## 2. Affiche la distance parcourue

Implémente la méthode `JedliksToyCar.distanceDisplay()` pour renvoyer la distance telle qu'elle est affichée sur l'écran LED :

```java
JedliksToyCar car = JedliksToyCar.buy();
car.distanceDisplay();
// => "Driven 0 meters"
```

## 3. Affiche le pourcentage de la batterie

Implémente la méthode `JedliksToyCar.batteryDisplay()` pour renvoyer le pourcentage de la batterie tel qu'il est affiché sur l'écran LED :

```java
JedliksToyCar car = JedliksToyCar.buy();
car.batteryDisplay();
// => "Battery at 100%"
```

## 4. Mets à jour le nombre de mètres parcourus quand tu conduis

Implémente la méthode `JedliksToyCar.drive()` qui met à jour le nombre de mètres parcourus :

```java
JedliksToyCar car = JedliksToyCar.buy();
car.drive();
car.drive();
car.distanceDisplay();
// => "Driven 40 meters"
```

## 5. Mets à jour le pourcentage de la batterie quand tu conduis

Mets à jour la méthode `JedliksToyCar.drive()` pour qu'elle mette à jour le pourcentage de la batterie :

```java
JedliksToyCar car = JedliksToyCar.buy();
car.drive();
car.drive();
car.batteryDisplay();
// => "Battery at 98%"
```

## 6. Empêche la voiture de rouler quand la batterie est vide

Mets à jour la méthode `JedliksToyCar.drive()` pour qu'elle n'augmente plus la distance parcourue et ne diminue plus le pourcentage de la batterie quand la batterie est vide (à 0 %) :

```java
JedliksToyCar car = JedliksToyCar.buy();

// Drain the battery
// ...

car.distanceDisplay();
// => "Driven 2000 meters"

car.batteryDisplay();
// => "Battery empty"
```
