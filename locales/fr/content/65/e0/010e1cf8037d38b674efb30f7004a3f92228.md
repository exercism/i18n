# Contribue via GitHub

Les contributions à la base de code d'Exercism se font via [GitHub][github].

Comme son nom l'indique, GitHub utilise [git][git] comme système de gestion de versions.
Si tu ne connais pas Git, la meilleure ressource en ligne est [Pro Git][pro-git].

Si tu n'es pas encore à l'aise avec GitHub et le _workflow_ de contribution, voici quelques ressources qui pourront t'aider à démarrer :

- [Introduction à GitHub, un cours interactif][github-course]
- [Comment créer une _pull request_ sur GitHub, tutoriel][pr-tutorial]
- [Comment créer une _pull request_ GitHub simple, vidéo d'anthonywritescode][anthonywritescode]

## Guides

Tu peux en savoir plus sur la manière de faire en sorte que ta contribution soit bien accueillie dans le guide [Comment réussir sa _pull request_][great-pr].

Nous avons aussi plusieurs guides de _pull requests_ propres à Exercism :

- [Comment réussir sa _pull request_][how-to-make-a-great-pr]
- [Le guide des contributeurs pour les _pull requests_][contributors-pr-guide]
- [Le guide des mainteneurs pour les _pull requests_][maintainers-pr-guide]
- [Permissions des dépôts pour les mainteneurs][maintainers-repo-permissions]
