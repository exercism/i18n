# À propos

Une définition de type crée un nouveau type nommé, distinct de tous les autres types, même de ceux qui ont le même type sous-jacent.

## Définis des types

Une définition de type commence par le mot-clé `type`, suivi du nom du nouveau type et de son type sous-jacent :

```go
type File []bool
```

Ici, `File` désigne une colonne verticale d'un échiquier, généralement étiquetée de A à H.
Chaque case de cette colonne est représentée par une valeur booléenne indiquant si elle est occupée ou non.
Maintenant que `File` est défini, on peut l'utiliser dans d'autres définitions :

```go
type Chessboard map[string]File

board := Chessboard{
    "A": File{true, false, true},
    "B": File{false, true, false},
}
```

`Chessboard` associe des identifiants de colonne à des valeurs `File`.
Chaque `File` est un _slice_ de booléens représentant les cases d'une colonne de l'échiquier.
Sans ces définitions de type, `board` serait un `map[string][]bool`, ce qui rendrait plus difficile la compréhension de ce que l'on représente.

## Les types définis sont distincts

Bien que `Score` et `int` contiennent tous deux des valeurs entières, passer de l'un à l'autre nécessite une conversion explicite :

```go
type Score int

var number int = 42

// var score Score = number is a compile error
var score Score = Score(number)
var converted int = int(score)
```

`42` est une constante non typée, on peut donc l'affecter directement à une variable `Score`.

Les types définis peuvent aussi avoir des méthodes, qui sont traitées dans le concept Méthodes.

## Les types struct

Les définitions de `struct` utilisent le même mot-clé `type` :

```go
type Player struct {
    Name  string
    Score Score
}
```

Les types struct sont traités dans le concept Structs.

## Les alias de type

Un alias de type crée un autre nom pour un type existant plutôt que de créer un nouveau type.
Comme un alias et son type d'origine sont identiques, leurs valeurs peuvent être utilisées de façon interchangeable.
Les alias se déclarent avec le mot-clé `type`, le nom de l'alias, le signe égal (`=`) et le type existant.

```go
type Square = bool

var isOccupied bool = true
var square Square = isOccupied // no conversion needed
```
