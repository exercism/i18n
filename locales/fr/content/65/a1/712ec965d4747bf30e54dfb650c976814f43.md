# Classes et propriétés en lecture seule

Les classes et propriétés en lecture seule permettent à une classe de définir des propriétés publiques pour y accéder facilement, tout en empêchant leur modification.
Pour déclarer une propriété en lecture seule, il faut placer `readonly` avant la spécification du type.
La propriété ne peut être affectée qu'une seule fois, mais toute tentative de réaffectation ou de modification de la valeur provoquera une Error.

```php
<?php

class Block
{
    public function __construct(
        public readonly int $length,
        public readonly int $width,
    ) {
    }
}
```

Les classes en lecture seule s'appuient sur ce comportement : lorsqu'elles sont déclarées `readonly`, la déclaration en lecture seule s'applique à chaque propriété.
De plus, elles empêchent l'ajout de propriétés dynamiques.

```php
<?php

readonly class Block
{
    public function __construct(
        public int $length,
        public int $width,
    ) {
    }
}
```
