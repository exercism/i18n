# Introduction

Une définition introduite par `:` peut s'appeler elle-même directement. Le compilateur de Factor infère l'effet de pile des mots récursifs comme pour n'importe quel autre mot : aucune déclaration spéciale n'est nécessaire pour une récursion simple.

```factor
: total ( seq -- sum )
    [ 0 ] [ unclip swap total + ] if-empty ;

{ 4 0 9 0 5 } total .    ! => 18
```

Ces deux moitiés correspondent au *cas de base* de la récursion (ici, la séquence vide a pour somme `0`) et à l'*étape récursive* (on retire un élément, on applique la récursion au reste, on combine les résultats).

`if-empty` et `unclip` sont les compagnons canoniques de la récursion sur les séquences. `if-empty ( seq emptyquot nonemptyquot -- )` exécute l'une des deux _quotations_ selon la séquence ; `unclip` retire le premier élément pour que l'étape récursive ait quelque chose de plus simple.
