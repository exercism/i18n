# Instructions

Convertis un nombre octal, représenté sous forme de _string_ (par exemple '1735263'), en son équivalent décimal en repartant des principes de base (autrement dit, non, tu n'as pas le droit d'utiliser des bibliothèques intégrées ou externes pour effectuer la conversion).

Implémente la conversion d'octal en décimal.
À partir d'une _string_ d'entrée en octal, ton programme doit produire une sortie décimale.

## Note

- Implémente la conversion toi-même.
  N'utilise pas autre chose pour faire la conversion à ta place.
- Considère une entrée invalide comme un octal 0.

## À propos de l'octal (base 8)

Le décimal est un système en base 10.

Un nombre comme 233 en notation base 10 peut se comprendre
comme une combinaison linéaire des puissances de 10 :

- Le chiffre le plus à droite est multiplié par 10^0 = 1
- Le nombre suivant est multiplié par 10^1 = 10
- ...
- Le *n*-ième nombre est multiplié par 10^*(n-1)*.
- Toutes ces valeurs sont additionnées.

Ainsi :

```text
   233 # decimal
 = 2*10^2 + 3*10^1 + 3*10^0
 = 2*100  + 3*10   + 3*1
```

L'octal est similaire, mais utilise les puissances de 8 plutôt que les puissances de 10.

Ainsi :

```text
   233 # octal
 = 2*8^2 + 3*8^1 + 3*8^0
 = 2*64  + 3*8   + 3*1
 = 128   + 24    + 3
 = 155
```
