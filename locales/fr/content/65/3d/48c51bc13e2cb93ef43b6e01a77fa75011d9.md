# Apprentissage

Tu veux te lancer avec Groovy, ou en apprendre davantage pendant que tu travailles sur les exercices ?

Essaie Groovy avec

* [un navigateur qui utilise un interprète en ligne](https://www.jdoodle.com/execute-groovy-online)
* [la Groovy Console](http://groovy-lang.org/groovyconsole.html) en tapant `groovyConsole` en ligne de commande
* [le Groovy Shell](http://groovy-lang.org/groovyconsole.html) en tapant `groovysh` en ligne de commande

Fais un tour rapide de Groovy avec

* le [Groovy Tutorial for Java Developers](https://www.timroes.de/2015/06/27/groovy-tutorial-for-java-developers/) de Tim Rows, tout aussi utile pour les développeurs qui ne viennent pas de Java
* [Learn X in Y minutes, Where X=Groovy ](https://learnxinyminutes.com/docs/groovy/)
* les [Groovy Basics](http://docs.smartthings.com/en/latest/getting-started/groovy-basics.html) de SmartThings
* quelques [Groovy Koans en ligne](http://www.groovy-koans.org/) de JDriven

Pour aller plus loin :

* la [documentation Groovy](http://www.groovy-lang.org/documentation.html)
* [Groovy In Action](https://www.manning.com/books/groovy-in-action-second-edition), _le livre_ de référence sur Groovy
* [Making Java Groovy](https://www.manning.com/books/making-java-groovy) de Ken Kousen
