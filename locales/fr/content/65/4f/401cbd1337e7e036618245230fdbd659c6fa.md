# À propos

Il peut être difficile de trouver un langage de programmation plus expressif. [Raku](https://raku.org/) est un langage moderne et multi-paradigme. Raku propose des méthodologies [procédurales](https://docs.raku.org/language/functions), [orientées objet](https://docs.raku.org/language/objects) et de [programmation fonctionnelle](https://docs.raku.org/language/functions#Functions_are_first-class_objects).

[Curieux ?](https://raku.org/) Creuse plus loin dans la [documentation](https://docs.raku.org/) ou dans le [dépôt](https://raku.land/) de modules (comme pypi ou CPAN).

C'est un langage extrêmement [flexible](https://docs.raku.org/language/operators), qui [s'adapte](https://docs.raku.org/language/glossary#gradual_typing) à ton style de programmation, qu'il s'agisse de _[one-liners](https://docs.raku.org/language/create-cli)_ rapides pour les administrateurs système, de scripts pour gérer un import de base de données, ou de toute la pile de modules nécessaire pour créer [tout un site web](https://cro.services/).

Raku apprend d'autres langages :

* Il renforce l'attrait de Perl sur le long terme grâce à un véritable système objet qui inclut les [rôles](https://docs.raku.org/language/typesystem#role), le _[threading](https://docs.raku.org/language/concurrency)_ et la répartition [multi-méthodes](https://docs.raku.org/language/glossary#Multi-dispatch).
* Il reprend le _threading_ de Java, [simplifié](https://docs.raku.org/language/concurrency) à une poignée de méthodes.
* Utiliser les interfaces de [fonctions étrangères](https://docs.raku.org/language/nativecall) venues de Lisp rend l'accès aux bibliothèques aussi simple qu'une ligne de code.
* Les [expressions régulières](https://docs.raku.org/language/regexes) montent désormais jusqu'à 11, avec l'introduction des [grammaires](https://docs.raku.org/language/grammars) d'analyse syntaxique (Parser Expression Grammars), qui permettent de s'attaquer à d'énormes tâches d'analyse.
* Les _strictures_ et les avertissements sont désormais automatiques, ce qui élimine d'énormes pans d'erreurs potentielles.
* ... et il sait faire des [maths](https://docs.raku.org/language/math) : ```1/10 * 3 == 0.3 ```. Essaie donc ça dans ton langage préféré !

Les devises de Raku :
* « Raku est conçu pour rendre faciles les tâches faciles, sans rendre impossibles les tâches difficiles. »
* « Il y a plus d'une façon de le faire, et désormais encore plus, avec le -Ofun (optimisé pour le plaisir) en prime. »
