# Introduction

Go contient des types numériques de base qui peuvent représenter des ensembles de valeurs entières ou à virgule flottante.

Ce concept se concentre sur deux types de nombres :

- `int` : par exemple `0`, `255`, `2147483647`.
   Un entier signé d'au moins 32 bits (plage de valeurs : de -2147483648 à 2147483647).
   Mais cela dépend de l'architecture du système.
   La plupart des ordinateurs modernes sont en 64 bits, donc `int` fait 64 bits (plage de valeurs : de -9223372036854775808 à 9223372036854775807).

- `float64` : par exemple `0.0`, `3.14`.
   Contient l'ensemble de tous les nombres à virgule flottante sur 64 bits.

Go prend en charge l'ensemble standard des opérateurs arithmétiques `+`, `-`, `*`, `/` et `%` (le reste, pas le modulo).

En Go, affecter une valeur d'un type à un autre nécessite une conversion explicite.
Par exemple, pour convertir un `int` en `float64`, il faut procéder comme suit :

```go
var x int = 42
f := float64(x)

fmt.Printf("x is of type: %s\n", reflect.TypeOf(x))
// Output: x is of type: int

fmt.Printf("f is of type: %s\n", reflect.TypeOf(f))
// Output: f is of type: float64
```
