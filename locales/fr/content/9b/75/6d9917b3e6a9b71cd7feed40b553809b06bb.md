# Instructions

Réécris un analyseur syntaxique Markdown.

L'exercice Markdown est un exercice de réécriture.
Il y a du code qui analyse une chaîne de caractères donnée selon la [syntaxe Markdown][markdown] et qui renvoie le HTML correspondant.
Même si ce code est écrit de façon confuse et difficile à suivre, il fonctionne tant bien que mal et tous les tests passent !
Ton défi est de réécrire ce code pour le rendre plus facile à lire et à maintenir, tout en veillant à ce que tous les tests continuent de passer.

Ce serait utile que tu notes dans des commentaires ce que tu as fait lors de ta réécriture, pour que les relecteurs puissent le voir, mais ce n'est pas strictement nécessaire.
Le plus important, c'est d'améliorer le code !

[markdown]: https://guides.github.com/features/mastering-markdown/
