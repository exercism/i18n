# Introduction

Les types C# peuvent être définis dans la portée d'une classe ou d'une structure. Le type englobant fournit une sorte d'espace de noms. L'accès à ce type se fait via le type englobant, avec la syntaxe pointée.

```csharp
class Outer
{
    public interface IInner {}
    public enum EInner {}
    public class CInner {}
    public struct SInner {}
}

var outer = new Outer();
var inner = new Outer.CInner();
```

On peut définir des niveaux d'accès pour les types imbriqués.

Les membres privés du type englobant sont accessibles aux membres du type imbriqué, mais pas l'inverse.
