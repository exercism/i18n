# Instructions

Le club de poésie du quartier entame une nouvelle saison. Les poètes rejoignent le club et, chaque fois que deux d'entre eux coécrivent un poème, ils font partie du même *cercle d'écriture*. Le club veut garder la trace de qui partage un cercle avec qui, et on t'a demandé d'écrire les mots qui s'en chargent.

Un ensemble disjoint est le choix idéal : chaque poète est un atome, et un cercle d'écriture est un groupe.

## 1. Ouvre le club

Définis `new-club`, qui prend une séquence de poètes et renvoie un nouvel ensemble disjoint où chaque poète est enregistré. Chaque poète commence dans son propre cercle d'écriture.

```factor
{ "Keats" "Byron" "Dickinson" } new-club
! => a disjoint set holding the three poets
```

## 2. Enregistre une collaboration

Définis `collaborate`, qui prend deux poètes et un club. Il fusionne les cercles d'écriture des deux poètes et renvoie le club, ce qui permet d'enregistrer les collaborations les unes après les autres.

```factor
{ "Keats" "Byron" "Dickinson" } new-club
"Keats" "Byron" rot collaborate
! => the club, with Keats and Byron now in one circle
```

## 3. Trouve le cercle d'un poète

Définis `circle-of`, qui prend un poète et un club et renvoie le représentant du cercle d'écriture de ce poète. Deux poètes qui partagent un cercle donnent toujours le même représentant.

```factor
{ "Keats" "Byron" "Dickinson" } new-club
"Dickinson" swap circle-of
! => "Dickinson"   (still in a circle of their own)
```

## 4. Partage un cercle ?

Définis `same-circle?`, qui prend deux poètes et un club et renvoie `t` quand les deux poètes appartiennent au même cercle d'écriture et `f` sinon. Compare les représentants des poètes plutôt que d'utiliser un test d'équivalence intégré.

```factor
{ "Keats" "Byron" "Dickinson" } new-club
"Keats" "Byron" rot collaborate
dup [ "Keats" "Byron" ] dip same-circle? .      ! => t
    [ "Keats" "Dickinson" ] dip same-circle? .  ! => f
```
