## MacOS

Commence par installer Lua et [Luarocks][2] avec [Homebrew][1] :

```shell
$ brew install lua luarocks
```

Installe ensuite le _framework_ de tests [Busted][3] pour Lua :

```shell
$ luarocks install --local busted
```

Ajoute `~/.luarocks/bin` au `$PATH` de ton système

```shell
export PATH="$HOME/.luarocks/bin:$PATH"
```

Note que ce n'est que temporaire.
Pour l'ajouter de façon permanente à ton `$PATH`, tu devras l'ajouter à ton `.bashrc`, `.zshrc` ou `config.fish` selon le shell que tu utilises.

Lance ensuite tes tests :

```shell
$ busted
```

## Windows 10 : WSL

Tu dois d'abord activer [WSL (Windows Subsystem for Linux)][7] avec [PowerShell][8] (Administrator) :

```shell
PS> Enable-WindowsOptionalFeature -Online -FeatureName Microsoft-Windows-Subsystem-Linux
```

Un redémarrage est nécessaire.

Ensuite, installe Ubuntu depuis le [Microsoft Store][9], **ou** télécharge-le puis installe-le avec PowerShell :

```shell
PS> curl.exe -L -o ubuntu1804.appx https://aka.ms/wsl-ubuntu-1804
PS> Add-AppxPackage .\ubuntu1804.appx; rm .\ubuntu1804.appx
PS> ubuntu1804
```

Mets ensuite à jour la liste de tes paquets :

```shell
PS> wsl
$ sudo apt-get update
```

Tu es maintenant prêt à installer [LuaRocks][2] et [Busted][3] en suivant les [instructions pour Ubuntu](#ubuntu) ci-dessus.

Une fois cela fait, tu peux lancer tes tests directement depuis n'importe quelle ligne de commande Windows :

```cmd
C:\> wsl busted
```

## Windows 10 : Docker

### Installe Gitbash

Cette étape est facultative. Tu devras peut-être adapter légèrement les étapes suivantes si tu préfères utiliser la CLI native de Windows ou une autre CLI.

Télécharge-le [ici][10].
Instructions d'installation [ici][11].

### Installe Docker

Suis les instructions pour installer [Docker for Windows][12].
Une fois l'installation terminée, tu peux exécuter la commande suivante pour vérifier qu'elle s'est bien déroulée.

```shell
$ docker --version
```

_Il se peut que tu rencontres une erreur en essayant de lancer Docker pour la première fois._

`cannot enable hyper-v service`

_Si cela se produit, tu peux suivre ces instructions pour [activer Hyper V][13]. Tu devras peut-être désactiver le paramètre, redémarrer ton ordinateur et le réactiver après le démarrage._

### Installe busted

Une fois Gitbash et Docker installés, tu pourras installer un « conteneur » busted.

Dans Gitbash, exécute ce qui suit :

Récupère ce conteneur Docker très répandu en exécutant ce qui suit :

```shell
$ docker pull imega/busted
```

Crée une fonction pour ne pas avoir à taper la commande entière à chaque fois.
Ajoute ceci à ton `.bashrc` :

```shell
dbusted() { docker run --rm -t -v "/$@":/data imega/busted; }
```

Maintenant, dans ta CLI, tu peux te déplacer dans le répertoire où tu veux lancer tes tests. Exécute ce qui suit :

```shell
$ dbusted $PWD
```

Tu devrais voir la sortie de tes tests busted.
