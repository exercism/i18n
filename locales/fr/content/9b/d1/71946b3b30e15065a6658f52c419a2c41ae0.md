## Fais connaissance avec « Hello, World! »

« Hello, World! » est probablement le programme le plus célèbre au monde.
Pratiquement toute personne qui a appris à coder l'a écrit au moins une fois.
Sa simplicité et son message convivial marquent souvent le premier pas dans le monde merveilleux de la programmation.

Sur Exercism, on te fournit une fonction nommée `hello` qui renvoie « Goodbye, Mars! ».

```python
def hello():
    return 'Goodbye, Mars!'
```

Ta tâche est de la modifier pour qu'elle renvoie « Hello, World! » à la place.

## L'approche traditionnelle

Pour commencer, nous avons l'approche la plus simple, et celle qu'Exercism espère que tu implémenteras.
Avec un simple changement de la _string_, de « Goodbye, Mars! » à « Hello, World! », on peut maintenant la renvoyer sans problème !

```python
def hello() -> str:
    return 'Hello, World'
```

## Approches alternatives

Je vais résoudre cet exercice en utilisant toutes les méthodes variées auxquelles j'ai pu penser.

Pour les besoins du récit, je vais appeler cette simple fonction la « machine », une machine dont l'unique tâche est de renvoyer un salut « Hello, World! ».

Voyons où cela nous mène... !

### La permutation

Un fort orage est passé et ta pauvre machine malchanceuse a été frappée par la foudre.
Elle s'allume encore, mais elle se comporte bizarrement maintenant.
Tous les caractères pour assembler le message de salutation sont toujours là, mais ils ne sont pas dans l'ordre, et les dégâts sur la carte logique signifient que la machine n'arrive plus à remettre le message dans le bon ordre.
Et comme par malchance, la machine plus petite, incroyablement fiable et *indestructible*, que tu avais construite plus tôt, était en fait volable (oui, elle a disparu !).
Par conséquent, tu décides de laisser ton bon vieux compagnon essayer toutes les façons possibles de mélanger ces lettres pour former le bon message.
Après tout, cela ne fait que 13 caractères et la machine a beaucoup de mémoire. Cela devrait être rapide...

```python
from itertools import permutations

def hello() -> str:
    chars = ['H', 'e', 'l', 'l', 'o', ',', ' ', 'W', 'o', 'r', 'l', 'd', '!']

    all_permutations = permutations(chars)
    for perm in all_permutations:
        if ("".join(perm) == "Hello, World!"):
            return ''.join(perm)
```

### La recherche

Tu as décidé de mettre à jour la machine pour lui permettre de saluer dans différentes langues.
Mais son UNIQUE tâche est de dire « Hello, World! » en anglais, alors dans sa confusion, elle décide de télécharger un nombre incalculable de façons de dire « Hello, World! », chacune avec des majuscules et un placement légèrement différents.
Cela t'a laissé perplexe, sans savoir laquelle choisir, mais au moins elles sont toutes dans un certain ordre.
Tu dois indiquer à la machine la bonne façon de formuler la phrase, pour qu'elle puisse la trouver et redevenir normale (peut-être).


### La classe

Tu décides d'expérimenter et de modifier la machine pour qu'elle se comporte différemment selon le bouton pressé.
Tu as pensé à la rendre plus décontractée, en commençant à dire « Hi », mais comme tu es une personne *classe*, tu décides de n'utiliser toujours que la méthode `hello` et de scotcher l'autre.

```python
salutation = Greeting()
```

### La récursion

Pour une raison quelconque, tu as décidé que ce serait drôle si la machine prenait un peu de retard et ne répondait que 10 secondes plus tard.
Ton frère soulève une fois de plus la question de la logique derrière cette fonctionnalité, car selon lui, tu es le seul à utiliser la machine.

```python
import time

def hello(n=10):
    if n == 0:
        return "Hello, World!"
    else:
        time.sleep(1)
        return hello(n-1)
```

### L'aléatoire

Soudain, un jour, tu te lasses du même salut encore et encore, alors tu décides de la laisser te saluer une dernière fois et de mettre la machine à la retraite pour de bon, sans jamais y retoucher.
Comme la machine t'a accompagné dans les bons comme dans les mauvais moments, et ce depuis longtemps, tu décides de laisser cette dernière rencontre entre « amis » entre les mains du destin.
 Tu l'allumes une dernière fois et tu la laisses tourner...

```python
import random

def hello():
    chars = list("Helo,Wrld!")
    greeting = ""
    while (greeting != "Hello, World!"):
        greeting = "".join(random.choices(chars, k=13))
    return greeting
```
