# Instructions

Le bureau des objets trouvés de l'école range tout dans des boîtes, et ce qui va dans une boîte peut être n'importe quoi : un pull, un nombre, un nom.

Écris une classe `LOST_BOX{T}`. Le squelette te fournit l'en-tête de la classe.

## 1. Prends quelque chose en dépôt

`create` prend la chose et le nom de la personne qui l'a déposée, et renvoie une boîte. Au départ, une boîte n'est pas réclamée.

```sather
box ::= #LOST_BOX{STR}("blue jumper", "Mia");
box.item
-- => "blue jumper"
box.handed_in_by
-- => "Mia"
box.claimed
-- => false
```

## 2. Réclame-la

`claim` marque la boîte comme réclamée. Elle ne renvoie rien.

```sather
box.claim;
box.claimed
-- => true
```

## 3. Est-ce qu'elle attend toujours ?

`waiting` indique si la boîte n'a pas encore été réclamée.

```sather
box.waiting
-- => false
```

## 4. Échange le contenu

`replace` prend une nouvelle chose, la met dans la boîte et renvoie ce qui s'y trouvait avant. Ce qui entre et ce qui sort sont tous les deux de type `T`.

```sather
old ::= box.replace("red jumper");
old
-- => "blue jumper"
box.item
-- => "red jumper"
```

## 5. Rédige le compte rendu

`describe` renvoie une ligne sur la boîte, du genre
`"blue jumper, handed in by Mia"`.

Pour mettre l'élément dans une _string_, la classe doit savoir qu'un `T` peut être converti en une _string_. Impose une contrainte sur le paramètre : écris l'en-tête de la classe sous la forme
`class LOST_BOX{T < $STR}`, et `item.str` devient alors autorisé.

```sather
box.describe
-- => "blue jumper, handed in by Mia"
```
