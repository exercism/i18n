# À propos

En PHP, on peut appeler une variable comme une fonction en lui appliquant des parenthèses [`()`]. Quand PHP tente d'invoquer la fonction, il recherche une fonction portant le même nom que la valeur de la variable.

```php
function foo(): string
{
    return "foo() invoked";
}

$func = 'foo';
$func(); // This calls foo()
```

## Appelle les fonctions statiques d'une classe

Les fonctions statiques d'une classe s'appellent de la même façon :

```php
class Rocket
{
    public static function launch()
    {
        return '3, 2, 1, Liftoff!';
    }
}

$func = 'Rocket::launch';
$func(); // This calls Rocket::launch()
```

## Appelle les fonctions d'une instance de classe

On peut aussi appeler la fonction d'une instance de classe :

```php
class Rocket
{
    public function openDoor()
    {
        return 'Door open.';
    }
}

$rocket = new Rocket();
$func = [$rocket, 'openDoor'];
$func(); // This calls Rocket::openDoor()
```
