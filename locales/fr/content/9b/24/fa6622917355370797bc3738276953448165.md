| Registre | Utilisation | Type    | Description                                     |
| -------- | ----------- | ------- | ----------------------------------------------- |
| `$a0`    | entrée      | adresse | chaîne de caractères d'entrée terminée par zéro |
| `$v0`    | sortie      | entier  | score au Scrabble                               |
| `$t0-9`  | temporaire  | quelconque | pour le stockage temporaire                  |
