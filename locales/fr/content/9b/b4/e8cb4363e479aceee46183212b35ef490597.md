# À propos

## Opérateurs arithmétiques

JavaScript fournit 6 opérateurs différents pour effectuer les opérations arithmétiques de base sur des nombres.

- `+` : l'opérateur d'addition sert à calculer la somme de deux nombres.

  ```javascript
  1 + 2; // => 3
  2.5 + 3.9; // => 6.5
  ```

- `-` : l'opérateur de soustraction sert à calculer la différence entre deux nombres

  ```javascript
  19 - 2; // => 17
  7.4 - 1.2; // => 6.2
  ```

- `*` : l'opérateur de multiplication sert à calculer le produit de deux nombres

  ```javascript
  7 * 5; // => 35
  9.2 * 6.3; // => 57.959999999999994
  ```

- `/` : l'opérateur de division sert à diviser deux nombres.
  Comme les nombres JavaScript sont toujours des nombres à virgule flottante, il n'existe pas de division entière.

  ```javascript
  8 / 2; // => 4
  25 / 3; // => 8.333333333333334
  ```

- `%` : l'opérateur modulo sert à trouver le reste d'une division.

  ```javascript
  40 % 4; // => 0
  11 % 4; // => 3
  -11 % 4; // => -3
  ```

- `**` : l'opérateur d'exponentiation sert à élever un nombre à une puissance.
  C'est l'équivalent d'utiliser [`Math.pow()`][mdn-math-pow]

  ```javascript
  4 ** 3; // => 64
  4 ** 1 / 2; // => 2
  ```

## Ordre des opérations

Lorsqu'on utilise plusieurs opérateurs sur une même ligne, JavaScript suit un ordre de priorité, comme le montre [ce tableau de priorité][mdn-operator-precedence].
Pour simplifier dans notre contexte, JavaScript applique la règle PEDMAS (parenthèses, exposants, division/multiplication, addition/soustraction) que l'on a apprise en cours de maths à l'école primaire.

<!-- prettier-ignore-start -->
```javascript
const result = 3 ** 3 + 9 * 4 / (3 - 1);
// => 3 ** 3 + 9 * 4/2
// => 27 + 9 * 4/2
// => 27 + 18
// => 45
```
<!-- prettier-ignore-end -->

## Opérateurs d'affectation raccourcis

Les opérateurs d'affectation raccourcis permettent d'écrire plus brièvement du code qui effectue des opérations arithmétiques sur une variable, et qui affecte la nouvelle valeur à la même variable.
Par exemple, considérons deux variables `x` et `y`.
Alors, `x += y` équivaut à `x = x + y`.
Souvent, on l'utilise avec un nombre plutôt qu'avec une variable `y`.
Les 5 autres opérations peuvent aussi s'écrire de la même manière.

```javascript
let x = 5;
x += 25; // x is now 30

let y = 31;
y %= 3; // y is now 1
```
