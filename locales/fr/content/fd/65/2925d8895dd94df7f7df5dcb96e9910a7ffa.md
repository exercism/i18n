# Introduction

Les mots les plus utiles pour manipuler les séquences prennent une *quotation* comme l'une de leurs entrées et s'en servent pour piloter l'opération :

```
each   ( seq quot -- )
map    ( seq quot -- newseq )
filter ( seq quot -- newseq )
reject ( seq quot -- newseq )
count  ( seq quot -- n )
any?   ( seq quot -- ? )
all?   ( seq quot -- ? )
```

```factor
{ 1 2 3 4 5 } [ even? ] filter .   ! => { 2 4 }
{ 1 2 3 4 5 } [ sq ] map .         ! => { 1 4 9 16 25 }
{ 1 2 3 4 5 } [ 2 > ] count .      ! => 3
```

`map-sum` (également dans `sequences`) applique une *quotation* à chaque élément de la séquence et additionne les résultats en une seule passe. Le même schéma se retrouve dans `sort-by` (dans [`sorting`][sorting]) et `minimum-by` / `maximum-by` (dans `sequences`).

[sorting]: https://docs.factorcode.org/content/vocab-sorting.html
