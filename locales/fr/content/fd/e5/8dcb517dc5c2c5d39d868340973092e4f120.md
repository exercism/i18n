# Introduction

En Go, une constante est une valeur simple et immuable, à laquelle on donne un nom avec le mot-clé `const` :

```go
const myWebsite = "Exercism"
```

Ces constantes ne sont pas typées, mais un type par défaut leur est attribué d'après leur syntaxe lorsqu'un type est nécessaire, par exemple quand elles sont passées à une méthode.
On peut créer des constantes typées en ajoutant explicitement un type :

```go
const myWebsite string = "Exercism"
```

Go n'a pas d'énumérations comme certains autres langages, mais il dispose d'un identifiant prédéclaré appelé `iota` pour créer des constantes énumérées.
Dans un bloc, les constantes sont implicitement répétées :

```go
const (
    a = 9
    b
    c
    d = iota
    e
    f
    g
)
fmt.Print(a, b, c, d, e, f, g)
// Output: 9 9 9 3 4 5 6
```
