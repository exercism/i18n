# Instructions

Tu es un immense fan de la [chaîne YouTube Numberphile](https://www.youtube.com/watch?v=PeUbRXnbmms) et tu viens de voir une chouette vidéo sur la _suite de Lucas_. Tu veux créer cette suite avec Elixir.

Pendant que tu conçois ta fonction, tu veux tirer parti de l'_évaluation paresseuse_ pour pouvoir générer autant de nombres que tu le souhaites, mais seulement si tu en as besoin. Tu décides donc d'utiliser un _stream_.

## 1. Intercepte les arguments invalides

Ajoute une clause de garde pour lever une erreur si un non-entier ou un entier inférieur à 1 est utilisé pour générer la suite. Faire cela dès la première étape évitera des bugs de récursion infinie dans les étapes suivantes.

```elixir
LucasNumbers.generate("Hello World")
# => ** (ArgumentError) count must be specified as an integer >= 1
```

## 2. Génère les cas de base

Tu sais que la suite possède deux nombres de départ qui ne suivent pas la même règle. Écris deux clauses de cas de base pour renvoyer ces nombres :

```elixir
LucasNumbers.generate(1)
# => [2]

LucasNumbers.generate(2)
# => [2, 1]
```

## 3. Crée le cas généralisé

Pour toute suite de plus de 2 éléments, tu sais qu'il faut additionner les deux nombres précédents pour obtenir le nombre suivant, et ainsi de suite. Écris le cas généralisé.

```elixir
LucasNumbers.generate(3)
# => [2, 1, 3]

LucasNumbers.generate(4)
# => [2, 1, 3, 4]
```
