## Personnaliser et lever des exceptions

Il est parfois nécessaire de [personnaliser](https://docs.python.org/3/tutorial/errors.html#user-defined-exceptions) et de [`raise`](https://docs.python.org/3/tutorial/errors.html#raising-exceptions) des exceptions dans ton code. Dans ce cas, pense à toujours inclure un **message d'erreur explicite** pour indiquer l'origine de l'erreur. Cela rend ton code plus lisible et facilite grandement le débogage.

On peut créer des exceptions personnalisées à l'aide de nouvelles classes d'exceptions (voir [`classes`](https://docs.python.org/3/tutorial/classes.html#tut-classes) pour plus de détails) qui sont généralement des sous-classes de [`Exception`](https://docs.python.org/3/library/exceptions.html#Exception).

Lorsque tu sais que l'origine de l'erreur sera dérivée d'un certain type d'exception, tu peux choisir d'hériter de l'un des [`built in error types`](https://docs.python.org/3/library/exceptions.html#base-classes) de la classe _Exception_. Quand tu lèves l'erreur, tu dois tout de même inclure un message explicite.

Cet exercice en particulier te demande de créer une _exception personnalisée_ à [lever](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement)/« lancer » lorsque la pile n'est pas suffisamment remplie. Les tests ne réussiront que si tu personnalises une exception appropriée, que tu lèves cette exception avec `raise` et que tu inclus des messages d'erreur appropriés.


```python
# subclassing the Exception to create a StackUnderflowError
class StackUnderflowError(Exception):
    """Exception raised when Stack is not full.
       message: explanation of the error.
    """
    def __init__(self, message):
        self.message = message

        
# raising a StackUnderflowError
raise StackUnderflowError("Insufficient number of items in stack")
```

De plus, cet exercice te demande de lever plusieurs `built-in exceptions` accompagnées de messages d'erreur.
Pour lever une `built-in exception` avec un message, écris ce message comme argument du type d'`exception` :

```python
# an example when division by zero is attempted.
raise ZeroDivisionError("divide by zero")

#an example when the operation is undefined.
raise ValueError("undefined operation")
```
