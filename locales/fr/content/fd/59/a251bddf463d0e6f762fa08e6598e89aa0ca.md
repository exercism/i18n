# Instructions

Dans cet exercice, tu vas écrire du code pour analyser la production d'une chaîne de montage dans une usine de voitures. La vitesse de la chaîne de montage peut aller de `0` (arrêt) à `10` (maximum).

À sa vitesse la plus basse (`1`), la chaîne produit `221` voitures par heure. La production augmente linéairement avec la vitesse. Donc, avec une vitesse réglée sur `4`, elle devrait produire `4 * 221 = 884` voitures par heure. Cependant, des vitesses plus élevées augmentent la probabilité que des voitures défectueuses soient produites, et celles-ci doivent alors être mises au rebut.

Tu as trois tâches.

## 1. Calcule le taux de réussite

Implémente la méthode `success_rate()` pour calculer la proportion d'éléments produits sans erreur pour une vitesse donnée. Le tableau suivant montre comment la vitesse influence le taux de réussite :

- `0` : 0 % de taux de réussite.
- `1` à `4` : 100 % de taux de réussite.
- `5` à `8` : 90 % de taux de réussite.
- `9` : 80 % de taux de réussite.
- `10` : 77 % de taux de réussite.

```R
success_rate(10)
# => 0.77
```

## 2. Calcule le taux de production par heure

Implémente la méthode `production_rate_per_hour()` pour calculer le taux de production horaire de la chaîne de montage, en tenant compte de son taux de réussite :

```R
production_rate_per_hour(6)
# => 1193.4
```

Note que la valeur renvoyée est un `double`.

## 3. Calcule le nombre d'éléments fonctionnels produits par minute

Implémente la méthode `working_items_per_minute()` pour calculer combien de voitures fonctionnelles sont produites par minute :

```R
working_items_per_minute(6)
# => 19
```

Note que la valeur renvoyée est un entier : les éléments incomplets ne sont pas comptés.
