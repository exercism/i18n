# Instructions

Dans cet exercice, tu vas traiter des lignes de log.

Chaque ligne de log est une _string_ formatée comme suit : `"[<LEVEL>]: <MESSAGE>"`.

Il existe trois niveaux de log différents :

- `INFO`
- `WARNING`
- `ERROR`

Tu as trois tâches, qui prennent chacune une ligne de log et te demandent d'en faire quelque chose.

## 1. Récupère le message d'une ligne de log

Implémente la fonction `message()` pour qu'elle renvoie le message d'une ligne de log :

```haxe
message("[ERROR]: Invalid operation")
// => "Invalid operation"
```

Les espaces en début et en fin de chaîne doivent être supprimés :

```haxe
message("[WARNING]:  Disk almost full\r\n")/ => "Disk almost full"
```

## 2. Récupère le niveau de log d'une ligne de log

Implémente la fonction `logLevel()` pour qu'elle renvoie le niveau de log d'une ligne de log, en minuscules :

```haxe
logLevel("[ERROR]: Invalid operation")
// => "error"
```

## 3. Reformate une ligne de log

Implémente la fonction `reformat()` qui reformate la ligne de log, en plaçant le message en premier, suivi du niveau de log entre parenthèses :

```haxe
reformat("[INFO]: Operation completed")
// => "Operation completed (info)"
```
