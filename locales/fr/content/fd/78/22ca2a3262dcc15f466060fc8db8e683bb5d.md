# Introduction

Swift dispose d'un ensemble d'instructions qui permettent de modifier le déroulement normal des boucles.
On les appelle des instructions de transfert de contrôle.
Tu as déjà vu `return` ; ce concept en présente d'autres, notamment `continue`, `break` et les étiquettes.
On ne parlera pas de `fallthrough` dans ce concept, mais tu peux en lire plus dans le [livre Swift][fallthrough].

## Continue

Il est parfois nécessaire de passer prématurément à l'itération suivante d'une boucle, sans exécuter le reste des instructions de l'itération en cours.
Le mot-clé `continue` permet de le faire.
Quand `continue` est exécuté, la boucle passe directement à la vérification suivante pour savoir si l'itération suivante peut être lancée, c'est-à-dire le `while` dans les boucles _while_ et _repeat-while_, ou la vérification de la présence d'un autre élément dans la séquence pour les boucles _for-in_.

```swift
count = 1
while count < 6 {
  count += 1
  if count == 4 { continue }
  print(count)
}

// prints:
// 2
// 3
// 5
```

## Break

L'instruction `break` permet de sortir prématurément d'une boucle.
Quand `break` est exécuté, la boucle s'arrête immédiatement et le programme poursuit avec la première instruction qui suit la boucle.

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  if !fruit.count.isMultiple(of: 2) { break }
  print(fruit)
}

// prints:
// banana
// grapes
```

## Étiquettes

Quand des boucles sont imbriquées, il arrive que l'on veuille utiliser `break` ou `continue` pour sortir ou redémarrer les boucles externes qui contiennent la boucle dans laquelle `break` ou `continue` est utilisé.
Dans ce genre de cas, on peut utiliser des étiquettes pour désigner la boucle à quitter ou à redémarrer.
On peut étiqueter une boucle en plaçant un nom suivi de deux-points avant le `while`, le `repeat` ou le `for` qui démarre la boucle.

Pour voir l'effet de cette utilisation des étiquettes, examinons la boucle suivante.

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  print("\n--- \(fruit) ---")
  for letter in fruit {
    guard letter != "n" else { break outerLoop }
    print(letter)
  }
}

// prints:
// --- banana ---
// b
// a
```
