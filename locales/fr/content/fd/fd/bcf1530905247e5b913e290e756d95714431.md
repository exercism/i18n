# Introduction

Un *tas* est une collection qui connaît toujours son plus petit élément et permet de le retirer rapidement : c'est l'implémentation naturelle d'une *file de priorité*. Les tas se trouvent dans le vocabulaire [`heaps`][heaps].

`<min-heap>` construit un tas vide dont la plus petite clé sort en premier ; `<max-heap>` est l'image miroir. Chaque élément est une *valeur* stockée sous une *clé*, et la clé est la priorité :

```
<min-heap> ( -- min-heap )
heap-push  ( value key heap -- )
```

```factor
USING: heaps ;

<min-heap>
"alice" 5 pick heap-push
"bob"   2 pick heap-push
```

Un tas est *muable* : `heap-push` le modifie sur place. `heap-peek` renvoie la valeur et la clé de tête sans les retirer, `heap-pop` les retire et les renvoie, et `heap-pop-all` vide le tas dans une liste d'associations de paires `{ key value }` par ordre de priorité :

```
heap-peek    ( heap -- value key )
heap-pop     ( heap -- value key )
heap-pop-all ( heap -- alist )
```

```factor
USING: heaps kernel prettyprint ;

<min-heap>
"alice" 5 pick heap-push
"bob"   2 pick heap-push
dup heap-peek drop .     ! => "bob"
heap-pop-all .           ! => { { 2 "bob" } { 5 "alice" } }
```

[heaps]: https://docs.factorcode.org/content/vocab-heaps.html
