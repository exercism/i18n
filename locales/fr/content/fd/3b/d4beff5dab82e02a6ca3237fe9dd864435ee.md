# Tests

Pour exécuter les tests depuis le répertoire de l’exercice, lance la commande :

```sh
odin test .
```

Pendant que tu testes, Odin peut « vet » ton code : il peut repérer des choses comme des imports et des variables inutilisés. Lance tes tests avec :

```sh
odin test . -vet
```

Pour plus d’options, consulte `odin test -help`.
