# Tests

Les tests nécessitent que le paquet `{testthat}` soit installé dans R.
Pour exécuter les tests d'un exercice, il suffit de lancer le script `test_<exercise_name>.R` depuis le répertoire de l'exercice.

Pour cela, on peut utiliser [la fonction `auto_test` de testthat](https://testthat.r-lib.org/reference/auto_test.html). Comme le code et les tests d'Exercism se trouvent dans le même dossier, utilise ce même chemin pour les paramètres `code_path` et `test_path`. En ligne de commande, tu peux aussi lancer `Rscript test_<exercise_name>.R`.

Consulte la [page des tests](https://exercism.org/docs/tracks/r/tests) pour plus d'informations.
