# Introduction

## Expressions régulières

Les expressions régulières en Gleam suivent la spécification **PCRE** (**P**erl **C**ompatible **R**egular **E**xpressions), comme dans d'autres langages populaires tels que Java, JavaScript ou Ruby.

Le module `gleam/regexp` du paquet `gleam_regexp` propose des fonctions pour manipuler les expressions régulières.

~~~~exercism/note
Cet exercice part du principe que tu connais déjà la syntaxe des expressions régulières, y compris les classes de caractères, les quantificateurs, les groupes et les captures.

Si tu as besoin de rafraîchir tes connaissances sur les expressions régulières, jette un œil à l'une de ces sources : [Regular-Expressions.info](https://www.regular-expressions.info), [Rex Egg](https://www.rexegg.com/), [RegexOne](https://regexone.com/), [Regular Expressions 101](https://regex101.com/), [RegExr](https://regexr.com/).
~~~~

La façon la plus courante de créer des expressions régulières est d'utiliser la fonction `regexp.from_string`.

```gleam
let assert Ok(re) = regexp.from_string("test")
```

Les fonctions de création d'expressions régulières renvoient une erreur si la syntaxe de l'expression régulière est invalide, c'est pourquoi une assertion `let` est utilisée ici pour s'assurer que l'expression régulière est valide.

La fonction `regexp.check` permet de vérifier si une expression régulière correspond à une _string_.

```gleam
let assert Ok(re) = regexp.from_string("test")

regexp.check(re, "this is a test")
// -> True

regexp.check(re, "this is too")
// -> False
```


### Captures

Si tu souhaites capturer des sous-chaînes avec une expression régulière, tu peux utiliser la fonction `regexp.scan` pour obtenir une liste de correspondances.

```gleam
let assert Ok(re) = regexp.from_string("[oi]n a (\\w+)")
regexp.scan(with: re, content: "I am on a boat in a lake.")
// -> [
//   Match(
//     content: "on a boat",
//     submatches: [Some("boat")]
//   ),
//   Match(
//     content: "in a lake",
//     submatches: [Some("lake")]
//   )
// ]
```

### Modificateurs

Le comportement d'une expression régulière peut être modifié en la créant avec la fonction `regexp.compile` et en lui passant des options.

```gleam
let options = regexp.Options(case_insensitive: True, multi_line: False)
let assert Ok(re) = regexp.compile("[A-Z]", with: options)
regexp.check(re, "abc123")
// -> True
```
