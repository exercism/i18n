# Introduction

Les caractères en Factor sont des entiers, des points de code Unicode, ce qui signifie que les comparaisons numériques `<`, `>`, `=` te donnent directement un ordre sensible à la casse. Le vocabulaire [`unicode`][unicode] ajoute des prédicats qui tiennent compte d'Unicode, ainsi que la conversion de casse d'un seul caractère.

## Prédicats de caractères

```
LETTER?  ( c -- ? )    ! uppercase letter
letter?  ( c -- ? )    ! lowercase letter
Letter?  ( c -- ? )    ! letter, either case
digit?   ( c -- ? )    ! decimal digit
blank?   ( c -- ? )    ! whitespace
```

```factor
USING: unicode ;

CHAR: A LETTER? .    ! => t
CHAR: a letter? .    ! => t
CHAR: 7 digit?  .    ! => t
```

## Conversion de casse

`ch>upper` et `ch>lower` changent la casse d'un seul caractère. Au niveau des _strings_, `>upper` et `>lower` les appliquent à chaque caractère d'une _string_.

```factor
CHAR: a ch>upper .   ! => 65   (which is CHAR: A)
"Hello" >upper .     ! => "HELLO"
```
