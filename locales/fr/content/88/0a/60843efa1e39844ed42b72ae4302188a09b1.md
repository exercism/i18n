# Introduction

En Cairo, les pointeurs intelligents sont des structures de données avancées qui garantissent une gestion sûre et efficace de la mémoire : ils ajoutent des protections aux pointeurs classiques et évitent les problèmes courants, comme le déréférencement d'un pointeur nul ou l'accès à une mémoire non initialisée.

## Qu'est-ce qu'un pointeur intelligent ?

Un pointeur intelligent se comporte comme un pointeur classique, mais il garde la trace de la propriété et garantit un accès sûr à la mémoire, ce qui évite les problèmes comme le déréférencement d'un pointeur nul ou suspendu.

## Les types de pointeurs intelligents

Cairo fournit plusieurs types de pointeurs intelligents, comme `Box<T>` et `Nullable<T>` :

- **`Box<T>`** : stocke les données dans un segment mémoire particulier, ce qui est idéal pour les données volumineuses ou de taille dynamique.
                Il permet de transférer la propriété sans copier les données.
- **`Nullable<T>`** : pointe vers une valeur valide de type `T` ou vers `null`, ce qui est pratique pour gérer des valeurs facultatives.

## La sécurité mémoire

Les pointeurs intelligents aident à éviter les accès mémoire dangereux : la mémoire est libérée automatiquement dès qu'elle n'est plus nécessaire, ce qui réduit le risque de fuites de mémoire.

### Exemple : utiliser `Box<T>` pour les types récursifs

Des pointeurs intelligents comme `Box<T>` permettent de manipuler des types récursifs en toute sécurité, par exemple dans un arbre binaire, en allouant la mémoire efficacement et en évitant la récursion infinie.

```rust
use core::box::{BoxTrait};

#[derive(Copy, Drop)]
enum BinaryTree {
    Leaf: u32,
    Node: (u32, Box<BinaryTree>, Box<BinaryTree>),
}

fn main() {
    let leaf1 = BinaryTree::Leaf(1);
    let leaf2 = BinaryTree::Leaf(2);
    let node = BinaryTree::Node((3, BoxTrait::new(leaf1), BoxTrait::new(leaf2)));
    println!("{:?}", node);
}
```

## Les gains de performance

Les pointeurs intelligents améliorent les performances en passant des références aux données plutôt qu'en copiant de grandes structures, ce qui réduit la surcharge mémoire.

```rust
// `Cart` is a large struct that contains a lot of information
fn pass_pointer(cart: Box<Cart>) {
    let cart = cart.unbox();
    println!("{} is shopping today and bought {} items", cart.buyer, cart.items);
}
```
