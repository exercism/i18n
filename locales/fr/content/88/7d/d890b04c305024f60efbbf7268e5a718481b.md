# Instructions

Ton ami, un artiste en herbe, t'a contacté avec une idée de projet. Combinons sa créativité visuelle et tes compétences techniques. Il est temps de t'essayer à l'[art génératif][generative-art] !

Les contraintes stimulent la créativité et raccourcissent les délais, alors vous avez décidé tous les deux de limiter votre chef-d'œuvre à une seule forme : le cercle. Mais il y aura beaucoup de cercles. Et ils pourront se déplacer ! Tu appelleras ça... des points dansants.

Ton ami voudra sûrement imaginer de nouveaux mouvements élaborés pour les points, alors tu vas commencer par coder une architecture qui te permettra de définir facilement de nouvelles animations par la suite.

## 1. Définis le comportement de l'animation

Chaque module d'animation doit implémenter deux _callbacks_ : `init/1` et `handle_frame/3`. Définis-les dans le module `Animation`.

Définis le _callback_ `init/1`. Il doit prendre un argument de type `opts` et renvoyer soit un tuple `{:ok, opts}`, soit un tuple `{:error, error}`. Les implémentations de ce _callback_ vérifieront si les options fournies sont valides pour ce type d'animation particulier.

Définis le _callback_ `handle_frame/3`. Il doit prendre trois arguments : le point, un numéro de _frame_ et des options. Il doit toujours renvoyer un point. Les implémentations de ce _callback_ modifieront les attributs du point en fonction du numéro de _frame_ courant et des options de l'animation.

## 2. Fournis une implémentation par défaut du _callback_ `init/1`

Le comportement `Animation` doit être facile à intégrer dans d'autres modules en appelant `use DancingDots.Animation`.

Pour cela, implémente la macro `__using__` dans le module `Animation` afin qu'elle définisse le module `Animation` comme comportement de l'autre module. Elle doit aussi fournir une implémentation par défaut du _callback_ `init/1`. Cette implémentation par défaut de `init/1` doit renvoyer les options fournies telles quelles.

```elixir
defmodule MyCustomAnimation do
  use DancingDots.Animation
end

MyCustomAnimation.init(some_option: true)
# => {:ok, [some_option: true]}
```

## 3. Implémente l'animation `Flicker`

Utilise le comportement `Animation` pour implémenter une animation scintillante.

Elle doit utiliser le _callback_ `init/1` par défaut, car elle ne prend aucune option.

Implémente le _callback_ `handle_frame/3`, qui gère une seule _frame_. Si le numéro de _frame_ est un multiple de quatre, la fonction doit renvoyer le point avec la moitié de son opacité d'origine. Pour les autres _frames_, elle doit renvoyer le point inchangé.

Les _frames_ sont numérotées à partir de `1`. Le point passé à `handle_frame/3` est toujours le point dans son état d'origine, pas dans l'état de la _frame_ précédente.

```elixir
dot = %DancingDots.Dot{x: 100, y: 100, radius: 24, opacity: 1}

DancingDots.Flicker.handle_frame(dot, 1, [])
# => %DancingDots.Dot{opacity: 1, radius: 24, x: 100, y: 100}

DancingDots.Flicker.handle_frame(dot, 4, [])
# => %DancingDots.Dot{opacity: 0.5, radius: 24, x: 100, y: 100}
```

## 4. Implémente l'animation `Zoom`

Utilise le comportement `Animation` pour implémenter une animation de zoom.

Cette animation prend une option : la vélocité. La vélocité peut être n'importe quel nombre. Si elle est négative, le point est dézoomé au lieu d'être zoomé.

Implémente le _callback_ `init/1`. Il doit vérifier que les options passées forment une _keyword list_ contenant la clé `:velocity`. La valeur de la vélocité doit être un nombre. Si ce n'en est pas un, renvoie l'erreur `"The :velocity option is required, and its value must be a number. Got: #{inspect(velocity)}"`.

Implémente le _callback_ `handle_frame/3`. Il doit renvoyer le point dont le rayon est augmenté de la vélocité multipliée par le numéro de _frame_ courant moins un.

Les _frames_ sont numérotées à partir de `1`. Le point passé à `handle_frame/3` est toujours le point dans son état d'origine, pas dans l'état de la _frame_ précédente.

```elixir
DancingDots.Zoom.init(velocity: nil)
# => {:error, "The :velocity option is required, and its value must be a number. Got: nil"}

dot = %DancingDots.Dot{x: 100, y: 100, radius: 24, opacity: 1}

DancingDots.Zoom.handle_frame(dot, 1, velocity: 10)
# => %DancingDots.Dot{radius: 24, opacity: 1, x: 100, y: 100}

DancingDots.Zoom.handle_frame(dot, 2, velocity: 10)
# => %DancingDots.Dot{radius: 34, opacity: 1, x: 100, y: 100}
```
