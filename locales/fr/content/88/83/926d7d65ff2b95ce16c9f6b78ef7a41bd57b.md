# Nombres

Crystal possède un type, `Number`, qui est le type de base de tous les types numériques.
Il existe deux sous-types principaux au sein du type Number : [`Int`][int] et [`Float`][float].

`Int` est l'abréviation d'_integer_ et représente les nombres entiers.
`Int` peut être négatif ou positif et ne comporte pas de virgule.

```crystal
1.class
# => Int32

-1.class
# => Int32
```

`Float` représente les nombres avec une virgule.
Les `Float` peuvent être négatifs ou positifs.

```crystal
10.5.class
# => Float64
```

## Conversion entre `Int` et `Float`

Les méthodes 'to_i' et 'to_f' permettent de convertir entre `Int` et `Float`.
Lors de la conversion d'un `Float` en `Int`, le nombre est arrondi vers le bas.

```crystal
1.to_f
# => 1.0

1.0.to_i
# => 1

1.9.to_i
# => 1
```

## Opérateurs arithmétiques

Tu peux utiliser les [opérateurs arithmétiques de base][math] sur les `Int` et les `Float`.
Ces opérateurs sont `+`, `-`, `*`, `/` et `%`.
Avec eux, tu peux mélanger des `Int` et des `Float`.

### Addition, soustraction et multiplication

L'opérateur `+` sert à l'addition, l'opérateur `-` à la soustraction et l'opérateur `*` à la multiplication.

| Opérateur | Exemple        |
| -------- | -------------- |
| `+`      | `4 + 6 => 10`  |
| `-`      | `15 - 10 => 5` |
| `*`      | `2 * 3 => 6`   |

### Division

La division permet de diviser des nombres.
L'opérateur `/` sert à la division.
Le résultat est toujours un `Float`.

```crystal
4 / 2
# => 2.0

4.0 / 2
# => 2.0
```

~~~~exercism/caution
Dans certains langages de programmation, une division par zéro produit une erreur.

En Crystal, une division par zéro donne `Infinity` ou `-Infinity`.
La seule exception est la division de zéro par zéro, qui donne `NaN` (Not a Number, soit « pas un nombre »).
`Infinity` et `NaN` sont des valeurs particulières du type `Float`.

```crystal
1 / 0
# => Infinity

-1 / 0
# => -Infinity

0 / 0
# => NaN
```
~~~~

### Modulo

Le modulo permet d'obtenir le reste d'une division.
L'opérateur `%` sert au modulo.

```crystal
5 % 2
# => 1

5.0 % 2
# => 1.0

5 % 3
# => 2
```

~~~~exercism/caution
Une division par zéro avec le modulo lève une erreur `DivisionByZeroError`.
C'est différent de la division normale.

```crystal
1 % 0
# Error: Unhandled exception: Division by 0 (DivisionByZeroError)
```
~~~~

## Arrondi

La méthode `round` prend un argument facultatif : le nombre de décimales souhaité pour l'arrondi.
Le nombre de décimales par défaut est 0.

```crystal
1.0.round
# => 1

1.5.round
# => 2

1.234.round(2)
# => 1.23
```

## Priorité et parenthèses

Crystal autorise les parenthèses (`()`), qui permettent de regrouper des expressions.
C'est utile quand tu veux changer l'ordre des opérations.

Quand on utilise plusieurs opérateurs arithmétiques, l'ordre des opérations est le même qu'en mathématiques, également appelé [PEMDAS][pemdas].
Il suit l'ordre des parenthèses (`()`), des exposants (`**`), de la multiplication (`*`) et de la division (`/`), puis de l'addition (`+`) et de la soustraction (`-`).

```crystal
2 + 3 - 4 * 4
# => -11

(2 + 3 - 4) * 4
# => 4
```
