# Tri

Mettre les choses dans l'ordre est suffisamment courant pour que la bibliothèque s'en charge pour toi.

```sather
   scores : ARRAY{INT} := |3, 1, 2|;
   scores.sort;              -- 1, 2, 3
```

`sort` fonctionne sur tout ce qui sait déjà se comparer : les nombres et les _strings_ y arrivent, parce qu'ils ont un `is_lt`.

## Trie selon ta propre règle

La plupart des ordres ne sont pas celui fourni par défaut. Le classement d'un championnat de netball n'est ni alphabétique ni basé sur la longueur des noms : il se fait par points, puis par différence de buts pour les équipes à égalité de points. `ARRAY` n'a aucun moyen de le deviner.

Tu passes donc l'ordre, sous la forme d'une routine liée :

```sather
   before(a, b : STR) : BOOL is
      return a.size < b.size;
   end;

   ...

   words.insertion_sort_by(bind(before(_, _)));
```

`insertion_sort_by` prend un `ROUT{T,T}:BOOL`, c'est-à-dire une routine qui prend deux des éléments à trier et qui répond si le premier doit venir avant le second. Elle appelle cette routine aussi souvent que nécessaire et range le tableau dans l'ordre qu'impliquent les réponses.

Voilà à quoi servait `understudy`. La bibliothèque sait trier, mais ne connaît rien à ton idée de l'ordre ; c'est dans la routine liée que les deux se rejoignent.

## Écrire la comparaison

La routine répond **vrai quand le premier argument vient en premier**.

```sather
   -- shortest first
   return a.size < b.size;

   -- longest first: turn it round
   return a.size > b.size;
```

Pour une règle qui comporte plusieurs parties, traite-les par ordre d'importance :

```sather
   higher(a, b : TEAM) : BOOL is
      if a.points /= b.points then
         return a.points > b.points;      -- more points comes first
      end;
      return a.difference > b.difference; -- level: better difference wins
   end;
```

Le premier `if` tranche dès que les points diffèrent. Ce n'est que lorsqu'ils sont égaux que la seconde ligne entre en jeu. Écrire d'abord le critère de départage reviendrait à ce que les points ne comptent jamais.

## Le tri modifie le tableau

`insertion_sort_by` range le tableau lui-même dans l'ordre et ne renvoie rien :

```sather
   teams.insertion_sort_by(bind(higher(_, _)));   -- teams is now sorted
```

Si l'ordre d'origine a de l'importance, trie une copie :

```sather
   ranked ::= teams.copy;
   ranked.insertion_sort_by(bind(higher(_, _)));
   return ranked;
```
