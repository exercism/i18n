# Introduction

Au-delà des classes de caractères et des quantificateurs, les expressions régulières peuvent décrire la *structure* et le *contexte*. Ces fonctionnalités font partie du même vocabulaire [`regexp`][regexp] et du même littéral `R/ /`.

Les parenthèses `( )` regroupent une partie d'un motif pour qu'un quantificateur ou un `|` (« ceci ou cela ») s'applique à tout le groupe ; un `?` après un groupe le rend facultatif :

```factor
USING: regexp ;

"abab"    R/ (ab)+/ matches? .             ! => t
"$100"    R/ \$\d+(\.\d{2})?/ matches? .   ! => t   (optional group)
```

Les ancres fixent un motif à une position : `^` (début), `$` (fin) et `\b` (une limite de mot).

Un _lookaround_ effectue une correspondance d'après ce qui entoure un endroit, sans le consommer :

```
(?=...)    ! lookahead — ... must follow
(?!...)    ! negative lookahead — ... must not follow
(?<=...)   ! lookbehind — ... must come before
```

```factor
USING: regexp ;

"spent $100 and $25" R/ (?<=\$)\d+/ all-matching-subseqs .
! => { "100" "25" }

"up 5% then 12%" R/ \d+(?=%)/ all-matching-subseqs .
! => { "5" "12" }
```

Une lettre d'option après le `/` fermant modifie tout le motif ; `i` le rend insensible à la casse :

```factor
USING: regexp ;

"REFUND" R/ refund/i matches? .   ! => t
```

Factor utilise le _lookaround_ à la place des groupes de capture : il ne dispose pas de l'extraction par groupes de capture, des rétroréférences ni des quantificateurs paresseux.
