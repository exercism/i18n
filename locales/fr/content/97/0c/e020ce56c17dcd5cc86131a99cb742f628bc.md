# Instructions supplémentaires

## Implémentation

Le parcours Crystal ajoute un test optionnel pour vérifier que les lettres possibles peuvent être n'importe quel caractère Unicode, et pas seulement des lettres alphabétiques ASCII.
Ces tests ne sont pas accessibles depuis l'éditeur en ligne, mais sont activés par défaut lorsqu'on les exécute en local.

Pour désactiver ces tests, ajoute l'option suivante lors de l'appel de l'exécuteur de tests : `--tag "~optional"`
