# Instructions

Dans cet exercice, tu vas écrire du code pour t'aider à te préparer à acheter un véhicule.

Tu as trois tâches : une pour déterminer si tu as besoin d'un permis, une pour t'aider à choisir entre deux véhicules, et une pour estimer le prix acceptable d'un véhicule d'occasion.

## 1. Détermine si tu auras besoin d'un permis de conduire

Certains types de véhicules nécessitent un permis de conduire pour être conduits.
Suppose que seuls les types `"car"` et `"truck"` nécessitent un permis ; tout le reste peut être conduit sans permis.

Implémente la fonction `needs_license(kind)` qui prend le type de véhicule sous forme de _string_ et renvoie un booléen indiquant si tu as besoin d'un permis pour ce type de véhicule.

```cpp
needs_license("car")
// => true

needs_license("bike")
// => false

needs_license("truck")
// => true
```

## 2. Choisis entre deux véhicules potentiels à acheter

Tu évalues les véhicules disponibles.
Tu réussis à réduire ton choix à deux options, mais tu as besoin d'aide pour prendre la décision finale.
Pour cela, implémente la fonction `choose_vehicle(option1, option2)` qui prend deux véhicules en arguments et renvoie une décision qui inclut l'option qui vient en premier dans l'ordre lexicographique.

```cpp
choose_vehicle("Wuling Hongguang", "Toyota Corolla")
// => "Toyota Corolla is clearly the better choice."

choose_vehicle("Volkswagen Beetle", "Volkswagen Golf")
// => "Volkswagen Beetle is clearly the better choice."
```

La _string_ renvoyée doit suivre le modèle "<CHOSEN_VEHICLE> is clearly the better choice.", où `<CHOSEN_VEHICLE>` est l'option choisie parmi les arguments passés.

## 3. Calcule une estimation du prix d'un véhicule d'occasion

Maintenant que tu as pris ta décision, tu veux t'assurer d'obtenir un prix équitable chez le concessionnaire.
Comme tu souhaites acheter un véhicule d'occasion, le prix dépend de l'âge du véhicule.
Pour une estimation approximative, suppose que si le véhicule a moins de 3 ans, il coûte 80 % de son prix d'origine lorsqu'il était neuf.
S'il a au moins 10 ans, il coûte 50 %.
Si le véhicule a au moins 3 ans mais moins de 10 ans, il coûte 70 % de son prix d'origine.

Implémente la fonction `calculate_resell_price(original_price, age)` qui applique cette logique à l'aide de `if`, `else if` et `else` (il existe d'autres façons de faire si tu veux t'entraîner).
Elle prend le prix d'origine et l'âge du véhicule en arguments et renvoie le prix estimé chez le concessionnaire.

```cpp
calculate_resell_price(1000, 1)
// => 800

calculate_resell_price(1000, 5)
// => 700

calculate_resell_price(1000.0, 15)
// => 500
```

> Note : la valeur de retour est de type `double`.
