# Ajout aux instructions

## Implémentation

Pour terminer cet exercice, tu dois créer le type de données `LinkedList` et implémenter les fonctions suivantes :

- `new`
- `cons`
- `nil`
- `fromList`
- `head`
- `tail`
- `isNil`
- `reverseLinkedList`
- `toList`

Tu trouveras une déclaration de type factice ainsi que les signatures de types déjà en place, mais c'est à toi de définir les fonctions et de créer un type de données qui a du sens.
