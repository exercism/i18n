# Introduction

## Les nombres à virgule flottante

Un nombre à virgule flottante est un nombre qui comporte zéro ou plusieurs chiffres après le séparateur décimal. Par exemple `-2.4`, `0.1`, `3.14`, `16.984025` et `1024.0`.

Les différents types à virgule flottante peuvent stocker un nombre différent de chiffres après le séparateur décimal, ce qu'on appelle leur précision.

C# dispose de trois types à virgule flottante :

- `float` : 4 octets (précision d'environ 6 à 9 chiffres). S'écrit `2.45f`.
- `double` : 8 octets (précision d'environ 15 à 17 chiffres). C'est le type le plus courant. S'écrit `2.45` ou `2.45d`.
- `decimal` : 16 octets (précision de 28 à 29 chiffres). Il sert généralement à manipuler des données monétaires, car sa précision réduit le risque d'erreurs d'arrondi. S'écrit `2.45m`.

Comme on peut le voir, chaque type peut stocker un nombre de chiffres différent. Par exemple, si on essaie de stocker PI dans un `float`, seules les 6 premières décimales seront conservées (le dernier chiffre stocké étant arrondi).

## Les boucles `while`

Dans cet exercice, tu voudras peut-être utiliser une boucle. Il y a plusieurs façons d'écrire des boucles en C#, mais la boucle `while` est la plus appropriée ici :

```csharp
int x = 23;

while (x > 10)
{
    // Execute logic if x > 10
    x = x - 2;
}
```

## Les boucles `do`/`while`

Si le code d'une boucle doit toujours être exécuté au moins une fois, on peut utiliser une boucle `do`/`while` :

```csharp
int x = 23;

do
{
    // Execute body, repeating only if x > 10
    x = x - 2;
} while (x > 10);
```
