# À propos

Pour exécuter une logique de façon répétée, on peut utiliser des boucles. L'un des types de boucles les plus courants en C# est la boucle `while`, qui continue de boucler jusqu'à ce qu'une condition booléenne soit évaluée à `false`.

```csharp
int x = 23;

while (x > 10)
{
    // Execute logic if x > 10
    x = x - 1;
}
```
