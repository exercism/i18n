# Tests

Pour lancer les tests avec DrRacket, il suffit d'ouvrir le fichier de test et de cliquer sur le bouton « Run » en haut à droite.

Pour lancer les tests en ligne de commande, exécute-les depuis le répertoire de l'exercice avec la commande suivante :

```
raco test <exercise>-test.rkt
```

où `<exercise>` doit être remplacé par le slug de l'exercice.
