# Ajout aux instructions

## Informations spécifiques à Arturo

Dans cet exercice, on attend de toi que tu renvoies les âges à l'aide d'une [grandeur physique][physical-quantities] dotée d'une unité personnalisée représentant la durée d'une seule année sur cette planète.
En Arturo, une quantité se compose d'une valeur numérique et d'une [unité de mesure][unit-of-measurement] associée.

```arturo
length: 10`m
units length ; `m
scalar length ; 10

10`m * 10`m ; 100 m²
```

~~~~exercism/caution
L'unité `yr intégrée à Arturo se convertit en 31556952 secondes.
Tu devras donc définir et utiliser ta propre unité d'année, en fonction du nombre de secondes mentionné précédemment dans les instructions.
~~~~

Les quantités peuvent être [converties][convert] vers une autre unité compatible.
```arturo
convert 1`m `ft ; 1250/381 ft
convert 100`m2 `ft2 ; 156250000/145161 ft²

property `m  ; length
property `m2 ; area

convert 1`m `m2 ; conversion error results
```

~~~~exercism/note
En raison des limites de précision des nombres à virgule flottante, Arturo stocke parfois la valeur scalaire sous forme de nombre rationnel.
La [fonction `to`][to] permet de récupérer la quantité sous forme de nombre à virgule flottante approché.

```arturo
length: convert 1`m `ft ; 1250/381 ft
to :floating length ; 3.280839895013123
```

[to]: https://arturo-lang.io/documentation/library/types/to/
~~~~

Arturo permet aussi de [spécifier][specify] ses propres unités pour les quantités.

```arturo
specify 'nauMile 1.151`mi
property `nauMile length
specify 'lea 3.00579`nauMile
property `lea ; length
depth: 20000`lea
convert depth `km ; 111355.7993425152 km
```
