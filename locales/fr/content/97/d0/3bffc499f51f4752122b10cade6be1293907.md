# À propos

Les [dictionnaires][dictionaries] sont l'un des principaux types de collection de Swift.
Un dictionnaire stocke des associations sans ordre entre des clés uniques et les valeurs correspondantes.
Toutes les clés d'un dictionnaire doivent être du même type, et toutes les valeurs doivent elles aussi partager le même type.

Les littéraux de dictionnaire s'écrivent sous la forme d'une suite de paires `key: value` séparées par des virgules et entourées de crochets :

```swift
var addresses: Dictionary<String, String> = [
    "The Munsters": "1313 Mockingbird Lane",
    "The Simpsons": "742 Evergreen Terrace",
    "Buffy Summers": "1630 Revello Drive"
]

var sequences: [String: [Int]] = [
    "Euler's totient": [1, 1, 2, 2, 4, 2, 6, 4],
    "Lazy caterer": [1, 2, 4, 7, 11, 16, 22, 29, 37],
    "Carmichael": [561, 1105, 1729, 2465, 2821, 6601, 8911, 10585, 15841]
]

let constants = [
    "pi": 3.14159,
    "e": 2.71828,
    "phi": 1.618033,
    "avogadro": 6.02214076e23
]
```

Les types des dictionnaires peuvent s'écrire explicitement de deux façons : `Dictionary<Key, Value>` ou la syntaxe abrégée `[Key: Value]`.

Pour créer un dictionnaire vide, précise explicitement les types de ses clés et de ses valeurs :

```swift
var emptyDict1: [Int: Int] = [:]
var emptyDict2 = [Character: String]()
var emptyDict3 = Dictionary<Int, Double>()
```

## Accède aux valeurs

On peut accéder aux valeurs à l'aide de la notation d'indice : place la clé entre crochets après le nom du dictionnaire.
Comme une clé peut ne pas être présente dans le dictionnaire, l'accès par indice renvoie un type *optionnel* (`Value?`).
Si la clé est présente, Swift renvoie la valeur encapsulée ; sinon, il renvoie `nil` :

```swift
let munster: String? = addresses["The Munsters"]
// Returns Optional("1313 Mockingbird Lane")

let carmichael = sequences["Carmichael"]
// Returns Optional([561, 1105, 1729, 2465, 2821, 6601, 8911, 10585, 15841])

let planck = constants["planck"]
// Returns nil
```

Pour éviter de manipuler des optionnels, on peut fournir une valeur par défaut à l'aide du paramètre `default` :

```swift
let e: Double = constants["e", default: 0]
// Returns 2.71828

let hoagie: [Int] = sequences["Hoagie", default: []]
// Returns []

let betty = addresses["Betty Cooper", default: "Address unknown"]
// Returns "Address unknown"
```

## Modifie les dictionnaires

Pour les dictionnaires mutables déclarés avec `var`, on peut ajouter ou mettre à jour des paires clé-valeur à l'aide d'une affectation par indice :

```swift
sequences["Euler's totient"]?.append(contentsOf: [6, 4])
// sequences["Euler's totient"] is now [1, 1, 2, 2, 4, 2, 6, 4, 6, 4]

addresses["Betty Cooper"] = "111 Queens Ave."
addresses["Betty Cooper", default: "Address unknown"]
// Returns "111 Queens Ave."

constants["Gelfond's"] = 23.140692
// Compiler error: Cannot assign through subscript: 'constants' is a 'let' constant
```

## Parcours un dictionnaire

On peut parcourir une à une les paires clé-valeur d'un dictionnaire à l'aide d'une boucle `for-in`.
Chaque élément est fourni sous la forme d'un tuple `(key, value)` :

```swift
for (name, address) in addresses {
    print("\(name) lives at \(address)")
}
```

## Trie les dictionnaires

Comme les dictionnaires ne sont pas ordonnés, les trier produit un tableau de paires clé-valeur.
On peut passer une fermeture à la méthode `sorted(by:)`, qui compare deux tuples `(key, value)` et renvoie `true` si le premier tuple doit apparaître avant le second :

```swift
func sortByNameLengthThenValue(_ lhs: (key: String, value: Double), _ rhs: (key: String, value: Double)) -> Bool {
    let left = lhs.value + Double(lhs.key.count)
    let right = rhs.value + Double(rhs.key.count)
    return left < right
}

let sortedConstants = constants.sorted(by: sortByNameLengthThenValue)
```
