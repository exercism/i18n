# Indices

## 1. Obtenir les permissions par défaut pour un type de compte

- Définis l'énumération `Permission` avec des valeurs pour les types de permission suivants : `None`, `Read`, `Write` et `Delete`.
- Utiliser les indicateurs de l'énumération permettrait d'utiliser d'emblée les opérations bit à bit sur l'énumération `Permission`, [voir `enum` `Flags`][docs-enum-flags].
- Le membre `All` de l'énumération peut être défini comme une combinaison des membres `Read`, `Write` et `Delete`.
- Définis l'énumération `AccountType` avec des valeurs pour les types de compte suivants : `Guest`, `User` et `Moderator`.
- Pour gérer chaque type de compte, on pourrait utiliser une instruction `if`, mais l'[instruction `switch`][docs.microsoft.com-switch-keyword] est une excellente alternative.
- Combiner des indicateurs revient à mettre un bit précis à `1` en utilisant l'un des [opérateurs bit à bit][docs.microsoft.com-bitwise-and-shift-operators].

## 2. Accorder une permission

- Combiner des indicateurs revient à mettre un bit précis à `1` en utilisant l'un des [opérateurs bit à bit][docs.microsoft.com-bitwise-and-shift-operators].

## 3. Révoquer une permission

- Retirer un indicateur revient à mettre un bit précis à `0` en combinant deux [opérateurs bit à bit][docs.microsoft.com-bitwise-and-shift-operators].

## 4. Vérifier une permission

- Vérifier une permission peut se faire en examinant le résultat de l'application de l'un des [opérateurs bit à bit][docs.microsoft.com-bitwise-and-shift-operators].
