# Indices

## 1. Lis les adresses e-mail depuis un fichier

- La [fonction `simplifile.read`][file-read] permet de lire le contenu d'un fichier.

## 2. Crée un fichier de _log_ dans lequel écrire

- La [fonction `simplifile.create_file`][file-create] permet de créer un fichier vide.

## 3. Enregistre un e-mail envoyé

- La [fonction `simplifile.append`][file-append] permet d'ajouter du texte à un fichier.

## 5. Envoie la _newsletter_

- Toutes les opérations nécessaires sur les fichiers ont déjà été implémentées dans les étapes précédentes.
- La [fonction `result.try`][result-try] et la [fonction `list.try_each`][list-try-each] permettent de manipuler le type `Result`.
