# Indices

## Général

- Lis la section sur la composition de fonctions dans le [manuel][function-composition-manual].
- Parcours les [méthodes disponibles pour les _Strings_][string-methods].

## 1. Nettoie le nom

- Il existe une [méthode intégrée][string-replace] pour remplacer toutes les occurrences d'une sous-chaîne dans une _string_.
- Il existe une [méthode intégrée][string-strip] pour supprimer les espaces en début et en fin de _string_.

## 2. Récupère la première lettre du nom

- Pour récupérer un caractère précis d'une _string_, tu peux utiliser l'[accès par indice][string-indexing].
- La façon la plus élégante d'écrire cela est d'utiliser l'opérateur de composition `∘`.

## 3. Formate la première lettre en initiale

- Il existe une [méthode intégrée][string-uppercase] pour convertir tous les caractères d'une _string_ en majuscules.

## 4. Mets les initiales à l'intérieur du cœur

- Tu peux utiliser des caractères Unicode dans les _strings_ en écrivant `'\u<id>'`, où, pour l'emoji cœur, l'id est `2764`.
- Tu peux le faire par [concaténation][string-concatenation] ou par [interpolation][string-interpolation].
