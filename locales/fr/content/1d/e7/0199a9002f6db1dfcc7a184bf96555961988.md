# À propos

## Instructions conditionnelles

Les instructions conditionnelles sont des instructions de prise de décision qui peuvent soit exécuter des effets de bord, soit contrôler le flux d'exécution d'un programme.
Parmi les instructions conditionnelles, on trouve les instructions `if`, `if/else`, `switch` et `ternary`.

On utilise les instructions conditionnelles pour poser des questions sur une valeur ou sur une relation entre plusieurs valeurs.
La question s'évalue en une réponse booléenne, mais l'instruction `if` elle-même peut renvoyer n'importe quelle valeur, ou simplement exécuter un effet de bord.

## Instructions `if`

L'instruction `if` la plus simple évalue une expression et exécute une seule ligne.
L'expression testée est toujours placée entre parenthèses.

Elle peut exécuter un effet de bord :

```c
if (count > 10)
    printf("count is greater than 10");
```

ou bien modifier le flux d'exécution :


```c
if (count > 10)
    return sum;
```

Si une instruction `if` exécute plus d'une ligne, elle doit regrouper ces lignes entre accolades :

```c
if (count > 10) {
    printf("count is greater than 10");
    return sum;
}
```

Certaines équipes de développement peuvent imposer comme convention que les instructions `if` utilisent toujours des accolades, même pour une seule ligne.


## Instructions `if` / `else`

Une instruction `if` peut être associée à un `else` :

```c
if (number % 2 == 0)
    return "even";
else
    return "odd";
```

## Instructions `if` / `else if`


Un `else` peut être associé à un autre `if` pour former ce qu'on appelle un `if-else-if ladder`.

```c
if (number == 0)
    return "zero";
else if (number < 0)
    return "negative";
else if (number < 10)
    return "single digit";   
else if (number % 2 == 0)
    return "even";
else
    return "odd";
```

## Instructions `switch`


Parfois, un `if-else-if ladder` est mieux représenté par une instruction `switch`.
Comme pour `if`, l'expression testée est toujours placée entre parenthèses.

```c
switch (number) {
    case -1:
        return "negative one";
    case 0:
        return "zero";
    case 1:
        return "positive one";
    case 10:
        return "positive ten";
    case -10:
        return "negative ten";
    default:
        return "don't care";
}
```

Le cas `default` s'exécute si la valeur testée ne correspond à aucun des cas précédents.

Si un cas d'une instruction `switch` ne renvoie pas de valeur, on insère généralement un `break` pour terminer chaque cas, sinon la logique « tombe » dans le cas suivant.
Il arrive que cette chute soit intentionnelle :

```c
switch (number) {
    case 0:
        msg = "zero"; break;
    case 1:
        msg = "one"; break;
    case 2: case 3: case 4:
        msg = "more than one and less than five"; break;
    default:
        msg = "don't care";
}
```

Quand cette chute se produit par inadvertance, c'est un bug.

```c
switch (number) {
    case 0:
        msg = "zero"; // bug! fallthrough of 0 will set msg to "one"
    case 1:
        msg = "one"; break; 
    case 2: case 3: case 4:
        msg = "more than one and less than five"; break;
    default:
        msg = "don't care";
}
```

Une instruction `switch` peut être avantageuse lorsqu'on teste des valeurs précises plutôt qu'une plage de valeurs.
Elle peut être plus rapide qu'un `if-else-if ladder`, car le compilateur peut optimiser l'instruction `switch` d'une manière dont il est incapable avec une échelle.
Une instruction `switch` peut aussi parfois sembler plus lisible qu'une échelle.

## Opérateur ternaire (aussi appelé opérateur conditionnel)

L'opérateur ternaire est une instruction conditionnelle en trois parties, souvent utilisée pour affecter une valeur.
L'expression à tester se place avant le point d'interrogation et n'a pas besoin d'être entre parenthèses.
La valeur renvoyée si l'expression est vraie se place avant les deux-points, et celle renvoyée si elle est fausse se place après.
On peut renvoyer aussi bien un littéral qu'une variable.

```c
int i = j > 5 ? 5: j;
```

On peut imbriquer les opérateurs ternaires pour réduire l'encombrement syntaxique.

```c
// the below could also be 
i = j > 5 ? j :k > 5 ? k: 10;
// but that may not be quite as readable

i = j > 5 ? j
    :k > 5 ? k
    :10;

// which is the same as
if (j > 5) i = j;
else if (k > 5) i = k;
else i = 10;
```

## Comparaisons conditionnelles pour les nombres à virgule flottante

En raison de la façon dont les nombres à virgule flottante sont implémentés, une simple opération mathématique peut produire une erreur d'arrondi, ce qui peut faire qu'un test d'égalité ne renvoie pas le résultat attendu.

```c
    a = 1.345f;
    b = 1.123f;
    c = a + b;
    // c may equal something like 2.4679999352
    if (c == 2.468)
        return "I won the lottery!";
```

On peut utiliser une valeur de tolérance, appelée `epsilon`, pour déterminer une plage dans laquelle une valeur peut se situer tout en étant considérée comme égale à une autre.
Certaines plateformes proposent des constantes intégrées pour les epsilon des `float` et des `double`.
Consulte la documentation de ton compilateur pour en savoir plus.
Le calcul de l'epsilon peut être complexe et varie selon les plateformes, voire selon les machines.
Voici un exemple de programme qui utilise une comparaison simple.

```c
#include <stdio.h>
#include <math.h>
#include <stdbool.h>

const double MY_EPSILON = .002;

bool same(double x, double y)
{
    return fabs(x - y) < MY_EPSILON;
}

int main()
{
    // Same should return true if the difference is less than MY_EPSILON
    printf("%s\n", same(1.1, 1.099) ? "true" : "false"); // prints true
    printf("%s\n", same(1.1, 1.098) ? "true" : "false"); // prints false
    return 0;
}
```

Méfie-toi des comparaisons d'égalité entre des `float`s ou des `double`s !
