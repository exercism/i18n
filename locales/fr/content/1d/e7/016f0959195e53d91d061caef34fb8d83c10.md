# Instructions

Le kata du diamant prend en entrée une lettre et l'affiche sous la forme d'un diamant. À partir d'une lettre, il affiche un diamant qui commence par 'A', avec la lettre fournie au point le plus large.

## Contraintes

* La première ligne contient un seul 'A'.
* La dernière ligne contient un seul 'A'.
* Toutes les lignes, sauf la première et la dernière, contiennent exactement deux lettres identiques.
* Toutes les lignes ont autant d'espaces de fin que d'espaces de début. (Cela peut être 0).
* Le diamant est symétrique horizontalement.
* Le diamant est symétrique verticalement.
* Le diamant a une forme carrée (la largeur est égale à la hauteur).
* Les lettres forment une forme de diamant.
* La moitié supérieure contient les lettres dans l'ordre croissant.
* La moitié inférieure contient les lettres dans l'ordre décroissant.
* Les quatre coins (qui contiennent les espaces) sont des triangles.

## Exemples

Dans les exemples suivants, les espaces sont représentés par des caractères `·`.

Diamant pour la lettre 'A' :

```text
A
```

Diamant pour la lettre 'C' :

```text
··A··
·B·B·
C···C
·B·B·
··A··
```

Diamant pour la lettre 'E' :

```text
····A····
···B·B···
··C···C··
·D·····D·
E·······E
·D·····D·
··C···C··
···B·B···
····A····
```
