# Instructions

Dans cet exercice, tu vas implémenter la logique de quête d'un nouveau jeu de rôle développé par un ami.

Le personnage principal du jeu est Annalyn, une jeune fille courageuse accompagnée d'un chien féroce et fidèle. Malheureusement, le malheur frappe : sa meilleure amie a été enlevée alors qu'elle cherchait des baies dans la forêt.

Annalyn va tenter de retrouver et de libérer sa meilleure amie, en emmenant éventuellement son chien avec elle dans cette quête.

Après avoir suivi un moment la piste de sa meilleure amie, elle découvre le camp où celle-ci est retenue prisonnière. Il s'avère qu'il y a deux ravisseurs : un puissant chevalier et un archer rusé.

Ayant trouvé les ravisseurs, Annalyn réfléchit aux actions suivantes dans lesquelles elle peut s'engager :

- _Attaque rapide_ : une attaque rapide est possible si le chevalier dort, car il lui faut du temps pour enfiler son armure, ce qui le rend vulnérable.
- _Espionner_ : on peut espionner le groupe si au moins l'un de ses membres est éveillé. Sinon, espionner est une perte de temps.
- _Signaler le prisonnier_ : on peut signaler le prisonnier à l'aide de cris d'oiseaux si le prisonnier est éveillé et que l'archer dort, car les archers sont entraînés aux signaux d'oiseaux et pourraient donc intercepter le message.
- _Libérer le prisonnier_ : Annalyn peut tenter de s'introduire discrètement dans le camp pour libérer le prisonnier.
  C'est une action risquée qui ne peut réussir que de deux façons :
  - Si Annalyn a son chien avec elle, elle peut sauver le prisonnier si l'archer dort.
    Le chevalier a peur du chien et l'archer n'aura pas le temps de se préparer avant qu'Annalyn et le prisonnier puissent s'échapper.
  - Si Annalyn n'a pas son chien, alors elle et le prisonnier doivent être très discrets !
    Annalyn peut libérer le prisonnier si le prisonnier est éveillé et que le chevalier et l'archer dorment tous les deux, mais si le prisonnier dort, il ne peut pas être sauvé : le prisonnier serait surpris par l'apparition soudaine d'Annalyn et réveillerait le chevalier et l'archer.

Tu as quatre tâches : implémenter la logique qui détermine si les actions ci-dessus sont possibles en fonction de l'état des trois personnages trouvés dans la forêt et de la présence ou non du chien d'Annalyn.

## 1. Vérifie si une attaque rapide est possible

Implémente la méthode (_static_) `QuestLogic.CanFastAttack()` qui prend une valeur booléenne indiquant si le chevalier est éveillé. Cette méthode renvoie `true` si une attaque rapide est possible en fonction de l'état du chevalier. Sinon, elle renvoie `false` :

```csharp
var knightIsAwake = true;
QuestLogic.CanFastAttack(knightIsAwake);
// => false
```

## 2. Vérifie si le groupe peut être espionné

Implémente la méthode (_static_) `QuestLogic.CanSpy()` qui prend trois valeurs booléennes, indiquant si le chevalier, l'archer et le prisonnier, respectivement, sont éveillés. La méthode renvoie `true` si le groupe peut être espionné, en fonction de l'état des trois personnages. Sinon, elle renvoie `false` :

```csharp
var knightIsAwake = false;
var archerIsAwake = true;
var prisonerIsAwake = false;
QuestLogic.CanSpy(knightIsAwake, archerIsAwake, prisonerIsAwake);
// => true
```

## 3. Vérifie si le prisonnier peut être signalé

Implémente la méthode (_static_) `QuestLogic.CanSignalPrisoner()` qui prend deux valeurs booléennes, indiquant si l'archer et le prisonnier, respectivement, sont éveillés. La méthode renvoie `true` si le prisonnier peut être signalé, en fonction de l'état des deux personnages. Sinon, elle renvoie `false` :

```csharp
var archerIsAwake = false;
var prisonerIsAwake = true;
QuestLogic.CanSignalPrisoner(archerIsAwake, prisonerIsAwake);
// => true
```

## 4. Vérifie si le prisonnier peut être libéré

Implémente la méthode (_static_) `QuestLogic.CanFreePrisoner()` qui prend quatre valeurs booléennes. Les trois premiers paramètres indiquent si le chevalier, l'archer et le prisonnier, respectivement, sont éveillés. Le dernier paramètre indique si le chien d'Annalyn est présent. La méthode renvoie `true` si le prisonnier peut être libéré en fonction de l'état des trois personnages et de la présence du chien d'Annalyn. Sinon, elle renvoie `false` :

```csharp
var knightIsAwake = false;
var archerIsAwake = true;
var prisonerIsAwake = false;
var petDogIsPresent = false;
QuestLogic.CanFreePrisoner(knightIsAwake, archerIsAwake, prisonerIsAwake, petDogIsPresent);
// => false
```
