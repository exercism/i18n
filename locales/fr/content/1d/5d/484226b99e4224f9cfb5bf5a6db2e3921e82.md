# À propos

Une `string` en C++ est un objet modifiable qui représente du texte sous la forme d'une séquence de caractères (des lettres, des chiffres, de la ponctuation, etc.). On manipule les _strings_ en appelant leurs méthodes.

## La bibliothèque de _strings_

En C++, le type `string` et les fonctions associées doivent être inclus depuis la bibliothèque de _strings_ avant toute utilisation. Pour ce faire, tu peux ajouter `#include <string>` en haut de ton fichier. Ils viennent alors peupler l'espace de noms `std`. Le littéral de chaîne utilise le guillemet double : `"`.

```cpp
#include <string>
std::string w_berry_quote{"A well-made sentence, I think, is a thing of beauty."};
```

## Les opérations courantes sur les _strings_

Tu peux utiliser l'opérateur `+` pour concaténer des _strings_ :

```cpp
std::string original_title{"The School of Rock"};
std::string sequel_indicator{"Electric Boogaloo"};
std::string next_movie_title = original_title + " 2: " + sequel_indicator;
```

Pour utiliser la bibliothèque de _strings_, il faut savoir qu'il est possible d'appeler une fonction qui appartient à un objet. On les appelle des fonctions membres. Plus loin dans le programme, tu en apprendras davantage sur les fonctions membres et le concept de classe associé.

```cpp
std::string qualification{"awesome"};
// 1st argument: from the index to the end of the string:
std::string who_is_awesome = qualification.substr(5);
// => "me"

// 2nd optional argument for the length:
std::string material{"haunted books"};
std::string ghost = material.substr(8, 3);
// => "boo"
```


La fonction `find` est également très utile. On l'appelle comme fonction membre d'une _string_, et elle prend une _string_ en argument. `find` renvoie la position de la première occurrence dans la _string_, en partant de zéro.

```cpp
std::string new_release{"apple released a new app!"};
new_release.find("app");
// => 0
new_release.find("!");
// => 24
```

Il y a aussi la fonction `to_string`, qui permet de convertir des entiers et des valeurs de type _float_ ou _double_ en _string_. `to_string` renvoie une _string_.

```cpp
int num{92};
double exponent{0.92e2};
std::string msg{ std::to_string(num) + " can also be written as " + std::to_string(exponent)};
// => 92 can also be written as 92.0000000
```
