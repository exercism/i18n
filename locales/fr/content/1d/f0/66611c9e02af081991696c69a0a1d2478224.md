# Ajout aux instructions

## Sortie

Dans cet exercice, tu vas implémenter un verbe qui génère le triangle de Pascal jusqu'à un nombre de lignes donné. La sortie de ton verbe peut être présentée de deux façons :

  1. Sous la forme d'un tableau de listes encadrées, où chaque liste représente une ligne du triangle de Pascal.
  1. Sous la forme d'un tableau où les nombres sont alignés à droite et où des zéros comblent les espaces vides à gauche.

### Exemple de sortie

Voici deux sorties valides pour `pascal 3` :

  - Sous la forme d'un tableau de listes encadrées :
```j
  (1 ; 1 1 ; 1 2 1) -: pascal 3          NB. This test will pass
```
  - Sous la forme d'un tableau avec remplissage :
```j
  (3 3$1 0 0 1 1 0 1 2 1) -: pascal 3   NB. This test also passes
```
