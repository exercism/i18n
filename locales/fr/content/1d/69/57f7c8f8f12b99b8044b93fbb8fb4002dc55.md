# À propos

Le filtrage par motifs consiste à créer des branches selon qu'une valeur correspond à des motifs donnés, éventuellement profonds. En Haxe, le **filtrage par motifs** se fait à l'aide de l'expression `switch` et de chacune des expressions `case`.

Prenons cette structure de données :

```haxe
enum Tree<T> {
  Leaf(v:T);
  Node(l:Tree<T>, r:Tree<T>);
}
```

- Les motifs sont toujours testés de haut en bas.
- L'expression du premier motif qui correspond à la valeur d'entrée est exécutée.
- Un motif `_` correspond à n'importe quoi, donc `case _:` équivaut à `default:`

## Filtrage des énumérations

On peut filtrer les énumérations naturellement par leur constructeur :

```haxe
var myTree = Node(Leaf("foo"), Node(Leaf("bar"), Leaf("foobar")));

var match = switch (myTree) {
  // Matches any Leaf
  case Leaf(_):
    "0";

  // Matches any Node that has r = Leaf
  case Node(_, Leaf(_)):
    "1";

  // Matches any Node that has
  // r = another Node which has
  // l = Leaf("bar")
  case Node(_, Node(Leaf("bar", _))):
    "2";

  // Matches anything
  case _:
    "3";
}

trace(match); // 2
```
