# Installe Emacs

Comme Emacs Lisp (elisp) est le langage d'extension d'Emacs, tu dois d'abord installer [GNU Emacs](http://www.gnu.org/software/emacs/).

Il est recommandé d'utiliser la dernière version d'Emacs, mais la version 28.1 ou supérieure doit être considérée comme l'implémentation cible pour les exercices.
Si tu as déjà Emacs installé, tu peux vérifier sa version avec `M-x emacs-version RET`.

## Sur OS X
Le plus simple est de te rendre sur [Emacs For Mac OS X](http://emacsformacosx.com/) et de télécharger le dmg, qui installera GNU Emacs comme une application OS X packagée.

Il existe des alternatives, comme Aquamacs (non recommandé) ou une installation via [Homebrew](https://formulae.brew.sh/formula/emacs), si tu préfères.

## Sur Linux
Sur certaines distributions, Emacs est déjà installé, car il fait partie de GNU.

### Ubuntu
La façon actuellement recommandée d'installer la version la plus récente d'Emacs passe par [snap](https://snapcraft.io/emacs) :

```
sudo snap install emacs --classic
```

Si tu ne veux pas utiliser snap, tu peux aussi installer Emacs via apt, mais la version disponible dans les dépôts Ubuntu est souvent obsolète.
Si tu veux installer une version plus récente d'Emacs via apt, tu devras utiliser un [PPA](https://launchpad.net/ubuntu/+ppas?name_filter=emacs) ou [compiler depuis les sources](https://www.emacswiki.org/emacs/BuildingEmacs).

Si installer la toute dernière version ne t'importe peu, il devrait suffire de faire

```
sudo apt-get install emacs
```

### Arch
Arch fournit généralement la dernière version d'Emacs, donc lance :

```
sudo pacman -S emacs
```

et tu devrais être prêt.

### Autres distributions
Renseigne-toi auprès de ta distribution pour savoir quelle version est disponible, puis utilise ton gestionnaire de paquets ou compile depuis les sources selon le cas.

### Windows
Pour installer Emacs sous Windows, rends-toi sur le [miroir d'archive FTP](https://ftpmirror.gnu.org/emacs/windows) le plus proche, récupère l'installateur (=emacs-XX.X-installer.exe=) et lance-le.
Si tu ne veux pas installer Emacs, tu peux récupérer le fichier dont le nom suit le motif =emacs-XX.x.zip=, le décompresser et lancer `bin\runemacs.exe`.

Si tu utilises [MSYS2](https://www.msys2.org/), tu peux installer la version 64 bits d'Emacs avec

```
pacman -S mingw-w64-x86_64-emacs
```

ou la version 32 bits avec

```
pacman -S mingw-w64-i686-emacs
```
