# Instructions complémentaires

## Format de sortie

Produis les paroles sous la forme d'une chaîne de caractères terminée par un caractère nul.

## Registres

| Registre | Utilisation   | Type       | Description                                    |
| -------- | ------------- | ---------- | ---------------------------------------------- |
| `$a0`    | entrée        | entier     | bouteilles au départ                           |
| `$a1`    | entrée        | entier     | bouteilles à retirer                           |
| `$a2`    | entrée/sortie | adresse    | chaîne de sortie terminée par un caractère nul |
| `$t0-9`  | temporaire    | quelconque | pour le stockage temporaire                    |
