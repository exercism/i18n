# À propos

Ce qu'il faut surtout retenir des chaînes de caractères en Java, c'est que ce sont des objets immuables qui représentent du texte sous la forme d'une séquence de caractères Unicode (lettres, chiffres, ponctuation, etc.).
On utilise des guillemets doubles pour définir une instance de `String` :

```java
String fruit = "Apple";
```

On peut manipuler une _string_ à l'aide des méthodes de la classe [`String`][string-class].
Comme la valeur d'une _string_ ne peut jamais changer après avoir été définie, toutes les méthodes de manipulation de _strings_ renvoient une nouvelle _string_.

Une _string_ est délimitée par des guillemets doubles (le caractère `"`).
Certains caractères spéciaux doivent être échappés à l'aide de la barre oblique inversée (`\`).
Les caractères à échapper en Java :

- `"`
- `\`

```java
String escaped = "c:\\test.txt";
// => c:\test.txt
```

Enfin, il existe de nombreuses façons de concaténer des _strings_.
La plus simple est l'opérateur `+` :

```java
String name = "Jane";
"Hello " + name + "!";
// => "Hello Jane!"
```

Pour tout formatage de chaîne plus complexe qu'une simple concaténation, la méthode `String.format` est préférable.

```java
String name = "Jane";
String.format("Hello %s!",name);
// => "Hello Jane!"
```

Il existe d'autres possibilités :

- utiliser la [classe `StringBuilder`][string-builder]
- utiliser la [méthode `String.concat`][string-concat]
