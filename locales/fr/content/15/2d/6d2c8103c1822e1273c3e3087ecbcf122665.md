# Normalisations du representer

Le [representer JavaScript][github-javascript-representer] applique les normalisations suivantes :

## Supprime les commentaires

Tous les commentaires sont supprimés.
Les exemples suivants sont équivalents :

### Exemple avec commentaires

```javascript
/**
 * Returns the string literal 'hi there' just to say hello
 * @return [String]
 */
function hello(/* nothing*/) {
  // just return it
  return 'hi there';
}
```

### Exemple sans commentaires

```javascript
function hello() {
  return 'hi there';
}
```

## Normalise l'espacement

Lorsque le code est représenté, c'est son _ordre_ qui est significatif, mais pas son emplacement physique.
Cela signifie que l'espacement est normalisé.
Les exemples suivants sont équivalents :

### Exemple avec une indentation de deux espaces

```javascript
function hello() {
  return 'hello world';
}
```

### Exemple avec une indentation de quatre espaces

```javascript
function hello() {
  return 'hello world';
}
```

### Exemple avec une indentation intéressante

```javascript
function hello() {
  return 'hello world';
}
```

## Normalise les identifiants

Les identifiants sont normalisés en une valeur de remplacement.

### Avant

```javascript
const MY_CONSTANT = 42;

function answer(multiplier, addition = 1) {
  return MY_CONSTANT * multiplier + addition;
}
```

### Après

```javascript
const PLACEHOLDER_1 = 42;

function PLACEHOLDER_2(PLACEHOLDER_3, PLACEHOLDER_4 = 1) {
  return PLACEHOLDER_1 * PLACEHOLDER_3 + PLACEHOLDER_4;
}
```
