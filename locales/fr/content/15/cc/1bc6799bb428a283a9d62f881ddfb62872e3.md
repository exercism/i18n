# Instructions

Dans cet exercice, tu vas écrire du code pour garder la trace des indicatifs téléphoniques internationaux grâce à un dictionnaire d'indicatifs téléphoniques.

Le dictionnaire utilise un entier pour ses clés (l'indicatif téléphonique) et une _string_ (le nom du pays) pour ses valeurs.

Tu as 9 tâches à réaliser, qui reposent toutes sur la classe statique `DialingCodes`.

## 1. Crée un nouveau dictionnaire

Implémente la méthode (statique) `DialingCodes.GetEmptyDictionary()` qui renvoie un dictionnaire vide.

```csharp
DialingCodes.GetEmptyDictionary();
// => empty dictionary
```

## 2. Crée un dictionnaire pré-rempli

Il existe un dictionnaire pré-rempli qui contient les 3 indicatifs téléphoniques suivants : "United States of America", dont l'indicatif est 1, "Brazil", dont l'indicatif est 55, et "India", dont l'indicatif est 91. Implémente la méthode (statique) `DialingCodes.GetExistingDictionary()` pour renvoyer ce dictionnaire pré-rempli :

```csharp
DialingCodes.GetExistingDictionary();
// => 1 => "United States of America", 55 => "Brazil", 91 => "India"
```

## 3. Ajoute un pays à un dictionnaire vide

Implémente la méthode (statique) `DialingCodes.AddCountryToEmptyDictionary()` qui crée un dictionnaire et y ajoute un indicatif téléphonique et le nom du pays associé.

```csharp
DialingCodes.AddCountryToEmptyDictionary(44, "United Kingdom");
// => 44 => "United Kingdom"
```

## 4. Ajoute un pays à un dictionnaire existant

Implémente la méthode (statique) `DialingCodes.AddCountryToExistingDictionary()` qui ajoute un indicatif téléphonique et le nom du pays associé à un dictionnaire non vide.

```csharp
DialingCodes.AddCountryToExistingDictionary(DialingCodes.GetExistingDictionary(),
  44, "United Kingdom");
// => 1 => "United States of America", 44 => "United Kingdom", 55 => "Brazil", 91 => "India"
```

## 5. Obtiens le nom du pays correspondant à un indicatif téléphonique

Implémente la méthode (statique) `DialingCodes.GetCountryNameFromDictionary()` qui prend un indicatif téléphonique et renvoie le nom du pays correspondant. Si l'indicatif ne figure pas dans le dictionnaire, une _string_ vide est renvoyée.

```csharp
DialingCodes.GetCountryNameFromDictionary(
  DialingCodes.GetExistingDictionary(), 55);
// => "Brazil"

DialingCodes.GetCountryNameFromDictionary(
  DialingCodes.GetExistingDictionary(), 999);
// => string.Empty
```

## 6. Vérifie qu'un pays existe dans le dictionnaire

Implémente la méthode (statique) `DialingCodes.CheckCodeExists()` pour vérifier si un indicatif téléphonique existe dans le dictionnaire.

```csharp
DialingCodes.CheckCodeExists(DialingCodes.GetExistingDictionary(), 55);
// => true
```

## 7. Mets à jour le nom d'un pays

Implémente la méthode (statique) `DialingCodes.UpdateDictionary()` qui prend un indicatif téléphonique et remplace le nom du pays correspondant dans le dictionnaire par le nom du pays passé en paramètre. Si l'indicatif n'existe pas dans le dictionnaire, celui-ci reste inchangé.

```csharp
DialingCodes.UpdateDictionary(
  DialingCodes.GetExistingDictionary(), 1, "Les États-Unis");
// => 1 => "Les États-Unis", 55 => "Brazil", 91 => "India"

DialingCodes.UpdateDictionary(
  DialingCodes.GetExistingDictionary(), 999, "Newlands");
// 1 => "United States of America", 55 => "Brazil", 91 => "India"
```

## 8. Supprime un pays du dictionnaire

Implémente la méthode (statique) `DialingCodes.RemoveCountryFromDictionary()` qui prend un indicatif téléphonique et supprime du dictionnaire l'enregistrement correspondant, à savoir l'indicatif et le nom du pays.

```csharp
DialingCodes.RemoveCountryFromDictionary(
  DialingCodes.GetExistingDictionary(), 91);
// => 1 => "United States of America", 55 => "Brazil"
```

## 9. Trouve le pays dont le nom est le plus long

Implémente la méthode (statique) `DialingCodes.FindLongestCountryName()` qui renvoie le nom du pays au nom le plus long parmi ceux stockés dans le dictionnaire.

```csharp
DialingCodes.FindLongestCountryName(
  DialingCodes.GetExistingDictionary());
// => "United States of America"
```
