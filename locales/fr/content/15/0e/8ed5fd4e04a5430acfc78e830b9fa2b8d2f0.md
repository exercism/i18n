# Introduction

La conversion de types en Cairo permet de convertir des valeurs d'un type à un autre en utilisant les traits `Into` et `TryInto`.
Le trait `Into` est utilisé pour les conversions garanties, tandis que `TryInto` gère les conversions faillibles qui peuvent échouer si la valeur ne correspond pas au type cible.
Ces traits peuvent également être implémentés pour des types personnalisés, ce qui permet des conversions flexibles et précises dans tes programmes.
