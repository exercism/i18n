# Introduction

Le module [`fractions`][fractions] permet de créer et de manipuler des [`rational numbers`][rational] : des fractions dont le numérateur est un entier divisé par un dénominateur entier.
Par exemple, on peut stocker `2/3` sous la forme d'une fraction exacte plutôt que la valeur approchée `0.6666...` d'un `float`.

Contrairement aux nombres `int`, `float` et `complex`, les fractions n'ont pas de forme littérale.
En revanche, le constructeur de fractions est assez souple.

Le plus évident : il peut prendre deux entiers en arguments.
Les facteurs communs sont supprimés automatiquement, ce qui réduit la fraction à sa « forme irréductible » (_les plus petits entiers qui représentent la fraction avec exactitude_) :

```python
>>> from fractions import Fraction

>>> f1 = Fraction(2, 3) # 2/3
>>> f1
Fraction(2, 3)

>>> f2 = Fraction(6, 9)
>>> f2
Fraction(2, 3)  # automatically simplified

>>> f1 == f2
True
```

Le constructeur de fractions peut aussi analyser une représentation sous forme de _string_ :

```python
>>> f3 = Fraction('2/3')
>>> f3
Fraction(2, 3)
```

Les fractions peuvent aussi fonctionner avec des paramètres `float`, mais cela peut poser problème à cause de la nature approximative de la représentation interne d'une valeur décimale en binaire.
Pour en savoir plus sur ce problème de représentation, consulte le site [0.30000000000000004][0.30000000000000004] et la page [Floating Point Arithmetic: Issues and Limitations ][fp-issues] de la documentation Python.

Pour un résultat plus fiable quand on utilise des nombres à virgule flottante avec des fractions, il y a la méthode `<fraction>.limit_denominator()`.


## Arithmétique avec les fractions

Les [`arithmetic operators`][operators] habituels `+ - * / **` fonctionnent avec les fractions, comme avec les autres types numériques.

Les entiers et les autres `Fraction` peuvent être inclus dans l'opération et donnent un résultat de type `Fraction`.
Inclure un `float` dans l'expression produit un `float`, avec une perte de précision (possible) en conséquence :

```python
>>> Fraction(2, 3) + Fraction(1, 4) # addition
Fraction(11, 12)

>>> Fraction(2, 3) * Fraction(6, 5) # multiply fractions
Fraction(4, 5)

>>> Fraction(2, 3) * 6 / 5 # fraction with integers
Fraction(4, 5)

>>> Fraction(2, 3) * 1.2  # fraction with float -> float
0.7999999999999999

>>> Fraction(2, 3) ** 2  # exponentiation with integer
Fraction(4, 9)
```

Diverses fonctions numériques standard de Python donnent aussi le résultat auquel on peut s'attendre avec les types `int` et `float` :

```python
>>> round(Fraction(11, 3))
4

>>> from math import floor, ceil
>>> floor(Fraction(11, 3))
3
>>> ceil(Fraction(11, 3))
4

>>> float(Fraction(11, 3))
3.6666666666666665
```
