# Les méthodes de tableau

Les tableaux sont une structure de données très courante. Il existe ainsi tout un ensemble de méthodes pour les manipuler, et notamment pour les trier, les inverser, y insérer des éléments, et bien d'autres choses encore.

Certaines de ces méthodes sont destructives, c'est-à-dire qu'elles modifient le tableau d'origine. D'autres ne le sont pas : elles renvoient un nouveau tableau sans toucher à l'original.

Voici quelques-unes des méthodes les plus courantes que l'on peut utiliser avec les tableaux :

## insert

Pour insérer un élément dans un tableau, tu peux utiliser la méthode [`insert`][insert], qui prend un indice et un élément en arguments.
L'élément est inséré à l'indice indiqué, et le reste du tableau est décalé vers la droite.
Si l'indice est hors limites, une `IndexError` est levée.

```crystal
numbers = [1, 2, 3]
numbers.insert(1, 4)
numbers # => [1, 4, 2, 3]

numbers.insert(5, 5) # => Error: Index out of bounds (IndexError)
```

## delete

Pour supprimer un élément précis d'un tableau, tu peux utiliser la méthode [`delete`][delete], qui prend un élément en argument.
La méthode renvoie l'élément qui a été supprimé.
Si l'élément n'existe pas dans le tableau, `nil` est renvoyé.

```crystal
numbers = [1, 2, 3]
numbers.delete(2) # => 2
numbers           # => [1, 3]
```

## first & last

Pour récupérer le premier ou le dernier élément d'un tableau, tu peux utiliser les méthodes [`first`][first] et [`last`][last].
Ces méthodes prennent un argument optionnel qui indique combien d'éléments renvoyer.
Elles améliorent la lisibilité par rapport à l'utilisation de l'indice `0` ou `-1`, ou d'un intervalle.
Si le tableau est vide, une `Enumerable::EmptyError` est levée.

```crystal
numbers = [1, 2, 3]
numbers.first # => 1
numbers.last  # => 3

numbers.first(2) # => [1, 2]
numbers.last(2)  # => [2, 3]

empty_array = [] of Int32
empty_array.last # => Error: Empty enumerable (Enumerable::EmptyError)
```

## reverse

Pour inverser un tableau, tu peux utiliser la méthode [`reverse`][reverse], qui renvoie un nouveau tableau avec les éléments dans l'ordre inverse.
Il est important de noter que `reverse` renvoie un nouveau tableau et ne modifie pas le tableau d'origine.
Si tu veux modifier le tableau d'origine, ajoute un `!` à la fin du nom de la méthode.

```crystal
numbers = [1, 2, 3]
numbers.reverse # => [3, 2, 1]
numbers         # => [1, 2, 3]

numbers.reverse! # => [3, 2, 1]
numbers          # => [3, 2, 1]
```

## flatten & compact & transpose & uniq

Les méthodes suivantes sont utiles pour effectuer des opérations comme rendre un tableau à une dimension, supprimer les éléments `nil`, supprimer les doublons ou transposer un tableau de tableaux.
Comme pour `reverse`, ces méthodes renvoient un nouveau tableau et ne modifient pas le tableau d'origine.

| Méthode | Description | exemple |
| ------ | ----------- | ------- |
| [`flatten`][flatten] | Renvoie un nouveau tableau qui est l'aplatissement à une dimension de ce tableau (de façon récursive). Autrement dit, pour chaque élément du tableau, extrait ses éléments dans le nouveau tableau. | `[[1, 2], [3, 4]].flatten # => [1, 2, 3, 4]` |
| [`compact`][compact] | Renvoie une copie de self dont tous les éléments `nil` ont été supprimés. | `[1, nil, 2, nil, 3].compact # => [1, 2, 3]` |
| [`transpose`][transpose] | Suppose que self est un tableau de tableaux et [transpose][transpose] les lignes et les colonnes. | `[[1, 2], [3, 4]].transpose # => [[1, 3], [2, 4]]` |
| [`uniq`][uniq] | Renvoie un nouveau tableau en supprimant les valeurs en double dans self. | `[1, 2, 1, 3, 1].uniq # => [1, 2, 3]` |

## Concaténation (`+`)

La méthode d'ajout (`<<`) est utile pour ajouter des objets à un tableau.
Toutefois, pour combiner deux tableaux, tu peux utiliser l'opérateur [`+`][concat], qui renvoie un nouveau tableau contenant les éléments des deux tableaux.

```crystal
[1, 2] + [3, 4] # => [1, 2, 3, 4]
```

Si tu ajoutes un tableau à un autre tableau, le tableau est ajouté comme un seul élément.

```crystal
[1, 2] << [3, 4] # => [1, 2, [3, 4]]
```

## empty?

Pour vérifier si un tableau est vide, tu peux utiliser la méthode [`empty?`][empty?], qui renvoie `true` si le tableau est vide et `false` sinon.
C'est plus lisible que de comparer la longueur du tableau à `0`.

```crystal
[].empty? # => true
[1, 2, 3].empty? # => false
```

## index

Pour obtenir l'indice d'un élément dans un tableau, tu peux utiliser la méthode [`index`][index], qui prend un élément en argument.
Si l'élément n'existe pas dans le tableau, `nil` est renvoyé.

```crystal
numbers = [1, 2, 3]
numbers.index(2) # => 1
```

## size

Pour connaître le nombre d'éléments d'un tableau, tu peux utiliser la méthode [`size`][size].

```crystal
numbers = [1, 2, 3]
numbers.size # => 3
```

## count

Pour compter le nombre de fois qu'un élément est présent dans un tableau, tu peux utiliser la méthode [`count`][count].

```crystal
fruits = ["apple", "banana", "apple"]
fruits.count("apple")      # => 2
fruits.count("banana")     # => 1
fruits.count("watermelon") # => 0
```

## sort

Pour trier un tableau, tu peux utiliser la méthode [`sort`][sort], qui renvoie un nouveau tableau avec les éléments triés.
Comme pour `reverse`, cette méthode renvoie un nouveau tableau et ne modifie pas le tableau d'origine.

```crystal
numbers = [3, 2, 1]
numbers.sort # => [1, 2, 3]
numbers      # => [3, 2, 1]

numbers.sort! # => [1, 2, 3]
numbers       # => [1, 2, 3]
```
