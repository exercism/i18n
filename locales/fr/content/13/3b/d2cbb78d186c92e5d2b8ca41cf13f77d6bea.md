# Instructions

Convertis une phrase en son acronyme.

Les passionnés de technologie adorent leurs TLA (acronymes de trois lettres) !

Aide à générer du jargon en écrivant un programme qui convertit un nom long comme Portable Network Graphics en son acronyme (PNG).

La ponctuation est gérée comme suit : les traits d’union sont des séparateurs de mots (comme les espaces) ; toute autre ponctuation peut être supprimée de l’entrée.

Par exemple :

| Entrée | Sortie |
| ------------------------- | ------ |
| As Soon As Possible       | ASAP   |
| Liquid-crystal display    | LCD    |
| Thank George It's Friday! | TGIF   |
