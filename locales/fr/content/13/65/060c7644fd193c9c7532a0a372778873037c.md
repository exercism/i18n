# Snippet Extractor

Le [Snippet Extractor][snippet-extractor] prend la soumission d'un apprenant et en extrait les dix premières lignes de code « intéressantes ».
L'extrait ainsi obtenu est affiché sur différentes pages du site.

Par défaut, les dix premières lignes sont affichées, en ignorant les lignes vides du début.
Ces dix premières lignes _pourraient_ contenir des éléments comme des commentaires, qui ne sont généralement pas idéaux à afficher dans un extrait de code.

## Personnaliser l'extraction d'extraits de code

Nous recommandons que chaque parcours [personnalise l'extraction d'extraits de code][snippet-extractor-customize], ne serait-ce que pour supprimer les commentaires du code source.
Pour personnaliser l'extraction d'extraits de code, tu devras :

1. Ajouter un fichier `lib/languages/<track_slug>.txt` qui configure l'extraction d'extraits de code.
   Ce fichier peut utiliser soit le [mode basique][basic-mode], soit le [mode étendu][extended-mode].
   La plupart des parcours utilisent le mode étendu, car il offre plus de flexibilité.
2. Ajouter un ou plusieurs cas de test dans un répertoire `tests/<track_slug>/<test_slug>`.
   Chaque répertoire de test doit contenir deux fichiers :

   1. `tests/<track_slug>/<test_slug>/code.<track_extension>` : le code sur lequel exécuter le Snippet Extractor
   2. `tests/<track_slug>/<test_slug>/expected_snippet.<track_extension>` : l'extrait attendu

Voir [cette pull request d'exemple][example-pr] qui personnalise l'extraction d'extraits de code pour le langage Arturo.
