# Introduction

## Tables de hachage

Les tables de hachage en Common Lisp sont des structures de données qui permettent de stocker des données associatives. 
Elles associent des clés (qui peuvent être n'importe quel objet) à des valeurs (qui peuvent être n'importe quel objet). 
D'autres langages donnent à ce concept le nom de _map_, _dictionary_ ou _hash_.

### Crée des tables de hachage

On peut créer des tables de hachage avec la fonction `make-hash-table`.

`(make-hash-table) ; => #<HASH-TABLE :TEST EQL :COUNT 0 {10024AD2B3}>`

(Note que la représentation affichée d'une table de hachage dépend de l'implémentation, elle peut donc être différente dans le REPL.)

### Récupère des valeurs à partir des clés

Pour récupérer une valeur à partir d'une clé dans la table de hachage, on utilise la fonction `gethash` :

```lisp
*h* ; => #<HASH-TABLE :TEST EQL :COUNT 3 {10024AD2B3}>`
(gethash :foo *h*) ; => :bar
                   ;    T
```

`gethash` renvoie [plusieurs valeurs][concept-multiple-values], ce qui sera expliqué dans un autre concept.

### Insère des valeurs

Pour insérer une valeur dans une table de hachage, on utilise `setf` avec `gethash` comme ceci :

`(setf (gethash :foo *hash-table*) :bar) : => :bar`

Cela remplace par `:bar` la valeur associée à la clé `:foo` dans la table de hachage `*hash-table*`.
Elle renvoie la valeur.

L'utilisation de `setf` sera expliquée dans un autre concept.
