# Installation

Le parcours C suppose que les logiciels suivants soient installés sur ton système :

* Un compilateur C moderne
* L'outil de compilation Make

L'IDE Xcode d'Apple réunit le compilateur et le système de compilation natif dans un seul IDE (environnement de développement intégré).
Sous Linux, le compilateur et le système de compilation natif sont généralement exposés sous forme d'outils en ligne de commande distincts.

## Linux

Sous Linux, il faut gcc ou clang comme compilateur, et `make` pour la compilation native.
Make est préinstallé sur la plupart des systèmes Unix, mais on le trouve le plus souvent via le gestionnaire de paquets.
Sur les distributions basées sur Debian et Ubuntu, tout ce dont tu as besoin s'installe avec `sudo apt-get install build-essential` s'il n'est pas déjà présent.

## MacOS

Sous MacOS, tu peux installer gcc ou clang avec [Homebrew][] via `brew install gcc` ou `brew install llvm`.

## Windows

Si tu utilises Windows 10, on te recommande de passer par le [Windows Subsystem for Linux][] et de suivre les instructions pour Linux ci-dessus.

Si tu utilises une version antérieure de Windows, ou si WSL Bash n'est pas disponible, tu peux utiliser [MSYS][] ou [mingw-w64][].

[Homebrew]: https://brew.sh
[Windows Subsystem for Linux]: https://docs.microsoft.com/en-gb/windows/wsl/about
[MSYS]: https://www.msys2.org
[mingw-w64]: http://mingw-w64.org
