# Instructions

Ton club de netball doit calculer son classement après chaque journée.

Les quatre tâches sont à réaliser dans la classe `NETBALL_LADDER`.

## 1. Points de classement

Une victoire vaut 4 points et un match nul 2. Les défaites ne rapportent rien.

```sather
NETBALL_LADDER::ladder_points(3, 1)
-- => 14
```

## 2. Différence de buts

Les buts marqués moins les buts encaissés. Elle peut être négative.

```sather
NETBALL_LADDER::goal_difference(180, 205)
-- => -25
```

## 3. Quarts-temps complets

Un quart-temps dure 15 minutes. Étant donné un nombre de minutes, combien de
quarts-temps complets cela représente-t-il ?

```sather
NETBALL_LADDER::whole_quarters(38)
-- => 2
```

## 4. Minutes écoulées dans le quart-temps

Avec le même nombre de minutes, combien de minutes se sont écoulées dans le
quart-temps en cours ?

```sather
NETBALL_LADDER::minutes_into_quarter(38)
-- => 8
```
