# Booléens

Haskell possède un type appelé [`Bool`][bools].
C'est une énumération de `True` et `False`.

## Opérateurs logiques

Haskell dispose de trois opérateurs logiques (`not`, `||`, `&&`), qui combinent des booléens pour former des expressions dont le résultat varie.

### Et(`&&`)

L'[opérateur _et_][and] en Haskell est représenté par `&&` et renvoie `True` si les deux valeurs valent `True` ; sinon, il renvoie `False`.
Pour utiliser l'opérateur _et_, on place un booléen à droite du `&&` et un autre à gauche.

```haskell
True && True
-- -> True

True && False
-- -> False
```

### Ou(`||`)

L'[opérateur _ou_][or] en Haskell est représenté par `||` et renvoie `True` si **au moins une** des valeurs données vaut `True`. 
Si les deux valeurs sont `False`, il renvoie `False`.
Pour utiliser l'opérateur _ou_, il faut placer un booléen à droite du `||` et un autre à gauche.

```haskell
True || True
-- -> True

True || False
-- -> True

False || False
-- -> False
```

### Non(`not`)

L'opérateur _non_ en Haskell est représenté par `not` : il renvoie `True` si le booléen donné vaut `False`, et `False` si la valeur fournie est `True`.
Pour utiliser l'opérateur _non_, il faut placer un booléen après l'opérateur (`not`).

```haskell
not True
-- -> False

not False
-- -> True
```

## Utilise les parenthèses(`()`)

Quand on travaille avec des booléens, on peut utiliser des parenthèses pour décider quels booléens évaluer en premier.
Le résultat peut changer selon la façon dont les parenthèses sont utilisées.
En Haskell, ce qui se trouve entre parenthèses est évalué en premier.

```haskell
True && False && False || True
-- -> True

True && False && (False || True)
-- -> False
```

Comme ce qui se trouve entre parenthèses est évalué en premier, l'opérateur _non_ s'appliquera à l'expression entre parenthèses dans l'exemple suivant.

```haskell
not True && False
-- -> False

not (True && False)
-- -> True
```

~~~~exercism/note
N'utilise des parenthèses que lorsqu'elles changent le résultat ; sinon, omets-les.
~~~~
