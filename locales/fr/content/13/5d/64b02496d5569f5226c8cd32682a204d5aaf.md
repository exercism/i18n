# Complément aux instructions

## Registres

| Registre | Utilisation | Type       | Description                                    |
| -------- | ----------- | ---------- | ---------------------------------------------- |
| `$a0`    | entrée      | adresse    | tableau de mots de facteurs                    |
| `$a1`    | entrée      | entier     | nombre de facteurs                             |
| `$a2`    | entrée      | entier     | limite                                         |
| `$v0`    | sortie      | entier     | somme des multiples inférieurs à la limite     |
| `$t0-9`  | temporaire  | quelconque | utilisé pour le stockage temporaire            |
