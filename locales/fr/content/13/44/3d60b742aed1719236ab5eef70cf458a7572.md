# Instructions

Pour rester dans le thème du jeu _wizards and warriors_, il est temps d'ajouter une méthode polyvalente pour lancer un dé. Ce sera le dé traditionnel à 18 faces, numéroté de 1 à 18. Les joueurs génèrent aussi une puissance de sort.

## 1. Permets à un joueur de _wizards and warriors_ de lancer un dé.

Implémente une méthode `RollDie()` dans la classe `Player`.

```csharp
var player = new Player();
player.RollDie();
// => >= 1 <= 18
```

## 2. Les joueurs ont besoin de leur puissance. Fournis un moyen de générer la puissance de sort

Implémente une méthode `GenerateSpellStrength()` dans la classe `Player`. La puissance de sort est comprise entre 0,0 et 100,0, cette dernière valeur exclue.

Note que la puissance de sort doit être un nombre réel (et non un entier) afin de réduire le risque d'égalité lorsque l'on compare les puissances de deux adversaires.

```csharp
var player = new Player();
player.GenerateSpellStrength();
// => >= 0.0 < 100.0
```
