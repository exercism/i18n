# Aide

## Lance les tests

Le parcours Factor utilise **Factor 0.101**. Après
[l'avoir installé](https://exercism.org/docs/tracks/factor/installation),
lance la commande suivante depuis le répertoire de cet exercice :

```
factor -roots=. -run=exercism-tools <exercise>
```

Par exemple, pour `hello-world` :

```
factor -roots=. -run=exercism-tools hello-world
```

Chaque exercice est livré avec un petit vocabulaire `exercism-tools` intégré
qui pilote l'exécution des tests. L'exécuteur de tests se termine avec le
statut 0 quand tous les tests réussissent, et avec un statut non nul
accompagné d'une sortie de diagnostic si un test échoue.

### Tests ignorés

Par défaut, seul le premier test s'exécute. Le mécanisme repose sur la ligne
`STOP-HERE` du fichier de test : au moment de l'analyse, elle indique au
lexer de Factor d'ignorer tout ce qui se trouve en dessous, de sorte que
l'exécuteur de tests ne voit que les tests au-dessus. Une fois que ton
premier test passe, tu peux activer davantage de tests de deux façons :

- **Supprime la ligne `STOP-HERE`** pour activer d'un coup tous les tests
  restants.
- **Déplace la ligne `STOP-HERE` plus bas** pour activer les tests un par
  un, ou une tâche à la fois. Les exercices d'apprentissage regroupent leurs
  tests sous des marqueurs `TASK:` : déplacer `STOP-HERE` juste avant le
  prochain `TASK:` est une étape naturelle.

Quand tous les tests passent, tu as résolu l'exercice.

## Soumets ta solution

Depuis le répertoire de l'exercice :

```
exercism submit <exercise>/<exercise>.factor
```

Par exemple :

```
exercism submit hello-world/hello-world.factor
```

Si le fichier `.meta/config.json` de l'exercice liste plus d'un fichier de
solution (certains exercices d'apprentissage répartissent une solution sur un
sous-vocabulaire d'aide), passe tous les fichiers que tu as modifiés à
`exercism submit`.

## Soumets des solutions incomplètes

Tu peux soumettre une solution même si des tests échouent : cela te permet de
voir comment d'autres ont abordé l'exercice et de demander un retour de mentor
sur ce que tu as déjà.

## Obtiens plus d'aide

- La [catégorie Factor du forum Exercism](https://forum.exercism.org/c/programming/factor/)
  est le meilleur endroit pour les questions et les retours propres au parcours.
- Le [Discord d'Exercism](https://exercism.org/r/discord) propose des canaux
  pour l'aide générale comme pour chaque parcours.
- La documentation officielle de Factor est exhaustive et dispose d'une recherche. Deux bons points d'entrée :
  - Le [manuel Factor](https://docs.factorcode.org/content/article-handbook.html),
    de style référence, organisé par vocabulaire.
  - Le [livre de recettes Factor](https://docs.factorcode.org/content/article-cookbook.html),
    de courts exemples idiomatiques classés par thème.
- Le [tutoriel Factor](https://andreaferretti.github.io/factor-tutorial/)
  d'Andrea Ferretti est une introduction rapide et conviviale au langage et à
  l'environnement de développement.
