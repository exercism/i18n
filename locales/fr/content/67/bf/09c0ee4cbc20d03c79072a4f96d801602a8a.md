# Tests

## Lance tous les tests

Il existe un script Raku avec l'extension `.rakutest`, qui servira à tester ta solution.
Tu peux lancer les tests à l'aide de la commande :

`prove6`

Avant de commencer l'exercice, la sortie ressemblera probablement à quelque chose comme :

```
# Failed test 'Say Hi!'
# at t/hello-world.rakutest line 6
# expected: "Hello, World!"
#  matcher: 'infix:<eq>'
#      got: "Goodbye, Mars!"
# You failed 1 test of 1
t/hello-world.rakutest ... Dubious, test returned 1
Failed 1/1 subtests
```

Tu devras modifier le module avec l'extension `.rakumod`, contenu dans le répertoire `lib/`, et écrire une solution pour que les tests passent.
Une fois que les tests passent, la sortie de la commande ci-dessus ressemblera probablement à quelque chose comme :

```
t/hello-world.rakutest ... ok
All tests successful.
```

## Arrête après le premier échec

Si tu as défini la variable d'environnement `RAKU_TEST_DIE_ON_FAIL`, l'exécuteur de tests s'arrêtera après le premier échec. Par exemple :

Sous Linux / OS X :

```bash
export RAKU_TEST_DIE_ON_FAIL=1
# now all the follow up runs will stop at the first failure
prove6
# until we do
unset RAKU_TEST_DIE_ON_FAIL
# or you can use it for one run like this:
RAKU_TEST_DIE_ON_FAIL=1 prove6
```

Ou sous Windows :

```
SET RAKU_TEST_DIE_ON_FAIL=1
REM now all the follow up runs will stop at the first failure
prove6
REM until we do
set RAKU_TEST_DIE_ON_FAIL=
```

Pour plus d'informations, consulte le
[chapitre sur les tests de la documentation Raku](https://docs.raku.org/language/testing.html).

## Dépannage

```
===SORRY!===
Could not find JSON::Fast
```

Tous les modules utilisés dans le parcours Raku sont inclus avec Rakudo Star.
Si tu obtiens un message d'erreur comme celui ci-dessus en essayant de lancer un test, tu devras soit t'assurer que tu disposes de la dernière distribution de Rakudo Star, soit installer le module toi-même à l'aide d'un gestionnaire de paquets.
Consulte la [documentation Raku sur les modules](https://docs.raku.org/language/modules#Looking_for_and_installing_modules.) pour savoir comment installer des modules.
