# Introduction

De nombreux types de membres de `struct` et de classe (les champs étant l'exception principale) peuvent utiliser la syntaxe des membres à corps d'expression. Définir un membre avec une expression produit souvent du code plus concis et plus lisible que les blocs ou instructions traditionnels.

Les méthodes et les propriétés en lecture seule font partie des membres que l'on peut définir avec un corps d'expression.

```csharp
public int Times3(int input) => input * 3;

public int Interesting => 1729;
```
