# Instructions

Apprends les bases des tables internes ABAP.

Ta classe contient une table interne nommée `initial_data`. Elle comporte trois colonnes : `GROUP`, `NUMBER` et `DESCRIPTION`.

```abap
TYPES group TYPE c LENGTH 1.
TYPES: BEGIN OF initial_type,
         group       TYPE group,
         number      TYPE i,
         description TYPE string,
       END OF initial_type,
       initial_data TYPE STANDARD TABLE OF initial_type WITH EMPTY KEY.
```

## Étape 1

Ta première tâche consiste à compléter la méthode `fill_itab` et à placer 6 enregistrements dans cette table avec les valeurs suivantes :

| GROUP | NUMBER | DESCRIPTION |
| --- | ----------- | ----------- |
| A | 10 | Group A-2 |
| B | 5 | Group B |
| A | 6 | Group A-1 |
| C | 22 | Group C-1 |
| A | 13 | Group A-3 |
| C | 500 | Group C-2 |

## Étape 2

Ensuite, implémente la méthode `add_to_itab` pour ajouter un enregistrement à la fin de la table interne avec la valeur suivante :

| GROUP | NUMBER | DESCRIPTION |
| --- | ----------- | ----------- |
| A | 19 | Group A-4 |

## Étape 3

Maintenant, trie la table interne dans la méthode `sort_itab` en classant la colonne `GROUP` par ordre alphabétique et la colonne `NUMBER` par ordre décroissant.

## Étape 4

Dans la méthode `search_itab`, recherche la table triée et renvoie l'indice de l'enregistrement dont la colonne `NUMBER` vaut 6.
