# À propos

[Les fonctions binaires bit à bit][bitwise-wiki] peuvent être appliquées à des entiers à l'aide des fonctions du [module Bitwise][bitwise-hexdocs].

- [`band/2`][bitwise-and] : ET bit à bit
- [`bsl/2`][bitwise-shift-left] : décalage à gauche
- [`bsr/2`][bitwise-shift-right] : décalage à droite
- [`bxor/2`][bitwise-xor] : OU exclusif bit à bit
- [`bor/2`][bitwise-or] : OU bit à bit
- [`bnot/1`][bitwise-not] : NON bit à bit

```elixir
Bitwise.band(0b1110, 0b1001)
# => 8 # 0b1000

Bitwise.bxor(0b1110, 0b1001)
# => 7 # 0b0111
```
