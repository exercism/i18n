# À propos

Crystal est un langage de programmation compilé et orienté objet.
Voici quelques-uns des objectifs du langage :

- Une syntaxe inspirée de Ruby.

- Un typage vérifié statiquement, mais sans avoir à préciser le type des variables ni des arguments de méthode.

- Pouvoir appeler du code C en écrivant des liaisons en Crystal.

- Disposer d'une évaluation et d'une génération de code à la compilation, afin d'éviter du code qui se répète.

- Être compilé en code natif efficace.
