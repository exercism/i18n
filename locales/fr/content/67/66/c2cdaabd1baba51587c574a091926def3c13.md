# `vec![]`

On peut utiliser les macros de Rust pour générer des vecteurs.

## Syntaxe

- `vec![]` utilise une macro de la bibliothèque standard de Rust pour initialiser un `Vec<T>` vide
- `vec![1; 3]` initialise un vecteur avec trois 1
- `vec![1, 2, 3]` initialise un vecteur avec les valeurs littérales 1, 2, 3
