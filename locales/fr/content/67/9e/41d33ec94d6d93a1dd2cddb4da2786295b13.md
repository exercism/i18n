# À propos

En Haxe, on peut définir une hiérarchie de classes à l'aide de l'_héritage_, qui permet à une classe dérivée (`Car`) d'hériter du comportement et des données de sa classe parente (`Vehicle`).

Dans la classe parente, on peut définir :

- Des méthodes que l'on peut redéfinir
- Des méthodes abstraites qui doivent être implémentées par les classes dérivées

```haxe
abstract class Vehicle {
  public function new() {}

  // Can be overridden
  public function drive() {
    // ...
  }

  // Must be implemented
  public abstract function getSpeed():Int;
}

class Car extends Vehicle {
  public function new() {
    super(); // Runs the parent class' constructor
  }

  public override function drive() {
    // ...
  }

  public function getSpeed():Int {
    // ...
  }
}
```

Si la classe parente possède un constructeur, on utilise `super()` pour l'appeler :

```haxe
abstract class Vehicle {
  var wheels:Int;

  public function new(wheels:Int) {
    this.wheels = wheels
  }
}

class Car extends Vehicle {
  var color:String;

  public function new(wheels:Int, color:String) {
    super(wheels);
    this.color = color;
  }
}

```
