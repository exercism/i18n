# Comment utiliser Markdown dans le mentorat

Tu peux utiliser Markdown dans tes commentaires de mentorat sur GitHub.
Cela te permet d'intégrer des extraits de code, d'ajouter des titres, du gras, de l'italique, des listes, etc., et de citer des phrases précédentes.

On autorise aussi certains éléments du « Markdown à la sauce GitHub » sur Exercism, en particulier la coloration syntaxique, les tableaux et le texte barré.

Si tu ne connais pas Markdown ni les extras de GitHub, on te recommande de lire le [guide GitHub sur Markdown](https://guides.github.com/features/mastering-markdown/).
