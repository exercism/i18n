# À propos

Elm est un langage entièrement fonctionnel : il n'y a donc pas d'instructions, seulement des expressions, et les fonctions sont toujours une seule expression.

Cela encourage à écrire des fonctions petites et simples, ce qui est généralement une bonne chose, mais il arrive que des fonctions soient inévitablement plus complexes, et il faut alors un moyen de garantir que ces fonctions peuvent être écrites de manière élégante.

C'est là que les expressions `let` entrent en jeu. Elles ont deux parties : une section `let`, où on peut créer autant de définitions que nécessaire, puis une section `in`, qui est une seule expression pouvant utiliser ces définitions.

En informatique, `let` crée une portée qui est locale à l'expression située dans `in`.

L'expression `let` est utile dans quelques situations :

- Pour simplifier des expressions
- Pour nommer les résultats d'expressions intermédiaires
- Pour découper une expression en morceaux plus petits si elle devient trop grande

On peut faire la plupart des choses dans une expression `let`, y compris la déstructuration, mais les éléments suivants ne sont pas autorisés :

- Les types personnalisés
- Les alias de type
- Le masquage de nom (on ne peut pas redéfinir ni réutiliser un nom qui est déjà dans la portée)

## Simplifie les expressions

Cette expression additionne les cubes de 3 nombres, mais elle est difficile à lire, et il serait facile que le calcul soit différent pour chaque nombre.

```elm
(a * a * a) + (b * b * b) + (c * c * c)
```

On peut définir une fonction `cube` dans une expression `let` pour rendre le calcul plus simple, plus expressif et plus sûr. Cette fonction pourrait avoir une annotation de type, mais dans du code Elm idiomatique, c'est relativement rare.

```elm
let
  cube x = x * x * x
in
  cube a + cube b + cube c
```

## Nomme les résultats des expressions intermédiaires

Ce code définit sideArea et topArea pour rendre le calcul plus simple et plus expressif.

```elm
cylinderArea : Float -> Float -> Float
cylinderArea radius height =
    let
        sideArea = 2 * pi * radius * height
        topArea = pi * radius ^2
    in
        sideArea + 2 * topArea
```

## Découpe une grande expression

Ce code crée un motif initial pour le [Game of Life](https://playgameoflife.com/) (un exercice d'exemple de programmation courant).

Il n'est pas important de comprendre exactement comment cela fonctionne, mais il devrait être évident que ce serait très volumineux si on l'écrivait comme une seule expression, sans `let`.

```elm
beginWithPattern : Size -> Padding -> Pattern -> GameOfLife
beginWithPattern minimumSize padding pattern =
    let
        size = calculateSize minimumSize padding pattern

        center = Size.center size

        centeredPattern = Pattern.centerAt center pattern

        dimensions = { width = size, height = size }

        deadCells = Matrix.create dimensions Dead
    in
    GameOfLife (bringPatternToLife deadCells centeredPattern)
```
