# Tests

## Clojure CLI

Les exercices Clojure d'Exercism sont fournis avec un fichier `deps.edn` qui contient un alias `:test` permettant d'invoquer le [cognitect-labs test-runner](https://github.com/cognitect-labs/test-runner) :

``` bash
clj -X:test
```

## Leiningen

On peut aussi utiliser Leiningen pour exécuter les tests de l'exercice, en lançant la commande suivante depuis le répertoire de l'exercice :

```bash
lein test
```
