# Instructions

La troupe de danse s'aligne en rangs, et tu gardes la trace de qui se tient où.

Les cinq tâches prennent place dans la classe `DANCE_FORMATION`.

## 1. Combien de personnes dans la rangée ?

```sather
DANCE_FORMATION::dancer_count(|"Mia", "Ana", "Ben"|)
-- => 3
```

## 2. Qui mène ?

Le meneur est la personne qui se tient en premier.

```sather
DANCE_FORMATION::leader(|"Mia", "Ana", "Ben"|)
-- => "Mia"
```

## 3. Qui est à l'arrière ?

Le marqueur arrière est la personne qui se tient en dernier, quelle que soit la longueur de la rangée.

```sather
DANCE_FORMATION::back_marker(|"Mia", "Ana", "Ben"|)
-- => "Ben"
```

## 4. La formation d'ouverture

La troupe ouvre toujours dans le même ordre : Mia, Ana, Ben. Renvoie cette rangée.

```sather
DANCE_FORMATION::opening_row
-- => an array holding "Mia", "Ana" and "Ben", in that order
```

Cette routine ne prend aucun argument.

## 5. Compte les pas

Chaque danseur a un certain nombre de pas à faire. Additionne-les.

```sather
DANCE_FORMATION::total_steps(|8, 16, 8|)
-- => 32
```

Une rangée vide, c'est zéro pas.
