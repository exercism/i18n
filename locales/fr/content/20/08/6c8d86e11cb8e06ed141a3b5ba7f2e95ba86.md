# Introduction

PHP permet de déclarer des fonctions à l'intérieur d'autres fonctions. Ces fonctions n'ont pas besoin d'être nommées, mais elles peuvent être affectées à des variables ou même passées directement à une autre fonction qui prend un paramètre de type fonction.

```php
function onlyOdds(array $numbers): array
{
    return array_filter($numbers, function($num) {
        return $num % 2 === 1;
    });
}
```
