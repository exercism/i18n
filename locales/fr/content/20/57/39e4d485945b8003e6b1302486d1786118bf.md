# À propos

Le vocabulaire [`sequences`][sequences] définit un seul [protocole][sequence-protocol] que les tableaux (`{ … }`), les vecteurs (`V{ … }`), les _strings_, les plages et les tranches implémentent tous. Tout ce que l'on peut faire avec l'un, on peut le faire avec les autres.

| mot         | effet                             |
|-------------|-----------------------------------|
| `length`    | `( seq -- n )`                    |
| `first`     | `( seq -- elt )`                  |
| `second`    | `( seq -- elt )`                  |
| `third`     | `( seq -- elt )`                  |
| `fourth`    | `( seq -- elt )`                  |
| `last`      | `( seq -- elt )`                  |
| `rest`      | `( seq -- tailseq )`              |
| `but-last`  | `( seq -- headseq )`              |
| `nth`       | `( n seq -- elt )` (indice à partir de 0) |
| `head`      | `( seq n -- headseq )`            |
| `head*`     | `( seq n -- headseq )` (tous sauf les n derniers) |
| `tail`      | `( seq n -- tailseq )`            |
| `tail*`     | `( seq n -- tailseq )` (les n derniers) |
| `subseq`    | `( from to seq -- newseq )`       |
| `remove-nth`| `( n seq -- newseq )`             |
| `pad-head`  | `( seq n elt -- padded )`         |
| `pad-tail`  | `( seq n elt -- padded )`         |
| `prefix`    | `( seq elt -- newseq )`           |
| `suffix`    | `( seq elt -- newseq )`           |
| `unclip`    | `( seq -- rest first )`           |
| `unclip-last` | `( seq -- butlast last )`       |
| `empty?`    | `( seq -- ? )`                    |
| `if-empty`  | `( seq emptyquot nonemptyquot -- … )` |
| `member?`   | `( elt seq -- ? )`                |
| `reverse`   | `( seq -- newseq )`               |
| `index`     | `( elt seq -- i/f )`              |
| `index-or-length` | `( elt seq -- i )` (longueur si absent) |
| `count`     | `( seq quot -- n )`               |
| `concat`    | `( seqs -- seq )`                 |
| `sum`       | `( seq -- n )`                    |
| `product`   | `( seq -- n )`                    |
| `find`      | `( seq quot -- i/f elt/f )`       |
| `find-last` | `( seq quot -- i/f elt/f )`       |
| `produce`   | `( pred quot -- seq )`            |

Les tableaux ont une longueur fixe, donc les opérations `prefix`/`suffix`/`append`/`prepend` renvoient toutes de nouvelles séquences plutôt que d'agrandir l'original. Les vecteurs sont redimensionnables : `push` et `pop` agissent sur place, mais `clone` est le bon point de départ si tu veux une nouvelle copie.

## Conversions

`>array`, `>string` et `>vector` (dans leurs vocabulaires respectifs) convertissent n'importe quelle séquence vers le type concret nommé. Utilise-les quand un appelant veut une représentation spécifique, ou pour matérialiser une tranche ou une autre séquence paresseuse.

```factor
USING: arrays sequences strings vectors ;

V{ 1 2 3 } >array  .   ! => { 1 2 3 }
{ 65 66 67 } >string . ! => "ABC"
"abc" >vector .        ! => V{ CHAR: a CHAR: b CHAR: c }
```
