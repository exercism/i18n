# Promotion des propriétés de constructeur

Dans les classes qui déclarent de nombreuses propriétés, déclarer séparément la classe, ses propriétés et un constructeur qui les affecte oblige à tout répéter.
La promotion des propriétés de constructeur permet de réduire le nombre de répétitions.

```php
<?php

class Book
{
    private string $isbn;
    private string $doi;
    private string $title;

    public function __construct(string $isbn, string, $doi, string $title)
    {
        $this->isbn = $isbn;
        $this->doi = $doi;
        $this->title = $title;
    }
}

// Using constructor property promotion
class Book
{
    public function __construct(
        private string $isbn,
        private string $doi,
        private string $title
    ) {
    }
}
