# Instructions

Dans cet exercice, tu vas traiter des lignes de journal.

Chaque ligne de journal est une _string_ au format suivant : `"[<LEVEL>]: <MESSAGE>"`.

Il existe trois niveaux de journal différents :

- `INFO`
- `WARNING`
- `ERROR`

Tu as trois tâches à accomplir ; chacune prend une ligne de journal et te demande d'en faire quelque chose.
Il existe de nombreuses façons de résoudre ces tâches : choisis tes techniques préférées parmi les exemples ci-dessus et vois ce que tu peux imaginer.

## 1. Récupère le message d'une ligne de journal

Implémente la fonction `message` pour qu'elle renvoie le message d'une ligne de journal :

```jq
"[ERROR]: Invalid operation" | message
# => "Invalid operation"
```

Les espaces blancs au début et à la fin doivent être supprimés :

```jq
"[WARNING]:  Disk almost full\r\n" | message
# => "Disk almost full"
```

## 2. Récupère le niveau d'une ligne de journal

Implémente la fonction `log_level` pour qu'elle renvoie, en minuscules, le niveau indiqué dans une ligne de journal :

```ruby
"[ERROR]: Invalid operation" | log_level
# => "error"
```

## 3. Reformate une ligne de journal

Implémente la fonction `reformat`, qui reformate la ligne de journal en plaçant le message en premier, suivi du niveau de journal entre parenthèses :

```ruby
"[INFO]: Operation completed" | reformat
# => "Operation completed (info)"
```
