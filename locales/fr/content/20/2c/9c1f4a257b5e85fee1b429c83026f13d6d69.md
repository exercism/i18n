## Indices

Pour cet exercice, les fonctionnalités F# suivantes sont utiles :
- [(..) start finish](https://fsharp.github.io/fsharp-core-docs/reference/fsharp-core-operators.html#(..)) permet de créer de façon concise une plage de valeurs.
- [List.sumBy](https://fsharp.github.io/fsharp-core-docs/reference/fsharp-collections-listmodule.html#sumBy) est un format condensé pour appliquer une fonction à un tableau puis additionner les résultats.
