# Introduction

## Boucles _for_

L'instruction `for` répète un bloc de code.
Sa première ligne contrôle la fréquence à laquelle le bloc se répète :

```go
for init; condition; post {
    // loop body
}
```

- L'instruction **init** s'exécute une seule fois avant la première itération. Il est courant de déclarer et d'initialiser une variable compteur utilisée par la boucle.
- La **condition** est une expression booléenne évaluée avant chaque itération. La boucle s'arrête lorsque celle-ci s'évalue à `false`.
- L'instruction **post** s'exécute après chaque itération terminée. Elle peut servir à mettre à jour un compteur.

N'entoure pas `init; condition; post` de parenthèses.
En revanche, les accolades qui entourent le corps de la boucle sont toujours obligatoires.

Cette boucle initialise `i` à `1`, affiche la valeur courante de `i`, l'incrémente pour l'itération suivante et s'arrête lorsque `i` atteint `10` :

```go
for i := 1; i < 10; i++ {
    fmt.Println(i)
}
```
