# Introduction

En Cairo, les booléens sont représentés par le type booléen prédéclaré `bool`, dont les valeurs peuvent être soit `true`, soit `false`.

```rust
let speeding = true;   // Boolean variable 'speeding' set to 'true'
let has_error = false; // Boolean variable 'has_error' set to 'false' 
```

Cairo prend en charge trois opérateurs logiques, qui évaluent des expressions en valeurs booléennes et renvoient soit `true`, soit `false`.

| Opérateur   | Ce que ça signifie                                  |
| ----------- | --------------------------------------------------- |
| `&&` (et)   | Il est vrai si les deux assertions sont vraies.     |
| `\|\|` (ou) | Il est vrai si au moins une assertion est vraie.    |
| `!` (non)   | Il est vrai seulement si l'assertion est fausse.    |
