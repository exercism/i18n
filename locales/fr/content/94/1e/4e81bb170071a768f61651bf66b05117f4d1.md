# Introduction

Une `str` en Python est une [séquence immuable][text sequence] de [points de code Unicode][unicode code points].
Ceux-ci peuvent inclure des lettres, des signes diacritiques, des caractères de positionnement, des nombres, des symboles monétaires, des emojis, de la ponctuation, différents espaces, des sauts de ligne, et bien d’autres choses encore.

Les _strings_ implémentent toutes les [opérations courantes sur les séquences][common sequence operations] et peuvent être parcourues avec la syntaxe `for item in <str>` ou `for index, item in enumerate(<str>)`.
On peut les concaténer avec `<str> + <other str>` ou `<str>.join(<iterable>)`, les découper avec `<str>.split(<separator>)`, et elles offrent de multiples options de formatage et d’assemblage.

Pour aller plus loin dans le travail sur les _strings_, Python fournit tout un ensemble de [méthodes de _string_][str-methods] qui aident à rechercher, nettoyer, transformer, traduire, et à bien d’autres opérations encore.

Une `str` étant _immuable_, la valeur de l’objet en mémoire ne change pas ; les méthodes qui semblent modifier une _string_ renvoient une nouvelle copie ou une nouvelle instance de cet objet `str`.
