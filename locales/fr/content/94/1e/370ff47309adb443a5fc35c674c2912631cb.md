# Base de données : dépenses élevées

## Énoncé du problème

ABC Corp a besoin qu'on trouve le nom et le département des employés dont les enregistrements de paiement dépassent un montant donné (par exemple `3000.00`).

Crée un _record_ nommé `HighPayment` pour renvoyer les données demandées. La définition de ce _record_ est la suivante.

```ballerina
type HighPayment record {
    string name;
    string department;
    decimal amount;
    string reason;
};
```

Utilise l'opération `query` du client JDBC pour récupérer les données demandées depuis la base de données.

> Remarque : trie le résultat par `payment_id` par ordre croissant.

## Détails de la base de données

Utilise la base de données H2 fournie pour ce problème.

> Le fichier de base de données d'exemple est `gofigure.mv.db`, et le nom de la base de données est `gofigure`. Il se trouve dans le dossier `db`.

Les tables suivantes existent déjà dans la base H2 d'exemple, avec quelques données d'exemple. Les noms de colonnes et les types de données sont indiqués ci-dessous.

**Nom de la table** : `Employee`

| **Colonnes :**      | type |
| -----------       | ----------- |
| `employee_id`     | entier, clé primaire auto-incrémentée       |
| `name`            | chaîne de caractères        |
| `city`            | chaîne de caractères        |
| `department`      | chaîne de caractères        |
| `age`             | entier        |

**Nom de la table** : `Payment`

| **Colonnes :**      | type |
| -----------       | ----------- |
| `payment_id`      | entier, clé primaire auto-incrémentée       |
| `date`            | date        |
| `amount`          | décimal        |
| `employee_id`     | entier        |
| `reason`          | chaîne de caractères        |

* Le fichier de base de données est `gofigure.mv.db`. Utilise l'URL JDBC suivante : `jdbc:h2:file:/path/to/db/file`
* Nom d'utilisateur : `root`
* Mot de passe : `root`

## Contraintes

* Utilise le fichier de base de données H2 fourni dans le dossier `db` pour valider les requêtes ainsi que l'exemple Ballerina
* Utilise l'approche des _params_ de dépendance Maven pour ajouter le pilote de base de données H2 comme dépendance de plateforme dans ton fichier Ballerina.toml

## Environnement de test

* Tu peux lancer les tests avec `bal test`, qui s'exécutent sur la base d'exemple fournie.
