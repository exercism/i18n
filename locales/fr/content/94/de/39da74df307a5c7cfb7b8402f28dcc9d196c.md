# Instructions

Dans cet exercice, tu vas implémenter la logique de quête d'un nouveau jeu de rôle qu'un ami est en train de développer.

Le personnage principal du jeu est Annalyn, une jeune fille courageuse accompagnée d'un chien de compagnie féroce et fidèle. Malheureusement, le malheur frappe : son meilleur ami a été enlevé alors qu'il cherchait des baies dans la forêt.

Annalyn va tenter de retrouver et de libérer son meilleur ami, en emmenant éventuellement son chien avec elle dans cette quête.

Après avoir suivi la trace de son meilleur ami pendant un moment, elle trouve le camp où celui-ci est retenu prisonnier. Il s'avère qu'il y a deux ravisseurs : un chevalier puissant et un archer rusé.

Ayant trouvé les ravisseurs, Annalyn réfléchit aux actions suivantes qu'elle peut entreprendre :

- _Attaque rapide_ : une attaque rapide est possible si le chevalier dort, car il lui faut du temps pour enfiler son armure, ce qui le laisse vulnérable.
- _Espionnage_ : on peut espionner le groupe si au moins l'un d'entre eux est éveillé. Sinon, espionner est une perte de temps.
- _Signaler au prisonnier_ : on peut signaler sa présence au prisonnier à l'aide de cris d'oiseaux si le prisonnier est éveillé et que l'archer dort, car les archers sont entraînés à imiter les cris d'oiseaux et pourraient donc intercepter le message.
- _Libérer le prisonnier_ : Annalyn peut tenter de s'infiltrer dans le camp pour libérer le prisonnier.
  C'est une entreprise risquée qui ne peut réussir que de deux façons :
  - Si Annalyn a son chien avec elle, elle peut sauver le prisonnier si l'archer dort.
    Le chevalier a peur du chien et l'archer n'aura pas le temps de se préparer avant qu'Annalyn et le prisonnier ne puissent s'échapper.
  - Si Annalyn n'a pas son chien, elle et le prisonnier doivent alors faire preuve de beaucoup de discrétion !
    Annalyn peut libérer le prisonnier si le prisonnier est éveillé et que le chevalier et l'archer dorment tous les deux, mais si le prisonnier dort, il ne peut pas être sauvé : le prisonnier serait surpris par l'apparition soudaine d'Annalyn et réveillerait le chevalier et l'archer.

Tu as quatre tâches : implémenter la logique qui détermine si les actions ci-dessus sont possibles, en fonction de l'état des trois personnages trouvés dans la forêt et de la présence ou non du chien d'Annalyn.

## 1. Vérifier si une attaque rapide est possible

Implémente la méthode `canFastAttack()`, qui prend une valeur booléenne indiquant si le chevalier est éveillé. Cette méthode renvoie `true` si une attaque rapide est possible compte tenu de l'état du chevalier. Sinon, elle renvoie `false` :

```haxe
var knightIsAwake = true;
canFastAttack(knightIsAwake);
// => false
```

## 2. Vérifier si le groupe peut être espionné

Implémente la méthode `canSpy()`, qui prend trois valeurs booléennes indiquant respectivement si le chevalier, l'archer et le prisonnier sont éveillés. La méthode renvoie `true` si le groupe peut être espionné, compte tenu de l'état des trois personnages. Sinon, elle renvoie `false` :

```haxe
var knightIsAwake = false;
var archerIsAwake = true;
var prisonerIsAwake = false;
canSpy(knightIsAwake, archerIsAwake, prisonerIsAwake);
// => true
```

## 3. Vérifier si l'on peut signaler au prisonnier

Implémente la méthode `canSignalPrisoner()`, qui prend deux valeurs booléennes indiquant respectivement si l'archer et le prisonnier sont éveillés. La méthode renvoie `true` si l'on peut signaler au prisonnier, compte tenu de l'état des deux personnages. Sinon, elle renvoie `false` :

```haxe
var archerIsAwake = false;
var prisonerIsAwake = true;
canSignalPrisoner(archerIsAwake, prisonerIsAwake);
// => true
```

## 4. Vérifier si le prisonnier peut être libéré

Implémente la méthode `canFreePrisoner()`, qui prend quatre valeurs booléennes. Les trois premiers paramètres indiquent respectivement si le chevalier, l'archer et le prisonnier sont éveillés. Le dernier paramètre indique si le chien d'Annalyn est présent. La méthode renvoie `true` si le prisonnier peut être libéré, compte tenu de l'état des trois personnages et de la présence du chien d'Annalyn. Sinon, elle renvoie `false` :

```haxe
var knightIsAwake = false;
var archerIsAwake = true;
var prisonerIsAwake = false;
var petDogIsPresent = false;
canFreePrisoner(knightIsAwake, archerIsAwake, prisonerIsAwake, petDogIsPresent);
// => false
```
