# Indentation

[comment]: # (Ce commentaire est renvoyé quand la solution utilise au moins une tabulation pour l'indentation)

Le code Elixir doit être indenté avec 2 espaces. Veille à ne pas utiliser de tabulations pour l'indentation.

Si tu résous les exercices Elixir sur ton propre ordinateur, pense à exécuter `mix format` dans le dossier de l'exercice. Cet outil remettra automatiquement ton code au format attendu par la communauté, et corrigera notamment tous les problèmes d'indentation.
