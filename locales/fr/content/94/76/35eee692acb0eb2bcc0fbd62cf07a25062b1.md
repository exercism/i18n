# Instructions

Tu es un elfe qui travaille dans la division logistique du père Noël et le patron t'a confié deux tâches pour mettre à jour le logiciel du système.

## 1. Récupère le nom du jouet

Le système doit pouvoir récupérer le nom d'un jouet depuis la base de données.
La base de données est constituée de tuples de type `(name: String, quantity: Int)`.

Implémente la fonction `getName(_:)`, qui prend un argument contenant un tuple de type `(name: String, quantity: Int)`.

```swift
let toy = (name: "Doll", quantity: 10)
getName(toy)
// Returns "Doll"
```

## 2. Ajoute un nouveau jouet à la base de données

Le marché du jouet est un marché rapide et changeant : ce qui est populaire évolue très vite.
Il faut donc une fonction qui crée un nouveau jouet.

Implémente la fonction `createToy(name:amount:)`, qui prend un argument `name` contenant le nom du jouet, et `amount` contenant la quantité du jouet.

```swift
createToy(name: "Doll", amount: 10)
// Returns (name: "Doll", amount: 10)
```

## 3. Mets à jour la quantité d'un jouet

Les elfes de l'atelier du père Noël fabriquent sans cesse de nouveaux jouets, et le père Noël doit suivre la quantité de chaque jouet.
Pour cela, le système doit pouvoir mettre à jour la quantité d'un jouet dans la base de données.

Implémente la fonction `updateQuantity(_:toy:Amount:)`, qui prend les arguments :
- `toys` qui contient un tableau de tuples de type `(name: String, quantity: Int)`.
- `toy` qui contient le nom du jouet à mettre à jour.
- `amount` qui contient la nouvelle quantité du jouet.

Tu peux supposer que le jouet est déjà dans la base de données, et tu n'as pas besoin de le vérifier.

```swift
let toys = [(name: "Doll", quantity: 10), (name: "Car", quantity: 5), (name: "Train", quantity: 3)]
updateQuantity(toys, toy: "Doll", amount: 15)
// Returns [(name: "Doll", quantity: 15), (name: "Car", quantity: 5), (name: "Train", quantity: 3)]
```

## 4. Ajoute une clé de catégorie à un jouet

Le père Noël veut pouvoir catégoriser les jouets de la base de données.
Ainsi, il peut facilement retrouver les jouets quand il doit faire une livraison, et trier les jouets de la base de données.

Cependant, lors de la première implémentation du système, la clé de catégorie a été oubliée.
Maintenant, le système doit pouvoir ajouter une clé de catégorie à un jouet dans la base de données.

Implémente la fonction `addCategory(_:category:)`, qui prend les arguments :
- `toys` qui contient un tableau de tuples de type `(name: String, quantity: Int)`.
- `category` qui contient la clé de catégorie à ajouter aux jouets.

Tu peux supposer que le jouet est déjà dans la base de données, et tu n'as pas besoin de le vérifier.
Tu peux aussi supposer que le jouet n'a pas déjà de clé de catégorie.

```swift
let toys = [(name: "Car", quantity: 5), (name: "Train", quantity: 3)]
addCategory(toys, category: "Vehicle")
// Returns [(name: "Car", quantity: 5, category: "Vehicle"), (name: "Train", quantity: 3, category: "Vehicle")]
```
