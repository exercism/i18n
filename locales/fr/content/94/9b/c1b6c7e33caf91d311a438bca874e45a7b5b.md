# Instructions

Elena est la nouvelle responsable qualité d'une usine de journaux.
Comme elle vient tout juste d'arriver dans l'entreprise, elle a décidé de passer en revue certains processus de l'usine pour voir ce qui pourrait être amélioré.

Elle a découvert que les techniciens effectuent de nombreux contrôles qualité à la main.

Elle y voit une belle occasion d'automatiser les choses et te demande, à toi qui es développeur freelance, de concevoir un logiciel pour surveiller certaines machines.

## 1. Surveille le taux d'humidité de la salle

Ta première mission est d'écrire un logiciel pour surveiller le taux d'humidité de la salle de production.
Un capteur est déjà connecté au logiciel de l'entreprise et renvoie régulièrement le pourcentage d'humidité de la salle.

Tu dois implémenter une fonction dans le logiciel qui lèvera une erreur si le pourcentage d'humidité est trop élevé.
La fonction doit s'appeler `check_humidity_level` et prendre le pourcentage d'humidité comme paramètre.

Si le pourcentage dépasse 70 %, tu dois t'arrêter avec une erreur (le message n'a pas d'importance).
Sinon, émets un message qui contient « humidity test passed » et renvoie `TRUE` pour confirmer que la mesure est bonne.

```R
check_humidity_level(60)
#> humidity test passed
#> [1] TRUE

check_humidity_level(100)
#> Error in check_humidity_level(100) : pct_humidity <= 70 is not TRUE
```

## 2. Détecte la surchauffe

Elena est très satisfaite de ta première mission et te demande de t'occuper de la surveillance de la température des machines.
Alors que tu discutes avec un technicien, Greg, il t'apprend que si la température d'une machine dépasse 500 °C, les techniciens commencent à s'inquiéter d'une surchauffe.

La machine est équipée d'un capteur qui mesure sa température interne.
Sache que le capteur est très sensible et tombe souvent en panne.
Dans ce cas, les techniciens doivent le remplacer.

Ton travail consiste à implémenter une fonction `report_overheating` qui prend la température comme paramètre et lève une erreur si le capteur est cassé ou si la machine commence à surchauffer.

Sachant que tu devras plus tard réagir différemment selon l'erreur, tu as besoin d'un mécanisme pour distinguer les deux types d'erreurs.

- Si le capteur est cassé, la température vaudra `NULL`.
  Dans ce cas, tu dois t'arrêter avec un message d'erreur qui contient « Sensor Broken ».
- Lorsque le capteur fonctionne, si la température dépasse 600 °C, tu dois t'arrêter avec un message qui contient la température.
- Si la température dépasse 500 °C sans atteindre 600 °C, tu dois émettre un avertissement qui contient la température et renvoyer `FALSE`.
- Sinon, tout va bien : émets le message `"temperature check passed: t °C"`, où `t` est la température, et renvoie `TRUE`.

```R
report_overheating(NULL)
#> Error in report_overheating(NULL) : Sensor Broken

report_overheating(800)
#> Error in report_overheating(800) : Overheating: 800 C

report_overheating(550)
#> [1] FALSE
#> Warning message:
#> In report_overheating(550) : Risk of overheating: 550 C

report_overheating(450)
#> temperature check passed: 450 °C
#> [1] TRUE
```


## 3. Surveille la machine

Maintenant que ta machine sait détecter les erreurs et que tu disposes d'une erreur personnalisée, tu ajoutes une fonction d'encapsulation qui peut rendre compte de l'état général.
En plus de renvoyer les _logs_ des fonctions précédentes, cette fonction d'encapsulation devra aussi ajouter des _logs_ selon le ou les types de pannes qui surviennent.

- Vérifie l'humidité et la température.
- En cas de problème, laisse simplement `check_humidity_level()` et `report_overheating()` produire leurs _logs_.
- Si tout va bien, ajoute un message qui contient « All OK ».

Implémente une fonction `monitor_the_machine()` qui prend l'humidité et la température comme arguments.

```R
# Working well
monitor_the_machine(53, 200)
#> humidity test passed
#> temperature check passed: 200 °C
#> All OK!

# High humidity
monitor_the_machine(90, 200)
#> Error in check_humidity_level(pct_humidity) : 
#>   pct_humidity <= 70 is not TRUE

# Faulty sensor
monitor_the_machine(53, NULL)
#> humidity test passed
#> Error in report_overheating(temperature) : Sensor Broken

# Mild overheating
monitor_the_machine(53, 550)
#> humidity test passed
#> Warning message:
#> In report_overheating(temperature) : Risk of overheating: 550 C

# Dangerous overheating: shutdown
monitor_the_machine(53, 650)
#> humidity test passed
#> Error in report_overheating(temperature) : Overheating: 650 C
```
