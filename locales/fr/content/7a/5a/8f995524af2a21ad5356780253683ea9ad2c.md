# À propos

Chapel est un langage de programmation conçu pour le calcul parallèle productif à grande échelle. Il permet aux chercheurs et aux professionnels de l'industrie d'exploiter facilement la puissance du calcul haute performance, sans sacrifier la productivité ni la lisibilité.

### Caractéristiques principales

- **productif** : le code est généralement aussi lisible et facile à écrire qu'en Python
- **évolutif** : fonctionne sur les ordinateurs portables, les clusters, le cloud et les systèmes HPC
- **rapide** : ses performances rivalisent avec celles de C/C++ et de MPI et d'OpenMP, voire les surpassent
- **portable** : se compile et s'exécute dans pratiquement n'importe quel environnement \*nix
- **open source** : hébergé sur GitHub, sous licence permissive.
