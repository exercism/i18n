# Tests

Pour exécuter la suite de tests :
```bash
tclsh exercise.test
```

## Tests ignorés

Résoudre un exercice, c'est faire passer tous ses tests. Par défaut, un seul test (le premier) est exécuté quand tu lances les tests. C'est voulu : cela te permet de te concentrer uniquement sur celui-là, le temps de le faire passer. Une fois qu'il passe, tu peux activer le test suivant en commentant ou en supprimant la commande `skip` qui le précède.

Autrement, pour exécuter tous les tests quel que soit leur statut « ignoré » :
```bash
RUN_ALL=1 tclsh exercise.test
```
