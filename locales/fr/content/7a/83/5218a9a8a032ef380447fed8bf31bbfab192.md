# Indices

## Général

- N'oublie pas d'exporter les trois sous-programmes publics.
  Liste-les dans le tableau `@EXPORT_OK`.

## 1. Vérifie si une date donnée est dans le passé

- Pour l'analyse des chaînes de date, celles-ci seront fournies au format ISO 8601.
  Utilise la variable de paquetage `$STRPTIME_FORMAT`.
- Les méthodes `Time::Piece->strptime` ou `DateTime::Tiny->from_string` te seront utiles.

## 2. Vérifie si une date donnée est dans l'après-midi

- L'« après-midi » commence à midi et se termine avant 18 h 00.

## 3. Analyse une date pour en faire une _string_ décrivant un rendez-vous

- Utilise `mm/dd/yyyy` comme format de date en sortie.
  Par exemple : 12/31/2021
- Le format d'heure en sortie utilise l'heure comprise entre 0 et 12, sans zéro ni espace en tête, et l'indicateur ampm en majuscules.
  Par exemple : 7:59 PM
- Si tu utilises le module Time::Piece, la méthode `strftime` est appropriée.
