# Introduction

Une `list` en R est une collection ordonnée d'éléments, qui diffère des `vectors` sur quelques points :

- Les éléments peuvent être de types différents (par exemple en mélangeant des `numeric` et des `character`).
- Les éléments peuvent être des structures complexes (par exemple des vecteurs, d'autres listes, etc.).
- La syntaxe d'accès aux éléments est différente.

Les analogies avec d'autres langages sont imparfaites. 
Une `list` R ressemble un peu à un dictionnaire Python, mais elle est ordonnée et on peut y accéder par un indice numérique.
Elle ressemble aussi un peu à une `struct` C, à la difference qu'une `list` peut facilement être étendue à l'exécution.

## Crée des listes

Donner des noms (souvent appelés _tags_) aux éléments est plus courant avec les listes qu'avec les vecteurs :

```R
list(x = 5.3, y = 4.2, color = "blue")
$x
#> [1] 5.3

$y
#> [1] 4.2

$color
#> [1] "blue"
```

Cependant, les _tags_ sont facultatifs et R utilise alors simplement des indices numériques :

```R
list(5.3, 4.2, "blue")
#> [[1]]
#> [1] 5.3

#> [[2]]
#> [1] 4.2

#> [[3]]
#> [1] "blue"
```

## Accède aux éléments d'une liste

Il y a trois façons de procéder, chacune utile dans un contexte différent.

### 1. Avec la notation `$tag`

Très courant lorsque les noms des _tags_ sont connus à l'avance.

```R
point <- list(x = 5.3, y = 4.2, color = "blue")
point$x
#> [1] 5.3
point$color
#> [1] "blue"
```

### 2. Avec la notation `[[tag]]`

Cette notation a l'avantage de permettre de choisir le nom du _tag_ à l'exécution.
Remarque les doubles crochets.

```R
want <- "y"
point[[want]] # same as point$y
#> [1] 4.2
```

### 3. Avec un indice de position

Cette méthode fonctionne que la liste ait des _tags_ ou non.
Là encore, les crochets sont doublés.

```R
point[[3]] # same as point$color
#> [1] "blue"
```

## Ajoute et supprime des éléments

Tout simple : affecter une valeur à un élément le modifie s'il existe déjà, ou l'insère s'il est nouveau.

```R
point$color <- "red"
point$trust <- TRUE
str(point)
#> List of 4
#>  $ x    : num 5.3
#>  $ y    : num 4.2
#>  $ color: chr "red"
#>  $ trust: logi TRUE
```

Pour supprimer un élément, il suffit de lui affecter `NULL`.

```R
point$trust <- NULL
str(point)
#> List of 3
#>  $ x    : num 5.3
#>  $ y    : num 4.2
#>  $ color: chr "red"
```
