# Indices

## Généralités

- Reviens sur le [concept Objects][concept-class-basics] si nécessaire pour revoir les bases.
- Lis attentivement les instructions concernant l'ordre des paramètres `x`, `y`, `width` et `height`. Ils sont faciles à confondre.

## 1. Définis une classe ProgramWindow

- Pense à utiliser la [syntaxe des classes][php-class] pour cette tâche.
- Définis les [propriétés][php-properties] en les ajoutant à la déclaration de la classe.

## 2. Définis une fonction constructeur pour la classe ProgramWindow

- Vérifie que ta fonction constructeur n'accepte aucun argument.
- Vérifie que chaque propriété est bien affectée à la valeur entière attendue.

## 3. Ajoute une méthode pour redimensionner la fenêtre

- Pense à utiliser une nouvelle [classe][php-class] dans le fichier `Size.php` pour cette tâche.
  - Par convention, un fichier ne contient généralement qu'une seule classe.
- Le constructeur de `Size` doit accepter des arguments pour les valeurs initiales des [propriétés][php-properties] de la classe.
- Crée une méthode `resize` sur l'objet `ProgramWindow` pour appliquer le changement à l'aide d'une instance de `Size`.

## 4. Ajoute une méthode pour déplacer la fenêtre

- Pense à utiliser une nouvelle [classe][php-class] dans le fichier `Position.php` pour cette tâche.
  - Par convention, un fichier ne contient généralement qu'une seule classe.
- Le constructeur de `Position` doit accepter des arguments pour les valeurs initiales des [propriétés][php-properties] de la classe.
- Crée une méthode `move` sur l'objet `ProgramWindow` pour appliquer le changement à l'aide d'une instance de `Position`.
