# Indices

## Généralités

- Essaie de décomposer un problème en un cas de base et un cas récursif. Par exemple, imaginons que tu veuilles compter combien de cookies se trouvent dans le bocal à cookies avec une approche récursive. Le cas de base est un bocal vide : il contient zéro cookie. Si le bocal n'est pas vide, alors le nombre de cookies dans le bocal est égal à un cookie plus le nombre de cookies dans le bocal après en avoir retiré un.

## 1. Définis les types de pizza et les options

- Le type `Pizza` est un [type récursif][recursive-types], dont les cas `ExtraSauce` et `ExtraToppings` « enveloppent » une pizza.

## 2. Calcule le prix d'une pizza

- Pour gérer le fait que le type `Pizza` soit un [type récursif][recursive-types], définis une [fonction récursive][recursive-functions].
