# Binaire, octal et hexadécimal

Le binaire, l'octal et l'hexadécimal (_également appelé hexa_) sont différents [systèmes de numération][numeral-systems] avec des bases différentes.
Le binaire est en base 2, l'octal en base 8 et l'hexadécimal en base 16.
Les entiers ordinaires sont en base 10 en Crystal.
Le binaire, l'octal et l'hexadécimal sont tous des représentations d'entiers.
Cela signifie qu'ils représentent des nombres positifs et négatifs (_y compris zéro_) sans fractions ni décimales, et prennent en charge toutes les opérations que l'on peut faire avec des entiers.

## Binaire

Le [binaire][binary] est un système de numération en base 2, qui n'utilise que les chiffres 0 et 1.
Il représente couramment les états 0 (« éteint ») et 1 (« allumé ») du flux électrique à travers les transistors et les interrupteurs des ordinateurs, ainsi que les charges positives et négatives des supports de stockage magnétiques.
Le binaire peut représenter tous les entiers utilisés en base 10.

Un extrait du système en base 2 ressemble à ceci, même s'il continue à l'infini et ne s'arrête pas à 128 :

| 128      | 64       | 32       | 16       | 8        | 4        | 2        | 1        |
| -------- | -------- | -------- | -------- | -------- | -------- | -------- | -------- |
| 2 \*\* 7 | 2 \*\* 6 | 2 \*\* 5 | 2 \*\* 4 | 2 \*\* 3 | 2 \*\* 2 | 2 \*\* 1 | 2 \*\* 0 |

Donc, si on veut représenter le nombre 6, ce serait en binaire : 110

| Valeur de position | 4   | 2   | 1   |
| ------------------ | --- | --- | --- |
| Nombre binaire     | 1   | 1   | 0   |

Et l'opération serait : `4 + 2 + 0 = 6`

Autre exemple : 19

| Valeur de position | 16  | 8   | 4   | 2   | 1   |
| ------------------ | --- | --- | --- | --- | --- |
| Nombre binaire     | 1   | 0   | 0   | 1   | 1   |

Le nombre binaire serait : 10011
Et l'opération serait : `16 + 0 + 0 + 2 + 1 = 19`

## Le binaire en Crystal

En Crystal, on peut représenter des littéraux binaires à l'aide du préfixe `0b`.
Si on écrit `0b10011`, Crystal l'interprète comme un nombre binaire et le convertit en base 10.

```crystal
0b10011
# => 19

typeof(0b10011)
# => Int32
```

Si tu écris un nombre avec un préfixe `0b` qui n'est pas dans le système binaire, cela provoquera une erreur de compilation.

```crystal
0b10211
# => Error: unexpected token: "211"
```

### Les opérations avec les nombres binaires

Comme les nombres binaires sont des entiers, on peut leur appliquer toutes les opérations que l'on peut faire avec des entiers.

```crystal
0b10011 + 0b10011
# => 38

0b10011 * 0b10011
# => 361

0b10011 / 3
# => 6.333333333333333
```

### Convertir vers et depuis la représentation binaire

Crystal convertit automatiquement un littéral binaire en `Int32`.
Pour convertir un `Int32` en représentation binaire, utilise la méthode [`<int>.to_s(base)`][to_s] avec l'argument de base défini à 2.
La méthode renvoie le nombre binaire sous la forme d'une _string_ :

```crystal
19.to_s(2)
# => "10011"
```

Pour convertir la représentation _string_ d'un nombre binaire en entier, on peut utiliser la méthode [`<int>.to_i(base)`][to_i] en lui passant la base (2) comme argument :

```crystal
"10011".to_i(2)
# => 19
```

Donner la mauvaise base (_ou une représentation binaire invalide_) provoquera une `ArgumentError` :

```crystal
"011021".to_i(2)
# => Invalid Int32: "011021" (ArgumentError)
```

### Les méthodes binaires

Certaines méthodes peuvent être utilisées sur les entiers pour obtenir des informations sur la représentation binaire du nombre.

[`<int>.bit_length`][bit_length] renvoie le nombre de bits nécessaires pour représenter le nombre :

```crystal
19.bit_length
# => 5
```

[`<int>.bit(index)`][bit] renvoie le bit à l'indice donné, en partant de la droite (_bit de poids faible_) :

```crystal
19.bit(0)
# => 1

0b10011.bit(1)
# => 1
```

## Octal

L'[octal][octal] est un système de numération en base 8.
Il utilise les chiffres 0, 1, 2, 3, 4, 5, 6 et 7.

En Crystal, on peut représenter des nombres octaux à l'aide du préfixe `0o`.
Comme pour le binaire, Crystal convertit automatiquement une représentation octale en `Int32`.

```crystal
0o123
# => 83
```

Préfixer avec `0o` un nombre qui n'est pas dans le système octal provoquera une erreur de compilation.

### Convertir vers et depuis la représentation octale

Comme pour le binaire, on peut utiliser la méthode [`<int>.to_s(base)`][to_s] pour convertir un `Int32` en représentation octale.
Et on peut utiliser la méthode [`<int>.to_i(base)`][to_s] pour convertir une représentation octale en `Int32`.

```crystal
83.to_s(8)
# => "123"

"123".to_i(8)
# => 83
```

Comme pour le binaire, donner la mauvaise base provoquera une `ArgumentError`.

## Hexadécimal

L'[hexadécimal][hexadecimal] est un système de numération en base 16.
Il utilise les chiffres de 0 à 9 et les lettres A, B, C, D, E et F.
A vaut 10, B vaut 11, C vaut 12, D vaut 13, E vaut 14 et F vaut 15.

On peut représenter des nombres hexadécimaux en Crystal à l'aide du préfixe `0x`.
Comme pour le binaire et l'octal, Crystal convertit automatiquement les littéraux hexadécimaux en `Int32`.

```crystal
#=> 0x123
291
```
 
Préfixer avec `0x` un nombre qui n'est pas hexadécimal provoquera une erreur de compilation.

### Convertir vers et depuis la représentation hexadécimale

Comme pour le binaire, on peut utiliser la méthode [`<int>.to_s(base)`][to_i] pour convertir un `Int32` en représentation hexadécimale.
Et on peut utiliser la méthode [`<int>.to_i(base)`][to_s] pour convertir une représentation hexadécimale en `Int32`.

```crystal
291.to_s(16)
# => "123"

"123".to_i(16)
# => 291
```

Comme pour le binaire et l'octal, donner la mauvaise base provoquera une `ArgumentError`.

## Précision

Lorsqu'on convertit un nombre en une représentation _string_, on peut spécifier la précision du nombre.
C'est-à-dire le nombre **minimum** de chiffres utilisés pour représenter le nombre.
Si le nombre a moins de chiffres que la précision, des zéros non significatifs sont ajoutés à la représentation _string_.
Pour cela, on passe l'argument `precision` à la méthode [`<int>.to_s(<base>, precision: <value>)`][to_s].

```crystal
291.to_s(16, precision: 5)
# => "00123"

543.to_s(precision: 2)
# => "543"
```

## Mise en majuscules

Lorsqu'on convertit un nombre en une représentation _string_, on peut préciser si on veut que les lettres de la _string_ soient en majuscules.
Pour cela, on passe l'argument `upcase` à la méthode [`<int>.to_s(<base>, upcase: <value>)`][to_s].

```crystal
255.to_s(16, upcase: true)
# => "FF"

255.to_s(16, upcase: false)
# => "ff"
```
