# Tests

Il y a deux façons différentes de se préparer à exécuter les tests avec Objective-C :

- Créer un projet Xcode avec une cible de test qui exécutera les tests.
- Utiliser le gem Ruby `objc` comme utilitaire d'exécution des tests.

Les deux sont décrits plus en détail ici : https://exercism.org/tracks/objective-c/tests
