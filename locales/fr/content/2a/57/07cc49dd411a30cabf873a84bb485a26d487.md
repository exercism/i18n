# Visibilité

Quand on utilise des classes pour organiser le code, la visibilité des propriétés, des méthodes et des constantes encourage des abstractions et des responsabilités appropriées.
La visibilité des propriétés, des méthodes et des constantes est définie par l'utilisation des mots-clés `public`, `private` ou `protected` au moment de leur déclaration.
La visibilité se conçoit toujours par rapport à un usage externe de la propriété, de la méthode ou de la constante de la classe.
Autrement dit, si une propriété est déclarée `public`, elle est observable et utilisable par des appels externes.
Les propriétés, méthodes et constantes privées ne sont pas observables ni utilisables par des appels externes.

```php
<?php

class SecretDocument
{
    private $encryption_key;

    public $title;

    public function __construct($encryption_key, $title)
    {
        $this->encryption_key = $encryption_key;
        $this->title = $title;
    }
}

$document = new SecretDocument('secret_password', 'Secret Plans');
$title = $document->title; // => succeeds
$key = $document->encryption_key; // => fails
```

Les propriétés, méthodes et constantes protégées ne sont observables que par elles-mêmes et par les classes filles (par héritage).

```php
<?php

class Shape
{
    protected $color = "blue";
}

class Square extends Shape
{
    public function getColor()
    {
        return $this->color;
    }
}

$square = new Square();
$color = $square->getColor(); // => succeeds
```
