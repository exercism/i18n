# À propos

Les opérateurs ternaires permettent de définir des conditions `if` dans des expressions plutôt que dans des blocs d'instructions. Cela rejoint les approches de la programmation fonctionnelle et permet souvent de rendre le code plus expressif et moins sujet aux erreurs.

L'opérateur ternaire combine trois expressions : une condition suivie d'une expression qui est évaluée et renvoyée si la condition est vraie (la partie `if`, introduite par `?`) et d'une expression qui est évaluée et renvoyée si la condition est fausse (la partie `else`, introduite par `:`).

```haxe
trace(true ? "Haxe" : "Not Haxe"); // Haxe
trace(1 == 2 ? "Something is wrong" : "That's obvious"); // That's obvious
```
