# Introduction

## Les _charlists_

Les _charlists_ se créent à l'aide du sigil `~c`.

```elixir
~c"hello"
```

~~~~exercism/note
Dans les anciennes versions d'Elixir, les _charlists_ sont représentées sous la forme `'hello'`, entre guillemets simples.
~~~~

Même si elles ressemblent beaucoup aux _strings_, ces deux types de données sont très différents l'un de l'autre. Une _charlist_ est un tableau d'entiers. Ces entiers représentent les valeurs Unicode d'un caractère donné, aussi appelées points de code.

```elixir
[65, 66, 67]
# => ~c"ABC"
```

On peut faire précéder un caractère de `?` pour obtenir son point de code.

```elixir
?A
# => 65

[?:, ?)]
# => ~c":)"
```

Comme les _charlists_ sont des tableaux, on peut les manipuler comme n'importe quel autre tableau, en utilisant la récursion et le filtrage par motif.

```elixir
[first_letter | _] = ~c"cat"
first_letter
# => 99
```

On peut concaténer deux tableaux avec `++`.

```elixir
~c"hi" ++ ~c"!"
# => ~c"hi!"
```

Plus le premier tableau est long, plus la concaténation est lente, donc mieux vaut éviter d'ajouter répétitivement des éléments à des tableaux de taille arbitraire.

## L'instruction `case`

`case` est une structure de contrôle qui permet de comparer une valeur donnée à de nombreux motifs. Les clauses d'une expression `case` sont évaluées de haut en bas, jusqu'à ce qu'une correspondance soit trouvée.

```elixir
age = 15

case age do
  0 -> ~c"infant"
  age when age < 4 -> ~c"baby"
  age when age < 13 -> ~c"child"
  age when age < 18 -> ~c"teenager"
  _ -> ~c"adult"
end

# => ~c"teenager"
```
