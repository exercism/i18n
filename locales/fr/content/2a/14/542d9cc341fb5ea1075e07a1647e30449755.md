# Introduction

Les nombres à virgule flottante sont des nombres avec un ou plusieurs chiffres après le séparateur décimal. Ils utilisent le format à virgule flottante à double précision sur 64 bits.

```elixir
float = 3.45
# => 3.45
```

## Travaille avec les nombres

Dans les modules [`Integer`][integer-functions] et [`Float`][float-functions], on trouve des fonctions utiles pour travailler avec ces types. Les opérateurs arithmétiques de base sont définis dans le module [`Kernel`][kernel-arithmetic-operators].

## Conversion

On peut mélanger des entiers et des nombres à virgule flottante dans une même expression arithmétique. Utiliser un nombre à virgule flottante dans une expression garantit que le résultat sera lui aussi un nombre à virgule flottante.

```elixir
2 * 3
# => 6

2 * 3.0
# => 6.0
```

Toutefois, dans une division, le résultat est toujours un nombre à virgule flottante, même si seuls des entiers sont utilisés.

```elixir
6 / 2
# => 3.0
```

Pour convertir un nombre à virgule flottante en entier, tu peux supprimer la partie décimale avec [`trunc/1`][trunc-1].
