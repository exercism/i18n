# Introduction

En JavaScript, un [ensemble][mdn-sets] est une structure qui ressemble à une liste et qui contient des valeurs uniques, lesquelles peuvent être des primitives et/ou des références vers des objets. Contrairement à un tableau, on ne peut pas accéder aux éléments d'un ensemble par leur indice.

On ne peut pas ajouter une valeur à un ensemble si elle est [strictement égale][mdn-strict-equality] à l'un des éléments de cet ensemble.

```javascript
const set = new Set();
const object = { color: 'lime green' };
const functionallyIdenticalObject = { color: 'lime green' };

set.add(object);
set.add('wow');
set.add(77);

console.log(set.size);
//=> 3

set.add(functionallyIdenticalObject); // added because functionallyIdenticalObject is not strictly equal to object
console.log(set.size);
//=> 4

set.add(77); // not added because 77 is strictly equal to 77
console.log(set.size);
//=> 4
```

Tu peux fournir un tableau en argument au moment de créer un ensemble : les valeurs de ce tableau deviennent alors les valeurs de l'ensemble, ce qui supprime aussi les doublons.

```javascript
const array = [1, 5, 4, 1];
const set = new Set(array); // the set's values become [1, 5, 4]

console.log(set.size);
//=> 3
```

Pour convertir un ensemble en tableau, tu peux utiliser [Array.from()][mdn-array-from], qui convertit un itérable, comme un ensemble ou une `Map`, en tableau.

```javascript
const set = new Set();

set.add(1);
set.add(2);
set.add(3);
set.add(4);

const array = Array.from(set);
console.log(array);
//=> [1, 2, 3, 4]
```
