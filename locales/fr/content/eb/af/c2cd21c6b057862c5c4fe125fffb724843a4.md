# Indice de rune utilisé avec des octets

Parcourir des `runes` et utiliser l'indice pour obtenir des `bytes` individuels est sans danger dans ce cas, 
car l'entrée ne contient que des caractères ASCII. 
Pour voir ce qui se passe quand on utilise des caractères non ASCII, ajoute ce cas de test :

```go
{
	s1:          "aüa",
	s2:          "aÃa",
	want:        1,
	expectError: false,
}
```
