# Tests

Pour tester la solution, il te suffit de **lancer le script de test**. Tu peux le faire depuis la console Red en utilisant la fonction `do` suivie du chemin du script de test, comme ceci :

```red
do %exercism/red/hello-world/hello-world-test.red
```

Ou en le passant simplement en argument au binaire Red dans le terminal de ton système :

```shell
red exercism/red/hello-world/hello-world-test.red
```

Au départ, seul le premier test du fichier de test est activé. C'est pour t'encourager à résoudre les exercices un par un. Une fois que le premier test passe, modifie le deuxième *argument* de la fonction `test-init` au début du fichier de test, puis relance-le. Cette valeur est le nombre de tests activés, donc la faire passer de `1` à `2` activera le deuxième test. Tu peux aussi supprimer le _refinement_ `\limit` de la fonction `test-init` ainsi que le deuxième argument, pour exécuter tous les tests sans en sauter.
