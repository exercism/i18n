# Introduction

Quand Elixir résout la fonction à invoquer, il utilise le nom du module pour effectuer une recherche. Cette recherche peut se faire dynamiquement si le nom du module est lié à une variable.

```elixir
defmodule MyModule do
  def message(), do: "My message"
end

atom = MyModule
atom.message()
# => "My message"
```

En interne, le nom d'un module est un atome. Tous les atomes de module Elixir sont automatiquement préfixés par `Elixir.`

```elixir
is_atom(Enum)
# => true
Enum == Elixir.Enum
# => true
```
