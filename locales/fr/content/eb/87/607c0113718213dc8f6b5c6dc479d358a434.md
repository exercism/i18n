# Complément aux instructions

## Registres

| Registre | Utilisation   | Type       | Description                                                    |
| -------- | ------------- | ---------- | -------------------------------------------------------------- |
| `$a0`    | entrée        | adresse    | _string_ contenant le nom, terminée par un caractère nul, ou pointeur nul |
| `$a1`    | entrée/sortie | adresse    | _string_ contenant le résultat, terminée par un caractère nul   |
| `$t0-9`  | temporaire    | quelconque | pour le stockage temporaire                                    |
