# Indices

## 1. Surveille le taux d'humidité de la pièce

- Si l'humidité est trop élevée, il suffit d'[arrêter][ref-stopifnot] ; aucun message n'est nécessaire.
- Si les conditions sont bonnes, il faut émettre un [message][ref-message].

## 2. Détecte la surchauffe

- Il y a plusieurs conditions à tester.
- Si tu as besoin d'[arrêter][ref-stop], le message d'erreur est important.
- Une condition inquiétante mais pas encore fatale nécessite un [avertissement][ref-warning].
- Un bon résultat nécessite un [message][ref-message] rassurant.
- N'oublie pas la valeur de retour booléenne.

## 3. Surveille la machine

- Les tâches 1 et 2 renvoient toutes les deux une valeur de retour booléenne que tu peux tester.
