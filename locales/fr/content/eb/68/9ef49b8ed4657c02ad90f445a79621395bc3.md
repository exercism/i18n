# À propos

En Factor, l'essentiel de l'itération passe par des combinateurs (`each`,
`map`, `reduce`), mais la récursion explicite garde encore sa place : quand
la récursion ne porte pas sur une liste, quand le cas de base n'est pas
trivial, ou quand on écrit soi-même un combinateur.

```factor
: total ( seq -- sum )
    [ 0 ] [ unclip swap total + ] if-empty ;

: gcd ( a b -- g )
    dup zero? [ drop ] [ tuck mod gcd ] if ;
```

Quelques points à connaître :

- Les définitions avec un simple `:` peuvent s'appeler récursivement sans
  syntaxe particulière. Le compilateur infère les effets de pile à travers
  l'appel récursif.
- `loop ( quot -- )` permet d'itérer sur une _quotation_ qui renvoie un
  booléen : on continue tant que le résultat est vrai.
- Les appels terminaux sont compilés en sauts, donc des _words_ très
  récursifs ne font pas exploser la pile.

Le couple `unclip` / `if-empty` est la forme standard de la récursion sur
une séquence ; `cond` est la forme standard de l'aiguillage à plusieurs cas.
