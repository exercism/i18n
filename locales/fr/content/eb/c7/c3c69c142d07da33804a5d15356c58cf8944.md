# Instructions supplémentaires

## Registres

| Registre | Utilisation  | Type    | Description                                             |
| -------- | ------------ | ------- | ------------------------------------------------------- |
| `$a0`    | entrée       | entier  | nombre de pièces en entrée                              |
| `$a1`    | entrée       | entier  | cible                                                   |
| `$a2`    | entrée/sortie | adresse | tableau de mots de pièces que l'on peut écraser         |
| `$v0`    | sortie       | entier  | nombre de pièces en sortie, -1 si l'entrée est invalide |
| `$t0-9`  | temporaire   | quelconque | utilisé pour le stockage temporaire                  |
