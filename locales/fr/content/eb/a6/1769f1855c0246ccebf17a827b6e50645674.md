# À propos

L'[opérateur ternaire][ternary-operator] est une forme abrégée d'une instruction if-else.
Il prend une expression booléenne et deux expressions séparées par un deux-points.
La première expression est évaluée si l'expression booléenne est vraie, sinon c'est la deuxième expression qui est évaluée.
Il se présente comme suit : `Boolean-expression ? expression1 : expression2`.

L'opérateur ternaire est idéal quand on veut une forme abrégée d'une instruction if-else et que les expressions sont courtes :

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = showFahrenheit ? temperatureInCelsius * 9 / 5 + 32 : temperatureInCelsius
print(temperature)
// Prints 86
```

L'exemple ci-dessus est la forme abrégée du code ci-dessous :

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = if showFahrenheit {
    temperatureInCelsius * 9 / 5 + 32
} else {
    temperatureInCelsius
}
```

[ternary-operator]: https://docs.swift.org/swift-book/LanguageGuide/BasicOperators.html#ID71
