# Instructions supplémentaires

## Compter les lettres en parallèle

Compte les lettres, en ignorant la casse et les caractères non alphabétiques, puis renvoie un dictionnaire qui associe chaque lettre minuscule à son nombre d'occurrences.
Considère les lettres comme des valeurs scalaires Unicode ; la normalisation Unicode n'est pas nécessaire.

Utilise `pf.Parallel.map!(items, { workers, task })` de la [plateforme roc-parallel](https://github.com/ageron/roc-parallel) pour traiter les `items` donnés à l'aide d'une fonction `task` pure, en parallèle sur plusieurs threads (indiqués par `workers`).
Les résultats sont renvoyés dans l'ordre d'entrée une fois que tous les items ont été traités.
Tu n'as besoin de modifier que `ParallelLetterFrequency.roc`.

## Lance les tests

Contrairement à la plupart des autres exercices, cet exercice utilise des fonctions à effets.
Exécute les tests avec `roc --opt=speed parallel-letter-frequency-test.roc`, plutôt qu'avec `roc test`.
Toute erreur renvoyée par le code Roc est signalée par la plateforme, dans un format différent de celui auquel on est habitué.

Tu peux aussi jeter un œil à l'[exercice bank-account](https://exercism.org/tracks/roc/exercises/bank-account), qui explore un autre aspect de la concurrence : appliquer des mises à jour à un état partagé en toute sécurité.
