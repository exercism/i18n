# Introduction

Les structs sont un élément de base essentiel de la programmation en Swift. Ils rassemblent des données et des fonctions liées au sein d'unités de fonctionnalité autonomes. Tous les types de base que tu as utilisés jusqu'ici, comme `Int`, `Double` et `Character`, ainsi que les types de collection tels que `Array`, `String` et `Dictionary`, sont en réalité des structs.

## Définis des structs

Un struct se définit à l'aide du mot-clé `struct`, suivi du nom du type que l'on définit, puis du corps, placé entre accolades.

Le corps peut être constitué de propriétés stockées, qui se définissent et se comportent exactement comme des constantes ou des variables ordinaires.

```swift
struct CharacterStats {
  var health = 0.0
  var speed = 0
  var strength = 0
}
```

## Instances

Comme indiqué plus haut, définir un struct revient simplement à définir un nouveau _type_. Ce n'est qu'un plan de ce à quoi ressembleront les valeurs de ce type, mais cela ne crée en réalité aucune valeur de ce type avec laquelle travailler.

Pour créer une _instance_ de ce type, il faut écrire le nom du type suivi de parenthèses.

```swift
let someStats = CharacterStats()
```

Cela crée des valeurs de ce type, dont les propriétés sont initialisées avec les valeurs par défaut fournies dans la définition.

Avec les structs, Swift fournit automatiquement ce qu'on appelle un _initialiseur membre par membre_ : il permet de fournir entre parenthèses des valeurs pour les propriétés du struct, lesquelles remplacent alors les valeurs par défaut de la définition.

```swift
let differentStats = CharacterStats(health: 100.0, speed: 6, strength: 18)
```

## Accède aux propriétés

On peut accéder aux propriétés d'un struct à l'aide de la _notation pointée_ : le nom de la valeur est suivi d'un point (`.`) puis du nom de la propriété.

```swift
someStats.health
// => 0
someStats.health = 87.3
```
