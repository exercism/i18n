# Debug

Lorsqu'un test échoue, un message s'affiche pour décrire ce qui n'a pas fonctionné.
Si tu veux davantage de sortie, tu peux utiliser le sous-programme `::YYY()` autour du code que tu souhaites inspecter.
(`::` est un raccourci pour `main::`).
Ce sous-programme fait partie du module [XXX][XXX].

Tu peux aussi simplement afficher un message avec la fonction `say`, par exemple `say 'Hello, World!';`.

L'exécuteur de tests en ligne utilise le [Test Anything Protocol][TAP].
En raison de la nature de TAP, l'utilisation de `print` dans l'exécuteur de tests en ligne est fortement déconseillée.

[TAP]: https://testanything.org/
