# Tests

Chaque exercice fournit les tests unitaires et une recette de compilation Make. C'est à toi de fournir l'implémentation.

Chaque fichier de test a vocation à être lié à ton implémentation, afin de produire un exécutable en console qui lance les tests. Quand tu lances cet exécutable, il affiche un message pour chaque test qui échoue et renvoie un code de sortie non nul lorsque des tests échouent.

Pour venir à bout d'un exercice :
* Crée la compilation initiale avec Make
* Pour chaque test unitaire :
  * Supprime la ligne `TEST_IGNORE()`.
  * Corrige les erreurs de compilation pour que le test échoue.
  * Implémente juste ce qu'il faut pour que le test passe.
  * Réécris ton implémentation pour améliorer la lisibilité, réduire les duplications, etc.
