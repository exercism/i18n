# Instructions

Chaitana possède un parc d'attractions très populaire.
Elle n'a qu'une seule attraction, située au beau milieu d'un parc magnifiquement paysagé : Les Plus Grandes Montagnes Russes du Monde(TM).
Même s'il n'y a que cette unique attraction, des gens viennent des quatre coins du monde et font la queue pendant des heures pour avoir la chance de monter dans l'_hypercoaster_ de Chaitana.

Cette attraction a deux files d'attente, chacune représentée par un `array` :

1. File normale
2. File express (_aussi appelée Fast-track_) - où les gens paient un supplément pour un accès prioritaire.

On t'a demandé d'écrire du code pour mieux gérer les visiteurs du parc.
Tu dois implémenter les fonctions suivantes au plus vite, avant que les visiteurs (et ta patronne, Chaitana !) ne s'énervent.

## 1. Ajoute une personne à la file d'attente

Définis la méthode `ColossalCoaster.add_to_queue` qui prend 4 arguments `<express_queue>, <normal_queue>, <ticket_type>, <person_name>` et renvoie la file d'attente appropriée, mise à jour avec le nom de la personne.

1. `<ticket_type>` est un `Int32` avec 1 == express_queue et 0 == normal_queue.
2. `<person_name>` est le nom (sous forme de `String`) de la personne à ajouter à la file d'attente correspondante.

```crystal
express_queue = ["Tony", "Bruce"]
normal_queue = ["RobotGuy", "WW"]
ColossalCoaster.add_to_queue(express_queue, normal_queue, 1, "RichieRich")
# => ["Tony", "Bruce", "RichieRich"]
```

## 2. Où sont mes amis ?

Une personne est arrivée en retard au parc, mais elle veut rejoindre la file d'attente où ses amis patientent.
Sauf qu'elle n'a aucune idée de l'endroit où ils se trouvent, et il n'y a pas de réseau téléphonique pour les appeler.

Définis la méthode `ColossalCoaster.find_my_friend` qui prend 2 arguments `queue` et `friend_name` et renvoie la position dans la file d'attente du nom de la personne.

1. `<queue>` est un `array` des personnes qui font la queue.
2. `<friend_name>` est le nom de l'ami dont tu dois trouver l'indice (sa place dans la file d'attente).

```crystal
ColossalCoaster.find_my_friend(["Natasha", "Steve", "T'challa", "Wanda", "Rocket"], "Steve")
# => 1
```

## 3. Puis-je les rejoindre ?

Maintenant que ses amis ont été trouvés (dans la tâche n° 2 ci-dessus), la personne en retard aimerait les rejoindre à leur place dans la file d'attente.
Définis la méthode `ColossalCoaster.add_with_friends` qui prend 3 arguments `queue`, `friend_name` et `person_name`.

1. `<queue>` est un `array` des personnes qui font la queue.
2. `<friend_name>` est le nom de l'ami à la position duquel la personne doit être ajoutée.
2. `<person_name>` est le nom de la personne à ajouter à cette position d'indice.

Renvoie la file d'attente mise à jour avec le nom de la personne arrivée en retard.

```crystal
ColossalCoaster.add_with_friends(["Natasha", "Steve", "T'challa", "Wanda", "Rocket"], "Steve", "Bucky")
# => ["Natasha", "Bucky", "Steve", "T'challa", "Wanda", "Rocket"]
```

## 4. Une personne malveillante dans la file d'attente

Tu viens d'apprendre, par la file d'attente, qu'une personne vraiment malveillante bouscule, crie et sème le trouble.
Tu dois virer ce malfrat pour mauvais comportement !

Définis la méthode `ColossalCoaster.remove_from_queue` qui prend 2 arguments `queue` et `person_name`.

1. `<queue>` est un `array` des personnes qui font la queue.
2. `<person_name>` est le nom de la personne à exclure.

Renvoie la file d'attente mise à jour, sans le nom de la personne malveillante.

```crystal
ColossalCoaster.remove_from_queue(["Natasha", "Steve", "Eltran", "Wanda", "Rocket"], "Eltran")
# => ["Natasha", "Steve", "Wanda", "Rocket"]
```

## 5. Trie la liste de la file d'attente

Pour des raisons administratives, tu dois obtenir tous les noms d'une file d'attente donnée par ordre alphabétique.

Définis la méthode `ColossalCoaster.sorted_queue` qui prend 1 argument, `queue` (le `array` des personnes qui font la queue).
La méthode doit renvoyer une copie triée du `array`.

```crystal
ColossalCoaster.sorted_queue(["Natasha", "Steve", "Eltran", "Natasha", "Rocket"])
# => ['Eltran', 'Natasha', 'Natasha', 'Rocket', 'Steve']
```
