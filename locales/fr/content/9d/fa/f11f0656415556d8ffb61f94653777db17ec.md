# Instructions

Dans cet exercice, tu vas écrire du code pour analyser la production d'une usine automobile.

## 1. Calcule le nombre de voitures fonctionnelles produites par heure

Les voitures sont produites sur une chaîne de montage.
La chaîne de montage tourne à une certaine vitesse, que l'on peut modifier.
Plus la chaîne de montage est rapide, plus il y a de voitures produites.
Cependant, modifier la vitesse de la chaîne de montage change aussi le nombre de voitures produites avec succès, c'est-à-dire les voitures sans aucune erreur de production.

Implémente une fonction qui prend le nombre de voitures produites par heure et le taux de réussite, et qui calcule le nombre de voitures produites avec succès par heure.
Le taux de réussite est donné en pourcentage, de `0` à `100` :

```go
CalculateWorkingCarsPerHour(1547, 90)
// => 1392.3
```

**Remarque :** la valeur de retour doit être un `float64`.

## 2. Calcule le nombre de voitures fonctionnelles produites par minute

Implémente une fonction qui prend le nombre de voitures produites par heure et le taux de réussite, et qui calcule combien de voitures sont produites avec succès chaque minute :

```go
CalculateWorkingCarsPerMinute(1105, 90)
// => 16
```

**Remarque :** la valeur de retour doit être un `int`.

## 3. Calcule le coût de production

Chaque voiture coûte normalement 10 000 $ à produire individuellement, que sa production soit réussie ou non.
Mais avec un peu d'organisation, on peut produire 10 voitures ensemble pour 95 000 $.

Par exemple, on peut produire 37 voitures de la manière suivante :
37 = 3 x groupes de dix + 7 voitures individuelles

Le coût pour 37 voitures est donc :
3\*95 000+7\*10 000=355 000

Implémente la fonction `CalculateCost` qui calcule le coût de production d'un certain nombre de voitures, que leur production soit réussie ou non :

```go
CalculateCost(37)
// => 355000

CalculateCost(21)
// => 200000
```

**Remarque :** la valeur de retour doit être un `uint`.
