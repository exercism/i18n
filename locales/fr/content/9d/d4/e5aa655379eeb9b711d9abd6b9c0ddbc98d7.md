# Instructions

Dans cet exercice, tu vas implémenter un moyen de garder une trace des meilleurs scores du jeu le plus populaire de la salle d'arcade près de chez toi.

## 1. Ajoute des joueurs au tableau des meilleurs scores

Pour ajouter un joueur au tableau des meilleurs scores, définis deux méthodes `add_player!` qui prennent les arguments suivants :

- Le premier argument est le dictionnaire des scores.
- Le deuxième argument est le nom d'un joueur, sous forme de _string_.
- Le troisième argument est le score, sous forme d'entier.
  Cet argument est facultatif : si aucune valeur n'est donnée, le score doit être fixé à 0.

```julia-repl
julia> scores = Dict{String, Int}()
Dict{String, Int64}()

julia> add_player!(scores, "Liselot", 486373)
Dict{String, Int64} with 1 entry:
  "Liselot" => 486373

julia> add_player!(scores, "Éimhín")
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0
```

## 2. Retire des joueurs du tableau des scores

Pour retirer un joueur du tableau des meilleurs scores, définis `remove_player!`, qui prend 2 arguments :

- Le premier argument est le dictionnaire des scores.
- Le deuxième argument est le nom du joueur, sous forme de _string_.

```julia-repl
julia> scores = Dict(
           "Liselot" => 486373,
           "Éimhín"  => 0,
       )
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0

julia> remove_player!(scores, "Liselot")
Dict{String, Int64} with 1 entry:
  "Éimhín" => 0
```

## 3. Mets à jour le score d'un joueur

Pour mettre à jour le score d'un joueur en remplaçant le score précédent, définis `update_score!`, qui prend 3 arguments :

- Le premier argument est le dictionnaire des scores.
- Le deuxième argument est le nom du joueur, sous forme de _string_, dont tu veux mettre à jour le score.
- Le troisième argument est le score que tu souhaites attribuer au meilleur score enregistré.

```julia-repl
julia> scores = Dict(
           "Liselot" => 486373,
           "Éimhín"  => 0,
       )
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0

julia> update_score!(scores, "Éimhín", 89479) # TODO: Should this return the dict?
89479

julia> scores
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 89479
```

## 4. Réinitialise le score d'un joueur

Pour réinitialiser le score d'un joueur, définis `reset_score!`, qui prend 2 arguments :

- Le premier argument est le dictionnaire des scores.
- Le deuxième argument est le nom du joueur, sous forme de _string_, dont tu veux réinitialiser le score.

```julia-repl
julia> scores = Dict(
           "Liselot" => 486373,
           "Éimhín"  => 0,
       )
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0

julia> reset_score!(scores, "Liselot") # TODO: Should this return the dict?
0

julia> scores
Dict{String, Int64} with 2 entries:
  "Liselot" => 0
  "Éimhín"  => 0
```

## 5. Récupère la liste des joueurs

Pour récupérer la liste des joueurs, définis `players`, qui prend 1 argument :

- Le premier argument est le dictionnaire des scores.

```julia-repl
julia> scores = Dict(
           "Liselot" => 486373,
           "Éimhín"  => 0,
       )
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0

julia> players(scores)
2-element Vector{String}:
 "Liselot"
 "Éimhín"
```
