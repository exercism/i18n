# Introduction

Lorsque l'on modélise des données qui ne peuvent prendre qu'un ensemble précis d'états possibles, comme les jours de la semaine, les points cardinaux ou les boutons d'une manette, les types de base comme `Int` ou `String` présentent des inconvénients majeurs.
Avec des entiers ou des _strings_, le code doit sans cesse vérifier qu'il n'y a pas de valeurs invalides (comme un code de statut `999` ou une faute de frappe comme `"leftt"`), et un lecteur humain ne peut pas facilement deviner ce que ces nombres représentent.

Swift résout ce problème avec les [_énumérations_][enumerations] (souvent abrégées en _enums_).
Une énumération définit un type commun à un groupe de valeurs nommées et apparentées. Comme le compilateur connaît à l'avance tous les cas possibles, il peut vérifier l'exactitude et l'exhaustivité du code à la compilation.
Les énumérations peuvent aussi avoir des méthodes, des initialiseurs et des propriétés calculées.

## Définis des énumérations

Définis une énumération avec le mot-clé `enum` suivi du nom du type, et liste ses cas entre accolades.
Par convention en Swift, le nom du type s'écrit en `UpperCamelCase`, tandis que chaque cas s'écrit en `lowerCamelCase` :

```swift
enum NESButton {
    case up
    case down
    case left
    case right
    case a
    case b
    case select
    case start
}
```

Tu peux aussi définir plusieurs cas sur une seule ligne, séparés par des virgules :

```swift
enum NESButton {
    case up, down, left, right, a, b, select, start
}
```

Pour désigner un cas d'énumération, écris le nom du type de l'énumération, un point (`.`), puis le nom du cas. Une fois que le type est connu ou peut être déduit par le compilateur, tu peux omettre le nom du type et utiliser la notation pointée abrégée :

```swift
var lastPressed = NESButton.up

// Swift infers the type, so you can omit the type name:
lastPressed = .down

let konamiCode: [NESButton] = [.up, .up, .down, .down, .left, .right, .left, .right, .b, .a]
```

## Méthodes et initialiseurs

Les énumérations peuvent définir des méthodes et des initialiseurs personnalisés, exactement comme les classes et les structures. À l'intérieur d'une méthode d'énumération, `self` désigne la valeur du cas courant :

```swift
enum Coin {
    case heads
    case tails

    init(_ value: Int) {
        if value.isMultiple(of: 2) {
            self = .heads
        } else {
            self = .tails
        }
    }

    func flip() -> Coin {
        switch self {
        case .heads: return .tails
        case .tails: return .heads
        }
    }
}

let tails = Coin(13)     // .tails
let heads = Coin(0)      // .heads
let flipped = heads.flip() // .tails
```

## Valeurs brutes

Les cas d'une énumération peuvent être préremplis avec des valeurs par défaut appelées [_valeurs brutes_][raw-values].
Toutes les valeurs brutes d'une énumération doivent être du même type (comme `Int`, `String` ou `Character`) :

```swift
enum NESButton: Character {
    case up = "⬆️"
    case down = "⬇️"
    case left = "⬅️"
    case right = "➡️"
    case a = "🅰️"
    case b = "🅱️"
    case select = "✅"
    case start = "🚦"
}

print(NESButton.left.rawValue) // Prints "⬅️"
```

Tu peux initialiser une énumération à partir d'une valeur brute avec `init(rawValue:)`. Comme une valeur brute invalide peut être fournie, cet initialiseur renvoie un optionnel :

```swift
let upButton = NESButton(rawValue: "⬆️") // Optional(NESButton.up)
let invalid = NESButton(rawValue: "🙄")  // nil
```

Swift peut affecter automatiquement des valeurs brutes pour les énumérations de type `String` et `Int` :

- Pour les énumérations de type `String`, la valeur brute de chaque cas vaut par défaut son nom.
- Pour les énumérations de type `Int`, les valeurs brutes commencent à `0` et augmentent de 1, sauf indication contraire.

```swift
enum Planet: Int {
    case mercury = 1, venus, earth, mars
}

print(Planet.earth.rawValue) // Prints 3
```
