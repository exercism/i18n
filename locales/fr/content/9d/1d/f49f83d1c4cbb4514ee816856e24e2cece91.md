# pas d'alias de type Stopwatch

Dans cet exercice, tu es censé définir `Stopwatch` comme un type opaque.
Utiliser `type alias Stopwatch` définit `Stopwatch` comme un alias de type, ce qui expose sa structure interne.
À la place, utilise `type Stopwatch` pour masquer la structure interne et empêcher les autres modules de déconstruire ou de mettre à jour directement les valeurs `Stopwatch`.
