# Instructions

Dans cet exercice, tu vas écrire du code pour aider une entreprise de panneaux à créer des messages personnalisés pour ses panneaux.

## 1. Crée un ensemble de _strings_ utiles

Définis les _strings_ constantes suivantes qui serviront à créer des panneaux :

- `birthday` : contient la valeur « Birthday »
- `valentine` : contient la valeur « Valentine's Day »
- `anniversary` : contient la valeur « Anniversary »

## 2. Définis un ensemble de caractères utiles

Définis les caractères constants suivants qui serviront à créer des panneaux :

- `space` : contient la valeur d'un espace (un seul espace)
- `exclamation` : contient la valeur « ! »

## 3. Combine des phrases pour construire des messages

Implémente la fonction `buildSign(for:name:)`, qui prend l'argument `for`, qui contient l'une des trois _strings_ que tu as définies dans la première tâche, et l'argument `name`, qui est une _string_ qui contient le nom de la personne à qui le panneau est destiné.
Tu dois utiliser la concaténation pour construire le message du panneau, et n'oublie pas de réutiliser les constantes déjà définies.
La fonction doit renvoyer le message du panneau sous forme de _string_.

```swift
buildSign(for: birthday, name: "Otto")
// returns "Happy Birthday Otto!"

buildSign(for: anniversary, name: "Valentina")
// returns "Happy Anniversary Valentina!"
```

## 4. Construis un panneau de remise de diplôme

Implémente la fonction `graduationFor(name:year:)` qui prend l'argument `name`, une _string_ qui contient le nom de la personne à qui le panneau est destiné, et l'argument `year`, un entier qui contient l'année de remise du diplôme.
Tu dois utiliser des _template strings_ pour construire le message du panneau.
La fonction doit renvoyer le message du panneau sous forme de _string_.

```swift
graduationFor(name: "Padma", year: 2023)
// returns "Congratulations Padma!\nClass of 2023"
```

## 5. Calcule le coût d'un panneau

Implémente la fonction `costOf(sign:)` qui prend l'argument `sign`, une _string_ qui contient le message du panneau.
Le prix de base d'un panneau est de 20 dans la devise donnée. De plus, chaque lettre coûte 2 (les espaces blancs sont pris en compte dans le calcul).
La fonction doit renvoyer le coût du panneau sous forme d'entier.

```swift
costOf(sign: "Happy Birthday Grandma!")
// returns 66
```
