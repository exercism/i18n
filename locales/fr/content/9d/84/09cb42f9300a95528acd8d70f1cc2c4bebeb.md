# Introduction

Les **fermetures** sont un patron de programmation en JavaScript qui permet d'utiliser, à l'intérieur d'un bloc de code imbriqué, des variables issues d'une [portée lexicale][wiki-lexical-scope] extérieure.
JavaScript prend en charge les fermetures de manière transparente, et on les utilise souvent sans savoir ce qu'elles sont.

```javascript
// Top-level declarations are global-scope
const dozen = 12;

{
  // Braces create a new block-scope
  // Referencing the outer variable is a closure.
  const twoDozen = dozen * 2;
}

// Because of the block-scope declaration, twoDozen is not available here.
twoDozen;
// => Uncaught ReferenceError: twoDozen is not defined
```

À l'exception des accolades `{}`, les fonctions (et les classes) créent elles aussi de nouvelles portées, qui peuvent _enfermer_ des valeurs :

```javascript
const dozen = 12;

// Functions create a new function-scope and block-scope.
// Referencing the outer variable here is a closure.
function nDozen(n) {
  // This is declared inside the function scope, and uses the top-level scope.
  // This works, and encloses the value 12.
  const twoDozen = dozen * 2;

  // This only uses the locally declared variable and the passed argument to the parameter `n`
  return (twoDozen / 2) * n;
}

// Because of the function-scope declaration, twoDozen is not available here.
twoDozen;
// => Uncaught ReferenceError: twoDozen is not defined
```

Comme le montrent les exemples avec `twoDozen`, des valeurs peuvent être enfermées dans une portée _imbriquée_ (fonction, bloc, etc.), mais elles ne peuvent pas être extraites de ce contexte.
Dans la plupart des cas, en JavaScript moderne, une valeur n'est pas censée _fuiter_ vers une portée extérieure.

## Des fermetures pour conserver un état et transmettre des valeurs

Utiliser une déclaration de variable mutable (comme `let` ou `var`) permet de conserver un état :

```javascript
let counter = 0;

// This function closure increments the counter's state in the outer lexical context.
// This way the counter can be shared between many calling contexts.
export function increment() {
  counter += 1;
  return counter;
}

increment();
// => 1

counter;
// => 1
```

## Enferme des valeurs sans laisser fuiter l'état

En combinant les deux idées, à savoir enfermer une valeur pour préserver un état et empêcher les valeurs enfermées de fuiter vers l'extérieur, on peut créer des valeurs privées.

La méthode la plus courante consiste à écrire une fonction qui renvoie une fonction qui enferme un certain état.

```javascript
export function makeCounter() {
  let counter = 0;

  // This returns a new function that encloses the local variable counter
  return function increment() {
    counter += 1;
    return counter;
  };
}

// Counter did not leak
counter;
// => Uncaught ReferenceError: counter is not defined

// This creates a new counter.
// This assigns the increment function to the variable myFirstCounter.
const myFirstCounter = makeCounter();

typeof myFirstCounter;
// => function

myFirstCounter.name;
// => increment

myFirstCounter();
// => 1
myFirstCounter();
// => 2

// This creates new counter (with new, separate local state / enclosed counter variable)
const mySecondCounter = makeCounter();

mySecondCounter();
// => 1

// It is not affect the first counter.

myFirstCounter();
// => 3
```
