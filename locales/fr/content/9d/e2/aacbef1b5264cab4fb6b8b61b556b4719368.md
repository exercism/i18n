# Tests

Un REPL Clojurescript permet d'exécuter du code facilement et d'obtenir un retour immédiat ; on peut aussi s'en servir pour lancer les tests.

## Leiningen
Pour ouvrir un REPL avec Clojure CLI, place-toi dans le répertoire qui contient l'exercice et lance :
``` bash
$ clojure -m cljs.main -re node
```

Note que Node doit être installé sur ton système.

Une fois que tu es prêt à travailler sur un exercice et que tu as créé un fichier pour ta solution (comme `bob.cljs`), tu peux lancer les tests depuis ton terminal avec `$ clojure -A:test`.

Commence par `require` le _namespace_ de test :
``` clojure
=> (require 'bob-test)
nil
;; and the test namespace
=> (require 'cljs.test)
```

Change le _ns_ pour celui du _namespace_ de test :
```clojure
=> (ns bob-test)
nil
```

Puis appelle `run-tests` sur `bob-test` :
``` clojure
=> (cljs.test/run-tests)

Testing bob-test

Ran 14 tests containing 14 assertions.
0 failures, 0 errors.
{:test 14, :pass 14, :fail 0, :error 0, :type :summary}
```

Pour lancer les tests d'un exercice avec Clojure CLI, il suffit d'appeler :
``` bash
$ clojure -M:test

Testing bob-tests

Ran 14 tests containing 14 assertions.
0 failures, 0 errors.
```
