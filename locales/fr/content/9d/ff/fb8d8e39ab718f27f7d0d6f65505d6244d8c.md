# Instructions supplémentaires

La sortie doit être organisée en [ordre ligne par ligne](https://en.wikipedia.org/wiki/Row-_and_column-major_order) : tous les mots de la première ligne, puis les mots de la deuxième ligne, et ainsi de suite.

## Registres

| Registre | Utilisation  | Type    | Description                              |
| -------- | ------------ | ------- | ---------------------------------------- |
| `$a0`    | entrée       | entier  | taille                                   |
| `$a1`    | entrée/sortie| adresse | matrice de mots, en ordre ligne par ligne |
| `$v0`    | sortie       | entier  | nombre de mots dans la matrice            |
| `$t0-9`  | temporaire   | quelconque | pour un stockage temporaire            |
