# À propos

Les _verbatim strings_ [permettent d'écrire des chaînes de caractères sur plusieurs lignes][verbatim-strings]. On les fait précéder d'un @. On peut aussi les utiliser avec l'interpolation de chaînes. Ajoute simplement un "\$" avant le guillemet d'ouverture.

```csharp
string str = @"
See no wretched
quotes everywhere
";
```

[verbatim-strings]: https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/strings/#regular-and-verbatim-string-literals
