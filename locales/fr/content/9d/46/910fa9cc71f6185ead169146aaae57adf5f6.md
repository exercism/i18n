# Apprendre

- [La documentation du langage de programmation Zig][documentation] offre un excellent aperçu de toutes les fonctionnalités que Zig met à la disposition de ceux qui l'utilisent.
- [Awesome Zig][awesome-zig] est un bon recueil de projets Zig réalisés par différentes personnes.
  Ce recueil présente des projets qui s'appuient sur du code Zig soigneusement développé.
- [Zighelp][zighelp] est une excellente introduction qui explique les fonctionnalités que Zig a à offrir.
- [Ziglings][ziglings] est vivement recommandé.
  Apprends Zig en corrigeant de petits programmes cassés.
- [Zig SHOWTIME][zig-showtime] est une émission diffusée en direct où les membres de la communauté Zig partagent du code et des idées.

[awesome-zig]: https://github.com/catdevnull/awesome-zig
[documentation]: https://ziglang.org/documentation/master/
[zighelp]: https://zighelp.org/
[zig-showtime]: https://zig.show/
[ziglings]: https://codeberg.org/ziglings/exercises
