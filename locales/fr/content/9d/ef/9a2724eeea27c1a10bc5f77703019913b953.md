# Introduction

## Le _cast_

Le _cast_ et la conversion de type sont deux manières différentes de faire passer une expression d'un type de données à un autre.

On peut appliquer un _cast_ à une expression pour la faire passer à un autre type avec l'opérateur de _cast_ `(<type>)`.

```csharp
long l = 1000L;
int i = (int)l;

object o = new Random();
Random r = (Random)o;
```

Si les types ne sont pas compatibles, une instance de `InvalidCastException` est levée. Dans le cas des nombres, cela indique que le type de destination ne peut pas représenter la valeur convertie. Dans le cas des classes, l'un des types doit dériver de l'autre (cela vaut aussi, trivialement, pour les structures).

Une alternative au _cast_ est la _conversion de type_, à l'aide de l'opérateur `is`. On l'applique généralement aux types de référence et aux types nullables.

```csharp
object o = new Random();
if (o is Random rand)
{
    int ii = rand.Next();
    // now, do something random
}
```

Si tu as besoin de détecter le type précis d'un objet, `is` peut être un peu trop permissif, car il renvoie vrai pour une classe ainsi que pour toutes les classes et interfaces dont elle dérive, directement ou indirectement. `typeof` et `Object.GetType()` sont la solution dans ce cas.

```csharp
object o = new List<int>();

o is ICollection<int> // true
o.GetType() == typeof(ICollection<int>) // false
o is List<int> // true
o.GetType() == typeof(List<int>) // true
```
