# Installation

Pour ces exercices, on utilise le simulateur MIPS populaire [MARS](https://dpetersanderson.github.io/Help/MarsHelpIntro.html). Télécharge l'archive jar de MARS depuis [GitHub](https://github.com/dpetersanderson/MARS/releases) et place-la dans un endroit facilement accessible. Installe aussi le Java SDK si tu ne l'as pas déjà.
