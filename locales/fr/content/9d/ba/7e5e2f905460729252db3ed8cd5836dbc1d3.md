# Complément aux instructions

## Définir un type inductif

Cet exercice attend que la valeur de retour soit un [type inductif][inductive] `Classification` que tu dois définir.

Ce type doit posséder une instance [BEq][beq], c'est-à-dire qu'il admet un test d'égalité booléenne, ainsi qu'une instance [Repr][repr], c'est-à-dire que les valeurs de ce type peuvent être formatées pour l'affichage.

Tu peux consulter [cette page][instance] sur les déclarations d'instances.
Lean peut [générer automatiquement des instances][deriving] pour de nombreuses classes.

## Sous-types

L'argument de la fonction `classify` est un [sous-type][subtype] appelé `Positive` :

```
def Positive := { x : Nat // x > 0 }
```

Les sous-types représentent les éléments d'un type donné qui satisfont un prédicat.
`Positive` représente les éléments de `Nat` qui sont supérieurs à `0`.

Tout élément d'un sous-type peut être vu comme un couple formé d'une valeur du type sous-jacent et d'une preuve, au sens mathématique, que cette valeur satisfait le prédicat correspondant.

Les sous-types font respecter des invariants au niveau du type, ce qui garantit que des valeurs mal formées ne peuvent pas être construites.
