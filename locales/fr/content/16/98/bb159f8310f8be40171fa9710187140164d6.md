# Instructions

Ton ami Johannes adore fabriquer son propre matériel en DIY (do it yourself).
Johannes vient de construire un extracteur de jus et en est très enthousiaste.
L'objectif de Johannes est de pouvoir préparer du jus frais chaque matin.

L'extracteur de jus de Johannes a de nombreuses fonctionnalités sophistiquées.
Comme un système de mesure intégré, qui peut t'indiquer la quantité de jus dans le verre.
Il a aussi un minuteur, qui t'indique depuis combien de temps la machine tourne.

Johannes n'est pas très doué en programmation, mais il veut écrire un programme pour contrôler la machine.
C'est pourquoi il t'a demandé de l'aider.

## 1. Voyant de débogage

La machine possède un voyant de débogage, c'est un mécanisme simple : si la machine est alimentée, le voyant de débogage est allumé.
Le programme ne s'exécute que si le voyant de débogage est allumé.

Cette méthode doit être une méthode de classe appelée `JuiceMaker`.

Définis la méthode de classe `JuiceMaker.debug_light_on?` qui renvoie `true`.

```crystal
JuiceMaker.debug_light_on?
#=> true
```

## 2. Initialiser la machine

Quand la machine est allumée, elle doit créer une instance d'une classe appelée `JuiceMaker`.
La machine est censée avoir un état initialisé.
L'état initialisé doit contenir les informations suivantes :

1. Si la machine est en marche ou non. Cette valeur doit toujours être `false` quand la machine est allumée.
2. La quantité de jus dans le verre, ce sera un capteur qui mesure la quantité de jus dans le verre.

Définis l'état initialisé, qui prend en paramètre la quantité de jus dans le verre, et construis cet état initialisé.
L'état initialisé doit comporter une variable d'instance `@running` qui vaut `false`, et une variable d'instance `@fluid` qui se base sur un argument fourni lors de l'initialisation de la classe.

```crystal
JuiceMaker.new(5)
#=> #<JuiceMaker:0x10f0b8 @running=false, @fluid=5>
```

## 3. Allumer la machine

La machine peut être allumée et éteinte.
Tu dois définir une méthode pour allumer la machine.
Quand la machine est allumée, l'état de marche doit être défini à `true`.

Définis la méthode `JuiceMaker#start` qui allume la machine.

```crystal
juice_maker = JuiceMaker.new(5)
juice_maker.start

juice_maker
#=> #<JuiceMaker:0x10f0b8 @running=true, @fluid=5>
```

## 4. État de la machine

La machine doit pouvoir t'indiquer son état.
Elle doit renvoyer `true` si la machine est en marche, et `false` si la machine n'est pas en marche.

Définis la méthode `JuiceMaker#running?` qui renvoie l'état de la machine.

```crystal
juice_maker = JuiceMaker.new(5)
juice_maker.start

juice_maker.running?
#=> true
```

## 5. Ajouter du jus

La machine peut ajouter du jus dans le verre.
La machine peut déterminer la quantité de jus ajoutée au verre.
La machine a besoin d'aide pour savoir quelle quantité de jus se trouve dans le verre une fois le jus ajouté.

Définis la méthode `JuiceMaker#add_fluid`, qui prend en paramètre la quantité de jus ajoutée et met à jour la quantité de jus dans le verre.

```crystal
juice_maker = JuiceMaker.new(5)
juice_maker.add_fluid(5)

juice_maker
#=> #<JuiceMaker:0x10f0b8 @running=false, @fluid=10>
```

## 6. Éteindre la machine

La machine peut être allumée et éteinte.
Tu dois définir une méthode pour éteindre la machine
Cette méthode ne sera appelée que lorsque la machine est en marche.
Quand la machine est éteinte, l'état de marche doit être défini à `false`.
La machine a aussi besoin d'aide pour déterminer la quantité de jus qui reste dans le verre après son extinction.
La machine consomme cinq unités de jus par minute.

Définis la méthode `JuiceMaker#stop` qui prend en paramètre le nombre de minutes pendant lesquelles la machine a tourné et qui renvoie la quantité de jus présente dans le verre une fois la machine éteinte.

```crystal
juice_maker = JuiceMaker.new(5)

juice_maker.start
juice_maker
#=> <JuiceMaker:0x10f0b8 @running=true, @fluid=5>

juice_maker.stop(1)
#=> #<JuiceMaker:0x10f0b8 @running=false, @fluid=0>
```
