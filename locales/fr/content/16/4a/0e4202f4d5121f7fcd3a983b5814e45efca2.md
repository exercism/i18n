# Introduction

De nombreux programmes ont besoin de valeurs aléatoires (_en apparence_) pour simuler des événements du monde réel.

Parmi les exemples courants et familiers, on trouve :
- Un lancer de pièce : une valeur aléatoire parmi `('Heads', 'Tails')`.
- Le lancer d'un dé : un entier aléatoire de 1 à 6.
- Le mélange d'un jeu de cartes : un ordre aléatoire d'une liste de cartes.
- La création d'arbres et de buissons dans une simulation graphique 3D.

Générer des valeurs _véritablement_ aléatoires avec un ordinateur est un [défi technique étonnamment difficile][truly-random], c'est pourquoi on qualifie souvent ces résultats de « pseudo-aléatoires ».

En pratique, une bibliothèque bien conçue comme le module [`random`][random] de la bibliothèque standard de Python est rapide, souple et donne des résultats largement suffisants pour la plupart des applications de modélisation, de simulation et de jeux.

Dans cette brève introduction, on présente les quatre fonctions les plus couramment utilisées du module.
On t'encourage à explorer la documentation complète de [`random`][random], car il existe de nombreux outils et options.

Avant de pouvoir utiliser les outils du module `random`, tu dois d'abord l'importer :

```python
>>> import random

# Choose random integer from a range
>>> random.randrange(1000)
360

>>> random.randrange(-1, 500)
228

>>> random.randrange(-10, 11, 2)
-8

# Choose random integer between two values (inclusive)
>>> random.randint(5, 25)
22

```

Pour éviter de taper le nom du module, tu peux importer des fonctions spécifiques par leur nom :

```python
>>> from random import choice, choices

# Using choice() to pick Heads or Tails 10 times
>>> tosses = []
... for side in range(10):
...    tosses.append(choice(['H', 'T']))    

>>> print(tosses)
['H', 'H', 'H', 'H', 'H', 'H', 'H', 'T', 'T', 'H']


# Using choices() to pick Heads or Tails 8 times
>>> picks = []
... picks.extend(choices(['H', 'T'], k=8))
... print(picks)
['T', 'H', 'H', 'T', 'H', 'H', 'T', 'T']
```



## `randrange()` et `randint()`

Comme le montre le premier exemple ci-dessus, la fonction `randrange()` prend trois formes :

1. `randrange(stop)` donne un entier `n` tel que `0 <= n < stop`
2. `randrange(start, stop)` donne un entier `n` tel que `start <= n < stop`
3. `randrange(start, stop, step)` donne un entier `n` tel que `start <= n < stop`
    et `n` appartient à la suite `start, start + step, start + 2*step...`

Dans le cas le plus courant où `step == 1`, `randint(a, b)` peut être plus pratique et plus lisible.
Les résultats possibles de `randint()` _incluent_ la borne supérieure, donc `randint(a, b)` équivaut à utiliser `randrange(a, b+1)`.



## `choice()` et `choices()`

Ces deux fonctions supposent que tu partes d'une [séquence][sequence-types] ou d'un autre conteneur.
Il s'agira généralement d'une `list`, ou, avec certaines limitations, d'un `tuple` ou d'un `set` (_un `tuple` est immuable et un `set` n'est pas ordonné_).

La fonction `choice()` renvoie un élément choisi au hasard dans une séquence donnée, et `choices()` renvoie un nombre donné d'éléments (`k`) choisis au hasard dans une séquence donnée.
Dans les exemples ci-dessus, on a supposé une pièce équilibrée avec une probabilité égale de tomber sur pile ou face, mais on peut aussi spécifier des poids.

Par exemple, si un sac contient 10 boules rouges et 15 boules vertes, et qu'on veut en tirer une au hasard :


```python
>>> random.choices(['red', 'green'], [10, 15])
['red']
```
