# Indices

## 1. Génère une planète aléatoire

- Java ne fournit pas de fonction pour choisir aléatoirement un élément dans une collection.
- Rappelle-toi que tu peux récupérer un élément d'un tableau par son indice, qui est un entier.

## 2. Génère un numéro d'immatriculation de vaisseau spatial aléatoire

- La classe `java.util.Random` fournit une méthode pour générer un `int` aléatoire entre 0 et un maximum donné.

## 3. Génère une date stellaire aléatoire

- La méthode de la classe `java.util.Random` qui génère un `double` aléatoire renvoie toujours un nombre entre `0.0` et `1.0`.
