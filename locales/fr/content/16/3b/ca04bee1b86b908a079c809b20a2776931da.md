# Instructions

Bonjour, Agent Double-Null0111.

Ta mission, si tu choisis de l'accepter, est d'écrire deux outils pour t'aider à infiltrer le quartier général d'UMBRA (United Minions Being Really Awful) et à récupérer les plans de leur dernière machination vraiment atroce. Deux outils te seront nécessaires pour mener à bien cette mission.

## 1. Protège les plans secrets récupérés à l'aide d'un mot de passe

Une fois les plans secrets en ta possession, tu devras les protéger pour que seules les personnes qui connaissent le mot de passe puissent les récupérer.

Pour ce faire, tu devras implémenter la fonction `protectSecret(_ secret: String, withPassword password: String) -> (String) -> String`.
Cette fonction renvoie une autre fonction qui prend en entrée des _strings_ pouvant être le mot de passe.
Si le mot de passe saisi est correct, la nouvelle fonction renvoie le secret dissimulé, mais si le mot de passe est incorrect, la fonction renvoie « Sorry. No hidden secrets here. »

```swift
let secretFunction = protectSecret("Steal the world's supply of french fries!", withPassword: "5up3r53cr37")

secretFunction("Open sesame")
// Returns "Sorry. No hidden secrets here."

secretFunction("5up3r53cr37")
// Returns "Steal the world's supply of french fries!"
```

## 2. Génère une combinaison pour ouvrir leur coffre-fort

Nous avons appris qu'UMBRA base toutes ses combinaisons de coffre-fort sur le numéro de la salle où se trouve le coffre.
Ces combinaisons sont générées en appliquant de façon répétée une fonction spéciale au numéro de la salle.
Ainsi, le premier nombre de la combinaison provient de l'application de la fonction au numéro de la salle, le deuxième de l'application de la fonction au premier nombre, et le troisième de l'application de la fonction au deuxième nombre.

Cependant, UMBRA change régulièrement la fonction utilisée pour générer les combinaisons, donc ton outil devra prendre à la fois un numéro de salle et la fonction appropriée pour générer la combinaison.

Implémente la fonction `generateCombination(forRoom room: Int, usingFunction f: (Int) -> Int) -> (Int, Int, Int)` pour générer la combinaison dont tu auras besoin.

```swift
func makeCombo(_ x: Int) -> Int {
  (x * 13) % 256
}

generateCombination(forRoom: 227, usingFunction: makeCombo)
// Returns (135, 219, 31)
```
