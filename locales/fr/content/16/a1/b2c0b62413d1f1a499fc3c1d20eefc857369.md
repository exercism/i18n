# Général

## 1. Définis le type personnalisé générique TreasureChest

- Le guide Elm contient une section sur les [types personnalisés][custom-types].
- Le type personnalisé `TreasureChest` ne possède qu'une seule variante.
- Par convention en Elm, lorsqu'un type personnalisé ne possède qu'une seule variante, la variante et le type portent le même nom (dans ce cas, les deux s'appelleraient `TreasureChest`)

## 2. Définis la fonction getTreasure

- Il existe une [notation abrégée pour déstructurer les types personnalisés à un seul membre][single-member-custom-destructuring].
- Le guide Elm contient une section sur [Maybe][maybe] si tu as besoin de te rafraîchir la mémoire.
