Conçois une suite de tests pour un outil qui compte les lignes, les lettres et les caractères.

C'est un exercice particulier. Au lieu d'écrire du code qui fonctionne avec une suite de tests existante, c'est à toi de définir la suite de tests. Pour t'aider, plusieurs variantes du code à tester sont fournies ; ta suite de tests doit au moins pouvoir détecter les problèmes (ou leur absence) qu'elles présentent.

Le système à tester est censé compter le nombre de lignes, de lettres et le nombre total de caractères dans les _strings_ fournies. Le principe est d'effectuer l'opération « add string » plusieurs fois, en passant des _strings_, puis d'appeler les fonctions « lines », « letters » et « characters » pour obtenir les totaux.
