# Introduction

Ruby est un [langage orienté objet][object-oriented-programming] dynamique.
En Ruby, tout est un [objet][object].

Il existe deux façons principales d'affecter des objets à des noms en Ruby : avec des variables ou des constantes.
Les variables s'écrivent toujours en [`snake_case`][snake-case].
Une variable peut référencer différents objets au cours de sa vie.
Par exemple, `my_first_variable` peut être définie et redéfinie de nombreuses fois à l'aide de l'opérateur `=` :

```ruby
my_first_variable = 1
my_first_variable = "Some string"
my_first_variable = SomeComplexObject.new
```

Les constantes, en revanche, sont censées n'être affectées qu'une seule fois.
Elles doivent commencer par une majuscule et s'écrivent normalement en capitales, avec les mots séparés par des tirets bas.

Par exemple :

```ruby
MY_FIRST_CONSTANT = 10

# Redefining not allowed
# MY_FIRST_CONSTANT = "Some String"
```

Ruby est organisé en classes.
Les classes sont définies à l'aide du mot-clé `class`, suivi du nom de la classe.
Les objets sont généralement créés en instanciant des classes à l'aide de la méthode `.new`.

Par exemple :

```ruby
# Define the class
class Calculator
  #...
end

# Create an instance of it and assign it to a variable
my_first_calc = Calculator.new
```

Les unités de fonctionnalité sont encapsulées dans des méthodes, comme les _fonctions_ d'autres langages.
Une méthode peut éventuellement être définie avec des arguments positionnels, et/ou des arguments nommés qui sont définis et appelés à l'aide de la syntaxe `:`.
Les méthodes renvoient implicitement le résultat de la dernière instruction évaluée, ou peuvent renvoyer explicitement un objet à l'aide du mot-clé `return`.
Les méthodes sont appelées à l'aide de la syntaxe `.`.

```ruby
class Calculator

  # Unnamed params
  def add(num1, num2)
    return num1 + num2 # Explicit return
  end

  # Named params
  def multiply(num1:, num2:)
    num1 * num2 # Implicit return
  end
end

calc = Calculator.new
calc.add(1, 3)
calc.multiply(num1: 2, num2: 5)
```
