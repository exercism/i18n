# Introduction

En SQL, une instruction `SELECT` permet de récupérer des données depuis une base de données.
Le résultat d'une instruction `SELECT` est un ensemble de résultats.
Un ensemble de résultats contient des valeurs organisées en lignes et en colonnes.
Chaque colonne correspond à un attribut particulier des données.
Chaque ligne contient une valeur pour chaque colonne.

Une façon de se le représenter : un ensemble de colonnes forme une structure de données, où chaque colonne représente un champ de cette structure et chaque ligne une instance de cette structure.

Avec une instruction `SELECT`, on précise les données que l'on veut récupérer.
On peut aussi, si besoin, transformer, filtrer ou modifier la forme des données renvoyées.

## Les bases

L'anatomie d'une instruction `SELECT` de base est la suivante :

```sql
SELECT <columns>
FROM <source>
WHERE <criteria>;
```

~~~~exercism/note
Les clauses `FROM` et `WHERE` sont facultatives.
Par exemple, une instruction comme `SELECT "Hello, world.";` est parfaitement valide.

À noter aussi que les retours à la ligne ne sont pas obligatoires : n'importe quel espacement suffit pour séparer les différentes clauses (c'est-à-dire les différentes parties) de l'instruction `SELECT`.
~~~~

Juste après le mot-clé `SELECT` vient la liste des colonnes que l'on veut obtenir dans le résultat.
La clause `FROM` indique la source des données, qui est en général une table de la base de données.
La clause `WHERE` filtre les données renvoyées selon un ou plusieurs critères.

## Filtrer les données avec la clause WHERE

La clause `WHERE` permet de filtrer les données récupérées par une instruction `SELECT`.
Par exemple, si l'on ne veut que la catégorie « Appliances », on peut faire ainsi :

```sql
SELECT * FROM inventory
WHERE category = "Appliances";
```

Résultat :
```
upc           category    supplier        brand      product_name                 weight  stock
------------  ----------  --------------  ---------  ---------------------------  ------  -----
899001234556  Appliances  Culinary Depot  QuickBrew  Single-Serve Coffee Maker    4.2     18   
880012349876  Appliances  Culinary Depot  HeatWave   Compact Toaster Oven         7.5     14   
844110220987  Appliances  Culinary Depot  BlendPro   High-Speed Personal Blender  3.1     16   
```

Ou encore, si l'on ne veut que les données dont le poids est compris entre 2,0 et 6,0 :

```sql
SELECT * FROM inventory
WHERE weight BETWEEN 2.0 AND 6.0;
```

Résultat :
```
upc           category    supplier        brand      product_name                  weight  stock
------------  ----------  --------------  ---------  ----------------------------  ------  -----
899001234556  Appliances  Culinary Depot  QuickBrew  Single-Serve Coffee Maker     4.2     18   
823450987112  Cookware    KitchenCo       FreshKeep  12-Piece Glass Container Set  6       33   
899998877665  Cookware    KitchenCo       IronCraft  Cast-Iron Grill Pan           5.3     21   
844110220987  Appliances  Culinary Depot  BlendPro   High-Speed Personal Blender   3.1     16   
```
