# Introduction

La syntaxe de déstructuration de tableau de JavaScript est un moyen concis d'extraire des valeurs d'un tableau et de les affecter à des variables distinctes.

Dans cet exemple, chaque valeur du tableau `numberOfMoons` est affectée à sa planète correspondante :

```javascript
const numberOfMoons = [0, 2, 14];
const [venus, mars, neptune] = numberOfMoons;

neptune;
// => 14
```
