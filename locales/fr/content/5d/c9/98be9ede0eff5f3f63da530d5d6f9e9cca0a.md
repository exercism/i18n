# Apprentissage

Tcl a été conçu dans le but d'être très simple, mais puissant.
C'est pourquoi apprendre [la syntaxe de base de Tcl][syntax] est assez facile.

Pour un tutoriel pratique, consulte [Learn X in Y minutes: Tcl][X-in-Y].

Pour un tutoriel complet en plusieurs parties :
 - [The Tcl tutorial][tutorial] couvre Tcl 8.5 (la version stable actuelle est la 9.0)
 - La prise en charge de la programmation orientée objet a été ajoutée au cœur de Tcl dans la version 8.6.
   Magicsplat propose un [tutoriel complet sur la POO][oo-tutorial] qui traite de ce sujet.

[X-in-Y]: https://learnxinyminutes.com/docs/tcl/
