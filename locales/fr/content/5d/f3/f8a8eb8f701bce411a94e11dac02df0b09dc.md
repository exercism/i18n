# À propos

Par défaut, les fonctions ont une liaison externe et peuvent être appelées depuis n'importe quel autre fichier du projet.
Pour en savoir plus sur la liaison, consulte le [concept de liaison](../linkage/introduction.md#Introduction).
Une fonction `static` ne peut être appelée que dans le fichier source où elle est définie.

Par exemple

```c
// file scope, internal linkage
// can only be called from within this file
static void some_function()
{
    // code snipped
}

// file scope, external linkage by default
// can be called from any other file in the project
int main()
{
    // code snipped
}
```

Même si une fonction est déclarée dans un fichier d'en-tête, si elle est définie comme `static`, il ne sera pas possible de l'appeler depuis l'extérieur de son fichier source.
Un fichier source pourrait inclure l'en-tête, appeler la fonction `static` déclarée dans l'en-tête et compiler, mais l'éditeur de liens ne parviendra pas à trouver la définition de la fonction `static`.
Une fonction marquée `static` dans un fichier source ne doit pas être déclarée dans son fichier d'en-tête.
