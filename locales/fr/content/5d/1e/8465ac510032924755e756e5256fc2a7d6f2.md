# Introduction

Les concepts de covariance et de contravariance en PHP sont importants, car PHP impose que ces règles soient respectées lorsqu'on étend des classes ou des interfaces.

La covariance préserve la relation entre deux types, tandis que la contravariance inverse cette relation. En bref, cela signifie que lorsqu'on étend des classes et qu'on redéfinit des fonctions, on peut autoriser des types plus ou moins spécifiques pour les paramètres d'une méthode, et renvoyer depuis cette méthode des types moins nombreux ou plus spécifiques.

## Exemples

Considérons la classe suivante :

```php
class Calculator 
{
    public function add(int $x, int $y): int 
    {
        return $x + $y;
    }
}
```

Si on étend cette classe, on peut autoriser davantage de types de paramètres que ceux déclarés à l'origine, mais on ne peut rien renvoyer d'autre que les types de retour d'origine.

```php
class Floatulator extends Calculator
{
    // This is valid
    public function add(int|float $x, int|float $y): int 
    {
        return (int)($x + $y);
    }
}
```

La classe étendue suivante n'est pas valide, car renvoyer des types supplémentaires ou plus larges n'est pas autorisé :

```php
class BrokenCalculator extends Calculator 
{
    // This is invalid and will not compile
    public function add(int|float $x, int|float $y): int|float{
        return $x + $y;
    }
}
```
