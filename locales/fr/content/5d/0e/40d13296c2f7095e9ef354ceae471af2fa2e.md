## Registres

| Registre | Utilisation  | Type    | Description                                      |
| -------- | ------------ | ------- | ------------------------------------------------ |
| `$a0`    | entrée       | adresse | chaîne de caractères terminée par un caractère nul |
| `$a1`    | entrée/sortie | adresse | chaîne de caractères résultat terminée par un caractère nul |
| `$t0-9`  | temporaire   | quelconque | pour le stockage temporaire                      |
