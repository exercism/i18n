# Introduction

On peut rendre un paramètre de méthode optionnel en lui affectant une valeur par défaut. Lorsqu'on appelle une méthode avec des paramètres optionnels, l'appelant n'est pas tenu de leur passer une valeur. Si aucune valeur n'est passée pour un paramètre optionnel, c'est sa valeur par défaut qui est utilisée.

Les paramètres optionnels _doivent_ se trouver à la fin de la liste de paramètres ; ils ne peuvent pas être suivis de paramètres non optionnels.

```csharp
class Card
{
    static string NewYear(int year = 2020)
    {
        return $"Happy {year}!";
    }
}

Card.NewYear();     // => "Happy 2020!"
Card.NewYear(1999); // => "Happy 1999!"
```
