# Indices

## Général

- La classe `string` propose de nombreuses [méthodes intégrées][methods] très utiles.

## 1. Récupère le message d'une ligne de log

- Il existe [plusieurs méthodes][index-of] pour trouver l'indice auquel un texte apparaît dans une `string`.
- La suppression des espaces blancs est [intégrée][trim].

## 2. Récupère le niveau de log d'une ligne de log

- Une `string` peut être convertie en minuscules à l'aide d'une [méthode intégrée][to-lower].

## 3. Reformate une ligne de log

- Il existe un [opérateur intégré][plus-operator] pour concaténer des _strings_.
