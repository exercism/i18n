# Introduction

## Le temps

Le module `Time` sert à afficher des dates et des heures lisibles par un être humain.
S'il est techniquement possible de manipuler des dates et des heures avec `Time`, il existe des paquets de la communauté Elm bien plus adaptés à cette tâche, comme [`justinmimbs/date`][date] ou [`CoderDennis/elm-time-format`][elm-time-format].

### Posix

Les instants sont représentés par le type opaque `Posix`, qui encapsule le temps Unix epoch, le nombre de millisecondes écoulées depuis le 1er janvier 1970 à minuit UTC.
Un `Posix` est une valeur non ambiguë qui ne varie pas d'un fuseau horaire à l'autre, ce qui en fait un bon choix pour mesurer le temps.
Dans une application Elm, les instants `Posix` sont généralement fournis par des sources externes, comme le navigateur.

Il est possible de transformer un `Posix` en un nombre de millisecondes, et inversement, avec les fonctions suivantes :

```elm
posixToMillis : Posix -> Int
millisToPosix : Int -> Posix
```

### Les fuseaux horaires

Dans notre vie quotidienne, nous ne lisons généralement pas de `Posix` et préférons l'heure locale, qui dépend de notre position sur Terre et des règles locales d'heure d'été.
En Elm, cette information est encodée dans le type opaque `Zone`, généralement fourni par le navigateur.

Il existe une `Zone` particulière qui est toujours accessible :

```elm
utc : Zone
```

### Les instants lisibles par un humain

Avec un `Posix` et une `Zone`, on dispose de suffisamment d'informations pour afficher l'heure locale avec le niveau de détail souhaité.
Voici une liste des fonctions qui peuvent servir à cela :

```elm
toYear : Zone -> Posix -> Int
toMonth : Zone -> Posix -> Month
toDay : Zone -> Posix -> Int
toWeekday : Zone -> Posix -> Weekday
toHour : Zone -> Posix -> Int
toMinute : Zone -> Posix -> Int
toSecond : Zone -> Posix -> Int
toMillis : Zone -> Posix -> Int
```

Tu auras sans doute remarqué deux autres types personnalisés de `Time` :

```elm
type Month = Jan | Feb | Mar | Apr | May | Jun | Jul | Aug | Sep | Oct | Nov | Dec
type Weekday = Mon | Tue | Wed | Thu | Fri | Sat | Sun
```

Il revient aux utilisateurs de convertir ces types personnalisés en valeurs lisibles par un humain.
