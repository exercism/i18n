# Introduction

Parfois, quand une fonction prend beaucoup d'arguments, il peut être difficile de se rappeler dans quel ordre les donner. Pour faciliter la lisibilité, Gleam permet d'étiqueter les arguments avec un nom.

Pour étiqueter un argument, indique le nom de l'étiquette avant le nom de l'argument, en les séparant par un espace.

```gleam
pub fn replace(
  in string: String,
  each target: String,
  with replacement: String
) -> String {
  // ...
}
```

Quand on appelle une fonction avec des arguments étiquetés, on peut passer les arguments dans n'importe quel ordre. Ces appels à `replace` sont tous équivalents :

```gleam
replace(in: "🍔🍔🍔" each: "🍔", with: "🍕")

replace(each: "🍔", in: "🍔🍔🍔", with: "🍕")

replace(with: "🍕", each: "🍔", in: "🍔🍔🍔")
```

Les étiquettes sont toujours facultatives. Même si une fonction prend des arguments étiquetés, on peut toujours l'appeler sans étiquette.

```gleam
replace("🍔🍔🍔", "🍔", "🍕")
```
