# N'utilise pas la méthode `main`

Essaie de retirer la méthode `main` du code.
Les tests de l'exercice n'exigent pas qu'une solution ait une méthode `main`, et sa présence rend le code un peu plus difficile à lire.

En général, on ajoute une méthode `main` pour faciliter le débogage du code.
Cependant, une meilleure approche consiste à déboguer le code pendant l'exécution d'un ou plusieurs tests unitaires.
Cela présente l'avantage supplémentaire de pouvoir se concentrer sur le débogage d'un cas de test précis.

Voici quelques liens qui expliquent comment déboguer du code Java pendant l'exécution de tests unitaires dans différents IDE :

- [Exécuter et déboguer des tests Java dans Visual Studio Code](https://code.visualstudio.com/docs/java/java-testing#_rundebug-test-cases)
- [Déboguer des tests dans IntelliJ IDEA](https://www.jetbrains.com/help/idea/performing-tests.html#RedebugFailedTests)
