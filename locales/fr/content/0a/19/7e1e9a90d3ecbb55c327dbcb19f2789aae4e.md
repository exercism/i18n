# Utiliser le littéral null

Lorsqu'on travaille avec des `Strings`, il vaut mieux comparer directement à `null` plutôt que d'utiliser `Optional`.

Utiliser `Optional` dans ce contexte ajoute une complexité inutile et fait l'impasse sur ce que l'on cherche justement à pratiquer : gérer directement les valeurs `null`.
