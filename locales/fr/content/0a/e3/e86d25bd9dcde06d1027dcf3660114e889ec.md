# Instructions

Dans cet exercice, tu vas implémenter la logique de quête d'un nouveau jeu de rôle développé par un ami. Le personnage principal du jeu est Annalyn, une fille courageuse accompagnée d'un chien de compagnie fidèle et féroce. Malheureusement, le malheur frappe : son meilleur ami a été enlevé alors qu'il cherchait des baies dans la forêt. Annalyn va tenter de le retrouver et de le libérer, en emmenant éventuellement son chien avec elle dans cette quête.

Après avoir suivi la piste de son meilleur ami pendant un certain temps, elle découvre le camp où il est retenu prisonnier. Il s'avère que les ravisseurs sont deux : un puissant chevalier et un archer rusé.

Après avoir trouvé les ravisseurs, Annalyn se demande lesquelles des actions suivantes elle peut entreprendre :

- Attaque rapide : une attaque rapide est possible si le chevalier dort, car il lui faut du temps pour enfiler son armure, ce qui le rend vulnérable.
- Espionnage : on peut espionner le groupe si au moins l'un d'entre eux est éveillé. Sinon, espionner est une perte de temps.
- Signaler au prisonnier : on peut signaler sa présence au prisonnier à l'aide de sons d'oiseaux si le prisonnier est éveillé et que l'archer dort, car les archers sont formés aux signaux d'oiseaux et pourraient donc intercepter le message.
- _Libérer le prisonnier_ : Annalyn peut essayer de se faufiler dans le camp pour libérer le prisonnier.
  C'est une entreprise risquée, qui ne peut réussir que de deux façons :
  - Si Annalyn a son chien avec elle, elle peut libérer le prisonnier si l'archer est endormi.
    Le chevalier a peur du chien et l'archer n'aura pas le temps de se préparer avant qu'Annalyn et le prisonnier ne puissent s'échapper.
  - Si Annalyn n'a pas son chien, alors elle et le prisonnier doivent être très discrets !
    Annalyn peut libérer le prisonnier si le prisonnier est éveillé et que le chevalier et l'archer dorment tous les deux, mais si le prisonnier dort, il ne peut pas être libéré : le prisonnier serait surpris par l'apparition soudaine d'Annalyn et réveillerait le chevalier et l'archer.

Tu as quatre tâches : implémenter la logique qui détermine si les actions ci-dessus sont possibles, en fonction de l'état des trois personnages présents dans la forêt et de la présence ou non du chien d'Annalyn.

## 1. Vérifie si l'action « Attaque rapide » est possible

Implémente une fonction nommée `canExecuteFastAttack` qui prend une valeur booléenne qui indique si le chevalier est éveillé. Cette fonction renvoie `true` si l'action « Attaque rapide » est possible, selon l'état du personnage. Sinon, elle renvoie `false` :

```purescript
knightIsAwake :: Boolean
knightIsAwake = true

canExecuteFastAttack knightIsAwake
-- => false
```

## 2. Vérifie si l'action « Espionnage » est possible

Implémente une fonction nommée `canSpy` qui prend trois valeurs booléennes qui indiquent, respectivement, si le chevalier, l'archer et le prisonnier sont éveillés. La fonction renvoie `true` si l'action « Espionnage » est possible, selon l'état des personnages. Sinon, elle renvoie `false` :

```purescript
knightIsAwake :: Boolean
knightIsAwake = true

archerIsAwake :: Boolean
archerIsAwake = true

prisonerIsAwake :: Boolean
prisonerIsAwake = true

canSpy knightIsAwake archerIsAwake prisonerIsAwake
-- => true
```

## 3. Vérifie si l'action « Signaler au prisonnier » est possible

Implémente une fonction nommée `canSignalPrisoner` qui prend deux valeurs booléennes qui indiquent, respectivement, si l'archer et le prisonnier sont éveillés. La fonction renvoie `true` si l'action « Signaler au prisonnier » est possible, selon l'état des personnages. Sinon, elle renvoie `false` :

```purescript
archerIsAwake :: Boolean
archerIsAwake = false

prisonerIsAwake :: Boolean
prisonerIsAwake = true

canSignalPrisoner archerIsAwake prisonerIsAwake -- => true
```

## 4. Vérifie si l'action « Libérer le prisonnier » est possible

Implémente une fonction nommée `canFreePrisoner` qui prend quatre valeurs booléennes. Les trois premiers paramètres indiquent, respectivement, si le chevalier, l'archer et le prisonnier sont éveillés. Le dernier paramètre indique si le chien d'Annalyn est présent. La fonction renvoie `true` si l'action « Libérer le prisonnier » est possible, selon l'état des personnages et la présence du chien d'Annalyn. Sinon, elle renvoie `false` :

```purescript
knightIsAwake :: Boolean
knightIsAwake = true

archerIsAwake :: Boolean
archerIsAwake = false

prisonerIsAwake :: Boolean
prisonerIsAwake = true

petDogIsPresent :: Boolean
petDogIsPresent = true

canFreePrisoner knightIsAwake archerIsAwake prisonerIsAwake petDogIsPresent
-- => false
```
