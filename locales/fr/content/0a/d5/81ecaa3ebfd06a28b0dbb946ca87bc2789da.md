# Débogue en `jq`

`jq` dispose d'un filtre [`debug`][debug] bien pratique.
Utilise-le pendant que tu développes tes solutions d'exercice pour inspecter les données qui se trouvent actuellement dans le pipeline jq.
Consulte la [documentation sur le débogage][debugging] pour plus de détails.

[debug]: https://jqlang.org/manual/#debug
[debugging]: https://exercism.org/docs/tracks/jq/debugging
