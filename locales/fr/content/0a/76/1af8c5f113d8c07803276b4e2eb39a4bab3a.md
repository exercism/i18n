# Ordre des annotations de fonction

Par convention, les annotations de fonction `@doc` doivent venir avant les annotations de fonction `@spec`, et les annotations de fonction `@spec` doivent se placer directement avant la fonction. Si la fonction comporte plusieurs clauses, les annotations de fonction doivent venir avant la première clause.

Exemple :

```elixir
@doc """
This function counts the number elements in a list
"""
@spec count(list(any())) :: integer()
def count([]), do: 0
def count([h | t]), do: 1 + count(t)
```
