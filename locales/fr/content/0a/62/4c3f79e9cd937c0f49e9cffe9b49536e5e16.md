# Indices

## Général

- Le prix d'un article est le deuxième élément de son tableau à 2 éléments.
  `second`, dans [`sequences`][sequences], permet de le lire.
- Les mots d'ordre supérieur comme `filter`, `count`, `sort-by` et `map-sum`
  prennent tous une *quotation* (du code entre `[ ]`) comme deuxième
  argument.

## 1. Trie l'inventaire par prix

- `sort-by` (dans [`sorting`][sorting]) prend une séquence et une quotation
  qui renvoie une clé triable pour chaque élément.

## 2. Trouve les articles sans prix défini

- Un prix manquant, c'est `f`. `f` est aussi la seule valeur _falsy_ de
  Factor, donc `[ second not ] filter` garde les articles dont le prix
  est `f`.
- `[ second ] reject` fait la même chose dans l'autre sens.

## 3. Compte les articles chers

- `count` exécute le prédicat sur chaque élément et compte les
  correspondances.

## 4. Trouve l'article le moins cher

- `minimum-by` (dans [`sequences`][sequences]) renvoie l'élément dont la
  clé extraite est la plus petite.

## 5. Additionne tous les prix

- `map-sum` (dans [`sequences`][sequences]) applique une quotation à chaque
  élément de la séquence et additionne les résultats.

[sequences]: https://docs.factorcode.org/content/vocab-sequences.html
[sorting]: https://docs.factorcode.org/content/vocab-sorting.html
