## Général

N'implémente pas la structure `SimpleLinkedList` comme une enveloppe autour d'un `Vec`. Alloue plutôt les nœuds sur le tas.

On peut l'implémenter comme ceci :

```
pub struct SimpleLinkedList<T> {
    head: Option<Box<Node<T>>>,
}
```

Le champ `head` pointe vers le premier élément (Node) de cette liste chaînée.

Cette implémentation nécessite aussi une structure `Node` avec les champs suivants :

```
struct Node<T> {
    data: T,
    next: Option<Box<Node<T>>>,
}
```

`data` contient les données stockées, et `next` pointe vers le nœud suivant (s'il existe) ou vers None.

## Pourquoi `Option<Box<Node<T>>>` et pas seulement `Option<Node<T>>` ?

Essaie de ton côté. Tu obtiendras l'erreur suivante.

```
| struct Node<T>
| ^^^^^^^^^^^^^^ recursive type has infinite size
...
|     next: Option<Node<T>>,
|     --------------------- recursive without indirection
```

Le problème est qu'à la compilation, la taille de `next` doit être connue.
Comme `next` est récursif (« un nœud contient un nœud qui contient un nœud... »), le compilateur ne sait pas quelle quantité de mémoire allouer.
À l'inverse, [Box](https://doc.rust-lang.org/std/boxed/) est un pointeur vers le tas dont la taille est définie.
