# Ajout aux instructions

## Comment cet exercice est structuré pour le parcours Python

Les tests de cet exercice attendent que ta solution soit implémentée en Python sous la forme d'une `class` `RelativeDistance`.
Si tu ne connais pas les `class`es en Python, [concept:python/classes]() et [les `classes` dans la documentation officielle de Python][classes in python] sont de bons points de départ.


`RelativeDistance` doit être initialisée (_voir [`__init__()`][init] pour plus d'informations_) avec `family_tree`, un dictionnaire dans lequel les `keys` sont des individus et les `values` des `list`es contenant les enfants de cet individu.
Tu devras aussi implémenter une [méthode][methods] `degree_of_separation` qui renvoie le degré de séparation entre `person_a` et `person_b`, deux individus de l'arbre familial fourni.


On te fournit une implémentation ébauchée de la [méthode spéciale][special-methods] `__init__` qui sert à créer une instance de la classe `RelativeDistance`, ainsi qu'une ébauche de la méthode `degree_of_separation`.
Tout d'abord, tu devras personnaliser `__init__` en ajoutant un attribut approprié sur `self` (_l'instance_) pour représenter les données de `family_tree`.
Ensuite, tu pourras ajouter ta logique à la méthode `degree_of_separation` pour calculer le degré de séparation entre `person_a` et `person_b`.


## Messages d'exception

Il est parfois nécessaire de [lever une exception][raising-exceptions].
Dans ce cas, tu dois toujours inclure un **message d'erreur explicite** pour indiquer l'origine de l'erreur.
Cela rend le code plus lisible et facilite grandement le débogage.
Lorsque tu sais que l'origine de l'erreur sera d'un certain type, tu peux choisir de lever l'un des [types d'erreur prédéfinis][base-error-classes], mais tu dois tout de même inclure un message explicite.

Cet exercice demande d'utiliser l'[instruction `raise`][raise-statement] pour « lever » plusieurs `ValueError`.
Dans le premier cas, tu devras lever une `ValueError` quand l'une des deux personnes passées à la méthode `RelativeDistance.degree_of_separation`, voire les deux, ne figure pas dans l'arbre familial.

```python
# Example when Person A is not in the tree.
raise ValueError("Person A not in family tree.")
```

Si les deux personnes sont présentes dans l'arbre familial, tu devras lever une `ValueError` quand il n'existe aucune connexion valide entre elles, au sens des règles.

```python
# Example when there are no valid connections.
raise ValueError("No connection between person A and person B.")
```

Les tests ne passeront que si tu `raise` le bon type d'`exception` et que tu y joins le message attendu.
Vérifie attentivement les tests et leurs résultats attendus, car ces instructions ne sont pas exhaustives.
