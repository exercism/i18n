# Tests

## Lance les tests

Quand tu es dans le répertoire d'un exercice, tu devrais voir deux sous-répertoires :

* `src` contient ta solution à l'exercice
* `spec` contient les tests à lancer pour l'exercice

Si tu es dans le bon répertoire (c'est-à-dire celui qui contient `src` et `spec`), tu peux lancer les tests de cet exercice avec la commande `crystal spec` :

```bash
$ pwd
/Users/johndoe/Code/exercism/crystal/hello-world

$ ls
GETTING_STARTED.md README.md          spec               src

$ crystal spec
```

Cela lancera tous les fichiers de test du répertoire `spec`.

Dans chaque fichier de test, tous les tests sauf le premier sont ignorés.

Une fois que tu fais passer un test, tu peux réactiver le test suivant en remplaçant `pending` par `it`.

## Formatage Crystal

Avant de soumettre, il est recommandé de lancer `crystal tool format` sur ta solution.

Tu peux formater tout ce qui se trouve dans le répertoire courant avec :

```bash
$ crystal tool format ./
```

Ou tu peux ne formater que certains fichiers avec :

```bash
$ crystal tool format ./<path>/<to>/<file>
```

## Soumets ta solution

N'oublie pas de soumettre le fichier source qui se trouve dans le répertoire `src` lorsque tu soumets ta solution :

```bash
$ exercism submit src/<exercise>.cr
```
