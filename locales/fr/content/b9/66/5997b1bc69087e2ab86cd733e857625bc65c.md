# Tests

## Installation

Suis les [instructions d'installation pour WebAssembly][docs-exercism-wasm] afin d'installer les dépendances nécessaires.

## Prérequis

Installe les dépendances de l'exercice :

```shell
# Using npm
npm install

# Alternatively using yarn
yarn
```

## Fais passer la suite de tests

Tous les exercices sont fournis avec une suite de tests qui t'aide à valider ta solution avant de la soumettre.
Tu peux exécuter ces tests en ouvrant une invite de commandes dans le répertoire de l'exercice, puis en lançant :

```bash
# Using npm
npm test

# Alternatively using yarn
yarn test
```

Dans certaines suites de tests, tous les tests, sauf le premier, ont été ignorés.

Une fois qu'un test passe, tu peux activer le suivant en remplaçant `xtest` par `test`.

## Écris des tests personnalisés

Si tu souhaites écrire des tests supplémentaires et personnalisés, crée un nouveau fichier `custom.spec.js`, puis soumets-le avec ta solution, en même temps que le nouveau fichier :

```shell
exercism submit numbers.wat custom.spec.js
```

[docs-exercism-wasm]: https://exercism.org/docs/tracks/wasm/installation
