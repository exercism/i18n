# À propos

Une valeur booléenne représente le fait qu'une condition est `true` ou `false`.
En Go, le type `bool` ne peut prendre que l'une de ces deux valeurs.

```go
isDoorLocked := true
hasKey := true
knowsCode := false
```

## Opérateurs logiques

Les opérateurs logiques agissent sur une ou deux valeurs booléennes et produisent un résultat booléen.

| Opérateur | Nom | Comportement                                        |
| --------- | --- | --------------------------------------------------- |
| `!`       | PAS | Renvoie l'opposé d'une seule valeur booléenne       |
| `&&`      | ET  | Renvoie `true` seulement si les deux côtés valent `true` |
| `\|\|`    | OU  | Renvoie `true` si au moins un côté vaut `true`      |

Utilise `!` (PAS) quand tu as besoin de l'opposé d'une valeur booléenne :

```go
!isDoorLocked // false
```

Utilise `&&` (ET) quand les deux conditions doivent être `true` :

```go
canUnlockDoor := isDoorLocked && hasKey // true
```

Utilise `||` (OU) quand au moins une condition doit être `true` :

```go
canOpenDoor := canUnlockDoor || knowsCode // true
```

Les opérateurs logiques sont évalués dans cet ordre : d'abord `!`, puis `&&`, puis `||`.
Utilise des parenthèses pour regrouper le code et contrôler l'ordre dans lequel les opérations sont effectuées :

```go
!true && false   // false because !true is evaluated first
!(true && false) // true because true && false is evaluated first
```
