# Strings

`STR` contient du texte. Une _string_ s'écrit entre guillemets doubles.

```sather
   composer : STR is
      return "Sibelius";
   end;
```

Une `STR` ne change jamais une fois qu'elle existe. Tout ce qui suit renvoie une _string_ *nouvelle* plutôt que de modifier celle que l'on interroge.

## Concaténation

```sather
"Jean" + " " + "Sibelius"      -- "Jean Sibelius"
```

`+` permet aussi de coller un nombre à une _string_, ce qui est la façon d'insérer un nombre dans une phrase :

```sather
"Opus " + 27           -- "Opus 27"
```

## Longueur

```sather
"Sibelius".size        -- 8
"".size                -- 0
```

`.size` compte les caractères, et la réponse est un `INT`.

## Extraits

| Appel | Réponse |
| --- | --- |
| `"Sibelius".head(3)` | `"Sib"` |
| `"Sibelius".tail(4)` | `"lius"` |

Demander plus qu'il n'y en a renvoie ce qu'il y a, plutôt que d'échouer.

## Comparaison

`=` permet de savoir si deux _strings_ sont le même texte, et `/=` si elles diffèrent.

```sather
"forte" = "forte"      -- true
"forte" = "Forte"      -- false
```

La casse compte. `.upper` et `.lower` renvoient une copie dans une casse donnée, ce qui est la façon habituelle de comparer sans s'en soucier :

```sather
"Forte".lower                    -- "forte"
"Forte".lower = "forte".lower    -- true
```

## Un mot sur la taille

Une `STR` est une suite d'octets, et `.size` compte les octets. Pour du texte anglais, cela revient au même que compter les lettres. Pour du texte comportant des accents ou d'autres alphabets, ce n'est pas le cas, car ces lettres occupent plus d'un octet chacune.
