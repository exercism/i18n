# Introduction

Les commentaires te permettent de laisser des notes dans le code sans changer la façon dont il s'exécute.
Les commentaires sur une ligne commencent par `//`, et les commentaires multilignes sont encadrés par `/*` et `*/` :

```go
// This is a single-line comment.

/*
This is a
multiline comment.
*/
```

Les commentaires ont différents rôles selon l'endroit où ils apparaissent.

## Commentaires de code

Les commentaires de code expliquent pourquoi on fait quelque chose, pas ce qu'on fait.
Utilise-les quand la raison derrière une décision n'est pas évidente à la lecture du code :

```go
results = results[1:] // skipping the header row
```

## Commentaires de documentation

Les commentaires de documentation se placent juste avant une déclaration, sans ligne vide entre le commentaire et la déclaration.
[`godoc`][godoc] les analyse pour générer la documentation du paquet.
Un commentaire de documentation doit être une phrase complète qui commence par le nom de l'identifiant et se termine par un point.

Les commentaires de paquet commencent par le nom du paquet :

```go
// Package kelvin provides tools to convert temperatures to and from Kelvin.
package kelvin
```

Les commentaires de fonction commencent par le nom de la fonction :

```go
// CelsiusFreezingTemp returns an integer value equal to the temperature at which water freezes in degrees Celsius.
func CelsiusFreezingTemp() int {
	return 0
}
```

[godoc]: https://go.dev/blog/godoc
