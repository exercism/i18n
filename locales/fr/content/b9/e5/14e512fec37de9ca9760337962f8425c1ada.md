## 1. Extrais les coordonnées

## 2. Formate les coordonnées

Implémente la fonction `convert_coordinate()` qui prend une coordonnée au format «\u00A02A\u00A0» et renvoie un tuple au format `("2", "A")`.


```python
>>> convert_coordinate("2A")

```

## 3. Fais correspondre les coordonnées

Implémente la fonction `compare_records()` qui prend une paire `(treasure, coordinate)` et un enregistrement `(location, coordinate, quadrant)`, puis compare leurs coordonnées.
Renvoie **`True`** si les coordonnées «\u00A0correspondent\u00A0», et **`False`** sinon.
Remets les coordonnées au bon format si nécessaire pour comparer correctement.


```python
>>> compare_records(('Brass Spyglass', '4B'), ('Seaside Cottages', ('1', 'C'), 'blue'))

```
