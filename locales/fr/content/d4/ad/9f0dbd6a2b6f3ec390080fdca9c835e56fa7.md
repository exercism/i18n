# Indices

## Général

- `<min-heap>`, `heap-push`, `heap-peek` et `heap-pop-all` se trouvent tous dans [`heaps`][heaps] ; `values` se trouve dans [`assocs`][assocs].
- Un tas stocke chaque élément sous la forme d'une *valeur* associée à une *clé* ; la clé est la priorité. `heap-push` les prend dans cet ordre : `( value key heap -- )`.

## 1. Ouvre la file d'attente

- `<min-heap>` construit un tas-min vide : la plus petite clé est servie en premier.

## 2. Ajoute un client

- Le nom du client est la valeur et la priorité est la clé, ce qui correspond exactement à l'ordre attendu par `heap-push`.
- `heap-push` consomme la file d'attente. Utilise `[ heap-push ] keep` pour ajouter le client tout en renvoyant la file d'attente.

## 3. Qui est le suivant ?

- `heap-peek` renvoie `value key` pour l'élément de tête sans le retirer. Tu ne veux que le nom, alors applique `drop` à la clé.

## 4. Sers tout le monde

- `heap-pop-all` vide le tas dans une liste d'associations de paires `{ key value }`, déjà dans l'ordre de priorité.
- `values` ne garde que les valeurs, c'est-à-dire les noms.
