# Introduction

Dans Cairo, la surcharge d'opérateurs te permet de définir un comportement personnalisé pour les opérateurs standards comme `+`, `-`, `==`, `<`, etc., lorsque tu manipules tes propres types.

Cela se fait en implémentant des traits spécifiques pour tes types personnalisés.

## Traits essentiels pour les opérateurs

### `Add` et `Sub`

Les traits `Add` et `Sub` te permettent de définir comment l'addition (`+`) et la soustraction (`-`) fonctionnent avec ton type :

```rust
impl MyTypeAdd of Add<MyType> {
    fn add(lhs: MyType, rhs: MyType) -> MyType {
        // Define addition behavior
    }
}
```

### `PartialEq`

Le trait `PartialEq` permet de comparer l'égalité (`==` et `!=`) entre les instances de ton type.

Cette comparaison peut souvent être générée automatiquement à l'aide de `#[derive(PartialEq)]`.

### `PartialOrd`

Le trait `PartialOrd` permet d'effectuer des opérations de comparaison (`<`, `>`, `<=`, `>=`) entre les instances de ton type.

Tu dois implémenter au moins la méthode `lt` (inférieur à) :

```rust
impl MyTypePartialOrd of PartialOrd<MyType> {
    fn lt(lhs: MyType, rhs: MyType) -> bool {
        // Define "less than" behavior
    }
}
```
