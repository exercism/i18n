# À propos

En Go, une `struct` est une suite d'éléments nommés appelés _champs_, et chaque champ possède un nom et un type.
Le nom d'un champ doit être unique au sein de la `struct`.
On peut comparer les `struct` aux _classes_ du paradigme de la programmation orientée objet.

## Définir une struct

On crée une nouvelle `struct` à l'aide des mots-clés `type` et `struct`, en définissant explicitement le nom et le type de ses champs.
Par exemple, on définit ici la `struct` `Shape`, qui contient le nom d'une forme et sa taille :

```go
type Shape struct {
    name string
    size int
}
```

Les noms de champs d'une `struct` suivent la convention de Go : les champs dont le nom commence par une lettre minuscule ne sont visibles que pour le code du même _package_, tandis que ceux dont le nom commence par une lettre majuscule sont visibles depuis les autres _packages_.

## Créer des instances d'une struct

Une fois la `struct` définie, il faut créer une nouvelle instance en indiquant les champs par leur nom, dans n'importe quel ordre :

```go
s := Shape {
    name: "Square",
    size: 25,
}
```

Pour lire ou modifier les champs d'une instance, on utilise la notation `.` :

```go
// Update the name and the size
s.name = "Circle"
s.size = 35
fmt.Printf("name: %s size: %d\n", s.name, s.size)
// Output: name: Circle size: 35
```

Les champs auxquels aucune valeur initiale n'est affectée prennent leur valeur zéro.
Par exemple :

```go
s := Shape{name: "Circle"}
fmt.Printf("name: %s size: %d\n", s.name, s.size)
// Output: name: Circle size: 0
```

Tu peux créer une instance de `struct` sans indiquer le nom des champs, à condition de définir les champs _dans l'ordre_ :

```go
s := Shape {
	"Oval",
	20,
}
```

Cependant, cette syntaxe est considérée comme du _code fragile_, car elle peut casser quand on ajoute un champ, surtout si le nouveau champ est d'un type différent.
Dans l'exemple suivant, on ajoute un champ supplémentaire à `Shape` :

```go
type Shape struct {
	name        string
	description string // new field 'description' added
	size        int
}

s := Shape{
    "Circle",
    20,
}
// Since the second field of the struct is now a string and not an int,
// the compiler will throw an error when compiling the program:
// Output: cannot use 20 (type untyped int) as type string in field value
// Output: too few values in Shape{...}
```

## Les fonctions « New »

Il est parfois agréable de disposer de fonctions qui aident à créer des instances de `struct`.
Par convention, ces fonctions s'appellent généralement `New` ou portent un nom qui commence par `New`, mais comme ce sont de simples fonctions ordinaires, tu peux leur donner le nom que tu veux.
Elles peuvent te faire penser aux constructeurs d'autres langages, mais en Go, ce ne sont que des fonctions ordinaires.

Dans l'exemple suivant, l'une de ces fonctions `New` sert à créer une nouvelle instance de `Shape` et à définir automatiquement une valeur par défaut pour la `size` de la forme :

```go
func NewShape(name string) Shape {
	return Shape{
		name: name,
		size: 100, //default-value for size is 100
	}
}

NewShape("Triangle")
// => Shape { name: "Triangle", size: 100 }

```

Utiliser des fonctions `New` présente les avantages suivants :

* la validation des valeurs fournies
* la gestion des valeurs par défaut
* comme les fonctions `New` sont souvent déclarées dans le même _package_ que les `struct` qu'elles initialisent, elles peuvent même initialiser des champs privés de la `struct`

Pour aller plus loin sur ce type, tu peux consulter ces ressources : [Go by Example: Structs][go-by-example-structs], [A Tour of Go: Structs][tour-of-go-structs] ou [Structures in Go (structs)][medium-structures-in-go]

## La fonction intégrée `new`

Une autre façon de créer une nouvelle instance de `struct` consiste à utiliser la fonction intégrée `new` :

```go
s := new(Shape) // s will be of type *Shape (pointer to shape)
fmt.Printf("name: %s size: %d\n", s.name, s.size)
// Output: name:  size: 0
```

Dans cet exemple, `new` crée une instance de la `struct` `Shape` dont toutes les valeurs sont initialisées à la valeur zéro de leur type, et renvoie un pointeur vers celle-ci.

~~~~exercism/note
La plupart du temps, tu ne verras pas de nouvelles instances de `struct` créées avec la fonction intégrée `new`.
Préfère toujours un littéral de `struct`, une fonction `New` personnalisée ou toute autre fonction fournie par le _package_ qui peut t'aider à construire une `struct`.
N'utilise la fonction intégrée `new` pour créer de nouvelles instances de `struct` qu'en dernier recours.
~~~~
