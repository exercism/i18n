# Instructions

Tu construis une petite calculatrice en notation polonaise inversée (NPI).
L'état de la calculatrice est une *pile de valeurs*, représentée par un tableau
Factor, et une *opération* est une _quotation_ qui prend une telle pile et en
renvoie une nouvelle.

```factor
{ 3 4 }   ! the calculator's stack: 3 is below 4
[ ... ]   ! an operation that consumes some values and pushes a result
```

## 1. Implémente l'addition

Définis `add-op` pour dépiler les deux valeurs du sommet de la pile, empiler
leur somme et renvoyer la nouvelle pile.

```factor
{ 3 4 } add-op .
! => { 7 }

{ 1 2 3 4 } add-op .
! => { 1 2 7 }
```

## 2. Implémente la multiplication

Définis `multiply-op` de la même façon, mais pour la multiplication.

```factor
{ 3 4 } multiply-op .
! => { 12 }
```

## 3. Applique une seule opération

Définis `apply-op` pour retirer une pile et une opération (une _quotation_) de
la pile de données et renvoyer la nouvelle pile de la calculatrice.

```factor
{ 3 4 } [ add-op ] apply-op .
! => { 7 }
```

## 4. Évalue un programme

Définis `evaluate` pour prendre une pile de départ et un tableau d'opérations,
appliquer chaque opération à tour de rôle et renvoyer la pile finale.

```factor
{ 3 4 5 } { [ add-op ] [ multiply-op ] } evaluate .
! => { 27 }
```

## 5. Évalue par nom

Maintenant, le programme est un tableau de *noms d'opérateurs* (_strings_), et
la calculatrice cherche chaque nom dans un _assoc_ qui associe les noms aux
opérations.

Définis `evaluate-named` pour prendre une pile de départ, un _assoc_
d'opérations nommées et un tableau de noms, puis renvoyer la pile finale.

```factor
{ 3 4 5 } H{ { "+" [ add-op ] } { "*" [ multiply-op ] } } { "+" "*" }
evaluate-named .
! => { 27 }
```

## 6. Divise en toute sécurité

Une vraie calculatrice ne doit pas produire silencieusement des résultats
absurdes quand on lui demande de diviser par zéro. La classe d'erreur
`zero-divisor-error` est déjà définie pour toi. Implémente `divide-op` de façon
analogue à `add-op` et `multiply-op`, sauf qu'elle `throw` un nouveau
`zero-divisor-error` quand le diviseur au sommet de la pile vaut `0`.

```factor
{ 12 4 } divide-op .
! => { 3 }

{ 1 5 6 2 } divide-op .
! => { 1 5 3 }

{ 5 0 } divide-op
! throws zero-divisor-error
```
