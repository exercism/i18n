# Instructions

Bienvenue dans le monde de *ChronoRealms*, une terre magique où de puissants Timekeepers contrôlent le cours du temps.

Dans ce royaume, les Timekeepers gèrent des « TimeShards », des unités spéciales que l'on peut additionner, soustraire, comparer et même tester pour l'égalité.

Ta mission est d'aider les Timekeepers en implémentant des opérateurs personnalisés pour manipuler ces TimeShards.

Les Timekeepers ont besoin que tu crées une structure personnalisée `TimeShard` qui prend en charge les opérations suivantes :

1. **Addition et soustraction de TimeShards** : les Timekeepers doivent pouvoir additionner et soustraire des TimeShards pour contrôler la chronologie.
2. **Comparaison de TimeShards** : il faut parfois comparer des TimeShards pour voir lequel est le plus grand, ou s'ils sont égaux.
3. **Vérification de l'égalité** : les Timekeepers doivent vérifier si deux TimeShards ont la même valeur.

Ta mission est d'implémenter les traits suivants pour la structure `TimeShard` :

1. **Addition (`Add`)** : permet d'additionner deux instances de `TimeShard`.
2. **Soustraction (`Sub`)** : permet de soustraire un `TimeShard` à un autre.
3. **Égalité (`PartialEq`)** : permet aux Timekeepers de vérifier si deux instances de `TimeShard` sont identiques.
4. **Comparaison (`PartialOrd`)** : permet de comparer deux instances de `TimeShard` pour voir laquelle est la plus grande ou la plus petite.

Un `TimeShard` sera représenté par une structure qui contient une valeur entière (`i32`).

Implémente les traits nécessaires pour faciliter le travail des Timekeepers.

```rust
let shard1 = TimeShard { value: 5 };
let shard2 = TimeShard { value: 3 };

// Adding TimeShards
let sum = shard1 + shard2; // TimeShard { value: 8 }

// Subtracting TimeShards
let difference = shard1 - shard2; // TimeShard { value: 2 }

// Checking equality
let are_equal = shard1 == shard2; // false

// Comparing TimeShards
let is_greater = shard1 > shard2; // true
```
