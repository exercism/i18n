# Ajout aux instructions

## Registres

| Registre | Utilisation | Type      | Objectif                       |
| -------- | ----------- | --------- | ------------------------------ |
| `$a0`    | entrée      | entier    | valeur donnée                  |
| `$v0`    | sortie      | entier    | différence des carrés          |
| `$t0-9`  | temporaire  | quelconque | utilisé pour le stockage temporaire |
