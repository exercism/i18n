# Introduction

## Opérateurs de comparaison

Les opérateurs de comparaison en Julia sont similaires à ceux de nombreux autres langages, même s'ils offrent quelques options supplémentaires aux amateurs de mathématiques.

Pour tester l'égalité, on dispose des opérateurs `==` (égal) et `!=` ou `≠` (différent).

```julia
txt = "abc"
txt == "abc"  # true
txt != "abc"  # false
txt ≠ "abc"  # false (synonym for !=)
```

On trouve également les différents opérateurs supérieur/inférieur.

```julia
1 < 3  # true
3 > 3  # false
3 <= 3  # true
3 ≤ 3  # true (synonym for <=)
4 >= 3  # true
4 ≥ 3  # true (synonym for >=)
```

Comme souvent avec Julia, un éditeur adapté facilite l'utilisation des symboles mathématiques. Tape `\ne`, `\le` ou `\ge` puis `TAB` pour obtenir `≠`, `≤` ou `≥`.

L'exemple précédent n'utilise que des nombres, mais nous verrons dans d'autres parties du programme que divers autres types possèdent une relation d'ordre et peuvent être comparés avec les opérateurs supérieur/inférieur.

Les opérateurs de comparaison peuvent être enchaînés, ce qui permet une syntaxe claire et concise :

```julia
n = 3
1 ≤ n ≤ 5  # true (n "between" two limits)
```

L'exemple précédent est un synonyme de `1 ≤ n && n ≤ 5`.

## Les branchements avec `if`

Voici la forme complète d'une instruction `if` :

```julia
if conditional1
    statements...
elseif conditional2
    statements...
else
    statements...
end
```

Nul besoin de parenthèses `()` ou d'accolades `{}`, et l'indentation ne sert « uniquement » à améliorer la lisibilité _(mais la lisibilité est très importante !)_.

`elseif` et `else` sont tous les deux facultatifs, et il peut y avoir plusieurs blocs `elseif`. En revanche, le `end` est obligatoire.

Il est possible d'imbriquer des instructions `if`, même s'il peut être utile de favoriser la lisibilité par un usage réfléchi des parenthèses, des indentations et des commentaires.

La forme la plus courte d'une instruction `if` ressemblerait à ceci :

```julia
if n < 0
    n = 0
end
```

Pour rappel : seules les expressions qui s'évaluent à `true` ou `false` peuvent servir de condition. Julia évite délibérément toute notion de « _truthiness_ », donc les valeurs nulles, les _strings_ vides et les tableaux vides ne sont _pas_ équivalents à `false`.

## L'opérateur ternaire

Une situation simple et courante consiste à choisir l'une de deux valeurs en fonction d'une condition.

Julia, comme beaucoup de langages, dispose d'un opérateur ternaire pour rendre cela plus concis.

La syntaxe est `conditional ? value_if_true : value_if_false`.

L'exemple précédent peut donc se réécrire ainsi :

```julia
n = n < 0 ? 0 : n
```

Les parenthèses ne sont pas exigées par le compilateur, mais elles peuvent améliorer la lisibilité.
