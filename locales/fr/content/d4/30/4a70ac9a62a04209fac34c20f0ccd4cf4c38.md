# Instructions

Tu travailles pour un cabinet d'avocats prestigieux spécialisé dans le traitement de demandes testamentaires uniques.

Dans cet exercice, tu vas ouvrir un coffre mystérieux.
Tu es l'exécuteur testamentaire et tu vas assembler les codes secrets, gardés depuis longtemps, de trois familles pour obtenir un numéro de compte et le code correspondant.

Pour empêcher une famille d'ouvrir le coffre seule, celui-ci ne peut être ouvert qu'en combinant leurs connaissances avec un modificateur secret que tu connais d'après le testament.

Tu as trois tâches, toutes liées à l'aide apportée aux familles pour ouvrir le coffre.

## 1. Prends place devant les familles et étale tes papiers

Définis un espace de noms appelé `estate_executor`.
Le code des tâches suivantes doit être défini dans le corps de l'espace de noms `estate_executor`.

```cpp
namespace some_name {
    // The space between the curly brackets
    // is called body of the  namespace.
}
```

## 2. Trouve le numéro de compte secret

C'est ton grand moment.
Toi seul détiens la clé modificatrice secrète qui permet de révéler le numéro de compte secret.

Définis la fonction `assemble_account_number(int secret_modifier)` qui prend le modificateur secret en argument et renvoie le numéro de compte assemblé sous forme d'`int`.

Pour obtenir le bon numéro, tu dois additionner le `bank_number_part` de chacune des trois familles.

## 3. Dernière étape : saisis le code secret

Les instructions du testament te demandent d'additionner d'abord tous les fragments bleus, puis tous les fragments rouges.
Le code résultant s'obtient en multipliant les deux sommes.

Définis la fonction `assemble_code()` qui renvoie le code résultant en combinant les fragments des trois familles en un seul `integer`.
La fonction ne prend aucun argument et s'appuie uniquement sur les informations contenues dans les espaces de noms correspondants des familles.
