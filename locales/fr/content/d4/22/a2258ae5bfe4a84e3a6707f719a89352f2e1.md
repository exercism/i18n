# Instructions supplémentaires

## Indices

Une [liste doublement chaînée](https://en.wikipedia.org/wiki/Doubly_linked_list) est une structure de données mutable. Comme F# est un langage avant tout fonctionnel, l'immuabilité est généralement préférée, mais le langage offre des fonctionnalités qui permettent d'utiliser la mutation quand c'est nécessaire.

- Le mot-clé `mutable` peut se placer devant les liaisons `let` et les champs d'[enregistrement](https://docs.microsoft.com/en-us/dotnet/articles/fsharp/language-reference/records), ce qui permet de leur affecter de nouvelles valeurs.

- Les propriétés d'une [classe](https://fsharpforfunandprofit.com/posts/classes) peuvent être rendues mutables en définissant un mutateur de propriété avec le mot-clé `set`.

Les liaisons mutables doivent être réaffectées avec `<-`

```fsharp
let mutable x = "initial value"
x <- "new value"
```
