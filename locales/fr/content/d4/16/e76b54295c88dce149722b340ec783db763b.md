# Indices

## Général

- Revois les motifs d'expressions régulières de l'introduction. N'oublie pas que, lorsque tu crées le motif à partir d'une chaîne de caractères, tu dois échapper certains caractères.
- Jette un œil à ce site sur les expressions régulières : [Regular-Expressions.info][website-regex-info].
- Jette un œil à ce site sur les expressions régulières : [Rex Egg - Le tutoriel d'expressions régulières le plus tyrannosaurique au monde][website-rexegg].
- Jette un œil à ce site sur les expressions régulières : [RegexOne - Apprends les expressions régulières avec des exercices simples et interactifs][website-regexone].
- Jette un œil à ce site sur les expressions régulières : [Regular Expressions 101 - un bac à sable d'expressions régulières en ligne][website-regex-101].
- Jette un œil à ce site sur les expressions régulières : [RegExr - un bac à sable d'expressions régulières en ligne][website-regexr].

## 1. Identifie les lignes de log corrompues

- La [fonction `regexp.from_string`][from-string] peut servir à compiler une expression régulière.
- La [fonction `regexp.check`][check] permet de tester si une expression régulière correspond à une chaîne de caractères.
- N'oublie pas d'échapper les caractères qui ont un sens particulier dans les expressions régulières.

## 2. Découpe la ligne de log

- La [fonction `regexp.split`][split] permet de découper une chaîne de caractères à l'aide d'une expression régulière.
- N'oublie pas d'échapper les caractères qui ont un sens particulier dans les expressions régulières.

## 3. Étiquette les lignes avec les noms d'utilisateur

- La [fonction `regexp.scan`][scan] permet de capturer des parties d'une chaîne de caractères à l'aide d'une expression régulière.
- N'oublie pas d'échapper les caractères qui ont un sens particulier dans les expressions régulières.
