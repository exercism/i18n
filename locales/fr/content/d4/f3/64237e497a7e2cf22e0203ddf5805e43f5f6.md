# À propos

En Common Lisp, les fonctions globales nommées se définissent avec `defun`.

Cette forme prend comme premier argument une liste de paramètres pour la fonction définie (cette liste de paramètres est aussi appelée _lambda list_).
Ensuite, elle peut, éventuellement, prendre une _string_ qui sert de documentation à cette fonction.
Enfin, viennent zéro ou plusieurs expressions qui constituent le corps de la fonction.

Pour appeler une fonction, on utilise le nom de la fonction comme premier élément d'une expression, suivi des éventuels paramètres de cette fonction.

```lisp
(defun add-one (x) (1+ x))

(add-one 3) ;; => 4
```

Les fonctions peuvent aussi prendre des [paramètres optionnels][concept-optional-parameters], des [paramètres de mot-clé][concept-keyword-parameters] et des [paramètres restants][concept-rest-parameters].
On en parlera dans les concepts suivants.

Le nom de la fonction est dans la portée du corps de la fonction, ce qui permet d'écrire des appels récursifs.

```lisp
(defun countdown (x)
  (if (zerop x) (print 'BLAST-OFF)
    (progn (print x) (countdown (1- x)))))

(countdown 3) ;; will print "3","2", "1" and "BLAST-OFF" to
              ;; standard output before evalutaing to 'BLAST-OFF
```
