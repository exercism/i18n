# Tests

Pour tester ta solution, ouvre le terminal et exécute

```
mason test
```

dans le dossier de l'exercice (celui qui contient le fichier `Mason.toml` ainsi que les dossiers `src/` et `test/`).

Si tu trouves que le message d'erreur n'est pas assez informatif, tu peux essayer ce qui suit pour en obtenir un plus détaillé.

```
mason test --show
```
