# Instructions complémentaires

## Implémentation

Les fonctions de cet exercice prennent un tableau contenant un ou plusieurs nombres, qui représentent chacun un « score de jeu ».

On peut lire les scores du joueur à partir de

| `scores`   |
|---|
| `scores[0]` |
| `scores[1]` |
| ... |
| `scores[scores_len - 1]` |

`personal_top_three()` doit écrire les meilleurs scores du joueur dans

| `output`   |
|---|
| `output[0]` |
| ... |
