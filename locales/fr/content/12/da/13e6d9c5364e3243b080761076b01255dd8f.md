# Le type tuple

En Cairo, un tuple est un type de données composé, polyvalent et efficace, qui permet de regrouper plusieurs valeurs de types différents au sein d'une seule entité.
Les tuples ont une longueur fixe, ce qui signifie qu'une fois déclarés, leur taille ne peut plus changer.

## Crée des tuples

Pour créer un tuple, on écrit une liste de valeurs séparées par des virgules entre parenthèses.
Chaque position du tuple a un type précis, et ces types peuvent être différents les uns des autres.

```rust
fn main() {
    let tup: (u32, u64, bool) = (10, 20, true);
}
```

Un tuple peut contenir plusieurs valeurs de types de données différents, y compris d'autres tuples.
Par exemple :

```rust
fn main() {
    let nested_tup: ((i32, u64), (u8, bool)) = ((10, 3), (5, false));
}
```

Ici, la variable `nested_tup` est un tuple qui contient deux tuples, ce qui montre qu'un tuple peut contenir d'autres tuples comme éléments.

## Déstructure des tuples

Pour accéder aux valeurs individuelles d'un tuple, on peut le déstructurer grâce à la correspondance de motifs.
Cela décompose le tuple en ses parties constituantes.

```rust
fn main() {
    let tup = (500, 6, true);

    let (x, y, z) = tup;

    println!("x is: {x}"); // prints "x is: 500"
    println!("y is: {y}"); // prints "x is: 6"
    println!("z is: {z}"); // prints "z is: true"
}
```

## Déclare et déstructure en même temps

On peut aussi déclarer et déstructurer un tuple en même temps.

```rust
fn main() {
    let (x, y): (felt252, felt252) = (2, 3);
}
```

## Le type unité `()`

Le type unité est un type particulier en Cairo qui n'a qu'une seule valeur : `()`.
Il est représenté par un tuple sans aucun élément.
La taille du type unité est toujours nulle, et il est garanti qu'il n'existe pas dans le code compilé.

En Cairo, toute expression renvoie une valeur, et quand une expression ne renvoie rien, elle renvoie implicitement `()`.
Cela peut être utile pour les fonctions qui doivent renvoyer une valeur mais qui n'ont aucune valeur significative à renvoyer.

## Déclaration d'un type tuple nommé

Un tuple nommé permet de créer un alias de type plus descriptif pour un tuple, ce qui améliore la lisibilité du code.

```rust
type Point = (u32, u32);

fn main() {
    let point: Point = (10, 8);
    println!("{point:?}"); // prints "(10, 8)"
}
```

Dans cet exemple, `Point` est un type tuple nommé qui représente une paire d'entiers non signés de 32 bits, ce qui rend le code plus expressif.
