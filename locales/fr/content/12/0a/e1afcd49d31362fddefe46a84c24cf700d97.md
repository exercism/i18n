# Introduction

Perl est un langage de programmation créé par Larry Wall, publié pour la première fois en 1987.

## Paquets et modules

Un paquet est un ensemble de code, souvent contenu dans un fichier de module du même nom avec l'extension `.pm`.
Le module peut ensuite être importé dans un autre fichier, généralement avec le mot-clé `use`.

```perl
# Foo.pm
package Foo;

# Accessible with `Foo::bar` when module is used
# or just `bar` if the subroutine is exported.
sub bar () {
    return 1;
}
```

## Variables

Il existe des variables scalaires (`$foo`), des tableaux (`@bar`) et des hash (`%baz`).
Pour rester simple, seules les variables scalaires seront utilisées ici.
Une valeur scalaire peut être : une _string_, un nombre, un booléen ou une [référence][perlreftut] vers quelque chose.
L'absence de valeur s'écrit `undef`.


Les mots-clés `my` et `our` déclarent une variable dans la portée lexicale, par exemple `my $foo;`.
Avec `our`, la variable est également un alias vers une variable de paquet du même nom.
Il existe d'autres façons de déclarer des variables qui ne seront pas abordées ici.

On peut affecter une valeur à une variable avec l'opérateur `=`, par exemple `$foo = 1;`, ce qui peut se faire en même temps que la déclaration de la variable, par exemple `my $foo = 1;`.

```perl
package Foo;

sub baz () {
    our $bar = 1; # Sets both $bar and $Foo::bar as 1.
    return $bar;
}

$Foo::bar = 2; # $bar is not accessible here, but $Foo::bar is.

# Both of these will print 1.
say baz;
say $Foo::bar;
```

## Sous-routines

Le mot-clé `sub` déclare une [sous-routine][perlsub].
Le mot-clé `return` quitte la sous-routine en renvoyant les valeurs spécifiées, ou une liste vide si aucune valeur n'est donnée.
Sans `return` explicite, la valeur renvoyée est déterminée par le contexte (scalaire, liste ou vide) dans lequel la sous-routine est utilisée et par sa dernière instruction.

```perl
sub hello () {
    return 'Hello, World!';
}
```

Les versions récentes de Perl permettent de spécifier des paramètres formels dans une [signature][perlsubsig].
La liste de paramètres peut contenir des variables scalaires, des tableaux ou des hash.
Une liste de paramètres vide signifie que la sous-routine n'accepte aucun argument.
Les versions plus anciennes de Perl obligeaient à récupérer les arguments depuis la variable spéciale `@_`, ce qui ne sera pas abordé ici.

## Commentaires

En Perl, les commentaires commencent par un `#` qui ne fait pas partie d'une _string_, et se terminent à la fin de la ligne.
