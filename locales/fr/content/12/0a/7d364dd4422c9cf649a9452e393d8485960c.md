# Ajout aux instructions

## Registres

| Registre | Utilisation  | Type    | Description                                  |
| -------- | ------------ | ------- | -------------------------------------------- |
| `$a0`    | entrée       | entier  | limite                                       |
| `$a1`    | entrée/sortie | adresse | tableau de destination pour les nombres premiers |
| `$v0`    | sortie       | entier  | nombre de nombres premiers                   |
| `$t0-9`  | temporaire   | quelconque | utilisé pour le stockage temporaire       |
