# Introduction

En Java, une `String` est un objet qui représente une chaîne de caractères immuable, c'est-à-dire une séquence de caractères Unicode (lettres, chiffres, ponctuation, etc.).
On utilise des guillemets doubles pour définir une instance de `String` :

```java
String fruit = "Apple";
```

On manipule les _strings_ en appelant leurs méthodes.
Une fois qu'une _string_ a été construite, sa valeur ne peut jamais changer.
Toute méthode qui semble modifier une _string_ renvoie en réalité une nouvelle _string_.
La classe `String` fournit quelques méthodes _statiques_ pour transformer les _strings_.
