# Indices

## Général

- Le temps d'exécution de cet exercice dépend fortement de l'algorithme utilisé, alors mise sur la vitesse.
- Les tests testent volontairement un grand nombre premier, et les solutions mal conçues vont dépasser le temps imparti.
- Le code Julia peut souvent s'exécuter plus vite si les lignes fréquemment utilisées sont extraites dans une fonction distincte (que l'on peut, si on le souhaite, imbriquer dans la fonction principale).
  - Contrairement à certains autres langages, en Julia, la précompilation est plus importante que tout surcoût d'appel de fonction.
- _Quelles valeurs faut-il tester pour s'assurer qu'elles ne sont pas des facteurs, avant de déclarer qu'un nombre est premier ?_ Garde ce groupe au minimum !
