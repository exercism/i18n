# Les structures conditionnelles

Une **structure conditionnelle** choisit entre deux chemins selon qu'une condition est vraie ou fausse.

```sather
   verdict(score : INT) : STR is
      if score >= 5 then
         return "Recalled";
      else
         return "Thank you";
      end;
   end;
```

Pour lire ce code : `if`, puis une question qui répond `true` ou `false`, puis `then`. Les lignes après `then` s'exécutent lorsque la réponse est vraie, et les lignes après `else` s'exécutent lorsqu'elle est fausse. `end;` referme l'ensemble.

## Plus de deux possibilités

`elsif` ajoute une autre question, posée uniquement lorsque celles au-dessus se sont révélées fausses.

```sather
   verdict(score : INT) : STR is
      if score >= 8 then
         return "Cast";
      elsif score >= 5 then
         return "Recalled";
      else
         return "Thank you";
      end;
   end;
```

L'ordre compte. Un score de `9` est attrapé par la première question et n'atteint jamais la seconde, même si `9 >= 5` est aussi vrai. Écrire les tests dans le mauvais ordre est la façon habituelle de se tromper.

Ça s'écrit `elsif`, pas `elseif`, et pas `else if`.

## Omets le `else`

On peut omettre `else` lorsqu'il n'y a rien à faire dans ce cas.

```sather
   if late then
      apologise;
   end;
```

Une routine qui doit renvoyer quelque chose a besoin que chaque chemin renvoie une valeur, donc dans cet exercice, chaque `if` conserve son `else`.
