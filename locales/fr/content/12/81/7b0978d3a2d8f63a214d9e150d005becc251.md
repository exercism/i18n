# Utilise `||` plutôt qu'un _if-else_

Pour changer une valeur lorsqu'elle vaut `nil` ou toute autre valeur _falsy_, utilise l'opérateur `||` plutôt qu'une instruction _if-else_.
C'est plus idiomatique et plus concis, et c'est aussi plus performant.

L'opérateur `||` renvoie la valeur à sa gauche si elle est _truthy_ ; sinon, il renvoie la valeur à sa droite.

Par exemple :

```crystal
# Rather than:
value.nil? ? "default" : value

# Consider:
value || "default"
```
