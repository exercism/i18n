# À propos

On peut parcourir [concept:csharp/enumerables]() à l'aide d'une boucle [`foreach`][foreach-statement] :

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // Output the vowel
    System.Console.Write(vowel);
}

// => aeiou
```

Une boucle `foreach` se compose de trois parties :

1. La déclaration : on définit la variable qui contiendra la valeur itérée. Cette variable ne peut être utilisée qu'à l'intérieur de la boucle.
2. L'objet itérable : l'objet que l'on peut parcourir.
3. Le corps de la boucle.

## Comparaison des boucles `for` et `foreach`

Cependant, de manière générale, une boucle `foreach` est préférable à une boucle `for` pour les raisons suivantes :

- Une boucle `foreach` garantit que _toutes_ les valeurs seront parcourues. Avec une boucle `for`, il est facile d'oublier des éléments, par exemple à cause d'une erreur de décalage.
- Une boucle `foreach` est plus _déclarative_ : le code communique _ce que_ tu veux qu'elle fasse, au lieu d'une boucle `for` qui communique _comment_ tu veux le faire.
- Une boucle `foreach` est à toute épreuve, alors qu'avec les boucles `for`, il est facile de commettre une erreur de décalage.
- Une boucle `foreach` fonctionne avec tous les types de collections, y compris ceux qui ne prennent pas en charge l'utilisation d'un indexeur pour accéder aux éléments.

Pour garantir qu'une boucle `foreach` parcourt _toutes_ les valeurs, le compilateur interdit la modification d'une collection à l'intérieur d'une boucle `foreach` :

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // This would result in a compiler error
    // vowel = 'Y';
}
```

Une boucle `for` présente toutefois quelques avantages par rapport à une boucle `foreach` :

- On peut commencer ou s'arrêter à l'indice que l'on veut.
- On peut utiliser n'importe quelle condition d'arrêt (booléenne).
- On peut sauter des éléments en personnalisant l'incrémentation de la variable de boucle.
- On peut parcourir les collections de la fin vers le début en décrémentant.
- On peut utiliser des boucles `for` dans des scénarios qui n'impliquent pas de collections.
