# Introduction

On suppose que tu connais la syntaxe JSON et les types de données.

jq fonctionne en faisant passer les données JSON entrantes à travers une _expression unique_ (écrite comme un _pipeline de filtres_) pour obtenir les données transformées souhaitées.

<!-- prettier-ignore -->
~~~~exercism/note
Le langage `jq` est implémenté par le _programme_ `jq`.
Ce programme fournit plusieurs options en ligne de commande pratiques pour contrôler la façon dont l'entrée est consommée et dont la sortie est présentée.

Dans les exemples ci-dessous, tu rencontreras :

- `-n` ou `--null-input`

    Normalement, on donne au programme `jq` un fichier à lire, ou bien on lui envoie des données sur son entrée.
    L'option `--null-input` permet de générer des données JSON sans aucune entrée.

- `-c` ou `--compact-output`

    Par défaut, `jq` affiche sa sortie de façon lisible.
    Il est extrêmement utile, pour un humain, de voir les données lorsqu'elles sont bien mises en forme.
    Cependant, ce n'est pas nécessaire pour les machines : l'option `--compact-output` supprime les espaces de mise en forme afin de réduire la taille du JSON obtenu.

- `-f filename` ou `--from-file filename`

    Lire le programme `jq` depuis `filename` au lieu de le fournir sur la ligne de commande.
    `sed` et `awk` utilisent tous les deux l'option `-f` dans le même but.
    Tu verras cette option utilisée dans les scripts de test des exercices d'entraînement.

Le reste de cette leçon portera sur le _langage_ `jq`.
~~~~

<!-- prettier-ignore-end -->

## Filtres et pipes

**Les filtres** sont aussi appelés **expressions**.

Un _filtre_ prend une entrée et produit une sortie.
Tout comme dans un shell Unix, on peut relier des _filtres_ avec un pipe `|` pour connecter la sortie d'un _filtre_ à l'entrée d'un autre.

## Le filtre identité : `.`

C'est le plus simple des _filtres_.
Il se contente de transmettre son entrée à sa sortie.

```sh
$ echo '[1, 2, 3]' | jq '.'
[
  1,
  2,
  3
]
```

## Tableaux

Voici une brève introduction à la manipulation des **tableaux**.
On abordera ce sujet plus en détail plus tard.

On accède aux éléments d'un _tableau_ avec des crochets, et les indices commencent à zéro.

```sh
$ echo '[10, 20, 30]' | jq '.[1]'
20
```

Un _filtre_ peut construire un _tableau_ en entourant une expression de `[` et `]`

- avec une liste d'éléments connue :

  ```sh
  jq -n '[1, 2, 3]'
  ```

- pour collecter un flux d'éléments : par exemple,
  `range` est une fonction qui produit un flux de nombres

  ```sh
  $ jq -n 'range(10; 70; 15)'
  10
  25
  40
  55
  ```

  Utiliser `[]` collecte les résultats de l'expression dans un tableau

  ```sh
  $ jq -c -n '[range(10; 70; 15)]'
  [10,25,40,55]
  ```

## La virgule est un opérateur

La _virgule_ n'est pas qu'une syntaxe qui sépare les éléments d'un _tableau_.
**La virgule** est un **opérateur** qui joint des flux.

Par exemple, `[1, 2, 3]` est un _filtre_ qui utilise le constructeur de _tableau_ `[]` pour collecter le résultat de la jointure des trois expressions `1`, `2` et `3`.

As-tu remarqué les points-virgules dans `range(10; 70; 15)` ci-dessus ?
Comme les _virgules_ ont un rôle précis dans le langage `jq`, les fonctions qui prennent plusieurs arguments utilisent des points-virgules pour séparer les arguments.

## Objets

Une brève introduction aux **objets**.

Comme dans de nombreux langages de programmation, on utilise des points pour accéder aux propriétés d'un _objet_

```sh
$ echo '{"foo": {"bar": "qux"}}' | jq '.foo.bar'
"qux"
```

<!-- prettier-ignore -->
~~~~exercism/note
On peut aussi utiliser des crochets pour les _objets_, mais il faut alors des guillemets pour les littéraux de chaîne.
C'est une méthode pour manipuler des clés contenant des espaces.

```sh
$ echo '{"foo bar": "qux"}' | jq '.["foo bar"]'
"qux"
```
~~~~

<!-- prettier-ignore-end -->

On peut construire un _objet_ avec `{}` et des paires `key: value`.
Les guillemets ne sont pas obligatoires autour des _clés_ qui sont des chaînes « simples ».

```sh
jq -n '{question: (6 * 9), answer: 42}'
```

produit

```none
{
  "question": 54,
  "answer": 42
}
```

Pour traiter la _clé_ comme une _expression_, il faut l'entourer de parenthèses (l'exemple qui suit produit lui aussi le même résultat que ci-dessus).

```sh
echo '[{"key":"question", "value":54}, {"key":"answer", "value":42}]' \
| jq '{(.[0].key): .[0].value, (.[1].key): .[1].value}'
```

## Pipelines

Par exemple, étant donné un fichier `file.json` contenant

```json
{
  "key1": "value1",
  "key2": [5, 15, 25]
}
```

Calculons la longueur du _tableau_ key2 :

```sh
$ jq '.key2 | length' file.json
3
```

On fait passer la sortie de l'expression `.key2` en entrée de `length`, qui produit sans surprise le nombre d'éléments du _tableau_.

## Les filtres peuvent ignorer leur entrée

Dans cet exemple, les données JSON d'entrée sont ignorées et n'ont aucun effet sur la sortie :

```sh
$ echo '{"answer": 42}' | jq '6 * 9'
54
```

## Les filtres peuvent produire des flux de données

Un _filtre_ peut produire plusieurs valeurs.
Par exemple, le _filtre_ `.[]` produit chaque élément d'un _tableau_ comme une valeur distincte :

```sh
$ jq -n -c '[1, 2, 3]'
[1,2,3]

$ jq -n -c '[1, 2, 3] | .[]'
1
2
3
```

En faisant passer la sortie d'un tel _filtre_ dans un autre, le 2e _filtre_ s'exécute **_pour chaque valeur_** :

```sh
$ jq -n -c '[1, 2, 3] | .[] | . * 2'
2
4
6
```

C'est comme une itération implicite.
Une fois que tu maîtrises cette technique, tu réalises que des _filtres_ `jq` très puissants peuvent être très concis.

## Parenthèses

**Les parenthèses** servent à regrouper des sous-expressions pour imposer l'ordre des opérations, comme dans d'autres langages.
En `jq`, leur nécessité peut sembler quelque peu surprenante.

Par exemple, imaginons que l'on veuille construire un _tableau_ de 2 éléments : la racine carrée de 9 ; et _e_ élevé à la puissance 1.
Les deux expressions individuelles sont `9 | sqrt` et `1 | exp`.
On s'attend à ce que la sortie soit le _tableau_ `[3, 2.7...]`

```jq
$ jq -n '[ 9|sqrt, 1|exp ]'
[
  20.085536923187668,
  2.718281828459045
]
```

Pourquoi n'a-t-on pas obtenu le résultat escompté ? `jq` l'interprète ainsi :

```jq
[ ((9|sqrt), 1) | exp ]
```

`jq` construit un flux de deux éléments (`3` et `1`), qui sont donnés chacun à `exp`.

Il faut s'assurer que `exp` ne prend qu'un seul nombre en entrée.
Autrement dit, il faut imposer que le pipe soit évalué avant la virgule.

```jq
$ jq -n '[ 9|sqrt, (1|exp) ]'
[
  3,
  2.718281828459045
]
```

## Fonctions et opérateurs

Sans entrer dans les détails (les fonctions feront l'objet d'un autre exercice), voici quelques fonctions intégrées utiles :

- `length`

  Prend un tableau en entrée et produit le nombre d'éléments de ce tableau.

  ```sh
  $ jq -n '[10, 20, 30, 40] | length'
  4
  ```

- `+`

  Cet opérateur fait des choses différentes selon le type de ses opérandes :
  il additionne des nombres,
  il concatène des chaînes de caractères,
  il ajoute des éléments à des tableaux,
  il fusionne des objets.

  ```sh
  $ jq -c -n '
      3 + 4,
      "foo" + "bar",
      ["a", "b"] + ["c"],
      {"m": 10} + {"n": 20}
  '
  7
  "foobar"
  ["a","b","c"]
  {"m":10,"n":20}
  ```

  `add` est une fonction qui prend un tableau et renvoie un élément obtenu en additionnant tous les éléments selon les règles de `+`.
  `[1, 2, 3] | add` produit `6`.

- `map`

  Prend un tableau en entrée et un filtre en argument, et produit un tableau où le filtre est appliqué à chaque élément

  ```sh
  $ jq -c -n '[10, 20, 30, 40] | map(. / 5)'
  [2,4,6,8]
  ```

- `select`

  Prend une entrée _quelconque_ et un filtre en argument :
  - si le filtre appliqué à l'argument donne une valeur _vraie_, renvoie l'entrée inchangée
  - sinon, ne renvoie _rien_ (pas la valeur `null`, vraiment aucune sortie)

  Par exemple, étant donné des nombres, sélectionne ceux qui sont divisibles par 3

  ```sh
  $ jq -n 'range(10) | select(. % 3 == 0)'
  0
  3
  6
  9
  ```

  Rappelle-toi que `range` produit un _flux_ de nombres.
  `select` est appelé une fois pour chaque nombre.
  Seuls les nombres qui « passent » l'expression sont produits.

  Tu as souvent besoin de sélectionner des éléments d'un tableau.
  Il y a plusieurs façons de le faire.

  Avec l'entrée `["Anne", "Bob", "Cathy", "Dave"]`, sélectionne les prénoms de longueur 4.
  - utilise `map` et `select` ensemble

    ```jq
    map(select(length == 4))
    ```

  - éclate le tableau en éléments, applique `select` sur ce flux, puis collecte les résultats

    ```jq
    [ .[] | select(length == 4) ]
    ```
