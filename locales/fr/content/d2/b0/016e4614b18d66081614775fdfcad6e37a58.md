# Indices

## Général

- Essaie de stocker le backend et les compteurs ensemble dans le type opaque.

- Pour appeler une fonction stockée dans un champ d'un enregistrement, utilise des parenthèses : `(backend.read!)(backend.state, max_bytes)`.

- Fais attention à `?` : renvoyer immédiatement en cas d'erreur ferait perdre le wrapper mis à jour et son compteur d'opérations.
