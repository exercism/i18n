# Introduction

## Les entiers

Les entiers sont des nombres entiers qui appartiennent à l'ensemble `{..., -2, -1, 0, 1, 2, ...}`.
Les valeurs maximale et minimale d'un entier dépendent du système sur lequel PHP s'exécute.
En général, sur la plupart des systèmes modernes, un entier est une valeur de 64 bits, ce qui signifie qu'il peut représenter `-9_223_372_036_854_775_808` jusqu'à `9_223_372_036_854_775_807` inclus.

```php
<?php

$a = 1234;
$a = 1_234_567;
```

On peut écrire des valeurs littérales entières dans une base autre que 10 en utilisant un préfixe de base :

```php
<?php

$a = 0123; // octal number (equivalent to 83 decimal)
$a = 0o123; // octal number (as of PHP 8.1.0)
$a = 0x1A; // hexadecimal number (equivalent to 26 decimal)
$a = 0b11111111; // binary number (equivalent to 255 decimal)
```

> Tiré de la [documentation][syntax] de PHP

## Les nombres à virgule flottante

Les nombres à virgule flottante sont utilisés en PHP pour représenter un sous-ensemble des nombres réels.
Ils commencent par un ou plusieurs chiffres séparés par un séparateur décimal.

```php
<?php

$a = 1.234; 
$b = 1.2e3; 
$c = 7E-10;
$d = 1_234.567; // as of PHP 7.4.0
```

### Pièges courants

Tous les nombres et toutes les opérations arithmétiques ne peuvent pas être effectués avec des nombres à virgule flottante.
Utiliser des nombres à virgule flottante pour représenter des dollars et des cents peut entraîner des erreurs d'arrondi.

```php
<?php

$result = 0.1 + 0.2; // => 0.30000000000000004
```

## Les opérateurs arithmétiques

PHP fournit un certain nombre d'opérateurs pour effectuer des opérations arithmétiques. PHP suit l'ordre des opérations mathématiques standard pour ses opérateurs arithmétiques. Les opérateurs fournis par PHP sont :

* Identité (+)
* Négation (-)
* Addition (+)
* Soustraction (-)
* Multiplication (*)
* Division (/)
* Modulo (%)
* Exponentiation (**)

```php
$moles = +'10';
$aLotOfMoles = 6.022 * 10**23 * $moles;
```
