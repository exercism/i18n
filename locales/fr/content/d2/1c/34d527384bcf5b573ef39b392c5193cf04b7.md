# Indices

## Général

- La documentation du paquet `Random` se trouve [ici][random-module]

## 1. Commence par la fin

- Utilise la fonction [`Random.constant`][random-constant]

## 2. On n'attrape pas les mouches avec du vinaigre

- Utilise la fonction [`Random.uniform`][random-uniform] pour générer les trésors
- Utilise la fonction [`Random.map`][random-map] pour envelopper le trésor

## 3. Explore les branches

- Utilise la fonction [`Random.int`][random-int] pour générer une valeur entre 2 et 4
- Tu peux accéder à cette valeur pour créer une `Branch` avec la fonction [`Random.andThen`][random-andThen]
- Utilise la fonction [`Random.list`][random-list] pour générer les branches
- Utilise la fonction [`Random.map`][random-map] pour envelopper les branches

## 4. Des labyrinthes étonnants

- Utilise la fonction [`Random.weighted`][random-weighted] pour générer une distribution inégale des résultats
- Utilise la fonction [`Random.lazy`][random-lazy] pour utiliser un générateur de façon récursive
- Pour en savoir plus sur la définition de structures de données récursives, c'est [ici][bad-recursion]
- Si tu finis par définir un générateur imbriqué `Generator (Generator Maze)`, tu peux utiliser [`Random.andThen`][random-andThen] avec la fonction `identity` pour l'aplatir

## 5. On doit aller plus loin

- Utilise la fonction [`Random.uniform`][random-uniform] pour générer les culs-de-sac ou les salles à la profondeur `0`
- Si tu finis par définir un générateur imbriqué `Generator (Generator Maze)`, tu peux utiliser [`Random.andThen`][random-andThen] avec la fonction `identity` pour l'aplatir
- Utilise la fonction [`Random.lazy`][random-lazy] pour utiliser un générateur de façon récursive
- Pour en savoir plus sur la définition de structures de données récursives, c'est [ici][bad-recursion]
