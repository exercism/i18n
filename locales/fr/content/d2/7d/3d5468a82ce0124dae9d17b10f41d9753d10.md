# Introduction

## Modules

Le code Gleam est organisé en modules, et chaque fichier correspond à un module Gleam.

Jusqu'à présent, on a écrit des fonctions avec la syntaxe `pub fn`, qui définit une fonction accessible publiquement depuis les autres modules. Les fonctions définies avec `fn` sont privées : elles ne sont visibles que dans le module où elles sont définies et ne peuvent pas être utilisées par d'autres modules.

```gleam
// This function is public
pub fn add(x, y) {
  x + y
}

// This function is private
fn subtract(x, y) {
  x - y
}
```

Les modules Gleam portent un nom, qui est basé sur le chemin de leur fichier dans le répertoire `src` ou `test`.

Par exemple, un module défini dans `src\geometry\rectangle.gleam` (sous Windows) ou `src/geometry/rectangle.gleam` (sous les systèmes de type UNIX) s'appellerait `geometry/rectangle`.

## Importe des fonctions depuis d'autres modules

On accède aux fonctions définies dans d'autres modules au moyen d'imports.
Quand on importe un module, toutes les fonctions qu'il expose deviennent accessibles.
Mais la façon d'y accéder varie selon la manière dont le module est importé.

Les imports qualifiés sont le comportement par défaut : pour accéder à une fonction d'un tel module (par exemple la fonction `map` du module `gleam/list`), on fait précéder son nom de celui du module (`list.map`).

```gleam
// Import the int module
import gleam/int

pub fn run(x: Int) -> String {
  // Use the to_string function from the int module
  int.to_string(x)
}
```

Par défaut, le nom utilisé pour désigner un module est la dernière partie de son nom, ici `int`, mais on peut le changer avec le mot-clé `as`.

```gleam
// Import the int module and refer to it as i
import gleam/int as i

pub fn run(x: Int) -> String {
  i.to_string(x)
}
```

Les imports non qualifiés permettent d'accéder directement aux fonctions exposées par le module, sans avoir à les préfixer.

```gleam
// Import the to_string function from the int module
import gleam/int.{to_string}

pub fn run(x: Int) -> String {
  to_string(x)
}
```

On préfère les imports qualifiés, car ils montrent plus clairement au lecteur d'où vient une fonction, et ils évitent les conflits de noms.


## Bibliothèque standard

Gleam dispose d'une bibliothèque standard riche et bien documentée. La documentation est disponible en ligne sur [hexdocs.pm/gleam_stdlib][docs]. Garde ce lien quelque part : tu l'utiliseras beaucoup !

La plupart des types de données intégrés ont un module correspondant qui propose des fonctions pour manipuler ce type de données, par exemple le module `gleam/int` pour les entiers, le module `gleam/string` pour les _strings_, le module `gleam/list` pour les tableaux, et ainsi de suite.

[docs]: https://hexdocs.pm/gleam_stdlib/
