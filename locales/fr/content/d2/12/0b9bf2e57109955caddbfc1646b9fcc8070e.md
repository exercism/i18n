# Instructions

Ton objectif est de convertir un nombre compris entre 1 et 31 en une séquence d'actions dans la poignée de main secrète.

On choisit la séquence d'actions en regardant les cinq chiffres les plus à droite du nombre, une fois converti en binaire.
Commence par le chiffre le plus à droite et va vers la gauche.

Les actions pour chaque position sont :

```plaintext
00001 = wink
00010 = double blink
00100 = close your eyes
01000 = jump
10000 = Reverse the order of the operations in the secret handshake.
```

Prenons le nombre `9` comme exemple :

- 9 en binaire s'écrit `1001`.
- Le chiffre le plus à droite est 1, donc la première action est `wink`.
- En allant vers la gauche, le chiffre suivant est 0, donc pas de double blink.
- En allant encore vers la gauche, le chiffre suivant est 0, donc tu gardes les yeux ouverts.
- En allant encore vers la gauche, le chiffre suivant est 1, donc tu sautes.

C'était le dernier chiffre, donc le code final est :

```plaintext
wink, jump
```

Avec le nombre 26, qui vaut `11010` en binaire, on obtient les actions suivantes :

- double blink
- jump
- inverser les actions

La poignée de main secrète pour 26 est donc :

```plaintext
jump, double blink
```
