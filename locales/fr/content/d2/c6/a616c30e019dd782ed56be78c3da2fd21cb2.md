# Opérateur ternaire

L'opérateur ternaire offre une syntaxe alternative pour effectuer une comparaison `if..else..` et renvoyer une valeur.

## Syntaxe

PHP fournit une instruction `if` qui permet d'évaluer une action en fonction de la « véracité » d'une condition.

```php
if ($condition) {
  $value = 1;
} else {
  $value = 2
}
```

L'opérateur ternaire peut aussi représenter la même opération :

```php
$value = $condition
  ? 1  // True branch
  : 2; // False branch
```

La syntaxe de comparaison est concise, représentée par `(condition) ? (evaluate if true) : (evaluate if false);`.

## Avantages

L'avantage évident de l'opérateur ternaire est la concision : l'expression conditionnelle s'écrit plus court qu'une instruction `if..else..`. Mais il y en a plusieurs autres :

- C'est une expression que l'on peut utiliser à l'intérieur d'une autre expression.
- Il facilite l'évaluation paresseuse de chaque branche.

  ```php
  function expensiveCalculation(): int
  {
    // An expensive calculation is performed
    $answerToEverything = 42;
    return $answerToEverything;
  }

  $needExactAnswer = false;
  $estimatedAnswer = 40;
  $answer = $needExactAnswer ? expensiveCalculation() : $estimatedAnswer;
  ```

  Dans cet exemple, si la réponse exacte n'est pas nécessaire, le calcul coûteux n'est pas exécuté.

## Inconvénients

Les opérateurs ternaires présentent plusieurs inconvénients, ce qui invite à réfléchir avant de les utiliser :

- Un opérateur ternaire peut être plus difficile à lire, car il repose sur l'interprétation de symboles plutôt que sur l'emploi de mots-clés.
- Un opérateur ternaire peut introduire des bugs sans qu'on le veuille, car en PHP il est associatif à gauche, contrairement à la plupart des langages modernes (par exemple C, Java, JavaScript).
- L'expression évaluée dans la branche vraie ou dans la branche fausse doit renvoyer une valeur.

## Encore plus court

La syntaxe du ternaire peut encore être raccourcie en `(condition) ?: (evaluate if falsey)`.
On peut par exemple s'en servir pour fournir une valeur de repli dans une expression :

```php
$fruit = null;
eat($fruit ?: 'apple');
```

Ceci est aussi parfois appelé l'_Elvis operator_ (`?:`)
