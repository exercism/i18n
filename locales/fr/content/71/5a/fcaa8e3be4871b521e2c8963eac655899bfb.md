# Indices

## Général

- `<dlist>` se trouve dans [`dlists`][dlists] ; les mots _push_ et _pop_ sont dans
  [`deques`][deques].
- `MEMO:` se trouve dans [`memoize`][memoize].
- Les variables locales (`::` et `:>`) gardent le corps du BFS lisible ; le prédicat
  voit les mêmes variables locales que le corps.

## 1. Vide la file des marées

- Commence par `<dlist>`, `[ push-back ] each` pour la remplir, puis vide-la avec une
  boucle `until` (prédicat `[ deque-empty? ]`) : extrais l'élément de tête dans un
  `V{ } clone`, en le convertissant en tableau à la fin avec `>array`.

## 2. Criques accessibles

- Schéma : `HS{ } clone` pour `visited`, `<dlist>` pour `frontier`, marque `start`
  comme visité et empile-le sur la frontière ; ensuite, boucle jusqu'à ce que la
  frontière soit vide : extrais l'élément de tête, cherche ses voisins dans la carte
  avec `at`, et pour chaque voisin non encore vu, ajoute-le à `visited` et fais un
  _push-back_ sur la frontière.

## 3. Nombre de sauts

- Même forme que la tâche 2, mais la deque contient des paires `{ cove distance }`.
  Quand tu extrais une paire dont la crique correspond à l'objectif, note la distance
  comme réponse et arrête-toi. Utilise une variable locale modifiable
  (`f :> answer!`) et fais dépendre la boucle `until` de
  `frontier deque-empty? answer or`.

## 4. Quantité d'or

- Une seule déclaration : `MEMO: gold-count ( cove -- n ) gold-distribution at 0 or ;`.
  `MEMO:` remplace le `:` initial ; tout le reste est une définition de mot
  normale. `at` renvoie `f` quand la clé est absente ; `0 or` substitue zéro.

## 5. Itinéraire du trésor

- `coves-reachable` renvoie un hash-set ; `members` (dans `sets`) le transforme en
  séquence. Construis un tableau de paires `{ gold cove }` avec
  `[ [ gold-count ] keep 2array ] map`, puis `sort` le tableau (qui ordonne les
  paires par leur premier élément), et `last second` sélectionne la crique de la
  paire la plus riche en or.
