# Introduction

La plupart des mots de séquence de Factor renvoient de *nouvelles* séquences et laissent leurs entrées intactes, mais les tableaux et les vecteurs prennent aussi en charge la **mutation sur place** lorsqu’on veut enregistrer un état qui évolue au fil du temps.

`set-nth` et `change-nth` modifient une case sur place, et fonctionnent aussi bien sur un tableau que sur un vecteur. `<array>` construit un tableau modifiable de longueur fixe ; les littéraux `V{ }`, `<vector>`, `push` et `pop` forment l’ensemble réservé aux vecteurs, car les tableaux ne peuvent pas changer de longueur. `clone` duplique la séquence pour que les mutations suivantes ne se répercutent pas sur l’original.

```factor
USING: arrays kernel sequences ;

5 0 <array>                 ! a fresh array { 0 0 0 0 0 }
dup 7 2 swap set-nth        ! { 0 0 7 0 0 } — set position 2 to 7
.

V{ } clone                  ! a fresh, empty vector
"alice" over push           ! V{ "alice" }
"bob" over push             ! V{ "alice" "bob" }
dup pop .                   ! "bob"
.                           ! V{ "alice" }
```
