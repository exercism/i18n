# Introduction

En Gleam, les _strings_ sont du texte immuable entouré de guillemets doubles, qui peut contenir des caractères unicode et s'écrire sur plusieurs lignes.

```gleam
let greeting = "Hello, Joe! 📞"

let multi_line_string = "one
two
three"
```

On peut concaténer des _strings_ avec l'opérateur `<>` :

```gleam
let name = "Mike"
"Hello, " <> name <> "!"
// -> "Hello, Mike!"
```

Le module [`gleam/string`][stdlib] de la bibliothèque standard fournit des fonctions pour manipuler les _strings_.

Les expressions `case` permettent de faire du filtrage par motif sur des _strings_ :

```gleam
pub fn on_an_excellent_adventure(name: String) -> Bool {
  case name {
    "Bill" -> True
    "Ted" -> True
    _ -> False
  }
}
```

Si tu veux filtrer sur le début d'un _string_ et affecter le reste à une variable, tu peux utiliser un motif avec l'opérateur `<>` :

```gleam
pub fn profession(name: String) -> String {
  case name {
    "Dr " <> rest -> rest <> " is a doctor"
    _ -> "I'm not sure what " <> name <> " does"
  }
}
```

[stdlib]: https://hexdocs.pm/gleam_stdlib/gleam/string.html
