# Instructions

Dans cet exercice, tu vas gérer un système d'inventaire.

L'inventaire doit être organisé par nom d'article et garder la trace du nombre d'articles disponibles.

Tu devras gérer l'ajout d'articles à un inventaire.
Chaque fois qu'un article apparaît dans une liste donnée, sa quantité dans l'inventaire doit être augmentée de `1`.
Tu devras aussi gérer la suppression d'articles d'un inventaire en diminuant les quantités de `1` lorsque c'est demandé.

Enfin, tu devras implémenter une fonction qui renvoie toutes les paires clé-valeur d'un inventaire donné sous la forme d'une `list` de `tuples`.


## 1. Crée un inventaire à partir d'une liste

Implémente la fonction `create_inventory(<input list>)` qui crée un « inventaire » à partir d'une liste d'articles en entrée.
Elle doit renvoyer un `dict` contenant chaque nom d'article associé à sa quantité respective.

```python
>>> create_inventory(["coal", "wood", "wood", "diamond", "diamond", "diamond"])
{"coal":1, "wood":2, "diamond":3}
```

## 2. Ajoute des articles d'une liste à un dictionnaire existant

Implémente la fonction `add_items(<inventory dict>, <item list>)` qui ajoute une liste d'articles à l'inventaire passé en argument :

```python
>>> add_items({"coal":1}, ["wood", "iron", "coal", "wood"])
{"coal":2, "wood":2, "iron":1}
```

## 3. Décrémente les articles de l'inventaire

Implémente la fonction `decrement_items(<inventory dict>, <items list>)` qui prend une `list` d'articles.
La fonction doit retirer `1` au compteur d'un article chaque fois que cet article apparaît dans la `list` :

```python
>>> decrement_items({"coal":3, "diamond":1, "iron":5}, ["diamond", "coal", "iron", "iron"])
{"coal":2, "diamond":0, "iron":3}
```

Les compteurs d'articles dans l'inventaire ne doivent pas pouvoir descendre en dessous de 0.
 Si le nombre de fois qu'un article apparaît dans la `list` d'entrée dépasse le compteur disponible, la quantité indiquée pour cet article doit rester à 0.
 Les demandes de retrait supplémentaires doivent être ignorées une fois que le compteur atteint zéro.

```python
>>> decrement_items({"coal":2, "wood":1, "diamond":2}, ["coal", "coal", "wood", "wood", "diamond"])
{"coal":0, "wood":0, "diamond":1}
```

## 4. Supprime entièrement une entrée de l'inventaire

Implémente la fonction `remove_item(<inventory dict>, <item>)` qui supprime entièrement un article et son compteur d'un inventaire :

```python
>>> remove_item({"coal":2, "wood":1, "diamond":2}, "coal")
{"wood":1, "diamond":2}
```

Si l'article n'est pas trouvé dans l'inventaire, la fonction doit renvoyer l'inventaire d'origine inchangé.

```python
>>> remove_item({"coal":2, "wood":1, "diamond":2}, "gold")
{"coal":2, "wood":1, "diamond":2}
```

## 5. Renvoie tout le contenu de l'inventaire

Implémente la fonction `list_inventory(<inventory dict>)` qui prend un inventaire et renvoie une liste de `tuples` `(item, quantity)`.
La liste ne doit inclure que les articles _disponibles_ (_dont la quantité est supérieure à zéro_) :

```python
>>> list_inventory({"coal":7, "wood":11, "diamond":2, "iron":7, "silver":0})
[('coal', 7), ('diamond', 2), ('iron', 7), ('wood', 11)]
```
