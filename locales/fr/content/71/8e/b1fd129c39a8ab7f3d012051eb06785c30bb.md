# Instructions

Ton association de quartier t'a demandé d'implémenter une application simple de registre pour gérer les inscriptions au jardin communautaire. La structure `Plot` t'a déjà été fournie.

## 1. Ouvre le jardin

Implémente la fonction `CommunityGarden.start/1` ; elle doit recevoir une liste de mots-clés d'options facultatives à transmettre au _processus agent_. L'état initial du jardin doit être initialisé pour représenter une collection vide de parcelles. Elle doit renvoyer un tuple `:ok` avec le pid du jardin.

```elixir
{:ok, pid} = CommunityGarden.start()
# => {:ok, #PID<0.112.0>}
```

## 2. Liste les inscriptions

Implémente la fonction `CommunityGarden.list_registrations/1`. Elle doit recevoir le `pid` du jardin communautaire. Elle doit renvoyer la liste des parcelles enregistrées.

```elixir
CommunityGarden.list_registrations(pid)
# => []
```

> À ce stade, on n'a pas encore ajouté la possibilité d'enregistrer une parcelle, donc cette liste doit être vide

## 3. Enregistre des parcelles au nom d'une personne

Implémente la fonction `CommunityGarden.register/2`. Elle doit recevoir le `pid` du jardin communautaire et un nom auquel enregistrer la parcelle. En cas de succès, elle doit renvoyer la structure `Plot` avec l'identifiant de la parcelle et la personne à qui elle est enregistrée.

Les identifiants doivent être incrémentaux et uniques. Tu peux conserver un compteur d'identifiants dans l'état de l'agent.

```elixir
CommunityGarden.register(pid, "Emma Balan")
# => %Plot{plot_id: 1, registered_to: "Emma Balan"}
CommunityGarden.list_registrations(pid)
# => [%Plot{plot_id: 1, registered_to: "Emma Balan"}]
```

## 4. Libère des parcelles

Implémente la fonction `CommunityGarden.release/2`. Elle doit recevoir le `pid` et l'`id` de la parcelle à libérer. Elle doit renvoyer `:ok` en cas de succès. Quand une parcelle est libérée, son identifiant n'est pas réutilisé ; il sert uniquement d'identifiant unique.

```elixir
CommunityGarden.release(pid, 1)
# => :ok
CommunityGarden.list_registrations(pid)
# => []
```

## 5. Récupère une parcelle enregistrée

Implémente la fonction `CommunityGarden.get_registration/2`. Elle doit recevoir le `pid` et l'`id` de la parcelle à vérifier. Elle doit renvoyer la parcelle si elle est enregistrée, et `:not_found` si elle ne l'est pas.

```elixir
CommunityGarden.get_registration(pid, 1)
# => %Plot{plot_id: 1, registered_to: "Emma Balan"}
CommunityGarden.get_registration(pid, 7)
# => {:not_found, "plot is unregistered"}
```
