# Tests

## Exécute les tests

Quand tu te trouves dans le dossier d'un exercice, tu devrais voir deux sous-dossiers :

* `Sources/<Exercise>` contient ta solution à l'exercice
* `Tests/<Exercise>Tests` contient les tests à exécuter pour cet exercice

Si tu te trouves dans le bon dossier (c'est-à-dire celui qui contient `Sources` et `Tests`), tu peux exécuter les tests de cet exercice avec `swift test` :

```bash
$ pwd
/Users/johndoe/Code/exercism/swift/hello-world

$ ls
HELP.md  Package.swift  README.md  Sources  Tests

$ swift test
```

Quand un test passe, supprime `.enabled(if: RUNALL)` dans l'instruction `@Test` pour activer le test suivant ; tu peux aussi exécuter tous les tests en définissant la variable d'environnement `RUNALL` sur `true` sous Linux ou macOS :

```bash
$ export RUNALL=true
```

Ou, si tu utilises PowerShell sous Windows :

```powershell
set RUNALL=true
```

## Soumets ta solution

Pour soumettre une solution à Exercism, tu dois te trouver dans le dossier qui contient les dossiers `Sources` et `Tests`.

```bash
$ exercism submit 
```
