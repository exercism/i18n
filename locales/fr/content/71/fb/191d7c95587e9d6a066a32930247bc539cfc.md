# Introduction

## Les bases

Java est un langage à typage statique, ce qui signifie que le type d'une variable est connu au moment de la compilation.
Affecter une valeur à un nom s'appelle définir une variable.
Une variable se définit en spécifiant explicitement son type.

```java
int explicitVar = 10;
```

La mise à jour de la valeur d'une variable se fait à l'aide de l'opérateur `=`.
Ici, `=` ne représente pas l'égalité mathématique.
Il affecte simplement une valeur à une variable.
Une fois définie, le type d'une variable ne peut plus jamais changer.

```java
int count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning a different type
// count = false;
```

Java est un [langage orienté objet][object-oriented-programming] et exige que toutes les fonctions soient définies dans une _classe_.
Le mot-clé `class` sert à définir une classe.

```java
class Calculator {
    // ...
}
```

Une fonction au sein d'une classe s'appelle une _méthode_.
Chaque méthode peut prendre zéro ou plusieurs paramètres.
Tous les paramètres doivent être typés explicitement ; il n'y a pas d'inférence de type pour les paramètres.
De même, le type de retour doit lui aussi être explicite.
Les valeurs sont renvoyées par les méthodes à l'aide du mot-clé `return`.
Pour qu'une méthode puisse être appelée par d'autres classes, il faut ajouter le modificateur d'accès `public`.

```java
class Calculator {
    public int add(int x, int y) {
        return x + y;
    }
}
```

Appeler une méthode se fait en précisant le nom de sa classe et de la méthode, et en passant des arguments pour chacun des paramètres de la méthode.

```java
int sum = new Calculator().add(1, 2);  // here the  "add" method has been called to perform the task of addition
```

En Java, la portée est définie entre les caractères `{` et `}`.

Java prend en charge deux types de commentaires.
Les commentaires sur une seule ligne sont précédés de `//` et les commentaires multilignes s'insèrent entre `/*` et `*/`.

[object-oriented-programming]: https://docs.oracle.com/javase/tutorial/java/javaOO/index.html
