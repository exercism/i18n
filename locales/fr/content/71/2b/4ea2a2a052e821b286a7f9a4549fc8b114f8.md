# Instructions

Dans cet exercice, tu vas implémenter les mécaniques d'un jeu de rôle.
Le personnage d'un joueur est représenté par le type suivant :

```elm
type alias Player =
    { name : Maybe String
    , level : Int
    , health : Int
    , mana : Maybe Int
    }
```

Dans ce jeu, les joueurs doivent atteindre le niveau 10 avant de débloquer une réserve de mana, afin de pouvoir commencer à lancer des sorts.
Tu vas travailler sur deux fonctionnalités de ce jeu : la mécanique de réanimation et la mécanique de lancement de sorts.

## 1. Présente-toi

Écris le contenu de la fonction `introduce`.
Les joueurs furtifs peuvent cacher leur nom et seront présentés comme `"Mighty Magician"`.
Sinon, utilise simplement ton nom pour te présenter.

```elm
introduce { name = Nothing, level = 2, health = 8, mana = Nothing }
    --> "Mighty Magician"

introduce { name = Just "Merlin", level = 2, health = 8, mana = Nothing }
    --> "Merlin"
```

## 2. Implémente la mécanique de réanimation

La fonction `revive` doit vérifier que le personnage du joueur est bien mort (ses points de vie sont tombés à 0).
Si c'est le cas, elle doit renvoyer une nouvelle instance de `Player` avec 100 points de vie.
Sinon, si le personnage du joueur n'est pas mort, la fonction `revive` renvoie `Nothing`.

Si le niveau du joueur est supérieur ou égal à 10, il doit aussi être réanimé avec 100 points de mana.
Si le niveau du joueur est inférieur à 10, son mana doit être `Nothing`.
La fonction `revive` doit préserver le niveau du joueur.

```elm
deadPlayer = { name = Nothing, level = 2, health = 0, mana = Nothing }

revive deadPlayer
    --> Just { name = Nothing, level = 2, health = 100, mana = Nothing }
```

Si la méthode `revive` est appelée sur un joueur dont les points de vie sont supérieurs ou égaux à 1, alors la fonction doit renvoyer `Nothing`.

```elm
alivePlayer = { name = Nothing, level = 2, health = 42, mana = Nothing }

revive alivePlayer
    --> Nothing
```

## 3. Implémente la mécanique de lancement de sorts

La fonction `castSpell` prend comme arguments un `Int` indiquant combien de mana le sort coûte, ainsi qu'un `Player`.
Elle renvoie le joueur mis à jour, ainsi que la quantité de dégâts que le sort lancé inflige.
Un sort lancé avec succès inflige des dégâts égaux à deux fois le coût en mana du sort.
Cependant, si le joueur n'a pas assez de mana, rien ne se passe : le joueur reste inchangé et aucun dégât n'est infligé.
Si le joueur n'a même pas de réserve de mana, tenter de lancer le sort doit diminuer ses points de vie du coût en mana du sort et n'inflige aucun dégât.

```elm
wizard = { name = Nothing, level = 18, health = 123, mana = Just 30 }

( updatedWizard, damage ) = castSpell 14 wizard

updatedWizard.mana --> Just 16
damage             --> 28
```
