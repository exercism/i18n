# Introduction

Les boucles permettent de répéter des blocs de code. Il existe trois types de boucles en Rust : la boucle `for`, qui permet de parcourir les éléments d'un itérateur ou d'une collection (techniquement, les valeurs de tout type qui implémente le trait `IntoIterator`), la boucle `while`, qui répète un bloc de code tant qu'une condition est remplie, et la boucle `loop`, qui répète indéfiniment du code jusqu'à ce qu'un `break` soit invoqué explicitement.
