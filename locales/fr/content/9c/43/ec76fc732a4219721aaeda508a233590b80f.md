# Introduction

En Factor, les tableaux sont le principal type de séquence à longueur fixe, et s'écrivent
`{ … }` : on peut modifier les éléments, mais pas la longueur. Les vocabulaires `arrays`
et `sequences` fournissent ensemble de petits constructeurs qui prennent des valeurs sur la
pile, ainsi que des opérations courantes pour concaténer, inverser et rechercher des éléments.

```factor
USING: arrays sequences ;

42 1array .                ! => { 42 }
"a" "b" "c" 3array .       ! => { "a" "b" "c" }
{ { 1 2 } { 3 4 } } concat .   ! => { 1 2 3 4 }
{ 1 2 3 } reverse .            ! => { 3 2 1 }
```
