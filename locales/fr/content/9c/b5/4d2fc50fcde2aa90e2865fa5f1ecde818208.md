# utilise la documentation de module

[comment]: # (Cette erreur est levée lorsque la soumission n'a pas de @moduledoc pour le module)

Il est recommandé d'avoir un attribut [`@moduledoc`](https://hexdocs.pm/elixir/writing-documentation.html#module-attributes) pour décrire l'intention du module.

- La documentation est un [citoyen de première classe](https://hexdocs.pm/elixir/writing-documentation.html) en Elixir : la documentation d'Elixir est conçue pour être facile à lire et à écrire.
- La syntaxe Markdown est prise en charge dans les attributs de documentation `@moduledoc` et `@doc`
