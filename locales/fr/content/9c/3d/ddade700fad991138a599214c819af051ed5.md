# Introduction

En Go, chaque variable possède une valeur.
Si tu déclares une variable sans lui affecter de valeur, elle prend la valeur zéro de son type.

Les types de base, notamment `bool`, les types numériques et `string`, possèdent chacun une valeur zéro fixe :

| Type                   | Valeur zéro |
| ---------------------- | ----------- |
| bool                   | `false`     |
| int, int8, int64, etc. | `0`         |
| float32, float64       | `0`         |
| complex64, complex128  | `0+0i`      |
| string                 | `""`        |

Les pointeurs, les fonctions, les interfaces, les _slices_, les _channels_ et les _maps_ ont pour valeur zéro `nil`.

Les tableaux et les _structs_ ne sont jamais `nil`, car ils contiennent directement les données, et non une référence vers celles-ci.
Chaque élément d'un tableau et chaque champ d'une _struct_ est initialisé à la valeur zéro de son propre type.
Par exemple, `var a [3]int` crée le tableau `[0, 0, 0]`.

## Déclare des valeurs zéro

Utilise `var` pour une déclaration :

```go
var myBool bool   // false
var mySlice []int // nil
```

Pour les _structs_, utilise un littéral composite `T{}` :

```go
type Person struct {
    Name string
    Age  int
}

myPerson := Person{} // Person{Name: "", Age: 0}
```
