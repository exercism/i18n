# Instructions

Ton ensemble à cordes donne un récital, et quelqu'un doit écrire le programme.

Les cinq tâches s'écrivent dans la classe `PROGRAMME_NOTES`.

## 1. Nomme le morceau et son compositeur

Mets d'abord le morceau, puis ` by `, puis le compositeur.

```sather
PROGRAMME_NOTES::full_title("Nocturne", "Chopin")
-- => "Nocturne by Chopin"
```

## 2. Mesure une ligne

L'imprimeur a besoin de savoir quelle longueur fait une ligne.

```sather
PROGRAMME_NOTES::title_length("Nocturne")
-- => 8
```

## 3. Les premières lettres

Étant donné un titre et un nombre, renvoie autant de lettres depuis le début.

```sather
PROGRAMME_NOTES::opening_letters("Nocturne", 3)
-- => "Noc"
```

## 4. Les dernières lettres

La même chose, en partant de la fin.

```sather
PROGRAMME_NOTES::closing_letters("Nocturne", 4)
-- => "urne"
```

## 5. Raccourcis un titre long

Les titres qui ne rentrent pas sont coupés à leurs six premières lettres, suivies de trois points.

```sather
PROGRAMME_NOTES::short_title("Nocturne in E flat")
-- => "Noctur..."
```
