# Instructions

Tu traces un sentier de randonnée à travers le bush. Les distances et les observations se présentent toutes deux sous forme de séquences, ce sont donc des itérateurs.

Tous les quatre vont dans la classe `BUSH_WALK`. Chacun d'eux est un itérateur, donc chaque nom se termine par `!`.

## 1. Les marqueurs

`markers!` prend un espacement en mètres et un nombre, puis renvoie la distance de chaque marqueur depuis le départ.

```sather
loop
   #OUT + BUSH_WALK::markers!(100, 3) + " ";
end;
-- 100 200 300
```

Avec un nombre égal à zéro, il ne renvoie rien du tout.

## 2. Jusqu'à la fin du sentier

`until_end!` prend les observations le long du sentier et les renvoie une par une, en s'arrêtant dès qu'il rencontre `"end"`. Le `"end"` lui-même n'est pas renvoyé.

```sather
loop
   #OUT + BUSH_WALK::until_end!(|"gum", "wattle", "end", "banksia"|) + " ";
end;
-- gum wattle
```

S'il n'y a pas de `"end"`, il renvoie tout.

## 3. Seulement les oiseaux

`birds!` prend les observations et ne renvoie que celles qui commencent par une majuscule, car c'est ainsi que ce relevé note les oiseaux.

```sather
loop
   #OUT + BUSH_WALK::birds!(|"gum", "Emu", "wattle", "Galah"|) + " ";
end;
-- Emu Galah
```

## 4. Numérotées

`numbered!` prend les observations et renvoie chacune d'elles précédée de sa position, en commençant à un.

```sather
loop
   #OUT + BUSH_WALK::numbered!(|"gum", "Emu"|) + " ";
end;
-- 1. gum 2. Emu
```
