# À propos

[Clojure](http://clojure.org) est un langage de programmation dynamique qui cible la machine virtuelle Java (JVM). 
Conçu comme un langage généraliste, Clojure allie l'accessibilité d'un langage de script à une infrastructure robuste pour la programmation multithread.

Clojure est avant tout un langage de programmation fonctionnel et propose un riche ensemble de [structures de données](http://clojure.org/data_structures) immuables et persistantes.

Clojure est open source, et les informations sur la contribution au langage [se trouvent ici](http://clojure.org/contributing).

Rich Hickey, le créateur de Clojure, voulait un Lisp moderne pour la programmation fonctionnelle, symbiotique avec la plateforme Java établie et conçu pour la concurrence ; c'est ainsi que Clojure est né.

Voici quelques citations qui illustrent bien les objectifs de Clojure :

* _Une bonne conception ne consiste pas à élaborer de grands plans, mais à démonter les choses._
* _Programmer, ce n'est pas taper du code... c'est réfléchir._
