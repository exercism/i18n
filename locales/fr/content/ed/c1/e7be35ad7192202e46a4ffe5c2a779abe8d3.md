# Introduction

Tout le code Common Lisp est constitué de S-expressions (expressions symboliques). On les appelle plus simplement des _sexprs_. Chaque _sexpr_ est soit un atome, soit un cons. Quand les S-expressions sont évaluées, elles renvoient automatiquement une valeur qui prend la place de l'expression. Quand on écrit ses propres fonctions (avec `defun`), la dernière valeur du corps du `defun` est automatiquement renvoyée :

```lisp
;; Defining a new function
(defun gimme-foo () 'foo)
;; Calling the function as an S-Expression
(gimme-foo) ; => FOO
```
