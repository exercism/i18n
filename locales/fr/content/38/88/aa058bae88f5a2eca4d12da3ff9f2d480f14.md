# À propos

Swift fournit un type intégré appelé [`Bool`][bools] pour représenter les valeurs de vérité : `true` et `false`.

## Opérateurs logiques

Swift fournit trois [opérateurs logiques][logical-operators] (`!`, `&&` et `||`) pour combiner et évaluer des expressions booléennes.

### Et logique (`&&`)

L'[opérateur _et_][and] (`&&`) renvoie `true` uniquement si les deux opérandes sont `true`.
Si l'un des opérandes est `false`, il renvoie `false`.
On place une expression ou une valeur booléenne de chaque côté du symbole `&&` :

```swift
true && true  // true
true && false // false
```

### Ou logique (`||`)

L'[opérateur _ou_][or] (`||`) renvoie `true` si **au moins un** des opérandes est `true`.
Il ne renvoie `false` que lorsque les deux opérandes sont `false`.
On place une expression ou une valeur booléenne de chaque côté du symbole `||` :

```swift
true || true   // true
true || false  // true
false || false // false
```

### Non logique (`!`)

L'[opérateur _non_][not] (`!`) inverse une valeur booléenne.
Il renvoie `true` si la valeur est `false`, et `false` si la valeur est `true`.
On place l'opérateur `!` immédiatement avant la valeur ou l'expression :

```swift
!true  // false
!false // true
```

## Utilise des parenthèses (`()`)

On peut utiliser des [parenthèses][explicit-parentheses] pour regrouper des expressions et contrôler l'ordre d'évaluation.
En Swift, les expressions entre parenthèses sont évaluées en premier :

```swift
true && false && false || true   // true
true && false && (false || true) // false
```

Le regroupement avec des parenthèses détermine aussi la façon dont l'opérateur _non_ s'applique aux expressions complexes :

```swift
!true && false   // false (evaluates (!true) first, then false && false)
!(true && false) // true  (evaluates (true && false) first to false, then !false)
```

~~~~exercism/note
Utilise des parenthèses quand tu as besoin de clarifier l'ordre d'évaluation ou de rendre des conditions complexes plus lisibles.
Évite d'ajouter des parenthèses inutiles quand la priorité par défaut est déjà claire.
~~~~
