# Liste de langages

## Histoire

Cette histoire facilite l'exploration des [listes][types-list] dans un langage.

Le principe de base est qu'une personne souhaite tenir une [liste][types-list] des langages qu'elle veut apprendre sur le site web d'Exercism.

## Tâches

Voici ce que l'exercice apprend généralement aux apprenants :

- Créer une liste.
- Ajouter des éléments à une liste.
- Supprimer des éléments d'une liste.
- Compter la longueur d'une liste.
- Récupérer le premier élément d'une liste.
- Vérifier si un élément appartient à une liste.
