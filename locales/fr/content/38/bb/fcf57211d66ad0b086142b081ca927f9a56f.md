# Introduction

## Surcharge de méthodes

En Java, la surcharge de méthodes est une fonctionnalité qui permet à une classe de posséder plusieurs méthodes portant le même nom, à condition que leurs listes de paramètres soient différentes.
Elle est liée au polymorphisme à la compilation (ou statique).
Ce concept est essentiel pour créer des méthodes qui effectuent des tâches similaires, mais avec des entrées différentes.

### Pourquoi surcharger des méthodes ?

La surcharge de méthodes améliore la lisibilité du programme.
On peut donner le même nom à différentes méthodes, mais avec des paramètres différents.
Selon le nombre de paramètres ou leur type, c'est la méthode correspondante qui est appelée.

### Comment surcharger des méthodes ?

La clé de la surcharge de méthodes réside dans la signature d'une méthode.
Deux méthodes sont considérées comme différentes si leurs signatures diffèrent.
Il y a deux façons de surcharger une méthode :

1. **Un nombre différent de paramètres** : les méthodes peuvent porter le même nom, mais avoir un nombre de paramètres différent.

   ```java
   public class Display {

       public void show(int x) {
           System.out.println("Show with int: " + x);
       }

       public void show(int x, int y) {
           System.out.println("Show with two ints: " + x + ", " + y);
       }
   }
   ```

2. **Des types de paramètres différents** : les méthodes peuvent porter le même nom et avoir le même nombre de paramètres, mais avec des types différents.

   ```java
   public class Display {

       public void show(int x) {
           System.out.println("Show with int: " + x);
       }

       public void show(String s) {
           System.out.println("Show with String: " + s);
       }
   }
   ```

### Points à retenir

- Les méthodes surchargées doivent modifier la liste des arguments.
- Les méthodes surchargées peuvent aussi modifier le type de retour, mais le simple fait de changer le type de retour ne constitue pas une surcharge de méthodes.
- On peut surcharger des méthodes dans une même classe ou dans une sous-classe.

Dans ce concept, on va explorer différents exemples et nuances de la surcharge de méthodes en Java.
