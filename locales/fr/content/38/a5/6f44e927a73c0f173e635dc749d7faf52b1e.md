# Introduction

## Erreurs

Les erreurs sont utiles pour signaler que quelque chose ne va pas ou est inattendu dans un programme ou dans un bout de code.

Ce sont des objets JavaScript.

La propriété principale de cet objet est `message` :

```javascript
const error = new Error('Oops, something went wrong');

console.log(error.message);
// => "Oops, something went wrong"
```

Avec la syntaxe `throw`, on peut lever une erreur.

```javascript
throw new Error('Oops');
```

Quand une erreur est levée, l'exécution en cours s'arrête et reprend dans le premier bloc `catch` de la pile d'appels.

```javascript
try {
  throw new Error('Oops');
} catch (error) {
  console.log(error.message);
  // => "Oops"
}
```

## Héritage

L'héritage est une façon de créer des relations parent-enfant entre les classes.
La classe enfant (parfois appelée _sous-classe_) a accès au comportement et aux données définis par la classe parente (parfois appelée _superclasse_).

```javascript
class Pet {
  constructor(name) {
    this.name = name;
  }

  introduce() {
    console.log(`This is my pet, ${this.name}.`);
  }
}

class Dog extends Pet {}

const dog = new Dog('Otis');
dog.introduce();
// => This is my pet, Otis.
```

Le mot-clé `extends` dans la déclaration de la classe enfant établit une relation avec la classe parente via la [chaîne de prototypes][prototype-chain].

Les objets créés par le constructeur de la classe enfant ont le prototype de la classe parente dans leur chaîne de prototypes, ce qui donne accès à toutes les méthodes ou données définies par la parente.

```javascript
const dog = new Dog('Otis');

Dog.prototype.isPrototypeOf(dog); // => true
Pet.prototype.isPrototypeOf(dog); // => true
Pet.prototype.isPrototypeOf(Dog.prototype); // => true

Pet.prototype.hasOwnProperty('introduce'); // => true
Dog.prototype.hasOwnProperty('introduce'); // => false
dog.hasOwnProperty('introduce'); // => false
```

Comme pour toute classe en JavaScript, les sous-classes peuvent hériter de `Error` pour créer des erreurs personnalisées en utilisant le mot-clé `extends`.
La syntaxe `instanceof` permet de vérifier si l'erreur interceptée est une instance d'une sous-classe particulière de `Error`.

```javascript
class CustomError extends Error {}

try {
  // ... Code that may throw an error
} catch (error) {
  if (error instanceof CustomError) {
    console.log('The error thrown is an instance of the CustomError');
  }
}
```

[prototype-chain]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Inheritance_and_the_prototype_chain
