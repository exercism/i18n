# Introduction

## Méthodes d'extension

Les méthodes d'extension permettent d'ajouter des méthodes à des types existants sans créer un nouveau type dérivé, sans recompiler ni modifier le type d'origine d'une autre manière. Elles sont définies comme des méthodes statiques mais sont appelées en utilisant la syntaxe de méthode d'instance. Leur premier paramètre, précédé du modificateur `this`, spécifie le type sur lequel la méthode opère, et elles sont mises dans la portée au niveau de l'espace de noms.

```csharp
public static int WordCount(this string str)
{
    return str.Split().Length;
}

"Hello World".WordCount();
// => 2
```
