# Indices

## 1. Récupère la première carte

- Cet [article][mdn-destructuring] donne un bon aperçu de la déstructuration de tableaux. Tu trouveras un exemple d'affectation de variable simple dans la section « Basic Array Destructuring ».

## 2. Récupère la deuxième carte

- Tu peux utiliser des espaces réservés pour ignorer une ou plusieurs valeurs du tableau.
- Tu trouveras un exemple [sur MDN][mdn-destructuring-ignore-value].

## 3. Échange les deux cartes

- Il est possible d'échanger deux valeurs dans une seule expression de déstructuration.
- Tu trouveras un exemple [sur MDN][mdn-destructuring-swapping].

## 4. Décale trois cartes

- Il est possible de changer la position de trois valeurs dans une seule expression de déstructuration.
- C'est la même chose que d'échanger deux valeurs, mais avec trois valeurs (ou plus).

## 5. Prends la pile nommée

- Les objets peuvent être déstructurés tout comme les tableaux.
- Tu trouveras un exemple [sur MDN][mdn-object-destructuring-basic-assignment].

## 6. Échange les piles nommées

- Lorsqu'une propriété est extraite d'un objet, elle peut être renommée à l'aide d'une syntaxe spécifique.
- Tu trouveras un exemple [sur MDN][mdn-object-destructuring-object-rename].
