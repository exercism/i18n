# Indices

## Général

- Lis la section sur les citations dans le [guide officiel de démarrage][getting-started-quote].
- Lis l'[introduction à l'AST d'Elixir par Lucas San Román][ast-intro-lucas].
- Lis [la documentation officielle de `quote`][doc-quote].
- Inspecte la sortie de [`quote`][doc-quote] pour te familiariser avec l'apparence des AST pour des extraits de code donnés.

## 1. Transforme du code en données

- Il existe une [fonction intégrée][doc-code-string-to-quoted] qui transforme une _string_ contenant du code en AST.

## 2. Analyse un seul nœud AST

- Inspecte la sortie de [`quote`][doc-quote] pour te familiariser avec l'apparence des AST pour des extraits de code donnés.
- Les opérations qui définissent une fonction sont `:def` et `:defp`.
- L'opération est le premier élément d'un tuple de nœud AST à trois éléments.
- Tu peux complètement ignorer le deuxième élément du tuple dans cet exercice.
- Le troisième élément du tuple est la liste d'arguments de l'opération qui définit la fonction.
- Le premier élément de cette liste est un tuple contenant le nom et les arguments de la fonction, et le deuxième élément est le corps de la fonction.

## 3. Décode la partie du message secret à partir de la définition de fonction

- Inspecte la sortie de [`quote`][doc-quote] pour te familiariser avec l'apparence des AST pour des extraits de code donnés.
- Le nœud AST qui contient le nom de la fonction contient aussi la liste d'arguments de la fonction comme troisième élément.
- L'arité d'une fonction est la longueur de sa liste d'arguments.
- Il existe une [fonction intégrée du module `String`][string-slice] qui permet d'obtenir les `n` premiers caractères d'une _string_.
- Une fonction sans arguments écrite sans parenthèses n'aura pas de liste en argument, mais un atome.

## 4. Corrige le décodage pour les fonctions avec des gardes

- Inspecte la sortie de [`quote`][doc-quote] pour te familiariser avec l'apparence des AST pour des extraits de code donnés.
- Lorsqu'une fonction a une garde, le troisième élément du tuple pour l'opération `:def/:defp` est un peu différent.
- Ce troisième élément est une liste à deux éléments : le premier est le tuple de l'opération `:when`, et le second est le corps de la fonction.
- Les arguments de l'opération `:when` sont une liste à deux éléments, où le premier argument est le nom de la fonction, et le second est l'expression de garde.

## 5. Décode le message secret complet

- Utilise la fonction `to_ast/1` que tu as implémentée dans la première tâche pour créer l'AST.
- Il existe une [fonction intégrée][macro-prewalk] qui peut parcourir chaque nœud d'un AST avec un accumulateur.
- Utilise la fonction `decode_secret_message_part/2` que tu as implémentée dans les tâches précédentes pour parcourir l'AST en pré-ordre.
- Pour inverser l'accumulateur à la fin et le transformer en _string_, rafraîchis tes connaissances sur [le module `Enum`][enum].
