# Introduction

En JavaScript, les _template strings_ permettent d'intégrer des expressions dans des _strings_, ce qu'on appelle aussi l'interpolation de _strings_.
Cette fonctionnalité étend les capacités de l'objet global [`String`][string-reference] intégré.

Pour créer une _template string_ en JavaScript, il suffit d'entourer le texte de _backticks_.
Le texte peut ainsi contenir des retours à la ligne et d'autres caractères spéciaux, et on peut aussi y intégrer des variables et d'autres expressions.

```javascript
const num1 = 1;
const num2 = 2;

`Adding ${num1} and ${num2} gives ${num1 + num2}.`;
// => Adding 1 and 2 gives 3.
```

Dans l'exemple ci-dessus, les _backticks_ (<code>\`\`</code>) servent à représenter une _template string_. Le `${...}` est l'espace réservé qui sert à la substitution.
Tous les types qui ne sont pas des _strings_ sont convertis _implicitement_ en _strings_.
Ce sujet est abordé dans le concept [conversion de types][type-conversion-concept].
Tous les types d'expressions peuvent être utilisés avec les _template strings_.

```javascript
const track = 'JavaScript';

`This track on exercism.org is ${track.toUpperCase()}.`;
// => This track on exercism.org is JAVASCRIPT.
```

Quand tu as besoin de formater des _strings_ sur plusieurs lignes :

```javascript
`This is an example of using template
strings to accomplish multiple
lines`;
```

Grâce aux possibilités de substitution, on peut aussi introduire de la logique pour déterminer ce que doit être la _string_ obtenue.

Un exemple est l'intégration d'un [opérateur ternaire][ternary-operator].
Cet opérateur est une forme courte pour écrire une instruction `if/else`.
La syntaxe est `condition ? consequent-expression : alternative-expression`.
Si la condition est _truthy_, l'opérande situé à gauche des deux-points sera renvoyé.
Sinon, le résultat de l'expression ternaire est l'opérande situé à droite des deux-points.

```javascript
const grade = 95;

`You have ${grade > 90 ? 'passed' : 'failed'} the exam.`;
// => You have passed the exam.
```
