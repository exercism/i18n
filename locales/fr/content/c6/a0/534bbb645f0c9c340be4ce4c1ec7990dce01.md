# Instructions

L'entreprise pour laquelle tu travailles s'apprête à lancer son tout nouveau smartphone, le **Smarty 5**, qui embarque un tout nouveau système de caméra, un nouveau design et un processeur révolutionnaire tournant sous un nouveau système d'exploitation appelé **smartyOS**.

Ce nouveau processeur est capable de gérer des mots de passe plus sécurisés que jamais, et l'entreprise a décidé d'en tirer parti.
Elle t'a demandé de mettre en place un système de verrouillage par mot de passe pour le téléphone, qui permet à l'utilisateur de définir un mot de passe, puis de vérifier si un mot de passe donné est correct.

~~~~exercism/caution
Le système de mots de passe utilisé dans cet exercice n'est pas sécurisé et ne sert qu'à des fins pédagogiques.
Il ne doit **PAS** être utilisé dans de vraies applications.
~~~~

## 1. Définis un mot de passe

Le téléphone permet aux utilisateurs d'utiliser plusieurs types de mots de passe différents, d'un simple mot de passe à chiffres à un mot de passe alphanumérique plus sécurisé, et même à un mot de passe qui stocke leur empreinte digitale.

Ces différents types de mots de passe utilisent des types différents : le mot de passe à chiffres utilise un `Int32`, le mot de passe alphanumérique utilise un `String` et le mot de passe par empreinte digitale utilise un `Float64`.

Implémente la classe `PasswordLock` avec un initialiseur qui prend en argument l'un des trois types de mots de passe et le stocke dans une variable d'instance appelée `@password`.

```crystal
password_lock = PasswordLock.new(1234)
# => #<PasswordLock:0x7f8e1b8c0b80 @password=1234>
```

## 2. Chiffre le mot de passe

L'entreprise a décidé de chiffrer le mot de passe pour qu'il ne soit pas stocké en clair et t'a demandé d'implémenter une méthode pour le chiffrer.

Chaque type de mot de passe se chiffre d'une manière qui lui est propre :

- Mot de passe `Int32` : le mot de passe est divisé par deux et arrondi à l'entier le plus proche.
- Mot de passe `String` : le mot de passe est inversé.
- Mot de passe `Float64` : le mot de passe est multiplié par quatre.

Implémente une méthode d'instance appelée `encrypt` qui ne prend aucun argument et qui modifie la variable d'instance `@password` pour qu'elle soit chiffrée.

```crystal
password_lock = PasswordLock.new(1234)
# => #<PasswordLock:0x7f8e1b8c0b80 @password=1234>

password_lock.encrypt
# => #<PasswordLock:0x7f8e1b8c0b80 @password=617>
```

## 3. Vérifie si un mot de passe est correct

L'entreprise t'a aussi demandé d'implémenter une méthode qui vérifie si un mot de passe donné est correct.

Elle veut que la méthode renvoie `nil` si le mot de passe est incorrect et `"Unlocked"` si le mot de passe est correct.

Implémente une méthode d'instance appelée `unlock?` qui prend en argument le mot de passe à vérifier.
La méthode doit renvoyer `nil` si le mot de passe est incorrect et `"Unlocked"` si le mot de passe est correct.

```crystal
password_lock = PasswordLock.new(1234)
password_lock.encrypt
password_lock.unlock?(1234)
# => "Unlocked"
```
