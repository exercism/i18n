# Indices

## 1. Estime le temps de préparation

- Utilise [`size()`][size-func] du vecteur pour déterminer le nombre de couches (la longueur du vecteur de couches).

## 2. Calcule les quantités de nouilles et de sauce nécessaires

- Commence par créer un objet `amount` pour suivre la quantité de nouilles et de sauce.
- Utilise une [boucle `for`][for-loop] pour parcourir les couches.
- Si tu rencontres une couche `"noodles"` ou `"sauce"` dans ta boucle, augmente en conséquence la quantité stockée dans l'objet `amount`.

## 3. Ajoute l'ingrédient secret

- Revois les [vecteurs][concept-vector] pour découvrir comment récupérer un élément d'un vecteur et comment remplacer un élément dans un vecteur.
- L'indice du dernier élément d'un vecteur `a` est `a.size() - 1`, ou tu peux utiliser directement `a.back()`.

## 4. Adapte les quantités de la recette

- Commence par créer un nouveau vecteur de la même taille que le vecteur d'entrée
- Utilise une [boucle `for`][for-loop] pour parcourir le vecteur d'entrée et générer le vecteur de sortie

## 5. Débloque le secret de famille

- Tu peux réutiliser le code de la tâche 3.
- Cette tâche nécessite la [surcharge de fonctions][function overloading].
