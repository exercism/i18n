## Messages d'exception

Parfois, il est nécessaire de [lever une exception](https://docs.python.org/3/tutorial/errors.html#raising-exceptions). Dans ce cas, il faut toujours inclure un **message d'erreur explicite** pour indiquer l'origine de l'erreur. Cela rend le code plus lisible et facilite grandement le débogage. Quand tu sais que l'origine de l'erreur sera d'un type donné, tu peux lever l'un des [types d'erreur intégrés](https://docs.python.org/3/library/exceptions.html#base-classes), mais il faut quand même inclure un message explicite.

La conjecture de Collatz ne concerne que les **entiers strictement positifs**, donc cet exercice attend de toi que tu utilises l'[instruction `raise`](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement) et que tu « lances » une `ValueError` dans ta solution si la valeur donnée est zéro ou un entier négatif. Les tests ne passeront que si tu `raise` l'`exception` et que tu y joins un message.

Pour lever une `ValueError` avec un message, écris le message comme argument du type `exception` :

```python
# example when argument is zero or a negative integer
raise ValueError("Only positive integers are allowed")
```
