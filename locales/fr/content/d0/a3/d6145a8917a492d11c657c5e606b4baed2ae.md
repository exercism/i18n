# Instructions spécifiques à SQLite

Cet exercice te demande de renseigner la colonne `result` de la table `etl` avec la valeur correcte, à partir de l'objet JSON qui se trouve dans la colonne `input`. Les clés de l'objet `result` doivent être triées par ordre alphabétique.

## Schéma de la table

```sql
CREATE TABLE "etl" ("input" TEXT, "result" TEXT);
```
