# Tests

Pour lancer les tests, exécute la commande `go test` depuis le répertoire de l'exercice.

Si la suite de tests contient des _benchmarks_, tu peux les lancer grâce aux options `--bench` et `--benchmem` :

    go test -v --bench . --benchmem

Garde à l'esprit que chaque relecteur exécutera les _benchmarks_ sur une machine différente, avec des caractéristiques différentes, et que les résultats de ces tests peuvent donc varier.
