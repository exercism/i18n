# Tests

Pour exécuter les tests, lance la commande suivante :

```bash
make
```

## Tests ignorés

Résoudre un exercice, c'est faire passer tous ses tests.
Par défaut, un seul test (le premier) est exécuté quand on lance les tests.
C'est volontaire : cela te permet de te concentrer sur ce seul test, le temps de le faire passer.
Une fois qu'il passe, tu peux activer le test suivant en supprimant la ligne `TEST_IGNORE()`.
Quand tous les tests sont activés et que ton implémentation les fait tous passer, tu as résolu l'exercice !
