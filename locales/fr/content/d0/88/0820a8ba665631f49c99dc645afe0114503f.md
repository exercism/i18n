# Instructions

Dans cet exercice, on va écrire du code pour aider une personne freelance à communiquer avec un chef de projet, en fournissant quelques utilitaires qui calculent rapidement des taux journaliers et mensuels, éventuellement avec une réduction donnée.

On commence par établir quelques règles entre la personne freelance et le chef de projet :

Le taux journalier vaut 8 fois le taux horaire.

Un mois compte 22 jours facturables.

La personne freelance propose d'appliquer une réduction si le chef de projet choisit de la faire facturer au mois, ce qui peut être pratique lorsqu'il y a un budget précis à respecter.

Les réductions sont représentées par des nombres décimaux exprimant un pourcentage, par exemple 25,0 (25 %).

## 1. Calcule le taux journalier à partir d'un taux horaire

Implémente une fonction qui calcule le taux journalier à partir d'un taux horaire :

```gleam
freelancer_rates.daily_rate(60)
# => 480.0
```

Le taux journalier renvoyé doit être un nombre décimal.

## 2. Calcule le prix après réduction

Implémente une fonction qui calcule le prix après réduction.

```gleam
freelancer_rates.apply_discount(150, 10)
# => 135.0
```

La valeur renvoyée doit toujours être un nombre décimal, sans aucun arrondi.

## 3. Calcule le taux mensuel à partir d'un taux horaire et d'une réduction

Implémente une fonction qui calcule le taux mensuel et applique une réduction :

```gleam
freelancer_rates.monthly_rate(77, 10.5)
# => 12130
```

Le taux mensuel renvoyé doit être arrondi à l'entier supérieur (on arrondit au plafond).

## 4. Calcule le nombre de jours travaillés à partir d'un budget, d'un taux horaire et d'une réduction

Implémente une fonction qui prend un budget, un taux horaire et une réduction, et qui calcule combien de jours de travail cela représente.

```gleam
freelancer_rates.days_in_budget(20000, 80, 11.0)
# => 35
```

Le nombre de jours renvoyé doit être arrondi au dixième inférieur (on arrondit au plancher).
