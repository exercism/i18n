# Introduction

En Gleam, `Nil` est un type avec une seule valeur, également appelée `Nil`. Il est similaire au `void` d'autres langages : on l'utilise quand une fonction n'a pas de valeur plus appropriée à renvoyer.

```gleam
io.println("Hello, Joe!")
// -> Nil
```

En Gleam, les valeurs ne sont pas « nil-able » ou « nullable » comme dans certains autres langages. Une valeur ne peut être `Nil` que si son type est `Nil`, et une valeur de tout autre type ne peut jamais être `Nil`.
