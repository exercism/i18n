# Instructions supplémentaires

## Registres

| Registre | Utilisation | Type       | Description                                |
| -------- | ----------- | ---------- | ------------------------------------------ |
| `$a0`    | entrée      | entier     | numéro de la case, dans l'intervalle 1..64 |
| `$v0`    | sortie      | entier     | les 32 bits de poids faible de la sortie   |
| `$v1`    | sortie      | entier     | les 32 bits de poids fort de la sortie     |
| `$t0-9`  | temporaire  | quelconque | pour un stockage temporaire                |
