# Expressions `match`

Une expression `match` évalue une valeur et une condition afin de renvoyer une expression à évaluer. Comme avec un opérateur ternaire, si la condition ne correspond pas, l'expression de retour n'est pas évaluée. Pour qu'une condition corresponde, une vérification d'identité (égalité stricte ou `===`) est effectuée.

```php
<?php
$some_value = 42;

$return_value = match($some_value) {
    0 => 'number is 0',
    1 => 'number is 1',
    default => 'number is something else'
}
```

Pour effectuer une vérification d'égalité (`==`), tu peux réorganiser la condition :

```php
<?php
$some_value = 42;

$return_value = match(true) {
    $some_value < 100 => 'number is less than 100',
    $some_value > 100 => 'number is greater than 100',
    $some_value == 100 => 'number is 100',
}
```

Dans une expression `match`, si aucune condition ne correspond, une erreur `UnhandledMatchError` est levée.
