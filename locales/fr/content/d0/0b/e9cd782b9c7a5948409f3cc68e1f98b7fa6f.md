# Installation

## Mac

Installe-le avec homebrew à l'aide de `brew install swi-prolog`.
Sinon, tu peux télécharger les sources correspondant à ta machine depuis le [site web de SWI Prolog](http://www.swi-prolog.org/download/devel).

## Windows

Télécharge les sources correspondant à ta machine depuis le [site web de SWI Prolog](http://www.swi-prolog.org/download/devel).

## Linux

Suis les instructions qui correspondent à ta distribution depuis [cette page](http://www.swi-prolog.org/build/unix.html).
