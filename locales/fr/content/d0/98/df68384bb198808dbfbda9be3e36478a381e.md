## 1. Convertir un signé en non signé

- Vérifie si la valeur signée est négative. Si c'est le cas, renvoie `Option::None`
- Vérifie si la valeur signée dépasse `u16::MAX` (65535). Si c'est le cas, renvoie `Option::None`
- Pour les valeurs valides, convertis avec `.try_into()` ou par conversion directe
- N'oublie pas que `u16` peut contenir des valeurs allant de 0 à 65535

## 2. Convertir un non signé en signé

- Comme `u16::MAX` (65535) tient sans problème dans un `i32`, cette conversion réussit toujours
- Utilise `.into()` pour convertir `u16` en `i32` en toute sécurité

## 3. Conversion de type personnalisé

- Implémente le trait `Into` avec la syntaxe : `impl IntoImplName of Into<SourceType, TargetType>`
- Dans la méthode `into`, crée une nouvelle instance du type cible
- Fais correspondre le champ `potency` d'`Essence` au champ `strength` d'`Elixir`
- Une fois le trait implémenté, tu peux utiliser `.into()` sur des instances d'`Essence`

## 4. Utiliser le trait `Into`

- Après avoir implémenté le trait `Into`, appelle `.into()` sur le paramètre `Essence`
- Le compilateur utilisera automatiquement ton implémentation du trait
- L'annotation du type de retour aide Cairo à savoir quelle conversion utiliser
