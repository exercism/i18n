# À propos

## Valeurs de retour multiples

En Swift, une fonction peut [renvoyer plusieurs valeurs][multiple-return-values] en renvoyant un tuple :

```swift
func reverseAndLength(_ str: String) -> (reverse: String, length: Int) {
    return (reverse: String(str.reversed()), length: str.count)
}

let result = reverseAndLength("Hello")
print(result.reverse) // Prints "olleH"
print(result.length)  // Prints 5
```

## Omets le mot-clé `return`

Lorsque le corps d'une fonction se réduit à une seule expression, tu peux [omettre le mot-clé `return`][implicit-returns] :

```swift
func reverseAndLength(_ str: String) -> (reverse: String, length: Int) {
    (reverse: String(str.reversed()), length: str.count)
}
```

Cette syntaxe de retour implicite s'applique à toutes les fonctions qui renvoient une valeur, pas seulement à celles qui renvoient des tuples.
