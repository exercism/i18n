# Introduction

Une fonction est un bloc de code organisé et réutilisable qui sert à effectuer une action.
Il existe plusieurs façons de définir des fonctions en JavaScript.
Nous allons ici nous intéresser aux _déclarations de fonction_ et aux _expressions de fonction_.
D'autres possibilités, comme les [fonctions fléchées][concept-arrow-functions], seront abordées dans d'autres concepts.

## Déclaration de fonction

La façon standard de définir une fonction en JavaScript est la _déclaration de fonction_, aussi appelée _définition de fonction_ ou _instruction de fonction_.

Elle se compose du mot-clé `function`, du nom de la fonction et d'une liste de paramètres séparés par des virgules, entre parenthèses.
Vient ensuite le corps de la fonction (l'ensemble des instructions qui définissent ce que fait la fonction), entouré d'accolades.

```javascript
function someName(param1, param2, param3) {
  // ...
}
```

En JavaScript, on invoque (on appelle) une fonction en indiquant le nom de la fonction, suivi de parenthèses qui contiennent les arguments.

```javascript
someName(arg1, arg2, arg3);
```

## Paramètres

Lorsqu'on travaille avec des paramètres à l'intérieur du corps de la fonction, il faut faire attention aux éventuels effets de bord.

- Les valeurs des [types de données primitifs][mdn-primitives] sont _immuables_.
  La valeur d'origine n'est jamais affectée par ce qui arrive à l'argument dans le corps de la fonction.
- Pour toutes les autres valeurs (objets, tableaux, fonctions), une réaffectation n'affecte pas la valeur d'origine.
  En revanche, si tu modifies un tel argument (par exemple en ajoutant une clé à un objet), tu modifies aussi la valeur d'origine qui a été passée.

Par défaut, en JavaScript, tous les paramètres définis dans la déclaration de fonction sont facultatifs.
Si tu fournis moins d'arguments qu'il n'y a de paramètres, les arguments manquants vaudront `undefined` à l'intérieur de la fonction, voir [Null et Undefined][concept-null-undefined].
Dans de nombreux cas, il est judicieux d'affecter une valeur par défaut plus appropriée que `undefined`.
Pour cela, il suffit de spécifier des paramètres par défaut directement dans la définition de la fonction.

```javascript
function someName(param1 = defaultValue1, param2 = defaultValue2) {
  // ...
}
```

## L'instruction `return`

Une instruction `return` met fin à l'exécution de la fonction et spécifie une valeur à renvoyer à l'appelant de la fonction. Une fonction peut contenir plusieurs instructions `return`.

```javascript
function checkNumber(num) {
  if (num === 0) {
    return 'You passed 0, please provide another number.';
  }

  return 'Thanks for passing such a nice number.';
}
```

Le résultat d'une fonction qui ne renvoie aucune valeur avec `return`, ou qui ne contient pas d'instruction `return`, est `undefined`.
Il n'existe pas de `return` implicite en JavaScript.

```javascript
function nakedReturn(a) {
  a * 2;
  return;
}

nakedReturn(1);
// => undefined

function noReturn(a) {
  a * 2;
}

noReturn(1);
// => undefined
```

En JavaScript, une fonction ne peut renvoyer qu'une seule valeur.
Si tu veux transmettre plus d'informations, tu dois d'abord les regrouper dans une seule entité, généralement un [objet][concept-objects] ou un [tableau][concept-arrays].

```javascript
function divide(a, b) {
  return {
    quotient: Math.floor(a / b),
    remainder: a % b,
  };
}
```

## Expression de fonction

Une déclaration de fonction est une instruction autonome.
Mais parfois, il est utile de définir une fonction au sein d'une autre expression, par exemple dans une affectation, comme paramètre de fonction ([_callback_][concept-callbacks]) ou comme valeur dans un [objet][concept-objects].
C'est possible avec une expression de fonction.
Elle a la même syntaxe qu'une déclaration de fonction, à ceci près que le nom de la fonction peut être omis pour créer une _fonction anonyme_.

```javascript
const someFunction = function (param) {
  // ...
};

someOtherFunction(function (param) {
  // ...
});

const obj = {
  someFunction: function (param) {
    // ...
  },
};
```
