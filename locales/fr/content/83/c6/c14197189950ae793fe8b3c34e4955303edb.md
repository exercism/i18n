# Introduction
Les types numériques intégrés de C++ se divisent en deux catégories : les nombres entiers et les nombres à virgule flottante.
Les nombres entiers sont des nombres sans partie décimale, comme `0`, `691` ou `-2`.
Les nombres à virgule flottante sont des nombres qui comportent une virgule décimale, comme `6.02214076`, `0.1` ou `-1.616`.

## Nombres entiers
L'exemple suivant montre la déclaration et l'initialisation de quatre variables différentes

```cpp
int m_morales{9241};              // base 10: 0-9
int a_apaec{0x24CD};              // base 16: 0-9 and A-F
int m_gargan{0b10010000011001};   // base  2: 0-1
int b_reilly{022031};             // base  8: 0-7
                                  // Leading with a 0 not the letter o.
```

Pour affecter une valeur à une variable `int`, on peut le faire directement avec un littéral.
Un littéral est un nombre écrit « en dur », c'est-à-dire une valeur fixe écrite directement dans le code, comme `9241`.
Il existe différents littéraux entiers pour plusieurs bases de représentation.
Les littéraux entiers décimaux sont les plus courants et utilisent les chiffres `0` à `9`.
En ajoutant un préfixe spécial, comme `0x`, on peut utiliser d'autres bases.
L'exemple ci-dessus montre le nombre `9241` dans ses quatre représentations et préfixes.
Toutes les variables sont initialisées à la même valeur.

Pour plus de détails sur les différents systèmes de représentation, jette un œil à [un petit tutoriel][cpp_numerical_bases].

Tu peux utiliser une apostrophe pour séparer les chiffres et rendre le nombre plus lisible.
`9'241` est identique à `0b0100'100'0001'1001` ou `92'4'1`.

## Nombres à virgule flottante

Les littéraux à virgule flottante se présentent sous deux formes.
En plus de la forme intuitive `0.0024`, on peut utiliser sa notation scientifique `2.4e-3`.
Le type à virgule flottante le plus courant est `double`.

## Arithmétique

C++ prend en charge `+`, `-`, `*`, `/`, `(` et `)` et `%` pour former des expressions.
Le résultat de l'opération entre deux entiers est aussi un entier.
`5 / 2` renvoie `2`.
Quand l'un des types impliqués est un type à virgule flottante, le résultat est lui aussi un nombre à virgule flottante.
`5.0 / 2` et `5 / 2.0` renvoient `2.5`.
`%` est l'opérateur modulo et renvoie le reste d'une division entière : `5%3` vaut `2`.

## L'opérateur d'affectation

L'opérateur d'affectation permet d'affecter un littéral à une variable.
L'affectation se fait toujours de droite à gauche, et jamais dans l'autre sens.

```cpp
int length = 5;
int width = 2;
length = width;
```

Ici, la valeur entière `5` est affectée à la variable `length`.
Ensuite, la valeur entière `2` est affectée à la variable `width`.
Enfin, la valeur de `width` est copiée dans la variable `length` et l'ancienne valeur `5` est perdue.
Note aussi qu'on n'affecte la valeur de `width` à `length` qu'au moment de l'opération d'affectation.
Par conséquent, si la valeur de `width` change plus tard, cela n'affectera pas la valeur prise par `length`.

L'opérateur d'affectation peut être combiné avec les autres opérateurs (arithmétiques et binaires) : on parle alors d'opérateurs `compound assignment`, à savoir `+=`, `-=`, `*=`, `/=`, `%=`.
Ces opérateurs modifient la valeur actuelle d'une variable en lui appliquant une opération.

```cpp
// we start with 0 people
int people{};
// we need 0 eggs
int eggs{};
// two people joined:
people += 2;
// people is now 2
// let's add 3 eggs per person
eggs += 3 * people;
// eggs is now 6
```

Les variables `people` et `eggs` sont initialisées à `0`.
Ensuite, on ajoute la valeur entière `2` à la valeur existante `0` de la variable `people` et on réaffecte le résultat à `people`.
`people` vaut maintenant `2`.
Plus tard, on ajoute `3` œufs par personne, ce qui donne `6` œufs au total.
On ajoute maintenant ce `6` à la valeur existante `0` de la variable `eggs` et on réaffecte le résultat à `eggs`.
`eggs` vaut `6` maintenant.
L'expression équivalente serait `people = people + 2` et `eggs = eggs + (3 * people)`.
