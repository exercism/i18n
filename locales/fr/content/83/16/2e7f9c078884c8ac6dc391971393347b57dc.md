# Introduction

## Génériques

Un type est un _type générique_ lorsqu'il peut contenir des valeurs de n'importe quel type au moyen d'un _paramètre de type_.

Par exemple, ce type `Box` possède le paramètre de type `a` (écrit avec des lettres minuscules).

```gleam
pub type Box(a) {
  Box(a)
}
```

Le paramètre de type `a` est un espace réservé pour n'importe quel type, donc `Box` peut être utilisé avec des _strings_, des entiers ou n'importe quel autre type.

```gleam
Box("Hello, Joe!") // The type is Box(String)

Box(42) // The type is Box(Int)
```

Un type peut avoir plusieurs paramètres de type, séparés par des virgules.

```gleam
pub type Pair(a, b) {
  Pair(a, b)
}
```

### Fonctions génériques

On peut aussi utiliser des paramètres de type dans les arguments des fonctions.

Cette fonction prend une valeur de type `a` et appelle deux fois une fonction qui prend un `a` et renvoie un `b`.

```gleam
pub fn twice(value: a, f: fn(a) -> b) -> b {
  f(value)
  f(value)
}
```
```gleam
// The type is fn(String, fn(String) -> Nil) -> Nil
twice("Hello, Joe!", io.println)
```
