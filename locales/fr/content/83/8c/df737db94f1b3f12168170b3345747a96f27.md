# Introduction

Une chaîne de caractères représente des données textuelles.
En Swift, une [`String`][strings-and-characters] est une collection ordonnée de valeurs `Character`, où chaque caractère représente un caractère Unicode.

On crée une _string_ à l'aide d'un littéral de chaîne, c'est-à-dire une suite de caractères entourée de guillemets doubles (`"`).
Pour les chaînes sur plusieurs lignes, utilise trois guillemets doubles (`"""`) :

```swift
let hello: String = "Hello, World!"

let poem: String = """
Roses are red,
Violets are blue.
Sugar is sweet,
And so are you.
"""
```

Les _strings_ Swift s'intègrent parfaitement à la classe [`NSString`][nsstring-docs] du framework Foundation, ce qui donne accès à de nombreuses capacités de traitement de texte.

## Characters

Un `Character` représente un seul groupe de graphèmes étendu, c'est-à-dire un caractère lisible par un humain composé d'une ou plusieurs [valeurs scalaires Unicode][unicode-scalar-values].
Une valeur scalaire Unicode est un point de code de 21 bits compris dans la plage `U+0000` à `U+D7FF` inclus, ou `U+E000` à `U+10FFFF` inclus.

```swift
let aChar: Character = "A"
```

## Type Inference

Quand on écrit un littéral de chaîne, Swift en infère automatiquement le type `String`.
Pour stocker un seul caractère dans un `Character`, il faut fournir une annotation de type explicite :

```swift
let aString = "A"        // Inferred as String
let aChar: Character = "A" // Explicitly typed as Character
print(type(of: aString)) // Prints String
print(type(of: aChar))   // Prints Character

// The following code will not compile:
let badChar: Character = "Too many characters"
// Error: Cannot convert value of type 'String' to specified type 'Character'
```

## Concatenation

On peut assembler des _strings_ à l'aide de l'opérateur d'addition (`+`) :

```swift
print("honey" + "comb")
// Prints "honeycomb"
```

On ne peut pas concaténer directement un `Character` à une _string_ avec `+` sans d'abord convertir le caractère en _string_.
En revanche, on peut utiliser la méthode [`append(_:)`][append] pour ajouter directement une _string_ ou un caractère à une _string_ modifiable :

```swift
var greeting = "Hello"
let world = ", world"
let period: Character = "."

greeting.append(world)
print(greeting) // Prints "Hello, world"

greeting.append(period)
print(greeting) // Prints "Hello, world."
```

## String Interpolation

L'[interpolation de _string_][string-interpolation] permet de construire une _string_ en intégrant des constantes, des variables, des littéraux et des expressions à l'intérieur de littéraux de chaîne.
Entoure chaque expression de parenthèses précédées d'un antislash (`\(` ... `)`) :

```swift
let radius = 5.0
let circle = "The area of a circle with radius \(radius) is \(Double.pi * radius * radius)"
print(circle) // Prints "The area of a circle with radius 5.0 is 78.53981633974483"
```

## String and Character Properties

Les _strings_ et les `Character` offrent plusieurs propriétés pour inspecter leur contenu.

### String Properties

Voici les propriétés de _string_ les plus courantes :

| Property  | Description                                    | Example                          |
| --------- | ---------------------------------------------- | -------------------------------- |
| `isEmpty` | Renvoie `true` si la _string_ ne contient aucun caractère | `"Hello".isEmpty` vaut `false` |
| `count`   | Renvoie le nombre de caractères dans la _string_ | `"Hello".count` vaut `5`       |

Pour une liste complète des propriétés, consulte la [documentation Apple sur `String`][string-docs].

### Character Properties

Voici les propriétés de `Character` les plus courantes :

| Property       | Description                                   | Example                              |
| -------------- | --------------------------------------------- | ------------------------------------ |
| `isLowercase`  | Renvoie `true` si le caractère est en minuscule  | `"a".isLowercase` vaut `true` |
| `isUppercase`  | Renvoie `true` si le caractère est en majuscule  | `"A".isUppercase` vaut `true` |
| `isNumber`     | Renvoie `true` si le caractère est un chiffre    | `"1".isNumber` vaut `true`    |
| `isWhitespace` | Renvoie `true` si le caractère est un espace | `" ".isWhitespace` vaut `true`|

Pour une liste complète des propriétés, consulte la [documentation Apple sur `Character`][character-docs].

## Type Conversion

On peut convertir d'autres types en _strings_ à l'aide de l'initialiseur `String(_:)`, qui prend en charge des types standard comme `Int`, `Double` et `Character` :

```swift
let charX: Character = "x"
print(String(charX))     // Prints "x"
print(String(110))       // Prints "110"
print(String(Double.pi)) // Prints "3.141592653589793"
```

## Special Characters

Les littéraux de chaîne en Swift prennent en charge plusieurs [séquences d'échappement][special-characters] pour les caractères spéciaux :

| Sequence   | Description                   |
| ---------- | ----------------------------- |
| `\0`       | Caractère nul                 |
| `\\`       | Antislash                     |
| `\t`       | Tabulation horizontale        |
| `\n`       | Saut de ligne (nouvelle ligne) |
| `\r`       | Retour chariot                |
| `\'`       | Guillemet simple              |
| `\"`       | Guillemet double              |
| `\u{n}`    | Scalaire Unicode arbitraire (hexadécimal) |

```swift
let quote: String = "\"Hello\", he said."
print(quote) // Prints "Hello", he said.

let unicode: Character = "\u{1F496}"
print(unicode) // Prints 💖
```
