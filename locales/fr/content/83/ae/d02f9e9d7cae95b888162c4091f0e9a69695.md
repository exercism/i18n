# À propos

Les [symboles][symbols] sont des identifiants nommés qui permettent de faire référence à une valeur.
Les symboles sont créés au moyen d'un littéral de symbole, qui consiste à faire précéder un nom du caractère `:`, par exemple `:foo`.
Ils peuvent aussi s'écrire entre guillemets, par exemple `:"foo"`, ce qui permet par exemple d'avoir des espaces dans le nom.

```ruby
:foo # => :foo
:"foo boo" # => :"foo boo"
```

Les symboles s'utilisent à de nombreux endroits du langage, notamment comme clés de _hash_, pour représenter des noms de méthodes et de variables.

## Identifiant

Ce qui distingue les symboles des _strings_, c'est qu'ils sont des identifiants et ne représentent ni des données ni du texte.
Cela signifie que deux symboles portant le même nom sont toujours le même objet.

```ruby
"foo".object_id # => 60
"foo".object_id # => 80
:foo.object_id # => 1086748
:foo.object_id # => 1086748
```

## Modifie les symboles

Les symboles sont immuables, ce qui signifie qu'on ne peut pas les modifier.
Cela signifie que quand on « modifie » un symbole, on crée en réalité un nouveau symbole.
Il existe quelques méthodes qui permettent de manipuler les symboles ; elles renvoient toutes de nouveaux symboles.
Toutes ces méthodes sont répertoriées dans l'[API Symbol][symbols-api].

```ruby
:foo.upcase # => :FOO

:foo.object_id # => 1086748
:foo.upcase.object_id # => 60
```

Le fait que les symboles soient immuables présente l'avantage qu'ils sont plus économes en mémoire que les _strings_, mais aussi plus sûrs à utiliser comme identifiants.

## Conversion

Les symboles peuvent être convertis en _strings_, et inversement.
Cela peut être utile lorsque tu veux modifier un symbole, ou lorsque tu veux utiliser un symbole comme _string_.
Pour présenter une _string_ comme un symbole, tu peux utiliser la méthode `String#to_sym` ; pour faire l'inverse, tu peux utiliser la méthode `Symbol#to_s`.
Comme les symboles ne disposent que d'un ensemble limité de méthodes, il peut être utile de convertir un symbole en _string_ pour lui appliquer des méthodes de _string_, si l'on a besoin d'un nouveau symbole.

```ruby
:foo.to_s # => "foo"
"foo".to_sym # => :foo
```
