# Installation

## Linux

Bash, en tant que _shell_ GNU, est présent sur tout système GNU/Linux.
Sous BSD et les autres dérivés d'UNIX, il faudra probablement que tu l'installes toi-même.
Si tu es sous BSD, AIX, ou sur une distribution Linux livrée sans bash, consulte la documentation de ton système d'exploitation pour l'installation des paquets non essentiels.

Dans l'interface graphique de ton choix, cherche une application nommée « Terminal » : elle se trouve peut-être dans une section « Administrative/System Tools ».

Pour vérifier la version de Bash disponible, depuis la ligne de commande ou le terminal, exécute :

    echo $BASH_VERSION

Si ton _shell_ est `bash`, tu devrais obtenir quelque chose comme :

    4.4.19(1)-release

Tu ne devrais pas avoir besoin de faire autre chose : à ce stade, bash est installé et présent dans ton PATH, puisque c'est ton _shell_ actuel.

Si ton _shell_ n'est pas bash, il n'y a aucune raison d'en changer.
Tu peux écrire et exécuter des scripts bash sans être dans un _shell_ bash.

Pour vérifier la version de bash installée, exécute :

```plain
bash --version
```

Tu obtiendras quelque chose comme ceci :

```
GNU bash, version 4.4.19(1)-release (x86_64-pc-linux-gnu)
Copyright (C) 2016 Free Software Foundation, Inc.
License GPLv3+: GNU GPL version 3 or later <http://gnu.org/licenses/gpl.html>

This is free software; you are free to change and redistribute it.
There is NO WARRANTY, to the extent permitted by law.
```

Sinon, il est possible que bash ne soit pas installé.
Tu devrais l'installer avec le gestionnaire de paquets de ta distribution.

## Windows

Sous Windows 10, tu peux installer [WSL](https://docs.microsoft.com/en-us/windows/wsl/about).
Cela installe une distribution Linux complète (enfin, sans les composants graphiques) qui s'exécute nativement sous Windows.

Sinon, tu peux installer :

* [Cygwin](https://cygwin.com/)
* [git for windows](https://gitforwindows.org/)
* [MinGW](http://mingw.org/)
* une distribution Linux complète dans [une machine virtuelle](https://docs.microsoft.com/en-us/virtualization/hyper-v-on-windows/about/)

## MacOS

Pour Apple OSX :

* ouvre le Finder,
* ouvre ton dossier Applications,
* ouvre le dossier Utilities,
* enfin, ouvre l'application `Terminal`.

Note que la version de bash installée sur MacOS est très ancienne : la version 3.2.
Cela tient (i) au fait que les versions plus récentes de bash sont sous licence GPLv3 et (ii) au refus d'Apple d'être contraint de respecter les termes de cette licence.
De plus, Apple a annoncé que bash allait disparaître de MacOS : le _shell_ de connexion par défaut a récemment été [remplacé de bash par zsh](https://support.apple.com/en-us/HT208050).

Pour obtenir un bash à jour sur ton Mac :

1. installe [Homebrew](https://brew.sh)
1. dans un Terminal, saisis : `brew install bash`

Cela installe un bash à jour dans (je crois) `/usr/local/bin/bash` (afin de ne pas écraser le bash par défaut du système, car d'autres outils peuvent dépendre de /bin/bash).

Si tu veux que le bash de Homebrew se lance quand tu tapes `bash`, modifie ton fichier ~/.bash_profile (ou ~/.profile) pour placer /usr/local/bin *avant* /bin dans le PATH :

    PATH=/usr/local/bin:$PATH
