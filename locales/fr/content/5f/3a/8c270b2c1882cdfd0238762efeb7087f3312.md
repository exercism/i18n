# À propos

C# propose plusieurs opérateurs pour manipuler les bits :

- [`&`][and-operator] : ET bit à bit
- [`|`][or-operator] : OU bit à bit
- [`~`][complement-operator] : complément bit à bit
- [`<<`][left-shift-operator] : décalage bit à bit vers la gauche
- [`>>`][right-shift-operator] : décalage bit à bit vers la droite
