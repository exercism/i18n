# Indices

## 1. Vérifie si l'action « Attaque rapide » est possible

- L'opérateur de négation logique (`!`) peut être placé devant une expression pour en inverser la valeur.
- Consulte [ce document][logical-operators] sur les opérateurs logiques

## 2. Vérifie si l'action « Espionner » est possible

- Les expressions logiques sont évaluées de gauche à droite, et l'on teste les éventuels « courts-circuits ».
- Pour bien comprendre ce mécanisme d'évaluation de gauche à droite, jette un œil à [cet article][operator-precedence].

## 3. Vérifie si l'action « Faire signe au prisonnier » est possible

- Les opérateurs logiques, par ordre de priorité décroissante : `!`, `&&`, `||`.
- Consulte [cet article][operator-precedence] sur la priorité des opérateurs

## 4. Vérifie si l'action « Libérer le prisonnier » est possible

- `()` est l'opérateur qui a la priorité la plus élevée. Utilise-le pour regrouper des expressions logiques.
