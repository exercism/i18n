# Introduction

## Enregistrements

Un enregistrement est une collection de champs (qui peuvent être de types différents) qui vont ensemble. Pour définir un enregistrement, on utilise le mot-clé `type`. Les champs d'un enregistrement sont définis entre les caractères `{` et `}`, et chaque champ a un nom _et_ un type. Pour créer un enregistrement, on spécifie les noms des champs et on leur affecte une valeur entre les caractères `{` et `}`. Tous les champs doivent recevoir une valeur lors de la création d'un enregistrement. On peut accéder aux valeurs des champs d'une instance d'enregistrement à l'aide de la notation avec point.

Lors de la définition ou de la création d'un enregistrement, chaque champ doit soit être sur une ligne séparée, soit être séparé par des points-virgules (`;`) lorsqu'il est sur une seule ligne.

```fsharp
// Define a record
type Address =
    { Street: string
      HouseNumber: int }

// Create a record
let oldAddress: Address =
    { Street = "Main Street"
      HouseNumber = 17 }

// Single-line alternative
type ConciseAddress = { Street: string; HouseNumber: int }
let conciseAddress: ConciseAddress = { Street = "Main Street"; HouseNumber = 17 }
```

Comme les enregistrements sont immuables, une fois qu'un enregistrement a été construit, les valeurs de ses champs ne peuvent plus jamais changer. Si tu souhaites modifier les valeurs d'un enregistrement, le mot-clé `with` te permet de créer une copie d'un enregistrement existant, mais avec de nouvelles valeurs pour un ou plusieurs champs.

```fsharp
// Copy the old address but change the house number
let newAddress: Address = { oldAddress with HouseNumber = 86 }
newAddress.Street      // => "Main Street"
newAddress.HouseNumber // => 86
```

Les enregistrements ont une _égalité structurelle_, ce qui signifie que deux instances du même enregistrement avec des valeurs identiques sont équivalentes.

En plus de pouvoir utiliser la notation avec point pour accéder aux champs d'un enregistrement, les enregistrements peuvent aussi être _déconstruits_ dans des liaisons et dans le filtrage par motif :

```fsharp
let myAddress: Address = { Street = "Broadway"; HouseNumber = 123 }
let { Street = myStreet; HouseNumber = myHouseNumber } = myAddress

match myAddress with
| { HouseNumber = 1 } -> printfn "First house"
| { HouseNumber = houseNumber; Street = street } -> printfn "House number %d on %s" houseNumber street
// => "House number 123 on Broadway
```
