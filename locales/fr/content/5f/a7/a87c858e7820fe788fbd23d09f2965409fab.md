# Tests

## Écris le code

Écris ton code dans `src/lib.cairo`.
Les exercices sont fournis avec un fichier squelette dans `src/lib.cairo`, qui te montrera les signatures du code que tu devras écrire.

Pour la plupart des exercices, il est préférable d'écrire tout ton code dans le fichier `src/lib.cairo`.
Si tu souhaites découper ta solution en plusieurs fichiers, consulte le [chapitre sur les modules][chapter-modules] de The Cairo Book.

[chapter-modules]: https://book.cairo-lang.org/ch07-02-defining-modules-to-control-scope.html

## Exécute les tests

Pour exécuter les tests, tu dois d'abord te placer dans le répertoire de l'exercice que tu veux tester : 

```bash
cd path/to/exercise
```

Puis exécute la commande suivante : 

```bash
scarb cairo-test
```

Par défaut, seul le premier test est activé.
Quand tu es prêt à passer au test suivant, retire l'attribut `ignore` du test suivant (`#[ignore]`).

Pour exécuter tous les tests, y compris ceux qui sont ignorés, tu peux retirer l'attribut `ignore` de tous les tests, ou simplement exécuter : 

```bash
scarb cairo-test --include-ignored
```

N'hésite pas à écrire le moins de code possible pour faire passer les tests.
Les échecs des tests te guideront vers ce qu'il faut écrire ensuite.

Comme Cairo vérifie tout le code à la compilation, il se peut que tes tests ne compilent pas tant que tu n'as pas écrit le code requis.
Même les tests marqués `ignore` sont vérifiés à la compilation.
Tu peux [mettre en commentaire][comments] les tests qui ne compilent pas en faisant commencer chaque ligne par `//`.
Ensuite, quand tu es prêt à travailler sur ce test, tu peux le décommenter.
Cairo dispose aussi d'une macro spéciale appelée `panic!()`, que tu peux utiliser sur les chemins de code inachevés pour que ton programme compile.

[comments]: https://book.cairo-lang.org/ch02-04-comments.html
