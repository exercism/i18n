# Tests

## Installe l'exécuteur de tests du parcours GDScript d'Exercism

Pour utiliser l'exécuteur de tests, tu dois avoir correctement [installé Godot][installation].

Pour compiler et tester des scripts GDScript pour Exercism, Godot sera lancé en mode « headless » depuis la CLI.
Ces instructions nécessitent pour l'instant Linux et bash.

### Étape 1 : installe l'infrastructure globale de l'exécuteur de tests

Pour préparer les tests, clone [https://github.com/exercism/gdscript-test-runner][gdscript-test-runner] et déplace son contenu vers `/opt/exercism/gdscript/test-runner/` :

```sh
git clone https://github.com/exercism/gdscript-test-runner.git
sudo mkdir -p /opt/exercism/gdscript/
sudo mv gdscript-test-runner/ /opt/exercism/gdscript/test-runner/
```

### Étape 2 : télécharge le script de l'exécuteur de tests pour un seul exercice

Si tu as bien configuré l'outil `exercism` et téléchargé au moins un exercice GDScript, un dossier `exercism/gdscript` a normalement été créé pour y ranger les exercices.
Enregistre [l'exécuteur de tests][test-local-gdscript-solution] dans ce dossier et rends le fichier exécutable, ou crée simplement un lien vers lui :

```sh
cd ~/exercism/gdscript # replace with your exercism/gdscript directory
ln /opt/exercism/gdscript/test-runner/bin/test-local-gdscript-solution.sh
```

## Lance les tests

Une fois les étapes d'installation terminées, tu peux partir de n'importe quel dossier d'exercice (par exemple `~/exercism/gdscript/two-fer`) et lancer le script (situé un niveau au-dessus, dans `../`) pour tester ta solution locale à cet exercice :

```sh
../test-local-gdscript-solution.sh
```
