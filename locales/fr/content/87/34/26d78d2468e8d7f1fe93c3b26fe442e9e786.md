# Configure l'outillage

Il y a trois éléments d'outillage que tu peux ajuster pour ton parcours :

- Le **[compteur de lignes de code](/docs/building/tooling/lines-of-code-counter)** : cet outil a pour rôle de compter les lignes de code de chaque itération soumise.
- L'**[extracteur de snippets](/docs/building/tooling/snippet-extractor)** : cet outil extrait un snippet pour chaque itération, qui est affiché sur le site.
- L'**[Exercism CLI](/docs/building/tooling/cli)** : cet outil est utilisé par les apprenants pour travailler sur un parcours en local, sur leur propre machine.

```exercism/note
Même si ajuster ces outils est facultatif, cela rendra l'intégration de ton parcours au site _bien_ meilleure.
C'est pourquoi on te conseille vivement d'ajuster les trois outils.
```
