# Instructions (complément)

## Mots

`find-fewest-coins ( coins target -- result )` renvoie un tableau de valeurs de pièces dont la somme vaut `target`. `coins` est un ensemble de hachage (par exemple `HS{ 1 5 10 25 }`) ; utilise les mots du vocabulaire `sets` (`members`, `in?`, …) pour le manipuler.

Quand aucune combinaison de `coins` ne permet d'obtenir `target`, lève une erreur `cannot-make-change`.
