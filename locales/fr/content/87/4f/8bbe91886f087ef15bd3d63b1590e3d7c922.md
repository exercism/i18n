# À propos des _strings_

Une [`string`][ref-string] en Kotlin est une séquence immuable de caractères Unicode.

[`Immutable`][wiki-immutable] signifie que toute opération sur une _string_ doit renvoyer une nouvelle _string_ : la _string_ d'origine ne peut jamais changer.

[`Unicode`][wiki-unicode] signifie que la plupart des systèmes d'écriture du monde peuvent être représentés, mais (contrairement à des langages plus anciens comme C) il n'y a pas de correspondance 1:1 entre les caractères et les octets.
Ce point sera approfondi dans le concept [`Chars`][concept-chars].

Une _string_ est entourée de guillemets doubles `" "`.

Certains caractères doivent être échappés : `\\`, ainsi que les caractères non imprimables habituels comme `\t` (tabulation) et `\n` (saut de ligne).

```kotlin
val s = "Escape backslash \\."
// Escape backslash \.
```

Les _strings_ multilignes sont entourées de 3 guillemets doubles et peuvent contenir du texte arbitraire (aucun échappement nécessaire).

```kotlin
val multi = """I'm a
    multi-line
    string with special characters \ \t """
//I'm a
//    multi-line
//    string with special characters  \ \t 
```

Utilise [trimIndent][trimIndent-doc] pour supprimer l'indentation commune des lignes.
C'est utile pour formater la _string_ :

```kotlin
val multi = """
    I'm a
      multi-line
    string""".trimIndent()

//I'm a
//  multi-line
//string
```

Sinon, [trimMargin][trimMargin-doc] te permet de spécifier un délimiteur.
Chaque ligne de la `String` commence alors après le délimiteur.
Le délimiteur par défaut est `|`, mais tu peux spécifier un autre délimiteur en paramètre.
Par exemple :

```kotlin
val multi = """
    |I'm a
    |  multi-line
    |string""".trimMargin()

//I'm a
//  multi-line
//string

val multi2 = """
    start>I'm a
    start>  multi-line
    start>string""".trimMargin("start>")

//I'm a
//  multi-line
//string
```

Les _strings_ peuvent être concaténées avec `+`, mais mieux vaut s'en tenir aux cas courts et simples.
Il existe d'autres options, souvent meilleures.

## _String templates_

[`Templates`][ref-templates] désigne ce que d'autres langages appellent « interpolation ».

Si une _string_ contient un signe dollar `$`, suivi d'un identifiant, ou contient des accolades (`{expression}`) autour d'une expression, ceux-ci sont remplacés respectivement par la valeur ou le résultat de l'expression.

```kotlin
val x = 42
val st = "x is $x, x squared is {x * x}"
// x is 42, x squared is 1764
```

## Formatage des _strings_

Sur la plateforme JVM (uniquement), `String.format()` permet un formatage plus précis que les _string templates_, avec une [syntaxe][web-formats] similaire à celle des fonctions [`printf`][wiki-printf] (_très anciennes !_).

```kotlin
String.format("%s %.3f", "π ≈", 3.14159)
//π ≈ 3.142
```

## Fonctions sur les _strings_

Kotlin fournit _de nombreuses_ [`functions`][ref-string-functions] pour manipuler les _strings_.

La plupart du temps, ce sont des [`extensions functions`][ref-extensions] plutôt que des membres de la classe `String`, même si cela a peu d'incidence sur la façon dont on les utilise.

~~~~exercism/note
Les pages de [documentation][ref-string-functions] assez complexes de Kotlin masquent les fonctions d'extension dans la vue par défaut.
Au moment de la rédaction de ce document, le contenu le plus précieux est masqué dans un onglet nommé `Members & Extensions`.
Clique dessus pour déplier cette section et voir tous les membres et extensions disponibles sur la classe `String`.

[ref-string-functions]: https://kotlinlang.org/api/core/kotlin-stdlib/kotlin/-string/
~~~~

L'exemple suivant ne montre qu'une petite sélection de ce qui est disponible :

```kotlin
val str = "Hello World!"

str.length              // => 12 (a property, not a function)
str.elementAt(6)        // => W
str.elementAtOrNull(20) // => null (index out of range)
str.substring(6, 11)    // => "World"
str.substringAfter(" ") // => "World!"

str.lowercase()         // => "hello world!"
str.uppercase()         // => "HELLO WORLD!"

str.startsWith("Hel")   // => true
str.endsWith("xyz")     // => false
str.indexOf("0")        // => 4

str.toCharArray()       // => [H, e, l, l, o,  , W, o, r, l, d, !]
"42".toInt() + 1        // => 43  (parsing; see also toFloat)

"Howdy!  ".trim()       // => "Howdy"
```

## Construis une _string_

Il arrive qu'une longue _string_ doive être construite par étapes, par exemple dans une boucle.

Concaténer des _strings_ avec `+` devient vite ni élégant ni performant : l'immuabilité implique qu'il y a _beaucoup_ de copie à effectuer.

Kotlin propose plusieurs façons plus efficaces de combiner plusieurs _strings_ :

- _String templates_, décrits ci-dessus.
- [`joinToString()][ref-jointostring], qui sera abordé dans le concept [Tableaux][concept-lists].
- Le [`StringBuilder`][ref-stringbuilder] de Java, qui n'est pas considéré comme particulièrement idiomatique en Kotlin.
- Le [`buildString()`][ref-buildstring] de Kotlin, qui encapsule `StringBuilder` dans une syntaxe plus concise et idiomatique.
Il prend la logique de construction de _strings_ comme argument lambda, ce qui sera abordé dans un concept ultérieur.

En substance, un `StringBuilder` est une structure de type tableau, avec de nombreuses méthodes pratiques.
Voici une petite sélection :

- [`append()`][ref-sb-append] pour ajouter à la fin.
- [`insert()`][ref-sb-insert] pour ajouter à une position donnée.
- [`deleteAt()`][ref-sb-deleteat] et [`deleteRange()`][ref-sb-deleterange] pour supprimer à une ou plusieurs positions données.
- `toString()` pour convertir en une _string_ normale à la fin : tout concaténer en une seule opération performante.

```kotlin
// Available, not recommended
val sb = StringBuilder()
sb.append("Hello ")
sb.append("World!")
sb.toString()
//Hello World!
```

Un exemple avec `buildString()`, utilisant une syntaxe abordée dans des concepts ultérieurs :

```kotlin
val countDown = buildString {
    for (i in 5 downTo 1) {
        append(i)
        append("_")
    }
}
// countDown is "5_4_3_2_1_"
```
