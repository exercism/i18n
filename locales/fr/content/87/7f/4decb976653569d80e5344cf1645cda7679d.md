# Indices

## Général

- Une fonction peut être définie de façon à prendre plusieurs arguments empaquetés ensemble, en utilisant le paramètre `*args` pour des arguments de type `list` et `tuple`, ou le paramètre `**kwargs` pour des arguments de type dictionnaire ou nommés.
- Pour empaqueter ou dépaqueter, utilise l'opérateur `*` ou `**`.

## 1. Crée une liste de tous les wagons

- Plusieurs arguments dans les paramètres d'une fonction peuvent être empaquetés avec l'opérateur `*args`.

## 2. Répare la liste des wagons

- Le dépaquetage avec l'opérateur `*` permet d'extraire les deux premiers éléments d'une `list` tout en gardant le reste intact.
- Pour ajouter une autre `list` à une `list` existante, tu peux utiliser l'opérateur `*` pour « étaler » la `list`.

## 3. Ajoute les arrêts manquants

- Utiliser `**kwargs` comme paramètre de fonction permet de passer un nombre arbitraire d'arguments nommés.
- Utiliser `**<dict>` comme argument dépaquette un dictionnaire en arguments nommés.
- Tu peux placer des arguments nommés dans un `{}` ou un `dict()`.
- Pour récupérer les valeurs d'un dictionnaire, tu peux utiliser la méthode `<dict>.values()`.

## 4. Étends les informations d'itinéraire

- Utiliser `**<dict>` comme argument dépaquette un dictionnaire en arguments nommés.
- Tu peux placer des arguments nommés dans un `{}` ou un `dict()`.

## 5. Répare le dépôt de wagons

- `zip(*iterators)` permet de transposer une `list` imbriquée.
- Pour extraire des données d'itérateurs issus de `zip`, tu peux utiliser une boucle _for_.
- Tu peux aussi dépaqueter des itérateurs issus de `zip` avec `*`.
  `[*content] = zip(iterator_1, iterator_2)` décompresse le `tuple` produit par `zip()` en une `list`.
