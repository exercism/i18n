# Instructions

C'est une nouvelle nuit bien chargée à la gare de triage d'Anvers. Tu es le régulateur de service : les wagons de marchandises qui arrivent doivent être regroupés en trains au départ, les attelages inspectés, les itinéraires séparés aux jonctions et le fret identique regroupé pour la facturation.

Chaque *wagon* est une _string_ qui indique ce qu'il transporte :
`"coal"`, `"timber"`, `"crates"`, etc.

## 1. Atteler des wagons en trains

Définis `couple` pour qu'elle prenne un tableau de wagons et une longueur `n`, et renvoie des trains de `n` wagons qui ne se chevauchent pas. Le dernier train peut être plus court si le total ne se divise pas de manière égale.

```factor
{ "coal" "coal" "coke" "ore" "ore" "timber" "timber" } 3 couple .
! => { { "coal" "coal" "coke" } { "ore" "ore" "timber" } { "timber" } }
```

## 2. Jeter un œil aux attelages

Définis `peek-couplings` pour qu'elle prenne un tableau de wagons et renvoie chaque paire adjacente, afin que l'inspecteur puisse examiner chaque attelage.

```factor
{ "coal" "ore" "timber" "crates" } peek-couplings .
! => { { "coal" "ore" } { "ore" "timber" } { "timber" "crates" } }
```

## 3. Séparer la rame aux jonctions

Définis `split-at-junctions` pour qu'elle prenne un tableau de wagons et un tableau de `junctions` (les wagons qui marquent un point de rupture), et renvoie les tronçons entre les wagons de jonction. Les wagons de jonction eux-mêmes ne sont pas conservés.

```factor
{ "coal" "coal" "switch" "ore" "switch" "timber" }
{ "switch" } split-at-junctions .
! => { { "coal" "coal" } { "ore" } { "timber" } }
```

## 4. Regrouper le fret identique

Définis `coalesce-cargo` pour qu'elle prenne un tableau de wagons et regroupe en séries les wagons *consécutifs* qui transportent le même fret.

```factor
{ "coal" "coal" "ore" "ore" "ore" "timber" "coal" } coalesce-cargo .
! => { { "coal" "coal" } { "ore" "ore" "ore" } { "timber" } { "coal" } }
```
