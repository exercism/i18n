# Instructions supplémentaires

## Implémentation

Tu dois renvoyer les anagrammes dans le même ordre que celui dans lequel elles sont listées parmi les mots candidats.

Contrairement à d'autres parcours, la version Go de l'exercice inclut des cas de test qui utilisent des caractères UTF-8 (non-ASCII) dans les _strings_.
Cependant, avec la prise en charge native d'UTF-8 de Go assurée par le type `rune`, cela ne devrait pas trop te déranger.
