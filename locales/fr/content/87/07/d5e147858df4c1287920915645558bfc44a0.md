# Introduction

C'est un sujet potentiellement _vaste_ ! Il est possible d'écrire un long livre à ce propos, et plusieurs personnes l'ont fait (cherche « unicode book » sur Amazon pour en voir quelques exemples).

## Un très bref historique

La gestion des caractères dans les ordinateurs était bien plus simple il y a quelques décennies, quand les programmeurs partaient du principe que l'anglais était la seule langue importante. Donc : 26 lettres, majuscules et minuscules, 10 chiffres, quelques signes de ponctuation, plus un code (0x07) pour faire sonner une cloche, et tout tenait sur 7 bits : le jeu de caractères [ASCII][wiki-ascii].

Naturellement, les gens ont commencé à demander ce qu'il en était de à, ä et Ł, puis d'autres ont demandé pour ऄ, ஹ et ญ, et les jeunes voulaient des emojis 😱. Que faire ?

Pour faire court, beaucoup de personnes intelligentes et patientes ont dû siéger dans des comités pendant des années, pour mettre au point les détails du jeu de caractères [Unicode][web-unicode] et des encodages comme [UTF-8][wiki-utf-8], et beaucoup de logiciels ont eu besoin d'une réécriture _très_ compliquée. Et beaucoup de nouveaux bugs ont été introduits.

Pour éviter que _tout_ ne casse, la conception d'Unicode/UTF-8 garantit que les 127 premiers codes sont identiques à l'ASCII _(même la cloche)_.

## Les caractères en Kotlin

Les langages conçus après 2005 environ ont l'énorme avantage qu'une norme Unicode raisonnablement stable existait déjà.

Kotlin (sorti pour la première fois en 2011) a pu partir du principe que ses utilisateurs emploieraient diverses langues (humaines), et auraient besoin d'Unicode pour les exprimer.

Les littéraux de caractère s'écrivent entre guillemets simples, et se distinguent des _strings_ écrites entre guillemets doubles. C'est probablement évident pour les personnes qui viennent du monde C/C++, mais potentiellement déroutant pour les programmeurs Python et JavaScript.

```kotlin
val a = 'a'
a::class.qualifiedName  // => kotlin.Char
a.code  // => 97

val jha = 'झ'  // Devanagari alphabet
jha.code  // => 2333

val heart = '❤'  // heart emoji
heart.code  // => 10084

Char.MAX_VALUE.code  // => 65535 (64k, the largest code point allowed)
```

La conversion entre `Char` et `Int` est simple :

```kotlin
a.code  // => 97  (a.toInt() is deprecated)
Char(97) // => 'a'
```

Le compilateur autorise _certaines_ formes d'arithmétique entière sur les `Char` :

```kotlin
'a' + 5       // => 'f'
'c' - 'a'   // => 2
'c' + 'a'   // => error!

'f' + ('A' - 'a')  // => 'F' (same as 'f'.uppercase()

'f'.dec() // => 'e' (decrement)
'f'.inc() // => 'g' (increment)
```

## Quelques fonctions pour `Char`

Comme toujours, il y a bien trop de [fonctions][ref-char-lib] pour qu'on puisse les aborder toutes ici, il ne s'agit donc que d'une sélection.

- Pour les alphabets qui s'y prêtent, change la casse avec [`uppercase()`][ref-uppercase] et [`lowercase()`][ref-lowercase].
- Teste la casse avec [`isUpperCase()`][ref-isuppercase] et [`isLowerCase()`][ref-islowercase].
- Teste le type de caractère avec :
    - [`isLetter()`][ref-isletter], couvre de nombreux alphabets
    - [`isDigit()`][ref-isdigit], dans la plage 0..9
    - `isLetterOrDigit()`, combine les deux précédentes
    - [`isWhitespace()`][ref-iswhitespace], n'importe quel caractère d'espacement

```kotlin
'झ'.isLetter()      // => true
'A'.isLowerCase()   // => false
'4'.isDigit()       // => true
'\t'.isWhitespace() // => true  (tab character)
```

## Conversions entre les listes de `Char` et les _strings_

Pour passer d'une _string_ à une liste de `Char`, on peut utiliser `toList()`.

Pour passer d'une liste de `Char` à une _string_, il y a la fonction [`joinToString()`][ref-jointostring], qui prend un séparateur (souvent la _string_ vide) en argument.

```kotlin
val kt = "kotlin".toList()  // => [k, o, t, l, i, n]
kt.joinToString("")   // => "kotlin"
kt.joinToString("_")  // => "k_o_t_l_i_n"
```

Note que `joinToString()` opère sur une List ou un Array. Pour _caster_ un seul `Char` en _string_ d'un caractère, utilise `toString()`.

```kotlin
'a'.toString() // => "a"
```

Pour vérifier si un caractère est présent dans une `String`, ou dans une liste ou un tableau de `Char`, on dispose de `in`, qui correspond à la fonction [`contains()`][ref-contains].

```kotlin
val clist = "kotlin".toList()  // => [k, o, t, l, i, n]
't' in clist     // => true
't' in "kotlin"  // => true
```
