# Indices

## 1. Convertis une note numérique en note alphabétique

- Utilise une [expression `if-then-else`][jq-man-if] avec autant de branches `elif` que nécessaire.

## 2. Compte le nombre d'étudiants pour chaque note alphabétique

- Le filtre `reduce` a besoin d'un _stream_ sur lequel itérer.
  L'entrée est un objet.
  Utilise l'expression `to_entries` pour transformer l'objet en tableau.
- L'objet résultat doit avoir toutes les notes alphabétiques possibles comme clés, même si aucun étudiant n'a obtenu cette note.
- L'[affectation `+=`][jq-man-arith-assign] sera utile.

[jq-man-if]: https://jqlang.org/manual/#if-then-else-end
[jq-man-arith-assign]: https://jqlang.org/manual/#arithmetic-update-assignment
