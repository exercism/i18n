# Indices

## 1. Définis le type externe `GbTree`

- Les types externes peuvent être définis avec la syntaxe `pub type TypeName(a, b, c)`.

## 2. Définis la fonction `new_gb_tree`

- Les fonctions externes peuvent être définies avec la syntaxe `@external(erlang, "module", "function")`.
- La fonction doit utiliser `gb_trees:empty/0`.

## 3. Définis la fonction `insert`

- Consulte la documentation de `gb_trees:insert/3` pour confirmer le bon ordre des arguments.
- La fonction externe peut être une fonction privée qui est appelée par la fonction `insert` afin de changer l'ordre des arguments.
- La fonction doit utiliser `gb_trees:insert/3`.

## 4. Définis la fonction `delete`

- Consulte la documentation de `gb_trees:delete_any/2` pour confirmer le bon ordre des arguments.
- La fonction externe peut être une fonction privée qui est appelée par la fonction `delete` afin de changer l'ordre des arguments.
- La fonction doit utiliser `gb_trees:delete_any/2`.
- La fonction `gb_trees:delete/2` plante si la clé n'est pas trouvée, donc elle ne doit pas être utilisée.
