# Introduction

Le type `Option` est utilisé pour représenter des valeurs qui peuvent être absentes ou présentes.

Il est défini dans le module `gleam/option` comme suit :

```gleam
type Option(a) {
  Some(a)
  None
}
```

Le constructeur `Some` est utilisé pour encapsuler une valeur lorsqu'elle est présente, et le constructeur `None` est utilisé pour représenter l'absence d'une valeur.

On accède souvent au contenu d'une `Option` par filtrage par motifs.

```gleam
import gleam/option.{type Option, None, Some}

pub fn say_hello(person: Option(String)) -> String {
  case person {
    Some(name) -> "Hello, " <> name <> "!"
    None -> "Hello, Friend!"
  }
}
```

```gleam
say_hello(Some("Matthieu"))
// -> "Hello, Matthieu!"

say_hello(None)
// -> "Hello, Friend!"
```

Le module `gleam/option` définit également plusieurs fonctions utiles pour manipuler les types `Option`, comme `unwrap`, qui renvoie le contenu d'une `Option` ou une valeur par défaut si elle vaut `None`.

```gleam
import gleam/option.{type Option}

pub fn say_hello_again(person: Option(String)) -> String {
  let name = option.unwrap(person, "Friend")
  "Hello, " <> name <> "!"
}
```
