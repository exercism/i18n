# Introduction

`List` est très semblable à un `Array`. Il y a cependant des différences majeures que tu ne veux surtout pas rater :

1. On ne peut pas accéder aux éléments d'une liste par leur indice avec des crochets, c'est-à-dire `[0]`.
2. On ne peut pas initialiser une liste.
3. Il n'existe pas de compréhensions de listes.
4. On peut modifier librement les éléments d'une liste pendant qu'on la parcourt.

`List` fait partie du _package_ `haxe.ds`, donc chaque fois que tu veux utiliser des listes, tu dois importer son _package_ :

```haxe
import haxe.ds.List;

class Main {
  static function main() {
    var myList = List<Int>();

    for (i in 0...5) {
      myList.add(i);
    }

    trace(myList); // {0, 1, 2, 3, 4}
  }
}
```
