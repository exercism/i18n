# Instructions supplémentaires

## Mots

Définis un tuple `rat` avec des emplacements `numerator` et `denominator`.
`<rat>` doit réduire ses arguments à leur plus simple expression, avec le
signe sur le numérateur (ainsi, un dénominateur est toujours positif).

- `<rat> ( numerator denominator -- rat )`. Construit un rationnel réduit.
- `>rat ( pair -- rat )`. Construit un `rat` à partir de `{ numerator denominator }`.
- `rat>pair ( rat -- pair )`. Renvoie `{ numerator denominator }`.
- `r+ ( a b -- c )`, `r- ( a b -- c )`, `r* ( a b -- c )`,
  `r/ ( a b -- c )`. Arithmétique sur deux rationnels.
- `r-abs ( a -- |a| )`. Valeur absolue.
- `r^ ( a n -- a^n )`. Élève un rationnel à une puissance entière
  (exposants négatifs autorisés).
- `real^r ( x a -- y )`. Élève un nombre réel à un exposant rationnel
  et renvoie un nombre décimal.

Les génériques `MATH:` de Factor (`+`, `-`, `*`, `/`) ne s'appliquent qu'à
la hiérarchie mathématique intégrée, c'est pourquoi cet exercice utilise des
mots dédiés plutôt que des méthodes sur ces génériques.
