# Instructions

Dans cet exercice, on va traiter des lignes de log.

Chaque ligne de log est une _string_ au format suivant : `"[<LEVEL>]: <MESSAGE>"`.

Il existe trois niveaux de log différents :

- `INFO`
- `WARNING`
- `ERROR`

Tu as trois tâches à accomplir ; chacune prend une ligne de log et te demande d'en faire quelque chose.

## 1. Récupère le message d'une ligne de log

Implémente la méthode (_static_) `LogLine.Message()` pour renvoyer le message d'une ligne de log :

```csharp
LogLine.Message("[ERROR]: Invalid operation")
// => "Invalid operation"
```

Les espaces blancs au début et à la fin doivent être supprimés :

```csharp
LogLine.Message("[WARNING]:  Disk almost full\r\n")
// => "Disk almost full"
```

## 2. Récupère le niveau de log d'une ligne de log

Implémente la méthode (_static_) `LogLine.LogLevel()` pour renvoyer le niveau de log d'une ligne de log, qui doit être renvoyé en minuscules :

```csharp
LogLine.LogLevel("[ERROR]: Invalid operation")
// => "error"
```

## 3. Reformate une ligne de log

Implémente la méthode (_static_) `LogLine.Reformat()` qui reformate la ligne de log, en plaçant le message en premier et le niveau de log après, entre parenthèses :

```csharp
LogLine.Reformat("[INFO]: Operation completed")
// => "Operation completed (info)"
```
