# Introduction

Les `Integer` peuvent contenir n'importe quel nombre, quelle que soit sa taille, dans la limite de la mémoire de ta machine, tandis que `Int` correspond à l'ensemble des entiers positifs et négatifs qui peuvent être représentés sur 32 ou 64 bits (garanti au moins de -2^29 à 2^29).

`Float` correspond à l'ensemble des nombres réels, limité par la précision de l'ordinateur.
Les opérations définies sur les nombres fonctionnent généralement sur l'un ou l'autre de ces types, mais pas sur les deux à la fois.

Les fonctions permettant de convertir entre `Float` et `Integer` incluent, entre autres, `toFloat`, qui convertit un `Int`/`Integer` en `Float`, et `ceiling`, qui convertit un `Float` en `Int`.

La conversion d'un type entier (`Int` ou `Integer`) vers n'importe quel autre type numérique se fait avec la fonction `fromIntegral`.
Le type cible est déduit automatiquement.
Par exemple :

```haskell
n :: Integer
n = 6
x :: Float
x = fromIntegral n      --> x = 6.0

m :: Int
m = 7
y :: Double
y = fromIntegral m      --> y = 7.0
```
