# Introduction

La déstructuration permet de décomposer des valeurs composées en Rust. On l'utilise souvent pour extraire des champs de tuples ou de structures.

Par exemple, l'extrait de code ci-dessous récupère deux valeurs d'un tuple :

```rust
let (first, second) = (1, 2);
```

La valeur `1` est liée à la variable `first`.
La valeur `2` est liée à la variable `second`.
