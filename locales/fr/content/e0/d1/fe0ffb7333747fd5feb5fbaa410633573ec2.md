## 1. Vérifie la criticité

- Les opérateurs de comparaison ([comparaisons][comparisons review]) et les opérations booléennes ([concept:python/bools]()) peuvent être combinés et utilisés avec des conditions.
- Les expressions conditionnelles doivent être évaluées à `True` ou `False`.
- `else` peut être utilisé pour un bloc de code qui s'exécute lorsque tous les tests conditionnels renvoient `False`.

  ```python
     >>> item = 'blue'
     >>> item_2 = 'green'
     
     >>>  if len(item) >= 3 and len(item_2) < 5:
            print('Both pass the test!')
          elif len(item) >= 3 or len(item_2) < 5:
            print('One passes the test!')
          else:
            print('None pass the test!')
    ...
    One passes the test!
  ```

## 2. Détermine la plage de puissance produite

- Les opérateurs de comparaison peuvent être combinés et utilisés avec des conditions.
- Un nombre quelconque d'instructions `elif` peut être utilisé comme « branches » de décision.
- Chaque « branche » peut avoir son propre `return`, même si les outils de lint peuvent le considérer comme une « mauvaise pratique ».
- Si le linter se plaint, envisage d'affecter la sortie d'une branche à une variable commune, puis de la renvoyer avec `return`.
