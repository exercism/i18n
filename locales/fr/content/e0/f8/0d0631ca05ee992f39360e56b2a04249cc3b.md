# Exemple

```riscvasm
.equ FRAME_SIZE, 16

.text
.global is_triple
```

Les lignes qui commencent par un point sont des _directives_ : des instructions destinées à l'assembleur, et non au processeur.
`.equ` donne le nom `FRAME_SIZE` au nombre 16.
`.text` indique que ce qui suit est du code.
`.global` rend le label `is_triple` visible en dehors de ce fichier, afin que le reste du code puisse l'appeler.
Tu peux aussi rencontrer `.globl`, qui veut dire la même chose.

```riscvasm
/* bool is_triple(unsigned a, unsigned b, unsigned c); */
is_triple:
```

`is_triple` vérifie si `a² + b² = c²`, et renvoie 1 dans ce cas, 0 sinon.
Par exemple, `(6, 8, 10)` donne 1, car `36 + 64 = 100`.
Le label `is_triple` marque l'endroit où commence la fonction.
Elle est appelée avec `a`, `b` et `c` dans les registres `a0`, `a1` et `a2`.

```riscvasm
        addi    sp, sp, -FRAME_SIZE
        sw      ra, 12(sp)      /* save the return address */
        sw      a1, 8(sp)       /* save b */
        sw      a2, 4(sp)       /* save c */
```

Le registre `ra` contient l'_adresse de retour_, l'endroit où revenir dans l'appelant lorsque l'on a terminé.
Chaque `call` écrase `ra`, donc on commence par le sauvegarder sur la _pile_.
La pile grandit vers le bas, vers des adresses plus petites, donc soustraire 16 au pointeur de pile `sp` nous réserve 16 octets.
(`sp` doit toujours être un multiple de 16.)
On sauvegarde aussi `b` et `c`, car une fonction qu'on appelle a le droit de modifier les registres `a`.

```riscvasm
        call    square          /* a0 = a * a */
        sw      a0, 0(sp)       /* save a * a */
```

`a` est déjà dans `a0`, là où `square` attend son entrée.
`call` place `ra` sur l'instruction suivante et saute vers `square`, qui renvoie son résultat dans `a0`.

```riscvasm
        lw      a0, 8(sp)       /* a0 = b */
        call    square          /* a0 = b * b */
        lw      t0, 0(sp)       /* t0 = a * a */
        add     t0, t0, a0      /* t0 = a * a + b * b */
        sw      t0, 0(sp)       /* save a * a + b * b */
```

On recharge `b` depuis la pile, on l'élève au carré, puis on l'ajoute à `a * a`.

```riscvasm
        lw      a0, 4(sp)       /* a0 = c */
        call    square          /* a0 = c * c */
        lw      t0, 0(sp)       /* t0 = a * a + b * b */
        sub     a0, t0, a0      /* a0 = a * a + b * b - c * c */
        seqz    a0, a0          /* a0 = 1 if that is zero, otherwise 0 */
```

La différence est nulle exactement quand `a² + b² = c²`.
`seqz` (« set if equal to zero ») transforme cela en 1 ou en 0.

```riscvasm
        lw      ra, 12(sp)      /* restore the return address */
        addi    sp, sp, FRAME_SIZE
        ret
```

On restaure `ra` et on rend les 16 octets de pile.
`ret` saute alors vers l'adresse contenue dans `ra`, de retour vers l'appelant.

```riscvasm
/* unsigned square(unsigned n); */
square:
        mul     a0, a0, a0      /* n * n */
        ret
```

`square` n'appelle aucune autre fonction, donc `ra` reste intact et il n'y a rien à sauvegarder.
Elle n'est pas marquée `.global`, car seul `is_triple` l'utilise.
