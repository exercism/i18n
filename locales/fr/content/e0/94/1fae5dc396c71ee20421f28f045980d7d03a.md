# Installation

Rends-toi sur [le wiki de `jq`][jq-wiki-install] pour les instructions d'installation.

## Informations sur la version

En juin 2025, la version actuelle de jq est la version **1.8**.
C'est la version utilisée par l'exécuteur de tests en ligne de jq.

De nombreux gestionnaires de paquets Linux installent une version plus ancienne, la version 1.6.
Il vaut mieux installer manuellement une version plus récente ; de nombreux changements bénéfiques sont apparus depuis la sortie de la v1.6 en 2018.

[jq-wiki-install]: https://github.com/jqlang/jq/wiki/Installation
