# Instructions

Dans cet exercice, on va vérifier les permissions des comptes utilisateurs d'un forum internet. Le forum prend en charge trois permissions différentes :

- Read
- Write
- Delete

Il existe trois types de comptes, chacun avec des permissions par défaut différentes :

- Guests : peuvent lire les publications.
- Users : peuvent lire et écrire des publications.
- Moderators : peuvent lire, écrire et supprimer des publications, ils ont toutes les permissions.

Parfois, les permissions individuelles peuvent être modifiées : on peut par exemple donner à un compte invité la permission d'écrire des publications, ou révoquer toutes les permissions d'un compte, ce qui le laisserait sans aucune permission.

## 1. Obtiens les permissions par défaut pour un type de compte

Commence par définir une énumération `AccountType` pour représenter les trois types de comptes : `Guest`, `User` et `Moderator`.

Ensuite, définis une énumération `Permission` pour représenter les trois types de permissions : `Read`, `Write` et `Delete`, ainsi que deux valeurs supplémentaires : `All` pour avoir toutes les permissions et `None` pour n'en avoir aucune.

Implémente ensuite la méthode (_static_) `Permissions.Default()` qui renvoie les permissions par défaut d'un type de compte donné :

```csharp
Permissions.Default(AccountType.Guest)
// => Permission.Read
```

## 2. Accorde une permission

Implémente la méthode (_static_) `Permissions.Grant()` qui accorde (ajoute) une permission :

```csharp
Permissions.Grant(current: Permission.None, grant: Permission.Read)
// => Permission.Read
```

## 3. Révoque une permission

Implémente la méthode (_static_) `Permissions.Revoke()` qui révoque (retire) une permission :

```csharp
Permissions.Revoke(current: Permission.Read, revoke: Permission.Read)
// => Permission.None
```

## 4. Vérifie la présence d'une permission

Implémente la méthode (_static_) `Permissions.Check()` qui prend les permissions actuelles du compte et vérifie si le compte est autorisé pour une permission donnée :

```csharp
Permissions.Check(current: Permission.Write, check: Permission.Read)
// => false
```
