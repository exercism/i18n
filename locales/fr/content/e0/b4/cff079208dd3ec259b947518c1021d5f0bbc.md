# Introduction

En Java, le littéral `null` est utilisé pour désigner l'absence de valeur.

Tous les types de données primitifs en Java ont une valeur par défaut et ne peuvent donc jamais être `null`. Par convention, ils commencent par une lettre minuscule, par exemple `int`.

Les types de référence contiennent l'adresse mémoire d'un objet et peuvent avoir une valeur `null`. Ils commencent généralement par une lettre majuscule, par exemple `String`.

Tenter d'affecter une valeur `null` à une variable de type primitif provoque une erreur de compilation, car la variable contient toujours une valeur primitive du type qui lui est affecté.

```java
//Throws compile time error stating the required type is int, but null was provided
int number = null;
```

Affecter une valeur `null` à une variable de référence ne provoque pas d'erreur de compilation, car les variables de référence peuvent être `null`.

```java
//No error will occur as the String variable str is nullable
String str = null;
```
