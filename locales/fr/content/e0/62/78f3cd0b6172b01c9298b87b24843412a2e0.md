# N'utilise pas la division ni le modulo

Comme le mentionnent les instructions, le but de cet exercice est de construire un crible d'Ératosthène sans utiliser des opérations telles que la division ou le modulo.
Reporte-toi au [lien Wikipédia](https://en.wikipedia.org/wiki/Sieve_of_Eratosthenes) pour une description de l'algorithme.

Construire le crible d'Ératosthène dans un langage immuable comme Elm peut sembler un peu artificiel, mais c'est un bel algorithme, inventé il y a plus de deux millénaires, qui vaut la peine d'être appris et implémenté correctement.
