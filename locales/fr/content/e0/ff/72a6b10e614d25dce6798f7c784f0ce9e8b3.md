# Introduction

Une boucle `for` permet d'exécuter du code de façon répétée, en boucle, jusqu'à ce qu'une condition soit remplie.

```csharp
for (int i = 0; i < 5; i++)
{
    System.Console.Write(i);
}

// => 01234
```

Une boucle `for` se compose de quatre parties :

1. L'initialisation : elle est exécutée une seule fois, avant d'entrer dans la boucle. Elle sert généralement à définir les variables utilisées dans la boucle.
2. La condition : elle est évaluée avant chaque itération de la boucle. La boucle continue de s'exécuter tant que cette condition vaut `true`.
3. L'itérateur : il est exécuté après chaque itération de la boucle. Il sert généralement à modifier (souvent : incrémenter ou décrémenter) la ou les variables de la boucle.
4. Le corps : le code qui est exécuté à chaque itération de la boucle.
