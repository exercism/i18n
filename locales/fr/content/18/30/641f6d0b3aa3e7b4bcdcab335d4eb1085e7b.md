# À propos

Les [paramètres variadiques][variadic-parameters] permettent à une fonction d'accepter zéro ou plusieurs valeurs d'un type donné pour un seul paramètre.
On définit un paramètre variadique en ajoutant trois points (`...`) à l'annotation de type du paramètre.

À l'intérieur du corps de la fonction, Swift rend ces valeurs disponibles sous la forme d'un tableau du type spécifié :

```swift
import Foundation

func geometricMean(_ numbers: Double...) -> Double {
    var total = 1.0
    for number in numbers {
        total *= number
    }
    return pow(total, 1.0 / Double(numbers.count))
}

let result = geometricMean(1, 2, 3, 4, 5)
// result is 2.605171084697352
```

~~~~exercism/note
Si une fonction comporte des paramètres supplémentaires après un paramètre variadique, le premier paramètre qui suit le paramètre variadique **doit** avoir une étiquette d'argument explicite, pour que Swift sache où se termine la liste d'arguments variadiques.
~~~~
