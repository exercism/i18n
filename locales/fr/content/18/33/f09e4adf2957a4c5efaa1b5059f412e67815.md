# Instructions complémentaires

## Indexation à partir de zéro

Rappelle-toi que, si l'on a coutume de compter à partir de 1 (autrement dit, « le 6ᵉ nombre premier est 13 »), de nombreux langages de programmation, dont Rust, utilisent une indexation à partir de 0 (autrement dit, `primes[5] == 13`). Utilise une indexation à partir de zéro pour ton implémentation.
