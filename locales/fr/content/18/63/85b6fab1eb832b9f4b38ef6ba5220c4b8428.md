# Booléens

Swift possède un type appelé [`Bool`][bools], qui sert à représenter les valeurs `true` et `false`.

## Opérateurs logiques

Swift possède 3 [opérateurs logiques (`!`, `||`, `&&`)][logical-operators] qui servent à combiner des booléens pour former des expressions produisant des valeurs différentes.

### Et (`&&`)

En Swift, l'[opérateur _et_][and] est représenté par `&&` et renvoie `true` si les deux valeurs fournies sont `true`, sinon il renvoie `false`.
Lorsqu'on utilise l'opérateur _et_, on place un booléen à droite du `&&` et un autre à gauche.

```Swift
true && true  // true
true && false // false
```

### Ou (`||`)

En Swift, l'[opérateur _ou_][or] est représenté par `||` et renvoie `true` si **au moins une** des valeurs fournies est `true` ; si les deux valeurs sont `false`, il renvoie `false`.
Lorsqu'on utilise l'opérateur _ou_, on place un booléen à droite du `||` et un autre à gauche.

```swift
true || true   // true
true || false  // true
false || false // false
```

### Non (`!`)

En Swift, l'[opérateur _non_][not] est représenté par `!` et renvoie `true` si le booléen fourni est `false`, et `false` si c'est `true` qui lui est fourni.
Lorsqu'on utilise l'opérateur _non_, on place un booléen après l'opérateur (`!`).

```swift
!true  // false
!false // true
```

## Utilise des parenthèses (`()`)

Quand on travaille avec des booléens, on peut utiliser des [parenthèses explicites][explicit-parentheses] pour décider quels booléens évaluer en premier.
Le résultat peut différer selon la façon dont les parenthèses sont utilisées.
En Swift, ce qui est entre parenthèses est évalué en premier.

```swift
true && false && false || true   // true
true && false && (false || true) // false
```

Comme ce qui est entre parenthèses est évalué en premier, dans l'exemple suivant, l'opérateur _non_ s'applique à l'expression entre parenthèses.

```Swift
!true && false   // false
!(true && false) // true
```

~~~~exercism/note
Tu ne dois utiliser des parenthèses que lorsqu'elles changent le résultat ; sinon, il vaut mieux les omettre.
~~~~
