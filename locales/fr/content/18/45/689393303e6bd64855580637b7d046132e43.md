# Débogue en local

Lorsque tu exécutes les tests du parcours Bash avec [Bats](https://github.com/bats-core/bats-core), Bats capture à la fois STDOUT et STDERR pour les assertions de sortie.

```exercism/caution
Cela fonctionne en local avec `bats`, mais **pas** dans l'éditeur en ligne d'Exercism.
```

Si tu veux afficher des messages de débogage sans affecter le résultat des tests, écris-les dans le descripteur de fichier (fd) 3.

```bash
echo 'debug message' >&3
```

Bats affiche ce qui est écrit dans fd 3 pendant l'exécution des tests, mais n'inclut pas cette sortie dans des assertions comme `assert_output`.

Exemple d'exécution :

```none
$ bats hello_world.bats
hello_world.bats
 ✓ Say Hi!
debug message
1 test, 0 failures
```

C'est utile quand tu exécutes les tests en local.
