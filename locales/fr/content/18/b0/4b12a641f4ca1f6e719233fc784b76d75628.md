# Instructions

Tu travailles dans une boutique de mode en ligne.
Tu as l'idée d'une fonctionnalité du site pour suggérer des tenues à l'utilisateur.
On s'intéresse aux tenues possibles, à leurs prix, et à la façon d'éliminer les associations qui ne vont pas ensemble.

~~~~exercism/note
S'il existe plusieurs façons de résoudre les problèmes qui suivent, tous peuvent être résolus avec une compréhension.
~~~~

## 1. Crée un vêtement


Implémente `clothingitem()` pour qu'elle prenne deux `Tuple`, l'un de `categories` et l'autre des `qualities` correspondantes.
La fonction doit renvoyer un `Dict` dont les `categories` sont les clés et les `qualities` les valeurs.

```julia-repl
julia> categories = ("item_name", "price", "color", "base_color");

julia> qualities = ("Descriptive Name", 99.00, "Ochre Red", "red");

julia> clothingitem(categories, qualities)
Dict{String, Any} with 4 entries:
  "price"      => 99.0
  "item_name"  => "Descriptive Name"
  "base_color" => "red"
  "color"      => "Ochre Red"
```

Ta fonction doit pouvoir gérer n'importe quel nombre de `categories`.

## 2. Suggère des combinaisons

Implémente `get_combinations()` pour qu'elle prenne un `Tuple` de hauts et un `Tuple` de bas.
La fonction doit renvoyer le `cartesian product` des tuples sous forme de tableau à deux dimensions (c'est-à-dire une `Matrix`).
Chaque entrée est une combinaison `(top, bottom)` sous la forme d'un `Tuple`.
Les hauts varient le long des lignes, les bas varient le long des colonnes.

```julia-repl
julia> tops = (
        Dict("item_name" => "Dress shirt"),
        Dict("item_name" => "Casual shirt")
        );

julia> bottoms = (
        Dict("item_name" => "Jeans"),
        Dict("item_name" => "Dress trousers")
       );

julia> get_combinations(tops, bottoms)
2×2 Matrix{Tuple{Dict{String, String}, Dict{String, String}}}:
 (Dict("item_name"=>"Dress shirt"), Dict("item_name"=>"Jeans"))   (Dict("item_name"=>"Dress shirt"), Dict("item_name"=>"Dress trousers"))
 (Dict("item_name"=>"Casual shirt"), Dict("item_name"=>"Jeans"))  (Dict("item_name"=>"Casual shirt"), Dict("item_name"=>"Dress trousers"))
```

## 3. Additionne les prix des tenues

Chaque pièce de vêtement possède un champ `price` qui lui est associé, il peut donc être utile de pouvoir comparer le prix total des tenues.
Implémente `get_prices()`, qui prend un tableau de combinaisons de vêtements.
La fonction doit renvoyer un tableau de forme identique, avec les prix des tenues à leurs positions respectives.

```julia-repl
julia> tops = (
        Dict("item_name" => "Dress shirt", "base_color" => "blue", "price" => 35),
        Dict("item_name" => "Casual shirt", "base_color" => "black", "price" => 20)
       );

julia> bottoms = (
        Dict("item_name" => "Jeans", "base_color" => "blue", "price" => 30),
        Dict("item_name" => "Dress trousers", "base_color" => "black", "price" => 75)
       );

julia> combomatrix = get_combinations(tops, bottoms);

julia> get_prices(combomatrix)
2×2 Matrix{Int}::
 65  110
 50   95

julia> filteredmatrix = filter_clashing(combomatrix)
1-element Vector{Tuple{Dict{String, Any}, Dict{String, Any}}}:
 (Dict("price" => 20, "item_name" => "Casual shirt", "base_color" => "black"), Dict("price" => 30, "item_name" => "Jeans", "base_color" => "blue"))

julia> get_prices(filteredmatrix)
1-element Vector{Int}:
 50
```

## 4. Élimine les tenues qui ne vont pas ensemble

Chaque pièce de vêtement possède un champ `base_color`.
Utilise ce champ pour supprimer toutes les combinaisons où le haut et le bas ont la même couleur de base.
Implémente `filter_clashing()` pour qu'elle prenne un tableau de combinaisons de vêtements.
Renvoie un tableau à une dimension (c'est-à-dire un `Vector`) contenant les combinaisons correspondantes.

```julia-repl
julia> tops = (
        Dict("item_name" => "Dress shirt", "base_color" => "blue", "price" => 35),
        Dict("item_name" => "Casual shirt", "base_color" => "black", "price" => 20)
       );

julia> bottoms = (
        Dict("item_name" => "Jeans", "base_color" => "blue", "price" => 30),
        Dict("item_name" => "Dress trousers", "base_color" => "black", "price" => 75)
       );

julia> combos = get_combinations(tops, bottoms);

julia> filter_clashing(combos)
1-element Vector{Tuple{Dict{String, Any}, Dict{String, Any}}}:
 (Dict("price" => 20, "item_name" => "Casual shirt", "base_color" => "black"), Dict("price" => 30, "item_name" => "Jeans", "base_color" => "blue"))
```
