# Indices

## Général

- Chaque tâche est un mot unique dont le corps est composé de mots de manipulation de pile du vocabulaire `kernel` : aucun calcul n'est nécessaire.
- Utilise `.s` dans l'écouteur pour afficher toute la pile pendant tes essais.

## 1. Échange les deux caisses du haut

- Un seul mot de manipulation de pile inverse les deux valeurs du haut : `swap`.

## 2. Enlève la caisse renversée

- `drop` supprime la valeur du haut ; les deux caisses en dessous restent intactes.

## 3. Garde une copie de la caisse du dessous

- `over` copie la deuxième valeur de la pile sur le dessus.

## 4. Range le jeu

- Amène la caisse du bas en haut avec `rot`, jette-la avec `drop`, duplique le nouveau sommet avec `dup`, puis `rot` à nouveau pour remettre les pièces dans l'ordre. Trace la pile mot par mot : `x y z` → `y z x` → `y z` → `y z z` → `z z y`.
