# Introduction

Un `vector` en Clojure est une collection séquentielle, indexée et immuable de zéro ou plusieurs valeurs. Cela signifie qu'une fois qu'un vecteur a été créé, il ne peut plus être modifié. Les fonctions qui manipulent des vecteurs renvoient un nouveau vecteur, tandis que le vecteur d'origine reste inchangé. Les valeurs d'un vecteur peuvent être de types hétérogènes. On peut définir des vecteurs comme suit :

```clojure
(def empty [])
(def single-value [5])
```

On peut récupérer les éléments d'un vecteur à l'aide d'un indice. Les vecteurs de Clojure sont indexés à partir de zéro, ce qui signifie que l'indice du premier élément est toujours zéro :

```clojure
(def numbers [2 3 5])
;; Read value from vector
(get numbers 2)
;;=> 5
;; Update value in vector
(assoc numbers 2 9)
;;=> [2 3 9]
```

Le vecteur d'origine reste inchangé :

```clojure
numbers
;;=> [2 3 5]
```

Pour mémoriser la valeur mise à jour, il faut la transmettre ou la capturer dans une var :

```clojure
(def updated-numbers
  (assoc numbers 2 9))
(get updated-numbers 2)
;;=> 9
```
