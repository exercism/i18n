# Indices

## 1. Calcule le taux d'intérêt

- Par défaut, tout nombre à virgule flottante défini dans du code Go est traité comme un `float64`.
  Comme le type de retour de la fonction `InterestRate` est `float32`, aucune conversion de type n'est nécessaire.

## 2. Calcule les intérêts

- Pour calculer les intérêts, il peut être utile de remarquer que `InterestRate` renvoie un pourcentage.
- On peut utiliser la fonction définie dans la tâche précédente (`InterestRate`) pour calculer les intérêts.
- Il peut être nécessaire de convertir le résultat de `InterestRate` en `float64`.

## 3. Calcule la mise à jour annuelle du solde

- Pour calculer la mise à jour annuelle du solde, utilise les fonctions définies dans les étapes précédentes.

## 4. Calcule le nombre d'années avant d'atteindre le solde souhaité

- Pour calculer le nombre d'années, on peut continuer à répéter jusqu'à atteindre le solde souhaité grâce à une [boucle `for`](https://gobyexample.com/for).
- Il existe un [opérateur](https://golang.org/ref/spec#IncDec_statements) spécial pour incrémenter une valeur de 1.
