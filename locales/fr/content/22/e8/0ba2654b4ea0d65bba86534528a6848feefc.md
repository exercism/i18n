# À propos

[Reason](https://reasonml.github.io/) est une syntaxe et une chaîne d'outils conçues pour les développeurs JavaScript, basées sur le langage fonctionnel [OCaml](https://ocaml.org/)

Étant typé statiquement, Reason est probablement plus sûr que JavaScript, mais il dispose d'une inférence de types puissante, ce qui signifie que les annotations de type ne te gênent pas.

Les exercices Exercism se compileront directement en JS, mais Reason peut être compilé via la chaîne d'outils OCaml en code natif, iOS, Android, et même des [microcontrôleurs](http://www.algo-prog.info/ocapic/web/index.php?id=ocapic)
