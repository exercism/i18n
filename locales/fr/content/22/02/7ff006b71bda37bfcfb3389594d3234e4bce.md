# À propos

En Gleam, un tableau est une collection immuable de zéro ou plusieurs valeurs. Les valeurs d'un tableau doivent toutes avoir le même type. Comme les tableaux sont immuables, une fois qu'un tableau a été construit, sa valeur ne peut plus jamais changer. Les fonctions ou opérateurs qui semblent modifier un tableau (comme l'ajout d'un élément) renvoient en réalité un nouveau tableau.

Un tableau peut se définir comme suit :

```gleam
let empty = []
let singleValue = [5]
let threeValues = ["a", "b", "c"]
```

La façon la plus courante d'ajouter un élément à un tableau est de le placer en tête avec la syntaxe de propagation :

```gleam
let two_to_four = [2, 3, 4]
let one_to_four = [1, ..two_to_four]
// -> [1, 2, 3, 4]
```

Le module [`gleam/list`](https://hexdocs.pm/gleam_stdlib/gleam/list.html) de la bibliothèque standard de Gleam contient de nombreuses fonctions utiles pour travailler avec les tableaux. Ce module est très couramment utilisé dans le code Gleam, il est donc bon de bien le connaître.

Les motifs de tableau s'utilisent dans les expressions `case` pour filtrer des tableaux et affecter à des variables les valeurs qu'ils contiennent :

```gleam
pub fn describe(list: List(String)) -> String {
  case list {
    [] -> "Empty list"
    [x] -> "List with one item: " <> x
    [x, y] -> "List with two items: " <> x <> " and " <> y
    _ -> "List with three or more items"
  }
}
```

En plus de filtrer des tableaux de longueur exacte, la syntaxe de propagation permet de filtrer des tableaux d'au moins une certaine longueur :

```gleam
pub fn describe(list: List(String)) -> String {
  case list {
    [_, _, ..] -> "List with at least two items"
    [_] -> "List with one item"
    [] -> "Empty list"
  }
}
```

La syntaxe de propagation permet aussi d'affecter le reste du tableau à une variable :

```gleam
pub fn remove_first_item(list: List(String)) -> List(String) {
  case list {
    // Return the list without the first item
    [_, ..rest] -> rest

    // There's no first item to remove, return an empty list
    _ -> []
  }
}
```

Une expression `case` doit avoir un motif pour chaque valeur possible du type filtré, c'est pourquoi on utilise souvent un motif de rejet (`_`) en dernier pour gérer les valeurs restantes.
