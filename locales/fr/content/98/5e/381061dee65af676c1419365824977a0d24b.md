# Instructions

Dans cet exercice, tu vas travailler sur un planificateur de rendez-vous pour un salon de beauté à New York, ouvert le 15 septembre 2012.

## 1. Analyse la date d'un rendez-vous

Implémente la méthode `AppointmentScheduler.schedule()` pour analyser une représentation textuelle d'une date de rendez-vous et la convertir en `LocalDateTime` correspondant :

```java
AppointmentScheduler scheduler = new AppointmentScheduler();
scheduler.schedule("7/25/2019 13:45:00");
// => LocalDateTime.of(2019, 7, 25, 13, 45, 0)
```

## 2. Vérifie si un rendez-vous est déjà passé

Implémente la méthode `AppointmentScheduler.hasPassed()` qui prend une date de rendez-vous et vérifie si le rendez-vous se situe quelque part dans le passé :

```java
AppointmentScheduler scheduler = new AppointmentScheduler();
scheduler.hasPassed(LocalDateTime.of(1999, 12, 31, 9, 0, 0));
// => true
```

## 3. Vérifie si le rendez-vous a lieu l'après-midi

Implémente la méthode `AppointmentScheduler.isAfternoonAppointment()` qui prend une date de rendez-vous et vérifie si le rendez-vous a lieu l'après-midi (>= 12:00 et < 18:00) :

```java
AppointmentScheduler scheduler = new AppointmentScheduler();
scheduler.isAfternoonAppointment(LocalDateTime.of(2019, 03, 29, 15, 0, 0))
// => true
```

## 4. Décris l'heure et la date du rendez-vous

Implémente la méthode `AppointmentScheduler.getDescription()` qui prend une date de rendez-vous et renvoie une description de cette date et de cette heure :

```java
AppointmentScheduler scheduler = new AppointmentScheduler();
scheduler.getDescription(LocalDateTime.of(2019, 03, 29, 15, 0, 0))
// => "You have an appointment on Friday, March 29, 2019, at 3:00 PM."
```

## 5. Renvoie la date anniversaire

Implémente la méthode `AppointmentScheduler.getAnniversaryDate()` qui renvoie la date anniversaire de cette année, à savoir le 15 septembre :

```java
AppointmentScheduler scheduler = new AppointmentScheduler();
scheduler.getAnniversaryDate()
// => LocalDate.of(<current year>, 9, 15)
```
