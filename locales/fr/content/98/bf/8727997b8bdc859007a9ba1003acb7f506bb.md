# Instructions

Dans cet exercice, tu vas écrire du code pour t'aider à préparer l'achat d'un véhicule.

Cet exercice comporte trois tâches : déterminer si tu as besoin d'un permis, t'aider à choisir entre deux véhicules, et estimer le prix acceptable pour un véhicule d'occasion.

## 1. Détermine si tu auras besoin d'un permis de conduire

Certains types de véhicules nécessitent un permis de conduire pour être utilisés.
Suppose que seuls les types `"car"` et `"truck"` nécessitent un permis, et que tout le reste peut être utilisé sans permis.

Implémente la fonction `needsLicense(kind)` qui prend le type de véhicule et renvoie un booléen indiquant si tu as besoin d'un permis pour ce type de véhicule.

```kotlin
needsLicense("car")
// => true

needsLicense("bike")
// => false

needsLicense("truck")
// => true
```

## 2. Choisis entre deux véhicules potentiels à acheter

Tu évalues les véhicules disponibles.
Tu arrives à réduire ton choix à deux options, mais tu as besoin d'aide pour prendre la décision finale.
Pour cela, implémente la fonction `chooseVehicle(option1, option2)` qui prend deux véhicules en arguments et renvoie une décision qui inclut l'option qui arrive en premier dans l'[ordre lexicographique][lexicographical-order].

```kotlin
chooseVehicle("Wuling Hongguang", "Toyota Corolla")
// => "Toyota Corolla is clearly the better choice."

chooseVehicle("Volkswagen Beetle", "Volkswagen Golf")
// => "Volkswagen Beetle is clearly the better choice."
```

## 3. Calcule une estimation du prix d'un véhicule d'occasion

Maintenant que tu as pris ta décision, tu veux t'assurer d'obtenir un prix correct chez le concessionnaire.
Comme tu cherches à acheter un véhicule d'occasion, le prix dépend de l'âge du véhicule.
Pour une estimation approximative, suppose que si le véhicule a moins de 3 ans, il coûte 80 % du prix d'origine qu'il avait lorsqu'il était neuf.
S'il a au moins 10 ans, il coûte 50 %.
Si le véhicule a au moins 3 ans mais moins de 10 ans, il coûte 70 % du prix d'origine.

Implémente la fonction `calculateResellPrice(originalPrice, age)` qui applique cette logique à l'aide de `if`, `else if` et `else` (il existe d'autres façons de faire si tu veux t'entraîner).
Elle prend le prix d'origine et l'âge du véhicule en arguments et renvoie le prix estimé chez le concessionnaire.

```kotlin
calculateResellPrice(1000, 1)
// => 800

calculateResellPrice(1000, 5)
// => 700

calculateResellPrice(1000, 15)
// => 500
```

[lexicographical-order]: https://en.wikipedia.org/wiki/Lexicographic_order
