# Instructions supplémentaires

## Except

La valeur de retour de la fonction `guess` est de type `Except String Result`.

Un [`Except ε α`][except] représente un calcul qui peut soit aboutir à une erreur de type `ε`, soit donner une valeur de type `α`.
C'est une monade, ce qui permet de composer ce genre de calculs.

## Programmation réactive

Pour des raisons pratiques, cet exercice ne nécessite pas une approche de programmation réactive.
Envisage plutôt d'implémenter une [machine à états finis][finite-state-machine].
