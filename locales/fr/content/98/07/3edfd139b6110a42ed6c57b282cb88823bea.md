# Introduction

Un hash est un type de données en Perl : il contient une collection non ordonnée de clés _string_ associées à des valeurs scalaires.

On remplit généralement une variable de type hash en lui affectant un tableau, par exemple `my %scores = (Alice => 10, Bob => 15, Charlie => 20);`.

Les éléments d'un tableau sont généralement séparés par des virgules, mais tu verras souvent ce qu'on appelle la « virgule grasse » `=>`, utilisée pour séparer les clés et les valeurs dans un tableau.
Son comportement est presque identique à celui d'une virgule, mais elle a l'avantage supplémentaire d'interpréter l'élément qui se trouve à sa gauche comme un _string_.

Un hash peut aussi être rempli en affectant une valeur à chaque clé individuellement, par exemple `$scores{Alice} = 10;`.

On accède aux valeurs d'un hash en indiquant les clés au moyen d'un indice, par exemple `$scores{Bob} # 15`.

Les clés d'un hash sont uniques.
Si une clé est donnée plusieurs fois, seule la dernière valeur donnée est conservée.

## Fonctions

Parmi les fonctions qui permettent de manipuler les hashes, on trouve [keys][keys] et [values][values], qui récupèrent les parties correspondantes d'un hash sous forme de tableau.
Les tableaux renvoyés par les fonctions [keys][keys] et [values][values] peuvent être utiles aux fonctions qui manipulent des tableaux telles que [grep][grep], [map][map] et [sort][sort], ainsi qu'aux boucles [for][for].

Les autres fonctions liées aux hashes incluent [exists][exists], qui vérifie si une clé existe dans un hash (même si sa valeur est `undef`), et [delete][delete], qui supprime une clé d'un hash.

## Variation des sigils

Lorsqu'on récupère des valeurs d'un hash, c'est le sigil utilisé qui détermine le résultat.
C'est l'indice `{}` placé à la fin du nom de la variable qui indique à Perl que tu accèdes à un hash portant ce nom.

```perl
my %names = (Alice => 10, Bob => 15, Charlie => 20);

$names{Alice}; # 10            <- A scalar
@names{Alice}; # (10)          <- A slice (with only one key, this probably isn't what you want. There will be a warning.)
%names{Alice}; # ('Alice', 10) <- A key/index + value slice

$names{'Bob', 'Charlie'}; #                            <- An error (disabled syntax for an ancient feature.)
@names{'Bob', 'Charlie'}; # (15, 20)                   <- A slice
%names{'Bob', 'Charlie'}; # ('Bob', 15, 'Charlie', 20) <- A key/index + value slice
```

Même si c'est autorisé, il est recommandé, pour la lisibilité, de ne pas donner le même nom à des variables de types différents.
