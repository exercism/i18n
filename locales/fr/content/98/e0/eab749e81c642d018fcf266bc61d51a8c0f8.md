# Annexe aux instructions

## Mots

`classify ( n -- str )` renvoie l'une des _strings_ `"perfect"`, `"abundant"` ou `"deficient"`.

## Erreurs

Quand l'entrée vaut zéro ou est négative, lève la _string_

```
"Classification is only possible for positive integers."
```

(tel quel, y compris le point final).
