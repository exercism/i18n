# Les constructeurs de _string_

Un `STR` ne change jamais. Donc `+` ne peut rien y ajouter : il doit fabriquer un _string_ entièrement nouveau qui reprend le contenu des deux.

Une fois, ça va. Dans une boucle, ce n'est plus le cas :

```sather
   -- don't
   script ::= "";
   loop
      script := script + lines.elt!;
   end;
```

À chaque tour, tout ce qui a été construit jusque-là est copié dans un nouveau _string_ et l'ancien est jeté. Dix lignes, cela fait dix copies, chacune plus longue que la précédente. Cent lignes, cent copies. Le travail augmente avec le *carré* du nombre de lignes, et une boucle qui semblait inoffensive devient la partie lente du programme.

## FSTR

`FSTR` est un _string_ qui *peut* être modifié : un **constructeur de _string_**. Y ajouter du contenu écrit en général simplement dans la place dont il dispose déjà, si bien qu'une boucle sur cent lignes fait à peu près le travail de cent lignes plutôt que cent copies.

```sather
   script ::= #FSTR;
   loop
      script := script + lines.elt!;
   end;
   return script.str;
```

Trois choses à remarquer.

**`#FSTR` en crée un vide.** `#FSTR(100)` en crée un avec de la place pour cent caractères déjà réservée, ce qui vaut la peine quand on connaît la taille.

**Tu dois réaffecter le résultat.** `script := script + ...`, jamais `script + ...` tout seul. En général, le résultat est le même constructeur que celui de départ, mais quand il n'a plus de place, c'en est un nouveau, plus grand, et ignorer le résultat te laisserait écrire dans l'ancien.

**`.str` à la fin.** Une routine qui promet `: STR` doit renvoyer un `STR`, et `.str` en fabrique un à partir du constructeur.

## Ce qu'on peut ajouter

`+` sur un `FSTR` accepte un _string_, un caractère, un nombre entier ou un booléen, donc il n'y a en général pas besoin de convertir au préalable :

```sather
   line ::= #FSTR;
   line := line + 1 + ". " + "Enter" + '!';   -- "1. Enter!"
```

## Les retours à la ligne

`"\n"` dans un _string_ est un retour à la ligne : un seul caractère, écrit avec deux.

```sather
   script := script + "Enter" + "\n" + "Exit";
```
