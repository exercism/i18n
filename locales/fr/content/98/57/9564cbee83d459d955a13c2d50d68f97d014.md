# Indices

## 1. Définis l'approbation

- On peut définir des types personnalisés avec la syntaxe `pub type Name { Variant1 }`.

## 4. Définis l'activité

- On peut définir des types personnalisés contenant des données avec la syntaxe `pub type Name { Variant1(SomeType) }`.

## 5. Note l'activité

- On peut faire du filtrage par motif sur les variantes d'un type personnalisé avec des expressions case.
- Si tu veux ajouter une condition supplémentaire à un motif, tu peux ajouter une garde à ce motif grâce au mot-clé `if`.
