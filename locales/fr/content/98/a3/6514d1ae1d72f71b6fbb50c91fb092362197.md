# Introduction

Par défaut, les valeurs en C# sont _mutables_, c'est-à-dire qu'elles peuvent changer au fil du temps. Pour rendre une valeur _immuable_, il y a deux options :

1. Ajoute le modificateur `const`
2. Ajoute le modificateur `readonly`

Le modificateur `const` présente quelques restrictions :

1. Il ne peut être appliqué qu'à des types « constants » : les _strings_, les booléens et les nombres.
1. La valeur `const` doit être initialisée immédiatement.

Si la valeur est d'un type non constant ou si tu dois initialiser la valeur dans un constructeur, `readonly` peut être utilisé pour garantir l'immuabilité.
