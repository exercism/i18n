# Complément d'instructions

## Mots

Définis un tuple `custom-set` et déclare-le comme une instance du _mixin_ `set`
avec `INSTANCE: custom-set set`.

- `<custom-set> ( -- set )` : construit un ensemble vide.
- `>custom-set ( seq -- set )` : construit un ensemble à partir d'une séquence,
  en supprimant silencieusement les doublons.

Fournis ensuite des méthodes `M:` (issues de `sets`) sur `members`, `in?`,
`adjoin` et `set-like` pour `custom-set`. Une fois la déclaration `INSTANCE:`
et ces quatre méthodes en place, `null?`, `union`, `intersect`, `diff`,
`subset?`, `set=` et `intersects?` du vocabulaire `sets` fonctionnent tous sur
ton ensemble grâce aux implémentations par défaut du protocole. Les tests
appellent directement ces mots.

`adjoin ( elt set -- )` modifie l'ensemble sur place en ajoutant `elt` à `set`
s'il n'y est pas déjà présent.
