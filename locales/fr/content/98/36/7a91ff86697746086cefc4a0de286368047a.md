# Indices

Cet exercice est centré sur un type composite défini par un mot-clé, avec des unions de types.

## 1. Définis des unions de types

- Regarde l'exemple dans l'introduction où un type est nommé.

## 2. Implémente le type composite Player

- Tous les champs doivent être *annotés avec des types*, deux d'entre eux avec des unions de types.
- Regarde l'exemple `Node` dans l'introduction pour un exemple concret de champs annotés avec des types.
- Tous les champs doivent avoir les valeurs par défaut listées dans les instructions.

## 3. Présente-toi

- Un [opérateur ternaire][control-flow] peut être utilisé pour une solution en une ligne.
- La fonction `ismissing` est utile ici.

## 4. Implémente les méthodes d'incrément

- Les arguments des méthodes doivent être annotés avec les types corrects pour `name` et `mana`.
- Tu trouveras d'autres exemples de signatures de fonctions et d'annotations d'arguments dans l'introduction.
- Les [opérateurs ternaires][control-flow] peuvent aussi être utilisés ici pour des solutions en une ligne.
- Il peut être utile d'étudier ou de revoir le concept sur `Multiple Dispatch` si nécessaire.

## 5. Implémente la fonction title

- Utilise la fonction `increment`.
- Un [opérateur ternaire][control-flow] peut être utilisé pour une solution en une ligne.

## 6. Implémente la fonction revive

- Utilise la fonction `increment`.
- Renvoie un joueur modifié s'il était mort, ou un joueur non modifié s'il était vivant.


[control-flow]: https://docs.julialang.org/en/v1/manual/control-flow/#man-conditional-evaluation
