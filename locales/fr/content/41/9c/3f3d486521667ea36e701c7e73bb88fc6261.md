# Introduction

Les `Complex numbers` ne sont pas compliqués.
Ils ont juste besoin d'un nom moins effrayant.


Ils sont si utiles, surtout en ingénierie et en science, que Python inclut [`complex`][complex] comme type numérique standard, aux côtés des entiers ([`int`s][ints]) et des nombres à virgule flottante ([`float`s][floats]).


Une valeur `complex` en Python est essentiellement une paire de nombres à virgule flottante :

```python
>>> my_complex = 5.443+6.77j
(5.443+6.77j)
```

On les appelle les parties « réelle » et « imaginaire ».
Tu as peut-être entendu dire que « `i` (ou `j`) est la racine carrée de -1 ».
Pour l'instant, tout cela signifie simplement que la partie imaginaire satisfait _par définition_ l'égalité `1j * 1j == -1`.
C'est une idée simple, mais elle mène à des conséquences mathématiques intéressantes.

En Python, la partie « imaginaire » se note `j` (_et non `i` comme dans les manuels de mathématiques_), et
le `j` doit suivre immédiatement un nombre, pour éviter que Python ne le prenne pour un nom de variable :


```python
>>> j
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
NameError: name 'j' is not defined

>>> 1j
1j

>>> type(1j)
<class 'complex'>
```


Il y a deux façons courantes de créer des nombres complexes.

1) Le constructeur [`complex(real, imag)`][complex] prend deux paramètres de type `float` :

    ```python
    >>> z1 = complex(1.5, 2.0)
    >>> z1
    (1.5+2j)
    ```

    Le constructeur peut aussi analyser une _string_ en entrée.
    Cela présente la curieuse limitation d'échouer si la _string_ contient des espaces.

    ```python
    >>> complex('4+2j')
    (4+2j)
    
    >>> complex('4 + 2j')
    Traceback (most recent call last):
      File "<stdin>", line 1, in <module>
    ValueError: complex() arg is a malformed string
    ```


2) Le nombre complexe peut être écrit sous forme de littéral `<real part> + <complex part>j`, ou simplement `<complex part>j` si la partie réelle est nulle :


    ```python
    >>> z2 = 2.0 + 1.5j
    >>> z2
    (2+1.5j)
    ```
    Le résultat final est identique à celui obtenu avec le constructeur `complex()`.


## Arithmétique

La plupart des [`operators`][operators] utilisés avec les nombres à virgule flottante et les entiers fonctionnent aussi avec les nombres complexes.

La division entière n'est _**pas**_ possible sur les nombres complexes, donc les opérateurs `//` et `%` et la fonction `divmod()` échoueront pour le type complexe.

Expliquer les règles de multiplication et de division des nombres complexes sort du cadre de ce concept (_et il est peu probable que tu aies souvent à effectuer ces opérations « à la main »_).

N'importe quelle introduction [mathématique][math-complex] ou d'[ingénierie électrique][engineering-complex] aux nombres complexes couvrira ces scénarios, si tu veux creuser le sujet.

La bibliothèque standard de Python contient un module [`math`][math-module] rempli de fonctionnalités utiles pour travailler avec des nombres réels, et le module [`cmath`][cmath] est son équivalent pour travailler avec des nombres complexes.
