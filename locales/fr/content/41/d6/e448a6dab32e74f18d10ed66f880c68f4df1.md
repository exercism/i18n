# À propos

La bibliothèque standard d'Elixir propose quatre modules différents pour manipuler les dates et les heures, chacun avec sa propre structure.

- Le [module `Date`][date]. Une structure `Date` peut être créée avec le _sigil_ [`~D`][sigil-d].
    ```elixir
    ~D[2021-01-01]
    ```

- Le [module `Time`][time]. Une structure `Time` peut être créée avec le _sigil_ [`~T`][sigil-t].
    ```elixir
    ~T[12:00:00]
    ```

- Le [module `NaiveDateTime`][naivedatetime] pour les dates et heures sans fuseau horaire. Une structure `NaiveDateTime` peut être créée avec le _sigil_ [`~N`][sigil-n].
    ```elixir
    ~N[2021-01-01 12:00:00]
    ```

- Le [module `DateTime`][datetime] pour les dates et heures avec un fuseau horaire. Utiliser ce module pour des fuseaux horaires autres que UTC nécessite une dépendance externe, une base de données de fuseaux horaires. Une structure `DateTime` peut être représentée avec le _sigil_ [`~U`][sigil-u], mais il est préférable de la créer avec les fonctions de `DateTime`.
    ```elixir
    DateTime.new!(~D[2021-01-01], ~T[12:00:00], "Etc/UTC")
    # => ~U[2021-01-01 12:00:00Z]
    ```

## Comparaisons

Pour comparer des dates ou des heures entre elles, cherche une fonction `compare` ou `diff` dans le module correspondant. Les opérateurs de comparaison comme `==`, `>` et `<` _semblent_ fonctionner, mais ils ne font pas une comparaison sémantique correcte pour ces structures.

```elixir
Date.compare(~D[2020-11-30], ~D[2020-12-01])
# => :lt

Time.diff(~T[13:45:00], ~T[13:46:30])
# => -90
```

## Décalage

On peut décaler les dates, les heures et les dates et heures vers l'avant ou vers l'arrière dans le temps grâce à la fonction `add/2` du module correspondant.

```elixir
# add 4 days
Date.add(~D[2021-01-01], 4)
# => ~D[2021-01-05]

# subtract 1 second
Time.add(~T[12:00:00], -1)
# => ~T[11:59:59.000000]

# add 4 days and 30 seconds
NaiveDateTime.add(~N[2021-01-01 12:00:00], 4 * 24 * 60 * 60 + 30)
# => ~N[2021-01-05 12:00:30]
```

## Conversions

Une structure `NaiveDateTime` peut être décomposée en une structure `Date` et une structure `Time` avec [`NaiveDateTime.to_date/1`][naivedatetime-to-date] et [`NaiveDateTime.to_time/1`][naivedatetime-to-time]. L'opération inverse est possible avec [`NaiveDateTime.new!/2`][naivedatetime-new].

```elixir
NaiveDateTime.to_date(~N[2021-01-01 12:00:00])
# => ~D[2021-01-01]

NaiveDateTime.to_time(~N[2021-01-01 12:00:00])
# => ~T[12:00:00]

NaiveDateTime.new!(~D[2021-01-01], ~T[12:00:00])
# => ~N[2021-01-01 12:00:00]
```
