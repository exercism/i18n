# Structures

Les structures rassemblent un ensemble fixe et hétérogène de données en une seule unité. En Rust, les structures présentent les propriétés suivantes :

- Chaque type de structure porte un nom particulier.
- Chaque membre d'une structure est appelé un **champ**.
- Chaque champ d'une structure porte un nom particulier.
- La visibilité est gérée champ par champ : chaque champ peut être public, privé ou autre, indépendamment des autres[^1].

# Aperçu des structures

Les structures sont définies à l'aide du mot-clé `struct`, suivi du nom du type que la structure décrit.
Ce nom peut ensuite être suivi d'accolades (pour une structure classique), de parenthèses (pour une structure tuple) ou d'un point-virgule (pour une structure unitaire).

```rust
struct Item {}
```

D'autres types sont ensuite intégrés au corps de la structure en tant que _champs_ de cette structure, chacun avec son propre type :

```rust
struct Item {
    name: String,
    weight: f32,
    worth: u32,
}
```

Enfin, on peut définir des méthodes sur les structures à l'intérieur d'un bloc `impl` :

```rust
impl Item {
    // initializes and returns a new instance of our Item struct
    fn new() -> Self {
        todo!()
    }
}
```

# Les formes de structures

Les structures se présentent sous trois formes : les structures à champs nommés (les structures classiques), les structures tuple et les structures unitaires.

Les structures ressemblent beaucoup aux **tuples**. En fait, la seule différence entre les structures et les tuples concerne ce qui est anonyme. La forme générale est la suivante :

- Les structures sont nommées et possèdent des champs nommés :

  ```rust
  struct Foo {
      bar: Bar,
      bat: Bat,
  }
  ```

  On accède aux champs par leur nom :

  ```rust
  let bar = foo.bar;
  ```

- Les structures tuple sont nommées et possèdent des champs anonymes :

  ```rust
  Foo(Bar, Bat)
  ```

  On accède aux champs par déstructuration ou par indice numérique :

  ```rust
  // unpacking
  let (bar, bat) = foo;
  ```

  ```rust
  // numeric index
  let bar = foo.0;
  let bat = foo.1;
  ```

- Les tuples sont anonymes et possèdent des champs anonymes :

  ```rust
  (Bar, Bat)
  ```

  Comme pour les structures tuple, on accède aux champs par déstructuration ou par indice numérique.

- Les structures anonymes sont, comme leur nom l'indique, anonymes, mais avec des champs nommés. Tu les as peut-être déjà rencontrées dans d'autres langages, comme Go ou Java. Elles n'existent pas en Rust ; il est considéré comme idiomatique d'utiliser un tuple à la place.

# Les types de taille nulle

Une structure peut avoir autant ou aussi peu de champs que nécessaire. Cela implique qu'il est légal pour une structure de n'avoir aucun champ. Une structure sans champ est appelée un **type de taille nulle** et bénéficie d'un traitement particulier de la part du compilateur : les types de taille nulle (souvent abrégés en **ZSTs**) ne consomment jamais d'espace sur la pile ni sur le tas, même quand on pourrait s'attendre à ce qu'ils le fassent. Par exemple, `Box<T>` n'alloue aucune mémoire sur le tas si `T` est un ZST.

On peut utiliser la syntaxe des structures classiques ou des structures tuple pour écrire un ZST :

```rust
// declaration
struct Foo {}
// instantiation
let foo = Foo {}
```

```rust
// declaration
struct Foo();
// instantiation
let foo = Foo();
```

Il existe aussi une notation abrégée pour les ZST :

```rust
// declaration
struct Foo;
// instantiation
let foo = Foo;
```

En général, lorsqu'on écrit un ZST, la notation abrégée est préférée, car on ne peut pas mélanger les styles : le style utilisé pour déclarer un ZST[^2] est celui qui est requis pour l'instancier.

Après tout ce que nous avons dit sur la syntaxe des ZST, voyons pourquoi on pourrait bien vouloir d'une telle chose. Un ZST ne peut stocker aucune donnée, mais il est très pratique pour implémenter des traits.

[^1]: [Cette documentation](https://doc.rust-lang.org/reference/visibility-and-privacy.html) explique certaines options de visibilité moins courantes.
[^2]: C'est un cas particulier d'une règle générale : le style utilisé pour déclarer un type de structure est celui qui est requis pour l'instancier.
