# Installation

Pour commencer, assure-toi qu'Erlang est installé, en suivant les instructions de la page d'installation d'[Erlang][1] selon ton cas.
[1]: /languages/erlang

## Homebrew pour Mac OS X

Mets à jour Homebrew vers la dernière version :

```bash
$ brew update
```

Installe LFE :

```bash
$ brew install lfe
```

## Installation depuis les sources

Installe les « _developer tools_ » ou les « _essential build packages_ » de ton système, ainsi que `git` et l'`erl` d'Erlang.

Par exemple, sur Ubuntu 18.04 :

```bash
$ sudo apt-get install build-essential git erlang erlang-base-hipe
```

Ensuite, tu peux télécharger et compiler LFE avec les commandes suivantes :

```bash
$ git clone https://github.com/lfe/lfe.git
$ cd lfe
$ make
$ make install
```

Une fois LFE compilé, tu peux lancer la REPL (session interactive) en exécutant le binaire ``lfe`` :

```bash
$ ./bin/lfe
```
