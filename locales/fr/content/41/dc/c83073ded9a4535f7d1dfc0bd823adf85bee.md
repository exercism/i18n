# Ajout

## Bonus

Deux tests facultatifs sont désactivés par défaut. Pour les activer, ajoute `const TEST_BIG_INTEGERS = true` à la portée globale de ton fichier de solution (ou décommente la ligne fournie dans le _stub_).

Ces nombres dépassent le type entier par défaut, mais les entiers 128 bits suffisent pour réussir les tests ; il n'y a pas besoin de `BigInt`.
