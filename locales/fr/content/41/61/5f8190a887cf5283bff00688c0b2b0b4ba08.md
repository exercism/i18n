# Instructions

Implémente la méthode classique de composition de messages secrets appelée code carré.

À partir d'un texte en anglais, renvoie la version encodée de ce texte.

Tout d'abord, on normalise l'entrée : les espaces et la ponctuation sont retirés du texte anglais, et le message est mis en minuscules.

Ensuite, les caractères normalisés sont répartis en lignes. Ces lignes peuvent être vues comme formant un rectangle lorsqu'on les affiche avec des retours à la ligne entre elles.

Par exemple, la phrase

```text
"If man was meant to stay on the ground, god would have given us roots."
```

est normalisée en :

```text
"ifmanwasmeanttostayonthegroundgodwouldhavegivenusroots"
```

Le texte en clair doit être organisé en un rectangle. La taille du rectangle (`r x c`) doit être déterminée par la longueur du message, de sorte que `c >= r` et `c - r <= 1`, où `c` est le nombre de colonnes et `r` le nombre de lignes.

Notre texte normalisé fait 54 caractères, ce qui impose un rectangle avec `c = 8` et `r = 7` :

```text
"ifmanwas"
"meanttos"
"tayonthe"
"groundgo"
"dwouldha"
"vegivenu"
"sroots  "
```

Le message codé s'obtient en lisant les colonnes de haut en bas, de gauche à droite.

Le message ci-dessus est codé comme suit :

```text
"imtgdvsfearwermayoogoanouuiontnnlvtwttddesaohghnsseoau"
```

Renvoie le texte encodé en blocs qui remplissent des rectangles parfaits `(r X c)`, avec `c` blocs de longueur `r`, séparés par des espaces. Pour les phrases qui comptent `n` caractères de moins que le rectangle parfait, complète chacun des `n` derniers blocs par un seul espace final.

```text
"imtgdvs fearwer mayoogo anouuio ntnnlvt wttddes aohghn  sseoau "
```

Remarque que si on empilait ces blocs, on pourrait décoder visuellement le texte chiffré pour retrouver le message d'origine :

```text
"imtgdvs"
"fearwer"
"mayoogo"
"anouuio"
"ntnnlvt"
"wttddes"
"aohghn "
"sseoau "
```
