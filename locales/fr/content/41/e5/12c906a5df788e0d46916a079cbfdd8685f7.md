# À propos

Ruby est livré avec une bibliothèque standard (souvent abrégée en « stdlib ») : une collection de classes pour travailler avec des données telles que les dates, le json ou les communications réseau.
Elle fournit aussi des fonctionnalités utiles pour rendre le code plus facile à utiliser.

`OpenStruct` fait partie de la bibliothèque standard et permet de créer facilement un objet à partir d'un `Hash`.
Plutôt que d'y accéder par les clés du `Hash`, `OpenStruct` permet d'utiliser des méthodes pour accéder aux valeurs et les définir.

Quand on utilise des classes de la bibliothèque standard, ou de n'importe quelle autre bibliothèque, il faut charger cette classe avec la méthode `require`.

```ruby
require 'ostruct'

attributes = { name: "Jeremy Walker", age: 21, location: "Nomadic" }
person = OpenStruct.new(attributes)

person.name
#=> Jeremy Walker

person.location
#=> Nomadic

# Update the age
person.age = 35

# It sets correctly
person.age
#=> 35
```

Un avantage bonus de tout cela, c'est que tu peux profiter d'un raccourci quand tu utilises la syntaxe de bloc.
Quand un bloc appelle une seule méthode, tu peux remplacer le bloc par `&:` suivi du nom de la méthode.
Par exemple, ces deux lignes sont synonymes :

```ruby
people.sum { |person| person.age }
people.sum(&:age)
```
