# Installation

Tu as besoin de [NodeJS LTS](https://nodejs.org/en).

> 💡 Ce parcours fonctionne probablement aussi avec d'anciennes versions stables, ainsi qu'avec la version « Current ».
> Cependant, [par conception](https://github.com/nodejs/release#release-schedule), les versions impaires ne sont jamais stables.
> Veille donc toujours à installer une version paire de NodeJS.

Installe [Yarn 4+](https://yarnpkg.com/getting-started/install) à l'aide de `corepack` de Node.JS :

```shell
corepack enable yarn
```

## Vérifie ton installation

Il faut généralement ouvrir un nouveau terminal pour pouvoir utiliser les binaires que tu viens d'installer.

```shell
$ node -v
v20.15.0

$ corepack -v
0.28.1

$ corepack yarn -v
v4.3.1
```

_Remarque : tes versions seront probablement différentes de celles-ci._

## Installation des exercices

**Chaque exercice** nécessite quelques outils pour exécuter les tests :

On peut les installer en exécutant cette commande dans le répertoire de chaque exercice :

```bash
$ corepack yarn install
```

Selon ton éditeur, l'[Editor SDK](https://yarnpkg.com/getting-started/editor-sdks) doit être installé dans chaque exercice pour fonctionner avec les installations Plug'n'Play.
Au moment de la rédaction, les éditeurs suivants sont pris en charge :

- [CoC nvim](https://yarnpkg.com/getting-started/editor-sdks#coc-nvim)
- [Emacs](https://yarnpkg.com/getting-started/editor-sdks#emacs)
- [Neovim Native LSP](https://yarnpkg.com/getting-started/editor-sdks#neovim-native-lsp)
- [VSCode](https://yarnpkg.com/getting-started/editor-sdks#vscode)
