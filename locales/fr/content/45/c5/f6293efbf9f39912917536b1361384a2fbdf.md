# Instructions complémentaires

## Instructions spécifiques au parcours

Implémente une fonction appelée `slices` qui renvoie un tableau de _strings_ comme décrit ci-dessus.
Ta fonction doit lever une `IllegalArgumentError` avec un message d'erreur approprié, comme suit.
- Si la _string_ donnée est vide, lève une erreur avec le message `series cannot be empty`.
- Si la longueur de la tranche est négative, lève une erreur avec le message `slice length cannot be negative`.
- Si la longueur de la tranche vaut zéro, lève une erreur avec le message `slice length cannot be zero`.
- Si la longueur de la tranche dépasse la longueur de la _string_, lève une erreur avec le message `slice length can not be greater than series length`.
