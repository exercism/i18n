# À propos des tableaux

En Java, les tableaux permettent de stocker plusieurs valeurs du même type dans une seule structure.
Contrairement à d'autres structures de données, un tableau a une taille fixe une fois créé.
On peut affecter des éléments à un tableau ou les récupérer à l'aide d'un indice.
Les tableaux Java utilisent une indexation à partir de zéro : l'indice du premier élément est 0, celui du deuxième est 1, etc.

Voici la syntaxe standard pour initialiser un tableau :

```java
type[] variableName = new type[size];
```

Le `type` est le type des éléments du tableau, qui peut être un type primitif (par exemple `int`) ou une classe (par exemple `String`).

La `size` est le nombre d'éléments que ce tableau pourra contenir (ce nombre ne peut pas être modifié par la suite).
Après la création du tableau, les éléments sont initialisés à leur valeur par défaut (généralement `0`, `false` ou `null`).

```java
// Declare array with explicit size (size is 2)
int[] twoInts = new int[2];
```

On peut aussi définir un tableau avec une notation abrégée qui permet à la fois de créer le tableau et de définir ses valeurs :

```java
// Two equivalent ways to declare and initialize an array (size is 3)
int[] threeIntsV1 = new int[] { 4, 9, 7 };
int[] threeIntsV2 = { 4, 9, 7 };
```

Comme le compilateur peut désormais déterminer le nombre d'éléments du tableau, la longueur peut être omise.

On peut affecter des éléments à un tableau et y accéder à l'aide d'une notation d'indice entre crochets :

```java
// Assign second element by index
twoInts[1] = 8;

// Retrieve the second element by index and assign to the int element
int secondElement = twoInts[1];
```

Accéder à un indice en dehors des indices valides du tableau provoque une `IndexOutOfBoundsException`.

On peut manipuler un tableau en appelant les méthodes ou les propriétés d'une instance de tableau, ou en utilisant les méthodes statiques définies dans la classe `Arrays` (généralement utilisées uniquement dans du code générique).
La propriété `length` contient la longueur d'un tableau.
On y accède comme ceci :

```java
int arrayLength = someArray.length;
```

Java fournit également une classe utilitaire pratique [`java.util.Arrays`](https://docs.oracle.com/en/java/javase/11/docs/api/java.base/java/util/Arrays.html) qui contient de nombreuses méthodes utiles liées aux tableaux (par exemple `Arrays.equals`).

Java prend également en charge les [tableaux multidimensionnels](https://www.programiz.com/java-programming/multidimensional-array) comme `int[][] arr = new int[3][4];`, ce qui peut être très utile.

Le fait qu'un tableau soit aussi une _collection_ signifie qu'en plus d'accéder aux valeurs par leur indice, tu peux parcourir _toutes_ ses valeurs à l'aide d'une boucle `for-each` :

```java
char[] vowels = { 'a', 'e', 'i', 'o', 'u' };

for(char vowel: vowels) {
    // Output the vowel
    System.out.print(vowel);
}

// => aeiou
```

Si tu veux plus de contrôle sur les valeurs à parcourir, tu peux utiliser une boucle `for` :

```java
char[] vowels = { 'a', 'e', 'i', 'o', 'u' };

for (int i = 0; i < 3; i++) {
    // Output the vowel
    System.out.print(vowels[i]);
}

// => aei
```
