# Introduction

## Les _packages_

En Go, une application est organisée en _packages_.
Un _package_ est un ensemble de fichiers sources situés dans le même dossier.
Tous les fichiers sources d'un dossier doivent avoir le même nom de _package_ en haut du fichier.
Par convention, on donne aux _packages_ le nom du dossier dans lequel ils se trouvent.

```go
package greeting
```

Go fournit une vaste bibliothèque standard de _packages_ que l'on peut utiliser dans son programme grâce au mot-clé `import`.
Les _packages_ de la bibliothèque standard s'importent par leur nom.

```go
package greeting

import "fmt"
```

Un _package_ importé s'utilise ensuite par son nom :

```go
world := "World"
fmt.Sprintf("Hello %s", world)
```

Go détermine si un élément peut être appelé par du code d'autres _packages_ à la façon dont il est déclaré.
Pour rendre une fonction, un type, une variable, une constante ou un champ de structure visible depuis l'extérieur (on dit alors qu'il est _exporté_), le nom doit commencer par une majuscule.

```go
package greeting

// Hello is a public function (callable from other packages).
func Hello(name string) string {
    return "Hello " + name
}

// hello is a private function (not callable from other packages).
func hello(name string) string {
    return "Hello " + name
}
```

## Formatage de chaînes de caractères

Go fournit un _package_ intégré appelé `fmt` (_package_ de formatage) qui propose une variété de fonctions pour manipuler le format des entrées et des sorties.
La fonction la plus couramment utilisée est `Sprintf`, qui utilise des verbes comme `%s` pour interpoler des valeurs dans une _string_ et renvoie cette _string_.

```go
import "fmt"

food := "taco"
fmt.Sprintf("Bring me a %s", food)
// Returns: Bring me a taco
```

En Go, les nombres à virgule flottante se formatent facilement avec les verbes de `Sprintf` : `%g` (représentation compacte), `%e` (exposant) ou `%f` (sans exposant).
Ces trois verbes permettent de contrôler la largeur du champ et la position numérique.

```go
import "fmt"

number := 4.3242
fmt.Sprintf("%.2f", number)
// Returns: 4.32
```

Tu trouveras la liste complète des verbes disponibles dans la [documentation du _package_ de formatage][fmt-docs].

`fmt` contient d'autres fonctions pour travailler avec les _strings_, comme `Println`, qui se contente d'afficher dans la console les arguments qu'elle reçoit, et `Printf`, qui met en forme l'entrée de la même façon que `Sprintf` avant de l'afficher.

[fmt-docs]: https://pkg.go.dev/fmt
