# Indices

## Général

- L'alignement d'une structure est l'alignement _maximal_ de ses champs.
- La taille d'une structure est un multiple de son alignement.

## 1. Crée une voiture télécommandée

- L'alignement d'une structure est l'alignement _maximal_ de ses champs.
- La taille d'une structure est un multiple de son alignement.
- L'alignement d'un tableau est égal à l'alignement de ses éléments.
- Chaque groupe de 8 octets d'une structure doit être classé séparément.
- Si un entier et un nombre à virgule flottante partagent les mêmes 8 octets, l'ensemble de ces 8 octets est passé dans un registre à usage général (GPR).
- Un nombre à virgule flottante ne peut pas être une constante définie au moment de l'assemblage avec `equ`, mais il peut être une constante de la section .rodata.
- Pour déplacer des octets bruts d'un registre `xmm` vers un GPR, sans modifier leur représentation binaire, on peut utiliser les instructions [movd][mov] ou [movq][mov].

## 2. Crée une nouvelle piste

- L'alignement d'une structure est l'alignement _maximal_ de ses champs.
- La taille d'une structure est un multiple de son alignement.
- Si deux champs adjacents d'une structure ne peuvent pas être regroupés pour tenir dans son alignement, des octets de remplissage sont insérés.

## 3. Crée un événement de course

- L'alignement d'une structure est l'alignement _maximal_ de ses champs.
- La taille d'une structure est un multiple de son alignement.
- Une structure d'au plus 16 octets est passée dans des registres à une fonction.
- Une structure de plus de 16 octets est généralement placée en mémoire.
- Quand une fonction renvoie une structure en mémoire, l'adresse d'un emplacement mémoire où stocker cette structure est passée comme premier argument implicite, dans `rdi`.
- Dans ce cas, la fonction doit renvoyer cette adresse dans `rax`.

## 4. Confirme une voiture pour la course

- L'alignement d'une structure est l'alignement _maximal_ de ses champs.
- La taille d'une structure est un multiple de son alignement.
- Un pointeur occupe 8 octets et est passé dans un registre à usage général (GPR), quelle que soit la taille du type vers lequel il pointe.
- Il faut mettre à jour à la fois le tableau `cars` et le nombre de voitures en course dans `race`.

## 5. Crée un tournoi

- L'alignement d'une structure est l'alignement _maximal_ de ses champs.
- La taille d'une structure est un multiple de son alignement.
- Une structure de plus de 16 octets est généralement placée en mémoire.
- Quand une fonction prend en argument une structure en mémoire, cette structure est passée sur la pile.
- Il faut mettre à jour à la fois le tableau `races` et le nombre de courses dans `tournament`.
