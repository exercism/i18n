# Indices

## Généralités

As-tu essayé de découper ta logique en une ou plusieurs fonctions auxiliaires ?
Ce type de chanson est connu sous le nom de [chanson cumulative][cumulative song], elle se prête donc particulièrement bien à être « découpée ».
Cela peut rendre le code plus facile à comprendre et respectera le [principe de responsabilité unique][Single Responsibility Principle].
