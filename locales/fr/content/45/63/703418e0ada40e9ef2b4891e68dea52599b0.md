# À propos

En Elixir, pour choisir un élément aléatoire dans une structure de données énumérable (par exemple un tableau ou un intervalle), on utilise [`Enum.random/1`][enum-random]. Cette fonction sélectionne un seul élément, chacun ayant la même probabilité d'être choisi. Choisir une seule valeur aléatoire dans un intervalle se fait en temps constant, sans parcourir tout l'intervalle.

## Nombres entiers et lettres aléatoires

- Choisis un entier aléatoire
  ```elixir
  Enum.random(1..10)
  # => 7
  ```
- Choisis une lettre aléatoire sous forme de _string_
  ```elixir
  <<Enum.random(?A..?Z)>>
  # => "K"
  ```
- Choisis une lettre aléatoire sous forme de _charlist_
  ```elixir
  [Enum.random(?A..?Z)]
  # => ~c"J"
  ```

Pour choisir plus d'un élément dans une structure de données énumérable, utilise [`Enum.take_random/2`][enum-take-random]. Pour trier une structure de données énumérable dans un ordre aléatoire, utilise [`Enum.shuffle/1`][enum-shuffle].

## Nombres décimaux aléatoires

Elixir ne dispose pas de ses propres fonctions pour choisir un nombre décimal aléatoire. Pour cela, on doit utiliser le module [`rand`][erl-rand] d'Erlang, qui est d'ailleurs ce que `Enum.random` utilise en interne.

- Choisis un nombre décimal aléatoire (supérieur ou égal à 0,0 et inférieur à 1,0) :

  ```elixir
  :rand.uniform()
  # => 0.275329955448815
  ```

- Choisis un nombre décimal aléatoire (supérieur ou égal à `a` et inférieur à `b`) :
  ```elixir
  a = 13
  b = 20
  :rand.uniform() * (b - a) + a
  # => 18.96815556890448
  ```

## Distribution normale

Toutes les fonctions mentionnées ci-dessus choisissent une valeur aléatoire dont chaque valeur possible a la même probabilité d'être choisie. C'est ce qu'on appelle une _distribution uniforme_. Le module `rand` propose aussi les fonctions [`normal/0`][erl-rand-normal-0] et [`normal/2`][erl-rand-normal-2], qui choisissent un nombre décimal aléatoire selon une [distribution normale][normal-distribution].

## Graine

Il est important de comprendre que les valeurs « aléatoires » sont générées par un [générateur de nombres _pseudo_ aléatoires][prng]. Un PRNG est un algorithme qui, à partir d'une valeur initiale appelée _graine_, génère une suite de nombres qui semble aléatoire, mais qui ne l'est pas du tout.

Ce fait peut être utile pour le débogage. Tu peux forcer le générateur de nombres pseudo aléatoires d'Erlang (et donc d'Elixir) à produire la même suite de valeurs en réinitialisant sa graine avec [`:rand.seed/2`][rand-seed-2]. Le premier argument est un algorithme PRNG précis, et le second un triplet de trois entiers : la graine.

```elixir
:rand.seed(:exsss, {1, 2, 3})
Enum.take_random(100..999, 3)
# => [680, 127, 622]

:rand.seed(:exsss, {1, 2, 3})
Enum.take_random(100..999, 3)
# => [680, 127, 622]
```

## Cryptographie

Les valeurs aléatoires renvoyées par `Enum.random` et par le module `rand` d'Erlang ne sont pas [sûres d'un point de vue cryptographique][cryptographically-secure-rng]. Ne les utilise pas pour générer des clés cryptographiques, des mots de passe ou des nonces. Pour ce cas d'usage, il y a la fonction [`:crypto.strong_rand_bytes/1`][erl-crypto-strong-rand-bytes] d'Erlang.
