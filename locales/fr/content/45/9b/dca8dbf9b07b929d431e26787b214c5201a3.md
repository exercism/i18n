# Tests

Le parcours Factor utilise **Factor 0.101**. Chaque exercice est fourni avec un vocabulaire `exercism-tools` qui définit les mots d'analyse `STOP-HERE` et `TASK:` ainsi qu'un exécuteur de tests. Depuis le répertoire de l'exercice, lance :

```
factor -roots=. -run=exercism-tools <exercise>
```

Par exemple, pour l'exercice `hello-world` :

```
factor -roots=. -run=exercism-tools hello-world
```

L'exécuteur se termine avec le statut 0 lorsque tous les tests sont réussis, et avec un statut non nul accompagné de messages de diagnostic lorsqu'un test échoue.

## Tests ignorés

Résoudre un exercice, c'est faire passer tous ses tests.
Par défaut, un seul test (le premier) est exécuté quand tu lances les tests.
C'est volontaire : cela te permet de te concentrer sur la seule réussite de ce test.

Le mécanisme repose sur la ligne `STOP-HERE` du fichier de test : au moment de l'analyse, elle indique à Factor d'ignorer tout ce qui se trouve en dessous, de sorte que l'exécuteur ne voit que les tests situés au-dessus. Une fois que ton premier test passe, tu peux activer d'autres tests de deux façons :

- **Supprime la ligne `STOP-HERE`** pour activer d'un coup tous les tests restants.
- **Déplace la ligne `STOP-HERE` plus bas** pour activer les tests un par un, ou une tâche à la fois. Les exercices d'apprentissage regroupent les tests sous des marqueurs `TASK:` ; déplacer `STOP-HERE` juste avant le `TASK:` suivant est une étape naturelle.

Quand tous les tests sont activés et que ton implémentation les fait tous passer, tu as résolu l'exercice !
