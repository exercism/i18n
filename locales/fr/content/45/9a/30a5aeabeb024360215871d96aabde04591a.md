# Introduction

Les [dictionnaires][dictionaries] sont l'un des trois principaux types de collection de Swift.
Un dictionnaire stocke des associations entre des _clés_, qui sont des éléments d'un type, et des _valeurs_, qui sont des éléments d'un autre type (éventuellement le même que celui des clés).

Les littéraux de dictionnaire s'écrivent sous la forme d'une série de paires `key: value`, séparées par des virgules et entourées de crochets.
On peut écrire un dictionnaire vide en faisant suivre le nom du type du dictionnaire d'une paire de parenthèses, par exemple `[Int: String]()`, ou, si le type peut être déterminé à partir du contexte, avec juste une paire de crochets entourant un deux-points, `[:]`.
Les noms de type des dictionnaires s'écrivent de deux manières : `Dictionary<K, V>` ou `[K: V]`, où `K` est le type des clés du dictionnaire et `V` le type des valeurs.
Lorsqu'on crée un dictionnaire vide, le type doit être précisé.

```swift
var addresses: Dictionary<String, String> = ["The Munsters": "1313 Mockingbird Lane", "The Simpsons": "742 Evergreen Terrace", "Buffy Summers": "1630 Revello Drive"]
var sequences: [String: [Int]] = ["Euler's totient": [1, 1, 2, 2, 4, 2, 6, 4], "Lazy caterer": [1, 2, 4, 7, 11, 16, 22, 29, 37], "Carmichael": [561, 1105, 1729, 2465, 2821, 6601, 8911, 10585, 15841]]
let constants = ["pi": 3.14159, "e": 2.71828, "phi": 1.618033, "avogadro": 6.02214076e23]
var emptyDict1: [Int: Int] = [:]
var emptyDict2 = [Character: String]()
var emptyDict3 = Dictionary<Int, Double>()
```

On peut accéder aux éléments d'un dictionnaire à l'aide de la notation par indice, où le nom du dictionnaire est suivi de crochets qui contiennent la clé dont on veut obtenir la valeur correspondante.

Remarque toutefois que la valeur renvoyée n'est pas de type _Value_, mais de type optionnel, _Value?_.
En effet, on peut fournir une clé qui n'est pas présente dans le dictionnaire.
Dans ce cas, Swift choisit de renvoyer `nil` plutôt que de lever une erreur.

```swift
let munster: String? = addresses["The Munsters"]
// Returns "1313 Mockingbird Lane"
let carmichael = sequences["Carmichael"]
// Returns [561, 1105, 1729, 2465, 2821, 6601, 8911, 10585, 15841]
let planck = constants["planck"]
// Returns nil
```

Pour éviter le type optionnel de la valeur renvoyée, on peut fournir une valeur par défaut à renvoyer si la clé ne se trouve pas dans le dictionnaire.

```swift
let e: Double = constants["e", default: 0]
// Returns 2.71828
let hoagie: [Int] = sequences["Hoagie", default: []]
// Returns []
let betty = addresses["Betty Cooper", default: "Address unknown"]
// Returns "Address unknown"
```

Cette notation par indice peut servir à récupérer la valeur associée à une clé comme à définir la valeur associée à cette clé, à condition que le dictionnaire ait été défini comme une variable (c'est-à-dire avec `var`).
Elle permet de mettre à jour la valeur associée à une clé ou d'ajouter une nouvelle paire _key: value_ au dictionnaire.

```swift
sequence["Euler's totient"]?.append(contentsOf: [6,4])
sequence["Euler's totient"]
// Returns [1, 1, 2, 2, 4, 2, 6, 4, 6, 4]
addresses["Betty Cooper"] = "111 Queens Ave."
addresses["Betty Cooper", default: "Address unknown"]
// Returns "111 Queens Ave."
constants["Gelfond's"] = 23.140692
// compiler error: "Cannot assign through subscript: 'constants' is a 'let' constant"
```

Comme pour les tableaux, on peut parcourir les paires _key: value_ d'un dictionnaire une par une à l'aide d'une boucle _for-in_.
Ce type de boucle prend chaque paire _key: value_ du dictionnaire et lie cette paire à un nom donné pour la traiter ensuite dans le corps de la boucle.
La paire est représentée sous forme de tuple et peut être décomposée comme n'importe quel autre tuple pour affecter chaque élément à un nom. Par exemple, pour afficher le carnet d'adresses, on peut écrire :

```swift
for (name, address) in addresses {
  print("\(name) lives at \(address)")
}

// prints out:
// Betty Cooper lives at 111 Queens Ave.
// The Munsters lives at 1313 Mockingbird Lane
// The Simpsons lives at 742 Evergreen Terrace
// Buffy Summers lives at 1630 Revello Drive
```

Comme les autres types de collection, les dictionnaires peuvent être triés selon des fonctions de tri arbitraires.
Pour ce faire, il faut d'abord définir une fonction qui prend deux paires _key: value_, représentées sous forme de tuples, et qui renvoie un `Bool` tel que la valeur renvoyée soit `true` si la première paire _key: value_ doit apparaître dans le résultat trié _avant_ la seconde.

On peut ensuite passer cette fonction à la méthode `sorted(by:)` du dictionnaire, qui renverra un tableau trié de paires _key: value_.
Par exemple, pour trier le dictionnaire `constants` selon la valeur de la constante plus le nombre de caractères de son nom, on pourrait écrire :

```swift
func weirdSort(_ lhs: (String, Double), _ rhs: (String, Double)) -> Bool {
  let left = lhs.1 + Double(lhs.0.count)
  let right = rhs.1 + Double(rhs.0.count)
  return left < right
}

let sortedConstants = constants.sorted(by: weirdSort)
// returns [(key "e", value 2.71828), (key "phi", value 1.618033), (key "pi", value 3.14159), (key "avogadro", value 6.02214076e+22)]
```
