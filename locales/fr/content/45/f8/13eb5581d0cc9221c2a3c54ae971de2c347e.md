# Tests

## Configuration

Suis les [instructions d'installation pour JavaScript][docs-exercism-javascript] afin d'installer les dépendances nécessaires.

## Prérequis

Installe les dépendances de l'exercice :

```shell
corepack pnpm install
```

Si `corepack` se plaint de ne pas être activé, tu peux l'activer en exécutant :

```bash
corepack enable pnpm
```

## Faire passer la suite de tests

Chaque exercice est fourni avec une suite de tests pour t'aider à valider ta solution avant de la soumettre.
Tu peux exécuter ces tests en ouvrant une invite de commandes dans le répertoire de l'exercice, puis en lançant :

```bash
corepack pnpm test
```

Dans certaines suites de tests, tous les tests sauf le premier sont ignorés.

Une fois qu'un test passe, tu peux activer le suivant en remplaçant `xtest` par `test`.

## Écris des tests personnalisés

Si tu souhaites écrire des tests supplémentaires et personnalisés, crée un nouveau fichier `custom.spec.js` et soumets-le avec ta solution :

```shell
exercism submit numbers.js custom.spec.js
```

[docs-exercism-javascript]: https://exercism.org/docs/tracks/javascript/installation
