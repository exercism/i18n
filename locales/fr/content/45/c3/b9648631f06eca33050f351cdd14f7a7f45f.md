# Instructions

Étant donné deux tableaux, détermine si le premier tableau est contenu dans le second, si le second tableau est contenu dans le premier, si les deux tableaux sont contenus l'un dans l'autre, ou si aucune de ces affirmations n'est vraie.

Plus précisément, un tableau A est un sublist du tableau B si, en retirant 0 ou plusieurs éléments au début de B et 0 ou plusieurs éléments à la fin de B, on obtient un tableau complètement égal à A.

Exemples :

 * A = [1, 2, 3], B = [1, 2, 3, 4, 5], A est un sublist de B
 * A = [3, 4, 5], B = [1, 2, 3, 4, 5], A est un sublist de B
 * A = [3, 4], B = [1, 2, 3, 4, 5], A est un sublist de B
 * A = [1, 2, 3], B = [1, 2, 3], A est égal à B
 * A = [1, 2, 3, 4, 5], B = [2, 3, 4], A est un superlist de B
 * A = [1, 2, 4], B = [1, 2, 3, 4, 5], A n'est ni un superlist, ni un sublist, ni égal à B
