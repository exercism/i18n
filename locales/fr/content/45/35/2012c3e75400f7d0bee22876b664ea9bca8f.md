# Déclaration de type

PHP est un langage _à typage dynamique_, ce qui signifie qu'une variable peut contenir n'importe quel type d'information.
PHP permet toutefois de déclarer _optionnellement_ des types forts pour les propriétés de classe, les arguments de fonction et les valeurs de retour de fonction.
Les déclarations de type fort en PHP fournissent des assertions de type à l'exécution, mais PHP tentera de convertir les types scalaires pour qu'ils correspondent à la déclaration lorsque c'est possible.
Ce comportement de conversion peut être désactivé à l'aide de la déclaration `strict_types` en haut du fichier.

```php
<?php
declare(strict_types=1);
```

De plus, une fonction peut renvoyer un type de retour `void` pour indiquer qu'aucune valeur ne doit être renvoyée par la fonction.

```php
<?php
declare(strict_types=1);

class Driver
{
    string $serial_number;

    function setSerialNumber(string $number): void
    {
        $this->serial_number = $number;
    }

    function getSerialNumber(): string
    {
        return $this->serial_number; 
    }
}

$driver = new Driver(); 
$driver->setSerialNumber(1234);
// => This will throw a TypeError with strict_types=1
```

## Types union

Si un argument de fonction, une valeur de retour ou une propriété de classe peut avoir plus d'un type, on peut déclarer une union de types.

```php
<?php

class IdentityCard
{
    private int|float $id = 0;

    public function assign(int|float $id): void
    {
        $this->id = intval($id);
    }
}

$card = new IdentityCard();
$card->assign(5.0);
```

## Types mixtes

En écrivant du code, il se peut qu'on ne puisse pas préciser de type.
Depuis PHP 8.0, un type de secours nommé `mixed` est fourni.
`mixed` équivaut à une union de types `object|resource|array|string|float|int|bool|null`.
