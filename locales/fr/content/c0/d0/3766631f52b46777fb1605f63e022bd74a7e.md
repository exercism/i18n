# Introduction

Un fichier, c'est un simple flux auquel on a donné un nom sur le disque. Le vocabulaire [`io.files`][io.files] t'offre deux façons de travailler avec un fichier : des mots pratiques qui lisent ou écrivent tout son contenu en un seul appel, et des mots qui ouvrent un flux, pour les cas où tu veux lire ou écrire de manière incrémentale.

Chaque mot qui touche à un fichier prend un **encodage**, le mécanisme qui transforme les octets en caractères et inversement. Pour du texte, c'est presque toujours [`utf8`][utf8], dans `io.encodings.utf8`.

## Lire un fichier entier

```
file-contents   ( path encoding -- str )
file-lines      ( path encoding -- seq )
```

`file-contents` renvoie le fichier entier sous la forme d'une seule _string_ ; `file-lines` renvoie un tableau de ses lignes, sans les sauts de ligne.

```factor
USING: io.encodings.utf8 io.files prettyprint ;

"sunny\ncloudy\n" "forecast.txt" utf8 set-file-contents

"forecast.txt" utf8 file-contents .
! => "sunny\ncloudy\n"

"forecast.txt" utf8 file-lines .
! => { "sunny" "cloudy" }
```

## Écrire un fichier entier

```
set-file-contents   ( str path encoding -- )
set-file-lines      ( seq path encoding -- )
```

Les deux **remplacent** le contenu du fichier (et le créent si besoin). `set-file-contents` écrit une _string_ telle quelle ; `set-file-lines` écrit chaque élément d'une séquence sur sa propre ligne, en ajoutant les sauts de ligne à ta place.

```factor
USING: io.encodings.utf8 io.files prettyprint ;

{ "sunny" "cloudy" } "forecast.txt" utf8 set-file-lines
"forecast.txt" utf8 file-contents .
! => "sunny\ncloudy\n"
```

## Ajouter du contenu à un fichier

Pour ajouter du contenu à un fichier sans effacer ce qui s'y trouve déjà, ouvre-le avec un combinateur `with-…` et écris dans le flux ambiant à l'intérieur de la _quotation_ :

```
with-file-appender   ( path encoding quot -- )
with-file-reader     ( path encoding quot -- )
with-file-writer     ( path encoding quot -- )
```

```factor
USING: io io.encodings.utf8 io.files prettyprint ;

"sunny\ncloudy\n" "forecast.txt" utf8 set-file-contents
"forecast.txt" utf8 [ "rainy" print ] with-file-appender
"forecast.txt" utf8 file-contents .
! => "sunny\ncloudy\nrainy\n"
```

Comme tout combinateur `with-…`, ce sont des portées à destructeur : le descripteur de fichier est fermé quand la _quotation_ se termine, même si elle lève une exception.
