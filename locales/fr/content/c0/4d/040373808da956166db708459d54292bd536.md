# Introduction

Outre l'instruction `if`, il existe aussi l'instruction `switch` pour exécuter du code de manière conditionnelle. On l'utilise lorsqu'une même variable doit être comparée à plusieurs variantes. Pour une variable x donnée, l'instruction `switch` en Haxe a la syntaxe suivante.

```haxe
var a = 2;

switch (a) {
  case 0:
    trace("a is 0");
  case 1:
    trace("a is 1");
  case 2:
    trace("a is 2");
  default:
    trace("a is something else");
}

// a is 2
```

Le cas `default` s'exécute quand aucun autre cas ne correspond.
