# Tests

## Clojure CLI

Les exercices Clojure sur Exercism sont livrés avec un fichier `deps.edn` contenant un alias `:test` qui permet d'appeler le [cognitect-labs test-runner](https://github.com/cognitect-labs/test-runner) :

``` bash
$ clj -X:test
```

Cette commande parcourt le répertoire `test` de ton projet à la recherche des tests définis avec `clojure.test`, puis les exécute.

## Leiningen

Pour exécuter les tests d'un exercice avec Leiningen, il suffit d'appeler :

``` bash
$ lein test

lein test bob-test

Ran 14 tests containing 14 assertions.
0 failures, 0 errors.
```
