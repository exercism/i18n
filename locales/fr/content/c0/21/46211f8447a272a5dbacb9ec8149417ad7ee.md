# Introduction

Cairo fournit des dictionnaires au sein de ses bibliothèques standard, représentés par le type `Felt252Dict<T>`.

Dans Cairo, le type des clés d'un dictionnaire est limité à `felt252`, contrairement à d'autres langages où l'on peut définir le type des clés.

Pour créer un dictionnaire, on peut utiliser la méthode `default` du trait `Default`, comme ceci :

```rust
let mut foo: Felt252Dict<u32> = Default::default();
```

Les opérations de base les plus souvent utilisées sont :

1. `insert(felt252, T) -> ()` pour écrire des valeurs dans une instance de dictionnaire, et
2. `get(felt252) -> T` pour en lire des valeurs.

Et voici comment on utilise ces opérations :

```rust
let mut foo: Felt252Dict<u32> = Default::default();
// Add a value to the dictionariy
foo.insert('bar', 42);
// Here we update the element of 'bar'
foo.insert('bar', 73);
// To retrieve a dictionary value, you can use
baz = foo.get('bar');
```

Si tu essaies de récupérer la valeur associée à une clé qui n'existe pas dans le dictionnaire, c'est la valeur zéro du type de valeur qui est renvoyée.

Cela peut prêter à confusion, surtout si la valeur par défaut de ton type de valeur (par exemple 0 pour un entier) est une valeur valide.

Cela signifie aussi qu'il n'existe aucun moyen de supprimer des données d'un dictionnaire.

C'est un point à garder en tête lorsque tu intègres cette structure dans ton code.
