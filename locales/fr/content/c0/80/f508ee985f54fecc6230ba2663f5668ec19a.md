# Indices

## Général

- Jette un œil à la [documentation de `elm/parser`][elm-parser]
- L'introduction présente tous les concepts nécessaires pour résoudre l'exercice

## 1. Analyse le prix de la pizza

- Le [parseur `int`][int] sert à analyser des entiers
- Plusieurs parseurs peuvent gérer le €, mais [`symbol`][symbol] est le plus approprié
- L'[opérateur `(|.)`][(|.)] peut analyser deux choses mais n'en garder qu'une

## 2. Analyse l'indicateur végétarien

- Le [parseur `oneOf`][oneOf] peut essayer différentes possibilités
- Il y a plusieurs façons d'analyser une _string_ donnée ; dans ce cas, [`keyword`][keyword] ou [`symbol`][symbol] sont appropriés
- Il y a plusieurs façons de renvoyer `True` lorsqu'un parseur réussit ; l'une des bonnes consiste à utiliser [`succeed`][succeed]

## 3. Analyse les noms de pizza et d'ingrédient

- Le [parseur `chompWhile`][chompWhile] sert à analyser des caractères quelconques
- La [fonction `isAlpha`][isAlpha] permet de valider les caractères ASCII majuscules et minuscules
- La [fonction `map`][map] permet de modifier le contenu d'un parseur
- La [fonction `String.toLower`][toLower] permet de convertir une _string_ en minuscules

## 4. Analyse une liste d'ingrédients

- Le [parseur `sequence`][sequence] sert à analyser des listes d'éléments
- Utilise toutes les fonctions appropriées que tu as définies jusqu'ici

## 5. Analyse la pizza complète

- Avec l'[opérateur `(|=)`][(|=)], il est assez simple de conserver plusieurs éléments dans un pipeline
- Utilise `Pizza` comme constructeur de type avec [`succeed`][succeed]
- Plusieurs parseurs peuvent gérer ":" et "-", mais [`symbol`][symbol] est le plus approprié
- Le [parseur `spaces`][spaces] est pratique pour se débarrasser des espaces superflus
- Utilise toutes les fonctions appropriées que tu as définies jusqu'ici

## 6. Analyse le menu complet

- Le [parseur `sequence`][sequence] sert à analyser des listes d'éléments
- N'oublie pas que `spaces` consomme aussi les caractères de nouvelle ligne, ce qui pourrait interférer avec le séparateur
- Le [parseur `end`][end] sert à vérifier que l'on a atteint la fin d'une _string_
- L'[opérateur `(|.)`][(|.)] peut analyser deux choses mais n'en garder qu'une
- Utilise toutes les fonctions appropriées que tu as définies jusqu'ici

## 7. Analyse les noms d'ingrédients composés de plusieurs mots

- Le [parseur `chompWhile`][chompWhile] sert à analyser des caractères quelconques
- La [fonction `isAlpha`][isAlpha] permet de valider les caractères ASCII majuscules et minuscules
- La [fonction `andThen`][andThen] permet d'inspecter le contenu d'un parseur
- La [fonction `problem`][problem] renvoie un parseur qui a atteint une impasse
- La [fonction `String.toLower`][toLower] permet de convertir une _string_ en minuscules
- La [fonction `String.trim`][trim] permet de supprimer les espaces blancs aux extrémités d'une _string_
