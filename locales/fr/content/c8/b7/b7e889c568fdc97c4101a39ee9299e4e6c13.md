# Indices

## Général

- Les opérateurs de fonction comme `+` ou `*` suivent des règles bien précises pour l'application de fonction ; tu peux [revoir l'ordre dans lequel les arguments des opérateurs sont appliqués.][function-operators]
- Le type `Nat` d'Unison est un type numérique particulier qui représente les nombres entiers positifs, à commencer par `0`. Parcours les [fonctions disponibles pour les valeurs `Nat` dans la bibliothèque standard.][nat-std-lib]

[function-operators]: https://www.unison-lang.org/learn/fundamentals/values-and-functions/function-application-operators/
[nat-std-lib]: https://share.unison-lang.org/@unison/code/latest/namespaces/public/base/latest/;/types/Nat
