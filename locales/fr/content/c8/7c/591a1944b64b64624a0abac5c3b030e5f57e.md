# Introduction

Il existe essentiellement deux types de boucles :

1. Boucler jusqu'à ce qu'une condition soit remplie.
2. Parcourir les éléments d'une collection.

Les deux sont possibles en Julia, même si la seconde est sans doute plus courante.

## La boucle `while`

Pour les problèmes ouverts, où l'on ne connaît pas à l'avance le nombre de tours de boucle, Julia dispose de la boucle `while`.

La forme de base est assez simple :

```julia
while condition
    do_something()
end
```

Dans ce cas, le programme continue de tourner dans la boucle jusqu'à ce que `condition` ne soit plus `true`.

Deux façons de sortir de la boucle de manière anticipée sont disponibles :

- Une instruction `break` fait sortir de la boucle, l'exécution se poursuivant à la ligne suivant le `end` de la boucle.
- Un `return x` arrête l'exécution de la fonction en cours et renvoie la valeur `x` à l'appelant.

Avec ces possibilités, il peut parfois être pratique de créer une boucle « infinie » avec `while true ... end`, puis de compter sur une condition d'arrêt trouvée dans le corps de la boucle pour déclencher un `break` ou un `return`.

## Parcourir une collection

L'illustration la plus simple consiste à parcourir une plage de valeurs.

Si l'on veut faire quelque chose 10 fois :

```julia
for n in 1:10
    do_something(n)
end
```

Si l'itération en cours ne satisfait pas une certaine condition, il est possible de passer immédiatement à l'itération suivante avec un `continue` :

```julia
for n in 1:10
    if is_useless(n)
        continue
    end
    
    # we decided this iteration could be useful
    do_something_slow(n)
end
```

Sous une forme plus courte, le bloc `if` pourrait être remplacé par `is_useless(n) && continue`.

On peut parcourir bien d'autres types de collections : les éléments d'un tableau, les caractères d'une _string_, les clés d'un dictionnaire...

Les exemples jusqu'ici parcourent la plage `1:10`, où la valeur est aussi l'indice de la boucle.

Plus généralement, on peut avoir besoin de l'indice et pas seulement de la valeur.
Pour cela, on utilise la fonction `eachindex()`, par exemple `for i in eachindex(my_array) ... end`.
