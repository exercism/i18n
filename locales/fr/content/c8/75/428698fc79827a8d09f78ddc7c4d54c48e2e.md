# Introduction

Un vecteur est un tableau à une dimension.
Ses éléments peuvent être de types différents.

## Crée des vecteurs

On peut créer des vecteurs avec la fonction `vector` ou en utilisant sa forme de lecture `#()`

```lisp
(vector 1 t "foo" 'b) ; => #(1 t "foo" B)
#(2 nil "bar" a)      ; => #(2 nil "bar" A)
```

## Accède aux éléments

Pour accéder aux éléments d'un vecteur, utilise `aref` ; les indices commencent à zéro :

```lisp
(aref #(1 2 3) 1) ; => 2
(aref #(a b c) 0) ; => A
```
