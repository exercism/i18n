# Instructions

Ton amie Li Mei tient un bar à jus où elle vend de délicieux jus de fruits mélangés. Tu es un client régulier de sa boutique et tu as réalisé que tu pourrais lui faciliter un peu la vie avec du code Factor.

## 1. Détermine combien de temps il faut pour mixer un jus

Li Mei aime dire à ses clients à l'avance combien de temps ils devront attendre pour un jus de la carte. Elle a du mal à se rappeler les chiffres exacts, car le temps nécessaire pour mixer les jus varie :

- `"Pure Strawberry Joy"` prend `0.5` minute.
- `"Energizer"` et `"Green Garden"` prennent `1.5` minute chacun.
- `"Tropical Island"` prend `3` minutes.
- `"All or Nothing"` prend `5` minutes.
- Toutes les autres boissons (par exemple les offres spéciales) prennent `2.5` minutes.

Définis `time-to-mix-juice` pour qu'elle retire de la pile le nom d'un jus et renvoie le nombre de minutes qu'il faut pour mixer cette boisson.

```factor
"Tropical Island" time-to-mix-juice .
! => 3

"Berries & Lime" time-to-mix-juice .
! => 2.5
```

## 2. Réapprovisionne la réserve de quartiers de citron vert

Beaucoup des créations de Li Mei contiennent des quartiers de citron vert, que ce soit comme ingrédient ou pour la décoration. Aussi, quand elle commence son service le matin, elle doit s'assurer que la réserve de quartiers de citron vert est bien pleine pour la journée à venir.

Définis `wedges-from-lime` pour qu'elle prenne une taille de citron vert et renvoie le nombre de quartiers qu'il produit : `6` pour un citron vert `"small"`, `8` pour un `"medium"`, `10` pour un `"large"`.

Définis ensuite `limes-to-cut` pour qu'elle prenne le nombre de quartiers `needed` et un tableau de `limes` (des tailles de citron vert, dans l'ordre de découpe). Elle découpe les citrons verts un par un, dans l'ordre, et s'arrête dès qu'elle a assez de quartiers ou qu'elle n'a plus de citrons verts. Renvoie le nombre de citrons verts qu'il a fallu découper.

```factor
25 { "small" "small" "large" "medium" "small" } limes-to-cut .
! => 4
```

## 3. Liste les temps de mixage de chaque commande dans la file d'attente

Li Mei aime garder une trace du temps qu'il faudra pour mixer les commandes des clients qui attendent.

Définis `order-times` pour qu'elle prenne un tableau de commandes et renvoie un tableau contenant le temps de mixage de chaque commande, dans le même ordre.

```factor
{ "Energizer" "Tropical Island" } order-times .
! => { 1.5 3 }
```

## 4. Termine le service

Li Mei travaille toujours jusqu'à 15 h. Ensuite, son employé Dmitry prend le relais. Il arrive souvent que des boissons aient été commandées mais pas encore préparées quand le service de Li Mei se termine ; c'est alors Dmitry qui prépare les jus restants.

Pour faciliter la passation, définis `remaining-orders` pour qu'elle prenne le nombre de minutes `time-left` du service de Li Mei et un tableau d'`orders` (des jus qui ont été commandés mais pas encore préparés). Renvoie les commandes que Dmitry devra prendre en charge, c'est-à-dire celles que Li Mei n'a pas le temps de commencer avant la fin de son service.

`time-left` est toujours supérieur à `0`. Les commandes sont préparées dans l'ordre dans lequel elles apparaissent dans le tableau. Une fois que Li Mei a commencé un jus, elle le termine toujours, même si elle doit travailler un peu plus longtemps. Si elle a le temps de commencer toutes les commandes, renvoie un tableau vide.

```factor
5 { "Energizer" "All or Nothing" "Green Garden" } remaining-orders .
! => { "Green Garden" }
```
