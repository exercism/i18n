# Méthodes de `String`

`String` dispose de plusieurs méthodes qui permettent de manipuler des _strings_.  
Ces méthodes s'appellent sur la _string_ elle-même et sont souvent enchaînées pour effectuer plusieurs opérations sur une _string_.

Voici une liste de quelques-unes des méthodes les plus courantes.
Consulte la [documentation de l'API de `String`][string-api] pour une liste complète des méthodes.

## String#upcase & String#downcase

La méthode [`upcase`][upcase] renvoie une nouvelle _string_ dont tous les caractères sont convertis en majuscules.

```crystal
"hello".upcase
# => "HELLO"
```

La méthode [`downcase`][downcase] renvoie une nouvelle _string_ dont tous les caractères sont convertis en minuscules.

```crystal
"HELLO".downcase
# => "hello"
```

## String#sub & String#gsub

Crystal propose des méthodes pour remplacer des parties d'une _string_.
Elles s'appellent [`sub`][sub] (_substitution_) et [`gsub`][gsub] (_substitution globale_).

Ces méthodes prennent en premier argument une _string_, un `Char` ou une regex, et en second argument une _string_ ou un `Char`.
Le premier argument est la partie de la _string_ qui sera remplacée, et le second argument est le remplacement.
Les `Char` et les regex seront expliqués dans des concepts ultérieurs.

La méthode `sub` remplace la première occurrence du premier argument par le second argument.

```crystal
"hello".sub("l", "r")
# => "herlo"
```

La méthode `gsub` fonctionne comme `sub`, mais remplace toutes les occurrences du premier argument par le second argument.

```crystal
"hello".gsub("l", "r")
# => "herro"
```

## String#chomp & String#strip

`chomp` et `strip` permettent de supprimer des caractères indésirables d'une _string_.

Par défaut, la méthode [`chomp`][chomp] supprime les derniers caractères `\r`, `\n` ou `\r\n` d'une _string_.
Si la méthode est appelée avec un argument, elle supprime la valeur donnée à la fin de la _string_, à condition qu'elle s'y trouve.

```crystal
"hello\n".chomp
# => "hello"

"hello".chomp("llo")
# => "he"
```

Par défaut, la méthode [`strip`][strip] supprime tous les espaces au début et à la fin d'une _string_.
Si la méthode est appelée avec un argument, elle supprime cet argument au début et à la fin de la _string_, s'il s'y trouve.

```crystal
" hello ".strip
# => "hello"
```

## String#index

La méthode [`index`][index] permet de trouver l'indice d'un caractère dans une _string_.
La méthode `index` prend en argument une `String`, un `Char` ou une regex.
Elle peut prendre un second argument facultatif pour préciser l'indice à partir duquel effectuer la recherche.
La méthode `index` renvoie l'indice de la première occurrence de l'argument.

```crystal
"hello".index("l")
# => 2

"hello".index("l", 3)
# => 3
```

## String#delete_at

Tu peux utiliser la méthode [`delete_at`][delete_at] pour supprimer un caractère d'une _string_.
La méthode `delete_at` prend un indice en argument et supprime le caractère situé à cet indice.

```crystal
"hello".delete_at(0)
# => "ello"

"hello".delete_at(3)
# => "helo"
```

## String#insert

La méthode [`insert`][insert] permet d'insérer une _string_ à un indice précis.
La méthode `insert` prend un indice en premier argument et une _string_ en second argument.
La méthode `insert` renvoie une nouvelle _string_ dans laquelle le second argument est inséré à l'indice donné.

```crystal
"hello".insert(0, "h")
# => "hhello"

"hello".insert(3, "l")
# => "helllo"
```
