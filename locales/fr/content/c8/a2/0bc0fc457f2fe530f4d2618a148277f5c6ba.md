# Instructions

Dans cet exercice, tu dois implémenter quelques fonctions pour manipuler un tableau de langages de programmation.

## 1. Définis une fonction qui renvoie un tableau de langages vide

Définis la fonction `language_list` qui ne prend aucun argument et qui renvoie un tableau vide.

```php
<?php

language_list();
// => []
```

## 2. Modifie la fonction pour créer un tableau à partir d'un nombre quelconque de langages

Modifie la fonction `language_list` pour qu'elle prenne un argument variadique de langages (_strings_).
Elle doit renvoyer le tableau résultant contenant les langages.

```php
<?php

$language_list = language_list();
// => []
$language_list = language_list("Clojure", "PHP");
// => ["Clojure", "PHP"]
$language_list = language_list("PHP", "Haskell", "Java", "C++", "Rust")
// => ["PHP", "Haskell", "Java", "C++", "Rust"]
```

## 3. Définis une fonction pour ajouter un langage au tableau

Définis la fonction `add_to_language_list` qui prend 2 arguments, un tableau de langages et le nouveau langage.

```php
<?php

$language_list = language_list();
// => []
$language_list = add_to_language_list($language_list, "Clojure");
// => ["Clojure"]
```

## 4. Définis une fonction pour retirer un élément du tableau de langages

Définis la fonction `prune_language_list` pour retirer le premier langage du tableau de langages.

```php
<?php

$language_list = language_list("PHP");
// => ["PHP"]
$language_list = prune_language_list($language_list);
// => []
```

## 5. Définis une fonction pour obtenir le premier élément du tableau

Définis la fonction `current_language` qui prend 1 argument (un _tableau de langages_).
Elle doit renvoyer le premier langage du tableau.
Suppose que le tableau contient toujours au moins un élément.

```php
<?php

$language_list = language_list("PHP", "Prolog");
// => ["PHP", "Prolog"]
$first = current_language($language_list);
// => "PHP"
```

## 6. Définis une fonction qui renvoie le nombre de langages dans le tableau

Définis la fonction `language_list_length` qui prend 1 argument (un _tableau de langages_).
Elle doit renvoyer le nombre de langages dans le tableau.

```php
<?php

$language_list = language_list("PHP", "Prolog", "Wren");
// => ["PHP", "Prolog", "Wren"]
language_list_length($language_list);
// => 3
```
