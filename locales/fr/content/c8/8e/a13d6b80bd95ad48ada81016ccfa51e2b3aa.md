# Les bases

Un programme Sather est composé de **classes** qui contiennent des **routines**.

```sather
class GREETER is

   hello : STR is
      return "Hello!";
   end;

end; -- class GREETER
```

## Classes

Une classe se nomme en majuscules, avec des traits de soulignement entre les mots : `GREETER`, `STAGE_DIRECTIONS`. Le nom du fichier correspond en général, en minuscules : `stage_directions.sa`.

Chaque routine vit à l'intérieur d'une classe. Il n'y a pas de code en dehors.

## Routines

Une routine qui produit une réponse déclare le type de réponse après un deux-points :

```sather
   hello : STR is
      return "Hello!";
   end;
```

`STR` est le type du texte. Une routine qui ne prend aucun argument s'écrit et s'appelle sans parenthèses.

Une routine peut prendre des arguments, écrits entre parenthèses après le nom :

```sather
   louder(word : STR) : STR is
      return word;
   end;
```

`return` renvoie une réponse et arrête la routine immédiatement, si bien que les lignes en dessous sont ignorées.

## Appelle

Depuis l'extérieur de la classe, nomme la classe, puis `::`, puis la routine :

```sather
GREETER::hello
```

Depuis l'intérieur de la même classe, on peut omettre le nom de la classe. C'est la façon habituelle de faire en sorte qu'une routine en utilise une autre :

```sather
   greeting_again : STR is
      return hello;
   end;
```

## Commentaires

Deux tirets commencent un commentaire qui va jusqu'à la fin de la ligne.

```sather
   -- Explain why, not what: the code already says what.
   hello : STR is
      return "Hello!";   -- a trailing comment is fine too
   end;
```

Par convention, une classe se termine par un commentaire qui la nomme. Les routines, les boucles et les classes se terminent toutes par `end;`, donc le commentaire indique à laquelle ce `end;` appartient :

```sather
end; -- class GREETER
```

## Points-virgules

Les instructions se terminent par un point-virgule. Le point-virgule après la dernière instruction d'une routine est facultatif, mais l'écrire à chaque fois, c'est une chose de moins à laquelle penser.
