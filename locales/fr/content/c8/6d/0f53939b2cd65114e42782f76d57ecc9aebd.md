# Instructions

Josh travaille sur un nouveau jeu de rôle et a besoin de ton aide pour implémenter certaines des mécaniques.

## 1. Définis les unions de types

Définis une union de types de `String` et `Missing` nommée `StringOrMissing`, qui pourra être utilisée plus loin dans le code.
Définis une union de types de `Int64` et `Nothing` nommée `IntOrNothing`, qui pourra être utilisée plus loin dans le code.

## 2. Implémente le type composite Player

Le type composite Player doit contenir quatre champs, chacun ayant une annotation de type et une valeur par défaut :
- Le `name` est un `StringOrMissing`, avec une valeur par défaut de `missing`
- Le `level` est un `Int64`, avec une valeur par défaut de `0`
- Le `health` est un `Int64`, avec une valeur par défaut de `100`
- Le `mana` est un `IntOrNothing`, avec une valeur par défaut de `nothing`

```julia-repl
julia> defaultplayer = Player()
Player(missing, 0, 100, nothing)

julia> wealthyplayer = Player(mana=100)
Player(missing, 0, 100, 100)

julia> namedplayer = Player(name="Guilian", level=10)
Player("Guilian", 10, 100, nothing)
```

## 3. Présente-toi

Implémente la fonction `introduce`.

Les joueurs furtifs peuvent cacher leur nom et seront présentés comme `"Mighty Magician"`.
Sinon, utilise simplement le nom du joueur pour le présenter.

```julia-repl
julia> introduce(Player(level=2, health=8))
"Mighty Magician"

julia> introduce(Player(name="Merlin", level=2, health=8))
"Merlin"
```

## 4. Implémente les méthodes d'incrémentation

La fonction utilitaire `increment` prend deux méthodes, chacune ayant une signature de fonction différente.
L'argument de chacune a besoin d'une annotation de type pour rendre la signature explicite.

La méthode `increment` pour les noms doit prendre le `name` d'un joueur.
- Si le nom est `missing`, renvoie le titre "The Great".
- Sinon, le titre " the Great" est ajouté au nom.

Cette méthode `increment` renvoie le nouveau nom.

```julia-repl
julia> player1 = Player(name="Ogre", level=5, health=49, mana=26)
Player("Ogre", 5, 49, 26)

julia> increment(player1.name)
"Ogre the Great"

julia> player2 = Player(level=32, mana=57)
Player(missing, 32, 100, 57)

julia> increment(player2.name)
"The Great"
```

La méthode `increment` pour le mana doit prendre le `mana` d'un joueur.
- Si le mana du joueur est `missing`, renvoie la valeur `50`.
- Sinon, le mana doit être augmenté de `100`.

Cette méthode `increment` renvoie le mana mis à jour.

```julia-repl
julia> player3 = Player(level=3)
Player(missing, 3, 100, nothing)

julia> increment(player3.mana)
50

julia> player4 = Player("Goblin", level=15, health=49, mana=26)
Player("Goblin", 5, 49, 26)

julia> increment(player4.mana)
126
```

## 5. Implémente la fonction de titre

Le niveau le plus élevé du jeu est `42`. Pour reconnaître l'exploit des joueurs qui atteignent ce niveau, un titre est ajouté à leur nom. La fonction `title!` met à jour le nom d'un joueur comme suit.

- Si le niveau du joueur est 42, le nom est mis à jour à l'aide de la fonction `increment`.
- Sinon, le nom reste inchangé.

Dans les deux cas, la fonction `title!` renvoie le nom du joueur.

```julia-repl
julia> player1 = Player(level=42, health=12)
Player(missing, 42, 12, nothing)

julia> title!(player1)
"The Great"

julia> player1.name
"The Great"

julia> player2 = Player(name="Svengali", level=42, health=36, mana=54)
Player("Svengali", 42, 36, 54)

julia> title!(player2)
"Svengali the Great"

julia> player2.name
"Svengali the Great"

julia> player3 = Player(name="Rasputin", level=21, health=100, mana=54)
Player("Rasputin", 21, 100, 54)

julia> title!(player3)
"Rasputin"

julia> player3.name
"Rasputin"
```

## 6. Implémente la fonction de réanimation

La fonction `revive!` doit vérifier que le personnage du joueur est bien mort (sa santé a atteint `0`).

Si le joueur est mort :
- Le joueur doit être réanimé avec une santé de `100`.
- Le mana du joueur doit être incrémenté à l'aide de la fonction `increment`.

Si le joueur est vivant, rien ne lui arrive.

La fonction `revive!` doit renvoyer le joueur.

```julia-repl
julia> deadplayer1 = Player(level=2, health=0)
Player(missing, 2, 0, nothing)

julia> revive!(deadplayer1)
Player(missing, 2, 100, 50)

julia> deadplayer2 = Player(level=12, health=0, mana=5)
Player(missing, 12, 0, 5)

julia> revive!(deadplayer2)
Player(missing, 12, 100, 105)

julia> aliveplayer = Player(level=23, health=1)
Player(missing, 23, 1, nothing)

julia> revive!(aliveplayer)
Player(missing, 23, 1, nothing)
```
