# À propos

Quand on travaille avec des nombres en F#, l'un des aspects essentiels est la distinction entre les entiers (nombres sans chiffres après le séparateur décimal) et les nombres à virgule flottante (nombres avec zéro ou plusieurs chiffres après le séparateur décimal).

Les deux types numériques les plus couramment utilisés en F# sont `int` (un entier 32 bits) et `float` (un nombre à virgule flottante 64 bits).

```fsharp
let i = 123   // Type is `int`
let d = 54.29 // Type is `float`
```

Les entiers comme les nombres à virgule flottante peuvent utiliser le caractère `_` comme _séparateur de chiffres_, ce qui peut être utile lorsqu'on définit de grands nombres :

```fsharp
let largeInt = 1_000_000
// => 1000000

let largeFloat = 9_876_543.21
// => 9876543.21
```

Les calculs se font à l'aide des [opérateurs arithmétiques][arithmetic-operators] standard (`+`, `-`, `*`, etc.). Les nombres peuvent être comparés à l'aide des [opérateurs de comparaison][comparison-operators] standard (`<`, `>=`, etc.) ainsi que des opérateurs d'égalité (`=`) et d'inégalité (`<>`).

```fsharp
5 * 6
// => 30

1.2 > 0.8
// => true

2 <> 4
// => true
```

Pour convertir un type numérique en un autre, il faut utiliser l'[opérateur de conversion][conversion-operators] intégré. Ces opérateurs portent le nom du type vers lequel ils convertissent.

```fsharp
let floatFromInt = float 2
let intFromFloat = int 3.39
```

Lorsqu'on convertit d'un type à un autre, il faut toujours être prudent. Si une valeur ne peut pas être représentée par le type cible, elle va déborder.
