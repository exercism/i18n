# À propos

L'opérateur ternaire conditionnel permet d'écrire une expression condensée qui renvoie l'une de deux valeurs alternatives selon une condition.
On l'appelle souvent l'« opérateur ternaire ».
Ce nom vient du fait que l'opérateur prend trois opérandes : `predicate ? consequent-expression : alternative-expression`
Il peut servir à remplacer de courtes instructions `if`-`else`.

Comme pour les instructions `if`, JavaScript effectue une conversion de type implicite pour évaluer la condition.
Si la condition est _truthy_, c'est l'opérande à gauche du deux-points qui est renvoyé.
Sinon, le résultat de l'expression ternaire est l'opérande à droite du deux-points.

```javascript
const year = 2020;

year > 2000 ? 'in the past years' : 'a long time ago';
// => 'in the past years'
```
