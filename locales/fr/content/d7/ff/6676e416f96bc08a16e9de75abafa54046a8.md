# Tests

## Lance les tests

Pour lancer les tests, exécute la commande suivante :

```bash
make
```

## Résous l'exercice

Résoudre un exercice, c'est faire passer tous ses tests. Par défaut, un seul test (le premier) est exécuté quand tu lances les tests. C'est intentionnel : cela te permet de te concentrer uniquement sur ce test, pour le faire passer. Une fois qu'il passe, tu peux activer le test suivant en supprimant la ligne `TEST_IGNORE()`. Quand tous les tests seront activés et que ton implémentation les fera tous passer, tu auras résolu l'exercice !
