# Introduction

## Exporte des fonctions

L'exportation de fonctions a été vue dans le premier concept, en voici un rapide rappel.

En Elm, chaque fichier est un module et doit contenir une instruction `module` avant tout autre code.

Le nom d'un module doit correspondre à celui de son fichier : le module `Calculator` doit donc se trouver dans le fichier Calculator.elm, et le module `Parser.Utils` dans le fichier Parser/Utils.elm.

Tout ce qui est défini dans un module a une portée privée : rien, à l'extérieur de ce module, ne peut y accéder, sauf ce qui est listé dans `exposing`.

```elm
-- Calculator.elm
-- Define the Calculator module, and expose the `add` function
module Calculator exposing (add)

six = 3 + 3

add number1 number2 = number1 + number2
```

```elm
-- Calculator.elm
-- Define the Calculator module, and expose everything within: `six` and `add`
module Calculator exposing (..)

six = 3 + 3

add number1 number2 = number1 + number2
```

https://elm-lang.org/docs/syntax#modules

## Importe des fonctions depuis d'autres modules

On accède aux fonctions définies dans d'autres modules grâce aux _imports_.
Toutes les fonctions de ce module qui ont été exposées par celui-ci deviennent accessibles lorsqu'on importe ce module.
La façon d'y accéder dépend toutefois de la manière dont le module est importé.

Les _imports_ qualifiés sont le comportement par défaut : pour accéder à une fonction d'un tel module (par exemple la fonction `map` du module `List`), on fait précéder son nom de celui du module (`List.map`).

Les _imports_ ouverts donnent un accès direct aux fonctions exposées par ce module, sans les préfixer. On les écrit avec le mot-clé `exposing`, en miroir de celui utilisé pour les exports. On peut exposer toutes les fonctions disponibles (avec `..`), ou seulement certaines (par exemple `map`).

On peut aussi importer des types et leurs constructeurs depuis d'autres modules, mais cela fait l'objet d'un concept ultérieur.

Les _imports_ qualifiés sont préférés, car ils clarifient le code et évitent les conflits de noms.

```elm
-- qualified imports
import List                            -- List.map, List.foldl
import List as L                       -- L.map, L.foldl

-- open imports
import List exposing (..)              -- map, foldl, concat, ...
import List exposing ( map, foldl )    -- map, foldl, List.concat
```

https://elm-lang.org/docs/syntax#modules

## Annotations de type

Une annotation de type s'écrit `name : parameter types -> return type`, les types des paramètres étant eux aussi séparés par `->`.

```elm
add : Int -> Int -> Int
add number1 number2 = number1 + number2
```

On peut utiliser des parenthèses pour définir les paramètres d'une fonction (qui sont eux-mêmes définis avec la même syntaxe, d'où le besoin de ces parenthèses).

```elm
-- Transform every character in a string
map : (Char -> Char) -> String -> String
map charMapperFunction string =
    -- ...
```

https://elm-lang.org/docs/syntax#type-annotations

## Nombres

Elm propose deux types de nombres, définis par les types `Int` et `Float`.
`Int` correspond à l'ensemble des entiers positifs et négatifs.
`Float` correspond à l'ensemble des nombres réels, limité par la précision de l'ordinateur.
Les opérations définies sur les nombres fonctionnent en général sur l'un ou l'autre des types, mais pas sur un mélange des deux.
Il existe des fonctions pour convertir l'un en l'autre : `toFloat` convertit un `Int` en `Float`, tandis que `round`, `floor`, `ceiling` ou `truncate` convertissent un `Float` en `Int` avec des sémantiques différentes.

https://package.elm-lang.org/packages/elm/core/latest/Basics#Int

## Opérations sur les _strings_

Pour représenter des mots et des phrases dans le code, Elm dispose d'un type `String` natif.
Les littéraux de type _string_ s'écrivent entre guillemets doubles, comme `"Hello World!"`.
Un opérateur de concaténation de _strings_ `++` et un opérateur d'égalité `==` sont disponibles par défaut.

```elm
hello : String -> String
hello subject = "Hello " ++ subject

hello "World!" --> "Hello World!"
```

La plupart des autres fonctions sur les _strings_ se trouvent dans le module `String`, qu'il faut importer.

https://package.elm-lang.org/packages/elm/core/latest/String
