# Instructions supplémentaires

## Notes d'implémentation

Un programme Factor est construit à partir de *mots*, regroupés en *vocabulaires*.

Factor charge un *vocabulaire* depuis un répertoire du même nom : le vocabulaire `hello-world` est donc le fichier `hello-world.factor` dans un répertoire `hello-world/`.

`: say-hello ( -- str ) … ;` définit le mot `say-hello`.
La partie entre parenthèses est son *effet de pile* : rien à gauche de `--` signifie qu'il ne prend aucune entrée, et `str` à droite signifie qu'il laisse une seule valeur (le nom n'est qu'une documentation, pas un type).
Tout ce qui se trouve entre l'effet de pile et le `;` de fermeture constitue le corps : le code qui s'exécute quand le mot est appelé.

La suite de tests appelle `say-hello` et vérifie la valeur qu'il laisse sur la pile.
Modifie le corps pour que le mot laisse plutôt `"Hello, World!"`, puis lance les tests.
