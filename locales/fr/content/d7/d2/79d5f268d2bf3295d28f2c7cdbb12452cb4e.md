# Introduction

## Formatage de _strings_

Il existe deux mécanismes principaux pour formater des _strings_ en C#/.NET : l'utilisation de `String.Format()` et l'interpolation de _strings_.

### Formatage composite

`String.Format()` prend une _string_ (appelée _format composite_ dans la documentation) composée de texte fixe et d'espaces réservés (appelés éléments de format dans la documentation), ainsi qu'un nombre variable d'arguments. La valeur de retour résout chaque élément de format à l'aide de l'argument correspondant, puis combine les valeurs résolues avec le texte fixe.

```csharp
string.Format("I had {0} bitcoins on {1}, the day I forgot my password.", 55.5, new DateTime(2010, 2, 25));
// => "I had 55.5 bitcoins on 2/25/2010 00:00:00, the day I forgot my password." - US settings
```

Ce mécanisme est techniquement appelé _formatage composite_.

### Interpolation de _strings_

Les chaînes interpolées sont précédées d'un `$` et contiennent des expressions évaluées à l'exécution, placées entre accolades. L'élément de format a la syntaxe suivante : `$"{<interpolationExpression>}"`. Elles suppriment le besoin d'une liste d'arguments séparée. Le résultat est fonctionnellement équivalent au mécanisme `String.Format()`.

```csharp
var loadsOf = 55.5;
var thatDay = new DateTime(2010, 2, 25);
$"I had {loadsOf} bitcoins on {thatDay}, the day I forgot my password."
// => "I had 55.5 bitcoins on 2/25/2010 00:00:00, the day I forgot my password." - US settings
```

### Éléments de format

Le texte entre accolades, c'est-à-dire les espaces réservés dans le cas du format composite et les expressions interpolées dans le cas de l'interpolation de _strings_, est appelé _élément de format_.

Un élément de format peut comporter jusqu'à 3 parties. La première est l'expression ou l'espace réservé d'argument obligatoire, comme dans l'exemple de code ci-dessus. Il y a en outre un alignement facultatif (introduit par une virgule, « , ») et une _chaîne de format_ facultative (introduite par deux-points, « : »).

`{<interpolationExpression>[,<alignment>][:<formatString>]}`

L'_alignement_ spécifie la longueur du « champ » dans lequel le texte est placé, complété par des espaces à gauche si l'alignement est positif, ou à droite s'il est négatif.

La _chaîne de format_ spécifie la forme du texte produit : faut-il par exemple inclure des séparateurs de milliers pour un nombre, ou bien produire uniquement la partie date d'un objet `DateTime` ?

Le code suivant illustre l'affichage de la partie date d'un objet `DateTime` et d'un nombre à virgule flottante sous forme exponentielle.

```csharp
var loadsOf = 55.5;
var thatDay = new DateTime(2010, 2, 25);
$"I had {loadsOf:E} bitcoins on {thatDay:d}, the day I forgot my password."
// => I had 5.550000E+001 bitcoins on 02/25/2010, the day I forgot my password. - US settings

string.Format(
    "I had {0:E} bitcoins on {1:d}, the day I forgot my password.",
    loadsOf, thatDay)
// => I had 5.550000E+001 bitcoins on 02/25/2010, the day I forgot my password. - US settings
```

Il existe un formatage standard et un formatage personnalisé, aussi bien pour les nombres que pour les dates. Il n'y a pas de différence essentielle entre les formats _personnalisés_ et _standard_, si ce n'est qu'on peut composer des chaînes de format personnalisées à partir de lettres de format.

### Culture

Chaque thread possède une culture par défaut, `Thread.CurrentThread.CurrentCulture`, encapsulée dans une instance de `CultureInfo`. La culture du thread détermine la façon dont les dates et les nombres sont formatés en fonction des variations régionales, comme la différence de format de date habituel entre le _DD/MM/YYYY_ britannique et le _MM/DD/YYYY_ américain.

`CultureInfo` implémente l'interface `IFormatProvider`, que l'on peut passer à certaines surcharges de `String.Format()`. Cela permet de remplacer la culture du thread.

## Chaînes verbatim

Les chaînes verbatim permettent d'écrire des _strings_ sur plusieurs lignes. Elles sont introduites par un @.

```csharp
string str = @"
See no wretched
quotes everywhere
";
```
