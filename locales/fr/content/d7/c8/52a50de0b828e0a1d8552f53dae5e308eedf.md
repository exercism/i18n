# Instructions

Sarah travaille sur un nouveau jeu de rôle et a besoin de ton aide pour les mécaniques du joueur.

## 1. Définis le tuple `player`

Définis une classe tuple `player` avec quatre emplacements et des valeurs par défaut :

| emplacement | valeur par défaut |
| -------- | ------- |
| `name`   | `f`     |
| `level`  | `0`     |
| `health` | `100`   |
| `mana`   | `f`     |

Une fois définie, on peut construire un joueur sous forme de littéral :

```factor
T{ player { name "Merlin" } { level 5 } } .
! => T{ player { name "Merlin" } { level 5 } }
```

## 2. Présente le joueur

Définis `introduce` pour renvoyer le nom du joueur. Les joueurs furtifs cachent leur nom (`name` vaut `f`) et doivent être présentés comme `"Mighty Magician"`.

```factor
T{ player { name "Merlin" } } introduce .
! => "Merlin"

T{ player { health 8 } } introduce .
! => "Mighty Magician"
```

## 3. Ranime un joueur tombé

Définis `revive` pour renvoyer un *nouveau* joueur avec `health` fixé à 100 et `mana` fixé à 100, mais uniquement si le `health` du joueur vaut `0`. Si le joueur est encore en vie, renvoie `f`.

```factor
T{ player { name "Merlin" } { health 0 } } revive .
! => T{ player { name "Merlin" } { health 100 } { mana 100 } }

T{ player { health 50 } } revive .
! => f
```

## 4. Subis des dégâts

Définis `take-damage` pour renvoyer un *nouveau* joueur dont le `health` a été réduit de la quantité donnée, sans jamais descendre en dessous de `0`.

```factor
T{ player { health 100 } } 30 take-damage .
! => T{ player { health 70 } }

T{ player { health 5 } } 30 take-damage .
! => T{ player { health 0 } }
```
