# Ajout aux instructions

## Indices

C'est le premier exercice dont les tests exigent que tu lèves une [`Exception`][exception-docs].
On lève généralement une `Exception` pour indiquer qu'un programme a rencontré une entrée ou un état inattendu.

Tout au long du parcours, les tests vérifieront que les exceptions que tu lèves sont :

1. des instances d'un type Java donné ;
2. (facultativement) initialisées avec un message donné.

[exception-docs]: https://docs.oracle.com/javase/8/docs/api/java/lang/Exception.html
