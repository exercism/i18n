# Instruction de cas d'usage

Même si cet exercice peut se résoudre d'une autre manière, la façon privilégiée de manipuler les types personnalisés reste le [filtrage par motif][pattern-matching].
Pour te permettre d'apprendre cette technique, utilise une instruction `case` dans ta solution.

[pattern-matching]: https://guide.elm-lang.org/types/pattern_matching.html
