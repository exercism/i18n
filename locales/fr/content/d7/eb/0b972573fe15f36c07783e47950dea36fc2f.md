# À propos

Elixir représente les valeurs vrai et faux avec le type booléen. Il n'existe que deux valeurs : `true` et `false`. Ces valeurs peuvent être combinées avec des opérateurs booléens ([`and/2`][strict-and], [`or/2`][strict-or], [`not/1`][strict-not]) :

```elixir
true_variable = true and true
false_variable = true and false

true_variable = false or true
false_variable = false or false

true_variable = not false
false_variable = not true
```

Les opérateurs [`and/2`][strict-and], [`or/2`][strict-or] et [`not/1`][strict-not] sont strictement booléens, ce qui signifie qu'ils exigent que leur _premier_ argument soit un booléen. Il existe aussi des opérateurs booléens équivalents qui fonctionnent avec tout type d'arguments : [`&&/2`][and], [`||/2`][or] et [`!/1`][not].

Les opérateurs booléens utilisent une _évaluation en court-circuit_, ce qui signifie que l'expression à droite de l'opérateur n'est évaluée que si c'est nécessaire.

Chaque opérateur a une précédence différente : `not/1` est évalué avant `and/2` et `or/2`. On peut utiliser des parenthèses pour évaluer une partie de l'expression avant les autres :

```elixir
not true and false
# => false

not (true and false)
# => true
```

Quand on écrit une fonction qui renvoie une valeur booléenne, il est [idiomatique de terminer le nom de la fonction][naming] par un `?`. La même convention peut s'appliquer aux variables qui stockent des valeurs booléennes.

```elixir
def either_true?(a?, b?) do
  a? or b?
end
```
