# Introduction

Des classes comme `LocalDate` et `LocalDateTime` décrivent un _point_ dans le temps.
Le paquetage `java.time` contient aussi deux classes qui décrivent une _quantité_ de temps :

- `java.time.Period` est une quantité de temps en années, mois et jours, comme « 2 mois et 5 jours ».
- `java.time.Duration` est une quantité de temps en heures, minutes, secondes, millisecondes et nanosecondes, comme « 1 heure et 30 minutes ».

Un `Period` suit le calendrier : on l'utilise donc avec des dates et des date-heures.
Un `Duration` mesure un temps exact : on l'utilise donc avec des heures et des date-heures, mais pas avec des dates.

```exercism/note
Comme les autres classes de `java.time`, `Period` et `Duration` sont immuables.
Les méthodes qui semblent les modifier renvoient à la place une _nouvelle_ instance.
```

## `Period`

On crée un `Period` avec l'une de ses méthodes de fabrique statiques :

```java
Period.ofDays(10);
// => P10D

Period.ofMonths(3);
// => P3M

Period.of(1, 2, 15);
// => P1Y2M15D
```

Le résultat de `toString()` utilise la notation [ISO-8601][iso-8601-durations] : `P` (pour « _period_ ») suivi du nombre d'années (`Y`), de mois (`M`) et de jours (`D`).

Une période peut être ajoutée à une date, ou retirée de celle-ci :

```java
LocalDate date = LocalDate.of(2024, 3, 10);

date.plus(Period.ofMonths(2));
// => 2024-05-10

date.minus(Period.ofDays(10));
// => 2024-02-29
```

Comme les mois n'ont pas tous la même longueur, ajouter des mois peut tomber sur un jour qui n'existe pas.
Dans ce cas, le résultat est ramené au dernier jour valide du mois :

```java
LocalDate.of(2025, 1, 31).plus(Period.ofMonths(1));
// => 2025-02-28
```

`Period.between()` renvoie la période entre deux dates, la première incluse et la seconde exclue :

```java
LocalDate start = LocalDate.of(2023, 3, 10);
LocalDate end = LocalDate.of(2024, 5, 25);

Period period = Period.between(start, end);
// => P1Y2M15D

period.getYears();
// => 1
period.getMonths();
// => 2
period.getDays();
// => 15
```

## Compte les unités avec `ChronoUnit`

Un `Period` garde ses années, ses mois et ses jours séparés.
Ainsi, `getDays()` ne renvoie que la _partie_ jours de la période, et non le nombre total de jours.
Pour compter le nombre total d'une unité donnée entre deux dates, utilise la méthode `between()` de [`java.time.temporal.ChronoUnit`][chronounit-docs] :

```java
LocalDate start = LocalDate.of(2024, 1, 15);
LocalDate end = LocalDate.of(2024, 3, 20);

Period.between(start, end);
// => P2M5D

Period.between(start, end).getDays();
// => 5

ChronoUnit.DAYS.between(start, end);
// => 65
```

Le résultat est négatif quand la seconde date est antérieure à la première :

```java
ChronoUnit.DAYS.between(end, start);
// => -65
```

## `Duration`

On crée aussi un `Duration` avec des méthodes de fabrique statiques :

```java
Duration.ofMinutes(90);
// => PT1H30M

Duration.ofHours(2).plusMinutes(15);
// => PT2H15M
```

Dans la notation ISO-8601, le `T` sépare la partie date de la partie heure, ce qui explique que les durées s'écrivent `PT...`.

Une durée peut être ajoutée à une date-heure, ou retirée de celle-ci :

```java
LocalDateTime start = LocalDateTime.of(2024, 3, 10, 22, 30);

start.plus(Duration.ofMinutes(90));
// => 2024-03-11T00:00
```

`Duration.between()` renvoie la quantité exacte de temps entre deux date-heures :

```java
LocalDateTime checkIn = LocalDateTime.of(2024, 3, 10, 18, 5);
LocalDateTime checkOut = LocalDateTime.of(2024, 3, 10, 19, 40);

Duration.between(checkIn, checkOut);
// => PT1H35M
```

On peut convertir une durée en une seule unité avec des méthodes comme `toHours()`, `toMinutes()` et `toSeconds()`.
Celles-ci renvoient la quantité _totale_ dans cette unité, arrondie à l'inférieur :

```java
Duration duration = Duration.ofMinutes(95);

duration.toHours();
// => 1
duration.toMinutes();
// => 95
```

Pour décomposer une durée en ses parties, comme sur une horloge, utilise plutôt les méthodes `toXxxPart()` :

```java
Duration duration = Duration.ofMinutes(95);

duration.toHoursPart();
// => 1
duration.toMinutesPart();
// => 35
```
