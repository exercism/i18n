# Instructions

Dans cet exercice, tu dois implémenter quelques règles de [Pac-Man][Pac-Man], le jeu d'arcade classique des années 1980.

Tu as quatre règles à implémenter, toutes liées aux états du jeu.

> _Ne te préoccupe pas de la façon dont les arguments sont obtenus, concentre-toi simplement sur la combinaison des arguments pour renvoyer le résultat attendu._

## 1. Définis si Pac-Man mange un fantôme

Définis la fonction `eat_ghost()` qui prend deux paramètres (_si Pac-Man a une super pastille active_ et _si Pac-Man touche un fantôme_) et renvoie une valeur booléenne indiquant si Pac-Man peut manger un fantôme.
 La fonction ne doit renvoyer `True` que si Pac-Man a une super pastille active et touche un fantôme.

```python
>>> eat_ghost(False, True)
...
False
```

## 2. Définis si Pac-Man marque des points

Définis la fonction `score()` qui prend deux paramètres (_si Pac-Man touche une super pastille_ et _si Pac-Man touche un point_) et renvoie une valeur booléenne indiquant si Pac-Man a marqué des points.
 La fonction doit renvoyer `True` si Pac-Man touche une super pastille ou un point.

```python
>>> score(True, True)
...
True
```

## 3. Définis si Pac-Man perd

Définis la fonction `lose()` qui prend deux paramètres (_si Pac-Man a une super pastille active_ et _si Pac-Man touche un fantôme_) et renvoie une valeur booléenne indiquant si Pac-Man perd.
 La fonction doit renvoyer `True` si Pac-Man touche un fantôme et n'a pas de super pastille active.

```python
>>> lose(False, True)
...
True
```

## 4. Définis si Pac-Man gagne

Définis la fonction `win()` qui prend trois paramètres (_si Pac-Man a mangé tous les points_, _si Pac-Man a une super pastille active_, et _si Pac-Man touche un fantôme_) et renvoie une valeur booléenne indiquant si Pac-Man gagne.
 La fonction doit renvoyer `True` si Pac-Man a mangé tous les points et n'a pas perdu selon les règles définies dans la partie 3.

```python
>>> win(False, True, False)
...
False
```
