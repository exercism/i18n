# Installe Python

Si Python n'est pas déjà installé sur ton système, tu trouveras des instructions détaillées par plateforme dans la section [Python Setup and Usage][using python] de la documentation officielle.
Real Python propose également un [guide bien fait][helpful guide] pour l'installation sur différentes plateformes, dont iOS et Android.

Enfin, ces articles de Brett Cannon, [A quick-and-dirty guide][quick-and-dirty] et [Why you should use `python -m pip`][python-m-pip], donnent de très bons conseils sur la gestion des installations et des paquets Python.

**Note pour les utilisateurs de MacOS :** avant MacOS Monterey (12.3), `Python 2.7` était préinstallé avec le système d'exploitation.
Utiliser `Python 2.7` avec Exercism ou la plupart des autres programmes n'est pas pris en charge.
Tu devrais plutôt installer [Python 3][Python-three downloads] avec l'une des méthodes détaillées ci-dessous.
À partir de MacOS Monterey (12.3), aucune version de Python n'est préinstallée avec MacOS.

Quelques liens directs vers la documentation, par système d'exploitation :

-  [Windows][windows] En complément, cet article de Microsoft sur [l'installation de Python sous Windows][python-on-windows] est utile.
-  [Systèmes Unix et Linux][unix-and-linux] (_ces méthodes fonctionnent en grande partie pour MacOS aussi_)
-  [MacOS][macos]

   Nous te recommandons aussi de regarder certaines des méthodes décrites dans l'article Real Python [Installing Python][installing-python] ou les articles de Brett Cannon cités plus haut.


Les tests et l'outillage d'Exercism prennent actuellement en charge `3.10` - `3.13.5` (_tests_) et [`Python 3.13.5`][313-new-features] (_outillage_).
Les exceptions à cette prise en charge sont signalées là où elles se produisent.
La plupart des exercices fonctionneront avec `Python 3.6+`, ou même des versions plus anciennes.
Mais nous ne garantissons pas la prise en charge des versions qui ne figurent pas dans [Active Python Releases][active-python-releases].


Reporte-toi à la [documentation Python 3.13.x][3.13 docs] pour savoir ce qui est pris en charge actuellement.
