# Introduction

En Cairo, les conversions de types permettent de transformer des données d'un type à un autre, pour une manipulation souple et sûre des données.

## Les bases

Cairo propose plusieurs mécanismes de conversion de types :

### La conversion directe

Pour les types numériques compatibles, on peut utiliser la conversion directe :

```rust
let small_number: u8 = 42;
let big_number: u32 = small_number.into();
```

### Le trait `Into`

Le trait `Into` permet de convertir un type en un autre :

```rust
let value: u16 = 100;
let converted: u32 = value.into();
```

### Le trait `TryInto`

Pour les conversions susceptibles d'échouer, utilise `TryInto`, qui renvoie une `Option` :

```rust
let large_value: u32 = 70000;
let small_value: Option<u16> = large_value.try_into();

match small_value {
    Option::Some(v) => println!("Converted: {}", v),
    Option::None => println!("Conversion failed"),
}
```

## Les conversions de types personnalisées

Tu peux implémenter `Into` pour tes propres types :

```rust
#[derive(Drop)]
struct Celsius {
    value: i32,
}

#[derive(Drop)]
struct Fahrenheit {
    value: i32,
}

impl CelsiusIntoFahrenheit of Into<Celsius, Fahrenheit> {
    fn into(self: Celsius) -> Fahrenheit {
        Fahrenheit { value: (self.value * 9) / 5 + 32 }
    }
}
```

## Considérations de sécurité

- Utilise `TryInto` quand la conversion risque d'échouer (par exemple, d'un grand type vers un petit type)
- Utilise `Into` quand la conversion réussit toujours
- Gère toujours les cas `Option::None` renvoyés par `TryInto`
- Fais attention au dépassement de capacité et au sous-dépassement lors des conversions entre types signés et non signés
