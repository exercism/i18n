# Instructions

Ton ami Kojo est un grand fan de nombres.
Il a un petit site web appelé « fun-with-numbers ».
Kojo n'est pas très bon en programmation, alors il t'a demandé de l'aide.

Tu vas créer deux fonctions auxiliaires pour de nouveaux jeux de nombres sur le site de Kojo, et une troisième pour valider certaines entrées que l'utilisateur peut saisir.

## 1. Calcule la somme des nombres sur la machine à sous

L'un des jeux sur le site de Kojo ressemble à une machine à sous qui affiche deux groupes de roues avec des chiffres dessus.
Chaque groupe de chiffres représente un nombre.
Pour la mécanique du jeu, Kojo a besoin de connaître la somme de ces deux nombres.

Écris une fonction `twoSum` qui prend deux tableaux en paramètres.
Chaque tableau contient un ou plusieurs nombres entre 0 et 9.
La fonction doit interpréter chaque tableau comme un nombre et renvoyer la somme de ces deux nombres.

```javascript
twoSum([1, 2, 3], [0, 7]);
//=> 130

// [1, 2, 3] represents 123 and [0, 7] represents 7.
// 123 + 7 = 130
```

## 2. Détermine si un nombre est un palindrome

Un autre jeu sur le site est un petit quiz appelé « Nombres chanceux ».
Un utilisateur peut saisir un nombre et voit ensuite si ce nombre appartient à une séquence ou à un motif secret.
La séquence ou le motif des « nombres chanceux » change chaque mois, et chaque utilisateur ne dispose que d'un nombre limité d'essais pour le deviner.

Les nombres chanceux de ce mois-ci doivent être des nombres palindromes.
Les nombres palindromes restent identiques lorsqu'on inverse leurs chiffres.

Implémente la nouvelle fonction `luckyNumber` qui prend un nombre en paramètre.
La fonction doit renvoyer `true` si le nombre est un palindrome et `false` sinon.
Le nombre en entrée sera toujours un entier positif.

```javascript
luckyNumber(1441);
//=>  true

luckyNumber(123);
//=> false
```

## 3. Génère un message d'erreur pour une entrée utilisateur invalide

À divers endroits sur le site, il y a des champs de saisie où les utilisateurs peuvent saisir des nombres et cliquer sur un bouton pour déclencher une action.
Kojo veut améliorer l'expérience utilisateur de son site.
Il veut afficher un message d'erreur si l'utilisateur clique sur le bouton alors que le champ contient une valeur d'entrée invalide.

Voici quelques informations supplémentaires sur la manière dont la valeur d'un champ de saisie est fournie.

- Si l'utilisateur saisit quelque chose dans un champ, la valeur associée est toujours une _string_, même s'il n'a saisi que des nombres.
- Si l'utilisateur saisit quelque chose puis l'efface, la variable sera une _string_ vide.
- Avant même que l'utilisateur ait commencé à saisir, la variable peut être `undefined` ou `null`.

Écris une fonction `errorMessage` qui prend l'entrée utilisateur en paramètre.
Si l'utilisateur n'a fourni aucune entrée, `errorMessage` doit renvoyer `'Required field'`.
Si l'entrée ne représente pas un nombre différent de zéro (selon les règles de conversion JavaScript), il faut renvoyer `'Must be a number besides 0'`.
Dans tous les autres cas, tu peux considérer que l'entrée est valide, la valeur de retour doit être une _string_ vide.

```javascript
errorMessage('123');
// => ''

errorMessage('');
// => 'Required field'

errorMessage('abc');
// => 'Must be a number besides 0'
```
