# Introduction

## Paramètres

Cet exercice aborde quelques détails des paramètres de méthode et de leur utilisation en C#.

Les paramètres transmettent des informations d'une méthode appelante à une méthode appelée.

- Le comportement des paramètres peut être modifié par l'utilisation de modificateurs tels que `ref` et `out`.

- Un paramètre avec le modificateur `out` transmet une valeur de la méthode appelée vers l'appelant. Ce paramètre peut être passé à la méthode appelée sans être initialisé et, de toute façon, dans la méthode appelée, il est traité comme s'il n'avait pas été initialisé à l'entrée. On comprend plus facilement le comportement et les règles concernant les modificateurs de paramètres à l'aide d'exemples (voir ci-dessous) et des messages du compilateur.

```csharp
void Foo(out int val)
{
    val = 42;
}
void Bar(int val)
{
    val = 42;
}

int importantValue = 1729;
Foo(out importantValue);
var result = importantValue == 42;
// => true

importantValue = 1729;
Bar(importantValue);
result = importantValue == 1729;
// => true
```

- Les paramètres `out` doivent être affectés dans une méthode appelée.

- Un paramètre avec le modificateur `ref` transmet une valeur à une méthode appelée. Lorsque la méthode se termine, l'appelant retrouve dans ce paramètre toutes les modifications effectuées par la méthode appelée.

```csharp
void Foo(ref int val)
{
    val *= 7;
}

int importantValue = 6;
Foo(ref importantValue);
return importantValue;
// => 42
```

- Les paramètres `ref` doivent être des variables, car la méthode appelée agit directement sur le paramètre tel que le voit l'appelant.
- Les modificateurs `out` et `ref` sont obligatoires à la fois dans la signature de la méthode appelée et au niveau du site d'appel.
