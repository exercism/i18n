# Aide

Les meilleurs endroits pour obtenir de l'aide avec Chapel sont [Chapel discourse][discourse-link] ou [stack overflow avec le tag chapel][so-link].
Si tu n'y trouves pas déjà de réponse, n'hésite pas à poser une nouvelle question !

Tu peux aussi poser ta question sur le [Chapel gitter][gitter-link], mais privilégie les deux options ci-dessus.
Ainsi, ta question et les réponses pourront aussi aider d'autres personnes qui rencontreront le même problème.

[discourse-link]: https://chapel.discourse.group/
[so-link]: https://stackoverflow.com/questions/tagged/chapel
[gitter-link]: https://gitter.im/chapel-lang/chapel
