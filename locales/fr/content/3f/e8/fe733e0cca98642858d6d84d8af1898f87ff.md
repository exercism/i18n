# Indices

## 1. Décrire des nombres simples

- utilise `fmt.Sprintf` pour formater

## 2. Décrire une boîte à nombres

- récupère le résultat renvoyé par la méthode `Number()`
- utilise `fmt.Sprintf` pour formater

## 3. Implémente une méthode qui extrait le nombre d'une boîte à nombres sophistiquée

- utilise une assertion de type pour vérifier qu'il s'agit bien d'un `FancyNumber`
- récupère la `string` à l'aide de la méthode `Value()`
- utilise `strconv.Atoi` pour convertir la `string` en `int` (on peut ignorer l'erreur, car on veut 0 si la conversion en `int` échoue)

## 4. Décrire une boîte à nombres sophistiquée

- utilise `ExtractFancyNumber` pour obtenir la valeur `int`
- convertis la valeur `int` en `float64`
- utilise `fmt.Sprintf` pour formater

## 5. Implémente `DescribeAnything`, qui utilise tout ce qui précède

- utilise soit des assertions de type (par exemple `i.(someType)`), soit un type switch (`switch v := i.(type)`)
- n'oublie pas de convertir les `int` en `float64`
