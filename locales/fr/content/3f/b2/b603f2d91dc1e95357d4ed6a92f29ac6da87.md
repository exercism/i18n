# Ajout aux instructions

## Astuces

Pour réaliser cet exercice, tu dois implémenter la fonction `slices`, qui prend un *texte* et renvoie les sous-séquences de chiffres d'une taille donnée :

Si c'est la première fois que tu résous cet exercice, il est recommandé de t'en tenir à la signature fournie :

```haskell
slices :: Int -> String -> [[Int]]
```

Plus tard, tu peux envisager de revenir sur ce problème et de jouer avec d'autres types de données et bibliothèques :

- `ByteString`, du paquet *bytestring*.
- `Sequence`, du paquet *containers*.
- `Text`, du paquet *text*.
- `Vector`, du paquet *vector*.

La suite de tests a été délibérément conçue pour accepter presque n'importe quelle signature de type qui a du sens, alors on t'encourage à trouver celle qui te semble la meilleure.
