# À propos

L'instruction `guard` de Swift sert à effectuer des retours anticipés depuis une fonction Swift lorsque la condition nécessaire pour que le traitement se poursuive n'est pas remplie, par exemple :

```swift
guard myValue = 0 else { return 0 }
let root = myValue.squareRoot()
```

Ici, le `guard` vérifie si l'expression booléenne qui suit le mot-clé `guard` est vraie. Si c'est le cas, le traitement se poursuit avec le code qui suit l'instruction `guard` (ici `let root = myValue.squareRoot()`). Sinon, c'est le code de la clause `else` qui est exécuté. Contrairement à une instruction `if`, une instruction `guard` _doit_ comporter une clause `else`, et contrairement à la clause `else` d'un `if`-`else`, la clause `else` d'un `guard` _doit_ quitter la portée de l'instruction `guard`. C'est-à-dire qu'elle doit utiliser une instruction de transfert de contrôle telle que `return`, `continue` ou `break`, ou bien lever une erreur ou quitter le programme.

Un exemple d'utilisation est la fonction sinc, qui est égale à sin(x)/x avec sinc(0) défini comme valant 1, ce qui évite les problèmes de division par zéro. Cette fonction peut s'écrire en Swift, à l'aide d'un `guard`, comme ceci :

```swift
func sinc(_ x: Double) -> Double {
    guard x != 0 else { return 1 }
    return sin(x) / x
}

sinc(0)              // returns 1
sinc(Double.pi / 2)  // returns 0.6366197723675814
```
