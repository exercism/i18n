# Instructions

Dans cet exercice, on va traiter des lignes de log.

Chaque ligne de log est une _string_ formatée comme suit : `"[<LEVEL>]: <MESSAGE>"`.

Il existe trois niveaux de log différents :

- `INFO`
- `WARNING`
- `ERROR`

Tu as plusieurs tâches, et chacune prend une ligne de log et te demande d'en faire quelque chose.

## 1. Permets de récupérer la _string_ après une sous-chaîne donnée

En regardant les logs du mois dernier, tu vois que le message de test se trouve toujours après une sous-chaîne donnée. Comme tu prévois de devoir extraire le message de test dans un futur proche, tu décides de créer une méthode utilitaire pour t'aider à le faire.

Implémente la méthode d'extension (_static_) `LogAnalysis.SubstringAfter()`, qui prend une _string_ comme délimiteur et renvoie la sous-chaîne qui suit ce délimiteur.

```csharp
var log = "[INFO]: File Deleted.";
log.SubstringAfter(": "); // => returns "File Deleted."
```

## 2. Permets de récupérer la _string_ entre deux sous-chaînes

En y regardant de plus près, tu vois que le niveau de log se trouve toujours entre crochets (`[` et `]`). Comme tu prévois également de devoir extraire le niveau de log dans un futur proche, tu décides de créer une autre méthode utilitaire pour t'aider à le faire.

Implémente la méthode d'extension (_static_) `LogAnalysis.SubstringBetween()` qui prend deux _strings_ comme délimiteurs et renvoie la sous-chaîne comprise entre ces deux délimiteurs.

```csharp
var log = "[INFO]: File Deleted.";
log.SubstringBetween("[", "]"); // => returns "INFO"
```

## 3. Analyse le message dans un log

Implémente la méthode d'extension (_static_) `LogAnalysis.Message()` pour renvoyer le message contenu dans un log.

```csharp
var log = "[ERROR]: Missing ; on line 20.";
log.Message(); // => returns "Missing ; on line 20."
```

## 4. Analyse le niveau de log dans un log

Implémente la méthode d'extension (_static_) `LogAnalysis.LogLevel()` pour renvoyer le niveau de log d'un log.

```csharp
var log = "[ERROR]: Missing ; on line 20.";
log.LogLevel(); // => returns "ERROR"
```
