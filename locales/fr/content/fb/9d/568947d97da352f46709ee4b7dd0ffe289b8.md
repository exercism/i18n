# À propos

Kotlin a été conçu et développé par JetBrains, la société derrière IntelliJ. 
C'est un langage qui s'exécute sur la JVM et peut cibler les versions 6 et au-delà (y compris la [plateforme Android](https://blog.jetbrains.com/kotlin/2017/05/kotlin-on-android-now-official/)).
JetBrains voulait utiliser un langage à typage statique capable d'éliminer le code passe-partout de Java, d'apporter des paradigmes fonctionnels modernes et d'offrir une interopérabilité Java bidirectionnelle transparente avec sa base de code existante. 
La JVM disposait déjà d'autres langages comme Groovy et Scala, mais aucun ne répondait à leurs critères, alors ils ont créé Kotlin.

La syntaxe de Kotlin est proche de celle de Scala et de Swift, mais elle reprend les meilleures fonctionnalités d'autres langages tels que
C# et Groovy. 
Kotlin a adopté une approche pragmatique pour les fonctionnalités intégrées au langage, en ne proposant que celles qui
se sont révélées utiles aux développeurs. 
Avec cette décision, ils ont implémenté un sous-ensemble des fonctionnalités de Scala, avec l'intention d'offrir un code plus facile à maintenir et une courbe d'apprentissage plus douce aux développeurs en quête d'un « meilleur Java ».

JetBrains a une équipe dédiée de développeurs qui travaillent sur Kotlin, et la base de code est disponible sur [Github](https://github.com/JetBrains/kotlin).
