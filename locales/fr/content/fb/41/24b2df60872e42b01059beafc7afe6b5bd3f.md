# Introduction

Tout comme on peut créer un pointeur vers un `int` ou un autre type de données de base, on peut créer un pointeur vers une fonction.
Un pointeur de fonction permet de passer une fonction à une autre fonction.
Une fonction qui est passée comme valeur de paramètre à une autre fonction est appelée fonction de première classe.
Une fonction qui prend une ou plusieurs fonctions en paramètre, ou qui renvoie une fonction, est appelée fonction d'ordre supérieur.

Dans l'exemple suivant, `is_even` et `is_odd` sont des fonctions de première classe.
La fonction d'ordre supérieur est `test_number`.

```c
#include <stdio.h>
#include <stdbool.h>

bool is_even (int number) {
    return number & 1 != 1;
}

bool is_odd (int number) {
    return number & 1 == 1;
}

// this function takes any other function which takes a number and returns a bool
void test_number(bool (*func) (int), int number, char *text){
    printf(text, number, func(number)? "true": "false");
}

int main() {
    // prints Testing odd for 3 is true
    test_number(is_odd, 3,"Testing odd for %d is %s\n");
    // prints Testing even for 3 is false
    test_number(is_even, 3,"Testing even for %d is %s\n");
}
```
La signature de fonction `bool (*func) (int)` du premier argument de `test_number` correspond à la signature des fonctions passées.
`is_even` et `is_odd` prennent toutes les deux un paramètre `int` et renvoient un `bool`.
Dans `(*func)`, `func` représente le nom de la fonction à utiliser.
Si l'on avait utilisé `(*fn)`, alors on l'aurait appelée ainsi : `printf(text, number, fn(number)? "true": "false");`.
Pour satisfaire le paramètre de type pointeur de fonction, on passe le nom d'une fonction ayant la signature attendue au moment d'appeler `test_number`.
Ainsi, on voit qu'un nom de fonction pointe vers l'adresse de cette fonction.
