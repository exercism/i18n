# Instructions

Tu as soudain une envie de _pancakes_.
En tant que personne moderne à l’esprit technique, tu écris une liste de courses pour les ingrédients des _pancakes_ au format JSON.
La structure de la liste est :

```json
{
  "name": "name of shopping list",
  "ingredients": [ ...list of ingredients... ],
  "optional ingredients": [ ...list of ingredients... ]
}
```

Un ingrédient est représenté par un objet JSON, comme ceci :

```json
{
  "item": "flour",
  "amount": {
    "quantity": 2,
    "unit": "cup"
  }
}
```

Un ingrédient possède une propriété facultative nommée `"substitute"` qui contient une _string_ désignant un autre ingrédient pouvant être utilisé à la place.

Voyons comment on peut examiner la liste de courses avec `jq`

## 1. Extrais le nom de la liste de courses

Écris une expression qui produit l’élément "name" de la liste de courses.

## 2. Compte combien d’ingrédients sont nécessaires

Ne compte que les ingrédients requis. N’inclus pas les ingrédients facultatifs.

## 3. Combien de sucre ?

Écris une expression qui produit la quantité de sucre.
Seule la partie numérique est demandée.

## 4. Associe les ingrédients qui peuvent être remplacés

Certains ingrédients peuvent être remplacés (si tu n’as pas l’ingrédient X, tu peux utiliser Y).
Produis un objet JSON qui associe l’ingrédient recommandé à son substitut.
Inclus les ingrédients facultatifs dans l’association.
