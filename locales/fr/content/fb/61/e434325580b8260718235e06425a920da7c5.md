# conditionnels inutiles

Cette solution utilise inutilement des [conditionnels][conditionals].
Combiner un [argument par défaut][default argument] avec [str.format][str.format] ou des _f-strings_ (_aussi appelées « chaînes de caractères formatées » ou « chaînes interpolées »_) permet de rendre le code plus clair et moins verbeux.

Consulte cet article sur les [arguments par défaut en Python][python default arguments] pour plus de détails.
L'article de blog [le formatage des chaînes en Python][string formatting in python] peut aussi être un bon point de départ pour découvrir les options de formatage de chaînes de Python.
