# Introduction

En Swift, on ne peut pas indexer une _string_ avec un entier (comme `string[3]`).
Comme les _strings_ Swift sont composées de caractères Unicode de longueur variable, trouver un caractère demande de parcourir les caractères qui le précèdent.

Pour accéder au caractère situé à une position donnée, il faut calculer un indice de type `String.Index`.
Ces indices sont appelés des _indices opaques_, car leur structure interne est gérée par Swift plutôt que manipulée directement comme des entiers bruts :

```swift
let csv = "apple,pear,peach,orange,cherry,lime,gooseberry"
let index = csv.index(csv.startIndex, offsetBy: 21)
print(csv[index])
// Prints "g"

print(index)
// Prints internal representation: Index(_rawBits: ...)
```
