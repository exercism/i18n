# À propos

Le filtrage consiste à créer une séquence à partir d'une autre séquence, en copiant tous les éléments de la séquence d'origine sauf certains d'entre eux.
Le choix des éléments à inclure dans la nouvelle séquence peut se faire à l'aide d'une fonction prédicat (une fonction qui s'évalue à une valeur booléenne), ou par égalité avec un objet précis.

## Supprime avec un prédicat

`remove-if` est une fonction qui prend une fonction prédicat et une séquence en arguments, et qui renvoie une séquence contenant uniquement les éléments pour lesquels le prédicat s'est évalué à faux.
Autrement dit, elle « supprime » tous les éléments de la séquence pour lesquels le prédicat s'évalue à vrai. Note cependant que cette fonction ne modifie pas la séquence d'origine !
À la place, elle renvoie une nouvelle séquence dépourvue des éléments concernés. Si le prédicat était vrai pour toutes les valeurs, c'est une séquence vide qui est renvoyée.

```lisp
(remove-if #'evenp '(1 2 3 4 5)) ; => (1 3 5)
(remove-if #'oddp '(1 3 5))      ; => ()
```

## Garde des éléments avec un prédicat

Il existe une fonction `remove-if-not`, identique à `remove-if` à ceci près qu'elle *garde* les éléments pour lesquels le prédicat s'évalue à vrai.

Autrement, on peut utiliser `complement` pour transformer un prédicat en son « opposé ».

```lisp
(remove-if #'evenp '(1 2 3 4 5 6))             ; => (1 3 5)
(remove-if-not #'oddp '(1 2 3 4 5 6))          ; => (1 3 5)
(remove-if (complement #'oddp) '(1 2 3 4 5 6)) ; => (1 3 5)
```

## Supprime un élément précis

Pour supprimer un élément précis d'une séquence, on peut utiliser `remove`, qui prend l'élément à supprimer et une séquence.
Toutes les valeurs de la séquence qui ne sont pas égales à l'élément à supprimer sont renvoyées.

```lisp
(remove 1 '(1 2 1 3 1 4)) ; => (2 3 4)
(remove #\l "hello")      ; => "heo"
```

La fonction à utiliser pour tester l'égalité peut être précisée avec le [paramètre mot-clé][concept-keyword-parameters] `:test`.

Note que `remove` pourrait être implémentée avec `remove-if`, en écrivant un prédicat qui teste l'égalité d'un objet avec un élément précis.

## De nombreuses options

Chacune de ces fonctions prend aussi de nombreux autres [paramètres mot-clé][concept-keyword-parameters], qui lui permettent de ne travailler que sur des sous-séquences, de ne s'appliquer qu'un certain nombre de fois, entre autres. Consulte la [documentation du Hyperspec][hyperspec-remove] pour tous les détails


## Options destructives

En plus de `remove`, `remove-if` et `remove-if-not`, il existe `delete`, `delete-if` et `delete-if-not`, qui ont le même effet, si ce n'est qu'elles peuvent modifier la séquence qu'on leur passe.
