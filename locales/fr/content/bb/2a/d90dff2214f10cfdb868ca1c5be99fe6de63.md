# À propos

Les types C# peuvent être définis dans la portée d'une classe ou d'un _struct_. Le type englobant fournit une sorte d'espace de noms. On accède au type imbriqué par l'intermédiaire du type englobant, avec la notation pointée.

```csharp
class Outer
{
    public interface IInner {}
    public enum EInner {}
    public class CInner {}
    public struct SInner {}
}

var outer = new Outer();
var inner = new Outer.CInner();
```

## Niveaux d'accès

Les niveaux d'accès peuvent s'appliquer aux types imbriqués. Par exemple, si une classe est `private`, elle n'est pas visible en dehors de la portée du type englobant et, bien entendu, ses instances ne peuvent être ni vues ni utilisées en dehors de cette portée.

Les membres privés de la classe englobante sont dans la portée de tous les membres de la classe imbriquée, mais seuls les membres non privés de la classe imbriquée sont dans la portée des membres de la classe englobante. Pour accéder aux membres de la classe englobante, la classe imbriquée doit recevoir une instance de cette classe englobante.

On le voit dans l'exemple suivant :

```csharp
class Outer
{
    public class InnerImpl
    {
        private Outer outer;

        public int Interesting = 42;

        public InnerImpl(Outer outer, int interesting)
        {
            this.outer = outer;
            Interesting = interesting;
        }

    }

    public InnerImpl Inner;
    public Outer()
    {
        Inner = new InnerImpl(this, 42);
    }
}

var outer = new Outer();
outer.Inner.Interesting
// => 42
var inner = new Outer.InnerImpl(outer, 1729);
outer.Inner.Interesting
// => 1729
```

## Empêche l'instanciation indépendante

Il existe un patron pour empêcher qu'un type instanciable soit créé en dehors du type englobant. On expose une interface publique, mais on garde privée la classe qui l'implémente.

```csharp
class Outer
{
    public interface IInner
    {
        void DoSomething();
    }

    private class InnerImpl : IInner
    {
        private Outer outer;
        public InnerImpl(Outer outer)
        {
            this.outer = outer;
        }
        public void DoSomething()
        {
            outer.DoSomethingElse();
        }
    }

    public IInner Inner;

    public Outer()
    {
        Inner = new InnerImpl(this);
    }
    private void DoSomethingElse()
    {
    }
}

var outer = new Outer();
outer.Inner.DoSomething();

// NOT var inner = new Outer.Inner(outer);
```

## Note pour les développeurs Java

Les classes imbriquées de C# sont un croisement entre les classes imbriquées statiques et les classes internes de Java. En C#, les membres privés de la classe englobante sont dans la portée des membres de la classe imbriquée, mais il n'existe aucune syntaxe particulière pour les instancier et les relier à une instance de la classe englobante. Il faut recourir à une variante du patron illustré dans les exemples ci-dessus.

C# possède bien des classes imbriquées statiques, mais ce ne sont que des classes imbriquées dotées d'un comportement statique.
