# Introduction

## Les expressions `case`

En Gleam, une expression `case` permet d'exécuter du code de façon conditionnelle. Avec une expression `case`, on peut comparer une valeur à un ou plusieurs _motifs_. Un exemple d'un tel motif est le _motif littéral_, qui compare une valeur à une valeur littérale (par exemple `1` ou `"hello"`).

Les expressions `case` s'écrivent avec le mot-clé `case` :

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    1 -> "One"
  }
}
```

Bien que cela puisse ressembler aux instructions `switch` d'autres langages, le filtrage par motif révèle tout son intérêt lorsqu'on utilise aussi d'autres motifs. L'un de ces motifs est le _motif de variable_, qui permet d'affecter une valeur à une variable. Dans cet exemple, la variable `i` reçoit la valeur de `number` si celui-ci n'est pas `0` :

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i -> "Non zero"
  }
}
```

Dans certains cas, on peut vouloir ajouter une condition supplémentaire à un motif. C'est ce qu'on appelle une _garde_ (clause), que l'on peut ajouter avec le mot-clé `if` :

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i if i < 0 -> "Negative number"
  }
}
```

Pour des raisons de performance, seuls les opérateurs mathématiques et booléens de base sont autorisés dans les gardes ; aucune autre fonction ne peut y être utilisée.

Dans l'exemple ci-dessus, certaines entrées possibles n'ont aucun motif correspondant. Le compilateur le détecte et produit une erreur. C'est ce qu'on appelle la _vérification d'exhaustivité_. Pour corriger l'avertissement, il faut gérer tous les cas. Pour cela, on peut utiliser le _motif joker_, un motif qui correspond à n'importe quelle valeur :

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i if i < 0 -> "Negative number"
    _ -> "Positive number"
  }
}

// No compiler error
```

On peut comparer plusieurs motifs dans une même clause en les séparant par `|`. Une clause ne peut contenir qu'une seule garde :

```gleam
pub fn describe(number: Int) -> String {
  let yell = True
  case number {
    0 -> "Zero"
    3 | 5 -> "One of the first odd prime numbers"
    2 | 4 | 6 | 8 if !yell -> "One of the even numbers less than 10"
    i if i % 2 == 0 && yell -> "[Yelling] I'm telling you! It's a even nunber"
    i if i < 0 -> "Negative number"
    _ -> "Positive number"
  }
}
// No compiler error
```

Les expressions `case` comparent une valeur à chaque motif, de haut en bas, jusqu'à ce qu'elles trouvent un motif correspondant et exécutent la logique associée à ce motif. L'ordre des motifs est important !
