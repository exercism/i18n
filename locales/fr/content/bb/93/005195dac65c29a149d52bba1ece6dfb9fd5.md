# Les classes avec état

Jusqu'ici, chaque classe n'était qu'une boîte à routines. Chacune prenait ses
arguments, calculait une réponse, puis oubliait tout.

Une classe peut au contraire **se souvenir** des choses. Un tableau de scores
doit le faire : le score dépend désormais de chaque but marqué depuis le début
de la partie.

## Les attributs

`attr` donne à une classe de quoi se souvenir.

```sather
class SCOREBOARD is

   attr home_score : INT;
   attr away_score : INT;

end; -- class SCOREBOARD
```

Chaque `attr` devient une routine qui lit la valeur, et une autre qui la
modifie :

```sather
   board.home_score            -- read it
   board.home_score := 4;      -- change it
```

Des attributs du même type peuvent partager une déclaration, comme les
arguments :

```sather
   attr home_score, away_score : INT;
```

## Les objets

Une classe avec des attributs est un modèle pour créer des **objets**. Chaque
objet possède ses propres copies des attributs, donc deux tableaux de scores
conservent deux scores.

`new` crée un objet. On l'utilise à l'intérieur d'une routine appelée `create`,
qui remplit ensuite l'objet et le renvoie :

```sather
   create(home, away : STR) : SAME is
      board ::= new;
      board.home_team := home;
      board.away_team := away;
      return board;
   end;
```

`SAME` signifie « cette classe ». Écrire `SCOREBOARD` à cet endroit dirait la
même chose, mais `SAME` continue de fonctionner si la classe est renommée.

## Crée-en un

`#` appelle `create` :

```sather
   board ::= #SCOREBOARD("Vixens", "Magpies");
```

Tu utilises `#` depuis `rehearsal-script` : `#FSTR` est exactement cela.

## Les routines qui modifient l'objet

À l'intérieur de la classe, un attribut s'utilise par son nom, sans objet
devant. Il désigne l'objet sur lequel la routine a été appelée.

```sather
   home_goal is
      home_score := home_score + 1;
   end;
```

`home_goal` ne déclare aucun type de retour, car elle ne renvoie rien : elle
modifie l'objet à la place. Appelle-la comme une instruction :

```sather
   board.home_goal;
```

## Les attributs commencent vides

Un attribut que personne n'a défini vaut zéro pour un `INT`, `false` pour un
`BOOL`, et void pour une _string_ ou un objet. Ainsi, un nouveau tableau de
scores affiche 0 à 0 sans que rien n'ait besoin de le préciser.
