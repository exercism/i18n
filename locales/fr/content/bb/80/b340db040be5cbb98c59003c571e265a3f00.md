# Utilise un paramètre par défaut

[comment]: # (This error is raised when the solution doesn't use default arguments)

Utilise un [argument par défaut](https://elixir-lang.org/getting-started/modules-and-functions.html#default-arguments) pour cette solution.

- Les [arguments par défaut](https://elixir-lang.org/getting-started/modules-and-functions.html#default-arguments) évitent d'avoir à écrire des clauses de fonction en double pour des fonctions qui ont des [arités](https://en.wikipedia.org/wiki/Arity) différentes.

```elixir
# Consider this function:
def foo(bar \\ "baz") do
  IO.puts(bar)
end
```

- Cette fonction définit désormais à la fois `foo/0` et `foo/1`
- si on appelle `foo()`, `"baz"` est écrit dans le group leader de l'application, qui écrit à son tour dans `stdout`
- si on appelle `foo("bar")`, `"bar"` est écrit dans le group leader de l'application, qui écrit à son tour dans `stdout`

> Quand Elixir est compilé et exécuté, la [BEAM VM](<https://en.wikipedia.org/wiki/BEAM_(Erlang_virtual_machine)>) démarre un processus appelé le `group leader`, qui représente l'entrée et la sortie standard ; ce processus est partagé avec tous les autres processus afin d'abstraire les opérations d'entrée et de sortie.
