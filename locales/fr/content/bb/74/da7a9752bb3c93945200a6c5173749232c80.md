## Instructions spécifiques au parcours

La sortie est attendue sous la forme d'un tableau à plat de nombres u16 ; elle sera désérialisée dans le tableau carré de tableaux requis :

```js
// output
[1,2,3,8,9,4,7,6,5]
// =>
// [[1, 2, 3],
//  [8, 9, 4],
//  [7, 6, 5]]
```
