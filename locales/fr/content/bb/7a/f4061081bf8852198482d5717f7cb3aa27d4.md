# Instructions

Ton équipe de design délaisse les transformations CSS au profit de Factor pour une
partie de son travail de mise en page. Pour faire plaisir au reste de l'équipe, tu
vas construire de petites transformations réutilisables, sous forme de _quotations_
qui prennent un point 2D et renvoient un point 2D.

Un point est un tableau de deux éléments : `{ x y }`.

## 1. Effectue une translation des coordonnées

Définis `translate-2d` pour qu'elle prenne deux valeurs `dx` et `dy` de la pile et
renvoie une _quotation_ qui applique une translation de `(dx, dy)` à un point.

```factor
{ 4 8 } 2 0 translate-2d call( p -- p' ) .
! => { 6 8 }
```

## 2. Mets les coordonnées à l'échelle

Définis `scale-2d` de la même façon : elle renvoie une _quotation_ qui met un point
à l'échelle selon `(sx, sy)`.

```factor
{ 6 -3 } 2 2 scale-2d call( p -- p' ) .
! => { 12 -6 }
```

## 3. Compose deux transformations

Définis `compose-transformations` pour qu'elle prenne deux _quotations_ de
transformation `f` et `g` et renvoie une seule _quotation_ qui applique `f`
d'abord, puis `g`.

```factor
{ 0 1 } 2 0 translate-2d 2 2 scale-2d compose-transformations
call( p -- p' ) .
! => { 4 2 }
```

## 4. Applique une transformation

Définis `apply-transformation` pour qu'elle prenne de la pile un point et une
_quotation_ de transformation, et renvoie le point transformé.

```factor
{ 4 8 } 2 0 translate-2d apply-transformation .
! => { 6 8 }
```

## 5. Transforme plusieurs points à la fois

Définis `transform-points` pour qu'elle prenne un tableau de points et une
_quotation_ de transformation, et renvoie le tableau des points transformés.

```factor
{ { 0 0 } { 1 1 } { 2 2 } } 1 0 translate-2d transform-points .
! => { { 1 0 } { 2 1 } { 3 2 } }
```
