# Introduction

En général, on ne veut pas réinventer la roue en programmation.
Pour de nombreux algorithmes standard, quelqu'un a peut-être déjà fait le travail à ta place.

## Inclusions

Pour inclure le contenu d'autres fichiers, C++ utilise la directive `include`.
Ces inclusions doivent être placées en haut du fichier.
Pendant la compilation, la ligne contenant la directive est remplacée par le contenu du fichier correspondant.
Les espaces de noms sont conservés tels quels dans le fichier d'origine après les inclusions.

## La bibliothèque standard

La bibliothèque standard offre de nombreuses fonctions, algorithmes et structures de données courants.
La bibliothèque standard utilise l'espace de noms `std`.

Un exemple est la bibliothèque de calcul numérique C `cmath`.
Elle fournit de nombreuses opérations mathématiques courantes.

```cpp
#include <cmath>

int cube_me(int a) {
    // raise `a` to the third power
    return std::pow(a, 3);
}
```

~~~~exercism/note
Les bibliothèques standard sont incluses avec des chevrons `<>` au lieu de guillemets doubles `"`.
La différence tient à l'emplacement où le compilateur recherche les fichiers correspondants.
La recherche dans le projet courant est ignorée pour la version avec chevrons, et elle commence directement dans les répertoires d'inclusion du système.
Si tu veux inclure des fichiers locaux, tu utiliserais des guillemets doubles : `#include "myfile"`
~~~~
