Tu peux aussi avoir envie d'afficher ces widgets toi-même dans des documents Markdown, par exemple à la fin d'un document, pour suggérer des lectures complémentaires ou de bons exercices sur lesquels apprendre quelque chose.

**Remarque :** tu peux également utiliser des liens normaux pour le texte en ligne, auxquels les infobulles seront ajoutées. Voir [la documentation sur les liens internes](/docs/building/markdown/internal-linking) pour plus de détails.

## Usage

Les widgets peuvent être utilisés partout où tu peux utiliser du Markdown, comme dans la documentation, les approches et les discussions entre apprenants et mentors.

Ils s'affichent à l'aide du format suivant :

```md
[<type>:<id>]()
```

Les parties `<type>` et `<id>` sont variables et dépendent du widget réellement utilisé.

La référence du lien, c'est-à-dire le contenu de `()`, est ignorée par le site. Tu peux y mettre ce que tu veux pour faciliter la maintenance.

## Widget d'exercice

Format du lien : `[exercise:<track-slug>/<exercise-slug>]()`

### Exemple

```markdown
Great job on solving this exercise! Some other exercises that you might also like to try:

- [exercise:fsharp/anagram]()
- [exercise:fsharp/isogram]()
```

## Widget de concept

Format du lien : `[concept:<track-slug>/<concept-slug>]()`

### Exemple

```markdown
There are three primary conditional statements that are used in Julia:

- [concept:julia/if-statements]()
- [concept:julia/ternary-operator]()
- [concept:julia/short-circuiting]()
```

## Widget d'approche

Format du lien : `[approach:<track-slug>/<exercise-slug>/<approach-slug>]()`

### Exemple

```markdown
Here are some approaches you might want to checkout!

- [approach:csharp/two-fer/method-overloading]()
- [approach:csharp/two-fer/optional-parameter]()
```

## Widget d'article

Format du lien : `[article:<track-slug>/<exercise-slug>/<article-slug>]()`

### Exemple

```markdown
We have an article you might be interested in:

- [article:csharp/reverse-string/performance]()
```
