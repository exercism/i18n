# Indices

## 1. Vérifie si une valeur est un booléen

- On peut utiliser `typeof` pour trouver le type d'une valeur.
- `typeof` renvoie une _string_.

## 2. Vérifie si une valeur est un nombre.

- On peut utiliser `typeof` pour trouver le type d'une valeur.
- `typeof` renvoie une _string_.
- Il faut vérifier `Infinity` et `NaN`.
- `NaN` n'est jamais égal à lui-même, mais il existe une [fonction intégrée][isNaN] pour vérifier si une valeur est NaN.

## 3. Vérifie si une valeur est un objet

- On peut utiliser `typeof` pour trouver le type d'une valeur.
- `typeof` renvoie une _string_.
- Il faudra vérifier `null`.

## 4. Vérifie si une _string_ est numérique

- On peut utiliser `typeof` pour trouver le type d'une valeur.
- `typeof` renvoie une _string_.
- On peut parcourir une _string_ pour vérifier si tous les caractères sont des chiffres.

## 5. Vérifie si un objet est électronique

- On peut utiliser `instanceof` pour vérifier si un objet est une instance d'une classe ou de l'une de ses sous-classes.

## 6. Vérifie si une valeur est un tableau non vide

- On peut utiliser `typeof` pour trouver le type d'une valeur.
- `typeof` renvoie une _string_.
- On peut vérifier la longueur d'un tableau pour savoir combien d'éléments il contient.

## 7. Vérifie si une valeur est un tableau vide

- On peut utiliser `typeof` pour trouver le type d'une valeur.
- `typeof` renvoie une _string_.
- On peut vérifier la longueur d'un tableau pour savoir combien d'éléments il contient.

## 8. Vérifie si un objet a une propriété ou une méthode `type`

- On peut utiliser l'opérateur `in` pour vérifier si un objet a une propriété ou une méthode.

## 9. Lève une erreur si un objet n'a pas la propriété ou la méthode `id`

- On peut utiliser l'opérateur `in` pour vérifier si un objet a une propriété ou une méthode.
- Si la propriété ou la méthode `id` est manquante, ta fonction doit lever une `Error`.

## 10. Vérifie si un objet a une propriété `id`

- Pour vérifier si un objet a une propriété (et non une méthode), on peut utiliser la fonction `Object.hasOwn()`.

## 11. Vérifie si un objet a une propriété `type` définie

- Pour vérifier si un objet a une propriété (et non une méthode), on peut utiliser la fonction `Object.hasOwn()`.
- Tu devras accéder à la propriété `type` et vérifier si elle est définie.

[isNaN]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/isNaN
