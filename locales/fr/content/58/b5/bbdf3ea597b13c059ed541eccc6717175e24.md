# Indices

## Général

- Utilise le [type liste (chaînée)][list] intégré.

## 1. Définis une fonction qui renvoie une liste de langages vide

- La fonction doit renvoyer `[]`.

## 2. Définis une fonction qui ajoute un langage à la liste

- On peut ajouter un élément en tête d'une liste avec `|`.

## 3. Définis une fonction qui retire un langage de la liste

- Elixir [fournit une fonction][tl] qui renvoie une liste sans son premier élément.

## 4. Définis une fonction qui renvoie le premier élément de la liste

- Elixir [fournit une fonction][hd] pour récupérer le premier élément d'une liste.

## 5. Définis une fonction qui renvoie le nombre de langages dans la liste

- Elixir [fournit une fonction][length] pour compter la longueur d'une liste.

## 6. Définis une fonction qui détermine si la liste contient un langage fonctionnel

- Ta fonction doit renvoyer une valeur booléenne indiquant si `"Elixir"` fait partie de la liste. Elixir [fournit une fonction][in] pour tester l'appartenance à une liste.
