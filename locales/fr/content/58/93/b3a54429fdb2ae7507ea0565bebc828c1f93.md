# À propos

Les [gardes][guards] servent de complément au [filtrage par motifs][exercism-pattern-matching], que l'on abordera dans un concept ultérieur. Les gardes permettent d'avoir différentes implémentations d'une fonction selon la valeur de l'entrée. Elles autorisent aussi des vérifications plus complexes.

Une garde est introduite par une barre verticale `|` suivie d'une expression booléenne, et se termine par un signe égal `=` puis le corps de la fonction. Une même fonction peut comporter plusieurs gardes. Les gardes sont évaluées de haut en bas, et la première qui vaut `True` est exécutée. Une garde peut comporter une instruction `otherwise`, qui attrape toutes les valeurs qui ne correspondent à aucune des gardes précédentes.

On peut aussi définir sa propre fonction et l'utiliser dans une garde.

```haskell
isEven :: Int -> String
isEven n
    | even n = "n is even"
    | otherwise = "n is odd"
```

We can also deffine our function and use it inside the guard statement.

```haskell
isEven' :: Int -> Bool
isEven' n = even n

isEven :: Int -> String
isEven n
    | isEven' n = "n is even"
    | otherwise = "n is odd"
```
