# Instructions

Tu as pour mission d'écrire un service qui ingère des événements. Chaque événement est associé à une date, mais tu remarques que 3 formats différents sont envoyés au point d'accès de ton service :

- `"01/01/1970"`
- `"January 1, 1970"`
- `"Thursday, January 1, 1970"`

Tu vois qu'il existe des similitudes entre eux et tu décides d'écrire des motifs d'expressions régulières composables.

## 1. Fais correspondre le jour, le mois et l'année d'une date

Implémente `day/0`, `month/0` et `year/0` pour renvoyer un motif de _string_ qui, une fois compilé, correspondrait aux composants numériques de `"01/01/1970"` (`dd/mm/yyyy`). Le jour et le mois peuvent apparaître sous la forme `1` ou `01` (complétés à gauche par des zéros).

```elixir
"31" =~ DateParser.day() |> Regex.compile!()
# => true
"12" =~ DateParser.month() |> Regex.compile!()
# => true
"1970" =~ DateParser.year() |> Regex.compile!()
# => true
```

## 2. Fais correspondre le jour de la semaine et le mois de l'année

Implémente `day_names/0` et `month_names/0` pour renvoyer un motif de _string_ qui, une fois compilé, correspondrait respectivement au nom du jour de la semaine et au nom du mois de l'année.

```elixir
"Tuesday" =~ DateParser.day_names() |> Regex.compile!()
# => true
"June" =~ DateParser.month_names() |> Regex.compile!()
# => true
```

## 3. Capture le jour, le mois et l'année

Implémente `capture_day/0`, `capture_month/0`, `capture_year/0`, `capture_day_name/0`, `capture_month_name/0` pour renvoyer un motif de _string_ qui capture les composants respectifs dans les noms : `"day"`, `"month"`, `"year"`, `"day_name"`, `"month_name"`

```elixir
DateParser.capture_month_name()
|> Regex.compile!()
|> Regex.named_captures("December")

# => %{"month_name" => "December"}
```

## 4. Combine les captures pour capturer la date entière

Implémente `capture_numeric_date/0`, `capture_month_name_date()`, et `capture_day_month_name_date/0` pour renvoyer un motif de _string_ qui capture les composants de la partie 3 en utilisant le format de date correspondant :

- date numérique - `"01/01/1970"`
- date avec le nom du mois - `"January 1, 1970"`
- date avec le jour et le nom du mois - `"Thursday, January 1, 1970"`

```elixir
DateParser.capture_numeric_date()
|> Regex.compile!()
|> Regex.named_captures("01/01/1970")

# => %{"day" => "01", "month" => "01", "year" => "1970"}
```

## 5. Restreins la capture pour qu'elle ne corresponde qu'à la date

Implémente `match_numeric_date/0`, `match_month_name_date/0`, et `match_day_month_name_date/0` pour renvoyer une expression régulière compilée qui ne correspond qu'à la date et qui peut aussi capturer les composants.

```elixir
"Thursday, January 1, 1970 was the Unix epoch." =~ DateParser.match_day_month_name_date()
# => false
"Thursday, January 1, 1970" =~ DateParser.match_day_month_name_date()
# => true

DateParser.match_day_month_name_date()
|> Regex.named_captures("Thursday, January 1, 1970")

# => %{
#     "day" => "1",
#     "day_name" => "Thursday",
#     "month_name" => "January",
#     "year" => "1970"
#   }
```
