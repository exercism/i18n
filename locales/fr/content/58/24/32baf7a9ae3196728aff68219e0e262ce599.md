# String

Le type de données `String` est une série linéaire de caractères encodés en UTF-8. Il est utile pour stocker des données textuelles.

## Crée une _string_

On peut créer une _string_ à l'aide des fonctions associées `String::new()` ou `String::from()`. De nombreux types disposent d'une méthode `to_string` qui produit une _string_, par exemple à partir d'un nombre.

```rust
let my_string = String::from("The answer is");
let answer = 42.to_string();
println!("{my_string} {answer}");
```

### La macro `format!`

Comme produire une longue _string_ à partir de plusieurs types de données plus petits est une opération courante, Rust propose aussi un raccourci qui masque les détails de l'appel à `to_string` : la macro `format!`. Par exemple, on peut simplifier la construction de la _string_ composite ci-dessus comme ceci :

```rust
let the_answer = format!("{} {}.", "The answer is", 42);
assert_eq!("The answer is 42.", the_answer);
```

## Les _string slices_

Les _strings_ entretiennent une relation étroite avec les _string slices_. Une _string slice_ est une référence immuable vers une zone de mémoire de taille connue, qui contient une série linéaire de caractères encodés en UTF-8. N'importe quelle _string_ peut être convertie en _string slice_ en l'empruntant avec l'opérateur de déréférencement (`&`). Pour convertir une _string slice_ en _string_, on peut utiliser aussi bien la méthode `to_string()` que `String::from`.

En Rust, une _string_ littérale s'écrit entre guillemets doubles. Ces littéraux de _string_ sont toujours des _string slices_, car ils font référence à une zone de mémoire immuable au sein de l'exécutable du programme.

```rust
let string = String::from("string");
let slice = "string";
assert_eq!(slice, &string);
```

## Modifie une _string_

Pour ajouter un seul caractère à la fin d'une _string_, utilise la méthode `push`. Pour ajouter une _string slice_ à une _string_, utilise la méthode `push_str` ou l'opérateur `+`.

```rust
fn main() {
    // For demonstration purposes, we're not using `format!`
    let s1 = String::from("tic");
    let s2 = String::from("tac");
    let s3 = String::from("toe");

    let s = s1 + "-" + &s2 + "-" + &s3;
    println!("{s}");
}
```

## Accède aux caractères d'une _string_

Comme les _strings_ Rust sont encodées en UTF-8, les caractères individuels n'ont pas tous la même taille. C'est pourquoi le type de données `String` ne fournit pas d'opérateur d'indexation (`[]`). Pour accéder à tous les caractères, ou à un caractère précis, d'une _string_, on peut utiliser la méthode `chars()`. Elle parcourt les caractères de la _string_ un par un, dans l'ordre.

```rust
let alphabet: String = ('a'..='z').collect();
for c in alphabet.chars() {
    println!("{c}");
}
let j = alphabet.chars().nth(9);
println!("{j:?}"); // prints Some('j')
```

`String` est un type de données riche, autour duquel sont construites de nombreuses méthodes et macros. Consulte [la documentation de la bibliothèque standard](https://doc.rust-lang.org/std/string/struct.String.html) pour découvrir toutes les méthodes et fonctionnalités offertes par `String`.
