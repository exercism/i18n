# paramètre obligatoire inattendu

Dans les tests, le paramètre \`${'parameter.name'}\` est fourni tantôt avec
une valeur, tantôt sans, mais il n'est _pas marqué comme optionnel_, ce qui
signifie que les tests ne passeront pas. Un paramètre TypeScript peut être
explicitement marqué comme optionnel à l'aide d'un suffixe `?` :

```typescript
function(${'parameter.name'}?: ${'parameter.type'}) {
  //
}
```

Ou bien, en lui affectant une valeur par défaut :

```typescript
function(${'parameter.name'}: ${'parameter.type'} = <default>) {
  //
}
```
