# Introduction

Un *ensemble disjoint* (une structure _union-find_) conserve une collection de valeurs réparties en groupes qui ne se recouvrent pas, et répond rapidement à une question : ces deux valeurs sont-elles dans le même groupe ? On le trouve dans le vocabulaire [`disjoint-sets`][disjoint-sets].

## Construis un ensemble disjoint

`<disjoint-set>` construit une structure vide. On ajoute les valeurs, les *atomes*, un par un avec `add-atom`, ou à partir d'une séquence avec `add-atoms`. Chaque atome démarre dans un groupe qui lui est propre.

```
<disjoint-set> ( -- disjoint-set )
add-atom       ( atom disjoint-set -- )
add-atoms      ( seq disjoint-set -- )
```

```factor
USING: disjoint-sets ;

<disjoint-set>
{ 1 2 3 } over add-atoms   ! 1, 2 and 3 each in their own group
```

L'ensemble disjoint est *mutable* : `add-atom`, `add-atoms` et `equate` le modifient sur place au lieu de renvoyer un nouvel ensemble. `keep` est pratique quand tu veux récupérer l'ensemble disjoint sur la pile après que l'un de ces mots l'a consommé.

## Fusionne les groupes

`equate` réunit les deux groupes qui contiennent ses atomes. L'union est transitive : si tu associes deux atomes, puis l'un d'eux avec un troisième, les trois se retrouvent dans un seul groupe.

```
equate ( atom1 atom2 disjoint-set -- )
```

## Représentants

Chaque groupe a un membre canonique, son *représentant*. `representative` le renvoie, et deux atomes appartiennent au même groupe précisément quand leurs représentants sont égaux.

```
representative ( atom disjoint-set -- representative )
```

```factor
USING: disjoint-sets ;

<disjoint-set>
{ 1 2 3 } over add-atoms
1 2 pick equate
1 over representative .   ! => 1
2 over representative .   ! => 1   (same representative as 1)
3 over representative .   ! => 3   (still on its own)
```

L'atome qu'un groupe choisit comme représentant est un détail interne : ne te fie jamais à ce qu'un atome précis soit choisi, seulement au fait que deux atomes du même groupe s'accordent.
