# Ajout aux instructions

## Indices

- Tester cet exercice peut être délicat si on se contente de coder « en dur » une série d'entrées et de sorties, c'est-à-dire d'écrire des valeurs fixes dans le code plutôt que de laisser le programme les calculer. Le [test basé sur les propriétés](https://fsharpforfunandprofit.com/posts/property-based-testing/) est une autre façon d'aborder les tests, qui permet de tester plus facilement ce type d'algorithme.
