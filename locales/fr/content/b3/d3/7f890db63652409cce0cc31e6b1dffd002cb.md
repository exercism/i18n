# Instructions

Dans cet exercice, tu vas écrire un peu de code pour t'aider à préparer l'achat d'un véhicule.

Tu as trois tâches : déterminer si tu auras besoin d'obtenir un permis, t'aider à choisir entre deux véhicules, et estimer le prix acceptable d'un véhicule d'occasion.

## 1. Détermine si tu auras besoin d'un permis de conduire

Certains types de véhicules exigent un permis de conduire pour être utilisés.
Suppose que seuls les types `car` et `truck` nécessitent un permis ; tout le reste peut être utilisé sans permis.

Implémente la fonction `needs_license(kind)` qui prend le type de véhicule et renvoie un booléen indiquant si tu as besoin d'un permis pour ce type de véhicule.

```R
needs_license("car");
# => TRUE

needs_license("bike");
# => FALSE
```

## 2. Choisis entre deux véhicules potentiels à acheter

Tu évalues les véhicules disponibles.
Tu arrives à réduire ton choix à deux options, mais tu as besoin d'aide pour prendre la décision finale.
Pour cela, implémente la fonction `choose_vehicle(option1, option2)` qui prend deux véhicules en arguments et renvoie une décision qui est simplement l'option qui vient en premier dans l'ordre alphabétique.

```R
choose_vehicle("Wuling Hongguang", "Toyota Corolla");
# =>  "Toyota Corolla"

choose_vehicle("Volkswagen Beetle", "Volkswagen Golf");
# =>  "Volkswagen Beetle"
```

## 3. Calcule une estimation du prix d'un véhicule d'occasion

Maintenant que tu as pris ta décision, tu veux t'assurer d'obtenir un prix correct chez le concessionnaire.
Comme tu souhaites acheter un véhicule d'occasion, le prix dépend de l'âge du véhicule.
Pour une estimation approximative, suppose que si le véhicule a moins de 3 ans, il coûte 80 % de son prix d'origine lorsqu'il était neuf.
S'il a plus de 10 ans, il coûte 50 %.
Si le véhicule a au moins 3 ans mais pas plus de 10 ans, il coûte 70 % de son prix d'origine.

Implémente la fonction `calculate_resale_price(original_price, age)`.
Elle prend le prix d'origine et l'âge du véhicule en arguments et renvoie le prix estimé chez le concessionnaire.

```R
calculate_resale_price(1000, 1);
# => 800

calculate_resale_price(1000, 5);
# => 700

calculate_resale_price(1000, 15);
# => 500
```
