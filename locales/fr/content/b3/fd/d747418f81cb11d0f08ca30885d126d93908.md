## La structure de cet exercice en Python

On a ajouté un descripteur de semaine supplémentaire (`fifth`) pour le cinquième jour de la semaine du mois, s'il existe.  
S'il n'y a pas de cinquième jour de la semaine dans un mois, tu dois lever une exception.

## Personnalise et lève des exceptions

Il est parfois nécessaire à la fois de [personnaliser](https://docs.python.org/3/tutorial/errors.html#user-defined-exceptions) et de [`raise`](https://docs.python.org/3/tutorial/errors.html#raising-exceptions) des exceptions dans ton code. Quand tu le fais, tu dois toujours inclure un **message d'erreur explicite** pour indiquer l'origine de l'erreur. Cela rend le code plus lisible et facilite grandement le débogage.

On peut créer des exceptions personnalisées à l'aide de nouvelles classes d'exception (voir [`classes`](https://docs.python.org/3/tutorial/classes.html#tut-classes) pour plus de détails) qui sont généralement des sous-classes de [`Exception`](https://docs.python.org/3/library/exceptions.html#Exception).

Dans les cas où tu sais que la source de l'erreur dérivera d'un certain type d'exception, tu peux choisir d'hériter de l'un des [`built in error types`](https://docs.python.org/3/library/exceptions.html#base-classes) sous la classe _Exception_. Quand tu lèves l'erreur, tu dois quand même inclure un message explicite.

Cet exercice en particulier te demande de créer une _exception personnalisée_ à [lever](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement)/« lancer » lorsque la fonction `meetup()` reçoit une combinaison de nom de jour et de nombre qui n'est pas valide. Les tests ne passeront que si tu personnalises les exceptions appropriées, que tu lèves ces exceptions avec `raise` et que tu inclus des messages d'erreur appropriés.

Pour personnaliser une `built-in exception`, crée une `class` qui hérite de cette exception. Quand tu lèves l'exception personnalisée avec un message, écris ce message comme argument du type `exception` :

```python
# subclassing the built-in ValueError to create MeetupDayException
class MeetupDayException(ValueError):
    """Exception raised when the Meetup weekday and count do not result in a valid date.

    message: explanation of the error.

    """
    def __init__(self, message):
        self.message = message

        
# raising a MeetupDayException
raise MeetupDayException("That day does not exist.")
```
