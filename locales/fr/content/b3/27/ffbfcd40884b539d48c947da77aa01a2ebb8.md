# Exercices dépréciés

Supprimer un exercice est une action destructive, car cela supprimerait toutes les solutions des utilisateurs pour cet exercice.
C'est pourquoi les exercices ne peuvent **jamais** être supprimés.
À la place, on permet de déprécier les exercices.

Déprécier un exercice a les conséquences suivantes :

- Les utilisateurs qui ont téléchargé ou commencé l'exercice peuvent accéder à leur solution existante comme d'habitude
- Les utilisateurs qui **n'ont pas** téléchargé ou commencé l'exercice ne le verront pas et ne pourront pas le commencer.

## Déprécie un exercice

Pour déprécier un exercice, il suffit de modifier son entrée dans `config.json` comme suit :

- **`status`** : défini sur `"deprecated"`
- **`prerequisites`** : défini sur `[]`
- **`practices`** : défini sur `[]` (exercices d'entraînement uniquement)
- **`concepts`** : défini sur `[]` (exercices d'apprentissage uniquement)

**Toutes les autres propriétés doivent rester identiques.**

**Tous les fichiers de l'exercice doivent rester intacts.**
