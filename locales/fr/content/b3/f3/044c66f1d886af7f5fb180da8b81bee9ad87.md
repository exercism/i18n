# Instructions

Réécris un analyseur Markdown.

L'exercice markdown est un exercice de réécriture.
Il y a du code qui analyse une _string_ donnée avec la [syntaxe Markdown][markdown] et renvoie le HTML associé à cette _string_.
Même si ce code est écrit de façon confuse et difficile à suivre, il fonctionne tant bien que mal et tous les tests passent !
Ton objectif est de réécrire ce code pour le rendre plus facile à lire et à maintenir, tout en veillant à ce que tous les tests continuent de passer.

Ce serait utile que tu notes dans des commentaires ce que tu as fait lors de ta réécriture, pour que les relecteurs puissent le voir, mais ce n'est pas strictement nécessaire.
Le plus important, c'est d'améliorer le code !

[markdown]: https://docs.github.com/en/get-started/writing-on-github/getting-started-with-writing-and-formatting-on-github/basic-writing-and-formatting-syntax
