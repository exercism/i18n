# À propos

Gleam représente les valeurs vrai et faux avec le type `Bool`. Il n'existe que deux valeurs : `True` et `False`. Ces valeurs peuvent être affectées à une variable :

```gleam
let true_variable = True
let false_variable = False
```

Les opérateurs `&&`, `||` et `!` permettent de manipuler des valeurs booléennes :

```gleam
True && True  // -> True
True && False // -> False

False || True  // -> True
False || False // -> False

!False // -> True
!True  // -> False
```

Les opérateurs `&&` et `||` utilisent l'évaluation en court-circuit, ce qui signifie que l'expression à droite de l'opérateur n'est évaluée que si c'est nécessaire.

Chaque opérateur a une priorité différente : `!` est évalué avant `&&` et `||`. On peut utiliser des accolades pour évaluer une partie de l'expression avant les autres :

```gleam
!True && False   // -> False
!{True && False} // -> True
```
