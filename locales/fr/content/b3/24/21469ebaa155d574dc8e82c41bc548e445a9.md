# À propos

Un **mot** est le nom que Factor donne à une fonction. Tu as découvert la pile de données et les mots de manipulation de la pile dans `basics` ; ici, tu définis tes propres mots, qui calculent à partir de leurs entrées.

```factor
: square ( x -- x*x ) dup * ;
: hello  ( -- )       "Hello, world!" print ;
: max3   ( a b c -- max ) max max ;
```

Une définition, c'est `:`, un effet de pile, le corps, puis `;`. Les noms entre `( … -- … )` sont là pour le lecteur ; ce que le compilateur vérifie, c'est le *nombre* d'entrées et de sorties. Une incohérence est une erreur à la compilation, ce qui attrape toute une classe de bugs qui seraient des erreurs à l'exécution dans un langage à typage dynamique dépourvu de ce genre de déclaration.

Les mots d'arithmétique entière `+`, `-` et `*` viennent du vocabulaire `math` et consomment chacun deux nombres au sommet de la pile. Le sommet de la pile est l'opérande de droite, donc `8 3 -` calcule `8 - 3`.

`CONSTANT:` définit un nom pour une valeur fixe ; appeler ce nom empile la valeur, exactement comme n'importe quel autre mot. Place les constantes en haut du fichier, avant tout mot qui les utilise.

Le corps d'un mot peut appeler n'importe quel mot déjà en portée : les définitions plus haut dans le même fichier, les mots des vocabulaires importés et les constantes que tu as déclarées. Composer de petits mots, chacun avec un seul rôle, est la façon habituelle de construire un programme.

Par convention :

- Les mots et les constantes utilisent `lowercase-kebab-case`.
- Les prédicats se terminent par `?` et produisent un booléen (`even?`, `empty?`).
- Les mots qui modifient leur entrée portent souvent le même nom que la version non mutante, que seul le contexte permet de distinguer.
