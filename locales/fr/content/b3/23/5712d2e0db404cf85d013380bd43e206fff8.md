# Introduction

## Égalité

En Elm, on peut vérifier que deux valeurs sont « identiques » avec l'opérateur d'égalité `(==)`.
L'opérateur d'inégalité est `(/=)` (et *non* `!=` comme dans beaucoup de langages).
L'opérateur d'égalité fonctionne sur les littéraux, les tuples, les _records_ et les _custom types_.

```elm
1 == 2
    --> False

1 /= 2
    --> True

(1, 2) == (2, 1)
    --> False

type alias MyRecord = { myInt : Int, myStrings : List String }
a : MyRecord
a = MyRecord (1 + 1) ["hello world"]

type alias MyOtherRecord = { myInt : Int, myStrings : List String }
myStrings =  (String.join " " ["hello", "world"]) :: []
b : MyOtherRecord
b = { myInt = 2, myStrings = myStrings}

a == b
    --> True
```

Fais attention : tu ne dois *jamais* comparer des fonctions, car cela ferait planter le programme à l'exécution.

## Comparaisons

Les opérateurs de comparaison `(<)`, `(<=)`, `(>)` et `(>=)`, ainsi que les fonctions `min`, `max` et `compare`, fonctionnent sur les types `comparable`.
Le type `comparable` est un type particulier qui regroupe tous les types natifs que l'on peut comparer : les nombres, les caractères, les _strings_, les tableaux de choses comparables et les tuples de choses comparables.

```elm
1 < 1 + 1
    --> True

'x' < 'X'
    --> False

"abc" < "abz"
    --> True

"abc" < "abcd"
    --> True

"abc" < "b"
    --> True

min [1 , 2, 9000] [10]
    --> [1 , 2, 9000]

min (1, "hello") (3, "bye")
    --> (1, "hello")
```

Les valeurs d'autres types, comme les _records_ ou les _custom types_, ne peuvent pas être comparées directement.

Certains types natifs exigent que leur contenu soit `comparable`, comme les clés de `Set` ou de `Dict`, car leur structure repose sur un ordre interne.

Les tableaux de valeurs `comparable` peuvent être triés avec `List.sort`, et les tableaux de valeurs que l'on peut convertir en valeurs `comparable` peuvent être triés avec `List.sortBy`.
Si tu as besoin d'un tri hiérarchique (trier selon une propriété, puis départager les égalités avec une autre), les tuples et les tableaux peuvent aussi être utilisés avec `List.sortBy`, car les tuples et les tableaux sont triés dans l'ordre lexicographique.


```elm
List.sort ["hi", "hello", "bye", "goodbye"]
    --> ["bye", "goodbye", "hello", "hi"]

List.sortBy String.length ["hi", "hello", "bye", "goodbye"]
    --> ["hi", "bye", "hello", "goodbye"]

-- sort by length, then alphabetically
List.sortBy (\str -> (String.length str, str)) ["hi", "mum", "hello", "sis", "bye", "dad"]
    --> ["hi", "bye", "dad", "mum", "sis", "hello"]
```

La fonction `compare` prend deux valeurs `comparable` et renvoie un `Order`.
Un `Order` est un type qui permet de savoir en une seule opération si une valeur est supérieure (`GT`), égale (`EQ`) ou inférieure (`LT`) à une autre.

```elm
compare 1 2
    --> LT

compare "" ""
    --> EQ

compare [12] []
    --> GT
```

On peut construire des fonctions de comparaison pour n'importe quel type et les utiliser, par exemple, pour trier avec `List.sortWith` :

```elm
type Color = Red | Green | Blue

compareColors : Color -> Color -> Order
compareColors a b =
  case (a, b) of
    (Red, Red) -> EQ
    (Red, _) -> LT
    (_, Red) -> GT
    (Green, Green) -> EQ
    (Green, _) -> LT
    (_, Green) -> GT
    (Blue, Blue) -> EQ

List.sortWith compareColors [Blue, Red, Green, Green, Blue]
    --> [Red, Green, Green, Blue, Blue]
```
