# À propos

La portée d'une valeur désigne l'endroit du programme où cette valeur est accessible.

## Les quatre types de portée : bloc, fonction, prototype de fonction, fichier

### Portée de bloc

Une valeur qui a une portée de bloc n'est accessible que depuis le bloc où elle est définie.
Pour en savoir plus sur les blocs, consulte le [concept de bloc](../blocks/introduction.md#Introduction).

### Portée de fonction

La portée de fonction est un type particulier de portée qui s'applique aux étiquettes utilisées avec les instructions `goto`.
Deux étiquettes portant le même nom ne peuvent pas être utilisées dans la même fonction, même si elles sont définies dans des blocs distincts à l'intérieur de cette fonction.

### Portée de prototype de fonction

La portée de prototype de fonction est un autre type particulier de portée qui ne s'applique qu'aux paramètres nommés dans le prototype (aussi appelé déclaration, étant entendu que toutes les déclarations ne sont pas des prototypes).
Le nom d'un paramètre est généralement facultatif dans une déclaration de fonction.
La portée d'un nom n'est pertinente qu'à l'intérieur de la déclaration.
Dans l'exemple suivant, l'identifiant `len` est défini puis référencé plus loin dans la déclaration de fonction.

```c
#include <stdio.h>

// len is defined and then referred to
void my_func(int len, int numbers[len]);

int main() {
    int numbers[2];
    numbers[0] = 1;
    numbers[1] = 2;
    my_func(2, numbers);
}

void my_func(int length, int numbers[length]) {
    // prints numbers should have 2 elements
    printf("numbers should have %d elements", length);
}
```

Note qu'à l'intérieur d'une déclaration, les noms doivent correspondre quand ils font référence à la même variable.
Si `my_func` était déclarée comme `void my_func(int len, int numbers[length]);`, une erreur de compilation semblable à celle-ci serait générée :

```
/tmp/scn62kKPEZ.c:4:35: error: 'length' undeclared here (not in a function)
    3 | void my_func(int len, int numbers[length]);
      |                                   ^~~~~~
/tmp/scn62kKPEZ.c: In function 'main':
/tmp/scn62kKPEZ.c:10:16: error: type of formal parameter 2 is incomplete
   10 |     my_func(2, numbers);
```

Une définition de fonction n'est pas tenue d'utiliser, pour un paramètre, le même nom que celui employé dans la déclaration de la fonction.
Dans l'exemple ci-dessus, `len` est utilisé dans la déclaration et `length` dans la définition, ce qui montre que la portée de l'identifiant `len` se limitait à la déclaration de la fonction.

### Portée de fichier

Une valeur qui a une portée de fichier est accessible depuis n'importe où dans le fichier.
Toute valeur de ce genre est définie en dehors d'une fonction.
