# Introduction

Un *tas* est une collection qui connaît toujours son plus petit élément et qui permet de le retirer rapidement. C'est l'outil naturel pour une *file de priorité* : une file d'attente où c'est l'élément le plus important qui passe en premier, et non celui qui a attendu le plus longtemps. Les tas se trouvent dans le vocabulaire [`heaps`][heaps].

## Construis un tas

`<min-heap>` construit un tas vide dont la *plus petite* clé sort en premier ; `<max-heap>` en est l'image miroir.

```
<min-heap> ( -- min-heap )
<max-heap> ( -- max-heap )
```

## Ajoute des éléments

Chaque élément est stocké sous forme d'une *valeur* associée à une *clé*, la clé étant la priorité selon laquelle Factor trie les éléments. `heap-push` en ajoute un :

```
heap-push ( value key heap -- )
```

```factor
USING: heaps ;

<min-heap>
"alice" 5 pick heap-push   ! value "alice", priority 5
"bob"   2 pick heap-push   ! value "bob",   priority 2
```

Un tas est *mutable* : `heap-push` le modifie sur place au lieu de renvoyer un nouveau tas. `keep` est bien pratique pour récupérer le tas sur la pile une fois que `heap-push` l'a consommé.

## Consulte et retire l'élément de tête

`heap-peek` renvoie l'élément de tête, c'est-à-dire la valeur ayant la plus petite clé, *sans* le retirer. `heap-pop` renvoie cet élément *et* le retire. `heap-empty?` indique s'il reste quelque chose, ce qui te permet de savoir quand arrêter de dépiler. `heap-pop-all` retire tout d'un coup et renvoie une liste d'associations de paires `{ key value }` dans l'ordre de priorité.

```
heap-peek    ( heap -- value key )
heap-pop     ( heap -- value key )
heap-empty?  ( heap -- ? )
heap-pop-all ( heap -- alist )
```

```factor
USING: assocs heaps kernel prettyprint ;

<min-heap>
"alice" 5 pick heap-push
"bob"   2 pick heap-push
dup heap-empty? .        ! => f      (two items waiting)
dup heap-peek drop .     ! => "bob"  (smallest key, still in the heap)
dup heap-pop drop .      ! => "bob"  (smallest key, now removed)
heap-pop-all .           ! => { { 5 "alice" } }
```

`heap-pop` et `heap-empty?` sont les briques de base pour servir les éléments un par un : on regarde ou on retire l'élément de tête, on agit dessus, et on s'arrête dès que `heap-empty?` renvoie `t`. Les tâches ci-dessous utilisent `heap-pop-all` pour vider toute la file en une seule étape, mais on obtient le même ordre en dépilant jusqu'à ce que le tas soit vide.

Les paires renvoyées par `heap-pop-all` forment une *liste d'associations* : `values` (dans `assocs`) ne garde que les valeurs et laisse tomber les clés.
