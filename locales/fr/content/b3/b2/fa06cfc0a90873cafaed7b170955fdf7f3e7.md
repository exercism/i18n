# Indices

## Généralités

- Ne modifie pas le code dans les _namespaces_ des familles.
- Ne copie pas les valeurs dans ton code, appelle les fonctions.

## 1. Prends place devant les familles et étale tes papiers

- Le _namespace_ doit s'appeler `estate_executor` pour que les tests fonctionnent.

## 2. Trouve le numéro de compte secret

Chaque `bank_number_part` doit être appelé avec le `secret_modifier` de la liste de paramètres.

## 3. Dernière étape : saisis le code secret

- Tu peux appeler des fonctions de _namespaces_ imbriqués comme ceci : `outer_namespace::inner_namespac::my_function`.

- Veille à additionner séparément les fragments bleu et rouge avant de multiplier les deux parties.
