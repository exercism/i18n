# Les boucles `for`

Les boucles sont un concept fondamental en programmation : elles permettent d'exécuter un bloc de code plusieurs fois.
En Swift, il existe deux types de boucles : les [boucles `for-in`][for-loops] et les boucles `while`. 
Dans ce chapitre, on va découvrir les boucles `for-in`.

Les boucles `for` permettent de parcourir une séquence de valeurs, en prenant chaque élément l'un après l'autre et en le liant à la variable de ton choix.
Swift permet de parcourir toutes sortes de séquences, comme les intervalles, les tableaux et les _strings_ (ainsi que d'autres types qui seront abordés plus tard).
Lorsque tous les éléments de la séquence ont été parcourus, la boucle se termine.

Une boucle `for` se déclare avec le mot-clé `for`, suivi d'un nom de variable, du mot-clé `in` et d'une séquence de valeurs à parcourir.
La variable donnée dans la boucle `for-in` est immuable, ce qui signifie que l'on ne peut pas modifier sa valeur à l'intérieur de la boucle.
Voici un exemple de boucle `for-in` qui parcourt un tableau de nombres :

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
  print(number)
}
print("Done with numbers")

// prints:
// 3
// 10
// 7
// 11
// Done with numbers
```

~~~~exercism/note
La variable `number` est déclarée dans la boucle `for-in` et n'est disponible que dans la portée de la boucle.

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
    number + 1
}
number + 1
// Error: Use of unresolved identifier 'number'
```
~~~~

## Parcours un intervalle

On peut aussi parcourir un intervalle de nombres avec une boucle `for-in`.
Cela permet d'exécuter un bloc de code un nombre précis de fois : par exemple, l'intervalle `1...5` parcourt les nombres 1, 2, 3, 4 et 5, donc la boucle s'exécute 5 fois.
Il peut arriver que tu veuilles parcourir les indices d'une structure de données comme un tableau ; dans ce cas, tu peux utiliser un intervalle `0..<array.count`.

```swift
let numbers = [3, 10, 7, 11]

for i in 0..<numbers.count {
  print(numbers[i])
}

// prints:
// 3
// 10
// 7
// 11
```

## Parcours une _string_

On peut aussi parcourir une _string_ avec une boucle `for-in`.
Cela permet de parcourir chaque caractère de la _string_, et note bien que le type donné dans la boucle est un `Character`.

```swift
let message = "Hello!"

for character in message {
  print(character)
}

// prints:
// H
// e
// l
// l
// o
// !
```

## stride

Swift fournit aussi une fonction `stride` qui permet de créer une séquence sur un intervalle avec un pas donné.
Cette séquence peut ensuite être parcourue avec une boucle `for-in`.
`stride` se décline en [`stride(from:to:by:)`][stride-to] ou [`stride(from:through:by:)`][stride-through] ; la première est exclusive et la seconde inclusive.

```swift
for i in stride(from: 0, to: 10, by: 2) {
  print(i)
}

// prints:
// 0
// 2
// 4
// 6
// 8
```

Note que le paramètre `to` est exclusif, donc la boucle s'arrête au nombre qui précède le paramètre `to`, tandis que le paramètre `through` est inclusif, si bien qu'ici elle inclurait aussi le `10`.

[stride-to]: https://developer.apple.com/documentation/swift/stride(from:to:by:)
[stride-through]: https://developer.apple.com/documentation/swift/stride(from:through:by:)
[for-loops]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#For-In-Loops
