# Ajout aux instructions

## Implémentation

~~~~exercism/note

Tu voudras peut-être (ou peut-être pas !) appeler la fonction `permutations(a, t)` de [Combinatorics.jl][combinatorics] dans ta solution.

[combinatorics]: https://juliamath.github.io/Combinatorics.jl/stable/api/#Combinatorics.permutations-Tuple{Any,%20Integer}
~~~~

- Si tu travailles dans l'éditeur en ligne, tu peux appeler `permutations(a ,t)` librement, car elle est déjà dans l'espace de noms. Tu peux voir le code source dans l'onglet intitulé `permutations.jl`.
- Si tu travailles en local, ajoute `include("permutations.jl")` en haut de ton fichier de solution pour accéder à une version de `permutations(a, t)` qui se trouve là. 

~~~~exercism/caution

Si tu utilises `Combinatorics.jl` `v1.0.3` en local, `permutations(a, t)` est *très* lente sur les grands tests.
Utilise soit le fichier fourni `permutations.jl`, soit une version `Combinatorics.jl` `v≥1.1.0`, soit « rétrograde » vers la `v1.0.2`.

~~~~
