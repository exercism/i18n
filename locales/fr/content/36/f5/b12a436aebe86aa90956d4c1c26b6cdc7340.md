# Ajout aux instructions

## Registres

| Registre | Utilisation | Type       | Description                                                    |
| -------- | ----------- | ---------- | -------------------------------------------------------------- |
| `$a0`    | entrée      | adresse    | _string_ de caractères trinaires terminée par un caractère nul  |
| `$v0`    | sortie      | entier     | valeur décimale de la _string_ d'entrée                         |
| `$t0-9`  | temporaire  | quelconque | utilisé pour le stockage temporaire                             |
