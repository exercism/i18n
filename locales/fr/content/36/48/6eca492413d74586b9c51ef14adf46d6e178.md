# À propos

Le type `Maybe` est la solution qu'offre le langage Elm pour représenter des valeurs optionnelles.
Il est donc présent dans la signature de type d'un grand nombre de fonctions essentielles d'Elm, et il est crucial de le comprendre.

## Définition et variable de type

Le type `Maybe` se définit comme suit :

```elm
type Maybe a = Nothing | Just a
```

C'est ce qu'on appelle une définition de « type personnalisé » dans la terminologie Elm.
Les types personnalisés sont présentés en détail dans un autre concept de ce parcours, mais on n'en a pas besoin pour comprendre spécifiquement `Maybe`.
Le `a` dans `Maybe a` et `Just a` représente une variable de type, ce qui signifie qu'il peut s'agir de n'importe quel type, comme `Int`, `Bool` ou `String`.
Ainsi, un `Maybe String` est une variable qui contient éventuellement une `String`, tandis qu'un `Maybe Int` contiendrait éventuellement un `Int`.

```elm
name : Maybe String
name = Just "Matthieu"

age : Maybe Int
age = Just 29
```

La barre verticale `|` dans la définition du type `Maybe` signifie « OU ».
Elle indique qu'une valeur de ce type peut soit être `Nothing`, soit être `Just` quelque chose de type `a`.
Imaginons donc que cette personne n'ait pas renseigné son nom et son âge : on obtiendrait alors ceci.

```elm
name : Maybe String
name = Nothing

age : Maybe Int
age = Nothing
```

## Lire le contenu d'une valeur `Maybe`

Pour lire le contenu d'une valeur `Maybe`, on a recours au « filtrage par motif ».
Le filtrage par motif est lui aussi présenté plus en détail dans un autre concept, on se concentre donc ici sur la façon dont on filtre un `Maybe`.

```elm
-- This function returns "Hello, <name>!" if the name was provided.
-- Otherwise, it just says "Hello, World!".
sayHello : Maybe String -> String
sayHello maybeName =
    case maybeName of
        Nothing -> "Hello, World!"
        Just someName -> "Hello, " ++ someName ++ "!"

sayHello (Just "Matthieu")
    --> "Hello, Matthieu!"

sayHello Nothing
    --> "Hello, World!"
```

Chaque fois que tu utilises une valeur `Maybe`, le compilateur Elm vérifie que le code gère toutes les possibilités : tu ne peux donc jamais filtrer un `Maybe` en ne traitant que le cas où il y a un `Just someValue`.
Cela peut sembler pénible au début, mais c'est l'une des plus grandes forces du langage Elm.
Cela permet d'éviter des centaines de bugs et fait de la réécriture guidée par le compilateur une expérience sans crainte et gratifiante.

## D'autres fonctions pour manipuler `Maybe`

Le module `Maybe` propose aussi un certain nombre de fonctions utiles pour manipuler les types `Maybe`.

```elm
sayHelloAgain : Maybe String -> String
sayHelloAgain name = "Hello, " ++ Maybe.withDefault "World" name ++ "!"

capitalizeName : Maybe String -> Maybe String
capitalizeName name = Maybe.map String.toUpper name

capitalizeName matthieu
    --> Just "MATTHIEU"

capitalizeName anon
    --> Nothing
```
