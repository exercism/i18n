# Indices

## 1. Supprime les pistes en double

- Tu peux voir un exemple de création d'un ensemble à partir d'un tableau dans la [documentation MDN][mdn-relation-to-arrays].
- Veille bien à reconvertir ton ensemble en tableau avant de le renvoyer.
- Reviens sur le [concept de déstructuration de tableau][concept-array-destructuring] pour revoir comment utiliser l'opérateur de décomposition.

## 2. Vérifie si une piste a déjà été ajoutée

- Il existe une [méthode intégrée][mdn-set-has] pour vérifier si un élément se trouve dans un ensemble.

## 3. Ajoute une piste

- Il existe une [méthode intégrée][mdn-set-add] pour ajouter un élément à un ensemble.
- Veille à ne pas appeler `Set.has()` manuellement pour vérifier la présence de l'élément avant de l'ajouter ; c'est `Set.add()` qui s'en charge pour toi !

## 4. Supprime une piste

- Il existe une [méthode intégrée][mdn-set-delete] pour supprimer un élément d'un ensemble.
- Veille à ne pas appeler `Set.has()` manuellement pour vérifier la présence de l'élément avant de le supprimer ; c'est `Set.delete()` qui s'en charge pour toi !

## 5. Liste les artistes uniques

- Il existe [plusieurs façons différentes][mdn-set-iteration] de parcourir un ensemble.
- Il existe une [méthode intégrée][mdn-string-split] pour diviser une _string_ en sous-chaînes.
- Reviens sur le [concept de déstructuration de tableau][concept-array-destructuring] pour revoir comment ignorer un élément lors de la déstructuration d'un tableau.
