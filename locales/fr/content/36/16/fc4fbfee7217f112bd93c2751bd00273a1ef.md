# Généralités

- Assure-toi de bien comprendre comment créer et mettre à jour des tableaux.
- La [documentation Python sur les `lists`][python lists] peut vraiment t'aider.
- La [section du tutoriel Python sur les `lists`][more on lists] est aussi une bonne ressource.

## 1. Ajoute-moi à la file d'attente

- Une instruction `if-else` peut t'aider à déterminer le type de ticket auquel tu as affaire.
- Tu peux ensuite `append()` la personne à la file d'attente en fonction du type de ticket.

## 2. Où sont mes amis

- Tu dois trouver l'`index()` du nom de l'ami dans la file d'attente.

## 3. Puis-je les rejoindre ?

- Comme tu connais l'`index()`, tu peux `insert()` l'ami dans la file d'attente à cet endroit.

## 4. Personne désagréable dans la file d'attente

- Tu connais le nom de la personne désagréable, tu peux donc la retirer de la file d'attente avec `remove()`.

## 5. Homonymes

- Compter avec `count()` les occurrences du `name` dans la file d'attente pourrait être une bonne stratégie ici.

## 6. Retire la dernière personne

- Même si tu peux retirer la personne par son nom avec `remove()`, la faire sortir avec `pop()` pourrait être plus rapide.

## 7. Trie la file d'attente

- N'oublie pas que tu dois éviter de modifier la file d'attente et de perdre son ordre d'origine.
- Une fois que tu as fait une `copy()`, le tri avec `sort()` devrait être simple.
- On cherche un tri _croissant_, ou un tri _alphabétique de a à z_.
