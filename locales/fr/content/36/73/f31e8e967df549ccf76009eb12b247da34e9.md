# Introduction

Julia, comme la plupart des langages de programmation, propose une grande variété de types de collections.

Certaines sont intrinsèquement ordonnées (notamment les `Vectors` et les `Arrays` de dimension supérieure), ce qui permet d'accéder aux éléments par leur position.
D'autres collections ne sont pas ordonnées (`Sets`, `Dicts`), et il faut alors accéder à leurs éléments par clé ou par valeur.

Dans le cas le plus simple, imaginons que l'on dispose d'un `Vector` de `Ints` et qu'on veuille le trier par ordre croissant.

```julia-repl
julia> v = [3, 2, 4, 1]
4-element Vector{Int64}:
 3
 2
 4
 1

julia> sort(v)
4-element Vector{Int64}:
 1
 2
 3
 4

# sort descending
julia> sort(v, rev=true)
4-element Vector{Int64}:
 4
 3
 2
 1
```

Simple !
La fonction `sort()` porte un nom évident et, apparemment, renvoie le `Vector` trié.

_Je plaisante !_
À ce stade du programme, tu te doutes peut-être (à juste titre) qu'il reste des nuances à aborder.

## Fonctions mutantes et non mutantes

Après avoir exécuté `sort(v)`, que vaut `v` ?

```julia-repl
julia> v
4-element Vector{Int64}:
 3
 2
 4
 1

julia> issorted(v)
false
```

Le vecteur d'origine n'a pas changé.
`sort()` est une fonction ***non mutante*** qui renvoie une _copie_ de son entrée.

C'est une bonne conception dans bien des contextes : on a affaire à une [fonction pure][wiki-pure-func] dont le comportement est facile à comprendre, même dans du code parallèle ou distribué.

À l'inverse, imaginons un tableau d'un milliard de _strings_ que l'on veuille trier.

Le tri est probablement lent.
En plus, il faut tout copier (_lent !_) et allouer assez de mémoire (_plusieurs gigaoctets !_) pour stocker la copie.

Compare avec ce code très similaire :

```julia-repl
# v is as previously

julia> issorted(v)
false

julia> sort!(v)
4-element Vector{Int64}:
 1
 2
 3
 4

julia> v
4-element Vector{Int64}:
 1
 2
 3
 4

julia> issorted(v)
true
```

Maintenant, le `Vector` d'entrée est trié sur place, sans copie, et l'ordre d'origine est définitivement perdu.

Cela peut être efficace, cela peut aussi être source de bugs et d'effets de bord inattendus, et cela peut dérouter les autres personnes qui utilisent ton code.
_Choisis avec soin !_

`sort!()` est une « fonction mutante » et, par convention (_très forte_), toute fonction qui modifie ses entrées voit un `!` ajouté à la fin de son nom, en guise d'avertissement pour les programmeurs.

## Trier selon quoi ?

Trier des valeurs `Int64` est relativement simple : même de jeunes enfants comprennent que 2 est plus grand que 1 et plus petit que 3.

D'autres types peuvent être plus compliqués, mais en général `x < y` si `isless(x, y) == true`.
Julia fournit des implémentations de `isless()` pour la plupart des types standard.

Par exemple, les caractères Unicode (pour les lettres européennes, les majuscules se trient avant les minuscules) :

```julia-repl
julia> j = collect("Julia")
5-element Vector{Char}:
 'J': ASCII/Unicode U+004A (category Lu: Letter, uppercase)
 'u': ASCII/Unicode U+0075 (category Ll: Letter, lowercase)
 'l': ASCII/Unicode U+006C (category Ll: Letter, lowercase)
 'i': ASCII/Unicode U+0069 (category Ll: Letter, lowercase)
 'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)

julia> sort(j)
5-element Vector{Char}:
 'J': ASCII/Unicode U+004A (category Lu: Letter, uppercase)
 'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)
 'i': ASCII/Unicode U+0false069 (category Ll: Letter, lowercase)
 'l': ASCII/Unicode U+006C (category Ll: Letter, lowercase)
 'u': ASCII/Unicode U+0075 (category Ll: Letter, lowercase)
```

On peut aussi appliquer une fonction arbitraire aux éléments avant de les trier, comme `abs` pour ignorer le signe ou `uppercase` pour un tri insensible à la casse :

```julia-repl
julia> nums = [3, -2, -4, 1]
4-element Vector{Int64}:
  3
 -2
 -4
  1

julia> sort(nums)
4-element Vector{Int64}:
 -4
 -2
  1
  3

julia> sort(nums, by=abs)
4-element Vector{Int64}:
  1
 -2
  3
 -4

# j is from "Julia", as previously

julia> sort(j, by=uppercase)
5-element Vector{Char}:
 'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)
 'i': ASCII/Unicode U+0069 (category Ll: Letter, lowercase)
 'J': ASCII/Unicode U+004A (category Lu: Letter, uppercase)
 'l': ASCII/Unicode U+006C (category Ll: Letter, lowercase)
 'u': ASCII/Unicode U+0075 (category Ll: Letter, lowercase)

julia> vecs = [[1, 3], [4, 2], [3, 4], [2, 1]];

julia> sort(vecs)  # by default sorts by the first element of the (2-element) vectors
4-element Vector{Vector{Int64}}:
 [1, 3]
 [2, 1]
 [3, 4]
 [4, 2]

julia> sort(vecs, by=last)
4-element Vector{Vector{Int64}}:
 [2, 1]
 [4, 2]
 [1, 3]
 [3, 4]
```

## Trier un tableau d'indices

Si les éléments à trier sont de gros objets, il peut être plus simple de travailler avec leur indice de position.

```julia-repl
julia> langs = ["Julia", "C++", "Python", "Elixir"]
4-element Vector{String}:
 "Julia"
 "C++"
 "Python"
 "Elixir"

julia> inxs = sortperm(langs)  # => Integers
4-element Vector{Int64}:
 2
 4
 1
 3

julia> langs[inxs]  # sort the entire vector
4-element Vector{String}:
 "C++"
 "Elixir"
 "Julia"
 "Python"

julia> langs[inxs[1:2]]  # slice the indices
2-element Vector{String}:
 "C++"
 "Elixir"
```

Comme `langs` est un Vector, chaque indice est un entier de l'[intervalle][concept-range] `1:length(langs)`.
La sortie de `sortperm()` est une [permutation][wiki-permutation] de ces entiers, qui correspond à un tri du vecteur d'entrée.

## Tri partiel

Ton programme a-t-il besoin que toute l'entrée soit triée ?
Quand seules les premières ou les dernières entrées présentent un intérêt, un [tri partiel][wiki-partial-sort] peut être nettement plus rapide.

Julia fournit les fonctions `partialsort()` et `partialsort!()`. Elles garantissent que l'entrée ou la plage d'entrées spécifiée est correcte, mais n'offrent aucune garantie sur le reste de l'entrée.

Le deuxième argument peut être un entier ou une plage, représentant l'indice ou les indices de l'entrée triée :

```julia-repl
julia> vsq = [9, 4, 16, 1];  # would be [1, 4, 9, 16] after a full sort

julia> partialsort(vsq, 4)
16

julia> partialsort(vsq, 2:3)
2-element view(::Vector{Int64}, 2:3) with eltype Int64:
 4
 9
```
