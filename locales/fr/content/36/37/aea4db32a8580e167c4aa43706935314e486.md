# Introduction

Si les types des paramètres peuvent être déduits, Swift permet également d'omettre les noms des paramètres et le mot-clé `in` de la définition de la fermeture. On peut alors désigner les paramètres à l'aide d'une syntaxe abrégée spéciale, où `$0` désigne le premier paramètre, `$1` le second, et ainsi de suite.

```swift
let mean: (Double, Double) -> Double = { $0 + $1 / 2.0 }

["apple", "ball", "carrot"].sorted(by: { $0.count < $1.count })
```
