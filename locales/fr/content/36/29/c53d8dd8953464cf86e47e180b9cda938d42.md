# À propos

## Opérateurs de comparaison

Les [opérateurs de comparaison][comparison-operators] servent à comparer des valeurs et renvoient une valeur `true` ou `false`.
Ces opérateurs prennent deux valeurs à comparer, qui doivent être du même type.
Si les valeurs ne sont pas du même type, le compilateur lève une erreur.
Voici la liste des opérateurs de comparaison, avec un exemple de cas où ils renvoient `true` :

| Méthode | Description | Exemple |
| ------ | --------------------- | ------- |
| ==     | égal à                | 1 == 1  |
| !=     | différent de          | 1 != 2  |
| <      | inférieur à           | 4 < 5   |
| <=     | inférieur ou égal à   | 4 <= 4  |
| >      | supérieur à           | 3 > 1   |
| >=     | supérieur ou égal à   | 2 >= 2  |

## Les instructions `if` et `else`

Une [instruction conditionnelle][conditional-statement] permet d'exécuter du code selon une condition qui vaut `true` ou `false`.
L'instruction conditionnelle la plus simple est l'[instruction `if`][if], qui exécute du code lorsque la condition vaut `true`.
Pour déclarer une instruction `if`, on écrit le mot-clé `if`, suivi de la condition, puis du code à exécuter entre accolades.

```swift
let wheelCount = 4
if wheelCount == 4 {
  print("Your vehicle is a car")
}
// Prints "Your vehicle is a car"
```

On peut combiner `if` avec `else` pour exécuter du code lorsque la condition vaut `false`.
L'instruction `else` doit être utilisée avec une instruction `if` et ne peut pas être utilisée seule.
Pour déclarer une instruction `else`, on écrit le mot-clé `else` après les accolades de l'instruction `if`, puis le code à exécuter entre accolades.

```swift
let precipitationInMM = 0.5
if precipitationInMM > 0.5 {
  print("You will need an umbrella")
} else {
  print("You will not need an umbrella")
}
// Prints "You will not need an umbrella"
```

On peut aussi enchaîner les instructions `if` avec `else if` pour tester plusieurs conditions.
Le principe est le même que pour une instruction `if`, mais le mot-clé est `else if` au lieu de `if`.
Une instruction `if` n'a pas besoin d'une instruction `else` pour être valide, mais elle peut en avoir une si nécessaire.

```swift
let favoriteFruit = "Apple"

if favoriteFruit == "Banana" {
    print("Your favorite fruit is a banana")
} else if favoriteFruit == "Orange" {
    print("Your favorite fruit is an orange")
} else if favoriteFruit == "Apple" {
    print("Your favorite fruit is an apple")
} else {
    print("Your favorite fruit is not a banana, orange or apple")
}
// Prints "Your favorite fruit is an apple"
```

## L'expression `if`

Une instruction `if` peut aussi servir d'expression pour affecter une valeur à une variable.
La dernière instruction du bloc `if` sert de valeur à l'expression `if`.
C'est utile lorsque tu veux affecter une valeur à une variable selon une condition.

```swift
let CpuBits = 32
let largest = if CpuBits == 64 {
  "x86_64"
} else {
  "x86_32"
}

print(largest)
// Prints "x86_32"
```
