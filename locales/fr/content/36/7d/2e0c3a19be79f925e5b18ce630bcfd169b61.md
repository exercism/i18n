# Tests

## Exécute les tests

Pour exécuter les tests, lance la commande suivante :

```bash
call {slug}Test.bat
```

## Résous l'exercice

Résoudre un exercice, c'est faire passer tous ses tests.
Une fois que tous les tests passent, tu as résolu l'exercice !

Pour t'aider à démarrer, chaque exercice est livré avec un fichier d'implémentation _stub_.
Tu peux t'en servir comme point de départ pour construire ta solution.
N'hésite pas à supprimer ou à modifier ce fichier si tu penses que c'est la bonne chose à faire.
