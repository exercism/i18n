# Utilisation du découpage de _string_

Utilise le type intégré `rune` pour manipuler les caractères individuels en Go.
Une `string` peut être convertie en `[]rune` (une tranche de runes) avec :

```go
aRunes := []rune(a)
```

Découper la _string_ en une multitude de petites _string_ (une par rune) fonctionne, mais c'est inefficace.
