# Introduction

## Mappage

Le mappage désigne l'application d'une fonction à chaque élément d'une séquence pour produire une nouvelle séquence.

On peut facilement le faire sur une liste avec la fonction `mapcar`.
Supposons que l'on ait une fonction `double` qui multiplie son argument par `2` :

```lisp
(mapcar #'double '(1 2 3 4)) ; => (2 4 6 8)
```

On remarque que le premier argument est une fonction à appeler. Le `#'` est une syntaxe de citation spéciale pour désigner une fonction.

La fonction `double` a d'abord été appelée avec le premier élément, puis avec le deuxième, etc.
Les résultats ont été collectés dans une liste, qui est la valeur de l'expression.

## Filtrage

Le filtrage est le processus qui consiste à créer une séquence à partir d'une autre en copiant tous les éléments de la séquence d'origine sauf certains.
Le choix des éléments à inclure dans la nouvelle séquence peut se faire par une fonction prédicat (une fonction qui renvoie une valeur booléenne), ou par égalité avec un objet précis.

### Supprime à l'aide d'un prédicat

`remove-if` est une fonction qui prend une fonction prédicat et une séquence comme arguments, et renvoie une séquence contenant uniquement les éléments pour lesquels le prédicat a renvoyé une valeur fausse.
Autrement dit, elle « supprime » tous les éléments de la séquence pour lesquels le prédicat renvoie vrai. Toutefois, note que cette fonction ne modifie pas la séquence d'origine !
Au lieu de cela, elle renvoie une nouvelle séquence sans les éléments concernés. Si le prédicat était vrai pour toutes les valeurs, une séquence vide est renvoyée.

```lisp
(remove-if #'evenp '(1 2 3 4 5)) ; => (1 3 5)
(remove-if #'oddp '(1 3 5))      ; => ()
```

### Supprime un élément précis

Si l'on veut supprimer un élément précis d'une séquence, on peut utiliser `remove`, qui prend l'élément à supprimer et une séquence.
Toutes les valeurs de la séquence qui ne sont pas égales à l'élément à supprimer sont renvoyées.
REMARQUE : L'égalité est vérifiée par défaut avec le [prédicat d'égalité générique][concept-equality] `eql`.

```lisp
(remove 1 '(1 2 1 3 1 4)) ; => (2 3 4)
(remove #\l "hello")      ; => "heo"
```
