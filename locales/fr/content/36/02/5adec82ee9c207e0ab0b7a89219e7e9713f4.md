# Ajout aux instructions

## Format de sortie

Produis la séquence d'actions sous forme de _string_ terminée par un caractère nul, en utilisant une virgule et un espace comme séparateurs.

## Registres

| Registre | Usage        | Type    | Description                   |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | entrée        | entier | nombre entre 1 et 31       |
| `$a1`    | entrée/sortie | adresse | _string_ de sortie terminée par un caractère nul |
| `$t0-9`  | temporaire    | quelconque     | utilisé pour le stockage temporaire    |
