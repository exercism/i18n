# À propos

ABAP dispose de plusieurs types numériques. Les plus courants pour de petits exercices d'introduction sont `i` pour les valeurs entières et `p` pour les valeurs décimales _packed_.

Utilise `i` quand une valeur doit être un nombre entier, par exemple un nombre de jours. Utilise un type décimal quand une valeur peut contenir des chiffres après la virgule, comme un taux horaire.

```abap
DATA hours_per_day TYPE i VALUE 8.
DATA rate_per_hour TYPE p LENGTH 8 DECIMALS 2 VALUE '89.89'.

DATA day_rate TYPE p LENGTH 8 DECIMALS 2.
day_rate = hours_per_day * rate_per_hour.
```

Les nombres _packed_ sont souvent utilisés dans les applications de gestion quand un nombre fixe de décimales est nécessaire. ABAP dispose aussi de nombres à virgule flottante décimaux (`decfloat16` et `decfloat34`) et de nombres à virgule flottante binaires (`f`). Les nombres à virgule flottante binaires peuvent être utiles pour les calculs scientifiques, mais ils ne constituent pas un bon choix par défaut pour les exemples de type monétaire, car beaucoup de fractions décimales ne peuvent pas être représentées exactement.
