# Introduction

Les entrées/sorties de Factor reposent sur des *flux* : des objets depuis lesquels on lit des octets ou des caractères, ou vers lesquels on les écrit. Le vocabulaire [`io`][io] te donne deux vues d'un même [protocole][stream-protocol].

## Les deux vues

Les mots **à flux explicite** prennent le flux en argument. Ils commencent tous par `stream-` :

```
stream-read       ( n stream -- seq/f )
stream-readln     ( stream -- str/f )
stream-write      ( seq stream -- )
stream-flush      ( stream -- )
stream-contents   ( stream -- seq )
stream-lines      ( stream -- seq )
```

Les mots **à flux ambiant** lisent depuis le flux *actuellement lié*, ou écrivent vers lui : il s'agit de la variable dynamique globale du programme `input-stream` ou `output-stream`. Leurs noms sont courts :

```
read1 read readln write write1 print flush
```

C'est la forme ambiante que l'on retrouve dans la plupart du code de tous les jours. On préfère la forme explicite quand on tient un flux précis et qu'on ne veut pas remplacer le flux ambiant.

## Les flux en mémoire

Pour cet exercice, tu travailleras avec des flux adossés à des _strings_, issus de [`io.streams.string`][io.streams.string] :

```
<string-reader>   ( str -- reader )
<string-writer>   ( -- writer )
```

Un `<string-reader>` lit depuis une _string_ littérale comme s'il s'agissait d'un fichier ; un `<string-writer>` collecte tout ce qu'on lui écrit, ce qui permet de le relire plus tard. Les deux implémentent le même protocole que les flux de fichiers, donc ce que tu apprends ici se transpose directement à `<file-reader>` / `<file-writer>`.

## Délimiter la portée avec `with-…`

Pour lier un flux explicite comme flux ambiant le temps d'une _quotation_ et le libérer ensuite, utilise un combinateur `with-…` :

```
with-input-stream    ( stream quot -- )
with-output-stream   ( stream quot -- )
with-string-writer   ( quot -- str )
with-file-reader     ( path encoding quot -- )
with-file-writer     ( path encoding quot -- )
```

Le combinateur [`with-string-writer`][with-string-writer] est la forme commode pour « collecter ce qu'affiche cette _quotation_ ». Il crée le writer, exécute la _quotation_ avec ce writer comme sortie ambiante, et renvoie la _string_ capturée :

```factor
USING: io io.streams.string ;

[ "captured" print ] with-string-writer .
! => "captured\n"
```

Tous les combinateurs `with-…` sont des combinateurs destructeurs (de la même famille que `with-disposal` et `with-destructors` de [`boatswains-bilge`][boatswains-bilge]) : le flux est libéré à la sortie, même si la _quotation_ lève une erreur.
