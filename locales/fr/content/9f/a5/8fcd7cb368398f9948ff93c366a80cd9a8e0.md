# Instructions

Dans cet exercice, tu vas travailler sur un planificateur de rendez-vous pour un salon de beauté qui a ouvert ses portes le 15 septembre 2012.

Tu as cinq tâches, qui porteront toutes sur des dates de rendez-vous.

## 1. Analyse la date d'un rendez-vous

Implémente la fonction `Schedule` pour analyser la représentation textuelle d'une date de rendez-vous et la convertir au format `time.Time` correspondant :

```go
Schedule("7/25/2019 13:45:00")
// => 2019-07-25 13:45:00 +0000 UTC
```

## 2. Vérifie si un rendez-vous est déjà passé

Implémente la fonction `HasPassed` qui prend une date de rendez-vous et vérifie si le rendez-vous se situe quelque part dans le passé :

```go
HasPassed("July 25, 2019 13:45:00")
// => true
```

## 3. Vérifie si le rendez-vous a lieu l'après-midi

Implémente la fonction `IsAfternoonAppointment` qui prend une date de rendez-vous et vérifie si le rendez-vous a lieu l'après-midi (>= 12:00 et < 18:00) :

```go
IsAfternoonAppointment("Thursday, July 25, 2019 13:45:00")
// => true
```

## 4. Décris la date et l'heure du rendez-vous

Implémente la fonction `Description` qui prend une date de rendez-vous et renvoie une description de cette date et de cette heure :

```go
Description("7/25/2019 13:45:00")
// => "You have an appointment on Thursday, July 25, 2019, at 13:45."
```

## 5. Renvoie la date anniversaire de l'ouverture du salon

Implémente la fonction `AnniversaryDate` qui renvoie la date anniversaire de l'ouverture du salon pour l'année en cours en UTC.

En supposant que l'année en cours soit 2020 :

```go
AnniversaryDate()

// => 2020-09-15 00:00:00 +0000 UTC
```

**Remarque :** la valeur de retour est un `time.Time` et l'heure de la journée n'a pas d'importance.
