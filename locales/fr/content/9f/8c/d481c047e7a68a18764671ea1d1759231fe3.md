# Instructions

Dans la continuité de ton travail sur le parc d'attractions, tu dois maintenant écrire quelques méthodes utilitaires pour faciliter la vérification de l'accès d'un visiteur à une attraction.

## 1. Vérifie si un visiteur a un pass d'attraction

Implémente la méthode `Attendee#has_pass?` pour renvoyer une valeur booléenne (`true`/`false`) en fonction de la présence d'un pass d'attraction.

```ruby
Attendee.new(100).has_pass?
# => false
```

## 2. Vérifie si un visiteur peut monter dans une attraction

Implémente la méthode `Attendee#fits_ride?` pour déterminer si un visiteur peut monter dans une attraction en fonction de sa taille.
La taille minimale requise pour l'attraction est fournie en argument.
La taille d'un visiteur doit être supérieure ou égale à la taille minimale requise pour l'attraction.

```ruby
Attendee.new(140).fits_ride?(100)
# => true
```

## 3. Vérifie si un visiteur est autorisé à monter dans une attraction

Implémente la méthode `Attendee#allowed_to_ride?` pour déterminer si un visiteur est autorisé à monter dans une attraction. La taille minimale requise pour l'attraction est fournie en argument. Un visiteur doit avoir un pass d'attraction et avoir la taille requise pour monter dans l'attraction.

```ruby
attendee = Attendee.new(100)
attendee.issue_pass!(42)
attendee.allowed_to_ride?(120)
# => false
```
