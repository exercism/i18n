# Introduction

Chaque bit d'un entier peut servir à stocker une valeur binaire.
Comme de nombreuses situations reposent sur de l'information binaire, comme vrai ou faux, l'inclusion ou l'exclusion, allumé ou éteint, la représentation binaire d'un entier de N bits offre un moyen compact de coder l'état binaire de N éléments.
C'est ce qui rend la capacité à manipuler des bits et des octets essentielle en langage assembleur.
Le jeu d'instructions x86-64 offre une grande variété d'instructions de manipulation de bits.

## Manipulation d'un seul bit

Ces instructions agissent sur un seul bit d'un opérande.

Elles prennent toutes deux opérandes, et la seconde indique l'indice du bit sur lequel on opère dans la première.
Toutes copient le bit sélectionné dans le **drapeau de retenue (CF)**.

| Nom  | Description                                                                   |
|------|-------------------------------------------------------------------------------|
| `bt` | copie le bit dans `CF` sans modifier d'opérande |
| `bts`| copie le bit dans `CF` et le met à 1 dans l'opérande de destination |
| `btr`| copie le bit dans `CF` et le met à 0 dans l'opérande de destination |
| `btc`| copie le bit dans `CF` et le complémente (l'inverse) dans l'opérande de destination |

## Opérations bit à bit

Les opérations bit à bit s'appliquent à tous les bits d'un opérande.

Chacune dispose d'une instruction portant le même nom que l'opération bit à bit effectuée :

| Nom   | Description                                  |
|-------|----------------------------------------------|
| `and` | 1 si les deux bits valent 1 |
| `or`  | 1 si au moins un des bits vaut 1 |
| `xor` | 1 si les bits diffèrent |
| `not` | 1 si le bit valait 0 ; 0 si le bit valait 1 |

La plupart prennent deux opérandes, effectuent une opération bit à bit sur les deux et stockent le résultat dans l'opérande de destination.
L'exception est `not`, qui ne prend qu'un seul opérande de destination.

## Masques

Quand on interprète un et zéro comme l'inclusion et l'exclusion, respectivement, on appelle un tel entier un _masque binaire_ (ou simplement un _masque_).

Un masque binaire « masque » des éléments : un zéro au `i`-ième bit exclut le `i`-ième élément, tandis qu'un un l'inclut.
On utilise aussi couramment un masque binaire pour inclure certains bits d'un entier tout en excluant les autres.

Par exemple, soit `A` un entier dont la représentation binaire est :

| indice | 7 | 6 | 5 | 4 | 3 | 2 | 1 | 0 |
|--------|---|---|---|---|---|---|---|---|
| bits   | 1 | 0 | 0 | 1 | 0 | 1 | 0 | 1 |

Soit également `M` un entier dont la représentation binaire est :

| indice | 7 | 6 | 5 | 4 | 3 | 2 | 1 | 0 |
|--------|---|---|---|---|---|---|---|---|
| bits   | 0 | 0 | 0 | 0 | 1 | 1 | 0 | 1 |

Les deux sont des entiers de `8` bits.
Dans ce cas, on peut dire que `M` sélectionne les bits `0`, `2` et `3` de `A`, et exclut les autres.

Les instructions bit à bit vues plus haut sont utiles pour manipuler des entiers à l'aide de masques.
Par exemple :

- Pour *effacer* les bits de `A` qui ne sont pas sélectionnés par `M`, il faut faire un ET bit à bit : `A AND M`.
- Pour *mettre à 1* les bits de `A` sélectionnés par `M`, il faut faire un OU bit à bit : `A OR M`.

## L'instruction `test`

L'instruction `test` effectue un ET bit à bit entre les deux opérandes et positionne les drapeaux en fonction du résultat.

Si A est le premier opérande et B le second :

| drapeau | positionné quand              |
|:-------:|:------------------------------|
| `CF`    | toujours effacé               |
| `ZF`    | A ET B == 0                   |
| `SF`    | le bit de signe de A ET B vaut 1 |
| `OF`    | toujours effacé               |

Cette instruction prend deux opérandes et met à jour les drapeaux, mais **ne modifie pas ses opérandes**.

## Opérations de décalage

Ces instructions décalent les bits de l'opérande de destination d'un nombre de positions spécifié par le second opérande.
Le second opérande doit être un nombre constant (un `immediate`) ou le registre `cl` (les `8` bits de poids faible de `rcx`).

| Nom         | Description              |
|-------------|--------------------------|
| `shl`/`sal` | Décale les bits vers la gauche |
| `shr`/`sar` | Décale les bits vers la droite |

À noter que le nombre de positions du second opérande est masqué sur `5` bits, ou `6` bits avec un opérande de destination de `64` bits.
Tout bit au-delà est en pratique ignoré.
Cela signifie que le décalage maximal est de `31`, ou `63` avec un opérande de `64` bits.

### `shl` / `sal`

`shl` et `sal` effectuent exactement la même opération : l'une est un alias de l'autre.

À chaque décalage vers la gauche, les bits les plus proches de la fin de la séquence sur la longueur du décalage sont d'abord déplacés dans `CF`, puis écartés.
À l'inverse, un nombre de nouveaux bits à zéro égal à la longueur du décalage est ajouté au début.

Comme chaque bit d'un entier représente une puissance de `2`, un décalage vers la gauche de n positions revient à multiplier l'entier par `2ⁿ`.

### `shr` / `sar`

Il existe deux instructions pour décaler les bits vers la droite : `shr` et `sar`.

Quelle que soit celle des deux instructions utilisée, les bits les plus proches du début de la séquence sur la longueur du décalage sont d'abord déplacés dans `CF`, puis écartés.
À l'inverse, un nombre de nouveaux bits égal à la longueur du décalage est ajouté à la fin.

La différence entre les deux est que `shr` insère des bits `0` à l'extrémité gauche, tandis que `sar` insère un `1` si le bit de poids fort était positionné, et un `0` sinon.
Cela signifie que `sar` préserve le signe lors du décalage d'un entier signé.

Comme chaque bit d'un entier représente une puissance de `2`, un décalage vers la droite de n positions avec `shr` revient à effectuer une division *non signée* par `2ⁿ`.

De même, un décalage vers la droite de n positions avec `sar` revient à effectuer une division *signée* par `2ⁿ`.

## Opérations de rotation

Ces instructions déplacent les bits de l'opérande de destination d'un nombre de positions spécifié par le second opérande.
Le second opérande doit être un nombre constant (un `immediate`) ou le registre `cl` (les `8` bits de poids faible de `rcx`).

La différence entre une rotation et un décalage est qu'une rotation n'écarte ni n'ajoute aucun bit.
Les bits qui seraient écartés par un décalage sont au contraire déplacés vers l'extrémité opposée.
Ainsi, tous les bits restent, ils changent tous de place.

| Nom   | Description                |
|-------|----------------------------|
| `rol` | Effectue une rotation des bits vers la gauche |
| `ror` | Effectue une rotation des bits vers la droite |

À noter que le nombre de positions du second opérande est masqué sur `5` bits, ou `6` bits avec un opérande de destination de `64` bits.
Tout bit au-delà est en pratique ignoré.
Cela signifie que la rotation maximale est de `31`, ou `63` avec un opérande de `64` bits.

## Autres instructions de manipulation de bits

Il existe d'autres instructions de manipulation de bits utiles :

| Nom      | Description                                    |
|----------|------------------------------------------------|
| `popcnt` | Compte le nombre de bits à 1 |
| `bsr`    | Donne l'indice du bit de poids fort à 1. Si aucun bit n'est à 1, le résultat est indéfini |
| `bsf`    | Donne l'indice du bit de poids faible à 1. Si aucun bit n'est à 1, le résultat est indéfini |

Ces instructions fonctionnent toutes avec deux opérandes de `16`, `32` ou `64` bits.
Elles ne peuvent pas être utilisées avec des opérandes de `8` bits.
