# À propos

La classe Lambda est un ensemble de méthodes fonctionnelles permettant de faire de la programmation de style fonctionnel avec Haxe. Elle permet d'opérer sur un Iterable entier d'un seul coup. C'est souvent préférable aux boucles, car c'est moins sujet aux erreurs et plus facile à lire. Pour plus de commodité, les classes Array et List contiennent certaines des méthodes les plus fréquemment utilisées de la classe Lambda.

Voici quelques-unes des fonctions de la classe `Lambda` :

- `Lambda.array`, `Lambda.list` Convertissent un Iterable en Array ou en List. Elles renvoient toujours une nouvelle instance.
- `Lambda.count` Compte le nombre d'éléments. Si l'Iterable est un Array ou une List, il est plus rapide d'utiliser sa propriété length.
- `Lambda.has` Détermine si l'élément spécifié se trouve dans l'Iterable.
- `Lambda.indexOf` Trouve l'indice de l'élément spécifié.
- `Lambda.find` Trouve le premier élément correspondant à la fonction de recherche donnée.
- `Lambda.concat` Fusionne deux Iterables et renvoie une nouvelle List.
- `Lambda.filter` Trouve les éléments qui satisfont un critère et renvoie une nouvelle List.

Un exemple illustrant quelques fonctions :

```haxe
using Lambda;

class Main {
  static function main() {
    var words = ["boat", "dog", "phone", "cat", "food"];

    var isThreeLetters = function(word) return word.length == 3;

    trace(words.filter(isThreeLetters)); // [dog,cat]
  }
}
```
