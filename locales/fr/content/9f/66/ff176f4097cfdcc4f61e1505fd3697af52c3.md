# Instructions

Dans cet exercice, tu vas traiter des lignes de _log_.

Chaque ligne de _log_ est une _string_ formatée comme suit : `"[<LEVEL>]: <MESSAGE>"`.

Il existe trois niveaux de _log_ différents :

- `INFO`
- `WARNING`
- `ERROR`

Tu as trois tâches, chacune prenant une ligne de _log_ et te demandant d'en faire quelque chose.

## 1. Récupère le message d'une ligne de log

Implémente la méthode (_static_) `LogLevels.message()` pour renvoyer le message d'une ligne de _log_ :

```java
LogLevels.message("[ERROR]: Invalid operation")
// => "Invalid operation"
```

Les espaces en début et en fin de ligne doivent être supprimés :

```java
LogLevels.message("[WARNING]:  Disk almost full\r\n")
// => "Disk almost full"
```

## 2. Récupère le niveau de log d'une ligne de log

Implémente la méthode (_static_) `LogLevels.logLevel()` pour renvoyer le niveau de _log_ d'une ligne de _log_, qui doit être renvoyé en minuscules :

```java
LogLevels.logLevel("[ERROR]: Invalid operation")
// => "error"
```

## 3. Reformate une ligne de log

Implémente la méthode (_static_) `LogLevels.reformat()` qui reformate la ligne de _log_, en plaçant le message en premier et le niveau de _log_ après, entre parenthèses :

```java
LogLevels.reformat("[INFO]: Operation completed")
// => "Operation completed (info)"
```
