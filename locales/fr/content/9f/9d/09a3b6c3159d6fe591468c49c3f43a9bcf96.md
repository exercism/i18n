# Structures

Les structures sont des types de données personnalisés qui permettent de nommer et de regrouper plusieurs valeurs liées entre elles.
Elles ressemblent aux tuples, mais sont plus flexibles et permettent de nommer chaque donnée, ce qui rend le code plus clair.
Les structures en Cairo ont les propriétés suivantes :

- Chaque type de structure a un nom qui lui est propre.
- Chaque membre d'une structure s'appelle un **champ**.
- Chaque champ d'une structure a un nom qui lui est propre.
- La visibilité est gérée au niveau de chaque champ : chaque champ peut être public ou privé indépendamment.

## Définis et instancie des structures

Pour définir une structure, utilise le mot-clé `struct` suivi d'un nom et d'accolades contenant les champs avec leurs noms et leurs types :

```rust
#[derive(Drop)]
struct User {
    active: bool,
    username: ByteArray,
    email: ByteArray,
    sign_in_count: u64,
}
```

Pour créer une instance d'une `struct`, indique le nom de la `struct` et utilise des accolades avec des paires clé-valeur pour les champs.
Note que tu peux lister les champs dans n'importe quel ordre lors de la création d'une instance :

```rust
let user1 = User {
   active: true, username: "someusername123", email: "someone@example.com", sign_in_count: 1
};

let user2 = User {
    sign_in_count: 1, username: "someusername123", active: true, email: "someone@example.com"
};
```

## Interagis avec une instance de structure

Utilise la notation pointée pour accéder aux champs d'une `struct` ou pour les modifier.
Note que pour modifier un champ, l'instance doit être mutable :

```rust
let mut user1 = User {
    active: true, username: "someusername123", email: "someone@example.com", sign_in_count: 1
};
user1.email = "anotheremail@example.com";
```

Comme pour toute expression, on peut construire une nouvelle instance de la `struct` comme dernière expression du corps de la fonction, afin de renvoyer implicitement cette nouvelle instance :

```rust
fn build_user(email: ByteArray, username: ByteArray) -> User {
    User {
        email: email,
        username: username,
        active: true,
        sign_in_count: 1,
    }
}
```

## Raccourci d'initialisation des champs

Dans le dernier exemple, il était logique de nommer les paramètres `email` et `username` de la fonction avec les mêmes noms que les champs de la `struct`, mais devoir les répéter pour les affecter aux champs est un peu fastidieux.
Heureusement, il existe un raccourci pratique pour initialiser les champs d'une structure à partir de variables portant les mêmes noms :

```rust
fn build_user_short(email: ByteArray, username: ByteArray) -> User {
    User { email, username, active: true, sign_in_count: 1, }
}
```

## Crée des instances à partir d'autres instances avec la syntaxe de mise à jour de structure

Utilise la syntaxe de mise à jour de structure pour créer une nouvelle instance à partir d'une instance existante, en modifiant certains champs tout en gardant les autres identiques.
On y parvient à l'aide de l'opérateur `..`.

Sans la syntaxe de mise à jour :

```rust
let user2 = User {
    active: user1.active,
    username: user1.username,
    email: "another@example.com",
    sign_in_count: user1.sign_in_count,
};
```

Avec la syntaxe de mise à jour :

```rust
let user2 = User { email: "another@example.com", ..user1 };
```

La syntaxe `..user1` copie les champs restants de `user1` vers `user2`.
Note que cela déplace les données de `user1` vers `user2`, donc `user1` ne peut plus être utilisé par la suite s'il contient des types non copiables.
