# Indices

## 1. Récupère tous les vins d'une couleur donnée

- Les arguments nommés s'écrivent en plaçant un nom devant l'argument, les deux étant séparés par un espace.
- La fonction [`list.filter`][list-filter] permet de sélectionner les éléments d'une liste qui correspondent à un prédicat donné.

## 2. Récupère tous les vins d'une couleur donnée mis en bouteille en une année donnée

- Les arguments nommés s'écrivent en plaçant un nom devant l'argument, les deux étant séparés par un espace.
- La fonction [`list.filter`][list-filter] permet de sélectionner les éléments d'une liste qui correspondent à un prédicat donné.

## 3. Récupère tous les vins d'une couleur donnée mis en bouteille dans un pays donné

- On peut implémenter cette fonction en appelant `wines_from_country`, puis `wines_of_color` sur le résultat.

[list-filter]: https://hexdocs.pm/gleam_stdlib/gleam/list.html#filter
