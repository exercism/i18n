# À propos

[F#](https://try.fsharp.org/) est un langage fonctionnel fortement typé qui fait partie de la famille des langages .NET de Microsoft.

Bien que F# soit idéal pour les problèmes de science des données, il peut traiter avec élégance presque tous les problèmes qu'on lui soumet.

Comme F# s'exécute sur le runtime .NET, on a accès à tout l'écosystème .NET, y compris tous les paquets disponibles sur [nuget.org](https://www.nuget.org/).

L'intégration avec du code .NET existant est d'autant plus simple que F# permet aussi d'écrire du code orienté objet.

La page d'accueil de F# est [fsharp.org](http://fsharp.org/) et une excellente introduction à F# se trouve sur le site [F# for fun and profit](http://fsharpforfunandprofit.com/).
