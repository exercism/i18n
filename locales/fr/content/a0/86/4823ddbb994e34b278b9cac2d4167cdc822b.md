# Ajout aux instructions

## Travaille avec les dates en Prolog

La prise en charge des dates intégrée à Prolog est [assez rudimentaire][built-in-dates-support].
Une façon bien plus agréable de travailler avec les dates est de passer par le [paquet date_time][date_time-package].

### Installe le paquet date_time

Si la version de Swipl que tu as installée est suffisamment récente, tu peux installer le paquet en lançant :

```bash
swipl pack install date_time
```

Si ça ne fonctionne pas, tu peux lancer :

```shell
swipl -g 'pack_install(date_time)'
```

~~~~exercism/note
Si tu utilises l'éditeur en ligne, tu n'as besoin de rien installer manuellement.
~~~~

### Utilise le paquet date_time

Ajoute le code suivant en haut de ton fichier de solution pour utiliser le paquet `date_time` :

```prolog
:- use_module(library(date_time)).
```

~~~~exercism/note
Astuce : la [source du paquet date_time][https://www.swi-prolog.org/pack/file_details/date_time/prolog/date_time.pl?show=src] est bien documentée et peut t'être d'une grande aide !
~~~~
