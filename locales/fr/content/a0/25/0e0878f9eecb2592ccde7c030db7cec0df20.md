# Général

- La documentation sur les [expressions régulières][regular-expressions] décrit les regex et la variante intégrée aux bibliothèques .NET.
- La documentation de [Regex][regex] décrit la classe intégrée de la bibliothèque.

## 1. Identifie les lignes de log corrompues

- Voir [cette discussion][ismatch] sur la mise en correspondance.

## 2. Découpe la ligne de log

- [Cet article][split] présente une approche pour découper des lignes.

## 3. Compte le nombre de lignes qui contiennent un mot de passe

- Voir [cette discussion][multiple-matches] sur les correspondances multiples et [ceci][multi-line] sur les recherches multilignes.

## 4. Supprime les artefacts du log

- [Cet article][replace] montre comment remplacer du texte.

## 5. Liste les lignes avec des mots de passe extrêmement faibles afin de pouvoir punir les coupables
