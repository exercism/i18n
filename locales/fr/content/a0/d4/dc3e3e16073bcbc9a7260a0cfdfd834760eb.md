# Ajout aux instructions

## Registres

| Registre | Utilisation  | Type    | Description                                        |
| -------- | ------------ | ------- | -------------------------------------------------- |
| `$a0`    | entrée       | adresse | chaîne de caractères d'entrée terminée par un nul  |
| `$a1`    | entrée       | entier  | clé de décalage                                    |
| `$a2`    | entrée/sortie | adresse | chaîne de caractères de résultat terminée par un nul |
| `$t0-9`  | temporaire   | quelconque | pour le stockage temporaire                     |
