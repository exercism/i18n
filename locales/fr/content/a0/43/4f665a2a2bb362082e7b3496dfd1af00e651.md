# Introduction

En Haxe, un **tableau** est une collection d'éléments (généralement) du même type. Il y a trois façons de créer un tableau en Haxe, soit avec un constructeur, soit avec une syntaxe de déclaration. En Haxe, le premier élément d'un tableau a un indice de zéro :

```haxe
var a = [1, 2, 3];
trace(a); // [1,2,3]

// Here the second element is called by index
trace(a[1]); // 2

// The actual first element's index is 0
trace(a[0]); // 1
```

Pour créer un tableau avec un constructeur, il faut passer le type des éléments qui seront inclus dans le tableau :

```haxe
var a:Array<Int> = [0, 1, 2, 3];
a[1] = "Hello"; // Error: the array a takes integers only
```

Si on veut qu'un tableau contienne plusieurs types d'éléments, on ajoute le type `Dynamic` à l'indicateur de type :

```haxe
var a:Array<Dynamic> = [10, "Bob", true]
```
