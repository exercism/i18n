# Introduction

Il existe deux types de nombres différents en C# :

- Les entiers : des nombres sans chiffre après le séparateur décimal (nombres entiers). Par exemple `-6`, `0`, `1`, `25`, `976` et `500000`.
- Les nombres à virgule flottante : des nombres avec zéro ou plusieurs chiffres après le séparateur décimal. Par exemple `-2.4`, `0.1`, `3.14`, `16.984025` et `1024.0`.

Les deux types numériques les plus courants en C# sont `int` et `double`. Un `int` est un entier de 32 bits et un `double` est un nombre à virgule flottante de 64 bits.

Les opérations arithmétiques se font à l'aide des opérateurs arithmétiques standard. Les nombres peuvent être comparés à l'aide des opérateurs de comparaison numériques standard ainsi que des opérateurs d'égalité (`==`) et d'inégalité (`!=`).

C# propose deux types de conversions numériques :

1. Les conversions implicites : aucune donnée n'est perdue et aucune syntaxe supplémentaire n'est nécessaire.
2. Les conversions explicites : des données peuvent être perdues et une syntaxe supplémentaire, sous la forme d'un _cast_, est nécessaire.

Comme un `int` a une précision moindre qu'un `double`, la conversion d'un `int` vers un `double` est sûre et constitue donc une conversion implicite. En revanche, convertir un `double` en `int` peut entraîner une perte de données, ce qui nécessite une conversion explicite.

```csharp
int softCool = 1358938113;
double notLost = 4.8151623;

// implicit cast: no loss of information
double macDebug = softCool;         // 1358938113.0

// explicit cast: possible loss of information 
int somethingLost = (int)notLost;   // 4
```
