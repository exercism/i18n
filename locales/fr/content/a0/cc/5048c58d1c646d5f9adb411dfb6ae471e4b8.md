# Introduction

De nombreux langages ont un moyen comme `null` ou `none` d'indiquer qu'une valeur n'existe pas. Comme R est conçu pour traiter de grands volumes de données (souvent désordonnées), il possède plusieurs formes de néant.

L'objectif général est de signaler les valeurs manquantes ou suspectes au fur et à mesure qu'on les rencontre, puis de continuer sans lever d'exception.

## NULL

Si une valeur n'existe vraiment pas, elle est représentée par `NULL`. C'est probablement ce qui se rapproche le plus de ce que feraient C ou Python.

```R
v <- c() # zero-length vector
v
#> NULL
is.null(v)
#> [1] TRUE
```

Dans de nombreux contextes, les valeurs `NULL` sont simplement ignorées :

```R
c(2, 3, NULL, 5)
#> [1] 2 3 5
```

## NA

Dans les situations où une valeur existe mais où l'on ne sait pas ce qu'elle vaut, on utilise `NA`. Par exemple, lorsqu'on compte les véhicules qui circulent sur une route, les observateurs humains peuvent tomber malades ou les capteurs automatiques tomber en panne, mais le trafic continue de s'écouler.

```R
v <- c(1, 2, NA, 4, 5)
v
#> [1]  1  2 NA 4  5
is.na(v) # test for data gaps
#> [1] FALSE FALSE  TRUE FALSE FALSE
```

Ainsi, `NA` est un marqueur qui avertit qu'il faut décider de la façon de le traiter.

## NaN

Abréviation de « Not a Number », `NaN` signale un problème de calcul dans les situations où un nombre était attendu.

```R
n <- c(0, 2, 4)
d <- c(0, 1, 2)
n / d
#> [1] NaN   2   2  # 0/0 is mathematically undefined
is.nan(n / d)
#> [1]  TRUE FALSE FALSE
```

Ce n'est pas la seule possibilité de calcul « invalide ».
Diviser par zéro renvoie `Inf` ou `-Inf` lorsque le numérateur est non nul, sans lever d'erreur.

```R
1 / 0
#> [1] Inf
```

## Vecteurs vides

Étonnamment peut-être, R n'a pas de moyen standard de vérifier qu'un vecteur est vide.

Même générer un vecteur vide n'est pas totalement évident.
On a vu dans une section précédente que `c()` sans argument renvoie `NULL`, et non un vecteur.

```R
is.vector(c())
#> [1] FALSE
```

Des fonctions comme `logical()` ou `integer()` prennent un argument qui précise la longueur souhaitée, laquelle peut être nulle.

```R
z <- logical(0)
is.vector(z)
#> [1] TRUE
length(z)
#> [1] 0
```

On peut aussi créer un vecteur puis en supprimer tous les éléments, comme décrit dans le [concept Vecteurs][concept-vectors].
On obtient alors un vecteur de longueur 0 du type approprié.

```R
v <- 5
v[-1]  # delete the first element
#> numeric(0)
```

[concept-vectors]: https://exercism.org/tracks/r/concepts/vectors
