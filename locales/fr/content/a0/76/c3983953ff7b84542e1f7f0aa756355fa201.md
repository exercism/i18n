# À propos

`when` est le mot-clé qui permet de filtrer les exceptions. Il se place après l'instruction `catch` et peut prendre une expression booléenne contenant n'importe quelle valeur présente dans la portée à ce moment-là. Ces valeurs ne doivent pas forcément être des membres de l'exception elle-même. Si le type de l'exception correspond et que l'expression vaut vrai, le bloc associé à cette instruction `catch` est exécuté ; sinon, c'est l'instruction `catch` suivante, s'il y en a une, qui est vérifiée.

```csharp
try
{
    // do stuff
}
catch (Exception ex) when (ex.Message != "")
{
    // output the message when it is not empty
}
catch (Exception ex)
{
    // show stack trace or something.
}
```
