# Instructions

Il y a un magasin d'électroménager appelé « Tech Palace » non loin d'ici.
Le propriétaire du magasin a récemment installé un grand écran pour diffuser des messages publicitaires et afficher un message d'accueil particulier lorsque les clients scannent leur carte de fidélité à l'entrée.
L'écran est composé de nombreuses petites LED et peut afficher plusieurs lignes de texte.

Le propriétaire du magasin a besoin de ton aide pour le code qui génère le texte destiné au nouvel écran.

## 1. Crée le message de bienvenue

<!-- markdownlint-disable-next-line MD038 -->
Pour la plupart des clients qui scannent leur carte de fidélité, le propriétaire du magasin veut voir s'afficher `Welcome to the Tech Palace, ` suivi du nom du client en majuscules.

Implémente la fonction `welcome_message` qui prend le nom du client sous la forme d'une courte _string_ (un argument de type `felt252`) et renvoie le message souhaité sous la forme d'un `ByteArray`.

```rust
welcome_message("Judy")
// => Welcome to the Tech Palace, JUDY
```

## 2. Ajoute une bordure décorative

Pour les clients fidèles qui achètent beaucoup dans le magasin, le propriétaire souhaite rendre l'affichage du message de bienvenue plus attrayant en ajoutant une ligne d'étoiles avant et après ce message.
Il ne sait pas encore combien d'étoiles doivent figurer sur ces lignes, il veut donc que ce soit configurable.

Écris une fonction `add_border` qui prend en arguments un message de bienvenue (un `ByteArray`) et le nombre d'étoiles par ligne (de type `u32`).
Elle doit renvoyer un `ByteArray` composé de 3 lignes : une ligne avec le nombre d'étoiles souhaité, puis le message de bienvenue tel qu'il a été transmis, puis une autre ligne d'étoiles.

```rust
add_border("Welcome!", 10)
```

Doit renvoyer ce qui suit :

```bash
**********
Welcome!
**********
```

## 3. Nettoie les anciens messages publicitaires

Avant d'installer ce nouvel écran, le magasin disposait d'un écran similaire qui ne pouvait afficher que des lignes statiques et non configurables.
Le propriétaire aimerait réutiliser certains des anciens messages publicitaires sur le nouvel écran.
Cependant, les données contiennent déjà une bordure d'étoiles et quelques espaces indésirables.
Ta tâche consiste à nettoyer les messages pour qu'ils puissent être réutilisés.

Implémente une fonction `clean_up_message` qui prend l'ancien message publicitaire sous la forme d'un `ByteArray`.
La fonction doit d'abord supprimer toutes les étoiles du texte, puis retirer les espaces au début et à la fin du texte restant.
La fonction doit ensuite renvoyer le message nettoyé.

```rust
let message: ByteArray = "
**************************
*    BUY NOW, SAVE 10%   *
**************************
";

clean_up_message(message)
// => BUY NOW, SAVE 10%
```
