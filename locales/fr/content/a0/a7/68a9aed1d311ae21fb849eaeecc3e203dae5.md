# Indices

## 1. Découpe une _string_ en lignes individuelles

- Swift dispose d'une [méthode][nsstring-components-docs] pour découper une _string_ en un tableau de _strings_ à l'aide d'un séparateur fourni.

## 2. Porte de devant

- Le gardien va réciter un poème, et tu devras découper ce poème en lignes individuelles ; pour cela, tu peux utiliser une fonction qui existe déjà.
- Tu peux utiliser une boucle `for` pour parcourir les lignes du poème.
- Tu peux utiliser la propriété `first` d'une _string_ pour obtenir le premier caractère d'une _string_.
- Pour stocker le premier caractère de chaque ligne, tu peux utiliser un tableau de caractères ou une _string_.

## 3. Porte de derrière

- Le gardien va réciter un poème, et tu devras découper ce poème en lignes individuelles ; pour cela, tu peux utiliser une fonction qui existe déjà.
- Tu peux utiliser une boucle `for` pour parcourir les lignes du poème.
- Tu peux utiliser la propriété `last` d'une _string_ pour obtenir le dernier caractère d'une _string_.
- Pour stocker le dernier caractère de chaque ligne, tu peux utiliser un tableau de caractères ou une _string_.

## 4. Salle secrète

- Le gardien va réciter un poème, et tu devras découper ce poème en lignes individuelles ; pour cela, tu peux utiliser une fonction qui existe déjà.
- Tu peux utiliser une boucle `for` qui itère sur la longueur des lignes du poème.
- Swift dispose d'une [méthode][indexing] pour obtenir le caractère situé à un indice précis dans une _string_.
- Swift dispose d'une [méthode][uppercased] pour convertir une _string_ en majuscules.
