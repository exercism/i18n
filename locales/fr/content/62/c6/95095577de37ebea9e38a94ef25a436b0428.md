# Introduction

## Ajusteurs temporels

Lorsque tu travailles avec des objets `java.time` comme `LocalDate`, il faut souvent effectuer des ajustements de date complexes, par exemple trouver le « deuxième mardi du mois ».
Plutôt que de calculer cela à la main, on peut utiliser **`TemporalAdjusters`**.

La classe utilitaire `java.time.temporal.TemporalAdjusters` (attention au « s » du pluriel) fournit des méthodes statiques pour de nombreux ajustements de date courants.
On applique ces ajustements avec la méthode `.with()` sur un objet temporel (comme `LocalDate`).

```exercism/note
Utiliser `with(TemporalAdjuster)` renvoie une _nouvelle_ instance et ne met pas à jour l'instance existante, car les objets `java.time` sont immuables.
```

```java
import java.time.LocalDate;
import java.time.Month;
import java.time.DayOfWeek;
import java.time.temporal.TemporalAdjusters;

LocalDate date = LocalDate.of(2024, Month.AUGUST, 15); // 2024-08-15 (a Thursday)

// Use a predefined adjuster: find the last day of the month
LocalDate lastDay = date.with(TemporalAdjusters.lastDayOfMonth());
// => 2024-08-31
```

Voici quelques ajusteurs essentiels, bien utiles pour les calculs de planification :

### Trouver un jour de la semaine par son rang

Utilise `dayOfWeekInMonth(int ordinal, DayOfWeek dayOfWeek)` pour trouver la n-ième occurrence d'un jour de la semaine.

```java
// Find the second Tuesday of August 2024
LocalDate secondTuesday = date.with(TemporalAdjusters.dayOfWeekInMonth(2, DayOfWeek.TUESDAY));
// => 2024-08-13
```

### Trouver le premier ou le dernier jour de la semaine dans le mois

Utilise `firstInMonth(DayOfWeek dayOfWeek)` ou `lastInMonth(DayOfWeek dayOfWeek)`.

```java
// Find the last Monday of August 2024
LocalDate lastMonday = date.with(TemporalAdjusters.lastInMonth(DayOfWeek.MONDAY));
// => 2024-08-26
```

### Ajustements relatifs (suivant/précédent)

Des ajusteurs comme `next()`, `previous()`, `nextOrSame()` et `previousOrSame()` trouvent l'occurrence suivante ou précédente d'un jour de la semaine donné, par rapport à la date courante.

- `next()`/`previous()` : excluent la date courante si elle correspond.
- `nextOrSame()`/`previousOrSame()` : incluent la date courante si elle correspond.

```java
LocalDate thursday = LocalDate.of(2024, Month.AUGUST, 15); // A Thursday

// Find the next Thursday (exclusive)
LocalDate nextThursday = thursday.with(TemporalAdjusters.next(DayOfWeek.THURSDAY));
// => 2024-08-22

// Find the next Thursday (inclusive) - returns the same date
LocalDate nextOrSameThursday = thursday.with(TemporalAdjusters.nextOrSame(DayOfWeek.THURSDAY));
// => 2024-08-15

// Find the previous Monday (exclusive)
LocalDate previousMonday = thursday.with(TemporalAdjusters.previous(DayOfWeek.MONDAY));
// => 2024-08-12
```

### Ajusteurs personnalisés

`TemporalAdjuster` est une interface fonctionnelle : tu peux donc écrire ton propre ajusteur sous forme de lambda, qui prend l'objet temporel à ajuster et renvoie l'objet ajusté.
Il s'applique avec `.with()`, exactement comme les ajusteurs prédéfinis, et il peut les utiliser en interne.

```java
import java.time.temporal.TemporalAdjuster;

// An adjuster that moves a weekend date to the following Monday
TemporalAdjuster skipWeekend = temporal -> {
    DayOfWeek day = DayOfWeek.from(temporal);
    if (day == DayOfWeek.SATURDAY || day == DayOfWeek.SUNDAY) {
        return temporal.with(TemporalAdjusters.next(DayOfWeek.MONDAY));
    }
    return temporal;
};

LocalDate saturday = LocalDate.of(2024, Month.AUGUST, 17);
LocalDate monday = saturday.with(skipWeekend);
// => 2024-08-19
```

Utiliser ces ajusteurs de la classe `TemporalAdjusters` simplifie énormément les tâches de manipulation de dates.
