# Introduction

## L'aléatoire

On peut utiliser une instance de la classe `java.util.Random` pour générer des nombres aléatoires en Java.

### Nombres entiers aléatoires

On peut générer un nombre entier aléatoire avec la méthode `nextInt()`.
Elle génère une valeur dans l'intervalle allant de `Integer.MIN_VALUE` à `Integer.MAX_VALUE`.

```java
Random random = new Random();

random.nextInt();
// => -1169335537
```

Pour limiter l'intervalle des valeurs générées, utilise `nextInt(int)`.
Elle génère une valeur comprise entre `0` (inclus) et la borne supérieure donnée (exclue).

Par exemple, ceci génère un nombre aléatoire de `0` à `9`.

```java
Random random = new Random();

random.nextInt(10);
// => 6
```

Et ceci génère un nombre aléatoire de `10` à `19`.

```java
Random random = new Random();

10 + random.nextInt(10);
// => 11
```

### Nombres décimaux aléatoires

On peut générer un nombre décimal aléatoire avec la méthode `nextDouble()`.
Elle génère une valeur comprise entre `0.0` et `1.0`.

```java
Random random = new Random();

random.nextDouble();
// => 0.19250004204021398
```

Et ceci génère un nombre aléatoire de `100.0` à `200.0`.

```java
Random random = new Random();

100.0 + 100.0 * random.nextDouble();
// => 111.31849856260328
```
