# Instructions

Dans cet exercice, tu vas implémenter un ensemble partiel de routines utilitaires pour aider un développeur à nettoyer des noms d'identifiants.
Au fil des 5 tâches, tu vas construire progressivement la routine `Clean`.
Un identifiant valide est composé de zéro ou plusieurs lettres et tirets bas.
Dans tous les cas, la _string_ en entrée est garantie non nulle.
Si une _string_ vide est passée à la fonction `Clean`, une _string_ vide doit être renvoyée.
Note que l'appelant doit éviter d'appeler la routine `Clean` avec un identifiant vide, car de tels identifiants sont sans effet.

## 1. Remplace les espaces rencontrés par des tirets bas

Implémente la méthode (_static_) `Identifier.Clean()` pour remplacer les espaces par des tirets bas.
Cela vaut aussi pour les espaces de début et de fin.

```csharp
Identifier.Clean("my   Id");
// => "my___Id"
```

## 2. Remplace les caractères de contrôle par la _string_ en majuscules "CTRL"

Modifie la méthode (_static_) `Identifier.Clean()` pour remplacer les caractères de contrôle par la _string_ en majuscules `"CTRL"`.

```csharp
Identifier.Clean("my\0Id");
// => "myCTRLId",
```

## 3. Convertis le kebab-case en camelCase

Modifie la méthode (_static_) `Identifier.Clean()` pour convertir le kebab-case en camelCase.

```csharp
Identifier.Clean("à-ḃç");
// => "àḂç"
```

## 4. Omets les caractères qui ne sont pas des lettres

Modifie la méthode (_static_) `Identifier.Clean()` pour omettre les caractères qui ne sont pas des lettres.

```csharp
Identifier.Clean("1😀2😀3😀");
// => ""
```

## 5. Omets les lettres grecques en minuscules

Modifie la méthode (_static_) `Identifier.Clean()` pour omettre les lettres grecques comprises entre 'α' et 'ω'.

```csharp
Identifier.Clean("MyΟβιεγτFinder");
// => "MyΟFinder"
```
