# Indices

## Général

- Ce tutoriel constitue une bonne introduction aux _strings_ C++.
- La classe `std::basic_string` dispose de nombreuses [méthodes intégrées][cpp-reference-string] très utiles.

## 1. Récupère le message d'une ligne de log

- Les méthodes intégrées offrent plusieurs façons de [rechercher][cpp-reference-string-find] du texte dans une _string_.
- Les méthodes intégrées peuvent nous aider à [extraire une partie][cpp-reference-string-substr] d'une _string_

## 2. Récupère le niveau de log d'une ligne de log

Il existe plusieurs façons de concaténer des _strings_, la plus simple étant d'utiliser [l'opérateur `+`][cpp-reference-string-concatenation], mais il existe aussi des [façons plus avancées][cpp-reference-printf].
