# Indices

## Général

- `throw` se trouve dans [`kernel`][kernel] ; `recover` se trouve dans [`continuations`][continuations].

## 1. Vérifie l'humidité

- Compare avec `>`, puis exécute `[ "humidity too high" throw ] when` pour déclencher l'erreur uniquement dans le cas problématique.

## 2. Vérifie la température

- Même structure que la tâche 1, avec `500` et un message différent.

## 3. Définis une erreur personnalisée

- `ERROR: machine-error ;` déclare la classe *et* un mot constructeur qui lève une nouvelle instance.

## 4. Surveille la machine

- Enveloppe chaque vérification dans `[ check-… ] [ drop machine-error ] recover`. La _quotation_ de récupération supprime l'erreur d'origine et lève une nouvelle `machine-error`, ce qui préserve la sémantique du « échec de l'un ou de l'autre » tout en masquant l'identité de l'exception d'origine.
- `bi*` de [`kernel`][kernel] applique une _quotation_ à chaque entrée.

[kernel]: https://docs.factorcode.org/content/vocab-kernel.html
[continuations]: https://docs.factorcode.org/content/vocab-continuations.html
