# Instructions

Dans cet exercice, on joue à un jeu de devinettes avec un ami. Les règles sont simples : tu choisis secrètement un nombre entre `1` et `100`, et ton ami essaie de deviner le nombre que tu as choisi. Pour aider ton ami, tu réponds différemment selon la proximité entre sa proposition et le nombre que tu as choisi (`42`). Voici les règles pour les différentes réponses :

- Si la proposition est `42` : « Correct »
- Si la proposition est `41` ou `43` : « So close »
- Si la proposition est inférieure à `41` : « Too low »
- Si la proposition est supérieure à `43` : « Too high »

Quatre tâches t'attendent pour coder les réponses aux propositions.

## 1. Réponds à une proposition correcte

Implémente la fonction `reply` pour répondre à une proposition correcte :

```fsharp
reply 42
// => "Correct"
```

## 2. Réponds à une proposition proche

Modifie la fonction `reply` pour répondre aux propositions proches :

```fsharp
reply 41
// => "So close"
```

## 3. Réponds aux propositions trop basses

Modifie la fonction `reply` pour répondre aux propositions trop basses :

```fsharp
reply 25
// => "Too low"
```

## 4. Réponds aux propositions trop hautes

Modifie la fonction `reply` pour répondre aux propositions trop hautes :

```fsharp
reply 88
// => "Too high"
```
