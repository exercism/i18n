# Indications

## 1. Vérifie si la nourriture est correcte

- Tu peux utiliser une instruction [`if`][if] pour vérifier si la nourriture est correcte.

## 2. Vérifie si la boisson est empoisonnée

- Il existe [une méthode][downcase] pour convertir une _string_ en minuscules.
- Tu peux vérifier si une _string_ contient un caractère précis en utilisant [`String#includes?`][includes?].

## 3. Remplace la boisson

- Tu peux utiliser des méthodes déjà implémentées pour vérifier si la boisson est empoisonnée.
- Il existe [un opérateur][or] qui permet de renvoyer la première valeur vraie.

[or]: https://crystal-lang.org/reference/latest/syntax_and_semantics/or.html
