# Instructions

Tu tiens un guide de terrain : une correspondance entre le nom d'un animal et l'habitat dans lequel il vit.

Les cinq tâches se font dans la classe `FIELD_GUIDE`.

## 1. Est-il dans le guide ?

```sather
FIELD_GUIDE::is_listed(guide, "emu")
-- => true
```

## 2. Où vit-il ?

Renvoie l'habitat enregistré pour un animal. Si le guide n'en a jamais entendu parler, renvoie `"Unknown"`.

```sather
FIELD_GUIDE::habitat_of(guide, "emu")
-- => "grassland"
FIELD_GUIDE::habitat_of(guide, "moa")
-- => "Unknown"
```

## 3. Ajoute une entrée

Renvoie le guide avec un animal de plus. Si un animal y figure déjà, son habitat est remplacé.

```sather
FIELD_GUIDE::add_entry(guide, "wombat", "forest")
-- => the guide, now with wombat in it
```

Ce que cette fonction renvoie devient le guide à utiliser par la suite. Ajouter à un guide complètement vide fonctionne et donne un guide contenant un seul animal.

## 4. Combien d'animaux ?

```sather
FIELD_GUIDE::entry_count(guide)
-- => 3
```

## 5. Quels habitats ?

Renvoie l'ensemble des habitats mentionnés dans le guide. Plusieurs animaux peuvent partager un même habitat, qui ne doit apparaître qu'une seule fois.

```sather
FIELD_GUIDE::all_habitats(guide)
-- => a set holding "grassland" and "forest"
```
