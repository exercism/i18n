# Introduction

## Valeurs par défaut des paramètres

Des [valeurs par défaut de paramètres][default-parameter-values] peuvent être fournies pour n'importe quel paramètre d'une fonction, en affectant une valeur au paramètre dans la liste des paramètres, après l'annotation de type du paramètre. Lorsqu'une valeur par défaut est spécifiée pour un paramètre, l'appelant de la fonction peut omettre ce paramètre lors de l'appel, et la valeur par défaut est utilisée à la place.

```swift
func greeting(name: String = "guest", duration: Int = 2) -> String {
  "Welcome, \(name). Enjoy your \(duration) night stay."
}

greeting(name: "Bobo", duration: 7)
// Returns "Welcome, Bobo. Enjoy your 7 night stay."
greeting(duration: 3)
// Returns "Welcome, guest. Enjoy your 3 night stay."
greeting(name: "Wynona")
// Returns "Welcome, Wynona. Enjoy your 2 night stay."
greeting()
// Returns "Welcome, guest. Enjoy your 2 night stay."
```

## Paramètres variadiques

Les [_paramètres variadiques_][variadic-parameters] en Swift permettent de passer zéro ou plusieurs valeurs du même type dans un seul paramètre d'une fonction. On l'indique en ajoutant `...` à l'annotation de type du paramètre.

Ces valeurs sont automatiquement regroupées dans un tableau dont les éléments ont le même type que le paramètre variadique.

```swift
func geometricMean(_ numbers: Double...) -> Double {
  var total = 1.0
  for number in numbers {
      total *= number
  }
  return pow(total, 1.0 / Double(numbers.count))
}

geometricMean(1, 2, 3, 4, 5)
// => 2.605171084697352
```

À noter que les paramètres variadiques présentent une limite en Swift.
Si une fonction prend, dans sa définition, des paramètres qui suivent le paramètre variadique, le premier paramètre qui suit le paramètre variadique _doit_ avoir une étiquette d'argument.

## Paramètres in-out

Dans le corps d'une fonction, les paramètres sont traités comme des constantes, et non comme des variables ; toute tentative de modifier la valeur d'un paramètre provoque une erreur de compilation.
Si une fonction souhaite modifier la valeur d'un paramètre, elle doit utiliser un [_paramètre in-out_][in-out-parameters] pour rendre cette mutabilité explicite.

Pour utiliser des paramètres in-out, il faut être sûr de trois choses :

1. La définition de la fonction doit marquer explicitement les paramètres in-out en écrivant le mot-clé `inout` entre le `:` et le nom du type dans l'annotation de type du paramètre.
2. La valeur passée au paramètre in-out doit être déclarée comme une variable, et non comme une constante. De même, elle ne peut pas être un littéral.
3. Le nom de la variable doit être précédé d'un `&` dans l'appel à la fonction, ce qui indique explicitement qu'elle est modifiable.

Une fois cela fait, la fonction crée une copie interne du paramètre in-out, la modifie comme indiqué dans le corps de la fonction, puis recopie la valeur modifiée dans la variable passée en argument lorsque la fonction se termine.

```swift
func updateVersion(_ record: inout (version: Int, title: String)) {
  record.version += 1
}

var dbRecord = (version: 2, title: "Exercism")
updateVersion(&dbRecord)

// dbRecord is now (3, "Exercism")
```

~~~~exercism/warning
Il y a quelques règles supplémentaires à connaître concernant les paramètres in-out.

1. Dans une fonction qui prend des paramètres in-out, il est interdit de référencer la variable passée en argument comme paramètre in-out.
2. La même variable ne peut pas être passée comme plusieurs paramètres in-out dans la même fonction.
   Par exemple, `inoutFunc(&mutVar, &mutVar)` provoque une erreur du compilateur.
~~~~

## Fonctions imbriquées

On peut définir des fonctions [à l'intérieur d'autres fonctions][nested-functions].
On y a souvent recours pour créer des fonctions utilitaires qui ne servent qu'à la fonction qui les contient et n'ont donc pas besoin de polluer l'espace de noms extérieur.

Ces fonctions se définissent et s'appellent comme des fonctions normales, mais ne sont pas visibles à l'extérieur de la fonction qui les contient.

```swift
func makeNumber(_ number: Int) -> Int {
  func double(_ x: Int) -> Int { 2 * x }
  func add(_ x: Int) -> Int { x + 1 }

  return number.isMultiple(of: 2) ? add(double(number)) : double(number)
}

makeNumber(3)
// Returns 6
makeNumber(4)
// Returns 9
```
