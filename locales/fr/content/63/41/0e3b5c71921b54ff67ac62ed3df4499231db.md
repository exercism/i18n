# Instructions

Dans cet exercice, on va traiter des lignes de _log_.

Chaque ligne de _log_ est une _string_ formatée comme suit : `"[<LEVEL>]: <MESSAGE>"`.

Il existe trois niveaux de _log_ différents :

- `INFO`
- `WARNING`
- `ERROR`

Tu as trois tâches, et chacune prend une ligne de _log_ et te demande d'en faire quelque chose.

Tu es libre d'utiliser soit les fonctions historiques de base R, soit la bibliothèque `stringr`, et les deux permettent d'écrire des solutions courtes et viables.

## 1. Récupère le message d'une ligne de _log_

Implémente la fonction `message` pour renvoyer le message d'une ligne de _log_ :

```R
message("[ERROR]: Invalid operation")
#> "Invalid operation"
```

Les espaces en début et en fin doivent être supprimés :

```R
message("[WARNING]:  Disk almost full\r\n")
#> "Disk almost full"
```

## 2. Récupère le niveau de _log_ d'une ligne de _log_

Implémente la fonction `log_level` qui renvoie le niveau de _log_ d'une ligne de _log_, en minuscules :

```R
log_level("[ERROR]: Invalid operation")
#> "error"
```

## 3. Reformate une ligne de _log_

Implémente la fonction `reformat` qui reformate la ligne de _log_, en plaçant le message en premier et le niveau de _log_ après, entre parenthèses :

```R
reformat("[INFO]: Operation completed")
#> "Operation completed (info)"
```
