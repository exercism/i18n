# Booléens

Certaines questions n'ont que deux réponses : oui ou non. Le type de Sather pour une telle réponse est `BOOL`, et les deux réponses s'écrivent `true` et `false`.

```sather
   ready : BOOL is
      return true;
   end;
```

## Comparer

Comparer deux nombres donne un `BOOL`.

| Opérateur | Question posée |
| --- | --- |
| `=` | sont-ils identiques ? |
| `/=` | sont-ils différents ? |
| `<` | celui de gauche est-il plus petit ? |
| `<=` | plus petit, ou identique ? |
| `>` | celui de gauche est-il plus grand ? |
| `>=` | plus grand, ou identique ? |

```sather
   old_enough(age : INT) : BOOL is
      return age >= 13;
   end;
```

Remarque que `=` pose une question. Mettre une valeur *dans* quelque chose, c'est `:=`, que tu as déjà vu, et les deux ne sont pas la même chose.

## Combiner

Trois opérateurs construisent des questions plus grandes à partir de questions plus petites.

`and` vaut true quand **les deux** côtés sont true.

```sather
harness_on and rope_checked
```

`or` vaut true quand **l'un ou l'autre** des côtés est true, ou les deux.

```sather
mat_below or net_below
```

`~` inverse une réponse : il transforme true en false et false en true.

```sather
~ready       -- true exactly when ready is false
```

`and` et `or` se placent entre deux réponses ; `~` se place devant une seule.
