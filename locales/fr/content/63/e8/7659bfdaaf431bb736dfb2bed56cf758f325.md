# Instructions

Dans cet exercice, tu dois traduire quelques règles du jeu classique Pac-Man en fonctions Haskell.

Tu as quatre règles à traduire, toutes liées aux états du jeu.

> Ne t'inquiète pas de la façon dont les arguments sont dérivés, concentre-toi simplement sur la combinaison des arguments pour renvoyer le résultat attendu.

## 1. Définis si Pac-Man mange un fantôme

Définis la fonction `eatsGhost` qui prend deux arguments (_si Pac-Man a une super pastille active_ et _si Pac-Man touche un fantôme_) et renvoie une valeur `Bool` quand Pac-Man est capable de manger le fantôme.
La fonction ne doit renvoyer `True` que lorsque Pac-Man a une super pastille active et touche un fantôme.

```haskell
eatsGhost False True
-- -> False
```

## 2. Définis si Pac-Man marque des points

Définis la fonction `scores` qui prend deux arguments (_si Pac-Man touche une super pastille_ et _si Pac-Man touche un point_) et renvoie une valeur `Bool` si Pac-Man a marqué.
La fonction doit renvoyer `True` lorsque Pac-Man touche une super pastille ou un point.

```haskell
scores True True
-- -> True
```

## 3. Définis si Pac-Man perd

Définis la fonction `loses` qui prend deux arguments (_si Pac-Man a une super pastille active_ et _si Pac-Man touche un fantôme_) et renvoie une valeur `Bool` si Pac-Man perd.
La fonction doit renvoyer `True` lorsque Pac-Man touche un fantôme et n'a pas de super pastille active.

```haskell
loses False True
-- -> True
```

## 4. Définis si Pac-Man gagne

Définis la fonction `wins` qui prend trois arguments (_si Pac-Man a mangé tous les points_, _si Pac-Man a une super pastille active_ et _si Pac-Man touche un fantôme_) et renvoie une valeur `Bool` si Pac-Man gagne.
La fonction doit renvoyer `True` lorsque Pac-Man a mangé tous les points _et_ n'a pas perdu d'après les arguments définis dans la partie 3.

```haskell
wins False True False
-- -> False
```
