# Instructions

Ton ami vient de t'envoyer un message contenant un important secret. Pour ne pas en rendre la lecture facile aux autres, le message a été chiffré au moyen d'une série de manipulations de bits. Tu vas devoir écrire les mots qui aident à déchiffrer le message.

## 1. Décale les bits vers la droite

La première étape du déchiffrement consiste à annuler le décalage effectué lors du chiffrement en décalant les bits vers la droite. Les étapes suivantes supposent que des zéros sont insérés par la gauche.

Définis `shift-back` qui prend une valeur de 32 bits et une quantité, et qui renvoie la valeur décalée vers la droite de cette quantité, avec un remplissage par des zéros.

```factor
0b1001 2 shift-back .
! => 0b0010
```

## 2. Mets à 1 certains bits

Ensuite, certains bits doivent être mis à 1.

Définis `set-bits` qui prend une valeur et un masque. Chaque bit de `value` dont le bit correspondant de `mask` vaut 1 doit être mis à 1 ; tous les autres bits restent inchangés.

```factor
0b0110 0b0101 set-bits .
! => 0b0111
```

## 3. Inverse des bits précis

Certains bits sont inversés pendant le chiffrement. Il faudra les inverser à nouveau pour déchiffrer le message.

Définis `flip-bits` qui prend une valeur et un masque. Chaque bit de `value` dont le bit correspondant de `mask` vaut 1 doit être inversé ; tous les autres bits restent inchangés.

```factor
0b1100 0b0101 flip-bits .
! => 0b1001
```

## 4. Efface des bits précis

Enfin, certains bits valent toujours 0 après le déchiffrement.

Définis `clear-bits` qui prend une valeur et un masque. Chaque bit de `value` dont le bit correspondant de `mask` vaut 1 doit être mis à 0 ; tous les autres bits restent inchangés.

```factor
0b0110 0b0101 clear-bits .
! => 0b0010
```
