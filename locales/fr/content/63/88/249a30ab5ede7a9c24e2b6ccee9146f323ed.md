# Introduction

Disponibles depuis `PHP 8.0.0`, les **déclarations de type union** acceptent des valeurs de plusieurs types différents, plutôt que d'un seul type. On définit un type union à l'aide de la barre verticale (`|`), qui sépare les types.

```php
function add(int|float $a, int|float $b): int|float
{
    return $a + $b;
}
```

PHP lève une `TypeError` en mode strict si les paramètres passés ne sont ni un `float` ni un `int`. En mode non strict, une erreur de type est levée si les paramètres passés ne peuvent pas être convertis en `float` ou en `int`.

De même, si la fonction ne renvoie pas l'un des types déclarés, PHP lève une `TypeError` à l'exécution.
