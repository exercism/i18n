# Indices

## Général

- Le vocabulaire `locals` fournit `::` et `[| | ]`.
- Les variables locales ne remplacent pas le code de pile : utilise-les là où elles apportent de la clarté.

## 1. Détermine l'état de cuisson

- `cond` de [`combinators`][combinators] est la bonne structure : une branche vérifie `dup not` (le minuteur vaut `f`), une autre vérifie `dup zero?`, et une branche par défaut gère le reste. Chaque branche doit faire `drop` sur le minuteur avant d'empiler la chaîne.

## 2. Estime le temps de préparation

- `:: preparation-time ( layers minutes-per-layer -- total )` avec `layers length minutes-per-layer *`.

## 3. Calcule les nouilles et la sauce nécessaires

- Les variables locales te permettent de faire référence à `layers` deux fois sans `dup`. `count` avec le prédicat `[ "noodles" = ]` (ou `"sauce" =`) te donne le nombre de couches pour chacun.
- `1/5` est un littéral rationnel de Factor.

## 4. Ajoute l'ingrédient secret

- `last` (dans [`sequences`][sequences]) lit le dernier élément ; `suffix` en ajoute un à la fin.

## 5. Adapte les quantités de la recette

- Le facteur d'échelle est `portions / 2`. Les variables locales te permettent de référencer `portions` à l'intérieur de la lambda.
- `assoc-map` de [`assocs`][assocs] prend une _quotation_ `( key value -- newkey newvalue )`. À l'intérieur de `[| key value | … ]`, renvoie les deux valeurs pour conserver la même clé et produire une nouvelle valeur.
