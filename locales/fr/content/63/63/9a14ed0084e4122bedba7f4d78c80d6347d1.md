# Les bases de la syntaxe Elm 2

## Exporte des fonctions

On a déjà vu comment exporter des fonctions dans le premier concept ; voici un petit rappel.

Chaque fichier en Elm est un module et doit contenir une instruction `module` avant tout autre code.

Les noms de module doivent correspondre au nom de leur fichier : le module `Calculator` doit donc se trouver dans le fichier Calculator.elm, et le module `Parser.Utils` doit se trouver dans le fichier Parser/Utils.elm.

Tout ce qui est défini dans un module a une portée privée et n'est pas accessible depuis l'extérieur de ce module, sauf si on le liste dans `exposing`.

```elm
-- Calculator.elm
-- Define the Calculator module, and expose the `add` function
module Calculator exposing (add)

six = 3 + 3

add number1 number2 = number1 + number2
```

```elm
-- Calculator.elm
-- Define the Calculator module, and expose everything within: `six` and `add`
module Calculator exposing (..)

six = 3 + 3

add number1 number2 = number1 + number2
```

https://elm-lang.org/docs/syntax#modules

## Importe des fonctions depuis d'autres modules

Pour accéder aux fonctions définies dans d'autres modules, on passe par des imports.
Toutes les fonctions de ce module qui ont été exposées par celui-ci deviennent accessibles quand on importe ce module.
Mais la façon d'y accéder dépend de la manière dont le module est importé.

Les imports qualifiés sont le comportement par défaut, et pour accéder à une fonction d'un tel module (par exemple la fonction `map` du module `List`), on préfixe le nom du module (`List.map`).

Les imports ouverts permettent d'accéder directement aux fonctions exposées de ce module, sans préfixe. On les fait avec le mot-clé `exposing`, en miroir de celui utilisé pour les exports. Tu peux exposer toutes les fonctions disponibles (avec `..`), ou seulement certaines (par exemple `map`).

Tu peux aussi importer des types et leurs constructeurs depuis d'autres modules, mais c'est un concept que l'on verra plus tard.

Les imports qualifiés sont préférés, car ils clarifient le code et évitent les conflits de noms.

```elm
-- qualified imports
import List                            -- List.map, List.foldl
import List as L                       -- L.map, L.foldl

-- open imports
import List exposing (..)              -- map, foldl, concat, ...
import List exposing ( map, foldl )    -- map, foldl, List.concat
```

https://elm-lang.org/docs/syntax#modules

## Annotations de type

Une annotation de type s'écrit `name : parameter types -> return type`, les types des paramètres étant eux aussi séparés par `->`.

```elm
add : Int -> Int -> Int
add number1 number2 = number1 + number2
```

On peut utiliser des parenthèses pour définir les paramètres d'une fonction (ces paramètres étant eux-mêmes définis avec la même syntaxe, d'où la nécessité de ces parenthèses).

```elm
-- Transform every character in a string
map : (Char -> Char) -> String -> String
map charMapperFunction string =
    -- ...
```

https://elm-lang.org/docs/syntax#type-annotations

## Nombres

Elm propose deux types de nombres, définis par les types `Int` et `Float`.
`Int` correspond à l'ensemble des entiers positifs et négatifs.
`Float` correspond à l'ensemble des nombres réels, limité par la précision de l'ordinateur.
Les opérations définies sur les nombres fonctionnent généralement sur l'un ou l'autre des types, mais pas sur un mélange des deux.
Il existe des fonctions pour convertir l'un en l'autre, comme `toFloat`, qui convertit un `Int` en `Float`, et `round`, `floor`, `ceiling` ou `truncate`, qui convertissent un `Float` en `Int` avec des sémantiques différentes.

https://package.elm-lang.org/packages/elm/core/latest/Basics#Int

## Opérations sur les _strings_

Pour décrire des mots et des phrases dans le code, Elm dispose d'un type `String` natif.
Les littéraux de _string_ s'écrivent entre guillemets doubles, par exemple `"Hello World!"`.
Un opérateur de concaténation de _strings_ `++` et un opérateur d'égalité `==` sont disponibles par défaut.

```elm
hello : String -> String
hello subject = "Hello " ++ subject

hello "World!" --> "Hello World!"
```

La plupart des autres fonctions sur les _strings_ se trouvent dans le module `String`, qu'il faut importer.

https://package.elm-lang.org/packages/elm/core/latest/String
