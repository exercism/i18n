# Introduction

Le type `Result` permet à une fonction de renvoyer une seule valeur qui indique tous les éléments suivants :
- Si l'opération a réussi ou échoué
- En cas de réussite, la valeur résultante de l'opération
- En cas d'échec, la raison de l'échec

## Utilisation

Le type `Result` est un type générique qui contient deux types sous-jacents :
- Le type de la valeur résultante en cas de réussite de l'opération
- Le type d'erreur en cas d'échec

Le type `Result` est aussi une [union discriminée][discriminated-union] avec les cas possibles suivants :
* `Ok <value>` qui représente un résultat réussi
* `Error <reason>` qui représente un échec

La fonction suivante montre comment créer une valeur de type `Result` :

```fsharp
let validateName (name: string) : Result<string, string> = 
    match name with
    | null -> Error "Name not found."
    | "" -> Error "Name is empty."
    | _ -> Ok name
```

Dans cet exemple, la valeur `Ok` est une _string_ (le nom donné), et la valeur `Error` est aussi une _string_ (la cause de l'erreur, sous une forme lisible par un humain).

## Lis le contenu d'une valeur `Result`

Prenons la définition de type et la signature de fonction suivantes :

```
type FileOpenError = 
| NotFound
| AccessDenied
| FileLocked

let openFile (filename: string) : Result<int, FileOpenError> =
```

Le code qui appelle la fonction `openFile` peut recourir au filtrage par motif pour gérer les cas de réussite et d'échec, comme dans l'exemple suivant :

```fsharp
match openFile(filename) with
| Ok handle -> doSomethingWithFile(handle)
| Error NotFound -> printfn $"Error: file {filename} was not found."
| Error AccessDenied -> printfn $"Error: you do not have permission to open the file {filename}."
| Error FileLocked -> printfn $"Error: file {filename} is already in use."
```
