# Intervalles

[Les intervalles][range] représentent une plage de valeurs comprise entre deux bornes.
Les types les plus courants qui prennent en charge les intervalles sont `Int`, `String` et `Date`.
On peut les utiliser pour beaucoup de choses : créer rapidement une collection, découper un tableau, vérifier si une valeur se trouve dans un intervalle, ou encore itérer.
On les crée à l'aide de l'opérateur d'intervalle `...` ou `..<` (respectivement inclusif et exclusif).

```swift
1...5 // A range containing 1, 2, 3, 4, 5
1..<5 // A range containing 1, 2, 3, 4
```

La raison d'avoir deux opérateurs d'intervalle est de pouvoir créer des intervalles qui incluent ou excluent la valeur de fin, ce qui peut être utile quand on travaille par exemple avec des indices qui commencent à zéro.

~~~~exercism/note
Quand on crée un intervalle en Swift à l'aide des opérateurs d'intervalle `...` ou `..<`, et que l'on veut appeler une méthode sur cet intervalle, il faut entourer l'intervalle de parenthèses.
Sinon, la méthode sera appelée sur le 2e argument de l'opérateur d'intervalle.

```swift
(1...5).contains(3) // Returns true
1...5.contains(3) // => Error: value of type 'Int' has no member 'contains'
```
~~~~

## Convertis un intervalle en tableau

Pour convertir un intervalle en tableau, on peut utiliser l'initialiseur `Array`.
C'est utile quand on veut créer une collection de valeurs sans avoir à les écrire une par une.

```swift
let range = 1...5
let array = Array(range)
// Returns [1, 2, 3, 4, 5]
```

## Découpe un tableau

On peut utiliser les intervalles pour découper un tableau.

```swift
let array = [1, 2, 3, 4, 5]
// Returns [1, 2, 3, 4, 5]
let slice = array[1...3]
// Returns [2, 3, 4]
```

## Méthodes des intervalles

Les intervalles disposent d'un ensemble de méthodes pour travailler avec eux.
Par exemple, ces méthodes permettent d'obtenir la somme de toutes les valeurs de l'intervalle ou de vérifier si l'intervalle contient une valeur.

| Méthode                | Description                                                             | Exemple                               |
| ---------------------- | ----------------------------------------------------------------------- | ------------------------------------- |
| `count`                | Renvoie la taille de l'intervalle                                       | `(1...5).count // returns 5`          |
| [`contains`][contains] | Renvoie `true` si l'intervalle contient la valeur donnée, sinon `false` | `(1...5).contains(3) // Returns true` |

## Intervalles sans fin et sans début

Un intervalle peut être sans fin et sans début.

Les intervalles sans fin et sans début sont utiles quand on veut, par exemple, découper un tableau depuis le début ou jusqu'à la fin.

~~~~exercism/caution
Un intervalle sans fin peut produire une séquence sans fin si on ne l'utilise pas avec précaution sur une collection.
~~~~

## Intervalles de _strings_

On peut utiliser des _strings_ dans les intervalles, ce qui permet d'obtenir un intervalle de _strings_ entre deux _strings_.
Par exemple, c'est pratique quand on veut obtenir l'alphabet.

```swift
"a"..."z" // A range containing ["a", "b", "c", ..., "z"]
```
