# Tests

## Lance les tests

Une fois les [étapes d’installation][test-installation-steps] terminées, tu devrais pouvoir partir de n’importe quel répertoire d’exercice (par exemple `~/exercism/gdscript/two-fer`) et lancer le script (qui se trouve un niveau au-dessus, dans `../`) pour tester ta solution locale à cet exercice :

```sh
../test-local-gdscript-solution.sh
```

## Résous un exercice

Résoudre un exercice consiste à faire passer tous ses tests.

Pour t’aider à démarrer, chaque exercice est accompagné d’un fichier GDScript portant le nom de l’exercice (par exemple `exercism/gdscript/two-fer/two_fer.gd`).
Tu peux utiliser ce fichier comme point de départ pour construire ta solution.
N’hésite pas à le modifier selon tes besoins, mais les tests exigent que les noms des fonctions soient ceux fournis au départ.

[test-installation-steps]: https://exercism.org/docs/tracks/gdscript/tests
