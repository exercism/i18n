# Ajout aux instructions

## Exemple d'entrée

```j
  INPUTS=: 2 ; 1 0 0 1 0 1 ; 10
```

Cela signifie que tes entrées sont :
```
  0{INPUTS NB. is the input base.
  1{INPUTS NB. is the digits.
  2{INPUTS NB. is the output base.
```
## Gestion des entrées invalides

Si l'une des valeurs d'entrée est invalide, ton verbe doit renvoyer soit un `empty` (par exemple, `0$0` ou `''`).

### Exemples

- Si la _base d'entrée_ est inférieure à 2 :
    ```j
      '' -: rebase 10 ; 0 0 0 0 ; 1
    ```

- Si la _base de sortie_ est inférieure à 2 :
    ```j
      '' -: rebase 1 ; 0 0 0 0 ; _7
    ```

- Si les _chiffres_ contiennent des valeurs supérieures ou égales à la base d'entrée :
    ```j
      '' -: rebase 10 ; 1 0 2 0 ; 2
    ```
