# Instructions

Tu vas aider des amoureux de lycée à déclarer leur flamme sur les réseaux sociaux en générant un cœur Unicode avec leurs initiales :

```
❤ J.  +  M. ❤
```

## 1. Nettoie le nom

Définis `cleanupname`, qui prend un nom sur la pile. Remplace chaque `-` par un espace, puis supprime les espaces au début et à la fin.

```factor
"Jane-Ann" cleanupname .
! => "Jane Ann"
```

## 2. Récupère la première lettre du nom

Définis `firstletter`, qui prend un nom. Réutilise `cleanupname` de la tâche précédente, puis récupère le premier caractère du résultat et renvoie-le sous la forme d'une _string_ d'un seul caractère.

```factor
"Jane" firstletter .
! => "J"
```

## 3. Mets la première lettre au format d'une initiale

Définis `initial`, qui prend un nom. Réutilise `firstletter` de la tâche précédente, mets-la en majuscule, puis ajoute un `.`.

```factor
"Robert" initial .
! => "R."
```

## 4. Place les initiales à l'intérieur du cœur

Définis `couple`, qui prend deux noms sur la pile. Réutilise `initial` de la tâche précédente sur chaque nom, puis assemble le résultat :

```factor
"Blake Miller" "Riley Lewis" couple .
! => "❤ B.  +  R. ❤"
```
