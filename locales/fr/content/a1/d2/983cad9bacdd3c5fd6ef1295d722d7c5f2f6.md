# Introduction

## Définis des variables

Définir une variable, c'est affecter une valeur à un nom. En Scala, il existe deux sortes de variables : les `val` et les `var`.

Une variable déclarée avec `val` est immuable, ce qui signifie qu'on ne peut plus modifier sa valeur après la première affectation :

```scala
val numberTen = 10

numberTen = 11
// --> raises a compile error "reassignment to val"
```

Une variable déclarée avec `var`, en revanche, peut être réaffectée à une nouvelle valeur du même type :

```scala
var someNumber = 10

someNumber = 11
// now someNumber has been reassigned
```

Scala est un langage à typage statique, ce qui signifie que tout possède un type au moment de la compilation. On peut définir une variable soit en précisant explicitement son type, soit en laissant le compilateur Scala inférer son type à partir de la valeur affectée (c'est ce qu'on appelle l'inférence de type). Par conséquent, les deux définitions de variable suivantes sont équivalentes :

```scala
val explicitNumber: Int = 10; // Explicitly typed
val implicitNumber = 10; // Implicitly typed
```

Une fois qu'une variable est définie, son type ne peut plus jamais changer.

```scala
var count = 1; // Assigning an initial value of type Int
count = 2;     // Updating to new value is possible, because it is defined as var

count = false;
// --> raises a compile error "type mismatch"
```

## Définis des méthodes dans les classes

Scala est un _langage orienté objet_ et exige que toutes les méthodes soient définies dans une _classe_. Le mot-clé `class` sert à définir une classe.

```scala
class Calculator {
  // ...
}
```

À l'intérieur d'une classe, une méthode se définit avec le mot-clé `def` suivi d'un nom. Chaque méthode peut prendre zéro ou plusieurs paramètres, listés et séparés par des virgules entre parenthèses. Tous les paramètres doivent avoir un type explicite : il n'y a pas d'inférence de type pour les paramètres. Après la liste des paramètres vient le type de retour de la méthode, séparé de la liste par un deuxième deux-points.

La définition de la méthode est suivie d'un signe `=` qui introduit le corps de la méthode. Dans l'exemple suivant, le corps de la méthode contient deux instructions, qui sont entourées d'accolades.

La méthode renvoie la valeur de la dernière expression ; dans ce cas, la méthode `add` renvoie la valeur de la variable `sum` :

```scala
class Calculator {
  // long form
  def add(x: Int, y: Int): Int = {
    val sum = x + y
    sum
  }
}
```

On peut apporter quelques améliorations pour raccourcir cette méthode et la rendre plus lisible :

- comme la variable `sum` n'est utilisée qu'une seule fois pour renvoyer la valeur, on peut la supprimer
- les méthodes qui ne comportent qu'une seule instruction n'ont pas besoin d'accolades
- le type de retour de la méthode peut être inféré de la même façon que le type d'une variable

Ce qui donne la méthode suivante, qui tient sur une seule ligne et offre la même fonctionnalité :

```scala
class Calculator {
  // shortened form
  def add(x: Int, y: Int) = x + y
}
```

## Instancie des classes et appelle des méthodes

Pour appeler une méthode, on crée d'abord une instance de la classe, puis on appelle la méthode sur cette instance en lui passant des arguments :

```scala
val calculator = new Calculator()
val sum = calculator.add(5, 7)
// sum is of type Int with assigned value of 12
```

## Commente

Scala prend en charge deux types de commentaires : les commentaires sur une seule ligne et ceux sur plusieurs lignes.

```scala
// this is a single line comment

/*
This comment spans across
multiple lines.
*/
```
