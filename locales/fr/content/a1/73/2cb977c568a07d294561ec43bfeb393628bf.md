# Tests

## Exécute les tests

Exécute la spécification de tests avec :

```bash
$ gradle test
```

## Active d'autres tests

Une fois que ton code passe tous les tests actifs, active un autre test en supprimant le `@Ignore` qui précède le test suivant qui t'intéresse. Pour ce faire, supprime la ligne `@Ignore` ou mets-la en commentaire en ajoutant deux barres obliques au début de la ligne.

```Groovy
//@Ignore
def 'outputs "Hello, Alice!" when given the name "Alice"'() {
    expect: hello.hello('Alice') == 'Hello, Alice!'
}
```
