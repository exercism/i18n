# Instructions supplémentaires

Écrase la _string_ fournie contenant le numéro de téléphone.
Si le numéro de téléphone n'est pas valide, remplace-la par une _string_ vide.

## Registres

| Registre | Utilisation  | Type       | Description                                                          |
| -------- | ------------ | ---------- | -------------------------------------------------------------------- |
| `$a0`    | entrée/sortie | adresse    | numéro de téléphone sous forme de _string_ terminée par un caractère nul |
| `$t0-9`  | temporaire    | quelconque | utilisé pour le stockage temporaire                                   |
