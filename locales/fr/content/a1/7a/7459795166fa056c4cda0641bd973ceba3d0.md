# À propos

L'instruction `guard` de Swift sert à effectuer des sorties anticipées depuis une fonction, une boucle ou une méthode lorsque la condition requise n'est pas remplie :

```swift
guard myValue >= 0 else { return 0 }
let root = myValue.squareRoot()
```

Dans l'exemple ci-dessus, `guard` évalue l'expression booléenne qui le suit.
Si la condition vaut `true`, l'exécution se poursuit avec le code qui suit l'instruction `guard`.
Si la condition vaut `false`, c'est le code à l'intérieur du bloc `else` qui est exécuté.

Contrairement à une instruction `if` :

- Une instruction `guard` **doit** comporter une clause `else`.
- La clause `else` **doit** transférer le contrôle pour sortir de la portée environnante (par exemple en utilisant `return`, `continue`, `break`, ou en levant une erreur).

`guard` sert souvent à valider proprement des préconditions.
Par exemple, prenons la fonction sinc ($\text{sinc}(x) = \frac{\sin(x)}{x}$, avec $\text{sinc}(0) = 1$ pour éviter la division par zéro) :

```swift
func sinc(_ x: Double) -> Double {
    guard x != 0 else { return 1 }
    return sin(x) / x
}

sinc(0)             // returns 1
sinc(Double.pi / 2) // returns 0.6366197723675814
```
