# Instructions

Tu administres un système composé de quelques applications qui produisent de nombreux _logs_. Tu veux écrire un petit programme qui va regrouper ces _logs_ et leur attribuer des étiquettes en fonction de leur niveau de gravité. Toutes les applications du système utilisent les mêmes codes de log, mais certaines applications historiques ne prennent pas en charge tous les codes.

| Code de log           | Étiquette de log | Pris en charge dans les applications historiques ? |
|-----------------------| ---------------- | -------------------------------------------------- |
| 0                     | trace            | non                                                |
| 1                     | debug            | oui                                                |
| 2                     | info             | oui                                                |
| 3                     | warning          | oui                                                |
| 4                     | error            | oui                                                |
| 5                     | fatal            | non                                                |
| autre / non pris en charge | unknown     | -                                                  |

## 1. Déterminer l'étiquette du log

Implémente la fonction `LogLevel.to_label/2`. Elle doit prendre un code entier et un booléen qui indique si le log provient d'une application historique, et renvoyer l'étiquette d'une ligne de log sous forme d'atome.

Les codes de log qui ne figurent pas dans le tableau doivent renvoyer une étiquette _unknown_. Les codes de log indiqués dans le tableau comme non pris en charge dans les applications historiques doivent eux aussi renvoyer une étiquette _unknown_ si le log provient d'une application historique.

```elixir
LogLevel.to_label(0, false)
# => :trace

LogLevel.to_label(0, true)
# => :unknown
```

## 2. Envoyer une alerte

Il faut bien prévenir quelqu'un quand des choses inattendues se produisent.

Implémente la fonction `LogLevel.alert_recipient/2` pour déterminer à qui l'alerte doit être envoyée. Elle doit prendre un code entier et un booléen qui indique si le log provient d'une application historique, et renvoyer le nom du destinataire sous forme d'atome.

Utilise la fonction `LogLevel.to_label/2` de la tâche précédente. Si l'étiquette du log est _error_ ou _fatal_, envoie l'alerte à l'équipe _ops_. Si tu reçois un log avec une étiquette _unknown_ provenant d'un système historique, envoie l'alerte à l'équipe _dev1_ ; les autres étiquettes inconnues doivent être envoyées à l'équipe _dev2_. Toutes les autres étiquettes de log peuvent être ignorées sans risque en renvoyant _false_.

```elixir
LogLevel.alert_recipient(-1, true)
# => :dev1

LogLevel.alert_recipient(0, false)
# => false
```
