# Tests

On utilise [PonyTest](https://stdlib.ponylang.io/pony_test--index/) de la bibliothèque standard pour écrire les tests qui servent à tester ta solution. Pour tester ta solution, compile et exécute ton code.

Par exemple, ta session pour « Hello World » peut ressembler à ceci :

```text
[red@apophenia:~/exercism/pony/hello-world]$ ponyc
Generating
 Reachability
 Selector painting
 Data prototypes
 Data types
 Function prototypes
 Functions
 Descriptors
Optimising
Writing ./hello-world.o
Linking ./hello-world

[red@apophenia:~/exercism/pony/hello-world]$ ./hello-world 
1 test started, 0 complete: hello-world/HelloWorld started
1 test started, 1 complete: hello-world/HelloWorld complete
---- Passed: hello-world/HelloWorld
----
---- 1 test ran.
---- Passed: 1
```
