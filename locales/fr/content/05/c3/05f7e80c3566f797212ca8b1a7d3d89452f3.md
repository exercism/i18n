# Introduction

## Déclaration de type

Les déclarations de type en PHP fournissent des assertions de type à l'exécution pour les arguments de fonction, les valeurs de retour et les propriétés de classe.
Sur les fonctions, on peut ajouter un type de retour `void` pour indiquer qu'aucune valeur n'est renvoyée par la fonction.
Les types déclarés servent aussi d'assertions à l'exécution, garantissant que les fonctions renvoient une réponse au type cohérent.

```php
<?php

class Driver
{
    private int $serial_number;

    public function setSerialNumber(int $number): void
    {
        $this->serial_number = $number;
    }

    public function getSerialNumber(): int
    {
        return $this->serial_number; 
    }
}

$driver = new Driver();
$driver->setSerialNumber("Version 1b"); // This will throw a TypeError
```

### Unions de types

Si un argument de fonction, une valeur de retour ou une propriété de classe peut être de plusieurs types, on peut déclarer une union de types.

```php
<?php

class IdentityCard
{
    private int|null $id = null;

    public function assign(int|float $id): void
    {
        $this->id = intval($id);
    }
}

$card = new IdentityCard();
$card->assign(5.0);
```

### Types mixtes

Lorsqu'on travaille avec du code, il n'est pas toujours possible de spécifier un type.
À partir de PHP 8.0, un type d'échappement nommé `mixed` est fourni.
Mixed équivaut à une union de types `object|resource|array|string|float|int|bool|null`.
