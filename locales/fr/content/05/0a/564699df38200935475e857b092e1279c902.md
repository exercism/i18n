# Indices

## 1. Général

- Lis la documentation sur les fichiers dans le [guide de démarrage][getting-started-file] officiel.
- Lis aussi la documentation sur les fichiers sur [joyofelixir.com][joy-of-elixir-file].
- Jette un œil à la [documentation du module `File`][file].

## 1. Lis les adresses e-mail depuis un fichier

- Il existe une [fonction intégrée][file-read] pour lire le contenu d'un fichier d'un seul coup.

## 2. Ouvre un fichier de log en écriture

- Il existe une [fonction intégrée][file-open] pour ouvrir un fichier.
- Le deuxième argument de cette fonction est une liste de modes qui permet de préciser que le fichier doit être ouvert en écriture.

## 3. Enregistre un e-mail envoyé

- Les fonctions permettant de lire et d'écrire dans un fichier ouvert avec [`File.open!/1`][file-open] se trouvent dans le module [`IO`][io].
- Il existe une [fonction intégrée][io-puts] pour écrire une _string_ dans un fichier, suivie d'un saut de ligne.

## 4. Ferme le fichier de log

- Il existe une [fonction intégrée][file-close] pour fermer un fichier.

## 5. Envoie la newsletter

- Toutes les opérations nécessaires sur les fichiers ont déjà été implémentées dans les étapes précédentes.
- Avant d'écrire dans un fichier, il faut d'abord l'ouvrir.
- Une fois toutes les opérations d'écriture dans un fichier terminées, il faut fermer le fichier.
