# Instructions

Tu es assistant pédagogique et tu corriges les examens d'élèves.
Garder la trace des résultats à la main devient à la fois fastidieux et propice aux erreurs.
Tu décides de rendre la chose un peu plus intéressante en écrivant quelques fonctions pour compter et calculer les résultats de la classe.

## 1. Arrondis les notes

Même si on peut accorder un « crédit partiel » sur les questions d'un examen, les notes globales de l'examen doivent être des `int`s.
Donc, avant de pouvoir faire quoi que ce soit d'autre avec les notes de la classe, il faut passer en revue toutes les notes et convertir les notes de type `double` en `int`s.

Crée la fonction `round_down_scores()` qui prend un `vector` de `student_scores`.
L'arrondi demandé par l'école est une troncature.
Heureusement pour toi, C++ peut convertir un type en un autre avec `static_cast`.
La conversion `static_cast` de `double` vers `int` supprime tous les chiffres après la virgule.
Cette fonction doit prendre le `vector` en entrée et `return` un nouveau `vector` dont toutes les notes sont converties en `int`s.

```cpp
std::vector<double> student_scores {90.33, 40.5, 55.44, 70.05, 30.55, 25.45, 80.45, 95.3, 38.7, 40.3};
round_down_scores(student_scores)
// => {90, 40, 55, 70, 30, 25, 80, 95, 38, 40}
```

Il existe d'autres méthodes pour obtenir le même résultat, mais un _cast_ est chose courante.

```cpp
int new_PI{static_cast<int>(3.14) + static_cast<int>(0.001592653589)};
// new_PI is 3.
```

## 2. Les élèves qui échouent

Pendant que tu corrigeais l'examen, tu as remarqué que certains élèves ne réussissaient pas aussi bien que tu l'espérais.
Mais tu étais distrait, et tu as oublié de noter exactement _combien_ d'élèves.

Crée la fonction `count_failed_students()` qui prend un `vector` de `student_scores`.
Cette fonction doit compter le nombre d'élèves qui n'ont pas la moyenne et renvoyer ce nombre sous forme d'entier.
Un élève doit obtenir une note supérieure à **40** pour réussir l'examen.

```cpp
count_failed_students({90,40,55,70,30,25,80,95,38,40});
// => 5
```

## 3. Calcule les notes alphabétiques

L'enseignant que tu assistes aime attribuer des notes alphabétiques en plus des notes numériques.
Comme les élèves obtiennent rarement 100 à un examen, les seuils inférieurs des « notes alphabétiques » sont calculés à partir de la meilleure note obtenue, et s'échelonnent régulièrement entre cette meilleure note et le seuil d'échec de **<= 40**.

Crée la fonction `letter_grades()` qui prend en paramètre la note la plus « haute » de l'examen, et renvoie un `array` (et non un vector) des seuils inférieurs pour chaque intervalle de note « à l'américaine » : `["D", "C", "B", "A"]`.

```cpp
/*Where the highest score is 100, and failing is <= 40.
       "F" <= 40
 41 <= "D" <= 55
 56 <= "C" <= 70
 71 <= "B" <= 85
 86 <= "A" <= 100
*/

letter_grades(100);
// => {41, 56, 71, 86}


/*Where the highest score is 88, and failing is <= 40.
       "F" <= 40
 41 <= "D" <= 52
 53 <= "C" <= 64
 65 <= "B" <= 76
 77 <= "A" <= 88
*/

letter_grades(88);
// => {41, 53, 65, 77}
```

## 4. Associe les noms aux notes

Tu as les notes d'examen par ordre décroissant, ainsi que les noms des élèves correspondants (triés dans l'ordre de leurs notes d'examen).
Tu aimerais associer le nom de chaque élève à sa note d'examen et afficher un classement global de la classe.

Crée la fonction `student_ranking()` avec les paramètres `student_scores` et `student_names`.
Associe chaque nom d'élève du `vector` student_names à sa note du `vector` student_scores.
Tu peux supposer que chaque `vector` argument est trié du meilleur au moins bon.
La fonction doit renvoyer un `vector` de _strings_ au format `<rank>. <student name>: <student score>`.

```cpp
std::vector<int> student_scores {100, 99, 90, 84, 66, 53, 47};
std::vector<std::string> student_names {"Joci", "Sara","Kora","Jan","Indra","Bern", "Fred"};
student_ranking(student_scores, student_names)
// =>
//  {"1. Joci: 100", "2. Sara: 99", "3. Kora: 90", "4. Jan: 84", "5. Indra: 66", "6. Bern: 53", "7. Fred: 47"}
```

## 5. Une note « parfaite »

Bien qu'une note « parfaite » de 100 soit rare à un examen, il est intéressant de savoir si au moins un élève l'a obtenue.

Crée la fonction `perfect_score()` avec les paramètres `student_scores` et `student_names`.
Les listes sont les mêmes qu'à la tâche 5.
La fonction doit `return` _le premier_ `<name>` (sous forme de _string_) de l'élève qui a obtenu 100 à l'examen.

Si aucune note de 100 n'est trouvée, une _string_ vide `""` doit être renvoyée.

```cpp
perfect_score({"Nur", "Tony", "Fatima"}, {90, 80, 100});
// => "Fatima"

perfect_score({"Nur", "Tony"}, {90, 80});
// => ""
```
