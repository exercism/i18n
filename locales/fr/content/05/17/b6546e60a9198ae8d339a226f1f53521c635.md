# Instructions supplémentaires

## Quelques notes sur les _strings_ en Arturo

Tu verras dans les tests une syntaxe qui t'est peut-être inconnue : des _strings_ multilignes délimitées par `{ braces }`.

### Références

* La documentation [Basic Usage][usage] du module Strings.

### Les littéraux de chaîne en Arturo

Arturo propose plusieurs façons d'écrire des littéraux de chaîne :

1. Les _strings_ sur une seule ligne, entourées de guillemets doubles

    ```arturo
    greeting: "Hello, World!"

    print express greeting     ; => "Hello, World!"
    ```

1. Les _strings_ qui se terminent en fin de ligne, avec un « guillemet intelligent » `«`

    ```arturo
    farewell: « Goodbye, Mars!

    print express farewell     ; => "Goodbye, Mars!"
    ```

   Elles restent très lisibles quand on a une liste de _strings_ courtes :

    ```arturo
    numberWords: [
        « one
        « two
        « three
        « four, and so on
    ]
 
    print express numberWords    ; => ["one" "two" "three" "four, and so on"]
    ```

1. Les _strings_ multilignes entourées d'accolades.
   L'indentation « commune » sera supprimée.
   Les retours à la ligne au début et à la fin sont supprimés.

    ```arturo
    multiline: {
        First line
        Second line
            Third line keeps indentation
        Last line!


    }

    print express first multiline   ; => 'F'
    print express last multiline    ; => '!'
    lines: split.lines multiline
    print size lines                ; => 4
    print express lines\2           ; => "    Third line keeps indentation"
    ```

1. Les _strings_ _verbatim_ sont conservées à l'identique, y compris les espaces en début et en fin.

    ```arturo
    code: {:
        greet: function [name][
            print ~"Hello, |name|~"

        greet "World""
    :}

    print ">" ++ code ++ "<"
    print express first code
        ; => prints a literal newline character between single quotes
    print express (split.lines code | get 1)
        ; => "    greet: function [name]["
    ```

1. Les _strings_ de style heredoc se trouvent sous une ligne de 3 tirets ou plus, jusqu'à la fin du fichier.
   Elles se comportent comme le mot-clé `__DATA__` de Perl.
   Ce style est utile dans un module, où l'on peut stocker de la documentation ou le texte de la licence dans une variable à la fin du fichier.

    Si l'on a ceci dans un fichier nommé « mymodule.art »

    ```arturo
    myLicense:
    ---------
    This text has been placed in the public domain.
    Do with it what you will.
    ```

    Ensuite

    ```arturo
    import {mymodule}!
    print ~">|myLicense|<"  ; => >This text has been placed in the public domain.
                            ; => Do with it what you will.<
    ```
