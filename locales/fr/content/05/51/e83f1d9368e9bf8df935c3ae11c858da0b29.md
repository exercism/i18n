# Conseils

## 1. Crée la classe `Alien`

- Le `constructor` n'a pas de type de retour et porte le même nom que la `class`.
- Une convention courante pour les `classes` est d'utiliser des noms en __PascalCase__.

## 2. La fonction `hit`

- Rappelle-toi l'invariant : les points de vie ne peuvent pas être négatifs.

## 3. La fonction `is_alive`

- La seule condition pour être mort est que les points de vie valent `0`.

## 4. La fonction `teleport`

- Les variables membres peuvent être modifiées par n'importe quelle fonction de la classe.

## 5. La fonction `collision_detection`

- Toutes les variables membres `public` sont accessibles depuis l'extérieur de la classe.
