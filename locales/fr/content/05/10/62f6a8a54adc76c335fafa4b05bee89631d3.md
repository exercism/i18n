# Introduction aux bases

[Go](https://golang.org) est un langage de programmation compilé et à typage statique.
Sa syntaxe est proche de celle du C.
On l'appelle souvent Golang à cause de son ancien nom de domaine, golang.org, mais son nom correct est Go.

Le concept Bases présente trois grandes caractéristiques du langage : les paquets, les fonctions et les variables.

## Paquets

Les applications Go sont organisées en paquets.
Un paquet est un ensemble de fichiers sources situés dans le même répertoire.
Tous les fichiers sources d'un répertoire doivent partager le même nom de paquet.
Par convention, le nom du paquet correspond au dernier répertoire du chemin d'importation.
Par exemple, les fichiers du [paquet « math/rand »](https://golang.org/src/math/rand/) commencent par l'instruction `package rand`.
Quand un paquet est importé, seules les entités (fonctions, types, variables, constantes) dont le nom commence par une lettre majuscule peuvent être utilisées ou accessibles.
Le style de nommage recommandé en Go est d'écrire les identifiants en `camelCase`, sauf ceux qui sont destinés à être accessibles depuis d'autres paquets, pour lesquels on utilise `PascalCase`.

```go
package lasagna
```

## Variables

Go est à typage statique, ce qui signifie que toutes les variables [doivent avoir un type défini](https://en.wikipedia.org/wiki/Type_system) au moment de la compilation.

On peut définir une variable en précisant explicitement un type :

```go
var explicit int // Explicitly typed
```

Tu peux aussi fournir une valeur d'initialisation, et le compilateur attribuera à la variable le type correspondant à celui de cette valeur.

```go
implicit := 10   // Implicitly typed as an int
```

Une fois déclarée, on peut affecter une valeur à une variable avec l'opérateur `=`.
Une fois déclarée, le type d'une variable ne peut plus jamais changer.

```go
count := 1 // Assign initial value
count = 2  // Update to new value

count = false // This throws a compiler error due to assigning a non `int` type
```

## Constantes

Une constante contient une donnée, comme une variable, mais sa valeur ne peut pas changer pendant l'exécution du programme.

Les constantes se définissent avec le mot-clé `const` et peuvent être des nombres, des caractères, des _strings_ ou des booléens :

```go
const Age = 21 // Defines a numeric constant 'Age' with the value of 21
```

## Fonctions

Les fonctions Go prennent zéro ou plusieurs paramètres.
Les paramètres doivent être typés explicitement, il n'y a pas d'inférence de type.

Les valeurs sont renvoyées par les fonctions avec le mot-clé `return`.

On appelle une fonction en indiquant son nom et en passant un argument pour chacun de ses paramètres.

À noter que Go prend en charge deux types de commentaires.
Les commentaires sur une seule ligne sont précédés de `//` et les commentaires multilignes s'insèrent entre `/*` et `*/`.

```go
package greeting

// Hello is a public function.
func Hello (name string) string {
    return hi(name)
}

// hi is a private function.
func hi (name string) string {
    return "hi " + name
}
```
