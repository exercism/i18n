# Tests

## Teste en interactif

Lance le REPL depuis le dossier dans lequel tu as téléchargé l'exercice.

Tu peux lancer les tests en chargeant le fichier de test dans le REPL avec `(load "exercise-test")` (en remplaçant « exercise » par le nom approprié). Évalue ensuite `(exercise-test:run-tests)` pour lancer tous les tests.

Si tu écris ton code directement dans le REPL, il te suffit d'évaluer `(exercise-test:run-tests)`.

Si tu écris ton code dans le fichier Lisp de l'exercice, charge-le avec `(load "exercise")`, puis évalue `(exercise-test:run-tests)`.

## Teste depuis la ligne de commande

Tu peux lancer les tests avec cette commande (là encore, remplace « exercise » par le nom approprié, aux deux endroits)

```sh
ros run --load exercise-test.lisp --eval '(uiop:quit (if (exercise-test:run-tests) 0 1))'
```
