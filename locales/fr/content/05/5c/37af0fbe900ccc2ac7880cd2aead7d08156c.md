# À propos

En général, une fonction n'accepte qu'un nombre fixe d'arguments.
Cependant, si tu fais précéder le type du dernier paramètre de `...`, la fonction peut accepter n'importe quel nombre d'arguments supplémentaires en fin de liste.
Le dernier paramètre devient alors un _paramètre variadique_.

```go
func sum(nums ...int) int {
    total := 0
    for _, n := range nums {
        total += n
    }
    return total
}
```

À l'intérieur de la fonction, le paramètre variadique est une _slice_ :

```go
sum(1, 2, 3)    // nums is []int{1, 2, 3}
sum(1, 2, 3, 4) // nums is []int{1, 2, 3, 4}
sum()           // nums is []int{}
```

Une fonction peut avoir des paramètres non variadiques avant le paramètre variadique.
Une fonction peut avoir au plus un paramètre variadique, et celui-ci doit être le dernier paramètre.

```go
func greet(greeting string, names ...string) {
    for _, name := range names {
        fmt.Printf("%s, %s!\n", greeting, name)
    }
}
```

## Déroule une slice

Pour passer une _slice_ à un paramètre variadique, fais-la suivre de `...` :

```go
nums := []int{1, 2, 3}
sum(nums...) // equivalent to sum(1, 2, 3)
```

`...` n'est valide que lorsqu'on passe une _slice_ à un paramètre variadique.
