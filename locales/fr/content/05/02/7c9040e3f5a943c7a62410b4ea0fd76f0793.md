# Instructions

Dans cet exercice, tu vas générer des messages de journal semi-structurés.

## 1. Émets des messages semi-structurés

Tu commenceras avec quelques fonctions ébauchées et l'énumération suivante :

```rust
#[derive(Clone, PartialEq, Debug)]
pub enum LogLevel {
    Info,
    Warning,
    Error,
}
```

Ton objectif est d'émettre un message de journal comme suit : `"[<LEVEL>]: <MESSAGE>"`.
Tu devras implémenter des fonctions qui correspondent aux niveaux de log.

Par exemple, l'extrait ci-dessous montre une sortie attendue pour la fonction `log`.

```rust
log(LogLevel::Error, "Stack overflow")
// Returns: "[ERROR]: Stack overflow"
```

Et pour `info` :

```rust
info("Timezone changed")
// Returns: "[INFO]: Timezone changed"
```

Amuse-toi bien !
