# Indices

## 1. Crée un nouveau tableau de scores

- Crée un nouvel objet en utilisant des accolades.
- Écris la clé sous forme de _string_ pour qu'elle puisse contenir des espaces.
- Sépare la clé et la valeur à l'aide de deux-points.

## 2. Ajoute des joueurs à un tableau de scores

- Utilise la notation entre crochets pour ajouter une clé dont le nom est stocké dans une variable (l'argument).
- Utilise l'opérateur d'affectation (`=`) pour définir une valeur pour la nouvelle clé.
- Autrement, tu peux utiliser [l'opérateur `+`][man-plus] pour fusionner l'objet entrant avec un nouvel objet.
- Rappelle-toi que les parenthèses sont nécessaires autour des expressions pour les clés d'un objet.

## 3. Retire des joueurs d'un tableau de scores

- Utilise [l'expression del][man-del].
- Référence la clé comme tu l'as fait dans la tâche précédente (notation entre crochets).
- Rappelle-toi que l'argument de `del` est une _expression d'indice_, et pas seulement une _string_.

## 4. Augmente le score d'un joueur

- Commence par réfléchir à la façon d'exprimer la nouvelle valeur que tu veux affecter.
- Utilise ensuite l'opérateur d'affectation comme dans la tâche 2 pour définir cette nouvelle valeur.
- Si ce n'est pas déjà fait, tu peux utiliser [l'opérateur d'affectation arithmétique][man-update-assignment] `+=`.

## 5. Applique les points bonus du lundi

- Ce serait un bon endroit pour utiliser `to_entries`/`from_entries`, ou `with_entries` pour itérer sur l'objet
- Pour chaque clé, définis la nouvelle valeur comme tu l'as fait dans la tâche 4.

## 6. Trouve le score total

- On veut parcourir les _valeurs_ de l'objet.
  On peut utiliser [`map_values`][man-map_values], ou [`.[]`][man-brackets] pour produire un flux de valeurs.
- L'expression `add` permet de calculer la somme d'une liste de nombres.
