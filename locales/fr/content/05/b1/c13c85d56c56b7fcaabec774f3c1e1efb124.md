# Introduction

Un `bit` est la valeur la plus élémentaire en informatique.
Le mot `bit` signifie « chiffre binaire ».
C'est une unité de stockage de données dans l'environnement d'exécution, suffisamment grande pour contenir un objet pouvant prendre l'une de deux valeurs.
En tant que tel, il possède une valeur binaire qui est soit `1`, soit `0`.
Tous les autres types de données sont composés de plusieurs `bits`.
Par exemple, un `byte` est généralement composé de huit `bits`.

## Masques de bits

Un masque de bits peut être n'importe quelle valeur servant à positionner des bits individuels.
Par exemple, l'alphabet anglais compte vingt-six lettres.
Une valeur d'au moins vingt-six bits, comme un entier non signé de 32 bits, peut servir de masque de bits pour définir une condition `true` ou `false` pour chaque lettre anglaise.
Toute valeur comportant suffisamment de bits pour traiter l'ensemble des conditions `true` ou `false` requises peut servir de masque de bits.
Le positionnement et la lecture des bits individuels se font à l'aide d'opérateurs bit à bit.

## Opérateurs bit à bit

Imaginons que l'on veuille savoir quelles lettres apparaissent dans une `string`.
Pour notre exemple, on n'utilisera que les vingt-six lettres de l'alphabet anglais.
Notre masque de bits sera un entier non signé de 32 bits.
Un `0` indiquera que la lettre n'apparaît pas.
Un `1` indiquera que la lettre apparaît une ou plusieurs fois.
Au départ, la représentation binaire de notre masque de bits sera une suite de 32 `0s` : `00000000000000000000000000000000`.
La position la plus à droite correspondra à `A`.
La deuxième en partant de la gauche correspondra à `B`, et ainsi de suite.
Supposons que l'on parcoure toutes les lettres de la _string_ dans une boucle : on veut alors une seule ligne de code capable de positionner n'importe quelle lettre.

### Opérateur de décalage à gauche : un moyen de positionner un bit

`<<` est l'opérateur bit à bit de décalage à gauche.

Si notre lettre est `A`, on ne veut pas décaler vers la gauche ; mais si notre lettre est `B`, on veut décaler d'une position vers la gauche, et si notre lettre est `C`, on veut décaler de deux positions, et ainsi de suite.
Bien que l'on perçoive les `chars` comme des lettres telles que `A` ou `B`, un `char` est implémenté en mémoire comme un type entier : on peut donc faire de simples calculs avec un `char`.
Si l'on dispose d'une variable nommée `letter` qui représente le `char` que l'on traite, on peut décaler vers la gauche du nombre de positions voulu en décalant `1` vers la gauche de la différence entre `letter` et le `char` `A`, comme ceci : `1 << letter - 'A'`.
`A` - `A` vaut `0`, donc on décale de `0` position si `letter` vaut `A`.
`B` - `A` vaut `1`, donc on décale de `1` position si `letter` vaut `B`, et ainsi de suite.

### Opérateur OU inclusif : un moyen de positionner un bit

Une fois que l'on sait _où_ l'on veut positionner un bit, on peut effectivement le positionner à l'aide de l'opérateur OU inclusif, qui est `|`.
Le résultat de l'opérateur `|` vaut `1` dans chaque position où l'opérande gauche ou l'opérande droit a un bit positionné.
Ainsi, le résultat de `0010 | 0001` est `0011`.
(Il est important de se rappeler que cette valeur vaut `11` en binaire, mais `3` en décimal.)
Pour affecter le résultat à une valeur, on peut combiner l'opérateur `|` avec l'opérateur d'affectation pour positionner les bits comme ceci : `|=`.
Pour rester simple, l'exemple suivant n'utilise pas de boucle, mais il montre comment on pourrait traiter les lettres `ABA` dans un masque de bits.

```c
#include <stdio.h>
#include <stdint.h>

int main() {
    // it's important to initialize the mask to 0 so we don't get garbage values
    uint32_t mask = 0;
    char letter_A = 'A';
    char letter_B = 'B';
    char letter_A_again = 'A';
    mask |= 1 << letter_A - 'A';
    mask |= 1 << letter_B - 'A';
    mask |= 1 << letter_A_again - 'A';
    // prints 3
    printf("%d", mask);
}
```

On positionne la partie la plus à droite de notre masque à `0001` pour `A`, puis on passe le masque à `0011` pour `B`.
Positionner un autre `A` ne modifie pas le masque existant.
On aurait pu éviter de positionner le bit à nouveau en vérifiant si `A` avait déjà été positionné.

### Opérateur ET : un moyen de lire un bit

`&` est l'opérateur ET bit à bit.
Le résultat de l'opérateur `&` vaut `1` dans chaque position où l'opérande gauche et l'opérande droit ont tous les deux un bit positionné.
Ainsi, le résultat de `0011 & 0001` est `0001`.
On peut le voir à l'œuvre dans l'exemple suivant.

```c
#include <stdio.h>
#include <stdint.h>

int main() {
    uint32_t mask = 0;
    char letter_A = 'A';
    char letter_B = 'B';
    char letter_A_again = 'A';
    mask |= 1 << letter_A - 'A';
    mask |= 1 << letter_B - 'A';
    // prints A already set
    if (mask & 1 << letter_A_again - 'A')
        printf("A already set\n");
    else
        mask |= 1 << letter_A_again - 'A';
    printf("%d", mask);
}
```

### Opérateur OU exclusif : un moyen d'inverser un bit

`^` est l'opérateur OU exclusif bit à bit.
Un opérateur OU _inclusif_ implique qu'il existe un opérateur OU _exclusif_ au comportement différent.
Le résultat de l'opérateur `^` vaut `1` dans chaque position où _un seul_ des opérandes gauche ou droit a un bit positionné.
Ainsi, le résultat de `0001 ^ 0011` est `0010`.
Le bit le plus à droite ne sera pas positionné, car _les deux_ opérandes ont `1` à la position la plus à droite.
L'opération OU exclusif est parfois notée XOR.
Si l'on applique un OU exclusif au résultat d'une valeur qui a elle-même subi un OU exclusif, on retrouve la valeur d'origine.
Cela peut servir à un chiffrement très simple, où la même clé sert à la fois à chiffrer et à déchiffrer les données.
Par exemple

```c
#include <stdio.h>

int main() {
    char a = 'a';
    char b = 'b';
    char c = 'c';
    // we will use "a" for the "key"
    char first = a ^ 'a';
    char second = b ^ 'a';
    char third = c ^ 'a';
    // prints three "dots" for unprintable characters
    printf("%c %c %c\n", first, second, third);
    // prints the ascii values 0 3 2
    printf("%d %d %d\n", first, second, third);
    first = first ^ 'a';
    second = second ^ 'a';
    third = third ^ 'a';
    // prints a b c
    printf("%c %c %c\n", first, second, third);
    // prints the ascii values 97 98 99
    printf("%d %d %d\n", first, second, third);
}
```

## Champs de bits

Nous avons vu comment des bits regroupés dans un type de données simple peuvent être adressés par leur position.
Les bits regroupés dans une `struct` peuvent être adressés par leur nom.
Un tel type de données s'appelle un `bit field`.
On peut avoir recours aux `bit fields` lorsque l'on a besoin d'un ensemble de drapeaux ON/OFF et que l'on souhaite réduire au minimum l'utilisation de la mémoire.

```c
#include <stdio.h>

int main() {

    struct lights {
        unsigned int number_of_lights;
        unsigned int red   : 1;
        unsigned int green : 1;
        unsigned int blue  : 1;
    };
    struct lights lightboard = {3, 0, 0, 0};
     
    //  prints 000
    printf("%d", lightboard.red);
    printf("%d", lightboard.green);
    printf("%d\n", lightboard.blue);
    
    lightboard.green = 1;

    //  prints 010
    printf("%d", lightboard.red);
    printf("%d", lightboard.green);
    printf("%d\n", lightboard.blue);
    
    // prints 3
    printf("%d\n", lightboard.number_of_lights);
}
```

La syntaxe `unsigned int variable_name : 1;` crée un champ de `1` bit dans un `unsigned int` placé à l'intérieur de la structure.
À la place d'un `unsigned int`, on peut utiliser un `signed int` ou, depuis C99 ou une version ultérieure, un type `bool`.
Une structure contenant des champs de bits peut aussi contenir des champs d'autres types de données, comme `number_of_lights` dans l'exemple ci-dessus.
