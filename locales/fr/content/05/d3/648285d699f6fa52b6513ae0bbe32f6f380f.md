# Compléments

## GNU awk et l'arithmétique à précision arbitraire

Par défaut, les nombres en `awk` sont représentés par des nombres à virgule flottante en double précision. Cela offre 53 bits de précision (voir la [Table 16.3][table-16.3] du manuel). Malheureusement, ce n'est pas suffisant pour venir à bout de cet exercice (attention, spoiler : un test nécessite 63 bits de précision).

« Précision insuffisante » ressemble à ceci :
```sh
$ gawk 'BEGIN {
  n = 2 ^ 54
  if (n == n + 1)
    print "not enough precision"
  else
    print "OK"
}'
```
```none
not enough precision
```

GNU `awk` peut utiliser des nombres à précision arbitraire, si les bibliothèques nécessaires ont été compilées dans l'exécutable `awk`. Vérifie la version de ton awk et cherche « GNU MPFR » :
```sh
$ gawk --version
GNU Awk 5.0.1, API: 2.0 (GNU MPFR 4.0.2, GNU MP 6.2.0)
...
```

Si elle est présente, active cette fonctionnalité avec l'option `-M` :
```sh
$ gawk -M 'BEGIN {
  n = 2 ^ 54
  if (n == n + 1)
    print "not enough precision"
  else
    print "OK"
}'
```
```none
OK
```

Et si ton `awk` ne gère pas `-M` ? Tu devras alors faire appel à un programme externe capable de faire de l'arithmétique à précision arbitraire, comme `bc`. Voir la section [Utiliser getline pour lire dans une variable depuis un pipe][getline-pipe] pour un exemple.
