# Installation

- macOS : lance `brew install futhark`
- linux : lance `brew install futhark`
- Windows : utilise WSL ou suis [les instructions spécifiques à Windows][windows-specific-instructions]

D'autres méthodes d'installation sont décrites dans [les instructions d'installation officielles][instructions].

[instructions]: https://futhark.readthedocs.io/en/stable/installation.html
[windows-specific-instructions]: https://futhark.readthedocs.io/en/stable/installation.html#windows-installation
