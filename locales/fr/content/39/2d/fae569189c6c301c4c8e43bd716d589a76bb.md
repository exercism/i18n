# Instructions

Un de tes amis tient un vieux magasin de gros appelé **Gross Store**.

Le nom vient de la quantité d'articles que le magasin vend : tout est exprimé en [grosse unité][gross-unit].

Ton ami t'a demandé de mettre en place un système de point de vente (POS) pour son magasin.

**Pour commencer, tu veux en construire un prototype.**

**Dans ton prototype, ton système ne fera qu'enregistrer la quantité.**

Ton ami t'a donné une liste de mesures pour t'aider :

| Unité              | Valeur |
| ------------------ | ----- |
| quarter_of_a_dozen | 3     |
| half_of_a_dozen    | 6     |
| dozen              | 12    |
| small_gross        | 120   |
| gross              | 144   |
| great_gross        | 1728  |

## 1. Stocke l'unité de mesure dans ton programme

Pour pouvoir utiliser la mesure, tu dois la stocker dans ton programme.

```rust
let units = units();
// Felt252Dictionary with entries like { 'dozen': 12 }
```

## 2. Crée une nouvelle facture client

Tu dois implémenter une fonction qui crée une nouvelle facture (vide) pour le client.

```rust
let bill = new_bill();
// Empty Felt252Dictionary
```

## 3. Ajoute un article à la facture du client

Pour cela, tu vas devoir :

- Renvoyer `false` si `unit` ne fait pas partie du dictionnaire `units`.
- Sinon, ajouter l'article à la `bill` du client en l'indexant par le nom de l'article, puis renvoyer `true`.
- Si l'article est déjà présent dans la facture, augmente sa quantité de la valeur associée à `unit`.

```rust
let bill = new_bill();
let units = units();
let ok = add_item(bill, units, 'carrot', 'dozen');
println!(ok);
// Output: true (since dozen is a valid unit)
```

> Note que la valeur renvoyée est de type `bool`.

## 4. Retire un article de la facture du client

Pour cela, tu vas devoir :

- Renvoyer `false` si l'article donné n'est **pas** dans la facture.
Un article est considéré comme absent de la facture si sa quantité vaut 0.
- Renvoyer `false` si `unit` ne fait pas partie du dictionnaire `units`.
- Renvoyer `false` si la nouvelle quantité devait être inférieure à 0.
- Si la nouvelle quantité vaut 0, l'article est considéré comme retiré de la `bill`, tu peux donc renvoyer `true`.
- Sinon, réduire la quantité de l'article et renvoyer `true`.

```rust
let bill = new_bill();
let units = units();
let ok = remove_item(bill, units, 'carrot', 'dozen');
println!(ok);
// Output: false (because there are no carrots in the bill)
```

> Note que la valeur renvoyée est de type `bool`.

## 5. Renvoie la quantité d'un article précis présent dans la facture du client

```rust
let mut bill: Felt252Dict<u32> = Default::default();
bill.insert('carrot', 12);
bill.insert('grapes', 3);
let qty = get_item(bill, 'carrot');
println!(qty);
// Output: 12
```

> Note que la valeur renvoyée est de type `u32`.

[gross-unit]: https://en.wikipedia.org/wiki/Gross_(unit)
