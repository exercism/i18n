# Introduction

## Alias

Pour partager du code entre différents modules Elixir au sein d'un même projet, tu dois référencer le module externe par son nom complet. Mais que faire si ce nom est trop long ou prête à confusion ?

La forme spéciale `alias` permet de raccourcir ou de changer le nom par lequel tu références un module externe. Utilisée sans argument, elle réduit le nom du module à son dernier segment : par exemple, `MyApp.Logger.Settings` devient `Settings`. Un nom personnalisé peut être précisé avec l'option `:as`.

En général, les alias sont ajoutés au début de la définition du module.

```elixir
defmodule Square do
  alias Integer, as: I

  def area(a), do: I.pow(a, 2)
end
```

## Import

La forme spéciale `import` permet d'utiliser les fonctions d'un module externe sans écrire le nom du module.

Importer un module externe entier peut créer des conflits avec les fonctions locales existantes. Pour éviter cela, deux options sont disponibles : `:except` et `:only`. Toutes deux attendent une liste de mots-clés, où la clé est le nom de la fonction et la valeur son arité.

En général, les imports sont ajoutés au début de la définition du module.

```elixir
defmodule Square do
  import Integer, only: [pow: 2]

  def area(a), do: pow(a, 2)
end
```
