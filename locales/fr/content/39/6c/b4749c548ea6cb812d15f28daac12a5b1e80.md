# Ajout aux instructions

## Fonctions et tests

Tu disposes d'une définition de départ pour la fonction `SayHi`.

```delphi
function SayHi : string;
begin
  result := 'Goodbye, Mars!';
end;
```

L'exécuteur de tests prend cette fonction et l'exécute, en comparant la valeur qu'elle [renvoie][returns] à la valeur attendue.
Utilise cette définition de fonction de départ comme base pour ta solution.

[returns]: https://www.freepascal.org/docs-html/3.2.2/ref/refse94.html
