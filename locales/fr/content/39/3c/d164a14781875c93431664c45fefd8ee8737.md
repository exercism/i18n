# Tuples

En Elm, les tuples peuvent contenir deux ou trois valeurs, et chaque valeur peut être de n'importe quel type. En Elm, les tuples servent surtout à représenter des types temporaires simples. C'est pour cette raison qu'un tuple est limité à 3 valeurs et que, pour t'encourager dans cette direction, seules des fonctions utilitaires pour 2 valeurs sont fournies. Pour des données plus complexes, il vaut mieux passer aux enregistrements. Un usage courant consiste à renvoyer plusieurs valeurs depuis une fonction. Les champs d'un tuple ne portent pas de nom : on y accède par déstructuration ou par position.

Tu peux lire une [introduction concise aux tuples][tuples-concise]. Il existe aussi une [introduction plus approfondie][tuples-in-depth], et la [doc de l'API du module Tuple][tuple-core] contient des exemples de code et une documentation détaillée.

## Déclaration

Les types des tuples se créent avec des parenthèses, et leurs types d'éléments sont séparés par des virgules.

```elm
type alias IntStringTuple = (Int, String)
```

### Création

Les tuples se créent avec des parenthèses, et leurs éléments sont séparés par des virgules.

```elm
aTuple : IntStringTuple
aTuple = (123, "elements can be of differing types")
```

Tu peux aussi utiliser `Tuple.pair` pour créer un tuple à deux valeurs.

```elm
anotherTuple : (String, String)
anotherTuple = Tuple.pair "this time it's" "two strings"
    --> ("this time it's", "two strings")
```

### Accès

Il existe aussi des fonctions pour accéder aux valeurs d'un tuple par position : `Tuple.first` et `Tuple.second`.

```elm
Tuple.first aTuple
    --> 123

Tuple.second aTuple
    --> "elements can be of differing types"
```

Les tuples peuvent être _déstructurés_ dans des liaisons, grâce au filtrage par motif sur les tuples. La déstructuration est possible dans les expressions let, les déclarations de fonctions et les instructions case.

```elm
repeatString : (Int, String) -> Bool
repeatString aTuple =
let
    (aNumber, aString) = aTuple
in
    String.repeat aNumber aString

repeatStringAgain : (Int, String) -> Bool
repeatStringAgain (aNumber, aString) = String.repeat aNumber aString
```

Le filtrage par motif dans une instruction case permet aussi de faire correspondre le contenu des valeurs :

```elm
has123 : (Int, String, Bool) -> Bool
has123 aTuple =
    case aTuple of
        (123, _, _) ->
            True
        (_, "123", _) ->
            True
        (_, _, True) ->
            True
        _ ->
            False
```
