# Nombres

`INT` est le type de Sather pour les nombres entiers : `0`, `7`, `-3`. Une routine qui répond par un nombre entier le signale après les deux-points, de la même manière qu'une routine qui répond par du texte indique `STR`.

```sather
   goals : INT is
      return 42;
   end;
```

Les routines peuvent prendre des **arguments**, des valeurs qu'on leur transmet au moment de l'appel. Chaque argument est nommé et reçoit un type, entre parenthèses après le nom de la routine :

```sather
   total(first : INT, second : INT) : INT is
      return first + second;
   end;
```

Lorsque deux arguments partagent le même type, on peut les nommer ensemble :

```sather
   total(first, second : INT) : INT is
```

Pour l'appeler, il suffit de mettre les valeurs entre parenthèses :

```sather
SCORES::total(3, 4)     -- this is 7
```

Les cinq opérateurs arithmétiques sont `+`, `-`, `*`, `/` et `%`.

`/` appliqué à deux `INT` est une **division entière** : elle abandonne tout reste au lieu de donner une fraction.

```sather
7 / 2      -- 3, not 3.5
```

`%` donne ce qui reste de cette division.

```sather
7 % 2      -- 1
```

Les deux vont de pair : `7`, c'est `3` fois `2` et il reste `1`.
