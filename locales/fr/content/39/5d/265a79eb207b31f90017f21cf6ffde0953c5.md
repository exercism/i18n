# Introduction

Un tableau en Gleam est une collection immuable de zéro ou plusieurs valeurs. Toutes les valeurs d'un tableau doivent avoir le même type. Comme les tableaux sont immuables, une fois qu'un tableau a été construit, sa valeur ne peut plus jamais changer. Toutes les fonctions et tous les opérateurs qui semblent modifier un tableau (comme l'ajout d'un élément) renvoient en réalité un nouveau tableau.

On peut définir un tableau comme ceci :

```gleam
let empty = []
let singleValue = [5]
let threeValues = ["a", "b", "c"]
```

La façon la plus courante d'ajouter un élément à un tableau consiste à utiliser la syntaxe de propagation :

```gleam
let two_to_four = [2, 3, 4]
let one_to_four = [1, ..two_to_four]
// -> [1, 2, 3, 4]
```

Le module [`gleam/list`](https://hexdocs.pm/gleam_stdlib/gleam/list.html) de la bibliothèque standard de Gleam contient de nombreuses fonctions utiles pour manipuler les tableaux. Ce module est très couramment utilisé dans le code Gleam, il est donc bon de le connaître.

On peut utiliser des motifs de tableaux dans les expressions `case` pour filtrer des tableaux et affecter les valeurs qu'ils contiennent à des variables :

```gleam
pub fn describe(list: List(String)) -> String {
  case list {
    [] -> "Empty list"
    [x] -> "List with one item: " <> x
    [x, y] -> "List with two items: " <> x <> " and " <> y
    _ -> "List with three or more items"
  }
}
```

En plus de filtrer sur des tableaux d'une longueur exacte, on peut utiliser la syntaxe de propagation pour filtrer sur des tableaux ayant au moins une certaine longueur :

```gleam
pub fn describe(list: List(String)) -> String {
  case list {
    [_, _, ..] -> "List with at least two items"
    [_] -> "List with one item"
    [] -> "Empty list"
  }
}
```

La syntaxe de propagation permet aussi d'affecter le reste du tableau à une variable :

```gleam
pub fn remove_first_item(list: List(String)) -> List(String) {
  case list {
    // Return the list without the first item
    [_, ..rest] -> rest

    // There's no first item to remove, return an empty list
    _ -> []
  }
}
```

Les expressions `case` doivent avoir un motif pour chaque valeur possible du type filtré, c'est pourquoi un motif joker (`_`) final est souvent utilisé pour gérer les valeurs restantes.
