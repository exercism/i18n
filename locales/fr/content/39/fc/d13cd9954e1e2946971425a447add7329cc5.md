# Introduction

Les erreurs servent à signaler que quelque chose ne va pas ou est inattendu dans un programme ou dans un bout de code.

Ce sont des objets JavaScript.

La propriété principale de cet objet est `message` :

```javascript
const error = new Error('Oops, something went wrong');

console.log(error.message);
// => "Oops, something went wrong"
```

Avec la syntaxe `throw`, tu peux lever une erreur.

```javascript
throw new Error('Oops');
```

Quand une erreur est levée, l'exécution courante s'arrête et reprend dans le premier bloc `catch` de la pile d'appels.

```javascript
try {
  throw new Error('Oops');
} catch (error) {
  console.log(error.message);
  // => "Oops"
}
```

Comme pour n'importe quelle classe en JavaScript, les sous-classes peuvent hériter de `Error` pour créer des erreurs personnalisées à l'aide du mot-clé `extends`.
La syntaxe `instanceof` permet de vérifier que l'erreur interceptée est une instance d'une sous-classe particulière de `Error`.

```javascript
class CustomError extends Error {}

try {
  // ... Code that may throw an error
} catch (error) {
  if (error instanceof CustomError) {
    console.log('The error thrown is an instance of the CustomError');
  }
}
```
