# À propos

PHP dispose de plusieurs structures de contrôle de boucle intégrées, comme `while`. La forme de base d'une instruction `while` est :

```php
while (expr) {
  // statements
}
```

Tant que l'expression (_expr_) s'évalue à une valeur _truthy_, la boucle parcourt les instructions qu'elle contient. Si l'expression (_expr_) s'évalue à faux avant la première itération, les instructions ne sont jamais exécutées.

Sinon, tu peux aussi utiliser une boucle `do-while`, qui exécute les instructions de la boucle une fois avant d'évaluer l'expression (_expr_).

```php
do {
  // statements
} while (expr);
```
