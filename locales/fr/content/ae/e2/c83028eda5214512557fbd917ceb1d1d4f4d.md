# Indices

## Général

- Il existe trois [opérateurs booléens][operators] pour manipuler des valeurs booléennes.
- On peut combiner plusieurs opérateurs dans une seule expression.

## 1. Vérifie si une attaque rapide est possible

- Les [opérateurs booléens][operators] peuvent aussi s'appliquer à des paramètres booléens.
