# Instructions

Dans cet exercice, tu vas gérer un système d'inventaire.

L'inventaire doit être organisé par nom d'article et doit garder la trace du nombre d'articles disponibles.

Tu devras gérer l'ajout d'articles à un inventaire.
Chaque fois qu'un article apparaît dans un vecteur donné, la quantité de cet article doit être augmentée de `1` dans l'inventaire.
Tu devras aussi gérer la suppression d'articles d'un inventaire en diminuant les quantités de `1` lorsqu'on le demande.

Enfin, tu devras implémenter une fonction qui renvoie toutes les paires clé-valeur d'un inventaire donné sous la forme d'un `vector` de `pair`s.

~~~~exercism/note
Les tests de cet exercice sont indépendants de la mutation, mais les noms des fonctions indiquent qu'elles ne devraient pas muter leur entrée.
Si tu veux utiliser les fonctions de l'introduction sans muter l'entrée, la fonction `copy()` te sera utile.
~~~~

## 1. Crée un inventaire à partir d'un vecteur

Implémente la fonction `create_inventory(<input vector>)` qui crée un « inventaire » à partir d'un vecteur d'articles en entrée.
Elle doit renvoyer un `dict` contenant chaque nom d'article associé à sa quantité respective.

```julia-repl
julia> create_inventory(["coal", "wood", "wood", "diamond", "diamond", "diamond"])
Dict("coal" => 1, "wood" => 2, "diamond" => 3)
```

## 2. Ajoute des articles d'un vecteur à un dictionnaire existant

Implémente la fonction `add_items(<inventory dict>, <item vector>)` qui ajoute un vecteur d'articles à l'inventaire passé en argument :

```julia-repl
julia> add_items(Dict("coal" => 1), ["wood", "iron", "coal", "wood"])
Dict("coal" => 2, "wood" => 2, "iron" => 1)
```

## 3. Décrémente des articles de l'inventaire

Implémente la fonction `decrement_items(<inventory dict>, <items vector>)` qui prend un `vector` d'articles.
Ta fonction doit retirer `1` au compteur d'un article chaque fois que cet article apparaît dans le `vector` :

```julia-repl
julia> decrement_items(Dict("coal" => 3, "diamond" => 1, "iron" => 5), ["diamond", "coal", "iron", "iron"])
Dict("coal" => 2, "diamond" => 0, "iron" => 3)
```

Les compteurs d'articles dans l'inventaire ne doivent pas pouvoir descendre en dessous de 0.
Si le nombre de fois qu'un article apparaît dans le `vector` d'entrée dépasse le compteur disponible, la quantité indiquée pour cet article doit rester à 0.
Les demandes de retrait supplémentaires doivent être ignorées une fois que le compteur atteint zéro.

```julia-repl
julia> decrement_items(Dict("coal" => 2, "wood" => 1, "diamond" => 2), ["coal", "coal", "wood", "wood", "diamond"])
Dict("coal" => 0, "wood" => 0, "diamond" => 1)
```

## 4. Retire complètement une entrée de l'inventaire

Implémente la fonction `remove_item(<inventory dict>, <item>)` qui retire complètement un article et son compteur d'un inventaire :

```julia-repl
julia> remove_item!(Dict("coal" => 2, "wood" => 1, "diamond" => 2), "coal")
Dict("wood" => 1, "diamond" => 2)
```

Si l'article n'est pas trouvé dans l'inventaire, la fonction doit renvoyer l'inventaire d'origine inchangé.

```julia-repl
julia> remove_item(Dict("coal" => 2, "wood" => 1, "diamond" => 2), "gold")
Dict("coal" => 2, "wood" => 1, "diamond" => 2)
```

## 5. Renvoye tout le contenu de l'inventaire

Implémente la fonction `list_inventory(<inventory dict>)` qui prend un inventaire et renvoie un vecteur de paires `(item, quantity)`.

Le vecteur ne doit inclure que les articles _disponibles_ (_dont la quantité est supérieure à zéro_), et doit être trié par ordre alphabétique des articles :

```julia-repl
julia> list_inventory(Dict("coal" => 7, "wood" => 11, "diamond" => 2, "iron" => 7, "silver" => 0))
["coal" => 7, "diamond" => 2, "iron" => 7, "wood" => 11]
```
