# Introduction

Les structures conditionnelles en C++ ressemblent à celles des autres langages.
Le type sous-jacent de toute opération conditionnelle est le type `bool`, qui peut valoir `true` ou `false`.
On utilise souvent les conditionnelles comme mécanismes de contrôle du flux pour vérifier différentes conditions.

On peut utiliser une instruction `if`, qui exécute son code si la condition sous-jacente est `true`, comme ceci :

```cpp
std::string value{"val"};

if (value == "val") {
    return "was val";
}
```

Lorsqu'il y a plus d'un cas possible, on peut enchaîner plusieurs instructions `if` à l'aide des instructions `else if` et `else`.

```cpp
int number{33};

if (number > 0) {
   return "positive";
} else if (number < 0) {
    return "negative";
} else {
   return "zero";
}
```

Depuis C++17, les instructions `if` peuvent aussi inclure une courte instruction d'initialisation, qui permet d'initialiser une ou plusieurs variables pour l'instruction `if`.
Par exemple :

```cpp
int num{7};
if (int v{2 * num}; v > 10) {
    return v;
} else {
    return num;
}
// => 14
```

> Remarque : les variables créées dans l'initialisation ne sont pas accessibles après la fin de l'instruction `if`.
