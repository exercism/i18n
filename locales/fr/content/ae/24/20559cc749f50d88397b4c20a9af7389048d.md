# Ajout aux instructions

## Note

Si tu modifies ce fichier dans un éditeur de texte plutôt que dans Pharo, consulte la section [Bien démarrer](https://www.exercism.org/tracks/pharo/installation).

Même si tu peux utiliser un éditeur de texte, l'IDE Pharo fait en partie ce qui rend ce langage si particulier.

Dans Pharo, tu peux exécuter du code (y compris les tests) avec des méthodes cassées et des classes manquantes.
Quand la VM rencontre du code cassé, elle ouvre un débogueur qui te permet d'explorer un peu mieux le problème.

Tu as alors la possibilité d'appuyer sur le bouton _Create_ pour ajouter une classe ou une méthode manquante, et de corriger le code qui provoque une erreur.
Quand tu le fais, le débogueur revient en arrière et te laisse reprendre l'exécution avec tes nouvelles modifications.

Essaie avec ton exemple HelloWorld, en lançant simplement l'une des méthodes de test unitaire.
