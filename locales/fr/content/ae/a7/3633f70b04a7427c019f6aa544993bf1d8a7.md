# Installation

## Prérequis

Le parcours C++ nécessite que les logiciels suivants soient installés sur ton système :
* un compilateur C++14 moderne
* le système de compilation multiplateforme CMake

On utilise [Catch2](https://github.com/catchorg/Catch2) pour les tests, une bibliothèque _header-only_ fournie avec les exercices.

Ces dépendances sont très courantes dans les projets C++, donc si tu rencontres le moindre problème lors de leur installation, tu trouveras de nombreuses ressources utiles en ligne.

De nombreux IDE, comme Visual Studio de Microsoft, Xcode d'Apple ou CLion de JetBrains, embarquent à la fois un compilateur et CMake : tu n'as donc besoin d'installer que l'IDE.

### Un compilateur C++14 moderne

Ce parcours nécessite un compilateur compatible [C++14](http://en.wikipedia.org/wiki/C%2B%2B14), une norme parue en 2014. Tous les principaux compilateurs sortis ces dernières années devraient être compatibles, donc tant que tu utilises une version assez récente, tout devrait bien se passer. Plus précisément : GCC version 7 ou ultérieure, Clang version 6 ou ultérieure, ou Visual Studio 2017 ou ultérieur.

### CMake

CMake est un système de compilation multiplateforme open source qui génère les scripts de compilation pour ton système de compilation natif (`make`, Visual Studio, Xcode, etc.). Le parcours C++ d'Exercism utilise CMake pour te fournir un système de compilation prêt à l'emploi qui :

* compile les tests
* compile ta solution
* lie l'exécutable de test
* exécute automatiquement les tests à chaque compilation
* fait échouer la compilation si un test échoue

Utiliser CMake permet à Exercism de fournir un script de compilation multiplateforme capable de générer les fichiers de projet pour des environnements de développement intégrés comme Visual Studio et Xcode. Tu peux ainsi te concentrer sur le problème sans avoir à te soucier de la configuration de la compilation pour chaque exercice.

Obtenir une compilation portable n'est pas chose facile et demande d'avoir accès à de nombreux types de systèmes. Si tu rencontres le moindre problème avec la recette CMake fournie, n'hésite pas à [signaler le problème](https://github.com/exercism/cpp/issues) pour que nous puissions améliorer la prise en charge de CMake.

[CMake 3.5.1 ou ultérieur](http://www.cmake.org/) est nécessaire pour utiliser la recette de compilation fournie.

## Windows

Sous Windows, tu peux télécharger [Visual Studio Community](https://www.visualstudio.com/vs/community/), gratuitement : tu obtiendras l'IDE Visual Studio et la dernière version du compilateur Microsoft Visual C++.

1. Suis [les instructions disponibles ici](https://docs.microsoft.com/en-us/cpp/build/cmake-projects-in-visual-studio) pour configurer CMake.
1. Télécharge l'exercice à l'aide de l'outil [Exercism CLI](https://exercism.io/cli-walkthrough).
1. Ouvre Visual Studio 2017 ou une version ultérieure (avec les outils Visual C++ pour CMake installés comme décrit dans le lien ci-dessus).
1. Ouvre le dossier de l'exercice dans VS.
1. Lance _« Build->Build the solution »_. Les tests s'exécutent en même temps que la compilation, et leur sortie s'affiche dans la fenêtre de compilation. Comme les tests s'exécutent pendant la compilation, VS signalera un échec de compilation si l'un des tests échoue, et les messages d'échec des tests apparaîtront dans la fenêtre de sortie de compilation.

Tu devrais pouvoir utiliser de la même manière d'autres IDE intégrés, comme CLion de JetBrains.

### Installe Boost sous Windows

Les exercices `meetup` et `gigasecond` dépendent des bibliothèques [Boost][boost-website]. Les étapes suivantes expliquent comment tout installer.

1. Télécharge les [bibliothèques Windows précompilées][sourceforge-boost-binaries] pour Boost.
   - Les exercices nécessitent au minimum la version 1.58 de Boost.
   - Tu peux trouver la version de MSVC en cliquant sur _« Modify »_ dans le Visual Studio Installer.
1. Extrais les bibliothèques dans un dossier local.
1. Définis la variable d'environnement `BOOST_ROOT` sur le dossier où tu as installé les bibliothèques Boost.
1. Si Visual Studio était ouvert pendant cette opération, ferme-le pour que la valeur de `BOOST_ROOT` soit bien prise en compte.
1. Lance Visual Studio et ouvre le dossier contenant l'exercice `gigasecond` ou `meetup`.
1. L'_« Startup Item »_ devrait être `gigasecond.exe` ou `meetup.exe`, et tu devrais obtenir des erreurs de compilation dans `gigasecond_test.cpp` ou `meetup_test.cpp` t'indiquant qu'il te reste des éléments à implémenter, comme pour les autres exercices.

## Linux

Toutes les versions récentes des distributions Linux disposent de compilateurs C++14 compatibles ; tu devrais pouvoir l'installer avec ton gestionnaire de paquets. Les versions prises en charge sont celles installées par défaut dans Ubuntu LTS 18.04.

Par exemple, sous Ubuntu, tu utiliserais la commande suivante pour installer gcc.

```bash
$ sudo apt-get install gcc
$ gcc --version
```

Si tu utilises une distribution plus ancienne, ton compilateur n'est peut-être pas compatible avec C++14. Dans ce cas, tu devras te rapprocher de ta distribution pour trouver comment installer la version minimale du compilateur.

## MacOS

Sous MacOS, tu peux installer GCC avec [Homebrew](http://brew.sh/) via `brew install gcc`.
