Les [booléens][booleans] en Haxe sont représentés par le type `Bool`, dont les valeurs peuvent être soit `true`, soit `false`.

Haxe prend en charge trois [opérateurs booléens][operators] : `!` (NON unaire), `&&` (ET binaire) et `||` (OU binaire).

Les expressions booléennes composées (`&&` et `||`) utilisent une évaluation _short-circuit_, où les expressions sont évaluées de gauche à droite, mais seulement dans la mesure nécessaire. C'est important dans des cas comme celui-ci :

```haxe
object != null && object.field == x
```

La première vérification booléenne garantit qu'on n'accède à `object.field` que si `object` n'est pas `null`, ce qui évite une erreur d'exécution.

Les trois opérateurs booléens ont des [précédences][precedence] différentes et sont évalués dans cet ordre : `!` -> `&&` -> `||`.

Mettre des expressions entre parenthèses `()` permet de passer outre ces règles de précédence, car les parenthèses ont une précédence plus élevée.

```haxe
!true && false   // => false
!(true && false) // => true
```
