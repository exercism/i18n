# Indices

## Généralités

- Le paquet [strings][strings-package] contient de nombreuses fonctions utiles pour les `string`.
- Il faut importer le paquet `strings` avant de pouvoir l'utiliser.
- Pour appeler une fonction du paquet `strings`, fais-la précéder de `strings.`.

## 1. Crée le message de bienvenue

- On peut concaténer des _string_ avec l'opérateur `+`.
- Il existe une fonction pour [convertir une `string` en majuscules][to-upper].

## 2. Ajoute une bordure décorative

- Il existe une fonction pour [créer une `string` qui contient un caractère donné répété un certain nombre de fois][repeat].
- Un saut de ligne est un [caractère d'échappement][escape-characters] spécial.

## 3. Nettoie les anciens messages marketing

- Il existe une fonction pour [remplacer des _strings_ dans une `string`][replace-all].
- Il existe une fonction pour [supprimer les espaces au début et à la fin d'une `string`][trim-space].
