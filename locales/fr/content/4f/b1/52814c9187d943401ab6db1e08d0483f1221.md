# Instructions append

## Déclarations de constantes

Dans cet exercice, on te demande de déclarer une série de constantes servant à identifier différents types de triangles.
Choisis le type de données qui te semble le plus adapté, puis fais passer les tests.

Ensuite, ça vaut peut-être le coup de se renseigner sur l'identifiant prédéclaré de Go, [iota](https://golang.org/ref/spec#Iota).
Il existe [un excellent article à ce sujet](https://splice.com/blog/iota-elegant-constants-golang/).
