# Introduction

Une année bissextile (dans le calendrier grégorien) survient :

- Dans toute année divisible par 4.
- À moins que l'année ne soit divisible par 100, auquel cas elle n'est bissextile que si elle est aussi divisible par 400.

Quelques exemples :

- 1997 n'était pas une année bissextile, car elle n'est pas divisible par 4.
- 1900 n'était pas une année bissextile, car elle n'est pas divisible par 400.
- 2000 était une année bissextile !
