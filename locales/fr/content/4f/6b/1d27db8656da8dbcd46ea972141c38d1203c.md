# Débogage

Pour t'aider à déboguer, plusieurs macros sont définies dans un [fichier debug.mac][debug].
On peut les appeler avec un ou plusieurs arguments du type et de la taille appropriés.
Par exemple :

```x86asm
debugf32 xmm0, xmm1 ; prints the value of two 32-bit floating-point numbers
debugd16 ax, cx, dx ; prints the value of three signed 16-bit integers
debugx64 [rax]      ; prints the value of a 64-bit integer in hexadecimal format
debugs rel mem, rsi ; prints two NUL-terminated strings
debugu8_xmm xmm1    ; prints 16 packed 8-bit unsigned integers
debug_flag e        ; prints true if je would jump, and false otherwise
```

Pour utiliser l'une de ces macros, il faut inclure `debug.mac` en haut du fichier de solution :

```x86asm
%include "debug.mac"
```

À noter que toutes les macros modifient temporairement `rsp`.
Pour déboguer une valeur se trouvant sur la pile, commence par charger cette valeur, ou son adresse, dans un autre registre.

[debug]: https://github.com/exercism/x86-64-assembly/tree/main/templates/debug.mac
