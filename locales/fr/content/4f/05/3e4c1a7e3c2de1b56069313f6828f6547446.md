S'il est possible de concaténer des _strings_ manuellement en Haxe, le langage prend en charge [l'interpolation de _strings_][string-interpolation], qui offre une syntaxe plus courte et plus pratique :

```haxe
var x = 42;
//The following two statements are equivalent:

// manual concatenation
trace("the number is " + x);

// using interpolation
trace('the number is $x');
```

Comme on le voit ci-dessus, les _strings_ interpolées sont encadrées par des guillemets simples (`'`), contrairement aux [_strings_][strings] classiques, et peuvent contenir des identifiants spéciaux, précédés du signe dollar (`$`), qui déclenchent l'interpolation.

Il est possible d'inclure des expressions entières en utilisant `${expr}`, où `expr` est n'importe quelle expression Haxe valide :

```haxe
trace('the next number is ${x + 1}');
```

Pour désactiver l'interpolation lorsqu'on veut obtenir un vrai signe dollar, on peut utiliser `$$` :

```haxe
trace('the price is $$42'); // outputs: the price is $42
```

Enfin, note que l'interpolation de _strings_ est une fonctionnalité de compilation, sans aucun impact sur les performances à l'exécution. En interne, le compilateur Haxe génère le code équivalent à une concaténation manuelle.

[strings]: https://haxe.org/manual/std-String.html
