# Instructions

Ton ami vient de t'envoyer un message contenant un secret important.
Comme ton ami ne voulait pas que les autres puissent le lire facilement, le message a été chiffré en effectuant une série de manipulations de bits.
Tu vas devoir écrire les fonctions qui t'aideront à déchiffrer le message.

## 1. Décale les bits vers la droite

La première étape pour déchiffrer le message consiste à annuler le décalage effectué lors du chiffrement en décalant les bits vers la droite.
D'autres étapes du processus de déchiffrement partiront du principe que des 0 sont insérés depuis la gauche.

Implémente la fonction `shift_back()` qui prend une valeur et le nombre de positions de décalage, et effectue le décalage.

```julia
shift_back(0b1001, 2) # => 0b0010
```

## 2. Mets certains bits à 1

Ensuite, certains bits doivent être mis à 1.

Implémente la fonction `set_bits()` qui prend une valeur et un masque et renvoie le résultat de la mise à 1 des bits de la valeur.
Un bit de `value` doit être mis à 1 lorsque le bit du `mask` est aussi à 1.
Tous les autres bits doivent rester inchangés.

```julia
set_bits(0b0110, 0b0101) # => 0b0111
```

## 3. Inverse certains bits

Certains bits sont inversés pendant le chiffrement.
Il faudra les inverser à nouveau pour déchiffrer le message.

Implémente la fonction `flip_bits()` qui prend une valeur et le masque.
Le masque indique quels bits de la valeur inverser.
Si le bit vaut 1 dans `mask`, le bit est inversé dans `value`.
Tous les autres bits restent inchangés.

```julia
flip_bits(0b1100, 0b0101) # => 0b1001
```

## 4. Mets à zéro certains bits

Enfin, certains bits valent toujours 0 après le déchiffrement.

Implémente la fonction `clear_bits()` qui prend une valeur et un masque.
Les bits de `value` doivent être mis à 0 lorsque le bit du masque vaut 1.
Tous les autres bits doivent rester inchangés.

```julia
clear_bits(0b0110, 0b0101) # => 0b0010
```
