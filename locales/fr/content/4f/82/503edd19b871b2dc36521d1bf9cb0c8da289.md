# Introduction

Python propose deux constructions de boucle.
Les boucles `while` servent aux itérations _indéfinies_ (non comptées) et les boucles `for` aux itérations _définies_ (comptées).
Les mots-clés `break`, `continue` et `else` permettent de personnaliser le comportement d'une boucle.
Les fonctions `range(<length of sequence>)` et `enumerate(<iterable>)` aident à compter les tours et à gérer les indices.

Les boucles `while` ne précisent pas à l'avance le nombre d'itérations à exécuter et continuent tant que l'expression `loop`, ou son « test », s'évalue à `True`.
La boucle se termine quand l'expression de la boucle s'évalue à `False`.

```python
while expression:
    set_of_statements
```

Les boucles `for` parcourent les valeurs de n'importe quelle séquence et se terminent lorsqu'il n'y a plus de valeurs à renvoyer.
La fonction `range(<length of sequence>)` fournit un compteur `loop` ou une séquence lorsqu'il n'y a ni structure de données ni autre itérable sur lequel boucler.

```python
# Python will keep track of the loop count internally.
for item in sequence:
    set_of_statements
    
# `range()` is used as an explicit loop counter.  
# This will loop 12 times, from index 0 to index 11.
for item in range(12):
    set_of_statements
```
