# Ajout aux instructions

## Implémentation

Comme il n'est pas possible, dans Cairo, de parcourir les clés d'un `Felt252Dict`, les tests vérifieront uniquement que les clés des lettres attendues ont les valeurs correctes dans le dictionnaire.

Les tests sont configurés pour ignorer toutes les autres clés qui pourraient être définies dans le dictionnaire obtenu.
