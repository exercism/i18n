# Exécute les tests

Depuis le terminal, place-toi dans le répertoire de base de l'exercice, puis exécute les tests avec :

```bash
$ gleam test
```

Cela exécutera le fichier de test qui se trouve dans le sous-dossier `test`, c'est-à-dire un fichier dont le nom se termine par `_test.gleam`

## Fonctions de test

Les tests utilisent un [framework de test personnalisé](https://github.com/exercism/gleam-test-runner/tree/main/runner).
Toute fonction publique du dossier `test` dont le nom se termine par `_test` sera considérée comme un test par le framework.

Par exemple :

```gleam
import bob
import exercism/should

pub fn shouting_test {
  bob.hey("WATCH OUT!")
  |> should.equal("Whoa, chill out!")
}
```
