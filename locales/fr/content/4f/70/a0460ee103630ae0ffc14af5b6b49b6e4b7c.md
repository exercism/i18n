# Indices

## Général

- Lis l'introduction, qui détaille un exemple similaire pas à pas.
- Un autre exemple figure dans la section [Interfaces][iteration-interface] du manuel Julia.

## 1. Définis le type `Fiberator`

- `n` indique combien de nombres il faut générer.
- Reste simple : aucune autre information n'est nécessaire.

## 2. Implémente la ou les méthodes `iterate`

- Consulte l'introduction pour les détails d'implémentation importants.
- L'argument `state` ne doit pas forcément être un entier. Il peut être de n'importe quel type.
- Réfléchis aux valeurs dont tu as besoin pour calculer l'élément suivant. Un tuple de ces valeurs doit constituer l'argument `state`.
- La méthode `iterate` renvoie un `Tuple` avec deux valeurs `(item, state)`. `item` est le nombre de Fibonacci, c'est-à-dire le `item` dans `for item in Fiberator(10)`.
- Si ton `state` contient plusieurs valeurs, envisage d'utiliser un tuple nommé pour clarifier la signification de chaque valeur.
  - C'est pratique pour la déstructuration, mais ce n'est pas obligatoire.

## 3. Fais fonctionner `collect`

- Une petite méthode (consulte l'introduction pour les détails d'implémentation importants).
- Si elle est absente, lis les messages d'erreur pour obtenir des indices.

## 4. Active l'inférence de type

- Une petite méthode (consulte l'introduction pour les détails d'implémentation importants).
- Fais attention à l'argument de la méthode.
- Après un `collect`, le résultat ne doit _pas_ être `Vector{Any}`.
