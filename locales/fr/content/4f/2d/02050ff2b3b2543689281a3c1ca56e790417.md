# Indices

## 1. Les trois numéros

- L'en-tête de la classe nomme la classe abstraite d'après le `<` :
  `class JUGGLING < $ACT is`.
- Chaque classe doit définir à la fois `name` et `minutes`, exactement comme la
  classe abstraite les déclare. En omettre un provoque une erreur de compilation
  qui nomme la routine.
- Chacune a aussi besoin d'un `create`, sinon `#JUGGLING` n'a rien à appeler.
  `create : SAME is return new; end;` suffit pour deux d'entre elles.
- `TRAPEZE` a besoin d'un attribut pour la hauteur, et d'un `create` qui prend
  cette hauteur.
- `+` ajoute un nombre à une _string_, donc `"Trapeze at " + height + "m"` n'a
  besoin d'aucune conversion.

## 2. Le spectacle

- Le type de l'argument est `ARRAY{$ACT}`. C'est ce qui permet à un seul tableau
  de contenir les trois sortes.
- `acts.elt!` donne un `$ACT`. Appeler `.minutes` dessus exécute de lui-même la
  bonne version : c'est le _dispatch_, et c'est tout l'intérêt de l'exercice. Il
  n'y a rien à vérifier et aucun `typecase` à écrire.
- `billing` construit une _string_ dans une boucle, donc `FSTR`, et le `", "` se
  place avant chaque nom sauf le premier.
- `longest` garde le meilleur numéro vu jusqu'ici. Commencer les meilleures
  minutes à `-1` fait que le premier numéro le bat toujours, ce qui gère le
  spectacle vide sans cas particulier : le nom reste `""`.
