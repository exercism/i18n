# Indices

## Général

- Une [_map_][maps] est une structure de données associative composée de paires clé-valeur.
- Elixir propose [de nombreuses fonctions utiles du module Map dans la bibliothèque standard][map-module].

## 1. Définis une nouvelle _map_ de meilleurs scores

- Elle doit renvoyer une [_map_][maps] vide.
- Les fonctions du [module Map][map-module] ou les formes littérales peuvent être utiles.

## 2. Ajoute des joueurs à la _map_ de meilleurs scores

- La _map_ résultante doit être renvoyée.
- Le [module Map][map-module] contient des fonctions utiles pour manipuler les _maps_. [L'une d'elles][map-put] place une valeur dans une _map_ sous une clé donnée.

## 3. Supprime des joueurs de la _map_ de scores

- La _map_ résultante doit être renvoyée.
- Le [module Map][map-module] contient des fonctions utiles pour manipuler les _maps_. [L'une d'elles][map-delete] supprime une clé d'une _map_.

## 4. Réinitialise le score d'un joueur

- La _map_ résultante doit être renvoyée avec le score du joueur réinitialisé à une valeur initiale.
- Le [module Map][map-module] contient des fonctions utiles pour manipuler les _maps_. [L'une d'elles][map-put] place une valeur dans une _map_ sous une clé donnée.

## 5. Mets à jour le score d'un joueur

- La _map_ résultante doit être renvoyée avec le score du joueur mis à jour.
- Le [module Map][map-module] contient des fonctions utiles pour manipuler les _maps_. [L'une d'elles][map-update] met à jour une valeur dans une _map_ sous une clé donnée.

## 6. Récupère une liste de joueurs

- Le [module Map][map-module] contient des fonctions utiles pour manipuler les _maps_. [L'une d'elles][map-keys] renvoie la liste de toutes les clés d'une _map_.
