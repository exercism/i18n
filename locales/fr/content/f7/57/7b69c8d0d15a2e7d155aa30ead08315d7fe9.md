# Instructions

Tu gères une boutique de mode en ligne. Chaque article de l'inventaire est un tableau à 2 éléments `{ name price }`, et l'inventaire complet est un tableau d'articles.

Un prix manquant est noté `f`.

## 1. Trie l'inventaire par prix

Définis `sort-by-price` pour renvoyer un nouveau tableau avec les articles triés par prix, par ordre croissant.

```factor
{ { "Maxi Brown Dress" 65 } { "Red Skirt" 50 } { "Bamboo Socks Cats" 20 } }
sort-by-price .
! => { { "Bamboo Socks Cats" 20 } { "Red Skirt" 50 } { "Maxi Brown Dress" 65 } }
```

## 2. Trouve les articles sans prix défini

Définis `with-missing-price` pour renvoyer un tableau contenant uniquement les articles dont le prix est `f`.

```factor
{ { "Black T-shirt" 40 } { "Denim Pants" f } { "Orange T-shirt" 40 } }
with-missing-price .
! => { { "Denim Pants" f } }
```

## 3. Compte les articles chers

Définis `expensive-items` pour prendre un inventaire et un seuil de prix, et renvoyer le nombre d'articles dont le prix est strictement supérieur au seuil.

```factor
{ { "Skirt" 50 } { "Coat" 120 } { "Hat" 25 } { "Dress" 80 } }
50 expensive-items .
! => 2

{ { "Skirt" 50 } { "Coat" 120 } { "Hat" 25 } { "Dress" 80 } }
0 expensive-items .
! => 4
```

## 4. Trouve l'article le moins cher

Définis `cheapest-item` pour renvoyer l'article avec le prix le plus bas. Les articles sans prix (`f`) n'apparaîtront pas dans l'entrée.

```factor
{ { "Skirt" 50 } { "Coat" 120 } { "Hat" 25 } } cheapest-item .
! => { "Hat" 25 }
```

## 5. Additionne tous les prix

Définis `total-price` pour renvoyer la somme de tous les prix. Les articles sans prix (`f`) n'apparaîtront pas dans l'entrée.

```factor
{ { "Skirt" 50 } { "Coat" 120 } { "Hat" 25 } } total-price .
! => 195
```

## 6. Formate un article en étiquette de prix

Définis `format-price-tag` pour renvoyer une _string_ de la forme `"name: $price"` pour un article. Les articles sans prix (`f`) n'apparaîtront pas ici.

```factor
{ "Skirt" 50 } format-price-tag .
! => "Skirt: $50"
```
