# Indices

## 1. Définis si Pac-Man peut manger un fantôme

* La fonction doit renvoyer une valeur booléenne.
* Tu peux utiliser l'opérateur logique `and` pour combiner les arguments et obtenir un résultat.

## 2. Définis si Pac-Man marque des points

* La fonction doit renvoyer une valeur booléenne.
* Tu peux utiliser l'opérateur booléen `or` pour combiner les arguments et obtenir un résultat.

## 3. Définis si Pac-Man perd

* La fonction doit renvoyer une valeur booléenne.
* Tu peux utiliser les opérateurs booléens `and` et `not` pour combiner les arguments et obtenir un résultat.

## 4. Définis si Pac-Man gagne

* La fonction doit renvoyer une valeur booléenne.
* Tu peux utiliser les opérateurs booléens `and` et `not` pour combiner les arguments et les résultats de l'une des fonctions implémentées précédemment.
