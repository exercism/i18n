# Tests

Pour exécuter les tests, suis ces étapes :

- Rends-toi dans le répertoire de l'exercice (par exemple `~/Exercism/hello-world`).
- Démarre une session `jconsole` (par exemple en tapant `jconsole` ou `ijconsole`) dans un terminal.
- Charge ton fichier de solution (par exemple `load 'hello-world.ijs'`)
- Charge le _framework_ de tests unitaires en tapant `load  'general/unittest'`
- Teste ta solution en tapant `unittest 'test.ijs'`.
<br></br>
- Tu peux aussi exécuter les tests en une seule ligne, comme ceci : `jconsole -js "load 'hello-world.ijs'" "echo unittest 'test.ijs'" "exit 0"`.

## Tests ignorés

Au début, seul le test initial sera activé.
Cette approche t'encourage à résoudre l'exercice étape par étape.
Chaque test comprend un nom au-dessus de sa définition, qui se termine par _'\_ignore'_.
Pour exécuter le test, remplace sa valeur par 0.

### Exemple :

```
    leap_test_02_ignore=: 1 NB. Change this value to 0 to run this test
    test_leap_test_02  =: monad define
    ...                     NB. test definitions
    )
```
