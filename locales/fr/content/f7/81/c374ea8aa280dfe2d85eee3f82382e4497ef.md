# Indices

## Général

- Lis la section sur les énumérables et les _streams_ dans le [guide officiel Getting Started][getting-started-streams].
- Lis la documentation officielle sur les [_streams_][stream].

## 1. Effectue un lancer de dé à 6 faces

- Les _ranges_ implémentent le _protocole Enumerable_.
- Il existe une [fonction intégrée][enum-random] pour choisir une valeur aléatoire dans un énumérable.

## 2. Continue à lancer tant que tu fais des six

- Il existe une [fonction intégrée][stream-repeatedly] qui crée un _stream_ généré en appelant une fonction de manière répétée.
- Il existe une [fonction intégrée pour les _streams_][stream-transform] qui fonctionne comme `Enum.reduce/3`.

## 3. Permets d'utiliser un dé truqué

- Utilise l'[opérateur de capture][special-forms-capture] pour capturer la fonction `roll/0`.
