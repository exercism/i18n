# Introduction

Le [type `enum`](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/builtin-types/enum) de C# représente un ensemble fixe de constantes nommées (une énumération).

Normalement, un membre d'un `enum` ne peut référencer qu'une seule de ces constantes nommées. Cependant, il est parfois utile d'en référencer plusieurs. Pour ce faire, on peut annoter l'`enum` avec l'[attribut `Flags`](https://docs.microsoft.com/en-us/dotnet/api/system.flagsattribute).

Un `enum` de drapeaux peut se définir comme suit (avec la notation binaire des entiers, `0b`) :

```csharp
[Flags]
enum PhoneFeatures
{
    Call = 0b00000001,
    Text = 0b00000010
}
```

Une instance de `PhoneFeatures` dont la valeur est `0b00000011` a ses deux drapeaux `Call` _et_ `Text` définis.

Par défaut, le type `int` est utilisé pour les valeurs des membres de l'`enum`. On peut utiliser un autre type entier en précisant le type dans la déclaration de l'`enum` :

```csharp
[Flags]
enum PhoneFeatures : byte
{
    Call = 0b00000001,
    Text = 0b00000010
}
```
