# À propos

Le [paquet `strings`](https://pkg.go.dev/strings) fournit des fonctions pour manipuler les _strings_.
En voici quelques-unes ; consulte la documentation pour découvrir les autres !

| Rôle                  | Fonction                                            | Objectif                                                             |
| --------------------- | --------------------------------------------------- | ------------------------------------------------------------------- |
| Conversion de casse   | [ToLower](https://pkg.go.dev/strings#ToLower)       | Convertir une _string_ en minuscules                                 |
| Conversion de casse   | [ToUpper](https://pkg.go.dev/strings#ToUpper)       | Convertir une _string_ en majuscules                                 |
| Recherche             | [Contains](https://pkg.go.dev/strings#Contains)     | Vérifier si une _string_ contient une sous-chaîne donnée             |
| Recherche             | [Count](https://pkg.go.dev/strings#Count)           | Compter les occurrences d'une sous-chaîne sans chevauchement         |
| Recherche             | [HasPrefix](https://pkg.go.dev/strings#HasPrefix)   | Vérifier si une _string_ commence par une sous-chaîne donnée         |
| Recherche             | [HasSuffix](https://pkg.go.dev/strings#HasSuffix)   | Vérifier si une _string_ se termine par une sous-chaîne donnée       |
| Recherche             | [Index](https://pkg.go.dev/strings#Index)           | Renvoyer l'indice de la première occurrence d'une sous-chaîne, ou -1 |
| Modification          | [Replace](https://pkg.go.dev/strings#Replace)       | Remplacer jusqu'à n occurrences d'une sous-chaîne                    |
| Modification          | [ReplaceAll](https://pkg.go.dev/strings#ReplaceAll) | Remplacer toutes les occurrences d'une sous-chaîne                   |
| Modification          | [TrimSpace](https://pkg.go.dev/strings#TrimSpace)   | Supprimer les espaces en début et en fin de chaîne                   |
| Découpage et assemblage | [Fields](https://pkg.go.dev/strings#Fields)       | Découper une _string_ en mots selon les espaces                      |
| Découpage et assemblage | [FieldsSeq](https://pkg.go.dev/strings#FieldsSeq) | Obtenir chaque mot un par un                                         |
| Découpage et assemblage | [Join](https://pkg.go.dev/strings#Join)           | Assembler un _slice_ de _strings_ avec un séparateur                 |
| Découpage et assemblage | [Split](https://pkg.go.dev/strings#Split)         | Découper une _string_ en parties selon un séparateur                 |
| Découpage et assemblage | [SplitSeq](https://pkg.go.dev/strings#SplitSeq)   | Obtenir chaque partie une par une                                    |

```go
import (
    "fmt"
    "strings"
)

// Case conversion
strings.ToLower("Gopher")              // "gopher"
strings.ToUpper("Gopher")              // "GOPHER"

// Searching
strings.Contains("Apple", "le")        // true
strings.Index("Apple", "le")           // 3
strings.Index("Apple", "xyz")          // -1
strings.Count("test", "t")             // 2
strings.HasPrefix("Gopher", "Go")      // true
strings.HasSuffix("Gopher", "er")      // true

// Modifying
strings.TrimSpace("  hello  ")         // "hello"
strings.Replace("aabbcc", "b", "x", 1) // "aaxbcc"
strings.ReplaceAll("aabbcc", "b", "x") // "aaxxcc"

// Splitting or Joining
strings.Fields("  a b\tc  ")               // []string{"a", "b", "c"}
strings.Split("a,b,c", ",")                // []string{"a", "b", "c"}
strings.Join([]string{"a", "b", "c"}, ",") // "a,b,c"

// You do not need to worry about this range syntax yet.
// It is covered later in the range iteration concept.
for word := range strings.FieldsSeq("  a b\tc  ") {
    fmt.Println(word)
}
// Output:
// a
// b
// c

for part := range strings.SplitSeq("a,b,c", ",") {
    fmt.Println(part)
}
// Output:
// a
// b
// c
```
