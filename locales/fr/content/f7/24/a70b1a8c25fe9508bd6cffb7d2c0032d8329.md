# Introduction

## Les expressions régulières en JavaScript

Une [expression régulière][mdn-regular-expressions] (ou regex) est une suite de caractères qui permet de cibler et de manipuler certains éléments dans des _strings_. On peut donc :

- **Rechercher** un texte dans une _string_
- **Remplacer** des sous-chaînes dans une _string_
- **Extraire** des informations d'une _string_

> 💡 La variante de regex utilisée par JavaScript fait partie du standard ECMA-262 du langage. Cela signifie que tu n'as pas à te soucier de la compatibilité propre aux navigateurs.

## Comment créer des expressions régulières

En JavaScript, une expression régulière s'écrit le plus souvent sous la forme `/pattern/modifiers`.

Il y a deux façons de créer une expression régulière :

1. **Littéral d'expression régulière** :

```javascript
const regex = /[a-z]/;
```

2. Le constructeur **RegExp** :

```javascript
const regex = new RegExp('[a-z]');
```

Dans les deux cas, JavaScript crée un objet à partir de l'expression régulière. Il est recommandé d'utiliser par défaut le littéral, dont les motifs sont immuables.

Le constructeur RegExp peut être utilisé dans les cas où l'expression régulière va changer ou n'est pas encore connue (comme une entrée utilisateur).

## 🏴‍☠️ Les flags

Les expressions régulières ont des superpouvoirs optionnels appelés [`flags`][mdn-flags], qui offrent des fonctionnalités supplémentaires.

Voici quelques-uns des plus utilisés :

- `/g` : recherche globale
- `/i` : insensible à la casse
- `/m` : recherche multiligne

Voici un exemple simple :

```javascript
const re = /home/gi;
const str = 'Home, sweet home.';
const myArray = str.match(re);
console.log(myArray);

// => ["Home", "home"]
```

Le caractère `g` permet de récupérer toutes les correspondances possibles dans une _string_. Sans cette option, JavaScript n'aurait extrait que la première correspondance, `Home`.

Le flag `/i`, insensible à la casse, rend la recherche d'un motif plus souple. Peu importe alors que ce que l'on cherche soit en `UPPERCASE` ou en `lowercase`.

Lorsque l'on utilise le constructeur `RegExp`, la syntaxe pour ajouter les flags est différente.

```javascript
let regex = /[a-z]/gi; // literal notation
let regex = new RegExp('[a-z]', 'gi'); // constructor with string pattern as first argument
let regex = new RegExp(/[a-z]/, 'gi'); // constructor with regular expression literal as first argument (Starting with ECMAScript 6)
```

## Les fonctions les plus courantes

Lorsque l'on combine les expressions régulières avec les fonctions natives de JavaScript, on dispose de moyens puissants pour manipuler des _strings_ et en extraire des données.

Voici quelques-unes des fonctions les plus couramment utilisées avec les expressions régulières.

### Test

La méthode [test()][mdn-regex-test]] recherche une correspondance entre une expression régulière et une _string_ donnée. Elle renvoie vrai ou faux.

```javascript
const str = 'It is difficult to test if you have a virus';
const result = /virus$/.test(str);

console.log(result);

// => true
```

### Match

Avec la méthode [match()][mdn-regex-match], on obtient un tableau utile dont le contenu dépend de la présence ou de l'absence des correspondances trouvées.

Ainsi, on peut à la fois **rechercher** et **extraire** des informations de n'importe quelle _string_. Par exemple :

```javascript
const funnyQuote =
  'If you see someone crying, ask if it is because of their haircut.';
const regex1 = /someone/;
const regex2 = /happy/;

funnyQuote.match(regex1);
// => ["someone", index: 3, input: "If you see someone crying, ask if it is because of their haircut.", groups: undefined]

funnyQuote.match(regex2);
// => null
```

Lorsque le flag de recherche globale `/g` est présent, au lieu d'obtenir la seule correspondance accompagnée d'informations utiles comme l'indice ou l'entrée, la méthode renvoie toutes les occurrences, affichées dans le tableau :

```javascript
const funnyQuote =
  'If you see someone crying, ask if it is because of their haircut.';

const regex3 = /if/gi;

funnyQuote.match(regex3);
// => ["If", "if"];
```

### Remplacer

La méthode [replace()][mdn-regex-replace] de JavaScript permet de rechercher une valeur dans une _string_ donnée et de la remplacer par une nouvelle valeur.

```javascript
string.replace(searchValue, newValue);
```

Le motif de recherche de la substitution peut être une simple _string_ ou une expression régulière.

```javascript
let string = 'I like dogs!';
let result = string.replace('dogs', 'cats');

let string = 'I would love to travel to Japan';
let result = string.replace(/Japan/g, 'Hawaii');
```

De plus, on peut passer une fonction à la place de la valeur de remplacement afin de modifier davantage chaque valeur.

```javascript
let text = 'Say hello to the chatbot.';
let result = text.replace(/chatbot|hello/gi, function (word) {
  return word.toUpperCase();
});

// => "Say HELLO to the CHATBOT"
```

### Diviser

La méthode [split()][mdn-regex-split] de JavaScript est une autre façon d'utiliser les expressions régulières pour manipuler des _strings_.

On utilise ici une expression régulière pour diviser une _string_ donnée en reconnaissant un motif, par exemple `str.split(/[,.\s]/)`. Ce motif sert alors de `separator`.

```javascript
const str = 'hello,user.how are.you';

const result = str.split(/[,.\s]/);

console.log(result);
// => ['hello', 'user', 'how', 'are', 'you']
```
