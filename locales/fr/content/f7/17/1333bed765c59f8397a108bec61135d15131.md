# Instructions supplémentaires

## Instructions spécifiques au parcours

Voici ce que tu dois savoir sur le format des entrées :

- **Argument de gauche** : le diagramme qui représente la disposition du jardin, fourni sous la forme d'un tableau de caractères dont le `tally` vaut 2.
- **Argument de droite** : le nom de l'élève, fourni sous forme d'une _string_.

Ta fonction sera appelée avec ces arguments, comme ceci :

```j
  diagram=. 2 24$'VRCGVVRVCGGCCGVRGCVCGCGVVRCCCGCRRGVCGCRVVCVGCGCV'
  student=. 'Fred'
  
  diagram plants student
```
