# À propos

Idris est un langage de programmation fonctionnel pur d'usage général, doté de [types dépendants](http://en.wikipedia.org/wiki/Dependent_type).
Les types dépendants permettent de définir des types en fonction de valeurs,
ce qui signifie que certains aspects du comportement d'un programme peuvent être spécifiés précisément dans le type.
Il est compilé, avec une [évaluation stricte](http://en.wikipedia.org/wiki/Eager_evaluation).
Ses fonctionnalités s'inspirent de Haskell et de ML, et incluent notamment :

- Types dépendants complets avec filtrage par motif dépendant
- Interface de fonctions étrangères simple (vers C)
- Édition interactive assistée par le compilateur : le compilateur aide à écrire du code à partir des types
- clauses where, avec la règle with, les expressions case simples, le filtrage par motif dans les liaisons let et lambda
- Enregistrements dépendants avec projection et mise à jour
- Interfaces (similaires aux classes de types de Haskell)
- Résolution de surcharge guidée par les types
- Notation do et crochets d'idiome
- Syntaxe significative à l'indentation
- Syntaxe extensible
- Univers cumulatifs
- Vérification de la totalité
- Environnement interactif à la manière de [Hugs](http://www.haskell.org/hugs/)
