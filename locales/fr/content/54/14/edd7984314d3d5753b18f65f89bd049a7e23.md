# Introduction

En Julia, un `String` est une suite finie et immuable de caractères [Unicode](https://en.wikipedia.org/wiki/Unicode), en encodage [UTF-8](https://en.wikipedia.org/wiki/UTF-8).

Un littéral `String` est une suite de caractères entourée de guillemets doubles :

```julia-repl
julia> "Christopher"
"Christopher"
```

On peut concaténer des _strings_ avec l'opérateur `*` :

```julia-repl
julia> "Christopher" * " " * "Paolini"
"Christopher Paolini"
```

~~~~exercism/advanced
Si tu es curieux de savoir pourquoi Julia utilise `*` plutôt que `+` pour la concaténation de chaînes, jette un œil au [manuel de Julia](https://docs.julialang.org/en/v1/manual/strings/#man-concatenation).
~~~~

Certains caractères spéciaux doivent être échappés en les faisant précéder d'une barre oblique inverse :

```julia-repl
julia> println("\t or spaces?")
         or spaces?
```

Julia propose par défaut de nombreuses fonctions utiles pour travailler sur les _strings_ :

```julia-repl
julia> lowercase("TEST")
"test"

julia> titlecase("TEST")
"Test"
```
