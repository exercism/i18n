# Ajout aux instructions

## Mots

`smallest` et `largest` renvoient chacun **deux** valeurs sur la pile : la
valeur palindrome (ou `f` s'il n'en existe aucune dans l'intervalle) et un
tableau de paires de facteurs.

- `smallest ( mn mx -- value factors )`
- `largest  ( mn mx -- value factors )`

Chaque paire dans `factors` est un tableau de 2 éléments `{ a b }`. Lève la
_string_ `"min must be <= max"` si `mn > mx`.
