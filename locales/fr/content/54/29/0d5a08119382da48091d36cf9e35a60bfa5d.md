# Introduction

## Opérateurs de comparaison

Les opérateurs de comparaison sont similaires à ceux de nombreux autres langages.

Pour l'égalité, les opérateurs sont `==` (égal) et `!=` (différent).

```Kotlin
val txt = "abc"
txt == "abc" // => true
txt != "abc" // => false
```

Les opérateurs supérieur et inférieur sont eux aussi classiques.

```Kotlin
1 < 3 // => true
3 > 3 // => false
3 <= 3 // => true
4 >= 3 // => true
```

## Crée des branches avec `if`

Voici la forme complète d'une expression `if` :

```Kotlin
if (conditional1) {
//    something...
} else if (conditional2) {
//    something...
} else {
//    something...
}
```

- Les parenthèses `()` autour de chaque condition sont obligatoires.
- Une condition doit s'évaluer à un booléen `true` ou `false`.
  Kotlin ne connaît pas la notion de « truthy » et de « falsy » que l'on trouve dans certains langages.
- Les accolades `{}` sont facultatives s'il n'y a qu'une seule expression.
- `else if` et `else` sont tous les deux facultatifs, et il peut y avoir plusieurs blocs `else if`.

L'expression `if` peut aussi servir à « choisir » une valeur :

```Kotlin
val number = 100000
val description = if (number > 100) "number is over 100" else "number is less than 100"
// => description = "number is over 100"
```

## Des alternatives ?

Par choix délibéré, Kotlin ne dispose _pas_ de l'opérateur ternaire `? :` que l'on trouve en Java.
On préfère une forme concise de `if ... else` :

```Kotlin
return if (isOK) goodValue else badValue
```
