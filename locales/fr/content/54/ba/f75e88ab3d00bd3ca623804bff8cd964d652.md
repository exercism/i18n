# Introduction

Les énumérations en Swift sont un mécanisme qui permet de créer de nouveaux types, habités par un nombre fini de valeurs nommées, qui peuvent porter des informations associées supplémentaires et auxquels on peut attacher des propriétés et des méthodes.

## Définis des énumérations

Les énumérations les plus simples se définissent comme ci-dessous.

```swift
enum NESButton {
  case up
  case down
  case left
  case right
  case a
  case b
  case select
  case start
}
```

Pour aller plus vite, on peut aussi écrire plusieurs cas sur une seule ligne, séparés par des virgules, avec un seul mot-clé `case`.

```swift
enum NESButton {
  case up, down, left, right, a, b, select, start
}
```

On définit ainsi un nouveau type nommé `NESButton` avec les valeurs possibles `up`, `down`, `left`, `right`, `a`, `b`, `select` et `start`. On peut désigner ces valeurs en faisant suivre le nom du type d'un point (`.`) et de la valeur. Quand le nom du type peut être déduit, seuls le point et la valeur sont nécessaires.

## Méthodes

Comme les autres types en Swift, les énumérations peuvent contenir des méthodes, qui leur permettent de fournir des fonctionnalités en fonction de leur valeur courante.

Les méthodes sont analogues à des fonctions, à ceci près qu'elles sont définies dans le corps de l'énumération et liées à sa valeur courante. On y accède par la notation pointée, où le nom de la valeur de l'énumération est suivi d'un point (`.`) puis du nom de la méthode et de ses paramètres.

À l'intérieur de la méthode, on peut désigner la valeur de l'énumération par `self` et, dans la signature de type, si l'on accepte en paramètre ou renvoie une valeur de l'énumération, on peut désigner le type par `Self`.

### Initialiseurs

Les initialiseurs sont des méthodes spéciales qui servent à construire une valeur de l'énumération. Leur définition ressemble beaucoup à celle d'une méthode, hormis qu'il n'y a pas de mot-clé `func`, pas de type de retour, que le nom doit être `init` et que l'initialiseur _doit_ affecter une valeur de l'énumération à `self`. On appelle un initialiseur soit par la notation pointée, soit en passant ses paramètres au nom de l'énumération.

```swift
enum Coin {
  case heads
  case tails

  init(_ i: Int) {
    if i.isMultiple(of: 2) {
      self = .heads
    } else {
      self = .tails
    }
  }

  func flip() -> Self {
    switch self {
    case .heads: return .tails
    case .tails: return .heads
    }
  }
}

let tails = Coin.init(13)
// .tails
let heads = Coin(0)
// .heads
let anotherTails = heads.flip()
// .tails
```

### Valeurs brutes

Les énumérations peuvent aussi porter une valeur interne appelée _valeur brute_. Toutes les valeurs brutes doivent être du même type, déclaré dans la définition de l'énumération. On peut donc, par exemple, affecter des valeurs de type `Character` à notre énumération `NESButton` en modifiant la définition :

```swift
enum NESButton: Character {
  case up = "⬆️"
  case down = "⬇️"
  case left = "⬅️"
  case right = "➡️"
  case a = "🅰️"
  case b = "🅱️"
  case select = "✅"
  case start = "🚦"
}
```

Ici, `: Character` indique au compilateur que les valeurs brutes seront de type `Character` et l'affectation de la valeur brute suit chaque valeur.

On peut accéder aux valeurs brutes par la propriété `rawValue` générée automatiquement pour chaque valeur.

```swift
NESButton.left.rawValue
// => "⬅️"
NESButton.b.rawValue
// => "🅱️"
```

Swift peut attribuer implicitement des valeurs brutes pour les valeurs brutes de type `String` et `Int`. Si l'on spécifie un type de valeur brute `String`, la valeur brute est implicitement affectée au nom de la valeur sous forme de _String_, sauf si la valeur implicite est remplacée par une affectation explicite.

Si l'on spécifie un type de valeur brute `Int`, la valeur brute est implicitement affectée à un entier 1 plus grand que la valeur brute du cas précédent, sauf si elle est remplacée par une affectation explicite. La valeur brute par défaut du premier cas est 0, sauf indication contraire.

```swift
enum Coin: String {
  case heads
  case tails = "eagle"
}

Coin.heads.rawValue
// => "heads"
Coin.tails.rawValue
// => "eagle"

enum Dwarf: Int {
  case grumpy, sleepy, sneezy, happy = 8, bashful, dopey, doc
}

Dwarf.grumpy.rawValue
// => 0
Dwarf.sneezy.rawValue
// => 2
Dwarf.happy.rawValue
// => 8
Dwarf.bashful.rawValue
// => 9
```
