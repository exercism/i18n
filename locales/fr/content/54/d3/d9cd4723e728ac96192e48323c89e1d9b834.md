# À propos

En Gleam, une expression `case` permet d'exécuter du code de manière conditionnelle. Avec une expression `case`, on peut comparer une valeur à un ou plusieurs _motifs_. Le _motif littéral_ en est un exemple : il fait correspondre une valeur à une valeur littérale (par exemple `1` ou `"hello"`).

Les expressions `case` s'écrivent avec le mot-clé `case` :

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    1 -> "One"
  }
}
```

Cela peut ressembler aux instructions `switch` d'autres langages, mais la correspondance de motifs révèle tout son intérêt lorsqu'on utilise aussi d'autres motifs. L'un d'eux est le _motif de variable_, qui permet d'affecter une valeur à une variable. Dans cet exemple, la variable `i` se voit affecter la valeur de `number` si celui-ci n'est pas `0` :

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i -> "Non zero"
  }
}
```

Dans certains cas, on peut vouloir ajouter une condition supplémentaire à un motif. C'est ce qu'on appelle une _garde_ (une clause), que l'on ajoute avec le mot-clé `if` :

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i if i < 0 -> "Negative number"
  }
}
```

Pour des raisons de performance, seuls les opérateurs mathématiques et booléens de base sont autorisés dans les gardes ; aucune autre fonction ne peut y être utilisée.

Dans l'exemple ci-dessus, toutes les entrées possibles n'ont pas de motif correspondant. Le compilateur le détecte et affiche une erreur. C'est ce qu'on appelle la _vérification exhaustive_. Pour faire disparaître l'avertissement, il faut gérer tous les cas. Pour cela, on peut utiliser le _motif joker_, un motif qui correspond à n'importe quelle valeur :

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i if i < 0 -> "Negative number"
    _ -> "Positive number"
  }
}

// No compiler error
```

Une expression `case` teste une valeur contre chaque motif, de haut en bas, jusqu'à ce qu'elle trouve un motif correspondant et exécute la logique associée à ce motif. L'ordre des motifs a son importance !
