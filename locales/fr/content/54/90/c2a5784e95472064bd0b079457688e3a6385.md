# Aide

Quelques pistes pour trouver de l'aide sur tes questions de Tcl :

* le _tag_ `tcl` sur [Stack Overflow](https://stackoverflow.com/tags/tcl).
* consulte la section Resources de la [page d'informations du _tag_ `tcl` de Stack Overflow](https://stackoverflow.com/tags/tcl/info).
* ouvre une _issue_ dans le dépôt [exercism/tcl](https://github.com/exercism/tcl) sur GitHub.
