# À propos

Les nombres décimaux sont des nombres qui ont un ou plusieurs chiffres après le séparateur décimal.

```gleam
let float = 3.45
// -> 3.45
```

Les nombres décimaux ont eux aussi leur propre ensemble d'opérateurs.

```gleam
1.0 +. 1.4 // -> 2.4
5.0 -. 1.5 // -> 3.5
5.0 /. 2.0 // -> 2.5
3.0 *. 3.1 // -> 9.3

2.0 >. 1.0  // -> True
2.0 <. 1.0  // -> False
2.0 >=. 1.0 // -> True
2.0 <=. 1.0 // -> False
```

On peut également ajouter des tirets bas aux nombres décimaux pour plus de clarté.

```gleam
1_000_000.0 // One million
```

On peut aussi utiliser la notation scientifique avec les nombres décimaux :

```gleam
1.01e3 // -> 1010
15.1e-3 // -> 0.0151
```
