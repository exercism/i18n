# Introduction à la conversion de type

Go exige une conversion explicite entre les différents types.
La conversion entre types (aussi appelée **transtypage**) se fait au moyen d'une fonction qui porte le nom du type de destination.
Par exemple, pour convertir un `int` en `float64`, il faut faire ce qui suit :

```go
var x int = 42 // x has type int
f := float64(x) // f has type float64 (ie. 42.0)
```

## Conversion entre types primitifs et _strings_

Il existe un paquet `strconv` pour convertir entre les types primitifs (comme `int`) et `string`.

```go
import "strconv"

var intString string = "42"
var i, err = strconv.Atoi(intString)

var number int = 12
var s string = strconv.Itoa(number)
```
