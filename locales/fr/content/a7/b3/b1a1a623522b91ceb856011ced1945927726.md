# À propos

JavaScript possède un opérateur d'incrémentation et un opérateur de décrémentation.
Ils modifient une variable sur place.
`++` ajoute 1 à un nombre, `--` soustrait 1 à un nombre.

```javascript
let i = 3;
i++;
// i is now 4

let j = 0;
j--;
// j is now -1
```

L'exemple ci-dessus montre l'opérateur d'incrémentation et de décrémentation postfixé.
Dans ce cas, l'opérateur est placé après la variable et la valeur de retour de l'expression est la valeur de la variable _avant_ l'incrémentation ou la décrémentation.

```javascript
let a = 3;
let b = a++;
// a = 4
// b = 3
```

Il existe aussi la variante préfixée, où l'opérateur est placé avant la variable.
La valeur de retour est alors la valeur de la variable _après_ l'incrémentation ou la décrémentation.

```javascript
let a = 3;
let b = ++a;
// a = 4
// b = 4
```
