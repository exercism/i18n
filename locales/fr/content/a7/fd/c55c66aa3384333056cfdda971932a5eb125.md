# Indices

## Général

- `case` (dans [`combinators`][combinators]) est le bon outil pour faire correspondre des valeurs égales ; `cond` est le bon outil pour les prédicats gardés.
- Les symboles (`yes`, `no`, `maybe`, `korean`, …) sont déjà déclarés via `SYMBOLS:` dans le fichier de l'exercice.

## 1. Évalue la cuisine

- Un `case` à deux clauses qui associe `korean` et `turkish` à leurs valeurs d'approbation.

## 2. Évalue le genre de film

- Fais correspondre `romance` et mets `[ drop no ]` comme valeur par défaut pour le reste. N'oublie pas que la branche par défaut voit la valeur d'origine au sommet de la pile ; supprime-la avant de pousser le résultat.

## 3. Évalue la balade

- Utilise `cond` (aussi dans `combinators`) ; chaque garde est `[ dup N > ]`. Le corps doit faire un `drop` des kilomètres avant de pousser la valeur d'approbation.

## 4. Évalue l'activité

- L'activité est `{ tag value }`. Utilise `first2` pour pousser les deux sur la pile, puis `swap` pour que le tag soit au sommet ; c'est ce que `case` compare.
- Les branches pour `board-game` et `chill` voient la valeur (`f`) encore sur la pile ; fais un `drop` avant de pousser la valeur d'approbation.
- Les branches pour `movie`, `restaurant` et `walk` voient la valeur concernée encore sur la pile, tu peux donc appeler directement ton mot de la tâche 2/1/3.
