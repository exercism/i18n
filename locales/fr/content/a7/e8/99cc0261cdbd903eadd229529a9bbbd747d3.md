# Introduction

## L’héritage

L’héritage est un concept fondamental de la POO (programmation orientée objet).
Il représente une relation de type EST-UN.
En programmation, cela veut littéralement dire la même chose qu’en anglais : hériter de caractéristiques d’un parent (en programmation, ces caractéristiques sont généralement des fonctions et des variables).

Prenons une classe `Animal`, comme ci-dessous :

```java
//Creating an Animal class with bark() as a member function.
public class Animal {

    public void bark() {
        System.out.println("This is an animal");
    }

}
```

`Animal` est une classe parente, car les propriétés de cette classe peuvent être étendues à tous les animaux en général.

Prenons un animal nommé `Lion`, avec une classe comme celle-ci :

```java
//Lion class is a child class of Animal.
public class Lion extends Animal {

    @Override
    public void bark() {
        System.out.println("Lion here!!");
    }

}
```

~~~~exercism/note
L’annotation `Override` indique qu’une méthode d’une sous-classe redéfinit une méthode de sa superclasse.
Elle n’est pas strictement nécessaire, mais c’est une bonne pratique de l’utiliser.
~~~~

Maintenant, chaque fois qu’on écrit :

```java
Animal animal = new Lion(); //creating instance of Animal, of type Lion
animal.bark();
```

Remarque : on initialise la classe `Animal` avec `Lion`.
Le résultat ressemblera à ceci :

```java
Lion here!!
```

Selon la POO, il existe de nombreux types d’héritage, mais Java n’en prend en charge que quelques-uns (multi-niveaux et hiérarchique).
Pour en savoir plus, lis [ceci][java-inheritance].
