# Représentations

Le [_representer_][representer] applique les normalisations suivantes :

- [Tous les commentaires et la documentation sont supprimés][remove-comments-and-docs]
- [Les imports des modules et des fonctions sont triés][sort-imports-order]
- [Le code est mis en forme avec `mix format`][format-code]
- [Les identifiants sont normalisés en une valeur de remplacement][normalize-identifiers]
- [Les clés sont triées dans les _maps_ et les _structs_][sort-keys-in-maps-and-structs]
