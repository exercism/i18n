# Erreurs de compilation

Le code contient une ou plusieurs erreurs de compilation, ce qui empêche l'exécution de la suite de tests. Pour trouver comment corriger ces erreurs, une bonne première étape consiste à examiner les messages d'erreur qui s'affichent lorsque l'on essaie de compiler le code. Ces messages d'erreur contiennent un numéro et une description, ce qui aide à identifier précisément le problème.
