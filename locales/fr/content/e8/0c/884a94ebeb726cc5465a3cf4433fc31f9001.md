# Introduction

## Les conditionnels `if`

### Les opérateurs logiques

Java prend en charge trois opérateurs logiques : `&&` (ET), `||` (OU) et `!` (PAS).

### L'instruction `if`

Le type sous-jacent de toute opération conditionnelle est le type `boolean`, qui peut prendre la valeur `true` ou `false`. Les conditionnelles servent souvent de mécanismes de contrôle de flux pour vérifier diverses conditions. Pour vérifier un cas particulier, on peut utiliser une instruction `if`, qui exécute son code si la condition sous-jacente vaut `true`, comme ceci :

```java
int val;

if(val == 9) {
    // conditional code
}
```

Dans les scénarios impliquant plus d'un cas, on peut enchaîner plusieurs instructions `if` à l'aide des instructions `else if` et `else`.

```java
if(val == 10) {
    // conditional code
} else if(val == 17) {
    // conditional code
} else {
    // executes when val is different from 10 and 17
}
```

### L'instruction `switch`

Java fournit également une instruction `switch` pour les scénarios comportant plusieurs options.

```java
int val;

// switch statement on variable content
switch(val) {
    case 1:
        // conditional code
        break;
    case 2: case 3: case 4:
        // conditional code
        break;
    default:
        // if all cases fail
        break;
}
```
