# Instructions

Dans cet exercice, tu dois implémenter quelques fonctions pour manipuler une liste de langages de programmation.

## 1. Définis une fonction qui renvoie une liste de langages vide

Définis la fonction `new/0`, qui ne prend aucun argument et renvoie une liste vide.

```elixir
LanguageList.new()
# => []
```

## 2. Définis une fonction qui ajoute un langage à la liste

Définis la fonction `add/2`, qui prend 2 arguments (une _liste de langages_ et un littéral de type _string_ représentant un _langage_). Elle doit renvoyer la liste résultante, avec le nouveau langage ajouté au début de la liste donnée.

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Clojure")
# => ["Clojure"]
language_list = LanguageList.add(language_list, "Haskell")
# => ["Haskell", "Clojure"]
```

## 3. Définis une fonction qui retire un langage de la liste

Définis la fonction `remove/1`, qui prend 1 argument (une _liste de langages_). Elle doit renvoyer la liste sans son premier élément. On considère que la liste contient toujours au moins un élément.

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Clojure")
# => ["Clojure"]
language_list = LanguageList.add(language_list, "Haskell")
# => ["Haskell", "Clojure"]
language_list = LanguageList.remove(language_list)
# => ["Clojure"]
```

## 4. Définis une fonction qui renvoie le premier élément de la liste

Définis la fonction `first/1`, qui prend 1 argument (une _liste de langages_). Elle doit renvoyer le premier langage de la liste. On considère que la liste contient toujours au moins un élément.

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Elm")
# => ["Elm"]
language_list = LanguageList.add(language_list, "Prolog")
# => ["Prolog", "Elm"]
LanguageList.first(language_list)
# => "Prolog"
```

## 5. Définis une fonction qui renvoie le nombre de langages de la liste

Définis la fonction `count/1`, qui prend 1 argument (une _liste de langages_). Elle doit renvoyer le nombre de langages présents dans la liste.

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Elm")
# => ["Elm"]
language_list = LanguageList.add(language_list, "Prolog")
# => ["Prolog", "Elm"]
LanguageList.count(language_list)
# => 2
```

## 6. Définis une fonction qui détermine si la liste contient un langage fonctionnel

Définis la fonction `functional_list?/1`, qui prend 1 argument (une _liste de langages_). Elle doit renvoyer une valeur booléenne. Elle doit renvoyer vrai si « Elixir » fait partie des langages de la liste.

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Elixir")
# => ["Elixir"]
LanguageList.functional_list?(language_list)
# => true
```
