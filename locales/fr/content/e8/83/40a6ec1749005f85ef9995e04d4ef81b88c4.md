# Instructions supplémentaires

## Registres

| Registre | Utilisation | Type    | Description                                                          |
| -------- | ----------- | ------- | -------------------------------------------------------------------- |
| `$a0`    | entrée      | adresse | _string_ terminée par un caractère nul, composée de caractères octaux |
| `$v0`    | sortie      | entier  | valeur décimale de la _string_ d'entrée                              |
| `$t0-9`  | temporaire  | quelconque | utilisé pour un stockage temporaire                               |
