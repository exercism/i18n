# Introduction

## Agent

Le module `Agent` fournit une abstraction pour lancer des [processus et la boucle _receive-send_][exercism-processes]. Désormais, on appellera _« agent processes »_ les processus démarrés avec le module `Agent`. On peut choisir un _agent process_ pour représenter un état partagé central.

Pour démarrer un _agent process_, `Agent` fournit la fonction `start/2`. La fonction que l'on fournit à `start` pour démarrer l'_agent process_ renvoie l'état initial du processus :

```elixir
# Start an agent process with an initial value of an empty list
{:ok, agent_pid} = Agent.start(fn -> [] end)
```

Tout comme `Map` ou `List`, `Agent` fournit de nombreuses fonctions pour manipuler les _agent processes_.

Il est d'usage d'organiser et d'encapsuler toutes les fonctionnalités liées à `Agent` dans un module dédié au domaine que l'on modélise.

[exercism-processes]: https://exercism.org/tracks/elixir/concepts/processes
