# Ajout aux instructions

## Implémentation

Si le dernier élément du tableau est un `object` plutôt qu'une `string`, il contient un qualificatif qui modifie la dernière ligne du proverbe.

```javascript
proverb('nail', 'shoe', { qualifier: 'horseshoe' });
// => For want of a nail the shoe was lost.
//    And all for the want of a horseshoe nail.
```
