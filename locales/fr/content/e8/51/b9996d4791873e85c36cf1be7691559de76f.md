# Le reste

En mathématiques, le **reste** est ce qui « reste » après avoir effectué un calcul.
Par exemple, le reste de `5 / 3` est `2`.

De nombreux langages de programmation utilisent le signe pourcentage (`%`) comme opérateur pour calculer le reste.
Par exemple :
```javascript
5 % 3 == 2
```

Le reste peut souvent se calculer aussi bien sur des nombres entiers que sur des nombres décimaux.
Par exemple,
```javascript
5.3 % 3 == 2.3
```

Lorsqu'on travaille avec des nombres négatifs, le résultat a toujours le même signe que le dividende (le nombre situé à gauche de l'opérateur, celui que l'on divise).
Par exemple :
```javascript
-5 % 3 == -2
5 % -3 == 2
-5 % -3 == -2
```

Certains langages (comme Python) utilisent l'opérateur `%` pour calculer le modulo, et non le reste.
Ces langages traitent les nombres négatifs différemment.
Tu peux en apprendre davantage à ce sujet [sur Wikipédia](https://en.wikipedia.org/wiki/Modulo).
