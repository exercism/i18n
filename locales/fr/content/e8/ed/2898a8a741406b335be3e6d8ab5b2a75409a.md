# Introduction

Les conditionnelles de Factor choisissent entre des **quotations**, des extraits de code écrits entre crochets, `[ ... ]`. Écrire `[ ... ]` place le code sur la pile en tant que valeur plutôt que de l'exécuter, puis la conditionnelle décide quelle quotation exécuter. (Les quotations sont traitées en détail dans un exercice ultérieur.)

`if` (dans [`kernel`][kernel]) est la conditionnelle de base de Factor. Il prend un booléen et deux quotations, exécute la première si le booléen est vrai et la seconde sinon.

```
if ( ? then-quot else-quot -- )
```

```factor
: abs ( x -- y ) dup 0 < [ neg ] [ ] if ;
```

`when` n'exécute sa quotation que si le booléen est vrai, `unless` seulement s'il est faux. Pour les branchements à plusieurs voies, il y a `cond` (dans [`combinators`][combinators]) :

```factor
USING: combinators ;

: classify ( n -- s )
    {
        { [ dup 0 <  ] [ drop "negative" ] }
        { [ dup 0 =  ] [ drop "zero"     ] }
        [ drop "positive" ]
    } cond ;
```
