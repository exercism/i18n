# Introduction

Il arrive qu'un morceau d'état doive être partagé entre plusieurs mots sans avoir à le faire passer par leur effet de pile à chaque fois. Les *variables dynamiques* de Factor, déclarées avec `SYMBOL:`, donnent à chaque mot accès à une valeur stockée dans un espace de noms.

## `SYMBOL:` et `SYMBOLS:`

`SYMBOL: name` déclare une variable. `SYMBOLS: a b c ;` en déclare plusieurs d'un coup :

```factor
USING: namespaces ;

SYMBOLS: counter total ;
```

## Définir et lire

`set-global` et `get-global` (dans [`namespaces`][namespaces]) agissent sur l'espace de noms global :

```
set-global    ( value variable -- )
get-global    ( variable -- value )
change-global ( variable quot: ( old -- new ) -- )
```

```factor
0 counter set-global
counter get-global .         ! => 0
counter [ 10 + ] change-global
counter get-global .         ! => 10
```

Pour un état au niveau du module, ce sont les variantes `-global` qu'il te faut.

## Liaisons à portée limitée avec `with-variable`

Une variable dynamique prend aussi en charge une seconde variante, *à portée limitée*. `set` / `get` / `change` (sans le suffixe `-global`) lisent et écrivent la portée dynamique *courante*, et `with-variable` (dans [`namespaces`][namespaces]) crée une nouvelle portée pendant toute la durée d'une *quotation* :

```
with-variable ( value variable quot -- )
set           ( value variable -- )
get           ( variable -- value )
change        ( variable quot: ( old -- new ) -- )
```

La variable est liée à `value` pendant l'exécution de `quot` ; dès que celle-ci se termine, la liaison disparaît. Cela permet à un appelant extérieur d'« injecter » une valeur que le code interne peut lire sans avoir à la faire passer par chaque signature de pile.

```factor
SYMBOL: greeting

"Hello" greeting [
    greeting get .                ! => "Hello"
    "Howdy" greeting set
    greeting get .                ! => "Howdy"
    greeting [ "!" append ] change
    greeting get .                ! => "Howdy!"
] with-variable

greeting get-global .    ! => f   (the scoped binding is gone)
```

Cet exercice n'utilise que la variante globale, mais reconnaître la famille parallèle `set`/`get`/`change` est utile quand tu lis le code des autres.

## Les vecteurs mutables

Comme les variables dynamiques contiennent une référence, tu peux y ranger une collection *mutable* et la modifier sur place :

```factor
SYMBOL: history

V{ } clone history set-global
"first event" history get-global push
"second event" history get-global push
history get-global .
! => V{ "first event" "second event" }
```

`V{ … }` est un vecteur littéral. Fais toujours un `clone` sur un littéral `V{ }` avant de le stocker : les littéraux sont partagés entre les appels.

## `find` : le premier élément correspondant

`find` (dans [`sequences`][sequences]) renvoie le premier élément pour lequel un prédicat renvoie vrai, ainsi que son indice :

```
find ( seq quot -- index elt/f )
```

Si rien ne correspond, les deux valeurs valent `f`. Écarter l'indice avec `nip` puis utiliser `unless*` est la combinaison standard pour obtenir une valeur par défaut en cas d'absence.

## `reject` : écarter les correspondances

`reject` (également dans [`sequences`][sequences]) est l'opposé de `filter` : il renvoie les éléments qui *ne satisfont pas* le prédicat.
