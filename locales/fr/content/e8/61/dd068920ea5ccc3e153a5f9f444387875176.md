# À propos

Une [boucle _while_][while-loops] est une instruction de contrôle de flux qui permet d'exécuter du code tant qu'une certaine condition est vraie.
Swift propose deux sortes de boucles _while_ : les boucles _while_ et les boucles _repeat-while_.
La condition d'une boucle _while_ est évaluée avant que le corps de la boucle soit exécuté ; si la condition est fausse, le corps de la boucle ne sera pas exécuté du tout.
Les boucles _while_ en Swift ont la structure suivante :

```swift
while <#condition#> {
  <#code#>
}
```

Ici, la boucle s'exécute tant que count est supérieur à 0, et affiche donc les nombres 2, 1 puis « Liftoff ! ».

```swift
var count = 2
while count > 0 {
  print("\(count)…")
  count -= 1
}
print("Liftoff!")

// prints:
// 2…
// 1…
// Liftoff!
```

Une [boucle _repeat-while_][while-loops] est similaire à une boucle _while_, mais la condition est évaluée après l'exécution du corps de la boucle.
Cela signifie que le corps de la boucle s'exécute toujours au moins une fois, même si la condition est fausse.
Les boucles _repeat-while_ en Swift ont la structure suivante :

```swift
repeat {
  <#code#>
} while <#condition#>
```

Ici, la boucle ne s'exécute qu'une seule fois, puisque la condition est fausse.
Comme il s'agit d'une boucle _repeat-while_, le corps de la boucle s'exécute une fois avant que la condition soit évaluée.

```swift
var count = 2
repeat {
  print("\(count)…")
} while count < 0
print("Liftoff!")
```

## Les boucles de liaison optionnelle

Une variante courante des boucles _while_ en Swift est la boucle _while_ à liaison optionnelle.
Ces boucles se répètent tant que l'appel à une fonction qui fournit une valeur optionnelle renvoie une valeur différente de `nil`.
Cette valeur (non optionnelle) est alors liée à un nom de ton choix et peut être utilisée dans le corps de la boucle.

```swift
var arr = [1,2]
while let count = arr.popLast() {
  print("\(count)…")
}
print("Liftoff!")

// prints:
// 2…
// 1…
// Liftoff!
```
