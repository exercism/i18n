# Apprentissage

Bash est un shell Unix très puissant et un langage de script pour les commandes, mais sa courbe d'apprentissage est assez raide.

* La [page de manuel](https://manpage.me/index.cgi?apropos=0&q=bash&sektion=1&manpath=Debian+7.8.0&arch=default&format=html)
  de Bash est un document bien écrit et instructif. Elle est en revanche très
  « dense » et demande à être lue et relue.

* D'autres guides, informations et exemples sont disponibles ici :
    * [Greg's Wiki](http://mywiki.wooledge.org/BashGuide),
    * le [Bash Hackers Wiki](https://web.archive.org/web/20230323071638/https://wiki.bash-hackers.org/),
    * la [page d'informations sur le tag bash](https://stackoverflow.com/tags/bash/info) sur
      Stack Overflow,
    * et, pour compléter la page de manuel, le [manuel GNU Bash](http://gnu.org/s/bash/manual)
      est _la_ source d'informations sur bash.

* [shellcheck.net](https://www.shellcheck.net/) propose une interface web
  (et un binaire pour certaines distributions) qui analyse les scripts shell
  à la recherche d'erreurs ou de problèmes courants, et explique comment les
  corriger au mieux.
