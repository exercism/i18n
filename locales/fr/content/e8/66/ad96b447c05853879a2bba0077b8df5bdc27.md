# Introduction

## Try/Rescue/Else/After

Utiliser `try..rescue` est une construction puissante pour intercepter les erreurs lorsqu'elles se produisent. Rattraper les erreurs permet aux fonctions de renvoyer des valeurs définies quand c'est nécessaire. La construction `try..rescue` nous offre aussi deux possibilités supplémentaires que l'on peut utiliser :

- le bloc `else`
  - Lorsque le bloc `try` réussit, le résultat est mis en correspondance avec ce bloc.
- le bloc `after`
  - Que le bloc `try` réussisse ou lève une erreur, le code du bloc `after` est toujours exécuté tant que le programme est en cours d'exécution à ce moment-là.
  - Le résultat du bloc `after` n'est pas renvoyé à la portée appelante.

```elixir
try do
  :a
rescue
  _ -> :error
else
  :a -> :success
after
  :some_action
end

# => :success
```

## Dispatch dynamique

Quand Elixir résout la fonction à invoquer, il utilise le nom du module pour effectuer une recherche. Cette recherche peut être effectuée dynamiquement si le nom du module est lié à une variable.

```elixir
defmodule MyModule do
  def message(), do: "My message"
end

atom = MyModule
atom.message()
# => "My message"
```

En interne, le nom d'un module est un atome. Tous les atomes de module d'Elixir sont automatiquement préfixés par `Elixir.`

```elixir
is_atom(Enum)
# => true
Enum == Elixir.Enum
# => true
```
