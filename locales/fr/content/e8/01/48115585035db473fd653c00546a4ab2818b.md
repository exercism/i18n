# À propos

En Rust, les booléens sont représentés par le type `bool`, dont la valeur peut être soit `true`, soit `false`.

Rust prend en charge un [opérateur de négation booléenne][negation operators] : `!` (NON).

Rust prend en charge six [opérateurs de comparaison][comparison operators] : `==` (égal à), `!=` (différent de), `>` (supérieur à), `<` (inférieur à), `>=` (supérieur ou égal à), `<=` (inférieur ou égal à). Ils permettent d'évaluer la relation entre des valeurs non booléennes pour obtenir une valeur booléenne.

```rust
1 > 0 // true
1 < 0 // false
1 == 0 // false
1 != 0 // true
1 >= 0 // true
1 <= 0 // false
```

Contrairement à certains autres langages, `0` n'est pas `false` et une valeur non nulle n'est pas `true`.

Rust prend en charge trois [opérateurs binaires logiques][logical binary operators] : `&` (ET logique), `|` (OU logique), `^` (OU exclusif).

Rust prend en charge deux [opérateurs booléens][lazy boolean operators] : `||` (OU) et `&&` (ET). Ils diffèrent de `|` et `&` en ce que l'opérande de droite n'est évalué que si l'opérande de gauche ne détermine pas déjà le résultat de l'expression. Autrement dit, `||` n'évalue son opérande de droite que lorsque l'opérande de gauche vaut `false`, et `&&` seulement lorsque celui-ci vaut `true`.

```rust
true || false // == true; the right-hand side was not evaluated
true && false // == false
```
