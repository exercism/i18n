# À propos

Les [_closures_][closures] en Swift sont des blocs de code autonomes auxquels on peut passer des paramètres pour déclencher leur exécution et renvoyer des valeurs. Les closures capturent aussi des valeurs de leur environnement et les utilisent dans leurs calculs. Comme elles sont autonomes, on peut les faire circuler dans un programme comme n'importe quelle autre valeur, ou les affecter à des constantes et à des variables.

Les closures ressemblent beaucoup aux fonctions Swift, et ce n'est pas un hasard. Les fonctions en Swift sont des cas particuliers de closures : elles sont tenues d'avoir un nom et se définissent avec une syntaxe légèrement différente.

Bien que les fonctions en Swift soient techniquement des closures, quand on parle de « closures » en Swift, on désigne en réalité les [expressions de closure][closure-expressions]. Une expression de closure s'écrit comme une liste de paramètres suivie d'un type de retour et du mot-clé `in`, puis du corps de la closure, le tout entre accolades :

```swift
{ (a: Double, b: Double) -> Double in
  return (a + b) / 2.0
}
```

Cela définit une expression de closure de type `(Double, Double) -> Double`, que l'on peut exécuter de la même manière qu'une fonction de ce type, en lui appliquant des paramètres du type approprié :

```swift
{ (a: Double, b: Double) -> Double in
  return (a + b) / 2.0
}(10.0, 15.0)
// returns 12.5
```

Comme il n'est pas très pratique d'écrire l'expression de closure complète chaque fois qu'on veut l'exécuter, on peut affecter une closure à un nom, comme n'importe quelle autre valeur en Swift. On peut ensuite l'appeler en appliquant ce nom aux paramètres :

```swift
let mean = { (a: Double, b: Double) -> Double in
  (a + b) / 2.0
}

mean(13.0, 100.0)
// returns 56.5
```

Comme on le voit ci-dessus, les closures, tout comme les fonctions ordinaires, peuvent omettre le mot-clé `return` lorsque le corps de la closure se réduit à une seule expression.

Le plus souvent, les closures s'emploient avec des fonctions d'ordre supérieur : on les passe en paramètres à ces fonctions, ou bien ces dernières les renvoient comme résultat :

```swift
[11, 75, 3, 99, 53].contains(where: { (x: Int) -> Bool in x > 100 })
// returns false

["apple", "ball", "carrot"].sorted(by: { (s1: String, s2: String) -> Bool in s1.count < s2.count })
// returns ["ball", "apple", "carrot"]

func makeAdder(base: Int) -> (Int) -> Int {
  { (x: Int) -> Int in base + x }
}
```
