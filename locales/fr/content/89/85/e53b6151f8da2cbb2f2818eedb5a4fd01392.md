# Introduction

En JavaScript, un tableau est une structure de type liste, sans longueur fixe, qui peut contenir n'importe quel type de primitives ou d'objets, même des types mélangés.

Pour créer un tableau, ajoute des éléments entre crochets (`[]`).
Pour lire une valeur du tableau, place l'indice entre crochets (`[]`) après l'identifiant.
Les indices d'un tableau commencent à zéro.

Par exemple :

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers[2];
// => 3
```

Pour récupérer le nombre d'éléments que contient un tableau, utilise la propriété `length` :

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.length;
// => 4
```

Pour modifier un élément du tableau, affecte une valeur à l'indice :

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers[0] = 'one';
numbers;
// => ['one', 'two', 3, 'four']
```

## Méthodes

Certaines des [méthodes][array_methods] disponibles sur chaque objet Array permettent d'ajouter ou de supprimer des éléments du tableau.

### push

> La méthode `push()` ajoute un ou plusieurs éléments à la fin d'un tableau et renvoie la nouvelle longueur du tableau.[^1]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.push(5); // => 5
numbers;
// => [1, 'two', 3, 'four', 5]
```

### pop

> La méthode `pop()` supprime le dernier élément d'un tableau et renvoie cet élément.
> Cette méthode modifie la longueur du tableau.[^2]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.pop(); // => four
numbers;
// => [1, 'two', 3]
```

### shift

> La méthode `shift()` supprime le premier élément d'un tableau et renvoie cet élément supprimé.
> Cette méthode modifie la longueur du tableau.[^3]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.shift(); // => 1
numbers;
// => ['two', 3, 'four']
```

### unshift

> La méthode unshift() ajoute un ou plusieurs éléments au début d'un tableau et renvoie la nouvelle longueur du tableau.[^4]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.unshift('one'); // => 5
numbers;
// => ['one', 1, 'two', 3, 'four']
```

### splice

> La méthode splice() modifie le contenu d'un tableau en supprimant ou en remplaçant des éléments existants et/ou en ajoutant de nouveaux éléments sur place. Cette méthode renvoie un tableau contenant les éléments supprimés.[^5]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.splice(2, 1, 'one'); // => [3]
numbers;
// => [1, 'two', 'one', 'four']
```
