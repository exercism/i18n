# Indices

## Général

- Les _lens_ sont peu utilisés en Roc, car la syntaxe de mise à jour des enregistrements couvre élégamment la plupart des cas d'usage.
  Par exemple, considère cet enregistrement imbriqué :

  ```roc
  bob = { hair: { color: Brown, length: Long }, mouth: Smiling, height: 6.0 }
  ```

  Maintenant, donnons une nouvelle coupe à Bob :

  ```roc
  new_bob = { ..bob, hair: { ..bob.hair, length: Short } }
  ```

  Aucun _lens_ nécessaire !

- Cela dit, même si les _lens_ sont rares en Roc, ils sont courants dans d'autres langages comme Haskell et Scala, alors tu seras peut-être curieux de savoir comment on pourrait les implémenter en Roc.
  C'est aussi un bon moyen de mettre en pratique des fonctionnalités avancées de Roc, comme les types paramétrés et les enregistrements qui contiennent des fonctions.
  Voici d'ailleurs une façon de représenter un _lens_ en Roc :

  ```roc
  Lens(whole, part) := {
      get : whole -> part,
      set : whole, part -> whole,
  }
  ```

  Il s'agit d'un type paramétré : `whole` et `part` peuvent être n'importe quels types.
  `whole` est généralement un enregistrement, tandis que `part` peut être n'importe quel type de champ.
  Le champ `get` contient une fonction qui renvoie une `part` précise du `whole` donné, tandis que le champ `set` contient une fonction qui renvoie une copie du `whole` donné, mais avec une `part` précise remplacée par la `part` fournie.

  Par exemple, voici un _lens_ pour récupérer ou définir les cheveux d'une personne :

  ```roc
  hair_lens = {
      get: |person| person.hair,
      set: |person, hair| { ..person, hair },
  }
  ```

  On peut utiliser ce _lens_ pour se concentrer sur les cheveux de Bob, comme ceci :

  ```roc
  bob_hair = bob |> hair_lens.get
  ```

  Et on peut changer sa coiffure comme ceci :

  ```roc
  new_hair = { ..bob.hair, length: Short }
  new_bob = bob |> (hair_lens.set)(new_hair)
  ```

- Remarque : les parenthèses autour de `hair_lens.set` sont obligatoires. Sans elles, Roc chercherait une fonction nommée `set` dans le type de `hair_lens`.

- Les _lens_ deviennent particulièrement utiles quand on commence à les composer, ce qui permet de récupérer et de modifier des parties profondément imbriquées.
  On peut y arriver en implémentant une fonction comme celle-ci :

  ```roc
  compose : Lens(outer, inner), Lens(inner, part) -> Lens(outer, part)
  ```

  Une fois cette fonction implémentée, on peut s'en servir pour créer un _lens_ sur la longueur des cheveux, comme ceci :

  ```roc
  length_lens = {
      get: |hair| hair.length,
      set: |hair, length| { ..hair, length },
  }
  hair_length_lens = compose(hair_lens, length_lens)

  ```

  Maintenant, tu peux donner une nouvelle coupe à Bob :

  ```roc
  set_hair_length = hair_length_lens.set
  new_bob = bob |> set_hair_length(Short)
  ```

- Tu voudras peut-être aussi implémenter une fonction qui permet d'appliquer n'importe quelle transformation à une partie imbriquée :

  ```roc
  over : Lens(whole, part), whole, (part -> part) -> whole
  ```

  Une fois implémentée, tu peux utiliser `over` comme ceci :

  ```roc
  cut_hair = |current_length| match current_length {
      Long => Short
      Short => Bald
      Bald => Bald
  }
  new_bob = hair_length_lens |> over(bob, cut_hair)
  ```

- On te conseille de faire passer les tests d'abord avec la syntaxe de mise à jour des enregistrements de Roc, puis d'essayer les _lens_ à la place.
