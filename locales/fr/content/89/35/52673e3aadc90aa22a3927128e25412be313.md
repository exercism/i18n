# Configuration

Ce parcours utilise deux outils pour exécuter la suite de tests et garantir les bonnes pratiques :

1. [vader.vim](https://github.com/junegunn/vader.vim)
2. [vint](https://github.com/Kuniwak/vint)

## Lance les tests

1. Installe [vader.vim](https://github.com/junegunn/vader.vim/#installation).
1. Ouvre ta solution :
    ```
    $ vim exercise.vim
    ```
1. Charge le fichier courant pour que ses fonctions globales soient accessibles à Vim :
    ```
    :source %
    ```
1. Lance les tests :
    ```
    :Vader exercise.vader
    ```

Les chemins peuvent varier.

Si tu veux un raccourci pratique pour les étapes ci-dessus, ajoute ceci à ton fichier vimrc :

```vim
function! s:exercism_tests()
  if expand('%:e') == 'vim'
    let testfile = printf('%s/%s.vader', expand('%:p:h'),
          \ tr(expand('%:p:h:t'), '-', '_'))
    if !filereadable(testfile)
      echoerr 'File does not exist: '. testfile
      return
    endif
    source %
    execute 'Vader' testfile
  else
    let sourcefile = printf('%s/%s.vim', expand('%:p:h'),
          \ tr(expand('%:p:h:t'), '-', '_'))
    if !filereadable(sourcefile)
      echoerr 'File does not exist: '. sourcefile
      return
    endif
    execute 'source' sourcefile
    Vader
  endif
endfunction

autocmd BufRead *.{vader,vim}
      \ command! -buffer Test call s:exercism_tests()
```

Ensuite, ouvre n'importe quel fichier `.vim` ou `.vader` d'un répertoire d'exercice, puis lance la commande `:Test`.

## Analyse les fichiers Vim

1. Installe [vint](https://github.com/Kuniwak/vint#quick-start).
1. Analyse tous les fichiers Vim de façon récursive :
    ```
    $ vint .
    ```

Pour plus d'informations sur le parcours Vim script, consulte la [page d'aide](https://exercism.org/languages/vimscript).
