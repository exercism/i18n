# Tests

Comme OCaml est un langage compilé, tu dois compiler ta soumission et le code de test avant de pouvoir lancer les tests.
On utilise [`dune`](https://dune.build/) pour la compilation.
Chaque dossier contient un fichier dune qui indique comment compiler, ainsi qu'un Makefile qui délègue à dune.

Pour compiler et lancer les tests, il te suffit de taper depuis le dossier de l'exercice :

```bash
make
```

## Crée ton premier module OCaml

Pour créer un module utilisable avec le test de l'exercice `bob`, place ce qui suit dans un fichier nommé `bob.ml` :

```ocaml
open Base 

let response_for input = failwith "TODO"
```
