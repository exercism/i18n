# Introduction

## Modules

Jusqu'ici, tous les exercices que tu as vus utilisaient des classes.
Parfois, on n'a pas besoin du coût supplémentaire que représente la création d'un objet avec un état, et on utilise donc `module` à la place.

Un module est très similaire à une classe (en fait, `Module` est le parent de `Class` dans la hiérarchie d'objets). La principale différence est qu'au lieu d'utiliser des méthodes d'instance, on utilise des méthodes de classe.
Les méthodes de classe commencent par `self.` et sont appelées directement sur un module.

Par exemple :

```ruby
module Speaker
  def self.echo(something)
    "#{something} ... #{something}"
  end
end

Speaker.echo("Hello")   #=> "Hello ... Hello"
```

## Boucles

Il existe plusieurs façons d'écrire des boucles en Ruby, mais comme on a tendance à utiliser l'énumération plutôt que les boucles en général, la boucle la plus courante est sans doute la boucle `while` :

```ruby
counter = 0

while counter < 5
  counter += 1
end
```

On peut aussi utiliser son pendant, `until`

```ruby
counter = 0

until counter == 5
  counter += 1
end
```
