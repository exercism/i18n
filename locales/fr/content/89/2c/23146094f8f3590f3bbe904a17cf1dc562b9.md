## La commande `apply` de Tcl

Les cas de test peuvent sembler déroutants.
On attend de toi que tu implémentes ceci : 

```tcl
set myList {alpha beta gamma delta}
listOps::filter $myList {{word} {expr {[string length $word] == 4}}
```

Pourquoi ce dernier argument comporte-t-il autant d'accolades ?

Rappelons que la commande `proc` est définie ainsi :

```tcl
proc procName argList body
```

Tcl dispose d'une commande `apply` :

```tcl
apply func ?arg1 arg2 ...?
```

ce « func » est une liste de deux éléments, `{argList body}`, qui est essentiellement une proc anonyme (ou « lambda »).
La commande `apply` invoque cette proc anonyme en lui passant les arguments dont elle a besoin.

Par exemple, ces extraits sont équivalents :

```tcl
# using proc
proc myReverse {str} {return [string reverse $str]}
puts [myReverse "Hello, World!"]

# using apply
puts [apply {{str} {string reverse $str}} "Hello, World!"]

# or, store the func in a variable
set func {{str} {string reverse $str}}
puts [apply $func "Hello, World!"]
```

Avec `apply`, il est plus simple de faire circuler des blocs de code.

Références : [`apply`](https://tcl.tk/man/tcl8.6/TclCmd/apply.htm), [`proc`](https://tcl.tk/man/tcl8.6/TclCmd/proc.htm).
