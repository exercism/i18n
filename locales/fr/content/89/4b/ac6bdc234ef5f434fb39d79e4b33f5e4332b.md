# À propos

Un *ensemble disjoint* (une structure union-find) regroupe une collection de valeurs réparties en groupes qui ne se chevauchent pas, et répond rapidement à une seule question : ces deux valeurs sont-elles dans le même groupe ? Il fait partie du vocabulaire [`disjoint-sets`][disjoint-sets].

`<disjoint-set>` construit une structure vide. Les valeurs, les *atomes*, s'ajoutent avec `add-atom`, ou en masse avec `add-atoms` ; chacun commence seul dans son groupe :

```
<disjoint-set> ( -- disjoint-set )
add-atom       ( atom disjoint-set -- )
add-atoms      ( seq disjoint-set -- )
```

```factor
USING: disjoint-sets ;

<disjoint-set>
{ "a" "b" "c" "d" } over add-atoms   ! four singleton groups
```

`equate` fusionne les groupes qui contiennent deux atomes. L'union est transitive : une fois que `a` est uni à `b` et `b` à `c`, tous les trois partagent un même groupe.

```
equate ( atom1 atom2 disjoint-set -- )
```

Chaque groupe est identifié par un unique membre canonique, son *représentant*. `representative` le renvoie, et deux atomes appartiennent au même groupe précisément lorsque leurs représentants sont égaux. `equiv?` effectue directement ce test :

```
representative ( atom disjoint-set -- representative )
equiv?         ( atom1 atom2 disjoint-set -- ? )
```

```factor
USING: disjoint-sets ;

<disjoint-set>
{ "a" "b" "c" "d" } over add-atoms
"a" "b" pick equate
"b" "c" pick equate
"a" "c" pick equiv? .          ! => t   (transitively connected)
"a" "d" pick equiv? .          ! => f
"a" over representative
"c" pick representative = .     ! => t   (same representative)
```

Le choix de l'atome qui sert de représentant à un groupe est un détail interne ; il peut s'agir de n'importe quel membre du groupe, et ce choix peut changer à mesure que les groupes fusionnent. Ne te fie jamais au fait qu'un atome particulier soit le représentant ; fie-toi uniquement au fait que deux atomes du même groupe s'accordent.

`disjoint-set-members` renvoie tous les atomes qui ont été ajoutés.

La structure est *mutable* : `equate` et `add-atom` modifient l'ensemble disjoint sur place au lieu de renvoyer un nouvel ensemble. L'implémentation utilise l'union par rang avec compression de chemin, de sorte qu'une longue suite d'appels à `equate` et `representative` s'exécute en temps constant pour chacun d'eux.
