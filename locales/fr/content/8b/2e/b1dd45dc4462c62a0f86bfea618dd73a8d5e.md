# Introduction

En Gleam, il existe deux sortes de nombres bien différentes : les entiers et les nombres décimaux.

Les entiers sont des nombres sans partie décimale.

```gleam
let integer = 3
// -> 3
```

On peut aussi ajouter des tirets bas aux entiers pour plus de lisibilité.

```gleam
1_000_000 // One million
```

Gleam propose plusieurs opérateurs qui fonctionnent avec les entiers.

```gleam
1 + 1 // -> 2
5 - 1 // -> 4
5 / 2 // -> 2
3 * 3 // -> 9
5 % 2 // -> 1

2 > 1  // -> True
2 < 1  // -> False
2 >= 1 // -> True
2 <= 1 // -> False
```
