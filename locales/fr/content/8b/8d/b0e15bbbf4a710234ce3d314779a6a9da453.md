# Instructions

Tu écris un système embarqué pour une machine à tickets _Take-A-Number_. C'est un modèle très simple, qui distribue des numéros consécutifs et indique quel a été le dernier numéro distribué.

## 1. Démarre la machine

Implémente la fonction `start/0`. Elle doit lancer un nouveau processus et renvoyer le PID de ce processus. Le nouveau processus n'a pas encore besoin de faire quoi que ce soit.

```elixir
TakeANumber.start()
# => #PID<0.138.0>
```

Note que le PID peut être différent chaque fois que tu exécutes ce code.

## 2. Signale l'état de la machine

Modifie la machine pour que le processus nouvellement lancé soit prêt à recevoir des messages (démarre une boucle de réception) avec un état initial de `0`. Il doit pouvoir recevoir des messages `{:report_state, sender_pid}`. En réponse à ces messages, il doit envoyer son état actuel (le dernier numéro de ticket distribué) à `sender_pid`, puis attendre d'autres messages.

```elixir
machine_pid = TakeANumber.start()

# a client sending a message to the machine
send(machine_pid, {:report_state, self()})

# a client receiving a message from the machine
receive do
  msg -> msg
end

# => 0
```

## 3. Distribue des numéros

Modifie la machine pour qu'elle puisse recevoir des messages `{:take_a_number, sender_pid}`. Elle doit augmenter son état de 1, envoyer le nouvel état à `sender_pid`, puis attendre d'autres messages.

```elixir
machine_pid = TakeANumber.start()

# a client sending a message to the machine
send(machine_pid, {:take_a_number, self()})

# a client receiving a message from the machine
receive do
  msg -> msg
end

# => 1
```

## 4. Arrête la machine

Modifie la machine pour qu'elle puisse recevoir un message `:stop`. Elle doit cesser d'attendre d'autres messages.

## 5. Ignore les messages inattendus

Modifie la machine pour que, lorsqu'elle reçoit un message inattendu, elle l'ignore et continue d'attendre d'autres messages.
