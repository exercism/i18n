# Indices

## 1. Récupère le message d'une ligne de _log_

- Récupère le texte qui suit le _premier_ deux-points.
  - Tu peux utiliser `index/1` et la notation de découpage.
  - Ou explore les fonctions d'expressions régulières.
- Utilise la fonction `trim` fournie.

## 2. Récupère le niveau de _log_ d'une ligne de _log_

- Récupère le texte entre la première paire de crochets.
- Rends le résultat en minuscules.

## 3. Reformate une ligne de _log_

- Réutilise les fonctions existantes.
- Deux approches sont possibles : utiliser l'interpolation de _string_ ou la concaténation.
