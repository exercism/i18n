# Indices

## Général

- La [documentation de l'API `Map`][map-docs] contient une liste des méthodes disponibles sur l'interface `Map`.

## 1. Renvoie les codes dans un dictionnaire

- Tu devras définir une `Map` [de telle manière][declaring-members] que tu puisses l'utiliser dans les méthodes de la classe.

## 2. Ajoute des entrées au dictionnaire

- Les dictionnaires ont une [méthode][map-put-docs] pour ajouter et mettre à jour la valeur d'une clé.

## 3. Trouve le pays d'un indicatif téléphonique

- Les dictionnaires ont une [méthode][map-get-docs] pour obtenir la valeur d'une clé.

## 4. N'autorise pas les doublons

- Il existe un moyen de vérifier si le dictionnaire contient une [clé][map-contains-key-docs] ou une [valeur][map-contains-value-docs].

## 5. Trouve l'indicatif téléphonique d'un pays

- Il existe un [moyen][map-entry-set-docs] d'obtenir une collection itérable d'entrées dans un dictionnaire, ce qui te permet de parcourir les paires clé-valeur.

## 6. Mets à jour l'indicatif téléphonique du pays

- N'oublie pas que l'ancien indicatif téléphonique du pays sera dans le dictionnaire.
- Il existe une [méthode][map-remove-docs] pour supprimer une entrée du dictionnaire.
