# Astuces pour déboguer en `jq`

`jq` est fourni avec un filtre [`debug`][debug] bien pratique.
Utilise-le pendant que tu développes les solutions de tes exercices, pour inspecter les données qui se trouvent à cet instant dans le pipeline jq.

`debug` affiche un « tableau de débogage » sur **stderr**.
Il renvoie l'entrée inchangée.
Le premier élément du tableau est la _string_ `DEBUG:`.
Le second élément dépend de la façon dont tu appelles `debug`.

1. la fonction `debug` d'arité zéro place une représentation compacte de l'entrée dans le tableau de débogage :

   ```sh
   jq -n '[11, 22, 33] | debug | map(. * 2)'
   ```

   affiche

   ```none
    ["DEBUG:",[11,22,33]]
    [
      22,
      44,
      66
    ]
   ```

2. la version d'arité un fait passer l'entrée dans le filtre donné :

   ```sh
   jq -n '[11, 22, 33] | debug("length: \(length), last: \(.[-1])") | map(. * 2)'
   ```

   ```none
    ["DEBUG:","length: 3, last: 33"]
    [
      22,
      44,
      66
    ]
   ```

   Le filtre n'a pas besoin d'être une _string_.
   Il peut être n'importe quoi, y compris plusieurs expressions séparées par des virgules, pour une sortie de débogage « multiligne » :

   ```sh
   jq -n '[11, 22, 33] as $a | 44 | debug("I am here:", $a, .)'
   ```

   ```none
   ["DEBUG:","I am here:"]
   ["DEBUG:",[11,22,33]]
   ["DEBUG:",44]
   44
   ```

[debug]: https://jqlang.org/manual/#debug
