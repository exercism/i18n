# Introduction

Contrairement à beaucoup d'autres langages, JavaScript possède deux entités différentes pour représenter l'absence de valeur (significative).
Ce sont `null` et `undefined`.

## Null

La valeur primitive `null` s'utilise comme une «\u00A0valeur vide\u00A0» intentionnelle pour des variables de n'importe quel type.

```javascript
let name = null;
// name is intentionally set to "empty" because it is not
// available
```

On peut vérifier si une variable vaut `null` en utilisant l'[opérateur d'égalité stricte][mdn-strict-equality] `===`.

```javascript
let name = null;

name === null;
// => true
```

## Undefined

> Une variable à laquelle aucune valeur n'a été affectée est de type `undefined`.<sup>1</sup>

Cela signifie que si `null` représente une valeur vide (mais une valeur quand même), `undefined` représente l'absence totale de valeur. 🤯

`undefined` apparaît dans différents contextes.

- Si une variable est déclarée sans valeur (sans initialisation), elle vaut `undefined`.
- Si tu essaies d'accéder à la valeur associée à une clé qui n'existe pas dans un objet, tu obtiens `undefined`.
- Si une fonction ne renvoie aucune valeur, le résultat est `undefined`.
- Si un argument n'est pas passé à une fonction, il vaut `undefined`, sauf si cet argument a une valeur par défaut.

```javascript
let name;
console.log(name);
// => undefined
```

On peut vérifier si une variable vaut `undefined` en utilisant l'opérateur d'égalité stricte `===`.

```javascript
let name;

name === undefined;
// => true
```

## Chaînage optionnel

Si tu essaies de récupérer une valeur imbriquée dans un objet alors que la clé parente n'existe pas, JavaScript lève une erreur.
Pour éviter facilement ce problème, le chaînage optionnel a été ajouté à la spécification du langage en 2020.
Avec l'opérateur de chaînage optionnel `?.`, tu peux t'assurer que JavaScript n'essaie d'accéder à la clé imbriquée que si la clé parente n'était pas `null` ou `undefined`.
Sinon, c'est `undefined` qui est renvoyé.

```javascript
const obj = {
  address: {
    street: 'Trincomalee Highway',
    city: 'Batticaloa',
  },
};

obj.address.zipCode;
// => undefined

obj.residence.street;
// => TypeError: Cannot read property 'street' of undefined

obj.residence?.street;
// => undefined
```

## Coalescence des nuls

Il y a des situations où tu veux appliquer une valeur par défaut au cas où une variable vaut `null` ou `undefined` (mais seulement dans ce cas).
Pour répondre à ce besoin, l'opérateur de coalescence des nuls `??` a été introduit en 2020.
Il ne renvoie l'opérande de droite que lorsque l'opérande de gauche vaut `null` ou `undefined`.
Sinon, c'est l'opérande de gauche qui est renvoyé.

```javascript
let amount = null;
amount = amount ?? 1;
// => 1

amount = 0;
amount = amount ?? 1;
// => 0
```
