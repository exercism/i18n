# Instructions

Ta tâche est de créer un vérificateur de mot de passe.
Un vérificateur de mot de passe valide le mot de passe proposé par un utilisateur pour s'assurer qu'il répond à un ensemble d'exigences définies par l'organisation qui contrôle l'accès à la ressource en question.

Pour cet exercice, les exigences du mot de passe sont :
* Doit comporter au moins 12 caractères
* Doit contenir au moins une lettre majuscule
* Doit contenir au moins une lettre minuscule
* Doit contenir au moins un chiffre
* Doit contenir au moins un symbole de l'ensemble !@#$%^&*

Ta solution doit utiliser un `Result` pour encapsuler le statut de succès ou d'échec.
Dans le cas de succès, le `Result` doit transmettre le mot de passe validé sous forme de _string_.
Dans le cas d'échec, le `Result` doit transmettre la règle qui a été violée.

~~~~exercism/note
Pour cet exercice, le vérificateur de mot de passe sera simpliste : il indiquera uniquement quand une seule règle a été violée.
Un exercice ultérieur explorera un vérificateur de mot de passe plus réaliste, qui peut indiquer quand plusieurs règles ont été violées en même temps.
~~~~

## 1. Implémente la fonction `checkPassword`

La fonction `checkPassword` vérifie le mot de passe donné par rapport aux règles mentionnées ci-dessus. En cas d'échec, elle indique la règle qui a été violée en encapsulant l'une des valeurs de `PasswordRule` dans la valeur de résultat.

```fsharp
checkPassword "abcdefghij5#"
// => Error MissingUppercaseLetter
```

## 2. Implémente la fonction ``getStatusMessage`

La fonction `getStatusMessage` renvoie une _string_ contenant un message lisible par un humain indiquant la signification du résultat renvoyé par `checkPassword`.

```fsharp
getStatusMessage (Error MissingDigit)
// => "Error: does not have at least one digit"
```
