# Workflow de déploiement

Le workflow de déploiement sert à déployer l'[outillage du parcours](/docs/building/tooling) vers :

1. [Docker Hub](https://hub.docker.com/) : utilisé dans des scripts ou pour des tests en local.
   Accessible publiquement.
2. [ECR](https://aws.amazon.com/ecr/) : utilisé dans l'environnement de production pour tester les solutions soumises.
   Privé.

## Source

Le workflow est défini dans le fichier `.github/workflows/deploy.yml`.
