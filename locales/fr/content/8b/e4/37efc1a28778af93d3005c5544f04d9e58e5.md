# Debug

Quand un test échoue, un message s'affiche, décrivant ce qui n'a pas fonctionné et pour quelle entrée. Tu peux aussi tirer parti du fait que toute [sortie console][programiz.com-basic-input-output] s'affichera également. Pour écrire dans la console, tu peux utiliser :

```csharp
Console.WriteLine("Debug message");
```
