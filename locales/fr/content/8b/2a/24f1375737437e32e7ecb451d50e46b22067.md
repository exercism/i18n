# Introduction

Le filtrage est le processus qui consiste à créer une séquence à partir d'une autre en copiant tous ses éléments sauf certains.
Le choix des éléments à inclure dans la nouvelle séquence peut se faire au moyen d'une fonction de prédicat (une fonction qui s'évalue en une valeur booléenne) ou par égalité avec un objet précis.

## Supprime à l'aide d'un prédicat

`remove-if` est une fonction qui prend une fonction de prédicat et une séquence en arguments, et qui renvoie une séquence constituée uniquement des éléments pour lesquels le prédicat s'est évalué à une valeur fausse.
Autrement dit, elle « supprime » tous les éléments de la séquence pour lesquels le prédicat s'évalue à vrai. Note cependant que cette fonction ne modifie pas la séquence d'origine !
Elle renvoie à la place une nouvelle séquence dépourvue des éléments concernés. Si le prédicat était vrai pour toutes les valeurs, c'est une séquence vide qui est renvoyée.

```lisp
(remove-if #'evenp '(1 2 3 4 5)) ; => (1 3 5)
(remove-if #'oddp '(1 3 5))      ; => ()
```

## Supprime un élément précis

Si l'on veut supprimer un élément précis d'une séquence, on peut utiliser `remove`, qui prend l'élément à supprimer et une séquence.
Toutes les valeurs de la séquence qui ne sont pas égales à l'élément à supprimer sont renvoyées.
REMARQUE : l'égalité est vérifiée par défaut avec le [prédicat d'égalité générique][concept-equality] `eql`.

```lisp
(remove 1 '(1 2 1 3 1 4)) ; => (2 3 4)
(remove #\l "hello")      ; => "heo"
```
