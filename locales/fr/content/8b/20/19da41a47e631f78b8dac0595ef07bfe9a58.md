# Instructions spécifiques à SQLite

La colonne **result** doit contenir un objet d'objets encodé en JSON, où chaque mot est une clé et où son nombre d'occurrences est un entier.

Prenons par exemple la phrase ci-dessus : `"That's the password: 'PASSWORD 123'!", cried the Special Agent.\nSo I fled.`
Le **result** obtenu pour cette entrée devrait être :

```json
{"123":1,"agent":1,"cried":1,"fled":1,"i":1,"password":2,"so":1,"special":1,"that's":1,"the":2}
```

## Schéma de la table

```sql
CREATE TABLE "word-count" (
    sentence TEXT NOT NULL,
    result   TEXT               -- json object
);
```
