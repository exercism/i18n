# Introduction

## Énumérations

Un type énuméré est un type de données particulier qui permet à une variable de prendre une valeur parmi un ensemble de constantes prédéfinies.
La variable doit être égale à l'une des valeurs prédéfinies pour ce type.
Les exemples courants incluent les points cardinaux (les valeurs `NORTH`, `SOUTH`, `EAST` et `WEST`) et les jours de la semaine.

Comme ce sont des constantes, les noms des champs d'un type énuméré s'écrivent en majuscules.

### Définis un type énuméré

Dans le langage de programmation Java, on définit un type énuméré à l'aide du mot-clé `enum`.
Par exemple, on définit un type énuméré pour les jours de la semaine comme ceci :

```java
public enum DayOfWeek {
    SUNDAY,
    MONDAY,
    TUESDAY,
    WEDNESDAY,
    THURSDAY,
    FRIDAY,
    SATURDAY
}
```

On utilise les types énumérés dès que l'on a besoin de représenter un ensemble fixe de constantes.
Cela inclut les types énumérés naturels comme les planètes de notre système solaire, et les ensembles de données dont on connaît toutes les valeurs possibles à la compilation, par exemple les choix d'un menu, les options de ligne de commande, etc.

### Utilise un type énuméré

Voici du code qui montre comment utiliser le type énuméré `DayOfWeek` défini ci-dessus :

```java
public class Shop {
    public String getOpeningHours(DayOfWeek dayOfWeek) {
        switch (dayOfWeek) {
            case MONDAY:
            case TUESDAY:
            case WEDNESDAY:
            case THURSDAY:
            case FRIDAY:
                return "9am - 5pm";
            case SATURDAY:
                return "10am - 4pm"
            case SUNDAY:
                return "Closed.";
        }
    }
}
```

```java
var shop = new Shop();
shop.getOpeningHours(DayOfWeek.WEDNESDAY);
// => "9am - 5pm"
```

### Ajoute des méthodes et des champs

Les types énumérés du langage Java sont bien plus puissants que leurs équivalents dans d'autres langages.
La déclaration `enum` définit une classe (appelée type énuméré).
Le corps de la classe du type énuméré peut contenir des méthodes et d'autres champs :

```java
public enum Rating {
    GREAT(5),
    GOOD(4),
    OK(3),
    BAD(2),
    TERRIBLE(1);

    private final int numberOfStars;

    Rating(int numberOfStars) {
        this.numberOfStars = numberOfStars;
    }

    public int getNumberOfStars() {
        return this.numberOfStars;
    }
}
```

Appel de la méthode `getNumberOfStars` sur un membre du type énuméré `Rating` :

```java
Rating.GOOD.getNumberOfStars();
// => 4
```
