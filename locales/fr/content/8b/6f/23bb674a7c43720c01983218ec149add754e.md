# Introduction

## Fonctions externes

Gleam peut s'exécuter sur la machine virtuelle Erlang (BEAM) ou sur des environnements d'exécution JavaScript. De nombreux autres langages utilisent ces environnements d'exécution, et il est souvent utile de pouvoir appeler depuis Gleam du code écrit dans ces langages.

La fonctionnalité de Gleam appelée _fonctions externes_ permet d'importer dans Gleam des fonctions écrites dans d'autres langages et de les appeler sans surcoût à l'exécution.

Si ton projet Gleam s'exécute sur la machine virtuelle Erlang et que tu souhaites appeler la fonction `reverse` du module `lists` d'Erlang, tu peux le faire en ajoutant l'attribut `@external` en tête d'une fonction Gleam, comme ceci :

```gleam
@external(erlang, "lists", "reverse")
pub fn reverse_list(x: List(a)) -> List(a)
```

Elle peut alors être appelée comme n'importe quelle fonction Gleam :

```gleam
let reversed = reverse_list([1, 2, 3])
// -> [3, 2, 1]
```

Si tu essaies de compiler ce code pour les environnements d'exécution JavaScript, la compilation échouera avec un message d'erreur, car il n'existe aucune implémentation pour JavaScript. On peut spécifier une autre implémentation pour les environnements d'exécution JavaScript comme ceci :

```gleam
@external(erlang, "lists", "reverse")
@external(javascript, "./my_module.mjs", "reverse")
pub fn reverse_list(x: List(a)) -> List(a)
```

Il est également possible d'écrire une implémentation en Gleam, qui sera utilisée lorsqu'il n'existe pas d'implémentation externe pour la cible de compilation actuelle :

```gleam
@external(erlang, "lists", "reverse")
pub fn reverse_list(x: List(a)) -> List(a) {
  tail_recursive_reverse(x, [])
}

fn tail_recursive_reverse(list, reversed) {
  case list {
    [] -> reversed
    [x, ..xs] -> tail_recursive_reverse(xs, [x, ..reversed])
  }
}
```

## Types externes

Les types externes permettent de faire référence à des types de données définis dans d'autres langages, comme Erlang ou JavaScript.

Pour définir un type externe, on déclare un type sans fournir aucun constructeur. Il peut ensuite être utilisé comme n'importe quel autre type.

```gleam
pub type OrderedDictionary(element)
```
