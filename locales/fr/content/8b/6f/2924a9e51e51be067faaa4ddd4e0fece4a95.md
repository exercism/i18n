# Introduction

## Récursion

Les fonctions récursives sont des fonctions qui s'appellent elles-mêmes.

Une fonction récursive doit avoir au moins un _cas de base_ et au moins un _cas récursif_.

Un _cas de base_ renvoie une valeur sans rappeler la fonction.
Un _cas récursif_ rappelle la fonction en modifiant l'entrée pour qu'elle finisse par correspondre au cas de base.

En Elm, les fonctions récursives se définissent généralement à l'aide du filtrage par motif, avec des expressions `case` ou plusieurs clauses de fonction.

```elm
count : List a -> Int
count list =
    case list of
        [] ->
            0  -- base case

        _ :: tail ->
            1 + count tail  -- recursive case
```

### Les boucles grâce à la récursion

En raison de l'immuabilité, les boucles en Elm s'écrivent différemment de celles des langages impératifs.
Par exemple, une boucle ressemble souvent à ceci :

```c
for(i = 0; i < array.length; i++) {
  // do something with array[i]
}
```

Dans un langage fonctionnel comme Elm, il n'est pas possible de modifier des variables.
Les boucles doivent donc être implémentées avec de la récursion.

L'équivalent d'une boucle `for` en Elm ressemblerait à ceci :

```elm
loop : List a -> (a -> b) -> List b
loop list f =
    case list of
        [] ->
            []

        head :: tail ->
            f head :: loop tail f
```

En pratique, on parcourt le plus souvent les listes et les autres structures de données en Elm à l'aide de fonctions du module `List`, comme `List.map`, `List.filter` et `List.foldl`.
Sous le capot, ces fonctions sont implémentées avec de la récursion.
