# Introduction

## Itérateurs

Un `Iterator` en Gleam est similaire à un tableau dans la mesure où il s'agit d'une collection ordonnée de valeurs, toutes de même type. Il en diffère par son caractère paresseux : il ne stocke pas toutes ses valeurs en mémoire d'un coup, mais les calcule à mesure qu'elles deviennent nécessaires.

Cela est utile lorsqu'on manipule des séquences très grandes, voire infinies : on peut alors les traiter même sans disposer d'assez de mémoire libre pour les stocker toutes.

Le module `gleam/iterator` définit le type `Iterator` ainsi que des fonctions permettant de manipuler les itérateurs.

Bon nombre des fonctions qui existent pour les tableaux existent aussi pour les itérateurs, comme `map`, `filter` et `take`. Ces fonctions renvoient des itérateurs : elles n'effectuent donc aucun travail tant que l'itérateur n'a pas été consommé.

```gleam
let iter = 
  [1, 2, 3, 4, 5, 6]
  |> iterator.from_list
  |> iterator.filter(fn(x) { x > 2 })
  |> iterator.take(2)

// No work has been done yet as the iterator has not been consumed

// Consume the iterator and collect the values into a list
iterator.to_list(iter)
// -> [3, 4]
```

La fonction `unfold` permet de créer des itérateurs à partir d'une fonction appelée de manière répétée pour produire la valeur suivante de la séquence.

Ici, la fonction `unfold` sert à créer un itérateur qui produit la suite de Fibonacci :

```gleam 
iterator.unfold(#(0, 1), fn(pair) {
  let x = pair.0 + pair.1
  iterator.Next(element: x, accumulator: #(pair.1, x))
})
|> iterator.take(6)
|> iterator.to_list
// -> [1, 2, 3, 5, 8, 13]
```

La séquence est ici infinie, c'est pourquoi la fonction `take` est utilisée pour la rendre finie avant de collecter les valeurs dans un tableau. Si l'on appelle `to_list` sur un itérateur infini, le programme s'exécutera jusqu'à épuisement de la mémoire, puis plantera.
