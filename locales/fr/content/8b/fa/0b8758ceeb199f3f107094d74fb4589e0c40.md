# Représentations

Le [representer Java][github-java-representer] applique les normalisations suivantes :

- Tous les commentaires sont supprimés
- Toutes les déclarations d'import sont supprimées
- Les identifiants sont normalisés en une valeur de remplacement

Après avoir appliqué les normalisations ci-dessus, la représentation obtenue est formatée selon [Google Java Style][google-java-style], afin d'éliminer les éventuelles différences de formatage de code restantes.

## Avant de soumettre

Vérifie les points suivants :

- Tu ne dupliques pas les retours donnés par l'analyseur.
- Tu regardes l'onglet « examples » dans la boîte de dialogue de soumission et tu vérifies que les retours ont du sens pour tous les onglets.
- Tu vérifies que tu ne fais pas référence aux espaces ni aux commentaires.
- Tu vérifies que tu ne fais pas référence aux noms de fonctions ou de variables tels qu'ils apparaissent dans la solution, mais que tu utilises plutôt la correspondance fournie (ou que tu omets les noms).
  Seuls les identifiants utilisés par les tests de l'exercice peuvent être cités sans risque, car ils sont toujours les mêmes pour tout le monde.
