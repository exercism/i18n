# Instructions

Dans cet exercice, tu vas implémenter la logique de quête d'un nouveau jeu de rôle développé par un ami.
Le personnage principal du jeu est Annalyn, une jeune fille courageuse accompagnée d'un chien de compagnie féroce et loyal.
Hélas, le malheur frappe : son meilleur ami a été enlevé alors qu'il cherchait des baies dans la forêt.
Annalyn va tenter de retrouver et de libérer son meilleur ami, en emmenant éventuellement son chien avec elle dans cette quête.

Après avoir suivi un moment la piste de son meilleur ami, elle trouve le camp où celui-ci est emprisonné.
Il s'avère qu'il y a deux ravisseurs : un puissant chevalier et un archer rusé.

Ayant trouvé les ravisseurs, Annalyn se demande lesquelles des actions suivantes elle peut entreprendre :

- _Attaque rapide_ : une attaque rapide est possible si le chevalier dort, car il lui faut du temps pour enfiler son armure, ce qui le rend vulnérable.
- _Espionner_ : on peut espionner le groupe si au moins l'un d'eux est éveillé.
  Sinon, espionner est une perte de temps.
- _Signaler au prisonnier_ : on peut signaler au prisonnier à l'aide de cris d'oiseaux si le prisonnier est éveillé et que l'archer dort, car les archers sont formés aux signaux d'oiseaux et pourraient intercepter le message.
- _Libérer le prisonnier_ : Annalyn peut tenter de s'introduire discrètement dans le camp pour libérer le prisonnier.
  C'est une manœuvre risquée, qui ne peut réussir que de deux façons :
  - Si Annalyn a son chien avec elle, elle peut secourir le prisonnier si l'archer dort.
    Le chevalier a peur du chien et l'archer n'aura pas le temps de se préparer avant qu'Annalyn et le prisonnier puissent s'échapper.
  - Si Annalyn n'a pas son chien, alors elle et le prisonnier doivent être très discrets !
    Annalyn peut libérer le prisonnier si le prisonnier est éveillé et que le chevalier et l'archer dorment tous les deux, mais si le prisonnier dort, il est impossible de le secourir : le prisonnier serait surpris par l'apparition soudaine d'Annalyn et réveillerait le chevalier et l'archer.

Tu as quatre tâches : implémenter la logique qui détermine si les actions ci-dessus sont disponibles selon l'état des trois personnages trouvés dans la forêt et selon la présence ou non du chien d'Annalyn.

## 1. Vérifie si une attaque rapide est possible

Définis la fonction `can_fast_attack()` qui prend une valeur booléenne indiquant si le chevalier est éveillé.
Cette fonction renvoie `true` si une attaque rapide est possible en fonction de l'état du chevalier.
Sinon, elle renvoie `false` :

```rust
let knight_awake = true;
can_fast_attack(knight_awake); // false
```

## 2. Vérifie si le groupe peut être espionné

Définis la fonction `can_spy()` qui prend trois valeurs booléennes indiquant respectivement si le chevalier, l'archer et le prisonnier sont éveillés.
La fonction renvoie `true` si l'on peut espionner le groupe, en fonction de l'état des trois personnages.
Sinon, elle renvoie `false` :

```rust
let knight_awake = false;
let archer_awake = true;
let prisoner_awake = false;
can_spy(knight_awake, archer_awake, prisoner_awake); // true
```

## 3. Vérifie si le prisonnier peut être signalé

Définis la fonction `can_signal_prisoner()` qui prend deux valeurs booléennes indiquant respectivement si l'archer et le prisonnier sont éveillés.
La fonction renvoie `true` si le prisonnier peut être signalé, en fonction de l'état des deux personnages.
Sinon, elle renvoie `false` :

```rust
let archer_awake = false;
let prisoner_awake = true;
can_signal_prisoner(archer_awake, prisoner_awake); // true
```

## 4. Vérifie si le prisonnier peut être libéré

Définis la fonction `can_free_prisoner()` qui prend quatre valeurs booléennes.
Les trois premiers paramètres indiquent respectivement si le chevalier, l'archer et le prisonnier sont éveillés.
Le dernier paramètre indique si le chien d'Annalyn est présent.
La fonction renvoie `true` si le prisonnier peut être libéré en fonction de l'état des trois personnages et de la présence du chien d'Annalyn.
Sinon, elle renvoie `false` :

```rust
let knight_awake = false;
let archer_awake = true;
let prisoner_awake = false;
let dog_present = false;
can_free_prisoner(knight_awake, archer_awake, prisoner_awake, dog_present); // false
```
