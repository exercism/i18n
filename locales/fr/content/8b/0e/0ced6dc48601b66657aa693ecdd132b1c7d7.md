# Instructions

Tu es en train de développer le nouveau jeu très apprécié **Crystal Hunter**.
Dans le jeu, tu incarnes un personnage qui se déplace et ramasse des cristaux.
Le joueur gagne en ramassant tous les cristaux.
Si le joueur entre en contact avec un bandit, il perd tous ses cristaux et la partie.
Il y a une exception à cette règle : le joueur peut avoir un power-up actif qui le rend invisible aux bandits.

Ton objectif est d'écrire des règles qui seront utilisées dans le jeu.

## 1. Définis si le personnage obtient des points bonus

Dans le jeu, le personnage obtient des points bonus s'il touche un bandit alors qu'il a un power-up.

Définis la méthode `Rules#bonus_points?` qui prend deux arguments (_si le personnage a un power-up actif_ et _si le personnage touche un bandit_) et renvoie un booléen qui indique si le personnage obtient des points bonus.
La méthode doit renvoyer `true` uniquement si le personnage a un power-up actif et touche un bandit, et `false` sinon.

```Crystal
Rules.new.bonus_points?(false, true)
# => false
```

## 2. Définis si le personnage marque des points

Le joueur gagne des points dans le jeu lorsqu'il ramasse un cristal ou un power-up.

Définis la méthode `Rules#score?`, qui prend deux arguments (_si le personnage touche un power-up_ et _si le personnage touche un cristal_) et renvoie un booléen indiquant si le personnage a marqué des points ou non.
La méthode doit renvoyer `true` si le personnage touche un power-up ou un cristal, et renvoyer `false` sinon.

```crystal
Rules.new.score?(true, true)
# => true
```

## 3. Définis si le personnage perd

Définis la méthode `Rules#lose?`, qui prend deux arguments (_si le personnage a un power-up actif_ et _si le personnage touche un bandit_) et renvoie un booléen qui indique si le personnage perd ou non.
La méthode doit renvoyer `true` si le personnage touche un bandit et n'a pas de power-up actif, et renvoyer `false` sinon.

```crystal
Rules.new.lose?(false, true)
# => true
```

## 4. Définis si le personnage gagne

Définis la méthode `Rules#win?`, qui prend trois arguments (_si le personnage a ramassé tous les cristaux_, _si le personnage a un power-up actif_ et _si le personnage touche un bandit_) et renvoie un booléen indiquant si le personnage gagne ou non.
La méthode doit renvoyer `true` si le personnage a rassemblé tous les cristaux et n'a pas perdu d'après les arguments définis dans la partie 3, et renvoyer `false` sinon.

```crystal
Rules.new.win?(false, true, false)
# => false
```
