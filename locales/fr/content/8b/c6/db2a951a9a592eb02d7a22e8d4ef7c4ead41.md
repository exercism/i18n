# Indices

## Général

- Lis la section consacrée au [module `Agent`][getting-started-agent] dans le guide de démarrage.
- Lis la documentation du [module `Agent`][elixir-doc-agent].
- Regarde [ElixirCasts: Introduction to Agents][elixircasts-agent].

## 1. Ouvre le jardin

- Consulte la documentation de [`Agent`][elixir-doc-agent].
- La fonction qui initialise l'état du _processus agent_ doit renvoyer l'état initial.

## 2. Liste les inscriptions

- Le module [`Agent`][elixir-doc-agent] contient de nombreuses fonctions pour obtenir l'état actuel du _processus agent_.

## 3. Enregistre des parcelles pour une personne

- Le module [`Agent`][elixir-doc-agent] contient des fonctions pour obtenir et mettre à jour l'état du _processus agent_.
- Ces fonctions demandent en général une fonction qui transforme l'état et renvoie une forme particulière.
- Pour garder la trace de l'id de la prochaine parcelle à attribuer, l'état de ton _processus agent_ doit conserver les parcelles ainsi que le prochain id à utiliser pour une parcelle.

## 4. Libère des parcelles

- Le module [`Agent`][elixir-doc-agent] contient des fonctions pour obtenir et mettre à jour l'état du _processus agent_.
- Ces fonctions demandent en général une fonction qui transforme l'état et renvoie l'état suivant.

## 5. Obtiens une parcelle enregistrée

- Le module [`Agent`][elixir-doc-agent] contient des fonctions pour obtenir l'état du _processus agent_.
- Récupère la parcelle, puis traite le résultat pour renvoyer le résultat correct.
