# À propos

Les [_strings_][strings] en Haxe sont des objets immuables qui représentent du texte sous forme de séquence de caractères Unicode (lettres, chiffres, ponctuation, etc.). On utilise des guillemets doubles pour définir une instance de `string` :

```haxe
var fruit:String = "Apple";
```

On peut manipuler une _string_ en appelant l'une de ses [méthodes ou propriétés][string-api]. Comme les valeurs de type _string_ ne peuvent jamais changer une fois définies, toutes les méthodes de manipulation de _string_ renvoient une nouvelle _string_.

Une _string_ est délimitée par des guillemets doubles (`"`). Certains caractères spéciaux doivent être [échappés][escaping] à l'aide du caractère antislash (`\`). De plus, les _strings_ Haxe, qui peuvent s'étendre sur plusieurs lignes, permettent de construire facilement de longs littéraux de chaînes de caractères :

```haxe
var escaped:String = "c:\\test.txt";
var multiline:String = "
- apple
- pear
- banana";
```

La façon la plus simple de concaténer des _strings_ consiste à utiliser l'[opérateur `+`][plus-operator].

```haxe
var name:String = "Jane";
trace("Hello " + name + "!");
// => "Hello Jane!"
```

Pour une mise en forme plus complexe, on préfère l'[interpolation de _string_][interpolation]. Pour ce faire, on entoure la _string_ de guillemets simples (`'`) et on utilise le signe dollar (`$`) pour déclencher l'interpolation de variable. Il est également possible d'évaluer des expressions entières avec `${expr}`, où `expr` désigne n'importe quelle expression Haxe valide :

```haxe
var name:String = "Jane";
trace('Hello $name!');
// => "Hello Jane!"
trace('HELLO ${name.toUpperCase()}!');
// => "HELLO JANE!"
```
