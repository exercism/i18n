# Instructions supplémentaires

## Registres

| Registre | Utilisation | Type    | Description                                              |
| -------- | ----------- | ------- | -------------------------------------------------------- |
| `$a0`    | entrée      | adresse | chaîne de caractères hexadécimaux terminée par un caractère nul |
| `$v0`    | sortie      | entier  | valeur décimale de la chaîne d'entrée                    |
| `$t0-9`  | temporaire  | quelconque | utilisé pour le stockage temporaire                   |
