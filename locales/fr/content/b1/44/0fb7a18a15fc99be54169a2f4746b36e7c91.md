# Indices

## Généralités

- Ne te préoccupe pas de la façon dont les arguments sont obtenus, concentre-toi simplement sur leur combinaison pour renvoyer le résultat attendu.
- Unison a [des règles spécifiques de priorité des opérateurs][operator-precedence], pense à utiliser des parenthèses si tu as besoin d'ordonner différemment l'application des fonctions.

## 1. Définis si Pac-Man peut manger un fantôme

- Tu dois définir une fonction qui prend 2 arguments. Le premier argument est une valeur [booléenne][boolean] qui indique si Pac-Man a une pastille énergétique active. Le second argument est une valeur [booléenne][boolean] qui indique si Pac-Man touche un fantôme.
- La fonction doit renvoyer une valeur [booléenne][boolean].
- Tu peux utiliser l'opérateur [booléen][boolean] `&&` pour combiner les arguments et obtenir un résultat.

## 2. Définis si Pac-Man marque des points

- Tu dois définir une fonction qui prend 2 arguments. Le premier argument est une valeur [booléenne][boolean] qui indique si Pac-Man touche une pastille énergétique. Le second argument est une valeur [booléenne][boolean] qui indique si Pac-Man touche un point.
- La fonction doit renvoyer une valeur [booléenne][boolean].
- Tu peux utiliser l'opérateur [booléen][boolean] `||` pour combiner les arguments et obtenir un résultat.

## 3. Définis si Pac-Man perd

- Tu dois définir une fonction qui prend 2 arguments. Le premier argument est une valeur [booléenne][boolean] qui indique si Pac-Man a une pastille énergétique active. Le second argument est une valeur [booléenne][boolean] qui indique si Pac-Man touche un fantôme.
- La fonction doit renvoyer une valeur [booléenne][boolean].
- Tu peux utiliser les opérateurs [booléens][boolean] `&&` et `not` pour combiner les arguments et obtenir un résultat.

## 4. Définis si Pac-Man gagne

- Tu dois définir une fonction qui prend 3 arguments. Le deuxième argument est une valeur [booléenne][boolean] qui indique si Pac-Man a mangé tous les points. Le premier argument est une valeur [booléenne][boolean] qui indique si Pac-Man a une pastille énergétique active. Le deuxième argument est une valeur [booléenne][boolean] qui indique si Pac-Man touche un fantôme.
- La fonction doit renvoyer une valeur [booléenne][boolean].
- Tu peux utiliser les opérateurs [booléens][boolean] `&&` et `not` pour combiner les arguments et les résultats des fonctions appelées.

[boolean]: https://elixir-lang.org/getting-started/basic-types.html#booleans
[operator-precedence]: https://www.unison-lang.org/learn/fundamentals/values-and-functions/function-application-operators/
