# Concaténation de _strings_

La concaténation de _strings_ est parfaitement valable en Crystal, mais pour composer une _string_, le plus courant est d'utiliser l'[interpolation de _strings_][interpolation].
Par exemple :

```crystal
# Rather than:
"One for " + name_variable + ", one for me"

# Consider:
"One for #{name_variable}, one for me."
```

[interpolation]: https://crystal-lang.org/reference/latest/syntax_and_semantics/literals/string.html#interpolation
