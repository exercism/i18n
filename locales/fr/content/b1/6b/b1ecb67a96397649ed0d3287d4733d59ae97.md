# Instructions supplémentaires

## Mots

- `tick ( matrix cols -- matrix' )` : avance la grille d'une génération et renvoie la nouvelle grille.

Chaque ligne de la grille est représentée sous la forme d'un entier de 64 bits ; `cols` est le nombre de colonnes (au plus 64). Par exemple,

```
    0 1 0
    1 0 0
    1 1 0
```

La grille est représentée par

```
0b010
0b100
0b110
```
