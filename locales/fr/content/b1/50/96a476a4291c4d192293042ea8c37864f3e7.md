# Instructions

Dans cet exercice, on va écrire du code pour analyser une chaîne de montage dans une usine de voitures.

## 1. Calcule le nombre de voitures fonctionnelles produites par heure

Implémente une fonction qui prend en entrée le nombre de voitures produites par heure et le taux de réussite, puis calcule le nombre de voitures réussies produites par heure. Le taux de réussite est donné sous forme de pourcentage, de `0` à `100` :

```lua
cars.calculate_working_cars_per_hour(1547, 90)
--> => 1392.3
```

**Remarque :** la valeur de retour doit être un nombre décimal.

## 2. Calcule le nombre de voitures fonctionnelles produites par minute

Implémente une fonction qui prend en entrée le nombre de voitures produites par heure et le taux de réussite, puis calcule combien de voitures sont produites avec succès chaque minute :

```lua
cars.calculate_working_cars_per_minute(1105, 90)
-- => 16
```

**Remarque :** la valeur de retour doit être un nombre entier.

## 3. Calcule le coût de production

Chaque voiture coûte normalement 10 000 $ à produire individuellement, qu'elle soit réussie ou non. Mais avec un peu d'organisation, on peut produire 10 voitures ensemble pour 95 000 $. Par exemple, on peut produire 37 voitures de la façon suivante :
37 = 3 x groupes de dix + 7 voitures individuelles

Ainsi, le coût pour 37 voitures est :
3 \* 95 000 + 7 \* 10 000 = 355 000

Implémente une fonction qui calcule le coût de production d'un certain nombre de voitures, qu'elles soient réussies ou non :

```lua
cars.calculate_cost(37)
-- => 355000

cars.calculate_cost(21)
-- => 200000
```

**Remarque :** la valeur de retour doit être un nombre entier.
