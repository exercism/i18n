# Indices

## Généralités

- Tous les mots pour lire et écrire se trouvent dans [`io.files`][io.files] ; l'encodage `utf8` qu'ils prennent tous vient de [`io.encodings.utf8`][utf8].

## 1. Lis chaque relevé

- `file-lines` renvoie un tableau de lignes dont les sauts de ligne ont été retirés.

## 2. Trouve le relevé le plus récent

- Lis les lignes avec `file-lines`, puis prends la dernière avec `last` (qui vient de `sequences`).

## 3. Lis le journal brut

- `file-contents` renvoie le fichier sous la forme d'une seule _string_, sauts de ligne compris.

## 4. Enregistre un relevé

- Ouvre le fichier en mode ajout et `print` le relevé à l'intérieur de la _quotation_ : `with-file-appender ( path encoding quot -- )`. Le relevé est utilisé à l'intérieur de la _quotation_ tandis que le chemin est consommé avant lui, c'est pourquoi les variables locales `::` gardent le corps lisible :
  `:: record-reading ( reading path -- ) path utf8 [ reading print ]
  with-file-appender ;`.

## 5. Réécris le journal

- `set-file-lines` écrit chaque élément d'une séquence sur sa propre ligne, en ajoutant les sauts de ligne à ta place.
