# Classes génériques

Tu utilises `ARRAY{STR}`, `FMAP{STR,INT}` et `FSET{STR}` depuis le début.
Les accolades ont toujours contenu un type. Maintenant, tu vas écrire une
classe avec ses propres accolades.

## Le problème

Le bureau des objets trouvés a besoin d'une boîte qui contient une seule chose
et qui se souvient de la personne qui l'a déposée. Une boîte pour un pull :

```sather
class JUMPER_BOX is
   attr item : JUMPER;
   ...
end;
```

puis la même classe encore une fois pour une gourde, et encore une fois pour
un téléphone. Trois copies qui ne diffèrent que par un mot.

## Le paramètre de type

```sather
class LOST_BOX{T} is

   attr item : T;

   create(thing : T) : SAME is
      box ::= new;
      box.item := thing;
      return box;
   end;

end; -- class LOST_BOX{T}
```

`{T}` après le nom de la classe est un **paramètre de type**. `T` n'est pas
un type : il représente le type qui sera fourni quand la classe est utilisée.
À l'intérieur de la classe, `T` s'utilise exactement comme n'importe quel nom
de type.

## Utilisation

Fournis le type entre accolades :

```sather
   jumper ::= #LOST_BOX{STR}("blue jumper");
   count ::= #LOST_BOX{INT}(3);

   jumper.item      -- "blue jumper", a STR
   count.item       -- 3, an INT
```

`LOST_BOX{STR}` et `LOST_BOX{INT}` sont deux types différents. Mettre l'un
là où l'autre est attendu est une erreur que le compilateur attrape,
exactement comme si tu avais écrit les deux classes à la main. C'est
d'ailleurs ce qui se passe en pratique : Sather construit une classe
distincte à partir du modèle pour chaque type réellement utilisé.

Il n'y a donc aucun coût à l'exécution, et aucune perte d'information de
type : `jumper.item` est vraiment un `STR`, et non quelque chose qu'il faut
vérifier ou convertir.

## Plusieurs paramètres

Une classe peut prendre plusieurs paramètres, séparés par des virgules.
`FMAP{K,T}` est l'exemple que tu connais déjà.

```sather
class LABELLED{L,T} is
   attr label : L;
   attr item : T;
   ...
end;
```

## Nommage

Par convention, une seule lettre majuscule : `T` pour une chose, `K` pour une
clé, `E` pour un élément. La bibliothèque les utilise partout.
