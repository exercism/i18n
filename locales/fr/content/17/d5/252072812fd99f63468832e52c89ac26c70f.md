# Annexe aux instructions

## Implémentation

L'utilisation des fonctionnalités de base du langage pour construire et déconstruire des tableaux par déstructuration, ainsi que du littéral de tableau `[]`, est autorisée, mais aucune fonction de `Array.prototype` ne doit être utilisée.

Pour pouvoir tester ta solution, assure-toi que `forEach` est implémenté.

```typescript
const list = List.create(1, 2)
list.forEach((item) => console.log(item))
// =>
//    1
//    2
```
