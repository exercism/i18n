# Instructions spécifiques à SQLite

Les colonnes **list_one** et **list_two** contiennent une liste d'entiers encodée en JSON.

Exemple :

```json
[1, 2, 3]
```

## Schéma de la table

```sql
CREATE TABLE sublist (
    list_one TEXT NOT NULL,     -- json array
    list_two TEXT NOT NULL,     -- json array
    result   TEXT
);
```
