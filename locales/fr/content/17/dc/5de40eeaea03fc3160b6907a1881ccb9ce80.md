# Instructions

Dans cet exercice, tu travailles dans une pizzeria qui livre aux clients.

Tu proposes trois types de pizzas :

- Margherita : 7 $
- Caprese : 9 $
- Formaggio : 10 $

Les clients peuvent aussi choisir deux options supplémentaires pour un petit supplément :

1. Sauce supplémentaire : 1 $
1. Garnitures supplémentaires : 2 $

Lorsque les clients passent une commande, des frais supplémentaires sont ajoutés s'ils ne commandent qu'une ou deux pizzas :

- 1 pizza : 3 $
- 2 pizzas : 2 $

Tu as trois tâches, qui porteront chacune sur des pizzas et leur prix.

## 1. Définis les types de pizzas et les options

Définis le type personnalisé `Pizza` pour représenter les différents types de pizzas et les options :

- `Margherita`
- `Caprese`
- `Formaggio`
- `ExtraSauce`
- `ExtraToppings`

`ExtraSauce` et `ExtraToppings` doivent encapsuler le type `Pizza`.

## 2. Calcule le prix d'une pizza

Implémente la fonction `pizza_price` pour calculer le prix d'une pizza :

```gleam
pizza_price(Caprese)
// -> 9
```

## 3. Calcule le prix d'une commande

Implémente la fonction `order_price` pour calculer le prix d'une commande de pizzas :

```gleam
order_price([Margherita, Formaggio])
// -> 19
```
