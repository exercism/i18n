# Général

## 1. Définis le type personnalisé générique `TreasureChest`

- Le type personnalisé `TreasureChest` ne comporte qu'une seule variante.

## 2. Définis le type personnalisé générique `UnlockResult`

- Le type personnalisé `UnlockResult` comporte 2 variantes, `Unlocked` et `WrongPassword`.

## 3. Définis la fonction `get_treasure`

- On peut, de la même manière, faire du _pattern matching_ sur les types personnalisés pour accéder à leurs valeurs.
