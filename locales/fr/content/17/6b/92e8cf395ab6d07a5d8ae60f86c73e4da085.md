# Introduction

On monte un club de programmation secret entre amis et amis d'amis.
Comme tout le monde ne se connaît pas, on a décidé de créer une poignée de main secrète qui permet de reconnaître qu'une personne est membre.
On ne veut pas que quelqu'un qui n'est pas dans le secret puisse déchiffrer le code.

Le code est conçu pour qu'une personne énonce un nombre entre 1 et 31, et que l'autre le transforme en une série d'actions.
