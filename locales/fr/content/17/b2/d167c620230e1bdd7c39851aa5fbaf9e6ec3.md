# Instructions

Tu es le signaleur à bord d'un patrouilleur côtier. La sacoche d'aujourd'hui doit contenir cinq petits mots prêts avant le début du quart du matin.

## 1. Cite une valeur

Le carnet de bord consigne chaque observation sous *forme source Factor*, le même texte que l'analyseur relira. Définis `quote-value` pour transformer n'importe quelle valeur en sa _string_ sous forme source.

```factor
123 quote-value .   ! => "123"
"hi" quote-value .  ! => "\"hi\""
```

## 2. Retire l'encadrement du drapeau

Les drapeaux de signalisation qui arrivent sont encadrés par un caractère marqueur à chaque extrémité. Définis `flag-body` pour renvoyer tout ce qui se trouve *entre* les deux marqueurs : supprime le premier caractère et le dernier.

Renvoyer une tranche (une vue) plutôt que d'en faire une copie.

```factor
"#NS-1024#" flag-body .   ! => "NS-1024"
```

## 3. Découpe un drapeau

Chaque drapeau porte un court code de préfixe, suivi de la charge utile. Définis `split-flag` pour prendre un drapeau et une longueur d'en-tête, et renvoyer *à la fois* la tranche d'en-tête et la tranche de corps.

```factor
"NS-1024" 2 split-flag .s
! => "NS"
! => "-1024"
```

## 4. Triangule à partir de deux relevés

Deux relevés de signal consécutifs donnent trois mesures dérivées : leur *différence* `a - b`, leur *milieu* `(a + b) / 2` et leur *rapport* `a / b`. Chaque mesure utilise les deux relevés.

Définis `triangulate` pour renvoyer les trois à partir d'une paire de relevés.

```factor
100 50 triangulate .s
! => 50
! => 75
! => 2
```

## 5. Résume trois relevés

Trois relevés consécutifs se résument en leur **somme**, leur **produit** et leur **maximum**. Chaque statistique utilise les trois relevés.

Définis `triangle-stats` pour renvoyer les trois.

```factor
5 3 8 triangle-stats .s
! => 16
! => 120
! => 8
```
