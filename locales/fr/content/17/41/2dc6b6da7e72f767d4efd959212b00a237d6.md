# Instructions

Tu travailles à la mise en œuvre d'un système de suivi de santé. Dans ce cadre, tu dois suivre les statistiques de santé des utilisateurs.

Tu commenceras avec quelques fonctions vides dans un bloc `impl`, ainsi qu'avec la définition de structure suivante :

```rust
pub struct User {
    name: String,
    age: u32,
    weight: f32,
}
```

Ton objectif est d'implémenter les méthodes vides de la `struct` `User` définie dans le bloc `impl`.

Par exemple, la méthode `new` doit renvoyer une instance de la `struct` `User` avec les valeurs de nom, d'âge et de poids indiquées.

```rust
let mut bob = User::new(String::from("Bob"), 32, 155.2);
// Returns: a User with name "Bob", age 32, and weight 155.2
```

La méthode `weight` doit renvoyer le poids de l'utilisateur.

```rust
bob.weight();
// Returns: 155.2
```

La méthode `set_age` doit définir l'âge de l'utilisateur.

```rust
bob.set_age(33);
// Updates Bob's age to 33; happy birthday Bob!
```

Amuse-toi bien !
