# Introduction

La récursion est une façon de répéter du code dans une fonction en faisant en sorte que la fonction s'appelle elle-même.
On peut la voir comme une autre manière de boucler ou d'itérer.
Comme pour les boucles, on utilise une expression booléenne ou un test `True`/`False` pour déterminer quand arrêter l'exécution récursive.
Contrairement aux boucles, une récursion sans condition d'arrêt ne peut pas tourner indéfiniment en Python.
Les valeurs utilisées dans chaque appel de fonction sont placées dans leur propre [cadre][stack-frame] sur la [pile d'appels][what-is-the-call-stack] de l'interprète Python.
Si le nombre total d'appels de fonction occupe plus d'espace que la pile n'en a, cela provoque une erreur.

```python
def print_increment(step, max_value):
    if step > max_value:
        return
    print(f'The step is {step}')
    print_increment(step + 1, max_value)


def main():
    print_increment(1, 2)
    print("After recursion")

if __name__ == "__main__":
    main()

```

Cela affiche

```
The step is 1
The step is 2
After recursion
```

Il y a parfois des situations qui sont plus lisibles et/ou plus faciles à comprendre lorsqu'elles sont exprimées avec la récursion plutôt qu'avec une boucle.
