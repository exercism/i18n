# préfère un type de retour explicite

Pour te prémunir contre les modifications accidentelles, définis toujours le type de `return` pour les API publiques, comme les fonctions exportées avec `export` :

\`\`\`typescript
  ${'signature'}: <return-type> {}
\`\`\`

TypeScript est vraiment doué pour l'inférence de type et attribuera un type de `return` à toutes les fonctions. Mais des modifications accidentelles peuvent changer ce type inféré, et cela peut ou non provoquer une erreur de compilation à la source de cette modification. Ajouter un type de retour explicite peut faire échouer la compilation à la source.
