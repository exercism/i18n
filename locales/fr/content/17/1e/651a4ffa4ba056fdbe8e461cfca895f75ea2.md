# Introduction

Une `string` en C++ est un objet modifiable qui représente du texte sous la forme d'une séquence de caractères (lettres, chiffres, ponctuation, etc.). On manipule les _strings_ en appelant les méthodes de la _string_.

## La bibliothèque de _strings_

En C++, le type _string_ et les fonctions associées doivent être inclus depuis la bibliothèque de _strings_ avant de pouvoir être utilisés. Pour cela, ajoute `#include <string>` en haut de ton fichier. Ils peuplent alors l'espace de noms `std`. Le nom pleinement qualifié du type _string_ est `std::string`. Le littéral de _string_ s'écrit avec le caractère guillemet double : `"`.

```cpp
#include <string>
std::string w_berry_quote{"A well-made sentence, I think, is a thing of beauty."};
```

## Les opérations courantes sur les _strings_

Tu peux utiliser l'opérateur `+` pour concaténer des _strings_ :

```cpp
std::string original_title{"The School of Rock"};
std::string sequel_indicator{"Electric Boogaloo"};
std::string next_movie_title = original_title + " 2: " + sequel_indicator;
```

Pour utiliser la bibliothèque de _strings_, il faut savoir qu'il est possible d'appeler une fonction qui appartient à un objet. On les appelle des fonctions membres. Plus tard dans le programme, tu en apprendras davantage sur les fonctions membres et sur le concept de classe qui leur est associé.

```cpp
std::string qualification{"awesome"};
// 1st argument: from the index to the end of the string:
std::string who_is_awesome = qualification.substr(5);
// => "me"

// 2nd optional argument for the length:
std::string material{"haunted books"};
std::string ghost = material.substr(8, 3);
// => "boo"
```


La fonction `find` est elle aussi très utile. Elle s'appelle comme fonction membre sur la _string_ et prend une _string_ en argument. `find` renvoie la position, indexée à partir de zéro, de la _première_ occurrence dans la _string_.

```cpp
std::string new_release{"apple released a new app!"};
new_release.find("app");
// => 0
new_release.find("e");
// => 4
```

Il existe aussi la fonction `std::to_string`, qui permet de convertir des entiers et des nombres à virgule flottante en _string_.

```cpp
int num{92};
double exponent{0.92e2};
std::string msg{ std::to_string(num) + " can also be written as " + std::to_string(exponent)};
// => 92 can also be written as 92.0000000
```
