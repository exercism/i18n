# À propos

Les méthodes peuvent prendre un paramètre _varargs_, ce qui permet à l'appelant de fournir zéro ou plusieurs arguments comme s'il s'agissait de paramètres normaux. La méthode recevra ces arguments dans un seul tableau.

Pour transformer un paramètre en paramètre _varargs_, ajoute le [mot-clé `params`](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/keywords/params) à la déclaration du paramètre :

```csharp
public static void PrintNumbers(params int[] numbers)
{
    foreach (var number in numbers)
    {
        Console.Write(number)
    }
}

// No values for a varags parameter is allowed
PrintNumbers();

PrintNumbers(1);
// => 1

PrintNumbers(1, 2, 3);
// => 123
```
