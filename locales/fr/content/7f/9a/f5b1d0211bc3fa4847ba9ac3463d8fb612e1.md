# Instructions

Un spectacle de cirque, c'est une succession de numéros. Chaque numéro a un contenu complètement différent, et la personne qui monte le spectacle a besoin des deux mêmes choses de la part de chacun.

C'est le premier exercice où tu écris plusieurs classes dans un même fichier. Le squelette te fournit la classe abstraite ; écris le reste en dessous.

## 1. Les trois numéros

Écris trois classes, chacune étant un `$ACT`.

| Classe | `name` | `minutes` |
| --- | --- | --- |
| `JUGGLING` | `"Juggling"` | 5 |
| `TUMBLING` | `"Tumbling"` | 3 |
| `TRAPEZE` | `"Trapeze at "` puis la hauteur puis `"m"` | 8 |

`JUGGLING` et `TUMBLING` se construisent sans argument. `TRAPEZE` se construit avec la hauteur en mètres :

```sather
#JUGGLING
#TRAPEZE(4)
```

donc `#TRAPEZE(4).name` vaut `"Trapeze at 4m"`.

## 2. Le spectacle

Écris une classe `CIRCUS_ACTS` avec trois routines, chacune prenant l'ordre de passage sous la forme d'un `ARRAY{$ACT}`.

**`total_minutes`** : la durée totale du spectacle.

```sather
CIRCUS_ACTS::total_minutes(|#JUGGLING, #TUMBLING|)
-- => 8
```

**`billing`** : les noms des numéros, réunis par `", "`.

```sather
CIRCUS_ACTS::billing(|#JUGGLING, #TUMBLING|)
-- => "Juggling, Tumbling"
```

**`longest`** : le nom du numéro qui dure le plus longtemps. Si deux numéros sont à égalité, c'est le premier qui l'emporte. Un spectacle vide n'a pas de numéro le plus long, la réponse est donc `""`.

```sather
CIRCUS_ACTS::longest(|#JUGGLING, #TUMBLING|)
-- => "Juggling"
```

Aucune des trois ne doit chercher à savoir de quel type de numéro il s'agit.
