# pas d'export nommé

L'instruction [`export %{export.name}`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/export) est introuvable. Les tests ne passeront pas sans elle.

Vérifie que `%{export.name}` existe bien et ajoute `export` devant :
```javascript
// exporting a "const"
export const %{export.name} = /*...*/

// exporting a named function declaration
export function %{export.name}() { /* ... */ }
```
