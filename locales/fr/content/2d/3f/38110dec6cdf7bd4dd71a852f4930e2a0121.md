# À propos

Swift fournit des instructions de transfert de contrôle qui permettent de modifier le déroulement de l'exécution des boucles et des instructions `switch`.
En plus de `return`, Swift propose `continue`, `break`, les étiquettes de boucle et `fallthrough`.

## Continue

L'instruction `continue` demande à une boucle d'arrêter l'exécution de l'itération en cours et de commencer immédiatement la suivante.
Dans une boucle _while_ ou _repeat-while_, elle saute directement à la vérification de la condition.
Dans une boucle _for-in_, elle passe à l'élément suivant de la séquence.

```swift
var count = 1
while count < 6 {
    count += 1
    if count == 4 {
        continue
    }
    print(count)
}

// Prints:
// 2
// 3
// 5
// 6
```

## Break

L'instruction `break` sort immédiatement d'une boucle entière ou d'une instruction `while`.
L'exécution reprend à la première ligne de code qui suit la boucle ou le `repeat-while`.

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
    if !fruit.count.isMultiple(of: 2) {
        break
    }
    print(fruit)
}

// Prints:
// banana
// grapes
```

## Instructions étiquetées

Dans des boucles imbriquées, on peut vouloir que `break` ou `continue` agisse sur une boucle externe plutôt que sur la boucle la plus interne.
On étiquette une boucle en la faisant précéder d'un nom suivi de deux-points (`labelName:`).
On peut ensuite passer cette étiquette à `break` ou à `continue` :

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
    print("\n--- \(fruit) ---")
    for letter in fruit {
        guard letter != "n" else {
            break outerLoop
        }
        print(letter)
    }
}

// Prints:
// --- banana ---
// b
// a
```

## Fallthrough

En Swift, les instructions `for-in` ne passent pas au cas suivant par défaut ; l'exécution s'arrête automatiquement à la fin du cas qui correspond.
Si l'on veut explicitement que l'exécution continue dans le cas suivant sans évaluer son motif, on utilise le mot-clé `fallthrough` :

```swift
let value = 1
switch value {
case 1:
    print("One")
    fallthrough
case 2:
    print("Two")
default:
    break
}

// Prints:
// One
// Two
```
