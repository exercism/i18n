# Introduction

## Booléens

Le type booléen en Lua possède les deux valeurs booléennes traditionnelles : `true` et `false`. On peut affecter ces valeurs à une variable, les combiner avec des opérateurs logiques (`and`, `or`, `not`) et les utiliser dans des tests conditionnels (par exemple dans des structures de contrôle).

```lua
local is_true = true
local is_false = false

true and true  --> true
true and false --> false
false or true  --> true
false or false --> false
not false      --> true
not true       --> false

-- prints 0
if is_true == true then
  print(0)
else
  print(1)
end
```

Les tests conditionnels et les opérateurs logiques considèrent comme faux à la fois le booléen `false` et `nil`, et comme vrai tout le reste.
```lua
1 and 2          --> 2
nil and 2        --> nil
false and 2      --> false
1 or 2           --> 1
false or 'hello' --> "hello"
nil or false     --> false
```

`and` et `or` utilisent tous les deux une *évaluation en court-circuit*, ce qui signifie qu'ils n'évaluent leur second opérande que lorsque c'est nécessaire. Toutes les opérations sont évaluées selon la [priorité des opérateurs](https://www.lua.org/manual/5.4/manual.html#3.4.8), où `not` est évalué avant `and` et `or`.
