# Instructions

Tu participes à un recensement des oiseaux. Chaque jour, quelqu'un s'installe dans un affût et compte ce qui passe en volant, et les comptages de la journée reviennent sous forme de tableau.

Les cinq tâches sont à effectuer dans la classe `BIRD_SURVEY`.

## 1. Le total

Fais la somme des comptages de chaque jour.

```sather
BIRD_SURVEY::total_seen(|3, 0, 7|)
-- => 10
```

Un recensement sans aucun jour compte zéro oiseau.

## 2. Le meilleur jour

Renvoie le plus grand comptage. S'il n'y a aucun jour, la réponse est zéro.

```sather
BIRD_SURVEY::busiest_day(|3, 0, 7|)
-- => 7
```

## 3. Les jours chargés

Combien de jours ont un comptage supérieur à un certain nombre ?

```sather
BIRD_SURVEY::days_over(|3, 0, 7|, 2)
-- => 2
```

Supérieur veut dire strictement supérieur : un comptage d'exactement 2 ne compte pas.

## 4. Les affûts à vérifier

Le premier jour du recensement, tu vérifies un affût, le deuxième jour deux, et ainsi de suite. Combien de vérifications d'affûts cela fait-il au total ?

```sather
BIRD_SURVEY::hides_to_check(4)
-- => 10
```

C'est 1 + 2 + 3 + 4.

## 5. Le premier jour chargé

Quel jour a été le premier avec un comptage supérieur à un certain nombre ? Les jours sont numérotés à partir de zéro, comme les positions dans un tableau. Si aucun jour n'a été aussi chargé, la réponse est `-1`.

```sather
BIRD_SURVEY::first_busy_day(|3, 0, 7|, 5)
-- => 2
BIRD_SURVEY::first_busy_day(|3, 0, 7|, 9)
-- => -1
```
