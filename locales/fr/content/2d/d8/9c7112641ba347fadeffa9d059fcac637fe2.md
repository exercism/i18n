# Ajout aux instructions

## Implémentation

Définis
`type Classification`
pour contenir les valeurs de classification des nombres naturels.
Tu peux choisir n'importe quelle représentation pour ce type.

Définis trois constantes Classification nommées

```text
	ClassificationDeficient
	ClassificationPerfect
	ClassificationAbundant
```

Implémente une fonction nommée Classify qui accepte
une entrée int64 et renvoie une Classification et une valeur d'erreur.

Crée une erreur nommée ErrOnlyPositive
qui est renvoyée quand l'entrée n'est pas un entier positif.
