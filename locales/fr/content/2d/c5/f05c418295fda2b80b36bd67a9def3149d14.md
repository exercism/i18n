# Instructions complémentaires

## Indices

Si l'argument est inférieur à `1`, renvoie [`NONE`](https://smlfamily.github.io/Basis/option.html#SIG:OPTION.option:TY:SPEC).

Certains de ces concepts peuvent t'aider :

- [L'évaluation paresseuse](https://en.wikipedia.org/wiki/Lazy_evaluation)
- Le crible (par exemple [le crible d'Ératosthène](https://en.wikipedia.org/wiki/Sieve_of_Eratosthenes)
- La primalité par [division par essais](https://en.wikipedia.org/wiki/Trial_division)
