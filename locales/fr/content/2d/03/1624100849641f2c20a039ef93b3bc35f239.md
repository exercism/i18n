# Agence de design web

## Histoire

Ton agence de design a surtout travaillé avec des transformations CSS pour construire des pages web. Après quelques discussions, la décision est prise de commencer à utiliser JavaScript pour effectuer certains calculs de façon dynamique. Certains de tes coéquipiers connaissent moins bien JavaScript, tu décides donc d'utiliser une fermeture de fonction pour créer une transformation réutilisable pour des paires de coordonnées `{x, y}`.

## Tâches

- Crée une fonction dont les arguments servent de fermeture dans une fonction renvoyée.

  - Une fonction de translation 2D, où la fonction externe indique la translation à appliquer, et la fonction renvoyée prend une coordonnée x, y et renvoie les coordonnées translatées.
  - Une fonction de mise à l'échelle 2D, où la fonction externe indique le facteur d'échelle, et la fonction renvoyée prend une coordonnée x, y et renvoie les coordonnées translatées.
  - Une fonction qui renvoie une fonction qui compose deux fonctions, autrement dit une fonction pour `g(f(x))`

- Crée une fonction qui mémoïse une fonction.
