# Ajout aux instructions

## Implémentation

Les tests nécessitent un constructeur qui prend un tableau. L'implémentation interne de ton ensemble personnalisé peut utiliser d'autres structures de données, mais tu devras peut-être implémenter un constructeur externe qui prend exactement un tableau pour que les tests passent.

Certaines méthodes ont un opérateur Unicode équivalent. Par exemple, `intersect(CustomSet([1, 2, 3, 4]), CustomSet([]))` équivaut à `CustomSet([1, 2, 3, 4]) ∩ CustomSet([])`.
