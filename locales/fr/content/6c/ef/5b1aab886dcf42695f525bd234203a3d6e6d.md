# Introduction

De nombreux langages de programmation ont des types numériques spécifiques pour représenter différents types de nombres, mais JavaScript n'en a que deux :

- `number` : un type de données numérique au format à virgule flottante 64 bits en double précision (IEEE 754).
  Quelques exemples : `-6`, `-2.4`, `0`, `0.1`, `1`, `3.14`, `16.984025`, `25`, `976`, `1024.0` et `500000`.
- `bigint` : un type de données numérique qui peut représenter des nombres entiers au format de précision arbitraire.
  Quelques exemples : `-12n`, `0n`, `4n` et `9007199254740991n`.

Si tu as besoin d'une [précision arbitraire][ref-arbitrary-precision] ou que tu travailles avec des nombres extrêmement grands, utilise le type `bigint`.
Sinon, le type `number` est sans doute le meilleur choix.

## Arrondi

Il existe un objet global intégré appelé `Math` qui fournit diverses [fonctions d'arrondi][ref-math-object-rounding]. Par exemple, tu peux arrondir à l'inférieur (`floor`) ou au supérieur (`ceil`) des nombres décimaux vers l'entier le plus proche.

```javascript
Math.floor(234.34); // => 234
Math.ceil(234.34); // => 235
```
