# Intervalles

[Les intervalles][range] représentent un intervalle entre deux valeurs.
Les types les plus courants qui prennent en charge les intervalles sont `Integer` et `String`.
Ils servent à beaucoup de choses : créer rapidement une collection, découper des _strings_, vérifier si une valeur se trouve dans un intervalle, ou encore itérer.
On les crée à l'aide de l'opérateur d'intervalle `..` ou `...` (respectivement inclusifs et exclusifs).

```ruby
1..5  # => 1..5
1...5 # => 1...5

(1..5).to_a # => [1, 2, 3, 4, 5]
(1...5).to_a # => [1, 2, 3, 4]
```

La raison d'avoir deux opérateurs d'intervalle est de permettre de créer des intervalles inclusifs ou exclusifs de la valeur de fin, ce qui peut être utile quand on travaille par exemple avec des indices qui commencent à zéro.

On peut aussi créer des intervalles avec le constructeur `Range`, `new`.

```ruby
Range.new(1, 5) # A range containing 1, 2, 3, 4, 5
```

~~~~exercism/note
Quand tu crées un intervalle en Ruby avec les opérateurs `..` ou `...` et que tu veux appeler une méthode sur cet intervalle, tu dois l'entourer de parenthèses.
Sinon, la méthode sera appelée sur le deuxième argument de l'opérateur d'intervalle.

```ruby
(1..5).sum # => 15
1..5.sum # => Error: undefined method `sum' for 5:Integer (NoMethodError)
```
~~~~

## Obtiens des sous-chaînes

Quand tu veux découper une _string_, tu peux utiliser l'opérateur d'intervalle pour obtenir une sous-chaîne.
Autrement dit, en créant un intervalle avec les indices de début et de fin de la sous-chaîne.

```ruby
"Hello World"[0..4] # => "Hello"
"Hello World"[6..10] # => "World"
```

Tu peux aussi utiliser des indices négatifs pour obtenir la sous-chaîne à partir de la fin de la _string_.

```ruby
"Hello World"[-5..-1] # => "World"
"Hello World"[6..-4] # => "Wo"
```

## Méthodes des intervalles

Les intervalles disposent bien d'un ensemble de méthodes pour les manipuler.
Par exemple, ces méthodes permettent d'obtenir la somme de toutes les valeurs de l'intervalle ou de vérifier si l'intervalle contient une valeur.

| Méthode                 | Description                                                                | Exemple                         |
| ----------------------- | -------------------------------------------------------------------------- | ------------------------------- |
| [`sum`][sum]            | Renvoie la somme de toutes les valeurs de l'intervalle                     | `(1..5).sum # => 15`            |
| [`size`][size]          | Renvoie la taille de l'intervalle                                          | `(1..5).size # => 5`            |
| [`include?`][indlude]   | Renvoie `true` si l'intervalle contient la valeur donnée, sinon `false`    | `(1..5).include?(3) # => true`  |

## Intervalles sans fin et sans début

Un intervalle peut être sans fin ou sans début.
Dans un intervalle sans fin ou sans début, la valeur de fin ou de début vaut `nil`, mais on peut omettre ce `nil` au moment de définir l'intervalle.

Les intervalles sans début et sans fin sont pratiques quand tu veux, par exemple, découper une _string_ depuis le début ou jusqu'à la fin.

```ruby
"Hello World"[0..] # => "Hello World"
"Hello World"[4..] # => "o World"
"Hello World"[..5] # => "Hello "
```

~~~~exercism/caution
S'il n'est pas utilisé sur une collection, l'intervalle sans fin peut provoquer une séquence sans fin si l'on n'y prend pas garde.
~~~~

## Intervalles de _string_

On peut aussi utiliser des _strings_ dans des intervalles, ce qui permet d'obtenir un intervalle de _strings_ entre deux _strings_.
Son comportement peut être un peu surprenant avec certaines _strings_, alors utilise-le avec prudence.

```ruby
("aa".."az").to_a # => ["aa", "ab", "ac", ..., "az"]
```
