# Introduction

## Énumérations

Le type `enum` de C# représente un ensemble fixe de constantes nommées (une énumération). Son but principal est de fournir un moyen sûr au niveau des types pour interagir avec des constantes numériques, en limitant les valeurs disponibles à un ensemble prédéfini. On peut définir une énumération simple comme suit :

```csharp
enum Season
{
    Spring,
    Summer,
    Autumn,
    Winter
}
```

S'ils ne sont pas définis explicitement, les membres de l'énumération se voient automatiquement attribuer des valeurs entières successives, la première valant zéro. Il est également possible d'attribuer des valeurs explicitement :

```csharp
enum Answer
{
    Maybe = 1,
    Yes = 3,
    No = 5
}
```
