# Instructions

Dans cet exercice, tu vas écrire du code pour imprimer des badges nominatifs destinés aux employés d'une usine.

## 1. Imprime un badge pour un employé

Les employés ont un identifiant, un nom et un nom de service. Les libellés de badge des employés sont formatés comme suit : `"[id] - name - DEPARTMENT"`. Implémente la méthode (_static_) `Badge.Print()` pour renvoyer le libellé de badge d'un employé :

```csharp
Badge.Print(734, "Ernest Johnny Payne", "Strategic Communication");
// => "[734] - Ernest Johnny Payne - STRATEGIC COMMUNICATION"
```

Note que le nom du service doit être en majuscules sur le libellé.

## 2. Imprime un badge pour un nouvel employé

En raison d'une bizarrerie du système informatique, il arrive parfois que les nouveaux employés n'aient pas encore d'identifiant lorsqu'ils commencent à travailler à l'usine. Comme les badges sont obligatoires, ils recevront un badge temporaire sans le préfixe d'identifiant. Modifie la méthode (_static_) `Badge.Print()` pour prendre en charge les nouveaux employés qui n'ont pas encore d'identifiant :

```csharp
Badge.Print(id: null, "Jane Johnson", "Procurement");
// => "Jane Johnson - PROCUREMENT"
```

## 3. Imprime un badge pour le propriétaire

Même le propriétaire de l'usine doit porter un badge en permanence. Cependant, un propriétaire n'a pas de service. Dans ce cas, le libellé doit afficher `"OWNER"` au lieu du nom du service. Modifie la méthode (_static_) `Badge.Print()` pour afficher un libellé pour le propriétaire :

```csharp
Badge.Print(254, "Charlotte Hale", department: null);
// => "[254] - Charlotte Hale - OWNER"
```

Note qu'il est possible que le propriétaire soit aussi un nouvel employé :

```csharp
Badge.Print(id: null, "Charlotte Hale", department: null);
// => "Charlotte Hale - OWNER"
```
