# Calcule la distance dans le constructeur

Tu peux envisager de calculer la distance de Hamming dans le constructeur et de stocker le résultat dans une variable membre, que tu pourras renvoyer dans `getHammingDistance()`.
Cette solution semble calculer la distance de Hamming dans la méthode `getHammingDistance()`.
Cela signifie que le calcul sera peut-être refait, à moins que le résultat ne soit stocké puis récupéré (auquel cas tu peux ignorer cette recommandation).
