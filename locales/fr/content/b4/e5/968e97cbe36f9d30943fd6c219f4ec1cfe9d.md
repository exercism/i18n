# À propos des opérateurs arithmétiques

## Opérateurs

Go prend en charge les opérateurs arithmétiques suivants :

| Opérateur | Exemple        |
| -------- | -------------- |
| `+`      | `4 + 6 == 10`  |
| `-`      | `15 - 10 == 5` |
| `*`      | `2 * 3 == 6`   |
| `/`      | `13 / 3 == 4`  |
| `%`      | `13 % 3 == 1`  |

Pour la division entière, le reste est ignoré (par exemple `5 / 2 == 2`).

L'opérateur `+` permet aussi de concaténer des _strings_ : `"foo" + "bar" == "foobar"`.

## Arithmétique entre types différents

Go n'autorise pas les opérations arithmétiques entre des types numériques différents :

```go
x := 42
n := 2.0
value := n * x // invalid operation: n * x (mismatched types float64 and int)
```

Les opérandes doivent être du même type, ce qui demande parfois une conversion explicite :

```go
x := float64(42)
n := 2.0
value := n * x 
```

## Affectations raccourcies

Chaque opérateur possède une forme d'affectation raccourcie qui met à jour la variable directement :

```go
a := 1
a += 2 // same as a = a + 2 == 3

b := 2
b -= 2 // same as b = b - 2 == 0

c := 4
c *= 2 // same as c = c * 2 == 8

d := 8
d /= 2 // same as d = d / 2 == 4

e := 16
e %= 2 // same as e = e % 2 == 0
```

## Incrémentation et décrémentation

Placées après une variable, les instructions d'incrémentation (`++`) et de décrémentation (`--`) augmentent ou diminuent de 1 la valeur numérique qu'elle stocke.
Les placer avant une variable provoque une erreur de syntaxe.

```go
a := 10
a++ // same as a += 1, a == 11

b := 10
b-- // same as b -= 1, b == 9
```

Comme ce sont des instructions, elles ne renvoient pas de valeur.
