# Introduction

## Propriétés

Une propriété en C# est un membre d'une classe qui permet d'accéder aux données de cette classe.
Les appelants peuvent définir ou récupérer (get) les données. Les propriétés peuvent être soit auto-implémentées, soit
avoir un champ de stockage. Elles comprennent un accesseur set et/ou un accesseur get.
Dans d'autres langages, un « mutator » est à peu près équivalent à
un accesseur set, et un « accessor » est à peu près équivalent à un accesseur get, bien que
la composition de la syntaxe soit complètement différente.

Lors de la définition d'une propriété, la valeur d'entrée peut être validée, formatée
ou autrement manipulée, et en fait toute opération programmatique accessible au code de la
classe peut être exécutée.

De même, lors de la récupération d'une propriété, les données peuvent être calculées ou formatées, et là encore,
toute opération programmatique disponible pour la classe peut être exécutée.

Les propriétés ont des modificateurs d'accès (`public`, `private`, etc.) de la même manière que les autres
membres de la classe, mais l'accesseur set peut avoir un niveau d'accès indépendant de l'accesseur de récupération (get)
et inversement. Une propriété ne doit pas nécessairement avoir les deux accesseurs, elle peut n'en avoir qu'un seul (soit get, soit set).

La syntaxe de base pour exprimer les propriétés peut prendre deux formes :

### Propriétés basées sur un champ ou une expression :

```csharp
private int myField;
public int MyProperty
{
    get { return myField; }
    set { myField = value; }
}
```

### Propriétés auto-implémentées

```
public int MyProperty { get; private set; } = 42;
```

L'initialisation est facultative.
