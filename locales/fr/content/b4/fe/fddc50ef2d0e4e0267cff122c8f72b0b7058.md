# Ajout aux instructions

## Astuces

Tu dois implémenter les fonctions `label` et `ohms`. Tu peux utiliser la signature fournie pour `label`, mais ne la laisse pas restreindre ta créativité.

Cet exercice traite des données textuelles. Pour des raisons historiques, le type `String` de Haskell est synonyme de `[Char]`, une liste de caractères. Pour une gestion plus efficace des données textuelles, on peut utiliser le type `Text`.

Comme extension optionnelle à cet exercice, tu peux

- Lis à propos des [types de _string_](https://haskell-lang.org/tutorial/string-types) en Haskell.
- Ajoute `- text` à ta liste de dépendances dans package.yaml.
- Importe `Data.Text` de [la façon suivante](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c) :

    ```haskell
    import qualified Data.Text as T
    import           Data.Text (Text)
    ```

- Tu peux maintenant écrire par exemple `label :: Resistor -> Text` et faire référence aux combinateurs de `Data.Text` comme par exemple `T.pack`.
- Consulte la documentation de [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html),

Cette partie est entièrement facultative.
