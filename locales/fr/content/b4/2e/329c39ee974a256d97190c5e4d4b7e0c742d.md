# Indices

## Général

- Ne te préoccupe pas de la façon dont les arguments sont obtenus, concentre-toi simplement sur leur combinaison pour renvoyer le résultat attendu.

## 1. Définis si pac-man peut manger un fantôme

- La fonction doit renvoyer une valeur [booléenne][boolean].
- Tu peux utiliser l'opérateur [booléen][boolean] [`and/2`][boolean-and] pour combiner les arguments afin d'obtenir un résultat.

## 2. Définis si pac-man marque des points

- La fonction doit renvoyer une valeur [booléenne][boolean].
- Tu peux utiliser l'opérateur [booléen][boolean] [`or/2`][boolean-or] pour combiner les arguments afin d'obtenir un résultat.

## 3. Définis si pac-man perd

- La fonction doit renvoyer une valeur [booléenne][boolean].
- Tu peux utiliser les opérateurs [booléens][boolean] [`and/2`][boolean-and] et [`not/1`][boolean-not] pour combiner les arguments afin d'obtenir un résultat.

## 4. Définis si pac-man gagne

- La fonction doit renvoyer une valeur [booléenne][boolean].
- Tu peux utiliser les opérateurs [booléens][boolean] [`and/2`][boolean-and] et [`not/1`][boolean-not] pour combiner les arguments et les résultats de l'une des fonctions implémentées précédemment.

[boolean]: https://hexdocs.pm/elixir/basic-types.html#booleans-and-nil
[boolean-and]: https://hexdocs.pm/elixir/Kernel.html#and/2
[boolean-or]: https://hexdocs.pm/elixir/Kernel.html#or/2
[boolean-not]: https://hexdocs.pm/elixir/Kernel.html#not/1
