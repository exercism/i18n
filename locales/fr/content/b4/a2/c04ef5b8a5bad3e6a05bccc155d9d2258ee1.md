# Instructions

Tu es le commissaire de bord du navire, chargé de gérer l'inventaire du garde-manger. L'inventaire est une table de hachage où chaque clé est le nom d'un objet et où la valeur correspond à la quantité en stock.

## 1. Construis un inventaire à partir d'une liste

Définis `create-inventory` de sorte qu'elle prenne une séquence de noms d'objets et renvoie une table de hachage qui associe chaque nom unique à son nombre d'occurrences.

```factor
{ "coal" "wood" "wood" "diamond" "diamond" "diamond" } create-inventory .
! => H{ { "coal" 1 } { "wood" 2 } { "diamond" 3 } }
```

## 2. Ajoute d'autres objets

Définis `add-items` de sorte qu'elle prenne un inventaire et une séquence d'objets et renvoie un nouvel inventaire dont les quantités ont été incrémentées pour chaque objet listé. L'inventaire d'origine ne doit pas être modifié.

```factor
H{ { "coal" 1 } } { "wood" "iron" "coal" "wood" } add-items .
! => H{ { "coal" 2 } { "wood" 2 } { "iron" 1 } }
```

## 3. Décrémente les quantités

Définis `decrement-items` de sorte qu'elle prenne un inventaire et une séquence d'objets et renvoie un nouvel inventaire dont les quantités ont été diminuées de un pour chaque objet listé. Les quantités ne doivent jamais descendre en dessous de zéro, et les objets qui ne sont pas déjà dans l'inventaire doivent être ignorés (aucune entrée négative n'est insérée).

```factor
H{ { "coal" 3 } { "diamond" 1 } { "iron" 5 } }
{ "diamond" "coal" "iron" "iron" } decrement-items .
! => H{ { "coal" 2 } { "diamond" 0 } { "iron" 3 } }
```

## 4. Supprime complètement un objet

Définis `remove-item` de sorte qu'elle prenne un inventaire et un objet et renvoie un nouvel inventaire dans lequel cet objet a été supprimé. Si l'objet n'est pas présent, renvoie une copie inchangée.

```factor
H{ { "coal" 2 } { "wood" 1 } { "diamond" 2 } } "coal" remove-item .
! => H{ { "wood" 1 } { "diamond" 2 } }
```

## 5. Liste les objets disponibles

Définis `list-inventory` de sorte qu'elle prenne un inventaire et renvoie un tableau de paires `{ name quantity }` ne contenant que les objets dont la quantité est supérieure à zéro, trié par ordre alphabétique du nom.

```factor
H{ { "coal" 7 } { "wood" 11 } { "diamond" 2 } { "iron" 7 } { "silver" 0 } }
list-inventory .
! => { { "coal" 7 } { "diamond" 2 } { "iron" 7 } { "wood" 11 } }
```
