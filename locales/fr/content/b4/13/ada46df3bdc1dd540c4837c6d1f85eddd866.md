# Introduction

AWK est un langage très simple qui ne possède que quelques types de données de base.
Dans cette leçon, on va voir les nombres et les _strings_.

## Les nombres

Les nombres en AWK sont implémentés sous forme de nombres à virgule flottante en double précision.
Il n'y a pas de distinction entre les entiers, les nombres à virgule flottante et les doubles.

AWK reconnaît les constantes numériques octales (commençant par `0`) et les constantes numériques hexadécimales (commençant par `0x` ou `0X`).

### Les opérations numériques

On peut utiliser les [opérateurs arithmétiques standards][ops-arith] `+`, `-`, `*`, `/`, `%`.
L'opérateur d'exponentiation est `^` (il est spécifié par POSIX), même si `**` peut aussi être utilisé.
Il existe plusieurs [fonctions numériques intégrées][funcs-numeric], notamment les fonctions trigonométriques, la génération de nombres aléatoires, et `int(x)` pour tronquer un nombre vers l'entier le plus proche entre _x_ et zéro.

Il n'existe pas d'_opérateurs_ bit à bit.
gawk les implémente sous forme de fonctions.
Les arguments doivent être des nombres non négatifs.

| fonction            | opération                                         |
| ------------------- | ------------------------------------------------- |
| `and(a, b [, ...])` | ET bit à bit des arguments                        |
| `or(a, b [, ...])`  | OU bit à bit des arguments                        |
| `xor(a, b [, ...])` | OU exclusif bit à bit des arguments               |
| `lshift(v, count)`  | la valeur de _v_ décalée de _count_ bits vers la gauche |
| `rshift(v, count)`  | la valeur de _v_ décalée de _count_ bits vers la droite |
| `compl(v, count)`   | complément bit à bit de _v_                       |

## Les _strings_

Les _strings_ en AWK sont des séquences de caractères.
Une constante _string_ s'écrit entre guillemets doubles.

~~~~exercism/caution
GNU awk autorise les caractères Unicode dans les _strings_ : d'autres implémentations d'awk ne le font pas forcément.
Comparons `gawk` et `mawk`, une autre implémentation populaire d'AWK :

```sh
$ echo "Hi friend 😀!" | gawk '{print length($3)}'
2
$ echo "Hi friend 😀!" | mawk '{print length($3)}'
5
```
~~~~

### Les opérations sur les _strings_

Il n'existe qu'une seule opération sur les _strings_ : la concaténation.
La concaténation n'a pas d'opérateur dédié ;
il suffit de placer deux _strings_ côte à côte pour les concaténer :

```awk
BEGIN {
    hw = "Hello" "World"
    print hw
}
# => HelloWorld
```

~~~~exercism/note
`print` est une **instruction**, pas une fonction.
`print` ne nécessite pas de parenthèses.
~~~~

AWK dispose d'une multitude de [fonctions de manipulation de _strings_][funcs-string].
On les découvrira en détail au fil du parcours.

## Convertir entre les nombres et les _strings_

Il n'existe pas d'opérateurs explicites pour convertir entre les nombres et les _strings_.
AWK le fait implicitement selon le contexte du programme.
Cela simplifie beaucoup le travail avec les valeurs des champs d'entrée : AWK fait généralement exactement ce que tu attends de lui.

* `print x + y` convertit les valeurs des variables `x` et `y` en nombres grâce à l'opération numérique `+`.
* `print x y` convertit les valeurs des variables `x` et `y` en _strings_ grâce à l'opération de concaténation.

Si tu veux être explicite, `0 + x` donne la représentation numérique de _x_ et `"" x` donne la représentation sous forme de _string_ de _x_.

### Des _strings_ vers les nombres

La façon dont AWK convertit une _string_ en nombre peut être déroutante.
Une façon simple de le voir : AWK lit les « caractères numériques » depuis le début de la _string_ jusqu'à ce qu'il rencontre un caractère « non numérique ».
Voici quelques exemples :

* `"2.5"` se convertit en nombre `2.5` ;
* `"1e3"` se convertit en nombre `1000` (notation scientifique) ;
* `"456abc"` se convertit en nombre `456` (comme `a` n'est pas un chiffre, la conversion s'arrête là).
* `"abc789"` se convertit en nombre `0` (il n'y a aucun chiffre au **début** de la _string_).

Tous les détails sont [dans le manuel][str-to-num].

## Déterminer le type d'une variable

La [fonction `typeof(var)`][func-typeof] renvoie le type sous forme de _string_.

```awk
BEGIN {
    x = "42"
    print x, typeof(x)
    x = x + 1           # type conversion
    print x, typeof(x)
}
```
affiche
```none
42 string
43 number
```
