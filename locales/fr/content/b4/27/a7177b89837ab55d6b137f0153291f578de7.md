## Variables

Les variables sont des noms symboliques, qui désignent soit des valeurs, soit des conteneurs.
Un nom de variable peut commencer, ou non, par un caractère spécial appelé [_sigil_][sigils], suivi d'un identifiant.
Un _sigil_ peut lui-même être suivi d'un [_twigil_][twigils].

Chaque sigil correspond à un type de structure de données différent.

```raku
my $scalar; # Assigned value will be stored as-is
my @array;  # Assigned value will be coerced into an array
my %hash;   # Assigned value will be coerced into a hash
my &code;   # Assigned value must be a code object
```

Les _twigils_ que l'on rencontre le plus souvent sont `^` et `:`, qui servent de raccourcis pour les signatures de blocs de code.
Le `^` sert aux paramètres positionnels.
Le `:` sert aux paramètres nommés.

```raku
{ $^a + $^b }; #`[same as] ->  $a,  $b { $a + $b }; # Called with (1, 2)
{ $:a + $:b }; #`[same as] -> :$a, :$b { $a + $b }; # Called with (a => 1, b => 2)
```

## Conteneurs

Les conteneurs sont ce qui permet de modifier une variable.

Les variables déclarées avec `constant`, ainsi que les variables sans sigil (déclarées avec un `\` devant l'identifiant), n'ont pas de conteneur et désignent directement des valeurs.

```raku
my $foo = 1;
$foo = 2;

constant $bar = 3;
my \baz = 4;

# The following will fail
$bar = 5;
baz  = 6;
```

## Types

Une variable peut être déclarée avec une contrainte de type.
Les contraintes de type peuvent aussi porter des coercions, en donnant un type accepté comme argument au type souhaité.

```raku
my Bool   $foo = True; # Booleans only.
my Bool() $bar = 0;    # Accepts type `Any`. Coerced to False.

my Str(Bool(Int)) $baz;
$baz = 1;   # "True"
$baz = "1"; # "1"
```

Utiliser des contraintes de type est une façon de tirer parti des routines à multi-dispatch.

```raku
multi foo (Int $bar) { say 'Type of arg to $bar is Int!' }
multi foo (Str $bar) { say 'Type of arg to $bar is Str!' }
```

En Raku, les types sont simplement une autre sorte d'objet.
Déclarer une `class`, un `role` ou une `enum` est une façon de créer tes propres objets de type.
Par exemple, le type intégré `Bool` est construit à partir d'une énumération : `enum Bool <False True>`.

Tu peux aussi créer des contraintes de type simples à partir d'autres types avec le mot-clé `subset`.
Tu peux restreindre davantage ce nouveau type en utilisant une clause `where`.
Une clause `where` peut aussi s'employer dans une signature.

```raku
subset PositiveInt of Int where * > 0;

sub is-even (PositiveInt $n where  %% 2) { say "$n is even!" }
```
