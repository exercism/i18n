# Introduction

## Paquetages et modules

### Importe

Un module se charge généralement avec le mot-clé `use`.
Cela le charge et appelle sa méthode `import`, ce qui importe tous les symboles exportés.

Les symboles présents dans le tableau `@EXPORT` du paquetage sont importés par défaut.
Ceux du tableau `@EXPORT_OK` doivent être importés explicitement.

### Exporte

Pour qu'un symbole puisse être importé, il doit d'abord être exporté.
Le module [Exporter][Exporter] est fourni avec Perl et c'est l'une des options les plus pratiques pour exporter.

Définition du module :
```perl
package Foo;

use Exporter ('import');
our @EXPORT_OK = ('bar');

sub bar { ... }
```

Utilisation du module :
```perl
use Foo ('bar');

bar();
```

### Modules de base

En plus d'[Exporter][Exporter], Perl dispose d'une grande variété de [modules de base][perl-core-modules] que l'on peut utiliser.
Quelques exemples utiles pour les exercices que tu pourrais rencontrer ici : [List::Util][List::Util], [Time::Piece][Time::Piece] et [Math::BigRat][Math::BigRat].

### CPAN

En plus des modules de base, [CPAN][metacpan] met à disposition des milliers de modules supplémentaires créés par la communauté Perl, prêts à être installés.
Le parcours Perl utilise un [cpanfile][test-runner-cpanfile] pour installer une sélection de modules utilisables avec l'exécuteur de tests Perl d'Exercism.
