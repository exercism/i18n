# Indices

## Général

- Le tuple `plot`, les symboles `registrations` et `next-id`, ainsi que le symbole `not-found`, sont déjà déclarés dans le fichier de l'exercice.
- Pour l'état au niveau du module, utilise `set-global`, `get-global` et `change-global`.

## 1. Ouvre le jardin et liste ses enregistrements

- `V{ } clone` est la bonne valeur de départ pour `registrations` (utilise toujours `clone` pour que le littéral ne soit pas partagé entre les appels).
- `1 next-id set-global` définit le compteur.
- Pour `list-registrations`, un seul `registrations get-global` suffit.

## 2. Enregistre une parcelle

- Lis d'abord `next-id`, puis `plot boa` pour construire la parcelle à partir de `id` et `name`.
- Incrémente le compteur avec `next-id [ 1 + ] change-global`.
- `push` (dans [`sequences`][sequences]) ajoute un élément à la fin d'un vecteur sur place, ce qui est parfait pour `registrations get-global`.

## 3. Libère une parcelle

- Une déclaration `:: release ( id -- )` rend `id` accessible à l'intérieur du prédicat de filtrage.
- `[ id>> id = ] reject` conserve toutes les parcelles dont l'emplacement `id` ne correspond *pas* à l'`id` local. Utilise-le comme corps d'un `change-global`.

## 4. Récupère une parcelle enregistrée

- `find` renvoie `( index elt/f )`. `nip` supprime l'indice.
- `[ not-found ] unless*` substitue le symbole lorsque rien n'a été trouvé.

[sequences]: https://docs.factorcode.org/content/vocab-sequences.html
