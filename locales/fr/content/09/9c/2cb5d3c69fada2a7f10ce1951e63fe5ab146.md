Mais les choses sont un peu désorganisées : les coordonnées d'Aazra semblent formatées et triées différemment de celles de Rui, et ils doivent sans cesse passer d'une liste à l'autre pour déterminer quels trésors vont avec quels emplacements. Comme ils sont des Gleamlins en herbe, ils sont venus te demander de l'aide pour écrire un petit programme (un ensemble de fonctions, en fait) afin de mieux organiser les informations de leur chasse.

## 1. Convertis les emplacements

Implémente la fonction `place_location_to_treasure_location` qui prend un emplacement de lieu (comme `#("C", 1)`) et le convertit en un emplacement de trésor (comme `#(1, "C")`).

```gleam
place_location_to_treasure_location(#("C", 1))
// -> #(1, "C")
```

## 2. Compare les emplacements de trésor et de lieu

Implémente la fonction `treasure_location_matches_place_location` qui prend un emplacement de lieu (comme `#("C", 1)`) et renvoie `True` s'il correspond à un emplacement de trésor (comme `#(1, "C")`).

```gleam
treasure_location_matches_place_location(#("C", 1), #(1, "C"))
// -> True

treasure_location_matches_place_location(#("C", 1), #(2, "C"))
// -> False
```

## 3. Compte les emplacements de trésor

Implémente la fonction `count_place_treasures`, qui prend un lieu (comme `#("Aqua Lagoon (Island of Mystery)", #("F", 1))`) et le tableau des trésors, et renvoie le nombre de trésors qu'on peut y trouver.

```gleam
let place = #("Aqua Lagoon (Island of Mystery)", #("F", 1))

count_place_treasures(place, treasures)
// -> 2
```

## 4. Lieux spéciaux

Implémente la fonction `special_case_swap_possible`, qui prend un trésor (comme `#("Amethyst Octopus", #(1, "F"))`), un lieu (comme `#("Seaside Cottages", #("C", 1))`) et un trésor souhaité (comme `#("Crystal Crab", #(6, "A"))`), et renvoie `True` pour les combinaisons suivantes :

- Le Brass Spyglass peut être échangé contre n'importe quel autre trésor à Abandoned Lighthouse.
- L'Amethyst Octopus peut être échangé contre le Crystal Crab ou le Glass Starfish à Stormy Breakwater.
- Le Vintage Pirate Hat peut être échangé contre le Model Ship in Large Bottle ou l'Antique Glass Fishnet Float à Harbor Managers Office.
