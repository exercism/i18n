# Indices

## Généralités

- Pour qu'un nom puisse prendre plusieurs types différents, il faut utiliser un [type union][union-type].
- Pour qu'une variable d'instance puisse être utilisée dans une expression de contrôle [`if var.is_a?(Type)`][if-is-a], il faut d'abord l'affecter à une variable locale.

## 1. Définis un mot de passe

- Il faut définir une classe nommée `PasswordLock`.
- Il faut définir une méthode initialize qui prend en argument un `String`, un `Int32` ou un `Float64`.
- Il faut définir une [variable d'instance][instance-variable] `@password` qui prend la valeur de l'argument passé au constructeur.

## 2. Chiffre le mot de passe

- Définis une méthode d'instance appelée `encrypt`.
- La méthode doit modifier la [variable d'instance][instance-variable] `@password` pour qu'elle soit chiffrée.
- Pour qu'une branche spécifique ne puisse être exécutée que si la variable est d'un type spécifique, il faut utiliser la méthode [`is_a?`][is-a] dans une expression de contrôle.

## 3. Vérifie si un mot de passe est correct

- On peut utiliser les méthodes déjà définies pour chiffrer la tentative de mot de passe fournie.
