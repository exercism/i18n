# Introduction

Le vocabulaire [`random`][random] de Factor fournit un seul mot générique, `random`, qui s'adapte à son argument, ainsi que des fonctions utilitaires pour mélanger et échantillonner des séquences.

```factor
USING: random ;

6 random .                       ! a value from 0..5
{ "rock" "paper" "scissors" } random .   ! a random element
{ 1 2 3 4 5 } randomize .        ! the same cards, reordered
{ 1 2 3 4 5 } 2 sample .         ! two distinct elements
```

Appliqué à un entier `n`, `random` renvoie une valeur dans `[0, n)` ; appliqué à une séquence, il renvoie un élément au hasard. `randomize` mélange sur place, et `sample` tire des éléments distincts.

Par défaut, ces mots tirent leurs valeurs d'un générateur global initialisé à partir de l'horloge système. Pour rendre les résultats reproductibles, installe un générateur initialisé avec une graine grâce à `<mersenne-twister>` (du vocabulaire [`random.mersenne-twister`][mt]) et `with-random` :

```factor
USING: random random.mersenne-twister ;

42 <mersenne-twister> [ 6 random ] with-random .   ! same value every run
```

[mt]: https://docs.factorcode.org/content/vocab-random.mersenne-twister.html
