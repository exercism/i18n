# N'écris pas dans la console

Supprime la ou les fonctions qui écrivent dans la console : les tests n'en ont pas besoin et elles rendent le code un peu plus difficile à lire.

En général, ces instructions sont ajoutées pour faciliter le débogage du code. Cependant, une meilleure approche consiste à déboguer le code pendant que l'on exécute un ou plusieurs tests unitaires. Cela présente l'avantage supplémentaire de pouvoir se concentrer sur le débogage d'un cas de test précis. Voici quelques liens qui expliquent comment déboguer du code Scala pendant l'exécution de tests unitaires dans différents IDE :

- [IntelliJ](https://www.jetbrains.com/help/idea/run-debug-and-test-scala.html)
- [Eclipse](http://scala-ide.org/docs/current-user-doc/features/scaladebugger/index.html)
