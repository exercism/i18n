# Tests

La plupart des tests vérifient que tu renvoies la valeur attendue, que ce soit en affectant [result] ou en passant une valeur à [exit].

Certains tests vérifient que tu lèves l'exception attendue avec [raise].

## Exécute les tests

L'utilitaire `make` est nécessaire pour exécuter les tests.

Depuis le répertoire de l'exercice, saisis dans une console/terminal :

```sh
make
```

Si tu n'as même pas touché au fichier de solution de l'exercice, tu verras un message du type :

```
Please implement your solution.
```

Supprime donc cette ligne avant de commencer à écrire ta solution.

Par défaut, seul le premier test est exécuté.

```text
TAP version 14
1..10
ok 1 - ...
```

Pour exécuter tous les tests, saisis :

```sh
make test=all
```

```text
TAP version 14
1..10
ok 1 - empty_sentence
ok 2 - perfect_lower_case
ok 3 - only_lower_case
ok 4 - missing_the_letter_x
ok 5 - missing_the_letter_h
ok 6 - with_underscores
ok 7 - with_numbers
ok 8 - missing_letters_replaced_by_numbers
ok 9 - mixed_case_and_punctuation
ok 10 - am_and_AM_are_26_different_characters_but_not_a_pangram
```

Une fois que tous les tests passent, tu as terminé l'exercice et tu peux soumettre la solution.

Il est possible de choisir un seul test à exécuter en passant le numéro correspondant, par exemple :

```sh
make test=2
```

n'exécuterait que le deuxième test.
