# Ajout aux instructions

## Registres

| Registre | Utilisation | Type | Description |
| -------- | ----------- | ---- | ----------- |
| `$a0`    | entrée      | adresse | tableau des poids des objets |
| `$a1`    | entrée      | adresse | tableau des valeurs des objets |
| `$a2`    | entrée      | entier  | nombre d'objets |
| `$a3`    | entrée      | entier  | poids maximal |
| `$v0`    | sortie      | entier  | valeur maximale |
| `$t0-9`  | temporaire  | quelconque | utilisé pour le stockage temporaire |
