# Apprendre

Odin est un langage de programmation système.
Comme en C, il faut gérer la mémoire manuellement.
C'est pourtant un langage plutôt simple.

Les ressources suivantes sont disponibles pour t'aider à apprendre Odin :

Pour un premier aperçu du langage :

* Regarde la [Introduction to Odin][video], présentée par le créateur d'Odin.
* Lis l'article [Introduction to Odin][intro], écrit par l'auteur de [« Understanding the Odin Programming Language »][book].
* Étudie le [Demo File][demo], qui montre en code les concepts d'Odin.

Creuse plus loin :

* [Aperçu du langage Odin][overview].
* La documentation des [paquets officiels][packages].
* Le livre [« Understanding the Odin Programming Language »][book] (payant).
* L'ensemble officiel des [« Odin Examples »][examples].
