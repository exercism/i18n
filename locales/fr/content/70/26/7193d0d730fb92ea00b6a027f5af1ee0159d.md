# Introduction

On appellera le _langage_ **AWK**, et l'_exécutable_ qui interprète les programmes AWK **`awk`** ou **`gawk`**.

## Motifs et actions

Un programme AWK est composé de **paires motif-action**

```awk
pattern1 { action1 }
pattern2 { action2 }
...
```

Un **motif** peut être une expression régulière que l'on compare à l'entrée.
Il peut aussi s'agir de n'importe quelle expression dont le résultat est vrai ou faux.

Une **action** est une ou plusieurs commandes AWK.
Les accolades qui l'entourent sont obligatoires.

Si le résultat du motif est _true_, l'action correspondante est évaluée.

## Enregistrements et champs

AWK analyse l'entrée comme une série d'**enregistrements**.
Chaque enregistrement est découpé en zéro ou plusieurs **champs**.

Le comportement par défaut est le suivant :

- découper l'entrée en enregistrements en utilisant le retour à la ligne comme « séparateur d'enregistrements », de sorte que chaque _ligne_ soit un enregistrement.
- découper l'enregistrement en champs en utilisant les espaces comme « séparateur de champs », de sorte que chaque _mot_ soit un champ.

## Motifs et actions, suite

On peut omettre le motif, auquel cas l'action est évaluée _pour chaque enregistrement en entrée_.

On peut omettre l'action, auquel cas l'action par défaut consiste à afficher l'enregistrement courant.

### Motifs spéciaux

Il existe deux motifs spéciaux que l'on utilise souvent.

- `BEGIN` évalue l'action associée avant qu'aucune entrée ne soit consommée.
- `END` évalue l'action associée une fois toute l'entrée consommée.

## Variables de champ

On désigne les champs par `$1`, `$2`, `$3`, etc.

L'enregistrement courant est `$0`.

Voici quelques autres variables intégrées fréquemment utilisées.

### Variables intégrées qui contrôlent l'analyse de l'entrée

- `RS` est le séparateur d'enregistrements de l'entrée.
  Comme on l'a dit, sa valeur par défaut est le retour à la ligne.
- `FS` est le séparateur de champs de l'entrée.

Ces variables sont souvent définies dans le bloc d'action `BEGIN`.

### Variables intégrées qui transmettent des informations

Ces variables sont définies automatiquement par AWK pendant l'exécution du programme.

- `NF` contient le nombre de champs de l'enregistrement courant.
  - Pour obtenir la valeur du dernier champ, utilise `$NF`.
- `NR` contient le numéro de l'enregistrement courant.
  - Lorsque plusieurs fichiers d'entrée sont traités, `NR` contient le nombre total d'enregistrements traités jusqu'ici.
- `FNR` contient le numéro de l'enregistrement courant dans le fichier d'entrée courant.
  - Pour illustrer la différence entre NR et FNR, voici un idiome AWK courant.
    ```awk
    NR == FNR {action}
    ```
    Cela signifie « si le numéro d'enregistrement cumulé est égal au numéro d'enregistrement du fichier courant ».
    Cela ne peut être vrai que pour les enregistrements du _premier fichier d'entrée_.

## Notion de vérité

AWK utilise la même notion de vérité que C.

- Le nombre `0` est faux.
- Tout autre nombre est vrai.

Comme AWK est un langage conçu pour traiter du texte, les valeurs de vérité s'étendent aussi aux _strings_.

- Une _string_ vide `""` est fausse.
- Toute _string_ non vide est vraie.

## Commentaires

Les commentaires commencent par le caractère `#` et vont jusqu'à la fin de la ligne.

## Exemples

Sur les systèmes de type Unix, `/etc/passwd` contient des informations sur les utilisateurs.
Chaque utilisateur est décrit sur une ligne distincte, les champs étant séparés par des deux-points.

Pour lister les noms d'utilisateur :

```sh
awk '
    BEGIN { FS = ":" }
    { print $1 }
' /etc/passwd
```

Remarque que l'action `{print $1}` n'a pas de motif, et qu'elle est donc exécutée pour chaque enregistrement.

Si l'on veut limiter la sortie aux seuls utilisateurs qui utilisent bash comme shell de connexion, on peut faire :

```sh
awk '
    BEGIN { FS = ":" }
    $7 == "/bin/bash" { print $1 }
' /etc/passwd
```
