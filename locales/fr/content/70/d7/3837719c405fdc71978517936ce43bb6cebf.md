# Tableaux

`ARRAY{T}` est une suite de valeurs de type `T` dont la taille est fixe.

```sather
   row : ARRAY{STR} := |"Mia", "Ana", "Ben"|;
   sizes : ARRAY{INT} := |3, 1, 2|;
```

## Les accolades

`ARRAY{STR}` se lit « tableau de `STR` ». Les accolades contiennent un **paramètre de type** :
`ARRAY` tout seul n'est pas un type, car un tableau doit être un tableau de quelque chose. Une
grande partie de la bibliothèque Sather est construite ainsi, et écrire une telle classe
soi-même viendra plus tard.

## Positions

```sather
row[0]                 -- the first
row[row.size - 1]      -- the last
row.size               -- how many
```

Les positions vont de `0` à `.size - 1`. Un tableau connaît sa taille et ne la change jamais :
on ne peut rien ajouter à un `ARRAY`.

## Crée un tableau sans littéral

`#ARRAY{INT}(n)` crée un tableau de `n` valeurs, toutes initialisées à zéro :

```sather
   counts ::= #ARRAY{INT}(5);      -- five noughts
   counts[0] := 7;
```

L'affectation dans une position utilise les mêmes crochets, à gauche de `:=`.

## Hors limites

Ni la lecture ni l'écriture d'une position qui n'existe pas ne sont vérifiées dans une
compilation normale. Le programme ne s'arrêtera pas avec un message utile ; il lira ou écrira
ce qui se trouve juste après en mémoire. Deux habitudes permettent de l'éviter : utiliser
`.size - 1` plutôt qu'un nombre compté à l'œil, et terminer les boucles avec
`until!(i >= a.size)` plutôt qu'avec un littéral.

## Affiche un tableau

`.str` donne le contenu entre accolades, ce qui est pratique quand on cherche une solution :

```sather
   #OUT + row.str;      -- {Mia,Ana,Ben}
```
