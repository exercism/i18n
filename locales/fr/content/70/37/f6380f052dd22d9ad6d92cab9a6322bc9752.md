# Introduction

# Espaces de noms

Une méthode importante pour organiser le code consiste à utiliser des espaces de noms.
Les classes et les modules fournissent des espaces de noms.
Deux méthodes peuvent entrer en collision de nom, ce que l'on peut résoudre en les plaçant dans des espaces de noms différents.
Les espaces de noms peuvent être imbriqués, ce qui peut aider à structurer de grandes bases de code.
On accède aux espaces de noms via l'opérateur de résolution de portée `::`.

L'exemple ci-dessous montre l'utilisation de deux méthodes `foo` différentes.
Elles sont utilisées ensemble en préfixant chacune par son espace de noms respectif.

```ruby
class MyNamespace
  def self.foo
    44
  end

  class MyInnerNamespace
    def self.baz
      90
    end
  end
end

class MyOtherNamespace
  def self.foo
    -2
  end
end

p MyNamespace::foo + MyOtherNamespace::foo * MyNamespace::MyInnerNamespace::baz  # => -136
```

Note que les espaces de noms sont interprétés en fonction de l'endroit où se trouve le code qui s'exécute.
Pour faire référence à un élément de l'espace de noms *racine* (c'est-à-dire en dehors de tous les espaces de noms définis), commence par `::`.

Par exemple :

```ruby
class Example
  def self.example
    5
  end
end

class MyNamespace

  class Example
    def self.example
      10
    end
  end

  def self.call_example
    p Example::example  # => 10
    p ::Example::example  # => 5
  end
end
```
