# Introduction

Une propriété en C# est un membre d'une classe qui donne accès aux données de cette classe.
Les appelants peuvent y définir ou y récupérer (get) des données. Les propriétés peuvent être
soit implémentées automatiquement, soit s'appuyer sur un champ de stockage. Elles comportent
un accesseur set et/ou un accesseur get.
Dans d'autres langages, un « mutateur » est à peu près l'équivalent d'un
accesseur set et un « accesseur » celui d'un accesseur get, même si
la composition de la syntaxe est complètement différente.

Lorsque l'on définit une propriété, la valeur d'entrée peut être validée, mise en forme
ou transformée d'une autre manière, et en fait toute opération programmatique accessible au code de la
classe peut être exécutée.

De même, lorsqu'on récupère une propriété, les données peuvent être calculées ou mises en forme et, là encore,
toute opération programmatique disponible dans la classe peut être exécutée.

Les propriétés ont des modificateurs d'accès (`public`, `private`, etc.) au même titre que les autres
membres d'une classe, mais l'accesseur set peut avoir un niveau d'accès indépendant de l'accesseur
de récupération (get), et inversement. Une propriété n'a pas forcément les deux accesseurs : elle peut n'en avoir qu'un seul (soit get, soit set).

La syntaxe de base pour exprimer les propriétés peut prendre deux formes :

## Propriétés basées sur un champ ou une expression :

```csharp
private int myField;
public int MyProperty
{
    get { return myField; }
    set { myField = value; }
}
```

## Propriétés implémentées automatiquement

```
public int MyProperty { get; private set; } = 42;
```

L'initialisation est facultative.
