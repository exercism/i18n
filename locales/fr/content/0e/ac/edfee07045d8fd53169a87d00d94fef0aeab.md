# Introduction

La classe `str` propose [de nombreuses méthodes utiles][str methods] pour manipuler et composer des _strings_.
On y trouve la recherche, le nettoyage, le découpage, la transformation, la traduction et bien d'autres techniques.

Les _strings_ sont des [séquences][text sequence] de [points de code Unicode][unicode code points] : des « caractères » individuels, ou points de code (des _strings_ de longueur 1), auxquels on peut accéder par un numéro d'indice `0-based index` depuis la gauche, ou un numéro d'indice `-1-based index` depuis la droite.
Les _strings_ implémentent toutes les [opérations courantes sur les séquences][common sequence operations].

On peut les parcourir avec la syntaxe `for item in <str>` ou `for index, item in enumerate(<str>)`.
On peut aussi les concaténer avec `<str> + <other str>` ou `<str>.join(<iterable>)`.

Les _strings_ sont _immuables_, ce qui signifie que la valeur d'un objet `str` en mémoire ne peut pas changer.
Les fonctions ou méthodes qui opèrent sur une `str` (_comme celles que l'on découvre ici_) renvoient une nouvelle `instance` de cet objet `str` au lieu de modifier la `str` d'origine.

Voici une petite sélection de méthodes de _strings_ en Python.
Pour une liste complète, consulte la [classe str][str methods] dans la documentation Python.


[`<str>.title()`][str-title] analyse une _string_ et met en majuscule le premier « caractère » de chaque « mot » trouvé.
En Python, cela dépend beaucoup du [codec de langue][codecs] utilisé et de la manière dont la langue concernée représente les mots et les caractères.
Il peut aussi y avoir des règles de [locale][locale] appliquées à une langue ou à un jeu de caractères.


```python
man_in_hat_th = 'ผู้ชายใส่หมวก'
man_in_hat_ru = 'мужчина в шляпе'
man_in_hat_ko = '모자를 쓴 남자'
man_in_hat_en = 'the man in the hat.'

>>> man_in_hat_th.title()
'ผู้ชายใส่หมวก'

>>> man_in_hat_ru.title()
'Мужчина В Шляпе'

>>> man_in_hat_ko.title()
'모자를 쓴 남자'

>> man_in_hat_en.title()
'The Man In The Hat.'
```

[`<str>.endswith(<suffix>)`][str-endswith] renvoie `True` si la _string_ se termine par `<suffix>`, et `False` sinon.


```python
>>> 'My heart breaks. 💔'.endswith('💔')
True

>>> 'cheerfulness'.endswith('ness')
True

# Punctuation is part of the string, so needs to be included in any endswith match.
>>> 'Do you want to 💃?'.endswith('💃')
False

>> 'The quick brown fox jumped over the lazy dog.'.endswith('dog')
False
```

[`<str>.strip(<chars>)`][str-strip] renvoie une copie de la `str` dont les `<chars>` en début et en fin ont été supprimés.
Les points de code indiqués dans `<chars>` ne forment ni un préfixe ni un suffixe : **toutes les combinaisons** de ces points de code seront supprimées en partant des **deux extrémités** de la _string_.
 Si rien n'est spécifié pour `<chars>`, toutes les combinaisons de points de code d'espacement seront supprimées.


 ```python
# This will remove "https://", because it can be formed from "/stph:". 
>>> 'https://unicode.org/emoji/'.strip('/stph:')
'unicode.org/emoji'

# Removal of all whitespace from both ends of the str.
>>> '   🐪🐪🐪🌟🐪🐪🐪   '.strip()
'🐪🐪🐪🌟🐪🐪🐪'

>>> justification = 'оправдание'
>>> justification.strip('еина')
'оправд'

# Prefix and suffix in one step.
>>> 'unaddressed'.strip('dnue')
'address'

>>> '  unaddressed  '.strip('dnue ')
'address'
```


[`<str>.replace(<substring>, <replacement substring>)`][str-replace] renvoie une copie de la _string_ où toutes les occurrences de `<substring>` sont remplacées par `<replacement substring>`.

La citation ci-dessous est tirée de [La Chasse au Snark][The Hunting of the Snark] de [Lewis Carroll][Lewis Carroll].

```python
# The Hunting of the Snark, by Lewis Carroll
>>> quote = '''
"Just the place for a Snark!" the Bellman cried,
   As he landed his crew with care;
Supporting each man on the top of the tide
   By a finger entwined in his hair.

"Just the place for a Snark! I have said it twice:
   That alone should encourage the crew.
Just the place for a Snark! I have said it thrice:
   What I tell you three times is true."
'''

>>> quote.replace('Snark', '🐲')
...
'\n"Just the place for a 🐲!" the Bellman cried,\n   As he landed his crew with care;\nSupporting each man on the top of the tide\n   By a finger entwined in his hair.\n\n"Just the place for a 🐲! I have said it twice:\n   That alone should encourage the crew.\nJust the place for a 🐲! I have said it thrice:\n   What I tell you three times is true."\n'

>>> 'bookkeeper'.replace('kk', 'k k')
'book keeper'
```
