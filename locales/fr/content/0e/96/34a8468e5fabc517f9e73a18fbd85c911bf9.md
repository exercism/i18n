# À propos

Une boucle [`for`][for-statement] permet d'exécuter du code de façon répétée jusqu'à ce qu'une condition soit remplie.

```csharp
for (int i = 0; i < 5; i++)
{
    System.Console.Write(i);
}

// => 01234
```

Une boucle `for` se compose de quatre parties :

1. L'initialisation : exécutée une fois avant d'entrer dans la boucle. Elle sert généralement à définir les variables utilisées dans la boucle.
2. La condition : exécutée avant chaque itération de la boucle. La boucle continue de s'exécuter tant que cette condition vaut `true`.
3. L'incrément : exécuté après chaque itération de la boucle. Il sert généralement à modifier (souvent à incrémenter ou décrémenter) la ou les variables de boucle.
4. Le corps : le code qui est exécuté à chaque itération de la boucle.

## Boucles `for` et `foreach`

En général, les boucles [concept:csharp/foreach-loops]() sont préférables aux boucles `for`, pour les raisons suivantes :

- Une boucle `foreach` garantit que l'on parcourt _toutes_ les valeurs. Avec une boucle `for`, il est facile d'oublier des éléments, par exemple à cause d'une erreur de décalage d'une unité.
- Une boucle `foreach` est plus _déclarative_ : ton code exprime _ce_ que tu veux faire, alors qu'une boucle `for` exprime _comment_ tu veux le faire.
- Une boucle `foreach` est à toute épreuve, alors qu'avec les boucles `for`, il est facile de commettre une erreur de décalage d'une unité.
- Une boucle `foreach` fonctionne avec tous les types de collections, y compris ceux qui ne permettent pas d'utiliser un indexeur pour accéder aux éléments.

Pour garantir qu'une boucle `foreach` parcourt _toutes_ les valeurs, le compilateur n'autorise pas la modification d'une collection à l'intérieur d'une boucle `foreach` :

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // This would result in a compiler error
    // vowel = 'Y';
}
```

Une boucle `for` présente tout de même quelques avantages par rapport à une boucle `foreach` :

- Tu peux commencer ou t'arrêter à l'indice de ton choix.
- Tu peux utiliser la condition d'arrêt (booléenne) que tu veux.
- Tu peux sauter des éléments en personnalisant l'incrémentation de la variable de boucle.
- Tu peux parcourir les collections de la fin vers le début en comptant à rebours.
- Tu peux utiliser des boucles `for` dans des situations qui n'impliquent pas de collections.
