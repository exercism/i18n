# Tests

## Exécuter les tests

Pour exécuter les tests, lance la commande suivante dans le répertoire de l'exercice :

```shell
make
```

Cette commande assemble ta solution, compile les tests, les lie dans un programme RISC-V et l'exécute sous `qemu-riscv32`.
Le programme affiche une ligne pour chaque test, indiquant s'il a réussi, échoué ou été ignoré, puis un récapitulatif.

## Résoudre l'exercice

Résoudre un exercice, c'est faire passer tous ses tests.
Par défaut, un seul test (le premier) est exécuté quand tu lances les tests.
C'est intentionnel : cela te permet de te concentrer sur la réussite de ce seul test.
Une fois qu'il passe, tu peux activer le test suivant en supprimant la ligne `TEST_IGNORE();`.
Quand tous les tests sont activés et que ton implémentation les fait tous passer, tu as résolu l'exercice !
