# Introduction

Une `Map` sert à stocker des paires de **clé** et de **valeur**. Les `Map` s'initialisent exactement comme un tableau, mais en utilisant l'opérateur de littéral de map `=>`. On peut aussi préciser explicitement leurs types de clé et de valeur, ou les laisser être déduits. Les clés doivent être uniques, sinon une erreur est levée.

```haxe
var map1:Map<Int, String> = [1 => "one", 2 => "two", 3 => "three"];

var map2 = ["one" => 1, "two" => 2, "three" => 3];

var map3 = [1 => "cat", 1 => "dog"]; // Error: Duplicate Key

var map4 = ["h" => "Hello", "b" => "Bye"];
trace(map4["h"]); // Hello
```

On peut parcourir une `Maps` avec une boucle `for`. On peut itérer soit sur les valeurs, soit sur les clés :

```haxe
for (value in map) {
  // ...
}

for (key in map.keys()) {
  // ...
}
```
