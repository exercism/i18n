# Introduction

Un *tuple* regroupe plusieurs valeurs nommées dans un seul objet, ce que d'autres langages appellent un enregistrement, une structure ou une classe. Chaque classe de tuple possède un ensemble fixe d'emplacements nommés, et Factor génère automatiquement les accesseurs et les mutateurs correspondants.

## Définis un tuple

```factor
TUPLE: point
    { x initial: 0 }
    { y initial: 0 } ;
```

Chaque emplacement se déclare `{ name initial: default-value }`. Sans clause `initial:`, la valeur par défaut est `f`.

## Construis un tuple

Le constructeur le plus simple est `new` :

```factor
point new .
! => T{ point }
```

`boa` (« par ordre des arguments ») remplit les emplacements dans l'ordre de déclaration, depuis la pile de données :

```factor
3 4 point boa .
! => T{ point { x 3 } { y 4 } }
```

La syntaxe littérale `T{ class { slot value } … }` permet de construire un tuple en ne définissant qu'une partie des emplacements, et s'affiche de la même façon :

```factor
T{ point { x 3 } } .
! => T{ point { x 3 } }
```

Lorsque la valeur d'un emplacement correspond à sa valeur par défaut, l'affichage l'omet.

## Lis un emplacement

Factor génère un accesseur `slot>>` pour chaque emplacement. Les accesseurs se trouvent dans [`accessors`][accessors] :

```factor
T{ point { x 3 } { y 4 } } x>> .
! => 3
```

## Mets à jour un emplacement

Les mutateurs s'écrivent `>>slot` et *modifient* le tuple sur place :

```factor
T{ point { x 3 } { y 4 } } 10 >>x .
! => T{ point { x 10 } { y 4 } }
```

Pour ne pas toucher à l'original, commence par `clone` :

```factor
: shifted ( pt -- pt' )
    clone 10 >>x ;
```

`change-slot` prend une _quotation_ qui associe la valeur actuelle à la nouvelle :

```factor
: shift-x ( pt dx -- pt )
    [ + ] curry change-x ;
```

`change-x` modifie lui aussi le tuple, donc fais un `clone` avant de l'appeler si tu veux préserver l'original.
