# Instructions supplémentaires

## Implémentation

Pour les entrées inférieures à `1`, le n-ième nombre premier ne peut pas être calculé.
Dans ce cas, ta fonction doit renvoyer une erreur.
Le message d'erreur doit décrire l'erreur.
Si l'entrée se trouve dans une plage valide, la fonction doit renvoyer le nombre premier attendu, sans erreur.
