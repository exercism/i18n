# Introduction

Les espaces de noms permettent de regrouper du code lié et d'éviter les conflits de noms ; on en trouve dans pratiquement toutes les bases de code, à l'exception des plus triviales.

La syntaxe est la suivante :

```csharp
namespace MyNameSpace
{
    public class MyClass {}

    public class OtherClass {}
}
```

Pour désigner un type déclaré dans un espace de noms depuis l'extérieur de la portée de cet espace, on préfixe le nom du type à l'aide de la syntaxe pointée. Autrement, et c'est le cas le plus courant, tu peux placer une directive `using` en haut du fichier (ou à l'intérieur d'un espace de noms), et le type s'utilise alors sans préfixe. Au sein d'un même espace de noms, il n'est pas nécessaire de qualifier les noms de types.

```csharp
namespace MySpace
{
    public class MyClass {}

    public class Foo
    {
        public void Bar()
        {
            var baz = new MyClass();
        }
    }
}

public class Qux
{
    public void Box()
    {
        var nux = new MySpace.MyClass();
    }
}

namespace OtherSpace
{
    using MySpace;

    public class Tix
    {
        public void Jeg()
        {
            var lor = new MyClass();
        }
    }
}
```

On peut donner un alias à un espace de noms avec la syntaxe `using MyAlias = MySpace;`, puis utiliser cet alias partout où l'espace de noms lui-même pourrait être utilisé.
