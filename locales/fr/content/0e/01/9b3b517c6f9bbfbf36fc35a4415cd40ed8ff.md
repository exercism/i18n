# À propos

[_La surcharge de méthodes_][member-overloading] permet à plusieurs méthodes d'une même classe de porter le même nom. Les méthodes surchargées doivent différer les unes des autres par :

- Le nombre de paramètres
- Le type des paramètres

Il n'existe pas de surcharge de méthodes basée sur le type de retour.

Le compilateur déduit automatiquement quelle méthode surchargée appeler [en fonction du nombre de paramètres et de leur type][overloading].

[member-overloading]: https://docs.microsoft.com/en-us/dotnet/standard/design-guidelines/member-overloading
[overloading]: https://csharpindepth.com/articles/Overloading
