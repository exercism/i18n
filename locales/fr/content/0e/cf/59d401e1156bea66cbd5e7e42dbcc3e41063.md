# Introduction

On peut accéder aux caractères individuels d'une `String` en utilisant la syntaxe d'indice qui s'emploie avec les tableaux.
Cependant, les [indices][string-indices] utilisés pour les _strings_ ne sont _pas_ des nombres entiers et ne peuvent pas être manipulés directement.
Il faut plutôt les calculer à partir d'un autre indice connu, comme `startIndex`, qui pointe vers la position du premier caractère d'une _string_ non vide, en utilisant les méthodes disponibles dans les bibliothèques [`String`][string-docs] et [`NSString`][nsstring-docs] (quand le module `Foundation` est importé, les _strings_ en Swift ont accès à toutes les propriétés et méthodes de NSString).

Par exemple, étant donnée la _string_ suivante :

```swift
let csv = "apple,pear,peach,orange,cherry,lime,goosberry"
```

On ne peut pas écrire `csv[21]` pour obtenir le « g » de « orange » : il faut à la place calculer une valeur de type `String.Index` et fournir cet indice.
Note que ces indices ne sont pas destinés à être interprétés directement par un humain.
On parle d'_indices opaques_, car il n'est pas nécessaire de savoir ce qu'ils contiennent.

```swift
let index = csv.index(csv.startIndex, offsetBy: 21)
csv[index]
// "g"
print(index)
// prints Index(_rawBits: 1376513)
```

Note cependant que si le décalage ne correspond pas à un indice valide, c'est-à-dire s'il renvoie un indice avant `startIndex` ou après `endIndex`, l'opération lève une erreur et fait planter le programme.
Pour éviter ce problème, on peut spécifier un indice limite.
Cela renvoie un indice optionnel et renvoie nil pour des indices qui seraient autrement invalides.

```swift
let tooFar = csv.index(csv.startIndex, offsetBy: 200)
// error: Execution was interrupted, reason: EXC_BAD_INSTRUCTION (code=EXC_I386_INVOP, subcode=0x0).
let tooFarButSafe = csv.index(csv.startIndex, offsetBy: 200, limitedBy: csv.endIndex)
// nil
```

De plus, les indices ne peuvent pas être partagés entre les _strings_.
Par exemple, si on se sert de l'`index` du « g » de « orange » calculé plus haut pour indexer la _string_ `fam = "This is my family: 👨‍👩‍👦‍👦, this is our dog: 🐶, this is our cat: 🐱!"`, c'est-à-dire `fam[index]`, le programme plantera.

Il y a de nombreuses raisons à tout cela, mais elles se résument toutes à « Unicode, c'est délicat ».

D'une manière générale, si tu as besoin d'un accès aléatoire à des caractères individuels, tu as probablement intérêt à utiliser une autre structure de données, comme `Array<Character>`.

## Quelques méthodes utiles

Swift dispose des méthodes `first` et `last` pour obtenir le premier et le dernier caractère d'une _string_.
Ces méthodes renvoient un caractère optionnel, donc si la _string_ est vide, elles renvoient nil.

```swift
let str = "Hello, world!"
print(str.first) // Prints Optional("H")
print(str.last)  // Prints Optional("!")
```

Tu peux aussi utiliser les méthodes `prefix` et `suffix` pour obtenir une sous-chaîne d'une _string_.
Ces méthodes prennent un nombre entier en argument et renvoient une sous-chaîne contenant les n premiers ou derniers caractères de la _string_.

```swift
let str = "Hello, world!"
print(str.prefix(5)) // Prints "Hello"
print(str.suffix(6)) // Prints "world!"
```
