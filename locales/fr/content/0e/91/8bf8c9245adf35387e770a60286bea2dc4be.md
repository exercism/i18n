# À propos

Un nombre à virgule flottante est un nombre comportant zéro ou plusieurs chiffres après le séparateur décimal.
Les exemples sont `4.0`, `0.1`, `3.14`, `-6.4` `16.984025` et `1024.0`.
En Ruby, les nombres à virgule flottante sont implémentés via la classe [Float][Float].

Tu peux trouver une brève introduction aux nombres à virgule flottante sur [0.30000000000000004.com][0.30000000000000004.com].

La [page Float Toy][evanw.github.io-float-toy] propose une jolie explication graphique de la façon dont les bits d'un nombre à virgule flottante sont convertis en une valeur à virgule flottante réelle.

Pour exécuter une logique de manière répétée, on peut utiliser des boucles.
Dans cet exemple, la boucle `while` est utile car elle continue de boucler _tant que_ la condition renvoie une valeur considérée comme vraie (c'est-à-dire ni `false` ni `nil`).
Ruby implémente une boucle similaire à la boucle `while`.
Elle s'appelle la boucle `until`, et tu as probablement deviné ce qu'elle fait.
Elle continue de boucler _jusqu'à ce que_ une condition booléenne vaille `true`.
Dans certains langages, pour qu'un bout de code s'exécute un nombre illimité de fois, on utilise des constructions comme `while true`.
En Ruby, la boucle `loop` existe pour cela.
Même si la boucle `loop` ne dépend pas d'une seule condition, on peut l'interrompre en utilisant le mot-clé `return` ou `break`.

La méthode `#years_before_desired_balance` de l'exercice précédent aurait pu être écrite avec l'une des trois boucles mentionnées :

## `while`

```ruby
def self.years_before_desired_balance(current_balance, desired_balance)
  years = 0
  while current_balance < desired_balance
    current_balance = annual_balance_update(current_balance)
    years += 1
  end
  years
end
```

## `until`

```ruby
def self.years_before_desired_balance(current_balance, desired_balance)
  years = 0
  until current_balance >= desired_balance
    current_balance = annual_balance_update(current_balance)
    years += 1
  end
  years
end
```

## `loop`

```ruby
def self.years_before_desired_balance(current_balance, desired_balance)
  years = 0
  loop do
    current_balance = annual_balance_update(current_balance)
    years += 1
    return years if current_balance >= desired_balance
  end
end
```

Comme tu l'as probablement remarqué, Ruby n'a pas d'opérateur d'incrémentation (`i++`) comme certains autres langages.
À la place, on peut utiliser des constructions comme `i += 1` (ce qui équivaut à `i = i + 1`).
