# À propos

L'attribut Flags permet de représenter les valeurs définies dans une union discriminée sous forme de positions de bits (c'est-à-dire de _flags_).
En tant que _flags_, ces valeurs peuvent être combinées, ce qui permet de représenter plusieurs conditions booléennes dans une seule valeur.

```fsharp
[<Flags>]
type PhoneFeatures =
| Call = 1
| Text = 2
```

```fsharp
[<Flags>]
type PhoneFeaturesBinary =
| Call = 0b00000001
| Text = 0b00000010
```

Activer un _flag_ se fait avec l'opérateur OR bit à bit (`|||`) ; désactiver un _flag_ se fait en combinant l'opérateur AND bit à bit (`&&&`) et l'opérateur de négation bit à bit (`~~~`).
Vérifier l'état d'un _flag_ se fait avec l'opérateur AND bit à bit, mais on peut aussi utiliser la méthode HasFlag().

```fsharp
let features = PhoneFeatures.Call

// Set the Text flag
let moreFeatures = features ||| PhoneFeatures.Text

moreFeatures.HasFlag(PhoneFeatures.Call) // => true
moreFeatures.HasFlag(PhoneFeatures.Text) // => true

// Unset the Call flag
let lessFeatures = features &&& ~~~PhoneFeatures.Call

lessFeatures.HasFlag(PhoneFeatures.Call) // => false
lessFeatures.HasFlag(PhoneFeatures.Text) // => true
```
