# Instructions supplémentaires

## Attribue une valeur spéciale à `errno`

Si le tampon est vide lors d'une tentative de lecture, une erreur est levée pour alerter le client.

Ces valeurs d'erreur se trouvent dans le fichier d'en-tête [`errno.h`][errno.h].

[errno.h]: https://en.wikipedia.org/wiki/Errno.h
