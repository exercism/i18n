# signature de distance modifiée

La signature de la fonction `Distance` doit être `Distance(a, b string) (int, error)`.
Exercism repose sur le principe du TDD ([développement piloté par les tests](http://testfirst.org/about#tdd)).
Les tests existent déjà et définissent l'interface publique, ainsi que le comportement du code à implémenter.
Modifier la signature casse les tests.
