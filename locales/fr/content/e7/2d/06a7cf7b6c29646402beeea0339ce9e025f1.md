# Pas d'export nommé

Aucun [export](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/export) appelé `%{export.name}` n'a été trouvé. Les tests ne passeront pas sans lui.

Vérifie que `%{export.name}` existe, puis ajoute `export` devant :
```javascript
// exporting a "const"
export const %{export.name} = /*...*/

// exporting a named function declaration
export function %{export.name}() { /* ... */ }
```
