# Introduction

## Filtrage par motif de littéraux

Bien que les expressions `if/else` puissent servir à exécuter une logique conditionnelle, Haskell dispose aussi d'une façon plus puissante d'exécuter une logique conditionnelle : [le filtrage par motif][pattern-matching].
Avec le filtrage par motif, on peut tester une valeur par rapport à un ou plusieurs _motifs_.
Un exemple d'un tel motif est le _motif constant_, qui fait correspondre une valeur à une constante (par exemple `1` ou `"hello"`).

Lorsque tu définis des fonctions, tu peux définir des corps de fonction distincts pour différents motifs.
Cela donne du code propre, simple et lisible.
Tu peux faire du filtrage par motif sur n'importe quel type de données : nombres, caractères, listes, tuples, etc.

Par exemple, une fonction triviale qui prend un nombre entier (`Int`) et le rapproche de _0_ d'une unité pourrait s'écrire comme ceci :

```haskell
closerToZero :: Int -> Int
closerToZero 0 = 0
closerToZero 1 = 0
```

Le filtrage par motif prend tout son sens lorsqu'on l'utilise avec d'autres motifs, par exemple le _motif variable_ :

```haskell
closerToZero :: Int -> Int
closerToZero 0 = 0
closerToZero n = n - 1
```

L'exemple ci-dessus traite de la même manière toutes les entrées autres que _0_, et produirait des résultats incorrects pour les nombres négatifs.
On peut résoudre ce problème en utilisant des motifs conditionnels, appelés _gardes_, qui s'expriment avec le symbole `|` :

```haskell
closerToZero :: Int -> Int
closerToZero n
    | n < 0 = n + 1
    | n > 0 = n - 1
```

Dans les exemples ci-dessus, certaines entrées possibles n'ont pas de motif correspondant.
Le compilateur le détectera et émettra un avertissement.
C'est une fonctionnalité très utile de Haskell qui aide à garantir que tous les chemins possibles sont couverts afin d'éviter les erreurs d'exécution.
On appelle cela la _vérification exhaustive_.
Pour résoudre l'avertissement, tu dois gérer tous les cas.
Dans les _gardes_, tu peux utiliser l'expression `otherwise` comme du sucre syntaxique pour `True` afin de capturer tous les motifs restants.

```haskell
closerToZero :: Int -> Int
closerToZero n
    | n < 0 = n + 1
    | n > 0 = n - 1
    | otherwise = 0
```

Le filtrage par motif teste une valeur par rapport à chaque motif, de haut en bas, jusqu'à ce qu'il trouve un motif correspondant et exécute la logique associée à ce motif.
**L'ordre des motifs compte !**
