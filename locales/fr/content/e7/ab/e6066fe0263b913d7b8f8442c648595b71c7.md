## Indices

Pour que le test passe, tu vas devoir créer quelques types sur lesquels ton code pourra s'appuyer. Il te faut en effet un objet pour `School` qui contient une séquence de type `Student`, ce dernier étant un tuple de `string` et de `int` destiné à stocker le nom et la note des élèves.

Voici du code pour ces types, qui pourrait t'aider à démarrer

```nim
type
  Student* = tuple[name: string, grade: int]
  School* = object
    students*: seq[Student]
```
