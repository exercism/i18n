# Complément aux instructions

## Format de l'entrée

Chaque domino est stocké sur un seul octet, la moitié gauche occupant le [quartet][nibble] de poids fort et la moitié droite le [quartet][nibble] de poids faible. Par exemple, les pierres `[2|1]`, `[2|3]` et `[1|3]` sont représentées par les octets `0x21 0x23 0x13`.

## Registres

| Registre | Utilisation | Type    | Description                                               |
| -------- | ----------- | ------- | --------------------------------------------------------- |
| `$a0`    | entrée      | adresse | tableau d'octets des pierres                              |
| `$a1`    | entrée      | entier  | nombre de pierres                                         |
| `$v0`    | sortie      | booléen | les dominos peuvent s'enchaîner (`0` = `false`, `1` = `true`) |
| `$t0-9`  | temporaire  | quelconque | utilisé pour le stockage temporaire                    |


[nibble]: https://en.wikipedia.org/wiki/Nibble
