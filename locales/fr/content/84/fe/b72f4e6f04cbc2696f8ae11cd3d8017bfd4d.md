# Ajout aux instructions

L'implémentation des nombres complexes dans la bibliothèque de base de Julia se trouve ici : https://github.com/JuliaLang/julia/blob/master/base/complex.jl.

---

## Bonus A
Tu peux travailler sur les exercices bonus portant sur l'arithmétique entre nombres réels et nombres complexes en décommentant :
`# enable_realcomplex_tests = true` dans le _stub_ `complex-numbers.jl` ou dans `runtests.jl`

## Bonus B
Tu peux travailler sur les exercices bonus entre nombres réels et nombres complexes en décommentant :
`# enable_syntaxsugar_tests = true` dans le _stub_ `complex-numbers.jl` ou dans `runtests.jl`
Ensuite, implémente `jm` de façon analogue à `im`, pour que `1 + 1jm == ComplexNumber(1, 1)`.
