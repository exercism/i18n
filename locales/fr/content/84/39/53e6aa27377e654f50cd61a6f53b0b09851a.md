# Instructions

Dans cet exercice, tu vas aider des amoureux de lycée à déclarer leur amour sur les réseaux sociaux en générant un cœur en ASCII avec leur initiale :

```
❤ J.  +  M. ❤
```

## 1. Nettoie le nom

Implémente la méthode `HighSchoolSweetheart.clean_up_name`.
Elle prend un nom, en retire tous les caractères `-` et les remplace par un espace.
Elle retire aussi les espaces au début et à la fin du nom.

```crystal
HighSchoolSweetheart.clean_up_name("Jane-Ann")
# => "Jane Ann"
```

## 2. Récupère la première lettre du nom

Implémente la méthode `HighSchoolSweetheart.first_letter`.
Elle prend un nom et renvoie sa première lettre.
Pense à réutiliser `HighSchoolSweetheart.clean_up_name`, que tu as définie à l'étape précédente.

```crystal
HighSchoolSweetheart.first_letter("Jane")
# => "J"
```

## 3. Mets la première lettre au format d'une initiale

Implémente la méthode `HighSchoolSweetheart.initial`.
Elle prend un nom et renvoie sa première lettre, en majuscule, suivie d'un point.
Pense à réutiliser `HighSchoolSweetheart.first_letter`, que tu as définie à l'étape précédente.

```crystal
HighSchoolSweetheart.initial("Robert")
# => "R."
```

## 4. Place les initiales à l'intérieur du cœur

Implémente la méthode `HighSchoolSweetheart.pair`.
Elle prend deux noms et renvoie les initiales entourées de cœurs emoji.
Pense à réutiliser `HighSchoolSweetheart.initial`, que tu as définie à l'étape précédente.

```crystal
HighSchoolSweetheart.pair("Blake Miller", "Riley Lewis")
# => "❤ B.  +  R. ❤"
```
