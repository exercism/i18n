# Tests

Tu peux utiliser l'éditeur en ligne du site d'Exercism pour résoudre les exercices.
Ou bien, télécharge les exercices sur ton ordinateur, résous-les en local, puis soumets-les à Exercism.

Si tu veux travailler en local, il te faudra le programme [`bats`][bats].
Consulte la page [Tests sur le parcours Bash][test-bash] pour les instructions d'installation.

Ton code sera testé sur l'exécuteur de tests jq d'Exercism avec [`jq` version **1.8**][jq].

[bats]: https://github.com/bats-core/bats-core
[test-bash]: https://exercism.org/docs/tracks/bash/tests
[jq]: https://jqlang.org/manual/
