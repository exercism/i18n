# Indices

## 1. Rends magnifique

- Le mapping est le bon processus pour appliquer une fonction à chaque élément d'une séquence.
- `mapcar` est une bonne fonction pour appliquer une fonction à un tableau.

## 2. Rien que le meilleur

- Le filtrage est le bon processus pour retirer un ou plusieurs éléments d'une séquence, ce qui donne une nouvelle séquence.
- `remove` permet de retirer d'une séquence les valeurs égales à un élément précis.
- `remove-if` permet de retirer les valeurs pour lesquelles une fonction de prédicat renvoie une valeur vraie.
