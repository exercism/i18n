# Indices

## 1. Imprime un badge pour un employé

- [L'interpolation de _string_][string-interpolation] permet de mettre en forme le badge de façon concise.
- Il existe une [méthode intégrée pour convertir une _string_ en majuscules][toupper].

## 2. Imprime un badge pour un nouvel employé

- Tu dois vérifier que l'ID vaut `null` avant de l'utiliser.
- [Ce tutoriel explique en détail comment manipuler les types valeur nullables][nullable-types-tutorial].

## 3. Imprime un badge pour le propriétaire

- Tu dois vérifier que le département vaut `null` avant de l'utiliser.
- [Ce tutoriel explique en détail comment manipuler les types référence nullables][nullable-reference-types-tutorial].
- L'[opérateur conditionnel null][null-conditional-operator] permet de simplifier l'appel d'un membre sur une valeur nullable.
- L'[opérateur de fusion null][null-coalescing-operator] permet de simplifier le renvoi d'une autre valeur lorsqu'une valeur nullable vaut `null`.
