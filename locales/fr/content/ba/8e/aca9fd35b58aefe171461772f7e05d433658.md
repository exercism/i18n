# Exécute les tests

Pour exécuter les tests d'un exercice donné, place-toi dans le dossier de l'exercice avec `cd`, puis lance la commande suivante :

```bash 
box task run TestRunner
# Or start up a test watcher that will rerun when files change
box task run TestRunner --:watcher
```

Les tests s'appuient sur une bibliothèque appelée TestBox, qui prend en charge les styles de test xUnit et BDD. Toutes les suites de tests seront écrites dans le [style BDD](https://testbox.ortusbooks.com/content/primers/bdd/specs.html), qui utilise des _closures_ pour définir les spécifications des tests. Pas besoin de te soucier de l'installation de TestBox : l'exécuteur de tests de la CLI s'en charge pour toi. Il te suffit d'être connecté à Internet la première fois que tu le lances. Tu peux en savoir plus ici :

[https://testbox.ortusbooks.com](https://testbox.ortusbooks.com)
