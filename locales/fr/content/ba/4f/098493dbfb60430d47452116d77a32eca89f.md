# Introduction

En Python, les instructions [`if`][if statement], `elif` (_une contraction de « else » et « if »_) et `else` servent à [contrôler le flux][control flow tools] d'exécution et à prendre des décisions dans un programme.
Contrairement à beaucoup d'autres langages de programmation, les versions 3.9 et antérieures de Python n'offrent pas d'instruction switch formelle : on utilise à la place plusieurs instructions `elif` pour obtenir un résultat similaire.

Python 3.10 introduit une variante d'instruction switch appelée `pattern matching`, qui sera abordée séparément dans un autre concept.

Les instructions conditionnelles utilisent des expressions qui doivent donner `True` ou `False`, soit en renvoyant directement un `bool`, soit en évaluant [« _truthy_ » ou « _falsy_ »][truth value testing].


```python
x = 10
y = 5

# The comparison '>' returns the bool 'True',
# so the statement is printed.
if x > y:
    print("x is greater than y")
...
>>> x is greater than y
```

Lorsqu'il est associé à `if`, un bloc de code `else` facultatif s'exécute lorsque la condition `if` d'origine prend la valeur `False` :

```python
x = 5
y = 10

# The comparison '>' here returns the bool False,
# so the 'else' block is executed instead of the 'if' block.
if x > y:
    print("x is greater than y")
else:
    print("y is greater than x")
...
>>> y is greater than x
```

`elif` permet d'enchaîner plusieurs évaluations et branches.

```python
x = 5
y = 10
z = 20

# The elif statement allows for the checking of more conditions.
if x > y > z:
    print("x is greater than y and z")
elif y > x > z:
    print("y is greater than x and z")
else:
    print("z is greater than x and y")
...
>>> z is greater than x and y
```

Les [opérations booléennes][boolean operations] et les [comparaisons][comparisons] peuvent se combiner avec les instructions conditionnelles pour des tests plus complexes :

```python
>>> def classic_fizzbuzz(number):
...     if number % 3 == 0 and number % 5 == 0:
...         say = 'FizzBuzz!'
...     elif number % 5 == 0:
...         say = 'Buzz!'
...     elif number % 3 == 0:
...         say = 'Fizz!'
...     else:
...         say = str(number)
...     return say

>>> classic_fizzbuzz(15)
'FizzBuzz!'

>>> classic_fizzbuzz(13)
'13'
```
