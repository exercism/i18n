# Instructions

Tu donnes les signaux de la pièce de ton école. Le régisseur veut que les répliques standard soient écrites pour que n'importe qui puisse assurer la régie.

Tu as quatre tâches, toutes dans la classe `STAGE_DIRECTIONS`.

## 1. Annonce le début

Renvoie la réplique qui ouvre le spectacle.

```sather
STAGE_DIRECTIONS::opening_line
-- => "The curtain rises."
```

## 2. Annonce l'entracte

Renvoie la réplique annoncée à la mi-temps.

```sather
STAGE_DIRECTIONS::interval_line
-- => "Interval. Fifteen minutes."
```

## 3. Annonce la fin

Renvoie la réplique qui clôt le spectacle.

```sather
STAGE_DIRECTIONS::closing_line
-- => "The curtain falls."
```

## 4. Donne le dernier signal

Le dernier signal est la même réplique que celle qui clôt le spectacle. Plutôt que d'écrire le texte une seconde fois, appelle la routine que tu as déjà écrite.

```sather
STAGE_DIRECTIONS::final_cue
-- => "The curtain falls."
```
