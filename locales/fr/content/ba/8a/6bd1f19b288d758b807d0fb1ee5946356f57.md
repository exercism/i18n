# Installation

Exercism te permet de programmer et de tester ton code ABAP directement dans le navigateur. Aucune installation supplémentaire n'est nécessaire. Toutefois, si tu préfères coder et tester sur ton propre système, tu peux te procurer un système ABAP d'essai.

Bien sûr, il se peut que ton employeur utilise SAP. Renseigne-toi auprès de ton service informatique pour savoir si tu peux accéder à un bac à sable de développement ABAP, et comment.

## Quelle version choisir ?

On te conseille d'utiliser une version récente de la plateforme ABAP toujours maintenue. Actuellement, il s'agit d'**ABAP 7.5 et versions ultérieures**. Tu trouveras les détails sur les versions actuelles et leur calendrier sur le [SAP Developer Center](hhttps://developers.sap.com/tutorials/mission-get-started-with-abap-development-on-premise).

## Quoi installer ?

On te recommande d'utiliser la plus récente [ABAP Cloud Developer Trial](https://hub.docker.com/r/sapse/abap-cloud-developer-trial). Elle repose sur ABAP 7.58. Tu peux installer le système SAP ABAP en tant qu'image Docker ou l'héberger dans la SAP Cloud Appliance Library. Il te faut également installer SAP GUI, pour Windows ou pour Java selon ton système d'exploitation. Tu peux télécharger SAP GUI [ici](https://www.sap.com/products/try-sap/trials-downloads.html?search=sap+gui).

Pour plus de détails, consulte ce billet de blog sur la [SAP Community](https://community.sap.com/t5/technology-blog-posts-by-sap/abap-cloud-developer-trial-2023-available-now/ba-p/14057183).
