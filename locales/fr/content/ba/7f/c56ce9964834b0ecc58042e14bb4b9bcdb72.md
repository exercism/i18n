# Introduction

De nombreux langages disposent d'un moyen comme `null` ou `none` pour indiquer une valeur inexistante.
Comme R est conçu pour traiter de grands volumes de données (souvent désordonnées), il dispose de plusieurs formes de néant.

L'objectif général est de signaler les valeurs manquantes ou suspectes au fur et à mesure qu'on les rencontre, puis de continuer sans lever d'exception.

## NULL

Si une valeur n'existe vraiment pas, elle est représentée par `NULL`. C'est probablement ce qui se rapproche le plus de ce que font C ou Python.

```R
v <- c() # zero-length vector
v
#> NULL
is.null(v)
#> [1] TRUE
```

Dans de nombreux contextes, les valeurs `NULL` sont simplement ignorées :

```R
c(2, 3, NULL, 5)
#> [1] 2 3 5
```

## NA

Pour les situations où une valeur existe mais où on ne sait pas ce qu'elle vaut, on utilise `NA`. Par exemple, lorsqu'on compte les véhicules qui circulent sur une route, il arrive que les observateurs humains tombent malades ou que les capteurs automatiques tombent en panne, mais le trafic continue de s'écouler.

```R
v <- c(1, 2, NA, 4, 5)
v
#> [1]  1  2 NA 4  5
is.na(v) # test for data gaps
#> [1] FALSE FALSE  TRUE FALSE FALSE
```

Ainsi, `NA` est un espace réservé, qui signale qu'il faut décider comment le traiter.

## Vecteurs vides

Assez étonnamment, R n'offre pas de moyen standard pour vérifier qu'un vecteur est vide, même si certains paquets tiers implémentent leurs propres fonctions comme `is.empty()`.

Même la création d'un vecteur vide n'a rien d'évident.
On a vu dans une section précédente que `c()` sans arguments renvoie `NULL`, et non un vecteur.

```R
is.vector(c())
#> [1] FALSE
```

Des fonctions comme `logical()` ou `integer()` prennent un argument qui indique la longueur souhaitée, laquelle peut être zéro.

```R
z <- logical(0)
is.vector(z)
#> [1] TRUE
length(z)
#> [1] 0
```

On peut aussi créer un vecteur puis en supprimer chaque élément, comme décrit dans le [concept Vecteurs][concept-vectors].
On obtient ainsi un vecteur de longueur 0, du type approprié.

```R
v <- 5
v[-1]  # delete the first element
#> numeric(0)
```

[concept-vectors]: https://exercism.org/tracks/r/concepts/vectors
