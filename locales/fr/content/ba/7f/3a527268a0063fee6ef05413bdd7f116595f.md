# Introduction

## Classes

La principale construction orientée objet en C# est la _classe_, qui combine des données (_champs_) et un comportement (_méthodes_). Les champs et les méthodes d'une classe sont appelés ses _membres_.

L'accès aux membres peut être restreint au moyen de modificateurs d'accès, les deux plus courants étant :

- `public` : le membre est accessible depuis n'importe quel code (aucune restriction).
- `private` : le membre n'est accessible que depuis le code de la même classe.

Tu peux voir une classe comme un modèle servant à créer des instances de cette classe. Pour créer une instance d'une classe (aussi appelée _objet_), on utilise le mot-clé `new` :

```csharp
class Car
{
}

// Create two car instances
var myCar = new Car();
var yourCar = new Car();
```

Les champs ont un type et peuvent être définis n'importe où dans une classe.
Les champs publics sont définis en `PascalCase` et les champs privés en `camelCase`, précédés d'un _underscore_ (`_`) :

```csharp
class Car
{
    // Accessible by anyone
    public int Weight;

    // Only accessible by code in this class
    private string _color;
}
```

On peut éventuellement affecter une valeur initiale à un champ. Si un champ ne spécifie _pas_ de valeur initiale, il prend la valeur par défaut de son type. On peut lire et mettre à jour les valeurs des champs d'une instance à l'aide de la notation pointée.

```csharp
class Car
{
    // Will be set to specified value
    public int Weight = 2500;

    // Will be set to default value (0)
    public int Year;
}

var newCar = new Car();
newCar.Weight; // => 2500
newCar.Year;   // => 0

// Update value of the field
newCar.Year = 2018;
```

Les champs privés sont généralement mis à jour comme effet de bord de l'appel d'une méthode. De telles méthodes ne renvoient généralement aucune valeur, auquel cas le type de retour doit être `void` :

```csharp
class CarImporter
{
    private int _carsImported;

    public void ImportCars(int numberOfCars)
    {
        // Update private field from public method
        _carsImported = _carsImported + numberOfCars;
    }
}
```
