# Introduction

## L'opérateur _pipe_

L'opérateur `|>` s'appelle l'opérateur _pipe_. Il permet d'enchaîner des appels de fonctions, de sorte que la valeur renvoyée par l'appel de fonction précédent soit passée à l'appel de fonction suivant.

```gleam
"hello"
|> string.uppercase
|> string.append("?!")
// -> "HELLO?!"
```

Le code ci-dessus est équivalent à ce qui suit :

```gleam
string.append(string.uppercase("hello"), "?!")
```

L'opérateur _pipe_ passe la valeur soit comme premier argument de l'appel de fonction, soit comme unique argument d'un nouvel appel, en choisissant celle des deux possibilités qui donne le bon type.

```gleam
100
|> function_that_takes_two_arguments(1)

// Is equivalent to
function_that_takes_two_arguments(100, 1)
```

```gleam
100
|> function_that_returns_a_function(1)

// Is equivalent to
function_that_returns_a_function(1)(100)
```

Il arrive parfois que l'on veuille placer la valeur à une autre position ; dans ce cas, on peut utiliser le marqueur de position `_` pour indiquer où la valeur doit être insérée.

```gleam
100
|> some_function(1, _, 2)
```
