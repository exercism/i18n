## Messages d'exception

Il est parfois nécessaire de [lever une exception](https://docs.python.org/3/tutorial/errors.html#raising-exceptions). Dans ce cas, il faut toujours inclure un **message d'erreur explicite** qui indique l'origine de l'erreur. Cela rend le code plus lisible et facilite grandement le débogage. Si tu sais que la source de l'erreur sera d'un type donné, tu peux lever l'un des [types d'erreur intégrés](https://docs.python.org/3/library/exceptions.html#base-classes), mais tu dois tout de même y joindre un message explicite.

Cet exercice demande en particulier d'utiliser l'[instruction `raise`](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement) pour « lever » une `ValueError` si les paramètres series et/ou length fournis en entrée de la fonction `slice()` sont vides ou hors limites. Les tests ne réussiront que si tu lèves l'`exception` avec `raise` et que tu y joins un message.

Pour lever une `ValueError` avec un message, écris ce message comme argument du type `exception` :

```python
# if the slice length is zero.
raise ValueError("slice length cannot be zero")

# if the slice length is negative.
raise ValueError("slice length cannot be negative")

# if the series provided is empty.
raise ValueError("series cannot be empty")

# if the slice length is longer than the series.
raise ValueError("slice length cannot be greater than series length")
```
