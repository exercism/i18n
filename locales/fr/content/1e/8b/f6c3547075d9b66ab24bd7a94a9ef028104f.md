# Indices

## Généralités

- Tous les mots de nettoyage se trouvent dans [`destructors`][destructors].
- `:>` et `::` (variables locales) rendent lisibles les corps qui manipulent plusieurs pompes. Ajoute `locals` à `USING:` si tu as besoin d'y recourir.

## 1. Vide la cale

- Un seul mot : `dispose`.

## 2. Routine de pompage

- Un seul mot : `with-disposal`. Ajoute `inline` après le `;` fermant pour que le compilateur puisse voir à travers l'argument _quotation_ :
  `: pump-out ( pump quot -- ) with-disposal ; inline`.

## 3. Routine de tout le quart

- Ouvre la portée avec `with-destructors`. À l'intérieur, enregistre chaque pompe avec `&dispose`, puis appelle la _quotation_ avec `call`. Avec des variables locales :
  `[ pump-a &dispose pump-b &dispose quot call ] with-destructors`.

## 4. Pompage risqué

- Même forme que la tâche 3, mais avec `|dispose` (uniquement en cas d'échec) sur une seule pompe.

## 5. Un objet jetable personnalisé : la valve

- `TUPLE: valve < disposable is-open ;` : `<` étend `disposable`, donc la mécanique du framework est héritée.
- `<valve>` utilise `new-disposable` (et non le simple `new`) pour que la nouvelle valve soit enregistrée auprès du framework.
- `M: valve dispose*` est ton point d'accroche de nettoyage. Il est important de ne rien renvoyer sur la pile : `>>is-open` laisse le tuple au sommet, donc termine par `drop`.

[destructors]: https://docs.factorcode.org/content/vocab-destructors.html
