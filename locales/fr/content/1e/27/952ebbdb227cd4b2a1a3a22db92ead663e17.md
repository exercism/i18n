# Références et instantanés

Quand on passe une variable à une fonction, sa propriété est généralement transférée, ce qui rend la variable d'origine inutilisable. C'est un peu pénible quand on veut accéder plusieurs fois au même état.
Cairo dispose de deux mécanismes pour transmettre une valeur sans la détruire ni la déplacer, appelés `references` et `snapshots`.

## Les instantanés

Les instantanés offrent une vue immuable d'une valeur à un moment donné, ce qui permet de conserver la propriété d'une variable tout en accédant à son état.
Toute modification de la variable crée une nouvelle cellule mémoire, sans changer la vue de l'instantané.

```rust
fn get_len(arr: @Array<u128>) -> u32 { // this parameter takes in a snapshot using `@` with the data-type
    arr.len()
}

fn foo(arr: Array<u128>) {
    arr.pop_front();
}

fn main() {
    let mut new_arr: Array<u128> = array![1, 2, 3, 4, 5, 6, 7, 8];
    let snapshot = @new_arr; // using `@` to create a snapshot of a variable
    let len = get_len(snapshot); // pass the snapshot as argument, retaining ownership
    foo(new_arr); // `new_arr` is still valid up until here and no further

    // let new_len = new_arr.len(); // this would throw an error if you uncommented the code because `new_arr` has been moved when it was passed into `foo()` above
}
```

## L'opérateur _desnap_

Pour reconvertir un instantané en variable ordinaire, on peut utiliser l'opérateur _desnap_ `*`, qui est l'opposé de l'opérateur `@`.
Seuls les types qui implémentent le trait `Copy` peuvent être convertis avec cet opérateur.

```rust
#[derive(Drop)]
struct Rectangle {
    height: u64,
    width: u64,
}

fn main() {
    let rec = Rectangle { height: 3, width: 10 };
    let area = calculate_area(@rec);
    println!("Area: {}", area);
}

fn calculate_area(rec: @Rectangle) -> u64 {
    // We need to transform the snapshots back into values using the desnap operator `*`.
    // Here we use `*` to both multiply the height and width and to desnap the snapshots.
    *rec.height * *rec.width
}
```

## Les références mutables

Les références mutables permettent de passer des valeurs mutables à une fonction pour qu'elles soient renvoyées implicitement, tout en conservant la propriété dans le contexte appelant.
On y parvient grâce au modificateur `ref`, à condition que la variable soit déclarée mutable avec le mot-clé `mut`.

```rust
fn foo(ref arr: Array<u128>) { // using `ref` marks the argument as a mutable reference
    arr.pop_front(); // modifies the state of arr
}

fn main() {
    let mut new_arr: Array<u128> = array![1, 2, 3, 4, 5, 6, 7, 8];

    foo(ref new_arr);  // use `ref` to pass a mutable reference to the function

    let new_len = new_arr.len();  // the current context retains ownership of `new_arr`, so we can still use it
}
```
