# À propos

## Les opérations bit à bit

Les opérations bit à bit permettent de manipuler les chiffres individuels d'un nombre binaire.
Ces opérations sont fondamentales en informatique, car elles offrent un moyen efficace d'effectuer des tâches de bas niveau, comme le contrôle de bits précis en mémoire, l'optimisation de calculs mathématiques, le chiffrement, les communications et l'encodage ou le décodage de données.

### Comprendre les entiers de 32 bits en Elm

En Elm, les entiers sont stockés sous forme d'entiers signés de 32 bits, en [complément à deux](https://en.wikipedia.org/wiki/Two%27s_complement), ce qui signifie qu'ils utilisent 32 chiffres binaires (_bits_) pour stocker chaque valeur entière.
Cette limite de bits détermine la plage d'entiers qu'Elm peut représenter directement :

Plage positive : 0 à 2<sup>31</sup> - 1 (soit 0 à 2 147 483 647)
Plage négative : -2<sup>31</sup> à -1 (soit -2 147 483 648 à -1).

Par exemple, l'entier `5` s'écrit en binaire `00000000000000000000000000000101`, même si, en général, on ignore les zéros de tête et qu'on dit simplement `101`.

### Bitwise

Elm fournit plusieurs opérateurs bit à bit dans son [module Bitwise](https://package.elm-lang.org/packages/elm/core/latest/Bitwise)

## Opérations de base

Modifier des bits individuels d'un nombre s'appelle le _masquage_.
Un _masque_ est un nombre dont certains bits ont été définis d'une manière particulière afin de manipuler un autre nombre à l'aide d'opérateurs bit à bit comme `and`, `or` et `xor`.

### Et

`and` combine deux nombres en ne conservant que les bits qui valent `1` dans les deux.
C'est utile pour vérifier si un bit particulier est à `1`.
Par exemple, pour vérifier si le 4e bit d'un nombre vaut `1`, fais un `and` avec un masque de `01000` (`8` en décimal) et regarde si le résultat est différent de zéro :

```elm
Bitwise.and 13 8 --> 8
--  13 = 01101
--   8 = 01000
-- and = 01000 = 8
```

### Ou

`or` combine deux nombres en mettant chaque bit à `1` s'il vaut `1` dans l'un des deux nombres, ou dans les deux.
C'est utile pour mettre un bit particulier à `1`.
Par exemple, pour mettre le 2e bit de `10101` à `1`, fais un `or` avec le masque `00010` :

```elm
Bitwise.or 21 2 --> 23
-- 21 = 10101
--  2 = 00010
-- or = 10111 = 23
```

### Ou exclusif (xor)

`xor` combine deux nombres en mettant chaque bit à `1` s'il vaut `1` dans l'un des nombres mais `0` dans l'autre.
C'est utile pour basculer un bit vers sa valeur opposée :

```elm
Bitwise.xor 20 5 --> 17
--  20 = 10100
--   5 = 00101
-- xor = 10001 = 17
```

### Complément

`complement` inverse chaque bit d'un nombre (`0` devient `1`, `1` devient `0`).

Attention : les nombres positifs deviennent alors négatifs, et les nombres négatifs deviennent positifs.
En effet, en binaire, les nombres négatifs sont représentés avec un `1` dans la position la plus à gauche.

```elm
Bitwise.complement 21 --> -22
--         21 = 00000000000000000000000000010101
-- complement = 11111111111111111111111111101010 = -22
```

### Décalage de bits

Les opérateurs suivants déplacent les bits vers la gauche ou vers la droite d'un nombre donné de positions, ce qui revient à multiplier ou à diviser par des puissances de 2.

`shiftLeftBy` déplace les bits vers la gauche, en complétant avec des `0` sur la droite.
Par exemple, pour décaler `21` de 3 positions vers la gauche :

```elm
Bitwise.shiftLeftBy 3 21 --> 168
--  21 = 10101
-- shiftLeftBy 3 = 10101000 = 168
```

Cela revient à écrire `21 * 2^3 = 21 * 2 * 2 * 2 = 168`

`shiftRightBy` déplace les bits vers la droite :

```elm
Bitwise.shiftRightBy 2 21 --> 5
--  21 = 10101
-- shiftRightBy 2 = 00101 = 5
```

Décaler de 2 positions vers la droite revient à une division entière par 4.

Note que cette fonction duplique la valeur présente dans le bit le plus à gauche.
Ainsi, les nombres négatifs restent négatifs :

```elm
Bitwise.shiftRightBy 3 -21 --> -3
--  -21 = 111...101011
-- shiftRightBy 3 = 111...11101 = -3
```

Si tu veux décaler vers la droite en complétant avec des zéros, utilise `shiftRightZfBy` :

```elm
Bitwise.shiftRightZfBy 3 -21 --> 536870909
--  -21 = 111...101011
-- shiftRightZfBy 3 = 00111...11101 = 536870909
```
