# Instructions

Tu as été chargé par le service des revendications d'Isaac's Asteroid Exploration Co. d'améliorer les performances de son système de revendication de terrains.

Chaque fois qu'un astéroïde est prêt à être exploité, les spéculateurs sont invités à revendiquer une parcelle de terrain.
Le terrain de l'astéroïde est divisé en parcelles rectangulaires qui ne se chevauchent pas.
Leurs dimensions varient, mais toutes ont leurs côtés parallèles aux axes de coordonnées.
Les spéculateurs revendiquent l'une de ces parcelles en précisant ses coordonnées.

Ton objectif est de développer un système performant pour gérer la ruée vers les terrains, qui a déjà fait planter le site par le passé.

L'unité de mesure est de 100 mètres, mais on peut l'ignorer dans ces exercices.

## 1. Définis un point

Définis une `struct` pour stocker des coordonnées `x` et `y`.
Ce sont des entiers positifs ou nuls plutôt petits, donc utilise le type `UInt16`.

```julia-repl
julia> Coord(7, 3)
Coord(0x0007, 0x0003)  # unsigned integers display in hex format by default
```

## 2. Définis un Plot

Comme toutes les parcelles doivent être rectangulaires, avec des côtés horizontaux et verticaux, seuls deux coins opposés suffisent pour les définir.

Implémente la `struct` `Plot`, dont le constructeur prend deux `Coord`.

`Plot` doit être une `struct` avec des arguments nommés, et les champs `bottom_left` et `top_right`.

```julia-repl
julia> plot = Plot(bottom_left=Coord(10, 1), top_right=Coord(20, 2))
Plot(Coord(0x000a, 0x0001), Coord(0x0014, 0x0002))

julia> plot.top_right
Coord(0x0014, 0x0002)
```

## 3. Vérifie si ta revendication a déjà été déposée

Les revendications sont très disputées, donc avant que la tienne soit acceptée, elle sera comparée aux revendications déjà présentes dans le registre.

Implémente la fonction `is_claim_staked()` pour déterminer si une revendication a déjà été déposée.

```julia-repl
julia> claim = Plot(bottom_left=Coord(10, 1), top_right=Coord(20, 2));
julia> register = Set{Plot}();
julia> is_claim_staked(claim, register)
false
```

## 4. Les spéculateurs peuvent déposer leur revendication en précisant une parcelle identifiée par les coordonnées de ses coins

Implémente la fonction mutante `stake_claim!()` pour permettre d'enregistrer une revendication.

Si la même revendication a déjà été déposée, renvoie `false`.

Si une nouvelle revendication est possible, ajoute-la au registre et renvoie `true`.

```julia_repl
julia> claim = Plot(bottom_left=Coord(10, 1), top_right=Coord(20, 2));
julia> register = Set{Plot}();
julia> stake_claim!(claim, register)
true
```

## 5. Trouve la longueur du plus grand côté d'une parcelle.

Implémente la fonction `get_longest_side()` pour obtenir le plus grand côté (horizontal ou vertical) d'une revendication.

```julia-repl
claim = Plot(bottom_left=Coord(10, 1), top_right=Coord(20, 2));

julia> get_longest_side(claim)
0x000a
```

## 6. Trouve la parcelle revendiquée qui a le plus grand côté, à des fins de recherche

Implémente la fonction `get_claim_with_longest_side()` pour examiner toutes les revendications enregistrées et renvoyer la ou les revendications ayant le plus grand côté.

```julia-repl
julia> plot1 = Plot(bottom_left=Coord(5, 3), top_right=Coord(10, 5));
julia> plot2 = Plot(bottom_left=Coord(0, 0), top_right=Coord(3, 3));
julia> register = Set{Plot}([plot1, plot2]);

julia> get_claim_with_longest_side(register)
Plot(Coord(0x0005, 0x0003), Coord(0x000a, 0x0005))
```

Renvoie la ou les `Plot` sous forme de `Set`, avec un seul élément s'il n'y a qu'une seule parcelle la plus longue, et plusieurs en cas d'égalité.
