# Ajout aux instructions

## Les traits Rust pour `.to_string()`

Tu devras aussi implémenter `.to_string()` pour la structure `Clock`.
On s'en servira pour afficher l'état de `Clock`.
Tu peux soit l'implémenter directement, soit utiliser le [trait Display][display-trait].

Dans ce cas, essaie plutôt d'implémenter le [trait Display][display-trait] pour `Clock`.

Les traits offrent un moyen commun d'implémenter des fonctionnalités pour différents types.

Pour aller plus loin, demande-toi comment tu pourrais implémenter `String::from` pour le type `Clock`.
Tu n'es pas obligé de l'implémenter vraiment : c'est redondant avec `Display`, qui est généralement le
meilleur choix quand le type de destination est `String`, mais il est utile d'avoir quelques traits de
conversion de types dans sa boîte à outils.

[display-trait]: https://doc.rust-lang.org/std/fmt/trait.Display.html
