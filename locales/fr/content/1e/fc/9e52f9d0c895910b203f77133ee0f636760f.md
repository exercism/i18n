# Introduction

R n'a pas de type [ensemble][wiki-set] distinct ; il utilise à la place diverses fonctions pour effectuer des opérations similaires sur des vecteurs.

L'opérateur [`%in%`][ref-match] teste l'appartenance à un ensemble.
Cet opérateur infixe est un synonyme de la fonction `is.element()`.

```R
2 %in% 1:10 # TRUE
12 %in% 1:10 # FALSE
```

Les fonctions utiles incluent :

- [`unique()`][ref-unique] pour supprimer les doublons.
- [`union()`][ref-sets] pour combiner des ensembles (mathématiquement, `A ∪ B`).
- [`intersect()`][ref-sets] pour trouver les éléments communs aux deux ensembles (`A ∩ B`).
- [`setdiff()`][ref-sets] pour soustraire un ensemble d'un autre (`A - B`).
- [`setequal`][ref-sets] pour tester l'égalité d'ensembles, en ignorant les doublons et l'ordre.

```R
> set_1 <- c("a", "b", "c", "b", "a")
> unique(set_1) # deduplicate
[1] "a" "b" "c"

> set_2 <- c('a', "c", "d")
> union(set_1, set_2) # values in either set
[1] "a" "b" "c" "d"

> intersect(set_1, set_2) # values in both sets
[1] "a" "c"

> setdiff(set_1, set_2) # values in set_1 but not set_2
[1] "b"

> setdiff(set_2, set_1) # values in set_2 but not set_1
[1] "d"

setequal(set_1, c("c", "b", "a", "b")) # are elements the same after deduplication?
[1] TRUE
```

Dans chaque cas, la fonction renvoie une copie et laisse les arguments inchangés.

## Tables de hachage

Les opérations sur les vecteurs décrites ci-dessus font partie de base R.
Elles sont utiles pour de petits problèmes, mais deviennent lentes pour de grands ensembles.

Divers paquets tiers implémentent des [tables de hachage][wiki-hash], afin d'améliorer les performances dans certains contextes.

Par exemple, le paquet [`hashtable`][ref-hashtable] fournit des implémentations de `hashmap` et `hashset`, qui passent mieux à l'échelle.
Comme la plupart des paquets externes, celui-ci n'est pas disponible dans Exercism, mais il vaut la peine de s'y intéresser pour des problèmes concrets.
