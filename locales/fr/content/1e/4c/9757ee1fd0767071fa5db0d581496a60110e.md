# À propos

Swift propose trois principales constructions de boucles :

- **Boucles `while`** : répètent un bloc de code tant qu'une condition donnée reste `true`. La condition est évaluée avant l'exécution du corps de la boucle.
- **Boucles `repeat-while`** : similaires aux boucles `while`, mais la condition est évaluée après l'exécution du corps de la boucle. Cela garantit que le corps est exécuté au moins une fois.
- **Boucles `for-in`** : exécutent un bloc de code une fois pour chaque élément d'une séquence ou d'une collection (comme un intervalle, un tableau ou une _string_).
