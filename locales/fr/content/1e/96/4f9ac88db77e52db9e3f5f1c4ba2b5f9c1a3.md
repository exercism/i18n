# Indices

## Général

- Les opérateurs sur les entiers et les nombres décimaux sont décrits dans [la visite guidée du langage][tour].
- Les fonctions qui permettent de manipuler les entiers sont définies dans [le module `gleam/int`][int].
- Les fonctions qui permettent de manipuler les nombres décimaux sont définies dans [le module `gleam/float`][float].
- Les fonctions qui permettent de manipuler les _strings_ sont définies dans [le module `gleam/string`][string].

[tour]: https://gleam.run/book/tour/ints-and-floats.html
[int]: https://hexdocs.pm/gleam_stdlib/gleam/int.html
[float]: https://hexdocs.pm/gleam_stdlib/gleam/float.html
[string]: https://hexdocs.pm/gleam_stdlib/gleam/string.html
