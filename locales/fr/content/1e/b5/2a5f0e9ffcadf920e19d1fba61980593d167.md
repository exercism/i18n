# Intégration à l'éditeur

La meilleure façon de développer en Clojure est d'utiliser un REPL connecté à l'éditeur. Des plugins sont disponibles pour les éditeurs/IDE les plus populaires :

- Emacs : [CIDER](https://cider.mx)
- IntelliJ : [Cursive](https://cursive-ide.com)
- VSCode : [Calva](https://calva.io)
- Vim : [Conjure](https://github.com/Olical/conjure)

Consulte la [documentation officielle](https://clojure.org/guides/editors) pour plus d'informations.
