# Instructions complémentaires

## Instructions spécifiques au parcours

Dans l'exercice « Yacht », tu vas créer un verbe qui calcule le score d'un lancer de cinq dés au jeu Yacht, en fonction de la catégorie choisie.

Pour cet exercice, ton verbe recevra deux arguments :

- **Argument gauche** : une _string_ représentant la catégorie de score à appliquer au lancer de dés.
- **Argument droit** : un tableau d'entiers représentant les cinq dés lancés.

Ton verbe doit être défini pour traiter ces entrées comme suit :

```j
  category =. 'Full House'
  dice     =. 1 3 3 3 5
  
  category scoreYacht dice
```
