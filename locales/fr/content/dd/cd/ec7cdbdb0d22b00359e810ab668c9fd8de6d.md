# Instructions

Dans cet exercice, tu dois implémenter quelques fonctions pour manipuler une liste de langages de programmation.

## 1. Définis une fonction qui renvoie une liste de langages vide

Définis la fonction `new` qui ne prend aucun argument et renvoie une liste vide.

```haskell
new
-- -> []
```

## 2. Définis une fonction qui ajoute un langage à la liste

Définis la fonction `add/2` qui prend 2 arguments (une _liste de langages_ et une chaîne de caractères littérale pour un _langage_).
Elle doit renvoyer la liste obtenue, avec le nouveau langage ajouté en tête de la liste donnée.

```haskell
add new "Clojure"
-- -> ["Clojure"]
add ["Clojure"] "Haskell"
-- -> ["Haskell", "Clojure"]
```

## 3. Définis une fonction qui retire un langage de la liste

Définis la fonction `remove` qui prend 1 argument (une _liste de langages_).
Elle doit renvoyer la liste sans son premier élément. Suppose que la liste contient toujours au moins un élément.

```haskell
remove ["Haskell", "Clojure", "Erlang"]
-- -> ["Clojure", "Erlang"]
```

## 4. Définis une fonction qui renvoie le premier élément de la liste

Définis la fonction `first` qui prend 1 argument (une _liste de langages_).
Elle doit renvoyer le premier langage de la liste.
Suppose que la liste contient toujours au moins un élément.

```haskell
first ["Elixir", "Haskell", "Clojure", "Prolog"]
-- -> "Elixir"
```

## 5. Définis une fonction qui renvoie le nombre de langages dans la liste

Définis la fonction `count` qui prend 1 argument (une _liste de langages_). 
Elle doit renvoyer le nombre de langages dans la liste.

```haskell
count ["Prolog", "Elm"]
-- -> 2
```

## 6. Définis une fonction qui détermine si la liste contient un langage fonctionnel

Définis la fonction `isFunctionalList` qui prend 1 argument (une _liste de langages_). 
Elle doit renvoyer une valeur booléenne. 
Elle doit renvoyer `True` si _"Haskell"_ figure parmi les langages de la liste.

```haskell
isFunctionalList ["Haskell"]
-- -> True
```
