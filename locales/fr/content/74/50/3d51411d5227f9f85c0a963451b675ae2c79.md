# À propos

Les structures de données qui peuvent contenir zéro ou plusieurs éléments sont appelées des _collections_. Un **tableau** est une collection dont la taille et la longueur sont fixes et dont tous les éléments doivent être du même type. On peut affecter des éléments à un tableau ou en récupérer à l'aide d'un indice. En C#, les tableaux sont indexés à partir de zéro, ce qui signifie que l'indice du premier élément est toujours zéro :

```csharp
// Declare array with explicit size (size is 2)
int[] twoInts = new int[2];

// Assign second element by index
twoInts[1] = 8;

// Retrieve the second element by index
twoInts[1] == 8; // => true

// Check the length of the array
twoInts.Length == 2; // => true
```

On peut aussi définir un tableau à l'aide d'une notation raccourcie qui permet à la fois de créer le tableau et de définir sa valeur. Comme le compilateur peut désormais déterminer combien d'éléments le tableau contiendra, la longueur peut être omise :

```csharp
// Three equivalent ways to declare and initialize an array (size is 3)
int[] threeIntsV1 = new int[] { 4, 9, 7 };
int[] threeIntsV2 = new[] { 4, 9, 7 };
int[] threeIntsV3 = { 4, 9, 7 };
```

On peut manipuler un tableau en appelant les [méthodes][array-methods] ou les [propriétés][array-properties] d'une instance de tableau, ou en utilisant les méthodes statiques définies dans la [classe `Array`][array-class].

## Itération

Un tableau est aussi une _collection_, ce qui signifie que l'on peut itérer sur _toutes_ ses valeurs à l'aide d'une [boucle `foreach`][foreach-statement] :

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // Output the vowel
    System.Console.Write(vowel);
}

// => aeiou
```

On peut utiliser une [boucle `for`][for-statement] pour parcourir un tableau :

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

for (int i = 0; i < vowels.Length; i++)
{
    // Output the vowel
    System.Console.Write(vowels[i]);
}

// => aeiou
```

Cependant, une boucle `foreach` est généralement préférable à une boucle `for`, pour les raisons suivantes :

- Une boucle `foreach` garantit d'itérer sur _toutes_ les valeurs. Avec une boucle `for`, il est facile d'oublier des éléments, par exemple à cause d'une erreur de décalage d'un indice.
- Une boucle `foreach` est plus _déclarative_ : le code exprime _ce_ que tu veux qu'il fasse, plutôt qu'une boucle `for` qui exprime _comment_ tu veux le faire.
- Une boucle `foreach` est infaillible, alors qu'avec les boucles `for`, il est facile de commettre une erreur de décalage d'un indice.
- Une boucle `foreach` fonctionne sur tous les types de collections, y compris ceux qui ne permettent pas d'utiliser un indexeur pour accéder aux éléments.

Pour garantir qu'une boucle `foreach` itère sur _toutes_ les valeurs, le compilateur n'autorise pas la modification d'une collection à l'intérieur d'une boucle `foreach` :

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // This would result in a compiler error
    // vowel = 'Y';
}
```

Une boucle `for` présente néanmoins quelques avantages par rapport à une boucle `foreach` :

- Tu peux commencer ou t'arrêter à l'indice que tu veux.
- Tu peux utiliser la condition d'arrêt (booléenne) que tu veux.
- Tu peux sauter des éléments en personnalisant l'incrémentation de la variable de boucle.
- Tu peux parcourir les collections de la fin vers le début en décrémentant.
- Tu peux utiliser les boucles `for` dans des situations qui n'impliquent pas de collections.

Sujets connexes :

- Sache que C# prend en charge les [tableaux multidimensionnels][multi-dimensional-arrays] comme `int[,] arr = new int[10, 5]`, qui peuvent être très utiles.
- Sache aussi que tu peux instancier des objets de type [`System.Array`][system-array-object] avec `Array.CreateInstance`. Ces objets sont peu utiles, principalement pour l'interopérabilité avec du code VB.NET. Ils ne sont pas interchangeables avec les tableaux standard (`T[]`) et peuvent avoir une borne inférieure non nulle.
