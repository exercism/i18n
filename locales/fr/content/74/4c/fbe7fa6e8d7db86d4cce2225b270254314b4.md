# Instructions

Un [nombre d'Armstrong][armstrong-number] est un nombre égal à la somme de ses propres chiffres, chacun élevé à la puissance du nombre de chiffres.

Par exemple :

- 9 est un nombre d'Armstrong, car `9 = 9^1 = 9`
- 10 *n'est pas* un nombre d'Armstrong, car `10 != 1^2 + 0^2 = 1`
- 153 est un nombre d'Armstrong, car `153 = 1^3 + 5^3 + 3^3 = 1 + 125 + 27 = 153`
- 154 *n'est pas* un nombre d'Armstrong, car `154 != 1^3 + 5^3 + 4^3 = 1 + 125 + 64 = 190`

Écris du code pour déterminer si un nombre est un nombre d'Armstrong.

[armstrong-number]: https://en.wikipedia.org/wiki/Narcissistic_number
