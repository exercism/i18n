# Comprends la récursion en JavaScript

La récursion est un concept puissant en programmation, qui repose sur une fonction qui s'appelle elle-même.
Elle peut être un peu délicate à appréhender au début, mais une fois que tu en comprends les fondements, elle devient un outil précieux pour résoudre des problèmes complexes.
On va explorer la récursion en JavaScript à l'aide d'exemples faciles à comprendre.

## Qu'est-ce que la récursion ?

La récursion se produit quand une fonction s'appelle elle-même, directement ou indirectement.
C'est semblable à une boucle, mais cela consiste à décomposer un problème en sous-problèmes plus petits et plus faciles à gérer.

### Exemple 1 : compte à rebours

Commençons par un exemple simple : une fonction de compte à rebours.

```javascript
function countdown(num) {
  // Base case
  if (num <= 0) {
    console.log('Blastoff!');
    return;
  }

  // Recursive case
  console.log(num);
  countdown(num - 1);
}

// Call the function
countdown(5);
```

Dans cet exemple :

- **Cas de base** : quand `num` devient inférieur ou égal à 0, la fonction affiche "Blastoff!" et cesse de s'appeler elle-même.
- **Cas récursif** : la fonction affiche la valeur actuelle de `num` puis s'appelle elle-même avec `num - 1`.

### Exemple 2 : la factorielle

Voyons maintenant un exemple classique de récursion : le calcul de la factorielle d'un nombre.

```javascript
function factorial(n) {
  // Base case
  if (n === 0 || n === 1) {
    return 1;
  }

  // Recursive case
  return n * factorial(n - 1);
}

// Test the function
console.log(factorial(5)); // Output: 120
```

Dans cet exemple :

- **Cas de base** : quand `n` vaut 0 ou 1, la fonction renvoie 1.
- **Cas récursif** : la fonction multiplie `n` par la factorielle de `n - 1`.

## Concepts clés

### Cas de base

Toute fonction récursive doit avoir au moins un cas de base, une condition dans laquelle la fonction cesse de s'appeler elle-même.
Sans cas de base, la récursion se poursuivrait indéfiniment, ce qui finit par provoquer un débordement de pile.

### Cas récursif

Le cas récursif définit comment la fonction s'appelle elle-même avec une version plus petite ou plus simple du problème.

## Avantages et inconvénients de la récursion

**Avantages :**

- Une solution élégante pour certains problèmes.
- Reproduit le principe de l'induction mathématique.

**Inconvénients :**

- Peut être moins efficace que les solutions itératives.
- Peut provoquer un débordement de pile en cas de récursion profonde.

## Conclusion

La récursion est une technique précieuse qui simplifie les problèmes complexes en les décomposant en sous-problèmes plus petits et plus faciles à gérer.
Comprendre les cas de base et les cas récursifs est essentiel pour écrire des solutions récursives efficaces en JavaScript.
