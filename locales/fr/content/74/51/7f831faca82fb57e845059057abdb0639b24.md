# Instructions supplémentaires

## Registres

| Registre | Utilisation  | Type    | Description                                    |
| -------- | ------------ | ------- | ---------------------------------------------- |
| `$a0`    | entrée       | adresse | tableau de mots contenant les capacités des seaux |
| `$a1`    | entrée       | entier  | seau de départ (1 ou 2)                        |
| `$a2`    | entrée       | entier  | volume cible                                   |
| `$a3`    | entrée/sortie | adresse | tableau de mots contenant le contenu final des seaux |
| `$v0`    | sortie       | entier  | nombre d'actions nécessaires, -1 si impossible |
| `$t0-9`  | temporaire   | quelconque | utilisé pour le stockage temporaire         |
