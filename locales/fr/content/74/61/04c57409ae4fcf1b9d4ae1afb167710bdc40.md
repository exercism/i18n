# Introduction

Une fonction d'ordre supérieur est une fonction qui fait l'une de ces deux choses :

- Elle prend une fonction en argument
- Elle renvoie une fonction

Un argument de type fonction n'est qu'un argument ordinaire, à ceci près qu'on peut l'appeler.

```fsharp
let double = fun x -> x * 2

let apply f x = f x

apply double 3
// => 6
```
