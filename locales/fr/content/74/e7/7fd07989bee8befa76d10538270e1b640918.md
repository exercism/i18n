# La question à un milliard de dollars du HTTP

## Énoncé du problème

On t'a demandé de trouver les `x` milliardaires les plus riches, par fortune nette, dans un ensemble donné de pays (nombre de pays = `N`). Pour cela, tu as accès à une API qui renvoie les détails des milliardaires par pays.

Pour simplifier l'accès à l'API, tu peux utiliser le connecteur [client `ims/billionairehub`](https://lib.ballerina.io/ims/billionairehub/1.0.0/clients/Client) pour te connecter à l'API qui renvoie les détails des milliardaires par pays.


## Contraintes

* 1 <= N <= 5
* 1 <= x <= 10

## Exemple 1

Entrée

```
Countries: ["United States"]
Limit: 3
```

Sortie

```
["Elon Musk", "Jeff Bezos", "Bill Gates"]
```

## Exemple 2

Entrée

```
Countries: ["China", "India"]
Limit: 5
```

Sortie

```
["Mukesh Ambani", "Gautam Adani & family", "Zhong Shanshan", "Zhang Yiming", "Ma Huateng"]
```

## Environnement de test

* L'identifiant client et le secret client pour te connecter à l'API des milliardaires t'ont été fournis dans `tests/Config.toml`. Tu peux les utiliser pour initialiser le client.
* Utilise `bal test` pour exécuter et tester ton implémentation.

## Indices

* Le [client](https://lib.ballerina.io/ims/billionairehub/1.0.0/clients/Client) du paquet `ims/billionairehub` permet d'appeler l'API qui renvoie les milliardaires par pays. Tu peux notamment utiliser la méthode distante `getBillionaires("<country>")`.
* Tu peux d'abord trouver les personnes les plus riches de chaque pays, puis les combiner pour trouver les `x` premières.
* Les [expressions de requête](https://ballerina.io/learn/by-example/query-expressions/) seront pratiques pour filtrer et trier.
