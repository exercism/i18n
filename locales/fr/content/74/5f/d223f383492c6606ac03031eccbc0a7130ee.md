# Astuces

## Général

## 1. Calcule le taux d'intérêt

- Pour vérifier des conditions, une instruction `if` ou `case` peut être utile.

## 2. Calcule la mise à jour annuelle du solde

- Pour calculer le rendement annuel, il peut être utile de convertir temporairement un solde négatif en solde positif. La classe `Float` possède une méthode qui convertit en valeur absolue aussi bien les valeurs positives que les valeurs négatives.

## 3. Calcule le nombre d'années avant d'atteindre le solde souhaité

- Pour calculer le nombre d'années, on peut continuer à boucler jusqu'à atteindre le solde souhaité.
