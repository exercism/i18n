# PaySwitch - Convertisseur de salaire

## Énoncé du problème

Une entreprise appelée **Insure Everyone** paie ses employés dans des devises étrangères. Mais, en raison d'exigences législatives, le salaire doit être converti dans la devise locale. Ses employés sont répartis dans le monde entier.
Le service RH d'Insure Everyone cherche l'aide d'un développeur talentueux pour écrire un programme qui convertit le salaire de chaque employé dans sa devise locale. Insure Everyone s'appuie sur les taux de change fournis par une API externe.

À partir de cette API externe de taux de change, tu dois écrire une fonction qui prend une `source currency`, un `salary` (dans la devise source) et la `local currency` de l'employé, et qui renvoie le salaire dans la devise locale.

## Contraintes

* 500 <= `salary` <= 10000
* `sourceCurrency` et `targetCurrency` sont des [codes de devise ISO (alphabétiques)](https://en.wikipedia.org/wiki/ISO_4217#Active_codes). Les entrées de test peuvent contenir des codes de devise invalides.
* La précision du taux renvoyé sera mesurée jusqu'à `5` décimales.

## Exemple

### Exemple 1

#### Entrée :
* Salaire : 1000
* Devise source : USD
* Devise cible : GBP

#### Sortie :

En supposant que le service externe de change ait renvoyé la réponse de taux de conversion suivante (omise) :

```json
{
    "base": "USD",
    "rates": {
        // omitted
        "GBP": 0.73584,
        // omitted
    }
}
```

La fonction doit renvoyer `735.84000`

### Exemple 2

#### Entrée :

* Salaire : 1000
* Devise source : GBP
* Devise cible : USD

#### Sortie :

En supposant que le service externe de change ait renvoyé la réponse de taux de conversion suivante (omise) :

```json
{
    "base": "GBP",
    "rates": {
        // omitted
        "USD": 1.35898,
        // omitted
    }
}
```

La fonction doit renvoyer `1358.9800`
