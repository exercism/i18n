# Threads

## Informations sur les threads spécifiques à Tcl

Tu vas implémenter du parallélisme à l'aide de threads : subdivise l'entrée en morceaux que le code qui s'exécute dans un thread peut examiner de façon asynchrone. 

Quelques lectures sur les threads Tcl :

* [Modèle de gestion des threads de Tcl](https://www.tcl.tk/doc/howto/thread_model.html)
* [Bien utiliser les threads… avec Tcl](https://www.activestate.com/blog/threads-done-right-tcl/)
* [Scripts Tcl multi-threads](http://www.beedub.com/book/4th/Threads.pdf),
  un chapitre de _Practical Programming in Tcl and Tk, 4th Ed._,
copyright 2003 © Brent Welch, Ken Jones
[http://www.beedub.com/book/](http://www.beedub.com/book/)
    * Remarque : ce chapitre affirme que « la plupart des distributions binaires de Tcl ne sont pas compilées avec la gestion des threads ». Ce n'est plus le cas : les distributions de Tcl sont désormais compilées avec le support des threads (voir [TIP 364](https://core.tcl-lang.org/tips/doc/trunk/tip/364.md))
* [Commandes du paquet Thread](https://tcl.tk/man/tcl8.6/ThreadCmd/contents.htm) issues de la documentation de Tcl.
