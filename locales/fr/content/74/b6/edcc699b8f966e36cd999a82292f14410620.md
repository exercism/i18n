# Instructions

Tu es un observateur d'oiseaux passionné et tu gardes une trace du nombre d'oiseaux qui ont visité ton jardin. D'habitude, tu tiens un décompte dans un carnet pour compter les oiseaux, mais pour mieux exploiter tes données, tu as numérisé les comptages d'oiseaux des dernières semaines.

## 1. Détermine le nombre total d'oiseaux que tu as comptés jusqu'ici

Commençons par analyser les données pour en avoir une vue d'ensemble.
Découvre combien d'oiseaux tu as comptés au total depuis que tu as commencé à tenir tes relevés.

Implémente une fonction `TotalBirdCount` qui accepte un *slice* d'`int` contenant le nombre d'oiseaux comptés par jour.
Elle doit renvoyer le nombre total d'oiseaux que tu as comptés.

```go
birdsPerDay := []int{2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1}
TotalBirdCount(birdsPerDay)
// => 34
```

## 2. Calcule le nombre d'oiseaux visiteurs d'une semaine précise

Maintenant que tu as une idée générale de tes comptages d'oiseaux, tu veux faire une analyse plus fine.

Implémente une fonction `BirdsInWeek` qui accepte un *slice* contenant le nombre d'oiseaux comptés par jour et un numéro de semaine.

Elle renvoie le nombre total d'oiseaux que tu as comptés dans cette semaine précise.
Tu peux considérer que les semaines sont toujours suivies en entier.

```go
birdsPerDay := []int{2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1}
BirdsInWeek(birdsPerDay, 2)
// => 12
```

## 3. Corrige une erreur de comptage

Tu t'es rendu compte que pendant tout le temps où tu essayais de suivre les oiseaux, un oiseau se cachait dans un coin éloigné du jardin.

Tu as compris que cet oiseau passait toujours un jour sur deux dans ton jardin.

Tu ne sais pas exactement où il était entre ces jours-là, mais en tout cas pas dans ton jardin.

Ton intuition d'observateur d'oiseaux te dit aussi que l'oiseau était dans ton jardin le premier jour que tu as répertorié dans ta liste.

Avec ces nouvelles informations, écris une fonction `FixBirdCountLog` qui prend en argument un *slice* contenant le nombre d'oiseaux comptés par jour et qui renvoie le *slice* après avoir corrigé l'erreur de comptage.

```go
birdsPerDay := []int{2, 5, 0, 7, 4, 1}
FixBirdCountLog(birdsPerDay)
// => [3 5 1 7 5 1]
```
