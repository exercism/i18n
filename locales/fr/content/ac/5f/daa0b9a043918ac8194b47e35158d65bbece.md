# Indices

## Général

- `H{ } clone` est la bonne façon de créer une nouvelle table de hachage mutable : les littéraux `H{ }` peuvent être partagés entre les appels.
- `inc-at` de [`assocs`][assocs] ajoute 1 à la valeur d'une clé (ou l'insère avec la valeur 1 si elle est absente).

## 1. Construis un inventaire à partir d'une liste

- Commence avec `H{ } clone` et `inc-at` pour chaque élément. Une _quotation_ fry `'[ _ inc-at ]` capture la table de hachage, ce qui te permet de la passer à `each`.
- Enveloppe l'itération dans `[ … ] keep` pour que la table de hachage soit la valeur laissée sur la pile.

## 2. Ajoute d'autres éléments

- La forme est la même que pour la tâche 1, sauf que tu pars d'un `clone` de l'inventaire d'entrée plutôt que d'un inventaire vide.

## 3. Décrémente les compteurs

- Utilise d'abord `key?` ; seuls les éléments déjà présents dans l'inventaire sont modifiés.
- `change-at` accepte une _quotation_ `( old -- new )` ; associe-la à `[ 1 - 0 max ]` (avec `max` de [`math.order`][math.order]) pour que le compteur ne devienne jamais négatif.

## 4. Supprime entièrement un élément

- `delete-at` modifie la table de hachage en place et ne renvoie rien. Fais d'abord un `clone`, puis `delete-at`, puis laisse le clone sur la pile.

## 5. Liste les éléments disponibles

- `>alist` convertit la table de hachage en une séquence de paires.
- `[ second 0 > ] filter` ne garde que les éléments en stock.
- `sort-keys` (dans [`sorting`][sorting]) trie l'alist par clé.
