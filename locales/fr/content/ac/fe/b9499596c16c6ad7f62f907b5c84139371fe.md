# Instructions

Tu travailles à la mise en place d'un système de suivi de santé.
Dans ce cadre, tu dois garder la trace des statistiques de santé des utilisateurs.

Tu commenceras avec quelques fonctions vides dans un bloc `impl`, ainsi qu'avec la définition de structure suivante :

```rust
pub struct User {
    name: String,
    age: u32,
    weight: u32,
}
```

Ton objectif est d'implémenter les méthodes vides de la `struct` `User` définie dans le bloc `impl`.

Par exemple, la méthode `new` doit renvoyer une instance de la `struct` `User` avec le nom, l'âge et le poids indiqués.

```rust
let mut bob = User::new("Bob", 32, 72);
// Returns: a User with name "Bob", age 32, and weight 72
```

La méthode `weight` doit renvoyer le poids du `User`.

```rust
bob.weight();
// Returns: 72
```

La méthode `set_age` doit définir l'âge du `User`.

```rust
bob.set_age(33);
// Updates Bob's age to 33; happy birthday Bob!
```

Amuse-toi bien !
