# Introduction

Une fonction permet de regrouper du code dans une unité réutilisable.
Elle se compose du mot-clé `func`, du nom de la fonction, et d'une liste, séparée par des virgules, de zéro ou plusieurs paramètres et types entre parenthèses.

## Paramètres de fonction

Tous les paramètres doivent être typés explicitement ; il n'y a pas d'inférence de type pour les paramètres.
Les paramètres n'ont pas de valeur par défaut, donc tous les paramètres d'une fonction sont obligatoires.

```go
import "fmt"

// No parameters
func PrintHello() {
    fmt.Println("Hello")
}

// Two parameters
func PrintGreetingName(greeting string, name string) {
  fmt.Println(greeting + " " + name)
}
```

Les paramètres de même type peuvent être déclarés ensemble, suivis d'une seule déclaration de type.

```go
import "fmt"

func PrintGreetingName(greeting, name string) {
  fmt.Println(greeting + " " + name)
}
```

## Paramètres vs arguments

Voyons rapidement deux termes que l'on confond souvent : `parameters` et `arguments`.
Les paramètres de fonction sont les noms définis dans la signature de la fonction, comme `greeting` et `name` dans la fonction `PrintGreetingName` ci-dessus.
Les arguments de fonction sont les valeurs concrètes passées aux paramètres de la fonction quand on appelle la fonction.
Par exemple, dans l'exemple ci-dessous, `"Hello"` et `"Katrina"` sont les arguments passés aux paramètres `greeting` et `name` :

```go
PrintGreetingName("Hello", "Katrina")
```

## Valeurs de retour

Les paramètres de la fonction sont suivis de zéro ou plusieurs valeurs de retour, qui doivent elles aussi être typées explicitement.
Une valeur de retour unique s'écrit sans parenthèses, plusieurs valeurs de retour sont entourées de parenthèses.
Les valeurs sont renvoyées au code appelant depuis les fonctions à l'aide du mot-clé `return`.
Une fonction peut contenir plusieurs instructions `return`.
L'exécution de la fonction se termine dès qu'elle rencontre l'une de ces instructions `return`.
Si une fonction doit renvoyer plusieurs valeurs, celles-ci sont séparées par des virgules.

```go
func Hello(name string) string {
  return "Hello " + name
}

func HelloAndGoodbye(name string) (string, string) {
  return "Hello " + name, "Goodbye " + name
}
```

## Appeler des fonctions

Pour appeler une fonction, on précise le nom de la fonction et on passe des arguments pour chacun de ses paramètres entre parenthèses.

```go
import "fmt"

// No parameters, no return value
func PrintHello() {
    fmt.Println("Hello")
}
// Called like this:
PrintHello()

// One parameter, one return value
func Hello(name string) string {
  return "Hello " + name
}
// Called like this:
greeting := Hello("Dave")

// Multiple parameters, multiple return values
func SumAndMultiply(a, b int) (int, int) {
    return a+b, a*b
}
// Called like this:
aplusb, atimesb := SumAndMultiply(a, b)
```

## Valeurs de retour nommées et retour « nu »

Comme les paramètres, les valeurs de retour peuvent être nommées, de façon facultative.
Si l'on utilise des valeurs de retour nommées, une instruction `return` sans arguments renvoie ces valeurs.
C'est ce que l'on appelle un retour « nu ».

```go
func SumAndMultiplyThenMinus(a, b, c int) (sum, mult int) {
    sum, mult = a+b, a*b
    sum -= c
    mult -= c
    return
}
```

## Passage par valeur et passage par référence

Il est aussi important de clarifier les notions de passage par valeur et de passage par référence.

Commençons par clarifier le passage par valeur.
Dans l'exemple ci-dessous, quand on passe la variable `val` à la fonction `MultiplyByTwo`, c'est une copie de `val` que l'on passe.
Pour cette raison, `newVal` a la valeur mise à jour `4`, mais la variable d'origine `val` vaut toujours `2`.
En coulisses, Go fait essentiellement une copie de la valeur d'origine, de sorte que seule cette copie, alias `v`, est modifiée par la fonction.

```go
val := 2
func MultiplyByTwo(v int) int {
    v = v * 2
    return v
}
newVal := MultiplyByTwo(val)
// newval is 4, val is still 2 because only a copy of its value was passed into the function
```

À proprement parler, en Go, tous les arguments sont passés par valeur, c'est-à-dire qu'une copie est faite de la valeur ou des données fournies à la fonction.
Mais si tu ne veux pas faire de copie des données passées à une fonction et que tu veux modifier ces données dans la fonction, tu dois alors utiliser des `pointers` comme arguments, autrement dit le passage par référence.

## Pointeurs

On utilise un `pointer` pour réaliser le passage par référence.
En passant des arguments `pointer` à une fonction, on peut modifier les données sous-jacentes transmises à la fonction au lieu de n'opérer que sur une copie de ces données.

Pour l'instant, il suffit de savoir que les types pointeur se reconnaissent au `*` placé devant le type dans la signature de la fonction.

```go
func HandlePointers(x, y *int) {
    // Some logic to handle integer values referenced by pointers x and y
}
```

Si la notion de `pointer` te paraît déroutante, pas de panique.
Une section dédiée plus loin dans le programme t'aidera à maîtriser les pointeurs.

## Exceptions

Note que les `slices` et les `maps` font exception à la règle mentionnée ci-dessus.
Quand on passe un `slice` ou une `map` comme arguments à une fonction, ils sont traités comme des types pointeur, même s'il n'y a pas de `*` explicite dans le type.
Cela signifie que si l'on passe un slice ou une map à une fonction et que l'on modifie leurs données sous-jacentes, les changements se répercutent sur le `slice` ou la `map` d'origine.
