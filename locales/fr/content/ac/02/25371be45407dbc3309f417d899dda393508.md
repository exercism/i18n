# Indices

## Général

- Lis la section sur les _[structs][getting-started-structs]_ dans le guide de démarrage.
- Lis la documentation de [`defstruct`][docs-defstruct].
- Regarde [Elixir Casts - #106: Intro to Structs][elixir-casts].

## 1. Crée une toute nouvelle voiture télécommandée

- L'attribut de module `@enforce_keys` permet de spécifier les valeurs requises. Il doit être défini avant d'appeler `defstruct`.
- Aucune valeur par défaut ne doit être spécifiée pour le champ `nickname`.
- La fonction `new/0` doit initialiser le `nickname` avec la valeur `"none"`.

## 2. Crée une toute nouvelle voiture télécommandée avec un surnom

- Utilise [`multiple-function-clauses`][multiple-fn-clauses] pour réutiliser le nom de la fonction tout en acceptant des arguments différents.
- Envisage un [`default-argument`][default-arg] pour la fonction.

## 3. Affiche la distance

- Pour les fonctions qui n'acceptent qu'un type précis de _struct_, veille à faire un filtrage par motif pour vérifier l'argument.
- Utilise _l'opérateur d'accès statique_ pour obtenir les valeurs des champs.

## 4. Affiche le pourcentage de batterie

- Pour les fonctions qui n'acceptent qu'un type précis de _struct_, veille à faire un filtrage par motif pour vérifier l'argument.
- Utilise _l'opérateur d'accès statique_ pour obtenir les valeurs des champs.

## 5. La conduite modifie la batterie et la distance parcourue

- Pour les fonctions qui n'acceptent qu'un type précis de _struct_, veille à faire un filtrage par motif pour vérifier l'argument.
- Utilise _l'opérateur d'accès statique_ pour obtenir les valeurs des champs.
- Revois l'introduction pour savoir comment mettre à jour les _structs_.

## 6. Gère la conduite avec une batterie à plat

- Si la batterie est à plat, la fonction doit renvoyer le _struct_ sans le modifier.
