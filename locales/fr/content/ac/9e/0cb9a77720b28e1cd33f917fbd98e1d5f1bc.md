# À propos

## Les nombres

Swift possède deux principaux types de nombres : les entiers et les nombres à virgule flottante.
Les [entiers][integers] sont des nombres sans partie décimale, par exemple `0`, `1`, `-1`, `42` et `-273`.
Les [nombres à virgule flottante][floatingpoint] sont des nombres dotés d'une partie fractionnaire, par exemple `0.0`, `3.14` et `-1.36969e-10`.
Swift permet aussi d'utiliser des tirets bas pour rendre les nombres plus lisibles : `1_000_000` est identique à `1000000`.
Les nombres à virgule flottante peuvent s'écrire en notation décimale ou exponentielle.

Dans la plupart des cas, on définit le type des entiers comme [`Int`][int] et celui des nombres à virgule flottante comme [`Double`][double].

Pour déclarer une variable ou une constante de type `Int` ou `Double`, tu peux utiliser une annotation de type :

```swift
let speed: Int = 42                           // speed is an Int
let pi: Double = 3.14                         // pi is a Double
let giga: Double = 1_000_000_000              // giga is a Double
let plancksConstant : Double = 6.62607015e-34 // plancksConstant is a Double
```

## Opérateurs arithmétiques

~~~~exercism/caution
En Swift, on ne peut pas mélanger les types dans les opérations arithmétiques : on ne peut donc pas utiliser un opérateur arithmétique entre un `Int` et un `Double`, ni l'inverse.
Il faut par conséquent effectuer d'abord une conversion de type.
~~~~

Swift dispose d'un ensemble d'[opérateurs arithmétiques][arithmetic-operators] permettant d'effectuer les opérations mathématiques de base.
L'opérateur `+` sert à l'addition, l'opérateur `-` à la soustraction et l'opérateur `*` à la multiplication.

| Opérateur | Exemple                 |
| --------- | ----------------------- |
| `+`       | `4 + 6   // equals  10` |
| `-`       | `15 - 10 // equals  5`  |
| `*`       | `2 * 3   // equals  6`  |

### Division

L'opérateur `/` sert à la division.
Avec des nombres à virgule flottante, le résultat est un nombre à virgule flottante.
Avec des entiers, le résultat est un entier.

```swift
5 / 2.0 // equals 2.5
5 / 2   // equals 2
```

Si on divise un nombre à virgule flottante par zéro, le résultat est `inf`, ou `-inf`, selon le signe du nombre.
Si on divise zéro par zéro, et que l'un des deux est un nombre à virgule flottante, le résultat est `nan`.
Si on divise un entier par zéro, on obtient une erreur de compilation.

```swift
print(5.0 / 0.0)  // Prints inf
print(-5.0 / 0.0) // Prints -inf
print(0.0 / 0.0)  // Prints nan

// The following code will not compile
print(5 / 0) // error: division by zero
```

### Le reste

L'[opérateur `%`][remainder-operator] donne le reste de la division du premier argument par le second.
Cet opérateur ne fonctionne qu'avec des entiers.
Comme pour la division, si le second argument vaut zéro, le résultat est une erreur de compilation.

```swift
5 % 2  // equals 1
-5 % 2 // equals -1

// The following code will not compile
5 % 0 // error: division by zero
```

~~~~exercism/note
En Swift, `%` est l'opérateur de reste, contrairement à de nombreux autres langages qui l'utilisent comme opérateur modulo.
L'opérateur de reste (`REM`) et l'opérateur modulo (`MOD`) ne se comportent pas de la même façon avec des nombres négatifs.
Avec l'opérateur de _remainder_, le résultat a le même signe que le premier argument ; le signe du second argument n'influence pas le résultat.
Avec les opérateurs _modulo_ d'autres langages, le résultat a le même signe que le second argument.

```swift
+5 % -2 // equals 1
```
~~~~

## Arrondir des nombres

Pour arrondir un nombre, on utilise la méthode `rounded()` sur un nombre à virgule flottante.
Pour arrondir à l'entier le plus proche, tu peux utiliser la méthode `rounded()` sans argument.
Pour arrondir vers le haut ou vers le bas, tu peux préciser une [règle d'arrondi][rounding-rule] : `rounded(.up)` ou `rounded(.down)`.

```swift
let x = 3.14
let y = x.rounded()      // y equals 3.0
let w = x.rounded(.down) // w equals 3.0
let z = x.rounded(.up)   // z equals 4.0
```

## Inférence de type

Swift peut [déduire le type][typeinference] d'un nombre à partir du contexte ; sans contexte supplémentaire, le compilateur suppose que ce nombre est un `Int`.
Si tu veux indiquer au compilateur que tu souhaites qu'un nombre entier soit un `Double`, tu dois soit utiliser une annotation de type, soit ajouter `.0` à la fin du littéral numérique, par exemple :

```swift
let x = 42         // x is an Int
let y = 42.0       // y is a Double
let z: Double = 42 // z is a Double
```

## Conversion de type

En Swift, pour convertir une valeur d'un type à un autre, tu dois effectuer une [conversion de type][type-conversion].
Par exemple, pour convertir un `Int` en `Double` et inversement, tu procèdes comme suit :

```swift
let x = 42
let d = Double(x)
print(d)           // Prints 42.0
print(type(of: d)) // Prints Double

let pi = 3.14
let iPi = Int(pi)
print(iPi)           // Prints 3
print(type(of: iPi)) // Prints Int
```
