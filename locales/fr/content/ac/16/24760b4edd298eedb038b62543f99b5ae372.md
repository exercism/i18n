# Indices

## Général

- [Ruby pour débutants : le néant et la vérité][rfb-nothingness-and-truth]

## 1. Vérifie si un visiteur a un pass d'attraction

- Convertis le pass_id en un objet booléen.
- Regarde la classe [`BasicObject`][basicobject-class] : elle contient des méthodes dont la plupart des classes héritent.

## 2. Vérifie si un visiteur est assez grand pour une attraction

- Compare la taille minimale de l'attraction à la taille du visiteur.
- Regarde le module [`Comparable`][comparable-module] : il contient des méthodes pour comparer des objets, qui peuvent être utilisées lorsqu'on les inclut.
  - La classe [Integer][integer-class] inclut le module [`Comparable`][comparable-module].

## 3. Vérifie si un visiteur est autorisé à monter dans l'attraction

- Combine les méthodes d'instance que tu as créées à l'aide d'un [opérateur booléen][pr-boolean-operator] pour renvoyer le résultat.
