# Instructions

Dans cet exercice, on va traiter des lignes de log.

Chaque ligne de log est une _string_ formatée comme suit : `"[<LVL>]: <MESSAGE>"`.

Voici les différents niveaux de log :

- `TRC` (trace)
- `DBG` (debug)
- `INF` (info)
- `WRN` (warning)
- `ERR` (error)
- `FTL` (fatal)

Tu as trois tâches, qui doivent toutes être réalisées pour fournir la fonctionnalité nécessaire.

## 1. Créer l'énumération `LogLevel`

Définis une énumération `LogLevel` comportant six cas correspondant aux niveaux de log ci-dessus, plus un cas inconnu pour les niveaux dont le niveau de log est manquant ou non standard.

- `trace`
- `debug`
- `info`
- `warning`
- `error`
- `fatal`
- `unknown`

## 2. Analyser le niveau de log

Ensuite, implémente l'initialiseur `LogLevel` pour analyser le niveau de log d'une ligne de log :

```swift
LogLevel("[INF]: File deleted")
// Returns LogLevel.info
LogLevel("Something went wrong!")
// Returns LogLevel.unknown
```

## 3. Convertir une ligne de log au format court

Le niveau de log d'une ligne de log est assez verbeux.
Pour réduire l'espace disque nécessaire au stockage des lignes de log, un format court a été développé : `"<ENCODED_LEVEL>:<MESSAGE>"`.

Le niveau de log encodé est une simple correspondance entre un niveau de log et un nombre :

- `trace` - `0`
- `debug` - `1`
- `info` - `4`
- `warning` - `5`
- `error` - `6`
- `fatal` - `7`
- `unknown` - `42`

Implémente la méthode `shortFormat(message: String) -> String` qui peut renvoyer le format raccourci d'une ligne de log sous forme de `String` :

```swift
let overflow = LogLevel.error
overflow.shortFormat(message: "Stack overflow")
// Returns "6:Stack overflow"
```
