# Introduction

Comprendre les références est un élément fondamental pour utiliser Perl efficacement.
Comme les références sont des scalaires, et que les tableaux et les _hash_ ne peuvent contenir que des scalaires, les références sont essentielles pour imbriquer ces structures de données.

On peut créer des références vers des variables et des sous-programmes existants à l'aide de l'opérateur antislash `\` :

* `\$scalar` pour créer une référence de scalaire (ça peut être n'importe quel scalaire, par exemple `\1`, pas seulement une variable).
* `\@array` pour créer une référence de tableau.
* `\%hash` pour créer une référence de _hash_.
* `\&sub` pour créer une référence de code.

Tu peux aussi créer ce qu'on appelle une référence anonyme pour les tableaux, les _hash_ et les sous-programmes :

* `['Alice', 'Bob', 'Charlie']` pour créer une référence de tableau anonyme.
* `{foo => 'a', bar => 'b', baz => 'c'}` pour créer une référence de _hash_ anonyme.
* `sub { return 1 }` pour créer une référence de code anonyme.

ATTENTION : les accolades en Perl peuvent être ambiguës dans certains contextes. Si tu n'obtiens pas la référence de _hash_ que tu attends, ajoute un plus au début pour lever l'ambiguïté, par exemple `+{}`. Voir [Accolades][perlrefcurlybrackets] pour plus d'informations.

On peut accéder aux références à l'aide de l'opérateur flèche `->` :

* `$ref->[0]` pour accéder à un élément à l'intérieur d'une référence de tableau.
* `$ref->{foo}` pour accéder à une valeur à l'intérieur d'une référence de _hash_.
* `$ref->($arg)` pour appeler un sous-programme via une référence de code.

On peut accéder aux données contenues dans des structures de données complexes, comme les tableaux multidimensionnels et les _hash_ imbriqués, en enchaînant les indices, par exemple `$ref->{foo}[0]{bar}` (équivalent à `$ref->{foo}->[0]->{bar}`).

Si tu veux déréférencer un tableau ou un _hash_ entier, tu peux utiliser l'opérateur flèche suivi de `@*` ou de `%*` selon le cas, par exemple `$ref->@*` ou `$ref->%*`.
Tu peux aussi obtenir des tranches d'une référence de tableau ou de _hash_ en remplaçant le `*` par un indice, par exemple `$ref->@[0..2]` ou `$ref->@{'Foo', 'Bar'}`.
Pour les tranches, la variance de sigil s'applique ici de la même manière qu'avec les variables de tableau et de _hash_.

[perlrefcurlybrackets]: https://perldoc.perl.org/perlref#Curly-Brackets
