# `defmacro` avec `_is` et point d'interrogation

Elixir suit des conventions de nommage bien précises, notamment pour nommer [les fonctions qui renvoient un booléen](https://hexdocs.pm/elixir/naming-conventions.html#trailing-question-mark-foo) et [les vérifications qui renvoient un booléen et sont valides dans les clauses de garde](https://hexdocs.pm/elixir/naming-conventions.html#is_-prefix-is_foo) :

> Les fonctions qui renvoient un booléen sont nommées avec un point d'interrogation à la fin.

> Les vérifications de type et les autres vérifications booléennes autorisées dans les clauses de garde sont nommées avec un préfixe `is_`.

Les macros peuvent s'utiliser dans les deux contextes, donc la notation dépend du contexte, mais les deux conventions de nommage ne doivent pas être mélangées.

```elixir
# this is the expected name of macros that return booleans

%{option1}

# this is the expected name of macros that return booleans and are valid in guard clauses

%{option2}

# this is the current name

%{actual}
```
