# Instructions

Ton ami vient de t'envoyer un message contenant un secret important.
Pour ne pas rendre sa lecture facile aux autres, le message a été chiffré à l'aide d'une série de manipulations de bits.
Tu vas devoir écrire un programme pour t'aider à déchiffrer le message.

## 1. Redécale les bits

La première étape pour déchiffrer le message consiste à annuler le décalage effectué lors du chiffrement en redécalant les bits vers la gauche.
Le nombre de positions à décaler peut varier d'un message à l'autre.

Implémente la méthode `Secrets.shift_back` qui prend une valeur et le nombre de positions à décaler vers la gauche.

```crystal
Secrets.shift_back(0b0001, 2)
# => 0b0100
```

## 2. Applique un masque de bits

L'étape suivante consiste à appliquer un masque de bits pour extraire la valeur de certains bits.
Le masque s'applique en effectuant un ET bit à bit entre la valeur et le masque.

Implémente la méthode `Secrets.apply_mask` qui prend une valeur et lui applique un masque.

```crystal
Secrets.apply_mask(0b0110, 0b0101)
# => 0b0100
```

## 3. Mets certains bits à 1

Le décalage des bits vers la gauche a ajouté de nouveaux bits à 0.
Certains de ces nouveaux bits doivent être mis à 1.
Le OU bit à bit est utile pour mettre certains bits à 1 tout en préservant les autres.

Implémente la méthode `Secrets.set_bits` qui prend deux valeurs et effectue un OU bit à bit.

```crystal
Secrets.set_bits(0b0110, 0b0101)
# => 0b111
```

## 4. Inverse le XOR

Une partie du processus de chiffrement applique un XOR avec une valeur convenue.
Pour retrouver la valeur d'origine, il suffit d'appliquer de nouveau le XOR entre la valeur chiffrée et la valeur convenue.
Cependant, à cause d'un malentendu, ton ami a inversé les bits de la valeur convenue (c'est-à-dire appliqué un NON bit à bit à la valeur convenue) avant d'appliquer le XOR.

Implémente la méthode `Secrets.reverse_xor` qui prend la valeur chiffrée et la valeur convenue et calcule la valeur d'origine.

```crystal
Secrets.reverse_xor(0b1100, 0b0101)
# => 0b(0110)
```
