# Audit des paiements de la base de données

## Énoncé du problème

ABC Corp te demande de charger toutes les données de la base de données SQL dans une [table Ballerina](https://ballerina.io/learn/by-example/table-syntax/) pour les traiter ensuite. Tu dois ensuite trouver les noms des employés dont les paiements dépassent un montant donné (par exemple 3000,00) en interrogeant la table Ballerina chargée.

**Étape 1 :**

Crée une table Ballerina avec les colonnes suivantes.

`payment_id` - entier

`amount` - nombre décimal

`employee_name` - _string_

**Étape 2 :**

Remplis la table Ballerina ci-dessus en chargeant l'ensemble complet des données correspondantes de la base de données H2. Utilise `payment_id` comme clé primaire de la table.

**Étape 3**

Interroge la table Ballerina à l'aide d'expressions de requête Ballerina pour trouver les noms des employés dont les paiements dépassent le montant donné. Trie le résultat par nom d'employé dans l'ordre croissant. Supprime les doublons de noms dans le résultat avant de le renvoyer.

> REMARQUE : il est obligatoire d'utiliser une table Ballerina pour implémenter la solution.

## Détails de la base de données

Utilise la base de données H2 fournie pour ce problème.

> Le fichier de base de données d'exemple est `gofigure.mv.db`, et le nom de la base de données est `gofigure`. Il se trouve dans le dossier `db`.

Les tables suivantes sont déjà présentes dans la base de données H2 d'exemple, avec quelques données d'exemple. Les noms de colonnes et les types de données sont indiqués ci-dessous.

**Nom de la table** : `Employee`

| **Colonnes :**      | type |
| -----------       | ----------- |
| `employee_id`     | entier, clé primaire auto-incrémentée       |
| `name`            | _string_        |
| `city`            | _string_        |
| `department`      | _string_        |
| `age`             | entier        |

**Nom de la table** : `Payment`

| **Colonnes :**      | type |
| -----------       | ----------- |
| `payment_id`      | entier, clé primaire auto-incrémentée       |
| `date`            | date        |
| `amount`          | nombre décimal        |
| `employee_id`     | entier        |
| `reason`          | _string_        |

* Le fichier de base de données est `gofigure.mv.db`. Utilise l'URL JDBC `jdbc:h2:file:/path/to/db/file`
* Nom d'utilisateur : `root`
* Mot de passe : `root`
