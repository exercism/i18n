# Tests

## Ligne de commande

La commande suivante permet d'exécuter les tests depuis la ligne de commande :

```bash
swipl -f <exercise>.pl -s <exercise>_tests.plt -g run_tests,halt -t 'halt(1)'
```

Remplace `<exercise>` par le nom de l'exercice que tu es en train de résoudre.

## Mode interactif

Pour lancer Prolog en mode interactif, commence par exécuter :

```bash
swipl
```

Une fois la console Prolog démarrée, charge ton implémentation et lance les tests avec :

```
?- ["<exercise>.pl"].
?- ["<exercise>_tests.plt"].
?- run_tests.
```

Remplace `<exercise>` par le nom de l'exercice que tu es en train de résoudre.

### Recharge les modifications

Une fois les fichiers ci-dessus chargés, tu peux appliquer les modifications que tu as faites en exécutant :

```
?- make.
```

## Tests ignorés

Quand tu commences un exercice, seul le premier test s'exécute. Les autres sont ignorés par l'ajout de `condition(pending)` au but `test`. Une fois que le premier test passe, réactive le test suivant en remplaçant `pending` par `true` dans `condition(pending)`. Répète l'opération pour chaque test jusqu'à ce qu'ils s'exécutent et passent tous.

### Ligne de commande

Ajoute l'argument `-- --all` à la fin de la commande pour exécuter aussi les tests en attente :

```bash
swipl -f <exercise>.pl -s <exercise>_tests.plt -g run_tests,halt -t 'halt(1)' -- --all
```
