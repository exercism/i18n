# À propos

[Les `Rational numbers`][rational] sont des fractions dont le numérateur et le dénominateur sont des entiers.

Par exemple, on peut stocker `2//3` sous forme de fraction exacte au lieu de la valeur approchée `Float64` `0.6666...`

L'avantage, c'est qu'un nombre rationnel reste exact (sauf dans le cas extrême de [dépassement d'entier][integer-overflow]), ce qui évite les erreurs d'arrondi souvent inévitables avec les nombres à virgule flottante.

Tu trouveras plus de détails sur la [page du manuel][julia-rational] de Julia.

Les nombres rationnels sont un type numérique assez simple, et ils se comportent globalement comme on peut s'y attendre.
Comme ils font partie des types standards de Julia depuis les premières versions, la plupart des fonctions les acceptent en entrée de la même façon que les entiers et les nombres à virgule flottante.

## Crée des nombres rationnels

La création est aussi simple que d'écrire `//` entre deux entiers.

```julia-repl
julia> 3//4
3//4

julia> a = 3; b = 4;

julia> a//b
3//4
```

Les facteurs communs sont automatiquement supprimés, ce qui réduit la fraction à sa [« forme irréductible »][lowest-terms] : les plus petits entiers qui représentent exactement la fraction, avec un dénominateur positif ou nul.

```julia-repl
julia> 5//15
1//3

julia> 5//-15
-1//3
```

Les résultats infinis sont acceptés, mais pas [`NaN`][NaN].

```julia-repl
julia> 1//0
1//0

julia> float(1//0)
Inf

julia> 0//0
ERROR: ArgumentError: invalid rational: zero(Int64)//zero(Int64)
```

## L'arithmétique avec les nombres rationnels

Les [`arithmetic operators`][operators] habituels `+ - * / ^ %` fonctionnent avec les rationnels, essentiellement de la même manière qu'avec les autres types numériques.

Les entiers et d'autres `Rational`s peuvent être inclus, et donnent un résultat de type `Rational`.
Si l'on inclut un `float` dans l'expression, le résultat est de type `float`, avec une perte de précision (possible) en conséquence.

Si tu veux un `float`, il suffit d'utiliser la fonction `float()` pour convertir un rationnel.
Il est tout à fait normal d'utiliser des nombres rationnels pour préserver la précision tout au long d'un long calcul, puis de convertir en nombre à virgule flottante à la fin.

```julia-repl
julia> 3//4 + 1//3  # addition
13//12

julia> 3//4 * 1//3  # multiplication
1//4

julia> 3//4 / 1//3  # division
9//4

julia> 3//4 ^ 2  # exponentiation
3//16

julia> 3//4 + 5  # rational and int => rational
23//4

julia> 3//4 + 5.3  # rational and float => float
6.05

julia> float(3//4)  # casting
0.75
```

Les rationnels et les [nombres complexes][complex] peuvent aussi être combinés.
Les nombres complexes sont traités dans un [concept à part][complex-concept].

## Autres opérations

En Julia, les nombres rationnels sont de simples nombres.
Le compilateur convertit généralement les types si nécessaire.

Fais cependant attention, car les comparaisons ne fonctionnent que pour les fractions dont la représentation décimale est finie :

```julia-repl
julia> 3//4 == 0.75
true

julia> 3//4 < 0.74
false
```

Mais dans tous les autres cas, il faut convertir un `Rational` en `Float` pour pouvoir comparer :

```julia-repl
julia> 1//3 == 1/3
false

julia> float(1//3) == 1/3
true
```

Les fonctions mathématiques acceptent des rationnels en entrée, mais peuvent renvoyer un résultat à virgule flottante :

```julia-repl
julia> sqrt(9//16)
0.75
```
