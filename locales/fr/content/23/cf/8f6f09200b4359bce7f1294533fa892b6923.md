# Tests

Il y a une configuration à faire une seule fois pour chaque exercice, ce qui peut prendre quelques minutes :

```
npm install
```

Ouvre deux terminaux, puis dans le premier, lance le processus de compilation.

```
npm start
```

Dans le second, démarre l'exécution des tests.

```
npm test
```

Au fur et à mesure que tu modifies le code, les deux processus vont reconstruire et relancer les tests en continu.
