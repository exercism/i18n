# À propos des listes

Les **listes** sont, en Java, des collections ordonnées, c'est-à-dire des séquences.
Contrairement aux tableaux, une [`List`](https://docs.oracle.com/en/java/javase/11/docs/api/java.base/java/util/List.html) peut grandir pour accueillir autant d'éléments que nécessaire.
L'une des implémentations standard est `ArrayList`, qui s'appuie sur un tableau redimensionnable.
Une autre implémentation standard est la classe `LinkedList`, qui s'appuie sur une liste doublement chaînée.

Les `List` peuvent être vides ou contenir un nombre quelconque d'éléments (doublons compris).
Une `List` est une **interface générique**, typée pour indiquer le type d'objets qu'elle peut contenir.
Par exemple :

```java
List<String> emptyListOfStrings = List.of();
List<Integer> singleInteger = List.of(1);
List<Boolean> threeBooleans = List.of(true, false, true);
List<Object> listWithMultipleTypes = List.of("hello", 1, true);
```

Les `List` disposent de diverses méthodes pratiques pour ajouter, supprimer ou récupérer un élément, et pour vérifier qu'un élément est présent :

```java
List<Character> vowels = new ArrayList<>(List.of('a', 'e', 'i', 'o', 'i', 'e', 'a'));
int startingSize = vowels.size(); // 7
vowels.add('u'); // vowels is now ['a', 'e', 'i', 'o', 'i', 'e', 'a', 'u']
char a = vowels.get(0); // 'a'
boolean hadI = vowels.remove('i'); // true and vowels is now ['a', 'e', 'o', 'i', 'e', 'a', 'u']
boolean hasI = vowels.contains('i'); // true (still have one more left)
```

La classe [`Collections`](https://docs.oracle.com/en/java/javase/11/docs/api/java.base/java/util/Collections.html) propose aussi des utilitaires pratiques pour manipuler des collections comme `List` :

```java
List<Integer> numbers = new ArrayList<>(List.of(1, 5, 3, 2, 4));
Collections.sort(numbers); // [1, 2, 3, 4, 5]
Collections.reverse(numbers); // [5, 4, 3, 2, 1]
Collections.fill(numbers, 42); // [42, 42, 42, 42, 42]
List<Integer> fiveNines = Collections.nCopies(5, 9); // [9, 9, 9, 9, 9]
```
