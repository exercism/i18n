# Introduction

[Les tableaux][arrays-concept] disposent de méthodes intégrées pour analyser le contenu d'un tableau.
La plupart de ces méthodes prennent en argument une fonction qui renvoie vrai ou faux.
Une telle fonction s'appelle un [`predicate`][predicate_in_programming].

Ces méthodes intégrées sont faites pour être utilisées _à la place d'une boucle `for`_ ou de la méthode `forEach` intégrée :

Exemple d'analyse avec une boucle `for` :

```javascript
const numbers = [1, 'two', 3, 'four'];
for (var i = 0; i < numbers.length; i++) {
  if (numbers[i] === 'two') {
    return i;
  }
}
// => 1
```

Exemple d'analyse avec une méthode intégrée :

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.indexOf('two');
// => 1
```

Voici d'autres méthodes intégrées bien utiles pour analyser un tableau. Consulte [MDN][mdn-array-methods] pour obtenir la liste complète des méthodes de tableau.

## `includes`

> La méthode includes() détermine si un tableau contient une certaine valeur parmi ses éléments, et renvoie vrai ou faux selon le cas. [^1]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.includes(1);
// => true
numbers.includes('one');
// => false
```

## `every`

> La méthode every() teste si tous les éléments du tableau réussissent le test implémenté par la fonction fournie. Elle renvoie une valeur booléenne. [^2]

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.every((num) => num % 2 !== 0);
// => true
```

## `some`

> La méthode some() teste si au moins un élément du tableau réussit le test implémenté par la fonction fournie. [^3]

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.some((num) => num % 2 !== 0);
// => true
```

## `find`

> La méthode find() renvoie la valeur du premier élément du tableau fourni qui satisfait la fonction de test fournie. Si aucune valeur ne satisfait la fonction de test, undefined est renvoyé. [^4]

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.find((num) => num < 5);
// => 1
```

## `findIndex`

> La méthode findIndex() renvoie l'indice du premier élément du tableau qui satisfait la fonction de test fournie. Sinon, elle renvoie -1, ce qui indique qu'aucun élément n'a réussi le test. [^5]

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.findIndex((num) => num > 7);
// => 4
numbers.findIndex((num) => num > 9);
// => -1
```
