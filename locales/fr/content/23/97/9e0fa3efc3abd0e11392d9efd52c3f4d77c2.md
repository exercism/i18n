# Instructions

Elyse est une magicienne en herbe et elle a besoin d'analyser son jeu de cartes de bien des façons.
Pour que les choses restent simples, elle n'utilise que des cartes dont les valeurs vont de 1 à 10.

## 1. Détermine combien de cartes d'un certain type se trouvent dans le jeu

Elyse veut savoir combien de cartes d'un type particulier elle a dans son jeu.

Écris une fonction `cardTypeCheck` qui prend deux paramètres : un tableau de cartes (le jeu d'Elyse) et le type de carte à compter.

<!--prettier-ignore -->
~~~exercism/note
La fonction doit utiliser `forEach` et renvoyer le nombre de cartes du type indiqué dans le jeu.
~~~

```javascript
const cardType = 3;
cardTypeCheck([1, 2, 3, 4], cardType);
// => 1
```

## 2. Détermine combien de cartes impaires ou paires il y a

Pour un autre tour, Elyse a besoin de savoir combien de cartes impaires ou paires se trouvent dans son jeu.

Implémente une fonction `determineOddEvenCards` qui prend deux paramètres : un tableau de cartes (le jeu d'Elyse) et un booléen (`true` correspond à « pair » et `false` à « impair »).

Cette fonction doit renvoyer un seul nombre : le nombre de cartes impaires ou paires présentes dans le jeu (selon la valeur du second argument).

<!--prettier-ignore -->
~~~exercism/note
Pour t'entraîner, utilise cette fois une boucle `for...of` dans l'implémentation de la fonction.
~~~

```javascript
determineOddEvenCards([1, 2, 3, 1, 5, 6], true);
// => 2

determineOddEvenCards([1, 2, 3, 1, 5, 6], false);
// => 4
```
