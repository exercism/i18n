# Introduction

Les [tuples][tuples] permettent de regrouper plusieurs valeurs en une seule valeur composée.
Contrairement aux tableaux, les valeurs d'un tuple n'ont pas besoin d'être du même type, et la taille d'un tuple est fixe une fois qu'il est créé.

Pour créer un tuple, on place les valeurs entre parenthèses, séparées par des virgules :

```swift
let order = ("biscuits", 2.99, 3)
```

On peut aussi préciser explicitement les annotations de type :

```swift
let order: (String, Double, Int) = ("biscuits", 2.99, 3)
```

Pour extraire les éléments individuels d'un tuple non nommé, on utilise la syntaxe d'indice commençant à 0 (`.0`, `.1`, etc.) :

```swift
let item = order.0     // "biscuits"
let quantity = order.2 // 3
```

## Tuples nommés

On peut donner un nom à chacun des éléments d'un tuple au moment de le définir :

```swift
let order = (item: "biscuits", price: 2.99, quantity: 3)
```

Nommer les éléments rend le code plus lisible et permet d'accéder aux éléments par leur étiquette, avec la notation pointée :

```swift
let item = order.item         // "biscuits"
let quantity = order.quantity // 3
```

On peut aussi inclure les noms des éléments dans l'annotation de type :

```swift
let order: (item: String, price: Double, quantity: Int) = (item: "biscuits", price: 2.99, quantity: 3)
```

## Modifie un tuple

Si un tuple est déclaré comme variable (`var`), on peut mettre à jour ses éléments :

```swift
var order = ("biscuits", 2.99, 3)
order.0 = "cookies"
order.1 = 1.99
order.2 = 5

print(order)
// Prints ("cookies", 1.99, 5)
```

## Plusieurs valeurs de retour

Bien que les fonctions Swift ne puissent renvoyer qu'une seule valeur, renvoyer un tuple permet de regrouper plusieurs valeurs et d'en [renvoyer plusieurs depuis une fonction][multiple-return-values] :

```swift
func divide(_ dividend: Int, by divisor: Int) -> (quotient: Int, remainder: Int) {
    let quotient = dividend / divisor
    let remainder = dividend % divisor
    return (quotient, remainder)
}

let result = divide(14, by: 4)
print("Quotient: \(result.quotient), Remainder: \(result.remainder)")
// Prints "Quotient: 3, Remainder: 2"
```

## Décomposition d'un tuple

On peut décomposer (extraire) les valeurs d'un tuple en constantes ou variables distinctes :

```swift
let order = ("biscuits", 2.99, 3)
let (item, price, quantity) = order

print(item) // Prints "biscuits"
```

La décomposition de tuple fonctionne aussi directement dans les boucles `for-in` :

```swift
let orders = [("biscuits", 2.99, 3), ("cookies", 1.99, 5)]

for (item, price, quantity) in orders {
    print("Item: \(item), Price: \(price), Quantity: \(quantity)")
}
```
