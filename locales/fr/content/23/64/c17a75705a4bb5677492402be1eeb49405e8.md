# À propos

`jq` est un outil pour analyser et transformer des données JSON.
`jq` est à JSON ce que `sed` est au texte : tu peux t'en servir pour découper, filtrer, projeter et transformer des données structurées avec la même facilité que `sed`, `awk`, `grep` et compagnie te permettent de jouer avec du texte.

`jq` est un langage de programmation fonctionnel à typage dynamique.
Toutes les valeurs sont immuables.

Les programmes `jq` sont composés de _pipelines_ de « filtres » : chaque filtre prend un élément en entrée, agit dessus et produit zéro ou plusieurs éléments transformés.
Un « filtre » peut aussi s'appeler une « expression ».

La ou les sorties d'une expression peuvent être transmises à une autre grâce à l'opérateur `|`.
`expressionA | expressionB` applique `expressionA` à une entrée, puis `expressionB` s'exécute de façon répétée pour chacune des sorties de `expressionA`.

On peut désigner explicitement l'entrée d'une expression par `.`.
Une expression qui ajoute `1` à son entrée s'écrit comme ceci : `. + 1` (ou `1 + .`).

## `jq` (le programme) face à `jq` (le langage)

`jq` est un programme que tu peux installer comme paquet sur divers systèmes d'exploitation, ou compiler depuis les sources (il est codé en C).
Il dispose de plusieurs [options en ligne de commande][cli-options] bien utiles, et il est plutôt rapide.

Le programme `jq` implémente aussi un _langage_ qui permet de manipuler les données d'entrée de façon arbitrairement complexe.

Ce parcours Exercism se concentrera sur le langage.
Tu verras des exemples d'utilisation du programme `jq` dans les tests.

## Versions

## JSON

D'après [json.org][json] :

> JSON (JavaScript Object Notation) est un format léger d'échange de données.
> Il est facile à lire et à écrire pour les humains.
> Il est facile à analyser et à générer pour les machines.
> Il repose sur un sous-ensemble du standard ECMA-262, 3e édition de décembre 1999, du langage de programmation JavaScript.
> JSON est un format texte totalement indépendant du langage, mais qui utilise des conventions familières aux programmeurs de la famille des langages C, notamment C, C++, C#, Java, JavaScript, Perl, Python et bien d'autres.
> Ces propriétés font de JSON un langage d'échange de données idéal.

Ce parcours porte sur `jq`, pas sur JSON.
On part du principe que tu connais [la syntaxe et les types de données JSON][wiki-json].
