# À propos

Un [`Attribute` C#][attribute-concept] permet de décorer une déclaration afin d'y associer des métadonnées : une classe, une méthode, une énumération, un champ, une propriété ou toute autre [déclaration prise en charge][attribute-targets].

Tu peux appliquer [un attribut][attribute] à une déclaration en l'ajoutant entre crochets `[]` avant la déclaration ; l'exemple suivant utilise à la fois un `ClassAttribute` et un `FieldAttribute` :

```csharp
[Class]
public class MyClass
{
    [Field] public int myField;
}
```

Les métadonnées déclaratives ne font qu'associer des informations structurées supplémentaires au code et ne modifient pas son comportement, mais elles sont utilisées par d'autres parties du code pour changer le comportement de leur cible, ou pour ajouter, modifier, supprimer ou restreindre certaines de ses fonctionnalités.

Il existe plusieurs attributs prédéfinis, comme `Flags`, `Obsolete` ou `Conditional`. Note que le nom complet de l'[attribut `Flags`][flags-attribute] est `FlagsAttribute`, mais que le suffixe « Attribute » peut être omis lors de son utilisation.

Les quatre attributs prédéfinis suivants sont couramment utilisés :

- `[Flags]` : prédéfini dans l'espace de noms System. Indique que l'énumération prend en charge à la fois les opérations bit à bit et la méthode `Enum.HasFlag()` ; de plus, `ToString` affiche tous les indicateurs : [voir l'exemple][flags-example].
- `[Obsolete]` : prédéfini dans l'espace de noms System. Permet d'ajouter un message expliquant pourquoi le code est obsolète ; il peut servir à afficher des avertissements ou des erreurs du compilateur.
- `[Conditional]` : prédéfini dans l'espace de noms System.Diagnostics. Permet de supprimer certains appels de méthode à la compilation à des fins de débogage (diagnostic).
- `[CallerMemberName]` : prédéfini dans l'espace de noms System.Runtime.CompilerServices. Permet à une méthode d'obtenir des informations sur son appelant.
