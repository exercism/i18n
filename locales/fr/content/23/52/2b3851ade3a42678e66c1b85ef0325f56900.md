# Classes et propriétés en lecture seule

Les classes et les propriétés en lecture seule permettent à une classe de définir des propriétés publiques faciles d'accès, tout en empêchant leur modification.
Pour déclarer une propriété en lecture seule, il faut ajouter `readonly` devant la spécification du type.
La propriété peut être affectée une seule fois, mais toute tentative de réaffectation ou de modification de sa valeur lèvera une Error.

```php
<?php

class Block
{
    public function __construct(
        public readonly int $length;
        public readonly int $width;
    ) {
    }
}
```

Les classes en lecture seule s'appuient sur ce comportement et, lorsqu'elles sont déclarées `readonly`, appliquent la lecture seule à chacune de leurs propriétés.
De plus, elles empêchent l'ajout de propriétés dynamiques.

```php
<?php

readonly class Block
{
    public function __construct(
        public int $length;
        public int $width;
    ) {
    }
}
```
