# Introduction

En Common Lisp, une fonction peut non seulement renvoyer une valeur, mais aussi en renvoyer plusieurs.
Par exemple, `floor`, qui arrondit vers zéro, renvoie deux valeurs : la première est la valeur arrondie et la seconde est le reste.

```lisp
(floor 3.5) ; => 3
            ;    0.5
```
(Nous afficherons les valeurs multiples renvoyées sur des lignes séparées de la sortie.)

## Renvoie plusieurs valeurs

Si tu veux qu'une fonction renvoie plusieurs valeurs, tu utilises l'accesseur `values` :

```lisp
(defun three-numbers () (values 1 2 3))
(three-numbers) ; => 1
                ;    2
                ;    3
```

## Gère plusieurs valeurs

Si seule la première valeur t'intéresse, rien de particulier à faire : le langage s'en charge.

```lisp
(+ (values 1 2 3) (values 10 20 30)) ; => 11
```

En revanche, si tu veux accéder à ces autres valeurs, tu devras utiliser plusieurs fonctions.
Les deux principales macros sont `multiple-value-list` et `multiple-value-bind`.
Elles servent à envelopper quelque chose qui renvoie plusieurs valeurs et à capturer toutes ces valeurs.
La première crée un tableau contenant toutes les valeurs.
La seconde te permet de lier des variables à chacune des valeurs.

```lisp
(multiple-value-list (values 1 2 3))                   ; => (1 2 3)
(multiple-value-bind (a b c) (values 1 2 3) 
   (+ a b c)) ; => 6
```
