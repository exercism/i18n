# Introduction

## Récursivité

La capacité d'une chose à être définie à partir d'elle-même s'appelle la récursivité. En Gleam, la récursivité se rencontre le plus souvent dans les fonctions récursives, c'est-à-dire des fonctions qui s'appellent elles-mêmes.

Une fonction récursive doit avoir au moins un _cas de base_ et au moins un _cas récursif_. Un _cas de base_ renvoie une valeur sans appeler la fonction à nouveau. Un _cas récursif_ appelle la fonction à nouveau, en modifiant l'entrée pour qu'elle finisse par correspondre au cas de base.

```gleam
pub fn factorial(x: Int) -> Int {
  case x {
    // Base case
    1 -> 1

    // Recursive case
    _ -> x * factorial(x - 1)
  }
}
```

Gleam n'a pas de syntaxe particulière pour les boucles ; toutes les boucles se font donc avec la récursivité.

```gleam
pub fn list_length(list: List(String)) -> Int {
  case list {
    [] -> 0
    [_, ..rest] -> 1 + list_length(rest)
  }
}
```

Gleam prend aussi en charge les types personnalisés récursifs. Dans un type personnalisé récursif, une ou plusieurs variantes se réfèrent au type lui-même dans les données qu'elles contiennent.

```gleam
pub type RussianDoll {
  Child               // Base case
  Mother(RussianDoll) // Recursive case
}
```
```gleam
let very_big_doll = Mother(Mother(Mother(Child)))
let small_doll = Mother(Child)
```
