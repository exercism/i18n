# Tests

Chaque exercice contient un fichier de tests.
Exécute les tests à l'aide du programme `bats`.

```bash
bats test-hello-world.bats
```

Il faudra installer `bats`.
Consulte la page [Tester sur le parcours Bash][bash] pour savoir comment installer `bats` sur ton système.

### bats est implémenté en bash

Le fichier bats est un script bash, avec quelques fonctions spéciales reconnues par la commande `bats`.
Tu verras des tests qui ressemblent à ceci :

```sh
jq -f some-exercise.jq <<< "{some,json,here}"
```

Cette syntaxe `<<<` est ce que bash appelle une [Here String][here-string].
Elle envoie la _string_ située à droite dans l'entrée standard du programme situé à gauche.
C'est ([à peu près][so]) la même chose que

```sh
echo "{some,json,here}" | jq -f some-exercise.jq
```

## Aide pour les fonctions d'assertion

Les tests utilisent des fonctions de la bibliothèque [bats-assert][bats-assert].
Tu y trouveras de l'aide pour les différentes fonctions `assert*`.

## Tests ignorés

Résoudre un exercice, c'est faire passer tous ses tests.
Par défaut, un seul test (le premier) est exécuté quand tu lances les tests.
C'est voulu : cela te permet de te concentrer sur ce seul test à faire passer.
Une fois qu'il passe, tu peux activer le test suivant en commentant ou en supprimant les

    [[ $BATS_RUN_SKIPPED == true ]] || skip

annotations qui précèdent les autres tests.

## Forcer l'exécution des tests ignorés

Pour exécuter tous les tests, y compris ceux qui portent une annotation `skip`, tu peux lancer :

```bash
BATS_RUN_SKIPPED=true bats test-some-exercise.bats
```

Il peut être pratique d'utiliser une fonction d'enveloppe pour taper moins : en `bash`, tu peux faire :

```bash
bats() {
    BATS_RUN_SKIPPED=true command bats *.bats
}
```

Il suffit ensuite de lancer les tests avec :

```bash
bats
```

## Débogue en `jq`

`jq` fournit un filtre [`debug`][debug] bien pratique.
Utilise-le pendant que tu développes tes solutions d'exercices pour inspecter les données qui se trouvent actuellement dans le pipeline de jq.
Consulte le [document sur le débogage][debugging] pour plus de détails.
