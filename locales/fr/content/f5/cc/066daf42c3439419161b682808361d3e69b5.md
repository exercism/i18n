# Écris le code

Écris ton code dans `<exercise_name>.zig`.
Certains exercices viennent avec des signatures déjà écrites pour des constructions Zig particulières, comme les [constantes][constants], les [fonctions][functions], les [_imports_][imports], les [structures][structs], et [potentiellement bien d'autres][et-cetera] !

Ces signatures déjà écrites sont là pour t'aider à venir à bout des exercices en te fournissant un point de départ clair.
Cependant, partir de ces signatures n'est pas indispensable.
D'autant que n'importe quel code qui passe les tests constitue une solution parfaitement acceptable.

## Lance les tests

Pour lancer les tests, il te suffit d'exécuter la commande suivante :

```bash
zig test test_exercise_name.zig
```

en remplaçant `exercise_name` par le nom de l'exercice.
La commande ci-dessus doit être lancée depuis le répertoire racine de l'exercice, car son fichier de test doit se trouver au même endroit.
De plus, tous les tests d'un exercice donné sont activés par défaut, et aucun test ne peut être ignoré.

Comme tous les tests obéissent à ces règles, il te faudra [mettre en commentaire][comments] les tests qui ne passent pas si tu veux avancer test par test.
Pour mettre un test en commentaire, il suffit de faire commencer chaque ligne par `//`.
Sinon, quand tu es sûr que ta solution peut passer les tests, tu peux décommenter ces tests pour voir si elle passe.
