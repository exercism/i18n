# Instructions

Ajoute le nombre de mines à un plateau de Démineur complété.

Le Démineur est un jeu populaire dans lequel il faut trouver les mines en s'aidant d'indices numériques qui indiquent combien de mines sont directement adjacentes (horizontalement, verticalement ou en diagonale) à une case.

Dans cet exercice, tu dois écrire du code qui compte le nombre de mines adjacentes à une case vide donnée et qui remplace cette case par ce nombre.

Le plateau est un rectangle composé de caractères d'espace (`' '`).
Une mine est représentée par un astérisque (`*`).

Si une case n'a aucune mine adjacente, laisse cette case vide.

## Examples

Par exemple, tu peux recevoir un plateau de 5 x 4 comme celui-ci (les espaces vides sont ici représentés par le caractère '·' pour l'affichage à l'écran) :

```text
·*·*·
··*··
··*··
·····
```

Et ton code le transformera en ceci :

```text
1*3*1
13*31
·2*2·
·111·
```
