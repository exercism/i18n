# Instructions

Dans cet exercice, tu vas écrire un programme qui détermine l'état d'une partie de [morpion][tic-tac-toe].
(_Tu connais peut-être aussi ce jeu sous le nom de « tic-tac-toe »._)

Le jeu se joue sur une grille 3×3.
Les joueurs placent à tour de rôle des `X` et des `O` sur la grille.
La partie se termine quand un joueur a gagné en alignant trois de ses marques sur une ligne, une colonne ou une diagonale de la grille, ou quand toute la grille est remplie.

Dans cet exercice, on suppose que c'est `X` qui commence.

C'est à toi de déterminer dans quel état se trouve une partie donnée.

Il y a 3 états possibles :

- La partie est **ongoing**.
- La partie s'est terminée par un **draw**.
- La partie s'est terminée par un **win**.

Si le plateau donné est invalide, lève une erreur appropriée.

Un plateau est invalide s'il remplit les conditions suivantes :

- Le plateau donné ne peut pas être obtenu en jouant les tours dans le bon ordre (rappelle-toi que c'est `X` qui commence).
- Des coups ont été joués alors que la partie était déjà terminée.

## Exemples

### Partie en cours

```text
   |   |
 X |   |
___|___|___
   |   |
   | X | O
___|___|___
   |   |
 O | X |
   |   |
```

### Match nul

```text
   |   |
 X | O | X
___|___|___
   |   |
 X | X | O
___|___|___
   |   |
 O | X | O
   |   |
```

### Victoire

```text
   |   |
 X | X | X
___|___|___
   |   |
   | O | O
___|___|___
   |   |
   |   |
   |   |
```

### Invalide

#### Ordre des tours incorrect

```text
   |   |
 O | O | X
___|___|___
   |   |
   |   |
___|___|___
   |   |
   |   |
   |   |
```

#### Partie poursuivie après une victoire

```text
   |   |
 X | X | X
___|___|___
   |   |
 O | O | O
___|___|___
   |   |
   |   |
   |   |
```
