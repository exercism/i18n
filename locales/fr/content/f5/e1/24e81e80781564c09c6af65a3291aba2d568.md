# Instructions

Apprends à combiner les données de deux tables internes différentes en une seule table interne de résultat.

Ta classe recevra deux tables internes qui contiennent deux jeux de données complètement différents, ALPHAS et NUMS.

```abap
TYPES: BEGIN OF alphatab_type,
         cola TYPE string,
         colb TYPE string,
         colc TYPE string,
       END OF alphatab_type.
TYPES: alphas TYPE STANDARD TABLE OF alphatab_type.
TYPES: BEGIN OF numtab_type,
         col1 TYPE string,
         col2 TYPE string,
         col3 TYPE string,
       END OF numtab_type.
TYPES: nums TYPE STANDARD TABLE OF numtab_type.
```

Les données de la table ALPHAS sont présentées ci-dessous.

| COLA | COLB | COLC |
| --- | --- | --- |
| A | B | C | 
| D | E | F |
| G | H | I |

Les données de la table NUMS sont présentées ci-dessous.

| COL1 | COL2 | COL3 |
| --- | --- | --- |
| 1 | 2 | 3 | 
| 4 | 5 | 6 |
| 7 | 8 | 9 |

Ta tâche consiste à renvoyer une table interne dont les enregistrements combinent les valeurs de chaque cellule de la table interne ALPHAS avec celles de la table interne NUMS. Par exemple, la valeur de la première colonne de la première ligne de la table interne COMBINED_DATA doit être « A1 ».

La table de retour attendue est définie comme suit :

```abap
TYPES: BEGIN OF combined_data_type,
         colx TYPE string,
         coly TYPE string,
         colz TYPE string,
       END OF combined_data_type.
TYPES: combined_data TYPE STANDARD TABLE OF combined_data_type WITH EMPTY KEY.
```
