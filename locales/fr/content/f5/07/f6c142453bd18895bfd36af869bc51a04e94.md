# À propos

Un *tas* est une collection qui connaît toujours son plus petit (ou son plus grand) élément et qui permet de le retirer rapidement. C'est l'implémentation naturelle d'une *file de priorité*. Les tas se trouvent dans le vocabulaire [`heaps`][heaps].

`<min-heap>` construit un tas vide dont la plus petite clé sort en premier ; `<max-heap>` fait sortir la plus grande en premier. Chaque élément est une *valeur* stockée sous une *clé*, et la clé est la priorité selon laquelle Factor ordonne :

```
<min-heap> ( -- min-heap )
<max-heap> ( -- max-heap )
heap-push  ( value key heap -- )
heap-push-all ( assoc heap -- )
```

```factor
USING: heaps ;

<min-heap>
"alice" 5 pick heap-push
"bob"   2 pick heap-push
```

Un tas est *mutable* : `heap-push` et `heap-pop` le modifient sur place.

```
heap-peek    ( heap -- value key )
heap-pop     ( heap -- value key )
heap-pop-all ( heap -- alist )
heap-empty?  ( heap -- ? )
heap-size    ( heap -- n )
```

`heap-peek` lit l'élément de tête sans le retirer ; `heap-pop` le retire et le renvoie ; `heap-pop-all` vide le tas dans une liste d'associations de paires `{ key value }`, par ordre de priorité.

```factor
USING: assocs heaps kernel prettyprint ;

<min-heap>
"alice" 5 pick heap-push
"bob"   2 pick heap-push
"carol" 9 pick heap-push
dup heap-pop .           ! => 2 "bob"   (removed; value then key)
heap-pop-all values .    ! => { "alice" "carol" }
```

L'ajout est en `O(log n)` et la lecture de l'élément de tête est en `O(1)`, donc répéter « prendre l'élément le plus urgent, puis en ajouter d'autres » reste rapide, même pour une grande file. L'implémentation est un tas binaire stocké dans un tableau redimensionnable ; la clé peut être n'importe quelle valeur ordonnable (nombres, _strings_, …).

[heaps]: https://docs.factorcode.org/content/vocab-heaps.html
