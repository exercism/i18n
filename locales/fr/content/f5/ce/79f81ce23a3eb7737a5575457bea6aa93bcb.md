# Introduction

Le type `char` de C# est une quantité de 16 bits qui représente les plus petites composantes adressables d'un texte. Plusieurs `char` peuvent former une _string_ comme `"word"`, ou bien les `char` peuvent être traités indépendamment. Leurs littéraux s'écrivent entre guillemets simples, par exemple `'A'`.

Les `char` de C# prennent en charge l'encodage Unicode UTF-16, donc en plus du jeu de caractères latins, on peut représenter pratiquement tous les systèmes d'écriture utilisés dans le monde, par exemple la lettre grecque `'β'`.

Il existe de nombreuses méthodes intégrées de la bibliothèque standard pour inspecter et manipuler les `char`. On les trouve sous forme de méthodes statiques de la classe `System.Char`.
