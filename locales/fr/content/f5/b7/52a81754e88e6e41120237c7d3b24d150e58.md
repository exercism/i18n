# Instructions

Calcule le nombre de grains de blé sur un échiquier.

Un échiquier comporte 64 cases.
La case 1 contient un grain, la case 2 en contient deux, la case 3 en contient quatre, et ainsi de suite, en doublant à chaque fois.

Écris du code qui calcule :

- le nombre de grains sur une case donnée
- le nombre total de grains sur l'échiquier
