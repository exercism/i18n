- Souviens-toi qu'il faut modifier le jeu de données `trees`, qui est disponible si on appelle `library(datasets)`.

- Regarde l'Introduction pour savoir comment changer le nom d'une colonne.

## 2. Ajoute les colonnes girth et weight

- Regarde l'Introduction pour savoir comment ajouter des colonnes.
- Les nouvelles colonnes peuvent être calculées à partir des colonnes existantes.
- N'oublie pas d'arrondir à la précision demandée.

## 3. Copie Orchard du jeu de données

- Il faut déplacer des colonnes et trier les lignes (voir l'Introduction).

## 4. Copie client du jeu de données

- Tu devras extraire un sous-ensemble de colonnes.
