# Indices

## Généralités

- `accessors` fournit les _getters_ `slot>>` générés automatiquement, les _setters_ `>>slot` et les _updaters_ `change-slot`.
- Les _setters_ et `change-slot` *modifient le tuple sur place*. Fais d'abord un `clone` si tu veux une mise à jour non destructive.

## 1. Définis le tuple `player`

- La syntaxe des _slots_ est `{ name initial: value }` à l'intérieur de `TUPLE: …  ;`.
- Les _slots_ sans clause `initial:` valent `f` par défaut.

## 2. Présente le joueur

- `name>>` lit le _slot_ `name`.
- `unless*`, de [`kernel`][kernel], est l'idiome « valeur par défaut si `f` ».

## 3. Ranime un joueur tombé

- `health>>` lit le _slot_ ; `zero?`, de [`math`][math], teste si la valeur vaut zéro.
- Construis le nouveau joueur avec `clone`, suivi de `100 >>health` et `100 >>mana`.
- Dans le cas « toujours en vie », renvoie `f`.

## 4. Subis des dégâts

- `change-health` accepte une _quotation_ `( old-health -- new-health )`.
- Une _quotation_ fry `'[ _ - 0 max ]` (avec `max` de [`math.order`][math.order]) te donne « soustraire les dégâts capturés et borner le résultat à zéro ».
- N'oublie pas de faire un `clone` avant de modifier le tuple.

[math]: https://docs.factorcode.org/content/vocab-math.html
