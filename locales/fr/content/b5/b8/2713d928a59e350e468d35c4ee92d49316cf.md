# Instructions

Prends un tableau imbriqué, quelle que soit sa profondeur, et renvoie un tableau entièrement aplati.

Note que certains parcours peuvent inclure des valeurs de type _null_ dans le tableau d'entrée, et que la façon dont ces valeurs sont représentées varie d'un parcours à l'autre.
Ces valeurs doivent être exclues du tableau aplati.

De plus, selon le parcours, l'entrée peut être d'un autre type et contenir des types différents.

Consulte la suite de tests pour plus de détails.

## Exemple

entrée : `[1, [2, 6, null], [[null, [4]], 5]]`

sortie : `[1, 2, 6, 4, 5]`
