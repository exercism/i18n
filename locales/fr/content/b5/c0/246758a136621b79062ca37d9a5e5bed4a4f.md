# Introduction

En Common Lisp, la liste des arguments d'une fonction est appelée [« liste lambda »][lambda-list].
Une liste lambda peut contenir des arguments de différents types.
Ces différents types sont désignés par des [« mots-clés de liste lambda »][lambda-list-keyword], qui commencent tous par `&`.
Les types les plus courants sont les arguments optionnels, les arguments nommés et les arguments restants.
Tous les paramètres qui suivent un mot-clé de liste lambda donné sont de ce type.
Un mot-clé de liste lambda ne peut être utilisé qu'une seule fois dans une liste lambda.

Les listes lambda sont aussi utilisées dans d'autres constructions dont on parlera plus tard, comme la déstructuration et les macros.
