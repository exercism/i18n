# Instructions

Ta tâche consiste à prendre une liste de buteurs d'un match et à compter combien de buts chaque joueur a marqués.

`PlayerName` est un alias de type pour `String`, pour rendre le code plus facile à lire et pour distinguer cet usage de `String` d'autres usages de `String`.

## 1. Agrège les buteurs

Implémente d'abord `updateGoalCountForPlayer` pour initialiser ou incrémenter le nombre de buts d'un joueur.
Implémente ensuite la fonction `aggregateScorers` pour compter combien de buts chaque joueur a marqués, en utilisant `updateGoalCountForPlayer`.
Cette fonction prend une `List PlayerName` (les noms des joueurs qui ont marqué les buts, qui peut contenir des noms de joueurs en double), et renvoie un `Dict PlayerName Int` contenant tous les joueurs de la liste ainsi que le nombre de buts qu'ils ont marqués.

```elm
aggregateScorers [ "Betty", "Cedd", "Betty" ]
--> Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ]
```

## 2. Supprime les joueurs non significatifs

Implémente la fonction `removeInsignificantPlayers`, pour filtrer les joueurs qui ont marqué moins de buts que le seuil.

```elm
removeInsignificantPlayers 2 (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
--> Dict.fromList [ ( "Betty", 2 ) ]
```

## 3. Réinitialise le nombre de buts d'un joueur

Implémente la fonction `resetPlayerGoalCount` pour remettre à zéro le nombre de buts marqués par un joueur.

```elm
resetPlayerGoalCount "Cedd" (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
--> Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 0 ) ]
```

## 4. Formate le nombre de buts pour un seul joueur

Implémente la fonction `formatPlayer` pour formater le nombre de buts d'un joueur sous forme de _string_. Si le joueur n'existe pas dans le dictionnaire, considère que son nombre de buts est zéro.

```elm
formatPlayer "Betty" (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
--> "Betty: 2"
```

## 5. Formate le nombre de buts pour tous les joueurs

Implémente la fonction `formatPlayers` pour formater le nombre de buts de tous les joueurs sous forme de _string_. Les joueurs doivent être triés par nom de joueur.

```elm
formatPlayers (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
--> "Betty: 2, Cedd: 1"
```

## 6. Combine les matchs

Implémente la fonction `combineGames`, en comptant le nombre total de buts marqués par chaque joueur dans les deux matchs.

```elm
combine Games
  (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
  (Dict.fromList [ ( "Betty", 2 ), ( "Mario", 3 ) ] )
--> Dict.fromList [ ( "Betty", 4 ), ( "Cedd", 1 ), ( "Mario", 3 ) ]
```
