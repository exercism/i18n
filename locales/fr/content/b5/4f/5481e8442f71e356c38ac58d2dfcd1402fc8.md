# Introduction

## Tableaux

JSON définit un **tableau** ainsi :

> Un tableau est une collection ordonnée de valeurs.
> Un tableau commence par `[` crochet ouvrant et se termine par `]` crochet fermant.
> Les valeurs sont séparées par `,` virgule.

Un tableau peut contenir zéro ou plusieurs valeurs JSON _de n'importe quel type_.
Les éléments d'un tableau n'ont pas besoin d'être tous du même type.

### Crée des tableaux

Utilise des crochets pour rassembler des éléments dans un tableau.

```jq
[1, 2, 3]
```

Les éléments d'un _stream_ peuvent être capturés dans un tableau en l'entourant de crochets.

```jq
range(5)     # => a stream of 5 numbers
[range(5)]   # => the array [0, 1, 2, 3, 4]
```

### Taille

La fonction `length` renvoie le nombre d'éléments d'un tableau.

### Indexe et découpe

L'indexation des tableaux commence à zéro.

Récupère un élément d'un tableau avec une expression entre crochets :
`.[2]` donne le troisième élément.

Les indices négatifs se comptent à rebours depuis la fin du tableau :
`.[-1]` donne le dernier élément ; `.[-2]` donne l'avant-dernier.

Un **slice** est une sous-séquence du tableau.
`.[10:15]` renvoie 5 éléments à partir de l'indice 10 ; l'indice de fin n'est _pas inclus_.

Il existe quelques fonctions pratiques :

- `first` donne le premier élément.
- `last` donne le dernier élément.
- `nth(n)` donne l'élément à l'indice `n`.

### Itère

`jq` fournit de nombreuses fonctions pour couvrir les besoins courants d'itération :

- `map(expr)` renvoie un nouveau tableau où `expr` est appliqué à chaque élément tour à tour.

  ```jq
  [1, 2, 3] | map(. * 10)    # => [10, 20, 30]

  ```

- `select(expr)` est une fonction qui applique `expr` à une _valeur unique_ ;
  si le résultat de l'expression vaut vrai, alors la valeur est renvoyée ;
  si le résultat vaut faux, _rien_ n'est renvoyé, pas `null`, vraiment rien.

  Pour l'appliquer à un tableau, combine-le avec `map`.

  ```jq
  [range(10)] | map(select(. % 2 == 0))    # => [0, 2, 4, 6, 8]
  ```

  Autrement, applique `select` à un _stream_ et rassemble les résultats.

  ```jq
  [range(10) | select(. % 2 == 0)]    # => [0, 2, 4, 6, 8]
  ```

- `any(condition)` et `all(condition)` renvoient une valeur booléenne indiquant si au moins un ou tous les éléments du tableau satisfont la condition.

  ```jq
  [1, 2, 3, 4] | any(. > 4)    # false
  [1, 2, 3, 4] | any(. >= 4)   # true

  [1, 2, 3, 4] | all(. >= 4)   # false
  [1, 2, 3, 4] | all(. <= 4)   # true
  ```
