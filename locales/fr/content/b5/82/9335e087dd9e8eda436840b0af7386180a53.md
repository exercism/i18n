# Introduction

## Objets

Un **objet** JSON est, pour reprendre la terminologie d'autres langages, un « hash », une « map » ou un « dictionnaire ».

JSON définit un _objet_ comme suit :

> Un objet est un ensemble non ordonné de paires **nom**/**valeur**.
> Un objet commence par une accolade ouvrante `{` et se termine par une accolade fermante `}`.
> Chaque _nom_ est suivi de deux-points `:` et les paires _nom/valeur_ sont séparées par une virgule `,`.

Le _nom_ **doit être une _string_**.
Un autre mot pour _nom_ est _clé_.

La _valeur_ peut être de n'importe quel type JSON.
Des _valeurs_ différentes dans un même objet peuvent être de types différents, comme dans cet exemple.

<!-- prettier-ignore -->
```json
{
  "name": "Jane",
  "age": 42,
  "pets": ["cat", "fish"],
  "address": {"street": "123 Main St", "city": "Springfield"}
}
```

<!-- prettier-ignore-end -->

Note qu'il **ne doit pas** y avoir de virgule après la _dernière_ paire clé-valeur.

### Crée des objets

Utilise des accolades pour rassembler les paires nom/valeur.
Même si les noms doivent être des _strings_, il n'est pas nécessaire de les mettre entre guillemets s'ils sont **de type identifiant** (composés de caractères alphanumériques et de tiret bas, et qui ne commencent pas par un chiffre).

```jq
{name: "Jane", age: 42}
```

Il est tout à fait valide d'utiliser des clés qui ne sont pas _de type identifiant_.
Mets-les simplement entre guillemets.

```jq
{"first name": "Jane", "last name": "Lopez", age: 42}
```

Si le nom est le résultat d'une expression, l'expression **doit** être mise entre parenthèses.

```sh
$ echo "Jane" | jq -Rc '{.: 42}'
# verbose error message ...

$ echo "Jane" | jq -Rc '{(.): 42}'
{"Jane":42}
```

### Indexation

On récupère les valeurs d'un objet avec la **notation pointée**.

```jq
{name: "Jane", age: 42} | .age    # => 42
```

Si tu ne peux pas désigner la clé comme un identifiant, utilise la **notation par crochets**.

```jq
"name" as $key | {name: "Jane", age: 42} | .$key    # => error
"name" as $key | {name: "Jane", age: 42} | .[$key]  # => "Jane"
```

### Ajoute ou modifie des paires clé-valeur

Pour ajouter une nouvelle paire clé-valeur à un tableau, ou pour mettre à jour la valeur d'une clé existante, utilise l'opérateur d'affectation `=`, avec une expression d'indice à gauche.

```jq
{name: "Jane", age: 42} | .sport = "tennis" | .age = 21
# => {
#      "name": "Jane",
#      "age": 21,
#      "sport": "tennis"
#    }
```

L'opérateur `+` _fusionne_ des objets.

```jq
{Richard: 54} + {Jane: 42}
# => {
#      "Richard": 54,
#      "Jane": 42
#    }
```

### Supprime une clé

Utilise la fonction `del` pour supprimer une clé.
Elle renvoie l'objet mis à jour.

```jq
{name: "Jane", age: 42} | del(.age)   # => {"name": "Jane"}
```

Le paramètre de `del` est une **expression d'indice** (en notation pointée ou par crochets) qui se résout en une clé de l'objet.
`jq` l'appelle une **expression de chemin**.
Il ne suffit pas de donner une simple _string_.

```jq
{name: "Jane", age: 42} | del(name)        # error: name/0 is not defined
{name: "Jane", age: 42} | del("name")      # error: Invalid path expression with result "name"
{name: "Jane", age: 42} | del(.name)       # OK
{name: "Jane", age: 42} | del(.["name"])   # OK
```

### Appartenance

- Pour tester si l'objet possède une clé, utilise la fonction `has`.

  ```jq
  {name: "Jane", age: 42} as $example
  |
    ($example | has("name")),    # => true
    ($example | has("sport"))    # => false
  ```

- Teste si une clé est dans un objet avec `in`.

  ```jq
  {name: "Jane", age: 42} as $example
  |
    ("name"  | in($example)),    # => true
    ("sport" | in($example))     # => false
  ```

### Liste toutes les clés

Utilise la fonction `keys` pour afficher la liste de toutes les clés.

```jq
{name: "Jane", age: 42} | keys   # => ["age", "name"]
```

Note que `keys` va _trier_ les clés.
Pour récupérer les clés dans l'ordre d'origine, utilise `keys_unsorted`.

Il n'existe pas de fonction équivalente pour lister toutes les _valeurs_.
Cependant, le filtre `.[]` produit les valeurs de l'objet sous forme de _flux_, et ce flux peut être capturé avec le constructeur de tableau `[...]`.

```jq
[{first: "Jane", last: "Lopez", status: "awesome!"} | .[]]
# => ["Jane", "Lopez", "awesome!"]
```

### Itération

- La fonction `map_values(filter)` applique le filtre à chaque _valeur_ de l'objet.

  ```jq
  {first: "Jane", last: "Lopez", status: "awesome!"}
  | map_values(ascii_upcase)
  # => {"first": "JANE", "last": "LOPEZ", "status": "AWESOME!"}
  ```

- Pour itérer sur un objet, il faut d'abord le convertir en un tableau d'objets clé-valeur.
  C'est ce que fait la fonction `to_entries`.

  ```jq
  {name: "Jane", age: 42} | to_entries'
  # => [
  #      {
  #        "key": "name",
  #        "value": "Jane"
  #      },
  #      {
  #        "key": "age",
  #        "value": 42
  #      }
  #    ]
  ```

  À ce stade, on peut utiliser les fonctions d'itération sur les tableaux, comme `map`.

- La fonction `from_entries` fait l'inverse : convertir un tableau d'objets clé-valeur en un objet.

  ```jq
  [
    {"key":"name", "value":"Jane"},
    {"key":"age", "value":42}
  ] | from_entries                  # =>{"name": "Jane", "age": 42}
  ```

- Pour appliquer un filtre à _chaque_ paire clé-valeur d'un objet, utilise la fonction `with_entries(filter)`.

  Par exemple, étant donné un objet qui associe un nom à un âge, on peut échanger les clés et les valeurs comme suit.

  ```jq
  {"Jane": 42, "Richard": 54}
  | with_entries({key: (.value | tostring), value: .key})
  ```

  produit

  ```json
  {
    "42": "Jane",
    "54": "Richard"
  }
  ```

  `with_entries(filter)` équivaut à

  ```jq
  to_entries | map(filter) | from_entries
  ```
