# À propos

Haxe prend en charge la réflexion sur les types et les champs à l'exécution. Pour utiliser la réflexion correctement, il faut comprendre quelles opérations sont prises en charge et lesquelles ne le sont pas. Compte tenu de la nature dynamique de la réflexion, il n'est pas toujours possible de le déterminer au moment de la compilation.

L'API de réflexion se compose de deux classes :

- `Reflect` : une API légère qui fonctionne au mieux avec les structures anonymes, avec une prise en charge limitée des classes.
- `Type` : une API plus robuste pour travailler avec les classes et les `enum`.

Les méthodes disponibles sont détaillées dans l'API de [Reflect][reflect] et de [Type][type].

Pour l'exemple suivant, on utilise la cible JavaScript :

```haxe
class Main {
  public static function main() {
    trace(Type.resolveClass("Main"));
  }
}

// This outputs
// class Test { static main() { console.log("Test.hx:3:",$hxClasses["Test"]); } }
```

[reflect]: https://api.haxe.org/Reflect.html
[type]: https://api.haxe.org/Type.html
