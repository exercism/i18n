# Tests

Pour exécuter les tests, exécute la commande suivante dans le répertoire de l'exercice :

```shell
make
```

## Tests ignorés

Résoudre un exercice, c'est faire passer tous ses tests.
Par défaut, un seul test (le premier) est exécuté quand on lance les tests.
C'est intentionnel : cela te permet de te concentrer uniquement sur la réussite de ce seul test.
Une fois qu'il passe, tu peux activer le test suivant en supprimant la ligne `TEST_IGNORE();`.
Quand tous les tests ont été activés et que ton implémentation les fait tous passer, tu auras résolu l'exercice !
