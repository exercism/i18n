# Instructions

Implémente les opérations de base sur les listes.

Dans les langages fonctionnels, les opérations sur les listes comme `length`, `map` et `reduce` sont très courantes. Implémente une série d'opérations de base sur les listes, sans utiliser les fonctions existantes.

Le nombre et les noms précis des opérations à implémenter dépendent du parcours, afin d'éviter les conflits avec des noms existants, mais les opérations générales que tu vas implémenter sont les suivantes :

* `append` (*étant donné deux listes, ajouter tous les éléments de la deuxième liste à la fin de la première*) ;
* `concatenate` (*étant donné une série de listes, combiner tous les éléments de toutes les listes en une seule liste aplatie*) ;
* `filter` (*étant donné un prédicat et une liste, renvoyer la liste de tous les éléments pour lesquels `predicate(item)` vaut vrai*) ;
* `length` (*étant donné une liste, renvoyer le nombre total d'éléments qu'elle contient*) ;
* `map` (*étant donné une fonction et une liste, renvoyer la liste des résultats de l'application de `function(item)` à tous les éléments*) ;
* `foldl` (*étant donné une fonction, une liste et un accumulateur initial, plier (réduire) chaque élément dans l'accumulateur en partant de la gauche avec `function(accumulator, item)`*) ;
* `foldr` (*étant donné une fonction, une liste et un accumulateur initial, plier (réduire) chaque élément dans l'accumulateur en partant de la droite avec `function(item, accumulator)`*) ;
* `reverse` (*étant donné une liste, renvoyer une liste avec tous les éléments d'origine, mais dans l'ordre inverse*) ;
