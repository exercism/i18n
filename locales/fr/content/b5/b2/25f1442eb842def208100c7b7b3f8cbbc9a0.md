# Instructions

Tu t'occupes de la table des accessoires pour la pièce de théâtre de l'école. Les accessoires forment un dictionnaire qui associe le nom d'un accessoire au nombre d'exemplaires disponibles.

Les trois tâches se trouvent dans la classe `MISSING_PROPS`.

## 1. Combien en a-t-on ?

Renvoie le nombre d'exemplaires d'un accessoire. Si l'accessoire n'est pas du tout sur la table, lève la _string_ `"Unknown prop: "` suivie de son nom.

```sather
MISSING_PROPS::count_of(props, "crown")
-- => 2

MISSING_PROPS::count_of(props, "sword")
-- raises "Unknown prop: sword"
```

Note la différence entre zéro exemplaire d'un accessoire et un accessoire qui n'existe pas. Un accessoire listé avec un zéro est connu ; il est simplement épuisé.

## 2. Prends-en un

Renvoie le nombre d'exemplaires restants après en avoir retiré un. Si l'accessoire est listé mais qu'il n'en reste aucun, lève `"Out of "` suivi de son nom.

```sather
MISSING_PROPS::take_one(props, "crown")
-- => 1

MISSING_PROPS::take_one(props, "lantern")
-- raises "Out of lantern"
```

Un accessoire qui n'est pas du tout sur la table doit quand même lever `"Unknown prop: ..."`, et tu ne devrais pas avoir à écrire ce message deux fois.

## 3. Rends compte

Renvoie un message au lieu de lever une erreur, quoi qu'il arrive.

```sather
MISSING_PROPS::report(props, "crown")
-- => "Took crown, 1 left"

MISSING_PROPS::report(props, "lantern")
-- => "Out of lantern"

MISSING_PROPS::report(props, "sword")
-- => "Unknown prop: sword"
```

Quand ça marche, le message est `"Took "`, le nom, `", "`, le nombre d'exemplaires restants, et `" left"`. Quand ça ne marche pas, le message est exactement ce qui a été levé.
