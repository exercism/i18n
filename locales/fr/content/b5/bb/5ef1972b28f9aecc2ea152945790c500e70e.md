# Instructions

Le projet de voiture télécommandée que tu as lancé dans l'exercice `classes` a bien avancé (félicitations !) et, grâce à plusieurs contrats de sponsoring récents, le budget contient de quoi financer quelques améliorations.

Une partie du budget sert à mettre en place de la télémétrie.

Pour ménager les sponsors, un panneau a été installé sur la voiture afin d'afficher les noms des sponsors pendant qu'elle parcourt la piste.

Tu noteras que l'arrivée de ces nouvelles technologies sophistiquées a considérablement réduit l'autonomie de la batterie de la voiture.

## 1. Permets à la voiture télécommandée d'afficher les noms des sponsors

Implémente `SetSponsors()` afin qu'elle prenne un ou plusieurs noms de sponsors et les stocke sur la voiture.

Note que l'argument de la méthode `SetSponsors()` est garanti non nul.

Implémente `DisplaySponsor()` pour afficher le sponsor sélectionné. Le premier sponsor passé en argument a pour `sponsorNum` 0, le deuxième 1, etc.

```csharp
var car = RemoteControlCar.Buy();
car.SetSponsors("Exercism", "Walker Industries", "Acme Co.");
var sp2 = car.DisplaySponsor(sponsorNum: 1);
// => "Walker Industries"
```

## 2. Récupère les données de télémétrie de la voiture

Implémente la méthode `RemoteControlCar.GetTelemetryData()`.

`GetTelemetryData()` doit exposer le pourcentage de batterie et la distance parcourue en mètres via des paramètres `out`.

`GetTelemetryData()` doit renvoyer `false` si l'argument serialNum est inférieur à la valeur reçue précédemment. (Il y a un problème lié à la présence de plusieurs nœuds de télémétrie.) Dans ce cas, `serialNum` prendra la valeur du plus grand `serialNum` précédent, et le pourcentage de batterie comme les mètres parcourus seront tous deux mis à `-1`. Lorsque l'appel réussit, `serialNum` reste inchangé.

```csharp
var car = RemoteControlCar.Buy();
car.Drive();
car.Drive();
int serialNum = 4;
car.GetTelemetryData(ref serialNum, out int batteryPercentage, out int distanceDrivenInMeters);
// => true, 4L, 80, 4

serialNum = 1;
car.GetTelemetryData(ref serialNum, out batteryPercentage, out distanceDrivenInMeters);
// => false, 4L, -1, -1
```

## 3. Ajoute une fonctionnalité pour que le système de télémétrie puisse obtenir la consommation de batterie par mètre

Implémente la méthode `TelemetryClient.GetBatteryUsagePerMeter()`.

Cette méthode appellera `RemoteControlCar.GetTelemetryData()`. Si `GetTelemetryData()` renvoie `false` ou que la voiture n'a pas roulé, cette routine doit renvoyer « no data ». Si `GetTelemetryData()` renvoie `true`, elle doit renvoyer un message de la forme « usage-per-meter=BATTERY-USAGE-PER-METER ». Le calcul effectué est (100 - pourcentage de batterie actuel) divisé par la distance parcourue en mètres jusqu'ici.

```csharp
var car = RemoteControlCar.Buy();
car.Drive();
car.Drive();
var tc = new TelemetryClient(car);
int serialNum = 4;
tc.GetBatteryUsagePerMeter(serialNum);
// => "usage-per-meter=5"

serialNum = 1;
tc.GetBatteryUsagePerMeter(serialNum);
// => "no data"
```
