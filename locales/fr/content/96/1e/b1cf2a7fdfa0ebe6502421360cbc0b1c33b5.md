# À propos

En C#, le [littéral `null`][null-keyword] sert à indiquer l'absence de valeur. Un type _nullable_ est un type qui autorise les valeurs `null`.

Avant C# 8.0, les types référence étaient toujours nullables et les types valeur ne l'étaient pas. Un [type valeur peut toutefois être rendu nullable][nullable-value-types] en lui ajoutant un point d'interrogation (`?`).

```csharp
string nullableReferenceType = "hello";
nullableReferenceType = null; // Valid as type is nullable

int nonNullableValueType = 5;
nonNullableValueType = null; // Compile error as type is not nullable

int? nullableValueType = 5; // Define nullable value type
nullableValueType = null;   // Valid as type is nullable
```

Accéder à un membre d'une variable dont la valeur est `null` compile sans problème, mais lève une `NullReferenceException` à l'exécution :

```csharp
string sentence = "What a nice day!";

// Throws NullReferenceException at runtime
sentence.Length;
```

Pour remédier à ce type d'erreur courant, C# 8 permet d'[activer une fonctionnalité][nullable-csharp-8] qui rend les [types référence non nullables par défaut][nullable-reference-types] :

```csharp
string nonNullableReferenceType = "book";
nonNullableReferenceType = null; // Compile warning (no error!)

string? nullableReferenceType = "movie";
nullableReferenceType = null; // Valid as type is nullable
```

Pour [manipuler des valeurs nullables sans risque][nullable-types-tutorial], il faut vérifier qu'elles ne sont pas `null` avant de les utiliser :

```csharp
string NormalizedName(string? name)
{
    if (name == null)
    {
        return "UNKNOWN";
    }
    else
    {
        // Value is not null at this point, so no compile warning
        // and no runtime NullReferenceException being thrown
        return name.ToUpper();
    }
}

NormalizedName(null); // => "UNKNOWN"
NormalizedName("Elisabeth"); // => "ELISABETH"
```

L'[opérateur `??`][null-coalescing-operator] permet de renvoyer une valeur par défaut lorsque la valeur est `null` :

```csharp
string? name1 = "John";
name1 ?? "Paul"; // => "John"

string? name2 = null;
name2 ?? "George"; // => "George"
```

L'[opérateur `?.`][null-conditional-operator] permet d'appeler des membres sans risque sur une valeur qui pourrait être `null` :

```csharp
string? fruit = "apple";
fruit?.Length; // => 5

string? vegetable = null;
vegetable?.Length; // => null
```

Si le compilateur pense qu'une valeur pourrait être `null` alors que tu es certain qu'elle ne le sera pas, tu peux utiliser l'[opérateur `!.`][null-forgiving-operator] pour supprimer l'avertissement. N'utilise cet opérateur qu'en dernier recours.

```csharp
void PrintName(string? name)
{
    // Assume that the IsValid() method only return true
    // when its argument is not null
    if (IsValid(name))
    {
        // No compile warning
        Console.WriteLine(name!.Length);
    }
}
```
