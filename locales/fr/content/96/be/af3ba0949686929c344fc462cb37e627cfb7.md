# Ajoute un nouveau parcours

La toute première étape pour ajouter un nouveau parcours de langage à Exercism est :

- [Demande un nouveau parcours de langage](/docs/building/tracks/new/request-new)

Une fois cette étape terminée, voici les étapes suivantes :

- [Rejoins notre communauté](/docs/building/tracks/new/join-our-community)
- [Sélectionne la variante du langage de programmation](/docs/building/tracks/new/select-programming-language-variant) (le cas échéant)
- [Sélectionne le framework de test](/docs/building/tracks/new/select-testing-framework)
- [Ajoute le premier exercice](/docs/building/tracks/new/add-first-exercise)
- [Configure l'intégration continue](/docs/building/tracks/new/setup-continuous-integration)
- [Ajoute les premiers exercices](/docs/building/tracks/new/add-initial-exercises)
- [Construis l'exécuteur de tests](/docs/building/tracks/new/build-test-runner)
- [Configure l'outillage](/docs/building/tracks/new/configure-tooling)
- [Prépare-toi au lancement](/docs/building/tracks/new/prepare-for-launch)
- [Teste le parcours](/docs/building/tracks/new/test-track)
- [Trouve des mainteneurs](/docs/building/tracks/new/find-maintainers)
- [Lance !](/docs/building/tracks/new/launch)
- [Active la coloration syntaxique](/docs/building/tracks/new/syntax-highlighting)
- [Implémente de l'outillage supplémentaire](/docs/building/tracks/new/implement-tooling)
- [Prépare-toi aux contributions open source d'inconnus](/docs/building/tracks/new/prepare-for-contributions)
