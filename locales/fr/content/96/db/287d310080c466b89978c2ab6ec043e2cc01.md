# Indices

## Général

- Une [valeur entière][integers] peut être définie comme une suite d'un ou plusieurs chiffres consécutifs.
- Une [valeur de type map][maps] stocke des données clé-valeur

## 1. Étant donné un échiquier et une colonne, compte combien de cases sont occupées

- On peut parcourir une [map][maps]
- Vérifie si la valeur vaut _true_.
  Si c'est le cas, incrémente.
  C'est ce qui permet de compter les pièces.
- Tu dois [renvoyer explicitement un entier][return] depuis une fonction.

## 2. Étant donné un échiquier et une rangée, compte combien de cases sont occupées

- Tu dois d'abord vérifier que la rangée est dans les limites.
- Parcours l'échiquier.
- Ajoute un si la case est occupée.

## 3. Compte combien de cases sont présentes dans l'échiquier donné

- Il existe de nombreuses façons de résoudre ce problème.
- Cette fonction doit renvoyer le nombre de cases configurées dans un échiquier.

## 4. Compte combien de cases sont occupées dans l'échiquier donné

- Récupère le CountInFile pour chaque colonne de l'échiquier.
