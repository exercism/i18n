# Introduction

Le type `Result` est la solution proposée par le langage Elm pour signaler les erreurs, et un moyen de s'en remettre. Il est assez proche du type `Maybe`, sauf que si `Maybe` peut être renvoyé par des fonctions susceptibles d'échouer, il ne dit rien sur la raison de l'échec. Result apporte justement ce contexte : pourquoi quelque chose a échoué.

Le type `Result` est défini comme suit :

```elm
type Result error value
  = Ok value
  | Err error
```

C'est ce que l'on appelle une définition de « type personnalisé » dans la terminologie d'Elm.
Les `error` et `value` dans `OK value` et `Error error` représentent une variable de type, ce qui signifie que celle-ci peut être n'importe quel type, comme `Int`, `Bool` ou `String`.
Ainsi, un `Result String Int` est une variable censée contenir un `Int`, et si une erreur survient, celle-ci sera représentée par une `String`.
Il existe un [module Result](https://package.elm-lang.org/packages/elm/core/latest/Result) qui fournit de nombreuses fonctions utilitaires bien pratiques pour travailler avec les résultats.
