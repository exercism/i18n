# À propos

Quand on modélise des données qui ne peuvent prendre qu'un ensemble précis d'états possibles, comme les jours de la semaine, les points cardinaux ou les boutons d'une manette, les types de base comme `Int` ou `String` présentent de gros inconvénients.
Avec des entiers ou des _strings_, le code doit sans cesse vérifier qu'il ne reçoit pas de valeurs invalides (comme un code de statut `999` ou une faute de frappe comme `"leftt"`), et une personne qui lit le code ne peut pas facilement deviner ce que représentent les nombres.

Swift résout ce problème avec les [_énumérations_][enumerations] (souvent abrégées en _enums_).
Une énumération définit un type commun pour un groupe de valeurs nommées apparentées. Comme le compilateur connaît à l'avance tous les cas possibles, il peut vérifier l'exactitude et l'exhaustivité du code à la compilation.
Les énumérations peuvent aussi avoir des méthodes, des initialiseurs et des propriétés calculées.

## Définir des énumérations

On définit une énumération avec le mot-clé `enum`, suivi du nom du type, et ses cas sont listés entre accolades.
Par convention en Swift, le nom du type s'écrit en `UpperCamelCase` et chaque cas en `lowerCamelCase` :

```swift
enum NESButton {
    case up
    case down
    case left
    case right
    case a
    case b
    case select
    case start
}
```

On peut aussi définir plusieurs cas sur une seule ligne, séparés par des virgules :

```swift
enum NESButton {
    case up, down, left, right, a, b, select, start
}
```

Pour désigner un cas d'énumération, on écrit le nom du type, un point (`.`) et le nom du cas. Une fois que le type est connu ou peut être déduit par le compilateur, on peut omettre le nom du type et utiliser la notation pointée raccourcie :

```swift
var lastPressed = NESButton.up

// Swift infers the type, so you can omit the type name:
lastPressed = .down

let konamiCode: [NESButton] = [.up, .up, .down, .down, .left, .right, .left, .right, .b, .a]
```

## Énumérations et instructions `switch`

Les énumérations s'intègrent parfaitement aux [instructions `switch`][enums-and-switches].
Comme un `switch` en Swift doit être exhaustif, le compilateur veille à ce que tous les cas possibles soient traités :

```swift
lastPressed = .left
switch lastPressed {
case .up: print("You pressed the UP button")
case .down: print("You pressed the DOWN button")
case .left: print("You pressed the LEFT button")
case .right: print("You pressed the RIGHT button")
case .a: print("You pressed the A button")
case .b: print("You pressed the B button")
case .select: print("You pressed the SELECT button")
case .start: print("You pressed the START button")
}
// Prints "You pressed the LEFT button"
```

Si tu oublies un cas sans fournir de clause `default`, le compilateur signale une erreur :

```swift
switch lastPressed {
case .up, .down, .left, .right:
    print("You pressed a direction button.")
}
// Error: Switch must be exhaustive
```

Il est souvent préférable de lister explicitement tous les cas plutôt que d'utiliser `default`. Ainsi, si on ajoute un nouveau cas plus tard, le compilateur nous avertit immédiatement qu'il faut mettre à jour toutes les instructions `switch` qui traitent cette énumération.

## Méthodes et initialiseurs

Les énumérations peuvent définir des méthodes et des initialiseurs personnalisés, comme les classes et les structures. À l'intérieur d'une méthode d'énumération, `self` désigne la valeur du cas courant :

```swift
enum Coin {
    case heads
    case tails

    init(_ value: Int) {
        if value.isMultiple(of: 2) {
            self = .heads
        } else {
            self = .tails
        }
    }

    func flip() -> Coin {
        switch self {
        case .heads: return .tails
        case .tails: return .heads
        }
    }
}

let tails = Coin(13)     // .tails
let heads = Coin(0)      // .heads
let flipped = heads.flip() // .tails
```

## Valeurs brutes

Les cas d'une énumération peuvent être préremplis avec des valeurs par défaut appelées [_valeurs brutes_][raw-values].
Toutes les valeurs brutes d'une énumération doivent être du même type (par exemple `Int`, `String` ou `Character`) :

```swift
enum NESButton: Character {
    case up = "⬆️"
    case down = "⬇️"
    case left = "⬅️"
    case right = "➡️"
    case a = "🅰️"
    case b = "🅱️"
    case select = "✅"
    case start = "🚦"
}

print(NESButton.left.rawValue) // Prints "⬅️"
```

On peut initialiser une énumération à partir d'une valeur brute avec `init(rawValue:)`. Comme une valeur brute invalide peut être fournie, cet initialiseur renvoie un optionnel :

```swift
let upButton = NESButton(rawValue: "⬆️") // Optional(NESButton.up)
let invalid = NESButton(rawValue: "🙄")  // nil
```

Swift peut affecter automatiquement des valeurs brutes pour les énumérations de type `String` et `Int` :

- Pour les énumérations de type `String`, la valeur brute de chaque cas vaut par défaut le nom du cas.
- Pour les énumérations de type `Int`, les valeurs brutes commencent à `0` et augmentent de 1, sauf indication contraire.

```swift
enum Planet: Int {
    case mercury = 1, venus, earth, mars
}

print(Planet.earth.rawValue) // Prints 3
```

## Valeurs associées

Les cas d'une énumération peuvent aussi stocker, à côté de chaque cas, des valeurs personnalisées de types variés, appelées [_valeurs associées_][associated-values] :

```swift
enum Suit: Character {
    case diamonds = "♦️", clubs = "♣️", hearts = "♥️", spades = "♠️"
}

enum Card {
    case ace(Suit)
    case king(Suit)
    case queen(Suit)
    case jack(Suit)
    case number(Suit, Int)

    func description() -> String {
        switch self {
        case .ace(let suit): return "A\(suit.rawValue)"
        case .king(let suit): return "K\(suit.rawValue)"
        case .queen(let suit): return "Q\(suit.rawValue)"
        case .jack(let suit): return "J\(suit.rawValue)"
        case let .number(suit, value): return "\(value)\(suit.rawValue)"
        }
    }
}

let aceOfSpades = Card.ace(.spades)
let twoOfHearts = Card.number(.hearts, 2)

print(aceOfSpades.description()) // Prints "A♠️"
print(twoOfHearts.description()) // Prints "2♥️"
```

Une énumération peut utiliser des valeurs brutes ou des valeurs associées, mais jamais les deux à la fois.

## Énumérations récursives

Une [énumération récursive][recursive-enumerations] est une énumération dont un ou plusieurs cas ont une autre instance de l'énumération comme valeur associée.
Pour activer la récursion, on marque le cas (ou toute l'énumération) avec le mot-clé `indirect` :

```swift
enum BinaryTree {
    case leaf(value: Int)
    indirect case node(left: BinaryTree, value: Int, right: BinaryTree)
}

let tree: BinaryTree = .node(
    left: .leaf(value: 1),
    value: 3,
    right: .node(left: .leaf(value: 5), value: 6, right: .leaf(value: 9))
)
```
