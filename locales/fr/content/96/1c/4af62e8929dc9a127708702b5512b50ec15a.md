# Introduction

## Variables

Elixir est un langage à typage dynamique, ce qui signifie que le type d'une variable n'est vérifié qu'à l'exécution. Avec l'opérateur de correspondance `=`, on peut lier une valeur de n'importe quel type à un nom de variable :

```elixir
# Bound an integer value of 1
count = 1
# You may re-bind variables
count = 2

# You may re-bind any type to a variable
count = false

# Strings can be created by enclosing characters within double quotes
message = "Success!"
```

## Modules

Elixir est un [langage de programmation fonctionnelle][functional-programming] et impose que toutes les fonctions nommées soient définies dans un _module_. Le mot-clé `defmodule` sert à définir un module. Tous les modules sont accessibles à tous les autres modules à l'exécution et n'ont pas besoin d'un _modificateur d'accès_ pour être visibles depuis les autres parties du programme. Un _module_ est l'équivalent d'une _classe_ dans d'autres langages de programmation.

```elixir
defmodule Calculator do
  # ...
end
```

## Fonctions nommées

Les _fonctions nommées_ doivent être définies dans un module. Le mot-clé `def` sert à définir une fonction nommée _publique_.

Une fonction peut prendre zéro ou plusieurs arguments. La valeur de la dernière expression d'une fonction est toujours _renvoyée implicitement_.

```elixir
defmodule Calculator do
  def add(x, y) do
    x + y
  end
end
```

Pour appeler une fonction, on précise le nom de son module et le nom de la fonction, puis on fournit une valeur pour chacun de ses arguments.

```elixir
sum = Calculator.add(1, 2)
# => 3
```

On peut utiliser le mot-clé `defp` à la place de `def` pour définir une fonction _privée_. Une fonction privée ne peut être utilisée que depuis le module qui l'a définie.

Quand on appelle une fonction depuis le module même où elle est définie, on peut omettre le nom du module.

Tu peux aussi écrire des fonctions courtes avec une syntaxe sur une seule ligne (remarque la virgule `,` et le deux-points `:` autour du mot-clé `do`).

```elixir
defmodule Calculator do
  def subtract(x, y) do
    private_subtract(x, y)
  end

  defp private_subtract(x, y), do: x - y
end

difference = Calculator.subtract(7, 2)
# => 5

difference = Calculator.private_subtract(7, 2)
# => ** (UndefinedFunctionError) function Calculator.private_subtract/2 is undefined or private
#       Calculator.private_subtract(7, 2)
```

## L'arité des fonctions

Il est courant de désigner les fonctions par leur _arité_. L'_arité_ d'une fonction est le nombre d'arguments qu'elle accepte.

```elixir
# add/3 because this function has three arguments, thus an arity of 3
def add(x, y, z) do
  x + y + z
end
```

## Conventions de nommage

Les noms de modules doivent être écrits en `PascalCase`. Le nom d'un module doit commencer par une lettre majuscule `A-Z` et peut contenir des lettres `a-zA-Z`, des chiffres `0-9` et des tirets bas `_`.

Les noms de variables et de fonctions doivent être écrits en `snake_case`. Le nom d'une variable ou d'une fonction doit commencer par une lettre minuscule `a-z` ou un tiret bas `_`, peut contenir des lettres `a-zA-Z`, des chiffres `0-9` et des tirets bas `_`, et peut se terminer par un point d'interrogation `?` ou un point d'exclamation `!`.

## Bibliothèque standard

Elixir dispose d'une bibliothèque standard très riche et bien documentée. La documentation est disponible en ligne sur [hexdocs.pm/elixir][docs]. Garde ce lien quelque part, tu vas beaucoup l'utiliser !

La plupart des types de données intégrés ont un module correspondant qui propose des fonctions pour manipuler ce type de données, par exemple le module `Integer` pour les entiers, le module `String` pour les _strings_, le module `List` pour les tableaux, et ainsi de suite.

Le module `Kernel` mérite une mention particulière. Il fournit les capacités de base sur lesquelles repose le reste de la bibliothèque standard, comme les opérateurs arithmétiques, les macros de contrôle de flux, et bien d'autres choses encore. Les fonctions du module `Kernel` sont importées automatiquement, tu peux donc les utiliser sans le préfixe `Kernel.`.
