# Instructions

Le bosco tient chaque jour un briefing de quart sur le pont : une salutation fixe, un appel de l'équipage de service, puis une formule de clôture. Tu vas décomposer le briefing en petites lignes nommées, puis les assembler.

Tu vas modifier **deux fichiers** pour cet exercice :

- `bosuns-briefing/helpers/helpers.factor` : de petits morceaux réutilisables. Vocabulaire : `bosuns-briefing.helpers`.
- `bosuns-briefing/bosuns-briefing.factor` : le fichier principal qui assemble les helpers. Vocabulaire : `bosuns-briefing`.

## 1. Salutation

Dans `helpers.factor`, définis `greeting` pour renvoyer la chaîne d'ouverture fixe `"All hands, attention!"`.

```factor
greeting .
! => "All hands, attention!"
```

## 2. Ligne d'équipage

Dans `helpers.factor`, définis `crew-line` pour qu'elle prenne une _string_ de nom et renvoie ce nom préfixé par `"  - "` (deux espaces, un trait d'union, un espace).

```factor
"Lopez" crew-line .
! => "  - Lopez"
```

## 3. Clôture

Dans `helpers.factor`, définis `closing` pour renvoyer la chaîne de clôture fixe `"Carry on."`.

```factor
closing .
! => "Carry on."
```

## 4. Liste d'équipage

Dans `bosuns-briefing.factor`, définis `roster` pour qu'elle prenne un tableau de noms d'équipage et renvoie une seule _string_ multi-ligne, où chaque nom est formaté par `crew-line`, le tout joint par des retours à la ligne.

```factor
{ "Lopez" "Mwangi" } roster .
! => "  - Lopez\n  - Mwangi"

{ } roster .
! => ""
```

## 5. Briefing

Dans `bosuns-briefing.factor`, définis `briefing` pour qu'elle prenne un tableau de noms d'équipage et renvoie le briefing complet sous forme d'une seule _string_ : la salutation sur la première ligne, la liste d'équipage sur les lignes suivantes, et la clôture sur la dernière ligne. Utilise les helpers et `roster`.

```factor
{ "Lopez" "Mwangi" } briefing .
! => "All hands, attention!\n  - Lopez\n  - Mwangi\nCarry on."

{ } briefing .
! => "All hands, attention!\n\nCarry on."
```
