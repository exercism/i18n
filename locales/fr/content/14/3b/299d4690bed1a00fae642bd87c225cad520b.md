# Introduction

La portée d'une valeur détermine où, dans le programme, cette valeur est accessible.

## Les quatre types de portée : bloc ; fonction ; prototype de fonction ; fichier

### Portée de bloc

Une valeur qui a une portée de bloc n'est accessible que depuis le bloc où elle est définie.
Pour en savoir plus sur les blocs, consulte le [concept de bloc](../blocks/introduction.md#Introduction).

### Portée de fonction

La portée de fonction est un type particulier de portée qui s'applique aux étiquettes utilisées avec les instructions `goto`.
Deux étiquettes de même nom ne peuvent pas être utilisées dans la même fonction, même si elles sont définies dans des blocs distincts à l'intérieur de cette fonction.

### Portée de prototype de fonction

La portée de prototype de fonction est un autre type particulier de portée, qui ne s'applique qu'aux paramètres nommés dans le prototype (que l'on désigne aussi par le terme de déclaration, en gardant à l'esprit que toutes les déclarations ne sont pas des prototypes).
Le nom d'un paramètre est généralement facultatif dans une déclaration de fonction.
La portée d'un nom n'est pertinente qu'à l'intérieur de la déclaration.
Une définition de fonction n'est pas obligée d'utiliser, pour un paramètre, le même nom que celui utilisé dans la déclaration de la fonction.

### Portée de fichier

Une valeur qui a une portée de fichier est accessible depuis n'importe quel endroit du fichier.
Une telle valeur est définie en dehors d'une fonction.
