# Appendice aux instructions

## Thèmes

Voici quelques thèmes Rust que tu peux avoir envie de lire pendant que tu résous ce problème :

- Les traits, à la fois le trait From et [implémenter tes propres traits](https://doc.rust-lang.org/book/ch10-02-traits.html)
- [Les implémentations de méthode par défaut](https://doc.rust-lang.org/book/ch10-02-traits.html#default-implementations) pour les traits
- Les macros : l'utilisation d'une macro peut réduire le code qui se répète et améliorer la lisibilité
  de cet exercice. Par exemple,
  [une macro peut implémenter un trait pour plusieurs types à la fois](https://stackoverflow.com/questions/39150216/implementing-a-trait-for-multiple-types-at-once),
  même s'il est tout à fait possible d'implémenter `years_during` directement dans le trait Planet. Une macro pourrait
  définir à la fois les structures et leurs implémentations. Pour débuter avec les macros, tu peux consulter :

  - [Le chapitre sur les macros dans The Rust Programming Language](https://doc.rust-lang.org/stable/book/ch19-06-macros.html)
  - [une ancienne version du chapitre sur les macros, avec des détails utiles](https://doc.rust-lang.org/1.30.0/book/first-edition/macros.html)
  - [Rust By Example](https://doc.rust-lang.org/stable/rust-by-example/macros.html)
