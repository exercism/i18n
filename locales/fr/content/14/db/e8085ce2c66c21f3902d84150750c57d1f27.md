# Ajout aux instructions

## Implémentation

Tu dois définir un type personnalisé 'DNA' avec une fonction 'Counts' qui renvoie deux valeurs :

- un décompte de fréquence pour le brin d'ADN donné
- une erreur (s'il y a des nucléotides invalides)

Quel type est adapté pour représenter un brin d'ADN ?

Quels sont les meilleurs types en Go pour représenter les valeurs de sortie ?

Jette un œil aux cas de test pour avoir une idée des entrées possibles.

## Note sur les tests

Tu te demandes peut-être à quoi correspond le fichier `cases_test.go`.
On l'explique dans [l'exercice leap][leap-exercise].
