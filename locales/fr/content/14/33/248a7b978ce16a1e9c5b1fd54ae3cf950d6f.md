# Installation

Ce parcours utilise ReScript 12 et nécessite [Node.js][nodejs] 22 ou une version supérieure.
De nombreux systèmes l'ont déjà installé par défaut, ou tu l'as peut-être installé auparavant pour un autre parcours.

Ouvre un terminal et exécute :

```sh
node -v
```

Si Node n'est pas installé, ou si une version plus ancienne s'affiche, suis les instructions d'installation officielles de [Node.js][nodejs-install] pour ta plateforme.

## Installe les dépendances

Chaque exercice ReScript est un projet npm autonome.
Après avoir téléchargé un exercice avec [l'Exercism CLI][exercism-cli], installe les dépendances du projet, dont ReScript, et tu es prêt à te lancer :

```sh
cd /path/to/exercise
npm install
```
