# Astuces

## Général

- [Le tutoriel sur les dictionnaires Python][dict-tutorial] peut être un excellent point de départ.
- La documentation Python sur les [types de mappage, les dictionnaires][dict docs] est également très utile.

## 1. Crée un inventaire à partir d'une liste

- Il te faut une [boucle `for`][for-loop] pour parcourir la liste d'articles, puis insérer chaque article dans le dictionnaire s'il n'y est pas déjà et incrémenter le compteur de l'article à l'aide de l'accesseur du dictionnaire.
- Tu peux utiliser [`dict.setdefault`][dict setdefault] pour t'assurer que la valeur est définie avant d'incrémenter le compteur de l'article.
- Cette fonction doit [renvoyer][return-keyword] un dictionnaire.

## 2. Ajoute des articles d'une liste à un dictionnaire existant

- Il te faut une [boucle `for`][for-loop] pour parcourir la liste d'articles, puis insérer chaque article s'il n'est pas déjà dans le dictionnaire et [incrémenter][increment] le compteur de l'article à l'aide de l'accesseur du dictionnaire.
- Tu peux utiliser [`dict.setdefault`][dict setdefault] pour t'assurer que la valeur est définie avant d'incrémenter le compteur de l'article.
- La fonction `add_items` peut être utilisée par la fonction `create_inventory` avec un dictionnaire vide en paramètre.
- Cette fonction doit [renvoyer][return-keyword] un dictionnaire.

## 3. Décrémente le nombre d'articles de l'inventaire

- Il te faut une [boucle `for`][for-loop] pour parcourir la liste d'articles, puis, si le nombre d'articles n'est pas `0`, [décrémenter][decrement] le nombre d'articles actuel.
- Tu peux utiliser le test `key in dict`, qui renvoie `True` si la clé existe, pour t'assurer que la valeur est dans le dictionnaire avant de décrémenter le nombre d'articles.
- Cette fonction doit [renvoyer][return-keyword] un dictionnaire.

## 4. Supprime complètement un article de l'inventaire

- Si l'article est dans le dictionnaire, [supprime-le][dict-pop].
- Si l'article n'est pas dans le dictionnaire, ne fais rien.
- Cette fonction doit [renvoyer][return-keyword] un dictionnaire.

## 5. Renvoie le contenu de l'inventaire

- Il te faut utiliser une [boucle `for`][for-loop] sur l'inventaire et, si le nombre d'articles est supérieur à `0`, ajouter le `tuple` à une `list`.
- Tu peux utiliser [`dict.items()`][dict items] pour parcourir en même temps l'article et sa valeur ; `items()` renvoie un `tuple` que tu peux utiliser ou décomposer, si besoin.
- Cette fonction doit [renvoyer][return-keyword] une [liste][list] de [tuples][tuples].
