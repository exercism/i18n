# Indices

## Généralités

- Lis la documentation sur les [optionnels][optionals] et sur les [instructions conditionnelles][conditionals] dans _A Tour of Swift_ d'Apple.

## 1. Écris une fonction qui calcule la taille des parts et qui renvoie nil pour une entrée invalide.

- L'aire d'un cercle est _pi_ \* _r_<sup>2</sup>, où _r_ est la moitié du diamètre.
- On peut utiliser une conversion de type pour convertir un `Int` en un `Double`.
- On peut utiliser une instruction conditionnelle de type `guard` pour quitter la fonction plus tôt si l'un des paramètres n'est pas valide.

## 2. Traite les entrées de ton application web pour déterminer la plus grande part.

- La liaison optionnelle permet de déterminer si un optionnel contient une valeur et d'extraire cette valeur si elle existe.
- On peut quitter la fonction plus tôt si on sait quelle doit être la valeur de retour, sans traitement supplémentaire.
- On ne peut pas comparer `nil` directement avec des valeurs différentes de `nil`.
- On peut utiliser des instructions `switch` et des motifs optionnels pour comparer des valeurs optionnelles.
