# À propos

« Statistiques » est un sujet vaste et complexe, qui comporte de nombreux aspects.

Certains de ces aspects ont été abordés dans le concept [`Randomness`][randomness], qui est un sujet distinct mais lié.

Sous leur forme la plus simple, les statistiques peuvent consister à résumer une collection itérable de données en une seule valeur.
Quand on découvre Julia, on peut être surpris du peu de fonctions intégrées au langage par défaut :

- [`sum`][sum], pour additionner des nombres.
- [`min`][min] et [`max`][max], pour obtenir les valeurs extrêmes des paramètres fournis.
- [`extrema`][extrema], pour obtenir le tuple (min, max) d'un itérable.
- [`length`][length], pour compter toutes les valeurs.
- [`count`][count], pour ne compter que les valeurs qui satisfont un certain critère.

```julia-repl
julia> v = collect(1:0.2:3)
11-element Vector{Float64}:
 1.0
 1.2
 ... # display truncated
 3.0

julia> mean(v)
2.0

julia> extrema(v)
(1.0, 3.0)

julia> length(v)
11

julia> min('g', 'a', 'c')
'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)

julia> count(isodd, 1:5)  # 1, 3, and 5 are odd
3
```

Cet ensemble restreint de fonctions est un choix délibéré, destiné à limiter la lourdeur de Julia de base en déplaçant les autres fonctions vers une cascade d'autres modules et paquets.

## Le module `Statistics`

Comme il fait partie de la bibliothèque standard, [`Statistics`][statistics] est probablement déjà installé : il suffit donc d'ajouter `using Statistics` en haut du programme pour le faire entrer dans l'espace de noms.

Ce module contient le niveau suivant de fonctions courantes, qui sont probablement utilisées par une partie des programmeurs.

Beaucoup de fonctions de `Statistics` supposent un minimum de connaissances sur le sujet.
Les exemples les plus simples sont les suivants :

- [`mean`][mean], que beaucoup de personnes appellent la moyenne (même résultat que `sum / length`).
- [`median`][median], la valeur centrale après tri.
- [`std`][std], l'[écart type][stddev] : une mesure de la dispersion des valeurs.
- [`var`][var], la variance : le carré de `std`, qui est généralement plus rapide à calculer.

Chaque fonction a tendance à offrir diverses options, et il existe _beaucoup_ d'autres fonctions, donc n'hésite pas à consulter la [documentation][statistics] si cela t'intéresse.
