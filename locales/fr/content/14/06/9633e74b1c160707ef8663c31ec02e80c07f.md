## Registres

| Registre | Utilisation  | Type    | Description                                        |
| -------- | ------------ | ------- | -------------------------------------------------- |
| `$a0`    | entrée       | adresse | chaîne d'entrée terminée par un caractère nul      |
| `$a1`    | entrée/sortie | adresse | chaîne de résultat terminée par un caractère nul   |
| `$t0-9`  | temporaire   | quelconque | pour le stockage temporaire                     |
