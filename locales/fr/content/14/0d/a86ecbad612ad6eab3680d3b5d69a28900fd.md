# Indices

## Général

- [Documentation Python : Enum](https://docs.python.org/3/library/enum.html)

## 1. Analyse le niveau de log

- Utilise [`str.split`](https://www.w3schools.com/python/ref_string_split.asp) pour extraire le niveau de log du message.
- À partir de la partie extraite de la _string_, accède au membre de l'énumération et renvoie-le avec `LogLevel(string)`.

## 2. Prends en charge un niveau de log inconnu

- Crée dans l'énumération existante un nouveau membre de niveau de log Unknown.
- Vérifie si la partie extraite de la _string_ est une valeur de l'énumération `LogLevel`.
- Si la valeur ne correspond à aucune des valeurs des membres de l'énumération, renvoie le membre Unknown de `LogLevel`.

## 3. Convertis une ligne de log au format court

- Trouve le code (un entier) du niveau de log en fonction de celui-ci ; plusieurs solutions sont possibles : des instructions `if`, une autre énumération ou n'importe quelle autre solution.
- Utilise le formatage de _strings_ pour renvoyer un code et un message correctement formatés.

## 4. Crée un alias

- Crée dans l'énumération existante un nouveau membre alias nommé Warn.
- Renvoie le membre que tu viens de créer.

## 5. Tous les noms et valeurs des membres

- Parcours tous les membres de l'énumération et renvoie un tableau de tuples.
- Le tuple peut être construit avec `(item1, item2)`.
- On peut accéder au nom et à la valeur d'un membre avec `member.name` et `member.value`.
- Renvoie le tableau contenant tous les tuples.
