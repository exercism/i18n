# Instructions

Izzy est une passionnée d'observation des oiseaux qui note combien d'oiseaux ont visité son jardin chaque jour.

Elle t'a demandé de l'aider à faire passer son observation des oiseaux au niveau supérieur et d'écrire quelques outils qui l'aideront à suivre et à traiter ces données.

Tu as choisi de stocker ces données dans un tableau d'entiers. Le premier nombre du tableau est le nombre d'oiseaux qui ont visité son jardin aujourd'hui, le deuxième hier, et ainsi de suite.

## 1. Vérifie combien d'oiseaux ont visité le jardin aujourd'hui

Implémente la fonction `today`. Elle prend un tableau contenant le nombre d'oiseaux observés chaque jour et renvoie le nombre du jour. Si le tableau est vide, elle doit renvoyer `0`.

```gleam
today([2, 5, 1])
// -> 2
```

## 2. Incrémente le compteur du jour

Implémente la fonction `increment_day_count`. Elle prend un tableau contenant le nombre d'oiseaux observés chaque jour et augmente de 1 le compteur du jour. Si le tableau est vide, elle renvoie `[1]`.

```gleam
increment_day_count([4, 0, 2])
// -> [5, 0, 2]
```

## 3. Vérifie s'il y a eu un jour sans oiseau

Implémente la fonction `has_day_without_birds`. Elle prend un tableau contenant le nombre d'oiseaux observés chaque jour. Elle doit renvoyer `True` s'il y a eu au moins un jour où aucun oiseau n'a visité le jardin, et `False` sinon. Si le tableau est vide, cela signifie qu'aucun oiseau n'a encore été enregistré ; renvoie `False`.

```gleam
has_day_without_birds([2, 0, 4])
// -> True

has_day_without_birds([3, 8, 1, 5])
// -> False
```

## 4. Calcule le nombre total d'oiseaux qui ont visité le jardin

Implémente la fonction `total`. Elle prend un tableau contenant le nombre d'oiseaux observés chaque jour et renvoie le nombre total d'oiseaux qui ont visité le jardin depuis que tu as commencé à collecter les données.

```gleam
total([4, 0, 9, 0, 5])
// -> 18
```

## 5. Calcule le nombre de journées chargées

Certains jours sont plus chargés que d'autres. Une journée chargée est une journée où cinq oiseaux ou plus ont visité le jardin.

Implémente la fonction `busy_days`. Elle prend un tableau contenant le nombre d'oiseaux observés chaque jour et renvoie le nombre de journées chargées.

```gleam
busy_days([4, 5, 0, 0, 6])
// -> 2
```
