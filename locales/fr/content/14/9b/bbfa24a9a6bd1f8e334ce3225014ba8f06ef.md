# Introduction

Un tampon de chaînes est un moyen efficace de construire une grande chaîne de caractères en y ajoutant bout à bout de petits éléments. Contrairement à String, une instance de StringBuf n'est pas immuable, en ce sens qu'on peut la passer en argument à des fonctions qui la modifient en y ajoutant d'autres valeurs.

```haxe
var a = new StringBuf();
a.add("Hello");
trace(a.toString()); // Hello
a.add("Haxe!");
trace(a.toString()); // HelloHaxe
```
