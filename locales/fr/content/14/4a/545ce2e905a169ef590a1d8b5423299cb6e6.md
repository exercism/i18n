# À propos

Une _string_ représente des données textuelles.
En Swift, une [`String`][strings-and-characters] est une collection ordonnée de valeurs `Character`, où chaque caractère représente un caractère Unicode.

Tu peux créer une _string_ à l'aide d'un littéral de chaîne, qui est une suite de caractères entourée de guillemets doubles (`"`).
Pour les chaînes sur plusieurs lignes, utilise trois guillemets doubles (`"""`) :

```swift
let hello: String = "Hello, World!"

let poem: String = """
Roses are red,
Violets are blue.
Sugar is sweet,
And so are you.
"""
```

Les _strings_ Swift s'intègrent parfaitement à la classe [`NSString`][nsstring-docs] du framework Foundation, ce qui donne accès à de vastes capacités de traitement de texte.

## Caractères

Un `Character` représente un seul _grapheme cluster_ étendu, un caractère lisible par un humain composé d'une ou plusieurs [valeurs scalaires Unicode][unicode-scalar-values].
Une valeur scalaire Unicode est un point de code de 21 bits compris entre `U+0000` et `U+D7FF` inclus, ou entre `U+E000` et `U+10FFFF` inclus.

```swift
let aChar: Character = "A"
```

## Inférence de type

Quand tu écris un littéral de chaîne, Swift infère automatiquement son type comme étant `String`.
Pour stocker un seul caractère dans un `Character`, tu dois fournir une annotation de type explicite :

```swift
let aString = "A"        // Inferred as String
let aChar: Character = "A" // Explicitly typed as Character
print(type(of: aString)) // Prints String
print(type(of: aChar))   // Prints Character

// The following code will not compile:
let badChar: Character = "Too many characters"
// Error: Cannot convert value of type 'String' to specified type 'Character'
```

## Concaténation

Tu peux assembler des _strings_ à l'aide de l'opérateur d'addition (`+`) :

```swift
print("honey" + "comb")
// Prints "honeycomb"
```

Tu ne peux pas concaténer directement un `Character` à une `String` avec `+` sans d'abord convertir le caractère en _string_.
Cependant, tu peux utiliser la méthode [`append(_:)`][append] pour ajouter directement une _string_ ou un caractère à une _string_ modifiable :

```swift
var greeting = "Hello"
let world = ", world"
let period: Character = "."

greeting.append(world)
print(greeting) // Prints "Hello, world"

greeting.append(period)
print(greeting) // Prints "Hello, world."
```

## Interpolation de _string_

L'[interpolation de _string_][string-interpolation] te permet de construire une _string_ en intégrant des constantes, des variables, des littéraux et des expressions à l'intérieur de littéraux de chaîne.
Entoure chaque expression de parenthèses précédées d'un antislash (`\(` ... `)`) :

```swift
let radius = 5.0
let circle = "The area of a circle with radius \(radius) is \(Double.pi * radius * radius)"
print(circle) // Prints "The area of a circle with radius 5.0 is 78.53981633974483"
```

## Propriétés de _string_ et de `Character`

Les _strings_ et les `Character` offrent plusieurs propriétés pour inspecter leur contenu.

### Propriétés de _string_

Voici quelques propriétés de _string_ courantes :

| Propriété | Description                                    | Exemple                          |
| --------- | ---------------------------------------------- | -------------------------------- |
| `isEmpty` | Renvoie `true` si la _string_ ne contient aucun caractère | `"Hello".isEmpty` vaut `false` |
| `count`   | Renvoie le nombre de caractères dans la _string_ | `"Hello".count` vaut `5`       |

Pour une liste complète des propriétés, consulte la [documentation Apple sur `String`][string-docs].

### Propriétés de `Character`

Voici quelques propriétés de `Character` courantes :

| Propriété      | Description                                   | Exemple                              |
| -------------- | --------------------------------------------- | ------------------------------------ |
| `isLowercase`  | Renvoie `true` si le caractère est en minuscule  | `"a".isLowercase` vaut `true` |
| `isUppercase`  | Renvoie `true` si le caractère est en majuscule  | `"A".isUppercase` vaut `true` |
| `isNumber`     | Renvoie `true` si le caractère est un chiffre    | `"1".isNumber` vaut `true`    |
| `isWhitespace` | Renvoie `true` si le caractère est un espace | `" ".isWhitespace` vaut `true`|

Pour une liste complète des propriétés, consulte la [documentation Apple sur `Character`][character-docs].

## Conversion de type

Tu peux convertir d'autres types en _strings_ à l'aide de l'initialiseur `String(_:)`, qui prend en charge des types standard comme `Int`, `Double` et `Character` :

```swift
let charX: Character = "x"
print(String(charX))     // Prints "x"
print(String(110))       // Prints "110"
print(String(Double.pi)) // Prints "3.141592653589793"
```

## Caractères spéciaux

Les littéraux de chaîne en Swift prennent en charge plusieurs [séquences d'échappement][special-characters] pour les caractères spéciaux :

| Séquence   | Description                   |
| ---------- | ----------------------------- |
| `\0`       | Caractère nul                 |
| `\\`       | Antislash                     |
| `\t`       | Tabulation horizontale        |
| `\n`       | Saut de ligne (nouvelle ligne) |
| `\r`       | Retour chariot                |
| `\'`       | Guillemet simple              |
| `\"`       | Guillemet double              |
| `\u{n}`    | Valeur scalaire Unicode arbitraire (en hexadécimal) |

```swift
let quote: String = "\"Hello\", he said."
print(quote) // Prints "Hello", he said.

let unicode: Character = "\u{1F496}"
print(unicode) // Prints 💖
```
