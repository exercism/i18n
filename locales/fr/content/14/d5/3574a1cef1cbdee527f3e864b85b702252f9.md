# Introduction

## Listes

Les listes font partie intégrante du langage Elixir. Elles sont considérées comme un type de base, noté à l'aide de crochets. Une liste peut être vide ou contenir un nombre quelconque d'éléments de n'importe quel type. Par exemple :

```elixir
empty_list = []
one_item_list = [1]
two_item_list = [1, 2]
multiple_type_list = [1, :pi, 3.14, "four"]
```

Elixir implémente les listes sous forme de liste chaînée, où chaque nœud stocke deux valeurs : le premier élément et une autre liste contenant tous les éléments restants. Le premier élément de la liste est appelé la _tête_ et la liste des éléments restants est appelée la _queue_. On peut utiliser cette notation dans le code :

```elixir
# [1] represented in [head | tail] notation
[1 | []]

# [1, 2, 3] represented in [head | tail] notation
[1 | [2 | [3 | []]]]
```

On peut utiliser la notation _`[head | tail]`_ pour ajouter des éléments au début d'une liste :

```elixir
# Suppose
list = [2, 1]

[3, 2, 1] == [3 | list]
# => true
```

Le module `Kernel` contient plusieurs fonctions pour manipuler les listes, ainsi que tout le module `List`.

```elixir
# Check if 1 is a member of the list
1 in [1, 2, 3, 4]
# => true
```
