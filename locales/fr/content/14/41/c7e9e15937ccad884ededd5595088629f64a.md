# Instructions

Une roue de chiffrement est constituée de deux disques emboîtés l'un dans
l'autre, qui font tourner l'alphabet : règle-la sur 3 et chaque lettre devient
celle située trois rangs plus loin, `z` revenant à `a`. Les détectives en
utilisent depuis des siècles. Tu en construis une.

Les cinq tâches prennent place dans la classe `CIPHER_WHEEL`.

## 1. Est-ce une lettre ?

```sather
CIPHER_WHEEL::is_letter('m')
-- => true
CIPHER_WHEEL::is_letter('7')
-- => false
```

## 2. Crie-le

Renvoie la majuscule d'un caractère. Tout ce qui n'est pas une lettre revient
inchangé.

```sather
CIPHER_WHEEL::shout('m')
-- => 'M'
```

## 3. Quel nombre représente-t-il ?

Renvoie le nombre qui correspond à un caractère.

```sather
CIPHER_WHEEL::code('a')
-- => 97
```

## 4. Le premier caractère

Renvoie le premier caractère d'une _string_.

```sather
CIPHER_WHEEL::first_character("Marlowe")
-- => 'M'
```

## 5. Tourne la roue

Étant donné une lettre minuscule et un nombre de rangs, renvoie la lettre
située ce nombre de rangs plus loin dans l'alphabet. Au-delà de `z`, elle
revient à `a`.

```sather
CIPHER_WHEEL::turn('a', 3)
-- => 'd'
CIPHER_WHEEL::turn('z', 1)
-- => 'a'
```

Tourner dans l'autre sens fonctionne aussi, avec un nombre de rangs négatif.

```sather
CIPHER_WHEEL::turn('a', -1)
-- => 'z'
```

Tu peux supposer que le caractère fourni est une lettre minuscule.
