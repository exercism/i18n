# Introduction

En Go, on peut parcourir un `slice` avec `for` et un indice, ou bien utiliser `range`. `range` permet aussi de parcourir une `map` ou un `channel`. Ce concept couvrira le parcours d'une `map`, mais parcourir un `channel` sort du cadre de ce concept.

Chaque itération renvoie deux valeurs : l'indice ou la clé, et une copie de l'élément situé à cet indice ou à cette clé.

## Parcours un slice

Simple comme bonjour : on parcourt un slice, dans l'ordre attendu.

```go
xi := []int{10, 20, 30}
for i, x := range xi {
  fmt.Println(i, x)
}
// outputs:
// 0, 10
// 1, 20
// 2, 30
```

## Parcours une map

Parcourir une map pose un nouveau problème : l'ordre est désormais aléatoire.

```go
hash := map[int]int{9: 10, 99: 20, 999: 30}
for k, v := range hash {
  fmt.Println(k, v)
}
// outputs, for example:
// 99 20
// 999 30
// 9 10
```

~~~~exercism/note
On pourrait croire que la sortie ci-dessus est incorrecte : on s'attendrait à ce que la première paire clé/valeur de la déclaration de la map, `9 10`, soit imprimée en premier et non en dernier.
Cependant, les maps n'ont pas d'ordre par nature : il n'y a ni première ni dernière paire clé/valeur.
Pour cette raison, lorsqu'on parcourt les entrées d'une map, l'ordre dans lequel ces entrées seront visitées est aléatoire et ne suit aucun schéma particulier.
Cela signifie que la sortie ci-dessus est possible, mais qu'elle peut différer de ce que tu obtiens si tu essaies de lancer ce code toi-même.
Pour en savoir plus, consulte [Spécification du langage Go : la clause `range`](https://go.dev/ref/spec#RangeClause).
~~~~

## Itération qui omet la clé ou la valeur

En Go, une variable inutilisée provoque une erreur à la compilation.
Parfois, on n'a besoin que de la valeur, comme dans le premier exemple :

```go
xi := []int{10, 20, 30}
for i, x := range xi {
  fmt.Println(x)
}
// Go build failed: i declared but not used
```

Tu peux remplacer `i` par `_`, ce qui indique au compilateur qu'on n'utilise pas cette valeur :

```go
xi := []int{10, 20, 30}
for _, x := range xi {
  fmt.Println(x)
}
// outputs:
// 10
// 20
// 30
```

Si tu veux n'afficher que l'indice, tu peux remplacer `x` par `_`, ou simplement omettre la déclaration :

```go
xi := []int{10, 20, 30}
// for i, _ := range xi {
for i := range xi {
  fmt.Println(i)
}
// outputs:
// 0
// 1
// 2
```

Enfin, et non des moindres, si tu dois effectuer une action mais que ni les valeurs ni les clés du slice ou de la map ne t'intéressent, tu peux omettre à la fois l'indice et la valeur :

```go
xi := []int{10, 20, 30}
count := 0
for range xi {
  count++
}
// count value:
// 3
```
