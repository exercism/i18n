# Indices

## 1. Extrais les coordonnées

- On cherche à extraire un élément d'un tuple.
- L'accès par indice est une possibilité.
- L'affectation multiple est une approche alternative.

## 2. Formate les coordonnées

- N'oublie pas le constructeur [`Tuple()`][Tuple].

## 3. Fais correspondre les coordonnées

- Tu disposes déjà d'une fonction qui convertit la coordonnée d'Azara au format de Rui.
- Tester l'égalité est une possibilité.
- Autrement, tu peux vérifier si la coordonnée se trouve dans l'enregistrement de Rui (∈).

## 4. Combine les enregistrements correspondants

- Est-ce que les enregistrements correspondent ? Tu sais déjà comment le tester.
- S'ils correspondent, il faut combiner les éléments souhaités dans un autre ordre dans la valeur de retour.
- Les éléments du tuple d'entrée ne sont pas tous renvoyés.
- La déstructuration est ton amie. Donner des noms explicites aux éléments est plus lisible et plus facile à déboguer que l'accès par indice.

[Tuple]: https://docs.julialang.org/en/v1/base/base/#Core.Tuple
