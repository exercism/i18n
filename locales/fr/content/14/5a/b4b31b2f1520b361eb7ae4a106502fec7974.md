# Introduction

En Haxe, une `class` est la principale structure de données : elle encapsule des données (les champs) et un comportement (les méthodes). Les champs et les méthodes sont aussi appelés membres d'une classe.

On peut restreindre l'accès aux membres à l'aide de modificateurs d'accès, qui sont :

- `public` : le membre est accessible depuis n'importe où.
- `private` : le membre n'est accessible qu'au sein de la même classe.

On peut voir les classes comme des modèles servant à créer des instances. Pour créer une instance, il suffit d'utiliser le mot-clé `new` :

```haxe
class Car {
  public function new() {}
}

var myCar = new Car();
var yourCar = new Car();
```

Pour définir un champ, utilise un modificateur d'accès suivi du nom de la variable et de son type :

```haxe
class Car {
  public var weight:Int; // Accessable by anyone

  private var color:String; // Accessable only within this class
}
```

Tu peux aussi définir une valeur initiale au moment de déclarer un champ. Si un champ ne précise pas de valeur initiale, il prend la valeur `null`. Tu peux accéder à un champ avec la notation pointée :

```haxe
class Car {
  public var weight:Int = 2500; // Weight will be set to 2500
  public var year:Int; // year will be null

  public function new() {}
}

var newCar = new Car();
newCar.weight; // 2500
newCar.year; // null

// Update value of field
newCar.year = 2020;
```
