# Indemnité de carburant

## Énoncé du problème

Chaque employé d'ABC Corp bénéficie d'une indemnité carburant illimitée. Les employés doivent envoyer un relevé chaque fois qu'ils font le plein de leur véhicule. Ces relevés sont ajoutés à la suite dans un même fichier CSV, puis traités à la fin du mois.

En tant que membre de l'équipe des opérations numériques, ta tâche consiste à lire ce fichier CSV et à écrire les résultats dans un autre fichier CSV. Le fichier de sortie doit contenir une entrée pour chaque employé, avec les détails suivants :

- Numéro d'employé
- Nombre de pleins de carburant
- Coût total du carburant
- Total des gallons
- Nombre total de miles accumulés

On te donne deux arguments de type `string`.

1. Chemin du fichier CSV d'entrée
1. Chemin du fichier CSV de sortie

Le fichier CSV d'entrée comporte `n` lignes, et chaque ligne se présente sous la forme suivante.

| Nom de colonne      | Type Ballerina |
| ----------- | ----------- |
| employee_id      | `int`       |
| odometer_reading   | `int`       |
| gallons   | `decimal` |
| gas_price(USD)  |`decimal`|

Le fichier de sortie doit contenir une entrée pour chaque employé, triée par ordre croissant de `employee_id`. Chaque ligne se présente sous la forme suivante :

| Nom de colonne      | Type Ballerina |
| ----------- | ----------- |
| employee_id      | `int`       |
| gas_fill_up_count   | `int`        |
| total_fuel_cost(USD)   | `decimal` |
| total_gallons  |`decimal`|
| total_miles_accrued  |`int`|

## Contraintes

- Nombre de lignes `n` dans le fichier CSV d'entrée : 2 <= n <= 1000
- Nombre d'employés dans l'entreprise : 97
- Le prix du carburant est exprimé par gallon
- Aucun relevé de plein manquant

## Exemple 1

- Entrée : `example01_input.csv`

```csv
2312,230,18.561,4.56
2312,500,19.345,4.89
```

- Sortie : `example01_output.csv`

```csv
2312,2,179.23521,37.906,270
```
