# Indices

## 1. Analyser la date du rendez-vous

- La classe `LocalDateTime` possède une méthode pour [analyser][localdatetime-parse] une `String` et la convertir en `LocalDateTime`.
- Utilise un [`DateTimeFormatter`][datetimeformatter-docs] avec un motif personnalisé pour analyser un format de date et d'heure non standard.

## 2. Vérifier si un rendez-vous est déjà passé

- Les instances de `LocalDateTime` disposent de [méthodes][localdatetime-methods] pour les comparer à d'autres `LocalDateTime`.
- Il existe une [méthode][localdatetime-methods] pour récupérer la date et l'heure actuelles.

## 3. Vérifier si le rendez-vous est dans l'après-midi

- Pour accéder à la partie horaire d'une instance de `LocalDateTime`, tu peux passer par l'une de ses [méthodes][localdatetime-methods].

## 4. Décrire l'heure et la date du rendez-vous

- Utilise un [`DateTimeFormatter`][datetimeformatter-docs] avec un motif personnalisé pour formater le `LocalDateTime`.
- Les tests s'exécutent comme s'ils tournaient sur une machine aux États-Unis, alors assure-toi que le formateur [utilise la bonne locale][datetimeformatter-ofpattern-with-locale].

## 5. Renvoyer la date d'anniversaire

- La classe `LocalDate` dispose d'une [méthode][localdate-methods] pour récupérer la date actuelle.
- Pour accéder à l'année d'une instance de `LocalDate`, tu peux passer par l'une de ses [méthodes][localdate-methods].
