# Utilise des _guards_

[comment]: # (This error is raised when the solution doesn't use guards at all)

Utilise des [_guards_](https://hexdocs.pm/elixir/master/guards.html) pour empêcher `two_fer/1` d'exécuter du code avec des entrées non binaires.

> Pour rappel, en Elixir, les [_strings_](https://elixir-lang.org/getting-started/binaries-strings-and-char-lists.html) sont considérées comme des [données binaires](https://elixir-lang.org/getting-started/binaries-strings-and-char-lists.html).

```elixir
# Consider this function with a guard:
def hello(what) when is_binary(what) do
  "Hello, #{what}!"
end
```

> Ce _guard_ peut être testé dans `iex`

```shell
iex> hello("world")
"Hello, world!"
iex> hello(123)
** (FunctionClauseError) no function clause matching in hello/1

    The following arguments were given to hello/1:

        # 1
        123
```
