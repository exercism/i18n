# Indices

## 1. Mélange un jus

- `cond` (dans [`combinators`][combinators]) est la façon la plus élégante de choisir une valeur en fonction d'une chaîne de tests d'égalité.

## 2. Réapprovisionne la réserve de quartiers de citron vert

- Une boucle `while` avec deux éléments d'état (les quartiers encore nécessaires et les citrons verts encore disponibles) est le choix naturel. Les déclarer avec `::` et `:> name!` garde le corps lisible.
- `unclip ( seq -- rest first )` retire le premier citron vert, prêt à être passé à `wedges-from-lime`.

## 3. Liste les temps de mélange de chaque commande dans la file d'attente

- Un seul mot de [`sequences`][sequences] fait tout le travail.

## 4. Termine le service

- La structure est la même que pour la tâche 2 : une boucle `while` pilotée par deux éléments d'état (les minutes restantes dans le service et les commandes encore en attente). Arrête dès que l'un de ces deux éléments est épuisé.

[sequences]: https://docs.factorcode.org/content/vocab-sequences.html
