# Ajout aux instructions

## Notes spécifiques à Rust

Cette version Rust de l'exercice diffère légèrement des versions dans les autres langages. Au lieu de te demander de renvoyer des erreurs pour les valeurs hors limites, on utilise le système de types fort de Rust pour limiter les entrées. Il est bien plus simple d'écrire une fonction qui prend en charge toutes les entrées valides, plutôt que d'obliger l'utilisateur de ton module à gérer les erreurs.

### Extension

Ajoute la possibilité de convertir jusqu'à la valeur maximale d'un u64 : `18_446_744_073_709_551_615`.

Pour te faire une idée de la sortie attendue, regarde le dernier cas de test.
