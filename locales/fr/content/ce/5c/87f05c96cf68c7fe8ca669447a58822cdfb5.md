# Introduction

Le système d'erreurs de Factor se compose de trois éléments :
`throw` (dans [`kernel`][kernel]) lève une erreur, `recover` (dans
[`continuations`][continuations]) en capture une, et `ERROR:` définit
une classe d'erreur de type tuple.

```factor
! "file not found" throw          (raises a string as the error)

[ "boom" throw ] [ drop "caught" ] recover .
! => "caught"
```

`recover ( try recovery -- )` exécute la quotation *try* ; si elle
lève une erreur, cette erreur est empilée et la quotation *recovery*
s'exécute.

`ERROR:` déclare à la fois la classe *et* un mot constructeur qui lève
une nouvelle instance :

```factor
! DOCTEST: SKIP
ERROR: not-found path ;

"/missing" not-found
! throws T{ not-found { path "/missing" } }
```

[continuations]: https://docs.factorcode.org/content/vocab-continuations.html
