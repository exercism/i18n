# Indices

## Général

- Rappelle-toi que la surcharge d'opérateurs passe par les _traits_ en Cairo
- L'attribut `#[derive(PartialEq)]` implémente automatiquement la comparaison d'égalité
- Pour implémenter `PartialOrd`, il suffit d'implémenter la méthode `lt` ; les autres opérateurs de comparaison en sont dérivés

## 1. Implémente `Add`

- La méthode `add` doit combiner les champs `value` des deux TimeShards
- Rappelle-toi que les TimeShards contiennent des valeurs `i32` pour lesquelles l'addition est déjà définie

## 2. Implémente `Sub`

- C'est similaire à l'addition, mais on utilise l'opérateur de soustraction entre les champs `value`
- L'ordre des opérandes est important dans une soustraction

## 3. Implémente `PartialOrd`

- La méthode `lt` doit comparer les champs `value` des TimeShards
- Une fois `lt` implémentée, les autres opérateurs de comparaison (`>`, `<=`, `>=`) fonctionneront automatiquement
- Rappelle-toi que `PartialEq` est déjà dérivé, donc tu n'as pas besoin de l'implémenter manuellement
