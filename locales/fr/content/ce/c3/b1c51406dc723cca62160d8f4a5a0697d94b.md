# Ordre des exercices du parcours Rust

La véritable source de vérité pour l'ordre des exercices et les thèmes est [config.json](config.json), mais ce fichier documente le raisonnement qui sous-tend l'ordre des exercices de ce fichier.

## Notre approche

Nous ordonnons nos exercices pour des apprenants qui découvrent Rust. C'est avec ce public en tête que nous suivons deux règles lorsque nous ajoutons de nouveaux exercices.

- Un exercice doit introduire un seul nouveau concept
- Les exercices doivent progresser des bases de Rust vers des concepts Rust avancés

### Un seul nouveau concept

Si la solution d'un exercice demande aux apprenants d'utiliser à la fois `Result` et `HashMap`, alors au moins un de ces concepts doit avoir été introduit par un exercice précédent.

Si le parcours comporte plusieurs exercices qui reposent sur un même concept, regroupe-les pour renforcer l'apprentissage.

### Progresser à travers Rust

#### Les premiers exercices

Les premiers exercices doivent se concentrer sur la syntaxe et les concepts Rust que l'on retrouve dans de nombreux langages de programmation : les conditions, les boucles, les fonctions d'ordre supérieur.

#### Les exercices intermédiaires

Les exercices situés au milieu du parcours doivent introduire des concepts moins courants. `Result`, `Option` et les traits, par exemple. Ou une syntaxe comme `while let`.

Tout au long de la section intermédiaire du parcours, les apprenants doivent se familiariser avec un large éventail de concepts Rust.

#### Les derniers exercices

Les exercices situés vers la fin du parcours doivent faire l'une de ces deux choses :

1. Introduire des concepts avancés : les _lifetimes_, la concurrence, le code _unsafe_
2. Exiger une solution complexe qui synthétise toutes les connaissances que les apprenants ont acquises jusqu'ici
