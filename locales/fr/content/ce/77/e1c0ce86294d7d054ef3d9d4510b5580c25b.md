# Instructions

Tu développes un système pour aider le personnel du site web d'un club de football à rendre compte des matchs.
Ce système est capable d'analyser différents aspects du match, sur le terrain comme en dehors, et de les convertir en un flux d'événements.

## 1. Produis les descriptions des joueurs à partir de leur numéro de maillot

L'équipe joue toujours en 4-3-3 et n'a jamais accepté le changement de règles de 1965 autorisant les remplacements, et encore moins des effectifs élargis.

Les descriptions des joueurs sont les suivantes :

```text
1 -> "goalie"
2 -> "left back"
3 & 4 -> "center back"
5 -> "right back"
6, 7 & 8 -> "midfielder"
9 -> "left wing"
10 -> "striker"
11 -> "right wing"
```

Implémente la méthode statique `PlayAnalyzer.AnalyzeOnField()` pour produire une description de joueur à partir de son numéro de maillot.

```csharp
PlayAnalyzer.AnalyzeOnField(10);
// => "striker"
```

## 2. Gère les numéros de maillot inconnus

Modifie la méthode `PlayAnalyzer.AnalyzeOnField()` pour renvoyer `UNKNOWN` quand un numéro de maillot en dehors de la plage 1-11 est traité.

## 3. Étends la couverture aux activités en dehors du terrain

Implémente la méthode `PlayAnalyzer.AnalyzeOffField()` pour produire des descriptions des activités et des personnages autour du terrain.
Cette méthode prend différents types de données qui doivent être analysées et converties en un texte approprié pour aider les journalistes.

Pour commencer, on va traiter les données concernant le stade :

- Le nombre actuel de spectateurs dans le stade (n'importe quel `int`)
- Les annonces diffusées par la sonorisation du stade (n'importe quelle `string`)

Les types de données inconnus ne doivent pas être traités ; si la méthode reçoit des données d'un autre type, elle doit renvoyer une _string_ vide.

```csharp
PlayAnalyzer.AnalyzeOffField(5000);
// => "There are 5000 supporters at the match."

PlayAnalyzer.AnalyzeOffField("5 minutes to go!");
// => "5 minutes to go!"

PlayAnalyzer.AnalyzeOffField(0.5);
// => ""
```

## 4. Rends compte des incidents pendant le match

Modifie la méthode `PlayAnalyzer.AnalyzeOffField()` pour produire des descriptions des incidents qui se produisent pendant le match.

Les incidents peuvent être n'importe quelle sous-classe du type `Incident` et contiennent une description de l'incident.
Les blessures sont un type particulier d'incident, car elles interrompent le match et doivent donc être traitées différemment.

```csharp
PlayAnalyzer.AnalyzeOffField(new Foul());
// => "The referee deemed a foul."

PlayAnalyzer.AnalyzeOffField(new Injury(8));
// => "Oh no! Player 8 is injured. Medics are on the field."
```

## 5. Rends compte des entraîneurs des clubs

Modifie la méthode `PlayAnalyzer.AnalyzeOffField()` pour mentionner les entraîneurs présents pendant le match.

Les entraîneurs sont des instances du type `Manager` et ont un nom ainsi que le nom du club qu'ils entraînent.
Le club d'un entraîneur peut être inconnu, auquel cas sa valeur est `null`.
Si le club d'un entraîneur n'est pas connu, il ne doit pas faire partie de la description.

```csharp
PlayAnalyzer.AnalyzeOffField(new Manager("José Mário dos Santos Mourinho Félix", null));
// => "José Mário dos Santos Mourinho Félix"

PlayAnalyzer.AnalyzeOffField(new Manager("Jürgen Klopp", "Liverpool"));
// => "Jürgen Klopp (Liverpool)"
```
