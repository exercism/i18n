# Astuces pour travailler avec les dates en Arturo

## Général

* Le type `:date` est décrit [dans la référence du langage][lang].
* Le module [`Dates`][dates] de la bibliothèque.
* Des exemples de [formatage et d'analyse][example] de dates.
* La fonction [`to`][to] du module Types est essentielle.
