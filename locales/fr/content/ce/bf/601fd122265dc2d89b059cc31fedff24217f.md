# Introduction

Un `String` en Haxe est un objet qui représente du texte immuable sous la forme d'une séquence de caractères Unicode (lettres, chiffres, ponctuation, etc.). Les guillemets doubles servent à définir une instance de `String` :

```haxe
var fruit:String = "Apple";
```

On manipule les _strings_ en appelant les méthodes d'une _string_. Une fois qu'une _string_ a été construite, sa valeur ne peut jamais changer. Toutes les méthodes qui semblent modifier une _string_ renvoient en réalité une nouvelle _string_.

Plusieurs _strings_ peuvent être concaténées (ajoutées) entre elles. La façon la plus simple d'y parvenir est d'utiliser l'opérateur `+`.

```haxe
var name:String = "Jane";
trace("Hello " + name + "!");
// => "Hello Jane!"
```

Pour tout formatage de _string_ plus complexe qu'une simple concaténation, l'interpolation de _string_ est préférable. Pour utiliser l'interpolation dans une _string_, entoure-la de guillemets simples (`'`). Tu peux ensuite utiliser le signe dollar (`$`) pour déclencher l'interpolation :

```haxe
var name:String = "Jane";
trace('Hello $name!');
// => "Hello Jane!"
```
