# Exercism API

## Description

La plupart des parcours de langage d'Exercism utilisent l'outil en ligne de commande `exercism` pour récupérer et soumettre des exercices, outil qui dialogue avec `exercism.io` via une API REST. Le parcours de langage Pharo Smalltalk utilise quant à lui la même API REST pour faire entrer et sortir les exercices de l'image Pharo, sans passer par un outillage intermédiaire. Ce document détaille l'API d'Exercism en mettant l'accent sur la façon dont le parcours de langage Pharo Smalltalk l'utilise. Il s'adresse aux mainteneurs de l'outillage Pharo Smalltalk.

## En-têtes

Tous les points de terminaison exigent que les en-têtes de la requête soient définis avec les valeurs suivantes :

```
Authorization: Bearer <token>
```

La valeur `<token>` est le jeton d'authentification de la CLI de l'utilisateur, disponible à l'adresse `https://exercism.io/my/settings`.

## Récupère les exercices

```
Content-Type: application/json
```

`GET api.exercism.io/v1/solutions/latest?exercise_id=<slug>&track_id<language> HTTP/1.1`

Dans l'URL ci-dessus, `<slug>` est le nom de l'exercice, par exemple `hello-world`, et `<language>` est le parcours de langage, par exemple `pharo-smalltalk`.

### Réponse

#### 200

Une requête réussie renvoie une réponse contenant une charge utile JSON. Le JSON contient des informations sur l'exercice ainsi qu'une URL permettant de télécharger les fichiers de l'exercice.

```json
"solution":{
	"id":"<id-string>",
	"url":"https://exercism.io/my/solutions/<id-string>",
	"team":null,
	"user":{
		"handle":"<exercism-user-name>",
		"is_requester":true
		},
		"exercise":{
			"id":"isogram",
			"instructions_url":"https://exercism.io/my/solutions/<id-string>",
			"auto_approve":false,
			"track":{
				"id":"pharo-smalltalk",
				"language":"Pharo"
				}
			},
			"file_download_base_url":"https://api.exercism.io/v1/solutions/<id-string>/files/",
			"files":[
				"IsogramTest.class.st",
				"README.md"
				],
			"iteration":null
		}
	}
```

#### 400

Le nom du parcours de langage est ambigu, ou les fichiers d'exercice soumis n'ont pas changé.

#### 403

La solution n'est pas déverrouillée pour l'utilisateur, ou le parcours de langage n'a pas été rejoint.

#### 404

Le parcours de langage ou l'exercice est introuvable.

## Soumets les exercices

```
Content-Type: application/octet-stream
```

`PATCH api.exercism.io//v1/solutions/<some-kind-of-token-or-hash> HTTP/1.1`

### Réponse

#### 201

Une soumission réussie.

#### 400

Un fichier soumis est trop volumineux (plus d'un mégaoctet), ou la solution est un doublon.

#### 403

La solution n'est pas accessible à l'utilisateur. L'identifiant utilisateur de la solution et celui de l'utilisateur actuel ne correspondent pas.

#### 404

L'identifiant de la solution est introuvable.
