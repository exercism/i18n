# Introduction

Jongler avec la pile fait très bien l'affaire pour les mots courts. Quand un mot prend plusieurs entrées et qu'on a besoin de les désigner par leur nom, Factor propose les *locals* : des liaisons nommées introduites avec `::` (pour les définitions de mots) ou `[| | ]` (pour les lambdas en ligne), toutes deux issues de [`locals`][locals].

```factor
USING: locals ;

:: hypotenuse ( a b -- c )
    a a *
    b b *
    + sqrt ;
```

Dans une _quotation_, `[| inputs | body ]` est un lambda avec des entrées nommées :

```factor
USING: assocs locals ;

H{ { "a" 1 } { "b" 2 } }
[| key value | key value 10 * ] assoc-map .
! => H{ { "a" 10 } { "b" 20 } }
```

[locals]: https://docs.factorcode.org/content/vocab-locals.html
