# Indices

## 1. Trouve une carte dans le paquet

- Il existe une [méthode intégrée][index] qui permet de trouver le premier élément de la collection qui remplit la condition indiquée dans le bloc, et de renvoyer son indice ou `nil` si aucun élément n'est trouvé.

## 2. Mets tous les caractères en majuscules

- Il existe une [méthode intégrée][map] pour transformer tous les éléments de la collection.
- Il existe une [méthode intégrée][capitalize] pour mettre en majuscule les mots d'une `String`.

## 3. Calcule le niveau de puissance de toutes les cartes

- Tu peux utiliser la [méthode `sum`] pour calculer le niveau de puissance total de toutes les cartes.
- La méthode `sum` peut aussi accepter un bloc pour transformer les éléments avant de les additionner.

## 4. Décode une carte

- Il existe une [méthode intégrée][each_char_with_index] pour parcourir les caractères d'une `String` avec un indice.
