# Intervalles

Un [intervalle][range] représente l'ensemble des valeurs comprises entre deux valeurs.
Les types les plus courants qui prennent en charge les intervalles sont `Int`, `Char` et `String`.
Ils servent à beaucoup de choses : créer rapidement une collection, découper des _strings_, vérifier si une valeur se trouve dans un intervalle, ou encore itérer.
On les crée avec l'opérateur d'intervalle `..` ou `...` (respectivement inclusif et exclusif).

```crystal
1..5  # A range containing 1, 2, 3, 4, 5
1...5 # A range containing 1, 2, 3, 4
```

Ces deux opérateurs d'intervalle permettent de créer des intervalles qui incluent ou excluent la valeur de fin, ce qui peut être utile quand on travaille par exemple avec des indices commençant à zéro.

On peut aussi créer des intervalles avec l'initialiseur `Range`.

```crystal
Range.new(1, 5) # A range containing 1, 2, 3, 4, 5
```

~~~~exercism/note
Quand tu crées un intervalle en Crystal avec les opérateurs `..` ou `...` et que tu veux appeler une méthode dessus, il faut entourer l'intervalle de parenthèses.
Sinon, la méthode sera appelée sur le deuxième argument de l'opérateur d'intervalle.

```crystal
(1..5).size # => 5
1..5.size # => Error: undefined method 'size' for Int32
```
~~~~

## Récupère des sous-chaînes

Pour découper une _string_, on peut se servir de l'opérateur d'intervalle afin d'en extraire une sous-chaîne.
Il suffit de créer un intervalle avec l'indice de début et l'indice de fin de la sous-chaîne.

```crystal
"Hello World"[0..4] # => "Hello"
"Hello World"[6..10] # => "World"
```

On peut aussi utiliser des indices négatifs pour récupérer la sous-chaîne à partir de la fin de la _string_.

```crystal
"Hello World"[-5..-1] # => "World"
"Hello World"[6..-4] # => "Wo"
```

## Méthodes des intervalles

Les intervalles disposent d'un ensemble de méthodes pour les manipuler.
On peut par exemple s'en servir pour calculer la somme de toutes les valeurs de l'intervalle ou pour vérifier qu'il contient une valeur.

| Méthode                 | Description                                                             | Exemple                         |
|-------------------------|-------------------------------------------------------------------------|---------------------------------|
| [`sum`][sum]            | Renvoie la somme de toutes les valeurs de l'intervalle                  | `(1..5).sum # => 15`            |
| [`size`][size]          | Renvoie la taille de l'intervalle                                       | `(1..5).size # => 5`            |
| [`includes?`][indludes] | Renvoie `true` si l'intervalle contient la valeur donnée, sinon `false` | `(1..5).includes?(3) # => true` |

## Intervalles sans fin et sans début

Un intervalle peut être sans fin ou sans début.
Dans un intervalle sans fin ou sans début, la valeur de début ou de fin vaut `nil`, mais ce `nil` peut être omis au moment de définir l'intervalle.

Les intervalles sans début et sans fin sont pratiques quand on veut, par exemple, découper une _string_ depuis le début ou jusqu'à la fin.

```crystal
"Hello World"[0..] # => "Hello World"
"Hello World"[4..] # => "o World"
"Hello World"[..5] # => "Hello"
```

~~~~exercism/caution
S'il n'est pas utilisé sur une collection, un intervalle sans fin peut produire une séquence infinie s'il n'est pas employé avec prudence.
~~~~

## Intervalles de `Char`

On peut utiliser des `Char` dans les intervalles, ce qui permet d'obtenir un ensemble de caractères compris entre deux caractères.
C'est par exemple pratique quand on veut récupérer l'alphabet.

```crystal
'a'..'z' # A range containing ['a', 'b', 'c', ..., 'z']
```

## Intervalles de _strings_

On peut aussi utiliser des _strings_ dans les intervalles, ce qui permet d'obtenir un ensemble de _strings_ entre deux _strings_.
Leur comportement est toutefois légèrement différent de celui de `Char` quand on utilise plusieurs caractères dans un intervalle de _strings_.
Il peut devenir déroutant avec des intervalles de _strings_ plus complexes : reste donc prudent.

```crystal
("aa".."az") # A range containing ["aa", "ab", "ac", ..., "az"]
```
