# Indices

- La fonction `format` sera nécessaire pour cet exercice.

## 1. Formater des valeurs trimestrielles

- `format` renvoie toujours `nil`, sauf si le paramètre de flux vaut `nil`.
- `~A` permet de formater une valeur.

## 2. Le rapport de deux trimestres

- Ta fonction précédente est parfaite pour créer les deux lignes nécessaires.
- `~%` et `~&` permettent de créer des sauts de ligne.

## 3. Lisible pour un humain ou pour un extraterrestre Lisp

- Ta fonction de formatage des trimestres précédente est parfaite pour créer les _strings_ nécessaires.
- `~S` permet de formater des valeurs sous une forme lisible.
