# Classes avec état

```sather
class SCOREBOARD is

   attr home_team, away_team : STR;
   attr home_score, away_score : INT;

   create(home, away : STR) : SAME is
      board ::= new;
      board.home_team := home;
      board.away_team := away;
      return board;
   end;

   home_goal is home_score := home_score + 1; end;

end; -- class SCOREBOARD
```

## attr, readonly attr, private attr

| Écrit | Lu depuis l'extérieur | Modifié depuis l'extérieur |
| --- | --- | --- |
| `attr x : INT` | oui | oui |
| `readonly attr x : INT` | oui | non |
| `private attr x : INT` | non | non |

Par défaut, c'est `readonly` qu'il faut utiliser. Il laisse tout le monde voir le score et impose que toute modification passe par `home_goal`, qui est l'endroit où vivent les règles de score.

## create et new

`new` produit un objet de cette classe dont tous les attributs sont vides. Il ne peut être utilisé qu'à l'intérieur de la classe.

`create` est une routine ordinaire au nom convenu : `#C(args)` équivaut exactement à `C::create(args)`. Une classe peut en avoir plusieurs, que l'on distingue par leurs arguments, et une classe qui n'en a aucune ne peut tout simplement pas être créée avec `#`.

## SAME

`SAME` désigne la classe dans laquelle il est écrit. Dans `create`, c'est le type de retour ; il sert aussi dans un argument, et c'est lui qui fait qu'une routine héritée parle de la classe qui hérite plutôt que de celle dont elle vient.

## Les routines sans type de retour

```sather
   home_goal is
      home_score := home_score + 1;
   end;
```

Pas de `:` ni de type. Une telle routine s'appelle comme une instruction et ne peut pas apparaître dans une expression. C'est le signe que l'intérêt de l'appel réside dans le changement qu'il provoque.

## self

À l'intérieur d'une routine, `self` est l'objet sur lequel elle a été appelée. On l'écrit rarement, car un attribut ou une routine nommés seuls désignent déjà ceux de `self`. Il est nécessaire quand l'objet doit être transmis ou renvoyé :

```sather
   with_goal : SAME is
      home_score := home_score + 1;
      return self;
   end;
```

`self`, `new`, `void`, `result`, `value` et `out` sont tous des mots que Sather s'est réservés, et aucun ne peut être employé comme nom de ton choix.

## Référence, pas valeur

On accède à un objet par une référence. Deux noms pour le même tableau de score voient le même score :

```sather
   a ::= #SCOREBOARD("Vixens", "Magpies");
   b ::= a;         -- not a copy
   b.home_goal;
   a.home_score     -- 1
```

`immutable class`, que l'on verra plus tard, est la façon d'obtenir l'autre comportement.
