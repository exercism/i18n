# Introduction

C#, comme de nombreux langages à typage statique, propose un certain nombre de types qui représentent des entiers, chacun avec sa propre plage de valeurs. En bas de l'échelle, le type `sbyte` a une valeur minimale de -128 et une valeur maximale de 127. Comme pour tous les types entiers, ces valeurs sont accessibles via `<type>.MinValue` et `<type>.MaxValue`. En haut de l'échelle, le type `long` a une valeur minimale de -9 223 372 036 854 775 808 et une valeur maximale de 9 223 372 036 854 775 807. Entre les deux se trouvent les types `short` et `int`.

Les plages sont déterminées par la largeur de stockage du type, telle qu'allouée par le système. Par exemple, un `byte` occupe 8 bits et un `long` en occupe 64.

Chacun des types ci-dessus est associé à un équivalent non signé : `sbyte`/`byte`, `short`/`ushort`, `int`/`uint` et `long`/`ulong`. Dans tous les cas, la plage de valeurs va de 0 à la valeur maximale signée négative multipliée par 2, plus 1.

| Type   | Largeur | Minimum                    | Maximum                     |
| ------ | ------- | -------------------------- | --------------------------- |
| sbyte  | 8 bits  | -128                       | +127                        |
| short  | 16 bits | -32 768                    | +32 767                     |
| int    | 32 bits | -2 147 483 648             | +2 147 483 647              |
| long   | 64 bits | -9 223 372 036 854 775 808 | +9 223 372 036 854 775 807  |
| byte   | 8 bits  | 0                          | +255                        |
| ushort | 16 bits | 0                          | +65 535                     |
| uint   | 32 bits | 0                          | +4 294 967 295              |
| ulong  | 64 bits | 0                          | +18 446 744 073 709 551 615 |

Une variable (ou une expression) d'un type donné peut facilement être convertie en un autre type. Par exemple, dans une opération d'affectation, si le type de la valeur affectée (lhs) garantit que cette valeur restera dans la plage du type auquel on l'affecte (rhs), alors une simple affectation suffit :

```csharp
uint ui = uint.MaxValue;
ulong ul = ui;    // no problem
```

En revanche, si la plage du type source n'est pas un sous-ensemble de la plage de valeurs du type de destination, une opération de _cast_, `()`, est nécessaire, même si la valeur en question se trouve dans la plage du type de destination :

```csharp
short s = 42;
uint ui = (uint)s;
```
