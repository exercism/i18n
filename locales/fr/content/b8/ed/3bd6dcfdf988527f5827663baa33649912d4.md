# À propos

Parfois, on n'a pas besoin de la surcharge que représente la création d'un objet avec un état.
Dans ce cas-là, on peut utiliser un `module`.

Un module est très proche d'une classe (en fait, `Module` est le parent de `Classes` dans la hiérarchie des objets), la principale différence étant qu'au lieu d'utiliser des méthodes d'instance, on utilise des méthodes de classe.
Les méthodes de classe commencent par `self.` et sont appelées directement sur un module.

Par exemple :

```ruby
module Speaker
  def self.echo(something)
    "#{something} ... #{something}"
  end
end

Speaker.echo("Hello")   #=> "Hello ... Hello"
```
