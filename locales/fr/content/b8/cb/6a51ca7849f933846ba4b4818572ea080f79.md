# Instructions (suite)

## Indices

On peut considérer cette structure de données comme un [`Rose Tree`](https://en.wikipedia.org/wiki/Rose_tree).
On te fournit un type de données `'a tree` qui représente cette structure de données.

**Remarques**

- Pour cet exercice, `Empty` représente `null`
- La liste imbriquée est représentée par `List [...]`.
- L'exemple d'entrée est représenté par `List [Elem 1, List [Elem 2, Elem 3, Empty, Elem 4], List [Empty], Elem 5]`
