# Introduction

## Vrai et faux

Les états logiques vrai et faux sont représentés par `true` et `false` en Ruby.
On peut soit les utiliser seuls comme littéraux, soit les obtenir comme résultat de méthodes logiques ou de comparaison.

```ruby
happy = true
sad = false

true && false
# => false

1 < 2
# => true
```

## _Truthy_ et _falsey_

Lorsqu'on évalue des objets dans des instructions `if` ou dans d'autres contextes booléens, tous les objets sont considérés comme _truthy_, **sauf** `false` et `nil`.

## Flux de contrôle

Les évaluations _truthy_ et _falsey_ sont utiles dans le contexte du flux de contrôle.
Comme dans les langages procéduraux, Ruby dispose d'une construction `if`...`else`, mais il est souvent plus courant d'utiliser `if` comme instruction de « garde » pour modifier l'évaluation d'une expression.

```ruby
def falsey
  nil || false
end

def truthy
  not falsey
end

if truthy
  # this block is evaluated
end

if falsey
  # this block is not evaluated
else
  # this block is evaluated
end

1 + 1 if truthy
# this will evaluate and return 2

2 + 2 if falsey
# the numbers are not added because of the modifier, nil is returned
```

Ruby fournit `unless` pour rendre le code plus lisible.
Par exemple, au lieu de `eat_desert if not too_full`, on peut aussi écrire `eat_desert unless too_full`.

```ruby
3 + 3 unless truthy
# the numbers are not added because of the modifier, nil is returned

4 + 4 unless falsey
# this will evaluate and return 8
```
