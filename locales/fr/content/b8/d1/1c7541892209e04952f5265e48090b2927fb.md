# Complément aux instructions

## Indices

Le module Sgf doit exporter un module `parseSgf` avec la signature suivante :

```haskell
parseSgf :: Text -> Maybe (Tree (Map Text [Text]))
```

Tu trouveras peut-être utile de copier les définitions suivantes pour SgfTree
et SgfNode :

```haskell
-- | A tree of nodes.
type SgfTree = Tree SgfNode

-- | A node is a property list, each key can only occur once.
-- Keys may have multiple values associated with them.
type SgfNode = Map Text [Text]
```

La bibliothèque parsec fait partie de la Haskell Platform. N'hésite pas à
en tirer parti.
