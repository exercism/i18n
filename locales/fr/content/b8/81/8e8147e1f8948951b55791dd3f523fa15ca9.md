# Introduction

## Les booléens en Julia

Les valeurs vraies ou fausses sont représentées par le type `Bool`.
Il ne contient que deux valeurs : `true` et `false`.

```julia-repl
julia> true
true

julia> false
false
```

## Opérateurs booléens

Il existe trois opérateurs booléens en Julia.

`&&` est l'opérateur booléen ET.
Il s'évalue à `true` si les expressions des *deux* côtés de `&&` sont `true`.

```julia-repl
julia> true && true
true

julia> true && false
false
```

`||` est l'opérateur booléen OU.
Il s'évalue à `true` si *au moins une* des expressions de part et d'autre de `||` est `true`.

```julia-repl
julia> true || true
true

julia> false || true
true
```

`!` est l'opérateur booléen NON.
Il échange les valeurs `true` et `false`.

```julia-repl
julia> !true
false

julia> !false
true
```

Pour les expressions plus longues et plus compliquées, il vaut mieux utiliser des parenthèses pour que ton intention soit claire.

```julia-repl
julia> (true || false) && (false && true)
false
```
