# Introduction

En Cairo, une fonction permet de regrouper du code dans une unité réutilisable, ce qui rend tes programmes plus modulaires et plus faciles à comprendre.
Les fonctions en Cairo se composent du mot-clé `fn`, suivi du nom de la fonction, d'une liste de paramètres entre parenthèses et d'un bloc de code qui définit ce que fait la fonction.

## Paramètres de fonction

En Cairo, tous les paramètres de fonction doivent être typés explicitement.
Contrairement à certains langages, Cairo n'infère pas les types et il n'existe aucune valeur par défaut pour les paramètres, ce qui signifie que tous les paramètres sont obligatoires.

```rust
// Function with no parameters
fn print_hello() {
    // Function body
}

// Function with two parameters
fn print_greeting_name(greeting: ByteArray, name: ByteArray) {
    // Function body
}
```

## Paramètres et arguments

Il est important de bien distinguer les `parameters` des `arguments` :

- Les **paramètres** sont les noms de variables utilisés dans la définition de la fonction, comme `greeting` et `name` dans la fonction `print_greeting_name`.
- Les **arguments** sont les valeurs réellement transmises à la fonction au moment de son appel.

```rust
// Calling the function with arguments
print_greeting_name(123, 456)
```

## Instructions et expressions

Le corps d'une fonction se compose d'une série d'instructions, éventuellement suivies d'une expression.

- Les instructions réalisent une action et ne renvoient pas de valeur.
- Les expressions s'évaluent en une valeur résultante.

Créer une variable et lui affecter une valeur avec le mot-clé `let` est une instruction.

```rust
let y = 6;
```

Mais le `6` de l'instruction ci-dessus est une expression qui s'évalue en la valeur `6`.

Appeler une fonction est une expression, car cet appel s'évalue toujours en une valeur : la valeur de retour explicite de la fonction, si elle est spécifiée, ou le type _unit_ `()` dans le cas contraire.

## Valeurs de retour

Les fonctions en Cairo peuvent renvoyer des valeurs au code qui les appelle.
Les valeurs de retour sont listées après les paramètres, séparées par une flèche `->`.
En Cairo, la valeur de retour d'une fonction correspond à la valeur de la dernière expression du corps de la fonction.
Tu peux sortir d'une fonction de façon anticipée en utilisant le mot-clé `return` et en précisant une valeur.

```rust
// Function returning the last (and only) expression
fn hello(name: ByteArray) -> ByteArray {
    "Hello " + name
}

// Function returning using the `return` keyword
fn double_if_even(value: u32) -> u32 {
    if value % 2 == 0 {
        return value * 2;
    }
    return value;
}
```

## Appelle des fonctions

Pour appeler une fonction en Cairo, il suffit d'utiliser le nom de la fonction suivi des arguments entre parenthèses.

```rust
// Calling a function with no parameters
print_hello()

// Calling a function with one parameter
let greeting = hello("John")

// Calling a function with multiple parameters
print_greeting_name("Howdy", "Joel")
```
