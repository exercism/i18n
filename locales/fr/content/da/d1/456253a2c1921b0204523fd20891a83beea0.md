# Instructions complémentaires

## Notes d'implémentation

La suite de tests passe une instance de la classe Function aux méthodes `keep` et `discard` comme [argument de bloc][block-argument].
Pour réussir les tests, il te faudra appeler cette fonction dans ton code.
Si tu ne sais pas comment t'y prendre, consulte la [documentation de la classe Function][function-class].

[block-argument]: https://wren.io/functions.html#block-arguments
[function-class]: https://wren.io/modules/core/fn.html
