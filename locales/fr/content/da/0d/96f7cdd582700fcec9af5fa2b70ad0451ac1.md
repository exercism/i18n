# Introduction

La [forme spéciale with][with] permet de se concentrer sur le « happy path » d'une série d'étapes qui peuvent échouer, et de gérer les échecs plus tard.

```elixir
with {:ok, id} <- get_id(username),
     {:ok, avatar} <- fetch_avatar(id),
     {:ok, image_type} <- check_valid_image_type(avatar) do
  {:ok, image_type, avatar}
else
  :not_found ->
    {:error, "invalid username"}

  {:error, "not an image"} ->
    {:error, "avatar associated to #{username} is not an image"}

  err ->
    err
end
```

À chaque étape, si une clause correspond, la chaîne continue jusqu'à ce que le bloc `do` soit exécuté. Si une correspondance échoue, la chaîne s'arrête et la clause qui ne correspond pas est renvoyée. Tu as la possibilité d'utiliser un bloc `else` pour intercepter les correspondances qui ont échoué et modifier la valeur de retour.

[with]: https://hexdocs.pm/elixir/Kernel.SpecialForms.html#with/1
