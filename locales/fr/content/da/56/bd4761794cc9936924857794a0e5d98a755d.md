# Installation

Tu auras besoin d'accéder à une base de données Oracle montée. Si tu n'en as pas déjà une d'installée, voici quelques options :
* obtenir un espace de travail gratuit sur https://apex.oracle.com
* télécharger VirtualBox depuis Oracle et exécuter une des images librement disponibles ; au moment d'écrire ces lignes, la plus simple pour démarrer est peut-être _Database App Development VM_. L'image est assez volumineuse...
* télécharger et installer une version de la base de données Oracle elle-même. Les licences Developer sont gratuites.
