# Indices

## 1. Calcule le taux d’intérêt

- Par défaut, tout nombre à virgule flottante défini dans le code F# est traité comme un `float`. Pour utiliser un autre type à virgule flottante (comme `single` ou `decimal`), il faut ajouter le [suffixe][literals] approprié au nombre.

## 2. Calcule les intérêts

- Lorsqu’on calcule les intérêts, il peut être utile de convertir un solde négatif en solde positif. On peut utiliser l’arithmétique ici, ou [cette méthode](https://fsharp.github.io/fsharp-core-docs/reference/fsharp-core-operators.html#abs).

- La formule pour calculer les intérêts est : `(interest rate of balance / 100) * balance`

## 3. Calcule la mise à jour annuelle du solde

- Lorsqu’on calcule le rendement annuel, il peut être utile de convertir temporairement un solde négatif en solde positif. On peut utiliser l’arithmétique, ou l’une des [fonctions mathématiques][math-functions] intégrées.

- La formule pour calculer la mise à jour annuelle du solde est : `balance + interest of balance`

[literals]: https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/literals
[math-functions]: https://www.dotnetperls.com/math-fs

## 4. Calcule le montant à donner

- La formule pour calculer le montant à donner est :
  - Si le solde est inférieur ou égal à 0 : `0`
  - Si le solde est supérieur à 0 : `balance * (tax free percentage / 100 * 2)`
