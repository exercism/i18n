# À propos

`<iota>` de Factor produit une séquence *virtuelle* des entiers
`0, 1, …, n-1`. La parcourir avec `map` donne une séquence tabulée
où chaque élément est une fonction de sa position :

```factor
USING: math sequences ;

5 <iota> [ sq ] map .         ! => { 0 1 4 9 16 }
8 <iota> [ 1 + ] map .        ! => { 1 2 3 4 5 6 7 8 }
```

Deux éléments permettent de transformer une séquence de codes
entiers en _string_ :

| mot       | rôle                                                              |
|-----------|-------------------------------------------------------------------|
| `CHAR:`   | littéral résolu à l'analyse, qui empile le point de code d'un caractère |
| `>string` | convertit une séquence de points de code en _string_              |

Combinés, ils forment l'idiome standard pour construire une rangée
de caractères indexés par position :

```factor
USING: kernel math sequences strings ;

10 <iota> [ 2 mod zero? [ CHAR: O ] [ CHAR: . ] if ] map >string .
! => "O.O.O.O.O."
```

Choisir le caractère avec `if` (ou `?`) à l'intérieur de la _quotation_
garde la décision propre à chaque position près de l'indice dont elle dépend.
