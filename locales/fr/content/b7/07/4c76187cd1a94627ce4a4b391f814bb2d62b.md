# Tests

Un script Perl avec l'extension `.t` se trouve dans le répertoire `t/`, et il servira à tester ta solution.
Tu peux exécuter les tests à l'aide de la commande :

```bash
`prove`
```

La documentation sur les assertions utilisées dans les fichiers de test se trouve dans [Test2::Manual::Testing::Introduction][test2-manual].

[test2-manual]: https://metacpan.org/pod/Test2::Manual::Testing::Introduction
