# Instructions

Tu gères une boutique de mode en ligne. Ta grande vente annuelle approche, alors tu dois faire l'inventaire de ton stock pour t'assurer que tout est prêt.

Chaque article de l'inventaire est représenté par un dictionnaire, et l'inventaire entier est un tableau de ces dictionnaires.

```elixir
%{
  name: "White Shirt",
  price: 40,
  quantity_by_size: %{s: 3, m: 7, l: 8, xl: 4}
}
```

## 1. Trie les articles par prix

Implémente la fonction `sort_by_price/1`. Elle doit prendre l'inventaire et le renvoyer trié par prix des articles, par ordre croissant.

```elixir
BoutiqueInventory.sort_by_price([
  %{price: 65, name: "Maxi Brown Dress", quantity_by_size: %{}},
  %{price: 50, name: "Red Short Skirt", quantity_by_size: %{}},
  %{price: 50, name: "Black Short Skirt", quantity_by_size: %{}},
  %{price: 20, name: "Bamboo Socks Cats", quantity_by_size: %{}}
])

# => [
#      %{price: 20, name: "Bamboo Socks Cats", quantity_by_size: %{}},
#      %{price: 50, name: "Red Short Skirt", quantity_by_size: %{}},
#      %{price: 50, name: "Black Short Skirt", quantity_by_size: %{}},
#      %{price: 65, name: "Maxi Brown Dress", price: 65, quantity_by_size: %{}}
#    ]
```

## 2. Trouve tous les articles auxquels il manque un prix

Après avoir trié ton inventaire par prix, tu as remarqué que tu avais dû faire une erreur au moment de faire l'inventaire et oublier de renseigner le prix de quelques articles.

Implémente la fonction `with_missing_price/1`. Elle doit prendre l'inventaire et renvoyer un tableau des articles qui n'ont pas de prix.

```elixir
BoutiqueInventory.with_missing_price([
  %{price: 40, name: "Black T-shirt", quantity_by_size: %{}},
  %{price: nil, name: "Denim Pants", quantity_by_size: %{}},
  %{price: nil, name: "Denim Skirt", quantity_by_size: %{}},
  %{price: 40, name: "Orange T-shirt", quantity_by_size: %{}}
])

# => [
#      %{price: nil, name: "Denim Pants", quantity_by_size: %{}},
#      %{price: nil, name: "Denim Skirt", quantity_by_size: %{}}
#    ]
```

## 3. Mets à jour les noms des articles

Tu as remarqué que le nom de certains articles contient un mot que tu ne veux plus utiliser. Tu dois maintenant mettre à jour tous les noms d'articles qui contiennent ce mot.

Implémente la fonction `update_names/3`. Elle doit prendre l'inventaire, l'ancien mot que tu veux supprimer, et un nouveau mot que tu veux utiliser à la place. Elle doit renvoyer un tableau des articles avec les noms mis à jour.

```elixir
BoutiqueInventory.update_names(
  [
    %{price: 40, name: "Black T-shirt", quantity_by_size: %{}},
    %{price: 70, name: "Denim Pants", quantity_by_size: %{}},
    %{price: 65, name: "Denim Skirt", quantity_by_size: %{}},
    %{price: 40, name: "Orange T-shirt", quantity_by_size: %{}}
  ],
  "T-shirt",
  "Tee"
)

# => [
#      %{price: 40, name: "Black Tee", quantity_by_size: %{}},
#      %{price: 70, name: "Denim Pants", quantity_by_size: %{}},
#      %{price: 65, name: "Denim Skirt", quantity_by_size: %{}},
#      %{price: 40, name: "Orange Tee", quantity_by_size: %{}}
#    ]
```


## 4. Augmente la quantité de l'article

Certains articles se vendaient particulièrement bien, alors tu en as commandé davantage, dans toutes les tailles.

Implémente la fonction `increase_quantity/2`. Elle doit prendre un seul article et un nombre `n`, et renvoyer cet article avec la quantité de chaque taille augmentée de `n`.

```elixir
BoutiqueInventory.increase_quantity(
  %{
    name: "Polka Dot Skirt",
    price: 68,
    quantity_by_size: %{s: 3, m: 5, l: 3, xl: 4}
  },
  6
)

# => %{
#      name: "Polka Dot Skirt",
#      price: 68,
#      quantity_by_size: %{l: 9, m: 11, s: 9, xl: 10}
#    }
```

## 5. Calcule la quantité totale de l'article

Pour savoir de combien de place tu as besoin dans ton stockage, tu dois savoir combien tu as de pièces de chaque article au total.

Implémente la fonction `total_quantity/1`. Elle doit prendre un seul article et renvoyer combien tu as de pièces au total, toutes tailles confondues.

```elixir
BoutiqueInventory.total_quantity(%{
  name: "Red Shirt",
  price: 62,
  quantity_by_size: %{s: 3, m: 6, l: 5, xl: 2}
})

# => 16
```
