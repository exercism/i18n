# Introduction

En Haxe, les exceptions sont un moyen sûr de gérer les erreurs qui surviennent pendant l'exécution du code. Toutes les exceptions devraient contenir un message décrivant l'erreur. On peut _lever_ des exceptions à l'aide du mot-clé `throw` :

```haxe
public function main(num:Int) {
  if (num < 10) {
    throw "Argument num cannot be greater than 10";
  }
  // ...
}
```

Lorsqu'une exception est levée, le code cherche une portion de code chargée de gérer l'erreur. S'il n'en trouve pas, il affiche le message d'erreur tout en arrêtant l'exécution du programme.

Pour gérer les exceptions en Haxe, on utilise le bloc `try-catch`. Cette instruction se compose d'un bloc `try` et d'un ou plusieurs blocs `catch`. Le bloc `try` _essaie_ d'exécuter un morceau de code, tandis que le bloc `catch` se tient prêt à _attraper_ une exception éventuelle, afin que l'exécution ne soit pas interrompue. Lorsque le bloc `catch` attrape une exception, il exécute aussi tout ce qui se trouve à l'intérieur du bloc :

```haxe
try {
  if (num < 10) {
    throw "Argument num cannot be greater than 10";
  }
} catch (e) {
  // All exceptions will be caught here
  trace(e.message); // Argument num cannot be greater than 10
}
```

Le type de l'argument du bloc `catch` doit être omis.
