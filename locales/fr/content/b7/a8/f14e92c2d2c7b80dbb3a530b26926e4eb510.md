# Affichage

L'affichage en Cairo permet d'afficher des messages et des valeurs dans la console, ce qui facilite le débogage des programmes ou la transmission d'informations pendant l'exécution.

Le système d'affichage est à la fois polyvalent et simple : il fournit des outils pour formater et produire en sortie des données de types variés.

## Les bases de l'affichage

Cairo fournit deux macros principales pour afficher du texte dans la console :

- **`println!`** : affiche la sortie sur une nouvelle ligne.
- **`print!`** : affiche la sortie en ligne, sans ajouter de nouvelle ligne.

Les deux macros prennent un `ByteArray` comme argument principal, qui peut être une _string_ simple ou une _string_ formatée avec des marqueurs pour les valeurs.

```rust
// Printing a simple message
println!("Hello, Cairo!");

// Printing with values
let x = 10;
let y = 20;
println!("Values: x = {}, y = {}", x, y);
```

Dans l'exemple ci-dessus :

- Les marqueurs `{}` sont remplacés par les valeurs de `x` et `y`.
- `println!` garantit que la sortie se termine par une nouvelle ligne.

## Formate des _strings_

Il peut arriver que tu aies besoin de créer une _string_ formatée sans l'afficher tout de suite.

La macro `format!` permet de le faire.

Elle fonctionne comme `println!`, mais renvoie un `ByteArray` au lieu d'envoyer la sortie vers la console.

```rust
let s1: ByteArray = "tic";
let s2: ByteArray = "tac";
let s3: ByteArray = "toe";

// Create a formatted string
let result = format!("{s1}-{s2}-{s3}");

println!("{}", result); // Output: tic-tac-toe
```

Dans cet exemple :

- `format!` rassemble `s1`, `s2` et `s3` en une seule _string_, en les séparant par des tirets (`-`).
- La _string_ obtenue peut être réutilisée ou affichée plus tard.

## Affiche des types de données personnalisés

Par défaut, Cairo ne peut afficher que les types de base, comme les entiers et les _strings_.

Si tu essaies d'afficher un type personnalisé, comme une structure, tu obtiendras une erreur, à moins que ce type n'implémente les traits `Display` ou `Debug`.

### Utilise `Display` pour un formatage personnalisé

Le trait `Display` permet de définir comment un type personnalisé doit être affiché.

Voici un exemple :

```rust
use core::fmt::{Display, Formatter, Error};

struct Point {
    x: u8,
    y: u8,
}

impl PointDisplay of Display<Point> {
    fn fmt(self: @Point, ref f: Formatter) -> Result<(), Error> {
        write!(f, "Point({}, {})", *self.x, *self.y)
    }
}

let p = Point { x: 3, y: 4 };
println!("{}", p); // Output: Point(3, 4)
```

Dans cet exemple :

- La fonction `fmt` définit comment la structure `Point` est convertie en une _string_ affichable.
- La macro `write!` ajoute la _string_ formatée au `Formatter`.

### Débogue avec `Debug`

Pour le débogage, Cairo fournit le trait `Debug`.

Tu peux le dériver automatiquement pour la plupart des types, ce qui permet d'afficher rapidement et facilement les détails internes de tes structures.

```rust
#[derive(Debug)]
struct Point {
    x: u8,
    y: u8,
}

let p = Point { x: 3, y: 4 };
println!("{:?}", p); // Output: Point { x: 3, y: 4 }
```

Dans cet exemple :

- `#[derive(Debug)]` génère automatiquement l'implémentation du trait `Debug`.
- Le marqueur `{:?}` indique à `println!` d'utiliser le trait `Debug` pour le formatage.

## Affiche en hexadécimal

Cairo permet d'afficher les entiers au format hexadécimal grâce au marqueur `{:x}`.

```rust
let value: u32 = 255;
println!("{:x}", value); // Output: ff
```

C'est particulièrement utile lorsqu'on travaille avec des représentations de données de bas niveau.
