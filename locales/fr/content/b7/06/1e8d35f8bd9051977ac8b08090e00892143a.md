# Getters et setters

Les getters et les setters sont des méthodes qui permettent de lire et d'écrire la valeur d'une propriété d'un objet.
Crystal dispose de macros, ce qui permet de définir facilement des getters et des setters pour une propriété.
Les macros sont un moyen de générer du code à la compilation, ce que l'on verra plus tard dans le concept de macro.

En Ruby, ces méthodes sont définies à l'aide des méthodes `attr_reader`, `attr_writer` et `attr_accessor`, et ressemblent beaucoup, en apparence, à l'implémentation de Crystal.
Crystal les a définies sous forme de macros `getter`, `setter` et `property`.

## Getters

Le getter est une macro qui définit une méthode qui renvoie la valeur d'une variable d'instance.
Cela signifie que tu n'as plus besoin d'écrire `@` devant la variable d'instance quand tu veux y accéder (dans les méthodes, sauf dans initialize) ; à la place, tu peux appeler la méthode que la macro getter a définie.

La macro getter peut accepter plusieurs variables d'instance, à condition de les séparer par des virgules.

```crystal
# This:
class Person
  @name : String
  @age : Int32

  def name
    @name
  end

  def age
    @age
  end
end

# Is the same as this:
class Person
  @name : String
  @age : Int32

  getter name, :age
end
```

Comme tu peux le voir, utiliser getter réduit la quantité de code à écrire et le rend plus facile à lire.
De plus, Ruby et Crystal diffèrent sur un point : Crystal accepte à la fois le nom de la variable et le symbole comme arguments de la macro getter.
Les symboles seront abordés plus tard dans le concept de symbole.

## Setters

Le setter est une macro qui définit une méthode qui affecte la valeur d'une variable d'instance.
Cette macro est assez rare et c'est généralement la macro `property` qui est utilisée à la place.
Les méthodes qui seront créées ressembleront à `name_of_method=` ; c'est le `=` qui fait que la propriété peut être définie.

Cette définition de méthode est un peu particulière, car l'argument que la méthode reçoit se trouve après le signe `=`.
Plusieurs autres méthodes spéciales de Crystal utilisent cette syntaxe, comme la méthode `+`.

Comme pour la macro getter, quand tu veux mettre à jour la valeur d'une variable d'instance après avoir défini un setter, tu peux appeler la méthode que la macro setter a définie.

```crystal
# This:
class Person
  @name : String
  @age : Int32

  def name=(name : String)
    @name = name
  end

  def age=(age : Int32)
    @age = age
  end
end

# Is the same as this:
class Person
  @name : String
  @age : Int32

  setter name, :age
end
```

## Property

Property est une macro qui définit à la fois un getter et un setter pour une variable d'instance.

```crystal
class Person
  @name : String
  @age : Int32

  property name, :age
end
```
