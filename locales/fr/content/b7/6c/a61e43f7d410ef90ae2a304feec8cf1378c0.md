# Ajout
## Bonus

Préserve les grappes de graphèmes, c'est-à-dire

```julia
myreverse("hi 👋🏾") == "👋🏾 ih"
myreverse("as⃝df̅") == "f̅ds⃝a"
```

Pour ce bonus, la bibliothèque standard `Unicode` te sera sans doute utile.

Pour activer le test des graphèmes, ajoute `const TEST_GRAPHEMES = true` dans la portée globale de ton fichier.
