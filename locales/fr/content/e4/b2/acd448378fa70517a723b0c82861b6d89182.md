# Introduction

Kotlin est un langage de programmation **à typage statique** développé par JetBrains. Cela signifie que le type des variables est défini à la compilation.

## Variables

Comme dans les autres langages de programmation à typage statique, le type de chaque variable doit être défini à la compilation. Tu peux éviter les déclarations de type explicites quand le compilateur peut les déduire de leur contexte.

Kotlin a des variables immuables (`val`) et mutables (`var`). La valeur d'une variable immuable ne peut pas être modifiée après l'affectation de sa valeur initiale. La plupart du temps, tu utiliseras ce type de variable.

```kotlin
val robotName = "HAL-9000"
userId = "T-1000"  // This will not compile
```

La valeur d'une variable mutable peut être modifiée une ou plusieurs fois :

```kotlin
var index = 12
print(index)  // 12

index = 100
print(index)  // 100
```

Les points-virgules en Kotlin sont facultatifs, sauf dans quelques cas particuliers que l'on abordera plus tard.

## Fonctions

Les fonctions en Kotlin se définissent avec le mot-clé `fun` et sont des _citoyens de première classe_ (sans rapport avec la POO). Cela signifie que tu peux les déclarer (ce que l'on appelle des `top-level functions`) directement dans des fichiers (en Java, par exemple, tu ne peux définir des méthodes que dans des classes, pas dans des fichiers) :

```kotlin
// This is content of the Hello.kt file

fun hello() {}
```

Les fonctions peuvent recevoir des arguments. Chaque argument a un nom et un type. Contrairement aux variables, le type des arguments ne peut pas être déduit. Une fonction peut avoir zéro ou plusieurs arguments :

```kotlin
fun hello() {}

fun hello(name: String) {}

fun hello(name: String, age: Int) {}
```

Une fonction Kotlin peut renvoyer une valeur ou non :

```kotlin
fun min(a: Int, b: Int): Int

fun countBonuses(user: User): Bonuses

fun run() {}
```

Pour renvoyer une valeur depuis une fonction, on utilise le mot-clé `return` :

```kotlin
fun getName(): String {
    return "Alice"
}
```

Les fonctions peuvent avoir des paramètres avec des valeurs par défaut. Ces valeurs sont utilisées si elles sont omises là où la fonction est appelée :

```kotlin
fun ping(host: String = "localhost") {
    println("PING --> $host")
}

ping("exercism.io")  // PING --> exercism.io
ping()               // PING --> localhost
```

## Commentaires

Utilise `//` pour définir un commentaire sur une seule ligne :

```kotlin
foo() // Everything after `//` will be ignored by compiler

// I will be ignored too
```

ou `/*` et `*/` pour définir des commentaires sur plusieurs lignes :

```kotlin
/*
   This this an example
   for a multiline comment
*/
```
