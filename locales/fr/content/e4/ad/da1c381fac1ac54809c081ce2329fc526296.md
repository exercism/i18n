# type boxé inattendu

Utilise `${'literal.type'}` plutôt que le type boxé `${'boxed.type'}`. En TypeScript, les types `Object`, `Number`, `Boolean` et `String` désignent des objets boxés non primitifs, que l'on n'utilise presque jamais à bon escient dans du code TypeScript ou JavaScript. Pour en savoir plus sur le _boxing_, c'est [ici](https://en.wikipedia.org/wiki/Object_type_(object-oriented_programming)#Boxing).
