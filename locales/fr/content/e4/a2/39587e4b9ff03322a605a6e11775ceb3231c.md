# Introduction

Imagine que tu veuilles tous les entiers positifs ou nuls jusqu'à 1000.
Il serait ridicule de devoir les saisir un par un dans un tableau.

Pour cela, on dispose du type `range` :

```julia-repl
julia> 0:1000
0:1000

julia> typeof(0:1000)
UnitRange{Int64}
```

Les _ranges_ sont très courants : non seulement pour t'éviter de tout saisir, mais aussi comme types de retour des fonctions.

Note que les _ranges_ ne sont _pas_ des vecteurs.
Ce ne sont qu'un ensemble d'instructions permettant de générer une séquence (évaluation « paresseuse », ou un « itérateur »).

Si tu as besoin d'un _range_ sous forme de vecteur, utilise la fonction `collect()` pour le convertir :

```julia-repl
julia> collect(0:5)
6-element Vector{Int64}:
 0
 1
 2
 3
 4
 5
```

On peut préciser le pas, ici 0,3 :

```julia-repl
julia>  collect(1.0:0.3:2.0)
4-element Vector{Float64}:
 1.0
 1.3
 1.6
 1.9
```

La syntaxe est donc `start:stepsize:stop`.
Les deux bornes sont _incluses_, comme on le voit dans l'exemple avec des entiers.
Si le pas ne divise pas exactement `stop - start`, le dernier élément ne dépassera pas `stop`.

## Les _ranges_ de lettres

On peut aussi utiliser des séquences non numériques dans les _ranges_.
L'exemple le plus simple est celui des lettres ASCII :

```julia-repl
julia> 'a':'d'
'a':1:'d'

julia> typeof('a':'d')
StepRange{Char, Int64}

julia> collect('a':'d')
4-element Vector{Char}:
 'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)
 'b': ASCII/Unicode U+0062 (category Ll: Letter, lowercase)
 'c': ASCII/Unicode U+0063 (category Ll: Letter, lowercase)
 'd': ASCII/Unicode U+0064 (category Ll: Letter, lowercase)
```

Le type `Char` sera abordé plus en détail dans un autre concept.
Pour l'instant, considère simplement ces valeurs comme des caractères isolés entre apostrophes.

## Fonctions et opérateurs pour les _ranges_

Vérifie les bornes d'un _range_ avec `first()` et `last()`.

```julia
 r = 1:10  # => 1:10
 first(r)  # => 1
 last(r)   # => 10
```

## En savoir plus sur l'indexation des vecteurs

On peut indexer un vecteur avec des _ranges_ d'entiers ou avec un autre vecteur :

```julia
nums = collect(10.0:50.0)
nums[3:2:7]  # gives [12.0, 14.0, 16.0]
nums[ [3, 5, 7] ] # also gives [12.0, 14.0, 16.0]
```
