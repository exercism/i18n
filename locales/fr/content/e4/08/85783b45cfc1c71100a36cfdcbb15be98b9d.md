# À propos

Les types personnalisés sont la façon dont on définit de nouveaux types de données en Gleam. Ils peuvent avoir plusieurs _variantes_, chacune avec son propre nom.

```gleam
pub type Season {
  Spring
  Summer
  Autumn
  Winter
}
```

Chaque cas d'un type personnalisé peut éventuellement contenir des données, et différents cas peuvent contenir des données de types différents. Quand une variante contient des données, on parle d'un _record_.

```gleam
pub type Number {
  SomeInt(Int)
  SomeFloat(Float)
  Invalid
}
```

On peut créer une valeur pour un cas précis en faisant référence à son nom s'il ne contient pas de données supplémentaires (`Spring`), ou en l'appelant comme une fonction s'il en contient (`SomeInt(2)`).

```gleam
let spring = Spring
let integer_two = SomeInt(2)
```

Les types personnalisés, comme tout ce qui existe en Gleam, bénéficient de l'_égalité structurelle_, ce qui signifie que deux valeurs de la même variante et avec les mêmes données sont équivalentes.

```gleam
Spring == Spring // -> True
Spring == Autumn // -> False
SomeInt(2) == SomeInt(2) // -> True
SomeInt(2) == SomeFloat(2.0) // -> False
```

On peut faire de la correspondance de motifs sur les variantes d'un type personnalisé à l'aide d'expressions `case`.

```gleam
import gleam/int
import gleam/float

pub fn describe(flexible_number: Number) -> String {
  case flexible_number {
    SomeFloat(f) -> "Float: " <> float.to_string(f)
    SomeInt(i) -> "Int: " <> int.to_string(i)
    Invalid -> "Neither a float nor an int"
  }
}
```
