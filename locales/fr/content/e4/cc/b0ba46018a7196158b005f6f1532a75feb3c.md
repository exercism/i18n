# Instructions

Dans cet exercice, tu vas écrire du code pour aider une entreprise de panneaux à créer des messages personnalisés pour ses panneaux.

## 1. Construis un panneau pour une occasion

Implémente la fonction `buildSign(occasion, name)` qui prend une _string_ comme paramètre `occasion` et une _string_ contenant le nom d'une personne comme paramètre `name`.
Ces deux paramètres seront insérés dans un _template string_ pour produire le message du panneau.

```javascript
buildSign('Birthday', 'Rob');
// => "Happy Birthday Rob!"
```

## 2. Construis un panneau d'anniversaire

Implémente la fonction `buildBirthdaySign(age)` qui prend un âge et, selon cet âge, détermine une partie du message sur le panneau.
Si l'âge est de 50 ans ou plus, le panneau désignera la personne comme _mature_, sinon il la désignera comme _young_.
Le résultat attendu exact est montré ci-dessous :

```javascript
buildBirthdaySign(50);
// => "Happy Birthday! What a mature fellow you are."

buildBirthdaySign(45);
// => "Happy Birthday! What a young fellow you are."
```

## 3. Construis un panneau de remise de diplôme

Implémente la fonction `graduationFor(name, year)` qui prend un nom comme paramètre de type _string_ et une année comme paramètre de type nombre, et qui utilise l'interpolation de _strings_ pour créer une phrase destinée à un panneau, en utilisant un retour à la ligne pour séparer les deux lignes du message.

```javascript
graduationFor('Hannah', 2022);
/* => "Congratulations Hannah!
       Class of 2022"
*/
```

## 4. Calcule le coût d'un panneau

Implémente la fonction `costOf(sign, currency)` qui prend une _string_ contenant le contenu du panneau et une _string_ représentant la devise.
Le panneau a un prix de base de 20 dans la devise donnée. De plus, chaque lettre coûte 2. (Les espaces sont inclus dans le calcul.)
La phrase renvoyée inclut le coût de création du panneau, écrit avec deux chiffres après la virgule, suivi de la _string_ de la devise.

```javascript
costOf('Happy Birthday Rob!', 'dollars');
// => "Your sign costs 58.00 dollars."
```
