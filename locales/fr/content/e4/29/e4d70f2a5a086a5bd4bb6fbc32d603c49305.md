# Introduction

## Comparaison

En JavaScript, on peut comparer les nombres à l'aide des opérateurs relationnels et d'égalité suivants :

| Comparaison           | Opérateur |
| --------------------- | --------- |
| Supérieur à           | `a > b`   |
| Supérieur ou égal à   | `a >= b`  |
| Inférieur à           | `a < b`   |
| Inférieur ou égal à   | `a <= b`  |
| Égal (strict)         | `a === b` |
| Différent (strict)    | `a !== b` |

Le résultat d'une comparaison est toujours une valeur booléenne : `true` ou `false`.

```javascript
1 < 3;
// => true

2 !== 2;
// => false

1 === 1.0;
// => true
// All numbers are floating-points, so this is different syntax for
// the exact same value.
```

En JavaScript, les opérateurs de comparaison ci-dessus peuvent aussi servir à comparer des _strings_.
Dans ce cas, c'est l'ordre lexicographique (celui du dictionnaire) qui s'applique.
Tu peux trouver la liste de l'ordre exact de tous les caractères [ici][utf-16-list].

```javascript
'Apple' > 'Pear';
// => false

'a' < 'above';
// => true

'a' === 'A';
// => false
```

## Conditions

Une façon courante d'exécuter du code de manière conditionnelle en JavaScript est l'instruction `if`.
Elle se compose du mot-clé `if`, d'une condition entre parenthèses et d'un bloc de code entre accolades.
Le bloc de code n'est exécuté que si la condition vaut `true`.

```javascript
if (condition) {
  // code that is executed if "condition" is true
}
```

On peut l'utiliser seule ou la combiner avec le mot-clé `else`.

```javascript
if (condition) {
  // code that is executed if "condition" is true
} else {
  // code that is executed otherwise
}
```

Pour imbriquer une autre condition dans l'instruction `else`, tu peux utiliser `else if`.

```javascript
if (condition1) {
  // code that is executed if "condition1" is true
} else if (condition2) {
  // code that is executed if "condition2" is true
  // but "condition1" was false
} else {
  // code that is executed otherwise
}
```
