# À propos

Haxe propose deux types de nombres : les nombres entiers et les nombres décimaux.

- `Int` : Représente un nombre entier.
- `Float` : Représente un nombre à virgule flottante 64 bits à double précision.

```haxe
var integer:Int = 10;
var floating:Float = 5.4;
```

Alors que tout `Int` peut être utilisé là où un `Float` est attendu (c'est-à-dire que `Int` **est assignable à** ou **s'unifie avec** `Float`), l'inverse n'est pas vrai : l'affectation d'un `Float` à un `Int` peut entraîner une perte de précision et n'est donc pas autorisée implicitement.

## Comparaison

Deux nombres sont égaux s'ils ont la même valeur.

```haxe
1 == 1; // true

1.2 == 1.2; // true

1 == 1.0; // true

0.2 + 0.1 == 0.3 // false
```

Pour le dernier cas, voir [0.30000000000000004.com][0.30000000000000004.com] pour une brève explication.
