# Introduction

En Python, un [tuple][tuple] est une collection _immuable_ d'éléments en _séquence_.
Comme la plupart des collections, `tuples` peut contenir n'importe quel type (ou plusieurs types) de données, y compris d'autres `tuples`.
Les tuples prennent en charge toutes les [opérations courantes sur les séquences][common sequence operations], mais **ne prennent pas** en charge les [opérations sur les séquences mutables][mutable sequence operations].

On peut parcourir les éléments d'un tuple avec la construction `for item in <tuple>`.
Si l'on a besoin à la fois de l'indice et de la valeur d'un élément, on peut utiliser `for index, item in enumerate(<tuple>)`.
Comme pour toute séquence, on accède aux éléments d'un `tuples` via la _notation entre crochets_, en utilisant un indice `0-based index` en partant de la gauche ou un indice `-1-based index` en partant de la droite.
On peut aussi copier un tuple en entier ou en partie grâce à la notation de tranches (_`<tuple>[<start>:<stop>:<step>]`_).


## Construction d'un tuple

Un tuple peut être créé de plusieurs façons : soit avec le constructeur de classe `tuple(<iterable>)`, soit avec la déclaration littérale `tuple`.

### Utilise le constructeur `tuple()` à vide ou avec un _itérable_ :

```python
>>> no_elements = tuple()
()

# The constructor *requires* an iterable, so single elements must be passed in a list or another tuple.
>>> one_element = tuple([16])
(16,)
```

Les _strings_ sont itérables, donc utiliser une seule `str` comme argument du constructeur `tuple()` peut donner des résultats surprenants :

```python
# String elements (characters) are iterated through and added to the tuple
>>> multiple_elements_string = tuple("Timbuktu")
('T', 'i', 'm', 'b', 'u', 'k', 't', 'u')
```

Les éléments d'un itérable sont ajoutés un par un :

```python
>>> multiple_elements_list = tuple(["Parrot", "Bird", 334782])
("Parrot", "Bird", 334782)

>>> multiple_elements_set = tuple({2, 3, 5, 7, 11})
(2,3,5,7,11)
```

#### Déclare un tuple comme _littéral_ :

Comme le constructeur `tuple(<iterable>)` n'accepte que des _itérables_ (ou rien du tout) comme arguments, il est bien plus simple de créer un tuple à un seul élément avec la méthode littérale.

```python
>>> no_elements = ()
()

>>> one_element = ("Guava",)
("Guava",)
```

On peut inclure des structures de données imbriquées comme éléments d'un `tuple`, y compris d'autres `tuples` :

```python
>>> nested_data_structures = ({"fish": "gold", "monkey": "brown", "parrot" : "grey"}, ("fish", "mammal", "bird"))
({"fish": "gold", "monkey": "brown", "parrot" : "grey"}, ("fish", "mammal", "bird"))

>>> nested_data_structures_1 = (["fish", "gold", "monkey", "brown", "parrot", "grey"], ("fish", "mammal", "bird"))
(["fish", "gold", "monkey", "brown", "parrot", "grey"], ("fish", "mammal", "bird"))
```

## Concaténation de tuples

On peut concaténer des tuples avec l'opérateur plus `+`, qui décompose chaque `tuple` pour créer un nouveau `tuple` combiné.

```python
>>> new_via_concatenate = ("George", 5) + ("cat", "Tabby")
("George", 5, "cat", "Tabby")

#likewise, using the multiplication operator * is the equivalent of using + n times
>>> first_group = ("cat", "dog", "elephant")

>>> multiplied_group = first_group * 3
('cat', 'dog', 'elephant', 'cat', 'dog', 'elephant', 'cat', 'dog', 'elephant')
```

## Accéder aux éléments d'un tuple

On accède aux éléments d'un `tuple` via la _notation entre crochets_, en utilisant un indice `0-based index` en partant de la gauche ou un indice `-1-based index` en partant de la droite.

```python
student_info = ("Alyssa", "grade 3", "female", 8 )

#gender is at index 2 or index -2
>>> student_gender = student_info[2]
'female'

>>> student_gender = student_info[-2]
'female'

#name is at index 0 or index -4
>>> student_name = student_info[0]
Alyssa

>>> student_name = student_info[-4]
Alyssa
```

## Parcourir les éléments d'un tuple

On peut _parcourir_ les éléments d'un `tuple` dans une boucle avec la syntaxe `for item in <tuple>`.
Si l'on a besoin à la fois des indices et des valeurs, on peut utiliser `for index, item in enumerate(<tuple>)`.

```python
>>> student_info = ("Alyssa", "grade 3", "female", 8 )
>>> for item in student_info:
...   print(item)

...
Alyssa
grade 3
female
8

>>> for index, item in enumerate(student_info):
...  print("Index is: " + str(index) + ", value is: " + str(item) +".")

...
Index is: 0, value is: Alyssa.
Index is: 1, value is: grade 3.
Index is: 2, value is: female.
Index is: 3, value is: 8.
```

## Vérifier l'appartenance à un tuple

L'opérateur `in` permet de vérifier si une valeur appartient à un `tuple`.

```python
>>> multiple_elements_list = tuple(["Parrot", "Bird", 334782])
("Parrot", "Bird", 334782)

>>> "Parrot" in multiple_elements_list
True
```
