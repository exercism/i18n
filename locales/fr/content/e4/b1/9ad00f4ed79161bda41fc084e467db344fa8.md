# Ressources

## Modules

Perl est livré avec un ensemble de modules de base, que tu peux retrouver listés sur [perldoc](https://perldoc.perl.org/modules). En général, tu peux utiliser n'importe lequel de ces modules immédiatement. (Certaines distributions peuvent nécessiter l'installation séparée des modules de base).

[Awesome Perl](https://github.com/hachiojipm/awesome-perl) est une liste sélectionnée de modules utiles, qui renvoie aussi à une sélection d'autres listes de recommandations.

Il existe plusieurs installateurs de modules pour Perl, qui te permettront d'installer une grande variété de modules disponibles sur [CPAN](https://metacpan.org/).

### App::cpm
Un installateur de modules très rapide et simple.
Un tutoriel est disponible sur [CPAN](https://metacpan.org/pod/App::cpm::Tutorial).

Il sera déjà installé si tu as suivi les instructions `local::lib` de la [documentation d'installation](https://exercism.org/tracks/perl5/installation).

Il te suffit de lancer `cpm install` pour installer les modules requis depuis un `cpanfile`, et d'utiliser `--with-recommends` ou `--with-suggested` pour installer respectivement les modules recommandés ou suggérés.

Lance `cpm install Module::Name` pour installer un module précis localement, ou `cpm install -g Module::Name` pour l'installer globalement.

### App::cpanminus
L'installateur de modules le plus connu et le plus utilisé.
Les instructions d'installation se trouvent sur [CPAN](https://metacpan.org/pod/App::cpanminus).

Lance `cpanm -L local --installdeps .` pour installer les modules requis depuis un `cpanfile`.
Lance `cpanm -L local Module::Name` pour installer un module précis localement, ou `cpanm Module::Name` pour l'installer globalement.

## Style de code et analyse statique

Si tu cherches de bons conseils généraux sur la façon d'écrire du Perl, [Perl Best Practices][PBP] de Damian Conway est une bonne référence.

Pour rendre ton code plus présentable, tu peux utiliser le module [Perl::Tidy][PerlTidy].

Tu peux ensuite utiliser le programme utilitaire `perltidy` fourni pour reformater ton code.

    # modify file in-place and save old version as some_script.pl.bak
    $ perltidy -b some_script.pl

`perltidy` propose *énormément* d'options de configuration, pour tous les goûts. Elles sont documentées [ici][perltidyDocs].

Il existe aussi [tidyview], une interface visuelle qui te permet d'ajuster les différentes options et d'en voir immédiatement le résultat.

Si tu veux faire respecter des règles de codage, il y a aussi [Perl::Critic][perlcritic]. Il est livré avec les règles décrites dans le livre *Perl Best Practices* mentionné plus haut, mais il existe de nombreux plugins, et il peut être personnalisé pour s'adapter à n'importe quelles règles de codage internes.

Pour l'utiliser :

    $ perlcritic some_script.pl

L'outil a un très grand nombre de réglages de configuration ; consulte sa [documentation][perlcriticdocs] pour tout savoir à leur sujet.
