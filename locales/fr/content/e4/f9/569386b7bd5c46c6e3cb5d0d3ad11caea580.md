# À propos

`case` est l'aiguillage à choix multiples de Factor, fondé sur l'égalité. C'est le bon outil quand le choix repose sur l'égalité d'une *seule* valeur avec l'une de plusieurs alternatives, et non quand chaque branche a besoin d'un test différent (utilise `cond` pour cela).

```factor
USING: combinators ;

SYMBOLS: yes no maybe ;

: invert ( ?/maybe -- ?'/maybe )
    {
        { yes [ no ] }
        { no  [ yes ] }
        [ ]            ! default: leave value alone
    } case ;
```

Quelques points à ne pas confondre :

- L'égalité, c'est `=`. Tout ce que `=` accepte peut servir de clé : des nombres, des _strings_, des caractères, des symboles, et même des tuples.
- Les branches *correspondantes* voient la pile *sans* la valeur d'entrée. Les branches *par défaut*, elles, la voient encore au sommet.
- Une instruction `case` sans branche par défaut et sans clause correspondante lève une erreur.

`case` se compile en table de saut quand c'est possible : ce n'est donc pas qu'un simple sucre syntaxique pour une chaîne de `if`, c'est aussi rapide.
