# Introduction

Les tableaux sont les séquences de longueur fixe de Factor : tu peux modifier les éléments, mais pas la longueur. Tu sais déjà écrire un tableau littéral (`{ … }`), ainsi que le découper et l'agréger. Cet exercice présente la petite boîte à outils qui intervient quand on construit des tableaux à partir des valeurs présentes sur la pile, avant d'en consulter ou d'en réorganiser le contenu.

## Construis à partir de la pile

`1array`, `2array`, `3array` et `4array` (dans [`arrays`][arrays]) prennent 1, 2, 3 ou 4 valeurs au sommet de la pile et les regroupent :

```
1array ( a       -- { a }       )
2array ( a b     -- { a b }     )
3array ( a b c   -- { a b c }   )
4array ( a b c d -- { a b c d } )
```

```factor
42 1array .                ! => { 42 }
3 4 2array .               ! => { 3 4 }
"x" "y" "z" 3array .       ! => { "x" "y" "z" }
1 2 3 4 4array .           ! => { 1 2 3 4 }
```

## Concatène et joins

`concat` (dans [`sequences`][sequences]) prend une séquence dont les éléments sont eux-mêmes des séquences et les aplatit d'un niveau. `join` fait la même chose en insérant un séparateur entre chaque paire :

```
concat ( seqs     -- seq )
join   ( seqs sep -- seq )
```

```factor
{ { 1 2 } { 3 4 } { 5 } } concat .
! => { 1 2 3 4 5 }

{ "alpha" "beta" "gamma" } ", " join .
! => "alpha, beta, gamma"
```

## Inverse l'ordre

`reverse` renvoie une nouvelle séquence dont les éléments sont dans l'ordre opposé :

```
reverse ( seq -- newseq )
```

```factor
{ 1 2 3 4 } reverse .   ! => { 4 3 2 1 }
```

## Est-ce un tableau ?

`array?` (dans [`arrays`][arrays]) est le prédicat de type. Il vaut vrai pour toute valeur construite par `<array>`, `1array`/`2array`/..., ou un littéral de tableau `{ … }`, et faux pour tout le reste (y compris les vecteurs, les _strings_ et les autres séquences) :

```
array? ( obj -- ? )
```

```factor
{ 1 2 3 } array? .         ! => t
"hello" array? .           ! => f
V{ 1 2 3 } array? .        ! => f
```

## Cherche un élément

`index` renvoie la position du premier élément égal à la valeur d'entrée, ou `f` s'il n'est pas présent. `member?` renvoie simplement un booléen. Les deux prennent l'**élément en premier** et la **séquence en second**. `members` (dans [`sets`][sets]) renvoie les éléments *uniques* d'une séquence, c'est-à-dire l'opération de déduplication, et `all-unique?` (également dans `sets`) teste si la séquence ne contient déjà aucun doublon :

```
index       ( elt seq -- i/f )
member?     ( elt seq -- ? )
members     ( seq     -- uniques )
all-unique? ( seq     -- ? )
```

```factor
"b" { "a" "b" "c" } index .       ! => 1
"z" { "a" "b" "c" } index .       ! => f
"b" { "a" "b" "c" } member? .     ! => t
"z" { "a" "b" "c" } member? .     ! => f
{ 1 2 3 2 1 } members .           ! => { 1 2 3 }
{ 1 2 3 } all-unique? .           ! => t
{ 1 2 1 } all-unique? .           ! => f
```
