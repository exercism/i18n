# Instructions

En passionné d'échecs, tu veux écrire ta propre version du jeu.
Certes, il existe sans doute déjà plein d'implémentations d'échecs en ligne, mais la tienne sera unique !

Tu commences par implémenter un système de déplacement de base pour les pièces.

La partie d'échecs se joue sur un échiquier de huit cases de large et huit cases de long.
Les cases sont identifiées par une lettre et un nombre.

## 1. Définis les intervalles des rangs et des colonnes

Le jeu devra stocker les rangs de l'échiquier.
Les rangs sont les lignes de l'échiquier et sont numérotés de 1 à 8.

Le jeu devra aussi stocker les colonnes de l'échiquier.
Les colonnes sont identifiées par les lettres de A à H.

Définis les constantes `Chess::RANKS` et `Chess::FILES` qui stockent respectivement l'intervalle des rangs et celui des colonnes.

```crystal
Chess::RANKS
# => 1..8

Chess::FILES
# => 'A'..'H'
```

## 2. Vérifie si une case est valide

Le jeu devra vérifier si une case est valide.
Une case est valide si son rang et sa colonne se trouvent dans les intervalles des rangs et des colonnes.

Définis la méthode `Chess.valid_square?` qui prend les arguments `rank`, un entier représentant le rang, et `file`, un caractère représentant la colonne.
La méthode doit renvoyer `true` si le rang et la colonne sont dans les intervalles des rangs et des colonnes, et renvoyer `false` sinon.

```crystal
Chess.valid_square?(1, 'A')
# => true
```

## 3. Récupère le surnom du joueur

Le jeu devra récupérer le surnom du joueur.
Le surnom est constitué des deux premiers caractères du prénom du joueur et des deux derniers caractères de son nom de famille.
Le surnom doit être en majuscules.

Définis la méthode `Chess.nickname` qui prend les arguments `first_name`, une _string_ contenant le prénom du joueur, et `last_name`, une _string_ contenant son nom de famille.
La méthode doit renvoyer le surnom du joueur sous forme de _string_ en majuscules.

```crystal
Chess.nickname("John", "Doe")
# => "JOOE"
```

## 4. Crée le message de déplacement

Le jeu devra créer un message pour un déplacement, qui indique quel joueur s'est déplacé vers quelle case.
Le message doit utiliser le surnom du joueur et la case vers laquelle il s'est déplacé.
Le jeu doit aussi déterminer si le déplacement est valide en vérifiant que la colonne et le rang de la case se trouvent dans les intervalles des colonnes et des rangs.

Si le déplacement est valide, le message doit être : `"{nickname} moved to {square}"`
Si le déplacement n'est pas valide, le message doit être : `"{nickname} attempted to move to {square}, but that is not a valid square"`

Définis la méthode `Chess.move_message` qui prend les arguments `first_name`, une _string_ contenant le prénom du joueur, `last_name`, une _string_ contenant son nom de famille, et `square`, une _string_ contenant la case vers laquelle le joueur s'est déplacé.
La méthode doit renvoyer le message du déplacement sous forme de _string_.

```crystal
Chess.move_message("John", "Doe", "A1")
# => "JOOE moved to A1"
```
