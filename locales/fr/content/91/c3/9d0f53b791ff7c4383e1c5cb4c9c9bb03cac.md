# Instructions

Elyse, future magicienne, poursuit son entraînement.
On lui donnera plusieurs jeux de cartes dont elle a besoin pour réaliser ses tours.
Pour simplifier un peu les choses, elle n'utilise que les cartes de 1 à 10.
Elle n'a qu'un exemplaire de chaque carte, il n'y a pas de doublons dans ses jeux de cartes.

Dans cet exercice, utilise les méthodes de la bibliothèque Base de Julia pour analyser le contenu d'un tableau.

## 1. Détermine si une carte est présente

Elyse veut déterminer si une carte est présente dans le jeu, autrement dit si le jeu contient un nombre précis.

```julia-repl
julia> card = 3;

julia> has_card([2, 3, 4, 5], card)
true
```

## 2. Trouve la position d'une carte

Elyse veut connaître la position (l'indice) d'une carte dans le jeu.
Si la carte n'est pas dans le jeu, renvoie `nothing`.

```julia-repl
julia> card = 2;

julia> find_card([9, 7, 3, 2], card)
4
```

## 3. Détermine si chaque carte est paire

Elyse veut savoir si chaque carte est paire, autrement dit si chaque nombre du jeu est pair.

```julia-repl
julia> all_cards_even([2, 4, 6, 7])
false
```

## 4. Vérifie si le jeu contient une carte de valeur impaire

Elyse veut savoir s'il y a un nombre impair dans le jeu.

```julia-repl
julia> any_odd_cards([3, 2, 6, 4, 8])
true
```

## 5. Détermine la position de la première carte qui est paire

Elyse veut connaître la position de la première carte qui est paire.
S'il n'y a aucune carte paire dans le jeu, renvoie `nothing`.

```julia-repl
julia> first_even_card_idx([5, 2, 3, 1])
2
```

## 6. Récupère la première carte impaire du jeu

Elyse veut connaître la valeur de la première carte qui est impaire.
S'il n'y a aucune carte impaire dans le jeu, renvoie `nothing`.

```julia-repl
julia> first_odd_card([4, 2, 8, 7, 9])
7
```
