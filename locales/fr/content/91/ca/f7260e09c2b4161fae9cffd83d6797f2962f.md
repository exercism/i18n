# Debug

Quand un test échoue, un message s'affiche pour décrire ce qui n'a pas fonctionné et pour quelle entrée.
Tu peux aussi te servir du fait que la [sortie de la console][fmt-println] sera également affichée.
Pour écrire dans la console, utilise :

```go
import "fmt"
fmt.Println("Debug message")
```

[fmt-println]: https://pkg.go.dev/fmt#Println

Remarque : quand tu débogues avec l'éditeur en ligne, utiliser par exemple `fmt.Print` n'ajoute pas de retour à la ligne après la sortie, ce qui peut déclencher un bug dans `go test --json` et donner une sortie de test en désordre.
