# À propos

Les nombres à virgule flottante sont des nombres fractionnaires ou entiers qui comportent un point décimal (comme `3.14`, `-1.7`, `99.99`, `2048.0`)

En Common Lisp, le type float se subdivise en plusieurs sous-types, chacun ayant ses propres caractéristiques et sa propre précision : short-float, single-float, double-float et long-float.

Le sous-type short-float occupe généralement le moins de mémoire et offre la plus faible précision des quatre sous-types. Il convient aux situations où la consommation de mémoire est une contrainte, mais où une précision moindre est acceptable.

Le sous-type single-float offre un compromis entre consommation de mémoire et précision. On l'utilise couramment pour les calculs en virgule flottante d'usage général.

Le sous-type double-float offre une précision supérieure à celle de single-float et convient aux applications qui exigent des calculs plus précis, comme les calculs scientifiques et les simulations numériques.

Le sous-type long-float offre la précision la plus élevée des quatre sous-types, mais il peut demander plus de mémoire que les autres. On l'emploie généralement dans des applications spécialisées qui exigent des calculs extrêmement précis.

Ces sous-types permettent aux programmeurs Common Lisp de choisir le niveau de précision et de consommation de mémoire adapté aux besoins de leurs applications.

En règle générale, si tu ne manipules que des nombres entiers, privilégie les entiers, car ils ne souffrent pas de la même perte de précision que les nombres à virgule flottante au fil de nombreux calculs.

## Référence

```lisp
;; Rounding to the Nearest Whole Number
(round 3.14)  ; => 3
(round -3.14) ; => -3
(round 2.72)  ; => 3
(round -2.72) ; => -3

;; Rounding Towards Zero
(truncate 3.14)  ; => 3
(truncate -3.14) ; => -3
(truncate 2.72)  ; => 2
(truncate -2.72) ; => -2

;; Rounding Towards Negative Infinity
(floor 3.14)  ; => 3
(floor -3.14) ; => -4
(floor 2.72)  ; => 2
(floor -2.72) ; => -3

;; Rounding Towards Positive Infinity
(ceiling 3.14)  ; => 4
(ceiling -3.14) ; => -3
(ceiling 2.72)  ; => 3
(ceiling -2.72) ; => -2
```
