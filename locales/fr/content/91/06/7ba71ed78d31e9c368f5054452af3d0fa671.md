# Instructions

Il était une fois un programmeur excentrique qui vivait dans une étrange maison aux fenêtres à barreaux.
Un jour, il a accepté un contrat proposé par un site d'offres d'emploi en ligne pour construire un robot de fête.
Le robot est censé accueillir les gens et les aider à rejoindre leur place.
La première édition était très technique et montrait le manque d'interaction humaine du programmeur.
Certains de ces défauts se sont d'ailleurs retrouvés dans l'édition suivante.

## 1. Accueille un nouvel invité à la fête

Implémente la fonction `Welcome` pour renvoyer un message de bienvenue à partir du nom donné :

```go
Welcome("Christiane")
// => Welcome to my party, Christiane!
```

## 2. Accueille un nouvel invité à la fête dont c'est l'anniversaire aujourd'hui

Implémente la fonction `HappyBirthday` pour renvoyer un message d'anniversaire à partir du nom et de l'âge de la personne.
Malheureusement, le programmeur est un peu frimeur, alors le robot doit démontrer qu'il connaît l'anniversaire de chaque invité.

```go
HappyBirthday("Frank", 58)
// => Happy birthday Frank! You are now 58 years old!
```

## 3. Indique le chemin

Implémente la fonction `AssignTable` pour indiquer le chemin.
Elle prend 5 paramètres.

- Le nom du nouvel invité à accueillir (`string`)
- Le numéro de table (`int`)
- Le nom du voisin de table (`string`)
- La direction dans laquelle trouver la table (`string`)
- La distance jusqu'à la table (`float64`)

Le format exact du résultat est visible dans l'exemple ci-dessous.

Le robot indique le numéro de table sur 3 chiffres.
Si le nombre compte moins de 3 chiffres, on lui ajoute des zéros devant pour atteindre 3 chiffres (par exemple 3 devient 003).
Le robot indique aussi la distance de la table.
Heureusement, avec une précision limitée à 1 chiffre.

```go
AssignTable("Christiane", 27, "Frank", "on the left", 23.7834298)
// =>
// Welcome to my party, Christiane!
// You have been assigned to table 027. Your table is on the left, exactly 23.8 meters from here.
// You will be sitting next to Frank.
```
