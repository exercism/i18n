# À propos

Un `SYMBOL:` ne *contient* pas de valeur : ce n'est qu'un nom. La valeur vit dans un espace de noms, et le nom sert de clé pour y accéder.

```factor
USING: namespaces ;

SYMBOL: history

V{ } clone history set-global
"first event" history get-global push
"second event" history get-global push
history get-global .
! => V{ "first event" "second event" }
```

Deux portées :

- **globale** : s'écrit et se lit avec `set-global`, `get-global`, `change-global`. Les valeurs persistent pendant toute la durée de vie du processus.
- **dynamique** : s'écrit et se lit avec `set`, `get`, `change`. Les liaisons existent le temps d'une forme `with-variable`, ce qui permet au code extérieur d'« injecter » une valeur que voit le code intérieur sans avoir à modifier toutes les signatures entre les deux.

```factor
"verbose" log-level [
    log-level get .   ! => "verbose"
] with-variable
```

`SYMBOL:` et `SYMBOLS:` déclarent des symboles au moment du chargement du vocabulaire, ce qui en fait des références partageables d'un fichier à l'autre.
