# Instructions

Implémente un évaluateur pour un sous-ensemble très simple de Forth.

[Forth][forth] est un langage de programmation à base de pile.
Implémente un évaluateur très élémentaire pour un petit sous-ensemble de Forth.

L'évaluateur doit prendre en charge les mots suivants :

- `+`, `-`, `*`, `/` (arithmétique sur les entiers)
- `DUP`, `DROP`, `SWAP`, `OVER` (manipulation de pile)

L'évaluateur doit aussi prendre en charge la définition de nouveaux mots à l'aide de la syntaxe habituelle : `: word-name definition ;`.

Pour simplifier, le seul type de données que tu dois prendre en charge est les entiers signés d'une taille d'au moins 16 bits.

Tu dois appliquer les règles suivantes pour la syntaxe : un nombre est une suite d'un ou plusieurs chiffres (ASCII), un mot est une suite d'une ou plusieurs lettres, chiffres, symboles ou signes de ponctuation qui ne forment pas un nombre.
(Forth utilise probablement des règles légèrement différentes, mais c'est suffisamment proche.)

Les mots ne sont pas sensibles à la casse.

[forth]: https://en.wikipedia.org/wiki/Forth_%28programming_language%29
