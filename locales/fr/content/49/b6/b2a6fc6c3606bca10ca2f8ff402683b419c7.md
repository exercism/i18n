# Instructions

Dans cet exercice, tu joues avec un ami à un jeu où il faut deviner un nombre. Les règles sont simples : tu choisis secrètement un nombre entre `1` et `100`, et ton ami essaie de deviner lequel. Pour aider ton ami, tu réponds différemment selon la proximité entre la supposition et le nombre que tu as choisi (`42`). Voici les règles pour les différentes réponses :

- Si la supposition est `42` : « Correct »
- Si la supposition est `41` ou `43` : « So close »
- Si la supposition est inférieure à `41` : « Too low »
- Si la supposition est supérieure à `43` : « Too high »

Tu as quatre tâches pour coder les réponses aux suppositions.

## 1. Réponds à une supposition correcte

Implémente la fonction `reply` pour répondre à une supposition correcte :

```gleam
reply(42)
// -> "Correct"
```

## 2. Réponds à une supposition proche

Modifie la fonction `reply` pour répondre aux suppositions proches :

```gleam
reply(41)
// -> "So close"
```

## 3. Réponds aux suppositions trop basses

Modifie la fonction `reply` pour répondre aux suppositions trop basses :

```gleam
reply(25)
// -> "Too low"
```

## 4. Réponds aux suppositions trop hautes

Modifie la fonction `reply` pour répondre aux suppositions trop hautes :

```gleam
reply(88)
// -> "Too high"
```
