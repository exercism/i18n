# Instructions

Dans cet exercice, on va modéliser une balance.

## 1. Crée un état initial pour la balance

Une fois initialisée, la balance doit partir de ses réglages d'usine, qui diffèrent selon l'endroit où la machine est vendue.
La machine doit donc pouvoir être initialisée avec une précision et en précisant si elle utilise le système métrique ou le système impérial.

Implémente la méthode `WeighingMachine#initialize`, qui prend deux arguments : `precision`, qui est un `Int32`, et `metric`, qui est un `Bool`.
L'argument `metric`, lorsqu'il vaut `true`, signifie que la machine doit utiliser le système métrique ; sinon, elle doit utiliser le système impérial.
La méthode d'initialisation doit également affecter la valeur `0.0` à la variable d'instance `@weight`.

```crystal
precision = 3
metric = true
vm = WeighingMachine.new(precision, metric)
```

## 2. Permets à la balance d'avoir une précision

Pour répondre à des besoins différents, on permet de personnaliser chaque balance avec une précision (le nombre de chiffres après le séparateur décimal).

Implémente la méthode _getter_ `WeighingMachine#precision`, qui renvoie la précision de la balance.

```crystal
precision = 3
metric = true
vm = WeighingMachine.new(precision, metric)
vm.precision
# => 3
```

## 3. Permets de définir le poids sur la balance

Implémente la propriété `WeighingMachine#weight` pour permettre de lire _et_ de définir le poids :

```crystal
precision = 3
metric = true
wm = WeighingMachine.new(precision, metric)
wm.weight = 60.5
wm.weight
# => 60.5

wm.weigh
# => 60.5
```

## 4. Permets à la machine de basculer entre les unités métriques et impériales

Implémente la propriété `WeighingMachine#metric=` pour permettre de définir l'unité.
Elle doit accepter une valeur booléenne.

```crystal
precision = 3
metric = true
wm = WeighingMachine.new(precision, metric)
vm.weight = 60.5
wm.metric = false

vm.weigh
# => 133.377
```
