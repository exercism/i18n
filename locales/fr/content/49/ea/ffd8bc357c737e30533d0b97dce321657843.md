# Introduction

Ton amie Eliud a hérité d'une ferme de sa grand-mère Tigist.
Sa mamie était inventrice et avait tendance à construire les choses de manière inutilement compliquée.
Le poulailler possède un afficheur numérique qui montre un nombre encodé représentant les positions de tous les œufs qui pourraient être ramassés.

Eliud te demande d'écrire un programme qui affiche le nombre effectif d'œufs dans le poulailler.

L'encodage des informations de position se calcule comme suit :

1. Parcours les emplacements de ponte potentiels et note un `1` pour un œuf présent ou un `0` pour un emplacement vide.
2. Convertis le nombre de binaire en décimal.
3. Affiche le résultat sur l'afficheur.

Exemple 1 :

```text
Chicken Coop:
 _ _ _ _ _ _ _
|E| |E|E| | |E|

Resulting Binary:
 1 0 1 1 0 0 1

Decimal number on the display:
89

Actual eggs in the coop:
4
```

Exemple 2 :

```text
Chicken Coop:
 _ _ _ _ _ _ _ _
| | | |E| | | | |

Resulting Binary:
 0 0 0 1 0 0 0 0

Decimal number on the display:
16

Actual eggs in the coop:
1
```
