# Instructions

Il était une fois un programmeur excentrique qui vivait dans une étrange maison aux fenêtres munies de barreaux. Un jour, il accepta une mission proposée par un site d'offres d'emploi en ligne : construire un robot de fête. Le robot est censé accueillir les gens et les aider à rejoindre leur place. La première édition était très technique et trahissait le manque de contact humain du programmeur. Certains de ces traits se sont d'ailleurs retrouvés dans l'édition suivante.

## 1. Accueille un nouvel invité à la fête

Implémente la méthode `welcome` pour renvoyer un message d'accueil à partir du nom donné :

```crystal
PartyRobot.welcome("Christiane")
# => Welcome to my party, Christiane!
```

## 2. Accueille un nouvel invité dont c'est l'anniversaire aujourd'hui

Implémente la méthode `happy_birthday` pour renvoyer un message d'anniversaire à partir du nom et de l'âge de la personne.
Malheureusement, le programmeur aime un peu trop se mettre en avant, alors le robot doit démontrer qu'il connaît l'anniversaire de chaque invité.

```crystal
PartyRobot.happy_birthday("Frank", 58)
# => Happy birthday Frank! You are now 58 years old!
```

## 3. Indique le chemin

Implémente la fonction `assign_table` pour indiquer le chemin.
Elle doit accepter 5 paramètres.

- Le nom du nouvel invité à accueillir (`String`)
- Le numéro de la table (`Int`)
- Le nom du voisin de table (`String`)
- La direction où trouver la table (`String`)
- La distance jusqu'à la table (`Float64`)

Le format exact du résultat est visible dans l'exemple ci-dessous.

Le nom du voisin de table doit être réduit à la première et à la dernière lettre du nom.
Frank devient Fk, Christian devient Cn, et ainsi de suite.

Le robot indique le numéro de la table.
Le robot mentionne aussi la distance de la table.
Heureusement, avec une précision limitée à 1 chiffre.

```crystal
PartyRobot.assign_table("Christiane", "on the left", 27, 23.7834298, "Frank")
# =>
# Welcome to my party, Christiane!
# You have been assigned to table 27. Your table is on the left, exactly 23.8 meters from here.
# You will be sitting next to Fk.
```
