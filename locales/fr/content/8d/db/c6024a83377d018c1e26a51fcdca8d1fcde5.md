# Instructions

Étant donné une _string_ de chiffres, calcule le plus grand produit d'une sous-chaîne contiguë de chiffres de longueur n.

Par exemple, pour l'entrée `'1027839564'`, le plus grand produit pour une série de 3 chiffres est 270 (9 * 5 * 6), et le plus grand produit pour une série de 5 chiffres est 7560 (7 * 8 * 3 * 9 * 5).

Note que ces séries doivent seulement occuper des *positions adjacentes* dans l'entrée ; les chiffres n'ont pas besoin d'être *numériquement consécutifs*.

Pour l'entrée `'73167176531330624919225119674426574742355349194934'`, le plus grand produit pour une série de 6 chiffres est 23520.
