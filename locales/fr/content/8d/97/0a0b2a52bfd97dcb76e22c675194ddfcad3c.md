# Indices

## 1. Crée un nouveau résident

- Revois le [concept des _structs_](/tracks/go/concepts/structs) pour savoir comment créer des _structs_.

## 2. Valide les informations d'un résident

- La valeur zéro d'une _string_ est `""`.
- La valeur zéro d'une _map_ est `nil`.
- Revois le [concept des _maps_](/tracks/go/concepts/maps) pour savoir comment déterminer si une clé existe dans une _map_.

## 3. Supprime les informations d'un résident

- Un résident est considéré comme supprimé quand tous ses champs sont définis à leur valeur zéro.
- Revois le [concept des valeurs zéro](/tracks/go/concepts/zero-values) pour connaître la valeur zéro de chaque type Go.

## 4. Compte les résidents

- Revois le [concept de l'itération avec _range_](/tracks/go/concepts/range-iteration) pour savoir comment parcourir un _slice_.
