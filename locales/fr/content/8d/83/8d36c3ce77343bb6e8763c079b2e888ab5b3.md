# Instructions

Tu es un observateur d'oiseaux passionné, et tu notes combien d'oiseaux ont visité ton jardin chaque jour.

Tu as décidé de faire passer ton passe-temps à un niveau supérieur et de créer quelques outils qui t'aideront à suivre et à traiter les données.

Tu as choisi de stocker les données sous forme de tableau d'entiers.
Le premier nombre du tableau est le nombre d'oiseaux qui ont visité ton jardin aujourd'hui, le deuxième hier, et ainsi de suite.

```exercism/note
Dans une application réelle, tu devrais toujours utiliser les modules de base quand c'est possible. Cependant, dans le but d'apprendre la récursion, n'utilise aucune des fonctions de `List` dans cet exercice.
```

## 1. Vérifie combien d'oiseaux ont visité ton jardin aujourd'hui

Implémente la fonction `today`.
Elle prend un tableau contenant le nombre d'oiseaux observés chaque jour et renvoie le nombre d'oiseaux d'aujourd'hui.
Si le tableau est vide, elle doit renvoyer `Nothing`, sinon le nombre est enveloppé dans un `Just`.

```elm
BirdCount.today [2, 5, 1]
    -- Just 2
```

## 2. Incrémente le nombre d'oiseaux d'aujourd'hui

Implémente la fonction `incrementDayCount`.
Elle prend un tableau contenant le nombre d'oiseaux observés chaque jour et augmente de 1 le nombre d'oiseaux d'aujourd'hui.
Si le tableau est vide, renvoie `[1]`.

```elm
BirdCount.incrementDayCount [4, 0, 2]
    -- [5, 0, 2]
```

## 3. Vérifie s'il y a eu une journée sans oiseau

Implémente la fonction `hasDayWithoutBirds`.
Elle prend un tableau contenant le nombre d'oiseaux observés chaque jour.
Elle doit renvoyer `True` s'il y a eu au moins une journée où aucun oiseau n'est venu dans le jardin, et `False` sinon.

```elm
BirdCount.hasDayWithoutBirds [2, 0, 4]
    -- True

BirdCount.hasDayWithoutBirds [3, 8, 1, 5]
    -- False
```

## 4. Calcule le nombre total d'oiseaux venus

Implémente la fonction `total`.
Elle prend un tableau contenant le nombre d'oiseaux observés chaque jour et renvoie le nombre total d'oiseaux qui ont visité ton jardin depuis que tu as commencé à collecter les données.

```elm
BirdCount.total [4, 0, 9, 0, 5]
    -- 18
```

## 5. Calcule le nombre de journées chargées

Certaines journées sont plus chargées que d'autres.
Une journée chargée est une journée où cinq oiseaux ou plus ont visité ton jardin.

Implémente la fonction `busyDays`.
Elle prend un tableau contenant le nombre d'oiseaux observés chaque jour et renvoie le nombre de journées chargées.

```elm
BirdCount.busyDays [4, 5, 0, 0, 6]
    -- 2
```
