# À propos

Haxe est un langage fortement typé, mais son système de typage peut être contourné quand c'est nécessaire. Affecter une valeur à un nom s'appelle définir une variable. Une variable peut être définie soit en spécifiant explicitement son type, soit en laissant le compilateur Haxe inférer le type grâce au [mot-clé `var`](var). Ainsi, les deux définitions de variable suivantes sont équivalentes :

```haxe
var explicitVariable:Int = 10; // Explicitly typed
var implicitVariable = 10; // Implicit typed
```

On peut mettre à jour une variable à l'aide de l'opérateur `=` :

```haxe
var number = 0; // Initial value
number = 1; // Updated value
```

Le compilateur lèvera une erreur si l'on essaie d'affecter une valeur dont le type est différent de celui de la variable :

```haxe
var number = 1; // Variable number is of integer type
number = "Hello" // Error trying to assign a string to an integer variable
```

En Haxe, le code s'écrit généralement à l'intérieur d'une _fonction_, aussi appelée [_méthode_](method). Ces fonctions peuvent prendre des paramètres (arguments) et renvoyer des valeurs à l'aide du mot-clé `return`. Les fonctions s'invoquent avec la syntaxe `()`. Toutes les fonctions doivent avoir un type de retour.

```haxe
function add(x:Int, y:Int):Int {
  return x + y;
}
```

En Haxe, la portée est définie entre les caractères `{` et `}`.

Haxe prend en charge deux types de commentaires. Les commentaires sur une seule ligne sont précédés de `//` et les commentaires multilignes s'insèrent entre `/*` et `*/`.
