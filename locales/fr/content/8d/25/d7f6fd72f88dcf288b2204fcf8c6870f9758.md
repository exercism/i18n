# Instructions

Dans cet exercice, tu vas jouer avec une voiture télécommandée, pour laquelle tu as enfin économisé assez d'argent pour l'acheter.

Les voitures commencent avec une batterie pleine (100 %). Chaque fois que tu conduis la voiture avec la télécommande, elle parcourt 20 mètres et consomme un pour cent de la batterie. Le surnom de la voiture n'est pas connu avant sa création.

La voiture télécommandée possède un écran LED sophistiqué qui affiche deux informations :

- La distance totale qu'elle a parcourue, affichée sous la forme : `"<METERS> meters"`.
- La charge restante de la batterie, affichée sous la forme : `"Battery at <PERCENTAGE>%"`.

Si la batterie est à 0 %, tu ne peux plus conduire la voiture et l'affichage de la batterie affichera `"Battery empty"`.

## 1. Crée une toute nouvelle voiture télécommandée

Implémente la fonction `RemoteControlCar.new/0` pour renvoyer une toute nouvelle structure de voiture télécommandée :

```elixir
RemoteControlCar.new()
# => %RemoteControlCar{
#      battery_percentage: 100,
#      distance_driven_in_meters: 0,
#      nickname: "none"
#    }
```

Le surnom est requis par la structure ; assure-toi qu'une valeur est initialisée dans la fonction `new`, mais pas dans la structure.

## 2. Crée une toute nouvelle voiture télécommandée avec un surnom

Implémente la fonction `RemoteControlCar.new/1` pour renvoyer une toute nouvelle structure de voiture télécommandée avec un surnom fourni :

```elixir
RemoteControlCar.new("Blue")
# => %RemoteControlCar{
#      battery_percentage: 100,
#      distance_driven_in_meters: 0,
#      nickname: "Blue"
#    }
```

## 3. Affiche la distance

Implémente la fonction `RemoteControlCar.display_distance/1` pour renvoyer la distance telle qu'affichée sur l'écran LED :

```elixir
car = RemoteControlCar.new()
RemoteControlCar.display_distance(car)
# => "0 meters"
```

Assure-toi que la fonction n'accepte qu'une structure `RemoteControlCar` comme argument.

## 4. Affiche le pourcentage de batterie

Implémente la fonction `RemoteControlCar.display_battery/1` pour renvoyer le pourcentage de batterie tel qu'affiché sur l'écran LED :

```elixir
car = RemoteControlCar.new()
RemoteControlCar.display_battery(car)
# => "Battery at 100%"
```

Assure-toi que la fonction n'accepte qu'une structure `RemoteControlCar` comme argument. Si la batterie est à 0 %, l'affichage de la batterie affichera "Battery empty".

## 5. La conduite modifie la batterie et la distance parcourue

Implémente la fonction `RemoteControlCar.drive/1` qui :

- augmente de 20 le nombre de mètres parcourus
- consomme 1 % de la batterie

```elixir
RemoteControlCar.new("Red")
|> RemoteControlCar.drive()

# => %RemoteControlCar{
#      battery_percentage: 99,
#      distance_driven_in_meters: 20,
#      nickname: "Red"
#    }
```

Assure-toi que la fonction n'accepte qu'une structure `RemoteControlCar` comme argument.

## 6. Prends en compte la conduite avec une batterie à plat

Mets à jour la fonction `RemoteControlCar.drive/1` pour qu'elle n'augmente pas la distance parcourue et ne diminue pas le pourcentage de batterie lorsque la batterie est déchargée (à 0 %) :

```elixir
%RemoteControlCar{
  battery_percentage: 0,
  distance_driven_in_meters: 1980,
  nickname: "Red"
}
|> RemoteControlCar.drive()

# => %RemoteControlCar{
#      battery_percentage: 0,
#      distance_driven_in_meters: 1980,
#      nickname: "Red"
#    }
```
