# Indices

## Général

- `if-empty` de [`sequences`][sequences] est le bon cas de base pour la récursion : une branche pour la séquence vide, l'autre pour la non vide.
- `unclip` est exactement ce dont une fonction auxiliaire récursive a besoin pour consommer un élément, puis s'appeler récursivement sur le reste.

## 1. Le comptage du jour

- Le comptage du jour correspond au premier élément. `if-empty` te donne le cas vide gratuitement.

## 2. Incrémenter le comptage du jour

- `unclip 1 + prefix` détache le premier élément, l'incrémente, puis le recolle.

## 3. Y a-t-il eu un jour sans oiseaux ?

- Deux conditions d'arrêt et une étape récursive : `cond` avec les prédicats `dup empty?` et `dup first zero?`, puis une branche par défaut qui applique `rest` à la séquence et poursuit la récursion.

## 4. Le total d'oiseaux depuis le début

- Cas de base : la somme d'une séquence vide vaut `0`.
- Cas récursif : `unclip swap total +` détache le premier élément, poursuit la récursion sur le reste, puis additionne.

## 5. Les journées chargées

- Cas de base : une séquence vide compte `0` journée chargée.
- Cas récursif : détache le premier comptage avec `unclip`, compare-le à `5`, poursuis la récursion sur le reste, puis ajoute `1` si la journée était chargée.
