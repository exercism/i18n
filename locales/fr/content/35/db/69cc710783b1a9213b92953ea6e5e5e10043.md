# gofmt non utilisé

Lance `gofmt` sur la solution, ce qui aide à formater le code en Go.

Le formatage du code en Go est très important pour la communauté.
La plupart des IDE peuvent être configurés pour formater automatiquement le code à chaque enregistrement. Par exemple :

- Visual Studio Code bénéficie d'un [excellent support de Go](https://code.visualstudio.com/docs/languages/go)
- Vim dispose aussi d'une [fantastique extension Go](https://github.com/fatih/vim-go)
- [Jetbrains Goland](https://www.jetbrains.com/go/) est un IDE complet dédié à Go

Pour lancer `gofmt` manuellement :

```bash
# will only show the differences
gofmt -d filename.go

# will apply the changes
gofmt -w filename.go
```

```git
%{gofmt}
```
