# Indices

## 1. Calcule le taux d'intérêt

- Utilise une expression conditionnelle comme instruction [`if`][if] et compare `balance` aux différentes plages.
- On peut utiliser le mot-clé `return` pour effectuer un retour anticipé depuis une méthode.

## 2. Calcule les intérêts

- Lorsqu'on calcule les intérêts, il peut être utile de remarquer que `interest_rate` renvoie un pourcentage.

## 3. Calcule la mise à jour annuelle du solde

- Lorsqu'on calcule la mise à jour annuelle du solde, on peut utiliser les méthodes que l'on a définies dans les étapes précédentes.

## 4. Calcule le nombre d'années avant d'atteindre le solde souhaité

- Pour calculer le nombre d'années, on peut continuer à boucler jusqu'à ce que le solde souhaité soit atteint. Cela peut se faire avec une boucle [`while`][while].

[if]: https://crystal-lang.org/reference/latest/syntax_and_semantics/if.html
[while]: https://crystal-lang.org/reference/latest/syntax_and_semantics/while.html
