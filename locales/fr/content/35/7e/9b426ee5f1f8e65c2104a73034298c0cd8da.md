# Intégrations de Babashka dans les éditeurs de texte

## nREPL

### Emacs : [CIDER](https://cider.mx/)

C'est celui qui a tout lancé, et son écosystème [Orchard](https://metaredux.com/posts/2018/11/09/ciders-orchard-the-heart.html) alimente bon nombre des autres extensions.

1. Installe [Emacs](https://www.gnu.org/software/emacs/download.html) pour ta plateforme.

2. Choisis une distribution Emacs existante ([Prelude](https://prelude.emacsredux.com/), [Spacemacs](https://www.spacemacs.org/) et [Doom Emacs](https://github.com/hlissner/doom-emacs) sont toutes excellentes) ou ajoute ceci à ton `init.el` :

```elisp
(unless (package-installed-p 'cider)
  (package-install 'cider))
  
(add-hook 'clojure-mode-hook #'cider-mode)
```

Résumé de la [documentation de CIDER](https://docs.cider.mx/cider/platforms/babashka.html) :

Démarre le serveur nREPL depuis le répertoire du projet :

```bash
$ bb --nrepl-server
```

Crée ou ouvre n'importe quel fichier Clojure (`.clj`) avec `C-x C-f` et connecte-toi avec `C-c C-x c j` (cider-connect-clj).

Les [raccourcis CIDER de base](https://docs.cider.mx/cider/usage/cider_mode.html#key-reference) :

* `cider-load-buffer` - `C-c C-k`
* `cider-eval-last-sexp` - `C-x C-e` ou `C-c C-e`
* `cider-eval-defun-at-point` - `C-M-x` ou `C-c C-c`

### VSCode : [Calva](https://github.com/BetterThanTomorrow/calva)

1. Installe [VSCode](https://code.visualstudio.com/).

2. Installe [Calva](https://marketplace.visualstudio.com/items?itemName=betterthantomorrow.calva).

Pour l'instant, Calva considère que ton code source s'inscrit dans le contexte d'un dossier, c'est-à-dire un projet Clojure. Une bonne façon d'en créer un est d'utiliser [clj-new](https://github.com/seancorfield/clj-new) :

```bash
$ clj -A:new lib myorg/bbtest
Generating a project called bbtest based on the 'lib' template.
The lib template is intended for library projects, not applications.
```
3. Démarre le serveur nREPL depuis le répertoire du projet :

```bash
$ cd bbtest
bbtest$ bb --nrepl-server 1667
Started nREPL server at localhost:1667
For more info visit https://github.com/borkdude/babashka/blob/master/doc/repl.md#nrepl.
```

Ouvre le dossier du projet dans VSCode (Ctrl+K Ctrl+O) ou depuis un autre terminal :

```bash
$ cd bbtest
bbtest$ code .
```

4. Dans VSCode, exécute la commande Calva `Connect to a running REPL` (ctrl+alt+c ctrl+alt+c). Lorsque l'on te le demande, choisis le projet `Generic` et saisis `localhost:1667`.

Commandes REPL :

* `Load Current File and Dependencies` ctrl+alt+c enter
* `Evaluate Current Form Inline` ctrl+alt+c e
* `Evaluate Current Top Level Form (defun)` ctrl+alt+c space

### IntelliJ : [Cursive](https://cursive-ide.com/)

1. Télécharge IntelliJ [ici](https://www.jetbrains.com/idea/download/index.html).
2. Installe Cursive en suivant le [guide d'utilisation](https://cursive-ide.com/userguide/) et [configure les dépendances](https://cursive-ide.com/userguide/deps.html).
3. Consulte [Cursive : travailler avec Babashka](https://cursive-ide.com/userguide/babashka.html) pour plus d'informations.

## Socket REPL

### Atom : [chlorine](https://github.com/mauricioszabo/atom-chlorine)

1. Installe [atom](https://flight-manual.atom.io/getting-started/sections/installing-atom/)

2. Installe le paquet `chlorine`

3. Démarre le REPL socket :

 ```
$ bb --socket-repl 1666
Babashka socket REPL started at localhost:1666
 ```

4. Ouvre la palette de commandes d'Atom (ctrl+shift+p) et exécute la commande `Connect Clojure Socket REPL` avec `localhost` `1666`

5. Modifie les raccourcis clavier dans keymap.cson via le menu `Edit` -> `Keymap...` :

```
'atom-text-editor[data-grammar="source clojure"]':
  'ctrl-; y':       'chlorine:connect-clojure-socket-repl'
  'ctrl-; e':       'chlorine:disconnect'
  'ctrl-; k':       'chlorine:clear-console'
  'ctrl-shift-enter':       'chlorine:load-file'
  'ctrl-enter':       'chlorine:evaluate-block'
  'shift-enter':       'chlorine:evaluate-top-block'
  'ctrl-; i':       'chlorine:inspect-block'
  'ctrl-; I':       'chlorine:inspect-top-block'
  'ctrl-; s':       'chlorine:evaluate-selection'
  'ctrl-; c':       'chlorine:break-evaluation'
  'ctrl-; S':       'chlorine:source-for-var'
  'ctrl-; d':       'chlorine:doc-for-var'
  'ctrl-; x':       'chlorine:run-tests-in-ns'
  'ctrl-; t':       'chlorine:run-test-for-var'
```

### Emacs : [inf-clojure](https://github.com/clojure-emacs/inf-clojure)

Pour Emacs, installe [inf-clojure](https://github.com/clojure-emacs/inf-clojure) en ajoutant ceci à ton `init.el` :

```
(unless (package-installed-p 'inf-clojure)
  (package-refresh-contents)
  (package-install 'inf-clojure))

(add-hook 'clojure-mode-hook #'inf-clojure-minor-mode)
```

Démarre le REPL socket comme ci-dessus, puis dans Emacs exécute `M-x inf-clojure-connect` (C-c M-c).

Évalue les formes avec C-c C-e. Pour obtenir la liste de toutes les commandes disponibles dans inf-clojure-mode (aussi appelé le REPL) et inf-clojure-minor-mode, tu peux soit invoquer C-h f RET inf-clojure-mode et C-h f RET inf-clojure-minor-mode, soit simplement parcourir leurs menus.

### Vim : [vim-iced](https://github.com/liquidz/vim-iced)

Télécharge l'[appimage Neovim](https://github.com/neovim/neovim/releases/download/v0.4.3/nvim.appimage) et crée un alias vers `vim`.

* Installe [vim-plug](https://github.com/junegunn/vim-plug) :

```
$ curl -fLo ~/.local/share/nvim/site/autoload/plug.vim --create-dirs \
    https://raw.githubusercontent.com/junegunn/vim-plug/master/plug.vim
```

Crée `~/.config/nvim/init.vim` :

```
call plug#begin('~/.vim/plugged')

Plug 'liuchengxu/vim-clap'
Plug 'guns/vim-sexp',    {'for': 'clojure'}
Plug 'liquidz/vim-iced', {'for': 'clojure'}

call plug#end()

" Enable vim-iced's default key mapping
" This is recommended for newbies
let g:iced_enable_default_key_mappings = v:true
```

Ouvre Neovim et lance la commande `:PlugInstall`.

Ajoute la commande `iced` au $PATH :

`$ export PATH=$PATH:~/.vim/plugged/vim-iced/bin`

* Démarre le serveur REPL socket, ouvre le fichier source et exécute `:IcedConnectSocketRepl 1666`.

Commandes REPL par défaut (le `<Leader>` par défaut est `\`) :

- `<Leader>ei` : Évalue l'élément interne
- `<Leader>ee` : Évalue la liste externe
- `<Leader>et` : Évalue la liste externe de premier niveau
