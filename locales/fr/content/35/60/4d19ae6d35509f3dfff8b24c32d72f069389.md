# Introduction

Quand une _quotation_ a besoin de *se souvenir* de valeurs de son environnement, ce que d'autres langages appellent une _closure_, Factor utilise deux outils : le mot `curry` et la syntaxe *fry* `'[ ]`.

## `curry` : capturer une valeur

`curry` (dans [`kernel`][kernel]) prend une valeur et une quotation et renvoie une nouvelle quotation avec cette valeur incorporée :

```
curry ( value quot -- newquot )
```

```factor
3 [ + ] curry .
! => [ 3 + ]

10 3 [ + ] curry call .
! => 13
```

Applique `curry` deux fois pour capturer deux valeurs :

```factor
2 3 [ + + ] curry curry .
! => [ 2 3 + + ]
```

## `compose` : assembler deux quotations

`compose` (dans [`kernel`][kernel]) colle deux quotations ensemble :

```
compose ( quot1 quot2 -- quot )
```

```factor
[ 1 + ] [ 2 * ] compose .
! => [ 1 + 2 * ]

5 [ 1 + ] [ 2 * ] compose call .
! => 12
```

## Les quotations fry : capturer plusieurs valeurs

Au-delà d'une ou deux captures, les appels enchaînés à `curry` deviennent difficiles à lire. La syntaxe *fry* utilise `'[ … ]` avec un ou plusieurs `_` comme emplacements réservés ; chaque `_` est remplacé par une valeur prise sur la pile de données, dans l'ordre :

```factor
2 3 '[ _ _ + + ] .
! => [ 2 3 + + ]
```

`curry` comme la syntaxe fry *consomment* leurs valeurs sur la pile au moment où la closure est construite. La ligne ci-dessus ne laisse rien sur la pile et remplace directement `[ + + ] curry curry`.

Les emplacements sont remplis de gauche à droite avec les valeurs de la pile du bas vers le haut : `2 3 '[ _ _ ]` donne `[ 2 3 ]`, et non `[ 3 2 ]`.

La syntaxe fry atteint aussi l'intérieur des quotations imbriquées, ce qui permet de placer les valeurs capturées exactement là où on le souhaite :

```factor
2 '[ [ _ > ] filter ] { 1 2 3 4 5 } swap call( s -- s ) .
! => { 3 4 5 }
```

Le `_` se trouve à l'intérieur du `[ … ]` interne, mais fry le remplit quand même.

## `call` avec un effet déclaré

Quand on finit par exécuter une quotation mémorisée, on déclare son effet de pile sur `call` pour que le compilateur puisse en vérifier les types :

```factor
{ 3 4 5 } [ first2 + ] call( p -- n ) .
! => 7

{ 3 4 5 } [ first ] call( p -- n ) .
! => 3
```

## Arithmétique vectorielle

Le vocabulaire [`math.vectors`][math.vectors] combine deux séquences de même longueur élément par élément. `v+` et `v*` les additionnent ou les multiplient ; `vmax` et `vmin` gardent la plus grande ou la plus petite de chaque composante. Chacun renvoie un tableau de 2 éléments :

```factor
{ 1 1 } { 3 4 } v+ .    ! => { 4 5 }
{ 2 5 } { 3 -1 } v* .   ! => { 6 -5 }
{ 1 9 } { 4 4 } vmax .  ! => { 4 9 }
{ 1 9 } { 4 4 } vmin .  ! => { 1 4 }
```
