# Introduction

Cet exercice aborde quelques détails sur les paramètres de méthode et leur utilisation en C#.

Les paramètres transmettent des informations d'une méthode appelante à une méthode appelée.

- Le comportement des paramètres peut être modifié par l'utilisation de modificateurs tels que `ref` et `out`.

- Un paramètre muni du modificateur `out` renvoie une valeur de la méthode appelée vers l'appelant. Le paramètre peut être passé à la méthode appelée sans avoir été initialisé et, dans tous les cas, il est traité au sein de la méthode appelée comme s'il n'avait pas été initialisé à l'entrée. On comprend le plus facilement le comportement et les règles concernant les modificateurs de paramètres à travers des exemples (voir ci-dessous) et les messages du compilateur.

```csharp
void Foo(out int val)
{
    val = 42;
}
void Bar(int val)
{
    val = 42;
}

int importantValue = 1729;
Foo(out importantValue);
var result = importantValue == 42;
// => true

importantValue = 1729;
Bar(importantValue);
result = importantValue == 1729;
// => true
```

- Les paramètres `out` doivent être affectés au sein de la méthode appelée.

- Un paramètre muni du modificateur `ref` passe une valeur dans la méthode appelée. Lorsque la méthode rend la main, l'appelant retrouve dans ce paramètre les modifications faites par la méthode appelée.

```csharp
void Foo(ref int val)
{
    val *= 7;
}

int importantValue = 6;
Foo(ref importantValue);
return importantValue;
// => 42
```

- Les paramètres `ref` doivent être des variables, car la méthode appelée agit directement sur le paramètre tel que le voit l'appelant.
- Les modificateurs `out` et `ref` sont obligatoires à la fois dans la signature de la méthode appelée et au niveau de l'appel.
