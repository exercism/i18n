# Introduction

Pour partager du code entre différents modules Elixir au sein d'un même projet, il faut référencer le module extérieur par son nom complet. Mais que faire si ce nom est trop long ou prête à confusion ?

La forme spéciale `alias` permet de raccourcir ou de changer le nom par lequel on référence un module extérieur. Utilisée sans argument, elle réduit le nom du module à son dernier segment : par exemple, `MyApp.Logger.Settings` devient `Settings`. On peut préciser un nom personnalisé avec l'option `:as`.

En général, on ajoute les alias au début de la définition du module.

```elixir
defmodule Square do
  alias Integer, as: I

  def area(a), do: I.pow(a, 2)
end
```
