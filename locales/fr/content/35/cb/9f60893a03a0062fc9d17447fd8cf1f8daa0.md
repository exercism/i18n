# Opérateur ternaire

L'opérateur ternaire offre une syntaxe alternative pour effectuer une comparaison `if..else..` et renvoyer une valeur.

## Syntaxe

PHP fournit une instruction `if` qui permet d'évaluer une action en fonction de la « véracité » d'une condition.

```php
if ($condition) {
  $value = 1;
} else {
  $value = 2
}
```

Sinon, l'opérateur ternaire peut représenter la même opération :

```php
$value = $condition
  ? 1  // True branch
  : 2; // False branch
```

La syntaxe de comparaison est courte, représentée par `(condition) ? (evaluate if true) : (evaluate if false);`.
