# Introduction

## Compréhensions de listes

Les compréhensions offrent un moyen de transformer des _Enumerables_ facilement et de façon déclarative.

Pour déclarer une compréhension très simple, on peut utiliser le mot-clé `for` suivi d'un _générateur_ et d'un _bloc do_ qui crée les nouvelles valeurs à partir des valeurs énumérées.

```elixir
for n <- [0, 1, 2, 3], do: n + 1
# => [1, 2, 3, 4]
```

Les compréhensions peuvent aussi avoir des _filtres_. Les valeurs qui ne passent pas le filtre sont retirées de la liste finale :

```elixir
for n <- [0, 1, 2, 3], n > 1, do: n + 1
# => [3, 4]
```

On peut déclarer des compréhensions plus compliquées sur plusieurs lignes :

```elixir
for {atom, number} <- [a: 1, b: 2, c: 3, d: 4],
    rem(number, 2) == 0 do
  atom
end

# => [:b, :d]
```

On peut créer un _produit cartésien_ en utilisant plusieurs générateurs. Cela signifie que chaque valeur générée par le premier générateur sera associée une fois à chaque valeur générée par le second générateur :

```elixir
for x <- [0, 1],
    y <- [0, 1] do
  {x, y}
end

# => [{0, 0}, {0, 1}, {1, 0}, {1, 1}]
```
