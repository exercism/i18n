# À propos

Les caractères en Factor sont des *entiers*, à savoir des points de code Unicode, donc les opérateurs numériques habituels `<`, `>`, `=` suffisent déjà à obtenir un ordre sensible à la casse. Le vocabulaire [`unicode`][unicode] ajoute par-dessus des prédicats qui tiennent compte d'Unicode, ainsi que la conversion de casse d'un caractère isolé.

## Prédicats

```
LETTER?  ( c -- ? )    ! uppercase letter
letter?  ( c -- ? )    ! lowercase letter
Letter?  ( c -- ? )    ! letter, either case
digit?   ( c -- ? )    ! decimal digit
digit>   ( c -- n )    ! the integer value of a digit char
blank?   ( c -- ? )    ! whitespace
alpha?   ( c -- ? )    ! letter or decimal digit
```

```factor
USING: unicode ;

CHAR: A LETTER? .    ! => t
CHAR: a letter? .    ! => t
CHAR: 7 digit?  .    ! => t
CHAR: \n blank? .    ! => t
```

## Conversion de casse

```
ch>upper  ( c -- c' )
ch>lower  ( c -- c' )
ch>title  ( c -- c' )
```

Appliqués au niveau d'une _string_, `>upper`, `>lower` et `>title` appliquent ces conversions à chaque caractère.

```factor
CHAR: a ch>upper .   ! => 65   (which is CHAR: A)
"Hello" >upper .     ! => "HELLO"
```
