# Ignore-moi

## Entrée

Ton script recevra le casse-tête alphamétique sous la forme d'une seule _string_ via
l'entrée standard (stdin). La _string_ du casse-tête suit le format
`WORD1 + WORD2 + ... == RESULT`.

Par exemple :

```text
SEND + MORE == MONEY
```

## Sortie

Si le casse-tête a une solution, affiche une seule ligne composée de paires
`LETTER=DIGIT` séparées par des espaces, triées par ordre alphabétique des lettres.

Pour l'exemple ci-dessus, la sortie doit être :

```text
D=7 E=5 M=1 N=6 O=0 R=8 S=9 Y=2
```

Si le casse-tête a plusieurs solutions valides, tu peux en afficher n'importe
laquelle.

Si le casse-tête n'a pas de solution, n'affiche rien (une ligne vide).
