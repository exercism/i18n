# Aucun argument par défaut n'est utilisé

Aucun [argument par défaut][default argument] n'est utilisé dans la définition de la fonction de cette solution.
Les [arguments par défaut en Python][default arguments in python] peuvent aider à se prémunir des situations où une fonction est appelée sans l'argument attendu, ou bien où aucun argument n'est disponible à passer.
Les `Default arguments` peuvent aussi aider à éviter du code conditionnel ou des vérifications inutiles à l'intérieur d'une fonction.

Cette solution peut être améliorée en recourant à un `default argument`, combiné à [str.format][str.format] ou à des [f-strings][f-strings] (_autrement dit des « formatted string literals » ou des « interpolated strings »_).

[String Formatting in Python][string formatting in python] de Real Python peut être un bon point de départ pour découvrir les options de formatage de chaînes de caractères en Python.
