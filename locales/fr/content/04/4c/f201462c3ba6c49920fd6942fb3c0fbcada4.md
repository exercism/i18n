# import ANSI avec :except

Les instructions mentionnent « Tu prévois d'ajouter la prise en charge d'autres couleurs de voiture, donc tu veux importer tout le module », à l'exception de la fonction `color` conflictuelle. Pour ce faire, utilise l'option `:except` comme ceci :

```elixir
import IO.ANSI, except: [color: 1]
```
