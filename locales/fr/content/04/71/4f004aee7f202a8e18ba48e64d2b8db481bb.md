# Introduction

## Types opaques

En Gleam, les types opaques sont des types personnalisés pour lesquels seul le module qui définit le type peut construire des valeurs de ce type ou les utiliser dans un filtrage par motif. C'est utile pour créer des types qui ne doivent être utilisés que d'une manière bien précise.

Les types opaques se définissent à l'aide du mot-clé `opaque`.

```gleam
pub opaque type PositiveInt {
  PositiveInt(inner: Int)
}
```

Ce type `PositiveInt` est destiné aux situations où l'on veut un entier, mais où celui-ci doit être supérieur ou égal à zéro. Un `Int` Gleam ordinaire ne conviendrait pas, car il peut aussi être négatif.

Le module qui définit ce type peut définir une fonction pour récupérer la valeur entière interne, et une fonction pour créer le type `PositiveInt`, qui renverra une erreur si la valeur n'est pas positive.

```gleam
pub fn from_int(i: Int) -> Result(PositiveInt, String) {
  case i {
    _ if i < 0 -> Error("Value must be positive")
    _ -> Ok(PositiveInt(i))
  }
}

pub fn to_int(i: PositiveInt) -> Int {
  i.inner
}
```

Avec cette API, les autres modules ne peuvent pas construire un `PositiveInt` avec une valeur négative, donc toute fonction qui prend un `PositiveInt` peut être sûre que la valeur est positive.
