# Annexe aux instructions

## Personnaliser et lever des exceptions

Il est parfois nécessaire de [personnaliser](https://docs.python.org/3/tutorial/errors.html#user-defined-exceptions) et de [`raise`](https://docs.python.org/3/tutorial/errors.html#raising-exceptions) des exceptions dans le code. Quand tu le fais, pense toujours à inclure un **message d'erreur explicite** qui indique l'origine de l'erreur. Cela rend le code plus lisible et facilite grandement le débogage.

Les exceptions personnalisées peuvent être créées au moyen de nouvelles classes d'exceptions (voir [`classes`](https://docs.python.org/3/tutorial/classes.html#tut-classes) pour plus de détails), qui sont généralement des sous-classes de [`Exception`](https://docs.python.org/3/library/exceptions.html#Exception).

Lorsque tu sais que la source de l'erreur sera dérivée d'un certain type d'exception, tu peux choisir d'hériter de l'un des [`built in error types`](https://docs.python.org/3/library/exceptions.html#base-classes) sous la classe _Exception_. Lorsque tu lèves l'erreur, pense quand même à inclure un message explicite.

Cet exercice en particulier te demande de créer deux _exceptions personnalisées_. Une exception à [lever](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement)/« lancer » lorsque ton tampon circulaire est **plein**, et une autre pour le cas où il est **vide**. Les tests ne passeront que si tu personnalises les exceptions adéquates, que tu lèves ces exceptions avec `raise` et que tu inclus des messages d'erreur appropriés.

Pour personnaliser une `built-in exception`, crée une `class` qui hérite de cette exception. Quand tu lèves l'exception personnalisée avec un message, écris ce message comme argument du type `exception` :

```python
# subclassing the built-in BufferError to create BufferFullException
class BufferFullException(BufferError):
    """Exception raised when CircularBuffer is full.

    message: explanation of the error.

    """
    def __init__(self, message):
        self.message = message

        
# raising a BufferFullException
raise BufferFullException("Circular buffer is full")
```
