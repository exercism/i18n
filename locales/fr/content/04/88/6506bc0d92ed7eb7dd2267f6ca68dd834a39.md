# Instructions

Dans cet exercice, tu mets en place un moyen de garder une trace des meilleurs scores du jeu le plus populaire de la salle d'arcade près de chez toi.

## 1. Définis une nouvelle _map_ de meilleurs scores

Pour créer une nouvelle _map_ de meilleurs scores, définis la fonction `HighScore.new/0`, qui ne prend aucun argument et renvoie une nouvelle _map_ vide de meilleurs scores.

```elixir
HighScore.new()
# => %{}
```

## 2. Ajoute des joueurs à la _map_ des meilleurs scores

Pour ajouter un joueur à la _map_ des meilleurs scores, définis `HighScore.add_player/3`, une fonction qui prend 3 arguments :

- Le premier argument est la _map_ des scores.
- Le deuxième argument est le nom d'un joueur, sous forme de _string_.
- Le troisième argument est le score, sous forme d'entier. Cet argument est optionnel : implémente le troisième argument avec une valeur par défaut de 0.

Stocke le score initial par défaut dans un attribut de module. On en aura de nouveau besoin.

```elixir
score_map = HighScore.new()
# => %{}
score_map = HighScore.add_player(score_map, "Dave Thomas")
# => %{"Dave Thomas" => 0}
score_map = HighScore.add_player(score_map, "José Valim", 486_373)
# => %{"Dave Thomas" => 0, "José Valim"=> 486_373}
```

## 3. Supprime des joueurs de la _map_ des scores

Pour supprimer un joueur de la _map_ des meilleurs scores, définis `HighScore.remove_player/2`, qui prend 2 arguments :

- Le premier argument est la _map_ des scores.
- Le deuxième argument est le nom du joueur, sous forme de _string_.

```elixir
score_map = HighScore.new()
# => %{}
score_map = HighScore.add_player(score_map, "Dave Thomas")
# => %{"Dave Thomas" => 0}
score_map = HighScore.remove_player(score_map, "Dave Thomas")
# => %{}
```

## 4. Réinitialise le score d'un joueur

Pour réinitialiser le score d'un joueur, définis `HighScore.reset_score/2`, qui prend 2 arguments :

- Le premier argument est la _map_ des scores.
- Le deuxième argument est le nom du joueur, sous forme de _string_, dont tu souhaites réinitialiser le score.

La fonction doit aussi fonctionner si le joueur n'a pas de score.

```elixir
score_map = HighScore.new()
# => %{}
score_map = HighScore.add_player(score_map, "José Valim", 486_373)
# => %{"José Valim"=> 486_373}
score_map = HighScore.reset_score(score_map, "José Valim")
# => %{"José Valim"=> 0}
```

## 5. Mets à jour le score d'un joueur

Pour mettre à jour le score d'un joueur en l'ajoutant au score précédent, définis `HighScore.update_score/3`, qui prend 3 arguments :

- Le premier argument est la _map_ des scores.
- Le deuxième argument est le nom du joueur, sous forme de _string_, dont tu souhaites mettre à jour le score.
- Le troisième argument est le score que tu souhaites **ajouter** au meilleur score enregistré.

La fonction doit aussi fonctionner si le joueur n'a pas de score précédent : considère que le score précédent vaut 0.

```elixir
score_map = HighScore.new()
# => %{}
score_map = HighScore.add_player(score_map, "José Valim", 486_373)
# => %{"José Valim"=> 486_373}
score_map = HighScore.update_score(score_map, "José Valim", 5)
# => %{"José Valim"=> 486_378}
```

## 6. Récupère un tableau de joueurs

Pour obtenir un tableau de joueurs, définis `HighScore.get_players/1`, qui prend 1 argument :

- Le premier argument est la _map_ des scores.

```elixir
score_map = HighScore.new()
# => %{}
score_map = HighScore.add_player(score_map, "Dave Thomas", 2_374)
# => %{"Dave Thomas" => 2_374}
score_map = HighScore.add_player(score_map, "José Valim", 486_373)
# => %{"Dave Thomas" => 2_374, "José Valim"=> 486_373}
HighScore.get_players(score_map)
# => ["Dave Thomas", "José Valim"]
```
