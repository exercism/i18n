# Les nombres

`INT` contient un nombre entier. En Sather, il fait exactement 32 bits, et va donc de -2147483648 à 2147483647.

```sather
   goals : INT is
      return 42;
   end;
```

## Arguments

Une routine prend des arguments entre parenthèses, chacun avec son type :

```sather
   total(first : INT, second : INT) : INT is
      return first + second;
   end;
```

Les arguments qui partagent un type peuvent partager la déclaration, ce qui est le style habituel :

```sather
   total(first, second : INT) : INT is
```

## Arithmétique

| Opérateur | Signification |
| --- | --- |
| `+` | addition |
| `-` | soustraction, et changement de signe |
| `*` | multiplication |
| `/` | division, en abandonnant le reste |
| `%` | le reste de cette division |

`/` entre deux `INT` ne produit jamais de fraction :

```sather
7 / 2      -- 3
7 % 2      -- 1
```

Si tu veux une fraction, il te faut `FLTD`, dont on parlera plus tard.

La multiplication et la division ont une priorité plus forte que l'addition et la soustraction, comme dans l'arithmétique ordinaire. Les parenthèses servent à regrouper quand tu veux autre chose :

```sather
2 + 3 * 4        -- 14
(2 + 3) * 4      -- 20
```

## Des routines utiles sur `INT`

```sather
7.max(3)     -- 7
7.min(3)     -- 3
(-7).abs     -- 7
7.str        -- "7", the number written as text
```

`.str` permet à un nombre de faire partie d'une phrase, une fois que tu as découvert les _strings_.
