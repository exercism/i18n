# À propos

## Égalité

En Elm, on peut vérifier si des types « sont identiques » à l'aide de l'[opérateur d'égalité][equality-operator] `(==)`.
L'opérateur de non-égalité est `(/=)` (*pas* `!=` comme dans beaucoup d'autres langages).

```elm
1 == 2
    --> False

1 /= 2
    --> True
```

Les deux valeurs comparées doivent être du même type.
L'opérateur d'égalité fonctionne sur les littéraux, les tuples, les records et les types personnalisés.
Il vérifie l'égalité structurelle, ce qui signifie que des valeurs égales ont le même contenu et la même structure profonde, indépendamment de l'annotation de type ou de leur position en mémoire.

```elm
(1, 2) == (2, 1)
    --> False

type alias MyRecord = { myInt : Int, myStrings : List String }
a : MyRecord
a = MyRecord (1 + 1) ["hello world"]

type alias MyOtherRecord = { myInt : Int, myStrings : List String }
myStrings =  (String.join " " ["hello", "world"]) :: []
b : MyOtherRecord
b = { myInt = 2, myStrings = myStrings}

a == b
    --> True
```

À noter que tu ne *devrais jamais* comparer des fonctions, car cela fait planter le programme à l'exécution.
Tu trouveras plus d'informations sur cette limitation [ici][equality-operator].

## Comparaisons

Les [opérateurs de comparaison][comparison-operators] `(<)`, `(<=)`, `(>)`, `(>=)` et les fonctions `min`, `max` et `compare` fonctionnent sur les types `comparable`.
Le type `comparable` est un type spécial qui regroupe tous les types intégrés que l'on peut comparer : les nombres, les caractères, les _strings_, les listes d'éléments comparables et les tuples d'éléments comparables.
Les caractères sont comparés d'après leurs [points de code Unicode][unicode-codepoint].

```elm
1 < 1 + 1
    --> True

'x' < 'X'
    --> False

'互' < '🙏'
    --> True
```

Les types qui s'apparentent à des séquences (les _strings_, les listes et les tuples) sont comparés dans l'[ordre lexicographique][lexicographic-order].
En résumé, les éléments d'une séquence sont comparés deux à deux, dans l'ordre, jusqu'à ce qu'un élément soit plus petit que l'autre ou qu'une séquence se termine.

```elm
"abc" < "abz"
    --> True

"abc" < "abcd"
    --> True

"abc" < "b"
    --> True

min [1 , 2, 9000] [10]
    --> [1 , 2, 9000]

min (1, "hello") (3, "bye")
    --> (1, "hello")

min (1, ['a', 'b']) (1, ['A', 'B'])
    --> (1, ['A', 'B'])
```

Les valeurs d'autres types, comme les records ou les types personnalisés, ne peuvent pas être comparées directement.

Certains types intégrés exigent que leur contenu soit `comparable`, comme les `Set` ou les clés de `Dict`, car leur structure repose sur un ordre interne.
Cela implique que des types personnalisés ne peuvent pas être stockés dans un `Set`, même s'il existe des alternatives proposées par la communauté : [`AnySet`][any-set], [`AnyDict`][any-dict], [`Sort`][sort] et d'autres.

Les listes de valeurs `comparable` peuvent être triées avec `List.sort`, et les listes de valeurs que l'on peut transformer en valeurs comparables avec `List.sortBy`.
Si tu as besoin d'un tri hiérarchique (trier selon une propriété, puis départager avec une autre), tu peux utiliser des tuples ou des listes avec `List.sortBy` (parmi d'autres [alternatives][sort-by]), puisque les tuples et les listes sont triés dans l'ordre lexicographique.


```elm
List.sort ["hi", "hello", "bye", "goodbye"]
    --> ["bye", "goodbye", "hello", "hi"]

List.sortBy String.length ["hi", "hello", "bye", "goodbye"]
    --> ["hi", "bye", "hello", "goodbye"]

-- sort by length, then alphabetically
List.sortBy (\str -> (String.length str, str)) ["hi", "mum", "hello", "sis", "bye", "dad"]
    --> ["hi", "bye", "dad", "mum", "sis", "hello"]
```

La fonction `compare` prend deux valeurs `comparable` et renvoie un `Order`.
Un `Order` est un type qui permet de savoir, en une seule opération, si une valeur est plus grande (`GT`), égale (`EQ`) ou plus petite (`LT`) qu'une autre.

```elm
compare 1 2
    --> LT

compare "" ""
    --> EQ

compare [12] []
    --> GT
```

On peut construire des fonctions de comparaison pour des types arbitraires et les utiliser, par exemple, pour trier avec `List.sortWith` :

```elm
type Color = Red | Green | Blue

compareColors : Color -> Color -> Order
compareColors a b =
  case (a, b) of
    (Red, Red) -> EQ
    (Red, _) -> LT
    (_, Red) -> GT
    (Green, Green) -> EQ
    (Green, _) -> LT
    (_, Green) -> GT
    (Blue, Blue) -> EQ

List.sortWith compareColors [Blue, Red, Green, Green, Blue]
    --> [Red, Green, Green, Blue, Blue]
```
