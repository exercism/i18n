# Introduction

## Opérateurs de comparaison

R possède un ensemble d'opérateurs identique à celui de nombreux autres langages :

```R
1 == 2 # FALSE
1 != 2 # TRUE
1 < 2 # TRUE
1 > 2 # FALSE
1 <= 2 # TRUE
1 >= 2 # FALSE
```

## Branchements

La forme de base d'une instruction `if`/`else` est la suivante :

```R
if (x > 10) {
    y <- "big"
} else if (x > 2) {
    y <- "medium"
} else {
    y <- "tiny"
}
```

Dans ce cas, les parenthèses (`()`) autour du booléen et les accolades (`{}`) autour du corps sont toutes deux obligatoires.

Une instruction `if` simple peut être raccourcie :

```R
if (x == 0) return("success")
```
