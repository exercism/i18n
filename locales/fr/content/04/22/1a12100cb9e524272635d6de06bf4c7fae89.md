# Instructions

Tu es le bosco d'un cargo côtier. La cale, le compartiment le plus bas de la coque, recueille les eaux usées, et à chaque quart le matériel de cale doit être ouvert, mis en route, puis rangé. Quoi qu'il arrive pendant le pompage, le matériel *doit* finir par retrouver son état rangé.

Les tests te donnent `<test-pump>` pour acquérir des pompes neuves. Chaque pompe a un slot `opened>>` qui vaut `t` tant qu'elle est ouverte et `f` une fois qu'elle a été libérée.

## 1. Vider la cale

Définis `drain-bilge` pour libérer une seule pompe. Appeler `drain-bilge` deux fois sur la même pompe ne doit pas poser de problème : le framework s'en charge pour toi.

```factor
<test-pump> dup drain-bilge opened>> .   ! => f
```

## 2. Routine de pompage

Définis `pump-out` de façon à prendre une pompe et une _quotation_, à empiler la pompe sur la pile pour que la _quotation_ l'utilise, puis à libérer la pompe ensuite, *même si la _quotation_ lève une exception*.

```factor
<test-pump> [ drop ] pump-out   ! pump released
```

## 3. Routine de quart complet

Définis `shift-routine` de façon à prendre deux pompes et une _quotation_. Ouvre une portée de destructeur, enregistre *les deux* pompes pour une libération inconditionnelle, puis appelle la _quotation_. Les deux pompes finissent libérées, que la _quotation_ se termine normalement ou qu'elle lève une exception.

La _quotation_ reçoit les deux pompes sur la pile comme entrées.

```factor
<test-pump> <test-pump> [ 2drop ] shift-routine
! both pumps released
```

## 4. Pompage risqué

Parfois, une pompe est prêtée : tu ne veux la libérer que si quelque chose tourne mal, sinon l'équipe du quart suivant a besoin de la retrouver ouverte. Définis `risky-pump-out` de façon à prendre une pompe et une _quotation_, à enregistrer la pompe pour une libération **en cas d'échec uniquement**, puis à appeler la _quotation_ avec la pompe sur la pile.

Si la _quotation_ réussit, la pompe reste ouverte. Si la _quotation_ lève une exception, la pompe est libérée et l'exception se propage.

```factor
<test-pump> [ drop ] risky-pump-out                ! stays open
<test-pump> [ drop "boom" throw ] risky-pump-out   ! pump released, throws
```

## 5. Un objet jetable personnalisé : la vanne

Complète la boîte à outils avec un tout nouvel objet jetable : une `valve`. Le tuple est déclaré pour toi :

```factor
TUPLE: valve < disposable is-open ;
```

- Définis `<valve> ( -- valve )` pour construire une nouvelle vanne via `new-disposable`, avec `is-open` initialisé à `t`.
- Implémente `M: valve dispose*` pour faire basculer `is-open` à `f`.

```factor
<valve> is-open>> .                ! => t
<valve> dup dispose is-open>> .    ! => f
```
