# Consignes

Dans cet exercice, tu vas écrire du code pour gérer des indicatifs téléphoniques internationaux à l'aide d'un _hashmap_.

Ce _map_ utilise des entiers comme clés (l'indicatif) et des _strings_ (les noms de pays) comme valeurs.

Tu as 11 tâches qui portent sur les indicatifs.

## 1. Crée un _hashmap_ pré-rempli

Il existe un _hashmap_ pré-rempli qui contient les 3 indicatifs suivants : « United States of America », dont l'indicatif est 1, « Brazil », dont l'indicatif est 55, et « India », dont l'indicatif est 91. Définis la _var_ `countries` pour stocker ce _hashmap_ pré-rempli :

```clojure
countries
;;=> {1 "United States of America", 55 "Brazil", 91 "India"}
```

## 2. Ajoute un pays à un _map_

Ajoute « United Kingdom », dont l'indicatif est 44, au _map_ créé dans la tâche 1 :

```clojure
(add-country countries 44 "United Kingdom")
;;=> {1 "United States of America", 44 "United Kingdom", 55 "Brazil", 91 "India"}
```

## 3. Récupère le nom du pays associé à un indicatif

Récupère le nom du pays dont l'indicatif est 55

```clojure
(country-name countries 55)
;;=> "Brazil"
```

## 4. Mets à jour le nom d'un pays

Remplace le nom « United States of America » par « Les États-Unis » :

```clojure
(update-map countries 1 "Les États-Unis")
;;=> {1 "Les États-Unis", 55 "Brazil", 91 "India"}
```

## 5. Vérifie qu'un pays existe dans le _map_

Vérifie qu'un enregistrement pour Brazil existe dans le _map_ créé dans la tâche 1

```clojure
(code-exists? countries 55)
;;=> true
```

## 6. Essaie de mettre à jour le nom d'un pays absent du _map_

Essaie de changer le nom d'un pays dont l'indicatif n'est pas dans le _map_, par exemple 999. Cela ne doit entraîner aucune modification du _map_ :

```clojure
(update-map countries 999, "Newlands")
;;=> {1 "United States of America", 44 "United Kingdom", 55 "Brazil", 91 "India"}
```

## 7. Supprime un pays du _map_

Supprime India du _map_ :

```clojure
(remove-country countries 91)
;;=> {1 "United States of America", 55 "Brazil"}
```

## 8. Trouve le pays dont le nom est le plus long

Parcours les valeurs du _map_ pour trouver celle dont le nom est le plus long :

```clojure
(longest-name countries)
;;=> "United States of America"
```
