# À propos

[Nil][nil-dictionary] est un mot anglais qui signifie « rien » ou « zéro ». En Elixir, `nil` est une valeur spéciale qui représente une _absence_ de valeur.

```elixir
# I do not have a favorite color
favorite_color = nil
```

`nil` est un atome, mais on l'écrit généralement `nil`, et non `:nil`. Les valeurs booléennes `true` et `false` sont aussi des atomes.

[//]: # (elixir-formatter-disable-next-block)

```elixir
nil === :nil
# => true

true === :true
# => true
```

On peut vérifier si la valeur d'une variable vaut `nil` avec [`==`][kernel-equal], par filtrage par motif, ou avec la garde [`is_nil`][kernel-is-nil].

```elixir
def call(phone_number) do
  if phone_number == nil do
    :error
  end
end
```

```elixir
def call(phone_number) when is_nil(phone_number) do
  :error
end
```

```elixir
def call(nil) do
  :error
end
```
