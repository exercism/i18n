# Instructions

Tu es un observateur d'oiseaux passionné qui gardes trace du nombre d'oiseaux qui ont visité ton jardin ces sept derniers jours.

Tu as cinq tâches, toutes portant sur le nombre d'oiseaux qui ont visité ton jardin.

## 1. Vérifie quels étaient les comptages la semaine dernière

Tu stockes tes comptages d'oiseaux au format JSON.
Un tableau « main » contient des tableaux de comptages hebdomadaires.
Chaque comptage hebdomadaire est un tableau de sept entiers, un nombre pour chaque jour de la semaine.
Tu ajoutes toujours les nouvelles semaines à la fin du tableau « main ».
Implémente le filtre qui renvoie les comptages de la semaine dernière.

```sh
$ cat bird-counting-data.json
[
  ...,
  [0, 2, 5, 3, 7, 8, 4],
  [4, 5, 9, 10, 9, 4, 3]
]

$ jq -f bird-count.jq < bird-counting-data.json
{
  "last_week": [0, 2, 5, 3, 7, 8, 4],
  ...
```

## 2. Vérifie combien d'oiseaux sont venus hier

Implémente le filtre pour renvoyer le nombre d'oiseaux qui ont visité ton jardin hier.
Les comptages sont ordonnés par jour : le premier élément correspond au comptage du jour le plus ancien, et le dernier à celui d'aujourd'hui.

```jq
$ jq -f bird-count.jq < bird-counting-data.json
{
  ...
  "yesterday": 4,
  ...
```

## 3. Calcule le nombre total d'oiseaux qui sont venus

Implémente le filtre pour renvoyer le nombre total d'oiseaux qui ont visité ton jardin cette semaine.

```jq
$ jq -f bird-count.jq < bird-counting-data.json
{
  ...
  "total": 44,
  ...
```

## 4. Calcule le nombre de jours chargés

Certains jours sont plus chargés que d'autres.
Un jour chargé est un jour où cinq oiseaux ou plus ont visité ton jardin.
Implémente le filtre pour renvoyer le nombre de jours chargés cette semaine.

```jq
$ jq -f bird-count.jq < bird-counting-data.json
{
  ...
  "busy_days": 4,
  ...
```

## 5. Vérifie s'il y a eu un jour sans aucun oiseau

Implémente le filtre qui renvoie `true` s'il y a eu cette semaine un jour où aucun oiseau n'est venu dans le jardin ; sinon, renvoie `false`.

```jq
$ jq -f bird-count.jq < bird-counting-data.json
{
  ...
  "has_day_without_birds": false
}
```
