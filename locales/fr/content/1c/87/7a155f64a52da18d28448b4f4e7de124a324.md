# Instructions supplémentaires

## Bonus

Teste ta fonction sur cette _string_ : `uüu` et regarde ce qui se passe.
Essaie d'écrire une fonction qui inverse correctement cette _string_.
Indice : les groupes de graphèmes

Pour que le test bonus s'exécute, retire l'attribut `#[ignore]` du dernier test, puis exécute les tests avec :

```bash
cargo test --features grapheme
```

Pour le bonus, tu auras besoin d'utiliser des bibliothèques externes (des `crate` dans le jargon Rust).
Un bon endroit où les chercher est [crates.io](https://crates.io/), le dépôt officiel des crates.
N'oublie pas que notre exécuteur de tests ne prend en charge qu'un ensemble limité de crates.
La liste complète se trouve dans [ce fichier](https://github.com/exercism/rust-test-runner/blob/main/local-registry/Cargo.toml), à la section `[dependencies]`.

Consulte la [documentation](https://doc.rust-lang.org/cargo/guide/dependencies.html) pour savoir comment utiliser des crates externes dans tes projets.
