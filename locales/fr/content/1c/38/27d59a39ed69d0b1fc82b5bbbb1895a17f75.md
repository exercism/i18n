vous retirer la liberté de partager et de modifier les œuvres. En revanche, nos
licences publiques générales ont pour but de garantir votre liberté de partager

Un bénéfice secondaire de la défense de la liberté de tous les utilisateurs est
que les améliorations apportées dans des versions alternatives du programme, si
elles sont largement utilisées, deviennent disponibles pour que d'autres
développeurs les intègrent. De nombreux développeurs de logiciels libres sont
réconfortés et encouragés par la coopération qui en résulte. Cependant, dans le
cas de logiciels utilisés sur des serveurs en réseau, ce résultat peut ne pas se
produire. La Licence publique générale GNU permet de faire une version modifiée
et de laisser le public y accéder sur un serveur sans jamais en publier le code
source.

La Licence publique générale GNU Affero est spécialement conçue pour garantir
que, dans de tels cas, le code source modifié devienne disponible pour la
communauté. Elle exige de l'exploitant d'un serveur en réseau qu'il fournisse le
code source de la version modifiée y fonctionnant aux utilisateurs de ce
serveur. Par conséquent, l'utilisation publique d'une version modifiée, sur un
serveur accessible publiquement, donne au public accès au code source de la
version modifiée.
