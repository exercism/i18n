# Introduction

Le type `char` de F# est une valeur de 16 bits qui représente les plus petites composantes adressables d'un texte, immuable par défaut.

Les `char` peuvent être définis comme des littéraux entre apostrophes :

```fsharp
let ch = 'A'
// => val ch: char = 'A'
```

Une _string_ est une séquence de `char`.

On peut récupérer un `char` individuel dans une _string_ à l'aide d'un indice (en partant de zéro) :

```fsharp
"Exercism"[4] //  =>  'c'
```

Quand on itère sur une _string_, on obtient un `char` à chaque étape.

L'exemple suivant utilise une fonction d'ordre supérieur et une fonction anonyme, pour aller plus vite.
Ces notions seront vues en détail plus tard dans le programme, mais pour l'instant elles offrent un moyen concis d'écrire une boucle sur les caractères d'une _string_.

```fsharp
Seq.map (fun c -> c, int c) "F#"  //  =>  [('F', 70); ('#', 35)]
```

Comme on le voit ci-dessus, un `char` peut être converti en sa valeur `int`.
Cela fonctionne aussi (*du moins une partie du temps*) pour d'autres systèmes d'écriture :

```fsharp
Seq.map (fun c -> c, int c) "東京"  //  =>  [('東', 26481); ('京', 20140)]
```

C'est l'Int16 sous-jacent qui est utilisé pour comparer les caractères :

```fsharp
'A' < 'D'  // =>  true
```

À l'inverse, un `int` peut être converti en `char` :

```fsharp
char 77  // => 'M'
```

La bibliothèque `System.Char` contient l'ensemble complet des méthodes attendues dans un langage .NET, comme les conversions en majuscules ou en minuscules :

```fsharp
'a' |> System.Char.ToUpper  // =>  'A'

'Q' |> System.Char.ToLower  // =>  'q'
```
