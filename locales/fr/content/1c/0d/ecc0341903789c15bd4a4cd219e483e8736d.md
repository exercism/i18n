# Déstructuration dans les paramètres

L'[affectation par déstructuration](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Destructuring_assignment) fonctionne aussi directement dans les paramètres, comme `%{parameter}`. Cela permet de donner un nom aux éléments contenus dans le paramètre, de limiter le nombre d'éléments reçus et de remplacer les indices numériques plus cryptiques par les éléments nommés.
