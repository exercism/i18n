# Instructions

Dans cet exercice, tu vas écrire du code pour aider une entreprise de panneaux à créer des messages personnalisés pour ses panneaux.

## 1. Crée un panneau pour une occasion

Implémente la méthode `build_sign( )` qui prend une _string_ comme paramètre `occasion` et une _string_ contenant le nom d'une personne comme paramètre `name`. Les deux paramètres seront insérés dans un _template string_ afin de produire le message sur le panneau.

```abap
build_sign( occasion = 'Birthday' 
            name     = 'Rob').
" => "Happy Birthday Rob!"
```

## 2. Crée un panneau d'anniversaire

Implémente la méthode `build_birthday_sign( )` qui prend un âge et qui, selon cet âge, détermine une partie du message sur le panneau. Si l'âge est supérieur ou égal à 50, le panneau contiendra le mot _mature_, sinon il contiendra le mot _young_.

```abap
build_birthday_sign( 45 ).
" => "Happy Birthday! What a young fellow you are."
```

## 3. Crée un panneau de remise de diplôme

Implémente la méthode `graduation_for( )` qui prend un nom comme paramètre de type _string_ et une année comme paramètre numérique, et qui utilise des _template strings_ pour créer une phrase destinée au panneau, avec un retour à la ligne pour séparer les deux lignes du message.

```abap
graduation_for( name = 'Hannah' 
                year = 2022 ).
" => "Congratulations Hannah!\nClass of 2022"
```

## 4. Calcule le coût d'un panneau

Implémente la fonction `cost_of( sign currency )` qui prend une _string_ contenant le contenu du panneau et une _string_ représentant la devise.
Le prix de base d'un panneau est de 20 dans la devise donnée. De plus, chaque lettre coûte 2. (Les espaces sont inclus dans le calcul.)
La phrase renvoyée contient le coût de création du panneau, écrit avec deux chiffres après la virgule, suivi de la _string_ de la devise.

```abap
costOf( sign     = 'Happy Birthday Rob!'
        currency = 'euros');
// => "Your sign costs 58.00 euros."
```
