# Introduction

Les espaces de noms sont une méthode importante pour organiser le code.
Deux fonctions peuvent entrer en collision de noms, ce que l'on peut résoudre en les plaçant dans des espaces de noms différents.
Les espaces de noms peuvent être imbriqués, ce qui peut aider à structurer de grandes bases de code.
On accède aux espaces de noms via l'opérateur de résolution de portée `::`.

L'exemple ci-dessous montre l'utilisation de deux fonctions `foo` différentes.
Elles sont utilisées ensemble en préfixant leurs espaces de noms respectifs.

```cpp
namespace my_ns {
    int foo() {
        return 44;
    }
    namespace my_inner_ns {
        int baz() {
            return 90;
        }
    }
}
namespace my_other_ns {
    int foo() {
        return -2;
    }
}

int myresult{my_ns::foo() + my_other_ns::foo() * my_ns::my_inner_ns::baz()};
```
