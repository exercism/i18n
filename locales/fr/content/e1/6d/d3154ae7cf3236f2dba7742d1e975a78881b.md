# Tests

Place-toi dans le répertoire qui contient le fichier `${slug}_test.sql` correspondant, où `${slug}` est le nom de l'exercice, avec des tirets à la place des espaces et en minuscules (par exemple `hello-world_test.sql` pour l'exercice `Hello World`).

```bash
sqlite3 -bail < ${slug}_test.sql
```

Tu peux utiliser des instructions `SELECT` pour déboguer.
La sortie sera transmise à `user_output.md` et affichée dans l'éditeur en ligne si les tests échouent.

Tu trouveras plus d'informations dans la [documentation du parcours SQLite sur les tests](https://exercism.org/docs/tracks/sqlite/tests).
