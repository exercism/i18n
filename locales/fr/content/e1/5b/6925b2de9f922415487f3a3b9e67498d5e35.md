# Indices

## Général

- Tous les mots dont tu as besoin se trouvent dans les vocabulaires
  [`math`][math] et [`math.functions`][math.functions]. Ajoute-les à ta
  ligne `USING:`.

## 1. Estime la valeur après l'échange

- Utilise `/` (effet de pile `( x y -- x/y )`) pour diviser le budget par le taux.

## 2. Calcule la somme restante après un échange

- Utilise `-` pour soustraire.

## 3. Calcule la valeur des billets

- Utilise `*` pour multiplier.

## 4. Calcule le nombre de billets

- `amount` peut être un nombre décimal ; il te faut un résultat entier.
- Une première approche : convertis d'abord le montant en entier avec
  `floor >integer`, puis divise avec `/i`.
- Autre possibilité : utilise directement `/i`, qui tronque aussi le
  nombre décimal quand le dénominateur est un entier, puis convertis avec
  `>integer`.

## 5. Calcule le reste après conversion en billets

- Utilise `mod` pour obtenir le reste.

## 6. Calcule la valeur après l'échange

- Calcule le taux de change *total* : prends `spread` pour cent de
  `exchange-rate` et ajoute le résultat à `exchange-rate`.
- Appelle ensuite `exchange-money` avec le budget et le taux total.
- Appelle ensuite `number-of-bills` pour arrondir vers le bas au nombre
  entier de billets de la coupure donnée.
- Appelle enfin `value-of-bills` pour obtenir la valeur finale.
- Ces quatre sous-calculs s'enchaînent naturellement ; si la manipulation
  de la pile devient pénible, la forme avec variables locales (`::` avec
  des paramètres nommés) convient très bien ici.
