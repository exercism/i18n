# À propos

Une [boucle _while_][while-loops] est une instruction de contrôle qui permet d'exécuter du code tant qu'une certaine condition est vraie.
Swift propose deux types de boucles _while_ : les boucles _while_ et _repeat-while_.
La condition d'une boucle _while_ est évaluée avant que le corps de la boucle ne soit exécuté ; si la condition est fausse, le corps de la boucle ne sera pas exécuté du tout.
Les boucles _while_ en Swift ont la structure suivante :

```swift
while <#condition#> {
  <#code#>
}
```

Ici, la boucle s'exécutera tant que count est supérieur à 0, et affichera donc les nombres 2, 1 et « Liftoff! ».

```swift
var count = 2
while count > 0 {
  print("\(count)…")
  count -= 1
}
print("Liftoff!")

// prints:
// 2…
// 1…
// Liftoff!
```

Une [boucle _repeat-while_][while-loops] est similaire à une boucle _while_, mais la condition est évaluée après que le corps de la boucle a été exécuté.
Cela signifie que le corps de la boucle s'exécutera toujours au moins une fois, même si la condition est fausse.
Les boucles _repeat-while_ en Swift ont la structure suivante :

```swift
repeat {
  <#code#>
} while <#condition#>
```

Ici, la boucle ne s'exécutera qu'une seule fois, puisque la condition est fausse.
Comme c'est une boucle _repeat-while_, le corps de la boucle s'exécutera une fois avant que la condition ne soit évaluée.

```swift
var count = 2
repeat {
  print("\(count)…")
} while count < 0
print("Liftoff!")
```
