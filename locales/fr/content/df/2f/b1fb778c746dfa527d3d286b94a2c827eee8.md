# Instructions

Tu es un observateur d'oiseaux passionné et tu notes combien d'oiseaux sont venus dans ton jardin au cours des sept derniers jours.

Tu as six tâches, qui portent toutes sur le nombre d'oiseaux venus dans ton jardin.

## 1. Vérifie quels étaient les comptages de la semaine dernière

Pour pouvoir comparer, tu gardes toujours près de toi une copie des comptages de la semaine dernière, à savoir : 0, 2, 5, 3, 7, 8 et 4. Implémente la méthode `BirdWatcher.getLastWeek()` qui renvoie les comptages de la semaine dernière :

```java
BirdWatcher.getLastWeek();
// => [0, 2, 5, 3, 7, 8, 4]
```

## 2. Vérifie combien d'oiseaux sont venus aujourd'hui

Implémente la méthode `BirdWatcher.getToday()` pour renvoyer le nombre d'oiseaux qui sont venus dans ton jardin aujourd'hui. Les comptages d'oiseaux sont ordonnés par jour : le premier élément correspond au comptage du jour le plus ancien et le dernier au comptage d'aujourd'hui.

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.getToday();
// => 1
```

## 3. Incrémente le comptage d'aujourd'hui

Implémente la méthode `BirdWatcher.incrementTodaysCount()` pour incrémenter le comptage d'aujourd'hui :

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.incrementTodaysCount();
birdCount.getToday();
// => 2
```

## 4. Vérifie s'il y a eu un jour sans aucun oiseau

Implémente la méthode `BirdWatcher.hasDayWithoutBirds()` qui renvoie `true` si un jour aucun oiseau n'est venu dans le jardin, et `false` dans le cas contraire :

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.hasDayWithoutBirds();
// => true
```

## 5. Calcule le nombre d'oiseaux venus les premiers jours

Implémente la méthode `BirdWatcher.getCountForFirstDays()` qui renvoie le nombre d'oiseaux venus dans ton jardin depuis le début de la semaine, en limitant le comptage au nombre de jours indiqué depuis le début de la semaine.

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.getCountForFirstDays(4);
// => 14
```

## 6. Calcule le nombre de jours chargés

Certains jours sont plus chargés que d'autres. Un jour chargé est un jour où cinq oiseaux ou plus sont venus dans ton jardin.
Implémente la méthode `BirdWatcher.getBusyDays()` pour renvoyer le nombre de jours chargés :

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.getBusyDays();
// => 2
```
