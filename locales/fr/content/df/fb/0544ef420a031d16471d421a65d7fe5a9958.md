# Indices

## Général

- Le fichier de solution est inclus dans un autre, qui appelle tes macros.
  Garde le nom de chaque macro et l'ordre de ses arguments exactement tels que la tâche les donne, sinon le fichier ne s'assemblera pas.
- Les arguments d'une macro sont des jetons, substitués en `%1`, `%2`, `%3` partout où ils apparaissent dans le corps.
  Il peut s'agir de registres, d'expressions d'adresse ou de littéraux, tant que chaque expansion est une instruction valide.
- Chaque macro est évaluée sur les registres qu'elle laisse intacts, et pas seulement sur ce qu'elle écrit.
  Lis la note sur les registres modifiés dans chaque tâche et ne modifie que les registres qu'elle autorise.

## 1. Nomme les constantes de format

- Un `%define` sur une seule ligne donne un nom à une valeur, pour que le reste du code puisse lire ce nom au lieu d'un nombre brut.
  Pour un nombre fixe, `equ` fait la même chose et c'est le choix habituel pour une constante.
- Les constantes d'octet peuvent s'écrire soit en hexadécimal (`0x20`), soit sous forme de littéral de caractère (`' '`).
  Les deux produisent la même valeur à l'assemblage.

## 2. Écris la macro `fill_run`

- Tu devrais donner à `rcx` le nom plus lisible `COUNTER`.
- `fill_run` est une macro multiligne qui prend 3 arguments.
  Les macros multilignes se définissent avec `%macro ... %endmacro`.
- Le premier argument de `fill_run` est une adresse mémoire contenue dans un registre général de 64 bits.
  Le deuxième est le nombre, qui peut être passé dans un registre général de 64 bits ou comme valeur immédiate.
  Le troisième est un octet à écrire, sous forme de valeur immédiate.
  Tu devrais concevoir le code de la macro en tenant compte de ces spécifications.
- Le seul registre que `fill_run` a le droit de modifier est `COUNTER`.
- Une boucle à l'intérieur d'une macro a généralement besoin d'une étiquette préfixée par `%%`.
  Sans ce préfixe, la même étiquette est créée à chaque appel de la macro, ce qui peut provoquer une erreur si la macro est appelée plus d'une fois.

## 3. Écris la macro `lay_columns`

- `lay_columns` est une macro multiligne qui prend 2 arguments.
  Les macros multilignes se définissent avec `%macro ... %endmacro`.
- Les deux arguments de `lay_columns` sont passés dans des registres généraux de 64 bits.
  Le premier est une adresse mémoire, le deuxième est un entier.
  Tu devrais concevoir le code de la macro en tenant compte de ces spécifications.
- Les seuls registres que `lay_columns` a le droit de modifier sont les deux passés en arguments.
- Le nombre de décalages que la macro doit écrire est fixé au moment de l'assemblage.
  Tu peux utiliser `%rep ... %endrep` pour répéter le code.
- Le calcul du décalage se fait avec `offset[i] = margin + i * COLUMN_STRIDE`.
  `margin` est le deuxième argument de la macro.
  `i` est un compteur de boucle qui peut être défini comme une variable `%assign`.

## 4. Écris la macro `set_header`

- `set_header` est une macro multiligne qui prend 2 arguments.
  Les macros multilignes se définissent avec `%macro ... %endmacro`.
- Le premier argument de `set_header` est l'expression d'une adresse mémoire effective.
  Elle prend un registre de base, qui peut être additionné à un registre d'index mis à l'échelle par `1`, `2`, `4` ou `8`, et une valeur immédiate.
  Cela signifie qu'un simple `rdi` est valide, tout comme `rdi+rax*4+2`.
- Le deuxième argument de `set_header` est une valeur immédiate qui peut valoir `0`, `1` ou `2`.
- `set_header` ne doit modifier aucun registre.
- Tu devrais copier un octet vers l'adresse de destination de manière conditionnelle, au moment de l'assemblage, selon le deuxième argument.
  Une valeur de `0` doit copier `PLAIN`, une valeur de `1` doit copier `RULED`, et une valeur de `2` doit copier `BOXED`.
