# À propos

[`case`][case] est une structure de contrôle qui permet de comparer une valeur donnée à de nombreux motifs. Les clauses d'une expression `case` sont évaluées de haut en bas, jusqu'à ce qu'une correspondance soit trouvée.

Souvent, utiliser `case` revient au même que de définir [plusieurs clauses de fonction][exercism-multiple-clause-functions]. La [correspondance de motifs][exercism-pattern-matching] et les [gardes][exercism-guards] peuvent s'utiliser dans les clauses d'une expression `case`.

```elixir
# one function clause, multiple case clauses
def age_group(age) do
  case age do
    0 -> ~c"infant"
    age when age < 4 -> ~c"baby"
    age when age < 13 -> ~c"child"
    age when age < 18 -> ~c"teenager"
    _ -> ~c"adult"
  end
end

# multiple function clauses, no case
def age_group(0), do: ~c"infant"
def age_group(age) when age < 4, do: ~c"baby"
def age_group(age) when age < 13, do: ~c"child"
def age_group(age) when age < 18, do: ~c"teenager"
def age_group(_), do: ~c"adult"
```

Il n'existe pas de règle stricte pour choisir l'un plutôt que l'autre. C'est une question de préférence personnelle, qui dépend généralement du contexte.
