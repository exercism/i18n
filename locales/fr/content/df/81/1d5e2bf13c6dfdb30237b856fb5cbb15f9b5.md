# À propos

Le Printer de Common Lisp est le mécanisme qui permet de produire des données vers des flux. Une fonction courante de ce mécanisme est `format`.

`format` prend deux paramètres obligatoires : un flux vers lequel écrire et une _string_ de contrôle. Le contenu de la _string_ de contrôle détermine comment les arguments suivants sont utilisés.

Le premier paramètre prend deux valeurs particulières : `t` et `nil`. `t` indique qu'il faut utiliser le flux lié à `*standard-output*`, tandis que `nil` indique qu'il faut créer une _string_ et la renvoyer. `format` renvoie `nil` sauf si le paramètre de flux vaut `nil`.

La _string_ de contrôle peut contenir des directives de format, qui sont signalées par un `~` suivi d'un caractère (la casse du caractère n'a pas d'importance). La directive de format détermine si des arguments sont consommés et comment ils sont formatés vers le flux.

Les principales directives de format de base sont :

* `~A` - formate de manière _esthétique_, « lisible par un humain ».
* `~S` - formate selon le format _standard_, pour être « lisible par une machine ».
* `~%` - émet un saut de ligne
* `~&` - émet un saut de ligne sauf si l'on est déjà au début d'une ligne.
* `~~` - émet un tilde.

Exemples :

```lisp
(format nil "The list is: ~A~%" (list 1 2 3)) ; => "The list is: (1 2 3)
                                                   "
(format nil "(format t ~S)" "hello world")    ; => "(format t \"hello world\""
(format nil "~&fresh~&lines")                 ;=> "fresh
                                                   lines"
(format nil "directives start with a ~~")     ; => "directives start with a ~"
```
