# Introduction

Les caractères et les _strings_ constituent la base de la représentation du texte en Elm.
On peut voir une _chaîne de caractères_ comme un tableau de caractères, et la plupart des fonctions de `List` ont leur équivalent dans le module `String`.

## Caractères

Le type `Char` représente un seul caractère unicode, entouré de guillemets simples, par exemple `'a'`. 
Le module `Char` fournit des fonctions prédicats (`Char -> Bool`) pour tester les propriétés d'un caractère : `isUpper`, `isLower`, `isAlpha` et `isAlphaNum`.
Le module fournit aussi des fonctions pour convertir un caractère, `toUpper`, `toLower`, `toLocaleUpper`, `toLocaleLower`, ainsi que pour passer à sa valeur unicode numérique (`Int`) et inversement, avec `toCode` et `fromCode`.

## Chaînes de caractères

Le type `String` fournit une représentation intégrée pour manipuler efficacement les _strings_ et peut représenter n'importe quelle séquence de caractères unicode.
Les _strings_ sont entourées de guillemets doubles : `"this is a string"`.
Les _strings_ multilignes sont entourées de triples guillemets doubles et peuvent contenir des guillemets et des retours à la ligne non échappés.

```elm 
haiku = 
"""
    Code's strings entwine
    , In binary, thoughts combine
    , Logic's elegant line.
"""
```

## Manipulation des chaînes de caractères

`reverse : String -> String` inverse la _string_.
```elm 
reverse "Hello world." 
    --> ".dlrow olleH"
```

`repeat : Int -> String -> String` répète une _string_ n fois.
```elm 
repeat 2 "Hello world." 
    --> "Hello world.Hello world."
```

`replace : String -> String -> String -> String` remplace toutes les occurrences d'une sous-chaîne donnée.
```elm
replace "Hello" "Goodbye cruel" "Hello world." 
    --> "Goodbye cruel world."
```

`append : String -> String -> String` ajoute une _string_ à la fin d'une autre.
L'opérateur `++` permet aussi de faire la même chose.
```elm
append "butter" "fly" 
    --> "butterfly"
"butter" ++ "fly" 
    --> "butterfly"
```

`concat : List String -> String` concatène un tableau de _strings_ en une seule _string_.
```elm
concat ["never", "the", "less"] 
    --> "nevertheless"
```

`split : String -> String -> List String` découpe une _string_ en un tableau de _strings_ au niveau du séparateur donné.
```elm
split ";" "cat;dog;cow" 
    --> ["cat", "dog", "cow"]
```

`join : String -> List String -> String` concatène un tableau de _strings_ en les séparant par un séparateur donné.
```elm
join "a" ["H", "w", "ii", "n"] 
    --> "Hawaiian"
```

`words : String -> List String` découpe une _string_ en plusieurs _strings_, en séparant sur les groupes d'espaces.
```elm
words "How are \t you? \n Good?" 
    --> ["How", "are", "you?", "Good?"]
```

`lines : String -> List String` découpe une _string_ en lignes, en séparant sur les retours à la ligne.
```elm
lines "How are you?\nGood?" 
    --> ["How are you?", "Good?"]
```

`cons : Char -> String -> String` ajoute un caractère au début d'une _string_.
```elm
cons 'T' "he truth is out there" 
    --> "The truth is out there"
```

`uncons : String -> Maybe ( Char, String )` sépare une _string_ non vide en sa tête et sa queue.
Cela te permet de faire du filtrage par motifs sur les _strings_, exactement comme tu le ferais avec des tableaux.
Les _strings_ vides renvoient `Nothing`.
```elm
uncons "abc" 
    --> Just ('a', "bc")
uncons ""
    --> Nothing
```

## Extraire des sous-chaînes

`slice : Int -> Int -> String -> String` extrait une sous-chaîne à partir d'un indice de début et d'un indice de fin.
Les indices négatifs sont comptés à partir de la fin du tableau.
```elm
slice 0 6 "snakes on a plane!" 
    --> "snakes"
slice 0 -7 "snakes on a plane!"
    --> "snakes on a"
```

`left : Int -> String -> String` et `right : Int -> String -> String` prennent respectivement n caractères à gauche ou à droite de la _string_.

```elm
left 2 "Mulder" 
    --> "Mu"
right 2 "Scully" 
    --> "ly"
```

`dropLeft : Int -> String -> String` et `dropRight : Int -> String -> String` suppriment respectivement n caractères à gauche ou à droite d'une _string_.
```elm
dropRight 6 "Hello world." 
    --> "Hello"
dropLeft 6 "Hello world." 
    --> "world"
```

## Vérifier les propriétés d'une chaîne

`length : String -> Int` renvoie le nombre de caractères d'une _string_.
```elm 
length "Hello world." 
    --> 12
```

`isEmpty : String -> Bool` détermine si une _string_ est vide. 
```elm 
isEmpty "Hello world." 
    --> False
```

`contains : String -> String -> Bool` vérifie si la seconde _string_ contient la première.
```elm
contains "the" "theory" 
    --> True
contains "THE" "theory" 
    --> False
```

`startsWith : String -> String -> Bool` et `endsWith : String -> String -> Bool` vérifient si la seconde _string_ commence ou se termine par une sous-chaîne donnée.
```elm
startsWith "the" "theory" 
    --> True
endsWith "ory" "theory" 
    --> True
```

`indexes : String -> String -> List Int` renvoie un tableau de tous les indices de début d'une sous-chaîne dans une autre _string_.
```elm
indexes "ss" "Mississippi"  
    --> [2, 5]
```

## Convertir des chaînes
`toInt : String -> Maybe Int` essaie de convertir une _string_ en `Just Int`, et renvoie `Nothing` pour les _strings_ mal formées.
```elm
toInt "-42" 
    --> Just -42
toInt "3.1" 
    --> Nothing
toInt "two" 
    --> Nothing
```

`fromInt : Int -> String` convertit un entier en _string_.
```elm
fromInt -42 
    --> "-42"
```

`toFloat : String -> Maybe Float` essaie de convertir une _string_ en nombre décimal, et échoue sur les _strings_ mal formées.
```elm
toFloat "-42" 
    --> Just -42.0
toFloat "3.1" 
    --> Just 3.1
toFloat "two" 
    --> Nothing
```

`fromFloat : Float -> String` convertit un nombre décimal en _string_.
```elm
fromFloat 3.9 
    --> "3.9"
```

`toList : String -> List Char` et `fromList : List Char -> String` convertissent respectivement une _string_ en tableau de caractères et inversement.
```elm 
toList "abc" 
    --> ['a', 'b', 'c']
fromList ['a', 'b', 'c'] 
    --> "abc"
```

`fromChar : Char -> String` convertit un caractère en _string_.
```elm
fromChar 'a' 
    --> "a"
```

## Formater des chaînes

`toUpper : String -> String` et `toLower : String -> String` convertissent respectivement une _string_ entièrement en majuscules ou en minuscules.
Utile pour les comparaisons insensibles à la casse.
```elm
toUpper "skinner" 
    --> "SKINNER"
toLower "X-FILES" 
    --> "x-files"
```

`pad : Int -> Char -> String -> String` complète une _string_ des deux côtés avec le `Char` fourni jusqu'à ce qu'elle atteigne la longueur donnée.
```elm
pad 5 ' ' "11"  
    --> "  11 "
```
De même, `padLeft` et `padRight` complètent une _string_ d'un seul côté jusqu'à ce qu'elle atteigne une longueur donnée.

`trim : String -> String` supprime les espaces des deux côtés d'une _string_.
```elm
trim "  hats  \n" 
    --> "hats"
```
`trimLeft` et `trimRight` suppriment les espaces d'un seul côté d'une _string_.

## Fonctions d'ordre supérieur

`map : (Char -> Char) -> String -> String` transforme chaque caractère d'une _string_ avec la fonction donnée.
À noter que la fonction fournie doit être une transformation de `Char` vers `Char`.
```elm
map (\c -> if c == '/' then '.' else c) "a/b/c" 
    --> "a.b.c"
```

`filter : (Char -> Bool) -> String -> String` ne conserve que les caractères qui passent le test.
```elm
filter isDigit "R2-D2" 
    --> "22"
```

`foldl : (Char -> b -> b) -> b -> String -> b` réduit une _string_ en partant de la gauche.
La fonction est appliquée avec le premier caractère comme premier paramètre et une valeur initiale fournie comme second paramètre.
Le résultat de la fonction doit être du même type que la valeur initiale fournie, et il est appliqué à chaque caractère, l'un après l'autre.
```elm
foldl (\c acc -> Char.toCode c + acc) 0 "the sum of my unicode is " 
    --> 2260
```
`foldr` fait la même chose, mais en partant de la droite de la _string_.

`any : (Char -> Bool) -> String -> Bool` détermine si au moins un caractère renvoie `True` au prédicat fourni.
```elm
any isDigit "R2-D2" 
    --> True
any isDigit "heart" 
    --> False
```
`all : (Char -> Bool) -> String -> Bool` détermine si tous les caractères d'une _string_ renvoient `True` au prédicat fourni.
```elm
all isDigit "R2-D2" 
    --> False
all isAlpha "heart" 
    --> True
```
