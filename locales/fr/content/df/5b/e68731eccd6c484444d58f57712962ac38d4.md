# Prépare le lancement

Avant de pouvoir lancer ton parcours, vérifie que les tâches suivantes ont bien été réalisées.

## Demande l'icône du parcours

Pour concevoir une icône destinée au site, ouvre une nouvelle _issue_ dans le dépôt [exercism/website-icons](https://github.com/exercism/website-icons/issues), en répondant aux questions suivantes :

- Le langage a-t-il un logo officiel ? Si oui
  - ajoute un lien vers un exemple
  - liste les exigences d'attribution et les droits accordés pour l'utilisation de ce logo
- Le langage a-t-il un logo non officiel ? Si oui
  - explique de quelles manières les gens utilisent ce logo non officiel
  - ajoute un lien vers un exemple
  - liste les exigences d'attribution de ce logo

## Ajoute la documentation du parcours

Ajoute les documents de parcours suivants :

- `docs/ABOUT.md` : une brève introduction au langage.
- `docs/INSTALLATION.md` : décris ce que l'apprenant doit installer pour pouvoir travailler sur le parcours sur son système local à l'aide de la CLI.
- `docs/LEARNING.md` : des liens vers des ressources d'apprentissage.
- `docs/RESOURCES.md` : des liens vers des ressources utiles.
- `docs/TESTS.md` : décris tout ce qui concerne l'exécution des tests dans le parcours.

Ces documents aideront l'apprenant à démarrer avec le parcours, mais aussi à en apprendre plus sur le parcours et son langage.
Consulte la [documentation sur les docs](/docs/building/tracks/docs) pour plus d'informations.

## Ajoute la documentation des exercices

Ajoute les documents d'exercice suivants :

- `exercises/shared/.docs/help.md` : contient les instructions propres au parcours sur la façon d'obtenir de l'aide
- `exercises/shared/.docs/tests.md` : contient les instructions propres au parcours sur la façon de lancer les tests

## Ajoute un extrait de code

Ajoute un extrait de code dans le fichier `docs/SNIPPET.txt`.
Cet extrait donne un aperçu visuel de ce à quoi ressemble la syntaxe du langage.
Consulte la [documentation sur les docs](/docs/building/tracks/docs) pour plus d'informations.

## Mets à jour les métadonnées

Les métadonnées du parcours sont définies dans le [fichier config.json](/docs/building/tracks/config-json).
Les propriétés suivantes doivent être mises à jour :

- `language` : le langage du parcours (par exemple `"C#"`). Sa longueur doit être <= 255
- `slug` : le langage du parcours sous la forme d'une _string_ en minuscules et en `kebab-case` (par exemple `"csharp"`). Sa longueur doit être <= 255
- `blurb` : une courte description du langage. Sa longueur doit être <= 400
- `online_editor` : un objet décrivant les paramètres utilisés par l'éditeur en ligne :
  - `indent_style` : soit `"space"`, soit `"tab"`
  - `indent_size` : la taille de l'indentation sous forme d'entier (par exemple `4`)
  - `highlightjs_language` : l'identifiant de langage pour Highlight.js (voir la [liste complète des identifiants](https://github.com/highlightjs/highlight.js/blob/main/SUPPORTED_LANGUAGES.md)). S'il n'y a pas de prise en charge de Highlight.js, ce champ peut être omis.
- `key_features` : les fonctionnalités clés du langage, qui décrivent succinctement ses caractéristiques les plus importantes. Pour plus d'informations, consulte la [documentation sur les fonctionnalités clés](/docs/building/tracks/config-json#h-key-features).
- `tags` : définis les tags qui s'appliquent à ce parcours, ce qui permet de le retrouver dans la recherche sur le site. Pour plus d'informations et pour la liste des tags pris en charge, consulte la [documentation sur les tags](/docs/building/tracks/config-json#h-tags).
