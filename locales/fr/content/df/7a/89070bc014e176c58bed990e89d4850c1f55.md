# Instructions

Tu es professeur.
À la fin de l'année, tu as attribué une note chiffrée à chacun de tes élèves.
Tu dois maintenant la traduire en lettre et compter combien d'élèves ont obtenu chaque lettre

## 1. Traduis une note chiffrée en lettre

La fonction `letter_grade` prend une note chiffrée en entrée et renvoie la lettre correspondante.
Utilise les intervalles suivants :

| Lettre |        Note |
| :----: | ----------: |
|   A    | 90 % - 100 % |
|   B    |  80 % - 89 % |
|   C    |  70 % - 79 % |
|   D    |  60 % - 69 % |
|   F    |   0 % - 59 % |

Exemple :

```jq
75 | letter_grade   # => "C"
```

## 2. Compte le nombre d'élèves pour chaque lettre

La fonction `count_letter_grades` prend un objet qui associe le nom des élèves à leurs notes.
Le résultat est un objet qui associe chaque lettre au nombre d'élèves ayant obtenu cette note.

Exemple :

```jq
{"Joe": 78, "Jane": 93, "Richard": 72} | count_letter_grades
# => {"A": 1, "B": 0, "C": 2, "D": 0, "F": 0}
```

Il existe plusieurs façons de résoudre ce problème.
Utilise le filtre `reduce` pour t'entraîner.
