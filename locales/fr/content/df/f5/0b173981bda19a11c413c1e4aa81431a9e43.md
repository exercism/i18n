# Introduction

## Les nombres

Il existe trois types de nombres natifs en Python : `ints`, `floats` et `complex`. Toutefois, dans cet exercice, tu ne manipuleras que des `ints` et des `floats`.

### ints

Les `ints` sont des nombres entiers, par exemple `1234`, `-10` ou `20201278`.

Les entiers en Python bénéficient d'une [précision arbitraire][arbitrary-precision] : le nombre de chiffres n'est limité que par la mémoire disponible du système hôte.

### floats

Les `floats` sont des nombres qui comportent une partie décimale, par exemple `0.0`, `3.14` ou `-9.01`.

Les nombres à virgule flottante sont généralement implémentés en Python à l'aide d'un `double` en C (_15 décimales de précision_), mais leur représentation varie en fonction du système hôte et d'autres détails d'implémentation. Cela peut créer quelques surprises lorsqu'on travaille avec des _floats_, mais c'est « suffisamment bon » pour la plupart des situations.

## Arithmétique

Python prend entièrement en charge les opérations arithmétiques entre `ints` et `floats`. Il convertit les nombres les plus étroits pour les accorder à leur équivalent plus large lorsqu'ils sont utilisés avec les opérateurs arithmétiques binaires (`+`, `-`, `*`, `/`, `//` et `%`).

Python considère les `ints` comme plus étroits que les `floats`. Ainsi, utiliser un _float_ dans une expression garantit que le résultat sera lui aussi un _float_. Cependant, dans une division, le résultat est toujours un _float_, même si seuls des entiers sont utilisés.

```python
# The int is widened to a float here, and a float type is returned.
>>> 3 + 4.0
7.0
>>> 3 * 4.0
12.0
>>> 3 - 2.0
1.0
# Division always returns a float.
>>> 6 / 2
3.0
>>> 7 / 4
1.75
# Calculating remainders.
>>> 7 % 4
3
>>> 2 % 4
2
>>> 12.75 % 3
0.75
```

Si tu as besoin d'un résultat entier, tu peux utiliser `//` pour tronquer le résultat.

```python
>>> 6 // 2
3
>>> 7 // 4
1
```

Pour convertir un _float_ en entier, tu peux utiliser `int()`. Pour convertir un entier en _float_, tu peux utiliser `float()`.

```python
>>> int(6 / 2)
3
>>> float(1 + 2)
3.0
```
