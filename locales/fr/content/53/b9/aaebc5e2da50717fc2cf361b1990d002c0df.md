# Installation

## Installer .NET 10

Le parcours Visual Basic utilise .NET 10.
Pour compiler et tester les exercices en local, installe [le SDK .NET 10 correspondant à ton système d'exploitation][install-sdk] :
installe le SDK, pas seulement l'environnement d'exécution.

## Vérifie ton installation

Ouvre un nouveau terminal et exécute :

```bash
dotnet --version
```

La commande doit afficher `10.0.0` ou une version ultérieure.

## Prise en charge des éditeurs

Le SDK .NET et un éditeur de texte sans fioritures suffisent pour faire les exercices.
Pour des fonctionnalités plus avancées comme la complétion de code et le débogage, tu peux envisager l'un de ces éditeurs :

- [Visual Studio 2026][visual-studio] sous Windows
- [Visual Studio Code][visual-studio-code] sous Windows, Linux ou macOS
- [JetBrains Rider][rider] sous Windows, Linux ou macOS
