# Plages

[Plages][range] représentent un intervalle entre deux valeurs.
Les types les plus courants qui prennent en charge les plages sont `Integer` et `String`.
On peut les utiliser pour beaucoup de choses, comme créer rapidement une collection, découper des _strings_, vérifier si une valeur se trouve dans une plage et l'itération.
On les crée à l'aide de l'opérateur de plage `..` ou `...` (inclusif et exclusif, respectivement).

```ruby
1..5  # => 1..5
1...5 # => 1...5

(1..5).to_a # => [1, 2, 3, 4, 5]
(1...5).to_a # => [1, 2, 3, 4]
```

Disposer de deux opérateurs de plage permet de créer des plages qui incluent ou excluent la valeur de fin, ce qui peut être utile lorsqu'on travaille par exemple avec des indices commençant à zéro.

On peut aussi créer des plages à l'aide de l'initialiseur `Range`.

```ruby
Range.new(1, 5) # A range containing 1, 2, 3, 4, 5
```

~~~~exercism/note
Lorsqu'on crée une plage en Ruby avec les opérateurs de plage `..` ou `...`, et qu'on veut appeler une méthode sur cette plage, il faut la mettre entre parenthèses.
Sinon, la méthode serait appelée sur le deuxième argument de l'opérateur de plage.

```ruby
(1..5).sum # => 15
1..5.sum # => Error: undefined method `sum' for 5:Integer (NoMethodError)
```
~~~~

## Extrais des sous-chaînes

Quand on veut découper une _string_, on peut utiliser l'opérateur de plage pour obtenir une sous-chaîne.
Autrement dit, en créant une plage avec l'indice de début et de fin de la sous-chaîne.

```ruby
"Hello World"[0..4] # => "Hello"
"Hello World"[6..10] # => "World"
```

On peut aussi utiliser des indices négatifs pour obtenir la sous-chaîne à partir de la fin de la _string_.

```ruby
"Hello World"[-5..-1] # => "World"
"Hello World"[6..-4] # => "Wo"
```

## Méthodes des plages

Les plages disposent d'un ensemble de méthodes permettant de travailler avec elles.
Par exemple, ces méthodes permettent d'obtenir la somme de toutes les valeurs de la plage ou de vérifier si la plage contient une valeur.

| Méthode                 | Description                                                         | Exemple                         |
| ----------------------- | ------------------------------------------------------------------- | ------------------------------- |
| [`sum`][sum]            | Renvoie la somme de toutes les valeurs de la plage                  | `(1..5).sum # => 15`            |
| [`size`][size]          | Renvoie la taille de la plage                                       | `(1..5).size # => 5`            |
| [`include?`][indlude]   | Renvoie `true` si la plage contient la valeur donnée, sinon `false` | `(1..5).include?(3) # => true`  |

## Plages sans fin et sans début

Une plage peut être sans fin ou sans début.
Dans une plage sans fin ou sans début, la valeur de début ou de fin vaut `nil`, mais on peut omettre ce `nil` lors de la définition de la plage.

Utiliser des plages sans début et sans fin est utile lorsqu'on veut, par exemple, découper une _string_ depuis le début ou jusqu'à la fin.

```ruby
"Hello World"[0..] # => "Hello World"
"Hello World"[4..] # => "o World"
"Hello World"[..5] # => "Hello"
```

~~~~exercism/caution
Si on ne l'utilise pas sur une collection, une plage sans fin peut produire une séquence infinie, si on n'y prend pas garde.
~~~~

## Plages de _strings_

On peut aussi utiliser des _strings_ dans des plages, ce qui permet d'obtenir un intervalle de _strings_ entre deux _strings_.
Leur comportement peut être un peu inattendu avec certaines _strings_, alors utilise-les avec prudence.

```ruby
"aa".."az".to_a # => ["aa", "ab", "ac", ..., "az"]
```
