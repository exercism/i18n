# Installation

## Installe la CLI Clojure

Clojure fournit des outils en ligne de commande pour : lancer une REPL interactive (Read-Eval-Print Loop), exécuter des programmes Clojure et évaluer des expressions Clojure.
On t'encourage à utiliser la CLI Clojure avec les exercices. Pour installer la [CLI Clojure](https://clojure.org/guides/deps_and_cli) :

### Windows
Pour les instructions d'installation sous Windows, voir : [Installation de la CLI Clojure](https://clojure.org/guides/getting_started#_installation_on_windows).

### Linux
Pour les instructions d'installation sur la plupart des plateformes, voir : [Installation de la CLI Clojure](https://clojure.org/guides/getting_started#_installation_on_linux).

### Homebrew pour Mac OS X
Mets à jour Homebrew :

``` bash
$ brew update
```

Installe la CLI Clojure :
``` bash
$ brew install node clojure/tools/clojure
```

`Node` est nécessaire pour l'environnement Node.

## Teste l'installation

Pour vérifier que l'installation est correcte, exécute `clojure --help` : la version s'affiche si tout s'est bien passé.

```bash
$ clojure --help
Version: 1.10.1.547
...
```
