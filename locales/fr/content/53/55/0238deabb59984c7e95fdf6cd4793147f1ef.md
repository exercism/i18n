# Modulo

Les comparaisons avec modulo sont parfaitement valides en Crystal, mais une façon plus lisible de comparer le reste d'une division consiste à utiliser la méthode [`divisible_by?`][divisible_by].
Ou mieux encore, si tu veux vérifier si un nombre est impair ou pair, utilise les méthodes [`odd?`][odd?] et [`even?`][even?].

Par exemple :

```crystal
# Rather than:
number %% 2 == 0

# Consider:
number.even?
```
