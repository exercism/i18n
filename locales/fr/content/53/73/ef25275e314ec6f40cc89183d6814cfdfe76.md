# À propos

Lorsqu'on parcourt une séquence, l'élément seul ne suffit parfois pas : on a aussi besoin de la position. Les mots d'itération *indexée* de Factor donnent les deux à la quotation par élément, avec l'indice au sommet de la pile. `times` est le mot associé pour l'itération comptée, sans séquence sous-jacente.

```factor
USING: io kernel math.parser sequences ;

! map-index: build a new sequence; quot sees ( elt index )
{ "alice" "bob" "carol" }
[ number>string ": " glue ] map-index .
! => { "alice: 0" "bob: 1" "carol: 2" }

! each-index: for side effect; quot sees ( elt index )
{ "alice" "bob" } [
    number>string ": " glue print
] each-index
! prints alice: 0
! prints bob: 1

! times: run a quotation N times
3 [ "tick " print ] times
```

| mot          | effet                                                                |
|--------------|----------------------------------------------------------------------|
| `each-index` | `( seq quot: ( elt index -- ) -- )`                                  |
| `map-index`  | `( seq quot: ( elt index -- newelt ) -- newseq )`                    |
| `times`      | `( n quot: ( -- ) -- )`, mais voir ci-dessous                        |

Une subtilité concernant `times` : bien que sa quotation soit documentée comme `( -- )`, le mot est `inline`, donc une quotation équilibrée en termes d'effets comme `( str -- str )` fonctionne parfaitement et fait circuler la pile d'une itération à l'autre. On obtient ainsi un accumulateur compté sans le moindre état mutable :

```factor
USING: kernel sequences ;

"" 3 [ "clop " append ] times .    ! => "clop clop clop "
```

La même astuce fonctionne pour `each-index` et `map-index` : l'effet par élément déclaré est un *minimum*, pas un maximum.
