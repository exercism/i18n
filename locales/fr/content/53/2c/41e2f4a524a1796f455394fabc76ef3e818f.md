# Strings

Une _chaîne de caractères_ est une suite de caractères entourée de guillemets.
Les guillemets simples comme les guillemets doubles sont pris en charge.

```php
<?php

$where = "Spain";
$what = 'rain';
```

## Interpolation des variables dans les _strings_

Dans une _string_ entre guillemets doubles, si une variable est référencée alors qu'elle est dans la portée, sa valeur est insérée dans la _string_.

```php
<?php

$answer = 42;
$expanded = "The answer to life, the universe, and everything is $answer"; 
```

## Prise en charge de l'encodage des caractères

Historiquement, les fonctions de manipulation de _strings_ en PHP ne prenaient en charge que les caractères ASCII et ignoraient les encodages Unicode modernes.
Chaque caractère ASCII occupe 1 octet, alors qu'un caractère Unicode peut mesurer de 1 à 4 octets.
Si tu as besoin de manipuler des _strings_ Unicode en toute sécurité, consulte les [versions multioctets][multi-byte-fns] des fonctions historiques.

```php
<?php

$byte_length = strlen('😃'); // => 4
$string_length = mb_strlen('😃'); // => 1
```

[multi-byte-fns]: https://www.php.net/manual/en/ref.mbstring.php
