# Ajout aux instructions

## Registres

| Registre | Utilisation  | Type    | Description                                  |
| -------- | ------------ | ------- | -------------------------------------------- |
| `$a0`    | entrée       | entier  | nombre naturel à factoriser                  |
| `$a1`    | entrée/sortie | adresse | tableau de destination des facteurs premiers |
| `$v0`    | sortie       | entier  | nombre de facteurs                           |
| `$t0-9`  | temporaire   | quelconque | utilisé pour le stockage temporaire       |
