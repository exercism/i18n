# Tests

Pour exécuter les tests de ce parcours, il te faut installer DUnitX. Consulte les instructions d'[installation](http://www.exercism.org/docs/tracks/delphi/installation) pour en savoir plus.

### Charge des exercices dans Delphi

Si Delphi est correctement installé et que les fichiers `*.dpr` sont associés à Delphi, un double-clic sur le fichier `*.dpr` fourni démarre Delphi et charge l'exercice ou le projet.

Pour compiler le projet, utilise le raccourci clavier `control + F9` ; pour le compiler et l'exécuter, appuie sur `F9`.

Sinon, tu peux aussi lancer Delphi et charger le projet depuis le menu déroulant `File`.
