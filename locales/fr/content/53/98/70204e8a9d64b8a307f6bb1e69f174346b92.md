# À propos

On peut utiliser les [types d'énumération][enumeration types] dès que l'on a un ensemble fixe de valeurs constantes. Utiliser un `enum` permet d'interagir avec des valeurs constantes de manière sûre du point de vue des types. Pour définir une énumération, on utilise le mot-clé `enum`. Pour désigner un membre d'énumération, on le fait précéder du nom de l'énumération et d'un point (par exemple `Status.Active`).

Chaque membre d'énumération associe un nom à une valeur `int`. Si le premier membre n'a pas de valeur explicite, sa valeur est fixée à `0`. Si aucune valeur n'est définie explicitement pour un membre d'énumération, sa valeur est automatiquement fixée à la valeur du membre précédent plus `1`.

```csharp
enum Season
{
    Spring,     // Auto set 0
    Summer = 2, // Set the value 2
    Autumn,     // Auto set 3
    Winter = 7  // Set the value 7
}
```

Les énumérations sont très déclaratives. Compare les deux appels de méthode suivants :

```csharp
Users.WithStatus(1)
Users.WithStatus(Status.Active)
```

Pour quelqu'un qui lit le code, la seconde version (avec une énumération) sera plus facile à comprendre.

## Énumérations de type numérique

Bien que le type numérique par défaut des valeurs soit `int`, on peut le changer en spécifiant explicitement n'importe quel autre type [numérique intégral][integral numeric].

L'énumération suivante utilise le type numérique `byte` pour ses valeurs :

```csharp
enum Priority : byte
{
    Low = 0,
    Medium = 127,
    High = 255
}
```

## Convertis en membre d'énumération

Pense toujours à utiliser une énumération dès que tu veux modéliser quelque chose comme un booléen. Outre les avantages de lisibilité mentionnés plus haut, les énumérations ont un autre avantage sur les booléens : de nouvelles valeurs peuvent toujours être ajoutées à une énumération, alors qu'une valeur booléenne ne sera jamais que `true` ou `false`. Utiliser une énumération est donc plus pérenne.

```csharp
enum Status
{
    Inactive = 0,
    Active = 1
}

Status active = (Status) 1;
active == Status.Active; // True
```

Note que l'on _peut_ convertir des valeurs entières en une énumération, mais que cela peut mener à des résultats inattendus lorsque la valeur entière ne correspond à aucune valeur de l'énumération :

```csharp
Status status = (Status) 2;
status == Status.Inactive; // False
status == Status.Active;   // False
```

## Analyse une énumération

Il est parfois utile de convertir une _string_ en un membre d'énumération à partir de son nom avec [`Enum.Parse`][enum parse] :

```csharp
var input = "Inactive";
Status status = (Status)Enum.Parse(typeof(Status), input);
// Inactive
```

Pour vérifier si un nom ou une valeur existe dans l'énumération, tu peux utiliser [`Enum.TryParse`][enum tryparse] ou [`Enum.IsDefined`][enum isdefined], qui renvoient tous les deux un booléen indiquant si le membre d'énumération existe :

```csharp
bool doesExist = Enum.IsDefined(typeof(Status), "Inexistent");
// False
```
