# Introduction

## Variables et affectation

R est un langage à typage dynamique, donc en général il n'est pas nécessaire de préciser le type d'une variable. L'opérateur d'affectation à privilégier est `<-`

```R
x <- 42
avogadro <- 6.02e23
mystr <- "Hello, World!"
```

Utiliser `=` à la place de `<-` fonctionne souvent, mais pas toujours, et est déconseillé car considéré comme un mauvais style.
Si on travaille dans RStudio, on peut le saisir avec le raccourci clavier `Alt-minus`.

Les opérateurs sont pour la plupart conventionnels, mais il faut noter `%/%` et `%%` :

```R
2 + 3   # 5
2 - 3   # -1
2 * 3   # 6
2 / 3   # 0.6666667
8 %/% 3 # 2 (integer division)
8 %% 3  # 2 (remainder)
2 ^ 3   # 8 (exponential)
```

En R, `#` commence un commentaire sur une seule ligne.
Il n'existe pas de syntaxe distincte pour les commentaires sur plusieurs lignes.

## Fonctions

Pour définir une fonction :

```R
squareit <- function(x) {
    x * x
}
```

Les fonctions peuvent prendre zéro ou plusieurs arguments, séparés par des virgules.
Les parenthèses `()` sont nécessaires avec `function()`, même s'il n'y a aucun paramètre.

On peut spécifier des valeurs par défaut pour les arguments d'une fonction, mais celles-ci doivent venir après les arguments qui n'en ont pas, et on utilise `=` et non `<-` pour affecter la valeur par défaut.
Voici un exemple plutôt inutile :

```R
squareit <- function(x = 42) {
    x * x
}

squareit()
#> [1] 1764
```

Les accolades `{ }` ne sont pas strictement obligatoires pour un corps de fonction sur une seule ligne, mais les inclure est considéré comme un bon style.

R renvoie automatiquement la dernière valeur d'une fonction, comme dans les exemples ci-dessus.

On peut utiliser `return()` n'importe où dans le corps de la fonction pour rendre une valeur de retour explicite.

Appeler une fonction se fait comme dans beaucoup d'autres langages :

```R
squareit(3)
#> [1] 9
```
