# Tests

Pour tester ta solution, il suffit de lancer :

```bash
make test
```

Cela exécutera le fichier de test `<exercise-name>-test.ys`, qui contient tous les
tests que ta solution devra réussir pour être correcte.
Tu devrais étudier ce fichier de test pour comprendre exactement ce que ta
solution doit faire.

> Remarque : la première fois que tu lances `make test`, cela vérifiera aussi que
> la bonne version de l'interprète `ys` de YAMLScript est installée au bon
> endroit.

Si tu lances `make test` avant d'avoir modifié le moindre fichier, tous les tests
échoueront.
C'est le comportement normal et attendu.
Le processus habituel de développement d'un exercice consiste à améliorer ta
solution par itérations, en lançant `make test` après chaque modification,
jusqu'à ce que tous les tests passent.

Si tu veux exécuter un seul test en particulier (pendant que tu te concentres sur
cette partie de la solution), tu peux ajouter cette paire clé/valeur à ce test :

```yaml
  ONLY: true
```

Si tu veux ignorer certains tests (pendant que tu travailles sur d'autres parties
de la solution), tu peux ajouter cette paire clé/valeur à ces tests :

```yaml
  SKIP: true
```


## Prérequis pour les tests

YAMLScript fonctionne actuellement sur MacOS et Linux.

Ton ordinateur devra disposer des commandes suivantes, toutes très courantes :

* `bash` - Tu peux exécuter les tests dans n'importe quel shell, mais `bash` doit être disponible.
* `make` - Tu dois utiliser GNU `make` pour exécuter les tests.
  Dans certains environnements, il peut porter un nom différent de `make`.
  Par exemple `gmake`.
* `prove` - Ce programme fait partie de toute installation normale de Perl.
* `curl` - Utilisé pour installer ys s'il n'est pas déjà installé.

Il est très probable que tu aies déjà tous ces programmes installés.
