# Introduction

Les entiers ne se limitent pas à des valeurs numériques : on peut aussi les voir comme des motifs de bits. Le vocabulaire [`math`][math] de Factor fournit les opérations de bas niveau standard sur ces motifs de bits, et le vocabulaire [`math.bitwise`][bitwise] y ajoute quelques utilitaires pour travailler avec des valeurs à largeur fixe.

## Décalages de bits

`shift ( m n -- m' )` décale les bits de `m`. Un `n` *positif* décale vers la gauche (en multipliant par 2 à chaque étape) ; un `n` *négatif* décale vers la droite (en divisant par 2 à chaque étape) :

```factor
3 2 shift .     ! => 12   (3 << 2)
24 -3 shift .   ! => 3    (24 >> 3)
```

Pour les entiers positifs, le décalage vers la droite fait tomber les bits du bas et remplit avec des zéros. Pour les entiers *négatifs*, le `shift` de Factor est arithmétique : il préserve le bit de signe, et remplit conceptuellement depuis la gauche avec des copies de ce bit de signe. (Les entiers de Factor sont à précision arbitraire, donc « la gauche » s'étend aussi loin que nécessaire.)

## Logique bit à bit

Les quatre opérations logiques de base sont :

```
bitor  ( x y -- z )   ! 1 in either operand
bitand ( x y -- z )   ! 1 in both operands
bitxor ( x y -- z )   ! 1 in exactly one operand
bitnot ( x   -- z )   ! flip every bit
bit?   ( x n -- ? )   ! true when bit at position n is set
```

```factor
0b1011 0b0010 bitor .    ! => 11  (0b1011)
0b1011 0b0010 bitand .   ! => 2   (0b0010)
0b1011 0b0010 bitxor .   ! => 9   (0b1001)
0b1011 bitnot .          ! => -12
0b1011 0 bit? .          ! => t   (low bit is set)
0b1011 2 bit? .          ! => f   (bit 2 is clear)
```

Le `bitnot` de `0b1011` vaut `-12` parce que les entiers de Factor sont à précision arbitraire : inverser les bits de `0b1011` revient conceptuellement à « tous des uns, avec les quatre bits de poids faible basculés en `0100` », ce qui, lu comme un grand entier signé, donne `-12`.

## Traiter une valeur comme N bits

`bits ( x n -- y )` de `math.bitwise` masque `x` sur ses `n` bits de poids faible. C'est la façon dont Factor « réinterprète une valeur comme un entier non signé de N bits » :

```factor
-1 8 bits .              ! => 255   (lowest 8 bits of -1 are all 1)
-2144333657 32 bits .    ! => 2150633639
```

Ce deuxième exemple compte pour cet exercice. Si on part d'une valeur Int32 négative en complément à deux et qu'on veut la décaler vers la droite « logiquement » (en remplissant par des zéros depuis la gauche) de `amount`, l'idiome Factor est le suivant :

```
( value -- shifted )
32 bits  amount neg  shift
```

On masque d'abord sur 32 bits pour passer à l'interprétation non signée, puis on décale. Comme la valeur masquée est positive ou nulle, `shift` se contente de faire tomber les bits du bas et de compléter avec des zéros.
