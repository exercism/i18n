# Introduction

La mémoire dynamique est mise en œuvre par des fonctions de bibliothèque que le programmeur utilise pour allouer et libérer de la mémoire à l'exécution.
Comme c'est le programmeur qui contrôle l'allocation et la libération de la mémoire, la mémoire dynamique n'est sûre que dans la mesure où le programmeur ne commet pas d'erreur humaine.
Pour cette raison, la mémoire dynamique est l'une des principales sources de bugs et une cible de choix pour les attaques de piratage.

## malloc

`malloc` est une fonction déclarée dans `stdlib.h` qui sert à allouer de la mémoire dynamique.
Si l'allocation réussit, un pointeur est renvoyé, qui pointe vers l'adresse du premier octet de la mémoire allouée.
Si l'allocation échoue, `NULL` est renvoyé.
Il est prudent de vérifier que le résultat de `malloc` n'est pas `NULL` et de gérer proprement un éventuel échec.
Le pointeur renvoyé est de type `pointer-to-void`, que l'on peut considérer en gros comme un pointeur « générique » qui peut être converti vers le type précis utilisé par la mémoire.
`malloc` prend un paramètre, qui est la taille en octets de la mémoire souhaitée.
La taille totale nécessaire pour allouer un tableau est la taille du type de données de chaque élément multipliée par le nombre d'éléments.
L'opérateur `sizeof` est couramment utilisé pour obtenir la taille du type de données de chaque élément.
L'exemple suivant le montre

```c
#include <stdio.h>
#include <stdlib.h>

int * my_function(int count) {
    // pointer-to-void from malloc is converted to a pointer-to-int
    int * numbers = malloc(sizeof(int) * count);
    return numbers;
}

int main() {
    int * numbers = my_function(3);
    if (!numbers) return -1;
    // printed The size of numbers is 8 bytes (can vary by system)
    printf("The size of numbers is %zu bytes\n", sizeof(numbers));
    numbers[0] = 1;
    numbers[1] = 2;
    numbers[2] = 3;
    // prints The first element of the array is 1
    printf("The first element of the array is %d\n", numbers[0]);
    // prints The second element of the array is 2
    printf("The second element of the array is %d\n", numbers[1]);
    // prints The third element of the array is 3
    printf("The third element of the array is %d\n", numbers[2]);
    free(numbers);
    numbers = NULL;
}
```

Il est important de se rappeler que la mémoire fraîchement allouée par `malloc` n'est pas initialisée et peut contenir des valeurs parasites.
Note que le `sizeof` du pointeur `numbers` n'est ni le nombre d'éléments du tableau, ni la quantité totale de mémoire allouée.
La taille du pointeur renvoyé par `malloc` est celle de n'importe quel pointeur sur ce système donné.
Le code d'exemple a été exécuté sur un système 64 bits, donc la taille du pointeur était de 8 octets (multiplié par 8 bits par octet = 64 bits.)
Le type du pointeur a été converti implicitement de _pointer-to-void_ en _pointer-to-int_.
Il aurait aussi pu être converti explicitement, comme ceci : `int * numbers = (int *) malloc(sizeof(int) * count);`.
Si les valeurs seront à coup sûr écrites avant d'être lues, alors utiliser `malloc` peut être un moyen efficace d'allouer de la mémoire.
Mais s'il est possible que les valeurs soient lues avant d'être initialisées, alors utiliser `malloc` est risqué.
Une façon plus sûre d'allouer de la mémoire consiste à utiliser `calloc`, qui initialise à zéro la mémoire fraîchement allouée.

Note dans les exemples ci-dessus l'utilisation de `free(numbers)`.

## free

`free` est une fonction déclarée dans `stdlib.h` qui sert à libérer de la mémoire allouée dynamiquement.
La mémoire allouée dynamiquement reste réservée jusqu'à ce que `free` la libère.
Certains systèmes d'exploitation libèrent automatiquement la mémoire allouée dynamiquement à la fin du programme, mais la bonne pratique est de ne pas compter là-dessus.
`free` prend un paramètre, un pointeur vers la mémoire qui a été allouée dynamiquement.
Un pointeur qui n'est pas mis à `NULL` après avoir été libéré est appelé pointeur suspendu.
Un pointeur suspendu peut désigner une autre mémoire que celle à laquelle il était destiné.
Ainsi, un pointeur suspendu peut entraîner une corruption de données ainsi que la substitution et l'exécution de code arbitraire.
Un pointeur vers de la mémoire allouée qui n'a pas été remis à `NULL` peut servir à pirater le programme.
La bonne pratique est de mettre un pointeur à `NULL` après l'avoir passé à `free`.

## calloc

`calloc` est une fonction déclarée dans `stdlib.h` qui sert à la fois à allouer de la mémoire dynamique et à initialiser à zéro la mémoire fraîchement allouée.
Si l'allocation réussit, un pointeur est renvoyé, qui pointe vers l'adresse du premier octet de la mémoire allouée.
Si l'allocation échoue, `NULL` est renvoyé.
Il est prudent de vérifier que le résultat de `calloc` n'est pas `NULL` et de gérer proprement un éventuel échec.
Le pointeur renvoyé est de type `pointer-to-void`, que l'on peut considérer en gros comme un pointeur « générique » qui peut être converti vers le type précis utilisé par la mémoire.
`calloc` prend deux paramètres.
Le premier paramètre indique combien d'éléments du type de données indiqué doivent être alloués.
Le second paramètre indique la taille du type de données à allouer.

Dans l'exemple suivant, toutes les instructions `printf` devraient toujours afficher `0`, puisque `calloc` garantit la mise à zéro des valeurs fraîchement allouées.

```c
#include <stdio.h>
#include <stdlib.h>

int * my_function(int count) {
    // allocates the amount of bytes in an int, multiplied by count
    int * numbers = calloc(count, sizeof(int));
    return numbers;
}

int main() {
    int * numbers = my_function(3);
    if (!numbers) return -1;
    // prints The first element of the array is 0
    printf("The first element of the array is %d\n", numbers[0]);
    // prints The second element of the array is 0
    printf("The second element of the array is %d\n", numbers[1]);
    // prints The third element of the array is 0
    printf("The third element of the array is %d\n", numbers[2]);
    free(numbers);
    numbers = NULL;
}
```

## realloc

`realloc` est une fonction déclarée dans `stdlib.h` qui sert soit à agrandir, soit à réduire de la mémoire déjà allouée.
Si la réallocation réussit, un pointeur est renvoyé, qui pointe vers l'adresse du premier octet de la mémoire réallouée.
Si la réallocation échoue, `NULL` est renvoyé.
Il est prudent de vérifier que le résultat de `realloc` n'est pas `NULL` et de gérer proprement un éventuel échec.
`realloc` prend deux paramètres.
Le premier paramètre est un pointeur vers la mémoire existante à réallouer.
Le second paramètre indique la taille en octets de la mémoire réallouée.
Les valeurs définies avant l'agrandissement de la mémoire sont conservées.
Il est important de se rappeler que la mémoire ajoutée lors de l'agrandissement n'est pas initialisée à zéro et que ses valeurs peuvent être n'importe quoi.
De même, la mémoire supprimée lors de la réduction n'est pas non plus initialisée et peut conserver ses valeurs.
L'exemple suivant montre l'agrandissement et la réduction d'un tableau

```c
#include <stdio.h>
#include <stdlib.h>

int * my_function(int count) {
    // allocates the amount of bytes in an int, multiplied by count
    int * numbers = calloc(count, sizeof(int));
    return numbers;
}

int * my_function_2 (int * ptr , int count) {
    // reallocates the memory to the size of an int multiplied by count
    int * numbers = realloc(ptr, sizeof(int) * count);
    // if realloc fails, exit the program
    if (!numbers) exit(-1);
    return numbers;
}

int main() {
    int * numbers = my_function(3);
    if (!numbers) return -1;
    numbers[0] = 1;
    numbers[1] = 2;
    numbers[2] = 3;
    // expand the size of the array
    numbers = my_function_2(numbers, 6);
    // prints The first element of the array is 1
    printf("The first element of the array is %d\n", numbers[0]);
    // prints The sixth element of the array is [whatever is there]
    // the additional memory is not initialized, so it could be
    // 0 or it could be 18728 or anything else
    printf("The sixth element of the array is %d\n", numbers[5]);
    numbers[5] = 6;
    // shrink the size of the array
    numbers = my_function_2(numbers, 3);
    // prints The sixth element of the array is [whatever is there]
    // the removed memory is not initialized, so it could be
    // 6 or it could be 43164 or anything else
    printf("The sixth element of the array is %d\n", numbers[5]);
}
```
