# Instructions

Larry est un Lisp Alien qui aime écrire du code pour jouer à des jeux.
Aujourd'hui, Larry veut écrire quelques fonctions pour l'aider dans un jeu qui ressemble beaucoup au morpion.

Comme au morpion, on joue à ce jeu sur un plateau qui est une grille 3x3.

## 1. Pars de zéro

D'abord, Larry a besoin d'une fonction pour créer un plateau vide `make-empty-board`.
Toutes les cases du plateau doivent être `NIL`.

```lisp
(make-empty-board) ; => #2A((NIL NIL NIL) (NIL NIL NIL) (NIL NIL NIL))
```

## 2. Pars d'un plateau existant

Ensuite, Larry a besoin d'une fonction pour créer un plateau à partir d'une liste de lignes.
Par exemple :

```lisp
(make-board-from-list '((A B C) (D E F) (G H I))) ; => #2A((A B C) (D E F) (G H I))
```

## 3. Condition de victoire

S'il arrive que trois symboles identiques soient alignés, alors ce joueur a gagné.
Larry aura besoin d'une fonction, `all-the-same-p`, qui, recevant un tableau de 3 éléments, vaut `T` si tous les éléments sont le même symbole.
(On peut utiliser `eq` pour déterminer si deux symboles sont identiques.)

```lisp
(all-the-same-p #(A A A)) ; => T
(all-the-same-p #(A B C)) ; => NIL
```

## 4. Dans une ligne

Maintenant, Larry a besoin d'un moyen d'obtenir les éléments d'une ligne.
La fonction `row` prend un plateau et un numéro de ligne et doit renvoyer un tableau contenant les éléments de cette ligne.

```lisp
(row #2A((1 2 3) (4 5 6) (7 8 9)) 1) ; => #(4 5 6)
```

## 5. Dans une colonne

Enfin, Larry a besoin d'un moyen d'obtenir les éléments d'une colonne.
La fonction `column` prend un plateau et un numéro de colonne et doit renvoyer un tableau contenant les éléments de cette colonne.

```lisp
(column #2A((1 2 3) (4 5 6) (7 8 9)) 1) ; => #(2 5 8)
```
