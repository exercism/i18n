# Les nombres

Crystal possède un type, `Number`, qui est le type de base de tous les types numériques.
Le type Number comporte deux sous-types principaux : [`Int`][int] et [`Float`][float].

`Int` est l'abréviation d'_integer_ et représente les nombres entiers.
`Int` peut être négatif ou positif, et ne comporte pas de virgule.

```crystal
1.class
# => Int32

-1.class
# => Int32
```

`Float` représente les nombres à virgule.
Les `Float` peuvent être négatifs ou positifs.

```crystal
10.5.class
# => Float64
```

## Conversion entre `Int` et `Float`

En utilisant les méthodes 'to_i' et 'to_f', on peut convertir une valeur entre `Int` et `Float`.
Lors de la conversion d'un `Float` en `Int`, le nombre est arrondi vers le bas.

```crystal
1.to_f
# => 1.0

1.0.to_i
# => 1

1.9.to_i
# => 1
```

## Opérateurs arithmétiques

Tu peux utiliser les [opérateurs arithmétiques de base][math] sur `Int` et `Float`.
Ces opérateurs sont `+`, `-`, `*`, `/` et `%`.
Quand on utilise ces opérateurs, on peut mélanger `Int` et `Float`.

### Addition, soustraction et multiplication

L'opérateur `+` sert à l'addition, l'opérateur `-` à la soustraction et l'opérateur `*` à la multiplication.

| Opérateur | Exemple        |
| -------- | -------------- |
| `+`      | `4 + 6 => 10`  |
| `-`      | `15 - 10 => 5` |
| `*`      | `2 * 3 => 6`   |

### Division

La division sert à diviser des nombres.
L'opérateur `/` sert à la division.
Le résultat est toujours un Float.

```crystal
4 / 2
# => 2.0

4.0 / 2
# => 2.0
```

~~~~exercism/caution
Dans certains langages de programmation, la division par zéro provoque une erreur.

En Crystal, la division par zéro donne `Infinity` ou `-Infinity`.
La seule exception est la division de zéro par zéro, qui donne `NaN` (Not a Number).
`Infinity` et `NaN` sont des valeurs particulières du type `Float`.

```crystal
1 / 0
# => Infinity

-1 / 0
# => -Infinity

0 / 0
# => NaN
```
~~~~

## Division entière

La division entière sert à diviser des nombres et à obtenir la partie entière du résultat.
Le résultat est toujours arrondi vers le bas pour donner un Int.

```crystal
4.0 // 2
# => 2

4.5 // 2
# => 2
```

~~~~exercism/caution
La division par zéro avec la division entière provoque une `DivisionByZeroError`.
C'est différent de la division normale.
~~~~

### Modulo

Le modulo sert à obtenir le reste d'une division.
L'opérateur `%` sert au modulo.

```crystal
5 % 2
# => 1

5.0 % 2
# => 1.0

5 % 3
# => 2
```

~~~~exercism/caution
La division par zéro avec le modulo provoque une DivisionByZeroError.
C'est différent de la division normale.

```crystal
1 % 0
# Error: Unhandled exception: Division by 0 (DivisionByZeroError)
```
~~~~

## Exponentiation

L'exponentiation sert à élever un nombre à une puissance.
L'opérateur `**` sert à l'exponentiation.
Le résultat d'une opération entre un `Float` et un `Int` est un `Float`.

```crystal
2 ** 2
# => 4

2.0 ** 2
# => 4.0
```

## Arrondi

La méthode `round` prend un argument facultatif : le nombre de décimales avec lequel arrondir.
La valeur par défaut du nombre de décimales est 0.

```crystal
1.0.round
# => 1

1.5.round
# => 2

1.234.round(2)
# => 1.23
```

### Arrondir vers le haut et vers le bas

Tu peux aussi arrondir vers le haut ou vers le bas jusqu'à un `Int` grâce aux méthodes `ceil` et `floor`.
La méthode `ceil` arrondit vers le haut, et la méthode `floor` arrondit vers le bas.

```crystal
1.0.ceil
# => 1

1.2.ceil
# => 2

1.7.floor
# => 1
```

## Priorité et parenthèses

Crystal accepte les parenthèses (`()`), qui permettent de regrouper des expressions.
C'est utile quand tu veux modifier l'ordre des opérations.

Quand tu utilises plusieurs opérateurs arithmétiques, l'ordre des opérations est le même qu'en mathématiques, aussi appelé [PEMDAS][pemdas].
Il suit l'ordre suivant : les parenthèses (`()`), les exposants (`**`), la multiplication (`*`) et la division (`/`), puis l'addition (`+`) et la soustraction (`-`).

```crystal
2 + 3 - 4 * 4
# => -11

(2 + 3 - 4) * 4
# => 4
```
