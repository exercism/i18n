# Instructions

Tu diriges un cinéma exclusif.
Pour assister à une séance, les clients doivent acheter un abonnement annuel, après quoi ils peuvent voir les films gratuitement.

Ton cinéma tient un registre des entrées.
Tu veux utiliser ce registre pour savoir quels membres ont utilisé leur abonnement annuel ce mois-ci.
Tu veux aussi obtenir des informations sur la répartition par âge de tes clients.
Tu te rends compte que les ensembles peuvent t'aider à atteindre ces objectifs.

## Les ensembles

Un ensemble est le type de données idéal pour stocker ce genre d'informations.

Un ensemble est un type de données qui sert à stocker des valeurs distinctes et uniques, sans ordre particulier.
Distinctes et uniques signifie qu'un élément est soit dans l'ensemble, soit absent ; contrairement à un tableau, il ne peut pas s'y trouver plusieurs fois.
Les ensembles ne sont généralement pas ordonnés ; si tu listes les éléments d'un ensemble, l'ordre obtenu peut différer de l'ordre dans lequel ils ont été ajoutés, ou même de l'ordre obtenu dans la liste précédente !

Une propriété fondamentale des ensembles est le test d'appartenance : la possibilité de vérifier si un ensemble contient un élément.
Le test d'appartenance est au cœur de presque tous les usages d'un ensemble.

Go ne fournit pas de type ensemble intégré.
Il est courant d'utiliser une `map[<type>]struct{}` ou une `map[<type>]bool` à la place d'un ensemble ; comme un ensemble, une `map` permet d'ajouter des éléments distincts et uniques et prend en charge le test d'appartenance.

## 1. Un endroit où stocker les informations des participants

Pour suivre les entrées et la répartition par âge, tu veux utiliser un ensemble.

Tu ne veux pas écrire deux ensembles séparés, un pour les noms et un pour les âges ; à la place, tu peux utiliser un ensemble générique pour les deux.
Définis un type `Set` comme une `map[T comparable]struct{}` pour stocker les participants.
Écris une fonction `NewSet[T comparable]()` qui renvoie un `Set[T]` vide.

```go
names := NewSet[string]()
```

## 2. Suivre les participants

Tu peux maintenant enregistrer les informations des participants.

Écris une méthode `Add[T]()` qui ajoute un élément à l'ensemble.

```go
names := NewSet[string]()
names.Add("Alice")
```

## 3. Vérifier les participants

Maintenant que tu as un ensemble de participants, tu peux vérifier si certains membres et certaines tranches d'âge se sont présentés.
Écris une méthode `Contains[T](element)` qui indique si un membre ou une tranche d'âge est présent dans le `Set`.

```
names := NewSet[string]()
names.Add("Alice")
names.Contains("Alice")
// => true
names.Contains("Bob")
// => false
```

## 4. Comparer les participants

Un autre mois est passé et tu as un nouveau `Set` de tranches d'âge.
Ton responsable marketing veut savoir si les nouvelles sorties de ce mois ont changé les tranches d'âge qui viennent.
Écris une méthode `Equals[T](other)` qui détermine si deux ensembles ont les mêmes éléments.

```go
agesOne := NewSet[int]()
names.Add(25)

agesTwo := NewSet[int]()
names.Add(25)

agesOne.Equals(agesTwo)
// => true

agesThree := NewSet[int]()
names.Add(35)

agesOne.Equals(agesThree)
// => false
```
