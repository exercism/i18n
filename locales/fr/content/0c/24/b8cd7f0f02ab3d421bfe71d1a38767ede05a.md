# À propos

L'[opérateur conditionnel ternaire][ternary-operator] est une forme abrégée et concise d'une expression `if-else`.
Il évalue une condition et renvoie l'une de deux valeurs selon que cette condition est `true` ou `false`.

L'opérateur s'écrit en trois parties : `condition ? trueExpression : falseExpression`.
Si `condition` vaut `true`, c'est `trueExpression` qui est évaluée et renvoyée ; sinon, c'est `falseExpression`.

L'opérateur ternaire est idéal pour des choix simples, sur une seule ligne :

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = showFahrenheit ? temperatureInCelsius * 9 / 5 + 32 : temperatureInCelsius
print(temperature)
// Prints 86
```

L'exemple ci-dessus est l'équivalent compact de :

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = if showFahrenheit {
    temperatureInCelsius * 9 / 5 + 32
} else {
    temperatureInCelsius
}
```

[ternary-operator]: https://docs.swift.org/swift-book/LanguageGuide/BasicOperators.html#ID71
