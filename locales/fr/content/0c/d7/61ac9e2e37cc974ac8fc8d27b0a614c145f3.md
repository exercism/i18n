# Introduction

On crée une instance d'une classe en appelant son _constructeur_ à l'aide de l'opérateur `new`. Un constructeur est une méthode spéciale au sein d'une classe, dont le but est d'initialiser celle-ci. En Haxe, la méthode constructeur porte le nom de `new()`.

```haxe
class Library {
  private var books:Int;

  public function new() {
    this.books = 10; // Initialize the books field
  }
}

var library = new Library(); // This calls the constructor
```

Comme n'importe quelle autre méthode, un constructeur peut prendre des paramètres. Ces paramètres sont (en général) stockés dans des champs privés, auxquels on accède par la suite.

```haxe
class Building {
  private var numberOfStories:Int;
  private var totalHeight: Float;

  public function new(numberOfStories:Int, storyHeight:Float) {
    this.numberOfStories = numberOfStories;
    this.totalHeight = storyHeight * numberOfStories;
  }
}

var largeBuilding = new Building(55, 6.2);
```
