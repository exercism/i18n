# Enseignes personnalisées

## Histoire

Dans cet exercice, on va écrire du code pour aider une entreprise spécialisée dans les enseignes à créer des messages personnalisés pour ses panneaux.

## Tâches

Voici des exemples de tâches qui correspondent à l'histoire d'un client qui conçoit une enseigne personnalisée : 

- Crée un ensemble de _strings_ utiles
- Crée un ensemble de caractères utiles
- Combine des phrases pour construire des messages
- Construis une enseigne de remise de diplôme
- Calcule le coût d'une enseigne
