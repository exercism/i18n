# Indices

## 1. Calcule le taux d'intérêt

- Tu es censé renvoyer un pourcentage.

## 2. Calcule les intérêts

- Pour calculer les intérêts, il peut être utile de remarquer que `interest_rate` renvoie un pourcentage.
- Tu peux utiliser la fonction définie dans la tâche précédente (`interest_rate`) pour calculer les intérêts.

## 3. Calcule la mise à jour annuelle du solde

- Pour calculer la mise à jour annuelle du solde, utilise les fonctions qui ont été définies dans les étapes précédentes.

## 4. Calcule le nombre d'années avant d'atteindre le solde souhaité

- Pour calculer le nombre d'années, on peut continuer à boucler jusqu'à atteindre le solde souhaité, à l'aide d'une boucle [`for`][for].
- Il existe un [opérateur][increment] spécial pour incrémenter une valeur de 1.
