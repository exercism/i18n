# Instructions

Tori est journaliste spécialisée dans le climat et elle veut écrire un article sur la météo de différentes villes. Elle dispose de données sur la météo de plusieurs villes et souhaite les classer en fonction de leur température, mais certaines températures sont en Fahrenheit et d'autres en Celsius. Elle a besoin de ton aide pour convertir les températures dans la même unité et les classer.

## 1. Convertis Fahrenheit en Celsius

Définis la fonction `fahrenheit_to_celsius` qui prend une température en Fahrenheit en argument et renvoie la température en Celsius.

Pour convertir des degrés Fahrenheit en degrés Celsius, soustrais 32 à la valeur en Fahrenheit, puis divise le résultat par 1,8.

```gleam
fahrenheit_to_celsius(72.5)
// -> 22.5
```

## 2. Compare deux températures

Définis la fonction `compare_temperature` qui prend deux températures et renvoie une valeur de type `Order` indiquant si la première température est inférieure, égale ou supérieure à la seconde.

```gleam
compare_temperature(Celsius(30.5), Fahrenheit(82.1))
// -> Gt
```

## 3. Trie les villes par température

Définis la fonction `sort_cities_by_temperature` qui prend une liste de villes et les renvoie de la plus froide à la plus chaude.

```gleam
sort_cities_by_temperature([
  City(name: "London", temperature: Celsius(30.5)),
  City(name: "Paris", temperature: Fahrenheit(82.1))
])
// -> [
//   City(name: "Paris", temperature: Fahrenheit(82.1)),
//   City(name: "London", temperature: Celsius(30.5)))
// ]
```
