# Introduction

En Go, une `struct` est une suite d'éléments nommés appelés _champs_, chaque champ possède un nom et un type.
Le nom d'un champ doit être unique au sein de la structure.
Les structures peuvent être comparées aux _classes_ de la programmation orientée objet.

## Définis une structure

On crée une nouvelle structure en utilisant les mots-clés `type` et `struct`, et on définit explicitement le nom et le type des champs.
Par exemple, ici on définit la structure `Shape`, qui contient le nom d'une forme et sa taille :

```go
type Shape struct {
    name string
    size int
}
```

Les noms de champs dans les structures suivent la convention Go : les champs dont le nom commence par une lettre minuscule ne sont visibles que par le code du même paquet, tandis que ceux dont le nom commence par une lettre majuscule sont visibles dans les autres paquets.

## Crée des instances d'une structure

Une fois que tu as défini la `struct`, il faut créer une nouvelle instance en définissant les champs par leur nom, dans n'importe quel ordre :

```go
s := Shape {
    name: "Square",
    size: 25,
}
```

Pour lire ou modifier les champs d'une instance, on utilise la notation `.` :

```go
// Update the name and the size
s.name = "Circle"
s.size = 35
fmt.Printf("name: %s size: %d\n", s.name, s.size)
// Output: name: Circle size: 35
```

Les champs qui n'ont pas de valeur initiale assignée auront leur valeur zéro.
Par exemple :

```go
s := Shape{name: "Circle"}
fmt.Printf("name: %s size: %d\n", s.name, s.size)
// Output: name: Circle size: 0
```

Tu peux créer une instance d'une `struct` sans utiliser les noms de champs, tant que tu définis les champs _dans l'ordre_ :

```go
s := Shape {
	"Oval",
	20,
}
```

Cependant, cette syntaxe est considérée comme du _code fragile_, car elle peut casser lorsqu'un champ est ajouté, surtout lorsque le nouveau champ est d'un type différent.
Dans l'exemple suivant, on ajoute un champ supplémentaire à `Shape` :

```go
type Shape struct {
	name        string
	description string // new field 'description' added
	size        int
}

s := Shape{
    "Circle",
    20,
}
// Since the second field of the struct is now a string and not an int,
// the compiler will throw an error when compiling the program:
// Output: cannot use 20 (type untyped int) as type string in field value
// Output: too few values in Shape{...}
```

## Les fonctions « New »

Parfois, il peut être pratique d'avoir des fonctions qui nous aident à créer des instances de structures.
Par convention, ces fonctions s'appellent généralement `New` ou ont leur nom qui commence par `New`, mais comme ce sont de simples fonctions, tu peux leur donner le nom que tu veux.
Elles peuvent te rappeler les constructeurs d'autres langages, mais en Go, ce ne sont que des fonctions ordinaires.

Dans l'exemple suivant, l'une de ces fonctions `New` est utilisée pour créer une nouvelle instance de `Shape` et définir automatiquement une valeur par défaut pour la `size` de la forme :

```go
func NewShape(name string) Shape {
	return Shape{
		name: name,
		size: 100, //default-value for size is 100
	}
}

NewShape("Triangle")
// => Shape { name: "Triangle", size: 100 }

```

Utiliser des fonctions `New` peut présenter les avantages suivants :

* la validation des valeurs données
* la gestion des valeurs par défaut
* comme les fonctions `New` sont souvent déclarées dans le même paquet que les structures qu'elles initialisent, elles peuvent même initialiser des champs privés de la structure

Pour approfondir ce type, tu peux consulter ces ressources : [Go by Example: Structs][go-by-example-structs], [A Tour of Go: Structs][tour-of-go-structs] ou [Structures in Go (structs)][medium-structures-in-go]

## La fonction intégrée `new`

Une autre façon de créer une nouvelle instance d'une structure consiste à utiliser la fonction intégrée `new` :

```go
s := new(Shape) // s will be of type *Shape (pointer to shape)
fmt.Printf("name: %s size: %d\n", s.name, s.size)
// Output: name:  size: 0
```

Dans cet exemple, `new` crée une instance de la structure `Shape` avec toutes les valeurs initialisées à la valeur zéro de leur type et renvoie un pointeur vers celle-ci.

~~~~exercism/note
La plupart du temps, tu ne verras pas de nouvelles instances de structures créées avec la fonction intégrée `new`.
Préfère toujours utiliser un littéral de structure, une fonction `New` personnalisée ou toute autre fonction fournie par le paquet qui peut t'aider à construire une structure.
N'utilise la fonction intégrée `new` pour créer de nouvelles instances de structures qu'en dernier recours.
~~~~
