# À propos

La récursion est une façon de répéter du code dans une fonction, en faisant en sorte que la fonction s'appelle elle-même.
C'est une autre manière de faire des boucles, c'est-à-dire d'itérer. Comme pour une boucle, la fonction doit tester une expression booléenne pour savoir quand s'arrêter.
Contrairement à une boucle, une récursion qui ne se termine jamais ne s'exécute pas indéfiniment.
Les valeurs utilisées dans chaque appel de fonction peuvent être placées dans leur propre trame sur la pile.
Si le nombre d'appels de fonction occupe plus d'espace que la pile n'en dispose, cela provoque une erreur de débordement de pile.

```c
int printIncrement (int i, int maxValue){
    if (i > maxValue) return i;
    printf("The number is %i\n", i++);
    printIncrement(i, maxValue);
}

int main() {
    printIncrement(1, 2);
    printf("After recursion");
    return 0;
}
```

Cela affiche

```
The number is 1
The number is 2
After recursion
```

Certaines situations sont parfois plus lisibles et/ou plus faciles à comprendre lorsqu'elles sont exprimées avec de la récursion plutôt qu'avec une boucle.


## Appel terminal

Un appel terminal, c'est lorsque la dernière instruction d'une fonction se contente de s'appeler elle-même, sans rien faire de plus.

Un appel terminal est une forme particulière de récursion qui peut permettre au compilateur d'optimiser la récursion en une boucle dans le code compilé.
Cela offre le meilleur des deux mondes : la lisibilité de la récursion avec les performances d'une boucle.
La compilation d'une récursion en boucle s'appelle `tail call elimination` ou `tail call optimization.`

Lorsqu'un appel terminal est compilé en boucle, une nouvelle trame de pile n'est pas créée à chaque appel de fonction.
L'adresse de la fonction appelée à l'origine reçoit les valeurs mises à jour, ce qui économise de l'espace sur la pile et améliore les performances.

Cet exemple n'est pas un appel terminal, car la fonction ajoute 1 au résultat de son propre appel

```c
int printIncrement (int i, int maxValue){
    if (i > maxValue) return 1;
    printf("The number is %i\n", i++);
    return 1 + printIncrement(i, maxValue);
}

int main() {
    int j = printIncrement(1, 2);
    printf("j is %i after recursion", j);
    return 0;
}
```

Cela affiche

```
The number is 1
The number is 2
j is 3 after recursion
```

Pour la réécrire sous forme d'appel terminal, fais de `j` un paramètre de `printIncrement`

```c
int printIncrement (int i, int maxValue, int j){
    if (i > maxValue) return j;
    printf("The number is %i\n", i++);
    return printIncrement(i, maxValue, ++j);
}

int main() {
    int j = printIncrement(1, 2, 1);
    printf("j is %i after recursion", j);
    return 0;
}
```

Tu trouveras peut-être qu'un appel terminal est plus facile à comprendre qu'un appel récursif qui n'est pas un appel terminal.
Cependant, les compilateurs ne garantissent généralement pas que tous les appels terminaux seront optimisés.
Quand on utilise la récursion, il est toujours important de savoir que le nombre d'itérations ne sera pas si grand que la pile finira par déborder.
