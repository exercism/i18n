Raku est un langage de programmation incroyablement riche, flexible et puissant.
Sa flexibilité permet aux programmeurs d'écrire du code expressif qui correspond à leur propre style.

Raku est un langage vaste, qui offre beaucoup de matière à apprendre, à explorer et à expérimenter.
Ce programme a pour but de couvrir les fondamentaux pour t'aider à démarrer.

La programmation orientée objet est au cœur de Raku, mais elle n'impose pas les pratiques de la programmation orientée objet.
En raison de sa nature orientée objet, ce programme fera souvent référence aux [objets, classes et méthodes][object-orientation].

## Variables

Pour rester simple, nous n'utiliserons que des [variables][variables] scalaires dans les bases.

Les variables scalaires sont des [identifiants][identifiers] précédés du sigil `$`.

Les variables scalaires peuvent contenir à peu près n'importe quoi, et leur type par défaut est [`Any`][Any].

La plupart des variables que tu utiliseras auront besoin d'une [déclaration][variable-declarator].
Pour l'instant, on s'en tiendra à [`my`][my] et [`constant`][constant].

```raku
my $foo;
constant $BAR;
```

## Sous-routines

Une sous-routine se déclare avec le déclarateur [`sub`][sub-declarator].

Une déclaration `sub` est suivie d'un [identifiant][identifiers] optionnel, puis d'une [signature][signatures] optionnelle, puis d'un [bloc][blocks].

Les sous-routines (entre autres choses) peuvent être exportées en ajoutant le trait [`is export`][exporting].

On peut appeler une sous-routine en appliquant un opérateur [postcirconfixe `( )`][postcircumfix-()] à l'identifiant.

```raku
sub foo ($bar) is export { ... } # Subroutine definition

foo($bar); # Subroutine call
```

## Opérateurs

Raku possède une grande variété d'[opérateurs][operators].
Pour les exercices du concept des bases, on utilisera quelques opérateurs mathématiques de base de Raku, comme `+` et `-`.

```raku
say 0.1 + 0.2 - 0.3;
# Raku is not like other languages -> https://0.30000000000000004.com/#raku
```

Tu peux facilement définir tes propres opérateurs en Raku si tu le souhaites.
La plupart des opérateurs intégrés sont aussi disponibles sous forme de sous-routines.

## Paquets et modules

Il existe plusieurs types de [paquets][package-declarator] en Raku. Dans les bases, nous n'utiliserons que `module`.

Pour déclarer un fichier entier comme `module`, on fait précéder la déclaration du module de `unit`.

```raku
unit module Foo;

sub bar () { ... }
```

## Commentaires

Raku dispose de [commentaires sur une seule ligne][single-line-comments] et de [commentaires multilignes ou intégrés][multi-line-comments].

Les commentaires sur une seule ligne commencent par `#` et se poursuivent jusqu'à la fin de la ligne.

Les commentaires multilignes ou intégrés commencent par un dièse suivi d'un accent grave et d'un caractère Unicode de ponctuation ouvrante.
Ils se terminent par le caractère fermant correspondant.

```raku
# This is a single-line comment

#`(
    This is a
    multi-line/embedded comment
)
```

## Conventions de style

Les [identifiants][identifiers] de variables et de sous-routines en Raku s'écrivent en `kebab-case`.
Les constantes s'écrivent en `ALL-CAPS`.
Les noms de paquets s'écrivent en `PascalCase`.
