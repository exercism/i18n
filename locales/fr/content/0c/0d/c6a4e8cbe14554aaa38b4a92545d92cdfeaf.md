# Debug

Quand un test échoue, un message s'affiche pour décrire ce qui s'est mal passé et pour quelle entrée. Tu peux aussi tirer parti du fait que toute [sortie de la console][dotnetperls.com-console-vbnet] sera affichée, elle aussi. Pour écrire dans la console, utilise :

```vbnet
Console.WriteLine("Debug message");
```

[dotnetperls.com-console-vbnet]: https://www.dotnetperls.com/console-vbnet
