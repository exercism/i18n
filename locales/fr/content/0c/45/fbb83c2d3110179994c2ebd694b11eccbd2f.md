# Introduction

Swift dispose d'instructions de transfert de contrôle pour modifier le déroulement de l'exécution des boucles et des instructions `switch`.
En plus de `return`, Swift propose `continue`, `break`, les étiquettes de boucle et `fallthrough`.

## Continue

L'instruction `continue` demande à une boucle d'arrêter l'exécution de l'itération en cours et de passer immédiatement à l'itération suivante.
Dans une boucle `while` ou `repeat-while`, elle saute directement à la vérification de la condition.
Dans une boucle `for-in`, elle passe à l'élément suivant de la séquence.

```swift
var count = 1
while count < 6 {
    count += 1
    if count == 4 {
        continue
    }
    print(count)
}

// Prints:
// 2
// 3
// 5
// 6
```

## Break

L'instruction `break` permet de sortir immédiatement d'une boucle ou d'une instruction `switch` entière.
L'exécution reprend à la première ligne de code qui suit la boucle ou le `switch`.

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
    if !fruit.count.isMultiple(of: 2) {
        break
    }
    print(fruit)
}

// Prints:
// banana
// grapes
```

## Instructions étiquetées

Dans des boucles imbriquées, tu peux vouloir que `break` ou `continue` agisse sur une boucle externe plutôt que sur la boucle la plus interne.
Pour étiqueter une boucle, il suffit de la faire précéder d'un nom suivi de deux-points (`labelName:`).
Tu peux ensuite passer cette étiquette à `break` ou à `continue` :

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
    print("\n--- \(fruit) ---")
    for letter in fruit {
        guard letter != "n" else {
            break outerLoop
        }
        print(letter)
    }
}

// Prints:
// --- banana ---
// b
// a
```
