# ne modifie pas les signatures fournies

Comme les instructions le mentionnent, tu ne dois pas modifier les signatures de `makeChest` et `makeTreasureChest`.
Elles doivent rester exactement telles quelles :

```elm
makeChest : String -> treasure -> Chest treasure {}

makeTreasureChest : Chest treasure { conditions | securePassword : (), uniqueTreasure : () } -> TreasureChest treasure
```
