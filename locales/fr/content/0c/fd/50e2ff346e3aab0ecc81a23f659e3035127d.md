# À propos

En plus de `cond`, Elixir fournit aussi la macro [`if/2`][getting-started-if], qui est utile quand on n'a qu'une seule condition à vérifier.

[`if/2`][kernel-if] prend une condition et deux options. Il renvoie la première option si la condition est _truthy_, et la seconde si la condition est _falsy_.

```elixir
age = 15

if age >= 16 do
  "You are allowed to drink beer in Germany."
else
  "No beer for you!"
end

# => "No beer for you!"
```

Si la seconde option n'est pas fournie, `nil` est renvoyé.

```elixir
age = 15

if age >= 16 do
  "You are allowed to drink beer in Germany."
end

# => nil
```

Il est aussi possible d'écrire une expression `if` sur une seule ligne. Note la virgule après la condition.

```elixir
if age >= 16, do: "beer", else: "no beer"
```

Cette syntaxe est pratique pour les expressions très courtes, mais il vaut mieux l'éviter si l'expression ne tient pas sur une seule ligne.

## _Truthy_ et _falsy_

En Elixir, tous les types de données s'évaluent à une valeur _truthy_ ou _falsy_ lorsqu'ils apparaissent dans un contexte booléen (comme une expression `if`). Toutes les données sont considérées comme _truthy_, **sauf** `false` et `nil`. En particulier, les _strings_ vides, l'entier `0` et les listes vides sont tous considérés comme _truthy_ en Elixir. En cela, [Elixir ressemble à Ruby mais diffère de JavaScript, Python ou PHP][falsy-various-langs].

```elixir
truthy? = fn x -> if x, do: "truthy", else: "falsy" end

truthy?.(true)
# => "truthy"
truthy?.(0)
# => "truthy"
truthy?.([])
# => "truthy"

truthy?.(false)
# => "falsy"
truthy?.(nil)
# => "falsy"
```

[`&&/2`][kernel-and], [`||/2`][kernel-or] et [`!/1`][kernel-not] sont des opérateurs booléens _truthy_ qui fonctionnent avec n'importe quelle valeur, et qui complètent les opérateurs booléens _stricts_ [`and/2`][kernel-boolean-and], [`or/2`][kernel-boolean-or] et [`not/1`][kernel-boolean-not].

```elixir
0 and true
# => ** (BadBooleanError) expected a boolean on left-side of "and", got: 0

0 && true
# => true
```
