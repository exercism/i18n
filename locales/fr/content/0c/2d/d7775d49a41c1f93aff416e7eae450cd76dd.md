# Complément aux instructions

## Mise en œuvre

Cet exercice introduit la [concurrence][oracle-docs-concurrency].
Pour réussir le dernier test, le [mot-clé `synchronized` ou les verrous][oracle-docs-synchronized] peuvent t'être utiles.

Les problèmes liés à l'exécution concurrente de code sont souvent intermittents, car ils dépendent de l'ordre dans lequel le code est exécuté.
C'est pourquoi le dernier test démarre plusieurs [_threads_][threads-api] à plusieurs reprises, afin d'augmenter les chances de détecter un bug.
Cela signifie que ce test devrait échouer si ton implémentation n'est pas [sûre vis-à-vis des _threads_][wiki-thread-safety], mais il se peut qu'il réussisse simplement parce qu'aucune tentative de modification concurrente n'a eu lieu.
Il est peu probable que cela se produise plusieurs fois de suite, étant donné que l'ordre dans lequel le code est exécuté devrait varier à chaque fois que tu exécutes le test.
Donc si tu exécutes le dernier test deux ou trois fois et qu'il réussit à chaque fois, tu peux être raisonnablement sûr que ton implémentation est correcte.
