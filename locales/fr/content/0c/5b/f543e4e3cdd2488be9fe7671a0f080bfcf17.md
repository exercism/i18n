# À propos

ClojureScript est un compilateur pour Clojure qui cible JavaScript. Il génère du code JavaScript compatible avec le mode de compilation avancé du compilateur d'optimisation Google Closure.

## Pourquoi Clojure ?

Clojure est un langage de programmation dynamique et polyvalent qui prend en charge le développement interactif. C'est aussi un langage fonctionnel qui offre un riche ensemble de structures de données immuables et persistantes. En tant que dialecte de Lisp, il adopte une philosophie où le code est une donnée et dispose d'un puissant système de macros.

## Pourquoi JavaScript ?

La diffusion du navigateur et des applications web a donné à JavaScript une portée exclusive qu'aucun autre langage n'égale. En raison de son importance, les moteurs JavaScript font eux aussi l'objet de nombreuses recherches et optimisations, ce qui permet à JavaScript de rivaliser en performance avec des plateformes bien plus établies comme la JVM.

## Pourquoi Google Closure ?

En tant que fournisseur de quelques-unes des applications web client-serveur les plus complexes utilisées aujourd'hui, Google a énormément investi dans la création de la bibliothèque Closure et du compilateur Closure, qui fonctionnent ensemble pour rendre possible l'optimisation de l'ensemble du programme, ce qui produit des programmes dont le temps de chargement reste minimal, même lorsqu'ils utilisent de nombreuses bibliothèques.

## Opportunités

ClojureScript combine la portée de la plateforme JavaScript, la souplesse et le développement interactif de Clojure, ainsi que l'optimisation de l'ensemble du programme de Google Closure pour offrir le langage le plus puissant pour programmer le web.
