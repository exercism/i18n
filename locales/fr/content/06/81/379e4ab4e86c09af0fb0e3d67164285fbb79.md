# Instructions complémentaires

## Mise en œuvre

Tu verras un fichier `cases_test.go` dans cet exercice.
Il contient les cas de test utilisés dans `leap_test.go`.
Tu peux la plupart du temps ignorer ce fichier.

Cependant, si ça t'intéresse... il nous arrive de générer les données de test à partir d'un [dépôt multi-langages][problem-specifications-leap].
Dans ce dépôt, les exercices peuvent avoir un [fichier .json][problem-specifications-leap-json] qui contient des données de test communes.
Certains de nos exercices locaux ont un [programme intermédiaire][local-leap-gen] qui prend le JSON de la spécification du problème et le transforme en structures Go qui alimentent le fichier `<exercise>_test.go`.
La transformation de ces données propre à Go se trouve dans le fichier `cases_test.go`.

[problem-specifications-leap]: https://github.com/exercism/problem-specifications/tree/master/exercises/leap
[problem-specifications-leap-json]: https://github.com/exercism/problem-specifications/blob/master/exercises/leap/canonical-data.json
[local-leap-gen]: https://github.com/exercism/go/blob/main/exercises/practice/leap/.meta/gen.go
