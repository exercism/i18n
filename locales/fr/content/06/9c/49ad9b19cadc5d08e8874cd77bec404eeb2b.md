# Tests

Tu peux implémenter un exercice dans ton propre système SAP. Suis ces étapes :

1. Crée un package SAP pour tous les exercices Exercism de ton système (nom recommandé : `$EXERCISM`)
2. Crée, pour chaque exercice, un package SAP en tant que sous-package (nom recommandé : `$EXERCISM_<name-of-exercise>`, exemple : `$EXERCISM_HELLO-WORLD`)
3. Crée une classe ABAP correspondant à l'exercice (exemple : `ZCL_HELLO_WORLD`)
4. Copie le code du modèle depuis Exercism dans la classe
5. Mets en place les classes de test et copie le code depuis Exercism dans la classe de test

Tu peux maintenant terminer l'implémentation de la classe et lancer le test unitaire pour vérifier que ta solution fonctionne correctement.

Note : cette configuration de packages te permettra de sauvegarder tout ton travail avec [abapGit](https://abapgit.org) en créant un dépôt pour le package `$EXERCISM`.

Pour plus de détails, consulte la [documentation ABAP d'Exercism](https://exercism.org/docs/tracks/abap).
