# Instructions

Écris une fonction qui convertit des nombres normaux en [nombres ordinaux](https://en.wikipedia.org/wiki/Ordinal_numeral). Pour zéro (0), renvoie simplement "0" sous forme de _string_.

Les nombres ordinaux sont des nombres qui décrivent la position de quelque chose dans une liste.
C'est dans ce contexte que les nombres ordinaux seront utilisés, avec un nom de nombre ordinal écrit en anglais.

Les nombres ordinaux sont (du moins, sous l'une de leurs formes) :

```
1st 2nd 3rd 4th 5th... 9th 10th 11th 12th... 20th 21st 22nd 23rd 24th... etc.
```

Ainsi, saisir un nombre normal donne son équivalent ordinal :

```
1 -> 1st
2 -> 2nd
3 -> 3rd
(and so on...)
```
