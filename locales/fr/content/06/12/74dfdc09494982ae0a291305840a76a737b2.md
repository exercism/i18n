# remplace la valeur magique par un identifiant

Il existe une [valeur magique](https://en.wikipedia.org/wiki/Magic_number_(programming)) : `%{literal}` peut être remplacée par `%{identifier}`.
Quand c'est possible, les constantes nommées sont souvent un meilleur choix que les littéraux écrits directement dans le code, et ce pour plusieurs raisons, notamment :

- Il est plus facile de lire et de comprendre le code.
  Quand on tombe sur la valeur littérale `%{literal}`, on peut se demander : « Que signifie `%{literal}` ici ? Pourquoi `%{literal}` ? »
  On peut déduire le sens après avoir lu le code attentivement, mais ce n'est pas évident.
  Les valeurs magiques deviennent particulièrement déroutantes quand la même valeur sert à des fins différentes dans une même section de code.
- Il est plus facile de modifier la valeur, car elle n'est pas dupliquée.
- Cela encourage et facilite la documentation et la traduction.
- Cela facilite l'autocomplétion dans de nombreux IDE.
