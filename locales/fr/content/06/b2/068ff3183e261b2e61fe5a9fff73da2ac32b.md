# If, Elseif, Else

Les instructions conditionnelles qui utilisent `if`, `elseif` et `else` font partie des éléments fondamentaux du contrôle du flux d'un programme.
L'instruction `if` évalue une expression et, si celle-ci vaut `true`, exécute la branche de code correspondante.

```php
<?php

if ($expression) {
    // .. executed if $expression is true
}
```

Si l'expression n'est pas une valeur booléenne, l'évaluation détermine si la valeur est « vraie » ou « fausse ».
En PHP, les valeurs suivantes sont considérées comme égales à `false` :

- un booléen `false`
- un entier `0`
- un nombre décimal `0.0` et `-0.0`
- un tableau vide `[]`
- une _string_ vide `""` ou une _string_ numérique `"0"`
- `null`

Toutes les autres valeurs sont considérées comme vraies.

## Répondre à plusieurs conditions

À la suite d'une instruction `if`, on peut enchaîner plusieurs conditions avec `elseif` et `else`.

```php
<?php

if ($value === 0) {
    // .. do something
} elseif ($value === 1) {
    // .. do something else
} else {
    // ,, do this if nothing else
}
```

Une seule instruction conditionnelle évaluée comme vraie sera exécutée.
Donc, si plusieurs conditions peuvent être vraies, l'ordre dans lequel elles sont écrites est important.

```php
<?php

if (true) {
    // .. always do something
} elseif (true)
    // .. will never be executed
} else {
    // .. will never be executed
}
```
