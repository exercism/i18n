# Ajout aux instructions

## Comment cet exercice est structuré sur le parcours Python

Les tests de cet exercice attendent que ton programme soit implémenté sous la forme d'une [`class`][classes in python] Garden (_voir aussi [concept:python/classes]()_).
Si tu ne connais pas les classes en Python, ce [tutoriel Real Python][how-to-make-a-class] peut être un bon point de départ supplémentaire.

Ta `class` doit implémenter une [`method`][methods] appelée `plants`, qui prend le nom d'un élève en argument et renvoie la `list` des noms de plantes qui appartiennent à cet élève.


## Constructeurs

Création du jardin d'exemple :

```python
[window][window][window]
VRCGVVRVCGGCCGVRGCVCGCGV
VRCCCGCRRGVCGCRVVCVGCGCV
```

serait, dans les tests, représenté par `Garden("VRCGVVRVCGGCCGVRGCVCGCGV\nVRCCCGCRRGVCGCRVVCVGCGCV")`.

Pour que cette représentation fonctionne, ta `class` devra implémenter une [`__init__()`][init] [méthode spéciale][special-methods].
Si tu ne connais pas `__init__()` ni les [_constructeurs_][what-is-a-constructor], la section [Objets de classe et objets d'instance][class vs instance objects in python] de la documentation Python donne une explication plus détaillée.


## Paramètres par défaut

Dans certains tests, une `list` d'élèves est passée en argument à `__init__()`.
Elle doit remplacer la liste des douze élèves fournie dans l'énoncé.
Ces deux instructions doivent fonctionner avec ta méthode `__init__()` :


```Python
# Make a garden based on the default 12-student roster.
Garden("VRCGVVRVCGGCCGVRGCVCGCGV\nVRCCCGCRRGVCGCRVVCVGCGCV") 

# Make a garden based on a 2-student roster.
Garden("VRCC\nVCGG", students=["Valorie", "Raven"]) 
```

Une approche consiste à faire de la `list` d'élèves un [argument par défaut][default argument values] ; la documentation Python décrit en détail les `default parameters` tout en expliquant les [définitions de fonctions][function definitions].
