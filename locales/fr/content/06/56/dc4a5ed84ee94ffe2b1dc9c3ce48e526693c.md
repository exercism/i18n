# Introduction

PHP fournit plusieurs opérateurs pour effectuer des opérations arithmétiques. Ces opérateurs suivent l'ordre de priorité mathématique standard. Voici les opérateurs fournis par PHP :

* Identité (+)
* Négation (-)
* Addition (+)
* Soustraction (-)
* Multiplication (*)
* Division (/)
* Modulo (%)
* Exponentiation (**)

```php
$moles = +'10';
$aLotOfMoles = 6.022 * 10**23 * $moles;
```
