# Introduction

Les types qui implémentent l'interface `IEnumerable<T>` sont dits _énumérables_. Tous les types de collection intégrés implémentent cette interface.

On peut parcourir un type énumérable avec une boucle `foreach` :

```csharp
var primes = new[] { 2, 3, 5, 7 };
foreach (var prime in primes)
{
    Console.Write(prime);
}
// => 2357
```

Pour implémenter `IEnumerable<T>`, un type doit définir une seule méthode : `IEnumerator<T> GetEnumerator()`. Comme on l'a vu, un type énumérable délègue le parcours effectif d'une collection à un type `IEnumerator<T>`. Pour implémenter cette interface, il faut définir une propriété et trois méthodes :

- `public T Current { get; }` : obtenir l'élément courant.
- `public bool MoveNext ();` : passer à l'élément suivant, et renvoyer `true` si le passage à l'élément suivant a réussi, et `false` sinon (il n'y a plus d'éléments).
- `public void Reset ();` : réinitialiser l'énumérateur dans son état initial (avant le premier élément).
