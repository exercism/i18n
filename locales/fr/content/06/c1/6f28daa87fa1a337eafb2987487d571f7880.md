# Introduction

Les expressions conditionnelles permettent d'exécuter du code selon qu'une condition est **vraie** ou **fausse**. Ces expressions s'écrivent ainsi :

```haxe
if (condition) {
  expressions
};
```

Le résultat de la condition est de type `Bool`, donc lorsque ce résultat vaut `true`, les expressions sont exécutées.

Parfois, lorsque la condition est en fait `false`, on veut exécuter un autre bout de code. C'est là qu'intervient l'expression `else`. `else` exécute des expressions lorsque la condition initiale est `false`. Mais que faire si l'on veut tester la condition pour plusieurs possibilités ? On utilise alors `else if (condition)`. Voici un exemple complet :

```haxe
var a = 10;

if (a == 2) {
  trace("a is 2");
} else if (a == 5) {
  trace("a is 5");
} else {
  trace("a is 10");
}

// a is 10
```
