# Instructions

Dans cet exercice, tu vas écrire un TreasureChest générique (voire magique !), pour y ranger des trésors.

## 1. Définis le type TreasureChest

Définis un type paramétrique `TreasureChest{T}` avec deux champs.

- Un champ `password` de type `String`, qui servira à stocker le mot de passe du coffre au trésor.
- Un champ `treasure` de type `T`, qui servira à stocker le trésor.
Cette valeur est générique, pour que le trésor puisse être n'importe quoi.

```julia-repl
julia> chest = TreasureChest{String}("password", "gold")
TreasureChest{String}("password", "gold")
```



## 2. Définis la fonction get_treasure()

Cette fonction prend deux arguments.

- Une `String` (pour essayer un mot de passe)
- Un type `TreasureChest`

Cette fonction doit comparer le mot de passe fourni avec le `password` du `TreasureChest`.

- Si les mots de passe correspondent, renvoie le trésor.
- Si les mots de passe ne correspondent pas, renvoie `nothing`.

```julia-repl
julia> get_treasure("password", chest)
"gold"

julia> get_treasure("wrong", chest)
# no output

julia> isnothing(get_treasure("wrong", chest))
true
```

## 3. Définis la fonction multiply_treasure()

Cette fonction prend deux arguments.

- Un multiplicateur entier `n`.
- Un type `TreasureChest{T}`.

La fonction doit renvoyer un nouveau `TreasureChest{Vector{T}}`, avec
- Le même mot de passe que l'original
- Le trésor multiplié, sous la forme d'un `Vector{T}` de longueur `n`, le trésor d'origine étant répété `n` fois.

```julia-repl
julia> multiply_treasure(3, chest)
TreasureChest{Vector{String}}("password", ["gold", "gold", "gold"])
```
