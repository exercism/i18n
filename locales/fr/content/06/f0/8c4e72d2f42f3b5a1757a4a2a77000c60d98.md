# Introduction

Les **expressions régulières** (_regex_) sont des séquences de caractères qui définissent un motif de recherche dans un texte.

Apprendre la syntaxe des expressions régulières dépasse le cadre de ce sujet.
On va se concentrer sur les expressions que `jq` met à disposition pour utiliser les _regex_.

## Variante de regex

Chaque outil implémente sa propre version des expressions régulières.
`jq` intègre la bibliothèque d'expressions régulières [Oniguruma][oniguruma], largement compatible avec les _regex_ de Perl v5.8.

La syntaxe précise utilisée par `jq` se trouve [dans le dépôt GitHub d'Oniguruma][onig-syntax].

<!-- prettier-ignore -->
~~~~exercism/caution
`jq` n'a pas de syntaxe particulière pour les expressions régulières.
Elles s'écrivent simplement comme des _strings_.
Cela signifie que les antislashs présents dans l'expression régulière doivent être échappés dans la _string_.

Par exemple, la classe de caractères des chiffres (`\d`) doit s'écrire `"\\d"`.
~~~~

## Fonctions de regex

Les expressions régulières de `jq` se limitent à [un ensemble de filtres][jq-regex-funcs].

### Correspondance simple

Si tu as besoin de savoir si une _string_ correspond à un motif, utilise le filtre `test`.

```jq
STRING | test(REGEX)
STRING | test(REGEX; FLAGS)
STRING | test([REGEX, FLAGS])
```

Ce filtre renvoie un résultat _booléen_.

```jq
"Hello World!" | test("W")    # => true
"Goodbye Mars" | test("W")    # => false
```

### Informations sur la correspondance

Si tu as besoin d'extraire la sous-chaîne qui correspond réellement au motif, utilise le filtre `match`.

```jq
STRING | match(REGEX)
STRING | match(REGEX; FLAGS)
STRING | match([REGEX, FLAGS])
```

Ce filtre renvoie :

- rien s'il n'y a pas de correspondance, ou
- un objet contenant diverses propriétés s'il y a une correspondance.

Cet exemple recherche deux voyelles identiques consécutives en utilisant la syntaxe de rétroréférence, `\1`.

```jq
"Hello World!" | match("([aeiou])\\1")
# => empty

"Goodbye Mars" | match("([aeiou])\\1")
# => {
#      "offset": 1,
#      "length": 2,
#      "string": "oo",
#      "captures": [
#        {
#          "offset": 1,
#          "length": 1,
#          "string": "o",
#          "name": null
#        }
#      ]
#    }
```

Le filtre `match` renvoie un objet pour _chaque_ correspondance.
Cet exemple montre l'option `"g"` en action pour trouver toutes les voyelles.

```jq
"Goodbye Mars" | match("[aeiou]"; "g")
# => { "offset": 1, "length": 1, "string": "o", "captures": [] }
#    { "offset": 2, "length": 1, "string": "o", "captures": [] }
#    { "offset": 6, "length": 1, "string": "e", "captures": [] }
#    { "offset": 9, "length": 1, "string": "a", "captures": [] }
```

### Sous-chaînes capturées

Comme le filtre `match`, le filtre `capture` renvoie un objet lorsqu'une correspondance a été trouvée.

```jq
STRING | capture(REGEX)
STRING | capture(REGEX; FLAGS)
STRING | capture([REGEX, FLAGS])
```

L'objet renvoyé est une association des **captures nommées**.

```jq
"JIRAISSUE-1234" | capture("(?<project>\\w+)-(?<issue_num>\\d+)")
# => {
#      "project": "JIRAISSUE",
#      "issue_num": "1234"
#    }
```

### Juste les sous-chaînes

Le filtre `scan` est semblable à `match` avec l'option `"g"`.

```jq
STRING | scan(REGEX)
STRING | scan(REGEX; FLAGS)
```

`scan` renvoie un _flux_ de sous-chaînes.

```jq
"Goodbye Mars" | scan("[aeiou]")
# => "o"
#    "o"
#    "e"
#    "a"
```

Utilise le constructeur de tableau `[...]` pour capturer les sous-chaînes.

```jq
"Goodbye Mars" | [ scan("[aeiou]") ]
# => ["o", "o", "e", "a"]
```

### Découpe une _string_

Si tu connais les parties de la _string_ que tu veux **garder**, utilise `match` ou `scan`.
Si tu connais les parties que tu veux **écarter**, utilise `split`.

```jq
STRING | split(REGEX; FLAGS)
```

<!-- prettier-ignore -->
~~~~exercism/caution
Le filtre `split` **d'arité 1** traite son argument comme une **chaîne fixe**.

Pour utiliser une expression régulière avec `split`, tu **dois** fournir le 2ᵉ argument ; il est tout à fait possible d'utiliser une _string_ vide.
~~~~

<!-- prettier-ignore-end -->

Un exemple qui découpe une _string_ sur des espaces quelconques.

```jq
"first   second           third fourth" | split("\\s+"; "")
# => ["first", "second", "third", "fourth"]
```

### Substitutions

Les filtres `sub` et `gsub` peuvent transformer la _string_ d'entrée en remplaçant les portions correspondantes par une _string_ de remplacement.

Pour ne remplacer que la première correspondance, utilise `sub`.
Pour les remplacer toutes, utilise `gsub`.

```jq
STRING | sub(REGEX; REPLACEMENT)
STRING | sub(REGEX; REPLACEMENT; FLAGS)
STRING | gsub(REGEX; REPLACEMENT)
STRING | gsub(REGEX; REPLACEMENT; FLAGS)
```

```jq
"Goodnight kittens. Goodnight mittens." | sub("night"; " morning")
# => "Good morning kittens. Goodnight mittens."

"Goodnight kittens. Goodnight mittens." | gsub("night"; " morning")
# => "Good morning kittens. Good morning mittens."
```

Le texte de remplacement peut faire référence aux sous-chaînes correspondantes ; utilise les captures nommées et l'[interpolation de _strings_][jq-interp].

```jq
"Some 3-letter acronyms: gnu, csv, png"
| gsub( "\\b(?<tla>[[:alpha:]]{3})\\b";     # find words 3 letters long
        "\(.tla | ascii_upcase)" )          # upper-case the match
# => "Some 3-letter acronyms: GNU, CSV, PNG"
```

## Options

Dans tous les filtres ci-dessus, FLAGS est une _string_ composée de zéro ou plusieurs des options prises en charge.

- `g` - Recherche globale (trouve toutes les correspondances, pas seulement la première)
- `i` - Recherche insensible à la casse
- `m` - Mode multiligne ('.' correspond aux retours à la ligne)
- `n` - Ignore les correspondances vides
- `p` - Les modes s et m sont tous les deux activés
- `s` - Mode monoligne ('^' -> '\A', '$' -> '\Z')
- `l` - Trouve les correspondances les plus longues possibles
- `x` - Format d'expression régulière étendu (ignore les espaces et les commentaires)

Par exemple

```jq
"JIRAISSUE-1234" | capture("(?<project>\\w+)-(?<issue_num>\\d+)")

# or with Extended formatting

"JIRAISSUE-1234" | capture("
                     (?<project>   \\w+ )  # the Jira project
                     -                     # followed by a hyphen
                     (?<issue_num> \\d+ )  # followed by digits
                   "; "x")
```
