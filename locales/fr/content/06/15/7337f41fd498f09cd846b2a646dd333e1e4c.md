# Introduction

Les boucles _repeat-while_ sont similaires aux boucles _while_, à la différence près que l'expression booléenne apparaît, et est évaluée, _après_ l'exécution du corps de la boucle. Par conséquent, ces boucles s'exécutent toujours au moins une fois.

```swift
repeat {
  print("This runs at least once")
} while false
print("Loop done")

// prints:
// This runs at least once
// Loop done
```
