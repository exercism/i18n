# Introduction

Tu as l'occasion d'écrire un logiciel pour le Bracketeer™, un _mainframe_ ancien mais puissant.
Le logiciel qui tourne dessus est écrit dans un langage propriétaire.
Sa syntaxe est en grande partie familière, mais tu remarques _beaucoup_ de crochets, d'accolades et de parenthèses.
Bien que le Bracketeer™ soit puissant, il manque de flexibilité.
Si le code source contient des crochets, des accolades ou des parenthèses qui ne sont pas équilibrés, le Bracketeer™ plante et doit être redémarré.
Pour éviter un tel scénario, tu commences à écrire du code capable de vérifier que les crochets, les accolades et les parenthèses sont équilibrés avant d'essayer de l'exécuter sur le Bracketeer™.
