# Référence Rust

## Concepts

Les exercices d'apprentissage Rust enseignent les concepts, des fondamentaux jusqu'à la maîtrise du langage. Ils sont classés et listés ci-dessous.

Les concepts d'Exercism existent pour être utiles concrètement aux apprenants, ce qui les distingue des idées abstraites. Ce document définit ce que ces concepts signifient en Rust. On a ajouté ci-dessous un regroupement visuel pour aider les mainteneurs de parcours à créer un document de référence efficace. Ces regroupements _ne constituent pas_ des divisions pédagogiques. Ne t'y réfère donc pas pendant que tu enseignes.

Les cases à cocher indiquent si les concepts sont déjà enseignés dans la liste de correspondance des exercices.

## Correspondance des exercices d'apprentissage

Même s'il serait idéal d'avoir un seul exercice d'apprentissage pour chacun des concepts listés ci-dessus, qui n'enseigne qu'un seul concept et n'exige que ses prérequis, ce n'est pas tout à fait réalisable. Par exemple, il serait difficile de concevoir un exercice qui enseigne ce que sont les fonctions sans exiger la moindre connaissance des primitives ; de même, il serait difficile d'enseigner les primitives, avec une suite de tests, sans aucune connaissance des fonctions.

Les exercices de ce tableau devraient former un graphe orienté acyclique (DAG) qui finira par couvrir tous les concepts listés ci-dessus.

| exercice                 | prérequis                                    | enseigne                                                 | narration                                                                        |
| ------------------------ | -------------------------------------------- | -------------------------------------------------------- | -------------------------------------------------------------------------------- |
| `hello-world`            | -                                            | fonctions, suites de tests                               | renvoyer le littéral `&str` `"hello world"`                                      |
| `compiled-calculator`    | `hello-world`                                | entiers, affectation de variables                        | effectuer une série d'opérations mathématiques et renvoyer implicitement le résultat |
| `conditionals`           | `hello-world`                                | conditions                                               | à structurer en trois branches `if` / `else if` / `else` ; retour implicite      |
| `slices`                 | `hello-world`, `compiled-calculator`         | tranches                                                 | extraire une tranche d'un paramètre qui est une tranche d'entiers                |
| `loops`                  | `slices`                                     | boucle simple sur une tranche                            | idéalement avec un retour anticipé, pour qu'il soit fastidieux de l'exprimer avec un itérateur |
| `iterator-use`           | `slices`                                     | utilisation d'itérateurs, `collect`                      |
| `integer-sizes`          | `compiled-calculator`                        | entiers autres que `i32`, conversion de type             | toujours tous signés                                                             |
| `unsigned-ints`          | `integer-sizes`                              | entiers non signés                                       |
| `indexing`               | `integer-sizes`, `slices`                    | indexation, `usize`                                      |
| `floats`                 | `compiled-calculator`                        | nombres décimaux                                         | probablement le même exercice de calcul compilé, avec des résultats non entiers  |
| `bools`                  | `compiled-calculator`                        | booléens, opérateurs booléens                            |
| `char`                   | `compiled-calculator`                        | type `char`                                              | devrait inclure quelques exemples de caractères larges                           |
| `str-use`                | `char`, `slices`                             | `&str`                                                   | remarque : immuable !                                                            |
| `string-use`             | `str-use`                                    | `String`                                                 | remarque : possédé, mutable                                                      |
| `format-macro`           | `string-use`                                 | macro `format!`                                          |
| `str-vs-string`          | `str-use`, `string-use`                      | combiner, convertir, coûts, etc                          |
| `generics-basics`        | `integer-sizes`, `floats`                    | utiliser des traits externes comme bornes, génériques de base | probablement toujours le calculateur compilé, mais générique                |
| `structs`                | `string-use`, `unsigned-ints`, `floats`      | créer et utiliser une structure pour gérer des données   | `Person` a un nom, une taille et une quantité de chaussures possédées           |
| `implicit-return`        | `compiled-calculator`                        | portées, expressions, retour implicite                   |
| `explicit-return`        | `implicit-return`, `conditionals`            | instruction `return` explicite                           |
| `methods`                | `structs`, `explicit-return`                 | blocs `impl`, méthodes                                   |
| `tuples`                 | `structs`                                    | tuples                                                   | à enseigner comme des structures anonymes ; enseigner la syntaxe `.0`            |
| `tuple-structs`          | `tuples`, `structs`                          | structures tuples (tuples nommés)                        |
| `basic-enums`            | `unsigned-ints`                              | énumérations de base (sans champs), `match`              |
| `enums`                  | `basic-enums`, `tuple-structs`               | syntaxe de tuple pour les variantes d'énumération        |
| `option`                 | `enums`                                      | `Option<T>`                                              |
| `result`                 | `enums`                                      | `Result<T, E>`                                           |
| `mutability`             | `compiled-calculator`                        | immuabilité par défaut ; mutabilité explicite            |
| `let-expressions`        | `loops`, `option`, `result`                  | `if let`, `while let`                                    | ne dépendra probablement que de `option` ou de `result`, selon l'implémentation |
| `vectors`                | `slices`                                     | `Vec<T>`                                                 |
| `hashmaps`               | `vectors`                                    | `Hashmap<K, V>`                                          |
| `entry-api`              | `hashmaps`                                   | API Entry                                                |
| `hashsets`               | `hashmaps`                                   | `HashSet<K>`                                             |
| `btreemaps`              | `hashmaps`                                   | `BTreeMap<K, V>`                                         |
| `deriving-traits`        | `structs`                                    | `PartialEq`, `PartialOrd`, `Debug`, `Display`, `Default` |
| `implementing-traits`    | `deriving-traits`                            | implémenter un trait manuellement                        | implémentera probablement `Iterator`                                             |
| `collection-conversions` | `vectors`, `hashsets`, `implementing-traits` | `FromIterator`, `IntoIterator`                           |
