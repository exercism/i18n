# Introduction

`when` est le mot-clé du filtrage des exceptions. Il se place après l'instruction catch et peut prendre une expression booléenne contenant toutes les valeurs qui sont dans la portée à cet instant. Si l'expression s'évalue à vrai, le bloc associé à cette instruction `catch` est exécuté ; sinon, l'instruction `catch` suivante, s'il y en a une, est vérifiée.

```csharp
try
{
    // do stuff
}
catch (Exception ex) when (ex.Message != "")
{
    // output the message when it is not empty
}
catch (Exception ex)
{
    // show stack trace or something.
}
```
