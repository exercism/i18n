# Instructions

Tu es un passionné d'observation des oiseaux qui compte chaque jour les oiseaux qui visitent son jardin. Les comptages sont stockés dans un tableau, du jour le plus ancien au plus récent.

## 1. Le comptage du jour

Définis `today` pour qu'elle retire de la pile le tableau des comptages quotidiens et renvoie le comptage du jour.

```factor
{ 2 5 0 7 4 1 } today .
! => 1
```

## 2. Incrémente le comptage du jour

Définis `increment-todays-count` pour qu'elle renvoie un nouveau tableau dans lequel le comptage du jour est augmenté de un. Le tableau d'origine ne doit pas être modifié.

```factor
{ 2 5 0 7 4 1 } increment-todays-count .
! => { 2 5 0 7 4 2 }
```

## 3. Y a-t-il eu un jour sans oiseau ?

Définis `has-day-without-birds?` pour qu'elle renvoie `t` si au moins un jour a enregistré zéro oiseau, sinon `f`.

```factor
{ 2 5 0 7 4 1 } has-day-without-birds? .
! => t

{ 2 5 1 } has-day-without-birds? .
! => f
```

## 4. Additionne les premiers jours

Définis `count-for-first-days` pour qu'elle prenne un tableau de comptages et un nombre `n`, et renvoie la somme des `n` premiers comptages.

```factor
{ 2 5 0 7 4 1 } 4 count-for-first-days .
! => 14
```

## 5. Compte les journées chargées

Une journée chargée est une journée avec cinq oiseaux ou plus. Définis `busy-days` pour qu'elle renvoie le nombre de journées chargées dans le tableau.

```factor
{ 2 5 0 7 4 1 } busy-days .
! => 2
```

## 6. Complète les jours manquants

Si tu n'as pas observé chaque jour d'une période de `n` jours, complète avec `0` les jours manquants à la fin. Définis `pad-missing-days` pour qu'elle prenne un tableau de comptages et une longueur cible `n`, et renvoie un tableau d'une longueur d'au moins `n` dont les emplacements supplémentaires valent `0`. Les comptages existants doivent être conservés tels quels ; si l'entrée est déjà au moins aussi longue que `n`, renvoie-la inchangée.

```factor
{ 2 5 0 } 7 pad-missing-days .
! => { 2 5 0 0 0 0 0 }

{ 4 1 6 8 } 3 pad-missing-days .
! => { 4 1 6 8 }
```
