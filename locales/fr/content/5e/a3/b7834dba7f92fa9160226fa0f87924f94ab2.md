# Indices

## Général

- Consulte la [référence du langage sur les tableaux][ref-arrays]
- Consulte la [référence des fonctions de tableau][ref-array-functions]

## 1. Définis une fonction qui renvoie une liste de langages vide

- Consulte la [référence du langage][ref-arrays]
- Tu peux renvoyer un tableau vide

## 2. Modifie la fonction pour créer une liste à partir d'un nombre quelconque de langages

- Reporte-toi à la référence des fonctions pour les [arguments de longueur variable][variable-arguments]

## 3. Définis une fonction pour ajouter un langage à la liste

- Crée une nouvelle fonction pour effectuer l'opération
- Réutilise une [fonction existante][ref-array-functions] ou utilise la [syntaxe d'insertion][square-bracket-syntax]

## 4. Définis une fonction pour retirer un élément de la liste de langages

- Crée une nouvelle fonction pour effectuer l'opération
- Réutilise une [fonction existante][ref-array-functions] pour effectuer l'opération

## 5. Définis une fonction pour obtenir le premier élément de la liste

- Crée une nouvelle fonction pour effectuer l'opération
- Utilise la [syntaxe d'indice][index-syntax] pour obtenir le premier élément

## 6. Définis une fonction pour renvoyer le nombre de langages de la liste

- Crée une nouvelle fonction pour effectuer l'opération
- Réutilise une [fonction existante][ref-array-functions] pour effectuer l'opération
