# À propos

Une [instruction `switch`][switch] compare une valeur à plusieurs motifs de correspondance possibles.
Elle offre une alternative plus propre et plus lisible à l'enchaînement de plusieurs instructions `if-else`.

Une instruction `switch` commence par le mot-clé `switch`, suivi de la valeur à tester.
Chaque correspondance possible est introduite par le mot-clé `case`.
Le mot-clé `default` définit un cas de repli, exécuté si aucun des cas explicites ne correspond.
Comme les chaînes `if-else`, une instruction `switch` n'exécute que le bloc de code associé au premier cas qui correspond.

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

Prenons la chaîne `if-else` suivante :

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

On peut l'écrire plus clairement avec une instruction `switch` :

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```

## Liaison de valeurs et clauses `where`

Un cas d'une instruction `switch` peut lier les valeurs correspondantes à des constantes ou des variables temporaires, utilisables dans le corps de ce cas.
Les cas peuvent aussi inclure une clause `where` pour vérifier des conditions booléennes supplémentaires avant la correspondance :

```swift
let x = 1337
switch sumOfDivisors(of: x) {
case let total where total == x:
    print(total, "is a perfect number")
default:
    print(x, "is not a perfect number")
}
```
