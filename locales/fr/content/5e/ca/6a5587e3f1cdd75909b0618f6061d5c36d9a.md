# Exécuter les tests

Choisis ton système d'exploitation :

- [Windows](#windows)
- [macOS](#macos)
- [Linux](#linux)

## Windows

1. Ouvre une invite de commandes.
2. Télécharge le premier exercice :

   ```batchfile
   C:\Users\JohnDoe>exercism download --exercise hello-world --track java
   ```

3. Déplace-toi dans le répertoire de l'exercice :

   ```batchfile
   C:\Users\JohnDoe>cd C:\Users\JohnDoe\exercism\java\hello-world
   ```

4. Lance les tests :

   ```batchfile
   C:\Users\JohnDoe>gradlew.bat test
   ```

   _(Ne t'inquiète pas si les tests échouent au début, c'est ainsi que tu commences chaque exercice.)_

5. Résous l'exercice. Trouve le guide `instructions.append.md` et suis-le ([voir sur GitHub][hello-world-tutorial]).

Bonne chance ! Amuse-toi bien !

3. Lance les tests :

   ```sh

   ```

   _(Ne t'inquiète pas si les tests échouent au début, c'est ainsi que tu commences chaque exercice.)_

4. Résous l'exercice. Trouve le guide `instructions.append.md` et suis-le ([voir sur GitHub][hello-world-tutorial]).

Bonne chance ! Amuse-toi bien !

## Linux

1. Dans la fenêtre du terminal, télécharge le premier exercice :

   ```sh
   exercism download --exercise hello-world --track java
   ```

2. Déplace-toi dans le répertoire de l'exercice :

   ```sh
   cd /home/johndoe/exercism/java/hello-world
   ```

3. Lance les tests :

   ```sh
   ./gradlew test
   ```

   _(Ne t'inquiète pas si les tests échouent au début, c'est ainsi que tu commences chaque exercice.)_

   Si tu obtiens l'erreur suivante :

   ```sh
   ./gradlew: Permission denied
   ```

   Alors le fichier n'a pas la permission d'exécution. Pour corriger ce problème, exécute :

   ```sh
   chmod +x ./gradlew
   ```

   Et maintenant, tu devrais pouvoir exécuter la commande précédente.

4. Résous l'exercice. Trouve le guide `instructions.append.md` et suis-le ([voir sur GitHub][hello-world-tutorial]).

Bonne chance ! Amuse-toi bien !

[hello-world-tutorial]: https://github.com/exercism/java/blob/main/exercises/practice/hello-world/.docs/instructions.append.md#tutorial
