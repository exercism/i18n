# À propos

[`fold`][fold] est un [adaptateur d'itérateur consommateur][consuming iterator adaptor] qui applique une fonction à chaque élément de l'itération et accumule le résultat dans une nouvelle valeur.

Chaque itération de `fold` prend deux arguments. Le premier est une valeur initiale pour l'accumulateur. Le second est une _closure_ qui prend elle aussi deux arguments : l'accumulateur et un élément. La valeur de retour de la _closure_ devient la nouvelle valeur de l'accumulateur. Une fois que l'itérateur est épuisé, la valeur finale de l'accumulateur est renvoyée.

On peut utiliser `fold` lorsqu'on souhaite transformer une collection en une seule valeur. Par exemple, si l'on veut la somme de tous les nombres pairs

```rust
pub fn main() {
    let even_sum = (1..=10).fold(0, |acc, num| if num % 2 == 0 { acc + num } else { acc });
    println!("{even_sum:?}");
}
```

Affiche `30`.

Ce que l'on peut faire avec `fold` peut souvent l'être avec une ou plusieurs autres fonctions. Pour l'exemple ci-dessus, utiliser [`filter`][filter] sur `(1..=10)` puis [`sum`][sum] serait moins verbeux et donnerait le même résultat, comme ceci

```rust
(0..=10).filter(|n| *n % 2 == 0).sum()
```

Parmi les autres fonctions plus couramment utilisées que `fold`, on trouve [`product`][product] et [`collect`][collect].

Un accumulateur peut aussi servir pour d'autres valeurs que des nombres. Par exemple

```rust
pub fn giant_grunts(initial: char) -> String {
    ["Bee", "Fee", "Gee", "Fi", "Hi", "Fo", "Mo", "Fum", "Tum"].iter().fold(
        String::new(),
        |acc, grunt| if grunt.starts_with(initial) { acc + grunt } else { acc },
    )
}

pub fn main() {
    let song = giant_grunts('F');
    println!("{song:?}");
}
```

Affiche `FeeFiFoFum`
