# Instructions

Détermine si un mot ou une phrase est un isogramme.

Un isogramme (aussi appelé « *non-pattern word* ») est un mot ou une phrase dans lequel aucune lettre ne se répète, mais où les espaces et les traits d'union peuvent apparaître plusieurs fois.

Exemples d'isogrammes :

- lumberjacks
- background
- downstream
- six-year-old

Le mot *isograms*, en revanche, n'est pas un isogramme, parce que le s se répète.
