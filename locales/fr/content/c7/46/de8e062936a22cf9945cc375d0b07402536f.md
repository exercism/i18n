## Éditeurs

### Gratuits et open source

- [VS Code](https://code.visualstudio.com)

  VS Code est un éditeur de code open source. Tu trouveras des informations sur la configuration de TypeScript [ici](https://code.visualstudio.com/docs/languages/typescript). VS Code est un éditeur populaire pour TypeScript, car Microsoft maintient à la fois VS Code et TypeScript : il s'accorde donc bien avec le langage. VS Code prend en charge TS sans configuration supplémentaire. En fait, VS Code a été écrit en TypeScript !

  Un problème fréquent avec VS Code et TS survient lorsque la version de ton éditeur et celle de ton projet sont différentes, ce qui peut amener VS Code à afficher un message d'erreur parfois déroutant. Tu trouveras des instructions pour gérer cette erreur [ici](https://code.visualstudio.com/docs/typescript/typescript-compiling#_using-newer-typescript-versions)

### Sous licence

- [Sublime Text](https://www.sublimetext.com)

  Sublime Text est un éditeur de code populaire qui prend en charge la plupart des langages grâce à des plugins installables. Il est gratuit à l'essai, mais on te proposera régulièrement d'acheter une licence, qui coûte actuellement \$70 USD.

- [WebStorm](https://www.jetbrains.com/webstorm/)

  WebStorm est un IDE (environnement de développement intégré) JavaScript/TypeScript complet. Il prend en charge TypeScript sans configuration supplémentaire et intègre les tests, le débogage et l'analyse de code. Il est gratuit à l'essai pendant 30 jours, puis une licence annuelle coûte \$129 USD la première année.
