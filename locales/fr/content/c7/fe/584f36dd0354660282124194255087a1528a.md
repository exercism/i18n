# À propos

Dans un langage purement fonctionnel comme Elm, une fonction appelée avec les mêmes arguments doit toujours renvoyer la même valeur.
Par conséquent, une fonction dont la signature de type est `rand : Int` ne peut être implémentée que par (`rand = 4`)[xkcd-random], ce qui n'augure rien de bon pour la génération de nombres entiers aléatoires.

Alors, comment générer des valeurs aléatoires en Elm ?
On divise le problème en deux : d'abord, on décrit la valeur que l'on veut générer avec un `Random.Generator a`, puis on génère une valeur.

La première façon de générer une valeur consiste à créer un `Random.Seed` via `initialSeed : Int -> Seed`.
Un `Seed` est un type opaque qui contient un entier et qui sait transformer cet entier d'une manière qui semblera aléatoire (on parle de pseudo-aléatoire).
Une fois que tu as un `Seed`, tu peux t'en servir pour générer une valeur avec un `Generator a`.
Un `Generator a` est un type opaque qui sait utiliser l'entier contenu dans un _seed_ pour créer une valeur pseudo-aléatoire de type `a`, ainsi qu'un nouveau _seed_ avec un entier mis à jour.

Pour générer une valeur, on peut utiliser `step : Generator a -> Seed -> ( a, Seed )`, qui renvoie une valeur et un nouveau _seed_ que l'on peut utiliser pour générer d'autres valeurs.

Utilisons ces fonctions pour extraire `n` valeurs aléatoires d'un générateur :

```elm
generate : Int -> Generator a -> List a
generate n generator = generateValuesFromSeed n generator (Random.initialSeed 42)

generateValuesFromSeed : Int -> Generator a -> Seed -> List a
generateValuesFromSeed n generator seed =
    if n <= 0 then
        []
    else
        let ( value, nextSeed ) = Random.step generator seed
        in value :: generateValuesFromSeed (n - 1) generator nextSeed
```

Notons que toutes ces fonctions sont pures, donc les appeler deux fois avec les mêmes arguments produira les mêmes valeurs.

```elm
generate 10 (Random.int 1 6)
    --> [4, 5, 3, 3, 5, 1, 2, 4, 6, 6]

generate 10 (Random.int 1 6)
    --> [4, 5, 3, 3, 5, 1, 2, 4, 6, 6]
```

La seconde façon de générer une valeur consiste à utiliser `Random.generate : (a -> msg) -> Generator a -> Cmd msg`, mais cela ne peut se faire qu'à l'intérieur d'une application Elm.
Dans ce cas, le _runtime_ d'Elm peut utiliser `step` ainsi que des ressources externes non pures pour générer des _seeds_, et appeler deux fois la même fonction donnera des résultats différents.

À partir de maintenant, on va se concentrer sur les générateurs.

Le module `Random` fournit deux générateurs de base pour créer des entiers et des nombres à virgule flottante dans une plage donnée :

```elm
generate 5 (Random.int -5 5)
    --> [0, 3, -5, 5, 0]

generate 3 (Random.float 0 5)
    --> [1.61803, 3.14159, 2.71828]
```

Ces valeurs peuvent être combinées en tuples, ou en tableaux de valeurs :

```elm
generate 2 (Random.list 3 (Random.int 0 3))
    --> [[0, 3, 3], [1, 3, 2]]

generate 2 (Random.pair (Random.int 0 3) (Random.float 10 10.3))
    --> [(0, 10.23412), (2, 10.17094)]
```

Le paquet (`elm-community/random-extra`)[random-extra] fournit beaucoup plus de générateurs pour diverses structures de données : les _strings_, les dates, les dictionnaires, les tableaux, les ensembles, etc.

On peut créer des générateurs qui ne renverront qu'une seule valeur grâce à `Random.constant` :

```elm
generate 4 (Random.constant "hello")
    --> ["hello", "hello", "hello", "hello"]
```

On peut choisir au hasard parmi des éléments donnés avec une probabilité égale grâce à `Random.uniform` :

```elm
generate 5 (Random.uniform Red [Green, Blue])
    --> [Red, Blue, Blue, Green, Red]
```

`Random.uniform` prend deux arguments (`Red` et `[Green, Blue]`) pour garantir qu'il y a au moins une valeur parmi laquelle choisir, puisqu'un seul tableau pourrait être vide.

On peut aussi ajuster les probabilités grâce à `Random.weighted` :

```elm
generate 5 (Random.weighted (80, Red) [(15, Green), (5, Blue)])
    --> [Red, Red, Green, Red, Red]
```

Les valeurs n'ont pas besoin de totaliser 100, elles seront de toute façon renormalisées.

On peut accéder à l'intérieur d'un générateur avec `Random.map` :

```elm
generate 3 (Random.int 1 6 |> Random.map (\n -> n * 10))
    --> [30, 60, 10]
```

On peut aussi utiliser `Random.map2` jusqu'à `Random.map5` pour combiner davantage de générateurs :

```elm
position =
    Random.map3
      (\x y z -> Position x y z)
      (Random.float -100 100)
      (Random.float -100 100)
      (Random.float -100 100)

generate 1 position
    --> [Position 33.788 -98.321 10.0845]
```

Pour des usages plus complexes, on dispose de `Random.andThen : (a -> Generator b) -> Generator a -> Generator b`, qui peut utiliser la valeur générée par un générateur pour en créer un autre :

```elm
bool = Random.uniform True [False]

failHalfOfTheTime : Generator a -> Generator (Maybe a)
failHalfOfTheTime generator =
    bool
        |> Random.andThen
            (\boolResult ->
                if boolResult then
                    Random.map Just generator

                else
                    Random.constant Nothing
            )

generate 6 (Random.int 0 1 |> failHalfOfTheTime)
    --> [Nothing, Just 1, Just 0, Nothing, Just 1, Nothing]
```

Il est parfois utile de définir un générateur de façon récursive.
Dans ces cas, tu pourrais avoir besoin d'utiliser `Random.lazy` pour empêcher le compilateur de dérouler le générateur à l'infini.

```elm
type Peano
    = Zero
    | Next Peano


peano : Generator Peano
peano =
    Random.uniform (Random.constant Zero)
        [ Random.map Next (Random.lazy (\_ -> peano))
        ]
        |> Random.andThen identity

generate 12 peano
    --> [Zero, Next(Next(Zero)), Zero, Next(Zero), Zero, Zero, Next(Zero), Zero, Zero, Next(Zero), Next(Next(Next(Zero)))]
```

Cet exemple est un peu lourd, alors décortiquons-le.

`Peano` est un type qui représente les entiers positifs : `Zero` vaut 0, `Next(Zero)` vaut 1, `Next(Next(Zero))` vaut 2, etc.
On définit `peano` pour nous donner un nombre `Peano` aléatoire.

Tout d'abord, notons que `Random.lazy` n'ajoute rien à la logique, il empêche simplement le compilateur d'écrire `peano` dans `peano` à l'infini.

On utilise `Random.uniform` pour choisir entre zéro (avec une probabilité de 50 %) et un autre nombre `Peano` plus un (avec une probabilité de 50 %).
Cependant, contrairement à l'exemple précédent, `Random.uniform` ne choisit pas parmi des valeurs (comme `Zero`) mais parmi des générateurs (comme `Random.constant Zero`), puisque l'on veut utiliser `peano` lui-même.
Cela signifie que `Random.uniform` va renvoyer une valeur de type `Generator (Generator Peano)`, ce qui n'est pas ce dont on a besoin.

Pour « aplatir » le générateur, on le fait passer dans `Random.andThen : (a -> Generator b) -> Generator a -> Generator b`, où l'on veut que `b` soit `Peano`.
Comme `Generator a` est `Generator (Generator Peano)`, `a` doit être `Generator Peano`, et la fonction `(a -> Generator b)` doit être de type `(Generator Peano -> Generator Peano)`.
On ne veut rien modifier, donc `identity` est le bon choix.

Enfin, quel genre de nombres `peano` va-t-il produire ?
On sait qu'il produira 0 dans 50 % des cas, ou une nouvelle itération de lui-même plus un dans 50 % des cas.
Cela signifie que les nombres seront 0 (50 % des cas), 1 (25 % des cas), 2 (12 % des cas), 3 (6 % des cas), etc.
`peano` peut produire des nombres arbitrairement grands, mais avec une probabilité qui décroît exponentiellement.
