# Instructions

Dans cet exercice, c'est la Saint-Valentin et tu réfléchis à ce que tu vas faire avec ton partenaire. Ton partenaire a plein d'idées et te demande de les évaluer afin de trouver la meilleure activité.

Ton partenaire te propose les idées suivantes :

- Jouer à un jeu de société
- Se détendre
- Regarder un film
- Aller au restaurant
- Faire une promenade

Tu as six tâches pour t'aider à choisir ton activité de la Saint-Valentin.

## 1. Définis l'approbation

Pour chaque idée proposée par ton partenaire, tu réponds par l'une des trois options suivantes : _yes_, _no_ ou _maybe_.

Définis le type de données algébrique `Approval` pour représenter ces options avec les trois cas suivants : `Yes`, `No` ou `Maybe`.

## 2. Définis les cuisines

Ton partenaire a sélectionné deux restaurants possibles : l'un de cuisine coréenne et l'autre de cuisine turque.

Définis le type de données algébrique `Cuisine` pour représenter ces restaurants avec les deux cas suivants : `Korean` ou `Turkish`.

## 3. Définis les genres de films

Il y a des tonnes de films parmi lesquels choisir, alors pour réduire le choix, ton partenaire précise aussi son genre préféré.

Définis le type de données algébrique `Genre` pour représenter les cas de genre suivants : `Crime`, `Horror`, `Romance` ou `Thriller`.

## 4. Définis l'activité

Comme on l'a vu, ton partenaire a proposé cinq activités possibles : jouer à un jeu de société, se détendre, regarder un film, aller au restaurant et faire une promenade.

Définis le type de données algébrique `Activity` pour représenter ces types d'activités :

- `BoardGame` : aucune donnée associée.
- `Chill` : aucune donnée associée.
- `Movie` : a son `Genre` comme donnée associée.
- `Restaurant` : a sa `Cuisine` comme donnée associée.
- `Walk` : a un `Int` représentant le nombre de kilomètres à parcourir comme donnée associée.

## 5. Évalue l'activité

Enfin, le moment est venu d'évaluer les idées de ton partenaire. Voici ton ressenti sur l'idée de ton partenaire :

- Jouer à un jeu de société : _no_.
- Se détendre : _no_.
- Regarder un film : _yes_ s'il s'agit d'un film romantique ; sinon, _no_.
- Aller au restaurant : _yes_ si la cuisine est coréenne, _maybe_ si elle est turque.
- Faire une promenade : _yes_ si la promenade fait moins de trois kilomètres ; _maybe_ si elle fait entre trois et cinq kilomètres (bornes comprises) ; sinon, _no_.

Implémente une fonction nommée `rateActivity` qui prend une valeur `Activity` et renvoie la valeur `Approval` correspondant aux ressentis ci-dessus.
Par exemple :

```haskell
rateActivity (Restaurant Turkish)
-- -> Maybe
```
