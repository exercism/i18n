# Instructions complémentaires

Pour le parcours Python, cet exercice te demande de créer une _classe_ `SpaceAge` (_[concept:python/classes]()_) qui contient des méthodes pour toutes les planètes du système solaire.
Les méthodes doivent suivre la convention de nommage `on_<planet name>`.

Chaque méthode doit `return` l'âge (_« sur » cette planète_) en années, arrondi à deux décimales :

```python
#creating an instance with one billion seconds, and calling .on_earth().
>>> SpaceAge(1000000000).on_earth()

#This is one billion seconds on Earth in years
31.69
```
