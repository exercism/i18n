# Indices

## Général

- Les concepts précédents [structs][], [maps][] et [methods][] sont utiles ici.


## 1. Suivre les participants

- Le concept [définition de type][] explique comment définir un nouveau type.
- Utilise `make()` pour créer une nouvelle instance de `map`.
- Pour ajouter une valeur à la `map`, utilise `struct{}{}` pour créer une instance du `struct{}` vide.

## 2. Vérifier les participants

- Si un élément est dans la `map`, l'ensemble contient cette valeur.
- L'[affectation à deux valeurs][] permet de vérifier si une `map` contient un élément.

## 3. Comparer les participants

- Deux ensembles sont égaux si toutes les valeurs de l'un sont contenues dans l'autre.
- `range` permet de parcourir tous les éléments de l'ensemble.
