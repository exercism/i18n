# Indices

## Généralités

- Tu peux utiliser la classe [Random][random-class] pour générer des nombres aléatoires.
- Pour en savoir plus, consulte l'article : [Random Number Generators in Java 17][random-number-generators].

## Génération du labyrinthe

Tu peux utiliser n'importe quel algorithme pour générer un labyrinthe parfait. Le [_backtracking_ récursif][recursive-backtracker] est un bon choix.
