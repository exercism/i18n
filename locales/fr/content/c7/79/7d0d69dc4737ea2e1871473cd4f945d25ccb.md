# Ajout aux instructions

Dans [concept:python/unpacking-and-multiple-assignment](https://github.com/exercism/python/tree/main/concepts/unpacking-and-multiple-assignment), tu as découvert plusieurs techniques pour manipuler des `lists`/`tuples` de longueur arbitraire, ainsi que des arguments de fonction de longueur arbitraire.
Cet exercice est l'endroit idéal pour mettre ces techniques en pratique.

## Comment cet exercice est implémenté pour Python

Les cas de test de ce parcours ajoutent un argument nommé supplémentaire, `qualifier`.
Utilise la valeur de cet argument nommé pour modifier la dernière phrase de ton proverbe.
