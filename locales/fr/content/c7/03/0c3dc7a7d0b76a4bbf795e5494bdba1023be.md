# Instructions supplémentaires

## Mots

Définis un tuple `robot` avec les emplacements `x`, `y` et `direction`. L'emplacement `direction` contient l'un des symboles `north`, `east`, `south` ou `west` (déclarés dans le vocabulaire de cet exercice).

- `<robot> ( x y direction -- robot )` : construire un robot.
- `move ( robot instructions -- robot )` : appliquer une chaîne d'instructions `R`, `L` et `A`, puis renvoyer le robot mis à jour.
