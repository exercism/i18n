# Instructions

Utilise des lentilles pour mettre à jour des enregistrements imbriqués (spécifique aux langages à données immuables).

Mettre à jour les champs d'enregistrements imbriqués et immuables est plutôt pénible.
Le code pour ce genre de cas est aussi lourd que la structure est profonde.
Si tu as, disons, une Person qui contient une Address, qui a une Street, qui a un Number, mettre à jour le Number nécessite de créer une nouvelle Street avec le nouveau Number, puis une nouvelle Address avec la nouvelle Street et, enfin, une nouvelle Person avec la nouvelle Address.
Déjà perdu ?

Une solution à ce problème consiste à utiliser des [lentilles][lenses].

Implémente plusieurs fonctions d'accès aux enregistrements à l'aide de lentilles.
La suite de tests te permet aussi d'éviter complètement les lentilles, afin que tu puisses expérimenter différentes approches.

[lenses]: https://en.wikibooks.org/wiki/Haskell/Lenses_and_functional_references
