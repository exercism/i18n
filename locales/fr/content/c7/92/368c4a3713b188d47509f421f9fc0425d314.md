# Introduction

Un `string` en Clojure est une chaîne de caractères Java : c'est un objet qui représente du texte immuable sous la forme d'une séquence de caractères Unicode (lettres, chiffres, ponctuation, etc.).

La bibliothèque `clojure.string` fournit de nombreuses fonctions standard de manipulation et de traitement de _string_. De plus, toutes les méthodes Java habituelles pour manipuler les _string_ sont disponibles via l'interopérabilité.
