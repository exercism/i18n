# Variable supplémentaire créée pour le nom

Créer une variable supplémentaire pour stocker le nom est inutile, car Go ne passe pas les variables par référence.
Réaffecter `name` ne changera pas la valeur au-delà de la portée de la fonction `ShareWith`.
Comme Go ne permet pas de fournir des valeurs par défaut aux paramètres d'une fonction, il est courant en Go de réaffecter la valeur pour obtenir une valeur par défaut.
