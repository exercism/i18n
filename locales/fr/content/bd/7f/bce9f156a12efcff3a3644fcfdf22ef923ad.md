# CLI

Pour exécuter les tests, ouvre une invite de commandes dans le répertoire de l'exercice, puis lance la commande [`stack test`][docs-stack-test]. Si ton code compile, cette commande t'indique quels tests sont réussis et lesquels sont échoués ; quand un test échoue, essaie de le faire passer, puis relance les tests.

Une fois que tous les tests sont réussis, tu peux soumettre ta solution en ouvrant une invite de commandes dans le répertoire de l'exercice et en lançant la commande [`exercism submit`][docs-exercism-cli].

[docs-stack-test]: https://docs.haskellstack.org/en/stable/build_command/
[docs-exercism-cli]: https://exercism.io/cli
