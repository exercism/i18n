# Introduction

## Durée de vie des ressources

[concept:csharp/resource-cleanup]() utilise l'interface `IDispose` pour signaler que la ressource d'un objet, ou un autre état du programme, devait être libérée ou réinitialisée lorsque l'objet n'était plus nécessaire (et que compter sur le ramasse-miettes n'y parviendrait pas ou n'offrirait pas le niveau de contrôle requis), et que la méthode `IDisposable.Dispose()` était l'endroit naturel pour de telles opérations de nettoyage.

Il existe une autre construction, le bloc `using`, qui permet, du point de vue de l'appelant, de rassembler toute la gestion de la durée de vie des ressources dans une seule instruction.

```csharp
using (var file = new File("my_secrets"))
{
    file.WriteSecret("xxxxxxx");
}
```

Dans l'exemple ci-dessus, les ressources du système de fichiers associées à `file` seront libérées et rendues au système d'exploitation à la sortie du bloc `using`.

Pour que ce mécanisme fonctionne, la variable de l'instruction `using` doit être un type référence qui implémente l'interface `IDisposable` et doit libérer des ressources ou réinitialiser l'état du programme dans sa méthode `Dispose()`.

C# 8 introduit un raffinement de ce mécanisme. Une instruction `using` peut être placée au début d'un bloc.

```csharp
using var drawingResource = some_provided_or_new_object;
try
{
    drawingResource.DrawSomething();
}
catch (Exception)
{
    throw;
}
```

Les développeurs Java y reconnaîtront un équivalent du mécanisme de _gestion automatique des ressources_ introduit dans Java 7.
