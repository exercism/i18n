# Introduction

## Les espaces de noms

Les espaces de noms servent à regrouper du code lié et à éviter les conflits de noms ; on les trouve dans presque toutes les bases de code, à l'exception des plus triviales.

La syntaxe est la suivante :

```csharp
namespace MyNameSpace
{
    public class MyClass {}

    public class OtherClass {}
}
```

Pour faire référence, en dehors de leur portée, à un type déclaré dans un espace de noms, on préfixe le nom de ce type par le nom de l'espace en question, suivi d'un point. Sinon, et c'est le cas le plus fréquent, on place une directive `using` en haut du fichier (ou dans un espace de noms), ce qui permet ensuite d'utiliser le type sans préfixe. Au sein d'un même espace de noms, il n'est pas nécessaire de qualifier les noms de types.

```csharp
namespace MySpace
{
    public class MyClass {}

    public class Foo
    {
        public void Bar()
        {
            var baz = new MyClass();
        }
    }
}

public class Qux
{
    public void Box()
    {
        var nux = new MySpace.MyClass();
    }
}

namespace OtherSpace
{
    using MySpace;

    public class Tix
    {
        public void Jeg()
        {
            var lor = new MyClass();
        }
    }
}
```

On peut donner un alias à un espace de noms avec la syntaxe `using MyAlias = MySpace;`, puis utiliser cet alias partout où l'espace de noms peut être utilisé.
