# Ajout aux instructions

## Construis ton propre DSL

Dans cet exercice, tu es entièrement libre de concevoir le DSL de graphe de tes rêves.

Les tests te demandent seulement de créer quelques graphes bien précis, et la façon dont tu les construis est entièrement ton choix.

Pour doubler le plaisir, tu peux éventuellement essayer d'implémenter une fonction `to_dot` qui convertit ton graphe au format DOT !

## Représentation du graphe

Définis ton DSL dans `Graph.roc`, puis utilise-le pour construire les graphes demandés par le _stub_.
Les deux identifiants de nœud de chaque `EdgeId` doivent être classés par ordre alphabétique.

| Définition | Graphe à construire |
| --- | --- |
| `empty_graph` | Un graphe vide |
| `graph_with_one_node` | Un seul nœud |
| `graph_with_one_node_with_attribute` | Un nœud avec un attribut |
| `graph_with_one_edge` | Une seule arête |
| `graph_with_one_attribute` | Un attribut de graphe |
| `graph_with_nodes_edges_and_attributes` | Des nœuds, des arêtes et des attributs |
| `multiple_edges_on_one_line` | Plusieurs arêtes exprimées sur une seule ligne |
| `only_1_edge_between_nodes` | Une seule arête entre chaque paire de nœuds |
