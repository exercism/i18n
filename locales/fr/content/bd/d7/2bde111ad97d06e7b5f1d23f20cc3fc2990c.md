# Instructions

`Two-fer`, ou `2-fer`, est la contraction de _two for one_.
Un pour toi, un pour moi.

Lorsqu'on te donne un nom, renvoie une _string_ contenant le message :

```text
One for name, one for me.
```

où `name` correspond au nom donné.

En revanche, si le nom est absent, renvoie la _string_ :

```text
One for you, one for me.
```

Voici quelques exemples :

|Nom     |_String_ à renvoyer
|:-------|:------------------
|Alice   |One for Alice, one for me.
|Bob     |One for Bob, one for me.
|        |One for you, one for me.
|Zaphod  |One for Zaphod, one for me.
