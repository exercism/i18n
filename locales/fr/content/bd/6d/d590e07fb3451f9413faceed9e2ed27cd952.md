# À propos

## Héritage

Java prend en charge l'héritage comme fonctionnalité centrale, ce qui permet ensuite de mettre en œuvre de nombreux principes de la POO, comme l'abstraction.

Une classe peut étendre une autre classe à l'aide du mot-clé `extends` et peut hériter d'une interface à l'aide du mot-clé `implements`.

## Modificateurs d'accès

Les modificateurs d'accès définissent les règles d'accès aux variables membres et aux méthodes d'une classe depuis d'autres classes (ou depuis n'importe où dans le code).

Il existe quatre modificateurs d'accès :

- `private`
- `public`
- `protected`
- par défaut (aucun mot-clé requis)

Tu peux en apprendre plus à leur sujet [dans cet article][access-modifiers]

## Héritage et composition

Ces deux concepts sont très proches et sont souvent confondus.

- L'héritage signifie que l'enfant a une relation _IS-A_ avec la classe parente.

```java
interface Animal() {
    public void bark();
}

class Dog implements Animal {
    public void bark() {
        System.out.println("Bark");
    }
}
```

Ici, `Dog` a une relation _IS-A_ avec `Animal`

- La composition représente une relation _HAS-A_.

```java
interface Engine {

}

class Car {
    private Engine engine;
}
```

Ici, `Car` a une relation _HAS-A_ avec `Engine`
