# Debug

Quand un test échoue, un message s'affiche pour décrire ce qui n'a pas fonctionné et pour quelle entrée. Tu peux inspecter n'importe quelle valeur de ton programme en la passant à la méthode `debug` (disponible dans `exercism/test_runner`). Cela capture les valeurs et t'affiche la sortie.


```gleam
import exercism/test_runner.{ debug }

let value: String = "test"
debug("The value is " <> value)
```
