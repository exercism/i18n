# Introduction

Une _string_ est le type de données JavaScript qui permet de stocker du texte.

## Crée une _string_

Pour créer une _string_, on entoure le texte de guillemets simples ou de guillemets doubles. Sur Exercism, on utilise des guillemets simples.

<!-- prettier-ignore-start -->
```javascript
'Hello, World!'
"Hello, World!"
```
<!-- prettier-ignore-end -->

## Une _string_ comme tableau de caractères

On peut considérer une _string_ comme un tableau de caractères dont le premier caractère a pour indice `0`. On peut accéder à un caractère individuel de la _string_ à l'aide de crochets et de l'indice de la lettre que l'on souhaite récupérer.

```javascript
'cat'[1];
// => 'a'
```

On peut déterminer le nombre de caractères d'une _string_ en accédant à la propriété `length`.

```javascript
'cat'.length;
// => 3
```

## Concaténation et méthodes

La façon la plus simple de concaténer des _strings_ est d'utiliser l'opérateur d'addition `+`.

```javascript
'I like' + ' ' + 'cats.';
// => "I like cats."
```

Les _strings_ fournissent de nombreuses méthodes utilitaires ; consulte la [documentation MDN sur les méthodes de String][mdn-string-methods] pour une liste complète. La liste suivante présente quelques méthodes utilitaires couramment utilisées.

- [`toUpperCase`][mdn-to-upper-case] et [`toLowerCase`][mdn-to-lower-case] : modifient la casse de tous les caractères
- [`trim`][mdn-trim] : supprime les espaces au début et à la fin
- [`includes`][mdn-includes], [`startsWith`][mdn-starts-with] et [`endsWith`][mdn-ends-with] : déterminent si une autre _string_ fait partie de la _string_ donnée
- [`slice`][mdn-slice] : extrait une partie de la _string_

Les _strings_ sont immuables en JavaScript. Ainsi, une « modification », par exemple avec certaines des méthodes ci-dessus, crée toujours une nouvelle _string_ à la place.
