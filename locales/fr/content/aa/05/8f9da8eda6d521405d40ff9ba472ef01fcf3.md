# Lance les tests en ligne de commande

Exécute les tests avec :

```bash
$ cargo test
```

Tous les tests sauf le premier ont été ignorés. Une fois que tu as fait passer le premier test, ouvre le fichier source des tests qui se trouve dans le répertoire `tests`, retire l'attribut `#[ignore]` du test suivant et fais-le passer à son tour. Chaque test est une fonction surmontée de l'attribut `#[test]`. Continue ainsi jusqu'à ce que tous les tests passent.

Si tu veux exécuter _uniquement_ les tests ignorés sans modifier le fichier source des tests, utilise :

```bash
$ cargo test -- --ignored
```

Si tu utilises Rust 1.51 ou une version ultérieure, tu peux exécuter _tous_ les tests avec

```bash
$ cargo test -- --include-ignored
```

Pour exécuter un test précis, par exemple `some_test`, tu peux utiliser :

```bash
$ cargo test some_test
```

Si ce test précis est ignoré, utilise :

```bash
$ cargo test some_test -- --ignored
```

Pour en savoir plus sur les tests en Rust, consulte la [documentation des tests][rust-tests] en ligne.

[rust-tests]: https://doc.rust-lang.org/book/ch11-02-running-tests.html
