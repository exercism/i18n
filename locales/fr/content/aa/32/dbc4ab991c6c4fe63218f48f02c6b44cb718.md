# À propos

`awk` est un langage de programmation interprété conçu pour le traitement de texte, généralement utilisé comme outil d'extraction et de rapport de données.
C'est une fonctionnalité standard de la plupart des systèmes d'exploitation de type Unix, et il dispose d'une [spécification POSIX][posix].

On peut dire qu'un paradigme de programmation `awk` est « piloté par les données » :
un programme `awk` lit des lignes (ou d'autres unités de texte) et cherche des correspondances de _motifs_.
Lorsqu'une correspondance est trouvée, l'_action_ spécifiée est exécutée.

Un programme `awk` ressemble à quelque chose comme
```awk
pattern1 {action1}
pattern2 {action2}
...
```

Le _motif_ peut être une expression régulière ou toute autre expression qui s'évalue à une valeur vrai/faux.
Le _motif_ peut être omis, auquel cas l'_action_ est exécutée pour chaque enregistrement de texte.
L'_action_ peut être omise, auquel cas l'action par défaut consiste à afficher l'enregistrement courant.

`awk` est un excellent ajout à la boîte à outils de l'utilisateur.
Il est très performant pour les petits programmes « one-liner » saisis en ligne de commande.
Un seul programme `awk` peut remplacer la plupart des pipelines de `grep`, `sed`, `tr`, `cut`

## Implémentations

`awk` a été inventé en 1977 par Alfred Aho, Peter Weinberger et Brian Kernighan (dont les noms de famille nous donnent le nom du langage).
Cette implémentation est devenue connue sous le nom de « old awk ».
En 1985, une version améliorée a été publiée, connue sous le nom de « BWK awk », « new awk » ou « the one-true-awk ».
C'est la version fournie avec macOS et certaines distributions \*BSD

Une autre implémentation courante est `mawk`, qui est basée sur un interpréteur de bytecode.
`mawk` est très rapide.
`mawk` est le `/usr/bin/awk` par défaut fourni sur de nombreuses distributions Linux.

### GNU awk

Ce parcours utilisera `gawk`, l'implémentation d'awk de GNU.
`gawk` n'a peut-être pas la vitesse brute de `mawk`, mais il est très riche en fonctionnalités, bien documenté et dispose de quelques options de ligne de commande pratiques.

### Shebang

Selon la plateforme, les scripts awk peuvent être exécutés en ajoutant une ligne [shebang][shebang] en haut du fichier.
Sur la plupart des systèmes, l'un des deux shebangs suivants devrait fonctionner.
Cependant, comme il n'existe pas de shebang unique qui fonctionne pour tous les systèmes, nous avons choisi d'omettre les shebangs.

```bash
#!/usr/bin/env -S gawk -f
#!/usr/bin/gawk -f
```
