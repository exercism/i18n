# À propos

En C#, les booléens sont représentés par le type `bool`, dont les valeurs peuvent être soit `true`, soit `false`.

C# prend en charge quatre [opérateurs booléens][operators] : `!` (PAS), `&&` (ET), `||` (OU) et `^` (OU exclusif). Les opérateurs `&&` et `||` utilisent une _évaluation en court-circuit_, ce qui signifie que le côté droit de l'opérateur n'est évalué que lorsque c'est nécessaire.

```csharp
true || false // => true
true && false // => false
true ^ false  // => true
true ^ true   // => false
```

Les trois opérateurs booléens ont chacun une [_précédence d'opérateurs_][precedence] différente. Par conséquent, ils sont évalués dans cet ordre : `not` (pas) d'abord, `&&` ensuite, `^` en troisième, et enfin `||`. Si tu veux « échapper » à ces règles, tu peux entourer une expression booléenne de parenthèses (`()`), car les parenthèses ont une précédence encore plus élevée.

```csharp
!true && false   // => false
!(true && false) // => true
```
