# Indices

## Général

- Le module `gleam/string` propose de nombreuses [fonctions sur les chaînes de caractères][stdlib].

## 1. Récupère le message d'une ligne de _log_

- L'opérateur `<>` peut être utilisé en filtrage par motif pour faire correspondre le début d'une _string_.
- Le module `gleam/string` propose une [fonction][trim] pour supprimer les espaces autour d'une _string_.

## 2. Récupère le niveau de _log_ d'une ligne de _log_

- Le module `gleam/string` propose une [fonction][lowercase] pour convertir une _string_ en minuscules.

## 3. Reformate une ligne de _log_

- L'opérateur `<>` peut être utilisé pour concaténer des _strings_.

[trim]: https://hexdocs.pm/gleam_stdlib/gleam/string.html#trim
[lowercase]: https://hexdocs.pm/gleam_stdlib/gleam/string.html#lowercase
