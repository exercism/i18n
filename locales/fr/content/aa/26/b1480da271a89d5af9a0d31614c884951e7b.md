# Introduction

Le mapping désigne l'application d'une fonction à chaque élément d'une séquence pour produire une nouvelle séquence.

On peut facilement le faire sur une liste avec la fonction `mapcar`.
Supposons que l'on ait une fonction `double` qui multiplie son argument par `2` :

```lisp
(mapcar #'double '(1 2 3 4)) ; => (2 4 6 8)
```

Remarque que le premier argument est une fonction à appeler. Le `#'` est une syntaxe de citation spéciale pour spécifier une fonction.

`double` a d'abord été appelée avec le premier élément, puis avec le deuxième, etc.
Les résultats ont été collectés dans une liste qui est la valeur de l'expression.
