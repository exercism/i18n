# Teste le parcours

_Avant_ de lancer ton parcours (autrement dit, tant que la clé `"active"` vaut encore `false` dans le `config.json` du parcours), il est important de tester le parcours.
Cela permet de trouver des erreurs (courantes) et de les corriger _avant_ le lancement du parcours, ce qui signifie que les apprenants ne les rencontreront jamais.

## Comment activer le parcours pour le tester

Pour activer le parcours en vue de le tester, il faut l'ajouter à notre base de données, ce que seuls les administrateurs du site peuvent faire.
Ouvre un sujet sur [le forum](https://forum.exercism.org/c/exercism/building-exercism/125) pour en faire la demande.

Note bien que l'ajout du parcours à la base de données ne lancera _pas_ le parcours, mais qu'il le rendra accessible sur le site pour les utilisateurs mainteneurs.

## Comment trouver des testeurs

Les utilisateurs idéaux pour tester le parcours sont les autres mainteneurs de parcours, car ils :

- ont de l'expérience dans la création d'un parcours (et savent donc ce qui aurait dû être construit)
- peuvent accéder aux parcours qui ne sont pas encore actifs

Pour que des mainteneurs testent ton parcours, ouvre un sujet sur [le forum](https://forum.exercism.org/c/exercism/building-exercism/125) pour en faire la demande.
