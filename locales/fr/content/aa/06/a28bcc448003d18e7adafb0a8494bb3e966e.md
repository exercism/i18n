# Les tests passent en local mais pas en ligne ?

Il arrive que les tests passent en local sur ta machine, mais pas en ligne.

Il y a en général quelques raisons à cela :

## Tu n'as pas activé tous les tests

De nombreux exercices Exercism sont fournis avec des tests désactivés.
Le but est que tu résolves chaque test dans l'ordre, en activant le suivant au fur et à mesure.
Le moment venu d'arriver à la fin de l'exercice, tous les tests devraient être activés et réussis, et tu auras une solution pleinement fonctionnelle.
Consulte la documentation du [parcours sur lequel tu travailles](/docs/tracks) pour savoir précisément comment les tests se désactivent dans ce langage.

Quand nous lançons les tests en ligne, nous activons d'abord tous les tests.
Si tu n'as pas activé tous les tests en local, nous risquons donc de tomber sur des cas limites auxquels tu n'as pas pensé, et les tests échoueront.

## Nous utilisons des versions différentes

Les exécuteurs de tests d'Exercism utilisent une version précise du langage.
Ce n'est peut-être pas la version la plus récente du langage, car nous devons mettre à jour manuellement nos exécuteurs de tests à chaque nouvelle version publiée.

Si les tests échouent en ligne, regarde la sortie (en cliquant sur le mot _« Échoué »_) et essaie de repérer ce qui pourrait ne pas aller.
Si tu penses que le problème vient d'une incompatibilité de versions, ouvre une _issue_ sur le dépôt GitHub de l'exécuteur de tests concerné.
Le nom de ce dépôt suit en général le modèle `https://github.com/exercism/$SLUG-test-runner` (par exemple `https://github.com/exercism/ruby-test-runner`).
