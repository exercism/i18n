# Ajout aux instructions

## Registres

| Registre | Utilisation | Type       | Description                                                    |
| -------- | ----------- | ---------- | -------------------------------------------------------------- |
| `$a0`    | entrée      | entier     | nombre de départ                                               |
| `$v0`    | sortie      | entier     | nombre d'étapes attendu, -1 si le nombre n'est pas valide      |
| `$t0-9`  | temporaire  | quelconque | utilisé comme stockage temporaire                              |
