# À propos

ABAP prend en charge les opérateurs arithmétiques habituels pour les valeurs numériques :

- `+` additionne des valeurs.
- `-` soustrait des valeurs.
- `*` multiplie des valeurs.
- `/` divise des valeurs.
- `MOD` renvoie le reste d'une division entière.

```abap
DATA total TYPE i.
total = 6 + 4 * 2.

DATA remaining_days TYPE i.
remaining_days = 70 MOD 22.
```

La multiplication et la division sont évaluées avant l'addition et la soustraction. Utilise des parenthèses lorsqu'un calcul doit être regroupé explicitement.

```abap
DATA result TYPE i.
result = ( 6 + 4 ) * 2.
```
