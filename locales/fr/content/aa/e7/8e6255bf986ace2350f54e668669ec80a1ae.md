# Tests

Un exercice téléchargé contient ces fichiers pour compiler et tester ta solution :

```text
hello-world/
├── HelloWorld.vb          # Your solution
├── HelloWorldTests.vb     # The test suite
├── HelloWorld.vbproj      # Project and build configuration
└── packages.lock.json     # Resolved project dependencies
```

Les noms de fichiers varient selon l'exercice.
Écris ta solution dans le premier fichier `.vb`.
Le deuxième fichier, dont le nom se termine par `Tests.vb`, est la [suite de tests xUnit][xunit].
En général, tu ne le modifies que pour réactiver les tests suivants.
Tu n'auras besoin de modifier aucun des deux derniers fichiers.
Le fichier `.vbproj` contient les paramètres de compilation du projet et les références directes aux paquets.
Le fichier `packages.lock.json` généré enregistre les versions résolues des paquets directs et transitifs.

~~~exercism/note
Les tests décrivent le comportement qu'une solution qui passe doit respecter.
Ils peuvent t'aider à clarifier des détails que les instructions ne couvrent pas.
~~~

## Exécute les tests

Ouvre un terminal dans le répertoire de l'exercice et lance :

```bash
dotnet test
```

La commande restaure les dépendances du projet, compile le projet et exécute ses tests.
Tu peux aussi utiliser `dotnet watch test` pour relancer les tests à chaque fois qu'un fichier source est modifié.

## Tests ignorés

Au départ, les exercices n'activent que le premier test, ce qui te permet de résoudre le reste étape par étape.
Ouvre le fichier dont le nom se termine par `Tests.vb` pour trouver les tests.
Chaque test est une sous-routine `Sub` annotée d'un attribut `<Fact>` xUnit.
Un test est ignoré tant que son attribut `<Fact>` possède un argument `Skip` :

```vb
<Fact(Skip:="Remove this Skip property to run this test")>
Public Sub Lowercase_words()
    Assert.Equal("ROR", Abbreviate("Ruby on Rails"))
End Sub
```

Pour activer le test, il suffit de supprimer l'argument `Skip` :

```vb
<Fact>
Public Sub Lowercase_words()
    Assert.Equal("ROR", Abbreviate("Ruby on Rails"))
End Sub
```

Une fois que le test que tu viens d'activer passe, répète ce processus avec le test ignoré suivant.
Quand tous les tests sont activés et passent, tu as terminé.
