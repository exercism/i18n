# Indices

## Général

- Pour chaque tâche, chaque fonction doit renvoyer une fermeture de fonction, en utilisant les arguments fournis. Consulte la section de la documentation Clojure sur les [fermetures de fonctions][closures] pour référence.

## 1. Traduis les coordonnées

- Les arguments fournis donnent la valeur de translation de la paire de coordonnées le long des axes _x_ et _y_.

## 2. Mets les coordonnées à l'échelle

- Les arguments fournis donnent le facteur d'échelle de la paire de coordonnées pour les axes _x_ et _y_.

## 3. Compose les fonctions de transformation

- Le résultat de la première transformation est un vecteur, mais les fonctions de transformation prennent deux arguments numériques. Tu devras récupérer les valeurs à partir du vecteur.
- N'oublie pas que l'ordre dans lequel les fonctions sont appliquées est important.

## 4. Sauvegarde les résultats des fonctions

- Pour cette fonction, tu ne dois mémoriser que le résultat de la dernière transformation.
- Pour renvoyer le résultat de la dernière transformation, tu devras vérifier si les arguments d'entrée sont les mêmes.
- Pour sauvegarder la valeur des arguments et le dernier résultat, tu peux utiliser un [atom][atoms].
