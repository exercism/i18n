# À propos

Les structures conditionnelles sont des instructions qui exécutent un code différent selon qu'une condition vaut `true` ou `false`.

Une [instruction `if`][if_statement] n'exécute son corps que lorsque sa condition est `true`.
Go ne connaît pas la notion de valeurs _truthy_ ou _falsy_ : la condition doit donc être de type `bool`.
Des expressions comme `if mySlice { ... }` ou `if 1 { ... }` provoquent des erreurs de compilation.

```go
func describe(val string) string {
    if val == "val" {
        return "was val"
    }
    return "was not val"
}
```

Utilise `else if` pour vérifier d'autres conditions, et `else` comme solution de repli si aucune ne correspond.
Les conditions sont évaluées de haut en bas, et seule la première branche dont la condition est vraie est exécutée.

```go
number := 0
result := "This number is "

if number > 0 {
    result += "positive"
} else if number < 0 {
    result += "negative"
} else {
    result += "zero"
}
```

De manière générale, Go privilégie le retour anticipé depuis le cas exceptionnel et évite `else`.

```go
func getVal(connected bool) int {
    if !connected {
        return readLocalVal()
    }

    return readVal()
}
```

Une instruction `if` peut aussi inclure une courte instruction d'initialisation.
On l'utilise couramment pour vérifier une erreur juste après un appel :

```go
num := 7
if v := 2 * num; v > 10 {
    fmt.Println(v)
} else {
    fmt.Println(num)
}
// Output: 14
```

Les variables déclarées dans l'instruction d'initialisation n'ont de portée que dans toute la chaîne `if`/`else`.
À noter que Go n'a pas d'opérateur ternaire, un choix de conception délibéré pour que le code reste facile à parcourir du regard.

Pour en savoir plus, consulte [Go by Example: If/Else][go_by_example_if].
