# Ajout aux instructions

## Indices

Pour réaliser cet exercice, tu dois créer le type de données `Robot`,
et implémenter les fonctions suivantes :

- `bearing`
- `coordinates`
- `mkRobot`
- `move`

Tu trouveras déjà une déclaration de données factice et les signatures de type,
mais c'est à toi de définir les fonctions et de créer un type de données,
un newtype ou un synonyme de type qui a du sens.
