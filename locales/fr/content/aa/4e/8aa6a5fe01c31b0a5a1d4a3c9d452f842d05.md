# Introduction

En Elixir, on peut définir des attributs de module qui peuvent servir de constantes dans nos fonctions.

```elixir
defmodule Example do
  # Defines the attribute as the value 1
  @constant_number 1

  def example_value() do
    # Returns the value 1
    @constant_number
  end
end
```

Lorsqu'on les utilise pour définir des constantes de module, les attributs peuvent être n'importe quelle expression qui peut être évaluée au moment de la compilation. Après la compilation, les attributs de module ne sont plus accessibles, car ils subissent une expansion lors de la compilation, à l'image des macros définies dans des langages comme le C.
