# Instructions complémentaires

## Mots

Implémente :

- `grep ( pattern flags files -- lines )`

`pattern` est la _string_ recherchée, `flags` est un tableau de zéro ou plusieurs _strings_ de drapeaux `"-n"`, `"-l"`, `"-i"`, `"-v"` et `"-x"`, et `files` est un tableau d'un ou plusieurs noms de fichiers. Renvoie les lignes correspondantes (avec les préfixes de nom de fichier et de numéro de ligne demandés, le cas échéant) sous forme d'un tableau de _strings_.

Quand le drapeau `-l` est fourni, renvoie un tableau des noms des fichiers qui contiennent au moins une correspondance.

## Lis les fichiers

Lis les lignes d'un fichier avec `file-lines`, en passant un encodage :

```factor
USING: io.encodings.utf8 io.files ;

"iliad.txt" utf8 file-lines
! => { "Achilles sing, O Goddess! Peleus' son;" ... }
```

Les trois fichiers de test (`iliad.txt`, `midsummer-night.txt` et `paradise-lost.txt`) accompagnent l'exercice dans le répertoire de travail, donc il suffit de les lire par leur nom.
