# Instructions

Comme presque tout le monde qui a un travail, Layla l'alien Lisp doit parfois rédiger des rapports pour informer les autres. Elle te demande si tu peux l'aider à formater les données dont elle dispose pour ces rapports.

## 1. Formate les valeurs trimestrielles

La première chose dont Layla a besoin, c'est une fonction : `format-quarter-value` qui prend deux paramètres : le trimestre et la valeur, et qui les formate pour un rapport. Elle doit renvoyer une _string_.

```lisp
(format-quarter-value "last" 3.14) ; => "The value last quarter: 3.14"
(format-quarter-value "this" 0) ; => "The value this quarter: 0"
```

## 2. Le rapport sur deux trimestres

Layla te remercie pour la fonction `format-quarter-value` et dit qu'elle sera très utile dans la *prochaine* fonction nécessaire.

Le rapport suivant doit montrer le trimestre et la valeur de 2 trimestres, imprimés sur deux lignes.

De plus, la sortie doit être écrite dans le flux fourni en premier argument.

Par exemple : `(format-two-quarters t "last" 3.14 "this" 0)` produira ce qui suit sur la sortie standard :

```

The value last quarter: 3.14
The value this quarter: 0

```

Remarque les lignes vides qui l'entourent.

## 3. Lisible par un humain ou par un alien Lisp

Layla a oublié de te dire que les aliens Lisp aiment voir les valeurs d'une manière qui se lise comme des données Lisp. Il leur faut donc une nouvelle fonction dont le résultat puisse se lire comme des données Lisp (là encore, vers le flux indiqué) :

```lisp
(format-two-quarters-for-reading nil "last" 3.14 "this" 0) ; =>

"(\"The value last quarter: 3.14\" \"The value this quarter: 0\")"
```
