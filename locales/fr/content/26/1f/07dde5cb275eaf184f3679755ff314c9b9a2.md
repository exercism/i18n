# À propos

Les [expressions `throw`][throw-expressions] sont une alternative aux instructions `throw` et permettent notamment d'enrichir les expressions ternaires et d'autres expressions composées.

```csharp
string trimmed = str == null ? throw new ArgumentException() : str.Trim();
```

Si `str` vaut `null` dans le code ci-dessus, une exception est levée.

[throw-expressions]: https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/keywords/throw#the-throw-expression
