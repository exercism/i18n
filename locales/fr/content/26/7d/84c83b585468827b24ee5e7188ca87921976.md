# Instructions

Un violon s'accorde à l'oreille, par rapport à une note de référence. Les cordes sont très éloignées les unes des autres en hauteur, et les nombres en jeu ne sont pas entiers.

Les cinq tâches se font toutes dans la classe `TUNING_THE_STRINGS`.

## 1. Monte d'une octave

Une note une octave plus haut a une fréquence deux fois plus élevée.

```sather
TUNING_THE_STRINGS::octave_up(440.0d)
-- => 880.0d
```

## 2. Descends d'une octave

Une octave en dessous, c'est la moitié.

```sather
TUNING_THE_STRINGS::octave_down(440.0d)
-- => 220.0d
```

## 3. À mi-chemin

Étant donné deux fréquences, renvoie celle qui se situe exactement entre les deux.

```sather
TUNING_THE_STRINGS::midpoint(440.0d, 442.0d)
-- => 441.0d
```

## 4. Quel est l'écart ?

Quand deux notes sont proches sans être identiques, on entend un battement une fois par seconde pour chaque cycle d'écart entre elles. Renvoie l'écart entre les fréquences. La réponse n'est jamais négative, quelle que soit la note la plus haute.

```sather
TUNING_THE_STRINGS::beats_per_second(441.5d, 440.0d)
-- => 1.5d
```

## 5. Répartis le temps de pratique

Étant donné un nombre de minutes et un nombre de musiciens, combien de minutes chacun obtient-il ? Les minutes et les musiciens sont des nombres entiers, mais la réponse ne l'est pas forcément.

```sather
TUNING_THE_STRINGS::minutes_each(45, 2)
-- => 22.5d
```
