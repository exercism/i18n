# Convention Ameba

**Ligne %{line_number}** :  le message %{message} a été signalé par Ameba.

Ce qui signifie que ce code ne suit pas les conventions générales de [style de code][code style].
Ce type de problème n'affecte généralement pas la façon dont le code _s'exécute_, mais il peut nuire à la lisibilité ou aux performances d'outils automatisés comme les générateurs de documentation ou les exécuteurs de tests.

[code style]: https://crystal-lang.org/reference/latest/conventions/coding_style.html
