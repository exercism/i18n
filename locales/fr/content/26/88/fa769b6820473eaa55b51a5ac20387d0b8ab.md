# Indices

## 1. Estime le temps de préparation

- Utilise la [fonction native `len()`][len-builtin] pour déterminer le nombre de couches (la longueur du _slice_ de couches).

## 2. Calcule les quantités de nouilles et de sauce nécessaires

- Commence par créer deux variables pour suivre les quantités de nouilles et de sauce.
- Utilise une boucle `for` pour parcourir les couches.
- Si tu rencontres une couche `'noodles'` ou `'sauce'` dans ta boucle, augmente en conséquence la quantité stockée dans la variable correspondante.

## 3. Ajoute l'ingrédient secret

- Reviens sur les [_slices_][concept-slices] pour découvrir comment récupérer un élément d'un _slice_ et comment remplacer un élément dans un _slice_.
- L'indice du dernier élément d'un _slice_ `a` est `len(a) - 1`.

## 4. Adapte les proportions de la recette

- Commence par créer un nouveau _slice_ de la même taille que le _slice_ d'entrée
- Utilise une [boucle `for`][for-loop] pour parcourir le _slice_ d'entrée et générer le _slice_ de sortie
