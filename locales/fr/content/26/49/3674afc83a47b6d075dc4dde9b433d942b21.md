# Installation

Ce parcours s'appuie tout du long sur [Wren Console][wren-console] pour fournir un environnement d'exécution local de Wren. Cela signifie que nous partons du principe que tout le Wren que tu exécuteras sur ton ordinateur passera par [Wren Console][wren-console]. Ne confonds pas cela avec la CLI officielle de Wren <abbr title="interface en ligne de commande">CLI</abbr>. Dans un monde parfait, tu pourrais utiliser cet environnement d'exécution, mais il [a](https://github.com/wren-lang/wren-cli/pull/74) actuellement [plusieurs](https://github.com/wren-lang/wren/pull/1006) [problèmes](https://github.com/wren-lang/wren-cli/issues/108) [différents](https://github.com/wren-lang/wren-cli/pull/105), ce qui en fait un choix loin d'être optimal pour apprendre Wren avec Exercism.

Wren Console est un fork de Wren CLI : il résout ces problèmes et ajoute des fonctionnalités qui rendent ton apprentissage plus fluide. Pas de panique : les connaissances et les concepts du langage Wren que tu vas apprendre ici s'appliqueront partout où tu voudras utiliser Wren par la suite.

## Aperçu de l'installation

- Installe Git pour disposer de la commande `git`
- Installe [Wren Console][wren-console] pour disposer de la commande `wrenc`

### Installer Git

Il te faut le binaire `git` installé et présent dans ton PATH. C'est ainsi que Wren Package installe les paquets (comme la suite de tests dont tu auras besoin pour tester tes exercices, etc.).

- **Windows** : le [téléchargement officiel de Git](https://git-scm.com/download/win) est un bon point de départ.
- **Linux** : ton gestionnaire de paquets préféré devrait faire l'affaire.
- **Mac** : toutes les versions récentes de Mac OS incluent `git` d'emblée.

Tu peux vérifier que Git est installé avec `git --version` :

```
$ git --version
git version 2.31.1
```

Pas d'inquiétude si ta version exacte diffère, ce n'est généralement pas très important.


### Installer Wren Console

#### Windows

Tu voudras sans doute [télécharger la dernière version][releases] depuis GitHub. Ensuite, il te faudra la décompresser et copier l'exécutable `wrenc` dans ton PATH.

Il est aussi possible de [compiler depuis les sources][build-from-source] avec Visual Studio.

#### Linux

Tu peux [télécharger la dernière version][releases] depuis GitHub ou [compiler depuis les sources][build-from-source].

```sh
wget -c https://github.com/joshgoebel/wren-console/releases/download/v0.3.1/wren-console-v0.3.1-linux.tar.gz
tar xzf wren-console-v0.3.1-linux.tar.gz
```

Et assure-toi qu'il est disponible dans ton `PATH`.

```sh
cp bin/wrenc /usr/local/bin/
```


#### Mac

La façon la plus simple d'installer Wren Console est d'utiliser le tap et la formule [Homebrew][homebrew] d'Exercism :

```
brew tap exercism/wren
brew install wren-console
```

Sinon, tu peux [télécharger la dernière version][releases] depuis GitHub et l'installer manuellement comme indiqué dans les instructions pour Linux. Compiler depuis les sources est aussi assez simple si tu maîtrises ce genre de choses.

### Tester l'installation

Une fois que tu penses avoir installé le binaire correctement, il est bon de vérifier que tout fonctionne.

1. Ouvre un _terminal_ (`Terminal`, `cmd`, `Powershell`, `bash`, ...)
2. Exécute `wrenc -v`

Tu devrais voir les versions de `wrenc` et de Wren s'afficher :

```
wrenc v0.3.1 (wren v0.4.0)
```

**Remarque** : il est important que tu ouvres une fenêtre de terminal _nouvelle_. Les fenêtres de terminal déjà ouvertes n'ont peut-être pas été rafraîchies à la fin de l'installation. Cela signifie qu'elles ignorent qu'un nouveau programme a été installé.

> _**Aide**_ : `'wrenc' is not recognised`
>
> Tu n'as probablement pas placé `wrenc` dans ton PATH... Sur MacOS et Linux, tu peux modifier ton path en ajoutant ce qui suit à
> `~/.bash_profile` ou `~/.zshrc` :
>
> ```bash
> export PATH=/path/to/your/wrenc/:$PATH
> ```
> **Aucune idée si tout ceci est correct.**
> Sur Windows, ouvre le menu Démarrer et recherche « environment variables ». Tu devras
> modifier l'entrée `PATH` et y _ajouter_ le chemin vers les binaires `wrenc`.
> On les trouve généralement dans `C:\Program Files\nodejs`. Si tu y navigues avec
> ton `File Explorer`, tu devrais trouver `node.exe`, `npm.bat` et `npx.bat`.
>
> Ferme tous les terminaux ouverts et ouvres-en un nouveau.

## Prérequis pour les exercices

Suis [ces instructions][cli-walkthrough] pour télécharger la CLI `exercism` adaptée à ton système d'exploitation.

Une fois la CLI installée et configurée, télécharge le premier exercice : `hello-world` :

```bash
$ exercism download --exercise=hello-world --track=wren
```

Chaque exercice a ensuite besoin de quelques paquets Wren pour exécuter les tests. Tu peux les installer en exécutant cette commande depuis le répertoire de l'exercice :

```bash
$ wrenc package.wren install
```
