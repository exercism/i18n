# Indices

## 1. Définis le type TreasureChest

- L'introduction contient tout ce dont tu as besoin pour cette étape.

## 2. Définis la fonction get_treasure()

- Un [opérateur ternaire][ternary] suffit.

## 3. Définis la fonction multiply_treasure

- La valeur de retour sera un `TreasureChest{Vector{T}}`, où `T` est le type du trésor dans le coffre fourni.
  - Dans l'esprit du concept, tu pourrais récupérer le type du trésor et créer un coffre paramétrique dont le paramètre est un `Vector` du type d'origine.
  - Bien plus simple (même si cela peut donner _un tout petit peu_ l'impression de tricher), tu pourrais ignorer le paramètre et laisser l'inférence de type s'en occuper.
- Pour créer un vecteur avec des éléments répétés, tu as le choix entre deux fonctions :
  - [`fill(value, multiplier)`][fill] prend une valeur scalaire et la répète.
  - [`repeat([value,], multiplier)`][repeat] répète le vecteur donné.
