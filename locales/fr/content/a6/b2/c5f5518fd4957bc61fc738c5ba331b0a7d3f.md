# Introduction

## Valeurs vraies et fausses

En Common Lisp, toutes les valeurs sont « vraies », sauf `()` qui est « fausse ».
Il existe deux symboles constants spéciaux, `t` et `nil`, dont les valeurs sont respectivement vrai et faux.

## Structures conditionnelles

Common Lisp propose plusieurs expressions conditionnelles différentes, la principale différence étant le nombre de branches qu'elles prennent en charge.

- `when` et `unless` n'autorisent qu'une seule branche :

```lisp
(when (= 2 2) "All is well")      ; => "All is well"
(unless (= 2 2) "Time to panic!") ; => NIL
```

La section qui suit l'expression de test peut contenir plus d'une expression.

- `if` fournit la construction classique _if-then-else_ :

```lisp
(if (= 2 2) 'how-honest 'you-liar) ; => HOW-HONEST
```

À noter que les clauses _then_ et _else_ ne peuvent contenir qu'une seule expression.

- `cond` permet d'avoir plusieurs branches sans imbriquer d'expressions `if` :

```lisp
(cond ((= 0 2) 'nope)
      ((= 1 2) 'try-again)
      ((= 2 2) 'quite-true)
      ((= 3 2) 'too-far)
      (t 'something-else))
; => QUITE-TRUE
```

À noter qu'il n'y a pas de limite au nombre d'expressions qui suivent l'expression de test.

- `case` fournit une construction classique de style _switch_ : elle confronte une seule valeur à plusieurs branches :

```lisp
(case 'elder-beast
  (cat "Meow")
  (bird "Chirp")
  (dog "Bark")
  (otherwise "???"))
; => "???"
```

À noter que, comme pour `cond`, il n'y a pas de limite au nombre d'expressions qui suivent l'expression de test.
