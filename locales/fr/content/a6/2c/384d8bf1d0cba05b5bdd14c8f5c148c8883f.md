# Indices

Pour toutes ces tâches, tu auras besoin de la commande `print` :
```awk
{print "something", "something else"}
```

## 1. Liste les noms d'utilisateur

* Utilise [la variable `FS`][var-fs] pour définir le séparateur de champs.

## 2. Affiche les numéros de ligne

* Utilise la [variable intégrée `NR`][var-nr] pour obtenir le numéro de ligne.

## 3. Affiche les enregistrements dont le répertoire personnel est invalide.

* Le répertoire personnel est le 6e champ.
* Utilise la fonction `startsWith` fournie.
* Utilise les [opérateurs booléens][boolean-ops] : `&&`, `||`, `!`.

## 4. Affiche le nombre d'utilisateurs valides qui utilisent bash

* Le shell de connexion est le dernier champ ; tu peux utiliser [la variable `NF`][var-nf].
