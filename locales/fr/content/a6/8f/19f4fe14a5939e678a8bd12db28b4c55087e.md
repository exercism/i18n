## 1. Documente le but des outils de formulaire

- L'attribut de module `@moduledoc` permet d'écrire la documentation d'un module.

## 2. Documente le remplissage de champs avec des valeurs vides

- L'attribut de module `@doc` permet d'écrire la documentation d'une fonction.
- L'attribut de module `@spec` permet d'écrire un typespec pour une fonction.
- Place les attributs `@doc` et `@spec` juste avant la première clause de la fonction que ces attributs décrivent.
- Consulte la [documentation sur les typespecs][typespecs-types] pour obtenir la liste de tous les types disponibles.
- Le type correct pour les _strings_ est [défini dans le module `String`][string-t].

## 3. Documente la séparation de valeurs en tableaux de lettres majuscules

- L'attribut de module `@doc` permet d'écrire la documentation d'une fonction.
- L'attribut de module `@spec` permet d'écrire un typespec pour une fonction.
- Place les attributs `@doc` et `@spec` juste avant la première clause de la fonction que ces attributs décrivent.
- Consulte la [documentation sur les typespecs][typespecs-types] pour obtenir la liste de tous les types disponibles.
- Le type correct pour les _strings_ est [défini dans le module `String`][string-t].
- Un tableau est un type paramétré.

## 4. Documente la vérification qu'une valeur tient dans un champ avec une longueur maximale

- L'attribut de module `@doc` permet d'écrire la documentation d'une fonction.
- L'attribut de module `@spec` permet d'écrire un typespec pour une fonction.
- Place les attributs `@doc` et `@spec` juste avant la première clause de la fonction que ces attributs décrivent.
- Consulte la [documentation sur les typespecs][typespecs-types] pour obtenir la liste de tous les types disponibles.
- Le type correct pour les _strings_ est [défini dans le module `String`][string-t].
- Des valeurs littérales peuvent être utilisées dans un typespec.
- La barre verticale `|` permet de représenter une union de types.

## 5. Documente les différents formats d'adresse

- L'attribut de module `@type` permet de définir un type public personnalisé.
- Les types peuvent être composés : par exemple, lorsque tu définis un type qui est une _map_, tu peux aussi préciser le type des valeurs associées à chaque clé.
- [L'opérateur de type `::`][type-operator] permet aussi de placer un nom de variable devant un type.
- Les types personnalisés peuvent servir à définir d'autres types personnalisés.

## 6. Documente le formatage de l'adresse

- L'attribut de module `@doc` permet d'écrire la documentation d'une fonction.
- L'attribut de module `@spec` permet d'écrire un typespec pour une fonction.
- Place les attributs `@doc` et `@spec` juste avant la première clause de la fonction que ces attributs décrivent.
- Consulte la [documentation sur les typespecs][typespecs-types] pour obtenir la liste de tous les types disponibles.
- Le type correct pour les _strings_ est [défini dans le module `String`][string-t].
- Les types personnalisés peuvent être utilisés dans un typespec.
