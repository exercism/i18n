# Instructions

Dans cet exercice, tu vas implémenter la logique de quête d'un nouveau jeu de rôle développé par un ami.
Le personnage principal du jeu est Annalyn, une jeune fille courageuse accompagnée d'un chien de compagnie féroce et fidèle.
Malheureusement, le malheur s'abat sur elle : son meilleur ami a été enlevé alors qu'il cherchait des baies dans la forêt.
Annalyn va tenter de retrouver et de libérer son meilleur ami, en emmenant éventuellement son chien avec elle dans cette quête.

Après avoir suivi la piste de son meilleur ami pendant un certain temps, elle trouve le camp où celui-ci est emprisonné.
Il s'avère qu'il y a deux ravisseurs : un chevalier puissant et un archer rusé.

Après avoir trouvé les ravisseurs, Annalyn réfléchit aux actions suivantes qu'elle peut entreprendre :

- _Attaque rapide_ : une attaque rapide peut être effectuée si le **chevalier** est **_endormi_**, car il lui faut du temps pour enfiler son armure, ce qui le rend vulnérable.
- _Espionnage_ : on peut espionner le groupe si **au moins l'un** de ses membres est **_éveillé_**. Sinon, l'espionnage est une perte de temps.
- _Signaler le prisonnier_ : on peut signaler sa présence au prisonnier à l'aide de chants d'oiseaux si le **prisonnier** est **_éveillé_** et que l'**archer** est **_endormi_**, car les archers sont formés à la communication par oiseaux et pourraient donc intercepter le message.
- _Libérer le prisonnier_ : Annalyn peut tenter de se faufiler dans le camp pour libérer le prisonnier.
  L'entreprise est risquée et ne peut réussir que de l'une des deux façons suivantes :
  - Si Annalyn a son chien avec elle, elle peut sauver le prisonnier si l'**archer** est **_endormi_**.
    Le chevalier a peur du chien et l'archer n'aura pas le temps de se préparer avant qu'Annalyn et le prisonnier ne s'échappent.
  - Si Annalyn n'a pas son chien, elle et le prisonnier doivent alors être très discrets !
    Annalyn peut libérer le prisonnier si le **prisonnier** est **_éveillé_** et que le **chevalier** et l'**archer** sont tous les deux **_endormis_**, mais si le **prisonnier** est **_endormi_**, il ne peut pas être sauvé : le prisonnier serait surpris par l'apparition soudaine d'Annalyn et réveillerait le chevalier et l'archer.

Tu as quatre tâches : implémenter la logique qui détermine si les actions ci-dessus sont disponibles, en fonction de l'état des trois personnages trouvés dans la forêt et de la présence ou non du chien d'Annalyn.

## 1. Vérifie si l'action « Attaque rapide » est possible

Implémente une fonction nommée `canExecuteFastAttack` qui prend une valeur booléenne indiquant si le chevalier est éveillé.
Cette fonction renvoie `true` si l'action « Attaque rapide » est disponible en fonction de l'état du personnage.
Sinon, elle renvoie `false` :

```javascript
const knightIsAwake = true;
canExecuteFastAttack(knightIsAwake);
// => false
```

## 2. Vérifie si l'action « Espionnage » est possible

Implémente une fonction nommée `canSpy` qui prend trois valeurs booléennes, indiquant si le chevalier, l'archer et le prisonnier, respectivement, sont éveillés.
La fonction renvoie `true` si l'action « Espionnage » est disponible en fonction de l'état des personnages.
Sinon, elle renvoie `false` :

```javascript
const knightIsAwake = false;
const archerIsAwake = true;
const prisonerIsAwake = false;
canSpy(knightIsAwake, archerIsAwake, prisonerIsAwake);
// => true
```

## 3. Vérifie si l'action « Signaler le prisonnier » est possible

Implémente une fonction nommée `canSignalPrisoner` qui prend deux valeurs booléennes, indiquant si l'archer et le prisonnier, respectivement, sont éveillés.
La fonction renvoie `true` si l'action « Signaler le prisonnier » est disponible en fonction de l'état des personnages.
Sinon, elle renvoie `false` :

```javascript
const archerIsAwake = false;
const prisonerIsAwake = true;
canSignalPrisoner(archerIsAwake, prisonerIsAwake);
// => true
```

## 4. Vérifie si l'action « Libérer le prisonnier » est possible

Implémente une fonction nommée `canFreePrisoner` qui prend quatre valeurs booléennes.
Les trois premiers paramètres indiquent si le chevalier, l'archer et le prisonnier, respectivement, sont éveillés.
Le dernier paramètre indique si le chien d'Annalyn est présent.
La fonction renvoie `true` si l'action « Libérer le prisonnier » est disponible en fonction de l'état des personnages et de la présence du chien d'Annalyn.
Sinon, elle renvoie `false` :

```javascript
const knightIsAwake = false;
const archerIsAwake = true;
const prisonerIsAwake = false;
const petDogIsPresent = false;
canFreePrisoner(knightIsAwake, archerIsAwake, prisonerIsAwake, petDogIsPresent);
// => false
```
