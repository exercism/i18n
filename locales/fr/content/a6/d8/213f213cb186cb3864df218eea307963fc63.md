# Introduction

Une propriété en Haxe est un membre d'une classe qui donne accès aux données de cette classe. Les appelants peuvent définir ou récupérer (get) ces données. Une propriété comporte un accesseur set et/ou un accesseur get.

Les propriétés ont des modificateurs d'accès (public, private, etc.) comme les autres membres de la classe, mais l'accesseur set peut avoir un niveau d'accès indépendant de l'accesseur get, et inversement. Une propriété n'a pas besoin d'avoir les deux accesseurs : elle peut n'en avoir qu'un seul (soit get, soit set).

L'accès en lecture et l'accès en écriture se reflètent directement dans la syntaxe, comme le montre l'exemple suivant :

```haxe
class Main {
  public var x(default, null):Int;
}
```

`default` et `null` sont tous deux des **identifiants d'accès** particuliers. Les identifiants d'accès définissent le comportement adopté lorsque le champ est lu (premier identifiant) et lorsqu'il est écrit (second identifiant). Les valeurs acceptées sont :

- `default` : autorise l'accès normal au champ si celui-ci est public.
- `null` : autorise l'accès uniquement depuis la classe dans laquelle le champ est défini.
- `get/set` : l'accès est généré sous la forme d'un appel à une méthode d'accès (`get_x()`).
- `dynamic` : identique à `get/set`, mais l'existence d'une méthode d'accès ne peut pas être vérifiée.
- `never` : n'autorise aucun accès, quel qu'il soit.

Voici un exemple complet :

```haxe
class Main {
  public var x(default, set):Int;

  public function set_x(x:Int):Int {
    return this.x = x + 2;
  }

  public function main() {
    trace(x); // null
    x = 2;
    trace(x); // 4
  }
}
```
