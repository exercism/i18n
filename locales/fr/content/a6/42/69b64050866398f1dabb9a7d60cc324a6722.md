# À propos

Go est un langage à typage statique, donc chaque variable a un type connu au moment de la compilation.
Une fois déclarée, le type d'une variable ne peut plus changer.

## Crée une variable

L'instruction `var` permet de déclarer le type d'une nouvelle variable, de définir sa valeur, ou les deux à la fois :

```go
var total int     // Type explicitly declared, value implicitly set (see note on zero values below)
var count int = 1 // Type explicitly declared, value explicitly set
var sum = 100     // Type implictly declared, value explicitly set
```

À l'intérieur d'une fonction, on peut aussi utiliser l'instruction d'affectation courte `:=`.

```go
count := 1 // Type implictly declared, value explicitly set
```

Une variable en Go a toujours une valeur.
Si aucune n'est définie à la déclaration, Go en fournit une [appelée valeur zéro][zero-values], en fonction du type de la variable.

```go
var total int     // 0
var name string   // ""
var ready bool    // false
```

## Mets à jour une variable

À l'intérieur d'une fonction, l'opérateur d'affectation `=` permet de définir une nouvelle valeur pour une variable existante :

```go
count := 1
count = 2
```

La nouvelle valeur doit avoir le même type que la variable :

```go
count := 1
count = false // compile error: a Boolean is not an int
```

[zero-values]: https://exercism.org/tracks/go/concepts/zero-values
