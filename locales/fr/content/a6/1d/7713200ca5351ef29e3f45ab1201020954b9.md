# Itération

En programmation, l'[itération][iteration] désigne le processus qui consiste à répéter un bloc de code plusieurs fois.
Cela peut se faire à l'aide de concepts comme les boucles _while_ et _until_.
On peut aussi y parvenir par récursion, c'est-à-dire une fonction qui s'appelle elle-même.

Cependant, le plus souvent, on veut itérer sur une collection d'éléments, comme un `Array`, un `Range` ou une `String`.
En Crystal, les classes `Array` et `Range` incluent toutes deux le module [`Enumerable`][enumerable], qui fournit un certain nombre de méthodes pour itérer sur les éléments.
De son côté, la classe `String` dispose de son propre ensemble de méthodes pour itérer sur les caractères.

Crystal ne possède pas non plus d'instruction `for` contrairement à d'autres langages.
À la place, il propose plusieurs méthodes qui permettent d'itérer.

## Itère

La façon la plus courante d'itérer sur une collection consiste à utiliser la méthode [`each`][each], qui passe chaque élément de la collection à un bloc.
C'est facile à faire avec un `Range`.
Imaginons que l'on veuille boucler entre 1 et 3 : on peut utiliser la méthode `each` pour itérer sur cet intervalle.

```crystal
(1..3).each do |n|
  puts n
end

# Output:
# 1
# 2
# 3
```

Encore plus simple, si on veut simplement itérer un certain nombre de fois, on peut utiliser la méthode [`times`][times], qui existe sur la classe `Int`.

```crystal
3.times do |n|
  puts n
end

# Output:
# 0
# 1
# 2
```

## Itère sur une `String`

Une `String` est une séquence de caractères et n'appartient pas au module `Enumerable`, ce qui signifie qu'elle possède son propre ensemble de méthodes pour itérer sur les caractères.
La façon la plus courante d'itérer sur une `String` consiste à utiliser la méthode [`each_char`][each_char], qui passe chaque caractère de la `String` à un bloc.

~~~~exercism/note
La méthode `each_char` passe un objet `Char` et non un objet `String` au bloc.
~~~~

```crystal
str = "hello"
str.each_char { |char| puts char }

# Output:
# h
# e
# l
# l
# o
```

Une autre façon d'itérer sur une `String` consiste à utiliser la méthode [`each_line`][each_line].
Cette méthode est surtout utilisée lorsqu'on lit un fichier ligne par ligne.

```crystal
str = "hello\nworld"
str.each_line do |line|
  puts line
end

# Output:
# hello
# world
```

## Itère sur un objet qui inclut le module `Enumerable`

Le module [`Enumerable`][enumerable] fournit un certain nombre de méthodes pour itérer sur les éléments d'une collection.
Les collections qui incluent le module `Enumerable` sont `Array`, `Range`, `Hash`, `Set` et d'autres ; ces dernières seront abordées dans de prochains concepts.

La façon la plus courante d'itérer sur un `Array` consiste à utiliser la méthode [`each`][each], qui passe chaque élément du `Array` à un bloc.

```crystal
arr = [5, 2, 3]
arr.each do |element|
  puts element
end

# Output:
# 5
# 2
# 3
```

### Map

La méthode [`map`][map] est une autre façon d'itérer sur un `Array` : elle renvoie un nouveau `Array` contenant les résultats de l'application du bloc à chaque élément.
Elle est similaire à la méthode `each`, mais elle renvoie un nouveau `Array` avec les éléments transformés.
La transformation est très utile lorsqu'on veut appliquer une fonction à chaque élément de la collection, ce qui est une opération courante.

```crystal
arr = [1, 2, 3]
new_arr = arr.map do |element|
  element * 2
end

new_arr
# => [2, 4, 6]
```

Avec une structure de contrôle comme `if`, on peut filtrer les éléments à transformer.

```crystal
arr = [1, 2, 3]
new_arr = arr.map do |element|
  if element.odd?
    element * 2
  else
    element
  end
end

new_arr
# => [2, 2, 6]
```

## Raccourci

En Crystal, il existe une syntaxe abrégée pour itérer sur chaque élément d'une collection et lui appliquer une méthode.
Elle est utile quand la logique est simple et qu'une seule méthode suffit à la transformer.
Pour cela, on utilise la syntaxe `&.` suivie du nom de la méthode.

```crystal
arr = [1, 2, 3]
arr.map(&.to_s)
# => ["1", "2", "3"]
```

### Avec un indice

Parfois, on a besoin de connaître l'indice de l'élément sur lequel on itère ; on peut pour cela utiliser la méthode [`each_with_index`][each_with_index] ou [`map_with_index`][map_with_index].
Elle passe chaque élément et son indice à un bloc, et la méthode accepte aussi un argument facultatif pour préciser l'indice de départ.

```crystal
arr = [1, 2, 3]
arr.each_with_index(4) do |element, index|
  puts "Element: #{element}, Index: #{index}"
end

# Output:
# Element: 1, Index: 4
# Element: 2, Index: 5
# Element: 3, Index: 6
```

À noter que la méthode [`each_char_with_index`][each_char_with_index] est également disponible pour les objets `String`.

### sum

La méthode [`sum`][sum] renvoie la somme de tous les éléments de la collection ; elle accepte aussi un bloc facultatif pour transformer les éléments avant de les additionner.
Elle accepte également un argument facultatif pour préciser la valeur initiale de la somme.

```crystal
arr = [1, 2, 3]
arr.sum
# => 6

arr.sum(2) { |n| n * 2 }
# => 14
```

### reduce

[`reduce`][reduce], ou fold comme on l'appelle dans d'autres langages, est une méthode qui, à partir d'une méthode de combinaison et d'une valeur initiale, combine tous les éléments de la collection.
La méthode `reduce` utilise un accumulateur qui est passé au bloc ; cet accumulateur est le résultat de l'itération précédente.
Il s'agit alors d'un processus récursif qui combine tous les éléments de la collection.

```crystal
arr = [1, 2, 3]
arr.reduce(0) do |acc, n|
  acc + n
end
# => 6
```

`reduce` peut sembler similaire à `sum`, mais `reduce` est plus flexible parce qu'il permet de préciser la valeur initiale de l'accumulateur et la méthode de combinaison.
On peut utiliser `reduce` pour implémenter `sum`, `count` et d'autres méthodes.
