# Teste en ligne de commande

Roc est fourni avec ses propres outils de test intégrés, pas besoin d'installer quoi que ce soit d'autre.

Pour tester ta solution à un exercice, ouvre un terminal, place-toi dans le répertoire de l'exercice, exécute `roc test <exercise-name>-test.roc`, par exemple `roc test hello-world-test.roc`, et vérifie que tous les tests passent. Ne modifie *pas* `*-test.roc` lui-même, seulement le ou les autres fichiers `*.roc`.
