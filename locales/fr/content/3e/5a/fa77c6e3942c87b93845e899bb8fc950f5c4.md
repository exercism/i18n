# Instructions

Convertis un nombre hexadécimal, représenté sous forme de _string_ (par exemple « 10af8c »), en son équivalent décimal à partir des principes de base (c'est-à-dire que non, tu n'as pas le droit d'utiliser des bibliothèques intégrées ou externes pour effectuer la conversion).

Sur le web, on utilise l'hexadécimal pour représenter les couleurs, par exemple vert : 008000, bleu canard : 008080, bleu marine : 000080.

Le programme doit gérer les _strings_ hexadécimales invalides.
