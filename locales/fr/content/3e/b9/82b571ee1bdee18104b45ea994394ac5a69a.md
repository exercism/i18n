# Ne pas utiliser les fonctions d'`Enum`

L'objectif de cet exercice est d'enseigner les listes et les fonctions du module [`Kernel`] et du module [`List`]. Résous-le sans utiliser les fonctions du module [`Enum`].

[`Kernel`]: https://hexdocs.pm/elixir/Kernel.html
[`List`]: https://hexdocs.pm/elixir/List.html
[`Enum`]: https://hexdocs.pm/elixir/Enum.html
