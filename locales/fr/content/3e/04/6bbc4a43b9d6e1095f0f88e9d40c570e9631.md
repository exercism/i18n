# Instructions

Elyse, future magicienne, poursuit son entraînement. On lui donnera plusieurs piles de cartes dont elle a besoin pour exécuter ses tours. Pour simplifier un peu les choses, elle n'utilise que les cartes de 1 à 10.

Dans cet exercice, utilise des méthodes natives pour analyser le contenu d'un tableau.

## 1. Trouve la position d'une carte

Elyse veut connaître la position (l'indice) d'une carte dans la pile.

```javascript
const card = 2;
getCardPosition([9, 7, 3, 2], card);
// => 3
```

## 2. Détermine si une carte est présente

Elyse veut déterminer si une carte est présente dans la pile, autrement dit si la pile contient un `number` spécifique.

```javascript
const card = 3;
doesStackIncludeCard([2, 3, 4, 5], card);
// => true
```

## 3. Détermine si chaque carte est paire

Elyse veut savoir si chaque carte est paire, autrement dit si chaque nombre de la pile est un `number` pair.

```javascript
isEachCardEven([2, 4, 6, 7]);
// => false
```

## 4. Vérifie si la pile contient une carte de valeur impaire

Elyse veut savoir s'il y a un nombre impair dans la pile.

```javascript
doesStackIncludeOddCard([3, 2, 6, 4, 8]);
// => true
```

## 5. Récupère la première carte impaire de la pile

Elyse veut connaître la valeur de la première carte qui est impaire.

```javascript
getFirstOddCard([4, 2, 8, 7, 9]);
// => 7
```

## 6. Détermine la position de la première carte qui est paire

Elyse veut connaître la position de la première carte qui est paire.

```javascript
getFirstEvenCardPosition([5, 2, 3, 1]);
// => 1
```
