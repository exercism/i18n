# Introduction

On peut comprendre une interface comme la signature d'une classe, puisqu'elle décrit les champs publics de cette classe. Une classe _implements_ une `interface` avec le mot-clé `implments`.

Sa syntaxe est très proche de celle d'une classe, à ceci près que les méthodes apparaissent sous forme de signatures sans corps :

```haxe
interface Language {
  private var languageName:String;

  public function speak():String;
}

class FrenchSpeaker implements Language {
  var languageName = "French";

  public function speak():String {
    return "Bonjour!";
  }
}
```

Les champs que l'on implémente depuis une interface **doivent** toujours utiliser le même modificateur de visibilité. Par exemple, si la variable `a` est `public` dans une interface, son implémentation doit aussi être `public`.
