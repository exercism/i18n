# Introduction aux tableaux

Bash propose deux types de paramètres : les valeurs « scalaires » et les tableaux.
Une valeur scalaire peut être une _string_ ou un nombre ; elle représente une seule « chose ».

La plupart du temps, les valeurs scalaires suffisent à contenir les données.
Mais parfois, on a besoin de stocker un tableau de valeurs scalaires.
Dans ce cas, tu utiliseras un _tableau_.

Il existe deux types de tableaux :

* Les tableaux à indices numériques associent une clé entière à une valeur de type _string_.
  (D'autres langages parlent peut-être de « liste » ou de « séquence ».)
* Les tableaux associatifs associent une clé de type _string_ à une valeur de type _string_.
  (D'autres langages parlent peut-être de « map » ou de « dictionnaire ».)

Les premières sections de ce document portent sur les tableaux à indices numériques (appelés simplement « tableaux » par la suite).
Les détails sur les tableaux associatifs arrivent à la fin.

~~~~exercism/caution
Les tableaux Bash ne peuvent stocker que des valeurs scalaires.
Il est impossible de créer un tableau à deux dimensions (un tableau de tableaux).
~~~~

## Déclare et initialise une variable tableau

Pour initialiser un tableau, il suffit d'affecter une liste d'éléments entre parenthèses (éventuellement vide) à une variable.

```bash
myarray=("one" "two" "three")
```

Comme pour toute affectation de variable, il ne doit y avoir aucun espace autour du signe égal.

Remarque qu'aucune virgule ne sépare les éléments ; c'est une liste de _strings_ dont les éléments sont séparés par des espaces.

En fait, la quantité d'espaces à l'intérieur des parenthèses est totalement arbitraire.
Les retours à la ligne sont autorisés ; utilises-en autant que tu veux pour améliorer la lisibilité.

```bash
myarray=(
    "first element"
    "second element"
    "this is the last element"
)
```

Affecter une liste de _strings_ à une variable tableau de cette manière place la première _string_ à l'indice zéro, la suivante à l'indice un, la suivante à l'indice deux, et ainsi de suite.

Il est possible d'initialiser un « tableau clairsemé » en précisant les indices dont tu as besoin.

```bash
raindrops=([3]="Pling" [5]="Plang [7]="Plong")
```

~~~~exercism/note
Pour le répéter : les indices de tableau commencent à zéro.
Cet extrait affiche « true » :

```bash
myarray=("one" "two" "three")
[[ "${myarray[0]}" == "one" ]] && echo true || echo false
```
~~~~

Tu peux utiliser la commande `declare` (ou `local` à l'intérieur d'une fonction) pour indiquer qu'une variable contiendra un tableau.

```bash
declare -a myarray
```

Il est plus idiomatique d'affecter directement une liste entre parenthèses (éventuellement vide) pour initialiser la variable.

## Accède aux éléments d'un tableau

Comme tu l'as vu dans la note ci-dessus, la syntaxe pour accéder à un élément d'un tableau est `${myarray[$index]}`.
L'indice est indiqué entre crochets.
Les accolades sont obligatoires.

~~~~exercism/note
Pour les tableaux à indices numériques, l'indice est une expression arithmétique.
Le manuel de Bash [l'indique][arithmetic] :

> Dans une expression arithmétique, les variables du shell peuvent également être référencées par leur nom, sans utiliser la syntaxe d'expansion de paramètre.

Cela signifie que le `$` n'est pas nécessaire pour l'expansion de variables « simples ».
Tu peux accéder aux éléments comme ceci, ce qui est un peu plus lisible :

```bash
i=5
echo "${myarray[i]}"
# ..............^
```

[arithmetic]: https://www.gnu.org/software/bash/manual/bash.html#Shell-Arithmetic
~~~~

Si l'indice donné n'existe pas dans le tableau, le résultat de l'expansion est une _string_ vide.

## Affecte une valeur à un tableau

Pour affecter une valeur à une entrée précise d'un tableau, utilise cette syntaxe :

```bash
myarray[10]="hello"
```

Pour _ajouter_ un élément à un tableau, utilise l'opérateur d'affectation par concaténation `+=`, et mets des parenthèses :

```bash
myarray+=("new element 1" "new element 2")
```

## Parcours un tableau

Tu auras généralement besoin de parcourir les _valeurs_ d'un tableau.
Utilise une boucle for (que tu as vue dans le concept [Boucles][looping]) :

```bash
myarray=("one" "two" "three")
for value in "${myarray[@]}"; do
    echo "$value"
done
```

Remarque la syntaxe spéciale pour l'expansion du tableau : `"${myarray[@]}"`
Cette forme d'expansion de paramètre substitue les valeurs du tableau sous forme de mots séparés.
Elle est en quelque sorte équivalente à :

```bash
for value in "${myarray[0]}" "${myarray[1]}" ... "${myarray[n]}"
```

La forme `"${myarray[@]}"` fonctionne avec les tableaux clairsemés : elle ne développe que les valeurs définies.

Cette expansion spéciale, où l'indice est une arobase (`@`), n'est spéciale qu'entre guillemets doubles.

#### Autres expansions de paramètres particulières

Voici encore deux ou trois éléments de syntaxe spéciale dont on a besoin pour parcourir un tableau.
Ils sont décrits dans le manuel à la section [l'expansion des paramètres du shell][man-expn].

Pour connaître la _longueur_ d'un tableau, utilise `${#myarray[@]}`, avec un `#` devant le nom.
La « longueur » d'un tableau désigne le nombre d'éléments qu'il contient.

Pour obtenir la liste des _indices_ d'un tableau, utilise `"${!myarray[@]}"`, avec un `!` devant le nom et l'expansion entre guillemets doubles.
Pour les tableaux à indices numériques, les indices sont listés dans l'ordre numérique.

### Parcours les indices d'un tableau

Il arrive qu'on ait besoin de l'indice en plus de la valeur.
Il y a plusieurs façons de faire.

1. Quand tu sais que les indices forment une suite ininterrompue, tu peux utiliser une boucle for _arithmétique_.

   ```bash
   for ((i = 0; i < ${#myarray[@]}; i++)); do
       echo "$i -> ${myarray[i]}"
   done
   ```

   Remarque la syntaxe `${#myarray[@]}`, avec le caractère `#` devant le nom du tableau.
   Comme les tableaux utilisent une indexation à partir de zéro, le dernier indice du tableau vaut la longueur du tableau moins un.

2. Quand le tableau est clairsemé, tu peux utiliser cette forme :

   ```bash
   for index in "${!raindrops[@]}"; do
       echo "$index -> ${raindrops[index]}"
   done
   ```

   Remarque la syntaxe `${!myarray[@]}`, avec le caractère `!` devant le nom du tableau.

## Inspecte un tableau

Si tu veux examiner le contenu d'un tableau, utilise la commande `declare` avec l'option `-p` :

```bash
a=("the 'first' element"
   second
   third
   'the "last" element')
declare -p a
```

Cela affiche le contenu avec la mise entre guillemets canonique du shell.

```bash
declare -a a=([0]="the 'first' element" [1]="second" [2]="third" [3]="the \"last\" element")
```

## Les tableaux associatifs

Pour le répéter, les tableaux associatifs utilisent des _strings_ comme indices, et non des nombres.
Tout ce qui précède s'applique aussi aux tableaux associatifs, avec quelques petites différences.
En général, on parle de « clé » et non d'« indice » : les tableaux associatifs associent des clés à des valeurs.

### Déclare un tableau associatif

Contrairement aux tableaux à indices numériques, les tableaux associatifs **doivent** être déclarés.
Utilise l'option `-A` de `declare` (ou `local` dans une fonction) :

```bash
declare -A mymap

myfunc() {
    local -A my_local_map
    # ...
}
```

### Initialise un tableau associatif

Les paires clé-valeur sont indiquées à l'intérieur de la liste entre parenthèses :

```bash
mymap=([first]=foo [second]=bar [third]=baz)
declare -p mymap
```

Cela affiche :

```
declare -A mymap=([second]="bar" [first]="foo" [third]="baz")
```

~~~~exercism/note
Sache que les tableaux associatifs ne sont **pas ordonnés**.
~~~~

La déclaration et l'initialisation peuvent tenir sur une seule ligne.

```bash
declare -A mymap=([first]=foo [second]=bar [third]=baz)
```

Dans les versions récentes de Bash, l'initialisation peut utiliser une liste `(key value key value ...)`.

```bash
declare -A mymap=(first foo second bar third baz)
```

### Accède aux valeurs

La même syntaxe que précédemment sert à accéder aux éléments : `${mymap[$key]}`.

Les clés d'un tableau associatif ne sont pas évaluées dans un contexte arithmétique.
La syntaxe habituelle d'expansion de paramètre est nécessaire.

### Affecte une valeur à un tableau associatif

L'affectation utilise la même syntaxe que précédemment :

```bash
mymap[$key]="$value"
```

### Parcours

Tu peux utiliser une boucle `for value in "${mymap[@]}"` pour parcourir le tableau.
Cependant, tu veux généralement aussi récupérer la clé en même temps que la valeur.

Utilise la syntaxe `"${!mymap[@]}"` que l'on a vue plus haut.

```bash
for key in "${!mymap[@]}"; do
    echo "$key -> ${mymap[$key]}"
done
```

Cela affiche

```
second -> bar
first -> foo
third -> baz
```

Pour insister encore une fois, les clés n'ont aucun ordre défini.
