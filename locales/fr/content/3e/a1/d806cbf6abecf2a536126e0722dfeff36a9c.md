# Introduction

Une `string` en C# est un objet qui représente une chaîne de caractères immuable, c'est-à-dire une séquence de caractères Unicode (lettres, chiffres, ponctuation, etc.). Les guillemets doubles sont utilisés pour définir une instance de `string` :

```csharp
string fruit = "Apple";
```

On manipule les _strings_ en appelant les méthodes de la _string_. Une fois qu'une _string_ a été construite, sa valeur ne peut plus jamais changer. Toutes les méthodes qui semblent modifier une _string_ renvoient en réalité une nouvelle _string_.

On peut concaténer (ajouter) plusieurs _strings_ ensemble. La façon la plus simple d'y parvenir est d'utiliser l'opérateur `+`.

```csharp
string name = "Jane";
"Hello " + name + "!";
// => "Hello Jane!"
```

Pour tout formatage de _string_ plus complexe qu'une simple concaténation, l'interpolation de _strings_ est préférée. Pour utiliser l'interpolation dans une _string_, on la fait précéder du symbole dollar (`$`). Ensuite, on peut utiliser des accolades (`{}`) pour accéder aux variables à l'intérieur de la _string_.

```csharp
string name = "Jane";
$"Hello {name}!";
// => "Hello Jane!"
```
