# Introduction

Un **word** est le nom que Factor donne à une fonction. Ce concept s'appuie sur la pile de données présentée dans `basics` et porte sur la définition de tes propres words : faire de l'arithmétique, nommer des valeurs fixes et composer des words à partir d'autres words.

Une définition commence par `:`, donne un effet de pile, puis le corps, puis `;`. Le compilateur vérifie que le corps correspond à l'effet déclaré :

```factor
: square ( x -- x*x ) dup * ;

4 square .    ! => 16
```

Les words arithmétiques sur les entiers `+`, `-` et `*` dépilent chacun deux nombres et empilent le résultat. Ils appartiennent au vocabulaire `math`, donc un fichier qui les utilise doit faire figurer `math` sur sa ligne `USING:`. Le sommet de la pile est l'opérande de droite :

```factor
2 3 + .    ! => 5
8 3 - .    ! => 5    (8 - 3, not 3 - 8)
2 3 * .    ! => 6
```

`CONSTANT:` nomme une valeur fixe. Une constante est elle-même un word, et l'appeler empile la valeur :

```factor
CONSTANT: pi 3

pi pi * .    ! => 9
```

Le corps d'un word peut appeler n'importe quel word déjà dans la portée, y compris ceux que tu as définis plus haut dans le même fichier :

```factor
: double    ( x -- 2x ) 2 * ;
: quadruple ( x -- 4x ) double double ;

5 quadruple .    ! => 20
```

Un `?` en fin de sortie est la convention pour « un booléen », et les words comme les constantes utilisent tous les deux `lowercase-kebab-case`.
