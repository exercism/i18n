## Introduction

Un pointeur est une variable ou une constante dont la valeur est l'adresse d'une autre variable ou constante.
Les pointeurs sont une fonctionnalité puissante et potentiellement dangereuse du C.
Il peut être difficile de comprendre les pointeurs.

Les variables et les constantes stockent leur valeur dans un emplacement mémoire.
Cet emplacement en mémoire est appelé l'adresse de la variable ou de la constante.

Pour obtenir l'adresse d'une variable, on utilise l'opérateur d'adresse, à savoir `&`.
```c
int i = 5;
int *i_address = &i;
```

Un type suivi d'un `*` puis d'un identifiant est la façon de déclarer un pointeur vers une variable de ce type.
Le `*` est appelé l'opérateur d'indirection, car il fait référence indirectement à la valeur dont le pointeur détient l'adresse.

Quand on crée un tableau comme ceci

```c
int my_ints[] = {1, 2};
```

La valeur de `my_ints` est en fait son adresse, qui se trouve aussi être la même que l'adresse de son premier élément.
L'adresse de son deuxième élément sera l'adresse du premier élément plus la taille d'un `int` sur le système.

C'est pourquoi les pointeurs sont déclarés avec un certain type.
Si un pointeur ne savait pas vers quel type il pointe, il ne saurait pas de combien d'octets avancer lorsqu'on lui ajoute `1`.
Ajouter `1` à un pointeur ne signifie pas nécessairement qu'on ajoute un octet à l'adresse.
Cela signifie qu'on ajoute `1` fois la longueur de son type en octets.
