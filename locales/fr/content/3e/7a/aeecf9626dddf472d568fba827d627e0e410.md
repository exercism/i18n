# Instructions (suite)

## Registres

| Registre | Utilisation | Type        | Description                                                                                  |
| -------- | ----------- | ----------- | -------------------------------------------------------------------------------------------- |
| `$a0`    | entrée      | entier      | côté a                                                                                       |
| `$a1`    | entrée      | entier      | côté b                                                                                       |
| `$a2`    | entrée      | entier      | côté c                                                                                       |
| `$v0`    | sortie      | entier      | type de triangle (`0` = scalène, `1` = isocèle, `2` = équilatéral, `3` = invalide)           |
| `$t0-9`  | temporaire  | quelconque  | utilisé pour le stockage temporaire                                                          |
