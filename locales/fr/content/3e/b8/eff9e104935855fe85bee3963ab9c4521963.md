# Indices

## Général

- Dans cet exercice, toutes les adresses mémoire sont alignées sur 16 octets, donc les déplacements alignés (`movdqa` pour les entiers, `movaps` pour les flottants) sont appropriés.
  Une adresse alignée peut aussi être utilisée directement comme opérande source en mémoire.

## 1. Convertis une image dans l'ordre d'affichage

- Dans chaque pixel de 4 octets, la conversion échange l'octet au décalage `0` (rouge) avec l'octet au décalage `2` (bleu), et laisse les décalages `1` (vert) et `3` (alpha) en place.
  Le même schéma se répète sur les quatre pixels.
- On peut utiliser une [permutation][pshufb] pour réorganiser les octets sur place selon les indices d'un vecteur de contrôle.
- Le vecteur de contrôle peut être défini en mémoire.
- Il peut y avoir plusieurs blocs, et chaque bloc fait 16 octets.

## 2. Remplis une zone d'une seule couleur

- La couleur est un seul pixel de 4 octets.
  Pour la stocker 16 octets à la fois, il faut d'abord la [diffuser][pshufd] sur les quatre voies d'un registre `xmm`.
- Un pixel de 4 octets doit d'abord être [déplacé][pinsrd] vers un registre `xmm` avant d'être diffusé.
- Chaque bloc rempli est identique, donc le registre rempli peut être créé une seule fois puis réutilisé.
- Il peut y avoir plusieurs blocs, et chaque bloc fait 16 octets.

## 3. Entrelace deux lignes de balayage

- Les instructions de [dépaquetage][unpack] permettent d'entrelacer les octets de deux opérandes.
- Les deux instructions de dépaquetage prennent le premier octet de chaque paire dans l'opérande destination, et le second dans l'opérande source.

## 4. Compacte une ligne éclaircie

- Les instructions de [compactage][pack] permettent de réduire la largeur des voies, tout en les écrêtant.
- Les instructions de compactage prennent les voies basses dans l'opérande destination, et les voies hautes dans l'opérande source.

## 5. Sépare les coordonnées en X et Y

- Les [permutations en virgule flottante][shufps] permettent de sélectionner et de réorganiser les voies de deux opérandes.
- Les coordonnées `x` se trouvent dans les voies paires (`0` et `2`) de chaque entrée, et les coordonnées `y` dans les voies impaires (`1` et `3`).
