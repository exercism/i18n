# Tests

Si tu as téléchargé un exercice avec la CLI, tu devrais voir un fichier Uiua portant le nom de l'exercice ainsi qu'un fichier `tests.ua`.
Ce fichier contient tous les cas de test, qui correspondent à ceux exécutés par l'exécuteur de tests lorsque tu envoies ta solution.
N'hésite pas à ajouter des cas de test supplémentaires pour expérimenter.
Cependant, modifier les tests n'a aucun effet sur le processus de l'exécuteur de tests en ligne.

## Tests en local

Pour exécuter les tests d'un exercice, ouvre un terminal dans le répertoire de l'exercice et lance la commande `uiua test tests.ua`.

Par exemple, la sortie d'un exercice `hello-world` non modifié peut ressembler à ceci :

```bash
$ uiua test tests.ua
Error: Goodbye, Mars!
  at tests.ua:3:1
3 | ⍤⤙≍ "Hello, World!" Hello
    ─
Test failed
```

La ligne `Error` affiche la sortie réelle de ton code.
Le numéro de ligne indique l'emplacement du résultat attendu dans `tests.ua`.
Une solution correcte produit :

```bash
$ uiua test tests.ua
Test passed
```
