# Instructions

Tu as plusieurs pizzerias dans ta ville et tu veux écrire une application web qui te permettra de comparer deux pizzas différentes pour savoir laquelle te donnera la plus grande part.

## 1. Écris une fonction qui calcule la taille des parts et renvoie nil pour les entrées invalides.

Implémente la fonction `sliceSize(diameter: Double?, slices: Int?) -> Double?` qui, à partir du diamètre d'une pizza et du nombre de parts par pizza, renvoie l'aire d'une part.
Pour un diamètre négatif ou un nombre de parts inférieur à 1, renvoie `nil`, car une pizza avec un diamètre négatif n'existe pas et il est impossible de découper une pizza en moins d'une part.
Si l'un des deux paramètres est `nil`, renvoie aussi `nil`.

```swift
sliceSize(diameter: 16, slices: 12)
// Returns 16.75516081914556
sliceSize(diameter: nil, slices: 8)
// Returns nil
```

## 2. Traite les entrées de ton application web pour déterminer la part la plus grande.

Ton application web passera quatre _strings_ à ta fonction `biggestSlice(diameterA: String, slicesA: String, diameterB: String, slicesB: String) -> String`.
Les deux premières _strings_ sont respectivement le diamètre et le nombre de parts de la première pizza, et les deux suivantes sont respectivement le diamètre et le nombre de parts de la seconde pizza.

Implémente `biggestSlice` pour qu'elle essaie de convertir le diamètre et le nombre de parts de chaque pizza respectivement en un `Double` et un `Int`.
Si ces deux valeurs peuvent être obtenues à partir des _strings_, utilise ta première fonction pour calculer l'aire ; sinon, l'aire de cette part est `nil`.
Une fois les aires des deux parts obtenues, compare-les en suivant les règles suivantes :

1. Si l'aire de la part A est un `Double` et que celle de la part B est `nil`, renvoie « Slice A is bigger ». Si c'est l'inverse, renvoie « Slice B is bigger ».
2. Si les deux aires sont des `Double`, renvoie « Slice A is bigger » ou « Slice B is bigger » selon la part dont l'aire est la plus grande.
3. Si les deux aires sont `nil`, ou si ce sont deux `Double` égaux, renvoie « Neither slice is bigger ».

~~~~exercism/note
Même si les entrées donnent une aire de part égale à 0, la part reste considérée comme valide et doit être vue comme plus grande qu'une part dont l'aire vaut `nil`.
~~~~

```swift
biggestSlice(diameterA: "10", slicesA: "6", diameterB: "14", slicesB: "12")
// Returns "Slice A is bigger"
biggestSlice(diameterA: "10", slicesA: "6", diameterB: "12", slicesB: "8")
// Returns "Slice B is bigger"
biggestSlice(diameterA: "Pepperoni", slicesA: "6", diameterB: "Sausage", slicesB: "12")
// Returns "Neither slice is bigger"
```
