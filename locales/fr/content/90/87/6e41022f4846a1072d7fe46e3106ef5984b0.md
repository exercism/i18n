# Indices

## 1. Amène les humains dans le monde de Troie

- Le cœur de cet exercice, c'est l'utilisation de `unique_ptr` et de `shared_ptr`. Quel type de pointeur intelligent faut-il utiliser pour chacune des variables `human` ?
- Les `artifacts` ne sont pas partagés, mais les `powers` sont nécessaires pour suivre les personnes influencées.
- Le pointeur `possession` doit être unique, tandis que les pointeurs de pouvoir doivent être partagés.

## 2. Apporte les artefacts à Troie

- Tu dois créer un pointeur intelligent et l'affecter à la variable `possession`.
- Utilise des _références_ pour modifier l'objet en dehors de la fonction.
- Jette un œil à [`std::make_unique`][make_unique] pour quelques indices.
- Le type de l'objet cible du pointeur doit être placé entre chevrons, puis de nouveau entre parenthèses pour définir l'objet.
- Voici un exemple complet : `variable = std::make_unique<int>(int{23});`

## 3. Rends les objets échangeables

- Tu peux parcourir la [référence de unique_ptr][unique_ptr] pour trouver une fonction qui convient.
- Penses-tu que `std::swap` peut t'aider ?
