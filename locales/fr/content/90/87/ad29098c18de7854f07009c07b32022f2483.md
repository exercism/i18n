# Introduction

## Opérateurs ternaires

L'_opérateur ternaire_ est une alternative légère et compacte aux instructions _if/else_ simples.
Généralement utilisé dans (mais pas limité à) les instructions de retour, il ne nécessite qu'une seule ligne pour prendre la décision, renvoyant la valeur de gauche si l'expression est `true` et la valeur de droite si elle est `false`, comme suit :

```java
boolean expr = 0 != 200;

// Ternary statement
int value = expr ? 22 : 33;
// => 22
```

Beaucoup d'expressions _if/else_ simples peuvent être simplifiées à l'aide d'_opérateurs ternaires_.
