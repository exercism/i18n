# Instructions

L'ESA (Exercism Space Agency) est en pleine préparation d'une nouvelle mission vers [Phobos][phobos], une lune de Mars.
L'objectif de la mission est de poser une sonde à la surface de Phobos et de renvoyer des données sur cette surface.
L'ESA a demandé ton aide pour construire l'ordinateur de navigation de la sonde.
L'ordinateur de navigation dispose d'une mémoire limitée, on doit donc garder une utilisation de la mémoire aussi faible que possible.
C'est pourquoi on doit utiliser les types de données adaptés.

## 1. Constantes de navigation

L'ordinateur de navigation a besoin de connaître la distance entre certains objets de l'espace pour effectuer les bons calculs ; cette distance se mesure en km.

Définis les constantes suivantes :

- `NEPTUNE_DISTANCE` avec la valeur `4_400_000_000`, qui doit être stockée dans un `Int64`
- `MARS_DISTANCE` avec la valeur `227_940_000`, qui doit être stockée dans un `Int32`
- `ATMOSPHERE_DISTANCE` avec la valeur `10_000`, qui doit être stockée dans un `Int16`

## 2. Analyse correcte de l'aire

L'ordinateur de navigation a besoin de connaître l'aire de certains objets de l'espace pour effectuer les bons calculs.
Une aire ne peut **PAS** être négative.
Les ingénieurs avaient prévu que le programme génère une erreur de dépassement lorsque l'aire était négative.
Cependant, ils ont oublié de convertir l'entier signé en entier non signé.

Par conséquent, les ingénieurs aimeraient un programme qui convertit un entier signé en entier non signé.

Implémente la méthode `Navigation#correct_area_analysis` qui prend un `measurement` en argument et renvoie l'aire sous la forme d'un entier non signé de 32 bits.

~~~~exercism/note
L'aire donnée tiendra toujours dans un entier non signé de 32 bits.
~~~~

```crystal
measurement = 52554
measurement.class
# => Int32

Navigation.new.correct_area_analysis(measurement)
# => 52554

Navigation.new.correct_area_analysis(measurement).class
# => UInt32
```

## 3. Calcule la vitesse

L'ordinateur de navigation a besoin de connaître la vitesse de la sonde.
La vitesse se mesure en m/s.

Pour calculer la vitesse, on doit connaître la distance parcourue et le temps mis pour parcourir cette distance.
Il suffit alors de prendre la distance et de la diviser par le temps.

La vitesse peut manquer de précision et ne sera jamais un nombre considérable.
On peut donc utiliser un `Float32`.

Implémente la méthode `Navigation#calculate_velocity` qui prend `distance` et `time` en arguments et renvoie la vitesse sous la forme d'un `Float` de 32 bits.

```crystal
distance = 52554
time = 2.5

Navigation.new.calculate_velocity(distance, time)
# => 21021.6

Navigation.new.calculate_velocity(distance, time).class
# => Float32
```
