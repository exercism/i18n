# Introduction

Un `array` en F# est une collection mutable de zéro valeur ou plus, dont la longueur est fixe. Cela signifie qu'une fois un tableau créé, sa taille ne peut plus changer, mais que ses valeurs, elles, peuvent être modifiées. Toutes les valeurs d'un tableau doivent avoir le même type. On peut définir un tableau comme ceci :

```fsharp
let empty = [| |]
let emptyAlternative = Array.empty

let singleValue = [| 5 |]
let singleValueAlternative = Array.singleton 5

let threeValues = [| "a"; "b"; "c" |]
```

On peut affecter des éléments à un tableau ou les récupérer à l'aide d'un indice. Les tableaux F# sont indexés à partir de zéro, ce qui signifie que l'indice du premier élément est toujours zéro :

```fsharp
let numbers = [| 2; 3; 5 |]

// Update value in array
numbers[2] <- 9

// Read value from array
numbers[2]
// => 9
```

On manipule les tableaux soit avec les fonctions et les opérateurs définis dans le module `Array`, soit manuellement à l'aide des critères spéciaux avec le modèle _tableau_ :

```fsharp
let describe array =
    match array with
    | [| |] -> "Empty"
    | [| 1; 2; three |] -> sprintf "1, 2, %d" three
    | _ -> "Other"

describe [| |]         // => "Empty"
describe [| 1; 2; 4 |] // => "1, 2, 4"
describe [| 5; 7; 9 |] // => "Other"
```

Tu peux aussi _ignorer_ une valeur lors des critères spéciaux ; quand tu ne te soucies _pas_ d'une valeur dans un cas précis (autrement dit, que tu ne vas pas _utiliser_ cette valeur), tu peux utiliser un trait de soulignement (`'_'`) pour le signaler :

```fsharp
let describe array =
    match array with
    | [| |] -> "Empty array"
    | [| x |] -> "Array with one item"
    | [| _; y |] -> "Array with two items (first item ignored)"
    | _ -> "Array with many items (all items ignored)"

describe [| |]          // => "Empty array"
describe [| 1 |]        // => "Array with one item"
describe [| 5; 7 |]     // => "Array with two items (first item ignored)"
describe [| 5; 7; 9 |]  // => "Array with many items (all items ignored)"
```

Le `'_'` seul doit toujours venir _en dernier_ lors des critères spéciaux : toute valeur qui _ne correspond pas_ aux autres cas sera traitée par ce cas.
