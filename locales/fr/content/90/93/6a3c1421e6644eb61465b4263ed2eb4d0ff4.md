# À propos

Un [enregistrement][records] est un ensemble de champs (qui peuvent être de types différents) qui vont ensemble. Pour [définir un enregistrement][define], on utilise le mot-clé `type`. Les champs d'un enregistrement se définissent entre les caractères `{` et `}`, et chaque champ possède un nom _et_ un type.

```fsharp
type Address =
    { Street: string
      HouseNumber: int }
```

Pour [créer un enregistrement][create], indique le nom des champs et affecte-leur une valeur entre les caractères `{` et `}`. Lors de la création d'un enregistrement, une valeur doit être affectée à chacun de ses champs. Les champs peuvent être indiqués dans n'importe quel ordre : ils ne doivent pas suivre l'ordre de la définition du type d'enregistrement. Pour accéder aux valeurs des champs d'une instance d'enregistrement, on utilise la notation pointée.

```fsharp
let oldAddress: Address =
    { Street = "Main Street"
      HouseNumber = 17 }

oldAddress.Street      // => "Main Street"
oldAddress.HouseNumber // 17
```

Lorsqu'on définit ou qu'on crée un enregistrement, chaque champ doit soit se trouver sur une ligne séparée, soit être séparé par des points-virgules (`;`) lorsqu'il se trouve sur une même ligne :

```fsharp
type Address = { Street: string; HouseNumber: int }

let oldAddress: Address = { Street = "Main Street"; HouseNumber = 17 }
```

Si les noms des champs d'un enregistrement sont uniques, les annotations de type sont facultatives, car le compilateur pourra déduire le type automatiquement. Si la combinaison des noms de champs n'est _pas_ unique, tu peux aider le compilateur à choisir le bon enregistrement, soit en utilisant un type explicite pour la liaison de l'enregistrement, soit en préfixant un ou plusieurs champs par le type d'enregistrement :

```fsharp
type Boat = { Weight: int; Length: int }
type Car = { Weight: int; Length: int }

// Let compiler infer type. As there are multiple matching record types,
// the last matching type is used (Car)
let typeEqualsLastMatch = { Weight = 5000; Length = 15 }

// Use type annotation on binding to force type to Boat
let typeAnnotation: Boat = { Weight = 5000; Length = 15 }

// Use fully qualified name for field to force type to Boat
let fullyQualifiedField = { Boat.Weight = 5000; Length = 15}
```

Les enregistrements étant immuables, une fois qu'un enregistrement est construit, les valeurs de ses champs ne peuvent plus jamais changer. Si tu veux modifier les valeurs d'un enregistrement, le mot-clé `with` te permet de [créer une copie d'un enregistrement existant, mais avec de nouvelles valeurs pour un ou plusieurs champs][create].

```fsharp
// Copy the old address but change the house number
let newAddress = { oldAddress with HouseNumber = 86 }
newAddress.Street      // => "Main Street"
newAddress.HouseNumber // => 86
```

Les enregistrements ont une [_égalité structurelle_][equality], ce qui signifie que deux instances d'un même enregistrement avec des valeurs identiques sont équivalentes :

```fsharp
let address1 = { Street = "Main Street"; HouseNumber = 17 }
let address2 = { Street = "Main Street"; HouseNumber = 17 }
let address3 = { Street = "Broadway"; HouseNumber = 17 }

address1 = address2 // => true
address1 = address3 // => false
```

En plus de permettre d'accéder aux champs d'un enregistrement par la notation pointée, les enregistrements peuvent aussi être _déconstruits_ dans des liaisons et dans des correspondances de motifs grâce au [motif d'enregistrement][record-patterns] :

```fsharp
let myAddress = { Street = "Broadway"; HouseNumber = 123 }
let { Street = myStreet; HouseNumber = myHouseNumber } = myAddress

match myAddress with
| { HouseNumber = 1 } -> printfn "First house"
| { HouseNumber = houseNumber; Street = street } -> printfn "House number %d on %s" houseNumber street
// => "House number 123 on Broadway
```
