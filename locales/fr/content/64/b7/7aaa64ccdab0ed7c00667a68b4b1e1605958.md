# Introduction

## Le hasard

En Elixir, pour choisir un élément au hasard dans une structure de données énumérable (par exemple un tableau, un intervalle), on utilise `Enum.random`. Cette fonction choisit un seul élément, chaque élément ayant la même probabilité d'être choisi.

Elixir ne dispose pas de ses propres fonctions pour choisir un nombre à virgule flottante au hasard. Pour cela, on doit utiliser Erlang directement.

## Les bibliothèques Erlang

Le code Elixir s'exécute dans la machine virtuelle BEAM. BEAM fait partie de l'Erlang Run-Time System. Inspiré par Erlang et partageant son environnement d'exécution, Elixir offre une excellente interopérabilité avec les bibliothèques Erlang. Cela signifie que les développeurs Elixir peuvent utiliser des bibliothèques Erlang depuis leur code Elixir. En fait, écrire des bibliothèques Elixir pour des fonctionnalités déjà fournies par les bibliothèques Erlang est déconseillé dans la communauté Elixir.

Par conséquent, certaines fonctionnalités, comme les opérations mathématiques ou les fonctions de minuterie, ne sont disponibles en Elixir que via Erlang.

La bibliothèque standard d'Erlang est utilisable dans notre code Elixir sans aucune étape supplémentaire.

On appelle les fonctions Erlang de la même manière que les fonctions Elixir, à une petite différence près. Les noms de modules Erlang sont des atomes en `snake_case`. Par exemple, pour appeler la fonction `pi/0` Erlang du module `math`, on écrirait :

```elixir
:math.pi()
# => 3.141592653589793
```

Les fonctions Erlang les plus couramment utilisées qui n'ont pas d'équivalent en Elixir sont :

- `:timer.sleep/1`, qui suspend un processus pendant le nombre de millisecondes donné.
- `:rand.uniform/0`, qui génère un nombre à virgule flottante `x` au hasard, où `0.0 <= x < 1.0`.
- `:io_lib.format/2`, qui fournit un formatage de _string_ à la C (à l'aide de séquences de contrôle). Avec cette fonction, on pourrait par exemple afficher un entier dans n'importe quelle base entre 2 et 36, ou formater un nombre à virgule flottante avec la précision souhaitée. Note que cette fonction, comme beaucoup de fonctions Erlang, renvoie une _charlist_.
- Le module `math`, qui fournit des fonctions mathématiques telles que `sin/1`, `cos/1`, `log2/1`, `log10/1`, `pow/2`, et bien d'autres.

Pour découvrir la bibliothèque standard d'Erlang, explore le [manuel de référence STDLIB][erl-stdlib-ref].

[erl-stdlib-ref]: https://www.erlang.org/doc/apps/stdlib/index.html
