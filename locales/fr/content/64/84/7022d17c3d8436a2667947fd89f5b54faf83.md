# Classes abstraites

Un spectacle de cirque, c'est une liste de numéros. La jonglerie, le trapèze et les acrobaties sont des choses différentes, dont le contenu diffère, mais la personne qui établit l'ordre de passage n'a besoin que de deux informations pour chacun : comment il s'appelle et combien de temps il dure.

Une **classe abstraite** décrit exactement cela, et rien de plus.

```sather
abstract class $ACT is
   name : STR;
   minutes : INT;
end; -- abstract class $ACT
```

Son nom commence par `$`. Elle énumère des routines sans corps : uniquement des signatures, chacune se terminant par un point-virgule. On ne peut rien créer à partir d'elle : il n'y a ni `create` ni `new`.

## Conformité

Une vraie classe promet d'être un `$ACT` en le nommant après le signe `<` :

```sather
class JUGGLING < $ACT is

   create : SAME is return new; end;

   name : STR is return "Juggling"; end;

   minutes : INT is return 5; end;

end; -- class JUGGLING
```

`<` se lit « est un ». La classe doit fournir chaque routine listée par la classe abstraite, avec les mêmes arguments et le même type de retour. En oublier une est une erreur de compilation, pas une surprise au moment de l'exécution.

Une classe peut y ajouter tout ce qu'elle veut. `TRAPEZE` peut avoir une hauteur qu'aucun autre numéro ne possède ; la classe abstraite ne le sait pas et ne s'en soucie pas.

## Utiliser le type

`$ACT` est un type, donc on peut déclarer n'importe quoi avec lui :

```sather
   acts : ARRAY{$ACT} := |#JUGGLING, #TRAPEZE(4), #TUMBLING|;
```

Ce tableau contient à la fois des objets de trois classes différentes, ce qu'un `ARRAY{JUGGLING}` ne pourrait pas faire.

## Dispatch

```sather
   loop
      total := total + acts.elt!.minutes;
   end;
```

`acts.elt!` est un `$ACT`. Lequel des `minutes` s'exécute est décidé au moment où la ligne s'exécute, en fonction de ce qu'est réellement l'objet : `JUGGLING::minutes` pour la jonglerie, `TRAPEZE::minutes` pour le trapèze. Ce choix s'appelle le ***dispatch***.

La routine qui effectue l'addition ne demande jamais quel genre de numéro elle manipule. Ajouter un quatrième type de numéro revient à écrire une nouvelle classe et à ne rien changer d'autre, et c'est bien là toute la raison de faire les choses ainsi.
