# Ajout aux instructions

## Format de sortie

Affiche la séquence de protéines sous la forme d'une _string_ terminée par un caractère nul, avec un caractère de nouvelle ligne après chaque protéine.

Un exemple de sortie serait `"Methionine\nPhenylalanine\nSerine\n"`

Si l'entrée est invalide, affiche une _string_ vide.

## Registres

| Registre | Utilisation  | Type       | Description                                      |
| -------- | ------------ | ---------- | ------------------------------------------------ |
| `$a0`    | entrée       | adresse    | _string_ d'entrée terminée par un caractère nul  |
| `$a1`    | entrée/sortie | adresse    | _string_ de sortie terminée par un caractère nul |
| `$t0-9`  | temporaire   | quelconque | utilisé pour le stockage temporaire              |
