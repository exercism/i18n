# Instructions

Ta tâche consiste à convertir des descriptions de date de livraison en dates de livraison _réelles_, en fonction du moment où la réunion a commencé.

Il existe deux types de descriptions de date de livraison :

1. Fixes : un ensemble prédéfini de mots.
2. Variables : des mots qui comportent une partie variable, mais qui suivent un ensemble prédéfini de schémas.

## Descriptions de date de livraison fixes

Il existe trois descriptions de date de livraison fixes :

- `"NOW"`
- `"ASAP"` (dès que possible)
- `"EOW"` (fin de semaine)

Le tableau suivant montre comment les traduire :

| Description | Début de la réunion | Date de livraison |
| ----------- | ------------------- | ----------------- |
| `"NOW"`     | -                   | Deux heures après le début de la réunion |
| `"ASAP"`    | Avant 13 h 00       | Aujourd'hui à 17 h 00 |
| `"ASAP"`    | À partir de 13 h 00 | Demain à 13 h 00 |
| `"EOW"`     | Lundi, mardi ou mercredi | Vendredi à 17 h 00 |
| `"EOW"`     | Jeudi ou vendredi   | Dimanche à 20 h 00 |

## Descriptions de date de livraison variables

Il existe deux schémas de description de date de livraison variables :

- `"<N>M"` (le N-ième mois)
- `"Q<N>"` (le N-ième trimestre)

| Description | Début de la réunion | Date de livraison |
| ----------- | ------------------- | ----------------- |
| `"<N>M"`    | Avant le N-ième mois | À 8 h 00 le _premier_ jour ouvré du N-ième mois de cette année |
| `"<N>M"`    | À partir du N-ième mois | À 8 h 00 le _premier_ jour ouvré du N-ième mois de l'année prochaine |
| `"Q<N>"`    | Avant ou dans le N-ième trimestre | À 8 h 00 le _dernier_ jour ouvré du N-ième trimestre de cette année |
| `"Q<N>"`    | Après le N-ième trimestre | À 8 h 00 le _dernier_ jour ouvré du N-ième trimestre de l'année prochaine |

~~~~exercism/note
Un jour ouvré est un lundi, un mardi, un mercredi, un jeudi ou un vendredi.

Une année compte quatre trimestres, chacun composé de trois mois :
1. janvier/février/mars
2. avril/mai/juin
3. juillet/août/septembre
4. octobre/novembre/décembre.
~~~~
