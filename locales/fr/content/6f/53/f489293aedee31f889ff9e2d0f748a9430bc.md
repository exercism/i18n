# Indices

## Général

- Ne te préoccupe pas de la façon dont les arguments sont _dérivés_ : concentre-toi sur la combinaison des arguments pour renvoyer le résultat attendu.

## 0. Définis un état de la machine

- Définis une variable nommée `PowerOn` avec une valeur [booléenne][booleans] vraie.

## 1. Détermine si Pac-Man peut manger un fantôme

- Tu peux utiliser l'[opérateur][logical-operators] `-and` pour combiner les arguments et obtenir un résultat.


## 2. Détermine si Pac-Man marque des points

- Tu peux utiliser l'[opérateur][logical-operators] `-or` pour combiner les arguments et obtenir un résultat.


## 3. Détermine si Pac-Man perd

- Tu peux utiliser l'[opérateur][logical-operators] `-not` pour combiner les arguments et obtenir un résultat.


## 4. Détermine si Pac-Man gagne

- Combine les [opérateurs][logical-operators] précédents pour obtenir le résultat.


## 5. Écris le SYNOPSIS de la condition de victoire

- Écris une courte description dans le bloc de commentaires de la dernière fonction `Win` en utilisant le [mot-clé][keywords] `SYNOPSIS`.
