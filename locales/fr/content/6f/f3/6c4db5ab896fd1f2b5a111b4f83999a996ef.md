# Introduction

## Booléens

En Java, les booléens sont représentés par le type `boolean`, dont les valeurs peuvent être `true` ou `false`.

Java prend en charge trois opérateurs booléens :  

- `!` (PAS) : inverse le booléen  
- `&&` (ET) : prend deux booléens et renvoie `true` s'ils sont tous les deux `true`
- `||` (OU) : renvoie `true` si l'un des deux booléens vaut `true`

### Exemples

```java
!true // => false
!false // => true
true && false // => false
true && true // => true
false || false // => false
false || true // => true
```
