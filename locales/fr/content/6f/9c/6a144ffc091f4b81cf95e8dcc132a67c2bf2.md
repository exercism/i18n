# Introduction

En JavaScript, un tableau est une structure de type liste, sans longueur fixe, qui peut contenir n'importe quel type de primitives ou d'objets, même des types mélangés.

Pour créer un tableau, on place des éléments entre crochets `[]`.
Pour lire une valeur du tableau, on place l'indice entre crochets `[]` après l'identifiant.
Les indices d'un tableau commencent à zéro.

Par exemple :

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers[2];
// => 3
```

Pour récupérer le nombre d'éléments d'un tableau, utilise la propriété `length` :

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.length;
// => 4
```

Pour modifier un élément du tableau, on affecte une valeur à son indice :

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers[0] = 'one';
numbers;
// => ['one', 'two', 3, 'four']
```

## Méthodes

Certaines des [méthodes][mdn-array] disponibles sur chaque objet Array permettent d'ajouter ou de retirer des éléments du tableau.
En voici quelques-unes à garder en tête quand tu travailles sur cet exercice :

### push

On peut _ajouter_ une `value` à la fin d'un tableau avec `.push(value)`.
La méthode renvoie la nouvelle longueur du tableau.

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.push(5); // => 5
numbers;
// => [1, 'two', 3, 'four', 5]
```

### pop

On peut _retirer_ la _dernière_ `value` d'un tableau avec `.pop()`
La méthode renvoie la valeur retirée.
La longueur du tableau diminue du fait de ce changement.

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.pop(); // => four
numbers;
// => [1, 'two', 3]
```

### shift

On peut _retirer_ la _première_ `value` d'un tableau avec `.shift()`
La méthode renvoie la valeur retirée.
La longueur du tableau diminue du fait de ce changement.

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.shift(); // => 1
numbers;
// => ['two', 3, 'four']
```

### unshift

On peut _ajouter_ une `value` au début d'un tableau avec `.unshift(value)`.
La méthode renvoie la nouvelle longueur du tableau.

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.unshift('one'); // => 5
numbers;
// => ['one', 1, 'two', 3, 'four']
```

### splice

On peut _retirer_ une `value` située à un `index` précis d'un tableau avec `.splice(index, 1)`.
La méthode renvoie le ou les éléments retirés.

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.splice(2, 1, 'one'); // => [3]
numbers;
// => [1, 'two', 'one', 'four']
```

~~~exercism/advanced
Ces méthodes sont plus puissantes que ce qui est décrit ici :

- `push` et `unshift` te permettent d'ajouter plusieurs valeurs à la fois, en passant plus d'arguments.
  Ce n'est pas nécessaire pour terminer cet exercice.
- Splice peut retirer plusieurs valeurs en augmentant le second argument.
  Ce n'est pas nécessaire pour terminer cet exercice.
- Splice peut aussi ajouter plusieurs valeurs en les passant comme arguments après le `deleteCount`.
  Cela permet de remplacer des valeurs, ou d'insérer des valeurs au milieu d'un tableau (par exemple en retirant 0 élément).
  Ce n'est pas nécessaire pour terminer cet exercice.
~~~
