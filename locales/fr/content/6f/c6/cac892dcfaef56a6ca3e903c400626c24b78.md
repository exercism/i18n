# Indices

## 1. Crée la table des meilleurs scores

- La table des meilleurs scores doit être une table de hachage.
- On peut créer une table de hachage avec `make-hash-table`.

## 2. Ajoute un joueur à la table

- Pour ajouter une paire clé/valeur à une table de hachage, utilise `(setf (gethash key table) value)`

## 3. Définis le score d'un joueur

- Définir le score d'un joueur est presque identique à ajouter le joueur à la table.
- Pour ajouter une paire clé/valeur à une table de hachage, utilise `(setf (gethash key table) value)`

## 4. Récupère un score depuis la table

- Utilise `gethash` pour récupérer la valeur associée à une clé dans la table de hachage.
- `gethash` prend un troisième argument optionnel : la valeur à utiliser si la clé est introuvable.

## 5. Retire un joueur de la table

- Utilise `remhash` pour retirer une clé de la table.
