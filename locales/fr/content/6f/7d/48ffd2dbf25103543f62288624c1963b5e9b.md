# Introduction

Extrait de [le manuel][man-types]

> jq prend en charge le même ensemble de types de données que JSON : les nombres, les _strings_, les booléens, les tableaux, les objets (qui, en langage JSON, sont des tables de hachage dont les clés sont uniquement des _strings_) et `"null"`.

Concentrons-nous sur les **nombres**.

## Nombres et opérateurs numériques

Tous les nombres, qu'ils soient entiers ou non, sont des nombres à virgule flottante en double précision IEEE754.
Cela nous limite à 53 bits de précision.

Les opérateurs habituels s'utilisent avec les nombres :

- arithmétique : `+`, `-`, `*`, `/`, `%`
- comparaison : `==`, `!=`, `<`, `<=`, `>=`, `>`
- les [fonctions mathématiques][man-math] standard

  Pour les fonctions à une entrée, on envoie la valeur dans la fonction avec un pipe

  ```sh
  $ jq -n '(1 | atan) * 4'
  3.141592653589793
  ```

  Pour les fonctions à deux entrées, la fonction ignore l'entrée et attend les
  entrées sous forme de paramètres (rappel : les paramètres sont séparés par des points-virgules)

  ```sh
  $ jq -n 'pow(2; 10)'
  1024
  ```

  Le point-virgule est le séparateur des arguments de fonction, pas la virgule.

## Autres expressions `jq`

Pour résoudre l'exercice, tu devras connaître les expressions conditionnelles.

### Expressions conditionnelles

`jq` utilise une [expression `if-then-else`][if-then-else] pour les **expressions conditionnelles**.
En tant qu'_expression_, elle s'insère dans un pipeline.

La syntaxe est : `if CONDITION then TRUE_EXPR else FALSE_EXPR end`.

La clause `else` est facultative.

```jq
42 | if . < 33 then "small" else "larger" end
# => "larger"
```

Les conditions supplémentaires utilisent `elif`

```jq
42 | if . < 33 then "small"
     elif . < 67 then "medium"
     else "large"
     end
# => "medium"
```
