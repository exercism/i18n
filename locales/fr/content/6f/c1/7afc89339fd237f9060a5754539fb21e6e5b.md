# Installation

## Prérequis

* Un processeur x86 64 bits
* Un compilateur C moderne
* L'outil de compilation Make
* Le Netwide Assembler (NASM)

Note que ce parcours ne prend en charge que la convention d'appel de l'ABI System V AMD64. Les utilisateurs de Windows devront installer Windows Subsystem for Linux (WSL), ou configurer une machine virtuelle Linux.

## Linux

Installe les logiciels requis avec le gestionnaire de paquets de ton système :

* Ubuntu, Debian : `$ sudo apt-get install gcc make nasm`
* Fedora : `$ sudo dnf install gcc make nasm`
* CentOS, RHEL : `$ sudo yum install gcc make nasm`
* Arch Linux : `$ sudo pacman -S gcc make nasm`
* OpenSUSE : `$ sudo zypper install gcc make nasm`

## macOS

Installe les Xcode Command Line Tools :

```bash
$ xcode-select --install
```

Installe NASM avec [Homebrew](http://brew.sh/) :

```bash
$ brew install nasm
```

## Windows

Pour installer WSL, consulte https://docs.microsoft.com/en-us/windows/wsl/install-win10.
