# Introduction

Une définition de collection inclut généralement un espace réservé entre chevrons, souvent T par convention. Une telle collection est appelée un type générique. Cela permet à celui qui utilise la collection de spécifier quel type d'éléments stocker dans la collection. Dans l'exemple de code ci-dessus, on instancie un tableau de _strings_.

On rend une classe ou une fonction **générique** en utilisant l'attribut `@:generic`. Cela amène le compilateur à identifier la classe ou la fonction comme générique :

```haxe
@:generic
class MyValue<T> {
  public var value:T;

  public function new(value:T) {
    this.value = value;
  }
}

var a = MyValue<String>("Hello");
trace(a.value); // Hello
```
