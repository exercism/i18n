# Installation

## Installe .NET

Le parcours F# repose sur la plateforme [.NET](https://dotnet.microsoft.com/learn/dotnet/what-is-dotnet), qui fonctionne sous Windows, Linux et macOS. Pour compiler des projets .NET, tu peux utiliser l'interface en ligne de commande (CLI) de .NET. Cette CLI fait partie du SDK .NET, que tu peux installer en suivant les [instructions d'installation](https://dotnet.microsoft.com/download). Remarque : le parcours F# nécessite la version 8.0 du SDK ou une version ultérieure.

Une fois l'installation terminée, tu peux vérifier que la CLI a bien été installée en exécutant cette commande dans un terminal :

```bash
dotnet --version
```

Si la sortie affiche une version supérieure ou égale à `8.0.100`, le SDK .NET a bien été installé.

## Utilise un IDE

Si tu veux une expérience d'édition plus complète, tu préféreras probablement utiliser un IDE. Voici les IDE les plus populaires qui prennent en charge la compilation de projets .NET :

- [Visual Studio 2022](https://www.visualstudio.com/downloads/)
- [Visual Studio Code](https://code.visualstudio.com/download) avec l'[extension Ionide-fsharp](https://marketplace.visualstudio.com/items?itemName=Ionide.Ionide-fsharp)
- [Visual Studio pour Mac](https://www.visualstudio.com/vs/visual-studio-mac/)
- [Project Rider](https://www.jetbrains.com/rider/download/)

Remarque : comme le format des projets .NET diffère sensiblement de celui des versions antérieures, les IDE plus anciens (comme Visual Studio 2015) ne sont pas pris en charge.
