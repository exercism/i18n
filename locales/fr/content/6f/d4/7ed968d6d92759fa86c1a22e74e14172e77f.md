# Indices

## Général

- Lis la documentation sur les [ensembles][set]
- La documentation sur les [listes][lists] pourrait aussi t'être utile

## 1. Commence une collection

- La fonction `Set` la plus adaptée est [`Set.singleton`][singleton]

## 2. Agrandis la collection

- Utilise la [fonction `Set.insert`][insert]
- Utilise la [fonction `Set.member`][member]

## 3. Commence à échanger

- Utilise la [fonction `Set.member`][member]
- Utilise la [fonction `Set.insert`][insert]
- Utilise la [fonction `Set.remove`][remove]

## 4. Il ne peut y en avoir qu'un de chaque

- Un `Set` a la propriété de ne contenir que des valeurs uniques
- Utilise la [fonction `Set.fromList`][fromList]
- Utilise la [fonction `Set.toList`][toList]
- `Set.toList` renvoie toujours une liste triée

## 5. Les cartes qu'ils n'ont pas

- Utilise la [fonction `Set.diff`][diff]
- Utilise la [fonction `Set.size`][size]

## 6. Les cartes qu'ils ont tous

- Utilise les [fonctions `List.foldl` ou `List.foldr`][fold]
- Utilise le filtrage par motif sur la liste pour distinguer les listes vides des listes non vides
- Utilise la [fonction `Set.intersect`][intersect]
- Utilise la [fonction `Set.toList`][toList]
- `Set.toList` renvoie toujours une liste triée

## 7. Toutes les cartes

- Utilise les [fonctions `List.foldl` ou `List.foldr`][fold]
- Utilise [`Set.empty`][empty] comme accumulateur
- Utilise la [fonction `Set.union`][union]
- Utilise la [fonction `Set.size`][size]

## 8. Un _shiny_ pour la victoire

- Utilise la [fonction `Set.partition`][partition]
- Utilise la [fonction `String.startsWith`][startsWith]
- Utilise la [fonction `Set.toList`][toList]
- `Set.toList` renvoie toujours une liste triée
