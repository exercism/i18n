# Indices

## Général

- Utilise le [type tableau][array] intégré.

## 1. Définis une méthode qui renvoie un tableau de langages vide

- La fonction doit renvoyer un tableau vide de type `Array(String)`.
- La syntaxe pour créer un tableau vide est `[]`.
  On peut préciser le type avec `of String`.

## 2. Définis une méthode pour ajouter un langage au tableau

- On peut ajouter un élément à un tableau avec `<<`.

## 3. Définis une méthode pour supprimer un langage du tableau

- Crystal [fournit une méthode][pop] pour supprimer le dernier élément d'un tableau.

## 4. Définis une méthode qui renvoie le n-ième élément du tableau

- Crystal [fournit une méthode][index] pour récupérer l'élément situé à un indice précis dans un tableau.

## 5. Définis une méthode pour analyser une _string_ de langages

- Crystal [fournit une méthode][split] pour convertir une _string_ en tableau à l'aide d'un délimiteur.
