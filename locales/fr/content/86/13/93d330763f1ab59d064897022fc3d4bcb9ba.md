# Introduction

La plupart des données en Factor résident dans des *séquences*. Les tableaux, les vecteurs et les _strings_ sont tous des séquences et partagent un ensemble commun de mots issus du vocabulaire [`sequences`][sequences].

## Littéraux de tableau

Un tableau littéral s'écrit avec `{ }` et des espaces entre les éléments :

```factor
{ 1 2 3 } .          ! => { 1 2 3 }
{ "a" "b" "c" } .    ! => { "a" "b" "c" }
```

Les tableaux sont de longueur fixe, donc des mots comme `suffix` et `remove-nth`, qui modifient le nombre d'éléments, renvoient une *nouvelle* séquence au lieu de modifier celle d'origine.

## Longueur et indiçage

```
length   ( seq -- n   )
first    ( seq -- elt )
rest     ( seq -- tailseq )    ! everything but the first element
last     ( seq -- elt )
but-last ( seq -- headseq )    ! everything but the last element
nth      ( n seq -- elt )      ! 0-based
?nth     ( n seq -- elt/f )    ! 0-based; f when out of bounds
```

```factor
{ 10 20 30 } length .       ! => 3
{ 10 20 30 } first .        ! => 10
{ 10 20 30 } rest .         ! => { 20 30 }
{ 10 20 30 } last .         ! => 30
{ 10 20 30 } but-last .     ! => { 10 20 }
1 { 10 20 30 } nth .        ! => 20
```

`?nth` est la version sûre vis-à-vis des bornes : on peut tester une position sans avoir à vérifier d'abord la longueur.

```factor
1 { 10 20 30 } ?nth .       ! => 20
9 { 10 20 30 } ?nth .       ! => f  (out of bounds, no error)
```

## Découpage

```
head ( seq n -- headseq )    ! first n elements
tail ( seq n -- tailseq )    ! drop first n
```

```factor
{ 1 2 3 4 5 } 3 head .   ! => { 1 2 3 }
{ 1 2 3 4 5 } 3 tail .   ! => { 4 5 }
```

Les deux lèvent une erreur si `n` est plus grand que la séquence. Si `n` est trop grand, `index-or-length` le réduit à la longueur de la séquence, de sorte que la tranche qui suit ne peut pas dépasser la fin :

```
index-or-length ( seq n -- seq n' )
```

```factor
{ 10 20 30 40 50 } 3 index-or-length head .   ! => { 10 20 30 }
{ 10 20 } 3 index-or-length head .            ! => { 10 20 }
```

Les variantes étoilées `head*` et `tail*` comptent depuis la fin. `head*` supprime les `n` derniers, tandis que `tail*` conserve les `n` derniers :

```
head* ( seq n -- headseq )   ! everything except the last n
tail* ( seq n -- tailseq )   ! the last n elements
```

```factor
{ 1 2 3 4 5 } 2 head* .   ! => { 1 2 3 }
{ 1 2 3 4 5 } 2 tail* .   ! => { 4 5 }
```

Pour une tranche arbitraire entre deux indices, `subseq` prend le *début* (inclus) et la *fin* (exclue) :

```
subseq ( from to seq -- subseq )
```

```factor
1 4 { 10 20 30 40 50 } subseq .   ! => { 20 30 40 }
1 4 "hello" subseq .              ! => "ell"
```

Quand on dispose d'un *début et d'une longueur*, il suffit de les additionner pour obtenir la fin :

```factor
2 dup 3 + "hello world" subseq .  ! => "llo"
```

(C'est l'intervalle d'indices `[2, 5)`, soit trois caractères à partir de la position 2.)

La question inverse, à savoir *où* apparaît une sous-séquence, trouve sa réponse avec `subseq-index`, qui renvoie l'indice de départ de la première correspondance, ou `f` s'il n'y en a aucune :

```
subseq-index ( seq subseq -- i/f )
```

```factor
"hello world" "o w" subseq-index .   ! => 4
"hello world" "xyz" subseq-index .   ! => f
```

## Remplissage

```
pad-head ( seq n elt -- padded )    ! prepend copies of elt
pad-tail ( seq n elt -- padded )    ! append copies of elt
```

Les deux étendent `seq` jusqu'à ce que sa longueur atteigne au moins `n`. Si `seq` est déjà aussi longue, elle est renvoyée telle quelle.

```factor
{ 2 5 0 } 6 0 pad-tail .   ! => { 2 5 0 0 0 0 }
{ 4 1 } 5 9 pad-head .     ! => { 9 9 9 4 1 }
```

## Les mêmes mots fonctionnent sur les _strings_

Une _string_ est une séquence de caractères, donc tout ce qui précède fonctionne aussi sur les _strings_, le résultat étant simplement une autre _string_ au lieu d'un tableau :

```factor
"hello" length .            ! => 5
"hello" 3 head .             ! => "hel"
"abc" 6 CHAR: . pad-tail .   ! => "abc..."
```

## Agrégation

`sum` et `product` (dans [`sequences`][sequences]) additionnent ou multiplient les éléments d'une séquence numérique :

```factor
{ 2 5 0 7 } sum .        ! => 14
{ 2 5 3 7 } product .    ! => 210
```

`count` applique un prédicat sur la séquence et renvoie le nombre d'éléments qui le rendent vrai :

```
count ( seq quot -- n )
```

```factor
{ 2 5 0 7 4 1 } [ even? ] count .    ! => 3
```

## Prédicats sur toute la séquence

```
any?   ( seq quot -- ? )
all?   ( seq quot -- ? )
empty? ( seq -- ? )
```

```factor
{ 2 5 0 7 } [ 4 > ] any? .      ! => t
{ 2 5 0 7 } [ 0 > ] all? .      ! => f
```

## Construction d'une nouvelle séquence

`suffix` ajoute un élément à la fin d'une séquence ; `prefix` en ajoute un au début. `unclip` détache le premier élément et `unclip-last` détache le dernier :

```
prefix      ( seq elt -- newseq )
suffix      ( seq elt -- newseq )
unclip      ( seq -- rest first )
unclip-last ( seq -- butlast last )
```

```factor
{ 7 9 } 3 prefix .             ! => { 3 7 9 }
{ 7 9 } 3 suffix .             ! => { 7 9 3 }
{ 4 0 9 } unclip .s
! => { 0 9 }
! => 4
```

En combinant `unclip-last` et `suffix`, on obtient une mise à jour non destructive du dernier élément (et `unclip` + `prefix` fait de même pour le premier) :

```factor
{ 10 20 30 } unclip-last 2 * suffix .
! => { 10 20 60 }
```

## Conversion entre types de séquences

`>array`, `>vector` et `>string` (dans [`arrays`][arrays] et les vocabulaires correspondants) forcent une séquence à prendre un type concret particulier. C'est utile quand une opération a renvoyé une tranche ou une séquence générique et que l'on a besoin de récupérer un tableau (ou une _string_).

```factor
{ 1 2 3 } 1 tail >array .   ! => { 2 3 }
"hello" >array .            ! => { 104 101 108 108 111 }
{ 65 66 67 } >string .      ! => "ABC"
```
