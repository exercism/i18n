# Tests

Pour lancer les tests, assemble le fichier exécuteur de tests d'un exercice donné et exécute-le, soit via l'interface graphique du simulateur MARS, soit en ligne de commande. Pour lancer les tests en ligne de commande, indique d'abord le fichier exécuteur, puis ton implémentation, comme ceci :

    java -jar /path/to/mars.jar nc runner.mips impl.mips

Pour lancer les tests dans l'interface graphique, `include` ton implémentation à la fin de « runner.mips » en décommentant la dernière ligne.

L'exécuteur de tests se termine soit par un message « success », soit s'arrête sur un test échoué avec un message qui précise l'entrée pour laquelle ce test a échoué.
