# Instructions

Dans cet exercice, tu vas travailler sur un planificateur de rendez-vous pour un salon de beauté à New York, ouvert le 15 septembre 2012.

Tu as quatre tâches, qui porteront toutes sur des dates de rendez-vous. Les dates et les heures utiliseront l'un des trois formats suivants :

- `"7/25/2019 13:45:00"`
- `"July 25, 2019 13:45:00"`
- `"Thursday, July 25, 2019 13:45:00"`

Les tests définissent automatiquement la culture sur `en-US` : tu n'as pas à définir ni à préciser la culture toi-même.

## 1. Analyse la date d'un rendez-vous

Implémente la méthode (_static_) `Appointment.Schedule()` pour analyser la représentation textuelle d'une date de rendez-vous et la convertir au format `DateTime` correspondant :

```csharp
Appointment.Schedule("7/25/2019 13:45:00")
// => new DateTime(2019, 7, 25, 13, 45, 0)
```

## 2. Vérifie si un rendez-vous est déjà passé

Implémente la méthode (_static_) `Appointment.HasPassed()` qui prend une date de rendez-vous et vérifie si le rendez-vous appartient au passé :

```csharp
Appointment.HasPassed(new DateTime(1999, 12, 31, 9, 0, 0))
// => true
```

## 3. Vérifie si le rendez-vous est l'après-midi

Implémente la méthode (_static_) `Appointment.IsAfternoonAppointment()` qui prend une date de rendez-vous et vérifie si le rendez-vous a lieu l'après-midi (>= 12:00 et < 18:00) :

```csharp
Appointment.IsAfternoonAppointment(new DateTime(2019, 03, 29, 15, 0, 0))
// => true
```

## 4. Décris la date et l'heure du rendez-vous

Implémente la méthode (_static_) `Appointment.Description()` qui prend une date de rendez-vous et renvoie une description de cette date et de cette heure :

```csharp
Appointment.Description(new DateTime(2019, 03, 29, 15, 0, 0))
// => "You have an appointment on 3/29/2019 3:00:00 PM."
```

## 5. Renvoie la date anniversaire

Implémente la méthode (_static_) `Appointment.AnniversaryDate()` qui renvoie la date anniversaire de cette année, à savoir le 15 septembre :

```csharp
Appointment.AnniversaryDate()
// => new DateTime(2019, 9, 15, 0, 0, 0)
```
