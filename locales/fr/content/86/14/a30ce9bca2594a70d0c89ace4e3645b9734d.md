# Ajout aux instructions

## Indices

Tu dois implémenter la fonction `rotate`, qui prend un `Int` et une `String`, puis l'encode à l'aide d'un chiffrement par rotation.
Tu peux utiliser la signature fournie si tu as un doute sur les types, mais ne la laisse pas restreindre ta créativité.

Cet exercice travaille sur des données textuelles. Pour des raisons historiques, le type `String` de Haskell est synonyme de `[Char]`, une liste de caractères. Pour manipuler les données textuelles plus efficacement, on peut utiliser le type `Text`.

Pour prolonger cet exercice de façon facultative, tu peux

- lire la page sur les [types de _string_](https://haskell-lang.org/tutorial/string-types) en Haskell.
- ajouter `- text` à ta liste de dépendances dans package.yaml.
- importer `Data.Text` de [la manière suivante](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c) :

```haskell
import qualified Data.Text as T
import           Data.Text (Text)
```

- utiliser le type `Text`, par exemple `rotate :: Int -> Text -> Text`, et faire appel aux combinateurs de `Data.Text` comme, par exemple, `T.pack`.
- consulter la documentation de
  [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html).
- remplacer toutes les occurrences de `String` par `Text` dans RotationalCipher.hs, c'est-à-dire :

```haskell
rotate :: Int -> Text -> Text
```

Cette partie est entièrement facultative.
