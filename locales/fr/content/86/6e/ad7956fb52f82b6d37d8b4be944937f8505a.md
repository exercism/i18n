# À propos

En Common Lisp, le temps est représenté de trois façons

- Le temps universel est un temps absolu, un entier qui représente le nombre de secondes écoulées depuis `1900-01-01T00:00:00Z` (soit minuit le 1er janvier 1900 en UTC).
- Le temps décodé est un tuple de 9 valeurs, qui représentent ensemble un instant calendaire précis : secondes, minutes, heure, jour du mois, mois, année, jour de la semaine, indicateur d'heure d'été, fuseau horaire.
(Nous y revenons en détail plus bas.)
- Le temps interne est un entier positif exprimé en « unités de temps internes » définies par l'implémentation, que l'on peut utiliser pour mesurer le temps d'exécution.

## Temps universel

Pour obtenir le temps universel courant, on utilise `get-universal-time` ou `get-decoded-time`.
La première renvoie le nombre de secondes écoulées depuis `1900-01-01T00:00Z` et la seconde renvoie ces mêmes données au format décodé.

Remarque : comme ce nombre est un entier positif, il est impossible d'encoder des dates antérieures à 1900.

## Temps décodé

`decode-universal-time` et `encode-universal-time` sont les principales fonctions pour manipuler le temps.
La première prend un temps universel et renvoie une valeur de temps décodé sous forme de [valeurs multiples][concept-multiple-values], et la seconde prend les valeurs de temps décodé en arguments et renvoie un temps universel.

Les deux prennent un argument de fuseau horaire facultatif.
Voir plus bas le format du fuseau horaire.

Un temps décodé est un ensemble de valeurs :

- *secondes* : un entier compris entre 0 et 59
- *minutes* : un entier compris entre 0 et 59
- *heure* : un entier compris entre 0 et 23
- *jour du mois* : un entier compris entre 1 et 31 (la borne supérieure dépend bien sûr du mois et de l'année)
- *mois* : un entier compris entre 1 et 12
- *année* : un entier qui indique l'année.
- *jour de la semaine* : un entier compris entre 0 et 6. 0 signifie lundi, 1 signifie mardi, etc. ... 6 signifie dimanche.
- *indicateur d'heure d'été* : une valeur vraie indique que l'heure d'été est en vigueur.
- *fuseau horaire* : un nombre d'heures compris entre -24 et 24, qui donne le décalage par rapport à UTC.
Ce nombre est un nombre rationnel et doit être un multiple de `1/3600`

```lisp
(encode-universal-time 1 2 3 4 5 2000 0) ; => 3166398121
(decode-universal-time 3166398121 0)     ; => 1
                                         ;    2
                                         ;    3
                                         ;    4
                                         ;    5
                                         ;    2000
                                         ;    3 (Thursday)
                                         ;    NIL
                                         ;    0
(decode-universal-time 2208988800 0)     ; => 0
                                         ;    0
                                         ;    0
                                         ;    1
                                         ;    1
                                         ;    1970
                                         ;    3
                                         ;    NIL
                                         ;    0
```

Remarque : le comportement est intéressant lorsque le paramètre de fuseau horaire n'est pas fourni.
Consulte la documentation de [`decode-universal-time`][hyperspec-decode-universal-time] et de [`encode-universal-time`][hyperspec-encode-universal-time] pour plus de détails.

## Temps interne

Un temps interne est un nombre entier positif exprimé en « unités de temps internes ». La différence entre deux de ces valeurs permet de mesurer le temps pendant l'exécution.

- `get-internal-real-time` renvoie le temps « réel » ou « horloge » courant.
- `get-internal-run-time` dépend beaucoup de l'implémentation et peut inclure ou non, par exemple, le temps passé en pagination mémoire ou en ramasse-miettes.

La variable `internal-time-units-per-second` contient une valeur qui correspond au nombre d'« unités de temps internes » par seconde pour l'environnement Lisp en cours d'exécution.
