# Instructions

Le salon de beauté de New York pour lequel tu as travaillé dans l'exercice Prendre rendez-vous pour la beauté se porte bien, et beaucoup de ses clients sont devenus des habitués.
Au lieu de réserver chaque visite séparément, un habitué a un rendez-vous fixe : « un mardi sur deux », « le dernier vendredi du mois », et ainsi de suite.
La propriétaire t'a demandé un outil qui calcule les dates qui se cachent derrière ces rendez-vous, ainsi que les dates de la routine mensuelle du salon.

## 1. Trouve le rendez-vous fixe d'un habitué

Implémente la méthode `SalonCalendar.standingAppointment()` qui prend une année, un mois, une occurrence (`1` pour la première, `2` pour la deuxième, etc.) et un jour de la semaine.
Elle renvoie la date de cette occurrence du jour de la semaine dans le mois :

```java
SalonCalendar calendar = new SalonCalendar();
calendar.standingAppointment(2024, Month.AUGUST, 2, DayOfWeek.TUESDAY);
// => LocalDate.of(2024, 8, 13)
```

## 2. Trouve le rendez-vous de fin de mois d'un habitué

Certains habitués préfèrent la dernière occurrence de leur jour dans le mois.
Implémente la méthode `SalonCalendar.lastAppointment()` qui prend une année, un mois et un jour de la semaine, et renvoie la date de la dernière occurrence de ce jour de la semaine dans le mois :

```java
SalonCalendar calendar = new SalonCalendar();
calendar.lastAppointment(2024, Month.AUGUST, DayOfWeek.FRIDAY);
// => LocalDate.of(2024, 8, 30)
```

## 3. Trouve le prochain jour disponible pour un client sans rendez-vous

Un client à l'accueil demande « le prochain samedi ».
Si le jour où il demande est déjà un samedi, il parle de ce jour-là même.
Implémente la méthode `SalonCalendar.nextAvailable()` qui prend une date et un jour de la semaine, et renvoie la première date à partir de la date donnée, celle-ci incluse, qui tombe ce jour de la semaine :

```java
SalonCalendar calendar = new SalonCalendar();
calendar.nextAvailable(LocalDate.of(2024, 8, 15), DayOfWeek.SATURDAY);
// => LocalDate.of(2024, 8, 17)
calendar.nextAvailable(LocalDate.of(2024, 8, 17), DayOfWeek.SATURDAY);
// => LocalDate.of(2024, 8, 17)
```

## 4. Trouve le jour de clôture

Le salon clôture ses comptes le dernier jour de chaque mois.
Mais le salon est fermé le week-end, donc quand le dernier jour du mois tombe un samedi ou un dimanche, les comptes sont clôturés le vendredi précédent.
Implémente la méthode `SalonCalendar.bookkeepingDay()` qui prend une année et un mois, et renvoie le jour de clôture de ce mois :

```java
SalonCalendar calendar = new SalonCalendar();
calendar.bookkeepingDay(2024, Month.SEPTEMBER);
// => LocalDate.of(2024, 9, 30)
calendar.bookkeepingDay(2024, Month.AUGUST);
// => LocalDate.of(2024, 8, 30)
```

## 5. Réutilise la règle du week-end pour le jour de paie

Le personnel est payé le 15 de chaque mois, avec la même règle du week-end : quand le 15 tombe un samedi ou un dimanche, le jour de paie est le vendredi précédent.
Plutôt que d'écrire la règle une seconde fois, transforme-la en un ajusteur réutilisable.

Implémente la méthode `SalonCalendar.precedingWorkday()` qui renvoie un `TemporalAdjuster` laissant un jour de semaine inchangé et ramenant un samedi ou un dimanche au vendredi précédent.
Implémente ensuite la méthode `SalonCalendar.payday()`, qui prend une année et un mois, en utilisant cet ajusteur :

```java
SalonCalendar calendar = new SalonCalendar();
LocalDate.of(2024, 6, 15).with(calendar.precedingWorkday());
// => LocalDate.of(2024, 6, 14)
calendar.payday(2024, Month.JUNE);
// => LocalDate.of(2024, 6, 14)
calendar.payday(2024, Month.AUGUST);
// => LocalDate.of(2024, 8, 15)
```

N'hésite pas à revenir en arrière pour utiliser cet ajusteur dans `bookkeepingDay()` également.
