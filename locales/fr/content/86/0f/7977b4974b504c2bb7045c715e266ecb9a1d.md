# Complément aux instructions

## Implémentation

Les tests de cet exercice s'attendent à ce que ton horloge soit implémentée à l'aide d'une `data declaration` en Pyret.
Si tu ne connais pas les déclarations de données, [la documentation officielle][data-declaration] est un bon point de départ.

Dans le cadre de cet exercice, tu vas comparer des valeurs construites par une variante de données `Clock`.
Comme les heures et les minutes d'une horloge peuvent déborder dans un sens comme dans l'autre, les combinaisons suivantes sont équivalentes sur une horloge : 1 heure 1 minute, 0 heure 61 minutes, 25 heures 1 minute et 2 heures -59 minutes.
L'opérateur de test `is` de Pyret utilise l'égalité structurelle, ce qui signifie qu'aucune de ces combinaisons ne sera égale par défaut.
Pour cette raison, tu devras définir ta propre méthode d'égalité pour comparer les moments entre les valeurs d'une variante de données Clock.
Si tu ne sais pas comment Pyret gère l'égalité, consulte la documentation officielle sur [l'égalité][equality].

[data-declaration]: https://pyret.org/docs/latest/s_declarations.html#%28part._s~3adata-decl%29
[equality]: https://pyret.org/docs/latest/equality.html
