# Instructions

Tu travailles pour un parc d'attractions et on t'a confié un cahier des charges pour concevoir un système qui gère la fréquentation et les attractions. Ta mission consiste à modéliser l'Attendee (la personne qui visite le parc).

## 1. Crée de nouveaux visiteurs

Implémente la méthode `Attendee#initialize` de la classe `Attendee` : elle prend une taille (en centimètres) et la stocke dans une variable d'instance.

```ruby
Attendee.new(106)
# => #<Attendee:0x000055c33e6c7e18 @height=106>
```

## 2. Quelle est la taille du visiteur

Implémente le _getter_ `Attendee#height` de la classe `Attendee` : il renvoie la taille de l'instance.

```ruby
Attendee.new(106).height
# => 106
```

## 3. Quel est l'identifiant du pass d'attractions

Tous les visiteurs n'ont pas acheté de pass, mais on doit savoir s'ils en ont un ou non. Implémente le _getter_ `Attendee#pass_id` de la classe `Attendee` : il doit renvoyer l'identifiant du pass de l'instance, ou `nil` si le visiteur n'en a pas.

```ruby
Attendee.new(106).pass_id
# => nil
```

## 4. Permets aux visiteurs d'acheter un pass

Implémente `Attendee#issue_pass!` pour modifier l'état de l'instance et affecter l'argument à la variable d'instance de l'identifiant du pass. Elle doit renvoyer l'identifiant du pass.

```ruby
attendee = Attendee.new(106)
attendee.issue_pass!(42)
attendee.pass_id
# => 42
```

## 5. Révoque le pass

Certains visiteurs enfreignent les règles avec un comportement dangereux, c'est pourquoi le parc veut pouvoir révoquer des pass. Implémente `Attendee#revoke_pass!` pour modifier l'état de l'instance et mettre l'identifiant du pass à `nil`.

```ruby
attendee = Attendee.new(106)
attendee.issue_pass!(42)
attendee.revoke_pass!
attendee.pass_id
# => nil
```
