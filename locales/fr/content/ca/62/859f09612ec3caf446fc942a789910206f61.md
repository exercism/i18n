# Lance les tests

SWI Prolog peut être exécuté de façon interactive ou directement en ligne de commande.

## En ligne de commande

La commande suivante permet de lancer les tests depuis la ligne de commande :

```bash
swipl -f <exercise>.pl -s <exercise>_tests.plt -g run_tests,halt -t 'halt(1)'
```

Remplace `<exercise>` par le nom de l'exercice que tu implémentes.

## En mode interactif

Pour lancer Prolog de façon interactive, commence par exécuter :

```bash
swipl
```

Une fois la console Prolog démarrée, charge ton implémentation et lance les tests avec :

```
?- ["<exercise>.pl"].
?- ["<exercise>_tests.plt"].
?- run_tests.
```

Remplace `<exercise>` par le nom de l'exercice que tu implémentes.

### Recharge les modifications

Une fois les fichiers ci-dessus chargés, tu peux appliquer les modifications que tu as faites en exécutant :

```
?- make.
```

## Tests ignorés

Quand tu commences un exercice, seul le premier test s'exécute. Les autres ont été ignorés en ajoutant `condition(pending)` au but `test`.
Une fois le premier test réussi, réactive le test suivant en remplaçant `pending` par `true` dans `condition(pending)`.
Répète l'opération pour chaque test jusqu'à ce qu'ils s'exécutent et réussissent tous.

### En ligne de commande

Ajoute l'argument `-- --all` à la fin de la commande pour exécuter aussi les tests en attente :

```bash
swipl -f <exercise>.pl -s <exercise>_tests.plt -g run_tests,halt -t 'halt(1)' -- --all
```
