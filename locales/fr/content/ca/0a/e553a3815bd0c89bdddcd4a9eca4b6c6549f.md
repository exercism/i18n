# Introduction

Les fonctions et méthodes en Go peuvent renvoyer plusieurs valeurs :

```go
func GetCard() (Card, error) { ... }
```

Chaque valeur de retour doit être affectée dans l'ordre et séparée par des virgules :

```go
card, err := GetCard()
```

Chaque position dans l'affectation déclare une variable.
Go ne compilera pas si une variable déclarée n'est jamais utilisée.
L'identifiant vide `_` remplace le nom d'une variable pour ignorer cette valeur de retour :

```go
card, _ := GetCard()
```

`error` est une interface intégrée.
Une erreur `nil` signifie qu'aucune erreur ne s'est produite ; toute valeur non nulle signifie que quelque chose s'est mal passé.
Par convention, les fonctions qui peuvent échouer devraient renvoyer une `error` comme dernière valeur.
L'appelant doit la vérifier avant d'utiliser les autres valeurs de retour :

```go
card, err := GetCard()
if err != nil {
    return err // do not use card here
}
// safe to use card here
```
