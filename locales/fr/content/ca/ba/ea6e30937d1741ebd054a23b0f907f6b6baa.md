# Indices

- L'entrée de `shared_birthday` peut être de type `String ` ou `Date `.
- La sortie de `random_birthdays` est `Vector{Date}`.
- Le nombre d'essais dans `estimate_probability_of_shared_birthday` doit être d'au moins 10 000, pour obtenir une estimation raisonnablement précise de la probabilité.
- Les fonctionnalités qui pourraient être utiles incluent [isleapyear][isleapyear] et [monthday][monthday],
- Le parcours d'apprentissage propose une documentation sur les concepts qui peut constituer une bonne introduction :
  - [Dates et heures][dates-times]
  - [Aléatoire][randomness]
  - [Composition de fonctions][function-composition]
  - [Fonctions d'ordre supérieur][hof]
