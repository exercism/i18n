# Utilise l'opérateur de coalescence null plutôt qu'un test de nullité

Utilise l'[opérateur de coalescence null](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/operators/null-coalescing-operator) pour simplifier le code, plutôt que de vérifier explicitement qu'une valeur est égale à `null` avant d'en faire quelque chose.
