# Introduction

## Tableaux et vecteurs

C++ propose différents conteneurs pour stocker des éléments de même type de manière ordonnée.
Il y a `std::array` pour les conteneurs de taille fixe et `std::vector`, qui offre des capacités de redimensionnement dynamique.

### Construction

Quand on déclare un tableau ou un vecteur, il faut préciser le type des éléments que ce conteneur va contenir.
Les tableaux nécessitent aussi une taille.
Regarde ces exemples pour voir l'initialisation des deux types de conteneurs :

```cpp
#include <array>
#include <string>

// std::array<element_type, size> variable_name {list of elements}
std::array<std::string, 3> indie_rock {"yeah", "yeah", "yeah"};
// indie_rock contains the elements "yeah" three times
```

Les vecteurs ont généralement besoin de plus d'espace, car ils allouent de la mémoire pour une croissance future.
Tu n'as pas besoin de préciser une taille :

```cpp
#include <vector>

// std::vector<element_type> variable_name {list of elements}
std::vector<int> countdown {3, 2, 1};
// countdown contains the elements 3, 2 and 1
```

> Remarque : tu n'as pas besoin de connaître les mécanismes exacts derrière le concept de _template_ pour l'instant, il aura son propre concept plus bas dans l'arbre du programme.

### Accès aux éléments

Les vecteurs et les tableaux partagent les mêmes fonctions pour accéder à leurs éléments.
On peut utiliser les fonctions membres `front` et `back` pour obtenir le premier et le dernier élément du conteneur.
Il y a aussi `at` et l'opérateur `[]` pour accéder à des éléments spécifiques.

```cpp
countdown[0];
// => 3
countdown.at(2);
// => 1
countdown[1] = 4;
// countdown now contains 3, 4 and 1
indie_rock.back() = "yeahs";
// indie_rock is now "yeah", "yeah", "yeahs"
```

> Remarque : si tu choisis une position qui n'est pas dans la plage de ton conteneur, `[]` peut entraîner un comportement indéfini.
> La fonction `at` lèvera une exception, ce qui pourrait te simplifier la vie à long terme.

### Modificateurs de vecteur

Comme un `vector` n'a pas une taille fixe, il est possible d'ajouter ou de supprimer des éléments.
Deux fonctions courantes pour cela sont `emplace_back` et `pop_back`.

```cpp
std::vector<std::string> witches {"Holly", "Alyssa", "Shannen"};
witches.pop_back();
// Shannen is no longer with the witches
witches.emplace_back("Rose");
// Rose has joined the team
```

### Capacité

Tu peux vérifier si les conteneurs sont vides avec la fonction membre `empty`.
Si tu veux connaître le nombre d'éléments, tu peux utiliser `size`.
