# À propos

Haxe prend nativement en charge les expressions régulières. Elles permettent de vérifier le format d'une _string_, de transformer une _string_ ou d'extraire des données régulières d'un texte donné.

Pour créer une expression régulière, on saisit le motif entre `~/` et `/` :

```haxe
var r = ~/haxe/i;
```

Une autre façon de faire est d'utiliser l'instance `EReg()` :

```haxe
var r = new EReg("haxe", "i");
```

Ici, le `i` est un drapeau qui rend le motif insensible à la casse. Il existe d'autres drapeaux, notamment :

- `g` : remplacement global.
- `m` : correspondance multiligne

Entre `~/` et `/`, on saisit le motif de l'expression régulière. Par exemple, pour chercher une _string_ qui contient des lettres de A à Z, on peut utiliser le motif d'intervalle `[A-Z]`. Il existe de nombreux motifs, notamment :

- `.` : n'importe quel caractère
- `*` : répéter zéro fois ou plus
- `+` : répéter une fois ou plus
- `[A-Z0-9]` : intervalles de caractères
