# Ressources

- La ressource la plus importante est la [documentation officielle][docs]
- Pour l'édition en ligne, utilise le [Uiua Pad][pad]
- Plonge dans le code source sur le [dépôt GitHub][github] d'Uiua
- Reste à jour grâce au [Uiua Blog][blog] officiel

Le [site principal][main] contient aussi un lien vers le serveur Discord, où tu peux discuter d'Uiua avec d'autres passionnés.
