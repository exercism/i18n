# À propos

La [surcharge de méthode][method-overloading] est un concept clé en Java : elle permet à une classe de posséder plusieurs méthodes portant le même nom, à condition que chaque méthode ait une liste de paramètres différente.
Cette fonctionnalité est un aspect fondamental de la programmation orientée objet en Java et offre un moyen d'effectuer des opérations similaires avec des types ou des nombres d'entrées différents.
La surcharge de méthode améliore la lisibilité et l'organisation du code, car elle permet à des méthodes qui remplissent des rôles similaires de partager le même nom.
Il est important de noter que la surcharge est déterminée par la signature de la méthode, qui comprend le nom de la méthode et la liste des paramètres.

## Points clés

- **La signature compte** : le type de retour ne fait pas partie de la signature de la méthode, donc changer uniquement le type de retour d'une méthode ne constitue pas une surcharge.
- **Différences de paramètres** : les méthodes surchargées doivent différer par le nombre ou le type de leurs paramètres.
- **Utilisation** : on utilise souvent la surcharge pour offrir des façons plus intuitives d'appeler une méthode avec différents types d'entrées.

## Exemples de surcharge de méthode

Prenons une classe `Calculator` capable d'additionner des nombres.
La surcharge permet différents types d'opérations d'addition :

```java
public class Calculator {

    public int add(int a, int b) {
        return a + b;
    }

    public double add(double a, double b) {
        return a + b;
    }

    public int add(int a, int b, int c) {
        return a + b + c;
    }
}
```

## Bonnes pratiques

- **Clarté** : les méthodes surchargées doivent être utilisées de manière à rendre le code plus intuitif.
  - Le comportement des méthodes surchargées doit être cohérent et lié.
- **Éviter l'ambiguïté** : veille à ce que chaque méthode surchargée ait un objectif clair et que les différences entre les listes de paramètres soient suffisamment significatives pour éviter toute confusion.
- **Documentation** : documente correctement chaque version des méthodes surchargées.
  - Une documentation claire aide les autres développeurs à comprendre l'objectif et l'usage de chaque variante de méthode.
- **Types de retour cohérents** : même si les types de retour peuvent varier dans les méthodes surchargées, il est généralement conseillé de les garder cohérents lorsque c'est possible afin d'éviter toute confusion.
- **Limiter la surcharge** : évite d'abuser de la surcharge de méthode.
  - Une surcharge excessive peut rendre le code plus difficile à lire et à maintenir.

## Conclusion

La surcharge de méthode est une fonctionnalité puissante de Java qui, lorsqu'elle est utilisée correctement, peut grandement améliorer la lisibilité et la flexibilité du code.
Elle rend les méthodes plus polyvalentes et mieux adaptées à des contextes différents, ce qui rend tes programmes Java plus modulaires et plus faciles à maintenir.
