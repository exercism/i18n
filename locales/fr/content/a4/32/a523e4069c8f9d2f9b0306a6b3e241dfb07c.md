# À propos

## Alias de type

En Gleam, on peut utiliser un alias de type pour donner un nom pratique à un type existant qui serait autrement pénible à écrire.

```gleam
pub type Headers =
  List(#(String, String))

pub fn html_headers() -> Headers {
  [
    #("content-type", "text/html"),
    #("x-frame-options", "DENY"),
  ]
}
```

Lorsqu'il est écrit avec `pub type`, l'alias peut être utilisé en dehors du module dans lequel il est défini. Si `pub` est omis, l'alias est privé et ne peut pas être référencé dans d'autres modules.
