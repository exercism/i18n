# camelCase

[comment]: # "Cette erreur est déclenchée quand une variable ou un type n'utilise pas camelCase/PascalCase"
[comment]: # "nécessite 2 paramètres :"
[comment]: # "- wrong : nom dont la casse est incorrecte"
[comment]: # "- correct : nom dont la casse est correcte"

La communauté Elm privilégie nettement l'usage de camelCase pour les noms de variables et de PascalCase pour les types.

On a trouvé le nom `%{wrong}`, qui devrait être remplacé par `%{correct}`.
