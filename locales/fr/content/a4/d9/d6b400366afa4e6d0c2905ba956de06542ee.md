# Astuces

## 1. Calcule le tarif journalier à partir d'un tarif horaire

- Utilise les opérateurs arithmétiques comme indiqué dans l'introduction de cet exercice.

## 2. Calcule le nombre de jours travaillés à partir d'un budget

- Détermine d'abord le tarif journalier, puis calcule le nombre de jours, et enfin arrondis ce nombre à l'entier inférieur.

## 3. Calcule le tarif réduit pour les projets importants

- Arrondis le résultat de la division à l'entier inférieur pour obtenir le nombre de mois complets.
- `100% - discount` correspond au pourcentage facturé après application de la réduction.
- Utilise `%`, l'opérateur modulo, pour calculer le nombre de jours qui dépassent les mois complets.
- Additionne les tarifs mensuels réduits et les tarifs journaliers complets, puis arrondis à l'entier supérieur
