# Énumérations

Les énumérations sont un type de données de Cairo qui permet de définir un ensemble de variantes prédéfinies dans un souci de lisibilité et de sûreté du code.
En Cairo, les variantes d'un `enum` peuvent être déclarées pour contenir différents types de données (entiers, structures, tuples, autres énumérations, etc.).

L'extrait de code ci-dessous montre comment définir des énumérations :

```rust
#[derive(Drop)]
enum Direction {
    North,
    East,
    South,
    West,
}
```

L'énumération `Direction` déclarée ci-dessus est une énumération simple avec quatre variantes : `North`, `East`, `South` et `West`.
La convention de nommage consiste à utiliser le `PascalCase` pour les variantes d'une énumération.
Chaque variante représente une valeur distincte du type d'énumération `Direction`.
Dans cet exemple, chaque variante n'a aucune valeur associée et peut être instanciée avec cette syntaxe :

```rust
let direction = Direction::North;
```

Ci-dessous, la même énumération `Direction`, mais dont les variantes ont des valeurs associées qui stockent le degré exact de la direction :

```rust
#[derive(Drop)]
enum Direction {
    North: u128,
    East: u128,
    South: u128,
    West: u128,
}
```

Cet exemple montre clairement que chaque variante de l'énumération `Direction` a une valeur associée de type `u128`.
Ce type d'énumération peut être instancié comme suit :

```rust
let direction = Direction::North(10);
```

## Exemple d'énumération complexe avec des types personnalisés

Une énumération peut être déclarée avec une combinaison de différents types de données comme variantes.
Dans l'exemple ci-dessous, `Action` est une énumération complexe qui a pour variantes `Quit`, `Direction`, `SendMessage`, `ChangeAvatar` et `ProfileState`.

```rust
#[derive(Drop)]
struct Move {
    up: u32,
    down: u32,
    right: u32,
    left: u32,
}

#[derive(Drop)]
enum UserCommand {
    Login,
    UpdateProfile,
    Logout,
}

#[derive(Drop)]
enum Action {
    Quit, //  variant with no associated value
    Direction: Move, // variant with the `Move` struct associated value
    SendMessage: felt252, // a single felt252 variant
    ChangeAvatarColor: (u8, u8, u8), // variant with the tuple of three associated values
    ProfileState: UserCommand // variant with an enum associated value
}
```

## Implémentations de traits pour les énumérations

En Cairo, on peut définir et implémenter des traits sur des énumérations personnalisées.
Cela te permet de définir des méthodes et des attributs associés à une énumération.
Voici un exemple : on y définit une énumération `Message` et on implémente un trait `Processing` pour celle-ci :

```rust
#[derive(Drop)]
enum Message {
    Quit,
    Echo: felt252,
    Move: (u128, u128),
}

trait Processing {
    fn process(self: Message);
}

impl ProcessingImpl of Processing {
    fn process(self: Message) {
        match self {
            Message::Quit => { println!("quitting") },
            Message::Echo(value) => { println!("echoing {}", value) },
            Message::Move((x, y)) => { println!("moving from {} to {}", x, y) },
        }
    }
}
```

Voici comment utiliser ce trait pour traiter un message `Quit` :

```rust
let msg: Message = Message::Quit;
msg.process(); // prints "quitting"
```

Dans de nombreuses situations, les énumérations s'avèrent très utiles, en particulier lorsqu'elles sont employées avec le flux `match` comme ci-dessus dans l'implémentation des traits.
Pour en savoir plus sur le flux `match`, consulte [The Cairo Book][match].
