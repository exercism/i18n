# Null

`null` est un type de valeur primitif qui ne comporte qu'une seule valeur : `null`.
Il sert souvent à représenter une absence de valeur.
Il est considéré comme _falsy_, mais il se distingue de `false` et des autres valeurs _falsy_.

```php
<?php

is_null(null); // => true
isset(null); // => false

null == true; // => false
null === true; // => false

null == false; // => true
null === false; // => false
```

## Manipuler les valeurs `null`

En PHP, les valeurs `null` sont une cause fréquente d'erreurs : elles sont souvent renvoyées à la place d'un état d'erreur ou pour représenter une absence de valeur. Pour éviter ces erreurs, il faut souvent « vérifier les valeurs nulles », c'est-à-dire s'assurer que la valeur n'est pas `null` avant de l'utiliser.

```php
<?php

$value = null;

$value->doSomething(); // throws an error as a null value is not an object instance.

if (!is_null($value)) {
    $value->doSomething(); // succeeds
}
```

Répéter ces vérifications peut vite être source d'erreurs, c'est pourquoi PHP fournit deux opérateurs pour manipuler les valeurs `null` : l'opérateur d'accès sûr `?->` et l'opérateur de coalescence `??`.

```php
<?php

$value = null;
$result = $value?->doSomething(); // => return null rather than error
$result = $result ?? "default"; // => "default" is assigned to $result
```
