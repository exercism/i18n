# Introduction

La forme spéciale `import` permet d'utiliser les fonctions d'un module externe sans passer par le nom du module.

Importer un module externe dans son ensemble peut créer des conflits avec les fonctions locales existantes. Pour éviter cela, tu disposes de deux options : `:except` et `:only`. Toutes les deux attendent une liste de mots-clés, dans laquelle la clé est le nom de la fonction et la valeur son arité.

En général, on place les instructions `import` au début de la définition du module.

```elixir
defmodule Square do
  import Integer, only: [pow: 2]

  def area(a), do: pow(a, 2)
end
```
