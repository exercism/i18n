# Indices

## 1. Définis un type `Coord`.

- `Coord` est une `struct`.
- Les champs sont `x` et `y`.
- Les deux sont de type `UInt16`.

## 2. Définis un type `Plot`.

- `Plot` est une `struct` avec le mot-clé `struct`.
- Les champs sont `bottom_left` et `top_right`.
- Les deux sont de type `Coord`.

## 4. Les spéculateurs peuvent revendiquer une parcelle en la désignant par les coordonnées de ses coins.

- Si la même revendication a déjà été enregistrée, renvoie `false` pour indiquer que ta revendication a échoué.
- Si c'est autorisé, ajoute ta revendication au registre. La fonction [`push!()`][push] peut être utile.
- Comme `stake_claim!()` est une fonction qui mute son argument, les changements dans le `register` seront visibles par l'appelant.
- L'enchaînement de la notation pointée est autorisé, comme `claim.bottom_left.x`.
- Renvoie `true` pour indiquer la réussite.

## 5. Trouve la longueur du côté le plus long d'une parcelle.

- Souviens-toi de l'orientation de ces parcelles rectangulaires. Tu peux en déduire les coordonnées `top_left` et `bottom_right`.
- Calculer la longueur des côtés est de l'arithmétique simple.
- Fais attention à la différence entre [`max()`][max] et [`maximum()`][maximum]. `max` prend un nombre quelconque d'arguments à comparer, `maximum` prend un seul objet itérable.

```julia-repl
julia> max(1, 2, 3)
3

julia> v = [1, 2, 3];
julia> maximum(v)
3
```
