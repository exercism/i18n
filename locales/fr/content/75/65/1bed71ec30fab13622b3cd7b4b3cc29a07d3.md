# Entry API

L'API entry est souvent la façon la plus idiomatique de manipuler le contenu d'une structure de _map_. Cependant, fait inhabituel pour Rust, elle n'a pas été formalisée sous la forme d'un trait ; ce n'est qu'un ensemble de types et de méthodes implémentés sur les types _map_ de la bibliothèque standard.

Fondamentalement, la méthode `map.entry()` fournit un `enum` :

```rust
enum Entry {
    Occupied(_),
    Vacant(_),
}
```

L'intérêt vient d'autres méthodes implémentées sur cet enum. Par exemple, si tu veux obtenir et éventuellement modifier la valeur associée à une clé particulière, et que la valeur par défaut du type convient, tu peux simplement faire :

```rust
// `entry` has type `&mut Value` for the value type of the map
let entry = map.entry(key).or_default();
```

Pour des applications comme un compteur, cela simplifie grandement la vie :

```rust
let counts: HashMap<_, usize> = HashMap::new();
for item in sequence {
    *counts.entry(item).or_default() += 1;
}
```

Si la valeur par défaut du type ne convient pas à ton application, tu peux fournir ta propre valeur par défaut constante avec `or_insert`, ou en calculer une avec `or_insert_with`.

Dans certains cas, tu peux souhaiter effectuer un calcul sur une valeur existante avant d'éventuelles insertions. Dans ces cas-là, `and_modify` le permet. Cependant, cet usage est assez rare. `and_modify` est plus couramment utilisé pour éviter d'avoir à déréférencer :

```rust
map.entry(key).and_modify(|v| *v += 1).or_default();
```

Il est parfois souhaitable de faire un match directement sur l'entrée. C'est autorisé :

```rust
match map.entry(key) {
    Entry::Occupied(occupied) => println!("removed from the map: {:?}", occupied.remove_entry()),
    Entry::Vacant(vacant) => println!("key not present in map: {:?}", vacant.key()),
}
```

Pour plus d'informations, voir [`std::collections::hash_map::Entry`](https://doc.rust-lang.org/std/collections/hash_map/enum.Entry.html) et [`std::collections::btree_map::Entry`](https://doc.rust-lang.org/std/collections/btree_map/enum.Entry.html).
