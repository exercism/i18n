# Introduction

Un `Option` est un enum qui permet de vérifier la validité des valeurs de retour d'une fonction. Il se définit ainsi :

```haxe
enum Option<T> {
  Some(v:T);
  None;
}
```

Il fait partie du _package_ `haxe.ds` :

```haxe
import haxe.ds.Option;

class Main {
  static public function main() {
    var result = trySomething();

    switch (result) {
      case None:
        trace("Nothing");
      case Some(s):
        trace("Got: " + s);
    }
  }

  static public function trySomething():Option<String> {
    if (Math.random() > 0.5) {
      return None;
    } else {
      return Some("Success");
    }
  }
}
```
