# Instructions

Conda Airlines est la plus grande compagnie aérienne du monde de la programmation, avec plus de 10 000 vols par jour !

Actuellement, ils attribuent tous les sièges aux passagers à la main ; il va falloir automatiser tout ça.

C'est _à toi_ qu'ils ont demandé de créer un logiciel pour automatiser l'attribution des sièges aux passagers.
Ils exigent que ton logiciel soit économe en mémoire et performant.

## 1. Génère les lettres de siège

Conda veut générer les lettres de siège de ses avions.
Un avion est composé de rangées de sièges.
Chaque rangée compte _4 sièges_.
Les sièges de chaque rangée portent toujours les noms `A`, `B`, `C` et `D`.
Le premier siège de la rangée est `A`, le deuxième est `B`, et ainsi de suite.
Après avoir atteint `D`, on repart à `A`.

Implémente une fonction `generate_seat_letters(<number>)` qui accepte un `int` indiquant le nombre de lettres de siège à générer.
La fonction doit ensuite renvoyer un _iterable_ de lettres de siège.

```python
>>> letters = generate_seat_letters(4)
>>> next(letters)
"A"
>>> next(letters)
"B"
```

## 2. Génère les sièges

Conda veut un système capable de générer un nombre donné de sièges pour ses avions.
Chaque avion a _4 sièges_ par rangée.
Les rangées sont définies par des nombres, en commençant à `1` et en augmentant.
Les sièges doivent être ordonnés, comme ceci : `1A`, `1B`, `1C`, `1D`, `2A`, `2B`, `2C`, `2D`, `3A`, `3B`, `3C`, `3D`, ...

Voici un exemple :

|      x      |  1  |  2  |
| :---------: | :-: | :-: |
|    Rangée    |  5  | 21  |
| Lettre de siège |  A  |  D  |
|   Résultat   | 5A  | 21D |

Beaucoup de compagnies aériennes n'ont pas de _rangée_ numéro 13 sur leurs vols, par superstition chez les passagers.
Conda Airlines suit également cette convention, alors assure-toi de ne _pas_ générer de sièges pour la _rangée_ numéro 13.

Implémente une fonction `generate_seats(<number>)` qui accepte un `int` indiquant le nombre de sièges à générer.
La fonction doit ensuite renvoyer un _iterable_ des sièges demandés.

```python
>>> seats = generate_seats(10)
>>> next(seats)
"1A"
>>> next(seats)
"1B"
```

## 3. Assigne les sièges aux passagers

Maintenant que tu as une fonction qui génère des sièges, tu peux t'en servir pour attribuer des sièges aux passagers.

Implémente une fonction `assign_seats(<passengers>)` qui accepte une `list` de noms de passagers.
La fonction doit ensuite renvoyer un _dictionnaire_ avec `passenger` comme _clé_ et `seat_number` comme _valeur_.

```python
>>> passengers = ['Jerimiah', 'Eric', 'Bethany', 'Byte', 'SqueekyBoots', 'Bob']

>>> assign_seats(passengers)
{'Jerimiah': '1A', 'Eric': '1B', 'Bethany': '1C', 'Byte': '1D', 'SqueekyBoots': '2A', 'Bob': '2B'}
```

## 4. Codes de billets

Conda Airlines aimerait avoir un code unique pour chaque billet.
Comme c'est une grande compagnie aérienne, elle a beaucoup de vols.
Cela signifie qu'il y a plusieurs vols avec le même numéro de siège.
Ils veulent que tu crées un système qui génère un billet unique, une _string_ de _12_ caractères.

Ce code commence par `assigned_seat`, suivi de `flight_id`.
Le reste du code est rempli de `0s`.

Implémente une fonction `generate_codes(<seat_numbers>, <flight_id>)` qui accepte une `list` de `seat_numbers` et une `string` contenant le numéro de vol.
La fonction doit ensuite renvoyer un `generator` qui produit un `ticket_number`.

```python
>>> seat_numbers = ['1A', '17D']
>>> flight_id = 'CO1234'
>>> ticket_ids = generate_codes(seat_numbers, flight_id)

>>> next(ticket_ids)
'1ACO12340000'
>>> next(ticket_ids)
'17DCO1234000'
```
