# Indices

## 1. Définis la fonction `with_retry`

- Une expression `case` permet de faire du filtrage par motif sur un résultat.

## 2. Définis la fonction `record_timing`

- La fonction `time_logger` doit être appelée même si la fonction `experiment` renvoie une valeur `Error`.

## 3. Définis la fonction `run_experiment`

- La [fonction `result.try`][result-try] peut être utilisée dans une expression `use` pour s'arrêter si un résultat est une valeur `Error`.

[result-try]: https://hexdocs.pm/gleam_stdlib/gleam/result.html#try
