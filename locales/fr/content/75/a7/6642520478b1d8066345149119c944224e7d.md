# Instructions supplémentaires

## Changements spécifiques à Elixir

Dans cet exercice, les nombres complexes sont représentés par un tuple de deux éléments contenant les parties réelle et imaginaire.

Par exemple, le nombre réel `1` est `{1, 0}`, le nombre imaginaire `i` est `{0, 1}` et le nombre complexe `4+3i` est `{4, 3}`.
