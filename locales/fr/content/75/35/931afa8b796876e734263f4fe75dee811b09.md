# Instructions

Étant donné deux tableaux `A` et `B`, détermine si :

- le tableau `A` est égal au tableau `B` ; ou
- le tableau `A` contient le tableau `B` (`A` est une super-liste de `B`) ; ou
- le tableau `A` est contenu dans le tableau `B` (`A` est une sous-liste de `B`) ; ou
- aucune de ces propositions n'est vraie, auquel cas les tableaux `A` et `B` ne sont pas égaux

Plus précisément, le tableau `A` est égal au tableau `B` si les deux tableaux ont les mêmes valeurs dans le même ordre.
Le tableau `A` est une super-liste de `B` si `A` contient une sous-séquence de valeurs égale à `B`.
Le tableau `A` est une sous-liste de `B` si `B` contient une sous-séquence de valeurs égale à `A`.

Exemples :

- Si `A = []` et `B = []` (les deux tableaux sont vides), alors `A` et `B` sont égaux
- Si `A = [1, 2, 3]` et `B = []`, alors `A` est une super-liste de `B`
- Si `A = []` et `B = [1, 2, 3]`, alors `A` est une sous-liste de `B`
- Si `A = [1, 2, 3]` et `B = [1, 2, 3, 4, 5]`, alors `A` est une sous-liste de `B`
- Si `A = [3, 4, 5]` et `B = [1, 2, 3, 4, 5]`, alors `A` est une sous-liste de `B`
- Si `A = [3, 4]` et `B = [1, 2, 3, 4, 5]`, alors `A` est une sous-liste de `B`
- Si `A = [1, 2, 3]` et `B = [1, 2, 3]`, alors `A` et `B` sont égaux
- Si `A = [1, 2, 3, 4, 5]` et `B = [2, 3, 4]`, alors `A` est une super-liste de `B`
- Si `A = [1, 2, 4]` et `B = [1, 2, 3, 4, 5]`, alors `A` et `B` ne sont pas égaux
- Si `A = [1, 2, 3]` et `B = [1, 3, 2]`, alors `A` et `B` ne sont pas égaux
