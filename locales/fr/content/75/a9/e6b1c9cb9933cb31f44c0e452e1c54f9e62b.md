# Indices

## Général

- [Documentation sur les listes][lists-docs] : documentation de référence pour `List<T>`.
- [Tutoriel sur les listes][lists-tutorial] : tutoriel de base sur la manipulation des tableaux.

## 1. Créer un nouveau tableau

- Les collections génériques s'instancient comme toutes les autres avec l'opérateur `new`. Pense à remplacer toute référence au paramètre générique `T` par le type des éléments de ta collection.

## 2. Définir un tableau existant

- Consulte cet [article][list-add] sur l'ajout d'un élément.

## 4. Compter les langages dans le tableau

- Consulte cet [article][list-count] sur la façon de récupérer le nombre d'éléments d'un tableau.

## 5. Vérifier si un langage se trouve dans le tableau

- Consulte cet [article][list-contains] sur la façon de vérifier si un élément se trouve dans un tableau.

## 6. Inverser le tableau

- Consulte cet [article][list-reverse] sur l'inversion d'un tableau.

## 7. Vérifier si le tableau est intéressant

- Consulte cet [article][list-item] sur la façon de récupérer un élément par son indice dans le tableau.

## 8.Retirer un langage

- Consulte cet [article][list-remove] sur la suppression d'un élément du tableau.

## 9. Vérifier si tous les langages du tableau sont uniques
