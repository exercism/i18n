# Ajout aux instructions

## Restrictions

Rust fournit déjà dans sa bibliothèque standard une
[fonction de recherche binaire](https://doc.rust-lang.org/std/primitive.slice.html#method.binary_search).
Pour cet exercice, tu ne dois pas utiliser cette fonction, mais uniquement d'autres outils de base à la place.

## Pour obtenir des points bonus

As-tu réussi à faire passer les tests et à garder le code propre ? Si tu le souhaites, il y a quelques choses supplémentaires que tu pourrais essayer.

- Actuellement, ta fonction find ne fonctionnera probablement que pour des tranches de nombres, mais le système de types de Rust est assez flexible pour créer une fonction find qui fonctionne sur toutes les tranches contenant des éléments que l'on peut ordonner.
- De plus, cette fonction find peut fonctionner non seulement sur des tranches, mais aussi en même temps sur un Vec ou un Array.

Pour exécuter les tests bonus, retire l'attribut `#[ignore]` et exécute les tests avec la fonctionnalité `generic`, comme ceci :

```bash
$ cargo test --features generic
```
