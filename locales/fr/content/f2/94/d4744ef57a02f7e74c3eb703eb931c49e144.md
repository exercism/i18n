# Instructions

Dans cet exercice, on va implémenter certaines règles du [Blackjack][blackjack], comme la manière dont le jeu se joue et dont on compte les points.

**Note** : dans cet exercice, _`A`_ désigne l'as, _`J`_ le valet, _`Q`_ la dame et _`K`_ le roi.
Les jokers sont écartés.
On suppose un [jeu standard de 52 cartes aux enseignes françaises][standard_deck], mais dans la plupart des versions, plusieurs jeux sont mélangés ensemble pour jouer.

## 1. Calcule la valeur d'une carte

Au Blackjack, c'est à chaque joueur de décider si un as vaut 1 ou 11 points (_on y reviendra plus tard_).
Les figures (`J`, `Q`, `K`) valent 10 points, et toute autre carte vaut sa valeur « pip » (_numérique_).

Définis la fonction `value_of_card(<card>)` avec le paramètre `card`.
La fonction doit renvoyer la _valeur numérique_ de la _string_ passée en argument.
Comme un as peut prendre plusieurs valeurs (1 **ou** 11), cette fonction doit fixer pour l'instant la valeur d'un as à 1.
Plus tard, tu implémenteras une fonction qui détermine la valeur d'un as à partir d'une main existante.

```python
>>> value_of_card('K')
10

>>> value_of_card('4')
4

>>> value_of_card('A')
1
```

## 2. Détermine quelle carte a la valeur la plus élevée

Définis la fonction `higher_card(<card_one>, <card_two>)` avec les paramètres `card_one` et `card_two`.
Pour le calcul des points, la valeur de `J`, `Q` ou `K` est 10.
La fonction doit renvoyer la carte qui a la valeur la plus élevée pour le calcul des points.
Si les deux cartes ont la même valeur, renvoie les deux.
On peut renvoyer les deux cartes en utilisant une virgule dans l'instruction `return` :

```python
# Using a comma in a return creates a Tuple.  Tuples will be covered in a later exercise.
>>> def returning_two_values(value_one, value_two):
        return value_one, value_two

>>> returning_two_values('K', '3')
('K', '3')
```

Un as peut prendre plusieurs valeurs, donc pour cette tâche, on fixera la valeur des cartes `A` à 1.

```python
>>> higher_card('K', '10')
('K', '10')

>>> higher_card('4', '6')
'6'

>>> higher_card('K', 'A')
'K'
```

## 3. Calcule la valeur d'un as

Comme on l'a mentionné plus haut, un as peut valoir _soit_ 1 **soit** 11 points.
Les joueurs essaient de s'approcher le plus possible de 21 points, sans aller _au-delà_ de 21 (ce qu'on appelle « sauter »).

Définis la fonction `value_of_ace(<card_one>, <card_two>)` avec les paramètres `card_one` et `card_two`, qui sont deux cartes déjà présentes dans la main _avant_ de recevoir un as.
Ta fonction devra décider si l'as à venir vaudra 1 ou 11, et renvoyer cette valeur.
Rappelle-toi : la valeur de la main avec l'as doit être aussi élevée que possible _sans_ dépasser 21.

**Indice** : si on a déjà un as en main, la valeur de l'as à venir sera de 1.

```python
>>> value_of_ace('6', 'K')
1

>>> value_of_ace('7', '3')
11
```

## 4. Détermine une main « natural » ou « blackjack »

Si un joueur reçoit un as (`A`) et une carte de dix (10, `K`, `Q` ou `J`) comme deux premières cartes, il obtient un score de 21.
On parle alors d'une main **blackjack**.


Définis la fonction `is_blackjack(<card_one>, <card_two>)` avec les paramètres `card_one` et `card_two`, qui sont deux cartes.
Détermine si cette main de deux cartes est un **blackjack**, et renvoie le booléen `True` si c'est le cas, `False` sinon.

**Note** : le _calcul_ du score peut se faire de plusieurs façons.
Mais si possible, on aimerait que tu vérifies s'il y a un as et une carte de dix **_dans_** la main (_ou à une certaine position_), plutôt que de _sommer_ les valeurs de la main.

```python
>>> is_blackjack('A', 'K')
True

>>> is_blackjack('10', '9')
False
```

## 5. Sépare les paires

Si les deux premières cartes d'une main ont la même valeur (_par exemple, deux six, ou un `Q` et un `K`_), un joueur peut choisir de les traiter comme deux mains distinctes.
C'est ce qu'on appelle « séparer les paires ».

Définis la fonction `can_split_pairs(<card_one>, <card_two>)` avec les paramètres `card_one` et `card_two`, qui sont deux cartes.
Détermine si cette main de deux cartes peut être séparée en deux paires.
Si la main peut être séparée, renvoie le booléen `True`, sinon renvoie `False`.

```python
>>> can_split_pairs('Q', 'K')
True

>>> can_split_pairs('10', 'A')
False
```

## 6. Double la mise

Quand les deux cartes distribuées au départ totalisent 9, 10 ou 11 points, un joueur peut placer une mise supplémentaire égale à sa mise d'origine.
C'est ce qu'on appelle « doubler la mise ».

Définis la fonction `can_double_down(<card_one>, <card_two>)` avec les paramètres `card_one` et `card_two`, qui sont deux cartes.
Détermine si on peut doubler la mise sur cette main de deux cartes, et renvoie le booléen `True` dans ce cas, `False` sinon.

```python
>>> can_double_down('A', '9')
True

>>> can_double_down('10', '2')
False
```
