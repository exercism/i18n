# À propos

Les chaînes de caractères sont un type de données qui représente une valeur textuelle.
Les [`Strings`][strings-and-characters] en Swift sont une collection de `Character`s, qui contiennent eux-mêmes une [valeur scalaire Unicode][unicode-scalar-values].

Tu peux créer une _string_ à l'aide d'un littéral de chaîne, qui est une suite de caractères entourée de guillemets doubles (`"`).
Pour les chaînes sur plusieurs lignes, tu peux utiliser des guillemets triples (`"""`).

```swift
let hello : String = "Hello, World!"

let poem : String = """
Roses are red,
Violets are blue.
Sugar is sweet,
And so are you.
"""
```

En Swift, les _strings_ héritent aussi de toutes les fonctionnalités de la classe [NSString][nsstring-docs], qui était utilisée à l'origine dans les bibliothèques Objective-C d'Apple.

## Character

`Character` est un type de données qui stocke une seule [valeur scalaire Unicode][unicode-scalar-values], elle-même composée d'un ou plusieurs points de code Unicode.
Une valeur scalaire Unicode est n'importe quel point de code [Unicode][unicode] compris entre `U+0000` et `U+D7FF` inclus, ou entre `U+E000` et `U+10FFFF` inclus.

```swift
let aChar : Character = "A"
```

## Inférence de type

Swift peut inférer le type d'un littéral de chaîne, et le considérera par défaut comme une `String`.
Tu peux déclarer explicitement une _string_ comme étant un `Character` grâce à l'annotation de type `Character`, ce qui impose que la valeur soit un seul caractère.

```swift
let aString = "A"
let aChar: Character = "A"
print(type(of: aString)) // Prints String
print(type(of: aChar))   // Prints Character

// The following code will not compile
let badChar: Character = "Too many characters"
// Error: Cannot convert value of type 'String' to specified type 'Character'
```

## Concaténation

En Swift, les _strings_ peuvent être [concaténées][concatenated] avec l'opérateur `+`.
Les `Character` ne peuvent **pas** être concaténés avec des _strings_ à l'aide de l'opérateur `+` sans d'abord convertir le caractère en _string_.

```swift
print("honey" + "comb")
// Prints "honeycomb"
```

La méthode [`append(_:)`][append] modifie la _string_ en ajoutant une _string_ ou un caractère à sa fin.

```swift
var greeting = "Hello"
let world = ", world"
let period: Character = "."

greeting.append(world)
print(greeting) // Prints "Hello, world"

greeting.append(period)
print(greeting) // Prints "Hello, world."
```

## Interpolation de _string_

L'[interpolation de _string_][string-interpolation] est une façon de construire une `String` à partir de valeurs venant de sources différentes, comme des variables et des expressions.
Pour insérer une valeur dans une _string_ par interpolation, tu places une expression ou une valeur entre parenthèses, précédées d'un antislash.

```swift
let radius = 5.0
let circle = "The area of a circle with radius \(radius) is \(Double.pi * radius * radius)"
print(circle) // Prints "The area of a circle with radius 5.0 is 78.53981633974483"
```

## Propriétés de _string_ et de `Character`

Les _strings_ et les `Character` possèdent quelques _propriétés_ différentes que l'on peut interroger pour obtenir des informations sur la _string_ ou le caractère.

### Propriétés de _string_

Voici quelques-unes des propriétés de _string_ les plus courantes ; pour les trouver toutes, consulte la [documentation][string-docs].

| Propriété | Description                                    | Exemple                        |
| --------- | ---------------------------------------------- | ------------------------------ |
| `isEmpty` | Renvoie `true` si la _string_ est vide         | `"Hello".isEmpty equals false` |
| `count`   | Renvoie le nombre de caractères dans la _string_ | `"Hello".count   equals 5`     |

### Propriétés de `Character`

Voici quelques-unes des propriétés de `Character` les plus courantes ; pour les trouver toutes, consulte la [documentation][string-docs].

| Propriété      | Description                                      | Exemple                        |
| -------------- | ------------------------------------------------ | ------------------------------ |
| `isLowercase`  | Renvoie `true` si le caractère est en minuscule  | `"a".isLowercase  equals true` |
| `isUppercase`  | Renvoie `true` si le caractère est en majuscule  | `"A".isUppercase  equals true` |
| `isNumber`     | Renvoie `true` si le caractère est un chiffre    | `"1".isNumber     equals true` |
| `isWhitespace` | Renvoie `true` si le caractère est un espace     | `" ".isWhitespace equals true` |

## Conversion de type

Pour convertir un type en _string_, tu peux utiliser l'initialiseur `String()`, qui accepte divers types, dont `Int`, `Double`, `Character`, et d'autres encore.

```swift
let charX: Character = "x"
print(String(charX))     // Prints "x"
print(String(110))       // Prints "110"
print(String(Double.pi)) // Prints "3.141592653589793"
```

## Caractères spéciaux

Swift dispose de quelques [caractères spéciaux][special-characters] utilisables dans les _strings_.

| Valeur   | Description                   |
| -------- | ----------------------------- |
| `\0`     | Caractère nul                 |
| `\\`     | Antislash                     |
| `\t`     | Tabulation horizontale        |
| `\n`     | Saut de ligne                 |
| `\r`     | Retour chariot                |
| `\'`     | Guillemet simple              |
| `\"`     | Guillemet double              |
| `\uFFFF` | Caractère Unicode hexadécimal |

```swift
let quote : String = "\"Hello\", he said."
print(quote) // Prints "Hello", he said.

let unicode : Character = "\u{1F496}"
print(unicode) // Prints 💖
```
