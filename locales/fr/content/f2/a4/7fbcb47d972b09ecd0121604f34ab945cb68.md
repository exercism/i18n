# Instructions complémentaires

## Indices

Pour terminer cet exercice, tu dois créer le type de données `BST`,
avec des instances `Eq` et `Show`, et implémenter les fonctions :

- `bstLeft`
- `bstRight`
- `bstValue`
- `empty`
- `fromList`
- `insert`
- `singleton`
- `toList`

Tu trouveras une déclaration de données factice et des signatures de type déjà en place,
mais c'est à toi de définir les fonctions et de créer un type de données,
un newtype ou un synonyme de type qui a du sens.
