# Consignes

Tu es un observateur d'oiseaux passionné qui garde la trace du nombre d'oiseaux ayant visité ton jardin.
D'habitude, tu tiens le compte des oiseaux à l'aide de bâtons dans un carnet, mais pour mieux exploiter tes données, tu as numérisé les comptages d'oiseaux des dernières semaines.

## 1. Détermine le nombre total d'oiseaux que tu as comptés jusqu'ici

Commençons par analyser les données en prenant un peu de hauteur.
Détermine combien d'oiseaux tu as comptés au total depuis que tu as commencé tes relevés.

Implémente une fonction `totalBirdCount` qui prend un tableau de `Int`s contenant le nombre d'oiseaux comptés par jour.
Elle doit renvoyer le nombre total d'oiseaux que tu as comptés.

```swift
let birdsPerDay = [2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1]
totalBirdCount(birdsPerDay)
// Returns 34
```

## 2. Calcule le nombre d'oiseaux qui ont visité ton jardin pendant une semaine donnée

Maintenant que tu as une idée générale de tes comptages d'oiseaux, tu veux faire une analyse plus fine.

Implémente une fonction `birdsInWeek` qui prend un tableau du nombre d'oiseaux comptés par jour ainsi qu'un numéro de semaine.

Elle renvoie le nombre total d'oiseaux que tu as comptés au cours de cette semaine précise.
Tu peux supposer que les semaines sont toujours suivies en entier.

```swift
let birdsPerDay = [2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1]
birdsInWeek(birdsPerDay, weekNumber: 2)
// Returns 12
```

## 3. Corrige une erreur de comptage

Tu t'es rendu compte que pendant tout le temps où tu essayais de suivre les oiseaux, l'un d'eux se cachait dans un coin éloigné du jardin.

Tu as compris que cet oiseau passait toujours un jour sur deux dans ton jardin.

Tu ne sais pas exactement où il se trouvait entre ces jours-là, mais en tout cas pas dans ton jardin.

Ton intuition d'observateur d'oiseaux te dit aussi que l'oiseau était dans ton jardin le premier jour que tu as relevé dans ta liste.

Avec ces nouvelles informations, écris une fonction `fixBirdCountLog` qui prend en argument un tableau du nombre d'oiseaux comptés par jour et qui renvoie le tableau après avoir corrigé l'erreur de comptage.

```swift
var birdsPerDay = [2, 5, 0, 7, 4, 1]
fixBirdCountLog(birdsPerDay)
// Returns [3, 5, 1, 7, 5, 1]
```
