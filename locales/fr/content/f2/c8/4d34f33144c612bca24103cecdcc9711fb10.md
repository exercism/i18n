# Introduction

Un `vector` en Clojure est une collection séquentielle, indexée et immuable de zéro ou plusieurs valeurs. Cela signifie qu'une fois qu'un _vector_ a été créé, il ne peut plus être modifié. Les fonctions qui agissent sur les _vectors_ renvoient un nouveau _vector_, tandis que le _vector_ d'origine reste inchangé. Les valeurs d'un _vector_ peuvent être de types hétérogènes. On peut définir un _vector_ comme ceci :

```clojure
(def empty [])
(def single-value 5)
(def single-value-alternative (vector 5))
(def three-values [a b c]
```

On peut récupérer les éléments d'un _vector_ à l'aide d'un indice. Les _vectors_ de Clojure sont indexés à partir de zéro, ce qui signifie que l'indice du premier élément est toujours zéro :

```clojure
(def numbers [2 3 5])
;; Read value from vector
(get numbers 2)
;;=> 5
;; Update value in vector
(assoc numbers 2 9)
;;=> [2 3 9]
```

Le _vector_ d'origine reste inchangé :

```clojure
numbers
;;=> [2 3 5]
```

Pour se souvenir de la valeur mise à jour, il faut la transmettre ou la capturer dans un _var_ :

```clojure
(def updated-numbers
  (assoc numbers 2 9))
(get updated-numbers 2)
;;=> 9
```
