# Introduction

Quand on ne connaît pas à l'avance le nombre d'itérations d'une boucle, c'est-à-dire quand on veut « continuer tant qu'un prédicat reste vrai », Factor utilise le combinateur `while` de [`kernel`][kernel] :

```
while ( pred body -- )
```

`pred` et `body` sont tous les deux des _quotations_ qui opèrent sur la pile de données. `while` appelle `pred` ; si `pred` laisse une valeur vraie au sommet de la pile, `while` exécute `body` et recommence ; sinon, la boucle s'arrête. L'état qui passe d'une itération à la suivante vit sur la pile entre les appels (ou dans des variables locales nommées quand il y a plus d'une valeur à conserver).

```factor
USING: kernel math ;

5 [ dup 0 > ] [ dup . 1 - ] while drop
! prints 5 4 3 2 1
```

`until` est la forme symétrique : elle continue *jusqu'à* ce que le prédicat devienne vrai.

[kernel]: https://docs.factorcode.org/content/vocab-kernel.html
