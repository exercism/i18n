# Introduction

Le `when` de Kotlin est une expression conditionnelle qui permet de choisir parmi plusieurs options. Il s'apparente au `switch` de Java, et il est plus souple qu'une chaîne de `if` ... `else if` ... `else`.

Comme `if`, `when` peut aussi s'utiliser comme une expression qui produit une valeur.

## Faire correspondre une valeur

Donne à `when` une valeur à comparer, entre parenthèses. Chaque branche compare cette valeur jusqu'à ce que l'une d'elles corresponde :

```kotlin
val animal = "chicken"
val type = when (animal) {
    "chicken" -> "bird"
    "poodle" -> "dog"
    else -> "unknown"
}
// type => "bird"
```

- Chaque branche s'écrit `pattern -> result`.
- Les branches sont essayées de haut en bas jusqu'à ce qu'une correspondance soit trouvée.
  Seule la première branche s'exécute.
- Utilise `else` pour toute valeur qui ne figure pas au-dessus (comme le `else` final d'une chaîne de `if`).

C'est le principe du [filtrage par motifs][pattern-matching].
Le `pattern` peut être une valeur à comparer, ou bien utiliser `is` pour faire correspondre par type :

```kotlin
fun typeText(subject: Any): String {
    return when(subject) {
        is Animal -> "Animal"
        is Fruit -> "Fruit"
        is String -> "Text"
        else -> "Unknown"
    }
}
```

ou `in` pour vérifier que la valeur est contenue dans un intervalle, une collection, une chaîne ou n'importe quoi d'autre doté d'une méthode `contains` :

```kotlin
fun describe(number: Int, position: String) {
    // Range
    when(number) {
        in 1..10 -> println("From 1 to 10")
        in 11..20 -> println("From 11 to 20")
    }

    // Collection
    when(number) {
        in listOf(2, 4, 6) -> println("small even")
        in listOf(3, 5, 7) -> println("small odd")
    }

    // String
    when(position) {
        in "center middle" -> println("inner")
        in "left right boundary" -> println("outer")
    }
}
```

~~~exercism/note
Tu peux aussi utiliser `in` avec d'autres objets en définissant la [fonction d'extension d'opérateur][kotlin-operator-overloading] `contains`.
Par exemple, avec [Regex][kotlin-regex] :

```kotlin
operator fun Regex.contains(text: CharSequence): Boolean = this.matches(text)

fun replace(input: String) {
    return when(input) {
        in Regex("""ani*""") -> println("animal")
        in Regex("""fru.*""") -> println("fruit")
        in Regex("""num.*""") -> println("number")
        else -> println("unknown")
    }
}
```

## Conditions de garde

Quand on fait correspondre une valeur, on peut ajouter des conditions supplémentaires dans un `if` après le motif.
Ces conditions s'appellent des conditions de garde.

```kotlin
val x = 5
val y = 10
val description = when (x) {
    5 if y % 2 == 0 -> "x is 5, y is even"
    else -> "other"
}
// description => "x is 5, y is even"
```

On peut même utiliser `else if`.

```kotlin
val x = 7
val y = 10
val description = when (x) {
    5 if y % 2 == 0 -> "x is 5, y is even"
    else if y % 2 == 0 -> "y is an even number"
    else -> "other"
}
// description => "y is an even number"
```


## Faire correspondre des conditions

Autre possibilité : on peut omettre la valeur et placer une condition booléenne sur chaque branche :

```kotlin
val x = 5
val y = 8
val description = when {
    x % 2 != 0 -> "x is odd"
    y % 2 == 0 -> "y is even"
    else -> "neither condition matched first"
}
// description => "x is odd"
```

Là encore, les branches sont examinées de haut en bas et seule la première dont la condition vaut `true` s'exécute.

## Utiliser `when` comme expression

Quand on utilise `when` pour son résultat (affecté à une variable, renvoyé par une fonction, etc.), tous les cas possibles doivent être couverts.

- Quand on fait correspondre une valeur, ajoute `else` sauf si toutes les valeurs possibles sont déjà traitées (par exemple toutes les valeurs d'un `Boolean` ou d'une `enum`).
- Quand on fait correspondre des conditions, une branche `else` est obligatoire, car le compilateur ne peut pas savoir que tes conditions couvrent tous les cas.

```kotlin
fun label(n: Int): String = when (n) {
    0 -> "zero"
    1 -> "one"
    else -> "other"
}
```
