# À propos

Une chaîne de caractères est le type de données JavaScript qui permet de stocker du texte.
Il n'existe pas de type de données distinct pour un caractère individuel.

## Créer une _string_

On crée une _string_ [littérale][literal] en entourant le texte de guillemets simples ou doubles.
Sur Exercism, on utilise les guillemets simples.

<!-- prettier-ignore-start -->
```javascript
'Hello, World!'
"Hello, World!"
```
<!-- prettier-ignore-end -->

Certains caractères spéciaux du texte doivent être précédés d'une barre oblique inversée `\`, voir les [séquences d'échappement sur MDN][mdn-escape-sequences].

<!-- prettier-ignore-start -->
```javascript
const text = 'I\'m having fun.\nWhat about you?';
console.log(text);
// => I'm having fun.
// => What about you?
```
<!-- prettier-ignore-end -->

En plus des guillemets simples et doubles, on peut aussi créer une _string_ en entourant le texte d'accents graves.
Cette syntaxe permet d'inclure des guillemets simples ou doubles, et même des retours à la ligne, sans avoir besoin de les échapper.
Elle permet aussi d'intégrer des expressions, voir les [_template strings_][mdn-template-strings] pour plus de détails.

```javascript
`A multi-line string
with 'single quotes'
and "double quotes"`;
```

## Les _strings_ comme tableaux de caractères

On peut considérer une _string_ comme un tableau de caractères dont le premier caractère a pour indice `0`.
Tu peux accéder à un caractère individuel de la _string_ à l'aide de crochets et de l'indice de la lettre que tu veux récupérer.
Sinon, il y a aussi la méthode `charAt`.

```javascript
'cat'[1];
// => 'a'

'cat'.charAt(2);
// => 't'
```

On peut déterminer le nombre de caractères d'une _string_ en accédant à la propriété `length`.

```javascript
'cat'.length;
// => 3
```

## Concaténation et méthodes

La façon la plus simple de concaténer des _strings_ est d'utiliser l'opérateur d'addition `+`.

```javascript
'I like' + ' ' + 'cats.';
// => "I like cats."
```

Les _strings_ offrent de nombreuses méthodes utilitaires, voir la [documentation MDN sur les méthodes de String][mdn-string-methods] pour une liste complète.
La liste suivante présente quelques-unes de ces méthodes utilitaires courantes.

- [`toUpperCase`][mdn-to-upper-case] et [`toLowerCase`][mdn-to-lower-case] : changer la casse de tous les caractères
- [`trim`][mdn-trim] : supprimer les espaces au début et à la fin
- [`includes`][mdn-includes], [`startsWith`][mdn-starts-with] et [`endsWith`][mdn-ends-with] : déterminer si une autre _string_ fait partie de la _string_ donnée
- [`slice`][mdn-slice] : extraire une portion de la _string_

## Les _strings_ sont immuables

Appliquer les méthodes ci-dessus ne modifie jamais la _string_ d'origine. À la place, une nouvelle _string_ est créée et renvoyée.
Les _strings_ (et les autres types de données primitifs) sont immuables en JavaScript.
Cela signifie aussi que tu ne peux pas affecter un caractère différent à un indice donné avec la syntaxe à crochets montrée plus haut (comme tu le ferais dans un tableau).

```javascript
const str = 'cat';
str[1] = 'u'; // fails silently
console.log(str);
// => 'cat'
```
