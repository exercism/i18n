# Ajout aux instructions

## Astuces

Pour venir à bout de cet exercice, tu dois créer le type de données `Matrix`,
avec les instances `Eq` et `Show`, et implémenter les fonctions suivantes :

- `cols`
- `column`
- `flatten`
- `fromList`
- `fromString`
- `reshape`
- `row`
- `rows`
- `shape`
- `transpose`

Tu trouveras une déclaration de données factice et les signatures de type
déjà en place, mais c'est à toi de définir les fonctions et de créer un type
de données, un _newtype_ ou un synonyme de type qui a du sens.

Aucune validation de l'entrée n'est requise. Laisse échouer si la matrice
n'est pas rectangulaire, si des caractères invalides sont rencontrés, etc.

shape est (rows, cols)
