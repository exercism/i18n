# Introduction

Un type de données algébrique (ADT) représente un nombre fixe de cas nommés.
Chaque valeur d'un ADT correspond à exactement un de ces cas nommés.

Un ADT se définit à l'aide du mot-clé `data`, ses cas étant séparés par le caractère pipe (`|`).
Si aucun des cas ne porte de donnée associée, l'ADT est semblable à ce que d'autres langages appellent généralement une énumération (ou _enum_).

```haskell
data Season
  = Spring
  | Summer
  | Autumn
  | Winter
```

Chaque cas d'un ADT peut éventuellement porter une donnée associée, et différents cas peuvent porter différents types de données.
Lorsqu'un cas porte une donnée associée, un constructeur est nécessaire.

```haskell
data Number
  = NInt Int      --'NInt' is the constructor for an Int Number.
  | NFloat Float  --'NFloat' is the constructor for an Float Number.
  | Invalid       --'Invalid' does not have data associated to it.
```

Créer une valeur pour un cas donné se fait en référençant son nom (par exemple, `NInt 22`).
Comme les noms de cas ne sont que des fonctions constructrices, la donnée associée peut être passée comme un argument de fonction ordinaire.

Les ADT ont une _égalité structurelle_, ce qui signifie que deux valeurs du même cas, avec les mêmes données (optionnelles), sont équivalentes.

Bien que l'on puisse utiliser des expressions `if/else` pour manipuler les ADT, la manière recommandée de les traiter est le filtrage par motifs à l'aide de l'instruction _case_ :

```haskell
add1 :: Number -> String
add1 number =
    case number of
      NInt    i -> show (i + 1)
      NFloat  f -> show (f + 1.0)
      Invalid   -> error "Invalid input"
```
