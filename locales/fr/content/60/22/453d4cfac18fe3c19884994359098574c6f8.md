# Introduction

## Comparaison

En Go, on peut comparer des nombres à l'aide des opérateurs relationnels et d'égalité suivants.

| Comparaison       | Opérateur |
| ------------------| --------- |
| égal              | `==`      |
| différent         | `!=`      |
| inférieur         | `<`       |
| inférieur ou égal | `<=`      |
| supérieur         | `>`       |
| supérieur ou égal | `>=`      |

Le résultat de la comparaison est toujours une valeur booléenne, donc soit `true`, soit `false`.

```go
a := 3

a != 4 // true
a > 5  // false
```

Les opérateurs de comparaison ci-dessus peuvent aussi servir à comparer des _strings_.
Dans ce cas, c'est l'ordre lexicographique (celui du dictionnaire) qui s'applique.
Par exemple :

```Go
	"apple" < "banana"  // true
	"apple" > "banana"  // false
```

## Les instructions `if`

En Go, les conditionnelles sont semblables à celles des autres langages.
Le type sous-jacent de toute opération conditionnelle est le type `bool`, qui peut valoir `true` ou `false`.
Les conditionnelles servent souvent de mécanismes de contrôle du flux pour vérifier diverses conditions.

Pour vérifier un cas particulier, on peut utiliser une instruction `if`, qui exécute son code si la condition sous-jacente est `true`, comme ceci :

```go
var value string

if value == "val" {
    return "was val"
}
```

Lorsqu'il y a plus d'un cas à traiter, on peut enchaîner plusieurs instructions `if` à l'aide des instructions `else if` et `else`.

```go
var number int
result := "This number is "

if number > 0 {
    result += "positive"
} else if number < 0 {
    result += "negative"
} else {
    result += "zero"
}
```

Les instructions `if` peuvent aussi comporter une courte instruction d'initialisation, qui permet d'initialiser une ou plusieurs variables pour l'instruction if.
Par exemple :

```go
num := 7
if v := 2 * num; v > 10 {
    fmt.Println(v)
} else {
    fmt.Println(num)
}
// Output: 14
```

> Remarque : toute variable créée dans l'instruction d'initialisation sort de la portée après la fin de l'instruction if.
