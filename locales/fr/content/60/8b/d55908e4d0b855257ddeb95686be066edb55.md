# Introduction

Un [`Attribute` C#](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/attributes/) permet de décorer une déclaration afin de lui associer des métadonnées : une classe, une méthode, une énumération, un champ, une propriété ou toute autre déclaration [prise en charge](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/attributes/#attribute-targets).

Tu peux appliquer un attribut en l'ajoutant sur la ligne qui précède la déclaration, à l'aide d'un `ClassAttribute` et d'un `FieldAttribute` :

```csharp
[Class]
class MyClass
{
    [Field]
    int myField;
}
```

Ces métadonnées déclaratives ne font qu'associer des informations structurées supplémentaires au code et ne modifient pas son comportement, mais elles sont utilisées par d'autres parties du code pour changer le comportement de leur cible, ou pour ajouter, modifier, supprimer ou restreindre certaines de ses fonctionnalités.

Il existe de nombreux [attributs prédéfinis et réservés](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/attributes/general#conditional-attribute), par exemple : `Flags`, `Obsolete`, `Conditional`, chacun ayant une signification précise que l'on peut consulter dans la documentation C#. Note que le nom complet d'un attribut comme [`Flags`](https://docs.microsoft.com/en-us/dotnet/api/system.flagsattribute) est `FlagsAttribute` par convention, mais que le suffixe _Attribute_ peut être omis lorsqu'il est appliqué sur une déclaration.
