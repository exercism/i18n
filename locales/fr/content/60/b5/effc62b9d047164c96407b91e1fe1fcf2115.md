# Astuces

## Général

- Lis la documentation sur les protocoles dans le [guide officiel Getting Started][getting-started-protocols] ou sur [elixirschool.com][elixir-school-protocols].

## 1. Définis la comestibilité

- Il existe une [macro spéciale][kernel-defprotocol] pour définir des protocoles.
- Un protocole se compose d'un ou plusieurs en-têtes de fonction.
- Un en-tête de fonction ressemble à une définition de fonction, mais sans le bloc `do`. Il définit le nom de la fonction et ses arguments, mais pas ce qu'elle fait.

## 2. Rends les miches de pain comestibles

- Il existe une [macro spéciale][kernel-defimpl] pour implémenter un protocole pour un type de données donné.
- Implémenter un protocole consiste à écrire une définition de fonction pour chaque en-tête de fonction du protocole.

## 3. Rends les potions de mana comestibles

- Il existe une [macro spéciale][kernel-defimpl] pour implémenter un protocole pour un type de données donné.
- Implémenter un protocole consiste à écrire une définition de fonction pour chaque en-tête de fonction du protocole.

## 4. Rends les poisons comestibles

- Il existe une [macro spéciale][kernel-defimpl] pour implémenter un protocole pour un type de données donné.
- Implémenter un protocole consiste à écrire une définition de fonction pour chaque en-tête de fonction du protocole.
