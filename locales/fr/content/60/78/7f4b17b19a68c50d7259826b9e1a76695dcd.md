# Indices

## Général

- Lis la documentation officielle sur les [intervalles][range].

## 1. Définis l'intervalle des rangées

- Il y a un [opérateur spécial][range-creation-operator] pour créer des intervalles.

## 2. Définis l'intervalle des colonnes

- Il y a un [opérateur spécial][range-creation-operator] pour créer des intervalles.
- Il y a une [syntaxe spéciale][unicode-code-points] pour écrire le point de code d'un caractère sans connaître explicitement sa valeur.

## 3. Transforme l'intervalle des rangées en un tableau de rangées

- Les intervalles implémentent le protocole `Enumerable`.
- Il y a une [fonction intégrée][enum-to-list] pour convertir une structure de données énumérable en un tableau.

## 4. Transforme l'intervalle des colonnes en un tableau de colonnes

- Les intervalles implémentent le protocole `Enumerable`.
- Il y a une [fonction intégrée][enum-map] pour convertir une structure de données énumérable en un tableau tout en modifiant ses éléments.
- La [forme spéciale bitstring][bitstring-special-form] peut être utilisée pour transformer un point de code en _string_.
