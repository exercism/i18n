# À propos

L'énumération consiste à parcourir une collection (`Array`, `Hash`, etc.) et à effectuer une action sur chaque objet.

L'énumération est un concept clé en Ruby et sert au tri (`sort_by`), au regroupement (`group_by`), à la transformation (`map`), à la réduction (`reduce`), et bien plus encore.
Tu verras le plus souvent l'énumération comme la façon idiomatique de parcourir des collections plutôt que de recourir à des boucles.

Une énumération simple pour afficher chaque mot d'un tableau ressemblerait à ceci :

```ruby
words = %w[the cat sat on the mat]
words.each do |word|
  puts word
end

# Output:
# the
# cat
# sat
# on
# the
# mat
```

Dans cet exemple, on a appelé la méthode `Array#each` et on lui a passé un _bloc_, qui prend un paramètre (`word`) et l'affiche.

On peut aussi chaîner les méthodes énumérables.
Par exemple, on peut chaîner `.with_index` après `each` pour afficher à la fois l'indice d'un objet et sa valeur :

```ruby
words = %w[the cat sat on the mat]
list = words.map.with_index { |word, index| "#{index}. #{word}" }
puts list

# Output:
# 0. the
# 1. cat
# ...
# 5. mat
```

Énumérer des objets `Hash` est exactement la même chose qu'énumérer des objets `Array`, sauf que le bloc reçoit deux arguments, la clé et la valeur :

```ruby
pet_names = {cat: "bob", horse: "caris", mouse: "arya"}
words.each { |animal, name| ... }

# The two arguments should be put in brackets when chaining
words.each.with_index { |(animal, name), index| ... }
```

Les méthodes décrites ci-dessus font partie du [module `Enumerable`][enumerable-module], qui est inclus dans `Array`, `Hash` et d'autres classes qui ont besoin de pouvoir énumérer.

[enumerable-module]: https://docs.ruby-lang.org/en/master/Enumerable.html
