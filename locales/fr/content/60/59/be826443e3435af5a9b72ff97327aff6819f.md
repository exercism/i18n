# Tests

Si le binaire phix se trouve dans ton PATH, saisis la commande :

```bash
p test 
```
Cela exécutera le fichier de test (test.exw).

Si le binaire phix n'est pas dans le PATH, sous Windows, saisis :

```cmd
\path\to\p.exe test
```

Sous Linux :

```bash
/path/to/p test
```

## Tests ignorés

Pour résoudre un exercice, il faut faire passer tous ses tests.
Par défaut, tous les tests du fichier test.exw sont exécutés.
Pour ignorer un test, ajoute deux tirets (le marqueur de commentaire standard en Phix) au début de la ligne.

À noter que les tests ne tiennent aucun compte des indicateurs include=false dans tests.toml ; c'est à l'auteur de test.exw de les maintenir manuellement dans ce fichier pour refléter la réalité, au bénéfice du site Exercism (par exemple pour la collecte des statistiques du parcours), mais rien dans le parcours lui-même ne les utilise, y compris le générateur de tests et l'exécuteur de tests.
