# Indices

## Généralités

- Les mots de lecture se trouvent dans [`io`][io] ; les constructeurs de _string-stream_ et `with-string-writer` se trouvent dans [`io.streams.string`][io.streams.string].
- Pour la tâche de vidage du _writer_, les variables locales (`::` et `:>`) gardent le corps lisible lorsqu'on doit toucher le même flux deux fois.

## 1. Écoute tout

- Un seul mot : `stream-contents`.

## 2. Compte les messages

- `stream-lines` découpe le flux en un tableau de lignes ; `length` renvoie le nombre.

## 3. Renvoie le dernier appel

- Le même `stream-lines` que ci-dessus, puis `last`, puis `>upper` (depuis `ascii`).

## 4. Diffuse un message

- `stream-write` écrit le message, `stream-flush` le pousse à l'extérieur. Le _writer_ est utilisé deux fois, alors utilise des variables locales `::` : `:: broadcast ( message writer -- ) message writer stream-write
  writer stream-flush ;`.

## 5. Capture la sortie d'une _quotation_

- Un seul mot : `with-string-writer`. Ajoute `inline` après le `;` fermant pour que le compilateur puisse voir à travers l'argument _quotation_ : `: capture ( quot -- captured ) with-string-writer ; inline`.
