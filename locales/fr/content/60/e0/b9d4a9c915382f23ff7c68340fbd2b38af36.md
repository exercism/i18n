# Mots-clés statiques de classe

Une classe est une unité d'organisation du code en PHP, qui représente souvent une instance d'une chose, d'un service ou d'une procédure.
Grâce aux mots-clés `static` et `self`, les propriétés et les méthodes peuvent exister en référence à la classe pour toutes les instances (ou aucune instance).

```php
<?php

class Book
{
    static $genre = 'Adventure';

    static function getGenre()
    {
        return self::$genre;
    }
}

// Usage
$genre = Book::$genre;
$genre = Book::getGenre();
```

## Limites

Les méthodes statiques de classe ne peuvent appeler que d'autres propriétés statiques ou méthodes de classe de leur propre classe.

```php
<?php

class Book
{
    $name = 'Treasure Island';

    static function getName()
    {
        // This static method cannot access the instance variable
        return $this->name;
    }
}
```
