# Instructions

Dans cet exercice, tu vas écrire du code pour aider un freelance à communiquer avec ses clients au sujet des tarifs de certains projets. Tu vas écrire quelques fonctions utilitaires pour calculer rapidement les coûts pour les clients.

## 1. Calculer le tarif journalier à partir d'un tarif horaire

Un client contacte le freelance pour se renseigner sur ses tarifs.
Le freelance lui explique qu'il **_travaille 8 heures par jour._**
Cependant, le freelance ne connaît que son tarif horaire pour le projet.
Aide-le à estimer un tarif journalier à partir d'un tarif horaire.

Implémente la fonction `dailyRateFrom(hourlyRate:)`, qui prend l'argument `hourlyRate` contenant le tarif horaire du freelance.  
La fonction doit renvoyer le tarif journalier calculé à partir du tarif horaire.

```swift
dailyRateFrom(hourlyRate: 60)
// Returns 480.0
```

Le tarif journalier renvoyé doit être un `Double`.

## 2. Calculer le tarif mensuel à partir d'un tarif horaire et d'une remise

Il arrive qu'un client souhaite engager le freelance pour une période plus longue.
Le freelance est prêt à accorder une remise au client, mais seulement si celui-ci l'engage pour au moins un mois.
Il y a en tout **_22 jours travaillés_**.
Aide le freelance à calculer son tarif mensuel, arrondi à l'entier le plus proche, à partir de son tarif horaire et du pourcentage de remise qu'il est prêt à accorder sur le tarif plein.

Implémente la fonction `monthlyRateFrom(hourlyRate:withDiscount:)`, qui prend les arguments `hourlyRate`, le tarif horaire du freelance, et `withDiscount`, la remise que le freelance est prêt à accorder au client.
La fonction doit renvoyer le tarif mensuel arrondi à l'entier le plus proche.

```swift
monthlyRateFrom(hourlyRate: 77, withDiscount: 10.5)
// Returns 12129
```

## 3. Calculer le nombre de jours travaillés à partir d'un budget, d'un tarif horaire et d'une remise

Un autre jour, un chef de projet propose au freelance de travailler sur un projet avec un budget fixe.
Étant donné le budget fixe et le tarif horaire du freelance, aide-le à calculer le nombre de jours qu'il travaillerait jusqu'à épuisement du budget.
Tiens compte du fait que dans ce scénario, le freelance est toujours prêt à accorder la remise, quel que soit le nombre de jours travaillés.
Le résultat _doit_ être **arrondi à l'entier inférieur**.

Implémente la fonction `workdaysIn(budget:hourlyRate:withDiscount:)`, qui prend les arguments :
- `budget`, le budget du projet.
- `hourlyRate`, le tarif horaire du freelance.
- `withDiscount`, la remise que le freelance est prêt à accorder au client.

La fonction doit renvoyer le nombre de jours travaillés du freelance sur le projet, arrondi à l'entier inférieur.

```swift
workdaysIn(budget: 20000, hourlyRate: 80, withDiscount: 11.0)
// Returns 35.0
```
