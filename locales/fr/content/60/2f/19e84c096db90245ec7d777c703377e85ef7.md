# Indices

## Général

- Pour en savoir plus sur les [erreurs][errors], consulte le guide de démarrage.
- Pour en savoir plus sur [`try`][docs-try], consulte la documentation.

## 1. Préviens l'équipe

- Laisse la fonction d'opération lever son erreur.
- Pour appeler une fonction contenue dans une variable, utilise l'opérateur `.`.

## 2. Encapsule l'erreur

- Utilise try .. rescue pour renvoyer le résultat attendu.

## 3. Transmets le message

- Utilise try .. rescue pour renvoyer le résultat attendu.
- Le bloc rescue te permet de faire du _pattern matching_ sur le nom du module de l'erreur et aussi de lier l'erreur à une variable.
