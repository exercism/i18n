## Structure du projet

-   `contracts` - code source de tous les contrats intelligents du projet et de leurs dépendances. Tu ne dois modifier que le fichier contracts/template.fc.
-   `wrappers` - classes enveloppes (implémentant `Contract` de ton-core) pour les contrats, y compris toutes les primitives de [dé]sérialisation et les fonctions de compilation.
-   `tests` - tests des contrats.
-   `scripts` - scripts utilisés par le projet, principalement les scripts de déploiement.
