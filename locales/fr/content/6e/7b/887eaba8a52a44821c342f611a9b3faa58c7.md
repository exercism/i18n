# Instructions

Implémente une fonction qui, à partir de deux points du plan cartésien 2D, produit un troisième point tel que le triangle formé par ces points soit équilatéral. La fonction renverra deux points, car il existe deux « troisièmes » points possibles qui forment un triangle équilatéral à partir des deux points initiaux. Il convient de noter qu'un triangle équilatéral est une figure à trois côtés dont les trois côtés sont de même longueur.

La fonction prend en entrée deux tuples Python, chacun spécifiant les coordonnées x et y d'un point, sous forme de nombres à virgule flottante. Par exemple, (0.0, 0.0) et (1.0, 1.0) peuvent être passés en entrée.

La fonction doit renvoyer un tuple composé de deux tuples, chacun spécifiant les coordonnées x et y d'un point, sous forme de nombres à virgule flottante. Par exemple, ((0.0, 0.0), (1.0, 1.0)) pourrait être une sortie possible.

La fonction doit lever l'exception Python native ArithmeticError si le solveur Z3 produit un résultat qui n'est pas satisfiable. Une ArithmeticError doit également être levée si les deux points d'entrée sont identiques.

La fonction ne doit pas utiliser la fonction « set_option() » de la bibliothèque z3 pour définir des paramètres globaux. Cette configuration est faite dans les cas de test afin de garantir que les nombres à virgule flottante ont la précision attendue (nombre de décimales).

Comme l'interprétation du modèle d'une variable Real de Z3 est une instance de AlgebraicNumRef, IntNumRef ou RatNumRef, une fonction est fournie pour convertir cette instance en nombre à virgule flottante.
