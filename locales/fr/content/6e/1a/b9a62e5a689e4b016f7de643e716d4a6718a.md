# Introduction

## La nullabilité

En C#, le littéral `null` sert à indiquer l'absence de valeur. Un type _nullable_ est un type qui autorise les valeurs `null`.

Avant C# 8.0, les types de référence étaient toujours nullables et les types valeur ne l'étaient pas. On peut rendre un type valeur nullable en lui ajoutant un point d'interrogation (`?`).

```csharp
string nullableReferenceType = "hello";
nullableReferenceType = null; // Valid as type is nullable

int nonNullableValueType = 5;
nonNullableValueType = null; // Compile error as type is not nullable

int? nullableValueType = 5; // Define nullable value type
nullableValueType = null;   // Valid as type is nullable
```

Accéder au membre d'une variable nulle ne provoque pas d'erreur de compilation, mais entraîne le déclenchement d'une `NullReferenceException` à l'exécution :

```csharp
string sentence = null;

// Throws NullReferenceException at runtime
sentence.Length;
```

Pour contrer ce type d'erreur courant, C# 8 permet d'activer une fonctionnalité qui rend les types de référence non nullables par défaut :

```csharp
string nonNullableReferenceType = "book";
nonNullableReferenceType = null; // Compile warning (no error!)

string? nullableReferenceType = "movie";
nullableReferenceType = null; // Valid as type is nullable
```

Pour manipuler des valeurs nullables en toute sécurité, on vérifie si elles sont `null` avant de les utiliser :

```csharp
string NormalizedName(string? name)
{
    if (name == null)
    {
        return "UNKNOWN";
    }

    // Value is not null at this point, so no compile warning
    // and no runtime NullReferenceException being thrown
    return name.ToUpper();
}

NormalizedName(null); // => "UNKNOWN"
NormalizedName("Elisabeth"); // => "ELISABETH"
```

L'opérateur `??` permet de renvoyer une valeur par défaut lorsque la valeur est `null` :

```csharp
string? name1 = "John";
name1 ?? "Paul"; // => "John"

string? name2 = null;
name2 ?? "George"; // => "George"
```

L'opérateur `?.` permet d'appeler des membres en toute sécurité sur une valeur qui peut être `null` :

```csharp
string? fruit = "apple";
fruit?.Length; // => 5

string? vegetable = null;
vegetable?.Length; // => null
```
