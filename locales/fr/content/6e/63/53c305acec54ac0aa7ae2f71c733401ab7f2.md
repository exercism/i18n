# Instructions

Dans cet exercice, on va implémenter un ensemble partiel de routines utilitaires pour aider un développeur à nettoyer des noms d'identifiants.

Au fil des 6 tâches, tu construiras progressivement les fonctions `transform`, qui convertit des caractères isolés, et `clean`, qui convertit des _strings_.

Un identifiant valide se compose de zéro ou plusieurs lettres, tirets bas, tirets, points d'interrogation et emojis.

Si une _string_ vide est passée à la fonction `clean`, une _string_ vide doit être renvoyée.

## 1. Remplace tous les tirets rencontrés par des tirets bas

Implémente la fonction `transform` pour remplacer tous les tirets par des tirets bas.

```fsharp
transform '-'  // => "_"
```

## 2. Supprime tous les espaces

Supprime tous les caractères d'espacement, y compris ceux en début et en fin de _string_.

```fsharp
transform ' '  // => ""
```

## 3. Convertis du `camelCase` en `kebab-case`

Modifie la fonction `transform` pour convertir du `camelCase` en `kebab-case`.

```fsharp
transform 'D'  // => "-d"
```

## 4. Omets les caractères qui sont des chiffres

Modifie la fonction `transform` pour omettre tout caractère numérique.

```fsharp
transform '7'  // => ""
```

## 5. Remplace les lettres grecques minuscules par des points d'interrogation

Modifie la fonction `transform` pour remplacer toutes les lettres grecques comprises entre 'α' et 'ω'.

```fsharp
transform 'β' // => "?"
```

## 6. Combine ces opérations pour les appliquer à une _string_

Implémente la fonction `clean` pour appliquer ces opérations à une _string_ entière.

Les caractères qui ne relèvent pas de ces règles doivent rester inchangés.

```fsharp
clean "  a2b Cd-ω😀  " //  => "ab-cd_?😀"
```

## Assemble une _string_ à partir de caractères

Ce sujet sera traité en détail plus tard dans le programme.

Pour l'instant, il peut être utile de savoir qu'il existe une [fonction d'ordre supérieur][higher-order-function] appelée [`String.collect`][string-collect], qui convertit une collection de `char`s en une _string_, à l'aide d'une fonction que tu fournis.

```fsharp
let transform ch = $"{ch}_"
String.collect transform "abc"  // =>  "a_b_c_"
```
