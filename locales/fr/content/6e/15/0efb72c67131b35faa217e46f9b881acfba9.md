# Introduction

En JavaScript, les valeurs peuvent être de différents types. On peut changer le type d'une variable par une _conversion de type_ explicite.
En plus de cela, JavaScript effectue aussi une _coercition de type_ (conversion de type implicite) quand le contexte l'exige.

## Conversion de type

Contrairement à beaucoup d'autres langages, JavaScript n'a pas de construction permettant de convertir une valeur vers un autre type, mais on peut utiliser à la place certains utilitaires intégrés.
En particulier, `Boolean`, `Number` et `String` peuvent être utilisés comme des fonctions pour convertir une valeur vers le type correspondant.

### Convertir en booléen (valeurs _truthy_/_falsy_)

Avec `Boolean(value)`, tu peux convertir n'importe quelle valeur en booléen.
Il existe un ensemble fixe de valeurs, appelées valeurs _falsy_, qui sont converties en `false`.
En particulier, `false`, `0`, une _string_ vide, `null`, `undefined` et `NaN` sont _falsy_.

Pour toutes les autres valeurs, `Boolean` renvoie `true`.
Ces valeurs sont dites _truthy_.

```javascript
Boolean(-1);
// => true

Boolean(0);
// => false

Boolean(' ');
// => true

Boolean('');
// => false
```

Note que, d'après les règles décrites, `'0'`, `'false'`, `[]` et `{}` sont **truthy** en JavaScript.

### Convertir en nombre

On peut utiliser `Number(value)` pour convertir une valeur en nombre.
Les espaces au début et à la fin d'une _string_ sont ignorés, et une _string_ vide est convertie en `0`.
Si tu essaies de convertir une valeur non primitive ou une _string_ qui ne représente pas un nombre, le résultat est `NaN` ([Not-A-Number][mdn-nan]).

```javascript
Number('  -12.34  ');
// => -12.34

Number('1,2');
// => NaN

Number('');
// => 0

Number({ num: 123 });
// => NaN
```

### Convertir en _string_

Avec `String(value)`, tu peux convertir une valeur en _string_.
Pour les valeurs primitives, le résultat est celui auquel on s'attend.

```javascript
String(12.34);
// => '12.34'

String(false);
// => 'false'

String(null);
// => 'null'

String(undefined);
// => 'undefined'
```

Pour les tableaux, la fonction `String` applique la conversion en _string_ à chaque élément, puis joint les résultats avec une virgule.
Tu peux aussi appliquer toi-même la [méthode `join`][mdn-join], par exemple pour personnaliser le séparateur.
Note que dans ces cas, `null` et `undefined` sont convertis en une _string_ vide.

```javascript
String([42, null, true, 'abc']);
// => '42,,true,abc'
```

Pour les objets, `String` renvoie par défaut un texte peu utile.

```javascript
String({ key: 'value' });
// => '[object Object]'
```

## Coercition de type

Dans certains contextes, JavaScript convertit automatiquement une valeur en un autre type de données avant d'évaluer une instruction.
Cette conversion implicite s'appelle la _coercition de type_.

### Contexte booléen

Quand une valeur non booléenne est utilisée dans un contexte booléen, JavaScript applique les mêmes règles que la fonction `Boolean` pour la convertir implicitement.

La coercition en booléen se produit couramment pour

- la condition d'une [instruction `if`][concept-conditionals]
- le premier opérande de l'[opérateur ternaire][mdn-ternary] `?`
- l'opérande de l'opérateur de négation logique `!`
- les opérandes des opérateurs ET logique `&&` et OU logique `||` (le résultat de l'expression est l'un des opérandes, pas nécessairement un booléen)

```javascript
const num = 0;
if (num) {
  // this block is NOT executed because 0 is falsy
}
```

### Contexte de _string_

Si l'opérateur d'addition `+` est utilisé avec des valeurs primitives et qu'un opérande est une _string_, l'autre est lui aussi converti en _string_.
La logique de conversion est la même que celle de la fonction `String`.
Ensuite, les deux _strings_ sont concaténées.

```javascript
let name;
'hello ' + name;
// => 'hello undefined'
```

### Contexte numérique

De nombreux opérateurs convertissent les opérandes en nombres (si nécessaire) selon la logique de la fonction `Number` expliquée plus haut.

- Opérateurs arithmétiques : `+` (si aucune _string_ n'est impliquée), `-`, `*`, `/`, `%`, `**`
- Opérateurs unaires plus et négation unaire : `+`, `-`
- Opérateurs relationnels (pour des opérandes non _string_) : `>`, `>=`, `<`, `<=`
- Opérateurs bit à bit : `|`, `&`, `^`, `~`

Consulte la [liste des opérateurs sur MDN][mdn-operators] pour plus de détails sur chacun de ces opérateurs.

Pour éviter les erreurs, il est recommandé d'appeler explicitement `Number` avant d'appliquer ces opérateurs.
