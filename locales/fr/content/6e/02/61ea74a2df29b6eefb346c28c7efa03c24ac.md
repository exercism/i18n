# Introduction

En Common Lisp, une fonction peut avoir des arguments optionnels, désignés dans la liste lambda par le mot-clé de liste lambda `&optional`.
Un paramètre est lié à la valeur `nil` s'il n'est pas spécifié.
S'il y a plusieurs paramètres optionnels, ils sont liés dans l'ordre.
On peut spécifier des valeurs par défaut pour les paramètres optionnels.
Enfin, on peut spécifier un symbole pour chaque paramètre optionnel ; ce symbole sera lié à vrai ou faux selon que ce paramètre a été fourni ou non par l'appelant de la fonction (c'est ce qu'on appelle le « paramètre _supplied-p_ »).

```lisp
(defun optional-parameters (&optional x (y 'default) (z nil z-supplied-p))
  (list x y (if z-supplied-p (list :z-was-supplied z)
                             (list :z-was-not-supplied z))))

(optional-parameters)          ; => (NIL DEFAULT (:Z-WAS-NOT-SUPPLIED NIL))
(optional-parameters 5 nil 10) ; => (5 NIL (:Z-WAS-SUPPLIED 10))
```
