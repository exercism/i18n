## Messages d'exception

Il est parfois nécessaire de [lever une exception](https://docs.python.org/3/tutorial/errors.html#raising-exceptions). Dans ce cas, il faut toujours inclure un **message d'erreur explicite** pour indiquer l'origine de l'erreur. Cela rend le code plus lisible et facilite grandement le débogage. Lorsque tu sais que l'origine de l'erreur sera d'un certain type, tu peux choisir de lever l'un des [types d'erreur intégrés](https://docs.python.org/3/library/exceptions.html#base-classes), mais il faut quand même inclure un message explicite.

Cet exercice demande d'utiliser l'[instruction `raise`](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement) pour « lever » une `ValueError` si l'on passe à la fonction `classify()` un nombre qui n'est pas un _entier positif_. Les tests ne réussiront que si tu utilises `raise` sur l'`exception` et que tu y ajoutes un message.

Pour lever une `ValueError` avec un message, écris le message comme argument passé au type `exception` :

```python
# if a number to be classified is less than 1.
raise ValueError("Classification is only possible for positive integers.")
```
