# Ajout aux instructions

~~~~exercism/note

La description ci-dessus mentionne les [_ensembles mathématiques_][math-sets], mais aussi qu'un triplet pythagoricien {a, b, c} _**doit**_ être ordonné de telle sorte que a < b < c (_ordre croissant_). 

Cela rend le type [`set`][python-sets] de Python inadapté à cet exercice, puisqu'il est par nature _non ordonné_. 
Il vaut mieux renvoyer une [`list`][python-list] de `list`s (_par exemple `[[a, b, c]]`_). 
Tu peux générer les triplets eux-mêmes dans l'ordre que tu veux, car l'ordre de la `list` englobante sera ignoré dans les tests. 

[math-sets]: https://en.wikipedia.org/wiki/Set_(mathematics)
[python-sets]: https://docs.python.org/3/tutorial/datastructures.html#sets
[python-list]: https://docs.python.org/3/tutorial/datastructures.html#more-on-lists
