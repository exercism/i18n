# Instructions

Dans cet exercice, tu vas implémenter la logique de quête d'un nouveau jeu de rôle qu'un ami est en train de développer. Le personnage principal du jeu est Annalyn, une jeune fille courageuse accompagnée d'un chien féroce et fidèle. Malheureusement, le malheur frappe : sa meilleure amie a été enlevée alors qu'elle cherchait des baies dans la forêt. Annalyn va tenter de retrouver et de libérer sa meilleure amie, en emmenant éventuellement son chien avec elle dans cette quête.

Après avoir suivi pendant un moment la piste de sa meilleure amie, elle trouve le camp dans lequel celle-ci est emprisonnée. Il s'avère qu'il y a deux ravisseurs : un puissant chevalier et un archer rusé.

Ayant trouvé les ravisseurs, Annalyn réfléchit aux actions suivantes qu'elle peut entreprendre :

- Attaque rapide : une attaque rapide est possible si le chevalier dort, car il lui faut du temps pour enfiler son armure, ce qui le rend vulnérable.
- Espionnage : on peut espionner le groupe si au moins l'un d'eux est éveillé. Sinon, espionner est une perte de temps.
- Signaler le prisonnier : on peut signaler le prisonnier à l'aide de sons d'oiseaux si le prisonnier est éveillé et que l'archer dort, car les archers sont formés au langage des oiseaux et pourraient donc intercepter le message.
- _Libérer le prisonnier_ : Annalyn peut tenter de se faufiler dans le camp pour libérer le prisonnier.
  C'est une entreprise risquée, qui ne peut réussir que de deux façons :
  - Si Annalyn est accompagnée de son chien, elle peut sauver le prisonnier tant que l'archer dort.
    Le chevalier a peur du chien et l'archer n'aura pas le temps de se préparer avant qu'Annalyn et le prisonnier ne s'échappent.
  - Si Annalyn n'a pas son chien, elle et le prisonnier doivent alors être très discrets !
    Annalyn peut libérer le prisonnier si celui-ci est éveillé et que le chevalier et l'archer dorment tous les deux, mais si le prisonnier dort, il ne peut pas être sauvé : il serait surpris par l'apparition soudaine d'Annalyn et réveillerait le chevalier et l'archer.

Tu as quatre tâches : implémenter la logique qui détermine si les actions ci-dessus sont disponibles, en fonction de l'état des trois personnages trouvés dans la forêt et de la présence ou non du chien d'Annalyn.

## 1. Vérifier si une attaque rapide est possible

Implémente la méthode `canFastAttack()` qui prend une valeur booléenne indiquant si le chevalier est éveillé. Cette méthode renvoie `true` si une attaque rapide est possible selon l'état du chevalier. Sinon, elle renvoie `false` :

```kotlin
val knightIsAwake = true

canFastAttack(knightIsAwake)
// => false
```

## 2. Vérifier si le groupe peut être espionné

Implémente la méthode `canSpy()` qui prend trois valeurs booléennes indiquant respectivement si le chevalier, l'archer et le prisonnier sont éveillés. La méthode renvoie `true` si le groupe peut être espionné, selon l'état des trois personnages. Sinon, elle renvoie `false` :

```kotlin
val knightIsAwake = false
val archerIsAwake = true
val prisonerIsAwake = false

canSpy(knightIsAwake, archerIsAwake, prisonerIsAwake)
// => true
```

## 3. Vérifier si le prisonnier peut être signalé

Implémente la méthode `canSignalPrisoner()` qui prend deux valeurs booléennes indiquant respectivement si l'archer et le prisonnier sont éveillés. La méthode renvoie `true` si le prisonnier peut être signalé, selon l'état des deux personnages. Sinon, elle renvoie `false` :

```kotlin
val archerIsAwake = false
val prisonerIsAwake = true

canSignalPrisoner(archerIsAwake, prisonerIsAwake)
// => true
```

## 4. Vérifier si le prisonnier peut être libéré

Implémente la méthode `canFreePrisoner()` qui prend quatre valeurs booléennes. Les trois premiers paramètres indiquent respectivement si le chevalier, l'archer et le prisonnier sont éveillés. Le dernier paramètre indique si le chien d'Annalyn est présent. La méthode renvoie `true` si le prisonnier peut être libéré, selon l'état des trois personnages et la présence du chien d'Annalyn. Sinon, elle renvoie `false` :

```kotlin
val knightIsAwake = false
val archerIsAwake = true
val prisonerIsAwake = false
val petDogIsPresent = false

canFreePrisoner(knightIsAwake, archerIsAwake, prisonerIsAwake, petDogIsPresent)
// => false
```
