# Introduction

Une *expression régulière* (regex) est un petit motif qui décrit à quoi un texte doit ressembler. Au lieu de vérifier toi-même une _string_ caractère par caractère, tu écris une fois la forme souhaitée et tu laisses Factor faire la correspondance. Les outils de regex de Factor se trouvent dans le vocabulaire [`regexp`][regexp].

## Écris un motif

En Factor, tu écris une regex entre `R/ ` et `/` :

```factor
R/ cat/      ! the pattern that matches the letters c, a, t
```

La plupart des caractères d'un motif se contentent de se représenter eux-mêmes : `R/ cat/` correspond au texte `cat`. Toute la puissance vient de quelques éléments particuliers qui représentent des *sortes* de caractères ou *combien* de fois ils apparaissent.

### Classes de caractères : « un caractère d'un ensemble »

```
\d        ! any digit, 0–9
\D        ! any NON-digit (the opposite of \d)
\s        ! any space, tab, or newline
\S        ! any NON-space character (the opposite of \s)
\w        ! a "word" character: a letter, a digit, or an underscore
\W        ! any NON-word character (the opposite of \w)
[A-Z]     ! any one capital letter A to Z
[a-z]     ! any one lowercase letter
[0-9]     ! any one digit (same as \d)
.         ! any single character at all
```

Une classe correspond à exactement *un* caractère. `[A-Z]` correspond à `Q` mais pas à `QQ`.

### Quantificateurs : « combien de fois »

Place l'un de ces éléments *après* un fragment pour indiquer combien de fois il peut se répéter :

```
{4}       ! exactly 4 times
{2,5}     ! between 2 and 5 times
+         ! one or more
*         ! zero or more
?         ! zero or one (optional)
```

Ainsi, `\d{4}` signifie quatre chiffres d'affilée, et `[A-Z]+` signifie une ou plusieurs lettres majuscules. En assemblant le tout, `R/ [A-Z]+-\d+/` décrit « une ou plusieurs majuscules, un tiret, puis un ou plusieurs chiffres », autrement dit un texte comme `SALE-2024`. Ici, le `-` est un caractère ordinaire : en dehors de `[ ]`, un tiret correspond simplement à un tiret (à l'intérieur d'une classe, comme dans `[A-Z]`, il marque une plage).

## Fais correspondre une _string_ entière

`matches?` répond à la question « est-ce que cette _string_ *entière* correspond au motif ? » : le motif doit rendre compte de chaque caractère, du début à la fin :

```
matches? ( string regexp -- ? )
```

```factor
USING: regexp ;

"SALE-2024"     R/ [A-Z]+-\d+/ matches? .   ! => t
"GET SALE-2024" R/ [A-Z]+-\d+/ matches? .   ! => f   (extra text before)
"SALE-2024 NOW" R/ [A-Z]+-\d+/ matches? .   ! => f   (extra text after)
"sale-2024"     R/ [A-Z]+-\d+/ matches? .   ! => f   (lowercase letters)
```

Même si `SALE-2024` se trouve à l'intérieur de `"GET SALE-2024"`, `matches?` renvoie quand même `f` : les caractères supplémentaires font partie de la _string_ et ne correspondent pas au motif. Quand tu veux seulement savoir si le motif apparaît *quelque part*, utilise `re-contains?` ; il renvoie `t` exactement là où `matches?` a renvoyé `f` :

```
re-contains? ( string regexp -- ? )
```

```factor
USING: regexp ;

"GET SALE-2024" R/ [A-Z]+-\d+/ matches? .      ! => f
"GET SALE-2024" R/ [A-Z]+-\d+/ re-contains? .  ! => t
```

## Trouve les correspondances dans un texte plus long

`re-contains?` te dit seulement *si* le motif est présent. Les mots suivants regardent à l'intérieur et indiquent *ce qui* a correspondu : `all-matching-subseqs` renvoie chaque endroit où le motif correspond, sous forme de séquence de _strings_, et `count-matches` se contente de les compter :

```
all-matching-subseqs ( string regexp -- seq )
count-matches        ( string regexp -- n )
```

```factor
USING: regexp ;

"3 cats, 12 dogs, 1 fish" R/ \d+/ all-matching-subseqs .
! => { "3" "12" "1" }            (every run of digits)

"the quick fox" R/ \S+/ all-matching-subseqs .
! => { "the" "quick" "fox" }     (every run of non-space characters)

"id_7!" R/ \w/ count-matches .   ! => 4   (i, d, _ and 7 count; ! does not)
```

## Remplace les correspondances

`re-replace` remplace chaque correspondance par un texte de remplacement et renvoie la nouvelle _string_ :

```
re-replace ( string regexp replacement -- result )
```

```factor
USING: regexp ;

"page 7 of 12" R/ \d+/ "N" re-replace .
! => "page N of N"
```

Le vocabulaire `regexp` contient d'autres mots qu'il vaut la peine de connaître : suis les liens pour plus de détails, [`first-match`][first-match] (uniquement la première correspondance) et [`re-split`][re-split] (découper une _string_ partout où le motif correspond).
