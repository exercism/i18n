# Tests

Exécute les tests avec :

```shell
npm run test
```

Tu peux aussi lancer Jest en mode « watch », ce qui relancera automatiquement tes tests à chaque fois que tu enregistres des modifications dans le code ou dans le module de test :

```shell
npm run watch
```

## Comprendre les tests ignorés

La méthode _skip_ indique à la suite de tests de ne pas exécuter un test. Cette fonction peut aussi être utilisée sous les alias : `it.skip(name, fn)`, `xit(name, fn)` ou `xtest(name, fn)`

- Pourquoi sont-ils ignorés ?

Pour permettre de se concentrer sur un seul test à la fois et de les activer un par un au fur et à mesure que la solution évolue.

- Comment les activer ?

Remplace `xtest` par `test`.

```javascript
test("title cased phrases", () => {
  expect(Acronyms.parse("Portable Network Graphics")).toEqual("PNG");
});
```
