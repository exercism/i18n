# À propos

En Go, les fonctions sont des valeurs de première classe.
Cela signifie que tu peux faire avec les fonctions les mêmes choses qu'avec toutes les autres valeurs : les affecter à des variables, les passer en arguments à d'autres fonctions, ou même renvoyer des fonctions depuis d'autres fonctions.

Ci-dessous, on crée deux fonctions, `engGreeting` et `espGreeting`, et on les affecte à la variable `greeting` :

```go
import "fmt"

func engGreeting(name string) string {
	return fmt.Sprintf("Hello %s, nice to meet you!", name)
}

func espGreeting(name string) string {
	return fmt.Sprintf("¡Hola %s, mucho gusto!", name)
}

greeting := engGreeting			// greeting is a variable of type func(string) string
fmt.Println(greeting("Alice"))	// Hello Alice, nice to meet you!

greeting = espGreeting
fmt.Println(greeting("Alice")) 	// ¡Hola Alice, mucho gusto!
```

Les valeurs de fonction permettent de paramétrer une fonction non seulement avec des données, mais aussi avec du comportement.
Dans l'exemple suivant, on passe du comportement à la fonction `dialog` via le paramètre `greetingFunc` :

```go
func dialog(name string, greetingFunc func(string) string) {
	fmt.Println(greetingFunc(name))
	fmt.Println("I'm a dialog bot.")
}

func espGreeting(name string) string {
	return fmt.Sprintf("¡Hola %s, mucho gusto!", name)
}

greeting := espGreeting
dialog("Alice", greeting)
// Output:
// ¡Hola Alice, mucho gusto!
// I'm a dialog bot.
```

La valeur d'une variable non initialisée de type fonction est `nil`.
Par conséquent, appeler une valeur de fonction `nil` provoque un panic.

```go
var dutchGreeting func(string) string
dutchGreeting("Alice") // panic: call of nil function
```

Les valeurs de fonction peuvent être comparées à `nil`.
Cela peut être utile pour éviter des panics inutiles dans le programme.

```go
var dutchGreeting func(string) string
if dutchGreeting != nil {
	dutchGreeting("Alice") // safe to call dutchGreeting
}
```

## Types de fonction

L'utilisation des valeurs de fonction est possible grâce aux types de fonction en Go.
Un type de fonction désigne l'ensemble des fonctions qui ont la même séquence de types de paramètres et la même séquence de types de résultat.
On peut déclarer des types définis par l'utilisateur à partir des types de fonction.
Par exemple, la fonction `dialog` des exemples précédents peut être mise à jour comme suit :

```go
type greetingFunc func(string) string

func dialog(name string, f greetingFunc) {
	fmt.Println(f(name))
	fmt.Println("I'm a dialog bot.")
}
```

## Fonctions anonymes

Un autre outil puissant rendu possible par la prise en charge des fonctions de première classe, ce sont les fonctions anonymes.
Les fonctions anonymes sont définies là où elles sont utilisées, sans nom après le mot-clé `func`.
Ces fonctions ont accès aux variables de la fonction qui les englobe.

Par exemple :

```go
func fib() func() int {
	var n1, n2 int

	return func() int {
		if n1 == 0 && n2 == 0 {
			n1 = 1
		} else {
			n1, n2 = n2, n1 + n2
		}
		return n2
	}
}

next := fib()
for i := 0; i < N; i++ {
  fmt.Printf("F%d\t= %4d\n", i, next())
}
```

Un appel à `fib` déclare les variables `n1` et `n2` et renvoie une fonction anonyme qui, à son tour, modifie les valeurs de ces variables à chaque fois que la fonction est appelée.
Le Nième appel de la fonction anonyme renvoie le Nième nombre de la suite de Fibonacci, en partant de 0. La fonction interne anonyme a accès aux variables locales (`n1` et `n2`) de la fonction englobante `fib`.
C'est un excellent moyen de faire en sorte que les valeurs de fonction conservent un état entre les appels.
On dit que la fonction anonyme est une fermeture sur les variables `n1` et `n2`.
Les fermetures sont largement utilisées en programmation, et tu verras peut-être d'autres langages les prendre en charge.
