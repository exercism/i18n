# Ajout aux instructions

## Registres

| Registre | Utilisation | Type        | Description                                    |
| -------- | ----------- | ----------- | ---------------------------------------------- |
| `$a0`    | entrée      | adresse     | chaîne de caractères binaires terminée par un caractère nul |
| `$v0`    | sortie      | entier      | valeur décimale de la chaîne d'entrée          |
| `$t0-9`  | temporaire  | quelconque  | utilisés pour le stockage temporaire           |
