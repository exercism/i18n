# Indices

À moins d'être vraiment à l'aise avec les expressions régulières, il peut être utile de tester la syntaxe dans un bac à sable en ligne comme [Regex101][regex101].

Pense à sélectionner la variante PCRE2.

Prédéfinir chaque expression régulière dans une `const` peut être une bonne pratique de style (pour la clarté et les performances).

## 1. Vérifie que la commande est valide

- Le caractère d'ancrage pour le début de la chaîne est `^`.
- Tu as seulement besoin d'un vrai ou d'un faux renvoyé par la recherche de l'expression régulière.
- Ce problème pourrait se résoudre sans expression régulière, mais reste dans l'esprit d'un exercice d'apprentissage.

## 2. Supprime les émojis chiffrés

- Un simple [`replace()`][replace].

## 3. Vérifie que le numéro de téléphone est valide

- Il faut une expression régulière plus longue, mais assez répétitive.
- `n` occurrences consécutives peuvent être spécifiées avec la syntaxe `{n}`.
- On a seulement besoin d'un vrai ou d'un faux pour la correspondance.

## 4. Récupère le lien du site web

- N'oublie pas d'échapper le point avec `\.`
- Capture la partie avant le point dans un [match][match].

## 5. Salue l'utilisateur

- Un `replace()` avec des captures nommées a le format `r"(?<name>...) " => s"\g<name>... "`
- Là encore, un `split()` pourrait résoudre la tâche, mais s'entraîner avec une expression régulière est utile.
