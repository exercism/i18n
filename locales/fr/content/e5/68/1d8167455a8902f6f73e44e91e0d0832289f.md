# Tests

Pour chaque exercice, il faut suivre les étapes générales suivantes.

Tout d'abord, place-toi dans le répertoire de l'exercice sur lequel tu veux t'entraîner, ici `bob`.

```bash
$ cd </path/to/exercism>/lfe/bob
```

Ensuite, lance les tests. La cible `test` de make dépend de `compile`, donc lancer `make test` garantit que ton code source est compilé, puis passe à l'exécution des tests.


```bash
$ make test
```

Félicitations ! Tu as des tests qui échouent !!!

Maintenant, lis le `README.md` pour découvrir ce que tu dois faire pour que tous tes tests passent.


Corrige la première erreur signalée par le test, puis relance les tests.

```bash
$ make test
```

Continue en corrigeant le test suivant qui échoue dans ton code source, et en relançant tes tests jusqu'à ce qu'ils passent tous.

Une fois que tous tes tests passent, jette un dernier coup d'œil à ton code dans le répertoire `src` pour t'assurer que tu en es satisfait, puis soumets-le pour revue.

Reçois des retours, révise ta solution, soumets-la, essaie l'exercice suivant, et recommence jusqu'à ce que tu atteignes l'illumination LFE.
