# Introduction

## Syntaxe générale

La boucle _for_ est l'une des instructions les plus couramment utilisées pour exécuter une logique de manière répétée.
En Go, elle se compose du mot-clé `for`, d'un en-tête et d'un bloc de code qui contient le corps de la boucle entouré d'accolades.
L'en-tête se compose de 3 composants séparés par des points-virgules `;` : init, condition et post.

```go
for init; condition; post {
  // loop body - code that is executed repeatedly as long as the condition is true
}
```

- Le composant **init** est du code qui s'exécute une seule fois avant le début de la boucle.
- Le composant **condition** doit être une expression qui s'évalue en un booléen et qui contrôle le moment où la boucle doit s'arrêter.
  Le code à l'intérieur de la boucle s'exécute tant que cette condition est vraie.
  Dès que cette expression est fausse, plus aucune itération de la boucle ne s'exécute.
- Le composant **post** est du code qui s'exécute à la fin de chaque itération.

**Remarque :** Contrairement à d'autres langages, il n'y a pas de parenthèses `()` autour des trois composants de l'en-tête.
En fait, insérer de telles parenthèses est une erreur de compilation.
Cependant, les accolades `{ }` qui entourent le corps de la boucle sont toujours obligatoires.

## Boucles _for_ - un exemple

Le composant init initialise généralement une variable compteur, le composant condition vérifie si la boucle doit continuer ou s'arrêter et le composant post incrémente généralement le compteur à la fin de chaque répétition.

```go
for i := 1; i < 10; i++ {
  fmt.Println(i)
}
```

Cette boucle affiche les nombres de `1` à `9` (`9` compris).
Définir le pas se fait souvent à l'aide d'une instruction d'incrémentation ou de décrémentation, comme le montre l'exemple ci-dessus.
