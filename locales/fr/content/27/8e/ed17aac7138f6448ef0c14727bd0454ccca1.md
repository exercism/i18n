# Introduction

Le type `atom` d'Elixir représente une constante fixe. La valeur d'un atome est simplement son propre nom, ce qui offre un moyen d'interagir avec les données qui est sûr au niveau des types. Les atomes peuvent être définis comme suit :

```elixir
# All atoms are preceded with a ':' then follow with alphanumeric snake-cased characters
variable = :an_atom
```

En interne, les _atomes_ sont représentés par un entier dans une table de correspondance, dont les entiers sont attribués automatiquement. Il n'est pas possible de modifier cette valeur interne.
