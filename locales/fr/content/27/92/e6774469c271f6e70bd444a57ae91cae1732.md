# Introduction

Les maps en Elixir sont la structure de données qui permet de stocker des informations sous forme de paires clé-valeur. Dans d'autres langages, on les connaît aussi sous le nom de tableaux associatifs (PHP), de hashes (Perl 5, Raku) ou de dictionnaires (Python).

Les clés et les valeurs peuvent être de n'importe quel type de données, mais lorsque la clé est un atome, on peut utiliser une syntaxe abrégée. Les maps ne garantissent pas l'ordre de leurs entrées lorsqu'on y accède ou qu'on les renvoie.

## Formes littérales

Une map vide se déclare simplement avec `%{}`. Pour ajouter des éléments à une map littérale, on peut utiliser deux formes :

```elixir
# If the key is an atom:
%{atom_key: 1}

# If the key is a different type:
%{1 => :atom_value}

# You can even mix these if the atom form comes second:
%{"first_form" => :a, atom_form: :b}
```

Bien qu'il n'existe pas de format canonique, choisis une manière cohérente de représenter les paires clé-valeur littérales.

## Fonctions du module Map

Elixir fournit de nombreuses fonctions pour manipuler les maps dans le _module Map_. Certaines fonctions du _module Map_ nécessitent qu'on leur passe une fonction _anonyme_ pour faciliter la transformation de la map.
