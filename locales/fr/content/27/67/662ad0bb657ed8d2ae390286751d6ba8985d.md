# Introduction

La possibilité pour quelque chose de se définir en termes de lui-même s'appelle la récursion. En F#, la récursion se rencontre le plus souvent dans les fonctions récursives, qui sont des fonctions qui s'appellent elles-mêmes.

Une fonction récursive doit avoir au moins un _cas de base_ et au moins un _cas récursif_. Un _cas de base_ renvoie une valeur sans rappeler la fonction. Un _cas récursif_ rappelle la fonction, en modifiant l'entrée pour qu'elle finisse par correspondre au cas de base.

Les fonctions récursives se définissent comme des fonctions classiques, mais avec le modificateur `rec`. Sans ce modificateur, une fonction ne pourra _pas_ s'appeler elle-même et toute tentative en ce sens provoquera une erreur de compilation. Il faut donc choisir explicitement d'utiliser la récursion.

```fsharp
let rec factorial x =
    // Base case
    if x = 1 then
        1
    // Recursive case
    else
        x * factorial (x - 1)
```

F# prend également en charge les types récursifs grâce aux types d'union discriminée. Dans un type d'union discriminée récursif, un ou plusieurs des cas font référence au type d'union discriminée lui-même dans leurs données. Comme les fonctions récursives, les types récursifs doivent avoir un cas de base. Contrairement aux fonctions récursives, les types récursifs n'utilisent pas le mot-clé `rec`.

```fsharp
type RussianDoll =
    | Doll                 // Base case
    | Layer of RussianDoll // Recursive case
```
