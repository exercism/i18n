# Introduction

En Go, `map` est un type de données intégré qui associe des clés à des valeurs.
Dans d'autres langages de programmation, tu connais peut-être le concept de `map` sous les noms de dictionnaire, table de hachage, magasin clé/valeur ou tableau associatif.

Syntaxiquement, `map` ressemble à ceci :

```go
map[KeyType]ElementType
```

Il est aussi important de savoir que chaque clé est unique, ce qui signifie qu'affecter deux fois la même clé écrase la valeur de la clé correspondante.

Pour créer une _map_, tu peux faire :

```go
  // With map literal
  foo := map[string]int{}
```

ou

```go
  // or with make function
  foo := make(map[string]int)
```

Voici quelques opérations que tu peux effectuer sur une _map_ :

```go
  // Add a value in a map with the `=` operator:
  foo["bar"] = 42
  // Here we update the element of `bar`
  foo["bar"] = 73
  // To retrieve a map value, you can use
  baz := foo["bar"]
  // To delete an item from a map, you can use
  delete(foo, "bar")
```

Si tu essaies de récupérer la valeur d'une clé qui n'existe pas dans la _map_, cela renvoie la valeur zéro du type de valeur.
Cela peut prêter à confusion, surtout si la valeur par défaut de ton `ElementType` (par exemple, 0 pour un int) est une valeur valide.
Pour vérifier si une clé existe dans ta _map_, tu peux utiliser

```go
  value, exists := foo["baz"]
  // If the key "baz" does not exist,
  // value: 0; exists: false
```
