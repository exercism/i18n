# Introduction

Un tuple est un conteneur ordonné de valeurs. Comme tous les types de données de Gleam, les tuples sont immuables. Chaque élément d'un tuple peut être d'un type différent, et peut même être un autre tuple.

Les tuples s'écrivent comme des valeurs séparées par des virgules entre `#(` et `)` : `#(1, 2.0, "Three")`.

```gleam
#("one", 2)      // Tuple pair (2 values)
#("one", 2, 3.0) // Tuple triplet (3 values)
```

Les tuples de même longueur et de mêmes types (dans le même ordre) peuvent être comparés par égalité.

```gleam
#(1, 2) == #(1, 2) // Same length, same types, same values, same order
// -> True

#(1, 2) == #(2, 1) // Same length, same types, same values, different order
// -> False

#(1, 2) == #(1, "2") // Same length, different types
// Compile error!

#(1, 2) == #(1, 2, 3) // Different length
// Compile error!
```

Il y a trois façons de récupérer les valeurs contenues dans un tuple :

- L'indexation.
- Le filtrage par motif avec `let`.
- Le filtrage par motif avec `case`.

```gleam
let person = #("Jordan", 52)

// Option 1: Indexing
person.0 // -> "Jordan"
person.1 // -> 52

// Option 2: let
let #(name2, length2) = person
// -> name2 = "Jordan"
// -> length2 = 52

// Option 3: case
case person {
  #(name3, length3) -> {
    name3   // -> "Jordan"
    length3 // -> 52
  }
}
```

On peut utiliser l'indexation des tuples dans les gardes d'une expression `case`.

```gleam
pub fn is_18(person) {
  case person {
    _ if person.1 >= 18 -> True
    _ -> False
  }
}
```
