# Instructions

Dans cet exercice, tu vas écrire un programme pour t'aider à te préparer à acheter un véhicule.

Tu as deux tâches : déterminer si tu auras besoin d'un permis de conduire, et estimer le prix acceptable pour un véhicule d'occasion.

## 1. Détermine si tu auras besoin d'un permis de conduire

Certains types de véhicules nécessitent un permis de conduire pour être conduits.
Suppose que seuls les véhicules dont le type contient `car` ou `truck` nécessitent un permis ; tout le reste peut être conduit sans permis.

Implémente une paire `pattern {action}` qui correspond quand le premier champ est `needs_license`.
Elle doit récupérer le type de véhicule depuis le deuxième champ, et afficher « true » si tu as besoin d'un permis pour ce type de véhicule.
Si tu n'as pas besoin de permis, tu n'as rien besoin d'afficher.

```sh
echo "needs_license,dumptruck" | gawk -f vehicle-purchase.awk
# => true

echo "needs_license,bike" | gawk -f vehicle-purchase.awk
# => (empty output)
```

## 2. Calcule une estimation du prix d'un véhicule d'occasion

Maintenant que tu as pris ta décision, tu veux t'assurer d'obtenir un prix correct chez le concessionnaire.
Comme tu souhaites acheter un véhicule d'occasion, le prix dépend de l'âge du véhicule.
Pour obtenir une estimation approximative, suppose que si le véhicule a moins de 3 ans, il coûte 80 % du prix d'origine qu'il avait quand il était neuf.
S'il a plus de 10 ans, il coûte 50 %.
Si le véhicule a au moins 3 ans mais pas plus de 10 ans, il coûte 70 % du prix d'origine.

Implémente une paire `pattern {action}` qui correspond quand le premier champ est `resell_price`.
Elle doit récupérer le prix d'origine du véhicule depuis le deuxième champ, et l'âge depuis le troisième champ.
L'action doit afficher le prix estimé.

```sh
echo "resell_price,1000,1" | gawk -f vehicle-purchase.awk
# => 800

echo "resell_price,1000,5" | gawk -f vehicle-purchase.awk
# => 700

echo "resell_price,1000,15" | gawk -f vehicle-purchase.awk
# => 500
```
