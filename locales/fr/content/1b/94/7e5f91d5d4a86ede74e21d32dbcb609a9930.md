# pas de littéral entier

Elixir dispose d'une [syntaxe spéciale](https://elixir-lang.org/getting-started/binaries-strings-and-char-lists.html#unicode-and-code-points) pour écrire des entiers qui correspondent à des [points de code Unicode](https://en.wikipedia.org/wiki/Code_point) : on peut placer un `?` devant le littéral de caractère pour révéler son point de code.

Par exemple :

```elixir
?a === 97
?\s === 32
?ß === 223
?互 === 20114
```

Lorsqu'on manipule des points de code, cette notation est bien plus lisible que des nombres, et il faut toujours la préférer.
