# Pac-Man

## Histoire

Cette histoire utilise le jeu d'arcade classique _Pac-Man_ comme base pour enseigner le concept de [type booléen][types-boolean] / [logique booléenne][concepts-boolean_logic].

Le thème est dérivé de la discussion de Weng, Tseng et Lee (2010)[(1)][1] sur les stratégies d'apprentissage efficace de la logique à partir d'états de jeu.

L'histoire utilise plusieurs vérifications d'états de jeu pour s'exercer sur les [expressions booléennes][concepts-boolean_logic] dans les constructions du langage.

## Tâches

États de jeu explorés :

- Si _Pac-Man_ peut manger un fantôme.
- Si _Pac-Man_ marque un point.
- Si _Pac-Man_ perd la partie.
- Si _Pac-Man_ gagne la partie.

## Terminologie

Termes utilisés dans l'histoire :

- _Pac-Man_ : le personnage principal du jeu, que le joueur contrôle.
- Super pac-gomme : un objet qui donne la capacité de manger les fantômes, avec une durée d'action limitée.
- Pac-gomme : un objet qui rapporte des points et dont il faut toutes les manger pour remporter le niveau.
- Fantôme : l'adversaire contrôlé par l'ordinateur ; si un fantôme touche _Pac-Man_ sans super pac-gomme active, _Pac-Man_ perd le niveau.
