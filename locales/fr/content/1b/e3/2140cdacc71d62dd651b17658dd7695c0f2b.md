# Conditions

Crystal possède ce qu'on appelle des expressions de contrôle : elles servent à contrôler la façon dont le programme s'exécute et prennent une valeur vraie ou fausse.
Certains opérateurs permettent de créer des valeurs vraies ou fausses : ce sont les [opérateurs d'égalité et de comparaison][equality-and-comparison].

Il existe deux expressions de contrôle principales, qui déterminent le code qui sera exécuté et celui qui ne le sera pas.
Autrement dit, la branche qui sera exécutée.

Ces deux expressions sont `if` et `unless`.

## Opérateurs de comparaison

Les opérateurs de comparaison servent à comparer des valeurs et renvoient une valeur `true` ou `false`.
Ces opérateurs exigent que les deux valeurs comparées soient du même type.
Si les valeurs ne sont pas du même type, le compilateur lèvera une erreur.
Voici la liste des opérateurs de comparaison, avec un exemple de cas où ils donnent une valeur `true` :

| Méthode | Description           | Exemple |
| ------- | --------------------- | ------- |
| <       | inférieur à           | 4 < 5   |
| <=      | inférieur ou égal à   | 4 <= 4  |
| >       | supérieur à           | 3 > 1   |
| >=      | supérieur ou égal à   | 2 >= 2  |

## Opérateurs d'égalité

Les opérateurs d'égalité sont proches des opérateurs de comparaison, mais ils servent à vérifier si deux valeurs sont égales ou non.

L'opérateur `==` vérifie si deux valeurs sont égales, type de la valeur compris.
Si les valeurs sont identiques, il renvoie `true`, sinon il renvoie `false`.
L'opérateur `==` peut comparer n'importe quel type de valeur avec n'importe quel autre type de valeur.
L'opérateur `!=` fonctionne de la même façon, mais renvoie `true` si les valeurs sont différentes et `false` si elles sont égales.

## Opérateur _spaceship_

L'opérateur _spaceship_ est un opérateur de comparaison à part, et son nom vient de son apparence.
Sa particularité est qu'il ne renvoie pas une valeur vraie ou fausse, mais un nombre.
Il s'écrit `<=>` et sert à comparer deux valeurs.
Il renvoie `1` si la valeur de gauche est supérieure à celle de droite, `-1` si la valeur de gauche est inférieure à celle de droite, et `0` si les valeurs sont égales.

```crystal
1 <=> 2 # => -1
2 <=> 2 # => 0
3 <=> 2 # => 1
```

## Instruction `if`

L'instruction [`if`][if] sert à vérifier si une condition donnée est vraie ou fausse.
Si la condition est vraie, le code contenu dans l'instruction est exécuté.
Une instruction `if` se termine par le mot-clé `end`.

```crystal
if 1 == 1
  puts "1 is equal to 1"
end
# => 1 is equal to 1

if 1 > 2
  puts "1 is greater than 2"
end
# => no output
```

## Instruction `unless`

L'instruction [`unless`][unless] fonctionne de manière très similaire à l'instruction `if`, mais elle exécute le code qu'elle contient lorsque la condition est fausse.

```crystal
unless 1 == 1
  puts "1 is not equal to 1"
end
# => no output

unless 1 > 2
  puts "1 is not greater than 2"
end
# => 1 is not greater than 2
```

## Instruction `else`

L'instruction `else` peut s'utiliser avec les instructions `if` et `unless`.
L'instruction `else` est exécutée si la branche `if` ou la branche `unless` n'est pas exécutée.

~~~~exercism/warning
Même si une branche `else` peut s'utiliser avec `unless,`, c'est déconseillé, car cela nuit à la lisibilité.
Il vaut mieux utiliser `if !condition` avec une branche else.
~~~~

```crystal
if 1 == 1
  puts "1 is equal to 1"
else
  puts "1 is not equal to 1"
end
# => 1 is equal to 1

unless 1 < 2
  puts "1 is not greater than 2"
else
  puts "1 is greater than 2"
end
# => 1 is greater than 2
```

## Instructions `elsif` en cascade

L'instruction `elsif` peut s'utiliser avec l'instruction if.
L'instruction `elsif` est exécutée si la branche if n'est pas exécutée et que la condition de l'instruction `elsif` est vraie.
Les instructions `elsif` peuvent s'enchaîner, et la première condition vraie sera exécutée.
Une instruction else peut aussi figurer à la fin de l'instruction if ; elle s'exécute si aucune des conditions précédentes n'était vraie.

```crystal
if 1 != 1
  puts "1 is not equal to 1"
elsif 1 > 2
  puts "1 is greater than 2"
else
  puts "1 is not equal to 1 and 1 is not greater than 2"
end
# => 1 is not equal to 1 and 1 is not greater than 2
```

## Opérateur ternaire

Crystal dispose d'un opérateur ternaire, une instruction if-else tenant sur une seule ligne : `condition ? expression_if_truthy : expression_if_falsey`

```crystal
1 == 1 ? puts("1 is equal to 1") : puts("1 is not equal to 1")
# => 1 is equal to 1
```

## `if` et `unless` en suffixe

Les instructions if et unless peuvent aussi s'utiliser comme [suffixe][if-as-suffix] : c'est pratique lorsque tu veux exécuter une seule ligne de code si une condition est vraie.
Il suffit de placer l'instruction if ou unless après le code que tu veux exécuter.

```crystal
puts "1 is equal to 1" if 1 == 1
# => 1 is equal to 1

puts "1 is not equal to 1" unless 1 == 1
# => no output
```

## Types et instructions conditionnelles

Lorsqu'on lui affecte des valeurs de types différents, la variable porte les deux types.
En effet, le compilateur ne sait pas quelle branche sera exécutée.
Cette affectation multiple, aussi appelée union, sera expliquée dans des concepts ultérieurs.
Cela se voit dans l'exemple suivant :

```crystal
if 1 == 1
  a = 1
else
  a = "1"
end

typeof(a) # => Int32 | String
```
