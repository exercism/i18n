# Aide

Où trouver de l'aide pour tes questions sur AWK :

* [l'étiquette `awk` de Stack Overflow][so].
* consulte la section Ressources de la [page d'infos de l'étiquette `awk` de Stack Overflow][so-info].
* ouvre un ticket sur le dépôt GitHub [exercism/awk][github].
* IRC : `irc://irc.liberachat.net/#awk`, `irc://irc.liberachat.net/#exercism`
    * consulte [Libera.chat][libera] si tu ne connais pas IRC.
