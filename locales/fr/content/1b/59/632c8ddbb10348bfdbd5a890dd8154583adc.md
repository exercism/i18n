# Outils pour les contributeurs

Les apprenants n'ont besoin que des outils décrits dans [INSTALLATION.md](INSTALLATION.md).
Les contributeurs ont besoin de quelques outils de plus, car les scripts du parcours s'en servent :

- `git`, pour cloner le dépôt et ouvrir des _pull requests_.
- `jq`, utilisé par `bin/verify-exercises` et `bin/add-practice-exercise`.
- `curl`, utilisé par `bin/fetch-configlet`.
- Python 3.11 ou version ultérieure, pour le générateur de tests.
- `clang-format`, que le générateur de tests exécute sur les fichiers qu'il écrit.
- `pre-commit`, qui lance les vérifications du dépôt avant chaque _commit_.

Installe-les avec la commande correspondant à ta distribution, puis suis les étapes de la section « Configure le dépôt ».

## Debian / Ubuntu

```shell
sudo apt install git jq curl clang-format pre-commit
```

## Fedora

```shell
sudo dnf install git jq curl pre-commit clang-tools-extra diffutils
```

## Arch Linux

```shell
sudo pacman -S git jq curl pre-commit clang diffutils
```

## openSUSE Tumbleweed

```shell
sudo zypper install git jq curl python3-pre-commit clang-tools diffutils
```

## Configure le dépôt

Depuis la racine du dépôt :

```shell
bin/fetch-configlet
bin/configlet info
pre-commit install
pre-commit run --all-files
```
