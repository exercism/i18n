# Indices

## 1. Crée un nouveau tableau

- On peut créer un tableau vide avec la syntaxe `[]`.

## 2. Définis un tableau existant

- On peut créer des tableaux contenant plusieurs éléments avec la syntaxe `["a", "b", "c"]`.

## 3. Ajoute un nouveau langage à un tableau

- On peut utiliser la syntaxe de propagation (`[x, ..list]`) pour ajouter un élément au début d'un tableau.

## 4. Compte les langages dans le tableau

- Il y a une fonction dans le module `gleam/list` pour [compter les éléments d'un tableau][length].

## 5. Inverse le tableau

- Il y a une fonction dans le module `gleam/list` pour [inverser un tableau][reverse].

## 6. Vérifie si le tableau est passionnant

- Tu peux utiliser le filtrage par motif avec les motifs de tableau et de propagation de tableau pour reconnaître des structures de tableau spécifiques.

[reverse]: https://hexdocs.pm/gleam_stdlib/gleam/list.html#reverse
[length]: https://hexdocs.pm/gleam_stdlib/gleam/list.html#length
