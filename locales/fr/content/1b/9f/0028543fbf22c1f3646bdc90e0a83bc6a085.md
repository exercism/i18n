# Introduction

Les expressions régulières en Elixir suivent la spécification **PCRE** (**P**erl **C**ompatible **R**egular **E**xpressions), à l'instar d'autres langages populaires comme Java, JavaScript ou Ruby.

Le module `Regex` propose des fonctions pour travailler avec les expressions régulières. Certaines fonctions du module `String` acceptent également les expressions régulières comme arguments.

## Sigils

La façon la plus courante de créer des expressions régulières est d'utiliser le sigil `~r`.

```elixir
~r/test/
```

Note que tous les sigils d'Elixir prennent en charge [différents types de délimiteurs][sigils], pas seulement `/`.

## Correspondance

L'opérateur `=~/2` permet d'effectuer une correspondance d'expression régulière qui renvoie un résultat `boolean`. Sinon, il existe aussi des fonctions `match?/2` dans le module `Regex` ainsi que dans le module `String`.

```elixir
"this is a test" =~ ~r/test/
# => true

String.match?("Alice has 7 apples", ~r/\d{2}/)
# => false
```

## Captures

Si une simple vérification booléenne ne suffit pas, utilise la fonction `Regex.run/3` pour obtenir une liste de toutes les captures (ou `nil` s'il n'y a pas de correspondance). Le premier élément de la liste renvoyée correspond toujours à l'ensemble de l'expression régulière, et les éléments suivants sont les groupes capturés.

```elixir
Regex.run(~r/(\d) apples/, "Alice has 7 apples")
# => ["7 apples", "7"]
```

## Modificateurs

Le comportement d'une expression régulière peut être modifié en ajoutant des modificateurs spéciaux. Quand on utilise un sigil pour créer une expression régulière, on ajoute les modificateurs après le second délimiteur.

Les modificateurs courants sont :
- `i` - rend la correspondance insensible à la casse.
- `u` - active les motifs spécifiques à Unicode comme `\p` et fait que les classes de caractères comme `\w`, `\s`, etc. correspondent aussi aux caractères Unicode.

```elixir
"this is a TEST" =~ ~r/test/i
# => true
```
