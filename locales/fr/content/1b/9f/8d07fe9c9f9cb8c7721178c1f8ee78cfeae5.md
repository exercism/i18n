## À propos d'Enum

L'instruction `enum` permet de créer un ensemble d'étiquettes fortement typé.
On peut ensuite utiliser cette énumération dans le code sans avoir à l'analyser ni à en vérifier l'orthographe.

En interne, les énumérations sont représentées par des entiers dont la valeur de départ est zéro.
Par défaut, PowerShell attribue la valeur zéro à la première étiquette de la liste, puis attribue aux étiquettes suivantes des entiers consécutifs.

Exemple :
```pwsh
Enum Fruits {
    APPLE       #default internal value 0
    ORANGE      #default internal value 1
    MANGO       #default internal value 2
}

$myFavFruit = [Fruits]::APPLE
Write-host $myFavFruit => APPLE
``````

Pour en savoir plus sur `enum` dans PowerShell, consulte [le module Enum.](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.core/about/about_enum)
