# Instructions

## À propos de la [notation positionnelle][positional-notation]

Dans la notation positionnelle, un nombre en base **b** peut se comprendre comme une combinaison linéaire des puissances de **b**.

Le nombre 42, _en base 10_, signifie :

`(4 × 10¹) + (2 × 10⁰)`

Le nombre 101010, _en base 2_, signifie :

`(1 × 2⁵) + (0 × 2⁴) + (1 × 2³) + (0 × 2²) + (1 × 2¹) + (0 × 2⁰)`

Le nombre 1120, _en base 3_, signifie :

`(1 × 3³) + (1 × 3²) + (2 × 3¹) + (0 × 3⁰)`

_Oui. Ces trois nombres ci-dessus sont exactement les mêmes. Félicitations !_
