# Classes

Les classes sont un concept central de la [programmation orientée objet][object-oriented-programming].
[En Crystal, tout est un objet][everything-is-an-object], chaque objet a un type et peut répondre à certaines méthodes.
Les classes sont des plans pour créer des objets : elles fournissent des valeurs initiales pour l'état, comme les variables, et des implémentations de comportement, comme les méthodes.
Les objets sont des instances de classe qui contiennent toutes les variables d'instance et les états.

## Définition d'une classe

Une classe se définit avec le mot-clé `class`, suivi du nom de la classe écrit en `UpperCamelCase`.

```crystal
class Account
end
```

## Crée une instance

Pour [créer une instance d'une classe][new-initialize], appelle le nom de la classe avec la méthode `new`.

```crystal
class Account
end

account = Account.new
```

Dans l'exemple ci-dessus, la variable `account` est une instance de la classe `Account`.

Lors de la création d'une instance, une méthode spéciale appelée `initialize` joue le rôle de constructeur.
Elle est appelée lorsqu'une instance est créée.
Le constructeur permet de définir l'état initial de l'instance.
La méthode `initialize` peut prendre des arguments, qui sont passés lors de la création d'une instance.

```crystal
class Account
  def initialize(number)
    5 + number # => 9
  end
end

Account.new(4)
```

~~~~exercism/note
La méthode `initialize` ne peut pas renvoyer de valeur manuellement ; à la place, c'est `new` qui renvoie l'instance nouvellement créée.

```crystal
class Account
  def initialize(number)
    5 + number
  end
end

Account.new(4)
# => #<Account:0x7f5dc33dcea0>
```
~~~~

## Méthodes d'instance

Une méthode d'instance est une méthode disponible sur une instance de classe, et qui peut être appelée sur cette instance.
Les méthodes d'instance se définissent avec le mot-clé `def`, suivi du nom de la méthode.
Elles se définissent à l'intérieur de la définition de la classe.

```crystal
class Account
  def balance
    100
  end
end

account = Account.new
account.balance # => 100
```

## Variables d'instance

Les [variables d'instance][instance-variable] sont des variables accessibles dans toutes les méthodes de l'instance.
Pour accéder à une variable d'instance, il faut définir une méthode d'instance.
On peut les initialiser dans la méthode `initialize`.
Elles se définissent avec le préfixe `@`.

```crystal
class Account
  def initialize
    @balance = 100
  end

  def balance
    @balance
  end
end

account = Account.new
account.balance
# => 100
```

Les variables d'instance peuvent aussi se définir à l'intérieur de la définition de la classe.

```crystal
class Account
  @age = 0
end
```

### Variables d'instance avec initialisation

On peut initialiser des variables d'instance avec un argument passé à la méthode `initialize`.
Comme Crystal ne peut pas inférer le type de l'argument utilisé lors de l'initialisation, il faut le préciser.
Si tu veux en savoir plus, tu peux lire : [l'inférence de type][type-inference].
Pour préciser le type de la variable, tu peux utiliser le symbole `:`, suivi du type.
Par exemple, si tu veux créer une variable d'instance appelée `balance` de type `Int32`, tu peux faire comme ceci : `@balance : Int32`.
Ou, si tu veux créer une variable d'instance appelée `raining` de type `Bool`, tu peux faire comme ceci : `@raining : Bool`.

Il y a plusieurs façons de faire : soit déclarer l'argument avec son type dans la méthode `initialize`, puis affecter la variable d'instance à l'argument, comme dans l'exemple suivant :

```crystal
class Account
  def initialize(balance : Int32)
    @balance = balance
  end

  def balance
    @balance
  end
end

account = Account.new(1)
account_2 = Account.new(5)

account.balance
# => 1

account_2.balance
# => 5
```

Une autre façon consiste à déclarer le type de la variable d'instance dans la définition de la classe sous la forme : `@<variable> : <Type>`, comme dans l'exemple suivant :

```crystal
class Weather

  @raining : Bool

  def initialize(raining)
    @raining = raining
  end

  def raining
    @raining
  end
end

weather = Weather.new(true)
weather.raining
# => true
```

### Raccourci pour initialiser les variables d'instance

Il existe un raccourci pour initialiser des variables d'instance directement dans les arguments de la méthode `initialize`, avec la même syntaxe `@<variable> : <Type>`.
Cela combine l'affectation de la variable d'instance à l'argument et la déclaration du type de la variable d'instance.

```crystal
class Account
  def initialize(@balance : Int32)
  end
end
```

## Modifie les variables d'instance

Les méthodes peuvent modifier les variables d'instance.
Ces méthodes peuvent être appelées sur l'instance de la classe.
Quand une méthode modifie une variable d'instance, cette modification n'est visible que dans l'instance de la classe sur laquelle tu l'as appelée.

```crystal
class Account
  def initialize(balance : Int32)
    @balance = balance
  end

  def withdraw(amount)
    @balance -= amount
  end

  def balance
    @balance
  end
end

account = Account.new(10)
account_2 = Account.new(10)
account.balance
# => 10

account_2.balance
# => 10

account.withdraw(5)
account.balance
# => 5

account_2.balance
# => 10
```

## Méthodes de classe

Les [méthodes de classe][class-methods] sont des méthodes définies pour une classe, mais pas pour ses instances.
Elles permettent de créer des méthodes qui ne dépendent pas de l'état de l'instance.
Elles se définissent avec le mot-clé `def`, suivi de `self.<method name>`.
`self` est une référence à l'espace de noms depuis lequel `self` est appelé.
Dans ce cas, il désigne la classe `Account`.
Cela reviendrait au même que d'écrire `Account.`, mais `self.` est la façon préférée.

```crystal
class Account
  def self.balance
    100
  end
end

Account.balance
# => 100
```
