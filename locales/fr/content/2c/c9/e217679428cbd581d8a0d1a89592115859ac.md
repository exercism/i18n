# À propos

On peut exécuter du code de façon conditionnelle à l'aide d'[expressions `if/elif/else`][conditional-expression]. Les conditions utilisées dans une expression `if/elif/else` doivent être de type `bool`. F# ne connaît pas la notion de valeurs _truthy_.

```fsharp
if x = 5 then
    printfn "x equals 5"
elif x > 7 then
    printfn "x is not 5 and greater than 7"
else
    printfn "x is not 5 and not greater than 7"
```

Comme `if/elif/else` est une expression, on peut la lier à un nom ou la renvoyer depuis une fonction.

```fsharp
let message =
    if x = 5 then
        "x equals 5"
    elif x > 7 then
        "x is not 5 and greater than 7"
    else
        "x is not 5 and not greater than 7"
```

Toutes les branches doivent renvoyer le même type. Sinon, le compilateur renvoie une erreur :

```fsharp
if x = 5 then
    true
elif x > 7 then
    5.6

// Results in compiler error
```

Les branches `else` et `elif` sont facultatives, mais uniquement si le type de l'expression renvoyée est [`unit`][unit-type].

```fsharp
// Valid if expression
if x > 2 then
    printfn "x is greater than two"

// Invalid if expression, results in compiler warning
if x > 2 then
    true
```

On peut également écrire une expression `if/else` sur une seule ligne. À réserver aux expressions `if` simples.

```fsharp
let y = if x > 5 then 10 else 20
```
