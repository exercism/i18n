# Tâches

Les tâches sont des _issues_ GitHub sur lesquelles nous aimerions que des personnes nous donnent un coup de main, de la relecture de texte à la création d'exercices d'apprentissage.
Elles sont présentées sur le site et renvoient aux _issues_ correspondantes sur GitHub.
Chaque tâche est associée à une ou plusieurs propriétés, qui sont remplies à partir des étiquettes de l'_issue_.
On peut ensuite filtrer les tâches en fonction de leurs propriétés.

## Étiquettes

Pour qu'une _issue_ soit considérée comme une tâche, elle doit porter une ou plusieurs étiquettes propres aux tâches.
Les mainteneurs peuvent donc choisir de ne faire apparaître que certaines _issues_ comme des tâches.

Chaque étiquette de tâche est définie comme suit : `x:<type>/<value>`, et cinq types de tâches sont pris en charge :

- `action`
- `knowledge`
- `module`
- `size`
- `type`

### Étiquette action

Les étiquettes `x:action/<value>` décrivent le type de travail que le contributeur effectuera en travaillant sur l'_issue_.

| Étiquette            | Description                            |
| -------------------- | -------------------------------------- |
| `x:action/create`    | Travailler sur quelque chose de zéro   |
| `x:action/fix`       | Corriger une _issue_                   |
| `x:action/improve`   | Améliorer une fonctionnalité ou un contenu existant |
| `x:action/proofread` | Relire du texte                        |
| `x:action/sync`      | Synchroniser le contenu avec sa dernière version |

### Étiquette connaissance

Les étiquettes `x:knowledge/<value>` décrivent le niveau de connaissance d'Exercism nécessaire au contributeur.

| Étiquette                  | Description                                |
| -------------------------- | ------------------------------------------ |
| `x:knowledge/none`         | Aucune connaissance d'Exercism requise     |
| `x:knowledge/elementary`   | Peu de connaissances d'Exercism requises   |
| `x:knowledge/intermediate` | Pas mal de connaissances d'Exercism requises |
| `x:knowledge/advanced`     | Des connaissances approfondies d'Exercism requises |

### Étiquette module

Les étiquettes `x:module/<value>` indiquent sur quelle partie d'Exercism le contributeur va travailler.

| Étiquette                    | Description                 |
| ---------------------------- | --------------------------- |
| `x:module/analyzer`          | Travailler sur les analyseurs |
| `x:module/concept`           | Travailler sur les concepts |
| `x:module/concept-exercise`  | Travailler sur les exercices d'apprentissage |
| `x:module/generator`         | Travailler sur les générateurs d'exercices |
| `x:module/practice-exercise` | Travailler sur les exercices d'entraînement |
| `x:module/representer`       | Travailler sur les representers |
| `x:module/test-runner`       | Travailler sur les exécuteurs de tests |

### Étiquette taille

Les étiquettes `x:size/<value>` décrivent la charge de travail attendue pour un contributeur.

| Étiquette        | Description            |
| ---------------- | ---------------------- |
| `x:size/tiny`    | Un tout petit peu de travail |
| `x:size/small`   | Un peu de travail      |
| `x:size/medium`  | Une quantité moyenne de travail |
| `x:size/large`   | Une grande quantité de travail |
| `x:size/massive` | Une quantité massive de travail |

### Étiquette type

Les étiquettes `x:type/<value>` décrivent le type de travail que le contributeur effectuera.

| Étiquette        | Description                                                                                                                                                                                                    |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `x:type/ci`      | Travailler sur l'intégration continue (par exemple les workflows GitHub Actions)                                                                                                                               |
| `x:type/coding`  | Écrire du code qui ne fait pas partie du contenu destiné aux apprenants. Il s'agit généralement de tâches liées à l'outillage de production (par exemple les exécuteurs de tests), à l'outillage interne (les générateurs) ou aux bibliothèques qu'Exercism maintient. |
| `x:type/content` | Travailler sur le contenu (par exemple les exercices, les concepts)                                                                                                                                            |
| `x:type/docker`  | Travailler sur les Dockerfiles                                                                                                                                                                                 |
| `x:type/docs`    | Travailler sur la documentation                                                                                                                                                                                |

## Tâches attribuées et non attribuées

Pour masquer une tâche parce que quelqu'un y travaille déjà, une _issue_ peut ajouter l'étiquette `x:status/claimed`.
