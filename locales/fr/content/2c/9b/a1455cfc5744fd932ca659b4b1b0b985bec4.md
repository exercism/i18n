# Indices

## Général

- Pour en savoir plus sur `if`, consulte le [guide de démarrage officiel][getting-started-if] ou le site [elixirschool.com][elixirschool-if].

## 1. Affiche un badge pour un employé

- C'est un cas de base dans lequel on peut supposer qu'aucune des données d'entrée n'est `nil`.
- Si tu as besoin de te rafraîchir la mémoire sur la manipulation des _strings_, lis la section qui leur est consacrée dans le [guide de démarrage officiel][getting-started-basic-strings].

## 2. Affiche un badge pour un nouvel employé

- Les _strings_ sont toujours _truthy_ et `nil` est _falsy_.
- Il existe une [macro][kernel-if] qui renvoie l'une des deux options, selon qu'on lui donne une valeur _truthy_ ou _falsy_.

## 3. Affiche un badge pour le propriétaire

- Les _strings_ sont toujours _truthy_ et `nil` est _falsy_.
- Il existe une [macro][kernel-if] qui renvoie l'une des deux options, selon qu'on lui donne une valeur _truthy_ ou _falsy_.
