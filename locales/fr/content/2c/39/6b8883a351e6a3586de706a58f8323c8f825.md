## Messages d'exception

Parfois, il est nécessaire de [lever une exception](https://docs.python.org/3/tutorial/errors.html#raising-exceptions). Dans ce cas, il faut toujours inclure un **message d'erreur explicite** pour indiquer l'origine de l'erreur. Cela rend le code plus lisible et facilite grandement le débogage. Lorsque tu sais que l'erreur provient d'un type précis, tu peux choisir de lever l'un des [types d'erreur intégrés](https://docs.python.org/3/library/exceptions.html#base-classes), mais tu dois tout de même y joindre un message explicite.

Cet exercice-ci demande d'utiliser [l'instruction `raise`](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement) pour « lever » une `ValueError` lorsque la fonction `convert()` reçoit une _string_ qui n'est pas un nombre OCR valide. Les tests ne passeront que si tu lèves l'`exception` avec `raise` et que tu y joins un message.

Pour lever une `ValueError` avec un message, écris ce message comme argument du type `exception` :

```python
# when the rows aren't multiples of 4
raise ValueError("Number of input lines is not a multiple of four")

# when the columns aren't multiples of 3
raise ValueError("Number of input columns is not a multiple of three")
```
