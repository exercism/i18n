# Installation

Des [binaires Uiua précompilés][releases] sont disponibles, donc pas besoin de compiler.
Consulte le [guide d'installation officiel][install-guide] pour les instructions les plus récentes, y compris l'intégration aux IDE et les polices.

```exercism/note
Actuellement, notre exécuteur de tests en ligne utilise la version `0.18.1`.
Compte tenu du rythme de développement rapide d'Uiua, cela peut changer, donc garde-le en tête si tu n'arrives pas à reproduire les résultats des tests depuis le site web.
```

Une fois Uiua téléchargé à l'emplacement voulu, tu devras ajouter Uiua au PATH de ton système.

- **macOS :** utilise le Finder pour ouvrir `Applications > Utilities > Terminal`. Saisis `export PATH="/path/to/uiua:$PATH"` pour lancer Uiua depuis n'importe quel emplacement.

- **Windows :** ouvre « Edit Environment Variables » depuis le menu Démarrer. Dans « Path », ajoute ton dossier Uiua.

- **Linux :** ouvre Terminal et ajoute `export PATH="/path/to/uiua:$PATH"` à `~/.bashrc` ou `~/.profile` pour y accéder facilement.

[releases]: https://github.com/uiua-lang/uiua/releases
[install-guide]: https://www.uiua.org/docs/install#basic
