# Instructions

Dans cet exercice, tu dois implémenter quelques règles du jeu classique Pac-Man.

Tu as quatre règles à implémenter, toutes liées aux états du jeu.

## 1. Définis si Pac-Man mange un fantôme

Implémente une fonction qui prend en entrée si Pac-Man a une super pac-gomme active et si Pac-Man touche un fantôme, et qui renvoie un booléen indiquant si Pac-Man est capable de manger le fantôme. La fonction doit renvoyer `true` uniquement si Pac-Man a une super pac-gomme active et touche un fantôme.

```lua
rules.eat_ghost(false, true)
-- => false
```

## 2. Définis si Pac-Man marque des points

Implémente une fonction qui prend en entrée si Pac-Man touche une super pac-gomme et si Pac-Man touche une pac-gomme, et qui renvoie un booléen indiquant si Pac-Man a marqué des points. La fonction doit renvoyer `true` si Pac-Man touche une super pac-gomme ou une pac-gomme.

```lua
rules.score(true, true)
-- => true
```

## 3. Définis si Pac-Man perd

Implémente une fonction qui prend en entrée si Pac-Man a une super pac-gomme active et si Pac-Man touche un fantôme, et qui renvoie un booléen indiquant si Pac-Man perd. La fonction doit renvoyer `true` si Pac-Man touche un fantôme et n'a pas de super pac-gomme active.

```lua
rules.lose(false, true)
-- => true
```

## 4. Définis si Pac-Man gagne

Implémente une fonction qui prend en entrée si Pac-Man a mangé toutes les pac-gommes, si Pac-Man a une super pac-gomme active et si Pac-Man touche un fantôme, et qui renvoie un booléen indiquant si Pac-Man gagne. La fonction doit renvoyer `true` si Pac-Man a mangé toutes les pac-gommes et n'a pas perdu, d'après les arguments définis dans la partie 3.

```lua
rules.win(false, true, false)
-- => false
```
