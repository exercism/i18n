# À propos

## Les booléens

PowerShell dispose du type [`bool`][booleans] pour représenter les valeurs vrai et faux.
Ce type ne comporte que deux valeurs : `True` et `False`.
On peut affecter ces valeurs à des variables en utilisant le préfixe `$` :

```powershell
> $TrueVar  = $true
> $FalseVar = $FALSE
#Case senstitivity doesn't matter here
```

On peut utiliser des [opérateurs logiques][logical-operators] comme `-and`, `-or` et `-not` pour combiner et évaluer des expressions booléennes.

```powershell
> $TrueVar  = $true -and $true
> $FalseVar = $true -and $false

> $TrueVar  = $true -or $false
> $FalseVar = $false -or $false

> $TrueVar  = -not $false
> $FalseVar = -not $true
```

## Conversion et véracité

PowerShell peut traiter implicitement n'importe quel type comme un booléen.
On peut toutefois aussi utiliser l'accélérateur de type booléen `[bool]` pour une conversion explicite.

Voici quelques règles générales que PowerShell applique pour convertir d'autres types en valeurs booléennes :

$false :
- Les chaînes de caractères vides comme `''` ou `""`
- Les valeurs nulles comme `$null`
- Les types numériques valant zéro (0)

$true :
- Les chaînes de caractères non vides
- Les instances de tout autre type qui n'est pas une collection

```powershell
> [bool] 0
False

> [bool] 0.0
False

> [bool] ""
False

> [bool] "Hello"
True

> [bool] 1234
True
```

Pour connaître en détail les règles de conversion des valeurs booléennes à partir des types de collection, consulte [ici][collection-conversion].
