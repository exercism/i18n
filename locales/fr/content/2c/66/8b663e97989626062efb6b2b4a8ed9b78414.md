# Instructions

Tu développes un système pour aider le personnel du site web d'un club de football à rédiger les comptes rendus des matchs. Les données arrivent de diverses sources et, une fois nettoyées, sont acheminées vers un flux unique.

## 1. Renvoie la description des joueurs en fonction de leur numéro de maillot

L'équipe joue toujours en 4-3-3 et n'a jamais accepté la modification des règles de 1965 qui autorise les remplacements, et encore moins l'élargissement des effectifs.

Les descriptions des joueurs sont les suivantes :

```text
1 -> "goalie"
2 -> "left back"
3 & 4 "center back"
5 -> "right back"
6, 7, & 8 -> "midfielder"
9 -> "left wing"
10 -> "striker"
11 -> "right wing"
```

Implémente la méthode statique `FootballMatchReports.onField()` pour renvoyer la description d'un joueur en fonction de son numéro de maillot.

```java
FootballMatchReports.onField(10);
// => "striker"
```

## 2. Renvoie « invalid » si le numéro de maillot ne fait pas partie de la liste officielle

Modifie la méthode `FootballMatchReports.onField()` pour qu'elle renvoie « invalid » lorsqu'un numéro de maillot en dehors de la plage 1-11 est traité.

```java
FootballMatchReports.onField(13);
// => "invalid"
```
