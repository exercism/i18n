# Instructions case

Quand on compare une valeur à une liste de possibilités, une chaîne de `elsif` répète la même chose encore et encore :

```sather
   if zone = 0 then
      return 0;
   elsif zone = 1 then
      return 550;
   elsif zone = 2 then
      return 370;
   else
      return 920;
   end;
```

`case` le dit une seule fois :

```sather
   case zone
   when 0 then return 0;
   when 1 then return 550;
   when 2 then return 370;
   else return 920;
   end;
```

La valeur se place après `case`. Chaque `when` fournit une valeur à laquelle la comparer, et le premier qui correspond s'exécute.

## Plusieurs valeurs dans un même when

Un `when` peut lister plusieurs valeurs, séparées par des virgules :

```sather
   case day
   when "Sat", "Sun" then return "Weekend";
   when "Mon", "Tue", "Wed", "Thu", "Fri" then return "Weekday";
   else return "Unknown";
   end;
```

Cela fonctionne pour les nombres entiers, les caractères et les _strings_ : n'importe quoi qui peut être comparé avec `=`.

## Le else n'est pas facultatif

**Un `case` qui ne correspond à rien et qui n'a pas de `else` est une erreur qui arrête le programme au moment où elle se produit.**

C'est différent de `if`, où omettre le `else` signifie simplement que rien ne se passe. C'est aussi différent de la plupart des langages, où un `case` sans correspondance ne fait rien, sans rien signaler.

Donc chaque `case` a besoin d'un `else`, même quand tu es sûr que les parties `when` couvrent déjà toutes les valeurs. Une quatrième zone est ajoutée plus tard, le `case` n'est pas mis à jour en conséquence, et le programme s'arrête sur le premier passager qui l'utilise.

## Un seul when s'exécute

Quand un `when` correspond, les instructions qui suivent son `then` s'exécutent et le `case` est terminé : le programme continue après le `end`. Les parties `when` situées en dessous ne sont jamais examinées, donc tu n'as rien à écrire pour empêcher la suivante de s'exécuter aussi.
