# Instructions

Dans cet exercice, tu vas écrire du code pour traiter une liste de langages de programmation que tu comptes pratiquer sur la plateforme Exercism.

Cet exercice comporte six tâches.

## 1. Crée une nouvelle liste

Avant de pouvoir ajouter des langages, il te faut commencer par créer une nouvelle liste. Définis une fonction qui renvoie une liste vide.

```clojure
(new-list)
;; => ()
```

## 2. Ajoute un nouveau langage à la liste

En explorant Exercism, tu vas découvrir des langages que tu veux apprendre, et tu auras besoin de pouvoir les ajouter à ta liste. Définis une fonction qui ajoute un nouveau langage au début de ta liste.

```clojure
(add-language "JavaScript" '("Clojurescript"))
;; => '("JavaScript" "Clojurescript")
```

## 3. Vérifie le dernier langage ajouté

Tu auras envie de vérifier rapidement quel langage tu viens d'ajouter. Définis une fonction qui renvoie le premier langage de ta liste.

```clojure
(first-language '("Haskell" "Python"))
;; => "Haskell"
```

## 4. Supprime le premier langage de la liste

Il t'arrivera parfois de changer d'avis sur un langage que tu viens d'ajouter. Définis une fonction qui supprime le premier langage de ta liste.

```clojure
(remove-language '("Common Lisp" "Racket" "Scheme"))
;; => '("Racket" "Scheme")
```

## 5. Compte les langages de la liste

Compter les langages un par un n'est pas pratique. Définis une fonction qui compte le nombre de langages de ta liste.

```clojure
(count-languages '("C#" "Racket" "Rust" "Ruby"))
;; => 4
```

## 6. Rassemble le tout

Définis une fonction `learning-list`, dans laquelle tu utiliseras certaines des fonctions que tu as définies plus haut.

- Crée une liste vide
- Ajoute 2 nouveaux langages de programmation à la liste.

  - Clojure
  - Lisp

- Supprime « Lisp » de la liste, car tu n'auras peut-être pas assez de temps cette année, et il ressemble beaucoup à Clojure.
- Ajoute 2 autres langages de programmation à la liste.

  - Java
  - JavaScript

- Renvoie le nombre total de langages. Indice : il doit être égal à 3.

```clojure
(learning-list)
;; => 3
```
