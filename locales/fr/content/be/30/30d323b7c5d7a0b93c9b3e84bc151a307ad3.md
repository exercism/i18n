# À propos

Disponibles à partir de `PHP 8.0.0`, les **déclarations de types union** acceptent des valeurs de plusieurs types différents, plutôt que d'un seul type. Les types union se définissent à l'aide de la barre verticale (`|`), qui sépare les types.

```php
function add(int|float $a, int|float $b): int|float
{
    return $a + $b;
}
```

## Nuances

- Les types `null` peuvent être déclarés _nullable_, soit avec `?Type`, soit avec `Type1|Type2|null`.
- Déclarer des types en double ou redondants provoque une erreur à la compilation.
- `void` ne peut pas être utilisé dans la déclaration d'un type union.
