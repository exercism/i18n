# À propos

Une `List` est très semblable à un [`Array`][array]. Il y a cependant des différences majeures qu'il ne faut pas rater :

1. On ne peut pas accéder à une liste par son indice à l'aide de crochets, c'est-à-dire `[0]`.
2. Une liste ne peut pas être initialisée.
3. Il n'existe pas de compréhensions de listes.
4. Une liste peut modifier librement ses éléments pendant qu'on la parcourt.

`List` fait partie du _package_ `haxe.ds`, donc chaque fois que tu veux utiliser des listes, tu dois importer son _package_ :

```haxe
import haxe.ds.List;

class Main {
  static function main() {
    var myList = List<Int>();

    for (i in 0...5) {
      myList.add(i);
    }

    trace(myList); // {0, 1, 2, 3, 4}
  }
}
```

[array]: https://haxe.org/manual/std-Array.html
