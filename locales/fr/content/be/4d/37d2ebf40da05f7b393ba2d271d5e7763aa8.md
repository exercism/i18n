# Instructions

Dans cet exercice, on va travailler avec des comptes d'épargne. Chaque année, le solde d'un compte d'épargne est mis à jour en fonction du taux d'intérêt. Le taux d'intérêt accordé par la banque dépend de la somme d'argent présente sur le compte (son solde) :

- 0,5 % pour un solde non négatif inférieur à `1000` dollars.
- 1,621 % pour un solde positif supérieur ou égal à `1000` dollars et inférieur à `5000` dollars.
- 2,475 % pour un solde positif supérieur ou égal à `5000` dollars.
- 3,213 % pour un solde négatif (ce qui donne un intérêt négatif).

Tu as trois tâches, qui portent chacune sur le solde et son taux d'intérêt.

## 1. Calcule le taux d'intérêt

Implémente la méthode `SavingsAccount.interest_rate` pour calculer le taux d'intérêt en fonction du solde indiqué :

```ruby
SavingsAccount.interest_rate(200.75)
#=> 0.5
```

Note que la valeur renvoyée est une instance de `Float`.

## 2. Calcule la mise à jour annuelle du solde

Implémente la méthode `SavingsAccount.annual_balance_update` pour calculer la mise à jour annuelle du solde, en tenant compte du taux d'intérêt :

```ruby
SavingsAccount.annual_balance_update(200.75)
#=> 201.75375
```

Note que la valeur renvoyée est une instance de `Float`.

## 3. Calcule le nombre d'années avant d'atteindre le solde souhaité

Implémente la méthode `SavingsAccount.years_before_desired_balance` pour calculer le nombre minimum d'années nécessaires pour atteindre le solde souhaité :

```ruby
SavingsAccount.years_before_desired_balance(200.75, 214.88)
#=> 14
```

Note que la valeur renvoyée est une instance de `Integer`.
