# Installation

Cairo s'installe simplement en téléchargeant Scarb. Scarb regroupe le compilateur Cairo et le serveur de langage Cairo dans un paquet facile à installer, ce qui te permet de commencer à écrire du code Cairo tout de suite. Scarb est aussi le gestionnaire de paquets de Cairo.

Pour obtenir les instructions d'installation recommandées pour ta plateforme, rends-toi sur [le site officiel de Cairo](https://www.cairo-lang.org/tutorials/getting-started-with-cairo/).

Par système d'exploitation :

- Linux/MacOS
    1. Installe [asdf](https://asdf-vm.com/guide/getting-started.html)
    2. Installe [scarb](https://docs.swmansion.com/scarb/download#install-via-asdf)
    3. Vérifie l'installation dans une nouvelle session de terminal `scarb --version`
- Windows
    1. Installe [scarb](https://docs.swmansion.com/scarb/download#windows)
    2. Vérifie l'installation dans une nouvelle session de terminal `scarb --version`

Avoir la chaîne d'outils installée, ce n'est pas tout ! Le support de l'IDE est un gain de productivité considérable auquel la plupart des développeurs se sont habitués.
Si tu utilises Visual Studio Code, on te recommande d'installer [l'extension Cairo](https://marketplace.visualstudio.com/items?itemName=starkware.cairo1), qui apporte la coloration syntaxique, la complétion de code et d'autres fonctionnalités utiles !
