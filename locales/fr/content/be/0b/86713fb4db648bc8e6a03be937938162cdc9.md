# Introduction

En Go, `for range` répète un bloc de code pour les valeurs issues d'une expression de `range`. Cette expression détermine si chaque itération renvoie une valeur ou deux.

## Expressions de `range`

### Parcours un slice

`range` appliqué à un slice renvoie l'indice et la valeur de chaque élément, dans l'ordre :

```go
vals := []int{10, 20, 30}
for i, v := range vals {
    fmt.Println(i, v)
}
// 0 10
// 1 20
// 2 30
```

### Parcours une map

`range` appliqué à une map renvoie chaque clé et chaque valeur, mais l'ordre d'itération n'est pas garanti.
Go randomise délibérément l'ordre d'itération des maps, donc un même programme peut produire une sortie différente à chaque exécution.

```go
hash := map[int]int{9: 10, 99: 20, 999: 30}
for k, v := range hash {
    fmt.Println(k, v)
}
// 99 20
// 999 30
// 9 10
```

### Parcours une _string_

`range` appliqué à une _string_ renvoie l'indice d'octet et chaque `rune` (point de code Unicode).
Dans l'exemple suivant, `子` occupe trois octets, donc `猫` commence à l'indice d'octet `3`, et non `1`.

```go
for i, r := range "子猫" {
    fmt.Println(i, r, string(r))
}
// 0 23376 子
// 3 29483 猫
```

Si tu as besoin d'indices de runes, convertis la _string_ en un slice de runes :

```go
for i, r := range []rune("子猫") {
    fmt.Println(i, r, string(r))
}
// 0 23376 子
// 1 29483 猫
```

### Parcours un entier

`range` peut aussi parcourir directement un entier, en produisant les valeurs de `0` jusqu'à cet entier exclu.
La valeur zéro et les valeurs négatives sont acceptées, mais ne produisent aucune itération.

```go
for n := range 3 {
    fmt.Println(n)
}
// 0
// 1
// 2
```

### Parcours un itérateur

`range` accepte un itérateur de type `iter.Seq[V]` ou `iter.Seq2[K, V]`.
Un itérateur est une fonction qui produit les valeurs d'une séquence l'une après l'autre.
`range` peut alors les parcourir.

```go
text := "The quick brown fox"
for word := range strings.FieldsSeq(text) {
    fmt.Println(word)
}
// The
// quick
// brown
// fox

names := []string{"Alice", "Bob", "Vera"}
for i, v := range slices.All(names) {
    fmt.Println(i, ":", v)
}
// 0 : Alice
// 1 : Bob
// 2 : Vera
```

### Parcours un `channel`

Enfin, `range` peut recevoir les valeurs envoyées dans un `channel` jusqu'à ce que ce channel soit fermé ailleurs.
Les channels sont traités plus en détail plus loin dans le programme du parcours.

## Omets l'indice ou la valeur

Go ne compile pas si une variable est déclarée mais jamais utilisée.

```go
vals := []int{10, 20, 30}
for i, v := range vals {
    fmt.Println(v)
}
// Go build failed: declared and not used: i
```

Si tu n'as besoin que de la valeur, affecte l'indice ou la clé à `_` pour l'ignorer.

```go
vals := []int{10, 20, 30}
for _, v := range vals {
    fmt.Println(v)
}
// 10
// 20
// 30
```

Si tu n'as besoin que de l'indice, omets complètement la valeur :

```go
vals := []int{10, 20, 30}
for i := range vals {
    fmt.Println(i)
}
// 0
// 1
// 2
```

Si tu n'as besoin ni de l'indice ni de la valeur, tu peux omettre les deux :

```go
vals := []int{10, 20, 30}
count := 0
for range vals {
    count++
}
// count == 3
```
