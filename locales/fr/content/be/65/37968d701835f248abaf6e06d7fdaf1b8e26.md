# Introduction

En Haxe, un type abstrait est un type qui est un type différent au moment de l'exécution. C'est une fonctionnalité de compilation qui définit des types « au-dessus » de types concrets afin de modifier ou d'enrichir leur comportement :

```haxe
abstract AbstractInt(Int) {
    inline public function new(i:Int) {
        this = i;
    }
}
```

Ici, on déclare le type `AbstractInt` à l'aide du mot-clé `abstract`. Sa syntaxe est très proche de celle de `class`. Et tout comme les classes, les types abstraits peuvent avoir des méthodes. Ils peuvent aussi être instanciés et utilisés exactement comme des classes :

```haxe
class Main {
    static public function main() {
        var a = new AbstractInt(12);
        trace(a); // 12
    }
}
```
