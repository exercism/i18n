# https://www.php.net/manual/en/language.basic-syntax.phptags.php"Opérateur de résolution de portée

L'opérateur de résolution de portée (`::`) permet de référencer une classe afin d'accéder à son nom, à ses constantes, à ses propriétés statiques ou à ses méthodes statiques.

```php
class MyClass
{
  public const MY_VALUE = 1;
}

// MyClass::class => "MyClass"
// MyClass::MY_VALUE => 1
```

## Utiliser `self` et `static` avec l'opérateur de résolution de portée

Il peut être nécessaire pour un objet de référencer sa propre portée. Pour cela, le mot-clé `self` permet à une classe de référencer sa propre portée. Utiliser le mot-clé `self` découple la classe de son propre nom, ce qui facilite la maintenance du code au fil du temps.

```php
class MyClass
{
  public const MY_VALUE = 1;

  public function getMyValue(): int
  {
    return self::MY_VALUE;
  }
}

// (new MyClass)->getMyValue() => 1
```

Toutefois, `self` est lié de manière lexicale à la classe dans laquelle il apparaît.

```php
class MyOtherClass extends MyClass
{
  public const MY_VALUE = 99;
}

// (new MyOtherClass)->getMyValue() => 1
```

Évaluer `MyOtherClass::getMyValue` renvoie toujours `1` au lieu de `99`. Pour contourner ce problème, utilise le mot-clé `static` avec l'opérateur de résolution de portée afin de « lier tardivement » la référence à la classe descendante courante.

```php
// Update MyClass:
class MyClass
{
  public const MY_VALUE = 1;

  public function getMyValue(): int
  {
    return static::MY_VALUE;
  }
}
```

## Utiliser `parent` avec l'opérateur de résolution de portée

Il peut être nécessaire de référencer spécifiquement une constante, une propriété ou une méthode disponible dans la portée du parent :

```php
class MyClass
{
  public function getMaximum(): int
  {
    return 5;
  }
}

class AnotherClass extends MyClass
{
  public function getMaximum(): int
  {
    return parent::getMaximum() * 2;
  }
}

// (new AnotherClass())->getMaximum() => 10
```

Le plus souvent, en programmation orientée objet, `parent` sert à appeler le constructeur du parent au moment où un objet est instancié :

```php
class ChildClass extends ParentClass
{
  public function __construct(): void
  {
    parent::__construct();
  }
}
```

## Points de vigilance

### Visibilité des constantes, des propriétés et des méthodes

L'opérateur de résolution de portée suit toujours les règles définies par les modificateurs de visibilité `public`, `private` et `protected`.
