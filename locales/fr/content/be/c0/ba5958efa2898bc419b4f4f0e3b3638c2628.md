# À propos

Une *expression régulière* (_regex_) est un petit motif qui décrit la forme d'un texte. Les outils d'expressions régulières de Factor se trouvent dans le vocabulaire [`regexp`][regexp], et un motif s'écrit comme un littéral entre `R/ ` et `/`.

La plupart des caractères d'un motif correspondent à eux-mêmes. La puissance d'expression vient des classes de caractères et des quantificateurs :

```
\d        ! a digit 0–9            \s   ! whitespace
\D        ! any non-digit          \S   ! non-whitespace
[A-Z]     ! one capital letter     .    ! any one character
[^0-9]    ! any char except a digit

{4}       ! exactly 4              +    ! one or more
{2,5}     ! between 2 and 5        *    ! zero or more
?         ! optional               |    ! either side (alternation)
```

Ainsi, `R/ [A-Z]{2}-\d{4}/` correspond à « deux majuscules, un tiret, quatre chiffres ».

## Correspondance sur la _string_ entière ou recherche

`matches?` ne réussit que si la _string_ *entière* correspond au motif. Les autres mots, eux, cherchent *à l'intérieur* d'une _string_ :

```
matches?             ( string regexp -- ? )
re-contains?         ( string regexp -- ? )
count-matches        ( string regexp -- n )
all-matching-subseqs ( string regexp -- seq )
first-match          ( string regexp -- slice/f )
re-split             ( string regexp -- seq )
re-replace           ( string regexp replacement -- result )
```

```factor
USING: regexp ;

"NS-1024" R/ [A-Z]{2}-\d{4}/ matches? .         ! => t
"id NS-1024 ok" R/ [A-Z]{2}-\d{4}/ matches? .   ! => f   (extra text)
"id NS-1024 ok" R/ [A-Z]{2}-\d{4}/ re-contains? .   ! => t

"a1b2c3" R/ \d/ count-matches .   ! => 3
"a1b2c3" R/ \d/ re-replace .      ! NOTE: see re-replace below
```

## Slices

`first-match` et `re-split` renvoient des objets `slice`, de simples vues sur la _string_ d'origine plutôt que de nouvelles _strings_. Convertis un slice avec `>string` lorsque tu as besoin d'une _string_ autonome (par exemple pour la comparer à un littéral _string_). `all-matching-subseqs` renvoie déjà des _strings_.

## Remplace

`re-replace` remplace chaque correspondance par une _string_ de remplacement et renvoie le résultat :

```factor
USING: regexp ;

"user=alice pass=hunter2" R/ pass=\S+/ "pass=****" re-replace .
! => "user=alice pass=****"
```

## Construis un motif à l'exécution

`R/ /` est analysé au chargement du fichier. Pour construire un motif à partir d'une _string_ calculée à l'exécution, utilise `<regexp>` :

```
<regexp> ( string -- regexp )
```

[regexp]: https://docs.factorcode.org/content/vocab-regexp.html
