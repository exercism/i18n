# Utiliser l'interpolation de _strings_

Utilise [l'interpolation de _strings_](https://docs.scala-lang.org/overviews/core/string-interpolation.html) pour construire dynamiquement une _string_, plutôt que de recourir à la concaténation de _strings_ ou à `StringBuilder`.

Le principal avantage est que le code avec interpolation de _strings_ est généralement plus facile à lire que la concaténation de _strings_ ou `StringBuilder`.
