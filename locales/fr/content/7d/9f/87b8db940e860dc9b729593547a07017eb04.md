# Général

- Documentation de l'API : [package regexp][package-regexp]
- Syntaxe des expressions régulières : [regexp/syntax][regexp-syntax]
- Le site [regex101.com][regex101] propose un testeur d'expressions régulières en ligne.
- Il est recommandé d'écrire les expressions régulières sous forme de [littéraux de chaîne bruts][raw-string-literals] entourés d'accents graves.

## 1. Identifie les lignes de _log_ corrompues

- La fonction [regexp.MatchString][fun-re-match-string] ou la méthode [MatchString][method-match-string] peuvent être utiles ici.
- Dans une expression régulière, le caractère `^` correspond au début d'une ligne ou d'une _string_.

## 2. Découpe la ligne de _log_

- La méthode [Split][regexp-split] peut être utile ici.

## 3. Compte le nombre de lignes contenant `password` dans du texte entre guillemets

- On peut rendre la correspondance sensible à la casse en faisant précéder l'expression régulière de `(?i)`.
  Cela active le drapeau `i`.
  Voir [ce tutoriel][yourbasic-i-flag].

## 4. Supprime les artefacts du _log_

- La méthode [ReplaceAllString][replace-all-string] peut être utile ici.

## 5. Étiquette les lignes avec les noms d'utilisateur

- La méthode [FindStringSubmatch][find-string-submatch] peut être utile ici.
