# À propos

Il existe en Clojure quelques constructions de base pour le [contrôle du flux](https://clojure.org/guides/learn/flow). `if` est l'expression conditionnelle la plus importante : elle se compose d'une condition, d'un « alors » et d'un « sinon » facultatif. `if` n'évalue que la branche sélectionnée par la condition.

```clojure
(if (even? 2) "even" "odd")
```

`cond` est une suite de tests et d'expressions. Chaque test est évalué dans l'ordre, et pour le premier test qui est vrai, l'expression correspondante est évaluée puis renvoyée.

```clojure
(cond (= x 5) "Expression to evaluate when x equals 5"
      (> x 7) "Expression to evaluate when x is greater than 7"
      :else   "Expression to evaluate in all other cases")
```
