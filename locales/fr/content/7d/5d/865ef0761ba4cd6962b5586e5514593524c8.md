# Introduction aux listes

En Java, les **listes** sont la collection qui représente une séquence ordonnée.
Contrairement aux tableaux, une [`List`](https://docs.oracle.com/en/java/javase/11/docs/api/java.base/java/util/List.html) peut grandir pour accueillir n'importe quel nombre d'éléments.
Une implémentation standard est `ArrayList`, qui repose sur un tableau redimensionnable.
Une autre implémentation standard est la classe `LinkedList`, qui repose sur une liste doublement chaînée.

Une `List` peut être vide ou contenir n'importe quel nombre d'éléments (y compris des doublons).
Une `List` est une **interface générique**, typée pour indiquer le type d'objets qu'elle peut contenir.
Par exemple :

```java
List<String> emptyListOfStrings = List.of();
List<Integer> singleInteger = List.of(1);
List<Boolean> threeBooleans = List.of(true, false, true);
List<Object> listWithMultipleTypes = List.of("hello", 1, true);
```

Les `List` proposent plusieurs méthodes utiles pour ajouter, supprimer ou récupérer un élément, ou pour vérifier sa présence :

```java
List<Character> vowels = new ArrayList<>(List.of('a', 'e', 'i', 'o', 'i', 'e', 'a'));
int startingSize = vowels.size(); // 7
vowels.add('u'); // vowels is now ['a', 'e', 'i', 'o', 'i', 'e', 'a', 'u']
char a = vowels.get(0); // 'a'
boolean hadI = vowels.remove('i'); // true and vowels is now ['a', 'e', 'o', 'i', 'e', 'a', 'u']
boolean hasI = vowels.contains('i'); // true (still have one more left)
```
