# Introduction

Par défaut, les variables sont limitées à la portée dans laquelle elles sont définies. Si elles sont définies dans un fichier, en dehors d'une fonction ou d'une classe, elles sont limitées à la portée du fichier. Si elles sont définies dans une fonction ou une classe, elles sont limitées à la portée de cette fonction ou de cette classe.

```php
<?php

$file_scoped = "I am file scoped";

function example(): void
{
  $function_scoped = "I am function scoped!";
}
```

Il est également possible de déclarer des variables avec une portée spécifiquement `global` ou `static`.
