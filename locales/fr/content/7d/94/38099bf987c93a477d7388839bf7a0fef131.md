# Instructions

Dans cet exercice, tu dois implémenter quelques méthodes pour manipuler un tableau de langages de programmation.

## 1. Définis une méthode qui renvoie un tableau de langages vide

Définis la méthode `LanguageList.list` qui ne prend aucun argument et renvoie un tableau vide de type `Array(String)`.

```crystal
LanguageList.list()
# => []
```

## 2. Définis une méthode qui ajoute un langage au tableau

Définis la méthode `LanguageList.add` qui prend 2 arguments (un _tableau de langages_ et un littéral de chaîne contenant un _langage_).
La méthode doit renvoyer le tableau avec le nouveau langage ajouté à la fin du tableau.

```crystal
language_list = LanguageList.list()
# => []
language_list = LanguageList.add(language_list, "Crystal")
# => ["Crystal"]
language_list = LanguageList.add(language_list, "Ruby")
# => ["Crystal", "Ruby"]
```

## 3. Définis une méthode qui retire un langage du tableau

Définis la méthode `LanguageList.remove` qui prend 1 argument (un _tableau de langages_).
La méthode doit renvoyer le tableau sans le dernier élément.
On suppose que le tableau aura toujours au moins un élément.

```crystal
language_list = LanguageList.list()
# => []
language_list = LanguageList.add(language_list, "Crystal")
# => ["Crystal"]
language_list = LanguageList.add(language_list, "Ruby")
# => ["Crystal", "Ruby"]
language_list = LanguageList.remove(language_list)
# => ["Crystal"]
```

## 4. Définis une méthode qui renvoie le n-ième élément du tableau

Définis la fonction `LanguageList.at` qui prend 2 arguments (un _tableau de langages_ et un indice).
La méthode doit renvoyer le langage à l'indice n dans le tableau.
On suppose qu'il y aura toujours un langage à cet indice.

```crystal
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Crystal")
# => ["Crystal"]
language_list = LanguageList.add(language_list, "Ruby")
# => ["Crystal", "Ruby"]
LanguageList.at(language_list, 1)
# => "Ruby"
```

## 5. Définis une méthode qui analyse une chaîne de langages

Définis la méthode `LanguageList.parse` qui prend 1 argument (un littéral de chaîne contenant des langages séparés par une virgule).
La méthode doit renvoyer un tableau de langages.

```crystal
LanguageList.parse("Crystal, Ruby")
# => ["Crystal", "Ruby"]
```
