# À propos

Une _quotation_, écrite entre `[ ]`, est l'équivalent Factor d'une fonction anonyme ou d'un bloc de code. C'est une valeur de première classe que l'on peut empiler, stocker ou transmettre, et qui ne s'exécute que lorsque quelque chose l'*appelle*.

```factor
[ 1 + ]              ! a quotation, sitting on the stack
5 [ 1 + ] call .     ! => 6
```

Les _quotations_ sont des séquences de mots, et Factor les utilise partout où un bout de comportement doit être différé ou paramétré :

- les branches de `if` / `when` / `unless` / `cond`
- le prédicat de `filter`, `count`, `any?`, `all?`
- la transformation de `map`, `each`, `reduce`
- le corps de `times`, `while`, `loop`

L'effet sur la pile d'une _quotation_ peut généralement être déduit. Quand ce n'est pas possible, généralement lorsqu'on la stocke pour l'appeler plus tard avec `call`, déclare l'effet explicitement : `call( a b -- c )`.

## Combiner des _quotations_

```
compose ( quot1 quot2 -- compound )
curry   ( value quot  -- curried )
```

`compose` concatène deux _quotations_ bout à bout pour former une nouvelle _quotation_ qui exécute la première, puis la seconde. `curry` ajoute une valeur fixe en tête et renvoie une _quotation_ qui empilera cette valeur avant d'invoquer l'originale. Toutes les deux produisent des _quotations_ ordinaires que l'on peut `call`, stocker ou passer à des combinateurs.

```factor
USING: kernel math ;

3 [ 2 * ] [ 1 + ] compose call .   ! 3 2 * 1 + => 7
5 [ 1 + ] curry call .             ! 5 1 +     => 6
```
