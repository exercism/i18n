# Instructions

Traduis les séquences d'ARN en protéines.

L'ARN peut être découpé en séquences de trois nucléotides appelées codons, puis traduit en un polypeptide comme ceci :

ARN : `"AUGUUUUCU"` => se traduit en

Codons : `"AUG", "UUU", "UCU"`
=> qui forment un polypeptide dont la séquence est la suivante =>

Protéine : `"Methionine", "Phenylalanine", "Serine"`

Il existe 64 codons qui correspondent eux-mêmes à 20 acides aminés ; cependant, les séquences de codons et les acides aminés qui en résultent ne sont pas tous importants dans cet exercice.
Si le programme fonctionne pour un codon, il doit fonctionner pour tous.
Cependant, n'hésite pas à compléter la liste de la suite de tests pour les inclure tous.

Il existe aussi trois codons terminaux (aussi appelés codons « STOP ») ; si l'un de ces codons est rencontré (par le ribosome), toute la traduction s'arrête et la protéine est terminée.

Tous les codons qui suivent sont ignorés, comme ceci :

ARN : `"AUGUUUUCUUAAAUG"` =>

Codons : `"AUG", "UUU", "UCU", "UAA", "AUG"` =>

Protéine : `"Methionine", "Phenylalanine", "Serine"`

Note que le codon stop `"UAA"` met fin à la traduction et que la méthionine finale n'est pas traduite dans la séquence de la protéine.

Voici les codons et les acides aminés correspondants nécessaires pour cet exercice.

| Codon              | Protein       |
| :----------------- | :------------ |
| AUG                | Methionine    |
| UUU, UUC           | Phenylalanine |
| UUA, UUG           | Leucine       |
| UCU, UCC, UCA, UCG | Serine        |
| UAU, UAC           | Tyrosine      |
| UGU, UGC           | Cysteine      |
| UGG                | Tryptophan    |
| UAA, UAG, UGA      | STOP          |

Pour en savoir plus sur [la traduction des protéines sur Wikipédia][protein-translation].
