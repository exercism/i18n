# Articles

Chaque exercice peut avoir des articles qui lui sont associés, lesquels explorent un aspect intéressant de l'exercice.

## Thèmes

Thèmes qu'un article peut explorer :

- Comparer les performances de différentes approches
- Tout autre sujet intéressant que tu peux imaginer !

## Considérations générales

- Si ton article s'appuie sur du code que tu as écrit, pense à committer ce code (dans le répertoire de l'article)
  - Un exemple étant un article sur les performances, pour lequel du code de _benchmark_ a été écrit

## Pour quels exercices écrire des articles ?

N'importe quel exercice, tant qu'il y a quelque chose d'intéressant à explorer.

## Fichiers

Chaque article doit ajouter les deux fichiers suivants :

- `.articles/<article-slug>/content.md` : description de l'article (voir [la documentation](/docs/building/tracks/practice-exercises#file-articles-article-slug-content-md))
- `.articles/<article-slug>/snippet.md` : extrait présentant l'article (voir [la documentation](/docs/building/tracks/practice-exercises#file-articles-article-slug-snippet-txt))

Tu devras ensuite ajouter ou mettre à jour :

- `.articles/config.json` : métadonnées des articles (voir [la documentation](/docs/building/tracks/practice-exercises#file-article-config-json))
