# Introduction

Les exceptions sont une forme de gestion des erreurs.
On les appelle exceptions, car elles apparaissent généralement lorsqu'on a affaire à un événement inattendu.

À tout moment dans notre code, on peut « lever » une exception.
On y parvient avec la méthode `raise`, à laquelle on passe un objet (normalement un objet Exception, bien qu'on puisse aussi passer de simples _strings_).
Par exemple, tu verras dans les squelettes d'exercices qu'on utilise le `RuntimeError` intégré pour indiquer à Ruby qu'une méthode n'a pas été implémentée.
Tu peux aussi utiliser la syntaxe abrégée `raise(ExceptionObject, params)`.
Si on omet la classe de l'exception, c'est `RuntimeError` qui est utilisée par défaut.
Par exemple :

```ruby
# These are equivalent
raise RuntimeError.new("Please implement this method")
raise RuntimeError, "Please implement this method"
raise "Please implement this method"
```

Quand Ruby voit cela, il fait remonter l'erreur jusqu'au sommet du programme, puis s'arrête.
Par exemple, si tu essaies de diviser quelque chose par zéro, tu verras quelque chose comme ceci :
```ruby
5/0

#=> Traceback (most recent call last):
#=> ...
#=> ZeroDivisionError (divided by 0)
```
