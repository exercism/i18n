# Apprentissage

* [The Rust Programming Language](https://doc.rust-lang.org/book/) est une excellente ressource pour débuter en Rust comme pour approfondir certaines fonctionnalités du langage.
* [Rust by Example](https://doc.rust-lang.org/stable/rust-by-example/) te montre des exemples des éléments les plus courants que tu écriras en Rust.
* [Into_rust()](http://intorust.com/) « Des _screencasts_ pour apprendre Rust. »
* [Rustlings](https://github.com/carols10cents/rustlings) « De petits exercices pour t'habituer à lire et à écrire du code Rust. »
* Le [Rust User Forum](http://users.rust-lang.org) répond aux questions de tous niveaux
