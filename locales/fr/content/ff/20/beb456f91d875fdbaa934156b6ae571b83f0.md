# Introduction

## Les instructions `switch`

Comme une instruction _if/else_, une instruction `switch` permet de modifier le déroulement du programme en exécutant du code de façon conditionnelle.
La différence, c'est qu'une instruction `switch` peut uniquement comparer la valeur d'une expression de type primitif ou de type _string_ à des valeurs constantes prédéfinies.

Certains mots-clés sont utiles lorsqu'on utilise une instruction `switch`.

- `switch` : ce mot-clé permet de déclarer la structure du `switch`.
  Il est suivi de l'expression ou de la variable qui déterminera le résultat.
- `case` : tu utiliseras ce mot-clé pour déclarer les différentes possibilités de résultat.
- `break` : le mot-clé `break` est très utile pour arrêter l'exécution du `switch` à la fin du flux souhaité.
  Si tu l'oublies, le programme continue et risque de produire des résultats inattendus.
- `default` : comme son nom l'indique, utilise-le comme résultat par défaut quand aucun autre `case` ne correspond au résultat de ton expression.

Dans leur forme la plus simple, les instructions `switch` testent une expression de type primitif ou de type _string_ et prennent une décision en fonction de sa valeur.
Par exemple :

```java
String direction = getDirection();
switch (direction) {
    case "left":
        goLeft();
        break;
    case "right":
        goRight();
        break;
    default:
        // otherwise
        markTime();
        break;
}
```
