# Instructions

En passionné d'échecs, tu aimerais écrire ta propre version du jeu.
Oui, il existe sans doute déjà plein d'implémentations d'échecs en ligne, mais la tienne sera unique !

Tu commences par implémenter un système de déplacement de base pour les pièces.

Le jeu d'échecs se jouera sur un échiquier de 8 cases de large et de 8 cases de long.
Les cases sont identifiées par une lettre et un chiffre.

## 1. Définis l'intervalle des rangées et des colonnes

Le jeu devra stocker les rangées de l'échiquier.
Les rangées sont les lignes de l'échiquier et sont numérotées de 1 à 8.

Le jeu devra aussi stocker les colonnes de l'échiquier.
Les colonnes sont identifiées par les lettres A à H.

Définis les constantes `Chess::RANKS` et `Chess::FILES` qui stockent respectivement l'intervalle des rangées et des colonnes.

```ruby
Chess::RANKS
# => 1..8

Chess::FILES
# => 'A'..'H'
```

## 2. Vérifie si une case est valide

Le jeu devra vérifier si une case est valide.
Une case est valide si sa rangée et sa colonne se trouvent dans les intervalles des rangées et des colonnes.

Définis la méthode `Chess.valid_square?` qui prend les arguments `rank`, qui contient un entier représentant la rangée, et `file`, qui contient un caractère représentant la colonne.
La méthode doit renvoyer `true` si la rangée et la colonne se trouvent dans les intervalles des rangées et des colonnes, et `false` sinon.

```ruby
Chess.valid_square?(1, 'A')
# => true
```

## 3. Récupère le surnom du joueur

Le jeu devra récupérer le surnom du joueur.
Le surnom est composé des 2 premiers caractères du prénom du joueur et des 2 derniers caractères de son nom de famille.
Le surnom doit être en majuscules.

Définis la méthode `Chess.nickname` qui prend les arguments `first_name`, qui contient une _string_ du prénom du joueur, et `last_name`, qui contient une _string_ de son nom de famille.
La méthode doit renvoyer le surnom du joueur sous forme de _string_ en majuscules.

```ruby
Chess.nickname("John", "Doe")
# => "JOOE"
```

## 4. Crée le message de déplacement

Le jeu devra créer un message pour un déplacement, indiquant quel joueur s'est déplacé vers quelle case.
Le message doit utiliser le surnom du joueur et la case vers laquelle il s'est déplacé.
Le jeu doit aussi déterminer si le déplacement est valide en vérifiant que la colonne et la rangée de la case se trouvent dans les intervalles des colonnes et des rangées.

Si le déplacement est valide, le message doit être : `"{nickname} moved to {square}"`
Si le déplacement est invalide, le message doit être : `"{nickname} attempted to move to {square}, but that is not a valid square"`

Définis la méthode `Chess.move_message` qui prend les arguments `first_name`, qui contient une _string_ du prénom du joueur, `last_name`, qui contient une _string_ de son nom de famille, et `square`, qui contient une _string_ de la case vers laquelle le joueur s'est déplacé.
La méthode doit renvoyer le message du déplacement sous forme de _string_.

```ruby
Chess.move_message("John", "Doe", "A1")
# => "JOOE moved to A1"
```
