# Introduction

## Nil

[Nil][nil-dictionary] est un mot anglais qui signifie « rien » ou « zéro ». En Elixir, `nil` est une valeur spéciale qui signifie une _absence_ de valeur.

```elixir
# I do not have a favorite color
favorite_color = nil
```

Dans d'autres langages de programmation, les valeurs `null` ou `none` peuvent jouer un rôle similaire.

## If

Outre `cond`, Elixir fournit aussi la macro [`if/2`][getting-started-if], qui est utile quand on n'a qu'une seule condition à vérifier.

La macro [`if/2`][kernel-if] prend une condition et deux options. Elle renvoie la première option si la condition est _truthy_, et la seconde si la condition est _falsy_.

```elixir
age = 15

if age >= 16 do
  "You are allowed to drink beer in Germany."
else
  "No beer for you!"
end

# => "No beer for you!"
```

Il est aussi possible d'écrire une expression `if` sur une seule ligne. Remarque la virgule après la condition.

```elixir
if age > 16, do: "beer", else: "no beer"
```

Cette syntaxe est pratique pour les expressions très courtes, mais il vaut mieux l'éviter si l'expression ne tient pas sur une seule ligne.

### _Truthy_ et _falsy_

En Elixir, tous les types de données s'évaluent en une valeur _truthy_ ou _falsy_ lorsqu'ils apparaissent dans un contexte booléen (comme une expression `if`). Toutes les données sont considérées comme _truthy_ **sauf** `false` et `nil`. En particulier, les _strings_ vides, l'entier `0` et les listes vides sont tous considérés comme _truthy_ en Elixir.
