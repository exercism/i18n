# À propos

Une `Map` sert à stocker des paires de **clé** et de **valeur**. Les `Maps` sont initialisées comme un tableau, mais en utilisant l'opérateur de littéral de map `=>`. On peut également définir explicitement leurs types de clé et de valeur, ou laisser ces types être inférés. Les clés doivent être uniques, sinon une erreur est levée.

```haxe
var map1:Map<Int, String> = [1 => "one", 2 => "two", 3 => "three"];

var map2 = ["one" => 1, "two" => 2, "three" => 3];

var map3 = [1 => "cat", 1 => "dog"]; // Error: Duplicate Key

var map4 = ["h" => "Hello", "b" => "Bye"];
trace(map4["h"]); // Hello
```

Une `Map` peut être parcourue avec une boucle `for`. On peut itérer sur les valeurs ou sur les clés :

```haxe
for (value in map) {
  // ...
}

for (key in map.keys()) {
  // ...
}
```

Sous le capot, une `Map` est un type abstrait. À la compilation, elle est convertie en l'un de plusieurs types spécialisés selon le type de la clé :

- `String` : `haxe.ds.StringMap`
- `Int` : `haxe.ds.IntMap`
- `EnumValue` : `haxe.ds.EnumValueMap`
- `{}` : `haxe.ds.ObjectMap`

Le type `Map` n'existe pas à l'exécution et a été remplacé par l'un des objets ci-dessus.
