# Instructions complémentaires

## Instructions spécifiques à SQLite

Pour remplir la table `results`, il y a quatre « propriétés » à prendre en compte :

* **scores** : tu dois regrouper tous les scores pour chaque `game_id`, et les stocker dans une _string_ dont les valeurs sont séparées par des virgules.
  Les scores doivent apparaître dans le même ordre que celui dans lequel ils ont été insérés dans la table `scores`.
* **latest** : tu dois trouver le dernier score inséré dans la table `scores`.
* **personalBest** : trouve le score maximal pour chaque `game_id`.
* **personalTopThree** : trouve les trois scores les plus élevés pour chaque `game_id`, puis regroupe-les dans une _string_ dont les valeurs sont séparées par des virgules, triées par ordre décroissant.
