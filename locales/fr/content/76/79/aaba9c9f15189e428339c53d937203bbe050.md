# Introduction

JavaScript est un langage dynamique, qui prend en charge les styles orienté objet, impératif et déclaratif (comme la programmation fonctionnelle).

## (Ré-)Affectation

En JavaScript, il existe plusieurs façons principales d'affecter des valeurs à des noms : avec des variables ou des constantes. Sur Exercism, les variables s'écrivent toujours en [camelCase][wiki-camel-case] ; les constantes s'écrivent en [SCREAMING_SNAKE_CASE][wiki-snake-case]. Il n'existe aucun guide officiel à suivre, et chaque entreprise ou organisation a son propre guide de style. _Tu peux écrire tes variables comme tu veux_. L'avantage d'écrire tes variables comme les exercices les préparent, c'est qu'elles seront mises en évidence différemment dans l'interface web et dans la plupart des environnements de développement (IDE).

En JavaScript, les variables peuvent être définies avec le mot-clé [`const`][mdn-const], [`let`][mdn-let] ou [`var`][mdn-var].

Une variable déclarée avec `let` ou `var` peut référencer différentes valeurs au cours de sa durée de vie. Par exemple, `myFirstVariable` peut être définie et redéfinie plusieurs fois avec l'opérateur d'affectation `=` :

```javascript
let myFirstVariable = 1
myFirstVariable = 'Some string'
myFirstVariable = new SomeComplexClass()
```

Contrairement à `let` et `var`, une variable définie avec `const` ne peut être affectée qu'une seule fois. C'est ainsi que l'on définit des constantes en JavaScript.

```javascript
const MY_FIRST_CONSTANT = 10

// Can not be re-assigned.
MY_FIRST_CONSTANT = 20
// => TypeError: Assignment to constant variable.
```

> 💡 Dans un prochain exercice d'apprentissage, la différence entre l'affectation (ou la liaison) d'une _constante_ et la valeur _constante_ est explorée et expliquée.

## Déclarations de fonctions

En JavaScript, les unités de fonctionnalité sont encapsulées dans des _fonctions_ ; on regroupe généralement dans un même fichier celles qui vont ensemble. Ces fonctions peuvent prendre des paramètres (arguments) et _renvoyer_ une valeur avec le mot-clé `return`. Les fonctions sont appelées avec la syntaxe `()`.

```javascript
function add(num1, num2) {
  return num1 + num2
}

add(1, 3)
// => 4
```

> 💡 En JavaScript, il existe _beaucoup_ de façons différentes de déclarer une fonction. Ces autres façons sont différentes de l'utilisation du mot-clé `function`. Le parcours essaie de les introduire progressivement, mais si tu les connais déjà, n'hésite pas à en utiliser une. Dans la plupart des cas, utiliser l'une ou l'autre n'est ni mieux ni pire.

## Expose aux autres fichiers

Pour rendre une `function`, une constante ou une variable disponible dans _d'autres fichiers_, il faut l'[exporter][mdn-export] avec le mot-clé `export`. Un autre fichier peut ensuite les [importer][mdn-import] avec le mot-clé `import`. C'est ce qu'on appelle le système de modules. Le fonctionnement de tous les tests en est un excellent exemple. Chaque exercice comporte au moins un fichier, par exemple `lasagna.js`, qui contient l'_implémentation_. Il y a en plus au moins un autre fichier, par exemple `lasagna.spec.js`, qui contient les _tests_. Ce fichier _importe_ les entités publiques (c'est-à-dire exportées) afin de tester l'implémentation :

```javascript
// file.js
export const MY_VALUE = 10

export function add(num1, num2) {
  return num1 + num2
}

// file.spec.js
import { MY_VALUE, add } from './file'

add(MY_VALUE, 5)
// => 15
```
