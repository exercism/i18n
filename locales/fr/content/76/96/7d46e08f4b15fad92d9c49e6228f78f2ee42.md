# Indices

## 1. Implémente l'interface `Stringer` pour le type `TemperatureUnit`

- Le type `TemperatureUnit` est déjà créé pour toi et représente une unité de température
- Note que 2 constantes de ce type sont déjà créées pour toi : `Celsius` et `Fahrenheit`, qui représentent respectivement une température en Celsius et en Fahrenheit
- Ajoute une méthode `String()` au type `TemperatureUnit` pour qu'il satisfasse l'interface `Stringer`.
  Cette méthode doit renvoyer la _string_ `"°C"` si l'unité de température est Celsius, ou `"°F"` si l'unité de température est Fahrenheit

## 2. Implémente l'interface `Stringer` pour le type `Temperature`

- Ajoute une méthode `String()` au type `Temperature` pour qu'il satisfasse l'interface `Stringer`
- La méthode `String()` doit renvoyer une _string_ contenant la valeur numérique de la température et l'unité de température, séparées par un espace (`<temperature> <unit>`)
- La structure `Temperature` contient un `TemperatureUnit` et un `int`.
  Tu peux utiliser [fmt.Sprintf][sprintf] pour t'aider à formater cette _string_
- Comme `TemperatureUnit` implémente déjà l'interface `Stringer` (depuis la tâche 1), les fonctions du paquet `fmt` comme [fmt.Sprintf][sprintf] sauront comment la formater quand tu utilises les [verbes de formatage][fmt] `%v` ou `%s`

## 3. Implémente l'interface `Stringer` pour le type `SpeedUnit`

- Le type `SpeedUnit` est déjà créé pour toi et représente une unité de température

- Ajoute une méthode `String()` au type `SpeedUnit` pour qu'il satisfasse l'interface `Stringer`.
  Cette méthode doit renvoyer la _string_ `"km/h"` si l'unité de vitesse est en kilomètres par heure, ou `"mph"` si l'unité de vitesse est en miles par heure.

- `Speed` contient un champ `Temperature` et un champ `Speed`, entre autres champs.
