# Return

En Crystal, la dernière expression d'une méthode renvoie sa valeur.
Cependant, il faut parfois renvoyer une valeur avant la dernière expression.
Pour cela, on peut utiliser le mot-clé `return`, qui renvoie la valeur de l'expression qui suit.
Le code écrit après un mot-clé `return` ne sera pas exécuté.

```crystal
def speed_limit(road_number)
    if road_number == 1
        return 50
        puts "This will not be executed"
    elsif road_number == 2
        return 80
        puts "This will not be executed"
    end
    100
end

p speed_limit(1) # => 50
p speed_limit(2) # => 80
p speed_limit(3) # => 100
```

~~~~exercism/note
Le mot-clé `return` doit être omis lorsque la dernière expression d'une méthode est la valeur à renvoyer.
~~~~
