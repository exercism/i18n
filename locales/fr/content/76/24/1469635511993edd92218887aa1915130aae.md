# À propos

La [forme spéciale with][with] permet de se concentrer sur le « happy path » d'une série d'étapes susceptibles d'échouer, et de gérer les échecs plus tard.

Imaginons que tu veuilles valider un nom d'utilisateur à l'aide de plusieurs vérifications. Tu pourrais te tourner vers `case` :

```elixir
case check_ascii(username) do
  {:ok, username} ->
    case check_starts_with_letter(username) do
      {:ok, username} ->
        {:ok, username}

      {:error, "usernames may only start with a letter"} = err ->
        err
    end

  {:error, "usernames may only contain ascii letters"} = err ->
    err
end
```

C'est peut-être lisible pour l'instant, mais si tu ajoutes d'autres vérifications imbriquées, ça va devenir plus confus. Dans ce cas, utilise `with` :


```elixir
with {:ok, username} <- check_ascii(username),
     {:ok, username} <- check_starts_with_letter(username),
     {:ok, username} <- check_not_a_joke_name(username),
     {:ok, username} <- check_if_available(username) do
  {:ok, "#{username} is a fine username and you deserve it!"}
end
```

À chaque étape, si une clause correspond, la chaîne se poursuit jusqu'à ce que le bloc `do` soit exécuté. Si une correspondance échoue, la chaîne s'arrête et la clause qui ne correspond pas est renvoyée.

Tu peux utiliser des gardes dans la chaîne, ainsi que l'opérateur `=` pour les correspondances classiques.

```elixir
with {:ok, id} <- get_id(username),
     {:ok, avatar} when is_bitstring(avatar) <- fetch_avatar(id),
     avatar_size = bit_size(avatar),
     {:ok, image_type} <- check_valid_image_type(avatar) do
  {:ok, image_type, avatar_size, avatar}
end
```

Enfin, tu as la possibilité d'utiliser un bloc `else` pour intercepter les correspondances qui échouent et modifier la valeur de retour.

```elixir
with {:ok, id} <- get_id(username),
     {:ok, avatar} when is_bitstring(avatar) <- fetch_avatar(id),
     avatar_size = bit_size(avatar),
     {:ok, image_type} <- check_valid_image_type(avatar) do
  {:ok, image_type, avatar_size, avatar}
else
  :not_found ->
    {:error, "invalid username"}

  {:error, "not an image"} ->
    {:error, "avatar associated to #{username} is not an image"}

  err ->
    err
end
```

Le bloc `else` s'apparente à une instruction `case` pour toute valeur qui ne correspond pas dans la clause `with`. La première valeur qui correspond est utilisée.
