# À propos

`reduce` est le _fold_ général de Factor : il parcourt une séquence en faisant passer un accumulateur dans une _quotation_ binaire qui prend l'accumulateur courant et l'élément suivant, et produit le nouvel accumulateur.

```
reduce ( seq init quot: ( prev elt -- next ) -- result )
```

```factor
USING: math sequences ;

{ 1 2 3 4 } 0 [ + ] reduce .         ! => 10
{ 1 2 3 4 } 1 [ * ] reduce .         ! => 24
```

Une valeur initiale personnalisée permet à `reduce` d'exprimer des _folds_ que `sum` ou `product` ne peuvent pas produire. Par exemple, la plus grande valeur d'une séquence, avec une valeur par défaut si chaque élément perd la comparaison :

```factor
USING: math.order ;

{ 3 1 -4 5 -2 } 0 [ max ] reduce .   ! => 5
{ -3 -1 -4 }    0 [ max ] reduce .   ! => 0
```

La valeur initiale `0` participe à la comparaison, donc une séquence entièrement négative produit quand même `0` plutôt que sa plus petite valeur.

## `produce`, l'_unfold_

Le dual de `reduce` est `produce` (dans [`sequences`][sequences]) : là où `reduce` *consomme* une séquence, `produce` en *génère* une. Une _quotation_ de prédicat teste l'état courant ; tant qu'elle renvoie une valeur vraie, une _quotation_ de corps produit l'élément suivant.

```
produce ( pred quot -- seq )
```

Utilisés ensemble, `reduce` et `produce` forment la paire _fold_/_unfold_ de Factor.

## Les réductions cumulatives

La famille de mots cumulatifs de [`math.statistics`][math.statistics] renvoie une séquence de même longueur que l'entrée, où chaque élément est la réduction du préfixe jusqu'à cette position incluse :

| mot           | opération cumulée |
|---------------|-------------------|
| `cum-sum`     | total cumulé      |
| `cum-product` | produit cumulé    |
| `cum-min`     | minimum cumulé    |
| `cum-max`     | maximum cumulé    |

```factor
USING: math.statistics ;

{ 3 1 4 1 5 9 2 6 } cum-sum .         ! => { 3 4 8 9 14 23 25 31 }
{ 3 1 4 1 5 9 2 6 } cum-min .         ! => { 3 1 1 1 1 1 1 1 }
{ 3 1 4 1 5 9 2 6 } cum-max .         ! => { 3 3 4 4 5 9 9 9 }
```

Les réductions cumulatives sont utiles quand on veut voir *comment* une quantité a évolué au fil de la séquence, et pas seulement sa valeur finale. Il est également utile de les enchaîner : la sortie d'une réduction cumulative est elle-même une séquence, prête à alimenter la suivante.
