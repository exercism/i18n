# Introduction

En Common Lisp, les _strings_ sont des [vecteurs][concept-vectors] de [caractères][concept-characters].
On les écrit comme des caractères entourés de guillemets doubles (par exemple "Hello World!").

Le prédicat `stringp` renvoie vrai uniquement si la valeur donnée est une _string_.

On peut découper les _strings_ en sous-chaînes avec la fonction `subseq`, qui prend la _string_, un indice de début et, éventuellement, un indice de fin.
L'indexation commence à zéro.

```lisp
(subseq "Hello World" 1 5)   ; => "ello"
(subseq "skip to the end" 5) ; => "to the end"
```

On peut comparer les _strings_ pour vérifier leur égalité avec `string=`.
Si la casse des caractères doit être ignorée, on peut utiliser `string-equal`.

```lisp
(string= "macaroni" "macaroni")      ; => T
(string= "macaroni" "MACARONI")      ; => NIL
(string-equal "macaroni" "MACARONI") ; => T
```

On peut effectuer des opérations comme la mise en majuscules, la mise en minuscules et la capitalisation des _strings_ avec `string-upcase`, `string-downcase` et `string-capitalize`.

```lisp
(string-upcase "not too loud")                ; => "NOT TOO LOUD"
(string-downcase "YELL IT FROM THE ROOFTOPS") ; => "yell it from the rooftops"
(string-capitalize "practical COMMON LiSP")   ; => "Practical Common Lisp"
```
