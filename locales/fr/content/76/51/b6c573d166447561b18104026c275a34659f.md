# Généralités

- N'oublie pas d'exposer toutes les fonctions dont les tests ont besoin.

## 1. Définis le type opaque `Password`, en utilisant le principe « Parse, don't validate »

- Le guide Elm contient une section sur les [types personnalisés][custom-types].
- Le type personnalisé `Password` ne possède qu'une seule variante.
- En Elm, l'usage veut que, lorsqu'un type personnalisé n'a qu'une seule variante, la variante et le type portent le même nom (ici, les deux s'appellent `Password`).
- Le guide Elm contient une section sur [Maybe][maybe] si tu as besoin d'un rappel.
