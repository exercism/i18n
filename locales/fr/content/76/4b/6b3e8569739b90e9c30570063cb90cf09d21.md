# À propos

Pour entamer le voyage en C++, on commence par les variables, les appels de fonction et les commentaires.

## Commentaires

Les commentaires existent sous deux formes : sur une seule ligne ou sur plusieurs lignes.
Tout ce qui suit `//` sur la même ligne est ignoré par le compilateur.
Les commentaires sur plusieurs lignes sont aussi appelés commentaires de style C.
Ils sont encadrés par `/*` et `*/`.
Tout ce qui se trouve entre ces deux marqueurs est également ignoré.

## Variables

Le C++ est un langage typé.
Tous les types doivent être connus au moment de la compilation, et il faut généralement les indiquer explicitement.
Le type d'une variable ne peut pas changer.
On peut déclarer une variable de type entier nommée `years` comme ceci :

```cpp
int years;
```

C'est une bonne pratique d'initialiser les variables dès leur déclaration.
Le C++ offre différents mécanismes pour cela.
La version avec les accolades est plus conforme au C++ moderne, mais la version avec le signe égal est aussi très courante.

```cpp
int tomatoes{80};
int potatoes = 40;
```

~~~~exercism/caution
Le C++ autorise bel et bien l'utilisation de variables non initialisées.
Tant qu'on ne lui a pas volontairement donné de valeur, la variable est indéfinie et peut contenir n'importe quoi.
Pour éviter les erreurs d'utilisation avant affectation et le comportement indéfini, il est conseillé de **toujours initialiser**.
Un comportement indéfini peut faire planter ton programme au pire moment possible, alors qu'il fonctionnait très bien jusque-là.
On ne le répétera jamais assez : évite le comportement indéfini à tout prix.
~~~~

## Opérations arithmétiques

Les opérateurs arithmétiques comme `*`, `+` ou `-` peuvent faire partie d'une expression comme `3 * 2` ou `tomatoes + potatoes`.

## Mets à jour les variables

Tu peux réaffecter des variables, tant qu'elles conservent leur type :

```cpp
tomatoes = tomatoes - 5; // tomatoes is now 75
potatoes = (32 * 2) + 11; // potatoes is now 75 as well
```

## Fonctions

Une fonction a un nom, un type de retour et une liste de paramètres (éventuellement vide).
Voici à quoi ressemblerait une fonction nommée `always_fortyseven` qui renverrait toujours 47 :

```cpp
int always_fortyseven() {
    return 47;
}
```

Voici `vip_fee`, qui prend un paramètre :
```cpp
int vip_fee(int standard_fee) {
    /*
    vip_fee calculates the vip fee based on the standard_fee.
    */
    int vip_multi{3};
    return standard_fee * vip_multi;
}
```

Ou `total_fee`, une fonction qui prend trois paramètres et qui appelle une autre fonction.

```cpp
int total_fee(int vips, int adults, int kids) {
    /*
    total_fee calculates the total price for a group of VIP and adult guests with kids.
    Kids get a flat discount on the standard fee.
    VIP guest fees are calculated by calling vip_fee.
    */
    int standard_fee{30};
    int kids_discount{15};

    int kids_total_fee = kids  * (standard_fee - kids_discount);
    int vips_total_fee = vips * vip_fee(standard_fee);
    int adult_total_fee = adults * standard_fee;

    return vips_total_fee + adult_total_fee + kids_total_fee;
}
```

En C++, les fonctions ne renvoient pas la valeur de la dernière instruction comme dans certains autres langages.
Le mot-clé `return` est obligatoire pour que le code compile.

### Les espaces blancs

Les espaces blancs servent à mettre en forme le code source et regroupent les espaces, les tabulations et les retours à la ligne.
Comme le compilateur ignore les espaces blancs inutiles, tu peux t'en servir pour structurer ton code.
Un usage judicieux des espaces blancs peut améliorer la lisibilité de ton code.
Il existe différents standards de formatage, mais ils sont tous conventionnels et ne sont pas imposés par le compilateur.

```cpp
// Formatting makes it easier to find bugs

int eggs_yolks =  3;
int      yeast = 15;

int flour=500;int sugar=200;// compact, but difficult to read
```
