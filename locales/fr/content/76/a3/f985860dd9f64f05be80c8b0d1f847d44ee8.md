# À propos

Une structure ou une classe peut définir des _propriétés stockées_, qui sont définies et se comportent exactement comme des constantes ou des variables ordinaires, et qui sont stockées dans une instance de cette structure ou de cette classe.

```swift
class GameCharacter {
  var health = 10
  let id = makeRandomID()
}

let character1 = GameCharacter()
let character2 = GameCharacter()

character1.health // => 10
character2.health // => 10

character1.health = 25

character1.health // => 25
character2.health // => 10

// This would trigger a compiler error due to id being a constant
// character2.id = 2
```
