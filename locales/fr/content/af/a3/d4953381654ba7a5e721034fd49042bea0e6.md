# Espace réservé

## Implémente les opérations de List

Le but de cet exercice est d'implémenter toi-même certaines des méthodes de List.
Il est naturel d'utiliser un objet List en interne pour stocker les données.
Ne touche pas aux méthodes de List (comme `where`, `map`, etc.).

Il y a quelques opérations « primitives » de List qui sont incontournables, comme :

* le découpage : `list[from..to]`
* l'ajout : `list.add(item)`

## Le protocole d'itérateur

Les opérations de liste à implémenter consistent toutes à itérer de différentes manières.
Renseigne-toi sur [le protocole d'itérateur][iter].
Tu pourras alors faire :

```wren
var list = ListOps.new([1, 2, 3, 4])
for (item in list) {
    do_something_with(item)
}
```

[iter]: https://wren.io/control-flow.html#the-iterator-protocol
