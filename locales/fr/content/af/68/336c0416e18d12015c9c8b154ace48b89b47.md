# Installation

Le [Godot Engine][godot-engine] sert à exécuter du code GDScript.
Le Godot Engine fonctionne sous Windows, Linux, macOS et Android.

## Installe Godot Engine

Le Godot Engine peut être téléchargé directement depuis [le site web de Godot Engine][download].
Le téléchargement contient un dossier zip avec deux exécutables, tous deux nommés d'après la version du Godot Engine.
Décompresse-le et ouvre le premier exécutable.

Si tu as besoin d'un guide vidéo, il y en a un [ici][video-guide] (il devrait fonctionner avec Godot 4.7 ou avec n'importe quelle autre version de Godot).

Ce parcours utilise Godot en version 4.7.2.

[godot-engine]: https://godotengine.org/
[download]: https://godotengine.org/download/
[video-guide]: https://www.youtube.com/watch?v=wOTZo0a_Fek
