# Introduction

Cet exercice va t'apprendre les fondements de Ruby.
Il couvre beaucoup de choses, mais ne t'inquiète pas s'il te semble dense : nous reviendrons sur chaque point bien plus en détail au fil du parcours.

L'une des choses essentielles à comprendre à propos de Ruby, c'est qu'il s'agit d'un [langage orienté objet][object-oriented-programming] et que **tout, en Ruby, est un [objet][object]**. Les nombres, les _strings_, les tableaux : ce sont tous des objets.

## Variables et constantes

On a l'habitude d'utiliser les objets en leur donnant un nom, que ce soit avec des variables ou des constantes.

Les variables s'écrivent toujours en [`snake_case`][snake-case].
Au cours de sa vie, une variable peut faire référence à différents objets.
Par exemple, `my_first_variable` peut être définie et redéfinie autant de fois que nécessaire avec l'opérateur `=` :

```ruby
my_first_variable = 1
my_first_variable = "Some string"
my_first_variable = SomeComplexObject.new
```

Les constantes, en revanche, sont censées n'être affectées qu'une seule fois.
Elles doivent commencer par une majuscule et s'écrivent normalement en majuscules, les mots étant séparés par des tirets bas.
Par exemple :

```ruby
MY_FIRST_CONSTANT = 10

# Redefining not allowed
# MY_FIRST_CONSTANT = "Some String"
```

## Classes

Ruby est organisé en classes.
Les classes se définissent avec le mot-clé `class`, suivi du nom de la classe.
Les objets sont généralement créés en instanciant des classes avec la méthode `.new`.
Par exemple :

```ruby
# Define the class
class Calculator
  #...
end

# Create an instance of it and assign it to a variable
my_first_calc = Calculator.new
```

## Méthodes

Les unités de fonctionnalité sont encapsulées dans des méthodes, un peu comme les _fonctions_ dans d'autres langages.

Une méthode peut être définie avec des arguments positionnels, des arguments nommés (que l'on définit et appelle avec la syntaxe `:`) ou sans aucun argument.

Une méthode renvoie implicitement le résultat de la dernière instruction évaluée, ou peut renvoyer explicitement un objet avec le mot-clé `return`.

```ruby
class Calculator

  # Positional arguments
  def add(num1, num2)
    return num1 + num2 # Explicit return
  end

  # Keyword arguments
  def multiply(num1:, num2:)
    num1 * num2 # Implicit return
  end
end
```

Les méthodes s'appellent avec la syntaxe `.` :

```ruby
calc = Calculator.new
calc.add(1, 3)
calc.multiply(num1: 2, num2: 5)
```
