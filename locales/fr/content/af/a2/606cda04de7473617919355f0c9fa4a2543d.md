# Indices

## Général

- Chaque tâche n'est qu'une fine surcouche autour d'un mot du vocabulaire
  [`math.combinatorics`][math.combinatorics].
- Les mots de comptage prennent deux entiers ; les mots de listage prennent une
  séquence.

## 1. Compte les combinaisons

- `nCk ( n k -- m )` renvoie le nombre de façons de choisir `k` éléments
  parmi `n`. La pile est déjà dans le bon ordre : il suffit de l'appeler.

## 2. Compte les permutations

- `nPk ( n k -- m )` renvoie le nombre de façons ordonnées de choisir `k`
  éléments parmi `n`.

## 3. Liste les combinaisons

- `all-combinations ( seq k -- combinations )` renvoie chaque
  sous-ensemble de `k` éléments de `seq`, dans l'ordre lexicographique.

## 4. Liste les permutations

- `all-permutations ( seq -- permutations )` renvoie toutes les façons
  d'ordonner `seq`.

## 5. Combinaisons dont la somme atteint une cible

- Pars de toutes les combinaisons de `k` éléments fournies par
  `all-combinations`.
- Ne garde que celles dont les éléments ont pour somme `target`. `filter` de
  [`sequences`][sequences] prend une _quotation_ qui renvoie un booléen ;
  à l'intérieur, `sum` (de [`math`][math]) fait la somme d'une combinaison, et
  `=` la compare avec la cible.
- Comme la tâche a besoin de `target` à l'intérieur de la _quotation_,
  définir le mot avec `::` (de [`locals`][locals]) permet de désigner `seq`,
  `k` et `target` par leur nom.
