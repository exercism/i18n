# À propos

Au-delà des classes de caractères et des quantificateurs, les expressions régulières peuvent décrire la *structure* et le *contexte* d'un texte. Ces fonctionnalités font partie du même vocabulaire [`regexp`][regexp], que l'on écrit avec le littéral `R/ /`.

## Groupes et alternatives

Les parenthèses `( )` regroupent une partie d'un motif, de sorte qu'un quantificateur ou un `|` (« ceci ou cela ») s'applique à tout le groupe. Un `?` placé après un groupe le rend facultatif :

```factor
USING: regexp ;

"abab"    R/ (ab)+/ matches? .             ! => t
"cat"     R/ cat|dog/ matches? .           ! => t
"$100.50" R/ \$\d+(\.\d{2})?/ matches? .   ! => t
"$100"    R/ \$\d+(\.\d{2})?/ matches? .   ! => t   (group optional)
```

## Ancres

```
^    ! start of the string
$    ! end of the string
\b   ! a word boundary
```

Une *limite de mot* (`\b`) est l'endroit où un caractère de mot (une lettre, un chiffre ou un tiret bas) en rencontre un qui n'en est pas un, y compris aux extrémités de la chaîne. Ainsi, `\bcat\b` ne correspond à `cat` que lorsque celui-ci est isolé :

```factor
USING: regexp ;

"cat nap" R/ \bcat\b/ re-contains? .   ! => t
"scatter" R/ \bcat\b/ re-contains? .   ! => f
```

## Lookaround

Un _lookaround_ teste ce qui se trouve juste avant ou juste après un endroit donné, sans que ces caractères fassent partie de la correspondance : sa largeur est nulle.

```
(?=...)    ! lookahead
(?!...)    ! negative lookahead
(?<=...)   ! lookbehind
```

```factor
USING: regexp ;

"spent $100 and $25" R/ (?<=\$)\d+/ all-matching-subseqs .
! => { "100" "25" }

"up 5% then 12%" R/ \d+(?=%)/ all-matching-subseqs .
! => { "5" "12" }
```

## Options

Une lettre d'option placée après le `/` de fermeture modifie l'ensemble du motif. `i` rend la recherche insensible à la casse :

```factor
USING: regexp ;

"REFUND" R/ refund/i matches? .   ! => t
```

## Transforme chaque correspondance

`map-matches` exécute une _quotation_ sur chaque correspondance et rassemble les résultats ; `each-match` fait de même, mais uniquement pour les effets de bord. Les deux passent à la _quotation_ l'indice `start` de la correspondance, son indice `end` et la chaîne entière, si bien que `subseq` permet de récupérer le texte correspondant :

```
map-matches ( string regexp quot: ( start end string -- obj ) -- seq )
each-match  ( string regexp quot: ( start end string --     ) --     )
```

```factor
USING: math regexp sequences ;

"a1 b22 c333" R/ \d+/ [ subseq length ] map-matches .
! => { 1 2 3 }
```

## Ce que Factor ne prend pas en charge

Le moteur d'expressions régulières de Factor ne sait pas **extraire les groupes de capture** (un groupe `( )` structure le motif, mais on ne peut pas relire le texte auquel il correspond), ne gère pas les **rétroréférences** (`\1`) ni les quantificateurs **paresseux / non gourmands** (`*?`, `+?`). Le _lookaround_ est le substitut idiomatique des groupes de capture : on fait correspondre la partie qui nous intéresse, reconnue grâce au contexte qui l'entoure.
