# Introduction

Haxe prend en charge nativement les expressions régulières. On peut les utiliser pour vérifier le format d'une _string_, transformer une _string_ ou extraire des données régulières d'un texte donné.

Pour créer une expression régulière, saisis entre `~/` et `/` :

```haxe
var r = ~/haxe/i;
```

Une autre façon de procéder consiste à utiliser l'instance `EReg()` :

```haxe
var r = new EReg("haxe", "i");
```

Ici, le `i` est une option qui rend le motif insensible à la casse. Il existe d'autres options, notamment :

- `g` : remplacement global.
- `m` : correspondance multiligne

Entre `~/` et `/`, on saisit les motifs d'expressions régulières. Par exemple, tu veux chercher une _string_ qui contient des lettres de A à Z. Ici, on peut utiliser le motif d'intervalle `[A-Z]`. Il existe de nombreux motifs d'expressions, notamment :

- `.` : n'importe quel caractère
- `*` : répéter zéro ou plusieurs fois
- `+` : répéter une ou plusieurs fois
- `[A-Z0-9]` : intervalles de caractères
