# Ajout aux instructions

## Messages d'exception

Il est parfois nécessaire de [lever une exception](https://docs.python.org/3/tutorial/errors.html#raising-exceptions). Dans ce cas, tu dois toujours inclure un **message d'erreur explicite** pour indiquer l'origine de l'erreur. Cela rend le code plus lisible et facilite grandement le débogage. Lorsque tu sais que la source de l'erreur sera d'un type donné, tu peux choisir de lever l'un des [types d'erreur intégrés](https://docs.python.org/3/library/exceptions.html#base-classes), mais tu dois tout de même inclure un message explicite.

Cet exercice en particulier exige que tu utilises [l'instruction `raise`](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement) pour « lever » une `ValueError` lorsque des bases d'entrée ou de sortie ne sont pas valides. Les tests ne seront réussis que si tu utilises `raise` sur l'`exception` en y joignant un message explicite.

Pour lever une `ValueError` avec un message, écris ce message comme argument du type `exception` :

```python
# for input.
raise ValueError("input base must be >= 2")

# another example for input.
raise ValueError("all digits must satisfy 0 <= d < input base")

# or, for output.
raise ValueError("output base must be >= 2")
```
