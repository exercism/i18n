# Introduction

Les types opaques en Gleam sont des types personnalisés dont seul le module qui définit le type peut construire les valeurs ou effectuer un filtrage par motif dessus. C'est utile pour créer des types qui ne doivent être utilisés que d'une manière bien précise.

Les types opaques se définissent à l'aide du mot-clé `opaque`.

```gleam
pub opaque type PositiveInt {
  PositiveInt(inner: Int)
}
```

Ce type `PositiveInt` est prévu pour les situations où l'on veut un entier, mais un entier supérieur ou égal à zéro. On ne peut pas utiliser un `Int` Gleam classique, car il peut aussi être négatif.

Le module qui définit ce type peut définir une fonction pour obtenir l'entier qu'il contient, et une fonction pour créer le type `PositiveInt`, laquelle renvoie une erreur si la valeur n'est pas positive.

```gleam
pub fn from_int(i: Int) -> Result(PositiveInt, String) {
  case i {
    _ if i < 0 -> Error("Value must be positive")
    _ -> Ok(PositiveInt(i))
  }
}

pub fn to_int(i: PositiveInt) -> Int {
  i.inner
}
```

Avec cette API, les autres modules ne peuvent pas construire de `PositiveInt` avec une valeur négative, donc toute fonction qui prend un `PositiveInt` peut être certaine que la valeur est positive.
