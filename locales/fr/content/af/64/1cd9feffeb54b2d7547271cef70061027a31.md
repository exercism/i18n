# Indices

## Général

- Le [tutoriel csharp.net sur les _strings_][tutorial-csharp.net-strings] offre une bonne introduction aux `string` C#.
- La classe `string` dispose de nombreuses [méthodes intégrées][docs-string-methods] utiles.

## 1. Récupère le message d'une ligne de log

- [Ce tutoriel][tutorial-docs.microsoft.com-search-text-in-string] explore différentes options pour rechercher du texte dans une _string_.
- La suppression des espaces blancs est [intégrée][tutorial-docs.microsoft.com-trim-white-space].

## 2. Récupère le niveau de log d'une ligne de log

- La modification de la casse d'un `string` est expliquée dans [ce tutoriel][tutorial-docs.microsoft.com-changing-case].

## 3. Reformate une ligne de log

- Il y a plusieurs façons de [concaténer des _strings_][tutorial-docs.microsoft.com-concatenate-strings], mais celle qui est privilégiée est généralement [l'interpolation de chaînes de caractères][tutorial-csharp.net-string-interpolation].
