# Indices

## Généralités

- Pense à bien lire la documentation des [décodeurs][decode] et des [encodeurs][encode]
- La [documentation GitHub][github] qui a inspiré cet exercice contient plus d'informations sur les objets JSON
- Tu devrais pouvoir utiliser [`Decode.decodeString`][decode-decodeString] pour tester tes décodeurs sur des entrées arbitraires

## 1. Un identifiant, s'il te plaît !

Cette tâche peut être résolue avec les fonctions suivantes :

- [`int`][decode-int]
- [`field`][decode-field]

## 2. C'est quoi déjà mon nom ?

Il y a deux façons principales de résoudre cette tâche :

- en utilisant [`maybe`][decode-maybe]
- en utilisant [`oneOf`][decode-oneOf] avec deux décodeurs possibles, l'un combinant [`field`][decode-field], [`string`][decode-string] et [`map`][decode-map], et l'autre utilisant [`succeed`][decode-succeed]

## 3. Un utilisateur ? À peine si je le connais !

Cette tâche peut être résolue avec les fonctions suivantes :

- `decodeId` et `decodeName`
- `User` utilisé comme constructeur de type
- [`map5`][decode-map5]
- [`field`][decode-field]
- [`int`][decode-int]
- [`string`][decode-string]
- [`bool`][decode-bool]

## 4. Je suis un commentaire fort et indépendant

Cette tâche peut être résolue avec les fonctions suivantes :

- [`field`][decode-field]
- [`int`][decode-int]
- [`nullable`][decode-nullable]

## 5. Un petit boulot

Cette tâche peut être résolue avec les fonctions suivantes :

- [`field`][decode-field]
- [`string`][decode-string]
- [`andThen`][decode-andThen]
- une instruction `case` qui vérifie le contenu de la _string_ en cours de décodage
- [`succeed`][decode-succeed]
- [`fail`][decode-fail]

## 6. Le réveil des liens

Cette tâche peut être résolue avec les fonctions suivantes :

- [`field`][decode-field]
- [`dict`][decode-dict]
- [`string`][decode-string]

## 7. Oui, des commentaires

`decodeComment` peut être résolu avec les fonctions suivantes :

- `decodeId`, `decodePullRequestReviewId`, `decodeUser`, `decodeSide`, `decodeLinks`
- `Comment` utilisé comme constructeur de type
- [`6`][decode-6]
- [`field`][decode-field]
- [`string`][decode-string]

`decodeComments` peut être résolu avec les fonctions suivantes :

- `decodeComment`
- [`list`][decode-list]

## 8. Tout se tient

Toutes les fonctions nécessaires à cette tâche sont définies dans [la documentation des encodeurs][encode], et peut-être certaines du [module `Maybe`][maybe]
