# Indices

## Généralités

- Les [ensembles][sets] sont des collections mutables et non ordonnées, sans éléments en double.
- Un ensemble peut contenir n'importe quel type de données.
- Les ensembles sont [itérables][iterable].
- On utilise le plus souvent les ensembles pour dédupliquer rapidement d'autres collections ou pour tester l'appartenance d'un élément.
- Les ensembles prennent aussi en charge des opérations mathématiques comme `union`, `intersection`, `difference` et `symmetric difference`.

## 1. Nettoie les ingrédients des plats

- Le constructeur `Set()` peut prendre n'importe quel [itérable][iterable] comme argument. Les vecteurs sont itérables.
- Rappel : on peut former des tuples avec `(element_1, element_2)`.

## 2. Cocktails et mocktails

- Un `Set` est _disjoint_ d'un autre ensemble si les deux ensembles n'ont aucun élément en commun.
- Le constructeur `Set()` peut prendre n'importe quel [itérable][iterable] comme argument. Les vecteurs sont itérables.
- On peut concaténer des _strings_ avec le signe `*`, et l'interpolation se fait via `$()`.

## 3. Classe les plats par catégorie

- Ici, parcourir les catégories de plats disponibles avec des boucles peut être utile.
- Si tous les éléments de `set_1` sont contenus dans `set_2`, alors `set_1 ⊆ set_2`.
- L'équivalent en méthode de `set ⊆ iterable` est `issubset(set, iterable)`.
- Les tuples peuvent contenir n'importe quel type de données, y compris d'autres tuples. On peut former des tuples avec `(element_1, element_2)`.
- On peut accéder aux éléments d'un tuple depuis la gauche avec un indice commençant à 1, ou depuis la droite avec un indice basé sur `end` (par exemple `tuple[end]`).
- Le constructeur `Set()` peut prendre n'importe quel [itérable][iterable] comme argument. Les vecteurs sont itérables.
- On peut concaténer des _strings_ avec le signe `*`, et l'interpolation se fait via `$()`.

## 4. Étiquette les allergènes et les aliments à éviter

- Une _intersection_ d'ensembles est l'ensemble des éléments communs à `set_1` et `set_2`.
- L'équivalent en méthode d'ensemble de `set ∩ iterable` est `intersect(set, iterable)` ou `∩(set, iterable)`.
- On peut accéder aux éléments d'un tuple depuis la gauche avec un indice commençant à 1, ou depuis la droite avec un indice basé sur `end` (par exemple `tuple[end]`).
- Le constructeur `Set()` peut prendre n'importe quel [itérable][iterable] comme argument. Les vecteurs sont itérables.
- On peut former des tuples avec `(element_1, element_2)`.

## 5. Compile une « liste principale » d'ingrédients

- Une _union_ d'ensembles réunit les éléments de `set_1` et de `set_2` dans un seul `Set`.
- L'équivalent en méthode d'ensemble de `set ∪ iterable` est `union(set, iterable)` ou `∪(set, iterable)`.
- Ici, parcourir les différents plats avec des boucles peut être utile, mais le _splatting_ peut aussi fonctionner.

## 6. Sors les entrées à passer sur des plateaux

- Une _différence_ d'ensembles retire les éléments de `set_2` de `set_1`, par exemple `setdiff(set_1, set_2)`.
- Le constructeur `Set()` peut prendre n'importe quel [itérable][iterable] comme argument. Les vecteurs sont itérables.
- Le constructeur `Sets` peut prendre n'importe quel [itérable][iterable] comme argument. Les ensembles sont itérables.

## 7. Trouve les ingrédients utilisés dans une seule recette

- Une _différence symétrique_ d'ensembles regroupe les éléments qui apparaissent dans `set_1` ou `set_2`, mais pas dans **_les deux_** ensembles.
- Une _différence symétrique_ d'ensembles revient à soustraire l'_intersection_ des `Set` de leur _union_, par exemple `setdiff(set_1 ∪ set_2, set_1 ∩ set_2)`.
- Une _différence symétrique_ de plus de deux `Set` inclut les éléments qui sont répétés plus de deux fois dans les `Sets` d'entrée. Pour supprimer ces éléments répétés d'un ensemble à l'autre, il faut soustraire du résultat les _intersections_ entre les paires d'ensembles.
- Ici, parcourir les différents plats avec des boucles peut être utile, mais le _splatting_ peut aussi fonctionner.
