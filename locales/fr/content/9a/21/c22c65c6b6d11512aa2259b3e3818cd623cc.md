# Ajout aux instructions

## Indices

Cet exercice porte sur des données textuelles. Pour des raisons historiques, le type `String` de Haskell est synonyme de `[Char]`, une liste de caractères. Pour manipuler les données textuelles plus efficacement, on peut utiliser le type `Text`.

Pour prolonger cet exercice de façon facultative, tu peux

- te renseigner sur les [types de _string_](https://haskell-lang.org/tutorial/string-types) en Haskell.
- ajouter `- text` à ta liste de dépendances dans package.yaml.
- importer `Data.Text` de [la façon suivante](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c) :

        import qualified Data.Text as T
        import           Data.Text (Text)

- écrire maintenant par exemple `abbreviate :: Text -> Text` et faire référence aux combinateurs de `Data.Text` par exemple sous la forme `T.filter`.
- consulter la documentation de [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html).

Cette partie est entièrement facultative.
