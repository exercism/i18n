# Instructions

Tu es analyste de données dans une entreprise qui analyse les données météo dans la région du Nord-Ouest Pacifique.
Tu vas travailler avec une base de données contenant une table `weather_readings` avec les colonnes suivantes.

* `date` : la date à laquelle l'échantillon a été collecté.
* `location` : le nom de la ville dans laquelle l'échantillon a été collecté.
* `temperature` : la température, en degrés Fahrenheit.
* `wind_speed` : la vitesse du vent, en miles par heure.

Dans chacune des tâches suivantes, il s'agit de récupérer le jeu de résultats demandé au moyen d'une instruction `SELECT`.
Note que dans chaque cas, le jeu de résultats sera stocké dans une nouvelle table (une table par tâche) au moyen d'une instruction `CREATE TABLE` pré-écrite.
Pour l'instant, ne te préoccupe pas de l'instruction `CREATE TABLE` ; elle sera abordée dans une autre leçon.
Concentre-toi simplement sur l'ajout de l'instruction `SELECT` appropriée pour accomplir la tâche demandée.

## 1. Récupère toutes les données

Récupère toutes les données de la table `weather_readings`.

## 2. Récupère uniquement les données de localisation et de température

Récupère uniquement les valeurs de localisation et de température de la table `weather_readings`.

## 3. Récupère uniquement les données pour Seattle

Récupère uniquement les données concernant la ville de Seattle.

## 4. Récupère uniquement les données dont la vitesse du vent est comprise dans un intervalle donné

Récupère uniquement les données pour lesquelles la vitesse du vent est comprise entre 5 et 15 miles par heure.
