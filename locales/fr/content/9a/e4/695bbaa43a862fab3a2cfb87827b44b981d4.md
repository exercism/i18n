# Introduction

Le type `Option` est le mécanisme du langage F# pour gérer les valeurs qui peuvent exister ou non.
Il offre une alternative sûre du point de vue du typage à l'utilisation de `null`, courante dans d'autres langages pour gérer ce genre de valeurs.
Il est utilisé dans de nombreuses fonctions de la bibliothèque standard F#, il est donc essentiel de le comprendre pour utiliser efficacement cette bibliothèque.

## Utilisation

Le type `Option` est un type générique (qui possède un type sous-jacent).  
Les valeurs de type `Option` sont soit `Some value`, qui représente une valeur précise, soit `None`, qui représente l'absence de valeur.

La fonction suivante montre comment créer une valeur `Option` :

```fsharp
let keepIfPositive (a: int) : int option = if a > 0 then Some a else None
```

~~~~exercism/note
`T option` est la syntaxe postfixée équivalente de `Option<T>` ; les deux formes syntaxiques peuvent être utilisées de façon interchangeable.
Cependant, d'après le guide de style F#, la notation postfixée est préférée pour les types Option (voir [section du guide de style F# sur la mise en forme des types et les annotations de type](https://learn.microsoft.com/en-us/dotnet/fsharp/style-guide/formatting#for-types-prefer-prefix-syntax-for-generics-foot-with-some-specific-exceptions)). 
~~~~

## Lire le contenu d'une valeur Option

La façon idiomatique de lire une valeur `Option` est le filtrage par motif, comme le montre l'exemple suivant :

```fsharp
// Returns "Hello, <name>!" if the name is provided; otherwise returns "Hello, you!"
let sayHello (optionalName: string option): string = 
    match optionalName with
    | Some name -> "Hello, " + name + "!"
    | None -> "Hello, you!"

sayHello (Some "Matthieu")
// --> "Hello, Matthieu!"

sayHello None
// --> "Hello, you!"
```

## Déballer les options avec des valeurs par défaut

Les `Option` peuvent être « déballées » (converties vers le type qu'elles contiennent) en fournissant des valeurs par défaut avec la fonction `Option.defaultValue`.
C'est particulièrement utile lorsqu'on veut s'assurer que la valeur n'est pas `None`.
Par exemple :

```fsharp
Option.defaultValue "" (Some "F#")
// --> "F#"

Option.defaultValue 0 None
// --> 0
```
