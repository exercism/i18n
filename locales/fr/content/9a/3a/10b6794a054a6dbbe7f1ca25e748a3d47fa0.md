# À propos

Par défaut, les variables sont limitées à la portée dans laquelle elles sont définies. Si elles sont définies dans un fichier, en dehors d'une fonction ou d'une classe, elles sont limitées à la portée du fichier. Si elles sont définies dans une fonction ou une classe, elles sont limitées à la portée de la fonction ou de la classe.

```php
<?php

$file_scoped = "I am file scoped";

function example(): void
{
  $function_scoped = "I am function scoped!";
}
```

## Portée globale

Utiliser le mot-clé `global` avant une affectation de variable crée une variable de portée globale. Cette pratique est souvent déconseillée, car elle crée du [code fortement couplé](<https://en.wikipedia.org/wiki/Coupling_(computer_programming)#Disadvantages_of_tight_coupling>).

```php
function example(): void
{
  global $hello = "World!";
}

echo $hello; // #=> "World!"
```

## Portée statique

Utiliser le mot-clé `static` avant une affectation ou une déclaration de variable préserve la portée de la variable, mais sa valeur est conservée entre les portées d'exécution.

```php
function counter(): int
{
  static $count = 0;
  $count += 1;
  return $count;
}
```

Dans cet exemple, la variable `$count` est initialisée à 0 _uniquement lors du premier appel de la fonction_. À chaque appel suivant, la valeur est reportée vers l'appel d'après. Ainsi, chaque invocation de la fonction renvoie un entier qui va croissant.
