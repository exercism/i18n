# À propos

On peut rendre un paramètre de méthode facultatif en lui affectant une valeur par défaut. Quand un paramètre est facultatif, l'appelant n'est pas obligé de fournir un argument pour ce paramètre, auquel cas c'est la valeur par défaut qui est utilisée. Les [paramètres facultatifs][optional-arguments] _doivent_ se trouver à la fin de la liste des paramètres ; ils ne peuvent pas être suivis de paramètres obligatoires. Si une méthode prend plusieurs paramètres facultatifs, on peut n'en préciser que quelques-uns en utilisant les [arguments nommés][named-arguments].

```csharp
class Card
{
    static string NewYear(int year = 2020, string sender = "me")
    {
        return $"Happy {year} from {sender}!";
    }
}

Card.NewYear();     // => "Happy 2020 from me!"
Card.NewYear(1999); // => "Happy 1999 from me!"
Card.NewYear(sender: "mom"); // => "Happy 2020 from mom!"
```

La valeur d'un paramètre facultatif doit être l'une des suivantes :

- Une expression constante (par ex. `"hi"`, `2`, `DayOfWeek.Friday`, `null`, etc.)
- Une expression `new` d'un type valeur
- Une expression `default` d'un type valeur
