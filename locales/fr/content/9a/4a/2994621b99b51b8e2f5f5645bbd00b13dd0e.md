# Instructions

Une école près de chez toi possède une association d'élèves très active.
Cette association est dirigée par un président et, tous les deux ans,
des élections sont organisées pour élire un nouveau président.

Pour l'élection de cette année, il a été décidé qu'un nouveau système
numérique de comptage des votes était nécessaire. L'école a besoin de ton aide
pour construire ce nouveau système.

## 1. Récupère le nombre de votes d'un `ElectionResult`

Le nouveau système aura besoin d'un moyen de récupérer le nombre de votes d'un compteur.

La structure `ElectionResult` est déjà créée pour toi et elle est définie ainsi :

```cpp
struct ElectionResult {
    // Name of the candidate
    std::string name{};
    // Number of votes the candidate has
    int votes{};
};
```

Comme tous les membres de la structure sont publics, tu n'as pas besoin d'écrire un `constructor` pour initialiser un objet `ElectionResult`.
Tu peux à la place utiliser une `initializer list` :

```cpp
ElectionResult hamilton{"Alex", 1804};
// => the hamilton object was initialized with the name "Alex" and 1804 votes.
```

Crée une fonction `vote_count` qui prend en argument une référence vers un `ElectionResult` et qui renvoie le nombre de votes de cet `ElectionResult`.

```cpp
vote_count(hamilton);
// => 1804
```

## 2. Incrémente les votes d'un `ElectionResult`

Il est enfin temps de traiter les votes !
Il te faut maintenant un moyen d'incrémenter les votes d'un `ElectionResult`.

Crée une fonction `void` `increment_vote_count` qui prend en argument une référence vers un `ElectionResult` ainsi qu'un nombre de votes, et qui incrémente de ce nombre les votes de l'`ElectionResult`.

```cpp
ElectionResult burr{"Aaron " 1801};

increment_vote_count(burr, 3);

vote_count(burr);
// => 1804
```

## 3. Comptage des votes et présidence

L'école a rendu ses votes et il est maintenant temps de vérifier les résultats pour connaître le vainqueur.

Crée une fonction `determine_result` qui reçoit une référence vers un décompte final et qui renvoie une référence vers l'`struct` du nouveau président.
Elle doit aussi modifier le nom du vainqueur en le préfixant par « President ».
Le décompte final est fourni sous la forme d'une `reference` vers un `std::vector<ElectionResult>`, un vecteur contenant les `ElectionResults` de tous les candidats participants.

```cpp
ElectionResult sanchez{"Pedro", 471};
ElectionResult wheatley{"Summer", 340};
std::vector<ElectionResult> final_count{sanchez, wheatley};

ElectionResult& winner = determine_result(final_count);

winner.name;
// => "President Pedro"
```

Pour simplifier, tu peux partir des hypothèses suivantes :
- Le `vector` contient au moins un élément.
- Il n'y aura pas d'égalité pour la première place.
