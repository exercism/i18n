# Instructions supplémentaires

## Mémoire réservée

Le tampon de la chaîne d'entrée utilise les octets 64 à 191 de la mémoire linéaire.


## Format de sortie

La série de nombres est attendue sous la forme d'un seul tableau continu de nombres u8 ; il sera découpé selon la longueur lors de la désérialisation :

```js
slice("123456", 3) => UInt8Array[1, 2, 3,   2, 3, 4,   3, 4, 5,   4, 5, 6]
// will be split into          [[1, 2, 3], [2, 3, 4], [3, 4, 5], [4, 5, 6]]
```
