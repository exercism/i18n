# À propos

## Les boucles `for`

Une instruction `for` répète un bloc de code.
Sa première ligne contrôle combien de fois le bloc se répète :

```go
for init; condition; post {
    // loop body
}
```

- L'instruction **init** s'exécute une seule fois, avant la première itération. Il est courant de déclarer et d'initialiser une variable compteur utilisée par la boucle.
- La **condition** est une expression booléenne évaluée avant chaque itération. La boucle s'arrête quand elle s'évalue à `false`.
- L'instruction **post** s'exécute après chaque itération terminée. Elle peut servir à mettre à jour un compteur.

N'entoure pas `init; condition; post` de parenthèses (`()`).
En revanche, les accolades `{ }` qui entourent le corps de la boucle sont toujours obligatoires.

Cette boucle initialise `i` à `1`, affiche la valeur courante de `i`, l'incrémente pour l'itération suivante et s'arrête quand `i` atteint `10` :

```go
for i := 1; i < 10; i++ {
    fmt.Println(i)
}
```

## Autres formes de boucle

### Boucle avec condition seule

On peut omettre les instructions init et post.
Une instruction `for` avec une seule condition joue le même rôle qu'une boucle _while_ dans d'autres langages.
Go n'a pas de mot-clé `while`.

```go
sum := 1
for sum < 1000 {
    sum += sum
}
fmt.Println(sum)
// Output: 1024
```

### Boucle infinie

On peut écrire une instruction `for` sans condition :

```go
for {
    // loop body
}
```

Cette boucle ne se termine pas d'elle-même.
L'exécution doit en sortir explicitement, par exemple avec `break` ou `return`.

## Contrôler les boucles

### `break` et `continue`

Dans cette boucle, `break` sort de la boucle :

```go
for n := 0; n <= 5; n++ {
    if n == 3 {
        break
    }
    fmt.Println(n)
}
// Output:
// 0
// 1
// 2
```

`continue` saute le reste du corps de la boucle en cours et passe à l'itération suivante :

```go
for n := 0; n <= 5; n++ {
    if n % 2 == 0 {
        continue
    }
    fmt.Println(n)
}
// Output:
// 1
// 3
// 5
```

### `break` et `continue` avec étiquettes

Dans des boucles imbriquées, un `break` ou un `continue` sans étiquette s'applique à la boucle la plus interne.
Pour étiqueter une boucle englobante, place un identifiant suivi de deux-points sur la ligne juste au-dessus.
Écris ensuite l'étiquette de la boucle après `break` ou `continue` pour que l'action s'y applique :

```go
OuterLoop:
for i := 0; i < 10; i++ {
    for j := 0; j < 10; j++ {
        if i + j == 10 {
            break OuterLoop
        }
    }
}
```
