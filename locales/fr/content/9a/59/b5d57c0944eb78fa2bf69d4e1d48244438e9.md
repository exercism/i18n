# Instructions

Tu es un passionné d'observation des oiseaux qui note combien d'oiseaux ont visité ton jardin ces sept derniers jours.

Tu as six tâches, toutes portant sur le nombre d'oiseaux qui ont visité ton jardin.

## 1. Vérifie quels étaient les comptages de la semaine dernière

Pour pouvoir comparer, tu gardes toujours une copie des comptages de la semaine dernière à portée de main, qui étaient : 0, 2, 5, 3, 7, 8 et 4. Définis la liaison `lastWeek` qui contient les comptages de la semaine dernière :

```fsharp
lastWeek
// => [| 0; 2; 5; 3; 7; 8; 4 |]
```

## 2. Vérifie combien d'oiseaux sont venus hier

Implémente la fonction `yesterday` pour qu'elle renvoie le nombre d'oiseaux qui ont visité ton jardin hier. Les comptages d'oiseaux sont ordonnés par jour, le premier élément étant le comptage du jour le plus ancien et le dernier celui d'aujourd'hui.

```fsharp
yesterday [| 3; 5; 0; 7; 4; 1 |]
// => 4
```

## 3. Calcule le nombre total d'oiseaux visiteurs

Implémente la fonction `total` pour qu'elle renvoie le nombre total d'oiseaux qui ont visité ton jardin :

```fsharp
total [| 3; 5; 0; 7; 4; 1 |]
// => 20
```

## 4. Vérifie s'il y a eu un jour sans aucun oiseau

Implémente la fonction `dayWithoutBirds` qui renvoie `true` s'il y a eu un jour où aucun oiseau n'a visité le jardin ; sinon, elle renvoie `false` :

```fsharp
dayWithoutBirds [| 3; 5; 0; 7; 4; 1 |]
// => true
```

## 5. Incrémente le comptage d'aujourd'hui

Implémente la fonction `incrementTodaysCount` pour incrémenter le comptage d'aujourd'hui et renvoyer les comptages mis à jour :

```fsharp
let birdCount = [| 3; 5; 0; 7; 4; 1 |]
incrementTodaysCount birdCount
// => [| 3; 5; 0; 7; 4; 2 |]
```

## 6. Vérifie si la semaine est inhabituelle

Au cours de l'année écoulée, tu as remarqué que certaines semaines présentent les mêmes motifs inhabituels :
- Les jours pairs de la semaine, il n'y avait aucun oiseau
- Les jours pairs de la semaine, exactement 10 oiseaux ont été observés
- Les jours impairs de la semaine, exactement 5 oiseaux ont été observés

Implémente la fonction `unusualWeek` qui renvoie `true` si le motif de comptage d'oiseaux de cette semaine correspond à l'un des motifs inhabituels :

```fsharp
unusualWeek [| 1; 0; 5; 0; 12; 0; 2 |]
// => true

unusualWeek [| 5; 0; 5; 12; 5; 3; 5|]
// => true
```

(Note que la parité des jours est indexée à partir de 1, et non de 0 : le premier élément du tableau correspond à un jour impair)
