# Instructions

Tu tiens le poste de sécurité d'une station de recherche. Le personnel porte des *badges* dont les codes suivent un format strict, le journal d'accès est plein de ces codes mêlés à du texte ordinaire, et il faut nettoyer ce journal avant de pouvoir le partager. Les expressions régulières sont l'outil qu'il faut pour chacune de ces tâches.

Un code de badge valide, c'est **deux lettres majuscules, un tiret, puis quatre chiffres**, par exemple `NS-1024`.

## 1. Vérifie un code de badge

Définis `valid-badge?`, qui prend une _string_ de badge et renvoie `t` quand la _string_ *entière* est un code de badge valide, et `f` sinon.

```factor
"NS-1024" valid-badge? .   ! => t
"NS-10"   valid-badge? .   ! => f
```

## 2. Extrais tous les codes d'une ligne de journal

Définis `badge-codes`, qui prend une ligne du journal d'accès et renvoie une séquence de tous les codes de badge qu'elle contient, dans l'ordre.

```factor
"seen NS-1024 then AB-0007 today" badge-codes .
! => { "NS-1024" "AB-0007" }
```

## 3. Compte les chiffres d'un code

Définis `digit-count`, qui prend une _string_ et renvoie le nombre de chiffres qu'elle contient.

```factor
"NS-1024" digit-count .   ! => 4
```

## 4. Masque les mots de passe

Les lignes du journal enregistrent parfois un mot de passe sous la forme `pass=` suivi du secret (une suite quelconque de caractères autres que des espaces). Définis `redact`, qui prend une ligne et la renvoie avec chacun de ces mots de passe remplacé par `pass=****`.

```factor
"user=alice pass=hunter2 ok" redact .
! => "user=alice pass=**** ok"
```
