# Introduction

## Types de fonctions

Si on enlève tous les noms et les étiquettes d'une signature de fonction Swift, il reste le type de la fonction.

```swift
func shoppingList(item: String, quantity: Int) -> String {
  "You need to buy \(quantity) \(item)."
}
// shoppingList: (String, Int) -> String

func repeater(_ phrase: String, times: Int) -> String {
  var result = ""
  for _ in 1...times {
    result += phrase
  }
  return result
}
// repeater: (String, Int) -> String

func printString(line: String) {
  print(line)
}
// printString: (String) -> ()
```

Remarque que les types des deux premières fonctions sont les mêmes, `(String, Int) -> String`, même si les deux signatures sont différentes et que les deux fonctions fonctionnent très différemment. Elles prennent toutes les deux une `String` et un `Int` en entrée et renvoient une `String`. Et, comme on peut le voir avec le type de la troisième fonction, même si le corps de la fonction ne semble rien renvoyer, elle renvoie en fait implicitement `()`, la seule valeur de type `Void`.

Ces types de fonctions peuvent être utilisés de la même manière que n'importe quel autre type en Swift, par exemple, ils peuvent être utilisés dans la déclaration de variables ou de constantes. Et comme les fonctions sont des valeurs en Swift, des fonctions existantes peuvent être affectées à ces constantes/variables :

```swift
var stringAndIntToString: (String, Int) -> String

stringAndIntToString = shoppingList
stringAndIntToString("carrots", 3)
// => "You need to buy 3 carrots."
```

Comme pour les autres variables/constantes, la valeur que tu lui affectes doit être du bon type :

```swift
stringAndIntToString = printShoppingList
// Error: Cannot assign value of type '(String) -> ()' to type '(String, Int) -> String'
```

## Types de fonctions comme types de paramètres

Comme les types de fonctions peuvent être utilisés partout où d'autres types peuvent l'être, il s'ensuit qu'ils peuvent être utilisés comme types de paramètres et passés à d'autres fonctions, puis appelés depuis ces fonctions.

```swift
func apply3(to str: String, function f: (String, Int) -> String) -> String {
  f(str,3)
}
// apply3: ([String], (String, Int) -> String) -> [String]

apply3(to: "eggs", function: shoppingList)
// => "You need to buy 3 eggs."

apply3(to: "eggs", function: repeater)
// => "eggseggseggs"
```

## Types de fonctions comme types de retour

De même, les types de fonctions peuvent être utilisés comme types de retour pour les fonctions. Autrement dit, on peut écrire des fonctions qui créent et renvoient d'autres fonctions. Lorsqu'on crée ces fonctions, la fonction renvoyée peut utiliser les autres paramètres passés à la fonction ou les variables locales créées à l'intérieur de la fonction parente.

```swift
func makeAdder(base: Int) -> (Int) -> Int {
  func adder(_ i: Int) -> Int {
    base + i
  }
  return adder
}
// makeAdder: (Int) -> (Int) -> Int

let add10 = makeAdder(base: 10)
// add10: (Int) -> Int

let subtract20 = makeAdder(base: -20)
// subtract20: (Int) -> Int

add10(5)
// => 15

subtract20(5)
// => -15
```
