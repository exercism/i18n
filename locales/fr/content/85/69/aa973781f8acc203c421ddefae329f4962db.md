# Introduction

## Les nombres

Java possède deux types de nombres différents :

- Entiers : nombres sans aucun chiffre après le séparateur décimal (nombres entiers).
  Par exemple `-6`, `0`, `1`, `25`, `976` et `-500000`.
- Nombres à virgule flottante : nombres comportant zéro ou plusieurs chiffres après le séparateur décimal.
  Par exemple `-20.4`, `0.1`, `2.72`, `16.984025` et `1024.0`.

Les deux types numériques les plus courants en Java sont `int` et `double`.
Un `int` est un entier de 32 bits et un `double` est un nombre à virgule flottante de 64 bits.

Les opérations arithmétiques s'effectuent à l'aide des opérateurs arithmétiques standard.
On peut comparer les nombres à l'aide des opérateurs de comparaison numériques standard (par ex. `5 > 4` et `4 <= 5`) et des opérateurs d'égalité (`==`) et d'inégalité (`!=`).

Java possède deux types de conversions numériques :

1. Conversions implicites : aucune donnée n'est perdue et aucune syntaxe supplémentaire n'est nécessaire.
2. Conversions explicites : des données peuvent être perdues et une syntaxe supplémentaire, sous la forme d'un _cast_, est nécessaire.

Comme un `int` est moins précis qu'un `double`, convertir un `int` en `double` ne présente aucun risque : c'est donc une conversion implicite.
En revanche, convertir un `double` en `int` peut entraîner une perte de données, ce qui exige une conversion explicite.

## Les instructions if-else

### L'instruction _if-then_

L'instruction de contrôle de flux la plus élémentaire en Java est l'instruction _if-then_.
Cette instruction sert à n'exécuter une portion de code que si une condition donnée est `true`.
Une instruction _if-then_ se définit à l'aide de la clause `if` :

```java
class Car {
    void drive() {
        // the "if" clause: the car needs to have fuel left to drive
        if (fuel > 0) {
            // the "then" clause: the car drives, consuming fuel
            fuel--;
        }
    }
}
```

Dans l'exemple ci-dessus, si la voiture n'a plus de carburant, l'appel à la méthode `Car.drive` ne fait rien.

### L'instruction _if-then-else_

L'instruction _if-then-else_ offre un chemin d'exécution alternatif lorsque la condition de la clause `if` est évaluée à `false`.
Ce chemin d'exécution alternatif suit une clause `if` et se définit à l'aide de la clause `else` :

```java
class Car {
    void drive() {
        if (fuel > 0) {
            fuel--;
        } else {
            stop();
        }
    }
}
```

Dans l'exemple ci-dessus, si la voiture n'a plus de carburant, l'appel à la méthode `Car.drive` appelle une autre méthode pour arrêter la voiture.

L'instruction _if-then-else_ prend aussi en charge plusieurs conditions grâce à la clause `else if` :

```java
class Car {
    void drive() {
        if (fuel > 5) {
            fuel--;
        } else if (fuel > 0) {
            turnOnFuelLight();
            fuel--;
        } else {
            stop();
        }
    }
}
```

Dans l'exemple ci-dessus, conduire la voiture lorsque le carburant est inférieur ou égal à `5` la fait effectivement rouler, mais allume le voyant de carburant.
Quand le carburant atteint `0`, la voiture s'arrête.
