# Instructions supplémentaires

## Registres

| Registre | Usage         | Type    | Description                                          |
| -------- | ------------- | ------- | ---------------------------------------------------- |
| `$a0`    | entrée        | adresse | première couleur sous forme de _string_ terminée par un caractère nul  |
| `$a1`    | entrée        | adresse | deuxième couleur sous forme de _string_ terminée par un caractère nul |
| `$a2`    | entrée        | adresse | troisième couleur sous forme de _string_ terminée par un caractère nul |
| `$a3`    | entrée/sortie | adresse | _string_ de sortie terminée par un caractère nul     |
| `$t0-9`  | temporaire    | quelconque | utilisés pour le stockage temporaire              |
