# Factice

## Le module « io »

Tu auras besoin de lire des fichiers dans cet exercice.
La classe `File` requise se trouve dans le module `io`.
Elle est décrite dans la [documentation du projet Wren CLI][wren-cli].

(À noter que le projet `wren-console` [étend le module `io`][wren-console] avec quelques méthodes,
bien que celles-ci ne soient pas nécessaires pour cet exercice.)

[wren-cli]: https://wren.io/cli/modules/
[wren-console]: https://github.com/joshgoebel/wren-console#extended-library-support
