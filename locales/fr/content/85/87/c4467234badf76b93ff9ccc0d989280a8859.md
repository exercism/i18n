# Introduction

Un *disposable* est tout objet qui détient une ressource du système d'exploitation — un fichier ouvert, un socket, un verrou adossé à une table de hachage — et qui doit être libéré quand on n'en a plus besoin. Le vocabulaire [`destructors`][destructors] de Factor enveloppe tout cela dans un petit _framework_, afin que le nettoyage ait bien lieu même quand une exception déroule la pile.

```factor
USING: destructors io.files io.encodings.utf8 ;

"log.txt" utf8 <file-writer> [
    "hello, world" write
] with-disposal
! file is closed even if write throws
```

`with-disposal ( disposable quot -- )` exécute la _quotation_ avec la ressource et la libère en sortant. Pour plusieurs ressources, ouvre une portée avec `with-destructors` et enregistre chacune d'elles avec `&dispose` (libération en sortie normale *et* en cas d'erreur) ou `|dispose` (libération uniquement en cas d'erreur).

Une classe rejoint le _framework_ en étendant `disposable` et en implémentant le générique `dispose*` : le _framework_ l'appelle une fois, et une seule, par objet. Le mot public que les appelants utilisent est `dispose`.

[destructors]: https://docs.factorcode.org/content/vocab-destructors.html
