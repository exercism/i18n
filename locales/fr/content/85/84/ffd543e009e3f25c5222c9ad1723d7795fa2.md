# Lance les tests

Pour lancer la suite de tests, exécute la commande suivante :

```bash
stack test
```

#### Si tu obtiens un message d'erreur comme celui-ci...

```
No .cabal file found in directory
```

ou

```
RedownloadInvalidResponse Request {
...
}
 "/home/username/.stack/build-plan/lts-xx.yy.yaml" (Response {responseStatus = Status {statusCode = 404, statusMessage = "Not Found"},
```

Tu utilises probablement une ancienne version de Stack et tu dois la mettre à jour. Essaie de lancer :

```bash
stack upgrade
```

Ou consulte les autres options de mise à jour dans la [documentation de Stack](https://docs.haskellstack.org/en/stable/install_and_upgrade/#upgrade).

#### Sinon, si tu obtiens un message d'erreur comme celui-ci...

```
No compiler found, expected minor version match with...
Try running "stack setup" to install the correct GHC...
```

Fais simplement ce qu'il indique, et il téléchargera et installera la bonne version du compilateur :

```bash
stack setup
```

# Lance *GHCi*

Si tu veux jouer avec ta solution dans GHCi, lance simplement la commande :

```bash
stack ghci
```
