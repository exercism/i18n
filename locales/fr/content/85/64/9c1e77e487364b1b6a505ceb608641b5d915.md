# Instructions

Dans cet exercice, tu vas écrire du code pour aider un freelance à communiquer avec ses clients au sujet du prix de certains projets.
Tu vas écrire quelques fonctions utilitaires pour calculer rapidement le coût pour les clients.

```exercism/note
La variable `ratePerHour` et la fonction `dayRate` concernent de l'argent.
Les unités de mesure sont des montants d'argent par unité de temps : respectivement des heures et des jours.
```

## 1. Calculer le tarif journalier à partir d'un tarif horaire

Un client contacte le freelance pour se renseigner sur ses tarifs.
Le freelance explique qu'il **_travaille 8 heures par jour._**
Cependant, le freelance ne connaît que son tarif horaire pour le projet.
Aide-le à estimer un tarif journalier à partir d'un tarif horaire.

```javascript
dayRate(89);
// => 712
```

Le tarif journalier n'a pas besoin d'être arrondi ni ramené à une précision « fixe ».

## 2. Calculer le nombre de jours travaillés à partir d'un budget fixe

Un autre jour, un chef de projet propose au freelance de travailler sur un projet avec un budget fixe.
Étant donné le budget fixe et le tarif horaire du freelance, aide-le à calculer le nombre de jours qu'il travaillerait jusqu'à épuisement du budget.
Le résultat _doit_ être **arrondi à l'entier inférieur**.

```javascript
daysInBudget(20000, 89);
// => 28
```

## 3. Calculer le tarif remisé pour les grands projets

Souvent, les clients du freelance l'engagent pour des projets qui s'étalent sur plusieurs mois.
Dans ce cas, le freelance décide d'accorder une remise pour chaque mois complet, et les jours restants sont facturés au tarif journalier.
Ton excellent équilibre entre vie professionnelle et vie personnelle fait que tu ne travailles que 22 jours par mois calendaire, donc **_chaque mois compte 22 jours facturables._**
Aide-le à estimer le coût de ce type de projets, à partir d'un tarif horaire, du nombre de jours facturables du projet et d'un taux de remise mensuel.
La remise est toujours passée sous forme de nombre, où `42%` devient `0.42`. Le résultat _doit_ être **arrondi à l'entier supérieur**.

```javascript
priceWithMonthlyDiscount(89, 230, 0.42);
// => 97972
```
