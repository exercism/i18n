# Tests

## Exécute les tests

Pour exécuter les tests, lance la commande suivante :

```bash
dotnet test
```

## Résous l'exercice

Résoudre un exercice, c'est faire passer tous ses tests. Par défaut, un seul test (le premier) est exécuté quand on lance les tests. C'est intentionnel, car cela te permet de te concentrer uniquement sur la réussite de ce test. Une fois qu'il passe, tu peux activer le test suivant en supprimant `Skip = "Remove this Skip property to run this test"` de l'attribut `[<Fact>]` ou `[<Theory>]` du test. Quand tous les tests sont activés et que ton implémentation les fait tous passer, tu as résolu l'exercice !

Pour t'aider à démarrer, chaque exercice est fourni avec un fichier d'implémentation vide. Tu peux t'en servir comme point de départ pour construire ta solution. N'hésite pas à supprimer ou à modifier ce fichier si tu penses que c'est la bonne chose à faire.

## Utilise des packages

On devrait pouvoir résoudre la plupart des exercices sans utiliser de package externe. Cependant, pour les exercices où tu veux vraiment utiliser un package externe, tu peux l'ajouter à ton projet en exécutant la commande suivante :

```bash
dotnet add package [package-name]
```
