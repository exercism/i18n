# Complément aux instructions

## Indices

Les tests unitaires fournissent des exemples de mots. Essaie de regrouper les consonnes indépendamment des combinaisons de consonnes particulières qui apparaissent dans les tests unitaires.

Cet exercice manipule des données textuelles. Pour des raisons historiques, le type `String` de Haskell est synonyme de `[Char]`, un tableau de caractères. Pour manipuler les données textuelles plus efficacement, on peut utiliser le type `Text`.

Comme extension facultative à cet exercice, tu peux

- En savoir plus sur les [types de chaînes de caractères](https://haskell-lang.org/tutorial/string-types) en Haskell.
- Ajouter `- text` à la liste des dépendances dans package.yaml.
- Importer `Data.Text` de [la façon suivante](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c) :

      import qualified Data.Text as T
      import           Data.Text (Text)

- Tu peux maintenant écrire par exemple `translate :: Text -> Text` et faire appel aux combinateurs de `Data.Text` comme par exemple `T.isSuffixOf`.
- Consulter la documentation de [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html),

Cette partie est entièrement facultative.
