# Instructions supplémentaires

## Indices

Pour faire cet exercice, tu dois créer le type de données `LinkedList` et implémenter les fonctions suivantes :

- `datum`
- `fromList`
- `isNil`
- `new`
- `next`
- `nil`
- `reverseLinkedList`
- `toList`

Tu trouveras une déclaration de données factice et les signatures de type déjà en place, mais c'est à toi de définir les fonctions et de créer un type de données, un newtype ou un synonyme de type qui a du sens.
