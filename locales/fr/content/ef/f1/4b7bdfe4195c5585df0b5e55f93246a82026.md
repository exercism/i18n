# À propos

En Common Lisp, tout est une expression.
Une expression est soit une chose unique (que l'on appelle un atome), soit un tableau de choses (délimité par des parenthèses : `()`).

## Citation

Toutes les S-expressions, comme les symboles, peuvent être citées :

```lisp
;; This line is evaluated as code
(gimme-foo)  ; => FOO

;; This line is treated as data
'(gimme-foo) ; => (GIMME-FOO)
```

Cette citation empêche l'évaluation d'une S-expression et la traite plutôt comme une donnée.
Voici une excellente [réponse sur Stack Overflow][so-quoting] qui aborde la citation un peu plus en détail.

[so-quoting]: https://stackoverflow.com/questions/134887/when-to-use-or-quote-in-lisp
