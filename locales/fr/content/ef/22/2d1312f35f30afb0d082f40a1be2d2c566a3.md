# Indices

## Général

- Utilise `?` pour manipuler les [points de code][codepoint] des caractères.
- `\s` peut servir à représenter un espace.
- Utilise la notation abrégée des [littéraux entiers binaires][integer-literal] pour manipuler les codes.
- Essaie d'utiliser la stratégie de récursion terminale.

## 1. Encode un acide nucléique en valeur binaire

- Cette fonction doit faire correspondre un entier à un autre.
- Cette fonction n'a pas besoin de récursion.
- Utiliser des fonctions à plusieurs clauses peut faciliter les choses en découpant le problème.

## 2. Décode la valeur binaire en acide nucléique

- Cette fonction est l'inverse de celle de la partie 1.
- Cette fonction n'a pas besoin de récursion.
- Utiliser des fonctions à plusieurs clauses peut faciliter les choses en découpant le problème.

## 3. Encode une charlist d'ADN

- Crée une fonction récursive terminale qui prend un point de code de la charlist et construit récursivement le bitstring résultat.
- Les fonctions récursives terminales ont besoin d'un accumulateur.
- Rappelle-toi qu'une [charlist][charlist] est une liste de [points de code entiers][codepoint].
- Tu peux récupérer le premier élément et le reste d'une liste grâce à une fonction intégrée du [module `Kernel`][kernel].
- Tu peux aussi faire du filtrage par motif sur une liste avec la notation [`[head | tail]`][list].
- Utilise des fonctions à plusieurs clauses pour séparer le cas de base des cas récursifs.
- N'oublie pas de préciser les types des segments de bitstring avec l'opérateur `::`.

## 4. Décode un bitstring d'ADN

- Crée une fonction récursive terminale qui [fait correspondre les 4 premiers bits][bitstring-matching] du [bitstring][bitstring] et construit récursivement le résultat sous forme de [charlist][charlist].
- Les fonctions récursives terminales ont besoin d'un accumulateur.
- Rappelle-toi que la [forme spéciale pour les bitstrings][bitstring-form] peut servir au filtrage sur les bitstrings.
- N'oublie pas de préciser les types des segments de bitstring avec l'opérateur `::`.
- Tu devras inverser l'accumulateur à la fin. Écris une fonction `reverse` privée et récursive terminale pour cela, et utilise-la dans le cas de base de la fonction `decode`.
