# Introduction

En C#, les exceptions offrent un moyen structuré, uniforme et sûr au niveau des types de gérer les erreurs qui surviennent pendant l'exécution. Bien gérer les exceptions et les erreurs est important pour éviter que l'application ne plante.

En C#, toutes les exceptions ont pour type de base la classe `System.Exception`. Celle-ci contient des propriétés importantes comme `Message`, qui contient une description lisible par un humain de la raison pour laquelle l'exception a été levée.

Pour signaler qu'une erreur doit se produire à un certain endroit du code, il faut créer un nouvel objet exception puis le lever, à l'aide du mot-clé `throw` :

```csharp
using System;
static int Square(int number)
{
    if (number >= 46341)
    {
        throw new ArgumentException($"Argument {number} cannot be higher than 46340 as its' square doesn't fit into int type.");
    }
    return number * number;
}
```

Quand une exception est levée, l'environnement d'exécution doit trouver le bout de code chargé de la gérer. Si aucun gestionnaire approprié n'est trouvé, l'environnement d'exécution affiche le message de l'exception non gérée et arrête l'exécution du programme.

Pour créer un gestionnaire d'exception, C# utilise l'instruction try-catch, qui se compose d'un bloc `try` et d'une ou plusieurs clauses `catch`. Le bloc `try` doit contenir et protéger le code susceptible de lever une exception. Les clauses `catch` doivent contenir le code qui gère le comportement du programme après que l'erreur s'est produite. Il est important de noter que l'ordre des exceptions après le bloc `try` a son importance : lorsque plusieurs exceptions sont listées, c'est la première clause `catch` qui correspond qui est exécutée.

```csharp
try
{
   if (number == 42)
   {
       throw new ArgumentException("The number cannot be equal to 42.", "number");
   }

   if (number < 0)
   {
      throw new ArgumentOutOfRangeException("number", "The number cannot be negative.");
   }

    // Process number ...
}
catch (ArgumentOutOfRangeException e)
{
    Console.WriteLine($"Number is out of range: {e.Message}.");
}
catch (ArgumentException)
{
    Console.WriteLine("Invalid number.");
}
```
