# Résous des exercices avec l'éditeur en ligne

Résoudre des exercices en ligne grâce à l'éditeur en ligne du site te permet de commencer rapidement un parcours.
Avec l'éditeur en ligne, tu n'as rien à installer sur ta machine : tout se passe dans le navigateur (y compris l'exécution des tests).

## Résous l'exercice

Le but de chaque exercice est de créer une implémentation qui passe tous les tests.
Une telle implémentation s'appelle une _solution_.

Pour commencer, va sur le site, rejoins un parcours et ouvre la page de l'exercice.
Là, tu peux cliquer sur le bouton _« Ouvrir dans l'éditeur »_.
Cela ouvre l'éditeur en ligne, qui affiche les informations suivantes :

- À gauche se trouve l'éditeur dans lequel tu écriras ta solution
- À droite se trouvent les instructions qui expliquent ce qui est attendu de toi

Tu peux alors commencer à écrire ta solution.

Cliquer sur le bouton _« Exécuter les tests »_ vérifie si ta solution passe les tests de l'exercice.
Une fois les tests exécutés, les résultats s'affichent à droite.

### Débogage

L'éditeur en ligne n'a pas de débogueur intégré.
Certains parcours prennent en charge le débogage par affichage : ton code peut alors produire du texte qui apparaît dans les résultats.
Si un parcours le prend en charge, les instructions expliquant comment utiliser cette fonctionnalité s'affichent à droite.

## Soumets ta solution

Une fois que ta solution passe tous les tests, tu peux la soumettre avec le bouton _« Soumettre »_.
