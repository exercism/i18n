# Tests

Pour exécuter les tests de tes exercices SQLite, suis ces étapes :

1. Ouvre ton terminal préféré.
2. Place-toi dans le répertoire qui contient le fichier `${slug}_test.sql` approprié, où `${slug}` est le nom de l'exercice, en utilisant des tirets à la place des espaces et tout en minuscules.
3. Exécute la commande suivante : 
```bash
sqlite3 -bail < ${slug}_test.sql
```
  
Cette commande initialise SQLite avec une base de données vide, exécute les tests indiqués dans `${slug}_test.sql`, puis se termine.
`-bail` garantit que l'exécution du code s'arrête en cas de code invalide.

Les résultats des tests s'affichent dans la console sous forme de tableau, avec la description de chaque test, son statut (par exemple « pass ») et un message lorsque le statut est « fail ».

## Débogage

Tu peux utiliser des instructions `SELECT` pour déboguer.
La sortie est transmise à `user_output.md` et affichée dans l'éditeur en ligne si les tests échouent.

## Détails de l'exécution

Le fichier de test (`${slug}_test.sql`) est un script assez complexe.
Voici un aperçu de ce qu'il fait.

1. Il crée les tables en lisant `create_fixture.sql`.
   Cela crée les tables, puis les remplit avec les valeurs de `data.csv` pour les données valides et de `error_data.csv` pour les entrées qui doivent échouer.
   Seules ces tables sont vérifiées pendant les tests ; les modifications apportées aux autres tables sont ignorées.
2. Il exécute le code de la solution en lisant le fichier `${slug}.sql`.
3. Il crée des tables pour stocker les cas de test et les résultats.
4. Il remplit les résultats des tests à partir des données de la ou des tables mises à jour par la solution.
5. Il affiche les résultats des tests (réussite ou échec, et détails éventuels).
Ces fichiers CSV contiennent les données nécessaires pour tester différents scénarios.
