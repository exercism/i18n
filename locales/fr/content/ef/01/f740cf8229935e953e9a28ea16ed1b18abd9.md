# Préférer IO.puts dans log_sent_email

Quand on écrit une ligne dans un fichier, il vaut mieux utiliser `IO.puts/2` plutôt que `IO.write/2`, car `IO.puts/2` ajoute automatiquement un caractère de nouvelle ligne à la fin.

```elixir
# preferred
IO.puts(pid, email)

# not preferred
IO.write(pid, email)
IO.write(pid, "\n")
```
