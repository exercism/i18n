## Paires

Un `Pair` est une structure de données qui contient exactement deux éléments, accessibles via les champs `first` et `second`.

On peut les construire avec `x => y` :

```julia-repl
julia> p = 3 => true
3 => true

julia> p.first
3

julia> p.second
true
```

Les éléments d'un `Pair` peuvent être de types différents :

```julia-repl
julia> typeof(p)
Pair{Int64,Bool}
```

Les `Pair`s ont deux usages courants en Julia : les dictionnaires et les remplacements.

### Remplacements

De nombreuses méthodes de remplacement prennent un `Pair` en argument pour indiquer clairement quel élément est remplacé.
Cela permet d'écrire une syntaxe comme

```julia-repl
julia> replace!([1, 3, 4, 1], 4 => 0)
4-element Array{Int64,1}:
 1
 3
 0
 1
```

où chaque `4` de la collection est remplacé par `0`, plutôt que la syntaxe moins claire

```julia
replace!([1, 3, 4, 1], 4, 0) # this method doesn't exist
```
