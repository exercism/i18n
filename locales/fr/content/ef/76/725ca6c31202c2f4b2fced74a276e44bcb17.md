# Instructions complémentaires

## Instructions spécifiques au parcours

Historiquement, Elm utilisait la programmation réactive fonctionnelle, avant de se spécialiser sur l'Elm Architecture.

Résous cet exercice comme si tu écrivais une application web avec l'Elm Architecture.
La sortie du programme doit être du HTML avec la structure suivante :

```html
<div>
  <dl>
    <dt>State</dt>
    <dd>Ongoing</dd>
    <dt>Word</dt>
    <dd>______</dd>
    <dt>Remaining failures</dt>
    <dd>5</dd>
  </dl>
</div>
```

où `<dl>` est l'élément de liste de descriptions, `<dt>` l'élément de terme de description et `<dd>` l'élément de détails de description, tous des éléments HTML standard.

En cas d'erreur, la sortie doit avoir la structure suivante :

```html
<div>
  <p>error message</p>
</div>
```
