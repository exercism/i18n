# Introduction

## Comparaisons

En C++, on peut comparer des valeurs à l'aide des opérateurs de comparaison.

| Comparaison         | Opérateur |
| ------------------  | --------- |
| égal à              | `==`      |
| différent de        | `!=`      |
| inférieur à         | `<`       |
| inférieur ou égal à | `<=`      |
| supérieur à         | `>`       |
| supérieur ou égal à | `>=`      |

Le résultat de ces comparaisons est toujours une valeur booléenne :

```cpp
int a{3};

bool eq1 = a != 4; // true

bool eq2 = a > 5;  // false
```

Les opérateurs `==` et `!=` vérifient respectivement si une valeur est égale à une autre ou non.
Voici quelques exemples courants :

```cpp
bool eq3 = 2 == 3; // false, integer comparison

bool eq4 = 2.1 != 2.2; // true, float comparison

bool eq5 = "hello" == "hello"; // true, string comparison
```

Les autres opérateurs permettent de vérifier si une valeur est supérieure à (`>`), supérieure ou égale à (`>=`), inférieure à (`<`) ou inférieure ou égale à (`<=`) une autre valeur.
Ce type de comparaison est disponible pour les nombres et les _strings_.
Lorsque l'on compare des _strings_, c'est l'ordre dictionnaire (aussi appelé ordre lexicographique) qui est utilisé.

```cpp
bool eq6 = 2 > 3; // false, integer comparison

bool eq7 = 1.2 < 1.3; // true, float comparison

bool eq8 = "Hello" < "World"; // true, string comparison
```

## Instructions `if`

Les conditions en C++ sont similaires à celles d'autres langages.
Le type sous-jacent de toute opération conditionnelle est le type `bool`, qui peut avoir la valeur `true` ou `false`.
Les conditions sont souvent utilisées comme mécanismes de contrôle de flux pour vérifier différentes situations.

On peut utiliser une instruction `if`, qui exécute son code si la condition sous-jacente est `true`, comme ceci :

```cpp
std::string value{"val"};

if (value == "val") {
    return "was val";
}
```

Dans les cas où il y a plusieurs possibilités, on peut enchaîner plusieurs instructions `if` à l'aide des instructions `else if` et `else`.

```cpp
int number{33};

if (number > 0) {
   return "positive";
} else if (number < 0) {
    return "negative";
} else {
   return "zero";
}
```

Depuis C++17, les instructions `if` peuvent aussi inclure une courte instruction d'initialisation, qui permet d'initialiser une ou plusieurs variables pour l'instruction `if`.
Par exemple :

```cpp
int num{7};
if (int v{2 * num}; v > 10) {
    return v;
} else {
    return num;
}
// => 14
```

> Remarque : les variables créées dans l'initialisation ne sont pas accessibles après la fin de l'instruction `if`.
