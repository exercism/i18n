# Booléens

Crystal dispose d'un type appelé [`Bool`][bools].
Il représente les valeurs `true` et `false`.

## Opérateurs logiques

Crystal possède trois opérateurs logiques (`!`, `||` et `&&`), qui combinent des booléens et forment des expressions produisant des valeurs différentes.

### ET (`&&`)

En Crystal, l'[opérateur _and_][and] est représenté par `&&` et renvoie `true` si les deux valeurs valent `true` ; sinon, il renvoie `false`.
Quand on utilise l'opérateur _and_, on place un booléen à droite du `&&` et un autre à gauche.

```crystal
true && true
# => true

true && false
# => false
```

### OU (`||`)

En Crystal, l'[opérateur _or_][or] est représenté par `||` et renvoie `true` si **au moins une** des valeurs données vaut `true`.
Si les deux valeurs valent `false`, il renvoie `false`.
Quand on utilise l'opérateur _or_, il faut placer un booléen à droite du `||` et un autre à gauche.

```crystal
true || true
# => true

true || false
# => true

false || false
# => false
```

### PAS (`!`)

En Crystal, l'opérateur _not_ est représenté par `!` et renvoie `true` si le booléen donné vaut `false`, et `false` s'il vaut `true`.
Quand on utilise l'opérateur _not_, il faut placer un booléen après l'opérateur (`!`).

```crystal
!true
# => false

!false
# => true
```

## Utilise des parenthèses (`()`)

Quand on travaille avec des booléens, on peut utiliser des parenthèses pour décider quels booléens évaluer en premier.
Le résultat peut différer selon la façon dont les parenthèses sont utilisées.
En Crystal, ce qui se trouve entre parenthèses est évalué en premier.

```crystal
true && false && false || true
# => true

true && false && (false || true)
# => false
```

Comme ce qui se trouve entre parenthèses est évalué en premier, l'opérateur _not_ s'applique à l'expression entre parenthèses dans l'exemple suivant.

```crystal
!true && false
# => false

!(true && false)
# => true
```

~~~~exercism/note
Tu ne dois utiliser des parenthèses que lorsqu'elles changent le résultat ; sinon, il faut les omettre.
~~~~

## _Truthy_ et _falsey_

En Crystal, les valeurs _falsey_ sont : `false`, `nil` et les pointeurs nuls ; **tout le reste** est _truthy_.
Ces valeurs peuvent être utilisées avec les opérateurs logiques mentionnés ci-dessus.

```crystal

true && nil
# => false

false && 4
# => false

true || nil
# => true
```

## Conventions de nommage des méthodes avec des booléens

En Crystal, il est courant de faire suivre d'un point d'interrogation (`?`) le nom d'une méthode qui renvoie une valeur _truthy_ ou _falsey_.
Dans la plupart des cas, cette méthode renverra une valeur booléenne, mais ce n'est pas obligatoire.
Cela signifie que la méthode peut être utilisée là où une valeur _truthy_ ou _falsey_ est attendue, par exemple comme condition d'une instruction `if` :

```crystal
def exchange(value)
    if value.nil?
        value = 5
    end
    value
end

exchange(10)
# => 10

exchange(nil)
# => 5
```

Les méthodes dont le nom se termine par un point d'interrogation et qui ne renvoient pas de valeur booléenne renvoient souvent `nil` à la place. `nil` est _semblable à `None` ou `null` dans d'autres langages_.
