# Débogage

Comme l'exécuteur de tests actuel utilise [PonyTest](https://stdlib.ponylang.io/pony_test--index/), l'acteur Main se trouve dans test.pony et ne doit pas être modifié dans le cadre de ta solution.

Comme le veut la bonne pratique dans les applications Pony, on ne donne pas accès à `Env` sauf en cas de besoin. Cela signifie que dans la quasi-totalité des cas, tu ne peux pas faire de débogage de type `printf` avec `env.out.print()`.

Cependant, Pony dispose d'un module [debug](https://stdlib.ponylang.io/debug--index/) qui permet aux programmes compilés avec l'option `-d` d'avoir un accès particulier à STDOUT et STDERR, sans accès à `Env`.

Si tu as besoin de faire du débogage de type `printf`, c'est cette fonctionnalité qu'il te faut utiliser.

Exemple de débogage :

```pony
use "debug"

actor Main
  new create(env: Env) =>
    MySolution.examplefn("First String", 42)

primitive MySolution
  fun examplefn(arg1: String, arg2: USize) =>
    Debug.out("arg1: " + arg1 + ", arg2: " + arg2.string() + " were provided to MySolution.examplefn()")
```
