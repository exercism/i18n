# Introduction

## _Strings_

Les chaînes de caractères en Elixir sont délimitées par des guillemets doubles, et elles sont encodées en UTF-8 :

```elixir
"Hi!"
```

Les _strings_ peuvent être concaténées à l'aide de l'opérateur `<>/2` :

```elixir
"Welcome to" <> " " <> "New York"
# => "Welcome to New York"
```

Les _strings_ en Elixir prennent en charge l'interpolation avec la syntaxe `#{}` :

```elixir
"6 * 7 = #{6 * 7}"
# => "6 * 7 = 42"
```

Pour insérer un caractère de saut de ligne dans une _string_, utilise le code d'échappement `\n` :

```elixir
"1\n2\n3\n"
```

Pour travailler confortablement avec des textes comportant beaucoup de sauts de ligne, utilise plutôt la syntaxe _heredoc_ à triple guillemets doubles :

```elixir
"""
1
2
3
"""
```

Elixir fournit de nombreuses fonctions pour travailler avec les _strings_ dans le module `String`.

## Opérateur pipe

L'opérateur `|>` est appelé l'opérateur pipe. Il permet d'enchaîner des appels de fonctions de sorte que la valeur renvoyée par l'appel de fonction précédent soit passée comme premier argument à l'appel de fonction suivant.

```elixir
"hello"
|> String.upcase()
|> Kernel.<>("?!")

# => "HELLO?!"
```
