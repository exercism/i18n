# Représentations

Le [representer][representer] utilise [`read`][cl-read] pour lire la soumission et [`write`][cl-write] pour écrire la représentation, et applique en plus quelques normalisations supplémentaires.
Chaque soumission se voit appliquer les normalisations suivantes :

- [Tous les commentaires sont supprimés][remove-comments]
- [Les chaînes de documentation sont supprimées][remove-doc-strings]
- [La casse du texte est normalisée][normalize-case]
- [Le formatage du texte est normalisé][normalize-formatting]
- [Les noms de symboles sont normalisés][normalize-names]
