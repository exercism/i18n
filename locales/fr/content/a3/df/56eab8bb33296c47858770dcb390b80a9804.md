# À propos

Les [_strings_][getting-started-strings] en Elixir sont délimitées par des guillemets doubles et sont encodées en UTF-8 :

```elixir
"Hi!"
```

Les _strings_ peuvent être concaténées à l'aide de l'opérateur [`<>/2`][kernel-concat] :

```elixir
"Welcome to" <> " " <> "New York"
# => "Welcome to New York"
```

Les _strings_ en Elixir prennent en charge [l'interpolation][string-interpolation] avec la syntaxe `#{}` :

```elixir
"6 * 7 = #{6 * 7}"
# => "6 * 7 = 42"
```

N'importe quelle expression Elixir est valide à l'intérieur de l'interpolation. Si une _string_ est fournie, elle est interpolée telle quelle. Si c'est une autre valeur qui est fournie, Elixir tentera de la convertir en _string_.

```elixir
"Elixir can convert booleans to strings: #{true}"
# => "Elixir can convert booleans to strings: true"

"And #{["lists", ", ", "too!"]}"
# => "And lists, too!"

"But not functions: #{fn x -> x end}"

# => ** (Protocol.UndefinedError) protocol String.Chars not implemented for #Function<7.126501267/1 in :erl_eval.expr/5> of type Function
#        (elixir 1.10.1) lib/string/chars.ex:3: String.Chars.impl_for!/1
#        (elixir 1.10.1) lib/string/chars.ex:22: String.Chars.to_string/1
```

Elixir fournit de nombreuses fonctions pour manipuler les _strings_ dans le module `String`. Si tu ne sais pas comment traiter une _string_ comme tu le souhaites, pense à parcourir [les fonctions disponibles dans le module `String`][string-module-functions] et tu trouveras très probablement ce dont tu as besoin.

```elixir
String.downcase("PLEASE NO SHOUTING")
# => "please no shouting"

String.split("hello", "", trim: true)
# => ["h", "e", "l", "l", "o"]

String.replace("Do I enjoy Elixir? Maybe...", "Maybe...", "Definitely!")
# => "Do I enjoy Elixir? Definitely!"

String.at("12345", 2)
# => "3"
```

En utilisant certaines de ces fonctions, n'oublie pas que le premier caractère d'une _string_ a pour indice `0`.

Certains caractères doivent être [échappés][escape-characters] pour figurer dans une _string_, par exemple les sauts de ligne, les guillemets doubles ou le caractère `#` :

```elixir
"\"A\" is the \#1st letter of the alphabet.\n"
```

Pour travailler confortablement avec des textes contenant beaucoup de sauts de ligne, utilise plutôt la [syntaxe heredoc à triple guillemets doubles][heredoc-syntax] :

```elixir
"""
1
2
3
"""
```

Tu rencontreras très souvent cette syntaxe pour documenter du code :

```elixir
defmodule MyApp.Hello do
  @moduledoc """
  This is the Hello module.
  """

  @doc """
  Says hello to the given `name`.

  Returns `:ok`.

  ## Examples

      iex> MyApp.Hello.world(:john)
      :ok

  """
  def world(name) do
    IO.puts("hello #{name}")
  end
end
```
