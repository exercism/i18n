# Fonctions

En JavaScript, les fonctions sont des _objets de première classe_, ce qui signifie qu'elles peuvent être affectées à des variables et à des propriétés, passées à d'autres fonctions et renvoyées par des fonctions. Elles peuvent avoir des propriétés et des méthodes, comme n'importe quel autre _objet_.

## Entrée : passage d'arguments

Les fonctions JavaScript permettent de passer des arguments lorsqu'on les appelle. Les arguments sont toujours [passés par valeur](https://dev.to/xpbytes/javascript-ruby-and-c-are-not-call-by-reference-23f7). Autrement dit, si une fonction réaffecte un paramètre à l'intérieur de la fonction, la valeur ne changera pas à l'extérieur de la fonction. Cela ne veut pas dire que les objets passés ne peuvent pas être mutés.

> [!TIP]
> Quand on passe un objet, c'est la référence vers cet objet qui est passée par valeur. Cela donne l'_impression_ que les objets passés sont traités différemment, mais ce n'est pas le cas.

Voici un exemple de fonction qui prend deux arguments et les multiplie :

```javascript
function multiply(a, b) {
  return a * b;
}

multiply(2, 3);
// => 6
```

## Sortie : valeur de retour

Une fonction JavaScript peut renvoyer une seule valeur à l'aide du mot-clé `return`, suivi d'une expression. Quand une fonction ne renvoie rien, la valeur renvoyée est `undefined`.

Voici un exemple de fonction qui renvoie une valeur :

```javascript
function multiply(a, b) {
  return a * b;
}

multiply(2, 3);
// => 6
```

## Définis des fonctions

Il existe quatre variantes de fonctions en JavaScript :

1. Les fonctions classiques, qui peuvent renvoyer n'importe quoi et s'exécutent toujours jusqu'au bout ;
2. Les fonctions async, qui renvoient toujours une `Promise` et peuvent être mises en pause puis reprises avec l'opérateur `await` ;
3. Les fonctions génératrices, qui renvoient toujours un objet `Generator` et peuvent être mises en pause puis reprises avec l'opérateur `yield` ;
4. Les fonctions génératrices asynchrones, qui renvoient toujours un objet `AsyncGenerator` et peuvent être mises en pause puis reprises avec _à la fois_ les opérateurs `yield` et `await`.

Pour chacune de ces quatre variantes, il y a trois façons de les définir :

1. à l'aide d'une déclaration
2. à l'aide d'une expression
3. à l'aide du constructeur

Enfin, il existe une syntaxe spéciale pour définir les _fonctions fléchées et les méthodes_.
