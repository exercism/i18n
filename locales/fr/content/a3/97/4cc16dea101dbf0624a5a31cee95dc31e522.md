# À propos

Les dictionnaires, comme leurs équivalents dans d'autres langages tels que les tables associatives ou les tableaux associatifs, stockent des paires clé/valeur, de sorte qu'une valeur peut être récupérée ou modifiée directement en passant la clé à la propriété d'indexeur du dictionnaire.

De plus, on peut ajouter et supprimer des paires clé/valeur d'un dictionnaire. Les clés, les valeurs et les paires clé/valeur peuvent être énumérées.

Les valeurs peuvent être des objets de n'importe quel type C#, ce qui inclut les primitives, les structs _et_ les classes.

L'objet Dictionary autorise les clés à être des objets de n'importe quel type. Toutefois, pour garantir un comportement correct à l'exécution, les clés doivent avoir un code de hachage approprié, tel que celui renvoyé par [GetHashCode][gethashcode].

Une instance de dictionnaire ne peut pas être consultée en toute sécurité par plus d'un _thread_ (elle n'est pas _thread-safe_). [ConcurrentDictionary][concurrent-dictionary] est disponible pour les situations multithread.

Voir aussi [HashSet][hashset], [ConcurrentDictionary][concurrent-dictionary], [SortedDictionary][sorted-dictionary].

Bien qu'il n'existe pas de version non générique de Dictionary, un certain nombre de classes subsistent dans la bibliothèque pour prendre en charge une table associative non générique. Il est utile de connaître les versions non génériques d'IDictionary et de Hashtable, principalement pour pouvoir les identifier quand on les rencontre. Il est peu probable que tu aies à les utiliser, sauf pour maintenir une ancienne base de code.

Tu voudras souvent exposer le dictionnaire et y accéder via son interface [`IDictionary<TKey, TValue>`][idictionary].

À noter que, en raison de la nature des [propriétés d'indexeur][indexer-properties], les valeurs primitives peuvent être modifiées sur place, par exemple :

```csharp
nums["some-number"] = 3;
nums["some-number"]++;
// nums["some-number"] == 4

```
