# Introduction

La classe `TimeZoneInfo` fournit des routines pour gérer les différences entre les fuseaux horaires. Elle contient aussi des méthodes qui facilitent la gestion de l'heure d'été.

La classe `CultureInfo` prend en charge les formats de date et d'heure dépendant des paramètres régionaux.

Pour permettre le développement multiplateforme, la classe `RuntimeInformation` permet de détecter le système d'exploitation sur lequel ton code s'exécute : Linux, Windows ou OSX.
