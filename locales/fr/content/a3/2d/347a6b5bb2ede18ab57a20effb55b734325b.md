# Indices

## Général

- Le type fourni est récursif : `Nil` représente un arbre vide, et `Node(node)` contient un enregistrement avec une valeur et deux sous-arbres.
  Un `match` permet de distinguer ces cas et de lier l'enregistrement du nœud.

- Les mises à jour d'enregistrement telles que `{ ..node, left: new_left }` conservent les autres champs ; il suffit d'envelopper l'enregistrement mis à jour dans `Node(...)` pour construire l'arbre obtenu.
