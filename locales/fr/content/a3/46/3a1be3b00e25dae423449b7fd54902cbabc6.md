# Indices

## Général

- [Tutoriel sur les types énumérés][java-tutorial-enum-types].

## 1. Analyse le niveau de log

- Il existe une [méthode pour obtenir une partie d'une _string_][java-docs-substring].
- Tu peux utiliser une [instruction `switch`][java-tutorial-switch-statement] pour gérer élégamment les différents niveaux de log.

## 2. Prends en charge un niveau de log inconnu

- Il existe un cas particulier de `switch` appelé `default`, qui permet d'intercepter les cas non spécifiés.

## 3. Convertis une ligne de log au format court

- Tu peux ajouter des champs et des méthodes à un type énuméré, consulte le [tutoriel sur les types énumérés][java-tutorial-enum-types].
