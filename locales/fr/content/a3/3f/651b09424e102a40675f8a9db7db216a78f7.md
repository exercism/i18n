# Instructions

Dans cet exercice, tu vas implémenter les règles qui permettent de calculer le salaire total d'un employé sur un mois.
L'International Siderurgy Company (ISC) a besoin d'aide pour calculer les salaires de ses employés, en tenant compte de divers facteurs qui peuvent influencer le montant final.

Tu as trois tâches, et tu dois utiliser l'opérateur ternaire plutôt que des instructions if/else pour les réaliser.

## 1. Détermine le multiplicateur de salaire

Implémente la méthode `salaryMultiplier`, qui renvoie le multiplicateur de salaire en fonction du nombre de jours d'absence d'un employé.
Applique une pénalité de 15 % si l'employé a manqué au moins cinq jours.

```java
int daysSkipped = 3;
salaryMultiplier(daysSkipped);
// => 1.0

daysSkipped = 7;
salaryMultiplier(daysSkipped);
// => 0.85
```

## 2. Calcule la prime pour les produits vendus

Implémente les méthodes `bonusMultiplier` et `bonusForProductsSold`.
L'ISC verse dix unités monétaires pour chaque produit vendu, et si un employé vend vingt produits ou plus, le multiplicateur passe à treize.
`bonusMultiplier` doit déterminer quel multiplicateur appliquer, et `bonusForProductSold` doit renvoyer la prime totale en unités monétaires.

```java
int productsSold = 21;
bonusMultiplier(productsSold);
// => 13
bonusForProductsSold(productsSold);
// => 273

productsSold = 5;
bonusMultiplier(productsSold);
// => 10
bonusForProductsSold(productsSold);
// => 50
```

## 3. Calcule le salaire final de l'employé

Implémente la méthode `finalSalary`.
Elle doit multiplier le salaire de base de `1000.00` par le multiplicateur de salaire, ajouter la prime, puis renvoyer le résultat.
Cependant, les salaires doivent être plafonnés à `2000.00`.

```java
int daysSkipped = 2;
int productsSold = 3;
finalSalary(daysSkipped, productsSold);
// => 1030.00

productsSold = 90;
finalSalary(daysSkipped, productsSold);
// => 2000.00
```
