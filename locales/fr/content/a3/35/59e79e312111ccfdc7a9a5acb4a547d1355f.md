# Instructions

Dans cet exercice, tu vas implémenter les mécaniques d'un jeu de rôle.
Le personnage d'un joueur est représenté par le type suivant :

```fsharp
type Player = {
    Name: string option
    Level: int
    Health: int
    Mana: int option
}
```

Dans ce jeu, les joueurs doivent atteindre le niveau 10 avant de déverrouiller une réserve de mana, ce qui leur permet de commencer à lancer des sorts.
Tu vas travailler sur deux fonctionnalités de ce jeu : la mécanique de réanimation et la mécanique de lancement de sorts.

## 1. Présente-toi

Écris le contenu de la fonction `introduce`.
Note que le champ `Name` de l'enregistrement `Player` est une `Option`.
Les joueurs furtifs pourraient vouloir cacher leur nom en le laissant défini à `None` ; ces joueurs seront présentés comme `"Mighty Magician"`.
Sinon, utilise simplement ton nom pour te présenter.

```fsharp
introduce { Name = None; Level = 2; Health = 8; Mana = None }
    --> "Mighty Magician"

introduce { Name = Some "Merlin"; Level = 2; Health = 8; Mana = None }
    --> "Merlin"
```

## 2. Implémente la mécanique de réanimation

La fonction `revive` doit vérifier que le personnage du joueur est bien mort (ses points de vie ont atteint 0).
Si c'est le cas, elle doit renvoyer une nouvelle instance de `Player` avec 100 points de vie.
Sinon, si le personnage du joueur n'est pas mort, la fonction `revive` renvoie `None`.

Si le niveau du joueur est de 10 ou plus, il doit aussi être réanimé avec 100 points de mana.
Si le niveau du joueur est inférieur à 10, son mana doit être `None`.
La fonction `revive` doit préserver le niveau du joueur.

```fsharp
let deadPlayer = { Name = None; Level = 2; Health = 0; Mana = None }

revive deadPlayer
    --> Some { Name = None; Level = 2; Health = 100; Mana = None }
```

Si la méthode `revive` est appelée sur un joueur dont les points de vie sont de 1 ou plus, alors la fonction doit renvoyer `None`.

```fsharp
let alivePlayer = { Name = None; Level = 2; Health = 42; Mana = None }

revive alivePlayer
    --> None
```

## 3. Implémente la mécanique de lancement de sorts

La fonction `castSpell` prend en arguments un `int` indiquant combien de mana le sort coûte, ainsi qu'un `Player`.
Elle renvoie le joueur mis à jour, ainsi que la quantité de dégâts que le sort lancé inflige.
Un lancement de sort réussi inflige des dégâts égaux à deux fois le coût en mana du sort.
Cependant, si le joueur n'a pas assez de mana, rien ne se passe, le joueur reste inchangé et aucun dégât n'est infligé.
Si le joueur n'a même pas de réserve de mana, tenter de lancer le sort doit diminuer ses points de vie du coût en mana du sort et n'inflige aucun dégât.

```fsharp
let wizard = { Name = None; Level = 18; Health = 123; Mana = Some 30 }

let updatedWizard, damage = castSpell 14 wizard

updatedWizard.Mana --> Some 16
damage             --> 28
```
