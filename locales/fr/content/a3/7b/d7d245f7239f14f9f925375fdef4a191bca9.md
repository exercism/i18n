# Introduction

Une boucle `for` permet de parcourir un tableau et de répéter le code pour chaque élément :

```haxe
var fruitList = ["apple", "banana", "pear"];

for (fruit in fruitList) {
  trace(fruit);
}

// apple
// banana
// pear
```

Dans l'exemple ci-dessus, `fruit` est la variable qui contient la valeur d'un élément individuel du tableau `fruitList`. Le compilateur s'assure que l'on peut parcourir `fruitList`, sinon il arrête l'exécution.

On peut parcourir des nombres à l'aide de l'opérateur d'intervalle. Cet opérateur prend deux opérandes `Int` et s'écrit `min...max` :

```haxe
for (i in 0...10) {
  trace(i); // from 0 to 9
}
```
