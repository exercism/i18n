# Utilisation des retours nus

La communauté Go recommande d'éviter les retours nus (ou *bare returns*) dans des circonstances normales, car ils rendent généralement le code plus difficile à lire.
Voir le [guide officiel de revue de code Go](https://github.com/golang/go/wiki/CodeReviewComments#naked-returns) pour plus de détails.
Une [proposition](https://github.com/golang/go/issues/21291) vise à supprimer complètement les retours nus dans Go 2.
