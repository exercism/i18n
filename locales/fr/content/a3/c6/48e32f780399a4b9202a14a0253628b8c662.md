# Instructions

Convertis un nombre hexadécimal, représenté sous forme de _string_ (par exemple « 10af8c »), en son équivalent décimal en partant des principes de base (autrement dit, non, tu n'as pas le droit d'utiliser des bibliothèques internes ou externes pour effectuer cette conversion).

Sur le web, on utilise l'hexadécimal pour représenter des couleurs, par exemple le vert : 008000, la sarcelle : 008080, le bleu marine : 000080).

Le programme doit gérer les _strings_ hexadécimales invalides.
