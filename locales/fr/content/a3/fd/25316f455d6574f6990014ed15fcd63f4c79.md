# Introduction

Le code Elixir s'exécute dans la machine virtuelle BEAM. BEAM fait partie de l'Erlang Run-Time System. Comme Elixir s'inspire d'Erlang et partage son environnement d'exécution, il offre une excellente interopérabilité avec les bibliothèques Erlang. Cela signifie que les développeurs Elixir peuvent utiliser les bibliothèques Erlang depuis leur code Elixir. D'ailleurs, au sein de la communauté Elixir, écrire des bibliothèques Elixir pour des fonctionnalités déjà fournies par les bibliothèques Erlang est mal vu.

Par conséquent, certaines fonctionnalités, comme les opérations mathématiques ou les fonctions de temporisation, ne sont disponibles en Elixir que par l'intermédiaire d'Erlang.

La bibliothèque standard d'Erlang est utilisable dans notre code Elixir sans aucune étape supplémentaire.

On peut appeler les fonctions Erlang de la même manière que les fonctions Elixir, à une petite différence près. Les noms des modules Erlang sont des atomes en `snake_case`. Par exemple, pour appeler la fonction Erlang `pi/0` du module `math`, on écrirait :

```elixir
:math.pi()
# => 3.141592653589793
```

Les fonctions Erlang les plus couramment utilisées qui n'ont pas d'équivalent en Elixir sont :

- `:timer.sleep/1`, qui suspend un processus pendant le nombre de millisecondes indiqué.
- `:rand.uniform/0`, qui génère un nombre décimal aléatoire `x`, où `0.0 <= x < 1.0`.
- `:io_lib.format/2`, qui permet de formater des _strings_ à la manière du C (à l'aide de séquences de contrôle). Avec cette fonction, on pourrait par exemple afficher un entier dans n'importe quelle base entre 2 et 36, ou formater un nombre décimal avec la précision souhaitée. À noter que cette fonction, comme beaucoup de fonctions Erlang, renvoie une charlist.
- Le module `math`, qui fournit des fonctions mathématiques telles que `sin/1`, `cos/1`, `log2/1`, `log10/1`, `pow/2`, et bien d'autres.

Pour découvrir la bibliothèque standard d'Erlang, explore le [manuel de référence STDLIB][erl-stdlib-ref].

[erl-stdlib-ref]: https://www.erlang.org/doc/apps/stdlib/index.html
