# Introduction

## Les types `struct`

On a déjà vu les types `struct` ; pour résumer, un `struct` est une séquence d'éléments nommés appelés _champs_, chaque champ ayant un nom et un type.
Le nom d'un champ doit être unique au sein du `struct`.
Les `struct` peuvent être comparés à la _classe_ du paradigme de la programmation orientée objet.

On crée un nouveau `struct` à l'aide des mots-clés `type` et `struct`, puis on définit explicitement le nom et le type des champs, comme le montre l'exemple ci-dessous.

```go
type StructName struct{
    field1 fieldType1
    field2 fieldType2
}
```

## Les types qui ne sont pas des `struct`

Il est aussi possible de définir des types qui ne sont pas des `struct`, que l'on peut utiliser comme alias d'un type intégré.

```go
type Name string
func SayHello(n Name) {
  fmt.Printf("Hello %s\n", n)
}
n := Name("Fred")
SayHello(n)
// Output: Hello Fred
```

On peut aussi définir des types qui ne sont pas des `struct`, composés de tableaux et de _maps_.

```go
type Names []string
func SayHello(n Names) {
  for _, name := range n {
    fmt.Printf("Hello %s\n", name)
  }
}
n := Names([]string{"Fred", "Bill"})
SayHello(n)
// Output:
// Hello Fred
// Hello Bill
```
