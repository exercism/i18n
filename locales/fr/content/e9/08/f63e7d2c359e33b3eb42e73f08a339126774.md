# À propos

- Le type [binaire][binary] est une spécialisation du type [bitstring][bitstring].
- Les binaires sont constitués d'[octets][wiki-byte].
  - Un octet est composé de 8 [bits][wiki-bit].
  - Un octet peut représenter des nombres allant de `0` à `255`
  - Les valeurs entières en [hexadécimal][wiki-hexadecimal] sont courantes lorsqu'on manipule des octets : `0x00` à `0xFF`.
- Les littéraux binaires se définissent à l'aide de [la forme spéciale `<<>>`][special-form].
  - Si tu utilises un entier supérieur à `255` pour un octet, seuls les 8 derniers bits sont utilisés, sauf si tu précises [l'unité et/ou la taille à utiliser][bin-size] à l'aide de l'opérateur [`::`][type-operator].
- [`<>/2`][bin-concat] permet de concaténer des bitstrings, des binaires ou des _strings_.

```elixir
<<255>> == <<0xFF>>
# Overflowing bits are truncated
<<256>> == <<0>>
<<256::size(16)>> == <<1, 0>>

<<"Hello">> == <<72, 101, 108, 108, 111>>
```

Un octet nul est un autre nom pour `<<0>>`.

## Les _strings_ sont des données binaires encodées

- Les _strings_ sont des données binaires encodées au format [UTF-8][wiki-utf8].
  - L'encodage se fait par blocs de 8 bits (un octet), et jusqu'à 4 octets sont utilisés pour représenter plus de 255 caractères.
  - La [longueur d'un _string_][string-length] peut ne pas être identique à sa [taille en octets][byte-size].

```elixir
# This string has a string length of 5, but is made up of 7 bytes
string = "cześć"
String.length(string) != byte_size(string)

# Even emoji strings are encoded binaries
"👍" == <<240, 159, 145, 141>>
```

## Le _pattern matching_ sur les données binaires

- On peut faire du _pattern matching_ sur un binaire dans son ensemble, ou bien utiliser la forme spéciale pour n'en faire correspondre qu'une partie.
  - Seule la dernière partie d'un _pattern matching_ peut avoir une taille variable.

```elixir
# Ignore the first 8 bytes, bind the remaining variable sized binary to `body`
<<_::binary-size(8), body::binary>>
```

On peut également le faire avec des _strings_ :

```elixir
# bind the first 5 bytes to `name`,
# match the string literal " the ",
# bind remaining bytes to `species`
<<name::binary-size(5), " the ", species::binary>> = <<"Frank the Walrus">>
{name, species}
# => {"Frank", "Walrus"}
```
