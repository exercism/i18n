# _Threads_

Cet exercice introduit les _threads_ afin de tester la robustesse de ton compte bancaire face à des opérations concurrentes. Quelques lectures sur les _threads_ en Tcl :

* [Tcl Threading Model](https://www.tcl.tk/doc/howto/thread_model.html)
* [Threads Done Right… with Tcl](https://www.activestate.com/blog/threads-done-right-tcl/)
* [Multi-Threaded Tcl Scripts](http://www.beedub.com/book/4th/Threads.pdf),
  un chapitre de _Practical Programming in Tcl and Tk, 4th Ed._,
copyright 2003 © Brent Welch, Ken Jones
[http://www.beedub.com/book/](http://www.beedub.com/book/)
    * À noter que ce chapitre affirme que « Most binary distributions of Tcl are not thread-enabled ». Ce n'est plus le cas aujourd'hui : les distributions de Tcl sont désormais compilées avec le support des _threads_ (voir [TIP 364](https://core.tcl-lang.org/tips/doc/trunk/tip/364.md))
* [Thread Package Commands](https://tcl.tk/man/tcl8.6/ThreadCmd/contents.htm) dans la documentation de Tcl.

## Installation

Certaines distributions de Tcl n'incluent pas le paquet Thread de Tcl par défaut : il peut être nécessaire de l'installer séparément.
Vérifie avec
```bash
$ echo 'package require Thread' | tclsh
```
Si cela ne produit _aucune sortie_, alors le paquet Thread est déjà installé.

Exécute `apt install tcl-thread` (ou `dnf install tcl-thread`) selon les besoins.
