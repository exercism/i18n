# Ressources

## Référence

- La [carte de référence RISC-V][reference-card] liste les instructions, les pseudo-instructions et les registres.
- La [convention d'appel RISC-V][psabi] décrit quels registres contiennent les entrées et les résultats d'une fonction, et lesquels une fonction doit préserver.
- Les [spécifications RISC-V][isa-manual] décrivent exactement ce que fait chaque instruction.
- Le [manuel de l'assembleur GNU][gas-directives] décrit des directives telles que `.section`, `.string`, `.word` et `.global`.

## Outils

- [Compiler Explorer][godbolt] montre l'assembleur qu'un compilateur produit pour un morceau de code C.
  Le lien l'ouvre avec un compilateur RISC-V 32 bits, ce qui te permet de comparer tes propres solutions avec ce qu'écrirait un compilateur.

## Communauté

- [RISC-V International][riscv-org] est l'organisation qui veille sur le standard RISC-V.
- [r/RISCV][reddit] est une communauté Reddit qui partage des actualités sur les puces, les cartes et les logiciels RISC-V.
- [Stack Overflow][stack-overflow] regroupe des questions et des réponses sur l'assembleur RISC-V.
