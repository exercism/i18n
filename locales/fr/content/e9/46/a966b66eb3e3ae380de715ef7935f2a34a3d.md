# À propos

Le concept de base `try .. rescue` peut être étendu pour prendre en charge les clauses `else` et `after` :

- Le bloc `else` :
  - où l'on effectue une correspondance de motif sur le résultat renvoyé par le bloc `try` en cas de succès.
- Le bloc `after` :
  - où les fonctions sont appelées, que le bloc `try` réussisse ou qu'il soit intercepté par `rescue`, tant que le programme est en cours d'exécution.
  - Le résultat du bloc `after` n'est pas renvoyé à la portée appelante.

```elixir
try do
  :a
rescue
  _ -> :error
else
  :a -> :success
after
  :some_action
end

# => :success
```
