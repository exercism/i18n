# Tests

Pour exécuter les tests fournis, tu auras besoin de la _gem_ Minitest. Ouvre une fenêtre de terminal et exécute la commande suivante pour installer minitest :

```
gem install minitest
```


Exécute les tests depuis le répertoire de l'exercice avec la commande suivante :

```
ruby <snake-case-exercise>_test.rb
```

Remplace `<snake-case-exercise>` par le nom de ton exercice en `snake_case`.

## Sortie en couleur

Tu peux utiliser `require 'minitest/pride'` ou exécuter la commande suivante pour obtenir une sortie en couleur :

```
ruby -r minitest/pride <snake-case-exercise>_test.rb
```
