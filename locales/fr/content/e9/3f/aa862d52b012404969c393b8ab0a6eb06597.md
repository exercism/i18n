# Introduction

Le concept [`Basics`][basics] a présenté deux façons de définir une fonction.

Le plus souvent, la forme multiligne :

```julia
function muladd(x, y, z)
    x * y + z
end
```

La forme « affectation », ou forme « sur une seule ligne », pour les définitions courtes :
```julia
muladd(x, y, z) = x * y + z
```

Dans une troisième forme, encore plus courte, on peut créer une fonction courte à usage unique, sans lui donner de nom :

```julia-repl
julia> map(x -> 2x, 1:3)
4-element Vector{Int64}:
 2
 4
 6

julia> map((x, y) -> x * y, 1:3, 4:6)
3-element Vector{Int64}:
  4
 10
 18
```

Ici, `x -> 2x` est une « fonction anonyme ».
C'est l'équivalent de ce que d'autres langages appellent une « fonction lambda ».

À noter que plusieurs arguments nécessitent des parenthèses, comme dans `(x, y) -> x * y`.

Les fonctions anonymes sont courantes dans le code Julia, en particulier lorsqu'elles sont combinées à des fonctions d'ordre supérieur comme `map()` et `filter()`.

## Les arguments de fonction

Jusqu'ici dans le programme, on n'a vu que des fonctions qui ont un nombre précis d'arguments et qui exigent que chaque appel les fournisse tous, dans le bon ordre.
Ce serait trop restrictif et peu pratique, c'est pourquoi il existe plusieurs autres possibilités.

### Les arguments facultatifs

Comme beaucoup de langages, Julia permet de définir une valeur par défaut pour chacun des arguments d'une fonction.

Lors d'un appel, on peut alors soit fournir une valeur pour cet argument, soit l'omettre et se fier à la valeur par défaut.

```julia-repl
julia> f(x, y=10) = x * y
f (generic function with 2 methods)

julia> f(2, 3)
6

julia> f(2)
20
```

Tous les arguments _sans_ valeur par défaut doivent venir avant les arguments _avec_ valeur par défaut, ce qui signifie que `f(x=2, y)` serait invalide.

### Les arguments nommés

Tous les exemples vus jusqu'ici utilisent des `positional arguments`, c'est-à-dire que les valeurs fournies lors d'un appel doivent respecter l'ordre des arguments correspondants dans la définition de la fonction.

Comme beaucoup de langages, Julia autorise aussi les `keyword arguments`.
Lors de l'appel, il faut préciser le nom de l'argument, mais on peut ensuite indiquer plusieurs arguments nommés dans n'importe quel ordre.

Une particularité de Julia est que les arguments nommés (s'il y en a) doivent être précédés d'un point-virgule `;` dans la définition de la fonction, pour les séparer des éventuels arguments positionnels.
Dans un appel, on peut utiliser `;` ou `,` entre le dernier argument positionnel et le premier argument nommé.

```julia-repl
julia> b(x; y) = x + y
b (generic function with 1 method)

julia> b(2, y=3)
5

# keyword is required when calling
julia> b(2, 3)
ERROR: MethodError: no method matching b(::Int64, ::Int64)
The function `b` exists, but no method is defined for this combination of argument types.
```

On peut éventuellement préciser des valeurs par défaut, exactement comme pour les arguments positionnels.

Il est fréquent d'obtenir une syntaxe comme `myarg=myarg` dans un appel de fonction, lorsqu'une variable portant le même nom que le paramètre a déjà été calculée.
Une syntaxe abrégée est autorisée dans ce cas :

```julia-repl
julia> width = 4.0
4.0

julia> height = √ width
2.0

julia> area(; width, height) = width * height
area (generic function with 1 method)

# repetition
julia> area(; width=width, height=height)
8.0

# shorthand form
julia> area(; width, height)
8.0
```

### Splat et slurp

Voici les noms consacrés d'un aspect bien utile de la syntaxe Julia, au cas où tu te posais la question.
Tous deux désignent l'opérateur `...`.

#### Splat

Le _splat_ s'utilise dans les _appels_ de fonction, pour décomposer une collection en valeurs individuelles attendues par la fonction.

C'est sans doute plus facile à montrer qu'à expliquer :

```julia-repl
julia> fxyz(x, y, z) = x * y * z
fxyz (generic function with 1 method)

julia> xyz = [2, 3, 4]
3-element Vector{Int64}:
 2
 3
 4

# Using the vector directly in a function call is invalid
julia> fxyz(xyz)
ERROR: MethodError: no method matching fxyz(::Vector{Int64})
The function `fxyz` exists, but no method is defined for this combination of argument types.

# splatting converts the vector to 3 numbers, used as positional arguments
julia> fxyz(xyz...)
24
```

Certains « appels de fonction » sont masqués par du sucre syntaxique, si bien que le _splat_ peut aussi servir de façon moins évidente.

Par exemple, l'affectation multiple utilise en interne une fonction de construction de tuple :

```julia-repl
julia> first, rest... = [1, 2, 3, 4]
4-element Vector{Int64}:
 1
 2
 3
 4

julia> first
1

julia> rest
3-element Vector{Int64}:
 2
 3
 4
```

On peut aussi fournir des arguments nommés par _splat_, généralement à l'aide d'un `named tuple`. 
Un `Dict` fonctionne aussi, mais les clés doivent être des symboles (des _strings_ ne fonctionneront pas).

```julia-repl
# function with 3 keyword arguments
julia> fabc(; a, b, c) = a + b + c
fabc (generic function with 1 method)

# named tuple
julia> abc_nt = (a=2, b=3, c=4)
(a = 2, b = 3, c = 4)

# there are no positional arguments, so need to use ; before kw argument
julia> fabc(;abc_nt...)
9

# Dict
julia> abc_dict = Dict(:a=>2, :b=>3, :c=>4)
Dict{Symbol, Int64} with 3 entries:
  :a => 2
  :b => 3
  :c => 4

julia> fabc(;abc_dict...)
9
```

#### Slurp

Le _slurp_ s'utilise dans la _définition_ de fonction, pour regrouper un nombre arbitraire de valeurs individuelles dans une collection.

```julia-repl
julia> f_more(i, j, more...) = i + j + sum(more)
f_more (generic function with 1 method)

julia> f_more(1, 3, 5, 7, 9, 11)
36
```

Le nom de l'argument _slurpé_ (ici `more`) n'a pas d'importance.
Le type de cette variable est choisi par le compilateur, mais pour les arguments positionnels il s'agira probablement d'un `tuple` ou d'un type similaire.

Les arguments nommés peuvent aussi être _slurpés_, ce qui donne un `Dict` (ou un type similaire).

```julia-repl
julia> f_kwslurp(x, y; switches...) = :mult in keys(switches) ? x * y : x + y
f_kwslurp (generic function with 1 method)

julia> f_kwslurp(5, 6; mult=true)
30

julia> f_kwslurp(5, 6)
11
```

N'importe quel argument nommé peut être utilisé dans l'appel.
C'est à la définition de la fonction de décider à quels mots-clés répondre et lesquels ignorer.
