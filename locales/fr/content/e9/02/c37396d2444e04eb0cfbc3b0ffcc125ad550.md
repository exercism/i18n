# Indices

## 1. Définis les types `Usd`, `Eur` et `Jpy`

- Les types `Usd`, `Eur` et `Jpy` peuvent être définis sans constructeurs, en utilisant la syntaxe `pub type TypeName`.

## 2. Définis le type `Money`.

- Le type `Money` doit prendre un paramètre de type fantôme pour la devise.

## 3. Définis les fonctions `dollar`, `euro` et `yen`

- L'annotation de retour des fonctions `dollar`, `euro` et `yen` doit être `Money(currency)`, où `currency` est le paramètre de type approprié du type `Money`.

## 4. Définis la fonction `total`

- L'annotation de retour de la fonction `total` doit utiliser le même paramètre de type que l'argument.
