# Instructions

Tu es le télégraphiste radio d'un cargo. Le signal arrive par une ligne bruitée (les machines du bord, les parasites météo, quelques conversations étrangères par-ci par-là), entremêlé au vrai Morse que tu cherches à capter. Pour capter le message, tu fais passer le fil dans un appareil à *bande* qui élimine tout sauf les symboles Morse valides (`.`, `-` et l'espace qui sépare les lettres).

Ton travail consiste à construire la bande sous la forme d'un flux d'entrée Factor personnalisé.

## 1. Définis la bande

Définis un tuple `tape` qui étend `disposable` et contient un seul emplacement, `wire`, pour le flux d'entrée sous-jacent.

```factor
TUPLE: tape < disposable wire ;
```

Écris ensuite le constructeur `<tape> ( wire -- tape )`. Utilise `new-disposable` (et non `new`) pour que l'infrastructure des destructeurs enregistre la bande, et stocke le flux sous-jacent dans l'emplacement `wire`.

## 2. Rejoins le _mixin_ input-stream

Déclare `tape` comme un `input-stream` :

```factor
INSTANCE: tape input-stream
```

Ainsi, les combinateurs par défaut du protocole sont dirigés vers ta classe.

## 3. Lis un symbole Morse

Implémente `M: tape stream-read1 ( tape -- elt/f )`. Lis les octets du fil sous-jacent jusqu'à tomber sur l'un de `CHAR: .`, `CHAR: -` ou `CHAR: \s` (un espace). Renvoie cet octet. Si le fil renvoie `f` (fin de flux), renvoie `f` toi aussi : la bande a fini son travail.

```factor
"x.y -ab cz" <string-reader> <tape>
[ stream-read1 ] [ stream-read1 ] [ stream-read1 ] tri
! => CHAR: . CHAR: - CHAR: \s
```

## 4. Délègue le type d'élément

Implémente `M: tape stream-element-type ( tape -- type )` en déléguant au fil : la bande ne change pas le type des éléments lus.

## 5. Nettoie

Implémente `M: tape dispose* ( tape -- )`. L'infrastructure appelle ta méthode exactement une fois par `dispose` ; il suffit de libérer le fil sous-jacent.

Une fois ces cinq éléments en place, la bande fonctionne comme un flux d'entrée ordinaire : `with-input-stream`, `stream-read` et les autres mots du protocole arrivent automatiquement à tes méthodes.
