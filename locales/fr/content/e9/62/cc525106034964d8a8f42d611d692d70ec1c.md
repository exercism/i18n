# Lance les tests Ceylon

Avant de pouvoir lancer les tests, il faut compiler le code avec [`ceylon compile`](https://ceylon-lang.org/documentation/current/reference/tool/ceylon/subcommands/ceylon-compile.html).

On lance les tests avec la commande [`ceylon test`](https://ceylon-lang.org/documentation/reference/tool/ceylon/subcommands/ceylon-test.html).

`ceylon test` attend un nom de module sur lequel exécuter les tests.
Dans le parcours Ceylon, chaque exercice ne comporte qu'un seul module.

Tu peux donc lancer les tests avec :

```bash
ceylon compile && ceylon test $(basename source/*)
```
