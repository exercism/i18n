# Introduction

Pour les bases concernant les arguments de fonction, consulte le [concept de fonction][function concept].

## Noms des paramètres

Les [noms de paramètres][parameters], comme les noms de variables, doivent commencer par une lettre ou un tiret bas et peuvent contenir des lettres, des tirets bas ou des chiffres.
Les noms de paramètres ne doivent pas contenir d'espaces ni de ponctuation.


## Arguments positionnels

Les arguments positionnels sont des valeurs transmises à une fonction dans le même ordre que les paramètres auxquels ils sont associés.
Il est possible de les passer en utilisant le nom de leur paramètre :


```python
def concat(greeting, name):
    return f"{greeting}{name}"
 
# Passing data to the function by position.
print(concat("Hello, ", "Judy"))
#->  Hello, Judy

# Passing data to the function using the parameter name.
print(concat(name="Sally", greeting="Hello, "))
#-> Hello, Sally
```

Le premier appel à concat passe les arguments par position.
Le second appel à concat passe les arguments par _nom_, ce qui permet de changer leur ordre.

À noter qu'un argument positionnel ne peut pas suivre un argument passé par nom (_aussi appelés [arguments nommés][keyword-arguments]. **À ne pas** confondre avec les paramètres positionnels variables ou les [**kwargs][kwargs]_).

Cet ensemble d'arguments :

```python
>>> print(concat(greeting="Hello, ", "Zed"))
```

produira cette erreur :

```
SyntaxError: positional argument follows keyword argument
```

## Valeurs par défaut des arguments

Des [valeurs par défaut][default arguments] pour un ou plusieurs arguments peuvent être fournies dans la liste des paramètres.
Cela permet d'appeler la fonction avec _moins_ d'arguments si nécessaire.
Il est possible de remplacer les valeurs par défaut en appelant la fonction avec de nouveaux arguments à la place de celles-ci :


```python
# Note the default arguments for both greeting and name.
def concat(greeting="Hello, ", name="you"):
    return f"{greeting}{name}"
 
# Function call overriding the defaults
print(concat(name="Jerry", greeting="Hello, "))
#-> Hello, Jerry

# Function call without arguments resulting in the defaults being used.
print(concat())
#-> Hello, you
```

## Arguments nommés

Les arguments nommés utilisent le nom du paramètre lorsqu'on passe des arguments à une fonction.
Il est aussi possible de les désigner par leur position :


```python
# Note the default arguments for both greeting and name.
def concat(greeting="Hello, ", name="you"):
    return f"{greeting}{name}"

# Function call using parameter names as argument keywords.
print(concat(name="Jerry", greeting="Hello, "))
#-> Hello, Jerry

# Function call with positional data as arguments.
print(concat("Hello, ", "Isaac"))
#-> Hello, Isaac
```
