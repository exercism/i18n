# Appendice aux instructions

## Comment cet exercice est structuré sur le parcours Python

Les tests de cet exercice attendent de toi que tu crées une [`class`][classes] Matrix (_voir aussi [concept:python/classes]()_).
Cela diffère du fait d'_utiliser_ un objet Matrix d'une bibliothèque tierce comme [Numpy][numpy-matrix], ce qui n'est pas pris en charge.
 _Pas de panique, ce n'est pas aussi compliqué que tu le penses !_
 Pour d'autres points de départ et plus de détails sur les `classes` et les structures de données, jette un œil aux ressources ci-dessous :


-   [**Un premier aperçu des classes**](https://docs.python.org/3/tutorial/classes.html#a-first-look-at-classes) dans la documentation de Python 3. 
-   [**Comment définir une classe en Python**](https://realpython.com/python3-object-oriented-programming/#how-to-define-a-class-in-python) sur le site Real Python.  
-   [**Les structures de données en Python**](https://docs.python.org/3/tutorial/datastructures.html) dans la documentation de Python 3.

[numpy-matrix]: https://numpy.org/doc/stable/reference/generated/numpy.matrix.html
