# À propos

Les types qui implémentent l'interface [`IEnumerable<T>`][IEnumerable] sont dits _énumérables_.
Tous les types de collections intégrés implémentent cette interface.

On peut parcourir un type énumérable à l'aide d'une boucle `foreach` :

```csharp
var primes = new[] { 2, 3, 5, 7 };
foreach (var prime in primes)
{
    Console.Write(prime);
}
// => 2357
```

Pour implémenter `IEnumerable<T>`, un type doit implémenter une seule méthode : `IEnumerator<T> GetEnumerator()`.
Comme on l'a vu, un énumérable délègue l'itération effective sur une collection à un type `IEnumerator<T>`.
Cette interface prend une propriété et trois méthodes à implémenter :

- `public T Current { get; }` : obtenir l'élément courant.
- `public bool MoveNext ();` : passer à l'élément suivant et renvoyer `true` si le passage à l'élément suivant a réussi, et `false` sinon (il n'y a plus d'éléments).
- `public void Reset ();` : réinitialiser l'énumérateur à son état initial (avant le premier élément).

[IEnumerable]: https://docs.microsoft.com/en-us/dotnet/api/system.collections.generic.ienumerable-1
