# Introduction

La plupart des données en Factor se trouvent dans des *séquences*. Les tableaux (`{ … }`), les vecteurs (`V{ … }`) et les _strings_ partagent tous le même [protocole][sequence-protocol] de [`sequences`][sequences].

```factor
{ 1 2 3 } length .    ! => 3
{ 1 2 3 } first .     ! => 1
{ 1 2 3 } last .      ! => 3
{ 1 2 3 4 5 } 3 head .! => { 1 2 3 }
```

Les agrégations (`sum`, `count`, `any?`, `all?`) et les prédicats comme `empty?` et `member?` fonctionnent uniformément sur tous les types de séquences. Construire de nouvelles séquences sans mutation : `prefix`, `suffix`, `append`, `unclip`, `unclip-last`.

`>array`, `>vector` et `>string` (dans [`arrays`][arrays] et les vocabulaires correspondants) convertissent entre les types de séquences quand on a besoin de récupérer un type concret particulier à partir d'une opération générique.

[arrays]: https://docs.factorcode.org/content/vocab-arrays.html

[sequences]: https://docs.factorcode.org/content/vocab-sequences.html
[sequence-protocol]: https://docs.factorcode.org/content/article-sequence-protocol.html
