# Installation

## Quelle version choisir ?

Nous t'encourageons à utiliser une version stable de PHP bénéficiant d'un support actif.
Actuellement, il s'agit de **PHP 8.2, 8.3 et 8.4**.
Tu trouveras les détails sur les versions actuelles et leur calendrier de maintenance dans [la documentation officielle de PHP](https://www.php.net/supported-versions.php).

## Installe PHP

La plupart des gestionnaires de paquets pour Linux / macOS fournissent des paquets précompilés.
PHP peut être téléchargé et compilé depuis les sources, disponibles sur [php.net/downloads.php](https://php.net/downloads.php) ou [windows.php.net/download](https://windows.php.net/download).

~~~~exercism/note
Un serveur web comme nginx ou le serveur HTTP Apache n'est pas nécessaire pour faire les exercices.
~~~~

### Linux

Les différentes distributions utilisent des méthodes différentes.
Tu devrais pouvoir exécuter

```shell
yum install php
```

ou

```shell
apt-get install php
```

selon ton gestionnaire de paquets.

Pour plus d'informations, consulte le manuel PHP sur [l'installation sur les systèmes Unix](https://www.php.net/manual/en/install.unix.php).

### macOS

Bien que PHP soit souvent fourni avec macOS, il est souvent obsolète.
Nous te recommandons d'installer PHP avec [Homebrew](https://brew.sh/).
Tu peux installer Homebrew en suivant les instructions [sur sa page d'accueil](https://brew.sh/#install).

Pour vérifier son installation, essaie la commande suivante, qui devrait afficher Homebrew `4.5.x` au moment de la rédaction.

```shell
brew --version 
```

Installe PHP avec Homebrew

```shell
brew install php@8.4
```

Cela devrait afficher la version de PHP désormais installée, au minimum la version `8.2.0`.

```shell
php -v
```

Pour plus d'informations, consulte le manuel sur [l'installation sur macOS](https://www.php.net/manual/en/install.macosx.php).

### Windows

Les binaires officiels de PHP pour Windows peuvent être téléchargés depuis [windows.php.net/download](https://windows.php.net/download).

Il existe des piles précompilées, notamment [WAMP](https://www.wampserver.com/en/) (Windows, Apache, MySQL, PHP) et [XAMPP](https://www.apachefriends.org/de/index.html).

Pour plus d'informations, consulte le manuel sur [l'installation sur les systèmes Windows](https://www.php.net/manual/en/install.windows.php).

### Docker

Si tu préfères les solutions conteneurisées, tu peux télécharger [l'image officielle de PHP depuis Docker Hub](https://hub.docker.com/_/php).
Tu auras aussi besoin de [Docker](https://docs.docker.com/engine/install/).

### Autres

Si tu veux utiliser un autre système d'exploitation, consulte les instructions sur [php.net/manual/en/install](https://www.php.net/manual/en/install.php).

## Installe PHPUnit

PHPUnit 12 n'est pas encore pris en charge !
~~~~

### Via une archive PHP (PHAR)

La façon la plus simple d'utiliser PHPUnit pour les exercices Exercism est de télécharger une distribution empaquetée sous forme d'archive PHP (PHAR), ce qui est aussi la façon recommandée d'utiliser PHPUnit.
Range le PHAR là où tu as rangé la CLI `exercism` afin de pouvoir exécuter PHPUnit d'où que tu sois.

Tu peux télécharger une version des paquets PHPUnit sous forme d'archive PHP :

```shell
wget -O phpunit.phar https://phar.phpunit.de/phpunit-11.phar
```

Rends ensuite le fichier téléchargé exécutable :

```shell
chmod +x phpunit.phar
```

Puis déplace-le au même endroit que la CLI `exercism`, en nommant la commande `phpunit` :

```shell
mv phpunit.phar ~/bin/phpunit
```

Tu peux maintenant exécuter `phpunit` d'où que tu sois, comme expliqué dans [la documentation sur les tests du parcours PHP](https://exercism.org/docs/tracks/php/tests) :

```shell
phpunit --version
```

La sortie devrait ressembler à ceci :

```text
PHPUnit 11.5.45 by Sebastian Bergmann and contributors.
```

Tu peux aussi suivre les [instructions officielles d'installation de PHPUnit](https://docs.phpunit.de/en/11.5/installation.html#installing-phpunit) pour installer PHPUnit.

### Via Composer

La version 11 de PHPUnit peut aussi être installée via [Composer](https://getcomposer.org).

#### Installe Composer

Installe [Composer](https://getcomposer.org) en suivant les [instructions d'installation](https://getcomposer.org/doc/00-intro.md) du système d'exploitation de ton appareil. Nous te recommandons de l'installer globalement pour plus de facilité.

#### Ajoute PHPUnit comme outil global

Avec la commande suivante :

```shell
composer global require phpunit/phpunit ^11.5
```

Veille à bien installer la version 11.5 ou une version ultérieure.
