# Instructions

Deux violonistes répètent un duo. Chaque partie est un tableau qui contient le nombre de notes de chaque mesure, et les parties n'ont pas toujours la même longueur.

Les quatre tâches se déroulent dans la classe `DUET_PRACTICE`.

## 1. Combien de mesures jouent-ils ensemble ?

Ils jouent ensemble tant que les deux parties ont encore une mesure.

```sather
DUET_PRACTICE::bars_together(|4, 4, 8, 8|, |4, 4|)
-- => 2
```

## 2. Combien de mesures correspondent ?

Compte les mesures où les deux parties ont le même nombre de notes. Seules les mesures que les deux parties ont en commun peuvent correspondre.

```sather
DUET_PRACTICE::in_unison(|4, 4, 8|, |4, 2, 8|)
-- => 2
```

## 3. Qui est le plus occupé ?

Compte les mesures où la première partie a davantage de notes que la seconde.

```sather
DUET_PRACTICE::louder_bars(|4, 8, 2|, |4, 2, 8|)
-- => 1
```

## 4. Pondère les mesures

Les mesures suivantes sont plus difficiles, donc une mesure compte autant que sa position : la première mesure compte une fois, la deuxième deux fois, la troisième trois fois. Multiplie le nombre de notes de chaque mesure par son numéro, puis additionne le tout.

```sather
DUET_PRACTICE::weighted_total(|4, 4, 8|)
-- => 36
```

C'est-à-dire 1×4 + 2×4 + 3×8. Les mesures sont numérotées à partir de un, pas de zéro.
