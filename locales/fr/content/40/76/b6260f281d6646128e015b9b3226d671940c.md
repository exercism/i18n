# Tests

Avant d'essayer d'exécuter les tests, assure-toi que le dossier de l'exercice est correctement configuré en suivant les étapes d'installation, à savoir `corepack yarn install` et la configuration de l'Editor SDK.

Exécute les tests avec :

```bash
$ corepack yarn test
```

## Tests ignorés

Dans les suites de tests, tous les tests sauf le premier ont été ignorés.

Une fois qu'un test passe, tu peux activer le suivant en remplaçant `xit` par `it`.
Les tests peuvent aussi être regroupés avec `xdescribe`.
Active le groupe en le remplaçant par `describe`.
Enfin, certains exercices peuvent avoir des tests optionnels `it.skip`.
Supprime `.skip` pour exécuter le test optionnel.
