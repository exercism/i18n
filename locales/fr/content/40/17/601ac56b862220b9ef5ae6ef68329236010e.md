# À propos

Le type `Option` est une énumération fournie par la bibliothèque standard. Il est utile pour représenter une valeur qui peut ne pas exister.
Même si cela peut sembler proche de `null` ou `nil`, c'est en réalité quelque chose de très différent et de particulier.

`Option<T>` contient un autre type et possède deux variantes : `Some(T)` et `None`.

Par exemple, `Option<u32>` contient le type `u32`.

## Utilisation

### Utiliser le `T` contenu dans `Option<T>`

Il existe plusieurs idiomes courants pour utiliser la valeur qui pourrait être présente dans une `Option` :

- `if let Some(t) = optional { ... }`.

    L'idiome `if let` extrait la valeur d'une `Option<T>` et la lie à la variable `t`. Cela te permet de l'utiliser directement dans la portée de ce bloc.

- `match optional { Some(t) => {...}, None => {...}}`

    L'opérateur `match` te permet aussi de décomposer une `Option` et de traiter les cas `None` dans une seule instruction ou expression. C'est une alternative à une succession d'instructions `if` et `else`. Utiliser `match` peut améliorer la lisibilité de certaines portions de code.
- `optional.map(|t| ...)`
   `Option::map` met à jour une Option en place, éventuellement avec un nouveau type, à partir de la fonction fournie.

   **Remarque** : elle agit sur la valeur contenue si elle est présente. La liaison devient une `Option<U>`, où la _closure_ fournie est `FnOnce(T) -> U`.
- `optional.unwrap()`.
   Déballer une `Option<T>` extrait `T`, mais provoquera une panique si `T` n'est pas présent. C'est parfois commode.

   **Important** : déballer peut faciliter le développement à court terme ou dans du code de test, mais cela introduit un risque de paniques à l'exécution. Il faut l'éviter autant que possible.

- `optional.expect("Unexpected None found! Aborting program.)`.
   La méthode `expect` sur `Option<T>` est assez semblable à `unwrap()`, mais elle provoquera une panique avec le message fourni si la valeur est `None`.

## Exemples

Quand une valeur existe dans une `Option<u32>` :

```rust
let has_something: Option<u32> = Some(100);
assert_eq!(has_something.unwrap(), 100);
```

Quand une valeur *n'existe pas* dans une `Option<u32>` :

```rust
let has_nothing: Option<u32> = None;
assert_eq!(has_nothing, None);
```
