# Indices

## Général

- Il te faudra importer le [module Dict][dict-module].

## 1. Agrège les buts des joueurs

- Le plus simple est probablement de définir une fonction de mise à jour et d'utiliser `Dict.update` dans `updateGoalCountForPlayer`.

## 2. Supprime les joueurs non significatifs

- `Dict.filter` est le plus simple pour ça.

## 3. Réinitialise le compteur de buts d'un joueur

- `Dict.insert` est le plus simple pour ça.

## 4. Formate le nombre de buts d'un seul joueur

- `Dict.get`, `Maybe.map` et `Maybe.withDefault` sont utiles pour ça.

## 5. Formate le nombre de buts de tous les joueurs

- `Dict.toList`, `List.map` et `String.join` sont utiles pour ça. `sort` n'est pas nécessaire.

## 6. Combine les parties

- `Dict.merge` est le plus simple pour ça.

[dict-module]: https://package.elm-lang.org/packages/elm/core/latest/Dict
