# Introduction

Comme tous les types de données standard de Clojure sont immuables, le langage propose des *types de référence*, qui offrent une mutation contrôlée. Les plus simples et les plus utilisés d'entre eux sont appelés des _Atoms_.

Les _Atoms_ sont créés avec la fonction `atom`, qui prend une valeur initiale :

```clojure
(def players (atom ()))
```

La valeur actuelle de l'_Atom_ se déréférence avec `deref` ou avec le raccourci `@` :

```clojure
@players
;;=> ()
```

La valeur actuelle de l'_Atom_ `players` peut être modifiée avec `swap!`, qui met à jour la valeur en appliquant une fonction :

```clojure
(swap! players conj :player1)
;;=> (:player1)
```

La fonction `reset!` remplace la valeur d'un _Atom_ sans tenir compte de sa valeur actuelle :

```clojure
(reset! players ())
```
