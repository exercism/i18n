# Instructions

Dans cet exercice, tu vas travailler sur un planificateur de rendez-vous pour un salon de beauté à New York qui a ouvert le 15 septembre 2012.

Tu as quatre tâches, qui impliqueront toutes des dates de rendez-vous. Les dates et les heures utiliseront l'un des trois formats suivants :

- `"7/25/2019 13:45:00"`
- `"July 25, 2019 13:45:00"`
- `"Thursday, July 25, 2019 13:45:00:00"`

~~~~exercism/caution
Les tests définiront automatiquement la culture sur `en-US` : tu n'as pas à définir ou spécifier la culture toi-même.
~~~~

## 1. Analyse la date de rendez-vous

Implémente la fonction `schedule` qui peut analyser une représentation textuelle d'une date de rendez-vous pour la convertir au format `DateTime` correspondant :

```fsharp
schedule "7/25/2019 13:45:00"
// => DateTime(2019, 7, 25, 13, 45, 0)
```

## 2. Vérifie si un rendez-vous est déjà passé

Implémente la fonction `hasPassed` qui prend une date de rendez-vous et vérifie si le rendez-vous a eu lieu dans le passé :

```fsharp
hasPassed (DateTime(1999, 12, 31, 9, 0, 0))
// => true
```

## 3. Vérifie si le rendez-vous a lieu l'après-midi

Implémente la fonction `isAfternoonAppointment` qui prend une date de rendez-vous et vérifie si le rendez-vous a lieu l'après-midi (>= 12:00 et < 18:00) :

```fsharp
isAfternoonAppointment (DateTime(2019, 03, 29, 15, 0, 0))
// => true
```

## 4. Décris l'heure et la date du rendez-vous

Implémente la fonction `description` qui prend une date de rendez-vous et renvoie une description de cette date et de cette heure :

```fsharp
description (DateTime(2019, 03, 29, 15, 0, 0))
// => "You have an appointment on 3/29/2019 3:00:00 PM."
```

## 5. Renvoie la date anniversaire

Implémente la fonction `anniversaryDate` qui renvoie la date anniversaire de cette année, c'est-à-dire le 15 septembre :

```fsharp
anniversaryDate()
// => DateTime(2019, 9, 15, 0, 0, 0)
```
