# À propos

C est un langage à typage statique, ce qui signifie que tout possède un type à la compilation.
Choisir un nom pour une [variable][variable] et lui donner un type s'appelle déclarer une variable.

On déclare une variable en précisant explicitement son type.
Le nom d'une variable [doit respecter certaines règles][name-rules], comme commencer par une lettre ou par un tiret bas.
Certains noms ne peuvent pas être utilisés, car ils sont réservés [aux mots-clés][reserved-keywords] ou [à d'autres identificateurs][reserved-identifiers].

Définir ou mettre à jour une variable se fait par affectation.
Affecter une valeur définit cette variable.
La définition de la variable est aussi appelée initialisation.

```c
int foo;      // Declare an integer named var
foo = 10;     // Define the variable

int bar = 15; // Both can also be done in a single statement
```

La valeur d'une variable peut être affectée et mise à jour à l'aide de l'[opérateur d'affectation simple `=`][assignment-operator].
Une fois définie, le type d'une variable ne peut plus jamais changer.

```c
int foo = 10; // Assign initial value
foo = 25;     // Update to new value

foo = false;  // Compiler error when assigning value of a different type
```

C est un langage [impératif][imperative] et [procédural][procedural].
Tous les calculs sont effectués sous la forme d'une série d'[instructions][statements] qui font partie d'une [fonction][function] ou de plusieurs fonctions.

Chaque fonction peut prendre zéro ou plusieurs [paramètres][parameters].
Lorsqu'on définit une fonction, tous les paramètres ainsi que la valeur de retour doivent être typés explicitement.
Les valeurs sont renvoyées par les fonctions à l'aide du [mot-clé `return`][return-keyword].
Par défaut, les fonctions ont une [classe de stockage][storage class] externe, ce qui signifie qu'elles existent pendant toute la durée de vie du programme et peuvent être visibles à l'extérieur du fichier.
Pour éviter cela, on peut ajouter le mot-clé `static` afin de préciser une visibilité interne.

```c
static int add(int x, int y) {
  return x + y;
}
```

Dans l'exemple ci-dessus, les variables `x` et `y` ne peuvent être utilisées qu'à l'intérieur de la fonction, c'est-à-dire qu'elles ont une portée de fonction.
La [portée][scope] est l'idée que la valeur associée à un nom (d'un élément de programme) n'est accessible que dans la « zone » de code où elle est définie.
Les principales zones de code en C sont :

- fichier
- fonction
- bloc (comme dans les boucles et les autres constructions)

On appelle une fonction en précisant son nom et en passant des arguments pour chacun de ses paramètres.

```c
int sum = add(1, 2);
```

C prend en charge deux types de [commentaires][comments].
Les commentaires sur une seule ligne sont précédés de `//` (depuis C99) et les commentaires sur plusieurs lignes sont insérés entre `/*` et `*/`.
