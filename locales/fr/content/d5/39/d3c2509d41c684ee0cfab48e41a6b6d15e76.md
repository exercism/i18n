# Indices

## Général

- Lis la section sur les [entrées et sorties (IO)][getting-started-io] dans le guide de démarrage.
- Lis la section sur le [débogage avec `IO.inspect/2`][getting-started-debugging-io-inspect] dans le guide de démarrage.
- Lis la documentation du [module `IO`][module-io].

## 1. Souhaite la bienvenue au nouveau joueur

- Il existe une [fonction intégrée][io-puts] qui écrit une _string_ sur la sortie standard.

## 2. Demande le nom du personnage

- Il existe une [fonction intégrée][io-gets] qui lit une _string_ depuis la sortie standard. Elle peut aussi écrire une invite, donc pas besoin d'utiliser une fonction séparée pour écrire la question.
- Il existe une [fonction intégrée][string-trim] dans le module `String` qui peut supprimer les espaces au début et à la fin de l'entrée.

## 3. Demande la classe du personnage

- Il existe une [fonction intégrée][io-gets] qui lit une _string_ depuis la sortie standard. Elle peut aussi écrire une invite, donc pas besoin d'utiliser une fonction séparée pour écrire la question.
- Il existe une [fonction intégrée][string-trim] dans le module `String` qui peut supprimer les espaces au début et à la fin de l'entrée.

## 4. Demande le niveau du personnage

- Il existe une [fonction intégrée][io-gets] qui lit une _string_ depuis la sortie standard. Elle peut aussi écrire une invite, donc pas besoin d'utiliser une fonction séparée pour écrire la question.
- Il existe une [fonction intégrée][string-trim] dans le module `String` qui peut supprimer les espaces au début et à la fin de l'entrée.
- Il existe une [fonction intégrée][string-to-integer] dans le module `String` qui peut convertir une _string_ en entier.

## 5. Combine les étapes précédentes en une seule

- Réutilise les fonctions implémentées dans les étapes précédentes.
- Il existe une [fonction intégrée][io-inspect], utile pour le débogage, qui peut écrire sur la sortie standard bien plus que des _strings_. Cette fonction accepte des options, par exemple une _string_ qui sera écrite avant la valeur passée.
- La fonction et son option mentionnées ci-dessus ajouteront à ta place un deux-points et un espace à cette _string_.
