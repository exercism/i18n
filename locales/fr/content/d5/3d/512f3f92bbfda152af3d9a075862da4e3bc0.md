# Teste en ligne de commande

Exécute les tests avec :

```bash
scarb cairo-test
```

Tous les tests sauf le premier sont ignorés. Une fois que tu as fait passer le premier test, ouvre le fichier source des tests, qui se trouve dans le répertoire `tests`, retire l'attribut `#[ignore]` du test suivant, puis fais passer les tests à nouveau. Chaque test pris séparément est une fonction précédée de l'attribut `#[test]`. Continue ainsi jusqu'à ce que tu passes tous les tests.

Si tu veux exécuter _tous_ les tests sans modifier le fichier source des tests, utilise :

```bash
scarb cairo-test --include-ignored
```

Pour exécuter un test précis, qu'il soit ignoré ou non, par exemple `some_test`, tu peux utiliser :

```bash
scarb cairo-test -f some_test
```

Pour en savoir plus sur les tests Cairo, consulte la [documentation des tests][cairo-tests] en ligne.

[cairo-tests]: https://book.cairo-lang.org/ch10-01-how-to-write-tests.html
