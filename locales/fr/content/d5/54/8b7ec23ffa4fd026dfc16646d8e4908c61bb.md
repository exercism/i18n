# Instructions supplémentaires

## Astuces

Pour venir à bout de cet exercice, tu dois créer le type de données `Deque` et implémenter les fonctions suivantes :

- `mkDeque`
- `pop`
- `push`
- `unshift`
- `shift`

Tu trouveras déjà en place une déclaration de données factice et les signatures de types, mais c'est à toi de définir les fonctions et de créer un type de données, un `newtype` ou un synonyme de type qui ait du sens.
