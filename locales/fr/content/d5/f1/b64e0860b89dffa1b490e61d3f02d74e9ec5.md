# Introduction

La macro `use` permet d'étendre rapidement notre module avec les fonctionnalités fournies par un autre module. Lorsqu'on fait `use` d'un module, celui-ci peut injecter du code dans notre module : il peut par exemple définir des fonctions, faire un `import` ou un `alias` d'autres modules, ou encore définir des attributs de module.

Si tu as déjà regardé les fichiers de test de certains exercices Elixir ici sur Exercism, tu as sans doute remarqué qu'ils commencent tous par `use ExUnit.Case`. C'est cette seule ligne de code qui rend les macros `test` et `assert` disponibles dans le module de test.

```elixir
defmodule LasagnaTest do
  use ExUnit.Case

  test "expected minutes in oven" do
    assert Lasagna.expected_minutes_in_oven() === 40
  end
end
```

## La macro `__using__/1`

Ce qui se passe exactement lorsqu'on fait `use` d'un module est dicté par la macro `__using__/1` de ce module. Elle prend un argument, une liste de mots-clés contenant les options, et renvoie une [expression quotée][concept-ast]. Le code de cette expression quotée est inséré dans notre module au moment de l'appel à `use`.

```elixir
defmodule ExUnit.Case do
  defmacro __using__(opts) do
    # some real-life ExUnit code omitted here
    quote do
      import ExUnit.Assertions
      import ExUnit.Case, only: [describe: 2, test: 1, test: 2, test: 3]
    end
  end
end
```

Les options peuvent être passées comme second argument lors de l'appel à `use`, par exemple `use ExUnit.Case, async: true`. Lorsqu'elles ne sont pas données explicitement, elles valent par défaut une liste vide.

[concept-ast]: https://exercism.org/tracks/elixir/concepts/ast
