# Ajout aux instructions

## Format des entrées

Le paramètre `board`, qui représente le plateau de jeu, se présente sous la forme d'un tableau de _strings_.

```javascript
['  B  ', ' B B ', 'B W B', ' W W ', '  W  '];
```

Chaque caractère d'une _string_ représente une case.
Les valeurs valides pour une case sont :

- ` ` un espace correspondant à une case vide
- `B` une case appartenant au joueur noir
- `W` une case appartenant au joueur blanc

## Formats de sortie

La fonction `getTerritory` doit renvoyer un objet avec 2 propriétés :

- `owner` Le propriétaire du territoire (`NONE`, `BLACK` ou `WHITE`)
- `territory` Un tableau de coordonnées représentant chaque case du territoire.

```javascript
{
    owner: 'BLACK',
    territory: [
        [0, 0],
        [0, 1],
        [1, 0],
    ],
}
```

La fonction `getTerritories` doit renvoyer un objet avec 3 propriétés :

- `territoryBlack` Un tableau de coordonnées représentant les territoires appartenant au joueur `BLACK`
- `territoryWhite` Un tableau de coordonnées représentant les territoires appartenant au joueur `WHITE`
- `territoryNone` Un tableau de coordonnées représentant les territoires n'appartenant à aucun des deux joueurs

```javascript
{
    territoryBlack: [
        [0, 0],
        [0, 1],
    ],
    territoryWhite: [
        [3, 0],
        [3, 1],
    ],
    territoryNone: [],
}
```
