# Introduction

On peut utiliser une expression `if/elif/else` pour exécuter de la logique de façon conditionnelle. F# propose aussi une autre manière, plus puissante, d'exécuter de la logique de façon conditionnelle : le filtrage par motif. Avec le filtrage par motif, on peut tester une valeur par rapport à un ou plusieurs _motifs_. Un exemple de tel motif est le _motif constant_, qui compare une valeur à une constante (par exemple `1` ou `"hello"`).

En F#, le filtrage par motif s'effectue à l'aide du mot-clé `match` :

```fsharp
let describe number =
    match number with
    | 0 -> "Zero"
    | 1 -> "One"
```

Même si cela peut ressembler aux instructions `switch` d'autres langages, le filtrage par motif montre toute sa puissance lorsqu'on utilise également d'autres motifs. Un de ces motifs est le _motif variable_, qui permet de capturer une valeur :

```fsharp
match number with
| 0 -> "Zero"
| i -> sprintf "Non zero: %d" i
```

Dans certains cas, il se peut que tu veuilles ajouter une condition supplémentaire à un motif. C'est ce qu'on appelle une _garde_ (clause), que l'on ajoute avec le mot-clé `when` :

```fsharp
match number with
| 0 -> "Zero"
| i when i < 0 -> "Negative number"
```

Dans l'exemple ci-dessus, toutes les entrées possibles ne trouveront pas de motif correspondant. Le compilateur le détecte et émet un avertissement. C'est ce qu'on appelle la _vérification d'exhaustivité_. Pour faire disparaître cet avertissement, il faut traiter tous les cas. Pour cela, on peut utiliser le _motif joker_, un motif qui correspond à n'importe quelle valeur :

```fsharp
match number with
| i when i < 0 -> "Negative number"
| _ -> "Positive number"

// No compiler warning
```

Le filtrage par motif teste une valeur par rapport à chaque motif, de haut en bas, jusqu'à ce qu'il trouve un motif correspondant et exécute la logique associée à ce motif. L'ordre des motifs est important !
