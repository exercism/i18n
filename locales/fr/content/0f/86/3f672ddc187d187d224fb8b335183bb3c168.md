# Introduction

L'un des concepts clés que tu rencontreras en Cairo est le type `felt252`, aussi appelé **élément de corps**. Ce type représente des entiers compris dans un intervalle précis, défini par un grand nombre premier $P$. Dans cet exercice, tu travailleras exclusivement avec le type `felt252`, qui est un élément essentiel de la programmation en Cairo.

Le type `felt252` de Cairo est un type scalaire qui sert à représenter les entiers allant de 0 à $P - 1$, où $P$ est un grand nombre premier actuellement fixé à $( 2^{251} + 17 \cdot 2^{192} + 1 )$. Ce type garantit que toutes les opérations arithmétiques sont effectuées modulo $P$, ce qui le distingue des types entiers standards que l'on rencontre dans d'autres langages de programmation.

Cairo prend en charge les opérations arithmétiques de base sur les valeurs `felt252` :

- **Addition (`+`)** : ajoute deux valeurs `felt252`.
  Si le résultat *dépasse* $P$, il est réduit modulo $P$.
- **Soustraction (`-`)** : soustrait une valeur `felt252` d'une autre.
  Si le résultat est négatif, il est ajusté pour rester dans l'intervalle, en ajoutant un multiple de $P$.
- **Multiplication (`*`)** : multiplie deux valeurs `felt252`, le résultat étant calculé modulo $P$.
- **Division (`/`)** : divise une valeur `felt252` par une autre, en garantissant que le résultat vérifie l'équation $( \frac{x}{y} \cdot y = x \mod P)$.
