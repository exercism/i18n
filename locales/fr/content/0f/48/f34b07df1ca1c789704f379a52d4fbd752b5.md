# Installation

## Quel awk as-tu ?

Le parcours AWK d'Exercism utilise `gawk`, la version GNU d'AWK.
Tu l'as peut-être déjà installé ; pour le vérifier, exécute cette commande
```sh
awk --version
```

Si elle renvoie :

* quelque chose comme `GNU Awk 5.1.0 ...`
    - Tu as déjà GNU awk et tu peux continuer avec les exercices.

* quelque chose comme `awk version 20200816`
    - C'est `nawk`, aussi appelé BWK awk (d'après Brian Kernighan) ou « one true awk ».
    - C'est ce qui est fourni avec MacOS et les systèmes BSD.
    - Lis la suite ci-dessous pour les instructions d'installation.

* l'erreur `awk: not an option: --version`
    - Tu as probablement `mawk`.
    - Pour confirmer, exécute : `awk -W version`, qui peut renvoyer `mawk 1.3.4 20200120`.
    - mawk est une implémentation d'awk très bonne et très rapide, mais elle ne dispose pas de certaines fonctionnalités propres à gawk que nous utiliserons dans le parcours.
    - Lis la suite ci-dessous pour les instructions d'installation.

* l'erreur `awk: unrecognized option: version` suivie de `BusyBox v1.35.0 ...`
    - Tu utilises peut-être Alpine Linux.
    - Lis la suite ci-dessous pour les instructions d'installation.

* une erreur « command not found »
    - Alors soit ton PATH est mal configuré, soit tu n'as tout simplement pas awk d'installé.
    - Lis la suite ci-dessous pour les instructions d'installation.

### Linux

Cela dépend du gestionnaire de paquets de ta distribution. En général :
```sh
apt install gawk
yum install gawk
apk add gawk
# and so on
```
Tu devras peut-être utiliser `sudo` pour exécuter la commande appropriée.

### MacOS

[Homebrew][brew] est ton ami. Suis le lien pour l'installer, puis exécute :
```sh
brew install gawk
```

### Windows

Pour [WSL][wsl], consulte les instructions pour Linux ci-dessus.
Pour cygwin, installe le paquet `gawk`.

### Compile depuis les sources

Pour les plus courageux, les instructions sont [disponibles dans le manuel de `gawk`][build].
