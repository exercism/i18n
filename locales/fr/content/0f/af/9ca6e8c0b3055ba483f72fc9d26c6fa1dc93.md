# Indices

## 1. Affiche un badge pour un employé

- L'[interpolation de chaînes de caractères][string-interpolation] permet de créer des chaînes de description.
- Il existe une [méthode intégrée pour convertir une chaîne en majuscules][to-upper-case].

## 2. Affiche un badge pour un nouvel employé

- Il faut vérifier que l'identifiant est `null` avant de l'utiliser.
- Tu peux utiliser les [opérateurs d'égalité][equality-operators] pour comparer la valeur à `null`

## 3. Affiche un badge pour le propriétaire

- Il faut vérifier que le département est `null` avant de l'utiliser.
- Tu peux utiliser les [opérateurs d'égalité][equality-operators] pour comparer la valeur à `null`
