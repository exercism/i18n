# Introduction

Il existe deux types de nombres différents en Java :

- Entiers : nombres sans chiffres après le séparateur décimal (nombres entiers).
  Par exemple `-6`, `0`, `1`, `25`, `976` et `-500000`.
- Nombres à virgule flottante : nombres avec zéro ou plusieurs chiffres après le séparateur décimal.
  Par exemple `-20.4`, `0.1`, `2.72`, `16.984025` et `1024.0`.

Les deux types numériques les plus courants en Java sont `int` et `double`.
Un `int` est un entier de 32 bits et un `double` est un nombre à virgule flottante de 64 bits.

Les opérations arithmétiques se font avec les opérateurs arithmétiques standards.
On peut comparer les nombres avec les opérateurs de comparaison numériques standards (par exemple `5 > 4` et `4 <= 5`) ainsi qu'avec les opérateurs d'égalité (`==`) et d'inégalité (`!=`).

Java propose deux types de conversions numériques :

1. Les conversions implicites : aucune donnée n'est perdue et aucune syntaxe supplémentaire n'est nécessaire.
2. Les conversions explicites : des données peuvent être perdues et une syntaxe supplémentaire, sous la forme d'un _cast_, est nécessaire.

Comme un `int` a une précision moindre qu'un `double`, convertir un `int` en `double` est sûr, et il s'agit donc d'une conversion implicite.
En revanche, convertir un `double` en `int` peut entraîner une perte de données, ce qui nécessite une conversion explicite.
