# Introduction

Rappelle-toi qu'un programme `jq` est un _pipeline_ d'expressions.
**L'affectation de variable** suit cette règle : une _affectation de variable_ est une expression qui ressemble à ceci :

```jq
... | expr as $varname | ...
```

## Le filtre renvoie l'entrée

Comme l'_expression identité_ `.`, la sortie d'une _affectation de variable_ est la même que son entrée.
Définir la valeur de la variable est un effet de bord.

Exemple montrant que `.` après l'affectation est identique à l'entrée initiale :

```sh
$ jq -c -n '42 | (. * 2) as $double | [., $double]'
[42,84]
```

## Portée des variables

La portée de la variable est « lexicale » : la variable reste dans la portée pour le reste du pipeline.
Les variables définies dans des fonctions (on verra les fonctions plus tard) sont « locales » à la fonction.

## Noms de variables

Le nom de la variable doit commencer par `$`.
Le reste du nom est un **identifiant** : il commence par une lettre ou un tiret bas, suivi de lettres, de chiffres ou de tirets bas.

## Affectation par déstructuration

D'après le manuel :

> On peut déclarer plusieurs variables avec une seule expression `as` en fournissant un motif qui _correspond à la structure de l'entrée_ (c'est ce qu'on appelle la « déstructuration »).

Exemples :

```jq
[1, 2, 3] as [$a, $b, $c]
| [$a, $b, $c]     # => [1, 2, 3]
```

```jq
{"foo": "bar", "len": [10, 20]} as {foo: $f, len: [$h, $w]}
| [$f, $h, $w]     # => ["bar", 10, 20]
```

Faire correspondre le nom de la variable à la _clé de l'objet_ permet un raccourci :

```jq
{"x": 4, "y": 7} as {$x, $y}
| [$x, $y]         # => [4, 7]
```

```jq
{"foo": "bar", "len": [10, 20]} as {$foo, $len}
| [$foo, $len]     # => ["bar", [10, 20]]
```

## Constantes

Comme le montre l'exemple ci-dessus, les variables sont pratiques pour stocker des constantes.
Mieux vaut donner un nom aux constantes plutôt que de laisser des « nombres magiques » apparaître dans le code.

## Souvent, les variables ne sont pas nécessaires

Il est souvent plus lisible d'omettre les variables.

Prenons le calcul de la moyenne d'un tableau de nombres

```jq
[2, 4, 8, 7]
| add as $sum
| length as $len
| $sum / $len
```

par rapport à

```jq
[2, 4, 8, 7] | add / length
```

Cela met en évidence l'un des aspects les plus puissants de `jq` : l'entrée d'un filtre est fournie à _chaque_ sous-expression :

- le tableau d'entrée `[2,4,8,7]` est passé à `add` (qui additionne les nombres en appliquant l'opérateur `+` à tous les éléments)
- _en parallèle_, `[2,4,8,7]` est aussi passé à `length`
- quand ces sous-expressions ont terminé, leurs résultats sont alors divisés, ce qui renvoie la valeur moyenne des nombres du tableau d'entrée.
