# Tests

Pour exécuter les tests, lance la commande `v test .` depuis le répertoire de l'exercice.

Si tu veux voir tous les tests qui ont été exécutés ainsi que des statistiques de vitesse, utilise `v -stats test .`

Pour plus d'informations sur les tests en V, consulte [la documentation](https://github.com/vlang/v/blob/master/doc/docs.md#testing).
