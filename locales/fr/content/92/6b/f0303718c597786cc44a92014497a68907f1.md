# Indices

## 1. Vérifie qu'une commande est valide

- Utilise l'expression [test][regex-test] pour renvoyer un booléen.
- N'oublie pas qu'on peut utiliser l'argument [flags][flags] pour des fonctionnalités supplémentaires, comme l'insensibilité à la casse.

## 2. Supprime les emojis chiffrés

- Grâce au chiffrement commun à chaque emoji, on peut utiliser `[0-9]` pour rechercher n'importe quel chiffre après le mot `emoji`.
- Le caractère `+` correspond à un ou plusieurs éléments consécutifs.
- Utilise la méthode [gsub][regex-gsub] pour remplacer chaque emoji par une _string_ vide.

## 3. Vérifie qu'un numéro de téléphone est valide

- Cet [article][phone-validation] explique vraiment bien les différentes façons de valider un numéro de téléphone.
- Utilise le filtre `test` pour vérifier si le numéro de téléphone est valide ou non.
- Renvoie la réponse finale avec une expression `if-then-else`.

## 4. Récupère le lien du site web

- On vise les mots reliés par un ou plusieurs points `.`.
- On peut utiliser le filtre [match][regex-match] avec le flag `g`.
- Le filtre [scan][regex-scan] est peut-être plus simple à utiliser.

## 5. Salue l'utilisateur

- Utiliser des [groupes de capture nommés][named-capture] est pratique pour réutiliser le texte correspondant.
- Le filtre [capture][regex-capture] est bien pratique pour faire référence au groupe nommé.

## 6. Analyse CSV très simple

- Ici, on veut utiliser [split][regex-split] parce qu'on connaît le délimiteur.
- Le motif est « une virgule suivie de zéro ou plusieurs espaces ».
- On doit utiliser le filtre `split` **à 2 arguments** ; il n'y a pas de _flags_ à préciser.
