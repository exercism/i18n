# Instructions

Te revoilà au travail sur le système ORM (_Object Relationship Mapping_, la correspondance objet-relationnel) introduit dans [exercise:csharp/object-relational-mapping]().

Notre analyse de l'utilisation de l'ORM montre que 95 % des transactions sont exécutées depuis une seule méthode appelante, et il a été décidé qu'il serait plus pertinent de disposer d'une unique méthode ORM qui ouvre, écrit et valide une transaction.

La base de données expose les méthodes d'instance suivantes :

- `Database.BeginTransaction()` démarre une transaction sur la base de données.
- `Database.Write(string data)` écrit des données dans la base de données au sein de la transaction. Si elle reçoit des données invalides, une exception sera levée. Une tentative d'appeler cette méthode sans avoir appelé `BeginTransaction()` provoquera la levée d'une exception. En cas de succès, l'état interne de la base de données passe à `DataWritten`.
- `Database.EndTransaction()` valide la transaction auprès de la base de données. Elle peut lever une exception si elle ne parvient pas à clôturer la transaction ou si `Database.BeginTransaction()` n'a pas été appelée.
- Un appel à `Database.Dispose()` nettoie la base de données si une exception est levée pendant une transaction. Cela fait passer l'état de la base de données à `Closed`.

## 1. Écrire dans la base de données

Implémente la méthode `Orm.Write()` pour démarrer une transaction sur la base de données, écrire les données passées en argument et valider la transaction. Toutes les exceptions, y compris `InvalidOperationException`, doivent pouvoir remonter à l'appelant sans être journalisées ni faire l'objet de la moindre intervention.

```csharp
Database db = new Database();
Orm orm = new Orm(db);
orm.Write("good write");
// => database has an internal state of State.Closed
orm.Write("bad write");
// => an exception is thrown but database is left with an internal state of State.Closed
orm.Write("bad commit");
// => an exception is thrown but database is left with an internal state of State.Closed
```

## 2. Écrire dans la base de données et renvoyer à l'appelant une indication du succès de l'écriture

Plusieurs mois se sont écoulés depuis l'introduction de `Orm.Write()` et l'équipe est divisée. Beaucoup de développeurs aimeraient que l'_ORM_ gère les erreurs lorsque des exceptions sont levées et renvoie simplement à l'appelant une indication de succès.

Implémente la méthode `Orm.WriteSafely()` pour démarrer une transaction sur la base de données, écrire les données passées en argument et valider la transaction (comme ci-dessus). Elle doit renvoyer `true` si l'_écriture_ a réussi, sinon `false`. N'essaie pas de journaliser l'exception.

```csharp
Database db = new Database();
Orm orm = new Orm(db);
orm.WriteSafely("good write");
// => true
orm.WriteSafely("bad write");
// => false
orm.WriteSafely("bad commit");
// => false
```
