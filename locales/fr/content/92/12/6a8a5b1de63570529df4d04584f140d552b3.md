## Le squelette

`src/TreeBuilding.hs` contient déjà une solution fonctionnelle qui passe tous les tests.
Elle est lente et difficile à lire ; ta tâche consiste à l'améliorer sans casser les tests.

`buildTree` renvoie `Nothing` quand les enregistrements ne forment pas un arbre valide.

## Changer la représentation

Les tests n'utilisent jamais directement les constructeurs de `Tree`.
Ils construisent plutôt les arbres attendus avec la fonction

```haskell
node :: Int -> [Tree] -> Tree
```

où `node i children` est le nœud d'identifiant `i` avec les enfants donnés, dans l'ordre croissant des identifiants.

Cela signifie que tu es libre de changer la façon dont `Tree` est représenté, par exemple comme ceci

```haskell
import qualified Data.Tree as T

type Tree = T.Tree Int

node :: Int -> [Tree] -> Tree
node = T.Node
```

tant que `Tree` dispose toujours d'instances `Eq` et `Show` et que `node` garde le même sens.
Si tu utilises une bibliothèque comme `containers`, pense à l'ajouter aux `dependencies` dans `package.yaml`.
