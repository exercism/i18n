# Instructions

Dans cet exercice, tu dois traduire quelques règles du jeu classique Pac-Man en fonctions Gleam.

Tu as quatre règles à traduire, toutes liées aux états du jeu.

> Ne te préoccupe pas de la façon dont les arguments sont obtenus, concentre-toi simplement sur la combinaison des arguments pour renvoyer le résultat attendu.

## 1. Définis si Pac-Man mange un fantôme

Définis la fonction `eat_ghost` qui prend deux arguments (_si Pac-Man a une super pastille active_ et _si Pac-Man touche un fantôme_) et qui renvoie une valeur booléenne indiquant si Pac-Man est capable de manger le fantôme. La fonction doit renvoyer `True` uniquement si Pac-Man a une super pastille active et touche un fantôme.

```gleam
eat_ghost(False, True)
// -> False
```

## 2. Définis si Pac-Man marque des points

Définis la fonction `score` qui prend deux arguments (_si Pac-Man touche une super pastille_ et _si Pac-Man touche un point_) et qui renvoie une valeur booléenne indiquant si Pac-Man a marqué. La fonction doit renvoyer `True` si Pac-Man touche une super pastille ou un point.

```gleam
score(True, True)
// -> True
```

## 3. Définis si Pac-Man perd

Définis la fonction `lose` qui prend deux arguments (_si Pac-Man a une super pastille active_ et _si Pac-Man touche un fantôme_) et qui renvoie une valeur booléenne indiquant si Pac-Man perd. La fonction doit renvoyer `True` si Pac-Man touche un fantôme et n'a pas de super pastille active.

```gleam
lose(False, True)
// -> True
```

## 4. Définis si Pac-Man gagne

Définis la fonction `win` qui prend trois arguments (_si Pac-Man a mangé tous les points_, _si Pac-Man a une super pastille active_ et _si Pac-Man touche un fantôme_) et qui renvoie une valeur booléenne indiquant si Pac-Man gagne. La fonction doit renvoyer `True` si Pac-Man a mangé tous les points et n'a pas perdu d'après les arguments définis dans la partie 3.

```gleam
win(False, True, False)
// -> False
```
