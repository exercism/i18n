# Le type booléen

En Cairo, le type booléen est indispensable pour les opérations logiques et les instructions conditionnelles.
Un booléen en Cairo a la taille d'un `felt252`, ce qui garantit une utilisation efficace de l'espace tout en conservant la simplicité de la logique vrai/faux.

Le type booléen de Cairo s'écrit avec le mot-clé `bool`.
Cela permet de déclarer et de manipuler des variables booléennes dans le langage.
Par exemple, considérons l'exemple suivant :

```rust
fn main() {
    let t = true;
    let f: bool = false; // with explicit type annotation
}
```

Dans cet exemple, on déclare deux variables booléennes.
La variable `t` reçoit la valeur `true` et son type booléen est déclaré implicitement, tandis que la variable `f` est annotée explicitement avec le type `bool` et reçoit la valeur `false`.

Un point important à noter : lorsqu'on déclare une variable booléenne en Cairo, on doit obligatoirement utiliser les littéraux `true` ou `false` comme valeur.
Autrement dit, des littéraux entiers comme `0` ou `1` ne peuvent pas remplacer `false` ou `true`.
L'application stricte de cette règle garantit la sûreté du typage et évite d'éventuelles erreurs de logique dans le développement de contrats intelligents.

## Les opérateurs booléens en Cairo

- `||` (OU logique) : renvoie `true` si au moins un des opérandes vaut `true`.
- `&&` (ET logique) : renvoie `true` si les deux opérandes valent `true`.
- `!` (NON logique) : renvoie la valeur booléenne opposée à celle de l'opérande.

## Exemple de code

L'extrait de code suivant montre comment utiliser les types booléens en Cairo.
Il montre la déclaration de variables booléennes, l'affectation d'expressions booléennes et l'utilisation d'assertions pour vérifier que la logique booléenne est correcte :

```rust
fn main() {
    // Declaration of Boolean variables
    let t: bool = true;
    let f: bool = false;

    // Boolean expression evaluation
    let true_expr = 5 == 5; // true
    let false_expr = 7 == 5; // false

    // Using Boolean operators
    let or_expr = t || f; // true || false => true
    let and_expr = t && f; // true && false => false
    let not_expr = !f; // !false => true

    // Assertions to verify the correctness
    assert(t == true_expr, 'this should be true'); // t == true
    assert(f == false_expr, 'this should be false'); // f == false
    assert(or_expr == true, 'this should be true for OR'); // true
    assert(and_expr == false, 'this should be false for AND'); // false
    assert(not_expr == true, 'this should be true for NOT'); // true
}
```
