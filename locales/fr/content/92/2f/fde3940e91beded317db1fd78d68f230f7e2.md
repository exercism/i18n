# Instructions

Tu es au poste radio côtier, à l'écoute du trafic radio : les messages arrivent sur la ligne, tu les consignes et tu renvoies les réponses. Cinq petits mots suffisent pour assurer le travail d'un service.

Les tests te passent des entrées `<string-reader>` (le trafic entrant) et utilisent `<string-writer>` pour la sortie. Mais chaque mot ici fonctionne de la même façon avec un vrai `<file-reader>` ou une socket.

## 1. Écoute jusqu'au bout

Définis `hear-out` pour vider un flux d'entrée dans une seule _string_.

```factor
"all quiet on the channel" <string-reader> hear-out .
! => "all quiet on the channel"
```

## 2. Compte les messages

Définis `count-messages` pour lire chaque ligne d'un flux d'entrée et renvoyer combien il y en avait.

```factor
"alpha\nbravo\ncharlie\n" <string-reader> count-messages .
! => 3
```

## 3. Répète le dernier appel

Définis `echo-back` pour lire chaque ligne et renvoyer la **dernière en majuscules** : la réponse radio standard « tu as dit X ».

```factor
"alpha\nbravo\n" <string-reader> echo-back .
! => "BRAVO"
```

## 4. Diffuse un message

Définis `broadcast` pour écrire un message vers un flux d'écriture donné et vider le flux pour qu'il soit envoyé immédiatement. Ne renvoie rien.

```factor
[ "mayday" output-stream get broadcast ] with-string-writer .
! => "mayday"
```

## 5. Capture la sortie d'une _quotation_

Définis `capture` pour exécuter une _quotation_ avec un nouveau string-writer comme sortie ambiante, et renvoyer tout ce que la _quotation_ a imprimé. La _quotation_ ne prend aucun argument : elle écrit simplement dans le flux ambiant comme d'habitude.

```factor
[ "test broadcast" print ] capture .
! => "test broadcast\n"
```
