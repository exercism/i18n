# À propos

Les instances de structures et de classes possèdent chacune une valeur implicite nommée `self`, qui fait référence à l'instance elle-même. `self` a plusieurs usages, mais il sert le plus souvent à lever l'ambiguïté sur les noms des propriétés et des méthodes de la structure ou de la classe lorsqu'une confusion est possible.

```swift
struct MySelf {
  var x = 0

  mutating func move(x: Int) {
    // here if we just say x = x it is unclear if we mean
    // the property x or the method parameter x, so we use
    // self for clarity
    self.x = x
  }
}
```

Les structures et les classes possèdent également une valeur `Self`, qui fait référence au type de la structure ou de la classe plutôt qu'à l'instance de celle-ci.
