# Instructions

Dans cet exercice, tu vas aider à gérer le quotidien d'une petite boulangerie grâce aux structures de contrôle de Cairo.

## 1. Calcule le total de la commande

Implémente `calculate_total`, qui calcule le coût d'une commande en fonction du type de pâtisserie et de sa quantité :

- Croissant : 3 pièces l'unité
- Muffin : 2 pièces l'unité
- Cookie : 1 pièce l'unité

```rust
calculate_total(Pastry::Croissant, 4) // Returns: 12 (4 * 3)
calculate_total(Pastry::Cookie, 10)   // Returns: 10 (10 * 1)
```

## 2. Applique les remises sur le volume

Implémente `apply_discount`, qui applique des remises en fonction du total de la commande.
Applique la remise en pourcentage au total, puis arrondis à la pièce entière inférieure (floor).

- Commandes ≥ 20 pièces : remise de 10 %
- Commandes ≥ 10 pièces : remise de 5 %
- Commandes < 10 pièces : aucune remise

```rust
apply_discount(25) // Returns: 22
apply_discount(15) // Returns: 14
apply_discount(8)  // Returns: 8
```

## 3. Crée le planning de cuisson

Implémente `baking_schedule`, qui crée un planning de cuisson quotidien.
La boulangerie cuit par lots de 5 commandes par heure :

```rust
baking_schedule(18) // Returns: [5, 5, 5, 3] (3 full batches + 3 remaining)
baking_schedule(10) // Returns: [5, 5] (2 full batches)
baking_schedule(3)  // Returns: [3] (1 partial batch)
```

Utilise les structures de contrôle adaptées (`if`/`else`, `loop`) pour résoudre efficacement chaque problème.
