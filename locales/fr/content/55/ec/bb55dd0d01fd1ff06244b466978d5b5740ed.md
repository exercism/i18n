# Indices

## Général

- `disposable` se trouve dans `destructors` ; les génériques du protocole de flux se trouvent dans `io` ; `<string-reader>` (utilisé par les tests) se trouve dans `io.streams.string`.
- Une déclaration `TUPLE: x < y ...` fait hériter `x` des _slots_ de `y`. `disposable` ajoute un drapeau `disposed` et enregistre le tuple auprès du _framework_ des destructeurs lorsqu'il est construit via `new-disposable`.

## 1. Définis la bande

- Le constructeur : `tape new-disposable swap >>wire ;`. Le `swap` sert à ce que le fil se retrouve sous la bande fraîchement construite, pour que `>>wire` puisse le consommer.

## 2. Rejoins le mixin _input-stream_

- Une seule ligne au niveau supérieur, après la déclaration `TUPLE:`.

## 3. Lis un symbole Morse

- La forme la plus simple est une petite boucle : lis un octet, vérifie-le, renvoie-le s'il s'agit d'un symbole Morse ou de `f`, sinon lis le suivant.
- Un littéral de caractère s'écrit `CHAR: .`. L'espace s'écrit `CHAR: \s`.
- `member?` fonctionne sur un petit tableau : `B{ CHAR: . CHAR: - CHAR: \s } member?`.
- La structure de contrôle la plus simple : une boucle `while` qui lit jusqu'à obtenir un symbole Morse ou `f`, accompagnée d'un `dup` final pour transmettre le résultat à l'appelant.

## 4. Délègue le type d'élément

- Une méthode d'une seule ligne : `wire>> stream-element-type`.

## 5. Nettoie

- Même forme : `wire>> dispose`.
- N'appelle pas `dispose*` toi-même : appelle `dispose` sur le fil. Le rôle du _framework_ est de s'assurer que ton `dispose*` ne s'exécute qu'une seule fois.
