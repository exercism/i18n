# Introduction

## Types imbriqués

Les types C# peuvent être définis dans la portée d'une classe ou d'un struct. Le type englobant fournit une sorte d'espace de noms. On accède au type via le type englobant, avec la syntaxe pointée.

```csharp
class Outer
{
    public interface IInner {}
    public enum EInner {}
    public class CInner {}
    public struct SInner {}
}

var outer = new Outer();
var inner = new Outer.CInner();
```

Tu peux définir des niveaux d'accès pour les types imbriqués.

Les membres privés du type externe sont accessibles aux membres du type imbriqué, mais pas l'inverse.
