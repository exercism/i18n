# Instructions

Le port de Palerme est un port très fréquenté, où de nombreux navires vont et viennent.
Depuis longtemps, il utilise un système manuel pour suivre les navires actuellement présents dans le port.
Ce système est très sujet aux erreurs, et le chef du port a décidé de le remplacer par un système informatisé.

Le chef du port t'a engagé pour mettre en place le nouveau système.
Le système doit gérer les identifiants des navires, mais aussi ceux des destinations.

## 1. Crée l'identifiant du port

La première chose à faire est de créer l'identifiant du port de Palerme.
L'identifiant est constitué des quatre premières lettres du nom du port, en majuscules.

Définis la constante `Port::IDENTIFIER` comme un symbole ayant la valeur `:PALE`.

```ruby
Port::IDENTIFIER 
# => :PALE
```

## 2. Récupère les identifiants d'autres ports

Le programme devra aussi gérer d'autres ports, il te faut donc également créer des identifiants pour eux.
Le port aimerait que le système soit automatisé et, comme les ports utilisent des conventions de nommage différentes, les identifiants doivent être générés à partir du nom du port.
L'identifiant est constitué des quatre premières lettres du nom du port, en majuscules.

Définis la méthode `Port.get_identifier` pour qu'elle prenne une _string_ en argument et renvoie l'identifiant de ce port sous forme de symbole.

```ruby
Port.get_identifier("Hamburg") 
# => :HAMB
```

## 3. Détermine à quel terminal un navire doit s'amarrer

Le port possède deux terminaux, et le système doit déterminer à quel terminal un navire doit s'amarrer.
Le terminal est déterminé par l'identifiant du navire.

L'identifiant est composé de 2 parties : la première est constituée de 3 lettres majuscules qui indiquent la cargaison transportée par le navire, puis 3 chiffres qui constituent l'identifiant unique du navire.

Si le navire transporte **OIL** ou **GAS**, il doit s'amarrer au terminal **A**.
Sinon, le navire doit s'amarrer au terminal **B**.

Définis la méthode `Port.get_terminal` pour qu'elle prenne en argument un symbole qui est l'identifiant du navire.
La méthode doit renvoyer le terminal sous forme de symbole.

```ruby
Port.get_terminal(:OIL123)
# => :A
```
