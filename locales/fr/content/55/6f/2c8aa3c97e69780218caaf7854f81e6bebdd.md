# Tableaux

Les tableaux en PHP sont des tableaux associatifs ordonnés.
Un tableau associatif est une structure de données qui associe une clé à une valeur.
Les tableaux sont polyvalents et peuvent être traités comme un tableau linéaire (comme en `C` ou en `Java`), une liste [vecteur], une table de hachage, un dictionnaire, une collection, une pile ou une file.

Une clé est facultative, mais si elle est fournie, elle doit être soit un `int`, soit une `string`.
Lorsqu'aucune clé n'est fournie, PHP utilise par défaut des clés entières dans l'ordre croissant, en commençant par `0`.

```php
$no_keys = ["my", "first", "array"];
$integer_keys = [0 => "my", 1 => "first", 2 => "array"];

$no_keys == $integer_keys // => equal returns true
$no_keys === $integer_keys // => strictly equal returns true
```

Un tableau peut stocker des valeurs de tous les types.
Chaque valeur peut avoir un type différent.

```php
$my_arr = [
  1,
  "second",
  new \DateTimeImmutable()
];
```

## Utilise les tableaux

Les tableaux peuvent être déclarés sous forme littérale (écrits dans le code, comme ci-dessus) ou créés et manipulés par des fonctions.

```php
$my_empty_arr = [];

// or
$my_empty_arr = array(); // => []

// or
$letters = mb_str_split("Hello"); // => ["H", "e", "l", "l", "o"] 
```

Accède aux valeurs, affecte-les et ajoute-les à l'aide de l'opérateur d'indice :

```php
$prime_numbers = [2, 3, 5, 6];

$prime_numbers[3] = 7; // replace 6 with 7

$prime_numbers[] = 11; // array now contains [2, 3, 5, 7, 11]
```

Parcours un tableau avec foreach :

```php
$names = ["Ani", "Jack", "Rami"]

// Iterate just the values
foreach ($names as $name) {
  echo $name;
}

// Iterate keys and values
foreach ($names as $index => $name) {
  echo "$index => $name";
}
```
