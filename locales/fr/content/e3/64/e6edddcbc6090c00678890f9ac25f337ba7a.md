# Indices

## Généralités

- Le [type atome est décrit ici][atom].

## 1. Détermine l'étiquette de log

- Tu peux utiliser la [forme spéciale `cond/1`][cond] pour gérer élégamment les différents codes de log.
- Tu peux utiliser les [opérateurs d'égalité][equality] pour comparer des entiers selon une égalité stricte de type.
- Il existe une [façon de spécifier une branche par défaut][cond] dans une expression `cond`, qui permet d'intercepter les cas non spécifiés.

## 2. Envoie une alerte

- Tu peux utiliser la [forme spéciale `cond/1`][cond] pour décider si une alerte doit être envoyée.
- Tu peux utiliser les [opérateurs d'égalité][equality] pour vérifier l'égalité d'atomes.

[equality]: https://hexdocs.pm/elixir/Kernel.html#==/2
[atom]: https://hexdocs.pm/elixir/basic-types.html#atoms
[cond]: https://hexdocs.pm/elixir/case-cond-and-if.html#cond
