# Introduction

## Protocoles

Les protocoles sont un mécanisme qui permet d'obtenir du polymorphisme en Elixir quand on veut qu'un comportement varie selon le type de données.

Les protocoles se définissent à l'aide de `defprotocol` et comportent un ou plusieurs en-têtes de fonction.

```elixir
defprotocol Reversible do
  def reverse(term)
end
```

Les protocoles s'implémentent à l'aide de `defimpl`.

```elixir
defimpl Reversible, for: List do
  def reverse(term) do
    Enum.reverse(term)
  end
end
```

Un protocole peut être implémenté pour n'importe quel type de données Elixir existant ou pour une structure.

Lorsqu'une fonction de protocole est appelée, l'implémentation appropriée est automatiquement choisie en fonction du type du premier argument.
