# Introduction

La *combinatoire* est la branche des mathématiques qui consiste à compter et à énumérer les façons de choisir ou d'arranger les éléments d'une collection. Le vocabulaire [`math.combinatorics`][math.combinatorics] de Factor répond aux deux questions de base :

- **Combinaisons** : des sélections où l'ordre n'a *pas* d'importance.
- **Permutations** : des arrangements où l'ordre *compte*.

Chaque question a un mot de *comptage* qui renvoie un nombre et un mot d'*énumération* qui renvoie les sélections elles-mêmes, ainsi qu'une variante _streaming_ `each-` qui appelle une _quotation_ pour chacune d'elles :

```
nCk              ( n k -- m )              ! count of k-combinations
nPk              ( n k -- m )              ! count of k-permutations
all-combinations ( seq k -- combinations )
all-permutations ( seq -- permutations )
each-combination ( seq k quot -- )
each-permutation ( seq quot -- )
```

```factor
USING: math.combinatorics prettyprint ;

5 2 nCk .                        ! => 10
{ 1 2 3 } 2 all-combinations .   ! => { { 1 2 } { 1 3 } { 2 3 } }
{ 1 2 } all-permutations .       ! => { { 1 2 } { 2 1 } }
```
