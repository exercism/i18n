# Boucles

Python propose deux constructions de boucle.
Les boucles `while` pour une itération _indéfinie_ (non comptée) et les boucles `for` pour une itération _définie_ (comptée).
Les mots-clés `break`, `continue` et `else` permettent de personnaliser le comportement d'une boucle.
`range()` et `enumerate()` facilitent le comptage et l'indexation dans les boucles.

## While

Les boucles [`while`][while statement] continuent de s'exécuter tant que l'`loop expression` ou le « test » s'évalue à `True` dans un [`boolean context`][truth value testing], et s'arrêtent lorsqu'il s'évalue à `False` :

```python
# Lists are considered "truthy" in a boolean context if they
# contain one or more values, and "falsy" if they are empty.

>>> placeholders = ["spam", "ham", "eggs", "green_spam", "green_ham", "green_eggs"]

>>> while placeholders:
...     print(placeholders.pop(0))
...
'spam'
'ham'
'eggs'
'green_spam'
'green_ham'
'green_eggs'
```

## For

La boucle [`for`][for statement] de base en Python se décrit mieux comme un _`for each`_ qui parcourt les valeurs de n'importe quel [objet itérable][iterable], et qui s'arrête quand l'appel à [`next()`][next built-in] ne renvoie plus de valeur (_ce qui lève une [`StopIteration`][stopiteration]_).

```python
>>> word_list = ["bird", "chicken", "barrel", "bongo"]

>>> for word in word_list:
...    if word.startswith("b"):
...        print(f"{word.title()} starts with a B.")
...    else:
...        print(f"{word.title()} doesn't start with a B.")
...
'Bird starts with a B.'
'Chicken doesn\'t start with a B.'
'Barrel starts with a B.'
'Bongo starts with a B.'
```


## L'objet séquence `range()`

Quand aucun `iterable` précis n'est fourni, la séquence spéciale [`range()`][range] sert de compteur de boucle.
`range()` prend un `int` qui marque le `stop` de la séquence, et peut prendre en option les paramètres `start` et `step`.
Si aucun nombre `start` n'est fourni, la séquence commence à 0.
Les objets `range()` sont **paresseux** (_les valeurs sont générées à la demande_), prennent en charge toutes les [opérations courantes sur les séquences][common sequence operations] et occupent une quantité de mémoire fixe, quelle que soit la longueur de la séquence demandée.
Étonnamment, `range()` [_n'est pas un itérateur_][range is not an iterator] et peut être utilisé dans de nombreux contextes sans boucle où une séquence de nombres est nécessaire.


```python
# Here we use range to produce some numbers, rather than creating a list of them in memory.
# The values will start with 1 and stop *before* 7.

>>> for number in range(1, 7):
...    if number % 2 == 0:
...       print(f"{number} is even.")
...    else:
...       print(f"{number} is odd.")
'1 is odd.'
'2 is even.'
'3 is odd.'
'4 is even.'
'5 is odd.'
'6 is even.'

# range() can also take a *step* parameter.
# Here we use range to produce only the "odd" numbers, starting with 3 and stopping *before* 15.

>>> for number in range(3, 15, 2):
...    if number % 2 == 0:
...       print(f"{number} is even.")
...    else:
...       print(f"{number} is odd.")
...
'3 is odd.'
'5 is odd.'
'7 is odd.'
'9 is odd.'
'11 is odd.'
'13 is odd.'
```


## Valeurs et indices avec `enumerate()`

Si tu as besoin à la fois des valeurs et des indices, la fonction intégrée [`enumerate(<iterable>)`][enumerate] renvoie un [`iterator`][iterator] sur des paires (`index`, `value`) :

```python
>>> word_list = ["bird", "chicken", "barrel", "apple"]

# *index* and *word* are the loop variables.
# Loop variables can be any valid python name.

>>> for index, word in enumerate(word_list):
...    if word.startswith("b"):
...        print(f"{word.title()} (at index {index}) starts with a B.")
...    else:
...        print(f"{word.title()} (at index {index}) doesn't start with a B.")
...
'Bird (at index 0) starts with a B.'
'Chicken (at index 1) doesn\'t start with a B.'
'Barrel (at index 2) starts with a B.'
'Apple (at index 3) doesn\'t start with a B.'


# The same method can be used as a "lookup" for pairing items between two lists.
# Of course, if the lengths or indexes don't line up, this doesn't work.

>>> word_list = ["cat", "chicken", "barrel", "apple", "spinach"]
>>> category_list = ["mammal", "bird", "thing", "fruit", "vegetable"]

>>> for index, word in enumerate(word_list):
...    print(f"{word.title()} is in category: {category_list[index]}.")
...
'Cat is in category: mammal.'
'Chicken is in category: bird.'
'Barrel is in category: thing.'
'Apple is in category: fruit.'
'Spinach is in category: vegetable.'
```

La fonction `enumerate(<iterable>)` accepte aussi un `start` pour commencer le comptage des indices à un autre nombre :


```python
# Here, the index count will start at 1.
>>> for position, word in enumerate(word_list, start=1):
...    if word.startswith("b"):
...        print(f"{word.title()} (at position {position}) starts with a B.")
...    else:
...        print(f"{word.title()} (at position {position}) doesn't start with a B.")
...
'Bird (at position 1) starts with a B.'
'Chicken (at position 2) doesn\'t start with a B.'
'Barrel (at position 3) starts with a B.'
'Apple (at position 4) doesn\'t start with a B.'
```


## Modifier le comportement d'une boucle

Le mot-clé [`continue`][continue statement] permet de sauter directement au cycle d'itération suivant :

```python
>>> word_list = ["bird", "chicken", "barrel", "bongo", "sliver", "apple", "bear"]
...
... # This will skip *bird*, at index 0
... for index, word in enumerate(word_list):
...     if index == 0:
...         continue
...     if word.startswith("b"):
...         print(f"{word.title()} (at index {index}) starts with a b.")
...
'Barrel (at index 2) starts with a b.'
'Bongo (at index 3) starts with a b.'
'Bear (at index 6) starts with a b.'
```


Le mot-clé [`break`][break statement] (_comme dans beaucoup de langages de la famille du C_) permet d'arrêter l'itération et de « sortir » de la `loop` la plus interne qui l'englobe :

```python
>>>  word_list = ["bird", "chicken", "barrel", "bongo", "sliver", "apple"]

>>> for index, word in enumerate(word_list):
...    if word.startswith("b"):
...        print(f"{word.title()} (at index {index}) starts with a B.")
...    elif word == "sliver":
...        break
...    else:
...        print(f"{word.title()} doesn't start with a B.")
... print("loop broken.")
...
'Bird (at index 0) starts with a B.'
'Chicken doesn\'t start with a B.'
'Barrel (at index 2) starts with a B.'
'Bongo (at index 3) starts with a B.'
'loop broken.'
```


La [clause `else`][loop else] d'une boucle est propre à Python et peut servir à des actions de « bilan » ou de « conclusion » lorsque l'itération est arrivée à son terme.
 Les instructions qui suivent le mot-clé `else` ne s'exécutent pas si l'itération se termine via `break` :


```python
>>> word_list = ["bird", "chicken", "barrel", "bongo", "sliver", "apple"]

# Using enumerate to get both an index and a value.

>>> for index, word in enumerate(word_list):
...    word = word.title()
...    if word.startswith("B"):
...        print(f"{word} (at index {index}) starts with a B.")
...
... # This executes once *StopIteration* is raised and 
... # There are no more items to iterate through.
... # Note the indentation, which lines up with the for keyword.
... else:
...    print(f"Found the above b-words, out of {len(word_list)} words in the word list.")
...
'Bird (at index 0) starts with a B.'
'Barrel (at index 2) starts with a B.'
'Bongo (at index 3) starts with a B.'
'Found the above b-words, out of 6 words in the word list.'


# Terminating a loop via *break* will bypass the loop *else* clause

>>> for index, word in enumerate(word_list):
...    word = word.title()
...    if word.startswith("B"):
...       print(f"{word} (at index {index}) starts with a B.")
...    if word.startswith("S"):
...        print("Found an S, stopping iteration.")
...        break

... # This statement does not run, because a *break* was triggered.
... else:
...    print(f"Found the above b-words, out of {len(word_list)} words in the word list.")
...
'Bird (at index 0) starts with a B.'
'Barrel (at index 2) starts with a B.'
'Bongo (at index 3) starts with a B.'
'Found an S, stopping iteration.'
```
