# À propos

Chaque processus Elixir possède son propre identifiant unique : un _PID_ (identifiant de processus).

- Les PID sont un type de données à part entière.
  - Tu peux vérifier si une variable est un PID avec [`is_pid/1`][kernel-is-pid]
- Tu peux obtenir le PID du processus courant avec `self()`.
- Les PID servent d'_adresses de boîte aux lettres_ : si tu as le PID d'un processus, tu peux lui envoyer un message.
- Les PID sont généralement créés indirectement, comme valeur de retour de fonctions qui créent de nouveaux processus, comme `spawn`.
  - Les PID ne devraient pas être créés directement par le programmeur. Si c'était nécessaire, Erlang dispose d'une fonction [`list_to_pid/1`][erlang-list-to-pid].

[kernel-is-pid]: https://hexdocs.pm/elixir/Kernel.html#is_pid/1
[erlang-list-to-pid]: https://www.erlang.org/doc/man/erlang.html#list_to_pid-1
