# Instructions

Il y a tout près une boutique d'électroménager qui s'appelle « Tech Palace ».
Le propriétaire de la boutique a récemment installé un grand écran pour y diffuser des messages publicitaires et pour afficher un salut spécial lorsque les clients scannent ce qu'ils appellent leurs cartes de fidélité à l'entrée.
L'écran est composé de nombreuses petites LED et peut afficher plusieurs lignes de texte.

Le propriétaire de la boutique a besoin de ton aide pour le code qui sert à générer le texte du nouvel écran.

## 1. Crée le message de bienvenue

Pour la plupart des clients qui scannent leur carte de fidélité, le propriétaire veut voir s'afficher `Welcome to the Tech Palace, ` suivi du nom du client en majuscules.

Implémente la fonction `welcome` qui prend le nom du client et renvoie le message voulu sous forme de _string_.

```julia-repl
julia> welcome("Judy")
"Welcome to the Tech Palace, JUDY"
```

## 2. Ajoute une bordure décorative

Pour les clients fidèles qui achètent beaucoup dans la boutique, le propriétaire veut rendre l'écran de bienvenue plus décoratif en ajoutant une ligne d'étoiles avant et après le message de bienvenue.
Il ne sait pas encore combien d'étoiles doivent figurer dans ces lignes, il veut donc que ce soit configurable.

Écris une fonction `add_border` qui prend un message de bienvenue et le nombre d'étoiles par ligne en arguments.
Elle doit renvoyer une _string_ composée de 3 lignes : une ligne avec le nombre d'étoiles voulu, puis le message de bienvenue tel qu'il a été passé en argument, puis une autre ligne d'étoiles.

```julia-repl
julia> add_border("Welcome!", 10)
"**********\nWelcome!\n**********"
```

## 3. Nettoie les anciens messages publicitaires

Avant d'installer ce nouvel écran, la boutique en avait un autre, similaire, qui ne pouvait afficher que des lignes statiques et non configurables.
Le propriétaire aimerait réutiliser certains des anciens messages publicitaires sur le nouvel écran.
Cependant, les données contiennent déjà des espaces indésirables qui servaient à aligner le texte sur plusieurs écrans empilés les uns sur les autres.
Ton rôle est de nettoyer ces messages pour qu'ils puissent être réutilisés.

Implémente une fonction `clean` qui prend l'ancien message publicitaire.
La fonction doit d'abord supprimer tous les espaces en début et en fin de texte, puis le renvoyer.

```julia-repl
julia> clean("    BUY NOW, SAVE 10%   ")
"BUY NOW, SAVE 10%"
```
