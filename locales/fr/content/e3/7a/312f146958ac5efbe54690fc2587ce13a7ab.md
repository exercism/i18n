## Messages d'exception

Il est parfois nécessaire de [lever une exception](https://docs.python.org/3/tutorial/errors.html#raising-exceptions). Quand on le fait, il faut toujours inclure un **message d'erreur explicite** pour indiquer l'origine de l'erreur. Cela rend le code plus lisible et facilite grandement le débogage. Si tu sais que la source de l'erreur sera d'un type précis, tu peux choisir de lever l'un des [types d'erreurs intégrés](https://docs.python.org/3/library/exceptions.html#base-classes), mais tu dois quand même y joindre un message explicite.

Cet exercice te demande d'utiliser [l'instruction `raise`](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement) pour « lever » une `ValueError` quand les coordonnées fournies ne sont pas valides. Les tests ne réussiront que si tu lèves l'`exception` avec `raise` et que tu y joins un message.

Pour lever une `ValueError` avec un message, écris ce message comme argument du type d'`exception` :

```python
# when the coordinates for the piece are invalid
raise ValueError('Invalid coordinate')
```
