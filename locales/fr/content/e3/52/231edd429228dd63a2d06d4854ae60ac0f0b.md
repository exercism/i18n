# Installation

## Version cible

Les tests de ce parcours utilisent l'image Docker `alpine:3.24.1` qui, en septembre 2026, utilise `sqlite3 version 3.53.4`.
Nous nous efforçons de faire en sorte que les outils fournis par ce parcours fonctionnent sur la dernière version LTS d'Ubuntu.
Même si tu disposes de versions plus récentes, garde en tête que certaines fonctionnalités peuvent ne pas fonctionner avec notre exécuteur de tests.
Tu peux comparer les fonctionnalités sur [l'historique des versions de SQLite][version-history].

## Windows

Pour installer SQLite sous Windows, suis ces étapes :

1. Télécharge les binaires Windows précompilés depuis la [page de téléchargement officielle][sqlite-download].
2. Décompresse le fichier ZIP téléchargé dans le répertoire de ton choix.
   Par exemple, `C:\Program Files\sqlite3`.
3. Ajoute le répertoire qui contient `sqlite3.exe` à la variable d'environnement PATH du système.
   La procédure diffère légèrement selon la version de Windows, mais l'information devrait être facile à trouver.
   Par exemple, les [instructions pour Windows 11][windows-11-install] et [Windows 10][windows-10-install].

## macOS

Sous macOS, SQLite est déjà installé.
Si tu as besoin d'une version plus récente, tu peux utiliser [Homebrew][homebrew] :

```bash
brew install sqlite
```

## Ubuntu / Debian

Sur Ubuntu et les systèmes basés sur Debian, tu peux installer SQLite avec apt :

```bash
sudo apt install sqlite3
```

## CentOS / Fedora / RHEL

Sur CentOS, Fedora et les systèmes basés sur Red Hat, tu peux installer SQLite avec yum ou dnf :

```bash
sudo yum install sqlite3
# OR
sudo dnf install sqlite3
```

## Arch Linux

Sous Arch Linux, tu peux installer SQLite avec pacman :

```bash
sudo pacman -S sqlite
```

## Autres méthodes d'installation et versions plus anciennes

Consulte la [page de téléchargement de SQLite][sqlite-download] pour plus d'informations et d'autres méthodes d'installation.
La section `Build Product Names and Info` contient le modèle de nommage des différentes versions de SQLite, tu devrais donc pouvoir chercher la version que tu veux avec ton moteur de recherche préféré.
