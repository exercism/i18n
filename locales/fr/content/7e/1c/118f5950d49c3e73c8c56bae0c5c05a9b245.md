# Instructions

Dans cet exercice, on va traiter des lignes de log.

Chaque ligne de log est une _string_ formatée comme ceci : `"[<LEVEL>]: <MESSAGE>"`.

Il existe trois niveaux de log : `INFO`, `WARNING` et `ERROR`.

Tu as trois tâches. Chacune prend une seule ligne de log de la pile.

## 1. Récupère le message d'une ligne de log

Définis `message` pour qu'il renvoie le message de la ligne de log. Les espaces en début et en fin de ligne doivent être supprimés.

```factor
"[ERROR]: Invalid operation" message .
! => "Invalid operation"

"[WARNING]:  Disk almost full\r\n" message .
! => "Disk almost full"
```

## 2. Récupère le niveau de log d'une ligne de log

Définis `log-level` pour qu'il renvoie le niveau de la ligne de log, en minuscules.

```factor
"[ERROR]: Invalid operation" log-level .
! => "error"
```

## 3. Reformate une ligne de log

Définis `reformat` pour placer le message en premier, suivi du niveau de log en minuscules entre parenthèses.

```factor
"[INFO]: Operation completed" reformat .
! => "Operation completed (info)"
```

----

***Note :*** Toutes les _strings_ de cet exercice sont en ASCII. Les exercices suivants aborderont la gestion des _strings_ prenant en charge Unicode.
