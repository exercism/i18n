# Instructions

Tu es un passionné d'observation des oiseaux qui note combien d'oiseaux ont visité ton jardin au cours des sept derniers jours.

Tu as six tâches, toutes portant sur le nombre d'oiseaux venus dans ton jardin.

## 1. Vérifie combien d'oiseaux sont venus aujourd'hui

Implémente la fonction `today()` pour qu'elle renvoie combien d'oiseaux ont visité ton jardin aujourd'hui. Les comptages d'oiseaux sont ordonnés par jour, le premier élément étant le comptage du jour le plus ancien et le dernier élément celui d'aujourd'hui.

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
today(birds_per_day)
# => 1
```

## 2. Incrémente le comptage d'aujourd'hui

Implémente la fonction `increment_todays_count()` pour incrémenter le comptage d'aujourd'hui :

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
increment_todays_count(birds_per_day)
# => c(2, 5, 0, 7, 4, 2)
```

## 3. Vérifie s'il y a eu un jour sans oiseau

Implémente la fonction `has_day_without_birds()` qui renvoie `TRUE` s'il y a eu un jour où aucun oiseau n'a visité le jardin ; sinon, elle renvoie `FALSE` :

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
has_day_without_birds(birds_per_day)
# => true
```

## 4. Calcule le nombre d'oiseaux venus pendant les premiers jours

Implémente la fonction `count_for_first_days()` qui renvoie le nombre d'oiseaux venus dans ton jardin depuis le début de la semaine, mais limite ce comptage au nombre de jours indiqué à partir du début de la semaine.

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
count_for_first_days(birds_per_day, 4)
# => 14
```

## 5. Calcule le nombre de jours chargés

Certains jours sont plus chargés que d'autres. Un jour chargé est un jour où cinq oiseaux ou plus sont venus dans ton jardin.
Implémente la fonction `busy_days()` pour qu'elle renvoie le nombre de jours chargés :

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
busy_days(birds_per_day)
# => 2
```

## 6. Calcule le total cumulé des visites d'oiseaux sur la dernière semaine

Tu te demandes combien d'oiseaux ont visité ton jardin en tout depuis le début de la semaine.
Calcule les totaux cumulés pour chaque jour.

```R
running_total(c(7, 6, 5, 4, 3, 2, 1))
#> [1]  7 13 18 22 25 27 28
```

## 7. Trie les noms des jours selon leur fréquentation

Tu soupçonnes que les visites d'oiseaux sont influencées par le trafic routier des environs, qui n'est pas le même le week-end et en semaine.

Trie les abréviations des jours par ordre _décroissant_ du nombre d'oiseaux venus.

```R
day_names <- c("Mon", "Tue", "Wed", "Thu", "Fri", "Sat", "Sun")
birds_per_day <- c(5, 2, 4, 6, 0, 9, 8)
busy_days_of_week(birds_per_day, day_names)
#> [1] "Sat" "Sun" "Thu" "Mon" "Wed" "Tue" "Fri"
```
