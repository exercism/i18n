# Instructions

Elyse, apprentie magicienne, poursuit son entraînement. On lui donne plusieurs piles de cartes avec lesquelles elle doit réaliser ses tours.
Pour simplifier un peu les choses, elle n'utilise que les cartes de 1 à 10.

Dans cet exercice, utilise les méthodes natives pour analyser le contenu d'un vecteur.

## 1. Détermine si une carte est présente

Elyse veut déterminer si une carte est présente dans la pile, autrement dit si la pile contient un nombre donné.

```R
card = 3;
does_stack_include_card(c(2, 3, 4, 5), card);
# => TRUE
```

## 2. Trouve la position d'une carte

Elyse veut connaître la position (l'indice) d'une carte dans la pile. 
Si la carte n'est pas dans la pile, renvoie `-1`.

```R
card = 2;
get_card_position(c(9, 7, 3, 2), card);
# => 4
```

## 3. Détermine si chaque carte est paire

Elyse veut savoir si chaque carte est paire, autrement dit si chaque nombre de la pile est un nombre pair.

```R
is_each_card_even(c(2, 4, 6, 7));
# => FALSE
```

## 4. Vérifie si la pile contient une carte de valeur impaire

Elyse veut savoir s'il y a un nombre impair dans la pile.

```R
does_stack_include_odd_card(c(3, 2, 6, 4, 8));
# => TRUE
```

## 5. Récupère la première carte impaire de la pile

Elyse veut connaître la valeur de la première carte impaire.  
Si aucune carte impaire n'est dans la pile, renvoie `-1`.

```R
get_first_odd_card(c(4, 2, 8, 7, 9));
# => 7
```

## 6. Détermine la position de la première carte paire

Elyse veut connaître la position de la première carte qui est paire.
Si aucune carte paire n'est dans la pile, renvoie `-1`.

```R
get_first_even_card_position(c(5, 2, 3, 1));
# => 2
```
