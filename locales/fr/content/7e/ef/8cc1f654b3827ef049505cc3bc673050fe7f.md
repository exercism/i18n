# Introduction

R ne dispose pas d'un type de données ensemble à part entière ; il utilise à la place diverses fonctions pour effectuer des opérations similaires sur des vecteurs.

L'opérateur `%in%` teste l'appartenance à un ensemble.

```R
2 %in% 1:10 # TRUE
12 %in% 1:10 # FALSE
```

Parmi les fonctions utiles, on trouve `unique` (pour supprimer les doublons), ainsi que `union()`, `intersect()`, `setdiff()` et `setequal()`, qui opèrent sur des paires d'ensembles.

```R
> set_1 <- c("a", "b", "c", "b", "a")
> unique(set_1) # deduplicate
[1] "a" "b" "c"

> set_2 <- c('a', "c", "d")
> union(set_1, set_2) # values in either set
[1] "a" "b" "c" "d"

> intersect(set_1, set_2) # values in both sets
[1] "a" "c"

> setdiff(set_1, set_2) # values in set_1 but not set_2
[1] "b"

> setdiff(set_2, set_1) # values in set_2 but not set_1
[1] "d"

setequal(set_1, c("c", "b", "a", "b")) # are elements the same after deduplication?
[1] TRUE
```

Dans chaque cas, `set_1` et `set_2` restent inchangés.
