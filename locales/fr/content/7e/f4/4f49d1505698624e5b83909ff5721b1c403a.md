# Introduction

Ruby est livré avec une bibliothèque standard (souvent abrégée en « stdlib »), un ensemble de classes permettant de travailler avec des choses telles que les dates, le json ou le réseau.
Elle fournit aussi quelques fonctionnalités pratiques pour rendre le code plus facile à utiliser.

`OpenStruct` fait partie de la bibliothèque standard et permet de créer facilement un objet à partir d'un `Hash`.
Plutôt que de devoir passer par les clés d'un `Hash`, `OpenStruct` permet d'utiliser des méthodes pour lire et modifier les valeurs.

Quand on utilise des classes de la bibliothèque standard, ou de n'importe quelle autre bibliothèque, il faut charger cette classe à l'aide de la méthode `require`.

```ruby
require 'ostruct'

attributes = { name: "Jeremy Walker", age: 21, location: "Nomadic" }
person = OpenStruct.new(attributes)

person.name
#=> Jeremy Walker

person.location
#=> Nomadic

# Update the age
person.age = 35

# It sets correctly
person.age
#=> 35
```

Un avantage supplémentaire : on peut profiter d'un raccourci avec la syntaxe de bloc.
Quand un bloc appelle une seule méthode, tu peux remplacer le bloc par `&:` suivi du nom de la méthode.
Par exemple, ces deux lignes sont synonymes :

```ruby
people.sum { |person| person.age }
people.sum(&:age)
```
