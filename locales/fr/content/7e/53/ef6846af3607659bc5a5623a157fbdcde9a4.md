# L'opérateur ternaire

Une condition ternaire est une façon plus courte d'écrire des instructions `if/else` simples.
Si une instruction `if/else` ne contient que deux branches, l'une pour le cas où la condition est vraie et l'autre pour le cas où elle est fausse, on peut la réécrire sous la forme d'une condition ternaire.

Les ternaires utilisent une combinaison des symboles `?` et `:` pour découper une condition :
```ruby
condition ? true_branch : false_branch
```

Le code à gauche du `?` est la condition, et le code à droite contient les deux branches possibles, séparées par le `:`.
Si la condition est _true_, c'est le code à _gauche_ du `:` qui est exécuté.
Si la condition est _false_, c'est le code à _droite_ du `:` qui est exécuté.

Par exemple :

```ruby
if traffic_light == 'green'
  cross_the_road
else
  wait
end
```

peut être réécrit ainsi :

```ruby
traffic_light == 'green' ? cross_the_road : wait
```
