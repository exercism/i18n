# Introduction aux boucles for-each

La [boucle for-each](https://docs.oracle.com/javase/tutorial/java/nutsandbolts/for.html) permet d'exécuter un bloc de code pour chaque élément d'une collection.
Certaines documentations (par exemple celle d'Oracle) les appellent des boucles `for` améliorées.

Voici la syntaxe générale :

```java
for(declaration: collection) {
    body;
}
```

La `declaration` déclare la variable qui sert à stocker les valeurs affectées depuis la collection.

La `collection` est un tableau ou une collection qui contient les valeurs qui seront affectées à la variable de boucle.

Le `body` contient les instructions qui seront exécutées une fois pour chaque valeur de la collection.

Par exemple :

```java
char[] vowels = {'a', 'e', 'i', 'o', 'u'};

for(char vowel: vowels) {
    System.out.println(vowel);
}
```

ce qui affiche :

```text
a
e
i
o
u
```

En général, une boucle `for-each` est préférable à une boucle `for` pour les raisons suivantes :

- Une boucle `for-each` est garantie de parcourir _toutes_ les valeurs.
- Une boucle `for-each` est plus _déclarative_, ce qui signifie que le code exprime _ce qu'il fait_ plutôt que _comment il le fait_.
- Une boucle `for-each` est infaillible, alors qu'avec une boucle `for`, il est facile de se tromper d'une unité (pense à utiliser `<` plutôt que `<=`).
- Une boucle `for-each` fonctionne avec tous les types de collections, y compris ceux qui ne permettent pas d'accéder aux éléments par leur indice (par exemple un `Set`).
