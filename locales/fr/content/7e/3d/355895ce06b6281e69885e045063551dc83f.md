# Instructions

Conçois une suite de tests pour un outil qui compte les lignes, les lettres et les caractères.

C'est un exercice spécial.
Au lieu de créer du code qui fonctionne avec une suite de tests existante, c'est toi qui définis la suite de tests.
Pour t'aider, plusieurs variantes du code à tester sont fournies ; ta suite de tests doit au moins être capable de détecter les problèmes (ou leur absence) qu'elles comportent.

Le système testé est censé être un système qui compte le nombre de lignes, de lettres et de caractères totaux dans les _strings_ fournies.
L'idée est que tu effectues l'opération « add string » un certain nombre de fois, en passant des _strings_, puis que tu appelles les fonctions « lines », « letters » et « characters » pour obtenir les totaux.
