# À propos des assertions de type

En Go, les interfaces peuvent introduire une ambiguïté sur le type sous-jacent.
En fait, l'interface vide peut contenir absolument n'importe quelle valeur concrète (y compris les types primitifs).
Une assertion de type permet d'extraire la valeur concrète sous-jacente d'une valeur d'interface, avec cette syntaxe : `interfaceVariable.(concreteType)`.

Si on affecte le résultat de cette instruction à une seule valeur, on affirme que la variable d'interface contient une valeur du type concret.
Par conséquent, un _panic_ peut survenir à l'exécution si la valeur d'interface n'a pas le type concret indiqué.
Par exemple :

```go
var input interface{} = 12
str := input.(string) // panic at runtime since input is not a string!
```

On peut vérifier si une valeur d'interface contient un type concret donné en utilisant les deux valeurs de retour de l'assertion de type : la valeur sous-jacente et un booléen qui indique si l'assertion a réussi.
Par exemple :

```go
str, ok := input.(string) // no panic if input is not a string
```

Si `input` contient une _string_, alors `str` sera la valeur sous-jacente et `ok` vaudra vrai.
Si `input` ne contient pas de _string_, alors `str` aura la valeur zéro du type `string` (c'est-à-dire `""`, la _string_ vide) et `ok` vaudra faux.
Aucun _panic_ ne se produit, dans un cas comme dans l'autre.

On rencontre souvent ce genre d'idiome :

```go
str, ok := input.(string)
if !ok {
    str = "a default value"
}
```

## Le _switch_ de type

Un **_switch_ de type** permet d'enchaîner plusieurs assertions de type.
Il a la même syntaxe qu'une assertion de type (`interfaceVariable.(concreteType)`), mais au lieu d'un `concreteType` précis, il utilise le mot-clé `type`.
Voici un exemple :

```go
var i interface{} = 12 // try: 12.3, true, int64(12), []int{}, map[string]int{}

switch v := i.(type) {
case int:
    fmt.Printf("the integer %d\n", v)
case string:
    fmt.Printf("the string %s\n", v)
default:
    fmt.Printf("type, %T, not handled explicitly: %#v\n", v, v)
}
```
