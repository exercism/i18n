# Introduction

## Tableaux et vecteurs

C++ propose différents conteneurs pour stocker de manière ordonnée des éléments de même type. On trouve `std::array` pour les conteneurs de taille fixe, et `std::vector`, dont la taille peut évoluer dynamiquement.

### Construction

Quand on déclare un tableau ou un vecteur, on doit préciser le type des éléments que le conteneur va contenir. Il faut aussi indiquer une taille pour les tableaux. Regarde ces exemples pour voir comment initialiser les deux types de conteneurs :

```cpp
#include <array>
#include <string>

// std::array<element_type, size> variable_name {list of elements}
std::array<std::string, 3> indie_rock {"yeah", "yeah", "yeah"};
// indie_rock contains the elements "yeah" three times
```

Les vecteurs ont généralement besoin de plus d'espace, car ils allouent de la mémoire pour pouvoir grandir. Tu n'as pas besoin d'en préciser la taille :

```cpp
#include <vector>

// std::vector<element_type> variable_name {list of elements}
std::vector<int> countdown {3, 2, 1};
// countdown contains the elements 3, 2 and 1
```

> Note : tu n'as pas encore besoin de connaître les mécanismes exacts qui se cachent derrière le concept de _template_, il aura son propre concept plus bas dans l'arborescence du programme.

### Accès aux éléments

Les vecteurs et les tableaux partagent les mêmes fonctions pour accéder à leurs éléments. Tu peux utiliser les fonctions membres `front` et `back` pour obtenir le premier et le dernier élément du conteneur. Il y a aussi `at` et l'opérateur `[]` pour accéder à des éléments précis.

```cpp
countdown[0];
// => 3
countdown.at(2);
// => 1
countdown[1] = 4;
// countdown now contains 3, 4 and 1
indie_rock.back() = "yeahs";
// indie_rock is now "yeah", "yeah", "yeahs"
```

> Note : si tu choisis une position qui n'est pas dans les limites de ton conteneur, `[]` peut entraîner un comportement indéfini.
> La fonction `at`, elle, lèverait une exception, ce qui pourrait te simplifier la vie sur le long terme.

### Modificateurs de vecteurs

Comme un `vector` n'a pas une taille fixe, il est possible d'y ajouter ou d'en retirer des éléments. Deux fonctions courantes pour cela sont `emplace_back` et `pop_back`.

```cpp
std::vector<std::string> witches {"Holly", "Alyssa", "Shannen"};
witches.pop_back();
// Shannen is no longer with the witches
witches.emplace_back("Rose");
// Rose has joined the team
```

### Capacité

Tu peux vérifier si un conteneur est vide avec la fonction membre `empty`. Si tu veux connaître le nombre d'éléments, tu peux utiliser `size`.
