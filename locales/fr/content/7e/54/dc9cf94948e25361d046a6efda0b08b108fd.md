# Introduction

En JavaScript, les _template strings_ permettent d'intégrer des expressions dans des chaînes de caractères, ce qu'on appelle aussi l'interpolation de chaînes.
Cette fonctionnalité étend les fonctionnalités de l'objet global `String` intégré.

Tu peux créer des _template strings_ en JavaScript en entourant le texte d'accents graves.
Celles-ci permettent non seulement d'inclure des retours à la ligne et d'autres caractères spéciaux dans le texte, mais aussi d'y intégrer des variables et d'autres expressions.

```javascript
const num1 = 1;
const num2 = 2;

`Adding ${num1} and ${num2} gives ${num1 + num2}.`;
// => Adding 1 and 2 gives 3.
```

Dans l'exemple ci-dessus, les accents graves (<code>\`\`</code>) servent à représenter une _template string_. Le `${...}` est l'espace réservé utilisé pour la substitution.
Tout type qui n'est pas une _string_ est converti _implicitement_ en _string_.
Ce sujet est abordé dans le concept [conversion de types][type-conversion-concept].
Tous les types d'expressions peuvent être utilisés avec les _template strings_.

```javascript
const track = 'JavaScript';

`This track on exercism.org is ${track.toUpperCase()}.`;
// => This track on exercism.org is JAVASCRIPT.
```

Lorsque tu as besoin de formater des _strings_ sur plusieurs lignes :

```javascript
`This is an example of using template
strings to accomplish multiple
lines`;
```

Grâce aux possibilités de substitution disponibles, tu peux aussi introduire de la logique dans le processus pour déterminer ce que la _string_ de sortie doit être.
Une façon de gérer cette logique consiste à utiliser l'[opérateur ternaire][ternary-operator].
On obtient ainsi la même fonctionnalité conditionnelle que `if/else`, dans un format légèrement différent.

Pour intégrer de la logique dans la syntaxe des _template strings_ :

```javascript
const grade = 95;

`You have ${grade > 90 ? 'passed' : 'failed'} the exam.`;
// => You have passed the exam.
```
