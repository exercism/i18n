# Instructions

Dans le jeu de cartes Spellbound Steel, on dispose d'un paquet de cartes comportant soit différents personnages tels que Warrior, Mage et Rogue, soit différents sorts tels que Fireball, Ice Storm et Lightning Bolt.
Une partie réunit entre deux et quatre joueurs, et le but est de vaincre les autres joueurs en jouant des cartes dont les niveaux de puissance sont plus élevés.

Tu veux prendre le dessus dans la partie en créant différentes méthodes pour calculer, trier et comparer les niveaux de puissance des cartes.

## 1. Trouve une carte dans le paquet

Tu ne sais pas avec certitude si une carte se trouve dans le paquet ou non.
Tu veux donc une méthode qui t'indique où trouver la première carte du paquet correspondant à celle que tu cherches.
Et si la carte n'est pas dans le paquet, tu veux le savoir aussi.

Implémente une méthode `SpellboundSteel.find_card?` qui prend un `Array` de cartes `String` ainsi qu'une carte `String` à trouver.
La méthode doit renvoyer l'indice de la première carte du paquet qui correspond à la carte recherchée.
Si la carte n'est pas dans le paquet, la méthode doit renvoyer `nil`.

```crystal
cards = ["Warrior", "Mage", "Rogue", "Fireball", "Ice Storm", "Lightning Bolt", "Mage"]
SpellboundSteel.find_card?(cards, "Mage")
# => 1
```

## 2. Mets une majuscule à tous les caractères

Pour rendre les cartes plus faciles à lire, tu veux mettre une majuscule à tous les caractères des noms de cartes.
Ainsi, tu verras facilement le nom des cartes quand tu les joueras.

Implémente une méthode `SpellboundSteel.capitalize_cards` qui prend un `Array` de cartes `String` et renvoie les cartes avec tous les caractères en majuscule.

```crystal
cards = ["warrior", "mage", "rogue", "fireball", "ice storm", "lightning bolt"]
SpellboundSteel.capitalize_cards(cards)
# => ["Warrior", "Mage", "Rogue", "Fireball", "Ice Storm", "Lightning Bolt"]
```

## 3. Calcule le niveau de puissance de toutes les cartes

Dans le jeu, il est important de calculer le niveau de puissance de toutes les cartes.
La puissance de toutes les cartes est indiquée dans le tableau suivant :

| Type de carte  | Niveau de puissance |
|----------------|---------------------|
| Warrior        | 10                  |
| Mage           | 20                  |
| Rogue          | 30                  |
| Fireball       | 15                  |
| Ice Storm      | 25                  |
| Lightning Bolt | 35                  |

Implémente une méthode `SpellboundSteel.calculate_power_level` qui prend un `Array` de cartes `String` et renvoie le niveau de puissance total de toutes les cartes.

```crystal
cards = ["Warrior", "Mage", "Rogue", "Fireball", "Ice Storm", "Lightning Bolt"]
SpellboundSteel.calculate_power_level(cards)
# => 135
```

## 4. Décode une carte

Dans le jeu, il existe ce qu'on appelle des cartes maudites.
Ce sont des cartes cachées qui ne peuvent être décodées que par le joueur qui les a jouées.
Pour décoder la carte, il faut retirer un caractère sur deux dans le nom de la carte.
Cela donne le nom de la carte.

Implémente une méthode `SpellboundSteel.decode_card` qui prend une carte `String` et renvoie la carte décodée.

```crystal
SpellboundSteel.decode_card("Wbalrrrlimoqr")
# => "Warrior"
```
