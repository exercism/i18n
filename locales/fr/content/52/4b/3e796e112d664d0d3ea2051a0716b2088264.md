# Instructions supplémentaires

# Entrées

Les entrées de cet exercice sont :

- `target` : une _string_ (par exemple `'stone'`) sera l'_argument de gauche_.
- `candidates` : un tableau de _strings_ mises en boîte (par exemple `'stone' ; 'tones' ; 'banana' ; 'tons' ; 'notes' ; 'Seton'`) sera l'_argument de droite_.

Voici comment on appellera ton verbe :

```j
  target     =. 'stone'
  candidates =. 'stone' ; 'tones' ; 'banana' ; 'tons' ; 'notes' ; 'Seton'
  
  subject findAnagrams candidates
```

## Sortie

Ton verbe doit renvoyer un _tableau_ de boîtes contenant les _strings_ qui sont des anagrammes de la cible. S'il n'y a aucune anagramme, le résultat doit être `empty`.
