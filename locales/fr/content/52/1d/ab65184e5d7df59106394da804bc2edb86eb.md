# Instructions

Dans cet exercice, tu vas écrire du code pour aider un freelance à communiquer avec un chef de projet.
Ta tâche consiste à fournir quelques utilitaires pour calculer rapidement les tarifs journalier et mensuel, éventuellement avec une remise donnée.

Nous commençons par établir quelques règles entre le freelance et le chef de projet :

- Le tarif journalier correspond à 8 fois le tarif horaire.
- Un mois compte 22 jours facturables.

Parfois, le freelance propose d'appliquer une remise sur son tarif journalier (par exemple pour ses clients les plus fidèles ou pour ses clients à but non lucratif).

Les remises sont modélisées par des nombres décimaux représentant des pourcentages, par exemple `25.0` (25 %).

## 1. Calculer le tarif journalier à partir d'un tarif horaire

Implémente une fonction appelée `dailyRateFrom` pour calculer le tarif journalier à partir d'un tarif horaire passé en paramètre.
Le contrat définit qu'une journée compte 8 heures facturables.

```swift
dailyRateFrom(hourlyRate: 60)
// Returns 480.0
```

Le tarif journalier renvoyé doit être un `Double`.

## 2. Calculer le tarif mensuel à partir d'un tarif horaire et d'une remise

Implémente une fonction `monthlyRateFrom` pour calculer le tarif mensuel remisé.
Elle prend deux paramètres : un tarif horaire et la remise en pourcentage.


```swift
monthlyRateFrom(hourlyRate: 77, withDiscount: 10.5)
// Returns 12129
```

Le tarif mensuel renvoyé doit être arrondi à l'entier supérieur (arrondi au plafond).

## 3. Calculer le nombre de jours travaillés complets à partir d'un budget, d'un tarif horaire et d'une remise

Implémente une fonction `workdaysIn` qui prend un budget, un tarif horaire et une remise, et calcule combien de journées de travail complètes cela couvre.

```swift
workdaysIn(budget: 20000, hourlyRate: 80, withDiscount: 11.0)
// Returns 35.0
```
Le nombre de jours renvoyé doit être arrondi à l'entier inférieur (arrondi au plancher).
