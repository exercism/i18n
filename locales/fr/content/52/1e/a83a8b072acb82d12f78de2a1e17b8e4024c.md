# Tests

Exécute les tests avec `exercism test` ou `eutest`. Par défaut, tous les tests sont exécutés.

## Ignore des tests

Une bonne façon de commencer est de commenter tous les tests sauf le premier dans `t_<exercise>.e`.

```euphoria
test_equal("no name given", "One for you, one for me.", two_fer())
-- test_equal("a name given", "One for Alice, one for me.", two_fer("Alice"))
-- test_equal("another name given", "One for Bob, one for me.", two_fer("Bob"))
```

Traite-les un par un, en décommentant le test suivant dès que le test en cours passe. Quand tous les tests passent, tu as terminé l'exercice.
