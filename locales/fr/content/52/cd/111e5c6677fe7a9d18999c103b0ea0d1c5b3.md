# Introduction

## Boucles

Les boucles servent à exécuter plusieurs fois une même logique.
Les deux types les plus courants sont la `while loop` (boucle indéfinie) et la `for loop` (boucle définie, ou comptée).
Il existe aussi la boucle `for each`, que l'on rencontrera dans un concept ultérieur.

### Syntaxe générale

La `for loop` se compose d'un en-tête et d'un bloc de code qui contient le corps de la boucle, entouré d'accolades.
L'en-tête se compose de 3 composants séparés par des points-virgules `;` : l'instruction d'initialisation, la condition et une autre expression.
Chacun d'eux peut être vide.

```cpp
for (init_statement; condition; expression) {
  some_statement;
}
```

- Le composant **init_statement** est du code qui ne s'exécute qu'une seule fois, avant le début de la boucle.
- Le composant **condition** doit être une expression qui s'évalue en un `boolean` et qui détermine quand la boucle doit s'arrêter.
  Le code à l'intérieur de la boucle s'exécutera tant que cette condition s'évalue à `true`.
  Dès que cette expression s'évalue à `false`, plus aucune itération de la boucle ne s'exécutera.
- Le composant **expression** est du code qui s'exécute à la fin de chaque itération.

La `while loop` exécute son corps tant que le contrôle de sa **condition** vaut `true`.
L'extrait de code ci-dessous montre comment transformer une boucle `for` en une `while loop`.

```cpp
init_statement;
while(condition) {
    some_statement;
    expression;
}
```

### Interlude : incréments et décréments

Lorsqu'on travaille avec des boucles, il est souvent nécessaire d'ajouter 1 ou de soustraire 1 à une variable compteur qui garde la trace des itérations.
C'est tellement courant que les actions d'incrémentation et de décrémentation ont des opérateurs spéciaux : `++` et `--`.

Ils existent sous une forme **préfixe** et une forme **postfixe**.
La forme préfixe modifie la variable avant son utilisation dans l'instruction, et la forme postfixe le fait après.
On veut probablement la version préfixe la plupart du temps.

```cpp
int a{3};
int b{--a};
// b is 2, a is now 2
int c{a++};
// c is 2, a is now 3
```

### Les boucles _for_ : un exemple

Le _composant d'initialisation_ initialise généralement une variable compteur, la _condition_ vérifie si la boucle doit continuer ou s'arrêter, et le _composant post_ incrémente généralement le compteur à la fin de chaque répétition.

```cpp
int sum{0};
for (int i{1}; i < 10; ++i) {
  sum += i;
}
```

Cette boucle additionne les nombres de `1` à `9` (`9` inclus).

### _break_ et _continue_

Dans le corps d'une boucle, tu peux utiliser le mot-clé `break` pour arrêter complètement l'exécution de la boucle :

```cpp
int sum{2};
while(true) {
    sum *= 2;
    if (sum > 1000)
        break;
}
// sum is now 1024
```

En revanche, le mot-clé `continue` arrête seulement l'exécution de l'itération en cours et passe à la suivante :

```cpp
int equal_sum{0};
for (int i{1}; i < 7; ++i) {
  if  (i%2 == 1) {
    continue;
  }
  equal_sum += i;
}
// equal_sum is now 12
```

~~~~exercism/note
Il est généralement plus facile de comprendre la logique d'une boucle lorsque l'utilisation de `break` et `continue` est minimisée, voire complètement évitée.
Ces deux mots-clés sautent certaines parties du code et rendent souvent le suivi plus difficile.
~~~~
