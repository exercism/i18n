# Les instructions conditionnelles

Ruby dispose de ce qu'on appelle des expressions de contrôle de flux : elles servent à contrôler la façon dont le programme s'exécute et prennent une valeur _truthy_ ou _falsey_.
Il existe des opérateurs qui permettent de créer des valeurs _truthy_ ou _falsey_, ce sont les [opérateurs de comparaison][comparison-operators].

Il existe deux expressions de contrôle principales qui déterminent quel code sera exécuté et quel code ne le sera pas, c'est-à-dire quelle branche donnée sera exécutée.

Ces deux expressions sont `if` et `unless`.

## Les opérateurs de comparaison

Les [opérateurs de comparaison][comparison-operators] servent à comparer des valeurs et renvoient une valeur `true` ou `false`.
Les opérateurs suivants exigent que les deux valeurs comparées soient du même type.
Si les valeurs ne sont pas du même type, le compilateur lèvera une erreur.
Voici une liste des opérateurs et un exemple de cas où ils renvoient `true` :

| Méthode | Description           | Exemple |
| ------- | --------------------- | ------- |
| <       | inférieur à           | 4 < 5   |
| <=      | inférieur ou égal à   | 4 <= 4  |
| >       | supérieur à           | 3 > 1   |
| >=      | supérieur ou égal à   | 2 >= 2  |

Contrairement aux opérateurs déjà mentionnés, les opérateurs d'égalité et de non-égalité permettent de comparer n'importe quel type de valeur.
L'opérateur `==` permet de vérifier si deux valeurs sont égales, ce qui inclut la vérification du type de la valeur.
L'opérateur `!=` fonctionne de la même manière, mais il renvoie `true` si les valeurs sont différentes et `false` si elles sont égales.
Voici une liste des opérateurs d'égalité et de non-égalité et un exemple de cas où ils renvoient `true` :

| Méthode | Description  | Exemple |
| ------- | ------------ | ------- |
| ==      | égal à       | 4 == 4  |
| !=      | différent de | 5 != 4  |

## L'instruction `if`

L'[instruction `if`][if] permet de vérifier si une condition donnée est _truthy_ ou _falsey_.
Si la condition est _truthy_, le code à l'intérieur de l'instruction `if` sera exécuté.
Une instruction `if` se termine par le mot-clé `end`.

```ruby
value = 1
if value == 1
  "1 is equal to 1"
end
# => "1 is equal to 1"

if value > 2
  "1 is greater than 2"
end
# => nil
```

## L'instruction `unless`

L'instruction `unless` fonctionne de manière très similaire à l'instruction `if`, mais elle exécute le code qu'elle contient si la condition est _falsey_.

```ruby
value = 1
unless value == 1
  "1 is not equal to 1"
end
# => nil

unless value > 2
  "1 is not greater than 2"
end
# => "1 is not greater than 2"
```

## L'instruction `else`

L'instruction `else` s'utilise conjointement avec l'instruction `if`.
L'instruction `else` est exécutée si la branche `if` ne l'est pas.

```ruby
value = 1
if value == 1
  "1 is equal to 1"
else
  "1 is not equal to 1"
end
# => "1 is equal to 1"

if value > 2
  "1 is greater than 2"
else
  "1 is not greater than 2"
end
# => "1 is not greater than 2"
```

## Les instructions `if` en cascade

L'instruction `elsif` s'utilise conjointement avec l'instruction `if`.
L'instruction `elsif` est exécutée si la branche `if` ne l'est pas et si la condition de l'instruction `elsif` est _truthy_.
Les instructions `elsif` peuvent être enchaînées et la première condition _truthy_ sera exécutée.
Une instruction `else` peut également se trouver à la fin de l'instruction `if` ; elle s'exécutera si aucune des conditions précédentes n'a été vraie.

```ruby
value = 1
if value == 0
  "1 is equal to 0"
elsif value > 2
  "1 is greater than 2"
else
  "1 is not equal to 0 and 1 is not greater than 2"
end
# => "1 is not equal to 0 and 1 is not greater than 2"
```
