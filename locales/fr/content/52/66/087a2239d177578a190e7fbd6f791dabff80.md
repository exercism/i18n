# Instructions

Tu fais du bénévolat au centre d'arts communautaire, où l'on installe une longue mosaïque de carreaux de céramique au-dessus de l'entrée principale. L'équipe de conception a organisé le travail **rangée par rangée** : chaque rangée est un tableau de couleurs de carreaux, et la mosaïque entière est un tableau de rangées.

Pendant que les bénévoles coupent, posent et déplacent des carreaux, toi, tu écris de petits mots réutilisables pour construire, combiner et retrouver des morceaux du motif.

## 1. Une bande d'un seul carreau

Définis `tile-strip` pour qu'elle prenne une couleur et renvoie une rangée d'un seul élément contenant uniquement cette couleur.

```factor
"sky-blue" tile-strip .
! => { "sky-blue" }
```

## 2. Une rangée de trois carreaux

Définis `row-of-three` pour qu'elle prenne trois couleurs sur la pile et renvoie une rangée de trois éléments.

```factor
"red" "white" "blue" row-of-three .
! => { "red" "white" "blue" }
```

## 3. Combine les rangées en une liste plate de carreaux

L'équipe de conception a besoin de vérifier les totaux de couleurs sur l'ensemble des rangées de la mosaïque. Définis `combine-rows` pour qu'elle prenne un tableau de rangées et renvoie une seule séquence contenant tous les carreaux dans l'ordre.

```factor
{ { "red" "white" } { "blue" "red" } } combine-rows .
! => { "red" "white" "blue" "red" }
```

## 4. Reflète une rangée

Pour les panneaux symétriques, l'équipe reflète une rangée avant de poser la copie sur le côté opposé. Définis `mirror-row` pour qu'elle renvoie une rangée dans l'ordre inverse.

```factor
{ "red" "white" "blue" } mirror-row .
! => { "blue" "white" "red" }
```

## 5. Où se trouve cette couleur dans la rangée ?

Définis `tile-position` pour qu'elle prenne une rangée et une couleur et renvoie l'indice (à partir de 0) du premier carreau ayant cette couleur dans la rangée. Si la couleur n'est pas présente, renvoie `f`.

```factor
{ "red" "white" "blue" } "white" tile-position .
! => 1

{ "red" "white" "blue" } "green" tile-position .
! => f
```

## 6. Cette rangée contient-elle la couleur ?

Définis `has-colour?` pour qu'elle prenne une rangée et une couleur et renvoie `t` si la couleur apparaît quelque part dans la rangée, sinon `f`.

```factor
{ "red" "white" "blue" } "white" has-colour? .
! => t

{ "red" "white" "blue" } "green" has-colour? .
! => f
```
