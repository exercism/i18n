# Introduction

Il existe essentiellement deux types de boucles :

1. Boucler jusqu'à ce qu'une condition soit remplie.
2. Parcourir les éléments d'une collection.

Les deux sont possibles en R, même si la première est sans doute la plus courante.

## `while` et `repeat`

Pour les problèmes ouverts, où le nombre de tours de boucle n'est pas connu à l'avance, R dispose de la boucle `while` avec une condition et de la boucle `repeat` sans condition (équivalente à `while (TRUE)`).

La forme de base est assez simple :

```R
while (condition) {
  do_something()
}
```

Dans ce cas, le programme continue de tourner dans la boucle jusqu'à ce que `condition` ne soit plus `TRUE`.

Deux façons de quitter la boucle de façon anticipée sont disponibles :

- Un `break` fait sortir de la boucle, l'exécution se poursuivant à la ligne suivante après l'accolade fermante `}` de la boucle.
- Un `return(x)` arrête l'exécution de la fonction courante et renvoie la valeur de retour `x` à l'appelant.

Avec ces options à disposition, il peut parfois être pratique de créer une boucle « infinie » avec `repeat { ... }`, puis de compter sur une condition d'arrêt trouvée dans le corps de la boucle pour déclencher un `break` ou un `return`.

Ces trois variantes sont équivalentes et se terminent toutes avec `x == 0.4444...`

```R
x <- 12
while (x > 1) {
  x <- x / 3
}

x <- 12
while (TRUE) {
  x <- x/3
  if (x <= 1) break
}

x <- 12
# no boolean clause 
repeat { 
  x <- x/3
  if (x <= 1) break
}
```

## Parcours un vecteur

C'est souvent inutile en R.
Comme on l'a vu dans d'autres concepts, de nombreuses fonctions opèrent sur des vecteurs entiers.

Cependant, les boucles explicites sont parfois inévitables.
C'est particulièrement vrai lorsque :

- Le corps de la boucle a des effets de bord, comme l'affichage ou les entrées/sorties de fichiers.
- La boucle continue jusqu'à ce qu'un critère soit atteint, après un nombre d'itérations imprévisible.

La condition de la boucle doit être entre parenthèses.
Comme pour le corps des fonctions, les accolades sont facultatives (mais souvent présentes) pour un corps de boucle tenant sur une seule ligne.

```R
words <- c("This", "is", "a", "loop")
for (w in words) { print(w) } # the braces are optional here
#> [1] "This"
#> [1] "is"
#> [1] "a"
#> [1] "loop"
```

Si l'itération en cours ne satisfait pas une certaine condition, il est possible de passer immédiatement à l'itération suivante avec un `next` :

```R
for (n in 1:10) {
    if (is_useless(n)) next
     
    # we decided this iteration could be useful
    do_something_slow(n)
}
```

Si tu as besoin de l'indice numérique, utilise `seq_along()`.

```R
v <- LETTERS[1:3]
v
#> [1] "A" "B" "C"

for (i in seq_along(v)) { print(sprintf("%s%i", v[i], i)) }
#> [1] "A1"
#> [1] "B2"
#> [1] "C3"
```

Utiliser `i in 1:length(v)` n'est _pas_ recommandé, car cela peut poser problème quand `length(v)` vaut zéro.
L'intervalle `1:0` est équivalent à `c(1, 0)`, donc le corps de la boucle s'exécutera et échouera probablement.
La fonction `seq_along()` est conçue pour gérer correctement ce cas.
