# Instructions

Tu travailles comme administrateur système pour une grande entreprise à Munich, en Allemagne. L'une de tes responsabilités est la gestion des comptes e-mail.

Tu entends des gens se plaindre de ne pas réussir à envoyer d'e-mails à M. Müller. Tu comprends vite que la plupart de l'entreprise utilise un vieux client de messagerie qui ne reconnaît pas `müller@firma.de` comme une adresse e-mail valide, à cause du caractère non ASCII.

Demander aux gens d'abandonner leur vieux client de messagerie préféré serait une bataille perdue d'avance, alors tu décides de créer des alias assainis pour tous les comptes e-mail.

## 1. Assainis les noms d'utilisateur existants en supprimant tout sauf les lettres minuscules

Implémente la fonction `sanitize/1`. Elle doit prendre un nom d'utilisateur sous forme de _charlist_ et renvoyer ce nom d'utilisateur privé de tous les caractères autres que les lettres minuscules.

```elixir
Username.sanitize(~c"schmidt1985")
# => ~c"schmidt"
```

## 2. Autorise les tirets bas

Étends la fonction `sanitize/1`. Elle ne doit pas retirer les tirets bas du nom d'utilisateur.

```elixir
Username.sanitize(~c"mark_fischer$$$")
# => ~c"mark_fischer"
```

## 3. Remplace les caractères allemands

L'alphabet allemand compte 4 caractères non ASCII, et chacun d'eux a un équivalent ASCII couramment reconnu.

| Caractère allemand | Équivalent ASCII |
| ------------------ | ---------------- |
| ä                  | ae               |
| ö                  | oe               |
| ü                  | ue               |
| ß                  | ss               |

Étends la fonction `sanitize/1`. Elle doit remplacer les caractères allemands conformément au tableau. Tu peux supposer sans risque que tous les noms d'utilisateur sont déjà en minuscules.

```elixir
Username.sanitize(~c"cäcilie_weiß")
# => ~c"caecilie_weiss"
```
