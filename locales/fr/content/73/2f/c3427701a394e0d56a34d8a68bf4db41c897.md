# À propos

Les [expressions `switch`][switch-expressions] se comportent de manière similaire aux [instructions `switch`][switch-statements] abordées dans [concept:csharp/switch-statements](). Elles prennent en charge une sorte de table de décision qui associe des conditions d'entrée à des actions ou à des valeurs.

Au cœur de l'expression `switch` se trouve le _pattern matching_. Dans l'exercice d'apprentissage, on faisait correspondre des valeurs à des _patterns_ `const`. Dans ce cas, les entrées du `switch` forment une _range expression_, que l'on fait correspondre à des valeurs const et aux valeurs utilisées par les _case guards_.

Les cas (aussi appelés _switch arms_) sont évalués dans l'ordre du texte et, dès qu'une correspondance est trouvée, le processus s'interrompt et la valeur associée est renvoyée.

Le cas `_`, qui est le dernier de la liste, est utile pour garantir que la correspondance est exhaustive et pour éviter d'éventuelles erreurs à l'exécution.

```csharp
double xx = 42d;

string interesting = xx switch
{
    0 => "I suppose zero is interesting",
    3.14 when DateTime.Now.Day == 14 && DateTime.Now.Month == 3 => "Mmm pie!",
    3.14 => "π",
    42 => "a bit of a cliché",
    1729 => "only if you are a pure mathematician",
    _ => "not interesting"
};

// => interesting == "a bit of a cliché"
```

Un « arm » du `switch` est sélectionné lorsque le _pattern_ correspond à la variable d'entrée et qu'au moins un _case guard_ est évalué à vrai.

Les expressions `switch` prennent aussi en charge les [_patterns_ de type][pattern-matching] et le _matching_ récursif.
