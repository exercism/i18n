# Introduction

## Les opérateurs de comparaison

Les [opérateurs de comparaison][comparison-operators] comparent deux valeurs du même type et renvoient une valeur `Bool` (`true` ou `false`).
Si tu essaies de comparer des valeurs de types différents, le compilateur produit une erreur.

Voici les opérateurs de comparaison standard en Swift :

| Opérateur | Description              | Exemple         |
| -------- | ------------------------ | --------------- |
| `==`     | Égal à                   | `1 == 1` (vrai) |
| `!=`     | Différent de             | `1 != 2` (vrai) |
| `<`      | Inférieur à              | `4 < 5`  (vrai) |
| `<=`     | Inférieur ou égal à      | `4 <= 4` (vrai) |
| `>`      | Supérieur à              | `3 > 1`  (vrai) |
| `>=`     | Supérieur ou égal à      | `2 >= 2` (vrai) |

## Les instructions `if` et `else`

Une [instruction conditionnelle][conditional-statement] exécute du code selon qu'une condition vaut `true` ou `false`.
L'instruction conditionnelle la plus courante est l'[instruction `if`][if], qui exécute un bloc de code seulement quand sa condition vaut `true`.
Pour écrire une instruction `if`, on utilise le mot-clé `if`, suivi de la condition et du bloc de code entre accolades :

```swift
let wheelCount = 4
if wheelCount == 4 {
    print("Your vehicle is a car")
}
// Prints "Your vehicle is a car"
```

Tu peux associer `if` à une clause `else` pour exécuter un autre code quand la condition vaut `false` :

```swift
let precipitationInMM = 0.5
if precipitationInMM > 0.5 {
    print("You will need an umbrella")
} else {
    print("You will not need an umbrella")
}
// Prints "You will not need an umbrella"
```

Pour tester plusieurs conditions à la suite, on enchaîne les instructions avec `else if`.
Une instruction `if` n'a pas besoin d'une branche `else`, mais tu peux en ajouter une pour gérer le cas où aucune des conditions ne correspond :

```swift
let favoriteFruit = "Apple"

if favoriteFruit == "Banana" {
    print("Your favorite fruit is a banana")
} else if favoriteFruit == "Orange" {
    print("Your favorite fruit is an orange")
} else if favoriteFruit == "Apple" {
    print("Your favorite fruit is an apple")
} else {
    print("Your favorite fruit is not a banana, orange, or apple")
}
// Prints "Your favorite fruit is an apple"
```

## L'expression `if`

En Swift moderne, les instructions `if` peuvent aussi servir d'expressions qui produisent une valeur.
Chaque branche s'évalue en une valeur, ce qui facilite l'affectation d'un résultat selon une condition :

```swift
let cpuBits = 32
let architecture = if cpuBits == 64 {
    "x86_64"
} else {
    "x86_32"
}

print(architecture)
// Prints "x86_32"
```

## L'opérateur ternaire

L'[opérateur ternaire][ternary-operator] est une forme abrégée d'une instruction `if`-`else`.
Il prend une expression booléenne et deux expressions séparées par deux-points.
La première expression est évaluée si l'expression booléenne est vraie, sinon c'est la seconde qui l'est.
Il s'écrit comme ceci : `Boolean-expression ? expression1 : expression2`.

L'opérateur ternaire est pratique quand on veut une forme abrégée d'une instruction `if`-`else` et que les expressions sont courtes :

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = showFahrenheit ? temperatureInCelsius * 9 / 5 + 32 : temperatureInCelsius
print(temperature)
// Prints 86
```

L'exemple ci-dessus est une version abrégée du code ci-dessous :

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = if showFahrenheit {
    temperatureInCelsius * 9 / 5 + 32
} else {
    temperatureInCelsius
}
```
