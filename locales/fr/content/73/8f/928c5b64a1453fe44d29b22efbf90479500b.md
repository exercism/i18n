# Instructions

Ta tâche consiste à calculer le score au Scrabble d'un mot en additionnant les valeurs de ses lettres.

Les lettres ont les valeurs suivantes :

| Lettre                       | Valeur |
| ---------------------------- | ------ |
| A, E, I, O, U, L, N, R, S, T | 1      |
| D, G                         | 2      |
| B, C, M, P                   | 3      |
| F, H, V, W, Y                | 4      |
| K                            | 5      |
| J, X                         | 8      |
| Q, Z                         | 10     |

Par exemple, le mot « cabbage » vaut 14 points :

- 3 points pour C
- 1 point pour A
- 3 points pour B

- 1 point pour A
- 2 points pour G
- 1 point pour E
