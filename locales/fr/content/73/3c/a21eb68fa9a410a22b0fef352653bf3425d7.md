# Tests

Tu peux utiliser l'éditeur en ligne sur le site d'Exercism pour résoudre les exercices.
Ou bien télécharger les exercices sur ton ordinateur, les résoudre en local, puis les soumettre à Exercism.
Le reste de ce document porte sur le travail en local.

## Exercism CLI

Tu auras besoin de l'outil en ligne de commande `exercism` pour télécharger et soumettre des exercices.
Consulte [la documentation de l'Exercism CLI][exercism-cli] pour savoir comment le télécharger et le configurer.

Pour télécharger un exercice, fais ceci :

```bash
exercism download --track 8th --exercise hello-world
```

Puis place-toi dans le répertoire de l'exercice :

```bash
cd /path/to/your/exercism_workspace/8th/hello-world
```

ou, si tu es sous Windows :

```cmd
cd \path\to\your\exercism_workspace\8th\hello-world
```

À noter que tu peux obtenir ton espace de travail exercism avec la commande `exercism configure`.

## Tester en local

Pour lancer les tests d'un exercice, tu dois te trouver dans le bon répertoire d'exercice.
Lance ensuite les tests avec cette commande :

```bash
8th -f test.8th
```

## Tests ignorés

Résoudre un exercice, c'est faire passer tous ses tests.
Par défaut, un seul test (le premier) est exécuté quand tu lances les tests.
C'est intentionnel : cela te permet de te concentrer sur ce seul test pour le faire passer.
Une fois qu'il passe, tu peux activer le test suivant en déplaçant la ligne `SKIP-REST-OF-TESTS` juste en dessous.

### Passer outre les tests ignorés

Pour lancer tous les tests, y compris ceux qui suivent le mot `SKIP-REST-OF-TESTS`, tu peux définir la variable d'environnement `RUN_ALL_TESTS` sur la valeur `true`. 
Une façon de la définir juste le temps de lancer les tests est (macOS et Linux) :

```bash
RUN_ALL_TESTS=true 8th -f test.8th
```

## Soumettre ta solution

Pour envoyer ta solution sur le site d'Exercism avec l'outil exercism :

```bash
exercism submit
```

À noter que tu peux envoyer ton code même s'il ne passe pas tous les tests.
C'est utile si tu es bloqué et que tu as besoin de l'aide d'un mentor.
