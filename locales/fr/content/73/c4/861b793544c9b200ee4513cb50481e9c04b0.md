# Introduction

Lorsque les types ne peuvent pas être convertis implicitement, il faut utiliser un opérateur de conversion explicite.
L'opérateur de conversion n'est rien d'autre que le type cible entre parenthèses, placé devant la valeur à convertir :

```csharp

int i = 7;
byte b = (byte)i; // Explicit cast from int to byte
```
