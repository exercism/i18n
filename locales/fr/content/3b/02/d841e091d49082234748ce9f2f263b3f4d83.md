# Indices

## Général

- Il y a trois [opérateurs booléens][boolean-operators] pour travailler avec des valeurs booléennes.
- Plusieurs opérateurs peuvent être combinés dans une même expression.

## 1. Vérifie si une attaque rapide peut être menée

- L'opérateur de négation logique (`!`) peut être placé devant une expression pour en inverser la valeur.

## 2. Vérifie si le groupe peut être espionné

- Les opérateurs booléens servent généralement à évaluer si deux expressions ou plus sont vraies ou non.

## 3. Vérifie si le prisonnier peut être signalé

- Les opérateurs booléens s'exécutent dans l'ordre de leur priorité (de la plus élevée à la plus faible) : `!`, `&&`, `||`.
- En général, il est conseillé d'utiliser des parenthèses pour clarifier ton intention.
- Pour plus de détails, consulte la section sur la priorité des opérateurs dans la [documentation officielle de Julia][operator-precedence].

## 4. Vérifie si l'option « Libérer le prisonnier » doit être affichée

- Les opérateurs booléens s'exécutent dans l'ordre de leur priorité (de la plus élevée à la plus faible) : `!`, `&&`, `||`.
- En général, il est conseillé d'utiliser des parenthèses pour clarifier ton intention.
