## Comment cet exercice est implémenté en Python : la récursivité

Cet exercice est conçu pour être résolu à l'aide de [concept:python/recursion](), plutôt qu'avec des boucles.
Une fonction récursive est une fonction qui s'appelle elle-même, ce qui est utile pour résoudre des problèmes qui se définissent en termes d'eux-mêmes.
Pour éviter une récursion infinie (ou plus précisément, pour éviter de faire déborder la pile), on utilise ce qu'on appelle un « cas de base ».
Quand le cas de base est atteint, une valeur non récursive est renvoyée, ce qui permet à l'appel de fonction précédent de se résoudre et de renvoyer sa valeur, et ainsi de suite, en se propageant le long de la pile jusqu'à ce que le premier appel de fonction renvoie la réponse.
On pourrait écrire une fonction récursive pour calculer 5! (c'est-à-dire 5 * 4 * 3 * 2 * 1) comme ceci :

````python
def factorial(number):
  if number <= 1:  # base case
    return 1

  return number * factorial(number - 1) # recursive case

print(factorial(5)) # returns 120
````

Enfin, il faut savoir que Python limite le nombre d'appels récursifs (1000 par défaut) et n'optimise pas la [récursion terminale][tail-recursion].

## Messages d'exception

Il est parfois nécessaire de [lever une exception][raising].
Quand tu le fais, tu dois toujours inclure un **message d'erreur explicite** pour indiquer l'origine de l'erreur.
Cela rend le code plus lisible et aide grandement au débogage.
Dans les cas où tu sais que l'origine de l'erreur sera d'un certain type, tu peux choisir de lever l'un des [types d'erreur intégrés][built-in-errors], mais tu dois quand même inclure un message explicite.

Cet exercice en particulier exige que tu utilises [l'instruction `raise`][raise-statement] pour « lancer » plusieurs `ValueErrors` si un nombre négatif est passé à la fonction `rows()`.
Les tests ne réussiront que si tu fais à la fois un `raise` de l'`exception` et que tu y ajoutes un message.

Pour lever une `ValueError` avec un message, écris le message comme argument du type `exception` :

```python
# if the rows function is passed a negative number.
raise ValueError("number of rows is negative")
```
