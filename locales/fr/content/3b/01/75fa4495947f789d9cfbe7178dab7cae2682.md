# Instructions

Daphne travaille sur un système qui exécute et enregistre les résultats de ses expériences. Une partie du code est devenue un peu verbeuse et répétitive, alors elle t'a demandé d'écrire quelques expressions `use` pour l'aider à le nettoyer.

## 1. Définis la fonction `with_retry`

Il arrive qu'une expérience échoue à cause d'une erreur ponctuelle ; dans ce cas, Daphne veut la relancer pour voir si elle fonctionne du deuxième coup.

Définis la fonction `with_retry`, qui prend en argument une fonction qui renvoie un résultat.

Si la fonction renvoie une valeur `Ok`, alors `with_retry` doit renvoyer cette valeur.

Si la fonction renvoie une valeur `Error`, alors `with_retry` doit rappeler la fonction et renvoyer le résultat de cet appel.

Daphne utilisera la fonction comme ceci :

```gleam
pub fn main() {
  use <- with_retry
  // Perform the experiment here
}
```

## 2. Définis la fonction `record_timing`

Daphne enregistre la durée d'exécution de chaque expérience en appelant une fonction de journalisation du temps avant et après chaque expérience.

Définis la fonction `record_timing`, qui prend deux arguments :
- Une fonction de journalisation du temps qui ne prend aucun argument et renvoie `Nil`.
- Une fonction d'expérience qui ne prend aucun argument et renvoie un résultat.

`record_timing` doit appeler la fonction de journalisation du temps, puis appeler la fonction d'expérience, puis appeler à nouveau la fonction de journalisation du temps, et enfin renvoyer le résultat de la fonction d'expérience.

Daphne utilisera la fonction comme ceci :

```gleam
pub fn main() {
  use <- record_timing(time_logger)
  // Perform the experiment here
}
```

## 3. Définis la fonction `run_experiment`

Une expérience se déroule en trois phases. La préparation, l'action et l'enregistrement. Les trois phases renvoient un résultat, et pour s'exécuter, chacune a besoin que la phase précédente ait renvoyé un résultat positif.

Définis la fonction `run_experiment`, qui prend quatre arguments :
- Le nom de l'expérience, sous forme de `String`.
- Une fonction de préparation qui ne prend aucun argument et renvoie un résultat.
- Une fonction d'action qui prend en argument la valeur `Ok` de la fonction de préparation et renvoie un résultat.
- Une fonction d'enregistrement qui prend en argument les valeurs `Ok` des fonctions de préparation et d'action et renvoie un résultat.

Si les trois fonctions réussissent, alors `run_experiment` doit renvoyer `Ok(#(experiment_name, recording_data))`.

Si l'une des fonctions renvoie une valeur `Error`, alors `run_experiment` doit renvoyer cette valeur.

Daphne utilisera la fonction comme ceci :

```gleam
pub fn main() {
  use setup_data, action_data <- run_experiment("Test 1", setup, action)
  // Record the results here
}
```
