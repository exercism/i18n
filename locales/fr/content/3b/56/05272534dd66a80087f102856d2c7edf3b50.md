# Mutabilité

Cairo, avec sa conception orientée blockchain, implémente par défaut un modèle de mémoire immuable.
Cela signifie qu'une fois qu'une valeur est écrite en mémoire, elle ne peut pas être écrasée, seulement lue.
Cairo propose cependant un mécanisme pour créer des variables mutables grâce au mot-clé `mut`.
Quand une variable est déclarée comme mutable et que sa valeur est modifiée, la nouvelle valeur est écrite dans une nouvelle cellule mémoire, et la variable est mise à jour pour pointer vers cette nouvelle cellule.
Ce mécanisme apporte de la souplesse tout en conservant les avantages de l'immuabilité.

Dans l'exemple ci-dessous, `x` est déclarée comme une variable immuable.
Si la valeur de `x` est modifiée, le compilateur lèvera une erreur.

```rust
let x = 5;
x = 2; // Error: cannot assign twice to immutable variable
```

On peut déclarer `x` comme une variable mutable à l'aide du mot-clé `mut`.
Cela permet de modifier la valeur de `x` après sa déclaration.

```rust
let mut x = 5;
x = 10;
```

Au final, c'est à toi de décider si tu utilises la mutabilité ou non, selon ce qui te semble le plus clair dans telle ou telle situation.

## Constantes

Comme les variables immuables, les constantes sont des valeurs liées à un nom et qui n'ont pas le droit de changer, mais il existe quelques différences entre les constantes et les variables :

- Les constantes se déclarent avec le mot-clé `const`
- On ne peut pas utiliser `mut` avec une constante
- Le type de la valeur doit toujours être indiqué explicitement
- Les constantes ne peuvent être déclarées que dans la portée globale
- Une constante ne peut être initialisée qu'avec une expression constante, et non avec le résultat d'un calcul effectué à l'exécution

```rust
struct AnyStruct {
    a: u256,
    b: u32
}

enum AnyEnum {
    A: felt252,
    B: (usize, u256)
}

const ONE_HOUR_IN_SECONDS: u32 = 3600;
const STRUCT_INSTANCE: AnyStruct = AnyStruct { a: 0, b: 1 };
const ENUM_INSTANCE: AnyEnum = AnyEnum::A('any enum');
const BOOL_FIXED_SIZE_ARRAY: [bool; 2] = [true, false];
```

Il est possible d'utiliser la macro `consteval_int!` pour créer une variable `const` qui est le résultat d'un calcul.

```rust
const ONE_HOUR_IN_SECONDS: u32 = consteval_int!(60 * 60);
```

## Masquage

Il est possible, et souvent idiomatique, de réutiliser un nom de variable au fil des transformations d'une valeur, en le redéclarant plusieurs fois avec `let`.
C'est ce qu'on appelle le _shadowing_.
Concrètement, la seconde variable masque la première : elle capte tous les usages du nom de variable jusqu'à ce qu'elle soit elle-même masquée ou que la portée se termine.

```rust
fn main() {
    let s: ByteArray = "my string";
    let s: ByteArray = s + " and a shadow";
    {
        let s: ByteArray = "a nested shadow";
        println!(s); // emits "a nested shadow"
    }
    println!(s); // emits "my string and a shadow"
}
```

Grâce au masquage, on peut même changer le type de la variable tout en réutilisant le même nom de variable.

```rust
fn main() {
    let x: u64 = 2;
    println!("x is u64, value: {}", x);               // prints "x is u64, value: 2"
    let x: ByteArray = format!("fizz");               // converts x to a ByteArray, type annotation is required
    println!("x is now ByteArray, value: \"{}\"", x); // prints 'x is now ByteArray, value: "fizz"'
}
```
