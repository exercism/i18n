# Ressources d'apprentissage recommandées

Exercism propose des exercices et des retours, mais il peut être difficile de s'y mettre quand on découvre l'ABAP pour la première fois. Ces ressources gratuites peuvent t'aider à démarrer :

* SAP Learning Journey [Learning the Basics of ABAP Programming](https://learning.sap.com/courses/learn-the-basics-of-abap-programming-on-sap-btp)
* [ABAP for Newbies Community](https://pages.community.sap.com/topics/abap/abap-for-newbies)
* [ABAP Language Documentation](https://help.sap.com/doc/abapdocu_latest_index_htm/latest/en-US/index.htm)
* [ABAP Starter](https://github.com/Keller-Michael/ABAP_starter)
* [ABAP Cheat Sheets](https://github.com/SAP-samples/abap-cheat-sheets)

Si tu débutes avec l'ABAP, on te recommande de suivre les unités suivantes du SAP Learning Journey :

- Getting Started
- ABAP Language Basics
- Local Classes 

Ensuite, tu seras prêt à résoudre les exercices ABAP sur Exercism.

Si tu arrives à des exercices plus complexes, on te suggère de parcourir également les unités suivantes :

- Structures
- Complex Internal Tables

Ces thèmes pourront t'aider à résoudre les exercices plus difficiles sur Exercism.
