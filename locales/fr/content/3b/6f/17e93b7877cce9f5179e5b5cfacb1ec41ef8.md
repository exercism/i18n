# Indices

## 1. Crée un nouveau tableau

- Tu trouveras comment définir un tableau vide sur [cette page][create-and-initialize].

## 2. Définis un tableau existant

- Tu trouveras comment définir et initialiser un tableau avec plusieurs éléments sur [cette page][create-and-initialize].

## 3. Ajoute un nouveau langage à un tableau

- Il existe un [opérateur intégré][cons] pour ajouter un élément au début d'un tableau.

## 4. Compte les langages dans le tableau

- Il existe une fonction dans le module `List` pour [compter les éléments d'un tableau][length].

## 5. Inverse le tableau

- Il existe une fonction dans le module `List` pour [inverser un tableau][reverse].

## 6. Vérifie si le tableau est intéressant

- Tu peux utiliser le filtrage par motif avec les motifs [cons][cons-pattern] et [list][list-pattern] pour faire correspondre des structures de tableau précises.
