# Introduction

## Les _strings_

Pour rappel, `jq` prend en charge les mêmes types de données que JSON.
JSON décrit les **chaînes de caractères** ainsi :

> Une chaîne de caractères est une suite de zéro ou plusieurs caractères Unicode, encadrée par des guillemets doubles et utilisant des échappements par barre oblique inverse.

### Séquences d'échappement

Dans une _string_, on utilise la barre oblique inverse pour insérer des caractères « spéciaux » :

- `\"` un guillemet double littéral,
- `\\` une barre oblique inverse littérale,
- les caractères d'espacement `\n`, `\t`, `\r`, `\f`, `\b`
- les caractères Unicode `\uAAAA`, où `A` est un chiffre hexadécimal

### Longueur d'une _string_

Pour trouver le nombre de caractères, utilise la fonction `length`.

```sh
$ jq -cn --args  '$ARGS.positional[] | length' "Hello world!" "❄🌡🤧🤒🏥🕰😀"
12
7
```

### Sous-chaînes

La notation **slice** permet d'extraire des sous-chaînes.
La syntaxe est `.[i:j]`.
La sous-chaîne renvoyée est de longueur `j - i` : elle contient les caractères depuis l'indice `i` (inclus) jusqu'à l'indice `j` (exclu).
Chacun des indices peut être négatif, auquel cas le comptage se fait à rebours depuis la fin de la _string_.
Chacun des indices peut être omis, auquel cas il désigne le début ou la fin de la _string_.
Les indices commencent à zéro.

```jq
"abcdefghij"[3:6]   # => "def"
"abcdefghij"[3:]    # => "defghij"
"abcdefghij"[:-2]   # => "abcdefgh"
```

### Concaténation

Utilise `+` pour concaténer des _strings_ :

```jq
"Hello" + " " + "world!"
# => "Hello world!"
```

Utilise `add` pour additionner un tableau de _strings_ :

```jq
["Hello", " ", "world!"] | add
# => "Hello world!"
```

### Découper et assembler

Pour découper une _string_, on utilise la fonction `split/1` ou l'opérateur `/` :

```jq
"Hello beautiful world!" | split(" ")   # => ["Hello", "beautiful", "world!"]
```

```jq
"Hello beautiful world!" / " "          # => ["Hello", "beautiful", "world!"]
```

L'inverse de `split/1` est `join/1`.

Il est souvent nécessaire de convertir une _string_ en tableau de caractères.
Pour cela, il y a deux façons de faire :

1. découper sur une chaîne vide

   ```jq
   "Hi friend 😀" / ""   # => ["H","i"," ","f","r","i","e","n","d"," ","😀"]
   ```

1. utiliser `explode` pour obtenir un tableau de _codepoints_

   ```jq
   "Hi friend 😀" | explode   # => [72,105,32,102,114,105,101,110,100,32,128512]
   ```

   `implode` est l'inverse de `explode`.

### Trouver l'indice d'une sous-chaîne

Utilise la fonction `index/1` ; l'indice commence à zéro.

```jq
"hello" | index("el")'   # => 1
```

Si la sous-chaîne n'est pas présente dans la _string_, le résultat est `null`

```jq
"hello" | index("elk")   # => null
```

### Interpolation de _strings_

Dans une _string_, la séquence `\(expression)` insère le _résultat_ de cette expression [dans la chaîne][interpolate] :

```jq
"The current datetime is \(now | strflocaltime("%c"))"   # => "The current datetime is Wed Nov 16 17:06:33 2022"
```

### Conversion de casse

Utilise les fonctions `ascii_downcase` et `ascii_upcase`.
