# À propos

L'un des aspects essentiels du travail avec les nombres en C# est la distinction entre les entiers (les nombres sans chiffre après le séparateur décimal) et les nombres à virgule flottante (les nombres avec zéro ou plusieurs chiffres après le séparateur décimal).

Les deux types numériques les plus couramment utilisés en C# sont `int` (un entier de 32 bits) et `double` (un nombre à virgule flottante de 64 bits).

```csharp
int i = 123;
double d = 54.29;
```

Les entiers comme les nombres à virgule flottante peuvent utiliser le caractère `_` comme _séparateur de chiffres_, ce qui peut être utile quand on définit de grands nombres :

```csharp
int largeInt = 1_000_000;
// => 1000000

double largeDouble = 9_876_543.21;
// => 9876543.21
```

Les opérations arithmétiques se font avec les [opérateurs arithmétiques][arithmetic-operators] standard (`+`, `-`, `*`, etc.). On peut comparer les nombres avec les [opérateurs de comparaison][comparison-operators] standard (`<`, `>=`, etc.), ainsi qu'avec l'[opérateur d'égalité][equality-operators] (`==`) et l'[opérateur d'inégalité][equality-operators] (`!=`).

```csharp
5 * 6;
// => 30

1.2 > 0.8
// => true

2 != 4
// => true
```

Quand on convertit un type numérique en un autre, il existe deux types de conversions numériques :

1. Les conversions implicites : aucune donnée n'est perdue et aucune syntaxe supplémentaire n'est nécessaire.
2. Les conversions explicites : des données peuvent être perdues et une syntaxe supplémentaire, sous la forme d'un _cast_, est nécessaire.

Comme un `int` est moins précis qu'un `double`, convertir un `int` en `double` est sûr, et il s'agit donc d'une conversion implicite. En revanche, convertir un `double` en `int` peut entraîner une perte de données, ce qui nécessite une conversion explicite.

```csharp
int i = 9;
double d = 2.66;

// Safe conversion, thus implicit conversion
double fromInt = i;

// Potentially unsafe conversion, thus explicit conversion
int fromDouble = (int)d;
```
