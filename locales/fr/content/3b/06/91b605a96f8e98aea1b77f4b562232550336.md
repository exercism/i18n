# L'instruction `case`

```sather
   case zone
   when 0 then return 0;
   when 1, 2 then return 550;
   else return 920;
   end;
```

## Comment se fait la comparaison

La valeur qui suit `case` est comparée à chaque valeur `when` avec `=`, de haut
en bas. La première correspondance est exécutée, et c'est la seule. Les autres
parties `when` sont ignorées, et l'exécution se poursuit après le `end`.

N'importe quel type qui prend en charge `=` peut être utilisé : `INT`, `CHAR`,
`STR`, `BOOL`.

## Le `else`

Un `case` sans correspondance et sans `else` lève une erreur fatale à
l'exécution. Écris toujours un `else`. Quand les cas restants ne devraient
vraiment pas se produire, dis-le à cet endroit plutôt que de l'omettre :

```sather
   else
      raise "unknown zone: " + zone;
   end;
```

`raise` viendra plus tard ; d'ici là, renvoyer une valeur par défaut raisonnable
fait l'affaire.

## Quand préférer `if`

`case` compare une seule valeur à des constantes. Tout le reste appelle `if` :

```sather
   -- ranges
   if age < 13 then ... elsif age < 16 then ... end;

   -- more than one value at a time
   if score >= 8 and sings then ... end;
```

Essayer de forcer un intervalle dans un `case` donne quelque chose de plus long
et de moins bon que le `if` qu'il remplace.

## `case` comme expression

`case` est une instruction, pas une expression, donc ceci n'est pas du Sather :

```sather
   -- wrong
   fare := case zone when 1 then 550 else 920 end;
```

Renvoie depuis l'intérieur de chaque branche, ou affecte une variable à
l'intérieur de chaque branche.
