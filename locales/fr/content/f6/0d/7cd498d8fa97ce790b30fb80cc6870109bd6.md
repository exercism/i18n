# Description

Implémente l'opération `accumulate`, qui, étant donné une collection et une opération à appliquer à chaque élément de cette collection, renvoie une nouvelle collection contenant le résultat de l'application de cette opération à chaque élément de la collection d'entrée.

Soit la collection de nombres :

- 1, 2, 3, 4, 5

Et une _quotation_ qui effectue :

- le carré d'un nombre (`[ sq ]`)

Ton code doit pouvoir produire la collection des carrés :

- 1, 4, 9, 16, 25

## Restrictions

Ne touche pas à la fonctionnalité collect/map/fmap/je-ne-sais-quoi fournie par ta bibliothèque standard !

À toi de résoudre cet exercice toi-même, avec d'autres outils de base.
