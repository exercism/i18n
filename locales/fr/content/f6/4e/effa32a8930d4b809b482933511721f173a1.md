# Introduction

Les caractères et les _strings_ constituent la base de la représentation du texte en Elm.
On peut voir les _strings_ comme des tableaux de caractères, et la plupart des fonctions du module `List` ont leur équivalent dans le module `String`.

## Caractères

Le type `Char` représente un seul caractère unicode entouré de guillemets simples, par exemple `'a'`. 
Le module `Char` fournit des fonctions de prédicat (`Char -> Bool`) qui testent les propriétés d'un caractère : `isUpper`, `isLower`, `isAlpha` et `isAlphaNum`.
Le module fournit aussi des fonctions pour convertir un caractère, `toUpper`, `toLower`, `toLocaleUpper`, `toLocaleLower`, ainsi que pour passer à sa valeur numérique unicode (`Int`) et inversement, avec `toCode` et `fromCode`.

## Les _strings_

Le type `String` offre une représentation intégrée qui permet de manipuler efficacement du texte, et peut représenter n'importe quelle séquence de caractères unicode, par exemple "this is an Elm string."
Les _strings_ multilignes s'écrivent avec trois guillemets doubles et peuvent contenir des guillemets et des retours à la ligne non échappés.
```elm
"""
    This is a multiline string.
All line-breaks and whitespace,
are preserved. 
"""
```

## Les fonctions du module `String`

Le module `String` contient toutes les fonctions résumées dans le tableau ci-dessous.
Parmi les fonctions les plus utilisées, on trouve :

`cons : Char -> String -> String` ajoute un caractère au début d'un _string_.
```elm
cons 'T' "he truth is out there" 
    --> "The truth is out there"
```

`(++): String -> String -> String` concatène deux _strings_.
```elm
"butter" ++ "fly" 
    --> "butterfly"
```

`split : String -> String -> List String` découpe un _string_ en un tableau de _strings_ au niveau du séparateur donné.
```elm
split ";" "cat;dog;cow" 
    --> ["cat", "dog", "cow"]
```

`join : String -> List String -> String` assemble un tableau de _strings_ en un seul, avec un séparateur donné.
```elm
join "a" ["H", "w", "ii", "n"] 
    --> "Hawaiian"
```
`replace : String -> String -> String -> String` remplace toutes les occurrences d'un sous-_string_ donné.
```elm
replace "Hello" "Goodbye cruel" "Hello world." 
    --> "Goodbye cruel world."
```

`length : String -> Int` renvoie le nombre de caractères d'un _string_.
```elm 
length "Hello world." 
    --> 12
```

`toInt : String -> Maybe Int` essaie de convertir un _string_ en `Just Int` et renvoie `Nothing` pour les _strings_ mal formés.
```elm
toInt "-42" 
    --> Just -42
```    

`contains : String -> String -> Bool` vérifie si le deuxième _string_ contient le premier.
```elm
contains "the" "theory" 
    --> True
```

`map : (Char -> Char) -> String -> String` applique une fonction donnée à chaque `Char` du _string_.
À noter que la fonction fournie doit être une application de `Char` vers `Char`.
```elm
map (\c -> if c == '/' then '.' else c) "a/b/c" 
    --> "a.b.c"
```
