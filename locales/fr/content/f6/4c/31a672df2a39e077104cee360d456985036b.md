# constructeur de chaîne utilisé

Utiliser `%{function}` est utile quand on concatène beaucoup de petits éléments dans une _string_.
Dans ce cas, l'opérateur `+=` est plus simple, plus rapide et consomme moins de mémoire.
Tu peux le vérifier en lançant les _benchmarks_ comme décrit dans les instructions de l'exercice.
