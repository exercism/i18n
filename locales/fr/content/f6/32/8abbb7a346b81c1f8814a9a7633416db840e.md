## Ajoute des méthodes à la classe Array

Cet exercice porte sur l'ajout de méthodes à la classe `Array` en Crystal.
Pour cela, tu devras définir une classe qui porte le nom `Array(T)` et y placer les méthodes.

```crystal
class Array(T)
  # your solution here
end
```

La classe `Array` est une classe [générique][generic] ; elle est aussi [_indexable_][indexable] et [_enumerable_][enumerable].
Le code source de la classe `Array` se trouve [ici][array].
