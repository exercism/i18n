# Introduction

## Nombres

De nombreux langages de programmation ont des types numériques spécifiques pour représenter différents types de nombres, mais JavaScript n'en a que deux :

- `number` : un type de données numérique au format à virgule flottante double précision sur 64 bits (IEEE 754).
  Par exemple `-6`, `-2.4`, `0`, `0.1`, `1`, `3.14`, `16.984025`, `25`, `976`, `1024.0` et `500000`.
- `bigint` : un type de données numérique qui peut représenter des _entiers_ au format à précision arbitraire.
  Par exemple `-12n`, `0n`, `4n` et `9007199254740991n`.

Si tu as besoin d'une précision arbitraire ou si tu travailles avec des nombres extrêmement grands, utilise le type `bigint`.
Sinon, le type `number` est probablement le meilleur choix.

### Arrondis

Il existe un objet global intégré appelé `Math` qui fournit diverses [fonctions d'arrondi][ref-math-object-rounding].
Par exemple, tu peux arrondir à l'inférieur (`floor`) ou au supérieur (`ceil`) des nombres décimaux à l'entier le plus proche.

```javascript
Math.floor(234.34); // => 234
Math.ceil(234.34); // => 235
```

## Les opérateurs arithmétiques

JavaScript fournit 6 opérateurs différents pour effectuer les opérations arithmétiques de base sur les nombres.

- `+` : l'opérateur d'addition sert à calculer la somme de nombres.
- `-` : l'opérateur de soustraction sert à calculer la différence entre deux nombres
- `*` : l'opérateur de multiplication sert à calculer le produit de deux nombres.
- `/` : l'opérateur de division sert à diviser deux nombres.

```javascript
2 - 1.5; //=> 0.5
19 / 2; //=> 9.5
```

- `%` : l'opérateur de modulo sert à calculer le reste d'une division.

  ```javascript
  40 % 4; // => 0
  -11 % 4; // => -3
  ```

- `**` : l'opérateur d'exponentiation sert à élever un nombre à une puissance.

  ```javascript
  4 ** 3; // => 64
  4 ** 1 / 2; // => 2
  ```

### L'ordre des opérations

Lorsque plusieurs opérateurs sont utilisés sur une même ligne, JavaScript suit un ordre de priorité, comme indiqué dans [ce tableau de priorité][mdn-operator-precedence].
Pour simplifier dans notre contexte, JavaScript applique la règle PEDMAS (parenthèses, exposants, division/multiplication, addition/soustraction) que l'on a apprise en cours de mathématiques à l'école primaire.

<!-- prettier-ignore-start -->
```javascript
const result = 3 ** 3 + 9 * 4 / (3 - 1);
// => 3 ** 3 + 9 * 4/2
// => 27 + 9 * 4/2
// => 27 + 18
// => 45
```
<!-- prettier-ignore-end -->

### Les opérateurs d'affectation raccourcis

Les opérateurs d'affectation raccourcis permettent d'écrire plus brièvement du code qui effectue des opérations arithmétiques sur une variable et qui affecte la nouvelle valeur à cette même variable.
Par exemple, prenons deux variables `x` et `y`.
Alors, `x += y` équivaut à `x = x + y`.
Souvent, on utilise un nombre à la place de la variable `y`.
Les 5 autres opérations peuvent aussi s'écrire de la même façon.

```javascript
let x = 5;
x += 25; // x is now 30

let y = 31;
y %= 3; // y is now 1
```
