# Indices

## Général

- Les indices d'un `Vector` commencent à `1`.
- Les paquets de cartes ne contiennent aucune carte en double.

## 1. Détermine si une carte est présente

- Il existe une méthode [`in`/`∈`](https://docs.julialang.org/en/v1/base/collections/#Base.in) dans Base pour déterminer si une collection contient une valeur.

## 2. Trouve la position d'une carte

- Il existe une méthode [`findfirst`](https://docs.julialang.org/en/v1/base/arrays/#Base.findfirst-Tuple{Function,%20Any}) dans Base pour trouver la position du premier élément d'une collection qui correspond à un prédicat donné.
- `==(x)` peut servir de prédicat pour trouver les éléments égaux à `x` dans les méthodes qui prennent des fonctions prédicat.

## 3. Détermine si chaque carte est paire

- Il existe une méthode [`all`](https://docs.julialang.org/en/v1/base/collections/#Base.all-Tuple{AbstractArray,%20Any}) dans Base qui renvoie `true` si tous les éléments d'une collection satisfont un prédicat donné.
- [`iseven`](https://docs.julialang.org/en/v1/base/numbers/#Base.iseven) est une fonction prédicat.

## 4. Vérifie si le paquet contient une carte de valeur impaire

- Il existe une méthode [`any`](https://docs.julialang.org/en/v1/base/collections/#Base.any-Tuple{AbstractArray,%20Any}) dans Base qui renvoie `true` si au moins un élément d'une collection satisfait un prédicat donné.
- [`isodd`](https://docs.julialang.org/en/v1/base/numbers/#Base.isodd) est une fonction prédicat.

## 5. Détermine la position de la première carte paire

- Il existe une méthode [`findfirst`](https://docs.julialang.org/en/v1/base/arrays/#Base.findfirst-Tuple{Function,%20Any}) dans Base pour trouver la position du premier élément d'une collection qui correspond à un prédicat donné.
- [`iseven`](https://docs.julialang.org/en/v1/base/numbers/#Base.iseven) est une fonction prédicat.

## 6. Récupère la première carte impaire du paquet

- Tu peux récupérer la `n`-ième valeur d'un vecteur `v` avec `v[n]`.
- Il existe une méthode [`findfirst`](https://docs.julialang.org/en/v1/base/arrays/#Base.findfirst-Tuple{Function,%20Any}) dans Base pour trouver la position du premier élément d'une collection qui correspond à un prédicat donné.
- Si aucun élément de la collection donnée ne correspond au prédicat passé à `findfirst`, `findfirst` renvoie `nothing`.
- Revois le fonctionnement de `nothing` en Julia : [concept:julia/nothingness](../../../../concepts/nothingness/about.md)
- Revois le fonctionnement des conditionnelles en Julia : [concept:julia/conditionals](../../../../concepts/conditionals/about.md)
