# À propos

Bien que Swift offre de nombreuses fonctionnalités dans sa bibliothèque standard, tu peux accéder à bien d'autres en important des bibliothèques et des frameworks externes.
Ces modules peuvent provenir directement du projet Swift (comme le [Swift Argument Parser][argument-parser]), de frameworks des plateformes Apple (comme [Foundation][apple-foundation] et le [Network Framework][network-framework]), ou de bibliothèques open source tierces (comme [SwiftyBeaver][swifty-beaver]).

Les modules essentiels comme Foundation, l'une des bibliothèques les plus utilisées en Swift, sont fournis avec la chaîne d'outils Swift.
Les bibliothèques tierces doivent, elles, être ajoutées à la configuration de ton projet (par exemple avec Swift Package Manager) avant de pouvoir être importées.

Pour importer un module, écris le mot-clé `import` suivi du nom du module :

```swift
import Foundation
```

Importer un module rend ses types, ses méthodes et ses fonctions disponibles pour ton code.
Par exemple, importer Foundation enrichit `String` de méthodes utilitaires pratiques comme `components(separatedBy:)`.

Par convention, les instructions `import` se placent en haut d'un fichier Swift, afin que les dépendances soient immédiatement visibles pour quiconque lit le code.

[argument-parser]: https://apple.github.io/swift-argument-parser/documentation/argumentparser/
[network-framework]: https://developer.apple.com/documentation/network
[swifty-beaver]: https://github.com/SwiftyBeaver/SwiftyBeaver
[apple-foundation]: https://developer.apple.com/documentation/foundation
