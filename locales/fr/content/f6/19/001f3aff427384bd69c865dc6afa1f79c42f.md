# Instructions

Chaque rôle de la pièce de l'école a une doublure : quelqu'un qui peut prendre la relève et faire ce que le rôle exige, sans que le régisseur sache qui c'est.

Les cinq tâches se trouvent toutes dans la classe `UNDERSTUDY`. Les deux premières sont des routines ordinaires que les tâches suivantes viendront lier.

## 1. Deux façons de dire une réplique

Écris `shout`, qui renvoie la réplique en majuscules, et `whisper`, qui la renvoie en minuscules avec `"..."` à chaque extrémité.

```sather
UNDERSTUDY::shout("who's there")
-- => "WHO'S THERE"
UNDERSTUDY::whisper("Who's There")
-- => "...who's there..."
```

## 2. Répète une réplique

`rehearse` prend une réplique et une façon de la dire, et renvoie le résultat. Son deuxième argument est de type `ROUT{STR}:STR`.

```sather
UNDERSTUDY::rehearse("who's there", bind(UNDERSTUDY::shout(_)))
-- => "WHO'S THERE"
```

## 3. La scène entière

`run_scene` prend un tableau de répliques et une façon de les dire, et les renvoie toutes dites de cette façon, réunies par `" "`.

```sather
UNDERSTUDY::run_scene(|"Enter", "Exit"|, bind(UNDERSTUDY::shout(_)))
-- => "ENTER EXIT"
```

Une scène vide est la _string_ vide.

## 4. Rends une façon de dire les choses

`understudy_for` prend le nom d'un style (soit `"shout"`, soit autre chose) et renvoie un `ROUT{STR}:STR`. `"shout"` donne celle qui crie ; toute autre valeur donne celle qui chuchote.

```sather
part ::= UNDERSTUDY::understudy_for("shout");
part.call("who's there")
-- => "WHO'S THERE"
```

## 5. Fixe un argument

Écris `repeat`, qui prend un nombre de fois et une réplique, et renvoie cette réplique répétée autant de fois, sans rien entre :

```sather
UNDERSTUDY::repeat(3, "Ha")
-- => "HaHaHa"
```

Écris ensuite `doubler`, qui ne prend aucun argument et renvoie un `ROUT{STR}:STR` qui répète deux fois ce qu'on lui donne, en liant `repeat` avec le nombre déjà renseigné.

```sather
UNDERSTUDY::doubler.call("Ha")
-- => "HaHa"
```
