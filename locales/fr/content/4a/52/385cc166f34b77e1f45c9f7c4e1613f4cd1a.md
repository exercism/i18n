# Introduction

## Importation

Bien que Swift inclue de nombreuses fonctionnalités dans sa bibliothèque standard, beaucoup d'autres fonctionnalités sont disponibles sous forme de bibliothèques externes.
Ces bibliothèques peuvent provenir du projet Swift lui-même, comme le [Swift Argument Parser][argument-parser], de bibliothèques à code source fermé d'entreprises, comme le [Network Framework][network-framework] d'Apple, ou de bibliothèques tierces, comme [Swifty Beaver][swifty-beaver].

Certains de ces modules, comme le Network Framework ou [Foundation][apple-foundation] (probablement la bibliothèque la plus utilisée en Swift), sont fournis avec l'installation de Swift.
Les bibliothèques tierces externes doivent être ajoutées au projet avant de pouvoir être importées, mais cela sort du cadre de cet exercice.

Pour importer des modules, on écrit le mot-clé `import` suivi du nom du module. On peut donc importer Foundation en ajoutant ce qui suit à son programme.

```swift
import Foundation
```

Cela donne accès à tous les types, valeurs et fonctionnalités de ce module ; par exemple, si l'on souhaite utiliser la méthode `components(separatedBy:)` de `String`, cette méthode devient disponible pour `String` grâce à cet import.

Bien qu'on puisse placer les instructions `import` n'importe où dans le code, avant le morceau de code qui utilise l'un des éléments du module, elles sont généralement placées au début du fichier qui les utilise, pour une meilleure lisibilité.

## Indexation des _string_

On peut accéder aux caractères individuels d'un `String` en utilisant la syntaxe d'indice employée avec les tableaux.
Cependant, les [indices][string-indices] utilisés pour les _string_ ne sont _pas_ des entiers et ne peuvent pas être manipulés directement.
Il faut à la place les calculer à partir d'un autre indice connu, comme `startIndex`, qui pointe vers la position du premier caractère d'une _string_ non vide, en utilisant les méthodes disponibles dans les bibliothèques [`String`][string-docs] et [`NSString`][nsstring-docs] (quand le module `Foundation` est importé, les _string_ en Swift ont accès à toutes les propriétés et méthodes de NSString).

Par exemple, étant donné la _string_ suivante :

```swift
let csv = "apple,pear,peach,orange,cherry,lime,goosberry"
```

On ne peut pas écrire `csv[21]` pour obtenir le « g » de « orange » ; il faut à la place calculer une valeur de type `String.Index` et fournir cet indice.
À noter que ces indices ne sont pas destinés à être lus par un humain tels quels.
On parle d'_indices opaques_, car un humain n'a pas besoin de savoir ce qu'ils contiennent.

```swift
let index = csv.index(csv.startIndex, offsetBy: 21)
csv[index]
// "g"
print(index)
// prints Index(_rawBits: 1376513)
```

Note cependant que si le décalage ne correspond pas à un indice valide, c'est-à-dire s'il donne un indice avant `startIndex` ou après `endIndex`, l'opération lèvera une erreur et fera planter le programme.
Pour éviter ce problème, on peut spécifier un indice limite.
La méthode renvoie alors un indice optionnel, et elle renvoie nil pour les indices qui seraient autrement invalides.

```swift
let tooFar = csv.index(csv.startIndex, offsetBy: 200)
// error: Execution was interrupted, reason: EXC_BAD_INSTRUCTION (code=EXC_I386_INVOP, subcode=0x0).
let tooFarButSafe = csv.index(csv.startIndex, offsetBy: 200, limitedBy: csv.endIndex)
// nil
```

De plus, les indices ne peuvent pas être partagés entre plusieurs _string_.
Par exemple, utiliser l'`index` du « g » de « orange » calculé plus haut pour indexer la _string_ `fam = "This is my family: 👨‍👩‍👦‍👦, this is our dog: 🐶, this is our cat: 🐱!"`, c'est-à-dire `fam[index]`, fera planter le programme.

Les raisons à tout cela sont nombreuses, mais elles se résument toutes à « Unicode, c'est délicat ».

D'une manière générale, si tu as besoin d'accéder de façon aléatoire à des caractères individuels, tu as probablement intérêt à utiliser une autre structure de données, comme `Array<Character>`.

### Quelques méthodes utiles

Swift dispose des méthodes `first` et `last` pour obtenir le premier et le dernier caractère d'une _string_.
Ces méthodes renvoient un caractère optionnel ; si la _string_ est vide, elles renvoient donc nil.

```swift
let str = "Hello, world!"
print(str.first) // Prints Optional("H")
print(str.last)  // Prints Optional("!")
```

Tu peux aussi utiliser les méthodes `prefix` et `suffix` pour obtenir une sous-chaîne d'une _string_.
Ces méthodes prennent un entier en argument et renvoient une sous-chaîne contenant les n premiers ou derniers caractères de la _string_.

```swift
let str = "Hello, world!"
print(str.prefix(5)) // Prints "Hello"
print(str.suffix(6)) // Prints "world!"
```

## Méthodes de _string_

Travailler avec des _string_ est une tâche courante en programmation.
C'est pourquoi Swift fournit tout un ensemble de méthodes pour les manipuler.
Ce document présente quelques-unes des méthodes et propriétés les plus courantes, dont certaines nécessitent d'importer le _framework_ Foundation.

### [`components(separatedBy:)`][components]

Quand tu veux découper une _string_ en un tableau de sous-chaînes, tu peux utiliser la méthode `components(separatedBy:)`.
Ainsi, si tu veux récupérer chaque mot d'une phrase, tu peux utiliser l'espace comme séparateur.

```swift
let sentence = "Hello, world!"
let words = sentence.components(separatedBy: " ")
print(words) // Prints ["Hello,", "world!"]
```

### [`hasPrefix(_:)`][hasPrefix], [`hasSuffix(_:)`][hasSuffix]

Quand tu veux vérifier si une _string_ commence ou se termine par une certaine sous-chaîne, tu peux utiliser les méthodes `hasPrefix(_:)` et `hasSuffix(_:)`.
Ces deux méthodes prennent une _string_ en argument et renvoient une valeur booléenne indiquant si la _string_ commence ou se termine par la sous-chaîne spécifiée.

```swift
let greeting = "Hello, world!"
print(greeting.hasPrefix("Hello"))  // Prints true
print(greeting.hasSuffix("world!")) // Prints true
```

### [`lowercased`][lowercased], [`uppercased`][uppercased], [`capitalized`][capitalized]

Quand tu veux changer la casse d'une _string_, tu peux utiliser les propriétés `lowercased`, `uppercased` et `capitalized`.
La propriété `lowercased` renvoie une nouvelle _string_ dont tous les caractères sont en minuscules, la propriété `uppercased` renvoie une nouvelle _string_ dont tous les caractères sont en majuscules, et la propriété `capitalized` renvoie une nouvelle _string_ dont le premier caractère de chaque mot est en majuscule.

```swift
let greeting = "hello, world!"
print(greeting.lowercased)  // Prints "hello, world!"
print(greeting.uppercased)  // Prints "HELLO, WORLD!"
print(greeting.capitalized) // Prints "Hello, World!"
```

### [`replacingOccurrences(of:with:)`][replacingOccurrences]

Quand tu veux remplacer toutes les occurrences d'une sous-chaîne dans une _string_ par une autre sous-chaîne, tu peux utiliser la méthode `replacingOccurrences(of:with:)`.
Cette méthode prend deux _strings_ en arguments : la sous-chaîne à remplacer et celle par laquelle la remplacer. Elle renvoie une nouvelle _string_ où toutes les occurrences de la sous-chaîne spécifiée ont été remplacées.

```swift
let greeting = "Hello, world!"
let newGreeting = greeting.replacingOccurrences(of: "world", with: "Swift")
print(newGreeting) // Prints "Hello, Swift!"
```

### [`joined(separator:)`][joined]

Cette méthode n'appartient pas au type `String`, mais au type `Array`.
Quand tu veux joindre un tableau de _strings_ en une seule _string_ avec un séparateur donné, tu peux utiliser la méthode `joined(separator:)`.
Cette méthode prend une _string_ en argument et renvoie une nouvelle _string_ formée de tous les éléments du tableau réunis, séparés par la _string_ spécifiée.

```swift
let words = ["Hello", "world"]
let sentence = words.joined(separator: ", ")
print(sentence) // Prints "Hello, world"
```
