# Indices

## Général

- Lis la documentation sur le module `Enum` dans le [guide officiel de démarrage][getting-started-enum] ou sur [elixirschool.com][elixir-school-enum].
- Jette un œil à la documentation pour la [liste complète des fonctions du module `Enum`][enum-functions].

## 1. Trier les articles par prix

- Il existe une [fonction intégrée][enum-sort-by] pour trier les énumérables à l'aide d'une fonction de tri.

## 2. Trouver tous les articles dont le prix est manquant

- Il existe une [fonction intégrée][enum-filter] pour filtrer les énumérables.

## 3. Mettre à jour les noms des articles

- Il existe une [fonction intégrée][enum-map] pour transformer chaque élément d'un énumérable.
- Il existe une [fonction intégrée][string-replace] qui permet de remplacer toutes les occurrences d'une _string_ par une autre.

## 4. Incrémenter la quantité de l'article

- Les _maps_ implémentent le protocole énumérable.
- Les fonctions d'`Enum` convertissent les _maps_ en une liste de tuples `{key, value}`.
- Il existe deux fonctions différentes qui peuvent retransformer une liste de tuples `{key, value}` en une _map_ à l'aide d'une fonction de transformation. [L'une d'elles renvoie toujours une nouvelle _map_][map-new], tandis que [l'autre permet de choisir un collectible][enum-into].

## 5. Calculer la quantité totale de l'article

- Les _maps_ implémentent le protocole énumérable.
- Les fonctions d'`Enum` convertissent les _maps_ en une liste de tuples `{key, value}`.
- Il existe une [fonction intégrée][enum-reduce] pour réduire un énumérable à une seule valeur.
