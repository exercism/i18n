# Instructions supplémentaires

## Indices

Les tests de cet exercice sont différents de ceux dont tu as l'habitude. Normalement, un test vérifie que, pour une entrée donnée, la sortie correspond à la valeur attendue. C'est ce qu'on appelle les _tests basés sur les valeurs_. Or cet exercice utilise les _tests basés sur les propriétés_, où les tests vérifient que, pour un ensemble d'entrées, la sortie possède une propriété particulière. Les deux différences essentielles entre ces deux approches sont les suivantes : 

1. Un test basé sur les propriétés ne travaille pas avec une seule valeur d'entrée, mais avec un grand nombre d'entre elles.
1. Un test basé sur les propriétés vérifie des propriétés, et non des valeurs concrètes.

Pour cet exercice, tous les tests vérifient une propriété de la forme de losange que ton code doit produire. De plus, tous les tests vérifient que la propriété testée est vraie pour toutes les lettres d'entrée valides ('A' à 'Z').

Pour faciliter les tests basés sur les propriétés, les tests de cet exercice s'appuient sur les paquets [FsCheck](https://www.nuget.org/packages/FsCheck) et [FsCheck.Xunit](https://packages.nuget.org/packages/FsCheck.Xunit/2.2.0). Pour en savoir plus sur FsCheck, la documentation du _framework_ est disponible [ici](https://fscheck.github.io/FsCheck/).

Si tu veux plus d'informations sur les tests basés sur les propriétés, consulte [cet article](http://www.erikschierboom.com/2016/02/22/property-based-testing/).
