# À propos

De nombreux opérateurs peuvent aussi s'utiliser sous forme d'[affectations composées][compound-assignment], une notation abrégée dans laquelle `x = op y` peut s'écrire `x op= y` :

```csharp
var features = PhoneFeatures.Call;
features |= PhoneFeatures.Text;
features &= ~PhoneFeatures.Call;
```
