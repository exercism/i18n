# À propos

Un [`Time`][time] en Go est un type qui décrit un instant précis.
On peut accéder aux informations de date et d'heure, les comparer et les manipuler grâce à ses méthodes, mais il existe aussi des fonctions qui s'appellent directement sur le paquet `time`.
La date et l'heure actuelles s'obtiennent avec la fonction [`time.Now`][now].

La fonction [`time.Parse`][parse] analyse des _strings_ et les convertit en valeurs de type `Time`.
Go a une manière bien particulière de définir le format attendu pour cette analyse.
Il faut écrire un exemple de ce format en utilisant les valeurs de cet horodatage spécial :
`Mon Jan 2 15:04:05 -0700 MST 2006`.

Par exemple :

```go
import "time"

func parseTime() time.Time {
    date := "Tue, 09/22/1995, 13:00"
    layout := "Mon, 01/02/2006, 15:04"

    t, err := time.Parse(layout,date) // time.Time, error
}

// => 1995-09-22 13:00:00 +0000 UTC
```

La méthode [`Time.Format()`][format] renvoie une représentation d'un instant sous forme de _string_.
Comme pour la fonction `Parse`, le format cible est là encore défini par un exemple qui utilise les valeurs de l'horodatage spécial.

Par exemple :

```go
import (
    "fmt"
    "time"
)

func main() {
    t := time.Date(1995,time.September,22,13,0,0,0,time.UTC)
    formattedTime := t.Format("Mon, 01/02/2006, 15:04") // string
    fmt.Println(formattedTime)
}

// => Fri, 09/22/1995, 13:00
```

## Options de format

Pour un format personnalisé, on combine plusieurs de ces options.
Go fournit également des [constantes de format][const] prédéfinies pour les dates et les horodatages.

| Élément            | Options                                        |
| ------------------ | ---------------------------------------------- |
| Année              | 2006 ; 06                                      |
| Mois               | Jan ; January ; 01 ; 1                         |
| Jour               | 02 ; 2 ; \_2 (pour le zéro qui précède)        |
| Jour de la semaine | Mon ; Monday                                   |
| Heure              | 15 ( format 24 heures ) ; 3 ; 03 (AM ou PM)    |
| Minute             | 04 ; 4                                         |
| Seconde            | 05 ; 5                                         |
| Marque AM/PM       | PM                                             |
| Jour de l'année    | 002 ; \_\_2                                    |

Le type `time.Time` propose diverses méthodes pour accéder à un élément particulier d'un instant, par exemple l'heure avec [`Time.Hour()`][hour] ou le mois avec [`Time.Month()`][month].
Pour en savoir plus sur son fonctionnement, consulte la [documentation officielle][time].

Le paquet [`time`][time] contient aussi un autre type, [`Duration`][duration], qui représente une durée écoulée, ainsi que la prise en charge des localisations et des fuseaux horaires, des minuteries et d'autres fonctionnalités associées, qui seront abordées dans un autre concept.
