# Apprendre

Exercism propose des exercices et des retours, mais il peut être difficile de s'y mettre quand on apprend Pascal pour la première fois. Ces ressources peuvent t'aider à démarrer :

* [Pascal Tutorial](https://www.tutorialspoint.com/pascal/index.htm) semble être un bon point de départ pour te familiariser avec Pascal si tu n'as aucune expérience de ce langage. Tu n'as pas besoin de Delphi pour faire les exercices abordés dans ce tutoriel. C'est peut-être un bon endroit pour t'entraîner avant de te lancer dans les exercices d'ici, qui, eux, nécessitent Delphi.
* [Pascal-Programming.info](http://www.pascal-programming.info/index.php) semble aussi proposer un bon tutoriel pour les personnes qui découvrent le langage.
* Il existe bien d'autres sources en ligne pour apprendre Pascal, trop nombreuses pour être listées ici.
