# Introduction

## Unions discriminées

Une union discriminée est un type qui représente un nombre fixe de cas nommés. Chaque valeur d'une union discriminée correspond à exactement un de ces cas nommés.

Une union discriminée se définit à l'aide du mot-clé `type`, en séparant les cas par des barres verticales (`|`) :

```fsharp
type Season =
    | Spring
    | Summer
    | Autumn
    | Winter
```

Chaque cas d'une union discriminée peut éventuellement avoir des données qui lui sont associées, et les différents cas peuvent avoir des types de données différents. Si aucun des cas n'a de données associées, l'union discriminée s'apparente à ce que d'autres langages appellent généralement une _énumération_ (ou _enum_).

```fsharp
type Number =
    | Integer of int
    | Float of float
    | Invalid
```

Pour créer une valeur d'un cas donné, il suffit de faire référence à son nom (par exemple `Success`). Comme les noms de cas ne sont que des fonctions de construction, les données associées peuvent être passées comme un argument de fonction classique. Si une autre union discriminée a défini un cas portant le même nom, tu devras utiliser son nom complet (par exemple `Result.Success`).

```fsharp
let byName = Integer 2
let byFullName = Number.Invalid
```

Les unions discriminées ont une _égalité structurelle_, ce qui signifie que deux valeurs du même cas, avec les mêmes données (facultatives), sont équivalentes.

Même s'il est possible d'utiliser des expressions `if/elif/else` pour manipuler les unions discriminées, la méthode recommandée pour les manipuler est le filtrage par motif, au moyen du _motif d'identificateur_ :

```fsharp
let describe number =
    match number with
    | Integer i -> sprintf "Integer: %d" i
    | Float d  -> sprintf "Float: %f" d
    | Invalid   -> "Invalid"
```
