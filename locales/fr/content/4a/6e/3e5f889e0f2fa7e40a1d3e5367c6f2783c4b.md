# Intervalles

[Les intervalles][range] représentent un intervalle entre deux valeurs.
Les types les plus courants qui prennent en charge les intervalles sont `Integer` et `String`.
On peut les utiliser pour beaucoup de choses : créer rapidement une collection, découper des _strings_, vérifier qu'une valeur se trouve dans un intervalle, ou encore pour l'itération.
On les crée avec l'opérateur d'intervalle `..` ou `...` (respectivement inclusif et exclusif).

```ruby
1..5  # => 1..5
1...5 # => 1...5

(1..5).to_a # => [1, 2, 3, 4, 5]
(1...5).to_a # => [1, 2, 3, 4]
```

La raison d'avoir deux opérateurs d'intervalle est de pouvoir créer des intervalles qui incluent ou excluent la valeur de fin, ce qui peut être utile, par exemple, quand on travaille avec des indices qui commencent à zéro.

On peut aussi créer des intervalles avec l'initialiseur `Range`.

```ruby
Range.new(1, 5) # A range containing 1, 2, 3, 4, 5
```

~~~~exercism/note
Quand on crée un intervalle en Ruby avec les opérateurs `..` ou `...` et qu'on veut appeler une méthode sur cet intervalle, il faut le mettre entre parenthèses.
Sinon, la méthode est appelée sur le deuxième argument de l'opérateur d'intervalle.

```ruby
(1..5).sum # => 15
1..5.sum # => Error: undefined method `sum' for 5:Integer (NoMethodError)
```
~~~~

## Obtiens des sous-chaînes

Pour découper une _string_, tu peux utiliser l'opérateur d'intervalle pour en obtenir une sous-chaîne.
Il suffit pour cela de créer un intervalle avec l'indice de début et l'indice de fin de cette sous-chaîne.

```ruby
"Hello World"[0..4] # => "Hello"
"Hello World"[6..10] # => "World"
```

Tu peux aussi utiliser des indices négatifs pour obtenir la sous-chaîne à partir de la fin de la _string_.

```ruby
"Hello World"[-5..-1] # => "World"
"Hello World"[6..-4] # => "Wo"
```

## Méthodes des intervalles

Les intervalles disposent d'un ensemble de méthodes pour travailler avec eux.
Par exemple, ces méthodes permettent d'obtenir la somme de toutes les valeurs de l'intervalle ou de vérifier si l'intervalle contient une valeur.

| Method                  | Description                                                             | Example                         |
| ----------------------- | ----------------------------------------------------------------------- | ------------------------------- |
| [`sum`][sum]            | Renvoie la somme de toutes les valeurs de l'intervalle                  | `(1..5).sum # => 15`            |
| [`size`][size]          | Renvoie la taille de l'intervalle                                       | `(1..5).size # => 5`            |
| [`include?`][indlude]   | Renvoie `true` si l'intervalle contient la valeur donnée, sinon `false` | `(1..5).include?(3) # => true`  |

## Intervalles sans fin et sans début

Un intervalle peut être sans fin ou sans début.
Dans un intervalle sans fin ou sans début, la valeur de début ou de fin vaut `nil`, mais on peut omettre ce `nil` quand on définit l'intervalle.

Les intervalles sans début et sans fin sont utiles quand on veut, par exemple, découper une _string_ depuis le début ou jusqu'à la fin.

```ruby
"Hello World"[0..] # => "Hello World"
"Hello World"[4..] # => "o World"
"Hello World"[..5] # => "Hello "
```

~~~~exercism/caution
S'il n'est pas utilisé sur une collection, l'intervalle sans fin peut provoquer une séquence sans fin, si l'on n'y prend pas garde.
~~~~

## Intervalles de chaînes de caractères

Les _strings_ peuvent aussi servir dans les intervalles et permettent d'obtenir un intervalle de _strings_ entre deux _strings_.
Leur comportement peut être un peu inattendu avec certaines _strings_, il vaut donc mieux les utiliser avec prudence.

```ruby
"aa".."az".to_a # => ["aa", "ab", "ac", ..., "az"]
```

## Objets personnalisés dans les intervalles

~~~~exercism/advanced
Ruby permet d'utiliser des objets personnalisés dans les intervalles.
Pour cela, l'objet doit implémenter ce qui suit :

- inclure le module `Comparable`
- la méthode `succ`
- la méthode `<=>`

Ces méthodes permettent à l'intervalle d'itérer sur l'objet et de comparer les objets qu'il contient.

```ruby
class Foo
  include Comparable

  attr_reader :value

  def initialize(value)
    @value = value
  end

  def succ
    Foo.new(value + 1)
  end

  def <=>(other)
    value <=> other.value
  end
end

(Foo.new(1)..Foo.new(5))
# => #<Foo:0x7f3552bebe70 @value=1>, #<Foo:0x7f3552bebe50 @value=2>, #<Foo:0x7f3552bebe40 @value=3>, #<Foo:0x7f3552bebe30 @value=4>, #<Foo:0x7f3552bebe20 @value=5>
```
