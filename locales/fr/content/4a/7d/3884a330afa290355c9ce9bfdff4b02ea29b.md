# Introduction

En Kotlin, les fonctions sont des citoyens de première classe.
Cela signifie qu'on peut les stocker dans des variables, les passer en arguments et même les renvoyer depuis d'autres fonctions.
Par exemple, voici comment affecter une fonction à la variable `addOne` :

```kotlin
val addOne = fun (num : Int) : Int {
    return num + 1
}
```

Une fonction peut aussi renvoyer une autre fonction :

```kotlin
fun makeAddOne() : (Int) -> Int {
    return fun(num : Int) : Int {
        return num + 1
    }
}

val addOne = makeAddOne()
```

Une fois affectée, la fonction peut être appelée à travers la variable comme s'il s'agissait d'une fonction comme une autre :
```kotlin
addOne(3)
// => 4
```

## Déclare des types de fonction

On peut déclarer le type d'une variable ou d'un paramètre avec la syntaxe `(parameter types) -> return type`.
Par exemple, pour déclarer une variable :

```kotlin
val addOne : (Int) -> Int = fun (num : Int) : Int {
    return num + 1
}
```

Et pour un paramètre de fonction :

```kotlin
fun perform(operation : (Int) -> Int) {
    operation(3)
}
```

## Expressions lambda

Une expression lambda est une façon plus concise de définir une fonction.
Elles s'écrivent sous la forme `{ parameters -> body }`.
L'expression renvoie la valeur de la dernière instruction du corps.
Par exemple :

```kotlin
// Assigning to a variable
val addOne = { num : Int -> num +  1}

// In a function call
perform({ num : Int -> num + 1 })
```

Kotlin peut inférer les types quand il dispose de suffisamment d'informations.
Par exemple, les exemples ci-dessus peuvent aussi s'écrire ainsi :

```kotlin
// Assigning to a variable
val addOne : (Int) -> Int = { num -> num + 1 }

// Or ...
val addOne  = { num : Int -> num + 1 }

// Using in a function
perform({ num -> num + 1 })
```

## `it` pour les lambdas à un seul paramètre

Quand l'expression n'a qu'un seul paramètre, on peut omettre celui-ci.
Kotlin met alors à disposition dans le corps un paramètre appelé `it`.
Par exemple :

```kotlin
val addOne : (Int) -> Int = { it +  1 }
```

## Passe des lambdas en dernier argument

Quand le dernier argument d'une fonction est une lambda, l'expression lambda s'écrit directement _après_ les parenthèses.
Par exemple :

```kotlin
// Function that takes a function as last argument
fun calculateFrom(from : Int, operation : (Int) -> Int) : Int {
    return operation(from)
}

// Call the calculateFrom function
calculateFrom(2) { it * 3 }
// => 6
```
