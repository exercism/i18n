# Introduction

Il est souvent utile de regrouper une collection d'éléments, puis de manipuler ces groupes comme des unités. En Rust, on appelle un tel groupe une structure, et chaque élément l'un des champs de cette structure. Une structure définit l'ensemble général des champs disponibles, mais un exemple particulier de structure s'appelle une instance.

De plus, on peut définir des méthodes sur les structures, et ces méthodes ont accès aux champs. La structure elle-même est alors désignée par `self`. Quand une méthode utilise `&mut self`, les champs peuvent être modifiés, ou mutés. Quand une méthode utilise `&self`, les champs ne peuvent pas être modifiés : ils sont immuables. Maîtriser la mutabilité aide le vérificateur d'emprunts à garantir que des catégories entières de bugs de concurrence ne se produisent tout simplement jamais en Rust.

Dans cet exercice d'apprentissage, tu vas implémenter deux sortes de méthodes sur une structure. Les premières sont généralement appelées des accesseurs : elles exposent les champs de la structure au monde extérieur, sans laisser qui que ce soit d'autre modifier cette valeur. En Rust, ces méthodes portent idiomatiquement le nom du champ qu'elles exposent, c'est-à-dire que si l'on a un accesseur qui récupère un champ de la structure nommé `name`, la méthode s'appellera simplement `name()`.

Tu vas aussi implémenter des méthodes d'un autre genre, généralement appelées des mutateurs. Celles-ci modifient la valeur du champ. Les mutateurs ne sont pas très courants en Rust (si un champ peut être librement modifié, il est plus courant de le rendre simplement public), mais ils sont utiles si la mise à jour du champ doit avoir des effets de bord, ou pour le contrôle d'accès : un mutateur marqué `pub(crate)` permet à d'autres modules du même crate de mettre à jour un champ privé, sur lequel l'extérieur ne peut pas agir.

Les structures se déclinent en trois variétés : les structures à champs nommés, les structures tuples et les structures unitaires. Dans cet exercice d'apprentissage, on va explorer la première variante : les structures à champs nommés.

Les structures se définissent à l'aide du mot-clé `struct`, suivi du nom du type qu'elles décrivent, avec une majuscule initiale :

```rust
struct Item {}
```

D'autres types sont ensuite intégrés au corps de la structure en tant que _champs_ de celle-ci, chacun avec son propre type :

```rust
struct Item {
    name: String,
    weight: f32,
    worth: u32,
}
```

Enfin, on peut définir des méthodes sur une structure à l'intérieur d'un bloc `impl` :

```rust
impl Item {
    // initializes and returns a new instance of our Item struct
    fn new() -> Self {
        todo!()
    }
}
```
