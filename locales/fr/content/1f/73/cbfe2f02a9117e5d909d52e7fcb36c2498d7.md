# À propos

`while` et `until` (dans [`kernel`][kernel]) sont des combinateurs de boucle pilotés par des _quotations_, pour le cas où on ne connaît pas le nombre d'itérations à l'avance :

```
while ( pred: ( -- ? ) body: ( -- ) -- )
until ( pred: ( -- ? ) body: ( -- ) -- )
```

`while` continue tant que `pred` laisse une valeur vraie ;
`until` continue tant que `pred` laisse `f`. Les deux s'arrêtent et
renvoient leur résultat dès que leur prédicat bascule.

```factor
USING: kernel math ;

! Halve down to 1
16 [ dup 1 > ] [ 2 / ] while .   ! => 1

! Double up to 100
1 [ dup 100 >= ] [ 2 * ] until .   ! => 128
```

Quand une seule valeur qui circule sur la pile ne suffit pas comme état (par exemple une liste restante, un total cumulé et un compteur en même temps), le motif le plus élégant est d'utiliser des _locals_ nommés pour plus de clarté. Les _locals_ sont présentés plus en détail plus loin dans le programme ; ici, il suffit de savoir que `:: word ( a b -- c )` déclare les entrées comme des _locals_ nommés, et que `:> name!` ajoute un _local_ modifiable que le corps peut mettre à jour avec `value name!`.

```factor
USING: kernel locals math sequences ;

! Sum a sequence by hand
:: sum-by-hand ( seq -- total )
    seq :> rest!
    0 :> running!
    [ rest length 0 > ] [
        rest unclip [ rest! ] dip
        running + running!
    ] while
    running ;
```
