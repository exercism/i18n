# formatage avec % ou « ancien style »

Cette solution utilise le `%%-formatting` ou le [formatage à l'ancienne][old-style formatting] pour les _strings_.

Bien que le `%%-formatting` soit une approche parfaitement valide, il peut créer des problèmes de représentation ou de lisibilité.
Utiliser la méthode [str.format()][str.format()] ou les [f-strings][f-strings] (_aussi appelées « littéraux de chaîne formatés » ou « chaînes interpolées »_) peut offrir des options qui améliorent la lisibilité et rendent le remplacement des variables dans les _strings_ plus clair.

L'article de blog [String Formatting in Python][string formatting in python] est un bon point de départ pour comprendre toutes les options de formatage de _strings_ de Python, et [Newer Python String Format Techniques][newer python string format techniques] propose aussi quelques astuces intéressantes pour utiliser `str.format()` et les `f-strings`.
