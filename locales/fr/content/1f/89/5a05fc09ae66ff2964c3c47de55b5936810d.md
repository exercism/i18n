# Ressources

## Crée ton premier module Coffee

Pour créer un module que l'on peut charger avec `Bob = require './bob'`, mets ce code dans `bob.coffee` :

```coffeescript
class Bob

module.exports = Bob
```

Tu trouveras plus d'informations sur les modules dans la [documentation de Node](http://nodejs.org/api/modules.html#modules_module_exports).

## Visual Studio sous Windows

Si tu disposes d'une version payante de Visual Studio, tu peux télécharger une solution Visual Studio déjà configurée pour fonctionner avec CoffeeScript et les autres langages pris en charge par Visual Studio.

![Explorateur de solutions](https://raw.githubusercontent.com/exercism/coffeescript/main/docs/img/SolutionExplorer.png)

1. Télécharge l'[Exercism.io Visual Studio Template](https://github.com/rprouse/Exercism.VisualStudio) depuis GitHub en cliquant sur le bouton Download Zip de la page.
2. Décompresse le modèle dans ton répertoire d'exercices, par exemple `C:\src\exercises`
2. Installe l'[Exercism CLI](http://exercism.io/cli)
3. Ouvre une invite de commandes dans ton répertoire d'exercices
4. Ajoute ta clé d'API à exercism `exercism configure --key=YOUR_API_KEY`
5. Configure ton répertoire source dans exercism `exercism configure --dir=C:\src\exercises`
6. [Récupère ton premier exercice](http://exercism.io/languages/coffeescript) `exercism fetch coffeescript`
7. Ouvre la solution Exercism dans Visual Studio
8. Développe le projet Exercism.coffeescript
9. Clique sur **Show All Files** dans l'Explorateur de solutions (voir ci-dessous)
10. L'exercice que tu viens de récupérer apparaîtra grisé. Fais un clic droit sur le dossier puis **Include In Project**
11. À toi de coder...

![Ajouter des fichiers](https://raw.githubusercontent.com/exercism/coffeescript/main/docs/img/AddFiles.png)

Pour travailler avec CoffeeScript dans Visual Studio, tu devrais installer l'extension [Web Essentials](http://vswebessentials.com/). Elle facilitera aussi grandement le travail avec Javascript.

Tu peux exécuter les tests unitaires depuis une ligne de commande node.js à l'aide du fichier batch du projet.

```bash
C:\Src\exercises\coffeescript> test example\bob_test.spec.coffee
.................

Finished in 0.02 seconds
17 tests, 17 assertions, 0 failures, 0 skipped
```

Si tu ne vois aucune sortie après avoir lancé les tests, c'est probablement que tu n'es pas dans une invite de commandes Node.js.
