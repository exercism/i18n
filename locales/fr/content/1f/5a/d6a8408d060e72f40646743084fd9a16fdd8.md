# Null

`null` est un type primitif qui ne peut prendre qu'une seule valeur : `null`.
On utilise souvent `null` pour représenter une absence de valeur.
Il est considéré comme « _falsey_ », mais il se distingue de `false` et des autres valeurs « _falsey_ ».

```php
<?php

is_null(null); // => true
isset(null); // => false

null == true; // => false
null === true; // => false

null == false; // => true
null === false; // => false
```

## Manipule les valeurs `null`

En PHP, les valeurs `null` sont une cause fréquente d'erreur : elles sont souvent renvoyées à la place d'un état d'erreur ou pour représenter une absence de valeur.
Pour éviter que des erreurs surviennent, il faut souvent recourir au « _null-checking_ » afin de vérifier que la valeur n'est pas `null` avant de l'utiliser.

Répéter ce « _null-checking_ » peut être source d'erreurs, c'est pourquoi PHP fournit deux opérateurs pour travailler avec les valeurs `null` : l'opérateur d'accès _null-safe_ `?->` et l'opérateur de coalescence `??`.
