# Introduction

En Python, `None` sert fréquemment à représenter l'absence de valeur, une valeur de remplissage pour définir une variable, un objet ou un argument `null` (vide).

Si tu as déjà entendu parler d'un type `NULL` ou `nil` dans un autre langage de programmation, ou si tu l'as déjà utilisé, alors cet usage de `None` en Python te sera familier.
`None` t'aide à déclarer des variables ou des arguments de fonction pour lesquels tu n'as pas encore de valeur.
On peut ensuite leur réaffecter des valeurs précises plus tard, selon les besoins :

```python
a = None
print(a)
#=> None

type(a)
#=> <class 'NoneType'>

# Adding a default argument with `None`
def add_to_todos(new_task, todo_list=None):
    if todo_list is None:
        todo_list = []  
    todo_list.append(new_task)
     
  return todo_list
```

`None` s'évalue à `False` lorsqu'il est utilisé dans une condition, ce qui en fait un outil pratique pour vérifier la « présence » ou l'« absence » d'une valeur, _quelle qu'elle soit_. C'est un schéma fréquent lorsqu'une fonction ou un traitement est susceptible de renvoyer une `error`, un `object` ou un message.

```python
a = None
if a: #<-- a will be evaluated to False when it is used in a conditional check.
    print("This will not be printed")
```
