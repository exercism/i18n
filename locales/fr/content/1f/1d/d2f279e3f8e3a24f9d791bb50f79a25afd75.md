# À propos

PHP est un langage côté serveur adapté au développement web. Son acronyme est récursif : il signifie _PHP: Hypertext Preprocessor_.

Bien plus polyvalent que les scripts CGI, PHP sert souvent à ajouter de l'interactivité à du HTML simple et à renforcer les frameworks web.

Ce langage peut être utilisé sur n'importe quel système d'exploitation. PHP est pris en charge par la plupart des serveurs web courants et passe souvent par un module d'interprète, ce qui combine du code web statique avec des inclusions dynamiques.

PHP n'est pas seulement un framework de serveur web. Il est aussi utile pour les scripts en ligne de commande (analyse syntaxique sans interface graphique) et pour développer des interfaces graphiques.

Tu devrais apprendre PHP parce que :

- c'est un langage open source
- il est bien documenté et bien pris en charge
- il est compatible avec la plupart des serveurs web courants
- il est facile à prendre en main pour commencer à apprendre
- il est hautement évolutif et extensible
