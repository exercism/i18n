# Introduction

## Atomes

Le type `atom` d'Elixir représente une constante fixe. La valeur d'un atome est simplement son propre nom. Cela nous permet d'interagir avec les données de manière sûre du point de vue des types. Les atomes peuvent être définis comme suit :

```elixir
# All atoms are preceded with a ':' then follow with alphanumeric snake-cased characters
variable = :an_atom
```

_Les atomes_ sont représentés en interne par un entier dans une table de correspondance, renseignée automatiquement. Il n'est pas possible de modifier cette valeur interne.

## Cond

Souvent, on veut écrire du code qui peut prendre différentes branches selon une condition. Même s'il existe de nombreuses façons de faire cela en Elixir, l'une des plus simples consiste à utiliser `cond/1`.

Dans sa forme la plus simple, `cond` suit le premier chemin qui s'évalue à `true`, parmi une ou plusieurs branches :

```elixir
cond do
  x > 10 -> :this_might_be_the_way
  y < 7 -> :or_that_might_be_the_way
  true -> :this_is_the_default_way
end
```

Si aucun chemin ne s'évalue à `true`, une erreur est levée par l'environnement d'exécution.
