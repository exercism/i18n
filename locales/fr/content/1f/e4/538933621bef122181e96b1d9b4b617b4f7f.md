# Introduction

## Dictionnaires

Un dictionnaire est une collection d'éléments où chaque élément est composé d'une clé et d'une valeur, de sorte que si l'on passe une clé à une méthode du dictionnaire, la valeur associée est renvoyée. Il joue le même rôle que les _maps_ ou les tableaux associatifs dans d'autres langages.

On peut créer un dictionnaire comme suit :

```csharp
new Dictionary<int, string>();
// Empty dictionary
```

Ou

```csharp
new Dictionary<int, string>
{
    [1] = "One",
    [2] = "Two"
};

// Or

new Dictionary<int, string>
{
    {1, "One"},
    {2, "Two"}
};
// 1 => "One", 2 => "Two"
```

Note que les types de la clé et de la valeur font partie de la définition du dictionnaire.

Une fois construit, on peut ajouter ou supprimer des entrées d'un dictionnaire à l'aide de ses méthodes intégrées `Add` et `Remove`.

Pour récupérer ou mettre à jour des valeurs dans un dictionnaire, on l'indexe à l'aide d'une clé :

```csharp
var numbers = new Dictionary<int, string>
{
   {1, "One"},
   {2, "Two"}
};

// Set the value of the element with key 2 to "Deux"
numbers[2] = "Deux";

// Get the value of the element with key 2
numbers[2];
// => "Deux"
```

Tu peux tester si une valeur existe dans le dictionnaire avec :

```csharp
var dict = new Dictionary<string, string>{/*...*/};
dict.ContainsKey("some key that exists");
// => true
```

Parcourir un dictionnaire énumère ses paires clé/valeur. Les dictionnaires possèdent aussi des propriétés qui permettent de parcourir ses clés ou ses valeurs.
