# Instructions

Appeler des API est un élément important quand on écrit du code sur internet. Dans cet exercice, tu vas devoir récupérer des données depuis un _endpoint_ et t'assurer que la récupération s'est bien passée.

## Objectifs

- Modifie le code fourni.
- Appelle le client HTTP et essaie de récupérer une citation. Le résultat doit être un type union composé de `string` et d'`error`.
- Si la citation est récupérée, affiche-la dans la console (avec `io:println()`).
- Si une `error` s'est produite, affiche le message d'erreur dans la console.
