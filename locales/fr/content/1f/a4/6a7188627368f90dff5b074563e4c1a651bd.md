# Les bases de la syntaxe Haskell

## Constantes et fonctions

Les programmes Haskell sont composés de définitions et d'expressions.

Une valeur constante se définit avec `name = expression`.

```haskell
five = 5

six = 3 + 3
```

Les fonctions se définissent avec `name parameters... = expression`, les paramètres étant séparés uniquement par des espaces.

```haskell
add number1 number2 = number1 + number2
```

Appeler une fonction est aussi une expression : on précise le nom de la fonction, puis on passe des arguments pour chacun de ses paramètres, séparés par des espaces, exactement comme pour les définitions de fonctions.

```haskell
five = add 2 3
```

On peut utiliser des parenthèses pour préciser l'ordre d'évaluation d'une expression.

```haskell
six = add 2 (1 * 4)

twelve = add 2 1 * 4
```

## Indentation / espaces significatifs

Haskell utilise les espaces et l'indentation pour délimiter le code.
***Le code qui fait partie d'une expression doit être plus indenté que le début de cette expression.***

- Les définitions de modules, d'imports et de fonctions de premier niveau doivent commencer à la colonne la plus à gauche.
- Si une expression est répartie sur plusieurs lignes, le code qui fait partie de cette expression doit être indenté sous cette expression, d'au moins un espace.
- Les parties de l'expression qui sont regroupées doivent être indentées avec le même nombre d'espaces.

```haskell
-- A function split over multiple lines, so subsequent lines must be indented
add number1 number2 =
    number1 + number2
```

https://en.wikibooks.org/wiki/Haskell/Indentation

## Modules

Les modules exportent des fonctions.
Cela signifie qu'on peut utiliser les fonctions que le module met à disposition dans sa déclaration d'export.
Un module peut aussi définir des fonctions réservées à un usage interne.
Par défaut, les fonctions qui ne sont pas explicitement exportées ne peuvent pas être utilisées depuis l'extérieur du module.

Au début d'un module, on précise le nom du module.
Si on a un fichier appelé Calculator.hs, on doit nommer le module Calculator.
Ensuite, on précise les fonctions que le module exporte, et après cela, on peut commencer à écrire les fonctions.
On commence donc par ceci.

```haskell
module Calculator ( add ) where
```

https://learnyouahaskell.github.io/modules#making-our-own-modules

## Commentaires

Un commentaire est un texte présent dans le fichier Haskell qui n'est pas interprété comme du code.
Il est surtout destiné à être lu par toi et par les autres programmeurs.
Il existe une syntaxe légère pour les commentaires sur une seule ligne, basée sur les doubles tirets.
Les commentaires multilignes sont également possibles grâce à la paire de délimiteurs d'ouverture et de fermeture `{-` et `-}`.

```haskell
-- a single line comment
-- another single line comment

{- a multiline comment
   spanning multiple lines
-}
```
