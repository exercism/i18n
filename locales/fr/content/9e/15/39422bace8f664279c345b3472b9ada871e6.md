## Booléens

Raku dispose des littéraux booléens `True` et `False`.
Dans un contexte booléen, tout ce qui est indéfini est considéré comme `False`.
Outre `Bool::False` lui-même, les valeurs définies considérées comme `False` incluent `0`, `NaN`, `()` (liste vide), `""` (chaîne vide) et les objets de type `Failure`.

L'opérateur [préfixe `?`][&prefix:<?>] force le contexte booléen sur un objet.
Son comportement est identique à celui d'un appel de la méthode [`Bool`][routine/Bool] sur cet objet.
L'opérateur [préfixe `!`][&prefix:<!>] donne l'inverse du préfixe `?`.

## Opérateurs infixes booléens

### Smartmatch

L'opérateur [infixe `~~`][&infix:<~~>], aussi appelé _smartmatch_, est un outil couramment utilisé en Raku.
Son comportement dépend de l'objet placé à droite de l'opérateur, car il s'agit d'un raccourci vers la méthode [`ACCEPTS`][routine/ACCEPTS] de cet objet.
La valeur à gauche est passée en argument à `ACCEPTS`.
Le résultat est une valeur booléenne.

### ET/OU logiques

Raku dispose des opérateurs [`&&`][&infix:<&&>]/[`and`][&infix:<and>], [`||`][&infix:<||>]/[`or`][&infix:<or>], [`//`][&infix:<//>]/[`orelse`][&infix:<orelse>] et [`^^`][&infix:<^^>]/[`xor`][&infix:<xor>] pour la logique booléenne (précédence forte et faible respectivement).
On peut les enchaîner.

```raku
1 xor 1 xor 1;
# Nil in Raku, 1 in Perl (because the latter makes the first pair false).
```

### Ternaire

Raku dispose d'un opérateur [infixe ternaire/conditionnel `?? !!`][infix-??-!!], qui s'écrit `$condition ?? $true !! $false`.

## Flux de contrôle

### if/elsif/else

Une instruction [`if`][control-if] sert à exécuter un bloc de code de façon conditionnelle.
Pour créer une instruction `if`, le mot-clé `if` est suivi d'une [expression][statements-and-expressions], puis d'un [bloc][control-block].

L'expression est évaluée dans un [contexte booléen][contexts-boolean], et le bloc est exécuté si l'expression vaut `True`.

Une instruction `if` peut être étendue avec les mots-clés [`elsif` et `else`][control-else/elsif], écrits de la même façon que `if`. Un bloc `else` s'exécute si toutes les expressions précédentes valent `False`, et un bloc `elsif` s'exécute de la même façon si sa propre expression vaut `True`.

On peut aussi utiliser `if` sous la forme de modificateur d'instruction :

```raku
say 'success' if True;
```

La forme avec modificateur d'instruction ne peut pas être utilisée avec `elsif` ni `else`.

### given/when/default

L'instruction [`given`][control-given] est le mot-clé de Raku qui sert à définir le thème courant, un peu comme `switch` le fait dans des langages tels que le C.
Les mots-clés pour chaque cas sont [`when` et `default`][control-default-and-when].

### for/while/loop

Une instruction [`for`][control-for] parcourt une liste donnée et exécute un bloc pour chaque élément présent dans cette liste.

Une instruction [`while`][control-while] exécute un bloc de façon répétée tant que son expression vaut `True`.

Une instruction [`loop`][control-loop] peut s'écrire de deux façons.
Si on ne lui donne qu'un bloc, elle exécute ce bloc de façon répétée jusqu'à ce que quelque chose interrompe explicitement la boucle.
Elle peut aussi s'écrire comme une boucle `for` de style C, avec un initialiseur, une condition et un incrément entre parenthèses avant le bloc.

```raku
loop (my $i = 0; $i < 10; $i++) {
    say $i;
}
```
