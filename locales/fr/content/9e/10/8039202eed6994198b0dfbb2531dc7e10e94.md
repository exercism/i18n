# Introduction

En plus de `cond`, Elixir fournit également la macro [`if/2`][getting-started-if], utile lorsqu'on n'a besoin de vérifier qu'une seule condition.

[`if/2`][kernel-if] accepte une condition et deux options. Elle renvoie la première option si la condition est _truthy_, et la seconde option si la condition est _falsy_.

```elixir
age = 15

if age >= 16 do
  "You are allowed to drink beer in Germany."
else
  "No beer for you!"
end

# => "No beer for you!"
```

Il est également possible d'écrire une expression `if` sur une seule ligne. Remarque la virgule qui suit la condition.

```elixir
if age > 16, do: "beer", else: "no beer"
```

Cette syntaxe est pratique pour des expressions très courtes, mais il vaut mieux l'éviter si l'expression ne tient pas sur une seule ligne.

## _Truthy_ et _falsy_

En Elixir, tous les types de données s'évaluent à une valeur _truthy_ ou _falsy_ lorsqu'ils apparaissent dans un contexte booléen (comme une expression `if`). Toutes les données sont considérées comme _truthy_, **sauf** `false` et `nil`. En particulier, les _strings_ vides, l'entier `0` et les tableaux vides sont tous considérés comme _truthy_ en Elixir.
