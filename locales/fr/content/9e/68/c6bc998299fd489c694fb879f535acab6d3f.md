# Tests

Pour utiliser l'exécuteur de tests, tu dois avoir correctement [installé Godot][installation].

## Lance les tests

L'[exécuteur de tests][test runner] sert à charger et à tester les solutions.
Pour t'en servir, télécharge-le en local puis lance-le avec `godot`.
À l'avenir, l'exécuteur de tests sera téléchargé automatiquement en même temps que les exercices quand tu utilises `exercism download`.

```bash
godot --headless -s /path/to/test_runner.gd -- <solution-slug> <path/to/solution>
```
