# Instructions supplémentaires

## Indices

Pour cet exercice, la fonctionnalité F# suivante te sera utile :

- Le type [Map](https://en.wikibooks.org/wiki/F_Sharp_Programming/Sets_and_Maps#Maps) associe des clés à des valeurs. Il est très proche du type `Dictionary<TKey, TValue>` de .NET, mais avec une différence majeure : `Map` est [immuable](https://fsharpforfunandprofit.com/posts/correctness-immutability/).
- Une [abréviation de type](https://fsharpforfunandprofit.com/posts/type-abbreviations/) sert à créer un alias descriptif pour un type plus complexe.
