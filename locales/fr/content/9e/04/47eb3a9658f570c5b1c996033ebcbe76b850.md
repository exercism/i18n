# Tests

## Teste de manière interactive

Lance ton implémentation de Common Lisp dans le répertoire de l'exercice sur lequel tu travailles (ou fais pointer le répertoire courant d'une implémentation de Common Lisp déjà lancée vers ce répertoire). 
Avec roswell, fais-le avec `ros run`.

(Tous les exemples ci-dessous supposent un exercice nommé `exercise-name`, à adapter si besoin.) 

Charge le fichier de test dans ton implémentation Lisp en cours d'exécution, par exemple `(load "exercise-name-test")`. 
(Cela chargera aussi le fichier de solution pour toi.)
Une fois le fichier de test chargé, tu peux exécuter les tests en évaluant `(exercise-name-test:run-tests)` dans le REPL.

Au fur et à mesure que tu modifies la solution que tu écris, utilise les fonctionnalités de ton éditeur pour charger les changements, ou évalue `(load "exercise-name")` pour charger ton fichier de solution.

Pense à évaluer `(exercise-name-test:run-tests)` pour relancer les tests après avoir chargé ta solution mise à jour.

## Teste en ligne de commande

Tu peux lancer les tests avec cette commande (là encore, remplace « exercise » par le nom approprié aux deux endroits)

```sh
ros run --load exercise-test.lisp --eval '(uiop:quit (if (exercise-test:run-tests) 0 1))'
```

Cette commande est plutôt lourde à utiliser.
Un contributeur a écrit quelques notes sur [comment la rendre plus facile à invoquer](https://glennj.github.io/exercism/cli).
