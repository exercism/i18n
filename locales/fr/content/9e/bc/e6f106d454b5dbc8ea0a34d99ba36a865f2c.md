# Instructions

Dans cet exercice, on travaille dans une pizzeria qui livre ses clients.

On propose trois types de pizzas :

- Margherita : \$7
- Caprese : \$9
- Formaggio : \$10

Les clients peuvent aussi choisir deux options supplémentaires pour un petit supplément :

1. Sauce supplémentaire : \$1
1. Garnitures supplémentaires : \$2

Lorsqu'un client passe une commande, des frais supplémentaires s'ajoutent s'il ne commande qu'une ou deux pizzas :

- 1 pizza : \$3
- 2 pizzas : \$2

Tu as trois tâches à réaliser, chacune portant sur des pizzas et leur prix.

## 1. Définis les types de pizzas et les options

Définis l'union discriminée `Pizza` pour représenter les types de pizzas et les deux options supplémentaires que l'on peut ajouter à une pizza :

- `Margherita`
- `Caprese`
- `Formaggio`
- `ExtraSauce`
- `ExtraToppings`

## 2. Calcule le prix d'une pizza

Implémente la fonction `pizzaPrice` pour calculer le prix d'une pizza :

```fsharp
pizzaPrice Caprese
// => 9
```

## 3. Calcule le prix d'une commande

Implémente la fonction `orderPrice` pour calculer le prix d'une commande de pizzas :

```fsharp
orderPrice [Margherita; Formaggio]
// => 19
```
