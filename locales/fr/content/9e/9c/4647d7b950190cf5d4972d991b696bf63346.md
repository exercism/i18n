# Instructions

Jen travaille dans la salle de tri d'une grande usine.
La salle de tri doit traiter tout ce qui y entre en le classant à l'aide d'une étiquette.
Jen s'occupe des éléments pré-classés comme des nombres et a besoin d'un programme pour l'aider à trier.

La plupart des valeurs primitives doivent recevoir des étiquettes simples.
Pour les nombres, elle veut des _strings_ qui disent `"This is the number 2.0"` (si le nombre valait 2).
Jen veut la même sortie pour les entiers et les nombres décimaux.

Il y a quelques interfaces `Box` qu'il faut déballer pour en récupérer le contenu.
Pour un `NumberBox`, elle veut des _strings_ qui disent `"This is a box containing the number 3.0"` (si la méthode `Number()` renvoie 3).
Pour un `FancyNumberBox`, elle veut des _strings_ qui disent `"This is a fancy box containing the number 4.0"`, mais uniquement si le type est un `FancyNumber`.

Tout ce qui est inattendu doit renvoyer `"Return to sender"`, pour que Jen puisse le renvoyer là d'où il vient.

## 1. Décris les nombres simples

Jen veut que les nombres renvoient des _strings_ comme `"This is the number 2.0"` (avec un chiffre après la virgule) :

```go
fmt.Println(DescribeNumber(-12.345))
// Output: This is the number -12.3
```

## 2. Décris une boîte de nombres

Jen veut que les boîtes de nombres renvoient des _strings_ comme `"This is a box containing the number 2.0"` (là encore, avec un chiffre après la virgule) :

```go
fmt.Println(DescribeNumberBox(numberBoxContaining{12}))
// Output: This is a box containing the number 12.0
```

## 3. Implémente une méthode qui extrait le nombre d'une boîte de nombres sophistiquée

Jen a besoin d'une fonction auxiliaire pour extraire le nombre d'un `FancyNumberBox`.
Si le `FancyNumberBox` est un `FancyNumber`, extrais sa valeur et convertis-la d'un `string` en un `int`.
Tout autre type de `FancyNumberBox` doit renvoyer 0.

```go
fmt.Println(ExtractFancyNumber(FancyNumber{"10"}))
// Output: 10
fmt.Println(ExtractFancyNumber(AnotherFancyNumber{"4"}))
// Output: 0
```

## 4. Décris une boîte de nombres sophistiquée

Si le `FancyNumberBox` est un `FancyNumber`, Jen veut des _strings_ qui disent `"This is a fancy box containing the number 4.0"`.
Tout autre type de `FancyNumberBox` doit dire `"This is a fancy box containing the number 0.0"`.

```go
fmt.Println(DescribeFancyNumberBox(FancyNumber{"10"}))
// Output: This is a fancy box containing the number 10.0
fmt.Println(DescribeFancyNumberBox(AnotherFancyNumber{"4"}))
// Output: This is a fancy box containing the number 0.0
```

REMARQUE : il faut utiliser la fonction `ExtractFancyNumber` !

## 5. Implémente `DescribeAnything` qui les utilise toutes

C'est la fonction principale dont Jen a besoin, celle qui prend n'importe quelle entrée.
`DescribeAnything` doit déléguer aux autres fonctions selon le type de la valeur passée en argument.
Plus précisément :

- `int` et `float64` doivent tous les deux déléguer à `DescribeNumber`
- `NumberBox` doit déléguer à `DescribeNumberBox`
- `FancyNumberBox` doit déléguer à `DescribeFancyNumberBox`
- tout le reste doit donner `"Return to sender"`

```go
fmt.Println(DescribeAnything(numberBoxContaining{12.345}))
// Output: This is a box containing the number 12.3
fmt.Println(DescribeAnything("some string"))
// Output: Return to sender
```
