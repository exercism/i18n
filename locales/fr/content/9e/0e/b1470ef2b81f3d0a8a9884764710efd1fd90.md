# À propos

Les [intervalles][range] représentent une séquence d'un ou plusieurs entiers consécutifs. Ils :

- sont créés avec l'[opérateur `..`][range-operator] et peuvent être aussi bien croissants que décroissants ;
- ont un pas par défaut de `1`, mais celui-ci peut être modifié avec l'[opérateur `..//`][range-operator-with-step] (depuis Elixir 1.12) ;
- incluent la première et la dernière valeur ;
- implémentent le [protocole Enumerable][enumerable] ;
- sont représentés en interne par une structure, mais peuvent être utilisés dans un filtrage par motif avec `..` ;
- peuvent être utilisés avec des entiers écrits en notation binaire, octale, hexadécimale et en notation de point de code ;
- peuvent être convertis en listes avec des fonctions telles que [`Enum.to_list/1`][enum-to-list] ou [`Enum.map/2`][enum-map].

```elixir
Enum.to_list(9..1)
# => [9, 8, 7, 6, 5, 4, 3, 2, 1]

Enum.map(?A..?F, &<<&1>>)
["A", "B", "C", "D", "E", "F"]
```
