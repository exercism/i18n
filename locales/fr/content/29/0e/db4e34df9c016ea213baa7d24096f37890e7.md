# Indices

## Général

- Essaie de découper un problème en un cas de base et un cas récursif. Par exemple, imaginons que tu veuilles compter combien de biscuits se trouvent dans le bocal à biscuits avec une approche récursive. Le cas de base est un bocal vide, qui ne contient aucun biscuit. Si le bocal n'est pas vide, alors le nombre de biscuits qu'il contient est égal à un biscuit plus le nombre de biscuits restants après en avoir retiré un.

## 1. Vérifie combien d'oiseaux sont venus aujourd'hui

- Cette tâche ne nécessite pas de récursion.
- Pour accéder au premier élément d'un tableau, on peut utiliser une expression `case`.

## 2. Incrémente le compteur du jour

- Cette tâche ne nécessite pas de récursion.
- Pour accéder au premier élément d'un tableau et au reste du tableau, on peut utiliser une expression `case`.

## 3. Vérifie s'il y a eu un jour sans oiseau

- Utilise la récursion pour parcourir les éléments du tableau jusqu'à trouver un jour où aucun oiseau n'est venu.
- Le cas de base est un tableau vide.

## 4. Calcule le nombre total d'oiseaux venus

- Utilise la récursion pour parcourir chaque élément du tableau.
- Le cas de base est un tableau vide.

## 5. Calcule le nombre de jours chargés

- Utilise la récursion pour parcourir chaque élément du tableau.
- Le cas de base est un tableau vide.
- Utilise une garde pour l'une des clauses de l'expression `case`.
