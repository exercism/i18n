# Classes

Les classes sont une unité d'organisation du code en PHP.
Le code qui représente le comportement d'un élément ou le comportement d'un processus peut être regroupé dans une classe.
Les fonctions affectées à une classe sont appelées `methods` par convention.

```php
<?php

class Door
{
    function lock()
    {
        // ...
    }

    function unlock()
    {
        // ...
    }
}
```

Les classes sont instanciées avec le mot-clé `new`, ce qui alloue de la mémoire pour l'instance de la classe et appelle le constructeur de la classe.
Une classe instanciée peut être affectée à une variable.
Pour invoquer les méthodes d'une instance de classe, on peut utiliser l'opérateur d'accès `->`.

```php
<?php

$a_door = new Door();
$a_door->lock();
$a_door->unlock();
```

Une classe instanciée peut faire référence à sa propre instance grâce à la variable spéciale `$this`.
Les classes peuvent aussi avoir des propriétés ; celles-ci se comportent comme des variables liées à l'instance de l'objet de la classe.
Ces propriétés peuvent être référencées depuis l'intérieur ou depuis l'extérieur de la classe.

```php
<?php

class Car
{
    public $color;

    function __construct($color)
    {
        $this->color = $color;
    }

    function getColor()
    {
        return $this->color;
    }
}

$a_car = new Car("red");
$a_car->color; // => "red" by accessing the property
$a_car->getColor(); // => "red" by invoking the instance method
```
