# Itération

En programmation, l'[itération][iteration] désigne le processus qui consiste à répéter un bloc de code plusieurs fois.
On peut y parvenir à l'aide de concepts comme les boucles _while_ et les boucles _until_.
On peut aussi le faire à l'aide de la récursivité, c'est-à-dire une fonction qui s'appelle elle-même.

Cependant, le plus souvent, on veut itérer sur une collection d'éléments, comme un `Array`, un `Range` ou une `String`.
En Crystal, les classes `Array` et `Range` incluent toutes les deux le module [`Enumerable`][enumerable], qui fournit un certain nombre de méthodes pour itérer sur les éléments.
Quant à la classe `String`, elle possède son propre ensemble de méthodes pour itérer sur les caractères.

Crystal n'a pas non plus d'instruction `for` comme les autres langages.
À la place, il dispose de plusieurs méthodes pour itérer.

## Itère

La façon la plus courante d'itérer sur une collection est d'utiliser la méthode [`each`][each], qui transmet chaque élément de la collection à un bloc.
Cela se fait facilement avec un `Range`.
Supposons que tu veuilles boucler entre 1 et 3 : tu peux utiliser la méthode `each` pour itérer sur ce `Range`.

```crystal
(1..3).each do |n|
  puts n
end

# Output:
# 1
# 2
# 3
```

Encore plus simple, si tu veux simplement itérer un certain nombre de fois, tu peux utiliser la méthode [`times`][times], qui existe sur la classe `Int`.

```crystal
3.times do |n|
  puts n
end

# Output:
# 0
# 1
# 2
```

## Itère sur une `String`

Une `String` est une séquence de caractères et n'appartient pas au module `Enumerable`, ce qui signifie qu'elle possède son propre ensemble de méthodes pour itérer sur les caractères.
La façon la plus courante d'itérer sur une `String` est d'utiliser la méthode [`each_char`][each_char], qui transmet chaque caractère de la `String` à un bloc.

~~~~exercism/note
La méthode `each_char` transmet un objet `Char` et non un objet `String` au bloc.
~~~~

```crystal
str = "hello"
str.each_char { |char| puts char }

# Output:
# h
# e
# l
# l
# o
```

Une autre façon d'itérer sur une `String` est d'utiliser la méthode [`each_line`][each_line].
Cette méthode sert surtout lorsqu'on lit un fichier ligne par ligne.

```crystal
str = "hello\nworld"
str.each_line do |line|
  puts line
end

# Output:
# hello
# world
```

## Itère sur un objet qui inclut le module `Enumerable`

Le module [`Enumerable`][enumerable] fournit un certain nombre de méthodes pour itérer sur les éléments d'une collection.
Les collections qui incluent le module `Enumerable` sont `Array`, `Range`, `Hash`, `Set` et d'autres ; ces dernières seront abordées dans des concepts ultérieurs.

La façon la plus courante d'itérer sur un `Array` est d'utiliser la méthode [`each`][each], qui transmet chaque élément de l'`Array` à un bloc.

```crystal
arr = [5, 2, 3]
arr.each do |element|
  puts element
end

# Output:
# 5
# 2
# 3
```

### Map

La méthode [`map`][map] est une autre façon d'itérer sur un `Array` : elle renvoie un nouveau `Array` contenant les résultats de l'application du bloc à chaque élément.
Elle est similaire à la méthode `each`, mais elle renvoie un nouveau `Array` avec les éléments transformés.
La transformation est très utile lorsqu'on veut appliquer une fonction à chaque élément de la collection, ce qui est une opération courante.

```crystal
arr = [1, 2, 3]
new_arr = arr.map do |element|
  element * 2
end

new_arr
# => [2, 4, 6]
```

Avec une structure de contrôle telle que `if`, tu peux filtrer les éléments à transformer.

```crystal
arr = [1, 2, 3]
new_arr = arr.map do |element|
  if element.odd?
    element * 2
  else
    element
  end
end

new_arr
# => [2, 2, 6]
```

### Avec l'indice

Parfois, on a besoin de connaître l'indice de l'élément sur lequel on itère ; on peut pour cela utiliser la méthode [`each_with_index`][each_with_index] ou [`map_with_index`][map_with_index].
Elle transmet chaque élément et son indice à un bloc, et la méthode accepte aussi un argument facultatif pour préciser l'indice de départ.

```crystal
arr = [1, 2, 3]
arr.each_with_index(4) do |element, index|
  puts "Element: #{element}, Index: #{index}"
end

# Output:
# Element: 1, Index: 4
# Element: 2, Index: 5
# Element: 3, Index: 6
```

À noter que la méthode [`each_char_with_index`][each_char_with_index] est également disponible pour les objets `String`.

### sum

La méthode [`sum`][sum] renvoie la somme de tous les éléments de la collection ; elle accepte aussi un bloc facultatif pour transformer les éléments avant de les additionner.
Elle accepte également un argument facultatif pour préciser la valeur initiale de la somme.

```crystal
arr = [1, 2, 3]
arr.sum
# => 6

arr.sum(2) { |n| n * 2 }
# => 14
```

### reduce

[`reduce`][reduce], ou _fold_ comme on l'appelle dans d'autres langages, est une méthode qui, avec une méthode de combinaison et une valeur initiale, combine tous les éléments de la collection.
La méthode `reduce` utilise un accumulateur qui est transmis au bloc ; cet accumulateur est le résultat de l'itération précédente.
Cela forme un processus récursif qui combine tous les éléments de la collection.

```crystal
arr = [1, 2, 3]
arr.reduce(0) do |acc, n|
  acc + n
end
# => 6
```

`reduce` peut sembler similaire à `sum`, mais `reduce` est plus flexible, car il permet de préciser la valeur initiale de l'accumulateur et la méthode de combinaison.
`reduce` peut servir à implémenter `sum`, `count` et d'autres méthodes.
