# Instructions

Dans cet exercice, tu vas implémenter la logique de quête d'un nouveau jeu de rôle que développe un ami.
Le personnage principal du jeu est Annalyn, une jeune fille courageuse accompagnée d'un chien de compagnie féroce et fidèle.
Malheureusement, le malheur frappe : son meilleur ami a été enlevé alors qu'il cherchait des baies dans la forêt.
Annalyn va tenter de retrouver et de libérer son meilleur ami, en emmenant éventuellement son chien avec elle dans cette quête.

Après avoir suivi pendant un moment la piste de son meilleur ami, elle trouve le camp où celui-ci est retenu prisonnier.
Il s'avère qu'il y a deux ravisseurs : un puissant chevalier et un archer rusé.

Ayant trouvé les ravisseurs, Annalyn réfléchit aux actions suivantes qu'elle peut entreprendre :

- _Attaque rapide_ : une attaque rapide est possible si le **chevalier** est **_endormi_**, car il lui faut du temps pour enfiler son armure, ce qui le rend vulnérable.
- _Espionnage_ : on peut espionner le groupe si **au moins un** de ses membres est **_éveillé_**. Sinon, espionner est une perte de temps.
- _Signaler au prisonnier_ : on peut signaler sa position au prisonnier à l'aide de cris d'oiseaux si le **prisonnier** est **_éveillé_** et que l'**archer** est **_endormi_**, car les archers sont formés au signalement par les oiseaux et pourraient donc intercepter le message.
- _Libérer le prisonnier_ : Annalyn peut tenter de s'introduire discrètement dans le camp pour libérer le prisonnier.
  C'est une entreprise risquée qui ne peut réussir que de deux façons :
  - Si Annalyn a son chien avec elle, elle peut sauver le prisonnier si l'**archer** est **_endormi_**.
    Le chevalier a peur du chien et l'archer n'aura pas le temps de se préparer avant qu'Annalyn et le prisonnier ne s'échappent.
  - Si Annalyn n'a pas son chien, elle et le prisonnier doivent être très discrets !
    Annalyn peut libérer le prisonnier si le **prisonnier** est **_éveillé_** et que le **chevalier** et l'**archer** sont tous les deux **_endormis_**, mais si le **prisonnier** est **_endormi_**, il ne peut pas être sauvé : le prisonnier serait surpris par l'apparition soudaine d'Annalyn et réveillerait le chevalier et l'archer.

Tu as quatre tâches : implémenter la logique qui détermine si les actions ci-dessus sont disponibles, en fonction de l'état des trois personnages présents dans la forêt et de la présence ou non du chien d'Annalyn.

## 1. Vérifie si l'action « Attaque rapide » est possible

Implémente une fonction nommée `canFastAttack` qui prend une valeur booléenne indiquant si le chevalier est éveillé.
Cette fonction renvoie `true` si l'action « Attaque rapide » est disponible en fonction de l'état du personnage.
Sinon, elle renvoie `false` :

```php
<?php
$is_knight_awake = true;

$infiltration = new AnnalynsInfiltration();
$infiltration->canFastAttack($is_knight_awake);
// => false
```

## 2. Vérifie si l'action « Espionnage » est possible

Implémente une fonction nommée `canSpy` qui prend trois valeurs booléennes, indiquant si le chevalier, l'archer et le prisonnier, respectivement, sont éveillés.
La fonction renvoie `true` si l'action « Espionnage » est disponible en fonction de l'état des personnages.
Sinon, elle renvoie `false` :

```php
<?php
$is_knight_awake = false;
$is_archer_awake = true;
$is_prisoner_awake = false;

$infiltration = new AnnalynsInfiltration();
$infiltration->canSpy($is_knight_awake, $is_archer_awake, $is_prisoner_awake);
// => true
```

## 3. Vérifie si l'action « Signaler au prisonnier » est possible

Implémente une fonction nommée `canSignal` qui prend deux valeurs booléennes, indiquant si l'archer et le prisonnier, respectivement, sont éveillés.
La fonction renvoie `true` si l'action « Signaler au prisonnier » est disponible en fonction de l'état des personnages.
Sinon, elle renvoie `false` :

```php
<?php
$is_archer_awake = false;
$is_prisoner_awake = true;

$infiltration = new AnnalynsInfiltration();
$infiltration->canSignal($is_archer_awake, $is_prisoner_awake);
// => true
```

## 4. Vérifie si l'action « Libérer le prisonnier » est possible

Implémente une fonction nommée `canLiberate` qui prend quatre valeurs booléennes.
Les trois premiers paramètres indiquent si le chevalier, l'archer et le prisonnier, respectivement, sont éveillés.
Le dernier paramètre indique si le chien d'Annalyn est présent.
La fonction renvoie `true` si l'action « Libérer le prisonnier » est disponible en fonction de l'état des personnages et de la présence du chien d'Annalyn.
Sinon, elle renvoie `false` :

```php
<?php
$is_knight_awake = false;
$is_archer_awake = true;
$is_prisoner_awake = false;
$is_dog_present = false;

$infiltration = new AnnalynsInfiltration();
$infiltration->canLiberate(
    $is_knight_awake,
    $is_archer_awake,
    $is_prisoner_awake,
    $is_dog_present
);
// => false
```
