# Instructions

Dans cet exercice, tu vas organiser des courses entre différents types de voitures télécommandées. Chaque voiture a ses propres caractéristiques de vitesse et de consommation de batterie.

Les voitures démarrent avec une batterie pleine (100 %). Chaque fois que tu conduis la voiture avec la télécommande, elle parcourt un nombre de mètres égal à la vitesse de la voiture, et le pourcentage de batterie restant diminue de sa consommation de batterie.

Si la batterie d'une voiture est inférieure à son pourcentage de consommation de batterie, on ne peut plus la conduire.

Chaque circuit a sa propre distance. On teste les voitures en vérifiant si elles peuvent terminer le circuit sans épuiser leur batterie.

Tu as six tâches, et chacune d'elles travaille avec des instances de voiture télécommandée.

## 1. Crée une voiture télécommandée

Permets de créer une voiture télécommandée en définissant un constructeur pour la classe `NeedForSpeed`, qui prend en paramètres la vitesse de la voiture en mètres et le pourcentage de consommation de batterie (tous deux de type `int`) :

```java
int speed = 5;
int batteryDrain = 2;
var car = new NeedForSpeed(speed, batteryDrain);
```

## 2. Crée un circuit

Permets de créer un circuit en définissant un constructeur pour la classe `RaceTrack`, qui prend comme unique paramètre la distance du circuit en mètres (de type `int`) :

```java
int distance = 800;
var raceTrack = new RaceTrack(distance);
```

## 3. Conduis la voiture

Implémente la méthode `NeedForSpeed.drive()` qui met à jour le nombre de mètres parcourus en fonction de la vitesse de la voiture. Implémente aussi la méthode `NeedForSpeed.distanceDriven()` qui renvoie le nombre de mètres parcourus par la voiture :

```java
int speed = 5;
int batteryDrain = 2;
var car = new NeedForSpeed(speed, batteryDrain);
car.drive();

car.distanceDriven();
// => 5
```

## 4. Vérifie si la batterie est déchargée

Modifie la méthode `NeedForSpeed.drive()` pour qu'elle décharge la batterie en fonction de la consommation de batterie de la voiture. Implémente aussi la méthode `NeedForSpeed.batteryDrained()` qui indique si la batterie est trop déchargée pour conduire :

```java
int speed = 5;
int batteryDrain = 2;
var car = new NeedForSpeed(speed, batteryDrain);
car.drive();

car.batteryDrained();
// => false
```

## 5. Crée la voiture télécommandée Nitro

La voiture télécommandée la plus vendue est la Nitro, qui atteint une vitesse de pointe impressionnante de 50 mètres, avec une consommation de batterie de 4 %. Implémente la méthode (statique) `NeedForSpeed.nitro()` qui renvoie ce type de voiture :

```java
var car = NeedForSpeed.nitro();
car.drive();
car.distanceDriven();
// => 50
```

## 6. Vérifie si une voiture télécommandée peut terminer une course

Pour terminer une course, une voiture doit pouvoir parcourir la distance de la course. Cela signifie qu'elle ne doit pas décharger sa batterie avant d'avoir franchi la ligne d'arrivée. Implémente la méthode `RaceTrack.canFinishRace()` qui prend en paramètre une instance de `NeedForSpeed` et renvoie `true` si la voiture peut terminer la course ; sinon, elle renvoie `false` :

```java
int speed = 5;
int batteryDrain = 2;
var car = new NeedForSpeed(speed, batteryDrain);

int distance1 = 100;
var race1 = new RaceTrack(distance1);

int distance2 = 300;
var race2 = new RaceTrack(distance2);

race1.canFinishRace(car);
// => true

race2.canFinishRace(car);
// => false
```
