# À propos

[OCaml](https://ocaml.org/) est un langage de programmation de qualité industrielle qui prend en charge les styles fonctionnel, impératif et orienté objet. Pas d'inquiétude si ces notions ne te sont pas familières : c'est un langage utilisé pour l'enseignement dans de nombreuses institutions (dont Cornell et Princeton).

L'une des meilleures caractéristiques d'OCaml est son [système de types](https://en.wikipedia.org/wiki/Type_system) riche et puissant : il permet de détecter certaines erreurs très tôt, ce qui épargne aux développeurs d'immenses frustrations.
De plus, l'[inférence de types](https://en.wikipedia.org/wiki/Type_inference) dispense les développeurs de préciser les types dans le code : le compilateur s'en charge pour toi !

Il est utilisé par Facebook (pour l'analyse statique de code avec [Infer](http://fbinfer.com/)) et Jane Street (pour offrir de solides garanties à leurs systèmes de trading internes), et il a influencé le [langage de programmation fonctionnel F#](https://fsharp.org/) et [ReasonML](https://reasonml.github.io/).
