# À propos des boucles for-each

La [boucle `for-each`](https://docs.oracle.com/javase/tutorial/java/nutsandbolts/for.html) permet d'exécuter un bloc de code pour chaque élément d'une collection.
Certaines documentations (comme celle d'Oracle) les appellent des boucles `for` améliorées.

Voici la syntaxe générale :

```java
for(declaration: collection) {
    body;
}
```

La partie `declaration` déclare la variable qui recevra les valeurs issues de la collection.

La partie `collection` est un tableau ou une collection qui contient les valeurs qui seront affectées à la variable de boucle.

La partie `body` contient les instructions qui seront exécutées une fois pour chaque valeur de la collection.

Par exemple :

```java
char[] vowels = {'a', 'e', 'i', 'o', 'u'};

for(char vowel: vowels) {
    System.out.println(vowel);
}
```

ce qui affiche :

```text
a
e
i
o
u
```

En général, une boucle `for-each` est préférable à une boucle `for` pour les raisons suivantes :

- Une boucle `for-each` parcourt _toutes_ les valeurs, sans exception.
- Une boucle `for-each` est plus _déclarative_ : le code exprime _ce qu'il fait_ plutôt que _comment il le fait_.
- Une boucle `for-each` est infaillible, alors qu'avec une boucle `for`, il est facile de se tromper d'une unité (pense à `<` par rapport à `<=`).
- Une boucle `for-each` fonctionne avec tous les types de collections, y compris ceux qui ne permettent pas d'utiliser un indice pour accéder aux éléments (par exemple un `Set`).
