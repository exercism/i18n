# Tests

## Exécute les tests

Pour exécuter les tests, lance la commande suivante :

```bash
bats test-<exercise-slug>.bats
```

### bats est implémenté en bash

Le fichier bats est un script bash, avec quelques fonctions spéciales reconnues par la commande `bats`.
Tu verras des tests qui ressemblent à ceci :

```bash
sed -E -f <exercise-slug>.sed <<< "$input"
```

Cette syntaxe `<<<` est une *Here String* de bash.
Elle envoie la chaîne située à droite vers l'entrée standard du programme situé à gauche.
C'est à peu près équivalent à

```bash
echo "$input" | sed -E -f <exercise-slug>.sed
```

## Tests ignorés

Résoudre un exercice, c'est faire passer tous ses tests.
Par défaut, un seul test (le premier) est exécuté quand tu lances les tests.
C'est intentionnel : cela te permet de te concentrer sur ce seul test pour le faire passer.
Une fois qu'il passe, tu peux activer le test suivant en commentant ou en supprimant l'

    [[ $BATS_RUN_SKIPPED == true ]] || skip

annotation qui précède les autres tests.

## Passe outre les tests ignorés

Pour exécuter tous les tests, y compris ceux qui portent une annotation `skip`, tu peux lancer :

```bash
BATS_RUN_SKIPPED=true bats test-<exercise-slug>.bats
```

ou bien tu peux commenter ou supprimer la ligne :

```bash
[[ $BATS_RUN_SKIPPED == "true" ]] || skip
```

du fichier de test.
