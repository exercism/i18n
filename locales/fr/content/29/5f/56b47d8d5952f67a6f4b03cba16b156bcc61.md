# À propos

Les _strings_ en F# sont des objets immuables qui représentent du texte sous la forme d'une séquence de caractères Unicode (lettres, chiffres, ponctuation, etc.). On utilise des guillemets doubles pour définir une instance de `string` :

```fsharp
let fruit = "Apple"
```

Pour manipuler une _string_, on peut appeler l'une de ses [méthodes][methods] ou l'une de ses [propriétés][properties], ou bien utiliser l'une des fonctions du [module `String`][string-module]. Comme les valeurs de type _string_ ne peuvent jamais changer une fois définies, toutes les méthodes et fonctions de manipulation de chaînes renvoient une nouvelle _string_.

Une _string_ est délimitée par des guillemets doubles (`"`). Certains caractères spéciaux doivent être [échappés][escaping] à l'aide du caractère barre oblique inverse (`\`). Les _strings_ peuvent aussi être préfixées par le symbole arobase (`@`), ce qui en fait une [chaîne verbatim][verbatim] qui ignore les caractères échappés.

```fsharp
let escaped = "c:\\test.txt"
let verbatim = @"c:\test.txt"
escaped = verbatim
// => true
```

Sinon, on peut définir des _strings_ à l'aide de [guillemets triples][triple-quoted] (`"""`), ce qui permet d'utiliser un guillemet double dans la chaîne sans devoir l'échapper.

```fsharp
let tripledQuoted = """<movie title="Se7en" />"""
// => "<movie title="Se7en" />
```

Enfin, on peut concaténer des _strings_ à l'aide de l'[opérateur `+`][plus-operator] :

```fsharp
let name = "Jane"
"Hello " + name + "!"
// => "Hello Jane!"
```
