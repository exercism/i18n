# N'utilise pas d'instructions `if` imbriquées

Essaie de réécrire les instructions `if` pour éviter une imbrication trop profonde, car cela peut donner du code plus difficile à suivre. Voyons les deux extraits de code suivants :

```csharp
void PrintName(Person p)
{
    if (p != null)
    {
        if (p.Name != null)
        {
            if (p.Age >= 21)
            {
                Console.WriteLine(p.Name);
            }
        }
    }
}
```

Compare maintenant avec le code suivant :

```csharp
void PrintName(Person p)
{
  if (p == null || p.Name == null || p.Age < 21)
  {
      return;
  }

  Console.WriteLine(p.Name);
}
```

Le deuxième exemple a une structure très particulière : tous les chemins qui traitent des erreurs sont gérés dans des blocs indentés, tandis que le « happy path » reste toujours aligné le plus à gauche. La lecture en devient très facile, car on voit d'un coup d'œil quel est le chemin le plus courant, celui sans erreur, à travers le code.
