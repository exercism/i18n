- Le code fourni dans les espaces de noms de la famille doit être considéré comme une donnée de base et ne pas être modifié.
- Ne recopie pas les valeurs dans le code, appelle les méthodes.

## 1. Prends place devant les familles et étale tes papiers

- L'espace de noms doit s'appeler `EstateExecutor` pour que ta solution réussisse les tests.

## 2. Trouve le numéro de compte secret

Chaque `bank_number_part` doit être appelé avec le `secret_modifier` de la liste de paramètres.

## 3. Dernière étape : saisis le code secret
