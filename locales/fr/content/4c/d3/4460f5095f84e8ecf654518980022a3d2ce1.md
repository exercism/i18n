# Introduction

De nombreux programmes ont besoin de valeurs (pseudo-)aléatoires pour simuler des événements du monde réel.

Voici des exemples courants et familiers :

- Un lancer de pièce : une valeur aléatoire parmi ('H', 'T').
- Le lancer d'un dé : un entier aléatoire de 1 à 6.
- Le mélange d'un jeu de cartes : un ordre aléatoire d'une liste de cartes.
- La création d'arbres et de buissons dans une simulation graphique 3D.

Générer de véritablement aléatoires avec un ordinateur est un [défi technique étonnamment difficile][why-randomness-is-hard], c'est pourquoi il existe aussi des générateurs « pseudo-aléatoires ».

## Génère des nombres aléatoires

En JavaScript, tu peux générer des nombres pseudo-aléatoires en utilisant la fonction [`Math.random()`][Math.random].
Elle renvoie un nombre à virgule flottante pseudo-aléatoire entre 0 (inclus) et 1 (exclu).

Pour obtenir un nombre aléatoire entre _min_ (inclus) et _max_ (exclus), tu peux utiliser une fonction comme celle-ci :

```javascript
function getRandomInRange(min, max) {
  return min + Math.random() * (max - min);
}
getRandomInRange(4, 10);
// => 5.72
```

## Génère des nombres entiers aléatoires

Pour générer un entier aléatoire, tu peux utiliser `Math.floor()` ou `Math.ceil()` pour transformer un nombre généré aléatoirement en entier.
