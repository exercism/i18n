# Installation

La distribution Racket peut être téléchargée depuis https://download.racket-lang.org

Des programmes d'installation sont fournis pour

* Windows
* Linux
* macOS

Consulte la page [Getting Started](http://docs.racket-lang.org/getting-started/) de Racket pour des ressources d'aide.

Le [Racket Guide](https://docs.racket-lang.org/guide/intro.html) t'initie à l'interaction avec Racket.

Consulte [DrRacket: The Racket Programming Environment](https://docs.racket-lang.org/drracket/index.html) pour savoir comment utiliser l'IDE DrRacket.

Consulte [Command-Line Tools and Your Editor of Choice](https://docs.racket-lang.org/guide/other-editors.html) pour une introduction aux outils en ligne de commande de Racket et à l'utilisation d'autres éditeurs.


## À propos de l'installateur Linux :
La version Linux est suffisamment générique pour fonctionner sur la plupart des distributions, y compris des distributions relativement anciennes.

Après avoir téléchargé le fichier d'installation, exécute-le avec
```
sh racket-8.10-x86_64-linux-cs.sh
```

Il faudra peut-être faire précéder la commande de `sudo` pour installer dans un emplacement qui nécessite les droits d'administrateur.

**Attention : Racket est peut-être aussi disponible via le gestionnaire de paquets de ta distribution, même s'il peut s'agir d'une version plus ancienne que la dernière version de Racket.**
Tu pourras toujours faire ce choix plus tard, mais en tant qu'apprenant, ton expérience sera bien meilleure si tu utilises la version actuelle disponible sur https://download.racket-lang.org


## À propos de l'installateur macOS :

Si ta machine utilise un processeur de la série M1 ou M2, sélectionne **Apple Silicon** dans le menu déroulant des plateformes avant de télécharger.
