# À propos

Les [_cons_][hyper-conses] sont un type de données de base en Common Lisp. Ils sont composés d'une tête et d'une queue (appelées, pour des [raisons historiques][history], le `car` et le `cdr`). 
Il n'y a aucune restriction sur les types de données de la tête et de la queue d'un _cons_.

Les _cons_ sont créés avec la fonction [`cons`][hyper-cons], qui prend deux objets et renvoie un _cons_ (parfois aussi appelé une « cellule _cons_ »).

Les parties d'un _cons_ sont accessibles avec les fonctions [`car`][hyper-car] et [`cdr`][hyper-cdr].

## Référence

```lisp
;; Testing for atoms
(atom 'foo)              ; => T
(atom '(bar baz))        ; => NIL

;; Testing for cons
(consp 'foo)             ; => NIL
(consp '(bar baz))       ; => T

;; First item of a cons
(car '(one two three))   ; => ONE
(first '(one two three)) ; => ONE

;; Rest of a cons
(cdr '(one two three))   ; => (TWO THREE)
(rest '(one two three))  ; => (TWO THREE)
```
