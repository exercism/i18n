# Indices

## 1. Remplace tous les espaces rencontrés par des tirets bas

- La [documentation de référence][char-docs] pour les `char` se trouve ici.
- Tu peux récupérer les `char` d'une _string_ de la même façon que les éléments d'un tableau, même si dans cet exercice il vaut peut-être mieux utiliser une fonction d'ordre supérieur comme `String.collect`.
- Les littéraux `char` s'écrivent entre apostrophes.

## 2. Supprime tous les espaces blancs

- Voir [cette méthode][iswhitespace] pour détecter les espaces et [cette méthode][isnumber] pour les chiffres.

## 3. Convertis le `camelCase` en `kebab-case`

- Voir [cette méthode][tolower] pour convertir un caractère en minuscule.

## 5. Omets les lettres grecques minuscules

- Les `char` prennent en charge les opérateurs d'égalité et de comparaison par défaut.
