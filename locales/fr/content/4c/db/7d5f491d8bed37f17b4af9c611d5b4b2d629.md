# Introduction

## Ensembles

Un ensemble est une collection immuable et non ordonnée de valeurs uniques. Tous les éléments d'un ensemble doivent être du même type.

Le module `gleam/set` définit le type `Set` et fournit des fonctions pour manipuler les ensembles.

On peut convertir des listes en ensembles, et inversement, avec `set.to_list` et `set.from_list`. L'ordre des éléments d'un ensemble n'est pas garanti.

```gleam
set.from_list([2, 3, 3, 3, 1, 1, 2])
// -> set.from_list([1, 2, 3])

set.to_list(set.from_list([2, 3, 3, 3, 1, 1, 2]))
// -> [1, 2, 3]
```

On peut créer et remplir des ensembles avec `set.new`, `set.insert` et `set.delete`.

```gleam
set.new()
// -> set.from_list([])

let eighty_eight = set.from_list([88])

set.insert(eighty_eight, 88)
// -> set.from_list([88])

set.insert(eighty_eight, 89)
// -> set.from_list([88, 89])

set.delete(eighty_eight, 89)
// -> set.from_list([88])
```

On peut interroger le contenu d'un ensemble avec les fonctions `set.contains` et `set.size`.

```gleam
set.contains(eighty_eight, 88)
// -> True

set.size(eighty_eight)
// -> 1
```

On peut combiner des ensembles avec `set.union` et `set.intersection`.

```gleam
let a = set.from_list([1, 5, 10])
let b = set.from_list([1, 2, 3, 4, 5])

set.union(a, b)
// -> set.from_list([1, 2, 3, 4, 5, 10])

set.intersection(a, b)
// -> set.from_list([1, 5])
```

On peut filtrer des ensembles.

```gleam
let is_small = fn(n) { n <= 3 }

set.filter(b, is_small)
// -> set.from_list([1, 2, 3])
```
