# Instructions

Tu viens de commencer à travailler à l'accueil d'une salle d'escalade.
Les membres achètent des abonnements pour un certain nombre de mois et enregistrent leur entrée et leur sortie à chaque visite.
Le gérant t'a demandé d'écrire un assistant qui répond aux questions que les membres posent le plus souvent.

## 1. Calculer la date de fin d'un abonnement

Un abonnement qui commence à une date donnée se termine le même jour du mois, le nombre de mois indiqué plus tard.
Si ce jour n'existe pas dans le mois de fin, l'abonnement se termine le dernier jour de ce mois.

Implémente la méthode `FrontDesk.membershipEnd()` qui prend la date de début d'un abonnement et son nombre de mois, et renvoie la date à laquelle il se termine :

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.membershipEnd(LocalDate.of(2024, 3, 10), 1);
// => LocalDate.of(2024, 4, 10)
frontDesk.membershipEnd(LocalDate.of(2025, 1, 31), 1);
// => LocalDate.of(2025, 2, 28)
```

## 2. Afficher la durée d'un abonnement

Sur la carte de membre, la salle indique la durée de l'abonnement en années, en mois et en jours.

Implémente la méthode `FrontDesk.membershipLength()` qui prend la date de début et la date de fin d'un abonnement, et renvoie la durée de l'abonnement sous forme de `Period` :

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.membershipLength(LocalDate.of(2023, 3, 10), LocalDate.of(2024, 5, 25));
// => Period.of(1, 2, 15)
```

## 3. Compter les jours restants d'un abonnement

Les membres demandent souvent combien de jours il leur reste avant la fin de leur abonnement.

Implémente la méthode `FrontDesk.daysLeft()` qui prend la date du jour et la date de fin d'un abonnement, et renvoie le nombre total de jours entre aujourd'hui et la date de fin.
Quand la date de fin est aujourd'hui ou est déjà passée, il ne reste aucun jour, et la méthode renvoie `0` :

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.daysLeft(LocalDate.of(2024, 1, 15), LocalDate.of(2024, 3, 20));
// => 65
frontDesk.daysLeft(LocalDate.of(2024, 4, 2), LocalDate.of(2024, 3, 20));
// => 0
```

## 4. Mesurer une visite

La salle est ouverte 24 heures sur 24, et le tourniquet enregistre la date et l'heure auxquelles un membre entre et sort.

Implémente la méthode `FrontDesk.visitDuration()` qui prend les date-heures d'entrée et de sortie d'une visite, et renvoie la durée de la visite sous forme de `Duration` :

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.visitDuration(LocalDateTime.of(2024, 3, 10, 23, 30), LocalDateTime.of(2024, 3, 11, 1, 15));
// => Duration.ofMinutes(105)
```

## 5. Imprimer une visite sur le ticket

Le ticket indique la durée d'une visite en heures et en minutes, par exemple `1h 35m`.
Les minutes s'écrivent toujours avec deux chiffres, les secondes éventuelles sont ignorées, et les heures ne sont pas limitées à une seule journée.

Implémente la méthode `FrontDesk.formatVisit()` qui prend la durée d'une visite et la renvoie dans ce format :

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.formatVisit(Duration.ofMinutes(95));
// => "1h 35m"
frontDesk.formatVisit(Duration.ofHours(2).plusMinutes(5));
// => "2h 05m"
frontDesk.formatVisit(Duration.ofHours(26).plusMinutes(10));
// => "26h 10m"
```
