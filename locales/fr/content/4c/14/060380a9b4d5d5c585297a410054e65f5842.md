# Introduction

Parfois, quand on parcourt une séquence, on a besoin de la *position* de l'élément en plus de l'élément lui-même. La famille `*-index` de [`sequences`][sequences] transmet les deux à la _quotation_ par élément. `times` en est le proche cousin pour l'itération comptée toute simple, utile quand tu n'as besoin que d'un décompte, et non d'une séquence.

## `each-index` et `map-index` : l'indice dans la _quotation_

```
each-index ( seq quot: ( elt index -- )       -- )
map-index  ( seq quot: ( elt index -- newelt ) -- newseq )
```

La _quotation_ reçoit l'élément situé sous l'indice, `index` se trouvant **au sommet** de la pile :

```factor
USING: io kernel math.parser sequences ;

{ "alice" "bob" "carol" } [
    number>string ": " glue print
] each-index
! prints:
! alice: 0
! bob:   1
! carol: 2

{ 10 20 30 } [ + ] map-index .
! => { 10 21 32 }       (index added to each element)
```

`each-index` exécute la _quotation_ pour son effet de bord et ne renvoie rien. `map-index` rassemble les résultats de chaque élément dans une nouvelle séquence du même type que l'entrée.

## `times` : l'itération comptée

`times` (dans [`math`][math]) exécute sa _quotation_ `n` fois.

```
times ( n quot: ( -- ) -- )
```

La forme publiée `( -- )` est le *minimum* : comme `times` est `inline`, une _quotation_ dont les effets sont équilibrés, comme `( str -- str )`, fonctionne très bien, et la pile est transmise d'une itération à l'autre. Cela te donne un accumulateur compté sans aucun état mutable :

```factor
USING: kernel sequences ;

"" 3 [ "clop " append ] times .    ! => "clop clop clop "
```

Le corps de chaque itération voit la _string_ courante, y ajoute du texte et laisse la nouvelle _string_ sur la pile pour l'itération suivante. La même astuce fonctionne avec `each-index` et `map-index` quand tu veux y faire circuler un accumulateur.
