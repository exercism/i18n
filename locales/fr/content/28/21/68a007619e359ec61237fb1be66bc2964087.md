## Messages d'erreur

Il est parfois nécessaire de [lever une exception](https://docs.python.org/3/tutorial/errors.html#raising-exceptions). Dans ce cas, tu dois toujours inclure un **message d'erreur explicite** qui indique l'origine de l'erreur. Cela rend le code plus lisible et facilite grandement le débogage. Si tu sais que l'erreur provient d'un type précis, tu peux choisir de lever l'un des [types d'erreur intégrés](https://docs.python.org/3/library/exceptions.html#base-classes), mais tu dois tout de même y joindre un message explicite.

Cet exercice demande en particulier d'utiliser l'[instruction `raise`](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement) pour « lever » une `ValueError` si la `matrix` est irrégulière. Les tests ne passeront que si tu lèves l'`exception` avec `raise` et que tu y joins un message.

Pour lever une `ValueError` avec un message, écris ce message en argument du type de l'`exception` :

```python
# if the matrix is irregular
raise ValueError("irregular matrix")
```
