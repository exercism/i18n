# Indices

## Général

- La documentation sur [l'instruction `using`][using-statement] décrit comment et quand utiliser le mot-clé `using`.

## 1. Écris dans la base de données

- Examine les différentes méthodes de la base de données, ainsi que les états dans lesquels celle-ci passe avec chacune d'elles.

## 2. Écris dans la base de données et renvoie à l'appelant une indication précisant si l'opération d'écriture a réussi

- L'utilisation des [`exceptions`][try-catch] est nécessaire dans ce cas.
