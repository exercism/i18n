# Introduction

En Ruby, les **tableaux** sont des collections ordonnées, indexées par des entiers, de n'importe quel objet.
Les indices d'un tableau commencent à `0`.
Un indice négatif est considéré comme relatif à la fin du tableau, c'est-à-dire qu'un indice de `-1` désigne le dernier élément du tableau, `-2` l'avant-dernier élément, et ainsi de suite.
Les tableaux Ruby intègrent le [module Enumerable][enumerable-module], qui ajoute plusieurs méthodes de parcours et de recherche, ainsi que la possibilité de trier.

## Crée un tableau

- Un tableau en Ruby peut contenir des objets de types différents.

```ruby
array = [1, "two", 3.0] #=> [1, "two", 3.0]
```

## Affectation d'éléments

On peut accéder aux éléments ou les modifier à l'aide d'indices.
On peut accéder à des sous-tableaux en précisant un indice de départ et une taille.

```ruby
a = ["", "", "", "", ""]

a[4] = "hello"  #=> [nil, nil, nil, nil, "hello"]
a[0, 3] = [ 'a', 'b', 'c' ] #=> ["a", "b", "c", nil, "hello"]
```

- Les indices négatifs se comptent à rebours depuis la fin du tableau.

```ruby
a = ['a', 'b']

a[-1] = "Z"
a #=> ["a", "Z"]
```

## Référence des éléments

- On peut récupérer des éléments d'un tableau avec la méthode #[].
- Elle renvoie l'élément situé à l'indice donné, ou un sous-tableau commençant à l'indice de départ et continuant sur la longueur d'éléments indiquée.

```ruby
a = [ "a", "b", "c", "d", "e" ]

a[2]    #=> "c"
a[6]    #=> nil
a[1, 2] #=> [ "b", "c" ]
```

- Les indices négatifs se comptent à rebours depuis la fin du tableau (-1 est le dernier élément)

```ruby
a = [ "a", "b", "c", "d", "e" ]

a[-2]    #=> "d"
a[-3, 3] #=> [ "c", "d", "e" ]
```

## Obtenir des informations sur un tableau

Les tableaux connaissent à tout moment leur propre longueur.
Pour connaître le nombre d'éléments d'un tableau, utilise length, count ou size.

```ruby
browsers = ['Chrome', 'Firefox', 'Safari', 'Opera', 'IE']
browsers.length #=> 5
browsers.count  #=> 5
browsers.size   #=> 5
```

## Ajoute des éléments à un tableau

On peut ajouter des éléments à la fin d'un tableau avec `push` ou `<<` :

```ruby
arr = [1, 2, 3, 4]
arr.push(5) #=> [1, 2, 3, 4, 5]
arr << 6    #=> [1, 2, 3, 4, 5, 6]
```

## Supprime des éléments d'un tableau

La méthode pop supprime le dernier élément d'un tableau et le renvoie :

```ruby
arr = [1, 2, 3, 4, 5, 6]
arr.pop #=> 6
arr     #=> [1, 2, 3, 4, 5]
```
