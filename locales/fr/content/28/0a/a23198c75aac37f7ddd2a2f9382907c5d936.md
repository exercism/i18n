# Débogage

Contrairement à de nombreux langages, le code WebAssembly n'a pas automatiquement accès à des ressources globales telles que la console. Ce genre de fonctionnalité doit au contraire être fourni sous forme d'imports.

Afin de fournir une fonctionnalité semblable à `console.log` et quelques autres commodités, le parcours WebAssembly d'Exercism expose une bibliothèque standard de fonctions dans tous les exercices.

Ces fonctions doivent être importées en haut de ton module WebAssembly, puis peuvent être appelées depuis le code WebAssembly.

Les fonctions `log_mem_*` s'attendent à pouvoir accéder à la mémoire linéaire de ton module WebAssembly. Par défaut, il s'agit d'un état privé ; pour la rendre accessible, tu dois donc exporter ta mémoire linéaire sous le nom d'export `mem`. Voici comment procéder :

```wasm
(memory (export "mem") 1)
```

# Journalise les variables locales et globales

Nous fournissons des fonctions de journalisation pour chacun des types primitifs de WebAssembly. C'est utile pour journaliser des variables globales et locales.

## log_i32_s - Journalise un entier signé de 32 bits dans la console

```wasm
(module
  (import "console" "log_i32_s" (func $log_i32_s (param i32)))
  (func $main
    ;; logs -1
    (call $log_i32_s (i32.const -1))
  )
)
```

# Journalise depuis la mémoire linéaire

La mémoire linéaire de WebAssembly est un tableau de valeurs adressables octet par octet. Elle fait office de mémoire virtuelle pour les programmes WebAssembly.

Nous fournissons des fonctions de journalisation qui permettent d'interpréter une plage d'adresses de la mémoire linéaire comme des tableaux statiques de certains types. Cela fonctionne de manière similaire aux TypedArrays de JavaScript. Les paramètres de longueur ne sont pas mesurés en octets, mais en nombre d'éléments consécutifs du type associé à la fonction.

**Pour que ces fonctions fonctionnent, ton module WebAssembly doit déclarer et exporter sa mémoire linéaire en utilisant l'export nommé "mem"**

```wasm
(memory (export "mem") 1)
```

## log_mem_as_utf8 - Journalise une séquence de caractères UTF8 dans la console

```wasm
(module
  (import "console" "log_mem_as_utf8" (func $log_mem_as_utf8 (param $byteOffset i32) (param $length i32)))
  (memory (export "mem") 1)
  (data (i32.const 64) "Goodbye, Mars!")
  (func $main
    ;; Logs "Goodbye, Mars!" to console
    (call $log_mem_as_utf8 (i32.const 64) (i32.const 14))
  )
)
```

## log_mem_as_i8 - Journalise une séquence d'entiers signés de 8 bits dans la console

```wasm
(module
  (import "console" "log_mem_as_i8" (func $log_mem_as_i8 (param $byteOffset i32) (param $length i32)))
  (memory (export "mem") 1)
  (func $main
    (memory.fill (i32.const 128) (i32.const -42) (i32.const 10))
    ;; Logs an array of 10x -42 to console
    (call $log_mem_as_u8 (i32.const 128) (i32.const 10))
  )
)
```
