# À propos

Les booléens en Kotlin sont représentés par le type `Boolean`, dont les valeurs peuvent être `true` ou `false`.

Kotlin prend en charge trois [opérateurs booléens][reference] intégrés : `!` (négation, aussi appelée NON), `&&` (conjonction paresseuse, aussi appelée ET) et `||` (disjonction paresseuse, aussi appelée OU). Les opérateurs `&&` et `||` utilisent l'_évaluation par court-circuit_, ce qui signifie que le membre de droite de l'opérateur n'est évalué que lorsque c'est nécessaire.

```kotlin
true || false // => true
true && false // => false
```

Les trois opérateurs booléens ont chacun une [_priorité d'opérateur_][precedence] différente. Par conséquent, ils sont évalués dans cet ordre : `!` en premier, `&&` en deuxième, et enfin `||`. Si tu veux t'affranchir de ces règles, tu peux entourer une expression booléenne de parenthèses (`()`), car les parenthèses ont une priorité encore plus élevée.

```kotlin
!true && false   // => false
!(true && false) // => true
```

[reference]: https://kotlinlang.org/docs/reference/basic-types.html#booleans
[precedence]: https://kotlinlang.org/docs/reference/grammar.html#expressions
