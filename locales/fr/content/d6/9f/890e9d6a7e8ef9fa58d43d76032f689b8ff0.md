# Instructions

Ta tâche consiste à écrire le code qui calcule les points d'énergie attribués aux joueurs lorsqu'ils terminent un niveau.

Les points attribués dépendent de deux choses :

- Le niveau (un nombre) que le joueur a terminé.
- La valeur de base de chaque objet magique collecté par le joueur pendant ce niveau.

Les points d'énergie sont attribués selon les règles suivantes :

1. Pour chaque objet magique, prends la valeur de base et trouve tous les multiples de cette valeur qui sont inférieurs au numéro du niveau.
2. Combine les ensembles de nombres.
3. Supprime les doublons.
4. Calcule la somme de tous les nombres restants.

Prenons un exemple :

**Le joueur a terminé le niveau 20 et a trouvé deux objets magiques dont les valeurs de base sont 3 et 5.**

Pour calculer les points d'énergie gagnés par le joueur, il faut trouver tous les multiples uniques de ces valeurs de base qui sont inférieurs au niveau 20.

- Multiples de 3 inférieurs à 20 : `{3, 6, 9, 12, 15, 18}`
- Multiples de 5 inférieurs à 20 : `{5, 10, 15}`
- Combine les ensembles et supprime les doublons : `{3, 5, 6, 9, 10, 12, 15, 18}`
- Additionne les multiples uniques : `3 + 5 + 6 + 9 + 10 + 12 + 15 + 18 = 78`
- Le joueur gagne donc **78** points d'énergie pour avoir terminé le niveau 20 et trouvé les deux objets magiques dont les valeurs de base sont 3 et 5.
