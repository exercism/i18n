# Ajout aux instructions

## Instructions complémentaires

On te fournit une table nommée « isogram ».
La première colonne, « phrase », contient du texte.
Tu dois déterminer si la phrase est un isogramme.
Mets à jour la deuxième colonne, « is_isogram », avec une valeur entière :

* 1 si la phrase est un isogramme,
* 0 sinon.

~~~~exercism/note
Les opérations de comparaison de SQLite renvoient des valeurs booléennes sous la forme de nombres 0/1.

```sh
$ sqlite3
sqlite> .mode table
sqlite> SELECT 1 < 2 AS "true", 1 > 2 AS "false";
+------+-------+
| true | false |
+------+-------+
| 1    | 0     |
+------+-------+
```
