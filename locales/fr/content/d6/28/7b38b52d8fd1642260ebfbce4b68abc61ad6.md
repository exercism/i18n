# Indices

## Général

- Dans cet exercice, on travaille avec des données textuelles et des tableaux. Les valeurs `Text` d'Unison peuvent être décomposées en un tableau de `Char`, puis recomposées en `Text`. L'UCM propose une fonctionnalité de « recherche par type » qui peut être utile pour trouver les fonctions pertinentes.
- Essaie de saisir `find : Text -> [Char]` dans la ligne de commande de l'UCM pour voir ce qui ressort. C'est le deux-points `:` qui indique qu'on recherche par type plutôt que par nom. [En savoir plus sur la commande `find`.](https://www.unison-lang.org/learn/ucm-commands/#find)
- Tu peux aussi parcourir en ligne les fonctions du type `Text` et les fonctions du type `List` sur [Unison share.](https://share.unison-lang.org/@unison/code/latest/namespaces/public/base/latest)
