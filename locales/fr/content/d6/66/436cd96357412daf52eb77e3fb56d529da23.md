# Introduction

Le module `Time` sert à afficher des dates et des heures lisibles par un humain.
S'il est techniquement possible de manipuler des dates et des heures avec `Time`, la communauté Elm propose des paquets bien mieux adaptés à cette tâche, comme [`justinmimbs/date`][date] ou [`CoderDennis/elm-time-format`][elm-time-format].

## Posix

Les instants sont représentés par le type opaque `Posix`, qui encapsule le temps epoch Unix, à savoir le nombre de millisecondes écoulées depuis le 1er janvier 1970 à minuit UTC.
Un `Posix` est une valeur non ambiguë qui ne varie pas d'un fuseau horaire à l'autre : c'est donc un bon choix pour conserver des instants.
Dans une application Elm, les valeurs `Posix` proviennent généralement de sources externes, comme le navigateur.

Il est possible de transformer un `Posix` en un nombre de millisecondes, et inversement, avec les fonctions suivantes :

```elm
posixToMillis : Posix -> Int
millisToPosix : Int -> Posix
```

## Fuseaux horaires

Dans la vie de tous les jours, on ne lit généralement pas de `Posix` : on préfère l'heure locale, qui dépend de notre position sur Terre et des règles locales d'heure d'été.
En Elm, ces informations sont encodées dans le type opaque `Zone`, lui aussi généralement fourni par le navigateur.

Il existe une `Zone` particulière, toujours accessible :

```elm
utc : Zone
```

## Les heures lisibles par un humain

Avec un `Posix` et une `Zone`, on dispose de suffisamment d'informations pour afficher l'heure locale avec autant de détails que souhaité.
Voici une liste des fonctions que l'on peut utiliser pour cela :

```elm
toYear : Zone -> Posix -> Int
toMonth : Zone -> Posix -> Month
toDay : Zone -> Posix -> Int
toWeekday : Zone -> Posix -> Weekday
toHour : Zone -> Posix -> Int
toMinute : Zone -> Posix -> Int
toSecond : Zone -> Posix -> Int
toMillis : Zone -> Posix -> Int
```

Tu auras sans doute remarqué deux autres types personnalisés de `Time` :

```elm
type Month = Jan | Feb | Mar | Apr | May | Jun | Jul | Aug | Sep | Oct | Nov | Dec
type Weekday = Mon | Tue | Wed | Thu | Fri | Sat | Sun
```

C'est aux utilisateurs de convertir ces types personnalisés en valeurs lisibles par un humain.
