# Introduction

Une [`function`][function] est un moyen de compartimenter le code afin de pouvoir l'appeler par son nom depuis un ou plusieurs endroits du programme. Les fonctions servent à accomplir des tâches précises et répétitives.

Plus formellement : une fonction est n'importe quel objet Python auquel on peut appliquer l'opération de [`function call`][calls]. Une fonction peut servir à [`return`][return] une ou plusieurs valeurs en résultat d'une ou plusieurs opérations, ou bien à produire un ou plusieurs [`side effects`][side effects]. Si une fonction ne précise pas de valeur de retour, elle renvoie quand même `None`.

Voici un exemple de fonction avec un effet de bord :

```python
>>> def hello():
...     print("Hello")
...
>>> hello()
Hello

```

Dans l'exemple ci-dessus, le mot-clé [`def`][def] sert à signaler le début de la définition de la fonction.
`hello` est le nom de la fonction.
Les parenthèses vides indiquent qu'aucune valeur n'est passée à la fonction.
Le corps de la fonction est l'unique instruction `print("Hello")`.
`print` est aussi une fonction.
Le `"Hello"` entre les parenthèses de la fonction `print` est ce qu'on appelle un [`argument`][arguments].
La fonction `print` utilise cet argument pour savoir quoi afficher.
Note que le corps de la fonction est indenté.
L'indentation est importante, car Python s'appuie sur elle pour savoir où se termine ce bloc de code.
Le corps de la fonction se termine soit à la fin du programme, soit juste avant la prochaine ligne de code qui n'est _pas_ indentée.
Comme `hello()` ne précise pas de valeur `return`, elle exécute son effet de bord, à savoir l'appel à `print()`, puis elle renvoie `None`.
Enfin, on appelle la fonction en utilisant son nom suivi de parenthèses, ce qui indique à l'interprète Python que ce nom est _appelable_.

Voici un exemple de fonction avec une valeur de retour :

```python
>>> def hello():
...     return "Hello"
... 
print(hello())
Hello

```

Le corps de cette fonction a été modifié : au lieu d'_appeler_ `print`, il _renvoie_ maintenant la `string` "Hello".
Au final, le code affiche toujours `"Hello"`, mais l'effet de bord a lieu dans le _code appelant_ plutôt que dans la fonction `hello`.
Si on omet les parenthèses lors de l'appel de la fonction `hello` (par exemple `print(hello)`), alors `print` afficherait quelque chose comme

```
<function hello at 0x0000026E18E93E20>
```

Il est important que, même si une fonction n'accepte aucun argument (c'est-à-dire qu'elle ne prend aucun paramètre), les parenthèses vides soient utilisées pour l'_appeler_ correctement.
Cela diffère d'un langage comme Ruby, qui n'exige pas de parenthèses vides pour appeler une fonction sans argument.

Une fonction peut définir zéro ou plusieurs [`parameters`][parameters]. Un paramètre définit quel(s) argument(s) la fonction accepte.

Voici un exemple de fonction qui accepte un argument :

```python
>>> def hello(name):
...     return f"Hello, {name}"
... 
>>> print(hello("Bob"))
Hello, Bob

```

Le paramètre est défini comme `name`.
`"Bob"` est l'argument que le programme passe à la fonction `hello`.
La fonction _renvoie_ la `string` "Hello, Bob".

Que se passe-t-il si quelqu'un appelle `hello` sans passer d'argument ?
Le programme lève une erreur :

```python
print(hello())
Traceback (most recent call last):

  Input In in <line: 1>
    print(hello())

TypeError: hello() missing 1 required positional argument: 'name'
```

Si on ne veut pas que le programme lève une erreur en l'absence d'argument (tout en permettant au code appelant de ne pas en fournir), on peut définir un [argument par défaut][default arguments].
Un argument par défaut définit la valeur à utiliser si l'argument est absent au moment de l'appel de la fonction.

Voici un exemple de fonction avec un argument par défaut :

```python
>>> def hello(name="you"):
...     return f"Hello, {name}"
... 
>>> print(hello())
Hello, you

```

Le paramètre `name` reçoit l'argument par défaut `"you"`, donc le programme affiche `Hello, you` si on ne lui passe pas d'argument `name`.

Pour en savoir plus sur les arguments de fonction, voir le concept [arguments de fonction][function arguments].
