# Instructions supplémentaires

## Mots

Définis un tuple `linked-list-node`.

Définis un tuple `linked-list` et fournis une méthode `M: linked-list length`
(de `sequences`) pour que les tests puissent appeler `length` directement
sur ta liste.

- `<linked-list> ( -- linked-list )` construit une liste vide.
- `>linked-list ( seq -- linked-list )` empile chaque élément de
  `seq` sur une nouvelle liste, dans l'ordre.
- `linked-list>array ( linked-list -- array )` renvoie les
  valeurs, le sommet de la liste en premier.
- `list-push ( linked-list value -- linked-list )` empile une valeur
  au sommet.
- `list-pop ( linked-list -- linked-list value )` retire et
  renvoie la valeur du sommet.
- `list-peek ( linked-list -- value )` renvoie la valeur du sommet
  sans la retirer.
- `list-reverse ( linked-list -- linked-list )` renvoie une liste
  avec les éléments dans l'ordre inverse.

Lance une classe d'erreur `list-empty` depuis `list-pop` et `list-peek`
quand la liste est vide.
