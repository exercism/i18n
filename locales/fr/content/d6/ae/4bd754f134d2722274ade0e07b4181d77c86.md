# À propos

Le type primitif `char` de Java est une représentation sur 16 bits d'un seul caractère Unicode.

~~~~exercism/note
Le type `char` repose sur la [spécification Unicode d'origine][unicode-specification], qui utilisait 16 bits pour représenter les caractères.
Cela suffit à couvrir la plupart des lettres courantes et couvre les caractères compris entre 0x0000 et 0xFFFF.
Depuis, la spécification a étendu la plage des caractères possibles jusqu'à 0x01FFFF.

[unicode-specification]: https://www.unicode.org/versions/Unicode1.0.0/
~~~~

Plusieurs `char` peuvent former une _string_, comme `"word"`, ou bien les `char` peuvent être traités indépendamment.
Un littéral `char` est entouré de guillemets simples (par exemple `'A'`).

```java
char lowerA = 'a';
char upperB = 'B';
```

## Récupère les `char` d'une `String`

La méthode `String.toCharArray` renvoie les caractères d'une `String` sous forme de tableau.
Comme mentionné dans [les tableaux][concept-arrays], on peut utiliser une boucle `for` pour parcourir le tableau.

```java
String text = "Hello";
char[] asArray = text.toCharArray();

for (char ch: asArray) {
    System.out.println(ch);
}

// Outputs:
// H
// e
// l
// l
// o
```

## La classe [Character][docs-character]

Il existe de nombreuses méthodes intégrées de la bibliothèque standard pour inspecter et manipuler les `char`.
On les trouve sous forme de méthodes statiques de la classe [`java.lang.Character`][docs-character].
Voici quelques exemples :

```java
Character.isWhitespace(' ');    // true
Character.isWhitespace('#');    // false

Character.isLetter('a');        // true
Character.isLetter('3');        // false

Character.isDigit('6');         // true
Character.isDigit('?');         // false
```

~~~~exercism/note
Certaines méthodes de la classe Character ont une surcharge qui leur permet de prendre soit un `char`, soit un `int`.
Par exemple, `isDigit` en a une qui accepte un [`char`][is-digit-char] et une autre un [`int`][is-digit-int].
Comme mentionné plus haut, le type `char` ne peut représenter que les caractères compris entre 0x0000 et 0xFFFF.
Le type `int`, lui, peut représenter tous les caractères, d'où les surcharges pour `int`.

[is-digit-char]: https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/lang/Character.html#isDigit(char)
[is-digit-int]: https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/lang/Character.html#isDigit(int)
~~~~

## Ajoute un `char` à une `String`

On peut utiliser l'opérateur `+` pour ajouter un `char` à une `String`.

```java
'a' + " banana"     // => "a banana"
"banana " + 'a'     // => "banana a"
```

~~~~exercism/caution
Fais bien attention à _ne pas_ utiliser `+` pour concaténer deux `char` afin de former une `String` !
Additionner deux `char` de cette façon donne un `int`, _pas_ une `String` !
Par exemple :

```java
'b' + 'c';
// => 197 (not the String "bc")
```

En effet, Java promeut le `char` en `int` (voir [4.2 Primitive Types and Values ][jls-primitives] de la [Java Language Specification][jls-main]).

[jls-main]: https://docs.oracle.com/javase/specs/jls/se21/html/
[jls-primitives]: https://docs.oracle.com/javase/specs/jls/se21/html/jls-4.html#jls-4.2
~~~~

Toutefois, lorsqu'il y a beaucoup de caractères à ajouter, il peut être plus efficace d'utiliser plutôt un [`StringBuilder`][docs-stringBuilder] :

```java
StringBuilder builder = new StringBuilder();
builder.append('a');
builder.append('b');
builder.append('c');

String builtString = builder.toString();
// => abc
```
