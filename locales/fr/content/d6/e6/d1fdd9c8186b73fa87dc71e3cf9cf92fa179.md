# Instructions

Tu écris le cœur numérique d'une petite console de mixage dans un studio d'enregistrement.

Le son arrive sous forme d'un flux d'échantillons.
Chaque échantillon est un nombre qui décrit la position du cône d'un haut-parleur à un instant donné.
Une console traite tout un bloc d'échantillons à la fois, en appliquant la même opération à chacun.

Tu as cinq tâches, chacune portant sur un bloc d'échantillons stocké en mémoire.
Tu reçois les opérandes par des adresses mémoire et tu écris ton résultat à une adresse de résultat.

~~~~exercism/note
Les calculs de cet exercice doivent être effectués à l'aide d'instructions SIMD, et non d'opérations scalaires.
~~~~

## 1. Mixe deux pistes

Le studio enregistre parfois des instruments sur des pistes différentes.
Pour les diffuser sur les mêmes enceintes, tu additionnes les deux pistes pour n'en faire qu'une.

Implémente la fonction `mix_tracks`, qui additionne deux pistes, échantillon par échantillon.
Chaque piste est un bloc de 8 échantillons signés de 16 bits.
Une somme qui dépasse la plage des entiers signés de 16 bits doit être saturée plutôt que de déborder.

Cette fonction prend comme arguments, dans cet ordre :

- `result` : adresse mémoire alignée sur 16 octets d'un tampon dans lequel sont écrits les 8 échantillons mixés.
- `track_a` : adresse mémoire alignée sur 16 octets de la première piste, avec 8 échantillons signés de 16 bits.
- `track_b` : adresse mémoire alignée sur 16 octets de la seconde piste, avec 8 échantillons signés de 16 bits.

```c
track_a = {10000, 30000, 20000, -30000, -20000, -100,  100, 0}
track_b = { 5000,  5000, 20000,  -5000, -20000,  100, -100, 0}
result  = {15000, 32767, 32767, -32768, -32768,    0,    0, 0}
```

Cette fonction ne renvoie aucune valeur.

## 2. Supprime la fuite

Quand deux microphones enregistrent en même temps, chacun capte une copie ténue de la source de l'autre.
Cette copie indésirable s'appelle la fuite.
Une fois cette fuite mesurée, il faut la soustraire pour nettoyer la piste.

Implémente la fonction `remove_bleed`, qui soustrait le bloc de fuite du bloc de la piste, échantillon par échantillon.
Chaque bloc est constitué de 8 échantillons signés de 16 bits, et la soustraction doit saturer.

Cette fonction prend comme arguments, dans cet ordre :

- `result` : adresse mémoire où sont écrits les 8 échantillons nettoyés (alignement non garanti).
- `track` : adresse mémoire alignée sur 16 octets de la piste enregistrée, 8 échantillons signés de 16 bits.
- `bleed` : adresse mémoire de la fuite à retirer, 8 échantillons signés de 16 bits (alignement non garanti).

```c
track  = {10000, -30000, 5000, 32767, 0,  200, -200, 15000}
bleed  = { 2000,   5000, 5000,    -5, 0,  300,  300,  5000}
result = { 8000, -32768,    0, 32767, 0, -100, -500, 10000}
```

Cette fonction ne renvoie aucune valeur.

## 3. Combine les vumètres

Au-dessus de chaque canal se trouve un vumètre, une petite barre dont la luminosité indique le volume de ce canal.
La face avant possède un vumètre principal qui doit briller aussi intensément que les deux canaux réunis.
Tu additionnes les deux blocs de vumètres pour le piloter.

Note qu'un vumètre déjà lumineux reste à sa luminosité maximale au lieu de repartir vers le sombre, donc la somme sature.

Implémente la fonction `combine_meters`, qui additionne deux blocs de vumètres échantillon par échantillon.
Cette fonction prend comme arguments, dans cet ordre :

- `result` : adresse mémoire alignée sur 16 octets où sont écrites les 16 valeurs combinées.
- `meter_a` : adresse mémoire alignée sur 16 octets du bloc de vumètres du premier canal, avec 16 valeurs non signées de 8 bits compactées.
- `meter_b` : adresse mémoire alignée sur 16 octets du bloc de vumètres du second canal, avec 16 valeurs non signées de 8 bits compactées.

Chaque bloc contient 16 valeurs non signées de 8 bits.
Il faut les additionner, en saturant sur la plage non signée.

```c
meter_a = {200, 100,  50, 255, 0, 128, 10, 240, 1, 2, 3, 4, 5, 6, 7, 8}
meter_b = {100, 100, 200,   1, 0, 128, 10,  20, 1, 2, 3, 4, 5, 6, 7, 8}
result  = {255, 200, 250, 255, 0, 255, 20, 255, 2, 4, 6, 8, 10, 12, 14, 16}
```

Cette fonction ne renvoie aucune valeur.

## 4. Applique un fondu

La chanson ne doit pas s'arrêter brutalement, elle doit s'estomper en fondu à la fin.
Tu disposes d'un bloc de _coefficients de gain_, un par échantillon, qui diminuent progressivement, de plus en plus faibles.

Chaque coefficient est une fraction exprimée sur `65536`.
Par exemple, si un échantillon vaut `16384`, il exprime en fait `16384 / 65536`, soit `1 / 4`.
La plus grande valeur utilisable, `32767`, est juste en dessous de la moitié.

Comme `65536` vaut `2^16`, multiplier un échantillon par son coefficient et ne garder que la _moitié haute_ du produit donne `sample * gain / 65536`.

Implémente la fonction `apply_fade`, qui met à l'échelle chaque échantillon selon son coefficient.
Cette fonction prend comme arguments, dans cet ordre :

- `result` : adresse mémoire alignée sur 16 octets où sont écrits tous les échantillons mis à l'échelle.
- `track` : adresse mémoire alignée sur 16 octets de la piste, avec `n` échantillons signés de 16 bits.
- `gains` : adresse mémoire alignée sur 16 octets des coefficients de gain, avec `n` valeurs signées de 16 bits, chacune dans la plage allant de `0` à `32767`.
- `n` : le nombre d'échantillons, toujours non nul et multiple de `8`, sous forme d'un entier non signé de 64 bits.

Note que la piste est un tableau qui contient `n` échantillons signés de 16 bits, où `n` n'est jamais nul et toujours un multiple de `8`.
Pour chaque échantillon, le résultat mis à l'échelle correspond aux 16 bits _hauts_ du produit signé : `sample * gain`.

```c
track  = {20000, 20000, 20000, 20000, -20000, -20000, -20000, -20000}
gains  = {32767, 24576, 16384,  8192,  32767,  24576,  16384,   8192}
result = { 9999,  7500,  5000,  2500, -10000,  -7500,  -5000,  -2500}
```

~~~~exercism/note
Conserver la moitié haute arrondit vers moins l'infini.
C'est pourquoi `20000 * 32767` donne `9999`, tandis que `-20000 * 32767` donne `-10000` et non `-9999`.
~~~~

Cette fonction ne renvoie aucune valeur.

## 5. Atténue une piste

Le batteur a été enregistré bien trop fort.
Pour baisser toute la piste, tu divises chaque échantillon par une constante.

Implémente la fonction `attenuate_track`.
Cette fonction prend comme arguments, dans cet ordre :

- `result` : adresse mémoire alignée sur 16 octets où sont écrits les résultats, sous forme d'entiers signés de 32 bits.
- `samples` : adresse mémoire alignée sur 16 octets des échantillons, `n` valeurs signées de 16 bits.
- `divisor` : adresse mémoire alignée sur 16 octets de 4 copies identiques du diviseur, sous forme d'entiers de 32 bits.
- `n` est le nombre d'échantillons, toujours non nul et multiple de `4`, sous forme d'un entier non signé de 64 bits.

Note que `samples` est un tableau qui contient `n` échantillons signés de 16 bits, où `n` n'est jamais nul et toujours un multiple de `4`.

Le diviseur est fourni sous forme de `4` copies du même entier de 32 bits, déjà répliquées pour pouvoir remplir les quatre voies d'un coup.

Le SIMD sur entiers n'a pas de division compactée, le travail se fait donc en virgule flottante compactée, avant d'être reconverti en entiers de 32 bits compactés pour être stockés dans `result`.
La conversion se fait par troncature vers zéro : un quotient de `2.3` devient `2` et `-2.3` devient `-2`.

```c
samples = {300, 150, 90, -120, 100, 50, -50, 7}
divisor = {3, 3, 3, 3}
result  = {100,  50, 30,  -40,  33, 16, -16, 2}
```

Cette fonction ne renvoie aucune valeur.
