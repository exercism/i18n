# Tests

Avant d'essayer d'exécuter les tests, assure-toi que le dossier de l'exercice est correctement configuré en suivant les étapes d'installation, à savoir `corepack yarn install` et la configuration de l'Editor SDK.

Exécute les tests avec :

```bash
$ corepack yarn test
```

Assure-toi que le code respecte les bonnes pratiques, comme celui des autres utilisateurs, avec eslint, un outil qui effectue une analyse statique du code.
Ce genre d'outil te fait gagner du temps pour détecter les fautes de frappe ou les erreurs bêtes dans ton code :

```bash
$ corepack yarn lint
```

Ou fais les deux en même temps :

```bash
$ corepack yarn test && corepack yarn lint
```

Le parcours TypeScript sur Exercism n'impose pas de _style_ de code, tu es donc libre de choisir entre les points-virgules, les tabulations ou les espaces, et tout ce qui se trouve entre les deux.

## Crée ton premier module

En général, les tests de ce parcours chargent ton implémentation en l'important comme module : `import Bob from './bob';`.
Pour que ça fonctionne, tu dois exporter ton implémentation depuis le fichier dans lequel les tests cherchent ton module, `bob.ts` :

```typescript
export class Bob {
  public hey(message: string) {
    // Your solution here
  }
}
```

Des squelettes sont fournis dans chaque exercice, et cet `export` y est déjà placé pour toi.
