# Booléens

Crystal possède un type appelé [`Bool`][bools].
Il représente les valeurs `true` et `false`.

## Opérateurs logiques

Crystal possède trois opérateurs logiques (`!`, `||`, `&&`), qui combinent des booléens et forment des expressions produisant des valeurs différentes.

### ET (`&&`)

En Crystal, l'opérateur [ET][and] est représenté par `&&` et renvoie `true` si les deux valeurs valent `true` ; sinon, il renvoie `false`.
Quand on utilise l'opérateur ET, on place un booléen à droite du `&&` et un autre à gauche.

```crystal
true && true
# => true

true && false
# => false
```

### OU (`||`)

En Crystal, l'opérateur [OU][or] est représenté par `||` et renvoie `true` si **au moins une** des valeurs données vaut `true`.
Si les deux valeurs valent `false`, alors il renvoie `false`.
Quand on utilise l'opérateur OU, un booléen doit être placé à droite du `||` et un autre à gauche.

```crystal
true || true
# => true

true || false
# => true

false || false
# => false
```

### NON (`!`)

En Crystal, l'opérateur NON est représenté par `!` et renvoie `true` si le booléen donné vaut `false`, et renvoie `false` si on lui fournit `true`.
Quand on utilise l'opérateur NON, un booléen doit être placé après l'opérateur (`!`).

```crystal
!true
# => false

!false
# => true
```

## Utilise les parenthèses (`()`)

Quand on travaille avec des booléens, on peut utiliser des parenthèses pour décider quels booléens évaluer en premier.
Le résultat peut être différent selon la façon dont les parenthèses sont utilisées.
En Crystal, ce qui se trouve entre parenthèses est évalué en premier.

```crystal
true && false && false || true
# => true

true && false && (false || true)
# => false
```

Comme ce qui se trouve entre parenthèses est évalué en premier, dans l'exemple suivant, l'opérateur NON s'appliquera à l'expression située entre parenthèses.

```crystal
!true && false
# => false

!(true && false)
# => true
```

~~~~exercism/note
Tu ne dois utiliser des parenthèses que lorsqu'elles changent le résultat ; sinon, il vaut mieux les omettre.
~~~~
