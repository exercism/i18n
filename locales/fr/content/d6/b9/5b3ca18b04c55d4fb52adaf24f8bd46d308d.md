# Instructions

Dans cet exercice, tu vas écrire du code pour aider un freelance à communiquer avec un chef de projet.
Ta tâche consiste à fournir quelques utilitaires pour calculer rapidement des tarifs journaliers et mensuels, éventuellement avec une remise donnée.

On établit d'abord quelques règles entre le freelance et le chef de projet :

- Le tarif journalier correspond à 8 fois le tarif horaire.
- Un mois compte 22 jours facturables.

Il arrive que le freelance propose d'appliquer une remise sur son tarif journalier (par exemple pour ses clients les plus fidèles ou pour des clients à but non lucratif).

Les remises sont modélisées sous forme de nombres décimaux représentant des pourcentages, par exemple `25.0` (25 %).

## 1. Calculer le tarif journalier à partir d'un tarif horaire

Implémente une fonction appelée `daily_rate` qui calcule le tarif journalier à partir d'un tarif horaire passé en paramètre.
Le contrat définit qu'une journée compte 8 heures facturables.

```cpp
daily_rate(60)
// => 480.0
```

Le tarif journalier renvoyé doit être de type `double`.

## 2. Calculer un prix après remise

Implémente une fonction `apply_discount` pour calculer le prix après remise.
Elle doit accepter deux paramètres : le prix d'origine et le taux de remise en pourcentage.

```cpp
apply_discount(150, 10)
// => 135.0
```

La valeur renvoyée doit toujours être de type `double`, sans aucun arrondi.

## 3. Calculer le tarif mensuel à partir d'un tarif horaire et d'une remise

Implémente une fonction `monthly_rate` pour calculer le tarif mensuel après remise.
Elle prend deux paramètres : un tarif horaire et la remise en pourcentage.

```cpp
monthly_rate(77, 10.5)
// => 12130
```

Le tarif mensuel renvoyé doit être arrondi vers le haut (arrondi au plafond) à l'entier le plus proche.

## 4. Calculer le nombre de jours travaillés complets à partir d'un budget, d'un tarif horaire et d'une remise

Implémente une fonction `days_in_budget` qui prend un budget, un tarif horaire et une remise, et calcule combien de journées de travail complètes cela permet de couvrir.

```cpp
days_in_budget(20'000, 80, 11.0)
// => 35
```

Le nombre de jours renvoyé doit être arrondi vers le bas (arrondi au plancher) à l'entier inférieur.
