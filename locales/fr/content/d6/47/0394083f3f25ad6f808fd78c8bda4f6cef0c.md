# À propos des fonctions anonymes et des closures

PHP permet de déclarer des fonctions à l'intérieur d'autres fonctions. Ces fonctions n'ont pas besoin d'avoir un nom : on peut les affecter à des variables, ou même les passer directement à une autre fonction qui attend un paramètre de type fonction.

```php
function onlyOdds(array $numbers): array
{
    return array_filter($numbers, function($num) {
        return $num % 2 === 1;
    });
}
```

La fonction définie et passée à `array_filter` ci-dessus est une fonction anonyme. `array_filter` s'en sert pour déterminer si une valeur donnée d'un tableau fera partie du résultat renvoyé par `array_filter`. Si la fonction renvoie `true` pour une valeur, alors cette valeur est incluse dans le tableau résultat.

Les fonctions anonymes permettent aussi de référencer, depuis l'intérieur de la fonction, des variables qui se trouvent dans la portée extérieure. On dit alors que la portée de la fonction « se referme » sur la variable utilisée dans la fonction, d'où le nom de _closure_. Dans certains langages, toutes les variables de la portée sont automatiquement utilisables à l'intérieur de la _closure_. En PHP, `$this`, qui désigne l'objet courant, est automatiquement accessible dans la _closure_. Toutes les autres variables doivent être référencées explicitement à l'aide du mot-clé `use`.

```php
function makeAdderFunction(int $number) {
    return function(int $x) use($number) {
        return $x + $number;
    }
}

$add5 = makeAdderFunction(5);
echo $add5(4); // echos 9
```

Dans la fonction `makeAdderFunction` ci-dessus, la fonction anonyme définie à l'intérieur, qui est ensuite renvoyée, « se referme » sur la valeur de `$number` qui lui est passée. Ainsi, chaque fois que cette fonction est exécutée, elle connaît la valeur de `$number` qui lui a été passée. Si tu appelles à nouveau cette fonction avec un autre nombre, tu obtiens une fonction complètement différente. Cela ne modifie ni les valeurs ni le comportement de la fonction renvoyée lors du premier appel.
Si la fonction doit se refermer sur plusieurs variables, celles-ci s'ajoutent dans le mot-clé `use`, séparées par des virgules.

PHP propose également une syntaxe de fonction plus courte, appelée `arrow functions`. Ces fonctions doivent rester assez simples. Leur forme de base est la suivante :

```php
fn(arguments) => expression
```

Avec ce style de fonction, pas besoin d'utiliser `use`. La fonction se referme automatiquement sur les valeurs de la portée parente et les capture. L'expression de ces fonctions fléchées est renvoyée automatiquement, sans avoir besoin d'utiliser le mot-clé `return`. On peut donc réécrire la fonction `onlyOdds` ci-dessus de cette façon :

```php
function onlyOdds(array $numbers): array
{
    return array_filter($numbers, fn($n) => $n % 2 == 1);
}
```

La fonction `makeAdderFunction` ci-dessus pourrait s'écrire ainsi :

```php
function makeAdderFunction(int $number) {
    return fn(int $x) => $x + $number;
}
```

**Note :** Si la fonction ne peut pas s'écrire sous forme d'expression, la syntaxe abrégée des fonctions fléchées n'est pas utilisable.

Les variables sont transmises aux fonctions anonymes et aux _closures_, et utilisées à l'intérieur, par valeur. Cela signifie que si tu modifies la valeur de la variable à l'intérieur de la fonction, cela n'affecte pas la valeur de la variable à l'extérieur. Si tu as besoin que la valeur soit modifiée, tu peux la passer par référence.

```php
function positiveAverage(array $numbers): float
{
    $total = 0;
    $count = 0;
    return array_walk(
      $numbers,
      function($num) use (&$count, &$total) {
          $total += abs($num);
          $count++;
      }
    );
    return $total / $count;
}
```

Dans l'exemple ci-dessus, `array_walk` parcourt chaque élément du tableau et envoie chaque valeur à la fonction déclarée dans l'appel. Elle tient un total cumulé dans `$total`, où chaque valeur ajoutée est la valeur absolue du nombre. Elle garde aussi la trace du nombre de valeurs. Ces deux valeurs sont utilisées dans la _closure_ par référence, ce qu'indique le `&` placé devant chaque variable dans la section `use`. Ainsi, les modifications apportées aux variables sont toujours en place lorsque `array_walk` a terminé, ce qui permet à la fonction de renvoyer la moyenne des valeurs absolues des nombres du tableau.

Les fonctions anonymes et les _closures_ offrent un moyen pratique de définir une fonction dont on n'a besoin que dans un seul contexte, ou de définir une fonction qui renvoie une fonction dynamique construite à partir d'un ensemble de paramètres connus à un autre moment que celui où la fonction est réellement utilisée.
