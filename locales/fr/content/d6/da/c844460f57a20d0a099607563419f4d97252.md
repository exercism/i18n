# Introduction

Une _quotation_, c'est-à-dire du code entre crochets `[ ]`, est elle-même une valeur en Factor, exactement comme un nombre ou une _string_. Tu peux la stocker dans une variable, la placer dans un tableau, la passer à un autre _word_, et l'appeler plus tard.

## `call`

`call` (dans [`kernel`][kernel]) exécute une _quotation_ :

```factor
3 4 [ + ] call .
! => 7
```

Quand on appelle une _quotation_ dans un contexte où Factor ne peut pas inférer son effet de pile, il faut déclarer cet effet explicitement :

```
call( stack-effect ) ! e.g. call( a b -- c )
```

```factor
: apply-binary ( a b op -- c )
    call( a b -- c ) ;

5 3 [ - ] apply-binary .
! => 2
```

Cela compile une vérification qui, à l'exécution, s'assure que la _quotation_ a bien l'effet déclaré.

## Les _quotations_ dans les séquences

Comme les _quotations_ sont des valeurs, un tableau peut contenir un mélange de nombres et de _quotations_ :

```factor
{ 3 4 [ + ] }
```

Cela fait de « un programme » une séquence ordinaire, et `each` devient un moyen naturel d'en exécuter un :

```
each ( seq quot -- )
```

```factor
{ [ 1 + ] [ 2 * ] } 5 swap [ call( x -- y ) ] each .
! 5 -> 6 -> 12
```

## Découpe la fin d'une séquence

`head*` renvoie tout sauf les `n` derniers éléments ; `last2` renvoie les deux derniers :

```
head* ( seq n -- headseq )
last2 ( seq -- penultimate last )
```

```factor
{ 1 2 3 4 5 } 2 head* .    ! => { 1 2 3 }
{ 1 2 3 4 5 } last2 .s
! => 4
! => 5
```

Avec `suffix`, tu as là tout ce qu'il faut pour écrire une opération de pile du type « consommer les deux éléments du haut, empiler un résultat ».
