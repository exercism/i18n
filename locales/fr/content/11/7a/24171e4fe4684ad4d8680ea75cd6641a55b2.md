## Instructions

Tu as été recruté par un centre de recyclage.
Par manque de place, tous les produits sont placés sur le même convoyeur, ce qui a fini par mélanger les différents matériaux et les rendre inutilisables.
Pour y remédier, on t'a confié la mission d'écrire des fonctions permettant d'identifier le type d'un produit.

### 1. Vérifie si une valeur est un booléen

Implémente la fonction `isBoolean`, qui vérifie si une valeur est un booléen.

```javascript
isBoolean(true);
// => true

isBoolean(null);
// => false
```

### 2. Vérifie si une valeur est un nombre.

Implémente la fonction `isNumber`, qui vérifie si une valeur est un `number` ou un `bigint` _fini_, c'est-à-dire ni `NaN` ni `Infinity`.

Il arrive que le dispositif de lecture des identifiants tombe en panne et lise une valeur non numérique comme `NaN` (« pas un nombre ») ou `Infinity`.
Ta fonction doit aussi pouvoir gérer correctement ce cas.

```javascript
isNumber(42);
// => true

isNumber('Hello, World!');
// => false

isNumber(42n);
// => true

isNumber(NaN);
// => false
```

### 3. Vérifie si une valeur est un objet

Implémente la fonction `isObject`, qui doit vérifier si la valeur est un objet.
Sur le convoyeur, `null` n'est rien et n'est pas considéré comme un objet.

```javascript
isObject({ greeting: 'Hello' });
// => true

isObject(25n);
// => false
```

### 4. Vérifie si une _string_ est numérique

Implémente la fonction `isNumericString`, qui doit vérifier si la valeur est une _string_ composée uniquement de chiffres, ou d'un signe moins suivi de chiffres indiquant un nombre négatif.
Seuls les entiers doivent être pris en compte ; les nombres décimaux ne sont pas considérés comme numériques pour cette vérification du robot de recyclage.

```javascript
isNumericString(42);
// => false

isNumericString('42');
// => true

isNumericString('Hi!');
// => false
```

### 5. Vérifie si un objet est électronique

Implémente la fonction `isElectronic`, qui vérifie si un objet est une instance de la classe `ElectronicDevice` fournie ou de l'une de ses classes filles.

```javascript
class Duck {
  //...
}

class WashingMachine extends ElectronicDevice {
  //...
}

isElectronic(new Duck());
// => false

isElectronic(new WashingMachine());
// => true
```

### 6. Vérifie si une valeur est un tableau non vide

Implémente la fonction `isNonEmptyArray`, qui vérifie si une valeur est un tableau non vide.

```javascript
isNonEmptyArray([1, 2, 3]);
// => true

isNonEmptyArray([]);
// => false
```

### 7. Vérifie si une valeur est un tableau vide

Implémente la fonction `isEmptyArray`, qui vérifie si une valeur est un tableau vide.

```javascript
isEmptyArray([1, 2, 3]);
// => false

isEmptyArray([]);
// => true
```

### 8. Vérifie si un objet possède une propriété ou une méthode `type`

Implémente la fonction `hasType`, qui vérifie si un objet possède une propriété ou une méthode `type`.

```javascript
class Keyboard(){
  type(){
    // ...
  }
}
hasType({ type:"car", color:"red" })
// => true

hasType({ color:"green" })
// => false

hasType(new Keyboard())
// => true
```

### 9. Lève une erreur si un objet ne possède pas de propriété ou de méthode `id`

Implémente la fonction `assertHasId`, qui lèvera une `Error` si un objet ne possède pas la propriété `id`.

Si un objet possède bien la propriété `id`, elle ne doit rien renvoyer.

```javascript
assertHasId({ id: 42, color: 'red' });
// => undefined

assertHasId({ color: 'green' });
// Error: "Object is missing the 'id' property"
```

### 10. Vérifie si un objet possède une propriété `id`

Implémente la fonction `hasIdProperty`, qui vérifie si un objet possède une propriété `id`.

```javascript
class SimpleData {
  constructor() {
    this.number = '42';
    this.id = 'BC269327FE1D9B95';
  }
}

class StealingData extends SimpleData {}

class MethodData {
  constructor() {
    this.number = '42';
    this._id = 'BC269327FE1D9B95';
  }

  get id() {
    return this._id;
  }
}

hasIdProperty(new SimpleData());
// => true

hasIdProperty(new MethodData());
// => false

hasIdProperty(new StealingData());
// => false
```

### 11. Vérifie si un objet possède une propriété `type` définie

Implémente la fonction `hasDefinedType`, qui vérifie si un objet possède une propriété `type` qui n'est pas `undefined`.

```javascript
hasDefinedType({ type: undefined, color: 'red' });
// => false

hasDefinedType({ type: 'car', color: 'green' });
// => true
```
