# Introduction

Dans Cairo, le concept d'_ownership_ s'applique aux _variables_ et définit les règles qui régissent qui peut utiliser ces variables.
Chaque variable déclarée ne peut être utilisée qu'une seule fois, ce qui signifie qu'une fois qu'une variable est utilisée, elle sera soit détruite, soit déplacée, selon le type d'utilisation.

La _destruction_ peut se produire de plusieurs façons :

- une variable sort de la portée (avec ou sans utilisation) ;
- un _struct_ est déstructuré ;
- une destruction explicite avec `destruct()`

_Déplacer_ une valeur signifie simplement passer cette valeur à une autre fonction.

Le langage Cairo utilise un système de types linéaire, dont il tire parti pour garantir que tout le code est prouvable (et vérifiable), tout en faisant abstraction de la mémoire immuable de la VM Cairo.
