# À propos

## Itération sur un tableau

Une boucle `for` permet d'itérer sur un tableau et de répéter le code pour chaque élément :

```haxe
var fruitList = ["apple", "banana", "pear"];

for (fruit in fruitList) {
  trace(fruit);
}

// apple
// banana
// pear
```

Dans l'exemple ci-dessus, `fruit` est la variable qui contient la valeur d'un élément du tableau `fruitList`. Le compilateur vérifie que l'on peut itérer sur `fruitList`, sinon il arrête l'exécution.

## Itération sur un intervalle

On peut itérer sur des nombres grâce à l'opérateur d'intervalle. Cet opérateur prend deux opérandes `Int` et s'écrit `min...max`. La borne `min` est incluse et la borne `max` est exclue (`min` <= i ET `max` > i)

```haxe
for (i in 0...10) {
  trace(i); // from 0 to 9
}
```

## Itération sur des paires clé-valeur

Il est possible d'itérer sur des collections de paires clé-valeur. La seule différence de syntaxe est qu'au lieu d'une seule variable, on utilise un identifiant de variable pour la clé, suivi de `=>`, puis l'identifiant de variable pour la valeur :

```haxe
var map = [1 => 101, 2 => 202, 3 => 303];

for (k => v in map) {
  trace(key, value);
}

// 1, 101
// 2, 202
// 3, 303
```
