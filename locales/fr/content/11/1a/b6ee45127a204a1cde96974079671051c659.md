# Tests

Pour exécuter les tests en ligne de commande, lance la commande suivante depuis le répertoire de l'exercice :

```bash
java -jar /path/to/mars.jar nc runner.mips impl.mips
```

## Interface graphique

Pour exécuter les tests via l'interface graphique du simulateur MARS, `include` ton implémentation à la fin de `runner.mips` en décommentant la dernière ligne.
