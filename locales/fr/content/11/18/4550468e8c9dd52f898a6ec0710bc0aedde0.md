# Instructions

Les points de terminaison HTTP fonctionnent mieux avec la vérification des types. Ajouter un type _record_ à une requête POST garantit que les bonnes données sont envoyées à chaque fois.

## Objectifs

- Modifie le code fourni.
- Ajoute les attributs nécessaires à ce record pour accepter deux opérandes et un opérateur.
- Ajoute une fonction de ressource HTTP pour accepter une requête POST sur le chemin '/calc'
- La fonction doit accepter le type record Calculation comme charge utile et renvoyer un objet JSON générique

### Entrées acceptées

```json
{ "operand1": 4, "operand2": 10.2, "operator": "+" }
```

### Valeur de retour

```json
{ "expression": "4+10.2", "result": 14.2 }
```
