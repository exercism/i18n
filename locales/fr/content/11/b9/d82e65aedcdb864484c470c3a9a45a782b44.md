# Instructions

Andrew, développeur dans son entreprise, a récemment écrit un générateur de requêtes SQL léger pour un outil de migration de base de données.
Sa première implémentation naïve fonctionnait parfaitement sur de petits ensembles de données.
Pourtant, lors de grosses migrations en production, l'application s'est mise à consommer énormément de mémoire et peinait sous une charge importante.
Après avoir profilé l'application, Andrew a compris que la concaténation de chaînes classique à l'intérieur des boucles obligeait Go à réallouer de la mémoire en permanence.
Aujourd'hui, il a besoin de ton aide pour réécrire l'utilitaire avec `strings.Builder` de Go, afin que l'application monte en charge correctement et traite de gros volumes de texte sans saturer le tas mémoire.

## 1. Génère des requêtes SELECT

Implémente la fonction `BuildSelectQuery`.
Elle prend un nom de table (`string`) et un _slice_ de noms de colonnes (`[]string`).
Elle doit renvoyer une instruction SQL `SELECT` complète, terminée par un point-virgule.
Si le _slice_ de colonnes est vide ou vaut `nil`, la requête doit se rabattre sur l'astérisque `*` pour sélectionner toutes les colonnes.

```go
columns := []string{"id", "name", "email"}
BuildSelectQuery("users", columns)
// Function return: "SELECT id, name, email FROM users;"

BuildSelectQuery("orders", nil)
// Function return: "SELECT * FROM orders;"
```

## 2. Génère des instructions INSERT par lots

Implémente la fonction `BuildBatchInserts`.
Elle prend un nom de table (`string`) et un _slice_ à deux dimensions représentant les lignes de la base de données (`[][]ColumnValue`).
Chaque élément d'une ligne associe un nom de colonne précis à sa valeur sous forme de _string_.
La fonction doit renvoyer un _slice_ d'instructions SQL `INSERT` individuelles.
Le format structuré en _slice_ garantit un ordre de sortie des requêtes prévisible et stable.
Si le _slice_ de lignes fourni en entrée est vide, renvoie un _slice_ de _strings_ vide.
Si une ligne est vide, ignore-la.
Les valeurs de type _string_ dans la clause `VALUES` doivent être entourées de guillemets simples `'`.

```go
rows := [][]ColumnValue{
    {
        {Column: "title", Value: "Book"},
        {Column: "price", Value: "100"},
    },
    {
        {Column: "title", Value: "Magazine"},
        {Column: "price", Value: "15"},
    },
}

BuildBatchInserts("products", rows)
// Function returns string slice: [
//   "INSERT INTO products (title, price) VALUES ('Book', '100');",
//   "INSERT INTO products (title, price) VALUES ('Magazine', '15');"
// ]
```
