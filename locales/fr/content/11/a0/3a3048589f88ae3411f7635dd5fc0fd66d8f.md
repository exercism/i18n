# spécification incorrecte

[comment]: # (Cet avertissement est émis lorsque la solution a un _typespec_ différent de celui de l'exemplar)

Vérifie que le _typespec_ de `two_fer/1` est correct. La fonction prend un argument, une _string_, et renvoie un résultat, lui aussi une _string_.

Le type correct pour les _strings_ est [`String.t()`](https://hexdocs.pm/elixir/String.html#t:t/0).

> Pour les outils d'analyse, les types `String.t()` et `binary()` sont équivalents. Cela dit, pour qui lit la documentation, `String.t()` indique qu'il s'agit d'un binaire encodé en UTF-8.

Le [type `string()`](https://hexdocs.pm/elixir/typespecs.html#the-string-type) désigne une _charlist_, et non une _string_ Elixir.

> Elixir décourage l'utilisation du type `string()`. Le type `string()` désigne les _strings_ Erlang, que l'on appelle « _charlists_ » en Elixir. Elles ne désignent pas les _strings_ Elixir, qui sont des binaires encodés en UTF-8.
