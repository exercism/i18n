# Ajout aux instructions

## Indices

Pour venir à bout de cet exercice, tu dois créer le type de données `Robot`, sous la forme d'une variable mutable, ainsi que le type de données `RunState`. Tu dois également implémenter les fonctions suivantes :

- `initialState`
- `mkRobot`
- `resetName`
- `robotName`

Tu trouveras une déclaration de données factice et des signatures de type déjà en place, mais c'est à toi de définir les fonctions et de créer un type de données, un newtype ou un synonyme de type qui ait du sens. Pour modéliser l'état, cet exercice utilise la monade [`State`](https://en.wikibooks.org/wiki/Haskell/Understanding_monads/State). Plus précisément, on combine la monade `State` avec la monade `IO` grâce aux [transformateurs de monade `StateT`](http://book.realworldhaskell.org/read/monad-transformers.html). Tous les tests sont exécutés avec `initialState` comme état fourni à `evalStateT`.
