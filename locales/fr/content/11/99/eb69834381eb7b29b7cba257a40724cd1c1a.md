# Introduction

Le type `enum` de C# représente un ensemble fixe de constantes nommées (une énumération). Son objectif principal est de fournir un moyen sûr au niveau des types d'interagir avec des constantes numériques, en limitant les valeurs disponibles à un ensemble prédéfini. Une énumération simple peut être définie comme suit :

```csharp
enum Season
{
    Spring,
    Summer,
    Autumn,
    Winter
}
```

S'ils ne sont pas définis explicitement, les membres d'une énumération se voient automatiquement affecter des valeurs entières successives, la première valant zéro. Il est également possible d'affecter des valeurs explicitement :

```csharp
enum Answer
{
    Maybe = 1,
    Yes = 3,
    No = 5
}
```
