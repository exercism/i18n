## 1. Définis une fonction qui vérifie si la liste des langages est vide

- L'une des [méthodes][list] du type List permet de vérifier si elle est vide.

- L'une des [méthodes][list] du type List permet d'ajouter des éléments.
- Rappel : les méthodes qui renvoient `void` n'ont pas besoin d'instructions `return`.

- L'une des [méthodes][list] du type List permet de supprimer des éléments.
- Rappel : les méthodes qui renvoient `void` n'ont pas besoin d'instructions `return`.

## 4. Définis une fonction qui renvoie le premier élément de la liste

- L'une des [méthodes][list] du type List permet de récupérer un élément situé à un certain indice.

## 5. Définis une fonction qui renvoie le nombre de langages dans la liste

- L'une des [méthodes][list] du type List permet d'obtenir la taille de la liste.

## 6. Définis une fonction qui détermine si un langage figure dans la liste

- L'une des [méthodes][list] du type List permet de vérifier si un élément figure dans la liste.
