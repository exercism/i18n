# Installation

## Installe Dart

Tu trouveras les instructions pour installer le SDK Dart sur le site de Dart : [Obtenir Dart][get-dart]

## Le plugin Dart pour ton IDE ou ton éditeur

Si tu utilises un IDE ou un éditeur, [ajoute un plugin Dart][editors] s'il en existe un pour l'éditeur que tu utilises.

[get-dart]: https://dart.dev/get-dart
[editors]:  https://dart.dev/tools#editors
