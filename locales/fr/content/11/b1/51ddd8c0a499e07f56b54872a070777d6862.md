# Ajout aux instructions

L'élévation d'un nombre complexe à une puissance nécessite une fonction exponentielle, une fonction sinus et une fonction cosinus, dont aucune n'est disponible en WebAssembly. Heureusement, on peut utiliser une [série de Taylor](https://en.wikipedia.org/wiki/Taylor_series) pour les calculer. Il te faut au moins une précision de `1/26!` pour correspondre aux valeurs attendues.

## Fonction exponentielle

```
exp(x) ≃ 1 + x + x ^ 2 / 2! + x ^ 3 / 3! + x ^ 4 / 4! + ... + x ^ n / n!
```

## Fonction sinus

```
sin(x) ≃ x - x ^ 3 / 3! + x ^ 5 / 5! - x ^ 7 / 7! + ... - x ^ n / n!
```

## Fonction cosinus

```
cos(x) ≃ 1 - x ^ 2 / 2! + x ^ 4 / 4! - x ^ 6 / 6! + ... - x ^ n / n!
```
