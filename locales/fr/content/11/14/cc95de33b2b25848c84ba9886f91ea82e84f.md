# Instructions

Ajoute le nombre de mines à une grille de démineur complétée.

Le démineur est un jeu populaire dans lequel le joueur doit trouver les mines à l'aide d'indices numériques qui indiquent combien de mines sont directement adjacentes à une case (horizontalement, verticalement, en diagonale).

Dans cet exercice, tu dois écrire du code qui compte le nombre de mines adjacentes à une case vide donnée et remplace cette case par ce nombre.

La grille est un rectangle composé de caractères d'espacement (' '). Une mine est représentée par un astérisque ('\*').

Si une case n'a aucune mine adjacente, laisse-la vide.

## Examples

Par exemple, tu peux recevoir une grille de 5 x 4 comme celle-ci (les cases vides sont représentées ici par le caractère '·' pour l'affichage à l'écran) :

```
·*·*·
··*··
··*··
·····
```

Et ton code la transformera en ceci :

```
1*3*1
13*31
·2*2·
·111·
```
