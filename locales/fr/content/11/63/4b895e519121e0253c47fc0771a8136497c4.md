## Messages d'exception

Il est parfois nécessaire de [lever une exception](https://docs.python.org/3/tutorial/errors.html#raising-exceptions). Quand tu le fais, tu dois toujours inclure un **message d'erreur explicite** pour indiquer l'origine de l'erreur. Cela rend le code plus lisible et facilite grandement le débogage. Lorsque tu sais que l'origine de l'erreur sera d'un type précis, tu peux choisir de lever l'un des [types d'erreur intégrés](https://docs.python.org/3/library/exceptions.html#base-classes), mais tu dois quand même y joindre un message explicite.

Cet exercice en particulier demande que tu utilises l'[instruction `raise`](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement) pour « déclencher » une erreur lorsque les règles de score ou de jeu ne sont pas respectées. Les tests ne passeront que si tu `raise` l'`exception` et que tu y joins un message.

Pour lever une `ValueError` avec un message, écris ce message comme argument du type `exception` :

```python
# example when a bonus is attempted with an open frame
raise IndexError("cannot throw bonus with an open tenth frame")

# example when fill balls are invalid
raise ValueError("invalid fill balls")
```
