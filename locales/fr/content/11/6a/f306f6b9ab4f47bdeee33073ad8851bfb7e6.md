# À propos

`TUPLE:` déclare une classe avec des emplacements nommés. Factor génère
automatiquement un mot constructeur (le nom de la classe suffixé par `new`),
un constructeur `boa` (par ordre d'arguments), une syntaxe littérale
`T{ class … }` et un mot accesseur par emplacement.

```factor
TUPLE: player
    { name initial: f }
    { level initial: 0 }
    { health initial: 100 } ;

player new .                                    ! T{ player }
3 100 "Merlin" player boa .                     ! by-order construction
T{ player { name "Merlin" } { health 50 } } .   ! literal syntax
```

Le système d'accesseurs de [`accessors`][accessors] fournit quatre
variantes par emplacement : `name>>`, `>>name`, `change-name`, et la paire
`[ … ] change-name`, qui modifie le tuple sur place. `>>name` et `change-name`
modifient le tuple ; pour laisser l'original intact, on commence par `clone`.

Les tuples prennent en charge `=` par égalité structurelle et s'affichent
en montrant les valeurs d'emplacement qui ne sont pas celles par défaut.

[accessors]: https://docs.factorcode.org/content/vocab-accessors.html
