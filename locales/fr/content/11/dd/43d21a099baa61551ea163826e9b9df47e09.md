# Instructions

Tu tiens un petit poste météo au bord de la Vltava à Prague, et à chaque service tu notes les relevés de température dans un journal en texte brut, un relevé par ligne. Cinq petits mots suffisent à tenir la comptabilité d'un service.

Chaque mot reçoit le chemin du fichier journal.

## 1. Lis chaque relevé

Définis `read-readings` pour renvoyer tous les relevés du journal sous forme d'un tableau de _strings_, un par ligne.

```factor
"weather.log" read-readings .
! => { "21.5" "19.0" "22.3" }
```

## 2. Trouve le relevé le plus récent

Définis `latest-reading` pour renvoyer le relevé le plus récent : la dernière ligne du journal.

```factor
"weather.log" latest-reading .
! => "22.3"
```

## 3. Lis le journal brut

Définis `log-text` pour renvoyer tout le fichier journal sous la forme d'une seule _string_, exactement tel qu'il est stocké.

```factor
"weather.log" log-text .
! => "21.5\n19.0\n22.3\n"
```

## 4. Enregistre un relevé

Définis `record-reading` pour ajouter un nouveau relevé à la fin du journal, sur sa propre ligne, sans toucher aux relevés précédents. Ne renvoie rien.

```factor
"23.1" "weather.log" record-reading
"weather.log" log-text .
! => "21.5\n19.0\n22.3\n23.1\n"
```

## 5. Réécris le journal

Définis `rewrite-log` pour remplacer tout le journal par un nouveau tableau de relevés, un par ligne.

```factor
{ "10.0" "11.0" } "weather.log" rewrite-log
"weather.log" log-text .
! => "10.0\n11.0\n"
```
