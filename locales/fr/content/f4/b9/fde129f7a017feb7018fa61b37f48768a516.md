# À propos

Tu sais maintenant comment itérer sur un _slice_ ou une _map_ en Go.

Pour récapituler, tu as appris que chaque itération renvoie deux valeurs : l'indice ou la clé, et une copie de l'élément situé à cet indice ou à cette clé.

## Itérer sur un _slice_

On ne peut plus simple : une boucle sur un _slice_ parcourt les éléments dans l'ordre attendu.

```go
xi := []int{10, 20, 30}
for i, x := range xi {
  fmt.Println(i, x)
}
// outputs:
// 0, 10
// 1, 20
// 2, 30
```

## Itérer sur une _map_

Itérer sur une _map_ pose un nouveau problème : l'ordre est désormais aléatoire.

```go
hash := map[int]int{9: 10, 99: 20, 999: 30}
for k, v := range hash {
  fmt.Println(k, v)
}
// outputs, for example:
// 99 20
// 999 30
// 9 10
```

~~~~exercism/note
On pourrait croire que la sortie ci-dessus est incorrecte, car on s'attendrait à ce que la première paire clé/valeur déclarée dans la _map_, `9 10`, soit la première affichée et non la dernière.
Or les _maps_ ne sont pas ordonnées par nature : il n'existe ni première ni dernière paire clé/valeur.
C'est pourquoi, lorsqu'on itère sur les entrées d'une _map_, l'ordre dans lequel les entrées sont visitées est aléatoire et ne suit aucun schéma particulier.
Cela signifie que la sortie ci-dessus est possible, mais qu'elle peut différer de ce que tu obtiendras si tu essaies de lancer ce code toi-même.
Pour en savoir plus, consulte [Go Language Spec: range clause](https://go.dev/ref/spec#RangeClause).
~~~~

## Itération en omettant la clé ou la valeur

En Go, une variable non utilisée provoque une erreur à la compilation.
Parfois, tu n'as besoin que de la valeur, comme dans le premier exemple :

```go
xi := []int{10, 20, 30}
for i, x := range xi {
  fmt.Println(x)
}
// Go build failed: i declared but not used
```

Tu peux remplacer le `i` par `_`, ce qui indique au compilateur que cette valeur n'est pas utilisée :

```go
xi := []int{10, 20, 30}
for _, x := range xi {
  fmt.Println(x)
}
// outputs:
// 10
// 20
// 30
```

Si tu veux afficher uniquement l'indice, tu peux remplacer le `x` par `_`, ou simplement omettre la déclaration :

```go
xi := []int{10, 20, 30}
// for i, _ := range xi {
for i := range xi {
  fmt.Println(i)
}
// outputs:
// 0
// 1
// 2
```

Enfin, et ce n'est pas le moins important, si tu dois effectuer une action sans avoir besoin des valeurs ni des clés du _slice_ ou de la _map_, tu peux omettre à la fois l'indice et la valeur :

```go
xi := []int{10, 20, 30}
count := 0
for range xi {
  count++
}
// count value:
// 3
```
