# Apprends Visual Basic

## Sites web

Visual Basic a beaucoup évolué au fil des années, et de nombreux tutoriels tiers renvoient à des outils ou à des fonctionnalités obsolètes.
La [documentation officielle de Visual Basic](https://learn.microsoft.com/en-us/dotnet/visual-basic/) est l'endroit le plus à jour et le plus fiable pour commencer.

## L'écosystème .NET

Visual Basic s'exécute sur le runtime .NET, et partage une grande partie de ses fonctionnalités de base avec C# et F#.
Comprendre le fonctionnement de .NET fera donc de toi un meilleur développeur VB.

- [Qu'est-ce que .NET ?](https://learn.microsoft.com/en-us/dotnet/core/introduction)
- [Le glossaire .NET](https://learn.microsoft.com/en-us/dotnet/standard/glossary)
- [Le Common Type System (CTS)](https://learn.microsoft.com/en-us/dotnet/standard/base-types/common-type-system)
