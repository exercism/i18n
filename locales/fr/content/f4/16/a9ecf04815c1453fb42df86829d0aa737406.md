# Ajout aux instructions

## Format de sortie

Produis une _string_ terminée par un caractère nul, en séparant les valeurs par une virgule et un espace.

Voici un exemple de sortie : `"491, 914, 142"`

Si l'entrée n'est pas valide, produis une _string_ vide.

## Registres

| Registre | Utilisation  | Type         | Description                                        |
| -------- | ------------ | ------------ | -------------------------------------------------- |
| `$a0`    | entrée       | adresse      | _string_ de la série terminée par un caractère nul |
| `$a1`    | entrée       | entier       | longueur de la tranche                             |
| `$a2`    | entrée/sortie | adresse     | _string_ de sortie terminée par un caractère nul   |
| `$t0-9`  | temporaire   | quelconque   | utilisé comme stockage temporaire                  |
