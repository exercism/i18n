# Introduction

Les tableaux associatifs de Factor (tables de hachage et compagnie) partagent un [protocole][assoc-protocol] commun issu de [`assocs`][assocs]. Le littéral de table de hachage s'écrit `H{ }` :

```factor
H{ { "coal" 1 } { "wood" 2 } } .

"coal" H{ { "coal" 1 } { "wood" 2 } } at .   ! => 1
"gold" H{ { "coal" 1 } { "wood" 2 } } at .   ! => f
```

Opérations courantes :

```
at        ( key assoc -- value/f )
key?      ( key assoc -- ? )
set-at    ( value key assoc -- )
delete-at ( key assoc -- )
inc-at    ( key assoc -- )
change-at ( key assoc quot -- )
keys      ( assoc -- keys )
values    ( assoc -- values )
>alist    ( assoc -- alist )
```

Les tables de hachage sont *mutables* : il faut faire un `clone` d'un littéral `H{ }` avant de le modifier, sinon le littéral est partagé entre les appels.

[assocs]: https://docs.factorcode.org/content/vocab-assocs.html
[assoc-protocol]: https://docs.factorcode.org/content/article-assocs-protocol.html
