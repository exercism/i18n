# À propos

Les blocs sont de petits groupes d'instructions qui peuvent être exécutés plusieurs fois.
On peut les voir comme des fermetures ou des fonctions anonymes.
Les blocs se définissent avec la syntaxe `do...end` (ci-dessus) ou `{}` (ci-dessous).
Les deux styles sont interchangeables, et les avis divergent sur le moment où utiliser l'un ou l'autre.

## Syntaxe raccourcie
Lorsqu'un bloc appelle une seule méthode, on peut le remplacer par `&:` suivi du nom de la méthode. Par exemple, ces deux lignes sont synonymes :

```ruby
people.sum { |person| person.age }
people.sum(&:age)
```
