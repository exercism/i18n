# Instructions

Dans cet exercice, tu vas créer un programme bien pratique pour ne plus avoir à mémoriser les valeurs des bandes.
Le programme prendra 1, 4 ou 5 couleurs en entrée et affichera la valeur correcte en ohms.
Les bandes de couleur sont codées comme suit :

| Couleur | Valeur |
| ------- | ------ |
| Black   | 0      |
| Brown   | 1      |
| Red     | 2      |
| Orange  | 3      |
| Yellow  | 4      |
| Green   | 5      |
| Blue    | 6      |
| Violet  | 7      |
| Gray    | 8      |
| White   | 9      |

Dans [`Resistor Color Trio`][resistor-color-trio-exercise], tu as décodé les trois premières bandes de couleur.
Par exemple : orange-orange-brown correspondait à la valeur principale `330`.
Dans cet exercice, tu vas devoir intégrer la _tolérance_.
La tolérance correspond à l'écart maximal dont une valeur peut s'écarter au-dessus ou en dessous de la valeur principale.
Par exemple, si la dernière bande est verte, la tolérance maximale sera de `±0.5%`.

La bande de tolérance prendra l'une de ces valeurs :

| Couleur | Tolérance |
| ------- | --------: |
| Grey    |    ±0.05% |
| Violet  |    ±0.10% |
| Blue    |    ±0.25% |
| Green   |    ±0.50% |
| Brown   |    ±1.00% |
| Red     |    ±2.00% |
| Gold    |    ±5.00% |
| Silver  |   ±10.00% |

Une résistance à quatre bandes se compose comme ceci :

| Bande_1 | Bande_2 | Bande_3     | Bande_4   |
| ------- | ------- | ----------- | --------- |
| Valeur_1 | Valeur_2 | Multiplicateur | Tolérance |

Exemples :

- orange-orange-brown-green donnerait `330` ohms avec une tolérance de `±0.5%`.
- orange-orange-red-grey donnerait `3300` ohms avec une tolérance de `±0.05%`.

La différence entre une résistance à quatre bandes et une résistance à cinq bandes, c'est que cette dernière possède une bande supplémentaire pour indiquer une valeur plus précise.

| Bande_1 | Bande_2 | Bande_3 | Bande_4     | Bande_5   |
| ------- | ------- | ------- | ----------- | --------- |
| Valeur_1 | Valeur_2 | Valeur_3 | Multiplicateur | Tolérance |

Exemples :

- orange-orange-orange-black-green donnerait `333` ohms avec une tolérance de `±0.5%`.
- orange-red-orange-blue-violet donnerait `323 million` ohms avec une tolérance de `±0.1%`.

Il existe aussi des résistances à une seule bande.
Les résistances à une seule bande n'ont que la couleur noire, de valeur 0.

Ton programme doit transformer une `list` de couleurs de bandes de résistance fournie en entrée en un libellé :

« ... ohms ±...% »

Ainsi, une `list` d'entrée `["orange", "orange", "black", "green"]` doit renvoyer :

« 33 ohms ±0.5% »

Lorsqu'il y a des milliers d'ohms, on dit « kiloohms ».
C'est un peu comme dire « kilomètre » pour 1000 mètres et « kilogramme » pour 1000 grammes.

Ainsi, une `list` d'entrée `["orange", "orange", "orange", "grey"]` doit renvoyer :

« 33 kiloohms ±0.05% »

Lorsqu'il y a des millions d'ohms, on dit « megaohms ».

Ainsi, une `list` d'entrée `["orange", "orange", "blue", "red"]` doit renvoyer :

« 33 megaohms ±2% »
