# Déstructuration

La déstructuration consiste à décomposer un élément en ses différentes parties et à lier chacune d'elles à une variable distincte.

## Déstructuration des tuples

Déstructurer un tuple est simple : il suffit d'affecter un nouveau nom de variable à chaque champ du tuple :

```rust
let (first, second) = (1, 2);
```

## Déstructuration des structures tuples

La déstructuration des structures tuples est identique à celle des tuples, à ceci près qu'on y ajoute le nom de la structure :

```rust
struct TupleStruct(&'static str, i32);
let my_tuple_struct = TupleStruct("foo", 123);
let TupleStruct(foo, num) = my_tuple_struct;
```

## Déstructuration des structures

La déstructuration des structures est semblable à celle des structures tuples. Il suffit d'utiliser les noms des champs :

```rust
struct ArabianNights {
    name: String,
    stories: usize,
}
let teller = ArabianNights { name: "Scheherazade".into(), stories: 1001 };
{
    let ArabianNights { name, stories } = teller;
    println!("{name} told {stories} stories");
}
```

## Déstructuration partielle

L'opérateur `..` permet d'ignorer certains champs lors de la déstructuration :

```rust
let ArabianNights { name, .. } = teller;
println!("{name} survived by her wits");
```

## Déstructuration conditionnelle

La déstructuration des structures et des tuples est infaillible. Les énumérations peuvent toutefois être déstructurées elles aussi, à l'aide des constructions de langage `if let`, `while let` et `match`.

```rust
if let Some(foo) = foo {
    println!("{foo:?}");
}
```
