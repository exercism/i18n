# Introduction

Un *tuple* est le type d'enregistrement, de structure ou de classe de Factor. Chaque classe de tuple possède un ensemble fixe de _slots_ nommés, et Factor génère automatiquement les _getters_ et les _setters_ correspondants.

```factor
TUPLE: point
    { x initial: 0 }
    { y initial: 0 } ;

T{ point { x 3 } { y 4 } } x>> .   ! => 3
3 4 point boa .                    ! => T{ point { x 3 } { y 4 } }
point new .                        ! => T{ point }
```

`boa` (« by order of arguments », soit « dans l'ordre des arguments ») remplit les _slots_ depuis la pile, dans l'ordre de déclaration. `new` construit une instance en donnant à chaque _slot_ la valeur `initial:` déclarée (ou `f` si aucune ne l'est).

Pour chaque _slot_, le _getter_ s'écrit `slot>>` et le _setter_ `>>slot`. Le _setter_ modifie l'instance sur place ; fais donc d'abord un `clone` si tu as besoin d'une mise à jour non destructive :

```factor
T{ point { x 3 } { y 4 } } clone 10 >>x .
! => T{ point { x 10 } { y 4 } }
```

Les valeurs par défaut des _slots_ s'écrivent `{ name initial: value }` ; sans `initial:`, la valeur par défaut est `f`.
