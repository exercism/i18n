# Instructions

Personne ne monte au trapèze au cirque tant que les contrôles de sécurité ne sont pas validés. Tu écris ces vérifications pour que les mêmes règles s'appliquent à tout le monde.

Les cinq tâches prennent place dans la classe `SAFETY_CHECK`.

## 1. Le tapis est-il prêt ?

Le tapis n'est prêt que s'il est à la fois posé et propre.

```sather
SAFETY_CHECK::mat_ready(true, false)
-- => false
```

## 2. Y a-t-il de quoi atterrir ?

Il doit y avoir un tapis en dessous, ou un filet en dessous. L'un ou l'autre suffit, et avoir les deux ne pose aucun problème.

```sather
SAFETY_CHECK::something_below(false, true)
-- => true
```

## 3. Qui a encore besoin du briefing ?

Toute personne qui n'a pas encore eu le briefing a besoin du briefing.

```sather
SAFETY_CHECK::needs_briefing(false)
-- => true
```

## 4. Cet artiste est-il assez âgé ?

Le trapèze est réservé aux artistes de 13 ans et plus.

```sather
SAFETY_CHECK::old_enough(13)
-- => true
```

## 5. Assemble le tout

Un artiste est autorisé à monter au trapèze lorsqu'il a l'âge requis, qu'il a eu le briefing et que le tapis est prêt.

```sather
SAFETY_CHECK::cleared(14, true, true, true)
-- => true
```

Les quatre arguments sont l'âge, le fait que la personne ait eu le briefing, le fait que le tapis soit posé et le fait que le tapis soit propre.
