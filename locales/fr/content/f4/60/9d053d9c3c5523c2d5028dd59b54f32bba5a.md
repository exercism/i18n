# À propos

En Swift, les _closures_ et les fonctions (qui ne sont en fait qu'un cas particulier de _closure_) peuvent accéder aux paramètres et aux variables de l'environnement qui les entoure. De plus, elles conservent l'accès à ces valeurs après la fin de l'exécution de la fonction englobante. Cette opération, qui consiste à obtenir et à conserver cet accès, est appelée [_capture_][capturing-values].

```swift
 func makeAdder(base: Int) -> (Int) -> Int {
   func adder(_ i: Int) -> Int {
     base + i
   }
   return adder
 }
 // makeAdder: (Int) -> (Int) -> Int

 let add10 = makeAdder(base: 10)
 // add10: (Int) -> Int

 let subtract20 = makeAdder(base: -20)
 // subtract10: (Int) -> Int

 add10(5)
 // => 15

 subtract20(5)
 // => -15

 func makeLogger(logLevel: String) -> (String) -> () {
   let logHeader = "[\(logLevel)]: "
   return { msg in print(logHeader, msg) }
 }
 // makeLogger: (String) -> (String) -> ()

 let infoLogger = makeLogger("info")
 // infoLogger: (String) -> ()

 infoLogger("This is a log message")
 // prints "[info]: This is a log message"
```

On observe cette capture avec les fonctions `makeAdder(base:)` et `makeLogger(logLevel:)` ci-dessus, où la fonction et la _closure_ qui sont renvoyées continuent d'utiliser les valeurs capturées de `base` et `logHeader`, même après que `makeAdder(base:)` et `makeLogger(logLevel:)` ont terminé leur exécution.

[capturing-values]: https://docs.swift.org/swift-book/LanguageGuide/Closures.html#ID103
