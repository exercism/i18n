# Introduction

Les tuples sont un moyen léger de regrouper un ensemble fixe de données de types arbitraires.
Un tuple peut contenir un nombre arbitraire d'éléments.
On peut accéder aux éléments par déstructuration.

```rust
fn main() {
    let tup: (u32, u64, bool) = (10, 20, true);
}

fn main() {
    let (x, y, z) = (500, 6, true);

    if y == 6 {
        println!("y is 6!");
    }
}
