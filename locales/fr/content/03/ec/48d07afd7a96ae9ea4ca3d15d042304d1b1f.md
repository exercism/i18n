# Normalisations du representer

Le [representer F#][representer] applique les normalisations suivantes :

## Supprime les commentaires

Tous les commentaires sont supprimés.

### Avant

```fsharp
module Fake

(* Block comment
   on multiple lines *)

let message = "Hi" (* Block comment after code *)

// Double-slash comment on single line
let reply = "Yo" // Double-slash comment after code

/// <summary>This function adds two numbers</summary>
/// <param name="x">The first number</param>
/// <param name="y">The second number</param>
/// <returns>The first number added to the second number</param>
let add x y = x + y
```

### Après

```fsharp
module Fake

let message = "Hi"

let reply = "Yo"

let add x y = x + y
```

## Supprime les déclarations d'import

Toutes les déclarations d'import sont supprimées.

### Avant

```fsharp
module Fake

open System
open System.IO

let message = "Hi"
```

### Après

```fsharp
module Fake

let message = "Hi"
```

## Formate le code

Le code est formaté à l'aide de la [bibliothèque fantomas][fantomas].
Celle-ci formate le code selon le guide de style F#.
La liste complète des transformations appliquées par fantomas se trouve [ici][fantomas-formatting].

### Avant

```fsharp
module Fake

let  add ( birthDate  :  DateTime)  =
    birthDate.Add (    2.0)

type Volume =
| Liter of float
| USPint of float
| ImperialPint of float
```

### Après

```fsharp
module Fake

let add (birthDate: DateTime) =
    birthDate.Add(2.0)

type Volume =
    | Liter of float
    | USPint of float
    | ImperialPint of float
```

## Normalise les identifiants

Les identifiants sont normalisés en une valeur de remplacement.

### Avant

```fsharp
module Fake

let foo x = x + 1
```

### Après

```fsharp
module PLACEHOLDER_1

let PLACEHOLDER_3 PLACEHOLDER_2 = PLACEHOLDER_2 + 1
```
