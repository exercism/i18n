# Instructions

Ellen crée un jeu dans lequel le joueur doit combattre des extraterrestres.
Elle vient tout juste de découvrir la programmation orientée objet (POO) et elle est impatiente de tirer parti de ce que l'usage de `classes` pourrait apporter à son programme.

Pour le plus grand plaisir d'Ellen, tu as proposé ton aide et elle t'a confié la tâche de programmer les extraterrestres que le joueur doit combattre.


## 1. Crée la classe `Alien`

Définis la classe `Alien` avec un constructeur qui accepte deux paramètres `int` `x` et `y` et les range dans les variables membres `x_coordinate` et `y_coordinate`.
Chaque extraterrestre démarre également avec un niveau de santé de `3`, donc la variable membre `health` doit aussi être initialisée.

`health` doit être une variable membre privée.
Pour permettre aux autres parties du programme de lire les informations sur la santé, Ellen veut une méthode `public` `get_health()` qui renvoie un `int`.

```cpp
Alien alien{2, 0};
alien.x_coordinate;
// => 2
alien.y_coordinate;
// => 0
alien.get_health();
// => 3
```

Ainsi, chaque extraterrestre doit pouvoir suivre en interne sa propre position et sa santé.

## 2. La fonction `hit`

Ellen aimerait que la `class` Alien ait une méthode `hit` qui diminue de `1` la santé d'un objet extraterrestre lorsqu'elle est appelée.
Ainsi, elle peut simplement appeler `some_alien_instance.hit()` au lieu de devoir modifier manuellement la santé d'un extraterrestre.
Vérifie que les points de vie ne descendent pas en dessous de zéro.
La fonction doit renvoyer `true`.
Ellen veut introduire des boucliers plus tard, qui signaleraient alors `false` si le bouclier est levé.

```cpp
Alien alien {0, 0};
alien.get_health();
// => 3 (Initial health value)

alien.hit(); // Decrements health by 1 point.
alien.get_health();
// => 2
```

## 3. La fonction `is_alive`

Tu réalises que si la santé continue de baisser, elle finira probablement par atteindre `0`.
Ce serait une bonne idée d'ajouter une méthode `is_alive` qu'Ellen peut appeler rapidement pour vérifier si l'extraterrestre est... eh bien... en vie. 😉
`some_alien_instance.is_alive()` doit renvoyer un booléen.

```cpp
alien.get_health();
// => 1
alien.is_alive();
// => true
alien.hit();
alien.get_health();
// => 0
alien.is_alive();
// => false
```

## 4. La fonction `teleport`

Dans le jeu d'Ellen, les extraterrestres peuvent se téléporter !
Tu devras écrire une méthode `teleport` qui prend les valeurs `x_new` et `y_new` et modifie les coordonnées de l'extraterrestre en conséquence.
Pour l'instant, la fonction doit renvoyer `true`.
Ellen veut ajouter des bombes qui bloquent la téléportation dans les niveaux suivants, qui signaleraient alors `false` pour les tentatives de téléportation ratées.

```cpp
alien.teleport(5, -4);
alien.x_coordinate;
// => 5
alien.y_coordinate;
// => -4
```

## 5. La fonction `collision_detection`

Si les extraterrestres peuvent être touchés par quelque chose, ils doivent alors pouvoir détecter quand une telle collision risque de se produire.
Ellen a besoin de savoir si deux extraterrestres occupent les mêmes coordonnées.
La fonction `collision_detection()` prend un autre objet extraterrestre en argument et renvoie un `bool`.

```cpp
Alien lrrr {3, 6};
Alien ndnd {-2, 12};
lrrr.collision_detection(ndnd);
// => false
ndnd.teleport(3, 6);
ndnd.collision_detection(lrrr);
// => true
```
