# Les plages

[Les plages][range] représentent un intervalle entre deux valeurs.
Les types les plus courants qui prennent en charge les plages sont `Int`, `Char` et `String`.
On peut s'en servir pour beaucoup de choses : créer rapidement une collection, découper des _strings_, vérifier si une valeur est dans une plage, ou encore itérer sur ses éléments.
On les crée avec l'opérateur de plage `..` ou `...` (respectivement inclusif et exclusif).

```crystal
1..5  # A range containing 1, 2, 3, 4, 5
1...5 # A range containing 1, 2, 3, 4
```

Ces deux opérateurs existent pour créer des plages inclusives ou exclusives de la valeur de fin, ce qui est utile quand on travaille par exemple avec des indices commençant à zéro.

On peut aussi créer des plages avec l'initialiseur `Range`.

```crystal
Range.new(1, 5) # A range containing 1, 2, 3, 4, 5
```

~~~~exercism/note
Quand on crée une plage en Crystal avec les opérateurs de plage `..` ou `...`, et qu'on veut appeler une méthode sur cette plage, il faut entourer la plage de parenthèses.
Sinon, la méthode sera appelée sur le 2e argument de l'opérateur de plage.

```crystal
(1..5).size # => 5
1..5.size # => Error: undefined method 'size' for Int32
```
~~~~

## Obtenir des sous-chaînes

Pour découper une _string_, on peut utiliser l'opérateur de plage afin d'obtenir une sous-chaîne.
Il suffit pour cela de créer une plage avec l'indice de début et l'indice de fin de la sous-chaîne.

```crystal
"Hello World"[0..4] # => "Hello"
"Hello World"[6..10] # => "World"
```

On peut aussi utiliser des indices négatifs pour obtenir la sous-chaîne à partir de la fin de la _string_.

```crystal
"Hello World"[-5..-1] # => "World"
"Hello World"[6..-4] # => "Wo"
```

## Les méthodes des plages

Les plages disposent d'un ensemble de méthodes pour travailler avec elles.
Par exemple, ces méthodes permettent d'obtenir la somme de toutes les valeurs de la plage ou de vérifier si la plage contient une valeur.

| Méthode                 | Description                                                             | Exemple                         |
|-------------------------|-------------------------------------------------------------------------|---------------------------------|
| [`sum`][sum]            | Renvoie la somme de toutes les valeurs de la plage                      | `(1..5).sum # => 15`            |
| [`size`][size]          | Renvoie la taille de la plage                                           | `(1..5).size # => 5`            |
| [`includes?`][indludes] | Renvoie `true` si la plage contient la valeur donnée, sinon `false`      | `(1..5).includes?(3) # => true` |

## Les plages sans fin et sans début

Une plage peut être sans fin ou sans début.
Une plage sans fin ou sans début a pour valeur de début ou de fin `nil`, mais on peut omettre `nil` quand on définit la plage.

Utiliser des plages sans début et sans fin est pratique quand on veut, par exemple, découper une _string_ depuis le début ou jusqu'à la fin.

```crystal
"Hello World"[0..] # => "Hello World"
"Hello World"[4..] # => "o World"
"Hello World"[..5] # => "Hello"
```

~~~~exercism/caution
Si on ne l'utilise pas sur une collection, une plage sans fin peut provoquer une séquence infinie, si on n'y prend pas garde.
~~~~

## Les plages de caractères

On peut utiliser des caractères dans des plages, ce qui permet d'obtenir un intervalle de caractères entre deux caractères.
C'est par exemple pratique quand on veut obtenir l'alphabet.

```crystal
'a'..'z' # A range containing ['a', 'b', 'c', ..., 'z']
```

## Les plages de _strings_

On peut aussi utiliser des _strings_ dans des plages, ce qui permet d'obtenir un intervalle de _strings_ entre deux _strings_.
Mais leur comportement est légèrement différent de celui de `Char` quand plusieurs caractères sont utilisés dans une plage de _strings_.
Ce comportement peut devenir déroutant avec des plages de _strings_ plus complexes, alors sois prudent.

```crystal
("aa".."az") # A range containing ["aa", "ab", "ac", ..., "az"]
```

## Les objets personnalisés dans les plages

~~~~exercism/advanced
Crystal permet d'utiliser des objets personnalisés dans des plages.
Pour cela, l'objet doit implémenter les éléments suivants :

- inclure le module `Comparable`
- la méthode `succ`
- la méthode `<=>`

Ces méthodes permettent à la plage d'itérer sur l'objet et de comparer les objets qu'elle contient.

```crystal
class Foo
  include Comparable(Foo)

  getter value

  def initialize(@value : Int32)
  end

  def succ
    Foo.new(value + 1)
  end

  def <=>(other : Foo)
 value <=> other.value
  end
end

Foo.new(1)..Foo.new(5)
# => #<Foo:0x7f3552bebe70 @value=1>, #<Foo:0x7f3552bebe50 @value=2>, #<Foo:0x7f3552bebe40 @value=3>, #<Foo:0x7f3552bebe30 @value=4>, #<Foo:0x7f3552bebe20 @value=5>
```
~~~~
