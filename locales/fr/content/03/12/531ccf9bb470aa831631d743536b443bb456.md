## General

- Classer une liste de mains de poker peut se voir comme un problème de tri.
- Rust fournit la méthode [sort](https://doc.rust-lang.org/std/vec/struct.Vec.html#method.sort) pour `Vec<T> where T: Ord`.
- [les types `Ord`](https://doc.rust-lang.org/std/cmp/trait.Ord.html) forment un [ordre total](https://en.wikipedia.org/wiki/Total_order) : exactement l'une des affirmations `a < b`, `a == b` ou `a > b` doit être vraie.
- Les mains de poker ne respectent pas un ordre total : il est possible que deux mains soient différentes tout en ayant le même ordre de tri. Exemple : `"3S 4S 5D 6H JH"`, `"3H 4H 5C 6C JD"`.
- Rust fournit [le trait `PartialOrd`](https://doc.rust-lang.org/std/cmp/trait.PartialOrd.html) pour gérer le cas d'éléments triables qui n'ont pas d'ordre total. En revanche, il ne fournit pas de méthode `sort` standard pour `Vec<T> where T: PartialOrd`. L'idiome standard pour trier un vecteur dans ce cas est `your_vec.sort_by(|a, b| a.partial_cmp(b).unwrap_or(Ordering::{Less|Equal|Greater}));`, selon tes besoins.
- Tu pourrais envisager d'implémenter un type représentant une main de poker qui implémente `PartialOrd`.
