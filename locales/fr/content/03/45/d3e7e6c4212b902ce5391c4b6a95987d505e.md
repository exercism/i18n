# Indices

## Généralités

- Ne t'inquiète pas de la façon dont les arguments sont _dérivés_ : concentre-toi sur la combinaison des arguments pour renvoyer le résultat attendu.

## 1. Définis si le personnage obtient des points bonus

- Tu peux utiliser [l'opérateur logique ET][and] pour combiner les arguments afin d'obtenir un résultat.

## 2. Définis si le personnage marque

- Tu peux utiliser [l'opérateur logique OU][or] pour combiner les arguments afin d'obtenir un résultat.

## 3. Définis si le personnage perd

- Tu peux utiliser [l'opérateur logique NON][not] pour inverser un argument afin d'obtenir un résultat.

## 4. Définis si le personnage gagne

- Tu peux utiliser les méthodes précédentes pour combiner les arguments afin d'obtenir un résultat.

[not]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/basicoperators/#Logical-NOT-Operator
[and]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/basicoperators/#Logical-AND-Operator
[or]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/basicoperators/#Logical-OR-Operator
