# Introduction

En Go, les fonctions sont des valeurs de première classe.
Cela signifie qu'on peut faire avec les fonctions la même chose qu'avec toutes les autres valeurs : les affecter à des variables, les passer en arguments à d'autres fonctions, ou même renvoyer des fonctions depuis d'autres fonctions.

Ci-dessous, on crée deux fonctions, `engGreeting` et `espGreeting`, et on les affecte à la variable `greeting` :

```go
import "fmt"

func engGreeting(name string) string {
	return fmt.Sprintf("Hello %s, nice to meet you!", name)
}

func espGreeting(name string) string {
	return fmt.Sprintf("¡Hola %s, mucho gusto!", name)
}

greeting := engGreeting			// greeting is a variable of type func(string) string
fmt.Println(greeting("Alice"))	// Hello Alice, nice to meet you!

greeting = espGreeting
fmt.Println(greeting("Alice")) 	// ¡Hola Alice, mucho gusto!
```

Les valeurs de fonction offrent la possibilité de paramétrer des fonctions non seulement avec des données, mais aussi avec du comportement.
Dans l'exemple suivant, on passe du comportement à la fonction `dialog` via le paramètre `greetingFunc` :

```go
func dialog(name string, greetingFunc func(string) string) {
	fmt.Println(greetingFunc(name))
	fmt.Println("I'm a dialog bot.")
}

func espGreeting(name string) string {
	return fmt.Sprintf("¡Hola %s, mucho gusto!", name)
}

greeting := espGreeting
dialog("Alice", greeting)
// =>
// ¡Hola Alice, mucho gusto!
// I'm a dialog bot.
```

La valeur d'une variable non initialisée de type fonction est `nil`.
Par conséquent, appeler une valeur de fonction `nil` provoque un _panic_.

```go
var dutchGreeting func(string) string
dutchGreeting("Alice") // panic: call of nil function
```

Les valeurs de fonction peuvent être comparées à `nil`.
Cela peut être utile pour éviter des _panics_ inutiles dans le programme.

```go
var dutchGreeting func(string) string
if dutchGreeting != nil {
	dutchGreeting("Alice") // safe to call dutchGreeting
}
```

## Types de fonction

Utiliser des valeurs de fonction est possible grâce aux types de fonction de Go.
Un type de fonction désigne l'ensemble de toutes les fonctions ayant la même séquence de types de paramètres et la même séquence de types de résultats.
On peut déclarer des types définis par l'utilisateur à partir de types de fonction.
Par exemple, la fonction `dialog` des exemples précédents peut être mise à jour comme suit :

```go
type greetingFunc func(string) string

func dialog(name string, f greetingFunc) {
	fmt.Println(f(name))
	fmt.Println("I'm a dialog bot.")
}
```

## Fonctions anonymes

La prise en charge des fonctions de première classe offre un autre outil puissant : les fonctions anonymes.
Les fonctions anonymes sont définies au moment de leur utilisation, sans nom après le mot-clé `func`.
De telles fonctions ont accès aux variables de la fonction englobante.

Par exemple :

```go
func fib() func() int {
	var n1, n2 int

	return func() int {
		if n1 == 0 && n2 == 0 {
			n1 = 1
		} else {
			n1, n2 = n2, n1 + n2
		}
		return n2
	}
}

next := fib()
for i := range N {
  fmt.Printf("F%d\t= %4d\n", i, next())
}
```

Un appel à `fib` déclare les variables `n1` et `n2` et renvoie une fonction anonyme qui, à son tour, modifie les valeurs de ces variables à chaque appel de la fonction.
Le N-ième appel de la fonction anonyme renvoie le N-ième nombre de la suite de Fibonacci en partant de 0. La fonction interne anonyme a accès aux variables locales (`n1` et `n2`) de la fonction englobante `fib`.
C'est un excellent moyen de faire conserver un état aux valeurs de fonction entre les appels.
On dit que la fonction anonyme est une fermeture des variables `n1` et `n2`. [Les fermetures][closure] sont largement utilisées en programmation et tu pourrais voir d'autres langages les prendre en charge.
