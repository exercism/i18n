# Complément d'instructions

## Astuces

Pour cet exercice, la fonctionnalité F# suivante est bien utile :

- Les [séquences](https://docs.microsoft.com/en-us/dotnet/articles/fsharp/language-reference/sequences) sont évaluées de manière paresseuse. Elles permettent de travailler avec une séquence infinie de valeurs.

Note : pour accélérer le calcul, il ne faut pas tester les nombres dont on sait à l'avance qu'ils ne seront jamais premiers. Pour plus d'informations, voir le [crible d'Ératosthène](https://en.wikipedia.org/wiki/Sieve_of_Eratosthenes).
