# Introduction

On a vu dans le concept `Vectors` qu'un vecteur peut être utilisé dans une expression conditionnelle, ce qui donne un vecteur logique. Celui-ci peut à son tour être utilisé dans des fonctions telles que `all()` et `any()`.

```R
v <- c(4, 7, 10)
v >= 6
#> [1] FALSE  TRUE  TRUE
all(v > 6)
#> [1] FALSE    # not all elements match this condition
any(v > 6)
#> [1] TRUE     # at least one element matches
```

La technique est bien plus puissante que cela.

## Sous-ensembles de vecteurs

On peut extraire des éléments choisis d'un vecteur à l'aide d'un numéro d'indice ou d'un vecteur d'indices :

```R
v <- 5:10
v
#> [1]  5  6  7  8  9 10
v[3] 
#> [1] 7
v[c(2, 4)]
#> [1] 6 8
```

Autrement, on peut utiliser un vecteur logique pour filtrer le vecteur d'origine, ce qui renvoie un sous-ensemble d'éléments associés à la valeur `TRUE` :

```R
v <- 1:3
bools <- c(FALSE, TRUE, TRUE)
v[bools]
#> [1] 2 3
```

À partir de là, il n'y a qu'un pas pour générer le vecteur booléen à l'aide d'une expression conditionnelle :

```R
bools <- v >= 2
bools
#> [1] FALSE  TRUE  TRUE

v[bools]
#> [1] 2 3

# simpler form
v[v >= 2]
#> [1] 2 3
```

## Trouve les indices

La fonction `which()` prend un argument booléen et renvoie un vecteur d'indices qui donnent `TRUE`.

```R
v
#> [1] 2 7 9

v[v > 5]  # returns values
#> [1]  7  9

which(v > 5) # returns indices
#> [1] 2 3
```

## Vérifie si un élément existe

Les sections précédentes portaient sur la recherche d'éléments correspondant à un certain critère.

Si tu as simplement besoin de savoir si le vecteur contient un élément précis, on utilise l'opérateur `%in%`.

```R
3 %in% 1:5
#> [1] TRUE
7 %in% 1:5
#> [1] FALSE
```

C'est fonctionnellement équivalent au code suivant, mais bien plus pratique :

```R
v <- 1:5
length(v[v == 3]) > 0
#> [1] TRUE
```
