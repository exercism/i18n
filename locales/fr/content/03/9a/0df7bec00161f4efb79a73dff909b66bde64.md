# Introduction

Une [`List`][lists] en Elm est une collection immuable de zéro ou plusieurs valeurs du même type.

On peut définir des listes comme suit :

```elm
empty = []
singleValue = [ 5 ]
threeValues = [ "a", "b", "c" ]
```

La façon la plus courante d'ajouter un élément à une liste est d'utiliser l'opérateur `::` (cons) :

```elm
twoToFour = [ 2, 3, 4 ]
oneToFour = 1 :: twoToFour --> [ 1, 2, 3, 4 ]
```

On manipule les listes à l'aide de fonctions et d'opérateurs définis dans le [module `List`][list-module] ou par [filtrage par motif][list-destructuring].

```elm
describe : List String -> String
describe list =
    case list of
        [] ->
            "Empty list"

        [ "hello" ] ->
            "Singleton list with: hello"

        x :: xs ->
            "Non-empty list with head: " ++ x

describe []                   --> "Empty list"
describe [ "hello" ]          --> "Singleton list with: hello"
describe [ "hello", "world" ] --> "Non-empty list with head: hello"
```
