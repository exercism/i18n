# Instructions

L'exercice d'introduction classique. Dis simplement « Hello, World! ».

[« Hello, World! »](http://en.wikipedia.org/wiki/%22Hello,_world!%22_program) est
le premier programme traditionnel pour débuter la programmation dans un nouveau langage
ou environnement.

Les objectifs sont simples :

- Modifie le code fourni pour qu'il produise la _string_ « Hello, World! ».
- Lance la suite de tests et assure-toi qu'elle réussit.
- Soumets ta solution et vérifie-la sur le site web.

Si tout se passe bien, tu seras prêt à récupérer ton premier véritable exercice.
