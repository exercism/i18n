# Instructions

Implémente une fonction qui utilise la logique propositionnelle pour recréer les propriétés suivantes :

1. A & B == (A' | B')' (DeMorgan's Law)
2. [A -> (A -> B)] -> (A -> B)
3. A & (B' -> A') -> B

La fonction doit renvoyer les trois théorèmes écrits en notation Z3.  
Utilise la fonction prove() pour confirmer l'exactitude de tes théorèmes.  
Renvoie les trois théorèmes, dans l'ordre, à la fin de la fonction.
