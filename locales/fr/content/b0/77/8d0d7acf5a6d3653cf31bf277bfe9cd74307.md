# Indices pour l'exercice Démineur en Bash

Cet exercice semble nécessiter un tableau à deux dimensions.
Bash ne propose que des [tableaux][array] à une dimension, indexés ou associatifs.

On peut simuler des tableaux multidimensionnels en utilisant un tableau associatif : il suffit d'encoder les indices dans une chaîne de caractères séparés par des virgules pour s'en servir comme clé du tableau.

```bash
# store this matrix:
#   a b
#   c d
declare -A array2d
array2d["0,0"]="a"
array2d["0,1"]="b"
array2d["1,0"]="c"
array2d["1,1"]="d"
```

[array]: https://www.gnu.org/software/bash/manual/bash.html#Arrays
