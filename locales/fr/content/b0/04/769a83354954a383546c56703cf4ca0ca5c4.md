# Instructions

Dans cet exercice, tu vas mettre en place la gestion des erreurs d'une calculatrice simple.

L'objectif est d'obtenir une calculatrice fonctionnelle qui renvoie une chaîne de caractères selon le modèle suivant : `16 + 51 = 67`, lorsqu'on lui fournit les arguments `16`, `51` et `+`.

```ruby
SimpleCalculator.calculate(16, 51, "+")
# => "16 + 51 = 67"
SimpleCalculator.calculate(32, 6, "*")
# => "32 * 6 = 192"
SimpleCalculator.calculate(512, 4, "/")
# => "512 / 4 = 128"
```

## 1. Gère le code qui peut lever des erreurs dans la méthode `calculate`

La méthode principale à implémenter dans cette tâche sera la méthode de classe `SimpleCalculator.calculate()`.
Elle prend trois arguments.
Les deux premiers arguments sont les nombres sur lesquels une opération va être effectuée.
Le troisième argument est de type _string_ et, pour cet exercice, il est nécessaire d'implémenter les opérations suivantes :

- l'addition à l'aide du _string_ `+`
- la multiplication à l'aide du _string_ `*`
- la division à l'aide du _string_ `/`

## 2. Gère les opérations illégales

Modifie la méthode `SimpleCalculator.calculate()` pour lever une exception `UnsupportedOperation` lorsque le symbole de l'opération est inconnu.

```ruby
SimpleCalculator.calculate(1, 2, '-')
# => Raises an UnsupportedOperation
```

~~~~exercism/note
Dans cet exercice, on attend de toi que tu définisses l'exception `UnsupportedOperation` pour une portée spécifique.
~~~~

## 3. Gère les arguments invalides

Modifie la méthode `SimpleCalculator.calculate()` pour lever une exception `ArgumentError` lorsque les types des arguments sont invalides.

```ruby
SimpleCalculator.calculate(1, '2', '*')
# => Raises an ArgumentError
```

## 4. Gère les exceptions de division par zéro

Modifie la méthode `SimpleCalculator.calculate()` pour gérer les exceptions `ZeroDivisionError`.
Le code de gestion doit renvoyer le _string_ dont le contenu est `Division by zero is not allowed.`.
Toute autre exception ne doit pas être gérée par la méthode `SimpleCalculator.calculate()`.

```ruby
SimpleCalculator.calculate(512, 0, "/")
# => returns "Division by zero is not allowed."
```
