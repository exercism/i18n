# Instructions supplémentaires

## Registres

| Registre | Utilisation  | Type    | Description                                      |
| -------- | ------------ | ------- | ------------------------------------------------ |
| `$a0`    | entrée       | adresse | chaîne de caractères de la question terminée par un caractère nul |
| `$v0`    | sortie       | entier  | résultat, 0 si la question n'est pas valide      |
| `$t0-9`  | temporaire   | quelconque | pour un stockage temporaire                   |
