# Introduction

## Boucles _while_

Avec une boucle _while_, on peut exécuter du code de manière répétée tant qu'une certaine condition est remplie.
Elle s'écrit avec le mot-clé `while`, suivi d'une condition entre parenthèses, et d'un bloc de code contenant le _corps_ de la boucle entre accolades.

```javascript
while (condition) {
  // code that is executed repeatedly as long as the condition is true
}
```

JavaScript dispose aussi d'une boucle _do-while_.
Ici, la condition est vérifiée après l'exécution du corps de la boucle.
C'est utile lorsque la condition dépend d'évaluations effectuées dans le corps.

```javascript
do {
  // The code here will always be executed once and then
  // repeatedly while the condition is true.
} while (condition);
```

À l'intérieur du corps d'une boucle, on peut utiliser le mot-clé `break` pour arrêter complètement l'exécution de la boucle.
En revanche, le mot-clé `continue` arrête seulement l'exécution de l'itération en cours et passe à la suivante.
Avec `continue`, on peut souvent éviter d'envelopper de grandes parties du corps de la boucle dans une instruction `if`.

```javascript
let i = 0;

while (i < 100) {
  i = i + 2;

  if (i % 3 === 0) {
    continue;
  }

  // The code here will only be executed when i was not divisible
  // by 3 in the check above.
}
```

## Instructions _switch_

Outre l'instruction `if`, JavaScript dispose aussi d'une instruction _switch_ pour exécuter conditionnellement de la logique.
Elle est utilisée lorsqu'une seule variable doit être comparée à plusieurs variantes.
La comparaison est effectuée en vérifiant l'égalité stricte (`===`), voir [concept de comparaison][concept-comparison].
Pour une variable `x` donnée, l'instruction _switch_ en JavaScript a la syntaxe suivante :

<!-- prettier-ignore-start -->
```javascript
switch (x) {
  case option1:
    // code that is executed when "x === option1" is true
    break;
  case option2:
    // code that is executed when "x === option2" is true
    break;
  default:
    // code that is executed when x does not equal any of the options
}
```
<!-- prettier-ignore-end -->

Le cas `default` est facultatif et s'utilise si l'on veut exécuter du code lorsque aucune des autres options ne correspond à la variable.

Les instructions `break` ci-dessus sont nécessaires car, par défaut, tous les cas sont « fallthrough » en JavaScript.
Cela signifie que, sans instruction `break`, tout le code des cas situés sous la première option correspondante serait exécuté même si `x` ne correspondait pas à ces options.
Ce comportement de « fallthrough par défaut » est un piège courant lorsqu'on utilise `switch` en JavaScript.
À l'intérieur d'une fonction, on peut aussi utiliser `return` à la place de `break` pour éviter ce problème.
