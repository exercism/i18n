# Jeu de rôle

## Histoire

Dans cet exercice, tu joues à un jeu de rôle nommé « Wizard and Warriors », qui te permet d'incarner soit un magicien, soit un guerrier.

Les règles diffèrent entre les guerriers et les magiciens pour déterminer le nombre de points de dégâts qu'ils infligent.

Pour un guerrier, les règles sont les suivantes :

- Infliger 6 points de dégâts si le personnage attaqué n'est pas vulnérable
- Infliger 10 points de dégâts si le personnage attaqué est vulnérable

Pour un magicien, les règles sont les suivantes :

- Infliger 3 points de dégâts si le magicien n'a pas préparé de sort à l'avance
- Infliger 12 points de dégâts si le magicien a préparé un sort à l'avance

En général, les personnages ne sont jamais vulnérables. Cependant, les magiciens _sont_ vulnérables s'ils n'ont pas préparé de sort.

## Tâches

L'histoire amène à définir des fonctions :

- Décrire un personnage
- Rendre les personnages non vulnérables par défaut
- Permettre aux magiciens de préparer un sort
- Rendre les magiciens vulnérables lorsqu'ils n'ont pas préparé de sort
- Calculer les points de dégâts d'un magicien
- Calculer les points de dégâts d'un guerrier
