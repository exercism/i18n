# arguments splat inattendus

Définis un paramètre nommé `%{splat-arg.name}` de type `%{parameter.type}`,
au lieu d'utiliser `...%{splat-arg.name}: %{parameter.type}[]`.

Les [paramètres du reste / arguments splat](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Functions/rest_parameters)
sont très pratiques quand la fonction ne dicte pas le nombre de valeurs qu'elle doit
recevoir, mais dans ce cas, le nombre de valeurs avec lesquelles la fonction sera
appelée est défini explicitement.
