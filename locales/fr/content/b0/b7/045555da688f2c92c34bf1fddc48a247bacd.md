# Introduction

Un _template_ est une _string_ ou un fichier utilisé pour produire n'importe quel type de sortie textuelle en fonction de l'entrée.

```haxe
var sample = "My name is ::name::";
var template = new haxe.Template(sample);
var myName = {name: "Joe"};
var output = template.execute(myName);

trace(output); // My name is Joe
```

Entre autres choses, on peut aussi utiliser des conditions pour effectuer des vérifications à l'intérieur des _templates_ :

```haxe
var sample = "::if isAwake:: I'm awake ::else:: Zzzzz ::end::";
var template = new haxe.Template(sample);
var awake = {isAwake: false};
var output = template.execute(awake);

trace(output); // Zzzzz
```
