# Toutes les combinaisons implémentées

Bien que cette solution passe les tests, elle est fortement couplée aux cas particuliers. Imagine toutes les nouvelles combinaisons qu'il faudrait ajouter si un ou plusieurs cas supplémentaires étaient demandés. Elle deviendrait rapidement difficile à maintenir.
Essaie de concaténer les _strings_, par exemple en utilisant l'opérateur `+=`.
