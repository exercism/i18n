# À propos

Go propose des types numériques de base qui peuvent représenter des ensembles de valeurs entières ou à virgule flottante.
Il existe différents types selon la taille de la valeur dont tu as besoin et l'architecture de l'ordinateur sur lequel l'application s'exécute (par exemple 32 bits et 64 bits).

Ce concept se concentre sur deux types de nombres :

- `int` : par exemple `0`, `255`, `2147483647`.
   Un entier signé qui fait au moins 32 bits (plage de valeurs : de -2147483648 à 2147483647).
   Cela dépend toutefois de l'architecture du système.
   La plupart des ordinateurs modernes sont en 64 bits, donc `int` occupe 64 bits (plage de valeurs : de -9223372036854775808 à 9223372036854775807).

- `float64` : par exemple `0.0`, `3.14`.
   Contient l'ensemble de tous les nombres à virgule flottante sur 64 bits.

Pour une liste complète des types numériques disponibles et plus de détails, consulte les ressources suivantes :

- [Déclarations des types intégrés de Go][go-builtins]
- [Digital Ocean - Comprendre les types de données en Go][do-understanding-types]
- [Arden Labs - Comprendre les types en Go][arden-understanding-types]

Go prend en charge l'ensemble standard des opérateurs arithmétiques `+`, `-`, `*`, `/` et `%` (le reste, pas le modulo).

En Go, affecter une valeur entre différents types nécessite une conversion explicite.
Par exemple, pour convertir un `int` en `float64`, tu dois procéder comme suit :

```go
var x int = 42
f := float64(x)

fmt.Printf("x is of type: %s\n", reflect.TypeOf(x))
// Output: x is of type: int

fmt.Printf("f is of type: %s\n", reflect.TypeOf(f))
// Output: f is of type: float64
```

Pour plus d'informations sur la conversion de types, consulte [A Tour of Go: Type Conversions][type-conversion]
