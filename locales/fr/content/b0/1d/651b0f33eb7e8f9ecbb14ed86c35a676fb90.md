# Préférer une constante de niveau supérieur

Pense à extraire le nombre `GIGASECOND` dans une constante :

```javascript
const %{name} = %{value}

// the rest of your code below it
export const gigasecond = (...)
```

Seules les fonctions, les classes et les constantes marquées `export` sont visibles et
accessibles depuis l'extérieur. Il est généralement judicieux de donner un nom aux
[nombres magiques](https://en.wikipedia.org/wiki/Magic_number_%%28programming%%29), ce qui
améliore la maintenabilité. Ces constantes peuvent rester dans le même fichier sans être
exposées au reste du code.
