# Tests

## Exécute les tests
Pour exécuter les tests d'une implémentation spécifique d'un exercice, voici les étapes recommandées :

1. crée ton implémentation dans `[SLUG].v`
1. place-toi dans le répertoire où se trouvent `[SLUG].v` et `run_test.v`
1. exécute `v -stats test run_test.v`

## Teste en V
Pour plus d'informations sur les tests en V, consulte la [documentation officielle](https://github.com/vlang/v/blob/master/doc/docs.md#testing)
