# À propos

Un StringBuf est un moyen efficace de construire une grande _string_ en ajoutant de petits éléments les uns à la suite des autres. Contrairement à String, une instance de StringBuf n'est pas immuable : on peut la passer en argument à des fonctions qui la modifient en y ajoutant d'autres valeurs.

```haxe
var a = new StringBuf();
a.add("Hello");
trace(a.toString()); // Hello
a.add("Haxe!");
trace(a.toString()); // HelloHaxe
```
