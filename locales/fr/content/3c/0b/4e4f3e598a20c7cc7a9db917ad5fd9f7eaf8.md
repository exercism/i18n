# Introduction

Les objets peuvent conserver leur propre état en définissant des _variables d'instance_, que l'on crée en plaçant un `@` devant le nom de la variable.

```ruby
@name = 2
```

Les objets définissent généralement leur état initial dans une méthode `initialize`, qui est automatiquement appelée lorsqu'on appelle `new` sur une classe.

```ruby
class Airplane
  def initialize
    @wings = 2
  end
end
```

La méthode `initialize` peut aussi prendre des arguments, pour que chaque instance puisse démarrer avec un état personnalisé :

```ruby
class Suitcase
  def initialize(locked)
    @locked = locked
  end
end
```

Considère les _variables d'instance_ comme privées : on ne les lit ni ne les modifie depuis l'extérieur. Pour lire et modifier une variable d'instance, il faut passer par des _méthodes d'instance_ :

```ruby
class Suitcase
  #...

  def locked? # Query methods should be named with a trailing `?`
    @locked
  end

  def unlock! # Methods which mutate state should have trailing `!`
    @locked = false
  end
end
```
