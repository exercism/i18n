# Indices

## Général

- La syntaxe `0b00` permet de spécifier un `int` en binaire plutôt qu'en décimal.

## 1. Encode un acide nucléique en valeur binaire

- On peut faire du filtrage par motif sur le type de nucléotide avec une expression `case`.

## 2. Décode la valeur binaire en acide nucléique

- On peut utiliser la syntaxe des `int` binaires dans les motifs.
- Renvoie `Error(Nil)` si la valeur `int` n'est pas un nucléotide valide.

## 3. Encode une liste d'ADN

- On peut utiliser la fonction `encode_nucleotide` pour encoder un seul nucléotide.

## 4. Décode un tableau de bits d'ADN

- On peut utiliser la syntaxe des `int` binaires dans un motif de tableau de bits.
- Renvoie `Error(Nil)` si le tableau de bits restant n'est pas assez long pour contenir un nucléotide.
