# Introduction

L'expression `let` sert à créer une portée locale, et elle est utile dans quelques situations :

- pour simplifier des expressions
- pour nommer les résultats d'expressions intermédiaires
- pour découper une expression en morceaux plus petits lorsqu'elle devient trop grande

On peut faire la plupart des choses à l'intérieur d'une expression `let`, y compris de la déstructuration (on reviendra plus en détail sur ce point dans les exercices suivants), mais il n'est pas possible de définir un nouveau type personnalisé ni un alias de type.

```elm
let
  cube x = x * x * x
in
  cube a + cube b + cube c
```

```elm
beginWithPattern : Size -> Padding -> Pattern -> GameOfLife
beginWithPattern minimumSize padding pattern =
    let
        size = calculateSize minimumSize padding pattern

        center = Size.center size

        centeredPattern = Pattern.centerAt center pattern

        dimensions = { width = size, height = size }

        deadCells = Matrix.create dimensions Dead
    in
    GameOfLife (bringPatternToLife deadCells centeredPattern)
```
