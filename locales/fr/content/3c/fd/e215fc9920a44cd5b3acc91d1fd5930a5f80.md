# Instructions

Convertis un nombre binaire, représenté sous forme de _string_ (par exemple '101010'), en son équivalent décimal en partant des principes de base.

Implémente la conversion du binaire vers le décimal. Étant donné une _string_ binaire en entrée, ton programme doit produire une sortie décimale. Le programme doit aussi gérer les entrées invalides.

## Remarque

- Implémente la conversion toi-même.
  N'utilise pas autre chose pour effectuer la conversion à ta place.

## À propos du binaire (base 2)

Le décimal est un système en base 10.

Un nombre comme 23 en base 10 peut se comprendre comme une combinaison linéaire des puissances de 10 :

- Le chiffre le plus à droite est multiplié par 10^0 = 1
- Le suivant est multiplié par 10^1 = 10
- ...
- Le *n*-ième nombre est multiplié par 10^*(n-1)*.
- Toutes ces valeurs sont additionnées.

Donc : `23 => 2*10^1 + 3*10^0 => 2*10 + 3*1 = 23 base 10`

Le binaire fonctionne de la même manière, mais utilise les puissances de 2 plutôt que les puissances de 10.

Donc : `101 => 1*2^2 + 0*2^1 + 1*2^0 => 1*4 + 0*2 + 1*1 => 4 + 1 => 5 base 10`.
