# Introduction

Une méthode est une fonction avec un argument _récepteur_ particulier.
Le récepteur apparaît dans sa propre liste d'arguments, entre le mot-clé `func` et le nom de la méthode.

```go
func (receiver type) MethodName(parameters) (returnTypes) {
}
```

Tu ne peux définir une méthode avec un récepteur que si le type de ce récepteur est défini dans le même paquet que la méthode.

```go
package person 

type Person struct {
	Name string
}

func (p Person) Greetings() string {
	return fmt.Sprintf("Welcome %s!", p.Name)
}
```

La méthode définie sur la structure peut être appelée avec la notation pointée.

```go
p := Person{Name: "Bronson"}
fmt.Println(p.Greetings())
// Output: Welcome Bronson!
```

Remarque la façon dont on a appelé la méthode `Greetings()` sur l'instance `p` de `Person`.
C'est exactement comme on appelle les méthodes dans un langage de programmation orienté objet.

Rappel : une méthode n'est qu'une fonction avec un argument récepteur.
Les méthodes aident à éviter les conflits de nommage. En effet, comme une méthode est liée à un type de récepteur particulier, on peut avoir le même nom de méthode sur des types différents.

```go
import "math"

type rect struct {
	width, height int
}
func (r rect) area() int {
	return r.width * r.height
}

type circle struct {
	radius int
}
func (c circle) area() float64 {
	return math.Pow(float64(c.radius), 2) * math.Pi
}
```

Il existe deux types de récepteurs : les récepteurs de valeur et les récepteurs de pointeur.

Toutes les méthodes que l'on a vues jusqu'ici ont un récepteur de valeur, ce qui signifie qu'elles reçoivent une copie de la valeur passée à la méthode. Toute modification effectuée sur le récepteur à l'intérieur de la méthode n'est donc pas visible pour l'appelant.

Tu peux déclarer des méthodes avec des récepteurs de pointeur afin de modifier la valeur vers laquelle pointe le récepteur.
Pour cela, on fait précéder le nom du type d'un `*`.
Par exemple, pour le type `rect`, un récepteur de pointeur serait déclaré `*rect`.
Ces modifications sont également visibles pour l'appelant de la méthode.

```go
type rect struct {
	width, height int
}
func (r *rect) squareIt() {
	r.height = r.width
}

r := rect{width: 10, height: 20}
fmt.Printf("Width: %d, Height: %d\n", r.width, r.height)
// Output: Width: 10, Height: 20

r.squareIt()
fmt.Printf("Width: %d, Height: %d\n", r.width, r.height)
// Output: Width: 10, Height: 10
```
