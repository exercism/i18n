# Indices

## Général

- Lis la section sur les processus dans le [guide de démarrage officiel][getting-started-processes].
- Lis [cet article de blog][mullen-processes] sur les processus en Elixir.

## 1. Démarre la machine

- La machine doit tourner dans un nouveau processus. Il existe [une fonction intégrée qui démarre un nouveau processus][kernel-spawn-1].
- Utilise une fonction anonyme d'arité 0 pour démarrer un nouveau processus. Cette fonction n'a pas encore besoin de faire quoi que ce soit.

## 2. Rapporte l'état de la machine

- Tu vas avoir besoin d'une nouvelle fonction nommée. Tu peux par exemple l'appeler `loop`.
- Cette nouvelle fonction doit prendre un argument : l'état.
- La fonction anonyme d'arité 0 de l'étape précédente peut appeler la nouvelle fonction nommée en lui passant l'état initial.
- La nouvelle fonction nommée doit répondre aux messages.
- Il existe [une fonction intégrée qui attend qu'un message arrive dans la boîte aux lettres du processus][kernel-receive].
- Il existe [une fonction intégrée qui envoie un message à un autre processus][kernel-send].
- Utilise la récursion pour attendre plus d'un message.

## 3. Distribue des nombres

- Cette étape est conceptuellement identique à la précédente. La seule différence est la nécessité de mettre à jour l'état de la machine.

## 4. Arrête la machine

- Cette étape ne nécessite l'envoi d'aucun message en réponse.
- Un processus se termine s'il n'a plus de code à exécuter.
- Quand tu as besoin de créer un bloc de code « vide » en Elixir, tu peux utiliser `nil` comme seule expression dans ce bloc de code.
- C'est un cas de base de la fonction récursive.

## 5. Ignore les messages inattendus

- Cette étape ne nécessite l'envoi d'aucun message en réponse.
- Tu peux utiliser `_` pour capturer tous les messages qui ne correspondaient à aucun motif précédent.
