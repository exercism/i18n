# Top secret

## Histoire

Tu luttes contre l'espionnage industriel avec l'aide d'une informatrice secrète qui encode des messages secrets via son code.

## Tâches

L'apprenant implémente une fonction pour décoder des messages à partir d'un code source, selon les étapes suivantes :

- Transformer le code source en AST
- Analyser un seul nœud : si le nœud est une définition de fonction, renvoyer le nom de la fonction
- Étendre l'analyse : ne renvoyer qu'un nombre de caractères égal au nombre d'arguments que la fonction reçoit
- Décoder le message : parcourir tous les nœuds et concaténer les _strings_ renvoyées
