# Installation

## Installation

Tu trouveras des instructions d'installation détaillées sur [elixir-lang.org/install](https://elixir-lang.org/install.html).

Pour tirer le meilleur parti de ton apprentissage sur Exercism, on te recommande d'installer localement les mêmes versions du langage que celles utilisées pour exécuter les tests de tes soumissions d'exercices.
Ces versions sont **Erlang/OTP 26 et Elixir 1.16**.

Pour vérifier quelles versions sont installées, exécute `elixir --version` dans ta ligne de commande.
