## Importation

Un module se charge généralement avec le mot-clé `use`.
Cela charge le module et appelle sa méthode `import`, ce qui importe tous les symboles exportés.

Les symboles présents dans le tableau `@EXPORT` du paquet sont importés par défaut.
Les symboles présents dans le tableau `@EXPORT_OK` du paquet doivent être importés explicitement.

Avant Perl `v5.37`, un module devait se terminer par une valeur vraie (généralement `1`) pour indiquer qu'il s'était chargé correctement.
Ce n'est pas nécessaire quand on utilise la fonctionnalité [`module_true`][module_true].

## Exportation

Pour qu'un symbole puisse être importé, il doit d'abord être exporté.
Le module [Exporter][Exporter] est fourni avec Perl et constitue l'une des options les plus pratiques pour exporter.

Définition du module :
```perl
package Foo;

use Exporter ('import');
our @EXPORT_OK = ('bar');

sub bar { ... }
```

Utilisation du module :
```perl
use Foo ('bar');

bar();
```

## Pragma

Un pragma est un module qui influence un aspect du comportement de Perl.

Les pragmas [`strict`][strict] et [`warnings`][warnings] sont généralement recommandés, respectivement pour restreindre les constructions dangereuses et signaler les problèmes potentiels.
Le pragma `strict` est activé quand on écrit `use v5.12` ou une version supérieure.
Le pragma `warnings` est activé quand on écrit `use v5.35` ou une version supérieure.

Le pragma [`feature`][feature] permet d'activer des fonctionnalités de Perl plus récentes et expérimentales.
Quand on donne au mot-clé `use` une version précise de Perl, celui-ci active l'ensemble de fonctionnalités correspondant à cette version.

## Modules du cœur

En plus d'[Exporter][Exporter], Perl propose une grande variété de [modules du cœur][perl-core-modules] prêts à l'emploi.
Quelques exemples utiles pour les exercices que tu pourrais rencontrer ici : [List::Util][List::Util], [Time::Piece][Time::Piece] et [Math::BigRat][Math::BigRat].

## CPAN

En plus des modules du cœur, [CPAN][metacpan] propose des milliers de modules supplémentaires créés par la communauté Perl, disponibles à l'installation.
Le parcours Perl utilise un [cpanfile][test-runner-cpanfile] pour installer une sélection de modules utilisables avec l'exécuteur de tests Perl d'Exercism.
