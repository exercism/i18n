# Transformation de carburant en JSON

## Énoncé du problème

Chaque employé d'ABC Corp bénéficie d'une allocation de carburant illimitée. Les employés doivent envoyer un relevé chaque fois qu'ils font le plein de leur véhicule. Ces relevés sont ajoutés au même fichier JSON, puis traités à la fin du mois.

En tant que membre de l'équipe des opérations numériques, ta tâche consiste à lire ce fichier JSON et à écrire les résultats dans un autre fichier JSON. Le fichier de sortie doit contenir une entrée pour chaque employé, avec les informations suivantes :

- Numéro d'employé
- Nombre de pleins de carburant
- Coût total du carburant
- Nombre total de gallons
- Distance totale parcourue en miles

On te donne deux arguments de type `string`.

1. Chemin du fichier JSON d'entrée.
1. Chemin du fichier JSON de sortie.

Le fichier JSON d'entrée contient un tableau d'objets JSON. Chaque objet JSON prend la forme suivante.


```json
{
    "type": "array",
    "items": {
        "type": "object",
        "properties": {
            "employeeId": {
                "type": "integer"
            },
            "odometerReading": {
                "type": "integer"
            },
            "gallons": {
                "type": "number"
            },
            "gasPrice": {
                "type": "number"
            }
        },
        "required": [
            "employeeId",
            "odometerReading",
            "gallons",
            "gasPrice"
        ]
    }
}
```

```ballerina
// Ballerina record type definition
type FillUpEntry record {|
    int employeeId;
    int odometerReading;
    decimal gallons;
    decimal gasPrice;
|};
```

Ta tâche consiste à transformer l'entrée JSON dans le format JSON suivant et à écrire le contenu dans le chemin indiqué. Le fichier de sortie doit contenir une entrée pour chaque employé, triée par ordre croissant de `employeeId`.

```json
{
    "type": "array",
    "items": {
        "type": "object",
        "properties": {
            "employeeId": {
                "type": "integer"
            },
            "gasFillUpCount": {
                "type": "integer"
            },
            "totalFuelCost": {
                "type": "number"
            },
            "totalGallons": {
                "type": "number"
            },
            "totalMilesAccrued": {
                "type": "integer"
            }
        },
        "required": [
            "employeeId",
            "gasFillUpCount",
            "totalFuelCost",
            "totalGallons",
            "totalMilesAccrued"
        ]
    }
 }
```

```ballerina
// Ballerina record type definition
type EmployeeFillUpSummary record {|
    int employeeId;
    int gasFillUpCount;
    decimal totalFuelCost;
    decimal totalGallons;
    int totalMilesAccrued;
|};
```

## Contraintes

- Nombre de relevés de plein `n` dans le fichier JSON d'entrée : 0 <= n <= 1000
- Nombre d'employés dans l'entreprise : 97
- Le prix du carburant est indiqué par gallon
- Aucun relevé de plein manquant

## Conseils

- Utilise le [module `ballerina/io`](https://lib.ballerina.io/ballerina/io/latest) pour lire et écrire des fichiers JSON.
- Convertis les valeurs JSON vers des types propres à l'application afin de manipuler les données de manière sûre au niveau des types. Consulte l'[exemple de conversion d'un JSON vers un type défini par l'utilisateur](https://ballerina.io/learn/by-example/convert-from-json-to-user-defined-type) dans Ballerina By Examples (BBE) pour plus d'informations.

```ballerina
   json jsonPayload = {id: "2", title: "Jeru", artist: "Gerry Mulligan", price: 17.99};

   // Using cloneWithType  
   Album album1 = check jsonPayload.cloneWithType();
   io:println(album1);
 
   // Using fromJsonWithType
   Album album2 = check jsonPayload.fromJsonWithType();
   io:println(album2);
```

- La [déstructuration des enregistrements](https://ballerina.io/learn/by-example/destructure-records-using-query) peut t'aider à réduire la verbosité du code.

```ballerina
   Album {id, title, artist, price} = album1;
   io:println(id);
   io:println(title);
```

- Utilise des fonctions à corps d'expression pour les fonctions qui ne comportent qu'une seule expression. Par exemple, les fonctions qui ne contiennent qu'une instruction de retour.

```ballerina
   function cfr(int deaths, int cases) returns decimal => <decimal>deaths / <decimal>cases * 100;
```
