# Nombres à virgule flottante

En PHP, les nombres à virgule flottante servent à représenter un sous-ensemble des nombres réels.
Ils s'écrivent avec un ou plusieurs chiffres séparés par un séparateur décimal.

```php
<?php

$a = 1.234; 
$b = 1.2e3; 
$c = 7E-10;
$d = 1_234.567; // as of PHP 7.4.0
```

## Pièges courants

On ne peut pas représenter tous les nombres ni effectuer toutes les opérations arithmétiques avec des nombres à virgule flottante.
Utiliser des nombres à virgule flottante pour représenter des dollars et des cents peut entraîner des erreurs d'arrondi.

```php
<?php

$result = 0.1 + 0.2; // => 0.30000000000000004
```
