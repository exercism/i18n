# Tests

## Exécute les tests

Pour exécuter les tests, lance la commande suivante :

```bash
dotnet test
```

Pour exécuter les tests automatiquement à chaque fois qu'un fichier source est modifié, lance la commande suivante :

```bash
dotnet watch test
```

## Résous l'exercice

Résoudre un exercice, cela veut dire faire passer tous ses tests. Par défaut, un seul test (le premier) est exécuté lorsqu'on lance les tests. C'est intentionnel, car cela te permet de te concentrer sur la réussite de ce seul test. Une fois qu'il passe, tu peux activer le test suivant en supprimant `Skip = "Remove this Skip property to run this test"` de l'attribut `[Fact]` ou `[Theory]` du test. Quand tous les tests ont été activés et que ton implémentation les fait tous passer, tu as résolu l'exercice !

Pour t'aider à démarrer, chaque exercice est accompagné d'un fichier d'implémentation squelette. Tu peux t'en servir comme point de départ pour construire ta solution. N'hésite pas à supprimer ou à modifier ce fichier si tu penses que c'est la bonne chose à faire.

## Utilise des paquets

Tu devrais pouvoir résoudre la plupart des exercices sans utiliser de paquets externes. Toutefois, pour les exercices où tu veux vraiment utiliser un paquet externe, tu peux l'ajouter à ton projet en lançant la commande suivante :

```bash
dotnet add package [package-name]
```
