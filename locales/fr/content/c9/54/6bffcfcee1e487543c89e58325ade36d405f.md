# Installation

Suis les instructions pour ton système sur la page d'installation de [golang.org](http://golang.org/doc/install).

## Version de Go

Ce parcours utilise Go 1.26.

Il est possible d'utiliser une version antérieure de Go en modifiant le fichier `go.mod` de chaque exercice et en changeant la ligne `go 1.26`.
Cependant, les tests utilisent des fonctionnalités introduites dans Go 1.22 et ne fonctionneront pas sans modification avec une version antérieure.
