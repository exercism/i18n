# C'est parti !

Pour activer le parcours, il suffit de basculer l'option `active` dans `config.json` sur `true`.
Au bout de quelques instants, le parcours apparaîtra sur le [site web](https://exercism.org/tracks).

À partir de ce moment-là, les modifications apportées à ton parcours seront automatiquement synchronisées avec le [site web](https://exercism.org/tracks).
