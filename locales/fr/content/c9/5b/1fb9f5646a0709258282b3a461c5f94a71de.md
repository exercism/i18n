# Complément d'instructions

## Registres

| Registre | Usage      | Type       | Description                                      |
| -------- | ---------- | ---------- | ------------------------------------------------ |
| `$a0`    | entrée     | entier     | année à vérifier                                 |
| `$v0`    | sortie     | booléen    | l'entrée est une année bissextile (`0` = `false`, `1` = `true`) |
| `$t0-9`  | temporaire | quelconque | utilisé pour le stockage temporaire              |
