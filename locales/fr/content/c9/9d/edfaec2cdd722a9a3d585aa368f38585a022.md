# À propos

Common Lisp utilise les opérateurs arithmétiques habituels pour la plupart des opérations, mais se distingue quelque peu par l'usage d'une « notation préfixée » plutôt que de la « notation infixe » plus familière.

Plus visuellement :

```lisp
;; Infix-notation (non-lisp languages)
1 + 2 + 3 + 4 + 5 ; => 15
;; Prefix-notation (lisp languages)
(+ 1 2 3 4 5)     ; => 15
```

Si la notation préfixée transforme certaines opérations comme `2 + 2` en la forme un peu inhabituelle `(+ 2 2)`, elle facilite beaucoup plus le travail sur plusieurs nombres à la fois.

## Les opérateurs arithmétiques avec un seul argument

Petite curiosité, les opérateurs `-` et `/` ont une signification particulière quand on ne leur passe qu'un seul nombre :

```lisp
;; A single number passed to `-` is simply negated
(- 4)   ; => -4
(- -32) ; => 32
;; A single number passed to `/` returns the reciprocal
(/ 8)   ; => 1/8
(/ 0.1) ; => 10.0
```

## Comparer des nombres

Enfin, tu trouveras peut-être utile de comparer différents nombres à l'aide de fonctions comme `=` (égal), `/=` (différent de) et `>=` (supérieur ou égal).
Quand ces comparaisons sont vraies (comme `(= 1 1)`), elles renvoient `T`, et quand elles ne le sont pas (comme `(> 0 1)`), elles renvoient `NIL`.

## Prédicats numériques

Le langage inclut aussi quelques prédicats utiles comme `zerop`, `evenp` et `oddp`, qui vérifient les conditions qui vont de soi.

## Référence

```lisp
;; Addition
(+ 1 2 3 4 5) ; => 15

;; Subtraction
(- 15 3 2)    ; => 10
(- 42)        ; => -42

;; Multiplication
(* 4 3 2 1)   ; => 24

;; Division
(/ 64 16 2)   ; => 2
(/ 5)         ; => 1/5

;; Exponentiation
(expt 2 8)    ; => 256

;; Square Root
(sqrt 25)     ; => 25

;; Modulo (Similar to remainder)
(mod 10 3)    ; => 1

;; Equality
(= 2 2)       ; => T
(= 3 5)       ; => NIL
```
