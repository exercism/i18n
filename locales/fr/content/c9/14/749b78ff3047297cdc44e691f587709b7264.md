# Ressources d'apprentissage recommandées

Bienvenue dans l'apprentissage de ColdFusion (CFML) !  CFML est un langage de script pour la JVM, dynamique et faiblement typé.  Il comporte deux types de fichiers différents.  Les fichiers `.cfm` (balisage ColdFusion)_ sont purement procéduraux et utilisent la syntaxe à base de balises pour générer du HTML à partir de gabarits.  On les utilise pour les vues lorsqu'on construit un site web : 

**index.cfm**

```xml
<cfoutput>
	<html>
		<h1>Welcome to my site, #FirstName# #LastName#!
	</html>
</cfoutput>
```

L'autre type de fichier est le `.cfc` (composant ColdFusion), et c'est ainsi que l'on déclare une classe.  Les composants servent à la logique métier, aux modèles et aux contrôleurs.  Ils utilisent généralement la syntaxe de script, qui ressemble à celle de JavaScript.

**Car.cfc**

```js
component accessors=true {
	property name='make' type='string';
	property name='model' type='string';
	property name='year' type='number';

	function init() {
		return this;
	}
 
}
```
