# Introduction

Bien que Swift possède de nombreux types différents, chacun d'entre eux appartient à l'une de deux classifications : les types valeur et les types référence. En Swift, les structures sont des types valeur, tandis que les classes sont des types référence.

La principale différence entre les types valeur et les types référence tient au fait que, lorsqu'une valeur d'un type valeur est affectée à une variable ou à une constante, ou passée à une fonction, c'est en réalité une copie de la valeur qui est affectée ou transmise, et non cette valeur-là. Modifier une copie d'une structure n'a aucun effet sur les autres copies. Avec les types référence, c'est une référence vers cette valeur qui est affectée ou transmise, si bien que deux noms différents peuvent désigner la même instance d'une classe. Cela peut conduire à modifier l'instance d'origine lorsqu'on y accède sous un autre nom.
