# Indices

## Généralités

- Une routine qui répond avec du texte se déclare `: STR`. Celle qui répond avec un nombre entier se déclare `: INT`.
- Deux arguments de même type peuvent partager une déclaration : `full_title(piece, composer : STR) : STR`.

## 1. Nomme le morceau et son compositeur

- Trois bouts de texte assemblés avec `+` : le morceau, puis `" by "`, puis le compositeur.
- Les espaces sont à l'intérieur des guillemets. `+` n'ajoute rien de lui-même.

## 2. Mesure une ligne

- `.size`, sans parenthèses après.

## 3. Les premières lettres

- `.head` prend le nombre entre parenthèses : `title.head(count)`.

## 4. Les dernières lettres

- `.tail` est `.head`, mais en comptant depuis l'autre bout.

## 5. Raccourcis un titre trop long

- Six lettres depuis le début, puis `"..."` ajouté avec `+`.
- Le nombre de lettres est toujours six, donc il peut être écrit directement dans l'appel plutôt que passé en argument.
