# Exécute les tests

Une fois `sbt` installé, tu peux exécuter les tests depuis la ligne de commande avec :

```bash
$ sbt test
```

Attention : exécuter `sbt test` à chaque fois sera lent, car `sbt` se réinitialise à chaque appel.

`sbt` fonctionne comme un _shell_ : une fois lancé, tu peux y exécuter des commandes. 

Par exemple, tu peux utiliser `sbt` pour relancer tes tests à chaque fois que les fichiers source changent :
```bash
$ sbt
>~ test
```

Sache que tous les tests sont désactivés, sauf le premier, pour que tu puisses travailler dessus. 
Pour continuer, il te suffit de retirer le mot-clé `pending` au début de chaque cas de test.

Va [ici](https://www.scala-sbt.org/) pour en savoir plus sur `sbt`.


Tu peux aussi exécuter les tests dans les environnements de développement (IDE) suivants :

* [Metals](https://scalameta.org/metals/docs/#running-tests)
* [IntelliJ IDEA with Scala Plugin](https://www.jetbrains.com/idea/)
