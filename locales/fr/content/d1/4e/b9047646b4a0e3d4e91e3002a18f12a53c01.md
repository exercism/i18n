# Introduction

En Common Lisp, une fonction peut avoir des paramètres nommés (appelés « paramètres à mot-clé »).
Ceux-ci sont désignés dans la liste lambda par le mot-clé de liste lambda `&key`.
Les paramètres à mot-clé ne sont pas des paramètres obligatoires.
Comme les paramètres optionnels, on peut leur donner des valeurs par défaut et des symboles auxquels lier leur état « fourni ou non ».

Lors de l'appel d'une fonction avec des paramètres à mot-clé, le nom du paramètre sous forme de mot-clé est placé devant la valeur du paramètre.
L'appelant de la fonction peut spécifier les paramètres à mot-clé dans n'importe quel ordre.

```lisp
(defun keyword-parameters (&key x (y 'default) (z nil z-supplied-p))
  (list x y (if z-supplied-p (list :z-was-supplied z)
                             (list :z-was-not-supplied z))))

(keyword-parameters)            ; => (NIL DEFAULT (:Z-WAS-NOT-SUPPLIED NIL))
(keyword-parameters :y 5)       ; => (NIL 5 (:Z-WAS-NOT-SUPPLIED NIL))
(keyword-parameters :z 10 :x 5) ; => (5 DEFAULT (:Z-WAS-SUPPLIED 10))
```

Il faut faire attention lorsqu'on combine des paramètres optionnels et des paramètres à mot-clé, car le nom du mot-clé et son argument pourraient être consommés par les paramètres optionnels :

```lisp
(defun could-be-confusing (&optional x y &key z) (list x y z))
(could-be-confusing :z 'huh?) ; => (:Z HUH? NIL)
```
