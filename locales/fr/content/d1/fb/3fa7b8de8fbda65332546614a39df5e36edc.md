# Ajout aux instructions

## Indices

Tu dois implémenter la fonction `responseFor` qui renvoie la réponse de Bob pour une entrée donnée. Tu peux utiliser la signature fournie si tu n'es pas sûr des types, mais ne la laisse pas brider ta créativité :

```haskell
responseFor :: String -> String
```

Pour résoudre cet exercice, tu peux te renseigner sur :

- [Les gardes][guards]

[guards]: https://www.futurelearn.com/courses/functional-programming-haskell/0/steps/27226

Cet exercice travaille sur des données textuelles. Pour des raisons historiques, le type `String` de Haskell est synonyme de `[Char]`, une liste de caractères. Pour manipuler plus efficacement des données textuelles, on peut utiliser le type `Text`.

Comme prolongement facultatif à cet exercice, tu peux

- Te renseigner sur les [types de chaînes de caractères](https://haskell-lang.org/tutorial/string-types) en Haskell.
- Ajouter `- text` à ta liste de dépendances dans package.yaml.
- Importer `Data.Text` [de la façon suivante](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c) :

    ```haskell
    import qualified Data.Text as T
    import           Data.Text (Text)
    ```

- Tu peux maintenant écrire par exemple `responseFor :: Text -> Text` et faire appel aux combinateurs de `Data.Text`, par exemple `T.isSuffixOf`.
- Consulte la documentation de [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html),
- Tu peux ensuite remplacer toutes les occurrences de `String` par `Text` dans Bob.hs :

    ```haskell
    responseFor :: Text -> Text
    ```

Cette partie est entièrement facultative.
