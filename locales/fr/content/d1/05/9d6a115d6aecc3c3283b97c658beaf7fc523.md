# Introduction

## Files d'attente

La bibliothèque standard de Gleam implémente un type `Queue` dans le module `gleam/queue`. Il est similaire au type `List`, mais avec quelques différences essentielles :

- Le type `Queue` n'a pas de syntaxe littérale permettant de construire des files d'attente ou d'effectuer un filtrage par motif dessus.
- On peut ajouter et retirer efficacement des éléments à l'avant comme à l'arrière du type `Queue`, alors que le type `List` ne permet d'ajouter et de retirer efficacement des éléments qu'à l'avant.

La plupart du temps, tu voudras utiliser le type `List`, mais lorsque tu as besoin de pouvoir ajouter et retirer des éléments à la fin d'une collection, le type `Queue` est un bon choix.

On peut créer des files d'attente avec les fonctions `queue.new` et `queue.from_list` :

```gleam
let empty = queue.new()
let one_to_four = queue.from_list([1, 2, 3, 4])
```

On peut ajouter des éléments à la file d'attente avec les fonctions `queue.push_front` et `queue.push_back` :

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])
let one_to_five = queue.push_back(one_to_four, 5)
let zero_to_five = queue.push_front(one_to_five, 0)
```

On peut retirer des éléments de la file d'attente avec les fonctions `queue.pop_front` et `queue.pop_back` :

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])

queue.pop_back(one_to_four)
// -> Ok(#(4, queue.from_list([1, 2, 3])))

queue.pop_front(one_to_four)
// -> Ok(#(1, queue.from_list([2, 3, 4])))

queue.pop_front(queue.new())
// -> Error(Nil)
```

On peut convertir une file d'attente en liste avec la fonction `queue.to_list` :

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])
queue.to_list(one_to_four)
// -> [1, 2, 3, 4]
```

### L'égalité des files d'attente

En raison de la façon dont les files d'attente sont implémentées, deux files d'attente contenant les mêmes éléments dans le même ordre peuvent ne pas être égales selon l'opérateur `==`, qui compare les valeurs de manière structurelle. Par exemple :

```gleam
let empty = queue.new()
let a = queue.push_front(empty, 1)
let b = queue.push_back(empty, 1)
a == b
// -> False
```

Si tu as besoin de comparer deux files d'attente pour savoir si elles sont égales, tu peux utiliser la fonction `queue.is_logically_equal`.

```gleam
queue.is_logically_equal(a, b, fn(x, y) { x == y })))
// -> True
```
