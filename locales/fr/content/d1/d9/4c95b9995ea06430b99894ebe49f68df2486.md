# Installation

Le compilateur Free Pascal version 3.2.2 peut s'installer directement depuis le gestionnaire de paquets, sur un grand nombre de plateformes et de systèmes.
S'il n'est pas disponible pour ton système ou ta plateforme, ou si tu préfères installer Free Pascal dans ton répertoire personnel, tu peux récupérer les binaires sur [Free Pascal - Download][fpc-download], décompresser l'archive, exécuter ```install.sh``` puis ajouter ```$HOME/fpc-3.2.2/bin``` à la variable d'environnement ```PATH```.

Pour d'autres options d'installation ou une description plus détaillée, consulte [Installing the Free Pascal Compiler - Free Pascal wiki][fpc-install-wiki].

[fpc-download]: https://www.freepascal.org/download.html
[fpc-install-wiki]: https://wiki.freepascal.org/Installing_the_Free_Pascal_Compiler
