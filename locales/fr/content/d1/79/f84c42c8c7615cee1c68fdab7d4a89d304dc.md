# À propos

Le module `gleam/order` de la bibliothèque standard de Gleam contient le type `Order`, qui sert à comparer des valeurs.

La définition de `Order` ressemble à ceci :

```gleam
pub type Order {
  Gt
  Eq
  Lt
}
```

Le type prend trois variantes, chacune servant à représenter la relation entre une valeur et une autre valeur :

- `Gt` : la valeur est _plus grande_ que l'autre valeur.
- `Eq` : la valeur est _égale_ à l'autre valeur.
- `Lt` : la valeur est _plus petite_ que l'autre valeur.

Lorsqu'un type de données peut être comparé par taille, il est courant que le module définisse une fonction `compare` qui renvoie une valeur `Order`. Par exemple, `gleam/float` et `gleam/int` définissent des fonctions `compare` qui opèrent respectivement sur les nombres décimaux et les entiers.

```gleam
int.compare(1, 2)
// -> Lt

int.compare(2, 2)
// -> Eq

float.compare(1.0, 2.0)
// -> Lt
```

Les fonctions de tri comme `list.sort` prennent souvent en argument une fonction qui renvoie une valeur `Order`, ce qui permet à l'appelant de définir comment la liste doit être triée.

```gleam
list.sort([3, 7, 3, 1], by: int.compare)
// -> [1, 3, 3, 7]
```
