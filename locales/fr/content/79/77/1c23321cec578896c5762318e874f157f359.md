# Introduction

## Compare des nombres

En JavaScript, on peut comparer des nombres à l'aide des opérateurs relationnels et d'égalité suivants.

| Comparaison            | Opérateur |
| ---------------------- | --------- |
| Supérieur à            | `a > b`   |
| Supérieur ou égal à    | `a >= b`  |
| Inférieur à            | `a < b`   |
| Inférieur ou égal à    | `a <= b`  |
| Égalité (stricte)      | `a === b` |
| Non-égalité (stricte)  | `a !== b` |

Le résultat de la comparaison est toujours une valeur booléenne, donc soit `true`, soit `false`.

```javascript
1 < 3;
// => true

2 !== 2;
// => false

1 === 1.0;
// => true
// All numbers are floating-points, so this is different syntax for
// the exact same value.
```

## Compare des _strings_

En JavaScript, les opérateurs de comparaison ci-dessus peuvent aussi servir à comparer des _strings_.
Dans ce cas, c'est l'ordre lexicographique (celui d'un dictionnaire) qui s'applique.
Tu peux trouver la liste de l'ordre exact de tous les caractères [ici][utf-16-list].

```javascript
'Apple' > 'Pear';
// => false

'a' < 'above';
// => true

'a' === 'A';
// => false
```

## Égalité stricte

Tu te demandes peut-être pourquoi JavaScript utilise trois signes égaux pour tester l'égalité.
`===` correspond au test d'_égalité stricte_ : aucune conversion de type n'est effectuée et des valeurs de types différents sont toujours inégales.

```javascript
'3' === 3;
// => false
// The value on the left has type string, the value on the right has type number.

1 === 1n;
// => false
// The value on the left has type number, the value on the right has type bigint.
```

En JavaScript, le moyen recommandé de tester l'égalité est d'utiliser `===` et `!==`.

Il existe aussi `==` et `!=`, qui correspondent à un test d'_égalité faible_.
Mieux vaut les éviter, car ils appliquent une conversion de type implicite avant d'effectuer la comparaison.
Dans ces cas, le résultat est difficile à prévoir et parfois contraire à ce que l'on attend.

```javascript
0 == false;
// => true
```
