# À propos

En Common Lisp, les valeurs fausses sont représentées par la liste vide (`()`) ou par le symbole `nil`.
Ces valeurs peuvent être citées ou non.

```lisp
;; Equivalent False Values
()   ; => NIL
nil  ; => NIL
'()  ; => NIL
'nil ; => NIL
```

Toutes les autres valeurs de Lisp représentent la vérité.
Il existe aussi le symbole constant spécial `t`, qui est toujours égal à `t` (et donc toujours vrai).

```lisp
;; Some Different True Values
42                        ; => 42
"this statement is false" ; => "this statement is false"
t                         ; => T
't                        ; => T
```
