# Instructions

Dans cet exercice, tu vas organiser des courses entre différents types de voitures radiocommandées.
Chaque voiture a ses propres caractéristiques et participe à des courses sur de nombreuses pistes différentes tout au long de la saison du tournoi.

~~~~exercism/note
Les fonctions de cet exercice sont déclarées dans un fichier source C avec les signatures fournies.
Ton code en assembleur x86-64 doit respecter ces spécifications.
~~~~

## 1. Crée une voiture radiocommandée

Tu as défini une structure `car_t` pour représenter une voiture radiocommandée :

```c
struct car_t {
    char name[10];
    int16_t speed;
    float battery;
};
```

Définis une fonction `new_car` en assembleur x86-64 pour créer une voiture radiocommandée.
Le champ `battery` commence toujours avec la valeur `100.0`.

```c
struct car_t new_car(short speed, const char name[]);
```

## 2. Crée une nouvelle piste

Les pistes sont représentées par une structure `track_t` :

```c
struct track_t {
    enum surface_t surface;
    size_t distance;
};
```

L'`enum surface_t` permet de suivre les différentes surfaces d'une piste :

```c
enum surface_t {
    ASPHALT,
    SAND,
    ICE,
    CLAY
};
```

Définis une fonction `new_track` en assembleur x86-64 pour créer une nouvelle piste.

```c
struct track_t new_track(enum surface_t surface, size_t distance);
```

## 3. Crée une course

Jusqu'à 6 voitures participent à chaque course, en parcourant un nombre de tours donné sur une piste.
Les courses sont représentées par une structure `race_t` :

```c
struct race_t {
    struct track_t track;
    uint8_t num_of_laps;
    struct car_t cars[6];
    uint8_t num_of_running_cars;
};
```

Définis une fonction `new_race` en assembleur x86-64.
Au départ, aucune voiture participante n'est confirmée pour la course :

```c
struct race_t new_race(struct track_t track, uint8_t num_of_laps);
```

## 4. Confirme la participation d'une voiture à la course

Quand le propriétaire d'une voiture demande qu'elle participe à une course, sa participation n'est confirmée que si la liste n'est pas déjà pleine.

Définis une fonction `add_participant` en assembleur x86-64.
S'il reste de la place pour un participant de plus dans la course, la voiture est ajoutée à la liste, ce qui met à jour le compteur, et sa participation est confirmée.
Sinon, les organisateurs de la course doivent informer le propriétaire de la voiture qu'elle ne peut pas participer cette fois-ci.

```c
bool add_participant(struct race_t *race, struct car_t car);
```

## 5. Crée un tournoi

Tu gardes la trace des courses programmées pour la saison dans une structure `tournament_t` :

```c
struct tournament_t {
    struct race_t races[20];
    size_t num_of_races;
};
```

Définis une fonction `add_race` en assembleur x86 pour ajouter une course au tableau du tournoi et mettre à jour son compteur.
Tu peux considérer qu'il y aura toujours assez de place dans le tableau `races` pour la nouvelle course.

```c
void add_race(struct tournament_t *tournament, struct race_t race);
```
