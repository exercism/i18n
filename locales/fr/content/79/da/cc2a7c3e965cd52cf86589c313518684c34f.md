# Introduction

En C#, le littéral `null` sert à indiquer l'absence d'une valeur. Un type _nullable_ est un type qui autorise les valeurs `null`.

Avant C# 8.0, les types référence étaient toujours _nullables_ et les types valeur ne l'étaient pas. On peut toutefois rendre un type valeur _nullable_ en lui ajoutant un point d'interrogation (`?`).

```csharp
string nullableReferenceType = "hello";
nullableReferenceType = null; // Valid as type is nullable

int nonNullableValueType = 5;
nonNullableValueType = null; // Compile error as type is not nullable

int? nullableValueType = 5; // Define nullable value type
nullableValueType = null;   // Valid as type is nullable
```

Accéder à un membre d'une variable dont la valeur est `null` se compile sans problème, mais lève une `NullReferenceException` au moment de l'exécution :

```csharp
string sentence = null;

// Throws NullReferenceException at runtime
sentence.Length;
```

Pour contrer ce type d'erreur courant, C# 8 permet d'activer une fonctionnalité qui rend les types référence non _nullables_ par défaut :

```csharp
string nonNullableReferenceType = "book";
nonNullableReferenceType = null; // Compile warning (no error!)

string? nullableReferenceType = "movie";
nullableReferenceType = null; // Valid as type is nullable
```

Pour manipuler des valeurs _nullables_ en toute sécurité, il faut vérifier qu'elles ne valent pas `null` avant de les utiliser :

```csharp
string NormalizedName(string? name)
{
    if (name == null)
    {
        return "UNKNOWN";
    }
    else
    {
        // Value is not null at this point, so no compile warning
        // and no runtime NullReferenceException being thrown
        return name.ToUpper();
    }
}

NormalizedName(null); // => "UNKNOWN"
NormalizedName("Elisabeth"); // => "ELISABETH"
```

L'opérateur `??` permet de renvoyer une valeur par défaut quand la valeur vaut `null` :

```csharp
string? name1 = "John";
name1 ?? "Paul"; // => "John"

string? name2 = null;
name2 ?? "George"; // => "George"
```

L'opérateur `?.` permet d'appeler des membres en toute sécurité sur une valeur susceptible d'être `null` :

```csharp
string? fruit = "apple";
fruit?.Length; // => 5

string? vegetable = null;
vegetable?.Length; // => null
```
