# Indices

## Général

- Tu aimerais peut-être créer un DSL basé sur des listes de tags et d'enregistrements, comme ceci :

  ```roc
  my_graph =
      Graph.create([
          Title("My Graph"),
          Node("a", { color: Green }),
          Node("b", { color: Blue }),
          Edge("a", "b", { style: Dotted }),
      ])
  ```

- Ou peut-être préférerais-tu un DSL basé sur des chaînes d'appels de fonctions, comme ceci :

  ```roc
  my_graph =
      Graph.create()
          .with_title("My Graph")
          .add_node("a", Attr.create().with_color(Green))
          ...
  ```

  Ou alors, tu as peut-être un plan complètement différent ?
  Vas-y !

- Cela dit, un DSL est généralement meilleur s'il est clair, concis et pas trop surprenant (par exemple, la fonction `minus` sert à soustraire, pas à construire une arête entre deux nœuds, comme dans `node("a") - node("b")`).
