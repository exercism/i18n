# Instructions

Re-bonjour, Agent Double-Null0111.

Les forces d'UMBRA s'agitent à nouveau, et c'est à toi de déjouer leur dernier plan.
Notre service de renseignement nous informe que ces Minions prévoient de faire exploser une bombe puante au bal du Gouverneur.

Comme les Minions sont très maladroits, il leur arrive souvent d'armer accidentellement les bombes puantes dans leurs labos et leurs bureaux.
Et comme ils oublient sans cesse comment désamorcer leurs bombes puantes, ils ont mis en place un système qui génère les instructions de désamorçage indiquant l'ordre dans lequel les fils doivent être coupés, à partir du numéro d'identification de la bombe.

Ton travail consiste à écrire le code qui te permettra de désamorcer la bombe puante du bal avant qu'elle n'explose.

## 1. Écris une closure pour inverser deux fils

Chaque bombe puante possède trois fils de couleurs différentes.
Écris une closure qui prend un tuple `(String, String, String)` et renvoie le tuple avec l'ordre des deux premiers éléments inversé.
Affecte cette closure au nom `flip`.

Il est important de noter que le type doit être `ChangeClosure` (ou un type _sendable_) ; la définition du type est donnée dans le fichier _stub_.
Sinon, le code ne compilera pas.

```swift
flip(("red", "yellow", "blue"))
// Returns ("yellow", "red", "blue")
```

## 2. Écris une closure pour faire tourner les fils

Écris une closure qui prend un tuple `(String, String, String)` et renvoie le tuple avec les fils tournés vers la gauche.
Affecte cette closure au nom `rotate`.

Il est important de noter que le type doit être `ChangeClosure` (ou un type _sendable_) ; la définition du type est donnée dans le fichier _stub_.

```swift
rotate(("red", "yellow", "blue"))
// Returns ("yellow", "blue", "red")
```

## 3. Implémente un générateur de mélange des fils

Pour déterminer dans quel ordre couper les fils de la bombe puante, tu vas devoir implémenter une fonction qui génère la fonction de mélange adaptée au numéro d'identification de la bombe puante.

Implémente la fonction :

```swift
makeShuffle(
  flipper: @escaping ((String, String, String)) -> (String, String, String),
  rotator: @escaping ((String, String, String)) -> (String, String, String)
) -> ([UInt8], (String, String, String)) -> (String, String, String)
```

qui prend en entrée une closure qui inverse deux fils et une closure qui fait tourner les trois fils, et qui renvoie une closure.
Cette closure renvoyée prend le numéro d'identification de la bombe puante et l'ordre des trois fils, puis calcule l'ordre dans lequel les fils doivent être coupés.
Le numéro d'identification est composé de huit bits, et chaque bit détermine s'il faut inverser les fils ou les faire tourner.

Pour chaque bit du numéro d'identification, en commençant par le bit le plus à droite, tu appliques la closure `flipper` au tuple de fils si le bit vaut 0, et tu appliques la closure `rotator` s'il vaut 1, ce qui donne le nouvel état des fils.
Une fois les closures appropriées appliquées pour les huit bits du numéro d'identification, l'état final des fils correspond à l'ordre dans lequel ils doivent être coupés.

```swift
let shuffler = makeShuffle(flipper: flip, rotator: rotate)
// Returns ([UInt8], (String, String, String)) -> (String, String, String)
shuffler([1, 0, 0, 1, 1, 0, 1, 1], ("red", "yellow", "blue"))
// Returns ("red", "blue", "yellow")
```
