# Annexe aux instructions

## Formats de sortie

La fonction `treeFromTraversals` doit renvoyer un objet avec 3 propriétés :

- `value` : la valeur du nœud courant
- `left` : un objet contenant l'enfant gauche du nœud
- `right` : un objet contenant l'enfant droit du nœud

```javascript
{
    value: 'a',
    left: { value: 'i', left: {}, right: {} },
    right: { value: 'x', left: {}, right: {} },
}
```

Si l'arbre est vide, il faut renvoyer un objet vide.
