# Introduction

## Tableaux de bits

Travailler avec des données binaires peut être délicat, c'est pourquoi Gleam fournit un type `BitArray` et une syntaxe associée pour construire et filtrer par motif des données binaires.

Les littéraux de tableaux de bits sont définis avec la syntaxe `<<>>`. Lorsque l'on définit un littéral de tableau de bits, celui-ci est découpé en segments. Chaque segment comporte une valeur et une annotation, séparées par un `:`. L'annotation indique le nombre de bits utilisés pour encoder la valeur ; elle peut être omise complètement, auquel cas un entier de 8 bits est utilisé par défaut.

```gleam
// This defines a bit array with three segments of a single bit each
<<0:1, 1:1, 0:1>>

// This defines a bit array with three segments of 8 bits each
<<0, 1, 0>>
```

Indiquer le type sous la forme `:1` est un raccourci pour écrire `:size(1)`. Tu dois utiliser la syntaxe longue si la taille en bits provient d'une variable.

```gleam
let segment_size = 1
<<0:size(segment_size), 1:size(segment_size), 0:size(segment_size)>>
```

### Binaire

Lorsqu'on écrit des littéraux d'entiers binaires, on peut les écrire directement en base 2 en préfixant le littéral par `0b`. Note qu'ils seront affichés sous forme de nombres en base 10 lorsqu'ils sont imprimés dans les tests ou dans ton programme.

```gleam
<<0b1011:4>> == <<11:4>>
// -> True
```

### Troncature

Si la valeur du segment dépasse la capacité du type du segment, elle est tronquée à partir de la gauche.

```gleam
<<0b1011:3>> == <<0b0011:3>>
// -> True
```

### Ajout au début et à la fin

Tu peux à la fois ajouter au début et à la fin d'un tableau de bits existant à l'aide de la syntaxe des tableaux de bits. L'annotation `:bits` doit être utilisée pour le tableau de bits existant.

```gleam
let value = <<0b110:3, 0b001:3>>
let new_value = <<0b011:3, value:bits, 0b000:3>>
// -> <<120, 8:size(4)>>
```

### Concaténation

On peut concaténer des tableaux de bits stockés dans des variables grâce à la syntaxe des tableaux de bits. L'annotation `:bits` doit être utilisée lorsqu'on concatène deux tableaux de bits de tailles variables.

```gleam
let first = <<0b110:3>>
let second = <<0b001:3>>
let concatenated = <<first:bits, second:bits>>
// -> <<49:size(6)>>
```

### Filtrage par motif

On peut aussi effectuer un filtrage par motif pour obtenir des valeurs à partir du tableau de bits. Tu dois connaître le nombre de bits de chaque segment que tu veux capturer, à une exception près : l'annotation `:bits` permet de filtrer par motif un tableau de bits de taille inconnue, mais elle ne peut servir que pour le dernier segment.

```gleam
let assert <<value:4, rest:bits>> = <<0b01101001:8>>
value == 0b0110
// -> True
```

### Inspection des tableaux de bits

~~~~exercism/note
Les tableaux de bits peuvent être affichés dans un format différent de celui qui a servi
à les créer. Cela prête souvent à confusion lorsqu'on apprend les tableaux de bits.
~~~~

Par défaut, les tableaux de bits sont affichés en segments de 8 bits (un octet), même si tu les as créés avec des segments d'une taille différente.

```gleam
<<2011:11>>
// -> <<251, 3:size(3)>>
```

Si tu crées un tableau de bits qui représente une _string_ encodée en UTF-8 et affichable, il peut être affiché comme une _string_ par des fonctions telles que `io.debug`. Cela vient d'un détail d'implémentation de la façon dont Gleam représente les _strings_ en interne.

```gleam
<<>>
// -> ""

<<65, 66, 67>>
// -> "ABC"
```
