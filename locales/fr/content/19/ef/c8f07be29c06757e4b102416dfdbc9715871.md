# Instructions

Dans cet exercice, tu vas traiter des lignes de log.

Chaque ligne de log est une chaîne de caractères qui a le format suivant : `"[<LEVEL>]: <MESSAGE>"`.

Il existe trois niveaux de log différents :

- `INFO`
- `WARNING`
- `ERROR`

Tu as trois tâches, et chacune d'elles prend une ligne de log et te demande d'en faire quelque chose. Il y a de nombreuses façons de résoudre ces tâches : choisis les méthodes que tu préfères parmi les exemples ci-dessus et vois ce que tu peux trouver.

## 1. Récupère le message d'une ligne de log

Implémente la méthode `LogLineParser#message` pour renvoyer le message d'une ligne de log :

```ruby
LogLineParser.new('[ERROR]: Invalid operation').message
# => "Invalid operation"
```

Les espaces en début et en fin de ligne doivent être supprimés :

```ruby
LogLineParser.new("[WARNING]:  Disk almost full\r\n").message
# => "Disk almost full"
```

## 2. Récupère le niveau de log d'une ligne de log

Implémente la méthode `LogLineParser#log_level` pour renvoyer le niveau de log d'une ligne de log, en minuscules :

```ruby
LogLineParser.new('[ERROR]: Invalid operation').log_level
# => "error"
```

## 3. Reformate une ligne de log

Implémente la méthode `LogLineParser#reformat` qui reformate la ligne de log, en plaçant le message en premier et le niveau de log après, entre parenthèses :

```ruby
LogLineParser.new('[INFO]: Operation completed').reformat
# => "Operation completed (info)"
```
