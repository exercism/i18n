# Exécuteurs de tests

Un exécuteur de tests est un logiciel qui exécute les tests d'un exercice sur le code d'un apprenant.

Les exécuteurs de tests nous apportent deux avantages :

1. Ils permettent d'écrire du code directement dans le navigateur, ce qui permet à un apprenant d'itérer sur une solution en voyant si les tests réussissent ou échouent.
2. Ils nous permettent de fournir aux mentors des informations sur le fait que le code d'un apprenant « fonctionne » ou non.

## Construis un exécuteur de tests

Si tu souhaites construire un exécuteur de tests, consulte la [documentation sur les exécuteurs de tests](/docs/building/tooling/test-runners) pour plus d'informations.
