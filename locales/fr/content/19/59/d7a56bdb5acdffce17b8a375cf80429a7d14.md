# Introduction

Le modificateur `const` peut être appliqué (et devrait généralement l'être) à tout champ dont la valeur est connue à la compilation et ne changera pas pendant la durée de vie du programme.

```csharp
private const int num = 1729;
public const string title = "Grand" + " Master";
```

Le modificateur `readonly` peut être appliqué (et devrait généralement l'être) à tout champ qui ne peut pas être déclaré `const`, dont la valeur ne changera pas pendant la durée de vie du programme et qui est soit initialisé en ligne, soit au moment de l'instanciation (par le constructeur ou par une méthode appelée par le constructeur).

```csharp
private readonly int num;
private readonly System.Random rand = new System.Random();

public MyClass(int num)
{
    this.num = num;
}
```
