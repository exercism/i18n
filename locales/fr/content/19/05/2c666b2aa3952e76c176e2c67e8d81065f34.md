# Introduction

L'opérateur ternaire conditionnel permet d'écrire une expression condensée qui renvoie l'une des deux valeurs alternatives en fonction d'une condition.
On l'appelle souvent « opérateur ternaire ».
Ce nom vient du fait que l'opérateur prend trois opérandes : `predicate ? consequent-expression : alternative-expression`
Il peut remplacer de courtes instructions `if` et `else`.

Comme pour les instructions `if`, JavaScript effectue une conversion de type implicite pour évaluer la condition.
Si la condition est évaluée comme vraie, l'opérande situé à gauche des deux-points est renvoyé.
Sinon, le résultat de l'expression ternaire est l'opérande situé à droite des deux-points.

```javascript
const year = 2020;

year > 2000 ? 'in the past years' : 'a long time ago';
// => 'in the past years'
```
