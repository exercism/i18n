## Registres

| Registre | Utilisation | Type    | Description                                  |
| -------- | ----------- | ------- | -------------------------------------------- |
| `$a0`    | entrée      | adresse | première _string_, terminée par un caractère nul  |
| `$a1`    | entrée      | adresse | seconde _string_, terminée par un caractère nul |
| `$v0`    | sortie      | entier  | distance de Hamming                          |
| `$t0-9`  | temporaire  | quelconque | pour le stockage temporaire               |
