# Introduction

Le [Zen de Python][zen-of-python] affirme qu'il devrait y avoir « une manière _évidente_ de faire quelque chose en Python ».

À partir de Python 3.6, l'[**interpolation littérale de _strings_**][string-interpolation] (les [**`f-string`s**][f-string]) est souvent la façon évidente et privilégiée de formater des _strings_ :

```python
>>> adjective = "easy"
>>> f"This is an {adjective} way to format strings!"
'This is an easy way to format strings!'
```

Cependant, vu la longue histoire de Python et la diversité de ses cas d'usage, il n'est peut-être pas surprenant qu'il existe **trois** autres façons courantes de formater des _strings_ en Python :

1. [`str.format()`][str-format] est polyvalent, très puissant et compatible à la fois avec [`gnu gettext`][gettext] et avec la plupart des versions de Python.
2. Si tu as besoin de simplicité, de sécurité et/ou d'une internationalisation poussée, [`string.Template()`][string-template] permet d'atténuer les risques quand il faut traiter des entrées, et d'encapsuler les _strings_ de traduction.
3. L'opérateur `%` est généralement considéré comme obsolète pour du nouveau code, même s'il fonctionne toujours dans le Python moderne.
  Il devrait surtout servir à assurer la compatibilité avec du code plus ancien.
  Le formatage avec `%` peut poser des problèmes d'affichage des caractères non ASCII et Unicode, et comporte plus d'erreurs et moins de fonctionnalités que les autres méthodes.
  Vérifie les détails de prise en charge propres à ta distribution Python si tu comptes l'utiliser.

Si tu veux aller plus loin, [tout sur le formatage][all-about-formatting] et [Python String Formatting Best Practices][formatting-best-practices] sont de bons points de départ.
