# Introduction

Outre l'instruction `if`, JavaScript dispose aussi d'une instruction `switch` pour exécuter du code de façon conditionnelle.
On l'utilise lorsqu'une même variable doit être comparée à plusieurs valeurs possibles.
La comparaison se fait par un test d'égalité stricte (`===`), voir [le concept de comparaison][concept-comparison].
Pour une variable `x` quelconque, l'instruction `switch` en JavaScript a la syntaxe suivante :

<!-- prettier-ignore-start -->
```javascript
switch (x) {
  case option1:
    // code that is executed when "x === option1" is true
    break;
  case option2:
    // code that is executed when "x === option2" is true
    break;
  default:
    // code that is executed when x does not equal any of the options
}
```
<!-- prettier-ignore-end -->

Le cas `default` est facultatif : il sert à exécuter du code si aucune des autres options ne correspond à la variable.

Les instructions `break` ci-dessus sont nécessaires car, par défaut, tous les cas s'enchaînent en JavaScript.
Cela signifie que sans aucune instruction `break`, tout le code des cas situés après la première option correspondante serait exécuté, même si `x` ne correspondait pas à ces options.
Ce comportement d'enchaînement par défaut est un piège courant lorsqu'on utilise `switch` en JavaScript.
À l'intérieur d'une fonction, on peut aussi utiliser `return` à la place de `break` pour éviter ce problème.
