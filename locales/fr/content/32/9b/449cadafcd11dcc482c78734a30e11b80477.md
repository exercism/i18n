## Général

- Pour en savoir plus sur les [compréhensions][elixir-comprehensions], consulte le guide de démarrage.
- Pour en savoir plus sur les [listes][elixir-lists], consulte le guide de démarrage.
- Pour en savoir plus sur les [_maps_][elixir-maps], consulte le guide de démarrage.
- Pour en savoir plus sur les [listes de mots-clés][elixir-kwlists], consulte le guide de démarrage.

## 1. Propose une combinaison

- Dans la compréhension de liste, utilise deux _générateurs_ pour créer le produit cartésien.

## 2. Écarte les tenues qui détonnent

- Tu peux utiliser le _filtrage par motif_ dans le _générateur_ pour déstructurer les champs et les lier à une variable.
- Utilise une expression de _filtre_ pour renvoyer `false` quand les couleurs de base sont identiques.

## 3. Filtre selon le prix de la combinaison

- Il existe plusieurs [fonctions de listes de mots-clés][kw-module] pour récupérer des options depuis une liste de mots-clés.
- Utilise une expression de _filtre_ pour renvoyer `false` quand le prix combiné est supérieur au prix maximum.
