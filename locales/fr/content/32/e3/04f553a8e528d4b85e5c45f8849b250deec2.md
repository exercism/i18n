# Ajout aux instructions

## Messages d'exception

Il est parfois nécessaire de [lever une exception](https://docs.python.org/3/tutorial/errors.html#raising-exceptions). Quand tu le fais, tu dois toujours inclure un **message d'erreur explicite** pour indiquer l'origine de l'erreur. Cela rend le code plus lisible et facilite grandement le débogage. Dans les cas où tu sais que l'erreur sera d'un certain type, tu peux choisir de lever l'un des [types d'erreur prédéfinis](https://docs.python.org/3/library/exceptions.html#base-classes), mais tu dois tout de même inclure un message explicite.

Cet exercice en particulier demande d'utiliser [l'instruction `raise`](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement) pour « lancer » un `ValueError` quand l'argument passé n'est pas un littéral binaire valide. Les tests ne seront réussis que si tu lèves l'`exception` avec `raise` et que tu y ajoutes un message.

Pour lever un `ValueError` avec un message, écris ce message comme argument du type `exception` :

```python
# example when the argument passed is not a valid binary literal
raise ValueError("Invalid binary literal: " + digits)
```
