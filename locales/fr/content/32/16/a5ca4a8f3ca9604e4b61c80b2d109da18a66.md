# Indices

## Général

- Un contrat se place après le type de retour et avant le `is` :

  ```sather
     spare_capacity(load : INT) : INT
        pre load >= 0
     is
        ...
     end;
  ```

- Dans un contrat, on peut utiliser les arguments et les attributs de l'objet, donc `limit` est disponible.
- Les tests sont compilés sans `-chk`, donc un contrat erroné ne les fera pas échouer. Écris-les pour le lecteur.

## 1. Monte un harnais

- `pre kg > 0`, sur `create`.
- Le corps est le `new` habituel : affecte l'attribut, puis renvoie-le.

## 2. Combien de marge reste-t-il ?

- Deux conditions reliées par `and` : `pre load >= 0 and load <= limit`.
- `post result >= 0`. Cela découle du `pre`, et c'est justement ce qui rend cette précision utile : cela garde la trace de la raison pour laquelle on peut faire confiance à la réponse.

## 3. Quel est le taux de remplissage ?

- `pre load >= 0` et `post result >= 0`.
- `load * 100 / limit`, dans cet ordre. Diviser d'abord ferait tout perdre, comme ce serait le cas dans `tuning-the-strings`.

## 4. Est-ce sûr ?

- Aucun `pre` du tout : tout l'intérêt est que l'on peut poser la question pour n'importe quelle charge.
- Le `post` reformule la question : `post result = (load <= limit)`. Des parenthèses, parce que `=` sert deux fois à des choses différentes.
