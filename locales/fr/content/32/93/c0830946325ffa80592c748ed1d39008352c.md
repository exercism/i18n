# Utilise le bon nom de méthode

Le nom de la méthode doit correspondre exactement à celui utilisé dans les tests.

Renomme la méthode en `%{methodName}`.

**REMARQUE** : Ne modifie pas les tests pour qu'ils correspondent à un autre nom de méthode.
En général, essaie seulement d'ajouter des tests supplémentaires (si tu le souhaites).
