# À propos

Lorsque l'on écrit des fonctions en Haskell, on peut utiliser le [filtrage par motif][pattern-matching]. Le filtrage par motif est une fonctionnalité très puissante de Haskell, qui permet de reconnaître des constructeurs de données et de lier des variables aux valeurs qu'ils contiennent. Comme son nom l'indique, il s'agit de confronter des valeurs à des motifs, et si une valeur correspond au motif, on peut lier des variables aux valeurs présentes dans ce motif. Le filtrage par motif repose principalement sur trois idées : reconnaître des valeurs, lier des variables et décomposer des valeurs.

~~~~exercism/note
Le filtrage par motif dans des langages comme Elixir est un peu différent de celui de Haskell. Elixir, par exemple, autorise plusieurs fois le même nom de liaison dans un motif, ce que Haskell ne permet pas.
~~~~


Prenons cette fonction par exemple :

```haskell
lucky :: Int -> String
lucky 7 = "Lucky number seven!"
lucky x = "Sorry, you're out of luck, pal!"
```

Ici, on a une fonction `lucky` qui prend un `Int` et renvoie un `String`. Nous avons défini deux motifs pour cette fonction : l'un qui correspond au nombre `7`, l'autre qui correspond à n'importe quel autre nombre. Le nom peut être ce que l'on veut (tant qu'il respecte les conventions de nommage de Haskell), mais on utilise `x` ici. Si le nombre vaut `7`, la fonction renvoie `"Lucky number seven!"`, sinon elle renvoie `"Sorry, you're out of luck, pal!"`. Il est important de noter ici que les motifs sont examinés de haut en bas ; si l'on avait inversé leur ordre, la fonction renverrait toujours `"Lucky number seven!"`.

## Motifs sur les listes

Un motif très courant consiste à reconnaître une liste pour en prendre la tête et la queue. Cela tient à la nature des listes, qui sont des listes chaînées. Voici un exemple de fonction qui renvoie la tête et la queue d'une liste :

```haskell
headAndTail :: [Int] -> (Int, [Int])
headAndTail [] = error "Can't call head on an empty list"
headAndTail (x:xs) = (x, xs)
```

On a ici deux motifs : l'un qui correspond à une liste vide, l'autre qui correspond à une liste comportant au moins un élément. En effet, si la liste est vide, il faut prévoir un cas pour cette situation, sinon on obtient une erreur à l'exécution. Si la liste n'est pas vide, on peut lier la tête de la liste à `x` et la queue à `xs`. Cela se fait à l'aide de l'opérateur `:` (cons), qui sert à ajouter un élément en tête d'une liste. Mais dans un filtrage par motif, il permet de décomposer une liste en sa tête et sa queue, soit en quelque sorte l'opération inverse.

`xs` est un nom courant pour la queue d'une liste : il rappelle qu'il s'agit d'une liste. Mais si l'on travaille avec une liste imbriquée, on peut utiliser `xss` pour montrer qu'il s'agit d'une liste de listes.

## Motifs sur les tuples

Comme pour les listes, on peut aussi filtrer sur des tuples. Voici un exemple de fonction qui prend un tuple et renvoie son premier et son deuxième élément :

```haskell
sumTuple :: (Int, Int) -> Int
sumTuple (x, y) = x + y
```

Ici, on a un motif qui correspond à un tuple de deux éléments : le premier élément est lié à `x` et le second à `y`.

## Le motif joker

Parfois, la valeur d'une variable ne nous intéresse pas : on veut simplement que le motif corresponde. C'est là qu'intervient le motif joker, noté par un tiret bas `_`.

Voici un exemple de fonction qui renvoie le premier élément d'une liste :

```haskell
head' :: [Int] -> Int
head' [] = error "Can't call head on an empty list"
head' (x:_) = x
```

Ici, on indique que la queue de la liste ne nous intéresse pas et on utilise donc le motif joker pour l'ignorer.

## Motifs sur les types

On peut aussi filtrer sur des types, en utilisant le constructeur de ce type. On peut également en extraire des valeurs, comme on l'a fait pour les tuples.

```haskell
data AccountType = Guest | User String 

greet :: AccountType -> String
greet Guest = "Welcome, guest!"
greet (User name) = "Welcome, " ++ name ++ "!"
```

Dans le premier motif, on filtre sur le constructeur `Guest` ; dans le second, on filtre sur le constructeur `User` et on lie la valeur qu'il contient à `name`.
