# Introduction

Il arrive qu'on n'ait pas besoin du surcoût qu'entraîne la création d'un objet avec un état.
Dans ce cas, on peut utiliser un `module`.

Un module est très proche d'une classe (en fait, `Module` est un ancêtre de `Class` dans la hiérarchie des objets). La principale différence est qu'au lieu d'utiliser des méthodes d'instance, on utilise des méthodes de classe.
Les méthodes de classe commencent par `self.` et sont appelées directement sur un module.

Par exemple :

```ruby
module Speaker
  def self.echo(something)
    "#{something} ... #{something}"
  end
end

Speaker.echo("Hello")   #=> "Hello ... Hello"
```
