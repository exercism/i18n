# Astuces

## Général

- Chaque routine se place à l'intérieur de `class STAGE_DIRECTIONS is` et de son `end;` correspondant. Le squelette contient déjà les deux : écris entre eux.
- Chaque routine se termine par son propre `end;`.

## 1. Annonce le début

- La réponse est un texte, donc la routine est déclarée `: STR`.
- Le texte se place entre guillemets doubles : `"like this"`.
- Rends la réponse avec `return`.

## 2. Annonce l'intervalle

- La même forme que la première tâche, avec un texte différent.
- Copie la ligne attendue exactement, y compris les points.

## 3. Annonce la fin

- À nouveau la même forme.

## 4. Appelle le signal final

- N'écris pas le texte une troisième fois.
- Dans la même classe, tu peux utiliser une routine par son nom, sans nom de classe devant et sans parenthèses : `closing_line`.
- Rends le résultat de cet appel avec `return`.
