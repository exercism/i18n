# Indices

## 1. Définis le score d'un joueur dans le _hash_ %Scores

- Tu veux modifier le _hash_ `%Scores` pour ajouter les scores de nouveaux joueurs et remplacer ceux des joueurs existants.
- Les _hash_ ne peuvent pas contenir de clés en double ; une valeur plus récente dans une liste remplacera une valeur plus ancienne.

## 2. Récupère le score d'un joueur depuis le _hash_ %Scores

- Tu veux utiliser le nom du joueur donné pour `return` le score de ce joueur depuis le _hash_ `%Scores`.

## 3. Augmente le score d'un joueur dans le _hash_ %Scores

- Tu veux modifier le _hash_ `%Scores` pour ajouter les scores des joueurs déjà existants aux nouveaux scores fournis.

## 4. Trie les joueurs du _hash_ %Scores par leur nom

- Tu veux `return` les noms des joueurs du _hash_ `%Scores` sous forme d'une liste triée par ordre alphabétique.


## 5. Trie les joueurs du _hash_ %Scores par leur score

- Tu veux `return` les noms des joueurs du _hash_ `%Scores` sous forme d'une liste triée par score, du plus élevé au plus faible.

## 6. Supprime un joueur du _hash_ %Scores

- Tu veux modifier le _hash_ `%Scores` pour supprimer le nom et le score du joueur donné.
