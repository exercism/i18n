# Les bases

Pour plus d'informations détaillées sur ces sujets, consulte la [page du concept][exercism-concept].

## Syntaxe générale

La balise d'ouverture PHP `<?php` marque le début du code PHP.
Toutes les instructions doivent se terminer par un `;` pour séparer les instructions.

```php
<?php

$message = "Success!"; // Statement correctly ends with `;`
$message = "I fail." // PHP Parse error: syntax error, [...]
```

Pour faciliter la lecture, tous les exemples de code omettent la balise d'ouverture PHP `<?php`.

## Commentaires

Les commentaires sur une seule ligne commencent par `//`.

```php
// Single line comment
```

## Valeurs et variables

À l'aide de l'opérateur d'affectation `=`, on peut affecter une valeur à une variable.
Les noms de variables doivent commencer par un signe dollar `$` et suivre les [conventions de nommage][exercism-concept-naming-conventions].

```php
$count = 1; // Assign value of 1

// Strings can be created by enclosing the characters
// within single `'` quotes or double `"` quotes.
$message = "Success!";
```

## Fonctions et méthodes

On peut passer des valeurs et des variables à des fonctions.
Les arguments d'une fonction deviennent de nouvelles variables qui contiennent les valeurs passées.
Une fonction peut renvoyer n'importe quelle valeur à l'aide du mot-clé `return`.

```php
function window_height($height)
{
    return $height + 10;
}

window_height(100);
// => 110
```

Les fonctions définies dans des classes et dans leurs instances sont appelées méthodes.
Pour appeler une méthode, on fait précéder son nom de l'instance et de `->`.
Les méthodes ont accès à la variable spéciale `$this`, qui fait référence à l'instance courante.

```php
<?php

class Calculator {
    public function sub($x, $y)
    {
        return $this->add($x, -$y); // Calls the method add() of the current instance
    }

    public function add($x, $y)
    {
        return $x + $y;
    }
}

$calculator = new Calculator(); // Creates a new instance of Calculator class
$calculator->sub(3, 1); // Calls the method sub() of the instance stored in $calculator
// => 2
```
