# Instructions

Dans cet exercice, tu vas aider des amoureux de lycée à déclarer leur flamme sur les réseaux sociaux en générant une boîte ASCII avec leurs initiales :

```
❤-------------------❤
|  J. K.  +  M. B.  |
❤-------------------❤
```

## 1. Récupère la première lettre du nom

Implémente la fonction `HighSchoolSweetheart.first_letter/1`. Elle doit prendre un nom et renvoyer sa première lettre. Elle doit aussi supprimer les espaces inutiles du nom.

```elixir
HighSchoolSweetheart.first_letter("Jane")
# => "J"
```

## 2. Mets en forme la première lettre en initiale

Implémente la fonction `HighSchoolSweetheart.initial/1`. Elle doit prendre un nom et renvoyer sa première lettre, en majuscule, suivie d'un point. Pense à réutiliser `HighSchoolSweetheart.first_letter/1` que tu as définie à l'étape précédente.

```elixir
HighSchoolSweetheart.initial("Robert")
# => "R."
```

## 3. Sépare le nom complet en prénom et nom de famille

Implémente la fonction `HighSchoolSweetheart.initials/1`. Elle doit prendre un nom complet, composé d'un prénom et d'un nom de famille séparés par un espace, et renvoyer les initiales. Pense à réutiliser `HighSchoolSweetheart.initial/1` que tu as définie à l'étape précédente.

```elixir
HighSchoolSweetheart.initials("Lance Green")
# => "L. G."
```

## 4. Place les initiales à l'intérieur de la boîte ASCII

Implémente la fonction `HighSchoolSweetheart.pair/2`. Elle doit prendre deux noms complets et renvoyer les initiales à l'intérieur d'une boîte ASCII. Tu n'as pas besoin de dessiner la boîte toi-même : sers-toi de celle qui est incluse dans le commentaire du code. Pense à réutiliser `HighSchoolSweetheart.initials/1` que tu as définie à l'étape précédente.

```elixir
HighSchoolSweetheart.pair("Blake Miller", "Riley Lewis")
# => """
# ❤-------------------❤
# |  B. M.  +  R. L.  |
# ❤-------------------❤
# """
```
