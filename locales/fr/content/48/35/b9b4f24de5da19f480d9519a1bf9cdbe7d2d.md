# Analyseur de lignes de log

## Histoire

Dans cet exercice, tu vas traiter des lignes de log.

Chaque ligne de log est une _string_ au format suivant : `"[<LVL>]: <MESSAGE>"`.

Voici les différents niveaux de log :

- `TRC` (trace)
- `DBG` (débogage)
- `INF` (information)
- `WRN` (avertissement)
- `ERR` (erreur)
- `FTL` (fatal)

## Tâches

Voici des exemples de tâches qui correspondent à l'analyseur de lignes de log :

- Analyser le niveau de log en une énumération
- Prendre en charge les niveaux de log inconnus
- Convertir une ligne de log dans un autre format, avec le niveau de log converti en une valeur numérique
