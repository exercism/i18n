# Introduction

## Fonctions fléchées

Outre les déclarations de fonction et les expressions de fonction, JavaScript dispose aussi d'une syntaxe très concise pour définir une fonction.
Ces fonctions sont appelées _fonctions fléchées_.

Voici une comparaison entre une déclaration de fonction et une fonction fléchée.

```javascript
function addUpTwoNumbers(num1, num2) {
  return num1 + num2;
}
// function keyword removed and => added
const addUpTwoNumbers = (num1, num2) => {
  return num1 + num2;
};
```

Si le corps de la fonction ne contient qu'une instruction `return`, comme dans l'exemple ci-dessus, les `{}` et le mot-clé `return` peuvent être omis.
S'il n'y a qu'un seul paramètre, les parenthèses `()` peuvent aussi être omises.

<!-- prettier-ignore-start -->
```javascript
const addUpTwoNumbers = (num1, num2) => num1 + num2;
const square = num => num * num;
```
<!-- prettier-ignore-end -->

Les fonctions fléchées sont souvent utilisées pour définir de courtes fonctions de rappel directement dans l'appel de fonction.

<!-- prettier-ignore-start -->
```javascript
applyToSquare(number => number * number);
```
<!-- prettier-ignore-end -->

## Analyse des tableaux

Les [tableaux][arrays-concept] ont des méthodes intégrées pour analyser leur contenu.
La plupart de ces méthodes prennent en argument une fonction qui renvoie vrai ou faux.
Une telle fonction est appelée un [`predicate`][predicate_in_programming].

Ces méthodes intégrées sont destinées à être utilisées _à la place d'une boucle `for`_ ou de la méthode `forEach` intégrée :

Exemple d'analyse avec une boucle `for` :

```javascript
const numbers = [1, 'two', 3, 'four'];
for (var i = 0; i < numbers.length; i++) {
  if (numbers[i] === 'two') {
    return i;
  }
}
// => 1
```

Exemple d'analyse avec une méthode intégrée :

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.indexOf('two');
// => 1
```

D'autres méthodes intégrées utiles pour analyser un tableau sont présentées ci-dessous.
Consulte [MDN][mdn-array-methods] pour une liste complète des méthodes de tableau.

### `includes`

La méthode `includes(value)` détermine si un tableau contient une certaine valeur.
Elle renvoie `true` lorsque la valeur est incluse, `false` sinon.

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.includes(1);
// => true
numbers.includes('one');
// => false
```

### `every`

La méthode `every(predicate)` prend une fonction qui est _un prédicat_.
Elle teste si tous les éléments du tableau renvoient `true` lorsqu'ils sont passés au prédicat.
Autrement dit, la méthode vérifie que tous ses éléments réussissent le test qui lui est passé.
Elle renvoie `true` lorsque chaque élément réussit le test du prédicat, `false` sinon.

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.every((num) => num % 2 !== 0);
// => true
```

### `some`

La méthode `some(predicate)` est identique à la méthode `every`, mais renvoie `true` si au moins un élément du tableau réussit le test du _prédicat_.

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.some((num) => num % 2 !== 0);
// => true
```

### `find`

La méthode `find(predicate)` renvoie la valeur du premier élément du tableau qui réussit le test `predicate`.
Là où `some()` renvoie `true` en cas de réussite, `find()` renvoie la valeur réelle dans le tableau.
La méthode renvoie `undefined` lorsqu'aucun des éléments du tableau ne réussit le test du _prédicat_.

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.find((num) => num < 5);
// => 1
```

### `findIndex`

La méthode `findIndex(predicate)` est identique à la méthode `find()`, mais elle renvoie l'_indice_ (le premier) de l'élément qui réussit le test du _prédicat_ au lieu de la `value`.
La méthode renvoie `-1` lorsqu'aucun des éléments du tableau ne réussit le test du _prédicat_.

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.findIndex((num) => num > 7);
// => 4
numbers.findIndex((num) => num > 9);
// => -1
```
