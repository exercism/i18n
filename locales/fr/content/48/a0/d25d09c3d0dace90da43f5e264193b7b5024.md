# Instructions supplémentaires

## Instructions spécifiques au parcours

Ta tâche consiste à implémenter un objet `circularBuffer` qui possède les méthodes suivantes :

- `clear()` : vide le tampon.
- `write(item)` : ajoute l'élément donné au tampon. Si le tampon est plein, elle doit lever `Error("Cannot write to full buffer.")`.
- `read()` : retire du tampon le plus ancien élément et le renvoie. Si le tampon est vide, elle doit lever `Error("Cannot read from an empty buffer.")`.
- `overwrite(item)` : si le tampon est plein, elle écrase l'élément le plus ancien avec `item`. Si le tampon n'est pas plein, elle se comporte comme `write`.
