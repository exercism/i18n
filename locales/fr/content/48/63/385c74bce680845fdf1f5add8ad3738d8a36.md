# Parseur de lignes de log

## Histoire

Dans cet exercice, tu vas traiter des lignes de log.

Chaque ligne de log est une _string_ formatée comme ceci : `"[<LEVEL>]: <MESSAGE>"`.

Il y a trois niveaux de log différents :

- `INFO`
- `WARNING`
- `ERROR`

## Tâches

Voici des exemples de tâches qui correspondent au parseur de lignes de log :

- Récupère le message d'une ligne de log
- Récupère le niveau de log d'une ligne de log
- Convertis une ligne de log vers un autre format
