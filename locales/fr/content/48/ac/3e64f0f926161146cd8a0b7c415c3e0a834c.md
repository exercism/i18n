# Introduction

Les [`Rational numbers`][rational] sont des fractions dont le numérateur et le dénominateur sont des entiers.

Par exemple, on peut stocker `2//3` sous forme de fraction exacte plutôt que sous la forme de la valeur approchée `Float64` `0.6666...`

L'avantage, c'est que (sauf dans le cas extrême de [débordement d'entier][integer-overflow]) un nombre rationnel reste exact, ce qui évite les erreurs d'arrondi souvent inévitables avec les nombres à virgule flottante.

Tu trouveras quelques détails supplémentaires dans la [page du manuel][julia-rational] de Julia.

Les nombres rationnels sont un type numérique assez simple, conçu pour fonctionner à peu près comme on s'y attend.
Comme ils font partie des types standard de Julia depuis les premières versions, la plupart des fonctions les acceptent en entrée au même titre que les entiers et les nombres à virgule flottante.

## Crée des nombres rationnels

La création est aussi simple que d'utiliser `//` entre deux entiers.

```julia-repl
julia> 3//4
3//4

julia> a = 3; b = 4;

julia> a//b
3//4
```

Les facteurs communs sont automatiquement supprimés, ce qui réduit la fraction à sa [« forme irréductible »][lowest-terms] : les plus petits entiers qui représentent exactement la fraction, avec un dénominateur positif ou nul.

```julia-repl
julia> 5//15
1//3

julia> 5//-15
-1//3
```

Les résultats infinis sont acceptés, mais pas [`NaN`][NaN].

```julia-repl
julia> 1//0
1//0

julia> float(1//0)
Inf

julia> 0//0
ERROR: ArgumentError: invalid rational: zero(Int64)//zero(Int64)
```

## Arithmétique avec les nombres rationnels

Les [`arithmetic operators`][operators] usuels `+ - * / ^ %` fonctionnent avec les rationnels, essentiellement comme avec les autres types numériques.

On peut inclure des entiers et d'autres `Rational`, ce qui donne un résultat `Rational`.
Inclure un `float` dans l'expression donne un résultat `float`, avec une perte de précision (possible) en conséquence.

Si tu veux un `float`, utilise simplement la fonction `float()` pour convertir un rationnel.
Il est tout à fait normal d'utiliser des nombres rationnels pour préserver la précision tout au long d'un long calcul, puis de convertir en _float_ à la fin.

```julia-repl
julia> 3//4 + 1//3  # addition
13//12

julia> 3//4 * 1//3  # multiplication
1//4

julia> 3//4 / 1//3  # division
9//4

julia> 3//4 ^ 2  # exponentiation
3//16

julia> 3//4 + 5  # rational and int => rational
23//4

julia> 3//4 + 5.3  # rational and float => float
6.05

julia> float(3//4)  # casting
0.75
```

On peut aussi combiner les rationnels et les [nombres complexes][complex].
Les nombres complexes font l'objet d'un [concept distinct][complex-concept].

## Autres opérations

En Julia, les nombres rationnels sont des nombres comme les autres.
Le compilateur convertit en général les types quand c'est nécessaire.

Attention toutefois : les comparaisons ne fonctionnent que pour les fractions dont la représentation décimale est finie :

```julia-repl
julia> 3//4 == 0.75
true

julia> 3//4 < 0.74
false
```

Mais sinon, il faut convertir un `Rational` en `Float` pour pouvoir comparer :

```julia-repl
julia> 1//3 == 1/3
false

julia> float(1//3) == 1/3
true
```

Les fonctions mathématiques prennent des rationnels en entrée, mais peuvent renvoyer un résultat à virgule flottante :

```julia-repl
julia> sqrt(9//16)
0.75
```
