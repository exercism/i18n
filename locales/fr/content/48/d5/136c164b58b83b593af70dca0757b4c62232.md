# Tests

Installe les dépendances.

```sh
dart pub get
```

Lance les tests.

```sh
dart test
```

Pour une sortie plus détaillée par test, utilise le reporter expanded.

```sh
dart test -r expanded
```

La plupart des exercices ont plusieurs tests, et tous sauf le premier sont ignorés par défaut.
Pour faire les tests un par un, remplace `skip: true` par `skip: false` sur chaque test au fur et à mesure.

Sinon, lance tous les tests d'un coup sans modifier le fichier.

```sh
dart test --run-skipped
```

Tous les tests sont exécutés par l'exécuteur de tests en ligne lors de la soumission, y compris ceux qui sont ignorés.
