# Pas de rescue

N'utilise pas les exceptions pour contrôler le flux d'exécution.
Essaie de résoudre cet exercice sans utiliser `rescue`.

Si tu utilises une fonction de la bibliothèque standard dont le nom se termine par un `!` (qui lève des erreurs), cherche une fonction équivalente sans le `!` (qui renvoie souvent `{:ok, result}` ou `{:error, message}`).

Remarque : si tu vois ce commentaire automatisé sur ta solution, d'autres commentaires automatisés peuvent ne pas être exacts.
Corrige d'abord ce problème !

```elixir
# preferred: for example `case`

case Date.new(1999, 13, 1) do
  {:ok, date} -> date
  {:error, _} -> nil
end

# discouraged: rescuing exceptions

try do
  Date.new!(1999, 13, 1)
rescue
  ArgumentError ->
    nil
end
```
