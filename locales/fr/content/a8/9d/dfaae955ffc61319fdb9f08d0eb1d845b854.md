# Instructions

Tu es en train de développer le nouveau jeu très apprécié **Wings Quest**.
Dans ce jeu, tu incarnes un oiseau qui se déplace et ramasse des graines.
Le joueur gagne en ramassant toutes les graines.
Si le joueur entre en contact avec un aigle, il perd toutes ses graines et perd la partie.
Il existe une exception à cette règle : le joueur peut avoir un bonus actif qui lui permet de voler plus haut que les autres oiseaux.

Ton objectif est d'écrire quelques règles qui seront utilisées dans le jeu.

## 1. Détermine si l'oiseau obtient des points bonus

Dans le jeu, l'oiseau obtient des points bonus s'il touche un aigle alors qu'un bonus est actif.

Définis la fonction `bonusPoints(powerUpActive:touchingEagle:)` qui prend deux arguments : `powerUpActive`, qui indique si l'oiseau a un bonus actif, et `touchingEagle`, qui indique si l'oiseau touche un aigle.
La fonction doit renvoyer `true` uniquement si l'oiseau a un bonus actif et touche un aigle, et `false` sinon.

```Swift
bonusPoints(powerUpActive: false, touchingEagle: true)
// Returns false
```

## 2. Détermine si l'oiseau marque des points

Dans le jeu, le joueur marque des points lorsqu'il ramasse une graine ou un bonus.

Définis la fonction `score(touchingPowerUp:touchingSeed:)` qui prend deux arguments : `touchingPowerUp`, qui indique si l'oiseau touche un bonus, et `touchingSeed`, qui indique si l'oiseau touche une graine.
La fonction doit renvoyer `true` si l'oiseau touche un bonus ou une graine, et renvoyer `false` sinon.

```Swift
score(touchingPowerUp: true, touchingSeed: true)
// Returns true
```

## 3. Détermine si l'oiseau perd

Définis la fonction `lose(powerUpActive:touchingEagle:)` qui prend deux arguments : `powerUpActive`, qui indique si l'oiseau a un bonus actif, et `touchingEagle`, qui indique si l'oiseau touche un aigle.
La fonction doit renvoyer `true` si le personnage touche un aigle et n'a pas de bonus actif, et renvoyer `false` sinon.

```Swift
lose(powerUpActive: false, touchingEagle: true)
// Returns true
```

## 4. Détermine si l'oiseau gagne

Définis la fonction `win(hasPickedUpAllSeeds:powerUpActive:touchingEagle:)` qui prend les arguments suivants :

- `hasPickedUpAllSeeds` si l'oiseau a ramassé toutes les graines.
- `powerUpActive` si l'oiseau a un bonus actif.
- `touchingEagle` si l'oiseau touche un aigle.

La fonction doit renvoyer `true` si l'oiseau a ramassé toutes les graines et n'a pas perdu, d'après les arguments définis dans la partie 3, et renvoyer `false` sinon.

```Swift
win(hasPickedUpAllSeeds: false, powerUpActive: true, touchingEagle: false)
// Returns false
```
