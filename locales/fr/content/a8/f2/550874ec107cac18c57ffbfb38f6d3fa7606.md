# Ajout aux instructions

Bien qu'il existe les méthodes `#reversed` et `#reverseDo:` pour les _strings_, peux-tu trouver comment t'y prendre toi-même, en utilisant une itération sur les caractères de plus bas niveau et des _streams_ ?

Pour t'aider à parcourir le code, Pharo dispose d'un outil bien pratique pour trouver du code. Appuie sur Shift-Enter pour l'activer.

NOTE : on a suivi la convention d'Exercism qui consiste à appeler la solution ReverseString, mais un nom plus Smalltalk serait StringReverser.

## Smalltalk et les _strings_

En ce qui concerne les _strings_, il y a quelques petits détails évidents, comme les guillemets doubles pour les commentaires, les guillemets simples pour les _strings_ et une syntaxe particulière pour les caractères (par exemple, $x pour le caractère « x »), qui peuvent te dérouter à la première lecture, car ces conventions diffèrent de celles utilisées dans d'autres langages.

Il y a aussi la notion de symbole : un _string_ qui est unique dans toute la mémoire ; c'est-à-dire que lorsqu'il est construit (généralement à la compilation), une recherche est faite en mémoire pour déterminer s'il en existe déjà un identique, et seul l'original est utilisé. La raison n'est pas seulement d'économiser de la mémoire, mais aussi d'accélérer considérablement la comparaison des symboles.

```smalltalk
"this is a comment"
'this is a string'
#'this is a symbol'
#thisIsASymbolToo
```

Il y a également très peu de virgules dans les programmes Smalltalk, car elles n'y jouent aucun rôle syntaxique.
C'est pourquoi les littéraux de tableau, par exemple, s'écrivent sans virgule ; ainsi
`#(1 2 3 4 5)`
Cependant, la virgule est un opérateur à part entière, et tu la remarqueras quand tu concatènes deux _strings_ ; par exemple
`'string1', 'string2'`

Enfin, il est bon de savoir que les _strings_ et les _characters_ sont des classes distinctes. Un _string_ est une collection de _characters_. Cela peut te prendre au dépourvu quand tu itères sur des _strings_, car tu peux finir par passer des caractères à une méthode qui attend des _strings_. Prenons l'exemple suivant :
```smalltalk
(('hello' at: 2) = $e) inspect.
(('hello' at: 2) = 'e') inspect.
```

## Smalltalk et les _streams_
Les _streams_ sont utiles pour lire et écrire de manière séquentielle. Ils rendent le code plus propre en évitant d'avoir à incrémenter un indice.
Les _streams_ opèrent sur n'importe quelle collection.
```smalltalk
stream := WriteStream on: String new.
stream nextPut: $h ; nextPutAll: 'ell' ; nextPut: $o.
stream contents inspect
```
