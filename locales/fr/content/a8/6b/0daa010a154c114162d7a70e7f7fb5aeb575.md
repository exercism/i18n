# Indices

## Général

- Pour récupérer plusieurs arguments dans les paramètres d'une fonction, tu peux les regrouper avec l'opérateur `*arguments` pour un **tableau**, ou `**keyword_arguments` pour des arguments nommés.
- Pour regrouper ou décomposer des arguments, on utilise les opérateurs _splat_ (`*` ou `**`).

## 1. Crée une liste de tous les wagons

- Plusieurs arguments dans les paramètres d'une fonction peuvent être regroupés avec l'opérateur `*arguments`.

## 2. Corrige la liste des wagons

- Le déballage avec l'opérateur _splat_ (`*`) permet d'extraire les deux premiers éléments d'un **tableau** tout en gardant le reste intact.
- Pour ajouter un **tableau** dans un **tableau** existant, tu peux utiliser l'opérateur _splat_ (`*`) pour « étaler » le **tableau**.

## 3. Ajoute les arrêts manquants

- Utiliser `**keyword_arguments` comme argument d'une méthode permet de passer autant d'arguments nommés que l'on veut.
- Utiliser `**<hash>` comme argument décompose un `Hash` en arguments nommés.
- Tu peux placer des arguments nommés entre `{}`, ce qui est une autre façon de créer un `Hash`.
- Pour récupérer les valeurs d'un `Hash`, tu peux utiliser la méthode `Hash#values`.

## 4. Étends les informations d'itinéraire

- Utiliser `**{some_hash: value}` comme argument décompose le `Hash` en arguments nommés.
