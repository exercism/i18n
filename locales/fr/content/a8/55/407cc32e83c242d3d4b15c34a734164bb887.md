# À propos

Les constantes sont des valeurs définies au moment de la compilation et qui ne peuvent pas être réaffectées.
On utilise le mot-clé `const` pour déclarer une constante seule :

```go
const greeting = "hello"
```

On peut déclarer plusieurs constantes dans un bloc.
Au sein d'un bloc, une constante sans valeur explicite reprend l'expression précédente :

```go
const (
    greeting    = "hello"
    buffSize    = 4096
    chunkSize   // 4096
)
```

Les constantes sont généralement déclarées au niveau du paquet, même si on peut aussi les déclarer à l'intérieur d'une fonction.

## Constantes typées et non typées

Déclarer une constante sans en préciser le type la rend non typée.
Une constante non typée n'a pas de type défini ; c'est sa valeur qui détermine les types avec lesquels elle est compatible.
Tant que la valeur sous-jacente est compatible, le compilateur la convertit vers le type requis à chaque utilisation :

```go
const numA = 2

math.Sqrt(numA)  // numA is treated as float64 here
var numB int = numA  // numA is treated as int here
```

Une constante typée fixe le type au moment de la déclaration :

```go
const num int = 2

math.Sqrt(num)  // compile error because a float is expected
```

## Ce qui peut être une constante

Une constante ne peut contenir que des booléens, des nombres, des _strings_ et des runes.
Comme les valeurs sont définies au moment de la compilation, on ne peut pas utiliser le résultat d'un appel de fonction pour une constante.

```go
const s = math.Sqrt(4)  // compile error because the value isn't known at compile time
```

## Iota

Au sein d'un bloc de constantes, `iota` représente la position d'une constante dans le bloc :

```go
const (
    Sunday    = iota // 0
    Monday           // 1
    Tuesday          // 2
    Wednesday        // 3
)
```

Chaque constante après la première hérite de la même expression, `iota` s'incrémentant de un.

`iota` fonctionne aussi dans les expressions.

```go
const (
    _  = iota             // position 0: value discarded
    KB = 1 << (10 * iota) // position 1: 1 << 10 = 1024
    MB                    // position 2: 1 << 20 = 1048576
    GB                    // position 3: 1 << 30 = 1073741824
)
```
