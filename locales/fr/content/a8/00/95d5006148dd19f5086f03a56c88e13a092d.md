# return explicite

Supprime le return explicite pour simplifier la méthode.

En Ruby, une méthode renvoie le résultat de la dernière instruction évaluée. Utiliser explicitement le mot-clé `return` est donc inutile, sauf lorsqu'on veut sortir plus tôt d'une méthode.

Par exemple, ceci affiche `16`, car la méthode `multiply` renvoie le résultat de `a * b`, sa dernière expression.

```ruby
def multiple(a, b)
  a * b
end

print multiple(2, 8)
```
