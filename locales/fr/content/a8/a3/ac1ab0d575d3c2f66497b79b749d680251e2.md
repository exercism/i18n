# Introduction

La boucle `for` est l'une des instructions les plus couramment utilisées pour exécuter de façon répétée une même logique.
En JavaScript, elle se compose du mot-clé `for`, d'un _en-tête_ entre parenthèses et d'un bloc de code contenant le _corps_ de la boucle, entre accolades.

```javascript
for (initialization; condition; step) {
  // code that is executed repeatedly as long as the condition is true
}
```

L'initialisation prépare généralement une variable compteur, la condition vérifie si la boucle doit continuer ou s'arrêter, et l'étape incrémente le compteur à la fin de chaque répétition.
Les différentes parties de l'en-tête sont séparées par des points-virgules.

```javascript
const list = ['a', 'b', 'c'];
for (let i = 0; i < list.length; i++) {
  // code that should be executed for each item list[i]
}
```

L'étape est souvent définie à l'aide de l'opérateur d'incrémentation ou de décrémentation de JavaScript, comme le montre l'exemple ci-dessus.
Ces opérateurs modifient une variable sur place.
`++` ajoute 1 à un nombre, `--` soustrait 1 à un nombre.

```javascript
let i = 3;
i++;
// i is now 4

let j = 0;
j--;
// j is now -1
```
