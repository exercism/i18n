# Instructions

Dans cet exercice, tu vas écrire du code pour aider un freelance à communiquer avec un chef de projet.
Ton objectif est de fournir quelques outils pour calculer rapidement des tarifs journaliers et mensuels, avec éventuellement une remise donnée.

On commence par établir quelques règles entre le freelance et le chef de projet :

- Le tarif journalier correspond à 8 fois le tarif horaire.
- Un mois compte 22 jours facturables.

Il arrive que le freelance propose d'appliquer une remise sur son tarif journalier (par exemple pour ses clients les plus fidèles ou pour des clients à but non lucratif).

Les remises sont modélisées par des nombres décimaux représentant des pourcentages, par exemple `25.0` (25 %).

~~~~exercism/note
Voici les suffixes des instructions en virgule flottante :

| Suffixe | Taille de l'opérande |
|---------|----------------------|
| `ss`    | 32 bits              |
| `sd`    | 64 bits              |

Voici quelques-unes des instructions abordées dans ce concept :

| Instruction       | Description                                                             |
|-------------------------|-----------------------------------------------------------------|
| movss/movsd a, b        | copie b dans a                                                  |
| addss/addsd a, b        | a = a + b                                                       |
| subss/subsd a, b        | a = a - b                                                       |
| mulss/mulsd a, b        | a = a * b                                                       |
| divss/divsd a, b        | a = a / b                                                       |
| cvtsi2ss/cvtsi2sd a, b  | convertit l'entier b en un nombre à virgule flottante a          |
| roundss/roundsd a, b, c | arrondit le nombre à virgule flottante b selon c et stocke le résultat dans a |
| cvtss2si/cvtsd2si a, b  | convertit le nombre à virgule flottante b en l'entier a          |
| comiss/comisd a, b      | effectue une comparaison entre a et b, déclenche une exception si `NaN` |
| ucomiss/ucomisd a, b    | effectue une comparaison entre a et b, positionne `PF` si `NaN`  |

Voici les nombres de contrôle d'arrondi de `roundss` et `roundsd` :

| Nombre | Mode          |
|:-------|:--------------|
| 0      | Au plus proche |
| 1      | Vers le bas   |
| 2      | Vers le haut  |
| 3      | Troncature    |
~~~~

## 1. Calculer le tarif journalier à partir d'un tarif horaire

Implémente une fonction `daily_rate` qui calcule le tarif journalier à partir d'un tarif horaire passé en paramètre, sous forme de nombre à virgule flottante 64 bits.
Le contrat stipule qu'une journée compte 8 heures facturables.

```c
daily_rate(60)
// => 480.0
```

Le tarif journalier renvoyé doit être un nombre à virgule flottante 64 bits.

## 2. Calculer un prix après remise

Implémente une fonction `apply_discount` qui calcule le prix après remise.
Elle doit accepter deux paramètres : le prix d'origine et le taux de remise en pourcentage, tous deux sous forme de nombres à virgule flottante 64 bits.

```c
apply_discount(150.0, 10.0)
// => 135.0
```

La valeur renvoyée doit toujours être un nombre à virgule flottante 64 bits.

## 3. Calculer le tarif mensuel à partir d'un tarif horaire et d'une remise

Implémente une fonction `monthly_rate` qui calcule le tarif mensuel après remise.
Elle prend deux paramètres, un tarif horaire et la remise en pourcentage, tous deux sous forme de nombres à virgule flottante 64 bits.

```c
monthly_rate(77.0, 10.5)
// => 12130
```

Le tarif mensuel renvoyé doit être arrondi vers le haut (arrondi au plafond) en un entier 64 bits.

## 4. Calculer le nombre de jours travaillés complets à partir d'un budget, d'un tarif horaire et d'une remise

Implémente une fonction `days_in_budget` qui prend les paramètres suivants :

1. Un budget, sous forme d'entier non signé 64 bits.
2. Un tarif horaire, sous forme de nombre à virgule flottante 64 bits.
3. Une remise en pourcentage, sous forme de nombre à virgule flottante 64 bits.

Cette fonction doit renvoyer le nombre de jours de travail complets que le budget couvre.

```c
days_in_budget(20000, 80, 11.0)
// => 35
```

Le nombre de jours renvoyé doit être arrondi vers le bas (arrondi au plancher) en un entier 32 bits.
