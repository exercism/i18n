# Pointeurs intelligents

Les pointeurs intelligents en Cairo sont un outil puissant qui assure une gestion sûre et efficace de la mémoire.

Un pointeur intelligent est une structure de données qui se comporte comme un pointeur classique, mais avec des mécanismes de sûreté supplémentaires pour éviter les problèmes courants de gestion de la mémoire, comme le déréférencement de pointeurs nuls ou l'accès à de la mémoire non initialisée.

## Qu'est-ce qu'un pointeur intelligent ?

De façon générale, un pointeur est une variable qui stocke une adresse mémoire, et qui pointe généralement vers une valeur stockée à cet emplacement.

Cependant, les pointeurs bruts peuvent être dangereux : s'ils ne pointent pas vers une mémoire valide ou s'ils sont déréférencés de manière incorrecte, cela peut entraîner des plantages ou un comportement imprévisible.

Les pointeurs intelligents résolvent ce problème en imposant des règles strictes de gestion de la mémoire, ce qui garantit que la mémoire est accédée de manière sûre et contrôlée.

Cairo, comme de nombreux langages modernes tels que Rust, a recours aux pointeurs intelligents pour éviter les accès mémoire non sûrs.

Un pointeur intelligent en Cairo ne se contente pas de stocker une adresse mémoire : il suit également la propriété et garantit la sûreté mémoire.

## Les types de pointeurs intelligents en Cairo

Cairo fournit plusieurs types de pointeurs intelligents, notamment `Box<T>` et `Nullable<T>`, chacun répondant à un objectif différent.

Voyons de plus près comment ces types fonctionnent et quand tu pourrais les utiliser.

### `Box<T>`

Le type `Box<T>` est le principal pointeur intelligent en Cairo.

Il permet de stocker des données dans un segment de mémoire spécial appelé « boxed segment ». Un `Box<T>` est un pointeur qui pointe vers ce segment, et lorsque tu crées une _box_, tu alloues de l'espace pour les données dans ce segment.

Les _boxes_ sont idéales dans les situations suivantes :

- Tu dois stocker une valeur d'un type dont la taille ne peut pas être déterminée au moment de la compilation.
- Tu disposes d'une grande quantité de données et tu veux en transférer la propriété sans les copier.

En utilisant une _box_, tu peux stocker des structures de données volumineuses de manière plus efficace.

Lorsque tu passes un `Box<T>` à une fonction, seul le pointeur est transmis, ce qui évite de copier l'intégralité des données et améliore les performances, en particulier avec les grandes structures.

### `Nullable<T>`

Le type `Nullable<T>` est un autre pointeur intelligent important en Cairo.

Il peut soit pointer vers une valeur valide de type `T`, soit valoir `null` s'il n'y a pas de valeur.

Ce type est utile dans les cas où tu dois stocker des valeurs qui n'existent pas toujours, par exemple dans un dictionnaire pouvant contenir des éléments optionnels.

En Cairo, `Nullable<T>` est généralement utilisé dans les dictionnaires pour gérer les cas où aucune valeur par défaut ne peut être appliquée.

Il permet de stocker des valeurs de manière conditionnelle, ce qui facilite la gestion sûre de l'absence de données.

## La sûreté mémoire avec les pointeurs intelligents

L'un des principaux avantages des pointeurs intelligents est qu'ils contribuent à garantir la sûreté mémoire.

En gérant la propriété et les règles d'accès, Cairo évite les problèmes courants tels que le déréférencement de pointeurs nuls ou pendants.

Les pointeurs intelligents détectent le moment où les données ne sont plus nécessaires et peuvent libérer automatiquement la mémoire lorsqu'elles sortent de la portée, ce qui réduit le risque de fuites de mémoire.

### Exemple : utiliser un `Box<T>` pour les types récursifs

Un défi courant dans de nombreux langages de programmation est la gestion des types récursifs.

Les types récursifs sont des types qui contiennent des références à eux-mêmes.

Sans une gestion appropriée de la mémoire, définir un type récursif peut entraîner des problèmes tels qu'une récursion infinie.

En Cairo, `Box<T>` permet de définir des types récursifs en toute sécurité.

Par exemple, tu peux utiliser `Box<T>` pour implémenter un arbre binaire, où chaque nœud contient une référence vers un autre nœud.

En stockant les références dans des _boxes_, Cairo garantit que l'utilisation de la mémoire est finie, et le compilateur peut déterminer la taille de mémoire nécessaire pour la structure.

```rust
use core::box::{BoxTrait};

#[derive(Copy, Drop)]
enum BinaryTree {
    Leaf: u32,
    Node: (u32, Box<BinaryTree>, Box<BinaryTree>),
}

fn main() {
    let leaf1 = BinaryTree::Leaf(1);
    let leaf2 = BinaryTree::Leaf(2);
    let node = BinaryTree::Node((3, BoxTrait::new(leaf1), BoxTrait::new(leaf2)));
    println!("{:?}", node);
}
```

### Les avantages des pointeurs intelligents en matière de performances

Les pointeurs intelligents améliorent également les performances de tes programmes.

Lorsque tu utilises `Box<T>`, seul le pointeur vers les données est transmis, au lieu de copier toute la structure de données.

C'est particulièrement utile lorsque tu manipules de grands ensembles de données, car cela réduit considérablement le surcoût des opérations mémoire.

Dans l'exemple suivant, les données sont passées par référence à l'aide d'un `Box<T>` pour éviter le coût de la copie de toute la structure :

```rust
#[derive(Drop)]
struct Cart {
    paid: bool,
    items: u256,
    buyer: ByteArray,
}

fn pass_data(cart: Cart) {
    println!("{} is shopping today and bought {} items", cart.buyer, cart.items);
}

fn pass_pointer(cart: Box<Cart>) {
    let cart = cart.unbox();
    println!("{} is shopping today and bought {} items", cart.buyer, cart.items);
}

fn main() {
    let new_cart = Cart { paid: true, items: 1, buyer: "John" };
    pass_data(new_cart);

    let new_box = BoxTrait::new(Cart { paid: false, items: 3, buyer: "Jane" });
    pass_pointer(new_box);
}
```

Dans cet exemple, `pass_pointer` prend un `Box<Cart>` au lieu d'un `Cart`, ce qui réduit la quantité de mémoire copiée lors de l'appel de la fonction.
