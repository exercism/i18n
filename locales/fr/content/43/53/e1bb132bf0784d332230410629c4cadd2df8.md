# Instructions

Affiche les nombres de 1 à n en suivant les règles suivantes :

1. Si le nombre est un multiple de 3, affiche « Fizz »
2. Si le nombre est un multiple de 5, affiche « Buzz »
3. Si le nombre est à la fois un multiple de 3 et un multiple de 5, affiche « Fizz Buzz »
4. Si le nombre n'est ni un multiple de 3 ni un multiple de 5, affiche le nombre

La sortie doit être un vecteur de _strings_, par exemple « 1 » « 2 » « Fizz » « 4 » « Buzz » ...
