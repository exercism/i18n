### Invocation dynamique de fonction

Les fonctions awk ne sont pas des objets de première classe : elles ne peuvent pas être transmises d'un endroit à l'autre comme le permettent certains autres langages.
Cependant, une variable peut contenir le _nom_ d'une fonction (une _string_), et la fonction est invoquée à l'aide d'une notation spéciale `@varname(args)`.
Un exemple :

```awk
function greet(name) {
    print "Hello, " name
}
BEGIN {
    greet("John")       # => "Hello, John"

    f = "greet"
    f("Bill")           # => error
    @f("Bill")          # => "Hello, Bill"
}
```
Tout cela est décrit dans la section [Appels de fonctions indirects][indirect].
Il s'agit d'une extension de `gawk`.
