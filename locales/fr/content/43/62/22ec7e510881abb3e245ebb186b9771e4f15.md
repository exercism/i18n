# Strings

Crystal dispose d'un type appelé [`String`][strings], qui sert à représenter du texte.
Les _strings_ de Crystal sont des séquences de caractères Unicode.
Les _strings_ sont immuables, ce qui signifie qu'elles ne peuvent pas être modifiées après leur création.
Cela signifie qu'une nouvelle _string_ est créée chaque fois que l'on modifie une _string_ ; par conséquent, la _string_ d'origine n'est pas modifiée.

Pour définir une _string_, on utilise des guillemets doubles `"`.

```crystal
"Hello World"
```

## Concaténation

Pour concaténer deux _strings_, on utilise l'opérateur `+`.
L'opérateur `+` renvoie une nouvelle _string_ qui combine les deux _strings_.

```crystal
hello = "Hello"
hello + " World"
# => "Hello World"
```

## Conversation entre _strings_ et nombres

La méthode `to_i` convertit une _string_ en entier.
Sinon, on peut utiliser la méthode `to_f` pour obtenir un nombre à virgule flottante.
Si la conversion de la _string_ en nombre est impossible, une exception `ArgumentError` sera levée.

```crystal
"1".to_i
# => 1

"1.0".to_f
# => 1.0

"Hello".to_i
# => ArgumentError: Invalid integer: Hello
```

Un entier ou un nombre à virgule flottante peut être converti en _string_ à l'aide de la méthode `to_s`.

```crystal
1.to_s
# => "1"

1.0.to_s
# => "1.0"
```

## Interpolation

L'interpolation est un moyen pratique de combiner des _strings_ et d'intégrer des expressions dans des _strings_.
Pour interpoler une _string_, on utilise le caractère `#` suivi d'accolades `{}`, avec l'expression à l'intérieur des accolades.

```crystal
name = "World"
"Hello #{name}!"
# => "Hello World!"
```

Crystal convertit automatiquement le résultat de l'expression en _string_.

```crystal
"Hello #{1 + 1}!"
# => "Hello 2!"
```

## Taille

Lorsque tu as besoin de connaître le nombre de caractères d'une _string_, tu peux utiliser la méthode `size`, qui renvoie la longueur de la _string_ sous forme d'entier.
La taille d'une _string_ est une propriété stockée de la _string_, donc la taille n'a pas besoin d'être calculée chaque fois que tu appelles la méthode, ce qui la rend très rapide.

```crystal
"Hello World".size
# => 11
```

## Indexation

L'indexation consiste à récupérer un caractère précis dans une _string_.
Pour récupérer un caractère d'une `String`, tu peux utiliser la notation habituelle entre crochets.

~~~~exercism/note
`[]` est implémenté comme une méthode d'instance de String, où l'indice est l'argument de la méthode.
~~~~

Le premier caractère d'une _string_ se trouve à l'indice 0.

```crystal
"Hello World"[0]
# => 'H'

"Hello World"[6]
# => 'W'
```

Pour obtenir un caractère depuis la fin d'une _string_, tu peux prendre la longueur de la _string_ moins un pour obtenir l'indice du dernier caractère, et pour obtenir l'avant-dernier caractère, tu peux prendre la longueur de la _string_ moins deux, et ainsi de suite.
Il existe un raccourci pour cela : utiliser simplement un indice négatif, où le dernier caractère se trouve à l'indice -1, l'avant-dernier à l'indice -2, et ainsi de suite.

```crystal
name = "Hello World"
name[name.size - 1]
# => 'd'

name[-1]
# => 'd'
```

## Échappement

Certains caractères ne peuvent pas être écrits directement dans une _string_ ; à la place, il faut utiliser une séquence d'échappement.
Par exemple, si tu veux utiliser des guillemets doubles dans une _string_, tu dois échapper ces guillemets doubles.
Tu peux utiliser le caractère `\` pour écrire une séquence d'échappement suivie du caractère que tu veux échapper.

Voici les caractères spéciaux en Crystal :

| Value    | Description                   |
| -------- | ----------------------------- |
| `\a`     | Alerte                        |
| `\b`     | Retour arrière                |
| `\e`     | Échappement                   |
| `\f`     | Saut de page                  |
| `\n`     | Saut de ligne ou nouvelle ligne |
| `\r`     | Retour chariot                |
| `\t`     | Tabulation horizontale        |
| `\v`     | Tabulation verticale          |
| `\\`     | Barre oblique inversée        |
| `\'`     | Guillemet simple              |
| `\"`     | Guillemet double              |
| `\377`   | Caractère ASCII octal         |
| `\xFF`   | Caractère ASCII hexadécimal   |
| `\uFFFF` | Caractère Unicode hexadécimal |

```crystal
puts "Hello \"World\""
# => Hello "World"

puts "Hello \nWorld"
# => Hello
# => World
```

## _Strings_ multilignes

Pour écrire une _string_ sur plusieurs lignes, tu utilises la même syntaxe que pour une _string_ sur une seule ligne, mais tu passes à la ligne pour chaque ligne que tu veux dans la _string_.

```crystal
"Hello
World"
# => "Hello\nWorld"
```
