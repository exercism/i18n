# Instructions

Dans cet exercice, tu vas mettre en place un moyen de suivre les meilleurs scores du jeu le plus populaire de la salle d'arcade de ta ville.

Tu as 7 fonctions à implémenter, toutes liées au renvoi et à la manipulation d'un dictionnaire de données de meilleurs scores.

## 1. Définis un nouveau dictionnaire des meilleurs scores

Crée une fonction `newScoreBoard()` qui ne prend aucun paramètre et qui renvoie un nouveau dictionnaire des meilleurs scores, dont les clés sont de type `String` et les valeurs de type `Int`.

## 2. Ajoute des joueurs au dictionnaire des meilleurs scores

Pour ajouter un joueur au dictionnaire des meilleurs scores, définis `addPlayer(_:_:_:)`, une fonction qui prend 3 paramètres :

- Le premier paramètre est le dictionnaire des scores. 
    Il doit s'agir d'un paramètre in-out.
- Le deuxième paramètre est le nom d'un joueur, sous forme de _string_.
- Le troisième paramètre est le score, sous forme de nombre entier. 
    Ce paramètre est facultatif, implémente le troisième paramètre avec une valeur par défaut de 0.

```swift
var highScores = newScoreBoard()
addPlayer(&highScores, "Dave Thomas")
// Returns ["Dave Thomas": 0]
addPlayer(&highScores, "José Valim", 486_373)
// Returns ["Dave Thomas": 0, "José Valim": 486_373]
```

## 3. Supprime des joueurs du dictionnaire des scores

Pour supprimer un joueur du dictionnaire des meilleurs scores, définis `removePlayer(_:_:)`, qui prend 2 paramètres :

- Le premier paramètre est le dictionnaire des scores. 
    Il doit s'agir d'un paramètre in-out.
- Le deuxième paramètre est le nom du joueur, sous forme de _string_.

Cette fonction doit supprimer le joueur du dictionnaire s'il s'y trouve, et ne rien faire dans le cas contraire.

```swift
var highScores = ["Dave Thomas": 0, "José Valim": 486_373]
removePlayer(&highScores, "Dave Thomas")
// Returns ["José Valim": 486_373]
removePlayer(&highScores, "Rose Fanaras")
// Returns ["José Valim": 486_373]
```

## 4. Réinitialise le score d'un joueur

Pour réinitialiser le score d'un joueur, définis `resetPlayer(_:_:)`, qui prend 2 paramètres :

- Le premier paramètre est le dictionnaire des scores.
    Il doit s'agir d'un paramètre in-out.
- Le deuxième paramètre est le nom du joueur dont tu souhaites réinitialiser le score, sous forme de _string_.

La fonction met le score du joueur à 0. 
Si le joueur n'est pas dans le dictionnaire, il ne doit rien se passer.

```swift
var highScores = ["Dave Thomas": 486_373, "José Valim": 10]
resetScore(&highScores, "Dave Thomas")
// Returns ["Dave Thomas": 0, "José Valim": 10]
```

## 5. Mets à jour le score d'un joueur

Pour mettre à jour le score d'un joueur en l'ajoutant au score précédent, définis `updateScore`, qui prend 3 paramètres :

- Le premier paramètre est le dictionnaire des scores. Il doit s'agir d'un paramètre in-out.
- Le deuxième paramètre est le nom du joueur dont tu souhaites mettre à jour le score, sous forme de _string_.
- Le troisième paramètre est le score que tu souhaites **ajouter** au meilleur score enregistré.

```swift
var highScores = ["Dave Thomas": 0, "José Valim": 486_373]
addPlayer(&highScores, "Freyja Ćirić", 12_771_008)
updateScore(&highScores, "Freyja Ćirić", 73)
// Returns ["Dave Thomas": 0, "José Valim": 486_373, "Freyja Ćirić": 12_771_081]
```

## 6. Récupère la liste des joueurs triés par nom

Définis la fonction `orderByPlayers`, qui prend 1 paramètre :

- Le premier paramètre est le dictionnaire des scores.

La fonction renvoie un tableau de tuples `(String, Int)`, à savoir les joueurs et leurs meilleurs scores, triés par ordre croissant du nom du joueur.

```swift
var highScores = ["Dave Thomas": 0, "José Valim": 486_373, "Freyja Ćirić": 12_771_091]
orderByPlayers(highScores)
// Returns [("Dave Thomas", 0), ("Freyja Ćirić", 12_771_091), ("José Valim", 486_373)]
```

## 7. Récupère la liste des joueurs classés par score décroissant

Pour obtenir la liste des joueurs classés par score décroissant, définis `orderByScores`, qui prend 1 paramètre :

- Le premier paramètre est le dictionnaire des scores.

La fonction renvoie un tableau de tuples `(String, Int)`, à savoir les joueurs et leurs meilleurs scores, triés par ordre décroissant du score du joueur.

```swift
var highScores = ["Dave Thomas": 0, "José Valim": 486_373, "Freyja Ćirić": 12_771_091]
orderByScores(highScores)
// Returns [("Freyja Ćirić", 12_771_091), ("José Valim", 486_373), ("Dave Thomas", 0)]
```
