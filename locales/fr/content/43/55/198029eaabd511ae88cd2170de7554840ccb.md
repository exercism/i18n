# Complément aux instructions

## Registres

| Registre | Utilisation  | Type    | Description                                        |
| -------- | ------------ | ------- | -------------------------------------------------- |
| `$a0`    | entrée       | adresse | _string_ de nom terminée par un caractère nul      |
| `$a1`    | entrée       | entier  | nombre                                             |
| `$a2`    | entrée/sortie | adresse | _string_ de résultat terminée par un caractère nul |
| `$t0-9`  | temporaire   | quelconque | pour le stockage temporaire                     |
