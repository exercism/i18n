# Instructions

Une école près de chez toi a une association étudiante très active.
L'association étudiante est dirigée par un président et, tous les 2 ans, des élections sont organisées pour élire un nouveau président.
Pour l'élection de cette année, il a été décidé qu'un nouveau système numérique de comptage des votes était nécessaire.

L'école a besoin de ton aide pour construire ce nouveau système.

## 1. Crée un compteur de votes

L'une des premières choses dont le nouveau système de vote a besoin est un compteur de votes.
Ce compteur permet de suivre les votes obtenus par un candidat donné.

Crée une fonction `new_vote_counter` qui accepte le nombre de votes initiaux d'un candidat et renvoie un instantané d'une structure `VoteCounter`, initialisée avec le nombre de votes initiaux donné.

```rust
let initial_votes: u32 = 2;
let counter: @VoteCounter = new_vote_counter(initial_votes);
// @VoteCounter {
//     value: 2,
// }
```

## 2. Récupère le nombre de votes d'un compteur

Tu as maintenant un moyen de créer de nouveaux compteurs !
Mais tu réalises maintenant que le nouveau système aura aussi besoin d'un moyen de récupérer le nombre de votes d'un compteur.

Crée une fonction `vote_count` qui prend un compteur (`@VoteCounter`) en argument et renvoie le nombre de votes du compteur.

```rust
let initial_votes: u32 = 3;
let vote_counter: @VoteCounter = new_vote_counter(initial_votes);

let count = vote_count(vote_counter);
// => 3
```

## 3. Incrémente les votes d'un compteur

C'est enfin le moment de compter les votes !
Il te faut maintenant un moyen d'incrémenter les votes d'un compteur.

Crée une fonction `increment_vote_count` qui prend un compteur (`@VoteCounter`) et un nombre de votes en arguments, et qui incrémente le compteur de ce nombre de votes.

```rust
let votes: u32 = 3;
let vote_counter: @VoteCounter = new_vote_counter(initial_votes);
let vote_counter: VoteCounter = increment_vote_count(vote_counter, 2);

let count = vote_count(@vote_counter);
// => 5
```

## 4. Crée les résultats de l'élection

Maintenant que tous les votes sont comptés, il est temps de préparer l'annonce des résultats pour toute l'école.
Pour cela, tu remarques qu'avoir uniquement des compteurs de votes ne suffit pas.
Il faut un moyen d'associer le nombre de votes à un candidat donné.

Crée une fonction `new_election_result` qui reçoit le nom d'un candidat et son nombre de votes, et renvoie un nouveau résultat d'élection.

```rust
let result: ElectionResult = new_election_result("Peter", 3);
// ElectionResult {
//     name: "Peter",
//     votes: @VoteCounter {
//         value: 3,
//     },
// }
```

La structure de résultat d'élection est déjà créée pour toi et elle est définie ainsi :

```rust
struct ElectionResult {
    name: ByteArray,
    counter: @VoteCounter,
}
```

## 5. Annonce les résultats

Il est temps d'annoncer le nouveau président à toute l'école !
Le président sera annoncé sur les petits panneaux d'affichage numériques de l'école.

Le message doit afficher le nom du nouveau président et le nombre de votes obtenus, au format suivant : `<candidate_name> (<votes>)`.
Voici un exemple d'un tel message : `"Peter (51)"`.

Crée une fonction `display_result` qui reçoit un `@ElectionResult` en argument et renvoie un `ByteArray` contenant le message à afficher.

```rust
let result = ElectionResult {
    name: "John",
    votes: @VoteCounter {
        value: 32,
    },
};

let msg = display_result(@result);
// => "John (32)"
```

## 6. Recompte des votes

Pour s'assurer que les résultats finaux étaient exacts, les votes ont été recomptés.
Lors du recomptage, on a constaté que le nombre de votes de certains candidats était erroné d'une unité.

Crée une fonction `decrement_votes_of_candidate` qui reçoit les résultats finaux et le nom d'un candidat dont il faut décrémenter le nombre de votes.
Les résultats finaux sont fournis sous la forme d'un `Felt252Dict<u32>`, où les clés sont les noms des candidats et les valeurs leur nombre total de votes.

```rust
let mut final_results: Felt252Dict<u32> = Default::default();
final_results.insert('Mary', 10);
final_results.insert('John', 51);

decrement_votes_of_candidate(ref final_results, 'Mary');

let decremented_votes = final_results.get('Mary');
// => 9
```
