# Introduction

Les méthodes d'extension permettent d'ajouter des méthodes à des types existants sans créer de nouveau type dérivé, sans recompiler ni modifier le type d'origine d'une autre manière. Elles se définissent comme des méthodes statiques, mais s'appellent avec la syntaxe des méthodes d'instance. Leur premier paramètre, précédé du modificateur `this`, précise le type sur lequel la méthode opère ; elles sont mises dans la portée au niveau de l'espace de noms.

```csharp
public static int WordCount(this string str)
{
    return str.Split().Length;
}

"Hello World".WordCount();
// => 2
```
