# Astuces

## 1. Rétrograde les notes

- Il existe différentes façons de comparer un type concret ou un type abstrait (voir l'introduction).
- La fonction [`ceil`][ceiling] peut prendre un type en argument pour indiquer le type de sortie souhaité.
- La fonction [`convert`][convert] est un moyen général de convertir entre types.
- Rappelle-toi qu'il existe une fonction qui renvoie le type de n'importe quelle entrée (ce qui peut être pratique pour le message d'erreur).
- Tu peux en savoir plus sur [`throw`][throw] et [MethodError][methoderror] dans la documentation.

## 2. Prétraite les données

- Ici, on peut considérer les `Vector`s et les `Set`s comme des types abstraits, du moins en ce qui concerne les comparaisons.
- Utilise ta fonction `demote` pour convertir les notes.
- Contente-toi d'inverser le vecteur (`O(N)`), sans le trier (`O(NlogN)`).
- Tu peux en savoir plus sur [`throw`][throw] et [MethodError][methoderror] dans la documentation.
