# Général

- [L'application partielle][partial-application] et [`(|>)`][pipe-operator] facilitent l'écriture de code élégant et enchaîné, quand la structure de données principale est le dernier argument des fonctions. Toutes les fonctions courantes de la bibliothèque standard font cela, comme `List.map`
- On peut utiliser une [instruction `let`][let] dans les fonctions `attack` pour appliquer partiellement les fonctions `attackWithSword` et `attachWithClaw` avec la force correcte pour Annalyn et Kazak.

[pipe-operator]: https://package.elm-lang.org/packages/elm/core/latest/Basics#|%3E
[partial-application]: https://riptutorial.com/elm/example/7499/partial-application
[let]: "https://elmprogramming.com/let-expression.html"
