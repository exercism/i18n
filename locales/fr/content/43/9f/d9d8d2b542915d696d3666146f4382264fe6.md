# Indices

## 1. Crée un nouveau tableau des meilleurs scores

- Crée un nouvel objet à l'aide d'accolades.
- Écris la clé sous forme de _string_ afin qu'elle puisse contenir des espaces.
- Sépare la clé et la valeur à l'aide de deux-points.

## 2. Ajoute des joueurs à un tableau des meilleurs scores

- Utilise la notation entre crochets pour ajouter une clé dont le nom est stocké dans une variable (l'argument).
- Utilise l'opérateur d'affectation (`=`) pour définir une valeur pour la nouvelle clé.
- Renvoie le paramètre du tableau des meilleurs scores après avoir ajouté le joueur.

## 3. Retire des joueurs d'un tableau des meilleurs scores

- Utilise l'[opérateur delete][mdn-delete].
- Référence la clé comme tu l'as fait dans la tâche précédente (la notation entre crochets).

## 4. Augmente le score d'un joueur

- Réfléchis d'abord à la façon d'exprimer la nouvelle valeur que tu veux affecter.
- Utilise ensuite l'opérateur d'affectation, comme dans la tâche 2, pour définir cette nouvelle valeur.
- Si tu ne l'as pas déjà fait, tu peux utiliser l'[opérateur d'affectation abrégé][mdn-shorthand-assignment] `+=`.

## 5. Applique les points bonus du lundi

- Utilise une boucle `for...in` pour parcourir toutes les clés de l'objet.
- Pour chaque clé, définis la nouvelle valeur comme tu l'as fait dans la tâche 4.
