# À propos

Comme d'autres langages, le C++ propose aussi une instruction `switch`.
Les instructions `switch` sont un moyen plus court d'écrire de longues instructions `if ... else if`.
Pour créer un `switch`, on commence par utiliser le mot-clé `switch` suivi d'un entier.
On déclare ensuite chacune des conditions avec le mot-clé `case`.
On peut aussi déclarer un cas `default`, qui s'exécutera quand aucune des conditions `case` précédentes ne correspond.
Chaque cas doit se terminer par une instruction `break` (ou `return`).

```cpp
int price{0};
int adults{3};
int kids{2};

switch (int group_size{adults + kids}) {
    case 1:
        price = 50;
        break;
    case 2:
        price = 70;
        break;
    default:
        price = group_size * 30;
}
```

## L'exécution en cascade

Un point important à propos de la construction `switch` est que le code continue de s'exécuter jusqu'à ce qu'une instruction `break` (ou `return`) l'arrête.
Cela peut entraîner un comportement inattendu.

```cpp
int adults{1};
int kids{0};
switch (int group_size{adults + kids}) {
    case 1:
        price = 50;
    case 2:
        price = 70;
    default:
        price = group_size * 30;
}
// price will be 30!
```

Le principal cas d'usage de cette exécution continue est une instruction qui porte plusieurs étiquettes.
Plusieurs résultats d'un `switch` peuvent correspondre au même morceau de code à exécuter.
Ainsi, dans une application de réservation par exemple, la fonction appelée pour des groupes de taille 2 et 3 peut être la même :
```cpp
switch (group_size) {
case 1:
    book_room();
    break;
case 2:
case 3:
    book_apartment(group_size);
    break;
default:
    book_house(group_size);
}
// book_apartment happens wheng roup_size is 2 or 3
```

~~~~exercism/note
Comme tu l'as vu, l'instruction `switch` en C++ est très limitée si on la compare à celle d'autres langages.
De nombreux langages peuvent faire des `switch` basés sur une expression booléenne, voire sur des expressions régulières.
Tu peux voir la version C++ comme une construction étendue de type goto/switch.
Seule l'instruction `switch` peut sauter vers une étiquette.
Ensuite, toutes les autres étiquettes sont ignorées et tu dois utiliser l'instruction `break` pour sortir du bloc de code.
~~~~
