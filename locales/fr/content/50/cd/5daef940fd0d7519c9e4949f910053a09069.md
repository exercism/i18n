# Liens internes

Les liens rendus via l'analyseur Markdown d'Exercism sont vérifiés pour déterminer s'ils sont internes et, le cas échéant, peuvent être décorés d'infobulles.

Une infobulle pour un concept peut ressembler à ceci :

<img src="https://raw.githubusercontent.com/exercism/docs/main/.imgs/concept-tooltip.png" height="200">

## Utilisation

Il n'existe pas de syntaxe spéciale pour décorer les liens de cette manière.
À la place, on vérifie si l'attribut href du lien suit l'une des deux formes suivantes :

- Une URL. Par ex. https://exercism.org/tracks/ruby/concepts/basics
- Un chemin absolu. Par ex. /tracks/ruby/concepts/basics

Nous ne prenons pas encore en charge les URL relatives (par ex. celles qui commencent par `./` ou `../`), car l'analyseur Markdown ne connaît ni le contexte du document qu'il rend, ni le contexte dans lequel il effectue le rendu, ni la structure d'un dépôt git.

## Alternatives

Plutôt que d'utiliser des liens normaux, tu pourrais être tenté d'afficher des widgets.
Ils sont généralement utilisés à la fin d'un document pour suggérer des lectures supplémentaires ou de bons exercices pour apprendre quelque chose.

Consulte [la documentation sur les widgets](/docs/building/markdown/widgets) pour plus de détails.
