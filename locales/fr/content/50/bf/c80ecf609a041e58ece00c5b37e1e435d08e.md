# À propos

Les variables qui sont déclarées avec le mot-clé `final` au lieu de `var` ne peuvent être affectées qu'une seule fois.

```haxe
final a = "hello";
var b = "world";
trace(a, b); // hello, world
b = "haxe";
trace(a, b); // hello, haxe

// The following line would cause a compilation error:
// a = "bye";
```

Il est important de noter que `final` peut ne pas avoir l'effet escompté avec des types qui ne sont pas immuables, comme les tableaux ou les objets :

```haxe
final a = [0, 1, 2];
trace(a); // [0,1,2]

// this would cause a compilation error:
// a = [0, 1, 2, 3];

// but the following line works:
a.push(3);
trace(a); // [0,1,2,3]
```
