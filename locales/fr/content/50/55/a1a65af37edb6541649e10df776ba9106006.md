# Tests

Pour lancer les tests, exécute la commande suivante :

```bash
make
```

## Tests ignorés

Résoudre un exercice, c'est faire en sorte que tous ses tests réussissent.
Par défaut, un seul test (le premier) est exécuté quand on lance les tests.
C'est volontaire : cela te permet de te concentrer uniquement sur la réussite de ce test.
Une fois qu'il réussit, tu peux activer le test suivant en supprimant la ligne `TEST_IGNORE()`.
Quand tous les tests sont activés et que ton implémentation les fait tous réussir, tu auras résolu l'exercice !

## Débogage

Pour t'aider à déboguer, plusieurs macros sont définies dans un fichier `debug.mac`.
On peut les appeler avec un ou plusieurs arguments de la taille appropriée.
Par exemple :

```x86asm
debugf32 xmm0, xmm1 ; prints the value of two 32-bit floating-point numbers
debugd16 ax, cx, dx ; prints the value of three signed 16-bit integers
debugx64 [rax]      ; prints the value of a 64-bit integer in hexadecimal format
debugs rsi          ; prints a NUL-terminated string whose address is stored in `rsi`
debugu8_xmm xmm1    ; prints 16 packed 8-bit unsigned integers
```

Pour utiliser l'une de ces macros, tu dois inclure `debug.mac` en haut du fichier de solution :

```x86asm
%include "debug.mac"
```
