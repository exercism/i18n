# Ajout aux instructions

## Fonctions et tests

Le code de départ qui t'est fourni,
```scheme
(provide hello)

(define (hello)
  "Goodbye, Mars!")
```
définit une fonction nommée `hello` et la rend exécutable.
L'exécuteur de tests récupère cette fonction et l'exécute, en comparant la valeur qu'elle renvoie à celle qu'il attend.
Utilise cette définition de fonction de départ comme base pour ta solution.
