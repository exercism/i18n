# Instructions spécifiques à SQLite

* La colonne **candidates** contient une liste de _strings_ encodée en JSON.
  Exemple :
  ```json
  ["stone","tones","banana","tons","notes","Seton"]
  ```
* La colonne **result** doit elle aussi contenir une liste de _strings_ encodée en JSON.

## Schéma de la table

```sql
CREATE TABLE anagram (
  subject    TEXT NOT NULL,
  candidates TEXT NOT NULL,     -- json array of strings
  result     TEXT               -- json array of strings
);
```
