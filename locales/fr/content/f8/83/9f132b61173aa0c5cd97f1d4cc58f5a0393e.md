# Introduction

## Arguments nommés

Quand une fonction prend beaucoup d'arguments, il peut être difficile de se souvenir de l'ordre dans lequel les fournir. Pour faciliter la lecture, Gleam permet de nommer les arguments.

Pour nommer un argument, indique le nom du label avant le nom de l'argument, en les séparant par un espace.

```gleam
pub fn replace(
  in string: String,
  each target: String,
  with replacement: String
) -> String {
  // ...
}
```

Quand on appelle une fonction avec des arguments nommés, on peut fournir les arguments dans n'importe quel ordre. Ces appels à `replace` sont tous équivalents :

```gleam
replace(in: "🍔🍔🍔", each: "🍔", with: "🍕")

replace(each: "🍔", in: "🍔🍔🍔", with: "🍕")

replace(with: "🍕", each: "🍔", in: "🍔🍔🍔")
```

Les labels sont toujours facultatifs. Même si une fonction prend des arguments nommés, on peut toujours l'appeler sans les labels.

```gleam
replace("🍔🍔🍔", "🍔", "🍕")
```
