# À propos

Les [tuples][tuples] servent à combiner plusieurs valeurs en une seule valeur composée, où chacune des valeurs peut avoir un type différent.
Le type de cette valeur composée est la combinaison des types des valeurs individuelles.
Comme les tableaux, les tuples sont des collections ordonnées.
Cependant, contrairement aux tableaux, les tuples ont une taille fixe ; pour changer le nombre d'éléments d'un tuple, il faut donc créer un nouveau tuple.

Pour créer un tuple, on place les valeurs entre parenthèses, séparées par des virgules :

```swift
let order = ("biscuits", 2.99, 3)
```

On peut aussi préciser le type de chaque valeur du tuple :

```swift
let order: (String, Double, Int) = ("biscuits", 2.99, 3)
```

Pour extraire les valeurs individuelles d'un tuple, on peut utiliser la syntaxe `.n`, où _n_ est l'indice de l'élément auquel on veut accéder, en commençant par 0 :

```swift
let orderItem = order.0
// Returns "biscuits"

let orderQuantity = order.2
// Returns 3
```

## Tuples nommés

On peut nommer les tuples en fournissant une étiquette pour chacune des valeurs :

```swift
let order = (item: "biscuits", price: 2.99, quantity: 3)
```

Cela peut être utile pour rendre le tuple plus lisible et plus explicite, en particulier lorsqu'il est utilisé comme valeur de retour d'une fonction.

Cela permet aussi d'accéder aux valeurs individuelles par leur nom :

```swift
let orderItem = order.item
// Returns "biscuits"
let orderQuantity = order.quantity
// Returns 3
```

Comme pour les tuples non nommés, on peut préciser le type de chaque valeur d'un tuple nommé :

```swift
let order: (item: String, price: Double, quantity: Int) = (item: "biscuits", price: 2.99, quantity: 3)
```

## Modifie un tuple

On peut modifier les éléments d'un tuple, et cela se fait avec la syntaxe `.n`.

```swift
var order = ("biscuits", 2.99, 3)
order.0 = "cookies"
order.1 = 1.99
order.2 = 5

order
// Returns ("cookies", 1.99, 5)
```

## Plusieurs valeurs de retour

En Swift, les fonctions ne peuvent renvoyer qu'une seule valeur.
Cependant, comme un tuple est une seule valeur, on peut regrouper plusieurs valeurs dans un tuple et renvoyer ce tuple depuis une fonction.
Cela permet en pratique de [renvoyer plusieurs valeurs depuis une fonction][multiple-return-values].

Voici un exemple de fonction qui renvoie un tuple contenant un quotient et un reste :

```swift
func divide(_ dividend: Int, by divisor: Int) -> (quotient: Int, remainder: Int) {
  let quotient = dividend / divisor
  let remainder = dividend % divisor
  return (quotient, remainder)
}
```

## Décomposition d'un tuple

Pour décomposer un tuple en ses composants individuels, on fournit autant de variables que le tuple a d'éléments.
Recourir à la décomposition de tuple peut rendre le code plus lisible, puisque cela permet de donner des noms explicites aux valeurs individuelles.

```swift
let order = ("biscuits", 2.99, 3)
let (item, price, quantity) = order

item
// Returns "biscuits"
```

La décomposition fonctionne aussi avec les boucles for-in :

```swift
let orders = [("biscuits", 2.99, 3), ("cookies", 1.99, 5)]

for (item, price, quantity) in orders {
  print("Item: \(item), Price: \(price), Quantity: \(quantity)")
}
```
