# Concepts de Luhn

Luhn est un algorithme de validation qui combine des assertions textuelles et numériques. Les solutions en Rust privilégient les approches fonctionnelles.

## Généralités

### Primitives

- `&str` et `char`
  - les apprenants doivent saisir la distinction entre un `char` pris isolément et un `&str` afin d'exclure ou d'inclure correctement des parties de l'entrée fournie
- entier
  - comprendre les entiers est important pour effectuer la validation numérique requise
- booléens
  - indispensables pour les assertions d'identité et les comparaisons finales

### Fonctionnalités des itérateurs

- chaînage
  - il est important de comprendre les chaînes d'itérateurs ici pour résoudre le problème de manière ordonnée.
- `map`, `filter`, _turbofish_, éventuellement `fold`
  - combiner _map_ et _filter_ fournit un patron de conception fondamental pour les problèmes de validation comme celui-ci. Les solutions à base de `fold` ont en outre l'avantage d'être plus concises.
  - le _turbofish_ est nécessaire dans certaines solutions pour indiquer à Rust quel type on crée à partir d'une expression chaînée

## Solution d'exemple 1

La [solution](https://exercism.org/tracks/rust/exercises/luhn/solutions/7038c269a4af4f5b95ca35a99c5c3b4d) de york

```rust
pub fn is_valid(code: &str) -> bool {
    code.chars()
        .filter(|c| !c.is_ascii_whitespace())
        .rev()
        .try_fold((0, 0), |(num_count, sum), c| {
            c.to_digit(10).map(|x| {
                let double = x * (num_count % 2 + 1);
                let double = if double > 9 { double - 9 } else { double };
                (num_count + 1, sum + double)
            })
        })
        .map_or(false, |(num_count, sum)| num_count >= 2 && sum % 10 == 0)
}
```

## Solution d'exemple 2

Canonique

```rust
pub fn is_valid(candidate: &str) -> bool {
    if candidate.chars().filter(|c| c.is_ascii_digit()).take(2).count() <= 1
        || candidate.chars().any(|c| !c.is_ascii_digit() && c != ' ')
    {
        return false;
    }

    candidate
        .chars()
        .filter_map(|c| c.to_digit(10))
        .rev()
        .enumerate()
        .map(|(index, digit)| if index % 2 == 0 { digit } else { digit * 2 })
        .map(|digit| if digit > 9 { digit - 9 } else { digit })
        .sum::<u32>()
        % 10
        == 0
}
```
