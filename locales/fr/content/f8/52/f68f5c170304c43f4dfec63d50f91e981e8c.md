# Introduction

JavaScript est un langage dynamique, qui prend en charge les styles orienté objet, impératif et déclaratif (par exemple la programmation fonctionnelle).

## Variables

Il existe plusieurs façons principales d'affecter des valeurs à des noms en JavaScript : avec des variables ou des constantes.
Sur Exercism, les variables s'écrivent toujours en [`camelCase`][wiki-camel-case] ; les constantes s'écrivent en [`SCREAMING_SNAKE_CASE`][wiki-snake-case].
Il n'existe pas de guide officiel à suivre, et chaque entreprise ou organisation a son propre guide de style.
_Tu peux écrire tes variables comme tu le souhaites_.
L'avantage d'écrire les variables comme les exercices les préparent, c'est qu'elles seront mises en évidence différemment dans l'interface web et dans la plupart des IDE.

En JavaScript, on peut définir des variables avec le mot-clé [`const`][mdn-const], [`let`][mdn-let] ou [`var`][mdn-var].

Une variable peut référencer différentes valeurs au cours de sa vie quand on utilise `let` ou `var`.
Par exemple, `myFirstVariable` peut être définie et redéfinie plusieurs fois avec l'opérateur d'affectation `=` :

```javascript
let myFirstVariable = 1;
myFirstVariable = 'Some string';
myFirstVariable = new SomeComplexClass();
```

Contrairement à `let` et `var`, une variable définie avec `const` ne peut être affectée qu'une seule fois.
C'est ainsi que l'on définit les constantes en JavaScript.

```javascript
const MY_FIRST_CONSTANT = 10;

// Can not be re-assigned.
MY_FIRST_CONSTANT = 20;
// => TypeError: Assignment to constant variable.
```

## Déclarations de fonctions

En JavaScript, les unités de fonctionnalité sont encapsulées dans des _fonctions_, que l'on regroupe généralement dans un même fichier quand elles vont ensemble.
Ces fonctions prennent des paramètres (afin de pouvoir recevoir des arguments) et peuvent _renvoyer_ une valeur avec le mot-clé `return`.
On appelle les fonctions avec la syntaxe `()`.

```javascript
function add(num1, num2) {
  return num1 + num2;
}

add(1, 3);
// => 4
```

Dans cet exemple, le nom de la fonction est `add`.
Elle prend deux paramètres, `num1` et `num2`.
Elle renvoie une valeur : le résultat de l'expression `num1 + num2`

Ensuite, la fonction `add` est _appelée_ avec deux arguments : `1` et `3`.
Le résultat de la fonction, la valeur de retour, est `4`.

```exercism/note
💡 En JavaScript, il existe _de nombreuses_ façons différentes de déclarer une fonction.
Certaines de ces autres façons sont différentes de l'utilisation du mot-clé `function`.
Le parcours essaie de les introduire progressivement, mais si tu les connais déjà, n'hésite pas à utiliser l'une ou l'autre.
Dans la plupart des cas, utiliser l'une ou l'autre n'est ni mieux ni pire.
```

## Expose du code aux autres fichiers

Pour rendre une `function`, une constante ou une variable disponible dans _d'autres fichiers_, il faut les [exporter][mdn-export] avec le mot-clé `export`.
Un autre fichier peut ensuite les [importer][mdn-import] avec le mot-clé `import`.
C'est ce qu'on appelle aussi le système de modules.

Un bon exemple est le fonctionnement de tous les tests.
Chaque exercice a au moins un fichier, par exemple `lasagna.js`, qui contient l'_implémentation_.
L'_implémentation_ est `export`ée depuis le fichier, ce qui la rend importable dans un autre fichier.
Il y a en plus au moins un autre fichier, par exemple `lasagna.spec.js`, qui contient les _tests_.
Ce fichier `import`e les entités publiques (c'est-à-dire `export`ées) afin de tester l'implémentation :

```javascript
// file.js
export const MY_VALUE = 10;

export function add(num1, num2) {
  return num1 + num2;
}

// file.spec.js
import { MY_VALUE, add } from './file';

add(MY_VALUE, 5);
// => 15
```
