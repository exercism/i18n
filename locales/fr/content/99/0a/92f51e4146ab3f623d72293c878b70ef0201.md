# Utilise l'interpolation de chaîne de caractères

[comment]: # (Cet avertissement est généré lorsque la solution n'utilise pas l'interpolation de chaîne de caractères)

Utilise [l'interpolation de chaîne de caractères](https://github.com/elixir-lang/elixir/blob/9cac52833e91b5ebac0d322b20e39605d8dafad9/lib/elixir/lib/string.ex#L20) pour insérer le paramètre `name` dans la chaîne de sortie.

- Si possible, dans le parcours Elixir d'Exercism, il est recommandé d'utiliser l'interpolation de chaîne de caractères plutôt que la concaténation de chaînes de caractères pour la lisibilité.

```elixir
def hello(what) do
  "Hello, #{what}"
end
```

- [Toute expression Elixir](https://github.com/elixir-lang/elixir/blob/9cac52833e91b5ebac0d322b20e39605d8dafad9/lib/elixir/lib/string.ex#L30) peut figurer dans la syntaxe d'interpolation de chaîne de caractères

```elixir
def pluralize_apple(n) when n >= 1 do
  "apple#{if n > 1, do: "s"}"
end
```
