# Installation

Utilise le binaire `full` correspondant à ta plateforme, disponible sur [la page officielle des versions][official-releases].
Pour l'instant, le parcours cible la version Arizona Bark d'Arturo 0.10.0.

~~~~exercism/caution
Homebrew est une méthode tierce très répandue pour installer des logiciels sur macOS et Linux.
Cependant, sa formule pour Arturo cible la variante `mini`, qui est incompatible avec ce parcours.
~~~~

Pour toute aide supplémentaire concernant l'installation d'Arturo, consulte le [Discord officiel d'Arturo][discord].

## Exécute du code Arturo

À ce stade, tu es prêt à écrire du code Arturo !
Pour accéder au REPL d'Arturo, lance `arturo` en ligne de commande.
Pour exécuter un script Arturo, lance `arturo <file>` en ligne de commande.

[official-releases]: https://arturo-lang.io/#download
