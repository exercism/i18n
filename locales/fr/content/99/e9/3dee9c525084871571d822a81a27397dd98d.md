# Instructions

Un pirate trace un itinéraire à travers une carte de criques cachées.
La carte est une table de hachage indexée par nom de crique ; chaque valeur est un
tableau des criques que l'on peut atteindre directement depuis celle-ci.

## 1. Vide la file de marée

Définis `tide-queue` pour qu'elle prenne un tableau d'éléments, pousse chacun dans une
nouvelle _deque_ (dans l'ordre), puis ressorte-les tous dans un tableau
qui préserve l'ordre d'origine. C'est le principe FIFO (premier entré, premier sorti) : on
ajoute à la fin, on retire au début.

```factor
{ "alpha" "bravo" "charlie" } tide-queue .
! => { "alpha" "bravo" "charlie" }
```

## 2. Criques accessibles

Définis `coves-reachable` pour qu'elle prenne une crique de départ et une carte,
et renvoie un _hash-set_ de toutes les criques accessibles depuis `start`,
y compris `start` elle-même.

```factor
"Skull Bay" H{
    { "Skull Bay"   { "Hidden Cove" } }
    { "Hidden Cove" { "Reef Point"  } }
    { "Reef Point"  { } }
} coves-reachable .
! => HS{ "Skull Bay" "Hidden Cove" "Reef Point" }
```

Utilise une `<dlist>` comme frontière du parcours en largeur et un `HS{ }` pour
l'ensemble des criques visitées.

## 3. Nombre de sauts

Définis `hop-count` pour qu'elle prenne une crique de départ, une crique d'arrivée et une
carte, et renvoie le nombre minimum de sauts entre elles, ou
`f` si la crique d'arrivée n'est pas accessible.

```factor
"Skull Bay" "Hidden Cove"
H{
    { "Skull Bay"   { "Hidden Cove" } }
    { "Hidden Cove" { } }
} hop-count .
! => 1
```

Fais suivre chaque crique de sa distance depuis le départ dans la
_deque_ (un tableau de 2 éléments fait l'affaire).

## 4. Quantité d'or

Le squelette déclare `gold-count` avec `:`. Remplace-le par `MEMO:`
(et non `:`) pour que le résultat de chaque crique ne soit calculé qu'une fois puis
mis en cache. Cherche l'or de la crique dans la constante `gold-distribution`
fournie par l'exercice.
Une crique absente de la distribution n'a pas d'or.

```factor
"Smuggler's Hollow" gold-count .   ! => 200
"Davy Jones' Locker" gold-count .  ! => 0
```

## 5. Route du trésor

Définis `treasure-route` pour qu'elle prenne une crique de départ et une carte, et
renvoie la crique accessible qui contient le plus d'or. Utilise
`coves-reachable` de la tâche 2 et `gold-count` de la tâche 4.

```factor
"Skull Bay" some-chart treasure-route .
! => "Smuggler's Hollow"   (the richest reachable cove)
```

Le `gold-count` mémoïsé rend les recherches répétées gratuites, ce qui est utile
quand plusieurs parties de l'algorithme consultent la même crique.
