# signature modifiée

Ne modifie pas les déclarations de fonctions, sauf si c'est absolument nécessaire.
Le squelette fournit les bons `exports` et les bonnes déclarations `function`, avec le nombre et le format de paramètres attendus.
Il est parfois possible de modifier la signature d'une fonction (c'est-à-dire de changer la façon dont ses paramètres fonctionnent), mais dans ce cas, les paramètres étaient déjà définis de façon optimale.
