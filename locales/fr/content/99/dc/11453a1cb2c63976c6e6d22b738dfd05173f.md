# Ressources recommandées

## Documentation

* [Groovy Language Documentation](http://docs.groovy-lang.org/docs/latest/html/documentation/)
* [Groovy JDK API Documentation](http://groovy-lang.org/gdk.html)
* La [Groovy Documentation](http://www.groovy-lang.org/documentation.html) d'Apache, avec notamment l'excellente section [Learn Groovy](http://www.groovy-lang.org/learn.html)

## Outils

* [SDKman](http://sdkman.io/)
* [Groovy Eclipse](https://github.com/groovy/groovy-eclipse/wiki)
* [IntelliJ Idea](https://www.jetbrains.com/idea/download/)

## Technologies

* [Gradle](https://gradle.org/), un outil de build pour les gouverner tous
* [Spock](http://spockframework.org/), la nouvelle génération de tests pour les langages de la JVM
* [Ratpack](https://ratpack.io/), des microservices miniatures avec des martinis
* [Grails](https://grails.org/), « Tu dois choisir, mais choisis sagement. »

## Collaboration
