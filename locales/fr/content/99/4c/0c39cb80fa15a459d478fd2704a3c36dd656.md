# Introduction

Python représente les valeurs vrai et faux avec le type [`bool`][bools], qui est une sous-classe de `int`.
Ce type ne comporte que deux valeurs : `True` et `False`.
Ces valeurs peuvent être affectées à une variable :

```python
>>> true_variable = True
>>> false_variable = False
```

On peut évaluer des expressions booléennes avec les opérateurs `and`, `or` et `not` :

```python
>>> true_variable = True and True
>>> false_variable = True and False

>>> true_variable = False or True
>>> false_variable = False or False

>>> true_variable = not False
>>> false_variable = not True
```

[bools]: https://docs.python.org/3/library/stdtypes.html#typebool
