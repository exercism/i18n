# Ajout aux instructions

## Astuce

Une fonction avec un *type de retour* ne peut renvoyer que des données de ce *type* et `null`.
Or, l'appelant de la fonction ne s'attend qu'à un seul type de données.

Exemple :
```dart
String hello(int a){
    if ( a == 0){
        return "a";
    } else {
        return null;
    }
}
```
Pour indiquer plus clairement que cette fonction peut aussi renvoyer `null` ou d'autres types de données, utilise `dynamic`.
```dart
dynamic hello(int a){
    if ( a == 0){
        return "a";
    } else {
        return null;
    }
}
