# Introduction

Avant l'introduction de la classe `Promise`, il n'y avait qu'une seule façon de gérer le code asynchrone : le _modèle de rappel_.

Une fonction de rappel est une fonction qui est passée comme argument à une autre fonction et qui sera appelée une fois qu'une action dans cette autre fonction est terminée. Un modèle courant pour ces fonctions de rappel est qu'elles acceptent une erreur comme premier paramètre (voir l'exemple ci-dessous).

```javascript
function callback(error, arg2, arg3) {}
```

Quel est le rapport avec le code asynchrone ?

Historiquement, on utilisait les fonctions de rappel pour pouvoir effectuer un travail une fois une tâche asynchrone terminée, sans bloquer tout le programme.

```javascript
fetchProduct(productId, function (error, data) {
  if (error) {
    // Handle the error
  } else {
    // Do some work
  }
});
```

Dans l'exemple ci-dessus, la fonction `fetchProduct` (qui est asynchrone) prend une fonction de rappel comme second argument qui décide quoi faire lorsque les données du produit ont été récupérées.
