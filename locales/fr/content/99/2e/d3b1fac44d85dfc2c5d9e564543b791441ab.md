# Instructions supplémentaires

## Registres

| Registre | Utilisation  | Type    | Description                        |
| -------- | ------------ | ------- | ---------------------------------- |
| `$a0`    | entrée       | entier  | N, somme des côtés du triangle     |
| `$a1`    | entrée/sortie | adresse | valeurs de a                       |
| `$a2`    | entrée/sortie | adresse | valeurs de b                       |
| `$a3`    | entrée/sortie | adresse | valeurs de c                       |
| `$v0`    | sortie       | entier  | nombre de triplets                 |
| `$t0-9`  | temporaire   | quelconque | pour le stockage temporaire     |
