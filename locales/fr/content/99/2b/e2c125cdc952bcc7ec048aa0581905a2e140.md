# Introduction

Les **_closures_** sont un modèle de programmation [en Clojure][clojure-guide-closures] qui permet d'utiliser des variables issues d'une [portée lexicale][wiki-lexical-scope] externe à l'intérieur d'une fonction. Clojure prend en charge les closures de façon transparente, et on les utilise souvent sans savoir ce qu'elles sont.

```clojure
;; Top-level definitions are global-scope
(def dozen 12)

;; Functions create a new scope.
;; Referencing the outer variable here is a closure.
(fn [n] (* dozen n))
```

## Closures pour conserver l'état et transmettre des valeurs

Utiliser un _atom_ permet de conserver un peu d'état :

```clojure
;; This function closure increments the counter's state
;; in the outer lexical context.
;; This way the counter can be shared between many calling contexts.

(def increment
  (let [counter (atom 0)]
    (fn [] (swap! counter inc))))
```

Chaque appel successif à `increment` incrémente son compteur :

``` clojure
(increment)
;;=> 1
(increment)
;;=> 2
```
