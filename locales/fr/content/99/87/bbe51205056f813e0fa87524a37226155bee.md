# Installe Kotlin

En plus de l'Exercism CLI et de ton éditeur de texte préféré, pour t'entraîner sur les exercices Kotlin d'Exercism, il te faut :

* le **Java Development Kit** (JDK), car Kotlin se compile en bytecode Java ; tu dois donc installer le JDK, qui inclut à la fois un environnement d'exécution Java *et* des outils de développement (notamment le compilateur Java) ; et
* **Gradle**, un outil de compilation conçu spécifiquement pour les projets basés sur la JVM et qui prend en charge Kotlin.

Choisis ton système d'exploitation :

* [Windows](#h-windows)
* [macOS](#h-macos)
* [Linux](#h-linux)

... ou ...
* si tu préfères ne pas utiliser de gestionnaire de paquets, tu peux [installer manuellement](#h-install-manually).

En option, tu peux aussi utiliser un [IDE Java](#h-java-ides).

----

## Windows

Ouvre une invite de commandes en mode administrateur. (Si tu as besoin d'aide pour ouvrir une invite en mode administrateur, consulte [ouvrir une invite avec élévation de privilèges dans Windows 8+](http://www.howtogeek.com/194041/how-to-open-the-command-prompt-as-administrator-in-windows-8.1/) (ou [Windows 7](http://www.howtogeek.com/howto/windows-vista/run-a-command-as-administrator-from-the-windows-vista-run-box/)).)

1. Si tu n'as pas installé Chocolatey, fais-le maintenant :

      ```batchfile
        C:\Windows\system32> @powershell -NoProfile -ExecutionPolicy unrestricted -Command "iex ((new-object net.webclient).DownloadString('https://chocolatey.org/install.ps1'))" && SET PATH=%PATH%;%ALLUSERSPROFILE%\chocolatey\bin
      ```

2.  Installe le JDK :

       ```batchfile
        C:\Windows\system32> choco install openjdk11
        ...
        C:\Windows\system32> refreshenv
        ...
       ```

On te recommande de fermer l'invite de commandes en mode administrateur et d'en ouvrir une nouvelle : tu n'as pas besoin de privilèges d'administrateur pour t'entraîner sur les exercices d'Exercism.

Tu es maintenant prêt à te lancer sur le parcours Kotlin d'Exercism !

Pour commencer, consulte « [Exécuter les tests](https://exercism.org/docs/tracks/kotlin/tests) ».

## macOS

Voici les instructions d'installation selon la méthode la plus courante, avec Homebrew. Si tu préfères, tu peux aussi [installer sous macOS sans Homebrew](#h-installing-on-macos-without-homebrew).

### Installation

1. Si tu n'as pas encore installé [Homebrew](http://brew.sh), fais-le maintenant :

      ```sh
        $ /usr/bin/ruby -e "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/master/install)"
      ```

2. Ajoute le dépôt [Homebrew Cask](https://caskroom.github.io/), ce qui permet d'installer des binaires précompilés comme le JDK.

      ```
        $ brew tap adoptopenjdk/openjdk
      ```

3.  Installe le JDK :

       ```
        $ brew install --cask adoptopenjdk11
       ```

Tu es maintenant prêt à te lancer sur le parcours Kotlin d'Exercism !

Pour commencer, consulte « [Exécuter les tests](https://exercism.org/docs/tracks/kotlin/tests) ».

## Linux

### Debian

Si tu utilises Debian ou l'une de ses dérivées (comme Ubuntu ou Linux Mint), utilise APT :

*(vérifié sur : Ubuntu 14, 16 et 18)*

1. Installe le JDK :

      ```sh
        $ sudo apt-get update
        $ sudo apt-get install software-properties-common
        $ sudo add-apt-repository ppa:openjdk-r/ppa
        $ sudo apt-get update
        $ sudo apt-get install openjdk-11-jdk
      ```


Tu es maintenant prêt à te lancer sur le parcours Kotlin d'Exercism !

Pour commencer, consulte « [Exécuter les tests](https://exercism.org/docs/tracks/kotlin/tests) ».

### Autres distributions Linux

Il existe de nombreuses façons d'installer le JDK 11, mais l'une des plus simples est d'utiliser SDKMAN, qui permet d'installer OpenJDK 11 sans difficulté. Suis les étapes suivantes :

1. Installe SDKMAN :
    ```sh
    $ curl -s "https://get.sdkman.io" | bash
    ``` 
    (si ça ne fonctionne pas, jette un œil aux instructions disponibles ici : https://sdkman.io/install )
1. Installe OpenJDK 11 :
    ```
    $ sdk install java 11.0.2-open
    ``` 

Tu es maintenant prêt à te lancer sur le parcours Kotlin d'Exercism !

Pour commencer, consulte « [Exécuter les tests](https://exercism.org/docs/tracks/kotlin/tests) ».

### Installe manuellement sous Windows

*REMARQUE : ces instructions s'adressent aux utilisateurs expérimentés de Windows. Si tu ne sais pas encore définir des variables d'environnement ou si tu n'es pas à l'aise avec la gestion de l'arborescence des dossiers, on te recommande vivement d'utiliser l'installation basée sur Chocolatey, [ci-dessus](#h-windows).*

1. Installe le JDK :
   1. Télécharge « **OpenJDK 11 (LTS)** » depuis [AdoptOpenJDK](https://adoptopenjdk.net/releases.html?variant=openjdk11#x64_win) (choisis **« Install JDK »**).
   -  Lance l'installateur en conservant toutes les valeurs par défaut.

Tu es maintenant prêt à te lancer sur le parcours Kotlin d'Exercism !

Pour commencer, consulte « [Exécuter les tests](https://exercism.org/docs/tracks/kotlin/tests) ».

## IDE Java

Il existe de nombreux IDE Java. Les trois plus populaires sont :

* [IntelliJ IDEA](https://www.jetbrains.com/idea/download/) (télécharge l'édition « Community »)
  - créé par les auteurs de Kotlin, cet IDE offre le meilleur support du langage.
- [Eclipse](https://www.eclipse.org/downloads/)
- [NetBeans](https://netbeans.org/downloads/) (télécharge le paquet « Java SE »)

et il en existe [d'autres](https://en.wikibooks.org/wiki/Java_Programming/Java_IDEs).
