# À propos

Les bibliothèques de classes de base .NET fournissent la classe [`Regex`][regex] pour le traitement des expressions régulières.

Consulte cet [article][regex-comparison] pour comparer C# avec d'autres variantes d'expressions régulières.

## Les groupes de capture

Un aspect à prendre en compte est celui des groupes de capture, qui renvoient les parties du texte correspondant à différentes parties du motif de l'expression régulière. L'approche des groupes de capture demande un certain temps d'adaptation. Consulte cette [documentation][capture].

Note qu'il existe une hiérarchie lorsqu'il est question de groupes de capture, `(?<capture-name>pattern)` :

- où un ensemble de zéro ou plusieurs correspondances est renvoyé (une pour chaque correspondance trouvée dans le texte).
- Chaque correspondance contient un certain nombre de groupes de capture
- Chaque groupe contient un certain nombre de captures.

De plus :

- `Match` dérive de `Group`
- `Group` dérive de `Capture`

Mises en garde :

- L'approche la plus sûre consiste à utiliser des captures nommées.
- Les groupes de capture apparaissent en général dans la collection `Groups` dans l'ordre où ils apparaissent dans le texte.
- `Groups[0]` semble correspondre à la correspondance entière.
- `Groups[<capture name>].Value` est très certainement ce qui t'intéresse. Les captures individuelles (autres que `Caputures[0]`) semblent, lorsqu'elles sont présentes, être destinées à des fins de diagnostic.

## Les options des expressions régulières

Familiarise-toi avec [`RegexOptions`][regex-options].

En plus des options habituelles comme `IgnoreCase`, il en existe pour `MultiLine`, utile pour traiter plusieurs lignes de texte d'un seul coup, et pour `IgnorePatternWhitespace`, qui, associée aux chaînes verbatim, à l'interpolation de chaînes et aux commentaires, peut être très expressive, comme le montre cet exemple :

```csharp
const string PREAMBLE = "preamble";
const string PWTEXT = "pwtext";
const string PW = "pw";
const string SPACE = "space";
const string POSTAMBLE = "postamble";

var pattern = $@"
    ^
    (?<{PREAMBLE}>.*)          # any text
    (?<{PWTEXT}>password)      # the literal text - password
    (?<{SPACE}>\s+)
    (?<{PW}>\w*)               # the password itself
    (?<{POSTAMBLE}>.*)         # any text
    $
  ";

var rewrittenLine = $"{grps[PREAMBLE].Value}{grps[PWTEXT].Value}{grps[SPACE].Value}{mask}{grps[POSTAMBLE].Value}";
```

Une autre option intéressante est `RegexOptions.Compiled` pour les expressions régulières [compilées][regex-compilation].
