# Résous les exercices en local

Résoudre les exercices sur ta machine te permet d'écrire tout le code dans un environnement qui t'est familier.

## Installe la CLI

Pour résoudre un exercice sur ta machine, tu dois d'abord installer et configurer l'Exercism CLI en suivant [ces instructions](https://exercism.org/cli-walkthrough).

### Configuration

Tu dois indiquer à la CLI qui tu es, afin que l'on puisse télécharger les bons éléments.
Tu trouveras ton jeton dans ta [page de paramètres](/settings/api_cli).
Tu peux ensuite configurer la CLI avec la commande suivante, en remplaçant `<your-api-token>` par la valeur indiquée sur la page de paramètres :

```
exercism configure --token=<your-api-token>
```

## Télécharge l'exercice

Une fois la CLI installée, tu peux t'en servir pour télécharger l'exercice sur ta machine avec la commande suivante (en remplaçant `<exercise-slug>` et `<track-slug>` par les valeurs correspondantes :

```
exercism download --exercise=<exercise-slug> --track=<track-slug>
```

Pas besoin de mémoriser cette structure de commande, car la page de l'exercice indique la commande qui convient.

Une fois la commande de téléchargement terminée, les fichiers de l'exercice sont téléchargés sur ta machine.

## Résous l'exercice

L'objectif de chaque exercice est de créer une implémentation qui réussit tous les tests.
Une telle implémentation s'appelle une _solution_.

Pour t'aider, chaque exercice contient les fichiers suivants :

- README.md : les instructions qui expliquent ce qui est attendu de toi
- HELP.md : des informations sur la façon de lancer les tests et d'obtenir de l'aide quand tu es bloqué
- HINTS.md (facultatif) : des indices pour t'aider à résoudre l'exercice
- Fichier(s) de test : ils contiennent les tests qui vérifient que ta solution est correcte
- Fichier(s) stub : ils fournissent un point de départ pour t'aider à construire ton implémentation

Selon le parcours, d'autres fichiers peuvent être requis par l'outillage du parcours pour que les tests s'exécutent.

## Soumets ta solution

Une fois que ta solution réussit tous les tests, tu peux la soumettre avec la commande suivante :

```
exercism submit <implementation_file_paths>
```

Cette commande envoie ta solution sur le site d'Exercism et affiche l'URL de la page de la solution.

Là encore, pas besoin de mémoriser cette commande, car le fichier `HELP.md` de l'exercice indique la bonne commande.

Tu peux soumettre une solution incomplète, ce qui te permet de :

- voir comment d'autres personnes ont résolu l'exercice
- demander de l'aide à un mentor

## Autres fonctionnalités de la CLI

### Affiche toutes les commandes

Exécute la sous-commande help pour obtenir la liste complète des commandes disponibles.

```bash
exercism help
```

### Dépannage

Vérifie que tu utilises bien la dernière version.

Vérifie la version que tu utilises :

```bash
exercism version
```

Compare avec la dernière version publiée et mets à jour si la tienne n'est pas la plus récente.

Après la mise à jour, revérifie la version. Si elle n'a pas changé, assure-toi que c'est bien le binaire mis à jour qui s'exécute.

```bash
which exercism
```

Si tu as toujours des difficultés, ouvre une _issue_ dans exercism/cli sur GitHub en y joignant la sortie de la commande troubleshoot.

```bash
exercism troubleshoot
```

Tu peux ouvrir des _issues_ sur [notre outil de suivi des issues](https://github.com/exercism/exercism/issues) et la communauté essaiera de t'aider. **Assure-toi d'avoir bien suivi la [visite guidée interactive](https://exercism.org/cli-walkthrough) avant d'ouvrir la moindre _issue_.**
