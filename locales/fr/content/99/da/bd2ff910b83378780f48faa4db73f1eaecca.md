# Debug

Quand un test échoue, un message s'affiche pour décrire ce qui s'est mal passé et pour quelle entrée. Tu peux inspecter n'importe quelle valeur de ton programme en les passant à la méthode `debug`. Elle capture alors ces valeurs et t'en affiche le résultat.

```ruby
debug "The value is #{value}."
debug "The input is #{input.inspect}"
```
