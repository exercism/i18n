# utiliser une valeur par défaut

Essaie de spécifier une valeur par défaut pour le paramètre `%{name}`.

Consulte [cette page](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/classes-and-structs/named-and-optional-arguments#optional-arguments) pour en savoir plus sur la façon de spécifier des valeurs par défaut pour les paramètres, aussi appelés paramètres optionnels.
