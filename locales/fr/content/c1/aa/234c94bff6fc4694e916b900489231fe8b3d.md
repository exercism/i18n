# À propos

Les [tuples][tuples] regroupent plusieurs valeurs en une seule valeur composée.
Contrairement aux tableaux, les valeurs d'un tuple ne sont pas forcément du même type, et la taille d'un tuple est fixe une fois celui-ci créé.

Pour créer un tuple, on place les valeurs entre parenthèses, séparées par des virgules :

```swift
let order = ("biscuits", 2.99, 3)
```

On peut aussi préciser explicitement les annotations de type :

```swift
let order: (String, Double, Int) = ("biscuits", 2.99, 3)
```

Pour extraire des éléments individuels d'un tuple non nommé, on utilise la syntaxe d'indice commençant à zéro (`.0`, `.1`, etc.) :

```swift
let item = order.0     // "biscuits"
let quantity = order.2 // 3
```

## Tuples nommés

On peut donner un nom aux différents éléments du tuple au moment de le définir :

```swift
let order = (item: "biscuits", price: 2.99, quantity: 3)
```

Nommer les éléments rend le code plus lisible et permet d'accéder aux éléments avec la notation pointée et leurs étiquettes :

```swift
let item = order.item         // "biscuits"
let quantity = order.quantity // 3
```

On peut aussi inclure le nom des éléments dans l'annotation de type :

```swift
let order: (item: String, price: Double, quantity: Int) = (item: "biscuits", price: 2.99, quantity: 3)
```

## Modifie un tuple

Si un tuple est déclaré comme variable (`var`), on peut modifier ses éléments :

```swift
var order = ("biscuits", 2.99, 3)
order.0 = "cookies"
order.1 = 1.99
order.2 = 5

print(order)
// Prints ("cookies", 1.99, 5)
```

## Renvoie plusieurs valeurs

En Swift, les fonctions ne peuvent renvoyer qu'une seule valeur, mais renvoyer un tuple permet de regrouper plusieurs valeurs et d'en [renvoyer plusieurs][multiple-return-values] depuis une fonction :

```swift
func divide(_ dividend: Int, by divisor: Int) -> (quotient: Int, remainder: Int) {
    let quotient = dividend / divisor
    let remainder = dividend % divisor
    return (quotient, remainder)
}

let result = divide(14, by: 4)
print("Quotient: \(result.quotient), Remainder: \(result.remainder)")
// Prints "Quotient: 3, Remainder: 2"
```

## Décomposition d'un tuple

On peut décomposer un tuple en séparant ses valeurs dans des constantes ou des variables distinctes :

```swift
let order = ("biscuits", 2.99, 3)
let (item, price, quantity) = order

print(item) // Prints "biscuits"
```

La décomposition de tuple fonctionne aussi directement dans les boucles `for-in` :

```swift
let orders = [("biscuits", 2.99, 3), ("cookies", 1.99, 5)]

for (item, price, quantity) in orders {
    print("Item: \(item), Price: \(price), Quantity: \(quantity)")
}
```
