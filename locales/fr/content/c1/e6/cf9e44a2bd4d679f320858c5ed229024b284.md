# Ajout aux instructions

## Format des entrées

Chaque liste d'entrées est représentée par une chaîne de caractères terminée par un caractère nul, avec un caractère de retour à la ligne à la fin de chaque entrée.

Un exemple serait `"nail\nshoe\nhorse\nrider\nmessage\nbattle\nkingdom\n"`

## Registres

| Registre | Utilisation   | Type    | Description                                                     |
| -------- | ------------- | ------- | --------------------------------------------------------------- |
| `$a0`    | entrée        | adresse | chaîne d'entrée terminée par un caractère nul, avec un retour à la ligne après chaque entrée |
| `$a1`    | entrée/sortie | adresse | chaîne de sortie terminée par un caractère nul                   |
| `$t0-9`  | temporaire    | quelconque | pour le stockage temporaire                                   |
