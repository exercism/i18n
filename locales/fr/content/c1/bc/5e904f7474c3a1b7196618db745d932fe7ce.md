# À propos

## Types de fonctions

On a déjà vu comment définir la signature d'une fonction : un nom de fonction, suivi d'une liste de libellés de paramètres séparés par des virgules avec leurs types, puis `->` et le type des valeurs renvoyées par la fonction.

Si on retire tous les noms et tous les libellés de cette signature, il ne reste que le [type de la fonction][function-types].

```swift
func shoppingList(item: String, quantity: Int) -> String {
  "You need to buy \(quantity) \(item)."
}
// shoppingList: (String, Int) -> String

func repeater(_ phrase: String, times: Int) -> String {
  var result = ""
  for _ in 1...times {
    result += phrase
  }
  return result
}
// repeater: (String, Int) -> String

func printString(line: String) {
  print(line)
}
// printString: (String) -> ()
```

Remarque que les types des deux premières fonctions sont identiques, `(String, Int) -> String`, bien que ces deux fonctions se comportent très différemment. Toutes les deux prennent une `String` et un `Int` en entrée et renvoient une `String`. Et, comme on peut le voir d'après le type de la troisième fonction, même si celle-ci ne semble rien renvoyer, elle renvoie en réalité `()`, l'unique valeur de type `Void`. Note que `()` et `Void` sont interchangeables comme noms de type, donc le type de `printString` pourrait aussi s'écrire `String) -> Void`.

Ces types s'utilisent de la même manière que n'importe quel autre type en Swift ; on peut par exemple les employer pour déclarer des variables ou des constantes. Et comme les fonctions sont des valeurs en Swift, on peut affecter des fonctions déjà existantes à ces constantes ou variables :

```swift
var stringAndIntToString: (String, Int) -> String

stringAndIntToString = shoppingList
stringAndIntToString("carrots", 3)
// => "You need to buy 3 carrots."

stringAndIntToString = repeater
stringAndIntToString("carrots", 3)
// => "carrotscarrotscarrots"
```

Comme pour les autres variables et constantes, la valeur qu'on y affecte doit être du bon type :

```swift
stringAndIntToString = printShoppingList
// Error: Cannot assign value of type '(String) -> ()' to type '(String, Int) -> String'
```

## Les types de fonctions comme types de paramètres

Comme les types de fonctions peuvent s'utiliser partout où d'autres types peuvent s'utiliser, il s'ensuit qu'[on peut les utiliser comme types de paramètres][functions-as-parameters], qu'on peut les passer à d'autres fonctions et les appeler depuis ces fonctions.

```swift
func apply3(to str: String, function f: (String, Int) -> String) -> String {
  f(str,3)
}
// apply3: ([String], (String, Int) -> String) -> [String]

apply3(to: "eggs", function: shoppingList)
// => "You need to buy 3 eggs."

apply3(to: "eggs", function: repeater)
// => "eggseggseggs"

func apply(functions fs: [(String, Int) -> String],
           to string: String,
          ) -> [String] {
  var result = [String]()
  for f in fs {
    result.append(f(string, 3))
  }
  return result

}
// apply: ([(String, Int) -> String], String) -> [String]


apply(functions: [shoppingList, repeater], to: "carrots")
// => ["You need to buy 3 carrots.", "carrotscarrotscarrots"]
```

## Les types de fonctions comme types de retour

De même, [les types de fonctions peuvent servir de types de retour][functions-as-returns] pour les fonctions. Autrement dit, on peut écrire des fonctions qui créent et renvoient d'autres fonctions. Quand on crée ces fonctions, la fonction renvoyée peut utiliser les autres paramètres passés à la fonction ou les variables locales créées à l'intérieur de la fonction parente.

```swift
func makeAdder(base: Int) -> (Int) -> Int {
  func adder(_ i: Int) -> Int {
    base + i
  }
  return adder
}
// makeAdder: (Int) -> (Int) -> Int

let add10 = makeAdder(base: 10)
// add10: (Int) -> Int

let subtract20 = makeAdder(base: -20)
// subtract10: (Int) -> Int

add10(5)
// => 15

subtract20(5)
// => -15
```

## Capture des valeurs

Comme on l'a vu avec la fonction `makeAdder(base:)` ci-dessus, les fonctions imbriquées peuvent accéder aux paramètres et aux variables de leurs fonctions englobantes. De plus, elles conservent l'accès à ces valeurs après la fin de la fonction englobante. Cette action, qui consiste à obtenir et à conserver cet accès, est appelée [_capture_][capturing-values].

## Fonctions d'ordre supérieur

Les fonctions qui prennent des fonctions en paramètres et/ou qui renvoient des fonctions sont appelées fonctions d'ordre supérieur. Swift dispose de nombreuses fonctions d'ordre supérieur dans ses diverses bibliothèques. Par exemple, la méthode `sorted(by:)` disponible sur les collections Swift comme `Array`, qui, pour un tableau dont les éléments sont de type `T`, prend une fonction de type `(T, T) -> Bool` déterminant laquelle de deux valeurs doit venir avant l'autre dans un tableau trié ; cette fonction renvoie `true` si la valeur de gauche doit apparaître en premier, et `false` si c'est celle de droite.

Un autre exemple est la méthode `contains(where:)` des collections qui, pour une collection dont les éléments sont de type `T`, prend une fonction de type `(T) -> Bool` ; celle-ci renvoie `true` si l'élément satisfait une certaine propriété et `false` sinon. `contains(where:)` renvoie alors `true` si un élément de la collection satisfait cette propriété.

```swift
func longer(_ strA: String, _ strB: String) -> Bool {
  strA.count > strB.count
}
// longer: (String, String) -> Bool

["apple", "ball", "carrot"].sorted(by: longer)
// => ["carrot", "apple", "ball"]

["apple", "ball", "carrot"].sorted(by: >)
// => ["carrot", "ball", "apple"]


func isBig(_ i: Int) -> Bool {
  i > 100
}
// isBig: (Int) -> Bool

func isVowel(_ char: Character) -> Bool {
  switch char.lowercased() {
  case "a", "e", "i", "o", "u": return true
  default: return false
  }
}
// isVowel: (Character) -> Bool

[1, 75, 3, 99].contains(where: isBig)
// => false

"Owl".contains(where: isVowel)
// => true

```
