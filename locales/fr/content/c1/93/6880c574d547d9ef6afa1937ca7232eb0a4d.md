# À propos

Une [fonction d'ordre supérieur](https://docs.microsoft.com/en-us/dotnet/fsharp/introduction-to-functional-programming/first-class-functions) est une fonction qui :

- Prend une fonction en argument
- Renvoie une fonction

Un argument de fonction n'est qu'un argument ordinaire, si ce n'est qu'on peut l'appeler.

```fsharp
let double = fun x -> x * 2

let apply f x = f x

apply double 3
// => 6
```
