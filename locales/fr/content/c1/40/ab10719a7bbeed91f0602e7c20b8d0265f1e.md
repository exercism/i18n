# Introduction

## Filtrage par motif

Une expression `if/elif/else` permet d'exécuter de la logique de façon conditionnelle. F# propose également une autre façon, plus puissante, d'exécuter de la logique de façon conditionnelle : le filtrage par motif. Avec le filtrage par motif, on peut tester une valeur par rapport à un ou plusieurs _motifs_. Un exemple d'un tel motif est le _motif constant_, qui compare une valeur à une constante (par exemple `1` ou `"hello"`).

En F#, le filtrage par motif se fait à l'aide du mot-clé `match` :

```fsharp
let describe number =
    match number with
    | 0 -> "Zero"
    | 1 -> "One"
```

Même si cela peut ressembler à des instructions `switch` dans d'autres langages, le filtrage par motif révèle tout son intérêt lorsqu'on utilise aussi d'autres motifs. L'un de ces motifs est le _motif de variable_, qui permet de capturer une valeur :

```fsharp
match number with
| 0 -> "Zero"
| i -> sprintf "Non zero: %d" i
```

Dans certains cas, tu peux vouloir ajouter une condition supplémentaire à un motif. C'est ce qu'on appelle une _garde_ (clause), que l'on peut ajouter à l'aide du mot-clé `when` :

```fsharp
match number with
| 0 -> "Zero"
| i when i < 0 -> "Negative number"
```

Dans l'exemple ci-dessus, il n'y a pas forcément de motif correspondant pour toutes les entrées possibles. Le compilateur le détecte et émet un avertissement. C'est ce qu'on appelle la _vérification d'exhaustivité_. Pour faire disparaître l'avertissement, il faut gérer tous les cas. Pour cela, on peut utiliser le _motif joker_, qui correspond à n'importe quelle valeur :

```fsharp
match number with
| i when i < 0 -> "Negative number"
| _ -> "Positive number"

// No compiler warning
```

Le filtrage par motif teste une valeur par rapport à chaque motif, de haut en bas, jusqu'à ce qu'il trouve un motif correspondant et exécute la logique associée à ce motif. L'ordre des motifs compte !
