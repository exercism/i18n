# Instructions

Dans cet exercice, tu vas traiter des lignes de _log_.

Chaque ligne de _log_ est une _string_ au format suivant : `"[<LVL>]: <MESSAGE>"`.

Voici les différents niveaux de _log_ :

- `TRC` (trace)
- `DBG` (debug)
- `INF` (info)
- `WRN` (avertissement)
- `ERR` (erreur)
- `FTL` (fatal)

Tu as trois tâches à réaliser.

## 1. Analyser le niveau de _log_

Définis une `enum` `LogLevel` qui compte six éléments correspondant aux niveaux de _log_ ci-dessus.

- `TRACE`
- `DEBUG`
- `INFO`
- `WARNING`
- `ERROR`
- `FATAL`

Ensuite, implémente la méthode `LogLine.getLogLevel()` qui renvoie le niveau de _log_ extrait d'une ligne de _log_ :

```java
var logLine = new LogLine("[INF]: File deleted");
logLine.getLogLevel();
// => LogLevel.INFO
```

## 2. Prendre en charge les niveaux de _log_ inconnus

Malheureusement, il arrive parfois que certaines lignes de _log_ aient un niveau inconnu.
Pour traiter correctement ces lignes de _log_, ajoute un élément `UNKNOWN` à l'`enum` `LogLevel`, qui devra être renvoyé lors de l'analyse d'un niveau de _log_ inconnu :

```java
var logLine = new LogLine("[XYZ]: Overly specific, out of context message");
logLine.getLogLevel();
// => LogLevel.UNKNOWN
```

## 3. Convertir une ligne de _log_ au format court

Le niveau de _log_ d'une ligne de _log_ est assez verbeux.
Pour réduire l'espace disque nécessaire pour stocker les lignes de _log_, on a mis au point un format court : `"[<ENCODED_LEVEL>]:<MESSAGE>"`.

Le niveau de _log_ encodé est une simple correspondance entre un niveau de _log_ et un nombre :

- `UNKNOWN` - `0`
- `TRACE` - `1`
- `DEBUG` - `2`
- `INFO` - `4`
- `WARNING` - `5`
- `ERROR` - `6`
- `FATAL` - `42`

Implémente la méthode `LogLine.getOutputForShortLog()` qui produit la ligne de _log_ au format raccourci :

```java
var logLine = new LogLine("[ERR]: Stack Overflow");
logLine.getOutputForShortLog();
// => "6:Stack Overflow"
```
