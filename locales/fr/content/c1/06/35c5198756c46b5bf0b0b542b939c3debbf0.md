# Instructions supplémentaires

## Le paquet de tri

Cet exercice te demande de trier un tableau, mais cette fonctionnalité n'est pas incluse dans la bibliothèque standard.
Tu pourrais écrire ta propre bibliothèque de tri, mais une meilleure option consiste à utiliser le [paquet sorts](https://github.com/diku-dk/sorts).

Tu peux utiliser ce paquet dans ta solution en exécutant la commande suivante dans le répertoire de la solution :

```shell
futhark pkg add github.com/diku-dk/sorts
futhark pkg sync
```

Ensuite, importe les [algorithmes de tri souhaités](https://github.com/diku-dk/sorts/tree/master/lib/github.com/diku-dk/sorts) via :

```futhark
import "lib/github.com/diku-dk/sorts/<sorting algorithm>"
```
