# Introduction

Le type union discriminée représente un nombre fixe de cas nommés. Chaque valeur d'une union discriminée correspond à exactement l'un de ces cas nommés.

Une union discriminée se définit à l'aide du mot-clé `type`, avec les cas séparés par des barres verticales (`|`) :

```fsharp
type Season =
    | Spring
    | Summer
    | Autumn
    | Winter
```

Chaque cas d'une union discriminée peut éventuellement avoir des données qui lui sont associées, et différents cas peuvent avoir des types de données différents. Si aucun des cas n'a de données associées, l'union discriminée s'apparente à ce que les autres langages appellent généralement une _énumération_ (ou _enum_).

```fsharp
type Number =
    | Integer of int
    | Float of float
    | Invalid
```

Pour créer une valeur pour un cas précis, il suffit de faire référence à son nom (par exemple `Success`). Comme les noms de cas sont de simples fonctions de construction, les données associées peuvent être passées comme un argument de fonction classique. Si une autre union discriminée a défini un cas du même nom, tu devras utiliser son nom complet (par exemple `Result.Success`).

```fsharp
let byName = Integer 2
let byFullName = Number.Invalid
```

Les unions discriminées ont une _égalité structurelle_, ce qui signifie que deux valeurs du même cas, avec les mêmes données (facultatives), sont équivalentes.

Même s'il est possible d'utiliser des expressions `if/elif/else` pour manipuler les unions discriminées, la méthode recommandée est le filtrage par motif à l'aide du _motif d'identifiant_ :

```fsharp
let describe number =
    match number with
    | Integer i -> sprintf "Integer: %d" i
    | Float d  -> sprintf "Float: %f" d
    | Invalid   -> "Invalid"
```
