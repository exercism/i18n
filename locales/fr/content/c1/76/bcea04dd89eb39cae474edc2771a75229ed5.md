# Ajout aux instructions

## Implémentation

Dans cet exercice, tu vas implémenter une procédure censée allouer la _string_ qu'elle renvoie. La libération de la _string_ incombe à l'appelant de la procédure.

```odin
// The procedure will be called like that:
converted := convert(3)
// ...
// and eventually the caller will delete the string
delete(converted)
```
