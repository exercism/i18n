# Représentations

Le [representer Python][representer] traite et normalise les solutions des apprenants pour les ramener à une forme plus « générique » :

- Le code est converti en AST à l'aide du [module AST de Python][python-ast].
- L'arbre AST final est converti en une _string_ sans espaces ni indentation, puis écrit dans `representation.txt`.
- Pour faciliter le dépannage, `representation.out` contient l'AST de départ, l'AST modifié et une représentation du code avec les normalisations appliquées.

- Suppressions :
    - les annotations de type (_y compris les annotations de type dans les dataclasses, voir Normalisations ci-dessous_)
    - les instructions `print()`
    - les blocs `if __name__ == __main__`
    -  les commentaires
    -  les docstrings

-  Remplacements :
    - les noms définis par l'utilisateur sont remplacés par des espaces réservés (_y compris les noms de fonctions, les paramètres et les variables dans les fonctions lambda_)

- Normalisations :
  - les guillemets simples `'` sont remplacés par des guillemets doubles `"` (_doublequotes_), sauf si des caractères d'échappement sont nécessaires, auquel cas ils restent inchangés.
  - les littéraux numériques voient leurs tirets bas supprimés et la notation scientifique est calculée en fonction de la position :
    - **66_777_888_433** --> 66777888433
    - **1_999_878_473.66** --> 1999878473.66
    - **77_555_998_125.445_779** --> 77555998125.44579
    - **44_573_123.445_312+123_674.889_12j** --> 44573123.445312 + 123674.88912j
    - **1e6** --> 1000000.0 #1000000
    -  **1e2+.23** --> 100.0 + 0.23 #100.23
    - **1e2+1_23e0+4.4e-1** --> 100.0 + 123.0 + 0.44 #223.44
    - **7e6+7e5+5e4+9.98e2+4.45_779e-1** -->7000000.0 + 700000.0 + 50000.0 + 998.0 + 0.445779 #7750998.445779
    - **(7e6+7e5+5e4+9.98e1+4.457_79e-1)+(1e2+1.23e1+4.444_23e-1)*1*j** --> (7000000.0 + 700000.0 + 50000.0 + 99.8 + 0.445779 + (100.0 + 12.3 + 0.444423) * 1j)  #7750100.245779+112.744423j
  - les fonctions et les classes dont le corps est vide après la suppression des docstrings se voient affecter `pass` comme corps.
  - les dataclasses dont des membres de données sont annotés mais non affectés reçoivent la valeur `None` pour ces membres. Voir la docstring qui commence à la ligne 153 de normalizer.py pour plus de détails.
