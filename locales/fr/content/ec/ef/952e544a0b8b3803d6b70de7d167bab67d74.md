# Instructions supplémentaires

## Format de sortie

Donne l'âge en centièmes d'année.

Par exemple, 100 × 1 000 000 000 ÷ 31 557 600 ≈ 3 169, donc quelqu'un âgé de 1 000 000 000 secondes a `3169` centièmes d'année terrestre.

## Registres

| Registre | Utilisation | Type       | Description                   |
| -------- | ----------- | ---------- | ----------------------------- |
| `$a0`    | entrée      | entier     | planète (`0` = Mercure, `1` = Vénus, `2` = Terre, `3` = Mars, `4` = Jupiter, `5` = Saturne, `6` = Uranus, `7` = Neptune) |
| `$a1`    | entrée      | entier     | secondes                      |
| `$v0`    | sortie      | entier     | âge en centièmes d'année      |
| `$t0-9`  | temporaire  | quelconque | utilisés pour le stockage temporaire |
