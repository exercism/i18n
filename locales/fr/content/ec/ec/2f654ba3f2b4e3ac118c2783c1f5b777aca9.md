# À propos

## Les types struct

Nous avons déjà vu les types struct ; pour rappel, une `struct` est une suite d'éléments nommés appelés _champs_, chaque champ ayant un nom et un type.
Le nom d'un champ doit être unique au sein de la `struct`.
On peut comparer les `Structs` à la _classe_ du paradigme de la programmation orientée objet.

Pour créer une nouvelle struct, on utilise les mots-clés `type` et `struct`, puis on définit explicitement le nom et le type des champs comme dans l'exemple ci-dessous.

```go
type StructName struct{
    field1 fieldType1
    field2 fieldType2
}
```

## Les types non-struct

Il est aussi possible de définir des types non-struct, que l'on peut utiliser comme alias pour des déclarations de types intégrés.

```go
type Name string
func SayHello(n Name) {
  fmt.Printf("Hello %s\n", n)
}
n := Name("Fred")
SayHello(n)
// Output: Hello Fred
```

Tu peux aussi définir des types non-struct composés de tableaux et de _maps_.

```go
type Names []string
func SayHello(n Names) {
  for _, name := range n {
    fmt.Printf("Hello %s\n", name)
  }
}
n := Names([]string{"Fred", "Bill"})
SayHello(n)
// Output:
// Hello Fred
// Hello Bill
```
