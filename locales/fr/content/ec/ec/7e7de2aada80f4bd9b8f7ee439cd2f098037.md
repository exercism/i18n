# Les nombres à virgule flottante

`INT` ne peut contenir que des nombres entiers, et diviser deux de ces nombres fait perdre le reste :

```sather
7 / 2        -- 3, not 3.5
```

Quand la fraction compte, il faut le type `FLTD`, un nombre **à virgule flottante**, qui peut contenir des valeurs entre les nombres entiers.

## Écris-en un

Un littéral à virgule flottante comporte un point décimal et un `d` à la fin.

```sather
   concert_a : FLTD is
      return 440.0d;
   end;
```

Le `d` n'est pas facultatif. `440.0` tout seul est d'un autre type, de moindre précision ; le `d` demande celui que ce parcours utilise partout.

Écris `2.0d`, pas `2d` : il faut aussi un point décimal.

## L'arithmétique

`+`, `-`, `*` et `/` fonctionnent tous, et `/` conserve désormais la fraction :

```sather
7.0d / 2.0d      -- 3.5
```

Les deux côtés doivent être de type `FLTD`. Sather ne mélange pas discrètement les deux types, donc `7 / 2.0d` provoque une erreur plutôt qu'une surprise.

## À partir d'un nombre entier

`.fltd` transforme un `INT` en `FLTD` :

```sather
   halve(n : INT) : FLTD is
      return n.fltd / 2.0d;
   end;
```

`halve(7)` vaut `3.5`. Remarque où se place la conversion : `(7 / 2).fltd` donnerait `3.0`, car la division aurait déjà perdu la moitié. Convertis **avant** de diviser, pas après.

## Quelle distance les sépare ?

`.abs` supprime le signe moins, ce qui permet de savoir de combien deux valeurs diffèrent sans se soucier de laquelle est la plus grande :

```sather
(440.0d - 442.0d).abs      -- 2.0
```
