# `break` et `continue`

Quand on utilise une structure de contrôle de boucle ou d'itération, les mots-clés `break` et `continue` aident à contrôler le déroulement d'un programme.
Le mot-clé `break` sort du contexte de la boucle pour rejoindre la portée extérieure, ce qui met fin à la boucle.
Le mot-clé `continue` saute le reste de l'itération en cours et reprend le contexte de la boucle au début de l'itération suivante.
Bien que cela soit peu courant, on peut fournir un nombre au mot-clé pour indiquer de combien de contextes il faut sortir, ou à quel niveau passer à l'itération suivante.

```php
<?php
$i = 1;
while ($i <= 10) {

    if ($i <= 5) {
        i += 1;
        continue;
    }
    break;
}
```

Dans l'exemple précédent, `continue` est exécuté cinq (5) fois, mais à la sixième (6) itération, `break` est exécuté, ce qui fait sortir le code de la boucle.
