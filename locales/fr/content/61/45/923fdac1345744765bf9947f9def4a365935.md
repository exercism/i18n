# À propos

MIPS est une architecture de jeu d'instructions de type RISC (ordinateur à jeu d'instructions réduit), aujourd'hui surtout utilisée dans les consoles de jeu vidéo et les routeurs. C'est aussi une architecture répandue dans les cours d'introduction et les manuels d'architecture des ordinateurs, en raison de sa simplicité par rapport à x86 et ARM. Ici, on utilise le jeu d'instructions 32 bits ; il existe aussi un jeu d'instructions 64 bits.

Ce parcours porte sur la programmation en langage d'assemblage MIPS, que l'on assemble et exécute sur un simulateur multiplateforme.
