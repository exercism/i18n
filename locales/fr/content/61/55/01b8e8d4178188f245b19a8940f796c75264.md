# Alias

La [forme spéciale `alias`][alias] permet de raccourcir ou de changer le nom sous lequel on fait référence à un module externe. On peut spécifier un nom personnalisé avec l'option `:as`.

```elixir
defmodule Square do
  alias Integer, as: I

  def area(a), do: I.pow(a, 2)
end
```

Utilisé sans argument, il réduit le nom du module à sa dernière partie, par exemple :

```elixir
alias MyApp.Account.User
# is the same as
alias MyApp.Account.User, as: User
```

Plusieurs alias peuvent être regroupés avec `{}` :

```elixir
alias MyApp.Account.{User, EmailValidation}
# is the same as
alias MyApp.Account.User
alias MyApp.Account.EmailValidation
```

En général, les alias sont ajoutés au début de la définition du module, mais ils peuvent l'être n'importe où. Ils ont une portée lexicale, ce qui signifie qu'un alias ajouté à l'intérieur d'une définition de fonction ne sera pas disponible dans une autre fonction.

Les alias inutilisés provoquent des avertissements du compilateur.

[alias]: https://hexdocs.pm/elixir/Kernel.SpecialForms.html#alias/2
