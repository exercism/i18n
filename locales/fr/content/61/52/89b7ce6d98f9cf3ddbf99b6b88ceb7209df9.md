# Introduction

## Attributs

Un [attribut `Attribute` du C#](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/attributes/) permet de décorer une déclaration afin d'y associer des métadonnées : une classe, une méthode, une énumération, un champ, une propriété ou toute [autre déclaration prise en charge](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/attributes/#attribute-targets).

On peut appliquer un attribut en l'ajoutant sur la ligne qui précède la déclaration, avec un `ClassAttribute` et un `FieldAttribute` :

```csharp
[Class]
class MyClass
{
    [Field]
    int myField;
}
```

Ces métadonnées déclaratives ne font qu'associer des informations structurées supplémentaires au code, sans modifier son comportement, mais elles sont utilisées par d'autres parties du code pour changer le comportement de leur cible, ou pour ajouter, modifier, supprimer ou restreindre certaines de ses fonctionnalités.

Il existe de nombreux [attributs prédéfinis et réservés](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/attributes/general#conditional-attribute), par exemple : `Flags`, `Obsolete`, `Conditional` et `Experimental`. Chacun a une signification sémantique précise, que l'on peut retrouver dans la documentation C#. À noter que le nom complet d'un attribut comme [`Flags`](https://docs.microsoft.com/en-us/dotnet/api/system.flagsattribute) prend la forme `<Name>Attribute` (par exemple `FlagsAttribute`).

## Énumérations de drapeaux

Le [type `enum` du C#](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/builtin-types/enum) représente un ensemble fixe de constantes nommées (une énumération).

Normalement, un membre d'une `enum` ne peut faire référence qu'à exactement une de ces constantes nommées. Cependant, il est parfois utile de faire référence à plusieurs constantes à la fois. Pour cela, on peut annoter l'`enum` avec l'[attribut `Flags`](https://docs.microsoft.com/en-us/dotnet/api/system.flagsattribute)

Une énumération de drapeaux peut se définir comme suit (avec la notation binaire des entiers `0b`) :

```csharp
[Flags]
enum PhoneFeatures
{
    Call = 0b00000001,
    Text = 0b00000010
}
```

Une instance de `PhoneFeatures` dont la valeur est `0b00000011` a ses deux drapeaux `Call` _et_ `Text` définis.

Par défaut, c'est le type `int` qui est utilisé pour les valeurs des membres de l'énumération. On peut utiliser un autre type entier en précisant le type dans la déclaration de l'énumération :

```csharp
[Flags]
enum PhoneFeatures : byte
{
    Call = 0b00000001,
    Text = 0b00000010
}
```
