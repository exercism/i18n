# Instructions

Mary est une grande fan de la série _Star Trek: The Next Generation_.
Elle joue souvent à des jeux de rôle papier, où elle et ses amis se font passer pour l'équipage du _Starship Enterprise_.
Le personnage de Mary est le capitaine Picard, ce qui signifie qu'elle doit tenir le journal de bord du capitaine.
Elle adore la part créative du jeu, mais n'aime pas devoir générer des données aléatoires à la volée.

Aide Mary en créant des générateurs aléatoires pour les données qui apparaissent couramment dans le journal de bord.

~~~~exercism/note
L'implémentation de départ de cet exercice prend une instance de `java.util.Random` comme argument de constructeur.
Cela permet aux tests de l'exercice de passer une instance avec une graine prédéfinie, ce qui rend les résultats des tests prévisibles.

Par conséquent, on attend de toi que tu utilises l'instance de `java.util.Random` fournie dans ton implémentation.
~~~~

## 1. Génère une planète aléatoire

Le _Starship Enterprise_ rencontre de nombreuses planètes au cours de ses voyages.
Dans l'univers de Star Trek, les planètes sont réparties en catégories selon leurs propriétés.
Par exemple, la Terre est une planète de classe `M`.
Toutes les classes planétaires possibles sont : `D`, `H`, `J`, `K`, `L`, `M`, `N`, `R`, `T` et `Y`.

Implémente la méthode `randomPlanetClass()`.
Elle doit renvoyer l'une des classes planétaires au hasard.

```java
captainsLog.randomPlanetClass();
// => "K"
```

## 2. Génère un numéro d'immatriculation de vaisseau aléatoire

L'Enterprise (numéro d'immatriculation `NCC-1701`) n'est pas le seul vaisseau à parcourir l'espace !
Quand il croise un autre vaisseau, Mary doit consigner le numéro d'immatriculation de ce vaisseau.

Les numéros d'immatriculation commencent par le préfixe « NCC- » puis utilisent un nombre compris entre `1000` et `9999` (inclus).

Implémente la méthode `randomShipRegistryNumber()` qui renvoie un numéro d'immatriculation de vaisseau aléatoire.

```java
captainsLog.randomShipRegistryNumber();
// => "NCC-1947"
```

## 3. Génère une date stellaire aléatoire

À quoi bon tenir un journal s'il ne contient pas de dates ?

Une date stellaire est un nombre à virgule flottante.
Les aventures du _Starship Enterprise_ de la première saison de _The Next Generation_ se déroulent entre les dates stellaires `41000.0` et `42000.0`.
Le « 4 » correspond au 24e siècle, le « 1 » à la première saison.

Implémente la méthode `randomStardate()` qui renvoie un nombre à virgule flottante compris entre `41000.0` (inclus) et `42000.0` (exclu).

```java
captainsLog.randomStardate();
// => 41458.15721310934
```
