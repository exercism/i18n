# Instructions

Pendant que tu travailles chez _Instruments of Texas_, ta mission est de travailler sur une calculatrice expérimentale écrite en C#. Tu construis un banc de test pour vérifier un certain nombre de fonctions de la calculatrice, en commençant par la multiplication. Tu verras qu'une attention particulière est portée au cas où les deux opérandes de la multiplication sont négatifs.

La classe `Calculator` t'est fournie et ne doit pas être modifiée.

## 1. Complète la définition de l'exception définie par l'utilisateur `CalculationException`

Complète la définition du constructeur de `CalculationException`, qui devra stocker (encapsuler) toute exception levée par la calculatrice ainsi que les opérandes en cours de traitement au moment où l'exception est levée.

## 2. Gère les cas de dépassement de capacité dans la calculatrice et fournis des informations plus riches à l'appelant

Implémente la méthode `CalculatorTestHarness.Multiply()`, qui doit appeler la méthode `Calculator.Multiply()` de l'instance de `Calculator` passée au constructeur, en lui passant les valeurs entières x et y. Si un dépassement de capacité se produit dans la méthode `Calculator.Multiply()`, celle-ci lève une `OverflowException`. Cette exception doit être interceptée dans la méthode `CalculatorTestHarness.Multiply()` et encapsulée dans une `CalculationException`, et les valeurs x et y transmises doivent être stockées comme opérandes de l'exception. L'objet `CalculationException` nouvellement créé doit être levé. Tu peux ignorer la valeur renvoyée par la méthode `Calculator.Multiply()` si celle-ci réussit.

```csharp
var cth = new CalculatorTestHarness(new Calculator());
cth.Multiply(Int32.MaxValue, Int32.MaxValue);
// => throws an instance of CalculationException

var cth2 = new CalculatorTestHarness(new Calculator());
cth2.Multiply(3, 2);
// => silently exits
```

## 3. Teste l'opération de multiplication pour des entrées valides

Implémente la méthode `CalculatorTestHarness.TestMultiplication()`, qui prend deux entiers et appelle la méthode `CalculatorTestHarness.Multiply()`. C'est `"Multiply succeeded"` qui est renvoyé.

```csharp
var cth = new CalculatorTestHarness(new Calculator());
cth.TestMultiplication(6, 7);
// => "Multiply succeeded"
```

## 4. Teste l'opération de multiplication pour des entrées négatives

Modifie la méthode `CalculatorTestHarness.TestMultiplication()` pour que `"Multiply failed for negative operands. <INNER_EXCEPTION_MESSAGE>"` soit renvoyé si les deux arguments entiers sont négatifs (inférieurs à zéro).

L'espace réservé `<INNER_EXCEPTION_MESSAGE>` doit être remplacé par le message de l'exception interne de la `CalculationException`.

```csharp
var cth = new CalculatorTestHarness(new Calculator());
cth.TestMultiplication(-2, -Int32.MaxValue);
// => "Multiply failed for negative operands. " + innerException.Message
```

## 5. Teste l'opération de multiplication pour des entrées positives

Modifie la méthode `CalculatorTestHarness.TestMultiplication()` pour que `"Multiply failed for mixed or positive operands. <INNER_EXCEPTION_MESSAGE>"` soit renvoyé si au moins un des arguments entiers n'est pas négatif.

L'espace réservé `<INNER_EXCEPTION_MESSAGE>` doit être remplacé par le message de l'exception interne de la `CalculationException`.

```csharp
var cth = new CalculatorTestHarness(new Calculator());
cth.TestMultiplication(Int32.MaxValue, Int32.MaxValue);
// => "Multiply failed for mixed or positive operands. " + innerException.Message
```
