# À propos

De nombreux [types de membres de *struct* et de classe][expression-bodied-members] (les champs étant la principale exception) peuvent utiliser la syntaxe des membres *expression-bodied*. Définir un membre à l'aide d'une expression produit souvent un code plus concis et plus lisible que les blocs ou instructions traditionnels.

```csharp
public int Times3(int input) => input * 3;

public int Interesting => 1729;
```

Les membres *expression-bodied* ne peuvent pas contenir de blocs de plusieurs instructions, mais si tu as un bagage en programmation fonctionnelle, sache que tout ce qu'un membre traditionnel peut faire peut être réalisé avec l'un de ces membres. L'« expression » peut être une opération d'affectation qui crée des effets de bord, ou un appel de méthode, ce qui signifie que tout est possible.

[expression-bodied-members]: https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/statements-expressions-operators/expression-bodied-members
