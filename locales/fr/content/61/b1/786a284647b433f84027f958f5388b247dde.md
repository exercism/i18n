# Introduction

Un _type énuméré_ est un type de données particulier qui permet à une variable de prendre une valeur parmi un ensemble de constantes prédéfinies.
La variable doit être égale à l'une des valeurs prédéfinies pour ce type.
Les exemples courants incluent les points cardinaux (les valeurs `NORTH`, `SOUTH`, `EAST` et `WEST`) et les jours de la semaine.

Comme ce sont des constantes, les noms des champs d'un type énuméré s'écrivent en lettres majuscules.

## Définis un type énuméré

En Java, on définit un type énuméré à l'aide du mot-clé `enum`.
Par exemple, on écrirait un type énuméré pour les jours de la semaine comme ceci :

```java
public enum DayOfWeek {
    SUNDAY,
    MONDAY,
    TUESDAY,
    WEDNESDAY,
    THURSDAY,
    FRIDAY,
    SATURDAY
}
```

On utilise un type énuméré chaque fois que l'on doit représenter un ensemble fixe de constantes.
Cela inclut les énumérations naturelles, comme les planètes de notre système solaire, ainsi que les ensembles de données dont on connaît toutes les valeurs possibles à la compilation : par exemple les choix d'un menu, les options en ligne de commande, et ainsi de suite.

## Utilise un type énuméré

Voici du code qui montre comment utiliser le type énuméré `DayOfWeek` défini plus haut :

```java
public class Shop {
    public String getOpeningHours(DayOfWeek dayOfWeek) {
        switch (dayOfWeek) {
            case MONDAY:
            case TUESDAY:
            case WEDNESDAY:
            case THURSDAY:
            case FRIDAY:
                return "9am - 5pm";
            case SATURDAY:
                return "10am - 4pm"
            case SUNDAY:
                return "Closed.";
        }
    }
}
```

```java
var shop = new Shop();
shop.getOpeningHours(DayOfWeek.WEDNESDAY);
// => "9am - 5pm"
```

## Ajoute des méthodes et des champs

Les types énumérés de Java sont bien plus puissants que leurs équivalents dans les autres langages.
La déclaration `enum` définit une _classe_ (appelée _type énuméré_).
Le corps de la classe énumérée peut contenir des méthodes et d'autres champs :

```java
public enum Rating {
    GREAT(5),
    GOOD(4),
    OK(3),
    BAD(2),
    TERRIBLE(1);

    private final int numberOfStars;

    Rating(int numberOfStars) {
        this.numberOfStars = numberOfStars;
    }

    public int getNumberOfStars() {
        return this.numberOfStars;
    }
}
```

Appeler la méthode `getNumberOfStars` sur un membre du type énuméré `Rating` :

```java
Rating.GOOD.getNumberOfStars();
// => 4
```
