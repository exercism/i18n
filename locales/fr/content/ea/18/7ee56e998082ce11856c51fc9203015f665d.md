# Debug

Pour t'aider à déboguer, tu peux utiliser [`print` ou des fonctions similaires][cl-print] pour écrire sur la sortie standard, qui sera visible dans la sortie des tests.

Par exemple, ajouter `(print "hello there")` dans la fonction que tu es en train d'écrire fera apparaître ce texte lors des exécutions des tests (à condition que le test exécute cette fonction).

Une « astuce » : si tu as plusieurs choses à afficher, rassemble-les dans un tableau puis affiche ce tableau : `(print (list :this "that" 'the-other))`.

[cl-print]: http://www.lispworks.com/documentation/HyperSpec/Body/f_wr_pr.htm
