# Instructions

Mecha Munch™, une entreprise d'automatisation des courses alimentaires, vient de t'embaucher pour travailler sur son application de commande.
Ton équipe a pour mission de construire un MVP (_[produit minimum viable][mvp]_) qui gère toutes les activités de base du panier d'achat, ce qui permet aux utilisateurs d'ajouter, de supprimer et de trier leurs commandes de courses.
Heureusement, une autre équipe s'occupe de tout ce qui touche à l'argent et au paiement !

## 1. Ajoute des articles au panier d'achat de l'utilisateur

Le MVP doit permettre à l'utilisateur d'ajouter des articles à son panier d'achat.
Il peut s'agir d'un seul article ou de plusieurs articles à la fois.
Comme il s'agit d'un MVP, la quantité d'un article est indiquée par des _répétitions_.
Si un utilisateur veut ajouter 2 Oranges, « Oranges » apparaîtra deux fois dans l'itérable d'entrée.
Si l'utilisateur a déjà cet article dans son panier, la quantité correspondante du panier doit être augmentée de 1.
Si l'article est _nouveau_ dans le panier, il doit y être ajouté avec une quantité de 1.

Crée la fonction `add_items!(<cart>, <items>)` qui prend en arguments un dictionnaire représentant le panier et un itérable d'articles à ajouter.
Elle doit renvoyer le dictionnaire du panier d'achat mis à jour pour l'utilisateur.

```julia-repl
julia> additems!(Dict("Banana" => 3, "Apple" => 2, "Orange" => 1),
                 ("Apple", "Apple", "Orange", "Apple", "Banana"))
Dict{String, Int64} with 3 entries:
  "Apple"  => 5
  "Orange" => 2
  "Banana" => 4

julia> additems!(Dict("Banana" => 3, "Apple" => 2, "Orange" => 1),
                 ["Banana", "Orange", "Blueberries", "Banana"])
Dict{String, Int64} with 4 entries:
  "Blueberries" => 1
  "Apple"       => 2
  "Orange"      => 2
  "Banana"      => 5
```

## 2. Mets à jour la section « idées » des recettes

L'application dispose d'une section « idées » remplie de recettes toutes prêtes issues de diverses cuisines.
L'utilisateur peut sélectionner l'une de ces recettes et faire ajouter automatiquement tous ses ingrédients à son panier d'achat.
Le chef de projet t'a demandé de créer un moyen de modifier ces recettes « idées », car l'équipe de contenu ne cesse de changer les ingrédients et les quantités.

Crée la fonction `update_recipes!(<ideas>, <updates>)` qui prend en arguments un dictionnaire « idées » et un dictionnaire de mises à jour de recettes.

## 3. Envoie le panier d'achat de l'utilisateur au magasin pour la préparation des commandes

L'application doit envoyer le panier d'un utilisateur donné au magasin pour qu'il soit préparé.
Cependant, les préparateurs du magasin ont besoin de savoir où trouver chaque article grâce à un code de rayon unique.
Le « panier de préparation » doit être trié selon les codes de rayon des articles, afin d'aider les préparateurs à être plus efficaces.

Crée la fonction `send_to_store(<cart>, <aislecodes>)` qui prend un panier d'achat d'utilisateur et un dictionnaire contenant les numéros de rayon du magasin.
La fonction doit renvoyer un « panier de préparation » combiné, contenant une paire `aislecode => quantity` pour chaque article commandé par le client.
Les articles doivent apparaître dans l'ordre de leurs codes de rayon.

```julia-repl
julia> cart = Dict("Orange" => 1, "Milk" => 2, "Banana" => 3, "Apple" => 2, "Chocolate" => 2);

julia> aislecodes = Dict("Orange" => 2.4, "Milk" => 3.3, "Banana" => 2.6, "Apple" => 2.2, "Chocolate" => 5.7);

julia> send_to_store(cart, aislecodes)
5-element Vector{Pair{Float64, Int64}}:
 2.2 => 2
 2.4 => 1
 2.6 => 3
 3.3 => 2
 5.7 => 2
```

## 4. Mets à jour l'inventaire du magasin pour refléter ce qu'un utilisateur a commandé

L'application ne peut pas se contenter d'enregistrer sans fin les commandes des clients.
Au bout d'un moment, le magasin va finir par être à court de divers produits.
Ton MVP doit donc mettre à jour l'inventaire du magasin chaque fois qu'un utilisateur envoie sa commande.
Sinon, les clients commanderont des produits qui ne sont en réalité pas disponibles.

Crée la fonction `update_store_inventory!(<inventory>, <cart>)` qui prend un `cart` et un `inventory`.
La fonction doit réduire les quantités de l'inventaire du magasin du nombre « commandé » dans le `cart`, puis renvoyer un dictionnaire des articles en rupture de stock (c'est-à-dire ceux qui ont atteint `0`).

```julia-repl
julia> inventory = Dict("Banana" => 15, "Apple" => 12, "Orange" => 1, "Milk" => 4);

julia> cart = Dict("Orange" => 1, "Milk" => 2, "Banana" => 3, "Apple" => 2);

julia> update_store_inventory!(inventory, cart)
Dict{String, Int64} with 1 entry:
  "Orange" => 0

julia> inventory
Dict{String, Int64} with 4 entries:
  "Milk"   => 2
  "Apple"  => 10
  "Orange" => 0
  "Banana" => 12
```

## 5. Réapprovisionne les articles en rupture de stock

Au-delà de la mise à jour de l'inventaire, ton application peut aussi aider à le réapprovisionner.
Ton MVP doit pouvoir préparer une mini-commande des articles en rupture de stock après la commande d'un client.
Cela permettra de déclencher plus facilement une commande importante.
De plus, il arrive que des articles promotionnels à durée limitée ne figurent pas dans la liste de stock.
Si ces articles sont épuisés avant la fin de la période promotionnelle, c'est qu'ils ont rencontré du succès et ils peuvent être ajoutés à la liste de stock.

Crée la fonction `reorder!(<outofstock>, <stock>)` qui prend `outofstock` et `stock`.
Le dictionnaire `stock` contient les articles standards du stock et leurs quantités de réapprovisionnement.
Le dictionnaire `outofstock` est le résultat de `update_store_inventory!`, à savoir un dictionnaire des articles dont la quantité est nulle.
Les quantités de `outofstock` doivent être mises à jour pour refléter celles de `stock`, puis renvoyées.
De plus, les articles présents dans `outofstock` mais absents de `stock` doivent être ajoutés à `stock` avec une quantité par défaut de `100`.

```julia-repl
julia> inventory = Dict("Banana" => 15, "Apple" => 12, "Orange" => 1, "Milk" => 4, "Chocolate" => 2);

julia> cart = Dict("Orange" => 1, "Milk" => 2, "Banana" => 3, "Apple" => 2, "Chocolate" => 2);

julia> stock = Dict("Banana" => 150, "Apple" => 120, "Orange" => 120, "Milk" => 45);

julia> outofstock = update_store_inventory!(inventory, cart)
Dict{String, Int64} with 1 entry:
  "Orange"    => 0
  "Chocolate" => 0

julia> reorder!(outofstock, stock)
Dict{String, Int64} with 1 entry:
  "Orange"    => 120
  "Chocolate" => 100

julia> stock 
Dict{String, Int64} with 5 entries:
  "Milk"      => 45
  "Apple"     => 120
  "Chocolate" => 100
  "Orange"    => 120
  "Banana"    => 150
```
