# Instructions complémentaires

## Structure du projet

Les exercices Clojure d'Exercism prennent en charge les deux outils les plus courants pour la gestion des dépendances et les tests, [Leiningen][leiningen] et la [CLI Clojure][clojure-cli].

Tu trouveras un fichier de test nommé `hello_world_test.clj` dans le répertoire `test`.
Écris ton code dans `src/hello_world.clj`. Il doit utiliser l'espace de noms `hello-world` pour que les tests puissent le trouver.

### Exécute les tests avec la CLI Clojure

```
$ clj -X:test
```

### Exécute les tests avec Leiningen

```
$ lein test

lein test hello-world-test

Ran 3 tests containing 3 assertions.
0 failures, 0 errors.
```

Ensuite, soumets l'exercice avec :

```
$ exercism submit src/hello_world.clj
```

Pour des instructions plus détaillées et des ressources d'apprentissage, consulte [la page du langage Clojure d'Exercism][exercism-clojure].

[leiningen]: https://leiningen.org
[clojure-cli]: https://clojure.org/guides/deps_and_cli
[exercism-clojure]: https://exercism.org/tracks/clojure
