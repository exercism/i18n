# Introduction

Une instruction `switch` évalue une expression et exécute le premier `case` qui correspond à sa valeur.
C'est souvent une alternative plus propre aux longues successions de `if ... else if`.
Par exemple :

```go
operatingSystem := "windows"

if operatingSystem == "windows" {
    // do something if the operating system is windows
} else if operatingSystem == "linux" {
    // do something if the operating system is linux
} else if operatingSystem == "macos" {
    // do something if the operating system is macos
} else {
    // do something if the operating system is none of the above
}
```

peut être réécrit ainsi :

```go
operatingSystem := "windows"

switch operatingSystem {
case "windows":
    // do something if the operating system is windows
case "linux":
    // do something if the operating system is linux
case "macos":
    // do something if the operating system is macos
default:
    // do something if the operating system is none of the above
}
```

Plusieurs valeurs peuvent être regroupées dans un même `case`, séparées par une virgule.
Ce cas correspondra si l'expression est égale à l'une de ces valeurs :

```go
switch operatingSystem {
case "windows", "linux":
    // do something if the operating system is windows or linux
case "macos":
    // do something if the operating system is macos
default:
    // do something if the operating system is none of the above
}
```

L'expression après `switch` peut aussi être entièrement omise.
Chaque `case` contient alors une expression booléenne, et le premier cas dont l'expression est vraie est exécuté.

```go
age := 21

switch {
case age > 20 && age < 30:
    // do something if age is between 20 and 30
case age == 10:
    // do something if age is equal to 10
default:
    // do something else for every other case
}
```
