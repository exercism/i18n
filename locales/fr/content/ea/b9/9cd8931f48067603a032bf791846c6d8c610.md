## Développement piloté par les tests

 Pense à regarder les commentaires en haut du fichier de tests.
 Ils t'aideront à comprendre la sortie attendue de ta fonction.

Ce défi _pourrait_ être résolu avec un minimum de code et beaucoup de texte « en dur », c'est-à-dire des valeurs fixes écrites directement dans le code plutôt que des données que l'on peut modifier, dupliqué d'un couplet à l'autre.
Toutefois, cette chanson est un type de [chanson cumulative][cumulative song], où chaque nouveau couplet s'appuie sur le couplet qui le précède.
Pour un défi de programmation plus relevé, essaie d'assembler chaque couplet à partir de ses éléments.
Par exemple, dans chaque couplet, le jour change et le cadeau change, et le reste du couplet est à peu près identique.
Quelle pourrait bien être une bonne stratégie pour éviter les répétitions ?

[cumulative song]: https://en.wikipedia.org/wiki/Cumulative_song
