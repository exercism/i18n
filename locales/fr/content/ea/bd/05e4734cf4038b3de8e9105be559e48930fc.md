# Astuces

## Général

- Le [tutoriel sur les chaînes de caractères][python-str-doc] de la documentation Python donne un aperçu du type `str` de Python.
- Les méthodes de _string_ [`str.join()`][str-join] et [`str.split()`][str-split] sont très utiles pour traiter des _strings_.
- La documentation Python sur les [types de séquences][common sequence operations] donne un tour d'horizon des opérations communes à toutes les séquences, notamment `strings`, `lists`, `tuples` et `ranges`.

Il y a quatre activités dans l'exercice, chacune avec un ensemble de texte ou de mots avec lesquels travailler.

## 1. Ajoute un préfixe à un mot

- Les petites _strings_ peuvent être concaténées avec l'opérateur `+`.

## 2. Ajoute des préfixes à des groupes de mots

- Crois-le ou non, [`str.join()`][str-join] est tout ce dont tu as besoin ici. **Une boucle n'est pas nécessaire**.
- Les tests vont fournir à ta fonction une `list`. Il ne sera pas nécessaire de modifier cette `list` si tu arrives à trouver une bonne _string_ de délimitation.
- Rappelle-toi que les _strings_ de délimitation se placent entre les éléments et les relient pour former une seule _string_. Les délimiteurs sont insérés _sans_ espace, même si tu peux inclure des espaces à l'intérieur.
- Comme [`str.split()`][str-split], `str.join()` peut traiter une _string_ de longueur arbitraire, composée de n'importe quels points de code Unicode. _Contrairement à_ `str.split()`, il peut aussi traiter des itérables de longueur arbitraire comme `list`, `tuple` et `set`.

## 3. Retire un suffixe d'un mot

- Les _strings_ peuvent être indexées ou découpées depuis la gauche (en partant de 0) ou depuis la droite (en partant de -1).
- Si tu veux le dernier point de code d'une _string_ de longueur arbitraire, tu peux utiliser `[-1]`.
- Les trois dernières lettres d'une _string_ peuvent être « découpées » à l'aide d'un indice négatif. Par exemple, `beautiful'[:-3] == 'beauti`

## 4. Extrais et transforme un mot

- Utiliser [`str.split()`][str-split] renvoie une `list` de _strings_ découpées sur les espaces blancs.
- Les `lists` sont des séquences et peuvent être indexées.
- On peut indexer directement [`str.split()`][str-split] : `'Exercism rocks!'.split()[0] == 'Exercism'`
- Fais attention à la ponctuation ! Les points peuvent être retirés avec une tranche : `'dark.'[:-1] == 'dark'`
