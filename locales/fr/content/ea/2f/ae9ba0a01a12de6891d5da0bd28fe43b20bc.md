# Instructions

Dans cet exercice, tu vas écrire du code pour imprimer des badges nominatifs pour les employés d'une usine.

## 1. Imprime un badge pour un employé

Les employés ont un identifiant, un nom et un service. Les libellés des badges des employés sont au format suivant : `"[id] - name - DEPARTMENT"`.
Implémente la méthode `Badge.print()` pour renvoyer le libellé du badge d'un employé :

```java
Badge badge = new Badge();
badge.print(734, "Ernest Johnny Payne", "Strategic Communication");
// => "[734] - Ernest Johnny Payne - STRATEGIC COMMUNICATION"
```

Note que le service doit être écrit en majuscules sur le libellé.

## 2. Imprime un badge pour un nouvel employé

À cause d'une bizarrerie du système informatique, les nouveaux employés n'ont parfois pas encore d'identifiant lorsqu'ils commencent à travailler à l'usine.
Comme les badges sont obligatoires, ils reçoivent un badge temporaire sans le préfixe d'identifiant. Modifie la méthode `Badge.print()` pour prendre en charge les nouveaux employés qui n'ont pas encore d'identifiant :

```java
Badge badge = new Badge();
Badge.print(null, "Jane Johnson", "Procurement");
// => "Jane Johnson - PROCUREMENT"
```

## 3. Imprime un badge pour le propriétaire

Même le propriétaire de l'usine doit porter un badge en permanence.
Cependant, un propriétaire n'a pas de service. Dans ce cas, le libellé doit afficher `"OWNER"` à la place du nom du service.
Modifie la méthode `Badge.print()` pour afficher un libellé pour le propriétaire :

```java
Badge badge = new Badge();
badge.print(254, "Charlotte Hale", null);
// => "[254] - Charlotte Hale - OWNER"
```

Note qu'il est possible que le propriétaire soit aussi un nouvel employé :

```java
Badge badge = new Badge();
badge.print(null, "Charlotte Hale", null);
// => "Charlotte Hale - OWNER"
```
