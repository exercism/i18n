# Annexe aux instructions

## Comment cet exercice est structuré en Python


Python offre une multitude de fonctions mathématiques, que ce soit dans le [module math][math-module] ou parmi les fonctions natives comme l'opérateur d'exponentiation `**`, [`pow()`][pow] et [`sum()`][sum].
Cependant, on t'invite à relever le défi de résoudre cet exercice sans ces fonctions natives ni ces modules.

Bien qu'il existe une formule mathématique permettant de trouver la racine carrée de _n'importe quel_ nombre, nous avons choisi de ne considérer que les [nombres entiers naturels][nautral-number] (les entiers positifs) comme solutions.  
Il est possible de calculer la racine carrée de n'importe quel nombre entier naturel en n'utilisant que des nombres entiers naturels dans le calcul.
