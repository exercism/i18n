# Introduction

[Go](https://golang.org) est un langage de programmation compilé et à typage statique.
Cet exercice présente trois grandes notions du langage : les paquets, les fonctions et les variables.

## Paquets

Les applications Go sont organisées en paquets.
Un paquet est un ensemble de fichiers sources situés dans le même répertoire.
Tous les fichiers sources d'un répertoire doivent partager le même nom de paquet.
Quand un paquet est importé, seules les entités (fonctions, types, variables, constantes) dont le nom commence par une lettre majuscule peuvent être utilisées ou accessibles.
Le style de nommage recommandé en Go consiste à nommer les identifiants en `camelCase`, sauf ceux destinés à être accessibles depuis d'autres paquets, qui doivent être en `PascalCase`.

```go
package lasagna
```

## Variables

Go est à typage statique, ce qui signifie que toutes les variables [doivent avoir un type défini](https://en.wikipedia.org/wiki/Type_system) à la compilation.

On peut définir une variable en spécifiant explicitement un type :

```go
var explicit int // Explicitly typed
```

On peut aussi utiliser un initialiseur, et le compilateur attribuera à la variable le type correspondant à celui de l'initialiseur.

```go
implicit := 10   // Implicitly typed as an int
```

Une fois déclarée, une variable peut recevoir des valeurs à l'aide de l'opérateur `=`.
Une fois déclarée, le type d'une variable ne peut plus jamais changer.

```go
count := 1 // Assign initial value
count = 2  // Update to new value

count = false // This throws a compiler error due to assigning a non `int` type
```

## Constantes

Une constante contient une donnée, exactement comme une variable, mais sa valeur ne peut pas changer pendant l'exécution du programme.

Les constantes se définissent avec le mot-clé `const` et peuvent être des nombres, des caractères, des _strings_ ou des booléens :

```go
const Age = 21 // Defines a numeric constant 'Age' with the value of 21
```

## Fonctions

Les fonctions Go acceptent zéro ou plusieurs paramètres.
Le type des paramètres doit être indiqué explicitement, il n'y a pas d'inférence de type.

Les valeurs sont renvoyées par une fonction à l'aide du mot-clé `return`.

Pour appeler une fonction, on indique son nom et on passe un argument pour chacun de ses paramètres.

À noter que Go prend en charge deux types de commentaires.
Les commentaires sur une seule ligne sont précédés de `//` et les commentaires multilignes sont insérés entre `/*` et `*/`.

```go
package greeting

// Hello is a public function.
func Hello (name string) string {
    return hi(name)
}

// hi is a private function.
func hi (name string) string {
    return "hi " + name
}
```
