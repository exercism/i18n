# Introduction

## Instructions conditionnelles

Les instructions conditionnelles sont des instructions de prise de décision : elles peuvent soit exécuter des effets de bord, soit contrôler le déroulement de l'exécution d'un programme.
Les instructions conditionnelles incluent les instructions `if`, `if/else`, `switch` et `ternary`.

On utilise les instructions conditionnelles pour poser des questions sur une valeur ou sur une relation entre plusieurs valeurs.
La question s'évalue en une réponse booléenne, mais l'instruction `if` elle-même peut renvoyer n'importe quelle valeur ou simplement exécuter un effet de bord.

## Les instructions `if`

L'instruction `if` la plus simple évalue une expression et exécute une seule ligne.
L'expression testée est toujours placée entre parenthèses.

Elle peut exécuter un effet de bord

```c
if (count > 10)
    printf("count is greater than 10");
```

ou modifier le déroulement de l'exécution


```c
if (count > 10)
    return sum;
```

Si une instruction `if` exécute plus d'une ligne, elle doit placer ces lignes entre accolades

```c
if (count > 10) {
    printf("count is greater than 10");
    return sum;
}
```

Certaines équipes de développement peuvent imposer que les instructions `if` utilisent toujours des accolades, même pour une seule ligne.


## `if` et `else`

Une instruction `if` peut être associée à un `else`

```c
if (number % 2 == 0)
    return "even";
else
    return "odd";
```

## `if` et `else if`


On peut associer `else` à un autre `if` pour créer ce qu'on appelle une `if-else-if ladder`.

```c
if (number == 0)
    return "zero";
else if (number < 0)
    return "negative";
else if (number < 10)
    return "single digit";   
else if (number % 2 == 0)
    return "even";
else
    return "odd";
```

## `switch`


Parfois, une `if-else-if ladder` peut être mieux représentée par un `switch`.
Comme pour `if`, l'expression testée est toujours placée entre parenthèses.

```c
switch (number) {
    case -1:
        return "negative one";
    case 0:
        return "zero";
    case 1:
        return "positive one";
    case 10:
        return "positive ten";
    case -10:
        return "negative ten";
    default:
        return "don't care";
}
```

Le cas `default` s'exécute si la valeur testée ne correspond à aucun des cas précédents.

Si un cas d'un `switch` ne fait pas de `return`, on insère généralement un `break` pour terminer chaque cas, sinon la logique « tombe » dans le cas suivant.
Il arrive que cette chute soit intentionnelle

```c
switch (number) {
    case 0:
        msg = "zero"; break;
    case 1:
        msg = "one"; break;
    case 2: case 3: case 4:
        msg = "more than one and less than five"; break;
    default:
        msg = "don't care";
}
```

Quand cette chute se produit involontairement, c'est un bug.

```c
switch (number) {
    case 0:
        msg = "zero"; // bug! fallthrough of 0 will set msg to "one"
    case 1:
        msg = "one"; break; 
    case 2: case 3: case 4:
        msg = "more than one and less than five"; break;
    default:
        msg = "don't care";
}
```

Un `switch` peut être avantageux lorsqu'on teste des valeurs précises plutôt qu'une plage de valeurs.
Il peut être plus rapide qu'une `if-else-if ladder`, car le compilateur peut parfois optimiser l'instruction `switch` d'une façon impossible avec une échelle.
Un `switch` peut parfois sembler plus lisible qu'une échelle.

## L'opérateur ternaire (ou opérateur conditionnel)

L'opérateur ternaire est une instruction conditionnelle en trois parties, souvent utilisée pour affecter une valeur.
L'expression à tester se trouve avant le point d'interrogation et n'a pas besoin d'être entre parenthèses.
La valeur renvoyée si la condition est vraie se trouve avant les deux-points, celle renvoyée si elle est fausse se trouve après.
On peut renvoyer soit un littéral, soit une variable.

```c
int i = j > 5 ? 5: j;
```

On peut imbriquer des opérateurs ternaires pour alléger la syntaxe.

```c
// the below could also be 
i = j > 5 ? j :k > 5 ? k: 10;
// but that may not be quite as readable

i = j > 5 ? j
    :k > 5 ? k
    :10;

// which is the same as
if (j > 5) i = j;
else if (k > 5) i = k;
else i = 10;
```
