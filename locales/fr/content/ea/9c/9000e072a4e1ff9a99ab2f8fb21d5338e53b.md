# Introduction

En Python, [une énumération](https://docs.python.org/3/library/enum.html) est un ensemble de noms liés à des valeurs `literal` ou `constant` uniques. Les énumérations se définissent en héritant d'une classe `Enum`. Les types d'énumération intégrés sont disponibles dans le module `enum`, et la classe `Enum` peut être importée avec `from enum import Enum`.

```python
class Color(Enum):
    RED = 1
    GREEN = 2
```

Note que les valeurs des membres d'une énumération peuvent être de n'importe quel type de données, comme str, tuple, float, etc.

```python
class Color(Enum):
    RED = 'red'
    GREEN = 'green'
```

Lorsque la même valeur est affectée à deux membres d'une énumération, le membre affecté en second devient un alias du premier. Il n'est pas permis d'utiliser le même nom pour deux membres d'une énumération.

```python
class Color(Enum):
    RED = 1
    GREEN = 2
    ALIAS_OF_RED = 1

Color.ALIAS_OF_RED
#=> <Color.RED: 1>

Color.ALIAS_OF_RED.value
#=> 1
```

On peut parcourir les membres de l'énumération avec la syntaxe standard `for member in` :

```python
for member in Color:
    print((member.name, member.value))
#=> (RED, 1)
#=> (GREEN, 2)
```

Les membres d'une énumération peuvent être comparés avec [`is` (_opérateur d'identité_)](https://www.w3schools.com/python/ref_keyword_is.asp) ou `is not`. Les opérateurs `==` ou `!=` (_opérateurs d'égalité_) fonctionnent de la même manière.

```python
a = Color.RED

a is Color.RED
#=> True

a == Color.RED
#=> True
```

Pour accéder à un membre de l'énumération correspondant à une valeur donnée, on peut utiliser `EnumName(value)` :

```python
g = Color(2)

g is Color.GREEN
#=> True

g
#=> <Color.GREEN: 2>
```
