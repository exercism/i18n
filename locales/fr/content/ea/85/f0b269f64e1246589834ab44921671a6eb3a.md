# Introduction

En plus des déclarations de fonction et des expressions de fonction, JavaScript dispose aussi d'une autre syntaxe très concise pour définir une fonction.
Ces fonctions sont appelées _fonctions fléchées_.

Dans ce concept, on va se concentrer sur la syntaxe qui permet d'écrire une fonction fléchée.
Il y a des différences dans le fonctionnement d'une fonction fléchée, comme la liaison de _this_, que l'on abordera dans d'autres concepts.

Voici une comparaison entre une déclaration de fonction et une fonction fléchée.

```javascript
function addUpTwoNumbers(num1, num2) {
  return num1 + num2;
}

// function keyword removed and => added
const addUpTwoNumbers = (num1, num2) => {
  return num1 + num2;
};
```

Ci-dessus, on voit que la syntaxe des fonctions fléchées :

1. supprime le mot-clé `function`
2. déclare l'identifiant `addUpTwoNumbers` avec `const`
3. ajoute une grosse flèche `=>`

Si le corps de la fonction ne contient qu'une instruction `return`, comme dans l'exemple ci-dessus, les accolades `{}` et le mot-clé `return` peuvent être omis.

<!-- prettier-ignore-start -->
```javascript
const addUpTwoNumbers = (num1, num2) => { return num1 + num2 };

// can be shortened to
const addUpTwoNumbers = (num1, num2) => num1 + num2;
// braces {} and return removed
```
<!-- prettier-ignore-end -->

Dans le cas particulier où une fonction fléchée renvoie uniquement un objet, il faut des parenthèses autour de l'objet pour pouvoir omettre l'instruction `return`.

```javascript
// explicit return of object
const addUpTwoNumbers = (num1, num2) => {
  return {
    num1,
    num2,
  };
};

// implicit return of object
const addUpTwoNumbers = (num1, num2) => ({ num1, num2 });
```

L'utilisation de parenthèses autour des paramètres dépend du nombre de paramètres.

<!-- prettier-ignore-start -->
```javascript
// one parameter does not need parenthesis
const square = num => num * num;

// two or more parameters need to be wrapped in parenthesis
const addUpTwoNumbers = (num1, num2) => num1 + num2;
```
<!-- prettier-ignore-end -->
