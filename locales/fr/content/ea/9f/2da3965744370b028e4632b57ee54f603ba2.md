# Introduction

## Constantes

Le modificateur `const` peut être appliqué (et devrait généralement l'être) à tout champ dont la valeur est connue à la compilation et ne change pas pendant toute la durée de vie du programme.

```csharp
private const int num = 1729;
public const string title = "Grand" + " Master";
```

Le modificateur `readonly` peut être appliqué (et devrait généralement l'être) à tout champ qui ne peut pas être déclaré `const`, dont la valeur ne change pas pendant toute la durée de vie du programme et qui est initialisé soit par un initialiseur en ligne, soit au moment de l'instanciation (par le constructeur ou par une méthode appelée par le constructeur).

```csharp
private readonly int num;
private readonly System.Random rand = new System.Random();

public MyClass(int num)
{
    this.num = num;
}
```

## Copie défensive

Dans les situations sensibles du point de vue de la sécurité (ou même simplement dans une grande base de code où les développeurs ont des priorités et des objectifs différents), il faut éviter de laisser contourner l'API publique d'une classe en acceptant et en stockant les paramètres mutables d'une méthode, ou en exposant un membre mutable d'une classe via une valeur de retour ou un paramètre `out`.

## Collections en lecture seule

Le modificateur `readonly` empêche que la valeur ou la référence d'un champ soit écrasée, mais il n'offre aucune protection pour les membres d'un type référence.

```csharp
readonly List<int> ints = new List<int>();

void Foo()
{
    ints.Add(1);    // ok
    ints = new List<int>(); // fails to compile
}
```

Pour garantir que tous les membres d'un type référence sont protégés, on peut rendre les champs `readonly` et définir des propriétés automatiques sans accesseur `set`.

La Base Class Library (BCL) fournit des versions en lecture seule de certaines collections lorsqu'il faut empêcher la modification des membres d'une collection. Elles se présentent sous forme de _wrappers_ :

- `ReadOnlyDictionary<T>` expose un `Dictionary<T>` en lecture seule.
- `ReadOnlyCollection<T>` expose un `List<T>` en lecture seule.
