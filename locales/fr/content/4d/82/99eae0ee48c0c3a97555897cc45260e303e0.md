# Introduction

Les instances de structures et de classes possèdent chacune une valeur implicite nommée `self`, qui fait référence à l'instance elle-même. `self` a plusieurs usages, mais on l'utilise le plus souvent pour lever l'ambiguïté sur les noms des propriétés et des méthodes de la structure ou de la classe, lorsqu'il peut y avoir confusion.

```swift
struct MySelf {
  var x = 0

  mutating func move(x: Int) {
    // here if we just say x = x it is unclear if we mean
    // the property x or the method parameter x, so we use
    // self for clarity
    self.x = x
  }
}
```
