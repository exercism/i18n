# Astuces

## 1. Trouve la position d'une carte

- Les indices d'un tableau commencent à `0`.
- Il existe une méthode [intégrée][indexof_method_docs] pour obtenir l'indice d'une valeur donnée.

## 2. Détermine si une carte est présente

- Il existe une méthode [intégrée][includes_method_docs] pour vérifier si la valeur est présente dans le tableau

## 3. Détermine si chaque carte est paire

- Il existe une méthode [intégrée][every_method_docs] pour vérifier si chaque valeur satisfait un prédicat

## 4. Vérifie si la pile contient une carte de valeur impaire

- Il existe une méthode [intégrée][some_method_docs] pour vérifier si au moins une valeur satisfait un prédicat

## 5. Récupère la première carte impaire de la pile

- Il existe une méthode [intégrée][find_method_docs] pour obtenir le premier élément qui satisfait un prédicat

## 6. Détermine la position de la première carte qui est paire

- Il existe une méthode [intégrée][findindex_method_docs] pour obtenir l'indice du premier élément du tableau qui satisfait un prédicat
