# Introduction

En Swift, une fonction peut renvoyer plusieurs valeurs : il suffit de construire un tuple avec ces différentes valeurs, puis de le renvoyer.

```swift
func reverseAndLength(_ str: String) -> (reverse: String, length: Int) {
  return (reverse: str.reverse, length: str.count)
}

reverseAndLength("Hello")
// => (reverse: "olleH", length: 5)
```
