# Indices

## 1. Récupère la première lettre du titre

- Il existe [une méthode][index] qui renvoie un `Char` à partir d'un `String`, à un indice donné.

## 2. Récupère les initiales des auteurs

- Tu peux utiliser des méthodes déjà implémentées pour obtenir la première lettre d'un `String`.
- Pour combiner des valeurs dans un `String`, tu peux utiliser [l'interpolation de chaînes][string-interpolation].

## 3. Déchiffre une lettre

- Il existe [une méthode][uppercase] pour vérifier si un `Char` est en majuscule.
- Il existe [une méthode][ord] pour obtenir le point de code d'un `Char`.

## 4. Déchiffre le texte

- Tu peux utiliser [une boucle][while] pour exécuter du code plusieurs fois.
