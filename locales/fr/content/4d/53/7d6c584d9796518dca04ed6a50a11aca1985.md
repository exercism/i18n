# Installation

## Ubuntu (et la plupart des autres distributions basées sur Debian)

Pour compiler le code en local, tu auras besoin de gcc et make, que l'on peut installer à l'aide de la commande suivante :

```shell
sudo apt install gcc make
```

Si tu n'utilises pas de matériel ARM64, installe l'émulateur [QEMU][] et la chaîne de compilation croisée GCC ARM64 à l'aide de la commande suivante :

```shell
sudo apt install qemu-user libc6-dev-arm64-cross gcc-aarch64-linux-gnu
```

## Windows

Utilise [Windows Subsystem for Linux][] avec une distribution basée sur Debian, puis suis les instructions Ubuntu ci-dessus.
Tu peux aussi mettre en place une machine virtuelle Linux.

## macOS

Tu peux lancer une machine virtuelle Linux avec n'importe quelle solution de virtualisation adaptée (par exemple [Lima][]).

[QEMU]: https://www.qemu.org/
[Windows Subsystem for Linux]: https://docs.microsoft.com/en-gb/windows/wsl/about
[Lima]: https://lima-vm.io/
