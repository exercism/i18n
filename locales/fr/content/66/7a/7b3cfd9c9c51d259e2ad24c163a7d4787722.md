# Instructions

En tant que future magicienne, Elyse doit s'entraîner sur quelques bases. Elle a une pile de cartes qu'elle souhaite manipuler.

Pour simplifier un peu les choses, elle n'utilise que les cartes de 1 à 10, ce qui permet de représenter sa pile de cartes par un vecteur de nombres.
La position d'une carte donnée correspond à l'indice dans le vecteur.

## 1. Récupère une carte de la pile

Pour piocher une carte, renvoie la carte à l'indice `position` de la pile donnée.

```R
stack <- c(1, 2, 4, 1)
position <- 3
get_item(stack, position)
# => 4
```

## 2. Échange une carte dans la pile

Fais un tour de passe-passe et échange la carte à l'indice `position` avec la carte de remplacement fournie.
Renvoie la pile modifiée.

```R
stack <- c(1, 2, 4, 1)
position <- 3
replacement_card <- 6
set_item(stack, position, replacement_card)
# => c(1, 2, 6, 1)
```

## 3. Insère une carte au sommet de la pile

Fais apparaître une carte en insérant une nouvelle carte au sommet de la pile.
Renvoie la pile modifiée.

```R
stack <- c(5, 9, 7, 1)
new_card <- 8
insert_item_at_top(stack, new_card)
# => c(5, 9, 7, 1, 8)
```

## 4. Retire une carte de la pile

Fais disparaître une carte en retirant de la pile la carte à la `position` donnée.
Renvoie la pile modifiée.

```R
stack <- c(3, 2, 6, 4, 8)
position <- 3
remove_item(stack, position)
# => c(3, 2, 4, 8)
```

## 5. Vérifie la taille de la pile

Vérifie si la taille de la pile est égale à `stack_size` ou non.

```R
stack <- c(3, 2, 6, 4, 8)
stack_size <- 4
check_size_of_stack(stack, stack_size)
# => FALSE
```

## 6. Retire la carte du sommet de la pile

Fais disparaître une carte en retirant la carte au sommet de la pile.
Renvoie la pile modifiée.

```R
stack <- c(3, 2, 6, 4, 8)
remove_item_from_top(stack)
# => c(3, 2, 6, 4)
```

## 7. Insère une carte en bas de la pile

Fais apparaître une carte en insérant une nouvelle carte en bas de la pile.
Renvoie la pile modifiée.

```R
stack <- c(5, 9, 7, 1)
new_card <- 8
insert_item_at_bottom(stack, new_card)
# => c(8, 5, 9, 7, 1)
```

## 8. Retire une carte du bas de la pile

Fais disparaître une carte en retirant la carte en bas de la pile.
Renvoie la pile modifiée.

```R
stack <- c(8, 5, 9, 7, 1)
remove_item_at_bottom(stack)
# => c(5, 9, 7, 1)
```
