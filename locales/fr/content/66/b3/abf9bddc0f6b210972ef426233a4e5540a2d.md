# Instructions

En tant que future magicienne, Elyse doit s'exercer sur quelques bases. Elle a un paquet de cartes qu'elle veut manipuler.

Pour que ce soit un peu plus simple, elle n'utilise que les cartes de 1 à 10.

## 1. Récupère une carte du paquet

Implémente la fonction `getCard` qui renvoie la carte à la position `index` du paquet donné. Si l'indice ne se trouve pas dans le paquet, renvoie Nothing.

```elm
getCard 2 ( Array.fromList [ 1, 2, 4, 1 ] )
    --> Just 4
getCard 6 ( Array.fromList [ 1, 2, 4, 1 ] )
    --> Nothing
```

## 2. Remplace une carte du paquet

Implémente la fonction `setCard` qui renvoie un paquet dont la carte à la position `index` a été remplacée par la nouvelle carte fournie.
Si l'indice ne se trouve pas dans le paquet, renvoie le paquet d'origine.

```elm
setCard 2 6 ( Array.fromList [ 1, 2, 4, 1 ] )
    --> Array.fromList [ 1, 2, 6, 1 ]
setCard 6 6 ( Array.fromList [ 1, 2, 4, 1 ] )
    --> Array.fromList [ 1, 2, 4, 1 ]
```

## 3. Ajoute une carte au paquet

Implémente la fonction `addCard` qui renvoie un paquet auquel la nouvelle carte a été ajoutée.

```elm
addCard 8 ( Array.fromList [ 5, 9, 7, 1 ] )
    --> Array.fromList [ 5, 9, 7, 1, 8 ]
```

## 4. Retire une carte du paquet

Implémente la fonction `removeCard` qui renvoie un paquet dont la carte à la position `index` a été retirée.
Si l'indice donné n'est pas un indice valide dans le paquet, renvoie le paquet d'origine.

```elm
removeCard 2 ( Array.fromList [ 3, 2, 6, 4, 8 ] )
    --> Array.fromList [ 3, 2, 4, 8 ]
removeCard 2 ( Array.fromList [ 3, 2 ] )
    --> Array.fromList [ 3, 2 ]
```

## 5. Compte le nombre de cartes paires dans le paquet

Implémente la fonction `evenCardCount` qui compte le nombre de cartes paires dans le paquet.

```elm
evenCardCount (Array.fromList [ 3, 8, 4, 5, 1, 6, 10 ] )
    --> 4
```
