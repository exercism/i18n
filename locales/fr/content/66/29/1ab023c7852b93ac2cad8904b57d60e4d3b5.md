# À propos

Si les classes de base de `java.time`, comme `LocalDate` et `LocalDateTime`, proposent des méthodes simples pour ajouter ou soustraire des unités de temps, les ajustements de date plus complexes demandent souvent une logique plus élaborée (par exemple trouver le « deuxième mardi du mois » ou le « dernier jour de l'année »).

Le paquet `java.time.temporal` fournit justement l'interface fonctionnelle [`TemporalAdjuster`][temporaladjuster-docs].
Elle représente une stratégie d'ajustement d'un objet temporel (comme un `LocalDate`).
La classe utilitaire [`TemporalAdjusters`][temporaladjusters-docs] (attention au « s » du pluriel) contient des méthodes de fabrique statiques qui fournissent de nombreuses implémentations d'ajusteurs prédéfinies et courantes.

## Utilise `TemporalAdjusters`

Les objets temporels comme `LocalDate` et `LocalDateTime` possèdent une méthode `with()` qui accepte un `TemporalAdjuster`.
Cette méthode renvoie un *nouvel* objet temporel auquel l'ajustement a été appliqué.

```exercism/note
`with(TemporalAdjuster)` renvoie une _nouvelle_ instance et ne met pas à jour l'instance existante, car toutes les classes temporelles de `java.time` sont immuables.
```

```java
import java.time.LocalDate;
import java.time.Month;
import java.time.DayOfWeek;
import java.time.temporal.TemporalAdjusters;

LocalDate date = LocalDate.of(2024, Month.AUGUST, 15); // 2024-08-15 (a Thursday)

// Use a predefined adjuster from TemporalAdjusters
LocalDate firstDayOfNextMonth = date.with(TemporalAdjusters.firstDayOfNextMonth());
// => 2024-09-01

LocalDate nextSunday = date.with(TemporalAdjusters.next(DayOfWeek.SUNDAY));
// => 2024-08-18
```

## Les ajusteurs prédéfinis courants

La classe `TemporalAdjusters` propose de nombreuses méthodes statiques utiles.
En voici quelques exemples courants :

### Trouve le énième jour de la semaine

L'ajusteur `dayOfWeekInMonth(int ordinal, DayOfWeek dayOfWeek)` trouve l'énième occurrence d'un jour de la semaine donné dans le mois.

```java
LocalDate date = LocalDate.of(2024, Month.AUGUST, 15); // 2024-08-15

// Find the second Tuesday of August 2024
LocalDate secondTuesday = date.with(TemporalAdjusters.dayOfWeekInMonth(2, DayOfWeek.TUESDAY));
// => 2024-08-13

// Find the fourth Friday of August 2024
LocalDate fourthFriday = date.with(TemporalAdjusters.dayOfWeekInMonth(4, DayOfWeek.FRIDAY));
// => 2024-08-23
```

### Trouve le premier ou le dernier jour de la semaine dans le mois

Les ajusteurs `firstInMonth(DayOfWeek dayOfWeek)` et `lastInMonth(DayOfWeek dayOfWeek)` trouvent la première ou la dernière occurrence d'un jour de la semaine dans le mois.

```java
LocalDate date = LocalDate.of(2024, Month.AUGUST, 15); // 2024-08-15

// Find the first Sunday of August 2024
LocalDate firstSunday = date.with(TemporalAdjusters.firstInMonth(DayOfWeek.SUNDAY));
// => 2024-08-04

// Find the last Monday of August 2024
LocalDate lastMonday = date.with(TemporalAdjusters.lastInMonth(DayOfWeek.MONDAY));
// => 2024-08-26
```

### Trouve le premier ou le dernier jour du mois ou de l'année

Des ajusteurs plus simples trouvent le premier ou le dernier jour du mois ou de l'année en cours.

```java
LocalDate date = LocalDate.of(2024, Month.AUGUST, 15); // 2024-08-15

LocalDate firstDay = date.with(TemporalAdjusters.firstDayOfMonth());
// => 2024-08-01

LocalDate lastDay = date.with(TemporalAdjusters.lastDayOfMonth());
// => 2024-08-31

LocalDate lastDayOfYear = date.with(TemporalAdjusters.lastDayOfYear());
// => 2024-12-31
```

### Les ajustements relatifs (suivant/précédent)

Les ajusteurs comme `next()`, `previous()`, `nextOrSame()` et `previousOrSame()` trouvent l'occurrence suivante ou précédente d'un jour de la semaine donné, par rapport à la date courante.

- `next()`/`previous()` : excluent la date courante si elle correspond.
- `nextOrSame()`/`previousOrSame()` : incluent la date courante si elle correspond.

```java
LocalDate thursday = LocalDate.of(2024, Month.AUGUST, 15); // A Thursday

// Find the next Sunday (exclusive)
LocalDate nextSunday = thursday.with(TemporalAdjusters.next(DayOfWeek.SUNDAY));
// => 2024-08-18

// Find the next Thursday (exclusive)
LocalDate nextThursday = thursday.with(TemporalAdjusters.next(DayOfWeek.THURSDAY));
// => 2024-08-22

// Find the next Thursday (inclusive) - returns the same date
LocalDate nextOrSameThursday = thursday.with(TemporalAdjusters.nextOrSame(DayOfWeek.THURSDAY));
// => 2024-08-15

// Find the previous Monday (exclusive)
LocalDate previousMonday = thursday.with(TemporalAdjusters.previous(DayOfWeek.MONDAY));
// => 2024-08-12
```

## Les ajusteurs personnalisés

Comme `TemporalAdjuster` est une [`@FunctionalInterface`][functionalinterface-docs], on peut créer ses propres ajusteurs personnalisés à l'aide d'expressions lambda pour la logique que les méthodes prédéfinies ne couvrent pas.
L'interface impose d'implémenter une seule méthode : `Temporal adjustInto(Temporal temporal)`.

```java
// Example: An adjuster that finds the next workday (Mon-Fri), skipping weekends.
TemporalAdjuster nextWorkday = temporal -> {
    LocalDate result = (LocalDate) temporal; // Assuming input is LocalDate
    do {
        result = result.plusDays(1);
    } while (result.getDayOfWeek() == DayOfWeek.SATURDAY || result.getDayOfWeek() == DayOfWeek.SUNDAY);
    return result;
};

LocalDate friday = LocalDate.of(2024, Month.AUGUST, 16);
LocalDate nextWorkdayDate = friday.with(nextWorkday);
// => 2024-08-19 (Monday)

LocalDate sunday = LocalDate.of(2024, Month.AUGUST, 18);
LocalDate nextWorkdayFromSunday = sunday.with(nextWorkday);
// => 2024-08-19 (Monday)
```

Les ajusteurs personnalisés sont puissants, mais ceux qui sont prédéfinis dans la classe `TemporalAdjusters` couvrent un large éventail de cas d'usage courants.
