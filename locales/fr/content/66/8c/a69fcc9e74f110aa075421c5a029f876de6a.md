# Introduction

## Plages

Les plages représentent une suite d'un ou plusieurs entiers consécutifs. On les crée en reliant deux entiers avec `..`.

```elixir
1..5
```

Les plages peuvent être croissantes ou décroissantes. Elles incluent toujours la première et la dernière valeur.

Une plage implémente le protocole _Enumerable_, ce qui signifie que les fonctions du module `Enum` peuvent être utilisées pour manipuler les plages.
