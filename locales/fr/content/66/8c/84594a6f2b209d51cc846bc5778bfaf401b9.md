# Indices

## Généralités

- Le type de retour est `Dec`, le type décimal à virgule fixe de Roc, qui peut représenter exactement les prix et les remises utilisés ici.
  Utilise `.to_dec()` pour combiner un nombre entier avec un prix décimal.

- Un tableau de fréquences peut t'aider à suivre les exemplaires en double sans dépendre de l'ordre du panier.
