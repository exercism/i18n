# À propos

Z3 est un langage de Satisfiability Modulo Theory (SMT), qui sert à déterminer si des équations ou des formules sont satisfaisables, autrement dit si elles admettent une solution possible.

On rencontre le plus souvent Z3 dans la vérification logicielle, la résolution de contraintes, les problèmes géométriques, la sécurité et d'autres applications qui tirent parti de calculs mathématiques rapides.

Z3 a été créé par le groupe Research in Software Engineering (RiSE) de Microsoft Research et, depuis 2015, il est devenu un langage open source. Le dépôt Github open source de Z3 se trouve à l'adresse https://github.com/Z3Prover/z3.
