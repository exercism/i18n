# Instructions

Tu t'occupes du tableau des scores pendant un match de netball. Contrairement à tout ce qu'on a vu jusqu'ici, un tableau des scores doit se souvenir de ce qui s'est passé.

La classe `SCOREBOARD` a besoin des éléments suivants. Le squelette te fournit la classe et ses deux déclarations d'attributs ; ajoute le reste.

## 1. Prépare le tableau des scores

`create` prend le nom de l'équipe à domicile et le nom de l'équipe à l'extérieur, et renvoie un tableau des scores avec les deux scores à zéro.

```sather
board ::= #SCOREBOARD("Vixens", "Magpies");
board.home_score
-- => 0
```

## 2. Marque un but

`home_goal` ajoute un point au score de l'équipe à domicile, et `away_goal` ajoute un point au score de l'équipe à l'extérieur. Aucune des deux ne renvoie de valeur.

```sather
board.home_goal;
board.home_score
-- => 1
```

## 3. Lis le tableau des scores

`summary` renvoie le tableau tel qu'il serait écrit : l'équipe à domicile, son score, un tiret, le score de l'équipe à l'extérieur, puis l'équipe à l'extérieur.

```sather
board.summary
-- => "Vixens 1 - 0 Magpies"
```

Les espaces sont exactement tels qu'affichés, et le tiret est un seul `-`.

## 4. Qui est en tête ?

`leader` renvoie le nom de l'équipe en tête, ou `"Draw"` lorsque les scores sont à égalité.

```sather
board.leader
-- => "Vixens"
```

## 5. Quel est l'écart de buts ?

`margin` renvoie le nombre de buts qui séparent les équipes. Il n'est jamais négatif, quelle que soit l'équipe en tête.

```sather
board.margin
-- => 1
```
