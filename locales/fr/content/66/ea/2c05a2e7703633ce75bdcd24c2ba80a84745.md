# Surcharge de fonctions

Nous avons vu dans l'exercice Lasagnes comment les fonctions en Swift sont définies à l'aide du mot-clé `func`, suivi d'une liste de noms de paramètres entre parenthèses, où ces noms comprennent une étiquette d'argument facultative et un nom de paramètre suivi d'une annotation de type, puis du corps de la fonction entre accolades. Par exemple :

```swift
func add(_ x: Int, and y: Int, doubleResult: Bool) -> Int {
  let sum = x + y
  if doubleResult {
    return sum * 2
  } else {
    return sum
  }
}

let twentySix = add(6, and: 7, doubleResult: true)
// => 26
```

Deux fonctions sont considérées comme distinctes en Swift si elles ont un nom différent, _ou_ si l'une des conditions suivantes est vraie :

- Elles ont un nombre de paramètres différent
- Leurs étiquettes d'argument externes sont différentes
- Le type de l'un des paramètres est différent

Ainsi, étant donné la définition de `add(_:and:doubleResult)` ci-dessus, chacune des fonctions suivantes est considérée comme distincte et peut être définie et utilisée dans le même programme :

```swift
// Different number of parameters
func add(_ x: Int, and y: Int) -> Int {
  x + y
}

let eleven = add(5, and: 6)
// => 11

// Different parameter type
func add(_ x: Double, and y: Int, doubleResult: Bool) -> Double {
  let sum = x + Double(y)
  if doubleResult {
    return sum * 2
  } else {
    return sum
  }
}

let twentySeven = add(6.5, and: 7, doubleResult: true)
// => 27.0

// Different argument label
func add(_ x: Int, and y: Int, doubleThat: Bool) -> Int {
  let sum = x + y
  if doubleThat {
    return sum * 2
  } else {
    return sum
  }
}
let thirteen = add(6, and: 7, doubleThat: false)
// => 13
```

Les fonctions sont également considérées comme distinctes si seule la valeur de retour change, même si, dans de nombreux cas, il est nécessaire de fournir un indice au compilateur sous la forme d'une annotation de type afin qu'il sache quelle version de la fonction appeler.

```swift
func add(_ x: Int, and y: Int, doubleResult: Bool) -> Double {
  let sum = Double(x + y)
  if doubleResult {
    return sum * 2
  } else {
    return sum
  }
}

let thirty = add(6, and: 9, doubleResult: true)
// Error: Ambiguous use of 'add(_:and:doubleResult:)'

let thirty: Double = add(6, and: 9, doubleResult: true)
// => 30
```

Mais changer uniquement le nom d'un paramètre interne ne permet pas de distinguer deux fonctions.

```swift
func add(_ w: Int, and y: Int, doubleResult: Bool) -> Int {
  let sum = w + y
  if doubleResult {
    return sum * 2
  } else {
    return sum
  }
}
// Error: Invalid redeclaration of 'add(_:and:doubleResult:)'
```
