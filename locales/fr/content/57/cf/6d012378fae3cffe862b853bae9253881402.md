# Installe Java

En plus de la CLI d'Exercism et de ton éditeur de texte préféré, pour t'entraîner sur les exercices Java d'Exercism, il te faut le **Java Development Kit** (JDK).
Le JDK comprend à la fois un environnement d'exécution Java _et_ des outils de développement (notamment le compilateur Java).

Il existe aujourd'hui de nombreuses variantes du JDK, dont certaines sont open source.
Chez Exercism, on recommande d'utiliser [Eclipse Temurin d'Adoptium][adoptium].

## Versions de Java prises en charge

Le parcours Java d'Exercism prend en charge Java 25 LTS et les versions antérieures.

## Installe Eclipse Temurin

Pour installer Eclipse Temurin sur ton système, rends-toi sur leurs excellentes [instructions d'installation][adoptium-installation-guide].
Tu y trouveras des instructions pour installer le JDK avec ton gestionnaire de paquets préféré, ainsi que des liens vers des installateurs à télécharger pour tous les principaux systèmes d'exploitation.

## IDE Java

Il existe de nombreux IDE gratuits pour Java.
Voici quelques choix populaires :

- [IntelliJ IDEA Community Edition][intellij-idea]
- [Eclipse][eclipse]
- [Visual Studio Code avec l'extension Java][vscode-java]

## Étapes suivantes

Tu es maintenant prêt à te lancer sur le parcours Java d'Exercism !

Pour commencer, consulte « [Lancer les tests][exercism-java-tests-docs] ».
