# Instructions supplémentaires

## Registres

| Registre | Utilisation | Type        | Description                                                   |
| -------- | ----------- | ----------- | ------------------------------------------------------------- |
| `$a0`    | entrée      | adresse     | chaîne de caractères d'entrée terminée par un caractère nul   |
| `$v0`    | sortie      | booléen     | l'entrée est un isogramme (`0` = `false`, `1` = `true`)       |
| `$t0-9`  | temporaire  | quelconque  | utilisé pour le stockage temporaire                           |
