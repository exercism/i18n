# Introduction

## Date et heure

Le _package_ `java.time`, introduit dans Java 8, contient plusieurs classes pour manipuler des dates et des heures.

### `LocalDate`

La classe `java.time.LocalDate` représente une date sans fuseau horaire dans le [système de calendrier ISO-8601][iso-8601], comme `2007-12-03` :

```java
LocalDate date = LocalDate.of(2007, 12, 3);
```

On peut comparer des dates entre elles :

```java
LocalDate date1 = LocalDate.of(2007, 12, 3);
LocalDate date2 = LocalDate.of(2007, 12, 4);

date1.isBefore(date2);
// => true

date1.isAfter(date2);
// => false
```

Une instance de `LocalDate` dispose d'accesseurs pour en extraire les composantes temporelles :

```java
LocalDate date = LocalDate.of(2007, 12, 3);

date.getDayOfMonth();
// => 3
```

Une instance de `LocalDate` dispose de méthodes pour lui ajouter des unités de temps :

```exercism/note
Ces méthodes renvoient une _nouvelle_ instance de `LocalDate` et ne modifient pas l'instance existante, car la classe `LocalDate` est immuable.
```

```java
LocalDate date = LocalDate.of(2007, 12, 3);

date.plusDays(3);
// => 2007-12-06
```

### `LocalDateTime`

La classe `java.time.LocalDateTime` représente une date et une heure sans fuseau horaire dans le [système de calendrier ISO-8601][iso-8601], comme `2007-12-03T10:15:30` :

```java
LocalDateTime datetime = LocalDateTime.of(2007, 12, 3, 10, 15, 30);
```

On peut convertir une instance de `LocalDate` en `LocalDateTime` :

```java
LocalDate date = LocalDate.of(2007, 12, 3);
LocalDateTime datetime = date.atTime(10, 15, 30);
datetime.toString();
// => "2007-12-03T10:15:30"
```

### Formater les dates et les heures

`LocalDate` comme `LocalDateTime` utilisent la notation standard [ISO-8601][iso-8601] pour convertir depuis et vers une `String`.

```java
LocalDateTime datetime = LocalDateTime.of(2007, 12, 3, 10, 15, 30);
LocalDateTime parsed = LocalDateTime.parse("2007-12-03T10:15:30");

datetime.isEqual(parsed);
// => true
```

Il n'est pas possible d'analyser une `LocalDate` ou une `LocalDateTime` à partir d'une `String` comme celle-ci en utilisant un format différent.
À la place, pour formater des dates selon un format personnalisé, il faut utiliser `java.time.format.DateTimeFormatter` :

```java
DateTimeFormatter parser = DateTimeFormatter.ofPattern("dd/MM/yyyy");
LocalDate date = LocalDate.parse("03/12/2007", parser);

DateTimeFormatter printer = DateTimeFormatter.ofPattern("MMMM d, yyyy");
printer.format(date);
// => "December 3, 2007"
```

On peut aussi préciser une locale lors de la création du format personnalisé, afin de formater et d'analyser selon différentes régions :

```java
DateTimeFormatter.ofPattern("MMMM d, yyyy", Locale.FRENCH).format(date);
// => décembre 3, 2007

DateTimeFormatter.ofPattern("MMMM d, yyyy", Locale.of("pt")).format(date);
// => dezembro 3, 2007
```

[iso-8601]: https://en.wikipedia.org/wiki/ISO_8601
