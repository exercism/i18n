# Introduction

`OpenStruct` permet de créer facilement un objet à partir d'un `Hash`.
Plutôt que d'y accéder par les clés du `Hash`, `OpenStruct` nous permet d'utiliser des méthodes pour lire et définir les valeurs.


```ruby
attributes = { name: "Jeremy Walker", age: 21, location: "Nomadic" }
person = OpenStruct.new(attributes)

person.name
#=> Jeremy Walker

person.location
#=> Nomadic

# Update the age
person.age = 35

# It sets correctly
person.age
#=> 35
```

Un avantage de cette approche est qu'on peut profiter d'un raccourci quand on utilise la syntaxe de bloc.
Quand un bloc appelle une seule méthode, tu peux remplacer le bloc par `&:` suivi du nom de la méthode.
Par exemple, ces deux lignes sont équivalentes :

```ruby
people.sum { |person| person.age }
people.sum(&:age)
```

## Bibliothèque standard

Toutes les classes que tu as vues dans les exercices précédents font partie de la bibliothèque de base de Ruby.

`OpenStruct` fait partie de la bibliothèque standard de Ruby (souvent abrégée en « stdlib ») : un ensemble de classes pour travailler avec des choses comme les dates, le JSON ou la mise en réseau.
Elle propose aussi des fonctionnalités utiles pour rendre ton code plus facile à manipuler.

Quand on utilise des classes qui ne viennent pas de la bibliothèque de base (ton propre code dans d'autres fichiers, des classes de la bibliothèque standard ou des dépendances externes), il faut les importer avec la méthode `require` avant de pouvoir s'en servir.
Par exemple :

```ruby
require 'ostruct'

person = OpenStruct.new(name: "Jeremy Walker")
# ...
```
