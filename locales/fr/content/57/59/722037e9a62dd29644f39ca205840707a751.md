# Tableaux associatifs et ensembles

Un tableau contient des valeurs à des positions numérotées. Parfois, l'étiquette utile n'est pas un nombre.

## Tableaux associatifs

Un **tableau associatif** associe chaque **clé** à une **cible**. On recherche une valeur par sa clé, et le tableau renvoie ce qui y a été rangé.

`FMAP{K,T}` est un tableau associatif qui va des clés de type `K` aux cibles de type `T`. Un guide qui associe le nom d'un animal à son lieu de vie est un `FMAP{STR,STR}`.

```sather
   guide ::= #FMAP{STR,STR};
   guide := guide.insert("emu", "grassland");
   guide.get("emu")               -- "grassland"
```

## Réaffecte toujours la réponse

Regarde à nouveau cette ligne du milieu. `insert` renvoie le tableau associatif avec la paire supplémentaire, et il faut conserver la réponse :

```sather
   guide := guide.insert("emu", "grassland");     -- yes
   guide.insert("emu", "grassland");              -- no: the answer is lost
```

C'est la même règle que pour `FSTR`, et pour la même raison. La réponse est en général le tableau qu'on a fourni, modifié sur place ; parfois, quand le tableau n'a plus de place, c'est un tableau plus grand. Comme on ne peut pas savoir lequel des deux, **utilise la réponse et cesse d'utiliser l'ancien nom.** Un nom qui date d'avant un `insert` peut être obsolète, ou ne plus désigner un tableau utilisable du tout.

Cela signifie aussi qu'un tableau associatif passé à une routine n'est pas à l'abri de ses modifications. Si l'original doit survivre, regarde `copy` sur la page du concept.

## Est-il présent ?

`has_ind` permet de savoir si une clé se trouve dans le tableau associatif. Le nom est l'abréviation de « has index », un indice étant ce que ces tableaux appellent une clé.

```sather
   guide.has_ind("emu")           -- true
   guide.has_ind("moa")           -- false
```

Demander une clé qui n'est pas là ne **déclenche pas** d'erreur. `get` renvoie la valeur vide du type (zéro pour un `INT`, et _void_ pour un `STR`), ce qui provoquera une erreur plus tard et ailleurs. Donc vérifie avant de récupérer :

```sather
   if guide.has_ind(animal) then
      return guide.get(animal);
   else
      return "Unknown";
   end;
```

## Ensembles

Un **ensemble** contient des valeurs sans répétition et sans ordre. `FSET{T}` est un ensemble de valeurs de type `T`.

```sather
   seen ::= #FSET{STR};
   seen := seen.insert("emu");
   seen := seen.insert("emu");    -- already there; nothing changes
   seen.size                      -- 1
   seen.has("emu")                -- true
```

Insérer deux fois la même chose n'en laisse qu'un seul exemplaire. C'est à cela que sert un ensemble : rassembler des éléments en oubliant combien de fois chacun est apparu.

`insert` sur un ensemble renvoie l'ensemble à utiliser ensuite, exactement comme pour un tableau associatif : réaffecte-le à chaque fois.

## Combien ?

`.size` fonctionne pour les deux : combien de paires contient un tableau associatif, et combien de valeurs contient un ensemble.
