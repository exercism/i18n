# Indices

## 1. Calcule le tarif journalier à partir d'un tarif horaire

- Utilise les opérateurs arithmétiques comme indiqué dans l'introduction de cet exercice.

## 2. Calcule le nombre de jours travaillés à partir d'un budget

- Détermine d'abord le tarif journalier, puis calcule le nombre de jours et, enfin, arrondis ce nombre à l'inférieur.

## 3. Calcule le tarif avec remise pour les grands projets

- Arrondis à l'inférieur le résultat de la division pour obtenir le nombre de mois complets.
- `100% - discount` correspond au pourcentage facturé après application de la remise.
- Utilise `MOD`, l'opérateur modulo, pour calculer le nombre de jours qui dépassent les mois complets.
- Additionne les tarifs mensuels remisés et les tarifs journaliers complets, puis arrondis le résultat au supérieur.
