# Introduction

## Enum

`Enum` est un module très utile qui fournit un ensemble d'algorithmes pour manipuler les énumérables. Il permet de trier, de filtrer, de regrouper, de compter, de chercher, de trouver les valeurs minimales et maximales, et bien plus encore.

De manière générale, un _énumérable_ est une donnée que l'on peut parcourir, c'est-à-dire une collection. En Elixir, un énumérable est n'importe quel type de données qui implémente le [protocole][exercism-protocols] `Enumerable`. Les plus courants sont les [listes][exercism-lists] et les [_maps_][exercism-maps].

De nombreuses fonctions `Enum` acceptent une fonction en argument.

```elixir
Enum.all?([1, 2, 3, 4, 5], fn x -> x > 3 end)
# => false
```

Les fonctions `Enum` les plus courantes sont `map` et `reduce`.

### `map/2`

`Enum.map/2` permet de remplacer chaque élément d'un énumérable par un autre élément. Le deuxième argument de `Enum.map/2` est une fonction qui accepte l'élément d'origine et renvoie son remplacement.

### `reduce/3`

`Enum.reduce/3` permet de _réduire_ tout l'énumérable à une seule valeur. Pour cela, on utilise une variable spéciale appelée l'_accumulateur_. L'accumulateur transporte l'état intermédiaire de la réduction entre les itérations.

Le deuxième argument de `Enum.reduce/3` est la valeur initiale de l'accumulateur. Le troisième argument est une fonction qui accepte un élément et un accumulateur, et renvoie la nouvelle valeur de l'accumulateur.

### Travailler avec les _maps_

Quand on utilise des _maps_ avec les fonctions `Enum`, la _map_ est automatiquement convertie en une liste de deux tuples `{key, value}`.

Pour la retransformer en _map_, utilise `Enum.into/2`. `Enum.into/2` est une fonction qui transforme un énumérable en un _collectable_ : toute structure de données qui implémente le protocole `Collectable`. On peut le voir comme l'opposé de `Enum.reduce/3`.

`Enum` propose également `Enum.into/3`. `Enum.into/3` est une variante de `Enum.into/2` qui accepte une fonction de transformation à appliquer pendant que l'énumérable est transformé en _collectable_.

#### Transformer les _maps_

Au lieu d'utiliser `Enum.into/3` ou `Enum.map/2` suivi de `Enum.into/2` pour appliquer une transformation (un mapping) à une _map_, on peut aussi utiliser la fonction dédiée `Map.new/2`. Elle fonctionne exactement comme `Enum.into/3` : elle accepte un énumérable et une fonction de transformation, mais renvoie toujours une nouvelle _map_ au lieu de laisser choisir le _collectable_.
