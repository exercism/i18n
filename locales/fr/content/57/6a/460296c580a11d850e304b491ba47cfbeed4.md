# Instructions

Dans cet exercice, on va travailler avec des comptes d'épargne.
Chaque année, le solde de ton compte d'épargne est mis à jour en fonction de son taux d'intérêt.
Le taux d'intérêt que ta banque t'accorde dépend du montant d'argent présent sur ton compte (son solde) :

- 3,213 % pour un solde inférieur à `0` dollar (le solde devient plus négatif).
- 0,5 % pour un solde supérieur ou égal à `0` dollar et inférieur à `1000` dollars.
- 1,621 % pour un solde supérieur ou égal à `1000` dollars et inférieur à `5000` dollars.
- 2,475 % pour un solde supérieur ou égal à `5000` dollars.

Tu as quatre tâches, chacune d'elles portera sur le solde et son taux d'intérêt.

## 1. Calcule le taux d'intérêt

Implémente la fonction `interest_rate` pour calculer le taux d'intérêt en fonction du solde indiqué :

```cpp
interest_rate(200.75);
// => 0.5
```

## 2. Calcule les intérêts

Implémente la fonction `yearly_interest` pour calculer les intérêts en fonction du solde indiqué :

```cpp
yearly_interest(200.75):
// => 1.003750
```

## 3. Calcule la mise à jour annuelle du solde

Implémente la fonction `annual_balance_update` pour calculer la mise à jour annuelle du solde, en tenant compte du taux d'intérêt :

```cpp
annual_balance_update(200.75);
// => 201.75375
```

## 4. Calcule le nombre d'années avant d'atteindre le solde souhaité

Implémente la fonction `years_until_desired_balance` pour calculer le nombre minimum d'années nécessaires pour atteindre le solde souhaité, en tenant compte du fait que chaque année, les intérêts sont ajoutés au solde.
Cela signifie que le solde après un an est : solde initial + intérêts sur le solde initial.
Le solde après la deuxième année est le solde après un an + les intérêts sur le solde après un an.
Et ainsi de suite, jusqu'à ce que le solde de l'année en cours soit supérieur ou égal au solde cible.

```cpp
double balance {200.75};
double targetBalance {214.88};
years_until_desired_balance(balance, targetBalance)
// => 14
```

Note que la valeur renvoyée est un `int`.
