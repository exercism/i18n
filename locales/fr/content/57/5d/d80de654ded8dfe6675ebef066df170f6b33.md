# Introduction

En Rust, tout type qui implémente le trait [`Iterator`](https://doc.rust-lang.org/stable/std/iter/trait.Iterator.html) peut être traité comme un itérateur.
Les [`collections`](https://doc.rust-lang.org/std/collections/index.html) intégrées de Rust peuvent être converties en itérateurs grâce aux méthodes `iter`, `iter_mut` et `into_iter`.
Les itérateurs disposent d'un large éventail de [méthodes puissantes](https://doc.rust-lang.org/stable/std/iter/trait.Iterator.html#provided-methods), comme `collect`, `map`, `filter` et `fold`, pour te permettre d'effectuer des opérations sur tes données.

```rust
use std::collections::HashMap;

let v = vec![0, 1, 2];

let mut iter = v.iter();

// Call next() to return the next value
assert_eq!(Some(&0), iter.next());
assert_eq!(Some(&1), iter.next());
assert_eq!(Some(&2), iter.next());
// Ahen None once it's over
assert_eq!(None, iter.next());

// Loop over iterators with built-in methods, such as `map` and `collect`
let w: HashMap<_, _> = v.into_iter().map(|x| (x, x + 1)).collect();
println!("{w:?}");
// => {1: 2, 0: 1, 2: 3}
```
