# Ajout aux instructions

## Format de sortie

Produis le losange sous la forme d'une _string_ terminée par un caractère nul, avec un saut de ligne à la fin de chaque ligne.

Un exemple de sortie serait `"  A  \n B B \nC   C\n B B \n  A  \n"`

## Registres

| Registre | Utilisation   | Type       | Description                                        |
| -------- | ------------- | ---------- | -------------------------------------------------- |
| `$a0`    | entrée        | byte       | lettre                                             |
| `$a1`    | entrée/sortie | adresse    | _string_ de résultat terminée par un caractère nul |
| `$t0-9`  | temporaire    | quelconque | pour le stockage temporaire                        |
