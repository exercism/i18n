# À propos

## Valeurs de retour multiples

[Plusieurs valeurs peuvent être renvoyées][multiple-return-values] par une fonction Swift, en créant un tuple à partir des différentes valeurs et en renvoyant ce tuple.

```swift
func reverseAndLength(_ str: String) -> (reverse: String, length: Int) {
  return (reverse: str.reverse, length: str.count)
}

reverseAndLength("Hello")
// => (reverse: "olleH", length: 5)
```

## Omets le `return`

```swift
func reverseAndLength(_ str: String) -> (reverse: String, length: Int) {
  (reverse: str.reverse, length: str.count)
}
```

Lorsque le corps entier d'une fonction se réduit à une seule expression, [le mot-clé `return` peut être omis][implicit-returns].

À noter que cela vaut pour tous les types de retour, pas seulement pour les valeurs de retour multiples.
