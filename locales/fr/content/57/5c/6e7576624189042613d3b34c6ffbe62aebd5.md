# Indices

## Général

- [La surcharge de méthodes en C#][member-overloading].
- [L'interpolation de _strings_][string-interpolation] permet de formater les _strings_ de description.

## 3. Décris le moyen de déplacement

- Une [condition simple][if-statement] peut servir à gérer la logique conditionnelle.

## 4. Décris un personnage qui se rend à une destination

- Tu peux réutiliser la fonctionnalité de description existante.
- Tu peux utiliser des [expressions dans les _strings_ interpolés][string-interpolation-expressions], ce qui signifie que tu peux appeler des méthodes directement dans les parties interpolées d'un _string_ interpolé.

## 5. Décris un personnage qui se rend à une destination sans préciser le moyen de déplacement

- Tu peux réutiliser la fonctionnalité existante qui prend bien un moyen de déplacement explicite.
- Tu peux utiliser des [paramètres optionnels][optional-arguments] pour réduire la quantité de code nécessaire.
