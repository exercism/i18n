# Instructions

Lamont est un alien Lisp qui veut écrire son propre jeu vidéo. L'une des tâches pour lesquelles il t'a demandé de l'aide consiste à tenir une liste des meilleurs scores.

## 1. Crée la table des meilleurs scores

Définis une fonction `make-high-score-table` qui ne prend aucun argument et renvoie une nouvelle table de hachage vide :

```lisp
(make-high-score-table) ; => #<HASH-TABLE :TEST EQL :COUNT 0 {1005A90103}>
```

## 2. Ajoute un joueur à la table

Pour ajouter un joueur à la table, définis une fonction `add-player` qui prend deux arguments :
- la table des meilleurs scores
- le nom du joueur sous forme de mot-clé

Initialise le score du joueur à zéro.

```lisp
(add-player hash-table :louis) ; => 0
(add-player hash-table :lilly) ; => 0
```

## 3. Définis le score d'un joueur

Pour définir le score d'un joueur, définis une fonction `set-score` qui prend trois arguments :
- la table des meilleurs scores
- le nom du joueur sous forme de mot-clé
- le score du joueur sous forme d'entier

```lisp
(set-score hash-table :louis 1234) ; => 1234
```

## 4. Récupère un score depuis la table

Pour récupérer le score d'un joueur depuis la table, définis une fonction `get-score` qui prend deux arguments :
- la table des meilleurs scores
- le nom du joueur sous forme de mot-clé

Cette fonction doit renvoyer le score enregistré pour le joueur.
Si aucun score n'est enregistré pour ce joueur, ou si ce joueur n'est pas encore dans la table, elle doit renvoyer `0`.

```lisp
(get-score hash-table :louis)                         ; => 1234
(get-score hash-table :lilly)                         ; => 0
(get-score hash-table :not-a-character-in-this-story) ; => 0
```

## 5. Supprime un joueur de la table

Pour supprimer un joueur de la table des meilleurs scores, définis une fonction `remove-player` qui prend deux arguments :
- la table des meilleurs scores
- le nom du joueur sous forme de mot-clé

Cette fonction doit gérer proprement les cas où le joueur n'a pas encore été ajouté à la table.
Évidemment, une fois qu'un joueur est supprimé, si on récupère son score depuis la table, celui-ci vaudra zéro.

```lisp
(set-score hash-table :louis 1234)           ; => 1234
(remove-player hash-table :louis)            ; => T
(get-score hash-table :louis)                ; => 0

(remove-player hash-table :not-in-the-table) ; => NIL
```
