# Introduction

`case` est une structure de contrôle qui permet de comparer une valeur donnée à plusieurs motifs. Les clauses d'une expression `case` sont évaluées de haut en bas, jusqu'à ce qu'une correspondance soit trouvée.

```elixir
age = 15

case age do
  0 -> ~c"infant"
  age when age < 4 -> ~c"baby"
  age when age < 13 -> ~c"child"
  age when age < 18 -> ~c"teenager"
  _ -> ~c"adult"
end

# => ~c"teenager"
```
