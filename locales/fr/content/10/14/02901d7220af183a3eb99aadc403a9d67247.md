# À propos

Le type d'[union discriminée][define] représente un nombre fixe de cas nommés. Chaque valeur d'une union discriminée correspond à exactement un des cas nommés. Ce type de données est appelé un _type somme_.

Chaque cas d'une union discriminée peut éventuellement avoir des données associées, et différents cas peuvent avoir différents types de données. Si aucun des cas n'a de données associées, l'union discriminée est semblable à ce que d'autres langages appellent généralement une _énumération_ (ou _enum_).

Une union discriminée est définie à l'aide du mot-clé `type` et nécessite très peu de syntaxe. Cela les rend faciles à utiliser, et tu les trouveras utilisées à de nombreux endroits, y compris dans la bibliothèque de base.

```fsharp
// Discriminated union without associated data
type Season =
    | Spring
    | Summer
    | Autumn
    | Winter

// Discriminated union with associated data
type Number =
    | Integer of int
    | Float of float
    | Invalid
```

On peut créer une valeur pour un cas spécifique en faisant référence à son nom, ou à son nom complet si le nom n'est pas unique. Comme les noms de cas ne sont que des fonctions de construction, les données associées peuvent être passées comme un argument de fonction classique.

```fsharp
let byName = Integer 2
let byFullName = Number.Invalid
```

Les unions discriminées ont une _égalité structurelle_, ce qui signifie que deux valeurs pour le même cas et avec les mêmes données (facultatives) sont équivalentes.

La façon privilégiée de travailler avec les unions discriminées est de passer par le [filtrage par motif][pattern-matching] en utilisant le [motif d'identificateur][identifier-patterns] :

```fsharp
let describe number =
    match number with
    | Integer i -> sprintf "Integer: %d" i
    | Float d  -> sprintf "Float: %f" d
    | Invalid   -> "Invalid"
```
