# Instructions

Ellen crée un jeu dans lequel le joueur doit combattre des aliens.
Elle vient tout juste d'apprendre la programmation orientée objet (POO) et elle est impatiente de tirer parti de ce que l'utilisation de `classes` pourrait apporter à son programme.

Pour le plus grand plaisir d'Ellen, tu as proposé ton aide, et elle t'a confié la tâche de programmer les aliens que le joueur doit combattre.


## 1. Crée la classe Alien

Définis la classe Alien avec un constructeur qui prend deux paramètres `<x_coordinate>` et `<y_coordinate>`, et qui les place dans les variables d'instance `x_coordinate` et `y_coordinate`.
Chaque alien commencera également avec 3 points de vie, donc la variable `health` doit aussi être initialisée.

```python
>>> alien = Alien(2, 0)
>>> alien.x_coordinate
2
>>> alien.y_coordinate
0
>>> alien.health
3
```

Maintenant, chaque alien doit pouvoir suivre en interne sa propre position et ses propres points de vie.

## 2. La méthode `hit`

Ellen aimerait que la `class` Alien ait une méthode `hit` qui diminue de 1 les points de vie d'un objet alien lorsqu'elle est appelée.
Ainsi, elle peut simplement appeler `<alien>.hit()` au lieu de devoir modifier manuellement les points de vie d'un alien.
C'est à toi de décider si `hit()` amène les points de vie _à_ zéro ou _en dessous_ de zéro.

```python
>>> alien = Alien(0, 0)

# Initialized health value.
>>> alien.health
3

# Decrements health by 1 point.
>>> alien.hit()
>>> alien.health
2
```

## 3. La méthode `is_alive`

Tu réalises que si les points de vie continuent de diminuer, à un moment donné ils atteindront probablement 0 (_voire moins !_).
Ce serait une bonne idée d'ajouter une méthode `is_alive` qu'Ellen peut appeler rapidement pour vérifier si l'alien est... eh bien... vivant. 😉
`<alien>.is_alive()` doit renvoyer un booléen.

```python
>>> alien.health
1
>>> alien.is_alive()
True
>>> alien.hit()
>>> alien.health
0
>>> alien.is_alive()
False
```

## 4. La méthode `teleport`

Dans le jeu d'Ellen, les aliens ont la capacité de se téléporter !
Tu vas devoir écrire une méthode `teleport` qui prend de nouvelles valeurs `x_coordinate` et `y_coordinate`, et qui modifie les coordonnées de l'alien en conséquence.

```python
>>> alien.teleport(5, -4)
>>> alien.x_coordinate
5
>>> alien.y_coordinate
-4
```

## 5. La méthode `collision_detection`

Évidemment, si les aliens peuvent être touchés par quelque chose, ils doivent alors être capables de détecter quand une telle collision s'est produite.
Cependant, les algorithmes de détection de collision peuvent être délicats, et tu ne sais pas encore comment en implémenter un.
Ellen a dit qu'elle s'en occuperait plus tard, mais elle aimerait quand même que la méthode `collision_detection` apparaisse dans la classe pour lui rappeler de développer cette fonctionnalité.
Elle devra prendre une variable quelconque (probablement un autre objet), mais c'est vraiment tout ce que tu sais.
Tu devras t'assurer que le fait de mettre la définition de la méthode dans la classe ne provoque aucune erreur lorsqu'elle est appelée :

```python
>>> alien.collision_detection(other_object)
>>>
```

## 6. Le compteur d'aliens

Ellen revient vers toi avec une nouvelle requête.
Elle veut garder la trace du nombre d'aliens créés depuis le début de la partie.
Elle dit que cela a un rapport avec le système de score.

Par exemple :

```python
>>> alien_one = Alien(5, 1)
>>> alien_one.total_aliens_created
1
>>> alien_two = Alien(3, 0)
>>> alien_two.total_aliens_created
2
>>> alien_one.total_aliens_created
2
# Accessing the variable from the class directly
>>> Alien.total_aliens_created
2
```
