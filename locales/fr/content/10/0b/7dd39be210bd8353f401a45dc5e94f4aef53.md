# Tests

## Depuis la ligne de commande

Tape simplement `p test`. On part du principe que le chemin vers les binaires phix est déclaré dans la variable d'environnement PATH.

Voir [Tests unitaires][unit-testing] pour plus de détails sur le framework de tests habituellement utilisé.

## Modifie le ou les fichiers test.exw

C'est encouragé au début de ton apprentissage. Insère un `--` devant tous les tests sauf le premier ou les deux premiers. Enregistre le fichier de test.
Écris ton code pour faire passer le premier test ou les deux premiers. Active ensuite d'autres tests au fur et à mesure, jusqu'à ce que tu parviennes à tous les faire passer.

[unit-testing]: http://phix.x10.mx/docs/html/unit_test.htm
