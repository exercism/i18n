# Introduction

C# est un langage à typage statique, ce qui signifie que tout a un type au moment de la compilation. Affecter une valeur à un nom s'appelle définir une variable. Une variable peut être définie soit en spécifiant explicitement son type, soit en laissant le compilateur C# inférer son type à partir de la valeur affectée (ce que l'on appelle l'_inférence de type_). Ainsi, les deux définitions de variable suivantes sont équivalentes :

```csharp
int explicitVar = 10; // Explicitly typed
var implicitVar = 10; // Implicitly typed
```

La mise à jour de la valeur d'une variable se fait à l'aide de l'opérateur `=`. Une fois définie, le type d'une variable ne peut jamais changer.

```csharp
var count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning different type
// count = false;
```

C# est un [langage orienté objet][object-oriented-programming] et exige que toutes les fonctions soient définies dans une _classe_. Le mot-clé `class` sert à définir une classe. Les objets (ou _instances_) sont créés à l'aide du mot-clé `new`.

```csharp
class Calculator
{
    // ...
}

var calculator = new Calculator();
```

Une fonction dans une classe est appelée une _méthode_. Chaque méthode peut prendre zéro ou plusieurs paramètres. Tous les paramètres doivent être explicitement typés, il n'y a pas d'inférence de type pour les paramètres. De même, le type de retour doit lui aussi être explicite. Les valeurs sont renvoyées par les méthodes à l'aide du mot-clé `return`. Pour qu'une méthode puisse être appelée par du code dans d'autres fichiers, le modificateur d'accès `public` doit être ajouté.

```csharp
class Calculator
{
    public int Add(int x, int y)
    {
        return x + y;
    }
}
```

Les méthodes sont invoquées à l'aide de la syntaxe du point (`.`) sur une instance, en spécifiant le nom de la méthode à appeler et en passant des arguments pour chacun des paramètres de la méthode. Les arguments peuvent éventuellement préciser le nom du paramètre correspondant.

```csharp
var calculator = new Calculator();
var sum_v1 = calculator.Add(1, 2);
var sum_v2 = calculator.Add(x: 1, y: 2);
```

En C#, la portée est définie entre les caractères `{` et `}`.

C# prend en charge deux types de commentaires. Les commentaires sur une seule ligne sont précédés de `//` et les commentaires multilignes sont insérés entre `/*` et `*/`.
