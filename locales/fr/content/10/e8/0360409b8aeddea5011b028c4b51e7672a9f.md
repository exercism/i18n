# Indices

## Général

- Lis la documentation sur les _strings_ dans le [guide officiel des _strings_][string-guide].
- Parcours les [méthodes disponibles pour les _strings_][string-methods].

## 1. Nettoie le nom

- Il existe une [méthode intégrée][string-replace] pour remplacer toutes les occurrences d'une sous-chaîne dans une _string_.
- Il existe une [méthode intégrée][string-strip] pour supprimer les espaces en début et en fin d'une _string_.

## 2. Récupère la première lettre du nom

- Pour obtenir un caractère précis dans une _string_, tu peux utiliser l'[opérateur d'indexation][string-indexing].

## 3. Formate la première lettre en initiale

- Il existe une [méthode intégrée][string-upcase] pour convertir tous les caractères d'une _string_ en majuscules.

## 4. Mets les initiales à l'intérieur du cœur

- Il existe une syntaxe spéciale pour [interpoler][string-interpolation] une expression à l'intérieur d'une _string_.
- Tu peux insérer un emoji de cœur dans une _string_ en utilisant une séquence d'échappement : `\u<id>`, l'identifiant de l'emoji de cœur est `2764`.
