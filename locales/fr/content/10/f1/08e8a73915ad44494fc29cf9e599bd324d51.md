# Installation

Il existe de nombreuses façons d'installer Zig, et leur nombre ne cesse d'augmenter à mesure que le langage mûrit.
Heureusement, toutes les méthodes d'installation populaires sont listées sur la [page d'installation de Zig][install-zig].

## Version de Zig

Pour l'instant, Exercism ne prend en charge que Zig 0.16.0 (publiée le 14 avril 2026).

Un exercice peut être compatible avec une autre version de Zig, mais ce n'est pas garanti.
Zig n'a pas encore atteint la version 1.0, et les changements incompatibles sont monnaie courante.

## Outils supplémentaires

### Zig fmt : génère du code bien formaté

Quand on résout un exercice, on peut adopter toutes sortes de styles de code pour ses solutions.
Cependant, en dehors de la résolution d'exercices, par exemple quand on crée des applications ou des bibliothèques, il est généralement judicieux de rendre son code cohérent et lisible.
Ces principes sont d'autant plus importants lorsque d'autres personnes, qui voudraient contribuer à tes projets, doivent lire ton code.

Pour régler ce problème, le compilateur Zig est livré avec un [_linter_][linters] léger intégré qui formate ton code de manière pratique.
Ce formateur de code cherche à suivre le [guide de style][style-guide] déjà établi par la [documentation de Zig][documentation].

Pour découvrir les fonctionnalités du formateur natif de Zig, utilise la commande suivante :

```bash
zig fmt --help
```

### Zig Zen : des règles pour coder

Parfois, un peu d'orientation aide beaucoup quand on accomplit une tâche, même quand on écrit du code.
Heureusement, une commande amusante est intégrée directement au compilateur Zig pour nous rappeler quelques-uns des objectifs qui président à l'écriture de bon code Zig.

Pour découvrir ces paroles de sagesse, tu peux utiliser la commande suivante :

```bash
zig zen
```

### Le Zig Language Server : une prise en charge complète de Zig dans l'éditeur

Ce logiciel tiers fournit la complétion dans l'éditeur et des fonctionnalités de navigation améliorées dans le code Zig, ce qui peut t'aider à apprendre le langage plus rapidement.

Consulte le [guide d'installation de ZLS][install-zls] pour les instructions les plus récentes.
