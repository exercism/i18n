# Introduction

Une fonction récursive est une fonction qui s'appelle elle-même.

Une fonction récursive doit avoir au moins un _cas de base_ et au moins un _cas récursif_.

Un _cas de base_ renvoie une valeur sans rappeler la fonction.
Un _cas récursif_ rappelle la fonction en modifiant l'entrée pour qu'elle finisse par correspondre au cas de base.

En Elm, les fonctions récursives sont généralement définies à l'aide du filtrage par motifs, avec des expressions `case` ou plusieurs clauses de fonction.

```elm
count : List a -> Int
count list =
    case list of
        [] ->
            0  -- base case

        _ :: tail ->
            1 + count tail  -- recursive case
```

## Les boucles par la récursion

En raison de l'immuabilité, les boucles en Elm s'écrivent différemment de celles des langages impératifs.
Par exemple, une boucle ressemble souvent à ceci :

```c
for(i = 0; i < array.length; i++) {
  // do something with array[i]
}
```

Dans un langage fonctionnel comme Elm, on ne peut pas modifier des variables.
Les boucles doivent donc être implémentées à l'aide de la récursion.

L'équivalent d'une boucle `for` en Elm ressemblerait à ceci :

```elm
loop : List a -> (a -> b) -> List b
loop list f =
    case list of
        [] ->
            []

        head :: tail ->
            f head :: loop tail f
```

En pratique, pour parcourir des tableaux et d'autres structures de données en Elm, on utilise le plus souvent des fonctions du module `List`, comme `List.map`, `List.filter` et `List.foldl`.
En interne, ces fonctions sont implémentées à l'aide de la récursion.
