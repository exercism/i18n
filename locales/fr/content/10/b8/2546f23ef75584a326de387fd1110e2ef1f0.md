# Instructions

Dans cet exercice, tu vas écrire du code pour gérer un dictionnaire d'indicatifs téléphoniques internationaux à l'aide d'une `Map`.

Le dictionnaire permet de retrouver le nom d'un pays (la valeur de la `Map`, de type `String`) à partir de l'indicatif téléphonique international (la clé de la `Map`, de type `Integer`).

## 1. Renvoie les codes dans une `Map`

Implémente la méthode `getCodes` qui ne prend aucun paramètre et renvoie une `Map` associant les indicatifs téléphoniques aux pays actuellement présents dans le dictionnaire.

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.getCodes();
// => empty map 
```

## 2. Ajoute des entrées au dictionnaire

Le dictionnaire doit être rempli.
Implémente la méthode `setDialingCode` qui prend un indicatif téléphonique et le pays correspondant, puis ajoute cet indicatif et ce pays.
Si l'indicatif téléphonique est déjà dans la `Map`, mets à jour celle-ci avec l'indicatif et le pays fournis.

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.setDialingCode(679, "Unknown");
// => { 679 => "Unknown" }

dialingCodes.setDialingCode(679, "Fiji");
// => { 679 => "Fiji" }
```

## 3. Retrouve le pays associé à un indicatif téléphonique

Implémente la méthode `getCountry` qui prend un indicatif téléphonique et renvoie le nom du pays correspondant à cet indicatif.

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.setDialingCode(55, "Brazil");
dialingCodes.getCountry(55);
// => "Brazil"
```

## 4. N'autorise pas les doublons

Lorsque tu ajoutes un indicatif téléphonique, il faut faire attention à ne pas ajouter deux fois le même indicatif ou le même pays.
Dans ce cas de figure, on considère que la première entrée est la bonne.
Implémente la méthode `addNewDialingCode` qui ajoute une entrée pour l'indicatif téléphonique et le pays donnés.
Cependant, contrairement à `setDialingCode`, elle ne fait rien si l'indicatif téléphonique ou le pays est déjà dans la `Map`.

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.addNewDialingCode(32, "Belgium");
dialingCodes.addNewDialingCode(379, "Vatican City");
// => { 32 => "Belgium", 379 => "Vatican City" }


dialingCodes.addNewDialingCode(32, "Other");
dialingCodes.addNewDialingCode(39, "Vatican City");
// => { 32 => "Belgium", 379 => "Vatican City" }
```

## 5. Trouve l'indicatif téléphonique d'un pays

C'est rare, mais des erreurs peuvent se produire.
Pour corriger l'erreur, il faut savoir à quel indicatif téléphonique le pays est actuellement associé.
Pour trouver quel indicatif téléphonique doit être corrigé, implémente la méthode `findDialingCode` qui prend un pays et renvoie son indicatif téléphonique.
Renvoie `null` si le pays n'est _pas_ dans la `Map`.

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.addDialingCode(44, "UK");
dialingCodes.findDialingCode("UK");
// => 44

dialingCodes.findDialingCode("Unlisted");
// => null
```

## 6. Mets à jour l'indicatif téléphonique d'un pays

Maintenant que l'on sait quel indicatif téléphonique doit être corrigé, on peut le mettre à jour.
Implémente la méthode `updateCountryDialingCode` qui prend le nouvel indicatif téléphonique du pays et le nom du pays, puis met à jour l'entrée en conséquence.
Ne fais rien si le pays n'est _pas_ dans la `Map` (cette méthode ne sert qu'à corriger des erreurs).

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.addDialingCode(88, "Japan");
// => { 88 => "Japan" }

dialingCodes.updateCountryDialingCode(81, "Japan");
// => { 81 => "Japan" }

dialingCodes.updateCountryDialingCode(32, "Mars");
// => { 81 => "Japan"}
```
