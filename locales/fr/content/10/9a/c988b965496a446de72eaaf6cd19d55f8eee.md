# Introduction

La bibliothèque standard d'Elixir offre 4 modules différents pour manipuler les dates et les heures, chacun avec sa propre _struct_.

- Le module `Date`. Une _struct_ `Date` peut être créée avec le _sigil_ `~D`.

  ```elixir
  ~D[2021-01-01]
  ```

- Le module `Time`. Une _struct_ `Time` peut être créée avec le _sigil_ `~T`.

  ```elixir
  ~T[12:00:00]
  ```

- Le module `NaiveDateTime` pour les dates et heures sans fuseau horaire. Une _struct_ `NaiveDateTime` peut être créée avec le _sigil_ `~N`.

  ```elixir
  ~N[2021-01-01 12:00:00]
  ```

- Le module `DateTime` pour les dates et heures avec un fuseau horaire. Pour utiliser ce module avec un fuseau horaire autre qu'UTC, il faut une dépendance externe : une base de données de fuseaux horaires.

## Comparaisons

Pour comparer des dates ou des heures entre elles, cherche une fonction `compare` ou `diff` dans le module correspondant. Les opérateurs de comparaison comme `==`, `>` et `<` _semblent_ fonctionner, mais ils ne font pas une comparaison sémantique correcte pour ces _structs_.
