# Appendice

## Comportement du Zipper

Le Zipper offre une façon fonctionnelle de naviguer dans un arbre de `Node`.

Tous les appels au Zipper doivent renvoyer un _nouvel_ objet Zipper.
Si le Zipper ne change pas les valeurs (c'est-à-dire si aucune méthode `Set*` n'a été appelée), il doit réutiliser le même arbre sous-jacent.
Quand une méthode `Set*` est appelée, le nouveau Zipper doit utiliser un nouvel arbre, sans modifier l'arbre d'origine.

Les appels au Zipper qui déplacent le _focus_ vers un `Node` invalide doivent renvoyer une erreur.
