# Introduction

## Listes

Une `list` en F# est une collection immuable de zéro ou plusieurs valeurs. Les valeurs d'une liste doivent toutes avoir le même type. Comme les listes sont immuables, une fois qu'une liste a été construite, sa valeur ne peut plus jamais changer. Toute fonction ou tout opérateur qui semble modifier une liste (par exemple en y ajoutant un élément) renvoie en réalité une nouvelle liste.

Une liste peut être définie comme suit :

```fsharp
let empty = []
let singleValue = [5]
let threeValues = ["a"; "b"; "c"]
```

La façon la plus courante d'ajouter un élément à une liste est d'utiliser l'opérateur `::` (cons) :

```fsharp
let twoToFour = [2; 3; 4]
let oneToFour = 1 :: twoToFour
// => [1; 2; 3; 4]
```

Une liste F# a une _tête_ (le premier élément) et une _queue_ (tout ce qui suit le premier élément). La queue d'une liste est elle-même une liste.

Les listes se manipulent soit avec les fonctions et opérateurs définis dans le module `List`, soit manuellement à l'aide du filtrage par motif avec les motifs _list_ et _cons_ :

```fsharp
let describe list =
    match list with
    | [] -> "Empty list"
    | head::tail -> sprintf "Non-empty list with head: %d" head

describe []        // => "Empty list"
describe [1]       // => "Non-empty with head: 1"
describe [5; 7; 9] // => "Non-empty with head: 5"
```

Tu peux aussi _ignorer_ une valeur lors du filtrage par motif ; lorsque tu ne te _soucies pas_ d'une valeur dans un cas précis (autrement dit, tu ne vas _pas_ l'utiliser), tu peux utiliser un tiret bas (`'_'`) pour le signaler :

```fsharp
let describe list =
    match list with
    | [] -> "Empty list"
    | [x] -> "List with one item"
    | [_; y] -> "List with two items (first item ignored)"
    | _ -> "List with many items (all items ignored)"

describe []        // => "Empty list"
describe [1]       // => "List with one item"
describe [5; 7]     // => "List with two items (first item ignored)"
describe [5; 7; 9] // => "List with many items (all items ignored)"
```

Le `'_'` seul doit toujours venir _en dernier_ lors du filtrage par motif ; toute valeur qui ne correspond à _aucun_ des autres cas sera traitée par ce cas.
