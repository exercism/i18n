# Indices

## 1. Affiche un badge pour un employé

- On peut utiliser un [_string template_][string-template] pour créer des _strings_ de description.
- Il existe une [méthode intégrée pour convertir une _string_ en majuscules][to-upper-case].

## 2. Affiche un badge pour un nouvel employé

- Vérifie que l'identifiant vaut `null` avant de l'utiliser.
- Tu peux utiliser un [opérateur d'égalité][kotlin-operators] pour vérifier si une valeur vaut `null`.

## 3. Affiche un badge pour le propriétaire

- Tu peux utiliser l'[opérateur Elvis][elvis-operator] pour fournir une valeur de remplacement quand une variable vaut `null`.
