# Jonglage de types

Le jonglage de types peut aussi être appelé coercition de types.
Le jonglage de types se produit lorsque deux valeurs de types différents sont converties vers le même type pour effectuer une opération.

```php
$baskets = 5 // int
$apples_per_basket = "3" // string
$baskets * $apples_per_basket
# => 15 // int
```

Lorsque l'expression est évaluée, la valeur _string_ est implicitement convertie en `int` pour correspondre à l'attente de l'opérateur `*`.
La décision du type vers lequel convertir est prise par PHP selon les règles de l'opération, et ces règles varient grandement.

La coercition de types se produit aussi lors de l'appel de fonctions et de méthodes :

```php
strlen(12321);
# => 5
```

## Transtypage

Plutôt que de compter sur une coercition implicite, on peut forcer explicitement une valeur à être évaluée comme un certain type en utilisant le transtypage de style `C` :

```php
$apples_per_basket = "3" // string
$my_number = (int) $apples_per_basket // cast string to int
# => 3 // int
```

Cela convertira la valeur vers le type spécifié dans les parenthèses `(...)`.
Tous les types primitifs peuvent être utilisés comme type cible : `bool`, `int`, `float`, `string`, `array`, `object`.

## Conversion temporaire uniquement

Le jonglage de types ou le transtypage **ne change pas** le type de la valeur stockée dans une variable.
Seule l'entrée de l'opération est convertie.

```php
$apples_per_basket = "3" // string
5 * $apples_per_basket
# $apples_per_basket => "3" // string

$my_number = (int) $apples_per_basket // cast string to int
# $apples_per_basket => "3" // string
```

## Perte d'informations

Lorsqu'une valeur est convertie vers un autre type, il peut y avoir une perte d'informations dans le processus :

```php
$exact_distance = 15.5
$rough_distance = (int) $exact_distance
// => 15

$is_distant = (bool) $exact_distance
// => true

$erroneous_distance = (float) $is_distant
// => 1.0
```

Compter sur le transtypage, explicitement ou implicitement, peut produire des erreurs dans un système plus vaste.

## Transtypage explicite vers `array` et `object`

Les valeurs peuvent aussi être converties vers les types `array` et `object`.
Si une valeur qui n'est pas un tableau ou un objet est convertie vers un `array`, elle est convertie en un seul élément présent dans un tableau :

```php
$day_of_the_week = 'Monday';
(array) $day_of_the_week
// => array(1) {
//      [0]=>
//        string(6) "Monday"
//    }
```

Lorsqu'elle est convertie en `object`, la valeur est affectée à une propriété publique nommée `scalar` :

```php
$car = "Honda"
(object) $car
// => object(stdClass)#1 (1) {
//      ["scalar"]=>
//        string(5) "Honda"
//    }
```

> `stdClass` est le type d'une classe anonyme intégrée à PHP.
