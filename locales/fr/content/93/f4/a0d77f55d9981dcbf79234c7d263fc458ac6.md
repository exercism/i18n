## 1. Démarre la machine

- Pense à [utiliser][use] le [comportement `GenServer`][genserver].
- Il existe [une fonction intégrée][start-link] qui démarre un processus `GenServer` lié. La seule chose que `TakeANumberDeluxe.start_link/2` doit faire est d'appeler cette fonction avec les bons arguments.
- `__MODULE__` est une variable spéciale qui contient le nom du module courant.
- Implémente le [`GenServer` _callback_ utilisé pour démarrer le processus][init].
- Le _callback_ doit renvoyer soit `{:ok, state}`, soit `{:stop, reason}`.
- Lis les options dans la liste de mots-clés `init_arg`.
- Il existe [une fonction intégrée][keyword-get] pour récupérer une valeur dans une liste de mots-clés.
- Utilise `TakeANumberDeluxe.State.new/2` pour obtenir l'état initial.
- Utilise `@impl` au-dessus de l'implémentation de ton _callback_ pour indiquer de quel comportement ce _callback_ provient.

## 2. Renvoie l'état de la machine

- Il existe [une fonction intégrée][call] qui envoie un message à un processus `GenServer` et reçoit une réponse. La seule chose que `TakeANumberDeluxe.report_state/1` doit faire est d'appeler cette fonction avec les bons arguments.
- Les messages envoyés à un serveur peuvent être n'importe quoi, mais il vaut mieux utiliser des atomes.
- Implémente le [`GenServer` _callback_ utilisé pour traiter les messages qui attendent une réponse][handle-call].
- Le _callback_ doit renvoyer `{:reply, reply, state}`.
- Passe l'état comme réponse.
- Utilise `@impl` au-dessus de l'implémentation de ton _callback_ pour indiquer de quel comportement ce _callback_ provient.

## 3. Ajoute de nouveaux numéros à la file d'attente

- Il existe [une fonction intégrée][call] qui envoie un message à un processus `GenServer` et reçoit une réponse. La seule chose que `TakeANumberDeluxe.queue_new_number/1` doit faire est d'appeler cette fonction avec les bons arguments.
- Les messages envoyés à un serveur peuvent être n'importe quoi, mais il vaut mieux utiliser des atomes.
- Implémente le [`GenServer` _callback_ utilisé pour traiter les messages qui attendent une réponse][handle-call].
- Le _callback_ doit renvoyer `{:reply, reply, state}`.
- Obtiens la réponse et le nouvel état en appelant `TakeANumberDeluxe.State.queue_new_number/1`. Utilise une [expression `case`][case] pour faire une correspondance de motifs sur la valeur de retour.
- La réponse doit être soit `{:ok, new_number}`, soit `{:error, error}`.
- Utilise `@impl` au-dessus de l'implémentation de ton _callback_ pour indiquer de quel comportement ce _callback_ provient.

## 4. Sers le prochain numéro de la file d'attente

- Il existe [une fonction intégrée][call] qui envoie un message à un processus `GenServer` et reçoit une réponse. La seule chose que `TakeANumberDeluxe.serve_next_queued_number/2` doit faire est d'appeler cette fonction avec les bons arguments.
- Les messages envoyés à un serveur peuvent être n'importe quoi, mais il vaut mieux utiliser des tuples si un argument doit être envoyé dans le message. Utilise un message comme celui-ci : `{:my_message_name, some_argument}`.
- Implémente le [`GenServer` _callback_ utilisé pour traiter les messages qui attendent une réponse][handle-call].
- Le _callback_ doit renvoyer `{:reply, reply, state}`.
- Obtiens la réponse et le nouvel état en appelant `TakeANumberDeluxe.State.serve_next_queued_number/2`. Utilise une [expression `case`][case] pour faire une correspondance de motifs sur la valeur de retour.
- La réponse doit être soit `{:ok, next_number}`, soit `{:error, error}`.
- Utilise `@impl` au-dessus de l'implémentation de ton _callback_ pour indiquer de quel comportement ce _callback_ provient.

## 5. Réinitialise l'état

- Il existe [une fonction intégrée][cast] qui envoie un message à un processus `GenServer` et n'attend pas de réponse. La seule chose que `TakeANumberDeluxe.reset_state/1` doit faire est d'appeler cette fonction avec les bons arguments.
- Les messages envoyés à un serveur peuvent être n'importe quoi, mais il vaut mieux utiliser des atomes.
- Implémente le [`GenServer` _callback_ utilisé pour traiter les messages qui n'attendent pas de réponse][handle-cast].
- Le _callback_ doit renvoyer `{:noreply, state}`.
- Utilise `TakeANumberDeluxe.State.new/2` pour obtenir le nouvel état, exactement comme dans `init/1`.
- Utilise `@impl` au-dessus de l'implémentation de ton _callback_ pour indiquer de quel comportement ce _callback_ provient.

## 6. Implémente l'arrêt automatique

- Modifie tous les _callbacks_ `init/1` et `handle_*` pour qu'ils renvoient un élément supplémentaire dans leurs tuples. Sa valeur doit être `state.auto_shutdown_timeout`.
- La valeur de retour `{:stop, reason}` de `init/1` n'a pas besoin de délai d'expiration.
- Implémente le [`GenServer` _callback_ utilisé pour traiter les messages qui n'ont pas été envoyés de la manière habituelle][handle-info].
- Ce _callback_ doit gérer les messages `:timeout` et quitter le processus, mais aussi intercepter et ignorer tous les autres messages.
- Pour quitter un processus GenServer, renvoie `{:stop, reason, state}` depuis le _callback_.
- La raison de sortie doit être `:normal`.
