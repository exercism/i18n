# Instructions

Dans cet exercice, tu vas écrire du code pour analyser la production d'une chaîne de montage dans une usine automobile. La vitesse de la chaîne de montage peut aller de `0` (arrêt) à `10` (maximum).

À sa vitesse minimale (`1`), `221` voitures sont produites chaque heure. La production augmente linéairement avec la vitesse. Ainsi, avec une vitesse réglée sur `4`, elle devrait produire `4 * 221 = 884` voitures par heure. Cependant, les vitesses plus élevées augmentent la probabilité que des voitures défectueuses soient produites, et celles-ci doivent alors être mises au rebut. Le tableau suivant montre comment la vitesse influence le taux de réussite :

- `0` : taux de réussite de 0 %.
- `1` à `4` : taux de réussite de 100 %.
- `5` à `8` : taux de réussite de 90 %.
- `9` : taux de réussite de 80 %.
- `10` : taux de réussite de 77 %.

Tu as trois tâches.

## 1. Calcule le taux de réussite

Implémente la fonction `successRate` pour calculer le taux de réussite à partir de la vitesse de production :

```fsharp
successRate 6
// => 0.9
```

## 2. Calcule le taux de production par heure

Implémente la fonction `productionRatePerHour` pour calculer le taux de production horaire de la chaîne de montage, en tenant compte de son taux de réussite :

```fsharp
productionRatePerHour 6
// => 1193.4
```

Note que la valeur renvoyée est un `float`.

## 3. Calcule le nombre de voitures fonctionnelles produites par minute

Implémente la fonction `workingItemsPerMinute` pour calculer combien de voitures fonctionnelles sont produites par minute :

```fsharp
workingItemsPerMinute 6
// => 19
```

Note que la valeur renvoyée est un `int`.
