# À propos

Quatre mots de [`grouping`][grouping] et [`splitting`][splitting] couvrent la quasi-totalité des besoins quand il s'agit de « découper une séquence en morceaux » :

```factor
USING: grouping kernel sequences splitting splitting.monotonic ;

! Disjoint chunks of N elements
{ 1 2 3 4 5 6 7 } 3 group .
! => { { 1 2 3 } { 4 5 6 } { 7 } }

! Overlapping sliding window of N elements
{ 1 2 3 4 5 } 2 clump .
! => { { 1 2 } { 2 3 } { 3 4 } { 4 5 } }

! Split wherever a predicate fires on an element
{ 1 2 0 3 4 0 5 } [ zero? ] split-when .
! => { { 1 2 } { 3 4 } { 5 } }

! Group runs where adjacent elements are "the same" by some test
{ 1 1 2 2 2 3 } [ = ] monotonic-split .
! => { { 1 1 } { 2 2 2 } { 3 } }
```

| mot              | effet                                                                  |
|-------------------|-------------------------------------------------------------------------|
| `group`           | `( seq n -- groups )` : des morceaux disjoints de *n* éléments          |
| `clump`           | `( seq n -- clumps )` : des fenêtres glissantes de *n* éléments qui se chevauchent |
| `split-when`      | `( seq quot: ( elt -- ? ) -- pieces )` : coupe dès que le quot est vrai |
| `monotonic-split` | `( seq quot: ( a b -- ? ) -- pieces )` : coupe quand le quot porte sur des éléments *adjacents* et vaut `f` |

Un modèle mental utile :

- **`group` / `clump`** regardent les tailles ; le paramètre *n* indique la taille de chaque fenêtre.
- **`split-when`** regarde des *éléments isolés* ; le prédicat décide si chaque élément constitue une « coupure ».
- **`monotonic-split`** regarde des *paires* ; le prédicat décide si deux éléments adjacents appartiennent encore à la même suite.
