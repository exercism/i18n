# Instructions

Tu vas écrire du code pour gérer un tableau de langages de programmation à apprendre.

## 1. Ajoute un langage à un tableau

Modifie le sous-programme `add-language`, qui prend un tableau de langages et un nom de langage comme arguments, pour renvoyer un tableau avec le nouveau langage ajouté à la fin.

## 2. Retire un langage d'un tableau

Modifie le sous-programme `remove-language` pour retirer le dernier langage d'un tableau donné.

## 3. Récupère le premier langage d'un tableau

Modifie le sous-programme `first-language` pour renvoyer le premier langage d'un tableau donné.

## 4. Récupère le dernier langage d'un tableau

Modifie le sous-programme `last-language` pour renvoyer le dernier langage d'un tableau donné.

## 5. Récupère une tranche de langages d'un tableau

Modifie le sous-programme `get-languages`, qui prend un tableau de langages et un tableau de nombres pour les éléments voulus, pour renvoyer une tranche du tableau donné.

## 6. Vérifie si un langage existe dans un tableau

Modifie le sous-programme `has-language`, qui prend un tableau de langages et un nom de langage comme arguments, pour renvoyer `True` ou `False` selon que le langage existe dans le tableau donné.
