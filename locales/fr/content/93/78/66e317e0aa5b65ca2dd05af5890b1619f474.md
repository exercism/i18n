# Modulo

Les comparaisons avec le modulo sont parfaitement valides en Crystal, mais une façon plus lisible de comparer le reste d'une division consiste à utiliser la méthode [`divisible_by?`][divisible_by].
Par exemple :

```crystal
# Rather than:
number %% 2 == 0

# Consider:
number.divisible_by?(2)
```
