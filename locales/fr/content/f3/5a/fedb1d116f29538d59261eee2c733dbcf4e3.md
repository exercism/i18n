# À propos

Rust implémente le type [char][char type] pour représenter un caractère unique. Un littéral `char` s'écrit entre apostrophes, comme `'a'`.
Chaque `char` occupe quatre octets et représente une seule [valeur scalaire Unicode][unicode scalar].

Cependant, un [`char`][character type] ne correspond pas toujours à ce que l'on considère comme une lettre. Certaines langues, comme l'hindi, utilisent des [diacritiques][diacritics], qui sont des symboles spéciaux modifiant le caractère auquel ils sont attachés. Bien qu'en Rust le diacritique soit un `char` à part entière, c'est l'ensemble formé du diacritique et du caractère qu'il modifie que l'on considère habituellement comme une lettre.

Le terme désignant un caractère et son diacritique est [grapheme cluster][grapheme cluster]. Il existe des _crates_ externes permettant de traiter les grapheme clusters, comme [unicode-segmentation][unicode-segmentation].

Exemple

```rust
pub fn main() {
    let text = "ü"; // a "u" with a diacritic
    let text_vec: Vec<char> = text.chars().collect(); // this gets the chars in "ü"
    println!("{:?}", text_vec.len()); // this prints the number of chars in "ü"
    println!("{:?}", text_vec[0]); // this prints the first char in "ü"
    println!("{:?}", text_vec[1]); // this prints the second char in "ü"
}
```

affiche

```rust
2
'u'
'\u{308}'
```

'\u{308}' est une autre façon d'écrire un littéral `char`. `\u` indique qu'il s'agit d'un `char` unicode, `{308}` étant le numéro Unicode unique de ce caractère ou de ce diacritique.
