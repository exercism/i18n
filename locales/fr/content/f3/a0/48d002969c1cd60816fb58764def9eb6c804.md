# Instructions

Karl veut tenir à jour un tableau des langages qu'il souhaite apprendre sur le site d'Exercism.
Karl doit pouvoir ajouter de nouveaux langages, en retirer d'anciens et vérifier si certains langages figurent dans le tableau.
Ce serait vraiment enthousiasmant si Karl voulait apprendre Java ou Kotlin !

## 1. Définis une fonction pour vérifier si le tableau de langages est vide

Karl doit savoir si son tableau de langages devient un jour vide, pour pouvoir aller en chercher d'autres à apprendre !
Définis une méthode appelée `isEmpty` qui renvoie `true` s'il n'y a aucun langage dans le tableau.

```java
if (languageList.isEmpty()) {
    findMoreLanguagesToLearn();
}
```

## 2. Définis une fonction pour ajouter un langage au tableau

Karl a hâte d'apprendre Kotlin et Python !
Aide Karl à démarrer en définissant une méthode appelée `addLanguage` qui prend le langage qu'il veut apprendre et l'ajoute au tableau.

```java
languageList.addLanguage("Kotlin");
languageList.addLanguage("Python");
```

## 3. Définis une fonction pour retirer un langage du tableau

Karl a décidé qu'il ne voulait pas apprendre Scala pour le moment.
Aide Karl à le retirer du tableau en définissant une méthode appelée `removeLanguage` qui prend le langage qu'il retire et le supprime du tableau.

```java
languageList.removeLanguage("Scala");
```

## 4. Définis une fonction pour renvoyer le premier élément du tableau

Karl veut se souvenir du premier langage qu'il a ajouté au tableau (et qui s'y trouve encore).
Définis une méthode appelée `firstLanguage` qui renvoie le premier langage du tableau.

```java
String kotlin = languageList.firstLanguage(); // "Kotlin"
```

## 5. Définis une fonction pour renvoyer le nombre de langages présents dans le tableau

Karl a besoin de savoir combien de langages il essaie d'apprendre.
Aide Karl à trouver la réponse en définissant une méthode appelée `count` qui renvoie le nombre de langages dans le tableau.

```java
int two = languageList.count(); // 2
```

## 6. Définis une fonction pour déterminer si un langage figure dans le tableau

Karl essaie de se rappeler s'il voulait apprendre Python ou Ruby.
Définis une méthode appelée `containsLanguage` qui prend le langage sur lequel il s'interroge, pour que Karl puisse le savoir !

```java
boolean learningPython = languageList.containsLanguage("Python"); // true
boolean learningRuby = languageList.containsLanguage("Ruby"); // false
```

## 7. Définis une fonction pour déterminer si le tableau est enthousiasmant

Si Karl veut apprendre Java ou Kotlin, c'est très enthousiasmant !
Définis une méthode appelée `isExciting` qui renvoie vrai si Karl veut apprendre Java ou Kotlin.

```java
javaLanguageList.isExciting() // true
neitherKotlinNorJavaLanguageList.isExciting() // false
```
