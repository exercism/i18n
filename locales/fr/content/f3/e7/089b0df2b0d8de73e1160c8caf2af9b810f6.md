# Instructions

Un ami vient de t'envoyer un message contenant un secret important.
Comme il ne voulait pas que d'autres puissent le lire facilement, le message a été chiffré en effectuant une série de manipulations de bits.
Tu vas devoir écrire les méthodes qui permettront de déchiffrer le message.

## 1. Redécale les bits

La première étape du déchiffrement consiste à annuler le décalage effectué lors du chiffrement, en redécalant les bits vers la droite.
Les étapes suivantes du déchiffrement supposent que des 0 sont insérés par la gauche.

Implémente la méthode `Secrets.shiftBack` qui prend une valeur et le nombre de positions à décaler, et effectue le décalage.

```java
Secrets.shiftBack(0b1001, 2);
# => 0b0010
```

## 2. Active certains bits

Ensuite, certains bits doivent être mis à 1.

Implémente la méthode `Secrets.setBits` qui prend une valeur et un masque et renvoie le résultat de la mise à 1 des bits de la valeur.
Un bit de la valeur doit être mis à 1 lorsque le bit correspondant du masque vaut aussi 1.
Tous les autres bits doivent rester inchangés.

```java
Secrets.setBits(0b0110, 0b0101);
# => 0b0111
```

## 3. Inverse des bits précis

Certains bits sont inversés lors du chiffrement.
Il faudra les inverser à nouveau pour déchiffrer le message.

Implémente la méthode `Secrets.flipBits` qui prend une valeur et le masque.
Le masque indique quels bits de la valeur doivent être inversés.
Si un bit du masque vaut 1, le bit correspondant de la valeur est inversé.
Tous les autres bits restent inchangés.

```java
Secrets.flipBits(0b1100, 0b0101);
# => 0b1001
```

## 4. Efface des bits précis

Enfin, il y a aussi certains bits qui donnent toujours 0 après déchiffrement.

Implémente la méthode `Secrets.clearBits` qui prend une valeur et un masque.
Les bits de `value` doivent être mis à 0 lorsque le bit correspondant du masque vaut 1.
Tous les autres bits doivent rester inchangés.

```java
Secrets.clearBits(0b0110, 0b0101);
# => 0b0010
```
