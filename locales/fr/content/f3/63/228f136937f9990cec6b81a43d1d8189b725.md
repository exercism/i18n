# Instructions

Dans cet exercice, on va mettre en place la gestion des erreurs d'une calculatrice d'entiers simple.
La calculatrice doit prendre en charge les opérations d'addition, de multiplication et de division, et renvoyer le résultat sous la forme d'une _string_ formatée.
Tu devras aussi gérer les erreurs liées aux opérations non valides et à la division par zéro.

L'objectif est d'obtenir une calculatrice fonctionnelle qui renvoie une _string_ au format suivant :

```rust
SimpleCalculator::calculate(16, 51, "+"); // => returns "16 + 51 = 67"

SimpleCalculator::calculate(32, 6, "*"); // => returns "32 * 6 = 192"

SimpleCalculator::calculate(512, 4, "/"); // => returns "512 / 4 = 128"
```

## 1. Implémente les opérations de la calculatrice

La fonction principale de cette tâche sera `SimpleCalculator::calculate`, qui prend trois arguments : deux entiers et un `ByteArray` qui représente l'opération.
Implémente les opérations suivantes :

- **Addition** avec le symbole `+`
- **Multiplication** avec le symbole `*`
- **Division** avec le symbole `/`

## 2. Gère les opérations non valides

Si le symbole de l'opération est autre chose que `+`, `*` ou `/`, la calculatrice doit soit paniquer, soit renvoyer une erreur :

- Si l'opération est une _string_ vide, panique avec un message d'erreur `ByteArray` : `"Operation cannot be an empty string"`.
- Pour toute autre opération non valide, renvoie `Result::Err("Operation is out of range")`.

```rust
SimpleCalculator::calculate(100, 10, "-"); // => returns Result::Err("Operation is out of range")

SimpleCalculator::calculate(8, 2, ""); // => panics with "Operation cannot be an empty string"
```

## 3. Gère les erreurs de division par zéro

Lorsqu'on essaie de diviser par `0`, la calculatrice doit paniquer avec un message d'erreur indiquant que la division par zéro n'est pas autorisée.
Le résultat renvoyé doit être une valeur `felt252` égale à `'Division by zero is not allowed'`.

```rust
SimpleCalculator::calculate(512, 0, "/"); // => panics with 'Division by zero is not allowed'
```
