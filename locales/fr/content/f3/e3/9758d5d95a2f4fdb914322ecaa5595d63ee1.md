# Les mots-clés statiques de classe

Une classe est une unité d'organisation du code en PHP ; elle représente souvent une instance d'une chose, d'un service ou d'une procédure.
Grâce aux mots-clés `static` et `self`, des propriétés et des méthodes peuvent exister en référence à la classe, pour toutes les instances (ou pour aucune).

```php
<?php

class Book
{
    static $genre = 'Adventure';

    static function getGenre()
    {
        return self::$genre;
    }
}

// Usage
$genre = Book::$genre;
$genre = Book::getGenre();
```

## Limitation

Les méthodes statiques de classe ne peuvent appeler que les propriétés statiques ou les méthodes statiques de leur propre classe.
