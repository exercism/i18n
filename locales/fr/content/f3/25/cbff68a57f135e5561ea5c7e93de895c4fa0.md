# Factice

## L'option `--argjson`

Les tests utilisent l'option `--argjson n 1` de `jq`.
Elle crée une variable jq nommée `$n` qui contient la valeur _**numérique**_ `1`.

À l'inverse, l'option `--arg n 1` crée une variable jq nommée `$n` qui contient la valeur _**string**_ `"1"`.

Dans ta solution, utilise `$n` comme entrée pour obtenir le n-ième nombre premier.

Voir [Invoquer jq][man-invoke] dans le manuel.

[man-invoke]: https://jqlang.org/manual/#invoking-jq
