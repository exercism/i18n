# Instructions

Dans cet exercice, on t'a chargé d'écrire le logiciel d'un appareil de chiffrement qui fonctionne en effectuant des transformations sur des données. Tu as besoin d'un moyen de créer de manière flexible des fonctions complexes en combinant des fonctions plus simples entre elles.

Pour chaque tâche, renvoie une fonction anonyme qui peut être appelée depuis la portée de l'appel.

## 1. Crée un additionneur

Implémente `secret_add`. Elle doit renvoyer une fonction qui prend un argument et lui ajoute l'argument passé à `secret_add`.

```gleam
let adder = secret_add(2)
adder(2)
// -> 4
```

## 2. Crée un soustracteur

Implémente `secret_subtract`. Elle doit renvoyer une fonction qui prend un argument et soustrait à cet argument le secret passé à `secret_subtract`.

```gleam
let subtractor = secret_subtract(2)
subtractor(3)
// -> 1
```

## 3. Crée un multiplicateur

Implémente `secret_multiply`. Elle doit renvoyer une fonction qui prend un argument et le multiplie par le secret passé à `secret_multiply`.

```gleam
let multiplier = secret_multiply(7)
multiplier(3)
// -> 21
```

## 4. Crée un diviseur

Implémente `secret_divide`. Elle doit renvoyer une fonction qui prend un argument et le divise par le secret passé à `secret_divide`.

```gleam
let divider = secret_divide(3)
divider(32)
// -> 10
```

## 5. Crée un combinateur de fonctions

Implémente `secret_combine`. Elle doit renvoyer une fonction qui prend un argument et lui applique, dans l'ordre, les deux fonctions passées à `secret_combine`.

```gleam
let multiply = secret_multiply(7)
let divide = secret_divide(3)
let combined = secret_combine(multiply, divide)

combined(6)
// -> 14
```
