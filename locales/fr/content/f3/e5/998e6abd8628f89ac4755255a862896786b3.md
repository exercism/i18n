# Introduction

## Binaires

Elixir offre une syntaxe élégante pour manipuler des données binaires, comme on l'a vu avec la forme spéciale `<<>>` fournie pour travailler avec les [_bitstrings_][exercism-bitstrings].

Le type binaire est une spécialisation du type _bitstring_. Là où un _bitstring_ peut être de n'importe quelle longueur (n'importe quel nombre de [bits][wiki-bit]), un binaire est une donnée dont le nombre de bits est divisible par 8. Autrement dit, quand on travaille avec des binaires, on raisonne souvent en [octets][wiki-byte] (8 bits). Un octet peut représenter des nombres entiers de `0` à `255`. Il est courant de manipuler des valeurs d'octets en [hexadécimal][wiki-hexadecimal], `0x00 - 0xFF`.

Les littéraux binaires se définissent à l'aide de la forme spéciale `<<>>`. Pour définir un littéral binaire, on peut utiliser des littéraux entiers et des littéraux _string_. Les valeurs entières supérieures à 255 débordent et seuls les 8 derniers bits de l'entier sont utilisés. Par défaut, le modificateur `::binary` est appliqué à la valeur. On peut concaténer des binaires avec l'opérateur `<>/2`.

```elixir
<<255>> == <<0xFF>>
# Overflowing bits are truncated
<<256>> == <<0>>
<<2, 4, 6, 8, 10, 12, 14, 16>> == <<0x02, 0x04, 0x06, 0x08, 0x0A, 0x0C, 0x0E, 0x10>>
```

Un _octet nul_ est un autre nom pour `<<0>>`.

### Filtrage par motif sur des données binaires

Le [filtrage par motif][exercism-pattern-matching] s'étend même aux binaires, et on peut appliquer un motif à une partie des données binaires, un peu comme on le ferait pour une liste.

```elixir
# Ignore the first 8 bytes, match and bind the remaining to `body`
<<_::binary-size(8), body::binary>>
```

Comme pour les autres formes de filtrage par motif, on peut s'en servir dans la signature d'une fonction pour choisir parmi plusieurs clauses.
