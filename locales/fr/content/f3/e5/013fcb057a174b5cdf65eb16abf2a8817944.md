# Indices

## 1. Crée une liste vide

Créer une liste vide revient à créer une liste avec des éléments. On peut le faire avec `list`, ou avec `quote` sur une liste vide.

## 2. Ajoute un nouveau langage à la liste

Clojure a une fonction de base qui permet d'[ajouter un élément au début d'une liste](https://clojuredocs.org/clojure.core/cons).

## 3. Vérifie le dernier langage ajouté

Comme les autres Lisp, Clojure a une fonction qui [renvoie le premier élément d'une liste](https://clojuredocs.org/clojure.core/first).

## 4. Retire le premier langage de la liste

De même, Clojure a aussi une fonction pour [renvoyer une liste dont le premier élément a été retiré](https://clojuredocs.org/clojure.core/rest).

## 5. Compte les langages dans la liste

Une fonction de base de Clojure permet de renvoyer facilement le [nombre d'éléments](https://clojuredocs.org/clojure.core/count) d'une liste.

## 6. Assemble le tout

Rappelle-toi que les appels de fonction peuvent être imbriqués.
