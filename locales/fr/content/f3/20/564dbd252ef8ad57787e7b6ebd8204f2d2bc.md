# Instructions

Dans cet exercice, tu vas traiter des lignes de _log_.

Chaque ligne de _log_ est une _string_ au format suivant : « [<LEVEL>]: <MESSAGE>* ».

## 1. Récupère le message d'une ligne de _log_

Implémente la fonction `LogLevels.message()` pour renvoyer le message d'une ligne de _log_, en retirant les espaces au début et à la fin.

## 2. Récupère le niveau de _log_ d'une ligne de _log_

Implémente la fonction `LogLevels.logLevel()` pour renvoyer le niveau de _log_ d'une ligne de _log_, en minuscules.

## 3. Reformate une ligne de _log_

Implémente la méthode `LogLevels.reformat()` qui prend une ligne de _log_ et une _string_ de localisation, et qui la reformate en un message contenant deux lignes.
La première ligne est au format `<LEVEL>@<LOCATIOON>:`, où :

* `<LEVEL>` est le niveau de _log_ en minuscules (comme dans la tâche 2, « Récupère le niveau de _log_ d'une ligne de _log_ »).
* `<LOCATION>` est la localisation fournie en deuxième paramètre.

La deuxième ligne contient exactement deux espaces, suivis du message de _log_ (comme dans la tâche 1, « Récupère le message d'une ligne de _log_ ») :

```kotlin
reformat("[TRACE]: Start of function", 2, 8)
// => "trace@208:
  Start of function"
```
