# Introduction

Le flux de contrôle en Cairo permet de contrôler le chemin d'exécution des programmes en fonction de conditions et de répétitions.

## Exécution conditionnelle

Utilise des expressions `if` pour exécuter du code en fonction de conditions :

```rust
let number = 42;
if number > 0 {
    println!("Positive number");
} else if number < 0 {
    println!("Negative number");  
} else {
    println!("Zero");
}
```

`if` est une expression, elle peut donc renvoyer des valeurs :

```rust
let result = if condition { 5 } else { 10 };
```

## Boucles

Utilise `loop` pour répéter du code.
Une boucle s'exécute indéfiniment tant que tu ne l'arrêtes pas ; utilise `break` pour sortir de la boucle quand une condition est remplie.

```rust
let mut counter = 0;
loop {
    if counter == 5 {
        break;
    }
    println!("Counter: {}", counter);
    counter += 1;
}
```

Les boucles peuvent renvoyer des valeurs avec `break` :

```rust
let result = loop {
    counter += 1;
    if counter == 10 {
        break counter * 2; // Returns 20
    }
};
```

Utilise `continue` pour passer à l'itération suivante :

```rust
let mut i = 0;
loop {
    i += 1;
    if i % 2 == 0 {
        continue; // Skip even numbers
    }
    if i > 10 {
        break;
    }
    println!("{}", i); // Only prints odd numbers
}
```
