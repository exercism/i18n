# Concepts nécessaires pour l'exercice Macros

Il existe de nombreuses façons de résoudre un exercice, mais je vais me pencher sur [l'exemple canonique](https://github.com/exercism/rust/blob/666c366fc0d39d9f6fd8e837facea8afe2153ae2/exercises/macros/example.rs) comme référence principale pour déterminer quels concepts sont utilisés.

Quand on parle de la liste des concepts, on entend [cette liste](https://github.com/exercism/v3/blob/master/languages/rust/reference/README.md)

Note que, pour les exercices d'apprentissage comme pour les exercices d'entraînement, la liste des concepts prérequis doit être aussi courte que possible. Le but ici n'est pas d'énumérer tous les concepts qui peuvent être utilisés dans toutes les approches possibles du problème ; il s'agit d'énumérer l'ensemble minimal de connaissances avec lesquelles un apprenant déterminé pourrait raisonnablement résoudre le problème.

Note que cet exercice deviendra très probablement un exercice d'apprentissage pour le concept « Écriture de macros déclaratives ».

## Concepts requis

### Existants

- structs
- (im)mutabilité
- `Hashmap<K, V>`

### À ajouter

- affectation de variable (partie de `fundamentals`)
- portée des variables / espaces de noms (partie de `fundamentals`)
- méthodes et fonctions associées (dépend de `structs`)
