# Introduction

La principale construction orientée objet en Java est la _classe_, qui combine des données (_champs_) et un comportement (_méthodes_). Les champs et les méthodes d'une classe sont appelés ses _membres_.

L'accès aux membres peut être contrôlé au moyen de modificateurs d'accès, dont les deux plus courants sont :

- `public` : le membre est accessible depuis n'importe quel code (aucune restriction).
- `private` : le membre n'est accessible que depuis le code de la même classe.

On peut voir une classe comme un modèle servant à créer des instances de cette classe.
Pour créer une instance d'une classe (aussi appelée _objet_), on utilise le mot-clé `new` :

```java
class Car {
}

// Create two car instances
Car myCar = new Car();
Car yourCar = new Car();
```

Les champs ont un type et un nom (défini en `camelCase`) et peuvent être définis n'importe où dans une classe (par convention, en `PascalCase`) :

```java
class Car {
    // Accessible by anyone
    public int weight;

    // Only accessible by code in this class
    private String color;
}
```

Il est possible d'affecter une valeur initiale à un champ.
Si un champ ne précise pas de valeur initiale, il prend la valeur par défaut de son type.
Les valeurs des champs d'une instance peuvent être lues et mises à jour à l'aide de la notation pointée.

```java
class Car {
    // Will be set to specified value
    public int weight = 2500;

    // Will be set to default value (0)
    public int year;
}

Car newCar = new Car();
newCar.weight; // => 2500
newCar.year;   // => 0

// Update value of the field
newCar.year = 2018;
```

Les champs privés sont généralement mis à jour par effet de bord lors de l'appel d'une méthode.
Ces méthodes ne renvoient généralement aucune valeur, auquel cas le type de retour doit être `void` :

```java
class CarImporter {
    private int carsImported;

    public void importCars(int numberOfCars)
    {
        // Update private field from public method
        carsImported = carsImported + numberOfCars;
    }
}
```
