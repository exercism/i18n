# À propos des bases

Le concept Les bases a introduit [Go](https://golang.org) en tant que langage de programmation compilé et à typage statique.
Le langage est souvent appelé Golang en raison de son ancien nom de domaine, golang.org, mais son nom officiel est Go.

Le concept Les bases présente trois caractéristiques majeures du langage : les paquets, les fonctions et les variables.

## Paquets

Les applications Go sont organisées en paquets.
Un paquet est un ensemble de fichiers sources situés dans le même répertoire.
Tous les fichiers sources d'un répertoire doivent partager le même nom de paquet.
Par convention, le nom du paquet correspond au dernier répertoire du chemin d'import.
Par exemple, les fichiers du [paquet « math/rand »](https://golang.org/src/math/rand/) commencent par l'instruction `package rand`.
Lorsqu'un paquet est importé, seules les entités (fonctions, types, variables, constantes) dont le nom commence par une lettre majuscule peuvent être utilisées ou accessibles.
Le style de nommage recommandé en Go est d'utiliser le `camelCase` pour les identifiants, sauf pour ceux destinés à être accessibles depuis d'autres paquets, qui doivent utiliser le `PascalCase`.

```go
package lasagna
```

## Variables

Go est à typage statique, ce qui signifie que toutes les variables [doivent avoir un type défini](https://en.wikipedia.org/wiki/Type_system) à la compilation.

On peut définir des variables en spécifiant explicitement un type :

```go
var explicit int // Explicitly typed
```

On peut aussi utiliser un initialiseur, et le compilateur attribuera à la variable un type correspondant à celui de l'initialiseur.

```go
implicit := 10   // Implicitly typed as an int
```

Une fois déclarées, les variables peuvent se voir affecter des valeurs à l'aide de l'opérateur `=`.
Une fois déclarée, le type d'une variable ne peut plus jamais changer.

```go
count := 1 // Assign initial value
count = 2  // Update to new value

count = false // This throws a compiler error due to assigning a non `int` type
```

## Constantes

Les constantes contiennent une donnée comme les variables, mais leur valeur ne peut pas changer pendant l'exécution du programme.

Les constantes sont définies à l'aide du mot-clé `const` et peuvent être des nombres, des caractères, des _strings_ ou des booléens :

```go
const Age = 21 // Defines a numeric constant 'Age' with the value of 21
```

## Fonctions

Les fonctions Go acceptent zéro ou plusieurs paramètres.
Les paramètres doivent être explicitement typés, il n'y a pas d'inférence de type.

Les valeurs sont renvoyées par les fonctions à l'aide du mot-clé `return`.

Une fonction est invoquée en spécifiant le nom de la fonction et en passant des arguments pour chaque paramètre de la fonction.

Notez que Go prend en charge deux types de commentaires.
Les commentaires sur une seule ligne sont précédés de `//` et les commentaires multilignes sont insérés entre `/*` et `*/`.

```go
package greeting

// Hello is a public function.
func Hello (name string) string {
    return hi(name)
}

// hi is a private function.
func hi (name string) string {
    return "hi " + name
}
```
