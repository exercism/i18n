# Installation


## Installe GHCup

La façon recommandée d'installer les outils Haskell passe par [GHCup][ghcup].

Avec GHCup, on peut gérer les compilateurs installés, les gestionnaires de projet et de paquets, ainsi que le serveur de langage.


## Installe Stack

Pour faire les exercices Exercism, tu n'as besoin que de Stack.

Pour installer Stack, lance la commande ou le script d'installation de GHCup.
Suis les valeurs par défaut, mais indique que tu souhaites aussi installer Stack.

Tu as sauté l'installation de Stack par inadvertance ?
Pas de panique : il te suffit de lancer `ghcup install stack` ensuite.

GHCup va installer

- **Un compilateur** (GHC : le Glasgow Haskell Compiler)

  À proprement parler, tu n'en as pas besoin pour Exercism, mais il est bien utile quand tu veux jouer avec [GHCi][ghc-guide-ghci] en dehors des répertoires d'exercices.

- **Cabal**

  Un gestionnaire de projet et de paquets.
  Tu n'en as pas besoin pour Exercism.

- **Stack**

  Le gestionnaire de projet et de paquets que tu utiliseras pour Exercism.
  Il s'assure que tu disposes du bon compilateur et des bonnes bibliothèques pour chaque projet (exercice) pris individuellement.

Pour vérifier que l'installation s'est bien passée, lance l'une ou l'autre de ces commandes :

- `ghcup list` : en cas de succès, tu obtiens une longue liste de versions d'outils, avec Stack marqué comme installé
- `stack --version` : en cas de succès, tu obtiens quelque chose comme `Version 2.7.5, Git revision ...`


## Obtiens la bonne version de GHC

Stack télécharge et installe automatiquement GHC lorsqu'il en a besoin.
Tu peux lancer l'installation et vérifier en exécutant les commandes suivantes dans un terminal :

```bash
# Note: it only makes sense to run Stack
# inside projects, so navigate into an
# exercise directory first!
exercism download --exercise=hello-world --track=haskell
cd ~/Exercism/haskell/hello-world
stack ghc -- --version
```

Si cela affiche quelque chose comme

```
The Glorious Glasgow Haskell Compilation System, version 8.8.4
```

alors GHC est correctement installé.


## Configure ton éditeur pour travailler avec Haskell

La prise en charge de Haskell est assurée par le Haskell Language Server (HLS).
Cette prise en charge n'est pas obligatoire, mais elle est vivement recommandée.


### Visual Studio Code (recommandé)

Il te suffit de récupérer l'[extension Haskell pour Visual Studio Code][vscode-haskell].
Elle utilisera GHCup pour installer HLS automatiquement, après quoi tout sera prêt.

**Remarque :** avec des exercices fraîchement téléchargés, HLS peut avoir du mal à démarrer.
Si cela se produit, lance `stack test` puis redémarre le serveur de langage.


### Autres éditeurs

Consulte la [documentation de HLS sur la configuration de l'éditeur][hls-editor-config].
Il se peut que tu doives installer HLS manuellement.
Pour cela, lance `ghcup install hls`.
