## 1. Définis une structure Size

Définis une structure nommée `Size` avec deux propriétés `Int`, `width` et `height`, qui stockent respectivement la largeur et la hauteur actuelles de la fenêtre.
La largeur et la hauteur initiales doivent être de 80 et 60, respectivement.
Ajoute une méthode `resize(newWidth:newHeight:)` qui prend en paramètres une nouvelle largeur et une nouvelle hauteur, et qui modifie les propriétés pour refléter la nouvelle taille.

```swift
let size1080x764 = Size(width: 1080, height: 764)
// Returns Size
var size1200x800 = size1080x764
// Returns Size
size1200x800.resize(newWidth: 1200, newHeight: 800)
size1200x800.height
// Returns 800
```

## 2. Définis une structure Position

Définis une structure nommée `Position` avec deux propriétés `Int`, `x` et `y`, qui stockent respectivement la position horizontale et la position verticale actuelles du coin supérieur gauche de la fenêtre.
Les valeurs initiales de x et de y doivent chacune être 0. La position (0, 0) correspond au coin supérieur gauche de l'écran : les valeurs de `x` augmentent quand on va vers la droite, et celles de `y` augmentent quand on descend.

Ajoute une méthode `moveTo(newX:newY:)` qui prend en paramètres une nouvelle valeur de x et une nouvelle valeur de y, et qui modifie les propriétés pour refléter la nouvelle position.

```swift
var point = Position(x: 10, y: 20)
// Returns Position
point.moveTo(newX: 100, newY: -100)
point.y
// Returns -100
```

## 3. Définis une classe Window

Définis une classe de fenêtre avec les propriétés suivantes :

- `title` : `String`, la valeur initiale est "New Window"
- `screenSize` : `Size`, une valeur constante avec `width` = 800 et `height` = 600
- `size` : `Size`, la valeur initiale est la valeur par défaut de la structure `Size`
- `position` : `Position`, la valeur initiale est la valeur par défaut de la structure `Position`
- `contents` : `String?`, la valeur initiale est `nil`

Tu dois aussi définir un initialiseur vide pour la classe.

```swift
let window = Window()
window.title
// Returns "New Window"
```

## 4. Ajoute une méthode pour redimensionner les fenêtres

- `resize(to:)` : `(Size) -> ()` - Cette méthode prend une structure `Size` en entrée et tente de redimensionner la fenêtre à la taille demandée. Cependant, la nouvelle taille ne peut pas dépasser certaines limites.
- La hauteur ou la largeur minimale autorisée est 1.
  Toute hauteur ou largeur demandée inférieure à 1 sera ramenée à 1.
- La hauteur et la largeur maximales dépendent de la position actuelle de la fenêtre, car les bords de la fenêtre ne peuvent pas dépasser ceux de l'écran.
  Les valeurs supérieures à ces limites seront ramenées à la plus grande taille possible.
  Par exemple, si la fenêtre est positionnée à `x` = 400, `y` = 300 et qu'un redimensionnement à `height` = 400, `width` = 300 est demandé, alors la fenêtre sera redimensionnée à `height` = 300, `width` = 300, car l'écran n'est pas assez grand dans la direction `y` pour satisfaire entièrement la demande.

## 5. Ajoute une méthode pour déplacer les fenêtres

- `move(to:)` : `(Position) -> ()` - C'est similaire à `resize(to:)`, sauf que cette méthode ajuste la _position_ de la fenêtre à la valeur demandée, plutôt que sa taille. Comme pour `resize`, la nouvelle position ne peut pas dépasser certaines limites.
- La plus petite position est 0 pour `x` comme pour `y`.
- La position maximale dans chaque direction dépend de la taille actuelle de la fenêtre ; les bords ne peuvent pas dépasser ceux de l'écran.
  Les valeurs supérieures à ces limites seront ramenées à la plus grande taille possible. Par exemple, si la fenêtre est positionnée à `x` = 250, `y` = 100 et qu'un déplacement à `x` = 600, `y` = 200 est demandé, alors la fenêtre sera déplacée à `x` = 550, `y` = 200, car l'écran n'est pas assez grand dans la direction `x` pour satisfaire entièrement la demande.

## 6. Ajoute des méthodes pour mettre à jour le texte de la fenêtre et afficher les informations de la fenêtre

- `update(title:)` : `(String) -> ()` - Cette méthode affecte à la propriété `title` la valeur de la _string_ passée en argument.
- `update(text:)` : `(String?) -> ()` - Cette méthode affecte à la propriété `contents` la valeur de la _string_ optionnelle passée en argument.
- `display()` : `() -> String` - Cette méthode renvoie une _string_ décrivant l'état actuel de la fenêtre. Par exemple, si la fenêtre a pour `title` "My First Window" avec pour position : x = 10, y = 100 ; pour taille : width = 200, height = 150 ; et pour contents : "I 😍 my window", elle doit renvoyer la _string_ : `"My First Window\nPosition: (10, 100), Size: (200 x 150)\nI 😍 my window\n"` - Si `contents` vaut `nil`, la dernière ligne doit être "[This window intentionally left blank]"

## 7. Crée un initialiseur pour la classe Window

Le système de fenêtres doit disposer d'un initialiseur pour que l'on puisse créer une fenêtre avec des entrées personnalisées.
Crée un **autre** initialiseur pour la classe `Window`.
Cet initialiseur doit prendre les paramètres suivants : `title`, `contents`, ainsi que deux paramètres optionnels `size` et `position`.
Les paramètres `size` et `position` doivent prendre par défaut les valeurs par défaut des structures `Size` et `Position`.

```swift
let window = Window(title: "My First Window", contents: "I 😍 my window")
window.display()
// Returns "My First Window\nPosition: (0, 0), Size: (80 x 60)\nI 😍 my window\n"

let window2 = Window(title: "My Second Window", contents: "I 😍 my window", size: Size(width: 200, height: 150), position: Position(x: 10, y: 100))
window2.display()
// Returns "My Second Window\nPosition: (10, 100), Size: (200 x 150)\nI 😍 my window\n"
```
