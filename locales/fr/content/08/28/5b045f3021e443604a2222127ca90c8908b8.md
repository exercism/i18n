# À propos

En Go, on peut comparer des valeurs à l'aide des opérateurs d'égalité et d'ordre.
Il existe 6 de ces opérateurs :

| Comparaison       | Opérateur |
| ------------------| --------- |
| égal à            | `==`      |
| différent de      | `!=`      |
| inférieur à       | `<`       |
| inférieur ou égal à | `<=`    |
| supérieur à       | `>`       |
| supérieur ou égal à | `>=`    |

Le résultat d'une comparaison est toujours une valeur booléenne :

```go
a := 3

a != 4 // true
a > 5  // false
```

## Opérateurs d'égalité

Les opérateurs d'égalité `==` et `!=` vérifient respectivement si une valeur est égale à une autre ou non.
On peut utiliser les opérateurs d'égalité sur la plupart des types en Go.
Voici quelques exemples courants :

```go
2 == 3 // false, integer comparison

2.1 != 2.2 // true, float comparison 

"hello" == "hello" // true, string comparison

'a' != 'b' // true, rune/byte comparison
```

## Opérateurs d'ordre

Les opérateurs d'ordre vérifient si une valeur est supérieure à (`>`), supérieure ou égale à (`>=`), inférieure à (`<`) ou inférieure ou égale à (`<=`) une autre valeur.
Ce type de comparaison est disponible pour les nombres, les bytes, les runes et les _strings_.
Quand on compare des _strings_, c'est l'ordre alphabétique (aussi appelé ordre lexicographique) qui est suivi.

```go
2 > 3 // false, integer comparison

1.2 < 1.3 // true, float comparison

'a' > 'b' // false, rune/byte comparison

"Hello" < "World" // true, string comparison
```
