# Instructions

Implémente les opérations de base sur les tableaux.

Dans les langages fonctionnels, les opérations sur les tableaux comme `length`, `map` et `reduce` sont très courantes.
Implémente une série d'opérations de base sur les tableaux, sans utiliser les fonctions existantes.

Le nombre et les noms exacts des opérations à implémenter dépendent du parcours, pour éviter les conflits avec les noms existants, mais les opérations générales que tu vas implémenter comprennent :

- `append` (*étant donné deux tableaux, ajoute tous les éléments du second tableau à la fin du premier*) ;
- `concatenate` (*étant donné une série de tableaux, combine tous les éléments de tous les tableaux en un seul tableau aplati*) ;
- `filter` (*étant donné un prédicat et un tableau, renvoie le tableau de tous les éléments pour lesquels `predicate(item)` est vrai*) ;
- `length` (*étant donné un tableau, renvoie le nombre total d'éléments qu'il contient*) ;
- `map` (*étant donné une fonction et un tableau, renvoie le tableau des résultats de l'application de `function(item)` à tous les éléments*) ;
- `foldl` (*étant donné une fonction, un tableau et un accumulateur initial, replie (réduit) chaque élément dans l'accumulateur depuis la gauche avec `function(accumulator, item)`*) ;
- `foldr` (*étant donné une fonction, un tableau et un accumulateur initial, replie (réduit) chaque élément dans l'accumulateur depuis la droite avec `function(item, accumulator)`*) ;
- `reverse` (*étant donné un tableau, renvoie un tableau avec tous les éléments d'origine, mais dans l'ordre inverse*) ;
