# Introduction

Pyret possède deux primitives booléennes distinctes, `true` et `false`.
Ces deux valeurs indiquent si une assertion ou une condition est vraie ou non.

```pyret
"a" == "a" # true
"a" == "b" # false
```

Pyret fournit les opérateurs `and` et `or`, qui permettent de combiner des valeurs booléennes.

L'opérateur `and` renvoie vrai si les deux côtés sont vrais et faux dans tous les autres cas.

```pyret
true and true # true
true and false # true
false and true # false
false and false # false
```

L'opérateur `or` renvoie vrai si au moins un des côtés est vrai, et faux si les deux côtés sont faux.

```pyret
true or true # true
true or false # true
false or true # true
false or false # false
```

`not()` est une fonction intégrée qui transforme une valeur vraie en fausse, ou une valeur fausse en vraie.

```pyret
not(true) # false
not(false) # true
```
