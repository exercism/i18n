# À propos

Le type booléen en Lua prend les deux valeurs booléennes traditionnelles : `true` et `false`. Ces valeurs peuvent être affectées à une variable, combinées avec des opérateurs logiques (`and`, `or`, `not`) et utilisées dans des tests conditionnels (par exemple dans des structures de contrôle).

```lua
local is_true = true
local is_false = false

true and true  --> true
true and false --> false
false or true  --> true
false or false --> false
not false      --> true
not true       --> false

-- prints 0
if is_true == true then
  print(0)
else
  print(1)
end
```

Les tests conditionnels et les opérateurs logiques considèrent le booléen `false` et `nil` comme faux, et tout le reste comme vrai.
```lua
1 and 2          --> 2
nil and 2        --> nil
false and 2      --> false
1 or 2           --> 1
false or 'hello' --> "hello"
nil or false     --> false
```

`and` et `or` utilisent tous les deux une *évaluation en court-circuit*, ce qui signifie qu'ils n'évaluent leur second opérande que lorsque c'est nécessaire. Toutes les opérations sont évaluées selon la [précédence des opérateurs](https://www.lua.org/manual/5.4/manual.html#3.4.8), où `not` est évalué avant `and` et `or`.

Étant donné que seuls `false` et `nil` sont considérés comme faux et que tout le reste est vrai, un idiome courant en Lua est le suivant :
```lua
x = x or y
```

Ce qui est équivalent à :
```lua
if not x then
  x = y
end
```

Il est assez courant d'utiliser ceci dans les fonctions, pour affecter une valeur par défaut lorsqu'un paramètre n'a pas de valeur (vaut `nil`) :
```lua
local function hello(name)
  name = name or "World"
  print("Hello " .. name)
end

hello()       --> "Hello World"
hello('Mars') --> "Hello Mars"
```
