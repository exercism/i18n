# Utilise l'interpolation de _string_ plutôt que la concaténation de _strings_

Utilise l'[interpolation de _string_](https://csharp.net-tutorials.com/operators/the-string-interpolation-operator/) pour construire dynamiquement une _string_, plutôt que la concaténation de _strings_. Le principal avantage, c'est qu'il y a moins de « bruit » ; là où la concaténation de _strings_ demande d'ajouter un `+` entre chaque _string_, l'interpolation de _string_ n'a pas cette contrainte. Résultat : le code qui utilise l'interpolation de _string_ est généralement un peu plus facile à lire.
