# À propos

ColdFusion (CFML) est un langage de script pour la JVM dont la syntaxe est proche de celle de C ou de JavaScript.  
Il se compile à la volée (JIT) en bytecode qui s'exécute sur la JVM, mais il reste dynamique et faiblement typé, ce qui rend le développement rapide et simple.  
CF est un langage multi-paradigme, qui prend en charge la POO classique et la programmation fonctionnelle.

CFML dispose aussi d'un langage de gabarits à base de balises intégré, ce qui le rend idéal pour les applications web.  
Il s'exécute dans un conteneur J2EE avec de nombreuses bibliothèques intégrées qui le rendent très productif, sans avoir besoin d'installer une multitude de paquets.  
CFML prend en charge nativement les fichiers zip, la génération de PDF et de fichiers Excel, les e-mails, FTP, HTTP, les systèmes de fichiers S3, les bibliothèques de sécurité ESAPI, les pilotes JDBC, JSON et les API REST.  

CFML peut aussi tirer parti de n'importe quel projet Java en déposant les JAR dans le projet et en instanciant directement des objets Java dans le code.  
Pour en savoir plus sur la syntaxe de base et les types de données de première classe, consulte ce guide : [Modern ColdFusion (CFML) in 100 Minutes](https://modern-cfml.ortusbooks.com/)
