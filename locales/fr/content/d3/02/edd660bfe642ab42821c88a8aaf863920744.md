# Introduction

Les méthodes peuvent avoir un paramètre _varargs_, qui permet à l'appelant de fournir zéro ou plusieurs arguments comme s'il s'agissait de paramètres ordinaires. La méthode reçoit ces arguments dans un seul tableau.

Pour transformer un paramètre en paramètre _varargs_, ajoute le mot-clé `params` à la déclaration du paramètre :

```csharp
public static void PrintNumbers(params int[] numbers)
{
    foreach (var number in numbers)
    {
        Console.Write(number)
    }
}

// No values for a varags parameter is allowed
PrintNumbers();

PrintNumbers(1);
// => 1

PrintNumbers(1, 2, 3);
// => 123
```
