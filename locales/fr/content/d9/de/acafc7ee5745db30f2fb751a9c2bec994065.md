# Introduction

## Constantes

En Gleam, les constantes permettent de donner un nom à des valeurs. On les définit avec le mot-clé `const`.

```gleam
pub const pi: Float = 3.14159

pub fn circle_area(radius: Float) -> Float {
  radius *. radius *. pi
}
```

Lorsqu'elles sont définies avec le mot-clé `pub`, les constantes de module sont accessibles depuis d'autres modules ; sinon, elles ne sont accessibles que depuis le module dans lequel elles sont définies.

## Ordres

Le module `gleam/order` de la bibliothèque standard de Gleam contient le type `Order`, qui sert à comparer des valeurs.

La définition de `Order` ressemble à ceci :

```gleam
pub type Order {
  Gt
  Eq
  Lt
}
```

Ce type prend trois variantes, chacune servant à représenter la relation entre une valeur et une autre valeur :

- `Gt` : la valeur est _supérieure_ à l'autre valeur.
- `Eq` : la valeur est _égale_ à l'autre valeur.
- `Lt` : la valeur est _inférieure_ à l'autre valeur.

Si un type de données peut être comparé par taille, il est courant que le module définisse une fonction `compare` qui renvoie une valeur `Order`. Par exemple, `gleam/float` et `gleam/int` définissent des fonctions `compare` qui opèrent respectivement sur les nombres flottants et les entiers.

```gleam
int.compare(1, 2)
// -> Lt

int.compare(2, 2)
// -> Eq

float.compare(1.0, 2.0)
// -> Lt
```

Les fonctions de tri, comme `list.sort`, prennent souvent une fonction qui renvoie une valeur `Order`, ce qui permet à l'appelant de définir comment la liste doit être triée.

```gleam
list.sort([3, 7, 3, 1], by: int.compare)
// -> [1, 3, 3, 7]
```
