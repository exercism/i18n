# Installation

Tu as besoin de [Vim](http://www.vim.org) pour faire les exercices :

- [macOS](#macos)
- [Ubuntu / Debian](#ubuntu--debian)
- [Windows](#windows)
- [Source](#source)

## macOS

Le système d'exploitation est livré avec Vim par défaut, mais c'est une version désespérément obsolète.

Tu utilises probablement [MacPorts](https://www.macports.org) ou [Homebrew](https://brew.sh) pour installer des logiciels.

Homebrew :

```
$ brew update
$ brew install vim
```

MacPorts :

```
$ sudo port install vim +huge
```

Si tu veux une interface graphique, jette plutôt un œil à [MacVim](https://macvim-dev.github.io/macvim).

## Ubuntu / Debian

Installe un Vim complet avec prise en charge de l'interface graphique (`gvim`) :

```
$ sudo apt-get update
$ sudo apt-get install vim-gtk
```

## Windows

Avec [Chocolatey](https://chocolatey.org) :

```
C:\> choco install vim
```

Ou télécharge et installe-le directement depuis [ce lien](http://www.vim.org/download.php#pc).

## Source

Si tu veux compiler toi-même le dernier Vim, jette un œil au [dépôt officiel sur GitHub](https://github.com/vim/vim).
