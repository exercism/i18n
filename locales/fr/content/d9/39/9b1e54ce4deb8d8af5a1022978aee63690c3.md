# À propos

## Les inclusions

Pour inclure le contenu d'autres fichiers, C++ utilise la directive `include`.
Ces inclusions doivent figurer en haut du fichier.
Lors de la compilation, la ligne contenant la directive est remplacée par le contenu du fichier correspondant.
Après l'inclusion, les espaces de noms sont conservés tels qu'ils sont dans le fichier d'origine.

## La bibliothèque standard

La bibliothèque standard propose de nombreuses fonctions, algorithmes et structures de données courants.
Elle utilise l'espace de noms `std`.

Prenons l'exemple de la bibliothèque de calcul numérique de C, `cmath`.
Elle fournit de nombreuses opérations mathématiques courantes.

```cpp
#include <cmath>

int cube_me(int a) {
    // raise `a` to the third power
    return std::pow(a, 3);
}
```

~~~~exercism/note
Les bibliothèques standard s'incluent avec des chevrons `<>` plutôt qu'avec des guillemets `"`.
La différence tient à l'endroit où le compilateur cherche les fichiers correspondants.
Avec la version entre chevrons, la recherche dans le projet courant est ignorée et commence directement dans les répertoires d'inclusion du système.
Si tu veux inclure des fichiers locaux, utilise des guillemets doubles : `#include "myfile"`
~~~~
