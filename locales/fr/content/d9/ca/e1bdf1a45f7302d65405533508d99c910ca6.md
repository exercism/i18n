# Introduction

Un *mot générique* déclare une opération qui peut avoir différentes implémentations selon la classe de son argument. On ajoute des méthodes avec `M:`.

```factor
USING: kernel math ;

GENERIC: area ( shape -- n )

TUPLE: square side ;
TUPLE: circle radius ;

M: square area side>> dup * ;
M: circle area radius>> dup * 3.14159 * ;
```

```factor
T{ square { side 4 } } area .    ! => 16
T{ circle { radius 2 } } area .  ! => 12.56636
```

`GENERIC:` déclare le mot et son effet de pile. `M:` définit une méthode sur une classe précise. À l'exécution, Factor sélectionne la méthode à exécuter selon la classe de l'argument au sommet de la pile.

On peut demander au mot générique pour quelles classes il possède des méthodes, et ajouter ou retirer des méthodes après coup. Il n'y a pas de syntaxe d'héritage particulière : n'importe quelle classe de tuple peut automatiquement recevoir des méthodes.
