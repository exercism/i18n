# Introduction

Un vecteur est un tableau à une dimension.
Il peut contenir des éléments de types différents.

## Créer des vecteurs

On peut créer des vecteurs avec la fonction `vector` ou à l'aide de sa forme de lecture `#()`

```lisp
(vector 1 t "foo" 'b) ; => #(1 T "foo" B)
#(2 nil "bar" a)      ; => #(2 NIL "bar" A)
```

Comme ce sont des tableaux, on peut aussi les créer avec `make-array` :

```lisp
(make-array 3 :initial-element 'x)        ; => #(X X X)
(make-array 3 :initial-contents '(a b c)) ; => #(A B C)
```

## Prédicat de vecteur

Pour vérifier qu'un objet est un vecteur, il suffit d'utiliser le prédicat `vectorp`.

## Accéder aux éléments

Pour accéder aux éléments d'un vecteur, utilise `aref` ; les indices commencent à zéro :

```lisp
(aref #(1 2 3) 1) ; => 2
(aref #(a b c) 0) ; => A
```
