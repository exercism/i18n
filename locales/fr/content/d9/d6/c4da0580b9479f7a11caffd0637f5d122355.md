# Indices

## Généralités

- `unparse` se trouve dans [`prettyprint`][prettyprint] ; les variantes de _slice_ se trouvent dans [`sequences`][sequences] ; la famille _cleave_ à entrées multiples se trouve dans [`combinators`][combinators].

## 1. Mets une valeur entre guillemets

- Un seul mot : `unparse`.

## 2. Retire l'encadrement du drapeau

- Retire le marqueur initial avec `1 tail-slice`, puis retire le marqueur final avec `1 head-slice*`.

## 3. Découpe un drapeau

- `head-slice` et `tail-slice` ont tous les deux besoin du drapeau *et* de la longueur d'en-tête sur la pile. C'est `[ head-slice ] [ tail-slice ] 2bi`.

## 4. Triangule à partir de deux relevés

- Trois _quotations_ différentes, chacune prenant les deux mêmes relevés : `[ - ] [ + 2 / ] [ / ] 2tri`.

## 5. Résume trois relevés

- Trois _quotations_ de trois entrées chacune : `3tri`. La _quotation_ qui additionne est `[ + + ]` ; le produit est `[ * * ]` ; le maximum est `[ max max ]`.
