# Introduction

En Go, on peut parcourir un `slice` avec `for` et un indice, ou bien utiliser `range`.
`range` permet aussi de parcourir une `map`.

Chaque itération renvoie deux valeurs : l'indice ou la clé, ainsi qu'une copie de l'élément situé à cet indice ou à cette clé.

## Parcours un `slice`

Simple comme bonjour : une boucle sur un slice suit l'ordre attendu.

```go
xi := []int{10, 20, 30}
for i, x := range xi {
  fmt.Println(i, x)
}
// outputs:
// 0, 10
// 1, 20
// 2, 30
```

## Parcours une `map`

Parcourir une `map` pose un nouveau problème.
L'ordre est désormais aléatoire.

```go
hash := map[int]int{9: 10, 99: 20, 999: 30}
for k, v := range hash {
  fmt.Println(k, v)
}
// outputs, for example:
// 99 20
// 999 30
// 9 10
```

~~~~exercism/note
On pourrait croire que la sortie ci-dessus est incorrecte, car on s'attendrait à ce que la première paire clé/valeur déclarée dans la map, `9 10`, soit la première affichée et non la dernière.
Cependant, les maps n'ont pas d'ordre par nature : il n'existe ni première ni dernière paire clé/valeur.
C'est pourquoi, lorsqu'on parcourt les entrées d'une map, l'ordre dans lequel elles sont visitées est aléatoire et ne suit aucun schéma particulier.
La sortie ci-dessus est donc possible, mais elle peut différer de ce que tu obtiendras si tu essaies de lancer ce code toi-même.
Pour en savoir plus, consulte [Spécification du langage Go : la clause range](https://go.dev/ref/spec#RangeClause).
~~~~

## Itération en omettant la clé ou la valeur

En Go, une variable inutilisée provoque une erreur à la compilation.
Parfois, seule la valeur nous intéresse, comme dans le premier exemple :

```go
xi := []int{10, 20, 30}
for i, x := range xi {
  fmt.Println(x)
}
// Go build failed: i declared but not used
```

Tu peux remplacer le `i` par `_`, ce qui indique au compilateur que cette valeur n'est pas utilisée :

```go
xi := []int{10, 20, 30}
for _, x := range xi {
  fmt.Println(x)
}
// outputs:
// 10
// 20
// 30
```

Si tu veux seulement afficher l'indice, tu peux remplacer le `x` par `_`,
ou simplement omettre la déclaration :

```go
xi := []int{10, 20, 30}
// for i, _ := range xi {
for i := range xi {
  fmt.Println(i)
}
// outputs:
// 0
// 1
// 2
```

## Types non-struct

Tu as déjà vu comment définir des types struct.
Il est aussi possible de définir des types non-struct, que tu peux utiliser comme alias d'un type prédéfini, et de leur ajouter des fonctions avec récepteur pour les étendre de la même façon que les types struct.

```go
type Name string
func SayHello(n Name) {
  fmt.Printf("Hello %s\n", n)
}
n := Name("Fred")
SayHello(n)
// Output: Hello Fred
```

Tu peux aussi définir des types non-struct composés de tableaux et de maps.

```go
type Names []string
func SayHello(n Names) {
  for _, name := range n {
    fmt.Printf("Hello %s\n", name)
  }
}
n := Names([]string{"Fred", "Bill"})
SayHello(n)
// Output:
// Hello Fred
// Hello Bill
```
