# Indices

## 1. Classe les clients

- Utiliser [`every()`][ref-every] avec une fonction anonyme peut être pratique.

## 2. Nomme les clients

- Traiter deux entrées en parallèle : pense à [`map2()`][ref-map2] comme approche possible.

## 3. Isole les clients emphatiques

- Les tâches précédentes t'aideront.
- Quels clients veux-tu [`keep`][ref-keep] dans la liste de sortie ?

## 4. Convertis les notes en binaire

- Il y a plusieurs façons de résoudre ce problème, mais [`if_else()`][ref-if_else] de la bibliothèque `dplyr` est peut-être le plus simple. On en a parlé dans le [concept Switch][concept-switch].
- Dans `purrr`, une autre possibilité est [`map_int()`][ref-map_int].

## 5. Calcule la moyenne des notes dans le temps

- C'est une moyenne cumulative, ce qui te donne un indice sur le nom d'une fonction utile.
- Une moyenne, c'est une somme divisée par une longueur ; on pourrait donc l'implémenter avec les fonctions de `purrr`.
  - On a vu dans l'introduction comment accumuler une somme.
  - On pourrait utiliser [`map2_dbl()`][ref-map2] pour diviser les sommes par les longueurs.
