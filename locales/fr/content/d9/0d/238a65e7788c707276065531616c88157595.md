# Supprime la fonction `main` et corrige le nom du paquet

Supprime la fonction `main`, renomme le paquet en `twofer` et lance les tests.

Une fonction `main` sert de point d'entrée à un programme. Exercism utilise le TDD ([développement piloté par les tests](http://testfirst.org/about#tdd)).
Autrement dit, on exécute le code en lançant les tests pour les faire réussir. Pour lancer les tests, utilise `go test` depuis le terminal.
Les tests réussiront si la fonctionnalité est correctement implémentée.
