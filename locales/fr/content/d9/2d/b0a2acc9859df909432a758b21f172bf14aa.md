# Introduction

En PHP, on peut appeler une variable comme une fonction en lui appliquant des parenthèses [`()`]. Lorsque PHP tente d'appeler la fonction, il cherche une fonction portant le même nom que la valeur de la variable.

```php
function foo(): string
{
    return "foo() invoked";
}

$func = 'foo';
$func(); // This calls foo()
```
