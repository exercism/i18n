# Introduction

## Booléens

Le type `Bool` est l'une des briques de base du langage.
Il sert à décrire si quelque chose est vrai ou faux, avec les valeurs `True` et `False` correspondantes.

Les booléens peuvent être combinés avec les opérateurs `&&` « et » et `||` « ou », et niés avec la fonction `not`.

Les booléens sont aussi extrêmement utiles pour créer, dans le code, des branches qui ne sont exécutées que si certaines conditions sont remplies.
En Elm, cela se fait avec une expression `if-then-else`, utilisée comme suit.

```elm
if someCondition || (someOtherCondition && anotherCondition) then
    doSomething
else
    doSomethingElse
```
