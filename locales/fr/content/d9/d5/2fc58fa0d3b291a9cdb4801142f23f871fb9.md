Tout le concept d'héritage est étroitement lié aux notions de [redéfinition de méthode][java-overriding].

- Révise le concept [concept:java/classes](https://github.com/exercism/java/tree/main/concepts/classes).

## 2. Décris un Warrior

- En Java, la méthode `toString()` est en fait définie dans la classe `Object` (qui est la superclasse de toutes les classes en Java).
  Tu peux en lire plus dans la [documentation officielle Oracle][object-class-java].
- Pour redéfinir cette méthode dans la classe d'implémentation, tu dois avoir une méthode de même nom, c'est-à-dire `toString()`, et de même type de retour, c'est-à-dire `String`.
- La méthode `toString()` doit être `public`.

## 3. Rend les Warriors invulnérables

- Redéfinis la méthode `isVulnerable()` dans la classe `Warrior` pour rendre les Warriors toujours invulnérables.

## 4. Calcule les points de dégâts d'un Warrior

- Redéfinis la méthode `getDamagePoints(Fighter)` dans la classe `Warrior`.
- Utilise une [instruction conditionnelle][if-else] pour renvoyer les points de dégâts, en tenant compte de la vulnérabilité de la cible.

## 6. Décris un Wizard

- En Java, la méthode `toString()` est en fait définie dans la classe `Object` (qui est la superclasse de toutes les classes en Java).
  Tu peux en lire plus dans la [documentation officielle Oracle][object-class-java].
- Pour redéfinir cette méthode dans la classe d'implémentation, tu dois avoir une méthode de même nom, c'est-à-dire `toString()`, et de même type de retour, c'est-à-dire `String`.
- La méthode `toString()` doit être `public`.

## 7. Permets aux Wizards de préparer un sort et rends-les vulnérables lorsqu'ils n'ont pas préparé de sort

- Seul un wizard peut préparer un sort. Il est donc logique que cette propriété soit définie dans la classe `Wizard`.
- Crée la méthode `prepareSpell()` dans la classe `Wizard`.
- Rappel : la classe parente (ici `Fighter`) n'a pas accès aux propriétés de la classe enfant (par exemple `Wizard`).
- Rappel : comme la méthode n'a pas de type de retour, tu dois utiliser `void` à la place.
- Redéfinis la méthode `isVulnerable()` dans la classe `Wizard` pour rendre les Wizards vulnérables s'ils n'ont pas préparé de sort.

## 8. Calcule les points de dégâts d'un Wizard

- Redéfinis la méthode `getDamagePoints(Fighter)` dans la classe `Wizard`.
- Utilise une [instruction conditionnelle][if-else] pour renvoyer les points de dégâts, en tenant compte de la valeur du champ _prepare spell_.
