# Introdução

## Módulos

Os módulos são uma forma de agrupar código relacionado, para evitar conflitos de nomes, e estão geralmente presentes em praticamente todos os projetos de código, exceto nos mais triviais.

A sintaxe é a seguinte:

```rust
mod my_module {
    pub struct MyStruct {}

    pub struct OtherClass {}
}
```

Fora do âmbito do módulo, os tipos incluídos em módulos são referidos prefixando o nome do tipo com a sintaxe de dois pontos duplos `::`.
Em alternativa, e mais habitualmente, podes colocar uma diretiva `use` no topo do ficheiro (ou dentro de um módulo) e depois os tipos podem ser usados sem o prefixo.
Dentro do mesmo módulo não é necessário qualificar os nomes dos tipos.

```rust
mod my_module {
    #[derive(Drop)]
    pub struct MyStruct {}

    pub struct Foo {}

    #[generate_trait]
    pub impl FooImpl of FooTrait {
        fn bar() {
            let baz = MyStruct {};
        }
    }
}

#[derive(Drop)]
pub struct Qux {}

#[generate_trait]
impl QuxImpl of QuxTrait {
    fn box() {
        let nux = my_module::MyStruct {};
    }
}

mod other_module {
    use super::my_module::*;

    #[derive(Drop)]
    pub struct Tix {}

    #[generate_trait]
    pub impl TixImpl of TixTrait {
        fn jeg() {
            let lor = MyStruct {};
        }
    }
}
```

Podes criar um alias para um módulo ou um tipo com a sintaxe `use core::array::ArrayTrait as Arr;` e depois usar o alias em qualquer lugar onde o módulo ou o tipo possam ser usados.
