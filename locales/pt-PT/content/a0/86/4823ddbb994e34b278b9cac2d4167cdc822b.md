# Anexo às instruções

## Trabalhar com datas em Prolog

O suporte incorporado do Prolog para datas é [razoavelmente rudimentar][built-in-dates-support].
Uma forma muito mais agradável de trabalhar com datas é através do [pacote date_time][date_time-package].

### Instalar o pacote date_time

Se a tua versão instalada do Swipl for bastante recente, podes instalar o pacote com o seguinte comando:

```bash
swipl pack install date_time
```

Se isso não funcionar, podes executar:

```shell
swipl -g 'pack_install(date_time)'
```

~~~~exercism/note
Se estás a usar o editor online, não precisas de instalar nada manualmente.
~~~~

### Usar o pacote date_time

Adiciona o seguinte código ao topo do teu ficheiro de solução para usares o pacote `date_time`:

```prolog
:- use_module(library(date_time)).
```

~~~~exercism/note
Dica: o [código-fonte do pacote date_time][https://www.swi-prolog.org/pack/file_details/date_time/prolog/date_time.pl?show=src] está bem documentado e pode ser uma grande ajuda!
~~~~
