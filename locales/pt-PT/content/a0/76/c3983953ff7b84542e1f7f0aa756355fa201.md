# Sobre

`when` é a palavra-chave na filtragem de exceções. É colocada depois da instrução catch e pode aceitar uma expressão Boolean que contenha quaisquer valores que estejam no âmbito no momento. Não têm de ser apenas membros da própria exceção. Se o tipo da exceção corresponder e a expressão for avaliada como true, o bloco associado a essa instrução `catch` é executado. Caso contrário, verifica-se a instrução `catch` seguinte, se existir.

```csharp
try
{
    // do stuff
}
catch (Exception ex) when (ex.Message != "")
{
    // output the message when it is not empty
}
catch (Exception ex)
{
    // show stack trace or something.
}
```

- Este artigo sobre [filtros de exceções][exception-filters] mostra como filtrar exceções.
