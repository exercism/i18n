# Instruções

Há uma loja de eletrodomésticos chamada "Tech Palace" aqui perto.
A dona da loja instalou recentemente um grande ecrã para usar em mensagens publicitárias e para mostrar uma saudação especial quando os clientes passam os cartões de fidelização à entrada.
O ecrã é composto por muitas pequenas luzes LED e consegue mostrar várias linhas de texto.

A dona da loja precisa da tua ajuda com o código que é usado para gerar o texto do novo ecrã.

## 1. Cria a mensagem de boas-vindas

<!-- markdownlint-disable-next-line MD038 -->
Para a maioria dos clientes que passam os cartões de fidelização, a dona da loja quer ver `Welcome to the Tech Palace, ` seguido do nome do cliente em letras maiúsculas no ecrã.

Implementa a função `welcome_message` que aceita o nome do cliente como argumento, uma string curta (`felt252`), e devolve a mensagem pretendida como uma `ByteArray`.

```rust
welcome_message("Judy")
// => Welcome to the Tech Palace, JUDY
```

## 2. Acrescenta uma moldura vistosa

Para os clientes fiéis que compram muito na loja, a dona quer que o ecrã de boas-vindas fique mais vistoso, acrescentando uma linha de estrelas antes e depois da mensagem de boas-vindas.
Ainda não sabe ao certo quantas estrelas devem estar nas linhas, por isso quer que isso seja configurável.

Escreve uma função `add_border` que aceita como argumentos uma mensagem de boas-vindas (uma `ByteArray`) e o número de estrelas por linha (do tipo `u32`).
Deve devolver uma `ByteArray` composta por 3 linhas: uma linha com o número de estrelas pretendido, depois a mensagem de boas-vindas tal como foi recebida e, por fim, outra linha de estrelas.

```rust
add_border("Welcome!", 10)
```

Deve devolver o seguinte:

```bash
**********
Welcome!
**********
```

## 3. Limpa as mensagens publicitárias antigas

Antes de instalar este novo ecrã, a loja tinha um ecrã semelhante que só conseguia mostrar linhas estáticas e não configuráveis.
A dona gostaria de reutilizar algumas das mensagens publicitárias antigas no novo ecrã.
No entanto, os dados já incluem uma moldura de estrelas e alguns espaços em branco indesejados.
A tua tarefa é limpar as mensagens para que possam ser reutilizadas.

Implementa uma função `clean_up_message` que aceita a mensagem publicitária antiga como uma `ByteArray`.
A função deve primeiro remover todas as estrelas do texto e, depois, remover os espaços em branco no início e no fim do texto restante.
A função deve depois devolver a mensagem limpa.

```rust
let message: ByteArray = "
**************************
*    BUY NOW, SAVE 10%   *
**************************
";

clean_up_message(message)
// => BUY NOW, SAVE 10%
```
