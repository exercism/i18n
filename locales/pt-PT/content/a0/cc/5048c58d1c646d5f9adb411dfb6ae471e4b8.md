# Introdução

Muitas linguagens têm uma forma como `null` ou `none` para indicar um valor inexistente.
Como R foi concebido para lidar com grandes volumes de dados (muitas vezes desorganizados), tem várias formas de representar o nada.

O objetivo geral é assinalar valores ausentes ou suspeitos à medida que são encontrados e depois continuar sem lançar uma exceção.

## NULL

Se um valor realmente não existe, é representado por `NULL`. Isto é provavelmente o mais próximo do que C ou Python fariam.

```R
v <- c() # zero-length vector
v
#> NULL
is.null(v)
#> [1] TRUE
```

Em muitos contextos, os valores `NULL` são simplesmente ignorados:

```R
c(2, 3, NULL, 5)
#> [1] 2 3 5
```

## NA

Para situações em que um valor existe, mas não sabemos qual é, usa-se `NA`. Por exemplo, ao contar veículos que circulam numa estrada, os observadores humanos podem ficar de baixa ou os sensores automáticos podem avariar, mas o trânsito continua a fluir.

```R
v <- c(1, 2, NA, 4, 5)
v
#> [1]  1  2 NA 4  5
is.na(v) # test for data gaps
#> [1] FALSE FALSE  TRUE FALSE FALSE
```

Assim, `NA` é um marcador de posição que avisa os humanos de que precisam de decidir como lidar com isto.

## NaN

Abreviatura de «Not a Number», `NaN` assinala um problema de cálculo em situações em que se esperava um número.

```R
n <- c(0, 2, 4)
d <- c(0, 1, 2)
n / d
#> [1] NaN   2   2  # 0/0 is mathematically undefined
is.nan(n / d)
#> [1]  TRUE FALSE FALSE
```

Esta não é a única possibilidade para cálculos «inválidos».
Dividir por zero devolve `Inf` ou `-Inf` para um numerador diferente de zero, sem lançar um erro.

```R
1 / 0
#> [1] Inf
```

## Vetores vazios

Talvez surpreendentemente, R não tem uma forma padrão de verificar se algo está vazio.

Mesmo gerar um vetor vazio não é totalmente óbvio.
Vimos numa secção anterior que `c()` sem argumentos devolve `NULL`, não um vetor.

```R
is.vector(c())
#> [1] FALSE
```

Funções como `logical()` ou `integer()` recebem um argumento que especifica o comprimento desejado, que pode ser zero.

```R
z <- logical(0)
is.vector(z)
#> [1] TRUE
length(z)
#> [1] 0
```

Também podemos gerar um vetor e depois remover todos os elementos, como descrito no [Conceito de Vetores][concept-vectors].
Isto resulta num vetor de comprimento zero de um tipo apropriado.

```R
v <- 5
v[-1]  # delete the first element
#> numeric(0)
```
