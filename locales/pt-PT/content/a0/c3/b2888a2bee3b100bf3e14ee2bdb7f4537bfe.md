# Introdução

Em C# existem dois tipos diferentes de números:

- Números inteiros: números sem algarismos depois do separador decimal (números sem parte fracionária). Alguns exemplos são `-6`, `0`, `1`, `25`, `976` e `500000`.
- Números de vírgula flutuante: números com zero ou mais algarismos depois do separador decimal. Alguns exemplos são `-2.4`, `0.1`, `3.14`, `16.984025` e `1024.0`.

Os dois tipos numéricos mais comuns em C# são `int` e `double`. Um `int` é um número inteiro de 32 bits e um `double` é um número de vírgula flutuante de 64 bits.

A aritmética faz-se com os operadores aritméticos padrão. Os números podem ser comparados com os operadores de comparação numérica padrão e com os operadores de igualdade (`==`) e de desigualdade (`!=`).

C# tem dois tipos de conversões numéricas:

1. Conversões implícitas: não há perda de dados e não é necessária sintaxe adicional.
2. Conversões explícitas: pode haver perda de dados e é necessária sintaxe adicional sob a forma de um _cast_.

Como um `int` tem menos precisão do que um `double`, converter um `int` num `double` é seguro e, por isso, é uma conversão implícita. No entanto, converter um `double` num `int` pode significar perda de dados, pelo que exige uma conversão explícita.

```csharp
int softCool = 1358938113;
double notLost = 4.8151623;

// implicit cast: no loss of information
double macDebug = softCool;         // 1358938113.0

// explicit cast: possible loss of information 
int somethingLost = (int)notLost;   // 4
```
