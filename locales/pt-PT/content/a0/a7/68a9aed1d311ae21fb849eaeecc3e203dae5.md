# Dicas

## 1. Dividir uma string em linhas individuais

- O Swift tem um [método][nsstring-components-docs] para dividir uma string num array de strings, usando um delimitador fornecido.

## 2. Porta da frente

- O guarda vai recitar um poema e vais ter de dividir o poema em linhas individuais. Para isso, podes usar uma função que já existe.
- Podes usar um ciclo for para iterar sobre as linhas do poema.
- Podes usar a propriedade `first` de uma string para obter o primeiro caráter de uma string.
- Para guardar o primeiro caráter de cada linha, podes usar um array de carateres ou uma string.

## 3. Porta de trás

- O guarda vai recitar um poema e vais ter de dividir o poema em linhas individuais. Para isso, podes usar uma função que já existe.
- Podes usar um ciclo for para iterar sobre as linhas do poema.
- Podes usar a propriedade `last` de uma string para obter o último caráter de uma string.
- Para guardar o último caráter de cada linha, podes usar um array de carateres ou uma string.

## 4. Sala secreta

- O guarda vai recitar um poema e vais ter de dividir o poema em linhas individuais. Para isso, podes usar uma função que já existe.
- Podes usar um ciclo for que percorre o comprimento das linhas do poema.
- O Swift tem um [método][indexing] para obter o caráter num índice específico de uma string.
- O Swift tem um [método][uppercased] para converter uma string em maiúsculas.
