# Anexo às instruções

## Instruções específicas deste track

A tua lista também tem de implementar a seguinte interface:

- `delete` (eliminar a primeira ocorrência de um valor especificado)
- `count` (contar o número de itens da lista)

Os stubs em `linked-list.v` fornecem o conjunto _mínimo_ de interfaces. Podes querer adicionar as tuas próprias definições, como uma estrutura para representar um item da lista.

No entanto, _não_ uses uma biblioteca para implementar este exercício e _não_ uses um array.
