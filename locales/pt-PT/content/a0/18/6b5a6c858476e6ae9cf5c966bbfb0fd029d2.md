# Recursos

Há muitos recursos online gratuitos e excelentes para Lua, entre eles:

1.  [lua.org][8]
2.  Uma introdução detalhada e autoritária a todos os aspetos da programação em Lua, muito recomendada e escrita pelo arquiteto-chefe da linguagem: [Programming in Lua, by Roberto Ierusalimschy][6]
3.  Para uma definição oficial da linguagem Lua, consulta o [Lua 5.4 Reference Manual][7], de R. Ierusalimschy, L. H. de Figueiredo, W. Celes.
4.  [Lua Style Guide][4]
5.  [Learn Lua in 15 minutes][5]
6.  Embora não seja muito bonita, a wiki do [lua-users.org][14] contém muita informação e conhecimento úteis
7.  Algumas opções para fazer linting
    -   [luacheck][12]
    -   [Detecting Undefined Variables][13]
8.  Implementações do Language Server Protocol para Lua
    -   [Lua Language Server][9]
    -   [EmmyLua-LanguageServer][10]
