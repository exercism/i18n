# Aprender

## Recursos de aprendizagem recomendados

O Exercism disponibiliza exercícios e feedback, mas a ML pode ser difícil de abordar para quem está a aprender SML pela primeira vez.
Estes recursos podem ajudar-te a começar:

### Nunca programei antes

A ML provavelmente não é a melhor linguagem para quem está a começar a programar.
Provavelmente é melhor começares com uma linguagem como Ruby ou Python, mas se te apetecer arriscar, talvez queiras ler [Programming in Standard ML '97: An On-line Tutorial][tutorial].
Sugiro que saltes a introdução e vás diretamente para [Simple applicative programming][node13], porque a introdução é muito técnica.

A Coursera oferece um curso sobre [programming languages][coursera].
O curso destina-se a programadores com alguma experiência, mas é difícil encontrar uma introdução melhor à linguagem ML.


### Já ouvi falar de programação funcional

Uma boa leitura é [Programming in Standard ML '97: An On-line Tutorial][tutorial].

Outra é [A Gentle Introduction to ML][gentle].

A Coursera oferece um curso sobre [programming languages][coursera].
É difícil encontrar uma introdução melhor à linguagem ML.

O [site do SML/NJ][smlnj] lista vários livros.
A maioria é bastante antiga e provavelmente difícil de encontrar, no entanto.
A linguagem não mudou muito, por isso, se conseguires encontrá-los, não penses que estão assim tão desatualizados.
Vê também as Four Lectures on Standard ML listadas na página.


## Sou um programador confiante

Se és um programador confiante e conheces muito bem as linguagens funcionais, podes ter uma boa visão geral da sintaxe em [Learn X in Y minutes][learnxy].

As [Four Lectures on Standard ML][four-lectures] são uma boa introdução.
