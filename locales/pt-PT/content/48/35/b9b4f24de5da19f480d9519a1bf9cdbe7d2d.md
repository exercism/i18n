# Analisador de linhas de registo

## História

Neste exercício vais processar linhas de registo.

Cada linha de registo é uma string formatada da seguinte forma: `"[<LVL>]: <MESSAGE>"`.

Estes são os diferentes níveis de registo:

- `TRC` (rastreio)
- `DBG` (depuração)
- `INF` (informação)
- `WRN` (aviso)
- `ERR` (erro)
- `FTL` (fatal)

## Tarefas

Estas são tarefas de exemplo que se enquadram no analisador de linhas de registo:

- Converter o nível de registo num enum
- Suportar níveis de registo desconhecidos
- Converter uma linha de registo noutro formato, com o nível de registo convertido num valor numérico
