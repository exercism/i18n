# Instruções

Tens a teu cargo a estação de processamento de um array de sismógrafos, uma rede de sensores que registam como o solo se move.

As leituras chegam em blocos de valores.
Algumas são deslocamentos do solo armazenados como números de vírgula flutuante de 32 bits, outras são contagens em bruto e palavras de estado armazenadas como inteiros de 32 bits.
A estação processa um bloco inteiro de uma só vez, aplicando a mesma operação a cada valor.

Tens seis tarefas, cada uma a operar sobre um bloco de valores guardados em memória.
Recebes os operandos através de endereços de memória e escreves a tua resposta através de um endereço de resultado.
Todos os endereços de memória neste exercício estão alinhados a 16 bytes.

~~~~exercism/note
Os cálculos neste exercício devem ser feitos com operações bit a bit e deslocamentos SIMD, e não com operações escalares.
~~~~

## 1. Retifica o traço

Para a análise de magnitude, só importa o tamanho de cada deslocamento do solo, não a sua direção.
O primeiro passo de processamento reduz cada leitura a um valor não negativo.

Implementa a função `rectify_trace`, que calcula o valor absoluto de cada leitura.
Um bloco contém 4 leituras, cada uma um número de vírgula flutuante de 32 bits.

Esta função recebe como argumentos, por esta ordem:

- `result`: endereço de memória de um buffer onde são escritas as 4 leituras retificadas.
- `trace`: endereço de memória das leituras registadas, com 4 valores, cada um um número de vírgula flutuante de 32 bits.

```c
trace  = {1.5, -2.25, 0.0, -135.75}
result = {1.5,  2.25, 0.0,  135.75}
```

Esta função não devolve nenhum valor.

## 2. Lê a escala de um tremor

Os analistas classificam os tremores pela sua potência de dois: uma leitura próxima de `8.0` fica na escala `3`, uma leitura próxima de `0.25` fica na escala `-2`.
Essa escala já está armazenada dentro de cada número de vírgula flutuante, no seu campo de expoente.

Um número de vírgula flutuante de 32 bits está organizado com um bit de sinal no bit 31, um expoente de 8 bits nos bits 30 a 23 e uma fração de 23 bits nos bits 22 a 0.
O expoente armazenado tem um desvio de 127, pelo que o valor do número é `(-1)^sign * 1.fraction * 2^(exponent - 127)`.

Implementa a função `reading_scale`, que extrai o expoente sem desvio de cada leitura como um inteiro de 32 bits com sinal.

Esta função recebe como argumentos, por esta ordem:

- `result`: endereço de memória de um buffer onde são escritas as 4 escalas, cada uma um inteiro de 32 bits com sinal.
- `trace`: endereço de memória das leituras retificadas, com 4 valores, cada um um número de vírgula flutuante de 32 bits.

```c
trace  = {8.0, 0.25, 1.0, 13.5}
result = {  3,   -2,   0,   3}
```

Esta função não devolve nenhum valor.
Todas as leituras são números de vírgula flutuante normais e não nulos.

## 3. Torna a resolução mais grosseira

Para armazenamento a longo prazo, as contagens de deslocamento em bruto são guardadas com uma resolução mais grosseira: cada contagem é dividida por uma potência de dois.

As contagens de deslocamento têm sinal: o solo pode mover-se nos dois sentidos.
Dividi-las corretamente exige o deslocamento que preserva o sinal.

Implementa a função `coarsen_displacements`, que divide cada contagem com sinal por `2^shift`, arredondando em direção ao infinito negativo.

Esta função recebe como argumentos, por esta ordem:

- `result`: endereço de memória de um buffer onde são escritas as 4 contagens com resolução reduzida, cada uma um inteiro de 32 bits com sinal.
- `counts`: endereço de memória das contagens em bruto, com 4 inteiros de 32 bits com sinal.
- `shift`: a potência de dois pela qual dividir, como um inteiro de 64 bits sem sinal entre `0` e `31`.

```c
counts = {1024, -1024, 25, -25}
shift  = 3
result = { 128,  -128,  3,  -4}
```

~~~~exercism/note
A instrução `movq` pode ser usada para copiar um inteiro de 64 bits de um registo de uso geral para um registo `xmm` sem alterar a representação de bits subjacente.
~~~~

Esta função não devolve nenhum valor.

## 4. Filtra os canais

Cada estação funde duas campanhas de registo e depois silencia os canais que o seu relatório de hardware assinala como avariados.
Cada bloco contém 4 máscaras de canais, cada uma um inteiro de 32 bits sem sinal, em que cada bit representa um canal: `1` ativo, `0` inativo.

Implementa a função `gate_channels`, que combina os canais ativos em qualquer das campanhas e depois limpa todos os canais assinalados como avariados.

Esta função recebe como argumentos, por esta ordem:

- `result`: endereço de memória de um buffer onde são escritas as 4 máscaras filtradas, cada uma um inteiro de 32 bits sem sinal.
- `enable_a`: endereço de memória das máscaras de ativação da primeira campanha, com 4 inteiros de 32 bits sem sinal.
- `enable_b`: endereço de memória das máscaras de ativação da segunda campanha, com 4 inteiros de 32 bits sem sinal.
- `faulty`: endereço de memória das máscaras de canais avariados, com 4 inteiros de 32 bits sem sinal.

```c
enable_a = {0b1100, 0b0001, 0b1111, 0b0000}
enable_b = {0b0110, 0b0001, 0b0000, 0b0000}
faulty   = {0b0100, 0b0011, 0b1001, 0b1111}
result   = {0b1010, 0b0000, 0b0110, 0b0000}
```

Esta função não devolve nenhum valor.

## 5. Alterna os bits de calibração

Uma vez por dia, a estação executa uma passagem de calibração, que inverte um conjunto escolhido de bits de configuração em cada palavra de estado e deixa todos os outros bits intactos.
Mas alguns bits estão bloqueados pelo hardware e nunca podem mudar, independentemente do que a passagem peça.
Executar a mesma passagem duas vezes restaura a configuração original.

Implementa a função `toggle_calibration`, que inverte, em cada palavra de estado, exatamente os bits que estão definidos na máscara de alternância correspondente e não estão definidos na máscara de bloqueio correspondente.

Esta função recebe como argumentos, por esta ordem:

- `result`: endereço de memória de um buffer onde são escritas as 4 palavras de estado atualizadas, cada uma um inteiro de 32 bits sem sinal.
- `status`: endereço de memória das palavras de estado atuais, com 4 inteiros de 32 bits sem sinal.
- `toggle`: endereço de memória das máscaras de alternância, com 4 inteiros de 32 bits sem sinal.
- `locked`: endereço de memória das máscaras de bloqueio, com 4 inteiros de 32 bits sem sinal.

```c
status = {0b1100, 0b0001, 0b1111, 0b1010}
toggle = {0b0110, 0b0011, 0b1111, 0b1010}
locked = {0b0010, 0b0001, 0b1100, 0b0000}
result = {0b1000, 0b0011, 0b1100, 0b0000}
```

Esta função não devolve nenhum valor.

## 6. Amplifica o traço

Cada canal do array tem o seu próprio ajuste de ganho, expresso como uma potência de dois: um ganho de `3` multiplica a leitura do canal por `8`, um ganho de `-5` divide-a por `32`.

A estação aplica estes ganhos sem uma única multiplicação, manipulando o campo de expoente de cada número de vírgula flutuante.

Implementa a função `amplify_trace`, que multiplica cada leitura por `2` elevado ao ganho do respetivo canal, operando apenas sobre os bits em bruto.

Esta função recebe como argumentos, por esta ordem:

- `result`: endereço de memória de um buffer onde são escritas as 4 leituras amplificadas.
- `trace`: endereço de memória das leituras, com 4 valores, cada um um número de vírgula flutuante de 32 bits.
- `gains`: endereço de memória dos ganhos por canal, com 4 inteiros de 32 bits com sinal.

```c
trace  = {1.5, -2.0, 0.25, 96.0}
gains  = {  2,    1,    3,   -5}
result = {6.0, -4.0,  2.0,  3.0}
```

Esta função não devolve nenhum valor.
Todas as leituras são números de vírgula flutuante normais e não nulos, e todos os resultados amplificados também são normais.
