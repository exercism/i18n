# Dicas

## Geral

- A [documentação da API de `Set`][set-docs] tem uma lista dos métodos disponíveis na interface `Set`.

## 1. Começa uma coleção

- A [classe `HashSet`][hashset-docs] tem um construtor que recebe uma `Collection`.

## 2. Aumenta a coleção

- Vê a assinatura do [método `add`][set-add-docs] definido na interface `Set`.

## 3. Começa a trocar

- Podes criar uma cópia de um `Set` envolvendo-o num `new HashSet<>()`.
- A [interface `Set`][set-docs] tem um método que remove todos os itens contidos noutra `Collection`.

## 4. Identifica as cartas comuns

- Podes criar uma cópia de um `Set` envolvendo-o num `new HashSet<>()`.
- A [interface `Set`][set-docs] tem um método que mantém todos os itens contidos noutra `Collection`.

## 5. Todas as cartas

- Podes criar uma cópia de um `Set` envolvendo-o num `new HashSet<>()`.
- A [interface `Set`][set-docs] tem um método que adiciona todos os itens contidos noutra `Collection`.
