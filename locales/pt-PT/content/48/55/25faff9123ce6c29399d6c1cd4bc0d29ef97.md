# Instruções

És o faroleiro do farol do Cabo Crozier. A partir da sala da
lanterna registas todas as embarcações que passam, cada uma
identificada por um indicativo único, e coordenas também as
retransmissões de sinais com os outros faróis ao longo da costa.

## 1. Um diário de bordo novo

Define `empty-log` para devolver um hash-set vazio e novo, pronto
a recolher indicativos.

```factor
empty-log .
! => HS{ }
```

## 2. Registar um avistamento

Define `sight` para receber um diário de bordo e um indicativo, e
registar o avistamento no local. Não devolve nada.

```factor
empty-log dup "NS-1024" sight .
! => HS{ "NS-1024" }
```

## 3. Já vimos este?

Define `seen?` para receber um diário de bordo e um indicativo,
devolvendo `t` se o indicativo já tiver sido registado e `f` caso
contrário.

```factor
HS{ "NS-1024" "WB-203" } "NS-1024" seen? .   ! => t
HS{ "NS-1024" "WB-203" } "X-99"    seen? .   ! => f
```

## 4. Esquecer um avistamento

Define `forget-sighting` para receber um diário de bordo e um
indicativo, e remover esse indicativo do diário de bordo no local.
Não devolve nada. Se o indicativo não estiver lá, não faz nada.

```factor
HS{ "NS-1024" "WB-203" } clone dup "WB-203" forget-sighting .
! => HS{ "NS-1024" }
```

## 5. Quantas embarcações distintas?

Define `unique-count` para devolver o número de indicativos
distintos no diário de bordo.

```factor
HS{ "NS-1024" "WB-203" "AC-77" } unique-count .   ! => 3
empty-log unique-count .                          ! => 0
```

## 6. Faróis alcançáveis

A guarda costeira mantém um `relay-map`: uma hashtable com os
nomes dos faróis como chaves, em que cada valor é um array dos
faróis para os quais o farol indicado pela chave pode
retransmitir diretamente.

Define `reachable` para receber um farol `start` e um
`relay-map`, e devolver um hash-set com todos os faróis
alcançáveis a partir de `start` (incluindo o próprio `start`)
através de retransmissões sucessivas.

```factor
H{
    { "Crozier"  { "Beacon"  "Hadley"  } }
    { "Beacon"   { "Crozier" "Spiral"  } }
    { "Hadley"   { "Crozier"           } }
    { "Spiral"   { "Beacon"  "Outpost" } }
    { "Outpost"  { "Spiral"            } }
    { "Far-Isle" { "Lonely"            } }
    { "Lonely"   { "Far-Isle"          } }
}
"Crozier" swap reachable .
! => HS{ "Crozier" "Beacon" "Hadley" "Spiral" "Outpost" }
```

O par `Far-Isle`/`Lonely` forma uma componente conexa isolada,
por isso nenhum dos dois aparece no resultado.
