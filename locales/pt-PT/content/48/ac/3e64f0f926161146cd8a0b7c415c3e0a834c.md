# Introdução

[`Rational numbers`][rational] são frações com um numerador inteiro dividido por um denominador inteiro.

Por exemplo, podemos guardar `2//3` como uma fração exata em vez do valor aproximado `Float64` `0.6666...`

A vantagem é que (exceto no caso extremo de [transbordo de inteiros][integer-overflow]) um número racional permanece exato, evitando os erros de arredondamento que são muitas vezes inevitáveis com números de vírgula flutuante.

Encontras mais alguns detalhes na [página do manual][julia-rational] da Julia.

Os números racionais são um tipo numérico bastante simples e funcionam, em grande medida, como esperarias.
Como são um tipo padrão na Julia desde as primeiras versões, a maioria das funções aceita-os como valores de entrada da mesma forma que os inteiros e os números de vírgula flutuante.

## Criar números racionais

Criar um número racional é tão simples como usar `//` entre dois inteiros.

```julia-repl
julia> 3//4
3//4

julia> a = 3; b = 4;

julia> a//b
3//4
```

Os fatores comuns são removidos automaticamente, reduzindo a fração aos seus ["termos mínimos"][lowest-terms]: os menores inteiros que representam a fração com exatidão e com um denominador não negativo.

```julia-repl
julia> 5//15
1//3

julia> 5//-15
-1//3
```

Aceitam-se resultados infinitos, mas não [`NaN`][NaN].

```julia-repl
julia> 1//0
1//0

julia> float(1//0)
Inf

julia> 0//0
ERROR: ArgumentError: invalid rational: zero(Int64)//zero(Int64)
```

## Aritmética com números racionais

Os habituais [`arithmetic operators`][operators] `+ - * / ^ %` funcionam com racionais, praticamente da mesma forma que com outros tipos numéricos.

Podes incluir inteiros e outros `Rational`s e obter um resultado `Rational`.
Incluir um `float` na expressão dá um resultado `float`, com uma consequente (possível) perda de precisão.

Se quiseres um `float`, usa simplesmente a função `float()` para converter um racional.
É perfeitamente normal usar números racionais para preservar a precisão ao longo de um cálculo extenso e, no fim, converter para um número de vírgula flutuante.

```julia-repl
julia> 3//4 + 1//3  # addition
13//12

julia> 3//4 * 1//3  # multiplication
1//4

julia> 3//4 / 1//3  # division
9//4

julia> 3//4 ^ 2  # exponentiation
3//16

julia> 3//4 + 5  # rational and int => rational
23//4

julia> 3//4 + 5.3  # rational and float => float
6.05

julia> float(3//4)  # casting
0.75
```

Os racionais também podem ser combinados com [números complexos][complex].
Os números complexos são abordados num [conceito separado][complex-concept].

## Outras operações

Na Julia, os números racionais são apenas números.
O compilador costuma converter os tipos conforme for necessário.

No entanto, tem em atenção que as comparações funcionam para frações com uma representação decimal finita:

```julia-repl
julia> 3//4 == 0.75
true

julia> 3//4 < 0.74
false
```

Mas, fora desses casos, um `Rational` deve ser convertido para `Float` antes de fazer comparações:

```julia-repl
julia> 1//3 == 1/3
false

julia> float(1//3) == 1/3
true
```

As funções matemáticas aceitam racionais como valores de entrada, mas podem dar um resultado de vírgula flutuante:

```julia-repl
julia> sqrt(9//16)
0.75
```
