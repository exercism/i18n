# Sobre

Arturo é uma linguagem de programação moderna, desenvolvida de forma independente, que segue alguns princípios muito simples e diretos:

* O código é apenas uma lista de palavras, símbolos e valores literais.
  
* As palavras e os símbolos dentro de um bloco são interpretados, quando necessário, de acordo com o contexto.
  
* Não há palavras reservadas nem palavras-chave: procura-as o mais que puderes, não há absolutamente nenhuma.
