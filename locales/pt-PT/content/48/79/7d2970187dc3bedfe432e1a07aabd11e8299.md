# Instruções

Neste exercício, vais ajudar namorados do liceu a declarar o seu amor nas redes sociais, gerando uma caixa ASCII com as iniciais deles:

```
❤-------------------❤
|  J. K.  +  M. B.  |
❤-------------------❤
```

## 1. Obter a primeira letra do nome

Implementa a função `HighSchoolSweetheart.first_letter/1`. Deve receber um nome e devolver a sua primeira letra. Deve limpar todos os espaços desnecessários do nome.

```elixir
HighSchoolSweetheart.first_letter("Jane")
# => "J"
```

## 2. Formatar a primeira letra como inicial

Implementa a função `HighSchoolSweetheart.initial/1`. Deve receber um nome e devolver a sua primeira letra, em maiúscula, seguida de um ponto. Certifica-te de que reutilizas `HighSchoolSweetheart.first_letter/1`, que definiste no passo anterior.

```elixir
HighSchoolSweetheart.initial("Robert")
# => "R."
```

## 3. Dividir o nome completo no primeiro nome e no último nome

Implementa a função `HighSchoolSweetheart.initials/1`. Deve receber um nome completo, composto por um primeiro nome e um último nome separados por um espaço, e devolver as iniciais. Certifica-te de que reutilizas `HighSchoolSweetheart.initial/1`, que definiste no passo anterior.

```elixir
HighSchoolSweetheart.initials("Lance Green")
# => "L. G."
```

## 4. Colocar as iniciais dentro da caixa ASCII

Implementa a função `HighSchoolSweetheart.pair/2`. Deve receber dois nomes completos e devolver as iniciais dentro de uma caixa ASCII. Não precisas de desenhar a caixa tu próprio. Usa a caixa incluída no comentário do código. Certifica-te de que reutilizas `HighSchoolSweetheart.initials/1`, que definiste no passo anterior.

```elixir
HighSchoolSweetheart.pair("Blake Miller", "Riley Lewis")
# => """
# ❤-------------------❤
# |  B. M.  +  R. L.  |
# ❤-------------------❤
# """
```
