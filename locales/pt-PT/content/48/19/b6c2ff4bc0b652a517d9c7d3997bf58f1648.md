# Instruções

Refatora um analisador sintático de Markdown.

O exercício de markdown é um exercício de refatoração. Há código que analisa uma determinada string com [sintaxe Markdown](https://guides.github.com/features/mastering-markdown/) e devolve o HTML associado a essa string. Apesar de este código estar escrito de forma confusa e ser difícil de seguir, de alguma maneira funciona e todos os testes passam! O teu desafio é reescrever este código para o tornar mais fácil de ler e de manter, garantindo ao mesmo tempo que todos os testes continuam a passar.

Seria útil que anotasses em comentários o que fizeste na tua refatoração, para que os revisores o possam ver, mas não é estritamente necessário. O mais importante é melhorar o código!
