# Anexo às instruções

## Instruções específicas da track

Os testes deste exercício exigem que uses extensions, um mecanismo para adicionar novas funcionalidades a uma classe existente cujo código não controlas diretamente, sem teres de criar uma subclasse.
Para saberes mais sobre as implementações de extensions do Kotlin, consulta a [documentação oficial](https://kotlinlang.org/docs/reference/extensions.html#extensions).

Os métodos `customFoldLeft` e `customFoldRight` são funções de "fold", um conceito bem conhecido no mundo da programação funcional, mas nem tanto no da orientada a objetos.
Se quiseres mais informação de fundo, consulta esta página sobre [fold](https://en.wikipedia.org/wiki/Fold_(higher-order_function)).
