# Analisador de linhas de registo

## História

Neste exercício vais processar linhas de registo.

Cada linha de registo é uma string formatada da seguinte forma: `"[<LEVEL>]: <MESSAGE>"`.

Existem três níveis de registo diferentes:

- `INFO`
- `WARNING`
- `ERROR`

## Tarefas

Estas são tarefas de exemplo que se adequam ao analisador de linhas de registo:

- Obter a mensagem de uma linha de registo
- Obter o nível de registo de uma linha de registo
- Converter uma linha de registo noutro formato
