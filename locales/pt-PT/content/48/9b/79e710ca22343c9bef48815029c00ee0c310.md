# Introdução

## Funções arrow

Além das declarações de funções e das expressões de funções, o JavaScript tem outra sintaxe muito concisa para definir uma função.
Estas funções chamam-se _funções arrow_.

Aqui está uma comparação entre uma declaração de função e uma função arrow.

```javascript
function addUpTwoNumbers(num1, num2) {
  return num1 + num2;
}
// function keyword removed and => added
const addUpTwoNumbers = (num1, num2) => {
  return num1 + num2;
};
```

Se o corpo da função contiver apenas uma instrução de retorno, como no exemplo acima, as chavetas `{}` e a palavra-chave `return` podem ser omitidas.
Se houver apenas um parâmetro, também se podem omitir os parênteses `()`.

<!-- prettier-ignore-start -->
```javascript
const addUpTwoNumbers = (num1, num2) => num1 + num2;
const square = num => num * num;
```
<!-- prettier-ignore-end -->

As funções arrow são usadas muitas vezes para definir funções de callback curtas diretamente na chamada da função.

<!-- prettier-ignore-start -->
```javascript
applyToSquare(number => number * number);
```
<!-- prettier-ignore-end -->

## Análise de arrays

Os [Arrays][arrays-concept] têm métodos incorporados para analisar o conteúdo do array.
A maioria destes métodos recebe como argumento uma função que devolve verdadeiro ou falso.
Uma função deste tipo chama-se [`predicate`][predicate_in_programming].

Estes métodos incorporados servem para serem usados _em vez de um ciclo `for`_ ou do método `forEach` incorporado:

Exemplo de análise com um ciclo for:

```javascript
const numbers = [1, 'two', 3, 'four'];
for (var i = 0; i < numbers.length; i++) {
  if (numbers[i] === 'two') {
    return i;
  }
}
// => 1
```

Exemplo de análise com um método incorporado:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.indexOf('two');
// => 1
```

Abaixo mostramos outros métodos incorporados úteis para analisar um array.
Consulta a [MDN][mdn-array-methods] para veres a lista completa de métodos de array.

### `includes`

O método `includes(value)` determina se um array inclui um determinado valor.
Devolve `true` quando o valor está incluído e `false` caso contrário.

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.includes(1);
// => true
numbers.includes('one');
// => false
```

### `every`

O método `every(predicate)` recebe uma função que é _um predicado_.
Testa se todos os elementos do array devolvem `true` quando são passados ao predicado.
Por outras palavras: o método testa se todos os seus elementos passam o teste passado à chamada da função.
Devolve `true` quando todos os elementos passam o teste do predicado e `false` caso contrário.

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.every((num) => num % 2 !== 0);
// => true
```

### `some`

O método `some(predicate)` é igual ao método `every`, mas devolve `true` se pelo menos um elemento do array passar o teste do _predicado_.

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.some((num) => num % 2 !== 0);
// => true
```

### `find`

O método `find(predicate)` devolve o valor do primeiro elemento do array que passa o teste do `predicate`.
Onde `some()` devolve `true` quando passa, `find()` devolve o valor concreto que está no array.
O método devolve `undefined` quando nenhum dos elementos do array passa o teste do _predicado_.

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.find((num) => num < 5);
// => 1
```

### `findIndex`

O `findIndex(predicate)` é igual ao método `find()`, mas devolve o _índice_ (o primeiro) do elemento que passa o teste do _predicado_ em vez do `value`.
O método devolve `-1` quando nenhum dos elementos do array passa o teste do _predicado_.

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.findIndex((num) => num > 7);
// => 4
numbers.findIndex((num) => num > 9);
// => -1
```
