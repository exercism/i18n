# Testes

Instala as dependências.

```sh
dart pub get
```

Corre os testes.

```sh
dart test
```

Para obteres uma saída mais detalhada por teste, usa o relator expandido.

```sh
dart test -r expanded
```

A maioria dos exercícios tem vários testes, e todos exceto o primeiro são ignorados por defeito.
Para fazeres os testes um a um, altera `skip: true` para `skip: false` em cada teste à medida que avanças.

Em alternativa, corre todos os testes de uma só vez sem editares o ficheiro.

```sh
dart test --run-skipped
```

Todos os testes são executados pelo executor de testes online ao submeteres, incluindo os ignorados.
