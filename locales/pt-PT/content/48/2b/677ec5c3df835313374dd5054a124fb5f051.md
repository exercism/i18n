# Noções básicas

Para informação mais detalhada sobre estes tópicos, visita a [página do conceito][exercism-concept].

## Sintaxe geral

A etiqueta de abertura do PHP `<?php` marca o início do código PHP.
Todas as instruções têm de terminar com `;` para separar as instruções.

```php
<?php

$message = "Success!"; // Statement correctly ends with `;`
$message = "I fail." // PHP Parse error: syntax error, [...]
```

Para facilitar a leitura, todos os exemplos de código omitem a etiqueta de abertura do PHP `<?php`.

## Comentários

Os comentários de uma linha começam com `//`.

```php
// Single line comment
```

## Valores e variáveis

Com o operador de atribuição `=`, podes atribuir um valor a uma variável.
Os nomes das variáveis têm de começar com um sinal de dólar `$` e seguir as [convenções de nomenclatura][exercism-concept-naming-conventions].

```php
$count = 1; // Assign value of 1

// Strings can be created by enclosing the characters
// within single `'` quotes or double `"` quotes.
$message = "Success!";
```

## Funções e métodos

Podes passar valores e variáveis a funções.
Os argumentos de uma função tornam-se novas variáveis que guardam os valores recebidos.
As funções podem devolver qualquer valor com a palavra-chave `return`.

```php
function window_height($height)
{
    return $height + 10;
}

window_height(100);
// => 110
```

As funções dentro de classes e das respetivas instâncias chamam-se métodos.
Para chamar um método, o nome é precedido pela instância e por `->`.
Os métodos têm acesso à variável especial `$this`, que se refere à instância atual.

```php
<?php

class Calculator {
    public function sub($x, $y)
    {
        return $this->add($x, -$y); // Calls the method add() of the current instance
    }

    public function add($x, $y)
    {
        return $x + $y;
    }
}

$calculator = new Calculator(); // Creates a new instance of Calculator class
$calculator->sub(3, 1); // Calls the method sub() of the instance stored in $calculator
// => 2
```
