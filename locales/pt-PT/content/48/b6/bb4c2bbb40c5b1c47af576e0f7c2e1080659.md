# Dicas

## 1. Define a pontuação de um jogador no hash %Scores

- Queres modificar o hash `%Scores` para adicionar pontuações de novos jogadores e substituir as pontuações dos jogadores que já existem.
- Os hashes não podem conter chaves duplicadas; um valor mais recente numa lista substitui um valor mais antigo.

## 2. Obtém a pontuação de um jogador a partir do hash %Scores

- Queres usar o nome do jogador indicado para `return` a pontuação desse jogador a partir do hash `%Scores`.

## 3. Aumenta a pontuação de um jogador no hash %Scores

- Queres modificar o hash `%Scores` para adicionar aos novos valores as pontuações dos jogadores que já existem.

## 4. Ordena os jogadores do hash %Scores por nome

- Queres `return` os nomes dos jogadores a partir do hash `%Scores` como uma lista ordenada alfabeticamente.


## 5. Ordena os jogadores do hash %Scores por pontuação

- Queres `return` os nomes dos jogadores a partir do hash `%Scores` como uma lista ordenada por pontuação, da mais alta para a mais baixa.

## 6. Remove um jogador do hash %Scores

- Queres modificar o hash `%Scores` para remover o nome e a pontuação do jogador indicado.
