# Instruções adicionais

## Instruções específicas do percurso

A tua tarefa é implementar um registo `circularBuffer` com os seguintes métodos:

- `clear()`: esvazia o buffer.
- `write(item)`: adiciona o item indicado ao buffer. Se o buffer estiver cheio, deve lançar `Error("Cannot write to full buffer.")`.
- `read()`: remove o elemento mais antigo do buffer e devolve-o. Se o buffer estiver vazio, deve lançar `Error("Cannot read from an empty buffer.")`.
- `overwrite(item)`: se o buffer estiver cheio, sobrescreve o `item` no lugar do elemento mais antigo. Se o buffer não estiver cheio, comporta-se como `write`.
