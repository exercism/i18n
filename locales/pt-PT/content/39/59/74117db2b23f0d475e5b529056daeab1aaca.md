# Instruções

O treino de netball começa com voltas. O treinador faz com que cada volta seja um pouco mais longa do que a anterior: a primeira tem 100 metros, a segunda 110, a terceira 120, e assim por diante, mais dez metros de cada vez.

As três tarefas fazem parte da classe `WARM_UP_LAPS`.

## 1. Qual é a distância total?

Dado um número de voltas, calcula a distância total.

```sather
WARM_UP_LAPS::distance_run(3)
-- => 330
```

Ou seja, 100 + 110 + 120. Zero voltas são zero metros.

## 2. Quantas voltas para percorrer uma distância?

Dada uma distância em metros, quantas voltas são precisas até o total ser pelo menos essa distância?

```sather
WARM_UP_LAPS::laps_to_reach(330)
-- => 3
WARM_UP_LAPS::laps_to_reach(331)
-- => 4
```

Zero metros não precisa de nenhuma volta.

## 3. Qual é a primeira volta que fica longa?

Dada uma distância em metros, qual é a primeira volta que é *ela própria* mais longa do que essa distância? A volta 1 tem 100 metros, a volta 2 tem 110, e assim por diante.

```sather
WARM_UP_LAPS::first_long_lap(115)
-- => 3
```

A volta 3 tem 120 metros, que é a primeira acima de 115.
