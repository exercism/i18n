# Sobre

O PHP tem várias estruturas de controlo de ciclos incorporadas, como o `while`. A forma básica de uma instrução `while` é:

```php
while (expr) {
  // statements
}
```

Enquanto a expressão (_expr_) for avaliada como um valor _verdadeiro_, o ciclo itera sobre as instruções no seu interior. Se a expressão (_expr_) for avaliada como false antes da primeira iteração, as instruções nunca são executadas.

Em alternativa, podes usar um ciclo `do-while`, que executa as instruções do ciclo uma vez antes de avaliar a expressão (_expr_).

```php
do {
  // statements
} while (expr);
```
