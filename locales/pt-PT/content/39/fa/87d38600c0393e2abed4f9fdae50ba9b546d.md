# Introdução

As tabelas de dispersão em Common Lisp são estruturas de dados para armazenar dados associativos.
Associam chaves (que podem ser qualquer objeto) a valores (que também podem ser qualquer objeto).
Noutras linguagens, este conceito pode ser designado por mapas, dicionários ou hashes.

## Criação de tabelas de dispersão

As tabelas de dispersão podem ser criadas com a função `make-hash-table`.

`(make-hash-table) ; => #<HASH-TABLE :TEST EQL :COUNT 0 {10024AD2B3}>`

(Repara que a apresentação impressa de uma tabela de dispersão depende da implementação, por isso pode aparecer de forma diferente no teu REPL.)

## Obtenção de valores através das chaves

Para obteres um valor a partir de uma chave da tabela de dispersão, usas a função `gethash`:

```lisp
*h* ; => #<HASH-TABLE :TEST EQL :COUNT 3 {10024AD2B3}>`
(gethash :foo *h*) ; => :bar
                   ;    T
```

O `gethash` devolve [múltiplos valores][concept-multiple-values], que serão explicados noutro conceito.

## Inserção de valores

Para inserires um valor numa tabela de dispersão, usas `setf` com `gethash` desta forma:

`(setf (gethash :foo *hash-table*) :bar) : => :bar`

Isto modifica o valor da chave `:foo` na tabela de dispersão `*hash-table*` para `:bar`.
Devolve o valor.

A utilização de `setf` será explicada noutro conceito.
