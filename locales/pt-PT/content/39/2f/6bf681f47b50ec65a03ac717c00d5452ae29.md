# Introdução

## Alias

Para partilhares código entre diferentes módulos Elixir dentro do mesmo projeto, precisas de referenciar o módulo externo pelo seu nome completo. Mas e se esse nome for demasiado longo ou confuso?

A forma especial `alias` permite-te encurtar ou alterar o nome pelo qual referencias um módulo externo. Quando é usada sem argumentos, reduz o nome do módulo ao seu último segmento, por exemplo, `MyApp.Logger.Settings` passa a ser `Settings`. Podes indicar um nome à tua escolha com a opção `:as`.

Normalmente, os aliases são adicionados no início da definição do módulo.

```elixir
defmodule Square do
  alias Integer, as: I

  def area(a), do: I.pow(a, 2)
end
```

## Import

A forma especial `import` permite-te usar funções de um módulo externo sem escrever o nome do módulo.

Importar um módulo externo inteiro pode criar conflitos com funções locais que já existam. Para evitar isso, tens duas opções: `:except` e `:only`. Ambas esperam uma lista de palavras-chave, em que a chave é o nome da função e o valor é o número de argumentos dessa função.

Normalmente, as importações são adicionadas no início da definição do módulo.

```elixir
defmodule Square do
  import Integer, only: [pow: 2]

  def area(a), do: pow(a, 2)
end
```
