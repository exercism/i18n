# Instruções

Um amigo teu tem uma antiga loja grossista chamada **Gross Store**.

O nome vem da quantidade de artigos que a loja vende: é tudo em [grosas][gross-unit].

O teu amigo pediu-te para implementares um sistema de ponto de venda (POS) para a loja dele.

**Primeiro, queres construir um protótipo para o sistema.**

**No teu protótipo, o sistema vai apenas registar a quantidade.**

O teu amigo deu-te uma lista de medidas para te ajudar:

| Unidade            | Valor |
| ------------------ | ----- |
| quarter_of_a_dozen | 3     |
| half_of_a_dozen    | 6     |
| dozen              | 12    |
| small_gross        | 120   |
| gross              | 144   |
| great_gross        | 1728  |

## 1. Guardar a unidade de medida no teu programa

Para usares a medida, tens de a guardar no teu programa.

```rust
let units = units();
// Felt252Dictionary with entries like { 'dozen': 12 }
```

## 2. Criar uma nova conta de cliente

Tens de implementar uma função que cria uma nova conta (vazia) para o cliente.

```rust
let bill = new_bill();
// Empty Felt252Dictionary
```

## 3. Adicionar um artigo à conta do cliente

Para implementares isto, tens de:

- Devolver `false` se a `unit` indicada não estiver no mapa `units`.
- Caso contrário, adicionar o artigo à `bill` do cliente, indexado pelo nome do artigo, e devolver `true`.
- Se o artigo já estiver na conta, aumentar a sua quantidade pelo valor que corresponde à `unit` indicada.

```rust
let bill = new_bill();
let units = units();
let ok = add_item(bill, units, 'carrot', 'dozen');
println!(ok);
// Output: true (since dozen is a valid unit)
```

> Repara que o valor devolvido é do tipo `bool`.

## 4. Remover um artigo da conta do cliente

Para implementares isto, tens de:

- Devolver `false` se o artigo indicado **não** estiver na conta.
Considera-se que um artigo não está na conta quando a sua quantidade é 0.
- Devolver `false` se a `unit` indicada não estiver no mapa `units`.
- Devolver `false` se a nova quantidade ficar abaixo de 0.
- Se a nova quantidade for 0, o artigo considera-se removido da `bill`, por isso podes devolver `true`.
- Caso contrário, reduzir a quantidade do artigo e devolver `true`.

```rust
let bill = new_bill();
let units = units();
let ok = remove_item(bill, units, 'carrot', 'dozen');
println!(ok);
// Output: false (because there are no carrots in the bill)
```

> Repara que o valor devolvido é do tipo `bool`.

## 5. Devolver a quantidade de um artigo específico que está na conta do cliente

```rust
let mut bill: Felt252Dict<u32> = Default::default();
bill.insert('carrot', 12);
bill.insert('grapes', 3);
let qty = get_item(bill, 'carrot');
println!(qty);
// Output: 12
```

> Repara que o valor devolvido é do tipo `u32`.

[gross-unit]: https://en.wikipedia.org/wiki/Gross_(unit)
