# Anexo às instruções

## Funções e testes

Recebes uma definição inicial para a função `SayHi`.

```delphi
function SayHi : string;
begin
  result := 'Goodbye, Mars!';
end;
```

O executor de testes recebe esta função, executa-a e compara o valor que [devolve][returns] com o valor que espera.
Usa esta definição inicial da função como base para a tua solução.

[returns]: https://www.freepascal.org/docs-html/3.2.2/ref/refse94.html
