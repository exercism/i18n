# Introdução

É útil reportar erros quando algo está errado ou inesperado num programa ou num excerto de código.

Os erros são objetos JavaScript.

A principal propriedade deste objeto é `message`:

```javascript
const error = new Error('Oops, something went wrong');

console.log(error.message);
// => "Oops, something went wrong"
```

Com a sintaxe `throw`, podes lançar um `Error`.

```javascript
throw new Error('Oops');
```

Quando um `Error` é lançado, a execução atual é interrompida e retoma no primeiro bloco catch da pilha de chamadas.

```javascript
try {
  throw new Error('Oops');
} catch (error) {
  console.log(error.message);
  // => "Oops"
}
```

Tal como em qualquer classe em JavaScript, as subclasses podem herdar de `Error` para criar erros personalizados com a palavra-chave `extends`.
A sintaxe `instanceof` verifica se o erro capturado é uma instância de uma subclasse específica de `Error`.

```javascript
class CustomError extends Error {}

try {
  // ... Code that may throw an error
} catch (error) {
  if (error instanceof CustomError) {
    console.log('The error thrown is an instance of the CustomError');
  }
}
```
