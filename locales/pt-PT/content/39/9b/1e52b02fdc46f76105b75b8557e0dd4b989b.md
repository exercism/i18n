# Luhn: usar o trait From

Antes de fazeres este exercício, provavelmente deves fazer o exercício Luhn original. Se ainda não completaste o Luhn, podes obtê-lo executando o comando:

```shell
exercism download --exercise=luhn --track=rust
```

No exercício Luhn original só validavas strings, mas o algoritmo de Luhn também pode ser aplicado a números inteiros.

Neste exercício vais implementar o [trait From](https://doc.rust-lang.org/std/convert/trait.From.html) para converter strings, strs e inteiros sem sinal numa struct que faz a validação.
