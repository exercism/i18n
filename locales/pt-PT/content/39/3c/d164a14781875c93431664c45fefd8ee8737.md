# Tuplos

Os tuplos em Elm podem conter dois ou três valores, e cada valor pode ter qualquer tipo.
Em Elm, os tuplos são sobretudo usados para tipos transitórios simples.
Por esta razão, os tuplos têm um máximo de 3 valores e, para reforçar isto, só são fornecidas funções de conveniência para 2 valores.
Para dados mais complexos, é melhor passar para registos.
Um uso comum é quando precisas de devolver mais do que um valor de uma função.
Os campos de um tuplo não têm nome; acede-se a eles por desestruturação ou por posição.

Podes ler uma [introdução concisa aos tuplos][tuples-concise].
Há também uma [introdução mais aprofundada][tuples-in-depth], e a [documentação da API do módulo Tuple][tuple-core] contém exemplos de código e documentação detalhada.

## Declaração

Os tipos para tuplos são criados com parênteses e os seus tipos de elementos são separados por vírgulas.

```elm
type alias IntStringTuple = (Int, String)
```

### Criação

Os tuplos são criados com parênteses e os seus elementos são separados por vírgulas.

```elm
aTuple : IntStringTuple
aTuple = (123, "elements can be of differing types")
```

Também podes usar `Tuple.pair` para criar um tuplo com dois valores.

```elm
anotherTuple : (String, String)
anotherTuple = Tuple.pair "this time it's" "two strings"
    --> ("this time it's", "two strings")
```

### Acesso

Há também funções para aceder aos valores de um tuplo por posição, `Tuple.first` e `Tuple.second`.

```elm
Tuple.first aTuple
    --> 123

Tuple.second aTuple
    --> "elements can be of differing types"
```

Os tuplos podem ser _desestruturados_ em associações usando correspondência de padrões de tuplos.
A desestruturação pode ser feita em expressões let, declarações de funções e instruções case.

```elm
repeatString : (Int, String) -> Bool
repeatString aTuple =
let
    (aNumber, aString) = aTuple
in
    String.repeat aNumber aString

repeatStringAgain : (Int, String) -> Bool
repeatStringAgain (aNumber, aString) = String.repeat aNumber aString
```

A correspondência de padrões numa instrução case também te permite corresponder ao conteúdo dos valores:

```elm
has123 : (Int, String, Bool) -> Bool
has123 aTuple =
    case aTuple of
        (123, _, _) ->
            True
        (_, "123", _) ->
            True
        (_, _, True) ->
            True
        _ ->
            False
```
