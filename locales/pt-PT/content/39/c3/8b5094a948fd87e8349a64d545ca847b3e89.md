# Instruções

Determina a diferença entre o quadrado da soma e a soma dos quadrados dos primeiros N números naturais.

O quadrado da soma dos primeiros dez números naturais é
(1 + 2 + ... + 10)² = 55² = 3025.

A soma dos quadrados dos primeiros dez números naturais é
1² + 2² + ... + 10² = 385.

Assim, a diferença entre o quadrado da soma dos primeiros dez números naturais e a soma dos quadrados dos primeiros dez números naturais é 3025 - 385 = 2640.

Não se espera que descubras por ti próprio uma solução eficiente para este problema a partir dos primeiros princípios; a investigação é permitida e, de facto, incentivada.
Encontrar o melhor algoritmo para o problema é uma competência essencial na engenharia de software.
