# Introdução

Uma `list` em R é uma coleção ordenada de itens, que difere dos `vectors` de algumas formas:

- Os itens podem ser de tipos diferentes (por exemplo, misturar `numeric` com `character`).
- Os itens podem ser estruturas complexas (por exemplo, vetores, outras listas, etc).
- Existe uma sintaxe diferente para aceder aos elementos.

As analogias com outras linguagens são imprecisas.
Uma `list` de R é um pouco semelhante a um dicionário de Python, mas a `list` é ordenada e pode ser acedida por índice numérico.
É um pouco semelhante a uma `struct` de C, exceto que a `list` pode ser facilmente estendida em tempo de execução.

## Criar listas

Dar nomes (muitas vezes chamados de etiquetas) aos elementos é mais comum em listas do que em vetores:

```R
list(x = 5.3, y = 4.2, color = "blue")
$x
#> [1] 5.3

$y
#> [1] 4.2

$color
#> [1] "blue"
```

No entanto, as etiquetas são opcionais e o R vai usar apenas números de índice:

```R
list(5.3, 4.2, "blue")
#> [[1]]
#> [1] 5.3

#> [[2]]
#> [1] 4.2

#> [[3]]
#> [1] "blue"
```

## Aceder aos elementos de uma lista

Há três formas de fazer isto, cada uma útil em contextos diferentes.

### 1. Com a notação `$tag`

Muito comum se os nomes das etiquetas forem conhecidos de antemão.

```R
point <- list(x = 5.3, y = 4.2, color = "blue")
point$x
#> [1] 5.3
point$color
#> [1] "blue"
```

### 2. Com a notação `[[tag]]`

Isto tem a vantagem de o nome da etiqueta poder ser escolhido em tempo de execução.
Repara nos parênteses retos duplos.

```R
want <- "y"
point[[want]] # same as point$y
#> [1] 4.2
```

### 3. Com índice de posição

Isto funciona quer a lista tenha etiquetas quer não.
Mais uma vez, os parênteses retos são duplos.

```R
point[[3]] # same as point$color
#> [1] "blue"
```

## Adicionar e eliminar elementos

Simples: atribuir a um elemento modifica-o se ele existir ou insere-o se for novo.

```R
point$color <- "red"
point[[trust]] <- TRUE
str(point)
#> List of 4
#>  $ x    : num 5.3
#>  $ y    : num 4.2
#>  $ color: chr "red"
#>  $ trust: logi TRUE
```

Para eliminar, atribui `NULL` ao elemento indesejado.

```R
point$trust <- NULL
str(point)
#> List of 3
#>  $ x    : num 5.3
#>  $ y    : num 4.2
#>  $ color: chr "red"
```
