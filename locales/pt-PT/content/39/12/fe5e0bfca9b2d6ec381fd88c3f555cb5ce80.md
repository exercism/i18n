# Testes

## Correr os testes

Para correr os testes, executa o seguinte comando:

```bash
make
```

## Resolver o exercício

Resolver um exercício significa fazer com que todos os seus testes passem.
Por predefinição, apenas um teste (o primeiro) é executado quando corres os testes.
Isto é intencional, pois permite-te que te concentres apenas em fazer esse teste passar.
Assim que passar, podes ativar o teste seguinte removendo a linha `TEST_IGNORE()`.
Quando todos os testes estiverem ativados e a tua implementação os fizer passar, terás resolvido o exercício!
