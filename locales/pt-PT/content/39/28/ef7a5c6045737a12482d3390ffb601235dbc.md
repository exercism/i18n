# Números

`INT` é o tipo de Sather para números inteiros: `0`, `7`, `-3`. Uma rotina que responde com um número inteiro diz isso depois dos dois pontos, tal como uma rotina que responde com texto diz `STR`.

```sather
   goals : INT is
      return 42;
   end;
```

As rotinas podem receber **argumentos**: valores que lhes são passados quando são chamadas. Cada argumento tem um nome e um tipo, entre parênteses, a seguir ao nome da rotina:

```sather
   total(first : INT, second : INT) : INT is
      return first + second;
   end;
```

Quando dois argumentos têm o mesmo tipo, podes indicá-los juntos:

```sather
   total(first, second : INT) : INT is
```

Chama-a pondo os valores entre parênteses:

```sather
SCORES::total(3, 4)     -- this is 7
```

Os cinco operadores aritméticos são `+`, `-`, `*`, `/` e `%`.

A `/` entre dois `INT`s é **divisão inteira**: descarta o resto em vez de dar uma fração.

```sather
7 / 2      -- 3, not 3.5
```

O `%` dá o que sobra dessa divisão.

```sather
7 % 2      -- 1
```

Os dois andam juntos: `7` é `3` vezes `2` com `1` de resto.
