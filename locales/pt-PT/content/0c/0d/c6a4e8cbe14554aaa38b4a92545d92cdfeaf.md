# Debug

Quando um teste falha, aparece uma mensagem a descrever o que correu mal e para que valor de entrada. Além disso, qualquer [saída para a consola][dotnetperls.com-console-vbnet] também será mostrada. Podes escrever para a consola com:

```vbnet
Console.WriteLine("Debug message");
```

[dotnetperls.com-console-vbnet]: https://www.dotnetperls.com/console-vbnet
