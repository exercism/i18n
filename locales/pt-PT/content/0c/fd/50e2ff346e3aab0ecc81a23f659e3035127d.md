# Sobre

Além de `cond`, o Elixir também fornece a macro [`if/2`][getting-started-if], que é útil quando precisas de verificar apenas uma condição.

[`if/2`][kernel-if] aceita uma condição e duas opções. Devolve a primeira opção se a condição for _truthy_, e a segunda opção se a condição for _falsy_.

```elixir
age = 15

if age >= 16 do
  "You are allowed to drink beer in Germany."
else
  "No beer for you!"
end

# => "No beer for you!"
```

Se a segunda opção não for indicada, será devolvido `nil`.

```elixir
age = 15

if age >= 16 do
  "You are allowed to drink beer in Germany."
end

# => nil
```

Também é possível escrever uma expressão `if` numa única linha. Repara na vírgula depois da condição.

```elixir
if age >= 16, do: "beer", else: "no beer"
```

Esta sintaxe é útil para expressões muito curtas, mas deve ser evitada se a expressão não couber numa única linha.

## _Truthy_ e _falsy_

No Elixir, todos os tipos de dados são avaliados como um valor _truthy_ ou _falsy_ quando aparecem num contexto booleano (como uma expressão `if`). Todos os dados são considerados _truthy_, **exceto** `false` e `nil`. Em particular, as strings vazias, o número inteiro `0` e as listas vazias são todos considerados _truthy_ no Elixir. Desta forma, [o Elixir é semelhante ao Ruby, mas diferente de JavaScript, Python ou PHP][falsy-various-langs].

```elixir
truthy? = fn x -> if x, do: "truthy", else: "falsy" end

truthy?.(true)
# => "truthy"
truthy?.(0)
# => "truthy"
truthy?.([])
# => "truthy"

truthy?.(false)
# => "falsy"
truthy?.(nil)
# => "falsy"
```

Os operadores booleanos [`&&/2`][kernel-and], [`||/2`][kernel-or] e [`!/1`][kernel-not] são operadores booleanos _truthy_ que funcionam com qualquer valor, e complementam os operadores booleanos _strict_ [`and/2`][kernel-boolean-and], [`or/2`][kernel-boolean-or] e [`not/1`][kernel-boolean-not].

```elixir
0 and true
# => ** (BadBooleanError) expected a boolean on left-side of "and", got: 0

0 && true
# => true
```
