# Dicas

## 1. Calcula a taxa de juro

- Espera-se que devolvas uma percentagem.

## 2. Calcula o juro

- Ao calcular o juro, pode ser útil reparar que `interest_rate` devolve uma percentagem.
- Podes usar a função definida na tarefa anterior (`interest_rate`) para calcular o juro.

## 3. Calcula a atualização anual do saldo

- Ao calcular a atualização anual do saldo, usa as funções que foram definidas nos passos anteriores.

## 4. Calcula os anos necessários para alcançar o saldo desejado

- Para calcular os anos, podes continuar a iterar até atingires o saldo desejado, usando um ciclo [`for`][for].
- Existe um [operador][increment] especial para incrementar valores em 1.
