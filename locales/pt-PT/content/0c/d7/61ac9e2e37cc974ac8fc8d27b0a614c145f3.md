# Introdução

Criar uma instância de uma classe faz-se chamando o seu _construtor_ através do operador `new`. Um construtor é um método especial dentro de uma classe cujo objetivo é inicializar a classe. Em Haxe, o método construtor chama-se `new()`.

```haxe
class Library {
  private var books:Int;

  public function new() {
    this.books = 10; // Initialize the books field
  }
}

var library = new Library(); // This calls the constructor
```

Tal como os métodos normais, os construtores podem ter parâmetros. Estes parâmetros são (normalmente) guardados em campos privados e acedidos mais tarde.

```haxe
class Building {
  private var numberOfStories:Int;
  private var totalHeight: Float;

  public function new(numberOfStories:Int, storyHeight:Float) {
    this.numberOfStories = numberOfStories;
    this.totalHeight = storyHeight * numberOfStories;
  }
}

var largeBuilding = new Building(55, 6.2);
```
