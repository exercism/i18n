# Anexo às instruções

## Instruções específicas do track

### Memória reservada

Os bytes 64 a 447 da memória linear estão reservados para a string de entrada.

A string de entrada pode ser modificada no local, se quiseres.

### Formato da string de entrada

Cada linha contém o nome da primeira equipa, depois um ponto e vírgula `;`, depois o nome da segunda equipa, outro ponto e vírgula `;`, o resultado da partida (`"win"`, `"draw"`, `"loss"`) e, por fim, uma mudança de linha `\n`.
