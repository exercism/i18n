# Introdução

O Swift tem instruções de transferência de controlo para alterar o fluxo de execução dos ciclos e das instruções switch.
Além do `return`, o Swift inclui `continue`, `break`, rótulos de ciclo e `fallthrough`.

## Continue

A instrução `continue` diz a um ciclo para parar de executar a iteração atual e começar imediatamente a iteração seguinte.
Num ciclo `while` ou `repeat-while`, salta diretamente para a verificação da condição.
Num ciclo `for-in`, avança para o elemento seguinte da sequência.

```swift
var count = 1
while count < 6 {
    count += 1
    if count == 4 {
        continue
    }
    print(count)
}

// Prints:
// 2
// 3
// 5
// 6
```

## Break

A instrução `break` sai imediatamente de um ciclo ou de uma instrução switch completos.
A execução retoma na primeira linha de código a seguir ao ciclo ou à instrução switch.

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
    if !fruit.count.isMultiple(of: 2) {
        break
    }
    print(fruit)
}

// Prints:
// banana
// grapes
```

## Instruções com rótulos

Em ciclos aninhados, podes querer que o `break` ou o `continue` afetem um ciclo exterior em vez do ciclo mais interior.
Podes rotular um ciclo colocando à frente dele um nome seguido de dois pontos (`labelName:`).
Depois, podes passar esse rótulo ao `break` ou ao `continue`:

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
    print("\n--- \(fruit) ---")
    for letter in fruit {
        guard letter != "n" else {
            break outerLoop
        }
        print(letter)
    }
}

// Prints:
// --- banana ---
// b
// a
```
