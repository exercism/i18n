# Instruções

A Tori é jornalista de clima e quer escrever um artigo sobre o tempo em diferentes cidades. Tem dados sobre o tempo em várias cidades e quer ordená-las com base na temperatura, mas algumas temperaturas estão em Fahrenheit e outras em Celsius. Precisa da tua ajuda para converter as temperaturas para a mesma unidade e ordená-las.

## 1. Converter Fahrenheit em Celsius

Define a função `fahrenheit_to_celsius`, que recebe uma temperatura em Fahrenheit como argumento e devolve a temperatura em Celsius.

Para converter Fahrenheit em Celsius, subtrai 32 ao valor em Fahrenheit e depois divide o resultado por 1.8.

```gleam
fahrenheit_to_celsius(72.5)
// -> 22.5
```

## 2. Comparar duas temperaturas

Define a função `compare_temperature`, que recebe duas temperaturas e devolve um valor `Order` que indica se a primeira temperatura é menor, igual ou maior do que a segunda.

```gleam
compare_temperature(Celsius(30.5), Fahrenheit(82.1))
// -> Gt
```

## 3. Ordenar cidades por temperatura

Define a função `sort_cities_by_temperature`, que recebe uma lista de cidades e devolve-as da mais fria para a mais quente.

```gleam
sort_cities_by_temperature([
  City(name: "London", temperature: Celsius(30.5)),
  City(name: "Paris", temperature: Fahrenheit(82.1))
])
// -> [
//   City(name: "Paris", temperature: Fahrenheit(82.1)),
//   City(name: "London", temperature: Celsius(30.5)))
// ]
```
