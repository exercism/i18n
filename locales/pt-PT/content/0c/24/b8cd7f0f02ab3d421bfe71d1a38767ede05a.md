# Sobre

O [operador condicional ternário][ternary-operator] é uma forma abreviada e concisa de escrever uma expressão `if-else`.
Avalia uma condição e devolve um de dois valores, dependendo de a condição ser `true` ou `false`.

O operador usa três partes: `condition ? trueExpression : falseExpression`.
Se `condition` for avaliada como `true`, `trueExpression` é avaliada e devolvida; caso contrário, `falseExpression` é avaliada e devolvida.

O operador ternário é ideal para escolhas simples, numa só linha:

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = showFahrenheit ? temperatureInCelsius * 9 / 5 + 32 : temperatureInCelsius
print(temperature)
// Prints 86
```

O exemplo acima é um equivalente compacto de:

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = if showFahrenheit {
    temperatureInCelsius * 9 / 5 + 32
} else {
    temperatureInCelsius
}
```

[ternary-operator]: https://docs.swift.org/swift-book/LanguageGuide/BasicOperators.html#ID71
