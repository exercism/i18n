# Sobre

A recursão é uma forma de repetir código dentro de uma função, fazendo com que a função se chame a si própria.
É outra forma de fazer ciclos ou de iterar. Tal como nos ciclos, a função deve testar uma expressão Boolean para saber quando terminar.
Ao contrário dos ciclos, uma recursão que nunca termina não corre infinitamente.
Os valores usados em cada chamada da função podem ser colocados no seu próprio quadro na pilha.
Se o número de chamadas da função ocupar mais espaço do que a pilha tem, o resultado é um erro de transbordamento da pilha.

```c
int printIncrement (int i, int maxValue){
    if (i > maxValue) return i;
    printf("The number is %i\n", i++);
    printIncrement(i, maxValue);
}

int main() {
    printIncrement(1, 2);
    printf("After recursion");
    return 0;
}
```

Isto imprime

```
The number is 1
The number is 2
After recursion
```

Há situações que são mais legíveis e/ou mais fáceis de compreender quando expressas através de recursão do que através de ciclos.


## Chamada de cauda

Uma chamada de cauda acontece quando a última instrução de uma função se limita a chamar a própria função, e nada mais.

Uma chamada de cauda é uma forma particular de recursão que pode permitir ao compilador otimizar a recursão para um ciclo no código compilado.
Assim, tens o melhor dos dois mundos: a legibilidade da recursão com o desempenho de um ciclo.
A compilação da recursão para um ciclo chama-se `tail call elimination` ou `tail call optimization.`

Quando uma chamada de cauda é compilada para um ciclo, não é criado um novo quadro de pilha para cada chamada da função.
O endereço da função, tal como foi chamada originalmente, recebe os valores atualizados, o que poupa espaço na pilha e melhora o desempenho.

Este exemplo não é uma chamada de cauda, porque a função soma 1 ao resultado da chamada a si própria

```c
int printIncrement (int i, int maxValue){
    if (i > maxValue) return 1;
    printf("The number is %i\n", i++);
    return 1 + printIncrement(i, maxValue);
}

int main() {
    int j = printIncrement(1, 2);
    printf("j is %i after recursion", j);
    return 0;
}
```

Isto imprime

```
The number is 1
The number is 2
j is 3 after recursion
```

Para o refatorar como chamada de cauda, transforma `j` num parâmetro de `printIncrement`

```c
int printIncrement (int i, int maxValue, int j){
    if (i > maxValue) return j;
    printf("The number is %i\n", i++);
    return printIncrement(i, maxValue, ++j);
}

int main() {
    int j = printIncrement(1, 2, 1);
    printf("j is %i after recursion", j);
    return 0;
}
```

Podes achar que uma chamada de cauda é mais fácil de compreender do que uma chamada recursiva que não é uma chamada de cauda.
No entanto, os compiladores normalmente não garantem que todas as chamadas de cauda sejam otimizadas.
Ao usar recursão, é sempre importante garantir que não haverá tantas iterações que a pilha transborde.
