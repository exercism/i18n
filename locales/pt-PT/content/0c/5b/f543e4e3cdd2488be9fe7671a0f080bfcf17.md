# Sobre

O ClojureScript é um compilador de Clojure cujo alvo é o JavaScript. Emite código JavaScript compatível com o modo de compilação avançado do compilador de otimização Google Closure.

## Porquê o Clojure?

O Clojure é uma linguagem de programação dinâmica e de uso geral que suporta o desenvolvimento interativo. É uma linguagem de programação funcional, com um conjunto rico de estruturas de dados imutáveis e persistentes. Enquanto dialeto de Lisp, tem uma filosofia de código como dados e um sistema de macros poderoso.

## Porquê o JavaScript?

A difusão do navegador e das aplicações web deu ao JavaScript um alcance exclusivo, inigualável por qualquer outra linguagem. Devido à sua importância, os motores de JavaScript também têm recebido muita investigação e otimização, o que permite ao JavaScript competir em desempenho com plataformas muito mais estabelecidas, como a JVM.

## Porquê o Google Closure?

Como fornecedores de algumas das aplicações web cliente-serviço mais complicadas em uso atualmente, a Google investiu fortemente na criação da biblioteca Closure e do compilador Closure, que funcionam em conjunto para tornar possível a otimização de todo o programa, produzindo programas com tempos de carregamento mínimos mesmo quando usam muitas bibliotecas.

## Oportunidade

O ClojureScript combina o alcance da plataforma JavaScript, a flexibilidade e o desenvolvimento interativo do Clojure e a otimização de todo o programa do Google Closure para oferecer a linguagem mais poderosa para programar para a web.
