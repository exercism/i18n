Raku é uma linguagem de programação incrivelmente rica, flexível e poderosa.
A sua flexibilidade permite aos programadores escrever código expressivo que se adequa ao seu próprio estilo.

O Raku é uma linguagem vasta, com muita profundidade para aprender, explorar e experimentar.
Este programa pretende abordar os fundamentos para que possas começar.

A programação orientada a objetos está no coração do Raku, mas não impõe práticas de programação orientada a objetos.
Devido à sua natureza orientada a objetos, este programa fará frequentemente referência a [objetos, classes e métodos][object-orientation].

## Variáveis

Para manter as coisas simples, em basics vamos usar apenas [variáveis][variables] escalares.

As variáveis escalares são [identificadores][identifiers] precedidos pelo sigilo `$`.

As variáveis escalares podem conter praticamente tudo e têm como tipo predefinido [`Any`][Any].

A maioria das variáveis que usares vai precisar de uma [declaração][variable-declarator].
Por agora, fica-te pelo [`my`][my] e pelo [`constant`][constant].

```raku
my $foo;
constant $BAR;
```

## Sub-rotinas

Uma sub-rotina é declarada com o declarador [`sub`][sub-declarator].

Uma declaração `sub` é seguida de um [identificador][identifiers] opcional, depois de uma [assinatura][signatures] opcional e, por fim, de um [bloco][blocks].

As sub-rotinas (entre outras coisas) podem ser exportadas adicionando o trait [`is export`][exporting].

Uma sub-rotina pode ser chamada com um operador [postcircumfix `( )`][postcircumfix-()] aplicado ao identificador.

```raku
sub foo ($bar) is export { ... } # Subroutine definition

foo($bar); # Subroutine call
```

## Operadores

O Raku tem uma grande variedade de [operadores][operators].
Nos exercícios do conceito basics, vamos usar alguns operadores matemáticos básicos em Raku, como `+` e `-`.

```raku
say 0.1 + 0.2 - 0.3;
# Raku is not like other languages -> https://0.30000000000000004.com/#raku
```

Podes facilmente definir os teus próprios operadores em Raku, se quiseres.
A maioria dos operadores incorporados também está disponível como sub-rotinas.

## Pacotes e Módulos

Existem vários tipos de [pacotes][package-declarator] em Raku. No basics, vamos usar apenas `module`.

Para declarar um ficheiro inteiro como um `module`, a declaração do módulo é precedida de `unit`.

```raku
unit module Foo;

sub bar () { ... }
```

## Comentários

O Raku tem comentários [de uma linha][single-line-comments] e [de várias linhas/incorporados][multi-line-comments].

Os comentários de uma linha começam com `#` e continuam até ao fim da linha.

Os comentários de várias linhas/incorporados começam com um cardinal seguido de um acento grave e de um caráter Unicode de Pontuação de Abertura.
Terminam com um caráter de fecho emparelhado correspondente.

```raku
# This is a single-line comment

#`(
    This is a
    multi-line/embedded comment
)
```

## Convenções de Estilo

Os [identificadores][identifiers] de variáveis e de sub-rotinas em Raku seguem o estilo `kebab-case`.
As constantes seguem o estilo `ALL-CAPS`.
Os nomes dos pacotes seguem o estilo `PascalCase`.
