# Letreiros personalizados

## História

Neste exercício vais escrever código para ajudar uma empresa de letreiros a criar mensagens personalizadas para os seus letreiros.

## Tarefas

Estas são tarefas de exemplo que se enquadram na história de um cliente a desenhar um letreiro personalizado:

- Cria um conjunto de strings úteis
- Cria um conjunto de carateres úteis
- Combina frases para construir mensagens
- Cria um letreiro de fim de curso
- Calcula o custo de um letreiro
