# Instruções

Geres um cinema exclusivo.
Para assistir a um filme, as pessoas têm de comprar passes anuais e, a partir daí, podem ver filmes gratuitamente.

O teu cinema mantém um registo de entradas.
Queres usar esse registo para acompanhar que sócios usaram o passe anual este mês.
Também queres obter informações sobre a distribuição etária dos teus clientes.
Percebes que podes usar conjuntos para atingir estes objetivos.

## Conjuntos

Um conjunto é o tipo de dados perfeito para guardar este tipo de informação.

Um conjunto é um tipo de dados usado para guardar valores distintos e únicos, sem qualquer ordem em particular.
Distintos e únicos significa que um elemento está no conjunto ou não está; ao contrário do que acontece com um array, não pode estar no conjunto mais do que uma vez.
Normalmente, os conjuntos não têm ordem; se listares os elementos de um conjunto, a ordem que obténs pode ser diferente da ordem em que foram adicionados, ou até diferente da ordem que obtiveste na listagem anterior!

Uma propriedade fundamental dos conjuntos é a verificação de pertença: a capacidade de verificar se um conjunto contém um elemento.
A verificação de pertença está no centro de quase todas as utilizações de um conjunto.

O Go não disponibiliza um tipo de dados de conjunto incorporado.
É comum usar um `map[<type>]struct{}` ou um `map[<type>]bool` no lugar de um conjunto; tal como um conjunto, um `map` permite adicionar elementos distintos e únicos e suporta verificações de pertença.

## 1. Um local para guardar a informação dos espetadores

Para acompanhar a assiduidade e a distribuição etária, queres usar um conjunto.

Não queres escrever conjuntos separados para nomes e idades; em vez disso, podes usar um conjunto genérico para ambos.
Define um tipo `Set` como `map[T comparable]struct{}` para guardar os espetadores.
Escreve uma função `NewSet[T comparable]()` que devolve um `Set[T]` vazio.

```go
names := NewSet[string]()
```

## 2. Acompanhar os espetadores

Agora já podes registar a informação dos espetadores.

Escreve um método `Add[T]()` que adiciona um elemento ao conjunto.

```go
names := NewSet[string]()
names.Add("Alice")
```

## 3. Verificar os espetadores

Agora que tens um conjunto de espetadores, podes verificar se sócios e faixas etárias específicas apareceram.
Escreve um método `Contains[T](element)` que devolve se um sócio ou uma faixa etária está no `Set`.

```
names := NewSet[string]()
names.Add("Alice")
names.Contains("Alice")
// => true
names.Contains("Bob")
// => false
```

## 4. Comparar os espetadores

Passou mais um mês e tens um novo `Set` de faixas etárias.
O teu responsável de marketing quer saber se as estreias deste mês mudaram as faixas etárias que aparecem.
Escreve um método `Equals[T](other)` que determina se dois conjuntos têm os mesmos elementos.

```go
agesOne := NewSet[int]()
names.Add(25)

agesTwo := NewSet[int]()
names.Add(25)

agesOne.Equals(agesTwo)
// => true

agesThree := NewSet[int]()
names.Add(35)

agesOne.Equals(agesThree)
// => false
```
