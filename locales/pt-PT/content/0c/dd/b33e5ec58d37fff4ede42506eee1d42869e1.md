# não alteres as assinaturas fornecidas

Como as instruções referem, não deves alterar as assinaturas de `makeChest` e `makeTreasureChest`.
Estas devem permanecer exatamente assim:

```elm
makeChest : String -> treasure -> Chest treasure {}

makeTreasureChest : Chest treasure { conditions | securePassword : (), uniqueTreasure : () } -> TreasureChest treasure
```
