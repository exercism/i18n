# Introdução

As tuplas são uma forma simples de agrupar um conjunto fixo de dados de tipos arbitrários.
Uma tupla pode ter um número arbitrário de elementos.
Podes aceder aos elementos recorrendo à desestruturação.

```rust
fn main() {
    let tup: (u32, u64, bool) = (10, 20, true);
}

fn main() {
    let (x, y, z) = (500, 6, true);

    if y == 6 {
        println!("y is 6!");
    }
}
