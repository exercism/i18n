# Intervalos

Os [intervalos][range] representam um intervalo entre dois valores.
Os tipos mais comuns que suportam intervalos são `Int`, `Char` e `String`.
Podem ser usados para muitas coisas, como criar rapidamente uma coleção, extrair partes de strings, verificar se um valor está dentro de um intervalo e iteração.
São criados com o operador de intervalo `..` ou `...` (inclusivo e exclusivo, respetivamente).

```crystal
1..5  # A range containing 1, 2, 3, 4, 5
1...5 # A range containing 1, 2, 3, 4
```

A razão para existirem dois operadores de intervalo é permitir criar intervalos que incluem ou excluem o valor final, o que pode ser útil quando, por exemplo, trabalhas com índices com base em zero.

Os intervalos também podem ser criados com o inicializador `Range`.

```crystal
Range.new(1, 5) # A range containing 1, 2, 3, 4, 5
```

~~~~exercism/note
Ao criar um intervalo em Crystal com os operadores de intervalo `..` ou `...`, e querendo chamar um método ao intervalo, tens de envolver o intervalo em parênteses.
Isto acontece porque, caso contrário, o método será chamado sobre o segundo argumento do operador de intervalo.

```crystal
(1..5).size # => 5
1..5.size # => Error: undefined method 'size' for Int32
```
~~~~

## Obter substrings

Quando queres extrair uma parte de uma string, podes usar o operador de intervalo para obter uma substring.
Ou seja, criando um intervalo com o índice inicial e final da substring.

```crystal
"Hello World"[0..4] # => "Hello"
"Hello World"[6..10] # => "World"
```

Também podes usar índices negativos para obter a substring a partir do fim da string.

```crystal
"Hello World"[-5..-1] # => "World"
"Hello World"[6..-4] # => "Wo"
```

## Métodos dos intervalos

Os intervalos têm um conjunto de métodos que podem ser usados para trabalhar com eles.
Por exemplo, estes métodos podem ser usados para obter a soma de todos os valores do intervalo ou verificar se o intervalo inclui um valor.

| Método                  | Descrição                                                             | Exemplo                         |
|-------------------------|-------------------------------------------------------------------------|---------------------------------|
| [`sum`][sum]            | Devolve a soma de todos os valores do intervalo                          | `(1..5).sum # => 15`            |
| [`size`][size]          | Devolve o tamanho do intervalo                                           | `(1..5).size # => 5`            |
| [`includes?`][indludes] | Devolve `true` se o intervalo incluir o valor indicado, caso contrário `false` | `(1..5).includes?(3) # => true` |

## Intervalos sem fim e sem início

Um intervalo pode ser sem fim e sem início.
Um intervalo sem fim ou sem início tem o valor inicial ou final como `nil`, mas o `nil` pode ser omitido ao definir o intervalo.

Usar intervalos sem início e sem fim é útil quando queres, por exemplo, extrair uma parte de uma string desde o início ou até ao fim.

```crystal
"Hello World"[0..] # => "Hello World"
"Hello World"[4..] # => "o World"
"Hello World"[..5] # => "Hello"
```

~~~~exercism/caution
Se não for usado sobre uma coleção, o intervalo sem fim pode originar uma sequência sem fim, caso não seja usado com cuidado.
~~~~

## Intervalos de Char

Os chars podem ser usados em intervalos e permitem obter um intervalo de chars entre dois chars.
Por exemplo, isto pode ser útil quando queres obter o alfabeto.

```crystal
'a'..'z' # A range containing ['a', 'b', 'c', ..., 'z']
```

## Intervalos de strings

As strings também podem ser usadas em intervalos, permitindo obter um intervalo de strings entre duas strings.
Mas o seu comportamento é ligeiramente diferente do de `Char` quando se usam vários carateres num intervalo de strings.
O comportamento pode tornar-se confuso ao criar intervalos de strings mais complexos, por isso tem cuidado.

```crystal
("aa".."az") # A range containing ["aa", "ab", "ac", ..., "az"]
```

## Objetos personalizados em intervalos

~~~~exercism/advanced
O Crystal permite-te usar objetos personalizados em intervalos.
Para isso, o objeto tem de implementar o seguinte:

- incluir o módulo `Comparable`
- o método `succ`
- o método `<=>`

Estes métodos permitem que o intervalo consiga iterar sobre o objeto e comparar os objetos no intervalo.

```crystal
class Foo
  include Comparable(Foo)

  getter value

  def initialize(@value : Int32)
  end

  def succ
    Foo.new(value + 1)
  end

  def <=>(other : Foo)
 value <=> other.value
  end
end

Foo.new(1)..Foo.new(5)
# => #<Foo:0x7f3552bebe70 @value=1>, #<Foo:0x7f3552bebe50 @value=2>, #<Foo:0x7f3552bebe40 @value=3>, #<Foo:0x7f3552bebe30 @value=4>, #<Foo:0x7f3552bebe20 @value=5>
```
~~~~
