# Instruções

A Ellen está a fazer um jogo em que o jogador tem de combater aliens.
Acabou de aprender Programação Orientada a Objetos (POO) e está ansiosa por tirar partido daquilo que a utilização de `classes` pode oferecer ao seu programa.

Para alegria da Ellen, ofereceste-te para ajudar e ela deu-te a tarefa de programar os aliens que o jogador tem de combater.


## 1. Cria a classe `Alien`

Define a classe `Alien` com um construtor que aceita dois parâmetros `int`, `x` e `y`, colocando-os nas variáveis membro `x_coordinate` e `y_coordinate`.
Todos os aliens começam também com um nível de saúde de `3`, por isso a variável membro `health` também deve ser inicializada.

`health` deve ser uma variável membro privada.
Para deixar que outras partes do programa leiam a informação relativa à saúde, a Ellen quer ter um método `public` `get_health()` que devolve um `int`.

```cpp
Alien alien{2, 0};
alien.x_coordinate;
// => 2
alien.y_coordinate;
// => 0
alien.get_health();
// => 3
```

Agora, cada alien deve conseguir acompanhar internamente a sua própria posição e a sua saúde.

## 2. A função `hit`

A Ellen gostaria que a `class` Alien tivesse um método `hit` que diminui em `1` a saúde de um objeto alien quando é chamado.
Assim, pode simplesmente chamar `some_alien_instance.hit()` em vez de ter de alterar manualmente a saúde de um alien.
Certifica-te de que os pontos de saúde não descem abaixo de zero.
A função deve devolver `true`.
A Ellen quer introduzir escudos mais tarde, que então reportariam `false` se o escudo estiver ativo.

```cpp
Alien alien {0, 0};
alien.get_health();
// => 3 (Initial health value)

alien.hit(); // Decrements health by 1 point.
alien.get_health();
// => 2
```

## 3. A função `is_alive`

Percebes que, se a saúde continuar a diminuir, a certo ponto provavelmente chegará a `0`.
Seria boa ideia acrescentar um método `is_alive` que a Ellen possa chamar rapidamente para verificar se o alien está... bem... vivo. 😉
`some_alien_instance.is_alive()` deve devolver um Boolean.

```cpp
alien.get_health();
// => 1
alien.is_alive();
// => true
alien.hit();
alien.get_health();
// => 0
alien.is_alive();
// => false
```

## 4. A função `teleport`

No jogo da Ellen, os aliens podem teletransportar-se!
Vais precisar de escrever um método `teleport` que recebe os valores `x_new` e `y_new` e altera as coordenadas do alien em conformidade.
Por agora, a função deve devolver `true`.
A Ellen quer acrescentar bombas que bloqueiam o teletransporte em níveis posteriores, que então reportariam `false` para tentativas de teletransporte falhadas.

```cpp
alien.teleport(5, -4);
alien.x_coordinate;
// => 5
alien.y_coordinate;
// => -4
```

## 5. A função `collision_detection`

Se os aliens podem ser atingidos por algo, então precisam de conseguir detetar quando tal colisão pode ocorrer.
A Ellen precisa de saber se dois aliens ocupam as mesmas coordenadas.
A função `collision_detection()` recebe outro objeto alien como argumento e devolve um `bool`.

```cpp
Alien lrrr {3, 6};
Alien ndnd {-2, 12};
lrrr.collision_detection(ndnd);
// => false
ndnd.teleport(3, 6);
ndnd.collision_detection(lrrr);
// => true
```
