## Geral

- Ordenar uma lista de mãos de póquer pode ser visto como um problema de ordenação.
- O Rust disponibiliza o método [sort](https://doc.rust-lang.org/std/vec/struct.Vec.html#method.sort) para `Vec<T> where T: Ord`.
- [Os tipos `Ord`](https://doc.rust-lang.org/std/cmp/trait.Ord.html) formam uma [ordem total](https://en.wikipedia.org/wiki/Total_order): exatamente uma das expressões `a < b`, `a == b` ou `a > b` tem de ser verdadeira.
- As mãos de póquer não seguem uma ordem total: é possível que duas mãos não sejam iguais mas tenham a mesma ordenação. Exemplo: `"3S 4S 5D 6H JH"`, `"3H 4H 5C 6C JD"`.
- O Rust disponibiliza a [trait `PartialOrd`](https://doc.rust-lang.org/std/cmp/trait.PartialOrd.html) para tratar o caso de coisas ordenáveis que não têm uma ordem total. No entanto, não disponibiliza um método `sort` padrão para `Vec<T> where T: PartialOrd`. A forma habitual de ordenar um vetor neste caso é `your_vec.sort_by(|a, b| a.partial_cmp(b).unwrap_or(Ordering::{Less|Equal|Greater}));`, consoante as tuas necessidades.
- Podes considerar implementar um tipo que representa uma mão de póquer e que implemente `PartialOrd`.
