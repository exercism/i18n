# Dicas

As três primeiras tarefas chamam todas a mesma função `print_name_badge()`.
A implementação pode ser construída passo a passo, acrescentando a lógica para as tarefas 2 e 3 à medida que avanças.

## 1. Cria um badge para um funcionário

- Este é o caso predefinido: basta juntar os 3 argumentos numa string adequada.
- A [interpolação de strings][interpolation] é provavelmente a abordagem mais fácil.

## 2. Cria um badge para um novo funcionário

- Agora o ID é `missing,`, por isso o formato da string de destino é diferente.
- [`ismissing()][ismissing] é útil aqui.
- A Julia tem um [operador ternário][ternary] com uma sintaxe concisa.

## 3. Cria um badge para o proprietário

- Agora o departamento é `nothing`.
- Existe uma função [`isnothing()`][isnothing].

## 4. Calcula o salário total dos funcionários sem ID

- Falta [algum][any] ID? Se não, o valor devolvido é zero.
- Para extrair as entradas com ID em falta, pode ajudar começar por [fazer zip][zip] dos vetores `ids` e `salaries`.
- Há várias formas de iterar sobre o vetor de tuplos resultante, sem escreveres um ciclo explícito.
  - Ao estilo de Python, com uma [compreensão][comprehension] de vetores.
  - De forma funcional, com [`map()`][map] e uma [função anónima][anonymous].
  - De forma vetorial, com [broadcasting][broadcasting] de uma [função anónima][anonymous].
- No final, haverá um [`sum()`][sum] sobre um vetor de salários modificado.
   - Os salários dos funcionários com ID podem ser omitidos ou definidos como zero.
