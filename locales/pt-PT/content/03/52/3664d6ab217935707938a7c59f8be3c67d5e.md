# Dicas

## Geral

## 1. Verifica quais eram as contagens na semana passada

- Devolve o _penúltimo_ elemento do array.

## 2. Verifica quantas aves visitaram ontem

- Como os dados são um array de arrays, tens de indexar uma vez para obteres o array semanal correto e voltar a indexar para obteres o dia que queres.
- O «Hoje» é o último elemento do array semanal.

## 3. Calcula o número total de aves que visitaram o jardim

- É possível calcular a soma de um array com o filtro [add][manual-add].
  Viste esta expressão no conceito Basics e no exercício Shopping.

## 4. Calcula o número de dias movimentados

- Tens de _selecionar_ os dias com uma contagem maior ou igual a 5 e depois devolver o tamanho do array resultante.

## 5. Verifica se houve algum dia sem visitas de aves

- A versão de um argumento do filtro [any][manual-any] será a mais adequada.

[manual-add]: https://jqlang.org/manual/#add
[manual-any]: https://jqlang.org/manual/#any
