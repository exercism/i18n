# Instruções

A empresa para a qual trabalhas quer reduzir a sua pegada de carbono, por isso quer que escrevas um programa para calcular o consumo de energia e o custo de funcionamento dos seus equipamentos eletrónicos.

## 1. Obter as horas extra

O teu empregador tem um programa que calcula quanto tempo demoram a funcionar os diferentes equipamentos eletrónicos.
Neste momento, o tempo está armazenado em horas.
Quando o teu empregador somou as horas, reparou que a duração não estava correta.
Querem que acrescentes 3 horas extra aos dados de tempo.
Também gostariam de saber quantas horas "extra" sobram depois de converteres os dados em dias "completos" (um dia tem 24 horas).
O tempo a converter pode não estar em dias completos.

Implementa uma função `get_extra_hours()` que aceita um número inteiro que representa o número de horas.
A função deve fazer o ajuste adequado das "horas extra" e depois `return` um número inteiro que representa quantas horas é preciso retirar ao total para obteres o tempo em dias "completos".

```python
>>> get_extra_hours(25)
4
```

## 2. Obter o valor em kW

O teu empregador quer saber o consumo de energia dos diferentes equipamentos eletrónicos em kW.
kW significa quilowatt, e o watt é uma unidade de potência.
O quilo, no nome da unidade, é um prefixo do sistema métrico que significa 1000.
Um quilowatt == 1000 watts.

Implementa uma função `get_kW_value()` que aceita um número inteiro que representa o número de watts.
A função deve depois `return` os watts em quilowatts, arredondados a 1 casa decimal.

```python
>>> get_kW_value(1150)
1.2
```

## 3. Obter o valor em kWh

Para conseguires calcular o custo de funcionamento dos equipamentos eletrónicos, o teu empregador precisa de saber o consumo de energia em kWh.
kWh significa quilowatt-hora, em que a hora é uma unidade de tempo.
Um quilowatt-hora == 1000 watts utilizados durante 1 hora.
Uma hora é composta por 60 minutos e um minuto é composto por 60 segundos.
Uma hora é igual a 3600 segundos.
Para calcular o valor em kWh, tens de converter os watts em kW e depois fazer a divisão inteira do resultado por 3600.

Implementa uma função `get_kWh_value()` que aceita um número inteiro que representa o número de watts.
A função deve depois `return` os quilowatts-hora como um número inteiro.

```python
>>> get_kWh_value(5000000)
1
```

## 4. Obter a eficiência

Os equipamentos eletrónicos não são 100% eficientes.
Por isso, o teu empregador quer que calcules a _eficiência_ dos equipamentos eletrónicos.
Para obteres a eficiência, tens de dividir o fator de potência (_um float entre 0 e 100_) por 100.

Implementa uma função `get_efficiency()` que aceita um float que representa o fator de potência.
A função deve depois `return` a eficiência calculada como um float.

```python
>>> get_efficiency(80)
0.8
```

## 5. Obter o custo

O teu empregador quer saber o custo de funcionamento dos equipamentos eletrónicos.
O custo de funcionamento dos equipamentos eletrónicos é a potência utilizada multiplicada pelo custo por kWh.
A potência utilizada é a potência fornecida dividida pela eficiência calculada.

Implementa uma função `get_cost(<watts>,<power_factor>,<price>)` que aceita um número inteiro que representa o número de watts, um float com o fator de potência e um float com o custo por kWh.
A função deve depois `return` o custo de funcionamento dos equipamentos eletrónicos como um float.

```python
>>> get_cost(5000000, 80, 0.25)
0.3125
```
