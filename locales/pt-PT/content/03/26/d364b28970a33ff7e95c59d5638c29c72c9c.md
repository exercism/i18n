# Sobre

O Lean é uma linguagem de programação funcional pura e estrita, de uso geral, com tipos dependentes e um assistente de provas integrado.
É usada para escrever programas a par de garantias de correção verificadas por máquina, e é amplamente aplicada na verificação formal de software e de matemática.

A **tipagem dependente** significa que os tipos podem depender de valores.
Isto permite codificar especificações e restrições diretamente no sistema de tipos, tornando os estados inválidos efetivamente _irrepresentáveis_.

O Lean baseia-se no princípio das proposições como tipos, segundo o qual as proposições lógicas são representadas como tipos e as provas são programas que habitam esses tipos.
Cada valor de um tipo que codifica uma especificação tem de ser construído de forma a _provar_ que é válido.

A **avaliação estrita** significa que os argumentos das funções são avaliados de imediato, o que dá uma ordem de avaliação determinística.
Isto simplifica o raciocínio sobre o comportamento e o desempenho do programa.
O Lean suporta avaliação preguiçosa, mas apenas de forma explícita.

**Puramente funcional** significa que as funções não alteram o estado nem têm efeitos secundários ocultos.
Uma função pura devolve sempre o mesmo valor para os mesmos valores de entrada, e os efeitos têm de ser explicitados e controlados.

O Lean é compilado antecipadamente para código nativo.
O seu sistema de execução inclui recolha de lixo sem rastreio e atualizações eficientes no local para dados não partilhados.
