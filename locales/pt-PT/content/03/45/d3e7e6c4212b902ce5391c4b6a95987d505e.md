# Dicas

## Geral

- Não te preocupes com a forma como os argumentos são _derivados_; concentra-te em combiná-los para devolver o resultado pretendido.

## 1. Define se a personagem recebe pontos de bónus

- Podes usar [o operador lógico _and_][and] para combinar argumentos e obter um resultado.

## 2. Define se a personagem marca pontos

- Podes usar [o operador lógico _or_][or] para combinar argumentos e obter um resultado.

## 3. Define se a personagem perde

- Podes usar [o operador lógico _not_][not] para negar um argumento e obter um resultado.

## 4. Define se a personagem ganha

- Podes usar os métodos anteriores para combinar argumentos e obter um resultado.

[not]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/basicoperators/#Logical-NOT-Operator
[and]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/basicoperators/#Logical-AND-Operator
[or]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/basicoperators/#Logical-OR-Operator
