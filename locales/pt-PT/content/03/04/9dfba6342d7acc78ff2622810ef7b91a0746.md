# Instruções

Neste exercício vais escrever algum código para ajudar a Betty's Bike Shop, uma loja online de bicicletas e peças.
Tens três tarefas, que têm como objetivo mostrar corretamente os preços das bicicletas e das peças no site.

## 1. Exporta a função `pence_to_pounds`

O teu colega já escreveu o esqueleto do módulo, as funções incompletas `pence_to_pounds` e `pounds_to_string`.
No entanto, esqueceu-se de exportar a função `pence_to_pounds`, por isso atualmente não é visível para outros módulos nem para o conjunto de testes.

Exporta a função `pence_to_pounds`.

## 2. Converte pence em libras

Atualmente, o preço é armazenado como um número inteiro de *pence* (a loja de bicicletas está sediada no Reino Unido).
No site, queremos mostrar o preço em *libras*, em que 1,00 libra equivale a 100 pence.
A tua primeira tarefa é implementar a função `pence_to_pounds`, que recebe uma quantidade de pence do tipo `Int` e a converte no equivalente em libras como `Float`.
Deves também adicionar anotações de tipo para essa função.

```gleam
pence_to_pounds(106)
// -> 1.06
```

## 3. Formata o preço para mostrar no site

Como as bicicletas da Betty são vendidas em libras, os preços devem ser apresentados com o símbolo "£".
A tua segunda tarefa é, por isso, implementar a função `pounds_to_string`, que recebe uma quantidade de libras como `Float` e devolve o preço apresentado como `String`, com o símbolo da libra colocado no início.

Deves importar os módulos `gleam/float` e `gleam/string` antes de os utilizar.

Deves também definir a anotação de tipo para `pounds_to_string`.

```gleam
pounds_to_string(1.06)
// -> "£1.06"
```
