# Introdução

Vimos no conceito `Vectors` que um vetor pode ser usado numa expressão condicional, dando origem a um vetor lógico. Este, por sua vez, pode ser usado em funções como `all()` e `any()`.

```R
v <- c(4, 7, 10)
v >= 6
#> [1] FALSE  TRUE  TRUE
all(v > 6)
#> [1] FALSE    # not all elements match this condition
any(v > 6)
#> [1] TRUE     # at least one element matches
```

A técnica é muito mais poderosa do que isto.

## Subconjuntos de um vetor

Podes extrair elementos selecionados de um vetor com um número de índice ou com um vetor de índices:

```R
v <- 5:10
v
#> [1]  5  6  7  8  9 10
v[3] 
#> [1] 7
v[c(2, 4)]
#> [1] 6 8
```

Em alternativa, usa um vetor lógico para filtrar o vetor original, devolvendo um subconjunto de entradas correspondentes a um valor `TRUE`:

```R
v <- 1:3
bools <- c(FALSE, TRUE, TRUE)
v[bools]
#> [1] 2 3
```

É um pequeno passo daí para gerar o vetor de valores Boolean com uma expressão condicional:

```R
bools <- v >= 2
bools
#> [1] FALSE  TRUE  TRUE

v[bools]
#> [1] 2 3

# simpler form
v[v >= 2]
#> [1] 2 3
```

## Encontrar índices

A função `which()` recebe um argumento do tipo Boolean e devolve um vetor de índices que resultam em `TRUE`.

```R
v
#> [1] 2 7 9

v[v > 5]  # returns values
#> [1]  7  9

which(v > 5) # returns indices
#> [1] 2 3
```

## Verificar se existe uma entrada

As secções anteriores eram sobre encontrar entradas que satisfazem um determinado critério.

Se só precisas de saber se o vetor contém um elemento específico, usa o operador `%in%`.

```R
3 %in% 1:5
#> [1] TRUE
7 %in% 1:5
#> [1] FALSE
```

Isto é funcionalmente equivalente ao seguinte código, mas muito mais conveniente:

```R
v <- 1:5
length(v[v == 3]) > 0
#> [1] TRUE
```
