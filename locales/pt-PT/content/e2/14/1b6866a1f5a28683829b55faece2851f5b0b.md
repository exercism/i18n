# Sobre

Os hashes são um tipo de dados em Perl que contém uma coleção não ordenada de chaves do tipo string emparelhadas com valores escalares.

Normalmente, uma variável do tipo hash é preenchida atribuindo-lhe uma lista, por exemplo, `my %scores = (Alice => 10, Bob => 15, Charlie => 20);`.

As listas são normalmente separadas por vírgulas, mas vais ver com frequência o que se chama «vírgula gorda» `=>` a separar chaves e valores numa lista.
O comportamento é quase idêntico ao de uma vírgula, mas tem a vantagem adicional de interpretar o elemento do lado esquerdo como uma string.

Os hashes podem ser preenchidos atribuindo valores a chaves individuais, por exemplo, `$scores{Alice} = 10;`.

Os valores de um hash podem ser acedidos especificando as chaves através de um subscrito, por exemplo, `$scores{Bob} # 15`.

As chaves de um hash são únicas.
Se uma chave for indicada várias vezes, apenas o último valor indicado é mantido.

## Funções

As funções para trabalhar com hashes incluem [keys][keys] e [values][values], que permitem obter essas partes respetivas de um hash como uma lista.
As listas devolvidas pelas funções [keys][keys] e [values][values] podem ser úteis para funções de lista como [grep][grep], [map][map] e [sort][sort], bem como para ciclos [for][for].

Outras funções para hashes incluem [exists][exists], para verificar se uma chave existe num hash (mesmo que o seu valor seja `undef`), e [delete][delete], para remover uma chave de um hash.

## Variação do sigilo

Ao obter valores de um hash, o sigilo usado determina o resultado.
É o subscrito `{}` no fim do nome da variável que indica ao Perl que estás a aceder a um hash com esse nome.

```perl
my %names = (Alice => 10, Bob => 15, Charlie => 20);

$names{Alice}; # 10            <- A scalar
@names{Alice}; # (10)          <- A slice (with only one key, this probably isn't what you want. There will be a warning.)
%names{Alice}; # ('Alice', 10) <- A key/index + value slice

$names{'Bob', 'Charlie'}; #                            <- An error (disabled syntax for an ancient feature.)
@names{'Bob', 'Charlie'}; # (15, 20)                   <- A slice
%names{'Bob', 'Charlie'}; # ('Bob', 15, 'Charlie', 20) <- A key/index + value slice
```

Embora seja permitido, recomenda-se que tipos de variáveis diferentes não partilhem o mesmo nome, por uma questão de legibilidade.
