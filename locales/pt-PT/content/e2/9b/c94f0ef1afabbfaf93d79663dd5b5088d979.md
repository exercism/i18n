# Ingestão de eventos

## História

Nesta história, tens um programa que precisa de ingerir eventos, mas as mensagens usam 3 formatos de data diferentes:

- `"01/01/1970"`
- `"January 1, 1970"`
- `"Thursday, January 1, 1970"`

A tarefa é escrever regex que faça corresponder e capture cada um destes tipos.

Aborda os seguintes temas:

- correspondência de carateres literais
- quantificadores
- alternâncias
- classes de carateres
- âncoras

## Tarefas

- Cria padrões que façam corresponder pequenos componentes
- Desenvolve e cria padrões que capturem esses pequenos componentes
- Desenvolve e cria padrões que capturem a partir dos formatos de data fornecidos
- Desenvolve e cria regex que faça corresponder e capture apenas esse formato de data
