# Instruções

Neste exercício és um grande fã de desporto e acabaste de descobrir uma paixão pelo basquetebol da NBA.
Como és novo no basquetebol da NBA, estás a estudar a história da NBA a fundo. Acompanhas equipas e treinadores, manténs as estatísticas de vitórias e derrotas e comparas tudo entre si.

Como ainda não tens uma equipa favorita, também vais desenvolver um algoritmo para descobrir se deves torcer por uma equipa em particular.
Tens sete tarefas para te ajudar a desenvolver o teu algoritmo proprietário _root-for-a-team_.

## 1. Define o modelo

Define o alias de tipo `Coach` para um registo com os dois campos seguintes, pela ordem indicada:

- `name`: o nome do treinador, do tipo `String`.
- `formerPlayer`: indica se o treinador foi jogador, do tipo `Bool`.

Define o alias de tipo `Stats` para um registo com os dois campos seguintes, pela ordem indicada:

- `wins`: o número de vitórias, do tipo `Int`.
- `losses`: o número de derrotas, do tipo `Int`.

Define o alias de tipo `Team` para um registo com os três campos seguintes, pela ordem indicada:

- `name`: o nome da equipa, do tipo `String`.
- `coach`: o treinador da equipa, do tipo `Coach`.
- `stats`: as estatísticas da equipa, do tipo `Stats`.

## 2. Cria uma equipa

Queres interagir com código de terceiros que tem o conceito de equipa, mas que chama o teu código com os parâmetros numa ordem diferente. Adiciona uma função `createTeam` com a seguinte assinatura `String -> Stats -> Coach -> Team`.

## 3. Substitui o treinador

Como os donos da NBA são impacientes, descobriste que maus resultados da equipa levavam muitas vezes à substituição do treinador.
Implementa a função `replaceCoach` que recebe o novo treinador e a equipa como parâmetros, e devolve a equipa mas com o novo treinador:

```elm
let
    coach = { name = "Larry Bird", formerPlayer = True }
    stats = { wins = 58, losses =  24 }
    team = { name = "Indiana Pacers", coach = coach, stats =  stats }
    newCoach = { name = "Isiah Thomas", formerPlayer = True }
in
replaceCoach newCoach team
--> { name = "Indiana Pacers"
--  , coach = { name = "Isiah Thomas", formerPlayer = True }
--  , stats = { wins = 58, losses = 24 } }
```

## 4. Verifica se deves torcer por uma equipa

No futuro, planeias elaborar um algoritmo complexo sobre se deves torcer por uma equipa ou não, mas, para a primeira tentativa, decidiste que deves torcer por qualquer equipa que tenha mais vitórias do que derrotas.

Queres que esta função seja reutilizável noutros contextos, por isso usa um registo extensível na assinatura de tipo para aceitar qualquer registo que tenha os campos relevantes.
Para manteres a função o mais concisa possível, queres usar correspondência de padrões para obter o campo `stats` do parâmetro da função.
Implementa a função `rootForTeam` que recebe uma equipa e devolve `True` se deves torcer por essa equipa; caso contrário, devolve `False`.

```elm
let
    spursCoach = { name = "Gregg Popovich", formerPlayer =  False }
    spursStats = { wins = 56, losses = 26 }
    spursTeam = { name = "San Antonio Spurs", coach = spursCoach, stats = spursStats }
in
rootForTeam spursTeam
--> True
```
