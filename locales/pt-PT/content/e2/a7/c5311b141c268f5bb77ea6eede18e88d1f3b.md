# Dicas

## Geral

- Um [valor inteiro][integers] pode ser definido como um ou mais algarismos consecutivos.
- Se vires um erro `panic:` quando corres os testes, é porque não implementaste uma das funções (deve dizer qual delas) ou deixaste o código de base no lugar. Tens de remover a linha `panic(...)` do código fornecido e substituí-la por uma implementação a sério.

## 1. Define o tempo de forno esperado em minutos

- Tens de definir uma [constante][constants] e atribuir-lhe o tempo de forno esperado, em minutos.
- Se vires um erro `undefined: OvenTime`, confirma bem que tens a constante definida.
- Se vires um erro `invalid operation: got != tc.expected (mismatched types float64 and int)`, provavelmente puseste um ponto decimal no `OvenTime`, o que levou o Go a inferir o tipo como número de vírgula flutuante. Remove o ponto decimal e o tipo passa a ser inferido como `int`.
- Se vires um erro `syntax error: non-declaration statement outside function body`, é provável que te tenhas esquecido da palavra-chave `const`.
- Se vires um erro `syntax error: unexpected :=, expecting =`, provavelmente estás a tentar atribuir a constante com `:=`, como se fosse uma variável; as constantes atribuem-se com `=`, não com `:=`.

## 2. Calcula o tempo de forno restante em minutos

- Tens de definir uma [função][functions] com um único parâmetro.
- Tens de [devolver explicitamente um número inteiro][return] de uma função.
- O parâmetro da função é um [inteiro][integers].
- Podes [chamar][calls] uma das outras funções que já definiste anteriormente.
- Podes usar o [operador matemático da subtração][operators] para subtrair valores.

- Podes usar o [operador matemático da adição][operators] para somar valores.
