# Anexo às instruções

## Dicas

Este exercício exige que trabalhes com Reactive extension. Para mais informações, vê [esta página](http://reactivex.io/intro.html).

Na programação reativa é mais fácil comunicar intenções através de diagramas de mármore.
Os testes são complementados com informação dos diagramas de mármore.
O formato de texto pode ser interpretado por [esta ferramenta](https://bitbucket.org/achary/rx-marbles/src/master/docs/syntax.md?fileviewer=file-view-default).
