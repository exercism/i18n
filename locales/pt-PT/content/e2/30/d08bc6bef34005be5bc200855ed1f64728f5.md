## Geral

- Os [String Templates][sap-string-templates] são um tipo de [Expressão de string](https://help.sap.com/doc/abapdocu_latest_index_htm/latest/en-US/index.htm?file=abapcompute_string.htm) que permite inserir uma ou mais [expressões incorporadas][sap-embed-expr] em strings.

- Opcional: o [operador condicional COND][sap-cond-operator] é uma forma abreviada de incorporar uma condição numa expressão. Como podemos incorporar expressões em string templates, podemos dispensar por completo uma construção `IF...ELSE...ENDIF`.

- Os String Templates também permitem inserir [carateres de controlo](https://help.sap.com/doc/abapdocu_latest_index_htm/latest/en-US/index.htm?file=abenstring_templates_separators.htm), uma forma mais curta das constantes da classe [`cl_abap_char_utilities`](https://help.sap.com/doc/abapdocu_latest_index_htm/latest/en-US/index.htm?file=abencl_abap_char_utilities.htm) a que alguns programadores ABAP podem estar habituados.

- As funções de descrição de strings incorporadas podem ajudar a determinar o [comprimento](https://help.sap.com/doc/abapdocu_latest_index_htm/latest/en-US/index.htm?file=abenlength_functions.htm) do letreiro.

- As [expressões incorporadas][sap-embed-expr] de um String Template também podem incluir [opções de formatação](https://help.sap.com/doc/abapdocu_latest_index_htm/latest/en-US/index.htm?file=abapcompute_string_format_options.htm). Estas podem ser úteis para mostrar apenas um resultado com um número fixo de casas decimais.
