# Anexo às instruções

A direção para onde o robô está virado será expressa como um dos seguintes números:

- Norte = 0
- Este = 1
- Sul = 2
- Oeste = 3

Quando a string de entrada for inválida, devolve a direção -1 (os restantes valores são ignorados).

## Memória reservada

O buffer da string de entrada usa os bytes 64-319 da memória linear.

A string de entrada pode ser modificada, se quiseres.
