# Nil

O Crystal tem um tipo chamado [`Nil`][nil], que só pode ter um valor: `nil`.
É usado para representar a ausência de um valor e é semelhante ao `null` ou ao `None` de outras linguagens.

Os valores nil podem ser devolvidos por vários métodos, por exemplo [`String#[]?`][string-index], que devolve `nil` se o índice estiver fora dos limites.

```crystal
"foo"[10]? # => nil
```

O Crystal tem aquilo a que se chama **NULL REFERENCE CHECKS**, o que significa que, por predefinição, nenhum dos tipos pode ser nil.
Isto significa que não podes atribuir `nil` a uma variável, a menos que a declares explicitamente como sendo do tipo `Nil`.
Por sua vez, isto significa que o compilador verifica automaticamente as referências nulas.

## Valor falsey

Podes adotar várias abordagens para lidar com valores `nil`.
O `nil` é um [valor falsey][truthy-falsey], tal como o `false`.
Isto significa que, em instruções e noutros locais onde se espera um valor falsey ou truthy, será tratado da mesma forma que o `false`.

```crystal
if nil
  puts "nil is truthy"
else
  puts "nil is falsey"
end

# => nil is falsey
```

Isto significa que o ramo truthy não será seguido se uma variável que pode ser `nil` tiver o valor `nil`.

```crystal
foo = "boo"[2]? # It is possible that foo is nil
if foo
  p foo.class # => Char
end
```

## Verificar se é nil

O Crystal tem um método que podes usar para verificar se um valor é `nil`.
Chama-se [`nil?`][nil?] e está disponível em todos os objetos.

```crystal
foo = "boo"[2]?
if foo.nil?
  puts "foo is nil"
else
  puts "foo is not nil"
end
```

Isto é um pouco diferente de usar apenas o valor numa condicional, porque nos últimos exemplos tanto o `false` como o `nil` eram tratados como falso.
Aqui, só o `nil` é tratado como falsey, porque se fosse `false` já não seria `nil` e, portanto, seria truthy.

## Operador or

A forma mais fácil de lidar com valores `nil` é garantir que nunca chegam a ser `nil`.
O operador or ([`||`][or]) é frequentemente usado quando se trabalha com `Bools`, mas, bem entendido, também pode ser usado para lidar com valores `nil`.
O operador or verifica se o primeiro valor é truthy; se não for, é usado o segundo valor.
Isto permite fazer com que, se o valor for `nil`, seja falsey e, por isso, seja usado o segundo valor.

```crystal
"foo"[10]? || "bar" # => "bar"
```
