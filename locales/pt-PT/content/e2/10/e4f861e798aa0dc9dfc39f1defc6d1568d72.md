# Introdução

As [estruturas][structs-and-classes] (habitualmente chamadas *structs*) são um dos principais blocos de construção dos programas em Swift.
As structs permitem-te criar tipos personalizados que agrupam propriedades (dados) e métodos (comportamento) relacionados.
Na verdade, os tipos padrão da Swift, incluindo `Int`, `Double`, `Bool`, `String`, `Array` e `Dictionary`, estão todos implementados como structs.

## Definir structs

Define uma struct com a palavra-chave `struct`, seguida do nome do tipo e de chavetas que contêm a sua definição.
Por convenção da Swift, os nomes das structs usam `UpperCamelCase`:

```swift
struct CharacterStats {
    var health = 0.0
    var speed = 0
    var strength = 0
}
```

## Criar instâncias

A definição de uma struct é um plano.
Para criar uma *instância* de uma struct, chama o seu inicializador escrevendo o nome do tipo seguido de parênteses:

```swift
var someStats = CharacterStats()
```

Isto cria uma instância preenchida com os valores predefinidos das propriedades da definição.

A Swift gera também automaticamente um **inicializador membro a membro** para as structs, que te permite inicializar as propriedades pelo nome:

```swift
let customStats = CharacterStats(health: 100.0, speed: 6, strength: 18)
```

## Aceder e modificar propriedades

Acedes e modificas as propriedades de uma instância com a *notação de ponto*:

```swift
var stats = CharacterStats()

print(stats.health) // Prints 0.0

stats.health = 87.3
print(stats.health) // Prints 87.3
```

Como as structs são tipos de valor, para modificar as propriedades de uma instância é preciso que a própria instância seja declarada com `var`.
Se a instância for declarada com `let`, todas as suas propriedades ficam imutáveis.
