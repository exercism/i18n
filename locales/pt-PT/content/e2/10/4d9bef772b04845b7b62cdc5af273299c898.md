# Adenda às instruções

## Palavras

Define um tuplo `cmplx` com os slots `real` e `imaginary`. Os acessores de slots `real>>` e `imaginary>>` vêm de graça com a definição do tuplo e são o que os testes usam para ler os componentes.

- `<cmplx> ( real imag -- cmplx )`: constrói um número complexo.
- `>cmplx ( pair -- cmplx )`: cria um `cmplx` a partir de `{ real imaginary }`.
- `cmplx>pair ( cmplx -- pair )`: devolve `{ real imaginary }`.
- `c+ ( a b -- c )`, `c- ( a b -- c )`, `c* ( a b -- c )`,
  `c/ ( a b -- c )`: aritmética sobre dois números complexos.
- `c-abs ( a -- |a| )`: valor absoluto (um número real).
- `c-conj ( a -- a* )`: conjugado complexo.
- `c-exp ( z -- e^z )`: exponencial complexa.

Os genéricos `MATH:` do Factor (`+`, `-`, `*`, `/`) só escolhem o método com base na hierarquia matemática incorporada, por isso este exercício usa nomes de palavras dedicados em vez de métodos nesses genéricos.

Os testes de aritmética que mistura números reais com números complexos foram excluídos: todas as operações aqui são entre dois valores `cmplx`.
