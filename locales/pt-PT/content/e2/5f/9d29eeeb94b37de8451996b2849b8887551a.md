# Depuração

Toda a saída do teu script Red fica visível na consola quando corres os testes. Podes usar `print` para o que quiseres, por exemplo os valores das palavras:

```red
print ["x =" x]
```

Além disso, a função `probe` é muito útil. Quando é avaliada, avalia o valor de entrada, imprime o resultado de forma a refletir o seu tipo e devolve-o. Por isso, na maioria dos casos é "transparente", e podes inseri-la dentro de expressões:

```red
x: 10
y: probe x + 5
```

Por vezes, a função chamada `type?` (sim, tem um ponto de interrogação no nome!) pode ser útil para verificar o tipo de um valor:

```red
print ["x type:" type? x]
```

Há também algumas técnicas de depuração mais avançadas [listadas na Wiki do Red](https://github.com/red/red/wiki/%5BDOC%5D-Debugging).
