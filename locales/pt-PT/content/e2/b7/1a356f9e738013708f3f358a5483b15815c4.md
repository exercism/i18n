# Dicas

## Geral

- As slices em Go começam no índice zero.
  O primeiro índice de uma slice é `0`.
- A função incorporada [`append`][append-builtin] é [`variadic`][variadic-gobyexample]
- Podes acrescentar os elementos de uma slice a outra slice usando a notação de três pontos:

```go
a := []int{1, 3}
b := []int{4, 2, 6}
c := append(a, b...)
fmt.Println(c)
// Output: [1 3 4 2 6]
```

## 1. Criar uma slice com determinadas cartas

- Para criar uma slice pré-preenchida com alguns dados, usa a notação literal de slice: `s := []T{x1, x2, ..., xn}`.

## 2. Obter uma carta de uma pilha

- Para obter o `n`-ésimo item de uma slice, [usa um índice][go-slices].
- Para verificar se um item existe numa slice, usa um condicional e compara o índice com o [comprimento da slice][len-builtin].

## 3. Trocar uma carta na pilha

- Para definir o `n`-ésimo item de uma slice, [usa um índice][go-slices] e atribui-lhe um novo valor.
- Para acrescentar um novo item ao fim de uma slice, usa a função `append`.

## 4. Acrescentar cartas ao topo da pilha

- Podes acrescentar itens ao início de uma slice acrescentando os elementos da slice original à slice do argumento `value`.

## 5. Remover uma carta da pilha

- Podes remover um item de uma slice acrescentando a parte a seguir a `index` à parte anterior a index.
