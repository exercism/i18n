# Sobre

Uma [`List`][lists] em Elm é uma coleção imutável de zero ou mais valores do mesmo tipo.
Como as listas são imutáveis, depois de uma lista ser construída o seu valor nunca mais pode mudar.
As listas em Elm têm uma _cabeça_ (o primeiro elemento) e uma _cauda_ (tudo o que vem depois do primeiro elemento).
A cauda de uma lista é ela própria uma lista.

As anotações de tipo para listas podem ser definidas da seguinte forma

```elm
List String --> a list of String
List Int --> a list of Int
```

As listas podem ser definidas da seguinte forma:

```elm
empty : List Char
empty = []

singleValue = [ 5 ] --> List Int
singleValueAlternative = List.singleton 5 --> List Int

threeValues = [ "a", "b", "c" ] --> List String
```

A forma mais comum de acrescentar um elemento a uma lista é através do operador `::` (cons):

```elm
twoToFour = [ 2, 3, 4 ]
oneToFour = 1 :: twoToFour --> [1; 2; 3; 4]
```

Podes acrescentar elementos a uma lista com o operador `++` ou com `List.append`:

```elm
[ 6, 7 ] ++ [ 8, 9 ]           --> [6, 7, 8, 9]
List.append [ 6, 7 ] [ 8, 9 ]  --> [6, 7, 8, 9]
```

As listas são manipuladas por funções e operadores definidos no [módulo `List`][list-module].

```elm
List.length [ 7, 8 ] --> 2
```

Qualquer função ou operador que pareça modificar uma lista (como acrescentar um elemento) devolve, na verdade, uma nova lista.
No entanto, o desempenho normalmente não é um problema, porque a implementação das listas evita alocações e cópias desnecessárias.

Também podes processar listas com [correspondência de padrões][list-destructuring].

```elm
describe : List String -> String
describe list =
    case list of
        [] ->
            "Empty list"

        [ "hello" ] ->
            "Singleton list with: hello"

        x :: xs ->
            "Non-empty list with head: " ++ x

describe []                   --> "Empty list"
describe [ "hello" ]          --> "Singleton list with: hello"
describe [ "hello", "world" ] --> "Non-empty list with head: hello"
```
