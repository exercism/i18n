# Instruções

Enquanto te preparavas para fazer bolachas para os teus amigos, descobriste que tens de converter algumas das medidas usadas na receita.
Como só conheces o sistema métrico, precisas de arranjar uma forma de converter as medidas de cozinha americanas mais comuns em mililitros (mL), para te facilitar a vida.

Usa esta tabela de conversão na tua solução:

| Unidade a converter | volume | em mililitros (mL) |
| --------------- | ------ | ------------------- |
| mL              | 1      | 1                   |
| copo americano          | 1      | 240                 |
| onça líquida americana  | 1      | 30                  |
| colher de chá americana     | 1      | 5                   |
| colher de sopa americana   | 1      | 15                  |

Como és um programador talentoso em formação, decides usar os mililitros como unidade de transição para facilitar a conversão de qualquer unidade da lista para qualquer outra (mesmo para ela própria).

## 1. Obtém a componente numérica de um par de volume

Implementa a função `getVolume`. Dado um par de volume (um tuplo), deve devolver apenas a componente numérica.

```haskell
getVolume (Cup, 2.0)
-- -> 2.0
```

## 2. Converte o par de volume em mililitros

Implementa a função `toMilliliter`. Dado um par de volume, deve converter o volume em mililitros usando a tabela de conversão.

Usa várias cláusulas de função e correspondência de padrões para criar as funções de cada unidade. Os átomos usados para denotar cada unidade são: `Cup`, `FluidOunce`, `Teaspoon`, `Tablespoon`, `Milliliter`.
Devolve o resultado da conversão envolvido num tuplo.

```haskell
toMilliliter (Cup, 2.5)
-- -> (Milliliter, 600.0)
```

## 3. Converte o par de volume em mililitros para outra unidade

Implementa a função `fromMilliliter`. Dado um par de volume e a unidade pretendida, deve converter o volume para a unidade pretendida usando a tabela de conversão.

Usa várias cláusulas de função e correspondência de padrões para criar as funções de cada unidade. Os átomos usados para denotar cada unidade são: `Cup`, `FluidOunce`, `Teaspoon`, `Tablespoon`, `Milliliter`.

```haskell
fromMilliliter (Milliliter, 1320.0) Cup
-- -> (Cup, 5.5)
```

## 4. Converte de qualquer unidade para qualquer unidade

Implementa a função `convert`. Dado um par de volume e a unidade pretendida, deve converter o volume dado para a unidade pretendida.

```haskell
convert (Teaspoon, 9.0) Tablespoon
-- -> (Tablespoon, 3.0)
```
