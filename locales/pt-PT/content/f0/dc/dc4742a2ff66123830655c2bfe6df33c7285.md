# Introdução

Em Factor, defines uma nova palavra com `: name ( stack-effect ) body ;`.
O corpo é uma sequência de palavras; chamar a tua nova palavra executa-as por
ordem.

```factor
USING: kernel ;
IN: my-vocab

: shout ( str -- str ) "!" append ;
```

Quando uma rotina se torna grande, podes (e deves) *fatorizá-la*: transformar
grupos de palavras em palavras mais pequenas com nome, cada uma com uma única
tarefa. A linguagem deve o seu nome a isto.

## Vocabulários

Cada ficheiro `.factor` declara um vocabulário com `IN:`. As palavras de um
vocabulário podem chamar palavras de outro, listando o outro vocabulário em
`USING:`.

```factor
! file: my-vocab/helpers/helpers.factor
USING: kernel ;
IN: my-vocab.helpers

: shout-line ( str -- str ) "!" append ;
```

```factor
! file: my-vocab/my-vocab.factor
USING: kernel my-vocab.helpers sequences ;
IN: my-vocab

: announce ( names -- strs )
    [ shout-line ] map ;
```

A estrutura de diretórios segue o nome pontuado do vocabulário: o vocabulário
`my-vocab` vive em `my-vocab/my-vocab.factor`; o vocabulário `my-vocab.helpers`
vive em `my-vocab/helpers/helpers.factor`. O carregador do Factor segue as
declarações `USING:` de forma transitiva, carregando cada vocabulário quando
necessário.
