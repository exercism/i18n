# Executar os testes

No terminal, muda para o diretório base do exercício e executa de seguida os testes com:

```bash
$ mix test
```

Isto vai executar o ficheiro de teste que se encontra na subpasta `test`, um ficheiro que termina em `_test.exs`

Documentação:

* [`mix test` - ferramenta de execução de testes do Elixir](https://hexdocs.pm/mix/Mix.Tasks.Test.html)
* [`ExUnit` - biblioteca de testes unitários do Elixir](https://hexdocs.pm/ex_unit/ExUnit.html)

## Testes pendentes

Nos conjuntos de testes dos exercícios de prática, todos os testes exceto o primeiro estão marcados para serem ignorados.

Quando conseguires passar um teste, podes deixar de ignorar o teste seguinte comentando o `@tag :pending` correspondente com o símbolo `#`.

Por exemplo:

```elixir
# @tag :pending
test "shouting" do
  assert Bob.hey("WATCH OUT!") == "Whoa, chill out!"
end
```

Se quiseres executar todos os testes de uma só vez, podes incluir todos os testes ignorados com a flag `--include` no comando `mix test`:

```bash
$ mix test --include pending
```

Ou podes ativar todos os testes comentando a linha `ExUnit.configure` no ficheiro `test/test_helper.exs`.

```elixir
# ExUnit.configure(exclude: :pending, trace: true)
```

## Opções úteis do `mix test`

* `test/<FILE>.exs:LINENUM` - executa apenas um único teste, o teste de `<FILE>.exs` cuja definição está na linha `LINENUM`
* `--failed` - executa apenas os testes que falharam na última vez que foram executados
* `--max-failures` - o conjunto de testes deixa de avaliar testes quando se atinge este número
de falhas
* `--seed 0` - desativa a aleatoriedade, para que os testes de um único ficheiro sejam sempre
executados pela ordem em que foram definidos
