# Debug

```pyret
fun print-forty-two():
  print(42) # 42
end
```

```pyret
fun return-forty-two() block:
  print(42) # 42
  42
end
```

[print][print] é uma expressão que devolve um valor.
O Pyret só permite uma única expressão dentro de um dado bloco de código, a menos que o bloco exterior esteja marcado com `block`.
No segundo exemplo, adicionar `block` à declaração da função permite-nos imprimir 42 antes de o devolver.

## Spies

```pyret
fun do-something():
    x = "foo"
    y = "bar"
    spy "strings": x, y end
    a = 1
    b = 2
    spy "numbers": a, b end
end
do-something();

# Spying "strings" (at <clipped>/example.arr:4:4-4:27)
#  x: "foo"
#  y: "bar"
# Spying "numbers" (at <clipped>/example.arr:7:4-7:27)
#  a: 1
#  b: 2
```

Uma instrução spy recebe uma etiqueta opcional, uma ou mais variáveis e mostra cada variável e o seu valor.
Como não é uma expressão, pode usar-se um spy num bloco sem que o bloco exterior tenha de estar marcado com `block`.
