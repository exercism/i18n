# Sobre

Se os tipos dos parâmetros puderem ser inferidos, o Swift também permite omitir os nomes dos parâmetros e a palavra-chave `in` da definição da closure. Em vez disso, podes referir-te aos parâmetros através de uma [sintaxe abreviada especial][shorthand-argument-names], em que `$0` se refere ao primeiro parâmetro, `$1` ao segundo, e assim sucessivamente.

```swift
let mean: (Double, Double) -> Double = { $0 + $1 / 2.0 }

["apple", "ball", "carrot"].sorted(by: { $0.count < $1.count })
```

Este estilo é usado sobretudo quando se passam closures para funções de ordem superior e se valoriza a brevidade.

[shorthand-argument-names]: https://docs.swift.org/swift-book/LanguageGuide/Closures.html#ID100
