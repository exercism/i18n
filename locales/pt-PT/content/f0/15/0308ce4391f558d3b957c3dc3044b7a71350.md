## Números e operadores numéricos

Todos os **números**, inteiros ou não, são números de vírgula flutuante de precisão dupla IEEE754.
A implementação do `jq` usa o tipo `double` do C.
Isto limita-nos a 53 bits de precisão.

Os operadores habituais estão disponíveis para usar com números:

- aritmética: `+`, `-`, `*`, `/`, `%`
- comparação: `==`, `!=`, `<`, `<=`, `>=`, `>`
- as [funções matemáticas][man-math] padrão

  Para funções com um parâmetro de entrada, encaminha o valor para a função

  ```sh
  $ jq -n '(1 | atan) * 4'
  3.141592653589793
  ```

  Para funções com dois parâmetros de entrada, a função ignora a entrada e espera-os como
  parâmetros

  ```sh
  $ jq -n 'pow(2; 10)'
  1024
  ```

  O ponto e vírgula é o separador dos argumentos da função, não a vírgula.

~~~~exercism/caution
O que significa dizer «Isto limita-nos a 53 bits de precisão»?

Uma demonstração:

```sh
$ jq -n 'pow(2;52) as $n | [$n, $n+1]'
[
  4503599627370496,
  4503599627370497
]
```

Parece bem. E se aumentarmos o expoente?

```sh
$ jq -n 'pow(2;53) as $n | [$n, $n+1]'
[
  9007199254740992,
  9007199254740992
]
```

Estes números não deviam ser iguais. 
É assim que se manifesta a «perda de precisão».
Isto significa que o `jq` não consegue lidar com números arbitrariamente grandes.
~~~~

## Expressões condicionais

O `jq` usa uma [expressão `if-then-else`][if-then-else] para **expressões condicionais**.
Como _expressão_, é colocada num pipeline.

A sintaxe é: `if CONDTITION then TRUE_EXPR else FALSE_EXPR end`.

A cláusula `else` é opcional.

```jq
42 | if . < 33 then "small" else "larger" end
# => "larger"
```

Para condições adicionais, usa `elif`

```jq
42 | if . < 33 then "small"
     elif . < 67 then "medium"
     else "large"
     end
# => "medium"
```
