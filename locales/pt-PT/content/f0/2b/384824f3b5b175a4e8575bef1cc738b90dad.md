# Dicas

## Geral

- A maioria das instruções com dois ou três operandos exige que todos os operandos tenham o mesmo tamanho.

## 1. Mantém o registo das diferentes moedas

- A maioria das instruções com dois ou três operandos exige que todos os operandos tenham o mesmo tamanho.
- Podes guardar as strings relevantes na secção .rodata ou na secção .data e encaminhá-las de acordo com o valor do enum.
- Um enum é convertido implicitamente num inteiro, normalmente de 32 bits.

## 2. Verifica a taxa de câmbio

- A maioria das instruções com dois ou três operandos exige que todos os operandos tenham o mesmo tamanho.
- O valor de cada elemento do enum é o índice no array de C referenciado por `value_in_US_dollars`.
- Em C, os índices começam no offset 0 e referem-se a elementos, independentemente do seu tamanho em bytes. Por isso, por exemplo, o índice `2` refere-se sempre ao terceiro elemento.
- Cada `double` ocupa 8 bytes de espaço.
- A taxa de câmbio pode ser calculada dividindo o valor em dólares americanos da moeda estrangeira pelo valor em dólares americanos da moeda nacional.

## 3. Calcula o valor das notas

- A maioria das instruções com dois ou três operandos exige que todos os operandos tenham o mesmo tamanho.
- O valor das notas pode ser calculado multiplicando `denomination` por `number_of_bills`.
- Um `unsigned long long` é um inteiro sem sinal de 64 bits.
- Um `unsigned short` é um inteiro sem sinal de 16 bits.
- Um `uint64_t` é um inteiro sem sinal de 64 bits.

## 4. Calcula o número de notas

- A maioria das instruções com dois ou três operandos exige que todos os operandos tenham o mesmo tamanho.
- Tens de arredondar `amount` por defeito antes de o converteres num inteiro.
- Um `float` é um número de vírgula flutuante de 32 bits.
- Podes usar [roundss][round] com `1` como terceiro operando para arredondar por defeito um valor de vírgula flutuante de 32 bits.
- Um `unsigned int` é um inteiro sem sinal de 32 bits.

## 5. Calcula o valor após o câmbio

- A maioria das instruções com dois ou três operandos exige que todos os operandos tenham o mesmo tamanho.
- Tens de converter `spread` num valor de vírgula flutuante antes de o dividires por `100` para obteres uma percentagem.
- Depois de obteres a percentagem, deves multiplicá-la por `exchange_rate` para obteres a _comissão_ do spread.
- A _taxa efetiva_ é a soma da taxa de câmbio com a comissão do spread.
- Deves dividir o orçamento pela taxa efetiva para obteres o valor máximo a cambiar.
- Podes reutilizar a função `get_number_of_bills` que implementaste antes para obteres o número de notas que vais usar.
- Um `uint32_t` é um inteiro sem sinal de 32 bits.

[round]: https://www.felixcloutier.com/x86/roundss
