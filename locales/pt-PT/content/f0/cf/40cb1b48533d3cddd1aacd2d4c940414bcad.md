# Geral

A documentação da [instrução switch][switch-statement] apresenta uma introdução às instruções `switch`.

## 1. Descreve os jogadores com base no número da camisola

- A instrução [`break`][break] é útil.

## 2. Lida com números de camisola desconhecidos

- A instrução [`default`][default] é útil.

## 3. Alarga a cobertura para incluir atividade fora do campo

- A [correspondência de padrões por tipos][switch-pattern-matching] é a chave para esta tarefa.
- Usa a instrução [`default`][default] para corresponder a qualquer outro tipo.

## 5. Faz um relatório sobre os treinadores dos clubes

- Consulta esta [documentação][switch-when] para a palavra-chave `when`.
