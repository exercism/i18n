# Analyzers

Os analyzers do Exercism avaliam automaticamente as submissões dos estudantes e apresentam comentários ao estilo de um mentor.

## Contribuir para os Analyzers

Cada linguagem tem o seu próprio Analyzer, escrito nessa linguagem.
O site funciona como orquestrador entre os Analyzers e as submissões dos estudantes.

Cada Analyzer vive na organização do Exercism no GitHub, num repositório chamado `<track_slug>-analyzer` (por exemplo, [`exercism/ruby-analyzer`](https://github.com/exercism/ruby-analyzer)).
Podes ver os Analyzers existentes [aqui](https://github.com/search?q=topic%3Aexercism-analyzer&type=repositories).

Se queres ajudar num Analyzer que já existe, abre um issue no respetivo repositório a perguntar se há algum sítio onde possas ajudar.
Se queres criar um Analyzer para uma linguagem que ainda não tem nenhum, segue as instruções para [criar um Analyzer](/docs/building/tooling/analyzers/creating-from-scratch).
