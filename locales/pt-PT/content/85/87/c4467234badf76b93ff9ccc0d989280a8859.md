# Introdução

Um *disposable* é qualquer coisa que detém um recurso do sistema operativo, como um ficheiro aberto, um socket ou um bloqueio assente numa tabela de hash, e que tem de ser libertado quando já não precisares dele. O vocab [`destructors`][destructors] do Factor envolve tudo isto num pequeno framework, para que a limpeza aconteça mesmo quando uma exceção desenrola a pilha.

```factor
USING: destructors io.files io.encodings.utf8 ;

"log.txt" utf8 <file-writer> [
    "hello, world" write
] with-disposal
! file is closed even if write throws
```

`with-disposal ( disposable quot -- )` corre a quotation com o recurso e liberta-o ao sair. Para mais do que um recurso, abre um âmbito com `with-destructors` e regista cada um com `&dispose` (liberta na saída normal *e* em caso de erro) ou `|dispose` (liberta apenas em caso de erro).

Uma classe junta-se ao framework ao estender `disposable` e implementar o genérico `dispose*`; o framework chama-o uma vez e só uma vez por objeto. A palavra pública que quem chama usa é `dispose`.

[destructors]: https://docs.factorcode.org/content/vocab-destructors.html
