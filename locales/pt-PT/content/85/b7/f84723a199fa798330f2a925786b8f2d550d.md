# Instruções

Neste exercício vais escrever algum código para te ajudar a cozinhar uma lasanha fantástica a partir do teu livro de cozinha preferido.
Tens quatro tarefas, todas relacionadas com o tempo gasto a cozinhar a lasanha.

## 1. Define o tempo esperado no forno, em minutos

Define a constante `expectedMinutesInOven`, que guarda quantos minutos a lasanha deve estar no forno.
De acordo com o livro de cozinha, o tempo esperado no forno, em minutos, é 40:

```swift
expectedMinutesInOven
// Returns 40
```

## 2. Calcula o tempo restante no forno, em minutos

Define a função `remainingMinutesInOven(elapsedMinutes:)`, que recebe o argumento `elapsedMinutes`, o qual guarda o número de minutos que a lasanha já esteve no forno.
A função deve devolver quantos minutos a lasanha ainda tem de permanecer no forno, com base no tempo esperado no forno, em minutos, da tarefa anterior.

```swift
remainingMinutesInOven(elapsedMinutes: 30)
// Returns 10
```

## 3. Calcula o tempo de preparação, em minutos

Define a função `preparationTimeInMinutes(layers:)`, que recebe o argumento `layers`, o qual guarda o número de camadas que adicionaste à lasanha.
A função deve devolver quantos minutos passaste a preparar a lasanha, assumindo que cada camada te leva 2 minutos a preparar.

```swift
preparationTimeInMinutes(layers: 2)
// Returns 4
```

## 4. Calcula o tempo total de trabalho, em minutos

Define a função `totalTimeInMinutes(layers:elapsedMinutes:)`, que recebe dois argumentos: o parâmetro `layers` é o número de camadas que adicionaste à lasanha e o parâmetro `elapsedMinutes` é o número de minutos que a lasanha esteve no forno.
A função deve devolver quantos minutos, no total, trabalhaste a cozinhar a lasanha, ou seja, a soma do tempo de preparação, em minutos, com o tempo, em minutos, que a lasanha esteve no forno até ao momento.

```swift
totalTimeInMinutes(layers: 3, elapsedMinutes: 20)
// Returns 26
```
