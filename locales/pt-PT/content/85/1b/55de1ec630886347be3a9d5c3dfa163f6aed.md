# Introdução

## Tipos de funções

Se retirares todos os nomes e etiquetas de uma assinatura de função em Swift, ficas apenas com o tipo da função.

```swift
func shoppingList(item: String, quantity: Int) -> String {
  "You need to buy \(quantity) \(item)."
}
// shoppingList: (String, Int) -> String

func repeater(_ phrase: String, times: Int) -> String {
  var result = ""
  for _ in 1...times {
    result += phrase
  }
  return result
}
// repeater: (String, Int) -> String

func printString(line: String) {
  print(line)
}
// printString: (String) -> ()
```

Repara que os tipos das duas primeiras funções são iguais, `(String, Int) -> String`, mesmo que as duas assinaturas sejam diferentes e as duas funções funcionem de forma muito diferente. Ambas recebem uma `String` e um `Int` como parâmetros de entrada e devolvem uma `String`. E, como se vê pelo tipo da terceira função, mesmo que o corpo da função não pareça devolver nada, na verdade devolve implicitamente `()`, o único valor do tipo `Void`.

Estes tipos de função podem ser usados da mesma forma que qualquer outro tipo em Swift, por exemplo, na declaração de variáveis ou constantes. E, como em Swift as funções são valores, podes atribuir funções já existentes a essas constantes ou variáveis:

```swift
var stringAndIntToString: (String, Int) -> String

stringAndIntToString = shoppingList
stringAndIntToString("carrots", 3)
// => "You need to buy 3 carrots."
```

Tal como acontece com outras variáveis ou constantes, o valor que lhe atribuis tem de ser do tipo correto:

```swift
stringAndIntToString = printShoppingList
// Error: Cannot assign value of type '(String) -> ()' to type '(String, Int) -> String'
```

## Tipos de função como tipos de parâmetros

Como os tipos de função podem ser usados em qualquer sítio onde se usam outros tipos, também podem ser usados como tipos de parâmetros, passados para outras funções e chamados a partir do interior dessas funções.

```swift
func apply3(to str: String, function f: (String, Int) -> String) -> String {
  f(str,3)
}
// apply3: ([String], (String, Int) -> String) -> [String]

apply3(to: "eggs", function: shoppingList)
// => "You need to buy 3 eggs."

apply3(to: "eggs", function: repeater)
// => "eggseggseggs"
```

## Tipos de função como tipos de retorno

Da mesma forma, os tipos de função podem ser usados como tipos de retorno de funções. Por outras palavras, podes escrever funções que criam e devolvem outras funções. Ao criar estas funções, a função que é devolvida pode usar os outros parâmetros passados para a função ou as variáveis locais criadas dentro da função envolvente.

```swift
func makeAdder(base: Int) -> (Int) -> Int {
  func adder(_ i: Int) -> Int {
    base + i
  }
  return adder
}
// makeAdder: (Int) -> (Int) -> Int

let add10 = makeAdder(base: 10)
// add10: (Int) -> Int

let subtract20 = makeAdder(base: -20)
// subtract20: (Int) -> Int

add10(5)
// => 15

subtract20(5)
// => -15
```
