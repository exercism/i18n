# Sobre

As charlists são criadas com o sigil `~c`.

```elixir
~c"hello"
```

~~~~exercism/note
Repara que, em versões mais antigas do Elixir, as charlists são representadas como `'hello'`, com plicas.
~~~~

Uma charlist é uma lista de números inteiros. Os números inteiros representam os valores Unicode de um determinado caráter, também conhecidos como pontos de código.

```elixir
[65, 66, 67]
# => ~c"ABC"
```

## As charlists _são_ listas

```elixir
~c"" === []
# => true

is_list(~c"hello")
# => true
```

Como as charlists são listas, podes trabalhar com elas tal como com qualquer outra lista: com recursão e correspondência de padrões, ou com o módulo [`List`][list].

```elixir
[first_letter | _] = ~c"cat"
first_letter
# => 99

List.first(~c"hello")
# => 104
List.pop_at(~c"hello", 0)
# => {104, ~c"ello"}

```

Podes concatenar duas listas com [`++`][kernel-concat-list].

```elixir
~c"hi" ++ ~c"!"
# => ~c"hi!"
```

Quanto mais longa for a primeira lista, mais lenta é a concatenação, por isso evita acrescentar repetidamente a listas de comprimento arbitrário.

## Imprimibilidade

Se uma lista de números inteiros contiver apenas números inteiros que são pontos de código de carateres imprimíveis, será apresentada como uma charlist. Mesmo que tenha sido definida com a sintaxe `[]`.

```elixir
~c"ABC"
# => ~c"ABC"

[65, 66, 67]
# => ~c"ABC"
```

Se uma lista de números inteiros contiver nem que seja um ponto de código de um caráter não imprimível (por exemplo, `0-6`, `14-26`, `28-31`), será apresentada como uma lista. Mesmo que tenha sido definida com a sintaxe `~c""`.

```elixir
~c"ABC\0"
# => [65, 66, 67, 0]

[65, 66, 67, 0]
# => [65, 66, 67, 0]
```

A imprimibilidade pode ser verificada com [`List.ascii_printable?`][list-ascii-printable].

```elixir
List.ascii_printable?([65, 66, 67])
# => true
List.ascii_printable?([65, 66, 67, 0])
# => false
```

Tem em atenção que estas são duas formas diferentes de _apresentar_ os mesmos dados. Os valores são estritamente iguais.

```elixir
~c"ABC" === [65, 66, 67]
# => true
```

Ao imprimir uma lista com [`IO.inspect`][io-inspect], podes usar a opção [`:charlists`][inspect-opts] para controlar a forma como as listas são impressas.

```elixir
IO.inspect(~c"ABC", charlists: :as_charlists)
# => prints ~c"ABC"

IO.inspect(~c"ABC", charlists: :as_lists)
# => prints [65, 66, 67]
```

## Pontos de código

Podes colocar `?` antes de um caráter para obter o seu ponto de código.

```elixir
?A
# => 65

[?:, ?)]
# => ~c":)"
```

## Charlists vs strings

As charlists e as strings compostas pelos mesmos carateres não são consideradas iguais.

```elixir
~c"hello" == "hello"
false
```

Cada valor numa charlist é o [ponto de código Unicode de um caráter][unicode-table], enquanto numa string os pontos de código são codificados como [UTF-8][utf8].

```elixir
IO.inspect(~c"tschüss", charlists: :as_lists)
# => prints [116, 115, 99, 104, 252, 115, 115]

IO.inspect("tschüss", binaries: :as_binaries)
# => prints <<116, 115, 99, 104, 195, 188, 115, 115>>
```

Repara como `ü`, com o ponto de código `252`, é codificado em UTF-8 como `195` e `188`.

**Na prática, as charlists são raramente usadas.** O seu principal caso de uso é a interação com o Erlang, em particular quando se usam bibliotecas mais antigas que não aceitam binários como argumentos.

Ao trabalhar com Elixir, **usa strings para armazenar texto**. O módulo `String` oferece uma grande variedade de funções para processar texto, funções que não estão disponíveis para as charlists.

As charlists podem ser convertidas em strings com [`to_string`][kernel-to-string].

```elixir
to_string(~c"hello")
# => "hello"
```
