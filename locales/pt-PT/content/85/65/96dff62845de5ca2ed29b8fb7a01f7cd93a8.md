# Sobre

## Contexto

Uma string é um pedaço de texto entre aspas.

```R
mystring <- "some text"
mystring
#> [1] "some text"
typeof(mystring)
#> [1] "character"
```

Infelizmente, a terminologia pode ser confusa para programadores familiarizados com outras linguagens.

Embora o `type` seja `character`, o R não faz distinção entre uma única letra (chamada `char` em várias outras linguagens, mas _não_ no R) e uma string longa.
Ambas são um único item e podem estar entre aspas simples `' '` ou duplas `" "`, indistintamente.

O guia de estilo recomenda usar aspas duplas, exceto quando queres usar aspas duplas dentro da string sem as escapar.

```R
str2 <- 'String with "quotes"'  # convenience format
str2
#> [1] "String with \"quotes\""    # standard format
```

Um `character vector` é, portanto, um vetor de strings, com cada string como um único elemento.

```R
s <- c("some", "strings")
s
#> [1] "some"    "strings"
length(s)
#> [1] 2
length(s[1])  # the number of vector elements, not the string length
#> [1] 1

nchar(s[1])  # the number of characters in the string "some"
#> [1] 4
```

No exemplo acima, `length(s[1])` é equivalente a `length("some")`: o número de _elementos do vetor_, não o _comprimento da string_.

Manipular uma string individual é, obviamente, possível, como acontece com `nchar()` no exemplo acima, mas requer funções específicas que serão discutidas mais abaixo.

### Carateres de escape

Como vimos acima, alguns carateres de pontuação precisam de ser «escapados», sendo precedidos por uma barra invertida `\`.

A lista não será surpresa para a maioria dos programadores com experiência, uma vez que este tópico está razoavelmente bem padronizado entre linguagens.

Além das aspas (como mostrado acima), a lista inclui novas linhas `\n`, tabulações `\t`, barra invertida `\\` e símbolos Unicode que começam por `\U` ou `\u`.

Para evitar usar muitos carateres de escape, é possível definir strings em bruto dentro de `r"( )"`:

```R
r"(raw "string")"
#> [1] "raw \"string\""
```

Para strings em bruto que contêm parênteses `( )`, há muitas outras [opções de sintaxe][book-raw].

### Locales

Qualquer versão do R atualmente suportada codifica strings em UTF-8, por isso a maioria das línguas do mundo pode ser suportada.

```R
"आधुनिक मानक हिन्दी"
#> [1] "आधुनिक मानक हिन्दी"
```

Além disso, muitas funções do R têm em conta o [`locale`][wiki-locale] e tentam seguir as convenções locais para a ordenação de strings, a conversão para maiúsculas/minúsculas, datas e horas, etc.

Este programa mostrará exemplos principalmente para inglês dos EUA: tanto porque isto é um padrão comum, como porque os autores do programa são residentes nos EUA.

Os locales são um tópico complexo, por isso procura documentação adaptada à tua própria situação.


## Funções para strings

A maioria das coisas é _possível_ no R base, mas muitos programadores consideram o suporte para manipulação de strings bastante limitado e confuso.

Felizmente, existem pacotes do `tidyverse` que são muito mais intuitivos, flexíveis e coerentes entre si.

### R base

Ainda há muito código legado a usar funções de string ao estilo antigo.
Isto inclui a maioria das soluções da comunidade no Exercism.

Além disso, para tarefas pequenas pode ser útil usar funções incorporadas em vez de importar uma biblioteca grande.
Os responsáveis do percurso de R tendem a adotar esta abordagem ao escrever soluções exemplares para validar os exercícios no nosso [repositório do GitHub][gh-exercism-r].

Por isso, ainda vale a pena aprender um pouco sobre as abordagens antigas.

As funções abaixo são apresentadas na sua forma mais simples, mas a maioria também tem argumentos opcionais.
Consulta a documentação para mais detalhes.

#### [`nchar`][ref-nchar]

Devolve o número de carateres numa string.

```R
nchar("string")
#> [1] 6

nchar("Hrōðgār") # a person in Beowulf, written in Old English
#> [1] 7
```

O tópico (_complicado!_) do que significa «caráter» está fora do nosso âmbito.
Repara apenas em alguns pontos nos exemplos acima:

- Apesar de implementadas em C internamente, as strings em R não terminam em `\0` (o que acrescentaria 1 ao comprimento).
- Os carateres Unicode multibyte são tratados como seria de esperar. «Hrōðgār» tem 7 carateres (também chamados «runes» ou «code points»), mas precisa de 10 bytes para armazenamento.

Tem atenção ao que passas ao `nchar`.
Os resultados podem ainda ser imprevisíveis para valores que não sejam `character`, embora isto tenha melhorado nas versões recentes do R.

#### [`grep`][ref-grep]

Procura um padrão num vetor de strings e devolve os índices onde há correspondência.

```R
grep("Jav", c("Java", "Python", "Javascript"))
#> [1] 1 3
```

#### [`paste`][ref-paste] e [`paste0`][ref-paste]

Combina um número arbitrário de strings numa única string.

Opcionalmente, podes especificar um separador para `paste`: a predefinição é um espaço.

`paste0(v)` é equivalente a `paste(v, sep = "")`.

```R
paste("bits", "of", "a", "string")
#> [1] "bits of a string"
paste0("bits", "of", "a", "string")
#> [1] "bitsofastring"
```

#### [`sprintf`][ref-sprintf]

Para um controlo mais fino sobre a montagem de strings, o R copia a função `sprintf` do C (e de várias linguagens posteriores: a Wikipedia [lista][wiki-printf-ports] cerca de 30).

```R
r <- 5.3
pi <- 3.14159
sprintf("A circle of radius %.1f has area %.2f", r, pi * r^2)
#> [1] "A circle of radius 5.3 has area 88.25"
```

#### [`trimws`][ref-trimws]

Os espaços em branco no início e/ou no fim podem ser removidos com `trimws()`:

```R
s <- "    messy string   "
trimws(s)
#> [1] "messy string"
```

Existe um parâmetro `which = "left"` (ou `"right"`) para evitar remover de ambas as extremidades.

#### [`substr`][ref-substr]

Opera sobre uma única string e devolve uma substring entre dois limites (inclusive).

```R
substr("Exercism", 5, 7)
#> [1] "cis"
```

#### [`strsplit`][ref-strsplit]

Divide uma string numa lista do R, com base numa string separadora.
O separador é obrigatório (sem valor predefinido), mas pode ser uma string vazia.

```R
strsplit("R, Python, Julia", ", ")
[[1]]
#> [1] "R"      "Python" "Julia" 

strsplit("Exercism", "")
[[1]]
#> [1] "E" "x" "e" "r" "c" "i" "s" "m"
```

As listas serão abordadas num [Conceito][concept-lists] separado.
Se ainda não chegaste a essa parte do programa, por agora fica a saber que a função [`unlist()`][ref-unlist] irá (neste caso) converter uma lista num vetor.

```R
unlist(strsplit("Exercism", ""))
#> [1] "E" "x" "e" "r" "c" "i" "s" "m"
```

#### [`regexpr`][ref-grep] e [`regexpr`][ref-grep]

Abreviatura de «expressão regular», estas funções procuram ocorrências de um padrão numa string e devolvem uma lista de dados (potencialmente) úteis.
São mencionadas apenas por uma questão de completude: _há opções melhores!_

`regexpr` devolve apenas a primeira ocorrência, `gregexpr` devolve todas as ocorrências («g» de pesquisa «global»).

Como os nomes sugerem, o padrão pode ser uma [expressão regular][wiki-regex], que será abordada num [Conceito posterior][concept-regex].

### Tidyverse

Sendo generosos, podemos dizer que as funções de string ao estilo antigo não são o melhor que o R tem para oferecer (_há visões menos generosas_).

Para melhorar a situação, a biblioteca [`stringr`][ref-stringr] está em desenvolvimento desde 2009 e é agora uma parte fundamental da coleção [Tidyverse][ref-tidyverse].

Importa-a para o teu namespace com `library(stringr)` ou `library(tidyverse)`.

Algumas funcionalidades fundamentais incluem:

- Todos os nomes de funções têm um prefixo `str_` e tentam deixar claro o propósito.
- A ordem dos argumentos tenta ser coerente entre si, com os dados de entrada como primeiro argumento.
- Os valores de entrada podem ir de uma única string a estruturas de dados complexas. As funções tentarão adaptar-se e fazer o mais sensato.

Como todos os pacotes do Tidyverse, o `stringr` tem boa documentação, normalmente escrita pelo(s) autor(es) do pacote.

- Um [site de referência][ref-stringr]
- Um [guia rápido][cheat-stringr]
- Um [capítulo][book-strings] de «R for Data Science».

Há dezenas de funções disponíveis no `stringr`, e têm frequentemente uma variedade de argumentos opcionais.
Isto pode ser um pouco esmagador ao início, por isso a documentação é a tua amiga.

Pensa no que queres colocar (uma única string? um vetor? algo mais complexo?) e no que queres obter.

Provavelmente há uma forma fácil de fazer o que quiseres, se conseguires encontrar a função certa e os argumentos certos.

#### Digressão: uma introdução rápida aos pipes

A utilização de pipes `|>` para ligar funções será discutida com mais detalhe noutras partes do programa.

Por agora, é útil saberes que:

- Um resultado à esquerda do pipe torna-se o primeiro argumento na função à direita (em que «direita» ignora quebras de linha opcionais).
- Quaisquer argumentos restantes podem ser incluídos na chamada à função.
- No R, o pipe tem de terminar numa _chamada_ à função, e não apenas num _nome_, por isso os parênteses são sempre obrigatórios (_isto difere de algumas outras linguagens_).

O exemplo abaixo ilustra a sintaxe.
As funções individuais serão discutidas mais adiante.

```R
library(stringr)

"Monday-25-February" |> 
  str_split("-") |>     
  unlist() |>               # [1] "Monday"   "25"       "February"
  str_sub(1, 3) |>          # [1] "Mon" "25"  "Feb"
  str_to_upper() |>         # [1] "MON" "25"  "FEB"
  str_flatten(collapse = ", ")
#> [1] "MON, 25, FEB"
```

#### Gerir comprimentos

[`str_length`][ref-str_length] conta code points (semelhante a `nchars`).

Várias outras funções manipulam espaços em branco, incluindo [`str_trim()`][ref-str_trim] e [`str_squish()`][ref-str_trim].
Esta é frequentemente uma tarefa de limpeza vital no início de qualquer projeto de ciência de dados.

```R
# The first 3 kernels in JuPyteR notebooks:
str_length(c("Julia", "Python", "R"))           #> [1] 1 6 5
#> [1] 5 6 1
str_pad(c("Julia", "Python", "R"), 8, "right")  # add spaces if necessary
#> [1] "Julia   " "Python  " "R       "

str_trim("Julia    Python    R    ")   # remove leading & trailing whitespace
#> [1] "Julia    Python    R"
str_squish("Julia   Python  R    ")  # trim, collapse multiple spaces 
#> [1] "Julia Python R"
```

#### Subconjuntos de strings

A função [`str_sub(string, start, end)`][ref-str_sub] devolve a substring de `start` a `end` (inclusive), enquanto [`str_sub_all()`][ref-str_sub] pode operar sobre múltiplas strings.

Há muita flexibilidade.
`start` e `end` assumem, por predefinição, o primeiro e o último caráter, respetivamente.
Podem ser vetores de índices.
Em agradável contraste com a indexação de vetores, os valores negativos contam a partir do fim da string, ao estilo do Python.

```R
s <- "abcdefgh"
str_sub(s, 2, 4)
#> [1] "bcd"
str_sub(s, 5)
#> [1] "efgh"
str_sub(s, -3, -2)
#> [1] "fg"
str_sub(s, c(1, 4), c(2, 5))
#> [1] "ab" "de"
str_sub(s, c(1, 4, 6), c(2, 5, -1))
#> [1] "ab"  "de"  "fgh"

s |> str_sub(2, 4) # these functions are designed for pipes
#> [1] "bcd"

# str_sub_all takes vector input, gives list output
str_sub_all(c(s, "ijklmnop"), c(1, 4, 6), c(2, 5, -1))
[[1]]
#> [1] "ab"  "de"  "fgh"

[[2]]
#> [1] "ij"  "lm"  "nop"
```

#### Unir strings

A função [`str_flatten`][ref-str_flatten] converte um vetor de carateres numa única string.
O argumento `collapse` é inserido entre cada elemento e a predefinição é `""`.

```R
c("R", "Julia", "Python") |> str_flatten()
#> [1] "RJuliaPython"
c("R", "Julia", "Python") |> str_flatten(collapse = " - ")
#> [1] "R - Julia - Python"
```

A função [`str_c`][ref-str_c] converte múltiplos vetores de carateres num único vetor de carateres, com reciclagem conforme necessário.

```R
str_c(LETTERS[1:8], 1:8, sep = ":")
#> [1] "A:1" "B:2" "C:3" "D:4" "E:5" "F:6" "G:7" "H:8"
```

A função [`str_glue`][ref-str_glue] traz interpolação simples de strings ao R.
As expressões dentro de chavetas `{ }` são interpretadas e a respetiva representação textual é substituída.

Se forem fornecidas várias strings de expressões, também serão unidas como em `str_flatten`.
As strings também podem, opcionalmente, ser limpas de espaços em branco no início e no fim.

```R
r <- 5.3
pi <- 3.14159
str_glue("A circle of radius {r} has area {pi * r^2}")
A circle of radius 5.3 has area 88.2472631
```

Embora `str_glue` seja flexível (e bastante complicado), há um leque ainda mais amplo de possibilidades na biblioteca subjacente [`glue`][ref-glue].

#### Dividir strings

Um uso muito comum do R é transformar dados desorganizados num formato consistente para análise.
Para ajudar nisto, há várias formas de dividir texto em substrings.

A função [`str_split_1`][ref-str_split] é a mais simples, convertendo uma única string num vetor de partes, divididas num determinado padrão especificado (não há padrão predefinido).

```R
s <- "R Julia Python"
str_split_1(s, " ")
#> [1] "R"      "Julia"  "Python"
```

A função [`str_split_i`][ref-str_split] recebe um vetor de carateres e um índice `n`, devolvendo um vetor com a `n`-ésima substring de cada string de entrada.

```R
s2 <- c(s, "C Kotlin, F#")  #> [1] "R Julia Python" "C Kotlin, F#"
str_split_i(s2, " ", 2)  # 2nd element of each
#> [1] "Julia"   "Kotlin,"
```

A função [`str_split`][ref-str_split] recebe um vetor de carateres e devolve uma lista de vetores.
Há um [Conceito de Listas][concept-lists] no nosso programa que explica o resultado.

```R
str_split(s2, " ")
[[1]]
#> [1] "R"      "Julia"  "Python"

[[2]]
#> [1] "C"       "Kotlin," "F#"     
```

Há também a função [`str_split_fixed`][ref-str_split], que devolve uma matriz.
As matrizes serão abordadas num Conceito posterior.

#### Comparar strings

Para comparar a string inteira, [`str_equal()`][ref-str_equal] pode usar várias definições de «igualdade».
No caso mais simples, a predefinição distingue maiúsculas de minúsculas, mas isso pode ser alterado.
Os locales e o [Unicode][wiki-unicode] criam muitas mais possibilidades.

```R
str_equal("Odin", "odin")
#> [1] FALSE
str_equal("Odin", "odin", ignore_case = TRUE)
#> [1] TRUE
```

Há muitas [outras funções][ref-string-matching], que serão discutidas com mais detalhe no [Conceito de Expressões Regulares][concept-regex].

#### Modificar strings

Algumas línguas (principalmente europeias) distinguem entre letras MAIÚSCULAS e minúsculas.
Há um conjunto de [funções][ref-str-case] do `stringr` para converter entre estas, de formas adequadas ao locale:

- `str_to_lower()`
- `str_to_upper()`
- `str_to_title()` : primeira letra de cada palavra em maiúscula
- `str_to_sentence()` : primeira letra da frase em maiúscula

```R
str_to_upper("elixir")    # defaults to locale = "en"
#> [1] "ELIXIR"
str_to_upper("ελληνικά")  # infers Greek
#> [1] "ΕΛΛΗΝΙΚΆ"

str_to_title("the cat sat on the mat")
#> [1] "The Cat Sat On The Mat"
str_to_sentence("the cat sat on the mat")
#> [1] "The cat sat on the mat"
```

Para substituição de substrings com base na correspondência de padrões, [`str_replace()`][ref-str_replace] altera a primeira ocorrência do padrão e [`str_replace_all()`][ref-str_replace] altera todas as ocorrências.

Para substituição de substrings com base na indexação de carateres, há uma forma de atribuição de [str_sub()][ref-str_sub].

```R
 s <- "abcde"
str_sub(s, 3, 4) <- "yz"
s
#> [1] "abyze"
```

#### Diversos

A função [`str_dup`][ref-str_dup] cria duplicados e [`str_unique`][ref-str_unique] remove duplicados.

Por predefinição, `str_dup` não tem separador, mas é possível especificar um.

```R
str_dup("xyz", 4, sep = ", ")
#> [1] "xyz, xyz, xyz, xyz"
```

`str_unique` é uma extensão de [`unique()`][ref-unique].
Ambas removem entradas duplicadas de um vetor, mas a função do `stringr` também consegue lidar com a distinção entre maiúsculas e minúsculas e várias correspondências específicas do locale.

```R
inp <- c("some", "strings", "Some", "Strings")
str_unique(inp)
#> [1] "some"    "strings" "Some"    "Strings"
str_unique(inp, ignore_case = TRUE)
#> [1] "some"    "strings"
```
