# Apêndice às instruções

## Registos

| Registo | Utilização   | Tipo    | Descrição                              |
| -------- | ------------ | ------- | -------------------------------------- |
| `$a0`    | entrada      | endereço | primeira cor como string terminada em null  |
| `$a1`    | entrada      | endereço | segunda cor como string terminada em null |
| `$a2`    | entrada      | endereço | terceira cor como string terminada em null  |
| `$a3`    | entrada/saída | endereço | string de saída terminada em null          |
| `$t0-9`  | temporário   | qualquer | utilizado para armazenamento temporário             |
