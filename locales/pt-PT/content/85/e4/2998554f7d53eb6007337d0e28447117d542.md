# Instruções

Trabalhas no balcão de segurança de uma estação de investigação. O pessoal
usa *crachás* cujos códigos seguem um formato rígido, o registo de acessos
está cheio desses códigos misturados com texto normal, e é preciso limpá-lo
antes de o poder partilhar. As expressões regulares são a ferramenta certa
para cada uma destas tarefas.

Um código de crachá válido é composto por **duas letras maiúsculas, um
hífen e, a seguir, quatro algarismos** (por exemplo, `NS-1024`).

## 1. Verifica um código de crachá

Define `valid-badge?`, que recebe uma string de crachá e devolve `t` quando
a string *toda* é um código de crachá válido e `f` caso contrário.

```factor
"NS-1024" valid-badge? .   ! => t
"NS-10"   valid-badge? .   ! => f
```

## 2. Extrai todos os códigos de uma linha de registo

Define `badge-codes`, que recebe uma linha do registo de acessos e devolve
uma sequência com todos os códigos de crachá que aparecem nela, pela ordem
em que aparecem.

```factor
"seen NS-1024 then AB-0007 today" badge-codes .
! => { "NS-1024" "AB-0007" }
```

## 3. Conta os algarismos de um código

Define `digit-count`, que recebe uma string e devolve quantos algarismos
ela contém.

```factor
"NS-1024" digit-count .   ! => 4
```

## 4. Oculta as palavras-passe

As linhas do registo por vezes guardam uma palavra-passe como `pass=`
seguido do segredo (qualquer sequência de carateres que não sejam
espaços). Define `redact`, que recebe uma linha e a devolve com todas
essas palavras-passe substituídas por `pass=****`.

```factor
"user=alice pass=hunter2 ok" redact .
! => "user=alice pass=**** ok"
```
