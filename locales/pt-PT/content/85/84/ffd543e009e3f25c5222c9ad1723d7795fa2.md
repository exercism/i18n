# Correr os testes

Para correres o conjunto de testes, executa o seguinte comando:

```bash
stack test
```

#### Se receberes uma mensagem de erro como esta...

```
No .cabal file found in directory
```

ou

```
RedownloadInvalidResponse Request {
...
}
 "/home/username/.stack/build-plan/lts-xx.yy.yaml" (Response {responseStatus = Status {statusCode = 404, statusMessage = "Not Found"},
```

Provavelmente estás a usar uma versão antiga do stack e precisas de a atualizar. Experimenta correr:

```bash
stack upgrade
```

Ou vê outras opções de atualização na [documentação do Stack](https://docs.haskellstack.org/en/stable/install_and_upgrade/#upgrade).

#### Caso contrário, se receberes uma mensagem de erro como esta...

```
No compiler found, expected minor version match with...
Try running "stack setup" to install the correct GHC...
```

Basta fazer o que diz e ele vai descarregar e instalar a versão correta do compilador:

```bash
stack setup
```

# Correr o *GHCi*

Se quiseres experimentar a tua solução no GHCi, basta correr o comando:

```bash
stack ghci
```
