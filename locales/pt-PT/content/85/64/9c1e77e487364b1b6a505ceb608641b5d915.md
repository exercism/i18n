# Instruções

Neste exercício vais escrever código para ajudar um freelancer a comunicar com os seus clientes sobre os preços de determinados projetos.
Vais escrever algumas funções utilitárias para calcular rapidamente os custos para os clientes.

```exercism/note
A variável `ratePerHour` e a função `dayRate` estão relacionadas com dinheiro.
As unidades de medida são dinheiro por unidade de tempo: horas e dias, respetivamente.
```

## 1. Calcula a taxa diária a partir de uma taxa horária

Um cliente contacta o freelancer para perguntar pelas suas taxas.
O freelancer explica que **_trabalha 8 horas por dia._**
No entanto, o freelancer só conhece a sua taxa horária para o projeto.
Ajuda-o a estimar uma taxa diária a partir de uma taxa horária.

```javascript
dayRate(89);
// => 712
```

A taxa diária não precisa de ser arredondada nem alterada para uma precisão "fixa".

## 2. Calcula o número de dias de trabalho a partir de um orçamento fixo

Noutro dia, um gestor de projeto propõe ao freelancer trabalhar num projeto com um orçamento fixo.
Dado o orçamento fixo e a taxa horária do freelancer, ajuda-o a calcular o número de dias que trabalharia até o orçamento se esgotar.
O resultado _tem_ de ser **arredondado por defeito** para o número inteiro mais próximo.

```javascript
daysInBudget(20000, 89);
// => 28
```

## 3. Calcula a taxa com desconto para projetos grandes

Muitas vezes, os clientes do freelancer contratam-no para projetos que se estendem por vários meses.
Nestes casos, o freelancer decide oferecer um desconto por cada mês completo, e os dias restantes são faturados à taxa diária.
O teu excelente equilíbrio entre a vida pessoal e o trabalho faz com que só trabalhes 22 dias em cada mês civil, por isso **_cada mês tem 22 dias faturáveis._**
Ajuda-o a estimar o custo desses projetos, dada uma taxa horária, o número de dias faturáveis que o projeto inclui e uma taxa de desconto mensal.
O desconto é sempre passado como um número, em que `42%` se torna `0.42`. O resultado _tem_ de ser **arredondado por excesso** para o número inteiro mais próximo.

```javascript
priceWithMonthlyDiscount(89, 230, 0.42);
// => 97972
```
