# Testes

## Correr os testes

Para correres os testes, executa o seguinte comando:

```bash
dotnet test
```

## Resolver o exercício

Resolver um exercício significa conseguir que todos os seus testes passem. Por predefinição, quando corres os testes só é executado um teste (o primeiro). Isto é intencional, pois permite-te focares-te apenas em fazer passar esse único teste. Assim que ele passar, podes ativar o teste seguinte removendo `Skip = "Remove this Skip property to run this test"` do atributo `[<Fact>]` ou `[<Theory>]` do teste. Quando todos os testes estiverem ativados e a tua implementação os fizer passar a todos, terás resolvido o exercício!

Para te ajudar a começar, cada exercício inclui um ficheiro de implementação stub. Podes usar este ficheiro como ponto de partida para construir a tua solução. Sente-te à vontade para remover ou alterar este ficheiro, se achares que é o melhor a fazer.

## Usar pacotes

Deverás conseguir resolver a maioria dos exercícios sem usar pacotes externos. No entanto, nos exercícios em que queiras mesmo usar um pacote externo, podes adicioná-lo ao teu projeto executando o seguinte comando:

```bash
dotnet add package [package-name]
```
