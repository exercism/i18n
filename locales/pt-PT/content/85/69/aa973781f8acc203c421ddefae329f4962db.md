# Introdução

## Números

Existem dois tipos diferentes de números em Java:

- Inteiros: números sem algarismos depois do separador decimal (números inteiros).
  Exemplos: `-6`, `0`, `1`, `25`, `976` e `-500000`.
- Números de vírgula flutuante: números com zero ou mais algarismos depois do separador
  decimal. Exemplos: `-20.4`, `0.1`, `2.72`, `16.984025` e `1024.0`.

Os dois tipos numéricos mais comuns em Java são `int` e `double`.
Um `int` é um inteiro de 32 bits e um `double` é um número de vírgula flutuante de 64 bits.

A aritmética faz-se com os operadores aritméticos habituais.
Os números podem ser comparados com os operadores de comparação numérica habituais (por exemplo, `5 > 4` e `4 <= 5`) e com os operadores de igualdade (`==`) e de desigualdade (`!=`).

O Java tem dois tipos de conversões numéricas:

1. Conversões implícitas: não se perde nenhum dado e não é precisa sintaxe adicional.
2. Conversões explícitas: podem perder-se dados e é precisa sintaxe adicional sob a forma de um _cast_.

Como um `int` tem menos precisão do que um `double`, converter de um `int` para um `double` é seguro e trata-se, por isso, de uma conversão implícita.
No entanto, converter de um `double` para um `int` pode significar perder dados, por isso exige uma conversão explícita.

## Instruções if-else

### A instrução _if-then_

A instrução de controlo de fluxo mais básica do Java é a instrução _if-then_.
Esta instrução serve para executar uma secção de código apenas se uma determinada condição for `true`.
Uma instrução _if-then_ define-se com a cláusula `if`:

```java
class Car {
    void drive() {
        // the "if" clause: the car needs to have fuel left to drive
        if (fuel > 0) {
            // the "then" clause: the car drives, consuming fuel
            fuel--;
        }
    }
}
```

No exemplo acima, se o carro ficar sem combustível, chamar o método `Car.drive` não faz nada.

### A instrução _if-then-else_

A instrução _if-then-else_ oferece um caminho de execução alternativo para quando a condição da cláusula `if` é avaliada como `false`.
Este caminho de execução alternativo segue-se a uma cláusula `if` e define-se com a cláusula `else`:

```java
class Car {
    void drive() {
        if (fuel > 0) {
            fuel--;
        } else {
            stop();
        }
    }
}
```

No exemplo acima, se o carro ficar sem combustível, chamar o método `Car.drive` chama outro método para parar o carro.

A instrução _if-then-else_ também suporta várias condições através da cláusula `else if`:

```java
class Car {
    void drive() {
        if (fuel > 5) {
            fuel--;
        } else if (fuel > 0) {
            turnOnFuelLight();
            fuel--;
        } else {
            stop();
        }
    }
}
```

No exemplo acima, conduzir o carro quando o combustível é inferior ou igual a `5` faz o carro andar, mas acende a luz do combustível.
Quando o combustível chega a `0`, o carro deixa de andar.
