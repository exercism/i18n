# Anexo às instruções

## Dicas

Os testes unitários fornecem exemplos de palavras. Tenta agrupar as consoantes independentemente das combinações específicas de consoantes nos testes unitários.

Este exercício trabalha com dados textuais. Por razões históricas, o tipo `String` do Haskell é sinónimo de `[Char]`, uma lista de carateres. Para lidar com dados textuais de forma mais eficiente, pode usar-se o tipo `Text`.

Como extensão opcional a este exercício, podes:

- Lê sobre [tipos de string](https://haskell-lang.org/tutorial/string-types) em Haskell.
- Adiciona `- text` à tua lista de dependências no package.yaml.
- Importa `Data.Text` da [seguinte forma](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c):

      import qualified Data.Text as T
      import           Data.Text (Text)

- Agora podes escrever, por exemplo, `translate :: Text -> Text` e referir-te aos combinadores de `Data.Text` como, por exemplo, `T.isSuffixOf`.
- Consulta a documentação de [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html),

Esta parte é totalmente opcional.
