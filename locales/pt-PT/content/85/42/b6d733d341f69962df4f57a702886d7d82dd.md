# Fictício

## Módulo "io"

Neste exercício, vais precisar de ler ficheiros.
A classe `File` necessária está no módulo `io`.
Está descrita na [documentação do projeto Wren CLI][wren-cli].

(Repara que o projeto `wren-console` [amplia o módulo `io`][wren-console] com alguns métodos,
embora não sejam necessários para este exercício.)

[wren-cli]: https://wren.io/cli/modules/
[wren-console]: https://github.com/joshgoebel/wren-console#extended-library-support
