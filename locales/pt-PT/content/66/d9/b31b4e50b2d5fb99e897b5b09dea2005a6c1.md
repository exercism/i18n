# Sobre

A Z3 é uma linguagem de Satisfiability Modulo Theory (SMT), utilizada para verificar se equações ou fórmulas são satisfazíveis, ou seja, se têm uma solução possível.

A Z3 é usada sobretudo em verificação de software, resolução de restrições, problemas geométricos, segurança e outras aplicações que beneficiam de computação matemática rápida.

A Z3 foi criada pelo grupo Research in Software Engineering (RiSE) da Microsoft Research e, a partir de 2015, tornou-se uma linguagem de código aberto. O repositório de código aberto da Z3 no GitHub está em https://github.com/Z3Prover/z3.
