# Instruções

Como aspirante a maga, a Elyse precisa de praticar o básico. Tem uma pilha de cartas que quer manipular.

Para facilitar um pouco as coisas, usa apenas as cartas de 1 a 10, por isso a sua pilha de cartas pode ser representada por um vetor de números.
A posição de uma determinada carta corresponde ao índice no vetor.

## 1. Retira uma carta da pilha

Para escolher uma carta, devolve a carta que está no índice `position` da pilha dada.

```R
stack <- c(1, 2, 4, 1)
position <- 3
get_item(stack, position)
# => 4
```

## 2. Troca uma carta na pilha

Faz um pouco de prestidigitação e troca a carta no índice `position` pela carta de substituição indicada.
Devolve a pilha ajustada.

```R
stack <- c(1, 2, 4, 1)
position <- 3
replacement_card <- 6
set_item(stack, position, replacement_card)
# => c(1, 2, 6, 1)
```

## 3. Insere uma carta no topo da pilha

Faz aparecer uma carta, inserindo uma nova carta no topo da pilha.
Devolve a pilha ajustada.

```R
stack <- c(5, 9, 7, 1)
new_card <- 8
insert_item_at_top(stack, new_card)
# => c(5, 9, 7, 1, 8)
```

## 4. Remove uma carta da pilha

Faz desaparecer uma carta, removendo da pilha a carta que está na posição `position`.
Devolve a pilha ajustada.

```R
stack <- c(3, 2, 6, 4, 8)
position <- 3
remove_item(stack, position)
# => c(3, 2, 4, 8)
```

## 5. Verifica o tamanho da pilha

Verifica se o tamanho da pilha é igual a `stack_size` ou não.

```R
stack <- c(3, 2, 6, 4, 8)
stack_size <- 4
check_size_of_stack(stack, stack_size)
# => FALSE
```

## 6. Remove a carta do topo da pilha

Faz desaparecer uma carta, removendo a carta que está no topo da pilha.
Devolve a pilha ajustada.

```R
stack <- c(3, 2, 6, 4, 8)
remove_item_from_top(stack)
# => c(3, 2, 6, 4)
```

## 7. Insere uma carta no fundo da pilha

Faz aparecer uma carta, inserindo uma nova carta no fundo da pilha.
Devolve a pilha ajustada.

```R
stack <- c(5, 9, 7, 1)
new_card <- 8
insert_item_at_bottom(stack, new_card)
# => c(8, 5, 9, 7, 1)
```

## 8. Remove uma carta do fundo da pilha

Faz desaparecer uma carta, removendo a carta que está no fundo da pilha.
Devolve a pilha ajustada.

```R
stack <- c(8, 5, 9, 7, 1)
remove_item_at_bottom(stack)
# => c(5, 9, 7, 1)
```
