## 1. Iniciar uma verificação de fiabilidade para um único valor de entrada

- Neste passo não precisas de uma tarefa: basta um processo ligado normal.
- Há uma [função incorporada][spawn-link] que executa uma função anónima num processo novo e liga-o ao processo atual.

## 2. Interpretar os resultados de uma verificação de fiabilidade

- Para receber uma única mensagem, chama [`receive`][receive] uma vez. Lê a primeira mensagem que corresponda a um dos padrões indicados e deixa as restantes na caixa de entrada do processo.
- Podes usar uma guarda ou [o operador de fixação][pin-operator] para garantir que só são recebidas mensagens de um processo cujo PID corresponda ao PID passado como argumento a `await_reliability_check_result/2`.
- [`receive`][receive] aceita uma cláusula `after` para lidar com tempos limite.

## 3. Executar uma verificação de fiabilidade concorrente para vários valores de entrada

- O processo atual tem de começar a capturar sinais de saída antes de serem criados novos processos ligados.
- Num processo, a captura de sinais de saída consegue-se definindo uma flag nesse processo.
- Há uma [função incorporada][process-flag] que define uma flag num processo e devolve o valor anterior dessa flag.
- A flag para capturar sinais de saída chama-se `:trap_exit` e aceita um valor Boolean.
- Usa as funções do módulo `Enum` para primeiro iniciar um processo para cada valor de entrada e depois aguardar as mensagens de cada processo. Usa as funções que implementaste nos dois passos anteriores. Repara que o mapa devolvido por `start_reliability_check/2` corresponde ao mapa que `await_reliability_check_result/2` espera como primeiro argumento.

## 4. Executar uma verificação de correção concorrente para vários valores de entrada

- Usa uma tarefa assíncrona neste passo.
- Há uma [função incorporada][task-async] que inicia uma tarefa assíncrona.
- Há uma [função incorporada][task-await] que espera que uma tarefa assíncrona termine de executar e devolve o resultado. Aceita um tempo limite como segundo argumento.
- Usa as funções do módulo `Enum` para primeiro iniciar uma tarefa para cada valor de entrada e depois esperar por cada tarefa.
