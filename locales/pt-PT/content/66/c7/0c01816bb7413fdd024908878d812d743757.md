# Testes

Executa os testes com:

```bash
$ gradlew test
```

> Usa `gradlew.bat` se estiveres no Windows

## Testes ignorados

Nos conjuntos de testes, todos os testes excepto o primeiro estão ignorados.

Assim que conseguires que um teste passe, podes ativar o seguinte removendo a anotação `@Ignore`.
