# Tuplas

Uma [tupla][tuple] é uma lista ordenada finita de elementos que é imutável.
As tuplas exigem que todas as posições tenham um tipo fixo.
Isto, por sua vez, significa que o compilador sabe que tipo está em cada posição.
Os tipos usados numa tupla podem ser diferentes em cada posição, mas os tipos têm de ser conhecidos em tempo de compilação.

## Criar uma tupla

Dependendo de os tipos dos valores da tupla poderem ser inferidos em tempo de compilação, a tupla pode ser criada de diferentes formas.
Se os valores forem conhecidos em tempo de compilação, a tupla pode ser criada usando a sintaxe literal de tuplas; caso contrário, é necessário declará-la explicitamente.
É também importante que os tipos dos valores correspondam aos tipos especificados na tupla e que o número de valores corresponda ao número de tipos especificados.
Eis um exemplo de definição através da sintaxe literal de tuplas:

```crystal
tuple = {1, "foo", 'c'} # Tuple(Int32, String, Char)
```

Existe também a possibilidade de criar uma tupla usando a classe `Tuple`.

```crystal
tuple = Tuple(Int32, String, Char).new(1, "foo", 'c')
```

Em alternativa, podes especificar explicitamente o tipo da variável atribuída à tupla.

```crystal
tuple : Tuple(Int32, String, Char) = {1, "foo", 'c'}
```

Especificar explicitamente o tipo da tupla pode ser útil, pois permite definir que uma posição pode conter um tipo de união.
Isto significa que uma posição pode conter múltiplos tipos.

```crystal
tuple : Tuple(Int32 | String, String, Char) = {1, "foo", 'c'}
```

## Conversão

### Criar uma tupla a partir de um array

Podes criar uma tupla a partir de um array usando o método `from` da classe `Tuple`.
Isto exige que o tipo da tupla seja especificado.

```crystal
array = [1, "foo", 'c']
tuple = Tuple(Int32, String, Char).from(array)
```

### Conversão para array

Podes converter uma tupla num array usando o método `to_a`.
O tipo dos elementos do array resultante é a união dos tipos de cada campo da tupla.

```crystal
tuple = {1, "foo", 'c'}
array = tuple.to_a
array # => [1, "foo", 'c']
```

### Abreviação para definir tuplas

Existe uma forma abreviada de definir tipos de tupla explícitos.
Isto é feito escrevendo os tipos dentro do literal de tupla.

```crystal
tuple : {Int32, String, Char} = {1, "foo", 'c'}
```

## Aceder a elementos

Tal como os arrays, as tuplas são indexadas a partir de zero, ou seja, o primeiro elemento está no índice 0.
No entanto, ao contrário dos arrays, o tipo de cada elemento é fixo e conhecido em tempo de compilação; por isso, ao indexar uma tupla, o tipo do elemento é específico da posição.
Para aceder a um elemento numa tupla, podes usar o operador `[]`.

```crystal
array = [1, "foo", 'c']
array[0]         # => 1
typeof(array[0]) # => Int32 | String | Char

tuple = {1, "foo", 'c'}
tuple[0]         # => 1
typeof(tuple[0]) # => Int32
```

Outra diferença no acesso a elementos de arrays é que, se o índice for especificado, o compilador verifica se o índice está dentro dos limites da tupla.
Isto significa que vais receber um erro de compilação em vez de um erro em tempo de execução.

```crystal
tuple = {1, "foo", 'c'}
tuple[3]
# => Error: index out of bounds for Tuple(Int32, String, Char) (3 not in -3..2)
```

No entanto, se o índice estiver guardado numa variável, o compilador não conseguirá verificar se o índice está dentro dos limites da tupla em tempo de compilação e, em vez disso, dará um erro em tempo de execução.

## Subtupla

Podes obter uma subtupla de uma tupla usando o operador `[]` com um intervalo.
O que é devolvido é uma nova tupla com os elementos do intervalo especificado.
O intervalo tem de ser fornecido em tempo de compilação; caso contrário, o compilador não conseguirá saber os tipos dos elementos na subtupla.
Isto significa que o intervalo tem de ser um literal de intervalo e não atribuído a uma variável.

```crystal
tuple = {1, "foo", 'c'}
subtuple = tuple[0..1] # Tuple(Int32, String)

i = 0..1
tuple[i]
# Error: Tuple#[](Range) can only be called with range literals known at compile-time
```

## Quando usar uma tupla

As tuplas são úteis quando queres agrupar um número fixo de valores cujos tipos são conhecidos em tempo de compilação.
Isto porque as tuplas requerem menos memória e são mais rápidas do que os arrays devido à imutabilidade das tuplas.
Outro caso de uso é devolver múltiplos valores de um método.
Isto é particularmente útil se os valores tiverem tipos diferentes, uma vez que cada posição na tupla pode ter um tipo diferente.

As tuplas não devem ser usadas quando é necessária uma estrutura de dados que possa crescer ou encolher de tamanho ou que precise de ser modificada frequentemente.
