# Instruções

Como aspirante a maga, a Elyse precisa de praticar o básico. Tem um baralho de cartas que quer manipular.

Para facilitar um pouco as coisas, só usa as cartas de 1 a 10.

## 1. Obter uma carta de um baralho

Implementa a função `getCard`, que devolve a carta na posição `index` do baralho dado. Se o índice não estiver no baralho, devolve Nothing.

```elm
getCard 2 ( Array.fromList [ 1, 2, 4, 1 ] )
    --> Just 4
getCard 6 ( Array.fromList [ 1, 2, 4, 1 ] )
    --> Nothing
```

## 2. Alterar uma carta no baralho

Implementa a função `setCard`, que devolve um baralho com a carta na posição `index` alterada para a nova carta fornecida.
Se o `index` não estiver no baralho, devolve o baralho original.

```elm
setCard 2 6 ( Array.fromList [ 1, 2, 4, 1 ] )
    --> Array.fromList [ 1, 2, 6, 1 ]
setCard 6 6 ( Array.fromList [ 1, 2, 4, 1 ] )
    --> Array.fromList [ 1, 2, 4, 1 ]
```

## 3. Adicionar uma carta ao baralho

Implementa a função `addCard`, que devolve um baralho com a nova carta adicionada.

```elm
addCard 8 ( Array.fromList [ 5, 9, 7, 1 ] )
    --> Array.fromList [ 5, 9, 7, 1, 8 ]
```

## 4. Remover uma carta do baralho

Implementa a função `removeCard`, que devolve um baralho com a carta na posição `index` removida.
Se o `index` dado não for um índice válido no baralho, devolve o baralho original.

```elm
removeCard 2 ( Array.fromList [ 3, 2, 6, 4, 8 ] )
    --> Array.fromList [ 3, 2, 4, 8 ]
removeCard 2 ( Array.fromList [ 3, 2 ] )
    --> Array.fromList [ 3, 2 ]
```

## 5. Contar o número de cartas pares no baralho

Implementa a função `evenCardCount`, que conta o número de cartas pares no baralho.

```elm
evenCardCount (Array.fromList [ 3, 8, 4, 5, 1, 6, 10 ] )
    --> 4
```
