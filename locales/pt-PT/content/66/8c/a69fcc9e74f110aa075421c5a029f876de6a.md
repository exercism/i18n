# Introdução

## Intervalos

Os intervalos representam uma sequência de um ou vários números inteiros consecutivos. São criados ao ligar dois números inteiros com `..`.

```elixir
1..5
```

Os intervalos podem ser crescentes ou decrescentes. Incluem sempre os valores inicial e final.

Um intervalo implementa o _protocolo Enumerable_, o que significa que podes usar funções do módulo `Enum` para trabalhar com intervalos.
