# Instruções

Neste exercício vais trabalhar com contas poupança.
Todos os anos, o saldo da tua conta poupança é atualizado com base na taxa de juro.
A taxa de juro que o teu banco te dá depende da quantidade de dinheiro na tua conta (o seu saldo):

- 3,213% para um saldo negativo (o saldo fica ainda mais negativo).
- 0,5% para um saldo positivo inferior a `1000` dólares.
- 1,621% para um saldo positivo maior ou igual a `1000` dólares e inferior a `5000` dólares.
- 2,475% para um saldo positivo maior ou igual a `5000` dólares.

Tens quatro tarefas, cada uma delas relacionada com o teu saldo e a sua taxa de juro.

## 1. Calcula a taxa de juro

Implementa o método `SavingsAccount.interest_rate()`, que recebe um saldo como argumento.
O método deve devolver a taxa de juro para o saldo indicado.

```Crystal
SavingsAccount.interest_rate(200.75)
# => 0.5
```

## 2. Calcula o juro

Implementa o método `SavingsAccount.interest()`, que recebe um saldo como argumento.
O método deve devolver o juro para o saldo indicado.

```Crystal
SavingsAccount.interest(200.75)
# => 1.00375
```

## 3. Calcula a atualização anual do saldo

Implementa o método `SavingsAccount.annual_balance_update()`, que recebe um saldo como argumento.
O método deve devolver o saldo ao fim de um ano.

```Crystal
SavingsAccount.annual_balance_update(200.75)
# => 201.75375
```

## 4. Calcula os anos necessários para atingir o saldo pretendido

Implementa o método `SavingsAccount.years_before_desired_balance()`, que recebe um saldo e um saldo objetivo como argumentos.
O método deve devolver o número de anos necessários para atingir o saldo objetivo.

```Crystal
balance = 200.75
target_balance = 214.88
SavingsAccount.years_before_desired_balance(balance, target_balance)
# => 14
```

~~~~exercism/note
Quando aplicas juro simples a um saldo principal, o saldo é multiplicado pela taxa de juro e o produto dos dois é o valor do juro.

O juro composto, por outro lado, é aplicado de forma recorrente.
Em cada aplicação, o valor do juro é calculado e adicionado ao saldo principal, para que os cálculos de juro seguintes incidam sobre um saldo principal maior.
~~~~
