# Anexo às instruções

## Palavras

Define uma tupla `game` e um construtor `<game> ( -- game )` que devolve um novo jogo sem lançamentos.

Disponibiliza estas palavras que operam sobre um jogo:

- `roll ( pins game -- )`: regista que foram derrubados `pins` pinos. Lança um erro quando o lançamento é inválido:
  - `"Negative roll is invalid"` para um número negativo de pinos.
  - `"Cannot roll after game is over"` quando todos os dez frames (e quaisquer lançamentos adicionais) tiverem sido lançados.
  - `"Pin count exceeds pins on the lane"` quando são derrubados mais pinos do que os que estão de pé.
- `score ( game -- n )`: a pontuação total do jogo. Lança `"Score cannot be taken until the end of the game"` quando o jogo ainda não está completo.

Repara que `roll` oculta a palavra de baralhamento `roll` do vocabulário `kernel`. O conjunto de testes resolve a ambiguidade com `FROM: bowling => roll ;`.
