# Sobre

Os Boolean em C++ são representados pelo tipo `bool`.
Um `bool` é `true` ou `false`.

## Operadores lógicos

O C++ suporta três operadores Boolean: `!` (NOT), `&&` (AND) e `||` (OR).
Também podes usar as versões alternativas `not`, `and` e `or`.

```cpp
true || false // => true
true && false // => false
!true // => false
not false // => true
```

## Precedência

Cada um dos três operadores Boolean tem uma _precedência de operadores_ diferente.
Por consequência, são avaliados por esta ordem: `!` primeiro, `&&` a seguir e, por fim, `||`.
Se quiseres forçar uma ordem diferente, podes envolver uma expressão Boolean em parênteses (isto é, `()`), pois os parênteses têm uma precedência de operadores ainda maior.

```cpp
!true && false   // => false
!(true and false) // => true
```

## Conversão

Se usares `true` ou `false` num lugar onde se espera um número, são convertidos em `1` e `0`, respetivamente.
Se usares um número numa operação Boolean, tudo exceto `0` é tratado como `true`, mesmo valores negativos.

```cpp
!true && 0.0   // => false
true + true + false // => 2
```
