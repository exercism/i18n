# Instruções

Aquele carro telecomandado que compraste recentemente transformou-se num passatempo completamente novo. Tens andado a organizar corridas de carros telecomandados.

Estavas quase a acabar de escrever um programa que permitiria correr simulações de corrida quando o teu gato saltou para cima do teclado e apagou algumas linhas de código. Agora o teu programa já não compila...

## 1. Corrige o erro de compilação `Race.__struct__/0 is undefined`

Adiciona um alias para que o módulo `NeedForSpeed.Race` possa ser referido pelo nome mais curto `Race`.

## 2. Corrige o erro de compilação `Car.__struct__/0 is undefined`

Adiciona um alias para que o módulo `NeedForSpeed.RemoteControlCar` possa ser referido pelo nome mais curto `Car`.

## 3. Corrige o erro de compilação `undefined function puts/1`

A função `puts/1` vem do módulo `IO`. Importa-a para a poderes usar sem referir o módulo.

## 4. Corrige o erro de compilação `undefined function default_color/0`

As funções `default_color/0`, `red/0`, `cyan/0` e `green/0` vêm todas do módulo `IO.ANSI`. Estás a planear adicionar suporte para outras cores de carro, por isso queres importar o módulo todo. Infelizmente, a função `color/1` do módulo `IO.ANSI` entra em conflito com uma das tuas funções locais. Importa o módulo `IO.ANSI` todo, exceto essa função.
