# Introdução

Trabalhar com dados binários pode ser complicado, por isso o Gleam disponibiliza um tipo `BitArray` e a sintaxe que o acompanha para construir dados binários e para fazer correspondência de padrões sobre eles.

Os literais de bit array definem-se com a sintaxe `<<>>`. Ao definir um literal de bit array, este é definido em segmentos. Cada segmento tem um valor e uma anotação, separados por `:`. A anotação especifica quantos bits serão usados para codificar o valor e pode ser omitida por completo, o que assume por predefinição um valor inteiro de 8 bits.

```gleam
// This defines a bit array with three segments of a single bit each
<<0:1, 1:1, 0:1>>

// This defines a bit array with three segments of 8 bits each
<<0, 1, 0>>
```

Especificar o tipo como `:1` é uma forma abreviada de escrever `:size(1)`. Tens de usar a sintaxe mais longa se o tamanho em bits vier de uma variável.

```gleam
let segment_size = 1
<<0:size(segment_size), 1:size(segment_size), 0:size(segment_size)>>
```

## Binário

Ao escrever literais de inteiros binários, podemos escrevê-los diretamente em notação de base 2, colocando o prefixo `0b` antes do literal. Repara que são apresentados como números decimais quando impressos nos testes ou no teu programa.

```gleam
<<0b1011:4>> == <<11:4>>
// -> True
```

## Truncagem

Se o valor do segmento exceder a capacidade do tipo do segmento, é truncado a partir da esquerda.

```gleam
<<0b1011:3>> == <<0b0011:3>>
// -> True
```

## Adicionar no início e no fim

Podes acrescentar tanto no início como no fim de um bit array existente usando a sintaxe de bit array. A anotação `:bits` tem de ser usada para o bit array existente.

```gleam
let value = <<0b110:3, 0b001:3>>
let new_value = <<0b011:3, value:bits, 0b000:3>>
// -> <<120, 8:size(4)>>
```

## Concatenar

Podemos concatenar bit arrays guardados em variáveis usando a sintaxe. A anotação `:bits` tem de ser usada ao concatenar dois bit arrays de tamanhos variáveis.

```gleam
let first = <<0b110:3>>
let second = <<0b001:3>>
let concatenated = <<first:bits, second:bits>>
// -> <<49:size(6)>>
```

## Correspondência de padrões

Também podes fazer correspondência de padrões para obter valores a partir do bit array. Tens de saber o número de bits de cada fragmento que queres capturar, com uma exceção: a anotação `:bits` pode ser usada para fazer correspondência de padrões com um bit array de tamanho desconhecido, mas só pode ser usada no último fragmento.

```gleam
let assert <<value:4, rest:bits>> = <<0b01101001:8>>
value == 0b0110
// -> true
```

## Inspecionar bit arrays

~~~~exercism/note
Os bit arrays podem ser impressos num formato diferente daquele que foi usado
para os criar. Isto causa frequentemente confusão quando se está a aprender bit arrays.
~~~~

Por predefinição, os bit arrays são apresentados em fragmentos de 8 bits (um byte), mesmo que os tenhas criado com fragmentos de outro tamanho.

```gleam
<<2011:11>>
// -> <<251, 3:size(3)>>
```

Se criares um bit array que representa uma string codificada em UTF-8 imprimível, pode ser apresentado como string por funções como `io.debug`. Isto deve-se a um detalhe de implementação da forma como o Gleam representa strings internamente.

```gleam
<<>>
// -> ""

<<65, 66, 67>>
// -> "ABC"
```
