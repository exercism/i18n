# Sobre

As [guardas][guards] são usadas como complemento da [correspondência de padrões][exercism-pattern-matching]. Permitem fazer verificações mais complexas. Podem ser usadas em [algumas situações, mas não todas][where-guards-can-be-used] onde a correspondência de padrões também pode ser usada, por exemplo em cláusulas de funções ou em cláusulas case.

```elixir
def empty?(list) when is_list(list) and length(list) == 0 do
  true
end
```

- As guardas começam com a palavra-chave `when`, seguida de uma expressão Boolean.
- As expressões de guarda são funções especiais que:
  - Têm de ser [puras][pure-function] e não alterar nenhum estado global.
  - Têm de devolver valores `true` ou `false` estritos.
- Encontras uma lista de guardas comuns na [documentação do Elixir][kernel-guards]. Incluem:
  - Verificações de tipo: [`is_integer/1`][guard-is-integer], [`is_list/1`][guard-is-list], [`is_nil/1`][guard-is-nil], etc.
  - Operadores aritméticos: [`+/2`][guard-plus], [`-/2`][guard-minus], etc.
  - Comparações: [`==/2`][guard-equals], [`>/2`][guard-greater], [`</2`][guard-less], etc.
  - Operadores Boolean: [`and/2`][guard-and], [`or/2`][guard-or], [`not/1`][guard-not]
  - Operador de pertença: [`in/2`][guard-in]
- Podes definir as tuas próprias guardas com [`defguard`][defguard].

  - De acordo com a [convenção de nomenclatura][naming] do Elixir, os nomes das guardas devem começar por `is_`.

    ```elixir
    defmodule HTTP do
      defguard is_success(code) when code >= 200 and code < 300

      def handle_response(code) when is_success(code) do
        :ok
      end
    end
    ```
