# Dicas

## Geral

- O pacote [`roc-random`](https://github.com/kili-ilo/roc-random) está disponível no cabeçalho de `simple-cipher-test.roc` (com o alias `random`).
  Podes usá-lo na tua solução se quiseres, por exemplo, importando `random.Random`.

- `Random.step(state, generator)` devolve `{ value, state }`, que contém um valor gerado e o estado aleatório atualizado.
  Devolve esse estado atualizado a partir de `create_random`, para que a chamada seguinte possa continuar a sequência.

- `Random.list` e `Random.map` podem ajudar a construir um gerador para uma chave completa.
