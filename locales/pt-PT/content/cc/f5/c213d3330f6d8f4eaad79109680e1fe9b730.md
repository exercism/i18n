# Sobre

As [listas][list] são um tipo de dados básico em Elixir para guardar uma coleção de valores. As listas são _imutáveis_, ou seja, não podem ser modificadas. Qualquer operação que altere uma lista devolve uma nova lista. As listas implementam o [protocolo Enumerable][enum-protocol], o que permite usar as funções dos módulos [Enum][enum] e [Stream][stream].

As listas em Elixir são implementadas como [listas ligadas][linked-list-wiki] e não como arrays de localizações de memória contíguas. Por isso, aceder a um elemento de uma lista demora um tempo linear, que depende do comprimento da lista.

As listas podem ser escritas na forma literal, na notação cabeça-cauda (que usa o operador `cons`, `|`), ou numa combinação das duas:

```elixir
# Literal Form
[]
[1]
[1, 2, 3]

# Head-tail Notation
[]
# same as [1]
[1 | []]
# same as [1, 2, 3]
[1 | [2 | [3 | []]]]

# Mixed
# same as [1, 2, 3]
[1 | [2, 3]]
```

Também pode haver mais do que um elemento antes do operador _cons_ (`|`).

```elixir
# Multiple prepends
[1, 2, 3 | [4, 5]]
```

A notação cabeça-cauda pode ser usada para acrescentar itens ao fim de uma lista.

```elixir
list = [2, 1]

[3, 2, 1] == [3 | list]
# => true
```

Acrescentar elementos a uma lista durante uma iteração é considerado um antipadrão. Acrescentar um elemento exige percorrer a lista toda e adicionar o elemento no fim; por isso, acrescentar um novo elemento em cada iteração obrigaria a percorrer a lista toda em cada iteração.

Podemos obter o mesmo resultado acrescentando um elemento ao início da lista invertida e invertendo o resultado a seguir. Acrescentar ao início é uma operação rápida e demora um tempo constante.

```elixir
# Appending to the end of a list (potentially slow)
[1, 2, 3] ++ [4] ++ [5] ++ [6]

# Prepend to the start of a list (faster, due to the nature of linked lists)
[6 | [5 | [4 | [3, 2, 1]]]]
# then reverse!
```

Existem várias funções comuns do `Kernel` para listas:

- [`hd/1`][hd] devolve a _cabeça_ de uma lista, ou seja, o _primeiro_ item da lista.
- [`tl/1`][tl] devolve a _cauda_ da lista, isto é, a lista _sem_ o _primeiro_ item.
- [`length/1`][length] devolve o número de itens da lista.
- [`in/2`][in] devolve um valor booleano que indica se o item é um elemento da lista.

Existe também o [módulo `List`][list].

As listas podem conter qualquer tipo de dados, bem como uma mistura de tipos de dados diferentes.

```elixir
list = [1, :a, 2.0, "string"]
```
