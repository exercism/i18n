# Introdução

## Arrays

Um `array` (ou _vetor_) em F# é uma coleção mutável de zero ou mais valores com um comprimento fixo. Isto significa que, depois de criado um array, o seu tamanho não pode mudar, mas os seus valores podem. Os valores de um array têm de ser todos do mesmo tipo. Os arrays podem ser definidos da seguinte forma:

```fsharp
let empty = [| |]
let emptyAlternative = Array.empty

let singleValue = [| 5 |]
let singleValueAlternative = Array.singleton 5

let threeValues = [| "a"; "b"; "c" |]
```

Podes atribuir elementos a um array ou obtê-los a partir dele através de um índice. Os arrays de F# começam em zero, o que significa que o índice do primeiro elemento é sempre zero:

```fsharp
let numbers = [| 2; 3; 5 |]

// Update value in array
numbers[2] <- 9

// Read value from array
numbers[2]
// => 9
```

Os arrays são manipulados através de funções e operadores definidos no módulo `Array` ou, manualmente, com correspondência de padrões através do padrão _array_:

```fsharp
let describe array =
    match array with
    | [| |] -> "Empty"
    | [| 1; 2; three |] -> sprintf "1, 2, %d" three
    | _ -> "Other"

describe [| |]         // => "Empty"
describe [| 1; 2; 4 |] // => "1, 2, 4"
describe [| 5; 7; 9 |] // => "Other"
```

Também podes _descartar_ um valor durante a correspondência de padrões. Quando _não_ te importas com um valor num caso específico (ou seja, não vais _usar_ esse valor), podes usar um underscore (`'_'`) para o indicar:

```fsharp
let describe array =
    match array with
    | [| |] -> "Empty array"
    | [| x |] -> "Array with one item"
    | [| _; y |] -> "Array with two items (first item ignored)"
    | _ -> "Array with many items (all items ignored)"

describe [| |]          // => "Empty array"
describe [| 1 |]        // => "Array with one item"
describe [| 5; 7 |]     // => "Array with two items (first item ignored)"
describe [| 5; 7; 9 |]  // => "Array with many items (all items ignored)"
```

O `'_'` isolado deve ficar sempre em _último_ lugar na correspondência de padrões: todos os valores que _não_ correspondam a nenhum dos outros casos serão tratados por este caso.
