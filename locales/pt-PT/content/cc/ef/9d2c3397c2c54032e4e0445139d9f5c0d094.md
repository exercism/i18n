# Introdução

O PowerShell é uma linguagem de scripting da Microsoft, de tipos implícitos e dinâmicos (também suporta variáveis de tipos fortes), focada principalmente na automatização de tarefas e na gestão de configuração.

O PowerShell suporta programação imperativa, funcional, orientada a objetos e até o estilo de pipeline.

O PowerShell foi construído sobre a plataforma .NET e lançado pela primeira vez em 2006.
Está incluído por predefinição em todos os sistemas Windows modernos e pode ser instalado no Mac e no Linux.


## Variáveis

Há duas formas comuns de definir uma variável em PowerShell.

O nome de uma variável em PowerShell tem de começar com `$` e usa-se o operador de atribuição `=` para associar o nome da variável a um valor.

```powershell
> $intVar = 1
> $doubleVar = 2.0
> $stringVar = "Hello"

# Checking a variable type using the GetType() method
> Write-Host $doubleVar.GetType()
System.Double
```

Também podes especificar explicitamente o tipo de uma variável, se quiseres impor um [tipo][strong typed] específico.
O PowerShell faz os possíveis para converter o valor de um tipo para outro, se for possível.

```powershell
# String represents a floating number can be converted to integer
> [int]$staticOne = "1.234"
> $staticOne
1

# String of letters can not be converted to double type
> [double]$staticTwo = "hello"
MetadataError: Cannot convert value "hello" to type "System.Double"
```


### Constantes

Em PowerShell, as constantes são variáveis só de leitura que não podem ser **removidas** depois de definidas.
Isto leva-nos à segunda forma de definir variáveis, usando o cmdlet `New-Variable`.

```powershell
> New-Variable -Name "MyConstant" -Value 100 -Option Constant
> $MyConstant
```

Para uma forma mais detalhada e avançada de criar uma nova variável com várias opções, consulta o cmdlet [New-Variable][New-Variable].


## Funções

Em PowerShell, as [funções][functions] definem-se com a palavra-chave `function`.
Cada função pode ter zero ou mais [parâmetros][parameters] formais entre parênteses `()`, seguidos do seu próprio [âmbito][scope], que começa com `{` e termina com `}`.

```powershell
function Greeting {
    return "Hello!"
}
```

Em PowerShell, as funções podem devolver valores explicitamente através da palavra-chave `return`, depois de serem chamadas com a sintaxe `FuncName $Arg`.

```powershell
function AddTwoNumbers($NumOne, $NumTwo):
    $result = $NumOne + $NumTwo
    return $result

> AddTwoNumbers 10 20
30
```

Uma análise mais avançada de como escrever uma definição de função detalhada, e de como as funções podem devolver valores implicitamente, será abordada no módulo do conceito `Functions`.


## Comentários

Um comentário de linha única em PowerShell começa com `#` e termina no fim da linha.
Um bloco de comentário em PowerShell começa com `<#` e termina com `#>`.
Uma demonstração avançada do bloco de comentário para criar ajuda baseada em comentários será abordada no módulo do conceito `Functions`.

```powershell
function Main() {
    #This is a comment
}
```
