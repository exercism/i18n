# Conceitos de números de Armstrong

> Um [número de Armstrong](https://en.wikipedia.org/wiki/Narcissistic_number) é um número que é a soma dos seus próprios algarismos, cada um elevado à potência do número de algarismos.

## Solução de exemplo

```rust
pub fn is_armstrong_number(num: u32) -> bool {
    let digits = format!("{}", num);
    digits
        .chars()
        .map(|c| c.to_digit(10).unwrap().pow(digits.len() as u32))
        .sum::<u32>()
    == num
}
```

## Conceitos

- funções: essenciais para verificar a solução e definir a lógica
- Conjuntos de testes: necessários para verificar a solução
- números inteiros: `u32` para o argumento e as verificações de identidade
- `&str`: necessário para contar o comprimento do número, uma vez que o Rust é fortemente tipado
- `Option<T>`: necessário para aceder ao valor real de `char::to_digit`
- conversão de tipos: necessária para aplicar operações aritméticas
- características dos iteradores:
  - turbofish para permitir uma solução numa única expressão
  - `map` e `sum` para reduzir convenientemente a expressão ao que precisamos de verificar
