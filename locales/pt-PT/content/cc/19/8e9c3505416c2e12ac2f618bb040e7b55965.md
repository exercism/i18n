# Instruções

Neste exercício vais trabalhar com algumas funções para gerir marcações.
O sistema guarda tudo em strings formatadas em ISO 8601, mas não é assim que as pessoas usam o calendário.
São necessárias várias funções para converter entre os diferentes formatos.

## 1. Cria uma marcação

Cria uma marcação daqui a `n` dias, à hora atual.
A função recebe `n` dias e devolve a hora da marcação daqui a `n` dias.

```javascript
createAppointment(4, now);
// Given now is Sun Oct 05 2022 23:28:43 GMT+0600 (Bangladesh Standard Time)
// => Sun Oct 09 2022 23:28:43 GMT+0600 (Bangladesh Standard Time)
```

Se o segundo parâmetro `now` não for usado, deve ser usada a hora atual.

## 2. Converte uma data num timestamp

Várias ferramentas só funcionam com o formato ISO 8601, normalizado internacionalmente.
Escreve a função `getAppointmentTimestamp`, que recebe uma data e devolve uma string nesse formato.

```javascript
const appointment = new Date(Date.UTC(2010, 6, 16, 12, 42, 0, 0));

getAppointmentTimestamp(appointment);
// => '2010-07-16T12:42:00.000Z'
```

## 3. Obtém os detalhes de uma marcação

Os timestamps são difíceis de ler; uma função para obter os detalhes da marcação deve ajudar nisso.
A função `getAppointmentDetails` recebe um timestamp no formato ISO 8601 e devolve o ano, o mês, o dia, a hora e os minutos.

```javascript
getAppointmentDetails('2022-04-24T08:15:00.000');
// => { year: 2022, month: 3, date: 24, hour: 8, minute: 15 }
```

## 4. Atualiza uma marcação com as opções indicadas

A função recebe como primeiro argumento a hora da marcação e como segundo argumento um objeto com algumas opções.
Tens de atualizar a marcação de acordo com as opções do objeto e devolver a nova data da marcação.
O objeto de opções pode ter várias opções.

```javascript
updateAppointment('2022-02-09T09:20:00.000', { month: 6 });
// => { year: 2022, month: 6, date: 9, hour: 10, minute: 20 }
```

## 5. Obtém o tempo disponível entre duas marcações

A função recebe duas marcações (timestamps) como argumentos.
Tens de devolver a diferença entre esses dois momentos em segundos.

Como meio segundo é quase irrelevante, arredonda o número antes de o devolver.

```javascript
timeBetween('2022-12-12T09:20:00.000', '2022-12-18T08:30:00.000');
// => 515400
```

## 6. Verifica se uma marcação é válida ou não

Por fim, quando a marcação é criada, o sistema precisa de verificar se é válida.
Por outras palavras, a marcação tem de estar no futuro e não no passado.

Escreve a função `isValid`, que recebe dois argumentos, um timestamp de marcação (string) e a hora atual como timestamp (string), e devolve `true` se a marcação estiver no futuro, dada a hora atual.

```javascript
isValid('2022-02-11T23:00:00.000', '2022-02-08T23:00:00.000');
// => true
```
