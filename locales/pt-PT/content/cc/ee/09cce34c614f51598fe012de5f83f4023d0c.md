# Instruções

A Elena é a nova responsável pela qualidade de uma fábrica de jornais. Como acabou de chegar à empresa, decidiu analisar alguns dos processos da fábrica para ver o que poderia ser melhorado.
Descobriu que os técnicos fazem muitos controlos de qualidade à mão.
Vê aí uma boa oportunidade de automatização e pede-te a ti, um programador independente, para desenvolveres um software que monitorize algumas das máquinas.

## 1. Monitoriza o nível de humidade da sala

A tua primeira missão é escrever um software para monitorizar o nível de humidade da sala de produção. Já existe um sensor ligado ao software da empresa que devolve periodicamente a percentagem de humidade da sala.

Precisas de implementar uma função no software que lance um erro se a percentagem de humidade for demasiado alta.
A função deve chamar-se `checkHumidityLevel` e receber a percentagem de humidade como parâmetro.

Deves lançar um erro (a mensagem não é importante) se a percentagem exceder 70%.

```javascript
checkHumidityLevel(60);
// => undefined
```

```javascript
checkHumidityLevel(100);
// Throws an error
```

## 2. Deteta o sobreaquecimento

A Elena ficou muito satisfeita com a tua primeira tarefa e pede-te para tratares da monitorização da temperatura das máquinas.
Enquanto conversas com um técnico, o Greg, ele diz-te que, se a temperatura de uma máquina exceder 500 °C, os técnicos começam a preocupar-se com o sobreaquecimento.

A máquina está equipada com um sensor que mede a sua temperatura interna.
Deves saber que o sensor é muito sensível e avaria com frequência.
Nesse caso, os técnicos terão de o substituir.

A tua tarefa é implementar uma função `reportOverheating` que recebe a temperatura como parâmetro e lança um erro se o sensor estiver avariado ou se a máquina começar a sobreaquecer.
Como vais precisar mais tarde de reagir de forma diferente consoante o erro, precisas de um mecanismo para distinguir os dois tipos de erro.
Podias basear-te nas mensagens de erro, mas isso tornaria o teu código frágil, pois deixaria de funcionar se a mensagem fosse atualizada.
Por isso, para o fazeres corretamente, vais lançar instâncias de classes de erro diferentes.

- Se o sensor estiver avariado, a temperatura será `null`.
  Nesse caso, deves lançar um `ArgumentError`.
- Quando tudo funciona, se a temperatura exceder 500 °C, deves lançar um `OverheatingError`.
  Esta classe de erro será instanciada com um argumento de temperatura.
  Certifica-te de que o `OverheatingError` que lanças tem uma propriedade `throw` associada.

```javascript
reportOverheating(null);
// Throws an ArgumentError
```

```javascript
reportOverheating(800);
// Throws an OverheatingError
```

## 3. Monitoriza a máquina

Agora que a tua máquina consegue detetar erros, vais implementar uma função que reage a esses erros de formas diferentes:

- Se o sensor estiver avariado, tens de avisar um técnico
- Se a temperatura for demasiado alta, ou desligas a máquina se a temperatura exceder 600 °C, ou acendes uma luz de aviso se for inferior a isso.
- Se ocorrer outro erro, voltas a lançá-lo.

Implementa uma função `monitorTheMachine` que recebe um argumento `actions`.

`actions` é um objeto que tem 4 propriedades:

| propriedade        | descrição                                                                             |
| ------------------ | ------------------------------------------------------------------------------------- |
| `check`            | uma _*função*_. Verifica a temperatura da máquina. Pode lançar vários erros.          |
| `alertDeadSensor`  | uma _*função*_. Avisa um técnico de que o sensor de temperatura está avariado.        |
| `alertOverheating` | uma _*função*_. Acende uma luz de aviso na máquina.                                   |
| `shutdown`         | uma _*função*_. Desliga a máquina.                                                    |

A função `monitorTheMachine(actions)` deve chamar internamente `check()`.
Se isso correr bem, a função não deve devolver nada.
Se isso lançar um erro, espera-se um comportamento diferente:

| exceção            | comportamento esperado                    |
| ------------------ | ----------------------------------------- |
| `ArgumentError`    | chamar a função `alertDeadSensor`.        |
| `OverheatingError` | executar o protocolo de sobreaquecimento. |
| _(qualquer outra coisa)_ | voltar a lançar o erro               |

**Protocolo de sobreaquecimento**
Se a temperatura for inferior a 600 °C, acende a luz de aviso chamando a função `alertOverheating`.
Se a temperatura exceder 600 °C, a situação é crítica, por isso chama a função `shutdown`.

```javascript
monitorTheMachine({
  check,
  alertDeadSensor,
  alertOverheating,
  shutdown,
});
```
