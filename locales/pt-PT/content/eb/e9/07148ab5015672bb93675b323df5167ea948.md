# Testes

Para testar a solução, só precisas de **executar o script de teste**. Podes fazer isto a partir da Red Console, usando a função `do` juntamente com o caminho do script de teste, assim:

```red
do %exercism/red/hello-world/hello-world-test.red
```

Ou basta adicioná-lo como argumento ao binário Red no terminal do teu sistema:

```shell
red exercism/red/hello-world/hello-world-test.red
```

Inicialmente, só o primeiro teste do ficheiro de teste estará ativo. Isto é para te encorajar a resolver os exercícios um de cada vez. Assim que conseguires passar o primeiro teste, altera o segundo *argumento* da função `test-init` no início do ficheiro de teste e volta a executá-lo. Este valor é o número de testes ativos, por isso, se o alterares de `1` para `2`, ativas o segundo teste. Também podes remover o refinamento `\limit` da função `test-init` e o segundo argumento, para executar todos os testes sem saltar nenhum.
