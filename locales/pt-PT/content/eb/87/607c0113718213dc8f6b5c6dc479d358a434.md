# Anexo às instruções

## Registos

| Registo | Utilização                 | Tipo     | Descrição                                            |
| ------- | -------------------------- | -------- | ---------------------------------------------------- |
| `$a0`   | parâmetro de entrada       | endereço | string de nome terminada por null, ou ponteiro null  |
| `$a1`   | parâmetro de entrada/saída | endereço | string de resultado terminada por null               |
| `$t0-9` | temporário                 | qualquer | para armazenamento temporário                        |
