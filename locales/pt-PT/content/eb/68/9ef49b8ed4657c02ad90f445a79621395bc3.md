# Sobre

A maior parte da iteração em Factor é expressa com combinadores (`each`, `map`, `reduce`), mas a recursão explícita ainda tem o seu lugar: quando a recursão não tem forma de lista, quando o caso base não é trivial, ou quando estás a implementar um combinador tu próprio.

```factor
: total ( seq -- sum )
    [ 0 ] [ unclip swap total + ] if-empty ;

: gcd ( a b -- g )
    dup zero? [ drop ] [ tuck mod gcd ] if ;
```

Algumas coisas que convém saber:

- As definições simples com `:` podem chamar-se a si próprias sem sintaxe especial. O compilador infere os efeitos de pilha ao longo da chamada recursiva.
- `loop ( quot -- )` permite-te iterar uma quotation que devolve um boolean: continua enquanto for avaliado como verdadeiro.
- As chamadas em cauda compilam para saltos, por isso, palavras profundamente recursivas não fazem a pilha transbordar.

O par `unclip` / `if-empty` é a forma padrão de recursão em sequências; `cond` é a forma padrão de despacho para vários casos.
