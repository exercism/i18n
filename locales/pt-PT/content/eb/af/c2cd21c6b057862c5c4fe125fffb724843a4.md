# índice de rune usado com bytes

Iterar sobre `runes` e usar o índice para obter `bytes` individuais é seguro neste caso,
porque a entrada é composta apenas por carateres ASCII.
Para ver o que acontece quando são usados carateres não ASCII, acrescenta este caso de teste:

```go
{
	s1:          "aüa",
	s2:          "aÃa",
	want:        1,
	expectError: false,
}
```
