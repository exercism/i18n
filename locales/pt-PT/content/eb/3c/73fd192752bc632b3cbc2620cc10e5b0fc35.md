# Introdução

Quando o Elixir resolve a função a invocar, usa o nome do módulo para fazer uma consulta. A consulta pode ser feita dinamicamente se o nome do módulo estiver associado a uma variável.

```elixir
defmodule MyModule do
  def message(), do: "My message"
end

atom = MyModule
atom.message()
# => "My message"
```

Internamente, o nome de um módulo é um átomo. Todos os átomos de módulo do Elixir são automaticamente prefixados com `Elixir.`

```elixir
is_atom(Enum)
# => true
Enum == Elixir.Enum
# => true
```
