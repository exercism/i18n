# Tratamento de erros

Neste exercício vais implementar uma função chamada `processString` que processa uma string de entrada com o devido tratamento de erros.

Vais aprender a:

- Verificar os tipos de entrada e lançar erros para valores de entrada inválidos.
- Lançar erros para casos específicos (por exemplo, strings vazias).
- Devolver a versão da string em maiúsculas, se esta for válida.
- Tratar e capturar erros com um bloco try..catch


Implementa a função processString com um bloco `try…catch`.

Dentro do bloco `try`:
- Se o valor de entrada não for uma string, lança um `TypeError`.
- Se o valor de entrada for uma string vazia, devolve `null`.
- Se o comprimento do valor de entrada for superior a 100, ou inferior a 10, lança um `RangeError`
- Se o valor de entrada contiver uma mistura de letras e números, lança um `SyntaxError`.
- Caso contrário, devolve o valor de entrada em `uppercase`.

*Não te esqueças de anexar mensagens de erro adequadas quando lançares o erro! Uma mensagem de erro informativa e bem estruturada pode poupar-te horas de depuração.*

Dentro do bloco `catch`:
- regista a mensagem do erro com `console.log`
- `throw` o `error` para que o seu tipo possa ser testado.
