# Instruções adicionais

## Sugestões

Para completar este exercício, tens de implementar as seguintes funções:

- `boardString`
- `canAttack`

As assinaturas de tipo já estão lá, mas cabe-te a ti definir as funções.

As posições são indicadas como tuplos de dois elementos:

- O primeiro elemento é a linha (fileira, em termos de xadrez).
- O segundo elemento é a coluna (coluna, em termos de xadrez).
- (0, 0) é o canto superior esquerdo do tabuleiro, (0, 7) é o canto superior direito,
- (7, 0) é o canto inferior esquerdo e (7, 7) é o canto inferior direito.
