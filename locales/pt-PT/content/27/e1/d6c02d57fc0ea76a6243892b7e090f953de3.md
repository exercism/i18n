# Introdução

Uma `string` em F# é um objeto que representa texto imutável como uma sequência de carateres Unicode (letras, algarismos, pontuação, etc.) e define-se da seguinte forma:

```fsharp
let fruit = "Apple"
```

As strings são manipuladas chamando os métodos da string ou usando as funções do módulo `String`. Assim que uma string é construída, o seu valor nunca pode mudar. Quaisquer métodos ou funções que pareçam modificar uma string vão, na verdade, devolver uma nova string.

As strings podem ser concatenadas ou formatadas de várias formas diferentes.
* Podes usar o operador `+` para concatenar:
```fsharp
let sentence = "Apple" + " is a type of fruit."
```
* Podes usar a função `sprintf` para formatar texto, em que tens marcadores de posição num texto de formatação (`%s` para uma `string`) e forneces os valores como argumentos:
```fsharp
let sentence = sprintf "%s is a type of %s." "Apple" "fruit"
```
