# Instruções

Neste exercício vais processar linhas de log.

Cada linha de log é uma string formatada da seguinte forma: `"[<LVL>]: <MESSAGE>"`.

Estes são os diferentes níveis de log:

- `TRC` (rastreio)
- `DBG` (debug)
- `INF` (informação)
- `WRN` (aviso)
- `ERR` (erro)
- `FTL` (fatal)

Tens três tarefas.

## 1. Analisar o nível de log

Define um enum `LogLevel` com seis elementos correspondentes aos níveis de log acima.

- `Trace`
- `Debug`
- `Info`
- `Warning`
- `Error`
- `Fatal`

De seguida, implementa o método (_static_) `LogLine.ParseLogLevel()` para analisar o nível de log de uma linha de log:

```csharp
LogLine.ParseLogLevel("[INF]: File deleted")
// => LogLevel.Info
```

## 2. Suportar um nível de log desconhecido

Infelizmente, por vezes algumas linhas de log têm um nível de log desconhecido. Para lidar com estas linhas de log de forma elegante, adiciona um elemento `Unknown` ao enum `LogLevel` que deve ser devolvido ao analisar um nível de log desconhecido:

```csharp
LogLine.ParseLogLevel("[XYZ]: Overly specific, out of context message")
// => LogLevel.Unknown
```

## 3. Converter uma linha de log para o formato curto

O nível de log de uma linha de log é bastante verboso. Para reduzir o espaço em disco necessário para armazenar as linhas de log, foi desenvolvido um formato curto: `"[<ENCODED_LEVEL>]:<MESSAGE>"`.

O nível de log codificado é um mapeamento simples de um nível de log para um número:

- `Unknown` - `0`
- `Trace` - `1`
- `Debug` - `2`
- `Info` - `4`
- `Warning` - `5`
- `Error` - `6`
- `Fatal` - `42`

Implementa o método (_static_) `LogLine.OutputForShortLog()` que consegue produzir o formato curto da linha de log:

```csharp
LogLine.OutputForShortLog(LogLevel.Error, "Stack overflow")
// => "6:Stack overflow"
```
