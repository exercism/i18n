# Introdução

O tipo `atom` do Elixir representa uma constante fixa. O valor de um átomo é simplesmente o seu próprio nome. Isto dá-nos uma forma de interagir com os dados com segurança de tipos. Os átomos podem ser definidos da seguinte forma:

```elixir
# All atoms are preceded with a ':' then follow with alphanumeric snake-cased characters
variable = :an_atom
```

_Os átomos_ são representados internamente por um número inteiro numa tabela de consulta, definido automaticamente. Não é possível alterar este valor interno.
