# Introdução

A capacidade de algo ser definido em termos de si próprio chama-se recursão. Em F#, a recursão encontra-se mais frequentemente em funções recursivas, que são funções que se chamam a si próprias.

Uma função recursiva tem de ter pelo menos um _caso base_ e pelo menos um _caso recursivo_. Um _caso base_ devolve um valor sem voltar a chamar a função. Um _caso recursivo_ volta a chamar a função, modificando o valor de entrada para que este, em algum momento, corresponda ao caso base.

As funções recursivas são definidas da mesma forma que as funções normais, mas com o modificador `rec`. Sem este modificador, uma função _não_ conseguirá chamar-se a si própria e qualquer tentativa de o fazer resultará num erro de compilação. Assim, a recursão tem de ser adotada explicitamente.

```fsharp
let rec factorial x =
    // Base case
    if x = 1 then
        1
    // Recursive case
    else
        x * factorial (x - 1)
```

O F# também suporta tipos recursivos através de tipos de união discriminada. Num tipo de união discriminada recursivo, um ou mais dos seus casos referem-se ao próprio tipo de união discriminada nos seus dados. Tal como as funções recursivas, os tipos recursivos têm de ter um caso base. Ao contrário das funções recursivas, os tipos recursivos não usam a palavra-chave `rec`.

```fsharp
type RussianDoll =
    | Doll                 // Base case
    | Layer of RussianDoll // Recursive case
```
