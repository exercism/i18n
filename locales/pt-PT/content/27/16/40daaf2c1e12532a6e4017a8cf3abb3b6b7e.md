# Sobre

## Introdução

Os genéricos são uma funcionalidade da linguagem que permite reutilizar código.
Por exemplo, não deveria importar que tipo uma lista contém para calcular o seu comprimento.
É por isso que a função `length` usa um parâmetro de tipo genérico `a` na sua assinatura de tipo.

```elm
length : List a -> Int
```

## Parâmetros nos tipos

Quando um tipo é genérico em relação a outro tipo, usamos um nome em minúsculas para esse outro tipo e chamamos-lhe parâmetro de tipo.
Exemplos comuns são os tipos personalizados `List`, `Maybe` e `Result`.

```elm
-- Maybe is generic over the type a
type Maybe a
    = Nothing
    | Just a

someString : Maybe String
someString = Just "hello"

someInt : Maybe Int
someInt = Just 42
```

Uma observação importante sobre os nomes dos parâmetros de tipo é que podem ter vários carateres.
A única restrição é que têm de ser nomes em minúsculas.
Por isso, quando é útil, costumamos dar-lhes nomes descritivos.

Um tipo pode ser genérico em relação a vários outros tipos e, por isso, ter vários parâmetros de tipo.
Nesse caso, cada tipo independente recebe um nome diferente em minúsculas.
O facto de serem independentes não impede que se tornem o mesmo tipo, apenas lhes permite ser diferentes.

```elm
-- Result is generic over the types error and value
type Result error value
    = Ok value
    | Err error
```

Os aliases de tipo de registo também podem ter parâmetros de tipo, embora seja menos comum.

```elm
-- Event is generic over the type a
type alias Event a =
    { at : Time
    , data : a 
    }
```

## Parâmetros de tipo nas funções

Uma vez que os tipos podem ser genéricos, as funções também podem.
É possível escrever funções que trabalham com tipos genéricos, como a `Maybe.withDefault`.

```elm
withDefault : a -> Maybe a -> a
withDefault default maybe =
    case maybe of
      Just value -> value
      Nothing -> default
```

As funções que recebem outras funções como parâmetros chamam-se funções de ordem superior, e estas também podem ser genéricas.

```elm
map : (a -> b) -> Maybe a -> Maybe b
map function maybe =
  case maybe of
    Just value ->
      Just (function value)

    Nothing ->
      Nothing
```
