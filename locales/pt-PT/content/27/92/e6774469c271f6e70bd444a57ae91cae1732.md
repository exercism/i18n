# Introdução

Os mapas em Elixir são a estrutura de dados para guardar informação em pares chave-valor. Noutras linguagens, estas estruturas também podem ser conhecidas como arrays associativos (PHP), hashes (Perl 5, Raku) ou dicionários (Python).

As chaves e os valores podem ser de qualquer tipo de dados, mas se a chave for um átomo podemos usar uma sintaxe abreviada. Os mapas não garantem a ordem das suas entradas quando estas são acedidas ou devolvidas.

## Formas literais

Um mapa vazio declara-se simplesmente com `%{}`. Se quisermos acrescentar itens a um literal de mapa, podemos usar duas formas:

```elixir
# If the key is an atom:
%{atom_key: 1}

# If the key is a different type:
%{1 => :atom_value}

# You can even mix these if the atom form comes second:
%{"first_form" => :a, atom_form: :b}
```

Embora não exista um formato canónico, escolhe uma forma consistente de representar os pares chave-valor literais.

## Funções do módulo Map

O Elixir disponibiliza muitas funções para trabalhar com mapas no _módulo Map_. Algumas funções do _módulo Map_ exigem que lhes passes uma função _anónima_ para ajudar na transformação do mapa.
