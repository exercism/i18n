# Introdução

Em Go, `map` é um tipo de dados incorporado que associa chaves a valores.
Noutras linguagens de programação, podes estar familiarizado com o conceito de `map` como um dicionário, uma tabela de hash, um armazenamento de chave/valor ou um array associativo.

Sintaticamente, `map` tem este aspeto:

```go
map[KeyType]ElementType
```

É também importante saber que cada chave é única, ou seja, atribuir a mesma chave duas vezes sobrescreve o valor da chave correspondente.

Para criar um map, podes fazer:

```go
  // With map literal
  foo := map[string]int{}
```

ou

```go
  // or with make function
  foo := make(map[string]int)
```

Aqui estão algumas operações que podes fazer com um map

```go
  // Add a value in a map with the `=` operator:
  foo["bar"] = 42
  // Here we update the element of `bar`
  foo["bar"] = 73
  // To retrieve a map value, you can use
  baz := foo["bar"]
  // To delete an item from a map, you can use
  delete(foo, "bar")
```

Se tentares obter o valor de uma chave que não existe no map, este devolve o valor zero do tipo do valor.
Isto pode confundir-te, sobretudo se o valor predefinido do teu `ElementType` (por exemplo, 0 para um int) for um valor válido.
Para verificar se uma chave existe no teu map, podes usar

```go
  value, exists := foo["baz"]
  // If the key "baz" does not exist,
  // value: 0; exists: false
```
