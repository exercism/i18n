# Instalação

A forma mais simples de instalar o PureScript é através do Node.js e do NPM.

Se ainda não tens o Node.js instalado no teu computador, podes transferi-lo do [site do Node.js](https://nodejs.org/). Assim que tiveres o Node.js a funcionar, introduz este comando no terminal para instalar o compilador PureScript e a ferramenta de build Spago:

    npm install --global purescript spago

Podes encontrar mais informações no [repositório do PureScript](https://github.com/purescript/purescript/blob/master/INSTALL.md).
