# Instruções

O problema das Oito Rainhas é uma pergunta clássica de entrevistas de programação. Felizmente, o Z3 torna-o fácil de resolver.
O problema é este: colocar 8 rainhas num tabuleiro de xadrez de modo a que duas rainhas não se possam capturar uma à outra. No xadrez, as rainhas movem-se qualquer número de casas numa única direção (para a frente, para trás, para a esquerda, para a direita, na diagonal). Escreve uma função que devolve uma lista de tuplos do Python com as posições das 8 rainhas.
