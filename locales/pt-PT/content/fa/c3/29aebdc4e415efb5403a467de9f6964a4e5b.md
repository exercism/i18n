# classes

As classes são um conceito central na [programação orientada a objetos][object-oriented-programming].
[Em Crystal, tudo é um objeto][everything-is-an-object], cada objeto tem um tipo e pode responder a alguns métodos.
As classes são moldes para criar objetos: fornecem valores iniciais para o estado, como variáveis, e implementações de comportamento, como métodos.
Os objetos são instâncias de uma classe que guardam todas as variáveis de instância e os seus estados.

## Definição de classe

Uma classe define-se com a palavra-chave `class`, seguida do nome da classe escrito em `UpperCamelCase`.

```crystal
class Account
end
```

## Criar uma instância

Para [criar uma instância de uma classe][new-initialize], chama o nome da classe com o método `new`.

```crystal
class Account
end

account = Account.new
```

No exemplo acima, a variável `account` é uma instância da classe `Account`.

Ao criar uma instância, um método especial chamado `initialize` funciona como construtor.
É chamado quando uma instância é criada.
O construtor permite-te definir o estado inicial da instância.
O método `initialize` pode receber argumentos, que são passados ao criar uma instância.

```crystal
class Account
  def initialize(number)
    5 + number # => 9
  end
end

Account.new(4)
```

~~~~exercism/note
O método `initialize` não pode devolver um valor manualmente; em vez disso, é o `new` que devolve a instância acabada de criar.

```crystal
class Account
  def initialize(number)
    5 + number
  end
end

Account.new(4)
# => #<Account:0x7f5dc33dcea0>
```
~~~~

## Métodos de instância

Um método de instância é um método que está disponível numa instância de uma classe e pode ser chamado nessa instância.
Os métodos de instância definem-se com a palavra-chave `def`, seguida do nome do método.
São definidos dentro da definição da classe.

```crystal
class Account
  def balance
    100
  end
end

account = Account.new
account.balance # => 100
```

## Variáveis de instância

[As variáveis de instância][instance-variable] são variáveis que estão disponíveis em todos os métodos da instância.
Para acederes a uma variável de instância, precisas de definir um método de instância.
Podem ser inicializadas no método `initialize`.
Definem-se com o prefixo `@`.

```crystal
class Account
  def initialize
    @balance = 100
  end

  def balance
    @balance
  end
end

account = Account.new
account.balance
# => 100
```

As variáveis de instância também podem ser definidas dentro da definição da classe.

```crystal
class Account
  @age = 0
end
```

### Variáveis de instância com inicialização

As variáveis de instância podem ser inicializadas com um argumento passado ao método `initialize`.
Como o Crystal não consegue inferir o tipo do argumento usado durante a inicialização, é preciso especificá-lo.
Se quiseres ler mais sobre isto, podes ler: [inferência de tipos][type-inference].
Para especificar o tipo da variável, podes usar o símbolo `:`, seguido do tipo.
Por exemplo, se quiseres criar uma variável de instância chamada `balance` do tipo `Int32`, podes fazer o seguinte: `@balance : Int32`.
Ou, se quiseres criar uma variável de instância chamada `raining` do tipo `Bool`, podes fazer o seguinte: `@raining : Bool`.

Há várias formas de fazer isto: ou declarar o argumento com o tipo no método `initialize` e depois atribuir esse argumento à variável de instância, como no exemplo seguinte:

```crystal
class Account
  def initialize(balance : Int32)
    @balance = balance
  end

  def balance
    @balance
  end
end

account = Account.new(1)
account_2 = Account.new(5)

account.balance
# => 1

account_2.balance
# => 5
```

Outra forma é declarar o tipo da variável de instância na definição da classe, na forma: `@<variable> : <Type>`, como no exemplo seguinte:

```crystal
class Weather

  @raining : Bool

  def initialize(raining)
    @raining = raining
  end

  def raining
    @raining
  end
end

weather = Weather.new(true)
weather.raining
# => true
```

## Modificar variáveis de instância

Os métodos podem modificar variáveis de instância.
Esses métodos podem ser chamados na instância da classe.
Quando um método modifica uma variável de instância, essa alteração só fica disponível na instância da classe onde o chamaste.

```crystal
class Account
  def initialize(balance : Int32)
    @balance = balance
  end

  def withdraw(amount)
    @balance -= amount
  end

  def balance
    @balance
  end
end

account = Account.new(10)
account_2 = Account.new(10)
account.balance
# => 10

account_2.balance
# => 10

account.withdraw(5)
account.balance
# => 5

account_2.balance
# => 10
```

## Métodos de classe

[Os métodos de classe][class-methods] são métodos definidos para uma classe, mas não para as suas instâncias.
Oferecem uma forma de criar métodos que não dependem do estado da instância.
Definem-se com a palavra-chave `def`, seguida de `self.<method name>`.
`self` é uma referência ao espaço de nomes a partir do qual o self está a ser chamado.
Neste caso, refere-se à classe `Account`.
Seria o mesmo que escrever `Account.`, mas `self.` é a forma preferida.

```crystal
class Account
  def self.balance
    100
  end
end

Account.balance
# => 100
```
