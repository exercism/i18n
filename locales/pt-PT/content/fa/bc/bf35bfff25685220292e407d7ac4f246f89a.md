# Anexo às instruções

Este é um bom exercício para experimentar literais de string não padrão e metaprogramação.

Podes encontrar uma breve introdução aos literais de string não padrão neste [artigo de blog](https://web.archive.org/web/20170625222109/https://iaindunning.com/blog/julia-unicode.html). Encontras um guia detalhado de metaprogramação no [manual](https://docs.julialang.org/en/v1/manual/metaprogramming/).

Podes expandir a tua solução ao adicionares a funcionalidade descrita abaixo.

O Bónus A exige apenas os conhecimentos básicos descritos no artigo de blog. O Bónus B exige um conhecimento consideravelmente mais aprofundado de metaprogramação em Julia.

## Bónus A
Implementa um literal de string que funciona como `ROT13` sobre a string:
```julia
R13"abcdefghijklmnopqrstuvwxyz" == "nopqrstuvwxyzabcdefghijklm"
```

## Bónus B
Implementa literais de string `R<i>`, `i = 0, ..., 26`, que deslocam a string para cada valor de `i`:
```julia
R0"Hello, World!" == "Hello, World!"
R4"Testing 1 2 3 testing" == "Xiwxmrk 1 2 3 xiwxmrk"
R13"abcdefghijklmnopqrstuvwxyz" == "nopqrstuvwxyzabcdefghijklm"
```
