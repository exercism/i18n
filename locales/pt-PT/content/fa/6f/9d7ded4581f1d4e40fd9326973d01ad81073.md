# Introdução

## Strings

Em Common Lisp, as strings são [vetores][concept-vectors] de [carateres][concept-characters]. Escrevem-se como carateres rodeados de aspas duplas (_por exemplo_, "Hello World!").

O predicado `stringp` devolve verdadeiro apenas se o valor dado for uma string.

As strings podem ser divididas em substrings com a função `subseq`, que recebe a string, um índice inicial e, opcionalmente, um índice final.
A indexação começa em zero.

```lisp
(subseq "Hello World" 1 5)   ; => "ello"
(subseq "skip to the end" 5) ; => "to the end"
```

As strings podem ser comparadas para verificar a igualdade com `string=`.
Se as maiúsculas e minúsculas dos carateres não importarem, pode usar-se `string-equal`.

```lisp
(string= "macaroni" "macaroni")      ; => T
(string= "macaroni" "MACARONI")      ; => NIL
(string-equal "macaroni" "MACARONI") ; => T
```

Operações como converter strings para maiúsculas, para minúsculas e capitalizá-las podem ser feitas com `string-upcase`, `string-downcase` e `string-capitalize`.

```lisp
(string-upcase "not too loud")                ; => "NOT TOO LOUD"
(string-downcase "YELL IT FROM THE ROOFTOPS") ; => "yell it from the rooftops"
(string-capitalize "practical COMMON LiSP")   ; => "Practical Common Lisp"
```
