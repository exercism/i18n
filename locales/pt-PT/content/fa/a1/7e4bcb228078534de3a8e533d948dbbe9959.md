# Introdução

Um número de vírgula flutuante é um número com zero ou mais algarismos depois do separador decimal. Por exemplo: `-2.4`, `0.1`, `3.14`, `5.`, `16.984025` e `1024.0`.

Tipos de vírgula flutuante diferentes podem armazenar quantidades diferentes de algarismos depois do separador de algarismos; a isto chama-se precisão.

O Go tem dois tipos de vírgula flutuante:

- `float32`: 32 bits (~6-9 algarismos de precisão).
- `float64`: 64 bits (~15-17 algarismos de precisão).
   Este é o tipo de vírgula flutuante predefinido.

Como se pode ver, os dois tipos podem armazenar um número diferente de algarismos.
Isto significa que tentar armazenar o PI num `float32` só vai guardar os primeiros 6 a 9 algarismos (sendo o último arredondado).

Por predefinição, o Go usa `float64` para os números de vírgula flutuante, a menos que o número de vírgula flutuante seja:

1. atribuído a uma variável com o tipo `float32`, ou
2. devolvido por uma função com tipo devolvido `float32`, ou
3. passado como argumento à função `float32()`.

O [pacote `math`] contém muitas funções matemáticas úteis.

[pacote `math`]: https://pkg.go.dev/math
