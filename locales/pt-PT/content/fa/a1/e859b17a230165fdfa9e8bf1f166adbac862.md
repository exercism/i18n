# Dicas

## Geral

- Todas as tarefas constroem texto num ciclo, por isso cada uma começa com `#FSTR` e termina com `.str`.
- Atribui o resultado de cada `+` de volta ao construtor: `script := script + ...`.

## 1. Repete uma deixa

- `1.upto!(times)` corre o ciclo o número certo de vezes. O valor que devolve não é preciso, por isso pode ir diretamente para uma variável que nunca é usada, ou então usa `times.times!`, que não devolve nada.
- Se não houver vezes nenhumas, não é preciso tratamento especial: o ciclo simplesmente não corre.

## 2. As iniciais do elenco

- `names.elt!` devolve cada nome; `[0]` obtém o primeiro caráter.
- Um `FSTR` aceita um `CHAR` diretamente, por isso não é preciso convertê-lo primeiro numa string.

## 3. Numera as linhas

- Dois iteradores num só ciclo, como no exercício anterior: `1.up!` para o número e `lines.elt!` para o texto.
- A nova linha vai *antes* de todas as linhas exceto a primeira. Testar o número é a forma mais fácil: `if number > 1 then ... end`.
- Um `FSTR` aceita o número diretamente, por isso `script + number + ". "` funciona sem conversão.

## 4. Grita uma linha

- `line.elt!` percorre uma string caráter a caráter.
- `.upper` não mexe em nada que não seja uma letra, por isso o espaço não precisa de tratamento especial.
