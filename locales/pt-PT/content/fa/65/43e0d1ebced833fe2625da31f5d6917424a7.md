# Para quem faz a manutenção

## Script auxiliar para criar testes de Fortran: create_fortran_test.py

Uma forma fácil de criar um teste de exercício é usar o script
`bin/create\_fortran\_test.py`

Usa este script para criar um ficheiro <exercise>\_test.f90 inicial que podes usar como modelo para o teu teste.
Normalmente, vais ter de substituir a função 'response' no ficheiro gerado pela chamada de função correta.

Repara também que o Fortran tem problemas com carateres especiais como `\n` e `\t`, por isso tem especial cuidado ao lidar com eles.

### Pré-requisitos

- CMake e compilador de Fortran a funcionar
- Python3.x (Podes fazê-lo funcionar com Python2, mas não fiz o
  esforço de o tornar compatível com versões anteriores)
- versão mais recente de https://github.com/exercism/problem-specifications.git
- git

### Fluxo de trabalho para criar um novo teste

- traz as alterações mais recentes de `exercism/problem-specifications`, por exemplo git clone git@github.com:exercism/problem-specifications.git
- cria um novo ramo para criar um novo exercício, por exemplo git checkout -b exercise-bob
- corre este script para o exemplo que queres criar
- copia `config/CMakeLists.txt` para o diretório do exercício (podes usar `bin/update-cmake-files` para isso)
- implementa um exercício que funcione
- corrige os potenciais testes problemáticos (ver, por exemplo, exercise/bob "Test 20" e "Test 24")
- garante que o comando `ctest` valida sem erros
- copia a tua solução para .meta/example.f90 e remove a implementação real do ficheiro do exercício, por exemplo bob.f90
- atualiza os diretórios .docs e .meta
  - cp ../problem-specifications/exercises/bob/description.md exercises/practice/bob/.docs/instructions.md
    - substitui "# Description" por "# Instructions"
  - preenche .meta/tests.toml manualmente (até existir uma forma automatizada)
  - preenche .meta/config.json manualmente (até existir uma forma automatizada)
    - Usa ../problem-specifications/exercises/bob/metadata.yml
- abre um pull request com as tuas alterações

Para o exemplo do bob:

```bash
$ python bin/create_fortran_test.py -j ../problem-specifications/main/exercises/bob/canonical-data.json -t exercises/practice/bob/bob_test.f90
Namespace(json='../problem-specifications/main/exercises/bob/canonical-data.json', target='exercises/practice/bob/bob_test.f90')
Wrote : exercises/practice/bob/bob_test.f90
$ cp config/CMakeLists.txt exercises/practice/bob/.
$ cd exercises/practice/bob
$ touch bob.f90
$ mkdir build
$ cd build
$ cmake ..
$ make
$ ctest -V
```

### Alterar `CMakeLists.txt`

Quando alterares o ficheiro do CMake, atualiza a cópia principal em `config/` e usa `bin/update-cmake-files` para a copiar para todos os diretórios dos exercícios.

## Solução

Quando tiveres uma solução, copia essa solução para o diretório ".meta" como "example.f90".

Talvez queiras deixar uma implementação esqueleto da função ou sub-rotina que ajude o estudante e deixar o ficheiro com o nome do exercício no diretório do exercício.
