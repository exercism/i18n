# Syllabus - O primeiro exercício

O primeiro exercício deve abordar o conceito `basics` e não deve ter pré-requisitos.
Deve fornecer apenas a informação suficiente para que o estudante consiga resolver o exercício em questão.

Muitos percursos já implementaram um exercício que aborda `basics`.
Para te familiarizares com o que costuma ser ensinado num exercício destes, recomendamos que te inscrevas em alguns percursos diferentes que tenham o Modo de Aprendizagem e que resolvas o primeiro exercício de conceito.

Cada linguagem é diferente e podes descobrir que precisas de introduzir mais do que outros percursos, ou menos.
Por exemplo, se precisares de compilar um programa para que este funcione, isso é algo que deves mencionar na introdução do exercício.

Outras coisas que são frequentemente abordadas no exercício `basics`:

- definições de funções ou métodos
- chamar funções
- passar argumentos a funções
- atribuir um valor a um nome (variáveis e/ou constantes)

Usa o menor número possível de tipos de dados.
Se conseguires, usa apenas números inteiros, pois a sua notação é igual na maioria das linguagens e será bem conhecida por praticamente toda a gente.

Se existir um percurso para uma linguagem semelhante à tua, podes verificar se consegues fazer um fork do exercício deles e usá-lo como ponto de partida.

Sê conciso: não queres sobrecarregar os estudantes com informação.
A introdução deve explicar _o suficiente_ para que o estudante consiga olhar para o código e identificar as diferentes partes.
Não precisam de compreender nada disso em profundidade, mas também não devem ficar sem saber o que é cada coisa.

O estudante só deve precisar de _usar_ ativamente um ou dois conceitos.
