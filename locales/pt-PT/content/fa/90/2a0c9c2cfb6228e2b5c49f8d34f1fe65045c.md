# Introdução

Um registo é uma coleção de campos (que podem ser de tipos diferentes) que estão relacionados entre si. Para definir um registo usa-se a palavra-chave `type`. Os campos de um registo definem-se entre os caracteres `{` e `}`, e cada campo tem um nome _e_ um tipo. Para criar um registo, especifica os nomes dos campos e atribui-lhes um valor entre os caracteres `{` e `}`. Todos os campos têm de ter um valor atribuído quando se cria um registo. Os valores dos campos de uma instância de um registo podem ser acedidos com a notação de ponto.

Ao definir/criar um registo, cada campo tem de estar numa linha separada ou, se estiverem na mesma linha, separados por pontos e vírgulas (`;`).

```fsharp
// Define a record
type Address =
    { Street: string
      HouseNumber: int }

// Create a record
let oldAddress: Address =
    { Street = "Main Street"
      HouseNumber = 17 }

// Single-line alternative
type ConciseAddress = { Street: string; HouseNumber: int }
let conciseAddress: ConciseAddress = { Street = "Main Street"; HouseNumber = 17 }
```

Como os registos são imutáveis, uma vez construído um registo, os valores dos seus campos nunca podem mudar. Se quiseres alterar os valores de um registo, a palavra-chave `with` permite-te criar uma cópia de um registo existente, mas com valores novos para um ou mais campos.

```fsharp
// Copy the old address but change the house number
let newAddress: Address = { oldAddress with HouseNumber = 86 }
newAddress.Street      // => "Main Street"
newAddress.HouseNumber // => 86
```

Os registos têm _igualdade estrutural_, o que significa que duas instâncias do mesmo registo com valores idênticos são equivalentes.

Além de poderes usar a notação de ponto para aceder aos campos de um registo, os registos também podem ser _desconstruídos_ em ligações e em correspondência de padrões:

```fsharp
let myAddress: Address = { Street = "Broadway"; HouseNumber = 123 }
let { Street = myStreet; HouseNumber = myHouseNumber } = myAddress

match myAddress with
| { HouseNumber = 1 } -> printfn "First house"
| { HouseNumber = houseNumber; Street = street } -> printfn "House number %d on %s" houseNumber street
// => "House number 123 on Broadway
```
