# Instruções

Uns programadores "outros" têm estado a trabalhar no projeto do carro telecomandado [exercise:csharp/remote-control-competition](). Chamaram-te para vires limpar o código.

## 1. Separa as responsabilidades entre o próprio carro e o sistema de telemetria

Refatora a classe `RemoteControlCar` para separares os métodos e as propriedades de telemetria, acedidos através de uma propriedade `Telemetry`.

```csharp
var car = new RemoteControlCar();
car.Telemetry.Calibrate();
car.Telemetry.SelfTest();
car.Telemetry.ShowSponsor("Walker Industries Inc.");
car.CurrentSponsor
// => "Walker Industries Inc."
car.Telemetry.SetSpeed(100, "cps");
car.GetSpeed()
// => "100 centimeters per second"
```

## 2. Impede que outro código crie demasiadas dependências do tipo Telemetry

Garante que a instância `Telemetry` não pode ser criada fora do âmbito do carro.

## 3. Impede que outro código crie dependências da estrutura Speed

Garante que a estrutura `Speed` não pode ser usada fora do âmbito da classe `RemoteControlCar`.

## 4. Impede que outro código crie dependências da enumeração SpeedUnits

Garante que a enumeração `SpeedUnits` não pode ser usada fora do âmbito da classe `RemoteControlCar`.
