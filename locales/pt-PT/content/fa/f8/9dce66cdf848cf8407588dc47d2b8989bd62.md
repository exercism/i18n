# Ajuda

Se estiveres com dificuldades, podes recorrer a um destes recursos para obter ajuda:

- [Pharo Syntax Cheatsheet](http://files.pharo.org/media/pharoCheatSheet.pdf)
- [Pharo Community Resources](http://pharo.org/community) (inclui uma ligação para o chat do Discord)
- [/r/pharo](https://www.reddit.com/r/pharo) é o subreddit do Pharo.
- Podes usar o [StackOverflow](http://stackoverflow.com/questions/tagged/pharo) para procurar o teu problema e ver se já obtiveste resposta. Também podes fazer perguntas e responder a outras.
