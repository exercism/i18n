# Instruções

A tua amiga Leticia trabalha no serviço de Achados e Perdidos de uma estação de metro.

Cada objeto encontrado é adicionado a uma nova entrada numa lista de itens do dia.
No final do mês, qualquer item que não tenha sido reclamado é transferido para um depósito numa caixa etiquetada com a data em que foi encontrado.
Tudo isto é feito em papel, por isso às vezes as coisas tornam-se complicadas!

## 1. Cria uma entrada para cada item

A primeira coisa que precisas de fazer é organizar todos os itens, para que possam ser consultados mais facilmente.
Cada item é identificado no armazenamento pelo seu ID, por uma descrição, pela data em que foi encontrado e por um número variável de categorias.

Define uma função `create_item_entry` que não devolve nenhum valor e que insere uma nova entrada para um item num local de memória.
Esta função pode receber qualquer número de parâmetros; os primeiros seis são sempre:

1. O endereço de um local de memória onde a entrada deve ser armazenada.
2. O ID do item, como um inteiro sem sinal de 64 bits.
3. O endereço de uma string com a descrição do item.
4. O dia em que o item foi encontrado, como um inteiro sem sinal de 64 bits.
5. O mês em que o item foi encontrado, como um inteiro sem sinal de 64 bits.
6. O número de categorias do item, como um inteiro sem sinal de 64 bits.

Cada parâmetro seguinte é o endereço de uma string com uma das categorias.

Os valores devem ser armazenados no local de memória fornecido pela mesma ordem dos argumentos: ID, descrição, dia, mês, número de categorias e cada categoria por ordem.

## 2. Reserva espaço para uma lista mensal de itens

É trabalhoso procurar itens em tantas listas diferentes.
Por isso, decides organizar tudo numa única lista para cada mês.
Esta lista é implementada como um array.

Define a função `create_monthly_list`, que aloca espaço de memória para um array e devolve o endereço desse local de memória.
Recebe como parâmetros:

1. A capacidade do array em bytes, como um inteiro sem sinal de 64 bits.
2. Uma função de alocação.

A função de alocação recebe como parâmetro um inteiro sem sinal de 64 bits correspondente ao tamanho de memória a alocar, em bytes, e devolve o endereço do espaço alocado.

Repara que o espaço alocado tem um valor _indefinido_, por isso todos os bytes desse espaço devem ser limpos, ou seja, o seu valor deve ser definido como `0`.

## 3. Insere um item na lista mensal

Todos os dias, cada item encontrado deve ser inserido na lista mensal.

Define a função `insert_found_item`, que não devolve nenhum valor e recebe como parâmetros:

1. O endereço de um espaço de memória onde se encontra a lista mensal.
2. O número atual de entradas já armazenadas na lista, como um inteiro sem sinal de 64 bits.
3. Uma nova entrada a adicionar à lista.

Podes considerar que a nova entrada cabe sempre na lista e que cada entrada na lista ocupa 120 bytes de espaço.

## 4. Imprime um item

Procurar uma entrada específica seria muito mais fácil se a Leticia a pudesse ver impressa no ecrã.

Define a função `print_item`, que recebe como parâmetros:

1. O endereço de um buffer onde pode ser armazenada uma string introdutória ASCII terminada em NUL.
2. O endereço de um espaço de memória onde se encontra a lista mensal.
3. O índice da entrada no array correspondente ao item que deve ser impresso, como um inteiro sem sinal de 64 bits.
4. Uma função de impressão.

Esta função não devolve nenhum valor e deve chamar a função de impressão com os seguintes argumentos:

1. O endereço de um local de memória onde está armazenada a string introdutória; ou `0` (como um inteiro de 64 bits) se nenhuma string for passada.
2. O índice da entrada no array correspondente ao item que deve ser impresso, como um inteiro sem sinal de 64 bits.
3. O ID do item, como um inteiro sem sinal de 64 bits.
4. O endereço de uma string com a descrição do item.
5. O dia em que o item foi encontrado, como um inteiro sem sinal de 64 bits.
6. O mês em que o item foi encontrado, como um inteiro sem sinal de 64 bits.
7. O número de categorias do item, como um inteiro sem sinal de 64 bits.
8. O endereço da primeira string de categoria.

A string introdutória é opcional.
Se for usada na função de impressão, esta string deve ser terminada em NUL (terminar em `0`) e ter no máximo 50 carateres, já a contar com o terminador NUL.
Caso contrário, deve ser passado o valor `0` à função de impressão.

Podes considerar que cada item na lista ocupa 120 bytes de espaço.
