# marcador de posição

## Dicas sobre o `jq`

Este exercício consiste em receber um objeto e transformá-lo num objeto novo.
Há algumas funções incorporadas que te podem ajudar:

- [`to_entries`][x_entries]
  - esta função recebe um objeto
  - devolve um _array_, em que cada elemento é um objeto `{"key": "K", "value": V}`
    - cada `K` é uma chave do objeto de entrada
    - cada `V` é o valor correspondente a `K`.
- [`from_entries`][x_entries]
  - a operação inversa
  - recebe um array de objetos `{"key": K, "value": V}` e constrói um objeto

Um exemplo:

```sh
jq -n '
    {
        "username": "glennj",
        "tracks": ["bash", "awk", "jq"],
        "reputation": 123
    }
    | to_entries
'
```

produz

```json
[
  {
    "key": "username",
    "value": "glennj"
  },
  {
    "key": "tracks",
    "value": ["bash", "awk", "jq"]
  },
  {
    "key": "reputation",
    "value": 123
  }
]
```

[x_entries]: https://jqlang.org/manual/#to_entries-from_entries-with_entries
