# Dicas

## Geral

- O namespace `clojure.string` tem muitas [funções úteis de manipulação de strings][string-ns].

## 1. Obter a mensagem de uma linha de registo

- Podes usar a função [`split`][split] para dividir uma string com base numa expressão regular.
- Podes usar a função [`trim`][trim] para remover espaços em branco das extremidades de uma string.

## 2. Obter o nível de registo de uma linha de registo

- Podes converter uma `string` em minúsculas com [`lower-case`][lower-case].

## 3. Reformatar uma linha de registo

- Podes usar a função [`str`][str] para concatenar strings.

[lower-case]: https://clojuredocs.org/clojure.string/lower-case
[split]: https://clojuredocs.org/clojure.string/split
[str]: https://clojuredocs.org/clojure.core/str
[string-ns]: https://clojuredocs.org/clojure.string
[trim]: https://clojuredocs.org/clojure.string/trim
