# Dicas

## Geral

- Existem três [operadores Boolean][boolean-operators] para trabalhar com valores Boolean escalares.
- É possível combinar vários operadores numa única expressão.

## 1. Verifica se é possível fazer um ataque rápido

- O operador lógico de negação (`!`) pode ser colocado antes de uma expressão para negar o seu valor.

## 2. Verifica se é possível espiar o grupo

- Os operadores Boolean são normalmente usados para avaliar se duas ou mais expressões são `TRUE` ou não`!`

## 3. Verifica se é possível sinalizar o prisioneiro

- Os operadores Boolean executam-se pela ordem da sua precedência (da mais alta para a mais baixa): `!`, `&&`, `||`.
- Em geral, recomenda-se o uso de parênteses para tornar a tua intenção mais clara.

## 4. Verifica se é possível libertar o prisioneiro

- Os operadores Boolean executam-se pela ordem da sua precedência (da mais alta para a mais baixa): `!`, `&&`, `||`.
- Em geral, recomenda-se o uso de parênteses para tornar a tua intenção mais clara.
