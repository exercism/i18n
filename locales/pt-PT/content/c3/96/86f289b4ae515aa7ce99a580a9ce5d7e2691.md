# Instruções

Converte um número, representado como uma sequência de algarismos numa base, para qualquer outra base.

Implementa a conversão de bases de forma genérica. Dado um número na base **a**, representado como uma sequência de algarismos, converte-o para a base **b**.

## Nota

- Tenta implementar a conversão tu próprio.
  Não uses outra coisa para fazer a conversão por ti.

## Sobre a [notação posicional](https://en.wikipedia.org/wiki/Positional_notation)

Na notação posicional, um número na base **b** pode ser entendido como uma combinação linear de potências de **b**.

O número 42, *na base 10*, significa:

(4 * 10^1) + (2 * 10^0)

O número 101010, *na base 2*, significa:

(1 * 2^5) + (0 * 2^4) + (1 * 2^3) + (0 * 2^2) + (1 * 2^1) + (0 * 2^0)

O número 1120, *na base 3*, significa:

(1 * 3^3) + (1 * 3^2) + (2 * 3^1) + (0 * 3^0)

Acho que já percebeste a ideia!

*Sim. Esses três números acima são exatamente os mesmos. Parabéns!*
