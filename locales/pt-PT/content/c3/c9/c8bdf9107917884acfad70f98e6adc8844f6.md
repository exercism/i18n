# Introdução

O atributo Flags permite que os valores definidos numa união discriminada sejam representados como posições de bits (ou seja, flags).
Enquanto flags, esses valores podem ser combinados, o que permite representar várias condições Boolean num único valor.

```fsharp
[<Flags>]
type PhoneFeatures =
| Call = 1
| Text = 2
```

```fsharp
[<Flags>]
type PhoneFeaturesBinary =
| Call = 0b00000001
| Text = 0b00000010
```

Definir uma flag pode ser feito com o operador OR bit a bit (`|||`); remover uma flag pode ser feito com uma combinação do operador AND bit a bit (`&&&`) e do operador de negação bit a bit (`~~~`).
Já verificar o estado de uma flag pode ser feito com o operador AND bit a bit, mas também podes usar o método `HasFlag()`.

```fsharp
let features = PhoneFeatures.Call

// Set the Text flag
let moreFeatures = features ||| PhoneFeatures.Text

moreFeatures.HasFlag(PhoneFeatures.Call) // => true
moreFeatures.HasFlag(PhoneFeatures.Text) // => true
```
