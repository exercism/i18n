# Instruções

Vais escrever algum código para gerir uma lista de linguagens de programação para aprender.
A lista vai estar guardada num array chamado `@LanguageList::Languages`.

## 1. Adicionar uma linguagem ao array @Languages

Modifica a sub-rotina `LanguageList::add_language`, que recebe o nome de uma linguagem como argumento, para adicionar essa linguagem ao fim do array `@LanguageList::Languages`.

## 2. Remover uma linguagem do array @Languages

Modifica a sub-rotina `LanguageList::remove_language` para remover a última linguagem do array `@LanguageList::Languages`.

## 3. Obter a primeira linguagem do array @Languages

Modifica a sub-rotina `LanguageList::first_language` para devolver a primeira linguagem do array `@LanguageList::Languages`.

## 4. Obter a última linguagem do array @Languages

Modifica a sub-rotina `LanguageList::last_language` para devolver a última linguagem do array `@LanguageList::Languages`.

## 5. Obter uma fatia de linguagens do array @Languages

Modifica a sub-rotina `LanguageList::get_languages`, que recebe uma lista de números correspondentes aos elementos pretendidos, para devolver uma fatia do array `@LanguageList::Languages`.

## 6. Verificar se uma linguagem existe no array @Languages

Modifica a sub-rotina `LanguageList::has_language`, que recebe o nome de uma linguagem como argumento, para devolver um valor verdadeiro ou falso que indica se a linguagem existe no array `@LanguageList::Languages`.
