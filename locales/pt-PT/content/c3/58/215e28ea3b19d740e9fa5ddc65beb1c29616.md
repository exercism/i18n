# Testes

## Correr os testes

1. Obtém um exercício:

    ```bash
    $ exercism download -track=kotlin --exercise=hello-world
    ```

2. Muda para o diretório do exercício:

    ```bash
    $ cd <path_to_exercise_directory>
    ```

3. Corre os testes:

    ```bash
    $ ./gradlew test
    ```

Na maioria dos exercícios, só o primeiro teste é executado por predefinição.  
Os restantes testes estão anotados com `@Ignore` para serem ignorados.  
À medida que resolves cada teste, remove o `@Ignore` do seguinte para progredires.

Esta é uma prática comum no desenvolvimento orientado por testes (ou TDD, para abreviar).
Serve para garantir que trabalhas num problema de cada vez.
