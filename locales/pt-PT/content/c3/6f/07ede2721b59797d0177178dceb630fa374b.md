# Instalação

## Instalar a CLI do Clojure
O Clojure disponibiliza ferramentas de linha de comandos que podes usar para iniciar um REPL do Clojure, usar bibliotecas de Clojure e Java e iniciar programas em Clojure.

Se precisares de instalar o Java, recomendamos o [Adoptium Temurin 17](https://adoptium.net/).

### Linux
Certifica-te de que tens as seguintes dependências instaladas: `bash`, `curl`, `rlwrap` e `Java`.
Podes instalar o Clojure de uma destas duas formas:

1. LinuxBrew - requer o [Homebrew](https://brew.sh/)

```bash
brew install clojure/tools/clojure
```

2. Instalador por script

```bash
curl -O https://download.clojure.org/install/linux-install-1.11.1.1347.sh
chmod +x linux-install-1.11.1.1347.sh
sudo ./linux-install-1.11.1.1347.sh
```

### Homebrew para Mac OS X
Instala as ferramentas de linha de comandos com o brew a partir do tap [clojure/tools](https://github.com/clojure/homebrew-tools):

```bash
brew install clojure/tools/clojure
```

#### Java

Qualquer distribuição de Java serve. Se for preciso, podes instalar o Temurin com o brew:

```bash
brew tap homebrew/cask-versions
brew install --cask temurin17
```

### Windows

O Clojure no Windows melhorou bastante recentemente. Costumávamos recomendar o WSL2, que funciona muito bem, mas agora existe um instalador PowerShell. Neste momento, o Clojure no Windows está em estado alpha; consulta [clj-on-windows](https://github.com/clojure/tools.deps.alpha/wiki/clj-on-Windows#known-issues) para conhecer os problemas conhecidos.

Certifica-te de que o Java está instalado e de que a variável de ambiente `JAVA_HOME` está definida, e corre:

```powershell
iwr -useb download.clojure.org/install/win-install-1.11.1.1165.ps1 | iex
```

Outra forma de instalar o Clojure no Windows é com o gestor de pacotes [Scoop](https://scoop.sh/). Para instalar o Scoop, abre o PowerShell e executa estes dois comandos, um a seguir ao outro:

 ```sh
 iwr -useb get.scoop.sh | iex
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser -Force
```

Para instalar o Clojure com o Scoop, tens de adicionar primeiro dois buckets importantes:

```sh
# if you don't have git version control system installed
# it is required for adding new external buckets to your scoop installer
# you can skip this step otherwise
scoop install git

# add scoop bucket for Java 
scoop bucket add java

# add scoop bucket for clojure build
scoop bucket add scoop-clojure https://github.com/littleli/scoop-clojure
```

Agora estamos prontos para instalar o Java e o Clojure com os seguintes comandos:

```sh
# install Java runtime and compiler
scoop install adoptopenjdk-lts-hotspot

# install official clojure tools
scoop install clojure

# update to the newest version
scoop update clojure
```

Depois de executares os passos acima com sucesso, deves conseguir correr o Clojure com o seguinte:

```sh
clj
```

## Instalar o Leiningen (opcional)

Embora já não seja necessário, continuamos a suportar a ferramenta de gestão de projetos completa [Leiningen](https://leiningen.org/).
Oferece uma grande variedade de tarefas úteis, como testes convenientes, compilações e um REPL melhorado.

1. Descarrega o [script lein](https://raw.githubusercontent.com/technomancy/leiningen/stable/bin/lein) ou o [lein.bat](https://raw.githubusercontent.com/technomancy/leiningen/stable/bin/lein.bat) (Windows)
2. Coloca-o no teu `$PATH`, onde a tua shell o consiga encontrar (por exemplo, `/usr/local/bin/`)
3. Torna-o executável (`sudo chmod a+x /usr/local/bin/lein`)
4. Corre `lein`.
