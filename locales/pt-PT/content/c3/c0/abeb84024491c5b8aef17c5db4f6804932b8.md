# Instruções

Usa o Crivo de Eratóstenes para encontrar todos os números primos de 2 até um determinado número.

O Crivo de Eratóstenes é um algoritmo simples e antigo para encontrar todos os números primos até um determinado limite.
Fá-lo marcando iterativamente como compostos (ou seja, não primos) os múltiplos de cada primo, começando pelos múltiplos de 2.
Não usa qualquer operação de divisão nem de resto.

Cria o teu intervalo, começando em dois e continuando até ao limite indicado, inclusive.
(ou seja, [2, limite])

O algoritmo consiste em repetir o seguinte vezes sem conta:

- pega no próximo número não marcado disponível na tua lista (é primo)
- marca todos os múltiplos desse número (não são primos)

Repete até teres processado todos os números do teu intervalo.

Quando o algoritmo termina, todos os números da lista que não foram marcados são primos.

[Este artigo da Wikipédia][eratosthenes] tem um gráfico útil que explica o algoritmo.

Repara que este é um algoritmo muito específico, e os testes não verificam se implementaste o algoritmo, apenas se chegaste à lista correta de números primos.
Um bom primeiro teste é verificar se não usas operações de divisão nem de resto (div, /, mod ou %, dependendo da linguagem).

[eratosthenes]: https://en.wikipedia.org/wiki/Sieve_of_Eratosthenes
