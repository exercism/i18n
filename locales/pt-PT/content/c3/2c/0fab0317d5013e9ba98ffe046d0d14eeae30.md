# Introdução

O tipo `char` do F# é um valor de 16 bits que representa os componentes de texto endereçáveis mais pequenos, imutável por predefinição.

Os `char`s podem ser definidos como literais com plicas:

```fsharp
let ch = 'A'
// => val ch: char = 'A'
```

Uma string é uma sequência de chars.

Podes obter um `char` individual de uma string com indexação (a começar em zero):

```fsharp
"Exercism"[4] //  =>  'c'
```

Iterar sobre uma string devolve um `char` a cada passo.

O exemplo seguinte usa uma função de ordem superior e uma função anónima, por conveniência.
Estes conceitos serão abordados como deve ser mais à frente no programa, mas por agora são essencialmente uma forma concisa de escrever um ciclo sobre os carateres de uma string.

```fsharp
Seq.map (fun c -> c, int c) "F#"  //  =>  [('F', 70); ('#', 35)]
```

Como mostrado acima, um `char` pode ser convertido no seu valor `int`.
Isto também funciona (*pelo menos algumas vezes*) para outros sistemas de escrita:

```fsharp
Seq.map (fun c -> c, int c) "東京"  //  =>  [('東', 26481); ('京', 20140)]
```

O Int16 subjacente é usado ao comparar carateres:

```fsharp
'A' < 'D'  // =>  true
```

Além disso, um `int` pode ser convertido em `char`:

```fsharp
char 77  // => 'M'
```

A biblioteca `System.Char` contém o conjunto completo de métodos esperados numa linguagem .NET, como as conversões para maiúsculas/minúsculas:

```fsharp
'a' |> System.Char.ToUpper  // =>  'A'

'Q' |> System.Char.ToLower  // =>  'q'
```
