# Arrays

Um **array**, ou _vetor_, guarda uma linha de valores, todos do mesmo tipo, por ordem.

O tipo escreve-se `ARRAY{T}`, em que `T` é aquilo que ele guarda. Um array de
strings é `ARRAY{STR}`; um array de números inteiros é `ARRAY{INT}`.

```sather
   row : ARRAY{STR} := |"Mia", "Ana", "Ben"|;
```

Os valores entre as duas marcas `|` são o **literal de array**. O Sather
calcula o tamanho a partir do número de valores que lá estão.

## Obter um valor

Os parênteses retos indicam a posição:

```sather
row[0]      -- "Mia"
row[1]      -- "Ana"
row[2]      -- "Ben"
```

A contagem começa em **zero**, não em um. Por isso o primeiro valor está em
`0`, e o último de uma linha de três está em `2`.

## Quantos?

`.size` é quantos valores o array guarda.

```sather
row.size    -- 3
```

Como a contagem começa em zero, a última posição é sempre `.size - 1`:

```sather
row[row.size - 1]     -- "Ben"
```

Pedir uma posição que não existe — `row[3]`, ou `row[-1]` — é um erro que o
Sather não deteta por ti, por isso vale a pena escrever `.size - 1` em vez de
contar os valores a olho.

## Percorrer um array

Um array e um ciclo combinam bem. Faz subir uma variável pelas posições e
usa-a para aceder a cada valor:

```sather
   total ::= 0;
   i ::= 0;
   loop
      until!(i >= scores.size);
      total := total + scores[i];
      i := i + 1;
   end;
```
