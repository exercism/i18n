# Testes

## Resumo
 
- Vai para o diretório do problema (por exemplo, `~/Exercism/hello-world`).
- Inicia uma sessão de `jconsole` num terminal.
- Carrega o ficheiro da tua solução (por exemplo, `load 'hello-world.ijs'`).
- Carrega o framework de testes unitários escrevendo `load  'general/unittest'`.
- Testa a tua solução escrevendo `unittest 'test.ijs'`.
<br></br>
- Em alternativa, é possível correr os testes numa única linha assim: `jconsole -js "load 'hello-world.ijs'" "echo unittest 'test.ijs'" "exit 0"`.

## Sessão do jconsole

Espera-se que a configuração dos testes do percurso seja o mais simples possível.
Se estiveres a trabalhar num exercício, por exemplo `hamming.ijs`, eis como o trabalho deve decorrer.
Edita `hamming.ijs` e escreve a tua solução.
Constrói a solução de forma interativa, começando por escrever.

```j
NB. your j terminal binary may be ijconsole (eg. on Debian)
jconsole 'hamming.ijs' NB. start a J console session with definitions loaded hamming.ijs
```

Depois, de dentro da consola J, recarrega escrevendo

```j
load 'hamming.ijs'
```

O passo seguinte é carregar o framework de testes unitários escrevendo

```j
load 'general/unittest'
```

Para correr os testes, depois de carregares a tua solução, escreve

```j
unittest 'test.ijs'
```

E depois observa os resultados.

## Linha de comandos

Podes correr os testes com um comando numa única linha no terminal, usando a opção -js:

```j
jconsole  -js "load 'hamming.ijs'" "echo unittest 'test.ijs'" "exit 0"
```
em que cada argumento representa um comando que será executado sequencialmente.
