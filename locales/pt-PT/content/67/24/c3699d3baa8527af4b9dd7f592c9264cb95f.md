# Sobre

Crystal é uma linguagem de programação compilada e orientada a objetos.
Alguns dos objetivos da linguagem são:

- Sintaxe inspirada em Ruby.

- Verificação estática de tipos, mas sem teres de especificar o tipo de variáveis ou argumentos de métodos.

- Poder chamar código C ao escrever ligações para ele em Crystal.

- Ter avaliação e geração de código em tempo de compilação, para evitar código repetitivo.

- Compilar para código nativo eficiente.
