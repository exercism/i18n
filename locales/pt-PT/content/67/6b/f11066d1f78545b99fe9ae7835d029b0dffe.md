# Introdução

Um dicionário (`dict`) em Python é uma estrutura de dados que associa _chaves_ [hashable][term-hashable] a _valores_ e é conhecido noutras linguagens de programação como tabela de hash redimensionável, hashmap ou [array associativo][associative-array].
Os dicionários são o único [tipo de mapeamento][mapping-types-dict] incorporado do Python.


As `keys` têm de ser hashable e únicas em todo o dicionário.
Os tipos de chave podem incluir `number`s, `str`s ou `tuple`s (de valores _imutáveis_).
Não podem conter estruturas de dados _mutáveis_, como `list`s, `dict`s ou `set`s.
A partir do Python 3.7, está garantido que a ordem das chaves de um `dict` é a ordem pela qual as entradas são inseridas.

Os `values` podem ser de qualquer tipo de dados ou estrutura.
 Os valores também podem estar aninhados _arbitrariamente_, pelo que podem incluir listas de listas, subdicionários e outras estruturas de dados personalizadas ou compostas.

Dada uma `key`, os dicionários conseguem obter um `value` em tempo constante (em média), _independentemente do número de entradas_.
Em comparação com a procura de um valor numa `list` ou num `array` (_sem saber a posição do `index`_), um `dict` usa significativamente mais memória, mas a obtenção é muito mais rápida.

Os dicionários são especialmente úteis em cenários em que a coleção de itens é grande e tem de ser acedida e atualizada com frequência.
