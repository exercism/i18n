# Sobre

O Elm é uma linguagem totalmente funcional, por isso não há instruções, apenas expressões, e as funções são sempre uma única expressão.

Isto incentiva funções pequenas e simples e é, em geral, uma coisa boa, mas por vezes as funções são inevitavelmente mais complexas, e precisamos de uma forma de garantir que podem ser escritas de forma elegante.

É aqui que entram as expressões `let`. Têm duas partes: uma secção `let`, onde podes criar tantas definições quantas precisares, e depois uma secção `in`, que é uma única expressão que pode usar essas definições.

Em termos de computação, `let` cria um âmbito que é local à expressão em `in`.

A expressão `let` é útil em algumas situações:

- Para simplificar expressões
- Para dar nome aos resultados de expressões intermédias
- Para dividir uma expressão em partes mais pequenas, se estiver a ficar grande

Podes fazer a maior parte das coisas dentro de uma expressão `let`, incluindo desestruturação, mas as seguintes não são permitidas:

- Tipos personalizados
- Alias de tipos
- Sombreamento de nomes (não podes redefinir ou reutilizar um nome que já está no âmbito)

## Simplificar expressões

Esta expressão soma os cubos de 3 números, mas é difícil de ler, e seria fácil que o cálculo fosse diferente para cada número.

```elm
(a * a * a) + (b * b * b) + (c * c * c)
```

Podemos definir uma função `cube` numa expressão `let` para tornar o cálculo mais simples, mais expressivo e mais seguro. Esta função podia ter uma anotação de tipo, mas em código Elm idiomático isso é relativamente raro.

```elm
let
  cube x = x * x * x
in
  cube a + cube b + cube c
```

## Dar nome aos resultados de expressões intermédias

Este código define sideArea e topArea para tornar o cálculo mais simples e mais expressivo.

```elm
cylinderArea : Float -> Float -> Float
cylinderArea radius height =
    let
        sideArea = 2 * pi * radius * height
        topArea = pi * radius ^2
    in
        sideArea + 2 * topArea
```

## Dividir uma expressão grande

Este código cria um padrão inicial para o [Jogo da Vida](https://playgameoflife.com/) (um exercício de exemplo comum em programação).

Não é importante perceber exatamente como funciona, mas esperemos que seja óbvio que seria muito grande se fosse escrito como uma única expressão, sem `let`.

```elm
beginWithPattern : Size -> Padding -> Pattern -> GameOfLife
beginWithPattern minimumSize padding pattern =
    let
        size = calculateSize minimumSize padding pattern

        center = Size.center size

        centeredPattern = Pattern.centerAt center pattern

        dimensions = { width = size, height = size }

        deadCells = Matrix.create dimensions Dead
    in
    GameOfLife (bringPatternToLife deadCells centeredPattern)
```
