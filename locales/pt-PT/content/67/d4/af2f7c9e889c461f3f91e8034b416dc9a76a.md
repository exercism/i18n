# Introdução

Muitos tipos de membros de struct e class (sendo os campos a principal exceção) podem usar a sintaxe de membro com corpo de expressão. Definir um membro com uma expressão produz, muitas vezes, código mais conciso e legível do que os blocos e instruções tradicionais.

Os métodos e as propriedades só de leitura estão entre os membros que podem ser definidos com corpos de expressão.

```csharp
public int Times3(int input) => input * 3;

public int Interesting => 1729;
```
