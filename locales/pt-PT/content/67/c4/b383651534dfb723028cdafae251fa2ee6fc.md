# Instruções

Aprende o básico sobre tabelas internas de ABAP.

A tua classe tem uma tabela interna chamada `initial_data`. Tem três colunas: `GROUP`, `NUMBER` e `DESCRIPTION`.

```abap
TYPES group TYPE c LENGTH 1.
TYPES: BEGIN OF initial_type,
         group       TYPE group,
         number      TYPE i,
         description TYPE string,
       END OF initial_type,
       initial_data TYPE STANDARD TABLE OF initial_type WITH EMPTY KEY.
```

## Passo 1

A tua primeira tarefa é completar o método `fill_itab` e inserir 6 registos nesta tabela com os seguintes valores:

| GROUP | NUMBER | DESCRIPTION |
| --- | ----------- | ----------- |
| A | 10 | Group A-2 |
| B | 5 | Group B |
| A | 6 | Group A-1 |
| C | 22 | Group C-1 |
| A | 13 | Group A-3 |
| C | 500 | Group C-2 |

## Passo 2

De seguida, implementa o método `add_to_itab` para adicionar um registo ao fim da tabela interna com o seguinte valor:

| GROUP | NUMBER | DESCRIPTION |
| --- | ----------- | ----------- |
| A | 19 | Group A-4 |

## Passo 3

Agora, ordena a tabela interna no método `sort_itab` com a coluna `GROUP` por ordem alfabética e a coluna `NUMBER` por ordem descendente.

## Passo 4

No método `search_itab`, procura na tabela ordenada e devolve o índice do registo que tem o valor 6 na coluna `NUMBER`.
