# Como usar Markdown na mentoria

Podes usar Markdown nos teus comentários de mentoria no GitHub.
Isto permite-te incorporar excertos de código, adicionar cabeçalhos, negrito, itálico, listas, etc., e citar frases anteriores.

Também permitimos alguns elementos de "Markdown com sabor do GitHub" no Exercism, mais concretamente realce de sintaxe, tabelas e texto rasurado.

Se não estás familiarizado com o Markdown nem com os extras do GitHub, recomendamos que leias o [guia de Markdown do GitHub](https://guides.github.com/features/mastering-markdown/).
