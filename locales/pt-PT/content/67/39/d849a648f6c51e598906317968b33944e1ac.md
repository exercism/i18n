# Dicas

## 1. Determina quanto tempo demora a preparar um pedido

- Podes usar um [ciclo for-in][for-in-loops] para ver uma bebida de cada vez.
- Podes usar uma instrução `switch` para devolver o tempo que demora a preparar cada tipo de bebida.

## 2. Reabastece a tua reserva de gomos de lima

- Os [arrays têm um método][array-docs] para remover o primeiro elemento de um array e devolvê-lo.
- Precisas de fazer uma cópia numa variável dos parâmetros da função se os quiseres alterar.

## 3. Termina o teu turno

- Se sabemos que ainda temos tempo no nosso turno, sabemos que vamos ter de preparar pelo menos um pedido.
    Isto é um bom indício de que um [ciclo repeat-while][repeat-loops] seria uma boa escolha.
- Os [arrays têm um método][array-docs] para remover o primeiro elemento de um array e devolvê-lo.

## 4. Acompanha certos pedidos

- Podes usar um [ciclo for-in][for-in-loops] para trabalhar em cada pedido de cada vez.
- Podes usar a decomposição de tuplos para dar nome aos elementos individuais do tuplo no ciclo for-in.
- Podes usar [instruções de transferência de controlo][control-transfer] para saltar para a iteração seguinte do ciclo nas bebidas que não interessam.
