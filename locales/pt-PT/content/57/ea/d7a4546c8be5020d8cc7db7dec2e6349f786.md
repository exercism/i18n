# Introdução

O `OpenStruct` permite-te criar facilmente um objeto a partir de um `Hash`.
Em vez de teres de aceder através das chaves de um `Hash`, o `OpenStruct` permite-nos usar métodos para aceder e definir valores.


```ruby
attributes = { name: "Jeremy Walker", age: 21, location: "Nomadic" }
person = OpenStruct.new(attributes)

person.name
#=> Jeremy Walker

person.location
#=> Nomadic

# Update the age
person.age = 35

# It sets correctly
person.age
#=> 35
```

Uma vantagem desta abordagem é podermos tirar partido de um atalho ao usar a sintaxe de bloco.
Nas situações em que um bloco chama um único método, podes substituir o bloco por `&:` seguido do nome do método.
Por exemplo, estas duas linhas são sinónimas:

```ruby
people.sum { |person| person.age }
people.sum(&:age)
```

## Biblioteca Padrão

Todas as classes que viste nos exercícios anteriores fazem parte da Biblioteca Principal do Ruby.

O OpenStruct faz parte da Biblioteca Padrão do Ruby (muitas vezes abreviada para "stdlib"), uma coleção de classes para trabalhar com coisas como datas, json e redes.
Também disponibiliza algumas funcionalidades úteis que tornam o teu código mais fácil de trabalhar.

Quando usas classes que não vêm da Biblioteca Principal, sejam o teu próprio código em ficheiros diferentes, classes da stdlib ou dependências externas, precisas de as importar com o método `require` antes de as poderes usar.
Por exemplo:

```ruby
require 'ostruct'

person = OpenStruct.new(name: "Jeremy Walker")
# ...
```
