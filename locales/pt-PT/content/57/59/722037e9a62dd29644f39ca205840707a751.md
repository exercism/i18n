# Mapas e conjuntos

Um array guarda valores em posições numeradas. Por vezes, o rótulo útil não é um número.

## Mapas

Um **mapa** associa cada **chave** a um **valor**. Procura algo pela chave e o mapa dá-te o que foi arquivado sob ela.

`FMAP{K,T}` é um mapa de chaves do tipo `K` para valores do tipo `T`. Um guia que associa o nome de um animal ao sítio onde vive é `FMAP{STR,STR}`.

```sather
   guide ::= #FMAP{STR,STR};
   guide := guide.insert("emu", "grassland");
   guide.get("emu")               -- "grassland"
```

## Atribui sempre o resultado de volta

Olha outra vez para aquela linha do meio. O `insert` devolve o mapa com o par extra lá dentro, e o resultado tem de ser guardado:

```sather
   guide := guide.insert("emu", "grassland");     -- yes
   guide.insert("emu", "grassland");              -- no: the answer is lost
```

Esta é a mesma regra que para `FSTR`, e pelo mesmo motivo. O resultado é normalmente o próprio mapa que entrou, alterado no local; ocasionalmente, quando o mapa fica sem espaço, é um mapa maior. Como não consegues distinguir qual dos dois, **usa o resultado e deixa de usar o nome antigo.** Um nome que sobrou de antes de um `insert` pode estar desatualizado ou pode já não descrever um mapa utilizável.

Isso também significa que um mapa entregue a uma rotina não está a salvo dela. Se o original tiver de sobreviver, vê o `copy` na página do conceito.

## Está lá?

O `has_ind` pergunta se uma chave está no mapa. O nome é a abreviatura de «has index», sendo um índice aquilo a que estes mapas chamam uma chave.

```sather
   guide.has_ind("emu")           -- true
   guide.has_ind("moa")           -- false
```

Pedir uma chave que não está lá não dá erro. O `get` devolve o valor vazio do tipo: zero para um `INT`, e void para uma `STR`, o que vai correr mal mais tarde e noutro sítio. Por isso, verifica antes de ir buscar:

```sather
   if guide.has_ind(animal) then
      return guide.get(animal);
   else
      return "Unknown";
   end;
```

## Conjuntos

Um **conjunto** contém valores sem repetições e sem ordem. `FSET{T}` é um conjunto de valores do tipo `T`.

```sather
   seen ::= #FSET{STR};
   seen := seen.insert("emu");
   seen := seen.insert("emu");    -- already there; nothing changes
   seen.size                      -- 1
   seen.has("emu")                -- true
```

Inserir algo duas vezes deixa uma só cópia. É para isso que serve um conjunto: colecionar coisas e esquecer com que frequência cada uma apareceu.

O `insert` num conjunto devolve o conjunto a usar a partir daí, exatamente como faz para um mapa, por isso atribui-o de volta sempre.

## Quantos

O `.size` funciona nos dois: quantos pares um mapa contém e quantos valores estão num conjunto.
