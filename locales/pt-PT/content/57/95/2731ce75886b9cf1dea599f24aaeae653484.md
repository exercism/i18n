# Anexo às instruções

## Registos

| Registo | Utilização     | Tipo    | Descrição                   |
| -------- | --------- | ------- | --------------------------- |
| `$a0`    | valor de entrada | endereço | array com as palavras dos livros |
| `$a1`    | valor de entrada | inteiro | número de livros             |
| `$v0`    | valor de saída   | inteiro | preço, em cêntimos           |
| `$t0-9`  | temporário | qualquer | usado para armazenamento temporário |
