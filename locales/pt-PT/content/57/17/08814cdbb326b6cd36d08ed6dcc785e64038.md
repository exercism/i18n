# Instruções

A tua tarefa é traduzir texto de inglês para Pig Latin usando as seguintes regras:

- **Regra 1**: Se uma palavra começa com um som de vogal, acrescenta um som "ay" ao fim da palavra (por exemplo, "apple" -> "appleay").
  Repara que "xr" e "yt" no início de uma palavra produzem sons de vogal (por exemplo, "xray" -> "xrayay", "yttria" -> "yttriaay").
- **Regra 2**: Se uma palavra começa com um som de consoante, move-o para o fim da palavra e depois acrescenta um som "ay" ao fim da palavra (por exemplo, "pig" -> "igpay").
  Os sons de consoante podem ser constituídos por várias consoantes, como o "ch" em "chair" ou o "st" em "stand" (por exemplo, "chair" -> "airchay").
- **Regra 3**: Se uma palavra começa com um som de consoante seguido de "qu", move-os para o fim da palavra e depois acrescenta um som "ay" ao fim da palavra (por exemplo, "square" -> "aresquay").
- **Regra 4**: Se uma palavra contém um "y" depois de um grupo de consoantes ou como a segunda letra numa palavra de duas letras, faz um som de vogal (por exemplo, "rhythm" -> "ythmrhay", "my" -> "ymay").
