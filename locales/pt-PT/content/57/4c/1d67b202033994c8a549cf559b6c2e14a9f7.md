# Apêndice às instruções

## Registos

| Registo | Utilização | Tipo    | Descrição                                       |
| -------- | --------- | ------- | ------------------------------------------------- |
| `$a0`    | entrada     | endereço | string de entrada terminada em nulo                      |
| `$v0`    | saída     | boolean | o valor de entrada é um isograma (`0` = `false`, `1` = `true`) |
| `$t0-9`  | temporário | qualquer     | utilizado para armazenamento temporário                        |
