# Apêndice de instruções

## Formato do resultado

Devolve o diamante como uma string terminada em null, com um caráter de mudança de linha no fim de cada linha.

Um exemplo de resultado seria `"  A  \n B B \nC   C\n B B \n  A  \n"`

## Registos

| Registo | Utilização        | Tipo    | Descrição                          |
| -------- | ---------------- | ------- | ---------------------------------- |
| `$a0`    | valor de entrada | byte    | letra                              |
| `$a1`    | valor de entrada/saída | endereço | string de resultado terminada em null |
| `$t0-9`  | temporário       | qualquer | para armazenamento temporário      |
