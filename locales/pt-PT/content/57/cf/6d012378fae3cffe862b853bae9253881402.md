# Instalar o Java

Para praticares os exercícios de Java no Exercism, além da CLI do Exercism e do teu editor de texto preferido, vais precisar do **Java Development Kit** (JDK). O JDK inclui tanto um Java Runtime _como_ ferramentas de desenvolvimento (das quais se destaca o compilador de Java).

Hoje em dia há muitas variantes do JDK, algumas delas de código aberto. Aqui no Exercism recomendamos o [Eclipse Temurin da Adoptium][adoptium].

## Versões de Java suportadas

O percurso de Java do Exercism suporta o Java 25 LTS e versões anteriores.

## Instalar o Eclipse Temurin

Para instalar o Eclipse Temurin no teu sistema, dá uma vista de olhos às excelentes [instruções de instalação][adoptium-installation-guide] deles. Aí encontras instruções sobre como instalar o JDK com o teu gestor de pacotes preferido, e também há links para instaladores que podes descarregar para todos os principais sistemas operativos.

## IDEs para Java

Há muitos IDEs gratuitos disponíveis para Java. Aqui ficam algumas escolhas populares:

- [IntelliJ IDEA Community Edition][intellij-idea]
- [Eclipse][eclipse]
- [Visual Studio Code com a extensão de Java][vscode-java]
