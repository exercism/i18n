# Introdução

## Enum

`Enum` é um módulo muito útil que fornece um conjunto de algoritmos para trabalhar com enumeráveis. Oferece ordenação, filtragem, agrupamento, contagem, pesquisa, procura de valores mínimos/máximos e muito mais.

Em geral, um _enumerável_ é qualquer dado sobre o qual se pode iterar, uma coleção. Em Elixir, um enumerável é qualquer tipo de dados que implemente o [protocolo][exercism-protocols] `Enumerable`. Os mais comuns são as [listas][exercism-lists] e os [mapas][exercism-maps].

Muitas funções de `Enum` aceitam uma função como argumento.

```elixir
Enum.all?([1, 2, 3, 4, 5], fn x -> x > 3 end)
# => false
```

As funções mais comuns de `Enum` são `map` e `reduce`.

### `map/2`

`Enum.map/2` permite-te substituir cada elemento de um enumerável por outro elemento. O segundo argumento de `Enum.map/2` é uma função que aceita o elemento original e devolve o seu substituto.

### `reduce/3`

`Enum.reduce/3` permite-te _reduzir_ todo o enumerável a um único valor. Para isso, é usada uma variável especial chamada _acumulador_. O acumulador transporta o estado intermédio da redução entre iterações.

O segundo argumento de `Enum.reduce/3` é o valor inicial do acumulador. O terceiro argumento é uma função que aceita um elemento e um acumulador e devolve o novo valor do acumulador.

### Trabalhar com mapas

Ao usar mapas com funções de `Enum`, o mapa é automaticamente convertido numa lista de 2 tuplos `{key, value}`.

Para o transformar novamente num mapa, usa `Enum.into/2`. `Enum.into/2` é uma função que transforma um enumerável num coletável, ou seja, qualquer estrutura de dados que implemente o protocolo `Collectable`. Pode ser encarada como o oposto de `Enum.reduce/3`.

`Enum` também tem `Enum.into/3`. `Enum.into/3` é uma variação de `Enum.into/2` que aceita uma função de transformação a aplicar enquanto transforma o enumerável num coletável.

#### Mapear mapas

Em vez de usar `Enum.into/3` ou `Enum.map/2` mais `Enum.into/2` para aplicar uma transformação (mapeamento) a um mapa, também podemos usar a função dedicada `Map.new/2`. Funciona exatamente como `Enum.into/3`, no sentido em que aceita um enumerável e uma função de transformação, mas devolve sempre um novo mapa em vez de nos deixar escolher um coletável.
