# Instruções

Neste exercício, vais trabalhar com contas poupança.
Todos os anos, o saldo da tua conta poupança é atualizado com base na respetiva taxa de juro.
A taxa de juro que o teu banco te dá depende da quantia de dinheiro na tua conta (o respetivo saldo):

- 3,213% para um saldo inferior a `0` dólares (o saldo fica ainda mais negativo).
- 0,5% para um saldo maior ou igual a `0` dólares e inferior a `1000` dólares.
- 1,621% para um saldo maior ou igual a `1000` dólares e inferior a `5000` dólares.
- 2,475% para um saldo maior ou igual a `5000` dólares.

Tens quatro tarefas, e cada uma delas envolve o saldo e a respetiva taxa de juro.

## 1. Calcula a taxa de juro

Implementa a função `interest_rate` para calcular a taxa de juro com base no saldo indicado:

```cpp
interest_rate(200.75);
// => 0.5
```

## 2. Calcula os juros

Implementa a função `yearly_interest` para calcular os juros com base no saldo indicado:

```cpp
yearly_interest(200.75):
// => 1.003750
```

## 3. Calcula a atualização anual do saldo

Implementa a função `annual_balance_update` para calcular a atualização anual do saldo, tendo em conta a taxa de juro:

```cpp
annual_balance_update(200.75);
// => 201.75375
```

## 4. Calcula os anos até atingir o saldo desejado

Implementa a função `years_until_desired_balance` para calcular o número mínimo de anos necessários para atingir o saldo desejado, tendo em conta que, todos os anos, são adicionados juros ao saldo.
Isto significa que o saldo após um ano é: saldo inicial + juros sobre o saldo inicial.
O saldo após o segundo ano é o saldo após um ano + juros sobre o saldo após um ano.
E assim sucessivamente, até que o saldo do ano atual seja maior ou igual ao saldo desejado.

```cpp
double balance {200.75};
double targetBalance {214.88};
years_until_desired_balance(balance, targetBalance)
// => 14
```

Repara que o valor devolvido é um `int`.
