## Geral

- [Sobrecarga de métodos em C#][member-overloading].
- Podes usar a [interpolação de strings][string-interpolation] para formatar strings de descrição.

## 3. Descreve o método de deslocação

- Podes usar um [condicional simples][if-statement] para a lógica condicional.

## 4. Descreve uma personagem que se desloca até um destino

- Podes reutilizar a funcionalidade de descrição existente.
- Podes usar [expressões em strings interpoladas][string-interpolation-expressions], o que significa que podes chamar métodos diretamente nas partes interpoladas de uma string interpolada.

## 5. Descreve uma personagem que se desloca até um destino sem especificar o método de deslocação

- Podes reutilizar a funcionalidade existente que recebe um método de deslocação explícito.
- Podes usar [parâmetros opcionais][optional-arguments] para simplificar a quantidade de código necessária.
