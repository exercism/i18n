# Instruções

Lamont é um alienígena Lisp que quer escrever o seu próprio videojogo. Uma das tarefas para as quais pediu a tua ajuda é manter uma lista de recordes.

## 1. Criar a tabela de recordes

Define uma função `make-high-score-table` que não recebe quaisquer argumentos e que é avaliada como uma nova tabela de hash vazia:

```lisp
(make-high-score-table) ; => #<HASH-TABLE :TEST EQL :COUNT 0 {1005A90103}>
```

## 2. Adicionar um jogador à tabela

Para adicionar um jogador à tabela, define uma função `add-player` que recebe dois argumentos:
- a tabela de recordes
- o nome do jogador como uma palavra-chave

Define a pontuação inicial do jogador como zero.

```lisp
(add-player hash-table :louis) ; => 0
(add-player hash-table :lilly) ; => 0
```

## 3. Definir a pontuação de um jogador

Para definir a pontuação de um jogador, define uma função `set-score` que recebe três argumentos:
- a tabela de recordes
- o nome do jogador como uma palavra-chave
- a pontuação do jogador como um número inteiro

```lisp
(set-score hash-table :louis 1234) ; => 1234
```

## 4. Obter uma pontuação a partir da tabela

Para obter a pontuação de um jogador a partir da tabela, define uma função `get-score` que recebe dois argumentos:
- a tabela de recordes
- o nome do jogador como uma palavra-chave

Esta função deve ser avaliada como a pontuação guardada para o jogador.
Se não houver nenhuma pontuação guardada para esse jogador, ou se esse jogador ainda não estiver na tabela, a avaliação deve resultar em `0`.

```lisp
(get-score hash-table :louis)                         ; => 1234
(get-score hash-table :lilly)                         ; => 0
(get-score hash-table :not-a-character-in-this-story) ; => 0
```

## 5. Remover um jogador da tabela

Para remover um jogador da tabela de recordes, define uma função `remove-player` que recebe dois argumentos:
- a tabela de recordes
- o nome do jogador como uma palavra-chave

Esta função deve lidar sem problemas com os casos em que o jogador ainda não foi adicionado à tabela.
É evidente que, depois de um jogador ser removido, se se obtiver a sua pontuação a partir da tabela, esta será zero.

```lisp
(set-score hash-table :louis 1234)           ; => 1234
(remove-player hash-table :louis)            ; => T
(get-score hash-table :louis)                ; => 0

(remove-player hash-table :not-in-the-table) ; => NIL
```
