# Sobre

[Structs e classes][structs-and-classes] são os principais blocos de construção para criar tipos personalizados em Swift.
Ambos te permitem agrupar propriedades (dados) e métodos (comportamento) relacionados em unidades reutilizáveis.
A maioria dos tipos fundamentais do Swift, incluindo `Int`, `Double`, `String` e tipos de coleção como `Array` e `Dictionary`, são implementados como structs.

Para guias detalhados sobre cada tipo, consulta:

- [concept:swift/structs]()
- [concept:swift/classes]()

## Escolher entre structs e classes

Embora tanto os structs como as classes te permitam definir tipos personalizados, diferem de forma fundamental na maneira como são passados em memória:

- **Os structs são tipos de valor**: quando atribuis ou passas um struct, o Swift faz uma cópia independente dos seus dados.
As alterações feitas a uma cópia não afetam as outras cópias.
- **As classes são tipos de referência**: quando atribuis ou passas uma instância de uma classe, o Swift partilha uma referência para a instância existente.
As alterações feitas através de uma referência afetam imediatamente todas as outras referências que apontam para a mesma instância.

O Swift dá ênfase à segurança e ao comportamento previsível, o que faz dos structs a recomendação predefinida para a maioria dos tipos personalizados.
Usar tipos de valor garante que alterar dados numa parte do teu programa não produz efeitos secundários inesperados noutras partes.

Em geral:

- **Usa um struct** quando modelas dados que representam valores independentes (como coordenadas, formas, dimensões geométricas ou registos formatados).
- **Usa uma classe** quando modelas entidades que têm identidades distintas ou requisitos de ciclo de vida partilhado (como controlos de interface, ligações a bases de dados ou manipuladores de ficheiros).
