# Introdução

## Números

Existem três tipos diferentes de números incorporados no Python: `ints`, `floats` e `complex`. No entanto, neste exercício vais lidar apenas com `ints` e `floats`.

### ints

Os `ints` são números inteiros, por exemplo `1234`, `-10`, `20201278`.

Os inteiros em Python têm [precisão arbitrária][arbitrary-precision] — o número de algarismos é limitado apenas pela memória disponível do sistema anfitrião.

### floats

Os `floats` são números com parte decimal, por exemplo `0.0`, `3.14`, `-9.01`.

Os números de vírgula flutuante são normalmente implementados em Python com um `double` em C (_15 casas decimais de precisão_), mas a representação varia consoante o sistema anfitrião e outros detalhes de implementação. Isto pode causar algumas surpresas ao trabalhar com números de vírgula flutuante, mas é "suficientemente bom" para a maioria das situações.

## Aritmética

O Python suporta totalmente a aritmética entre `ints` e `floats`. Converte os números mais estreitos para corresponderem aos seus equivalentes menos estreitos quando são usados com os operadores aritméticos binários (`+`, `-`, `*`, `/`, `//` e `%`).

O Python considera os `ints` mais estreitos do que os `floats`. Por isso, usar um float numa expressão garante que o resultado também será um float. No entanto, ao fazer uma divisão, o resultado é sempre um float, mesmo que só se usem números inteiros.

```python
# The int is widened to a float here, and a float type is returned.
>>> 3 + 4.0
7.0
>>> 3 * 4.0
12.0
>>> 3 - 2.0
1.0
# Division always returns a float.
>>> 6 / 2
3.0
>>> 7 / 4
1.75
# Calculating remainders.
>>> 7 % 4
3
>>> 2 % 4
2
>>> 12.75 % 3
0.75
```

Se precisares de um resultado inteiro, podes usar `//` para truncar o resultado.

```python
>>> 6 // 2
3
>>> 7 // 4
1
```

Para converteres um float num número inteiro, podes usar `int()`. Para converteres um número inteiro num float, podes usar `float()`.

```python
>>> int(6 / 2)
3
>>> float(1 + 2)
3.0
```
