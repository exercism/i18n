# Instruções

És professor(a).
No final do ano, atribuíste uma nota numérica a cada um dos teus alunos.
Agora precisas de converter essas notas em notas alfabéticas e de contar quantos alunos obtiveram cada uma.

## 1. Converter uma nota numérica numa nota alfabética

A função `letter_grade` recebe uma nota numérica como parâmetro de entrada e devolve a letra.
Usa estes intervalos:

| Letra |      Nota |
| :----: | --------: |
|   A    | 90% - 100% |
|   B    |  80% - 89% |
|   C    |  70% - 79% |
|   D    |  60% - 69% |
|   F    |   0% - 59% |

Exemplo:

```jq
75 | letter_grade   # => "C"
```

## 2. Contar o número de alunos em cada nota alfabética

A função `count_letter_grades` recebe um objeto que associa os nomes dos alunos às respetivas notas.
O resultado é um objeto que associa cada nota alfabética ao número de alunos com essa nota.

Exemplo:

```jq
{"Joe": 78, "Jane": 93, "Richard": 72} | count_letter_grades
# => {"A": 1, "B": 0, "C": 2, "D": 0, "F": 0}
```

Há várias formas diferentes de resolver isto.
Usa o filtro `reduce` para praticar.
