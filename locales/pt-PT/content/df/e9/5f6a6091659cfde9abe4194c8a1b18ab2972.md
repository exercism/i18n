# Introdução

Os carateres e as strings constituem a base da representação de texto em Elm.
As strings podem ser vistas como listas de carateres, e a maioria das funções de `List` tem o seu equivalente no módulo `String`.

## Carateres

O tipo `Char` representa um único caráter Unicode com aspas simples, por exemplo `'a'`.
O módulo `Char` fornece funções de predicado (`Char -> Bool`) para testar propriedades de um caráter: `isUpper`, `isLower`, `isAlpha` e `isAlphaNum`.
O módulo também fornece funções para converter um caráter com `toUpper`, `toLower`, `toLocaleUpper` e `toLocaleLower`, bem como para converter de e para o seu valor numérico Unicode (`Int`) com `toCode` e `fromCode`.

## Strings

O tipo `String` fornece uma representação incorporada para manipular strings de forma eficiente e pode representar qualquer sequência de carateres Unicode.
As strings representam-se com aspas duplas: `"this is a string"`.
As strings com várias linhas representam-se com triplas aspas duplas e podem conter aspas e mudanças de linha sem escape.

```elm 
haiku = 
"""
    Code's strings entwine
    , In binary, thoughts combine
    , Logic's elegant line.
"""
```

## Manipulação de strings

`reverse : String -> String` inverte a string.
```elm 
reverse "Hello world." 
    --> ".dlrow olleH"
```

`repeat : Int -> String -> String` repete uma string n vezes.
```elm 
repeat 2 "Hello world." 
    --> "Hello world.Hello world."
```

`replace : String -> String -> String -> String` substitui todas as ocorrências de uma dada substring.
```elm
replace "Hello" "Goodbye cruel" "Hello world." 
    --> "Goodbye cruel world."
```

`append : String -> String -> String` junta duas strings.
O operador `++` também pode ser usado para isso.
```elm
append "butter" "fly" 
    --> "butterfly"
"butter" ++ "fly" 
    --> "butterfly"
```

`concat : List String -> String` concatena uma lista de strings numa única string.
```elm
concat ["never", "the", "less"] 
    --> "nevertheless"
```

`split : String -> String -> List String` divide uma string numa lista de strings no separador indicado.
```elm
split ";" "cat;dog;cow" 
    --> ["cat", "dog", "cow"]
```

`join : String -> List String -> String` junta uma lista de strings com um separador indicado.
```elm
join "a" ["H", "w", "ii", "n"] 
    --> "Hawaiian"
```

`words : String -> List String` divide uma string em strings, separando por blocos de espaços em branco.
```elm
words "How are \t you? \n Good?" 
    --> ["How", "are", "you?", "Good?"]
```

`lines : String -> List String` divide uma string em linhas, separando pelas mudanças de linha.
```elm
lines "How are you?\nGood?" 
    --> ["How are you?", "Good?"]
```

`cons : Char -> String -> String` acrescenta um caráter ao início de uma string.
```elm
cons 'T' "he truth is out there" 
    --> "The truth is out there"
```

`uncons : String -> Maybe ( Char, String )` divide uma string não vazia na sua cabeça e na sua cauda.
Isto permite-te fazer correspondência de padrões com strings exatamente como farias com listas.
As strings vazias devolvem `Nothing`.
```elm
uncons "abc" 
    --> Just ('a', "bc")
uncons ""
    --> Nothing
```

## Obter substrings

`slice : Int -> Int -> String -> String` devolve uma substring dados um índice de início e de fim.
Os índices negativos contam a partir do fim da lista.
```elm
slice 0 6 "snakes on a plane!" 
    --> "snakes"
slice 0 -7 "snakes on a plane!"
    --> "snakes on a"
```

`left : Int -> String -> String` e `right : Int -> String -> String` retiram n carateres do lado esquerdo ou direito da string, respetivamente.

```elm
left 2 "Mulder" 
    --> "Mu"
right 2 "Scully" 
    --> "ly"
```

`dropLeft : Int -> String -> String` e `dropRight : Int -> String -> String` removem n carateres do lado esquerdo ou direito de uma string, respetivamente.
```elm
dropRight 6 "Hello world." 
    --> "Hello"
dropLeft 6 "Hello world." 
    --> "world"
```

## Verificar propriedades das strings

`length : String -> Int` devolve o número de carateres de uma string.
```elm 
length "Hello world." 
    --> 12
```

`isEmpty : String -> Bool` determina se uma string está vazia. 
```elm 
isEmpty "Hello world." 
    --> False
```

`contains : String -> String -> Bool` verifica se a segunda string contém a primeira.
```elm
contains "the" "theory" 
    --> True
contains "THE" "theory" 
    --> False
```

`startsWith : String -> String -> Bool` e `endsWith : String -> String -> Bool` verificam se a segunda string começa/termina com uma dada substring.
```elm
startsWith "the" "theory" 
    --> True
endsWith "ory" "theory" 
    --> True
```

`indexes : String -> String -> List Int` obtém uma lista de todos os índices iniciais de uma substring noutra string.
```elm
indexes "ss" "Mississippi"  
    --> [2, 5]
```

## Converter strings
`toInt : String -> Maybe Int` tenta converter uma string em `Just Int` e devolve `Nothing` para strings com formato incorreto.
```elm
toInt "-42" 
    --> Just -42
toInt "3.1" 
    --> Nothing
toInt "two" 
    --> Nothing
```

`fromInt : Int -> String` converte um número inteiro numa string.
```elm
fromInt -42 
    --> "-42"
```

`toFloat : String -> Maybe Float` tenta converter uma string num número de vírgula flutuante, falhando nas strings com formato incorreto.
```elm
toFloat "-42" 
    --> Just -42.0
toFloat "3.1" 
    --> Just 3.1
toFloat "two" 
    --> Nothing
```

`fromFloat : Float -> String` converte um número de vírgula flutuante numa string.
```elm
fromFloat 3.9 
    --> "3.9"
```

`toList : String -> List Char` e `fromList : List Char -> String` convertem uma string para e de uma lista de carateres, respetivamente.
```elm 
toList "abc" 
    --> ['a', 'b', 'c']
fromList ['a', 'b', 'c'] 
    --> "abc"
```

`fromChar : Char -> String` converte um caráter numa string.
```elm
fromChar 'a' 
    --> "a"
```

## Formatar strings

`toUpper : String -> String` e `toLower : String -> String` convertem strings para todas maiúsculas ou todas minúsculas, respetivamente.
Útil para comparações que não distinguem maiúsculas de minúsculas.
```elm
toUpper "skinner" 
    --> "SKINNER"
toLower "X-FILES" 
    --> "x-files"
```

`pad : Int -> Char -> String -> String` preenche uma string de ambos os lados com o `Char` fornecido até esta ter o comprimento indicado.
```elm
pad 5 ' ' "11"  
    --> "  11 "
```
De forma semelhante, `padLeft` e `padRight` preenchem uma string de um dos lados até esta ter o comprimento indicado.

`trim : String -> String` remove os espaços em branco de ambos os lados de uma string.
```elm
trim "  hats  \n" 
    --> "hats"
```
`trimLeft` e `trimRight` removem os espaços em branco de um dos lados de uma string.

## Funções de ordem superior

`map : (Char -> Char) -> String -> String` transforma cada caráter de uma string com a função indicada.
Repara que a função fornecida tem de ser um mapeamento de e para `Char`.
```elm
map (\c -> if c == '/' then '.' else c) "a/b/c" 
    --> "a.b.c"
```

`filter : (Char -> Bool) -> String -> String` mantém apenas os carateres que passam no teste.
```elm
filter isDigit "R2-D2" 
    --> "22"
```

`foldl : (Char -> b -> b) -> b -> String -> b` reduz uma string começando pela esquerda.
A função é aplicada com o primeiro caráter como primeiro parâmetro e um valor inicial fornecido como segundo parâmetro.
O resultado da função tem de ser do mesmo tipo que o valor inicial fornecido e é aplicado a cada caráter, pela ordem.
```elm
foldl (\c acc -> Char.toCode c + acc) 0 "the sum of my unicode is " 
    --> 2260
```
`foldr` faz o mesmo, mas começando pelo lado direito da string.

`any : (Char -> Bool) -> String -> Bool` determina se algum caráter devolve `True` ao predicado fornecido.
```elm
any isDigit "R2-D2" 
    --> True
any isDigit "heart" 
    --> False
```
`all : (Char -> Bool) -> String -> Bool` determina se todos os carateres de uma string devolvem `True` ao predicado fornecido.
```elm
all isDigit "R2-D2" 
    --> False
all isAlpha "heart" 
    --> True
```
