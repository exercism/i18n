# Instruções

És um observador de aves entusiasta que acompanha quantas aves visitaram o teu jardim nos últimos sete dias.

Tens seis tarefas, todas relacionadas com o número de aves que visitaram o teu jardim.

## 1. Verifica quais foram as contagens da semana passada

Para fins de comparação, guardas sempre por perto uma cópia das contagens da semana passada, que foram: 0, 2, 5, 3, 7, 8 e 4. Implementa o método `BirdWatcher.getLastWeek()` que devolve as contagens da semana passada:

```java
BirdWatcher.getLastWeek();
// => [0, 2, 5, 3, 7, 8, 4]
```

## 2. Verifica quantas aves visitaram hoje

Implementa o método `BirdWatcher.getToday()` para devolver quantas aves visitaram o teu jardim hoje. As contagens de aves estão ordenadas por dia, sendo o primeiro elemento a contagem do dia mais antigo e o último elemento a contagem de hoje.

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.getToday();
// => 1
```

## 3. Incrementa a contagem de hoje

Implementa o método `BirdWatcher.incrementTodaysCount()` para incrementar a contagem de hoje:

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.incrementTodaysCount();
birdCount.getToday();
// => 2
```

## 4. Verifica se houve um dia sem aves a visitar o jardim

Implementa o método `BirdWatcher.hasDayWithoutBirds()` que devolve `true` se houve um dia em que zero aves visitaram o jardim; caso contrário, devolve `false`:

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.hasDayWithoutBirds();
// => true
```

## 5. Calcula o número de aves visitantes nos primeiros dias

Implementa o método `BirdWatcher.getCountForFirstDays()` que devolve o número de aves que visitaram o teu jardim desde o início da semana, mas limita a contagem ao número especificado de dias a partir do início da semana.

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.getCountForFirstDays(4);
// => 14
```

## 6. Calcula o número de dias movimentados

Há dias mais movimentados do que outros. Um dia movimentado é aquele em que cinco ou mais aves visitaram o teu jardim.
Implementa o método `BirdWatcher.getBusyDays()` para devolver o número de dias movimentados:

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.getBusyDays();
// => 2
```
