# Testes


## Correr e testar as tuas soluções


### A partir da linha de comandos

Basta escrever `make chez` se usares o ChezScheme ou `make guile` se usares o GNU Guile\.

### A partir de um REPL

* Introduz `test.scm` no prompt do REPL\.
* Desenvolve a tua solução no ficheiro de solução do exercício (por exemplo, `hello-world.scm`), recarregando-o à medida que avanças\.
* Corre `(test)` para verificar a tua solução\.
