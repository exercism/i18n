# Apêndice às instruções

## Notas específicas do WebAssembly

A assinatura da função para a exportação `convert` do WebAssembly é a seguinte:

```wasm
(func (export "convert")
    (param $arrOffset i32)
    (param $arrLength i32)
    (param $inputBase i32)
    (param $outputBase i32)
    (result i32 i32 i32)
)
```

Os dois primeiros parâmetros, `$arrOffset` e `$arrLength`, indicam o deslocamento base e o comprimento de um array de inteiros de 32 bits com sinal. O parâmetro de comprimento é medido em número de elementos do array, não em bytes. Antes de chamar esta função, quem a chama escreve este array na memória linear do WebAssembly, começando no deslocamento `$arrOffset`. A memória linear do WebAssembly é sempre expressa em little-endian.

Assim, quem chama a função codificaria o array `[1,2]` como a seguinte sequência de oito bytes.

```
| 64 | 65 | 66 | 67 | 68 | 69 | 70 | 71 |
| ---- arr[0] ----- | ---- arr[1] ----- |
,0x01,0x00,0x00,0x00,0x02,0x00,0x00,0x00,
```

Os parâmetros `$inputBase` e `$outputBase` não envolvem a memória linear.

O tipo do resultado é `(i32 i32 i32)`. Os dois primeiros valores são o `offset` e o `length` da tua saída na memória linear. Se quiseres, podes sobrescrever os endereços da memória linear usados para os dados de entrada. O terceiro valor devolvido é um código de estado i32 usado para o tratamento de erros.

Se o terceiro valor devolvido indicar um estado de erro, os testes unitários não leem os dois primeiros valores devolvidos.
