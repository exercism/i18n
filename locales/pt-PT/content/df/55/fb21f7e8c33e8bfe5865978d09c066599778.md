# Sobre

Os combinadores transformam padrões de reorganização da pilha em palavras com nome e componíveis. Quando já escreveste Factor suficiente, deixas de pensar «preciso de fazer `dup`, depois correr F e depois manter o original» e escreves simplesmente `[ F ] keep`.

| padrão                             | reorganizações                 | combinador      |
|------------------------------------|-------------------------------|-----------------|
| aplicar F, preservar o valor de entrada | `dup F swap`              | `[ F ] keep`    |
| duas funções de um valor de entrada | `dup F swap G`               | `[ F ] [ G ] bi`|
| três funções de um valor de entrada | complicado                   | `[ F ] [ G ] [ H ] tri` |
| muitas funções de um valor de entrada | muito complicado           | `{ Fs … } cleave`|
| operar sobre valores *por baixo* do topo | `swap F swap`          | `[ F ] dip`     |
| a mesma operação sobre dois valores | `swap F swap F`              | `[ F ] bi@`     |
| operações diferentes sobre dois valores | `swap F swap G`          | `[ F ] [ G ] bi*`|

A família com o prefixo `2` (`2bi`, `2dip`, `2tri`, `2dup`, `2drop`,
`2nip`, `2swap`) faz o mesmo quando cada operação precisa de *dois*
valores de entrada; `3dup` e `4dup` estendem o idioma de duplicação a três
ou quatro valores no topo da pilha.

Para além da família cleave/dip/bi, o [`kernel`][kernel] também oferece
variantes de fluxo de controlo que propagam `f` de forma limpa:

| palavra     | efeito                                              |
|-------------|-----------------------------------------------------|
| `if*`       | o ramo verdadeiro vê o valor; o ramo falso não      |
| `?last`     | último elemento de uma sequência, ou `f` se estiver vazia |
| `pop*`      | variante de `pop` que descarta (modifica um vetor)  |
| `dupd`      | duplica o *segundo* a contar do topo                |
| `pick`      | copia o *terceiro* a contar do topo para o topo     |
| `swapd`     | troca o segundo e o terceiro a contar do topo       |
| `rotd`      | roda os três de baixo de uma pilha com quatro elementos |
| `tuck`      | copia o topo para debaixo do segundo a contar do topo |
| `with`      | incorpora um valor fixo numa quotation para HOS     |
| `while`     | ciclo enquanto um predicado se verifica             |
| `until`     | ciclo até um predicado se verificar                 |

Escolher o combinador certo é, em si, uma competência. A regra geral:
quando o corpo de uma definição já tem mais do que uma palavra de
reorganização seguida, há normalmente um combinador que capta melhor a
intenção.

[kernel]: https://docs.factorcode.org/content/vocab-kernel.html
