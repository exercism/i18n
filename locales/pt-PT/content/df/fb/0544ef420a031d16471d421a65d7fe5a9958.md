# Dicas

## Geral

- O teu ficheiro de solução é incluído noutro, que chama as tuas macros.
  Mantém o nome de cada macro e a ordem dos argumentos exatamente como a tarefa os dá, ou o ficheiro não será montado.
- Os argumentos de uma macro são tokens, substituídos por `%1`, `%2`, `%3` onde quer que apareçam no corpo.
  Podem ser registos, expressões de endereço ou literais, desde que cada expansão seja uma instrução válida.
- Cada macro é verificada pelos registos que deixa intactos, e não apenas pelo que escreve.
  Lê a nota de cada tarefa sobre os registos que a macro pode alterar e muda apenas os registos que ela permite.

## 1. Dá nome às constantes de formato

- Um `%define` de uma só linha dá um nome a um valor, para que o resto do código possa ler o nome em vez de um número cru.
  Para um número fixo, `equ` faz o mesmo e é a escolha habitual para uma constante.
- As constantes de bytes podem ser escritas em hexadecimal (`0x20`) ou como um literal de caráter (`' '`).
  Ambas montam para o mesmo valor.

## 2. Escreve a macro `fill_run`

- Deves dar a `rcx` o nome legível `COUNTER`.
- `fill_run` é uma macro de várias linhas que recebe 3 argumentos.
  As macros de várias linhas definem-se com `%macro ... %endmacro`.
- O primeiro argumento de `fill_run` é um endereço de memória num registo de uso geral de 64 bits.
  O segundo é a contagem, que pode ser passada num registo de uso geral de 64 bits ou como um valor imediato.
  O terceiro é um byte a escrever, como valor imediato.
  Deves planear o código da macro tendo em conta estas especificações.
- O único registo que `fill_run` pode modificar é `COUNTER`.
- Um ciclo dentro de uma macro costuma precisar de um rótulo com o prefixo `%%`.
  Sem este prefixo, o mesmo rótulo é criado de cada vez que a macro é chamada, o que pode causar um erro se a macro for chamada mais do que uma vez.

## 3. Escreve a macro `lay_columns`

- `lay_columns` é uma macro de várias linhas que recebe 2 argumentos.
  As macros de várias linhas definem-se com `%macro ... %endmacro`.
- Ambos os argumentos de `lay_columns` são passados em registos de uso geral de 64 bits.
  O primeiro é um endereço de memória, o segundo é um número inteiro.
  Deves planear o código da macro tendo em conta estas especificações.
- Os únicos registos que `lay_columns` pode modificar são os dois passados como argumentos.
- O número de deslocamentos que a macro tem de escrever é fixo em tempo de montagem.
  Podes usar `%rep ... %endrep` para repetir o código.
- O cálculo do deslocamento é feito com `offset[i] = margin + i * COLUMN_STRIDE`.
  `margin` é o segundo argumento da macro.
  `i` é um contador de ciclo que pode ser definido como uma variável `%assign`.

## 4. Escreve a macro `set_header`

- `set_header` é uma macro de várias linhas que recebe 2 argumentos.
  As macros de várias linhas definem-se com `%macro ... %endmacro`.
- O primeiro argumento de `set_header` é a expressão de um endereço de memória efetivo.
  Recebe um registo de base que pode ser somado a um registo de índice escalado por `1`, `2`, `4` ou `8`, e um valor imediato.
  Isto significa que um simples `rdi` é válido, tal como `rdi+rax*4+2`.
- O segundo argumento de `set_header` é um valor imediato que pode ter os valores `0`, `1` ou `2`.
- `set_header` não pode modificar nenhum registo.
- Deves copiar condicionalmente um byte para o endereço de destino em tempo de montagem, de acordo com o segundo argumento.
  Um valor de `0` deve copiar `PLAIN`, um valor de `1` deve copiar `RULED` e um valor de `2` deve copiar `BOXED`.
