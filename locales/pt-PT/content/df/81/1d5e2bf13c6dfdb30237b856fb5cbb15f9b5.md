# Acerca de

O Printer de Common Lisp é o mecanismo que permite enviar dados para streams. Uma das funções mais usadas deste mecanismo é a `format`.

A `format` recebe dois parâmetros obrigatórios: um stream para onde escrever e uma string de controlo. O conteúdo da string de controlo determina como são usados os restantes argumentos.

O primeiro parâmetro tem dois valores especiais: `t` e `nil`. O `t` indica que deve ser usado o stream ligado a `*standard-output*`, e o `nil` indica que deve ser criada e devolvida uma string. A `format` devolve `nil`, exceto se o parâmetro stream for `nil`.

A string de controlo pode conter diretivas de formato, que são assinaladas por um `~` seguido de um caráter (não interessa se o caráter é maiúsculo ou minúsculo). A diretiva de formato define se são consumidos argumentos e como são formatados para o stream.

As diretivas de formato básicas mais importantes são:

* `~A` - formata de forma _estética_, "legível para humanos".
* `~S` - formata no _standard_, para ser "legível por máquinas".
* `~%` - emite uma nova linha
* `~&` - emite uma nova linha, a menos que já estejas no início de uma linha.
* `~~` - emite um til.

Exemplos:

```lisp
(format nil "The list is: ~A~%" (list 1 2 3)) ; => "The list is: (1 2 3)
                                                   "
(format nil "(format t ~S)" "hello world")    ; => "(format t \"hello world\""
(format nil "~&fresh~&lines")                 ;=> "fresh
                                                   lines"
(format nil "directives start with a ~~")     ; => "directives start with a ~"
```
