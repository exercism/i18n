# Introdução

Em Toyland, os comboios andam sempre ocupados a entregar tesouros por toda a cidade, desde berlindes brilhantes a blocos de construção raros.
Os carris por onde circulam são feitos de peças coloridas em forma de dominó, cada uma marcada com dois números.
Para que os comboios se movam, os dominós têm de formar uma cadeia perfeita em que os números coincidem.

Hoje, uma entrega urgente de brinquedos raros está em espera.
Deram-te um conjunto de peças de carril para inspecionares.
Se conseguirem formar uma cadeia contínua, o comboio segue viagem, levando sorrisos por toda a Toyland.
Caso contrário, o conjunto é descartado e tenta-se outro.

Os brinquedos contam contigo para resolveres este puzzle.
Será que os dominós vão ligar os carris e pôr o comboio a andar, ou será que o conjunto fica para trás?
