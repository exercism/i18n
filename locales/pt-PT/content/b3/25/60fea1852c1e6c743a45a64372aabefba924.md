# Instruções

Neste exercício vais escrever algum código para te ajudar a cozinhar uma lasanha fantástica do teu livro de receitas favorito.

Tens cinco tarefas, todas relacionadas com o tempo gasto a cozinhar a lasanha.

## 1. Define o tempo esperado no forno em minutos

Define a variável imutável `expectedMinutesInOven` que devolve quantos minutos a lasanha deve estar no forno.
Tem de ser exportada.
Segundo o livro de receitas, o tempo esperado no forno é de 40 minutos:

```nim
nim> expectedMinutesInOven
40 == type int
```

## 2. Calcula o tempo restante no forno em minutos

Implementa o procedimento `remainingMinutesInOven`, que recebe como parâmetro os minutos reais que a lasanha já esteve no forno e devolve quantos minutos a lasanha ainda tem de permanecer no forno, com base no tempo esperado no forno em minutos da tarefa anterior.

```nim
nim> remainingMinutesInOven(30)
10 == type int
```

## 3. Calcula o tempo de preparação em minutos

Implementa o procedimento `preparationTimeInMinutes`, que recebe como parâmetro o número de camadas que adicionaste à lasanha e devolve quantos minutos passaste a preparar a lasanha, assumindo que cada camada demora 2 minutos a preparar.

```nim
nim> preparationTimeInMinutes(2)
4 == type int
```

## 4. Calcula o tempo total de trabalho em minutos

Implementa o procedimento `totalTimeInMinutes`, que recebe dois parâmetros: o parâmetro `numberOfLayers` é o número de camadas que adicionaste à lasanha, e o parâmetro `actualMinutesInOven` é o número de minutos que a lasanha já esteve no forno.
O procedimento deve devolver quantos minutos, no total, dedicaste a cozinhar a lasanha. Esse total é a soma do tempo de preparação em minutos com o tempo, em minutos, que a lasanha já passou no forno até ao momento.

```nim
nim> totalTimeInMinutes(3, 20)
26 == type int
```
