# Apêndice às instruções

## Como este exercício está estruturado em Python

Adicionámos um descritor de semana adicional (`fifth`) para o quinto dia da semana do mês, se existir.  
Se não houver um quinto dia da semana num mês, deves lançar uma exceção.

## Personalizar e lançar exceções

Por vezes é necessário [personalizar](https://docs.python.org/3/tutorial/errors.html#user-defined-exceptions) e [`raise`](https://docs.python.org/3/tutorial/errors.html#raising-exceptions) exceções no teu código. Quando o fizeres, deves incluir sempre uma **mensagem de erro significativa** que indique qual é a origem do erro. Isto torna o teu código mais legível e ajuda imenso na depuração.

As exceções personalizadas podem ser criadas através de novas classes de exceção (vê [`classes`](https://docs.python.org/3/tutorial/classes.html#tut-classes) para mais detalhes.) que são tipicamente subclasses de [`Exception`](https://docs.python.org/3/library/exceptions.html#Exception).

Nas situações em que sabes que a origem do erro será derivada de um determinado tipo de exceção, podes optar por herdar de um dos [`built in error types`](https://docs.python.org/3/library/exceptions.html#base-classes) da classe _Exception_. Ao lançar o erro, deves continuar a incluir uma mensagem significativa.

Este exercício em particular exige que cries uma _exceção personalizada_ para ser [lançada](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement)/«thrown» quando a tua função `meetup()` recebe uma combinação de nome de dia da semana e número que é inválida. Os testes só passam se personalizares as exceções adequadas, as lançares com `raise` e incluíres mensagens de erro adequadas.

Para personalizar uma `built-in exception`, cria uma `class` que herde dessa exceção. Ao lançar a exceção personalizada com uma mensagem, escreve a mensagem como argumento do tipo `exception`:

```python
# subclassing the built-in ValueError to create MeetupDayException
class MeetupDayException(ValueError):
    """Exception raised when the Meetup weekday and count do not result in a valid date.

    message: explanation of the error.

    """
    def __init__(self, message):
        self.message = message

        
# raising a MeetupDayException
raise MeetupDayException("That day does not exist.")
```
