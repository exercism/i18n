# Sobre

Uma **word** é o nome que o Factor dá a uma função. Conheceste a pilha de dados e as shuffle words em `basics`; aqui defines as tuas próprias words, que calculam com os seus valores de entrada.

```factor
: square ( x -- x*x ) dup * ;
: hello  ( -- )       "Hello, world!" print ;
: max3   ( a b c -- max ) max max ;
```

Uma definição é `:`, um efeito de pilha, o corpo e, por fim, `;`. Os nomes dentro de `( … -- … )` são para quem lê; o que o compilador verifica é o *número* de valores de entrada e de saída. Uma discrepância é um erro de compilação, o que apanha uma classe de bugs que seriam erros em tempo de execução numa linguagem de tipos dinâmicos sem este tipo de declaração.

As words de aritmética com inteiros `+`, `-`, `*` vêm do vocabulário `math` e cada uma consome dois números do topo da pilha. O topo da pilha é o operando da direita, por isso `8 3 -` calcula `8 - 3`.

`CONSTANT:` define um nome para um valor fixo; chamar o nome coloca o valor na pilha, exatamente como qualquer outra word. Coloca as constantes no topo do ficheiro, antes de qualquer word que as use.

O corpo de uma word pode chamar qualquer word que já esteja no âmbito: definições anteriores no mesmo ficheiro, words de vocabulários importados e as constantes que declaraste. Compor words pequenas, com um único propósito, é a forma normal de construir um programa.

Por convenção:

- As words e as constantes usam `lowercase-kebab-case`.
- Os predicados terminam em `?` e produzem um Boolean (`even?`, `empty?`).
- As words que alteram o seu valor de entrada partilham muitas vezes o nome com a versão que o não altera, distinguindo-se apenas pelo contexto.
