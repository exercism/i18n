# Instruções

Refatora um parser de Markdown.

O exercício de Markdown é um exercício de refatoração.
Há código que faz o parsing de uma string com sintaxe de Markdown e devolve o HTML associado a essa string.
Embora este código esteja escrito de forma confusa e seja difícil de seguir, de alguma forma funciona e todos os testes estão a passar!
O teu desafio é reescrever este código para o tornar mais fácil de ler e de manter, garantindo ao mesmo tempo que todos os testes continuam a passar.

Seria útil que tomasses notas do que fizeste na tua refatoração em comentários, para que os revisores possam ver isso, mas não é estritamente necessário.
O mais importante é melhorar o código!
