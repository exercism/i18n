# Sobre

O âmbito de um valor tem a ver com o sítio do programa onde esse valor pode ser acedido.

## Os quatro tipos de âmbito: bloco, função, protótipo de função e ficheiro

### Âmbito de bloco

Um valor com âmbito de bloco só pode ser acedido a partir do interior do bloco onde está definido.
Para saberes mais sobre blocos, consulta o [conceito de bloco](../blocks/introduction.md#Introduction).

### Âmbito de função

O âmbito de função é um tipo especial de âmbito que se aplica aos rótulos usados com instruções `goto`.
Não podem existir dois rótulos com o mesmo nome na mesma função, mesmo que os rótulos estejam definidos em blocos separados dentro da função.

### Âmbito de protótipo de função

O âmbito de protótipo de função é outro tipo especial de âmbito que se aplica apenas aos parâmetros com nome dentro do protótipo (também designado por declaração, tendo em conta que nem todas as declarações são protótipos).
O nome de um parâmetro é normalmente opcional numa declaração de função.
O âmbito de um nome só é relevante dentro da declaração.
No exemplo seguinte, o identificador `len` é definido e depois referido mais à frente na declaração da função.

```c
#include <stdio.h>

// len is defined and then referred to
void my_func(int len, int numbers[len]);

int main() {
    int numbers[2];
    numbers[0] = 1;
    numbers[1] = 2;
    my_func(2, numbers);
}

void my_func(int length, int numbers[length]) {
    // prints numbers should have 2 elements
    printf("numbers should have %d elements", length);
}
```

Repara que, dentro de uma declaração, os nomes têm de coincidir quando se faz referência à mesma variável.
Se `my_func` fosse declarada como `void my_func(int len, int numbers[length]);`, seria gerado um erro de compilação parecido com

```
/tmp/scn62kKPEZ.c:4:35: error: 'length' undeclared here (not in a function)
    3 | void my_func(int len, int numbers[length]);
      |                                   ^~~~~~
/tmp/scn62kKPEZ.c: In function 'main':
/tmp/scn62kKPEZ.c:10:16: error: type of formal parameter 2 is incomplete
   10 |     my_func(2, numbers);
```

Uma definição de função não tem de usar o mesmo nome para um parâmetro que foi usado na declaração da função.
No exemplo acima, usou-se `len` na declaração e `length` na definição, o que mostra que o âmbito do identificador `len` se limitava à declaração da função.

### Âmbito de ficheiro

Um valor com âmbito de ficheiro pode ser acedido a partir de qualquer ponto do ficheiro.
Qualquer valor deste tipo é definido fora de uma função.
