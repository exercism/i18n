# Acerca de

O Gleam representa os valores verdadeiro e falso com o tipo `Bool`. Existem apenas dois valores: `True` e `False`. Estes valores podem ser associados a uma variável:

```gleam
let true_variable = True
let false_variable = False
```

Os operadores `&&`, `||` e `!` podem ser usados para manipular valores Boolean:

```gleam
True && True  // -> True
True && False // -> False

False || True  // -> True
False || False // -> False

!False // -> True
!True  // -> False
```

Os operadores `&&` e `||` usam avaliação de curto-circuito, o que significa que a expressão do lado direito do operador só é avaliada se for necessário.

Cada um dos operadores tem uma precedência diferente, em que `!` é avaliado antes de `&&` e `||`. As chavetas podem ser usadas para avaliar uma parte da expressão antes das outras:

```gleam
!True && False   // -> False
!{True && False} // -> True
```
