# Dicas

## Geral

- Não alteres o código nos namespaces das famílias.
- Não copies os valores para o teu código: chama as funções.

## 1. Toma o teu lugar à frente das famílias e dispõe os teus papéis

- O namespace tem de se chamar `estate_executor` para os testes funcionarem.

## 2. Encontra o número de conta secreto

Tens de chamar cada `bank_number_part` com o `secret_modifier` da lista de parâmetros.

## 3. Último passo: introduz o código secreto

- Podes chamar funções de namespaces aninhados assim: `outer_namespace::inner_namespac::my_function`.

- Tem cuidado: soma os fragmentos azuis e vermelhos separadamente antes de multiplicar as duas partes.
