# Realce de sintaxe estático

O realce de sintaxe estático é o realce de código que o utilizador _não_ pode alterar.
Isto inclui fragmentos de código, iterações e muito mais.

```exercism/note
O editor online _não_ usa realce de sintaxe estático, porque o utilizador pode alterar o código em tempo real.
Se quiseres saber mais sobre como tratamos o realce de sintaxe no editor online, consulta a [documentação do realce de sintaxe dinâmico](/docs/building/tracks/new/syntax-highlighting/dynamic).
```

## Implementação

O realce de sintaxe estático é feito com a [biblioteca highlightjs](https://highlightjs.org/).

Ao adicionar suporte para a tua linguagem, há três opções:

1. A linguagem é suportada _nativamente_ pelo highlightjs (ou seja, está listada como [linguagem suportada](https://github.com/highlightjs/highlight.js/blob/main/SUPPORTED_LANGUAGES.md)).
   Nesse caso, continua na secção [Configurar o track](#configuring-track).
2. A linguagem é suportada através de um plugin do highlightjs já existente.
   Nesse caso, continua na secção [Usar um plugin existente](#using-an-existing-plugin).
3. A linguagem _não_ é suportada.
   Aqui tens três opções:
   1. Escrever um plugin do highlightjs de raiz, como descrito na secção [Criar um novo plugin](#create-a-new-plugin).
   2. A sintaxe da tua linguagem é (muito) parecida com a sintaxe de outra linguagem (por exemplo, a sintaxe de Unison é parecida com a de Haskell); nesse caso, podes considerar usar o realce de sintaxe dessa linguagem para a tua.
      Consulta a secção [Configurar o track](#configuring-track) para mais informações.
   3. Não usar realce de sintaxe estático.

### Configurar o track

Para ativar o suporte do highlightjs para a linguagem do teu track, tens de alterar o [ficheiro config.json](/docs/building/tracks/config-json) do track.
Dentro do ficheiro `config.json`, adiciona/define a chave `online_editor.highlightjs_language` com o identificador de linguagem do highlightjs adequado (que podes encontrar na documentação).

#### Exemplo

```json
{
  "online_editor": {
    "highlightjs_language": "csharp"
  }
}
```

### Usar um plugin existente

Para usar um plugin existente, este tem de estar publicado no [NPM](https://www.npmjs.com/).
Se o plugin não estiver publicado no NPM, podes:

1. Perguntar ao autor do plugin se quer publicá-lo no NPM.
2. Fazer fork do repositório e publicá-lo tu próprio.
3. Pedir-nos (ao Exercism) que façamos fork do repositório e o publiquemos.
   Para tal, abre um tópico no [fórum](https://forum.exercism.org/c/exercism/building-exercism/125) a pedir isso.

O passo seguinte é [ativar o plugin](#enable-plugin).

### Ativar o plugin

Para ativar um plugin (que tem de estar publicado no [NPM](https://www.npmjs.com/)), abre um tópico no [fórum](https://forum.exercism.org/c/exercism/building-exercism/125) a pedir-nos que adicionemos suporte para o plugin no site.
Nós (o Exercism) criaremos então um Pull Request que adiciona o plugin ao site.
Depois de o PR ser integrado, podes ativar o suporte do highlightjs seguindo as instruções da secção [Configurar o track](#configuring-track).

### Criar um novo plugin

Se quiseres criar um plugin, tens duas opções de alojamento:

1. Criar um repositório na tua conta pessoal e publicá-lo tu próprio.
2. Pedir-nos (ao Exercism) que criemos um repositório e deixar que sejamos nós a publicá-lo.
   Para tal, abre um tópico no [fórum](https://forum.exercism.org/c/exercism/building-exercism/125) a pedir isso.

Depois de teres um repositório, segue as [instruções para contribuir com uma linguagem](https://highlightjs.readthedocs.io/en/latest/language-contribution.html) para implementares o plugin.

Depois, tens de publicar o plugin no [NPM](https://www.npmjs.com/).
O passo seguinte é [ativar o plugin](#enable-plugin).

### Usar outra linguagem

A sintaxe da tua linguagem é (muito) parecida com a sintaxe de outra linguagem; nesse caso, podes considerar usar o realce de sintaxe dessa linguagem para a tua.
Para isso, configura o track para usar o identificador de linguagem do highlightjs dessa outra linguagem.
Consulta a secção [Configurar o track](#configuring-track) para mais informações.
