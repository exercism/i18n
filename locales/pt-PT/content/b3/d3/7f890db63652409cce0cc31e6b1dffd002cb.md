# Instruções

Neste exercício, vais escrever algum código para te ajudar a preparar a compra de um veículo.

Tens três tarefas: uma para determinar se vais precisar de carta de condução, uma para te ajudar a escolher entre dois veículos e uma para estimar o preço aceitável de um veículo usado.

## 1. Determina se vais precisar de carta de condução

Alguns tipos de veículos exigem carta de condução para serem conduzidos.
Assume que só os tipos `car` e `truck` exigem carta; tudo o resto pode ser conduzido sem carta.

Implementa a função `needs_license(kind)`, que recebe o tipo de veículo e devolve um Boolean que indica se precisas de carta para esse tipo de veículo.

```R
needs_license("car");
# => TRUE

needs_license("bike");
# => FALSE
```

## 2. Escolhe entre dois veículos possíveis para comprar

Avalias as tuas opções de veículos disponíveis.
Consegues reduzi-las a duas opções, mas precisas de ajuda para tomar a decisão final.
Para isso, implementa a função `choose_vehicle(option1, option2)`, que recebe dois veículos como argumentos e devolve uma decisão que é simplesmente a opção que vem primeiro por ordem alfabética.

```R
choose_vehicle("Wuling Hongguang", "Toyota Corolla");
# =>  "Toyota Corolla"

choose_vehicle("Volkswagen Beetle", "Volkswagen Golf");
# =>  "Volkswagen Beetle"
```

## 3. Calcula uma estimativa para o preço de um veículo usado

Agora que tomaste a tua decisão, queres garantir que consegues um preço justo no concessionário.
Como estás interessado em comprar um veículo usado, o preço depende da idade do veículo.
Para uma estimativa aproximada, assume que, se o veículo tiver menos de 3 anos, custa 80% do preço original que tinha quando era novo.
Se tiver mais de 10 anos, custa 50%.
Se o veículo tiver pelo menos 3 anos mas não mais de 10, custa 70% do preço original.

Implementa a função `calculate_resale_price(original_price, age)`.
Recebe o preço original e a idade do veículo como argumentos e devolve o preço estimado no concessionário.

```R
calculate_resale_price(1000, 1);
# => 800

calculate_resale_price(1000, 5);
# => 700

calculate_resale_price(1000, 15);
# => 500
```
