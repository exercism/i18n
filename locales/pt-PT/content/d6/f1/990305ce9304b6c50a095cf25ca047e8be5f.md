# Anexo às instruções

## Instruções adicionais

Vais receber uma tabela chamada "isogram".
A primeira coluna, "phrase", contém algum texto.
Tens de determinar se a frase é um isograma.
Atualiza a segunda coluna, "is_isogram", com um valor inteiro:

* 1 se a frase for um isograma,
* 0 se não for.

~~~~exercism/note
As operações de comparação do SQLite devolvem valores Boolean sob a forma de números 0/1

```sh
$ sqlite3
sqlite> .mode table
sqlite> SELECT 1 < 2 AS "true", 1 > 2 AS "false";
+------+-------+
| true | false |
+------+-------+
| 1    | 0     |
+------+-------+
```
