# Anexo às instruções

## Palavras

Define um tuplo `linked-list-node`.

Define um tuplo `linked-list` e disponibiliza um método `M: linked-list length` (de `sequences`) para que os testes possam chamar `length` diretamente na tua lista.

- `<linked-list> ( -- linked-list )`: constrói uma lista vazia.
- `>linked-list ( seq -- linked-list )`: acrescenta cada elemento de `seq` a uma lista nova, por ordem.
- `linked-list>array ( linked-list -- array )`: devolve os valores, começando pelo topo da lista.
- `list-push ( linked-list value -- linked-list )`: acrescenta um valor ao topo.
- `list-pop ( linked-list -- linked-list value )`: remove e devolve o valor do topo.
- `list-peek ( linked-list -- value )`: devolve o valor do topo sem o remover.
- `list-reverse ( linked-list -- linked-list )`: devolve uma lista com os elementos por ordem inversa.

Lança uma classe de erro `list-empty` a partir de `list-pop` e `list-peek` quando a lista estiver vazia.
