# Testes

Antes de tentares executar os testes, certifica-te de que a pasta do exercício está configurada corretamente, seguindo os passos de instalação, nomeadamente `corepack yarn install` e a configuração do Editor SDK.

Executa os testes com:

```bash
$ corepack yarn test
```

Certifica-te de que o teu código segue as boas práticas, tal como o código de outros utilizadores, com o eslint, uma ferramenta que faz análise estática ao teu código.
Ferramentas como esta poupam-te tempo a detetar gralhas ou erros parvos no teu código:

```bash
$ corepack yarn lint
```

Ou faz as duas coisas ao mesmo tempo:

```bash
$ corepack yarn test && corepack yarn lint
```

O percurso de TypeScript no Exercism não impõe um _estilo_ de código, por isso és livre de escolher entre pontos e vírgulas, tabs ou espaços, e tudo o que fica pelo meio.

## Criar o teu primeiro módulo

Normalmente, os testes deste percurso carregam a tua implementação importando-a como um módulo: `import Bob from './bob';`.
Para que isto funcione, tens de exportar a tua implementação a partir do ficheiro onde os testes procuram o teu módulo, `bob.ts`:

```typescript
export class Bob {
  public hey(message: string) {
    // Your solution here
  }
}
```

Fornecemos esqueletos em cada exercício e já lá colocámos este `export` por ti.
