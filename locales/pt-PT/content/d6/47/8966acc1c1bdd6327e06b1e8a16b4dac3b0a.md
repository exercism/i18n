# Dicas

## Geral

- O [manual de código do Haxe][codebook-strings] tem uma boa introdução às `String` do Haxe.
- A classe `String` tem muitos [métodos incorporados][string-api] úteis.
- A classe `StringTools` disponibiliza ainda [métodos relacionados com strings][stringtools-api].

## 1. Obter a mensagem de uma linha de registo

- A diferença entre os métodos `substr` e `substring` está descrita na [API][string-api] da classe `String`.
- Para remover espaços em branco, podes usar a [API][stringtools-api] da classe `StringTools`.

## 2. Obter o nível de registo de uma linha de registo

- Alterar as maiúsculas e minúsculas de uma `String` faz parte da [API][string-api] da classe `String`.

## 3. Reformular uma linha de registo

- A forma preferida de formatar e concatenar strings é usar [interpolação][interpolation].
