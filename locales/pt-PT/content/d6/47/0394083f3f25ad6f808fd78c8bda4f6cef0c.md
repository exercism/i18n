# Acerca de funções anónimas e fechos

O PHP permite declarar funções dentro de outras funções. Essas funções não precisam de ter nome, mas podem ser atribuídas a variáveis ou até passadas diretamente para outra função que requeira um parâmetro que seja uma função.

```php
function onlyOdds(array $numbers): array
{
    return array_filter($numbers, function($num) {
        return $num % 2 === 1;
    });
}
```

A função definida e passada para `array_filter` acima é uma função anónima. A função `array_filter` usa-a para determinar se um determinado valor de um array será devolvido no resultado do `array_filter`. Se a função devolver `true` para um valor, esse valor será incluído no array de resultado.

As funções anónimas também podem ser usadas para referir, de dentro da função, variáveis que estão no âmbito fora da função. É a isto que se chama «fechar» o âmbito da função sobre a variável que é usada dentro dela; daí o nome «fecho». Nalgumas linguagens, todas as variáveis que estão no âmbito podem ser usadas automaticamente dentro do fecho. No PHP, `$this`, que se refere ao objeto atual, é automaticamente permitido dentro do fecho. Todas as outras variáveis têm de ser referidas explicitamente com a palavra-chave `use`.

```php
function makeAdderFunction(int $number) {
    return function(int $x) use($number) {
        return $x + $number;
    }
}

$add5 = makeAdderFunction(5);
echo $add5(4); // echos 9
```

Na função `makeAdderFunction` acima, o valor de `$number` que é passado fica «fechado» dentro da função anónima definida internamente, que é depois devolvida. A partir daí, sempre que essa função é executada, sabe qual é o valor de `$number` que foi passado. Se chamares esta função outra vez com outro número, obténs uma função completamente diferente. Os valores ou o comportamento devolvidos pela primeira chamada à função não mudam.
Se precisares de fechar sobre mais do que uma variável, podes adicioná-las à palavra-chave `use`, separadas por vírgulas.

O PHP também tem uma sintaxe de função mais curta, chamada `arrow functions`. Têm de ser bastante simples. A forma básica destas é:

```php
fn(arguments) => expression
```

Neste estilo de função, não precisas de usar `use`. Fecha automaticamente sobre quaisquer valores do âmbito pai e captura-os. A expressão nestas arrow functions é devolvida automaticamente, sem precisares da palavra-chave `return`. Isto permite-nos reescrever a função `onlyOdds` acima assim:

```php
function onlyOdds(array $numbers): array
{
    return array_filter($numbers, fn($n) => $n % 2 == 1);
}
```

A `makeAdderFunction` acima podia ser reescrita assim:

```php
function makeAdderFunction(int $number) {
    return fn(int $x) => $x + $number;
}
```

**Nota:** Se a função não puder ser escrita como uma expressão, não podes usar a sintaxe mais curta das arrow functions.

As variáveis são passadas para as funções anónimas e os fechos, e usadas dentro deles, por valor. Isto significa que, se alterares o valor da variável dentro da função, isso não afeta o valor da variável fora da função. Se precisares que o valor seja modificado, podes passá-lo por referência.

```php
function positiveAverage(array $numbers): float
{
    $total = 0;
    $count = 0;
    return array_walk(
      $numbers,
      function($num) use (&$count, &$total) {
          $total += abs($num);
          $count++;
      }
    );
    return $total / $count;
}
```

No exemplo acima, `array_walk` percorre cada elemento do array, enviando cada valor para a função declarada na chamada. Mantém um total acumulado em `$total`, em que cada valor somado é o valor absoluto do número. Registra também quantos números havia. Ambos os valores são usados no fecho por referência, o que é indicado pelo `&` à frente de cada variável na secção `use`. Isto significa que as alterações feitas às variáveis continuam a existir quando o `array_walk` termina, para que a função possa devolver a média dos valores absolutos dos números do array.

As funções anónimas e os fechos podem ser uma forma prática de definir uma função que só é necessária num único contexto, ou de definir uma função que devolve uma função dinâmica com base num conjunto de parâmetros conhecidos numa altura diferente daquela em que a função é realmente usada.
