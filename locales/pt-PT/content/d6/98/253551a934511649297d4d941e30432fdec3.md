# Introdução

Uma [`function`][function] é uma forma de compartimentar o código para que possa ser chamada pelo nome a partir de um ou mais locais do programa.
As funções servem para realizar tarefas específicas e repetitivas.

Mais formalmente: uma função é qualquer objeto Python ao qual se pode aplicar a operação [`function call`][calls].
Uma função pode ser usada para [`return`][return] um ou mais valores como resultado de uma ou mais operações, ou pode ser usada para um ou mais [`side effects`][side effects].
Se uma função não especificar um valor devolvido, ainda assim devolve `None`.

Segue-se um exemplo de uma função com um efeito secundário:

```python
>>> def hello():
...     print("Hello")
...
>>> hello()
Hello

```

No exemplo acima, a palavra-chave [`def`][def] serve para assinalar o início da definição da função.
`hello` é o nome da função.
Os parênteses vazios indicam que não está a ser passado nenhum valor para a função.
O corpo da função é a única instrução `print("Hello")`.
`print` também é uma função.
O `"Hello"` entre os parênteses da função `print` é aquilo a que se chama um [`argument`][arguments].
O argumento é usado pela função `print` para saber o que imprimir.
Repara que o corpo da função está indentado.
A indentação é importante porque o Python depende dela para saber onde termina esse bloco de código.
O corpo da função termina no fim do programa ou imediatamente antes da linha de código seguinte que _não_ está indentada.
Como `hello()` não especifica nenhum valor de `return`, executa o seu efeito secundário, que é chamar `print()`, e depois devolve `None`.
Por fim, chamamos a função usando o seu nome e os parênteses, o que indica ao intérprete Python que este é um nome _callable_.

Segue-se um exemplo de uma função com um valor devolvido:

```python
>>> def hello():
...     return "Hello"
... 
print(hello())
Hello

```

O corpo desta função foi alterado: em vez de _chamar_ `print`, agora _devolve_ a `string` "Hello".
No final, o código continua a imprimir `"Hello"`, mas o efeito secundário ocorre no _código que chama_ em vez de na função `hello`.
Se os parênteses fossem omitidos ao chamar a função `hello` (por exemplo, `print(hello)`), então `print` mostraria algo como

```
<function hello at 0x0000026E18E93E20>
```

É importante que, mesmo que uma função não aceite argumentos (_ou seja, não tenha parâmetros_), seja necessário usar os parênteses vazios para a _chamar_ corretamente.
Isto é diferente de uma linguagem como o Ruby, que não exige parênteses vazios para chamar uma função sem argumentos.

Uma função pode definir zero ou mais [`parameters`][parameters]. Um parâmetro define que argumentos a função aceita.

Segue-se um exemplo de uma função que aceita um argumento:

```python
>>> def hello(name):
...     return f"Hello, {name}"
... 
>>> print(hello("Bob"))
Hello, Bob

```

O parâmetro está definido como `name`.
`"Bob"` é o argumento que o programa passa à função `hello`.
A função _devolve_ a `string` "Hello, Bob".

E se alguém chamar `hello` sem passar um argumento?
O programa dá um erro:

```python
print(hello())
Traceback (most recent call last):

  Input In in <line: 1>
    print(hello())

TypeError: hello() missing 1 required positional argument: 'name'
```

Se não quisermos que o programa dê erro quando não há argumento (_mas quisermos permitir que o código que chama não forneça nenhum_), podemos definir um [argumento por omissão][default arguments].
Um argumento por omissão define que valor usar se o argumento estiver em falta quando a função é chamada.

Segue-se um exemplo de uma função com um argumento por omissão:

```python
>>> def hello(name="you"):
...     return f"Hello, {name}"
... 
>>> print(hello())
Hello, you

```

Ao parâmetro `name` é atribuído o argumento por omissão `"you"`, por isso o programa mostra `Hello, you` se não lhe for passado um argumento `name`.

Para saberes mais sobre argumentos de funções, consulta o conceito [argumentos de funções][function arguments].
