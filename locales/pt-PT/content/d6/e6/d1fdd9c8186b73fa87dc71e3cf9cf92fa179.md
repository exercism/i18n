# Instruções

Estás a escrever o núcleo digital de uma pequena mesa de mistura de um estúdio de gravação.

O som chega como um fluxo de amostras.
Cada amostra é um número que descreve a posição do cone de um altifalante num determinado instante.
Uma mesa de mistura processa um bloco inteiro de amostras de uma só vez, aplicando a mesma operação a cada uma.

Tens cinco tarefas, cada uma a operar sobre um bloco de amostras guardado na memória.
Recebes os operandos através de endereços de memória e escreves o resultado através de um endereço de resultado.

~~~~exercism/note
Os cálculos deste exercício devem ser feitos com instruções SIMD, não com operações escalares.
~~~~

## 1. Misturar duas faixas

Por vezes, o estúdio grava instrumentos em faixas diferentes.
Para os reproduzir nos mesmos altifalantes, somas as duas faixas numa só.

Implementa a função `mix_tracks`, que soma duas faixas, amostra a amostra.
Cada faixa é um bloco de 8 amostras de 16 bits com sinal.
Uma soma que ultrapasse o intervalo de 16 bits com sinal tem de saturar em vez de dar a volta.

Esta função recebe como argumentos, por esta ordem:

- `result`: endereço de memória alinhado a 16 bytes de um buffer onde são escritas as 8 amostras misturadas.
- `track_a`: endereço de memória alinhado a 16 bytes da primeira faixa, com 8 amostras de 16 bits com sinal.
- `track_b`: endereço de memória alinhado a 16 bytes da segunda faixa, com 8 amostras de 16 bits com sinal.

```c
track_a = {10000, 30000, 20000, -30000, -20000, -100,  100, 0}
track_b = { 5000,  5000, 20000,  -5000, -20000,  100, -100, 0}
result  = {15000, 32767, 32767, -32768, -32768,    0,    0, 0}
```

Esta função não devolve nada.

## 2. Remover o bleed

Quando dois microfones gravam ao mesmo tempo, cada um capta uma cópia ténue da fonte do outro.
A esta cópia indesejada chama-se _bleed_.
Depois de medido, esse bleed tem de ser subtraído para limpar a faixa.

Implementa a função `remove_bleed`, que subtrai o bloco de bleed ao bloco da faixa, amostra a amostra.
Cada bloco tem 8 amostras de 16 bits com sinal, e a subtração tem de saturar.

Esta função recebe como argumentos, por esta ordem:

- `result`: endereço de memória onde são escritas as 8 amostras limpas (alinhamento não garantido).
- `track`: endereço de memória alinhado a 16 bytes da faixa gravada, com 8 amostras de 16 bits com sinal.
- `bleed`: endereço de memória do bleed a remover, com 8 amostras de 16 bits com sinal (alinhamento não garantido).

```c
track  = {10000, -30000, 5000, 32767, 0,  200, -200, 15000}
bleed  = { 2000,   5000, 5000,    -5, 0,  300,  300,  5000}
result = { 8000, -32768,    0, 32767, 0, -100, -500, 10000}
```

Esta função não devolve nada.

## 3. Combinar medidores

Por cima de cada canal está um medidor de nível, uma pequena barra cujo brilho mostra o volume desse canal.
O painel frontal tem um medidor principal que deve brilhar tanto como os dois canais juntos.
Somas os dois blocos de medidores para o alimentar.

Repara que um medidor aceso fica no brilho máximo em vez de voltar ao escuro, por isso a soma satura.

Implementa a função `combine_meters`, que soma dois blocos de medidores, amostra a amostra.
Esta função recebe como argumentos, por esta ordem:

- `result`: endereço de memória alinhado a 16 bytes onde são escritos os 16 valores combinados.
- `meter_a`: endereço de memória alinhado a 16 bytes do bloco de medidores do primeiro canal, com 16 valores de 8 bits sem sinal empacotados.
- `meter_b`: endereço de memória alinhado a 16 bytes do bloco de medidores do segundo canal, com 16 valores de 8 bits sem sinal empacotados.

Cada bloco tem 16 valores de 8 bits sem sinal.
Devem ser somados, saturando ao intervalo dos valores sem sinal.

```c
meter_a = {200, 100,  50, 255, 0, 128, 10, 240, 1, 2, 3, 4, 5, 6, 7, 8}
meter_b = {100, 100, 200,   1, 0, 128, 10,  20, 1, 2, 3, 4, 5, 6, 7, 8}
result  = {255, 200, 250, 255, 0, 255, 20, 255, 2, 4, 6, 8, 10, 12, 14, 16}
```

Esta função não devolve nada.

## 4. Aplicar um desvanecimento

A canção não deve parar de repente: deve ir-se desvanecendo no fim.
Tens um bloco de _coeficientes de ganho_, um por amostra, que vão diminuindo cada vez mais.

Cada coeficiente é uma fração com denominador `65536`.
Por exemplo, se uma amostra tem o valor `16384`, na verdade representa `16384 / 65536`, que é `1 / 4`.
O maior valor utilizável, `32767`, fica um pouco abaixo de metade.

Como `65536` é `2^16`, multiplicar uma amostra pelo seu coeficiente e ficar com a _metade superior_ do produto dá `sample * gain / 65536`.

Implementa a função `apply_fade`, que escala cada amostra pelo seu coeficiente.
Esta função recebe como argumentos, por esta ordem:

- `result`: endereço de memória alinhado a 16 bytes onde são escritas todas as amostras escaladas.
- `track`: endereço de memória alinhado a 16 bytes da faixa, com `n` amostras de 16 bits com sinal.
- `gains`: endereço de memória alinhado a 16 bytes dos coeficientes de ganho, com `n` valores de 16 bits com sinal, cada um no intervalo de `0` a `32767`.
- `n`: o número de amostras, que é sempre diferente de zero e múltiplo de `8`, como um inteiro de 64 bits sem sinal.

Repara que a faixa é um array que contém `n` amostras de 16 bits com sinal, em que `n` nunca é zero e é sempre múltiplo de `8`.
Para cada amostra, o resultado escalado são os 16 bits _superiores_ do produto com sinal: `sample * gain`.

```c
track  = {20000, 20000, 20000, 20000, -20000, -20000, -20000, -20000}
gains  = {32767, 24576, 16384,  8192,  32767,  24576,  16384,   8192}
result = { 9999,  7500,  5000,  2500, -10000,  -7500,  -5000,  -2500}
```

~~~~exercism/note
Ficar com a metade superior arredonda em direção a menos infinito.
É por isso que `20000 * 32767` dá `9999`, enquanto `-20000 * 32767` dá `-10000` e não `-9999`.
~~~~

Esta função não devolve nada.

## 5. Atenuar uma faixa

O baterista foi gravado com um volume demasiado alto.
Para baixar a faixa inteira, divides cada amostra por uma constante.

Implementa a função `attenuate_track`.
Esta função recebe como argumentos, por esta ordem:

- `result`: endereço de memória alinhado a 16 bytes onde são escritos os resultados, como inteiros de 32 bits com sinal.
- `samples`: endereço de memória alinhado a 16 bytes das amostras, `n` valores de 16 bits com sinal.
- `divisor`: endereço de memória alinhado a 16 bytes de 4 cópias iguais do divisor, como inteiros de 32 bits.
- `n` é o número de amostras, que é sempre diferente de zero e múltiplo de `4`, como um inteiro de 64 bits sem sinal.

Repara que `samples` é um array que contém `n` amostras de 16 bits com sinal, em que `n` nunca é zero e é sempre múltiplo de `4`.

O divisor é fornecido como `4` cópias do mesmo inteiro de 32 bits, já replicado para poder preencher as quatro vias de uma só vez.

O SIMD inteiro não tem divisão empacotada, por isso o trabalho é feito em vírgula flutuante empacotada e depois convertido de volta em inteiros de 32 bits empacotados, para serem guardados em `result`.
Converte de volta truncando para zero, de modo que um quociente de `2.3` passa a `2` e `-2.3` passa a `-2`.

```c
samples = {300, 150, 90, -120, 100, 50, -50, 7}
divisor = {3, 3, 3, 3}
result  = {100,  50, 30,  -40,  33, 16, -16, 2}
```

Esta função não devolve nada.
