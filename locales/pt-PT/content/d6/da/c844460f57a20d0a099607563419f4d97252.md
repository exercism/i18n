# Introdução

Uma *quotation*, código entre parênteses retos `[ ]`, é ela própria um valor em Factor, tal como um número ou uma string. Podes guardá-la numa variável, colocá-la num array, passá-la a outra palavra e *chamá-la* mais tarde.

## `call`

`call` (no [`kernel`][kernel]) executa uma quotation:

```factor
3 4 [ + ] call .
! => 7
```

Quando chamas uma quotation num contexto em que o Factor não consegue inferir o seu efeito de pilha, tens de declarar o efeito explicitamente:

```
call( stack-effect ) ! e.g. call( a b -- c )
```

```factor
: apply-binary ( a b op -- c )
    call( a b -- c ) ;

5 3 [ - ] apply-binary .
! => 2
```

Isto compila uma verificação em tempo de execução de que a quotation tem realmente o efeito declarado.

## Quotations em sequências

Como as quotations são valores, um array pode conter uma mistura de números e quotations:

```factor
{ 3 4 [ + ] }
```

Isso faz de "um programa" uma sequência normal, e `each` torna-se uma forma natural de o executar:

```
each ( seq quot -- )
```

```factor
{ [ 1 + ] [ 2 * ] } 5 swap [ call( x -- y ) ] each .
! 5 -> 6 -> 12
```

## Cortar o fim de uma sequência

`head*` devolve tudo exceto os últimos `n` elementos; `last2` devolve os dois últimos:

```
head* ( seq n -- headseq )
last2 ( seq -- penultimate last )
```

```factor
{ 1 2 3 4 5 } 2 head* .    ! => { 1 2 3 }
{ 1 2 3 4 5 } last2 .s
! => 4
! => 5
```

Em conjunto com `suffix`, é tudo o que precisas para escrever uma operação de pilha que "consome os dois de cima e empilha um resultado".
