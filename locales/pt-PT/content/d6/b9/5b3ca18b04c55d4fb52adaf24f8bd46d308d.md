# Instruções

Neste exercício, vais escrever código para ajudar um freelancer a comunicar com um gestor de projeto.
A tua tarefa é criar alguns utilitários para calcular rapidamente valores diários e mensais, opcionalmente com um desconto.

Vamos primeiro estabelecer algumas regras entre o freelancer e o gestor de projeto:

- O valor diário é 8 vezes o valor por hora.
- Um mês tem 22 dias faturáveis.

Por vezes, o freelancer oferece-se para aplicar um desconto no valor diário (por exemplo, para os clientes mais fiéis ou para clientes sem fins lucrativos).

Os descontos são representados por números fracionários que representam percentagens, por exemplo, `25.0` (25%).

## 1. Calcula o valor diário a partir de um valor por hora

Implementa uma função chamada `daily_rate` que calcula o valor diário a partir de um valor por hora recebido como parâmetro.
O contrato define que um dia tem 8 horas faturáveis.

```cpp
daily_rate(60)
// => 480.0
```

O valor diário devolvido deve ser do tipo `double`.

## 2. Calcula um preço com desconto

Implementa uma função `apply_discount` que calcula o preço depois de aplicar um desconto.
Deve aceitar dois parâmetros: o preço original e a taxa de desconto em percentagem.

```cpp
apply_discount(150, 10)
// => 135.0
```

O valor devolvido deve ser sempre do tipo `double`, sem qualquer arredondamento.

## 3. Calcula o valor mensal a partir de um valor por hora e de um desconto

Implementa uma função `monthly_rate` que calcula o valor mensal com desconto.
Deve ter dois parâmetros: um valor por hora e o desconto em percentagem.

```cpp
monthly_rate(77, 10.5)
// => 12130
```

O valor mensal devolvido deve ser arredondado para cima, para o número inteiro mais próximo.

## 4. Calcula o número de dias de trabalho completos a partir de um orçamento, de um valor por hora e de um desconto

Implementa uma função `days_in_budget` que recebe um orçamento, um valor por hora e um desconto, e calcula quantos dias completos de trabalho isso cobre.

```cpp
days_in_budget(20'000, 80, 11.0)
// => 35
```

O número de dias devolvido deve ser arredondado para baixo, para o número inteiro mais próximo.
