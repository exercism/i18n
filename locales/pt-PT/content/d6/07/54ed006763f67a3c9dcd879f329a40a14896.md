# Bools

O Crystal tem um tipo conhecido como [`Bool`][bools].
Representa os valores `true` e `false`.

## Operadores lógicos

O Crystal tem três operadores lógicos (`!`, `||`, `&&`), que combinam Bools e formam expressões que produzem valores diferentes.

### E(`&&`)

O [operador _e_][and] em Crystal é representado por `&&` e devolve `true` se ambos os valores forem `true`; caso contrário, devolve `false`.
Quando usas o operador _e_, colocas um Bool à direita do `&&` e outro à esquerda.

```crystal
true && true
# => true

true && false
# => false
```

### Ou(`||`)

O [operador _ou_][or] em Crystal é representado por `||` e devolve `true` se **pelo menos um** dos valores dados for `true`.
Se ambos os valores forem `false`, devolve `false`.
Quando usas o operador _ou_, deves colocar um Bool à direita do `||` e outro à esquerda.

```crystal
true || true
# => true

true || false
# => true

false || false
# => false
```

### Não(`!`)

O operador _não_ em Crystal é representado por `!` e devolve `true` se o Bool dado for `false`, e devolve `false` se lhe for passado `true`.
Quando usas o operador _não_, deves colocar um Bool depois do operador (`!`).

```crystal
!true
# => false

!false
# => true
```

## Usar parênteses(`()`)

Quando trabalhas com Bools, podes usar parênteses para decidir que Bools avaliar primeiro.
O resultado pode ser diferente consoante a forma como usas os parênteses.
Em Crystal, o que está entre parênteses é avaliado primeiro.

```crystal
true && false && false || true
# => true

true && false && (false || true)
# => false
```

Como o que está entre parênteses é avaliado primeiro, no exemplo seguinte o operador _não_ aplica-se à expressão que está dentro dos parênteses.

```crystal
!true && false
# => false

!(true && false)
# => true
```

~~~~exercism/note
Só deves usar parênteses quando afetam o resultado; caso contrário, devem ser omitidos.
~~~~
