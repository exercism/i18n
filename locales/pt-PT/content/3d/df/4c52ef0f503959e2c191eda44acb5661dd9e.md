## 5. Classifica a atividade

- A melhor forma de executar lógica com base no valor da atividade é usar a [correspondência de padrões][pattern-matching].
- A forma de fazer corresponder os casos de uma união discriminada (e, opcionalmente, os respetivos dados associados) é através de [padrões de identificador][identifier-patterns].
- Se quiseres acrescentar uma condição adicional a um padrão, podes adicionar uma [guarda][guards].
- Se quiseres apanhar mais do que um valor de uma só vez, podes usar um [padrão curinga][wildcard-patterns].
