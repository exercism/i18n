# Testes

## clojure.test

O Babashka já vem com o clojure.test incluído. Quando estiveres pronto para trabalhar num exercício e tiveres criado um ficheiro para a tua solução (como `bob.clj`), podes correr os testes com `clojure.test/run-tests` [como descrito aqui](http://clojure.github.io/clojure/clojure.test-api.html#clojure.test/run-tests).


O REPL permite-te correr código facilmente e obter feedback imediato, e também pode ser usado para correr testes. Recomenda-se o uso do `rlwrap` para ativar a edição de linha e o histórico de comandos com as setas para cima e para baixo. Para testar um exercício, muda para o diretório dele e abre um socket REPL, adicionando os diretórios `src` e `test` ao classpath:
``` bash
/bob $ rlwrap bb --classpath src:test socket-repl 1666
```

Primeiro, faz `require` do namespace de teste:
``` clojure
=> (require 'bob-test)
nil
```

Depois, chama `run-tests` a `bob-test`:
``` clojure
=> (clojure.test/run-tests 'bob-test)

Testing bob-test

Ran 25 tests containing 25 assertions.
0 failures, 0 errors.
{:test 25, :pass 25, :fail 0, :error 0, :type :summary}
```

Para criar um script que corre os testes:

``` clojure
#!/usr/bin/env bb

(require '[clojure.test :as t]
         '[babashka.classpath :as cp])

(cp/add-classpath "src:test")                        

(require 'bob-test)                  

(def test-results
  (t/run-tests 'bob-test))           

(def failures-and-errors
  (let [{:keys [:fail :error]} test-results]
    (+ fail error)))                                 

(System/exit failures-and-errors)
```
