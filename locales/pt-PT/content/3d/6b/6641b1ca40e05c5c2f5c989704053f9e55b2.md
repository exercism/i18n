# Instruções

O exercício introdutório clássico.
Diz apenas "Hello, World!".

O ["Hello, World!"][hello-world] é o tradicional primeiro programa para quem está a começar a programar numa nova linguagem ou ambiente.

Os objetivos são simples:

- Altera o código fornecido para que produza a string "Hello, World!".
- Corre o conjunto de testes e certifica-te de que todos passam.
- Submete a tua solução e verifica-a no site.

Se tudo correr bem, estarás pronto para obter o teu primeiro exercício real.

[hello-world]: https://en.wikipedia.org/wiki/%22Hello,_world!%22_program
