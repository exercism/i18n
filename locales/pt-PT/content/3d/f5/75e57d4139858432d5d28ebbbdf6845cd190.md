# Introdução

O Haxe suporta reflexão de tipos e de campos em tempo de execução. Para usar a reflexão corretamente, é necessário compreender que tipo de operações são suportadas e quais não são. Dada a natureza dinâmica da reflexão, nem sempre é possível determiná-lo em tempo de compilação.

A API de reflexão é composta por duas classes:

- `Reflect`: uma API leve, que funciona melhor com estruturas anónimas e tem suporte limitado para classes.
- `Type`: uma API mais robusta para trabalhar com classes e enums.

No exemplo seguinte, vamos usar o target JavaScript:

```haxe
class Main {
  public static function main() {
    trace(Type.resolveClass("Main"));
  }
}

// This outputs
// class Test { static main() { console.log("Test.hx:3:",$hxClasses["Test"]); } }
```
