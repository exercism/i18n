# Instruções

És um observador de aves entusiasta que regista quantas aves visitaram o teu jardim nos últimos sete dias.

Tens cinco tarefas, todas relacionadas com o número de aves que visitaram o teu jardim.

## 1. Verifica quais foram as contagens da semana passada

Para efeitos de comparação, guardas sempre por perto uma cópia das contagens da semana passada, que foram: 0, 2, 5, 3, 7, 8 e 4. Implementa o método `BirdCount.last_week`, que devolve as contagens da semana passada:

```ruby
BirdCount.last_week
# => [0, 2, 5, 3, 7, 8, 4]
```

## 2. Verifica quantas aves visitaram ontem

Implementa o método `BirdCount#yesterday` para devolver quantas aves visitaram o teu jardim ontem. As contagens de aves estão ordenadas por dia: o primeiro elemento é a contagem do dia mais antigo e o último é a contagem de hoje.

```ruby
birds_per_day = [2, 5, 0, 7, 4, 1]
bird_count = BirdCount.new(birds_per_day)
bird_count.yesterday
# => 4
```

## 3. Calcula o número total de aves que visitaram o jardim

Implementa o método `BirdCount#total` para devolver o número total de aves que visitaram o teu jardim:

```ruby
birds_per_day = [2, 5, 0, 7, 4, 1]
bird_count = BirdCount.new(birds_per_day)
bird_count.total
# => 19
```

## 4. Calcula o número de dias movimentados

Alguns dias são mais movimentados do que outros. Um dia movimentado é aquele em que cinco ou mais aves visitaram o teu jardim.
Implementa o método `BirdCount#busy_days` para devolver o número de dias movimentados:

```ruby
birds_per_day = [2, 5, 0, 7, 4, 1]
bird_count = BirdCount.new(birds_per_day)
bird_count.busy_days
# => 2
```

## 5. Verifica se houve algum dia sem aves a visitar o jardim

Implementa o método `BirdCount#day_without_birds?` que devolve `true` se houve um dia em que zero aves visitaram o jardim; caso contrário, devolve `false`:

```ruby
birds_per_day = [2, 5, 0, 7, 4, 1]
bird_count = BirdCount.new(birds_per_day)
bird_count.day_without_birds?
# => true
```
