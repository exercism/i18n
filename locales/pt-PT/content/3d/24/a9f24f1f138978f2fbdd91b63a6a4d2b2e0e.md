# Introdução

## Noções básicas

Em F#, dar um valor a um nome é designado por _associação_. As associações são imutáveis, o que as torna semelhantes às constantes de outras linguagens. Como o F# é uma linguagem de tipagem estática, cada associação tem um tipo em tempo de compilação.

As associações definem-se com a palavra-chave `let`. Especificar o tipo de uma associação é opcional para a maioria das associações, porque a _inferência de tipos_ do F# consegue normalmente inferir o tipo a partir do seu valor. Uma associação tem este aspeto:

```fsharp
// Automatically inferred type
let fingers = 10
```

As funções também são associações normais, mas com um ou mais parâmetros. Uma função devolve automaticamente a sua última expressão. A inferência de tipos também funciona para a maioria das funções, analisando com que valores a função é chamada e que valor devolve.

```fsharp
// Automatically inferred types for parameters and return type
let add x y = x + y
```

Para invocar uma função, indicas o seu nome e passas argumentos para cada um dos parâmetros da função.

```fsharp
let five = add 2 3
```

Se não for possível inferir o tipo de uma associação, o compilador dá um erro. Para corrigir isto, acrescenta uma anotação de tipo explícita à associação.

```fsharp
// Explicit type annotation
let fingers: int = 10

// Explicit type annotation (also for parameters)
let add (x: int) (y: int): int = x + y
```

Em F#, as associações só podem ser usadas _depois_ de terem sido definidas. Usar uma associação antes de a definires dá origem a um erro de compilação.

```fsharp
// Compile error as the add binding has not yet been defined
// let seven = add 3 4

let add x y = x + y
```

O F# usa espaços em branco significativos para definir o âmbito. Isto significa que o âmbito é definido pela indentação do código com espaços, em relação à linha que declara a associação. A convenção predefinida é usar quatro espaços de indentação:

```fsharp
let toes =
    let left = 5
    let right = 5
    left + right

let multiplyPlusTwo x y =
    let product = x * y
    product + 2

// Trying to access the left, right or product bindings
// here would result in a compile error
```

As associações do F# (que incluem as funções) organizam-se habitualmente em módulos. Um módulo agrupa funcionalidades relacionadas e é definido com a palavra-chave `module`. A definição do módulo tem de vir antes das suas associações:

```fsharp
module Calculator

let pi = 3.14

let add x y = x + y
```

O F# suporta dois tipos de comentários. Os comentários de uma linha são precedidos de `//` e os comentários de várias linhas são inseridos entre `(*` e `*)`.
