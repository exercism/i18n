# Introdução


## Booleanos

O PowerShell tem o tipo [`bool`][booleans] para representar valores booleanos: verdadeiro e falso.
Neste tipo há apenas dois valores: `True` e `False`.
Podes associar estes valores a variáveis com o prefixo `$`:

```powershell
> $TrueVar  = $true
> $FalseVar = $FALSE
#Case senstitivity doesn't matter here
```

Podemos usar [operadores lógicos][logical-operators] como `-and`, `-or` e `-not` para combinar e avaliar expressões booleanas.

```powershell
> $TrueVar  = $true -and $true
> $FalseVar = $true -and $false

> $TrueVar  = $true -or $false
> $FalseVar = $false -or $false

> $TrueVar  = -not $false
> $FalseVar = -not $true
```


## Ajuda baseada em comentários

A [`Comment-based help`][comment-based help] do PowerShell ajuda a fornecer informação detalhada sobre funções e scripts, escrita em comentários.
Utiliza palavras-chave especiais nos comentários de ajuda para indicar os tópicos em foco, como `.SYNOPSIS`, `.EXAMPLE` ou `.NOTES`.

```powershell
function ExampleFunction($Arg) {
    <#
    .DESCRIPTION
    A detailed description of the function or script. This keyword can be used only once in each topic.

    .PARAMETER Arg
    The description of a parameter, it must be follow with the parameter name.
    #>
}
```

Podes ver a informação da ajuda baseada em comentários com o cmdlet `Get-Help`.

```powershell
> Get-Help -Name "ExampleFunction"
```
