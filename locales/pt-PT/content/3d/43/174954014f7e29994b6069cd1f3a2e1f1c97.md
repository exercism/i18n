# APRENDIZAGEM

O Vim já vem com uma excelente documentação integrada. A interface para a documentação é o comando `:help`.

Para uma introdução, vê `:h user-manual`.

Quase todas as instalações do Vim também incluem um tutorial interativo:

```
$ vimtutor
```

O Vim já existe há décadas e continua popular. Encontras muitos recursos sobre ele na Internet, uns melhores do que outros. Os bons estão listados [aqui](https://exercism.org/docs/tracks/vimscript/resources).
