# Instruções

O caderno de um detetive enche-se à medida que um caso avança e volta a esvaziar-se à medida que as linhas de investigação vão sendo descartadas.

As cinco tarefas vão todas para a classe `CASE_NOTES`.

## 1. Abre um caso

Devolve um caderno novo e vazio.

```sather
notes ::= CASE_NOTES::new_case;
notes.size
-- => 0
```

## 2. Regista uma pista

Adiciona uma pista ao fim do caderno. Isto não devolve nada: altera o caderno que recebe.

```sather
CASE_NOTES::add_clue(notes, "muddy boots");
notes.size
-- => 1
```

## 3. Quantas pistas?

```sather
CASE_NOTES::clue_count(notes)
-- => 1
```

## 4. Descarta uma pista

Retira do caderno a pista que está numa determinada posição. Tudo o que vem depois sobe uma posição. Isto também não devolve nada.

```sather
CASE_NOTES::rule_out(notes, 0);
```

## 5. Relê o caso

Devolve todas as pistas do caderno, unidas com `"; "`. Um caderno vazio lê-se como a string vazia.

```sather
CASE_NOTES::summary(notes)
-- => "muddy boots; broken window"
```
