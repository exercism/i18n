# Instruções

Um espetáculo de circo é uma ordem de apresentação de números. Cada número funciona de forma completamente diferente por dentro, e quem monta o espetáculo precisa das mesmas duas coisas de cada um deles.

Este é o primeiro exercício em que escreves várias classes num só ficheiro. O esqueleto dá-te a classe abstrata. Escreve as restantes por baixo dela.

## 1. Os três números

Escreve três classes, cada uma um `$ACT`.

| Classe | `name` | `minutes` |
| --- | --- | --- |
| `JUGGLING` | `"Juggling"` | 5 |
| `TUMBLING` | `"Tumbling"` | 3 |
| `TRAPEZE` | `"Trapeze at "` then the height then `"m"` | 8 |

`JUGGLING` e `TUMBLING` são criados sem argumentos. `TRAPEZE` é criado com a altura em metros:

```sather
#JUGGLING
#TRAPEZE(4)
```

por isso `#TRAPEZE(4).name` é `"Trapeze at 4m"`.

## 2. O espetáculo

Escreve uma classe `CIRCUS_ACTS` com três rotinas, cada uma das quais recebe a ordem de apresentação como um `ARRAY{$ACT}`.

**`total_minutes`**: quanto tempo demora o espetáculo todo.

```sather
CIRCUS_ACTS::total_minutes(|#JUGGLING, #TUMBLING|)
-- => 8
```

**`billing`**: os nomes dos números, unidos com `", "`.

```sather
CIRCUS_ACTS::billing(|#JUGGLING, #TUMBLING|)
-- => "Juggling, Tumbling"
```

**`longest`**: o nome do número que demora mais tempo. Quando dois são iguais, ganha o que vem primeiro. Um espetáculo vazio não tem número mais longo, por isso a resposta é `""`.

```sather
CIRCUS_ACTS::longest(|#JUGGLING, #TUMBLING|)
-- => "Juggling"
```

Nenhuma das três pode perguntar que tipo de número tem.
