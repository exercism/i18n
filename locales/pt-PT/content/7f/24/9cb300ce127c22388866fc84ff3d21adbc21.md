# Aprender

## Aprender D

Em geral, o Exercism parte do princípio de que já conheces a sintaxe e os mecanismos da linguagem que estás a aprender. No entanto, conhecer a sintaxe de uma linguagem é apenas o primeiro passo para ganhares mestria nessa linguagem. O Exercism permite-te praticar a resolução de problemas e partilhar discussões com outros programadores que já resolveram o mesmo problema. É da discussão partilhada que retiramos experiência e uma compreensão mais profunda, que nos tornam melhores programadores.

Aqui tens alguns recursos para começares:

* [Aprender D como principiante](http://ddili.org/ders/d.en/index.html), o excelente livro de Ali Cehreli
* [Aprender D para programadores com experiência](http://wiki.dlang.org/Coming_From) para quem vem de outras linguagens
* [Tutoriais de D](https://wiki.dlang.org/Tutorials)
* [Visão geral das funcionalidades únicas de D](http://dlang.org/overview.html)
* [Perguntas frequentes sobre D](http://dlang.org/faq.html)
* [DConf](http://dconf.org/2016/index.html): apresentações e vídeos no YouTube

Para obteres mais ajuda:

* Coloca as tuas perguntas no canal IRC [#d](irc://irc.freenode.net/d) no freenode ([interface web](https://kiwiirc.com/client/irc.freenode.net/d))
* Pede ajuda em [D.learn](http://forum.dlang.org/group/learn)
* Abre uma questão no [rastreador de erros do D](https://issues.dlang.org/)

## Desenvolvimento orientado a testes

O Exercism parte do princípio de que já conheces o conceito de desenvolvimento orientado a testes. Cada exercício vem com uma série de testes já escritos para ti. Percorres o exercício um teste de cada vez, escrevendo a implementação de forma incremental para satisfazer os testes.
