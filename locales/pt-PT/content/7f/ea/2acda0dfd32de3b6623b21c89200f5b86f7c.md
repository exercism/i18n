# Instruções

Neste exercício, vais implementar uma forma de acompanhar os recordes do jogo mais popular do teu salão de jogos.

Tens 5 funções para implementar, a maioria relacionadas com a manipulação de um objeto que guarda recordes.

## 1. Cria uma nova tabela de recordes

Cria uma função `createScoreBoard` que cria um objeto que serve de tabela de recordes.
As chaves deste objeto serão os nomes dos jogadores e os valores serão as suas pontuações.
Para efeitos de teste, queres incluir diretamente uma entrada no objeto.
Esta entrada inicial deve ser composta por `The Best Ever` como nome do jogador e `1000000` como pontuação.

```javascript
createScoreBoard();
// returns an object with one initial entry
```

## 2. Adiciona jogadores a uma tabela de recordes

Para adicionar um jogador à tabela de recordes, define a função `addPlayer`.
Aceita 3 parâmetros:

- O primeiro parâmetro é um objeto de tabela de recordes existente.
- O segundo parâmetro é o nome de um jogador, como string.
- O terceiro parâmetro é a pontuação, como número.

A função devolve o mesmo objeto de tabela de recordes que recebeu, depois de adicionar o novo jogador.

```javascript
addPlayer({ 'Dave Thomas': 0 }, 'José Valim', 486373);
// => {'Dave Thomas': 0, 'José Valim': 486373}
```

## 3. Remove jogadores de uma tabela de recordes

Se os jogadores violarem as regras do salão de jogos, são removidos manualmente da tabela de recordes.
Define `removePlayer`, que recebe 2 parâmetros:

- O primeiro parâmetro é um objeto de tabela de recordes existente.
- O segundo parâmetro é o nome do jogador, como string.

Esta função deve remover da tabela a entrada do jogador indicado e devolver a tabela em seguida.
Se o jogador não estiver na tabela, não deve acontecer nada à tabela.
Deve ser devolvida tal como está.

```javascript
removePlayer({ 'Dave Thomas': 0 }, 'Dave Thomas');
// => {}

removePlayer({ 'Dave Thomas': 0 }, 'Rose Fanaras');
// => { 'Dave Thomas': 0 }
```

## 4. Aumenta a pontuação de um jogador

Se um jogador terminar outro jogo no salão, uma certa quantidade de pontos será adicionada à pontuação anterior na tabela.
Implementa `updateScore`, que recebe 3 parâmetros:

- O primeiro parâmetro é um objeto de tabela de recordes existente.
- O segundo parâmetro é o nome do jogador cuja pontuação deve ser aumentada.
- O terceiro parâmetro é a pontuação que queres **adicionar** à pontuação guardada.

A função deve devolver a tabela depois de feita a atualização.

```javascript
updateScore({ 'Freyja Ćirić': 12771008 }, 'Freyja Ćirić', 73);
// => {"Freyja Ćirić", 12771081}
```

## 5. Aplica os pontos de bónus de segunda-feira

O salão de jogos mantém uma tabela de recordes separada às segundas-feiras.
No fim do dia, cada jogador dessa tabela recebe 100 pontos adicionais.

Implementa a função `applyMondayBonus`, que aceita uma tabela de recordes.
A função adiciona os pontos de bónus a cada jogador que esteja listado nessa tabela.
Depois, devolve a tabela.

```javascript
const scoreBoard = {
  'Dave Thomas': 44,
  'Freyja Ćirić': 539,
  'José Valim': 265,
};

applyMondayBonus(scoreBoard);
// => { 'Dave Thomas': 144, 'Freyja Ćirić': 639, 'José Valim': 365 }
```
