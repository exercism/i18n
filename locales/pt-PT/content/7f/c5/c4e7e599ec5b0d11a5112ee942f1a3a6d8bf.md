# Anexo às instruções

## Implementação

Este exercício introduz os [genéricos](https://docs.oracle.com/javase/tutorial/java/generics/index.html).
Para os testes passarem, tens de construir a tua classe de modo a que aceite qualquer tipo de valor, por exemplo `Integer` ou `String`.

Os genéricos são úteis porque te permitem escrever código mais geral e reutilizável.
As implementações [List](https://docs.oracle.com/javase/8/docs/api/java/util/List.html) e [Map](https://docs.oracle.com/javase/8/docs/api/java/util/Map.html) do Java são ambas exemplos de classes que usam genéricos.
Ao usá-las, podes construir uma `List` que contém `Integers` ou uma lista que contém `Strings` ou qualquer outro tipo.

Há algumas restrições nos tipos usados com genéricos.
Uma delas é que, depois de construíres uma `List` que contém `Integers`, já não podes colocar `Strings` lá dentro.
Tens de especificar que tipo queres colocar na classe quando a constróis, e essa instância só pode depois ser usada com esse tipo.

Por exemplo, podias construir uma lista de `Integers`:

`List<Integer> someList = new LinkedList<>();`

Agora, `someList` só pode conter `Integers`. Também podias fazer:

`List<String> someOtherList = new LinkedList<>()`

Agora, `someOtherList` só pode conter `Strings`.

Outra restrição é que qualquer tipo usado com genéricos não pode ser um [tipo primitivo](https://docs.oracle.com/javase/tutorial/java/nutsandbolts/datatypes.html), como `int` ou `long`.
No entanto, todos os tipos primitivos têm um tipo de referência correspondente, por isso, em vez de `int` podes usar [`Integer`](https://docs.oracle.com/javase/8/docs/api/java/lang/Integer.html) e, em vez de `long`, podes usar [`Long`](https://docs.oracle.com/javase/8/docs/api/java/lang/Long.html).

Pode ajudar olhar para um [exemplo de caso de uso de genéricos](https://docs.oracle.com/javase/tutorial/java/generics/types.html) para começares.
