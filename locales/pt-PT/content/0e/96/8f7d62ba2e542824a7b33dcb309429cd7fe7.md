# Testes

## Correr os testes

Para correr os testes, executa o seguinte comando na pasta do exercício:

```shell
make
```

Isto monta a tua solução, compila os testes, liga-os num programa RISC-V e executa-o com o `qemu-riscv32`.
O programa imprime uma linha por cada teste, indicando se passou, falhou ou foi ignorado, e no fim mostra um resumo.

## Resolver o exercício

Resolver um exercício significa fazer com que todos os testes passem.
Por omissão, quando corres os testes só é executado um teste (o primeiro).
Isto é intencional: assim podes concentrar-te apenas em fazer passar esse teste.
Assim que passar, podes ativar o teste seguinte removendo a linha `TEST_IGNORE();`.
Quando tiveres ativado todos os testes e a tua implementação fizer com que passem todos, terás resolvido o exercício!
