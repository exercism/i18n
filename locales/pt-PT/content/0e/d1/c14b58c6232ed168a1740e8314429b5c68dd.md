# Malabarismo de tipos

O malabarismo de tipos também pode ser conhecido como coerção de tipos.
O malabarismo de tipos acontece quando dois valores de tipos diferentes são convertidos no mesmo tipo para realizar uma operação.

```php
$baskets = 5 // int
$apples_per_basket = "3" // string
$baskets * $apples_per_basket
# => 15
```

Isto pode acontecer de forma implícita (vê o exemplo acima) ou explícita, com uma conversão de tipos ao estilo do `C`:

```php
$apples_per_basket = "3" // string
$my_number = (int) $apples_per_basket // cast string to int
# => 3 // int
```

Os tipos permitidos para a conversão manual de tipos são: `bool`, `int`, `float`, `string`, `array`, `object`.
O mais comum é usar a conversão de tipos para transformar um número inteiro (`int`) num número de vírgula flutuante (`float`), ou vice-versa.
