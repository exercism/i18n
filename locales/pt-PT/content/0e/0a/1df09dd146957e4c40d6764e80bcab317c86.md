# Introdução

Um *tuplo* agrupa vários valores nomeados num único objeto: aquilo a que outras linguagens chamam registo, struct ou classe. Cada classe de tuplo tem um conjunto fixo de fendas nomeadas, e o Factor gera automaticamente getters e setters para elas.

## Definir um tuplo

```factor
TUPLE: point
    { x initial: 0 }
    { y initial: 0 } ;
```

Cada fenda é declarada como `{ name initial: default-value }`. Sem a cláusula `initial:`, o valor predefinido é `f`.

## Construir um tuplo

O construtor mais simples é `new`:

```factor
point new .
! => T{ point }
```

`boa` («por ordem dos argumentos») preenche as fendas pela ordem de declaração, a partir da pilha de dados:

```factor
3 4 point boa .
! => T{ point { x 3 } { y 4 } }
```

A sintaxe literal `T{ class { slot value } … }` permite-te construir um tuplo com apenas um subconjunto de fendas definidas, e imprime-se da mesma forma:

```factor
T{ point { x 3 } } .
! => T{ point { x 3 } }
```

Quando o valor de uma fenda corresponde ao predefinido, ele é omitido na impressão.

## Ler uma fenda

O Factor gera um getter `slot>>` para cada fenda. Os getters vivem em [`accessors`][accessors]:

```factor
T{ point { x 3 } { y 4 } } x>> .
! => 3
```

## Atualizar uma fenda

Os setters escrevem-se `>>slot` e *modificam* o tuplo no local:

```factor
T{ point { x 3 } { y 4 } } 10 >>x .
! => T{ point { x 10 } { y 4 } }
```

Para deixares o original intacto, faz `clone` primeiro:

```factor
: shifted ( pt -- pt' )
    clone 10 >>x ;
```

`change-slot` recebe uma quotation que transforma o valor atual no novo:

```factor
: shift-x ( pt dx -- pt )
    [ + ] curry change-x ;
```

`change-x` também modifica o tuplo, por isso faz `clone` antes de a chamares, se quiseres preservar o original.
