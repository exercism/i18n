# Introdução

Os operadores ternários permitem definir condições `if` em expressões em vez de blocos de instruções. Isto reflete as abordagens da programação funcional e, muitas vezes, torna o código mais expressivo e menos propenso a erros.

O operador ternário combina três expressões: uma condição seguida de uma expressão a avaliar e a devolver se a condição for verdadeira (a parte `if`, introduzida por `?`) e uma expressão a avaliar e a devolver se a condição for falsa (a parte `else`, introduzida por `:`).

```csharp
int a = 3, b = 4;
int max = a > b ? a : b;
// => 4
```
