# Anexo às instruções

Cada lista de valores de entrada é representada como uma string, com um caráter de nova linha no fim de cada valor de entrada.

Um exemplo seria `"nail\nshoe\nhorse\nrider\nmessage\nbattle\nkingdom\n"`

Cada linha de saída deve terminar com um caráter de nova linha `\n`.

## Memória reservada

Os bytes 128-383 da memória linear estão reservados para a string de entrada.
