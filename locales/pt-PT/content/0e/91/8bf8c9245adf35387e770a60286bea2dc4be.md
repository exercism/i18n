# Acerca de

Um número de vírgula flutuante é um número com zero ou mais algarismos depois do separador decimal.
Alguns exemplos são `4.0`, `0.1`, `3.14`, `-6.4` `16.984025` e `1024.0`.
No Ruby, os números de vírgula flutuante são implementados através da classe [Float][Float].

Podes encontrar uma breve introdução aos números de vírgula flutuante em [0.30000000000000004.com][0.30000000000000004.com].

A [página Float Toy][evanw.github.io-float-toy] tem uma explicação gráfica interessante de como os bits de um número de vírgula flutuante são convertidos num valor de vírgula flutuante real.

Para executar lógica repetidamente, podes usar ciclos.
Neste exemplo, o ciclo `while` é útil porque continua a repetir _enquanto_ uma condição for avaliada como um valor truthy (ou seja, não `false` nem `nil`).
O Ruby tem um ciclo semelhante ao ciclo `while`.
Chama-se ciclo `until` e provavelmente já adivinhaste o que faz.
Continua a repetir _até_ uma condição Boolean ser avaliada como `true`.
Em algumas linguagens, para fazer com que um bloco de código seja executado um número ilimitado de vezes, usam-se construções como `while true`.
No Ruby, o ciclo `loop` existe precisamente para isso.
Embora o ciclo `loop` não dependa de uma única condição, pode ser cancelado com a palavra-chave `return` ou `break`.

O método `#years_before_desired_balance` do exercício anterior podia ter sido escrito com qualquer um dos três ciclos mencionados:

## `while`

```ruby
def self.years_before_desired_balance(current_balance, desired_balance)
  years = 0
  while current_balance < desired_balance
    current_balance = annual_balance_update(current_balance)
    years += 1
  end
  years
end
```

## `until`

```ruby
def self.years_before_desired_balance(current_balance, desired_balance)
  years = 0
  until current_balance >= desired_balance
    current_balance = annual_balance_update(current_balance)
    years += 1
  end
  years
end
```

## `loop`

```ruby
def self.years_before_desired_balance(current_balance, desired_balance)
  years = 0
  loop do
    current_balance = annual_balance_update(current_balance)
    years += 1
    return years if current_balance >= desired_balance
  end
end
```

Como provavelmente já reparaste, o Ruby não tem um operador de incremento (`i++`) como algumas outras linguagens.
Em vez disso, podes usar construções como `i += 1` (que é equivalente a `i = i + 1`).
