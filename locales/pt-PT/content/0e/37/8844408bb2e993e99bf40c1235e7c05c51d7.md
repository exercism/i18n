# Recursos

- [A documentação da linguagem de programação Zig][documentation] é uma excelente visão geral de todas as funcionalidades que a linguagem Zig oferece a quem a utiliza.
- [A biblioteca padrão do Zig][std] é uma boa referência para aprenderes como se escreve código Zig e mostra muitas das funções que podes importar para o teu próprio código.
- [Awesome Zig][awesome-zig] é uma lista curada de projetos Zig.
- [#zig][irc] no irc.freenode.net é o principal canal de IRC do Zig.
- [O Stack Overflow][stack-overflow] pode ser usado para descobrir excertos de código e soluções para problemas que já podem ter sido colocados e talvez resolvidos por outras pessoas.
- [/r/Zig][reddit] é o principal subreddit do Zig.
- [O Discord da linguagem de programação Zig][discord-zig] é o principal [Discord][discord].
  Proporciona uma ótima forma de contactares com a comunidade Zig em geral e de obteres ajuda rápida e direta para qualquer problema relacionado com Zig.
- [A newsletter Zig SHOWTIME][newsletter] anuncia novos episódios, eventos importantes e ligações para novos projetos Zig interessantes.
