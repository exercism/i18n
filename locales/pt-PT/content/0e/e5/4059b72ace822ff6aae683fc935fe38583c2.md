# Sobre

Imagina que tens uma base de código com várias centenas de milhares de linhas. Num método que estás a desenvolver, recebes o dicionário de programadores. Talvez te tenham incumbido de imprimir os detalhes de programadores privilegiados. Decides apagar a cor dos olhos no dicionário para proteger a privacidade dos programadores. A não ser que se tenha feito uma [cópia profunda][so-deep-copy] do dicionário no método `Authenticator.GetDevelopers()`, ou, melhor ainda, que este tenha sido envolvido numa coleção só de leitura, terás acabado de destruir o autenticador.

Isto segue o princípio de [cópia defensiva][defensive-copying]. Podes garantir que a tua API formal não é contornada ao evitares expor aos chamadores o estado interno que pode ser escrito.

[so-deep-copy]: https://stackoverflow.com/questions/78536/deep-cloning-objects
[defensive-copying]: https://www.informit.com/articles/article.aspx?p=31551&seqNum=2
