# Introdução

Um `Map` serve para guardar pares de **chave** e **valor**. Os `Map` são inicializados tal como um array, mas usam o operador de literal de map `=>`. Também podes definir explicitamente os tipos de chave e valor, ou deixar que os tipos sejam inferidos. As chaves têm de ser únicas, caso contrário é lançado um erro.

```haxe
var map1:Map<Int, String> = [1 => "one", 2 => "two", 3 => "three"];

var map2 = ["one" => 1, "two" => 2, "three" => 3];

var map3 = [1 => "cat", 1 => "dog"]; // Error: Duplicate Key

var map4 = ["h" => "Hello", "b" => "Bye"];
trace(map4["h"]); // Hello
```

Podes iterar um `Maps` com um ciclo `for`. Podes iterar sobre os valores ou sobre as chaves:

```haxe
for (value in map) {
  // ...
}

for (key in map.keys()) {
  // ...
}
```
