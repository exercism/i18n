# Introdução

Uma propriedade em C# é um membro de uma classe que dá acesso aos dados dentro dessa classe.
Quem chama pode definir ou obter (get) os dados. As propriedades podem ser autoimplementadas ou
ter um campo de suporte. São compostas por um acessador set e/ou um acessador get.
Em algumas outras linguagens, um "mutator" é mais ou menos equivalente a
um acessador set e um "accessor" é mais ou menos equivalente a um acessador get, embora
a composição da sintaxe seja completamente diferente.

Ao definir uma propriedade, o valor de entrada pode ser validado, formatado
ou manipulado de outra forma. De facto, qualquer operação programática acessível ao código da
classe pode ser executada.

Do mesmo modo, ao obter uma propriedade, os dados podem ser calculados ou formatados e, uma
vez mais, qualquer operação programática disponível para a classe pode ser executada.

As propriedades têm modificadores de acesso (`public`, `private`, etc.) tal como os outros
membros da classe, mas o acessador set pode ter um nível de acesso independente do acessador
get (de obtenção) e vice-versa. Uma propriedade não tem de ter os dois acessadores; pode ter apenas um (get ou set).

A sintaxe básica para expressar propriedades pode assumir duas formas:

## Propriedades com campo de suporte ou expressão:

```csharp
private int myField;
public int MyProperty
{
    get { return myField; }
    set { myField = value; }
}
```

## Propriedades autoimplementadas

```
public int MyProperty { get; private set; } = 42;
```

A inicialização é opcional.
