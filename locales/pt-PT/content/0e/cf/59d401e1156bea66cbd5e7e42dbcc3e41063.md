# Introdução

É possível aceder a carateres individuais de uma `String` usando a sintaxe de subscrito que se usa com arrays.
No entanto, os [índices][string-indices] usados nas strings _não_ são números inteiros e não é possível trabalhar com eles diretamente.
Em vez disso, têm de ser calculados com base noutro índice conhecido, como `startIndex`, que aponta para a posição do primeiro caráter numa string não vazia, usando os métodos disponíveis nas bibliotecas [`String`][string-docs] e [`NSString`][nsstring-docs] (quando o módulo `Foundation` é importado, as strings em Swift têm acesso a todas as propriedades e métodos de NSString).

Por exemplo, dada a seguinte string:

```swift
let csv = "apple,pear,peach,orange,cherry,lime,goosberry"
```

Não se pode escrever `csv[21]` para obter o "g" em "orange"; em vez disso, é preciso calcular um valor do tipo `String.Index` e fornecer esse índice.
Repara que estes índices não foram feitos para serem compreendidos diretamente por humanos.
São o que se chama de _índices opacos_, pois os humanos não precisam de saber o que está lá dentro.

```swift
let index = csv.index(csv.startIndex, offsetBy: 21)
csv[index]
// "g"
print(index)
// prints Index(_rawBits: 1376513)
```

Repara, no entanto, que se o deslocamento não for um índice válido, ou seja, se devolver o índice antes de `startIndex` ou depois de `endIndex`, a operação vai gerar um erro e fazer o programa terminar de forma abrupta.
Para evitar este problema, podes especificar um índice limitante.
Isto devolve um índice opcional e devolve nil para índices que de outra forma seriam inválidos.

```swift
let tooFar = csv.index(csv.startIndex, offsetBy: 200)
// error: Execution was interrupted, reason: EXC_BAD_INSTRUCTION (code=EXC_I386_INVOP, subcode=0x0).
let tooFarButSafe = csv.index(csv.startIndex, offsetBy: 200, limitedBy: csv.endIndex)
// nil
```

Além disso, os índices não podem ser partilhados entre strings.
Por exemplo, usar o `index` do "g" em "orange" calculado acima para indexar a string `fam = "This is my family: 👨‍👩‍👦‍👦, this is our dog: 🐶, this is our cat: 🐱!"`, ou seja, `fam[index]`, vai fazer o teu programa terminar abruptamente.

Há muitas razões para tudo isto, mas, no fundo, resumem-se todas a "O Unicode é complicado".

De um modo geral, se precisares de acesso aleatório a carateres individuais, provavelmente queres usar outra estrutura de dados, como `Array<Character>`.

## Alguns métodos úteis

O Swift tem os métodos `first` e `last` para obter o primeiro e o último caráter de uma string.
Estes métodos devolvem um caráter opcional, por isso, se a string estiver vazia, devolvem nil.

```swift
let str = "Hello, world!"
print(str.first) // Prints Optional("H")
print(str.last)  // Prints Optional("!")
```

Também podes usar os métodos `prefix` e `suffix` para obter uma substring de uma string.
Estes métodos recebem um número inteiro como argumento e devolvem uma substring com os primeiros ou os últimos n carateres da string.

```swift
let str = "Hello, world!"
print(str.prefix(5)) // Prints "Hello"
print(str.suffix(6)) // Prints "world!"
```
