# Dicas

## Geral

- Um ciclo em x86-64 consegue-se saltando para uma etiqueta anterior e pode sair-se dele saltando para uma etiqueta fora do ciclo.
- Para acederes ao conteúdo guardado num endereço de memória, tens de o desreferenciar com `[]`.
- O prefixo para aceder a valores de 4 bytes na memória é `dword`.
- Um array é representado pelo seu endereço, que é um valor de 8 bytes em x86-64.
- Se uma função chamada modificar um registo, tens de guardar qualquer valor desse registo que venhas a usar mais tarde.

- Podes usar `inc` para somar 1 ao valor do operando de destino.
