# Instruções

Neste exercício vais escrever código para analisar a produção de uma linha de montagem numa fábrica de automóveis.
A velocidade da linha de montagem pode variar entre `0` (desligada) e `10` (máxima).

À velocidade mais baixa (`1`), são produzidos `221` automóveis por hora.
A produção aumenta linearmente com a velocidade.
Por isso, com a velocidade definida em `4`, devem produzir-se `4 * 221 = 884` automóveis por hora.
No entanto, velocidades mais altas aumentam a probabilidade de se produzirem automóveis com defeito, que depois têm de ser descartados. 

Tens três tarefas.

## 1. Calcular a taxa de sucesso

Implementa o método (_static_) `AssemblyLine.SuccessRate()` para calcular a proporção de itens criados sem erros para uma determinada velocidade.
A tabela seguinte mostra como a velocidade influencia a taxa de sucesso:

- `0`: taxa de sucesso de 0%.
- `1` a `4`: taxa de sucesso de 100%.
- `5` a `8`: taxa de sucesso de 90%.
- `9`: taxa de sucesso de 80%.
- `10`: taxa de sucesso de 77%.

```csharp
AssemblyLine.SuccessRate(10)
// => 0.77
```

## 2. Calcular a taxa de produção por hora

Implementa o método (_static_) `AssemblyLine.ProductionRatePerHour()` para calcular a taxa de produção da linha de montagem por hora, tendo em conta a taxa de sucesso:

```csharp
AssemblyLine.ProductionRatePerHour(6)
// => 1193.4
```

Repara que o valor devolvido é um `double`.

## 3. Calcular o número de itens funcionais produzidos por minuto

Implementa o método (_static_) `AssemblyLine.WorkingItemsPerMinute()` para calcular quantos automóveis funcionais são produzidos por minuto:

```csharp
AssemblyLine.WorkingItemsPerMinute(6)
// => 19
```

Repara que o valor devolvido é um `int`.
