# Testes

## Correr os testes
O percurso de Haxe assenta na framework de testes [Buddy](https://github.com/ciscoheat/buddy).
Podes instalá-la com o seguinte:

```bash
haxelib install buddy
```

Para correres os testes, executa o seguinte comando:

```bash
haxe test.hxml
```

No ficheiro de testes, cada bloco describe marca uma secção de testes do exercício, e cada teste é um bloco `it` ou `xit`.
Os blocos `it` são executados quando corres os testes, mas os blocos `xit` são testes que ficaram pendentes.
Quando submetes uma solução, o executor de testes do Exercism corre todos os blocos `it` ou `xit`.
Quando trabalhas localmente, só o primeiro teste é executado por predefinição.
Para correres outros testes, muda os blocos `xit` correspondentes para blocos `it` e volta a correr `haxe test.hxml`.


Além disso, alguns exercícios podem precisar de bibliotecas adicionais instaladas através do haxelib.
Quando isso acontecer, haverá uma nota nas instruções do exercício.

## Resolver o exercício

Resolver um exercício significa fazer passar todos os seus testes.
Para te ajudar a começar, cada exercício inclui um ficheiro de implementação esqueleto.
Podes usar este ficheiro como ponto de partida para construíres a tua solução.
Sente-te à vontade para remover ou alterar este ficheiro se achares que é o melhor a fazer.
Tenta concentrar-te num único teste de cada vez enquanto caminhas para a solução.
