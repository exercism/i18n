# Introdução

## Nil

`Nil` em Gleam é um tipo com um único valor, também chamado `Nil`. É semelhante ao `void` de outras linguagens, na medida em que é usado quando uma função não tem nenhum valor mais adequado para devolver.

```gleam
io.println("Hello, Joe!")
// -> Nil
```

Em Gleam, os valores não são "niláveis" nem "anuláveis", como acontece nalgumas outras linguagens. Um valor só pode ser `Nil` se o seu tipo for `Nil`, e um valor de qualquer outro tipo nunca pode ser `Nil`.

## IO

Tal como a maioria das linguagens de programação, o Gleam tem "efeitos secundários", por isso uma função pode ler e alterar o estado do mundo, para além de devolver um valor.

O módulo `gleam/io` da biblioteca padrão de Gleam fornece funções para imprimir strings na consola.

```gleam
io.println("Hello, Joe!")
// Hello, Joe!
// -> Nil
```

Outros pacotes podem fornecer outras funções de IO, como o `simplifile`, um pacote que disponibiliza funções para ler e escrever ficheiros.

```gleam
simplifile.read("favourite-colour.txt")
// -> Ok("Pink\n")
```
