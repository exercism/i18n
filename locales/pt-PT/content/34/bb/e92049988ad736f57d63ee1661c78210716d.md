# Sobre

O Haxe é uma linguagem de programação e um compilador de código aberto, de alto nível, fortemente tipados, multiplataforma e orientados a objetos, capazes de produzir aplicações e código-fonte para muitas plataformas informáticas diferentes a partir de uma única base de código.

Existem várias linguagens de destino suportadas, que permitem diferentes casos de utilização: [Linguagens de destino suportadas][supported-target-languages]

[Tipos][types] dá a conhecer os sete tipos diferentes do Haxe e a forma como interagem entre si. A discussão sobre tipos continua em [Sistema de tipos][type-system], onde se explicam funcionalidades como a unificação, os parâmetros de tipo e a inferência de tipos.

[Campos de classe][class-fields] aborda toda a estrutura das classes do Haxe e, entre outros tópicos, trata as propriedades, os campos inline e as funções genéricas.

Em [Expressões][expressions] vemos como fazer com que os programas façam realmente alguma coisa, recorrendo a expressões.

[Funcionalidades da linguagem][language-features] conclui a referência da linguagem Haxe, descrevendo em detalhe algumas funcionalidades, como a correspondência de padrões, a interpolação de strings e a eliminação de código morto.
