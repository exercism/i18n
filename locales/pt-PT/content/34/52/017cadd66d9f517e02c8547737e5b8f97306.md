# Dicas

## Geral

- Tens de definir todos os métodos fora do initialize no `module`, `TicketingReservation`.
- O módulo tem de ser colocado acima da classe `TicketSystem`.

## 1. Criar um sistema de bilheteira

- Cria uma classe chamada `TicketSystem`.
- Cria um [construtor][new-initialize] para a classe `TicketSystem`.
- Cria uma [variável de instância][instance-variable] `@tickets_available` que recebe o valor do primeiro argumento passado ao construtor.
- Cria uma [variável de instância][instance-variable] `@stadium` que recebe o nome do segundo argumento passado ao construtor.

## 2. Obter a quantidade de bilhetes disponíveis

- Cria um módulo acima da classe `TicketSystem` chamado `TicketingReservation`.
- Liga o módulo à classe com a palavra-chave [include][include].
- Cria um método chamado `tickets_available` dentro do módulo que devolve a quantidade de bilhetes disponíveis.

## 3. Encomendar bilhetes

- Cria um método chamado `order_ticket?` dentro do módulo.
- Usa um [operador de comparação][equality-and-comparison] para verificar se há pelo menos 100 bilhetes disponíveis.
- Se houver pelo menos 100 bilhetes disponíveis, subtrai 1 à [variável de instância][instance-variable] `@tickets_available`.
- Devolve `true` se houver pelo menos 100 bilhetes disponíveis, caso contrário devolve `false`.

## 4. Mensagem da encomenda

- Cria um método chamado `order_message` dentro do módulo.
- Podes usar métodos já definidos para verificar se há bilhetes suficientes disponíveis.
- Para formar a mensagem, podes usar [interpolação de strings][string-interpolation].
