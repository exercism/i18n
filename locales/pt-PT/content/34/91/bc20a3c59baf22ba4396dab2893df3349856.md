# Introdução

O Python tem três tipos diferentes de números incorporados: inteiros ([`int`][int]), números de vírgula flutuante ([`float`][float]) e números complexos ([`complex`][complex]).
As frações ([`fractions.Fraction`][fractions]) e os decimais ([`decimal.Decimal`][decimals]) também estão disponíveis por importação da biblioteca padrão.

Os números inteiros, incluindo os números hexadecimais ([_`hex()`_][hex]), octais ([_`oct()`_][oct]) e binários ([_`bin()`_][bin]) **sem** casas decimais, também são identificados como `ints`.

O Python suporta totalmente a aritmética entre estes diferentes tipos de números e converte os números mais estreitos para corresponderem aos seus equivalentes menos estreitos quando se usam os operadores aritméticos binários (`+`, `-`, `*`, `/`, `//` e `%`).
