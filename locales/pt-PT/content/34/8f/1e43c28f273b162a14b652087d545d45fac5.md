# Introdução

Os valores Boolean em Java são representados pelo tipo `boolean`, e podem ser `true` ou `false`.

O Java suporta três operadores booleanos:  

- `!` (NÃO): nega o valor Boolean  
- `&&` (E): recebe dois valores Boolean e resulta em true se ambos forem true  
- `||` (OU): resulta em true se algum dos dois valores Boolean for true  

## Exemplos

```java
!true // => false
!false // => true
true && false // => false
true && true // => true
false || false // => false
false || true // => true
```
