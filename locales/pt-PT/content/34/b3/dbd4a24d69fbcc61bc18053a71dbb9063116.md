# Anexo às instruções

## Notas de implementação

O objeto `Tree` tem dois atributos:

- `String` label
- `List<Tree>` children

O programa de testes cria árvores através da aplicação repetida da função construtora
`Tree.of`. Por exemplo, a instrução

```java
Tree tree = Tree.of("a", List.of(Tree.of("b"), Tree.of("c", List.of(Tree.of("d")))));
```

constrói a seguinte árvore:

```text
      "a"
       |
    -------
    |     |
   "b"   "c"
          |
         "d"
```

Podes assumir que não haverá valores duplicados nas árvores de teste.

---

Os métodos `FromPov` e `PathTo` são a parte interessante do exercício.

O método `FromPov` recebe um argumento `from` do tipo `String`, que especifica um nó da
árvore através do seu valor. Deve devolver uma árvore com o valor `from` na raiz.
Podes modificar a árvore original e devolvê-la, ou criar uma nova árvore e devolver
essa. Se devolveres uma nova árvore, podes consumir ou destruir a árvore original à
vontade. Claro que é simpático deixá-la sem alterações.

O método `PathTo` recebe dois argumentos `from` e `to` do tipo `String`, que especificam
dois nós da árvore através dos seus valores. Deve devolver o caminho mais curto na
árvore do primeiro até ao segundo nó.

## Mensagens de exceção

Por vezes é necessário [lançar uma exceção](https://docs.oracle.com/javase/tutorial/essential/exceptions/throwing.html).
Quando o fazes, deves incluir sempre uma **mensagem de erro significativa** para indicar qual é a origem do erro.
Isso torna o teu código mais legível e ajuda imenso a fazer debug.

Este exercício em particular exige que uses a [palavra-chave throw](https://docs.oracle.com/javase/tutorial/essential/exceptions/throwing.html)
para "lançar" várias `UnsupportedOperationException` se à classe `Tree()` for passada uma árvore que não pode ser reorientada, ou se não for possível encontrar um caminho entre um `start node` e um `end node`.
Os testes só passam se fizeres `throw` da `exception` e incluíres uma mensagem com ela.

Para lançar uma `UnsupportedOperationException` com uma mensagem, escreve a mensagem como argumento do tipo `exception`:

```java
// when a tree cannot be oriented to a new node POV
throw new UnsupportedOperationException("Tree could not be reoriented");

// when a path cannot be found between a start and end node on the tree.
throw new UnsupportedOperationException("No path found");
```
