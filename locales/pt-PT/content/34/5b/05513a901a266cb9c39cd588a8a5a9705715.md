# Dicas

## 1. Determina se vais precisar de carta de condução

- Usa o [operador de igualdade] para verificar se o teu valor de entrada é igual a uma determinada string.
- Usa um dos dois [operadores Boolean] para combinar os dois requisitos.
- Não precisas de um condicional para resolver esta tarefa. Podes devolver diretamente a expressão Boolean que construíres.

## 2. Escolhe entre dois veículos possíveis para comprar

- Para esta tarefa, vais precisar da [expressão condicional] `if-then-else`.
- Usa um [operador de comparação] para determinar qual das opções vem primeiro por ordem alfabética.
- Por fim, constrói a frase de recomendação.
  Podes usar a concatenação ou a interpolação de strings que aprendeste no conceito Strings para construir a frase de recomendação.

## 3. Calcula uma estimativa para o preço de um veículo usado

- Começa por determinar a percentagem com base na idade do veículo.
  Usa uma expressão `if-elsif-else`.
- Para calcular o resultado, aplica a percentagem ao preço original.
  Por exemplo, `30% of x` pode ser calculado multiplicando `x` por `30` e dividindo por `100`.
