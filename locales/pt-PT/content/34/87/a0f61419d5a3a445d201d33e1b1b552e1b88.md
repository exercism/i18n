# Instruções

Um buffer circular, buffer cíclico ou buffer em anel é uma estrutura de dados que usa um único buffer de tamanho fixo como se estivesse ligado de ponta a ponta.

Um buffer circular começa vazio e com um determinado comprimento predefinido.
Por exemplo, este é um buffer de 7 elementos:
<!-- prettier-ignore -->
    [ ][ ][ ][ ][ ][ ][ ]

Assume que é escrito um 1 no meio do buffer (a localização inicial exata não importa num buffer circular):
<!-- prettier-ignore -->
    [ ][ ][ ][1][ ][ ][ ]

Depois, assume que são adicionados mais dois elementos, 2 e 3, que ficam acrescentados depois do 1:
<!-- prettier-ignore -->
    [ ][ ][ ][1][2][3][ ]

Se forem removidos dois elementos do buffer, são removidos os valores mais antigos que estão dentro dele.
Os dois elementos removidos, neste caso, são o 1 e o 2, deixando o buffer apenas com um 3:
<!-- prettier-ignore -->
    [ ][ ][ ][ ][ ][3][ ]

Se o buffer tiver 7 elementos, fica completamente cheio:
<!-- prettier-ignore -->
    [5][6][7][8][9][3][4]

Quando o buffer está cheio, é lançado um erro, a avisar o cliente de que novas escritas ficam bloqueadas até que uma fenda fique livre.

Quando o buffer está cheio, o cliente pode optar por sobrescrever os dados mais antigos com uma escrita forçada.
Neste caso, são adicionados mais dois elementos, A e B, que sobrescrevem o 3 e o 4:
<!-- prettier-ignore -->
    [5][6][7][8][9][A][B]

O 3 e o 4 foram substituídos por A e B, o que faz agora do 5 o dado mais antigo do buffer.
Por fim, se forem removidos dois elementos, o que seria devolvido é o 5 e o 6, originando o buffer:
<!-- prettier-ignore -->
    [ ][ ][7][8][9][A][B]

Como há espaço disponível, se o cliente voltar a usar a sobrescrita para guardar C e D, será usado o espaço onde antes estavam guardados o 5 e o 6, e não a localização do 7 e do 8.
O 7 continua a ser o elemento mais antigo e o buffer volta a estar cheio.
<!-- prettier-ignore -->
    [C][D][7][8][9][A][B]
