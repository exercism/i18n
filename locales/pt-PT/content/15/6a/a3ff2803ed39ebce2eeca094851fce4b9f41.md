# Introdução

O módulo [`fractions`][fractions] permite-nos criar e trabalhar com [`rational numbers`][rational]: frações com um numerador inteiro dividido por um denominador inteiro.
Por exemplo, podemos guardar `2/3` como uma fração exata em vez do valor aproximado `float` `0.6666...`.

Ao contrário dos números `int`, `float` e `complex`, as frações não têm uma forma literal.
No entanto, o construtor de frações é bastante flexível.

O mais óbvio é que pode receber dois inteiros como argumentos.
Os fatores comuns são removidos automaticamente, convertendo a fração para a sua "forma irredutível" (_os menores inteiros que representam a fração com exatidão_):

```python
>>> from fractions import Fraction

>>> f1 = Fraction(2, 3) # 2/3
>>> f1
Fraction(2, 3)

>>> f2 = Fraction(6, 9)
>>> f2
Fraction(2, 3)  # automatically simplified

>>> f1 == f2
True
```

O construtor de frações também pode analisar uma representação em string:

```python
>>> f3 = Fraction('2/3')
>>> f3
Fraction(2, 3)
```

As frações também podem trabalhar com parâmetros `float`, mas isso pode dar problemas devido à natureza aproximada de representar o valor decimal internamente em binário.
Para saber mais sobre este problema de representação, consulta o site [0.30000000000000004][0.30000000000000004] e [Floating Point Arithmetic: Issues and Limitations ][fp-issues] na documentação do Python.

Para um resultado mais fiável ao usar números de vírgula flutuante com frações, existe o método `<fraction>.limit_denominator()`.


## Aritmética com frações

Os habituais [`arithmetic operators`][operators] `+ - * / **` funcionam com frações, tal como com outros tipos numéricos.

Inteiros e outros `Fraction`s podem ser incluídos na expressão e dão um resultado `Fraction`.
Incluir um `float` na expressão dá como resultado um `float`, com uma consequente (possível) perda de precisão:

```python
>>> Fraction(2, 3) + Fraction(1, 4) # addition
Fraction(11, 12)

>>> Fraction(2, 3) * Fraction(6, 5) # multiply fractions
Fraction(4, 5)

>>> Fraction(2, 3) * 6 / 5 # fraction with integers
Fraction(4, 5)

>>> Fraction(2, 3) * 1.2  # fraction with float -> float
0.7999999999999999

>>> Fraction(2, 3) ** 2  # exponentiation with integer
Fraction(4, 9)
```

Várias funções numéricas padrão do Python também dão o resultado que poderias esperar ao trabalhar com os tipos `int` e `float`:

```python
>>> round(Fraction(11, 3))
4

>>> from math import floor, ceil
>>> floor(Fraction(11, 3))
3
>>> ceil(Fraction(11, 3))
4

>>> float(Fraction(11, 3))
3.6666666666666665
```
