# Introdução

A enumeração é o ato de percorrer uma coleção (`Array`, `Hash`, etc.) e realizar alguma ação em cada objeto.

A enumeração é um conceito fundamental no Ruby e é usada para ordenar (`sort_by`), agrupar (`group_by`), mapear (`map`), reduzir (`reduce`) e muito mais.
Vais ver a enumeração com mais frequência como a forma idiomática de iterar sobre coleções em vez de usar ciclos.

Uma enumeração simples que usa `map` e `with_index` é assim:

```ruby
words = %w[the cat sat on the mat]
list = words.map.with_index do |word, index|
  "#{index}. #{word}"
end

puts list

# Output:
# 0. the
# 1. cat
# 2. sat
# 3. on
# 4. the
# 5. mat
```
