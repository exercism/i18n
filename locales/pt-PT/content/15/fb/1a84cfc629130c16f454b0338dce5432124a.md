# Sobre

Um [`Array`][array] em Elm é uma coleção imutável e rápida de zero ou mais valores do mesmo tipo.
Como os arrays são imutáveis, depois de um array ser construído, o seu valor nunca pode mudar.
Não existe sintaxe literal para arrays (ao contrário do que acontece com as listas), por isso usa-se antes a sintaxe Array.fromList.
Por exemplo, um `Array` com "a", "b" e "c" lá dentro aparece normalmente como `Array.fromList ["a", "b", "c"]`.
Vais ver isto na saída da consola, no depurador e noutros sítios do género.

Ao contrário de `List`, que é uma [importação predefinida][default-imports], o módulo `Array` tem de ser importado explicitamente, com `import Array` ou algo semelhante.

As anotações de tipo para listas podem definir-se da seguinte forma:

```elm
Array String --> an array of String
Array Int --> an array of Int
```

Os arrays podem definir-se da seguinte forma:

```elm
import Array exposing (Array)

empty : Array Char
empty = Array.empty

singleValue = Array.fromList [ 5 ] --> Array Int

repeatSingleValue = Array.repeat 2 5 --> Array.fromList [ 5, 5 ]

initialiseFromIndex = Array.initialise 3 (\index -> index * 2) --> Array.fromList [ 0, 2, 4 ]

initialisefromList = Array.fromList [ "a", "b", "c" ] --> Array.fromList [ "a", "b", "c" ]
```

Os elementos adicionam-se a um array com `Array.push`:

```elm
twoToFour = Array.fromList [ 2, 3, 4 ]
oneToFour = Array.push 1 twoToFour --> Array.fromList [ 1, 2, 3, 4 ]
```

Os arrays são concatenados com `Array.append`:

```elm
sixSeven = Array.fromList [ 6, 7 ]
eightNine = Array.fromList [ 8, 9 ]
Array.append sixSeven eightNine --> Array.fromList [ 6, 7, 8, 9 ]
```

Obtém-se um elemento de um array com `Array.get`:

```elm
sixSeven = Array.fromList [ 6, 7 ]
Array.get 0 sixSeven --> Just 6
```

Substitui-se um elemento de um array com `Array.set`:

```elm
sixSeven = Array.fromList [ 6, 7 ]
Array.set 1 8 sixSeven --> Array.fromList [ 6, 8 ]
```

Os arrays são manipulados por funções definidas no [módulo `Array`][array-module].

```elm
oneTwo = Array.fromList [ 1, 2 ]
Array.length oneTwo --> 2
```

Qualquer função ou operador que pareça modificar um `Array` (como adicionar um elemento) devolve, na verdade, um novo `Array`.
No entanto, o desempenho normalmente não é problema, porque a implementação de `Array` evita alocações e cópias desnecessárias.

[array-module]: https://package.elm-lang.org/packages/elm/core/latest/Array
