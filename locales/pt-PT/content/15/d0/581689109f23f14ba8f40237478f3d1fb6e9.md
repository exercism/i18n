# Dicas

## Geral

- Tudo aqui está em [`regexp`][regexp], escrito com `R/ /`.
- Um grupo é `( ... )`; `|` é "ou"; lookaround é `(?=...)`,
  `(?!...)` e `(?<=...)`.

## 1. Valida um montante

- Transforma a parte dos cêntimos num grupo e marca-a como opcional:
  `(\.\d{2})?`.
- Escreve `\$` para um sinal de dólar literal e depois usa `matches?` para
  exigir que a string *inteira* se encaixe: `R/ \$\d+(\.\d{2})?/ matches?`.

## 2. Extrai os valores em dólares

- Um *lookbehind* só corresponde a algarismos quando vem primeiro um `$`,
  sem incluir o `$`: `R/ (?<=\$)\d+/`.
- `all-matching-subseqs` recolhe todas as correspondências desse tipo.

## 3. Extrai as percentagens

- Um *lookahead* só corresponde a algarismos quando vem a seguir um `%`:
  `R/ \d+(?=%)/`.

## 4. Assinala uma linha

- Usa `|` para as duas palavras e a opção `i` para não distinguir maiúsculas
  de minúsculas: `R/ refund|chargeback/i`.
- `re-contains?` indica se a linha corresponde em algum ponto.

[regexp]: https://docs.factorcode.org/content/vocab-regexp.html
