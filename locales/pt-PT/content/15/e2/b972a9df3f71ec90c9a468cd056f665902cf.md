# Métodos de arrays

Os arrays são uma estrutura de dados comum.
Por isso, existe um conjunto de métodos que podes usar para trabalhar com arrays.
Alguns exemplos são ordenar, inverter, inserir e muitos outros.

Alguns destes métodos são destrutivos, o que significa que modificam o array original.
Outros não são destrutivos, ou seja, devolvem um novo array e não modificam o original.

Aqui ficam alguns dos métodos mais comuns que podes usar quando trabalhas com arrays:

## insert

Quando inseres um elemento num array, podes usar o método [`insert`][insert], que recebe um índice e um elemento como argumentos.
O elemento será inserido no índice especificado e o resto do array será deslocado para a direita.
Se o índice estiver fora dos limites, será lançado um `IndexError`.

```crystal
numbers = [1, 2, 3]
numbers.insert(1, 4)
numbers # => [1, 4, 2, 3]

numbers.insert(5, 5) # => Error: Index out of bounds (IndexError)
```

## delete

Quando queres eliminar um elemento específico de um array, podes usar o método [`delete`][delete], que recebe um elemento como argumento.
O método devolve o elemento que foi removido.
Se o elemento não existir no array, será devolvido `nil`.

```crystal
numbers = [1, 2, 3]
numbers.delete(2) # => 2
numbers           # => [1, 3]
```

## first & last

Quando queres obter o primeiro ou o último elemento de um array, podes usar os métodos [`first`][first] e [`last`][last].
Estes métodos recebem um argumento opcional que especifica quantos elementos devem ser devolvidos.
Podem melhorar a legibilidade em comparação com o uso do índice `0` ou `-1`, ou de um intervalo.
Se o array estiver vazio, será lançado um `Enumerable::EmptyError`.

```crystal
numbers = [1, 2, 3]
numbers.first # => 1
numbers.last  # => 3

numbers.first(2) # => [1, 2]
numbers.last(2)  # => [2, 3]

empty_array = [] of Int32
empty_array.last # => Error: Empty enumerable (Enumerable::EmptyError)
```

## reverse

Quando queres inverter um array, podes usar o método [`reverse`][reverse], que devolve um novo array com os elementos pela ordem inversa.
É importante notar que `reverse` devolve um novo array e não modifica o array original.
Se quiseres modificar o array original, acrescenta um `!` ao fim do nome do método.

```crystal
numbers = [1, 2, 3]
numbers.reverse # => [3, 2, 1]
numbers         # => [1, 2, 3]

numbers.reverse! # => [3, 2, 1]
numbers          # => [3, 2, 1]
```

## flatten & compact & transpose & uniq

Os métodos seguintes são úteis para operações como tornar um array unidimensional, remover elementos `nil`, remover duplicados ou transpor um array de arrays.
Tal como `reverse`, estes métodos devolvem um novo array e não modificam o array original.

| Método | Descrição | Exemplo |
| ------ | ----------- | ------- |
| [`flatten`][flatten] | Devolve um novo array que é um achatamento unidimensional deste array (recursivamente). Ou seja, para cada elemento do array, extrai os seus elementos para o novo array. | `[[1, 2], [3, 4]].flatten # => [1, 2, 3, 4]` |
| [`compact`][compact] | Devolve uma cópia de si próprio com todos os elementos nil removidos. | `[1, nil, 2, nil, 3].compact # => [1, 2, 3]` |
| [`transpose`][transpose] | Assume que si próprio é um array de arrays e [transpõe][transpose] as linhas e as colunas. | `[[1, 2], [3, 4]].transpose # => [[1, 3], [2, 4]]` |
| [`uniq`][uniq] | Devolve um novo array, removendo os valores duplicados de si próprio. | `[1, 2, 1, 3, 1].uniq # => [1, 2, 3]` |

## Concat(`+`)

O método append (`<<`) é útil quando queres acrescentar objetos a um array.
No entanto, quando combinas dois arrays, podes usar o operador [`+`][concat], que devolve um novo array com os elementos de ambos os arrays.

```crystal
[1, 2] + [3, 4] # => [1, 2, 3, 4]
```

Se acrescentares um array a outro array, o array será adicionado como um único elemento.

```crystal
[1, 2] << [3, 4] # => [1, 2, [3, 4]]
```

## empty?

Para verificares se um array está vazio, podes usar o método [`empty?`][empty?], que devolve `true` se o array estiver vazio e `false` caso contrário.
Isto melhora a legibilidade em comparação com verificar o comprimento do array em relação a `0`.

```crystal
[].empty? # => true
[1, 2, 3].empty? # => false
```

## index

Quando queres obter o índice de um elemento num array, podes usar o método [`index`][index], que recebe um elemento como argumento.
Se o elemento não existir no array, será devolvido `nil`.

```crystal
numbers = [1, 2, 3]
numbers.index(2) # => 1
```

## size

Quando queres saber o número de elementos de um array, podes usar o método [`size`][size].

```crystal
numbers = [1, 2, 3]
numbers.size # => 3
```

## count

Quando queres contar o número de vezes que um elemento aparece num array, podes usar o método [`count`][count].

```crystal
fruits = ["apple", "banana", "apple"]
fruits.count("apple")      # => 2
fruits.count("banana")     # => 1
fruits.count("watermelon") # => 0
```

## sort

Quando queres ordenar um array, podes usar o método [`sort`][sort], que devolve um novo array com os elementos ordenados.
Tal como `reverse`, este método devolve um novo array e não modifica o array original.

```crystal
numbers = [3, 2, 1]
numbers.sort # => [1, 2, 3]
numbers      # => [3, 2, 1]

numbers.sort! # => [1, 2, 3]
numbers       # => [1, 2, 3]
```
