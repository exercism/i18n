# Introdução

Lembra-te do que dissemos no conceito Fundamentos: um programa AWK é composto por **pares padrão-ação**.

```awk
pattern1 { action1 }
pattern2 { action2 }
...
```

## O que queremos dizer com «padrão»?

O «padrão» é qualquer expressão AWK.
É o valor de verdade do resultado da expressão que determina se a ação é executada.

## O padrão vazio

O padrão pode ser omitido.
Neste caso, a ação é executada para cada registo.

Podemos imprimir todos os nomes de utilizador do ficheiro passwd.

```sh
awk -F: '{print $1}' /etc/passwd
```

## Expressões regulares

O AWK consegue comparar strings com expressões regulares para obter um resultado Boolean.

Usa o operador `~` de correspondência de expressões regulares para testar um campo específico.
Este operador recebe uma string como operando à esquerda e uma expressão regular como operando à direita.
Um literal de expressão regular é escrito entre barras `/`.

Para encontrar os utilizadores do ficheiro passwd que iniciam sessão com o bash:

```sh
awk -F: '$7 ~ /bash/ {print $1}' /etc/passwd
```

O `!~` é o operador «a expressão regular **não** corresponde».

Para fazer corresponder uma expressão regular ao registo atual, podes escrever `$0 ~ /regex/`.
Isto é tão comum que existe uma forma abreviada: podes omitir o `$0` e o `~` e escrever simplesmente `/regex/`

```sh
awk '/regex/' data.txt
```

## Expressões

As expressões AWK (aritméticas, lógicas ou de outro tipo) podem ser usadas como padrões.

Para extrair todos os utilizadores com UID 1000 ou superior:

```sh
awk -F: '$3 >= 1000' /etc/passwd
```

Lembra-te de que os valores falsos do AWK são o número zero e a string vazia, e de que todos os outros números ou strings são verdadeiros.
Qualquer expressão que resulte num número ou numa string pode ser usada como padrão.

## Funções

Qualquer função [incorporada][builtins] ou [definida pelo utilizador][user-defined] pode ser usada numa expressão e, por conseguinte, no padrão.
Alguns exemplos:

```awk
length($1) {print "first field is not empty"}
```
```awk
toupper(substr($1, 1, 1)) ~ /[AEIOU]/ {print "starts with a vowel"}
```

## Padrões constantes

Uma construção habitual em AWK é:

```sh
{
    xyz()   # some code that transforms each record
}
1
```

O `1` é um padrão verdadeiro sem ação associada.
Isto significa «imprime o registo atual».
