# Dicas

## Geral

- Para aceder e definir variáveis de instância, escreves `@` seguido do nome da variável.

## 1. Inicializa `TaskHandler`

- Para criar um `Proc` usa a sintaxe `-> (args) { block }`.
- Quando um `Proc` é definido para uma variável de instância, é preciso indicar o tipo explicitamente.
  Podes fazê-lo adicionando `: Proc(<arg_type>, <return_type>)` depois do nome da variável.
  Ou com a sintaxe `-> (arg_1 : <arg_type>) : <return_type> { block }`.
- O `Proc` deve comparar se o argumento é maior ou igual a 0.

## 2. Atualiza a lógica da condição da tarefa

- O método deve receber um bloco como argumento e atribuí-lo à variável de instância `@task_condition_logic`.

## 3. Executa a tarefa seguinte

- Para executar um `Proc` podes usar o método `call`, que aceita os argumentos do Proc.
