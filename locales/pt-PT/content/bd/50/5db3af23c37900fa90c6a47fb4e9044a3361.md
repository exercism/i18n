# Apêndice de instruções

## Cria a tua própria DSL

Neste exercício, tens total liberdade para desenhar a DSL de grafos dos teus sonhos.

Os testes só te pedem que cries alguns grafos específicos; a forma como os construis depende inteiramente de ti.

Para tornar isto ainda mais divertido, podes, se quiseres, tentar implementar uma função `to_dot` que converte o teu grafo para o formato DOT!

## Representação do grafo

Define a tua DSL em `Graph.roc` e usa-a para construir os grafos pedidos pelo stub.
Os dois IDs de nó em cada `EdgeId` têm de estar ordenados alfabeticamente.

| Definição | Grafo a construir |
| --- | --- |
| `empty_graph` | Um grafo vazio |
| `graph_with_one_node` | Um nó |
| `graph_with_one_node_with_attribute` | Um nó com um atributo |
| `graph_with_one_edge` | Uma aresta |
| `graph_with_one_attribute` | Um atributo do grafo |
| `graph_with_nodes_edges_and_attributes` | Nós, arestas e atributos |
| `multiple_edges_on_one_line` | Várias arestas expressas numa só linha |
| `only_1_edge_between_nodes` | Apenas uma aresta entre cada par de nós |
