# Introdução

Uma _string_ é o tipo de dados de JavaScript para armazenar dados de texto.

## Criar uma string

Crias uma string ao envolver o texto em aspas simples ou aspas duplas.
No Exercism, usamos aspas simples.

<!-- prettier-ignore-start -->
```javascript
'Hello, World!'
"Hello, World!"
```
<!-- prettier-ignore-end -->

## Strings como listas de carateres

Podemos tratar uma string como uma lista de carateres em que o primeiro caráter tem o índice `0`.
Podes aceder a um caráter individual da string com parênteses retos (`[]`) e o índice da letra que queres obter.

```javascript
'cat'[1];
// => 'a'
```

Podes determinar o número de carateres de uma string acedendo à propriedade `length`.

```javascript
'cat'.length;
// => 3
```

## Concatenação e métodos

A forma mais simples de concatenar strings é usar o operador de adição `+`.

```javascript
'I like' + ' ' + 'cats.';
// => "I like cats."
```

As strings disponibilizam muitos métodos auxiliares; consulta a [documentação da MDN sobre métodos de string][mdn-string-methods] para veres a lista completa.
A lista seguinte mostra alguns auxiliares usados com frequência.

- [`toUpperCase`][mdn-to-upper-case] e [`toLowerCase`][mdn-to-lower-case] - alteram as maiúsculas e minúsculas de todos os carateres
- [`trim`][mdn-trim] - remove os espaços em branco no início e no fim
- [`includes`][mdn-includes], [`startsWith`][mdn-starts-with] e [`endsWith`][mdn-ends-with] - determinam se outra string faz parte da string dada
- [`slice`][mdn-slice] - extrai uma secção da string

Em JavaScript, as strings são imutáveis. Por isso, uma "modificação", por exemplo através de alguns dos métodos acima, cria sempre uma nova string.
