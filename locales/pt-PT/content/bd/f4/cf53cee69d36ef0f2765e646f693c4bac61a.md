# Sobre

O [D](https://dlang.org) é uma linguagem de programação de sistemas com sintaxe
semelhante à do C e tipos estáticos. Combina eficiência, controlo e poder de modelação com segurança
e produtividade do programador. A linguagem foi desenvolvida originalmente por [Walter Bright](https://en.wikipedia.org/wiki/Walter_Bright) e [Andrei
Alexandrescu](https://en.wikipedia.org/wiki/Andrei_Alexandrescu) a partir da versão 2 do D.

O D é o resultado de décadas de experiência na implementação de compiladores para muitas linguagens
distintas e tem um grande número de [características únicas](http://dlang.org/overview.html):

- construções de alto nível para um grande poder de modelação
- linguagem compilada de alto desempenho
- tipos estáticos
- evolução do C++ (sem os erros)
- interface direta com as APIs do sistema operativo e com o hardware
- tempos de compilação extremamente rápidos
- permite programação segura em termos de memória (SafeD)
- código fácil de manter e de compreender.
- curva de aprendizagem curta (sintaxe semelhante à do C, à do Java e de outras linguagens)
- compatível com a interface binária de aplicações do C
- multi-paradigma (imperativo, estruturado, orientado a objetos, genérico, pureza da programação funcional e até assembly)
- prevenção de erros integrada (contratos, testes unitários)

A [D Language Foundation](https://dlang.org/foundation.html) é a organização dedicada a desenvolver e a
impulsionar a linguagem D.
