# Instruções

`Two-fer` ou `2-fer` é a forma abreviada de dois por um.
Um para ti e um para mim.

Dado um nome, devolve uma string com a mensagem:

```text
One for name, one for me.
```

Em que "name" é o nome indicado.

No entanto, se o nome não for indicado, devolve a string:

```text
One for you, one for me.
```

Aqui ficam alguns exemplos:

|Nome    |String a devolver
|:-------|:------------------
|Alice   |One for Alice, one for me.
|Bob     |One for Bob, one for me.
|        |One for you, one for me.
|Zaphod  |One for Zaphod, one for me.
