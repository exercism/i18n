# Introdução

Uma [lista][list] é uma coleção mutável de itens em _sequência_.
 São uma estrutura de dados extremamente flexível e útil que muitos métodos e operações `built-in` em Python produzem como resultado.
 As listas podem conter referências a qualquer tipo de dados (ou a vários), incluindo outras listas ou estruturas de dados como [tuplas][tuples], [conjuntos][sets] ou [dicionários][dicts].
 O conteúdo pode ser percorrido usando a construção `for item in <list>`.
 Se precisares de índices com o conteúdo, podes usar `for index, item in enumerate(<list>)`.
 Os elementos dentro de uma `list` podem ser acedidos através de um número de índice `0-based index` a partir da esquerda, ou de um número de índice `-1-based index` a partir da direita.
 As listas podem ser copiadas na totalidade ou em parte usando  _notação de fatia_ ou `<list>.copy()`.
