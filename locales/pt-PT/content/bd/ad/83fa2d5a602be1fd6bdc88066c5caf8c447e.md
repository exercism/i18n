# Introdução

## Tempo de vida dos recursos

[concept:csharp/resource-cleanup]() usa a interface `IDispose` para sinalizar que os recursos de um objeto ou outro estado do programa precisavam de ser libertados ou repostos quando o objeto já não era necessário (e que confiar no coletor de lixo não o conseguiria fazer nem dar o nível de controlo necessário) e que o método `IDisposable.Dispose()` era o local natural para essas operações de limpeza.

Existe outra construção, o bloco `using`, que permite, do ponto de vista de quem chama, reunir toda a gestão do tempo de vida dos recursos numa única instrução.

```csharp
using (var file = new File("my_secrets"))
{
    file.WriteSecret("xxxxxxx");
}
```

No exemplo acima, os recursos do sistema de ficheiros associados a `file` são libertados de volta para o sistema operativo quando se sai do bloco `using`.

Para que o padrão funcione, a variável na instrução using tem de ser um tipo de referência que implemente a interface `IDisposable` e tem de libertar recursos/repor o estado do programa no seu método `Dispose()`.

O C# 8 introduz um refinamento deste padrão. Uma instrução using pode ser colocada no início de um bloco.

```csharp
using var drawingResource = some_provided_or_new_object;
try
{
    drawingResource.DrawSomething();
}
catch (Exception)
{
    throw;
}
```

Os programadores de Java podem reconhecer nisto um análogo do mecanismo de _gestão automática de recursos_ introduzido no Java 7.
