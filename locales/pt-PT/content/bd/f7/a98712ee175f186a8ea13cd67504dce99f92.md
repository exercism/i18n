# Introdução

## Namespaces

Os namespaces são uma forma de agrupar código relacionado e de evitar conflitos de nomes, e estão geralmente presentes em todas as bases de código, exceto nas mais triviais.

A sintaxe é a seguinte:

```csharp
namespace MyNameSpace
{
    public class MyClass {}

    public class OtherClass {}
}
```

Os tipos incluídos em namespaces são referidos fora do âmbito do namespace ao prefixar o nome do tipo com a sintaxe de ponto. Em alternativa, e mais habitualmente, podes colocar uma diretiva `using` no topo do ficheiro (ou dentro de um namespace) e o tipo pode ser usado sem o prefixo. Dentro do mesmo namespace, não é preciso qualificar os nomes dos tipos.

```csharp
namespace MySpace
{
    public class MyClass {}

    public class Foo
    {
        public void Bar()
        {
            var baz = new MyClass();
        }
    }
}

public class Qux
{
    public void Box()
    {
        var nux = new MySpace.MyClass();
    }
}

namespace OtherSpace
{
    using MySpace;

    public class Tix
    {
        public void Jeg()
        {
            var lor = new MyClass();
        }
    }
}
```

Podes dar um alias a um namespace com a sintaxe `using MyAlias = MySpace;` e depois usar o alias em qualquer sítio onde o namespace possa ser usado.
