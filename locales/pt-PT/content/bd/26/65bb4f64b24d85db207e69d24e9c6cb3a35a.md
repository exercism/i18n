# Debug

Quando um teste falha, é apresentada uma mensagem que descreve o que correu mal e com que valor de entrada.
Podes inspecionar valores arbitrários no teu programa ao passá-los ao método `debug` (disponível em `exercism/test_runner`).
Isto vai capturar os valores e mostrar-te a saída.


```gleam
import exercism/test_runner.{ debug }

let value: String = "test"
debug("The value is " <> value)
```
