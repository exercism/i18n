# Dicas

## Geral

- Um [valor inteiro][integers] pode ser definido como um ou mais algarismos consecutivos.
- Se vires um erro `panic` ao correr os testes, é porque não implementaste uma das funções (deve indicar qual) ou deixaste o código de partida no sítio.
  Tens de remover a linha `panic!(...)` do código fornecido e substituí-la por uma implementação real.

## 1. Define o tempo de forno esperado em minutos

- Tens de definir uma [função][functions] sem parâmetros.
- Tens de [devolver][return] o tempo de forno esperado em minutos a partir da função.

## 2. Calcula o tempo de forno restante em minutos

- Tens de definir uma [função][functions] com um único parâmetro.
- O parâmetro da função é um [inteiro][integers].
- Tens de [devolver explicitamente um inteiro][return] a partir de uma função.
- Podes [chamar][functions] uma das outras funções que definiste antes.
- Podes usar o [operador matemático de subtração][operators] para subtrair valores.

## 3. Calcula o tempo de preparação em minutos

- Tens de definir uma [função][functions] com um único parâmetro.
- O parâmetro da função é um [inteiro][integers].
- Tens de [devolver explicitamente um inteiro][return] a partir de uma função.
- Podes usar o [operador matemático de multiplicação][operators] para multiplicar valores.

## 4. Calcula o tempo de trabalho decorrido em minutos

- Tens de definir uma [função][functions] com dois parâmetros.
- O parâmetro da função é um [inteiro][integers].
- Tens de [devolver explicitamente um inteiro][return] a partir de uma função.
- Podes [chamar][functions] uma das outras funções que definiste antes.
- Podes usar o [operador matemático de adição][operators] para somar valores.
