# Instruções

És um observador de aves entusiasta que acompanha quantas aves visitaram o teu jardim em cada dia.

Decidiste levar a tua observação de aves a um novo nível e implementar algumas ferramentas que te vão ajudar a acompanhar e a processar os dados.

Escolheste guardar os dados numa lista de números inteiros. O primeiro número da lista é o número de aves que visitaram o teu jardim hoje, o segundo ontem, e assim por diante.

## 1. Verifica quantas aves visitaram hoje

Implementa a função `BirdCount.today/1`. Deve receber uma lista de contagens diárias de aves e devolver a contagem de hoje. Se a lista estiver vazia, deve devolver `nil`.

```elixir
BirdCount.today([2, 5, 1])
# => 2
```

## 2. Incrementa a contagem de hoje

Implementa a função `BirdCount.increment_day_count/1`. Deve receber uma lista de contagens diárias de aves e incrementar a contagem de hoje em 1. Se a lista estiver vazia, devolve `[1]`.

```elixir
BirdCount.increment_day_count([4, 0, 2])
# => [5, 0, 2]
```

## 3. Verifica se houve um dia sem aves visitantes

Implementa a função `BirdCount.has_day_without_birds?/1`. Deve receber uma lista de contagens diárias de aves. Deve devolver `true` se houve pelo menos um dia em que nenhuma ave visitou o jardim, e `false` caso contrário.

```elixir
BirdCount.has_day_without_birds?([2, 0, 4])
# => true

BirdCount.has_day_without_birds?([3, 8, 1, 5])
# => false
```

## 4. Calcula o número total de aves visitantes

Implementa a função `BirdCount.total/1`. Deve receber uma lista de contagens diárias de aves e devolver o número total que visitou o teu jardim desde que começaste a recolher os dados.

```elixir
BirdCount.total([4, 0, 9, 0, 5])
# => 18
```

## 5. Calcula o número de dias movimentados

Alguns dias são mais movimentados do que outros. Um dia movimentado é aquele em que cinco ou mais aves visitaram o teu jardim.

Implementa a função `BirdCount.busy_days/1`. Deve receber uma lista de contagens diárias de aves e devolver o número de dias movimentados.

```elixir
BirdCount.busy_days([4, 5, 0, 0, 6])
# => 2
```
