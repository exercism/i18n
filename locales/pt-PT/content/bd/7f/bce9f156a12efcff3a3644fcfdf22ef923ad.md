# CLI

Para correres os testes, abre uma linha de comandos no diretório do exercício e executa o comando [`stack test`][docs-stack-test]. Se o teu código compilar, este comando mostra-te quais testes passaram e quais falharam. Quando um teste falhar, tenta fazê-lo passar e volta a executar os testes.

Assim que todos os testes estiverem a passar, podes submeter a tua solução: abre uma linha de comandos no diretório do exercício e executa o comando [`exercism submit`][docs-exercism-cli].

[docs-stack-test]: https://docs.haskellstack.org/en/stable/build_command/
[docs-exercism-cli]: https://exercism.io/cli
