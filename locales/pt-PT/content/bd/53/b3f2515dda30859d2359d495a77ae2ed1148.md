# criada uma variável extra para o nome

Criar uma variável extra para guardar o nome é desnecessário, porque Go não passa variáveis por referência.
Reatribuir a `name` não altera o valor fora do âmbito da função `ShareWith`.
Como Go não oferece uma forma de definir valores predefinidos para parâmetros de função,
é prática comum em Go reatribuir o valor para definir um valor predefinido.
