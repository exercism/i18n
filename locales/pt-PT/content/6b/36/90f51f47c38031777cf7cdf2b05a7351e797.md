# Sobre

Em F#, os Boolean são representados pelo tipo `bool`, cujos valores podem ser `true` ou `false`.

O F# suporta três [operadores booleanos][operators]: `not` (NOT), `&&` (AND) e `||` (OR). Os operadores `&&` e `||` usam _avaliação de curto-circuito_, o que significa que o lado direito do operador só é avaliado quando é necessário.

```fsharp
true || false // => true
true && false // => false
```

Cada um dos três operadores booleanos tem uma [_precedência de operadores_][precedence] diferente. Por isso, são avaliados por esta ordem: primeiro o `not`, depois o `&&` e, por fim, o `||`. Se quiseres "contornar" estas regras, podes colocar uma expressão booleana entre parênteses (`()`), uma vez que os parênteses têm uma precedência de operadores ainda maior.

```fsharp
not true && false   // => false
not (true && false) // => true
```
