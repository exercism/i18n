# Instruções

Neste exercício vais implementar um conjunto parcial de rotinas utilitárias para ajudar um programador a limpar nomes SqueakyClean.

Nas 4 tarefas vais construir gradualmente o método `clean`.
Um nome SqueakyClean válido é composto por zero ou mais letras e underscores.

Em todos os casos, é garantido que a string de entrada não é nula. Repara que o método `clean` deve tratar uma string vazia como válida.

## 1. Substituir todos os espaços encontrados por underscores

Implementa o método (estático) `SqueakyClean.clean()` para substituir todos os espaços por underscores. Isto também se aplica a espaços no início e no fim.

```java
SqueakyClean.clean("my   Id");
// => "my___Id"
```

## 2. Converter kebab-case em camelCase

Modifica o método (estático) `SqueakyClean.clean()` para converter kebab-case em camelCase.

```java
SqueakyClean.clean("a-bc");
// => "aBc"
```

## 3. Converter leetspeak em texto normal

Modifica o método (estático) `SqueakyClean.clean()` para converter [leetspeak][leet-speak] em texto normal.

Por simplicidade, vamos apenas substituir `4`, `3`, `0`, `1` e `7` por `a`, `e`, `o`, `l` e `t`, respetivamente.

```java
SqueakyClean.clean("H3ll0 W0rld");
// => "Hello_World"
SqueakyClean.clean("4 73s7");
// => "a_test"
```

## 4. Omitir os carateres que não são letras

Modifica o método (estático) `SqueakyClean.clean()` para omitir quaisquer carateres que não sejam letras.

```java
SqueakyClean.clean("a$#.b");
// => "ab"
```

[leet-speak]: https://en.wikipedia.org/wiki/Leet
