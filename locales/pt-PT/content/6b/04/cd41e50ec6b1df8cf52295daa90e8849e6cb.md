# Apêndice das instruções

## Dicas

- Para analisar o texto, podes tentar usar a biblioteca [Sprache](https://github.com/sprache/Sprache/blob/develop/README.md). Também podes encontrar um bom tutorial [aqui](https://www.thomaslevesque.com/2017/02/23/easy-text-parsing-in-c-with-sprache/).
- Podes resolver este exercício com um algoritmo de força bruta, mas provavelmente terá um desempenho fraco em tempo de execução.
  Tenta encontrar uma solução mais sofisticada.
- Dica: podes tentar o algoritmo de soma por colunas que habitualmente se ensina na escola.
