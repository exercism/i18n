# Dicas

## Geral

- Não te preocupes com a forma como os argumentos são obtidos; foca-te apenas em combinar os argumentos para devolver o resultado pretendido.

## 1. Define se o pac-man pode comer um fantasma

- A função tem de devolver um valor Boolean.
- Podes usar o operador lógico e ([`&&`][logical operators]) para combinar os argumentos e obter um resultado.

## 2. Define se o pac-man pontua

- A função tem de devolver um valor Boolean.
- Podes usar o operador lógico ou ([`||`][logical operators]) para combinar os argumentos e obter um resultado.

## 3. Define se o pac-man perde

- A função tem de devolver um valor Boolean.
- Podes usar os operadores Boolean [`&&`][logical operators] e [`!`][logical operators] para combinar os argumentos e obter um resultado.

## 4. Define se o pac-man ganha

- A função tem de devolver um valor Boolean.
- Podes usar os operadores Boolean [`&&`][logical operators] e [`!`][logical operators] para combinar os argumentos e os resultados de uma das funções implementadas anteriormente.

[logical operators]: https://en.cppreference.com/w/cpp/language/operator_logical
