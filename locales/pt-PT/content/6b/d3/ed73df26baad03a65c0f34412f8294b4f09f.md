# Instruções

Neste exercício vais escrever código para ajudar um freelancer a comunicar com um gestor de projeto: vais criar alguns utilitários que calculam rapidamente a tarifa diária e a tarifa mensal, opcionalmente com um determinado desconto.

Primeiro, estabelecemos algumas regras entre o freelancer e o gestor de projeto:

- A tarifa diária é 8 vezes a tarifa horária.
- Um mês tem 22 dias faturáveis.

Por vezes, o freelancer quer aplicar um desconto à tarifa diária (por exemplo, aos clientes mais leais ou a clientes sem fins lucrativos).

Os descontos são modelados como números fracionários que representam uma percentagem, por exemplo `25.0` (25%).

## 1. Calcular a tarifa diária a partir de uma tarifa horária

Implementa uma função que calcule a tarifa diária a partir de uma tarifa horária:

```haskell
dailyRate 60
-- -> 480.0
```

A tarifa diária devolvida deve ser um double.

## 2. Calcular um preço com desconto

Implementa uma função que calcule o preço depois de aplicar um desconto.

```haskell
applyDiscount 150 10
-- -> 135.0
```

O valor devolvido deve ser sempre um double, sem qualquer arredondamento.

## 3. Calcular a tarifa mensal a partir de uma tarifa horária e de um desconto

Implementa uma função que calcule a tarifa mensal e aplique um desconto:

```haskell
monthlyRate 77 10.5
-- -> 12130
```

A tarifa mensal devolvida deve ser arredondada por excesso (para cima) para o número inteiro mais próximo.

## 4. Calcular o número de dias de trabalho a partir de um orçamento, de uma tarifa horária e de um desconto

Implementa uma função que recebe um orçamento, uma tarifa horária e um desconto, e calcula quantos dias de trabalho isso cobre.

```haskell
daysInBudget 20000 80 11.0
-- -> 35.1
```

O número de dias devolvido deve ser arredondado por defeito (para baixo) com uma casa decimal.
