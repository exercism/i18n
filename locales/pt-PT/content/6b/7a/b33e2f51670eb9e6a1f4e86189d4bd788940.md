# Testes

Se descarregaste um exercício com a ferramenta CLI, deves ver um ficheiro Futhark com o nome do exercício e um ficheiro `test.fut`.
Este ficheiro contém todos os casos de teste, que correspondem aos que são executados pelo test runner quando carregas a tua solução.
Podes adicionar mais casos de teste para experimentares à vontade.
No entanto, alterar os testes não afeta o processo do test runner online.

## Testes locais

Para executares os testes de um exercício, abre um terminal na pasta do exercício e executa o comando `futhark test test.fut` (ou `exercism test`).

Para saberes mais sobre testes com Futhark, consulta a documentação do [`futhark test`][test-command].
