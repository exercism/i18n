# Instruções

O trabalho está a correr bem na _Instruments of Texas_ com a Calculadora RPN. A tua equipa quer agora conseguir escrever uma versão em string da equação num recurso _IO_.

## 1. Abre um ficheiro

A tua equipa ainda não decidiu para que tipo de dispositivo escrever a equação, por isso sugeres uma abordagem de _despacho dinâmico_ para conseguires injetar o recurso na função em vez de o codificares diretamente. Implementa a função `write/3` para abrir um dispositivo _IO_ usando o recurso e o nome do ficheiro.

Podes assumir que `resource` será sempre um átomo que representa um módulo com uma função `open/1` que devolve `{:ok, io_device}`.

Quando a função for bem-sucedida, devolve um tuplo ok com a equação.

```elixir
RPNCalculator.Output.write(resource, "file_to_be_written", "1 4 +")
# {:ok, "1 4 +"}
```

## 2. Tenta escrever no dispositivo IO

Agora que abriste o dispositivo IO, tenta escrever nele com `IO.write/2`.

Estende a função `write/3` para realizar esta ação. A tentativa de escrita pode lançar um erro; recupera do erro devolvendo um tuplo de erro:

```elixir
RPNCalculator.Output.write(resource, "bad_file", "1 4 +")
# {:error, "Unable to write to resource"}
```

## 3. Fecha o dispositivo IO

É uma boa prática tentar sempre libertar os recursos que abriste, mesmo que a função que usa o recurso lance um erro. Estende a função `write/3` para chamar a função de fecho do recurso e fechar o dispositivo _IO_.

Podes assumir que `resource` será sempre um átomo que representa um módulo com uma função `close/1` que recebe um dispositivo _IO_.
