# Sobre

O Tcl, que se pronuncia "tickle" e é a abreviatura de Tool Command Language, é uma linguagem de programação dinâmica e de código aberto.

Foi concebida com o objetivo de ser muito simples, mas poderosa. É tão simples que a sintaxe completa está descrita em [apenas 12 regras][rules]. Ainda assim, é uma linguagem de programação completa.

O Tcl transforma tudo em *comandos*, incluindo atribuições de variáveis, definições de procedimentos e fluxo de controlo. Nesse aspeto, é parecido tanto com a escrita de scripts de shell como com Lisp.

O Tcl suporta vários paradigmas de programação, incluindo os estilos orientado a objetos, imperativo e funcional. Os casos de uso mais comuns do Tcl são como ambientes de scripting incorporados em aplicações C e para prototipar interfaces gráficas com o toolkit gráfico Tk.
