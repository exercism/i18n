# Sobre

Os enums de Rust também são chamados [tipos de dados algébricos](https://en.wikipedia.org/wiki/Algebraic_data_type), ou [uniões etiquetadas](https://en.wikipedia.org/wiki/Tagged_union). Porque é que isto importa? As enumerações são um conceito popular e as linguagens de programação implementam-nas de forma diferente. A programação funcional influenciou o design de Rust e a implementação de `enum` demonstra isso.

- [introdução aos enums no livro de Rust](https://doc.rust-lang.org/book/ch06-01-defining-an-enum.html)
