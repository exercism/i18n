# Sobre

## Módulos

O código Gleam está organizado em módulos, e cada ficheiro é um módulo Gleam.

Até agora escrevemos funções com a sintaxe `pub fn`, que define uma função disponível publicamente para outros módulos. As funções definidas com `fn` são privadas do módulo onde são definidas e não podem ser usadas por outros módulos.

```gleam
// This function is public
pub fn add(x, y) {
  x + y
}

// This function is private
fn subtract(x, y) {
  x - y
}
```

Os módulos Gleam têm nomes, e o nome baseia-se no caminho do ficheiro dentro do diretório `src` ou `test`.

Por exemplo, um módulo definido em `src\geometry\rectangle.gleam` (no Windows) ou `src/geometry/rectangle.gleam` (em sistemas operativos do tipo UNIX) teria o nome `geometry/rectangle`.

## Importar funções de outros módulos

O acesso a funções definidas noutros módulos faz-se através de importações. Ao importar um módulo, todas as funções desse módulo que ele expôs ficam acessíveis. Mas a forma como lhes acedes depende da forma como o módulo é importado.

As importações qualificadas são o padrão, e aceder a uma função desse módulo (por exemplo, a função `map` do módulo `gleam/list`) faz-se escrevendo o nome do módulo à frente (`list.map`).

```gleam
// Import the int module
import gleam/int

pub fn run(x: Int) -> String {
  // Use the to_string function from the int module
  int.to_string(x)
}
```

Por predefinição, o nome usado para te referires ao módulo é a última parte do nome do módulo, neste caso `int`, mas isto pode ser alterado com a palavra-chave `as`.

```gleam
// Import the int module and refer to it as i
import gleam/int as i

pub fn run(x: Int) -> String {
  i.to_string(x)
}
```

As importações não qualificadas permitem o acesso direto às funções expostas desse módulo, sem prefixo.

```gleam
// Import the to_string function from the int module
import gleam/int.{to_string}

pub fn run(x: Int) -> String {
  to_string(x)
}
```

As importações qualificadas são preferíveis, pois deixam mais claro para quem lê de onde vem cada função e ajudam a evitar conflitos de nomes.
