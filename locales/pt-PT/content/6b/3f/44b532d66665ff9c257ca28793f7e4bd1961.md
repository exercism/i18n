# Introdução

Trabalhas numa empresa de bioengenharia especializada no desenvolvimento de soluções terapêuticas.

A tua equipa acaba de receber um novo projeto para desenvolver uma terapia dirigida para um tipo raro de cancro.

~~~~exercism/note
É tudo muito complicado, mas a ideia básica é que, por vezes, o corpo das pessoas produz demasiada quantidade de uma determinada proteína.
Isso pode causar todo o tipo de estragos.

Mas se conseguires criar uma molécula muito específica (chamada micro-RNA), essa molécula pode impedir que a proteína seja produzida.

Esta técnica chama-se [interferência de RNA][rnai].

[rnai]: https://admin.acceleratingscience.com/ask-a-scientist/what-is-rnai/
