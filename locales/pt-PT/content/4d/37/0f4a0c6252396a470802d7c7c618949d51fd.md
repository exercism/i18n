# Dicas

## 1. Encontra a posição de uma carta

- Os índices do array começam em `0`.
- Existe um método [integrado][indexof_method_docs] para obteres o índice de um determinado valor.

## 2. Determina se uma carta está presente

- Existe um método [integrado][includes_method_docs] para verificares se o valor está presente no array

## 3. Determina se cada carta é par

- Existe um método [integrado][every_method_docs] para verificares se cada valor passa um predicado

## 4. Verifica se o baralho contém uma carta de valor ímpar

- Existe um método [integrado][some_method_docs] para verificares se pelo menos um valor passa um predicado

## 5. Obtém a primeira carta ímpar do baralho

- Existe um método [integrado][find_method_docs] para obteres o primeiro elemento que passa um predicado

## 6. Determina a posição da primeira carta que é par

- Existe um método [integrado][findindex_method_docs] para obteres o primeiro índice no array em que o valor
