# Dicas

## Geral

- Lê sobre [erros][getting-started-errors] no guia Getting Started.
- Lê sobre [`defexception`][defexception] na documentação.
- Lê sobre o [comportamento `Exception`][exception-behaviour] na documentação.
- Lê os excertos de código da introdução.

## 1. Erro de divisão por zero

- Implementa o módulo, indicando a mensagem com uma [macro incorporada para definir exceções][defexception].
- Os módulos podem ser aninhados dentro de outros módulos.

## 2. Erro de underflow da pilha

- Implementa o módulo, indicando a mensagem com uma [macro incorporada para definir exceções][defexception].
- Podes usar um dos callbacks do comportamento Exception para definir uma exceção cuja mensagem muda em função dos argumentos passados a `raise/2`.
- Os módulos podem ser aninhados dentro de outros módulos.

## 3. Escreve uma função de divisão

- Escreve uma função com várias cláusulas, usando guardas para o controlo do fluxo.
- Podes fazer correspondência de padrões na lista de argumentos da função para associar os valores da pilha a variáveis.
