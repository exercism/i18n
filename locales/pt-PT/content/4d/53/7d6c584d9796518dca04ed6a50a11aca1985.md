# Instalação

## Ubuntu (e a maioria das outras distribuições baseadas em Debian)

Para compilar código localmente, vais precisar do gcc e do make, que podes instalar com

```shell
sudo apt install gcc make
```

Se não estiveres a correr em hardware ARM64, instala o emulador [QEMU][] e a cross-toolchain GCC ARM64 com

```shell
sudo apt install qemu-user libc6-dev-arm64-cross gcc-aarch64-linux-gnu
```

## Windows

Usa o [Windows Subsystem for Linux][] com uma distribuição baseada em Debian e segue as instruções para Ubuntu acima.
Em alternativa, configura uma máquina virtual Linux.

## macOS

Podes lançar uma máquina virtual Linux com qualquer solução de virtualização adequada (por exemplo, o [Lima][]).

[QEMU]: https://www.qemu.org/
[Windows Subsystem for Linux]: https://docs.microsoft.com/en-gb/windows/wsl/about
[Lima]: https://lima-vm.io/
