# Dicas

## 1. Obtém a primeira letra do título

- Existe [um método][index] que devolve um `Char` de uma `String` num dado índice.

## 2. Obtém as iniciais dos autores

- Podes usar métodos já implementados para obter a primeira letra de uma `String`.
- Para combinar valores numa `String` podes usar [interpolação de strings][string-interpolation].

## 3. Decifra a letra

- Existe [um método][uppercase] para verificar se um `Char` está em maiúsculas.
- Existe [um método][ord] para obter o ponto de código de um `Char`.

## 4. Decifra o texto

- Podes usar [ciclos][while] para executar código várias vezes.
