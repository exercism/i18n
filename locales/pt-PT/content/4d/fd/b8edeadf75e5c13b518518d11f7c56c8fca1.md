# Sobre

O Ruby é uma linguagem de programação dinâmica e de código aberto, focada na simplicidade e na produtividade.
Tem uma sintaxe elegante, natural de ler e fácil de escrever.

O Ruby foi criado como uma linguagem de equilíbrio cuidadoso.
O seu criador, [Yukihiro "Matz" Matsumoto](https://en.wikipedia.org/wiki/Yukihiro_Matsumoto), combinou partes das suas linguagens preferidas (Perl, Smalltalk, Eiffel, Ada e Lisp) para formar uma nova linguagem que equilibrava a programação funcional com a programação imperativa.

Disse muitas vezes que está "a tentar tornar o Ruby natural, não simples", de uma forma que espelha a vida.

Nesta linha, acrescenta: "O Ruby é simples na aparência, mas é muito complexo por dentro, tal como o nosso corpo humano."

Podes ler mais sobre a linguagem Ruby [no seu site](https://www.ruby-lang.org/en/about/).
