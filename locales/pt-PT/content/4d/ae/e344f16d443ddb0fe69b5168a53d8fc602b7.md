# Introdução

## Funções de callback

As funções de callback são funções passadas como argumentos.
Este padrão de programação cria uma sequência de chamadas de funções, tanto na programação síncrona como na assíncrona.
Escrever uma função de callback não é diferente de escrever uma função; no entanto, a função de callback tem de corresponder à assinatura definida pela função que a chama.

```javascript
const squareLength = 5;

// Caller function takes a callback function
function applyToSquare(callback) {
  return callback(squareLength);
}

// Callback must expect the possible argument from the calling function
function areaOfSquare(number) {
  return number * number;
}

applyToSquare(areaOfSquare); // => 25
```

Também podes escrever callbacks como expressão de função, expressão de função anónima ou expressão de função arrow:

```javascript
applyToSquare(function squarePerimeter(side) {
  return side * 4;
});

applyToSquare(function (side) {
  return side * 4;
});

applyToSquare((side) => {
  return side * 4;
});
```
