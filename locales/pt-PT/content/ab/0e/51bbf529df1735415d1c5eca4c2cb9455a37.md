# Introdução

Os intervalos representam uma sequência de um ou vários números inteiros consecutivos. Criam-se ligando dois números inteiros com `..`.

```elixir
1..5
```

Os intervalos podem ser ascendentes ou descendentes. O primeiro e o último valor estão sempre incluídos.

Um intervalo implementa o _protocolo Enumerable_, o que significa que podes usar as funções do módulo `Enum` para trabalhar com intervalos.
