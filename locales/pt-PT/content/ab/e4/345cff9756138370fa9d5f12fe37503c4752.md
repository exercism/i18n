# Apêndice de instruções

## Instruções específicas do percurso

Para algo um pouco diferente, também podes experimentar uma solução com uma função `unfold`. Provavelmente já conheces `foldLeft/Right`: «mapeiam» uma coleção inteira para outra coisa (normalmente algo que não é uma coleção). `unfold` é a operação «inversa»: «mapeia» algo (normalmente algo que não é uma coleção) para uma coleção. Por isso, fazer `unfold` é uma adição lógica e faz parte do repertório padrão da programação funcional.

Este exercício pode ser encarado como um caso para fazer `unfold`: «mapear» um `Int` para uma `String` (que é, naturalmente, de forma implícita, uma `Seq[Char]`).

As coleções do Scala têm-no desde a 2.13, por exemplo [`List.unfold`][list] e `Iterator.unfold`. Recebe um estado inicial e uma função que devolve o elemento seguinte e o estado seguinte, ou `None` para parar:

```scala
List.unfold(1234)(n => Option.when(n > 0)((n % 10, n / 10)))
// List(4, 3, 2, 1)
```

[list]: https://www.scala-lang.org/api/current/scala/collection/immutable/List$.html
