# Instruções

Se queres construir algo com um Raspberry Pi, provavelmente vais usar _resistências_.
Neste exercício, precisas de saber duas coisas sobre elas:

- Cada resistência tem um valor de resistência.
- As resistências são pequenas. Tão pequenas que, se imprimisses nelas o valor da resistência, seria difícil de ler.

Para contornar este problema, os fabricantes imprimem faixas com código de cores nas resistências para indicar os seus valores de resistência.
Cada faixa tem uma posição e um valor numérico.

As duas primeiras faixas de uma resistência têm um esquema de codificação simples: cada cor corresponde a um único número.

Neste exercício vais criar um programa útil, para não precisares de memorizar os valores das faixas.

Estas cores estão codificadas da seguinte forma:

- Black: 0
- Brown: 1
- Red: 2
- Orange: 3
- Yellow: 4
- Green: 5
- Blue: 6
- Violet: 7
- Grey: 8
- White: 9

O objetivo deste exercício é criar uma forma de:
1. procurar o valor numérico associado a uma determinada faixa colorida
2. converter o valor numérico numa string que representa a cor
3. listar as diferentes cores das faixas

Para a tarefa número um, vais precisar da crate externa [`int-enum`](https://docs.rs/int-enum/0.5.0/int_enum/) e, para a tarefa número três, vais precisar da [`enum-iterator`](https://docs.rs/enum-iterator/1.2.0/enum_iterator/).
Ambas já estão incluídas no `Cargo.toml` deste exercício.
Certifica-te de que consultas a documentação das crates para aprenderes a usá-las.
Podes consultar a implementação por omissão da trait Debug para Enums para completares a tarefa número dois.

As mnemónicas associam as cores aos números que, quando guardados num array, acabam por corresponder ao seu índice no array: Better Be Right Or Your Great Big Values Go Wrong.

Podes encontrar mais informação sobre a codificação de cores das resistências no [artigo da Wikipédia sobre o código de cores eletrónico](https://en.wikipedia.org/wiki/Electronic_color_code).
