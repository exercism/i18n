# Instruções

É o turno da noite no cais de Hull. O cargueiro *Olwen* está atracado ao lado e uma equipa de estivadores trabalha o manifesto em paralelo. Todas as caixas têm de ser pesadas antes de irem a bordo, e o capitão do porto mantém uma única **contagem de tonelagem** em curso que todos os içamentos atualizam. O senão: só há um guindaste no cais, por isso a contagem não pode ser corrompida por dois estivadores a atualizá-la ao mesmo tempo.

Cada caixa é um array de pesos de itens. O peso da caixa é a soma desses itens.

## 1. Pesar uma caixa

Define `weigh-crate` de modo a receber uma caixa e a devolver o seu peso total. Isto é trabalho sequencial simples: uma caixa, um número como resultado.

```factor
{ 12 8 15 } weigh-crate .
! => 35
```

## 2. Pesar o manifesto inteiro em paralelo

Define `weigh-all` de modo a receber um array de caixas e a devolver o array dos respetivos pesos, pela mesma ordem. Usa `parallel-map` para que o trabalho de cada caixa aconteça em simultâneo.

```factor
{ { 5 5 } { 10 } { 3 4 5 } } weigh-all .
! => { 10 10 12 }
```

## 3. Construir um guindaste novo

Define `<crane>` para construir um guindaste novo: um tuplo com um `<lock>` novo e uma tonelagem de `0`. O guindaste é o recurso partilhado que as tarefas seguintes vão proteger.

```factor
<crane> tonnage>> .
! => 0
```

## 4. Içar uma caixa para a contagem em curso

Define `hoist-crate` de modo a receber um `weight` e um `crane` e a adicionar o peso à tonelagem do guindaste **sob o lock do guindaste**, para que a sequência de ler, somar e escrever seja atómica face a outros estivadores que estejam a içar ao mesmo tempo.

```factor
<crane>
35 over hoist-crate
17 over hoist-crate
tonnage>> .
! => 52
```

## 5. Ler a tonelagem em curso

Define `crane-tonnage` para devolver a tonelagem atual do guindaste, também sob o lock, para que a leitura não veja um valor corrompido a meio de um içamento.

```factor
<crane>
35 over hoist-crate
crane-tonnage .
! => 35
```

## 6. Carregar a carga

Define `load-cargo` de modo a receber um array de caixas e um guindaste e, **para cada caixa, lança um thread de estivador** que pesa a caixa e iça o peso para o guindaste. A palavra só devolve depois de todos os estivadores terem terminado. Usa `<promise>` e `?promise` para coordenar a junção.

```factor
<crane> :> crane
{ { 5 5 } { 10 } { 3 4 5 } } crane load-cargo
crane crane-tonnage .
! => 32
```
