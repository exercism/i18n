# Anexo às instruções

## Formato de entrada

O parâmetro `board`, que representa o tabuleiro de jogo, está no formato de um array de strings.

```javascript
['  B  ', ' B B ', 'B W B', ' W W ', '  W  '];
```

Cada caráter de uma string representa uma célula.
Os valores válidos para uma célula são:

- ` ` um espaço em branco que corresponde a uma célula vazia
- `B` uma célula que pertence ao jogador preto
- `W` uma célula que pertence ao jogador branco

## Formatos de saída

A função `getTerritory` deve devolver um objeto com 2 propriedades:

- `owner` O dono do território (`NONE`, `BLACK` ou `WHITE`)
- `territory` Um array de coordenadas que representa cada célula do território.

```javascript
{
    owner: 'BLACK',
    territory: [
        [0, 0],
        [0, 1],
        [1, 0],
    ],
}
```

A função `getTerritories` deve devolver um objeto com 3 propriedades:

- `territoryBlack` Um array de coordenadas que representa os territórios que pertencem ao jogador `BLACK`
- `territoryWhite` Um array de coordenadas que representa os territórios que pertencem ao jogador `WHITE`
- `territoryNone` Um array de coordenadas que representa os territórios que não pertencem a nenhum dos dois jogadores

```javascript
{
    territoryBlack: [
        [0, 0],
        [0, 1],
    ],
    territoryWhite: [
        [3, 0],
        [3, 1],
    ],
    territoryNone: [],
}
```
