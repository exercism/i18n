# Instalação

## Que awk é que tenho?

O track AWK do Exercism usa `gawk`, o AWK da GNU.
Podes já tê-lo; para verificar, executa este comando
```sh
awk --version
```

Se obtiveres um destes resultados:

* algo como `GNU Awk 5.1.0 ...`
    - Já tens o GNU awk e podes continuar com os exercícios.

* algo como `awk version 20200816`
    - Isto é `nawk`, também conhecido como BWK awk (em referência a Brian Kernighan) ou "one true awk".
    - É o que vem incluído no MacOS e nos sistemas BSD.
    - Lê mais abaixo as instruções de instalação.

* o erro `awk: not an option: --version`
    - Provavelmente tens o `mawk`.
    - Confirma com: `awk -W version`, que pode devolver `mawk 1.3.4 20200120`.
    - O mawk é uma implementação de awk muito boa e rápida, mas não tem algumas das funcionalidades específicas do gawk que vamos usar no track.
    - Lê mais abaixo as instruções de instalação.

* o erro `awk: unrecognized option: version` seguido de `BusyBox v1.35.0 ...`
    - Podes estar a usar o Alpine Linux.
    - Lê mais abaixo as instruções de instalação.

* um erro "command not found"
    - Então ou o teu PATH está desconfigurado ou simplesmente não tens o awk instalado.
    - Lê mais abaixo as instruções de instalação.

### Linux

Depende do gestor de pacotes da tua distribuição. Normalmente:
```sh
apt install gawk
yum install gawk
apk add gawk
# and so on
```
Podes precisar de usar `sudo` para executar o comando adequado.

### MacOS

O [Homebrew][brew] é o teu amigo. Segue a ligação para o instalar e depois corre:
```sh
brew install gawk
```

### Windows

Para o [WSL][wsl], vê as instruções para Linux acima.
Para o Cygwin, instala o pacote `gawk`.

### Compilar a partir do código-fonte

Para os corajosos, há instruções [disponíveis no manual do `gawk`][build].
