# Introdução

Lembra-te de que um programa em `jq` é uma _cadeia de expressões_.
A **atribuição de variável** segue esta regra: uma _atribuição de variável_ é uma expressão com este aspeto:

```jq
... | expr as $varname | ...
```

## A saída do filtro é a sua entrada

Tal como a _expressão de identidade_ `.`, a saída da _atribuição de variável_ é igual à sua entrada.
Definir o valor da variável é um efeito secundário.

Exemplo que mostra que `.` depois da atribuição é igual à entrada inicial:

```sh
$ jq -c -n '42 | (. * 2) as $double | [., $double]'
[42,84]
```

## Âmbito da variável

O âmbito da variável é "lexical": a variável fica no âmbito até ao fim da cadeia.
As variáveis definidas em funções (veremos as funções mais à frente) são "locais" à função.

## Nomes de variáveis

O nome da variável tem de começar por `$`.
O resto do nome da variável é um **identificador**: começa por uma letra ou um underscore, seguido de letras, números ou underscores.

## Atribuição por desestruturação

Do manual:

> É possível declarar várias variáveis com uma única expressão `as`, fornecendo um padrão que _corresponde à estrutura da entrada_ (a isto chama-se "desestruturação").

Exemplos:

```jq
[1, 2, 3] as [$a, $b, $c]
| [$a, $b, $c]     # => [1, 2, 3]
```

```jq
{"foo": "bar", "len": [10, 20]} as {foo: $f, len: [$h, $w]}
| [$f, $h, $w]     # => ["bar", 10, 20]
```

Fazer corresponder o nome da variável à _chave do objeto_ oferece um atalho:

```jq
{"x": 4, "y": 7} as {$x, $y}
| [$x, $y]         # => [4, 7]
```

```jq
{"foo": "bar", "len": [10, 20]} as {$foo, $len}
| [$foo, $len]     # => ["bar", [10, 20]]
```

## Constantes

Como se mostra no exemplo acima, as variáveis são úteis para guardar constantes.
É melhor dar um nome às constantes do que ter "números mágicos" a aparecer no código.

## Muitas vezes as variáveis não são necessárias

Muitas vezes, o código fica mais legível se omitires as variáveis.

Vejamos o cálculo da média de uma lista de números

```jq
[2, 4, 8, 7]
| add as $sum
| length as $len
| $sum / $len
```

em comparação com

```jq
[2, 4, 8, 7] | add / length
```

Isto realça um dos aspetos mais poderosos do `jq`: a entrada de um filtro é fornecida a _todas_ as subexpressões:

- o array de entrada `[2,4,8,7]` é passado a `add` (que soma os números aplicando o operador `+` a todos os elementos)
- _em paralelo_, `[2,4,8,7]` também é passado a `length`
- quando estas subexpressões terminam, os resultados são divididos, devolvendo o valor médio dos números do array de entrada.
