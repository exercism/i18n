# Introdução

Em Java existem dois tipos diferentes de números:

- Inteiros: números sem algarismos depois do separador decimal (números inteiros). Alguns exemplos são `-6`, `0`, `1`, `25`, `976` e `-500000`.
- Números de vírgula flutuante: números com zero ou mais algarismos depois do separador decimal. Alguns exemplos são `-20.4`, `0.1`, `2.72`, `16.984025` e `1024.0`.

Os dois tipos numéricos mais comuns em Java são o `int` e o `double`. Um `int` é um inteiro de 32 bits e um `double` é um número de vírgula flutuante de 64 bits.

A aritmética faz-se com os operadores aritméticos normais. Os números podem ser comparados com os operadores de comparação numérica normais (por exemplo, `5 > 4` e `4 <= 5`) e com os operadores de igualdade (`==`) e de desigualdade (`!=`).

O Java tem dois tipos de conversões numéricas:

1. Conversões implícitas: não se perdem dados e não é preciso sintaxe adicional.
2. Conversões explícitas: podem perder-se dados e é preciso sintaxe adicional sob a forma de um _cast_.

Como um `int` tem menos precisão do que um `double`, converter de um `int` para um `double` é seguro e, por isso, é uma conversão implícita. No entanto, converter de um `double` para um `int` pode significar perder dados, por isso exige uma conversão explícita.
