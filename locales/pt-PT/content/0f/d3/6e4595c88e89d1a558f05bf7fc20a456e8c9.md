# Adenda às instruções

## Notas

Este exercício pede que cries uma estrutura de dados de lista ligada que possa ser percorrida. 

1. Implementa a propriedade `Count`: não deve ser possível alterar o seu valor a partir do exterior. 
2. Implementa o método `Push(T value)`, que adiciona um valor à lista, na cabeça. 
3. Implementa o método `Pop()`, que remove e devolve um valor da cabeça. 
4. Adiciona um construtor que permita a inicialização com um único valor ou com um iterável. 
5. Implementa a interface `IEnumerable<T>`. Para mais informações, consulta [esta página](https://docs.microsoft.com/en-us/dotnet/api/system.collections.generic.ienumerable-1). 
6. Certifica-te de que o método `Reverse()` está disponível.
