# Dicas

## 1. Imprime um crachá para um funcionário

- A [interpolação de strings][string-interpolation] pode ser usada para criar strings de descrição.
- Existe um [método incorporado para converter uma string em maiúsculas][to-upper-case].

## 2. Imprime um crachá para um novo funcionário

- Deves verificar se o ID é `null` antes de o usares.
- Podes usar os [operadores de igualdade][equality-operators] para comparar o valor com `null`

## 3. Imprime um crachá para o proprietário

- Deves verificar se o departamento é `null` antes de o usares.
- Podes usar os [operadores de igualdade][equality-operators] para comparar o valor com `null`
