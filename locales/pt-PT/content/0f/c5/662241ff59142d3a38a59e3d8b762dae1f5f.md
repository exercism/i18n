# Dicas

## Geral

- [Propriedades][docs.microsoft.com-properties]
- [Utilizar propriedades][docs.microsoft.com-using-properties]

## 1. Permitir que a balança tenha uma precisão

- Precisas de adicionar uma [propriedade só de leitura][stackoverflow.com-get-only-properties] onde guardar a precisão.
- Podes inicializar a propriedade com apenas um acessador `get` a partir do construtor (e apenas a partir do construtor).

## 2. Permitir que o peso seja definido na balança

- Deves adicionar uma propriedade com um [campo de suporte][docs.microsoft.com-properties-with-backing-fields] privado.

## 3. Garantir que um peso de entrada negativo é rejeitado

- A palavra-chave `value` serve para nos referirmos ao valor que quem chama quer que a propriedade tenha.
- Adiciona [validação][stackoverflow.com-validating-properties] ao acessador `set` de `Weight` para lançar uma exceção quando o valor for inválido.

## 4. Permitir que seja aplicado um ajuste de tara à balança

- Deves adicionar uma [propriedade autoimplementada][docs.microsoft.com-auto-implemented-properties] para o ajuste de tara.

## 5. Garantir que a balança tem um ajuste de tara predefinido

- Podes inicializar uma [propriedade autoimplementada][docs.microsoft.com-auto-implemented-properties] tal como podes inicializar um campo.

## 6. Permitir que o peso seja obtido

- Deves adicionar uma propriedade que só tenha `get`, na qual se calcula o peso de visualização correto.

## 7. Mostrar corretamente a string do peso de visualização

- Deves [formatar a string][stackoverflow.com-format-string] adequadamente.
