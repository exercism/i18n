# Dicas

## Geral

- Lê a documentação sobre [operadores de comparação][comparison-operators]
- Lê a documentação sobre [ordenar listas][list-sort]
- Lembra-te de como podes [aceder a registos ou fazer correspondência de padrões][records]

## 1. Comparar os níveis de poder

- Usa o [operador `(>)`][greater]

## 2. Encontrar o poder mais alto

- Usa a [função `max`][max]

## 3. Ordenar as cartas

- Usa a [função `List.sortBy`][sort-by]

## 4. As cartas mais fixes primeiro

- Usa as funções [`List.sortBy`][sort-by] ou [`List.sortWith`][sort-with]
- Podes usar tuplos para ordenações hierárquicas

## 5. Poder brilhante

- Podes definir explicitamente uma ordem ou usar a [função `compare`][compare] com um valor específico
- Podes usar tuplos para ordenações hierárquicas

## 6. Faz as tuas apostas

- Usa `compareShinyPower` em `expectedWinner`
- Usa um `case` para [fazer correspondência de padrões com a ordem][pattern-match]
