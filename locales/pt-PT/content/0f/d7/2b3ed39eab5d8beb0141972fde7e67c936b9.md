A concatenação de strings com o operador `+` é uma abordagem válida, mas pode criar problemas de manutenção e de legibilidade.
Usar o método [str.format()][str.format()] ou as [f-strings][f-strings] _(também conhecidas como "literais de string formatados" ou "strings interpoladas")_ pode oferecer opções que melhoram a manutenção e tornam mais clara a substituição de variáveis dentro das strings.

O artigo [Formatação de strings em Python][string formatting in python] é um bom ponto de partida para compreender todas as opções de formatação de strings do Python, e [Técnicas mais recentes de formatação de strings em Python][newer python string format techniques] também traz algumas dicas e truques úteis para usar `str.format()` e `f-strings`.
