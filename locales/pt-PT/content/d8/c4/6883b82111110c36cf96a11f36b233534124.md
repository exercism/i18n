# Anexo às instruções

## Formato da saída

Apresenta as plantas do aluno como uma string, usando uma vírgula e um espaço como separadores.

## Memória reservada

O buffer para a string do diagrama usa os bytes 1024-2047 da memória linear.
O buffer para a string do aluno usa os bytes 2048-3071 da memória linear.

As strings de entrada podem ser modificadas no local, se quiseres.
