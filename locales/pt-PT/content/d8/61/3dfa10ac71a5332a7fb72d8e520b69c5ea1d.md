# Sobre

Rust é uma linguagem de programação de sistemas que é extremamente rápida, evita falhas de segmentação e garante a segurança entre threads.
O seu objetivo é trazer para a programação de sistemas o design moderno das linguagens e um sistema de tipos avançado.
Rust não usa um coletor de lixo. Em vez disso, recorre a análise estática avançada para garantir libertações determinísticas.
Consegue-o através do conceito de [ownership](https://doc.rust-lang.org/book/ch04-00-understanding-ownership.html).

O núcleo do Rust e a biblioteca padrão são intencionalmente mínimos; as pilhas não estão incluídas.
Em vez disso, os Rustaceans são encorajados a acrescentar bibliotecas à linguagem, chamadas _crates_, partilhando-as no [crates.io](https://crates.io/).

Rust é usado com mais frequência em aplicações onde a velocidade, o desempenho e a estabilidade são essenciais.
A lista [Awesome Rust](https://github.com/kud1ing/awesome-rust) reúne exemplos de projetos em Rust, que incluem ferramentas de linha de comandos, ORMs, sistemas operativos e jogos.
Independentemente do que construíres em Rust, vai ser rápido e seguro em termos de memória!

A página inicial do Rust é [rust-lang.org](https://www.rust-lang.org/).
Rust tem excelente documentação em [rust-lang.org/documentation.html](https://www.rust-lang.org/documentation.html).
Quem está a dar os primeiros passos deve começar por «The Book», que está em [doc.rust-lang.org/book/](https://doc.rust-lang.org/book/).
