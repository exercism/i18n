# Cabeçalho de nível superior fictício

## Números em Euphoria

Em Euphoria, um `atom` pode conter qualquer tipo de número, com o subtipo `integer` reservado aos números inteiros.
É possível resolver este exercício em linguagens do tipo C devolvendo um inteiro sem sinal de 64 bits.

No entanto, os inteiros em Euphoria têm sinal e são _um bit menores do que a palavra de máquina_, logo demasiado pequenos para este exercício, enquanto os atoms conseguem guardar inteiros maiores com os 64 bits de precisão necessários.

### 32 bits

Existe uma versão de 32 bits do Euphoria, que ainda existe para que as aplicações legadas possam continuar a usar dll/so de 32 bits já compiladas quando não há uma versão de 64 bits disponível, ou quando o wrapper dessas aplicações está cheio de deslocamentos de 32 bits codificados de forma fixa.
Esta versão é completamente inadequada para resolver esta tarefa, visto que esses atoms só têm 53 bits de precisão.
Se estás a ter dificuldade em resolver este exercício localmente, certifica-te de que estás a usar uma versão de 64 bits do Euphoria.
