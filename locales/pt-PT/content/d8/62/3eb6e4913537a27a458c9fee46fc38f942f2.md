# Dicas

## Geral

- Os endereços de memória em x86-64 são números de 64 bits (8 bytes).
- Deves usar `rel` para formar endereços relativos válidos na memória.

## 1. Obter o valor RGB de uma cor

- Os endereços de memória em x86-64 são números de 64 bits (8 bytes).
- Deves usar `rel` para formar endereços relativos válidos na memória.
- Para acederes ao conteúdo guardado num endereço de memória, tens de o desreferenciar com `[]`.
- Os inteiros de 32 bits (4 bytes) são devolvidos em `eax`.

## 2. Adicionar a cor base

- Os endereços de memória em x86-64 são números de 64 bits (8 bytes).
- Deves usar `rel` para formar endereços relativos válidos na memória.
- As variáveis inicializadas são definidas na _secção .data_.
- Uma variável tem de ser declarada `global` para ser visível a outros ficheiros de código-fonte.
- Podes reutilizar a função `get_color_value` já implementada.

## 3. Definir constantes para as cores primárias

- Os endereços de memória em x86-64 são números de 64 bits (8 bytes).
- Deves usar `rel` para formar endereços relativos válidos na memória.
- As constantes inicializadas são definidas na _secção .rodata_.
- Uma constante tem de ser declarada `global` para ser visível a outros ficheiros de código-fonte.

## 4. Combinar cores

- Os endereços de memória em x86-64 são números de 64 bits (8 bytes).
- Deves usar `rel` para formar endereços relativos válidos na memória.
- Para acederes ao conteúdo guardado num endereço de memória, tens de o desreferenciar com `[]`.
- Uma função ou dados externos têm de ser declarados `extern` na secção correspondente.
- Uma função externa pode modificar qualquer um dos registos habituais que estejas a usar, por isso tens de guardar as variáveis na memória antes de a chamares.
- `combining_function` recebe o valor de 32 bits (não o endereço) da cor base em `rdi` e o valor de 32 bits (não o endereço) da cor secundária em `rsi`.
