# Instruções

Neste exercício estás a jogar um jogo de interpretação de papéis em que diferentes tipos de lutadores podem combater entre si.
O jogo tem regras diferentes para cada tipo de lutador.
Vamos concentrar-nos em dois tipos específicos: Wizards e Warriors.

Para um Warrior, as regras são estas:

- Um Warrior nunca é vulnerável.
- Um Warrior causa `6` pontos de dano se o lutador que está a atacar não for vulnerável.
- Um Warrior causa `10` pontos de dano se o lutador que está a atacar for vulnerável.

Para um Wizard, as regras são estas:

- Um Wizard pode preparar um feitiço com antecedência.
- Um Wizard é vulnerável a menos que tenha preparado um feitiço com antecedência.
- Um Wizard causa `12` pontos de dano se tiver preparado um feitiço com antecedência.
- Um Wizard causa `3` pontos de dano se não tiver preparado um feitiço com antecedência.

## 1. Cria a classe Warrior

Cria uma nova classe chamada `Warrior`.
Esta classe deve herdar da classe `Fighter` existente.

## 2. Descreve um Warrior

Atualiza a classe `Warrior` para que o seu método `toString()` descreva que tipo de lutador é.
O método deve devolver a string `"Fighter is a Warrior"`.

```java
Warrior warrior = new Warrior();
warrior.toString();
// => "Fighter is a Warrior"
```

## 3. Torna os Warriors invulneráveis

Atualiza a classe `Warrior` para que o seu método `isVulnerable()` devolva sempre `false`.

```java
Warrior warrior = new Warrior();
warrior.isVulnerable();
// => false
```

## 4. Calcula os pontos de dano de um Warrior

Atualiza a classe `Warrior` para que o seu método `getDamagePoints(Fighter)` calcule o dano causado por um Warrior de acordo com as regras acima.

```java
Warrior warrior = new Warrior();
Wizard wizard = new Wizard();

warrior.getDamagePoints(wizard);
// => 10
```

## 5. Cria a classe Wizard

Cria outra nova classe chamada `Wizard`.
Esta classe também deve herdar da classe `Fighter` existente.

## 6. Descreve um Wizard

Atualiza a classe `Wizard` para que o seu método `toString()` descreva que tipo de lutador é.
O método deve devolver a string `"Fighter is a Wizard"`.

```java
Wizard wizard = new Wizard();
wizard.toString();
// => "Fighter is a Wizard"
```

## 7. Permite que os Wizards preparem um feitiço e torna-os vulneráveis quando não tiverem um feitiço preparado

Atualiza a classe `Wizard` para adicionar um método chamado `prepareSpell()`.
A classe deve registar quando este método é chamado e garantir que o seu método `isVulnerable()` devolve `false` apenas quando um feitiço estiver preparado.

```java
Wizard wizard = new Wizard();
wizard.prepareSpell();
wizard.isVulnerable();
// => false
```

## 8. Calcula os pontos de dano de um Wizard

Atualiza a classe `Wizard` para que o seu método `getDamagePoints(Fighter)` calcule o dano causado por um Wizard de acordo com as regras acima.

```java
Wizard wizard = new Wizard();
Warrior warrior = new Warrior();

wizard.prepareSpell();
wizard.getDamagePoints(warrior);
// => 12
```
