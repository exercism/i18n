# Introdução

Common Lisp fornece várias expressões condicionais diferentes, sendo a principal diferença o número de ramos que suportam.

- `when` e `unless` permitem um único ramo:

```lisp
(when (= 2 2) "All is well")      ; => "All is well"
(unless (= 2 2) "Time to panic!") ; => NIL
```

A secção após a expressão de teste pode conter mais do que uma expressão.

- `if` fornece a construção clássica if-then-else:

```lisp
(if (= 2 2) 'how-honest 'you-liar) ; => HOW-HONEST
```

Repara que tanto a cláusula then como a cláusula else só podem ser uma única expressão.

- `cond` permite ter vários ramos sem aninhar expressões `if`:

```lisp
(cond ((= 0 2) 'nope)
      ((= 1 2) 'try-again)
      ((= 2 2) 'quite-true)
      ((= 3 2) 'too-far)
      (t 'something-else))
; => QUITE-TRUE
```

Repara que não há limite para o número de expressões após a expressão de teste. 

- `case` fornece uma construção clássica ao estilo 'switch': compara um único valor com vários ramos:

```lisp
(case 'elder-beast
  (cat "Meow")
  (bird "Chirp")
  (dog "Bark")
  (otherwise "???"))
; => "???"
```

Repara que, tal como no `cond`, não há limite para o número de expressões após a expressão de teste.
