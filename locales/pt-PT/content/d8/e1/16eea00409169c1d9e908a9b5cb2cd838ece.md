# Instruções

Pediram-te para fazer mais algum trabalho no sistema de autenticação de rede.

Além de a identidade do administrador estar escrita diretamente no código do sistema durante o desenvolvimento, os responsáveis também querem dar o mesmo tratamento aos programadores seniores.

## 1. Guarda os dados do administrador do sistema diretamente no código e torna-os acessíveis a quem os invoca.

Os dados do administrador são os seguintes:

| Email        | Cor dos olhos | Largura do filtro | Nome     | Morada 1 | Morada 2 |
| ------------ | ------------- | ----------------- | -------- | -------- | -------- |
| admin@ex.ism | green         | 0.9               | Chanakya | Mumbai   | India    |

Implementa a propriedade `Authenticator.Admin` para devolver os dados de identidade do administrador do sistema. O nome e cada parte da morada devem ficar em elementos separados da lista `NameAndAddress`.

```csharp
var authenticator = new Authenticator();
authenticator.Admin;
// => {"admin@ex.ism", {"green", 0.9m}, ["Chanakya", "Mumbai", "India"]}
```

## 2. Guarda os dados dos programadores diretamente no código e torna-os acessíveis sob a forma de um dicionário

Os dados dos programadores são os seguintes:

| Email         | Cor dos olhos | Largura do filtro | Nome     | Morada 1 | Morada 2 |
| ------------- | ------------- | ----------------- | -------- | -------- | -------- |
| bert@ex.ism   | blue          | 0.8               | Bertrand | Paris    | France   |
| anders@ex.ism | brown         | 0.85              | Anders   | Redmond  | USA      |

Implementa a propriedade `Authenticator.Developers` para devolver os dados de identidade dos programadores. A chave do dicionário é o nome do programador.

```csharp
var authenticator = new Authenticator();
authenticator.Developers;
// => ["Bertrand"] = {"bert@ex.ism", {"blue", 0.8m}, ["Bertrand", "Paris", "France"]},
// ["Anders"] = {"anders@ex.ism", {"brown", 0.85m}, ["Anders", "Redmond", "USA"]},

```
