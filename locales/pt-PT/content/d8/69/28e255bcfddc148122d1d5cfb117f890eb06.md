# Instruções

Estás a fazer caminhadas na Nova Zelândia e a tirar marcações de uma bússola. Uma marcação é um número inteiro de graus e é um valor: rodar 20 graus não altera a marcação que tiraste, dá-te outra.

Escreve uma `immutable class BEARING`. O stub dá-te o cabeçalho da classe e o respetivo atributo.

## 1. Tira uma marcação

`create` recebe um número de graus e devolve uma marcação. Os graus vão de 0 a 359, por isso qualquer valor fora desse intervalo dá a volta: 370 é 10 e -10 é 350.

```sather
#BEARING(370).degrees
-- => 10
#BEARING(-10).degrees
-- => 350
```

## 2. Roda

`turned` recebe um número de graus para rodar e devolve a nova marcação. Um número negativo roda no sentido oposto. A marcação sobre a qual foi chamado mantém-se inalterada.

```sather
#BEARING(350).turned(20).degrees
-- => 10
```

## 3. Compara

`is_eq` recebe outra marcação e devolve se são iguais. Assim que existir, o `=` funciona com marcações.

```sather
#BEARING(10) = #BEARING(370)
-- => true
```

## 4. Dá nome ao ponto cardeal

`point` devolve o ponto cardeal mais próximo da marcação, como um de `"N"`, `"NE"`, `"E"`, `"SE"`, `"S"`, `"SW"`, `"W"`, `"NW"`.

Cada ponto cobre 45 graus, centrado na sua marcação exata: o norte vai de 337.5, passando por 0, até 22.5; o nordeste vai de 22.5 a 67.5, e assim por diante. Como as marcações aqui são números inteiros, uma marcação de 22 é `"N"` e 23 é `"NE"`.

```sather
#BEARING(0).point
-- => "N"
#BEARING(90).point
-- => "E"
#BEARING(225).point
-- => "SW"
```

## 5. Anota-o

`str` devolve os graus e o ponto cardeal, como `"90 degrees (E)"`.

```sather
#BEARING(90).str
-- => "90 degrees (E)"
```
