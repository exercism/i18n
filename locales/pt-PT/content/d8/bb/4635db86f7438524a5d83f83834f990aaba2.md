# Instruções

Vais escrever algum código para gerir um quadro de pontuações de um jogo.
O quadro de pontuações será um hash chamado `%HighScoreBoard::Scores`.
As chaves do hash serão os nomes dos jogadores e os valores serão as suas pontuações.

## 1. Define a pontuação de um jogador no hash %Scores

Modifica a sub-rotina `HighScoreBoard::set_player_scores`, que recebe nomes de jogadores e pontuações como argumentos, para definir as pontuações dos jogadores no hash `%HighScoreBoard::Scores`.

## 2. Obtém a pontuação de um jogador a partir do hash %Scores 

Modifica a sub-rotina `HighScoreBoard::get_player_score`, que recebe um nome de jogador como argumento, para devolver a pontuação do jogador a partir do hash `%HighScoreBoard::Scores`.

## 3. Aumenta a pontuação de um jogador no hash %Scores

Modifica a sub-rotina `HighScoreBoard::increase_player_scores`, que recebe nomes de jogadores e pontuações como argumentos, para aumentar as pontuações dos jogadores no hash `%HighScoreBoard::Scores` na pontuação indicada.

## 4. Ordena os jogadores do hash %Scores pelo nome

Modifica a sub-rotina `HighScoreBoard::sort_players_by_name` para devolver os nomes dos jogadores no hash `%HighScoreBoard::Scores` ordenados por nome.

## 5. Ordena os jogadores do hash %Scores pela pontuação

Modifica a sub-rotina `HighScoreBoard::sort_players_by_score` para devolver os nomes dos jogadores no hash `%HighScoreBoard::Scores` ordenados por pontuação.

## 6. Elimina um jogador do hash %Scores

Modifica a sub-rotina `HighScoreBoard::delete_player`, que recebe um nome de jogador como argumento, para eliminar o jogador do hash `%HighScoreBoard::Scores`.
