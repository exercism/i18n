# Instruções

É mais uma noite movimentada na estação de triagem de Antuérpia. És o
controlador de serviço: os vagões de mercadorias que chegam têm de ser
reagrupados em comboios de saída, os engates inspecionados, as rotas
divididas nos entroncamentos e a carga idêntica agrupada para faturação.

Cada *vagão* é uma string que indica o que transporta:
`"coal"`, `"timber"`, `"crates"`, etc.

## 1. Engata os vagões em comboios

Define `couple` de modo a receber um array de vagões e um comprimento
`n`, e a devolver comboios não sobrepostos de `n` vagões cada. O último
comboio pode ser mais curto se a contagem não for divisível.

```factor
{ "coal" "coal" "coke" "ore" "ore" "timber" "timber" } 3 couple .
! => { { "coal" "coal" "coke" } { "ore" "ore" "timber" } { "timber" } }
```

## 2. Espreita os engates

Define `peek-couplings` de modo a receber um array de vagões e a devolver
todos os pares adjacentes, para que o inspetor possa examinar cada
engate.

```factor
{ "coal" "ore" "timber" "crates" } peek-couplings .
! => { { "coal" "ore" } { "ore" "timber" } { "timber" "crates" } }
```

## 3. Divide a cadeia nos entroncamentos

Define `split-at-junctions` de modo a receber um array de vagões e um
array de `junctions` (vagões que marcam um ponto de quebra), e a devolver
os troços entre os vagões de entroncamento. Os próprios vagões de
entroncamento não são mantidos.

```factor
{ "coal" "coal" "switch" "ore" "switch" "timber" }
{ "switch" } split-at-junctions .
! => { { "coal" "coal" } { "ore" } { "timber" } }
```

## 4. Agrupa a carga idêntica

Define `coalesce-cargo` de modo a receber um array de vagões e a agrupar
em sequências os vagões *consecutivos* que transportam a mesma carga.

```factor
{ "coal" "coal" "ore" "ore" "ore" "timber" "coal" } coalesce-cargo .
! => { { "coal" "coal" } { "ore" "ore" "ore" } { "timber" } { "coal" } }
```
