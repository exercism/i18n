# Instruções

Trabalhas numa prestigiada sociedade de advogados especializada em tratar de pedidos de testamento invulgares.

Neste exercício, vais abrir um cofre misterioso.
És o testamenteiro da herança e vais juntar os códigos secretos há muito guardados de três famílias para obter um número de conta e o código correspondente.

Para impedir que qualquer família abra o cofre sozinha, este só pode ser aberto combinando o conhecimento das famílias com um modificador secreto que conheces do testamento.

Tens três tarefas, todas relacionadas com ajudar as famílias a abrir o cofre.

## 1. Senta-te em frente das famílias e dispõe os teus papéis

Define um namespace chamado `EstateExecutor`.
O código das tarefas seguintes deve ser definido no corpo do namespace `EstateExecutor`.

```ruby
class SomeName
  # The space between the class/module name
  # and the `end` keyword
  # is called body of the  namespace.
end
```

## 2. Encontra o número de conta secreto

Este é o teu grande momento.
Só tu tens a chave do modificador secreto para revelar o número de conta secreto.

Define o método `assemble_account_number(secret_modifier)`, que recebe como argumento o modificador secreto, do tipo `Integer`, e devolve o número de conta reunido, também do tipo `Integer`.

Para obteres o número correto, tens de somar a `bank_number_part` de cada uma das três famílias.

## 3. Último passo: introduz o código secreto

As instruções do testamento pedem-te que juntes primeiro todos os fragmentos azuis e depois todos os vermelhos.
O código resultante obtém-se multiplicando as duas somas.

Define o método `assemble_code`, que devolve o código resultante, combinando os fragmentos das três famílias num único resultado do tipo `Integer`.
O método não tem argumentos e baseia-se apenas na informação contida nos namespaces relevantes das famílias.
