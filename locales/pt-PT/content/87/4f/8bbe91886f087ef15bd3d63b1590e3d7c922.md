# Sobre as strings

Uma [`string`][ref-string] em Kotlin é uma sequência imutável de carateres Unicode.

[`Immutable`][wiki-immutable] significa que qualquer operação sobre uma string tem de devolver uma nova string: a string original nunca pode mudar.

[`Unicode`][wiki-unicode] significa que é possível representar a maioria dos sistemas de escrita do mundo, mas (ao contrário de linguagens mais antigas, como o C) não existe uma correspondência de 1:1 entre carateres e bytes.
Isto será abordado com mais detalhe no Conceito [`Chars`][concept-chars].

Uma string é delimitada por aspas duplas `" "`.

Alguns carateres precisam de escape: `\\`, mais os habituais carateres não imprimíveis, como `\t` (tabulação) e `\n` (nova linha).

```kotlin
val s = "Escape backslash \\."
// Escape backslash \.
```

As strings com várias linhas são delimitadas por 3 aspas duplas e podem conter texto arbitrário (não é preciso fazer escape).

```kotlin
val multi = """I'm a
    multi-line
    string with special characters \ \t """
//I'm a
//    multi-line
//    string with special characters  \ \t 
```

Usa o [trimIndent][trimIndent-doc] para remover a indentação comum das linhas.
Isto é útil para formatar a string:

```kotlin
val multi = """
    I'm a
      multi-line
    string""".trimIndent()

//I'm a
//  multi-line
//string
```

Em alternativa, o [trimMargin][trimMargin-doc] permite-te especificar um delimitador.
Cada linha da `String` começa então depois do delimitador.
O delimitador predefinido é `|`, mas podes especificar um delimitador diferente como parâmetro.
Por exemplo:

```kotlin
val multi = """
    |I'm a
    |  multi-line
    |string""".trimMargin()

//I'm a
//  multi-line
//string

val multi2 = """
    start>I'm a
    start>  multi-line
    start>string""".trimMargin("start>")

//I'm a
//  multi-line
//string
```

As strings podem ser concatenadas com `+`, mas é melhor limitar isso a casos curtos e simples.
Há outras opções, muitas vezes melhores.

## Modelos de string

[`Templates`][ref-templates] refere-se àquilo a que outras linguagens chamam «interpolação».

Se uma string contém um sinal de dólar `$` seguido de um identificador, ou contém chavetas (`{expression}`) a rodear uma expressão, esses elementos são substituídos, respetivamente, pelo valor ou pelo resultado da expressão.

```kotlin
val x = 42
val st = "x is $x, x squared is {x * x}"
// x is 42, x squared is 1764
```

## Formatação de strings

Na plataforma JVM (e apenas nela), `String.format()` permite uma formatação mais precisa do que os modelos de string, com uma [sintaxe][web-formats] semelhante à das funções [`printf`][wiki-printf] (_muito antigas!_).

```kotlin
String.format("%s %.3f", "π ≈", 3.14159)
//π ≈ 3.142
```

## Funções de string

O Kotlin fornece _muitas_ [`functions`][ref-string-functions] para manipular strings.

Na sua maioria, são [`extensions functions`][ref-extensions] e não membros da classe `String`, embora isto tenha pouco efeito na forma como as usamos.

~~~~exercism/note
As páginas de [documentação][ref-string-functions] do Kotlin, bastante complexas, escondem as funções de extensão na vista predefinida.
No momento em que isto foi escrito, o conteúdo mais valioso estava escondido num separador chamado `Members & Extensions`.
Clica nele para expandir esta secção e ver todos os membros e extensões disponíveis na classe `String`.

[ref-string-functions]: https://kotlinlang.org/api/core/kotlin-stdlib/kotlin/-string/
~~~~

O exemplo seguinte mostra apenas uma pequena seleção do que está disponível:

```kotlin
val str = "Hello World!"

str.length              // => 12 (a property, not a function)
str.elementAt(6)        // => W
str.elementAtOrNull(20) // => null (index out of range)
str.substring(6, 11)    // => "World"
str.substringAfter(" ") // => "World!"

str.lowercase()         // => "hello world!"
str.uppercase()         // => "HELLO WORLD!"

str.startsWith("Hel")   // => true
str.endsWith("xyz")     // => false
str.indexOf("0")        // => 4

str.toCharArray()       // => [H, e, l, l, o,  , W, o, r, l, d, !]
"42".toInt() + 1        // => 43  (parsing; see also toFloat)

"Howdy!  ".trim()       // => "Howdy"
```

## Construir uma string

Por vezes, é preciso construir uma string longa por etapas, por exemplo dentro de um ciclo.

Concatenar strings com `+` depressa deixa de ser elegante e eficiente: a imutabilidade implica que é preciso fazer _imensas_ cópias.

O Kotlin tem várias formas mais eficientes de combinar várias strings:

- Modelos de string, descritos acima.
- [`joinToString()][ref-jointostring], que será abordado no Conceito [Lists][concept-lists].
- O [`StringBuilder`][ref-stringbuilder] do Java, que não é considerado particularmente idiomático em Kotlin.
- O [`buildString()`][ref-buildstring] do Kotlin, que envolve o `StringBuilder` numa sintaxe mais concisa e idiomática.
  Recebe a lógica de construção da string como argumento lambda, o que será abordado num Conceito mais adiante.

Essencialmente, um `StringBuilder` é uma estrutura do tipo lista, com muitos métodos convenientes.
Esta é uma pequena seleção:

- [`append()`][ref-sb-append] para acrescentar ao fim.
- [`insert()`][ref-sb-insert] para inserir numa posição especificada.
- [`deleteAt()`][ref-sb-deleteat] e [`deleteRange()`][ref-sb-deleterange] para remover de posições especificadas.
- `toString()` para converter numa string normal no fim: concatena tudo numa única operação eficiente.

```kotlin
// Available, not recommended
val sb = StringBuilder()
sb.append("Hello ")
sb.append("World!")
sb.toString()
//Hello World!
```

Um exemplo com `buildString()`, que usa sintaxe de Conceitos posteriores:

```kotlin
val countDown = buildString {
    for (i in 5 downTo 1) {
        append(i)
        append("_")
    }
}
// countDown is "5_4_3_2_1_"
```
