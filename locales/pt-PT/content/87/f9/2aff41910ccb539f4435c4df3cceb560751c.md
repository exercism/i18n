# Introdução

Um `Integer` guarda qualquer número, por maior que seja, até ao limite da memória da tua máquina, ao passo que um `Int` corresponde ao conjunto dos números inteiros positivos e negativos que se podem representar em 32 ou 64 bits (garantidamente, pelo menos, de -2^29 a 2^29).

Um `Float` corresponde ao conjunto dos números reais, limitado pela precisão do computador.
As operações definidas sobre números funcionam habitualmente com um tipo ou com o outro, mas não com ambos.

As funções para converter entre `Float` e `Integer` incluem, entre outras, `toFloat`, que converte `Int`/`Integer` em `Float`, e `ceiling`, que converte um `Float` num `Int`.

A conversão de um tipo inteiro (`Int` ou `Integer`) para qualquer outro tipo numérico é feita com a função `fromIntegral`.
O tipo de destino é inferido automaticamente.
Por exemplo:

```haskell
n :: Integer
n = 6
x :: Float
x = fromIntegral n      --> x = 6.0

m :: Int
m = 7
y :: Double
y = fromIntegral m      --> y = 7.0
```
