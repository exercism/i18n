# Introdução

A desestruturação é uma forma de decompor valores compostos em Rust. É frequentemente usada para extrair campos de tuplas ou de estruturas.

Por exemplo, o excerto seguinte extrai dois valores de uma tupla:

```rust
let (first, second) = (1, 2);
```

O valor `1` fica ligado à variável `first`.
O valor `2` fica ligado à variável `second`.
