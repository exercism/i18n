# Configurar as ferramentas

Há três ferramentas que deves ajustar no teu percurso:

- O **[Contador de Linhas de Código](/docs/building/tooling/lines-of-code-counter)**: esta ferramenta tem a tarefa de contar as linhas de código de cada iteração submetida.
- O **[Extrator de Snippets](/docs/building/tooling/snippet-extractor)**: esta ferramenta extrai um snippet para cada iteração, que aparece no site.
- A **[Exercism CLI](/docs/building/tooling/cli)**: esta ferramenta é usada pelos estudantes para trabalhar num percurso localmente, na sua própria máquina.

```exercism/note
Embora ajustar estas ferramentas seja opcional, torna a integração do teu percurso no site _muito_ melhor.
Por isso, recomendamos vivamente que ajustes as três ferramentas.
```
