# Dicas

## 1. Converter uma nota numérica numa nota alfabética

- Usa uma [expressão `if-then-else`][jq-man-if] com tantos ramos `elif` quantos forem necessários.

## 2. Contar o número de alunos para cada nota alfabética

- O filtro `reduce` precisa de um _stream_ para iterar.
  O valor de entrada é um objeto.
  Usa a expressão `to_entries` para transformar o objeto num array.
- O objeto resultante tem de ter todas as notas alfabéticas possíveis como chaves, mesmo que nenhum aluno tenha obtido essa nota.
- A [atribuição `+=`][jq-man-arith-assign] vai ser útil.

[jq-man-if]: https://jqlang.org/manual/#if-then-else-end
[jq-man-arith-assign]: https://jqlang.org/manual/#arithmetic-update-assignment
