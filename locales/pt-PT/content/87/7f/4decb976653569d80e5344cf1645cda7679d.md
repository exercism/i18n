# Dicas

## Geral

- Uma função pode ser definida de modo a receber vários argumentos agrupados de uma só vez, usando o parâmetro `*args` para argumentos do tipo `list` e `tuple`, ou o parâmetro `**kwargs` para argumentos baseados em dicionários e palavras-chave.
- Para agrupar ou desagrupar, usa o operador `*` ou `**`.

## 1. Cria uma lista com todas as carruagens

- É possível agrupar vários argumentos nos parâmetros da função com o operador `*args`.

## 2. Corrige a lista de carruagens

- Usar o desempacotamento com o operador `*` permite-te extrair os dois primeiros elementos de uma `list` e manter o resto intacto.
- Para adicionar outra `list` a uma `list` existente, podes usar o operador `*` para "espalhar" a `list`.

## 3. Adiciona as paragens em falta

- Usar `**kwargs` como parâmetro de uma função permite passar um número arbitrário de argumentos de palavra-chave.
- Usar `**<dict>` como argumento desempacota um dicionário em argumentos de palavra-chave.
- Podes colocar argumentos de palavra-chave num `{}` ou em `dict()`.
- Para obter os valores de um dicionário, podes usar o método `<dict>.values()`.

## 4. Estende a informação de encaminhamento

- Usar `**<dict>` como argumento desempacota um dicionário em argumentos de palavra-chave.
- Podes colocar argumentos de palavra-chave num `{}` ou em `dict()`.

## 5. Corrige o depósito de carruagens

- `zip(*iterators)` pode ser usado para transpor uma `list` aninhada.
- Para extrair dados de iteradores sobre os quais aplicaste `zip`, podes usar um ciclo for.
- Também podes desempacotar iteradores sobre os quais aplicaste `zip` usando `*`.
  `[*content] = zip(iterator_1, iterator_2)` desempacota o `tuple` produzido por `zip()` numa `list`.
