# Introdução

Este é potencialmente um tema _enorme_!
É possível escrever um livro comprido sobre isto, e várias pessoas já o fizeram (procura "unicode book" na Amazon para veres alguns exemplos).

## Uma história muito breve

Lidar com carateres nos computadores era muito mais simples nas primeiras décadas, quando os programadores assumiam que o inglês era a única língua importante.
Assim: 26 letras, maiúsculas e minúsculas, 10 algarismos, vários sinais de pontuação, mais um código (0x07) para tocar uma campainha, e cabia tudo em 7 bits: o conjunto de carateres [ASCII][wiki-ascii].

Naturalmente, as pessoas começaram a perguntar: e quanto a à, ä e Ł? Depois, outras pessoas começaram a perguntar sobre ऄ, ஹ e ญ, e os jovens queriam emojis 😱.
O que fazer?

Resumindo, muitas pessoas inteligentes e pacientes tiveram de servir em comités durante anos, a definir os detalhes do conjunto de carateres [Unicode][web-unicode] e de codificações como o [UTF-8][wiki-utf-8], e muito software precisou de uma reescrita _muito_ complicada.
Além disso, foram introduzidos muitos bugs novos.

Para evitar que _tudo_ se quebrasse, a conceção do Unicode/UTF-8 garante que os primeiros 127 códigos são idênticos aos do ASCII _(até a campainha)_.

## Carateres em Kotlin

As linguagens concebidas depois de 2005 têm a enorme vantagem de já existir um padrão Unicode razoavelmente estável.

O Kotlin (lançado pela primeira vez em 2011) pôde assumir que os utilizadores usariam uma variedade de línguas (humanas) e precisariam do Unicode para as expressar.

Os literais de caráter escrevem-se entre plicas e são distintos das strings escritas entre aspas.
Isto é provavelmente óbvio para quem vem do mundo C/C++, mas pode ser confuso para programadores de Python e JavaScript.

```kotlin
val a = 'a'
a::class.qualifiedName  // => kotlin.Char
a.code  // => 97

val jha = 'झ'  // Devanagari alphabet
jha.code  // => 2333

val heart = '❤'  // heart emoji
heart.code  // => 10084

Char.MAX_VALUE.code  // => 65535 (64k, the largest code point allowed)
```

Converter entre `Char` e `Int` é simples:

```kotlin
a.code  // => 97  (a.toInt() is deprecated)
Char(97) // => 'a'
```

O compilador permite _algumas_ formas de aritmética de inteiros com `Char`s:

```kotlin
'a' + 5       // => 'f'
'c' - 'a'   // => 2
'c' + 'a'   // => error!

'f' + ('A' - 'a')  // => 'F' (same as 'f'.uppercase()

'f'.dec() // => 'e' (decrement)
'f'.inc() // => 'g' (increment)
```

## Algumas funções para `Char`

Como sempre, há [demasiadas funções][ref-char-lib] para discutir aqui, por isso isto é apenas uma seleção.

- Para os alfabetos adequados, muda entre maiúsculas e minúsculas com [`uppercase()`][ref-uppercase] e [`lowercase()`][ref-lowercase].
- Testa se é maiúscula ou minúscula com [`isUpperCase()`][ref-isuppercase] e [`isLowerCase()`][ref-islowercase].
- Testa o tipo de caráter com:
    - [`isLetter()`][ref-isletter], abrange muitos alfabetos
    - [`isDigit()`][ref-isdigit], no intervalo 0..9
    - `isLetterOrDigit()`, combina as duas anteriores
    - [`isWhitespace()`][ref-iswhitespace], qualquer caráter de espaço em branco

```kotlin
'झ'.isLetter()      // => true
'A'.isLowerCase()   // => false
'4'.isDigit()       // => true
'\t'.isWhitespace() // => true  (tab character)
```

## Conversões entre listas de `Char` e strings

Para converter uma string numa lista de `Char`, podemos usar `toList()`.

Para converter uma lista de `Char` numa string, existe a função [`joinToString()`][ref-jointostring], que recebe um separador (muitas vezes a string vazia) como argumento.

```kotlin
val kt = "kotlin".toList()  // => [k, o, t, l, i, n]
kt.joinToString("")   // => "kotlin"
kt.joinToString("_")  // => "k_o_t_l_i_n"
```

Repara que a `joinToString()` opera sobre uma List ou Array.
Para _converter_ um único `Char` numa string de 1 caráter, usa `toString()`.

```kotlin
'a'.toString() // => "a"
```

Para verificar se um caráter está presente numa `String`, ou numa lista ou array de `Char`, temos o `in`, que corresponde à função [`contains()`][ref-contains].

```kotlin
val clist = "kotlin".toList()  // => [k, o, t, l, i, n]
't' in clist     // => true
't' in "kotlin"  // => true
```
