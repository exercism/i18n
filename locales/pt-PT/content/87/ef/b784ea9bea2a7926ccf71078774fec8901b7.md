# Instruções

Neste exercício vais processar linhas de registo.

Cada linha de registo é uma string formatada da seguinte forma: `"[<LEVEL>]: <MESSAGE>"`.

Existem três níveis de registo diferentes:

- `INFO`
- `WARNING`
- `ERROR`

Tens três tarefas, cada uma das quais recebe uma linha de registo e pede-te para fazer algo com ela.

## 1. Obtém a mensagem de uma linha de registo

Implementa o método (_static_) `LogLine.Message()` para devolver a mensagem de uma linha de registo:

```csharp
LogLine.Message("[ERROR]: Invalid operation")
// => "Invalid operation"
```

Qualquer espaço em branco no início ou no fim deve ser removido:

```csharp
LogLine.Message("[WARNING]:  Disk almost full\r\n")
// => "Disk almost full"
```

## 2. Obtém o nível de registo de uma linha de registo

Implementa o método (_static_) `LogLine.LogLevel()` para devolver o nível de registo de uma linha de registo, que deve ser devolvido em minúsculas:

```csharp
LogLine.LogLevel("[ERROR]: Invalid operation")
// => "error"
```

## 3. Reformata uma linha de registo

Implementa o método (_static_) `LogLine.Reformat()` que reformata a linha de registo e coloca a mensagem primeiro e o nível de registo depois, entre parênteses:

```csharp
LogLine.Reformat("[INFO]: Operation completed")
// => "Operation completed (info)"
```
