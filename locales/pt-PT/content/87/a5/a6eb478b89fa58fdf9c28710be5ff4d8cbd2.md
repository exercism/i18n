# Introdução

Uma `List` é muito parecida com um `Array`. No entanto, há diferenças importantes que não deves ignorar:

1. Uma lista não pode ser indexada com parênteses retos, ou seja, `[0]`.
2. Uma lista não pode ser inicializada.
3. Não existem compreensões de listas.
4. Uma lista pode modificar livremente os seus elementos enquanto itera sobre eles.

`List` é um membro do pacote `haxe.ds`, por isso, sempre que quiseres usar listas, tens de importar o pacote:

```haxe
import haxe.ds.List;

class Main {
  static function main() {
    var myList = List<Int>();

    for (i in 0...5) {
      myList.add(i);
    }

    trace(myList); // {0, 1, 2, 3, 4}
  }
}
```
