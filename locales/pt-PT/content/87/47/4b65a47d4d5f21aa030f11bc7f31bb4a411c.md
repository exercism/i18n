# Dicas

## 1. Define o tipo externo `GbTree`

- Os tipos externos podem ser definidos com a sintaxe `pub type TypeName(a, b, c)`.

## 2. Define a função `new_gb_tree`

- As funções externas podem ser definidas com a sintaxe `@external(erlang, "module", "function")`.
- A função deve usar `gb_trees:empty/0`.

## 3. Define a função `insert`

- Consulta a documentação de `gb_trees:insert/3` para confirmares a ordem correta dos argumentos.
- A função externa pode ser uma função privada chamada pela função `insert` para alterar a ordem dos argumentos.
- A função deve usar `gb_trees:insert/3`.

## 4. Define a função `delete`

- Consulta a documentação de `gb_trees:delete_any/2` para confirmares a ordem correta dos argumentos.
- A função externa pode ser uma função privada chamada pela função `delete` para alterar a ordem dos argumentos.
- A função deve usar `gb_trees:delete_any/2`.
- A função `gb_trees:delete/2` provoca um erro se a chave não for encontrada, por isso não deve ser usada.
