# Anexo às instruções

## Palavras

`find-fewest-coins ( coins target -- result )` devolve um array
de denominações de moedas cuja soma é `target`. `coins` é um hash
set (por exemplo, `HS{ 1 5 10 25 }`); usa as palavras do vocabulário
`sets` (`members`, `in?`, …) para trabalhar com ele.

Quando nenhuma combinação de `coins` permite chegar a `target`, lança
um erro `cannot-make-change`.
