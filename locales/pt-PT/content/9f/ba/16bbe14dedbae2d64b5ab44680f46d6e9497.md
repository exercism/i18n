# Sobre

A biblioteca de sequências do Factor apoia-se fortemente em *quotations* (código
entre parênteses retos `[ ]`) para parametrizar a iteração. A forma é sempre a
mesma: passas uma sequência e uma quotation, e a word de ordem superior corre a
quotation sobre cada elemento.

```factor
{ 1 2 3 4 5 } [ even? ] filter .   ! => { 2 4 }
{ 1 2 3 4 5 } [ even? ] reject .   ! => { 1 3 5 }
{ 1 2 3 4 5 } [ 3 > ] find .s      ! => 3 / 4 (index, element)
{ 1 2 3 4 5 } [ sq ] map .         ! => { 1 4 9 16 25 }
{ 1 2 3 4 5 } [ . ] each           ! prints each element
0 { 1 2 3 4 5 } [ + ] reduce .     ! => 15
```

O conjunto habitual, completo:

| word         | forma                                       |
|--------------|---------------------------------------------|
| `each`       | `( seq quot -- )`                           |
| `map`        | `( seq quot -- newseq )`                    |
| `filter`     | `( seq quot -- newseq )`                    |
| `reject`     | `( seq quot -- newseq )`                    |
| `find`       | `( seq quot -- i/f elt/f )`                 |
| `find-last`  | `( seq quot -- i/f elt/f )`                 |
| `reduce`     | `( seq init quot -- result )`               |
| `map-sum`    | `( seq quot -- n )`                         |
| `count`      | `( seq quot -- n )`                         |
| `any?`       | `( seq quot -- ? )`                         |
| `all?`       | `( seq quot -- ? )`                         |
| `with`       | `( value seq quot -- seq curry )`           |
| `without`    | `( seq exclude -- newseq )`                 |
| `sort`       | `( seq -- sortedseq )`                      |
| `sum`        | `( seq -- n )`                              |
| `minimum`    | `( seq -- elt )`                            |
| `maximum`    | `( seq -- elt )`                            |
| `minimum-by` | `( seq quot -- elt )`                       |
| `maximum-by` | `( seq quot -- elt )`                       |

Quando *a tua* word encaminha para um destes combinadores uma quotation que só
é conhecida em tempo de execução, declara a tua word com `; inline`, para que a
inferência de efeitos do combinador consiga ver a forma da quotation no local
da chamada. As words construídas apenas com quotations literais não precisam
disso.

Para além das operações básicas sobre sequências:

| vocab              | fornece                                       |
|--------------------|-----------------------------------------------|
| [`sorting`][sorting]          | `sort`, `sort-by`                             |
| [`math.statistics`][math.statistics]  | `cum-sum`, `cum-product`, `cum-min`, `cum-max` |
| [`grouping`][grouping]         | `group`, `clump`, `monotonic-split`           |
| [`sets`][sets]             | `members`, `all-unique?`                      |

Os pares (`bi`, `tri`) e os combinadores "n-ary" (`2map`, `2each`, `zip`) seguem
o mesmo padrão quando a quotation precisa de mais do que um parâmetro de entrada.
