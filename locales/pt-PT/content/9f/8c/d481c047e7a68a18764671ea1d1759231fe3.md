# Instruções

Continuando o teu trabalho no parque de diversões, pediram-te para escreveres alguns métodos utilitários que facilitem a verificação de se um visitante pode andar numa atração.

## 1. Verifica se um visitante tem um passe para as atrações

Implementa o método `Attendee#has_pass?` para devolver um valor Boolean (`true`/`false`) com base na existência de um passe para as atrações.

```ruby
Attendee.new(100).has_pass?
# => false
```

## 2. Verifica se um visitante tem altura para uma atração

Implementa o método `Attendee#fits_ride?` para verificar se um visitante tem altura para uma atração, com base na sua altura.
A altura mínima exigida pela atração é fornecida como argumento.
Um visitante tem de ter uma altura maior ou igual à altura mínima exigida pela atração.

```ruby
Attendee.new(140).fits_ride?(100)
# => true
```

## 3. Verifica se um visitante tem permissão para andar na atração

Implementa o método `Attendee#allowed_to_ride?` para verificar se um visitante tem permissão para andar numa atração. A altura mínima exigida pela atração é fornecida como argumento. Um visitante tem de ter um passe para as atrações e de ter altura suficiente para a atração.

```ruby
attendee = Attendee.new(100)
attendee.issue_pass!(42)
attendee.allowed_to_ride?(120)
# => false
```
