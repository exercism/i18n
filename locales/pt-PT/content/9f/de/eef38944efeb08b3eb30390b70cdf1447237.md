# Dicas

## 1. Obter todos os vinhos de uma determinada cor

- Os argumentos nomeados especificam-se escrevendo um nome antes do nome do argumento, separado por um espaço.
- Podes usar a função [`list.filter`][list-filter] para selecionar elementos de uma lista que correspondam a um determinado predicado.

## 2. Obter todos os vinhos de uma determinada cor engarrafados num determinado ano

- Os argumentos nomeados especificam-se escrevendo um nome antes do nome do argumento, separado por um espaço.
- Podes usar a função [`list.filter`][list-filter] para selecionar elementos de uma lista que correspondam a um determinado predicado.

## 3. Obter todos os vinhos de uma determinada cor engarrafados num determinado país

- Esta função pode ser implementada chamando `wines_from_country` e depois `wines_of_color` ao resultado.
