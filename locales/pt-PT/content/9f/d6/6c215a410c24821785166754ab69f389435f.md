# Sobre

[F#](https://try.fsharp.org/) é uma linguagem funcional, de tipagem forte, que faz parte do conjunto de linguagens .NET da Microsoft.

Embora o F# seja ótimo para problemas de ciência de dados, também consegue lidar de forma elegante com quase todos os problemas que lhe apresentes.

Como o F# corre no runtime .NET, tens acesso a todo o ecossistema .NET, incluindo todos os pacotes em [nuget.org](https://www.nuget.org/).

A integração com código .NET existente é ainda mais simples, uma vez que o F# também te permite escrever código orientado a objetos.

A página inicial do F# é [fsharp.org](http://fsharp.org/) e encontras uma excelente introdução ao F# no site [F# for fun and profit](http://fsharpforfunandprofit.com/).
