# Sobre

A classe Lambda é uma coleção de métodos funcionais que permitem usar programação de estilo funcional com Haxe. Permite-nos operar sobre um Iterable inteiro de uma só vez. Isto é muitas vezes preferível a rotinas com ciclos, uma vez que é menos propenso a erros e mais fácil de ler. Por conveniência, as classes Array e List contêm alguns dos métodos usados com mais frequência da classe Lambda.

Algumas das funções da classe `Lambda` incluem:

- `Lambda.array`, `Lambda.list` Converte um Iterable em Array ou List. Devolve sempre uma nova instância.
- `Lambda.count` Conta o número de elementos. Se o Iterable for um Array ou uma List, é mais rápido usar a propriedade length.
- `Lambda.has` Determina se o elemento especificado está no Iterable.
- `Lambda.indexOf` Descobre o índice do elemento especificado.
- `Lambda.find` Encontra o primeiro elemento que satisfaz a função de pesquisa fornecida.
- `Lambda.concat` Junta dois Iterables, devolvendo uma nova List.
- `Lambda.filter` Encontra os elementos que satisfazem um critério, devolvendo uma nova List.

Um exemplo que demonstra algumas funções:

```haxe
using Lambda;

class Main {
  static function main() {
    var words = ["boat", "dog", "phone", "cat", "food"];

    var isThreeLetters = function(word) return word.length == 3;

    trace(words.filter(isThreeLetters)); // [dog,cat]
  }
}
```
