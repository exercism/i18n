# Instruções

Neste exercício vais processar linhas de log.

Cada linha de log é uma string com o seguinte formato: `"[<LEVEL>]: <MESSAGE>"`.

Existem três níveis de log diferentes:

- `INFO`
- `WARNING`
- `ERROR`

Tens três tarefas, cada uma das quais recebe uma linha de log e pede-te que faças algo com ela.

## 1. Obter a mensagem de uma linha de log

Implementa o método (_static_) `LogLevels.message()` para devolver a mensagem de uma linha de log:

```java
LogLevels.message("[ERROR]: Invalid operation")
// => "Invalid operation"
```

Qualquer espaço em branco no início ou no fim deve ser removido:

```java
LogLevels.message("[WARNING]:  Disk almost full\r\n")
// => "Disk almost full"
```

## 2. Obter o nível de log de uma linha de log

Implementa o método (_static_) `LogLevels.logLevel()` para devolver o nível de log de uma linha de log, que deve ser devolvido em minúsculas:

```java
LogLevels.logLevel("[ERROR]: Invalid operation")
// => "error"
```

## 3. Reformata uma linha de log

Implementa o método (_static_) `LogLevels.reformat()` que reformata a linha de log, colocando a mensagem primeiro e o nível de log depois, entre parênteses:

```java
LogLevels.reformat("[INFO]: Operation completed")
// => "Operation completed (info)"
```
