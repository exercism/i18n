# Instruções

Neste exercício vais trabalhar num agendador de marcações para um salão de beleza que abriu a 15 de setembro de 2012.

Tens cinco tarefas, todas elas relacionadas com datas de marcações.

## 1. Interpreta a data da marcação

Implementa a função `Schedule` para interpretar uma representação textual da data de uma marcação no formato `time.Time` correspondente:

```go
Schedule("7/25/2019 13:45:00")
// => 2019-07-25 13:45:00 +0000 UTC
```

## 2. Verifica se uma marcação já passou

Implementa a função `HasPassed`, que recebe a data de uma marcação e verifica se a marcação está algures no passado:

```go
HasPassed("July 25, 2019 13:45:00")
// => true
```

## 3. Verifica se a marcação é à tarde

Implementa a função `IsAfternoonAppointment`, que recebe a data de uma marcação e verifica se a marcação é à tarde (>= 12:00 e < 18:00):

```go
IsAfternoonAppointment("Thursday, July 25, 2019 13:45:00")
// => true
```

## 4. Descreve a hora e a data da marcação

Implementa a função `Description`, que recebe a data de uma marcação e devolve uma descrição dessa data e hora:

```go
Description("7/25/2019 13:45:00")
// => "You have an appointment on Thursday, July 25, 2019, at 13:45."
```

## 5. Devolve a data de aniversário da abertura do salão

Implementa a função `AnniversaryDate`, que devolve a data de aniversário da abertura do salão para o ano atual em UTC.

Partindo do princípio de que o ano atual é 2020:

```go
AnniversaryDate()

// => 2020-09-15 00:00:00 +0000 UTC
```

**Nota:** o valor devolvido é um `time.Time` e a hora do dia não importa.
