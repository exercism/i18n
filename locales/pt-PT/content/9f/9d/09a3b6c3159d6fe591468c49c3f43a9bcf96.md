# Structs

As structs são tipos de dados personalizados que te permitem agrupar e dar nome a vários valores relacionados.
São semelhantes às tuplas, mas mais flexíveis, e permitem-te dar um nome a cada dado, o que torna o teu código mais claro.
As structs em Cairo têm estas propriedades:

- Cada tipo de struct tem um nome específico.
- Cada membro de uma struct chama-se **campo**.
- Cada campo de uma struct tem um nome específico.
- A visibilidade é gerida ao nível do campo: cada campo pode ser público ou privado de forma independente.

## Definir e instanciar structs

Para definir uma struct, usa a palavra-chave `struct` seguida de um nome e de chavetas que contêm os campos, com os respetivos nomes e tipos:

```rust
#[derive(Drop)]
struct User {
    active: bool,
    username: ByteArray,
    email: ByteArray,
    sign_in_count: u64,
}
```

Para criar uma instância de uma struct, indica o nome da struct e usa chavetas com pares chave-valor para os campos.
Repara que podes listar os campos por qualquer ordem ao criar uma instância:

```rust
let user1 = User {
   active: true, username: "someusername123", email: "someone@example.com", sign_in_count: 1
};

let user2 = User {
    sign_in_count: 1, username: "someusername123", active: true, email: "someone@example.com"
};
```

## Interagir com uma instância de uma struct

Usa a notação de ponto para aceder aos campos de uma instância de struct e para os modificar.
Repara que, para modificar um campo, a instância tem de ser mutável:

```rust
let mut user1 = User {
    active: true, username: "someusername123", email: "someone@example.com", sign_in_count: 1
};
user1.email = "anotheremail@example.com";
```

Tal como em qualquer expressão, podemos construir uma nova instância da struct como última expressão do corpo da função, para devolver implicitamente essa nova instância:

```rust
fn build_user(email: ByteArray, username: ByteArray) -> User {
    User {
        email: email,
        username: username,
        active: true,
        sign_in_count: 1,
    }
}
```

## Abreviatura de inicialização de campos

No último exemplo, fazia sentido dar aos parâmetros `email` e `username` da função os mesmos nomes que os campos da struct, mas ter de os repetir ao atribuí-los aos campos da struct é um pouco maçador.
Felizmente, existe uma abreviatura prática para inicializar campos de uma struct a partir de variáveis com os mesmos nomes:

```rust
fn build_user_short(email: ByteArray, username: ByteArray) -> User {
    User { email, username, active: true, sign_in_count: 1, }
}
```

## Criar instâncias a partir de outras instâncias com a sintaxe de atualização de structs

Usa a sintaxe de atualização de structs para criar uma nova instância a partir de uma já existente, alterando alguns campos e mantendo os restantes iguais.
Para isso, usa-se o operador `..`.

Sem a sintaxe de atualização:

```rust
let user2 = User {
    active: user1.active,
    username: user1.username,
    email: "another@example.com",
    sign_in_count: user1.sign_in_count,
};
```

Com a sintaxe de atualização:

```rust
let user2 = User { email: "another@example.com", ..user1 };
```

A sintaxe `..user1` copia os campos restantes de `user1` para `user2`.
Repara que isto move os dados de `user1` para `user2`, por isso já não podes usar `user1` depois, se este contiver tipos não copiáveis.
