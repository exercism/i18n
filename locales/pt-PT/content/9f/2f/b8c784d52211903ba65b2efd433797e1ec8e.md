# Introdução

A entrada/saída (I/O) do Factor assenta em *fluxos*: objetos dos quais lês bytes ou carateres, ou para os quais os escreves. O vocabulário [`io`][io] dá-te duas perspetivas do mesmo [protocolo][stream-protocol].

## As duas perspetivas

As palavras de **fluxo explícito** recebem o fluxo como argumento. Começam todas por `stream-`:

```
stream-read       ( n stream -- seq/f )
stream-readln     ( stream -- str/f )
stream-write      ( seq stream -- )
stream-flush      ( stream -- )
stream-contents   ( stream -- seq )
stream-lines      ( stream -- seq )
```

As palavras de **fluxo ambiente** leem de, ou escrevem para, o fluxo que estiver *associado no momento*: a variável dinâmica de todo o programa, `input-stream` ou `output-stream`. Têm nomes curtos:

```
read1 read readln write write1 print flush
```

A forma ambiente é a que a maior parte do código do dia a dia usa. A forma explícita é aquela a que recorres quando tens um fluxo específico em mãos e não queres trocar o ambiente.

## Fluxos em memória

Para o exercício, vais trabalhar com fluxos com suporte em string de [`io.streams.string`][io.streams.string]:

```
<string-reader>   ( str -- reader )
<string-writer>   ( -- writer )
```

Um `<string-reader>` lê de uma string literal como se fosse um ficheiro; um `<string-writer>` recolhe tudo o que se escreve nele para o poderes ler mais tarde. Ambos implementam o mesmo protocolo que os fluxos de ficheiro, por isso as lições transferem-se diretamente para `<file-reader>` / `<file-writer>`.

## Âmbito com `with-…`

Para associares um fluxo explícito como o fluxo ambiente de um bloco de código e o descartares depois, usa um combinador `with-…`:

```
with-input-stream    ( stream quot -- )
with-output-stream   ( stream quot -- )
with-string-writer   ( quot -- str )
with-file-reader     ( path encoding quot -- )
with-file-writer     ( path encoding quot -- )
```

[`with-string-writer`][with-string-writer] é a forma prática para "recolher o que este bloco de código imprime": constrói o writer, executa o bloco de código com esse writer como saída ambiente e devolve a string capturada:

```factor
USING: io io.streams.string ;

[ "captured" print ] with-string-writer .
! => "captured\n"
```

Todos os combinadores `with-…` são combinadores destrutores (a mesma família de `with-disposal` e `with-destructors` de [`boatswains-bilge`][boatswains-bilge]): o fluxo é descartado à saída, mesmo que o bloco de código lance uma exceção.
