# Instruções

Estás a ajudar um amigo a gerar um relatório a partir das leituras que ele fez em diferentes cantos do seu jardim.
Infelizmente, o teu amigo guardou os dados num formato estranho.
Cada leitura é um conjunto de campos separados por vírgulas.
No entanto, ele guardou números de dois algarismos distribuídos por duas colunas.

| número do campo | significado |
| --- | --- |
| 1 | número de identificação |
| 2 | localização |
| 3 | primeira leitura, algarismo das dezenas |
| 4 | primeira leitura, algarismo das unidades |
| 5 | segunda leitura, algarismo das dezenas |
| 6 | segunda leitura, algarismo das unidades |

Para uma linha de entrada como `101,house,4,2,5,4`
- a primeira leitura é `42`,
- a segunda leitura é `54`.

## Tarefa 1: Gerar o relatório

A tua tarefa é encontrar a média das duas leituras e apresentar os resultados de cada linha no seguinte formato

```none
#<id>, <label> = <average>
```

Como a média de 42 e 54 é 48, o resultado para a linha de exemplo deve ser:

```none
#101, house = 48
```
