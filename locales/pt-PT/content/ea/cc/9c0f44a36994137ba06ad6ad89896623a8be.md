# Instruções

A Mecha Munch™, uma empresa de automatização de compras de supermercado, acabou de te contratar para trabalhares na sua aplicação de encomendas.
A tua equipa tem a tarefa de criar um MVP (_[produto mínimo viável][mvp]_) que gere todas as atividades básicas do carrinho de compras, permitindo aos utilizadores adicionar, remover e ordenar as suas encomendas de supermercado.
Felizmente, há outra equipa a tratar de tudo o que diz respeito ao dinheiro e ao pagamento!

## 1. Adiciona artigo(s) ao carrinho de compras do utilizador

O MVP deve permitir que o utilizador adicione artigos ao seu carrinho de compras.
Pode ser um único artigo ou vários artigos de uma só vez.
Como se trata de um MVP, a quantidade de cada artigo é indicada por _repetições_.
Se um utilizador quiser adicionar 2 Oranges, «Oranges» aparece duas vezes no iterável de entrada.
Se o utilizador já tiver o artigo no carrinho, a quantidade no carrinho deve ser aumentada em 1.
Se o artigo for _novo_ no carrinho, deve ser adicionado com uma quantidade de 1.

Cria a função `add_items!(<cart>, <items>)` que recebe um dicionário que representa o carrinho e um iterável de artigos a adicionar como argumentos.
Deve devolver o dicionário do carrinho de compras atualizado do utilizador.

```julia-repl
julia> additems!(Dict("Banana" => 3, "Apple" => 2, "Orange" => 1),
                 ("Apple", "Apple", "Orange", "Apple", "Banana"))
Dict{String, Int64} with 3 entries:
  "Apple"  => 5
  "Orange" => 2
  "Banana" => 4

julia> additems!(Dict("Banana" => 3, "Apple" => 2, "Orange" => 1),
                 ["Banana", "Orange", "Blueberries", "Banana"])
Dict{String, Int64} with 4 entries:
  "Blueberries" => 1
  "Apple"       => 2
  "Orange"      => 2
  "Banana"      => 5
```

## 2. Atualiza a secção «ideias» de receitas

A aplicação tem uma secção «ideias» preenchida com receitas completas de várias cozinhas.
O utilizador pode selecionar qualquer uma destas receitas e fazer com que todos os seus ingredientes sejam adicionados automaticamente ao carrinho de compras.
O responsável pelo projeto pediu-te para criares uma forma de editar estas receitas «ideias», uma vez que a equipa de conteúdos está sempre a alterar ingredientes e quantidades.

Cria a função `update_recipes!(<ideas>, <updates>)` que recebe um dicionário «ideias» e um dicionário de atualizações de receitas como argumentos.
A função deve devolver o dicionário «ideias» atualizado.

## 3. Envia o carrinho de compras do utilizador para a loja, para preparação

A aplicação precisa de enviar o carrinho de um determinado utilizador para a loja, para preparação.
No entanto, quem prepara as encomendas na loja precisa de saber onde encontrar cada artigo, através de um código de corredor único.
O «carrinho de preparação» tem de ser ordenado pela ordem dos códigos de corredor dos artigos, para ajudar quem prepara as encomendas a ser mais eficiente.

Cria a função `send_to_store(<cart>, <aislecodes>)` que recebe o carrinho de compras de um utilizador e um dicionário com os números de corredor da loja.
A função deve devolver um «carrinho de preparação» combinado, com um par `aislecode => quantity` para cada artigo que o cliente está a encomendar.
Os artigos devem aparecer pela ordem dos respetivos códigos de corredor.

```julia-repl
julia> cart = Dict("Orange" => 1, "Milk" => 2, "Banana" => 3, "Apple" => 2, "Chocolate" => 2);

julia> aislecodes = Dict("Orange" => 2.4, "Milk" => 3.3, "Banana" => 2.6, "Apple" => 2.2, "Chocolate" => 5.7);

julia> send_to_store(cart, aislecodes)
5-element Vector{Pair{Float64, Int64}}:
 2.2 => 2
 2.4 => 1
 2.6 => 3
 3.3 => 2
 5.7 => 2
```

## 4. Atualiza o inventário da loja de acordo com o que o utilizador encomendou

A aplicação não pode limitar-se a fazer encomendas de clientes indefinidamente.
Mais cedo ou mais tarde, a loja vai ficar sem vários produtos.
Por isso, o MVP da tua aplicação precisa de atualizar o inventário da loja sempre que um utilizador envia a sua encomenda para a loja.
Caso contrário, os clientes vão encomendar produtos que na verdade não estão disponíveis.

Cria a função `update_store_inventory!(<inventory>, <cart>)` que recebe um `cart` e um `inventory`.
A função deve reduzir as quantidades do inventário da loja pelo número «encomendado» no «carrinho» e depois devolver um dicionário com os artigos que estão esgotados (ou seja, que chegaram a `0`).

```julia-repl
julia> inventory = Dict("Banana" => 15, "Apple" => 12, "Orange" => 1, "Milk" => 4);

julia> cart = Dict("Orange" => 1, "Milk" => 2, "Banana" => 3, "Apple" => 2);

julia> update_store_inventory!(inventory, cart)
Dict{String, Int64} with 1 entry:
  "Orange" => 0

julia> inventory
Dict{String, Int64} with 4 entries:
  "Milk"   => 2
  "Apple"  => 10
  "Orange" => 0
  "Banana" => 12
```

## 5. Encomenda de novo os artigos esgotados

Além de atualizar o inventário, a tua aplicação também pode ajudar a reabastecê-lo.
O teu MVP deve conseguir preparar uma mini-encomenda de todos os artigos que ficam esgotados depois da encomenda de um cliente.
Isto vai ajudar a simplificar o lançamento de uma encomenda maior.
Além disso, por vezes há artigos promocionais por tempo limitado que não estão na lista de stock.
Se se esgotarem antes de terminar o período promocional, é sinal de que são populares e podem ser adicionados à lista de stock.

Cria a função `reorder!(<outofstock>, <stock>)` que recebe `outofstock` e `stock`.
O dicionário `stock` contém os artigos de stock habituais e as respetivas quantidades de reencomenda.
O dicionário `outofstock` é o resultado de `update_store_inventory!`, ou seja, um dicionário com os artigos de quantidade zero.
As quantidades de `outofstock` devem ser atualizadas de acordo com as de `stock` e devolvidas.
Além disso, os artigos de `outofstock` que não estejam presentes em `stock` devem ser adicionados a `stock` com uma quantidade predefinida de `100`.

```julia-repl
julia> inventory = Dict("Banana" => 15, "Apple" => 12, "Orange" => 1, "Milk" => 4, "Chocolate" => 2);

julia> cart = Dict("Orange" => 1, "Milk" => 2, "Banana" => 3, "Apple" => 2, "Chocolate" => 2);

julia> stock = Dict("Banana" => 150, "Apple" => 120, "Orange" => 120, "Milk" => 45);

julia> outofstock = update_store_inventory!(inventory, cart)
Dict{String, Int64} with 1 entry:
  "Orange"    => 0
  "Chocolate" => 0

julia> reorder!(outofstock, stock)
Dict{String, Int64} with 1 entry:
  "Orange"    => 120
  "Chocolate" => 100

julia> stock 
Dict{String, Int64} with 5 entries:
  "Milk"      => 45
  "Apple"     => 120
  "Chocolate" => 100
  "Orange"    => 120
  "Banana"    => 150
```
