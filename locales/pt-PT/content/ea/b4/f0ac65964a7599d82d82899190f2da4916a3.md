# Anexo às instruções

## Como este exercício está estruturado em Python


O Python oferece uma grande variedade de funções matemáticas, sob a forma do [módulo math][math-module] e de funções incorporadas como o operador de exponenciação `**`, a [`pow()`][pow] e a [`sum()`][sum].
No entanto, gostaríamos que considerasses o desafio de resolver este exercício sem essas funções incorporadas nem esses módulos.

Embora exista uma fórmula matemática que calcula a raiz quadrada de _qualquer_ número, optámos por ter apenas [números naturais][nautral-number] (inteiros positivos) como soluções.  
É possível calcular a raiz quadrada de qualquer número natural usando apenas números naturais no cálculo.
