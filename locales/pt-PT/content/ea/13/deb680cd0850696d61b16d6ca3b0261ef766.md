# Introdução

O [Go](https://golang.org) é uma linguagem de programação compilada e de tipagem estática.
Este exercício apresenta três funcionalidades importantes da linguagem: pacotes, funções e variáveis.

## Pacotes

As aplicações em Go organizam-se em pacotes.
Um pacote é um conjunto de ficheiros de código-fonte que estão no mesmo diretório.
Todos os ficheiros de código-fonte num diretório têm de ter o mesmo nome de pacote.
Quando um pacote é importado, só as entidades (funções, tipos, variáveis, constantes) cujos nomes começam por letra maiúscula podem ser usadas ou acedidas.
O estilo de nomenclatura recomendado em Go é usar `camelCase` para os identificadores, exceto para aqueles que devem ser acessíveis entre pacotes, que devem usar `PascalCase`.

```go
package lasagna
```

## Variáveis

O Go tem tipagem estática, o que significa que todas as variáveis [têm de ter um tipo definido](https://en.wikipedia.org/wiki/Type_system) em tempo de compilação.

As variáveis podem ser definidas especificando explicitamente um tipo:

```go
var explicit int // Explicitly typed
```

Também podes usar um inicializador, e o compilador atribui à variável o tipo correspondente ao do inicializador.

```go
implicit := 10   // Implicitly typed as an int
```

Depois de declarada, podes atribuir valores a uma variável com o operador `=`.
Depois de declarada, o tipo de uma variável nunca muda.

```go
count := 1 // Assign initial value
count = 2  // Update to new value

count = false // This throws a compiler error due to assigning a non `int` type
```

## Constantes

As constantes guardam um valor tal como as variáveis, mas o seu valor não pode mudar durante a execução do programa.

As constantes definem-se com a palavra-chave `const` e podem ser números, carateres, strings ou Boolean:

```go
const Age = 21 // Defines a numeric constant 'Age' with the value of 21
```

## Funções

As funções em Go aceitam zero ou mais parâmetros.
Os parâmetros têm de ter tipo explícito; não há inferência de tipos.

Os valores são devolvidos pelas funções com a palavra-chave `return`.

Uma função é invocada indicando o nome da função e passando argumentos para cada um dos seus parâmetros.

Repara que o Go suporta dois tipos de comentários.
Os comentários de uma linha são precedidos por `//` e os comentários de várias linhas são inseridos entre `/*` e `*/`.

```go
package greeting

// Hello is a public function.
func Hello (name string) string {
    return hi(name)
}

// hi is a private function.
func hi (name string) string {
    return "hi " + name
}
```
