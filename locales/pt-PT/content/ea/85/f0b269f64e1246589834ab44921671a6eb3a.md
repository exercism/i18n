# Introdução

Além das declarações de função e das expressões de função, o JavaScript também tem outra sintaxe muito concisa para definir uma função.
Estas funções chamam-se _funções arrow_.

Neste conceito, vamos focar-nos na sintaxe usada para escrever uma função arrow.
Há diferenças na forma como uma função arrow funciona, como a ligação do _this_, que serão abordadas noutros conceitos.

Aqui está uma comparação entre uma declaração de função e uma função arrow.

```javascript
function addUpTwoNumbers(num1, num2) {
  return num1 + num2;
}

// function keyword removed and => added
const addUpTwoNumbers = (num1, num2) => {
  return num1 + num2;
};
```

Acima, vais ver que a sintaxe da função arrow:

1. remove a palavra-chave `function`
2. declara o identificador `addUpTwoNumbers` como uma `const`
3. acrescenta uma seta grossa `=>`

Se o corpo da função contiver apenas uma instrução `return`, como no exemplo acima, as `{}` e a palavra-chave `return` podem ser omitidas.

<!-- prettier-ignore-start -->
```javascript
const addUpTwoNumbers = (num1, num2) => { return num1 + num2 };

// can be shortened to
const addUpTwoNumbers = (num1, num2) => num1 + num2;
// braces {} and return removed
```
<!-- prettier-ignore-end -->

No caso especial de devolver apenas um objeto a partir de uma função arrow, são necessários parênteses à volta do objeto para poder omitir a instrução `return`.

```javascript
// explicit return of object
const addUpTwoNumbers = (num1, num2) => {
  return {
    num1,
    num2,
  };
};

// implicit return of object
const addUpTwoNumbers = (num1, num2) => ({ num1, num2 });
```

O uso de parênteses à volta dos parâmetros depende do número de parâmetros.

<!-- prettier-ignore-start -->
```javascript
// one parameter does not need parenthesis
const square = num => num * num;

// two or more parameters need to be wrapped in parenthesis
const addUpTwoNumbers = (num1, num2) => num1 + num2;
```
<!-- prettier-ignore-end -->
