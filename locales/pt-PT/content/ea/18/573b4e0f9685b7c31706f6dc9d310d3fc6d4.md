# Aprender C#

## Sites

- A [documentação oficial do C#](https://docs.microsoft.com/en-us/dotnet/articles/csharp/) tem ótimos conteúdos sobre uma grande variedade de temas, incluindo [tutoriais](https://docs.microsoft.com/en-us/dotnet/articles/csharp/tutorials/index) e uma [visita guiada à linguagem](https://docs.microsoft.com/en-us/dotnet/articles/csharp/tour-of-csharp/index).
- [Learn C#](http://www.learncs.org/) é um tutorial interativo que funciona no browser e que te apresenta os conceitos fundamentais da programação em C#.

## Vídeos

- [C# 101](https://www.youtube.com/playlist?list=PLdo4fOcmZ0oVxKLQCHpiUWun7vlJJvUiN) Os conceitos e a sintaxe da linguagem de programação C#, com demonstrações de código ao vivo.
- [.NET Core 101](https://www.youtube.com/playlist?list=PLdo4fOcmZ0oWoazjhXQzBKMrFuArxpW80) Tudo sobre «O que é o .NET» e como publicar a tua primeira aplicação.
- [Programming in C# Jump Start](https://channel9.msdn.com/Series/Programming-in-C-Jump-Start) é uma boa introdução passo a passo à programação em C#.
- [C# Fundamentals for Absolute Beginners](https://mva.microsoft.com/en-US/training-courses/c-fundamentals-for-absolute-beginners-16169?l=Lvld4EQIC_2706218949) é uma ótima forma de conhecer o C#.
- A [PluralSight](https://www.pluralsight.com/) tem vários [ótimos](https://www.pluralsight.com/courses/csharp-6-from-scratch) [cursos](https://www.pluralsight.com/courses/c-sharp-fundamentals-with-visual-studio-2015) [de introdução](http://www.pluralsight.com/courses/csharp-best-practices-improving-basics). O inconveniente: a PluralSight é um serviço pago, mas podes pedir um [teste gratuito](https://www.pluralsight.com/pricing).
