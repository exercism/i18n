# Instruções

Neste exercício vais escrever código para imprimir crachás com o nome dos funcionários da fábrica.

## 1. Imprimir um crachá para um funcionário

Os funcionários têm um ID, um nome e o nome do departamento. As etiquetas dos crachás dos funcionários têm o seguinte formato: `"[id] - name - DEPARTMENT"`.
Implementa o método `Badge.print()` para devolver a etiqueta do crachá de um funcionário:

```java
Badge badge = new Badge();
badge.print(734, "Ernest Johnny Payne", "Strategic Communication");
// => "[734] - Ernest Johnny Payne - STRATEGIC COMMUNICATION"
```

Repara que o departamento deve aparecer em maiúsculas na etiqueta.

## 2. Imprimir um crachá para um novo funcionário

Devido a uma peculiaridade do sistema informático, por vezes os novos funcionários ainda não têm um ID quando começam a trabalhar na fábrica.
Como os crachás são obrigatórios, recebem um crachá temporário sem o prefixo do ID. Altera o método `Badge.print()` para suportar novos funcionários que ainda não têm um ID:

```java
Badge badge = new Badge();
Badge.print(null, "Jane Johnson", "Procurement");
// => "Jane Johnson - PROCUREMENT"
```

## 3. Imprimir um crachá para o proprietário

Até o proprietário da fábrica tem de usar um crachá a toda a hora.
No entanto, o proprietário não tem departamento. Nesse caso, a etiqueta deve imprimir `"OWNER"` em vez do nome do departamento.
Altera o método `Badge.print()` para imprimir uma etiqueta para o proprietário:

```java
Badge badge = new Badge();
badge.print(254, "Charlotte Hale", null);
// => "[254] - Charlotte Hale - OWNER"
```

Repara que é possível que o proprietário também seja um novo funcionário:

```java
Badge badge = new Badge();
badge.print(null, "Charlotte Hale", null);
// => "Charlotte Hale - OWNER"
```
