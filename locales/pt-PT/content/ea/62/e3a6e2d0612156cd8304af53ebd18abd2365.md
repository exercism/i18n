# Instruções (apêndice)

## Estrutura do projeto

Os exercícios de Clojure no Exercism suportam as duas ferramentas mais comuns para a gestão de dependências e testes, o [leiningen][leiningen] e a [Clojure CLI][clojure-cli].

Vais encontrar um ficheiro de testes chamado `hello_world_test.clj` dentro da pasta `test`.
Escreve o teu código em `src/hello_world.clj`. Deve usar o namespace `hello-world` para que os testes o consigam detetar.

### Executar os testes com a Clojure CLI

```
$ clj -X:test
```

### Executar os testes com o Leiningen

```
$ lein test

lein test hello-world-test

Ran 3 tests containing 3 assertions.
0 failures, 0 errors.
```

Depois, submete o exercício com:

```
$ exercism submit src/hello_world.clj
```

Para instruções mais detalhadas e recursos de aprendizagem, consulta a [página da linguagem Clojure do Exercism][exercism-clojure].

[leiningen]: https://leiningen.org
[clojure-cli]: https://clojure.org/guides/deps_and_cli
[exercism-clojure]: https://exercism.org/tracks/clojure
