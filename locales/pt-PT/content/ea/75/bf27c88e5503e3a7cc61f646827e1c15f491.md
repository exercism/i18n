# Boutique de Moda

## História

Tens uma boutique de moda online. O Black Friday está a chegar, por isso precisas de fazer o balanço do teu inventário para garantir que estás pronto.

Cada artigo do inventário é representado por um mapa/dicionário, e o inventário completo é uma lista/array desses mapas/dicionários.

```elixir
%{
  name: "White Shirt",
  price: 40,
  quantity_by_size: %{s: 3, m: 7, l: 8, xl: 4}
}
```

## Tarefas

- Ordena os artigos por preço
- Encontra todos os artigos sem preço
- Incrementa a quantidade do artigo
- Calcula a quantidade total do artigo
