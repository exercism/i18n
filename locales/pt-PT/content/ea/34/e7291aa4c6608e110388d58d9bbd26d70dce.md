# Dicas

## 1. Verifica o nível de humidade da sala

- Lógica simples de if...else.
- Um operador ternário é suficiente.
- Esta tarefa usa uma função `error()`, não `throw()`.
- A macro `@info` também é necessária.
- Lê a secção de registo da introdução para veres como gerar mensagens de registo.

## 2. Verifica se há sobreaquecimento

- Há duas condições de falha a testar.
- Cada uma precisa de um `throw()` se falhar.
- A macro `@info` é necessária para o sucesso.

## 3. Define um erro personalizado

- Vê a introdução para veres um exemplo de como definir um erro personalizado.
- Os campos e as mensagens de impressão personalizadas são possíveis, mas não são obrigatórios.

## 4. Monitoriza a máquina

- Podes usar as funções `humiditycheck` e `temperaturecheck`, mas isso não é estritamente necessário.
- Se as usares, deves conseguir verificar de forma independente se ambas as funções lançam erros e adicionar os registos adequados.
- Uma variável definida fora de um bloco `try...catch` pode ser atualizada a partir de dentro do bloco, se for necessário.
- Lembrete: se uma ou ambas as verificações falharem, só precisas de lançar um `MachineError` depois de adicionares os registos.
