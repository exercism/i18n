# Introdução

## Instruções condicionais

As instruções condicionais são instruções de decisão que podem executar efeitos secundários ou controlar o fluxo de execução de um programa.
Incluem as instruções `if`, `if/else`, `switch` e `ternary`.

Servem para fazer perguntas sobre um valor ou sobre uma relação entre valores.
A pergunta resulta numa resposta Boolean, mas a própria instrução `if` pode devolver qualquer valor ou pode simplesmente executar um efeito secundário.

## Instruções if

A instrução `if` mais simples avalia uma expressão e executa uma linha.
A expressão que está a ser testada é sempre colocada entre parênteses.

Pode executar um efeito secundário

```c
if (count > 10)
    printf("count is greater than 10");
```

ou pode alterar o fluxo de execução


```c
if (count > 10)
    return sum;
```

Se uma instrução `if` executar mais do que uma linha, tem de colocar essas linhas entre chavetas

```c
if (count > 10) {
    printf("count is greater than 10");
    return sum;
}
```

Algumas equipas de programação podem definir como norma que as instruções `if` usem sempre chavetas, mesmo para uma só linha.


## If else

Uma instrução `if` pode ser combinada com um `else`

```c
if (number % 2 == 0)
    return "even";
else
    return "odd";
```

## If else if


Um `else` pode ser combinado com outro `if` para criar o que se chama uma `if-else-if ladder`.

```c
if (number == 0)
    return "zero";
else if (number < 0)
    return "negative";
else if (number < 10)
    return "single digit";   
else if (number % 2 == 0)
    return "even";
else
    return "odd";
```

## Switch


Por vezes, uma `if-else-if ladder` pode ser melhor representada por um `switch`.
Tal como no `if`, a expressão que está a ser testada é sempre colocada entre parênteses.

```c
switch (number) {
    case -1:
        return "negative one";
    case 0:
        return "zero";
    case 1:
        return "positive one";
    case 10:
        return "positive ten";
    case -10:
        return "negative ten";
    default:
        return "don't care";
}
```

O caso `default` é executado se o valor que está a ser testado não corresponder a nenhum dos casos anteriores.

Se um caso de `switch` não devolver nada, normalmente insere-se um `break` para terminar cada caso; caso contrário, a lógica "cai" para o caso seguinte.
Por vezes, essa queda é intencional

```c
switch (number) {
    case 0:
        msg = "zero"; break;
    case 1:
        msg = "one"; break;
    case 2: case 3: case 4:
        msg = "more than one and less than five"; break;
    default:
        msg = "don't care";
}
```

Quando essa queda acontece sem intenção, é um bug.

```c
switch (number) {
    case 0:
        msg = "zero"; // bug! fallthrough of 0 will set msg to "one"
    case 1:
        msg = "one"; break; 
    case 2: case 3: case 4:
        msg = "more than one and less than five"; break;
    default:
        msg = "don't care";
}
```

Um switch pode ser vantajoso quando se testa contra valores específicos em vez de um intervalo de valores.
Pode ser mais rápido do que uma `if-else-if ladder`, porque o compilador pode conseguir otimizar a instrução `switch` de formas que não consegue com uma ladder.
Um switch pode, por vezes, parecer mais legível do que uma ladder.

## Operador ternário (também conhecido como condicional)

O operador ternário é uma instrução condicional de três partes, muitas vezes usada para definir um valor.
A expressão a testar vem antes do ponto de interrogação e não tem de estar entre parênteses.
O valor devolvido se for verdadeiro vem antes dos dois pontos; o valor devolvido se for falso vem depois dos dois pontos.
Tanto pode ser devolvido um literal como uma variável.

```c
int i = j > 5 ? 5: j;
```

Os operadores ternários podem ser aninhados para reduzir a confusão sintática.

```c
// the below could also be 
i = j > 5 ? j :k > 5 ? k: 10;
// but that may not be quite as readable

i = j > 5 ? j
    :k > 5 ? k
    :10;

// which is the same as
if (j > 5) i = j;
else if (k > 5) i = k;
else i = 10;
```
