# Dicas

## Geral

- O [Tutorial de strings][python-str-doc] da documentação do Python tem uma visão geral do tipo `str` do Python.
- Os métodos de string [`str.join()`][str-join] e [`str.split()`][str-split] são muito úteis quando processas strings.
- A documentação do Python sobre [Tipos de sequência][common sequence operations] tem uma descrição das operações comuns a todas as sequências, incluindo `strings`, `lists`, `tuples` e `ranges`.

O exercício tem quatro atividades, cada uma com um conjunto de texto ou palavras com que trabalhar.

## 1. Adicionar um prefixo a uma palavra

- As strings pequenas podem ser concatenadas com o operador `+`.

## 2. Adicionar prefixos a grupos de palavras

- Por incrível que pareça, [`str.join()`][str-join] é tudo o que precisas aqui. **Não é preciso um ciclo**.
- Os testes vão passar à tua função uma `list`. Não precisas de alterar esta `list` se conseguires descobrir uma boa string delimitadora.
- Lembra-te de que as strings delimitadoras ficam entre os elementos e «colam»-nos numa única string. Os delimitadores são inseridos _sem_ espaços, embora possas incluir caracteres de espaço dentro deles.
- Tal como [`str.split()`][str-split], `str.join()` consegue processar uma string de comprimento arbitrário, formada por quaisquer pontos de código unicode. _Ao contrário_ de `str.split()`, também consegue processar iteráveis de comprimento arbitrário, como `list`, `tuple` e `set`.

## 3. Remover um sufixo de uma palavra

- As strings podem ser indexadas ou fatiadas tanto a partir da esquerda (começando em 0) como da direita (começando em -1).
- Se quiseres o último ponto de código de uma string de comprimento arbitrário, podes usar `[-1]`.
- As últimas três letras de uma string podem ser «cortadas» com um índice negativo. Por exemplo: `beautiful'[:-3] == 'beauti`

## 4. Extrair e transformar uma palavra

- Usar [`str.split()`][str-split] devolve uma `list` de strings separadas por espaços em branco.
- As `lists` são sequências e podem ser indexadas.
- [`str.split()`][str-split] pode ser indexado diretamente: `'Exercism rocks!'.split()[0] == 'Exercism'`
- Cuidado com a pontuação! Os pontos finais podem ser removidos com uma fatia: `'dark.'[:-1] == 'dark'`
