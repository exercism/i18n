# Instruções

Tu! Sim, tu, destemido programador de Lisp! [Lenny, o alienígena lisp][alien] precisa da tua ajuda! O Lenny quer ir andar com todos os outros alienígenas lisp, mas os pais disseram-lhe que não vai a lado nenhum enquanto o quarto não estiver limpo.

O problema é que o Lenny quase não consegue ver o chão! O Lenny não consegue distinguir os seus átomos dos seus conses, os seus símbolos das suas palavras-chave, os seus `car`s dos seus `cdr`s!

Consegues ajudar o Lenny a arrumar esta confusão? Não te esqueças dos [teus parênteses][xkcd], vais precisar deles!

## 1. Relembra ao Lenny o que são os símbolos

Antes de o Lenny começar, precisa de relembrar o aspeto dos símbolos e das palavras-chave: já há algum tempo que não arruma nada... Ajuda o Lenny definindo duas funções: `lennys-favorite-food`, que avalia para um símbolo, e `lennys-secret-keyword`, que avalia para uma palavra-chave. Por exemplo:

```lisp
(lennys-favorite-food) ; => LASAGNA
```

```lisp
(lennys-secret-keyword) ; => :ALIENS-ARE-REAL
```

Repara que podes devolver o símbolo ou a palavra-chave que quiseres (se não fores fã de lasanha ou não acreditares em alienígenas).

## 2. Ajuda o Lenny a distinguir entre átomos e conses

Depois de relembrar os símbolos e as palavras-chave, está na hora de arrumar! Para organizar todas as S-Expressions espalhadas pelo quarto, o Lenny precisa de ajuda para determinar o que é um cons e o que é um átomo. Podes ajudar implementando duas funções, `is-an-atom-p` e `is-a-cons-p`:

```lisp
(is-an-atom-p 'one-thing)    ; => T
(is-an-atom-p '(two things)) ; => NIL
```

```lisp
(is-a-cons-p 'one-thing)    ; => NIL
(is-a-cons-p '(two things)) ; => T
```

Para esta secção, há várias funções incorporadas de Lisp que podes achar úteis. Além disso, por agora, podes simplesmente considerar `T` como verdadeiro e `NIL` como falso.

## 3. Ajuda o Lenny a dividir os seus conses

Por fim, os conses do Lenny são demasiado volumosos para arrumar como deve ser, por isso é preciso dividi-los em partes mais pequenas. Podes ajudar definindo mais duas funções para dividir os conses (`first-thing` e `rest-of-it`)?

```lisp
(first-thing '(first second third)) ; => FIRST
(rest-of-it  '(first second third)) ; => (SECOND THIRD)
```

Mais uma vez, algumas funções incorporadas do Common Lisp podem dar jeito aqui.
