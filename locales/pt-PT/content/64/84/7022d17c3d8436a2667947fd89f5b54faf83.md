# Classes abstratas

Um espetáculo de circo é uma lista de atrações. Malabarismo, trapézio e acrobacia são coisas diferentes, com interiores diferentes, mas quem monta a ordem do espetáculo só precisa de saber duas coisas sobre cada uma: como se chama e quanto tempo demora.

Uma **classe abstrata** descreve exatamente isso, e nada mais.

```sather
abstract class $ACT is
   name : STR;
   minutes : INT;
end; -- abstract class $ACT
```

O seu nome começa por `$`. Lista rotinas sem corpo: apenas assinaturas, cada uma terminada no ponto e vírgula. Não se pode criar nada a partir dela: não há `create` nem `new`.

## Conformidade

Uma classe real promete ser um `$ACT` ao indicá-lo depois de `<`:

```sather
class JUGGLING < $ACT is

   create : SAME is return new; end;

   name : STR is return "Juggling"; end;

   minutes : INT is return 5; end;

end; -- class JUGGLING
```

Lê-se `<` como «é um». A classe tem de fornecer todas as rotinas que a classe abstrata lista, com os mesmos argumentos e o mesmo tipo de valor devolvido. Omitir uma é um erro de compilação, não uma surpresa em tempo de execução.

Uma classe pode acrescentar o que mais quiser. O `TRAPEZE` pode ter uma altura que nenhuma outra atração tem; a classe abstrata nem sabe nem se importa.

## Utilizar o tipo

`$ACT` é um tipo, por isso qualquer coisa pode ser declarada com ele:

```sather
   acts : ARRAY{$ACT} := |#JUGGLING, #TRAPEZE(4), #TUMBLING|;
```

Esse array contém objetos de três classes diferentes ao mesmo tempo, o que um `ARRAY{JUGGLING}` não conseguiria.

## Despacho

```sather
   loop
      total := total + acts.elt!.minutes;
   end;
```

`acts.elt!` é um `$ACT`. Qual `minutes` é executado decide-se quando a linha é executada, consoante o que o objeto é na realidade: `JUGGLING::minutes` para o malabarismo, `TRAPEZE::minutes` para o trapézio. A essa escolha chama-se **despacho**.

A rotina que faz a soma nunca pergunta que tipo de atração tem. Acrescentar um quarto tipo de atração significa escrever uma nova classe e não mudar mais nada, que é precisamente a razão de o fazer assim.
