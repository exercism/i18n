# Introdução

## Aleatoriedade

Em Elixir, para escolher um elemento aleatório de uma estrutura de dados enumerável (por exemplo, uma lista ou um intervalo), usamos `Enum.random`. Esta função escolhe um único elemento, e todos os elementos têm a mesma probabilidade de serem escolhidos.

O Elixir não tem funções próprias para escolher um número de vírgula flutuante aleatório. Para isso, temos de usar o Erlang diretamente.

## Bibliotecas Erlang

O código Elixir corre na máquina virtual BEAM. O BEAM faz parte do sistema de execução do Erlang. Inspirado pelo Erlang e partilhando o seu ambiente de execução, o Elixir oferece uma excelente interoperabilidade com as bibliotecas Erlang. Isto significa que os programadores de Elixir podem usar bibliotecas Erlang a partir do seu código Elixir. De facto, escrever bibliotecas Elixir para funcionalidades que as bibliotecas Erlang já fornecem é desencorajado na comunidade Elixir.

Como resultado, certas funcionalidades, como operações matemáticas ou funções de temporização, só estão disponíveis em Elixir através do Erlang.

A biblioteca padrão do Erlang está disponível para uso no nosso código Elixir, sem passos adicionais.

As funções Erlang podem ser chamadas da mesma forma que chamamos as funções Elixir, com uma pequena diferença. Os nomes dos módulos Erlang são átomos em `snake_case`. Por exemplo, para chamar a função `pi/0` do Erlang a partir do módulo `math`, escreverias:

```elixir
:math.pi()
# => 3.141592653589793
```

As funções Erlang mais usadas que não têm equivalente em Elixir são:

- `:timer.sleep/1`, que suspende um processo durante o número de milissegundos indicado.
- `:rand.uniform/0`, que gera um número de vírgula flutuante aleatório `x`, em que `0.0 <= x < 1.0`.
- `:io_lib.format/2`, que fornece formatação de strings ao estilo C (usando sequências de controlo). Com esta função, podíamos, por exemplo, imprimir um número inteiro em qualquer base entre 2 e 36 ou formatar um número de vírgula flutuante com a precisão desejada. Nota que esta função, como muitas funções Erlang, devolve uma charlist.
- O módulo `math`, que fornece funções matemáticas como `sin/1`, `cos/1`, `log2/1`, `log10/1`, `pow/2`, entre outras.

Para descobrir a biblioteca padrão do Erlang, explora o [Manual de Referência da STDLIB][erl-stdlib-ref].

[erl-stdlib-ref]: https://www.erlang.org/doc/apps/stdlib/index.html
