# Sobre

A Swift é uma linguagem de programação moderna, de código aberto, que funciona em macOS, Linux e Windows.

A Swift foi inicialmente desenvolvida pela Apple para interoperar com os seus principais frameworks, o Cocoa e o CocoaTouch, ambos implementados sobretudo em Objective-C.

A Swift sofre a influência de um grande número de linguagens de programação existentes e incorpora conceitos de uma grande variedade de métodos de programação.
Tudo, desde scripts até à programação orientada a objetos e funcional.

A Apple refere-se à Swift como uma "linguagem de programação orientada a protocolos" e manifestou o objetivo de, com o tempo, tornar a Swift útil para tudo, desde scripts até um sistema operativo.
