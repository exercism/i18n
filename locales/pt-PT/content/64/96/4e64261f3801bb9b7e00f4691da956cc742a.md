# Descrição

O exercício introdutório clássico.
Diz apenas "Hello, World!".

O ["Hello, World!"][hello-world] é o primeiro programa tradicional de quem começa a programar numa nova linguagem ou ambiente.

Os objetivos são simples:

- Modifica o código fornecido para que produza a string "Hello, World!".
- Corre o conjunto de testes e certifica-te de que passa.
- Submete a tua solução e verifica-a no site.

Se tudo correr bem, estás pronto para ir buscar o teu primeiro exercício a sério.

[hello-world]: https://en.wikipedia.org/wiki/%22Hello,_world!%22_program
