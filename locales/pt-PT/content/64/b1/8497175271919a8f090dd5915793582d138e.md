# Introdução

## Tempo

O conceito de _tempo_ é tratado em .NET usando a estrutura `DateTime`. Existem rotinas para converter entre a hora local e UTC. As operações aritméticas podem ser efetuadas com a ajuda de `TimeSpan`.

## Fuso horário

A classe `TimeZoneInfo` fornece rotinas para lidar com as diferenças entre fusos horários. A classe `TimeZoneInfo` contém também métodos que ajudam a lidar com a hora de verão.

A classe `CultureInfo` suporta formatos de data e hora dependentes da localidade.

Para suportar programação multiplataforma, a classe `RuntimeInformation` permite-te detetar em que sistema operativo o teu código está a ser executado: Linux, Windows ou OSX.
