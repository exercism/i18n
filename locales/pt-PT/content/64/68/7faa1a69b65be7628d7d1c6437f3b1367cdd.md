# Anexo às instruções

## Implementação

Define uma única func Go, `Cost`, que calcula o custo de uma determinada lista de livros com base nos descontos definidos.

Usa a seguinte assinatura para a func `Cost`:

```go
func Cost(books []int) int
```

A `Cost` devolve o custo total (depois dos descontos) em cêntimos.
Por exemplo, para um único livro, o custo é de 800 cêntimos, o que equivale a $8.00.
Para este exercício, só são necessários cálculos com números inteiros.
