# Sobre o básico

O conceito Básico apresentou o [Go](https://golang.org) como uma linguagem de programação compilada e com tipos estáticos.
A linguagem é muitas vezes chamada Golang devido ao seu antigo nome de domínio, golang.org, mas o nome correto é Go.

O conceito Básico apresenta três características importantes da linguagem: pacotes, funções e variáveis.

## Pacotes

As aplicações Go estão organizadas em pacotes.
Um pacote é um conjunto de ficheiros de código-fonte que estão no mesmo diretório.
Todos os ficheiros de código-fonte de um diretório têm de partilhar o mesmo nome de pacote.
É convencional que o nome do pacote seja o último diretório do caminho de importação.
Por exemplo, os ficheiros do [pacote "math/rand"](https://golang.org/src/math/rand/) começam com a instrução `package rand`.
Quando um pacote é importado, só as entidades (funções, tipos, variáveis, constantes) cujos nomes começam por letra maiúscula podem ser usadas ou acessadas.
O estilo de nomenclatura recomendado em Go é que os identificadores sejam escritos em `camelCase`, exceto os que se destinam a ser acessíveis entre pacotes, que devem ser em `PascalCase`.

```go
package lasagna
```

## Variáveis

Go tem tipos estáticos, o que significa que todas as variáveis [têm de ter um tipo definido](https://en.wikipedia.org/wiki/Type_system) em tempo de compilação.

As variáveis podem ser definidas indicando explicitamente um tipo:

```go
var explicit int // Explicitly typed
```

Também podes usar um inicializador, e o compilador atribui à variável o tipo do inicializador.

```go
implicit := 10   // Implicitly typed as an int
```

Depois de declarada, uma variável pode receber valores com o operador `=`.
Depois de declarada, o tipo de uma variável nunca pode mudar.

```go
count := 1 // Assign initial value
count = 2  // Update to new value

count = false // This throws a compiler error due to assigning a non `int` type
```

## Constantes

As constantes guardam um dado, tal como as variáveis, mas o seu valor não pode mudar durante a execução do programa.

As constantes são definidas com a palavra-chave `const` e podem ser números, carateres, strings ou Boolean:

```go
const Age = 21 // Defines a numeric constant 'Age' with the value of 21
```

## Funções

As funções em Go aceitam zero ou mais parâmetros.
Os parâmetros têm de ser tipados explicitamente, não há inferência de tipos.

Os valores são devolvidos pelas funções com a palavra-chave `return`.

Uma função é invocada indicando o nome da função e passando argumentos para cada um dos seus parâmetros.

Repara que o Go suporta dois tipos de comentários.
Os comentários de uma linha são precedidos por `//` e os comentários de várias linhas são inseridos entre `/*` e `*/`.

```go
package greeting

// Hello is a public function.
func Hello (name string) string {
    return hi(name)
}

// hi is a private function.
func hi (name string) string {
    return "hi " + name
}
```
