# Conceitos necessários para o exercício Macros

Há muitas formas de resolver um exercício, mas vou usar o [exemplo canónico](https://github.com/exercism/rust/blob/666c366fc0d39d9f6fd8e837facea8afe2153ae2/exercises/macros/example.rs) como a minha referência principal para os conceitos utilizados.

Quando nos referimos à lista de conceitos, queremos dizer [esta lista](https://github.com/exercism/v3/blob/master/languages/rust/reference/README.md)

Repara que, tanto nos exercícios de conceito como nos de prática, a lista de conceitos pré-requisitos deve ser o mais pequena possível. O objetivo aqui não é enumerar todos os conceitos que podem ser usados em todas as abordagens possíveis ao problema; é enumerar o conjunto mínimo de conhecimentos com que um estudante determinado poderia, em princípio, resolver o problema.

Repara que é muito provável que este exercício venha a ser um exercício de conceito para o conceito "Escrever macros declarativas".

## Conceitos necessários

### Existentes

- structs
- (im)mutabilidade
- `Hashmap<K, V>`

### A adicionar

- atribuição de variáveis (parte dos `fundamentals`)
- âmbito de variáveis / espaços de nomes (parte dos `fundamentals`)
- métodos e funções associadas (depende de `structs`)
