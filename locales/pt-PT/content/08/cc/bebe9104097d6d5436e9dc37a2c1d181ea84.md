# Dicas

## Geral

- Os ciclos `while` são usados para iteração _indefinida_ (não contada)
- Os ciclos `for` são usados para iteração _definida_ (contada).
- As palavras-chave `break` e `continue` ajudam a personalizar o comportamento dos ciclos.
- Podes usar `std::to_string()` da biblioteca `string` para converter um número inteiro numa string.

Familiarizares-te também com o seguinte pode ajudar-te a completar as tarefas:

- [`vectors`][vectors]: indexação, tamanho, [`<vector>.emplace_back`][emplace], [`<vector>.pop_back()`][pop].
- [`string`][string]: usar o `+` para concatenar strings, conversão de números inteiros em strings, [`to_string`][to\_string].

## 1. Arredondar as pontuações

- Os ciclos `While` continuam a executar-se até a condição de teste ser avaliada como `False`.
- `<vector>.back()` devolve o último elemento de um `vector`.
- `<vector>.pop_back()` remove o último elemento de um `vector`.

## 2. Alunos que não passam

- Precisas mesmo de criar um contador de resultados e de o _incrementar_. Vais querer fazer `return` da contagem dos alunos que não passam quando o ciclo terminar.

## 3. Calcular as notas com letras

- A pontuação necessária para não reprovar é sempre 41, porque um "F" é **<= 40**. O intervalo de pontuações restante, de 41 até à pontuação mais alta, deve ser dividido em quatro intervalos iguais, um por cada nota com letra.
- Subtrai 40 à pontuação mais alta para obteres o intervalo total de pontuações que dão direito a notas com letra (de A a D).
- Divide esse intervalo total por 4 para obteres o tamanho de cada intervalo de notas.
- Soma esse tamanho de intervalo a 40 repetidamente para calculares os limites inferiores de cada nota com letra.
- `static_cast<int>` sem parâmetros deve arredondar bem os incrementos.
- Espera-se que devolvas um array, não um vector.

## 4. Fazer corresponder nomes a pontuações

- Se os dois contentores tiverem o mesmo comprimento e estiverem ordenados da mesma forma, podes usar o `index` de um para obteres um `value` do outro?
- Podes usar `std::to_string(int)` para converter um número numa string.
- Não te esqueças de seguir o formato do resultado do exemplo.

## 5. Uma pontuação "perfeita"

- Pode haver ou não um aluno com uma pontuação de 100, e não podes devolver uma string vazia sem verificares **todas** as pontuações.
- As instruções de `control flow`, `continue` e `break`, podem ser úteis aqui para ultrapassares valores indesejados.
