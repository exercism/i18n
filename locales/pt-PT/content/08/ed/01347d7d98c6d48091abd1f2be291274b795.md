# Instalação


## Instala o GHCup

A forma recomendada de instalar as ferramentas de Haskell é através do [GHCup][ghcup].

Com o GHCup podes gerir os compiladores instalados, os gestores de projetos/pacotes e o servidor de linguagem.


## Instala o Stack

Para fazer os exercícios do Exercism só precisas do Stack.

Para instalar o Stack, corre o comando ou o script de instalação do GHCup.
Segue as opções predefinidas, mas indica que também queres instalar o Stack.

Saltaste a instalação do Stack sem querer?
Não há problema: basta correr `ghcup install stack` depois.

O GHCup vai instalar

- **Um compilador** (GHC: the Glasgow Haskell Compiler)

  Em rigor, não precisas disto para o Exercism, mas dá jeito quando queres brincar com o [GHCi][ghc-guide-ghci] fora dos diretórios dos exercícios.

- **Cabal**

  Um gestor de projetos/pacotes.
  Não precisas disto para o Exercism.

- **Stack**

  O gestor de projetos/pacotes que vais usar para o Exercism.
  Vai garantir que tens o compilador e as bibliotecas certos para cada projeto (exercício).

Para verificar se a instalação foi bem-sucedida, corre um destes comandos

- `ghcup list`: se correr bem, vês uma longa lista de versões de ferramentas, com o Stack marcado como instalado
- `stack --version`: se correr bem, vês algo como `Version 2.7.5, Git revision ...`


## Obtém a versão certa do GHC

O Stack descarrega e instala o GHC automaticamente quando for preciso.
Podes iniciar a instalação e verificá-la correndo os seguintes comandos num terminal:

```bash
# Note: it only makes sense to run Stack
# inside projects, so navigate into an
# exercise directory first!
exercism download --exercise=hello-world --track=haskell
cd ~/Exercism/haskell/hello-world
stack ghc -- --version
```

Se isto mostrar algo como

```
The Glorious Glasgow Haskell Compilation System, version 8.8.4
```

então o GHC está instalado corretamente.


## Configura o teu editor para trabalhar com Haskell

O suporte para Haskell é fornecido pelo Haskell Language Server (HLS).
O suporte da linguagem não é obrigatório, mas é vivamente recomendado.


### Visual Studio Code (recomendado)

Basta instalar a [extensão Haskell para o Visual Studio Code][vscode-haskell].
Vai usar o GHCup para instalar o HLS automaticamente e, a partir daí, está tudo pronto.

**Nota:** com exercícios acabados de descarregar, o HLS pode ter dificuldade em arrancar.
Se isso acontecer, corre `stack test` e reinicia o servidor de linguagem.


### Outros editores

Consulta a [documentação do HLS sobre a configuração do editor][hls-editor-config].
Pode ser preciso instalar o HLS manualmente.
Para isso, corre `ghcup install hls`.
