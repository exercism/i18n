# Instruções

Neste exercício, vais simular um sistema informático baseado em janelas.
Vais criar janelas que podem ser movidas e redimensionadas e que mostram o seu conteúdo.

## 1. Define uma estrutura Size

Define uma estrutura chamada `Size` com duas propriedades do tipo `Int`, `width` e `height`, que guardam, respetivamente, a largura e a altura atuais da janela.
A largura e a altura iniciais devem ser 80 e 60, respetivamente.
Inclui um método `resize(newWidth:newHeight:)` que recebe novos parâmetros de largura e altura e altera as propriedades de acordo com o novo tamanho.

```swift
let size1080x764 = Size(width: 1080, height: 764)
// Returns Size
var size1200x800 = size1080x764
// Returns Size
size1200x800.resize(newWidth: 1200, newHeight: 800)
size1200x800.height
// Returns 800
```

## 2. Define uma estrutura Position

Define uma estrutura chamada `Position` com duas propriedades do tipo `Int`, `x` e `y`, que guardam, respetivamente, a posição horizontal e vertical atual do canto superior esquerdo da janela.
Os valores iniciais de x e y devem ser ambos 0. A posição (0, 0) é o canto superior esquerdo do ecrã, com os valores de `x` a aumentar à medida que te deslocas para a direita e os valores de `y` a aumentar à medida que te deslocas para baixo.

Inclui um método `moveTo(newX:newY:)` que recebe novos parâmetros x e y e altera as propriedades de acordo com a nova posição.

```swift
var point = Position(x: 10, y: 20)
// Returns Position
point.moveTo(newX: 100, newY: -100)
point.y
// Returns -100
```

## 3. Define uma classe Window

Define uma classe de janela com as seguintes propriedades:

- `title` : `String`, valor inicial é "New Window"
- `screenSize` : `Size`, valor constante com `width` = 800 e `height` = 600
- `size` : `Size`, valor inicial é o valor predefinido da estrutura `Size`
- `position` : `Position`, valor inicial é o valor predefinido da estrutura `Position`
- `contents` : `String?`, valor inicial é `nil`

Deves também definir um inicializador vazio para a classe.

```swift
let window = Window()
window.title
// Returns "New Window"
```

## 4. Adiciona um método para redimensionar janelas

- `resize(to:)` : `(Size) -> ()` - Este método recebe uma estrutura `Size` como parâmetro de entrada e tenta redimensionar a janela para o tamanho especificado. No entanto, o novo tamanho não pode exceder certos limites. 
- A altura ou a largura mínima permitida é 1.
  Alturas ou larguras pedidas inferiores a 1 serão limitadas a 1.
- A altura e a largura máximas dependem da posição atual da janela; os bordos da janela não podem ultrapassar os bordos do ecrã. 
  Valores superiores a estes limites serão limitados ao maior tamanho possível.
  Por exemplo, se a posição da janela for `x` = 400, `y` = 300 e for pedido um redimensionamento para `height` = 400, `width` = 300, a janela será redimensionada para `height` = 300, `width` = 300, porque o ecrã não é suficientemente grande na direção `y` para acomodar totalmente o pedido.

## 5. Adiciona um método para mover janelas

- `move(to:)` : `(Position) -> ()` - É semelhante a `resize(to:)`, mas este método ajusta a _posição_ da janela ao valor pedido, em vez do tamanho. Tal como em `resize`, a nova posição não pode exceder certos limites.
- A posição mais pequena é 0, tanto para `x` como para `y`.
- A posição máxima em qualquer das direções depende do tamanho atual da janela; os bordos não podem ultrapassar os bordos do ecrã.
       Valores superiores a estes limites serão limitados ao maior tamanho possível. Por exemplo, se o tamanho da janela for `x` = 250, `y` = 100 e for pedido um movimento para `x` = 600, `y` = 200, a janela será movida para `x` = 550, `y` = 200, porque o ecrã não é suficientemente grande na direção `x` para acomodar totalmente o pedido.

## 6. Adiciona métodos para atualizar o texto da janela e mostrar informações da janela

- `update(title:)` : `(String) -> ()` - Este método define a propriedade `title` com o valor da string que foi passada.
- `update(text:)` : `(String?) -> ()` - Este método define a propriedade `contents` com o valor da string opcional que foi passada.
- `display()` : `() -> String` - Este método devolve uma string que descreve o estado atual da janela. Por exemplo, se a janela tiver o `title` "My First Window", com a posição: x = 10, y = 100; o tamanho: width = 200, height = 150; e contents: "I 😍 my window", deve devolver a string: `"My First Window\nPosition: (10, 100), Size: (200 x 150)\nI 😍 my window\n"` - Se `contents` for `nil`, a última linha deve ser "[This window intentionally left blank]"

## 7. Cria um inicializador para a classe Window

O sistema de janelas deve ter um inicializador para que a janela possa ser criada com valores de entrada personalizados.
Cria **outro** inicializador para a classe `Window`.
O inicializador deve receber os seguintes parâmetros: `title`, `contents` e dois parâmetros opcionais, `size` e `position`.
Os parâmetros `size` e `position` devem ter como valores predefinidos os valores predefinidos das estruturas `Size` e `Position`.

```swift
let window = Window(title: "My First Window", contents: "I 😍 my window")
window.display()
// Returns "My First Window\nPosition: (0, 0), Size: (80 x 60)\nI 😍 my window\n"

let window2 = Window(title: "My Second Window", contents: "I 😍 my window", size: Size(width: 200, height: 150), position: Position(x: 10, y: 100))
window2.display()
// Returns "My Second Window\nPosition: (10, 100), Size: (200 x 150)\nI 😍 my window\n"
```
