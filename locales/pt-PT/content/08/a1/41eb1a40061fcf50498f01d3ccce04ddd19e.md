# Introdução

O fluxo de controlo em Cairo permite-te controlar o caminho de execução dos teus programas com base em condições e repetição.

## Execução condicional

Usa expressões `if` para executar código com base em condições:

```rust
let number = 42;
if number > 0 {
    println!("Positive number");
} else if number < 0 {
    println!("Negative number");  
} else {
    println!("Zero");
}
```

`if` é uma expressão, por isso pode devolver valores:

```rust
let result = if condition { 5 } else { 10 };
```

## Ciclos

Usa `loop` para repetir código.
Um ciclo corre indefinidamente a menos que o pares; usa `break` para sair do ciclo quando uma condição se verifica.

```rust
let mut counter = 0;
loop {
    if counter == 5 {
        break;
    }
    println!("Counter: {}", counter);
    counter += 1;
}
```

Os ciclos podem devolver valores com `break`:

```rust
let result = loop {
    counter += 1;
    if counter == 10 {
        break counter * 2; // Returns 20
    }
};
```

Usa `continue` para saltar para a iteração seguinte:

```rust
let mut i = 0;
loop {
    i += 1;
    if i % 2 == 0 {
        continue; // Skip even numbers
    }
    if i > 10 {
        break;
    }
    println!("{}", i); // Only prints odd numbers
}
```
