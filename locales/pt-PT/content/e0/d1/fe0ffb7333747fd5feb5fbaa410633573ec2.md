## 1. Verifica a criticidade

- Os operadores de comparação ([comparisons][comparisons review]) e as operações Boolean ([concept:python/bools]()) podem ser combinados e usados com condicionais.
- As expressões condicionais têm de resultar em `True` ou `False`.
- Podes usar `else` para um bloco de código que é executado quando todos os testes condicionais devolvem `False`.

  ```python
     >>> item = 'blue'
     >>> item_2 = 'green'
     
     >>>  if len(item) >= 3 and len(item_2) < 5:
            print('Both pass the test!')
          elif len(item) >= 3 or len(item_2) < 5:
            print('One passes the test!')
          else:
            print('None pass the test!')
    ...
    One passes the test!
  ```

## 2. Determina o intervalo de potência de saída

- Os operadores de comparação podem ser combinados e usados com condicionais.
- Podes usar qualquer número de instruções `elif` como "ramos" de decisão.
- Cada "ramo" pode ter um `return` separado, embora as ferramentas de linting possam considerar isso "má prática".
- Se o linter se queixar, considera atribuir o resultado de um ramo a uma variável comum e depois devolveres essa variável com `return`.
