# Sobre

A principal construção orientada a objetos em Java é a _classe_, que combina dados ([_campos_][fields]), também conhecidos como variáveis de instância, e comportamento ([_métodos_][methods]).
Os campos e métodos de uma classe são conhecidos como os seus _membros_.

O acesso aos membros pode ser controlado através de modificadores de acesso, sendo os dois mais comuns:

- [`public`][public]: o membro pode ser acedido por qualquer código (sem restrições).
- [`private`][private]: o membro só pode ser acedido por código da mesma classe.

Em Java, se não for especificado nenhum modificador de acesso, o padrão é a _visibilidade de pacote_.
Neste caso, o membro é visível a todas as classes definidas no mesmo pacote.

O agrupamento acima referido de dados e comportamento relacionados, bem como a restrição do acesso aos membros, é conhecido como [_encapsulamento_][encapsulation], que é um dos conceitos centrais da programação orientada a objetos.

Podes pensar numa classe como um modelo para criar instâncias dessa classe.
Para [criar uma instância de uma classe][creating-objects] (também conhecida como _objeto_), usa-se a [palavra-chave `new`][new]:

```java
class Car {
}

// Create two car instances
Car myCar = new Car();
Car yourCar = new Car();
```

Os [campos][fields] têm um tipo e um nome (escritos em [camelCase][camel-case]) e podem ser definidos em qualquer parte de uma classe (escritos em [PascalCase][pascal-case]).

```java
class Car {
    // Accessible by anyone
    public int weight;

    // Only accessible by code in this class
    private String color;
}
```

Podes atribuir opcionalmente um valor inicial a um campo.
Se um campo _não_ especificar um valor inicial, será definido com o [valor predefinido][default-values] do seu tipo.
Os valores dos campos de uma instância podem ser acedidos e atualizados com a notação de ponto.

```java
class Car {
    // Will be set to specified value
    public int weight = 2500;

    // Will be set to default value (0)
    public int year;
}

Car newCar = new Car();
newCar.weight; // => 2500
newCar.year;   // => 0

// Update value of the field
newCar.year = 2018;
```

Os campos privados são normalmente atualizados como efeito secundário de chamar um método.
Normalmente, esses métodos não devolvem qualquer valor; nesse caso, o tipo de retorno deve ser [`void`][void]:

```java
class CarImporter {
    private int carsImported;

    public void importCars(int numberOfCars)
    {
        // Update private field
        carsImported = carsImported + numberOfCars;
    }
}
```

Repara que não é habitual usar campos públicos em classes Java.
Normalmente, usam-se campos privados, que são acedidos através de [_getters_ e _setters_][so-getters-setters].

Dentro de uma classe, a [palavra-chave `this`][this] refere-se à classe atual.
Isto é especialmente útil se um parâmetro tiver o mesmo nome que um campo:

```java
class CarImporter {
    private int carsImported;

    public void setImportedCars(int carsImported)
    {
        // Update private field from public method
        this.carsImported = carsImported;
    }
}
```
