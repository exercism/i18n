# Introdução

O tipo `Bool` é um dos blocos de construção da linguagem. Serve para descrever se algo é verdadeiro ou falso, com os respetivos valores `True` e `False`.

Os Boolean podem combinar-se com os operadores `&&` ("E") e `||` ("OU"), e ser negados com a função `not`.

Os Boolean são também extremamente úteis para criar ramificações no teu código que só são executadas se certas condições se verificarem. Em Elm, isso faz-se com uma expressão `if-then-else`, usada da seguinte forma.

```elm
if someCondition || (someOtherCondition && anotherCondition) then
    doSomething
else
    doSomethingElse
```
