# Introdução

Em Java, o literal `null` serve para indicar a ausência de um valor.

Em Java, todos os tipos de dados primitivos têm um valor predefinido e, por isso, nunca podem ser `null`.
Por convenção, começam com uma letra minúscula, por exemplo `int`.

Os tipos de referência contêm o endereço de memória de um objeto e podem ter o valor `null`.
Normalmente começam com uma letra maiúscula, por exemplo `String`.

Se tentares atribuir o valor `null` a uma variável primitiva, vais obter um erro de compilação, porque a variável contém sempre um valor primitivo do tipo que lhe foi atribuído.

```java
//Throws compile time error stating the required type is int, but null was provided
int number = null;
```

Atribuir o valor `null` a uma variável de referência não provoca um erro de compilação, porque as variáveis de referência podem ter o valor `null`.

```java
//No error will occur as the String variable str is nullable
String str = null;
```
