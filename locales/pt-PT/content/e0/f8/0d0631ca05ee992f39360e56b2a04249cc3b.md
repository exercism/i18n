# Exemplo

```riscvasm
.equ FRAME_SIZE, 16

.text
.global is_triple
```

As linhas que começam com um ponto são _diretivas_: instruções para o assembler, e não para o processador.
O `.equ` dá o nome `FRAME_SIZE` ao número 16.
O `.text` diz que o que se segue é código.
O `.global` torna o rótulo `is_triple` visível fora deste ficheiro, para que outro código o possa chamar.
Também podes ver `.globl`, que significa o mesmo.

```riscvasm
/* bool is_triple(unsigned a, unsigned b, unsigned c); */
is_triple:
```

O `is_triple` verifica se `a² + b² = c²`, devolvendo 1 no caso afirmativo e 0 caso contrário.
Por exemplo, `(6, 8, 10)` dá 1, porque `36 + 64 = 100`.
O rótulo `is_triple` marca onde a função começa.
É chamada com `a`, `b` e `c` nos registos `a0`, `a1` e `a2`.

```riscvasm
        addi    sp, sp, -FRAME_SIZE
        sw      ra, 12(sp)      /* save the return address */
        sw      a1, 8(sp)       /* save b */
        sw      a2, 4(sp)       /* save c */
```

O registo `ra` guarda o _endereço de retorno_: o ponto no código que nos chamou para onde voltamos quando acabarmos.
Cada `call` reescreve o `ra`, por isso guardamo-lo primeiro na _pilha_.
A pilha cresce para baixo, na direção de endereços menores, por isso subtrair 16 ao ponteiro da pilha `sp` reserva-nos 16 bytes.
(O `sp` tem de ser sempre um múltiplo de 16.)
Também guardamos `b` e `c`, porque uma função que chamamos pode alterar os registos `a`.

```riscvasm
        call    square          /* a0 = a * a */
        sw      a0, 0(sp)       /* save a * a */
```

O `a` já está em `a0`, que é onde o `square` espera o seu parâmetro de entrada.
O `call` define o `ra` como a instrução seguinte e salta para o `square`, que devolve o seu resultado em `a0`.

```riscvasm
        lw      a0, 8(sp)       /* a0 = b */
        call    square          /* a0 = b * b */
        lw      t0, 0(sp)       /* t0 = a * a */
        add     t0, t0, a0      /* t0 = a * a + b * b */
        sw      t0, 0(sp)       /* save a * a + b * b */
```

Voltamos a carregar `b` da pilha, elevamo-lo ao quadrado e somamo-lo a `a * a`.

```riscvasm
        lw      a0, 4(sp)       /* a0 = c */
        call    square          /* a0 = c * c */
        lw      t0, 0(sp)       /* t0 = a * a + b * b */
        sub     a0, t0, a0      /* a0 = a * a + b * b - c * c */
        seqz    a0, a0          /* a0 = 1 if that is zero, otherwise 0 */
```

A diferença é zero exatamente quando `a² + b² = c²`.
O `seqz` (definir se for igual a zero) transforma isso em 1 ou 0.

```riscvasm
        lw      ra, 12(sp)      /* restore the return address */
        addi    sp, sp, FRAME_SIZE
        ret
```

Restauramos o `ra` e devolvemos os 16 bytes da pilha.
O `ret` salta então para o endereço em `ra`, de volta para quem nos chamou.

```riscvasm
/* unsigned square(unsigned n); */
square:
        mul     a0, a0, a0      /* n * n */
        ret
```

O `square` não chama nenhuma outra função, por isso o `ra` fica intacto e não há nada para guardar.
Não está marcada com `.global`, porque só o `is_triple` a usa.
