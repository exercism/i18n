# Instruções

Neste exercício vais verificar as permissões de contas de utilizador num fórum da internet. O fórum suporta três permissões diferentes:

- Read
- Write
- Delete

Existem três tipos de contas, cada um com permissões predefinidas diferentes:

- Convidados: podem ler publicações.
- Utilizadores: podem ler e escrever publicações.
- Moderadores: podem ler, escrever e apagar publicações, têm todas as permissões.

Por vezes, é possível modificar permissões individuais. Por exemplo, podes dar a uma conta de convidado a permissão para também escrever publicações, ou revogar todas as permissões de uma conta, ficando esta sem nenhuma permissão.

## 1. Obter as permissões predefinidas de um tipo de conta

Primeiro, define um enum `AccountType` para representar os três tipos de conta: `Guest`, `User` e `Moderator`.

A seguir, define um enum `Permission` para representar os três tipos de permissão: `Read`, `Write`, `Delete`, e mais dois: `All`, para ter todas as permissões, e `None`, para não ter nenhuma das permissões.

Depois, implementa o método (_static_) `Permissions.Default()` para devolver as permissões predefinidas de um tipo de conta específico:

```csharp
Permissions.Default(AccountType.Guest)
// => Permission.Read
```

## 2. Conceder uma permissão

Implementa o método (_static_) `Permissions.Grant()` que concede (adiciona) uma permissão:

```csharp
Permissions.Grant(current: Permission.None, grant: Permission.Read)
// => Permission.Read
```

## 3. Revogar uma permissão

Implementa o método (_static_) `Permissions.Revoke()` que revoga (remove) uma permissão:

```csharp
Permissions.Revoke(current: Permission.Read, revoke: Permission.Read)
// => Permission.None
```

## 4. Verificar uma permissão

Implementa o método (_static_) `Permissions.Check()` que recebe as permissões atuais da conta e verifica se a conta está autorizada para uma determinada permissão:

```csharp
Permissions.Check(current: Permission.Write, check: Permission.Read)
// => false
```
