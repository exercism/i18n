# Dicas

## Geral

- Os primeiros seis argumentos inteiros são passados a uma função em `rdi`, `rsi`, `rdx`, `rcx`, `r8` e `r9`.
- Os endereços na memória são valores de 64 bits (8 bytes).

## 1. Cria uma entrada para cada item

- Os primeiros seis argumentos inteiros são passados a uma função em `rdi`, `rsi`, `rdx`, `rcx`, `r8` e `r9`.
- Os endereços na memória são valores de 64 bits (8 bytes).
- Todos os argumentos inteiros a seguir ao sexto são passados na pilha, o primeiro deles em `rsp + 8`.
- O número de argumentos extra é igual ao número de categorias, que é passado em `r9`.
- Podes fazer um ciclo para adicionar os argumentos extra um a um, ou podes usar [movsq][movs] combinado com [rep][rep].

## 2. Reserva espaço para uma lista mensal de itens

- Os primeiros seis argumentos inteiros são passados a uma função em `rdi`, `rsi`, `rdx`, `rcx`, `r8` e `r9`.
- Os endereços na memória são valores de 64 bits (8 bytes).
- Precisas de saber o tamanho do array para limpar os seus bytes depois de chamares a função que aloca memória.
- Quando chamas uma função externa, esta pode alterar o valor em qualquer _registo preservado pelo chamador_.
- Podes preservar o valor de um registo na pilha usando [push][push] ou manipulando `rsp` diretamente.
- Qualquer modificação a `rsp`, incluindo com `push`, tem de ser revertida antes de a função terminar, quer com [pop][pop], quer alterando `rsp` diretamente.

## 3. Insere um item na lista mensal

- Os primeiros seis argumentos inteiros são passados a uma função em `rdi`, `rsi`, `rdx`, `rcx`, `r8` e `r9`.
- Os endereços na memória são valores de 64 bits (8 bytes).
- Um valor que não cabe num registo é passado a uma função na pilha.
- Cada entrada de um item ocupa 120 bytes de espaço, o que é muito maior do que o tamanho máximo de um registo (8 bytes).
- Os argumentos passados na pilha encontram-se em endereços a começar em `rsp + 8`.
- Podes fazer um ciclo para adicionar os valores ao endereço de memória de destino, ou podes usar [movsb][movs] combinado com [rep][rep].

## 4. Imprime um item

- Os primeiros seis argumentos inteiros são passados a uma função em `rdi`, `rsi`, `rdx`, `rcx`, `r8` e `r9`.
- Os endereços na memória são valores de 64 bits (8 bytes).
- A string introdutória é opcional: podes chamar a função de impressão com `0` em vez dela.
- Se a string introdutória for passada à função de impressão, tem de ter no máximo 50 carateres ASCII, já incluindo o terminador NUL (valor `0`).
- Sempre que chamas uma função, tens de reservar espaço na pilha para qualquer argumento a seguir ao sexto.
- A ABI System V determina que a pilha deve estar alinhada a 16 bytes antes de chamares uma função, o que é especialmente importante para funções externas.
- Cada entrada de um item na lista ocupa 120 bytes de espaço.
