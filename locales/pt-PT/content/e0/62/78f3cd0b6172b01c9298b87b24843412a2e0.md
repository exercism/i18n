# não uses divisão nem módulo

Como as instruções referem, o objetivo deste exercício é construir um Crivo de Eratóstenes sem usar operações como a divisão ou o módulo.
Consulta a [ligação para a Wikipédia](https://en.wikipedia.org/wiki/Sieve_of_Eratosthenes) para veres uma descrição do algoritmo.

Construir um Crivo de Eratóstenes numa linguagem imutável como o Elm pode parecer um pouco antinatural, mas é um algoritmo bonito, inventado há mais de dois milénios, que vale a pena aprender e implementar corretamente.
