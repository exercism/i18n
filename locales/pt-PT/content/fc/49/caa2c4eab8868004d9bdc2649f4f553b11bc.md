# Dicas

## Geral

- Cada ficheiro começa com uma linha `USING:` que lista os vocabulários que toma de empréstimo, e uma linha `IN:` que declara o seu próprio vocabulário. O nome que vem depois de `IN:` tem de corresponder ao caminho do ficheiro dentro da raiz do exercício: `bosuns-briefing.helpers` para `helpers/helpers.factor` e `bosuns-briefing` para o ficheiro principal.
- Sempre que chamas uma palavra de outro vocabulário, acrescenta esse vocabulário à linha `USING:`.

## 1. `greeting`

- `greeting` não recebe nada e devolve uma única string literal. O corpo é apenas essa string literal.

## 2. `crew-line`

- `prepend` (em `sequences`) recebe `( seq1 seq2 -- newseq )` e devolve `seq2` seguido de `seq1`. Por isso, `"Lopez" "  - " prepend` produz `"  - Lopez"`.

## 3. `closing`

- Tem a mesma forma que `greeting`.

## 4. `roster`

- `[ crew-line ] map` (de `sequences`) aplica `crew-line` a cada elemento do array de entrada e devolve um array de strings formatadas.
- `"\n" join` (de `splitting`) concatena um array de strings, inserindo `"\n"` entre cada par.

## 5. `briefing`

- O resultado são três strings unidas por `"\n"`: o greeting, o roster dos nomes de entrada e o closing.
- `3array` (de `arrays`) agrupa os três valores num único array, pronto para `"\n" join`.
- Usa `[ greeting ] dip` para colocar o greeting *por baixo* dos nomes que já estão na pilha; depois corre `roster` sobre os nomes e, a seguir, `closing`, deixando três strings prontas para `3array`.
