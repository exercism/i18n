# Char

`Char` é um tipo de dados em Crystal que representa um ponto de código [Unicode][unicode] de 32 bits.
O seu tamanho torna-os eficientes em termos de memória e dá-lhes propriedades específicas que as Strings não têm.
Criam-se com aspas simples (`'`) e só permitem que se coloque lá dentro um único ponto de código Unicode.

```crystal
'a' # => 'a'
'a'.class # => Char
```

É bastante comum trabalhar com Chars quando se trabalha com Strings em Crystal, já que vários métodos da classe String devolvem Chars ou recebem Chars como argumentos.
Por exemplo, o método [`String#[]`][index] devolve um Char, e o método [`String#chars`][chars] devolve uma coleção de Chars.

## Incrementar / Decrementar

Como um Char é um ponto Unicode de 32 bits, suporta incremento e decremento. Isso faz com que, se tiveres `'a'`, possas obter `'b'` somando um.

```crystal
'a' + 5
# => 'f'

'z' - 25
# => 'a'
```

Existe também um método chamado [`Char#succ`][succ], que devolve o caráter seguinte na tabela Unicode, e [`Char#pred`][pred], que devolve o caráter anterior na tabela Unicode.

```crystal
'a'.succ
# => 'b'

'z'.pred
# => 'y'
```

## Concatenação

Como um Char serve apenas para representar um ponto Unicode de 32 bits, dois Chars não podem ser concatenados.
Por isso, um Char só pode ser concatenado com Strings.

```Crystal
'a' + "bc"
# => "abc"

'a' + 'b'
# => error: expected argument #1 to 'Char#+' to be Int or String, not Char
```

## Métodos de propriedades

O Crystal tem alguns métodos para obter informação sobre um caráter, como por exemplo se é um número ou uma letra, ou se é maiúsculo ou minúsculo.
Eis uma lista de alguns desses métodos; para uma lista completa, consulta a [API de Char][char-api]:

| Método                           | Descrição                                            |
| -------------------------------- | ---------------------------------------------------- |
| [`Char#number?`][number]         | Devolve `true` se o Char for um número               |
| [`Char#letter?`][letter]         | Devolve `true` se o Char for uma letra               |
| [`Char#lowercase?`][lowercase]   | Devolve `true` se o Char for minúsculo               |
| [`Char#uppercase?`][uppercase]   | Devolve `true` se o Char for maiúsculo               |
| [`Char#ascii?`][ascii]           | Devolve `true` se o Char for um caráter ASCII        |
| [`Char#whitespace?`][whitespace] | Devolve `true` se o Char for um caráter de espaço em branco |

## Conversão

### Conversão entre pontos de código e Chars

Como um Char é um ponto Unicode de 32 bits, podes converter entre Chars e pontos de código (Int).
Isto pode ser feito com o método [`Char#ord`][ord], que devolve o ponto de código do Char, ou com o método [`Int#chr`][chr], que devolve o Char do ponto de código.

```crystal
'a'.ord
# => 97

97.chr
# => 'a'
```

### Conversão entre tipos

Tal como acontece com outros tipos de dados, os Chars têm alguns métodos para converter entre tipos.
O mais comum é o método `Char#to_s`, que converte o Char numa String. No entanto, existe também o método `Char#to_i`, que converte o Char num Int, e o método `Char#to_f`, que converte o Char num Float.

```crystal
'a'.to_s
# => "a"

'4'.to_i
# => 4

'a'.to_i
# => Error: Invalid integer: a (ArgumentError)
```
