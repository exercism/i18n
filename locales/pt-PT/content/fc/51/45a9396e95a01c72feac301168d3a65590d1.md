# Dicas

## Geral

- Para extrair vários argumentos nos parâmetros da função, podes empacotá-los com `...<args>`.
- Para usar rest e spread, usa o operador `...`.

## 1. Criar uma lista com todos os vagões

- Vários argumentos nos parâmetros da função podem ser empacotados com a [sintaxe `...<args>` (spread)][spread-syntax].

## 2. Mover os dois primeiros elementos para o fim do array

- Podes desempacotar uma série de parâmetros com [uma atribuição por desestruturação (`...`)][destructuring-assignment].
  Isto permite-te extrair os dois primeiros elementos de um `array` mantendo o resto intacto.
- Para adicionares outro `array` a um `array` existente, podes usar o operador `...` para fazer "spread" do `array`.

## 3. Adicionar os valores em falta

- Ao usar o desempacotamento com o operador rest (`...`), podes extrair o primeiro elemento de um `array` mantendo o resto intacto.
- Para adicionares outro `array` a um `array` existente, podes usar o operador `...` para fazer "spread" do `array`.

## 4. Ampliar a informação de percurso

- Para adicionares outro `object` a um `object` existente, podes usar o operador `...` para fazer "spread" do `object`.

## 5. Separar a hora de chegada da informação de percurso

- Para extrair um valor de um `object` mantendo o resto intacto, podes usar o operador rest (`...`).
