# usa funções com múltiplas cláusulas

[comment]: # (A intenção por trás deste comentário é dizer às pessoas para usar funções com múltiplas cláusulas, mas, como é muito difícil escrever uma boa análise para isso, verifica em vez disso utilizações de if, case e cond)

O objetivo deste exercício é ensinar funções com múltiplas cláusulas. Resolve-o sem usar `if`, `case` ou `cond`. Em vez disso, define várias cláusulas da função `compare`.
