# Introdução

## Noções básicas

### Funções

Em Gleam, as funções definem-se com a sintaxe `pub fn`.

```gleam
pub fn add(x: Int, y: Int) -> Int {
  x + y
}
```

Esta função recebe dois argumentos, ambos do tipo `Int`, e devolve um valor do tipo `Int`. Não existe a palavra-chave `return` em Gleam: o valor da última expressão de uma função é sempre _devolvido implicitamente_.

As anotações de tipo dos argumentos e o tipo devolvido são opcionais, e o Gleam verifica sempre completamente os tipos do teu código. Normalmente, quem programa em Gleam dá anotações de tipo às suas funções por clareza, mas podes omiti-las se quiseres.

```gleam
pub fn add(x, y) {
  x + y
}
```

Podes chamar uma função com a sintaxe `function_name(argument1, argument2)`.

```gleam
pub fn double(x: Int) -> Int {
  // Call the add function defined above
  add(x, x)
}
```

### Variáveis

Em Gleam, as variáveis definem-se com a sintaxe `let name = expression`.

```gleam
pub fn main() {
  let count = 1
}
```

As variáveis podem ser declaradas com anotações de tipo. Tal como nos argumentos de uma função, estas são opcionais, embora a maioria de quem programa em Gleam omita as anotações de tipo das variáveis para ser mais breve.

```gleam
pub fn main() {
  let count: Int = 1
}
```

### Literais de string

Em Gleam, as strings escrevem-se com aspas duplas.

```gleam
pub fn greeting() {
  "Hello, world!"
}
```

### Comentários no código

Podes usar comentários para deixar notas a outros programadores que leiam o código-fonte. Em Gleam, os comentários são linhas únicas precedidas de `//`.

```gleam
pub fn main() {
  // This is a comment
  let x = 1
}
```
