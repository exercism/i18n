# Introdução

## Carateres

O tipo `char` do C# é uma quantidade de 16 bits para representar os componentes mais pequenos e endereçáveis do texto. Vários `char`s podem formar uma string como `"word"`, ou os `char`s podem ser processados independentemente. Os seus literais usam aspas simples, por exemplo, `'A'`.

Os `char`s do C# suportam a codificação Unicode UTF-16, por isso, para além do conjunto de carateres latinos, praticamente todos os sistemas de escrita usados no mundo podem ser representados, por exemplo, a letra grega `'β'`.

Existem muitos métodos de biblioteca incorporados para inspecionar e manipular `char`s. Estes podem ser encontrados como métodos estáticos da classe `System.Char`.

## String Builder

Os `char`s são por vezes usados em conjunto com um objeto `StringBuilder`. Este objeto tem métodos que permitem construir uma string caráter a caráter e manipulá-la. No final do processo, pode chamar-se `ToString` ao objeto para obter uma string completa.
