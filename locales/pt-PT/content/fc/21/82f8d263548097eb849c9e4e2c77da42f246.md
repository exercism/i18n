# Instructions

Estamos a criar um clube de queijo, que vai usar ML para selecionar novos queijos a oferecer aos nossos clientes amantes de queijo, com base no seu historial e nos seus gostos.

Os novos membros têm de preencher um inquérito inicial para reunirmos alguns dados básicos com que começar.
A partir daí, verificou-se que existe um subconjunto de clientes enfáticos cujas críticas carecem de subtileza.
Como isto pode acabar por enviesar de forma irrevogável um algoritmo mais subtil, existe um algoritmo à parte, criado para responder às suas necessidades.
Pedem-te que forneças algumas funções auxiliares para tratar os seus dados.

~~~~exercism/note
Embora possa haver diferentes formas de resolver as tarefas seguintes, cada uma pode ser resolvida com, no máximo, duas funções de ordem superior.
~~~~

## 1. Classifica os clientes

O sistema de avaliação tem uma base de cinco estrelas, que consiste simplesmente nos números inteiros `1:5`.
Os clientes enfáticos só dão avaliações de `1` ou `5`, e queremos saber se um cliente tem este comportamento.

Implementa `all_15()`, que recebe um vetor de avaliações e devolve `true` se todas as avaliações forem `1` ou `5`, e false caso contrário.

```R
all_15(c(2, 3, 4, 4, 1))
#> [1] FALSE

all_15(c(1, 5, 5, 1, 5))
#> [1] TRUE
```

## 2. Nomeia os clientes

Precisamos de associar o nome (ou ID) do cliente às suas avaliações.

Implementa `name_customers()`, que recebe um vetor de nomes e uma lista de avaliações e os "junta" numa lista de listas.

Os elementos internos das listas devem ter os nomes `name` e `rating`.

```R
names <- c("c1", "c2")
ratings <- list(c(2, 3, 5), c(1, 1, 5))
name_customers(names, ratings)
#> [[1]]
#> [[1]]$name
#> [1] "c1"

#> [[1]]$rating
#> [1] 2 3 5

#> [[2]]
#> [[2]]$name
#> [1] "c2"

#> [[2]]$rating
#> [1] 1 1 5
```

## 3. Separa os clientes enfáticos

Precisamos de separar os clientes mais enfáticos dos restantes.

Implementa `emphatics()`, que recebe os clientes e as avaliações.
Devolve uma lista restrita aos clientes que usam apenas avaliações de `1` ou `5` estrelas.`

```R
# names and ratings as in the task 2 example

emphatics(names, ratings)
#> [[1]]
#> [[1]]$name
#> [1] "c2"

#> [[1]]$rating
#> [1] 1 1 5
```

## 4. Converte as avaliações em binário

Como os clientes enfáticos só usam avaliações de `1` e `5`, será computacionalmente mais conveniente converter estas em `0` e `1`.

Implementa `to_binary()`, que recebe um vetor de avaliações enfáticas.
Devolve avaliações binárias, em que `1` foi convertido em `0` e `5` foi convertido em `1`.

```R
to_binary(c(1, 1, 5, 5, 1))
#> [1] 0 0 1 1 0
```

## 5. Calcula as avaliações médias ao longo do tempo

Queres continuar a melhorar as recomendações para todos os clientes individualmente (não apenas para os enfáticos), à medida que compreendes melhor os seus gostos.

Implementa `satisfactions()`, que recebe um vetor de avaliações.
Devolve um vetor de avaliações médias acumuladas até esse momento.
Arredonda os resultados a 2 casas decimais.

Esperemos que os números continuem a crescer, para clientes felizes!

```R
satisfactions(c(1, 2, 2, 3))
#> [1] 1.00 1.50 1.67 2.00
```
