# Mapas e conjuntos

| Tipo | Contém | Procura-se por |
| --- | --- | --- |
| `ARRAY{T}` | valores por ordem | posição |
| `FMAP{K,T}` | pares chave-alvo | chave |
| `FSET{T}` | valores, sem repetições | pertença |

## FMAP

```sather
   m ::= #FMAP{STR,INT};
   m := m.insert("emu", 2);
   m.get("emu")          -- 2
   m.has_ind("emu")      -- true
   m.size                -- 1
   m := m.delete("emu");
```

`m["emu"]` **não** é a forma de ler um mapa. O `FMAP` não tem essa rotina e essa linha não compila. É `get`.

### Chaves em falta

O `get` sobre uma chave que não existe devolve o valor vazio do tipo em vez de se queixar: `0`, `false` ou void. Uma `STR` void não falha onde é produzida; falha mais tarde, onde quer que acabe por ser usada. Usar `has_ind` primeiro é o hábito que vale a pena criar.

## FSET

```sather
   s ::= #FSET{STR};
   s := s.insert("emu");
   s.has("emu")          -- true
   s.size                -- 1
   s := s.delete("emu");
```

Os conjuntos combinam-se:

```sather
   a.union(b)            -- in either
   a.intersect(b)        -- in both
   a.difference(b)       -- in a but not b
   a.is_subset(b)
```

## Atribuir de volta e copiar

O `insert` e o `delete` devolvem o contentor a usar a partir de agora. Normalmente é o mesmo objeto, alterado no local; quando tem de crescer, é um novo, maior. Por isso:

```sather
   m := m.insert(k, v);     -- always
```

e o nome à esquerda é o único em que podes confiar depois disso. Outro nome para o mesmo mapa, obtido antes do `insert`, pode estar desatualizado.

Para guardares uma cópia independente, tira uma primeiro:

```sather
   n ::= m.copy.insert(k, v);      -- m is unchanged
```

com um senão: um mapa onde nunca se inseriu nada é **void**, e o `copy` sobre um mapa void falha. O `insert`, o `get`, o `has_ind` e o `size` lidam todos com um mapa void (`#FMAP{K,T}` é void, e é ao inserir nele que um mapa começa a existir), mas o `copy` não.

O `HMAP` e o `HSET` são as versões que só mudam no local. São mais rápidas para construir algo grande, e são a escolha errada enquanto estás a aprender.

## Percorrer um

| Iterador | Dá |
| --- | --- |
| `m.ind!` | cada chave |
| `m.target!` | cada alvo |
| `m.pair!` | cada chave e alvo em conjunto |
| `s.elt!` | cada valor de um conjunto |

Nem um mapa nem um conjunto têm ordem. Duas execuções podem percorrê-los de forma diferente, por isso nunca escrevas nada que dependa daquilo que vem primeiro.

```sather
   loop
      #OUT + guide.ind! + "\n";
   end;
```
