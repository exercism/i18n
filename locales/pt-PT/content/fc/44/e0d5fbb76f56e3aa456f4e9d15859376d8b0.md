# Sobre

O [Groovy](http://www.groovy-lang.org/) é a linguagem dinâmica, poderosa e com tipagem opcional da Apache Foundation, que também oferece capacidades de tipagem estática e compilação estática.

O Groovy tem como objetivo melhorar a produtividade do programador graças a uma sintaxe concisa e fácil de aprender.
Facilita a escrita de scripts, a criação de linguagens específicas de domínio, a metaprogramação em tempo de execução e de compilação, e a programação funcional.

Dá acesso a todo o ecossistema de bibliotecas Java e integra-se perfeitamente com aplicações Java.

Pode ser usado como uma linguagem de scripts simples ou adicionado a frameworks Java complexos. 
Alimenta tecnologias como: 
* o Gradle, 
* o Spock, 
* o Ratpack, 
* o Grails, 
* e a escrita de scripts no Jenkins.

Além disso, é divertido.
