A verdadeira aprendizagem vem a seguir!

Esta semana lançámos o novo separador "Dig Deeper" nos exercícios. Foi concebido para te ajudar a ir além da fase de resolução e a explorar as nuances e as contrapartidas de um exercício, sem precisares de pedir ajuda a um mentor.

## Introdução

As soluções dos nossos exercícios variam imenso.
O exercício "a sério" mais básico na maioria dos percursos é o `TwoFer`.
Uma solução típica tem este aspeto (isto é Ruby, mas é semelhante na maioria das linguagens):

```ruby
module TwoFer
  def self.two_fer(name='you')
    "One for #{name}, one for me."
  end
end
```

No entanto, das 500 soluções mais recentes que passaram nos testes, mais de 350 eram únicas 😲
E mesmo quando normalizas coisas como espaços em branco e nomes de variáveis, mais de metade continuam a ser soluções realmente únicas.

O que torna absolutamente fascinante explorar a forma como cada pessoa resolve as coisas.
Mas também é totalmente impraticável. Há milhões de soluções no Exercism e lê-las todas levaria, literalmente, uma vida inteira.

No entanto! Como concebemos os exercícios e orientámos centenas de milhares de pessoas através deles, a nossa equipa tem uma ideia bastante clara das diferentes abordagens que as pessoas seguem.
Por isso, adicionámos o novo separador Dig Deeper para destacar as diferentes formas idiomáticas (ou não idiomáticas, mas interessantes) de resolver um exercício.

## Um exemplo

Vamos ver um exemplo para mostrar isto em ação.
Em C#, há várias formas de inverter uma string.

Podes usar o método `Array.Reverse()`:
```csharp
var chars = input.ToCharArray();
Array.Reverse(chars);
return new string(chars);
```

Ou usar uma abordagem mais curta, baseada em LINQ:
```csharp
return new string(input.Reverse().ToArray());
```

ou usar um `StringBuilder`:
```
var chars = new StringBuilder();
for (var i = input.Length - 1; i >= 0; i--)
{
    chars.Append(input[i]);
}
return chars.ToString();
```

ou até seguir uma via um pouco menos idiomática (mas mais eficiente!) e usar `Span<T>`:

```csharp
Span<char> chars = stackalloc[input.Length];
for (var i = 0; i < input.Length; i++)
{
    chars[input.Length - 1 - i] = input[i];
}
return new string(chars);
```

Chamamos a cada uma destas uma Abordagem, e cada uma tem o seu próprio artigo a explicá-la.
