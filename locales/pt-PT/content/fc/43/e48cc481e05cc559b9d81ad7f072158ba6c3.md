# Introdução

A instrução `guard` de Swift serve para devolver valores antecipadamente de funções Swift quando não se verifica uma condição necessária para que o processamento continue, por exemplo:

```swift
guard myValue >= 0 else { return 0 }
let root = myValue.squareRoot()
```

Aqui, o `guard` verifica se a expressão Boolean que se segue à palavra-chave `guard` é avaliada como verdadeira. Se for, o processamento continua com o código que se segue à instrução `guard` (aqui, `let root = myValue.squareRoot()`. Caso contrário, executa o código da cláusula else. Ao contrário de uma condicional `if`, uma instrução `guard` _tem obrigatoriamente_ de ter uma cláusula else e, ao contrário da cláusula else de um if-else, a cláusula else de um `guard` _tem_ de sair do âmbito da instrução `guard`. Ou seja, tem de usar uma instrução de transferência de controlo como `return`, `continue` ou `break`, ou então lançar um erro ou terminar o programa.
