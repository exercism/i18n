# Debug

Quando um teste falha, é apresentada uma mensagem que descreve o que correu mal e para que valor de entrada.

Imprimir valores e o conteúdo de variáveis também pode ajudar a perceber o que se passa.
O PHP consegue imprimir valores com:

- `echo 'Debug message';` para mostrar uma string à tua escolha
- `var_dump($variable);` para obteres mais detalhes sobre um valor, por exemplo o tipo que o PHP vê
