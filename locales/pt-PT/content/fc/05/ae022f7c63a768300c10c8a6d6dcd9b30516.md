# Dicas

**Lembra-te**: os testes deste exercício são indiferentes à mutação, mas os nomes das funções indicam que estas não devem provocar mutações.
Se quiseres usar funções da introdução sem alterares o valor de entrada, a função `copy()` será útil.

## 1. Cria um inventário com base num vetor

- Pode ser útil ver a Tarefa 2 antes de começares.

## 2. Adiciona itens de um vetor a um dicionário existente

- A abordagem mais simples é percorrer o vetor de entrada item a item.
- A função [`haskey(dict, key)`][haskey] será útil.

## 3. Decrementa itens do inventário

- O código é bastante semelhante ao da Tarefa 2, com uma mudança de sinal.
- Lembra-te de não deixar a contagem de itens ficar abaixo de zero.
- A lógica `if...else` funciona, mas a função [`max()`][max] permite escrever código conciso e idiomático.

## 4. Remove completamente uma entrada do inventário

- A Julia tem uma função que faz exatamente isto: lê a introdução.

## 5. Devolve todo o conteúdo do inventário

- Lembra-te de remover os itens com contagem zero.
- Para quem está a começar, pode ser mais fácil percorrer os itens e usar [`push!()`][push] se for apropriado.
- Uma compreensão de listas ao estilo do Python é muito mais concisa, e é permitido acrescentar uma cláusula `if` no fim.
- Apesar de exigir conhecimentos de Conceitos posteriores, quem estiver familiarizado com programação funcional pode querer explorar a função [`filter()`][filter].
- É necessária uma lista ordenada, e [`sort()`][sort] ordena, por omissão, pela primeira parte de um par.
