# Carateres

Um **caráter** é uma só letra, um algarismo, um espaço ou um símbolo. Em Sather, o tipo para um caráter é `CHAR`, e um caráter escreve-se entre plicas.

```sather
   initial : CHAR is
      return 'M';
   end;
```

Plicas para um caráter, aspas para uma string. `'M'` e `"M"` são tipos diferentes e não podem ser trocados um pelo outro.

## Carateres a partir de uma string

Uma string é uma fila de carateres, e os parênteses retos dão acesso a um deles pela posição, a contar do zero, tal como num array.

```sather
"Marlowe"[0]      -- 'M'
"Marlowe"[3]      -- 'l'
```

## Perguntar sobre um caráter

| Chamada | Resposta |
| --- | --- |
| `c.is_alpha` | é uma letra? |
| `c.is_digit` | é um dos algarismos de `0` a `9`? |
| `c.is_upper` | é uma maiúscula? |
| `c.is_lower` | é uma minúscula? |

Cada uma devolve `true` ou `false`.

```sather
'M'.is_alpha      -- true
'7'.is_alpha      -- false
'7'.is_digit      -- true
```

## Converter entre maiúsculas e minúsculas

`.upper` dá a maiúscula de uma letra, e `.lower` dá a minúscula. Tudo o que não seja uma letra é devolvido sem alterações.

```sather
'm'.upper         -- 'M'
'M'.lower         -- 'm'
'7'.upper         -- '7'
```

## Carateres como números

Cada caráter tem um número. `.int` dá esse número, e `.char` transforma um número de volta num caráter.

```sather
'a'.int           -- 97
'b'.int           -- 98
98.char           -- 'b'
```

Os números exatos raramente importam. O que importa é que as letras de `a` a `z` estão em ordem e uma a seguir à outra, por isso `'c'.int - 'a'.int` é 2: a posição do `c` no alfabeto. É isso que faz funcionar uma roda de cifra.
