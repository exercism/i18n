# Subsídio de Combustível

## Enunciado do problema

Todos os funcionários da ABC Corp recebem um subsídio de combustível ilimitado. Os funcionários têm de enviar um registo sempre que abastecem os veículos. Estes registos são acrescentados ao mesmo ficheiro CSV e processados no fim do mês.

Como membro da equipa de operações digitais, a tua tarefa é ler este ficheiro CSV e escrever os resultados noutro ficheiro CSV. O ficheiro de saída deve conter uma entrada por cada funcionário, com os seguintes dados:

- Número do funcionário
- Número de abastecimentos
- Custo total do combustível
- Total de galões
- Total de milhas acumuladas

Recebes dois argumentos do tipo `string`.

1. Caminho do ficheiro CSV de entrada
1. Caminho do ficheiro CSV de saída

O ficheiro CSV de entrada tem `n` linhas e cada linha tem o seguinte formato.

| Nome da coluna      | Tipo em Ballerina |
| ----------- | ----------- |
| employee_id      | `int`       |
| odometer_reading   | `int`       |
| gallons   | `decimal` |
| gas_price(USD)  |`decimal`|

O ficheiro de saída deve conter uma entrada por cada funcionário, ordenadas por ordem crescente de `employee_id`. Cada linha tem o seguinte formato:

| Nome da coluna      | Tipo em Ballerina |
| ----------- | ----------- |
| employee_id      | `int`       |
| gas_fill_up_count   | `int`        |
| total_fuel_cost(USD)   | `decimal` |
| total_gallons  |`decimal`|
| total_miles_accrued  |`int`|

## Restrições

- Número de linhas `n` no ficheiro CSV de entrada: 2 <= n <= 1000
- Número de funcionários da empresa: 97
- O preço do combustível é por galão
- Não faltam registos de abastecimento

## Exemplo 1

- Entrada: `example01_input.csv`

```csv
2312,230,18.561,4.56
2312,500,19.345,4.89
```

- Saída: `example01_output.csv`

```csv
2312,2,179.23521,37.906,270
```
