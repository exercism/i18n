# Dicas

## 1. Extrair as coordenadas

- Estamos a tentar extrair um elemento de um tuplo.
- A indexação é uma possibilidade.
- A atribuição múltipla é uma abordagem alternativa.

## 2. Formatar as coordenadas

- Lembra-te do construtor [`Tuple()`][Tuple].

## 3. Fazer corresponder as coordenadas

- Já tens uma função para converter a coordenada da Azara no formato do Rui.
- Testar a igualdade é uma possibilidade.
- Em alternativa, testa se a coordenada está no registo do Rui (∈).

## 4. Combinar os registos correspondentes

- Os registos correspondem? Já sabes como testar isso.
- Se corresponderem, os elementos pretendidos têm de ser combinados por uma ordem diferente no valor devolvido.
- Nem todos os elementos do tuplo de entrada fazem parte do resultado.
- O desempacotamento é teu amigo. Dar nomes significativos aos elementos é mais legível e mais fácil de depurar do que usar indexação.

[Tuple]: https://docs.julialang.org/en/v1/base/base/#Core.Tuple
