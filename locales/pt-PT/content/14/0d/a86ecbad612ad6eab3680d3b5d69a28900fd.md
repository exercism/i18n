# Dicas

## Geral

- [Documentação do Python: Enum](https://docs.python.org/3/library/enum.html)

## 1. Faz o parsing do nível de log

- Usa [`str.split`](https://www.w3schools.com/python/ref_string_split.asp) para extrair o nível de log da mensagem.
- Com a parte extraída da string, acede ao membro do enum e devolve-o usando `LogLevel(string)`.

## 2. Suporta um nível de log desconhecido

- Cria um novo membro de nível de log Unknown no enum existente.
- Verifica se a parte extraída da string é um valor do enum `LogLevel`.
- Se o valor não corresponder a nenhum dos valores dos membros do enum, devolve o membro Unknown de `LogLevel`.

## 3. Converte a linha de log para o formato curto

- Encontra o código (um número inteiro) do nível de log com base no nível de log; há várias soluções possíveis: condicionais, outro enum ou qualquer outra solução.
- Usa formatação de strings para devolver um nível de código e uma mensagem devidamente formatados.

## 4. Cria um alias

- Cria o novo membro alias com o nome Warn no enum existente.
- Devolve o membro recém-criado.

## 5. Todos os nomes e valores dos membros

- Itera sobre todos os membros do enum e devolve uma lista de tuplos.
- O tuplo pode ser construído com `(item1, item2)`.
- O nome e o valor do enum podem ser acedidos com `member.name` e `member.value`.
- Devolve a lista que contém todos os tuplos.
