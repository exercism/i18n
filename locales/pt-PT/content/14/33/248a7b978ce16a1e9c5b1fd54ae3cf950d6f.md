# Instalação

Este track usa ReScript 12 e precisa do [Node.js][nodejs] 22 ou superior.
Muitos sistemas já o trazem pré-instalado, ou podes já tê-lo instalado para outro track.

Abre um terminal e executa:

```sh
node -v
```

Se o Node não estiver instalado, ou se estiver listada uma versão mais antiga, segue as [instruções oficiais de instalação do Node.js][nodejs-install] para a tua plataforma.

## Instalar as dependências

Cada exercício de ReScript é um projeto npm autónomo.
Depois de descarregares um exercício com o [Exercism CLI][exercism-cli], instala as dependências do projeto, incluindo o ReScript, e está tudo pronto para começar:

```sh
cd /path/to/exercise
npm install
```
