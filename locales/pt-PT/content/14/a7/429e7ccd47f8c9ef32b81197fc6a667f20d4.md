# Dicas

## Geral

- Lê sobre [opcionais][optionals] e sobre [condicionais][conditionals] no _A Tour of Swift_, da Apple.

## 1. Escreve uma função que calcule o tamanho das fatias e que devolva nil para parâmetros de entrada inválidos.

- A área de um círculo é _pi_ \* _r_<sup>2</sup>, em que _r_ é metade do diâmetro.
- Podes usar a conversão de tipos para converter um `Int` num `Double`.
- Podes usar uma condicional ao estilo guard para sair mais cedo se algum dos parâmetros for inválido.

## 2. Processa o valor de entrada da tua aplicação web para determinar a fatia maior.

- Podes usar a ligação opcional para verificar se um opcional tem valor e para extrair esse valor, caso exista.
- Podes sair da função mais cedo se souberes qual deve ser o valor devolvido, sem processamento adicional.
- Não podes comparar `nil` diretamente com valores que não sejam `nil`.
- Podes usar instruções switch e padrões opcionais para comparar valores opcionais.
