## Implementation

Deves definir um tipo personalizado 'DNA' com uma função 'Counts' que devolve dois valores:

- uma contagem de frequência para a cadeia de DNA fornecida
- um erro (se houver nucleótidos inválidos)

Qual é um bom tipo para uma cadeia de DNA?

Quais são os melhores tipos de Go para representar os valores de saída?

Dá uma vista de olhos pelos casos de teste para teres uma pista sobre quais poderão ser os possíveis parâmetros de entrada.
