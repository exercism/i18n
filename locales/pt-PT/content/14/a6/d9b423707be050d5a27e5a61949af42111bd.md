# Dicas

## 1. Substitui os espaços que encontrares por underscores

- Encontras aqui a [documentação de referência][char-docs] sobre os `Char`.
- Os literais `Char` escrevem-se entre aspas simples e os literais `String` entre aspas duplas.

## 2. Remove todos os espaços em branco

- Consulta [este método][isspace] para detetar carateres de espaço em branco e [este método][isdigit] para algarismos.

## 3. Converte camel-case em kebab-case

- Consulta [este método][isuppercase] para verificar se um caráter é maiúsculo.
- Consulta [este método][lowercase] para converter um caráter em minúscula.

## 5. Omite as letras gregas minúsculas

- Os `Char` suportam os operadores de igualdade e de comparação predefinidos.

## 6. Combina estas operações para operar sobre uma string

- Podes iterar sobre uma string da mesma forma que sobre um array.
- Para fazeres todas as transformações, considera usar uma compreensão.
- Várias strings podem ser [unidas][join] numa só.
