# Introdução

Em Haxe, uma `class` é a principal estrutura de dados, que encapsula dados (campos) e comportamento (métodos). Os campos e os métodos também se chamam membros de uma classe.

O acesso aos membros pode ser restringido com modificadores de acesso, que são:

- `public`: o membro pode ser acedido a partir de qualquer lugar.
- `private`: o membro só pode ser acedido pela própria classe.

As classes podem ser vistas como modelos para criar instâncias. Para criar uma instância, basta usar a palavra-chave `new`:

```haxe
class Car {
  public function new() {}
}

var myCar = new Car();
var yourCar = new Car();
```

Para definir um campo, usa um modificador de acesso seguido do nome e do tipo da variável:

```haxe
class Car {
  public var weight:Int; // Accessable by anyone

  private var color:String; // Accessable only within this class
}
```

Também podes definir um valor inicial ao declarar um campo. Se um campo não especificar um valor inicial, assume o valor `null`. Podes aceder a um campo com a notação de ponto:

```haxe
class Car {
  public var weight:Int = 2500; // Weight will be set to 2500
  public var year:Int; // year will be null

  public function new() {}
}

var newCar = new Car();
newCar.weight; // 2500
newCar.year; // null

// Update value of field
newCar.year = 2020;
```
