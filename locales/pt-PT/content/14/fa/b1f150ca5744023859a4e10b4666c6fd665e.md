# Dicas

## Geral

- [O tutorial de dicionários do Python][dict-tutorial] pode ser um ótimo ponto de partida.
- A documentação do Python sobre [tipos de mapeamento - dicts][dict docs] também é bastante útil.

## 1. Cria um inventário a partir de uma lista

- Precisas de um [ciclo for][for-loop] para iterar a lista de itens, depois inserir cada item no dicionário se faltar e incrementar a contagem do item usando o acesso ao dicionário.
- Podes usar [`dict.setdefault`][dict setdefault] para garantires que o valor está definido antes de incrementar a contagem do item.
- Esta função deve [devolver][return-keyword] um dict.

## 2. Adiciona itens de uma lista a um dicionário existente

- Precisas de um [ciclo for][for-loop] para iterar a lista de itens, depois inserir cada item se ainda não estiver no dicionário e [incrementar][increment] a contagem do item usando o acesso ao dicionário.
- Podes usar [`dict.setdefault`][dict setdefault] para garantires que o valor está definido antes de incrementar a contagem do item.
- A função `add_items` pode ser usada pela função `create_inventory` com um dicionário vazio como parâmetro.
- Esta função deve [devolver][return-keyword] um dict.

## 3. Decrementa itens do inventário

- Precisas de um [ciclo for][for-loop] para iterar a lista de itens e, se o número de itens não for `0`, [decrementar][decrement] o número atual de itens.
- Podes usar a verificação `key in dict`, que devolve `True` se a chave existir, para garantires que o valor está no dicionário antes de decrementar o número de itens.
- Esta função deve [devolver][return-keyword] um dict.

## 4. Remove completamente um item do inventário

- Se o item estiver no dicionário, [remove-o][dict-pop].
- Se o item não estiver no dicionário, não faças nada.
- Esta função deve [devolver][return-keyword] um dict.

## 5. Devolve o conteúdo do inventário

- Tens de usar um [ciclo for][for-loop] no inventário e, se o número de itens for maior do que `0`, acrescentar o `tuple` a uma `list`.
- Podes usar [`dict.items()`][dict items] para iterar ao mesmo tempo sobre o item e o valor; `items()` devolve um `tuple` que podes usar ou desconstruir, se for preciso.
- Esta função deve [devolver][return-keyword] uma [lista][list] de [tuplos][tuples].
