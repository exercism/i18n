# Introdução

Um buffer de String é uma forma eficiente de construir uma string grande, acrescentando-lhe pequenos elementos uns a seguir aos outros. Ao contrário de String, uma instância de StringBuf não é imutável: pode ser passada como argumento a funções que a modificam, acrescentando-lhe mais valores.

```haxe
var a = new StringBuf();
a.add("Hello");
trace(a.toString()); // Hello
a.add("Haxe!");
trace(a.toString()); // HelloHaxe
```
