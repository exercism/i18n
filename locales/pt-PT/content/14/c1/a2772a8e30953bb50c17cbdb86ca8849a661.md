# Instruções

A Izzy é uma observadora de aves ávida que mantém o registo de quantas aves visitaram o seu jardim em cada dia.

Ela pediu-te ajuda para levar a sua observação de aves a um novo nível e para implementares algumas ferramentas que a ajudem a registar e a processar os dados.

Escolheste guardar os dados numa lista de números inteiros. O primeiro número da lista é o número de aves que visitaram o teu jardim hoje, o segundo ontem, e assim sucessivamente.

## 1. Verifica quantas aves visitaram hoje

Implementa a função `today`. Deve receber uma lista com as contagens diárias de aves e devolver a contagem de hoje. Se a lista estiver vazia, deve devolver `0`.

```gleam
today([2, 5, 1])
// -> 2
```

## 2. Incrementa a contagem de hoje

Implementa a função `increment_day_count`. Deve receber uma lista com as contagens diárias de aves e incrementar a contagem de hoje em 1. Se a lista estiver vazia, devolve `[1]`.

```gleam
increment_day_count([4, 0, 2])
// -> [5, 0, 2]
```

## 3. Verifica se houve algum dia sem aves visitantes

Implementa a função `has_day_without_birds`. Deve receber uma lista com as contagens diárias de aves. Deve devolver `True` se houve pelo menos um dia em que nenhuma ave visitou o jardim, e `False` caso contrário. Se a lista estiver vazia, isso conta como ainda não ter sido registada nenhuma ave; devolve `False`.

```gleam
has_day_without_birds([2, 0, 4])
// -> True

has_day_without_birds([3, 8, 1, 5])
// -> False
```

## 4. Calcula o número total de aves visitantes

Implementa a função `total`. Deve receber uma lista com as contagens diárias de aves e devolver o número total de aves que visitaram o teu jardim desde que começaste a recolher os dados.

```gleam
total([4, 0, 9, 0, 5])
// -> 18
```

## 5. Calcula o número de dias movimentados

Há dias mais movimentados do que outros. Um dia movimentado é aquele em que cinco ou mais aves visitaram o teu jardim.

Implementa a função `busy_days`. Deve receber uma lista com as contagens diárias de aves e devolver o número de dias movimentados.

```gleam
busy_days([4, 5, 0, 0, 6])
// -> 2
```
