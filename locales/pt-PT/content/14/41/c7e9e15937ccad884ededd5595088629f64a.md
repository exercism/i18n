# Instruções

Uma roda de cifra é composta por dois discos, um dentro do outro, que fazem girar o alfabeto: põe-na no 3 e cada letra passa a ser a que fica três posições à frente, com o `z` a voltar ao `a`. Os detetives usam-nas há séculos. Estás a construir uma.

As cinco tarefas ficam todas na classe `CIPHER_WHEEL`.

## 1. É uma letra?

```sather
CIPHER_WHEEL::is_letter('m')
-- => true
CIPHER_WHEEL::is_letter('7')
-- => false
```

## 2. Grita-o

Devolve a maiúscula de um caráter. Tudo o que não for uma letra é devolvido tal como está.

```sather
CIPHER_WHEEL::shout('m')
-- => 'M'
```

## 3. Qual é o número?

Devolve o número que corresponde a um caráter.

```sather
CIPHER_WHEEL::code('a')
-- => 97
```

## 4. O primeiro caráter

Devolve o primeiro caráter de uma string.

```sather
CIPHER_WHEEL::first_character("Marlowe")
-- => 'M'
```

## 5. Gira a roda

Dada uma letra minúscula e um número de posições, devolve a letra que fica esse número de posições à frente no alfabeto. Depois do `z`, volta ao `a`.

```sather
CIPHER_WHEEL::turn('a', 3)
-- => 'd'
CIPHER_WHEEL::turn('z', 1)
-- => 'a'
```

Também funciona girar para trás, com um número negativo de posições.

```sather
CIPHER_WHEEL::turn('a', -1)
-- => 'z'
```

Podes assumir que o caráter recebido é uma letra minúscula.
