# Introdução

Uma declaração `MACRO:` é como `:`, mas o corpo corre em *tempo de compilação* e tem de devolver uma quotation. O compilador substitui a chamada da macro pela quotation devolvida. Como o corpo é código Factor normal, construir a quotation resultante é apenas manipular sequências de words.

```factor
USING: kernel macros sequences ;

MACRO: twice ( quot -- compound )
    dup append ;

: shout-twice ( name -- ) [ " ahoy!" append print ] twice ;
! At compile time, the call site is replaced with
! [ " ahoy!" append print " ahoy!" append print ].
```

Os parâmetros de entrada de uma macro são *literais no local da chamada*. Se passares um valor que não seja literal, o compilador recusa-se a especializar. O corpo da macro precisa do valor em tempo de compilação, não em tempo de execução.

Um parente próximo é o bloco de avaliação em tempo de análise `<< … >>`, que executa Factor arbitrário em tempo de compilação sem o contrato de devolver uma quotation. Ambos fazem parte do mecanismo [`macros`][macros] do Factor.
