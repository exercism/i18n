# Aprendizagem

Odin é uma linguagem de programação de sistemas.
Tal como em C, o programador tem de gerir a memória manualmente.
Ainda assim, é uma linguagem bastante simples.

Os seguintes recursos estão disponíveis para te ajudar a aprender Odin:

Tem um primeiro contacto com a linguagem:

* Vê a [Introduction to Odin][video], apresentada pelo criador do Odin.
* Lê o artigo [Introduction to Odin][intro], escrito pelo autor de ["Understanding the Odin Programming Language"][book].
* Estuda o [Ficheiro de demonstração][demo], que mostra, em código, conceitos do Odin.

Aprofunda com:

* [Visão geral da linguagem Odin][overview].
* A documentação dos [pacotes oficiais][packages].
* O livro ["Understanding the Odin Programming Language"][book] (pago).
* O conjunto oficial de ["Odin Examples"][examples].
