# Dicas

## Geral

- Uma chamada de cauda em x86-64 é um `jmp` para outra função
- Para funções que não são naturalmente recursivas de cauda, podes definir um auxiliar que recebe um acumulador como argumento extra e faz uma chamada de cauda a si próprio

## 1. Divide a massa

- O algoritmo de Euclides já está em forma de cauda
- O caso base é `rsi == 0`
- Para calcular `a mod b`, podes usar [div][integers-concept]

## 2. Fatorial duplo

- Tanto `0!!` como `1!!` são `1`
- Num fatorial duplo, `n` diminui 2 a cada passo
- O acumulador começa em `1`

## 3. Transformação de convergência de Newton/Euler

- O teu auxiliar recursivo de cauda pode receber tantos argumentos extra quantos precisares para manter os valores em curso
- Podes consultar [um conceito anterior][floats-concept] para instruções sobre como operar com números de vírgula flutuante de 64 bits
- Multiplica a soma final por `2`, uma vez que a fórmula dá `π/2`
