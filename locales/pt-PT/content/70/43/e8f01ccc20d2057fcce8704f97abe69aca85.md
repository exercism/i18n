# Testes

A maioria dos testes verifica que, ao atribuíres um valor a [result] ou ao passares um valor a [exit], devolves o valor esperado.

Alguns testes verificam que lanças a exceção esperada com [raise].

## Executar os testes

O utilitário `make` é uma dependência para executar os testes.

Dentro do diretório do exercício, escreve numa consola/terminal:

```sh
make
```

Se ainda não tocaste no ficheiro de solução do exercício, vais ver uma mensagem como:

```
Please implement your solution.
```

Por isso, remove esta linha antes de começares a escrever a tua solução.

Por predefinição, só o primeiro teste é executado.

```text
TAP version 14
1..10
ok 1 - ...
```

Para executar todos os testes, escreve:

```sh
make test=all
```

```text
TAP version 14
1..10
ok 1 - empty_sentence
ok 2 - perfect_lower_case
ok 3 - only_lower_case
ok 4 - missing_the_letter_x
ok 5 - missing_the_letter_h
ok 6 - with_underscores
ok 7 - with_numbers
ok 8 - missing_letters_replaced_by_numbers
ok 9 - mixed_case_and_punctuation
ok 10 - am_and_AM_are_26_different_characters_but_not_a_pangram
```

Quando todos os testes passarem, terminaste o exercício e podes submeter a solução.

É possível escolher um único teste para executar, passando o número correspondente, por exemplo:

```sh
make test=2
```

executaria apenas o segundo teste.
