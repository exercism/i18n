# Introdução

## A expressão if

A **expressão condicional** do `jq` é `if A then B else C end`.

`if-then-else` é um filtro como todas as funções internas do `jq`: recebe uma entrada e produz uma saída.

Se a expressão `A` produzir um valor «verdadeiro», o filtro `if` avalia `B`.
Caso contrário, avalia `C`.
A entrada do filtro `if` é passada a `B` ou a `C`.

```jq
42 | if . < 50 then "small" else "big" end      # => "small"
```

```jq
5 | if . % 2 == 0 then . / 2 else . * 4 end     # => 20
```

~~~~exercism/note
A cláusula `else` é **opcional**; as duas instruções seguintes são equivalentes.

```jq
if A then B else . end
if A then B end
```
~~~~

## Condicionais aninhadas

Podes acrescentar mais condições com `elif`.

```jq
42 | if . < 33 then "small"
     elif . < 66 then "medium"
     else "big"
     end
# => "medium"
```

Usa as cláusulas `elif` que precisares.

## O que conta como verdadeiro

Os únicos valores «falsos» em `jq` são: `false` e `null`.
Tudo o resto é «verdadeiro», até o número zero e a string vazia, o array vazio e o objeto vazio.

## Operadores Boolean

Os **operadores Boolean** `and` e `or` podem ser usados para construir consultas complexas.

```jq
42 | if . < 33 or . > 66 then "big or small"
     else "medium"
     end
```

Para negar, usa `not`. Isto é um **filtro**, não um operador.

```jq
42 | if (. < 33 or . > 66 | not) then "medium"
     else "big or small"
     end
```

## O operador alternativo

O **operador alternativo** permite-te especificar um valor por omissão se uma expressão for falsa ou nula.

```jq
A // B

# This is identical to
if A then A else B end
```

Para demonstrar:

```jq
[3, 5, 18] | add / 2       # => 13
[]         | add / 2       # => error: null (null) and number (2) cannot be divided
[]         | add // 0 / 2  # => 0
```
