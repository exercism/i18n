# Arrays

`ARRAY{T}` é uma sequência fixa de valores do tipo `T`.

```sather
   row : ARRAY{STR} := |"Mia", "Ana", "Ben"|;
   sizes : ARRAY{INT} := |3, 1, 2|;
```

## As chavetas

`ARRAY{STR}` lê-se "array de `STR`". As chavetas contêm um **parâmetro de tipo**:
`ARRAY` sozinho não é um tipo, porque um array tem de ser um array de alguma
coisa. Grande parte da biblioteca do Sather está construída assim, e escrever
uma classe destas é assunto para mais tarde.

## Posições

```sather
row[0]                 -- the first
row[row.size - 1]      -- the last
row.size               -- how many
```

As posições vão de `0` a `.size - 1`. Um array sabe qual é o seu tamanho e nunca
o altera: não há forma de acrescentar elementos a um `ARRAY`.

## Criar um sem usar um literal

`#ARRAY{INT}(n)` cria um array com `n` valores, todos a zero:

```sather
   counts ::= #ARRAY{INT}(5);      -- five noughts
   counts[0] := 7;
```

Atribuir a uma posição usa os mesmos parênteses retos à esquerda de
`:=`.

## Fora dos limites

Ler ou escrever numa posição que não existe não é verificado numa compilação
normal. Não vai parar o programa com uma mensagem útil; vai ler ou escrever o
que estiver a seguir na memória. Dois hábitos evitam isso: usa
`.size - 1` em vez de um número contado de cabeça, e termina os ciclos com
`until!(i >= a.size)` em vez de um literal.

## Imprimir um

`.str` devolve o conteúdo entre chavetas, o que dá jeito enquanto estás a
resolver qualquer coisa:

```sather
   #OUT + row.str;      -- {Mia,Ana,Ben}
```
