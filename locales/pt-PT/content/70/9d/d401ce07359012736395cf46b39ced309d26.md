# Instruções adicionais

## Registos

| Registo | Utilização | Tipo    | Descrição                          |
| -------- | --------- | ------- | -------------------------- |
| `$a0`    | entrada   | endereço | array com os pesos dos itens      |
| `$a1`    | entrada   | endereço | array com os valores dos itens     |
| `$a2`    | entrada   | inteiro | número de itens            |
| `$a3`    | entrada   | inteiro | peso máximo             |
| `$v0`    | saída     | inteiro | valor máximo              |
| `$t0-9`  | temporário | qualquer | usado para armazenamento temporário |
