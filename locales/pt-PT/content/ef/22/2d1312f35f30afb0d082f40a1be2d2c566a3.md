# Dicas

## Geral

- Usa `?` para trabalhar com os [pontos de código][codepoint] dos carateres.
- Podes usar `\s` para representar um espaço.
- Usa a notação abreviada de [literal inteiro binário][integer-literal] para trabalhar com os códigos.
- Tenta usar a estratégia de recursão de cauda.

## 1. Codifica o ácido nucleico num valor binário

- Esta função precisa de mapear um número inteiro noutro.
- Esta função não precisa de recursão.
- Usar várias cláusulas de função pode facilitar isto, ao decompor o problema.

## 2. Descodifica o valor binário no ácido nucleico

- Esta função é o oposto da função da parte 1.
- Esta função não precisa de recursão.
- Usar várias cláusulas de função pode facilitar isto, ao decompor o problema.

## 3. Codifica uma charlist de ADN

- Cria uma função recursiva de cauda que recebe um ponto de código da charlist e constrói recursivamente a bitstring resultante.
- As funções recursivas de cauda precisam de um acumulador.
- Lembra-te de que uma [charlist][charlist] é uma lista de [pontos de código inteiros][codepoint].
- Podes obter o primeiro item e os restantes de uma lista com uma função incorporada do [módulo `Kernel`][kernel].
- Também podes fazer correspondência de padrões numa lista com a notação [`[head | tail]`][list].
- Usa várias cláusulas de função para separar o caso base dos casos recursivos.
- Não te esqueças de especificar os tipos dos segmentos da bitstring com o operador `::`.

## 4. Descodifica uma bitstring de ADN

- Cria uma função recursiva de cauda que faz correspondência com os [primeiros 4 bits][bitstring-matching] da [bitstring][bitstring] e constrói recursivamente a [charlist][charlist] resultante.
- As funções recursivas de cauda precisam de um acumulador.
- Lembra-te de que a [forma especial de bitstring][bitstring-form] pode ser usada para fazer correspondência com bitstrings.
- Não te esqueças de especificar os tipos dos segmentos da bitstring com o operador `::`.
- Vais precisar de inverter o acumulador no fim. Escreve uma função `reverse` privada e recursiva de cauda para o fazer e usa-a no caso base da função `decode`.
