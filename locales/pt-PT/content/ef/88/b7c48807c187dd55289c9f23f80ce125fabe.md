# Anexo às instruções

## Dicas

Para completares este exercício, tens de criar o tipo de dados `LinkedList`
e implementar as seguintes funções:

- `datum`
- `fromList`
- `isNil`
- `new`
- `next`
- `nil`
- `reverseLinkedList`
- `toList`

Encontras uma declaração de dados de exemplo e as assinaturas de tipo já no código,
mas és tu que tens de definir as funções e criar um tipo de dados com significado,
um newtype ou um sinónimo de tipo.
