# Sobre

Em Common Lisp, tudo é uma expressão.
Uma expressão é ou uma coisa única (a que se chama átomo) ou uma lista de coisas (delimitada por parênteses: `()`).

## Citação

Todas as S-expressões, tal como os símbolos, podem ser citadas:

```lisp
;; This line is evaluated as code
(gimme-foo)  ; => FOO

;; This line is treated as data
'(gimme-foo) ; => (GIMME-FOO)
```

Esta citação impede a avaliação de uma S-expressão, tratando-a antes como dados.
Aqui está uma excelente [resposta no Stack Overflow][so-quoting] que aborda a citação com um pouco mais de detalhe.

[so-quoting]: https://stackoverflow.com/questions/134887/when-to-use-or-quote-in-lisp
