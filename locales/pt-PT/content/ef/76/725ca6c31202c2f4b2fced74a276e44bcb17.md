# Instruções adicionais

## Instruções específicas deste track

Historicamente, o Elm usava programação reativa funcional até se especializar no uso da Arquitetura Elm.

Resolve este exercício como se estivesses a escrever uma aplicação web com a Arquitetura Elm.
O resultado do programa deve ser HTML com a seguinte estrutura

```html
<div>
  <dl>
    <dt>State</dt>
    <dd>Ongoing</dd>
    <dt>Word</dt>
    <dd>______</dd>
    <dt>Remaining failures</dt>
    <dd>5</dd>
  </dl>
</div>
```

em que `<dl>` é o elemento de lista de descrição, `<dt>` o elemento de termo de descrição e `<dd>` o elemento de detalhes de descrição, todos elementos HTML padrão.

Se houver um erro, o resultado deve ter a seguinte estrutura

```html
<div>
  <p>error message</p>
</div>
```
