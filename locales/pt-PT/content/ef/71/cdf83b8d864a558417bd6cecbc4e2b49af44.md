# Debug

Como o test-runner atual usa o [PonyTest](https://stdlib.ponylang.io/pony_test--index/), o ator Main está em test.pony e não deve ser editado como parte da tua solução.

Como é boa prática nas aplicações Pony, não damos acesso a `Env` a não ser que seja necessário. Isto significa que, em quase todos os casos, não consegues usar depuração ao estilo printf com `env.out.print()`.

No entanto, o Pony tem um módulo [debug](https://stdlib.ponylang.io/debug--index/) que permite que os programas compilados com a flag `-d` tenham acesso especial a STDOUT e STDERR sem acesso a `Env`.

Se precisares de depuração ao estilo printf, deves usar esta funcionalidade.

Exemplo de depuração:

```pony
use "debug"

actor Main
  new create(env: Env) =>
    MySolution.examplefn("First String", 42)

primitive MySolution
  fun examplefn(arg1: String, arg2: USize) =>
    Debug.out("arg1: " + arg1 + ", arg2: " + arg2.string() + " were provided to MySolution.examplefn()")
```
