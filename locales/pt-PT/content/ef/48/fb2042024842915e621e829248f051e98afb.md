## Pares

Um `Pair` é uma estrutura de dados que contém exatamente dois elementos acessíveis através dos campos `first` e `second`.

Podem ser construídos com `x => y`:

```julia-repl
julia> p = 3 => true
3 => true

julia> p.first
3

julia> p.second
true
```

Os elementos de um `Pair` podem ser de tipos diferentes:

```julia-repl
julia> typeof(p)
Pair{Int64,Bool}
```

Os `Pair` têm duas utilizações comuns em Julia: dicionários e substituições.

### Substituições

Muitos métodos de substituição recebem um `Pair` como argumento, para deixar claro qual é o elemento que está a ser substituído.
Isso permite uma sintaxe como

```julia-repl
julia> replace!([1, 3, 4, 1], 4 => 0)
4-element Array{Int64,1}:
 1
 3
 0
 1
```

em que cada `4` da coleção é substituído por `0`, em vez da sintaxe menos clara

```julia
replace!([1, 3, 4, 1], 4, 0) # this method doesn't exist
```
