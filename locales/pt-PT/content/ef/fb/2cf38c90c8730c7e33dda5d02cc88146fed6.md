# Introdução

As exceções em C# proporcionam uma forma estruturada, uniforme e segura em termos de tipos de tratar as condições de erro que ocorrem em tempo de execução. Um tratamento adequado de exceções e erros é importante para evitar que a aplicação vá abaixo.

Em C#, todas as exceções têm a classe `System.Exception` como tipo base. Contém propriedades importantes, como `Message`, que contém uma descrição legível do motivo pelo qual a exceção foi lançada.

Para assinalar que deve haver um erro numa determinada parte do código, é preciso criar um novo objeto de exceção e lançá-lo, com a palavra-chave `throw`:

```csharp
using System;
static int Square(int number)
{
    if (number >= 46341)
    {
        throw new ArgumentException($"Argument {number} cannot be higher than 46340 as its' square doesn't fit into int type.");
    }
    return number * number;
}
```

Quando uma exceção é lançada, o runtime tem a tarefa de encontrar o código responsável por tratar essa exceção. Se não encontrar nenhum código de tratamento adequado, o runtime apresenta a mensagem de exceção não tratada, para além de interromper a execução do programa.

Para tratar uma exceção, o C# usa a instrução try-catch, composta por um bloco `try` e uma ou mais cláusulas `catch`. O bloco `try` deve conter e proteger o código que pode levar ao lançamento da exceção. As cláusulas `catch` devem conter o código que define o comportamento do programa depois de o erro acontecer. Convém notar que a ordem das exceções a seguir ao bloco `try` faz diferença: quando estão listadas várias exceções, é executada a primeira cláusula `catch` que corresponda.

```csharp
try
{
   if (number == 42)
   {
       throw new ArgumentException("The number cannot be equal to 42.", "number");
   }

   if (number < 0)
   {
      throw new ArgumentOutOfRangeException("number", "The number cannot be negative.");
   }

    // Process number ...
}
catch (ArgumentOutOfRangeException e)
{
    Console.WriteLine($"Number is out of range: {e.Message}.");
}
catch (ArgumentException)
{
    Console.WriteLine("Invalid number.");
}
```
