# Bools

Crystal tem um tipo conhecido como [`Bool`][bools].
Representa os valores `true` e `false`.

## Operadores lógicos

Crystal tem três operadores lógicos (`!`, `||`, `&&`) que combinam Bools e formam expressões que produzem valores diferentes.

### And(`&&`)

O [operador _and_][and] em Crystal é representado por `&&` e devolve `true` se ambos os valores forem `true`; caso contrário, devolve `false`.
Quando usas o operador _and_, colocas um Bool à direita do `&&` e outro à esquerda.

```crystal
true && true
# => true

true && false
# => false
```

### Or(`||`)

O [operador _or_][or] em Crystal é representado por `||` e devolve `true` se **pelo menos um** dos valores dados for `true`.
Se ambos os valores forem `false`, devolve `false`.
Quando usas o operador _or_, deves colocar um Bool à direita do `||` e outro à esquerda.

```crystal
true || true
# => true

true || false
# => true

false || false
# => false
```

### Not(`!`)

O operador _not_ em Crystal é representado por `!` e devolve `true` se o Bool dado for `false` e devolve `false` se lhe for fornecido `true`.
Quando usas o operador _not_, deves colocar um Bool depois do operador (`!`).

```crystal
!true
# => false

!false
# => true
```

## Usar parênteses(`()`)

Quando trabalhas com Boolean, podes usar parênteses para decidir que Bools são avaliados primeiro.
O resultado pode ser diferente consoante a forma como usas os parênteses.
Em Crystal, o que está entre parênteses é avaliado primeiro.

```crystal
true && false && false || true
# => true

true && false && (false || true)
# => false
```

Como o que está entre parênteses é avaliado primeiro, no exemplo seguinte o operador _not_ aplica-se à expressão dentro dos parênteses.

```crystal
!true && false
# => false

!(true && false)
# => true
```

~~~~exercism/note
Só deves usar parênteses quando estes afetam o resultado; caso contrário, deves omiti-los.
~~~~

## Truthy e falsey

Em Crystal, os valores "falsey" são: `false`, `nil` e ponteiros nulos; **todo o resto** é "truthy".
Estes valores podem ser usados com os operadores lógicos mencionados acima.

```crystal

true && nil
# => false

false && 4
# => false

true || nil
# => true
```

## Convenções de nomenclatura de métodos com Boolean

Em Crystal, é comum dar ao nome de um método que devolve um valor truthy ou falsey um ponto de interrogação (`?`).
Na maioria dos casos, este método devolve um valor Bool, mas não tem de ser assim.
Isto significa que o método pode ser usado em locais onde se espera um valor truthy ou falsey, por exemplo, como condição de uma condicional `if`:

```crystal
def exchange(value)
    if value.nil?
        value = 5
    end
    value
end

exchange(10)
# => 10

exchange(nil)
# => 5
```

Os métodos com um ponto de interrogação no fim do nome que não devolvem um valor Bool devolvem muitas vezes `nil`.
O `nil` é _semelhante ao `None` ou ao `null` de outras linguagens_.
