# Introdução

## Comparações

Em C++, podes comparar valores usando os operadores de comparação.

| Comparação        | Operador  |
| ------------------| --------- |
| igual             | `==`      |
| não igual         | `!=`      |
| menor             | `<`       |
| menor ou igual    | `<=`      |
| maior             | `>`       |
| maior ou igual    | `>=`      |

O resultado destas comparações é sempre um valor booleano:

```cpp
int a{3};

bool eq1 = a != 4; // true

bool eq2 = a > 5;  // false
```

Os operadores `==` e `!=` verificam, respetivamente, se um valor é igual a outro ou não.
Aqui estão alguns exemplos comuns:

```cpp
bool eq3 = 2 == 3; // false, integer comparison

bool eq4 = 2.1 != 2.2; // true, float comparison

bool eq5 = "hello" == "hello"; // true, string comparison
```

Os outros operadores verificam se um valor é maior que (`>`), maior ou igual a (`>=`), menor que (`<`) ou menor ou igual a (`<=`) outro valor.
Este tipo de comparação está disponível para números e strings.
Ao comparar strings, segue-se a ordem de dicionário (também conhecida como ordem lexicográfica).

```cpp
bool eq6 = 2 > 3; // false, integer comparison

bool eq7 = 1.2 < 1.3; // true, float comparison

bool eq8 = "Hello" < "World"; // true, string comparison
```

## Condicionais if

Os condicionais em C++ são semelhantes aos condicionais de outras linguagens.
O tipo subjacente de qualquer operação condicional é o tipo `bool`, que pode ter o valor `true` ou `false`.
Os condicionais são frequentemente usados como mecanismos de controlo de fluxo para verificar várias condições.

Pode usar-se um condicional `if`, que executa o seu código se a condição subjacente for `true`, assim:

```cpp
std::string value{"val"};

if (value == "val") {
    return "was val";
}
```

Em cenários com mais do que um caso, podem encadear-se vários condicionais `if` usando as instruções `else if` e `else`.

```cpp
int number{33};

if (number > 0) {
   return "positive";
} else if (number < 0) {
    return "negative";
} else {
   return "zero";
}
```

Desde o C++17, os condicionais `if` também podem incluir uma pequena instrução de inicialização, que pode ser usada para inicializar uma ou mais variáveis para o condicional `if`.
Por exemplo:

```cpp
int num{7};
if (int v{2 * num}; v > 10) {
    return v;
} else {
    return num;
}
// => 14
```

> Nota: as variáveis criadas na inicialização não podem ser acedidas depois do fim do condicional if.
