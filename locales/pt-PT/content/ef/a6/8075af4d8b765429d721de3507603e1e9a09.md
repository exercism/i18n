# Resolver exercícios com o editor online

Resolver exercícios online com o editor online do site permite-te começar rapidamente num percurso.
Com o editor online, não precisas de instalar nada na tua máquina local; tudo funciona no navegador (incluindo correr os testes).

## Resolver o exercício

O objetivo de cada exercício é criar uma implementação que passe em todos os testes.
Essa implementação é conhecida como uma _solução_.

Para começares, vai ao site, junta-te a um percurso e vai à página do exercício.
Aí, podes clicar no botão "Abrir no editor".
Isto vai abrir o editor online, que mostra as seguintes informações:

- O lado esquerdo contém o editor onde vais programar a tua solução
- O lado direito contém as instruções que explicam o que se espera de ti

Depois, podes começar a programar a tua solução.

Clicar no botão "Executar os testes" verifica se a tua solução passa nos testes do exercício.
Assim que os testes forem executados, os resultados dos testes são apresentados à direita.

### Depuração

O editor online não tem um depurador integrado.
Alguns percursos suportam depuração baseada em impressão, em que o teu código pode produzir texto que é apresentado nos resultados.
Se um percurso suportar isto, as instruções sobre como usar esta funcionalidade são mostradas no lado direito.

## Submeter a tua solução

Assim que a tua solução passar em todos os testes, podes submetê-la com o botão "Submeter".
