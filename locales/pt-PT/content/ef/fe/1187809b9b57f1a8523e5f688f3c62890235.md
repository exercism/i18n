# Introdução

O Swift disponibiliza um tipo incorporado chamado [`Bool`][bools] para representar valores de verdade: `true` e `false`.

## Operadores lógicos

O Swift disponibiliza três [operadores lógicos][logical-operators] (`!`, `&&` e `||`) para combinar e avaliar expressões do tipo Boolean.

### AND lógico (`&&`)

O [operador _and_][and] (`&&`) devolve `true` apenas se ambos os operandos forem `true`.
Se um dos operandos for `false`, devolve `false`.
Coloca uma expressão ou um valor do tipo Boolean de cada lado do símbolo `&&`:

```swift
true && true  // true
true && false // false
```

### OR lógico (`||`)

O [operador _or_][or] (`||`) devolve `true` se **pelo menos um** dos operandos for `true`.
Só devolve `false` quando ambos os operandos são `false`.
Coloca uma expressão ou um valor do tipo Boolean de cada lado do símbolo `||`:

```swift
true || true   // true
true || false  // true
false || false // false
```

### NOT lógico (`!`)

O [operador _not_][not] (`!`) inverte um valor do tipo Boolean.
Devolve `true` se o valor for `false`, e `false` se o valor for `true`.
Coloca o operador `!` imediatamente antes do valor ou da expressão:

```swift
!true  // false
!false // true
```

## Usar parênteses (`()`)

Podes usar [parênteses][explicit-parentheses] para agrupar expressões e controlar a ordem de avaliação.
Em Swift, as expressões dentro de parênteses são avaliadas primeiro:

```swift
true && false && false || true   // true
true && false && (false || true) // false
```

O agrupamento com parênteses também determina como o operador NOT se aplica a expressões complexas:

```swift
!true && false   // false (evaluates (!true) first, then false && false)
!(true && false) // true  (evaluates (true && false) first to false, then !false)
```

~~~~exercism/note
Usa parênteses quando precisares de clarificar a ordem de avaliação ou de tornar condições complexas mais fáceis de ler.
Evita adicionar parênteses desnecessários quando a precedência predefinida já é clara.
~~~~
