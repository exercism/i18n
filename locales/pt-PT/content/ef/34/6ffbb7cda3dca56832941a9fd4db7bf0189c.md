# Introdução

## `Base.@kwdef`

A macro `Base.@kwdef` pode ser usada para definir automaticamente construtores que recebem argumentos de palavra-chave para a definição de uma [struct][struct].
Permite também definir valores predefinidos para os campos.

Por exemplo, a seguinte definição

```julia
Base.@kwdef struct HumanStats
    birthyear::Int
    height::Int
    mass::Int
    bmi::Float64 = mass / (0.01 * height)^2
end
```

define três construtores de uma só vez

```julia-repl
julia> methods(HumanStats)
# 3 methods for type constructor:
[1] HumanStats(; birthyear, height, mass, bmi) [...]
[2] HumanStats(birthyear::Int64, height::Int64, mass::Int64, bmi::Float64) [...]
[3] HumanStats(birthyear, height, mass, bmi) [...]
```

incluindo um construtor baseado em argumentos de palavra-chave

```julia-repl
julia> HumanStats(
           birthyear = 2002,
           height = 193,
           mass = 83
       )
HumanStats(2002, 193, 83, 22.28247738194314)
```

ao passo que a definição normal

```julia
struct HumanStats
    birthyear::Int
    height::Int
    mass::Int
    bmi::Float64
end
```

só define os dois seguintes

```julia-repl
julia> methods(HumanStats)
# 2 methods for type constructor:
[1] HumanStats(birthyear::Int64, height::Int64, mass::Int64, bmi::Float64) [...]
[2] HumanStats(birthyear, height, mass, bmi) [...]
```

e exigiria definir manualmente um construtor baseado em argumentos de palavra-chave.

### Quando usar `Base.@kwdef`?

Os construtores baseados em argumentos de palavra-chave são especialmente úteis para construir structs que recebem um grande número de argumentos, em particular quando o tipo ou o valor dos argumentos não se relaciona diretamente com o significado dos argumentos.

Repara na seguinte definição:

```julia
dirk = BasketballPlayer(1978, 1994, 2019, 213, 111, 42, 1998, [2011], 31560, 11489, 3651)
```

Não é claro o que cada valor significa sem conheceres a definição do tipo.
E mesmo que conheças a definição, provavelmente terias de consultar a ordem vezes sem conta.

No entanto, ao usares um construtor baseado em argumentos de palavra-chave, o significado deles torna-se imediatamente óbvio:

```julia
dirk = BasketballPlayer(
    birthyear = 1978,
    career_start = 1994,
    career_end = 2019,
    height = 213,
    weight = 111,
    number = 42,
    drafted = 1998,
    championships = [2011],
    points = 31560,
    rebounds = 11489,
    assists = 3651
)
```

~~~~exercism/caution
O `Base.@kwdef` não é exportado nem está documentado no manual e, por isso, não faz parte da [API pública do Julia][public-api].
Isto significa que a sua interface não tem, tecnicamente, garantia de estabilidade e pode mudar entre versões secundárias do Julia.

No entanto, a macro é amplamente utilizada em todo o ecossistema e é pouco provável que venha a ser alterada de forma incompatível.

Para mais informações, consulta:

- ["What does `@kwdef` do?"][discourse-kwdef]
- [Issue #32659 do Julia para adicionar o `@kwdef` ao Manual][add-kwdef-to-manual]
- [Issue #33192 do Julia para exportar o `@kwdef`][export-kwdef]

~~~~
