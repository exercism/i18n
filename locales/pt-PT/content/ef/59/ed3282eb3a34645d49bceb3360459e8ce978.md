## Ferramentas interativas de jq

Fornece alguns dados de entrada e experimenta vários filtros do jq para ver o que se consegue.

- [jq playground][jqplay], uma experiência de "experimentar online". 
- [ijq][ijq], ferramenta interativa de jq, como o jqplay para a linha de comandos.
- [jqp][jqp] é outra ferramenta de linha de comandos: usa o gojq como backend, que não é 100% compatível com o jq original.

## Outras ferramentas de processamento de JSON

- [gron][gron]: "achata" o JSON numa sequência de atribuições individuais, o que torna possível usar ferramentas orientadas a linhas (grep, etc.) para o processar.
- [jo][jo]: um pequeno utilitário para criar objetos JSON a partir de variáveis de shell.
- [jello][jello]: o jello é semelhante ao jq, com a diferença de que usa a sintaxe padrão de dicionários e listas do Python.
