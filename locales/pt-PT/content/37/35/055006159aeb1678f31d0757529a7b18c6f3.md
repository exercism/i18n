# Sobre

[Tuplos][tuple] são frequentemente usados para agrupar informação. Diferem das listas por terem tamanho fixo e poderem conter diferentes tipos de dados.
Os tuplos são criados com parênteses, `()`, e são frequentemente usados para devolver vários valores a partir de uma função.

```haskell
tuple = (1, "abc", False)
```

Isto pode ser útil quando, por exemplo, queres guardar uma coordenada num espaço 2D. Nesse caso, sabes que o tuplo terá sempre dois elementos, as coordenadas x e y.

```haskell
coordinate = (3, 4)
```

## Acesso aos elementos

Muitas vezes trabalhas com tuplos curtos e podes aceder aos elementos com as funções `fst` e `snd`.

```haskell
x = fst coordinate
-- x = 3
y = snd coordinate
-- y = 4
```

[tuple]: https://hackage.haskell.org/package/base/docs/Data-Tuple.html
