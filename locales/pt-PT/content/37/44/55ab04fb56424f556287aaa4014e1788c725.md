# Instruções adicionais

## Instruções específicas do track

Eis o que precisas de saber sobre o formato dos dados de entrada:

- **Argumento esquerdo**: o nome do planeta, fornecido como uma string.
- **Argumento direito**: a idade em segundos, fornecida como um número inteiro.

A tua função vai ser chamada com estes argumentos desta forma:

```j
  planet  =. 'Earth'
  seconds =. 1000000000
  
  planet age seconds
```
