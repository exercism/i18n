# Realce de sintaxe

Há dois tipos de realce de sintaxe no site:

1. Realce de código _estático_ (trechos de código, iterações e afins).
   Consulta a [documentação sobre o realce de sintaxe estático](/docs/building/tracks/new/syntax-highlighting/static) para mais informações.
2. Realce de código _dinâmico_ (o editor online).
   Consulta a [documentação sobre o realce de sintaxe dinâmico](/docs/building/tracks/new/syntax-highlighting/dynamic) para mais informações.

```exercism/note
Os requisitos para o realce de sintaxe estático e dinâmico são _muito_ diferentes, razão pela qual usam bibliotecas diferentes.
```
