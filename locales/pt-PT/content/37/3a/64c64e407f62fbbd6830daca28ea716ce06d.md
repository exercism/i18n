## Closures à direita

O Swift oferece outra variação da sua sintaxe quando se trabalha com closures, conhecida como [closures à direita][trailing-closures]. As closures à direita surgem quando o último parâmetro na lista de parâmetros de uma função tem um tipo de função. Neste caso, se estivermos a passar uma closure, a closure pode ser escrita _depois_ do parêntese de fecho e o rótulo do argumento é omitido. Repara que se houver apenas um parâmetro para a função, os parênteses podem ser omitidos por completo.

```swift
func fetchURL(_ urlString: String,
              uponReceipt handleResult: (String) -> ()
             )  -> () {
  if let url = URL(string: urlString), let htmlString = fetch(url) {
    handleResult(htmlString)
  }
}

fetchURL("https://www.swift.org") { print($0) }
// prints the fetched html string

["apple", "ball", "carrot"].sorted { $0.count < $1.count }
```

## Múltiplas closures à direita

Embora as versões anteriores do Swift só suportassem o uso de uma única closure à direita, a partir da versão 5.2.4, o Swift oferece suporte para múltiplas closures à direita.

Se uma função tiver mais do que uma closure no fim da sua lista de parâmetros, a sintaxe de closures à direita pode ser usada para mover todas elas para fora dos parênteses. No entanto, apenas o primeiro rótulo do argumento é omitido, os restantes têm de ser rotulados:

```swift
func fetchURL(_ urlString: String,
              uponReceipt handleResult: (String) -> (),
              onFailure handleFailure: () -> ()
             )  -> () {
  if let url = URL(string: urlString), let htmlString = fetch(url) {
    handleResult(htmlString)
  } else {
    handleFailure()
  }
}

fetchURL("https://www.swift.org") {
  print($0)
} onFailure: {
  print("Error: https://www.swift.org could not be fetched")
}
// prints the fetched html string on successful fetch or prints error message on failure
```
