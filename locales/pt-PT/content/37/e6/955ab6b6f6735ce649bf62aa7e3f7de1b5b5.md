# Dicas

## 1. Verifica se a ação 'Ataque Rápido' é possível

- O operador lógico NOT (`not`) pode ser colocado antes de uma expressão para negar o seu valor.

## 2. Verifica se a ação 'Aproximar e Espiar' é possível

- As expressões lógicas são avaliadas da esquerda para a direita e testadas quanto a possíveis 'curto-circuitos'.

## 3. Verifica se a ação 'Sinalizar o Prisioneiro' é possível

- Os operadores lógicos, por ordem de precedência (do mais alto para o mais baixo): `not`, `&&`, `||`.
