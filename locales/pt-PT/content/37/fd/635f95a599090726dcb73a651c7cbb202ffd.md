# Anexo às instruções

## Imprimir a árvore

Este exercício tem alguns métodos de classe predefinidos que ajudam a imprimir a árvore num formato agradável.
O seu principal objetivo é ajudar a fazer debug e dar mais clareza.
Se implementares o resto da classe corretamente, deve imprimir a árvore por ti.

```powershell
.Example
$tree = [BinarySearchTree]::new(@(50, 76, 1, 34, 89, 44, 25, 6, 26, 100, 13))
$tree.ToString()

Return:
@"
50
├──L:1
│   └──R:34
│       ├──L:25
│       │   ├──L:6
│       │   │   └──R:13    
│       │   └──R:26        
│       └──R:44
└──R:76
    └──R:89
        └──R:100
"@
```
