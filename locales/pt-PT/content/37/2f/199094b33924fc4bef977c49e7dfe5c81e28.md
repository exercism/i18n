# Instruções

Olá, Agente Double-Null0111.

A tua missão, caso decidas aceitá-la, é escrever um par de ferramentas para te ajudar a infiltrar-te no quartel-general da UMBRA (United Minions Being Really Awful) e recuperar os planos do seu mais recente e autenticamente terrível esquema.
Vais precisar de três ferramentas para levar a cabo esta missão.

## 1. Gera um número de identificação

Cada capanga tem um identificador único que muda todos os dias e depende do número de segredos que guarda e do número de horas que dorme.
Vais precisar de escrever uma função que recebe o dia (como um `Int`) e cria uma função geradora de identificadores para esse dia.
A função geradora de identificadores recebe dois parâmetros:

1. o número de segredos guardados
2. o número de horas que o capanga dorme

O identificador é calculado assim:

1. multiplica o número de segredos guardados pelo número de horas que dorme
2. soma o dia (representado como um `Int`) ao resultado

```kotlin
val idGenerator = makeIdGenerator(4)
idGenerator(3, 6)
// => 22

idGenerator(11, 5)
//  => 59
```

## 2. Protege os planos secretos recuperados com uma palavra-passe secreta

Depois de teres os planos secretos, vais precisar de os proteger para que só quem souber a palavra-passe os possa recuperar.
Para isso, vais precisar de implementar a função `protectSecret(secret: String, password: String) : (String) -> String`.
Esta função devolve outra função que recebe possíveis palavras-passe como valor de entrada.
Se a palavra-passe introduzida estiver correta, a nova função devolve o segredo escondido; mas se a palavra-passe estiver incorreta, a função devolve "Sorry. No hidden secrets here."

```kotlin
val secretFunction = protectSecret("Steal the world's supply of french fries!", "5up3r53cr37")

secretFunction("Open sesame")
// Returns "Sorry. No hidden secrets here."

secretFunction("5up3r53cr37")
// Returns "Steal the world's supply of french fries!"
```

## 3. Descobre a palavra-passe secreta

A base da UMBRA tem várias salas guardadas por um segurança que te vai pedir a palavra-passe secreta.
A palavra-passe secreta depende do número da sala.
Infelizmente, só conhecemos metade do algoritmo para calcular a palavra-passe.
A outra metade pode ser obtida perguntando a um dos capangas.

Implementa a função `getPassword` que recebe o seguinte e devolve a palavra-passe:

1. o número da sala
2. a função do capanga, e devolve a palavra-passe secreta

A palavra-passe secreta obtém-se chamando a função do capanga com outra função que representa o algoritmo que nós conhecemos.
A nossa parte do algoritmo:

1. recebe dois números e soma-os
2. multiplica o resultado pelo id da sala

```kotlin
val minionFunction = { yourFunc : (Int, Int) -> Int ->
    "Password=${yourFunc(1, 3)}"
}

getPassword(5, minionFunction)
// Returns "Password=20"
```
