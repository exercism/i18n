# Introdução

Em programação, é essencial tratar os erros de forma adequada para garantir que situações inesperadas não façam um programa terminar de forma inesperada nem comportar-se de forma imprevisível.
O Cairo disponibiliza dois mecanismos principais para tratar erros:

1. **Erros irrecuperáveis** com `panic`, que param o programa imediatamente.
2. **Erros recuperáveis** com `Result`, que permitem que o programa trate os erros e reaja a eles.

## Erros irrecuperáveis com `panic`

Às vezes, um programa depara-se com um erro tão grave que não consegue continuar.
Nesses casos, o Cairo usa a função `panic` para parar a execução imediatamente.
Isto é útil quando um erro, como tentar aceder a um índice fora dos limites, torna impossível que o programa continue de forma sensata.
A função `panic` aceita uma mensagem do tipo `ByteArray` que descreve o motivo do erro.

Por exemplo, em Cairo:

```rust
fn main() {
    let data = array![1, 2];
    panic("An unrecoverable error has occurred!");
}
```

Este exemplo demonstra um panic forçado, que para o programa imediatamente com uma mensagem.

### A macro `assert!`

A macro `assert!` é uma ferramenta útil para impor condições específicas no teu código.
Se a condição em `assert!` for avaliada como `false`, o programa entra em panic com uma mensagem de erro do tipo `ByteArray`.
Isto é usado frequentemente para verificar pressupostos durante o desenvolvimento e garantir que os valores cumprem determinados critérios.

Por exemplo:

```rust
fn main() {
    let x = 5;
    assert!(x > 0, "x must be greater than zero");
}
```

Se `x` não for maior do que zero, o programa entra em panic com a mensagem `"x must be greater than zero"`. A macro `assert!` é útil para verificar invariantes e pré-condições sem escreveres manualmente código de tratamento de erros.

## Erros recuperáveis com `Result`

Nem todos os erros precisam de parar o programa.
Alguns podem ser tratados de forma adequada para que o programa possa continuar.
O enum `Result` do Cairo representa estes erros recuperáveis e tem duas variantes:

- `Result::Ok` indica sucesso.
- `Result::Err` representa um erro.

Com o `Result`, uma função pode devolver um valor de sucesso ou um erro, o que permite à função que a chamou decidir o que fazer a seguir.

```rust
fn divide(a: u32, b: u32) -> Result<u32, ByteArray> {
    if b == 0 {
        Result::Err("Error: Division by zero")
    } else {
        Result::Ok(a / b)
    }
}
```

Neste exemplo, se `b` for zero, é devolvido um erro; caso contrário, é devolvido o resultado da divisão.
