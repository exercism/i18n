# Strings

O Crystal tem um tipo conhecido como [`String`][strings], que serve para representar texto.
As strings do Crystal são sequências de carateres Unicode.
As strings são imutáveis, ou seja, não podem ser alteradas depois de criadas.
Isto significa que é criada uma nova string sempre que modificas uma string; por isso, a string original não é modificada.

Para definir uma string usas aspas duplas `"`.

```crystal
"Hello World"
```

## Concatenação

Para concatenar duas strings, usa o operador `+`.
O operador `+` devolve uma nova string que combina as duas strings.

```crystal
hello = "Hello"
hello + " World"
# => "Hello World"
```

## Conversão entre strings e números

O método `to_i` converte uma string num número inteiro.
Em alternativa, podes usar o método `to_f` para obter um número de vírgula flutuante.
Se a string não puder ser convertida num número, é lançado um `ArgumentError`.

```crystal
"1".to_i
# => 1

"1.0".to_f
# => 1.0

"Hello".to_i
# => ArgumentError: Invalid integer: Hello
```

Um número inteiro ou de vírgula flutuante pode ser convertido numa string com o método `to_s`.

```crystal
1.to_s
# => "1"

1.0.to_s
# => "1.0"
```

## Interpolação

A interpolação é uma forma prática de combinar strings e de incorporar expressões em strings.
Para interpolar uma string, podes usar o caráter `#` seguido de chavetas `{}`, com a expressão dentro das chavetas.

```crystal
name = "World"
"Hello #{name}!"
# => "Hello World!"
```

O Crystal converte automaticamente o resultado da expressão numa string.

```crystal
"Hello #{1 + 1}!"
# => "Hello 2!"
```

## Tamanho

Quando precisas de saber o número de carateres de uma string, podes usar o método `size`, que devolve o comprimento da string como um número inteiro.
O tamanho de uma string é uma propriedade armazenada da string, por isso não é preciso calculá-lo sempre que chamas o método, o que o torna muito rápido.

```crystal
"Hello World".size
# => 11
```

## Indexação

A indexação é usada quando queres obter um caráter específico de uma string.
Para obter um caráter de uma `String`, podes usar a notação de parênteses retos que já conheces.

~~~~exercism/note
`[]` está implementado como um método de instância de String, em que o índice é o argumento do método.
~~~~

No Crystal, o primeiro caráter de uma string está no índice 0.

```crystal
"Hello World"[0]
# => 'H'

"Hello World"[6]
# => 'W'
```

Para obter um caráter do fim de uma string, podes usar o comprimento da string menos um para obter o índice do último caráter, e para obter o penúltimo caráter usas o comprimento da string menos dois, e assim sucessivamente.
Há um atalho para isto: basta usares um índice negativo, em que o último caráter está no índice -1, o penúltimo caráter no índice -2, e assim sucessivamente.

```crystal
name = "Hello World"
name[name.size - 1]
# => 'd'

name[-1]
# => 'd'
```

### Teste de substring

O Crystal permite testar se uma string contém uma substring através da indexação.
A mesma notação de parênteses retos serve para isso, mas em vez de um índice indica-se uma substring.
Se a substring existir na string, a substring é devolvida; caso contrário, é lançado um `NilAssertionError`.

```crystal
"Hello World"["Hello"]
# => "Hello"

"Hello World"["Goodbye"]
# => NilAssertionError
```

Se quiseres um valor `Bool` que indique se a substring existe, podes usar o método `includes?`.

```crystal
"Hello World".includes?("Hello")
# => true

"Hello World".includes?("Goodbye")
# => false
```

## Sequências de escape

Alguns carateres não podem ser escritos diretamente numa string; nesse caso, tens de usar uma sequência de escape.
Por exemplo, se quiseres usar aspas duplas numa string, tens de escapar as aspas duplas.
Podes usar o caráter `\` para escrever uma sequência de escape seguida do caráter que queres escapar.

Estes são os carateres especiais do Crystal:

| Valor    | Descrição                          |
| -------- | ---------------------------------- |
| `\a`     | Alerta                             |
| `\b`     | Retrocesso                         |
| `\e`     | Escape                             |
| `\f`     | Avanço de página                   |
| `\n`     | Nova linha                         |
| `\r`     | Retorno de carro                   |
| `\t`     | Tabulação horizontal               |
| `\v`     | Tabulação vertical                 |
| `\\`     | Barra invertida                    |
| `\'`     | Aspas simples                      |
| `\"`     | Aspas duplas                       |
| `\377`   | Caráter ASCII octal                |
| `\xFF`   | Caráter ASCII hexadecimal          |
| `\uFFFF` | Caráter Unicode hexadecimal        |

```crystal
puts "Hello \"World\""
# => Hello "World"

puts "Hello \nWorld"
# => Hello
# => World
```

## Strings com várias linhas

Para escrever uma string com várias linhas, usas a mesma sintaxe de uma string de uma só linha, mas mudas de linha a cada linha que queres incluir na string.

```crystal
"Hello
World"
# => "Hello\nWorld"
```

## Unicode

O [Unicode][unicode] é uma norma para codificar, representar e processar texto em diferentes sistemas de escrita.
O Unicode suporta mais de 100 000 carateres, incluindo letras, pontuação, símbolos e emojis.

Como o Crystal usa Unicode para as strings, podes, por exemplo, colocar emojis nas strings.

```crystal
"Hello 🌍"
# => "Hello 🌍"
```

Por vezes, queres usar um caráter que não está disponível, por exemplo, no teu editor ou no teu sistema.
Nesse caso, podes usar a sequência de escape Unicode para escrever o caráter.

```crystal
"\u{1F310}"
# => "🌐"
```
