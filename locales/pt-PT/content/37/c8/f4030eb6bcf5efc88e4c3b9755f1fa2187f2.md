## 1. Identifica as linhas de registo corrompidas

- Usa o [sigil `r`][sigil-r] para criar uma expressão regular.
- Existe [um operador][match-operator] que podes usar para verificar uma string em relação a uma expressão regular. Há também uma [função `Regex`][regex-match] e uma [função `String`][string-match] que fazem o mesmo.
- Não te esqueças de escapar os carateres que têm um significado especial nas expressões regulares.

## 2. Divide a linha de registo

- Existe uma [função `Regex`][regex-split], bem como uma [função `String`][string-split], que conseguem dividir uma string numa lista de strings com base numa expressão regular.
- Não te esqueças de escapar os carateres que têm um significado especial nas expressões regulares.

## 3. Remove os artefactos do registo

- Existe uma [função `Regex`][regex-replace], bem como uma [função `String`][string-replace], que conseguem substituir uma parte de uma string que corresponde a uma determinada expressão regular por outra string.
- Existe um [modificador][regex-modifiers] que faz com que toda a expressão regular não distinga maiúsculas de minúsculas.

## 4. Etiqueta as linhas com nomes de utilizador

- Existe uma [função `Regex`][regex-run] que executa uma expressão regular sobre uma string e devolve todas as capturas.
