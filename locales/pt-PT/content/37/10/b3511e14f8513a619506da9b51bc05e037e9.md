# Introdução

O Go não tem o conceito de vazio, null ou undefined para os valores das variáveis.
As variáveis declaradas sem um valor inicial explícito assumem, por omissão, o valor zero do respetivo tipo.

O valor zero dos tipos primitivos, como booleans, tipos numéricos e strings, é `false`, `0` e `""`, respetivamente.

O identificador `nil`, que significa zero, é o valor zero de tipos mais complexos, como ponteiros, funções, interfaces, slices, canais e mapas.

A tabela seguinte detalha o valor zero dos tipos de Go.

| Tipo      | Valor zero |
| --------- | ---------- |
| boolean   | `false`    |
| numérico  | `0`        |
| string    | `""`       |
| ponteiro  | `nil`      |
| função    | `nil`      |
| interface | `nil`      |
| slice     | `nil`      |
| canal     | `nil`      |
| mapa      | `nil`      |

Talvez tenhas reparado que os tipos struct não aparecem na tabela acima.
Isso acontece porque o valor zero de um tipo struct depende dos seus campos.
Uma struct fica com o valor zero quando todos os seus campos ficam com o respetivo valor zero.
