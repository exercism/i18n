# Instruções

A tua tarefa é determinar o que vais dizer quando ofereceres a bolacha extra.

Se o teu amigo gosta de bolachas e se chama Do-yun, vais dizer:

```text
One for Do-yun, one for me.
```

Se o teu amigo não gosta de bolachas, dás a bolacha à pessoa seguinte na fila da pastelaria.
Como não sabes o nome dela, dizes _you_ em vez do nome.

```text
One for you, one for me.
```

Aqui tens alguns exemplos:

| Nome   | Diálogo                     |
| :----- | :-------------------------- |
| Alice  | One for Alice, one for me.  |
| Bohdan | One for Bohdan, one for me. |
|        | One for you, one for me.    |
| Zaphod | One for Zaphod, one for me. |
