# Introdução

Em Cairo, não existe um tipo nativo para strings.
Em vez disso, podes usar um único `felt252` para guardar uma string curta com até 31 carateres, ou um `ByteArray` para strings de comprimento arbitrário.
As strings curtas usam aspas simples e o `ByteArray` usa aspas duplas.
Todos os carateres têm de seguir o padrão ASCII.
