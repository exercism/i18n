# Introdução

## Explicação

Para além dos tipos de dados primitivos como `number` e `string`, existe em JavaScript outro tipo de dados importante chamado `object`.
Os objetos são coleções de pares chave-valor.
Como tal, podem ser usados da mesma forma que aquilo a que noutras linguagens se chama muitas vezes mapas ou dicionários.

Noutras linguagens, todos os valores de um mapa têm frequentemente de ter o mesmo tipo de dados.
Em JavaScript, só o tipo da chave está restringido: tem de ser uma `string`.
Os valores dentro de um mesmo objeto podem ter tipos diferentes.
Podem ser tipos primitivos como números, mas também arrays, outros objetos ou até funções.
Isto torna os objetos muito versáteis, ao ponto de serem também entidades centrais para a [programação orientada a objetos][oop] (POO) em JavaScript.

A seguir, vamos focar-nos nos objetos enquanto coleções ou mapas.
Outros casos de uso dos objetos serão abordados noutros conceitos, vê por exemplo [Classes][concept-classes].

## Criar um objeto

Crias um objeto com chavetas.
Também podes incluir algumas entradas diretamente.
Para isso, indica primeiro a chave, seguida de dois pontos e do valor.

```javascript
const emptyObject = {};

const obj = {
  favoriteNumber: 42,
  greeting: 'Hello World',
  useGreeting: true,
  address: {
    street: 'Trincomalee Highway',
    city: 'Batticaloa',
  },
  fruits: ['melon', 'papaya'],
  addNumbers: function (a, b) {
    return a + b;
  },
};
```

A vírgula final depois da última entrada é opcional em JavaScript.

Podes perguntar-te porque é que as chaves não estão entre aspas, apesar de se supor que são strings.
É uma notação abreviada.
Se a chave seguir as regras de nomenclatura de um [identificador][mdn-identifier] de JavaScript, podes omitir as aspas.
Para chaves com carateres especiais no nome, tens de usar a notação habitual de strings.

```javascript
const obj = {
  '1keyStartsWithNumber': '...',
  'key/with/slashes': '...',
  'key-with-dashes': '...',
  'key with spaces': '...',
  '#&()[]{}èä樹keyWithSpecialChars': '...',
};
```

## Obter um valor

Há duas formas de obter o valor de uma determinada chave: a notação de ponto e a notação de parênteses retos.

```javascript
const obj = { greeting: 'hello world' };

obj.greeting;
// => hello world

obj['greeting'];
// => hello world

// Bracket notation also works with variables.
const key = 'greeting';
obj[key];
// => hello world
```

Usar a notação de ponto como forma abreviada tem a mesma restrição que omitir as aspas.
Só funciona se a chave seguir as regras de nomenclatura de identificadores.

## Adicionar ou alterar um valor

Podes adicionar ou alterar um valor com o operador de atribuição `=`.
Mais uma vez, tens à disposição a notação de ponto e a notação de parênteses retos.

```javascript
const obj = { greeting: 'hello world' };

obj.greeting = 'Hi there!';
obj['greeting'] = 'Welcome.';

obj.newKey1 = 'new value 1';
obj['new key 2'] = 'new value 2';

const key = 'new key 3';
obj[key] = 'new value 3';
```

## Eliminar uma entrada

Podes eliminar um par chave-valor de um objeto com a palavra-chave `delete`.

```javascript
const obj = {
  key1: 'value1',
  key2: 'value2',
};

delete obj.key1;
delete obj['key2'];
```

## Verificar se uma chave existe

Podes verificar se uma determinada chave existe num objeto com o método `hasOwnProperty`.

```javascript
const obj = { greeting: 'hello world' };

obj.hasOwnProperty('greeting');
// => true

obj.hasOwnProperty('age');
// => false
```

## Percorrer um objeto com um ciclo

Existe um ciclo especial `for...in` para iterar sobre todas as chaves de um objeto.

```javascript
const obj = {
  name: 'Ali',
  age: 65,
};

for (let key in obj) {
  console.log(key, obj[key]);
}
// name Ali
// age 65
```

Para evitares erros subtis, deves assumir sempre que o ciclo `for...in` visita as chaves por uma ordem arbitrária.
Além disso, tem em atenção que o `for...in` inclui [chaves herdadas][concept-inheritance] na sua iteração.
