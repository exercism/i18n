# Sobre os Ciclos For-Each

O [ciclo for-each](https://docs.oracle.com/javase/tutorial/java/nutsandbolts/for.html) fornece um mecanismo para executar um bloco de código para cada elemento de uma coleção.
Alguma documentação (por exemplo, a documentação da Oracle) refere-se a estes como ciclos for melhorados.

Eis a sintaxe geral:

```java
for(declaration: collection) {
    body;
}
```

A `declaration` declara a variável usada para guardar os valores atribuídos a partir da `collection`.

A `collection` é um array ou uma coleção que contém os valores que vão ser atribuídos à variável do ciclo.

A `body` contém as instruções que vão ser executadas uma vez por cada valor da coleção.

Por exemplo:

```java
char[] vowels = {'a', 'e', 'i', 'o', 'u'};

for(char vowel: vowels) {
    System.out.println(vowel);
}
```

o que produz a seguinte saída:

```text
a
e
i
o
u
```

Em geral, um ciclo `for-each` é preferível a um ciclo `for` pelas seguintes razões:

- Um ciclo `for-each` itera garantidamente sobre _todos_ os valores.
- Um ciclo `for-each` é mais _declarativo_, ou seja, o código comunica _o que_ está a fazer, em vez de _como_ o está a fazer.
- Um ciclo `for-each` é à prova de erro, ao passo que com ciclos `for` é fácil cometer um erro de um a mais ou a menos (pensa em usar `<` em vez de `<=`).
- Um ciclo `for-each` funciona com todos os tipos de coleção, incluindo aqueles que não permitem usar um índice para aceder aos elementos (por exemplo, um `Set`).
