# Classes

As classes são uma unidade de organização de código em PHP.
O código que representa o comportamento de um item ou o comportamento de um processo pode ser agrupado numa classe.
As funções que são atribuídas a uma classe são chamadas `methods` por convenção.

```php
<?php

class Door
{
    function lock()
    {
        // ...
    }

    function unlock()
    {
        // ...
    }
}
```

As classes são instanciadas com a palavra-chave `new`. Isto aloca memória para a instância da classe e chama o método construtor da classe.
As classes instanciadas podem ser atribuídas a uma variável.
Para invocar os métodos de uma instância de classe, podemos usar o operador de acesso `->`.

```php
<?php

$a_door = new Door();
$a_door->lock();
$a_door->unlock();
```

Uma classe instanciada pode referenciar a sua própria instância usando a variável especial `$this`.
As classes também podem ter propriedades; estas funcionam como variáveis ligadas à instância do objeto da classe.
Estas propriedades podem ser referenciadas interna ou externamente.

```php
<?php

class Car
{
    public $color;

    function __construct($color)
    {
        $this->color = $color;
    }

    function getColor()
    {
        return $this->color;
    }
}

$a_car = new Car("red");
$a_car->color; // => "red" by accessing the property
$a_car->getColor(); // => "red" by invoking the instance method
```
