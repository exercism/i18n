# Testes

## Correr os testes

Para correr os testes, executa o seguinte comando:

```bash
bats test-<exercise-slug>.bats
```

### O bats é implementado em bash

O ficheiro do bats é um script de bash, com algumas funções especiais reconhecidas pelo comando `bats`.
Vais ver alguns testes com este aspeto:

```bash
sed -E -f <exercise-slug>.sed <<< "$input"
```

Essa sintaxe `<<<` é uma *Here String* do bash.
Envia a string do lado direito para a entrada padrão do programa do lado esquerdo.
É aproximadamente o mesmo que

```bash
echo "$input" | sed -E -f <exercise-slug>.sed
```

## Testes ignorados

Resolver um exercício significa fazer com que todos os seus testes passem.
Por omissão, quando corres os testes, só um teste (o primeiro) é executado.
Isto é intencional: permite-te concentrares-te apenas em fazer passar esse teste.
Assim que passar, podes ativar o próximo teste comentando ou removendo as

    [[ $BATS_RUN_SKIPPED == true ]] || skip

anotações que precedem os outros testes.

## Contornar os testes ignorados

Para correr todos os testes, incluindo os que têm anotações `skip`, podes usar:

```bash
BATS_RUN_SKIPPED=true bats test-<exercise-slug>.bats
```

ou então podes comentar ou eliminar a linha:

```bash
[[ $BATS_RUN_SKIPPED == "true" ]] || skip
```

do ficheiro de testes.
