# Sobre

As strings de F# são objetos imutáveis que representam texto como uma sequência de carateres Unicode (letras, algarismos, pontuação, etc.). Usam-se aspas duplas para definir uma instância de `string`:

```fsharp
let fruit = "Apple"
```

Podes manipular uma string chamando um dos seus [métodos][methods] ou [propriedades][properties], ou usando uma das funções do [módulo `String`][string-module]. Como os valores do tipo string nunca mudam depois de serem definidos, todos os métodos e funções de manipulação de strings devolvem uma nova string.

Uma string é delimitada por aspas duplas (`"`). Alguns carateres especiais precisam de [escape][escaping], usando a barra invertida (`\`). Também podes colocar o símbolo arroba (`@`) antes de uma string, o que a transforma numa [string verbatim][verbatim], que ignora qualquer escape.

```fsharp
let escaped = "c:\\test.txt"
let verbatim = @"c:\test.txt"
escaped = verbatim
// => true
```

Em alternativa, podes definir strings com [aspas triplas][triple-quoted] (`"""`), o que permite usar aspas duplas dentro da string sem as escapar.

```fsharp
let tripledQuoted = """<movie title="Se7en" />"""
// => "<movie title="Se7en" />
```

Por fim, podes concatenar strings com o [operador `+`][plus-operator]:

```fsharp
let name = "Jane"
"Hello " + name + "!"
// => "Hello Jane!"
```
