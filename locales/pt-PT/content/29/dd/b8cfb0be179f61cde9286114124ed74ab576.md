# Instruções

Neste exercício, vais implementar a lógica da missão de um novo jogo de RPG que um amigo está a desenvolver.
A personagem principal do jogo é a Annalyn, uma rapariga corajosa com um cão de estimação feroz e leal.
Infelizmente, o desastre acontece: a melhor amiga dela foi raptada enquanto procurava bagas na floresta.
A Annalyn vai tentar encontrar e libertar a melhor amiga, podendo levar o cão com ela nesta missão.

Depois de algum tempo a seguir o rasto da melhor amiga, encontra o acampamento onde ela está presa.
Acontece que há dois raptores: um cavaleiro poderoso e um arqueiro astuto.

Depois de encontrar os raptores, a Annalyn pondera quais das seguintes ações pode realizar:

- _Ataque rápido_: um ataque rápido pode ser feito se o **cavaleiro** estiver **_a dormir_**, pois ele demora tempo a vestir a armadura, o que o torna vulnerável.
- _Espiar_: o grupo pode ser espiado se **pelo menos um** deles estiver **_acordado_**. Caso contrário, espiar é uma perda de tempo.
- _Sinalizar o prisioneiro_: o prisioneiro pode ser sinalizado com sons de pássaros se o **prisioneiro** estiver **_acordado_** e o **arqueiro** estiver **_a dormir_**, pois os arqueiros são treinados em sinais com pássaros, pelo que poderiam intercetar a mensagem.
- _Libertar o prisioneiro_: a Annalyn pode tentar entrar furtivamente no acampamento para libertar o prisioneiro.
  Isto é arriscado e só pode ter sucesso de uma de duas formas:
  - Se a Annalyn tiver o cão com ela, pode resgatar o prisioneiro se o **arqueiro** estiver **_a dormir_**.
    O cavaleiro tem medo do cão e o arqueiro não terá tempo de se preparar antes de a Annalyn e o prisioneiro fugirem.
  - Se a Annalyn não tiver o cão, então ela e o prisioneiro têm de ser muito furtivos!
    A Annalyn pode libertar o prisioneiro se o **prisioneiro** estiver **_acordado_** e o **cavaleiro** e o **arqueiro** estiverem ambos **_a dormir_**, mas se o **prisioneiro** estiver **_a dormir_** não pode ser resgatado: o prisioneiro assustar-se-ia com o aparecimento súbito da Annalyn e acordaria o cavaleiro e o arqueiro.

Tens quatro tarefas: implementar a lógica que determina se as ações acima estão disponíveis, com base no estado das três personagens encontradas na floresta e na presença ou não do cão da Annalyn.

## 1. Verifica se a ação «Ataque rápido» é possível

Implementa uma função chamada `canFastAttack` que recebe um valor booleano que indica se o cavaleiro está acordado.
Esta função devolve `true` se a ação «Ataque rápido» estiver disponível, com base no estado da personagem.
Caso contrário, devolve `false`:

```php
<?php
$is_knight_awake = true;

$infiltration = new AnnalynsInfiltration();
$infiltration->canFastAttack($is_knight_awake);
// => false
```

## 2. Verifica se a ação «Espiar» é possível

Implementa uma função chamada `canSpy` que recebe três valores booleanos, que indicam se o cavaleiro, o arqueiro e o prisioneiro, respetivamente, estão acordados.
A função devolve `true` se a ação «Espiar» estiver disponível, com base no estado das personagens.
Caso contrário, devolve `false`:

```php
<?php
$is_knight_awake = false;
$is_archer_awake = true;
$is_prisoner_awake = false;

$infiltration = new AnnalynsInfiltration();
$infiltration->canSpy($is_knight_awake, $is_archer_awake, $is_prisoner_awake);
// => true
```

## 3. Verifica se a ação «Sinalizar o prisioneiro» é possível

Implementa uma função chamada `canSignal` que recebe dois valores booleanos, que indicam se o arqueiro e o prisioneiro, respetivamente, estão acordados.
A função devolve `true` se a ação «Sinalizar o prisioneiro» estiver disponível, com base no estado das personagens.
Caso contrário, devolve `false`:

```php
<?php
$is_archer_awake = false;
$is_prisoner_awake = true;

$infiltration = new AnnalynsInfiltration();
$infiltration->canSignal($is_archer_awake, $is_prisoner_awake);
// => true
```

## 4. Verifica se a ação «Libertar o prisioneiro» é possível

Implementa uma função chamada `canLiberate` que recebe quatro valores booleanos.
Os primeiros três parâmetros indicam se o cavaleiro, o arqueiro e o prisioneiro, respetivamente, estão acordados.
O último parâmetro indica se o cão da Annalyn está presente.
A função devolve `true` se a ação «Libertar o prisioneiro» estiver disponível, com base no estado das personagens e na presença do cão da Annalyn.
Caso contrário, devolve `false`:

```php
<?php
$is_knight_awake = false;
$is_archer_awake = true;
$is_prisoner_awake = false;
$is_dog_present = false;

$infiltration = new AnnalynsInfiltration();
$infiltration->canLiberate(
    $is_knight_awake,
    $is_archer_awake,
    $is_prisoner_awake,
    $is_dog_present
);
// => false
```
