# Dicas

## General

- Tenta dividir um problema num caso base e num caso recursivo. Por exemplo, imagina que queres contar quantos biscoitos há no pote de biscoitos com uma abordagem recursiva. Um caso base é um pote vazio: tem zero biscoitos. Se o pote não estiver vazio, o número de biscoitos no pote é igual a um biscoito mais o número de biscoitos no pote depois de retirar um biscoito.

## 1. Verifica quantas aves visitaram hoje

- Esta tarefa não precisa de recursão.
- Podes aceder ao primeiro elemento de uma lista com uma expressão case.

## 2. Incrementa a contagem de hoje

- Esta tarefa não precisa de recursão.
- Podes aceder ao primeiro elemento de uma lista e ao resto da lista com uma expressão case.

## 3. Verifica se houve um dia sem aves visitantes

- Usa a recursão para iterar sobre os elementos da lista até encontrares um dia sem aves visitantes.
- O caso base é uma lista vazia.

## 4. Calcula o número total de aves visitantes

- Usa a recursão para iterar sobre todos os elementos da lista.
- O caso base é uma lista vazia.

## 5. Calcula o número de dias movimentados

- Usa a recursão para iterar sobre todos os elementos da lista.
- O caso base é uma lista vazia.
- Usa uma guarda numa das cláusulas da expressão case.
