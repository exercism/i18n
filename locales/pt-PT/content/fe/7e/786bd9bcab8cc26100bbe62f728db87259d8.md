# Instruções

Neste exercício, vais implementar uma forma de acompanhar as pontuações máximas do jogo mais popular do salão de jogos da tua zona.

Tens 6 funções para implementar, a maioria relacionada com a manipulação de um objeto que guarda pontuações máximas.

## 1. Cria uma nova tabela de pontuações máximas

Escreve uma função `create_score_board` que cria um objeto que serve de tabela de pontuações máximas.
As chaves deste objeto serão os nomes dos jogadores e os valores serão as suas pontuações.
Para efeitos de teste, queres incluir diretamente uma entrada no objeto.
Esta entrada inicial deve consistir em `"The Best Ever"` como nome do jogador e `1000000` como pontuação.

```jq
create_score_board
# returns an object with one initial entry
```

## 2. Adiciona jogadores a uma tabela de pontuações

Para adicionar um jogador à tabela de pontuações máximas, implementa a função `add_player`.
Recebe uma tabela de pontuações como entrada e precisa de dois parâmetros: o nome do jogador e a pontuação do jogador.
A função devolve o objeto da tabela de pontuações com o novo jogador adicionado.

```jq
{"José Valim", 486373}
| add_player("Dave Thomas"; 0)
# => {"Dave Thomas": 0, "José Valim": 486373} -- in some order
```

Se o jogador já estiver na tabela, devolve a tabela sem alterações.

## 3. Remove jogadores de uma tabela de pontuações

Se os jogadores violarem as regras do salão de jogos, são removidos manualmente da tabela de pontuações máximas.
Implementa `remove_player`, que recebe uma tabela como entrada e um parâmetro, o nome do jogador a remover.
Esta função deve remover a entrada do jogador indicado da tabela e devolver a nova tabela.
Se o jogador não estiver na tabela, não deve acontecer nada à tabela; deve ser devolvida tal como está.

```q
{"Dave Thomas": 0} | remove_player("Dave Thomas")
# => {}

{"Dave Thomas": 0} | remove_player("Rose Fanaras")
# => {"Dave Thomas": 0}
```

## 4. Aumenta a pontuação de um jogador

Se um jogador terminar outro jogo no salão de jogos, uma certa quantidade de pontos será adicionada à pontuação anterior na tabela.
Implementa `update_score`, que recebe uma tabela de pontuações como entrada e precisa de dois parâmetros: o nome do jogador e a quantidade de pontos a adicionar.
A função deve devolver a tabela de pontuações depois de feita a atualização.

```jq
{"Freyja Ćirić": 12771000} | update_score("Freyja Ćirić"; 73)
# => {"Freyja Ćirić": 12771073}
```

Esta função deve adicionar o jogador à tabela, caso ainda não esteja nela.

## 5. Aplica os pontos de bónus de segunda-feira

O salão de jogos tem uma tabela de pontuações separada às segundas-feiras.
No fim do dia, cada jogador dessa tabela recebe 100 pontos adicionais.

Implementa a função `apply_monday_bonus`.
A função adiciona os pontos de bónus a cada jogador que esteja listado nessa tabela.

```jq
{
  "Dave Thomas": 44,
  "Freyja Ćirić": 539,
  "José Valim": 265
}
| apply_monday_bonus
# => {"Dave Thomas": 144, "Freyja Ćirić": 639, "José Valim": 365}
```

## 6. Encontra a pontuação total

Diferentes salões de jogos competem entre si para determinar quem tem os melhores jogadores.
O salão com a pontuação total mais alta ganha a honra.

Escreve uma função `total_score`.
Recebe uma tabela de pontuações como entrada e devolve a soma das pontuações de todos os jogadores.

```jq
{
  "Dave Thomas": 44,
  "Freyja Ćirić": 539,
  "José Valim": 265
}
| total_score
# => 848
```
