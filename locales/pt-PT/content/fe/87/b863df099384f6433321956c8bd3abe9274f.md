# Dicas

## 1. Imprimir um crachá para um funcionário

- Para construir as strings em Base R, a função [`sprintf`][ref-sprintf] é útil.
- Para uma abordagem Tidyverse, podes usar [`str_glue`][ref-str_glue] da biblioteca `stringr`.

## 2. Imprimir um crachá para um novo funcionário

- Ramifica com base em [`is.na`][ref-isna].

## 3. Imprimir um crachá para o proprietário

- Ramifica com base em [`is.null`][ref-isnull].

## 4. Calcular o salário total dos funcionários sem ID

- Podes [filtrar][concept-vector-filtering] com base em [`is.na`][ref-isna] e depois usar [`sum`][ref-sum].
- O que é `salaries[is.na(ids)]` se não houver funcionários sem ID? Seria útil verificar isto numa consola de R. Se o R não estiver instalado no teu computador, consolas online como [rdrr.io][web-rdrr] podem ajudar.
