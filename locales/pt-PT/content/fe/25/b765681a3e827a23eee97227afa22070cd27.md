# Números de vírgula flutuante

Os números de vírgula flutuante são usados em PHP para representar um subconjunto dos números reais.
Começam por um ou mais algarismos separados por um separador decimal.

```php
<?php

$a = 1.234; 
$b = 1.2e3; 
$c = 7E-10;
$d = 1_234.567; // as of PHP 7.4.0
```

## Armadilhas comuns

Nem todos os números nem todas as operações aritméticas podem ser efetuados com números de vírgula flutuante.
Usar números de vírgula flutuante para representar dólares e cêntimos pode dar origem a erros de arredondamento muitas vezes.

```php
<?php

$result = 0.1 + 0.2; // => 0.30000000000000004
```
