# Introdução

O Lua usa duas representações para números: números inteiros de 64 bits e números de vírgula flutuante de precisão dupla. Suporta o conjunto habitual de operadores aritméticos: adição, subtração, multiplicação, divisão e negação. Além disso, suporta divisão inteira, módulo e exponenciação.

| Operador | Exemplo             |
| -------- | ------------------- |
| `+`      | `1 + 2 --> 3`       |
| `-`      | `2 - 1 --> 1`       |
| `*`      | `2 * 2 --> 4`       |
| `/`      | `4 / 2 --> 2.0`     |
| `//`     | `11 // 3 --> 3`     |
| `%`      | `11 % 3 --> 2`      |
| `^`      | `10 ^ 2 --> 100.0`  |
| `-`      | `-(2 * 2) --> -4`   |
