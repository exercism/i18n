# Introdução

## Variáveis

Lembra-te de que um programa `jq` é um _pipeline de expressões_.
A **atribuição de variáveis** segue esta regra: uma _atribuição de variável_ é uma expressão com este aspeto:

```jq
... | expr as $varname | ...
```

### O filtro devolve a entrada

Tal como a _expressão de identidade_ `.`, a saída da _atribuição de variável_ é igual à sua entrada.
Definir o valor da variável é um efeito secundário.

Exemplo que mostra que `.`, depois da atribuição, é igual à entrada inicial:

```sh
$ jq -c -n '42 | (. * 2) as $double | [., $double]'
[42,84]
```

### Âmbito das variáveis

O âmbito da variável é «lexical»: a variável permanece no âmbito até ao fim do pipeline.
As variáveis definidas em funções (falaremos de funções mais adiante) são «locais» à função.

### Nomes das variáveis

A variável tem de começar por `$`.
O resto do nome da variável é um **identificador**: começa por uma letra ou um underscore, seguido de letras, números ou underscores.

### Atribuição com desestruturação

Do manual:

> É possível declarar várias variáveis com uma única expressão `as`, fornecendo um padrão que _corresponda à estrutura da entrada_ (isto é conhecido como «desestruturação»).

Exemplos:

```jq
[1, 2, 3] as [$a, $b, $c]
| [$a, $b, $c]     # => [1, 2, 3]
```

```jq
{"foo": "bar", "len": [10, 20]} as {foo: $f, len: [$h, $w]}
| [$f, $h, $w]     # => ["bar", 10, 20]
```

Fazer corresponder o nome da variável à _chave do objeto_ oferece um atalho:

```jq
{"x": 4, "y": 7} as {$x, $y}
| [$x, $y]         # => [4, 7]
```

```jq
{"foo": "bar", "len": [10, 20]} as {$foo, $len}
| [$foo, $len]     # => ["bar", [10, 20]]
```

### Constantes

Como se vê no exemplo acima, as variáveis são úteis para guardar constantes.
É melhor dar um nome às constantes do que deixar «números mágicos» aparecerem no código.

### Muitas vezes, as variáveis não são necessárias

Muitas vezes, omitir variáveis torna o código mais legível.

Considera o cálculo da média de uma lista de números

```jq
[2, 4, 8, 7]
| add as $sum
| length as $len
| $sum / $len
```

em comparação com

```jq
[2, 4, 8, 7] | add / length
```

Isto realça um dos aspetos mais poderosos do `jq`: a entrada de um filtro é disponibilizada a _todas_ as subexpressões:

- o array de entrada `[2,4,8,7]` é passado a `add` (que soma os números aplicando o operador `+` a todos os elementos)
- _em paralelo_, `[2,4,8,7]` também é passado a `length`
- quando estas subexpressões terminam, os seus resultados são divididos, devolvendo o valor médio dos números do array de entrada.

### Operadores de `jq` necessários para o exercício de aprendizagem

#### Operador alternativo: `//`

A expressão `a // b` produz `b` se `a` for false ou null; caso contrário, produz `a`.
No contexto de definir uma variável, isto é muito útil para fornecer um valor por omissão:

```jq
(.input.theAnswer // 42) as $answer | ...
```

#### Operadores aritméticos

- `+`, `-`, `*` são os habituais operadores numéricos de adição, subtração e multiplicação.
