# Sobre

Um *heap* é uma coleção que sabe sempre qual é o seu item mais pequeno (ou maior) e permite removê-lo rapidamente. É a implementação natural de uma *fila de prioridade*. Os heaps fazem parte do vocabulary [`heaps`][heaps].

O `<min-heap>` cria um heap vazio cuja chave mais pequena sai primeiro; o `<max-heap>` entrega primeiro a maior. Cada item é um *valor* guardado sob uma *chave*, e a chave é a prioridade pela qual o Factor ordena:

```
<min-heap> ( -- min-heap )
<max-heap> ( -- max-heap )
heap-push  ( value key heap -- )
heap-push-all ( assoc heap -- )
```

```factor
USING: heaps ;

<min-heap>
"alice" 5 pick heap-push
"bob"   2 pick heap-push
```

Um heap é *mutável*: `heap-push` e `heap-pop` alteram-no no próprio local.

```
heap-peek    ( heap -- value key )
heap-pop     ( heap -- value key )
heap-pop-all ( heap -- alist )
heap-empty?  ( heap -- ? )
heap-size    ( heap -- n )
```

O `heap-peek` lê o elemento da frente sem o remover; o `heap-pop` remove-o e devolve-o; o `heap-pop-all` esvazia o heap para uma lista de associações de pares `{ key value }` por ordem de prioridade.

```factor
USING: assocs heaps kernel prettyprint ;

<min-heap>
"alice" 5 pick heap-push
"bob"   2 pick heap-push
"carol" 9 pick heap-push
dup heap-pop .           ! => 2 "bob"   (removed; value then key)
heap-pop-all values .    ! => { "alice" "carol" }
```

Inserir é `O(log n)` e ler o elemento da frente é `O(1)`, por isso a repetição de «tirar o item mais urgente e acrescentar mais» mantém-se rápida mesmo com uma fila grande. A implementação é um heap binário guardado num array que cresce; a chave pode ser qualquer valor ordenável (números, strings, …).

[heaps]: https://docs.factorcode.org/content/vocab-heaps.html
