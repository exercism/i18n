# Introdução

Em Common Lisp, uma função não só pode devolver um valor, como pode devolver vários valores.
Por exemplo, `floor`, que arredonda para baixo em direção a zero, devolve dois valores: o primeiro é o valor arredondado e o segundo é o resto.

```lisp
(floor 3.5) ; => 3
            ;    0.5
```
(Vamos mostrar os vários valores devolvidos em linhas separadas da saída.)

## Devolver vários valores

Se quiseres que uma função devolva vários valores, usas o acessor `values`:

```lisp
(defun three-numbers () (values 1 2 3))
(three-numbers) ; => 1
                ;    2
                ;    3
```

## Lidar com vários valores

Se só te importas com o primeiro valor, não precisas de fazer nada de especial: a linguagem trata disso:

```lisp
(+ (values 1 2 3) (values 10 20 30)) ; => 11
```

No entanto, se quiseres aceder a esses outros valores, há várias funções que precisas de usar.
As duas principais macros são `multiple-value-list` e `multiple-value-bind`.
Estas são usadas para envolver algo que devolve vários valores e capturar todos os valores.
A primeira cria uma lista com todos os valores.
A segunda permite-te associar variáveis aos valores individuais.

```lisp
(multiple-value-list (values 1 2 3))                   ; => (1 2 3)
(multiple-value-bind (a b c) (values 1 2 3) 
   (+ a b c)) ; => 6
```

Outra função útil é `nth-value`
