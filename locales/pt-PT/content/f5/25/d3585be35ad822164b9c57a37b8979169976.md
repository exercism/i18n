# Instruções

Neste exercício, vais implementar um programa que determina o estado de um [jogo do galo][tic-tac-toe].
(_Também podes conhecer este jogo como "noughts and crosses" ou "Xs and Os"._)

O jogo joga-se numa grelha de 3×3.
Os jogadores jogam à vez e colocam `X`s e `O`s na grelha.
O jogo termina quando um jogador ganha, ao colocar três marcas seguidas numa linha, numa coluna ou numa diagonal da grelha, ou quando a grelha fica completamente preenchida.

Neste exercício, vamos assumir que o `X` começa.

A tua tarefa é determinar em que estado está um dado jogo.

Há 3 estados possíveis:

- O jogo está **ongoing**.
- O jogo terminou em **draw**.
- O jogo terminou em **win**.

Se o tabuleiro dado for inválido, lança um erro adequado.

Um tabuleiro é inválido se cumprir as seguintes condições:

- O tabuleiro dado não pode ser alcançado quando os turnos são jogados pela ordem correta (lembra-te de que é o `X` que começa).
- O jogo continuou a ser jogado depois de já ter terminado.

## Exemplos

### Jogo em curso

```text
   |   |
 X |   |
___|___|___
   |   |
   | X | O
___|___|___
   |   |
 O | X |
   |   |
```

### Empate

```text
   |   |
 X | O | X
___|___|___
   |   |
 X | X | O
___|___|___
   |   |
 O | X | O
   |   |
```

### Vitória

```text
   |   |
 X | X | X
___|___|___
   |   |
   | O | O
___|___|___
   |   |
   |   |
   |   |
```

### Inválido

#### Ordem de turnos errada

```text
   |   |
 O | O | X
___|___|___
   |   |
   |   |
___|___|___
   |   |
   |   |
   |   |
```

#### Jogo continuado depois de uma vitória

```text
   |   |
 X | X | X
___|___|___
   |   |
 O | O | O
___|___|___
   |   |
   |   |
   |   |
```
