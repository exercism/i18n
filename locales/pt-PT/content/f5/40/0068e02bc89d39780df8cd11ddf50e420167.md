# Dicas

## Geral

- Cada operação devolve um buffer atualizado em vez de modificar o original. Isto inclui `read`, cujo resultado bem-sucedido contém tanto `value` como `updated_buffer`.

- Usa atualizações de registo como `{ ..buffer, length: 0 }` para preservares os outros campos.

- `List.replace` devolve um `Try` cujo registo bem-sucedido contém a lista atualizada no seu campo `list`.
