# Sobre

Os ciclos `for` são o tipo de ciclo mais complexo em PHP. Comportam-se como os ciclos `for` em `C`, `Java` e `JavaScript`. A sua forma básica é:

```php
for (expr1; expr2; expr3) {
  // statements
}
```

A primeira expressão (_expr1_) é avaliada antes de o ciclo começar. A segunda expressão (_expr2_) é avaliada antes de cada iteração. Se for avaliada como um valor _truthy_, as instruções são executadas. Após a execução das instruções, a terceira expressão (_expr3_) é avaliada.
