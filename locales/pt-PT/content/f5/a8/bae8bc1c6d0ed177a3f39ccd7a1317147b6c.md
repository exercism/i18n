# Instruções

Neste exercício vais implementar um conjunto parcial de funções utilitárias para ajudar um programador a limpar nomes de identificadores.

Ao longo das 5 tarefas vais construir gradualmente a função `clean`.
Um identificador válido é composto por zero ou mais letras e underscores.

Se for passada uma string vazia à função `clean`, deve ser devolvida uma string vazia.

## 1. Substitui os espaços por underscores

Implementa uma função `clean1` que substitua todos os espaços por underscores. Isto também se aplica aos espaços no início e no fim.

```elm
clean1 "my   Id"
    --> "my___Id"
```

## 2. Substitui os carateres de controlo pela string "[CTRL]" em maiúsculas

Implementa a `clean2` para fazer tudo o que a função anterior faz e substituir os carateres de controlo comuns (\n, \t e \r) pela string `"[CTRL]"`.

```elm
clean2 "my\nId"
    --> "my[CTRL]Id",
```

## 3. Converte kebab-case em camelCase

Implementa a `clean3` para fazer tudo o que a função anterior faz e converter kebab-case em camelCase.

```elm
clean3 "à-ḃç"
    --> "àḂç"
```

## 4. Omite os algarismos

Implementa a `clean4` para fazer tudo o que a função anterior faz e omitir todos os algarismos.

```elm
clean4 "123"
    --> ""
```

## 5. Omite as letras gregas minúsculas

Por fim, implementa a `clean` para fazer tudo o que a função anterior faz e omitir quaisquer letras gregas no intervalo entre 'α' e 'ω'.

```elm
clean "My Οβιεγτ Finder"
    --> "My_Ο_Finder"
```
