# Introdução

O tipo `char` do C# é uma quantidade de 16 bits que representa os componentes endereçáveis mais pequenos do texto.
Vários `char`s podem formar uma string como `"word"`, ou os `char`s podem ser
processados individualmente. Os seus literais usam plicas, por exemplo `'A'`.

Os `char`s do C# suportam a codificação Unicode UTF-16, pelo que, além do conjunto de carateres latinos,
praticamente todos os sistemas de escrita usados em todo o mundo podem ser representados,
por exemplo a letra grega `'β'`.

Há muitos métodos incorporados na biblioteca para inspecionar e manipular `char`s. Podes
encontrá-los como métodos estáticos da classe `System.Char`.
