# Classes genéricas

```sather
class LOST_BOX{T} is
   attr item : T;
   create(thing : T) : SAME is
      box ::= new;
      box.item := thing;
      return box;
   end;
end;
```

## O que é o parâmetro

`T` representa um tipo fornecido no ponto de utilização. Quando o programa é
compilado, o Sather constrói uma classe distinta para cada combinação
efetivamente usada. Por isso:

- `LOST_BOX{STR}` e `LOST_BOX{INT}` são tipos sem qualquer relação entre si;
- não há verificação em tempo de execução, nem boxing, nem conversão;
- um erro na classe manifesta-se para cada tipo com que é usada.

É a mesma abordagem dos templates de C++ ou dos genéricos do Rust, e ao
contrário dos genéricos do Java, em que o tipo é apagado e tudo é, na
realidade, um objeto.

## Parâmetros com restrições

Um `T` simples pode ser atribuído, passado e devolvido, nada mais, porque nada
mais se sabe sobre ele. Para chamar rotinas sobre ele, indica aquilo com que
tem de estar em conformidade:

```sather
class LOST_BOX{T < $STR} is
   describe : STR is return "a box holding " + item.str; end;
end;
```

`T < $STR` exige que `T` esteja em conformidade com `$STR` e, em troca, permite
chamar `item.str`. Tudo o que um `T` simples não consegue fazer pode ser
permitido através de uma restrição.

Sem a restrição, `item.str` não compila, e a mensagem aponta para a linha
dentro da classe genérica e não para a linha que a usou.

## Rotinas genéricas?

Não existem. Só as classes recebem parâmetros. Uma rotina que tenha de funcionar
com vários tipos ou vive numa classe genérica, ou recebe um tipo abstrato como
`$STR`.

## Como escolher entre as duas

| | classe genérica | classe abstrata |
| --- | --- | --- |
| decidido | quando é compilada | quando é executada |
| guarda | um tipo por instanciação | qualquer tipo em conformidade |
| custo | nenhum | um despacho |

`ARRAY{$ACT}` usa as duas: genérica no tipo dos elementos, abstrata naquilo que
esses elementos podem ser.

Recorre a uma classe genérica quando o tipo é o mesmo de ponta a ponta e quem
usa a classe sabe disso. Recorre a uma classe abstrata quando vários tipos têm
de coexistir numa mesma coleção.
