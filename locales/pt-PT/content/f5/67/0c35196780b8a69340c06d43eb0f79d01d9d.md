# Anexo de instruções

## Implementação

Muitos dos nossos exercícios de Pyret mais básicos podem ser resolvidos apenas com [expressões de aplicação de funções][function application expressions] sob a forma de `foo(1)`.
Este exercício, no entanto, espera que [expressões com ponto][dot expressions] possam ser usadas para aceder a campos de dados e de métodos naquilo que a tua função devolve.
Isto pode ser feito com [expressões de objeto][object expressions], o que te permite aceder aos campos de um literal de objeto.
As [declarações de dados][data declarations] são uma abordagem semelhante mas mais avançada, que também utiliza campos de dados e de métodos.

[function application expressions]: https://pyret.org/docs/latest/Expressions.html#%28part._s~3aapp-expr%29
[dot expressions]: https://pyret.org/docs/latest/Expressions.html#%28part._s~3adot-expr%29
[object expressions]: https://pyret.org/docs/latest/Expressions.html#%28elem._%28bnf-prod._%28.Pyret._obj-expr%29%29%29
[data declarations]: https://pyret.org/docs/latest/s_declarations.html#%28part._s~3adata-decl%29
