# Escrever o código

Escreve o teu código em `<exercise_name>.zig`.
Alguns exercícios incluem assinaturas já escritas para construções específicas do Zig, como [constantes][constants], [funções][functions], [imports][imports], [structs][structs] e [potencialmente muitas mais][et-cetera]!

Estas assinaturas já escritas servem para te ajudar a concluir os exercícios, dando-te um ponto de partida claro.
No entanto, não é obrigatório começar por estas assinaturas.
Sobretudo porque qualquer código que passe nos testes é uma solução perfeitamente aceitável.

## Correr os testes

Para correr os testes, basta executares o seguinte comando:

```bash
zig test test_exercise_name.zig
```

substituindo `exercise_name` pelo nome do exercício.
O comando acima tem de ser executado no diretório raiz do exercício. O ficheiro de testes deve estar nesse mesmo local.
Além disso, todos os testes de um exercício estão ativados por omissão e não é possível saltar nenhum deles.

Como todos os testes têm estas condições, se quiseres percorrer cada teste um a um, terás de [comentar][comments] os testes que ainda não passam.
Comentar um teste é tão simples como começar cada linha com `//`.
Em alternativa, quando estiveres confiante de que a tua solução passa nos testes, podes descomentar esses testes para ver se passa.
