# Instruções

Aprende a combinar dados de duas tabelas internas diferentes numa única tabela interna de resultado.

A tua classe vai receber duas tabelas internas que contêm dois conjuntos de dados completamente diferentes, ALPHAS e NUMS.

```abap
TYPES: BEGIN OF alphatab_type,
         cola TYPE string,
         colb TYPE string,
         colc TYPE string,
       END OF alphatab_type.
TYPES: alphas TYPE STANDARD TABLE OF alphatab_type.
TYPES: BEGIN OF numtab_type,
         col1 TYPE string,
         col2 TYPE string,
         col3 TYPE string,
       END OF numtab_type.
TYPES: nums TYPE STANDARD TABLE OF numtab_type.
```

Os dados da tabela ALPHA são os que se mostram abaixo.

| COLA | COLB | COLC |
| --- | --- | --- |
| A | B | C | 
| D | E | F |
| G | H | I |

Os dados da tabela NUMS são os que se mostram abaixo.

| COL1 | COL2 | COL3 |
| --- | --- | --- |
| 1 | 2 | 3 | 
| 4 | 5 | 6 |
| 7 | 8 | 9 |

A tua tarefa é devolver uma tabela interna com registos que combinam os valores de cada célula da tabela interna ALPHAS com os da tabela interna NUMS. Por exemplo, o valor da primeira coluna da primeira linha da tabela interna COMBINED_DATA deve ser "A1".

A tabela devolvida esperada tem a seguinte definição:

```abap
TYPES: BEGIN OF combined_data_type,
         colx TYPE string,
         coly TYPE string,
         colz TYPE string,
       END OF combined_data_type.
TYPES: combined_data TYPE STANDARD TABLE OF combined_data_type WITH EMPTY KEY.
```
