# Dicas

## 1. Substitui todos os espaços que encontrares por underscores

A biblioteca incorporada `clojure.string` contém uma função [`replace`][str-replace].

## 2. Substitui os carateres de controlo pela string "CTRL" em maiúsculas

Podes usar o método [`isISOControl`][java-ctrl] da classe `Character` do Java.

## 3. Converte kebab-case em camelCase

Tenta separar a string pelos hífenes com [`split`][str-split].
Se não contiver hífenes, deves devolvê-la tal como está. Podes verificar isso com [`includes?`][str-includes]. Usa [`upper-case`][str-upper-case] para criar as "corcovas" do camelCase. Por fim, concatena-as com [`join`][str-join].

## 4. Omite os carateres que não são letras

Podes filtrar os carateres usando [`Character/isLetter`][java-isletter] como predicado.

## 5. Omite as letras gregas minúsculas

As letras gregas minúsculas são os pontos Unicode `\u03B1` a `\u03C9`, ou os valores inteiros 945 a 969.
