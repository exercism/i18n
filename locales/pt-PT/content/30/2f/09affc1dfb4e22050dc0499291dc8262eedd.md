# Sobre

`assocs` é um [protocolo][assoc-protocol], não um único tipo de dados. As tabelas de hash (`H{ }`), as listas de associação (sequências de pares `{ key value }`) e os mapas em árvore implementam-no todos, e a maioria das palavras que trabalham com assocs é intercambiável entre eles.

```factor
USING: assocs ;

H{ } clone "coal" over inc-at
"coal" over inc-at
"wood" over inc-at      ! => H{ { "coal" 2 } { "wood" 1 } }
```

O conjunto de palavras é vasto: iteração ordenada, mapeamento, filtragem. Ainda assim, a maior parte do trabalho ao nível dos exercícios usa apenas um pequeno grupo:

| palavra     | efeito                                        |
|-------------|-----------------------------------------------|
| `at`        | `( key assoc -- value/f )`                    |
| `at*`       | `( key assoc -- value ? )` distingue o valor f de uma chave em falta |
| `key?`      | `( key assoc -- ? )`                          |
| `set-at`    | `( value key assoc -- )`: muta o assoc        |
| `change-at` | `( key assoc quot -- )`: `quot` é `( old -- new )` |
| `inc-at`    | `( key assoc -- )`: `+1`, inserindo `1` se a chave não existir |
| `delete-at` | `( key assoc -- )`: muta o assoc              |
| `>alist`    | `( assoc -- pairs )`                          |

`sort-keys` e `sort-values` (em `sorting`) ordenam uma alist pelo campo escolhido.

[assoc-protocol]: https://docs.factorcode.org/content/article-assocs-protocol.html
