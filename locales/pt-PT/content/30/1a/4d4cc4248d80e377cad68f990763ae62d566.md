# Acerca de

Os inicializadores de objetos são uma alternativa aos construtores. A sintaxe é uma lista de pares nome=valor separados por vírgulas, como se ilustra abaixo:

```csharp
public class Person
{
    public string Name;
    public string Address;
}

var person = new Person{Name="The President", Address = "Élysée Palace"};
```

As coleções também podem ser inicializadas desta forma. Normalmente, isso faz-se com listas separadas por vírgulas, como mostra o exemplo seguinte:

```csharp
IList<Person> people = new List<Person>{ new Person(), new Person{Name="Joe Shmo"}};
```

Esta abordagem (e esta sintaxe) pode ser usada com qualquer classe que implemente `IEnumerable` e tenha um método `Add()`.

Os campos podem ser indicados por qualquer ordem ou omitidos por completo.

Os dicionários usam a seguinte sintaxe:

```csharp
IDictionary<int, string> numbers = new Dictionary<int, string>{ [0] = "zero", [1] = "one"...};

// or

IDictionary<int, string> numbers = new Dictionary<int, string>{ {0, "zero" }, {1,  "one"}...};
```

Os campos inicializados têm de estar acessíveis a quem faz a chamada. Normalmente, isso significa que têm de ser `public` ou `internal`.

Há uma forte tendência para promover a imutabilidade entre os criadores da linguagem e os principais praticantes, pelo que a mutabilidade dos objetos inicializados desta forma é vista como uma desvantagem. Existem propostas para introduzir uma cláusula `init` na próxima versão da linguagem, o C# 9, que poderá resolver esta questão.

- A documentação dos [inicializadores de objetos][object-initializers] descreve como usar os inicializadores.
- A documentação dos [inicializadores de coleções][collection-initializers] dá uma pré-visualização de como os inicializadores podem ser usados com coleções como dicionários e listas.
