# Apêndice às instruções

## Formato do campo de minas

O campo de minas é representado como uma string terminada em nulo, com um caráter de nova linha no final de cada linha.

Um exemplo seria `"   \n * \n   \n"`

## Registos

| Registo  | Utilização   | Tipo    | Descrição                     |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | entrada      | endereço | string de entrada terminada em nulo  |
| `$a1`    | entrada/saída | endereço | string de saída terminada em nulo |
| `$t0-9`  | temporário   | qualquer | para armazenamento temporário  |
