# Testes

Podes correr os testes fornecidos através do DrRacket ou a partir da linha de comandos.

Para correr o teste através do DrRacket, basta abrires o ficheiro de teste e clicares no botão "Run", no canto superior direito.

Para correr o teste a partir da linha de comandos, basta executá-lo a partir do diretório do exercício. Por exemplo, se a suite de testes se chama `hello-world-test.rkt`, podes correr o seguinte comando:

```
raco test hello-world-test.rkt
```

o que mostra o seguinte:

```
raco test: (submod "hello-world-test.rkt" test)
2 success(es) 0 failure(s) 0 error(s) 2 test(s) run
0
2 tests passed
```
