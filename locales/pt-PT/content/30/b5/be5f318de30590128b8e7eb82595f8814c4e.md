# Anexo às instruções

## Implementação

Há muitas formas de realizar este exercício, mas fornecemos alguns stubs adicionais para quem quiser praticar a escrita dos seus próprios [manipuladores de habilidades][ability-handler-docs].

A assinatura da função auxiliar `checkBalance` fornecida para este exercício usa um requisito de habilidade, `{Stack}`.
A habilidade `Stack` está definida para ti, mas o manipulador, `Stack.run`, não está!
Se quiseres, podes implementar as funções `Stack.run`, `checkBalance` e `isPaired`.
Os testes vão correr mesmo que escolhas não implementar este exercício com habilidades.

[ability-handler-docs]: https://www.unison-lang.org/learn/fundamentals/abilities/writing-abilities/
