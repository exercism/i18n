# Instruções

Neste exercício vais escrever um `SecureTreasureChest` genérico (e mágico!) para guardar um tesouro.
Os alunos mais atentos já devem ter reparado que o `TreasureChest` anterior não era assim tão seguro!
Se usavas a função `getTreasure`, tinhas de fornecer a palavra-passe, mas mesmo assim podias simplesmente desestruturar o tipo `TreasureChest` para obter o tesouro, sem precisares de saber a palavra-passe.
Pior ainda: também podias obter a palavra-passe da mesma forma!
Vamos corrigir isso com um tipo opaco.

## 1. Define o tipo opaco Password, usando o padrão "Parse, don't validate"

Define um tipo personalizado `Password` com uma única variante.

A variante deve ter um valor `String` associado, para a palavra-passe.

Deves expor o tipo `Password`, mas não a variante.
Isto torna `Password` um tipo opaco e significa que já não podes usar desestruturação para obter a palavra-passe.
Não é possível testar se um tipo é opaco ou não; em código de produção, usarias o [elm-review][elm-review] (uma ferramenta de análise estática) para o garantir.

Define e expõe uma função `createPassword`, com uma definição de tipo, que recebe uma `String` e devolve um `Maybe Password`.

A Owasp recomenda que [as palavras-passe tenham pelo menos 8 carateres][owasp-password-length], por isso vamos usar o padrão [Parse, don't validate][parse-dont-validate] para impor este invariante.

Se a palavra-passe tiver menos de 8 carateres, `createPassword` deve devolver `Nothing`; caso contrário, deve devolver `Just Password`.

## 2. Expõe o SecureTreasureChest, mas não a sua variante

Deves expor o tipo `SecureTreasureChest`, mas não a variante.
Isto torna `SecureTreasureChest` um tipo opaco e significa que já não podes usar desestruturação para obter a palavra-passe nem o tesouro.

## 3. Define a função createTreasure

Esta função deve receber dois parâmetros e ter uma definição de tipo.

- um tipo genérico (para o tesouro)
- uma `Password` (para a palavra-passe)

A função deve devolver um `SecureTreasureChest`.

Expõe esta função, para que outros módulos possam criar instâncias de `SecureTreasureChest`.

## 4. Define a função getTreasure

Esta função deve receber dois parâmetros e ter uma definição de tipo.

- uma `String` (para a palavra-passe)
- um tipo personalizado genérico `SecureTreasureChest`

Esta função deve verificar a tentativa de palavra-passe fornecida contra a `Password` no `SecureTreasureChest`.

A função deve devolver um `Maybe`.

Se as palavras-passe coincidirem, devolve `Just` com o valor genérico do `SecureTreasureChest` (o tesouro!)

Se as palavras-passe não coincidirem, devolve `Nothing`.

Expõe esta função, para que outros módulos possam obter o tesouro de um `SecureTreasureChest`, desde que forneçam a palavra-passe correta.
