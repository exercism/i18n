# Apêndice às instruções

## Dicas

Para completares este exercício, tens de implementar a função `score`,
que recebe uma sequência de *lançamentos* de bowling e devolve a pontuação
final ou o erro adequado:

```haskell
score :: [Int] -> Either BowlingError Int

data BowlingError = IncompleteGame
                  | InvalidRoll { rollIndex :: Int, rollValue :: Int }
                  deriving (Eq, Show)
```

Vais encontrar estas definições já feitas, mas cabe-te a ti definir a
função.

Tem em conta que o conjunto de testes espera que os lançamentos sejam
numerados a partir do zero.
