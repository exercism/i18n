# Instruções

Neste exercício vais trabalhar num agendador de marcações para um salão de beleza em Nova Iorque que abriu a 15 de setembro de 2012.

Tens cinco tarefas, todas relacionadas com datas de marcação.
Os horários estão no formato de 24 horas (sem AM/PM).

## 1. Converter uma data de marcação só com números

Implementa a função `schedule_appointment()` para converter uma representação textual de uma data de marcação no formato `DateTime` correspondente.

Repara que o valor de entrada está no formato dos Estados Unidos: mês/dia/ano.

```julia-repl
julia> schedule_appointment("07/25/2023 13:45:00")
2023-07-25T13:45:00
```

## 2. Verificar se uma marcação já passou

Implementa a função `has_passed()`, que recebe uma data de marcação e verifica se a marcação já passou:

```julia-repl
julia> has_passed(DateTime(1999, 12, 31, 9, 0, 0))
true
```

## 3. Verificar se a marcação é à tarde

Implementa a função `is_afternoon_appointment()`, que recebe uma data de marcação e verifica se a marcação é à tarde (>= 12:00 e < 18:00):

```julia-repl
julia> is_afternoon_appointment(DateTime(2023, 3, 29, 15, 0, 0))
true
```

## 4. Descrever a data e a hora da marcação

Implementa a função `description()`, que recebe uma data de marcação e devolve uma descrição dessa data e hora:

```julia-repl
julia> describe(DateTime(2023, 3, 29, 15, 0, 0))
"You have an appointment on Wednesday, March 29, 2023 at 15:00"
```

## 5. Devolver a data de aniversário

Implementa a função `anniversary_date()`, que devolve a data de aniversário deste ano, que é 15 de setembro:

```julia-repl
julia> anniversary_date()  # run during 2025
2025-09-15
```
