# Instruções

Dado um número n, determina qual é o enésimo número primo.

Ao listar os seis primeiros números primos: 2, 3, 5, 7, 11 e 13, vemos que o
sexto número primo é 13.

Se a tua linguagem de programação tiver métodos na biblioteca padrão para lidar
com números primos, faz de conta que não existem e implementa-os tu próprio.
