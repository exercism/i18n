# Instruções

A Jen trabalha na sala de triagem de uma grande fábrica.
A sala de triagem tem de processar tudo o que lá entra, categorizando-o com uma etiqueta.
A Jen é responsável pelos itens pré-categorizados como números e precisa de um programa que a ajude com a triagem.

A maioria dos valores primitivos deve receber etiquetas diretas.
Para os números, quer strings que digam `"This is the number 2.0"` (se o número for 2).
A Jen quer o mesmo resultado para inteiros e para números de vírgula flutuante.

Há algumas interfaces `Box` que é preciso desembrulhar para obter o seu conteúdo.
Para uma `NumberBox`, quer strings que digam `"This is a box containing the number 3.0"` (se o método `Number()` devolver 3).
Para uma `FancyNumberBox`, quer strings que digam `"This is a fancy box containing the number 4.0"`, mas apenas se o tipo for um `FancyNumber`.

Tudo o que for inesperado deve dizer `"Return to sender"`, para que a Jen os possa devolver à origem.

## 1. Descrever números simples

A Jen quer que os números devolvam strings como `"This is the number 2.0"` (incluindo um algarismo depois da vírgula):

```go
fmt.Println(DescribeNumber(-12.345))
// Output: This is the number -12.3
```

## 2. Descrever uma caixa de números

A Jen quer que as caixas de números devolvam strings como `"This is a box containing the number 2.0"` (mais uma vez, incluindo um algarismo depois da vírgula):

```go
fmt.Println(DescribeNumberBox(numberBoxContaining{12}))
// Output: This is a box containing the number 12.0
```

## 3. Implementar um método que extrai o número de uma caixa de números sofisticada

A Jen precisa de uma função auxiliar para extrair o número de uma `FancyNumberBox`.
Se a `FancyNumberBox` for um `FancyNumber`, extrai o seu valor e converte-o de uma `string` para um `int`.
Qualquer outro tipo de `FancyNumberBox` deve devolver 0.

```go
fmt.Println(ExtractFancyNumber(FancyNumber{"10"}))
// Output: 10
fmt.Println(ExtractFancyNumber(AnotherFancyNumber{"4"}))
// Output: 0
```

## 4. Descrever uma caixa de números sofisticada

Se a `FancyNumberBox` for um `FancyNumber`, a Jen quer strings que digam `"This is a fancy box containing the number 4.0"`.
Qualquer outro tipo de `FancyNumberBox` deve dizer `"This is a fancy box containing the number 0.0"`.

```go
fmt.Println(DescribeFancyNumberBox(FancyNumber{"10"}))
// Output: This is a fancy box containing the number 10.0
fmt.Println(DescribeFancyNumberBox(AnotherFancyNumber{"4"}))
// Output: This is a fancy box containing the number 0.0
```

NOTA: devemos usar a função `ExtractFancyNumber`!

## 5. Implementar `DescribeAnything`, que usa todas as anteriores

Esta é a função principal de que a Jen precisa, que recebe qualquer valor de entrada.
A `DescribeAnything` deve delegar nas outras funções com base no tipo do valor recebido.
Mais concretamente:

- `int` e `float64` devem ambos delegar em `DescribeNumber`
- `NumberBox` deve delegar em `DescribeNumberBox`
- `FancyNumberBox` deve delegar em `DescribeFancyNumberBox`
- qualquer outra coisa deve resultar em `"Return to sender"`

```go
fmt.Println(DescribeAnything(numberBoxContaining{12.345}))
// Output: This is a box containing the number 12.3
fmt.Println(DescribeAnything("some string"))
// Output: Return to sender
```
