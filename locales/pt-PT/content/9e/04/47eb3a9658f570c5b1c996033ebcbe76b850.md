# Testes

## Testar interativamente

Inicia a tua implementação de Common Lisp na diretoria do exercício em que estás a trabalhar (ou muda a diretoria atual de uma implementação de Common Lisp já em execução para essa diretoria).
Com o roswell, faz isto com `ros run`.

(Todos os exemplos aqui assumem um exercício chamado `exercise-name`; ajusta conforme necessário.)

Carrega o ficheiro de testes na tua implementação de Lisp em execução, por exemplo, `(load "exercise-name-test")`. 
(Isto também carrega o ficheiro de solução por ti.)
Depois de o ficheiro de testes estar carregado, podes correr os testes avaliando `(exercise-name-test:run-tests)` no REPL.

À medida que vais fazendo alterações à solução que estás a escrever, usa a funcionalidade do teu editor para carregar as alterações ou avalia `(load "exercise-name")` para carregar o teu ficheiro de solução.

Lembra-te de avaliar `(exercise-name-test:run-tests)` para voltares a correr os testes depois de carregares a tua solução atualizada.

## Testar a partir da linha de comandos

Podes lançar os testes com esta invocação na linha de comandos (mais uma vez, substitui "exercise" pelo nome adequado em dois sítios)

```sh
ros run --load exercise-test.lisp --eval '(uiop:quit (if (exercise-test:run-tests) 0 1))'
```

Esse comando é bastante complicado de usar.
Um contribuidor escreveu algumas notas sobre [como torná-lo mais fácil de invocar](https://glennj.github.io/exercism/cli).
