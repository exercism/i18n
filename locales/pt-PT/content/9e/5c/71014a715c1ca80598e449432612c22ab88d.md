## Geral

### 1. Formata um cântico mágico

- Usa a macro `format!` para combinar vários valores de entrada do tipo `ByteArray` numa única string.
- Separa os cânticos com um delimitador como `"-"` para corresponder ao resultado esperado.
- Garante que o resultado é devolvido como um `ByteArray`.

### 2. Implementa o trait `Display` para `EchoStone`

- O trait `Display` permite-te definir como o `EchoStone` deve aparecer quando é impresso com `{}`.
- Usa a macro `write!` dentro da função `fmt` para formatar a string de saída.
- Inclui os campos `power` e `duration` num formato claro e conciso, por exemplo, `EchoStone [power: X, duration: Y]`.

### 3. Implementa o trait `Debug` para `EchoStone`

- O trait `Debug` serve para fins de debug, permitindo um resultado mais detalhado ou estruturado quando é impresso com `{:?}`.
- Segue um formato de debug claro, como `Debugging EchoStone: { power: X, duration: Y }`.
- Usa a macro `write!` para criar o resultado de debug.
