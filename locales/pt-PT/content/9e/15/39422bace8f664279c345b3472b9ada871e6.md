## Booleans

O Raku tem os literais Boolean `True` e `False`.
Em contexto Boolean, tudo o que não estiver definido é considerado `False`.
Além do próprio `Bool::False`, entre os valores definidos que são considerados `False` estão `0`, `NaN`, `()` (lista vazia), `""` (string vazia) e objetos do tipo `Failure`.

O operador [prefixo `?`][&prefix:<?>] força o contexto Boolean num objeto.
O seu comportamento é o mesmo que chamar o método [`Bool`][routine/Bool] a esse objeto.
O operador [prefixo `!`][&prefix:<!>] dá o inverso do prefixo `?`.

## Operadores infixos Boolean

### Smartmatch

O operador [infixo `~~`][&infix:<~~>], também conhecido como smartmatch, é uma ferramenta muito usada no Raku.
O seu comportamento depende do objeto que está do lado direito do operador, pois é um atalho para o método [`ACCEPTS`][routine/ACCEPTS] desse objeto.
O valor do lado esquerdo é passado como argumento ao `ACCEPTS`.
O resultado é um valor Boolean.

### AND/OR lógicos

O Raku tem os operadores [`&&`][&infix:<&&>]/[`and`][&infix:<and>], [`||`][&infix:<||>]/[`or`][&infix:<or>], [`//`][&infix:<//>]/[`orelse`][&infix:<orelse>] e [`^^`][&infix:<^^>]/[`xor`][&infix:<xor>] para lógica Boolean (precedência alta e baixa, respetivamente).
Podem ser encadeados.

```raku
1 xor 1 xor 1;
# Nil in Raku, 1 in Perl (because the latter makes the first pair false).
```

### Ternário

O Raku tem um operador [infixo `?? !!`][infix-??-!!] ternário/condicional, que se escreve como `$condition ?? $true !! $false`.

## Fluxo de controlo

### if/elsif/else

Uma condicional [`if`][control-if] é usada para executar um bloco de código de forma condicional.
Para criar uma condicional `if`, a palavra-chave `if` é seguida de uma [expressão][statements-and-expressions] e depois de um [bloco][control-block].

A expressão é avaliada em [contexto Boolean][contexts-boolean], e o bloco é executado se a expressão for avaliada como `True`.

Uma condicional `if` pode ser ampliada com as palavras-chave [`elsif` e `else`][control-else/elsif], escritas da mesma forma que o `if`. Um bloco `else` é executado se todas as expressões anteriores forem avaliadas como `False`, e um bloco `elsif` é executado da mesma forma, se a sua própria expressão for avaliada como `True`.

Em alternativa, o `if` pode ser usado na forma de modificador de instrução:

```raku
say 'success' if True;
```

A forma de modificador de instrução não pode ser usada com `elsif` nem com `else`.

### given/when/default

A instrução [`given`][control-given] é a palavra-chave de topicalização do Raku, de forma semelhante à forma como o `switch` topicaliza em linguagens como o C.
As palavras-chave para os casos individuais são [`when` e `default`][control-default-and-when].

### for/while/loop

Uma instrução [`for`][control-for] itera sobre uma lista e executa um bloco para cada elemento dessa lista.

Uma instrução [`while`][control-while] executa um bloco repetidamente enquanto a expressão indicada for avaliada como `True`.

Uma instrução [`loop`][control-loop] pode ser escrita de duas formas.
Se lhe for dado apenas um bloco, executa esse bloco repetidamente até algo quebrar o ciclo explicitamente.
Também pode ser escrita como um ciclo `for` ao estilo do C, com um inicializador, uma condicional e um incrementador entre parênteses antes do bloco.

```raku
loop (my $i = 0; $i < 10; $i++) {
    say $i;
}
```
