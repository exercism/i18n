# Anexo às instruções

## Dicas

Para este exercício, a seguinte funcionalidade do F# dá jeito:

- O tipo [Map](https://en.wikibooks.org/wiki/F_Sharp_Programming/Sets_and_Maps#Maps) associa chaves a valores. É muito semelhante ao tipo `Dictionary<TKey, TValue>` do .NET, mas com uma diferença importante: o `Map` é [imutável](https://fsharpforfunandprofit.com/posts/correctness-immutability/).
- Uma [abreviatura de tipo](https://fsharpforfunandprofit.com/posts/type-abbreviations/) serve para criar um alias descritivo para um tipo mais complexo.
