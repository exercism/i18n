# Anexo às instruções

## Implementação

~~~~exercism/note

Podes (ou não!) querer chamar a função `permutations(a, t)` de [Combinatorics.jl][combinatorics] na tua solução.

[combinatorics]: https://juliamath.github.io/Combinatorics.jl/stable/api/#Combinatorics.permutations-Tuple{Any,%20Integer}
~~~~

- Se estiveres a trabalhar no editor online, podes chamar `permutations(a ,t)` à vontade, uma vez que já está no espaço de nomes. Podes ver o código-fonte no separador com a etiqueta `permutations.jl`.
- Se estiveres a trabalhar localmente, acrescenta `include("permutations.jl")` ao início do teu ficheiro de solução para acederes à versão de `permutations(a, t)` que está lá. 

~~~~exercism/caution

Se usares `Combinatorics.jl` `v1.0.3` localmente, a função `permutations(a, t)` é *muito* lenta nos testes grandes.
Usa o ficheiro fornecido `permutations.jl`, atualiza para `Combinatorics.jl` `v≥1.1.0` ou "desce" para `v1.0.2`.

~~~~
