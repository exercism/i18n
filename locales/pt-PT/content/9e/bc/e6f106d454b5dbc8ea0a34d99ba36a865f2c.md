# Instruções

Neste exercício, trabalhas numa pizzaria que faz entregas ao domicílio.

Ofereces três tipos de pizza:

- Margherita: \$7
- Caprese: \$9
- Formaggio: \$10

Os clientes podem também escolher duas opções adicionais por um pequeno custo extra:

1. Molho extra: \$1
1. Ingredientes extra: \$2

Quando os clientes fazem uma encomenda, é acrescentada uma taxa adicional se encomendarem apenas uma ou duas pizzas:

- 1 pizza: \$3
- 2 pizzas: \$2

Tens três tarefas, cada uma delas sobre pizzas e o seu preço.

## 1. Define os tipos de pizza e as opções

Define a união discriminada `Pizza` para representar os tipos de pizza e as duas opções adicionais que podem ser acrescentadas a uma pizza:

- `Margherita`
- `Caprese`
- `Formaggio`
- `ExtraSauce`
- `ExtraToppings`

## 2. Calcula o preço da pizza

Implementa a função `pizzaPrice` para calcular o preço de uma pizza:

```fsharp
pizzaPrice Caprese
// => 9
```

## 3. Calcula o preço de uma encomenda

Implementa a função `orderPrice` para calcular o preço de uma encomenda de pizzas:

```fsharp
orderPrice [Margherita; Formaggio]
// => 19
```
