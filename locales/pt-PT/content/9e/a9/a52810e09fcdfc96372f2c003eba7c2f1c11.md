# Dicas

## 1. Devolve uma lista com os nomes dos artigos

- A [função `iterator.map`][map] pode ser usada para transformar os artigos de um iterador.

## 2. Devolve os artigos que sejam baratos

- A [função `iterator.filter`][filter] pode ser usada para remover alguns artigos de um iterador.

## 3. Devolve os artigos que estão esgotados

- A [função `iterator.filter`][filter] pode ser usada para remover alguns artigos de um iterador.

## 4. Devolve o stock total

- A [função `iterator.fold`][fold] pode ser usada para reduzir um iterador a um único valor.
