# Introdução

Além de `cond`, o Elixir também disponibiliza a macro [`if/2`][getting-started-if], que é útil quando precisas de verificar apenas uma condição.

A [`if/2`][kernel-if] aceita uma condição e duas opções. Devolve a primeira opção se a condição for _truthy_ e a segunda opção se a condição for _falsy_.

```elixir
age = 15

if age >= 16 do
  "You are allowed to drink beer in Germany."
else
  "No beer for you!"
end

# => "No beer for you!"
```

Também é possível escrever uma expressão `if` numa só linha. Repara na vírgula depois da condição.

```elixir
if age > 16, do: "beer", else: "no beer"
```

Esta sintaxe é útil para expressões muito curtas, mas deve ser evitada se a expressão não couber numa só linha.

## _Truthy_ e _falsy_

No Elixir, todos os tipos de dados são avaliados como um valor _truthy_ ou _falsy_ quando aparecem num contexto booleano (como uma expressão `if`). Todos os dados são considerados _truthy_, **exceto** `false` e `nil`. Em particular, as strings vazias, o número inteiro `0` e as listas vazias são todos considerados _truthy_ no Elixir.
