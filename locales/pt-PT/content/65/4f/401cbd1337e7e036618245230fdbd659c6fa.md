# Sobre

Pode ser difícil encontrar uma linguagem de programação mais expressiva. O [Raku](https://raku.org/) é uma linguagem moderna e multiparadigma. O Raku oferece metodologias [procedurais](https://docs.raku.org/language/functions), [orientadas a objetos](https://docs.raku.org/language/objects) e de [programação funcional](https://docs.raku.org/language/functions#Functions_are_first-class_objects).

[Tens curiosidade?](https://raku.org/) Explora mais a [documentação](https://docs.raku.org/) ou o [repositório](https://raku.land/) de módulos (como o pypi ou o CPAN).

É uma linguagem extremamente [flexível](https://docs.raku.org/language/operators), que se [adapta](https://docs.raku.org/language/glossary#gradual_typing) ao teu estilo de programação, seja para [programas de uma linha](https://docs.raku.org/language/create-cli) rápidos para administradores de sistemas, scripts para gerir uma importação de base de dados, ou a pilha completa de módulos necessária para criar um [site inteiro](https://cro.services/).

O Raku aprende com outras linguagens:

* Reforça o apelo duradouro do Perl com um sistema de objetos a sério, incluindo [roles](https://docs.raku.org/language/typesystem#role), [threading](https://docs.raku.org/language/concurrency) e despacho [multi-método](https://docs.raku.org/language/glossary#Multi-dispatch).
* Vai buscar o threading ao Java, simplificado a um punhado de métodos.
* A utilização de interfaces de [função externa](https://docs.raku.org/language/nativecall) do Lisp torna o acesso a bibliotecas tão simples como uma linha de código.
* As [expressões regulares](https://docs.raku.org/language/regexes) agora vão até ao 11, com a introdução das [gramáticas](https://docs.raku.org/language/grammars) de expressões de análise, que te permitem enfrentar enormes tarefas de análise sintática.
* As restrições e os avisos agora são automáticos, eliminando uma enorme quantidade de erros potenciais.
* ... e ainda sabe fazer [matemática](https://docs.raku.org/language/math): ```1/10 * 3 == 0.3 ``` - experimenta na tua linguagem preferida!

Os lemas do Raku:
* "O Raku foi concebido para facilitar as tarefas fáceis, sem tornar impossíveis as tarefas difíceis."
* "Há mais do que uma forma de fazer as coisas - agora com ainda mais -Ofun (otimizado para a diversão) acrescentado."
