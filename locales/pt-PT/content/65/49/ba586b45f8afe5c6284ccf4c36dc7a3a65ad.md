# Anexo às instruções

## Palavras

Define um tuplo `triangle` com os campos `a`, `b` e `c`.

- `<triangle> ( a b c -- triangle )`: constrói um triângulo a partir de três comprimentos de lado.
- `equilateral? ( triangle -- ? )`
- `isosceles? ( triangle -- ? )`
- `scalene? ( triangle -- ? )`

Cada predicado devolve `f` para triângulos que violam a desigualdade triangular ou que têm um lado não positivo.
