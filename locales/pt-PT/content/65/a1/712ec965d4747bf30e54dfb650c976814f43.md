# Classes e propriedades readonly

As classes e propriedades readonly permitem especificar propriedades públicas de acesso fácil, mas impedem a sua modificação.
Para declarar uma propriedade como readonly, é preciso acrescentar `readonly` antes da especificação do tipo.
A propriedade pode ser atribuída uma vez, mas qualquer tentativa de a reatribuir ou modificar o valor origina um Error.

```php
<?php

class Block
{
    public function __construct(
        public readonly int $length,
        public readonly int $width,
    ) {
    }
}
```

As classes readonly baseiam-se neste comportamento e, quando declaradas como `readonly`, aplicam a declaração de apenas leitura a cada propriedade.
Além disso, impedem a adição de propriedades dinâmicas.

```php
<?php

readonly class Block
{
    public function __construct(
        public int $length,
        public int $width,
    ) {
    }
}
```
