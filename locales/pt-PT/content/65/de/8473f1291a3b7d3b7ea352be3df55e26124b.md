# Sobre

Uma definição de tipo cria um novo tipo com nome, distinto de qualquer outro tipo, mesmo de um que tenha o mesmo tipo subjacente.

## Definir tipos

Uma definição de tipo começa com a palavra-chave `type`, seguida do nome do novo tipo e do seu tipo subjacente:

```go
type File []bool
```

Aqui, `File` refere-se a uma coluna vertical de um tabuleiro de xadrez, habitualmente identificada de A a H.
Cada casa desta coluna é representada por um valor Boolean que assinala se está ocupada ou não.
Agora que `File` está definido, podemos usá-lo noutras definições:

```go
type Chessboard map[string]File

board := Chessboard{
    "A": File{true, false, true},
    "B": File{false, true, false},
}
```

`Chessboard` associa identificadores de coluna a valores `File`.
Cada `File` é uma slice de valores Boolean que representa as casas de uma coluna do tabuleiro.
Sem estas definições de tipo, `board` seria um `map[string][]bool`, o que dificultaria perceber o que estamos a representar.

## Tipos definidos são distintos

Embora `Score` e `int` contenham ambos valores inteiros, passar de um para o outro exige uma conversão explícita:

```go
type Score int

var number int = 42

// var score Score = number is a compile error
var score Score = Score(number)
var converted int = int(score)
```

`42` é uma constante sem tipo, por isso pode ser atribuída diretamente a uma variável `Score`.

Os tipos definidos também podem ter métodos, que são abordados no conceito Métodos.

## Tipos struct

As definições de struct usam a mesma palavra-chave `type`:

```go
type Player struct {
    Name  string
    Score Score
}
```

Os tipos struct são abordados no conceito Structs.

## Aliases de tipo

Um alias de tipo cria um novo nome para um tipo já existente, em vez de criar um tipo novo.
Como um alias e o tipo original são idênticos, os seus valores podem ser usados indistintamente.
Os aliases declaram-se com a palavra-chave `type`, o nome do alias, o sinal de igual (`=`) e o tipo existente.

```go
type Square = bool

var isOccupied bool = true
var square Square = isOccupied // no conversion needed
```
