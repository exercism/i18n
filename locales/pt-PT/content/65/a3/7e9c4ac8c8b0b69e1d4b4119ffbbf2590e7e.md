# Introdução

Em Gleam, uma expressão `case` pode ser usada para executar código de forma condicional. Com uma expressão case, um valor pode ser testado contra um ou mais _padrões_. Um exemplo desses padrões é o _padrão literal_, que compara um valor com um valor literal (por exemplo, `1` ou `"hello"`).

As expressões case escrevem-se com a palavra-chave `case`:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    1 -> "One"
  }
}
```

Embora isto possa parecer-se com as instruções `switch` de outras linguagens, a correspondência de padrões começa a brilhar quando usas também outros padrões. Um desses padrões é o _padrão de variável_, que permite atribuir um valor a uma variável. Neste exemplo, a variável `i` recebe o valor de `number` se este não for `0`:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i -> "Non zero"
  }
}
```

Em alguns casos, podes querer adicionar uma condição adicional a um padrão. Isto é conhecido como uma _guarda_ (cláusula), que pode ser adicionada com a palavra-chave `if`:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i if i < 0 -> "Negative number"
  }
}
```

Por razões de desempenho, só são permitidos operadores matemáticos e booleanos básicos nas guardas. Outras funções não podem ser usadas nas guardas.

No exemplo acima, nem todos os valores de entrada possíveis terão um padrão correspondente. O compilador deteta isto e mostra um erro. Isto é conhecido como _verificação exaustiva_. Para resolver o aviso, tens de tratar todos os casos. Para isso, podes usar o _padrão de descarte_, que é um padrão que corresponde a qualquer valor:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i if i < 0 -> "Negative number"
    _ -> "Positive number"
  }
}

// No compiler error
```

As expressões case testam um valor contra cada padrão, de cima para baixo, até encontrarem um padrão correspondente e executarem a lógica associada a esse padrão. A ordem dos padrões importa!
