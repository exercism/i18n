# Introdução

Uma definição `:` pode chamar-se a si própria diretamente. O compilador de Factor infere o efeito de pilha das palavras recursivas tal como faz para qualquer outra palavra. Não é precisa nenhuma declaração especial para recursão simples.

```factor
: total ( seq -- sum )
    [ 0 ] [ unclip swap total + ] if-empty ;

{ 4 0 9 0 5 } total .    ! => 18
```

As duas metades são o *caso base* da recursão (aqui, a sequência vazia soma `0`) e o *passo recursivo* (retira um elemento, faz a recursão sobre o resto, combina os resultados).

`if-empty` e `unclip` são os companheiros canónicos da recursão sobre sequências. `if-empty ( seq emptyquot nonemptyquot -- )` executa uma de duas quotations consoante a sequência; `unclip` retira o primeiro elemento para que o passo recursivo tenha algo mais simples.
