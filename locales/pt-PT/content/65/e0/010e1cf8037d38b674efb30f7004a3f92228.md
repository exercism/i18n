# Como contribuir através do GitHub

As contribuições para o código do Exercism fazem-se através do [GitHub][github].

Como o nome indica, o GitHub usa o [git][git] como sistema de controlo de versões.
Se não estás familiarizado com o Git, o melhor recurso online é o [Pro Git][pro-git].

Caso não estejas familiarizado com o GitHub e com o fluxo de trabalho de contribuição, aqui estão alguns recursos que te podem ajudar a começar:

- [Introdução ao GitHub - Curso interativo][github-course]
- [Como criar um pull request no GitHub - Tutorial][pr-tutorial]
- [Como fazer um PR simples no GitHub - Vídeo de anthonywritescode][anthonywritescode]

## Guias

Podes ler mais sobre como garantir que a tua contribuição é bem-vinda no guia [Como fazer um ótimo pull request][great-pr].

Temos também vários guias de pull requests específicos do Exercism:

- [Como fazer um ótimo pull request][how-to-make-a-great-pr]

- [O guia de pull requests para responsáveis pela manutenção][maintainers-pr-guide]
- [Permissões de repositório para responsáveis pela manutenção][maintainers-repo-permissions]
