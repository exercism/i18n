# Aprender

Queres começar com Groovy, ou aprender mais enquanto trabalhas nos exercícios?

Experimenta o Groovy com

* [um navegador com um intérprete online](https://www.jdoodle.com/execute-groovy-online)
* a [Groovy Console](http://groovy-lang.org/groovyconsole.html), escrevendo `groovyConsole` numa linha de comandos
* a [Groovy Shell](http://groovy-lang.org/groovyconsole.html), escrevendo `groovysh` numa linha de comandos

Dá uma vista de olhos rápida ao Groovy com

* o [Groovy Tutorial for Java Developers](https://www.timroes.de/2015/06/27/groovy-tutorial-for-java-developers/) de Tim Rows, igualmente bom para quem não programa em Java
* [Learn X in Y minutes, Where X=Groovy ](https://learnxinyminutes.com/docs/groovy/)
* o [Groovy Basics](http://docs.smartthings.com/en/latest/getting-started/groovy-basics.html) da SmartThings
* alguns dos [online Groovy Koans](http://www.groovy-koans.org/) da JDriven

Aprofunda com

* a [Groovy Documentation](http://www.groovy-lang.org/documentation.html)
* [Groovy In Action](https://www.manning.com/books/groovy-in-action-second-edition), _O Livro_ sobre Groovy
* [Making Java Groovy](https://www.manning.com/books/making-java-groovy), de Ken Kousen
