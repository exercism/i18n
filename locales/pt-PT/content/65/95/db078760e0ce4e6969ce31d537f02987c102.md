# Anexo às instruções

## Implementação

Define duas funções: (Duas? Sim, às vezes pedimos mais ao Go.)

All devolve uma lista de todas as substrings de s com comprimento n.

`All(n int, s string) []string`

UnsafeFirst devolve a primeira substring de s com comprimento n.

`UnsafeFirst(n int, s string) string`

Neste momento, podes considerar este exercício concluído e seguir em frente.

Mas espera, talvez faças uma pergunta razoável: porque é que a função se chama **Unsafe** First? Se estiveres interessado, continua a ler para um exercício bónus.

## Exercício bónus

Quando conseguires que o `go test` passe, experimenta `go test -tags asktoomuch`.
Isto usa uma _etiqueta de compilação_ para ativar um teste que não estava ativado antes.
As etiquetas de compilação permitem selecionar os ficheiros que o pacote vai usar.
No nosso caso, vão controlar quais os ficheiros de teste que são usados.
Podes ler mais sobre isto na [documentação do Go](https://golang.org/pkg/go/build/#hdr-Build_Constraints).

Podes notar que não consegues satisfazer este teste _asktoomuch_.
Precisamos de uma forma de sinalizar que, em alguns casos, não podes obter os primeiros N carateres da string.
UnsafeFirst não consegue fazer isso, porque só devolve uma string.

Para resolver isso, vamos adicionar outro valor devolvido à função.
Define `First(int, string) (first string, ok bool)` e testa com `go test -tags first`.

O segundo argumento de retorno `ok bool` é um padrão comum e idiomático em Go.
Por exemplo, encontras isso em [consultas de mapas](https://blog.golang.org/go-maps-in-action) e [asserções de tipos](https://tour.golang.org/methods/15).
