# Anexo às instruções

## Palavras

Define um tuplo `robot` com os campos `x`, `y` e `direction`. O campo `direction` contém um dos símbolos `north`, `east`, `south` ou `west` (declarados no vocabulário deste exercício).

- `<robot> ( x y direction -- robot )`: constrói um robô.
- `move ( robot instructions -- robot )`: aplica uma string de instruções `R`, `L` e `A` e devolve o robô atualizado.
