# Introdução

Uma `string` em Clojure é uma string Java: um objeto que representa texto imutável como uma sequência de carateres Unicode (letras, algarismos, pontuação, etc.).

A biblioteca `clojure.string` fornece muitas funções padrão de manipulação e processamento de strings. Além disso, todos os métodos Java habituais para operar sobre strings estão disponíveis através de interoperabilidade.
