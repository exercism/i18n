# Dicas

## Geral

- Podes usar a [classe Random][random-class] para gerar números aleatórios.
- Lê mais no artigo: [Geradores de números aleatórios no Java 17][random-number-generators].

## Geração de labirintos

Podes usar qualquer algoritmo para gerar um labirinto perfeito. O [recursive backtracker][recursive-backtracker] é uma boa escolha.

## Carateres de desenho de caixas

| Caráter | Nome                                   | Unicode |
|:---------:|:--------------------------------------|:--------|
|     ┌     | desenhos de caixa, traço leve, para baixo e para a direita |  U+250C |
|     ─     | desenhos de caixa, traço leve, horizontal |  U+2500 |
|     ┬     | desenhos de caixa, traço leve, para baixo e horizontal |  U+252C |
|     ┐     | desenhos de caixa, traço leve, para baixo e para a esquerda |  U+2510 |
|     │     | desenhos de caixa, traço leve, vertical |  U+2502 |
|     └     | desenhos de caixa, traço leve, para cima e para a direita |  U+2514 |
|     ┴     | desenhos de caixa, traço leve, para cima e horizontal |  U+2534 |
|     ┘     | desenhos de caixa, traço leve, para cima e para a esquerda |  U+2518 |
|     ├     | desenhos de caixa, traço leve, vertical e para a direita |  U+2520 |
|     ⇨     | seta branca para a direita |  U+21E8 |
