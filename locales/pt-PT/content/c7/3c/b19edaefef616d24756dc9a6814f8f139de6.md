## Tupla

[Tuplas][tuple] são usadas frequentemente para agrupar informação, diferem das listas por terem tamanho fixo e poderem conter tipos de dados diferentes.
As tuplas criam-se usando parênteses curvos, `()`, e são frequentemente usadas para devolver vários valores a partir de uma função.

```haskell
tuple = (1, "abc", False)
```

Isto pode ser útil quando, por exemplo, queres guardar uma coordenada num espaço 2D; assim sabes que a tupla terá sempre dois elementos, as coordenadas x e y.

```haskell
coordinate = (3, 4)
```

### Acesso aos elementos

Muitas vezes trabalhas com tuplas curtas, e podes aceder aos elementos usando as funções `fst` e `snd`.

```haskell
x = fst coordinate
-- x = 3
y = snd coordinate
-- y = 4
```

## Correspondência de padrões

Ao escrever funções em Haskell, podemos usar um [estilo assertivo][assertive-style] com [correspondência de padrões][pattern-match-doc]:
A correspondência de padrões é uma funcionalidade muito poderosa do Haskell que te permite fazer corresponder construtores de dados e ligar variáveis aos valores que estão dentro deles.
Como o nome sugere, o que fazemos é comparar valores com padrões e, se o valor corresponder ao padrão, podemos ligar variáveis aos valores dentro do padrão.
A correspondência de padrões baseia-se principalmente nestes conceitos: reconhecer valores, ligar variáveis e decompor valores.

Vê esta função, por exemplo:

```haskell
lucky :: Int -> String
lucky 7 = "Lucky number seven!"
lucky x = "Sorry, you're out of luck, pal!"
```

Aqui temos uma função `lucky` que recebe um `Int` e devolve uma `String`.
Definimos dois padrões para a função, um que corresponde ao número `7` e outro que corresponde a qualquer outro número; o nome pode ser o que quiseres (desde que siga a convenção de nomenclatura do Haskell), mas aqui usamos `x`.
Se o número for `7`, a função devolve `"Lucky number seven!"`; caso contrário, devolve `"Sorry, you're out of luck, pal!"`.
É importante notar que os padrões são verificados de cima para baixo, por isso, se tivéssemos trocado a ordem dos padrões, a função devolveria sempre `"Lucky number seven!"`.

### Padrões de listas

Um padrão muito comum é fazer correspondência com listas, o que consiste em obter a cabeça e a cauda da lista.
Isto deve-se à natureza das listas: são listas ligadas.
Eis um exemplo de uma função que devolve a cabeça e a cauda de uma lista:

```haskell
headAndTail :: [Int] -> (Int, [Int])
headAndTail [] = error "Can't call head on an empty list"
headAndTail (x:xs) = (x, xs)
```

Temos aqui dois padrões, um que corresponde a uma lista vazia e outro que corresponde a uma lista com pelo menos um elemento.
Isto acontece porque, se a lista estiver vazia, precisamos de ter um caso para isso; caso contrário, obteríamos um erro em tempo de execução.
Se a lista não estiver vazia, podemos fazer corresponder a cabeça da lista com `x` e a cauda da lista com `xs`.
Isto é feito com o operador `:` (cons), que serve para acrescentar um elemento ao início de uma lista.
Mas, na correspondência de padrões, permite decompor uma lista na sua cabeça e cauda, ou seja, de certa forma faz o inverso.

O `xs` é um nome comum para a cauda de uma lista, realça que é uma lista; mas, se estiveres a trabalhar com uma lista aninhada, podes usar `xss` para realçar que é uma lista de listas.

### Padrões de tuplas

Tal como com as listas, também podemos fazer correspondência com tuplas.
Eis um exemplo de uma função que recebe uma tupla e devolve o primeiro e o segundo elemento:

```haskell
sumTuple :: (Int, Int) -> Int
sumTuple (x, y) = x + y
```

Aqui temos um padrão que corresponde a uma tupla com dois elementos; o primeiro elemento é ligado a `x` e o segundo elemento é ligado a `y`.

### Padrões wildcard

Às vezes não nos importamos com o valor de uma variável, só queremos fazer correspondência com o padrão.
É aqui que entra o padrão wildcard, que é representado por um sublinhado `_`.

Eis um exemplo de uma função que devolve o primeiro elemento de uma lista:

```haskell
head' :: [Int] -> Int
head' [] = error "Can't call head on an empty list"
head' (x:_) = x
```

Aqui dizemos que não precisamos da cauda da lista, por isso usamos o padrão wildcard para a ignorar.

### Padrões de tipos

Também podemos fazer correspondência com tipos, o que é feito usando o construtor desse tipo.
Também podemos extrair valores do tipo, como fizemos com as tuplas.

```haskell
data AccountType = Guest | User String 

greet :: AccountType -> String
greet Guest = "Welcome, guest!"
greet (User name) = "Welcome, " ++ name ++ "!"
```

No primeiro padrão, fazemos correspondência com o construtor `Guest`; no segundo padrão, fazemos correspondência com o construtor `User` e ligamos o valor que está dentro a `name`.
