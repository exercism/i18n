## Editores

### Gratuitos / de código aberto

- [VS Code](https://code.visualstudio.com)

  O VS Code é um editor de código aberto. Podes encontrar informações sobre como configurar o TypeScript [aqui](https://code.visualstudio.com/docs/languages/typescript). O VS Code é um editor popular para TypeScript porque a Microsoft mantém tanto o VS Code como o TypeScript, por isso funciona bem com a linguagem; o VS Code suporta TS sem qualquer configuração extra. Na verdade, o VS Code foi escrito com TypeScript!

  Um problema comum com o VS Code e o TS é quando as versões do teu editor e do projeto são diferentes, o que pode fazer com que o VS Code mostre uma mensagem de erro possivelmente confusa. As instruções sobre como lidar com este erro estão [aqui](https://code.visualstudio.com/docs/typescript/typescript-compiling#_using-newer-typescript-versions)

### Licenciados

- [Sublime Text](https://www.sublimetext.com)

  O Sublime Text é um editor de código popular com suporte para a maioria das linguagens através de plugins instaláveis. É gratuito para experimentar, mas serás regularmente solicitado a comprar uma licença, que atualmente custa \$70 USD.

- [WebStorm](https://www.jetbrains.com/webstorm/)

  O WebStorm é um IDE (Ambiente de Desenvolvimento Integrado) completo para JavaScript/TypeScript. Suporta TypeScript sem qualquer configuração extra e tem testes, debug e análise de código integrados. É gratuito para experimentar durante 30 dias, depois uma licença anual custa \$129 USD no primeiro ano.
