# Anexo às instruções

Em [concept:python/unpacking-and-multiple-assignment](https://github.com/exercism/python/tree/main/concepts/unpacking-and-multiple-assignment), aprendeste várias técnicas para trabalhar com `lists`/`tuples` de comprimento arbitrário, bem como com argumentos de funções de comprimento arbitrário.
Este exercício é um ótimo sítio para praticar essas técnicas.

## Como este exercício está implementado para Python

Os casos de teste deste track adicionam um argumento nomeado adicional chamado `qualifier`.
Deves usar o valor deste argumento nomeado para modificar o último verso do teu provérbio.
