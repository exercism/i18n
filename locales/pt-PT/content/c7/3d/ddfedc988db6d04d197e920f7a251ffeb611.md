Os blocos de código são usados abundantemente em Raku.
São fundamentais para as funções, mas também aparecem em ferramentas como `grep` e `map`, como blocos de instruções `if`, `for`, `while` e `given`, e até em índices de arrays.

## Rotinas

[`Subs`][type/Sub] e [`Methods`][type/Method] são tipos de [`Routines`][type/Routine] em Raku.

Uma rotina pode terminar em qualquer momento com um valor devolvido, usando a palavra-chave [`return`][control-return], uma ferramenta útil para criar funções.
Se não especificares nenhum `return`, a última instrução da rotina será o seu valor devolvido implícito.

Uma rotina pode ter uma [`Signature`][language/signatures] entre parênteses, antes do bloco de código.

[`Routine`][type/Routine] é uma subclasse de [`Block`][type/Block].

```raku
sub add ($x, $y --> Int) { return $x + $y }
say add(1, 2); # 3
```

Os métodos serão abordados num conceito separado, relacionado com classes e objetos.

## Blocos

Um [`Block`][type/Block] é um objeto de código reutilizável, normalmente usado para criar lambdas.

A última instrução de um bloco é o seu valor devolvido implícito.

Um bloco pode ter uma [`Signature`][language/signatures] precedida de `->` antes do bloco de código.

[`Block`][type/Block] é uma subclasse de [`Code`][type/Code], que é a classe base fundamental de todos os objetos de código em Raku.

```raku
my $add = -> $x, $y { $x + $y };
say $add(1, 2); # 3
```

## Assinaturas

Uma [`Signature`][language/signatures] é composta por zero ou mais [`Parameters`][type/Parameter], separados por vírgulas.

No fim de uma assinatura, podes especificar um tipo de retorno com uma [seta de tipo de retorno][signatures-return-type-arrow] `-->`.

Uma assinatura pode ser usada para especificar os argumentos que um `Block` aceita.

Neste conceito, vamos manter as assinaturas simples, usando apenas parâmetros posicionais com variáveis de sigilo escalar e um tipo de retorno.
Estes serão aprofundados noutros conceitos.

## Multi-Dispatch

Em Raku, podes escrever várias rotinas com o mesmo nome mas com assinaturas diferentes, usando a palavra-chave `multi`.
Esta funcionalidade é conhecida como [multi-dispatch][multi-dispatch].
Quando a rotina é chamada pelo nome, o ambiente de execução determina o candidato adequado e invoca-o.

Isto será abordado com mais detalhe num conceito sobre tipos.

```raku
multi foo () { say 'No arguments given'}

multi foo ($bar) { say "One argument given: $bar" }
```

## WhateverCode

Quando o asterisco [`Whatever`][type/Whatever] `*` é usado em combinação com a maioria dos operadores, é criado um objeto [`WhateverCode`][type/WhateverCode].
Isto permite-te criar blocos com uma sintaxe mais simples.

```raku
# These will all give code blocks that increment a single argument by 1:
-> $x { $x  + 1 }; # Explicit signature
      { $^x + 1 }; # Signature via placeholder variable
      { $_  + 1 }; # Topic variable
          * + 1;   # WhateverCode
```
