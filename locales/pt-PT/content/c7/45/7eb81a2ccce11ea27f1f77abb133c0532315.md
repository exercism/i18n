# Dicas

## Geral

- Todos os nomes aqui terminam em `!`, e todos entregam valores com `yield`
  em vez de `return`.
- Marca os argumentos como `once`. Nada aqui quer um argumento reavaliado
  a cada volta.
- Testa um deles escrevendo um ciclo à volta dele. Um iterador não pode ser
  chamado sozinho, por isso não há nada para imprimir sem um `loop`.

## 1. Os marcadores

- Um `loop` dentro do iterador, controlado por `1.upto!(count)`, que entrega
  `spacing` vezes o número.
- Não é preciso nada de especial para uma contagem de zero: `1.upto!(0)` não
  dá nada, por isso o ciclo interior acaba de imediato e o iterador termina.

## 2. Até o trilho acabar

- Percorre o array com `elt!` e usa `quit` quando o valor for `"end"`.
- A ordem importa: `quit` antes do `yield`, ou o `"end"` é entregue antes de
  parares.
- Não é preciso nada para um array sem `"end"` lá dentro. O `elt!` esgota-se
  e o iterador termina.

## 3. Só as aves

- Percorre o array e usa `yield` apenas dentro de um `if`. Uma volta que não
  entrega nada dá simplesmente outra volta. Um iterador não é obrigado a
  entregar de cada vez.
- Um nome começa com maiúscula quando `.is_upper` é verdadeiro para o seu
  primeiro caráter.
- Protege-te contra strings vazias antes de ires buscar o primeiro caráter.

## 4. Numerados

- Dois iteradores dentro do teu próprio iterador: `1.up!` para o número e
  `elt!` para o avistamento. É o emparelhamento do `duet-practice`, agora
  dentro de algo que escreveste.
- Constrói a string com `+`. O número vem primeiro, por isso começa com
  `number.str`, já que se pode adicionar um número a uma string, mas não o
  contrário.
