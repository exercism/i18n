# Binário, octal e hexadecimal

Binário, octal e hexadecimal (_também conhecido como hex_) são [sistemas de numeração][numeral-systems] diferentes, com bases diferentes.
O binário é de base 2, o octal é de base 8 e o hexadecimal é de base 16.
Os números inteiros normais são de base 10 em Crystal.
Binário, octal e hexadecimal são todos representações de números inteiros.
Isto significa que representam números positivos e negativos (_incluindo o zero_) sem frações nem decimais e que suportam todas as operações que conseguimos fazer com números inteiros.

## Binário

O [binário][binary] é um sistema de numeração de base 2, que usa apenas os algarismos 0 e 1.
Representa habitualmente os estados 0 («desligado») e 1 («ligado») do fluxo elétrico através de transístores e interruptores nos computadores, bem como as cargas positivas e negativas nos suportes de armazenamento magnético.
O binário consegue representar todos os números inteiros que se usam em base 10.

Um excerto do sistema de base 2 tem este aspeto, embora continue infinitamente e não pare em 128:

| 128      | 64       | 32       | 16       | 8        | 4        | 2        | 1        |
| -------- | -------- | -------- | -------- | -------- | -------- | -------- | -------- |
| 2 \*\* 7 | 2 \*\* 6 | 2 \*\* 5 | 2 \*\* 4 | 2 \*\* 3 | 2 \*\* 2 | 2 \*\* 1 | 2 \*\* 0 |

Por isso, se quisermos representar o número 6, em binário seria: 110

| Valor posicional | 4   | 2   | 1   |
| ---------------- | --- | --- | --- |
| Número binário   | 1   | 1   | 0   |

E a operação seria: `4 + 2 + 0 = 6`

Outro exemplo: 19

| Valor posicional | 16  | 8   | 4   | 2   | 1   |
| ---------------- | --- | --- | --- | --- | --- |
| Número binário   | 1   | 0   | 0   | 1   | 1   |

O número binário seria: 10011
E a operação seria: `16 + 0 + 0 + 2 + 1 = 19`

## Binário em Crystal

Em Crystal, podemos representar literais binários com o prefixo `0b`.
Se escrevermos `0b10011`, o Crystal interpreta-o como um número binário e converte-o para base 10.

```crystal
0b10011
# => 19

typeof(0b10011)
# => Int32
```

Se escreveres um número com o prefixo `0b` que não pertença ao sistema binário, isso vai dar origem a um erro de compilação.

```crystal
0b10211
# => Error: unexpected token: "211"
```

### Operações com números binários

Como os números binários são números inteiros, podemos fazer com eles todas as operações que fazemos com números inteiros.

```crystal
0b10011 + 0b10011
# => 38

0b10011 * 0b10011
# => 361

0b10011 / 3
# => 6.333333333333333
```

### Converter para e a partir da representação binária

O Crystal converte automaticamente um literal binário em `Int32`.
Para converteres um `Int32` numa representação binária, usa o método [`<int>.to_s(base)`][to_s] com o argumento da base definido como 2.
O método devolve uma representação em string do número binário:

```crystal
19.to_s(2)
# => "10011"
```

Para converteres a representação em string de um número binário num número inteiro, podes usar o método [`<int>.to_i(base)`][to_i], passando a base (2) como argumento:

```crystal
"10011".to_i(2)
# => 19
```

Indicar a base errada (_ou uma representação binária inválida_) dá origem a um `ArgumentError`:

```crystal
"011021".to_i(2)
# => Invalid Int32: "011021" (ArgumentError)
```

### Métodos para números binários

Há alguns métodos que podes usar com números inteiros para obteres informações sobre a representação binária do número.

[`<int>.bit_length`][bit_length] devolve o número de bits necessários para representar o número:

```crystal
19.bit_length
# => 5
```

[`<int>.bit(index)`][bit] devolve o bit no índice indicado, a começar pela direita (_bit menos significativo_):

```crystal
19.bit(0)
# => 1

0b10011.bit(1)
# => 1
```

## Octal

O [octal][octal] é um sistema de numeração de base 8.
Usa os algarismos 0, 1, 2, 3, 4, 5, 6 e 7.

Em Crystal, podemos representar números octais com o prefixo `0o`.
Tal como no binário, o Crystal converte automaticamente uma representação octal num `Int32`.

```crystal
0o123
# => 83
```

Colocar o prefixo `0o` num número que não pertença ao sistema octal dá origem a um erro de compilação.

### Converter para e a partir da representação octal 

Tal como no binário, podemos usar o método [`<int>.to_s(base)`][to_s] para converter um `Int32` numa representação octal.
E podemos usar o método [`<int>.to_i(base)`][to_s] para converter uma representação octal num `Int32`.

```crystal
83.to_s(8)
# => "123"

"123".to_i(8)
# => 83
```

Tal como no binário, indicar a base errada dá origem a um `ArgumentError`.

## Hexadecimal

O [hexadecimal][hexadecimal] é um sistema de numeração de base 16.
Usa os algarismos 0 a 9 e as letras A, B, C, D, E e F.
A corresponde a 10, B a 11, C a 12, D a 13, E a 14 e F a 15.

Podemos representar números hexadecimais em Crystal com o prefixo `0x`.
Tal como no binário e no octal, o Crystal converte automaticamente os literais hexadecimais em `Int32`.

```crystal
#=> 0x123
291
```
 
Colocar o prefixo `0x` num número não hexadecimal dá origem a um erro de compilação.

###  Converter para e a partir da representação hexadecimal

Tal como no binário, podemos usar o método [`<int>.to_s(base)`][to_i] para converter um `Int32` numa representação hexadecimal.
E podemos usar o método [`<int>.to_i(base)`][to_s] para converter uma representação hexadecimal num `Int32`.

```crystal
291.to_s(16)
# => "123"

"123".to_i(16)
# => 291
```

Tal como no binário e no octal, indicar a base errada dá origem a um `ArgumentError`.

## Precisão

Ao converteres um número numa representação em string, podes especificar a precisão do número.
Ou seja, a quantidade **mínima** de algarismos usada para representar o número.
Se o número tiver menos algarismos do que a precisão, são acrescentados zeros à esquerda na representação em string.
Isto faz-se passando o argumento `precision` ao método [`<int>.to_s(<base>, precision: <value>)`][to_s].

```crystal
291.to_s(16, precision: 5)
# => "00123"

543.to_s(precision: 2)
# => "543"
```

## Upcase

Ao converteres um número numa representação em string, podes especificar se queres que as letras na string fiquem em maiúsculas.
Isto faz-se passando o argumento `upcase` ao método [`<int>.to_s(<base>, upcase: <value>)`][to_s].

```crystal
255.to_s(16, upcase: true)
# => "FF"

255.to_s(16, upcase: false)
# => "ff"
```
