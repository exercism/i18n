# Instruções

O teu amigo Chandler planeia visitar países exóticos de todo o mundo. Infelizmente, o Chandler não é bom a matemática. Está bastante preocupado em ser enganado pelas casas de câmbio durante a viagem, e quer que lhe faças uma calculadora de moedas. Aqui estão as especificações dele para a aplicação:

## 1. Estimar o valor após o câmbio

Cria a função `exchange_money()`, que recebe 2 parâmetros:

1. `budget` : O orçamento que planeias trocar.
2. `exchange_rate` : A quantia de moeda nacional equivalente a uma unidade de moeda estrangeira.

Esta função deve devolver o valor da moeda trocada.

**Nota:** Se a tua moeda for USD e quiseres trocar USD por EUR com uma taxa de câmbio de `1.20`, então `1.20 USD == 1 EUR`.

```python
>>> exchange_money(127.5, 1.2)
106.25
```

## 2. Calcular a moeda que sobra após um câmbio

Cria a função `get_change()`, que recebe 2 parâmetros:

1. `budget` : O orçamento antes do câmbio.
2. `exchanging_value` : A quantia de dinheiro que é *retirada* do orçamento para ser trocada.

Esta função deve devolver o dinheiro que *sobra* do orçamento.

```python
>>> get_change(127.5, 120)
7.5
```

## 3. Calcular o valor das notas

Cria a função `get_value_of_bills()`, que recebe 2 parâmetros:

1. `denomination` : O valor de uma única nota.
2. `number_of_bills` : O número total de notas.

Este posto de câmbio só trabalha com dinheiro em determinados incrementos.
O total que recebes tem de ser divisível pelo valor de uma "nota" ou unidade, o que pode deixar uma fração ou um resto.
A tua função deve devolver apenas o valor total das notas (_excluindo os montantes fracionários_) que o posto devolveria.
Infelizmente, o posto fica com o resto/troco como bónus extra.

```python
>>> get_value_of_bills(5, 128)
640
```

## 4. Calcular o número de notas

Cria a função `get_number_of_bills()`, que recebe `amount` e `denomination`.

Esta função deve devolver o _número de notas de moeda_ que podes receber dentro do _amount_ indicado.
Por outras palavras: quantas _notas inteiras_ de moeda cabem no montante inicial?
Lembra-te de que só podes receber _notas inteiras_, não frações de notas, por isso não te esqueças de dividir em conformidade.
Na prática, estás a arredondar _por defeito_ para a nota/denominação inteira mais próxima.

```python
>>> get_number_of_bills(127.5, 5)
25
```

## 5. Calcular o que sobra depois de trocar por notas

Cria a função `get_leftover_of_bills()`, que recebe `amount` e `denomination`.

Esta função deve devolver o _montante que sobra_ que não pode ser devolvido do _amount_ inicial, dada a denominação das notas.
É muito importante saber exatamente quanto é que o posto fica a ganhar.

```python
>>> get_leftover_of_bills(127.5, 20)
7.5
```

## 6. Calcular o valor após o câmbio

Cria a função `exchangeable_value()`, que recebe `budget`, `exchange_rate`, `spread` e `denomination`.

O parâmetro `spread` é a *percentagem cobrada* como comissão de câmbio, escrita como um número inteiro.
Tem de ser convertido em decimal, dividindo-o por 100.
Se `1.00 EUR == 1.20 USD` e o *spread* for `10`, a taxa de câmbio real será: `1.00 EUR == 1.32 USD`, porque 10% de 1.20 é 0.12, e esta comissão adicional é somada ao câmbio.

Esta função deve devolver o valor máximo da nova moeda depois de calcular a *taxa de câmbio* mais o *spread*.
Lembra-te de que a *denominação* da moeda é um número inteiro e não pode ser subdividida.

**Nota:** O valor devolvido deve ser do tipo `int`.

```python
>>> exchangeable_value(127.25, 1.20, 10, 20)
80
>>> exchangeable_value(127.25, 1.20, 10, 5)
95
```
