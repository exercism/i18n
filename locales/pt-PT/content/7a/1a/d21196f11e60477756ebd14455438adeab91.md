# Dicas

## Geral

- Volta a ver o [Conceito de Objetos][concept-class-basics], se precisares, para recordar as bases.
- Lê com atenção as instruções sobre a posição dos parâmetros `x`, `y`, `width` e `height`. É fácil confundi-los.

## 1. Define uma classe ProgramWindow

- Lembra-te de usar a [sintaxe de classes][php-class] nesta tarefa.
- Define [propriedades][php-properties] adicionando-as à declaração da classe.

## 2. Define uma função construtora para a classe ProgramWindow

- Verifica se a tua função construtora não aceita quaisquer argumentos.
- Verifica se cada propriedade está a ser definida com o valor inteiro esperado.

## 3. Adiciona um método para redimensionar a janela

- Lembra-te de usar uma nova [classe][php-class] no ficheiro `Size.php` nesta tarefa.
  - Por convenção, os ficheiros costumam conter apenas uma única classe.
- O construtor de `Size` deve aceitar argumentos para os valores iniciais das [propriedades][php-properties] da classe.
- Cria um método `resize` do objeto `ProgramWindow` para aplicar a alteração através de uma instância de `Size`.

## 4. Adiciona um método para mover a janela

- Lembra-te de usar uma nova [classe][php-class] no ficheiro `Position.php` nesta tarefa.
  - Por convenção, os ficheiros costumam conter apenas uma única classe.
- O construtor de `Position` deve aceitar argumentos para os valores iniciais das [propriedades][php-properties] da classe.
- Cria um método `move` do objeto `ProgramWindow` para aplicar a alteração através de uma instância de `Position`.
