# Introdução

Uma `list` em R é uma coleção ordenada de itens, que difere dos `vectors` em alguns aspetos:

- Os itens podem ser de tipos diferentes (por exemplo, misturar `numeric` com `character`).
- Os itens podem ser estruturas complexas (por exemplo, vetores, outras listas, etc.).
- A sintaxe para aceder aos elementos é diferente.

As analogias com outras linguagens são imprecisas.
Uma `list` em R é um pouco parecida com um dicionário de Python, mas a `list` é ordenada e pode ser acedida por um índice numérico.
É também um pouco parecida com um `struct` de C, com a diferença de que a `list` pode ser facilmente ampliada em tempo de execução.

## Criar listas

Dar nomes (a que se chama frequentemente «etiquetas») aos elementos é mais comum em listas do que em vetores:

```R
list(x = 5.3, y = 4.2, color = "blue")
$x
#> [1] 5.3

$y
#> [1] 4.2

$color
#> [1] "blue"
```

No entanto, as etiquetas são opcionais e o R usa então apenas os números dos índices:

```R
list(5.3, 4.2, "blue")
#> [[1]]
#> [1] 5.3

#> [[2]]
#> [1] 4.2

#> [[3]]
#> [1] "blue"
```

## Aceder aos elementos de uma lista

Há três formas de o fazer, cada uma útil em contextos diferentes.

### 1. Com a notação `$tag`

Muito comum quando os nomes das etiquetas são conhecidos à partida.

```R
point <- list(x = 5.3, y = 4.2, color = "blue")
point$x
#> [1] 5.3
point$color
#> [1] "blue"
```

### 2. Com a notação `[[tag]]`

Tem a vantagem de o nome da etiqueta poder ser escolhido em tempo de execução.
Repara que os parênteses retos são duplos.

```R
want <- "y"
point[[want]] # same as point$y
#> [1] 4.2
```

### 3. Com o índice de posição

Funciona quer a lista tenha etiquetas quer não.
Mais uma vez, os parênteses retos são duplos.

```R
point[[3]] # same as point$color
#> [1] "blue"
```

## Adicionar e eliminar elementos

É simples: atribuir um valor a um elemento modifica-o se ele existir ou insere-o se for novo.

```R
point$color <- "red"
point$trust <- TRUE
str(point)
#> List of 4
#>  $ x    : num 5.3
#>  $ y    : num 4.2
#>  $ color: chr "red"
#>  $ trust: logi TRUE
```

Para eliminar, atribui `NULL` ao elemento de que já não precisas.

```R
point$trust <- NULL
str(point)
#> List of 3
#>  $ x    : num 5.3
#>  $ y    : num 4.2
#>  $ color: chr "red"
```
