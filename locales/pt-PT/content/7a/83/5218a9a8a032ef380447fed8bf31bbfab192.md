# Dicas

## Geral

- Não te esqueças de exportar as três sub-rotinas públicas.
  Lista-as no array `@EXPORT_OK`.

## 1. Verifica se uma determinada data está no passado

- Para analisar strings de data, as strings serão fornecidas no formato ISO 8601.
  Usa a variável de pacote `$STRPTIME_FORMAT`.
- Os métodos `Time::Piece->strptime` ou `DateTime::Tiny->from_string` serão úteis.

## 2. Verifica se uma determinada data ocorre à tarde

- A "tarde" começa ao meio-dia e termina antes das 18:00.

## 3. Converte uma data numa string que descreve uma marcação

- Usa `mm/dd/yyyy` como formato de data de saída.
  Por exemplo: 12/31/2021
- O formato de hora de saída usa a hora no intervalo 0-12, sem zero à esquerda nem espaço, e o indicador am/pm em maiúsculas.
  Por exemplo: 7:59 PM
- Se usares o módulo Time::Piece, o método `strftime` é o mais indicado.
