# Testes

Para correr o conjunto de testes:
```bash
tclsh exercise.test
```

## Testes ignorados

Resolver um exercício significa fazer com que todos os seus testes passem. Por predefinição, quando corres os testes só é executado um deles (o primeiro). Isto é intencional, porque te permite concentrar-te apenas em fazer passar esse teste. Assim que passar, podes ativar o teste seguinte comentando ou removendo o comando `skip` que o precede.

Em alternativa, para correr todos os testes independentemente do estado de "ignorados":
```bash
RUN_ALL=1 tclsh exercise.test
```
