# Instalar o `testthat`

Os testes desta track usam o pacote `testthat`.

Para instalar o pacote, basta abrir o R e correr:

`install.packages("testthat")`

Para verificares que o pacote ficou instalado com sucesso, executa:

`library(testthat)`

# Correr os testes

Cada problema terá um script chamado `test_<exercise-name>.R` (por exemplo, `test_hello-world.R`).

Para correr os testes de um exercício, basta executar este script de R.

No RStudio, isto é tão simples como abrir o script de teste e clicar em "Source", no canto superior direito do painel de código-fonte. Isto irá carregar o teu código de solução através do comando `source` na primeira linha do script de teste e, em seguida, executar o conjunto de testes do `testthat` que se seguem.

Nota, no entanto, que o comando `source()` na primeira linha do script de teste só funciona se o teu script de solução (`<exercise-name>.R`) estiver no teu diretório de trabalho. Se não for o caso, tens de:
- alterar o teu diretório de trabalho, por exemplo, `setwd('exercism/r/hello-world/')`, ou
- atualizar a primeira linha do script de teste, por exemplo, `source('exercism/r/hello-world/hello-world.R')`

Se preferires, também podes correr os testes a partir da linha de comandos com `Rscript path_to_exercise_directory/test_<exercise-name>.R` (por exemplo, `Rscript hello-world/test_hello-world.R`).

Outra forma prática de correr estes testes é usar a [função `auto_test` do testthat](https://www.rdocumentation.org/packages/testthat/topics/auto_test). Como o código e os testes do Exercism estão na mesma pasta, usa o mesmo caminho para os parâmetros `code_path` e `test_path`. Depois de correres `auto_test()`, os testes do exercício são executados automaticamente sempre que atualizares ou guardares o teu código R para o exercício. Isto ajuda a iterar rapidamente enquanto trabalhas na tua solução.
