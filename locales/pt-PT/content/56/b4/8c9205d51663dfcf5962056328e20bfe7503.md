# Instruções

A Bellebrook Basketball League é uma liga com várias equipas, cada uma com um plantel de jogadores.
Está prestes a começar uma nova época, e eles precisam de criar um novo sistema de bilhetes para vender bilhetes para os jogos.
Na época passada, vendiam bilhetes à entrada do estádio, mas a popularidade disparou, e este ano decidiram vender bilhetes online para dar resposta ao aumento da procura.

A liga contactou-te e pediu-te para criares um sistema para gerir a venda de bilhetes.

## 1. Cria um sistema de bilhetes

Primeiro, precisas de criar um sistema de bilhetes para gerir a venda de bilhetes.
O sistema de bilhetes tem de indicar quantos bilhetes estão disponíveis para um jogo.

Deve ser criada uma instância de uma classe chamada `TicketSystem` para cada jogo.
O estado inicializado deve conter as seguintes informações:

1. Quantos bilhetes estão disponíveis para o jogo.
2. Em que estádio o jogo se realiza.

Constrói um estado inicializado a partir de argumentos que indiquem o número de bilhetes disponíveis e em que estádio o jogo se realiza.
O estado inicializado deve ser composto pelas variáveis de instância `@tickets_available` e `@stadium`.
Estas devem conter o primeiro e o segundo argumentos dados, respetivamente.

```crystal
TicketSystem.new(100, "Bellebrook")
# => #<TicketSystem:0x10f0b8 @tickets_available=100, @stadium="Bellebrook">
```

## 2. Obtém a quantidade de bilhetes disponíveis

Primeiro, precisas de criar um método que devolva a quantidade de bilhetes disponíveis para um determinado jogo.

Define um módulo chamado `TicketingReservation` acima da classe já definida.
Este módulo deve ser incluído na classe `TicketSystem`.

Dentro do módulo, define um método chamado `tickets_available`.
Este método deve devolver a quantidade de bilhetes disponíveis.

```crystal
ticket_system = TicketSystem.new(100)
ticket_system.tickets_available
#=> 100
```

## 3. Encomendar bilhetes

Tens de criar um método que verifique se há bilhetes disponíveis para um determinado jogo.
O jogo precisa de ter 100 bilhetes de reserva.
Isto serve para garantir que há sempre bilhetes disponíveis para as pessoas que compram bilhetes à entrada do estádio.

Dentro do módulo `TicketingReservation`, define um método chamado `order_ticket?`.
O método deve devolver `true` se estiverem disponíveis pelo menos 100 bilhetes e `false` caso contrário.
Se estiverem disponíveis pelo menos 100 bilhetes, o método também deve diminuir em 1 o número de bilhetes disponíveis.

```crystal
ticket_system = TicketSystem.new(100)
ticket_system.order_ticket?
#=> true
```

## 4. Mensagem da encomenda

O sistema de bilhetes tem de ter mensagens fáceis de compreender para os utilizadores.
E as mensagens devem parecer pessoais, por isso devem incluir o nome do utilizador.

Se a compra do bilhete for bem-sucedida, o utilizador deve receber uma mensagem a informá-lo de que a compra foi bem-sucedida, do seu número de bilhete e do estádio onde o jogo se realiza.
O número do bilhete deve ser o número de bilhetes disponíveis antes da encomenda.

Se a compra for bem-sucedida, a mensagem deve ter este aspeto: `{name}, your purchase was successful, your ticket number is #{ticket_number}, and the game is played at the {stadium_name} stadium.`.
Se a compra não for bem-sucedida, a mensagem deve ter este aspeto: `{name}, your purchase was unsuccessful, there are not enough tickets available.`.

Dentro do módulo `TicketingReservation,` define um método chamado `order_message` que recebe um argumento `name` com o nome do comprador.
O método deve devolver uma string com a mensagem.

```crystal
ticket_system = TicketSystem.new(100, "Bellebrook")
ticket_system.order_message("John")
#=> "John, your purchase was successful, your ticket number is #100, and the game is played at the Bellebrook stadium."
```
