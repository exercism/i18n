# Anexo às instruções

## `Print` não coloca aspas em valores de string

Este exercício envolve manipular pontuações numéricas.
#[a: 1]` and `#[a: "1"]` não são iguais:

```arturo
inspect #[a: 1]
; [ :dictionary
;        a  :        1 :integer
; ]

inspect #[a: "1"]
; [ :dictionary
;        a  :        1 :string
; ]
equal? #[a: "1"] #[a: 1]
; false
```

Uma prática comum de depuração é usar `print` nos valores.
No entanto, a saída não adiciona aspas em torno das strings.
Por isso, uma string numérica como `"1"`, quando impressa, parece igual ao número inteiro `1`.

```arturo
print #[a: 1]
; [a:1]
print #[a: "1"]
; [a:1]
```
No resultado dos testes deste exercício, podes ver um resultado como `:x: equal? [a:1 e:1 i:1 o:1 u:1] [a:1 e:1 i:1 o:1 u:1]`.
Os dois dicionários comparados parecem iguais quando impressos.
No entanto, o primeiro dicionário tem valores de string numéricos e o segundo tem valores inteiros, por isso não são iguais.
Ao depurar, podes usar `inspect` para verificar o conteúdo do teu dicionário.

## `Express` coloca aspas em valores de string

`express` converte um valor em código Arturo e devolve uma string que representa essa representação de código.
Nesse resultado, quaisquer valores de string serão colocados entre aspas.
Como resultado, `express "1"` devolve `"1"`, e não `1`.

```arturo
express #[name: "Octavius" age: 22]
; #[name: "Octavius" age: 22 ]
```
```arturo
express #[name: "Octavius" age: "22"]
; #[name: "Octavius" age: "22" ]
```
