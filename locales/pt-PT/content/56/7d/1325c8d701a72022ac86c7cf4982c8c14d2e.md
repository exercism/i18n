# Sobre

O `Sed` é uma ferramenta tradicional e uma linguagem de programação dos sistemas Unix, usada para fazer transformações de texto num fluxo de entrada (um ficheiro ou a entrada de um pipeline), fazendo uma única passagem sobre a(s) entrada(s) e lendo o texto linha a linha. Este percurso aborda o `sed` como linguagem de programação.

## Principais funcionalidades
+ Comando de substituição `s/<REGEX>/[REPLACEMENT]/[FLAGS]`.
+ [Expressões regulares][regex-wiki].
+ Duas variáveis: **pattern space** e **hold space**.
+ Controlo de fluxo com instruções do tipo goto, *regexps* e endereços de linha.

## Variantes
O `Sed` foi desenvolvido em 1974 e tem algumas implementações clássicas. Este percurso usa a implementação [GNU Sed][sed-home], juntamente com todas as extensões *GNU*, e as [ERE (expressão regular estendida)][ere-info].
