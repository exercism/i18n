# Instruções

O teu amigo acabou de te enviar uma mensagem com um segredo importante.
Para que não fosse fácil para os outros lê-la, a mensagem foi encriptada através de uma série de manipulações de bits.
Vais precisar de escrever as funções que ajudam a desencriptar a mensagem.

## 1. Deslocar os bits de volta

O primeiro passo para desencriptar a mensagem é desfazer o deslocamento feito no processo de encriptação, deslocando os bits de volta para a direita.
Haverá passos seguintes no processo de desencriptação que assumem que os `0`s são inseridos a partir do lado esquerdo.

Implementa a função `shiftBack`, que recebe um número de posições a deslocar e um valor, e efetua o deslocamento.

```elm
shiftBack 2 42 --> 10
```

## 2. Definir alguns bits

De seguida, há alguns bits que precisam de ser definidos como `1`.

Implementa a função `setBits`, que recebe uma máscara e um valor e devolve o resultado de definir como `1` os bits do valor.
Um bit do valor deve ser definido como `1` onde o bit da máscara também for `1`.
Todos os outros bits devem permanecer inalterados.

```elm
setBits 66 212 --> 64
```

## 3. Inverter bits específicos

Alguns bits são invertidos durante a encriptação.
Será preciso invertê-los de volta para desencriptar a mensagem.

Implementa a função `flipBits`, que recebe uma máscara e um valor.
A máscara indica quais os bits do valor a inverter.
Se o bit for `1` na máscara, o bit é invertido no valor.
Todos os outros bits permanecem inalterados.

```elm
flipBits 23 157 --> 138
```

## 4. Limpar bits específicos

Há também determinados bits que desencriptam sempre para 0.

Implementa a função `clearBits`, que recebe uma máscara e um valor.
Os bits do `value` devem ser definidos como 0 onde o bit da máscara for 1.
Todos os outros bits devem permanecer inalterados.

```elm
clearBits 2 15 --> 13
```

## 5. Desencriptar uma mensagem

Agora que tens todas as funções de que precisas, podes descodificar a mensagem do teu amigo.
Implementa a função `decrypt`, que realiza as seguintes operações:

1. Define os bits a partir do ano em que o teu amigo nasceu (1996)
2. Inverte o resultado com o ano em que se conheceram (2009)
3. Desloca os bits de volta pelo número de aulas que têm juntos (5)
4. Limpa o primeiro e o quinto bit.

```elm
decrypt 380182 --> 11840
```

Implementa a função `decrypt` recorrendo a todas as funções que implementaste nas tarefas anteriores.
