# Instruções

Neste exercício, vais aplicar as [regras do jogo de Go](https://matmoore.github.io/learngo/). As regras em si já estão escritas, só precisas de as aplicar para atualizar o Jogo e tratar de erros / violações das regras.

O jogo é representado da seguinte forma:

```gleam
pub type Player {
  Black
  White
}


pub type Game {
  Game(
    white_captured_stones: Int,
    black_captured_stones: Int,
    player: Player,
    error: String,
  )
}
```

Há 4 regras no jogo:

- Cada ponto só pode ter uma pedra.
- As pedras do adversário podem ser capturadas.
- Não podes colocar uma pedra num ponto em que ela se capturaria a si própria.
- Não podes usar o mesmo ponto duas vezes.

## 1. Aplica as regras

Escreve o conteúdo da função `apply_rules`, que recebe um `Game` inicial e um conjunto de regras, e devolve o novo `Game` depois de as regras serem aplicadas.

Três das regras verificam violações das regras e podem devolver um erro, por isso têm o tipo de retorno `Result(Game, String)`. Se alguma destas regras falhar, deve devolver-se o jogo original, mas com o campo `error` atualizado com o erro correspondente.

A outra regra não verifica violações e, por isso, não pode falhar (embora possa devolver um `Game` alterado), pelo que tem o tipo de retorno `Game`.

Se todas as regras passarem, devem manter-se todas as alterações ao `Game` feitas pelas regras e o jogador deve ser alterado.

```gleam
pub fn apply_rules(
  game: Game,
  rule1: fn(Game) -> Result(Game, String),
  rule2: fn(Game) -> Game,
  rule3: fn(Game) -> Result(Game, String),
  rule4: fn(Game) -> Result(Game, String),
) -> Game {
  // -> If all rules pass, return a `Game` with all changes from the rules applied, and change player
  // -> If any rule fails, return the original Game, but with the error field set
}
```
