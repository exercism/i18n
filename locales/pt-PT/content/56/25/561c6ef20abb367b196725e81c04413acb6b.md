# Instalação

Para obteres as instruções de instalação recomendadas para a tua plataforma,
vai ao [the official Rust website].

Ter a toolchain instalada não é tudo!
O suporte de IDE é um enorme ganho de produtividade que a maioria dos programadores já espera ter.
Se usas o Visual Studio Code, consulta a sua [documentação para suporte a Rust][vscode].
Também te recomendamos vivamente que atives a [verificação com o clippy][vscode-linting]!

[the official Rust website]: https://www.rust-lang.org/tools/install
[vscode]: https://code.visualstudio.com/docs/languages/rust
[vscode-linting]: https://code.visualstudio.com/docs/languages/rust#_linting
