# Instruções

Neste exercício vais escrever código para imprimir crachás com o nome dos funcionários de uma fábrica. Os funcionários têm um ID, um nome e o nome do departamento. As etiquetas dos crachás dos funcionários têm o seguinte formato: `"[id] - name - DEPARTMENT"`.

## 1. Imprime um crachá para um funcionário

Implementa a função `NameBadge.print/3`. Deve receber um ID, um nome e um departamento. Deve devolver a etiqueta do crachá, com o nome do departamento em maiúsculas.

```elixir
NameBadge.print(67, "Katherine Williams", "Strategic Communication")
# => "[67] - Katherine Williams - STRATEGIC COMMUNICATION"
```

## 2. Imprime um crachá para um funcionário novo

Devido a uma peculiaridade do sistema informático, os funcionários novos às vezes ainda não têm um ID quando começam a trabalhar na fábrica. Como os crachás são obrigatórios, recebem um crachá temporário sem o prefixo do ID.

Alarga a função `NameBadge.print/3`. Quando o ID não existir, deve imprimir um crachá sem esse prefixo.

```elixir
NameBadge.print(nil, "Robert Johnson", "Procurement")
# => "Robert Johnson - PROCUREMENT"
```

## 3. Imprime um crachá para o proprietário

Até o proprietário da fábrica tem de usar sempre um crachá. No entanto, o proprietário não tem departamento. Neste caso, a etiqueta deve imprimir `"OWNER"` em vez do nome do departamento.

Alarga a função `NameBadge.print/3`. Quando o departamento não existir, assume que o crachá pertence ao proprietário da empresa.

```elixir
NameBadge.print(204, "Rachel Miller", nil)
# => "[204] - Rachel Miller - OWNER"
```

Repara que é possível que o proprietário também seja um funcionário novo.

```elixir
NameBadge.print(nil, "Rachel Miller", nil)
# => "Rachel Miller - OWNER"
```
