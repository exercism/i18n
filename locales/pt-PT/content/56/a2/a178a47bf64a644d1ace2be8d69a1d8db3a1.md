# Acerca

Em Haxe, as exceções são uma forma segura de lidar com os erros que ocorrem durante a execução do código. Todas as exceções devem conter uma mensagem que descreve o erro. Podemos _lançar_ exceções com a palavra-chave `throw`:

```haxe
public function main(num:Int) {
  if (num < 10) {
    throw "Argument num cannot be greater than 10";
  }
  // ...
}
```

Quando uma exceção é lançada, o código procura uma parte encarregada de tratar o erro. Se não encontrar nenhuma, mostra a mensagem de erro e para a execução do programa.

Para tratar exceções em Haxe, usamos o bloco `try-catch`. Esta instrução composta é formada por um bloco `try` e um ou mais blocos `catch`. O bloco `try` _tenta_ executar um trecho de código, enquanto o bloco `catch` fica à espera de uma exceção lançada para a _apanhar_, de modo a que a execução não seja interrompida. Quando um bloco `catch` apanha uma exceção, também executa tudo o que está dentro do bloco:

```haxe
try {
  if (num < 10) {
    throw "Argument num cannot be greater than 10";
  }
} catch (e) {
  // All exceptions will be caught here
  trace(e.message); // Argument num cannot be greater than 10
}
```

Deve omitir-se o tipo do argumento do bloco `catch`.

É importante notar que as exceções devem ser usadas em casos em que acontece algo excecional, um erro que exige um tratamento especial. Não as deves usar para controlar o fluxo de um programa, pois isso é considerado um mau design, o que costuma dar origem a um fraco desempenho e a problemas de manutenção.
