# Sobre

As [listas][list] são um tipo de dados básico em Haskell para guardar uma coleção de valores.
As listas são _imutáveis_, ou seja, não podem ser modificadas.
Qualquer operação que altere uma lista devolve uma nova lista.
Existem vários métodos no Prelude que te permitem trabalhar com listas.

Em Haskell, as listas são implementadas como [listas ligadas][linked-list-wiki] e não como arrays de posições de memória contíguas.
Por isso, aceder a um elemento de uma lista demora um tempo linear, que depende do comprimento da lista.

As listas podem ser escritas na forma literal, na notação cabeça-cauda (que usa o operador `cons`, `:`), ou numa combinação das duas:

```haskell
-- Literal Form
[]
[1]
[1, 2, 3]

-- Head-tail Notation
[]
-- same as [1]
1 : []
-- same as [1, 2, 3]
1 : (2 : (3 : []))

-- Mixed
-- same as [1, 2, 3]
1 : [2, 3]
```

A notação cabeça-cauda pode ser usada para acrescentar itens ao fim de uma lista.

```haskell
list = [2, 1]

[3, 2, 1] == 3 : list
-- -> True
```

Acrescentar elementos ao fim de uma lista durante a iteração é considerado um antipadrão.
Acrescentar um elemento obriga a percorrer a lista toda e a colocá-lo no final e, por isso, acrescentar um novo elemento a cada iteração obrigaria a percorrer a lista toda em cada iteração.

Podemos obter o mesmo resultado acrescentando um elemento ao início da lista invertida e invertendo depois o resultado. Acrescentar ao início é uma operação rápida e demora um tempo constante.

```haskell
-- Appending to the end of a list (potentially slow)
[1, 2, 3] ++ [4] ++ [5] ++ [6]

-- Prepend to the start of a list (faster, due to the nature of linked lists)
6 : (5 : (4 : [3, 2, 1]))
-- then reverse!
```

Existem várias funções comuns do Prelude para listas:

- [`head`][head] devolve a _cabeça_ de uma lista, ou seja, o _primeiro_ item da lista.
- [`tail`][tail] devolve a _cauda_ da lista, ou seja, a lista _sem_ o _primeiro_ item.
- [`length`][length] devolve o número de itens da lista.
- [`elem`][elem] devolve um valor Boolean que indica se o item é um elemento da lista.

Existe também o [módulo `Data.List`][list].

## Tipos de listas

Em Haskell, as listas são **homogéneas**.
Isto significa que todos os elementos de uma lista têm o mesmo tipo.
Quando tentas colocar elementos de tipos diferentes na mesma lista, obténs um erro de tipo.

```haskell
list = [1, "string"]
-- Error: No instance for (Num String) arising from the literal ‘1’
```

A anotação de tipo de uma lista é `[a]`, em que a é o tipo que a lista contém, por exemplo `String` ou `Int`.

``` haskell
a :: [Int] 
a = [1, 2, 3]
```
