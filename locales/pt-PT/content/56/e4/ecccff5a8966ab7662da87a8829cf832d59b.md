# Introdução

Uma expressão Boolean é uma pergunta feita a um ou mais valores, à qual se pode responder com `true` ou `false`.
Uma expressão verdadeira devolve `1`; uma expressão falsa devolve `0`.
Além disso, os números também têm um valor verdadeiro ou falso. O zero é `false`; um valor diferente de zero é `true`.

O código C antigo ou usa diretamente o tipo `int` para valores Boolean, ou o programador pode ter definido constantes como `TRUE` e `FALSE` para associar `1` e `0` a uma representação Boolean.

Com a versão C99, foi adicionado o tipo `_Bool`.
O ficheiro de cabeçalho `stdbool.h` define três novos símbolos Boolean: `bool`, `true` e `false`.
`true` corresponde a `1`, `false` corresponde a `0` e `bool` corresponde a `_Bool`.
Agora, em vez de usarem diretamente `int`s ou de criarem os seus próprios mapeamentos Boolean, os programadores podem incluir `stdbool.h` e obter automaticamente símbolos Boolean no seu código.

## Operadores de comparação

O C suporta seis operadores de comparação: `==` (igual), `!=` (diferente), `>` (maior que), `<` (menor que), `>=` (maior ou igual a) e `<=` (menor ou igual a).
Estes operadores comparam as relações entre valores e transformam-nas em valores Boolean.

```c
0 == 0 // true. Although 0 is false, 0 equals 0 is true.
0 != 0 // false
1 > 0 // true
1 < 0 // false
1 >= 0 // true
1 <= 0 // false
```

## Operadores Boolean

O C suporta três operadores Boolean: `||` (ou), `&&` (e) e `!` (não).

O `!` usa-se com um operando.
Inverte o valor Boolean do operando.
Por exemplo, `0` é `false`, mas `!0` é `true`.

O `||` e o `&&` usam-se com dois operandos.
O operando à direita só é avaliado quando o operando à esquerda ainda não determina o resultado da expressão.
Ou seja, o `||` só avalia o operando à direita quando o operando à esquerda é avaliado como `false`.
O `&&` só avalia o operando à direita quando o operando à esquerda é avaliado como `true`.
