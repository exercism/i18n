# Dicas

## Geral

- `matches?`, `all-matching-subseqs`, `count-matches` e `re-replace` estão
  todos em [`regexp`][regexp]. Escreve cada padrão como um literal entre
  `R/ ` e `/`.
- Um código de distintivo válido é composto por duas maiúsculas, um hífen e
  quatro algarismos: `R/ [A-Z]{2}-\d{4}/`.

## 1. Verifica um código de distintivo

- `matches?` testa a string *toda*, que é exatamente o que "isto é um
  código de distintivo válido?" precisa: `R/ [A-Z]{2}-\d{4}/ matches?`.

## 2. Extrai todos os códigos de uma linha de registo

- `all-matching-subseqs` devolve cada correspondência como uma sequência
  de strings. Passa-lhe o mesmo padrão do código de distintivo.

## 3. Conta os algarismos de um código

- `\d` corresponde a um algarismo; `count-matches` conta quantas vezes o
  padrão corresponde: `R/ \d/ count-matches`.

## 4. Oculta as palavras-passe

- `\S` significa "um caráter que não é espaço", por isso `R/ pass=\S+/`
  corresponde a `pass=` mais o segredo que se segue.
- `re-replace` recebe a string, o padrão e o texto de substituição
  `"pass=****"`.

[regexp]: https://docs.factorcode.org/content/vocab-regexp.html
