# Introdução

O Common Lisp permite ao programador escrever «comentários» que o computador ignora.
Os comentários de uma só linha começam com um ou mais pontos e vírgulas (`;`) e, ocasionalmente, podes ver o seguinte:

```lisp
(code...) ; => value
```

Aqui, o comentário é usado para indicar o valor que o Common Lisp devolve depois de correr o código dessa linha.

É idiomático usar um único ponto e vírgula para um comentário curto no fim de uma linha, dois para um comentário mais longo acima de uma secção de código, três para um comentário extenso que descreve algo como uma função e quatro para um comentário como um cabeçalho no topo de um ficheiro de código-fonte.
