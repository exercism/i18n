# Introdução

## Strings

Uma string é uma série de carateres, rodeada de aspas.
Tanto as aspas simples como as duplas são suportadas.

```php
<?php

$where = "Spain";
$what = 'rain';
```

### Expansão de variáveis em strings

Nas strings entre aspas duplas, se fizeres referência a uma variável que está no âmbito, o valor é inserido na string.

```php
<?php

$answer = 42;
$expanded = "The answer to life, the universe, and everything is $answer"; 
```

### Suporte de codificação de carateres

Historicamente, as funções de string em PHP só suportavam carateres ASCII e não suportavam as codificações Unicode modernas.
Cada caráter ASCII ocupa 1 byte, enquanto os carateres Unicode podem ocupar entre 1 e 4 bytes.
Se precisares de manipular strings Unicode em segurança, consulta as [versões multibyte][multi-byte-fns] das funções históricas.

```php
<?php

$byte_length = strlen('😃'); // => 4
$string_length = mb_strlen('😃'); // => 1
```

[multi-byte-fns]: https://www.php.net/manual/en/ref.mbstring.php
