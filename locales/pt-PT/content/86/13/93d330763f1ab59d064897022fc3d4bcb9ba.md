# Introdução

A maior parte dos dados em Factor vive em *sequências*. Arrays, vetores e
strings são todos sequências e partilham um conjunto comum de palavras do
vocabulário [`sequences`][sequences].

## Literais de array

Um array literal usa `{ }` com espaços em branco entre os elementos:

```factor
{ 1 2 3 } .          ! => { 1 2 3 }
{ "a" "b" "c" } .    ! => { "a" "b" "c" }
```

Os arrays têm um comprimento fixo, por isso palavras como `suffix` e `remove-nth`,
que alteram o número de elementos, devolvem uma sequência *nova* em vez de
aumentarem a original.

## Comprimento e indexação

```
length   ( seq -- n   )
first    ( seq -- elt )
rest     ( seq -- tailseq )    ! everything but the first element
last     ( seq -- elt )
but-last ( seq -- headseq )    ! everything but the last element
nth      ( n seq -- elt )      ! 0-based
?nth     ( n seq -- elt/f )    ! 0-based; f when out of bounds
```

```factor
{ 10 20 30 } length .       ! => 3
{ 10 20 30 } first .        ! => 10
{ 10 20 30 } rest .         ! => { 20 30 }
{ 10 20 30 } last .         ! => 30
{ 10 20 30 } but-last .     ! => { 10 20 }
1 { 10 20 30 } nth .        ! => 20
```

`?nth` é a versão segura quanto aos limites: podes consultar uma posição
sem verificar primeiro o comprimento.

```factor
1 { 10 20 30 } ?nth .       ! => 20
9 { 10 20 30 } ?nth .       ! => f  (out of bounds, no error)
```

## Fatiar

```
head ( seq n -- headseq )    ! first n elements
tail ( seq n -- tailseq )    ! drop first n
```

```factor
{ 1 2 3 4 5 } 3 head .   ! => { 1 2 3 }
{ 1 2 3 4 5 } 3 tail .   ! => { 4 5 }
```

Ambas lançam um erro se `n` for maior do que a sequência. Se `n` for
demasiado grande, `index-or-length` reduz o seu valor até ao comprimento
da sequência, para que a fatia seguinte não ultrapasse o fim:

```
index-or-length ( seq n -- seq n' )
```

```factor
{ 10 20 30 40 50 } 3 index-or-length head .   ! => { 10 20 30 }
{ 10 20 } 3 index-or-length head .            ! => { 10 20 }
```

As variantes com asterisco `head*` e `tail*` contam a partir do fim:
`head*` descarta os últimos `n` elementos e `tail*` mantém os últimos `n`:

```
head* ( seq n -- headseq )   ! everything except the last n
tail* ( seq n -- tailseq )   ! the last n elements
```

```factor
{ 1 2 3 4 5 } 2 head* .   ! => { 1 2 3 }
{ 1 2 3 4 5 } 2 tail* .   ! => { 4 5 }
```

Para uma fatia arbitrária entre dois índices, `subseq` recebe o
*início* (inclusive) e o *fim* (exclusive):

```
subseq ( from to seq -- subseq )
```

```factor
1 4 { 10 20 30 40 50 } subseq .   ! => { 20 30 40 }
1 4 "hello" subseq .              ! => "ell"
```

Quando tens um *início e um comprimento*, soma-os para obter o fim:

```factor
2 dup 3 + "hello world" subseq .  ! => "llo"
```

(Este é o intervalo de índices `[2, 5)`: três carateres a começar na
posição 2.)

A pergunta inversa, *onde* ocorre uma subsequência, é respondida por
`subseq-index`, que devolve o índice inicial da primeira correspondência,
ou `f` quando não há nenhuma:

```
subseq-index ( seq subseq -- i/f )
```

```factor
"hello world" "o w" subseq-index .   ! => 4
"hello world" "xyz" subseq-index .   ! => f
```

## Preenchimento

```
pad-head ( seq n elt -- padded )    ! prepend copies of elt
pad-tail ( seq n elt -- padded )    ! append copies of elt
```

Ambas aumentam `seq` até o seu comprimento ser pelo menos `n`. Se `seq`
já tiver esse comprimento, é devolvido sem alterações.

```factor
{ 2 5 0 } 6 0 pad-tail .   ! => { 2 5 0 0 0 0 }
{ 4 1 } 5 9 pad-head .     ! => { 9 9 9 4 1 }
```

## As mesmas palavras funcionam com strings

Uma string é uma sequência de carateres, por isso tudo o que está acima
também funciona com strings: o resultado é apenas outra string em vez de
um array:

```factor
"hello" length .            ! => 5
"hello" 3 head .             ! => "hel"
"abc" 6 CHAR: . pad-tail .   ! => "abc..."
```

## Agregação

`sum` e `product` (em [`sequences`][sequences])
somam ou multiplicam os elementos de uma sequência numérica:

```factor
{ 2 5 0 7 } sum .        ! => 14
{ 2 5 3 7 } product .    ! => 210
```

`count` aplica um predicado à sequência e devolve quantos elementos o
tornaram verdadeiro:

```
count ( seq quot -- n )
```

```factor
{ 2 5 0 7 4 1 } [ even? ] count .    ! => 3
```

## Predicados sobre a sequência inteira

```
any?   ( seq quot -- ? )
all?   ( seq quot -- ? )
empty? ( seq -- ? )
```

```factor
{ 2 5 0 7 } [ 4 > ] any? .      ! => t
{ 2 5 0 7 } [ 0 > ] all? .      ! => f
```

## Construir uma nova sequência

`suffix` acrescenta um elemento ao fim de uma sequência; `prefix` acrescenta
um ao início. `unclip` retira o primeiro elemento e `unclip-last` retira o
último:

```
prefix      ( seq elt -- newseq )
suffix      ( seq elt -- newseq )
unclip      ( seq -- rest first )
unclip-last ( seq -- butlast last )
```

```factor
{ 7 9 } 3 prefix .             ! => { 3 7 9 }
{ 7 9 } 3 suffix .             ! => { 7 9 3 }
{ 4 0 9 } unclip .s
! => { 0 9 }
! => 4
```

Combinar `unclip-last` e `suffix` dá uma atualização não destrutiva do
último elemento (e `unclip` + `prefix` faz o mesmo para o primeiro):

```factor
{ 10 20 30 } unclip-last 2 * suffix .
! => { 10 20 60 }
```

## Converter entre tipos de sequência

`>array`, `>vector` e `>string` (em [`arrays`][arrays] e nos vocabulários
correspondentes) forçam uma sequência a assumir um tipo concreto
específico. É útil quando uma operação devolveu uma fatia ou uma sequência
genérica e precisas de obter de volta um array (ou uma string).

```factor
{ 1 2 3 } 1 tail >array .   ! => { 2 3 }
"hello" >array .            ! => { 104 101 108 108 111 }
{ 65 66 67 } >string .      ! => "ABC"
```
