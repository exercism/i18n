# Dicas

## Geral

- Usa o [tipo array][array] incorporado.

## 1. Define um método que devolva um array vazio de linguagens

- A função tem de devolver um array vazio com o tipo `Array(String)`.
- A sintaxe para criar um array vazio é `[]`.
  O tipo pode ser especificado com `of String`.

## 2. Define um método que adicione uma linguagem ao array

- É possível acrescentar um elemento a um array com `<<`.

## 3. Define um método que remova uma linguagem do array

- O Crystal [fornece um método][pop] para remover o último elemento de um array.

## 4. Define um método que devolva o enésimo elemento do array

- O Crystal [fornece um método][index] para obter o elemento num índice específico de um array.

## 5. Define um método que analise uma string de linguagens

- O Crystal [fornece um método][split] para converter uma string num array usando um delimitador.
