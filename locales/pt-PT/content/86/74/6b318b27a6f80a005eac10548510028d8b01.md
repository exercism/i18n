# Instruções

Neste exercício vais trabalhar num agendador de marcações para um salão de beleza em Nova Iorque, que abriu a 15 de setembro de 2012.

Tens quatro tarefas, todas elas relacionadas com datas de marcações. As datas e as horas usam um dos três formatos seguintes:

- `"7/25/2019 13:45:00"`
- `"July 25, 2019 13:45:00"`
- `"Thursday, July 25, 2019 13:45:00"`

Os testes definem automaticamente a cultura como `en-US`. Não tens de definir nem especificar a cultura.

## 1. Interpreta a data da marcação

Implementa o método (_static_) `Appointment.Schedule()` para interpretar uma representação textual de uma data de marcação e convertê-la no formato `DateTime` correspondente:

```csharp
Appointment.Schedule("7/25/2019 13:45:00")
// => new DateTime(2019, 7, 25, 13, 45, 0)
```

## 2. Verifica se uma marcação já passou

Implementa o método (_static_) `Appointment.HasPassed()`, que recebe uma data de marcação e verifica se a marcação ficou algures no passado:

```csharp
Appointment.HasPassed(new DateTime(1999, 12, 31, 9, 0, 0))
// => true
```

## 3. Verifica se a marcação é à tarde

Implementa o método (_static_) `Appointment.IsAfternoonAppointment()`, que recebe uma data de marcação e verifica se a marcação é à tarde (>= 12:00 e < 18:00):

```csharp
Appointment.IsAfternoonAppointment(new DateTime(2019, 03, 29, 15, 0, 0))
// => true
```

## 4. Descreve a hora e a data da marcação

Implementa o método (_static_) `Appointment.Description()`, que recebe uma data de marcação e devolve uma descrição dessa data e dessa hora:

```csharp
Appointment.Description(new DateTime(2019, 03, 29, 15, 0, 0))
// => "You have an appointment on 3/29/2019 3:00:00 PM."
```

## 5. Devolve a data de aniversário

Implementa o método (_static_) `Appointment.AnniversaryDate()`, que devolve a data de aniversário deste ano, que é 15 de setembro:

```csharp
Appointment.AnniversaryDate()
// => new DateTime(2019, 9, 15, 0, 0, 0)
```
