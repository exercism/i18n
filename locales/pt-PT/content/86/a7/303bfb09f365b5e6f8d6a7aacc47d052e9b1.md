# Testes

Para correr os testes, monta e executa o ficheiro do test runner de um determinado exercício, quer através da interface gráfica do simulador MARS, quer na linha de comandos. Para correr na linha de comandos, indica primeiro o ficheiro runner e depois a tua implementação, assim:

    java -jar /path/to/mars.jar nc runner.mips impl.mips

Para correr na interface gráfica, faz `include` da tua implementação no fim do ficheiro "runner.mips", descomentando a última linha.

O test runner ou termina com uma mensagem “success”, ou acaba num teste que falha, apresentando uma mensagem que indica o valor de entrada para o qual esse teste falhou.
