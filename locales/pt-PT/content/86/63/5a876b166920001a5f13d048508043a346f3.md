# Anexo às instruções

## Instruções específicas do Odin

Para resolveres este exercício, vais precisar de manter um registo dos nomes dos robôs que criaste. A estrutura de dados `Robot_Storage` é disponibilizada para esse efeito.

Como os nomes dos robôs são `string` em Odin e têm de ser alocados manualmente à medida que crias os robôs, é da tua responsabilidade libertar a memória associada no procedimento `delete_storage()`.
