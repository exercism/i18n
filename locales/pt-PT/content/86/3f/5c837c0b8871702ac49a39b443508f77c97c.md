# Introdução

## Operadores de comparação

Os [operadores de comparação][comparison-operators] comparam dois valores do mesmo tipo e devolvem um valor `Bool` (`true` ou `false`).
Se tentares comparar valores de tipos diferentes, o compilador dá um erro.

Os operadores de comparação padrão em Swift são:

| Operador | Descrição                | Exemplo         |
| -------- | ------------------------ | --------------- |
| `==`     | Igual a                  | `1 == 1` (true) |
| `!=`     | Diferente de             | `1 != 2` (true) |
| `<`      | Menor que                | `4 < 5`  (true) |
| `<=`     | Menor ou igual a         | `4 <= 4` (true) |
| `>`      | Maior que                | `3 > 1`  (true) |
| `>=`     | Maior ou igual a         | `2 >= 2` (true) |

## Condicionais if e else

Uma [instrução condicional][conditional-statement] executa código consoante uma condição seja avaliada como `true` ou `false`.
A condicional mais comum é a instrução `if`, que só executa um bloco de código quando a sua condição é `true`.
Escreve uma instrução `if` com a palavra-chave `if`, seguida da condição e do bloco de código entre chavetas:

```swift
let wheelCount = 4
if wheelCount == 4 {
    print("Your vehicle is a car")
}
// Prints "Your vehicle is a car"
```

Podes combinar o `if` com uma cláusula `else` para executar código alternativo quando a condição é `false`:

```swift
let precipitationInMM = 0.5
if precipitationInMM > 0.5 {
    print("You will need an umbrella")
} else {
    print("You will not need an umbrella")
}
// Prints "You will not need an umbrella"
```

Para testar várias condições em sequência, encadeia as instruções com `else if`.
Uma instrução `if` não precisa de um ramo `else`, mas podes incluí-lo para tratar os casos em que nenhuma das condições se verifica:

```swift
let favoriteFruit = "Apple"

if favoriteFruit == "Banana" {
    print("Your favorite fruit is a banana")
} else if favoriteFruit == "Orange" {
    print("Your favorite fruit is an orange")
} else if favoriteFruit == "Apple" {
    print("Your favorite fruit is an apple")
} else {
    print("Your favorite fruit is not a banana, orange, or apple")
}
// Prints "Your favorite fruit is an apple"
```

## Expressões if

No Swift moderno, as instruções `if` também podem ser usadas como expressões que produzem um valor.
Cada ramo é avaliado como um valor, o que facilita atribuir resultados de forma condicional:

```swift
let cpuBits = 32
let architecture = if cpuBits == 64 {
    "x86_64"
} else {
    "x86_32"
}

print(architecture)
// Prints "x86_32"
```

## Operador ternário

O [operador condicional ternário][ternary-operator] é uma forma abreviada e concisa de uma expressão `if-else`.
Avalia uma condição e devolve um de dois valores, consoante essa condição seja `true` ou `false`.

O operador usa três partes: `condition ? trueExpression : falseExpression`.
Se `condition` for avaliada como `true`, avalia-se e devolve-se `trueExpression`; caso contrário, avalia-se e devolve-se `falseExpression`.

O operador ternário é ideal para escolhas simples, numa única linha:

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = showFahrenheit ? temperatureInCelsius * 9 / 5 + 32 : temperatureInCelsius
print(temperature)
// Prints 86
```

O exemplo acima é o equivalente compacto de:

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = if showFahrenheit {
    temperatureInCelsius * 9 / 5 + 32
} else {
    temperatureInCelsius
}
```
