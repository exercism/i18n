# Sobre

## Cópias e referências

Com os conhecimentos que temos hoje, é um pouco trabalhoso atualizar uma variável com a ajuda de uma função.
Cada argumento de função é tratado como uma cópia e não altera o valor original.
Consoante o tamanho do teu tipo, isto pode ter consequências graves para o desempenho do teu código.

```cpp
int adjust_salary(int base, int kids) {
    return base + kids * 500;
}
int now_a_mother_of_twins{2500};
adjust_salary(now_a_mother_of_twins, 2);

// now_a_mother_of_twins is still 2500
now_a_mother_of_twins = adjust_salary(now_a_mother_of_twins, 2);
// now_a_mother_of_twins is now 3500
```

As `References` podem ser vistas como alias: as alterações feitas a elas têm efeito na variável original.
As `References` usam um **e comercial** (`&`) na declaração do tipo.

```cpp
int balance{1000};
int& budget{balance};
int pro_computer_wheels{699};
budget -= pro_computer_wheels;
// budget is now 301;
// balance is also 301;
```
[Reatribuir][Reseating] (mudar a ligação de uma `reference`) não é possível.
Não podes ter uma `reference` não inicializada.
As `References` têm de ser inicializadas com uma variável existente.

```cpp
int main_acc{1'000'000};
int side_acc{-20};
int& savings{main_acc};
// => main_acc and savings are 1'000'000

// try to reseat savings to use main account
savings = side_acc;
// savings and main_acc are now -20
// as this uses the **value** of side_acc
savings += 20;
// savings and main_acc are now 0, side_acc is stil -20

int& future_budget;
// => compiler error, reference must be bound!
```

## `void`

Com o poder das `references`, podes nem sequer precisar de devolver um valor de uma função.
Neste cenário, usa-se o `void` como tipo de retorno.

```cpp
void increase_power(int& level) {
    level += 500;
}
int goku{8700};
increase_power(goku);
// goku's power level?
// It's over 9000!
```
