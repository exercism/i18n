# Dicas

## 1. Substitui os espaços que encontrares por underscores

- A [documentação de referência][char-docs] sobre `char` está aqui.
- Podes obter `char` de uma string da mesma forma que obténs elementos de um array, embora neste exercício possa ser melhor usar uma função de ordem superior como `String.collect`.
- Os literais `char` ficam entre aspas simples.

## 2. Remove todos os espaços em branco

- Vê [este método][iswhitespace] para detetar espaços e [este método][isnumber] para algarismos.

## 3. Converte camel-case em kebab-case

- Vê [este método][tolower] para converter um caráter em minúscula.

## 5. Omite as letras gregas minúsculas

- `char` suporta os operadores de igualdade e de comparação predefinidos.
