# Dicas

## Geral

* O que poderá fazer um zipper mais simples sobre uma estrutura de dados de lista (não vazia)? Prescindir de um grau de movimento no zipper pode ajudar se ficares preso. Um Zipper sobre uma lista só precisaria de se preocupar em mover para a esquerda, mover para a direita, e obter e definir um elemento no foco.
* O `t` em `Zipper t a` representa a estrutura de dados de árvore binária para efeitos deste exercício. Isto dá ao Zipper a capacidade de fazer "zip" por potencialmente mais do que uma estrutura de dados!
