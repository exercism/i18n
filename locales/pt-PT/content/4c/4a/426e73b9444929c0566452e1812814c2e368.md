# não uses condicionais aninhadas

Tenta reescrever as condicionais para evitar aninhamento profundo, porque isso pode dar origem a código mais difícil de seguir. Vê os dois exemplos de código seguintes:

```csharp
void PrintName(Person p)
{
    if (p != null)
    {
        if (p.Name != null)
        {
            if (p.Age >= 21)
            {
                Console.WriteLine(p.Name);
            }
        }
    }
}
```

Compara com o código seguinte:

```csharp
void PrintName(Person p)
{
  if (p == null || p.Name == null || p.Age < 21)
  {
      return;
  }

  Console.WriteLine(p.Name);
}
```

O segundo exemplo tem uma estrutura muito específica: todos os caminhos que tratam de erros são tratados em blocos indentados, enquanto o «caminho feliz» fica sempre alinhado à esquerda. Assim, a leitura torna-se muito mais fácil, porque se percebe rapidamente qual é o caminho mais comum e sem erros ao longo do código.
