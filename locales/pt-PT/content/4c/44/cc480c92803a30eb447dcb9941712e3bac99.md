# Instalação

A distribuição do Racket pode ser descarregada em https://download.racket-lang.org

Existem instaladores para

* Windows
* Linux
* macOS

Consulta a página [Getting Started](http://docs.racket-lang.org/getting-started/) do Racket para encontrares materiais de orientação.

O [Racket Guide](https://docs.racket-lang.org/guide/intro.html) apresenta-te a interação com o Racket.

Consulta [DrRacket: The Racket Programming Environment](https://docs.racket-lang.org/drracket/index.html) para orientação sobre a utilização do IDE DrRacket.

Consulta [Command-Line Tools and Your Editor of Choice](https://docs.racket-lang.org/guide/other-editors.html) para uma introdução às ferramentas de linha de comandos do Racket e à utilização de outros editores.


## Acerca do instalador para Linux:
A versão para Linux é suficientemente genérica para funcionar na maioria das distribuições, incluindo distribuições relativamente antigas.

Depois de descarregares o ficheiro do instalador, executa-o com
```
sh racket-8.10-x86_64-linux-cs.sh
```

Pode ser necessário acrescentar `sudo` no início do comando para instalar num local que exige acesso de administrador.

**Atenção: o Racket também pode estar disponível através do gestor de pacotes da tua distribuição, embora possa ser mais antigo do que a versão mais recente do Racket.**
Embora possas optar por fazê-lo mais tarde, enquanto aprendiz terás uma experiência muito melhor se te mantiveres na versão atual disponível em https://download.racket-lang.org


## Acerca do instalador para macOS:

Se a tua máquina usa processadores da série M1 ou M2, seleciona **Apple Silicon** no menu pendente de plataformas antes de descarregares.
