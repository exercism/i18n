# Instruções

Um robô de festa está a preparar bandeirolas para a grande festa. Cada
linha de bandeirolas é uma fila horizontal de `n` bandeirinhas, e o
caráter de cada bandeirinha é decidido pela posição que ocupa na
fila, contada da esquerda a partir de `0`. Ajuda o robô a
montar os padrões abaixo.

## 1. Bandeirolas do alfabeto

Define `alphabet-bunting` para tirar da pilha um número inteiro não
negativo `n` e devolver uma string com as primeiras `n` letras
minúsculas do alfabeto.

```factor
5 alphabet-bunting .
! => "abcde"

0 alphabet-bunting .
! => ""
```

Podes assumir que `n` é, no máximo, `26`.

## 2. Bandeirolas de contagem

Define `counting-bunting` para receber `n` e devolver uma string de `n`
algarismos, em que a bandeirinha na posição `i` mostra `i mod 10`.

```factor
12 counting-bunting .
! => "012345678901"
```

## 3. Bandeirolas às riscas

Define `stripe-bunting` para alternar entre dois carateres: as posições
pares recebem `*` e as posições ímpares recebem `-`.

```factor
6 stripe-bunting .
! => "*-*-*-"

1 stripe-bunting .
! => "*"
```

## 4. Bandeirolas com marcador

Cada quinta bandeirinha é um marcador especial. Define `marker-bunting`
de modo a que as posições `0`, `5`, `10`, … recebam `|` e as restantes recebam `.`.

```factor
11 marker-bunting .
! => "|....|....|"
```

## 5. Bandeirolas do vale

O robô pendura uma bandeirola de tamanho fixo com 10 bandeirinhas, presa a um
gancho no centro. Contando da bandeirinha mais à esquerda, na posição `-5`,
até `5` (exclusive), o caráter de cada bandeirinha é a
distância ao centro, escrita como um algarismo.

Define `valley-bunting` (sem parâmetros de entrada) para devolver essa
string fixa.

```factor
valley-bunting .
! => "5432101234"
```
