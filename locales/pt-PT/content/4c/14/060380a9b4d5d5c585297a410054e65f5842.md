# Introdução

Por vezes, quando percorres uma sequência, precisas da *posição* do elemento a par do próprio elemento. A família `*-index` em [`sequences`][sequences] passa ambos à quotation de cada elemento. O `times` é o primo chegado para a iteração contada simples: útil quando só precisas de uma contagem, não de uma sequência.

## `each-index` e `map-index`: o índice na quotation

```
each-index ( seq quot: ( elt index -- )       -- )
map-index  ( seq quot: ( elt index -- newelt ) -- newseq )
```

A quotation recebe o elemento abaixo do índice; o `index` fica **no topo** da pilha:

```factor
USING: io kernel math.parser sequences ;

{ "alice" "bob" "carol" } [
    number>string ": " glue print
] each-index
! prints:
! alice: 0
! bob:   1
! carol: 2

{ 10 20 30 } [ + ] map-index .
! => { 10 21 32 }       (index added to each element)
```

O `each-index` executa a quotation pelo seu efeito secundário e não devolve nada. O `map-index` recolhe os resultados de cada elemento numa nova sequência do mesmo tipo que a sequência de entrada.

## `times`: iteração contada

O `times` (em [`math`][math]) executa a sua quotation `n` vezes.

```
times ( n quot: ( -- ) -- )
```

A forma publicada `( -- )` é o *mínimo*. Como o `times` é `inline`, uma quotation com efeitos equilibrados como `( str -- str )` funciona sem problema, e a pilha é transportada ao longo das iterações. Assim tens um acumulador contado sem qualquer estado mutável:

```factor
USING: kernel sequences ;

"" 3 [ "clop " append ] times .    ! => "clop clop clop "
```

O corpo de cada iteração vê a string corrente, acrescenta-lhe algo e deixa a nova string na pilha para a iteração seguinte. O mesmo truque funciona com o `each-index` e o `map-index` quando queres passar um acumulador de iteração em iteração.
