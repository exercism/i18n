# Instruções

Acabaste de começar a trabalhar na receção de um ginásio de escalada.
Os sócios compram subscrições por um determinado número de meses e registam a entrada e a saída em cada visita.
O gerente pediu-te para escreveres uma função auxiliar que responda às perguntas que os sócios fazem com mais frequência.

## 1. Calcula quando termina uma subscrição

Uma subscrição que começa numa data indicada termina no mesmo dia do mês, tantos meses mais tarde quantos os indicados.
Se esse dia não existir no mês final, a subscrição termina no último dia desse mês.

Implementa o método `FrontDesk.membershipEnd()`, que recebe a data de início de uma subscrição e o respetivo número de meses, e devolve a data em que termina:

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.membershipEnd(LocalDate.of(2024, 3, 10), 1);
// => LocalDate.of(2024, 4, 10)
frontDesk.membershipEnd(LocalDate.of(2025, 1, 31), 1);
// => LocalDate.of(2025, 2, 28)
```

## 2. Mostra quanto tempo dura uma subscrição

No cartão de sócio, o ginásio imprime quanto tempo a subscrição dura, em anos, meses e dias.

Implementa o método `FrontDesk.membershipLength()`, que recebe a data de início e a data de fim de uma subscrição, e devolve a duração da subscrição como um `Period`:

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.membershipLength(LocalDate.of(2023, 3, 10), LocalDate.of(2024, 5, 25));
// => Period.of(1, 2, 15)
```

## 3. Conta os dias que restam de uma subscrição

Os sócios perguntam muitas vezes quantos dias lhes restam antes de a subscrição terminar.

Implementa o método `FrontDesk.daysLeft()`, que recebe a data de hoje e a data de fim de uma subscrição, e devolve o número total de dias desde hoje até à data de fim.
Quando a data de fim é hoje ou já passou, não restam dias, por isso o método devolve `0`:

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.daysLeft(LocalDate.of(2024, 1, 15), LocalDate.of(2024, 3, 20));
// => 65
frontDesk.daysLeft(LocalDate.of(2024, 4, 2), LocalDate.of(2024, 3, 20));
// => 0
```

## 4. Mede a duração de uma visita

O ginásio está aberto 24 horas por dia e o torniquete regista a data e a hora de entrada e de saída de cada sócio.

Implementa o método `FrontDesk.visitDuration()`, que recebe a data e a hora de entrada e de saída de uma visita, e devolve quanto tempo a visita durou como um `Duration`:

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.visitDuration(LocalDateTime.of(2024, 3, 10, 23, 30), LocalDateTime.of(2024, 3, 11, 1, 15));
// => Duration.ofMinutes(105)
```

## 5. Imprime uma visita no recibo

O recibo mostra a duração de uma visita em horas e minutos, como `1h 35m`.
Os minutos são sempre escritos com dois algarismos, os segundos são omitidos e as horas não estão limitadas a um único dia.

Implementa o método `FrontDesk.formatVisit()`, que recebe a duração de uma visita e a devolve neste formato:

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.formatVisit(Duration.ofMinutes(95));
// => "1h 35m"
frontDesk.formatVisit(Duration.ofHours(2).plusMinutes(5));
// => "2h 05m"
frontDesk.formatVisit(Duration.ofHours(26).plusMinutes(10));
// => "26h 10m"
```
