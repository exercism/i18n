# Dicas

## 1. Cria um novo inventário utilizando os itens

- Tens de usar `return` para devolver uma referência a um hash a partir da sub-rotina `create_inventory`, com os itens como chaves e, como valores, a quantidade de cada um deles presente no array referenciado por `$items`.

## 2. Adiciona ao inventário utilizando os itens

- Tens de usar `return` para devolver uma referência a um hash a partir da sub-rotina `add_items`, com a quantidade de itens aumentada pelo número de itens contidos no array referenciado por `$items`.

## 3. Remove os itens do inventário

- Tens de usar `return` para devolver uma referência a um hash a partir da sub-rotina `remove_items`, com a quantidade de itens diminuída pelo número de itens contidos no array referenciado por `$items`.
- A contagem de itens não pode descer abaixo de `0`.

## 4. Elimina completamente o item do inventário

- Tens de usar `return` para devolver uma referência a um hash a partir da sub-rotina `delete_item`, com o item completamente removido do inventário.
