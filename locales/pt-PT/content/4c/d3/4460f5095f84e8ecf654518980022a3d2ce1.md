# Introdução

Muitos programas precisam de valores (pseudo)aleatórios para simular acontecimentos do mundo real.

Exemplos comuns e familiares incluem:

- Lançar uma moeda ao ar: um valor aleatório de ('H', 'T').
- Lançar um dado: um número inteiro aleatório de 1 a 6.
- Baralhar um baralho de cartas: uma ordem aleatória de uma lista de cartas.
- A criação de árvores e arbustos numa simulação gráfica 3-D.

Gerar valores verdadeiramente aleatórios com um computador é um [desafio técnico surpreendentemente difícil][why-randomness-is-hard], e é por isso que também existem geradores "pseudoaleatórios".

## Gerar números aleatórios

Em Javascript, podes gerar números pseudoaleatórios com a função [`Math.random()`][Math.random].
Esta devolve um número de vírgula flutuante pseudoaleatório entre 0 (incluído) e 1 (excluído).

Para obteres um número aleatório entre _min_ (incluído) e _max_ (excluído), podes usar uma função parecida com esta:

```javascript
function getRandomInRange(min, max) {
  return min + Math.random() * (max - min);
}
getRandomInRange(4, 10);
// => 5.72
```

## Gerar números inteiros aleatórios

Para gerares um número inteiro aleatório, podes usar `Math.floor()` ou `Math.ceil()` para transformar um número gerado aleatoriamente num número inteiro.
