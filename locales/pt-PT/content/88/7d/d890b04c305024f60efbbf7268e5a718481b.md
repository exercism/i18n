# Instruções

O teu amigo, um aspirante a artista, contactou-te com uma ideia de projeto. Vamos juntar a criatividade visual dele à tua experiência técnica. Está na hora de experimentares [arte generativa][generative-art]!

As restrições ajudam a criatividade e encurtam os prazos dos projetos, por isso combinaram os dois limitar a vossa obra-prima a uma única forma: o círculo. Mas vai haver muitos círculos. E podem mover-se! Vais chamar-lhe... pontos dançantes.

O teu amigo vai certamente querer inventar novos movimentos elaborados para os pontos, por isso vais começar a programar criando uma arquitetura que te permita definir novas animações facilmente mais tarde.

## 1. Define o comportamento da animação

Cada módulo de animação tem de implementar dois callbacks: `init/1` e `handle_frame/3`. Define-os no módulo `Animation`.

Define o callback `init/1`. Deve receber um argumento do tipo `opts` e devolver um tuplo `{:ok, opts}` ou um tuplo `{:error, error}`. As implementações deste callback verificam se as opções dadas são válidas para este tipo específico de animação.

Define o callback `handle_frame/3`. Deve receber três argumentos: o ponto, um número de frame e as opções. Deve devolver sempre um ponto. As implementações deste callback modificam os atributos do ponto com base no número do frame atual e nas opções da animação.

## 2. Fornece uma implementação predefinida do callback `init/1`

O comportamento `Animation` deve ser fácil de incorporar noutros módulos, bastando chamar `use DancingDots.Animation`.

Para isso, implementa a macro `__using__` no módulo `Animation`, de modo a definir o módulo `Animation` como o comportamento do outro módulo. Deve também fornecer uma implementação predefinida do callback `init/1`. A implementação predefinida de `init/1` deve devolver as opções dadas sem alterações.

```elixir
defmodule MyCustomAnimation do
  use DancingDots.Animation
end

MyCustomAnimation.init(some_option: true)
# => {:ok, [some_option: true]}
```

## 3. Implementa a animação `Flicker`

Usa o comportamento `Animation` para implementar uma animação intermitente.

Deve usar o callback `init/1` predefinido, porque não recebe opções.

Implementa o callback `handle_frame/3`, que trata de um único frame. Se o número do frame for múltiplo de quatro, a função deve devolver o ponto com metade da sua opacidade original. Nos restantes frames, deve devolver o ponto inalterado.

Os frames contam-se a partir de `1`. O ponto passado a `handle_frame/3` está sempre no seu estado original, não no estado do frame anterior.

```elixir
dot = %DancingDots.Dot{x: 100, y: 100, radius: 24, opacity: 1}

DancingDots.Flicker.handle_frame(dot, 1, [])
# => %DancingDots.Dot{opacity: 1, radius: 24, x: 100, y: 100}

DancingDots.Flicker.handle_frame(dot, 4, [])
# => %DancingDots.Dot{opacity: 0.5, radius: 24, x: 100, y: 100}
```

## 4. Implementa a animação `Zoom`

Usa o comportamento `Animation` para implementar uma animação de zoom.

Esta animação recebe uma opção: a velocidade. A velocidade pode ser qualquer número. Se for negativa, o ponto é reduzido em vez de ampliado.

Implementa o callback `init/1`. Deve validar que as opções passadas são uma lista de palavras-chave com uma chave `:velocity`. O valor da velocidade tem de ser um número. Se não for um número, devolve o erro `"The :velocity option is required, and its value must be a number. Got: #{inspect(velocity)}"`.

Implementa o callback `handle_frame/3`. Deve devolver o ponto com o raio aumentado pelo número do frame atual, menos um, multiplicado pela velocidade.

Os frames contam-se a partir de `1`. O ponto passado a `handle_frame/3` está sempre no seu estado original, não no estado do frame anterior.

```elixir
DancingDots.Zoom.init(velocity: nil)
# => {:error, "The :velocity option is required, and its value must be a number. Got: nil"}

dot = %DancingDots.Dot{x: 100, y: 100, radius: 24, opacity: 1}

DancingDots.Zoom.handle_frame(dot, 1, velocity: 10)
# => %DancingDots.Dot{radius: 24, opacity: 1, x: 100, y: 100}

DancingDots.Zoom.handle_frame(dot, 2, velocity: 10)
# => %DancingDots.Dot{radius: 34, opacity: 1, x: 100, y: 100}
```
