# Dicas

## 1. Obtém a primeira carta

- [Este guia][destructuring_resource] tem uma boa visão geral da desestruturação sequencial. Encontras lá um exemplo de associação de nomes a valores.

## 2. Obtém a segunda carta

- Podes usar marcadores de posição para ignorar um ou mais valores na associação.

## 3. Troca as duas primeiras cartas

- É possível usar `&` para combinar os restantes elementos numa sequência.

## 4. Descarta a carta de cima

- Podes usar `:as all` para associar o vetor inteiro ao símbolo `all`.

## 5. Insere as cartas de figuras

- Encontras mais informações sobre onde desestruturar [aqui][where-to-destructure].
