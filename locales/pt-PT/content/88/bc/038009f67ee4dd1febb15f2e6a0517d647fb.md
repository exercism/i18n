# Ordenação

Pôr as coisas por ordem é tão comum que a biblioteca faz isso por ti.

```sather
   scores : ARRAY{INT} := |3, 1, 2|;
   scores.sort;              -- 1, 2, 3
```

`sort` funciona com tudo o que já sabe comparar-se: os números e as strings conseguem, porque têm um `is_lt`.

## Ordenar com a tua própria regra

Na maioria dos casos, a ordem não é a predefinida. A classificação de netball não é alfabética nem por comprimento do nome: é por pontos e, depois, pela diferença de golos para as equipas empatadas em pontos. Não há forma de o `ARRAY` adivinhar isso.

Por isso, passas a ordem como uma rotina vinculada:

```sather
   before(a, b : STR) : BOOL is
      return a.size < b.size;
   end;

   ...

   words.insertion_sort_by(bind(before(_, _)));
```

`insertion_sort_by` recebe um `ROUT{T,T}:BOOL`, ou seja, uma rotina que recebe dois dos elementos a ordenar e responde se o primeiro pertence antes do segundo. Chama essa rotina tantas vezes quantas precisa e coloca o array na ordem que as respostas implicam.

Era para isto que servia o `understudy`. A biblioteca sabe ordenar e não sabe nada sobre a tua ideia de ordem; a rotina vinculada é onde as duas se encontram.

## Escrever a comparação

A rotina responde **true quando o primeiro argumento vem primeiro**.

```sather
   -- shortest first
   return a.size < b.size;

   -- longest first: turn it round
   return a.size > b.size;
```

Para uma regra com mais do que uma parte, trata as partes por ordem de importância:

```sather
   higher(a, b : TEAM) : BOOL is
      if a.points /= b.points then
         return a.points > b.points;      -- more points comes first
      end;
      return a.difference > b.difference; -- level: better difference wins
   end;
```

O primeiro `if` decide sempre que os pontos são diferentes. Só quando são iguais é que a segunda linha tem voto na matéria. Escrever primeiro o desempate significaria que os pontos nunca importaram.

## A ordenação altera o array

`insertion_sort_by` ordena o próprio array e não devolve nada:

```sather
   teams.insertion_sort_by(bind(higher(_, _)));   -- teams is now sorted
```

Se a ordem original for importante, ordena uma cópia:

```sather
   ranked ::= teams.copy;
   ranked.insertion_sort_by(bind(higher(_, _)));
   return ranked;
```
