# Números

O Crystal tem um tipo, `Number`, que é o tipo base de todos os tipos numéricos.
Existem dois subtipos principais dentro do tipo Number: [`Int`][int] e [`Float`][float].

`Int` é a abreviatura de integer e representa números inteiros.
`Int` pode ser negativo ou positivo, sem parte decimal.

```crystal
1.class
# => Int32

-1.class
# => Int32
```

`Float` representa números com parte decimal.
Os `Float` podem ser negativos ou positivos.

```crystal
10.5.class
# => Float64
```

## Converter entre `Int` e `Float`

Com os métodos `to_i` e `to_f`, podes converter entre `Int` e `Float`.
O número é arredondado para baixo quando convertes de `Float` para `Int`.

```crystal
1.to_f
# => 1.0

1.0.to_i
# => 1

1.9.to_i
# => 1
```

## Operadores aritméticos

Podes usar os [operadores aritméticos básicos][math] com `Int` e `Float`.
Os operadores são `+`, `-`, `*`, `/` e `%`.
Ao usar estes operadores, podes misturar `Int` e `Float`.

### Adição, subtração e multiplicação

O operador `+` serve para a adição, o operador `-` para a subtração e o operador `*` para a multiplicação.

| Operador | Exemplo        |
| -------- | -------------- |
| `+`      | `4 + 6 => 10`  |
| `-`      | `15 - 10 => 5` |
| `*`      | `2 * 3 => 6`   |

### Divisão

A divisão serve para dividir números.
O operador `/` é usado para a divisão.
O resultado é sempre um `Float`.

```crystal
4 / 2
# => 2.0

4.0 / 2
# => 2.0
```

~~~~exercism/caution
Em algumas linguagens de programação, dividir por zero dá origem a um erro.

No Crystal, dividir por zero dá como resultado `Infinity` ou `-Infinity`.
A única exceção é dividir zero por zero, que dá `NaN` (Not a Number).
`Infinity` e `NaN` são valores particulares do tipo `Float`.

```crystal
1 / 0
# => Infinity

-1 / 0
# => -Infinity

0 / 0
# => NaN
```
~~~~

### Módulo

O módulo serve para obter o resto de uma divisão.
O operador `%` é usado para o módulo.

```crystal
5 % 2
# => 1

5.0 % 2
# => 1.0

5 % 3
# => 2
```

~~~~exercism/caution
Dividir por zero ao usar o módulo resulta num DivisionByZeroError.
Isto é diferente da divisão normal.

```crystal
1 % 0
# Error: Unhandled exception: Division by 0 (DivisionByZeroError)
```
~~~~

## Arredondamento

O método `round` aceita um argumento opcional: o número de casas decimais para arredondar.
O número de casas decimais predefinido é 0.

```crystal
1.0.round
# => 1

1.5.round
# => 2

1.234.round(2)
# => 1.23
```

## Prioridade e parênteses

O Crystal permite parênteses (`()`), que podem ser usados para agrupar expressões.
Isto é útil quando queres alterar a ordem das operações.

Quando usas vários operadores aritméticos, a ordem das operações é a mesma que na matemática, também conhecida como [PEMDAS][pemdas].
Segue a ordem de parênteses (`()`), expoentes (`**`), multiplicação (`*`) e divisão (`/`), e adição (`+`) e subtração (`-`).

```crystal
2 + 3 - 4 * 4
# => -11

(2 + 3 - 4) * 4
# => 4
```
