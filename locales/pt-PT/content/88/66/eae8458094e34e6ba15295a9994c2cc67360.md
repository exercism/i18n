# Sobre

[Ballerina](https://ballerina.io/) é uma linguagem de programação compilada, transacional, com tipagem estática e forte, e com sintaxes textuais e gráficas. A Ballerina incorpora conceitos fundamentais de integração de sistemas distribuídos na própria linguagem e oferece um ambiente concorrente e com segurança de tipos para implementar microsserviços com transações distribuídas, mensagens fiáveis, processamento de fluxos e fluxos de trabalho.

A Ballerina é uma linguagem concebida para que a integração seja simples. Baseada nas interações de diagramas de sequência, a Ballerina tem suporte incorporado para padrões e conectores de integração comuns, incluindo transações distribuídas, compensação e disjuntores. Com suporte de primeira classe para JSON e XML, a Ballerina torna simples e eficaz a construção de integrações robustas entre pontos finais de rede.
