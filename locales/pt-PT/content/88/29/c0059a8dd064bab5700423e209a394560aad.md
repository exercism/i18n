# Testes

Os testes exigem que o pacote `{testthat}` esteja instalado no R.
Para correr os testes de um exercício, basta executar o script `test_<exercise_name>.R` dentro do diretório do exercício.

Isto pode ser feito de forma cómoda com [a função `auto_test` do testthat](https://testthat.r-lib.org/reference/auto_test.html). Como o código e os testes do Exercism estão na mesma pasta, usa este mesmo caminho para os parâmetros `code_path` e `test_path`. Na linha de comandos, podes também executar `Rscript test_<exercise_name>.R`.

Consulta a [página de testes](https://exercism.org/docs/tracks/r/tests) para mais informações.
