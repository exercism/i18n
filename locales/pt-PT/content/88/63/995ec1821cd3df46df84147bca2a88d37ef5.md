# Introduction

O principal construto orientado a objetos em C# é a _classe_, que é uma combinação de dados (_campos_) e comportamento (_métodos_). Os campos e os métodos de uma classe são conhecidos como os seus _membros_.

O acesso aos membros pode ser restringido através de modificadores de acesso, sendo os dois mais comuns:

- `public`: qualquer código pode aceder ao membro (sem restrições).
- `private`: só o código da mesma classe pode aceder ao membro.

Podes pensar numa classe como um modelo para criar instâncias dessa classe. Para criar uma instância de uma classe (também conhecida como _objeto_), usa-se a palavra-chave `new`:

```csharp
class Car
{
}

// Create two car instances
var myCar = new Car();
var yourCar = new Car();
```

Os campos têm um tipo e podem ser definidos em qualquer parte de uma classe.
Os campos públicos definem-se em PascalCase e os campos privados definem-se em camelCase e começam com um underscore `_`:

```csharp
class Car
{
    // Accessible by anyone
    public int Weight;

    // Only accessible by code in this class
    private string _color;
}
```

Podes, opcionalmente, atribuir um valor inicial a um campo. Se um campo _não_ especificar um valor inicial, fica com o valor predefinido do seu tipo. Podes aceder aos valores dos campos de uma instância e atualizá-los com a notação de ponto.

```csharp
class Car
{
    // Will be set to specified value
    public int Weight = 2500;

    // Will be set to default value (0)
    public int Year;
}

var newCar = new Car();
newCar.Weight; // => 2500
newCar.Year;   // => 0

// Update value of the field
newCar.Year = 2018;
```

Os campos privados são normalmente atualizados como efeito secundário da chamada de um método. Esses métodos habitualmente não devolvem nenhum valor, e nesse caso o tipo de retorno deve ser `void`:

```csharp
class CarImporter
{
    private int _carsImported;

    public void ImportCars(int numberOfCars)
    {
        // Update private field from public method
        _carsImported = _carsImported + numberOfCars;
    }
}
```
