# Instruções

Depois de uma revisão de segurança recente, foi-te pedido que limpasse os ficheiros de log arquivados da organização.

## 1. Identifica as linhas de log corrompidas

Precisas de ter uma ideia de quantas linhas de log do teu arquivo não cumprem os padrões atuais.
Acreditas que um teste simples revela se uma linha de log é válida.
Para ser considerada válida, uma linha deve começar por uma das seguintes strings:

- [DEBUG]
- [INFO]
- [WARNING]
- [ERROR]

Implementa a função `valid_line?/1` para devolver `true` se a linha de log for válida.

```elixir
LogParser.valid_line?("[ERROR] Network Failure")
# => true

LogParser.valid_line?("Network Failure")
# => false
```

## 2. Divide a linha de log

Pouco depois de começares o projeto de análise de logs, dás-te conta de que os logs de uma aplicação não estão divididos em linhas como os das outras. Neste projeto, o que devia estar em linhas separadas aparece antes numa única linha, ligado por setas extravagantes como `<--->` ou `<*~*~>`.

Na verdade, qualquer string cujo primeiro caráter seja `<`, cujo último caráter seja `>` e que tenha, pelo meio, qualquer combinação dos seguintes carateres `~`, `*`, `=`, e `-` pode ser usada como separador nos logs deste projeto.

Implementa a função `split_line/1`, que recebe uma linha e devolve uma lista de strings.

```elixir
LogParser.split_line("[INFO] Start.<*>[INFO] Processing...<~~~>[INFO] Success.")
# => ["[INFO] Start.", "[INFO] Processing...", "[INFO] Success."]
```

## 3. Remove os artefactos do log

Descobriste que algum processamento a montante dos logs tem vindo a espalhar pelos logs o texto "end-of-line" seguido de um número de linha (sem espaço entre eles).

Implementa a função `remove_artifacts/1` para receber uma string e remover todas as ocorrências do texto end-of-line (independentemente de serem maiúsculas ou minúsculas), devolvendo uma linha de log limpa.

As linhas que não contenham o texto end-of-line devem ser devolvidas sem alterações.

Remove apenas a string end-of-line, não é preciso ajustar os espaços em branco.

```elixir
LogParser.remove_artifacts("[WARNING] end-of-line23033 Network Failure end-of-line27")
# => "[WARNING]  Network Failure "
```

## 4. Etiqueta as linhas com nomes de utilizador

Notaste que algumas das linhas de log incluem frases que se referem a utilizadores.
Estas frases contêm sempre a string `"User"`, seguida de um ou mais carateres de espaço e, depois, de um nome de utilizador.
Decides etiquetar essas linhas.

Implementa uma função `tag_with_user_name/1` que processa as linhas de log:

- As linhas que não contêm a string `"User"` mantêm-se inalteradas.
- Nas linhas que contêm a string `"User"`, acrescenta ao início da linha `[USER]` seguido do nome do utilizador.

```elixir
LogParser.tag_with_user_name("[INFO] User Alice created a new project")
# => "[USER] Alice [INFO] User Alice created a new project"
```

Podes assumir que:

- Cada ocorrência da string `"User"` é seguida de um ou mais carateres de espaço e do nome de utilizador.
- Há, no máximo, uma ocorrência da string `"User"` em cada linha.
- Os nomes de utilizador são strings não vazias que não contêm espaços.
