# Introdução

Os ponteiros inteligentes em Cairo são estruturas de dados avançadas que garantem uma gestão de memória segura e eficiente ao adicionar funcionalidades de segurança aos ponteiros normais, prevenindo problemas comuns como desreferenciar ponteiros nulos ou aceder a memória não inicializada.

## O que é um ponteiro inteligente?

Um ponteiro inteligente comporta-se como um ponteiro normal, mas controla a propriedade e garante um acesso seguro à memória, prevenindo problemas como a desreferenciação de ponteiros nulos ou pendentes.

## Tipos de ponteiros inteligentes

Cairo fornece vários tipos de ponteiros inteligentes, como `Box<T>` e `Nullable<T>`:

- **`Box<T>`**: Armazena dados num segmento de memória especial, ideal para dados grandes ou de tamanho dinâmico.
                Permite transferir a propriedade sem copiar os dados.
- **`Nullable<T>`**: Aponta para um valor válido do tipo `T` ou para `null`, útil para lidar com valores opcionais.

## Segurança da memória

Os ponteiros inteligentes ajudam a prevenir acessos inseguros à memória, garantindo que a memória é automaticamente libertada quando já não é necessária, reduzindo assim o risco de fugas de memória.

### Exemplo: Utilizar `Box<T>` para tipos recursivos

Ponteiros inteligentes como `Box<T>` permitem um manuseamento seguro de tipos recursivos, como numa árvore binária, ao alocar memória de forma eficiente e evitar a recursão infinita.

```rust
use core::box::{BoxTrait};

#[derive(Copy, Drop)]
enum BinaryTree {
    Leaf: u32,
    Node: (u32, Box<BinaryTree>, Box<BinaryTree>),
}

fn main() {
    let leaf1 = BinaryTree::Leaf(1);
    let leaf2 = BinaryTree::Leaf(2);
    let node = BinaryTree::Node((3, BoxTrait::new(leaf1), BoxTrait::new(leaf2)));
    println!("{:?}", node);
}
```

## Vantagens de desempenho

Os ponteiros inteligentes melhoram o desempenho ao passar referências para os dados em vez de copiar grandes estruturas, reduzindo a sobrecarga de memória.

```rust
// `Cart` is a large struct that contains a lot of information
fn pass_pointer(cart: Box<Cart>) {
    let cart = cart.unbox();
    println!("{} is shopping today and bought {} items", cart.buyer, cart.items);
}
```
