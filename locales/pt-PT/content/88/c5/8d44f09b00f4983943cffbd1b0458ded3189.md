# Introdução

Os carateres em Factor são inteiros, ou seja, pontos de código Unicode, por isso os operadores numéricos `<`, `>`, `=` dão-te diretamente uma ordenação que distingue maiúsculas de minúsculas. O vocabulário [`unicode`][unicode] acrescenta predicados que têm em conta o Unicode e a conversão de maiúsculas e minúsculas de carateres individuais.

## Predicados sobre carateres

```
LETTER?  ( c -- ? )    ! uppercase letter
letter?  ( c -- ? )    ! lowercase letter
Letter?  ( c -- ? )    ! letter, either case
digit?   ( c -- ? )    ! decimal digit
blank?   ( c -- ? )    ! whitespace
```

```factor
USING: unicode ;

CHAR: A LETTER? .    ! => t
CHAR: a letter? .    ! => t
CHAR: 7 digit?  .    ! => t
```

## Conversão de maiúsculas e minúsculas

`ch>upper` e `ch>lower` trocam um único caráter. Ao nível da string, `>upper` e `>lower` aplicam-nas a todos os carateres de uma string.

```factor
CHAR: a ch>upper .   ! => 65   (which is CHAR: A)
"Hello" >upper .     ! => "HELLO"
```
