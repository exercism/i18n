# Instruções

Neste exercício vais trabalhar com contas poupança. Todos os anos, o saldo da tua conta poupança é atualizado com base na sua taxa de juro. A taxa de juro que o teu banco te dá depende da quantidade de dinheiro na tua conta (o saldo):

- 3,213% para um saldo negativo (resulta em juros negativos).
- 0,5% para um saldo positivo inferior a `1000` dólares.
- 1,621% para um saldo positivo maior ou igual a `1000` dólares e inferior a `5000` dólares.
- 2,475% para um saldo positivo maior ou igual a `5000` dólares.

Todos os anos o governo permite-te doar uma percentagem do teu dinheiro a instituições de caridade, livre de impostos. Como és uma pessoa simpática, se o teu saldo ficar positivo no final do ano, pegas na percentagem livre de impostos, duplicas e arredondas para baixo até ao dólar inteiro mais próximo. Não te importas de pagar impostos sobre a segunda metade da doação.

Tens três tarefas, cada uma delas vai lidar com o teu saldo e a sua taxa de juro.

## 1. Calcula a taxa de juro

Implementa a função `interestRate` para calcular a taxa de juro com base no saldo indicado:

```fsharp
interestRate 200.75m
// => 0.5f
```

Repara que o valor devolvido é um `single`.

## 2. Calcula os juros

Implementa o método `interest` para calcular os juros com base no saldo indicado:

```fsharp
interest 200.75m
// => 1.00375m
```

Repara que o valor devolvido é um `decimal`.

## 3. Calcula a atualização do saldo anual

Implementa a função `annualBalanceUpdate` para calcular a atualização do saldo anual, tendo em conta a taxa de juro:

```fsharp
annualBalanceUpdate 200.75m
// => 201.75375m
```

Repara que o valor devolvido é um `decimal`.

## 4. Calcula quanto dinheiro doar

Implementa a função `amountToDonate` para calcular quanto dinheiro doar a instituições de caridade, com base no saldo e na percentagem livre de impostos que o governo permite:

```fsharp
let balance = 550.5m
let taxFreePercentage = 2.5
amountToDonate balance taxFreePercentage
// => 27
```

Repara que o valor devolvido é um `int`.
