# Introdução

Em Elixir, as funções são tratadas como cidadãos de primeira classe. Isto significa que:

- As funções nomeadas e as funções anónimas podem ser atribuídas a variáveis.
- As funções nomeadas e as funções anónimas podem ser passadas de um lado para o outro como dados, sob a forma de argumentos e de valores devolvidos.
- As funções anónimas podem ser criadas dinamicamente.

Ao contrário das funções nomeadas, as funções anónimas não têm uma referência estática disponível: só estão acessíveis se forem atribuídas a uma variável ou invocadas imediatamente.

Podemos usar funções anónimas para:

- Ocultar dados recorrendo ao âmbito lexical (também conhecido como closure).
- Criar funções dinamicamente em tempo de execução.

As funções anónimas começam com a palavra reservada `fn`, os argumentos são separados do corpo da função pelo token `->` e terminam com um `end`. Tal como nas funções nomeadas, a última expressão da função é _devolvida implicitamente_ à função que a invoca.

Para invocares uma referência de função, tens de usar um `.` entre a variável da referência e a lista de argumentos:

```elixir
function_variable = fn param ->
  param + 1
end

function_variable.(1)
# => 2
```

Podes até usar a notação de captura abreviada para tornar isto mais conciso:

```elixir
variable = &(&1 + 1)

variable.(1)
# => 2
```
