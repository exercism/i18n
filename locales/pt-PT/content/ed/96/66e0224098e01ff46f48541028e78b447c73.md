# Sobre

O [Clojure](http://clojure.org) é uma linguagem de programação dinâmica que tem como alvo a máquina virtual Java (JVM).
Concebida como linguagem de propósito geral, o Clojure combina a acessibilidade de uma linguagem de script com uma infraestrutura robusta para a programação com múltiplos threads.

O Clojure é predominantemente uma linguagem de programação funcional e dispõe de um conjunto rico de [estruturas de dados](http://clojure.org/data_structures) imutáveis e persistentes.

O Clojure é de código aberto, e [podes encontrar aqui](http://clojure.org/contributing) informações sobre como contribuir para a linguagem.

Rich Hickey, o criador do Clojure, queria um Lisp moderno para programação funcional, simbiótico com a plataforma Java já estabelecida e concebido para a concorrência; foi assim que o Clojure nasceu.

Aqui ficam duas citações que exemplificam os objetivos do Clojure:

* _Um bom design não consiste em fazer grandes planos, mas em desmontar as coisas._
* _Programar não é escrever... é pensar._
