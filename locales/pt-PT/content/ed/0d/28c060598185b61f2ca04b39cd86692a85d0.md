# sugere remover extern crate

Considera remover `extern crate`, pois [já não é necessário](https://doc.rust-lang.org/stable/edition-guide/rust-2018/module-system/path-clarity.html#no-more-extern-crate) na edição de 2018 do Rust, que é a edição que os exercícios da track de Rust estão configurados para usar.
