# Instruções

Neste exercício vais escrever um TreasureChest genérico (e mágico!) para guardar algum tesouro.

## 1. Define o tipo TreasureChest

Define um tipo paramétrico `TreasureChest{T}` com dois campos.

- Um campo `password` do tipo `String`, que vai ser usado para guardar a palavra-passe do baú do tesouro.
- Um campo `treasure` do tipo `T`, que vai ser usado para guardar o tesouro.
Este valor é genérico, para que o tesouro possa ser qualquer coisa.

```julia-repl
julia> chest = TreasureChest{String}("password", "gold")
TreasureChest{String}("password", "gold")
```



## 2. Define a função get_treasure()

Esta função deve receber dois argumentos.

- Uma `String` (para tentar uma palavra-passe)
- Um tipo `TreasureChest`

Esta função deve verificar a tentativa de palavra-passe fornecida contra a `password` do `TreasureChest`.

- Se as palavras-passe coincidirem, devolve o tesouro.
- Se as palavras-passe não coincidirem, devolve `nothing`.

```julia-repl
julia> get_treasure("password", chest)
"gold"

julia> get_treasure("wrong", chest)
# no output

julia> isnothing(get_treasure("wrong", chest))
true
```

## 3. Define a função multiply_treasure()

Esta função deve receber dois argumentos.

- Um multiplicador inteiro `n`.
- Um tipo `TreasureChest{T}`.

A função deve devolver um novo `TreasureChest{Vector{T}}`, com 
- A mesma palavra-passe que o original
- O tesouro multiplicado como um `Vector{T}` de comprimento `n`, com o tesouro original repetido `n` vezes.

```julia-repl
julia> multiply_treasure(3, chest)
TreasureChest{Vector{String}}("password", ["gold", "gold", "gold"])
```
