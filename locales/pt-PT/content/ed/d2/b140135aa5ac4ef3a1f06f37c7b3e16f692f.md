# Sobre

Uma [instrução switch][switch] permite-te comparar um valor com vários valores possíveis.
Permite-te escrever código mais conciso do que se usares várias instruções `else-if`.
Uma instrução switch começa com a palavra-chave `switch`, seguida do valor a comparar.
Depois, podes definir os casos com a palavra-chave `case`, seguida do valor com que queres comparar.
A palavra-chave `default` serve para definir o caso predefinido, quando nenhum dos casos corresponde.
Tal como as instruções `else-if`, as instruções `switch` só executam o bloco de código associado ao primeiro caso correspondente.

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

Considera o seguinte exemplo:

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

Em alternativa, podias escrever isto assim:

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```

[switch]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#Switch
