## Geral

[Fatias](https://doc.rust-lang.org/book/2018-edition/ch04-03-slices.html) têm, para além do acesso normal aos elementos por indexação (slice[index]), muitas funções úteis como [split_at](https://doc.rust-lang.org/std/primitive.slice.html#method.split_at) ou [obter subfatias](https://doc.rust-lang.org/std/primitive.slice.html#method.get) (slice[start..end]).

Podes resolver este exercício usando apenas o velho e aborrecido acesso a elementos por indexação, mas talvez as outras funções fornecidas possam tornar o teu código mais limpo e mais seguro.

## Para pontos bónus

- Para que a tua função funcione com todos os tipos de elementos que podem ser ordenados, dá uma olhadela ao [Ord Trait](https://doc.rust-lang.org/std/cmp/trait.Ord.html).
- Para que a tua função funcione diretamente com Vec e Array, podes usar a [AsRef Trait](https://doc.rust-lang.org/std/convert/trait.AsRef.html)
