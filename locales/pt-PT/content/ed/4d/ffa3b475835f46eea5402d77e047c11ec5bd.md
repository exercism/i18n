# Instruções

O teu grupo de cordas vai dar um recital e alguém tem de escrever o programa.

As cinco tarefas ficam todas na classe `PROGRAMME_NOTES`.

## 1. Indica o nome da peça e quem a escreveu

Coloca a peça primeiro, depois ` by `, e por fim o compositor.

```sather
PROGRAMME_NOTES::full_title("Nocturne", "Chopin")
-- => "Nocturne by Chopin"
```

## 2. Mede uma linha

A gráfica precisa de saber o comprimento de uma linha.

```sather
PROGRAMME_NOTES::title_length("Nocturne")
-- => 8
```

## 3. As primeiras letras

Dado um título e um número, devolve esse número de letras a partir do início.

```sather
PROGRAMME_NOTES::opening_letters("Nocturne", 3)
-- => "Noc"
```

## 4. As últimas letras

O mesmo, mas a contar a partir do fim.

```sather
PROGRAMME_NOTES::closing_letters("Nocturne", 4)
-- => "urne"
```

## 5. Encurta um título longo

Os títulos que não cabem são cortados nas suas primeiras seis letras, seguidas de três pontos.

```sather
PROGRAMME_NOTES::short_title("Nocturne in E flat")
-- => "Noctur..."
```
