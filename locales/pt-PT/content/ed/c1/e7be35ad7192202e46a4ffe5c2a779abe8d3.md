# Introdução

Todo o código Common Lisp é composto por S-Expressions (Expressões Simbólicas). São abreviadas para sexprs. Cada sexpr é ou um átomo ou um cons. Quando as S-Expressions são avaliadas, devolvem automaticamente um valor que ocupa o lugar da expressão. Quando escreves as tuas próprias funções (usando `defun`), o último valor dentro do corpo do `defun` é devolvido automaticamente:

```lisp
;; Defining a new function
(defun gimme-foo () 'foo)
;; Calling the function as an S-Expression
(gimme-foo) ; => FOO
```
