# Instruções

Estás a marcar um trilho pedestre pelo mato. As distâncias e os avistamentos vêm ambos como sequências, por isso são ambos iteradores.

Os quatro ficam na classe `BUSH_WALK`. Todos eles são iteradores, por isso todos os nomes terminam em `!`.

## 1. Os marcadores

`markers!` recebe um espaçamento em metros e um número, e dá a distância de cada marcador desde o início.

```sather
loop
   #OUT + BUSH_WALK::markers!(100, 3) + " ";
end;
-- 100 200 300
```

Uma contagem de zero não dá nada.

## 2. Até ao fim do trilho

`until_end!` recebe os avistamentos ao longo do trilho e dá-os um a um, parando quando encontra `"end"`. O próprio `"end"` não é dado.

```sather
loop
   #OUT + BUSH_WALK::until_end!(|"gum", "wattle", "end", "banksia"|) + " ";
end;
-- gum wattle
```

Se não houver `"end"`, dá tudo.

## 3. Apenas as aves

`birds!` recebe os avistamentos e dá apenas os que começam com letra maiúscula, que é como este levantamento escreve as aves.

```sather
loop
   #OUT + BUSH_WALK::birds!(|"gum", "Emu", "wattle", "Galah"|) + " ";
end;
-- Emu Galah
```

## 4. Numerado

`numbered!` recebe os avistamentos e dá cada um com a sua posição à frente, a contar a partir de um.

```sather
loop
   #OUT + BUSH_WALK::numbered!(|"gum", "Emu"|) + " ";
end;
-- 1. gum 2. Emu
```
