# Instruções

És um elfo a trabalhar na divisão de logística do Pai Natal e o chefe deu-te um par de tarefas para melhorar o software do sistema.

## 1. Obter o nome do brinquedo

O sistema tem de conseguir obter o nome de um brinquedo a partir da base de dados.
A base de dados é composta por tuplas do tipo `(name: String, quantity: Int)`.

Implementa a função `getName(_:)`, que recebe um argumento que contém uma tupla do tipo `(name: String, quantity: Int)`.

```swift
let toy = (name: "Doll", quantity: 10)
getName(toy)
// Returns "Doll"
```

## 2. Adicionar um brinquedo novo à base de dados

O mercado dos brinquedos é rápido e está sempre a mudar: o que é popular muda muito depressa.
Por isso, é precisa uma função que crie um brinquedo novo.

Implementa a função `createToy(name:amount:)`, que recebe um argumento `name`, que contém o nome do brinquedo, e `amount`, que contém a quantidade do brinquedo.

```swift
createToy(name: "Doll", amount: 10)
// Returns (name: "Doll", amount: 10)
```

## 3. Atualizar a quantidade de um brinquedo

Os elfos da oficina do Pai Natal estão constantemente a fazer mais brinquedos, e o Pai Natal tem de manter o controlo da quantidade de cada brinquedo.
Para isso, o sistema tem de conseguir atualizar a quantidade de um brinquedo na base de dados.

Implementa a função `updateQuantity(_:toy:Amount:)`, que recebe os argumentos:
- `toys`, que contém um array de tuplas do tipo `(name: String, quantity: Int)`.
- `toy`, que contém o nome do brinquedo a atualizar.
- `amount`, que contém a nova quantidade do brinquedo.

Podes assumir que o brinquedo já está na base de dados e que não precisas de verificar isso.

```swift
let toys = [(name: "Doll", quantity: 10), (name: "Car", quantity: 5), (name: "Train", quantity: 3)]
updateQuantity(toys, toy: "Doll", amount: 15)
// Returns [(name: "Doll", quantity: 15), (name: "Car", quantity: 5), (name: "Train", quantity: 3)]
```

## 4. Adicionar uma chave de categoria a um brinquedo

O Pai Natal quer conseguir categorizar os brinquedos na base de dados.
Assim, consegue encontrar facilmente os brinquedos quando precisa de fazer uma entrega, e consegue ordenar os brinquedos na base de dados.

No entanto, quando o sistema foi implementado pela primeira vez, a chave de categoria foi esquecida.
Agora, o sistema tem de conseguir adicionar uma chave de categoria a um brinquedo na base de dados.

Implementa a função `addCategory(_:category:)`, que recebe os argumentos:
- `toys`, que contém um array de tuplas do tipo `(name: String, quantity: Int)`.
- `category`, que contém a chave de categoria a adicionar aos brinquedos.

Podes assumir que o brinquedo já está na base de dados e que não precisas de verificar isso.
Podes também assumir que o brinquedo ainda não tem nenhuma chave de categoria.

```swift
let toys = [(name: "Car", quantity: 5), (name: "Train", quantity: 3)]
addCategory(toys, category: "Vehicle")
// Returns [(name: "Car", quantity: 5, category: "Vehicle"), (name: "Train", quantity: 3, category: "Vehicle")]
```
