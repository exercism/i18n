# Instruções

A Elena é a nova gestora de qualidade de uma fábrica de jornais.
Como acaba de chegar à empresa, decidiu rever alguns dos processos da fábrica para ver o que pode ser melhorado.

Descobriu que os técnicos fazem muitos controlos de qualidade à mão.

Vê aí uma boa oportunidade de automatização e pede-te, enquanto programador independente, que desenvolvas um software para monitorizar algumas das máquinas.

## 1. Monitorizar o nível de humidade da sala

A tua primeira missão é escrever um software para monitorizar o nível de humidade da sala de produção.
Já existe um sensor ligado ao software da empresa que devolve periodicamente a percentagem de humidade da sala.

Tens de implementar uma função no software que lance um erro se a percentagem de humidade for demasiado alta.
A função deve chamar-se `check_humidity_level` e receber a percentagem de humidade como parâmetro.

Deves parar com um erro (a mensagem não é importante) se a percentagem ultrapassar 70%.
Caso contrário, emite uma mensagem que inclua "humidity test passed" e devolve `TRUE` para confirmar que a medição está boa.

```R
check_humidity_level(60)
#> humidity test passed
#> [1] TRUE

check_humidity_level(100)
#> Error in check_humidity_level(100) : pct_humidity <= 70 is not TRUE
```

## 2. Detetar sobreaquecimento

A Elena está muito satisfeita com a tua primeira tarefa e pede-te para tratares da monitorização da temperatura das máquinas.
Enquanto conversas com um técnico, o Greg, ficas a saber que, se a temperatura de uma máquina ultrapassar 500 °C, os técnicos começam a preocupar-se com o sobreaquecimento.

A máquina está equipada com um sensor que mede a sua temperatura interna.
Deves saber que o sensor é muito sensível e avaria com frequência.
Nesse caso, os técnicos terão de o substituir.

A tua tarefa é implementar uma função `report_overheating` que recebe a temperatura como parâmetro e lança um erro se o sensor estiver avariado ou se a máquina começar a sobreaquecer.

Sabendo que, mais tarde, vais precisar de reagir de forma diferente consoante o erro, precisas de um mecanismo para distinguir os dois tipos de erros.

- Se o sensor estiver avariado, a temperatura será `NULL`.
  Nesse caso, deves parar com uma mensagem de erro que inclua "Sensor Broken" como parte da string.
- Quando o sensor estiver a funcionar, se a temperatura ultrapassar 600 °C, deves parar com uma mensagem que inclua a temperatura.
- Se a temperatura ultrapassar 500 °C mas não 600 °C, deves emitir um aviso que inclua a temperatura e devolver `FALSE`.
- Caso contrário, está tudo bem, por isso emite a mensagem `"temperature check passed: t °C"`, em que `t` é a temperatura, e devolve `TRUE`.

```R
report_overheating(NULL)
#> Error in report_overheating(NULL) : Sensor Broken

report_overheating(800)
#> Error in report_overheating(800) : Overheating: 800 C

report_overheating(550)
#> [1] FALSE
#> Warning message:
#> In report_overheating(550) : Risk of overheating: 550 C

report_overheating(450)
#> temperature check passed: 450 °C
#> [1] TRUE
```


## 3. Monitorizar a máquina

Agora que a tua máquina consegue detetar erros e tens um erro personalizado de máquina, adicionas uma função de invólucro que consegue relatar como está tudo a funcionar.
Além de devolver os registos das funções anteriores, esta função de invólucro também terá de adicionar registos consoante os tipos de falha que ocorram.

- Verifica a humidade e a temperatura.
- Se houver problemas, deixa apenas que `check_humidity_level()` e `report_overheating()` apresentem os seus registos.
- Se estiver tudo bem, adiciona uma mensagem que inclua "All OK".

Implementa uma função `monitor_the_machine()` que recebe a humidade e a temperatura como argumentos.

```R
# Working well
monitor_the_machine(53, 200)
#> humidity test passed
#> temperature check passed: 200 °C
#> All OK!

# High humidity
monitor_the_machine(90, 200)
#> Error in check_humidity_level(pct_humidity) : 
#>   pct_humidity <= 70 is not TRUE

# Faulty sensor
monitor_the_machine(53, NULL)
#> humidity test passed
#> Error in report_overheating(temperature) : Sensor Broken

# Mild overheating
monitor_the_machine(53, 550)
#> humidity test passed
#> Warning message:
#> In report_overheating(temperature) : Risk of overheating: 550 C

# Dangerous overheating: shutdown
monitor_the_machine(53, 650)
#> humidity test passed
#> Error in report_overheating(temperature) : Overheating: 650 C
```
