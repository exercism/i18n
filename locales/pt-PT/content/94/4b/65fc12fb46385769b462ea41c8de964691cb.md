# Dicas

## 1. Determina se vais precisar de uma carta de condução

- Usa o [operador de comparação de igualdade][comparison-operators] para verificar se o teu valor de entrada é igual a uma determinada string.
- Usa um dos dois [operadores lógicos][logical-operators] que aprendeste no conceito de Boolean para combinar os dois requisitos.
- **Não** precisas de uma condicional para resolver esta tarefa. Podes devolver diretamente a expressão Boolean que crias.

## 2. Escolhe entre dois veículos potenciais para comprar

- Usa um [operador de comparação][comparison-operators] para determinar que opção vem primeiro na ordem lexicográfica.
- Depois, define o valor de uma variável auxiliar consoante o resultado dessa comparação, com a ajuda de uma [condicional if-else][if-statement].
- Por fim, constrói a frase de recomendação.
  Para isso, podes usar o operador `+` para concatenar as duas strings.

## 3. Calcula uma estimativa para o preço de um veículo usado

- Começa por determinar a percentagem do preço original com base na idade do veículo.
  Guarda-a numa variável auxiliar. Usa uma [condicional if-else if-else][if-statement] como é referido nas instruções.
- Nas duas condições if, usa [operadores de comparação][comparison-operators] para comparar a idade do carro com os valores limite.
- Para calcular o resultado, aplica a percentagem ao preço original. Por exemplo, `30% of x` pode ser calculado dividindo `30` por `100` e multiplicando por `x`.

[comparison-operators]: https://golang.org/ref/spec#Comparison_operators
[logical-operators]: https://golang.org/ref/spec#Logical_operators
[if-statement]: https://golang.org/ref/spec#If_statements
