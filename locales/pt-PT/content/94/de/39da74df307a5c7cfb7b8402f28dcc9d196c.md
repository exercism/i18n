# Instruções

Neste exercício, vais implementar a lógica da missão de um novo jogo de RPG que um amigo está a desenvolver.

A personagem principal do jogo é a Annalyn, uma rapariga corajosa com um cão de estimação feroz e leal. Infelizmente, o desastre acontece: o seu melhor amigo foi raptado enquanto procurava bagas na floresta.

A Annalyn vai tentar encontrar e libertar o seu melhor amigo, podendo levar o cão com ela nesta missão.

Depois de algum tempo a seguir o rasto do seu melhor amigo, encontra o acampamento onde ele está preso. Acontece que há dois raptores: um cavaleiro poderoso e um arqueiro astuto.

Depois de encontrar os raptores, a Annalyn pondera quais das seguintes ações pode realizar:

- _Ataque rápido_: é possível fazer um ataque rápido se o cavaleiro estiver a dormir, pois demora algum tempo a vestir a armadura e, por isso, fica vulnerável.
- _Espiar_: é possível espiar o grupo se pelo menos um deles estiver acordado. Caso contrário, espiar é uma perda de tempo.
- _Sinalizar o prisioneiro_: é possível sinalizar o prisioneiro com sons de aves se o prisioneiro estiver acordado e o arqueiro estiver a dormir, pois os arqueiros são treinados em sinais de aves e podem intercetar a mensagem.
- _Libertar o prisioneiro_: a Annalyn pode tentar entrar furtivamente no acampamento para libertar o prisioneiro.
  Isto é arriscado e só pode correr bem de uma de duas formas:
  - Se a Annalyn tiver o cão com ela, pode resgatar o prisioneiro se o arqueiro estiver a dormir.
    O cavaleiro tem medo do cão e o arqueiro não terá tempo de se preparar antes de a Annalyn e o prisioneiro conseguirem escapar.
  - Se a Annalyn não tiver o cão, então ela e o prisioneiro têm de ser muito discretos!
    A Annalyn pode libertar o prisioneiro se este estiver acordado e o cavaleiro e o arqueiro estiverem ambos a dormir, mas se o prisioneiro estiver a dormir não pode ser resgatado: o prisioneiro ficaria sobressaltado com o aparecimento súbito da Annalyn e acordaria o cavaleiro e o arqueiro.

Tens quatro tarefas: implementar a lógica para determinar se as ações acima estão disponíveis, com base no estado das três personagens encontradas na floresta e na presença ou não do cão da Annalyn.

## 1. Verifica se é possível fazer um ataque rápido

Implementa o método `canFastAttack()`, que recebe um valor do tipo boolean que indica se o cavaleiro está acordado. Este método devolve `true` se for possível fazer um ataque rápido com base no estado do cavaleiro. Caso contrário, devolve `false`:

```haxe
var knightIsAwake = true;
canFastAttack(knightIsAwake);
// => false
```

## 2. Verifica se é possível espiar o grupo

Implementa o método `canSpy()`, que recebe três valores do tipo boolean, que indicam se o cavaleiro, o arqueiro e o prisioneiro, respetivamente, estão acordados. O método devolve `true` se for possível espiar o grupo, com base no estado das três personagens. Caso contrário, devolve `false`:

```haxe
var knightIsAwake = false;
var archerIsAwake = true;
var prisonerIsAwake = false;
canSpy(knightIsAwake, archerIsAwake, prisonerIsAwake);
// => true
```

## 3. Verifica se é possível sinalizar o prisioneiro

Implementa o método `canSignalPrisoner()`, que recebe dois valores do tipo boolean, que indicam se o arqueiro e o prisioneiro, respetivamente, estão acordados. O método devolve `true` se for possível sinalizar o prisioneiro, com base no estado das duas personagens. Caso contrário, devolve `false`:

```haxe
var archerIsAwake = false;
var prisonerIsAwake = true;
canSignalPrisoner(archerIsAwake, prisonerIsAwake);
// => true
```

## 4. Verifica se é possível libertar o prisioneiro

Implementa o método `canFreePrisoner()`, que recebe quatro valores do tipo boolean. Os primeiros três parâmetros indicam se o cavaleiro, o arqueiro e o prisioneiro, respetivamente, estão acordados. O último parâmetro indica se o cão da Annalyn está presente. O método devolve `true` se for possível libertar o prisioneiro, com base no estado das três personagens e na presença do cão da Annalyn. Caso contrário, devolve `false`:

```haxe
var knightIsAwake = false;
var archerIsAwake = true;
var prisonerIsAwake = false;
var petDogIsPresent = false;
canFreePrisoner(knightIsAwake, archerIsAwake, prisonerIsAwake, petDogIsPresent);
// => false
```
