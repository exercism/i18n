# Números exatos

Dois dos tipos de números que já encontraste prescindem de algo.

`INT` tem exatamente 32 bits, por isso guarda números desde cerca de menos dois mil milhões até dois mil milhões e nem um a mais. Ultrapassa isso e dá a volta silenciosamente: nenhum erro, apenas uma resposta errada.

`FLTD` guarda frações, mas apenas de forma aproximada. `0.1d + 0.2d` é quase exatamente `0.3`, mas não exatamente.

Para trabalho em que isso é importante, a biblioteca tem um tipo para cada caso.

## INTI: números inteiros de qualquer tamanho

`INTI` guarda um número inteiro sem limite, a não ser a memória.

```sather
   #INTI(2).pow(100)
   -- 1267650600228229401496703205376
```

Um `INT` não consegue guardar isso. Um `FLTD` conseguiria guardar algo próximo, e perderia os últimos vinte algarismos.

Cria um a partir de um `INT`, ou de uma string quando o número é demasiado grande para ser escrito como `INT` logo à partida:

```sather
   #INTI(42)
   #INTI("123456789012345678901234567890")
```

Depois, `+`, `-`, `*`, `/` e as comparações funcionam como habitualmente, e `.str` dá todos os algarismos.

Contar as formas como um grupo de dançarinos se pode alinhar é a razão habitual para querer isto. Doze dançarinos têm 479001600 formas, que um `INT` consegue guardar; treze têm 6227020800, que já não consegue.

```sather
   #INTI(20).factorial
   -- 2432902008176640000
```

## RAT: frações exatas

`RAT` guarda um número inteiro sobre outro, e mantém-nos assim.

```sather
   #RAT(1, 3)          -- 1/3, exactly
   #RAT(1, 2) + #RAT(1, 3)
   -- 5/6
```

Não acontece nenhum arredondamento, porque nada é alguma vez convertido num decimal.

```sather
   #RAT(1, 10) + #RAT(2, 10) = #RAT(3, 10)      -- true
   0.1d + 0.2d = 0.3d                            -- not to be relied on
```

Um `RAT` reduz-se a si próprio: `#RAT(2, 4)` é `1/2`, e imprime-se como `1/2`. Um que resulte inteiro imprime-se como um número inteiro: `#RAT(6, 3)` imprime `2`.

## O custo

Ambos são mais lentos que os tipos incorporados, e ambos alocam memória. `INT` e `FLTD` são instruções únicas da máquina; `INTI` e `RAT` são objetos a fazer aritmética em software.

Usa-os quando o objetivo é a exatidão, e os tipos normais em todos os outros casos.
