# Introdução

Os Boolean em Cairo são representados pelo tipo Boolean pré-declarado `bool`, cujos valores podem ser `true` ou `false`.

```rust
let speeding = true;   // Boolean variable 'speeding' set to 'true'
let has_error = false; // Boolean variable 'has_error' set to 'false' 
```

O Cairo suporta três operadores lógicos que permitem avaliar expressões para valores Boolean, devolvendo `true` ou `false`.

| Operador    | O que significa                                          |
| ----------- | -------------------------------------------------------- |
| `&&` (e)    | É verdadeiro se ambas as afirmações forem verdadeiras.   |
| `\|\|` (ou) | É verdadeiro se pelo menos uma das afirmações for verdadeira. |
| `!` (não)   | É verdadeiro apenas se a afirmação for falsa.            |
