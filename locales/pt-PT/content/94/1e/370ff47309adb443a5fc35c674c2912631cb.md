# Despesas elevadas na base de dados

## Enunciado do problema

A ABC Corp precisa que encontres o nome e o departamento dos empregados com registos de pagamento superiores a um determinado valor (por exemplo, `3000.00`).

Cria um registo chamado `HighPayment` para devolver os dados necessários. A definição do registo é a seguinte.

```ballerina
type HighPayment record {
    string name;
    string department;
    decimal amount;
    string reason;
};
```

Usa a operação `query` do cliente JDBC para obteres os dados necessários da base de dados.

> NOTA: ordena o resultado por `payment_id` em ordem crescente.

## Detalhes da base de dados

Usa a base de dados H2 fornecida para este problema.

> O ficheiro da base de dados de exemplo é `gofigure.mv.db` e o nome da base de dados é `gofigure`. Está dentro da pasta `db`.

As tabelas seguintes já existem na base de dados H2 de exemplo, com alguns dados de exemplo. Os nomes das colunas e os tipos de dados encontram-se abaixo.

**Nome da tabela**: `Employee`

| **Colunas:**      | tipo |
| -----------       | ----------- |
| `employee_id`     | inteiro, chave primária com incremento automático       |
| `name`            | string        |
| `city`            | string        |
| `department`      | string        |
| `age`             | inteiro        |

**Nome da tabela**: `Payment`

| **Colunas:**      | tipo |
| -----------       | ----------- |
| `payment_id`      | inteiro, chave primária com incremento automático       |
| `date`            | data        |
| `amount`          | decimal        |
| `employee_id`     | inteiro        |
| `reason`          | string        |

* O ficheiro da base de dados é `gofigure.mv.db`. Usa o URL JDBC `jdbc:h2:file:/path/to/db/file`
* Nome de utilizador: `root`
* Palavra-passe: `root`

## Restrições

* Usa o ficheiro da base de dados H2 fornecido na pasta `db` para validares as consultas e o exemplo de Ballerina
* Usa a abordagem dos parâmetros de dependência do maven para adicionares o controlador da base de dados H2 como dependência de plataforma no teu Ballerina.toml

## Ambiente de testes
