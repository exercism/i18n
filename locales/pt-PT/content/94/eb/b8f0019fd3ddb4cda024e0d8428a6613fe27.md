# Dicas

## Geral

- Um valor inteiro pode ser definido como um ou mais algarismos consecutivos.

## 1. Define o tempo esperado no forno, em minutos

- Tens de definir uma [associação][bindings].

## 2. Calcula o tempo restante no forno, em minutos

- Tens de definir uma [função][functions] com um único parâmetro.
- Podes usar a associação definida anteriormente e referi-la pelo nome.
- A última expressão de uma função é [devolvida automaticamente][return-values] pela função; não tens de indicar explicitamente que valor devolver.
- Podes usar o [operador matemático de subtração][operators] para subtrair valores.

## 3. Calcula o tempo de preparação, em minutos

- Tens de definir uma [função][functions] com um único parâmetro.
- Podes usar o [operador matemático de multiplicação][operators] para multiplicar valores.

## 4. Calcula o tempo decorrido, em minutos

- Tens de definir uma [função][functions] com dois parâmetros.
- Podes [chamar][calling] uma das outras funções que definiste anteriormente.
- Podes usar o [operador matemático de adição][operators] para somar valores.
