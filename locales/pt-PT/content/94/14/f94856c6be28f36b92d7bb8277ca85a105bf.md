# Introdução

## Ciclos for

Uma instrução `for` repete um bloco de código.
A sua primeira linha controla a frequência com que o bloco se repete:

```go
for init; condition; post {
    // loop body
}
```

- A instrução **init** corre uma vez antes da primeira iteração. É comum declarar e inicializar uma variável contadora usada pelo ciclo.
- A **condition** é uma expressão Boolean avaliada antes de cada iteração. O ciclo para quando esta for avaliada como `false`.
- A instrução **post** corre depois de cada iteração concluída. Pode ser usada para atualizar um contador.

Não coloques `init; condition; post` entre parênteses.
No entanto, as chavetas à volta do corpo do ciclo são sempre obrigatórias.

Este ciclo começa com `i` em `1`, imprime o valor atual de `i`, incrementa-o para a iteração seguinte e termina quando `i` atinge `10`:

```go
for i := 1; i < 10; i++ {
    fmt.Println(i)
}
```
