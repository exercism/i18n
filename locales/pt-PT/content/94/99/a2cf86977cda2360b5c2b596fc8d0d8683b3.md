# indentação

[comment]: # (Este comentário é devolvido quando a solução usou pelo menos uma tabulação para indentar)

O código Elixir deve ser indentado com 2 espaços. Certifica-te de que não usas tabulações para indentar.

Se estás a resolver exercícios de Elixir no teu próprio computador, considera executar `mix format` no diretório do exercício. Vai formatar o teu código automaticamente de acordo com as normas da comunidade, incluindo corrigir todos os problemas de indentação.
