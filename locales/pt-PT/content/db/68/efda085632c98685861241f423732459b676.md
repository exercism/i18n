# Aprender

## Aprender C++ a partir do zero

C++ é uma linguagem com uma sintaxe ampla e expressiva, que suporta vários estilos de programação diferentes: procedural, orientado a objetos, funcional e genérico, bem como combinações de todos eles no mesmo programa. Este percurso da linguagem procura apresentar problemas com dificuldade gradualmente crescente. No entanto, há elementos da sintaxe da linguagem que é melhor apresentar de outra forma que não como uma série de exercícios.

De um modo geral, o Exercism parte do princípio de que já conheces a sintaxe e os mecanismos de uma linguagem num determinado percurso. Contudo, conhecer a sintaxe de uma linguagem é apenas o primeiro passo para te tornares proficiente numa linguagem. O Exercism permite-te praticar a resolução de problemas e partilhar discussões com outros programadores que resolveram o mesmo problema. É da discussão partilhada que ganhamos perícia e intuição para nos tornarmos melhores programadores.

Se estás a dar os primeiros passos na linguagem C++, deves primeiro dedicar algum tempo a aprender o básico da linguagem. Aqui ficam alguns recursos que te podem ajudar a começar:

* [Learn C++](http://www.learncpp.com/)
* [C++ Koans](https://github.com/torbjoernk/CppKoans)

O [Coliru](http://coliru.stacked-crooked.com/) é uma interface web simples, em forma de formulário, para um compilador de C++ que te permite experimentar pequenos programas. Por vezes, pode ser uma forma mais fácil de fazer um teste rápido do que construir algo localmente num ambiente de desenvolvimento integrado.

## Desenvolvimento orientado a testes em C++

O Exercism parte do princípio de que já conheces o conceito de desenvolvimento orientado a testes. Cada exercício vem com uma série de testes já escritos para ti. Avanças pelo exercício um teste de cada vez, escrevendo uma implementação de forma incremental para satisfazer os testes.

Se és novo no desenvolvimento orientado a testes, recomenda-se vivamente que comeces por fazer o workshop [Test-Driven Development in C++](https://github.com/boostcon/cppnow_presentations_2014/tree/master/files/test_driven) do [C++ Now! 2014](http://cppnow.org/). As mesmas ferramentas usadas nesse workshop são usadas no percurso de C++ do Exercism.
