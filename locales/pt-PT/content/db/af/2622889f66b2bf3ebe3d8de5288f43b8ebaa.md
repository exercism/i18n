# Instruções

Foste tentado a voltar a Hyperia (com a inflação alta) por uma diária de fazer chorar.

O Banco Central está a ponderar introduzir o dólar americano como segunda moeda, por isso todos os sistemas de contabilidade têm de ser adaptados para lidar com várias moedas.

Pediram-te para implementar o objeto de montante monetário.

## 1. Permitir testar a igualdade do montante monetário

Modifica a estrutura `CurrencyAmount` para tratar a igualdade. Se as duas estruturas de montante monetário não tiverem a mesma moeda ("USD" ou "HD"), deve ser lançada uma instância de `ArgumentException`.

```csharp
CurrencyAmount amountA = new CurrencyAmount(55, "HD");
CurrencyAmount amountB = new CurrencyAmount(55, "HD");
CurrencyAmount amountC = new CurrencyAmount(55, "USD");
amountA == amountB
// => true
amountA != amountB
// => false
amountA == amountC
// => ArgumentException
amountA != amountC
// => ArgumentException
```

## 2. Comparar montantes monetários

Modifica a estrutura `CurrencyAmount` para tratar as comparações (`>` e `<`, apenas). Se as duas estruturas de montante monetário não tiverem a mesma moeda ("USD" ou "HD"), deve ser lançada uma instância de `ArgumentException`.

```csharp
CurrencyAmount amountA = new CurrencyAmount(55, "HD");
amountA > new CurrencyAmount(50, "HD")
// => true
amountA < new CurrencyAmount(50, "HD")
// => false
amountA > new CurrencyAmount(50, "USD")
// => ArgumentException
```

## 3. Somar e subtrair montantes monetários

Modifica a estrutura `CurrencyAmount` para tratar a adição e a subtração aritméticas (`+` e `-`, apenas). Se as duas estruturas de montante monetário não tiverem a mesma moeda ("USD" ou "HD"), deve ser lançada uma instância de `ArgumentException`.

```csharp
CurrencyAmount amountA = new CurrencyAmount(55, "HD");
CurrencyAmount amountB = new CurrencyAmount(100, "HD");
CurrencyAmount amountC = new CurrencyAmount(55, "USD");
amountA + amountB
// => {155, HD}
amountB - amountA
// => {45, HD}
amountA + amountC
// => ArgumentException
```

## 4. Multiplicar e dividir montantes monetários

Modifica a estrutura `CurrencyAmount` para tratar a multiplicação e a divisão aritméticas (`*` e `/`, apenas).

```csharp
CurrencyAmount amountA = new CurrencyAmount(10, "HD");
amountA * 2m
// => {20, HD}
amountA / 2m
// => {5, HD}
```

## 5. Converter o montante monetário num `double`

Modifica a estrutura `CurrencyAmount` para que uma instância possa ser convertida explicitamente num `double`.

```csharp
CurrencyAmount amountA = new CurrencyAmount(55.5m, "HD");
(double)amountA
// => 55.5d
```

## 6. Converter o montante monetário num `decimal`

Modifica a estrutura `CurrencyAmount` para que uma instância possa ser convertida implicitamente num `decimal`.

```csharp
CurrencyAmount amountA = new CurrencyAmount(55.5m, "HD");
decimal d = amountA;
// => d == 55.5m
```
