# Testes

Podes correr os testes de várias formas.

## Interativamente a partir do Emacs

1. Abre o ficheiro de testes, `M-x eval-buffer RET`
2. Interativamente e individualmente, com `M-x ert RET test-name RET`
3. Interativamente e de uma só vez, com `M-x ert RET t RET`
   Repara que isto vai correr todos os testes atualmente carregados no Emacs!
4. Volta a executar `M-x eval-buffer RET` antes de testar sempre que fizeres alterações

Para executares apenas os testes do buffer atual, podes adicionar isto ao teu `.emacs` ou `init.el`:

```elisp
(defun my-eval-and-run-all-tests-in-buffer ()
  "Deletes all loaded tests from the runtime, evaluates the current buffer and runs all loaded tests with ert."
  (interactive)
  (ert-delete-all-tests)
  (eval-buffer)
  (ert 't))
```

Depois de reiniciares o Emacs:

1. Abre o ficheiro de testes
2. `M-x my-eval-and-run-all-tests-in-buffer RET`

## A partir do terminal

Para correres todos os testes a partir do terminal, em modo batch, executa `emacs -batch -l ert -l *-test.el -f ert-run-tests-batch-and-exit`

O comando acima é um pouco complicado, por isso, se quiseres:

1. Cria um ficheiro no teu `$PATH` (provavelmente em `~/bin`) chamado `ert-run`
2. O conteúdo do ficheiro deve ser o seguinte:
   ```sh
   #!/usr/bin/env sh
   emacs -batch -l ert -l $1 -f ert-run-tests-batch-and-exit
   ```
3. Torna o ficheiro executável com `chmod +x ert-run`

Deves conseguir simplesmente chamar `ert-run *-test.el` e correr os testes
em modo batch.

## Outras opções

Podes encontrar outras opções na documentação, `C-h i m ert RET`.
