# Introdução

## Alias de tipos

### Alias de tipos

Em Gleam, um alias de tipo permite dar um nome mais conveniente a um tipo que já existe e que, de outra forma, seria trabalhoso de escrever.

```gleam
pub type Headers =
  List(#(String, String))

pub fn html_headers() -> Headers {
  [
    #("content-type", "text/html"),
    #("x-frame-options", "DENY"),
  ]
}
```

Quando é escrito com `pub type`, o alias pode ser usado fora do módulo onde é definido. Se omitires o `pub`, o alias fica privado e não pode ser referido noutros módulos.

## Dicionários

Os dicionários em Gleam são a estrutura de dados que guarda informação em pares chave-valor. Noutras linguagens, também podem ser conhecidos como arrays associativos, hashes ou dicionários.

Qualquer tipo pode ser usado para as chaves e os valores de um dicionário, e este não garante a ordem das suas entradas quando são acedidas ou devolvidas.

### Trabalhar com dicionários

Os dicionários são criados e manipulados com funções do módulo `gleam/dict`.

```gleam
// Create an empty dict
let dict1 = dict.new()

// Create a dict with some values
let dict2 = dict.from_list([
  #("name", "Gleam"),
  #("colour", "Pink"),
])

// Add a value to a dict
let dict3 = dict.insert(dict2, "website", "https://gleam.run")

// Get a value from a dict
let name = dict.get(dict3, "name")
// -> Ok("Gleam")
```
