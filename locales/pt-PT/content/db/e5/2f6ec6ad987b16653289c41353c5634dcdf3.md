# Dicas

## 1. Apresenta-te

A função `introduce` tem de «desembrulhar» o valor contido em `player.Name`.
Considera usar a [função `Options.defaultValue`][defaultvalue] para converter `player.Name` no seu valor «embrulhado» quando é `Some`, ou no valor predefinido necessário quando é `None`.

## 2. Implementa a mecânica de reviver

A função `revive` tem de devolver `Some <player>` ou `None`, em que `<player>` é um registo `Player`, possivelmente com alguns campos modificados.

## 3. Implementa a mecânica de lançamento de feitiços

Considera usar uma expressão match para cobrir tanto o caso `Some` como o caso `None`, como no exemplo seguinte:

```fsharp
let exists (x: int option) =
    match x with
    | Some n -> true
    | None -> false
```
