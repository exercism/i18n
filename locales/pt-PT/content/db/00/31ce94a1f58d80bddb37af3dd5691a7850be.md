# Introdução

Os booleanos em Rust são representados pelo tipo `bool`, cujos valores podem ser `true` ou `false`.

O Rust suporta seis operadores de comparação: `==` (igual), `!=` (diferente), `>` (maior que), `<` (menor que), `>=`
(maior ou igual a), `<=` (menor ou igual a). Podem ser usados para avaliar a relação entre valores não Boolean e obter um valor Boolean.

```rust
1 > 0 // true
1 < 0 // false
1 == 0 // false
1 != 0 // true
1 >= 0 // true
1 <= 0 // false
```

Ao contrário de algumas outras linguagens, `0` não é `false` e um valor diferente de zero não é `true`.

O Rust suporta dois operadores Boolean: `||` (ou), `&&` (e). Só são avaliados quando o operando à esquerda ainda não
determina o resultado da expressão. Ou seja, `||` só avalia o operando à direita quando o operando à esquerda tem o valor
`false`, e `&&` só quando tem o valor `true`.
