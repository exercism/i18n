# Introdução

## Arrays

A biblioteca central do Cairo implementa um tipo `Array`.

É semelhante aos tipos de array habituais noutras linguagens de programação, mas com algumas diferenças importantes:

- Só é possível adicionar elementos de forma eficiente ao fim do tipo `Array`, e só é possível removê-los de forma eficiente do início.
- É impossível definir um item manualmente através do índice do array.

Os arrays podem ser criados com a função `ArrayTrait::new` e também com a macro `array!`:

```rust
let empty: Array<u32> = ArrayTrait::new();
let one_to_four = array![1, 2, 3, 4];
```

É possível adicionar elementos ao array com a função `ArrayTrait::append`:

```rust
let mut num_array = array![1, 2, 3, 4];
num_array.append(5);
// -> [1, 2, 3, 4, 5]
```

É possível remover elementos do array com a função `ArrayTrait::pop_front`:

```rust
let mut one_to_four = array![1, 2, 3, 4];

one_to_four.pop_front();
// -> [2, 3, 4]
```

O Cairo também introduz um tipo `Span` que funciona como um «instantâneo» do `Array`.

Todos os `Array` podem ser convertidos num `Span` com a função `ToSpanTrait::span`:

```rust
let one_to_four = array![1, 2, 3, 4];
let one_to_four_span = one_to_four.span();
// -> [1, 2, 3, 4]
```

Converter um array num `Span` é muito eficiente, porque `Span` é apenas uma estrutura de dados que permite ao Cairo «ver» uma secção do array, sem o modificar de modo algum.

Ao converter um array num `Span`, o Cairo permite realizar mais operações do que as que seriam permitidas diretamente no `Array`, como remover um item do início do span.

```rust
let one_to_four = array![1, 2, 3, 4];
let mut one_to_four_span = one_to_four.span();
one_to_four_span.pop_back();
// -> [2, 3, 4]
```

Repara que tivemos de tornar `one_to_four_span` mutável com a palavra-chave `mut` para podermos invocar `pop_back`, que modifica o span ao encurtar a secção do array que o span está a «ver».
