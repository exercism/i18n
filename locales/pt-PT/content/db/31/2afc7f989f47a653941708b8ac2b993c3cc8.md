# Instruções

Neste exercício, a tua tarefa é escrever o software de um dispositivo de encriptação que funciona realizando transformações sobre os dados. Precisas de uma forma flexível de criar funções complicadas combinando funções mais simples.

Para cada tarefa, devolve uma função anónima que possa ser invocada a partir do âmbito de chamada.

Todas as funções devem esperar argumentos inteiros. Os números inteiros também são adequados para realizar operações bit a bit em Elixir.

## 1. Cria um somador

Implementa `Secrets.secret_add/1`. Deve devolver uma função que recebe um argumento e lhe soma o argumento passado a `secret_add`.

```elixir
adder = Secrets.secret_add(3)
adder.(2)
# => 5
```

## 2. Cria um subtrator

Implementa `Secrets.secret_subtract/1`. Deve devolver uma função que recebe um argumento e subtrai a esse argumento o segredo passado a `secret_subtract`.

```elixir
subtractor = Secrets.secret_subtract(2)
subtractor.(3)
# => 1
```

## 3. Cria um multiplicador

Implementa `Secrets.secret_multiply/1`. Deve devolver uma função que recebe um argumento e o multiplica pelo segredo passado a `secret_multiply`.

```elixir
multiplier = Secrets.secret_multiply(7)
multiplier.(3)
# => 21
```

## 4. Cria um divisor

Implementa `Secrets.secret_divide/1`. Deve devolver uma função que recebe um argumento e o divide pelo segredo passado a `secret_divide`.

```elixir
divider = Secrets.secret_divide(3)
divider.(32)
# => 10
```

Recorre à divisão inteira para que o resultado seja compatível com os valores de entrada esperados pelas outras funções.

## 5. Cria um "and"-er

Implementa `Secrets.secret_and/1`. Deve devolver uma função que recebe um argumento e realiza uma operação _and_ bit a bit sobre esse argumento e o segredo passado a `secret_and`.

```elixir
ander = Secrets.secret_and(1)
ander.(2)
# => 0
```

## 6. Cria um "xor"-er

Implementa `Secrets.secret_xor/1`. Deve devolver uma função que recebe um argumento e realiza uma operação _xor_ bit a bit sobre esse argumento e o segredo passado a `secret_xor`.

```elixir
xorer = Secrets.secret_xor(1)
xorer.(3)
# => 2
```

## 7. Cria um combinador de funções

Implementa `Secrets.secret_combine/2`. Deve devolver uma função que recebe um argumento e lhe aplica, pela ordem indicada, as duas funções passadas a `secret_combine`.

```elixir
add_one = Secrets.secret_add(1)
multiply_by_2 = Secrets.secret_multiply(2)
combined = Secrets.secret_combine(add_one, multiply_by_2)

combined.(3)
# => 8
```
