# Declaração de tipos

As declarações de tipos no PHP fornecem verificações de tipo em tempo de execução para argumentos de funções, valores devolvidos e propriedades de classe.
Nas funções, pode acrescentar-se um tipo de retorno `void` para indicar que a função não devolve nenhum valor.
Os tipos declarados também servem como verificações em tempo de execução de que as funções devolvem uma resposta com um tipo adequado.

```php
<?php

class Driver
{
    private int $serial_number;

    public function setSerialNumber(int $number): void
    {
        $this->serial_number = $number;
    }

    public function getSerialNumber(): int
    {
        return $this->serial_number; 
    }
}

$driver = new Driver();
$driver->setSerialNumber("Version 1b"); // This will throw a TypeError
```

## Uniões de tipos

Se um argumento de função, um valor devolvido ou uma propriedade de classe puder ser de mais do que um tipo, pode declarar-se uma união de tipos.

```php
<?php

class IdentityCard
{
    private int|null $id = null;

    public function assign(int|float $id): void
    {
        $this->id = intval($id);
    }
}

$card = new IdentityCard();
$card->assign(5.0);
```

## Tipos mistos

Quando trabalhamos com código, pode não ser possível especificar um tipo.
A partir do PHP 8.0, é disponibilizado um tipo de escape chamado `mixed`.
`mixed` é equivalente a uma união de tipos de `object|resource|array|string|float|int|bool|null`.
