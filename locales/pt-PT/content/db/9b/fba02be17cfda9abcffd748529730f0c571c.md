# Instruções adicionais

## Palavras

Define um tuplo `stopwatch` e um construtor `<stopwatch> ( -- stopwatch )` que devolve um novo cronómetro no estado `"ready"`, sem tempo decorrido e sem voltas anteriores.

Disponibiliza estas palavras que operam sobre um cronómetro:

- `state ( stopwatch -- str )`: `"ready"`, `"running"` ou `"stopped"`.
- `current-lap ( stopwatch -- str )`: o tempo decorrido da volta atual, como uma string `"HH:MM:SS"`.
- `total ( stopwatch -- str )`: o tempo decorrido combinado da volta atual e de todas as voltas anteriores, como uma string `"HH:MM:SS"`.
- `previous-laps ( stopwatch -- seq )`: um array das voltas registadas anteriormente, cada uma como uma string `"HH:MM:SS"`.
- `start ( stopwatch -- )`, `stop ( stopwatch -- )`, `reset ( stopwatch -- )` e `lap ( stopwatch -- )`: os quatro comandos da tabela acima. Chamar um deles a partir de um estado que não o permite deve lançar um erro com `throw`.

O tempo avança com:

- `advance-time ( str stopwatch -- )`: adiciona a duração `"HH:MM:SS"` à volta atual. Isto só tem efeito enquanto o cronómetro está a correr.
