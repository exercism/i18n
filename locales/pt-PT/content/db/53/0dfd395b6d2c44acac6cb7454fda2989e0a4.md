# Sobre

As [bitstrings][bitstring] permitem aos programadores trabalhar com dados binários de forma eficaz.

- Podes construir bitstrings de forma elegante com a [forma especial `<<>>`][bitstring-form].

  ```elixir
  <<0b101::3>> == <<5::3>> and <<5::3>> == <<5::size(3)>>
  # => true

  first = <<0b110::3>>
  second = <<0b001::3>>
  combined = <<first::bitstring, second::bitstring>>
  # => <<49::size(6)>>
  ```

- Podes fazer correspondência com a forma `<<>>` e usar essa correspondência para [decompor ainda mais os dados binários][bitstring-matching].

  ```elixir
  <<data_size::32, count::size(data_size)>> = <<8::32, 3::8>>
  # => <<0, 0, 0, 8, 3>>
  data_size
  # => 8
  count
  # => 3
  ```

- Podes fazer correspondência com o resto da bitstring usando `::bitstring`.

  ```elixir
  <<_::32, remainder::bitstring>> = <<8::32, 3::8>>
  # => <<0, 0, 0, 8, 3>>
  remainder
  # => <<3>>
  ```

- O *tipo* de dados binário é um tipo específico de bitstring em que o número de bits é divisível por 8.
  - Todos os binários são bitstrings, mas nem todas as bitstrings são binários.
- O Elixir oferece açúcar sintático para trabalhar com [literais inteiros][integer-literal] em diferentes formas:
  - `0b1000001 = ?A = 65`
