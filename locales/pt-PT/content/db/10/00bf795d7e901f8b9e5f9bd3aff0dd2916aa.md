# Dicas

## Geral

- Lê sobre [erros][getting-started-errors] no guia Getting Started.
- Lê sobre [IO][getting-started-io] no guia Getting Started.

## 1. Abrir um ficheiro

- Usa _dynamic dispatch_ para invocar a função open. Revê o excerto de código da introdução.

## 2. Tentar escrever no ficheiro

- Recorre à construção try-rescue.
- Existe uma [função][io-write] no módulo `IO` que te permite escrever num dispositivo de IO.
- Podes usar o bloco `rescue` para fazer correspondência de padrões com o erro e devolver o tuplo de erro.
- Podes usar o bloco `else` para fazer correspondência de padrões com o valor devolvido por uma escrita bem-sucedida.

## 3. Fechar o ficheiro

- Podes usar o bloco `after` para executar uma função, quer um bloco `try` seja bem-sucedido, quer seja resgatado.
