# Instruções

Neste exercício vais modelar uma balança com o quilograma como unidade.

Tens 6 tarefas, cada uma das quais exige que implementes uma ou mais propriedades:

## 1. Permite que a balança tenha uma precisão

Para responder a exigências diferentes, permitimos que cada balança seja personalizada com uma precisão (o número de algarismos depois do separador decimal).
Implementa a classe `WeighingMachine` com uma propriedade `Precision` só de leitura, definida com o argumento `precision` do construtor:

```csharp
var wm = new WeighingMachine(precision: 3);

//  => wm.Precision == 3
```

## 2. Permite definir o peso na balança

Implementa a propriedade `WeighingMachine.Weight` para permitir obter _e_ definir o peso:

```csharp
var wm = new WeighingMachine(precision: 3);
wm.Weight = 60.5;

//  => wm.Weight == 60.5
```

## 3. Garante que um peso de entrada negativo é rejeitado

Como é óbvio, ninguém pode ter um peso negativo.
Adiciona validação à propriedade `WeighingMachine.Weight` para lançar uma `ArgumentOutOfRangeException` ao tentar defini-la com um peso negativo:

```csharp
var wm = new WeighingMachine(precision: 3);
wm.Weight = -10; // Throws an ArgumentOutOfRangeException
```

## 4. Permite aplicar um ajuste de tara à balança

O ajuste de tara pode ser qualquer valor (mesmo negativo ou um valor que torne o peso apresentado negativo).
Implementa a propriedade `WeighingMachine.TareAdjustment` para permitir definir o ajuste de tara:

```csharp
var wm = new WeighingMachine(precision: 3);
wm.TareAdjustment = -10.6;

// => wm.TareAdjustment == -10.6
```

## 5. Garante que a balança tem um ajuste de tara predefinido

Depois de alguns testes aprofundados, parece que, devido a um problema de fabrico, todas as balanças têm tendência para sobrestimar o peso em `5`.
Altera a propriedade `WeighingMachine.TareAdjustment` para `5` como valor predefinido.

```csharp
var wm = new WeighingMachine(precision: 3);

// => wm.TareAdjustment == 5.0
```

## 6. Permite obter o peso

Implementa a propriedade `WeighingMachine.DisplayWeight`, que deve devolver uma string que mostre o peso depois do ajuste de tara, com a precisão correta aplicada e a unidade adicionada.
Tem em atenção que:
``` display-weight = input-weight - tare-adjustment ```

```csharp
var wm = new WeighingMachine(precision: 3);
wm.Weight = 60.567;
wm.TareAdjustment = 10;

// => wm.DisplayWeight == "50.567 kg"
```
