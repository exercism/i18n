# Instruções

Neste exercício, vais aplicar as [regras do jogo de Go](https://matmoore.github.io/learngo/). As regras em si já estão escritas, só precisas de as aplicar para atualizar o `Game` e tratar os eventuais erros / violações das regras.

O jogo é representado da seguinte forma:

```elm
type Player
    = Black
    | White


type alias Game =
    { whiteCapturedStones : Int
    , blackCapturedStones : Int
    , player : Player
    , error : String
    }
```

Há 4 regras no jogo:

- Cada ponto só pode ter uma pedra (`oneStonePerPointRule`)
- As pedras do adversário podem ser capturadas! (`captureRule`)
- Não podes colocar uma pedra onde ela se capturaria a si própria (`libertyRule`)
- Não podes usar o mesmo ponto duas vezes (`koRule`)

## 1. Aplica as regras

Escreve o conteúdo da função `applyRules`, que recebe um `Game` inicial e um conjunto de regras, e devolve o novo `Game` depois de as regras terem sido aplicadas.

`oneStonePerPointRule`, `libertyRule` e `koRule` verificam todas as violações das regras, podem devolver um erro e, por isso, têm o tipo de retorno `Result String Game`. Se alguma destas regras falhar, o jogo original deve ser devolvido, mas com o campo `error` atualizado com o erro em causa.

`captureRule` não verifica violações e, por isso, não pode falhar (embora possa devolver um `Game` alterado), pelo que tem o tipo de retorno `Game`.

Se todas as regras passarem, quaisquer alterações ao `Game` feitas pelas regras devem ser mantidas, e o jogador deve ser alterado. A função `changePlayer` é fornecida para fazer isto.

```elm
applyRules : Game -> Rule -> NonValidatingRule -> Rule -> Rule -> Game
applyRules game oneStonePerPointRule captureRule libertyRule koRule =
--> If all rules pass, return a `Game` with all changes from the rules applied, and changePlayer
--> If any rule fails, return the original Game, but with the error field set
```
