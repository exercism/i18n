# Instruções

És um ávido observador de aves que acompanha quantas aves visitaram o teu jardim.
Normalmente fazes uma contagem num caderno para contar as aves, mas para trabalhares melhor com os teus dados, digitalizaste as contagens de aves das últimas semanas.

## 1. Determina o número total de aves que contaste até agora

Vamos começar por analisar os dados com uma visão geral.
Descobre quantas aves contaste no total desde que começaste os teus registos.

Implementa uma função `TotalBirdCount` que aceita uma slice de `int`s com a contagem de aves por dia.
Deve devolver o número total de aves que contaste.

```go
birdsPerDay := []int{2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1}
TotalBirdCount(birdsPerDay)
// => 34
```

## 2. Calcula o número de aves visitantes numa semana específica

Agora que já tens uma noção geral dos números das tuas contagens de aves, queres fazer uma análise mais detalhada.

Implementa uma função `BirdsInWeek` que aceita uma slice de contagens de aves por dia e um número de semana.

Devolve o número total de aves que contaste nessa semana específica.
Podes assumir que as semanas são sempre registadas por completo.

```go
birdsPerDay := []int{2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1}
BirdsInWeek(birdsPerDay, 2)
// => 12
```

## 3. Corrige um erro de contagem

Deste-te conta de que, durante todo o tempo em que tentavas acompanhar as aves, havia uma ave que estava escondida num canto distante do jardim.

Percebeste que essa ave passava sempre dia sim, dia não, no teu jardim.

Não sabes exatamente onde ela estava entre esses dias, mas de certeza que não estava no teu jardim.

A tua intuição de observador de aves também te diz que a ave estava no teu jardim no primeiro dia que registaste na tua lista.

Dada esta nova informação, escreve uma função `FixBirdCountLog` que recebe uma slice de aves contadas por dia como argumento e devolve a slice depois de corrigir o erro de contagem.

```go
birdsPerDay := []int{2, 5, 0, 7, 4, 1}
FixBirdCountLog(birdsPerDay)
// => [3 5 1 7 5 1]
```
