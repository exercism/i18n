# Introdução aos ciclos `for`

O [ciclo `for`](https://docs.oracle.com/javase/tutorial/java/nutsandbolts/for.html) fornece um mecanismo para executar um conjunto de instruções repetidamente até que uma condição se verifique.
O ciclo é composto por quatro partes:

```java
for (initialization; test; update) {
    body;
}
```

A `initialization` define um estado inicial para o ciclo e é executada exatamente uma vez no início do ciclo.
Normalmente, declara e atribui uma variável que é usada na expressão `test` e na instrução `update`.
Por exemplo:

```java
int i = 1
```

A expressão `test` verifica se o ciclo deve terminar.
Se for avaliada como `true`, o corpo e depois a expressão `update` são executados.
Se for avaliada como `false`, nem o corpo nem a instrução `update` são executados, e a execução continua depois da chaveta de fecho do ciclo.
Normalmente, verifica a variável atribuída no bloco de inicialização.
Por exemplo:

```java
i <= 10
```

Depois de executar o corpo do ciclo, é executada a expressão `update`.
Normalmente, incrementa ou decrementa a variável do ciclo num determinado valor.
Por exemplo:

```java
i++
```

Um ciclo `for` que imprima os primeiros quatro quadrados seria assim:

```java
for (int i = 1; i <= 4; i++) {
    System.out.println("square of " + i + " is " + i * i);
}
```

O resultado seria:

```text
square of 1 is 1
square of 2 is 4
square of 3 is 9
square of 4 is 16
```

Se quiseres iterar sobre todos os elementos de uma coleção, é preferível usar um ciclo `for-each`, mas podes fazê-lo com um ciclo `for` assim:

```java
for (int i = 0; i < array.length; i++) {
    System.out.print(array[i]);
}
```

Um ciclo `for` tem algumas vantagens em relação a um ciclo `for-each`:

- Podes começar ou parar no índice que quiseres.
- Podes usar qualquer condição de terminação do tipo Boolean que quiseres.
- Podes saltar elementos ao personalizar o incremento da variável do ciclo.
- Podes percorrer coleções de trás para a frente, contando de forma decrescente.
- Podes usar ciclos `for` em situações que não envolvem coleções.
