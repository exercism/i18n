# Anexo às instruções

## Registos

| Registo | Utilização               | Tipo            | Descrição                                        |
| ------- | ------------------------ | --------------- | ------------------------------------------------ |
| `$a0`   | parâmetro de entrada     | endereço        | array de palavras com as capacidades dos baldes   |
| `$a1`   | parâmetro de entrada     | inteiro         | balde inicial (1 ou 2)                            |
| `$a2`   | parâmetro de entrada     | inteiro         | volume pretendido                                 |
| `$a3`   | parâmetro de entrada/saída | endereço      | array de palavras com o conteúdo final dos baldes |
| `$v0`   | valor devolvido          | inteiro         | número de ações necessárias, -1 se não for possível |
| `$t0-9` | temporário               | qualquer        | usado para armazenamento temporário               |
