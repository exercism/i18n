# Instruções

Um [número de Armstrong][armstrong-number] é um número que é igual à soma dos seus próprios algarismos, cada um elevado à potência do número de algarismos.

Por exemplo:

- 9 é um número de Armstrong, porque `9 = 9^1 = 9`
- 10 *não* é um número de Armstrong, porque `10 != 1^2 + 0^2 = 1`
- 153 é um número de Armstrong, porque: `153 = 1^3 + 5^3 + 3^3 = 1 + 125 + 27 = 153`
- 154 *não* é um número de Armstrong, porque: `154 != 1^3 + 5^3 + 4^3 = 1 + 125 + 64 = 190`

Escreve código para determinar se um número é um número de Armstrong.

[armstrong-number]: https://en.wikipedia.org/wiki/Narcissistic_number
