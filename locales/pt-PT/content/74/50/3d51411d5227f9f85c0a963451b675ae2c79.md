# Acerca de

As estruturas de dados que podem conter zero ou mais elementos são conhecidas como _coleções_. Um **array** (ou _vetor_) é uma coleção que tem um tamanho/comprimento fixo e cujos elementos têm de ser todos do mesmo tipo. Podes atribuir elementos a um array ou obtê-los a partir dele através de um índice. Os arrays de C# são indexados a partir de zero, ou seja, o índice do primeiro elemento é sempre zero:

```csharp
// Declare array with explicit size (size is 2)
int[] twoInts = new int[2];

// Assign second element by index
twoInts[1] = 8;

// Retrieve the second element by index
twoInts[1] == 8; // => true

// Check the length of the array
twoInts.Length == 2; // => true
```

Também podes definir arrays com uma notação abreviada que te permite criar o array e definir logo o seu valor. Como o compilador consegue agora determinar quantos elementos o array vai ter, podes omitir o comprimento:

```csharp
// Three equivalent ways to declare and initialize an array (size is 3)
int[] threeIntsV1 = new int[] { 4, 9, 7 };
int[] threeIntsV2 = new[] { 4, 9, 7 };
int[] threeIntsV3 = { 4, 9, 7 };
```

Podes manipular arrays chamando os [métodos][array-methods] ou as [propriedades][array-properties] de uma instância de array, ou usando os métodos estáticos definidos na [classe `Array`][array-class].

## Iteração

Um array também é uma _coleção_, o que significa que podes iterar sobre _todos_ os seus valores com um ciclo [`foreach`][foreach-statement]:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // Output the vowel
    System.Console.Write(vowel);
}

// => aeiou
```

Também podes usar um ciclo [`for`][for-statement] para iterar sobre um array:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

for (int i = 0; i < vowels.Length; i++)
{
    // Output the vowel
    System.Console.Write(vowels[i]);
}

// => aeiou
```

No entanto, em geral um ciclo `foreach` é preferível a um ciclo `for` pelas seguintes razões:

- Um ciclo `foreach` tem a garantia de iterar sobre _todos_ os valores. Com um ciclo `for`, é fácil deixar de fora elementos, por exemplo devido a um erro de off-by-one.
- Um ciclo `foreach` é mais _declarativo_: o teu código comunica _o que_ queres que aconteça, em vez de um ciclo `for`, que comunica _como_ o queres fazer.
- Um ciclo `foreach` é à prova de erro, ao passo que com os ciclos `for` é fácil cometer um erro de off-by-one.
- Um ciclo `foreach` funciona com todos os tipos de coleção, incluindo aqueles que não suportam o acesso aos elementos através de um indexador.

Para garantir que um ciclo `foreach` itera sobre _todos_ os valores, o compilador não permite atualizar uma coleção dentro de um ciclo `foreach`:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // This would result in a compiler error
    // vowel = 'Y';
}
```

Um ciclo `for` tem, de facto, algumas vantagens sobre um ciclo `foreach`:

- Podes começar ou parar no índice que quiseres.
- Podes usar a condição de terminação (Boolean) que quiseres.
- Podes saltar elementos personalizando o incremento da variável do ciclo.
- Podes processar coleções de trás para a frente, contando de forma decrescente.
- Podes usar ciclos `for` em cenários que não envolvem coleções.

Tópicos relacionados:

- Deves saber que C# suporta [arrays multidimensionais][multi-dimensional-arrays] como `int[,] arr = new int[10, 5]`, que podem ser muito úteis.
- Deves também saber que podes instanciar objetos do tipo [`System.Array`][system-array-object] com `Array.CreateInstance`. Esses objetos têm pouca utilidade, sobretudo para interoperabilidade com código VB.NET. Não são intercambiáveis com arrays padrão (`T[]`). Podem ter um limite inferior diferente de zero.
