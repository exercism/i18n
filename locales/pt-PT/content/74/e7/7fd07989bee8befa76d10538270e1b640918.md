# A pergunta de mil milhões de dólares do HTTP

## Enunciado do problema

Foi-te pedido que encontrasses os `x` bilionários mais ricos, por património líquido, num determinado conjunto de países (número de países = `N`). Para isso, foi-te dado acesso a uma API que devolve os detalhes dos bilionários por país.

Para simplificar o acesso à API, podes usar o conector [cliente `ims/billionairehub`](https://lib.ballerina.io/ims/billionairehub/1.0.0/clients/Client) para te ligares à API, que devolve os detalhes dos bilionários por país.

## Restrições

* 1 <= N <= 5
* 1 <= x <= 10

## Exemplo 1

Entrada

```
Countries: ["United States"]
Limit: 3
```

Saída

```
["Elon Musk", "Jeff Bezos", "Bill Gates"]
```

## Exemplo 2

Entrada

```
Countries: ["China", "India"]
Limit: 5
```

Saída

```
["Mukesh Ambani", "Gautam Adani & family", "Zhong Shanshan", "Zhang Yiming", "Ma Huateng"]
```

## Ambiente de teste

* O Client ID e o Client Secret para te ligares à API dos bilionários foram-te fornecidos no ficheiro `tests/Config.toml`. Podes usá-los para inicializar o cliente.
* Usa `bal test` para correr e testar a tua implementação.

## Dicas

* O [cliente](https://lib.ballerina.io/ims/billionairehub/1.0.0/clients/Client) do pacote `ims/billionairehub` pode ser usado para invocar a API que devolve os bilionários por país. Podes usar, em concreto, o método remoto `getBillionaires("<country>")`.
* Podes começar por encontrar as pessoas mais ricas de cada país e depois combiná-las para encontrares os `x` bilionários mais ricos.
* As [expressões de consulta](https://ballerina.io/learn/by-example/query-expressions/) serão úteis para filtrar e ordenar.
