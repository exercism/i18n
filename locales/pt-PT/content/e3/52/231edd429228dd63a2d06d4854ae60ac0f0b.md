# Instalação

## Versão alvo

Os testes deste track usam a imagem Docker `alpine:3.24.1` que, a partir de setembro de 2026, usa `sqlite3 version 3.53.4`.
Procuramos garantir que as ferramentas fornecidas por este track funcionem na versão mais recente do Ubuntu LTS.
Embora possas ter versões mais recentes instaladas, tem em atenção que algumas funcionalidades podem não funcionar com o nosso test runner.
Podes comparar as funcionalidades no [histórico de versões do SQLite][version-history].

## Windows

Para instalar o SQLite no Windows, segue estes passos:

1. Descarrega os binários pré-compilados para Windows a partir da [página oficial de downloads][sqlite-download].
2. Extrai o ficheiro ZIP descarregado para o diretório que quiseres.
   Por exemplo, `C:\Program Files\sqlite3`.
3. Adiciona o diretório que contém `sqlite3.exe` à variável de ambiente PATH do sistema.
   O processo é um pouco diferente em cada versão do Windows, mas a informação deve ser fácil de encontrar.
   Por exemplo, [instruções para o Windows 11][windows-11-install] e [Windows 10][windows-10-install].

## macOS

No macOS, o SQLite já vem pré-instalado.
No entanto, se precisares de uma versão mais recente, podes usar o [Homebrew][homebrew]:

```bash
brew install sqlite
```

## Ubuntu / Debian

Nos sistemas Ubuntu e baseados em Debian, podes instalar o SQLite com o apt:

```bash
sudo apt install sqlite3
```

## CentOS / Fedora / RHEL

Nos sistemas CentOS, Fedora e baseados em Red Hat, podes instalar o SQLite com o yum ou o dnf:

```bash
sudo yum install sqlite3
# OR
sudo dnf install sqlite3
```

## Arch Linux

No Arch Linux, podes instalar o SQLite com o pacman:

```bash
sudo pacman -S sqlite
```

## Outras formas de instalação e versões mais antigas

Consulta a [página de downloads do SQLite][sqlite-download] para mais informações e métodos de instalação alternativos.
A secção `Build Product Names and Info` tem o modelo de nomenclatura para as diferentes versões do SQLite, por isso deves conseguir procurar a versão que queres com o teu motor de busca preferido.
