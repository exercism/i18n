# Introdução

Java é uma [linguagem orientada a objetos][object-oriented-programming] e uma linguagem de tipos estáticos, o que significa que o tipo de uma variável é conhecido em tempo de compilação.
Atribuir um valor a um nome chama-se definir uma variável.
Uma variável define-se especificando explicitamente o seu tipo.

```java
int explicitVar = 10;
```

Para atualizar o valor de uma variável usa-se o operador `=`.
Aqui, o `=` não representa igualdade matemática.
Apenas atribui um valor a uma variável.
Depois de definida, o tipo de uma variável nunca pode mudar.

```java
int count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning a different type
// count = false;
```

Java é uma [linguagem orientada a objetos][object-oriented-programming] e exige que todas as funções sejam definidas numa _classe_.
A palavra-chave `class` usa-se para definir uma classe.

```java
class Calculator {
    // ...
}
```

Uma função dentro de uma classe chama-se _método_.
Cada método pode ter zero ou mais parâmetros.
Todos os parâmetros têm de ter um tipo explícito: não há inferência de tipos para parâmetros.
Do mesmo modo, o tipo do valor devolvido também tem de ser explícito.
Os valores são devolvidos pelos métodos com a palavra-chave `return`.
Para que outras classes possam chamar um método, é preciso acrescentar o modificador de acesso `public`.

```java
class Calculator {
    public int add(int x, int y) {
        return x + y;
    }
}
```

Para invocar/chamar um método, indica-se o nome da sua classe e do método e passam-se argumentos para cada um dos parâmetros do método.

```java
int sum = new Calculator().add(1, 2);  // here the  "add" method has been called to perform the task of addition
```

Em Java, o âmbito define-se entre os carateres `{` e `}`.

Java suporta dois tipos de comentários.
Os comentários de uma linha são precedidos de `//` e os comentários de várias linhas são inseridos entre `/*` e `*/`.

[object-oriented-programming]: https://docs.oracle.com/javase/tutorial/java/javaOO/index.html
