# Dicas

## Geral

- O [tipo átomo está descrito aqui][atom].

## 1. Determina o rótulo do log

- Podes usar a [forma especial `cond/1`][cond] para tratar de forma elegante os vários códigos de log.
- Podes usar [operadores de igualdade][equality] para comparar números inteiros quanto à igualdade estrita de tipo.
- Existe uma [forma de especificar um ramo predefinido][cond] numa expressão cond, que podes usar para apanhar os casos não especificados.

## 2. Envia um alerta

- Podes usar a [forma especial `cond/1`][cond] para decidir se um alerta deve ser enviado.
- Podes usar [operadores de igualdade][equality] para comparar átomos quanto à igualdade.

[equality]: https://hexdocs.pm/elixir/Kernel.html#==/2
[atom]: https://hexdocs.pm/elixir/basic-types.html#atoms
[cond]: https://hexdocs.pm/elixir/case-cond-and-if.html#cond
