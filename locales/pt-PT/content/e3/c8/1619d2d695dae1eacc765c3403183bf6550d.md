# Sobre

Cada processo Elixir tem o seu próprio identificador único: um _PID_ (identificador de processo).

- Os PIDs são um tipo de dados próprio.
  - Podes verificar se uma variável é um PID com [`is_pid/1`][kernel-is-pid]
- Podes obter o PID do processo atual com `self()`.
- Os PIDs funcionam como _endereços de caixa de correio_: se tiveres o PID de um processo, podes enviar uma mensagem a esse processo.
- Normalmente, os PIDs são criados indiretamente, como valor devolvido de funções que criam novos processos, como `spawn`.
  - Os PIDs não devem ser criados diretamente pelo programador. Se fosse preciso, o Erlang tem uma função [`list_to_pid/1`][erlang-list-to-pid].

[kernel-is-pid]: https://hexdocs.pm/elixir/Kernel.html#is_pid/1
[erlang-list-to-pid]: https://www.erlang.org/doc/man/erlang.html#list_to_pid-1
