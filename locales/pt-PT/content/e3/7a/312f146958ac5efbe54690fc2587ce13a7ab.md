# Anexo às instruções

## Mensagens de exceção

Por vezes, é necessário [lançar uma exceção](https://docs.python.org/3/tutorial/errors.html#raising-exceptions). Quando o fazes, deves incluir sempre uma **mensagem de erro esclarecedora** que indique qual é a origem do erro. Isto torna o teu código mais legível e ajuda imenso a depurar. Nos casos em que sabes que a origem do erro será de um determinado tipo, podes optar por lançar um dos [tipos de erro incorporados](https://docs.python.org/3/library/exceptions.html#base-classes), mas deves continuar a incluir uma mensagem esclarecedora.

Este exercício em particular exige que uses a [instrução raise](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement) para "lançar" um `ValueError` quando recebes coordenadas inválidas. Os testes só passam se fizeres o `raise` da `exception` e incluíres uma mensagem com ela.

Para lançar um `ValueError` com uma mensagem, escreve a mensagem como argumento do tipo da `exception`:

```python
# when the coordinates for the piece are invalid
raise ValueError('Invalid coordinate')
```
