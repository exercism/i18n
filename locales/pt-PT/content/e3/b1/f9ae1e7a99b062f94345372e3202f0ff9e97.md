# Instruções

Há uma loja de eletrodomésticos chamada "Tech Palace" aqui perto.
O dono da loja instalou recentemente um grande ecrã para usar em mensagens de marketing e para mostrar uma saudação especial quando os clientes passam os seus chamados cartões de fidelização à entrada.
O ecrã é composto por muitas luzes LED pequenas e consegue mostrar várias linhas de texto.

O dono da loja precisa da tua ajuda com o código que é usado para gerar o texto para o novo ecrã.

## 1. Cria a mensagem de boas-vindas

Para a maioria dos clientes que passam os seus cartões de fidelização, o dono da loja quer ver `Welcome to the Tech Palace, ` seguido do nome do cliente em letras maiúsculas no ecrã.

Implementa a função `welcome` que aceita o nome do cliente e devolve a mensagem pretendida como uma string.

```julia-repl
julia> welcome("Judy")
"Welcome to the Tech Palace, JUDY"
```

## 2. Adiciona uma moldura vistosa

Para os clientes fiéis que compram muito na loja, o dono quer que o ecrã de boas-vindas seja mais vistoso, adicionando uma linha de estrelas antes e depois da mensagem de boas-vindas.
Ainda não têm a certeza de quantas estrelas devem ter as linhas, por isso querem que isso seja configurável.

Escreve uma função `add_border` que aceita uma mensagem de boas-vindas e o número de estrelas por linha como argumentos.
Deve devolver uma string composta por 3 linhas: uma linha com o número de estrelas pretendido, depois a mensagem de boas-vindas tal como foi passada, e depois outra linha de estrelas.

```julia-repl
julia> add_border("Welcome!", 10)
"**********\nWelcome!\n**********"
```

## 3. Limpa as mensagens de marketing antigas

Antes de instalar este novo ecrã, a loja tinha um ecrã semelhante que só conseguia mostrar linhas estáticas, não configuráveis.
O dono gostaria de reutilizar algumas das antigas mensagens de marketing no novo ecrã.
No entanto, os dados já incluem alguns espaços em branco indesejados que eram usados para alinhar o texto entre vários ecrãs empilhados uns sobre os outros.
A tua tarefa é limpar as mensagens para que possam ser reutilizadas.

Implementa uma função `clean` que aceita a antiga mensagem de marketing.
A função deve primeiro remover todos os espaços em branco no início e no fim do texto e devolvê-lo.

```julia-repl
julia> clean("    BUY NOW, SAVE 10%   ")
"BUY NOW, SAVE 10%"
```
