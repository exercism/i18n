# Dicas

## Geral

- [Constantes][const]

## 1. Representar a taxa de juro fixa de um empréstimo

- A constante deve ser não tipada, mas tem de ser aceitável em qualquer sítio onde se possa usar um número de vírgula flutuante.
  A função deve devolver a constante.

## 2. Representar o número de dias de um ano

- A função deve devolver a constante.

## 3. Representar os meses do ano

- Existe um [identificador][iota] para criar constantes enumeradas.
  Um bloco tem este [aspeto][block].
  A função deve receber um argumento e devolvê-lo.

## 4. Representar um número de conta

- A constante deve ser não tipada, mas tem de ser aceitável em qualquer sítio onde se possa usar uma string.
  A função deve devolver a constante.

[const]: https://golang.org/doc/effective_go.html#constants
[iota]: https://golang.org/ref/spec#Iota
[block]: https://golang.org/pkg/debug/macho/#pkg-constants
