# Dicas

## Geral

- Lê sobre a utilização de bibliotecas Erlang no [guia oficial de introdução][getting-started-erlang-libraries] e, em particular, sobre [formatação de strings][getting-started-formatted-text-output].

## 1. Gera um planeta aleatório

- Usa o atributo de módulo fornecido com uma lista de letras que representam classes planetárias.
- Existe uma [função incorporada][enum-random] para escolher um elemento de uma lista aleatoriamente.

## 2. Gera um número de registo aleatório de nave estelar

- Existe uma [função incorporada][enum-random] para escolher um elemento de um intervalo aleatoriamente.

## 3. Gera uma data estelar aleatória

- Não existe nenhuma função de Elixir que devolva um número de vírgula flutuante aleatório.
- Existe uma [função incorporada de Erlang][erl-rand-uniform] que devolve um número de vírgula flutuante aleatório x em que `0.0 <= x < 1.0`.
- Se `x` pertence a um intervalo `0.0 <= x < 1.0`, mas precisas de um número de um intervalo diferente `a <= x < b`, podes deslocar o intervalo de x multiplicando-o pela largura do intervalo (`b - a`) e somando o início do intervalo (`a`). Ou seja: `x * (b - a) + a`.

## 4. Formata a data estelar

- Não existe nenhuma função de Elixir capaz de, num único passo, formatar um número de vírgula flutuante como uma string com uma determinada precisão.
- Existe uma [função incorporada de Erlang][erl-io-lib-format] que recebe uma string de formatação e uma lista de dados e devolve um charlist.
- Existe uma [função incorporada][to-string] que transforma um charlist numa string.
- A string de formatação dessa função contém sequências de controlo.
- Uma sequência de controlo começa com `~` e tem o padrão `~F.P.PadModC`, em que `F` representa a largura da saída, `P` representa a precisão, `Pad` representa o caráter de preenchimento, `Mod` representa o modificador da sequência de controlo, e `C` é o tipo da sequência de controlo.
- Para formatar um número de vírgula flutuante com uma precisão pretendida, basta uma sequência de controlo com o padrão `~.PC`.
- O tipo de sequência de controlo para números de vírgula flutuante é `f`.
- A string de formatação exata de que precisas é `~.1f`.
