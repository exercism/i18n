# Dicas

## Geral

- O [pacote strings][strings-package] contém muitas funções úteis para trabalhar com `string`.
- O pacote `strings` tem de ser importado antes de o poderes usar.
- Para chamares funções do pacote `strings`, acrescenta-lhes o prefixo `strings.`.

## 1. Cria a mensagem de boas-vindas

- Podes concatenar strings com o operador `+`.
- Há uma função para [converter uma `string` em maiúsculas][to-upper].

## 2. Adiciona uma moldura vistosa

- Há uma função para [criar uma `string` com um determinado caráter repetido várias vezes][repeat].
- Uma nova linha é um [caráter de escape][escape-characters] especial.

## 3. Limpa as mensagens de marketing antigas

- Há uma função para [substituir strings dentro de uma `string`][replace-all].
- Há uma função para [remover os espaços no início e no fim de uma `string`][trim-space].
