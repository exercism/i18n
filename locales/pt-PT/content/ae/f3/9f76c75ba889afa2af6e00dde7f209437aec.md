# Introdução

As classes são definições que combinam dados (_também conhecidos como `attributes`, `properties`, `data members`, `variables` ou `fields`_) com `functions` (_também conhecidas como `methods`_).
As definições de classes servem para criar cópias ou `instances` de uma `class`, normalmente conhecidas como `objects`.
Os objetos podem representar entidades do mundo real (_como carros ou gatos_) ou conceitos mais abstratos (_como números inteiros, veículos ou mamíferos_).
Cada objeto é único na memória do computador e representa uma parte de um modelo global.
As classes e os objetos aparecem em vários paradigmas de programação, mas são essenciais à [programação orientada a objetos][oop] (POO), na qual os programas são compostos por objetos que interagem entre si.

[oop]:https://www.educative.io/blog/object-oriented-programming
