# sem condicionais

Os operadores condicionais não são necessários. Os operadores condicionais acrescentam ruído desnecessário. Usa [valores por omissão dos parâmetros](https://docs.scala-lang.org/tour/default-parameter-values.html) e [interpolação de strings](https://docs.scala-lang.org/overviews/core/string-interpolation.html) para construir dinamicamente a string a devolver.
