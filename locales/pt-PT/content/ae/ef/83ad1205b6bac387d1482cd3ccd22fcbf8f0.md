# Instruções

Neste exercício, vais gerir um sistema de inventário.

O inventário deve estar organizado pelo nome do item e deve manter o registo do número de itens disponíveis.

Vais ter de tratar da adição de itens a um inventário.
Cada vez que um item aparece num determinado vetor, a quantidade desse item no inventário deve ser aumentada em `1`.
Vais também ter de tratar da remoção de itens de um inventário, diminuindo as quantidades em `1` quando pedido.

Por fim, vais ter de implementar uma função que devolve todos os pares chave-valor de um determinado inventário como um `vector` de `pair`s.

~~~~exercism/note
Os testes deste exercício são agnósticos à mutação, mas os nomes das funções indicam que estas não devem mutar os dados.
Se quiseres usar funções da introdução sem mutar a entrada, a função `copy()` vai ser útil.
~~~~

## 1. Criar um inventário a partir de um vetor

Implementa a função `create_inventory(<input vector>)` que cria um «inventário» a partir de um vetor de itens.
Deve devolver um `dict` que contém cada nome de item emparelhado com a respetiva quantidade.

```julia-repl
julia> create_inventory(["coal", "wood", "wood", "diamond", "diamond", "diamond"])
Dict("coal" => 1, "wood" => 2, "diamond" => 3)
```

## 2. Adicionar itens de um vetor a um dicionário existente

Implementa a função `add_items(<inventory dict>, <item vector>)` que adiciona um vetor de itens ao inventário recebido:

```julia-repl
julia> add_items(Dict("coal" => 1), ["wood", "iron", "coal", "wood"])
Dict("coal" => 2, "wood" => 2, "iron" => 1)
```

## 3. Decrementar itens do inventário

Implementa a função `decrement_items(<inventory dict>, <items vector>)` que recebe um `vector` de itens.
A tua função deve remover `1` da contagem de um item por cada vez que esse item aparece no `vector`:

```julia-repl
julia> decrement_items(Dict("coal" => 3, "diamond" => 1, "iron" => 5), ["diamond", "coal", "iron", "iron"])
Dict("coal" => 2, "diamond" => 0, "iron" => 3)
```

As contagens de itens no inventário não devem poder descer abaixo de 0.
Se o número de vezes que um item aparece no `vector` de entrada exceder a contagem disponível, a quantidade indicada para esse item deve permanecer em 0.
Os pedidos adicionais de remoção de contagens devem ser ignorados assim que a contagem chega a zero.

```julia-repl
julia> decrement_items(Dict("coal" => 2, "wood" => 1, "diamond" => 2), ["coal", "coal", "wood", "wood", "diamond"])
Dict("coal" => 0, "wood" => 0, "diamond" => 1)
```

## 4. Remover uma entrada do inventário por completo

Implementa a função `remove_item(<inventory dict>, <item>)` que remove um item e a sua contagem por completo do inventário:

```julia-repl
julia> remove_item!(Dict("coal" => 2, "wood" => 1, "diamond" => 2), "coal")
Dict("wood" => 1, "diamond" => 2)
```

Se o item não for encontrado no inventário, a função deve devolver o inventário original inalterado.

```julia-repl
julia> remove_item(Dict("coal" => 2, "wood" => 1, "diamond" => 2), "gold")
Dict("coal" => 2, "wood" => 1, "diamond" => 2)
```

## 5. Devolver todo o conteúdo do inventário

Implementa a função `list_inventory(<inventory dict>)` que recebe um inventário e devolve um vetor de pares `(item, quantity)`.

O vetor deve incluir apenas os itens _disponíveis_ (_com uma quantidade superior a zero_) e deve ser ordenado por ordem alfabética dos itens:

```julia-repl
julia> list_inventory(Dict("coal" => 7, "wood" => 11, "diamond" => 2, "iron" => 7, "silver" => 0))
["coal" => 7, "diamond" => 2, "iron" => 7, "wood" => 11]
```
