# Instalação

## Pré-requisitos

O track de C++ exige que tenhas o seguinte software instalado no teu sistema:
* um compilador de C++14 moderno
* o sistema de compilação multiplataforma CMake

Usamos o [Catch2](https://github.com/catchorg/Catch2) para os testes. É uma biblioteca apenas de cabeçalhos que vem incluída com os exercícios.

Este conjunto de dependências é muito comum em projetos de C++, por isso, se tiveres algum problema a configurá-lo, vais encontrar muitos recursos úteis online.

Muitos IDEs, como o Visual Studio da Microsoft, o Xcode da Apple e o CLion da JetBrains, já incluem um compilador e o CMake em conjunto, por isso só deves precisar de instalar o IDE.

### Um compilador C++14 moderno

Este track exige um compilador com suporte para [C++14](http://en.wikipedia.org/wiki/C%2B%2B14), lançado em 2014. Todos os compiladores principais lançados nos últimos anos devem ser compatíveis, por isso, desde que tenhas uma versão razoavelmente recente, não deves ter problemas. Em concreto, o GCC versão 7 ou posterior, o Clang versão 6 ou posterior, ou o Visual Studio 2017 ou posterior.

### CMake

O CMake é um sistema de compilação multiplataforma de código aberto que gera scripts de compilação para o teu sistema de compilação nativo (`make`, Visual Studio, Xcode, etc.). O track de C++ do Exercism usa o CMake para te dar uma compilação pronta a usar que:

* compila os testes
* compila a tua solução
* liga o executável de testes
* executa automaticamente os testes como parte de cada compilação
* faz falhar a compilação se algum dos testes falhar

Usar o CMake permite ao Exercism disponibilizar um script de compilação multiplataforma capaz de gerar ficheiros de projeto para ambientes de desenvolvimento integrados como o Visual Studio e o Xcode. Assim, podes concentrar-te no problema e não te preocupares em configurar uma compilação para cada exercício.

Conseguir uma compilação portátil não é fácil e exige acesso a muitos tipos de sistemas. Se tiveres algum problema com a configuração de CMake fornecida, [reporta o problema](https://github.com/exercism/cpp/issues) para podermos melhorar o suporte do CMake.

É necessária a versão [CMake 3.5.1 ou posterior](http://www.cmake.org/) para usar a configuração de compilação fornecida.

## Windows

Se usas Windows, podes obter o [Visual Studio Community](https://www.visualstudio.com/vs/community/), uma transferência gratuita que te dá o IDE do Visual Studio e a versão mais recente do compilador Microsoft Visual C++.

1. Segue [as instruções aqui](https://docs.microsoft.com/en-us/cpp/build/cmake-projects-in-visual-studio) para configurar o CMake.
1. Transfere o exercício com a ferramenta [CLI do Exercism](https://exercism.io/cli-walkthrough).
1. Abre o Visual Studio 2017 ou superior (com as ferramentas Visual C++ para CMake instaladas, como descrito na ligação acima).
1. Abre a pasta do exercício no VS.
1. Executa "Build->Build the solution". Os testes são executados com a compilação, e o resultado aparece na janela de compilação. Como os testes correm durante a compilação, o VS indica uma falha de compilação se um dos testes falhar, e as mensagens de falha dos testes aparecem na janela de saída da compilação.

Deves conseguir usar outros IDEs integrados, como o CLion da JetBrains, de forma semelhante.

### Instalar o Boost no Windows

Os exercícios `meetup` e `gigasecond` dependem das bibliotecas [Boost][boost-website]. Os passos seguintes descrevem como configurar isso.

1. Transfere as [bibliotecas pré-compiladas para Windows][sourceforge-boost-binaries] do Boost.
   - Os exercícios exigem uma versão mínima do Boost igual à 1.58.
   - Podes descobrir a versão do MSVC clicando em "Modify" no Visual Studio Installer.
1. Extrai as bibliotecas para uma pasta local.
1. Define a variável de ambiente `BOOST_ROOT` com a pasta onde instalaste as bibliotecas do Boost.
1. Se tinhas o Visual Studio aberto enquanto fazias isto, fecha-o para garantir que o valor de `BOOST_ROOT` é lido.
1. Inicia o Visual Studio e abre a pasta que contém o exercício `gigasecond` ou `meetup`.
1. O "Startup Item" deve ser `gigasecond.exe` ou `meetup.exe`, e deves obter erros de compilação em `gigasecond_test.cpp` ou `meetup_test.cpp` a dizer-te para implementares os itens em falta, tal como nos outros exercícios.

## Linux

Todas as versões recentes das distribuições de Linux têm compiladores de C++14 compatíveis, por isso deves conseguir instalá-lo com o teu gestor de pacotes. As versões que suportamos são as versões instaladas por omissão no Ubuntu LTS 18.04.

Por exemplo, no Ubuntu usarias o seguinte comando para instalar o gcc.

```bash
$ sudo apt-get install gcc
$ gcc --version
```

Se estiveres numa distribuição mais antiga, podes não ter um compilador com suporte para C++14. Nesse caso, tens de ver junto da tua distribuição como instalar a versão mínima do compilador.

## MacOS

Se usas macOS, podes instalar o GCC com o [Homebrew](http://brew.sh/) através de `brew install gcc`.
