Em Haxe, os [Boolean][booleans] são representados pelo tipo `Bool`, cujos valores podem ser `true` ou `false`.

O Haxe suporta três [operadores booleanos][operators]: `!` (NOT unário), `&&` (AND binário) e `||` (OR binário)

As expressões booleanas compostas (`&&` e `||`) usam avaliação de _curto-circuito_: as expressões são avaliadas da esquerda para a direita, mas apenas até onde for necessário. Isto é importante em casos como o seguinte:

```haxe
object != null && object.field == x
```

A primeira verificação booleana garante que `object.field` só é acedido se `object` não for `null`, o que protege contra um erro de execução.

Os três operadores booleanos têm uma [precedência][precedence] diferente e são avaliados por esta ordem: `!` -> `&&` -> `||`.

Envolver expressões em parênteses `()` permite sobrepor estas regras de precedência, uma vez que os parênteses têm uma precedência mais elevada.

```haxe
!true && false   // => false
!(true && false) // => true
```
