# Apêndice das instruções

## Nota

Se estiveres a editar este ficheiro num editor de texto e não no Pharo, consulta a secção [Primeiros passos](https://www.exercism.org/tracks/pharo/installation).

Embora possas usar um editor de texto, é em parte o IDE do Pharo que torna esta linguagem tão especial.

Em Pharo, podes correr código (incluindo testes) com métodos com erros e classes em falta.
Quando a VM encontra código com erros, abre um debugger que te permite explorar o problema um pouco melhor.

Tens então a opção de carregar no botão Create para adicionar uma classe ou um método em falta, bem como corrigir qualquer código que esteja a causar um erro.
Quando o fazes, o debugger recua e deixa-te retomar a execução com as tuas novas alterações.

Experimenta fazer isto com o teu exemplo HelloWorld, bastando correr um dos métodos de teste unitário.
