# Instruções adicionais

## Implementação

Se o último elemento da lista for um `object` em vez de uma `string`, esse elemento contém um qualificador que modifica a linha final do provérbio.

```javascript
proverb('nail', 'shoe', { qualifier: 'horseshoe' });
// => For want of a nail the shoe was lost.
//    And all for the want of a horseshoe nail.
```
