# Sobre

Em Rust, os booleanos são representados pelo tipo `bool`, cujos valores podem ser `true` ou `false`.

O Rust tem um [operador de negação Boolean][negation operators]: `!` (negação).

O Rust tem seis [operadores de comparação][comparison operators]: `==` (igual), `!=` (diferente), `>` (maior que), `<` (menor que), `>=`
(maior ou igual a), `<=` (menor ou igual a). Podem ser usados para avaliar a relação entre valores que não são Boolean e obter um valor
Boolean.

```rust
1 > 0 // true
1 < 0 // false
1 == 0 // false
1 != 0 // true
1 >= 0 // true
1 <= 0 // false
```

Ao contrário de algumas outras linguagens, `0` não é `false` e um valor diferente de zero não é `true`.

O Rust tem três [operadores binários lógicos][logical binary operators]: `&` (E lógico), `|` (Ou lógico), `^` (Ou exclusivo lógico).

O Rust tem dois [operadores Boolean][lazy boolean operators]: `||` (Ou), `&&` (E). Diferem de `|` e `&` porque o operando da direita
só é avaliado quando o operando da esquerda ainda não determina o resultado da expressão. Ou seja, o `||` só avalia
o operando da direita quando o operando da esquerda resulta em `false`, e o `&&` só o faz quando este resulta em `true`.

```rust
true || false // == true; the right-hand side was not evaluated
true && false // == false
```
