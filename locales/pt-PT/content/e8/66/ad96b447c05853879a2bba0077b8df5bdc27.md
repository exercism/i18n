# Introdução

## Try/Rescue/Else/After

Usar `try..rescue` é uma construção poderosa para capturar erros quando estes ocorrem. Capturar erros permite que as funções devolvam valores definidos quando é necessário. A construção `try..rescue` também nos oferece duas funcionalidades adicionais que podemos aproveitar:

- o bloco `else`
  - Quando o bloco try tem sucesso, o resultado é associado a este bloco.
- o bloco `after`
  - Independentemente de o bloco try ter sucesso ou lançar uma exceção, o código no bloco `after` é sempre executado, desde que o programa esteja a correr nesse ponto.
  - O resultado do bloco `after` não é devolvido ao âmbito de chamada.

```elixir
try do
  :a
rescue
  _ -> :error
else
  :a -> :success
after
  :some_action
end

# => :success
```

## Despacho dinâmico

Quando o Elixir resolve a função a invocar, usa o nome do módulo para efetuar uma procura. A procura pode ser feita dinamicamente se o nome do módulo estiver associado a uma variável.

```elixir
defmodule MyModule do
  def message(), do: "My message"
end

atom = MyModule
atom.message()
# => "My message"
```

Internamente, o nome de um módulo é um átomo. Todos os átomos de módulos do Elixir são automaticamente prefixados com `Elixir.`

```elixir
is_atom(Enum)
# => true
Enum == Elixir.Enum
# => true
```
