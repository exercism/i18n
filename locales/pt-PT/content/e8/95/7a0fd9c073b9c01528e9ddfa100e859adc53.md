# Introdução

## Agent

O módulo `Agent` proporciona uma abstração para criar [processos e o ciclo _receive-send_][exercism-processes]. A partir daqui, chamamos _processos agente_ aos processos iniciados com o módulo `Agent`. Um _processo agente_ pode ser escolhido para representar um estado partilhado central.

Para iniciar um _processo agente_, o `Agent` fornece a função `start/2`. A função que forneces ao fazer `start` do _processo agente_ devolve o estado inicial do processo:

```elixir
# Start an agent process with an initial value of an empty list
{:ok, agent_pid} = Agent.start(fn -> [] end)
```

Tal como o `Map` ou a `List`, o `Agent` fornece muitas funções para trabalhar com _processos agente_.

É habitual organizar e encapsular toda a funcionalidade relacionada com o `Agent` num módulo para o domínio que estás a modelar.

[exercism-processes]: https://exercism.org/tracks/elixir/concepts/processes
