# Dicas

## 1. Criar um carro telecomandado

- Devolve uma lista com 4 elementos nomeados.
- `speed` e `battery_drain` são fornecidos como argumentos.
- `battery` e `distance_traveled` assumem valores por omissão.

## 2. Criar uma pista de corrida

- Devolve uma lista de comprimento 1.

## 3. Verificar se a bateria está descarregada

- Para contar como "descarregada", a carga da bateria não precisa de ser zero: basta estar suficientemente baixa para que não se consiga completar outro passo.
- O controlo do carro é feito em passos discretos. Quando falamos de um "passo", referimo-nos a "cada vez que `drive()` é chamada".

## 4. Conduzir o carro

- A bateria está descarregada? Se estiver, o carro deve ser atualizado?
- `battery_drain` é a percentagem de carga perdida em cada passo.
- `speed` é a distância percorrida em cada passo.
- Devolve um carro atualizado, conforme apropriado.

## 5. Verificar se um carro telecomandado consegue terminar uma corrida

- Quantos passos mais consegue o carro completar?
- Não existem passos parciais, por isso a função [`floor`][ref-round] pode ser útil. Em alternativa, a divisão inteira `%/%` também funciona com números de vírgula flutuante, truncando o resultado.
- Que distância consegue o carro percorrer nesse número de passos?
- É suficiente?

## 6. Guardar se o carro consegue terminar uma pista com a bateria cheia

- Reinicia `battery` e `distance_traveled` para os valores de um carro novo antes de qualquer cálculo.
- As listas são vetores _recursivos_, por isso podem conter outras listas.
- O nome do novo elemento é fornecido em tempo de execução, por isso a notação `$` não funciona. A Introdução sugere alternativas.
- O valor do novo elemento é uma `list` de comprimento 2. Não pode ser um `vector`, porque mistura elementos numéricos e lógicos.
- Devolve o carro atualizado.
- Assume que podem ser adicionados vários elementos à pista, com nomes diferentes.

[ref-round]: https://www.rdocumentation.org/packages/base/versions/3.3.0/topics/Round
