# Instruções

Neste exercício tens de implementar algumas funções para manipular uma lista de linguagens de programação.

## 1. Define uma função que devolve uma lista de linguagens vazia

Define a função `new/0`, que não recebe argumentos e devolve uma lista vazia.

```elixir
LanguageList.new()
# => []
```

## 2. Define uma função que adiciona uma linguagem à lista

Define a função `add/2`, que recebe 2 argumentos (uma _lista de linguagens_ e um literal de string de uma _linguagem_). Deve devolver a lista resultante, com a nova linguagem acrescentada ao início da lista indicada.

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Clojure")
# => ["Clojure"]
language_list = LanguageList.add(language_list, "Haskell")
# => ["Haskell", "Clojure"]
```

## 3. Define uma função que remove uma linguagem da lista

Define a função `remove/1`, que recebe 1 argumento (uma _lista de linguagens_). Deve devolver a lista sem o primeiro elemento. Assume que a lista tem sempre pelo menos um elemento.

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Clojure")
# => ["Clojure"]
language_list = LanguageList.add(language_list, "Haskell")
# => ["Haskell", "Clojure"]
language_list = LanguageList.remove(language_list)
# => ["Clojure"]
```

## 4. Define uma função que devolve o primeiro elemento da lista

Define a função `first/1`, que recebe 1 argumento (uma _lista de linguagens_). Deve devolver a primeira linguagem da lista. Assume que a lista tem sempre pelo menos um elemento.

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Elm")
# => ["Elm"]
language_list = LanguageList.add(language_list, "Prolog")
# => ["Prolog", "Elm"]
LanguageList.first(language_list)
# => "Prolog"
```

## 5. Define uma função que devolve quantas linguagens tem a lista

Define a função `count/1`, que recebe 1 argumento (uma _lista de linguagens_). Deve devolver o número de linguagens na lista.

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Elm")
# => ["Elm"]
language_list = LanguageList.add(language_list, "Prolog")
# => ["Prolog", "Elm"]
LanguageList.count(language_list)
# => 2
```

## 6. Define uma função que determina se a lista inclui uma linguagem funcional

Define a função `functional_list?/1`, que recebe 1 argumento (uma _lista de linguagens_). Deve devolver um valor Boolean. Deve devolver true se _"Elixir"_ for uma das linguagens da lista.

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Elixir")
# => ["Elixir"]
LanguageList.functional_list?(language_list)
# => true
```
