# Sobre

Um [ciclo while][while-loops] é uma instrução de controlo de fluxo que permite executar código enquanto uma determinada condição for verdadeira.
O Swift disponibiliza dois tipos de ciclos while: ciclos while e ciclos repeat-while.
A condição do ciclo while é avaliada antes de o corpo do ciclo ser executado; se a condição for falsa, o corpo do ciclo não é executado de todo.
Os ciclos while em Swift têm a seguinte estrutura:

```swift
while <#condition#> {
  <#code#>
}
```

Aqui, o ciclo será executado enquanto count for maior que 0 e imprimirá assim os números 2, 1 e "Liftoff!".

```swift
var count = 2
while count > 0 {
  print("\(count)…")
  count -= 1
}
print("Liftoff!")

// prints:
// 2…
// 1…
// Liftoff!
```

Um [ciclo repeat-while][while-loops] é semelhante a um ciclo while, mas a condição é avaliada depois de o corpo do ciclo ser executado.
Isto significa que o corpo do ciclo é sempre executado pelo menos uma vez, mesmo que a condição seja falsa.
Os ciclos repeat-while em Swift têm a seguinte estrutura:

```swift
repeat {
  <#code#>
} while <#condition#>
```

Aqui, o ciclo é executado apenas uma vez, pois a condição é falsa.
Como é um ciclo repeat-while, o corpo do ciclo é executado uma vez antes de a condição ser avaliada.

```swift
var count = 2
repeat {
  print("\(count)…")
} while count < 0
print("Liftoff!")
```

## Ciclos de ligação opcional

Uma variante comum dos ciclos while em Swift é o ciclo while de ligação opcional.
Estes ciclos repetem-se enquanto a chamada a alguma função que produz um valor opcional devolver um valor diferente de `nil`.
Esse valor (não opcional) fica então ligado a um nome à tua escolha e pode ser usado no corpo do ciclo.

```swift
var arr = [1,2]
while let count = arr.popLast() {
  print("\(count)…")
}
print("Liftoff!")

// prints:
// 2…
// 1…
// Liftoff!
```
