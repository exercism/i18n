# Instruções

A tua tarefa é identificar se há, num saco de rebuçados, uma cor que representa a maioria do saco. 🍬 O elemento maioritário é aquele que ocupa mais de metade do espaço de uma coleção. Dada uma lista de elementos que representam as cores, devolve a cor que constitui a maioria; caso contrário, indica que não foi encontrada nenhuma maioria.

Para uma lista simples, `[Red, Red, Blue, Red, Green]`, o valor devolvido deve ser Red, porque Red aparece 3 vezes numa lista de 5. Mas para uma lista `[Red, Red, Blue, Green]`, não há maioria, apesar de Red ser o elemento mais comum, porque 2/4 não é maior do que metade dos elementos.
