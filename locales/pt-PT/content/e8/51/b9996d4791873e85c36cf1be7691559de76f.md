# Resto

Em matemática, o **resto** é a quantidade que "sobra" depois de fazer um cálculo.
Por exemplo, o resto de `5 / 3` é `2`.

Muitas linguagens de programação usam o sinal de percentagem (`%`) como operador para calcular o resto.
Por exemplo:
```javascript
5 % 3 == 2
```

Muitas vezes, é possível calcular o resto tanto com números inteiros como com números de vírgula flutuante.
Por exemplo,
```javascript
5.3 % 3 == 2.3
```

Quando trabalhas com números negativos, o resultado tem sempre o mesmo sinal que o dividendo (o número do lado esquerdo que está a ser dividido).
Por exemplo:
```javascript
-5 % 3 == -2
5 % -3 == 2
-5 % -3 == -2
```

Algumas linguagens (como o Python) usam o operador `%` para calcular o módulo, não o resto.
Isso trata os números negativos de forma diferente.
Podes saber mais sobre isto [na Wikipédia](https://en.wikipedia.org/wiki/Modulo).
