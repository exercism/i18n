# Introdução

Os condicionais do Factor escolhem entre **quotations**: fragmentos de código escritos entre parênteses retos, `[ ... ]`. Escrever `[ ... ]` coloca o código na pilha como um valor, em vez de o executar; é o condicional que decide depois qual delas executar. (As quotations são abordadas em detalhe num exercício posterior.)

O `if` (em [`kernel`][kernel]) é o condicional básico do Factor. Recebe um boolean e duas quotations: executa a primeira se o boolean for verdadeiro e a segunda caso contrário.

```
if ( ? then-quot else-quot -- )
```

```factor
: abs ( x -- y ) dup 0 < [ neg ] [ ] if ;
```

O `when` só executa a sua quotation quando o boolean for verdadeiro; o `unless`, só quando for falso. Para escolher entre vários caminhos, há o `cond` (em [`combinators`][combinators]):

```factor
USING: combinators ;

: classify ( n -- s )
    {
        { [ dup 0 <  ] [ drop "negative" ] }
        { [ dup 0 =  ] [ drop "zero"     ] }
        [ drop "positive" ]
    } cond ;
```
