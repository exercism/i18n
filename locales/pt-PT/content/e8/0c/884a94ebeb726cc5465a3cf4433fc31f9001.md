# Introdução

## Condicionais If

### Operadores lógicos

O Java suporta os três operadores lógicos `&&` (E), `||` (OU) e `!` (NÃO).

### Condicional

O tipo subjacente de qualquer operação condicional é o tipo `boolean`, que pode ter o valor `true` ou `false`. As condicionais são frequentemente usadas como mecanismos de controlo de fluxo para verificar várias condições. Para verificar um caso específico, pode ser usada uma condicional `if`, que executa o seu código se a condição subjacente for `true`, assim:

```java
int val;

if(val == 9) {
    // conditional code
}
```

Em cenários com mais do que um caso, muitas condicionais `if` podem ser encadeadas usando as instruções `else if` e `else`.

```java
if(val == 10) {
    // conditional code
} else if(val == 17) {
    // conditional code
} else {
    // executes when val is different from 10 and 17
}
```

### Instrução switch

O Java também disponibiliza uma instrução `switch` para cenários com várias opções.

```java
int val;

// switch statement on variable content
switch(val) {
    case 1:
        // conditional code
        break;
    case 2: case 3: case 4:
        // conditional code
        break;
    default:
        // if all cases fail
        break;
}
```
