# Apêndice às instruções

## Implementação

Alguns editores removem espaços em branco.
Se dependes de espaços em branco no fim de uma string multilinha, usa antes um formato que não dependa desses espaços, ou ajusta as definições do teu editor.

[Guia rápido de strings multilinha para Ruby](https://commandercoriander.net/blog/2014/11/09/a-multiline-string-cheatsheet-for-ruby/)
