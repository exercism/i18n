# Aprender

O Tcl foi concebido com o objetivo de ser muito simples mas poderoso.
Por esse motivo, aprender [a sintaxe básica do Tcl][syntax] é bastante fácil.

Para um tutorial prático, vê o [Learn X in Y minutes: Tcl][X-in-Y].

Para um tutorial mais completo, em várias partes:
 - [O tutorial de Tcl][tutorial] abrange a versão 8.5 do Tcl (a versão estável atual é a 9.1)
 - O suporte para programação orientada por objetos foi adicionado ao núcleo do Tcl na versão 8.6.
   O Magicsplat tem um [tutorial de POO][oo-tutorial] bastante completo que o aborda.
