# Ajuda

Se estiveres com dificuldades, podes recorrer a um dos seguintes recursos:

- [The Emacs Wiki](http://emacswiki.org/) é inestimável. Vale a pena passar lá muito tempo.
- [The Emacs Editor](http://www.gnu.org/software/emacs/manual/html_node/emacs/index.html) é o manual oficial do GNU Emacs.
- IRC - há canais na [Libera.Chat](https://libera.chat/) para `#emacs`, `#org-mode` e muitos pacotes do Emacs, e muita gente prestável por lá. E, com o Emacs, o IRC está tão perto quanto `M-x erc`.
- Matrix - no [Matrix](https://matrix.org/) há salas para [emacs](https://matrix.to/#/#emacs:matrix.org), [org-mode](https://matrix.to/#/#org-mode:matrix.org) e outros pacotes do Emacs.
  Podes [juntar-te ao espaço Emacs no Matrix](https://matrix.to/#/#emacs-space:matrix.org) para teres uma visão geral dos canais disponíveis.
  Para entrares no Matrix a partir do Emacs, podes usar o pacote [Ement.el](https://github.com/alphapapa/ement.el).
- O [StackOverflow](http://stackoverflow.com/questions/tagged/elisp) e o [Emacs StackExchange](https://emacs.stackexchange.com/questions/tagged/elisp) podem ser usados para procurar o teu problema e ver se já foi respondido. Também podes fazer e responder a perguntas.
