# Introdução

Uma forma comum de usar o tipo união discriminada em F# é representar um conjunto fixo de constantes nomeadas: uma estrutura a que se chama "enum" noutras linguagens.

Normalmente, numa união discriminada deste tipo, cada caso só pode referir-se a exatamente uma dessas constantes nomeadas.
No entanto, por vezes é útil referir mais do que uma constante.
Para isso, podes anotar a união discriminada com o atributo Flags.

Uma união discriminada com o atributo Flags pode definir-se da seguinte forma (usando a notação de inteiros binários 0b):

```fsharp
[<Flags>]
type PhoneFeatures =
| Call = 0b00000001
| Text = 0b00000010
```

Uma instância de `PhoneFeatures` com o valor `0b00000011` tem os flags `Call` e `Text` definidos.
