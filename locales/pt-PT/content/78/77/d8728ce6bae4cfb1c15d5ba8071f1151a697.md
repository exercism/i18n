# Instruções

Neste exercício vais escrever código para acompanhar uma lista de linguagens de programação que queres aprender no Exercism.

Tens seis tarefas, e todas envolvem lidar com listas.

## 1. Cria uma nova lista

Para acompanhares as linguagens que queres aprender, vais precisar de criar uma nova lista. Define a ligação `newList`, que contém uma lista nova e vazia.

```fsharp
newList
// => []
```

## 2. Define uma lista existente

De momento, tens um papel com a lista das linguagens que queres aprender: F#, Clojure e Haskell. Define a ligação `existingList` para representar esta lista.

```fsharp
existingList
// => ["F#"; "Clojure"; "Haskell"]
```

## 3. Adiciona uma nova linguagem a uma lista

À medida que exploras o Exercism e encontras linguagens mais interessantes, vais querer adicioná-las à tua lista. Implementa a função `addLanguage` para acrescentar uma nova linguagem ao início da tua lista.

```fsharp
addLanguage "TypeScript" ["JavaScript"; "CoffeeScript"]
// => ["TypeScript"; "JavaScript"; "CoffeeScript"]
```

## 4. Conta as linguagens da lista

Contar as linguagens uma a uma é incómodo. Implementa a função `countLanguages` para contar o número de linguagens da tua lista.

```fsharp
countLanguages ["C#"; "Racket"; "Rust"; "Ruby"]
// => 4
```

## 5. Inverte a lista

A dada altura, dás conta de que a tua lista está, na verdade, pela ordem inversa! Implementa a função `reverseList` para inverter a tua lista.

```fsharp
reverseList ["Prolog"; "C"; "Idris"; "Assembly"]
// => ["Assembly"; "Idris"; "C"; "Prolog"]
```

## 6. Verifica se a lista é entusiasmante

Embora gostes de todas as linguagens, o F# tem um lugar especial no teu coração. Por isso, ficas mesmo entusiasmado com uma lista de linguagens se:

- A primeira da lista for o F#.
- O segundo item da lista for o F# e a lista tiver duas ou três linguagens.

Implementa a função `excitingList` para verificar se uma lista de linguagens é entusiasmante:

```fsharp
excitingList ["Nim"; "F#"]
// => true
```
