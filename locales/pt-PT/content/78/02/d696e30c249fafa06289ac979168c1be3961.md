# Dicas

## Geral

- Os arrays com as contagens de aves contêm sempre exatamente 7 inteiros.

## 1. Verifica quais foram as contagens na semana passada

- Existem [várias formas de definir um array][creating-arrays].

## 2. Verifica quantas aves visitaram ontem

- Lembra-te de que as contagens estão ordenadas por dia, do mais antigo para o mais recente, e o último elemento representa o dia de hoje.
- Podes aceder ao penúltimo elemento usando o seu índice (fixo) (lembra-te de começar a contar do zero) ou calculando o seu índice a partir do comprimento do array, seja através de uma [função no módulo `Array`][length-function], seja acedendo a uma das [propriedades][length-property] do array.

## 3. Calcula o número total de aves que visitaram

- O módulo `Array` tem uma [função para somar os valores de um array][sum-function].

## 4. Verifica se houve algum dia sem aves visitantes

- O módulo `Array` tem uma [função para verificar se um array contém um valor específico][contains-function].

## 5. Incrementa a contagem de hoje

- Existem duas formas de atualizar um valor num array:
  - O operador `<-` permite atualizar um valor num array.
  - O módulo `Array` tem uma [função para atualizar um valor num array][set-function].
- A função acima para atualizar um valor num array não devolve um valor. Por isso, deves devolver manualmente o array atualizado depois de definires o seu valor.

## 6. Verifica se há uma semana invulgar

- Em vez de verificar todos os valores individualmente, usa [pattern matching][pattern-matching-array].
