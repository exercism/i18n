## Geral

- Os seis primeiros argumentos inteiros são passados a uma função em `rdi`, `rsi`, `rdx`, `rcx`, `r8` e `r9`.
- Para aceder a menos de 64 bits num registo, podes consultar o [Manual da AMD][manual] para o nome adequado.

## 1. Define `get_box_weight`

- Os seis primeiros argumentos inteiros são passados a uma função em `rdi`, `rsi`, `rdx`, `rcx`, `r8` e `r9`.
- Para aceder a menos de 64 bits num registo, podes consultar o [Manual da AMD][manual] para o nome adequado.
- Podes sair da função mais cedo para verificar cada passo.
- Há uma [instrução][movzx] para estender valores com zeros.

## 2. Define `max_number_of_boxes`

- Os seis primeiros argumentos inteiros são passados a uma função em `rdi`, `rsi`, `rdx`, `rcx`, `r8` e `r9`.
- Para aceder a menos de 64 bits num registo, podes consultar o [Manual da AMD][manual] para o nome adequado.

## 3. Define `items_to_be_moved`

- Os seis primeiros argumentos inteiros são passados a uma função em `rdi`, `rsi`, `rdx`, `rcx`, `r8` e `r9`.
- Para aceder a menos de 64 bits num registo, podes consultar o [Manual da AMD][manual] para o nome adequado.
- Podes sair da função mais cedo para verificar cada passo.
- A subtração funciona da mesma forma para números sem sinal e com sinal.

## 4. Define `calculate_payment`

- Os seis primeiros argumentos inteiros são passados a uma função em `rdi`, `rsi`, `rdx`, `rcx`, `r8` e `r9`.
- Para aceder a menos de 64 bits num registo, podes consultar o [Manual da AMD][manual] para o nome adequado.
- Podes sair da função mais cedo para verificar cada passo.
- Se obtiveres respostas realmente grandes quando esperas um valor negativo, é provável que o sinal de um dos números esteja incorreto.
- Há uma [instrução][cqo] para estender valores com sinal de `rax` para `rdx`.
- Há uma [instrução][idiv] para divisão com sinal.
- O pagamento é dividido entre ti e um determinado número de trabalhadores, e também recebes o resto.
- O resto de uma divisão é guardado em `rdx`.
