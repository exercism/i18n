# Sobre

A linguagem assembly ARM64/AArch64 é a versão de 64 bits do conjunto de instruções ARM.
Baseia-se no conjunto de instruções ARMv7, que por sua vez deriva, de forma livre, dos antigos conjuntos de instruções ARM Classic.

Este percurso envolve programação em linguagem assembly ARM64, montada e executada num simulador multiplataforma.
