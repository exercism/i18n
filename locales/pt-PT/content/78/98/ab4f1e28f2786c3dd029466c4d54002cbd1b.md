# Introdução

Muitos programas precisam de valores (pseudo)aleatórios para simular acontecimentos do mundo real.

Alguns exemplos comuns e familiares:

- O lançamento de uma moeda: um valor aleatório de ('H', 'T').
- O lançamento de um dado: um número inteiro aleatório de 1 a 6.
- Baralhar um baralho de cartas: uma ordenação aleatória de uma lista de cartas.
- A criação de árvores e arbustos numa simulação gráfica 3D.

Gerar valores verdadeiramente aleatórios com um computador é um [desafio técnico surpreendentemente difícil][why-randomness-is-hard], e é por isso que também existem geradores "pseudoaleatórios".

A [especificação da linguagem][spec] JavaScript não obriga a uma implementação concreta para a geração de números aleatórios.
Todos os principais navegadores e ambientes de execução de JavaScript implementam um PRNG (gerador de números pseudoaleatórios).

## Gerar números aleatórios

Em JavaScript, podes gerar números pseudoaleatórios com a função [`Math.random()`][Math.random].
Esta devolve um número de vírgula flutuante pseudoaleatório entre 0 (inclusive) e 1 (exclusive).

Para obteres um número aleatório entre _min_ (inclusive) e _max_ (exclusive), podes usar uma função parecida com esta:

```javascript
function getRandomInRange(min, max) {
  return min + Math.random() * (max - min);
}
getRandomInRange(4, 10);
// => 5.72
```

## Gerar números inteiros aleatórios

Para gerares um número inteiro aleatório, podes usar `Math.floor()` ou `Math.ceil()` para transformar um número gerado aleatoriamente num número inteiro.
