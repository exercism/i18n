# Introdução

## Números

Em C# existem dois tipos diferentes de números:

- Inteiros: números sem algarismos depois do separador decimal (números inteiros). Por exemplo: `-6`, `0`, `1`, `25`, `976` e `500000`.
- Números de vírgula flutuante: números com zero ou mais algarismos depois do separador decimal. Por exemplo: `-2.4`, `0.1`, `3.14`, `16.984025` e `1024.0`.

Os dois tipos numéricos mais comuns em C# são `int` e `double`. Um `int` é um inteiro de 32 bits e um `double` é um número de vírgula flutuante de 64 bits.

A aritmética é feita com os operadores aritméticos habituais. Os números podem ser comparados com os operadores de comparação numérica habituais e com os operadores de igualdade (`==`) e de desigualdade (`!=`).

O C# tem dois tipos de conversões numéricas:

1. Conversões implícitas: não há perda de dados e não é precisa sintaxe adicional.
2. Conversões explícitas: pode haver perda de dados e é precisa sintaxe adicional, na forma de um _cast_.

Como um `int` tem menos precisão do que um `double`, converter de `int` para `double` é seguro e, por isso, é uma conversão implícita. No entanto, converter de `double` para `int` pode significar perda de dados, por isso exige uma conversão explícita.

```csharp
int softCool = 1358938113;
double notLost = 4.8151623;

// implicit cast: no loss of information
double macDebug = softCool;         // 1358938113.0

// explicit cast: possible loss of information 
int somethingLost = (int)notLost;   // 4
```

## Condicionais

Neste exercício tens de executar lógica de forma condicional. A forma mais comum de o fazer em C# é através de uma condicional `if/else`:

```csharp
int x = 6;

if (x == 5)
{
    // Execute logic if x equals 5
}
else if (x > 7)
{
    // Execute logic if x greater than 7
}
else
{
    // Execute logic in all other cases
}
```

A condição de uma condicional `if` tem de ser do tipo `bool`. O C# não tem o conceito de valores _truthy_.
