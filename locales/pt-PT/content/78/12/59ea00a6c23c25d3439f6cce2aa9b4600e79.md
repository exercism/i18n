# Anexo às instruções

## Apêndice

~~~~exercism/note
As instruções acima estão sincronizadas com um repositório partilhado, para garantir a consistência entre todos os percursos de linguagem.
Este apêndice acrescenta esclarecimentos adicionais ou altera as instruções conforme necessário, para as alinhar melhor com os objetivos do percurso de Clojure.
~~~~

É importante não usar funções incorporadas existentes com uma funcionalidade semelhante à da função que estás a implementar, pois isso reduziria o valor de aprendizagem pretendido do exercício.
Em Clojure, não existe nenhuma função incorporada para contar o número de bits de um número, por isso podes usar qualquer função de Clojure na tua implementação.
No entanto, o Java inclui uma função para esse efeito: `bitCount`.
