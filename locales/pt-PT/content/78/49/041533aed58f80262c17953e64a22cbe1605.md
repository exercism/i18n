# Instalação

Para trabalhares nos exercícios, vais precisar destes programas:

1. [`OPAM`, o gestor de pacotes do OCaml](https://opam.ocaml.org/)

   Consulta as [Instruções de instalação do Real World OCaml, 2.ª ed.](https://dev.realworldocaml.org/install.html)
   para saberes como instalar e configurar o `OPAM` no teu sistema operativo.

2. O compilador de OCaml

   Vê a lista das versões disponíveis:

   ```bash
   opam switch
   ```

   Se já tens um switch para OCaml 5.1, podes carregá-lo executando `opam switch <switch-name>`, ou criar um novo switch executando:

   ```bash
   opam switch create exercism 5.4.0
   ```

   O nome `exercism` aqui é opcional, mas dar nome aos switches é uma boa prática.

3. Instala bibliotecas padrão estendidas e bibliotecas de testes

   Executa o seguinte para instalar as dependências necessárias a este percurso:

   ```bash
   opam install base core_kernel ounit qcheck
   ```

   Alguns exercícios usam apenas a biblioteca padrão do OCaml, e outros usam as bibliotecas estendidas da Jane Street chamadas Base e Core_kernel.
   A biblioteca de testes chama-se OUnit, e alguns exercícios usam ainda a biblioteca QCheck para testes baseados em propriedades.
   Executar o comando acima instala estas bibliotecas.

4. Instala e usa a shell interativa (opcional)

   Um resumo de como [configurar e usar o `utop`](https://dev.realworldocaml.org/install.html):

   ```bash
   opam install utop
   ```

   Cria um novo ficheiro chamado `.ocamlinit` no teu diretório pessoal e acrescenta-lhe as seguintes linhas:

   ```ocaml
   #use "topfind";;
   #require "base";;
   open Base
   ```

5. Instala ferramentas no VS Code (opcional)

   Se usas o VS Code:
   - Instala o servidor de linguagem de OCaml a partir [daqui](https://github.com/ocaml/ocaml-lsp).
   - Instala a extensão OCaml para VS Code a partir [daqui](https://marketplace.visualstudio.com/items?itemName=ocamllabs.ocaml-platform), ou procura por `OCaml Platform` da Ocaml Labs.
