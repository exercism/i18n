# Anexo às instruções

## Traits de Rust para `.to_string()`

Também vais precisar de implementar `.to_string()` para a estrutura `Clock`.
Vamos usar isto para mostrar o estado do `Clock`.

Podes fazê-lo implementando-o diretamente ou usando a [trait Display][display-trait].

Se for esse o caso, experimenta antes implementar a [trait Display][display-trait] para `Clock`.

As traits permitem uma forma comum de implementar funcionalidade para vários tipos.

Para aprenderes mais, pensa em como poderias implementar `String::from` para o tipo `Clock`.
Não precisas de o implementar de facto: é redundante em relação a `Display`, que é geralmente a
melhor escolha quando o tipo de destino é `String`. Ainda assim, é útil teres algumas traits de
conversão de tipos no teu conjunto de ferramentas.

[display-trait]: https://doc.rust-lang.org/std/fmt/trait.Display.html
