# Instruções

O departamento de reclamações da Isaac's Asteroid Exploration Co. pediu-te que melhores o desempenho do sistema de reivindicação de terrenos.

Sempre que um asteroide está pronto para exploração, os especuladores são convidados a reivindicar um lote de terreno.
O terreno do asteroide está dividido em lotes retangulares que não se sobrepõem.
As dimensões variam, mas todos têm os lados paralelos aos eixos de coordenadas.
Os especuladores reivindicam um dos lotes de terreno indicando as suas coordenadas.

O teu objetivo é desenvolver um sistema com bom desempenho para lidar com a corrida ao terreno que, no passado, já fez o site ir abaixo.

A unidade de medida é 100 metros, mas podes ignorá-la nestas tarefas.

## 1. Define um ponto

Define uma `struct` para guardar as coordenadas `x` e `y`.
São números inteiros não negativos bastante pequenos, por isso usa o tipo `UInt16`.

```julia-repl
julia> Coord(7, 3)
Coord(0x0007, 0x0003)  # unsigned integers display in hex format by default
```

## 2. Define um lote

Como todos os lotes têm de ser retangulares, com lados horizontais e verticais, bastam dois cantos opostos para os definir.

Implementa a `struct` `Plot`, que recebe duas structs Coord no seu construtor.

A `Plot` deve ser uma struct com palavras-chave, com os campos `bottom_left` e `top_right`.

```julia-repl
julia> plot = Plot(bottom_left=Coord(10, 1), top_right=Coord(20, 2))
Plot(Coord(0x000a, 0x0001), Coord(0x0014, 0x0002))

julia> plot.top_right
Coord(0x0014, 0x0002)
```

## 3. Verifica se a tua reivindicação já foi registada

Há concorrência por estas reivindicações, por isso, antes de a tua reivindicação ser aceite, vai ser comparada com as reivindicações já existentes no registo.

Implementa a função `is_claim_staked()` para determinar se uma reivindicação já foi registada.

```julia-repl
julia> claim = Plot(bottom_left=Coord(10, 1), top_right=Coord(20, 2));
julia> register = Set{Plot}();
julia> is_claim_staked(claim, register)
false
```

## 4. Os especuladores podem reivindicar um lote identificado pelas coordenadas dos seus cantos

Implementa a função mutável `stake_claim!()` para permitir registar uma reivindicação.

Se a mesma reivindicação já tiver sido registada, devolve `false`.

Se for possível registar uma nova reivindicação, adiciona-a ao registo e devolve `true`.

```julia_repl
julia> claim = Plot(bottom_left=Coord(10, 1), top_right=Coord(20, 2));
julia> register = Set{Plot}();
julia> stake_claim!(claim, register)
true
```

## 5. Determina o comprimento do lado maior de um lote.

Implementa a função `get_longest_side()` para obteres o lado maior (horizontal ou vertical) de uma reivindicação.

```julia-repl
claim = Plot(bottom_left=Coord(10, 1), top_right=Coord(20, 2));

julia> get_longest_side(claim)
0x000a
```

## 6. Determina o lote reivindicado com o lado maior, para fins de investigação

Implementa a função `get_claim_with_longest_side()` para examinares todas as reivindicações registadas e devolveres a reivindicação ou reivindicações com o lado maior.

```julia-repl
julia> plot1 = Plot(bottom_left=Coord(5, 3), top_right=Coord(10, 5));
julia> plot2 = Plot(bottom_left=Coord(0, 0), top_right=Coord(3, 3));
julia> register = Set{Plot}([plot1, plot2]);

julia> get_claim_with_longest_side(register)
Plot(Coord(0x0005, 0x0003), Coord(0x000a, 0x0005))
```

Devolve o(s) lote(s) como um `Set`, com um elemento se houver um único lote com o lado maior, ou vários em caso de empate.
