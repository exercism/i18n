# Sobre

O Swift fornece três construções principais de ciclos:

- **ciclos `while`**: Repetem um bloco de código enquanto uma condição especificada continuar `true`. A condição é avaliada antes de executar o corpo do ciclo.
- **ciclos `repeat-while`**: Semelhantes aos ciclos `while`, mas a condição é avaliada depois de executar o corpo do ciclo. Isto garante que o corpo é executado pelo menos uma vez.
- **ciclos `for-in`**: Executam um bloco de código uma vez por cada elemento de uma sequência ou coleção (como um intervalo, um array ou uma string).
