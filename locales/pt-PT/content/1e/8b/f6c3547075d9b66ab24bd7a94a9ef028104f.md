# Dicas

## Geral

- Todas as palavras de limpeza estão em [`destructors`][destructors].
- `:>` e `::` (variáveis locais) mantêm legíveis os corpos com várias bombas. Acrescenta `locals` ao `USING:` se recorreres a eles.

## 1. Esvaziar a sentina

- Uma palavra: `dispose`.

## 2. Rotina de bombagem

- Uma palavra: `with-disposal`. Acrescenta `inline` depois do `;` de fecho,
  para que o compilador consiga ver através do argumento quotation:
  `: pump-out ( pump quot -- ) with-disposal ; inline`.

## 3. Rotina de turno completo

- Abre o âmbito com `with-destructors`. Lá dentro, regista cada
  bomba com `&dispose` e depois faz `call` à quotation. Com variáveis locais:
  `[ pump-a &dispose pump-b &dispose quot call ] with-destructors`.

## 4. Bombagem arriscada

- A mesma forma da tarefa 3, mas com `|dispose` (apenas para falhas) numa
  única bomba.

## 5. Um disposable personalizado: a válvula

- `TUPLE: valve < disposable is-open ;` — o `<` estende `disposable`, por isso a maquinaria do framework é herdada.
- `<valve>` usa `new-disposable` (e não apenas `new`), para que a nova válvula fique registada no framework.
- `M: valve dispose*` é o teu hook de limpeza. Devolver nada na pilha é importante: `>>is-open` deixa o tuple no topo, por isso termina com `drop`.

[destructors]: https://docs.factorcode.org/content/vocab-destructors.html
