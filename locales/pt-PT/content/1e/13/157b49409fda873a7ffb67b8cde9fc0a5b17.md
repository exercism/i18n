`String` e `&str` são duas formas fundamentais de trabalhar com dados textuais em Rust.

A `String` é um vetor de bytes `u8` com posse própria e é mutável.
Um `&str` é uma referência emprestada a um slice de String e, por isso, imutável.

Também podes criar e modificar `String`s usando um dos seus muitos métodos, como o `push`.
```rust
let mut a_string = String::from("hello");
a_string.push('!');
```

Também podes criar uma `String` convertendo um `&str`:
```rust
let a_string = "hello".to_string();
```
