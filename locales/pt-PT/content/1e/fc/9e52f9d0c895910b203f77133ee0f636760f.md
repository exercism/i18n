# Introdução

O R não tem um tipo [conjunto][wiki-set] separado; em vez disso, usa várias funções para realizar operações semelhantes sobre vetores.

O operador [`%in%`][ref-match] testa se um elemento pertence a um conjunto.
Este operador infixo é sinónimo da função `is.element()`.

```R
2 %in% 1:10 # TRUE
12 %in% 1:10 # FALSE
```

Entre as funções relevantes estão:

- [`unique()`][ref-unique] para remover duplicados.
- [`union()`][ref-sets] para combinar conjuntos (matematicamente, `A ∪ B`).
- [`intersect()`][ref-sets] para encontrar os elementos comuns a ambos os conjuntos (`A ∩ B`).
- [`setdiff()`][ref-sets] para subtrair um conjunto a outro (`A - B`).
- [`setequal`][ref-sets] para testar a igualdade de conjuntos, ignorando duplicados e a ordem.

```R
> set_1 <- c("a", "b", "c", "b", "a")
> unique(set_1) # deduplicate
[1] "a" "b" "c"

> set_2 <- c('a', "c", "d")
> union(set_1, set_2) # values in either set
[1] "a" "b" "c" "d"

> intersect(set_1, set_2) # values in both sets
[1] "a" "c"

> setdiff(set_1, set_2) # values in set_1 but not set_2
[1] "b"

> setdiff(set_2, set_1) # values in set_2 but not set_1
[1] "d"

setequal(set_1, c("c", "b", "a", "b")) # are elements the same after deduplication?
[1] TRUE
```

Em todos os casos, a função devolve uma cópia e deixa os argumentos inalterados.

## Tabelas de hash

As operações com vetores descritas acima fazem parte do R base.
São úteis para problemas pequenos, mas tornam-se lentas para conjuntos grandes.

Vários pacotes de terceiros implementam [tabelas de hash][wiki-hash], para melhorar o desempenho em alguns contextos.

Por exemplo, o pacote [`hashtable`][ref-hashtable] disponibiliza implementações de `hashmap` e `hashset`, que escalam melhor.
Como a maioria dos pacotes externos, este não está disponível no Exercism, mas vale a pena explorá-lo para problemas do mundo real.
