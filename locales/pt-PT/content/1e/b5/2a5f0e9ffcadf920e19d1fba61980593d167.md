# Integração com editores

A melhor forma de programar em Clojure é com um REPL ligado ao editor. Existem plugins para os editores/IDEs mais populares:

- Emacs: [CIDER](https://cider.mx)
- IntelliJ: [Cursive](https://cursive-ide.com)
- VSCode: [Calva](https://calva.io)
- Vim: [Conjure](https://github.com/Olical/conjure)

Consulta a [documentação oficial](https://clojure.org/guides/editors) para mais informações.
