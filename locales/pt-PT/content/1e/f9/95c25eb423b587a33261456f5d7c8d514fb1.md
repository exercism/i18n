# Sobre

Escreve código que se lê como inglês simples.

O Visual Basic corre no mesmo runtime .NET que o C# e o F#.
Tens LINQ, genéricos e async/await, mas a sintaxe foi feita para ser lida, não descodificada.

Se já conheces C# ou F#, o runtime .NET e as bibliotecas vão ser-te familiares.
Se conheces VB6, VBA ou VBScript, essa sintaxe familiar é agora suportada pelo runtime .NET testado em combate.

Sem chavetas para equilibrar, sem pontos e vírgulas para caçar.
