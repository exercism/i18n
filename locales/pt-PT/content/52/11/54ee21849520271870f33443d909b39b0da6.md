# Introdução

Os ciclos servem para executar alguma lógica repetidamente.
Os dois tipos mais comuns são o `while loop` (repetição indefinida) e o `for loop` (repetição definida, ou contada).
Existe também o ciclo `for each`, que vai aparecer num conceito mais à frente.


## Sintaxe geral

O `for loop` é composto por um cabeçalho e por um bloco de código que contém o corpo do ciclo entre chavetas.
O cabeçalho é composto por 3 componentes separados por pontos e vírgulas `;`: a instrução de inicialização, a condição e outra expressão.
Qualquer um deles pode estar vazio.

```cpp
for (init-statement; condition; expression) {
  some_statement;
}
```

- O componente **init** é código que corre apenas uma vez, antes de o ciclo começar.
- O componente **condition** tem de ser uma expressão que seja avaliada como Boolean e que controle quando o ciclo deve parar.
O código dentro do ciclo corre enquanto esta condição for avaliada como true.
Assim que esta expressão for avaliada como false, deixa de haver novas iterações do ciclo.
- O componente **expression** é código que corre no fim de cada iteração.


O `while loop` executa o seu corpo enquanto a verificação da sua condição for verdadeira.
O excerto de código abaixo mostra como transformar um ciclo for num ciclo while.

```cpp
init-statement;
while(condition) {
    some_statement;
    expression;
}
```

## Interlúdio: incrementos e decrementos

Ao trabalhar com ciclos, é muitas vezes necessário somar 1 ou subtrair 1 a uma variável contadora.
Isto é tão comum que a operação tem operadores especiais: `++` e `--`.

Têm uma forma de prefixo e uma forma de sufixo.
A forma de prefixo altera a variável antes de esta ser usada na instrução, e a forma de sufixo altera-a depois.
Na maioria das vezes, provavelmente vais querer a versão de prefixo.

```cpp
int a{3};
int b{--a};
// b is 2, a is now 2
int c{a++};
// c is 2, a is now 3
```

## Ciclos for: um exemplo

O componente init costuma criar uma variável contadora, a condição verifica se o ciclo deve continuar ou parar e o componente post incrementa habitualmente o contador no fim de cada repetição.

```cpp
int sum{0};
for (int i{1}; i < 10; ++i) {
  sum += i;
}
```

Este ciclo soma os números de `1` a `9` (incluindo o `9`).

## break e continue

Dentro do corpo de um ciclo, podes usar a palavra-chave `break` para interromper completamente a execução do ciclo:

```cpp
int sum{2};
while(true) {
    sum *= 2;
    if (sum > 1000)
        break;
}
// sum is now 1024
```

Em contrapartida, a palavra-chave `continue` interrompe apenas a execução da iteração atual e passa para a seguinte:

```cpp
int equal_sum{0};
for (int i{1}; i < 7; ++i) {
  if  (i%2 == 1) {
    continue;
  }
  equal_sum += i;
}
// equal_sum is now 12
```
> Nota: normalmente é mais fácil compreender a lógica do ciclo quando o uso de `break` e `continue` é reduzido ao mínimo ou evitado por completo.
