# Introdução

## Ciclos

Os ciclos servem para executar a mesma lógica repetidamente.
Os dois tipos mais comuns são o `while loop` (repetição indefinida) e o `for loop` (repetição definida, ou contada).
Há também o ciclo `for each`, que vais encontrar num conceito mais adiante.

### Sintaxe geral

O `for loop` é composto por um cabeçalho e por um bloco de código que contém o corpo do ciclo entre chavetas.
O cabeçalho é composto por 3 componentes separados por pontos e vírgulas `;`: a instrução de inicialização, a condição e outra expressão.
Qualquer um deles pode estar vazio.

```cpp
for (init_statement; condition; expression) {
  some_statement;
}
```

- O componente **instrução de inicialização** é código que corre apenas uma vez, antes de o ciclo começar.
- O componente **condição** tem de ser uma expressão que seja avaliada como um `boolean` e que controla quando o ciclo deve parar.
  O código dentro do ciclo corre enquanto esta condição for avaliada como `true`.
  Assim que esta expressão for avaliada como `false`, deixa de haver novas iterações do ciclo.
- O componente **expressão** é código que corre no fim de cada iteração.

O `while loop` executa o seu corpo enquanto a verificação da **condição** for `true`.
O excerto de código abaixo mostra como transformar um `for` num `while loop`.

```cpp
init_statement;
while(condition) {
    some_statement;
    expression;
}
```

### Interlúdio: incrementos e decrementos

Quando trabalhas com ciclos, é frequente teres de somar ou subtrair 1 a uma variável contadora que acompanha as iterações.
Isto é tão comum que as operações de incremento e decremento têm operadores especiais: `++` e `--`.

Existem na forma **prefixada** e na forma **pós-fixada**.
A forma prefixada altera a variável antes de esta ser usada na instrução; a forma pós-fixada altera-a depois.
Na maior parte das vezes, vais provavelmente querer a versão prefixada.

```cpp
int a{3};
int b{--a};
// b is 2, a is now 2
int c{a++};
// c is 2, a is now 3
```

### Ciclos for: um exemplo

O _componente de inicialização_ costuma criar uma variável contadora, a _condição_ verifica se o ciclo deve continuar ou parar e o _componente posterior_ incrementa normalmente o contador no fim de cada repetição.

```cpp
int sum{0};
for (int i{1}; i < 10; ++i) {
  sum += i;
}
```

Este ciclo soma os números de `1` a `9` (incluindo o `9`).

### Break e continue

Dentro do corpo de um ciclo, podes usar a palavra-chave `break` para interromper completamente a execução do ciclo:

```cpp
int sum{2};
while(true) {
    sum *= 2;
    if (sum > 1000)
        break;
}
// sum is now 1024
```

Em contrapartida, a palavra-chave `continue` apenas interrompe a execução da iteração atual e passa à seguinte:

```cpp
int equal_sum{0};
for (int i{1}; i < 7; ++i) {
  if  (i%2 == 1) {
    continue;
  }
  equal_sum += i;
}
// equal_sum is now 12
```

~~~~exercism/note
Normalmente é mais fácil compreender a lógica do ciclo quando o uso de `break` e `continue` é minimizado ou evitado por completo.
Ambas as palavras-chave saltam certas secções do código e tornam-no muitas vezes mais difícil de acompanhar.
~~~~
