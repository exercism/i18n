# Instruções

Neste exercício, vais escrever código para ajudar um freelancer a comunicar com um gestor de projeto.
A tua tarefa é fornecer alguns utilitários para calcular rapidamente os valores diários e mensais, opcionalmente com um determinado desconto.

Começamos por estabelecer algumas regras entre o freelancer e o gestor de projeto:

- O valor diário é 8 vezes o valor por hora.
- Um mês tem 22 dias faturáveis.

Por vezes, o freelancer oferece aplicar um desconto no seu valor diário (por exemplo, para os clientes mais leais ou para clientes sem fins lucrativos).

Os descontos são modelados como números fracionários que representam percentagens, por exemplo, `25.0` (25%).

## 1. Calcula o valor diário a partir do valor por hora

Implementa uma função chamada `dailyRateFrom` para calcular o valor diário, recebendo o valor por hora como parâmetro.
O contrato define que um dia tem 8 horas faturáveis.

```swift
dailyRateFrom(hourlyRate: 60)
// Returns 480.0
```

O valor diário devolvido deve ser um `Double`.

## 2. Calcula o valor mensal a partir do valor por hora e de um desconto

Implementa uma função `monthlyRateFrom` para calcular o valor mensal com desconto.
Recebe dois parâmetros: o valor por hora e o desconto em percentagem.


```swift
monthlyRateFrom(hourlyRate: 77, withDiscount: 10.5)
// Returns 12129
```

O valor mensal devolvido deve ser arredondado por excesso (para cima) ao número inteiro mais próximo.

## 3. Calcula o número de dias úteis completos a partir de um orçamento, do valor por hora e de um desconto

Implementa uma função `workdaysIn` que recebe um orçamento, um valor por hora e um desconto, e calcula quantos dias úteis completos isso cobre.

```swift
workdaysIn(budget: 20000, hourlyRate: 80, withDiscount: 11.0)
// Returns 35.0
```
O número de dias devolvido deve ser arredondado por defeito (para baixo) ao número inteiro seguinte.
