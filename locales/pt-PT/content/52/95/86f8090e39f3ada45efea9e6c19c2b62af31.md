# Condicionais

O Ruby tem aquilo a que se chamam expressões de controlo de fluxo. Estas são usadas para controlar a forma como o programa corre e recebem um valor truthy ou falsey.
Há operadores que podem ser usados para criar valores truthy ou falsey, conhecidos como [operadores de comparação][comparison-operators].

Há duas expressões de controlo principais que determinam que código vai correr e que código não vai.
Por outras palavras, decidem qual dos ramos vai correr.

Essas duas são: `if` e a expressão `unless`.

## Operadores de comparação

Os [operadores de comparação][comparison-operators] são usados para comparar valores e devolvem um valor `true` ou `false`.
Os operadores seguintes exigem que os dois valores a comparar sejam do mesmo tipo.
Se os valores não forem do mesmo tipo, o compilador lança um erro.
Aqui está uma lista dos operadores e um exemplo de quando dão um valor `true`:

| Método | Descrição              | Exemplo |
| ------ | ---------------------- | ------- |
| <      | menor que              | 4 < 5   |
| <=     | menor ou igual a       | 4 <= 4  |
| >      | maior que              | 3 > 1   |
| >=     | maior ou igual a       | 2 >= 2  |

Os operadores de igualdade e de diferença podem ser usados para comparar qualquer tipo de valor, ao contrário dos operadores já mencionados.
O operador `==` é usado para verificar se dois valores são iguais, e isso inclui verificar o tipo do valor.
O `!=` funciona da mesma forma, mas devolve `true` se os valores não forem iguais e `false` se forem iguais.
Aqui está uma lista dos operadores de igualdade e de diferença e um exemplo de quando dão um valor `true`:

| Método | Descrição      | Exemplo |
| ------ | -------------- | ------- |
| ==     | igual a        | 4 == 4  |
| !=     | diferente de   | 5 != 4  |

## A condicional if

A condicional [`if`][if] é usada para verificar se uma dada condição é "truthy" ou "falsey".
Se a condição for truthy, o código dentro da condicional corre.
Uma condicional `if` termina com a palavra-chave `end`.

```ruby
value = 1
if value == 1
  "1 is equal to 1"
end
# => "1 is equal to 1"

if value > 2
  "1 is greater than 2"
end
# => nil
```

## A condicional unless

A condicional `unless` funciona de forma muito semelhante à condicional `if`, mas corre o código dentro da condicional `unless` se a condição for falsey.

```ruby
value = 1
unless value == 1
  "1 is not equal to 1"
end
# => nil

unless value > 2
  "1 is not greater than 2"
end
# => "1 is not greater than 2"
```

## A cláusula else

A cláusula `else` pode ser usada em conjunto com a condicional `if`.
A cláusula `else` é executada se o ramo `if` não for executado.

```ruby
value = 1
if value == 1
  "1 is equal to 1"
else
  "1 is not equal to 1"
end
# => "1 is equal to 1"

if value > 2
  "1 is greater than 2"
else
  "1 is not greater than 2"
end
# => "1 is not greater than 2"
```

## Condicionais em cascata

A condicional `elsif` pode ser usada em conjunto com a condicional `if`.
A condicional `elsif` é executada se o ramo `if` não for executado e a condição da condicional `elsif` for truthy.
As condicionais `elsif` podem ser encadeadas e a primeira condição truthy é executada.
Pode também haver uma cláusula `else` no fim da condicional `if`, que corre se nenhuma das condicionais anteriores tiver sido verdadeira.

```ruby
value = 1
if value == 0
  "1 is equal to 0"
elsif value > 2
  "1 is greater than 2"
else
  "1 is not equal to 0 and 1 is not greater than 2"
end
# => "1 is not equal to 0 and 1 is not greater than 2"
```
