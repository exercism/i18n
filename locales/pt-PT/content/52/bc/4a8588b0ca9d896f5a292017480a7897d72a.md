# Instruções

No jogo de cartas Spellbound Steel, tens um baralho de cartas com diferentes personagens, como warriors, mages e rogues, ou diferentes feitiços, como fireball, ice storm e lightning bolt.
O jogo tem entre dois e quatro jogadores, e o objetivo é derrotar os outros jogadores jogando cartas com níveis de poder mais altos.

Queres ganhar vantagem no jogo criando vários métodos para calcular, ordenar e comparar os níveis de poder das cartas.

## 1. Encontrar uma carta no baralho

Não tens a certeza se uma carta está no baralho ou não.
Por isso, queres um método que te diga onde podes encontrar a primeira carta do baralho do tipo que procuras.
Ou, se a carta não estiver no baralho, também queres saber isso.

Implementa um método `SpellboundSteel.find_card?` que recebe um `Array` de cartas do tipo `String` e uma carta do tipo `String` a encontrar.
O método deve devolver o índice da primeira carta do baralho que corresponde à carta a encontrar.
Se a carta não estiver no baralho, o método deve devolver `nil`.

```crystal
cards = ["Warrior", "Mage", "Rogue", "Fireball", "Ice Storm", "Lightning Bolt", "Mage"]
SpellboundSteel.find_card?(cards, "Mage")
# => 1
```

## 2. Escrever todos os nomes das cartas com maiúscula inicial

Para tornar as cartas mais fáceis de ler, queres escrever todos os nomes das cartas com maiúscula inicial.
Assim consegues ver facilmente os nomes das cartas quando as jogas.

Implementa um método `SpellboundSteel.capitalize_cards` que recebe um `Array` de cartas do tipo `String` e devolve as cartas com a primeira letra de cada nome em maiúscula.

```crystal
cards = ["warrior", "mage", "rogue", "fireball", "ice storm", "lightning bolt"]
SpellboundSteel.capitalize_cards(cards)
# => ["Warrior", "Mage", "Rogue", "Fireball", "Ice Storm", "Lightning Bolt"]
```

## 3. Calcular o nível de poder de todas as cartas

No jogo, é importante calcular o nível de poder de todas as cartas.
O poder de todas as cartas pode ver-se na seguinte tabela:

| Tipo de carta  | Nível de poder |
|----------------|-------------|
| Warrior        | 10          |
| Mage           | 20          |
| Rogue          | 30          |
| Fireball       | 15          |
| Ice Storm      | 25          |
| Lightning Bolt | 35          |

Implementa um método `SpellboundSteel.calculate_power_level` que recebe um `Array` de cartas do tipo `String` e devolve o nível de poder total de todas as cartas.

```crystal
cards = ["Warrior", "Mage", "Rogue", "Fireball", "Ice Storm", "Lightning Bolt"]
SpellboundSteel.calculate_power_level(cards)
# => 135
```

## 4. Descodificar uma carta

No jogo, existem as chamadas cartas amaldiçoadas.
Estas cartas são cartas ocultas que só podem ser descodificadas pelo jogador que as jogou.
Para descodificares a carta, tens de retirar todos os segundos carateres do nome da carta.
Isso dá-te o nome da carta.

Implementa um método `SpellboundSteel.decode_card` que recebe uma carta do tipo `String` e devolve a carta descodificada.

```crystal
SpellboundSteel.decode_card("Wbalrrrlimoqr")
# => "Warrior"
```
