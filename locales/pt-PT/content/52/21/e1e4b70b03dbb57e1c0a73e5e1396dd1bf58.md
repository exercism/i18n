# Sobre

O tipo `Option` é o mecanismo da linguagem F# para lidar com valores que podem ou não existir.
Fornece uma alternativa com segurança de tipos ao uso de `null`, que é comum noutras linguagens para lidar com este tipo de valores.
É usado em muitas funções da biblioteca padrão do F#, por isso compreendê-lo é essencial para usar eficazmente a biblioteca padrão do F#.

## Vantagens de usar o tipo `Option`

* __Segurança em tempo de compilação__: Ao tornar a presença ou a ausência de um valor explícita no sistema de tipos, o compilador consegue garantir que tratas o caso «sem valor», evitando uma vasta categoria de erros que poderiam ocorrer com valores `null`.

* __Segurança em tempo de execução__: Em vez de usar `null`, o F# usa `None` para representar a ausência de um valor, tornando impossível que ocorra uma `NullReferenceException`.

* __Obriga a um tratamento explícito__: O sistema de tipos exige que o código trate explicitamente tanto o caso `Some value` como o caso `None`, tornando o teu código mais robusto e previsível.

* __Funciona com correspondência de padrões__: Os `Option` funcionam na perfeição com o idioma de correspondência de padrões do F#, oferecendo uma forma limpa e segura de desconstruir e tratar o valor, se ele existir, ou de realizar uma ação diferente, se não existir.

## Utilização

O tipo `Option` é um tipo genérico (que tem um tipo subjacente).
Os valores `Option` são `Some value`, que representa um valor específico, ou `None`, que representa a ausência de valor.

A função seguinte demonstra como criar um valor `Option`:

```fsharp
let keepIfPositive (a: int) : int option = if a > 0 then Some a else None
```

~~~~exercism/note
`T option` é a sintaxe pós-fixada equivalente a `Option<T>`; as duas formas sintáticas podem ser usadas de forma intermutável.
No entanto, de acordo com o Guia de Estilo do F#, a notação pós-fixada é a preferida para os tipos Option (vê a [secção do Guia de Estilo do F# sobre Formatação de Tipos e Anotações de Tipo](https://learn.microsoft.com/en-us/dotnet/fsharp/style-guide/formatting#for-types-prefer-prefix-syntax-for-generics-foot-with-some-specific-exceptions)).
~~~~

Um caso de uso típico de um `Option` são as funções de pesquisa.
Por exemplo, a função `List.tryFind` devolve `Some index` quando o item está na lista (em que `index` é a posição do valor procurado na lista), ou `None` quando o item não está na lista.

## Ler o conteúdo de um valor Option

A forma idiomática de ler um valor `Option` é através da correspondência de padrões, como mostra o exemplo seguinte:

```fsharp
// Returns "Hello, <name>!" if the name is provided; otherwise returns "Hello, you!"
let sayHello (optionalName: string option): string = 
    match optionalName with
    | Some name -> "Hello, " + name + "!"
    | None -> "Hello, you!"

sayHello (Some "Matthieu")
// --> "Hello, Matthieu!"

sayHello None
// --> "Hello, you!"
```

## Desembrulhar Options com valores predefinidos

Os `Option` podem ser «desembrulhados» (convertidos para o tipo que contêm) fornecendo valores predefinidos com a função `Option.defaultValue`.
Isto é particularmente útil quando queres garantir que o valor não é `None`.
Por exemplo:

```fsharp
Option.defaultValue "" (Some "F#")
// --> "F#"

Option.defaultValue 0 None
// --> 0
```

## Mais funções no módulo `Option`

O módulo `Option` também inclui funções que correspondem às funções disponíveis para listas, arrays, sequências e outros tipos de coleção, como `Option.map`, `Option.iter`, `Option.forall` e `Option.count`.
Estas funções permitem tratar os `Option` como uma coleção de zero ou um elementos.
