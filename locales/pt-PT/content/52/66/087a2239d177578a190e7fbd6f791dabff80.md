# Instruções

Estás como voluntário no centro de artes comunitário, onde está a ser montado um longo mosaico de azulejos cerâmicos sobre a entrada principal. A equipa de design organizou o trabalho **linha a linha**: cada linha é um array de cores de azulejo, e o mosaico inteiro é um array de linhas.

Enquanto os voluntários cortam, colocam e reorganizam azulejos, tu escreves pequenas palavras reutilizáveis para construir, combinar e consultar partes do design.

## 1. Uma faixa de um só azulejo

Define `tile-strip` para receber uma cor e devolver uma linha de 1 elemento que contém apenas essa cor.

```factor
"sky-blue" tile-strip .
! => { "sky-blue" }
```

## 2. Uma linha de três azulejos

Define `row-of-three` para tirar três cores da pilha e devolver uma linha de 3 elementos.

```factor
"red" "white" "blue" row-of-three .
! => { "red" "white" "blue" }
```

## 3. Combina as linhas numa lista plana de azulejos

A equipa de design precisa de verificar rapidamente os totais de cores de todas as linhas do mosaico. Define `combine-rows` para receber um array de linhas e devolver uma única sequência com todos os azulejos por ordem.

```factor
{ { "red" "white" } { "blue" "red" } } combine-rows .
! => { "red" "white" "blue" "red" }
```

## 4. Espelha uma linha

Para painéis simétricos, a equipa espelha uma linha antes de colocar a cópia no lado oposto. Define `mirror-row` para devolver uma linha por ordem inversa.

```factor
{ "red" "white" "blue" } mirror-row .
! => { "blue" "white" "red" }
```

## 5. Onde está esta cor na linha?

Define `tile-position` para receber uma linha e uma cor e devolver o índice (com base em 0) do primeiro azulejo com essa cor na linha. Se a cor não estiver presente, devolve `f`.

```factor
{ "red" "white" "blue" } "white" tile-position .
! => 1

{ "red" "white" "blue" } "green" tile-position .
! => f
```

## 6. Esta linha contém a cor?

Define `has-colour?` para receber uma linha e uma cor e devolver `t` se a cor aparecer em qualquer posição da linha, caso contrário `f`.

```factor
{ "red" "white" "blue" } "white" has-colour? .
! => t

{ "red" "white" "blue" } "green" has-colour? .
! => f
```
