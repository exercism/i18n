# Adenda às instruções

# Parâmetros de entrada

Os parâmetros de entrada deste exercício são:

- `target`: uma string (por exemplo, `'stone'`), que será o _argumento da esquerda_.
- `candidates`: uma lista de strings em caixas (por exemplo, `'stone' ; 'tones' ; 'banana' ; 'tons' ; 'notes' ; 'Seton'`), que será o _argumento da direita_.

O teu verbo será chamado assim:

```j
  target     =. 'stone'
  candidates =. 'stone' ; 'tones' ; 'banana' ; 'tons' ; 'notes' ; 'Seton'
  
  subject findAnagrams candidates
```

## Saída

O teu verbo deve devolver uma _lista_ de caixas que contêm as strings que são anagramas do target. Se não houver anagramas, o resultado deve ser `empty`.
