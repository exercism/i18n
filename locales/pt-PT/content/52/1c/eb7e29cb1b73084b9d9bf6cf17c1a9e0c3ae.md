# Instruções

Neste exercício vais escrever código para imprimir crachás com nomes para os funcionários de uma fábrica. 
Os funcionários têm um ID, um nome e o nome do departamento. 
As etiquetas dos crachás dos funcionários têm o seguinte formato: `"[id] - name - DEPARTMENT"`.

## 1. Imprime um crachá para um funcionário

Implementa a função `print_name_badge`. Deve receber um ID, um nome e um departamento.
Deve devolver a etiqueta do crachá, com o nome do departamento em maiúsculas.

```R
print_name_badge(67, "Katherine Williams", "Strategic Communication")
# => "[67] - Katherine Williams - STRATEGIC COMMUNICATION"
```

## 2. Imprime um crachá para um novo funcionário

Devido a uma particularidade do sistema informático, às vezes os novos funcionários ainda não têm um ID quando começam a trabalhar na fábrica. 
Como os crachás são obrigatórios, recebem um crachá temporário sem o prefixo do ID.

Amplia a função `print_name_badge`. Quando o ID está em falta, deve imprimir um crachá sem ele.

```R
print_name_badge(NA, "Robert Johnson", "Procurement")
# => "Robert Johnson - PROCUREMENT"
```

## 3. Imprime um crachá para o proprietário

Até o proprietário da fábrica tem de usar um crachá em todos os momentos. 
No entanto, o proprietário não tem departamento e nunca vai ter: está acima de todos os departamentos. 
Neste caso, a etiqueta deve imprimir `"OWNER"` em vez do nome do departamento.

Amplia a função `print_name_badge`. Quando o departamento é `NULL`, assume que o crachá pertence ao proprietário da empresa.

```R
print_name_badge(204, "Rachel Miller", NULL)
# => "[204] - Rachel Miller - OWNER"
```

Repara que é possível que o proprietário também seja um novo funcionário.

```R
print_name_badge(NA, "Rachel Miller", NULL)
# => "Rachel Miller - OWNER"
```

## 4. Calcula o salário total dos funcionários sem ID

Como uma medida aproximada de quão bem os IDs estão a ser atribuídos, queres ver o salário combinado dos funcionários sem ID. 
Um valor elevado significa que há muitos à espera, ou que o problema está a afetar pessoas com mais antiguidade: ambos são maus.

Implementa a função `salaries_no_id`, que recebe um vetor de IDs e um vetor correspondente de salários e devolve a soma dos salários das pessoas que ainda não têm ID. 
Os dois vetores têm o mesmo comprimento.

```R
ids <- c(204, NA, 210, 352, NA, 263)
salaries <- c(23, 21, 47, 35, 17, 101) * 1000
salaries_no_id(ids, salaries)
# => 38,000
```

_Como aprendizagem extra não testada:_ Se não houver funcionários sem ID, qual é o "vetor vazio" que estás a somar?
