# Introdução

## Operadores ternários

O _operador ternário_ é uma alternativa leve e compacta às condicionais _if/else_ simples.
Normalmente usado em instruções de retorno (mas não só), basta-lhe uma única linha para tomar a decisão: devolve o valor da esquerda se a expressão for `true` e o valor da direita se for `false`, como se segue:

```java
boolean expr = 0 != 200;

// Ternary statement
int value = expr ? 22 : 33;
// => 22
```

Muitas expressões _if/else_ simples podem ser simplificadas com _operadores ternários_.
