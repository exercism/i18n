# Introdução

## Noções básicas

### Variáveis

O Elixir é uma linguagem de tipo dinâmico, o que significa que o tipo de uma variável só é verificado em tempo de execução. Com o operador de correspondência `=`, podemos associar um valor de qualquer tipo a um nome de variável:

```elixir
# Bound an integer value of 1
count = 1
# You may re-bind variables
count = 2

# You may re-bind any type to a variable
count = false

# Strings can be created by enclosing characters within double quotes
message = "Success!"
```

### Módulos

O Elixir é uma [linguagem de programação funcional][functional-programming] e exige que todas as funções nomeadas sejam definidas num _módulo_. A palavra-chave `defmodule` serve para definir um módulo. Todos os módulos estão disponíveis para os restantes módulos em tempo de execução e não precisam de um _modificador de acesso_ para ficarem visíveis a outras partes do programa. Um _módulo_ é análogo a uma _classe_ noutras linguagens de programação.

```elixir
defmodule Calculator do
  # ...
end
```

### Funções nomeadas

As _funções nomeadas_ têm de ser definidas num módulo. A palavra-chave `def` serve para definir uma função nomeada _pública_.

Cada função pode ter zero ou mais argumentos. O valor da última expressão de uma função é sempre _devolvido implicitamente_.

```elixir
defmodule Calculator do
  def add(x, y) do
    x + y
  end
end
```

Para invocar uma função, indicas o nome do módulo e da função e forneces um valor para cada um dos argumentos da função.

```elixir
sum = Calculator.add(1, 2)
# => 3
```

Podes usar a palavra-chave `defp` em vez de `def` para definir uma função _privada_. As funções privadas só podem ser usadas dentro do próprio módulo que as definiu.

Ao invocar uma função dentro do próprio módulo onde está definida, podes omitir o nome do módulo.

Também podes escrever funções curtas com uma sintaxe de uma só linha (repara na vírgula `,` e nos dois pontos `:` à volta da palavra-chave `do`).

```elixir
defmodule Calculator do
  def subtract(x, y) do
    private_subtract(x, y)
  end

  defp private_subtract(x, y), do: x - y
end

difference = Calculator.subtract(7, 2)
# => 5

difference = Calculator.private_subtract(7, 2)
# => ** (UndefinedFunctionError) function Calculator.private_subtract/2 is undefined or private
#       Calculator.private_subtract(7, 2)
```

### Aridade das funções

É comum referir as funções pela sua _aridade_. A _aridade_ de uma função é o número de argumentos que aceita.

```elixir
# add/3 because this function has three arguments, thus an arity of 3
def add(x, y, z) do
  x + y + z
end
```

### Convenções de nomenclatura

Os nomes dos módulos devem usar `PascalCase`. Um nome de módulo tem de começar por uma letra maiúscula `A-Z` e pode conter letras `a-zA-Z`, números `0-9` e underscores `_`.

Os nomes das variáveis e das funções devem usar `snake_case`. Um nome de variável ou de função tem de começar por uma letra minúscula `a-z` ou um underscore `_`, pode conter letras `a-zA-Z`, números `0-9` e underscores `_`, e pode terminar com um ponto de interrogação `?` ou um ponto de exclamação `!`.

### Biblioteca padrão

O Elixir tem uma biblioteca padrão muito rica e bem documentada. A documentação está disponível online em [hexdocs.pm/elixir][docs]. Guarda este link em algum lugar: vais usá-lo muitas vezes!

A maioria dos tipos de dados incorporados tem um módulo correspondente que oferece funções para trabalhar com esse tipo de dados. Por exemplo, há o módulo `Integer` para números inteiros, o módulo `String` para strings, o módulo `List` para listas, e assim por diante.

Um módulo que vale a pena destacar é o módulo `Kernel`. Fornece as capacidades básicas sobre as quais o resto da biblioteca padrão é construído, como operadores aritméticos, macros de fluxo de controlo e muito mais. As funções do módulo `Kernel` são importadas automaticamente, por isso podes usá-las sem o prefixo `Kernel.`.

### Comentários no código

Os comentários podem ser usados para deixar notas a outros programadores que leiam o código-fonte. Em Elixir, os comentários de uma só linha são precedidos por `#`.
