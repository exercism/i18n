# Instruções

A ESA (Exercism Space Agency) está a planear a toda a velocidade uma nova missão a [Phobos][phobos], uma lua de Marte.
O objetivo da missão é aterrar uma sonda na superfície de Phobos e enviar de volta dados sobre a superfície.
A ESA pediu a tua ajuda para construir o computador de navegação da sonda.
O computador de navegação tem memória limitada, por isso precisamos de manter o uso de memória o mais baixo possível.
Por isso, precisamos de usar os tipos de dados adequados.

## 1. Constantes de navegação

O computador de navegação precisa de saber a distância entre alguns objetos no espaço para fazer os cálculos corretos. A distância é medida em km.

Define as seguintes constantes:

- `NEPTUNE_DISTANCE` com o valor `4_400_000_000`, que deve ser guardado como um `Int64`
- `MARS_DISTANCE` com o valor `227_940_000`, que deve ser guardado como um `Int32`
- `ATMOSPHERE_DISTANCE` com o valor `10_000`, que deve ser guardado como um `Int16`

## 2. Análise correta da área

O computador de navegação precisa de saber a área de alguns objetos no espaço para fazer os cálculos corretos.
Uma área **NÃO** pode ser negativa.
Os engenheiros planearam o programa para gerar um erro de overflow quando a área fosse negativa.
No entanto, os engenheiros esqueceram-se de mudar o inteiro com sinal para um inteiro sem sinal.

Por isso, os engenheiros gostariam de um programa que converta um inteiro com sinal num inteiro sem sinal.

Implementa o método `Navigation#correct_area_analysis`, que recebe uma `measurement` como argumento e devolve a área como um inteiro sem sinal de 32 bits.

~~~~exercism/note
A área fornecida caberá sempre num inteiro sem sinal de 32 bits.
~~~~

```crystal
measurement = 52554
measurement.class
# => Int32

Navigation.new.correct_area_analysis(measurement)
# => 52554

Navigation.new.correct_area_analysis(measurement).class
# => UInt32
```

## 3. Calcular a velocidade

O computador de navegação precisa de saber a velocidade da sonda.
A velocidade é medida em m/s.

Para calcular a velocidade, precisamos de saber a distância percorrida e o tempo que demorou a percorrê-la.
Depois, pega na distância e divide-a pelo tempo.

A velocidade pode não ser exata e nunca será um número considerável.
Por isso, podemos usar um `Float32`.

Implementa o método `Navigation#calculate_velocity`, que recebe `distance` e `time` como argumentos e devolve a velocidade como um `Float` de 32 bits.

```crystal
distance = 52554
time = 2.5

Navigation.new.calculate_velocity(distance, time)
# => 21021.6

Navigation.new.calculate_velocity(distance, time).class
# => Float32
```
