# Sobre

Um [registo][records] é um conjunto de campos (que podem ser de tipos diferentes) que estão relacionados entre si. Para [definir um registo][define], usa-se a palavra-chave `type`. Os campos de um registo definem-se entre os carateres `{` e `}`, e cada campo tem um nome _e_ um tipo.

```fsharp
type Address =
    { Street: string
      HouseNumber: int }
```

Para [criar um registo][create], indica os nomes dos campos e atribui-lhes um valor entre os carateres `{` e `}`. Ao criar um registo, todos os campos têm de receber um valor. Os campos podem ser indicados em qualquer ordem, não têm de corresponder à ordem da definição do tipo de registo. Para aceder aos valores dos campos de uma instância de um registo, usa-se a notação de ponto.

```fsharp
let oldAddress: Address =
    { Street = "Main Street"
      HouseNumber = 17 }

oldAddress.Street      // => "Main Street"
oldAddress.HouseNumber // 17
```

Ao definir ou criar um registo, cada campo tem de estar numa linha própria ou, quando estão na mesma linha, separado por pontos e vírgulas (`;`):

```fsharp
type Address = { Street: string; HouseNumber: int }

let oldAddress: Address = { Street = "Main Street"; HouseNumber = 17 }
```

Se os nomes dos campos de um registo forem únicos, as anotações de tipo são opcionais, pois o compilador consegue inferir o tipo automaticamente. Se a combinação de nomes de campos _não_ for única, podes ajudar o compilador a escolher o registo correto, quer usando um tipo explícito para a associação do registo, quer colocando o tipo do registo antes de um ou mais campos:

```fsharp
type Boat = { Weight: int; Length: int }
type Car = { Weight: int; Length: int }

// Let compiler infer type. As there are multiple matching record types,
// the last matching type is used (Car)
let typeEqualsLastMatch = { Weight = 5000; Length = 15 }

// Use type annotation on binding to force type to Boat
let typeAnnotation: Boat = { Weight = 5000; Length = 15 }

// Use fully qualified name for field to force type to Boat
let fullyQualifiedField = { Boat.Weight = 5000; Length = 15}
```

Como os registos são imutáveis, depois de um registo estar construído, os valores dos seus campos nunca podem mudar. Se quiseres alterar os valores de um registo, a palavra-chave `with` permite-te [criar uma cópia de um registo existente, mas com novos valores para um ou mais campos][create].

```fsharp
// Copy the old address but change the house number
let newAddress = { oldAddress with HouseNumber = 86 }
newAddress.Street      // => "Main Street"
newAddress.HouseNumber // => 86
```

Os registos têm [_igualdade estrutural_][equality], o que significa que duas instâncias do mesmo registo com valores idênticos são equivalentes:

```fsharp
let address1 = { Street = "Main Street"; HouseNumber = 17 }
let address2 = { Street = "Main Street"; HouseNumber = 17 }
let address3 = { Street = "Broadway"; HouseNumber = 17 }

address1 = address2 // => true
address1 = address3 // => false
```

Além de poderes usar a notação de ponto para aceder aos campos de um registo, os registos também podem ser _desconstruídos_ em associações e em correspondência de padrões, usando o [padrão de registo][record-patterns]:

```fsharp
let myAddress = { Street = "Broadway"; HouseNumber = 123 }
let { Street = myStreet; HouseNumber = myHouseNumber } = myAddress

match myAddress with
| { HouseNumber = 1 } -> printfn "First house"
| { HouseNumber = houseNumber; Street = street } -> printfn "House number %d on %s" houseNumber street
// => "House number 123 on Broadway
```
