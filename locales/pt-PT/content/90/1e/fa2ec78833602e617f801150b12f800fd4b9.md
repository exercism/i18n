# Introdução

Um `array` em F# (também chamado _vetor_) é uma coleção mutável de zero ou mais valores com um comprimento fixo. Isto significa que, depois de um array ser criado, o seu tamanho não pode mudar, mas os seus valores podem. Todos os valores de um array têm de ter o mesmo tipo. Podes definir arrays da seguinte forma:

```fsharp
let empty = [| |]
let emptyAlternative = Array.empty

let singleValue = [| 5 |]
let singleValueAlternative = Array.singleton 5

let threeValues = [| "a"; "b"; "c" |]
```

Podes atribuir elementos a um array ou lê-los a partir dele com um índice. Os arrays em F# começam no zero, o que significa que o índice do primeiro elemento é sempre zero:

```fsharp
let numbers = [| 2; 3; 5 |]

// Update value in array
numbers[2] <- 9

// Read value from array
numbers[2]
// => 9
```

Podes manipular os arrays com as funções e os operadores definidos no módulo `Array` ou, manualmente, com correspondência de padrões, usando o padrão _array_:

```fsharp
let describe array =
    match array with
    | [| |] -> "Empty"
    | [| 1; 2; three |] -> sprintf "1, 2, %d" three
    | _ -> "Other"

describe [| |]         // => "Empty"
describe [| 1; 2; 4 |] // => "1, 2, 4"
describe [| 5; 7; 9 |] // => "Other"
```

Também podes _descartar_ um valor ao fazer correspondência de padrões. Quando _não_ te importas com um valor num caso específico (ou seja, não o vais _usar_), podes usar um sublinhado (`'_'`) para o indicar:

```fsharp
let describe array =
    match array with
    | [| |] -> "Empty array"
    | [| x |] -> "Array with one item"
    | [| _; y |] -> "Array with two items (first item ignored)"
    | _ -> "Array with many items (all items ignored)"

describe [| |]          // => "Empty array"
describe [| 1 |]        // => "Array with one item"
describe [| 5; 7 |]     // => "Array with two items (first item ignored)"
describe [| 5; 7; 9 |]  // => "Array with many items (all items ignored)"
```

O `'_'` sozinho deve vir sempre em _último_ lugar na correspondência de padrões. Qualquer valor que _não_ corresponda a nenhum dos outros casos será tratado por este caso.
