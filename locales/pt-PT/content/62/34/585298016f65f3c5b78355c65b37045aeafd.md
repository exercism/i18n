# Testes

## Ficheiros do exercício

Um exercício descarregado inclui estes ficheiros para compilar e testar a tua solução:

```text
hello-world/
├── HelloWorld.vb       # Your solution
├── HelloWorldTests.vb  # The test suite
├── HelloWorld.vbproj   # Project and build configuration
└── packages.lock.json  # Resolved project dependencies
```

Os nomes dos ficheiros variam de exercício para exercício.
Escreve a tua solução no ficheiro `.vb` cujo nome não termina em `Tests`.
O ficheiro que termina em `Tests.vb` é o conjunto de testes xUnit; normalmente, só deves editá-lo para remover argumentos `Skip`.
Normalmente, não precisas de editar o ficheiro de projeto nem o ficheiro de bloqueio.

## Executar os testes

Abre um terminal na pasta do exercício e executa:

```bash
dotnet test
```

O comando restaura as dependências do projeto, compila o projeto e executa os testes.
Também podes usar `dotnet watch test` para voltar a executar os testes sempre que um ficheiro de código-fonte muda.

## Testes ignorados

Os exercícios ativam inicialmente apenas o primeiro teste, o que te permite resolver os restantes passo a passo.
Abre o ficheiro que termina em `Tests.vb` para encontrares os testes.
Cada teste é uma sub-rotina `Sub` marcada com um atributo `<Fact>` do xUnit.
Um teste é ignorado enquanto o seu atributo `<Fact>` tiver um argumento `Skip`:

```vb
<Fact(Skip:="Remove this Skip property to run this test")>
Public Sub Lowercase_words()
    Assert.Equal("ROR", Abbreviate("Ruby on Rails"))
End Sub
```

Para ativares o teste, basta removeres o argumento `Skip`:

```vb
<Fact>
Public Sub Lowercase_words()
    Assert.Equal("ROR", Abbreviate("Ruby on Rails"))
End Sub
```

Depois de o teste agora ativado passar, repete este processo com o próximo teste ignorado.
Quando todos os testes estiverem ativados e a passar, está feito.
