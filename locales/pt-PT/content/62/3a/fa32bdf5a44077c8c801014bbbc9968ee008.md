# Dicas

## 1. Desloca os bits para trás

- Há dois operadores para deslocar para a direita, mas só um insere sempre um 0.

## 2. Coloca alguns bits a 1

- Um dos operadores bit a bit coloca sempre um bit a 1 onde os bits de ambos os valores são 1.

## 3. Inverte bits específicos

- Há uma operação bit a bit que inverte um bit onde a máscara é 1.

## 4. Limpa bits específicos

- Uma das operações bit a bit limpa bits onde o bit da máscara é 0.
- Mas podes precisar de a combinar com outro operador para limpar bits onde a máscara é 1.
