# PowerShell

Automatiza tudo!
Escreve scripts em qualquer sistema operativo para gerir ficheiros, processos, um centro de dados ou serviços na nuvem.
Explora interativamente dados estruturados como JSON, XML e CSV; trabalha com qualquer interface de gestão, desde APIs web e CIM até aplicações de linha de comandos.

# Sobre o PowerShell

Uma linguagem de scripting .NET de código aberto e multiplataforma, shell e framework de gestão de configuração, o PowerShell ajuda profissionais de TI e utilizadores avançados a controlar e automatizar praticamente tudo.

O PowerShell é construído sobre o .NET Framework e transforma o clássico conceito de pipe do Unix, estendendo-o da mera passagem de texto ou fluxos binários para a passagem de instâncias de objetos que incluem informação de tipo (por exemplo, datas e horas) e estado complexo com os seus dados estruturados.
Enquanto numa shell tradicional podes recorrer ao processamento de texto para extrair informação específica da saída de um comando, no PowerShell tens acesso a propriedades e métodos (incluindo formas de inspecionar objetos para determinar que propriedades e métodos estão disponíveis).
Podes trabalhar com ficheiros CSV, converter JSON em hashtables, navegar por documentos XML e muito mais, o que torna facilmente combináveis muitas tarefas que seriam difíceis ou impraticáveis com análise de texto.

O PowerShell é extensível.
Não apenas através de ferramentas de linha de comandos autónomas, à maneira das outras shells, mas também através de scripts, funções e cmdlets distribuídos em módulos que se integram realmente com o sistema de ajuda do PowerShell, o editor de linha de comandos com realce de sintaxe, a descoberta automática de parâmetros e o preenchimento automático com a tecla Tab.
Podes até estender a sintaxe simples e explorável de propriedade + conteúdo do sistema de ficheiros a armazenamentos de dados como o registo do Windows e o repositório de certificados, o SQL Server e até o Azure!

O PowerShell inclui muitas funcionalidades adicionais:

- «Cmdlets» incorporados para tarefas comuns de administração de sistemas, como gerir ficheiros, serviços, processos e até o registo, os registos de eventos e o Common Information Model (CIM), pedidos web e muito mais.
- Compatibilidade com scripts e ferramentas de linha de comandos existentes.
- Interfaces extensíveis e módulos e comandos fáceis de descobrir.
- Acesso total ao .NET Framework e extensibilidade através de assemblies .NET do NuGet.
- Um histórico de comandos completo, com informação sobre o sucesso e a duração da execução de um comando.
- Capacidades poderosas de manipulação de objetos. Os objetos podem ser manipulados diretamente, serializados e até enviados para outras ferramentas ou bases de dados.

Encontras documentação detalhada sobre o PowerShell, a linguagem, os conceitos essenciais e as funcionalidades, juntamente com os instaladores, em https://docs.microsoft.com/en-us/powershell.
