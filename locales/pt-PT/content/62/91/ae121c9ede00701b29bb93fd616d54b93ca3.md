## 1. Verifica se o comando é válido

Além de ser inteligente, o chatbot também é um assistente leal.

Para pedir algo ao chatbot, o utilizador tem de dizer a palavra “**Chatbot**” na primeira posição do comando.

Não importa se a palavra-chave está em maiúsculas ou minúsculas. O importante aqui é a posição da palavra.

Implementa a função `is_valid_command()` que ajuda o chatbot a reconhecer quando o utilizador está a dar um comando.

```julia-repl
julia> is_valid_command("Chatbot, play a song from the 80's.")
True

julia> is_valid_command("Hey Chatbot, where is the closest pharmacy?")
False

julia> is_valid_command("CHATBOT, do you have a solution for this challenge?")
True
```

## 2. Remove emojis encriptados

O chatbot tem dificuldade em compreender como as pessoas usam emojis para expressar as suas emoções.

Quando o chatbot recebe mensagens dos utilizadores, cada emoji é representado como “_emoji_” seguido do seu número _id_.

Implementa o método `remove_emoji()` para receber uma string e remover toda a encriptação dos emojis ao longo da mensagem.

As linhas que não contêm texto de emoji devem ser devolvidas sem alterações.

Remove apenas a string do emoji. Não tentes ajustar os espaços em branco.

```julia-repl
julia> remove_emoji("I love playing videogames emoji3465 it's one of my hobbies")
"I love playing videogames  it's one of my hobbies"
```

## 3. Verifica se o número de telefone é válido

Tendo em conta a transferência de funcionalidades do chatbot para uma aplicação móvel, espera-se que o utilizador escreva um número de telefone durante a conversa.

O problema é que o chatbot só consegue ler e validar um número com um formato específico.

Se o número for válido (corresponder à sequência de carateres especificada pela **expressão regular**), o chatbot responde com uma mensagem a agradecer ao utilizador e a confirmar o número. Se o número for inválido, a função informa o utilizador de que o número de telefone não é válido.

O formato esperado é: (+##) ###-###-###

```julia-repl
julia> check_phone_number("(+34) 659-771-594")
"Thanks! You can now download me to your phone."

julia> check_phone_number("659-771-594")
"Oops, it seems like I can't reach out to 659-771-594"
```

## 4. Obtém o link do website

O chatbot é um software muito curioso. Apesar de conseguir pesquisar na internet sobre um determinado tema, gosta de perguntar aos utilizadores por websites interessantes ou URLs onde possa encontrar informações relevantes.

Exemplo de conversa:

- **Chatbot**: Olá, nome de utilizador, gostaria de aprender a programar em JavaScript. Conheces algum site interessante onde possa aprender?
- **Utilizador**: Aprendi muito no [exercism.org](http://exercism.org)

Implementa a função `getURL()` que consegue devolver um array apenas com o link de cada website.

```julia-repl
julia> getURL("I learned a lot from exercism.org")
["exercism.org"]
```

## 5. Cumprimenta o utilizador

Para armazenar dados de todas as pessoas que conversaram com ele, o chatbot consegue obter o nome completo a partir do perfil do utilizador neste formato: **“smith, john”**.

Assim, queremos que o nosso chatbot seja muito educado e cause uma boa impressão.

Escreve a função `nice_to_meet_you()` que recebe uma string com o nome completo do utilizador e devolve a string **“Nice to meet you, John Smith”**

```julia-repl
julia> str = "Smith, John"

julia> nice_to_meet_you(str)
"Nice to meet you, John Smith"
```
