# Instruções

Neste exercício, vais implementar um conjunto parcial de rotinas utilitárias para ajudar um programador a limpar nomes de identificadores.
Ao longo das 5 tarefas, vais construir gradualmente a rotina `Clean`.
Um identificador válido é composto por zero ou mais letras e underscores.
Em todos os casos, é garantido que a string de entrada não é nula.
Se for passada uma string vazia à função `Clean`, deve ser devolvida uma string vazia.
Repara que quem chama deve evitar chamar a rotina `Clean` com um identificador vazio, uma vez que esses identificadores não têm qualquer efeito.

## 1. Substitui todos os espaços encontrados por underscores

Implementa o método (_static_) `Identifier.Clean()` para substituir todos os espaços por underscores.
Isto também se aplica a espaços no início e no fim.

```csharp
Identifier.Clean("my   Id");
// => "my___Id"
```

## 2. Substitui os carateres de controlo pela string em maiúsculas `"CTRL"`

Modifica o método (_static_) `Identifier.Clean()` para substituir os carateres de controlo pela string em maiúsculas `"CTRL"`.

```csharp
Identifier.Clean("my\0Id");
// => "myCTRLId",
```

## 3. Converte kebab-case em camelCase

Modifica o método (_static_) `Identifier.Clean()` para converter kebab-case em camelCase.

```csharp
Identifier.Clean("à-ḃç");
// => "àḂç"
```

## 4. Omite os carateres que não são letras

Modifica o método (_static_) `Identifier.Clean()` para omitir todos os carateres que não sejam letras.

```csharp
Identifier.Clean("1😀2😀3😀");
// => ""
```

## 5. Omite as letras gregas minúsculas

Modifica o método (_static_) `Identifier.Clean()` para omitir todas as letras gregas no intervalo de 'α' a 'ω'.

```csharp
Identifier.Clean("MyΟβιεγτFinder");
// => "MyΟFinder"
```
