# Dicas

## 1. Verifica se a comida está correta

- Podes usar uma [condicional `if`][if] para verificar se a comida está correta.

## 2. Verifica se a bebida está envenenada

- Existe [um método][downcase] para converter uma string em minúsculas.
- Podes verificar se uma string tem um caráter específico com [`String#includes?`][includes?].

## 3. Substitui a bebida

- Podes usar métodos já implementados para verificar se a bebida está envenenada.
- Existe [um operador][or] que pode ser usado para devolver o primeiro valor que seja verdadeiro.

[includes?]: https://crystal-lang.org/api/latest/String.html#includes%3F%28search%3AChar%7CString%29%3ABool-instance-method
[or]: https://crystal-lang.org/reference/latest/syntax_and_semantics/or.html
