# Instruções

Neste exercício, vais jogar um jogo de adivinhar números com um amigo. As regras são simples: escolhes secretamente um número entre `1` e `100` e o teu amigo tenta adivinhar que número escolheste. Para ajudar o teu amigo, respondes de forma diferente consoante a proximidade do palpite em relação ao número que escolheste (`42`). Estas são as regras para as diferentes respostas:

- Se o palpite for `42`: "Correct"
- Se o palpite for `41` ou `43`: "So close"
- Se o palpite for inferior a `41`: "Too low"
- Se o palpite for superior a `43`: "Too high"

Tens quatro tarefas para codificar as respostas aos palpites.

## 1. Responde a um palpite correto

Implementa a função `reply` para responder a um palpite correto:

```fsharp
reply 42
// => "Correct"
```

## 2. Responde a um palpite próximo

Modifica a função `reply` para responder a palpites próximos:

```fsharp
reply 41
// => "So close"
```

## 3. Responde a palpites demasiado baixos

Modifica a função `reply` para responder a palpites demasiado baixos:

```fsharp
reply 25
// => "Too low"
```

## 4. Responde a palpites demasiado altos

Modifica a função `reply` para responder a palpites demasiado altos:

```fsharp
reply 88
// => "Too high"
```
