# Introdução

## Temporal Adjusters

Quando trabalhas com objetos `java.time` como `LocalDate`, muitas vezes precisas de fazer ajustes de datas complexos, como encontrar a "segunda terça-feira do mês".
Em vez de calculares isto manualmente, podes usar **`TemporalAdjusters`**.

A classe utilitária `java.time.temporal.TemporalAdjusters` (atenção ao "s" do plural) disponibiliza métodos estáticos para muitos ajustes de datas comuns.
Aplicas estes ajustes com o método `.with()` num objeto temporal (como `LocalDate`).

```exercism/note
Usar `with(TemporalAdjuster)` devolve uma _nova_ instância e não atualiza a instância existente, porque os objetos `java.time` são imutáveis.
```

```java
import java.time.LocalDate;
import java.time.Month;
import java.time.DayOfWeek;
import java.time.temporal.TemporalAdjusters;

LocalDate date = LocalDate.of(2024, Month.AUGUST, 15); // 2024-08-15 (a Thursday)

// Use a predefined adjuster: find the last day of the month
LocalDate lastDay = date.with(TemporalAdjusters.lastDayOfMonth());
// => 2024-08-31
```

Eis alguns ajustadores essenciais para cálculos de agendamento:

### Encontrar a enésima ocorrência de um dia da semana

Usa `dayOfWeekInMonth(int ordinal, DayOfWeek dayOfWeek)` para encontrar a enésima ocorrência de um dia da semana.

```java
// Find the second Tuesday of August 2024
LocalDate secondTuesday = date.with(TemporalAdjusters.dayOfWeekInMonth(2, DayOfWeek.TUESDAY));
// => 2024-08-13
```

### Encontrar o primeiro/último dia da semana no mês

Usa `firstInMonth(DayOfWeek dayOfWeek)` ou `lastInMonth(DayOfWeek dayOfWeek)`.

```java
// Find the last Monday of August 2024
LocalDate lastMonday = date.with(TemporalAdjusters.lastInMonth(DayOfWeek.MONDAY));
// => 2024-08-26
```

### Ajustes relativos (next/previous)

Ajustadores como `next()`, `previous()`, `nextOrSame()` e `previousOrSame()` encontram a ocorrência seguinte ou anterior de um determinado dia da semana, em relação à data atual.

- `next()`/`previous()`: excluem a data atual se coincidir.
- `nextOrSame()`/`previousOrSame()`: incluem a data atual se coincidir.

```java
LocalDate thursday = LocalDate.of(2024, Month.AUGUST, 15); // A Thursday

// Find the next Thursday (exclusive)
LocalDate nextThursday = thursday.with(TemporalAdjusters.next(DayOfWeek.THURSDAY));
// => 2024-08-22

// Find the next Thursday (inclusive) - returns the same date
LocalDate nextOrSameThursday = thursday.with(TemporalAdjusters.nextOrSame(DayOfWeek.THURSDAY));
// => 2024-08-15

// Find the previous Monday (exclusive)
LocalDate previousMonday = thursday.with(TemporalAdjusters.previous(DayOfWeek.MONDAY));
// => 2024-08-12
```

### Ajustadores personalizados

`TemporalAdjuster` é uma interface funcional, por isso podes escrever um ajustador teu como uma lambda que recebe o objeto temporal a ajustar e devolve o objeto já ajustado.
Aplica-se com `.with()` tal como os ajustadores predefinidos, e pode usá-los internamente.

```java
import java.time.temporal.TemporalAdjuster;

// An adjuster that moves a weekend date to the following Monday
TemporalAdjuster skipWeekend = temporal -> {
    DayOfWeek day = DayOfWeek.from(temporal);
    if (day == DayOfWeek.SATURDAY || day == DayOfWeek.SUNDAY) {
        return temporal.with(TemporalAdjusters.next(DayOfWeek.MONDAY));
    }
    return temporal;
};

LocalDate saturday = LocalDate.of(2024, Month.AUGUST, 17);
LocalDate monday = saturday.with(skipWeekend);
// => 2024-08-19
```

Usar estes ajustadores da classe `TemporalAdjusters` pode simplificar bastante as tarefas de manipulação de datas.
