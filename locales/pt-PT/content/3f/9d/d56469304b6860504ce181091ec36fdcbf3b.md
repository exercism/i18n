# Instruções

A dona da pizzaria da tua zona pediu-te para a ajudares a calcular os tempos de cozedura de diferentes pizzas. Neste exercício vais escrever algumas funções para fazer esses cálculos.

Tens três tarefas.

## 1. Calcula o tempo de cozedura restante, em minutos

Define e implementa a função `remainingMinutesInOven()`, que calcula quantos minutos mais precisas de manter a pizza no forno.

A função deve aceitar um parâmetro **opcional** (com valor predefinido) para o número de minutos que passaram desde que começaste a cozer a pizza. Se o parâmetro não for indicado, assume que acabaste de colocar a pizza no forno e que já passaram **0 (zero)** minutos.

Para simplificar, vamos assumir que todos os tipos de pizza precisam de exatamente 40 minutos no forno para ficarem prontas.

```kotlin
remainingMinutesInOven()   // => 40

remainingMinutesInOven(10)   // => 30
```

## 2. Calcula o tempo de preparação, em minutos

Antes de cozer a pizza, tens de preparar a massa, estendê-la e colocar as coberturas.

Define e implementa a função `preparationTimeInMinutes()`, que calcula quantos minutos são necessários para preparar a pizza antes de a colocar no forno.

A função deve aceitar um parâmetro **obrigatório** (`numberOfIngredientTypes`) para o número de tipos de ingredientes de cobertura que vão ser usados.

Assume que precisas de 5 minutos para fazer e estender a massa e 2 minutos para usar **cada** tipo de cobertura.

```kotlin
preparationTimeInMinutes(0) // => 5

preparationTimeInMinutes(1) // => 7
```

## 3. Calcula o tempo decorrido, em minutos

Define e implementa a função `elapsedCookingTimeInMinutes()`, que calcula quantos minutos são necessários para preparar, cozer e servir a pizza. Usa as funções dos passos anteriores ao fazer os cálculos.

A função deve aceitar dois parâmetros. O primeiro é **obrigatório** e é o número de tipos de ingredientes de cobertura. O segundo é **opcional** e é o tempo de servir, em minutos (assume que é 0 se não for indicado).

```kotlin
elapsedCookingTimeInMinutes(1)  // => 47

elapsedCookingTimeInMinutes(2, 3)  // => 52
```
