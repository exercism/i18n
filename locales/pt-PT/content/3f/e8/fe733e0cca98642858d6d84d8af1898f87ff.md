# Dicas

## 1. Descreve números simples

- usa `fmt.Sprintf` para formatar

## 2. Descreve uma caixa de número

- obtém o resultado do método `Number()`
- usa `fmt.Sprintf` para formatar

## 3. Implementa um método que extrai o número de uma caixa de número sofisticada

- usa uma asserção de tipo para verificar se isto é um `FancyNumber`
- obtém a `string` do método `Value()`
- usa `strconv.Atoi` para converter a `string` num `int` (podemos descartar o erro, uma vez que queremos 0 se não for possível convertê-la num `int`)

## 4. Descreve uma caixa de número sofisticada

- usa `ExtractFancyNumber` para obter o valor `int`
- converte o `int` num `float64`
- usa `fmt.Sprintf` para formatar

## 5. Implementa `DescribeAnything`, que usa todas as anteriores

- usa asserções de tipo (por exemplo, `i.(someType)`) ou um switch de tipo (`switch v := i.(type)`)
- lembra-te de converter o `int` num `float64`
