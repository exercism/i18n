# Adenda às instruções

## Dicas

Para completar este exercício, precisas de implementar a função `slices`, que recebe um *texto* e devolve as subsequências de algarismos com um tamanho especificado:

Se é a primeira vez que resolves este exercício, é recomendável que uses a assinatura fornecida:

```haskell
slices :: Int -> String -> [[Int]]
```

Mais tarde, pode ser boa ideia revisitar este problema e experimentar outros tipos de dados e bibliotecas:

- `ByteString`, do pacote *bytestring*.
- `Sequence`, do pacote *containers*.
- `Text`, do pacote *text*.
- `Vector`, do pacote *vector*.

O conjunto de testes foi concebido intencionalmente para aceitar quase qualquer assinatura de tipo que faça sentido, por isso encorajamos-te a encontrar a que achas que é a melhor.
