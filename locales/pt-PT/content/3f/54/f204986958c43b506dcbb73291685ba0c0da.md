# Introdução

## Parâmetros

Este exercício aborda alguns detalhes dos parâmetros dos métodos e da sua utilização em C#.

Os parâmetros transportam informação de um método que chama para um método chamado.

- O comportamento dos parâmetros pode ser modificado com o recurso a modificadores como `ref` e `out`.

- Um parâmetro com o modificador `out` transmite um valor de volta do método chamado para quem o chama. O parâmetro pode ser passado ao método chamado sem estar inicializado e, em qualquer caso, é tratado dentro do método chamado como se, à entrada, não tivesse sido inicializado. A forma mais fácil de compreender o comportamento e as regras relativas aos modificadores de parâmetros é através de exemplos (ver abaixo) e de mensagens do compilador.

```csharp
void Foo(out int val)
{
    val = 42;
}
void Bar(int val)
{
    val = 42;
}

int importantValue = 1729;
Foo(out importantValue);
var result = importantValue == 42;
// => true

importantValue = 1729;
Bar(importantValue);
result = importantValue == 1729;
// => true
```

- Os parâmetros `out` têm de receber uma atribuição dentro do método chamado.

- Um parâmetro com o modificador `ref` passa um valor para um método chamado. Quando o método termina, quem o chama encontra nesse parâmetro todas as atualizações feitas pelo método chamado.

```csharp
void Foo(ref int val)
{
    val *= 7;
}

int importantValue = 6;
Foo(ref importantValue);
return importantValue;
// => 42
```

- Os parâmetros `ref` têm de ser variáveis, pois o método chamado vai operar diretamente sobre o parâmetro tal como é visto por quem o chama.
- Os modificadores `out` e `ref` são obrigatórios tanto na assinatura do método chamado como no local da chamada.
