# Introdução

## Classes

A principal construção orientada a objetos em Java é a _classe_, que combina dados (_campos_) e comportamento (_métodos_).
Os campos e os métodos de uma classe são os seus _membros_.

O acesso aos membros pode ser controlado através de modificadores de acesso. Os dois mais comuns são:

- `public`: qualquer código pode aceder ao membro (sem restrições).
- `private`: só o código da mesma classe pode aceder ao membro.

Podes pensar numa classe como um modelo para criar instâncias dessa classe.
Para criar uma instância de uma classe (também conhecida como _objeto_), usa-se a palavra-chave `new`:

```java
class Car {
}

// Create two car instances
Car myCar = new Car();
Car yourCar = new Car();
```

Os campos têm um tipo e um nome (definido em camelCase) e podem ser definidos em qualquer parte de uma classe (por convenção, escritos em PascalCase):

```java
class Car {
    // Accessible by anyone
    public int weight;

    // Only accessible by code in this class
    private String color;
}
```

É possível atribuir opcionalmente um valor inicial a um campo.
Se um campo _não_ especificar um valor inicial, fica com o valor predefinido do seu tipo.
Os valores dos campos de uma instância podem ser consultados e atualizados com a notação de ponto.

```java
class Car {
    // Will be set to specified value
    public int weight = 2500;

    // Will be set to default value (0)
    public int year;
}

Car newCar = new Car();
newCar.weight; // => 2500
newCar.year;   // => 0

// Update value of the field
newCar.year = 2018;
```

Os campos privados são normalmente atualizados como efeito secundário da chamada de um método.
Estes métodos normalmente não devolvem nenhum valor, caso em que o tipo devolvido deve ser `void`:

```java
class CarImporter {
    private int carsImported;

    public void importCars(int numberOfCars)
    {
        // Update private field from public method
        carsImported = carsImported + numberOfCars;
    }
}
```
