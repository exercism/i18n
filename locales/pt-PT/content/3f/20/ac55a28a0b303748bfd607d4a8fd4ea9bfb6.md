# Introdução

## Funções anónimas

As funções são tratadas como cidadãos de primeira classe em Elixir. Isto significa que:

- Funções nomeadas e anónimas podem ser atribuídas a variáveis.
- Funções nomeadas e anónimas podem ser passadas como dados, como argumentos e valores devolvidos.
- Funções anónimas podem ser criadas dinamicamente.

As funções anónimas, ao contrário das funções nomeadas, não têm uma referência estática disponível. Só estão disponíveis se forem atribuídas a uma variável ou invocadas imediatamente.

Podemos usar funções anónimas para:

- Esconder dados usando âmbito lexical (também conhecido como closure).
- Criar funções dinamicamente em tempo de execução.

As funções anónimas começam com a palavra reservada `fn`, os argumentos são separados do corpo da função com o token `->`, e terminam com um `end`. Tal como nas funções nomeadas, a última expressão da função é _devolvida implicitamente_ à função que a chama.

Para invocar uma referência de função, tens de usar um `.` entre a variável de referência e a lista de argumentos:

```elixir
function_variable = fn param ->
  param + 1
end

function_variable.(1)
# => 2
```

Podes até usar notação de captura abreviada para tornar isto mais conciso:

```elixir
variable = &(&1 + 1)

variable.(1)
# => 2
```

## Manipulação de bits

O Elixir suporta muitas funções para trabalhar com bits no _módulo Bitwise_.

- `band/2`: AND bit a bit
- `bsl/2`: deslocamento para a esquerda bit a bit
- `bsr/2`: deslocamento para a direita bit a bit
- `bxor/2`: XOR bit a bit
- `bor/2`: OR bit a bit
- `bnot/1`: NOT bit a bit

Aqui está um exemplo de como usar uma função bit a bit:

```elixir
Bitwise.bsl(1, 3)
# => 8
```

Todas as funções bit a bit só funcionam com números inteiros.

Se estiveres a usar a versão 1.9 do Elixir ou inferior, precisas de chamar `require Bitwise` no início da definição do módulo para poderes usar o módulo _Bitwise_.
