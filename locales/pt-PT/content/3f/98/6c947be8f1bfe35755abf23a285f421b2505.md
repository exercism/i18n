# Instruções

Dada uma palavra, calcula a pontuação de Scrabble dessa palavra.

## Valores das letras

Vais precisar destes:

```text
Letter                           Value
A, E, I, O, U, L, N, R, S, T       1
D, G                               2
B, C, M, P                         3
F, H, V, W, Y                      4
K                                  5
J, X                               8
Q, Z                               10
```

## Exemplos

A palavra "cabbage" deve valer 14 pontos:

- 3 pontos pelo C
- 1 ponto pelo A, duas vezes
- 3 pontos pelo B, duas vezes
- 2 pontos pelo G
- 1 ponto pelo E

E, para somar:

- `3 + 2*1 + 2*3 + 2 + 1`
- = `3 + 2 + 6 + 3`
- = `5 + 9`
- = 14

## Extensões

- Podes usar uma letra dupla ou tripla.
- Podes usar uma palavra dupla ou tripla.
