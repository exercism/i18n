# Sobre

O Python tem três tipos diferentes de números incorporados: inteiros ([`int`][int]), números de vírgula flutuante ([`float`][float]) e complexos ([`complex`][complex]).
As frações ([`fractions.Fraction`][fractions]) e os decimais ([`decimal.Decimal`][decimals]) também estão disponíveis através de importação da biblioteca padrão.

Os números inteiros, incluindo os números hexadecimais ([_`hex()`_][hex]), octais ([_`oct()`_][oct]) e binários ([_`bin()`_][bin]) **sem** casas decimais, também são identificados como `ints`:

```python
# Ints are whole numbers.
>>> 1234
1234
>>> type(1234)
<class 'int'>

>>> -12
-12
```

Os números que contêm um ponto decimal (com ou sem parte fracionária) são identificados como `floats`:

```python
>>> 3.45
3.45
>>> type(3.45)
<class 'float'>
```

## Aritmética

O Python suporta totalmente a aritmética entre estes diferentes tipos de números e converte os números de menor amplitude para corresponderem aos de maior amplitude quando são usados com os operadores aritméticos binários (`+`, `-`, `*`, `/`, `//` e `%`).

Todos os números (exceto os complexos) suportam todas as [operações aritméticas][arithmetic-operations], avaliadas de acordo com a [precedência de operadores][operator precedence].
O suporte para funções matemáticas (para além de `+` e `-`) para números complexos encontra-se no módulo [cmath][cmath].

### Adição e subtração

Os operadores de adição e subtração comportam-se como na matemática normal.
Se um ou mais dos operandos for um `float`, os restantes `int`s também serão convertidos em `float`s:

```python
>>> 5 - 3
2
# The int is widened to a float here, and a float is returned.
>>> 3 + 4.0
7.0
```

### Multiplicação

Tal como na adição e na subtração, a multiplicação converte os números de menor amplitude para corresponderem aos de maior amplitude:

```python
>>> 3 * 2
6

>>> 3 * 2.0
6.0
```

### Divisão

A divisão devolve sempre um `float`, mesmo que o resultado seja um número inteiro:

```python
>>> 6/5
1.2

>>> 6/2
3.0
```

### Divisão inteira

Se precisares de um resultado `int`, podes usar a divisão inteira para truncar o resultado.
A divisão inteira é efetuada com o operador `//`:

```python
>>> 6//5
1

>>> 6//2
3
```

### Módulo

O operador de módulo (`%`) devolve o resto da divisão dos dois operandos:

```python
# The result of % is zero here, because dividing 8 by 2 leaves no remainder
>>> 8 % 2
0

# The result of % is 2 here, because 3 only goes into 5 once, with 2 left over
>>> 5 % 3
2
```

Outra forma de ver 5 % 3:

```python
>>> whole_part = int(5/3)
1

>>> decimal_part = 5/3 - whole_part
0.6666666666666667

>>> whole_remainder = decimal_part * 3
2.0
```

## Exponenciação

A exponenciação é efetuada com o operador `**`:

```python
>>> 2 ** 3
8

>>> 4 ** 0.5
2
```

## Conversões

Os números podem ser convertidos de `int` para `floats` e de `floats` para `int` com as funções incorporadas `int()` e `float()`:

```python
>>> int(3.45)
3

>>> float(3)
3.0
```

## Arredondamento

O Python disponibiliza uma função incorporada [`round(<number>, <decimal_places>)`][round] para arredondar um número de vírgula flutuante a um determinado número de casas decimais.
Se não for especificado nenhum número de casas decimais, o número é arredondado ao inteiro mais próximo e devolve um `int`:

```python
>>> round(3.1415926535, 2)
3.14

>>> round(3.1415926535)
3
```

## Prioridade e parênteses

O Python permite-te usar parênteses para agrupar expressões.
Isto é útil quando queres alterar a ordem de operações predefinida.

```python
>>> 2 + 3 * 4
14

>>> (2 + 3) * 4
20
```

O Python segue a regra [PEMDAS][pemdas] para a precedência de operadores.
Isto significa que os cálculos dentro de `()` têm a prioridade mais alta, seguidos de `**` e, depois, de `*`, `/`, `//`, `%`, `+` e `-`:

```python
>>> 2 + 3 - 4 * 4
-11

>>> (2 + 3 - 4) * 4
4

# In the following example, the `**` operator has the highest priority, then `*`, then `+`
# Meaning we first do 4 ** 4, then 3 * 256, then 2 + 768
>>> 2 + 3 * 4 ** 4
770
```

## Precisão e representação

Os inteiros em Python têm [precisão arbitrária][arbitrary-precision]: o número de algarismos é limitado apenas pela memória disponível do sistema anfitrião.

Os números de vírgula flutuante são habitualmente implementados com um `double` em C (_15 casas decimais de precisão_), mas a representação varia consoante o sistema anfitrião.
Os números complexos têm uma parte `real` e uma parte `imaginary`, ambas representadas por números de vírgula flutuante.

Para uma discussão mais detalhada das questões e limitações da aritmética de vírgula flutuante entre linguagens de programação, dá uma vista de olhos em [0.30000000000000004.com][0.30000000000000004.com] e em [The Python Tutorial][floating point math].
