# Apêndice às instruções

## Implementação

Vais escrever uma implementação de uma lista duplamente ligada genérica.
Implementa um `Node` para guardar um valor e ponteiros para os nós seguinte e anterior.
Depois, implementa uma `List` que guarda referências ao primeiro e ao último nó e oferece funções para adicionar e remover itens.

Usar o genérico `comparable` permite que a lista guarde qualquer tipo de dados comparável.

O teu `Node` deve ter os seguintes campos e métodos:

- `Value`: o valor do nó.
- `Next() *Node`: ponteiro para o nó seguinte.
- `Prev() *Node`: ponteiro para o nó anterior.

Deves ter uma função `NewList()` que cria e devolve uma `List`:

- `NewList[T comparable](args ...any) *List[T]`: cria uma nova lista ligada preservando a ordem dos valores.

A tua `List[T]` deve ter os seguintes métodos:

- `First() *Node[T]`: devolve um ponteiro para o primeiro nó (cabeça).
- `Last() *Node[T]`: devolve um ponteiro para o último nó (cauda).
- `Push(v T)`: insere um valor no fim da lista.
- `Pop() (T, error)`: remove um valor do fim da lista.
- `Unshift(v T)`: insere um valor no início da lista.
- `Shift() (T, error)`: remove um valor do início da lista.
- `Reverse()`: inverte a lista ligada.
