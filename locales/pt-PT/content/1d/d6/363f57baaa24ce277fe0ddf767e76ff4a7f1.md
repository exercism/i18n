# Dicas

## 1. Lê endereços de email de um ficheiro

- Podes usar a [função `simplifile.read`][file-read] para ler o conteúdo de um ficheiro.

## 2. Cria um ficheiro de registo para escrita

- Podes usar a [função `simplifile.create_file`][file-create] para criar um ficheiro vazio.

## 3. Regista um email enviado

- Podes usar a [função `simplifile.append`][file-append] para acrescentar texto a um ficheiro.

## 5. Envia a newsletter

- Todas as operações necessárias sobre ficheiros já foram implementadas nos passos anteriores.
- Podes usar a [função `result.try`][result-try] e a [função `list.try_each`][list-try-each] para trabalhar com o tipo `Result`.
