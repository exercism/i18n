# Dicas

## Geral

- Lê sobre a composição de funções no [manual][function-composition-manual].
- Explora os [métodos disponíveis para _Strings_][string-methods].

## 1. Limpar o nome

- Existe um [método incorporado][string-replace] para substituir todas as ocorrências de uma substring numa string.
- Existe um [método incorporado][string-strip] para remover os espaços em branco no início e no fim de uma string.

## 2. Obter a primeira letra do nome

- Para obter um caráter específico de uma string, podes usar a [indexação][string-indexing].
- A forma mais limpa de escrever isto é usar o operador de composição `∘`.

## 3. Formatar a primeira letra como inicial

- Existe um [método incorporado][string-uppercase] para converter todos os carateres de uma string na sua variante maiúscula.

## 4. Colocar as iniciais dentro do coração

- Podes usar carateres Unicode em strings com: `'\u<id>'`, em que, no caso do emoji de coração, o id é `2764`.
- Isto pode ser feito com [concatenação][stting-concatenation] ou [interpolação][string-interpolation].
