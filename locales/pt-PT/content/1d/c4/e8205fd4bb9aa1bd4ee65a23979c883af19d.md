# Sobre

O mais importante a reter sobre as strings em Java é que são objetos imutáveis que representam texto como uma sequência de carateres Unicode (letras, algarismos, pontuação, etc.).
Usam-se aspas duplas para definir uma instância de `String`:

```java
String fruit = "Apple";
```

É possível manipular uma string com os métodos da classe [`String`][string-class].
Como os valores do tipo string nunca podem mudar depois de serem definidos, todos os métodos de manipulação de strings devolvem uma nova string.

Uma string é delimitada por carateres de aspas duplas (`"`).
Alguns carateres especiais precisam de ser escapados com o caráter barra invertida (`\`).
Carateres que é preciso escapar em Java:

- `"`
- `\`

```java
String escaped = "c:\\test.txt";
// => c:\test.txt
```

Por fim, há muitas formas de concatenar strings.
A mais simples é o operador `+`:

```java
String name = "Jane";
"Hello " + name + "!";
// => "Hello Jane!"
```

Para qualquer formatação de strings mais complexa do que uma simples concatenação, é preferível usar o método `String.format`.

```java
String name = "Jane";
String.format("Hello %s!",name);
// => "Hello Jane!"
```

Outras possibilidades são:

- usar a [classe `StringBuilder`][string-builder]
- usar o [método `String.concat`][string-concat]
