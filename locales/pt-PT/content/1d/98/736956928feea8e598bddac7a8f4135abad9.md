# Dicas

## 1. Obter as permissões predefinidas para um tipo de conta

- Define o enum `Permission` com valores para os seguintes tipos de permissão: `None`, `Read`, `Write` e `Delete`.
- Usar as flags do enum permitiria usar operações bit a bit sem mais nada para o enum `Permission`, [vê `enum` `Flags`][docs-enum-flags].
- O membro `All` do enum pode ser definido como uma combinação dos membros `Read`, `Write` e `Delete` do enum.
- Define o enum `AccountType` com valores para os seguintes tipos de conta: `Guest`, `User` e `Moderator`.
- Para tratar cada tipo de conta, podias usar uma condicional `if`, mas a [instrução `switch`][docs.microsoft.com-switch-keyword] é uma ótima alternativa.
- Combinar flags significa colocar um determinado bit a `1` com um dos [operadores bit a bit][docs.microsoft.com-bitwise-and-shift-operators].

## 2. Conceder uma permissão

- Combinar flags significa colocar um determinado bit a `1` com um dos [operadores bit a bit][docs.microsoft.com-bitwise-and-shift-operators].

## 3. Revogar uma permissão

- Remover uma flag significa colocar um determinado bit a `0` usando uma combinação de dois [operadores bit a bit][docs.microsoft.com-bitwise-and-shift-operators].

## 4. Verificar uma permissão

- Podes verificar uma permissão vendo o resultado de aplicar um dos [operadores bit a bit][docs.microsoft.com-bitwise-and-shift-operators].
