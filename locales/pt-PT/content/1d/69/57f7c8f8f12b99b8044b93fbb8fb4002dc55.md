# Sobre

A correspondência de padrões é o processo de ramificar consoante um valor corresponde a padrões dados, que podem ser profundos. Em Haxe, a **correspondência de padrões** faz-se com uma expressão `switch` e com expressões `case` individuais.

Considera esta estrutura de dados:

```haxe
enum Tree<T> {
  Leaf(v:T);
  Node(l:Tree<T>, r:Tree<T>);
}
```

- A correspondência dos padrões é sempre feita de cima para baixo.
- O padrão mais acima que corresponde ao valor de entrada tem a sua expressão executada.
- Um padrão `_` corresponde a qualquer coisa, por isso `case _:` é igual a `default:`

## Correspondência de enums

A correspondência de enums pode ser feita pelo seu próprio construtor, de forma natural:

```haxe
var myTree = Node(Leaf("foo"), Node(Leaf("bar"), Leaf("foobar")));

var match = switch (myTree) {
  // Matches any Leaf
  case Leaf(_):
    "0";

  // Matches any Node that has r = Leaf
  case Node(_, Leaf(_)):
    "1";

  // Matches any Node that has
  // r = another Node which has
  // l = Leaf("bar")
  case Node(_, Node(Leaf("bar", _))):
    "2";

  // Matches anything
  case _:
    "3";
}

trace(match); // 2
```
