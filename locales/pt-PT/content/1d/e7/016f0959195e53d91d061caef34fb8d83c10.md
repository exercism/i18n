# Instruções

O kata Diamante recebe uma letra como entrada e desenha-a em forma de diamante. Dada uma letra, imprime um diamante que começa com 'A', com a letra fornecida no ponto mais largo.

## Requisitos

* A primeira linha contém um 'A'.
* A última linha contém um 'A'.
* Todas as linhas, exceto a primeira e a última, têm exatamente duas letras iguais.
* Todas as linhas têm tantos espaços à direita como à esquerda. (Podem ser 0).
* O diamante é horizontalmente simétrico.
* O diamante é verticalmente simétrico.
* O diamante tem forma quadrada (a largura é igual à altura).
* As letras formam um diamante.
* A metade superior tem as letras por ordem crescente.
* A metade inferior tem as letras por ordem decrescente.
* Os quatro cantos (que contêm os espaços) são triângulos.

## Exemplos

Nos exemplos seguintes, os espaços são indicados pelo caráter `·`.

Diamante para a letra 'A':

```text
A
```

Diamante para a letra 'C':

```text
··A··
·B·B·
C···C
·B·B·
··A··
```

Diamante para a letra 'E':

```text
····A····
···B·B···
··C···C··
·D·····D·
E·······E
·D·····D·
··C···C··
···B·B···
····A····
```
