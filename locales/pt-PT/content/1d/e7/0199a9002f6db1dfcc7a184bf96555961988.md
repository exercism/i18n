# Sobre

## Condicionais

As condicionais são instruções de decisão que podem executar efeitos secundários ou controlar o fluxo de execução de um programa.
As condicionais incluem as instruções `if`, `if/else`, `switch` e `ternary`.

As condicionais servem para fazer perguntas sobre um valor ou sobre uma relação entre valores.
A pergunta dá como resultado uma resposta Boolean, mas a própria instrução `if` pode devolver qualquer valor ou pode simplesmente executar um efeito secundário.

## Instruções if

A instrução `if` mais simples avalia uma expressão e executa uma linha.
A expressão a testar é sempre colocada entre parênteses.

Pode executar um efeito secundário

```c
if (count > 10)
    printf("count is greater than 10");
```

ou pode alterar o fluxo de execução


```c
if (count > 10)
    return sum;
```

Se uma instrução `if` executa mais do que uma linha, tem de colocar as linhas entre chavetas

```c
if (count > 10) {
    printf("count is greater than 10");
    return sum;
}
```

Algumas equipas de programação podem definir como norma que as instruções `if` usem sempre chavetas, mesmo para uma única linha.


## If / Else

Uma instrução `if` pode ser associada a um `else`

```c
if (number % 2 == 0)
    return "even";
else
    return "odd";
```

## If / Else If


O `else` pode ser associado a outro `if` para criar aquilo a que se chama uma `if-else-if ladder`.

```c
if (number == 0)
    return "zero";
else if (number < 0)
    return "negative";
else if (number < 10)
    return "single digit";   
else if (number % 2 == 0)
    return "even";
else
    return "odd";
```

## Switch


Por vezes, uma `if-else-if ladder` pode ser melhor representada por um `switch`.
Tal como no `if`, a expressão a testar é sempre colocada entre parênteses.

```c
switch (number) {
    case -1:
        return "negative one";
    case 0:
        return "zero";
    case 1:
        return "positive one";
    case 10:
        return "positive ten";
    case -10:
        return "negative ten";
    default:
        return "don't care";
}
```

O caso `default` é executado se o valor a testar não corresponder a nenhum dos casos anteriores.

Se um caso do `switch` não devolve um valor, normalmente insere-se um `break` para terminar cada caso; caso contrário, a lógica "cai" no caso seguinte.
Por vezes, a passagem para o caso seguinte é intencional

```c
switch (number) {
    case 0:
        msg = "zero"; break;
    case 1:
        msg = "one"; break;
    case 2: case 3: case 4:
        msg = "more than one and less than five"; break;
    default:
        msg = "don't care";
}
```

Quando a passagem para o caso seguinte acontece sem intenção, é um bug.

```c
switch (number) {
    case 0:
        msg = "zero"; // bug! fallthrough of 0 will set msg to "one"
    case 1:
        msg = "one"; break; 
    case 2: case 3: case 4:
        msg = "more than one and less than five"; break;
    default:
        msg = "don't care";
}
```

Um switch pode ser vantajoso quando se testam valores específicos em vez de um intervalo de valores.
Pode ser mais rápido do que uma `if-else-if ladder` porque o compilador pode conseguir otimizar a instrução `switch` de formas que não consegue com uma escada.
Um switch pode, por vezes, parecer mais legível do que uma escada.

## Operador Ternário (também conhecido como Condicional)

O operador ternário é uma condicional com três partes, frequentemente utilizada para atribuir um valor.
A expressão a testar fica antes do ponto de interrogação e não precisa de estar entre parênteses.
O valor devolvido se a condição for verdadeira fica antes dos dois pontos e o valor devolvido se for falsa fica depois dos dois pontos.
Pode devolver-se um literal ou uma variável.

```c
int i = j > 5 ? 5: j;
```

Os operadores ternários podem ser aninhados para reduzir o ruído sintático.

```c
// the below could also be 
i = j > 5 ? j :k > 5 ? k: 10;
// but that may not be quite as readable

i = j > 5 ? j
    :k > 5 ? k
    :10;

// which is the same as
if (j > 5) i = j;
else if (k > 5) i = k;
else i = 10;
```

## Comparações condicionais de valores de vírgula flutuante

Devido à forma como os números de vírgula flutuante são implementados, uma simples operação matemática pode originar um erro de arredondamento, o que pode fazer com que um teste de igualdade não devolva o resultado esperado.

```c
    a = 1.345f;
    b = 1.123f;
    c = a + b;
    // c may equal something like 2.4679999352
    if (c == 2.468)
        return "I won the lottery!";
```

Pode utilizar-se um valor de tolerância, designado por `epsilon`, para determinar um intervalo dentro do qual um valor pode estar para ainda ser considerado igual quando comparado com outro valor.
Algumas plataformas têm constantes incorporadas para os épsilons de float e double.
Consulta a documentação do teu compilador para saber mais.
Calcular o épsilon pode ser complexo e pode variar entre plataformas, até entre máquinas individuais.
Eis um programa de exemplo que usa uma comparação simples.

```c
#include <stdio.h>
#include <math.h>
#include <stdbool.h>

const double MY_EPSILON = .002;

bool same(double x, double y)
{
    return fabs(x - y) < MY_EPSILON;
}

int main()
{
    // Same should return true if the difference is less than MY_EPSILON
    printf("%s\n", same(1.1, 1.099) ? "true" : "false"); // prints true
    printf("%s\n", same(1.1, 1.098) ? "true" : "false"); // prints false
    return 0;
}
```

Tem cuidado ao comparar `float`s ou `double`s para verificar a igualdade!
