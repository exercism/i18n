# Anexo às instruções

## Formato da saída

Devolve a letra como uma string terminada em null.

## Registos

| Registo | Utilização    | Tipo     | Descrição                          |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | entrada        | inteiro | garrafas iniciais                 |
| `$a1`    | entrada        | inteiro | número a retirar                     |
| `$a2`    | entrada/saída | endereço | string de saída terminada em null |
| `$t0-9`  | temporário    | qualquer     | para armazenamento temporário         |
