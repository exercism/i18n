# Anexo às instruções

## Saída

Neste exercício, vais implementar um verbo que gera o Triângulo de Pascal até um dado número de linhas. A saída do teu verbo pode ser formatada de duas formas:

  1. Como um array de listas encaixotadas, em que cada lista representa uma linha do Triângulo de Pascal.
  1. Como uma tabela, em que os números estão alinhados à direita e usam-se zeros para preencher os espaços vazios à esquerda.

### Exemplo de saída

Aqui estão duas saídas válidas para `pascal 3`:

  - Como um array de listas encaixotadas:
```j
  (1 ; 1 1 ; 1 2 1) -: pascal 3          NB. This test will pass
```
  - Como uma tabela com preenchimento:
```j
  (3 3$1 0 0 1 1 0 1 2 1) -: pascal 3   NB. This test also passes
```
