# Instalar o Emacs

Como o Emacs Lisp (elisp) é a linguagem de extensão do Emacs, vais precisar de instalar primeiro o [GNU Emacs](http://www.gnu.org/software/emacs/).

Recomendamos que uses a versão mais recente do Emacs, mas deves considerar a 28.1 ou superior como a versão de referência para os exercícios.
Se já tens o Emacs instalado, podes verificar a versão do Emacs com `M-x emacs-version RET`.

## No OS X
A forma mais fácil é visitares o site [Emacs For Mac OS X](http://emacsformacosx.com/) e descarregares o dmg, que instala o GNU Emacs como uma aplicação empacotada para OS X.

Existem alternativas, como o Aquamacs (não recomendado) ou a instalação através do [Homebrew](https://formulae.brew.sh/formula/emacs), se preferires.

## No Linux
Em algumas distribuições, o Emacs já vem instalado, uma vez que faz parte do GNU.

### Ubuntu
A forma atualmente recomendada de instalar a versão mais recente do Emacs é através do [snap](https://snapcraft.io/emacs):

```
sudo snap install emacs --classic
```

Se não quiseres usar o snap, também podes instalar o Emacs via snap, mas a versão disponível nos repositórios do Ubuntu está muitas vezes desatualizada.
Se quiseres instalar uma versão mais recente do Emacs via apt, vais precisar de usar um [PPA](https://launchpad.net/ubuntu/+ppas?name_filter=emacs) ou [compilar a partir do código-fonte](https://www.emacswiki.org/emacs/BuildingEmacs).

Se não precisares da versão mais recente, deve bastar:

```
sudo apt-get install emacs
```

### Arch
O Arch costuma trazer a versão mais recente do Emacs, por isso executa:

```
sudo pacman -S emacs
```

e estará tudo pronto.

### Outras distribuições
Verifica junto da tua distribuição qual é a versão atual e usa o teu gestor de pacotes ou compila a partir do código-fonte, conforme for mais adequado.

### Windows
Para instalar o Emacs no Windows, vai ao [espelho do arquivo FTP](https://ftpmirror.gnu.org/emacs/windows) mais próximo, obtém o instalador (=emacs-XX.X-installer.exe=) e executa-o.
Se quiseres usar o Emacs sem o instalar, podes obter o ficheiro com o padrão =emacs-XX.x.zip=, descomprimi-lo e executar `bin\runemacs.exe`.

Se usares o [MSYS2](https://www.msys2.org/), podes instalar a versão de 64 bits do Emacs com

```
pacman -S mingw-w64-x86_64-emacs
```

ou a versão de 32 bits com

```
pacman -S mingw-w64-i686-emacs
```
