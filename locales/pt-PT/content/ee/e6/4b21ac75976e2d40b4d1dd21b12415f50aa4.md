# Dicas

## Geral

- Os ciclos [`while`][while-loops] servem para iterações _indefinidas_ (não contadas).
- Os ciclos [`for`][for-loops] servem para iterações _definidas_ (contadas).
- As palavras-chave [`break` e `continue`][control flow] ajudam a personalizar o comportamento do ciclo.
- [`range(<start>, <stop>, <step>)`][range] pode ser usado para gerar uma sequência para um contador de ciclo.
- A função incorporada [`enumerate()`][enumerate] devolve pares (`<value>`, `<index>`) para iterar.

Familiarizar-te com o seguinte também pode ajudar a completar as tarefas:

- [`lists`][list]: indexação, listas aninhadas, [`<list>.append()`][append and pop], [`<list>.pop()`][append and pop].
- [`str`][str]: o construtor `str()`, usar o `+` para concatenar strings e, opcionalmente, [`f-strings`][f-strings].

## 1. Arredondar as pontuações

- Os ciclos `While` continuam a executar até a condição de teste ser avaliada como `False`.
- `<list>.pop()` remove e devolve o último item de uma `list`.
- As listas vazias resultam em `False` (a maioria dos objetos vazios em Python é "Falsy")

## 2. Alunos que não passam

- Não precisas de declarar contadores de `loop` nem de `index` quando percorres um objeto com um ciclo `for`.
- Já um contador de resultados precisa de ser criado e _incrementado_: vais querer fazer `return` do número de alunos que não passam quando o ciclo terminar.

## 3. As "melhores"

- Não precisas de declarar contadores de `loop` nem de `index` quando percorres um objeto com um ciclo `for`.
- Ter uma `list` vazia à qual adicionar as "melhores" notas é útil aqui.
- `<list>.append()` pode ajudar a adicionar coisas à `list` de resultados.

## 4. Calcular as classificações em letras

- Estes são os _limites inferiores_. O _limite inferior_ de um "D" é uma pontuação de **41**, uma vez que um "F" é **<= 40**.
- [`range()`][range] pode ser útil aqui para gerar uma sequência com os incrementos corretos de "F" -> "A".
- [`round()`][round] sem parâmetros deve arredondar os incrementos de forma adequada.
- Tal como na tarefa das "melhores", `<list>.append()` pode ser útil aqui para acrescentar itens de `range()` a uma `list` de resultados.

## 5. Associar nomes a pontuações

- [`enumerate()`][enumerate] pode ser útil aqui.
- Se ambas as listas tiverem o mesmo comprimento e estiverem ordenadas da mesma forma, podes usar o `index` de uma para obter um `value` da outra?

## 6. Uma pontuação "perfeita"

- Pode haver ou não um aluno com uma pontuação de 100 e não podes devolver `[]` sem verificar **todas** as pontuações.
- As instruções de [`control flow`][control flow] `continue` e `break` podem ser úteis aqui para passar à frente de valores indesejados.
