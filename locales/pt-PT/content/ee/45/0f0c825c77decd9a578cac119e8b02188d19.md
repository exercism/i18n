# Introduction

No Conceito [`Vectors`][vectors], dissemos que «os arrays estão no cerne da linguagem Julia» e que um vetor é um array unidimensional.

Dado isto, podíamos razoavelmente esperar que a linguagem oferecesse muitas formas versáteis e poderosas de fazer coisas com vetores, seja lá o que isso signifique.

## Funções que esperam um parâmetro de entrada do tipo vetor

Algumas funções muito simples recebem um parâmetro de entrada do tipo vetor e devolvem um valor escalar.

```julia
v = [2, 3, 4]
length(v)  # => 3
sum(v)  # => 9
```

## Aritmética

Imagina que tens um vetor numérico e queres subtrair 0,5 a cada valor.

```julia-repl
julia> v = [1.2, 1.5, 1.7]
3-element Vector{Float64}:
 1.2
 1.5
 1.7

julia> v - 0.5
ERROR: MethodError: no method matching -(::Vector{Float64}, ::Float64)
```

Isso falha, então e se subtraíres outro vetor?

```julia-repl
julia> v - [0.5, 0.5, 0.5]
3-element Vector{Float64}:
 0.7
 1.0
 1.2
```

Funciona, mas é bastante tedioso e consome muita memória à medida que os vetores ficam maiores.

Felizmente, a Julia tem um ponto «mágico» para resolver este problema de forma muito simples: só precisas de `v .- 0.5`.

A próxima secção explica porquê.

## Broadcasting

Então, `v - 0.5` falha, mas `v .- 0.5` funciona, e precisamos de perceber o que o ponto está a fazer.

Duas coisas, que se combinam para dar o resultado desejado.

### 1. Aplicação elemento a elemento

Primeiro, acrescentar um ponto _antes_ de qualquer operador infixo significa «aplicar esta operação a cada elemento separadamente».

Da mesma forma, acrescentar um ponto _depois_ do nome de uma função «vetoriza-a», mesmo que a função tenha sido escrita para valores de entrada escalares.

```julia-repl
julia> sqrt.([1, 4, 9])
3-element Vector{Float64}:
 1.0
 2.0
 3.0
```

### 2. Expansão de singletons

Vimos num exemplo anterior que podemos subtrair vetores de igual comprimento, mas repara que `.-` é um operador _mais seguro_ do que `-`, porque torna clara a intenção elemento a elemento.

```julia-repl
julia> v .- [0.5, 0.5, 0.5]
3-element Vector{Float64}:
 0.7
 1.0
 1.2
```

E quanto a vetores de comprimentos diferentes?

```julia-repl
julia> v .- [0.5, 0.5]
ERROR: DimensionMismatch: arrays could not be broadcast to a common size

julia> v .- [0.5,]
3-element Vector{Float64}:
 0.7
 1.0
 1.2
```

Em geral, comprimentos diferentes são um erro, _exceto_ quando um deles tem comprimento 1 (tecnicamente, uma dimensão «singleton»).

Os singletons como `[0.5,]` ou apenas `0.5` são automaticamente expandidos para o comprimento necessário por repetição.
É isto que está no cerne do `broadcasting`.

### Broadcasting no local

Se o uso de memória for uma preocupação, as operações no local são uma forma comum de tentar reduzir as alocações.

No entanto, as operações de broadcasting nos exemplos acima criam um novo `Vector` em vez de modificarem o original.

Para modificar o `Vector` original no local, a modificação tem de ser feita com broadcasting.

```julia-repl
julia> v .= v .+ 1
3-element Vector{Int64}:
 2
 3
 4

julia> v .+= 1  # equivalent operation to above
3-element Vector{Int64}:
 3
 4
 5

julia> v
3-element Vector{Int64}:
 3
 4
 5
```

## Indexação

A seleção de elementos de um vetor pelo número do índice já foi abordada em Conceitos anteriores.

```julia
a = collect('A':'Z')  # => 26-element Vector{Char}

# index with an integer
a[2]  # => 'B'

# index with a range
 a[12:2:18]  # => ['L', 'N', 'P, 'R']
 
 # index with another vector
 a[ [1, 3, 5] ]  # => ['A', 'C', 'E']
```

### Indexação lógica

Também é possível selecionar elementos que satisfazem uma determinada expressão lógica (tecnicamente, um «predicado»).
Isto normalmente requer broadcasting.

```julia-repl
julia> a[a .< 'D']
3-element Vector{Char}:
 'A': ASCII/Unicode U+0041 (category Lu: Letter, uppercase)
 'B': ASCII/Unicode U+0042 (category Lu: Letter, uppercase)
 'C': ASCII/Unicode U+0043 (category Lu: Letter, uppercase)
```

Para expressões mais complexas, os pontos tendem a multiplicar-se (mas são pequenos e fáceis de escrever).

```julia-repl
julia> a[a .< 'D' .|| a .> 'W']
6-element Vector{Char}:
 'A': ASCII/Unicode U+0041 (category Lu: Letter, uppercase)
 'B': ASCII/Unicode U+0042 (category Lu: Letter, uppercase)
 'C': ASCII/Unicode U+0043 (category Lu: Letter, uppercase)
 'X': ASCII/Unicode U+0058 (category Lu: Letter, uppercase)
 'Y': ASCII/Unicode U+0059 (category Lu: Letter, uppercase)
 'Z': ASCII/Unicode U+005A (category Lu: Letter, uppercase)
```

Um lembrete: o «vetor» pode, na verdade, ser qualquer iterável ordenado apropriado, como um intervalo:

```julia-repl
julia> n = 3:10
3:10

julia> n[isodd.(n)]
4-element Vector{Int64}:
 3
 5
 7
 9
```
