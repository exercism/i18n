# Dicas

## Geral

Quando lidas com árvores, a [recursão][recursion] costuma ser a tua amiga.

- O essencial aqui é encontrar uma forma de dividir o problema em problemas mais pequenos com a mesma estrutura.
- Há uma pista nas instruções que indica onde podes fazer isso.
- Os dois percursos são necessários para resolver o problema.
- Qual é a relação entre os dois percursos? A posição da `root` pode dar-te uma pista.
- Qual é o caso base? O primeiro teste aponta para uma boa resposta.

[recursion]: https://en.wikipedia.org/wiki/Recursion
