# Dicas

## Geral

- Para criares os métodos getter e setter, usa as macros `getter`, `setter` e `property`.

## 1. Criar um estado inicial para a balança

- Para inicializares a balança, usa o método `initialize`.
- O método deve receber dois argumentos, `precision` e `metric`, que devem ser um `Int32` e um `Bool`, respetivamente. Estes devem ser usados para definir as variáveis de instância `@precision` e `@metric`.
- A variável de instância `@weight` deve ser definida como `0.0`.

## 2. Permitir que a balança tenha uma precisão

- A macro `getter` permite-te definir um método que devolve o valor de uma variável de instância.

## 3. Permitir definir o peso na balança

- A macro `property` permite-te definir um método que obtém e define o valor de uma variável de instância.

## 4. Permitir que a máquina alterne entre unidades métricas e imperiais

- A macro `setter` permite-te definir um método que define o valor de uma variável de instância.
