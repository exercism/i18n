# Instalação

Este percurso baseia-se no [Node.js][web-nodejs] para disponibilizar um ambiente de execução para JavaScript.
Isto significa que assumimos que toda a execução de JavaScript no teu computador vai acontecer através do [Node.js][web-nodejs].

## Requisitos do percurso

Muitas máquinas vêm já com o [Node.js][web-nodejs] pré-instalado, ou ele pode ter sido instalado anteriormente, ou como dependência.
Por isso, antes de fazermos seja o que for, convém verificar se já está instalado:

1. Abre um _terminal_ (`Terminal`, `cmd`, `Powershell`, `bash`, ...)
1. `node -v`

Se o [Node.js][web-nodejs] estiver instalado, é mostrada uma versão.
Anota essa versão.
Se o [Node.js][web-nodejs] _não_ estiver instalado, é apresentado um erro.
Normalmente, algo do género de `'node' is not recognised`.

## Node.js

### Se o Node.js já estiver pré-instalado

Vai ao [site do Node.js][web-nodejs].
Vão ser apresentadas _duas_ versões (se o site detetar o teu sistema operativo; caso contrário, seleciona primeiro o teu sistema operativo).
Se a versão que obtiveste com o `node -v` corresponder a uma delas, está tudo bem.
Se não corresponder, recomendamos que uses o Node.js LTS.
Se receias que a atualização possa estragar algo no teu sistema, podes continuar como se estivesse tudo bem;
podemos não conseguir dar apoio se acontecer algo inesperado.

### Se o Node.js não estiver instalado

Há algumas formas de instalar o [Node.js][web-nodejs]:

- através de um [instalador ou binário][web-nodejs-download]
- através de um [gestor de pacotes][web-nodejs-package]

Ambas as opções funcionam em Windows, macOS e Linux. Se não sabes o que fazer, usar um instalador é o mais fácil.

- Recomendamos que uses a versão **LTS**. É também indicada como _recomendada_ no site do [Node.js][web-nodejs] "para a maioria dos utilizadores".
- Segue as instruções na página web e/ou durante a instalação e instala o [Node.js][web-nodejs].

## Testar a instalação

Depois de o instalador terminar, de o gestor de pacotes concluir, ou de o binário ter sido copiado e as instruções terem sido seguidas, é boa ideia testar se está tudo bem.

1. Abre um _terminal_ (`Terminal`, `cmd`, `Powershell`, `bash`, ...)
1. `node -v`

A versão deve corresponder à que aparece no site.

> [!NOTE]
> É importante abrir uma janela de terminal _nova_.
> As janelas de terminal já abertas podem não ter sido atualizadas depois de a instalação terminar.
> Isto significa que esses terminais não sabem que foi instalado um novo programa.

> [!IMPORTANT] > _**Ajuda**_: `'node' is not recognised`
>
> Se usaste o instalador oficial, o teu `PATH` já devia ter sido configurado automaticamente, mas se a tua shell tiver dificuldade em localizar os módulos instalados globalmente, ou se compilares o Node.js a partir do código-fonte, atualiza o teu `PATH` para incluir os binários do `npm`.
>
> No macOS e no Linux podes fazê-lo adicionando o seguinte a `~/.bash_profile` ou a `~/.zshrc`:
>
> ```shell
> export PATH=/usr/local/share/npm/bin:$PATH
> ```
>
> No Windows, abre o menu Iniciar e procura por "environment variables".
> Vais ter de editar a entrada `PATH` e _adicionar_ aqui o caminho para os binários do `npm`.
> Normalmente, encontram-se em `C:\Program Files\nodejs`.
> Se navegares até aqui com o `File Explorer`, deves encontrar `node.exe`, `npm.bat` e `npx.bat`.
>
> Fecha todos os terminais abertos e abre um novo.

## Ativar o corepack

Para usar um gestor de pacotes versionado e compatível com este percurso, é preciso ativar o `corepack` uma vez:

```shell
corepack enable pnpm
```

## Requisitos dos exercícios

Segue [estas instruções][cli-walkthrough] para descarregar a CLI do Exercism para o teu sistema operativo.

Depois de a CLI estar instalada e configurada, descarrega o primeiro exercício, o `hello-world`:

```shell
exercism download --exercise=hello-world --track=javascript
```

Cada exercício precisa depois de algumas ferramentas para correr os testes.
Podes instalá-las executando este comando dentro do diretório de cada exercício:

```shell
corepack pnpm install
```

Como este percurso passou a usar o pnpm, não precisas de te preocupar com o espaço em disco.
Dá uma vista de olhos ao [pnpm](https://pnpm.io/), que garante que só é instalada uma cópia de cada versão de pacote no disco.

> **Mas o que é o corepack e porque é que isto funciona?**
>
> Não precisas desta informação para concluir o percurso de JavaScript, mas se estás curioso por perceber o que acabou de acontecer, os parágrafos seguintes são para ti:
>
> Isto funciona porque o `corepack` é uma ferramenta que vem incluída no Node.js, que foi instalado segundo os passos acima.
> Pode instalar o gestor de pacotes `pnpm`. Configura o sistema
> O comando `corepack` procura um ficheiro `package.json`, que existe em _cada_ pasta de exercício.
> Depois verifica o `packageManager`, que corresponde a `pnpm`, por isso pode continuar. Se for preciso, atualiza primeiro o `pnpm`.
> Este ficheiro também lista as `"dependencies"` acima, que são depois descarregadas pelo `pnpm` e colocadas numa cache local.
>
> Os scripts no `package.json` usam os binários da cache local, e são esses scripts que servem para correr os testes, como indicado na descrição do `exercise`.
