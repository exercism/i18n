# Dicas

## 1. Adicionar uma linguagem ao array @Languages

- Queres modificar o array `@Languages` para adicionar uma nova linguagem ao fim.

## 2. Remover uma linguagem do array @Languages

- Queres modificar o array `@Languages` para remover a última linguagem.

## 3. Obter a primeira linguagem do array @Languages

- Queres devolver o primeiro elemento do array `@Languages` com `return`.

## 4. Obter a última linguagem do array @Languages

- Queres devolver o último elemento do array `@Languages` com `return`.

## 5. Obter uma fatia de linguagens do array @Languages

- Queres uma fatia do array `@Languages`.
- Lembra-te de que os índices começam em 0. O elemento `1` é o índice `0`.

## 6. Verificar se uma linguagem existe no array @Languages

- Queres devolver um valor verdadeiro, por exemplo, `1`, ou falso, por exemplo, `0`, se a linguagem indicada existir no array `@Languages`.
