# Aprendizagem

Se estás a começar com SQLite e queres aprender o básico da sintaxe SQL e da gestão de bases de dados, aqui tens alguns recursos excelentes pensados para quem está a dar os primeiros passos:

- **Introdução ao SQL no YouTube**: Vê o [What is SQL?][sql-youtube], um vídeo de 4 minutos para principiantes da autoria de Danielle Thé.

- **SQLite Tutorials**: Os [SQLite Tutorials][sqlite-tutorial] oferecem uma introdução acessível a quem está a começar com SQLite, abordando conceitos fundamentais como a criação de bases de dados, a realização de consultas e a manipulação de dados.

- **SQLZoo**: Pratica as tuas competências de SQL com exercícios e tutoriais interativos no [SQLZoo][sqlzoo], incluindo conteúdo específico de SQLite adequado a principiantes.

Estes recursos dão-te uma base para aprender SQLite e a sintaxe SQL, ajudando quem está a começar a compreender os conceitos das bases de dados e a ganhar experiência prática com bases de dados SQLite.

[sqlite-tutorial]: https://www.sqlitetutorial.net/
[sql-youtube]: https://www.youtube.com/watch?v=27axs9dO7AE
[sqlzoo]: https://sqlzoo.net/
