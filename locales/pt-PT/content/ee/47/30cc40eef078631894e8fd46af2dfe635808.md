# Dicas

## 1. Gera um número de registo de nave estelar aleatório

- Para gerar um número aleatório no intervalo de _min_ (inclusive) a _max_ (exclusive), podes usar o fragmento `min + Math.random()*(max - min)`.
- Existe uma [função integrada][floor] para converter um número de vírgula flutuante num número inteiro.

## 2.Gera uma data estelar aleatória

- Para gerar um número aleatório no intervalo de _min_ (inclusive) a _max_ (exclusive), podes usar o fragmento `min + Math.random()*(max - min)`.
