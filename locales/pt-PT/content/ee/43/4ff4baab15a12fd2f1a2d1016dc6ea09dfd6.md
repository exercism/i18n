# Dicas

## 1. Obter uma carta de uma pilha

- Os índices de `vector` começam em `1`.
- Podes obter o `n`-ésimo valor de um `vector` `v` com `v[n]`.

## 2. Trocar uma carta na pilha

- Os `vector` são mutáveis: podes alterar o seu conteúdo a qualquer momento, atribuindo um novo valor.

## 3. Inserir uma carta no topo da pilha

- Podes `c`oncatenar para adicionar um novo valor ao fim de um `vector`.

## 4. Remover uma carta da pilha

- Consulta a introdução para saberes como eliminar um elemento de um `vector` num determinado índice.

## 5. Verificar o tamanho da pilha

- Existe uma função `length` na Base para obter o comprimento de uma coleção.

## 6. Remover a carta do topo da pilha

- Tens de remover novamente um elemento, mas desta vez no fim de um `vector`.
- A função `length` pode ser útil aqui.

## 7. Inserir uma carta na base da pilha

- Podes `c`oncatenar para adicionar um novo valor ao início de um `vector`.

## 8. Remover uma carta da base da pilha

- Tens de remover um elemento, mas desta vez no início de um `vector`.
