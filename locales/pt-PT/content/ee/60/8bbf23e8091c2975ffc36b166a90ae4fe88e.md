# Introdução

O Elixir usa _Behaviours_ no código para proporcionar interfaces genéricas comuns e, ao mesmo tempo, facilitar implementações específicas para cada módulo que as implementa. Um desses exemplos comuns é o _Access Behaviour_.

O _Access Behaviour_ fornece uma interface comum para obter dados de uma estrutura de dados baseada em chaves. O _Access Behaviour_ está implementado para mapas e listas de palavras-chave, mas vamos ver a sua utilização com mapas para teres uma ideia de como funciona. O _Access Behaviour_ especifica que, quando tens um mapa, podes acrescentar-lhe _parênteses retos_ e depois usar a chave para obter o valor associado a essa chave.

```elixir
# Suppose we have these two maps defined (note the difference in the key type)
my_map = %{key: "my value"}
your_map = %{"key" => "your value"}

# Obtain the value using the Access Behaviour
my_map[:key] == "my value"
your_map[:key] == nil
your_map["key"] == "your value"
```

Se a chave não existir na estrutura de dados, é devolvido `nil`. Isto pode ser uma fonte de comportamento indesejado, porque não lança um erro. Repara que o próprio `nil` implementa o Access Behaviour e devolve sempre `nil` para qualquer chave.
