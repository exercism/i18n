# Aprender

* O [The Rust Programming Language](https://doc.rust-lang.org/book/) é um excelente recurso para começar a programar em Rust e para te aprofundares em funcionalidades específicas da linguagem.
* O [Rust by Example](https://doc.rust-lang.org/stable/rust-by-example/) mostra-te exemplos das coisas mais comuns que vais escrever em Rust.
* O [Into_rust()](http://intorust.com/) "Vídeos para aprender Rust."
* O [Rustlings](https://github.com/carols10cents/rustlings) "Pequenos exercícios para te habituares a ler e escrever código Rust."
* O [Rust User Forum](http://users.rust-lang.org) responde a perguntas de todos os níveis
