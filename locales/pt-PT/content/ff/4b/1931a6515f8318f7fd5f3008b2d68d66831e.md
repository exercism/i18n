# Instruções

Como entusiasta de xadrez, gostarias de escrever a tua própria versão do jogo.
Sim, já deve haver por aí imensas implementações de xadrez disponíveis online, mas a tua vai ser única!

Começas por implementar um sistema básico de movimento das peças.

O jogo de xadrez vai ser jogado num tabuleiro com 8 casas de largura e 8 casas de comprimento.
As casas são identificadas por uma letra e um número.

## 1. Define o intervalo de filas e colunas

O jogo vai ter de guardar as filas do tabuleiro.
As filas são as linhas do tabuleiro e são numeradas de 1 a 8.

O jogo também vai ter de guardar as colunas do tabuleiro.
As colunas são as linhas verticais do tabuleiro e são identificadas pelas letras de A a H.

Define as constantes `Chess::RANKS` e `Chess::FILES`, que guardam, respetivamente, o intervalo das filas e das colunas.

```ruby
Chess::RANKS
# => 1..8

Chess::FILES
# => 'A'..'H'
```

## 2. Verifica se uma casa é válida

O jogo vai ter de verificar se uma casa é válida.
Uma casa é válida se a fila e a coluna estiverem dentro dos intervalos das filas e das colunas.

Define o método `Chess.valid_square?`, que recebe os argumentos `rank`, que contém um número inteiro correspondente à fila, e `file`, que contém um caráter correspondente à coluna.
O método deve devolver `true` se a fila e a coluna estiverem dentro dos intervalos das filas e das colunas e devolver `false` caso contrário.

```ruby
Chess.valid_square?(1, 'A')
# => true
```

## 3. Obtém a alcunha do jogador

O jogo vai ter de obter a alcunha do jogador.
A alcunha é formada pelos 2 primeiros carateres do primeiro nome do jogador e pelos 2 últimos carateres do apelido do jogador.
A alcunha deve ser escrita em maiúsculas.

Define o método `Chess.nickname`, que recebe os argumentos `first_name`, que contém uma string com o primeiro nome do jogador, e `last_name`, que contém uma string com o apelido do jogador.
O método deve devolver a alcunha do jogador como uma string em maiúsculas.

```ruby
Chess.nickname("John", "Doe")
# => "JOOE"
```

## 4. Cria a mensagem de uma jogada

O jogo vai ter de criar uma mensagem para uma jogada, indicando que jogador se moveu para que casa.
A mensagem deve usar a alcunha do jogador e a casa para onde ele se moveu.
O jogo também tem de determinar se a jogada é válida, verificando se a coluna e a fila da casa estão dentro dos intervalos das colunas e das filas.

Se a jogada for válida, a mensagem deve ser: `"{nickname} moved to {square}"`
Se a jogada for inválida, a mensagem deve ser: `"{nickname} attempted to move to {square}, but that is not a valid square"`

Define o método `Chess.move_message`, que recebe os argumentos `first_name`, que contém uma string com o primeiro nome do jogador, `last_name`, que contém uma string com o apelido do jogador, e `square`, que contém uma string com a casa para onde o jogador se moveu.
O método deve devolver a mensagem da jogada como uma string.

```ruby
Chess.move_message("John", "Doe", "A1")
# => "JOOE moved to A1"
```
