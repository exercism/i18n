# Introdução

## Nil

[Nil][nil-dictionary] é uma palavra inglesa que significa "nada" ou "zero". Em Elixir, `nil` é um valor especial que representa uma _ausência_ de valor.

```elixir
# I do not have a favorite color
favorite_color = nil
```

Noutras linguagens de programação, valores como `null` ou `none` podem ter um papel semelhante.

## If

Além de `cond`, Elixir também disponibiliza a macro [`if/2`][getting-started-if], que é útil quando só precisas de verificar uma condição.

[`if/2`][kernel-if] aceita uma condição e duas opções. Devolve a primeira opção se a condição for _truthy_ e a segunda se a condição for _falsy_.

```elixir
age = 15

if age >= 16 do
  "You are allowed to drink beer in Germany."
else
  "No beer for you!"
end

# => "No beer for you!"
```

Também é possível escrever uma expressão `if` numa única linha. Repara na vírgula a seguir à condição.

```elixir
if age > 16, do: "beer", else: "no beer"
```

Esta sintaxe é útil para expressões muito curtas, mas deve ser evitada se a expressão não couber numa única linha.

### _Truthy_ e _falsy_

Em Elixir, todos os tipos de dados são avaliados como um valor _truthy_ ou _falsy_ quando aparecem num contexto Boolean (como uma expressão `if`). Todos os dados são considerados _truthy_ **exceto** `false` e `nil`. Em particular, strings vazias, o número inteiro `0` e listas vazias são todos considerados _truthy_ em Elixir.
