# Dicas

## 1. Cria um novo quadro de pontuações máximas

- Podes usar as funções [`dict.new`][new] e [`dict.from_list`][from_list] para criar um novo dicionário.

## 2. Adiciona jogadores a um quadro de pontuações

- Podes usar a função [`dict.insert`][insert] para adicionar um novo par chave-valor a um dicionário.

## 3. Remove jogadores de um quadro de pontuações

- Podes usar a função [`dict.delete`][delete] para remover um par chave-valor de um dicionário.

## 4. Aumenta a pontuação de um jogador

- Podes usar a função [`dict.get`][get] para obter o valor correspondente a uma chave num dicionário.
- Podes usar a função [`dict.insert`][insert] para substituir um par chave-valor existente num dicionário.

## 5. Aplica os pontos de bónus de segunda-feira

- Podes usar a função [`dict.map_values`][map_values] para modificar todos os valores de um dicionário.
