# Sobre

Um `Map` serve para guardar pares de **chave** e **valor**. Os `Map` inicializam-se tal como um array, mas usam o operador de literal de map `=>`. Também é possível definir explicitamente os tipos da chave e do valor, ou deixar que os tipos sejam inferidos. As chaves têm de ser únicas, caso contrário é lançado um erro.

```haxe
var map1:Map<Int, String> = [1 => "one", 2 => "two", 3 => "three"];

var map2 = ["one" => 1, "two" => 2, "three" => 3];

var map3 = [1 => "cat", 1 => "dog"]; // Error: Duplicate Key

var map4 = ["h" => "Hello", "b" => "Bye"];
trace(map4["h"]); // Hello
```

É possível iterar um `Map` com um ciclo `for`. Podes iterar sobre os valores ou sobre as chaves:

```haxe
for (value in map) {
  // ...
}

for (key in map.keys()) {
  // ...
}
```

Nos bastidores, um `Map` é um tipo abstrato. Em tempo de compilação, é convertido num de vários tipos especializados, consoante o tipo da chave:

- `String`: `haxe.ds.StringMap`
- `Int`: `haxe.ds.IntMap`
- `EnumValue`: `haxe.ds.EnumValueMap`
- `{}`: `haxe.ds.ObjectMap`

O tipo `Maps` não existe em tempo de execução, tendo sido substituído por um dos objetos acima.
