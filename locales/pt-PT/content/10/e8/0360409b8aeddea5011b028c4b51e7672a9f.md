# Dicas

## Geral

- Lê sobre strings no [guia de strings][string-guide] oficial.
- Explora os [métodos disponíveis para _Strings_][string-methods].

## 1. Limpa o nome

- Existe um [método incorporado][string-replace] para substituir todas as ocorrências de uma substring numa string.
- Existe um [método incorporado][string-strip] para remover espaços em branco no início e no fim de uma string.

## 2. Obtém a primeira letra do nome

- Para obteres um caráter específico de uma string, podes usar o [operador de indexação][string-indexing].

## 3. Formata a primeira letra como inicial

- Existe um [método incorporado][string-upcase] para converter todos os carateres de uma string na sua variante em maiúsculas.

## 4. Coloca as iniciais dentro do coração

- Existe uma sintaxe especial para [interpolar][string-interpolation] uma expressão dentro de uma string.
- Podes colocar um emoji de coração numa string recorrendo a escape: `\u<id>`; o id do emoji de coração é `2764`.
