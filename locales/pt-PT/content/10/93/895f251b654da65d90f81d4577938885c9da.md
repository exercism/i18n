# Instruções

A Ellen está a fazer um jogo em que o jogador tem de combater alienígenas.
Acabou de aprender Programação Orientada a Objetos (POO) e está ansiosa por tirar partido do que a utilização de `classes` pode oferecer ao seu programa.

Para grande satisfação da Ellen, ofereceste-te para ajudar e ela deu-te a tarefa de programar os alienígenas que o jogador tem de combater.

## 1. Cria a classe Alien

Define a classe Alien com um construtor que aceita dois parâmetros `<x_coordinate>` e `<y_coordinate>`, colocando-os nas variáveis de instância `x_coordinate` e `y_coordinate`.
Cada alienígena também começa com um nível de saúde de 3, por isso a variável `health` também deve ser inicializada.

```python
>>> alien = Alien(2, 0)
>>> alien.x_coordinate
2
>>> alien.y_coordinate
0
>>> alien.health
3
```

Agora, cada alienígena deve conseguir acompanhar internamente a sua própria posição e saúde.

## 2. O método `hit`

A Ellen gostaria que a `class` Alien tivesse um método `hit` que diminui a saúde de um objeto alienígena em 1 sempre que é chamado.
Assim, pode simplesmente chamar `<alien>.hit()` em vez de ter de alterar manualmente a saúde de um alienígena.
Cabe-te a ti decidir se `hit()` leva os pontos de saúde _até_ ou _abaixo_ de zero.

```python
>>> alien = Alien(0, 0)

# Initialized health value.
>>> alien.health
3

# Decrements health by 1 point.
>>> alien.hit()
>>> alien.health
2
```

## 3. O método `is_alive`

Percebes que, se a saúde continuar a diminuir, em algum momento provavelmente chegará a 0 (_ou até menos!_).
Seria uma boa ideia acrescentar um método `is_alive` que a Ellen possa chamar rapidamente para verificar se o alienígena está... bem... vivo. 😉
`<alien>.is_alive()` deve devolver um Boolean.

```python
>>> alien.health
1
>>> alien.is_alive()
True
>>> alien.hit()
>>> alien.health
0
>>> alien.is_alive()
False
```

## 4. O método `teleport`

No jogo da Ellen, os alienígenas têm a capacidade de se teletransportar!
Terás de escrever um método `teleport` que recebe novos valores `x_coordinate` e `y_coordinate` e altera as coordenadas do alienígena em conformidade.

```python
>>> alien.teleport(5, -4)
>>> alien.x_coordinate
5
>>> alien.y_coordinate
-4
```

## 5. O método `collision_detection`

Obviamente, se os alienígenas podem ser atingidos por algo, então precisam de conseguir detetar quando ocorreu uma colisão dessas.
No entanto, os algoritmos de deteção de colisões podem ser complicados, e ainda não sabes como implementar um.
A Ellen disse que o fará mais tarde, mas mesmo assim gostaria que o método `collision_detection` aparecesse na classe como um lembrete para desenvolver a funcionalidade.
Terá de receber uma variável de algum tipo (provavelmente outro objeto), mas isso é realmente tudo o que sabes.
Terás de garantir que colocar a definição do método na classe não causa erros quando é chamado:

```python
>>> alien.collision_detection(other_object)
>>>
```

## 6. Contador de alienígenas

A Ellen voltou com um novo pedido para ti.
Ela quer acompanhar quantos alienígenas foram criados ao longo do tempo de vida do jogo.
Ela diz que tem algo a ver com o sistema de pontuação.

Por exemplo:

```python
>>> alien_one = Alien(5, 1)
>>> alien_one.total_aliens_created
1
>>> alien_two = Alien(3, 0)
>>> alien_two.total_aliens_created
2
>>> alien_one.total_aliens_created
2
# Accessing the variable from the class directly
>>> Alien.total_aliens_created
2
```

A Ellen adora o que fizeste até agora, mas tem mais um favor para te pedir.
Ela gostaria de uma função autónoma (_fora da classe `Alien()`_) que crie uma `list` de objetos `Alien()`, dada uma lista de posições (como `tuples`).
