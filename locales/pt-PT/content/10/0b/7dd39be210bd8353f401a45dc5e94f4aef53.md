# Testes

## A partir da linha de comandos

Escreve simplesmente `p test`. Assume-se que o caminho para os binários do phix foi declarado na variável de ambiente PATH.

Consulta [Testes unitários][unit-testing] para saber mais sobre o framework de testes normalmente usado.

## Editar o(s) ficheiro(s) `test.exw`

Isto é incentivado no início do teu percurso. Insere um `--` antes de todos os testes, exceto no primeiro ou nos dois primeiros. Guarda o ficheiro de teste.
Escreve o teu código para resolver o primeiro teste ou os dois primeiros. Depois, ativa progressivamente mais testes até conseguires passar em todos.

[unit-testing]: http://phix.x10.mx/docs/html/unit_test.htm
