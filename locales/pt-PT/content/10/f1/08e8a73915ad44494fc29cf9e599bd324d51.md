# Instalação

Há muitas formas de instalar Zig, e o número de formas de instalar Zig tem vindo a aumentar à medida que a linguagem amadurece.
Felizmente, todos os métodos de instalação populares estão listados na [página de instalação do Zig][install-zig].

## Versão do Zig

Atualmente, o Exercism só suporta o Zig 0.16.0 (lançado a 14 de abril de 2026).

Um exercício pode ser compatível com uma versão diferente do Zig, mas isso não é garantido.
O Zig ainda não chegou à versão 1.0 e as alterações que quebram a compatibilidade são comuns.

## Utilitários adicionais

### Zig fmt - Gerar código bem formatado

Ao resolver qualquer exercício, podes usar todo o tipo de estilos de código nas tuas soluções.
No entanto, fora da resolução de exercícios, como ao criar aplicações ou bibliotecas, costuma ser boa ideia manter o código consistente e legível.
Essas considerações são especialmente importantes quando outras pessoas que queiram ajudar nos teus projetos têm de ler o teu código.

Para resolver este problema, o compilador Zig inclui um [linter][linters] leve incorporado que formata o teu código de forma prática.
Este formatador de código procura seguir o [guia de estilo][style-guide] já estabelecido pela [documentação do Zig][documentation].

Para veres as funcionalidades do formatador nativo do Zig, usa o seguinte comando:

```bash
zig fmt --help
```

### Zig Zen - Regras para programar

Às vezes, um pouco de orientação faz toda a diferença na realização de qualquer tarefa, mesmo ao escrever código.
Felizmente, temos um comando divertido incorporado no compilador Zig para nos lembrar de alguns dos objetivos que estão por trás de escrever bom código Zig.

Para veres estas palavras de sabedoria, podes usar o seguinte comando:

```bash
zig zen
```

### The Zig Language Server - Suporte de editor completo para Zig

Este software de terceiros fornece sugestões de conclusão no editor e funcionalidades melhoradas de navegação no código Zig, que te podem ajudar a aprender a linguagem mais depressa.

Consulta o [Guia de instalação do ZLS][install-zls] para obteres as instruções mais recentes.
