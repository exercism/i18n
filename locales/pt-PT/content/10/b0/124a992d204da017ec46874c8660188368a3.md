# Introdução

Em Go, as strings são imutáveis.
Concatenar strings com `+` dentro de um ciclo provoca alocações frequentes e copia os dados várias vezes.
O [pacote `strings`](https://pkg.go.dev/strings) disponibiliza o [`Builder`](https://pkg.go.dev/strings#Builder) para minimizar o consumo de memória, montando strings de forma eficiente.

## Construir strings

O valor zero de um `strings.Builder` está pronto a usar de imediato, sem qualquer inicialização ou alocação explícita.
Podes acrescentar novos dados ao builder através de métodos de escrita específicos.
Cada método de escrita devolve um valor de erro para satisfazer as interfaces padrão de Go, mas é garantido que esse valor é sempre `nil` e, no código do dia a dia, é normalmente ignorado.

Os métodos mais usados são:

- `WriteString(s string) (int, error)`: acrescenta uma string ao buffer.
- `WriteRune(r rune) (int, error)`: acrescenta a codificação UTF-8 de uma rune.
- `WriteByte(c byte) error`: acrescenta um único byte.

```go
var sb strings.Builder

sb.WriteString("Hello")
var r rune = ' '
sb.WriteRune(r)
var b byte = '.'
sb.WriteByte(b)
```

## Obter e reiniciar

Depois de terminares a montagem do texto, podes extrair o conteúdo acumulado como uma string normal de Go chamando o método `String()`.
Chamar `String()` é uma operação muito barata, porque devolve a fatia de bytes subjacente diretamente como string, sem copiar os dados acumulados.

Se precisares de reutilizar a mesma instância do builder para montar uma nova string (por exemplo, dentro de um ciclo), podes chamar o método `Reset()`.
Isto esvazia o buffer interno, o que te permite começar do zero e montar a string seguinte, mantendo nos bastidores a capacidade de memória já alocada.

```go
var sb strings.Builder

sb.WriteString("Task One")
fmt.Println(sb.String()) // Output: Task One

// Clear the buffer for resource reuse
sb.Reset()

sb.WriteString("Task Two")
fmt.Println(sb.String()) // Output: Task Two
```
