# Introdução

O `case` é uma estrutura de controlo de fluxo que permite comparar um dado valor com vários padrões. As cláusulas de uma expressão `case` são avaliadas de cima para baixo, até que se encontre uma correspondência.

```elixir
age = 15

case age do
  0 -> ~c"infant"
  age when age < 4 -> ~c"baby"
  age when age < 13 -> ~c"child"
  age when age < 18 -> ~c"teenager"
  _ -> ~c"adult"
end

# => ~c"teenager"
```
