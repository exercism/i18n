# Instruções

Um naturalista está a catalogar os dragões que vivem à volta da caldeira. Todos partilham
características entre si, ou seja, cada dragão tem um nome, uma cor e uma idade, mas
especializam-se de formas muito próprias. Vais construir uma pequena árvore de herança de
classes de dragões e uma única palavra que envelhece qualquer descendente.

## 1. A família dos dragões

Define desde logo toda a árvore de herança de classes de tuplos (os respetivos
construtores vêm nas tarefas seguintes):

- `dragon`, com os slots `name`, `color` e `age`.
- `fire-dragon`, uma subclasse de `dragon`, com um slot adicional `flame-temp`.
- `ice-dragon`, outra subclasse de `dragon`, com um slot adicional `chill-temp`.
- `volcano-dragon`, uma subclasse de `fire-dragon`, com um slot adicional
  `lava-volume`.

Depois, dá a `dragon` um construtor `<dragon>`.

```factor
"Falkor" "white" 100 <dragon> name>> .   ! => "Falkor"
```

## 2. Os que cospem fogo

Dá a `fire-dragon` um construtor `<fire-dragon>`.

```factor
"Smaug" "red" 500 1200 <fire-dragon> flame-temp>> .   ! => 1200
"Smaug" "red" 500 1200 <fire-dragon> dragon? .        ! => t
```

## 3. Os que cospem gelo

Dá a `ice-dragon` um construtor `<ice-dragon>`.

```factor
"Frosty" "blue" 200 -40 <ice-dragon> chill-temp>> .   ! => -40
"Frosty" "blue" 200 -40 <ice-dragon> fire-dragon? .   ! => f   (siblings)
```

## 4. Os habitantes do vulcão

Dá a `volcano-dragon` um construtor `<volcano-dragon>`.

```factor
"Vesuvius" "red" 1000 1500 99 <volcano-dragon> dragon? .       ! => t
"Vesuvius" "red" 1000 1500 99 <volcano-dragon> fire-dragon? .  ! => t
```

## 5. Envelhecer qualquer dragão

Define `age-dragon` para incrementar em uma unidade o slot `age` de qualquer dragão (ou
descendente). Não devolve nada.

```factor
"Falkor" "white" 100 <dragon> dup age-dragon age>> .   ! => 101
```

A mesma palavra deve funcionar em todos os descendentes: é precisamente esse o objetivo do
acessor partilhado.
