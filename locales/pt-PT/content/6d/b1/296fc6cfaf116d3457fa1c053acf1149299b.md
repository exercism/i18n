# Introdução

Como muitas outras linguagens, o C++ tem _ponteiros_.
Já sabes que as _referências_ e os _ponteiros_ são semelhantes, mas pensa neles como um nível mais próximo do funcionamento interno do teu computador.
Os _ponteiros_ são variáveis que guardam endereços de objetos.
São usados para interagir diretamente com objetos, permitindo a alocação dinâmica de memória e a manipulação eficiente de dados em C++.

Se és novo nos _ponteiros_, podem parecer um pouco misteriosos, mas assim que te habituares a eles, são bastante simples.

São uma parte crucial do C++, por isso dedica algum tempo a compreendê-los bem.
A versão mais básica apresentada neste conceito é também chamada _dumb pointer_ ou _raw pointer_.
No C++ moderno existem também os _smart pointers_; o tipo básico não é nada inteligente e tens de tratar de todo o trabalho manualmente.

Antes de aprofundar os detalhes, vale a pena compreender a utilidade dos _ponteiros_.
Os _ponteiros_ são uma forma de partilhar o endereço de um objeto com outras partes do nosso programa, o que é útil por dois motivos principais:

1. Tal como as _referências_, os ponteiros evitam cópias e ajudam a reduzir o consumo de recursos do teu programa.
1. Ao contrário das _referências_, os ponteiros podem ser reatribuídos a objetos diferentes.
1. Os ponteiros também podem apontar para um valor nulo, para indicar que, neste momento, não apontam para nenhum objeto.

## Sintaxe geral

A declaração de um ponteiro em C++ implica especificar o tipo de dados para o qual o ponteiro aponta, seguido de um asterisco (`*`) e do nome do ponteiro.
Quando os ponteiros são declarados, não são inicializados automaticamente.
Sem uma atribuição explícita, um ponteiro contém normalmente um valor indeterminado, muitas vezes designado por "endereço de lixo".
Embora alguns compiladores possam inicializar os ponteiros com `nullptr`, esse comportamento não é garantido em todos os compiladores, por isso é essencial não contar com ele.
A melhor prática é inicializar explicitamente os raw pointers e verificar se não são nulos antes de os utilizar, para evitar potenciais problemas.

```cpp
int* ptr{nullptr}; // Declares a pointer and makes sure it is not invalid
```

Para atribuir o endereço de uma variável a um ponteiro, usas o operador de endereço (`&`).
A desreferenciação de um ponteiro faz-se com o _operador de indireção_ (`*`).

```cpp
std::string opponent{"Solomon Lane"};
// 'ethan' points to the address of the string opponent
std::string* ethan{&opponent};
// Instead of ethan's, the opponent's name address is given to the passPort
std::string passportName{*ethan};
```

Atenção: a desreferenciação tem de ser feita explicitamente, ao passo que as _referências_ funcionam como um simples alias.

## Aritmética de ponteiros

A _aritmética de ponteiros_ permite-te realizar operações aritméticas sobre ponteiros, o que é particularmente útil quando trabalhas com arrays.
Somar um número inteiro a um ponteiro faz com que este passe a apontar para um elemento diferente.

```cpp
// Stargate Coordinate Code
int gateCode[] = {462, 753, 218, 611, 977};
// 'ptr' points to the first element of 'gateCode'
int* ptr{&gateCode[0]};
// Accesses the third Stargate address through pointer arithmetic
int dialedAddress{*(ptr + 2)};
// Chevron encoded! Dialing Stargate address:
openStarGate(dialedAddress);
```

~~~~exercism/caution
A aritmética de ponteiros em C++ pode facilmente levar a __comportamento indefinido__ se não for tratada com cuidado.
O comportamento indefinido pode manifestar-se em resultados inesperados do programa, encerramentos anómalos ou até vulnerabilidades de segurança.
Um exemplo famoso das consequências do comportamento indefinido ocorreu na [explosão do foguetão Ariane 5][ariane-flight-v88] em 1996, em que uma exceção de software, causada pela conversão de um número de vírgula flutuante de 64 bits num inteiro com sinal de 16 bits, levou a uma falha catastrófica.

## Acesso a variáveis membro

Em C++, o operador `->` serve para aceder aos membros de um objeto através de um ponteiro para esse objeto.
É uma forma abreviada que simplifica o acesso aos membros de objetos apontados por ponteiros.
Por exemplo, se `ptr` for um ponteiro para um objeto com uma variável membro `x`, em vez de usares `(*ptr).x`, podes usar diretamente `ptr->x`.
Este operador melhora a legibilidade do código e reduz a verbosidade quando trabalhas com ponteiros para objetos.

Eis um exemplo breve, com uma _struct_ `Superhero` que tem uma variável membro `superpower`.
A função main cria um ponteiro `dianaPrince` para um objeto `Superhero` (que representa a Wonder Woman).
O operador `->` é usado para aceder à variável membro `superpower`, mostrando o icónico "Lasso of Truth" da Wonder Woman.

```cpp
struct Superhero {
    std::string superpower;
};
Superhero wonder_woman{};
Superhero* dianaPrince = &wonder_woman;
dianaPrince->superpower = "Lasso of Truth";
// Using the -> operator to access member variable superpower:
std::cout << "Wonder Woman, possesses the mighty " << dianaPrince->superpower;
// Memory cleanup:
delete dianaPrince;
```

## Ponteiros vs. referências

Os ponteiros e as referências permitem ambos o acesso indireto a objetos, mas diferem nas suas capacidades e nas considerações de segurança.
Os ponteiros oferecem a flexibilidade de mudar o objeto para o qual apontam e podem ser atribuídos como nulos.
No entanto, essa flexibilidade introduz riscos, como desreferenciar ponteiros nulos ou criar ponteiros pendentes.
As referências, por sua vez, não podem ser nulas e ficam associadas a objetos válidos aquando da sua criação, evitando estes riscos.
Dada a sua natureza mais segura, as referências devem ser preferidas em vez dos ponteiros, a menos que sejam necessárias as funcionalidades adicionais que os ponteiros oferecem.
