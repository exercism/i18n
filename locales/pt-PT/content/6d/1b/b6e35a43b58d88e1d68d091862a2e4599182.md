# não uses funções de listas

Por favor, não uses módulos externos (como List, Enum ou Stream) na tua
implementação. O objetivo deste exercício é criares estas funções básicas
tu próprio. Podes usar funções básicas do Kernel (como `Kernel.+/2`
para somar números), mas não uses funções do Kernel para listas como
`++`, `--`, `hd`, `tl`, `in`, `for` e `length`.
