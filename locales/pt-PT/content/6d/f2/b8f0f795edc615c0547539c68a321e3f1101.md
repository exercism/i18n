# Aprendizagem

O Lean é, ao mesmo tempo, uma linguagem de programação funcional de uso geral e um assistente de provas.
Existem inúmeros recursos disponíveis para aprender Lean, alguns focados nos seus aspetos de programação e outros no seu uso como provador de teoremas.

O livro [Functional Programming in Lean][functional-programming] é uma introdução ao paradigma da programação funcional com Lean.
Destina-se a programadores que querem aprender Lean, mesmo que nunca tenham trabalhado com linguagens de programação funcionais.

Para um olhar mais aprofundado sobre a prova de teoremas em Lean, o livro [Theorem Proving in Lean 4][theorem-proving] está listado como recurso oficial.

[The Lean Language Reference][lean-reference] é a fonte de referência para informações detalhadas sobre a linguagem.

A [Lean Community][community-resources] disponibiliza muitos outros recursos para aprender Lean.
