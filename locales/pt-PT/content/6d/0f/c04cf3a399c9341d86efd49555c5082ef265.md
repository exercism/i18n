# Introdução

## IO

As funções para lidar com entrada e saída são fornecidas pelo módulo `IO`.

### Saída

Para escrever uma string na saída padrão, usa `IO.puts`. O `IO.puts` acrescenta sempre uma nova linha no fim da string. Se não quiseres esse comportamento, usa antes o `IO.write`. Ambas as funções devolvem o átomo `:ok` se forem bem-sucedidas.

```elixir
IO.puts("Hi!")
# > Hi!
# => :ok
```

O `IO.puts` é útil para escrever strings, mas pouco mais. Se precisares de uma ferramenta de depuração que te permita escrever qualquer valor na saída padrão, usa antes o `IO.inspect`. O `IO.inspect` devolve o valor que lhe foi passado, sem alterações, por isso pode ser inserido em qualquer ponto do teu código. Também aceita muitas opções, por exemplo `:label`, que te permitem distingui-lo de outras chamadas a `IO.inspect`.

### Entrada

Para ler uma linha da entrada padrão, usa `IO.gets`. O `IO.gets` aceita um argumento: uma string que será impressa como um pedido de entrada. O `IO.gets` não acrescenta uma nova linha depois do pedido; inclui-a tu próprio se precisares.

```elixir
IO.gets("What's your name?\n")
# > What's your name?
# < Mary
# => "Mary\n"
```
