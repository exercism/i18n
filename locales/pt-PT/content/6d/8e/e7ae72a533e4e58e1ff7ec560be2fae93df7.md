# Recursos

* [The Rust Programming Language](https://doc.rust-lang.org/book/) é um excelente recurso para dares os primeiros passos em Rust e também para te aprofundares em funcionalidades específicas da linguagem.
* [Rust by Example](https://doc.rust-lang.org/stable/rust-by-example/) mostra-te exemplos das coisas mais comuns que vais escrever em Rust.
* A [documentação da API de Rust](http://doc.rust-lang.org/std/) pode ser usada para descobrires novos métodos e perceberes como funcionam.
* O [Stack Overflow](http://stackoverflow.com/questions/tagged/rust) pode ser usado para procurar o teu problema e ver se já foi respondido. Também podes fazer perguntas e responder a perguntas.
* O [Rust User Forum](http://users.rust-lang.org) serve para discussões gerais sobre Rust.
* O [/r/rust](http://www.reddit.com/r/rust/) é o subreddit oficial do Rust.
* O servidor oficial de [The Rust Programming Language](https://discord.gg/rust-lang) no [Discord](https://discordapp.com/) serve para fazeres perguntas rápidas e discutires a linguagem.
