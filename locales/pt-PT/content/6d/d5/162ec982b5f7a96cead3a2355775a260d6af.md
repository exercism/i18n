# Visibilidade

Quando usas classes para organizar código, a visibilidade das propriedades, dos métodos e das constantes ajuda a criar abstrações e responsabilidades adequadas.
A visibilidade das propriedades, dos métodos e das constantes é definida pelo uso das palavras-chave `public`, `private` ou `protected` no momento em que são declaradas.
A visibilidade refere-se sempre a uma utilização externa da propriedade, do método ou da constante da classe.
Ou seja, se uma propriedade for declarada `public`, é observável e utilizável a partir de chamadas externas.
As propriedades, os métodos e as constantes privados não são observáveis nem utilizáveis a partir de chamadas externas.

```php
<?php

class SecretDocument
{
    private $encryption_key;

    public $title;

    public function __construct($encryption_key, $title)
    {
        $this->encryption_key = $encryption_key;
        $this->title = $title;
    }
}

$document = new SecretDocument('secret_password', 'Secret Plans');
$title = $document->title; // => succeeds
$key = $document->encryption_key; // => fails
```

As propriedades, os métodos e as constantes protegidos só são observáveis para a própria classe e para as classes filhas (por herança).

```php
<?php

class Shape
{
    protected $color = "blue";
}

class Square extends Shape
{
    public function getColor()
    {
        return $this->color;
    }
}

$square = new Square();
$color = $square->getColor(); // => succeeds
```
