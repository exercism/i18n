# Aprender

## Começar com o Emacs

Já instalaste o Emacs. E agora?

Podes começar pelo tutorial premindo `C-h t`, e não é um mau sítio para começar. O tutorial ensina-te o básico de edição, pesquisa e navegação no Emacs.

Se és completamente novo no Emacs, pode fazer sentido usar um starter kit, que já vem com um conjunto de configurações e pacotes prontos a usar.

O pacote [Emacs Prelude](http://batsov.com/prelude/) oferece um bom conjunto de predefinições sensatas e de pacotes.

Para instalar o Emacs Prelude, corre o seguinte num terminal:

```
curl -L https://github.com/bbatsov/prelude/raw/master/utils/installer.sh | sh
```

e não deixes de consultar o [guia de instalação](https://prelude.emacsredux.com/en/latest/installation/) para mais instruções.


Se já conheces o vim, podes ter interesse no starter kit [Doom Emacs](https://github.com/doomemacs/doomemacs), que integra emulação do vim com o [evil-mode](https://github.com/emacs-evil/evil).

Para instalar o Doom Emacs, corre o seguinte num terminal:

```
git clone --depth 1 https://github.com/doomemacs/doomemacs ~/.emacs.d
~/.emacs.d/bin/doom install
```

e não deixes de consultar o [guia de instalação](https://github.com/doomemacs/doomemacs#install) para mais instruções.

## Configurar a verificação de sintaxe e o linting

Recomenda-se configurar a verificação de sintaxe e o linting com o [Flycheck](https://www.flycheck.org/en/latest/).

Se ainda não adicionaste o repositório [MELPA](https://melpa.org/) ao teu Emacs, fá-lo adicionando o seguinte ao teu [ficheiro de inicialização](https://www.flycheck.org/en/latest/glossary.html#term-init-file)

```elisp
(require 'package)

(add-to-list 'package-archives
             '("MELPA Stable" . "https://stable.melpa.org/packages/") t)
(package-initialize)
(package-refresh-contents)
```

A instalação e a configuração do Flycheck sem [use-package](https://github.com/jwiegley/use-package) fazem-se adicionando o seguinte ao teu [ficheiro de inicialização](https://www.flycheck.org/en/latest/glossary.html#term-init-file)

```elisp
(package-install 'flycheck)
(add-hook 'after-init-hook #'global-flycheck-mode)
```

A instalação e a configuração do Flycheck com [use-package](https://github.com/jwiegley/use-package) fazem-se adicionando o seguinte ao teu [ficheiro de inicialização](https://www.flycheck.org/en/latest/glossary.html#term-init-file)

```elisp
(use-package flycheck
  :ensure t
  :init (global-flycheck-mode))
```

Para mais informações e resolução de problemas, consulta a [documentação do Flycheck](https://www.flycheck.org/en/latest/user/troubleshooting.html).

## Aprender Emacs Lisp

A melhor documentação sobre Emacs Lisp é... a que vem com o próprio Emacs! Para acederes à [Emacs Lisp Reference](https://www.gnu.org/software/emacs/manual/elisp.html), escreve `C-h i` e procura a entrada Elisp, ou seleciona Help &rarr; More Manuals &rarr; Emacs Lisp Reference. Repara que o manual pode faltar em algumas distribuições; nesse caso, podes encontrá-lo [online](https://www.gnu.org/software/emacs/manual/elisp.html).

Se estás a começar agora com o Elisp, podes ler a [Introduction to Emacs Lisp](http://www.emacswiki.org/emacs/EmacsLispIntro), que se abre da mesma forma.

## Boas práticas e convenções do Emacs Lisp

O manual do Emacs tem uma secção sobre [convenções de codificação](https://www.gnu.org/software/emacs/manual/html_node/elisp/Coding-Conventions.html) do Emacs Lisp. Há também um [guia de estilo](https://github.com/bbatsov/emacs-lisp-style-guide) mantido pela comunidade no GitHub.
