# Instalação

## Instalar o .NET

A track de C# é construída sobre a plataforma [.NET](https://dotnet.microsoft.com/learn/dotnet/what-is-dotnet), que funciona em Windows, Linux e macOS.
Para compilar projetos .NET, podes usar a interface de linha de comandos (CLI) do .NET.
Esta CLI faz parte do SDK .NET, que podes instalar de acordo com as [instruções de instalação](https://dotnet.microsoft.com/download/dotnet/8.0).
Nota: a track de C# requer a versão 9.0 ou superior do SDK.

Depois de concluíres a instalação, podes verificar se a CLI foi instalada com sucesso ao correr este comando num terminal:

```bash
dotnet --version
```

Se o resultado for uma versão igual ou superior a `9.0.100`, o SDK .NET foi instalado com sucesso.

## Usar um IDE

Se quiseres uma experiência de edição mais completa, provavelmente vais querer usar um [IDE ou ambiente de desenvolvimento integrado](https://en.wikipedia.org/wiki/Integrated_development_environment).
Estes são os IDEs mais populares que suportam a compilação de projetos .NET:

- [Visual Studio 2022](https://www.visualstudio.com/downloads/)
- [Visual Studio Code](https://code.visualstudio.com/download) com a [extensão C#](https://marketplace.visualstudio.com/items?itemName=ms-dotnettools.csharp)
- [Visual Studio for Mac](https://www.visualstudio.com/vs/visual-studio-mac/)
- [Project Rider](https://www.jetbrains.com/rider/download/)

Nota: como o formato de projeto .NET é bastante diferente das versões anteriores, os IDEs mais antigos (como o Visual Studio 2015) não são suportados.
