# Instalação

As soluções deste track são escritas em assembly RISC-V de 32 bits e executadas por emulação, por isso não é preciso hardware RISC-V.
Cada exercício inclui um Makefile que compila os testes e os executa.
Para o usares, precisas de três ferramentas:

- [Zig][zig], que fornece o assembler de RISC-V, o compilador de C e o linker através de `zig cc`.
- [Make][make], que executa a compilação.
- `qemu-riscv32` do [QEMU][qemu], que executa o programa resultante.

## macOS

Inicia uma máquina virtual Linux com qualquer solução de virtualização adequada (por exemplo, [Lima][lima]) e segue as instruções de uma das secções sobre distribuições de Linux abaixo.

## Windows

Usa o [Windows Subsystem for Linux][wsl] e segue as instruções de uma das secções sobre distribuições de Linux abaixo.
Em alternativa, configura uma máquina virtual Linux.

## Debian / Ubuntu

Instala o Make e os emuladores em modo de utilizador do QEMU:

```shell
sudo apt install make qemu-user
```

Depois, instala o Zig 0.15.2 ou superior como descrito em [Transferência direta][zig-install].

## Fedora

Instala as três ferramentas com:

```shell
sudo dnf install zig make qemu-user
```

## Arch Linux

Instala as três ferramentas com:

```shell
sudo pacman -S zig make qemu-user
```

## openSUSE Tumbleweed

Instala as três ferramentas com:

```shell
sudo zypper install zig make qemu-linux-user
```

## Verificar a instalação

Confirma que as três ferramentas são encontradas:

```shell
zig version
make --version
qemu-riscv32 --version
```

Depois, descarrega um exercício com o CLI do Exercism e executa os seus testes:

```shell
exercism download --track=risc-v --exercise=hello-world
cd ~/exercism/risc-v/hello-world/
make
```
