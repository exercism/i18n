# Apêndice de instruções

## Cria a tua própria DSL

Neste exercício, tens total liberdade para desenhar a DSL de grafos dos teus sonhos.

Talvez queiras criar uma DSL baseada em listas de etiquetas e registos, como esta:

```roc
my_graph =
    Graph.new([
        Title("My Graph"),
        Node("a", { color: Green }),
        Node("b", { color: Blue }),
        Edge("a", "b", { style: Dotted }),
    ])
```

Ou talvez prefiras uma DSL baseada em cadeias de chamadas de funções, como esta:

```roc
my_graph =
    Graph.new
        .with_title("My Graph")
        .add_node("a", Attr.new.with_color(Green))
        ...
```

Ou talvez tenhas um plano completamente diferente? Avança! Os testes só te pedem que cries alguns grafos específicos; a forma como os construis depende inteiramente de ti.

Dito isto, uma DSL costuma ser melhor se for clara, concisa e não demasiado surpreendente (por exemplo, a função `minus` serve para subtrair, não para criar uma aresta entre dois nós, como em `node("a") - node("b")`).

Para tornar isto ainda mais divertido, podes, se quiseres, tentar implementar uma função `to_dot` que converte o teu grafo para o formato DOT!
