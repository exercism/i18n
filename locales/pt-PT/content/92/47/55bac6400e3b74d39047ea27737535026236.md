# Instruções

Um novo clube de poesia abriu na cidade e estás a pensar em ir.
Como já houve incidentes no passado, o clube tem uma política de entrada muito específica que tens de dominar antes de tentares entrar.

Há duas portas no clube de poesia, ambas vigiadas.
Para conseguires entrar, tens de descobrir a palavra-passe desse dia:

## 1. Divide uma string em linhas individuais

A primeira coisa que tens de fazer é dividir o poema em linhas individuais.
O guarda vai recitar um poema, e vais ter de o dividir em linhas.

Implementa a função `splitOnNewlines` que recebe uma string e a divide num array de strings, usando o caráter de nova linha como delimitador.
A função deve devolver um array de strings, em que cada string é uma linha do poema.

```swift
splitOnNewlines("Hello.\nHow are you?\n\nI'm doing fine.")
// returns ["Hello." ,"How are you?", "", "I'm doing fine"].
```

## 2. Porta da frente

1. O guarda vai recitar um poema
2. Vais ter de dividir o poema em linhas individuais.
3. Vais ter de obter a primeira letra de cada linha.
   - Se a linha estiver vazia, deves usar `_` em vez disso.
4. Vais ter de juntar as letras, que formarão uma palavra.

Por exemplo, um dos escritores preferidos deles é Michael Lockwood, que escreveu o seguinte poema _acróstico_, o que significa que a primeira letra de cada frase forma uma palavra:

```text
Stands so high
Huge hooves too
Impatiently waits for
Reins and harness
Eager to leave
```

Quando o guarda recitar o poema, vais dividi-lo em linhas individuais e responder com as primeiras letras de cada linha, ou seja, `["S", "H", "I", "R", "E"]`.

O guarda vai depois dar-te a palavra formada pelo array de letras com que respondeste, para a colocares em maiúsculas.
Por fim, a palavra-passe que devolves é `"SHIRE"`, e podes entrar.

Implementa a função `frontDoorPassword` que recebe uma string que representa o poema.
A função deve devolver a palavra-passe que darias ao guarda.

```swift
frontDoorPassword("Stands so high\nHuge hooves too\nImpatiently waits for\nReins and harness\nEager to leave")
// returns "SHIRE"
```

## 3. Porta de trás

Na parte de trás do clube encontras os poetas mais prestigiados, que é como a zona VIP.
Como isto não é para todos, o processo da porta de trás é um pouco mais complicado.

1. O guarda vai recitar um poema.
2. Vais ter de dividir o poema em linhas.
3. Vais ter de obter a última letra de cada linha.
   - Por vezes, a linha tem espaços à direita, por isso vais ter de os remover.
4. Vais ter de juntar as letras e depois acrescentar `", please"` ao fim da palavra formada pelas letras.

Por exemplo, o poema mencionado antes também é _teléstico_, o que significa que a última letra de cada frase forma uma palavra:

```text
Stands so high
Huge hooves too
Impatiently waits for
Reins and harness
Eager to leave
```

Quando o guarda recitar o poema, vais dividi-lo em linhas individuais, remover os espaços à direita e responder com as últimas letras de cada linha, ou seja, `["h", "o", "r", "s", "e"]`.

O guarda vai depois dar-te a palavra formada pelo array de letras com que respondeste, para a colocares em maiúsculas e acrescentares `", please"`.
Por fim, a palavra-passe que devolves é `"horse, please"`, e podes entrar.

Implementa a função `backDoorPassword` que recebe uma string que representa o poema.
A função deve devolver a palavra-passe que darias ao guarda.

```swift
backDoorPassword("Stands so high\nHuge hooves too\nImpatiently waits for\nReins and harness\nEager to leave")
// returns "horse, please"
```

## 4. Sala secreta

Dentro da sala de trás do clube há outra porta que dá para a sala secreta, onde só os poetas de topo podem entrar.

1. O guarda vai recitar um poema.
2. Vais ter de dividir o poema em linhas.
3. Vais ter de obter a i<sup>ésima</sup> letra da i<sup>ésima</sup> linha.
4. Vais ter de juntar as letras e depois acrescentar `"!"` ao fim da palavra formada pelas letras.
5. Vais ter de colocar a palavra em maiúsculas.

Por exemplo, uma versão modificada do poema mencionado antes encaixa neste padrão:

```text
Stands so high
Huge hooves too
Impatiently waits for
Rider with harness
Eager to leave
```

Quando o guarda recitar o poema, vais dividi-lo em linhas individuais, remover os espaços à direita e responder com as i<sup>ésimas</sup> letras de cada linha, ou seja, ["S", "u", "p", "e", "r"].

O guarda vai depois dar-te a palavra formada pelo array de letras com que respondeste, para a colocares em maiúsculas e acrescentares `"!"`.
Por fim, a palavra-passe que devolves é `SUPER!`, e podes entrar.

Implementa a função `secretRoomPassword` que recebe uma string que representa o poema.
A função deve devolver a palavra-passe que darias ao guarda.

```swift
secretRoomPassword("Stands so high\nHuge hooves too\nImpatiently waits for\nRider with harness\nEager to leave")
// returns "SUPER!"
```
