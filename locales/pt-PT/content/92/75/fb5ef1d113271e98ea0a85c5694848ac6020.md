# Testes

Para executar os testes, corre o comando `v test .` dentro do diretório do exercício.

Se quiseres ver todos os testes que foram executados, juntamente com estatísticas sobre a velocidade, usa `v -stats test .`

Para mais informações sobre testes em V, consulta [a documentação](https://github.com/vlang/v/blob/master/doc/docs.md#testing).
