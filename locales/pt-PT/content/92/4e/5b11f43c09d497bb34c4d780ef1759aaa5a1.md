# Apêndice às instruções

## Responsabilidades do Roc e do anfitrião

Em código Roc, normalmente concentramo-nos na lógica de negócio, enquanto a plataforma trata da concorrência e do estado partilhado.
Por isso, neste exercício só precisas de implementar as operações de conta em `BankAccount.roc`, sem te preocupares com a concorrência.
As contas começam fechadas, reabrir uma conta repõe o saldo, e os depósitos e levantamentos têm de ser positivos.

## Demonstração opcional do servidor

O ficheiro `bank-account-demo.roc` incluído mostra como a tua implementação pode ser usada num pequeno serviço web.
Podes lê-lo no editor, mas é independente dos testes e não faz parte da tua solução.

Para executar a demonstração, tens de [instalar o Roc](https://www.roc-lang.org/install/) na tua máquina, instalar a [CLI do Exercism](https://exercism.org/cli-walkthrough) e depois executar este comando num terminal:

```sh
exercism download --exercise=bank-account --track=roc
```

De seguida, implementa `BankAccount.roc` e testa-o com o seguinte comando (muda o local de transferência indicado pela CLI se for diferente do caminho abaixo):

```sh
cd ~/Exercism/roc/bank-account
roc test bank-account-test.roc
```

Quando todos os testes passarem, podes iniciar o servidor da demonstração com o seguinte comando:

```sh
roc bank-account-demo.roc
```

O servidor usa a [plataforma basic-webserver](https://github.com/roc-lang/basic-webserver) e o suporte SQLite integrado (o Roc transfere a plataforma na primeira execução).
Não é preciso um servidor de base de dados separado.
O servidor escuta em `http://127.0.0.1:8000` e cria `bank-account-demo.db` no teu diretório atual (define `DB_PATH` para usares um ficheiro de base de dados diferente).
Pára o servidor com Ctrl-C.
Os dados sobrevivem a reinícios.

Noutro terminal, podes chamar o serviço web com `curl` (no Windows, usa sempre `curl.exe` para evitares o alias `curl` do PowerShell).
Por exemplo, eis como abrir a conta n.º 123, depositar 50, levantar 10 e verificar o saldo:

```sh
curl -X POST http://127.0.0.1:8000/accounts/123/open
curl -X POST http://127.0.0.1:8000/accounts/123/deposit/50
curl -X POST http://127.0.0.1:8000/accounts/123/withdraw/10
curl http://127.0.0.1:8000/accounts/123/balance
```

O saldo é `40`.
Os IDs das contas e os montantes têm de ser números inteiros sem sinal.
As atualizações devolvem `OK` em caso de sucesso ou um erro da tua implementação de conta em caso de falha.
Para fechar a conta n.º 123:

```sh
curl -X POST http://127.0.0.1:8000/accounts/123/close
```

Para experimentares pedidos concorrentes no Linux/macOS, usa um ID de conta novo e envia 100 depósitos a partir de oito clientes:

```sh
curl -X POST http://127.0.0.1:8000/accounts/456/open
seq 100 | xargs -P 8 -I '{}' curl --fail --silent --show-error -X POST http://127.0.0.1:8000/accounts/456/deposit/1
curl http://127.0.0.1:8000/accounts/456/balance
```

No Windows, usa o [PowerShell 7+](https://learn.microsoft.com/powershell/scripting/install/installing-powershell-on-windows) para o exemplo em paralelo:

```powershell
curl.exe -X POST http://127.0.0.1:8000/accounts/456/open
1..100 | ForEach-Object -Parallel { curl.exe --fail --silent --show-error -X POST http://127.0.0.1:8000/accounts/456/deposit/1 } -ThrottleLimit 8
curl.exe http://127.0.0.1:8000/accounts/456/balance
```

Todos os depósitos devem ser bem-sucedidos e o saldo deve ser `100`.

## Como a demonstração trata a concorrência

Cada pedido lê a conta, chama as tuas funções Roc e guarda o resultado dentro de uma transação `Immediate` do SQLite.
As operações falhadas são revertidas sem alterar a conta.
O SQLite permite apenas um escritor de cada vez, o que impede que pedidos concorrentes sobreponham as atualizações uns dos outros (mesmo entre contas diferentes).

Nota: o exercício usa `U64`, mas a demonstração guarda os saldos como inteiros do SQLite e rejeita atualizações que excedam o valor máximo de `I64` (`9223372036854775807`).

Para um exemplo de como executar cálculos independentes em paralelo, experimenta o [exercício parallel-letter-frequency](https://exercism.org/tracks/roc/exercises/parallel-letter-frequency).
