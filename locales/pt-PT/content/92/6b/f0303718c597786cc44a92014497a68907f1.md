# Dicas

## 1. Verifica se o comando é válido

- Usa a expressão [test][regex-test] para devolver um Boolean.
- Lembra-te de que podemos usar o argumento [flags][flags] para funcionalidades adicionais, como não distinguir maiúsculas de minúsculas.

## 2. Remove os emojis encriptados

- Uma vez que todos os emojis partilham a mesma encriptação, podemos usar `[0-9]` para procurar qualquer algarismo a seguir à palavra `emoji`.
- O caráter `+` corresponde a um ou mais itens consecutivos.
- Usa o método [gsub][regex-gsub] para substituir cada emoji por uma string vazia.

## 3. Verifica se o número de telefone é válido

- Este [artigo][phone-validation] explica muito bem as diferentes formas de validar um número de telefone.
- Usa o filtro `test` para verificar se o número de telefone é válido ou não.
- Devolve a resposta final com uma expressão `if-then-else`.

## 4. Obtém a ligação do site

- O nosso objetivo são palavras unidas por um ou mais pontos `.`.
- Podes usar o filtro [match][regex-match] com a flag `g`.
- O filtro [scan][regex-scan] pode ser mais fácil de usar.

## 5. Cumprimenta o utilizador

- Usar [grupos de captura com nome][named-capture] é útil para reutilizar o texto da correspondência.
- O filtro [capture][regex-capture] é útil para fazer referência ao grupo com nome.

## 6. Análise muito simples de CSV

- Aqui, queremos usar [split][regex-split] porque conhecemos o delimitador.
- O padrão é «vírgula seguida de zero ou mais espaços».
- Temos de usar o filtro `split` **de aridade 2**; não há flags para especificar.
