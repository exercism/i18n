# Instruções

Neste exercício vais ajudar a gerir as operações diárias de uma pequena pastelaria, usando as estruturas de controlo de fluxo de Cairo.

## 1. Calcular o total da encomenda

Implementa `calculate_total`, que calcula o custo de uma encomenda com base no tipo de pastelaria e na quantidade:

- Croissant: 3 moedas cada
- Queque: 2 moedas cada
- Bolacha: 1 moeda cada

```rust
calculate_total(Pastry::Croissant, 4) // Returns: 12 (4 * 3)
calculate_total(Pastry::Cookie, 10)   // Returns: 10 (10 * 1)
```

## 2. Aplicar descontos de volume

Implementa `apply_discount`, que aplica descontos com base no total da encomenda.
Aplica a percentagem de desconto ao total e arredonda depois para baixo, para o número inteiro de moedas mais próximo (floor).

- Encomendas ≥ 20 moedas: 10% de desconto
- Encomendas ≥ 10 moedas: 5% de desconto
- Encomendas < 10 moedas: sem desconto

```rust
apply_discount(25) // Returns: 22
apply_discount(15) // Returns: 14
apply_discount(8)  // Returns: 8
```

## 3. Criar o horário de cozedura

Implementa `baking_schedule`, que cria um plano diário de cozedura.
A pastelaria coze em lotes de 5 encomendas por hora:

```rust
baking_schedule(18) // Returns: [5, 5, 5, 3] (3 full batches + 3 remaining)
baking_schedule(10) // Returns: [5, 5] (2 full batches)
baking_schedule(3)  // Returns: [3] (1 partial batch)
```

Usa as estruturas de controlo de fluxo adequadas (`if`/`else`, `loop`) para resolveres cada problema de forma eficiente.
