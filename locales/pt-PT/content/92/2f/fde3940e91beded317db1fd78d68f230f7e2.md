# Instruções

Estás no posto de rádio costeiro, a monitorizar as conversas do canal:
as mensagens chegam pelo fio, registas-as e reenvias as respostas.
Cinco pequenas palavras tratam do trabalho de um turno.

Os testes passam-te entradas `<string-reader>` (tráfego de entrada)
e usam `<string-writer>` para a saída, mas todas as palavras aqui
funcionam da mesma forma com um `<file-reader>` real ou um socket.

## 1. Ouve tudo

Define `hear-out` para esvaziar um fluxo de entrada e devolver o seu conteúdo como uma única string.

```factor
"all quiet on the channel" <string-reader> hear-out .
! => "all quiet on the channel"
```

## 2. Conta as mensagens

Define `count-messages` para ler todas as linhas de um fluxo de entrada
e devolver quantas havia.

```factor
"alpha\nbravo\ncharlie\n" <string-reader> count-messages .
! => 3
```

## 3. Repete a última chamada

Define `echo-back` para ler todas as linhas e devolver a **última em maiúsculas**,
a resposta padrão de rádio «disseste X».

```factor
"alpha\nbravo\n" <string-reader> echo-back .
! => "BRAVO"
```

## 4. Emite uma mensagem

Define `broadcast` para escrever uma mensagem para um writer fornecido e
descarregar o fluxo para que saia imediatamente. Não devolve nada.

```factor
[ "mayday" output-stream get broadcast ] with-string-writer .
! => "mayday"
```

## 5. Captura a saída de uma quotation

Define `capture` para executar uma quotation com um string-writer
novo como saída ambiente, e devolver o que quer que a quotation
tenha imprimido. A quotation não recebe argumentos, limita-se a
escrever para o fluxo ambiente como habitualmente.

```factor
[ "test broadcast" print ] capture .
! => "test broadcast\n"
```
