# O tipo Boolean

Em Cairo, o tipo Boolean é essencial para operações lógicas e instruções condicionais.
Os Boolean em Cairo têm o tamanho de um `felt252`, o que garante um uso eficiente do espaço e mantém a simplicidade da lógica verdadeiro/falso.

O tipo Boolean em Cairo é especificado com a palavra-chave `bool`.
Isto permite declarar e manipular variáveis Boolean na linguagem.
Por exemplo, considera o exemplo seguinte:

```rust
fn main() {
    let t = true;
    let f: bool = false; // with explicit type annotation
}
```

Neste exemplo, são declaradas duas variáveis Boolean.
A variável `t` recebe o valor `true` e é declarada implicitamente como do tipo Boolean, enquanto a variável `f` é anotada explicitamente com o tipo `bool` e recebe o valor `false`.

Um aspeto importante a ter em conta é que, ao declarar uma variável Boolean em Cairo, é obrigatório usar um dos literais `true` ou `false` como valor.
Isto significa que literais inteiros, como `0` ou `1`, não podem ser usados como substitutos de `false` ou `true`.
A aplicação rigorosa desta regra garante a segurança de tipos e evita potenciais erros lógicos no desenvolvimento de contratos inteligentes.

## Operadores Boolean em Cairo

- `||` (OU lógico): Devolve `true` se pelo menos um dos operandos for `true`.
- `&&` (E lógico): Devolve `true` se ambos os operandos forem `true`.
- `!` (NÃO lógico): Devolve o valor Boolean oposto do operando.

## Código de exemplo

O seguinte excerto de código demonstra como usar tipos Boolean em Cairo.
Mostra a declaração de variáveis Boolean, a atribuição de expressões Boolean e a utilização de asserções para verificar a correção da lógica Boolean:

```rust
fn main() {
    // Declaration of Boolean variables
    let t: bool = true;
    let f: bool = false;

    // Boolean expression evaluation
    let true_expr = 5 == 5; // true
    let false_expr = 7 == 5; // false

    // Using Boolean operators
    let or_expr = t || f; // true || false => true
    let and_expr = t && f; // true && false => false
    let not_expr = !f; // !false => true

    // Assertions to verify the correctness
    assert(t == true_expr, 'this should be true'); // t == true
    assert(f == false_expr, 'this should be false'); // f == false
    assert(or_expr == true, 'this should be true for OR'); // true
    assert(and_expr == false, 'this should be false for AND'); // false
    assert(not_expr == true, 'this should be true for NOT'); // true
}
```
