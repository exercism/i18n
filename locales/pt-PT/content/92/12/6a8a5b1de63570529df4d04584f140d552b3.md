# Apêndice às instruções

## O esqueleto

`src/TreeBuilding.hs` já contém uma solução que funciona e passa todos os testes.
É lenta e difícil de ler; a tua tarefa é torná-la melhor sem quebrar os testes.

`buildTree` devolve `Nothing` quando os registos não formam uma árvore válida.

## Alterar a representação

Os testes nunca usam os construtores de `Tree` diretamente.
Em vez disso, constroem as árvores esperadas com a função

```haskell
node :: Int -> [Tree] -> Tree
```

em que `node i children` é o nó com o id `i` e os filhos indicados, por ordem crescente de id.

Isto significa que podes alterar livremente a forma como `Tree` é representado, por exemplo para

```haskell
import qualified Data.Tree as T

type Tree = T.Tree Int

node :: Int -> [Tree] -> Tree
node = T.Node
```

desde que `Tree` continue a ter instâncias de `Eq` e `Show` e `node` mantenha o mesmo significado.
Se usares uma biblioteca como `containers`, não te esqueças de a adicionar às `dependencies` do `package.yaml`.
