# Instruções

Voltaste a trabalhar no sistema ORM (mapeamento objeto-relacional) apresentado em [exercise:csharp/object-relational-mapping]().

A nossa análise de utilização do ORM mostra que 95% das transações são executadas dentro de um único método que as invoca, e decidiu-se que seria mais adequado ter um único método do ORM que abrisse, escrevesse e confirmasse uma transação.

A base de dados tem os seguintes métodos de instância:

- `Database.BeginTransaction()` inicia uma transação na base de dados.
- `Database.Write(string data)` escreve dados na base de dados dentro da transação. Se receber dados inválidos, é lançada uma exceção. Uma tentativa de chamar este método sem que `BeginTransaction()` tenha sido chamado provoca o lançamento de uma exceção. Se for bem-sucedido, o estado interno da base de dados passa a `DataWritten`.
- `Database.EndTransaction()` confirma a transação na base de dados. Pode lançar uma exceção se não conseguir fechar a transação ou se `Database.BeginTransaction()` não tiver sido chamado.
- Uma chamada a `Database.Dispose()` limpa a base de dados se for lançada uma exceção durante uma transação. Isto faz com que o estado da base de dados passe a `Closed`.

## 1. Escrever na base de dados

Implementa o método `Orm.Write()` para iniciar uma transação na base de dados, escrever os dados recebidos e confirmar a transação. Todas as exceções, incluindo `InvalidOperationException`, devem poder chegar a quem chama o método, sem serem registadas nem sofrerem qualquer outra intervenção.

```csharp
Database db = new Database();
Orm orm = new Orm(db);
orm.Write("good write");
// => database has an internal state of State.Closed
orm.Write("bad write");
// => an exception is thrown but database is left with an internal state of State.Closed
orm.Write("bad commit");
// => an exception is thrown but database is left with an internal state of State.Closed
```

## 2. Escrever na base de dados e devolver a quem chama uma indicação de se a escrita foi bem-sucedida

Já passaram alguns meses desde que `Orm.Write()` foi introduzido e há divisão na equipa. Muitos programadores gostariam que o _ORM_ tratasse os erros quando são lançadas exceções e devolvesse simplesmente a quem chama uma indicação de sucesso.

Implementa o método `Orm.WriteSafely()` para iniciar uma transação na base de dados, escrever os dados recebidos e confirmar a transação (como acima). Deve devolver `true` se a _escrita_ tiver sido bem-sucedida e `false` caso contrário. Não tentes registar a exceção.

```csharp
Database db = new Database();
Orm orm = new Orm(db);
orm.WriteSafely("good write");
// => true
orm.WriteSafely("bad write");
// => false
orm.WriteSafely("bad commit");
// => false
```
