# Introdução

Uma definição de tipo cria um novo tipo com nome, distinto de todos os outros tipos, mesmo daqueles que têm o mesmo tipo subjacente.

## Definir tipos

Uma definição de tipo começa com a palavra-chave `type`, seguida do nome do novo tipo e do seu tipo subjacente:

```go
type File []bool
```

Aqui, `File` refere-se a uma única coluna vertical de um tabuleiro de xadrez, habitualmente identificada de A a H.
Cada casa desta coluna é representada por um valor Boolean que indica se está ocupada ou não.
Agora que `File` está definido, podemos usá-lo dentro de outras definições:

```go
type Chessboard map[string]File

board := Chessboard{
    "A": File{true, false, true},
    "B": File{false, true, false},
}
```

`Chessboard` associa identificadores de coluna a valores `File`.
Cada `File` é um slice de valores Boolean que representa as casas de uma coluna do tabuleiro.
Sem estas definições de tipo, `board` seria um `map[string][]bool`, o que tornaria mais difícil perceber o que estamos a representar.
