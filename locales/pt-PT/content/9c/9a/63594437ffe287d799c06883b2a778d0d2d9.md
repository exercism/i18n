# Instruções

A estação meteorológica de Wellington vai substituir o seu sistema manual de registo de temperatura por um novo sistema digital.
No sistema antigo, os cálculos eram feitos manualmente.
No sistema novo, vão ser automatizados.
Os cálculos incluem a conversão da temperatura de Celsius para Fahrenheit e o cálculo da temperatura média.
O sistema novo tem sensores para registar dados de temperatura em Celsius.

A estação meteorológica de Wellington quer a tua ajuda com o sistema novo.

## 1. Converter a temperatura de Celsius para Kelvin

A estação meteorológica tem uma secção no seu site destinada aos investigadores.
Os investigadores estão interessados na temperatura em Kelvin.

Kelvin é uma unidade usada para medir a temperatura.
Está na mesma escala que Celsius, mas com um ponto de partida diferente.
O seu ponto de partida é o zero absoluto, que corresponde a 0 K (Kelvin) ou -273,15 °C (Celsius).

Aqui está uma tabela que mostra a conversão entre Celsius e Kelvin:

| Celsius (°C) | Kelvin (K) |
| ----------- | --------- |
| -273,15     | 0         |
| -100        | 173,15    |
| 0           | 273,15    |
| 100         | 373,15    |

A estação meteorológica quer que implementes um método que converta uma temperatura de Celsius para Kelvin.

Implementa o método `Temperature#to_kelvin`, que recebe um argumento `celsius` e devolve a temperatura em Kelvin, somando 273,15 ao valor de `celsius` indicado.

```crystal
Temperature.new.to_kelvin(0)
# => 273.15
```

## 2. Arredondar a temperatura

O sensor de temperatura da estação meteorológica é exato.
Consegue medir a temperatura com uma precisão de 0,0001 °C.
A estação meteorológica só quer mostrar a temperatura arredondada a 1 casa decimal, porque a maioria dos utilizadores não está interessada nesse nível de precisão.

A estação meteorológica quer que implementes um método que arredonde a temperatura a 1 casa decimal.

Implementa o método `Temperature#round`, que recebe um argumento `celsius` e devolve a temperatura arredondada a 1 casa decimal.

```crystal
Temperature.new.round(10.1234)
# => 10.1

Temperature.new.round(10.1567)
# => 10.2
```

## 3. Converter a temperatura de Celsius para Fahrenheit

A estação meteorológica tem uma secção no seu site destinada aos turistas.
Os turistas estão interessados na temperatura em Fahrenheit.

Fahrenheit é uma unidade de medida de temperatura.
Tem uma escala diferente da de Celsius.
0 °C corresponde a 32 °F, e 1 grau Celsius equivale a 1,8 graus Fahrenheit.

Aqui está uma tabela que mostra a conversão entre Celsius e Fahrenheit:

| Celsius (°C) | Fahrenheit (°F) |
| ----------- | -------------- |
| -273,15     | -459,8         |
| -100        | -148           |
| 0           | 32             |
| 100         | 212            |

A estação meteorológica quer que implementes um método que converta temperaturas de Celsius para Fahrenheit.

Implementa o método `Temperature#to_fahrenheit`, que recebe um argumento `celsius` e devolve a temperatura em Fahrenheit como um número inteiro.

```crystal
Temperature.new.to_fahrenheit(10)
# => 50
```

## 4. Obter o número de sensores em falta

Durante a instalação dos sensores de temperatura, os trabalhadores de manutenção perceberam que faltavam alguns sensores.
Cada unidade de medição de temperatura precisa de quatro sensores de temperatura.
A equipa de manutenção contou quantos sensores tinha, mas precisava de saber quantos faltavam.
Gostariam de receber ajuda para contar quantos sensores precisam de comprar para construir outra unidade de medição de temperatura completa.

Implementa o método `Temperature#number_missing_sensors`, que recebe um argumento `number_of_sensors` e devolve o número de sensores em falta.

```crystal
Temperature.new.number_missing_sensors(10)
# => 2
```
