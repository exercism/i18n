# evitar literais de caráter

Verifica se as letras são diferentes, sejam quais forem as letras.
Esta solução usa literais de caráter (por ex. `'T'`), mas não são necessários para este exercício.
Embora a descrição mencione o caso de uso dos nucleótidos do ADN, podes calcular a distância de Hamming para quaisquer duas strings com o mesmo comprimento.
