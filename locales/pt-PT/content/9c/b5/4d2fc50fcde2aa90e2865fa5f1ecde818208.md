# usa a documentação do módulo

[comment]: # (Este erro é gerado quando a submissão não tem @moduledoc para o módulo)

Recomenda-se ter um atributo [`@moduledoc`](https://hexdocs.pm/elixir/writing-documentation.html#module-attributes) para descrever a intenção do módulo.

- A documentação é um [cidadão de primeira classe](https://hexdocs.pm/elixir/writing-documentation.html) em Elixir: a documentação do Elixir foi pensada para ser fácil de ler e de escrever.
- A sintaxe Markdown é suportada dentro dos atributos de documentação `@moduledoc` e `@doc`
