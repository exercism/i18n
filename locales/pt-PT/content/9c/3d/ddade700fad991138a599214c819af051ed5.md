# Introdução

Em Go, todas as variáveis têm um valor.
Declarar uma variável sem lhe atribuir nenhum valor define-a com o valor zero do seu tipo.

Os tipos básicos, incluindo `bool`, os tipos numéricos e `string`, têm cada um um valor zero fixo:

| Tipo                   | Valor zero |
| ---------------------- | ---------- |
| bool                   | `false`    |
| int, int8, int64, etc. | `0`        |
| float32, float64       | `0`        |
| complex64, complex128  | `0+0i`     |
| string                 | `""`       |

Os apontadores, as funções, as interfaces, as slices, os canais e os mapas têm um valor zero igual a `nil`.

Os arrays e as structs nunca são `nil`, porque guardam os dados diretamente, e não uma referência a eles.
Cada elemento de um array e cada campo de uma struct é inicializado com o valor zero do seu próprio tipo.
Por exemplo, `var a [3]int` cria o array `[0, 0, 0]`.

## Declarar valores zero

Usa `var` para uma declaração:

```go
var myBool bool   // false
var mySlice []int // nil
```

Usa um literal composto `T{}` para structs:

```go
type Person struct {
    Name string
    Age  int
}

myPerson := Person{} // Person{Name: "", Age: 0}
```
