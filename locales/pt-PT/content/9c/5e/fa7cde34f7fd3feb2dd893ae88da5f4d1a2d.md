# Introdução

Os ciclos permitem repetir blocos de código. Em Rust existem três tipos de ciclos: o ciclo `for`, que permite iterar sobre os elementos de um iterador ou de uma coleção (tecnicamente, valores de qualquer tipo que implemente o trait `IntoIterator`), o ciclo `while`, que repete um bloco de código enquanto uma condição se verificar, e o ciclo `loop`, que repete código indefinidamente até que um `break` seja invocado explicitamente.
