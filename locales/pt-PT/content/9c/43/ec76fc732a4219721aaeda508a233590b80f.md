# Introdução

Os arrays são o principal tipo de sequência de comprimento fixo do Factor, escritos
`{ … }`: podes alterar os elementos, mas não o comprimento. Os vocabulários `arrays`
e `sequences`
dão-te, em conjunto, pequenos construtores que retiram valores da
pilha, além de operações do dia a dia para juntar, inverter e
consultar elementos.

```factor
USING: arrays sequences ;

42 1array .                ! => { 42 }
"a" "b" "c" 3array .       ! => { "a" "b" "c" }
{ { 1 2 } { 3 4 } } concat .   ! => { 1 2 3 4 }
{ 1 2 3 } reverse .            ! => { 3 2 1 }
```
