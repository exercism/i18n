# Apêndice às instruções

## Dicas

Para completares este exercício, precisas de implementar as seguintes funções:

- `territories` devolve as coordenadas (a começar em 1; o canto superior esquerdo é (1,1)) dos pontos de cada território, juntamente com quem é o «dono» do território.

- `territoriesFor` devolve o território que contém a coordenada, juntamente com o dono do território. Se a coordenada não apontar para um local vazio, devolve *Nothing*.

Um território pertence a um dos jogadores se as pedras desse jogador forem as únicas pedras adjacentes ao território.

Vais encontrar as assinaturas de tipo já no sítio, mas cabe-te a ti definir as funções.
