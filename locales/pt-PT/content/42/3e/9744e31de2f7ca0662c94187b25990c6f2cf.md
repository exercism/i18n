# Debug

Quando um teste falha, é apresentada uma mensagem a descrever o que correu mal.
Se quiseres mais informação, podes usar a sub-rotina `::YYY()` à volta do código que queres inspecionar.
(`::` é um atalho para `main::`).
Esta sub-rotina faz parte do módulo [XXX][XXX].

Também podes simplesmente imprimir uma mensagem com a função `say`, por exemplo, `say 'Hello, World!';`.

O test runner online usa o [Test Anything Protocol][TAP].
Devido à natureza do TAP, o uso de `print` no test runner online é fortemente desaconselhado.

[TAP]: https://testanything.org/
