# Anexo às instruções

## Registos

| Registo | Utilização | Tipo     | Descrição                                                         |
| ------- | ---------- | -------- | ----------------------------------------------------------------- |
| `$a0`   | entrada    | inteiro  | número                                                            |
| `$v0`   | saída      | boolean  | indica se é um número de Armstrong (`0` = `false`, `1` = `true`) |
| `$t0-9` | temporário | qualquer | usado para armazenamento temporário                               |
