# Testes

Cada exercício traz os testes unitários e uma receita de compilação do Make.
A implementação é tua.

Cada ficheiro de teste foi feito para ser ligado à tua implementação, de modo a produzir um executável de consola que corre os testes.
Ao correr o executável de testes, são impressas mensagens para cada teste que falha e é reportado um código de saída diferente de zero quando os testes falham.

Para trabalhar num exercício:
* Cria a compilação inicial com o Make
* Para cada teste unitário:
  * Remove a linha `TEST_IGNORE()`.
  * Resolve os erros de compilação para que o teste falhe.
  * Implementa apenas o necessário para que o teste passe.
  * Refatora a tua implementação para melhorar a legibilidade, reduzir a duplicação, etc.
