# Instruções

Neste exercício vais escrever um TreasureChest genérico (e mágico!) para guardar algum tesouro.

## 1. Define o tipo personalizado genérico TreasureChest

Define um tipo personalizado `TreasureChest` com uma única variante.

A variante deve ter um valor `String` associado, que será usado para guardar a palavra-passe do baú do tesouro.

A variante deve também ter um valor genérico associado, que será usado para guardar o tesouro.
Este valor é genérico para que o tesouro possa ser qualquer coisa.

## 2. Define a função getTreasure

Esta função deve receber dois parâmetros

- uma `String` (para tentar uma palavra-passe)
- um tipo personalizado genérico `TreasureChest`

Esta função deve comparar a tentativa de palavra-passe fornecida com a `String` no `TreasureChest`.

A função deve devolver um `Maybe`.

Se as palavras-passe coincidirem, devolve `Just` com o valor genérico do `TreasureChest` (o tesouro!)

Se as palavras-passe não coincidirem, devolve `Nothing`.

## 3. Define a função multiplyTreasure

Esta função (de ordem superior) deve receber dois parâmetros

- uma função multiplicadora que recebe um parâmetro genérico e devolve uma lista do mesmo tipo genérico
- um tipo personalizado genérico `TreasureChest`, também com o mesmo tipo genérico

Esta função deve chamar a função multiplicadora com o tesouro que está no baú.

A função deve devolver um novo TreasureChest, com a mesma palavra-passe do original e com o tesouro multiplicado (o valor devolvido)
