# Introdução

O Factor modela datas e horas com o vocabulário [`calendar`][calendar]. Um ponto no tempo é um `timestamp`; um intervalo de tempo é uma `duration`.

## Construir uma data

`<date>` (em [`calendar`][calendar]) constrói um `timestamp` à meia-noite do dia indicado:

```
<date> ( year month day -- timestamp )
```

```factor
USING: calendar ;

1904 11 16 <date> .
! a timestamp at midnight on 1904-11-16
```

`>date<` volta a dividir um timestamp nas suas partes:

```
>date< ( timestamp -- year month day )
```

```factor
1904 11 16 <date> >date< .   ! => 16   (with 1904 and 11 below it)
```

## Inspecionar uma data

`day-of-week` devolve o dia da semana como um número inteiro, `0` para Sunday até `6` para Saturday. `day-names` (em [`calendar.english`][english]) é a lista de nomes correspondente, por isso `day-names nth` transforma o número numa palavra:

```factor
USING: calendar calendar.english sequences ;

2024 1 8 <date> day-of-week .          ! => 1
day-names .   ! { "Sunday" "Monday" ... "Saturday" } — Sunday first
```

`leap-year?` aceita um ano (ou um timestamp) e `days-in-month` devolve o número de dias do mês de um timestamp, já a ter em conta os anos bissextos:

```
leap-year?    ( obj -- ? )
days-in-month ( timestamp -- n )
```

```factor
2024 leap-year? .                ! => t
2024 2 1 <date> days-in-month .  ! => 29
```

## Aritmética com datas

Palavras como `days`, `weeks` e `hours` constroem uma `duration`, e `time+` desloca um timestamp por uma delas:

```
days  ( x -- duration )
time+ ( timestamp duration -- timestamp )
```

```factor
2024 2 28 <date> 1 days time+ >date< .
! => 29   (2024-02-29, with 2024 and 2 below it)
```

A aritmética transita corretamente entre fronteiras de meses e de anos, e dois timestamps que nomeiam o mesmo instante comparam-se como iguais com `=`.

## Horas do dia

`<timestamp>` constrói um timestamp completo, até ao segundo. O seu último argumento é o desvio em relação ao UTC; `instant` (uma `duration` de zero) mantém o timestamp em UTC:

```
<timestamp> ( year month day hour minute second gmt-offset -- timestamp )
```

```factor
USING: calendar ;

1969 7 21 2 56 15 instant <timestamp> .
! a timestamp at 02:56:15 on 1969-07-21
```

`>time<` é a contraparte de `>date<`, dividindo um timestamp na sua hora, minuto e segundo:

```
>time< ( timestamp -- hour minute second )
```

```factor
1969 7 21 2 56 15 instant <timestamp> >time< .   ! => 15   (with 2 and 56 below it)
```

`seconds` e `minutes` constroem uma `duration` tal como `days`, `weeks` e `hours`, por isso qualquer uma delas pode ser passada a `time+`:

```
seconds ( x -- duration )
minutes ( x -- duration )
```

Os campos individuais de um timestamp leem-se com os acessores `year>>`, `month>>`, `day>>`, `hour>>`, `minute>>` e `second>>`:

```factor
1969 7 21 2 56 15 instant <timestamp> hour>> .   ! => 2
```
