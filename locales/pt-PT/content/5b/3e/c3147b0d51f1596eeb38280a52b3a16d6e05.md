# Dicas

## Geral

- Lê sobre [pattern matching][pattern-matching] no guia oficial.
- Dá uma vista de olhos a este guia rápido sobre [desestruturação][destructuring].
- O pattern matching de registos é [explicado aqui][records-pattern-matching] com mais detalhe.

## 1. Deteta comentários vazios

- Podes usar `(a, b)` diretamente no argumento da função, se o argumento for um par.
- Podes substituir os valores que recebes mas não usas pelo wildcard `_`.
- Para verificar se uma string está vazia, consulta a [documentação de `String`][string-docs].

## 2. Conta o número de comentários do criador

- Podes desestruturar um tipo personalizado com uma única variante `type Box = Box AB` diretamente num argumento de função, assim: `(Box ab)`.
- Podes usar pattern matching no campo `a` de um registo `{a : A, b : B}`, assim: `{ a }`.
- Podes usar as duas técnicas anteriores ao mesmo tempo em tipos personalizados que contêm um registo.
- Não podes fazer pattern matching diretamente ao par `ab` de um registo `{ ab : (A, B) }`. Tens de fazer pattern matching a `{ ab }` primeiro e só depois usar `( a, b) = ab` numa ligação `let`.
- Para encontrar o número de elementos que satisfazem uma condição numa lista, usa as [funções de `List`][list-docs].
- Podes desestruturar pares diretamente nos argumentos de funções anónimas.

## 3. Deteta tickets atribuídos à equipa de desenvolvimento

- Tal como na tarefa 2, podes fazer pattern matching aos campos relevantes de um registo «encaixotado» no argumento da função.
- Podes usar pattern matching de forma recursiva para corresponder a um valor aninhado, como `Just (Box "42")`.
- Podes usar o wildcard `_` para corresponder a qualquer coisa numa expressão `case`.

## 4. Atribui tickets aos funcionários de TI

- Tal como nas tarefas 2 e 3, podes fazer pattern matching aos campos relevantes de um registo «encaixotado» no argumento da função.
- Além disso, podes usar a palavra-chave `as` para fazer pattern matching a um campo e, ao mesmo tempo, ligar o registo inteiro: `(Box ({ a } as ab))`.
- Podes fazer pattern matching aos valores de um tipo personalizado com a expressão `case`.
- Usa o construtor de tipo `Ticket` para devolver um ticket.
- Usa a [sintaxe de atualização de registos][record-update] para modificar registos.
