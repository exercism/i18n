# Instruções

O novo aeroporto de Berlim contratou programadores para o seu laboratório de robôs e tu vais começar a trabalhar lá.
Têm robôs desajeitados, com um aspeto algo humanoide, que estão a tentar usar para melhorar o atendimento ao cliente.

A tua primeira tarefa é escrever um programa para que o robô consiga cumprimentar as pessoas na sua língua materna depois de estas digitalizarem o passaporte no balcão de check-in automático.

O robô tem orgulho nas suas capacidades, por isso diz sempre primeiro qual é a língua que sabe falar e só depois cumprimenta a pessoa.
Por exemplo, se alguém digitalizar um passaporte alemão, o robô diria:

```txt
I can speak German: Hallo Dietrich!
```

## 1. Cria a funcionalidade abstrata de saudação

Não vais escrever tu o código para as diferentes línguas, por isso tens de estruturar o código do robô de forma a que outros programadores possam acrescentar mais línguas facilmente no futuro.

Como primeiro passo, define uma interface `Greeter` com dois métodos.

- `LanguageName`, que devolve o nome da língua (uma `string`) na qual o robô deve cumprimentar o visitante.
- `Greet`, que recebe o nome do visitante (uma `string`) e devolve uma `string` com a mensagem de saudação numa língua específica.

A seguir, implementa uma função `SayHello` que recebe como argumentos o nome do visitante e qualquer coisa que implemente a interface `Greeter`, e devolve a string de saudação pretendida.
Por exemplo, imagina uma implementação alemã de `Greeter` para a qual `LanguageName` devolve `"German"` e `Greet` devolve `"Hallo {name}!"`:

```go
SayHello("Dietrich", germanGreeter)
// => "I can speak German: Hallo Dietrich!"
```

## 2. Implementa o italiano

Agora a tua tarefa é fazer com que o robô funcione para as pessoas que digitalizam passaportes italianos.

Para isso, cria uma struct `Italian` e implementa os dois métodos necessários para que a struct cumpra a interface `Greeter` que definiste na tarefa 1.
Podes cumprimentar alguém em italiano com `"Ciao {name}!"`.

## 3. Implementa o português

Antes de dares o dia por terminado, também deves acabar a funcionalidade para cumprimentar pessoas em português.

Para isso, cria uma struct `Portuguese` e implementa os dois métodos necessários para que a struct cumpra também aqui a interface `Greeter`.
Podes cumprimentar alguém em português com `"Olá {name}!"`.
