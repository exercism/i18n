# Adenda às instruções

## Dicas

Neste exercício, fornecemos a definição do
[tipo de dados algébrico](https://learnyouahaskell.github.io/making-our-own-types-and-typeclasses)
chamado `Planet`.
Tens de implementar a função `ageOn`, que calcula quantos
anos alguém teria num `Planet`, a partir de uma idade em segundos.

Podes usar a assinatura fornecida se não tiveres a certeza sobre os tipos, mas
não deixes que ela limite a tua criatividade:

```haskell
ageOn :: Planet -> Float -> Float
```
