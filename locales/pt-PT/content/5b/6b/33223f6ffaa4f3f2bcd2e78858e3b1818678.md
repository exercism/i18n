# Introdução

O PowerShell é uma linguagem de scripting dinâmica e de tipagem implícita (_mas que também suporta [variáveis fortemente tipadas][strong typed]_) da Microsoft, focada sobretudo na automatização de tarefas e na gestão de configuração.

O PowerShell suporta programação imperativa, funcional, orientada a objetos e até no estilo de pipeline.

O PowerShell foi construído sobre a plataforma .NET e lançado pela primeira vez em 2006.
Vem incluído por predefinição em todos os sistemas operativos Windows modernos e também pode ser instalado no Mac e no Linux.


## Variáveis

Há duas formas comuns de definir uma variável no PowerShell.

Os nomes das variáveis no PowerShell têm de começar por um `$`. Para associar o nome da variável a um valor, usa-se o operador de atribuição `=`.

```powershell
> $intVar = 1
> $doubleVar = 2.0
> $stringVar = "Hello"

# Checking a variable type using the GetType() method
> Write-Host $doubleVar.GetType()
System.Double
```

Também podes especificar explicitamente o tipo de uma variável, se quiseres impor/exigir que o valor seja de um determinado tipo.
O PowerShell faz tudo o que pode para converter o valor de um tipo para outro, se for possível.

```powershell
# String represents a floating number can be converted to integer
> [int]$staticOne = "1.234"
> $staticOne
1

# String of letters can not be converted to double type
> [double]$staticTwo = "hello"
MetadataError: Cannot convert value "hello" to type "System.Double"
```


### Constantes

As constantes no PowerShell são variáveis que não podem ser **alteradas** nem **removidas** depois de definidas.
Isto leva-nos à segunda forma de definir variáveis: usar o cmdlet `New-Variable`.

```powershell
> New-Variable -Name "MyConstant" -Value 100 -Option Constant
> $MyConstant
```

Para formas mais detalhadas e avançadas de criar uma nova variável, lê [New-Variable][New-Variable].


## Funções

As [funções][functions] no PowerShell são definidas com a palavra-chave `function`.
Cada função pode ter zero ou mais parâmetros formais nos parênteses `()`, seguidos do âmbito da função, que começa com `{` e termina com `}`.

```powershell
function Greeting {
    return "Hello!"
}
```

As funções no PowerShell podem devolver valores explicitamente através da palavra-chave `return`, depois de serem chamadas com a sintaxe `FuncName $Arg`.

```powershell
function AddTwoNumbers($NumOne, $NumTwo):
    $result = $NumOne + $NumTwo
    return $result

> AddTwoNumbers 10 20
30
```

Uma abordagem mais avançada a como escrever uma definição de função detalhada e a como as funções podem devolver valores implicitamente será abordada no módulo do conceito `Functions`.


## Comentários

Os comentários de uma só linha no PowerShell começam com um `#` e terminam no final da linha.
Os blocos de comentários no PowerShell começam com `<#` e terminam com `#>`.
Uma demonstração avançada de blocos de comentários para criar Comment-Based Help será abordada no módulo do conceito `Functions`.

```powershell
function Main() {
    #This is a comment
    <#
    And this is a comment block
    that can span multiple lines
    #>
}
```
