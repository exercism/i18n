# Introdução

Factor é uma linguagem *concatenativa*: cada palavra lê os seus valores de entrada de uma **pilha de dados** partilhada e volta a colocar nela os seus resultados. Não existe outra forma de fazer passar valores.

Escrever um literal coloca-o no topo da pilha; o código lê-se da esquerda para a direita:

```factor
1 2 3    ! stack (bottom → top): 1 2 3
```

Uma declaração de *efeito de pilha* documenta o contrato de uma palavra:

```factor
: restow ( a b -- b a ) swap ;
```

`( a b -- b a )` indica que a palavra retira dois valores da pilha e deixa lá dois, pela ordem inversa. Os nomes servem apenas de documentação, só o *número* de parâmetros de entrada e de resultados é verificado pelo compilador, e o topo da pilha é o nome mais à direita.

As **palavras de reorganização** do `kernel`, que usas no dia a dia, mudam a ordem do topo da pilha:

```
dup  ( x   -- x x   )
drop ( x   --       )
swap ( x y -- y x   )
over ( x y -- x y x )
nip  ( x y -- y     )
rot  ( x y z -- y z x )
```

As palavras definem-se com `:` e terminam em `;`; o compilador recusa uma definição cujo corpo não corresponda ao efeito declarado.
