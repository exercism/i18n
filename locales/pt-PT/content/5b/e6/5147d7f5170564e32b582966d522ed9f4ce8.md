# Introdução

Trabalhas numa empresa que cria um jogo multijogador online chamado Lexiconia.

Para jogar, cada jogador recebe 13 letras, que tem de reorganizar para formar palavras. Letras diferentes valem pontos diferentes, porque é mais fácil formar palavras com umas letras do que com outras.

O jogo foi lançado originalmente em inglês, mas é muito popular, e agora a empresa quer expandir-se também para outras línguas.

Línguas diferentes precisam de ter pontuações diferentes para as letras.
As pontuações são determinadas pela frequência com que as letras são usadas, em comparação com as outras letras dessa língua.

Por exemplo, a letra 'C' é bastante comum em inglês e vale apenas 3 pontos.
Mas, em norueguês, é uma letra muito rara e vale 10 pontos.

Para ser mais fácil adicionar novas línguas, a tua equipa precisa de mudar a forma como as letras e as respetivas pontuações são guardadas no jogo.
