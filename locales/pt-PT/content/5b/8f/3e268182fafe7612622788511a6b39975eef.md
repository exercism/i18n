# Instruções

Neste exercício, vais simular um sistema informático baseado em janelas.
Vais criar algumas janelas que podem ser movidas e redimensionadas.
A imagem seguinte ilustra os valores com que vais trabalhar a seguir.

```text
 ╔════════════════════════════════════════════════════════════╗
 ║                                                            ║
 ║        position::$y,_                                      ║
 ║        position::$x  \                                     ║
 ║                       \<---- size::$width ---->            ║
 ║                 ^      *──────────────────────┐            ║
 ║                 |      │        title         │            ║
 ║                 |      ├──────────────────────┤            ║
 ║                 |      │                      │            ║
 ║          size::$height │                      │            ║
 ║                 |      │       contents       │            ║
 ║                 |      │                      │            ║
 ║                 |      │                      │            ║
 ║                 v      └──────────────────────┘            ║
 ║                                                            ║
 ║                                                            ║
 ╚════════════════════════════════════════════════════════════╝
```

## 1. Define as propriedades da janela do programa

Usando a estrutura de classe fornecida, define as propriedades para os valores `y`, `x`, `height` e `width`.

```php
<?php

$window = new ProgramWindow();
$window->y; // => null
$window->x; // => null
$window->height; // => null
$window->width; // => null
```

## 2. Define os valores iniciais da janela do programa

Define um construtor para `ProgramWindow`.
Não deve receber quaisquer argumentos, mas durante a execução do construtor define os valores predefinidos das suas propriedades.
Deve definir os valores iniciais de `y` e `x` como `0`.
Deve definir a `height` e a `width` iniciais para um tamanho de ecrã de `600x800`.

```php
<?php

$window = new ProgramWindow();
$window->y; // => 0 
$window->x; // => 0
$window->height; // => 600
$window->width; // => 800
```

## 3. Define uma função para redimensionar a janela

Define uma nova classe em `Size.php` para uma classe Size.
Deve receber argumentos do construtor para definir as propriedades `height` e `width`.
Além disso, `ProgramWindow` precisa de uma função de redimensionamento, que recebe a instância do objeto `Size` e atualiza as suas próprias propriedades.

```php
<?php 

$window = new ProgramWindow();
$size = new Size(764, 1080);
$window->resize($size)

$window->height;
// => 764
$window->width;
// => 1080
```

## 4. Define uma função para mover a janela

Define uma nova classe em `Position.php` para uma classe Position.
Deve receber argumentos do construtor para definir as propriedades `y` e `x`.
Além disso, `ProgramWindow` precisa de uma função de movimento, que recebe a instância do objeto `Position` e atualiza as suas próprias propriedades.

```php
<?php 

$window = new ProgramWindow();
$position = new Position(80, 313);
$window->move($position)

$window->y;
// => 80
$window->x;
// => 313
```
