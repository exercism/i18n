# Dicas

## Geral

- Consegues realizar todas estas tarefas sem usar uma condicional `if`.

## 1. Determina se vais precisar de carta de condução

- Usa o [operador de igualdade][cmp] para verificar se o primeiro campo é igual a uma determinada string.
- Usa uma expressão regular para verificar se o segundo campo contém as substrings necessárias.
- Usa um dos dois [operadores booleanos][bool] para combinar os dois requisitos.

## 2.Calcula uma estimativa do preço de um veículo usado

- Usa os [operadores de comparação][cmp] para determinar qual desconto usar.

[cmp]: https://www.gnu.org/software/gawk/manual/html_node/Comparison-Operators.html
[bool]: https://www.gnu.org/software/gawk/manual/html_node/Boolean-Ops.html
