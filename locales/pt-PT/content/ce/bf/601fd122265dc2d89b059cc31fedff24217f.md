# Introdução

Em Haxe, uma `String` é um objeto que representa texto imutável como uma sequência de carateres Unicode (letras, algarismos, pontuação, etc.). Usam-se aspas duplas para definir uma instância de `String`:

```haxe
var fruit:String = "Apple";
```

As strings são manipuladas ao chamar os métodos da string. Uma vez construída, o valor de uma string nunca pode mudar. Quaisquer métodos que pareçam modificar uma string devolvem, na verdade, uma nova string.

É possível concatenar (somar) várias strings umas às outras. A forma mais simples de o fazer é usar o operador `+`.

```haxe
var name:String = "Jane";
trace("Hello " + name + "!");
// => "Hello Jane!"
```

Para qualquer formatação de strings mais complexa do que uma simples concatenação, prefere-se a interpolação de strings. Para usar interpolação numa string, coloca-a entre aspas simples (`'`). Depois, podes usar o cifrão (`$`) para ativar a interpolação:

```haxe
var name:String = "Jane";
trace('Hello $name!');
// => "Hello Jane!"
```
