# Introdução

O sistema de erros do Factor é composto por três peças: `throw` (em
[`kernel`][kernel]) lança um erro, `recover` (em
[`continuations`][continuations]) captura-o, e `ERROR:` define
uma classe de erro do tipo tuplo.

```factor
! "file not found" throw          (raises a string as the error)

[ "boom" throw ] [ drop "caught" ] recover .
! => "caught"
```

`recover ( try recovery -- )` executa a quotation *try*; se esta
lançar um erro, o erro é colocado na pilha e a quotation *recovery* é
executada.

`ERROR:` declara a classe *e* uma palavra construtora que
lança uma nova instância:

```factor
! DOCTEST: SKIP
ERROR: not-found path ;

"/missing" not-found
! throws T{ not-found { path "/missing" } }
```

[kernel]: https://docs.factorcode.org/content/vocab-kernel.html
[continuations]: https://docs.factorcode.org/content/vocab-continuations.html
