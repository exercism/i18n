# API do Exercism

## Descrição

A maioria dos percursos de linguagem do Exercism usa a ferramenta de linha de comandos `exercism` para obter e submeter exercícios, que interage com o `exercism.io` através de uma API REST. O percurso de linguagem Pharo Smalltalk, por sua vez, usa a mesma API REST para trazer e retirar exercícios da imagem Pharo sem recorrer a qualquer ferramenta intermediária. Este documento descreve a API do Exercism, com especial atenção à forma como é usada pelo percurso de linguagem Pharo Smalltalk. Destina-se aos responsáveis pela manutenção das ferramentas de Pharo Smalltalk.

## Cabeçalhos

Todos os endpoints exigem que os cabeçalhos do pedido sejam definidos com os seguintes valores:

```
Authorization: Bearer <token>
```

O valor `<token>` é o token de autenticação da CLI do utilizador, disponível em `https://exercism.io/my/settings`.

## Obter exercícios

```
Content-Type: application/json
```

`GET api.exercism.io/v1/solutions/latest?exercise_id=<slug>&track_id<language> HTTP/1.1`

No URL acima, `<slug>` é o nome do exercício, por exemplo `hello-world`, e `<language>` é o percurso de linguagem, por exemplo `pharo-smalltalk`.

### Resposta

#### 200

Um pedido bem-sucedido devolve uma resposta com um payload JSON. Dentro do JSON estão informações sobre o exercício e um URL a partir do qual podes descarregar os ficheiros do exercício.

```json
"solution":{
	"id":"<id-string>",
	"url":"https://exercism.io/my/solutions/<id-string>",
	"team":null,
	"user":{
		"handle":"<exercism-user-name>",
		"is_requester":true
		},
		"exercise":{
			"id":"isogram",
			"instructions_url":"https://exercism.io/my/solutions/<id-string>",
			"auto_approve":false,
			"track":{
				"id":"pharo-smalltalk",
				"language":"Pharo"
				}
			},
			"file_download_base_url":"https://api.exercism.io/v1/solutions/<id-string>/files/",
			"files":[
				"IsogramTest.class.st",
				"README.md"
				],
			"iteration":null
		}
	}
```

#### 400

O nome do percurso de linguagem é ambíguo ou os ficheiros de exercício submetidos não foram alterados.

#### 403

A solução não está desbloqueada para o utilizador ou este não aderiu ao percurso de linguagem.

#### 404

Não foi possível encontrar o percurso de linguagem ou o exercício.

## Submeter exercícios

```
Content-Type: application/octet-stream
```

`PATCH api.exercism.io//v1/solutions/<some-kind-of-token-or-hash> HTTP/1.1`

### Resposta

#### 201

Uma submissão bem-sucedida.

#### 400

Um ficheiro submetido é demasiado grande (mais de um megabyte) ou a solução é uma duplicação.

#### 403

O utilizador não tem acesso à solução. O ID de utilizador da solução e o ID de utilizador atual não coincidem.

#### 404

O ID da solução não foi encontrado.
