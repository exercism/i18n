# Dicas

## 1. Analisar a data da marcação

- A classe `LocalDateTime` tem um método para [analisar][localdatetime-parse] uma `String` e convertê-la numa `LocalDateTime`.
- Usa um [`DateTimeFormatter`][datetimeformatter-docs] com um padrão personalizado para analisar um formato de data/hora não padrão.

## 2. Verificar se uma marcação já passou

- As instâncias de `LocalDateTime` têm [métodos][localdatetime-methods] para as comparar com outras `LocalDateTime`.
- Existe um [método][localdatetime-methods] para obter a data e a hora atuais.

## 3. Verificar se a marcação é à tarde

- Podes aceder à parte da hora de uma instância de `LocalDateTime` através de um dos seus [métodos][localdatetime-methods].

## 4. Descrever a hora e a data da marcação

- Usa um [`DateTimeFormatter`][datetimeformatter-docs] com um padrão personalizado para formatar a `LocalDateTime`.
- Os testes correm como se estivessem a correr numa máquina nos Estados Unidos, por isso certifica-te de que o formatador [usa a região correta][datetimeformatter-ofpattern-with-locale].

## 5. Devolver a data de aniversário

- A classe `LocalDate` tem um [método][localdate-methods] para obter a data atual.
- Podes aceder ao ano de uma instância de `LocalDate` através de um dos seus [métodos][localdate-methods].
