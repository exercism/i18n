# usa guards

[comment]: # (Este erro é apresentado quando a solução não usa guards de todo)

Usa [guards](https://hexdocs.pm/elixir/master/guards.html) para impedires que `two_fer/1` execute código com valores de entrada que não sejam binários.

> Lembra-te de que, em Elixir, as [strings](https://elixir-lang.org/getting-started/binaries-strings-and-char-lists.html) são consideradas [dados binários](https://elixir-lang.org/getting-started/binaries-strings-and-char-lists.html).

```elixir
# Consider this function with a guard:
def hello(what) when is_binary(what) do
  "Hello, #{what}!"
end
```

> Podes testar este guard no `iex`

```shell
iex> hello("world")
"Hello, world!"
iex> hello(123)
** (FunctionClauseError) no function clause matching in hello/1

    The following arguments were given to hello/1:

        # 1
        123
```
