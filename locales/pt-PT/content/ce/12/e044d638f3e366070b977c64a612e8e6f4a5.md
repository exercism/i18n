# Dicas

## 1. Hora de misturar um sumo

- O `cond` (em [`combinators`][combinators]) é a forma mais limpa de
  escolher um valor com base numa cadeia de testes de igualdade.

## 2. Reabastecer a reserva de gomos de lima

- Um ciclo `while` com dois valores de estado (os gomos ainda
  necessários e as limas ainda disponíveis) é a escolha natural.
  Declará-los com `::` e `:> name!` mantém o corpo legível.
- O `unclip ( seq -- rest first )` retira a primeira lima, pronta
  para alimentar o `wedges-from-lime`.

## 3. Listar os tempos de mistura de cada pedido na fila

- Uma palavra de [`sequences`][sequences] faz o trabalho todo.

## 4. Terminar o turno

- A forma é a mesma da tarefa 2: um ciclo `while` conduzido por dois
  valores de estado (os minutos que faltam no turno e os pedidos ainda
  à espera). Para assim que um deles acabar.

[combinators]: https://docs.factorcode.org/content/vocab-combinators.html
[sequences]: https://docs.factorcode.org/content/vocab-sequences.html
