# Sobre funções de ordem superior

As funções em Kotlin são cidadãs de primeira classe.
Isto significa que podem ser guardadas em variáveis, passadas como argumentos e até devolvidas por outras funções.
Por exemplo, atribuir uma função à variável `addOne`:

```kotlin
val addOne = fun (num : Int) : Int {
    return num + 1
}
```

Uma função também pode devolver outra função:

```kotlin
fun makeAddOne() : (Int) -> Int {
    return fun(num : Int) : Int {
        return num + 1
    }
}
```

Depois de atribuída, a função pode ser chamada através da variável como se fosse apenas mais uma função:
```kotlin
addOne(3)
// => 4
```

## Declarar tipos de função

O tipo de uma variável ou de um parâmetro pode ser declarado com a sintaxe `(parameter types) -> return type`.
Por exemplo, para declarar uma variável:

```kotlin
val addOne : (Int) -> Int = fun (num : Int) : Int {
    return num + 1
}
```

E para um parâmetro de função:

```kotlin
fun perform(operation : (Int) -> Int) {
    operation(3)
}
```

## Expressões lambda

Uma expressão lambda é uma forma mais curta de definir uma função.
Escrevem-se na forma `{ parameters -> body }`.
A expressão devolve o último valor da última instrução do corpo.
Por exemplo:

```kotlin
// Assigning to a variable
val addOne = { num : Int -> num +  1}

// In a function call
perform({ num : Int -> num + 1 })
```

O Kotlin consegue inferir tipos quando há informação suficiente.
Por exemplo, os exemplos acima também podem ser escritos assim:

```kotlin
// Assigning to a variable
val addOne : (Int) -> Int = { num -> num + 1 }

// Or ...
val addOne  = { num : Int -> num + 1 }

// Using in a function
perform({ num -> num + 1 })
```

## `it` para expressões lambda com um único parâmetro

Quando a expressão tem apenas um parâmetro, o parâmetro pode ser omitido.
O Kotlin disponibiliza então, no corpo, um parâmetro chamado `it`.
Por exemplo:

```kotlin
val addOne : (Int) -> Int = { it +  1 }
```

## Passar expressões lambda à direita

Quando o último argumento de uma função é uma expressão lambda, essa expressão escreve-se diretamente _depois_ dos parênteses.
Por exemplo:

```kotlin
// Function that takes a function as last argument
fun calculateFrom(from : Int, operation : (Int) -> Int) : Int {
    return operation(from)
}

// Call the calculateFrom function
calculateFrom(2) { it * 3 }
// => 6
```
