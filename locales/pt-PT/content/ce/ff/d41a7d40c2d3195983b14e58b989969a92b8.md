# Sobre

Futhark é uma linguagem de programação puramente funcional, concebida para computação paralela de dados de alto desempenho. Embora partilhe algumas semelhanças de sintaxe e de estrutura com linguagens funcionais como Haskell e Standard ML, o seu foco é outro. Em vez de dar ênfase a sistemas de tipos ricos ou à máxima expressividade, o Futhark procura gerar código paralelo eficiente. No centro do Futhark estão as operações em massa sobre arrays, conhecidas como combinadores de array de segunda ordem (SOACs), tais como `map`, `reduce` e `filter`, que se assemelham às funções de ordem superior familiares noutras linguagens funcionais. Estes SOACs são definidos com semântica sequencial, mas são concebidos para ser compilados em execução paralela, o que permite obter clareza e desempenho.
