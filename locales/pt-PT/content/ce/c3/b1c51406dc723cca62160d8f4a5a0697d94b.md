# Ordem dos problemas do percurso de Rust

A fonte de verdade efetiva da ordem dos problemas e dos tópicos é [config.json](config.json), mas este ficheiro documenta o raciocínio por trás da ordem dos problemas definida nesse mesmo ficheiro.

## A nossa abordagem

Ordenamos os problemas a pensar em estudantes que estão a aprender Rust. Com esse público em mente, seguimos duas regras quando adicionamos novos problemas.

- Um exercício deve introduzir um único conceito novo
- Os exercícios devem progredir das bases de Rust até conceitos avançados de Rust

### Um conceito novo

Se a solução de um problema exigir que os estudantes usem tanto `Result` como `HashMap`, pelo menos um destes conceitos deve ter sido introduzido por um problema anterior.

Se o percurso tiver vários problemas que dependem de um conceito, agrupa-os para reforçar a aprendizagem.

### Progressão em Rust

#### Problemas iniciais

Os problemas iniciais devem centrar-se na sintaxe e nos conceitos de Rust que existem em muitas linguagens de programação: condicionais, ciclos, funções de ordem superior.

#### Problemas intermédios

Os problemas a meio do percurso devem introduzir conceitos menos comuns. `Result` e `Option` e traits, por exemplo. Ou sintaxe como `while let`.

Ao longo da secção intermédia do percurso, os estudantes devem familiarizar-se com uma grande variedade de conceitos de Rust.

#### Problemas finais

Os problemas no final do percurso devem fazer uma de duas coisas:

1. Introduzir conceitos avançados: lifetimes, concorrência, unsafe
2. Exigir uma solução complexa que sintetize todos os conhecimentos que os estudantes adquiriram até à data
