# Anexo às instruções

## Notas específicas do exercício em Rust

Esta versão em Rust é ligeiramente diferente das versões deste exercício noutras linguagens. Em vez de te pedir para devolveres erros para valores fora do intervalo, usamos o sistema de tipos forte de Rust para limitar os valores de entrada. É muito mais fácil fazer com que uma função lide com todos os valores de entrada válidos do que exigir a quem usa o teu módulo que trate dos erros.

### Extensão

Acrescenta a capacidade de converter até ao valor máximo de u64: `18_446_744_073_709_551_615`.

Para teres uma ideia da saída que isto deve produzir, vê o último caso de teste.
