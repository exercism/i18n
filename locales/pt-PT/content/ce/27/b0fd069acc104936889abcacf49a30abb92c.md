# Dicas

## 1. Descreve um caráter

- Altera os [construtores][constructor-syntax] das classes `Wizard` e `Warrior` para passarem o tipo de caráter respetivo ao [construtor da classe base][instance-constructors].
- Guarda o tipo de caráter num [campo][fields] da classe `Character`.
- A classe `Character` herda implicitamente da classe `object`, cujo [método `ToString()` podes substituir][override-tostring].

## 2. Faz com que os carateres não sejam vulneráveis por predefinição

- Implementa o método `Vulnerable()` na classe `Character` para devolver sempre `false`.

## 3. Permite que os Wizards preparem uma magia

- Adiciona um campo à classe `Wizard` para guardar se uma magia foi preparada e atualiza-o no método `PrepareSpell()`.
- Ao início, a magia não deve estar preparada.

## 4. Torna os Wizards vulneráveis quando não tiverem preparado uma magia

- Substitui o método `Vulnerable()` na classe `Wizard` para tornar os Wizards vulneráveis se não tiverem preparado uma magia.

## 5. Calcula os pontos de dano de um Wizard

- Utiliza uma [condicional][if-else] para devolver os pontos de dano, tendo em conta o valor do campo que indica se a magia foi preparada.

## 6. Calcula os pontos de dano de um Warrior

- Podes chamar um método à instância de `Character` recebida para determinas a sua vulnerabilidade.
- Utiliza uma [condicional][if-else] para devolver os pontos de dano, tendo em conta a vulnerabilidade do alvo.
