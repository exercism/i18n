# Introdução

Fazer malabarismos com a pilha funciona bem para palavras curtas. Quando uma palavra tem
vários parâmetros de entrada e precisas de te referir a eles pelo nome, o Factor
oferece-te os *locals*: ligações com nome introduzidas com `::` (para definições de
palavras) ou `[| | ]` (para lambdas em linha), ambos fornecidos por
[`locals`][locals].

```factor
USING: locals ;

:: hypotenuse ( a b -- c )
    a a *
    b b *
    + sqrt ;
```

Dentro de uma quotation, `[| inputs | body ]` é uma lambda com parâmetros de entrada
nomeados:

```factor
USING: assocs locals ;

H{ { "a" 1 } { "b" 2 } }
[| key value | key value 10 * ] assoc-map .
! => H{ { "a" 10 } { "b" 20 } }
```

[locals]: https://docs.factorcode.org/content/vocab-locals.html
