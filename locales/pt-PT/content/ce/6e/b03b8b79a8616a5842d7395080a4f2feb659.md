# Anexo às instruções

## Algumas notas adicionais para a implementação em C++

Este exercício usa o [`unordered_set`][set]
Provavelmente precisas da função [`emplace`][emplace] para adicionar elementos ao conjunto.

Podes deparar-te com [`const`][const], porque ainda não apareceu no programa.
Quando precede uma variável, funciona como uma salvaguarda.
As variáveis `const` não podem ser alteradas.
Este exercício também usa a palavra-chave [`unsigned`][unsigned].
Isto duplica o intervalo do número inteiro a que se aplica, mas não deixa que ele se torne negativo.


[set]: https://en.cppreference.com/w/cpp/container/unordered_set
[emplace]: https://en.cppreference.com/w/cpp/container/vector/emplace
[const]: https://www.learncpp.com/cpp-tutorial/const-variables-and-symbolic-constants/
[unsigned]: https://www.learncpp.com/cpp-tutorial/unsigned-integers-and-why-to-avoid-them/
