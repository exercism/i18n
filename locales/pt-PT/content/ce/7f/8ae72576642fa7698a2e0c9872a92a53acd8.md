# Dicas

## Geral

- Lembra-te de que a sobrecarga de operadores em Cairo é implementada através de traits
- O atributo `#[derive(PartialEq)]` implementa automaticamente a comparação de igualdade
- Quando implementas `PartialOrd`, só precisas de implementar o método `lt`; os restantes operadores de comparação são derivados a partir dele

## 1. Implementar `Add`

- O método `add` deve combinar os campos `value` dos dois TimeShards
- Lembra-te de que os TimeShards contêm valores `i32`, que já têm a adição definida

## 2. Implementar `Sub`

- Semelhante à adição, mas usa o operador de subtração entre os campos `value`
- A ordem dos operandos é importante na subtração

## 3. Implementar `PartialOrd`

- O método `lt` deve comparar os campos `value` dos TimeShards
- Depois de o `lt` estar implementado, os restantes operadores de comparação (`>`, `<=`, `>=`) funcionam automaticamente
- Lembra-te de que o `PartialEq` já é derivado, por isso não precisas de o implementar manualmente
