# Instruções

Neste exercício vais construir o tratamento de erros de uma calculadora simples.

O objetivo é teres uma calculadora funcional que devolve uma string com o seguinte padrão: `16 + 51 = 67`, quando recebe os argumentos `16`, `51` e `+`.

```ruby
SimpleCalculator.calculate(16, 51, "+")
# => "16 + 51 = 67"
SimpleCalculator.calculate(32, 6, "*")
# => "32 * 6 = 192"
SimpleCalculator.calculate(512, 4, "/")
# => "512 / 4 = 128"
```

## 1. Trata o código que pode lançar erros dentro do método `calculate`

O método principal a implementar nesta tarefa será o método de classe `SimpleCalculator.calculate()`.
Recebe três argumentos.
Os dois primeiros argumentos são números sobre os quais vai ser realizada uma operação.
O terceiro argumento é do tipo string e, para este exercício, é necessário implementar as seguintes operações:

- adição, usando a string `+`
- multiplicação, usando a string `*`
- divisão, usando a string `/`

## 2. Trata operações ilegais

Atualiza o método `SimpleCalculator.calculate()` para lançar uma exceção `UnsupportedOperation` quando o símbolo da operação é desconhecido.

```ruby
SimpleCalculator.calculate(1, 2, '-')
# => Raises an UnsupportedOperation
```

~~~~exercism/note
Neste exercício, espera-se que definas a exceção `UnsupportedOperation` para um âmbito específico.
~~~~

## 3. Trata argumentos inválidos

Atualiza o método `SimpleCalculator.calculate()` para lançar uma exceção `ArgumentError` quando os tipos dos argumentos são inválidos.

```ruby
SimpleCalculator.calculate(1, '2', '*')
# => Raises an ArgumentError
```

## 4. Trata exceções DivideByZero

Atualiza o `SimpleCalculator.calculate()` para tratar exceções `ZeroDivisionError`.
O código de tratamento deve devolver a string com o conteúdo `Division by zero is not allowed.`.
Qualquer outra exceção não deve ser tratada pelo método `SimpleCalculator.calculate()`.

```ruby
SimpleCalculator.calculate(512, 0, "/")
# => returns "Division by zero is not allowed."
```
