# Instruções

Implementa uma função com lógica proposicional para 
recriar as seguintes propriedades:

1. A & B == (A' | B')' (Lei de De Morgan)
2. [A -> (A -> B)] -> (A -> B)
3. A & (B' -> A') -> B

A função deve devolver os três teoremas escritos em notação Z3.  
Usa a função prove() para confirmar a exatidão dos teus teoremas.  
Devolve os três teoremas, por ordem, no final da função.
