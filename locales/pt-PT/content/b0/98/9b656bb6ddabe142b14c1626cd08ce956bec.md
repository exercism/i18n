# Introdução

Uma `String`, em Julia, é uma sequência ordenada de carateres. Como o manual salienta: "Claro que a verdadeira dificuldade surge quando alguém pergunta o que é um caráter."

Grande parte desta complexidade será abordada com mais detalhe no conceito `Chars`, mas, em resumo:

- Todas as strings em Julia são Unicode.
- As strings que também são ASCII (letras inglesas de A a Z, maiúsculas e minúsculas, algarismos e alguns carateres de pontuação) são _fáceis_ de usar.
- A maioria dos outros sistemas de escrita do mundo é _possível_ de usar, mas exige mais cuidado.

## Literais de strings

Em geral, as strings são delimitadas por aspas duplas `" "`.
As aspas simples `' '` servem apenas para `Chars`.

Também é possível usar aspas duplas triplas `""" """`, o que permite usar `"` dentro da string sem escapar.
Mais importante ainda, a indentação extra indesejada é removida das strings com várias linhas.

```julia-repl
julia> """
       Multiline
       String
       """
"Multiline\nString\n"
```

### Escapar carateres

Como a maioria das linguagens a partir do C, Julia usa uma barra invertida `\` para escapar:

1. Para introduzir carateres não imprimíveis, como a nova linha `\n` do exemplo anterior.
2. Para proteger carateres que, de outro modo, teriam um significado especial, como `\$` (ver abaixo).

## Indexação

Em princípio, as strings podem ser indexadas exatamente como os vetores:

```julia-repl
julia> s[1], s[5]
('J', 'a')
```

Isto funciona claramente para uma string ASCII como "Julia", mas ignora a maioria das línguas do mundo.

Considera um dos carateres de Beowulf, escrito em inglês antigo há cerca de 15 séculos.

"Hrōðgār" tem claramente 7 carateres, mas nem todos são ASCII.

```julia-repl
julia> king = "Hrōðgār"
"Hrōðgār"

julia> length(king)
7

julia> isascii(king)
false

# collect() converts to a Char vector:
julia> collect(king)
7-element Vector{Char}:
 'H': ASCII/Unicode U+0048 (category Lu: Letter, uppercase)
 'r': ASCII/Unicode U+0072 (category Ll: Letter, lowercase)
 'ō': Unicode U+014D (category Ll: Letter, lowercase)
 'ð': Unicode U+00F0 (category Ll: Letter, lowercase)
 'g': ASCII/Unicode U+0067 (category Ll: Letter, lowercase)
 'ā': Unicode U+0101 (category Ll: Letter, lowercase)
 'r': ASCII/Unicode U+0072 (category Ll: Letter, lowercase)
```

A indexação de uma string como esta começa bem, mas, a certa altura, deixa de funcionar:

```julia-repl
julia> king[3]
'ō': Unicode U+014D (category Ll: Letter, lowercase)

julia> king[4]
ERROR: StringIndexError: invalid index [4], valid nearby indices [3]=>'ō', [5]=>'ð'
```

O problema é que este tipo de indexação conta _bytes_, que, nas strings não ASCII, não têm uma relação de 1:1 com os carateres.
Um caráter Unicode/UTF-8 pode precisar de até 4 bytes para ser representado, e o conceito `Chars` vai explorar isto mais a fundo.

## Construir strings

### Concatenação

Muitas linguagens usam `+` como operador de concatenação de strings, mas Julia não.
Pelo menos, a mensagem de erro é útil.

```julia-repl
julia> "s1 " + "s2"
ERROR: MethodError: no method matching +(::String, ::String)
The function `+` exists, but no method is defined for this combination of argument types.
String concatenation is performed with * 

julia> "s1 " * "s2"
"s1 s2"
```

A função `string()` concatena um número arbitrário de strings.

```julia-repl
julia> string("lots ", "of ", "bits")
"lots of bits"
```

A função `join()` faz o mesmo e também aceita um vetor de strings, concatenando-as com um separador dado (por omissão, `""`).

```julia-repl
julia> join(["lots", "of", "bits"], "_")
"lots_of_bits"
```

Repara que as strings são imutáveis e que a concatenação implica cópias.
Por isso, concatenações repetidas dentro de um ciclo são ineficientes; é melhor reunir os fragmentos num vetor e juntá-los todos no fim.

### Repetição

Simples:

```julia-repl
julia> repeat("Abc", 5)
"AbcAbcAbcAbcAbc"
```

### Interpolação

Muitas linguagens têm forma de inserir valores calculados nas strings, embora haja um desacordo extraordinário sobre a melhor sintaxe a usar.

Em Julia, os valores interpolados são precedidos de `$`.

```julia-repl
julia> myvar = 42
42

julia> "myvar evaluates to $myvar"
"myvar evaluates to 42"

julia> r = 5.3
5.3

julia> "A circle of radius $r has area $(π * r^2)"
"A circle of radius 5.3 has area 88.24733763933729"
```

Os parênteses são obrigatórios quando a sua omissão seria ambígua, mas são opcionais para um único identificador seguido de espaço em branco.

Para incluir um $ na string, escapa-o como `\$`.

Repara na limitação de que, atualmente, a interpolação não permite formatação, como o número de casas decimais a apresentar.

### `@sprintf()`

Para um controlo mais fino sobre a construção de strings, Julia copia a função `sprintf` do C (e de várias linguagens posteriores: a Wikipédia lista cerca de 30).

Em Julia, isto está implementado como uma `macro` dentro do módulo `Printf`, daí o prefixo `@`.

```julia-repl
julia> using Printf

julia> r = 5.3
5.3

julia> @sprintf("A circle of radius %.1f has area %.2f", r, π * r^2)
"A circle of radius 5.3 has area 88.25"
```

## Funções de strings

Por simplicidade, esta secção vai centrar-se nas funções que devolvem uma nova string e deixam o valor de entrada inalterado.
Muitas têm um equivalente, com o sufixo `!`, que modifica o valor de entrada no local.

### Comprimento

Qual é o comprimento de uma string?
Às vezes, depende de como contas.

O caso simples são as strings ASCII, em que cada caráter ocupa 1 byte.

```julia-repl
julia> string_asc = "Julia"
"Julia"

julia> length(string_asc)
5

julia> sizeof(string_asc)
5
```

A função `length()` devolve o número de _carateres_ e a função `sizeof()` o número de _bytes_.

Esta distinção torna-se importante com outros conjuntos de carateres:

```julia-repl
julia> king = "Hrōðgār"
"Hrōðgār"

julia> length(king)
7

julia> sizeof(king)
10
```

### Divisão

Uma operação comum em programação é pegar numa string comprida e dividi-la em partes, com base numa string separadora de um ou mais carateres.

De um modo geral, usamos a função `split()`.
O separador, por omissão, é (qualquer) espaço em branco, mas é possível indicar outros.

```julia-repl
julia> split("my little string")
3-element Vector{SubString{String}}:
 "my"
 "little"
 "string"

julia> split("My_snake_case_string", "_")
4-element Vector{SubString{String}}:
 "My"
 "snake"
 "case"
 "string"
```

Estes exemplos dividem uma string em _strings_ mais pequenas.
Dividir uma string em _carateres_ é uma operação diferente.

### Procurar e substituir

Determinada substring está contida numa string?
Curiosamente, há duas funções para testar isto: `occursin()` e `contains()` diferem apenas na ordem dos argumentos.

```julia-repl
julia> needle = "Julia"
"Julia"

julia> haystack = "Python, Julia and R"
"Python, Julia and R"

julia> occursin(needle, haystack)
true

julia> contains(haystack, needle)
true
```

Para sermos mais específicos quanto à posição:

```julia-repl
julia> startswith(haystack, "Python")
true

julia> endswith(haystack, "Python")
false
```

Para obter os índices início:fim de uma substring, temos várias funções:

- `findfirst()`
- `findlast()`
- `findprev()`
- `findnext()`

```julia-repl
julia> findfirst(needle, haystack)
9:13
```

Para substituir substrings, lista as alterações com a sintaxe `x => y`.

```julia-repl
julia> replace("abc", "a"=>"b", "b"=>"c", "c"=>"a")
"bca"
```

Desde a versão 1.7 de Julia, a função `replace` pode receber um número arbitrário de alterações, com a garantia de que nenhum caráter é alterado mais do que uma vez durante a substituição.

A sintaxe `x => y` chama-se `pair`, um tipo importante em Julia, abordado com mais detalhe no conceito `Dicts and Pairs`.

### Espaços em branco

Muitas vezes, precisamos de remover os espaços em branco no início e/ou no fim de uma string.

As funções para isto são `lstrip()` (esquerda), `rstrip()` (direita) e `strip()` (ambos).

```julia-repl
julia> strip("\n\t  useful_bit\n\n")
"useful_bit"
```

### Alterar maiúsculas e minúsculas

Estas funções têm nomes bastante óbvios:

```julia-repl
julia> s = repeat("aBcD ", 5)
"aBcD aBcD aBcD aBcD aBcD "

julia> uppercase(s)
"ABCD ABCD ABCD ABCD ABCD "

julia> lowercase(s)
"abcd abcd abcd abcd abcd "

julia> titlecase(s)  # Initial letter of each word uppercase
"Abcd Abcd Abcd Abcd Abcd "
```
