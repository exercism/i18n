# Dicas para o exercício Campo de Minas em Bash

Este exercício parece exigir um array bidimensional.
O Bash só oferece [arrays][array] indexados ou associativos unidimensionais.

É possível simular arrays multidimensionais com um array associativo: codifica os índices numa string separada por vírgulas e usa-a como chave do array.

```bash
# store this matrix:
#   a b
#   c d
declare -A array2d
array2d["0,0"]="a"
array2d["0,1"]="b"
array2d["1,0"]="c"
array2d["1,1"]="d"
```

[array]: https://www.gnu.org/software/bash/manual/bash.html#Arrays
