# Anexo às instruções

## Registos

| Registo | Utilização | Tipo    | Descrição                              |
| -------- | ------------ | ------- | -------------------------------------- |
| `$a0`    | entrada      | endereço | string de pergunta terminada em null   |
| `$v0`    | saída        | inteiro | resultado, 0 se a pergunta não for válida |
| `$t0-9`  | temporário   | qualquer | para armazenamento temporário          |
