# Sobre

Go tem tipos numéricos básicos que conseguem representar conjuntos de valores inteiros ou de vírgula flutuante.
Há tipos diferentes consoante o tamanho do valor de que precisas e a arquitetura do computador onde a aplicação está a correr (por exemplo, 32 bits e 64 bits).

Este conceito vai centrar-se em dois tipos de números:

- `int`: por exemplo, `0`, `255`, `2147483647`.
   Um número inteiro com sinal que tem pelo menos 32 bits de tamanho (intervalo de valores: de -2147483648 a 2147483647).
   Mas isto depende da arquitetura do sistema.
   A maioria dos computadores modernos é de 64 bits, por isso `int` terá 64 bits de tamanho (intervalo de valores: de -9223372036854775808 a 9223372036854775807).

- `float64`: por exemplo, `0.0`, `3.14`.
   Contém o conjunto de todos os números de vírgula flutuante de 64 bits.

Para uma lista completa dos tipos numéricos disponíveis e mais detalhes, consulta os seguintes recursos:

- [Declarações de tipos incorporados do Go][go-builtins]
- [Digital Ocean - Compreender os tipos de dados em Go][do-understanding-types]
- [Arden Labs - Compreender os tipos em Go][arden-understanding-types]

Go suporta o conjunto padrão de operadores aritméticos `+`, `-`, `*`, `/` e `%` (resto, não módulo).

Em Go, atribuir um valor entre tipos diferentes exige uma conversão explícita.
Por exemplo, para converter um `int` num `float64`, terias de fazer o seguinte:

```go
var x int = 42
f := float64(x)

fmt.Printf("x is of type: %s\n", reflect.TypeOf(x))
// Output: x is of type: int

fmt.Printf("f is of type: %s\n", reflect.TypeOf(f))
// Output: f is of type: float64
```

Para mais informações sobre conversão de tipos, consulta [A Tour of Go: conversão de tipos][type-conversion]
