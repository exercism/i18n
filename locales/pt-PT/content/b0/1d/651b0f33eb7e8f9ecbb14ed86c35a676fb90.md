# preferir uma constante de nível superior

Considera extrair o número `GIGASECOND` para uma constante:

```javascript
const %{name} = %{value}

// the rest of your code below it
export const gigasecond = (...)
```

Só as funções, as classes e as constantes com `export` ficam visíveis e acessíveis a partir do exterior. Normalmente faz sentido dar um nome aos [números mágicos](https://en.wikipedia.org/wiki/Magic_number_%%28programming%%29). Isso facilita a manutenção. Estas constantes podem ficar no mesmo ficheiro sem ficarem expostas a outro código.
