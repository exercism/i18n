# Introdução

## Ciclos while

Com um ciclo while, podes executar código repetidamente enquanto uma determinada condição se verificar.
Escreve-se com a palavra-chave `while` seguida de uma condição entre parênteses e de um bloco de código que contém o _corpo_ do ciclo, delimitado por chavetas.

```javascript
while (condition) {
  // code that is executed repeatedly as long as the condition is true
}
```

O JavaScript também tem um ciclo do-while.
Aqui, a condição é verificada depois de o corpo do ciclo ser executado.
Isto é útil quando a condição depende de avaliações feitas no corpo.

```javascript
do {
  // The code here will always be executed once and then
  // repeatedly while the condition is true.
} while (condition);
```

Dentro do corpo de um ciclo, podes usar a palavra-chave `break` para interromper completamente a execução do ciclo.
Em contraste, a palavra-chave `continue` apenas interrompe a execução da iteração atual e continua para a seguinte.
Com o `continue`, podes muitas vezes evitar envolver grandes partes do corpo do ciclo numa condicional.

```javascript
let i = 0;

while (i < 100) {
  i = i + 2;

  if (i % 3 === 0) {
    continue;
  }

  // The code here will only be executed when i was not divisible
  // by 3 in the check above.
}
```

## Instruções switch

Além da condicional, o JavaScript também tem uma instrução switch para executar lógica condicionalmente.
É usada quando é preciso comparar uma única variável com várias alternativas.
A comparação é feita através da verificação de igualdade estrita (`===`), vê [comparação de conceitos][concept-comparison].
Para uma variável `x`, a instrução switch em JavaScript tem a seguinte sintaxe.

<!-- prettier-ignore-start -->
```javascript
switch (x) {
  case option1:
    // code that is executed when "x === option1" is true
    break;
  case option2:
    // code that is executed when "x === option2" is true
    break;
  default:
    // code that is executed when x does not equal any of the options
}
```
<!-- prettier-ignore-end -->

O caso `default` é opcional e é usado caso queiras executar algum código se nenhuma das outras opções corresponder à variável.

As instruções `break` acima são necessárias porque, por predefinição, todos os casos são "fallthrough" em JavaScript.
Isso significa que, sem qualquer `break`, todo o código nos casos abaixo da primeira opção correspondente seria executado, mesmo que `x` não correspondesse a essas opções.
Este comportamento de "fallthrough" por predefinição é uma armadilha comum quando usas `switch` em JavaScript.
Dentro de uma função, também podes usar `return` em vez de `break` para evitar este problema.
