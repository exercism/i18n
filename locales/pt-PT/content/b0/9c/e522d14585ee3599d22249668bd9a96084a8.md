# argumentos splat inesperados

Define um parâmetro com o nome `%{splat-arg.name}` e o tipo `%{parameter.type}`,
em vez de usares `...%{splat-arg.name}: %{parameter.type}[]`.

[Parâmetros rest / argumentos splat](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Functions/rest_parameters)
são excelentes quando a função não impõe quantos valores quer receber,
mas neste caso está definido explicitamente com quantos valores a função vai ser
chamada.
