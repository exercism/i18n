# Dicas

## Geral

- Numa string codificada em ASCII, todos os carateres ocupam 1 byte em memória.
- Tens de usar `[]` para desreferenciar posições de memória.
- O valor ASCII de uma letra maiúscula é menos 32 do que o valor ASCII da letra minúscula correspondente.

- Os valores de 1 byte são devolvidos em `al`.

## 2. Capitalizar uma palavra

- Numa string codificada em ASCII, todos os carateres ocupam 1 byte em memória.
- Tens de usar `[]` para desreferenciar posições de memória.
- O valor ASCII de uma letra maiúscula é menos 32 do que o valor ASCII da letra minúscula correspondente.
- Capitalizar significa ter um único caráter _maiúsculo_, seguido de carateres _minúsculos_.
- Só os valores entre 'a' e 'z' são letras minúsculas, e só os valores entre 'A' e 'Z' são letras maiúsculas.
- Por isso, primeiro tens de extrair a primeira letra e convertê-la em maiúscula, se estiver em minúscula.
- Depois tens de determinar o resto da string: cada caráter a seguir ao primeiro deve ser convertido em minúscula, se for uma letra maiúscula, ou mantido como está, caso contrário.
- A string termina quando se encontra `'\0'` (o caráter NUL).
- Podes usar `lodsb` para carregar em `al` um byte da posição de memória em `rsi`, alterando `rsi` em 1.
- Podes usar `stosb` para armazenar na posição de memória em `rdi` um byte carregado em `al`, alterando `rdi` em 1.

- Numa string codificada em ASCII, todos os carateres ocupam 1 byte em memória.

- O valor ASCII de uma letra maiúscula é menos 32 do que o valor ASCII da letra minúscula correspondente.
- Tens de percorrer a string com um ciclo para encontrar a última letra.
- Só os valores entre 'a' e 'z' são letras minúsculas, e só os valores entre 'A' e 'Z' são letras maiúsculas.
- Os valores de 1 byte são devolvidos em `al`.

## 4. Ser educado

- Numa string codificada em ASCII, todos os carateres ocupam 1 byte em memória.
- Tens de usar `[]` para desreferenciar posições de memória.
- O valor ASCII de uma letra maiúscula é menos 32 do que o valor ASCII da letra minúscula correspondente.
- Reutiliza uma função existente para capitalizar a palavra.
- Podes usar `movsb` para copiar um byte do endereço de memória em `rsi` para o endereço de memória em `rdi`, alterando tanto `rsi` como `rdi` em 1.
- Podes definir uma string inicializada na _section .rodata_ ou na _section .data_.
- Tens de usar `rel` para calcular um endereço relativo.
- Para um array declarado com a etiqueta `arr`, `$ - arr` corresponderia ao tamanho total de `arr` em bytes, se fosse usado logo depois de declarar o array.
- Podes usar `rep` para repetir uma instrução de string como `movsb` um número de vezes especificado por `rcx`.
- A string deve terminar com `'\0'` (o caráter NUL) como terminador.
- Lembra-te de que os carateres especiais, com uma barra invertida (como `'\0'`), devem ser definidos entre crases (`` ` ``), ou usando o seu valor decimal (que é `0` para o NUL).
