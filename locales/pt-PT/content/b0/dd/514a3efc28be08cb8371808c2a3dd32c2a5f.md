# Instruções

Neste exercício, vais escrever algum código para te ajudar a preparar a compra de um veículo.

Tens três tarefas: uma para determinar se vais precisar de tirar carta de condução, uma para te ajudar a escolher entre dois veículos e uma para estimar um preço aceitável para um veículo usado.

## 1. Determina se vais precisar de carta de condução

Alguns tipos de veículos exigem carta de condução para os conduzir.
Assume que só os tipos `'car'` e `'truck'` exigem carta; tudo o resto pode ser conduzido sem carta.

Implementa a função `needsLicense(kind)`, que recebe o tipo de veículo e devolve um boolean que indica se precisas de carta de condução para esse tipo de veículo.

```javascript
needsLicense('car');
// => true

needsLicense('bike');
// => false
```

## 2. Escolhe entre dois veículos que podes comprar

Avalias as opções de veículos disponíveis.
Consegues reduzi-las a duas opções, mas precisas de ajuda para tomar a decisão final.
Para isso, implementa a função `chooseVehicle(option1, option2)`, que recebe dois veículos como argumentos e devolve uma decisão que inclui a opção que vem primeiro por ordem alfabética.

```javascript
chooseVehicle('Wuling Hongguang', 'Toyota Corolla');
// =>  'Toyota Corolla is clearly the better choice.'

chooseVehicle('Volkswagen Beetle', 'Volkswagen Golf');
// =>  'Volkswagen Beetle is clearly the better choice.'
```

## 3. Calcula uma estimativa para o preço de um veículo usado

Agora que já tomaste a tua decisão, queres garantir que consegues um preço justo no stand.
Como estás interessado em comprar um veículo usado, o preço depende da idade do veículo.
Para uma estimativa aproximada, assume que, se o veículo tiver menos de 3 anos, custa 80% do preço original que tinha quando era novo.
Se tiver mais de 10 anos, custa 50%.
Se o veículo tiver pelo menos 3 anos, mas não mais de 10, custa 70% do preço original.

Implementa a função `calculateResellPrice(originalPrice, age)`, que aplica esta lógica com `if`, `else if` e `else` (há outras formas, se quiseres praticar).
Recebe o preço original e a idade do veículo como argumentos e devolve o preço estimado no stand.

```javascript
calculateResellPrice(1000, 1);
// => 800

calculateResellPrice(1000, 5);
// => 700

calculateResellPrice(1000, 15);
// => 500
```
