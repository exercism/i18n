# Introdução

Quando tens vários valores discretos possíveis entre os quais escolher, `case` (nos [`combinators`][combinators]) é uma opção mais limpa do que uma cadeia de `if`s.

## `case`

```
case ( obj assoc -- )
```

`case` retira o valor do topo da pilha e recebe um *assoc* de cláusulas. Cada cláusula é `{ value [ body ] }`. Ganha a primeira cláusula cujo valor `=` o valor de entrada; o seu corpo é executado com o valor de entrada *já consumido*. Uma entrada final que seja apenas `[ body ]` é a predefinição: o valor de entrada *ainda está na pilha* quando é executado.

```factor
USING: combinators ;

: name-of ( n -- s )
    {
        { 1 [ "one" ] }
        { 2 [ "two" ] }
        [ drop "many" ]
    } case ;
```

A igualdade é feita com `=`, por isso qualquer coisa que compare como igual serve como chave: números, strings e símbolos servem todos.

## `cond` para ramos com guarda

Quando a escolha depende de um *predicado* em vez de igualdade (por exemplo, `x > 11`), `cond` é a ferramenta certa. Conheceste o `cond` em [Cars, Assemble!][cars-assemble].

## Símbolos

Um `SYMBOL:` declara uma palavra que se coloca a si própria na pilha: um valor de etiqueta que se autoavalia. `SYMBOLS:` declara vários de uma só vez:

```factor
SYMBOLS: yes no maybe ;
```

Agora `yes` é um valor, comparável com `=`, que podes usar como chave de um `case`:

```factor
: invert ( ? -- ?' )
    { { yes [ no ] } { no [ yes ] } [ ] } case ;
```
