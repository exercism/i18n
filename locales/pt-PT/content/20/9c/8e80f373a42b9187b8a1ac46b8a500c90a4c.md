# Instruções

Neste exercício vais processar entradas de registo.

Cada linha de registo é uma string com o seguinte formato: `"[<LEVEL>]: <MESSAGE>"`.

Há três níveis de registo diferentes:

- `INFO`
- `WARNING`
- `ERROR`

Tens três tarefas, cada uma delas recebe uma linha de registo e pede-te para fazer algo com ela.
Há muitas formas de resolver estas tarefas. Escolhe as tuas técnicas preferidas dos exemplos acima e vê o que consegues fazer.

## 1. Obter a mensagem de uma linha de registo

Implementa a função `message` para devolver a mensagem de uma linha de registo:

```jq
"[ERROR]: Invalid operation" | message
# => "Invalid operation"
```

Quaisquer espaços em branco no início ou no fim devem ser removidos:

```jq
"[WARNING]:  Disk almost full\r\n" | message
# => "Disk almost full"
```

## 2. Obter o nível de registo de uma linha de registo

Implementa a função `log_level` para devolver o nível de registo de uma linha de registo, que deve ser devolvido em minúsculas:

```ruby
"[ERROR]: Invalid operation" | log_level
# => "error"
```

## 3. Reformular uma linha de registo

Implementa a função `reformat` que reformula a linha de registo, colocando a mensagem primeiro e o nível de registo depois dela, entre parênteses:

```ruby
"[INFO]: Operation completed" | reformat
# => "Operation completed (info)"
```
