# Decomposição e atribuição múltipla

A decomposição é o ato de extrair os elementos de uma coleção, como um `Array` ou um `Hash`.
Os valores decompostos podem depois ser atribuídos a variáveis na mesma instrução.

[A atribuição múltipla][multiple assignment] é a capacidade de atribuir valores decompostos a várias variáveis numa só instrução.
Isto permite escrever código mais conciso e legível, e faz-se separando com vírgulas as variáveis a atribuir, como em `first, second, third = [1, 2, 3]`.

O operador splat (`*`) e o operador splat duplo (`**`) são frequentemente usados em contextos de decomposição.
O operador splat (`*`) pode ser usado para combinar vários **arrays** num só **array**, _decompondo_ cada um num novo **array** comum.
O operador splat duplo (`**`) pode ser usado para combinar vários **hashes** num só **hash**, _decompondo_ cada um num novo **hash** comum.
Esta sintaxe serve para distinguir os vários valores aceites como argumentos posicionais do caso em que se aceitam quaisquer argumentos de palavra-chave.

Quando o operador splat (`*`) é usado sem uma coleção, _empacota_ (ou compõe) vários valores num **array**.
Isto é frequentemente usado na atribuição múltipla para agrupar numa só variável todos os elementos «restantes» que não têm uma atribuição individual.

Em Ruby, é comum usar este comportamento de decomposição/composição ao usar ou definir métodos que aceitam um número arbitrário de argumentos posicionais ou de palavra-chave.
Vais ver muitas vezes estes argumentos definidos como `def some_method(*args, **kwargs)` e usados como `some_method(*some_array, **some_hash)`.

~~~~exercism/caution
Não deves confundir `*<variable_name>` e `**<variable_name>` com `*` e `**`.
Enquanto `*` e `**` são usados para a multiplicação e a exponenciação, respetivamente, `*<variable_name>` e `**<variable_name>` são usados como operadores de composição e de decomposição.
~~~~

[multiple assignment]: https://docs.ruby-lang.org/en/master/syntax/assignment_rdoc.html#label-Multiple+Assignment
