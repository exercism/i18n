# Dicas

## 1. Implementa o método calculate para suportar algumas operações básicas

- Usa uma [instrução `switch`][switch-statement-docs] para corresponder a diferentes operações.

## 2. Trata operações ilegais

- Não podes verificar se um valor é `null` dentro de uma instrução `switch`.
- Usa um caso `default` para qualquer outra coisa no fim do switch.

## 3. Trata a exceção lançada ao dividir por zero

- Usa um [bloco `try-catch`][exception-handling-docs] para capturar a `ArithmeticException` lançada ao dividir por zero.
- A classe `IllegalOperationException` tem um construtor que recebe uma mensagem e uma causa como parâmetros.

[switch-statement-docs]: https://docs.oracle.com/javase/tutorial/java/nutsandbolts/switch.html
[exception-handling-docs]: https://docs.oracle.com/javase/tutorial/essential/exceptions/handling.html
