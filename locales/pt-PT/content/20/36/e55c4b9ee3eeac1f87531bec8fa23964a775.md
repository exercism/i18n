# Anexo às instruções

## Instruções específicas da track

### Formato do campo minado

O campo minado é representado como uma string, com um caráter de nova linha no final de cada linha.

Um exemplo seria `"   \n * \n   \n"`

### Memória reservada

O buffer para a string de entrada usa os bytes 64-319 da memória linear.

A string de entrada pode ser modificada no próprio local, se quiseres.
