# Instruções

A trupe de dança alinha-se em filas e tu andas a manter o registo de quem está onde.

As cinco tarefas ficam todas na classe `DANCE_FORMATION`.

## 1. Quantos há na fila?

```sather
DANCE_FORMATION::dancer_count(|"Mia", "Ana", "Ben"|)
-- => 3
```

## 2. Quem lidera?

O líder é quem fica à frente.

```sather
DANCE_FORMATION::leader(|"Mia", "Ana", "Ben"|)
-- => "Mia"
```

## 3. Quem está atrás?

O marcador de trás é quem fica em último lugar, por muito comprida que seja a fila.

```sather
DANCE_FORMATION::back_marker(|"Mia", "Ana", "Ben"|)
-- => "Ben"
```

## 4. A formação de abertura

A trupe abre sempre pela mesma ordem: Mia, Ana, Ben. Devolve essa fila.

```sather
DANCE_FORMATION::opening_row
-- => an array holding "Mia", "Ana" and "Ben", in that order
```

Esta rotina não recebe argumentos.

## 5. Conta os passos

Cada dançarino tem um número de passos para fazer. Soma-os.

```sather
DANCE_FORMATION::total_steps(|8, 16, 8|)
-- => 32
```

Uma fila vazia são zero passos.
