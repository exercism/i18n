# Introdução

O Elixir representa os valores verdadeiro e falso com o tipo booleano. Existem apenas dois valores: `true` e `false`. Estes valores podem ser associados a uma variável:

```elixir
true_variable = true
false_variable = false
```

Podemos avaliar expressões booleanas estritas com os operadores `and/2`, `or/2` e `not/1`.

```elixir
true_variable = true and true
false_variable = true and false

true_variable = false or true
false_variable = false or false

true_variable = not false
false_variable = not true
```

Quando escreves uma função que devolve um valor booleano, é idiomático terminar o nome da função com um `?`. A mesma convenção pode ser usada para variáveis que guardam valores booleanos.

```elixir
def either_true?(a?, b?) do
  a? or b?
end
```
