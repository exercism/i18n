# Instruções

Chamar APIs é uma parte importante de escrever código na internet. Neste exercício, vais precisar de obter dados de um endpoint e garantir que foram obtidos com sucesso.

## Objetivos

- Modifica o código fornecido.
- Invoca o cliente HTTP e tenta obter uma citação. Este resultado deve ser um tipo de união composto por `string` e `error`.
- Se receberes a citação, imprime-a na consola (com `io:println()`).
- Se tiver ocorrido um `error`, imprime a mensagem de erro na consola.
