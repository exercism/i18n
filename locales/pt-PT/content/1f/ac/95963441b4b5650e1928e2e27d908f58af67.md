# formatação com percentagem ou ao estilo antigo

Esta solução usa `%%-formatting` ou [formatação ao estilo antigo][old-style formatting] para strings.

Embora `%%-formatting` seja uma abordagem totalmente válida, pode criar problemas de representação ou de legibilidade.
Usar o método [str.format()][str.format()] ou [f-strings][f-strings] (_também conhecidas como «literais de string formatados» ou «strings interpoladas»_) pode oferecer opções que melhoram a legibilidade e tornam mais clara a substituição de variáveis dentro das strings.

O artigo de blog [String Formatting in Python][string formatting in python] é um bom ponto de partida para compreender todas as opções de formatação de strings em Python, e [Newer Python String Format Techniques][newer python string format techniques] também dá algumas boas dicas e truques para usar `str.format()` e `f-strings`.
