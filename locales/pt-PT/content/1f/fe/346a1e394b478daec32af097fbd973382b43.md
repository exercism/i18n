# Dicas

## Geral

- Explora as [funções disponíveis no _módulo string_][string-module-functions] para descobrires que operações sobre strings a biblioteca padrão do Gleam oferece.

## 1. Obtém a primeira letra do nome

- Existe uma [função][string-first] para obter o primeiro caráter de uma string.
- Existem várias [funções][string-trim] para remover espaços em branco do início, do fim, ou do início e do fim de uma string.

## 2. Formata a primeira letra como inicial

- Existe uma [função][string-upcase] para converter todos os carateres de uma string na sua variante maiúscula.
- Podes usar o operador `<>` para concatenar strings.

## 3. Divide o nome completo no primeiro nome e no último nome

- Existe uma [função][string-split] que divide uma string pelos carateres de espaço em branco.
- Podes atribuir os primeiros elementos de uma lista a variáveis recorrendo a pattern matching sobre a lista.

## 4. Coloca as iniciais dentro do coração

- Podes usar o operador `<>` para concatenar strings.
