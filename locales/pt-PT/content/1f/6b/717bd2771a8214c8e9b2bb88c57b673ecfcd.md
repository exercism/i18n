# Instruções

A biblioteca de Luton é uma grande biblioteca com uma vasta coleção de literatura, que vai de livros a arte.
A biblioteca tem uma secção onde se estuda literatura e se registam livros no sistema informático.

Algumas partes pretendem ser automatizadas e pedem-te ajuda.
Isto inclui desde automatizar os formulários do processo de inscrição até ajudar a desencriptar textos.

## 1. Obter a primeira letra do título

Os livros de uma biblioteca devem ser fáceis de encontrar, por isso são ordenados pela primeira letra do título.

Implementa o método `Library.first_letter`, que recebe um argumento `title`, que contém o título do livro.
O método deve devolver a primeira letra do título.

```Crystal
Library.first_letter("Mystery of the Crystal Skull")
# => 'M'
```

## 2. Obter as iniciais do autor

A biblioteca tem muitos livros escritos por autores diferentes.
Frequentemente, os autores são referidos pelas suas iniciais, por isso a biblioteca pediu um sistema que devolva as iniciais do autor a partir do seu primeiro e último nome.
As iniciais devem ser formatadas assim: `{first_letter_of_first_name}.{first_letter_of_last_name}`

Implementa o método `Library.initials`, que recebe dois argumentos, `first_name` e `last_name`, que contêm o primeiro e o último nome do autor.
O método deve devolver as iniciais do autor.

```Crystal
Library.initials("William", "Shakespeare")
# => "W.S"
```

## 3. Desencriptar uma letra

Parte da literatura está encriptada e a biblioteca tem muitos textos encriptados.
A biblioteca gostaria de um novo sistema de desencriptação para uma encriptação especial.

A encriptação funciona tomando a letra e substituindo-a pela letra que a precede no alfabeto.
Por exemplo, `a` passa a `z`, `b` passa a `a`, `c` passa a `b`, e assim sucessivamente.

A biblioteca gostaria que o sistema conseguisse desencriptar tanto letras maiúsculas como minúsculas, mantendo cada letra no mesmo formato da letra original.

Implementa o método `Library.decrypt_character`, que recebe um argumento `character`, que contém a letra a desencriptar.
O método deve devolver a letra desencriptada.

```Crystal
Library.decrypt_character('a')
# => 'z'
```

## 4. Desencriptar um texto

A biblioteca também gostaria de desencriptar um texto inteiro encriptado com este método, que usa a letra anterior no alfabeto.

O desencriptador deve desencriptar apenas letras e deixar todos os outros carateres como estão.

Implementa o método `Library.decrypt_text`, que recebe um argumento `text`, que contém o texto a desencriptar.
O método deve devolver o texto desencriptado.

```Crystal
Library.decrypt_text("Ifmmp Xpsme!")
# => "Hello World!"
```
