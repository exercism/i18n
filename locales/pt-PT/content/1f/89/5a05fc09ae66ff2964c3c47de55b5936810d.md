# Recursos

## Criar o teu primeiro módulo Coffee

Para criar um módulo que possa ser carregado com `Bob = require './bob'`, coloca este código em `bob.coffee`:

```coffeescript
class Bob

module.exports = Bob
```

Podes encontrar mais informações sobre módulos na [documentação do Node](http://nodejs.org/api/modules.html#modules_module_exports).

## Visual Studio no Windows

Se tens uma versão paga do Visual Studio, podes descarregar uma solução de Visual Studio já configurada para funcionar com CoffeeScript e com as outras linguagens que o Visual Studio suporta.

![Solution Explorer](https://raw.githubusercontent.com/exercism/coffeescript/main/docs/img/SolutionExplorer.png)

1. Descarrega o [Exercism.io Visual Studio Template](https://github.com/rprouse/Exercism.VisualStudio) do GitHub, clicando no botão Download Zip da página.
2. Descomprime o modelo para o teu diretório de exercícios, por exemplo `C:\src\exercises`
2. Instala a [Exercism CLI](http://exercism.io/cli)
3. Abre uma linha de comandos no teu diretório de exercícios
4. Adiciona a tua chave de API ao exercism `exercism configure --key=YOUR_API_KEY`
5. Configura o teu diretório de origem no exercism `exercism configure --dir=C:\src\exercises`
6. [Obtém o teu primeiro exercício](http://exercism.io/languages/coffeescript) `exercism fetch coffeescript`
7. Abre a solução do Exercism no Visual Studio
8. Expande o projeto Exercism.coffeescript
9. Clica em **Show All Files** no Solution Explorer (vê abaixo)
10. O exercício que acabaste de obter aparece a cinzento. Clica com o botão direito na pasta e escolhe **Include In Project**
11. Mãos à obra...

![Adicionar ficheiros](https://raw.githubusercontent.com/exercism/coffeescript/main/docs/img/AddFiles.png)

Para trabalhar com CoffeeScript no Visual Studio, deves instalar a extensão [Web Essentials](http://vswebessentials.com/). Também vai tornar muito mais fácil trabalhar com Javascript.

Podes correr os testes unitários a partir de uma linha de comandos do node.js, usando o ficheiro batch do projeto.

```bash
C:\Src\exercises\coffeescript> test example\bob_test.spec.coffee
.................

Finished in 0.02 seconds
17 tests, 17 assertions, 0 failures, 0 skipped
```

Se não vires qualquer resultado ao correr os testes, provavelmente não estás numa linha de comandos do Node.js.
