# Introdução

Em Python, o `None` é usado com frequência para representar a ausência de um valor: um marcador de posição para definir uma variável, um objeto ou um argumento `null` (vazio).

Se já ouviste falar de um tipo `NULL` ou `nil` noutra linguagem de programação, ou já o usaste, então este uso de `None` em Python vai ser-te familiar.
O `None` ajuda-te a declarar variáveis ou argumentos de função para os quais ainda não tens valores.
Depois, podes reatribuir-lhes valores específicos, conforme for necessário:


```python
a = None
print(a)
#=> None

type(a)
#=> <class 'NoneType'>

# Adding a default argument with `None`
def add_to_todos(new_task, todo_list=None):
    if todo_list is None:
        todo_list = []  
    todo_list.append(new_task)
     
  return todo_list
```

O `None` é avaliado como `False` quando é usado numa verificação condicional, por isso é útil para validar a "presença" ou a "ausência" de um valor (de _qualquer_ valor), um padrão muito usado quando uma função ou um processo pode devolver um `error`, um `object` ou uma mensagem.

```python
a = None
if a: #<-- a will be evaluated to False when it is used in a conditional check.
    print("This will not be printed")
```
