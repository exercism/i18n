# Introdução

## Átomos

O tipo `atom` do Elixir representa uma constante fixa. O valor de um átomo é simplesmente o seu próprio nome. Isto dá-nos uma forma segura, do ponto de vista dos tipos, de interagir com dados. Os átomos podem ser definidos da seguinte forma:

```elixir
# All atoms are preceded with a ':' then follow with alphanumeric snake-cased characters
variable = :an_atom
```

Internamente, cada _átomo_ é representado por um número inteiro numa tabela de consulta, atribuído automaticamente. Não é possível alterar esse valor interno.

## Cond

Muitas vezes queremos escrever código que possa ramificar com base numa condição. Embora haja muitas formas de o fazer em Elixir, uma das mais simples é usar o `cond/1`.

Na sua forma mais simples, o `cond` segue o primeiro de um ou mais ramos que seja avaliado como `true`:

```elixir
cond do
  x > 10 -> :this_might_be_the_way
  y < 7 -> :or_that_might_be_the_way
  true -> :this_is_the_default_way
end
```

Se nenhum caminho for avaliado como `true`, o ambiente de execução lança um erro.
