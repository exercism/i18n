# Introdução

És um grande fã de [geocaching](https://en.wikipedia.org/wiki/Geocaching), que combina o teu amor pela natureza com o prazer de resolver quebra-cabeças.
Embora o site de geocaching local liste as coordenadas GPS de todas as caches, _não_ permite criar uma rota eficiente para as recolher.
Acontece que tens um software de procura de caminhos instalado na tua máquina, mas ele usa um formato de GPS diferente do do site de geocaching.
Para introduzires os dados no software de procura de caminhos, vais ter de analisar os graus e o hemisfério, tanto da latitude como da longitude, de cada coordenada GPS que aparece no site.
