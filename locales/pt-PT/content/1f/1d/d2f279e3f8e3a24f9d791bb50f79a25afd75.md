# Sobre

O PHP é uma linguagem do lado do servidor vocacionada para o desenvolvimento web. A sigla é recursiva: _PHP: Hypertext Preprocessor_.

Consideravelmente mais versátil do que a programação CGI, o PHP é frequentemente usado para adicionar interatividade a HTML simples e reforçar frameworks web.

A linguagem pode ser utilizada em qualquer sistema operativo. O PHP é suportado pela maioria dos servidores web mais comuns e é frequentemente processado através de um módulo intérprete. Isto combina código web estático com inclusões dinâmicas.

O PHP não é apenas um framework de servidor web. Também é útil para scripts na linha de comandos (análise sintática sem interface gráfica) e para desenvolver interfaces gráficas.

Deves aprender PHP porque:

- é uma linguagem de código aberto
- está bem documentada e tem bom suporte
- é compatível com a maioria dos servidores web mais comuns
- é fácil de aprender e de dar os primeiros passos
- é altamente escalável e extensível
