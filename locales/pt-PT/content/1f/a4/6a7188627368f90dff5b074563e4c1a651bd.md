# Noções básicas de sintaxe de Haskell

## Constantes e funções

Os programas em Haskell são compostos por definições e expressões.

Um valor constante é definido com `name = expression`.

```haskell
five = 5

six = 3 + 3
```

As funções definem-se com `name parameters... = expression`, sendo os parâmetros separados apenas por espaços.

```haskell
add number1 number2 = number1 + number2
```

Invocar uma função também é uma expressão e faz-se indicando o seu nome e passando argumentos para cada um dos parâmetros da função, separados por espaços, tal como nas definições de funções.

```haskell
five = add 2 3
```

Pode-se usar parênteses para especificar a ordem de avaliação de uma expressão.

```haskell
six = add 2 (1 * 4)

twelve = add 2 1 * 4
```

## Indentação / espaços em branco significativos

Haskell usa espaços em branco e indentação para delimitar o código.
***O código que faz parte de uma expressão deve estar indentado mais para dentro do que o início dessa expressão.***

- As definições de módulos, importações e funções de nível superior têm de começar na coluna mais à esquerda.
- Se uma expressão for dividida em várias linhas, o código que faz parte dessa expressão tem de ser indentado abaixo dessa expressão com pelo menos um espaço.
- As partes da expressão que estão agrupadas devem ser indentadas com o mesmo número de espaços.

```haskell
-- A function split over multiple lines, so subsequent lines must be indented
add number1 number2 =
    number1 + number2
```

https://en.wikibooks.org/wiki/Haskell/Indentation

## Módulos

Os módulos exportam funções.
Isso significa que podes usar as funções que o módulo disponibiliza na sua declaração de exportação.
Um módulo também pode definir funções apenas para uso interno.
Por predefinição, as funções que não são exportadas explicitamente não podem ser usadas fora do módulo.

No início de um módulo, especificamos o nome do módulo.
Se tivermos um ficheiro chamado Calculator.hs, devemos dar ao nosso módulo o nome Calculator.
De seguida, especificamos as funções que exporta e, depois disso, podemos começar a escrever as funções.
Por isso, vamos começar com isto.

```haskell
module Calculator ( add ) where
```

https://learnyouahaskell.github.io/modules#making-our-own-modules

## Comentários

Um comentário é algum texto dentro do ficheiro Haskell que não é interpretado como código.
Destina-se principalmente a ser lido por ti e por outros programadores.
Existe uma sintaxe simples para comentários de uma linha, baseada em dois traços.
Também é possível ter comentários de várias linhas com o par de delimitadores de abertura e fecho `{-` e `-}`.

```haskell
-- a single line comment
-- another single line comment

{- a multiline comment
   spanning multiple lines
-}
```
