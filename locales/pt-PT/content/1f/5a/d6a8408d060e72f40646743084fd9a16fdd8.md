# Null

O null é um tipo de valor primitivo com um único valor: `null`.
O null é muitas vezes usado para representar o nada.
É considerado "falsey", mas é distinto de `false` e de outros valores falsey.

```php
<?php

is_null(null); // => true
isset(null); // => false

null == true; // => false
null === true; // => false

null == false; // => true
null === false; // => false
```

## Trabalhar com valores null

Em PHP, os valores null são uma causa comum de erros, porque muitas vezes são devolvidos no lugar de um estado de erro ou para representar o nada.
Para evitar que os erros surjam, é muitas vezes necessário fazer uma "verificação de null" para garantir que o valor não é null antes de o usar.

Fazer esta verificação repetidamente pode dar origem a erros, por isso o PHP fornece dois operadores para trabalhar com valores null: o operador de acesso seguro a null `?->` e o operador de coalescência de null `??`.
