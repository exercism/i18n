# Anexo às instruções

## Dicas

Tens de implementar a função `responseFor`, que devolve a resposta do Bob para um determinado valor de entrada. Podes usar a assinatura fornecida se tiveres dúvidas quanto aos tipos, mas não deixes que isso restrinja a tua criatividade:

```haskell
responseFor :: String -> String
```

Para resolveres este exercício, podes ler sobre:

- [Guardas][guards]

[guards]: https://www.futurelearn.com/courses/functional-programming-haskell/0/steps/27226

Este exercício trabalha com dados textuais. Por razões históricas, o tipo `String` do Haskell é sinónimo de `[Char]`, uma lista de carateres. Para um tratamento mais eficiente de dados textuais, podes usar o tipo `Text`.

Como extensão opcional deste exercício, podes

- Ler sobre [tipos de string](https://haskell-lang.org/tutorial/string-types) em Haskell.
- Adicionar `- text` à tua lista de dependências no package.yaml.
- Importar `Data.Text` [da seguinte forma](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c):

    ```haskell
    import qualified Data.Text as T
    import           Data.Text (Text)
    ```

- Agora podes escrever, por exemplo, `responseFor :: Text -> Text` e referir-te aos combinadores de `Data.Text` como, por exemplo, `T.isSuffixOf`.
- Consultar a documentação de [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html),
- Podes depois substituir todas as ocorrências de `String` por `Text` no Bob.hs:

    ```haskell
    responseFor :: Text -> Text
    ```

Esta parte é totalmente opcional.
