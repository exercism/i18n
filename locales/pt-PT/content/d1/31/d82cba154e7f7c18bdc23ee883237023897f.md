# Contribuir para o Exercism

Esta secção da documentação mostra como contribuir para o Exercism.
Contém informações e especificações sobre as várias áreas do Exercism, para além de guias sobre temas como tornares-te responsável pela manutenção e escolher uma história para um exercício.

Para teres uma ideia de onde podes ajudar, dá uma olhada na nossa [lista de tarefas][tasks].

As contribuições para a base de código são feitas através do [GitHub][github].

[tasks]: https://exercism.org/contributing/tasks
[github]: /docs/building/github
