# Introdução

Em Common Lisp, uma função pode ter parâmetros nomeados (referidos como "parâmetros de palavra-chave").
Estes são designados na lista lambda pela palavra-chave da lista lambda `&key`.
Os parâmetros de palavra-chave não são parâmetros obrigatórios.
Tal como os parâmetros opcionais, podem receber valores predefinidos e símbolos para ligar ao seu estado de 'fornecido ou não'.

Ao chamar uma função com parâmetros de palavra-chave, o nome do parâmetro como palavra-chave é usado antes do valor do parâmetro.
Quem chama a função pode especificar os parâmetros de palavra-chave em qualquer ordem.

```lisp
(defun keyword-parameters (&key x (y 'default) (z nil z-supplied-p))
  (list x y (if z-supplied-p (list :z-was-supplied z)
                             (list :z-was-not-supplied z))))

(keyword-parameters)            ; => (NIL DEFAULT (:Z-WAS-NOT-SUPPLIED NIL))
(keyword-parameters :y 5)       ; => (NIL 5 (:Z-WAS-NOT-SUPPLIED NIL))
(keyword-parameters :z 10 :x 5) ; => (5 DEFAULT (:Z-WAS-SUPPLIED 10))
```

Convém ter cuidado ao combinar parâmetros opcionais e de palavra-chave, pois o nome da palavra-chave e o argumento podem ser consumidos pelos parâmetros opcionais:

```lisp
(defun could-be-confusing (&optional x y &key z) (list x y z))
(could-be-confusing :z 'huh?) ; => (:Z HUH? NIL)
```
