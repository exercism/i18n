# Executar os testes

Com o `sbt` instalado, podes executar os testes a partir da linha de comandos com:

```bash
$ sbt test
```

Repara que executar o `sbt test` todas as vezes vai ser lento, porque o `sbt` é reinicializado em cada invocação.

O `sbt` funciona como uma shell: depois de o iniciares, podes executar comandos dentro dele.

Por exemplo, podes usar o `sbt` para voltar a executar os testes sempre que os ficheiros de código mudarem:
```bash
$ sbt
>~ test
```

Repara que todos os testes foram desativados exceto o primeiro, para que possas trabalhar nele.
Para continuares, basta removeres a palavra-chave `pending` do início de cada caso de teste.

Vai [aqui](https://www.scala-sbt.org/) para saberes mais sobre o `sbt`.


Também podes executar os testes nos seguintes ambientes de desenvolvimento integrados (IDEs):

* [Metals](https://scalameta.org/metals/docs/#running-tests)
* [IntelliJ IDEA with Scala Plugin](https://www.jetbrains.com/idea/)
