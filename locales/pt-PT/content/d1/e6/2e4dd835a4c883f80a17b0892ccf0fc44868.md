# Case

[`case`][case] (muitas vezes designado por *switch* noutras linguagens) é uma forma de expressão de controlo, tal como o if-else.
O `case` permite encadear várias instruções if-else-if, pode ser mais legível e permite construir coisas poderosas.

Um `case` é definido pela palavra-chave `case`, seguida de uma expressão opcional.
Depois, para cada caso, usa-se a palavra-chave `when`, seguida de uma expressão que é comparada com a expressão do `case`.
A palavra-chave `when` não deve estar indentada em relação à palavra-chave `case`.
A seguir à palavra-chave `when` vem o código que deve ser executado se a expressão do `case` corresponder à expressão do `when`.
O `case` permite uma cláusula `else` opcional, que é executada se nenhum outro caso corresponder.

A expressão do `case` é avaliada e depois comparada com cada expressão do `when`.
A comparação é feita com o [operador de subsunção do case (`===`)][case-subsumption].

```Crystal
case 1
when 1
  puts "One"
when 2
  puts "Two"
else
  puts "Other"
end
# => One

# This is the same as:
tmp = 1
if 1 === tmp
  puts "One"
elsif 2 === tmp
  puts "Two"
else
  puts "Other"
end
```

## Operador de subsunção do case (`===`)

O operador de subsunção do case (`===`) é um pouco diferente do operador de igualdade (`==`).
O operador verifica se o lado direito é um membro do conjunto descrito pelo lado esquerdo.
Isto significa que a posição de cada operando é importante.
O funcionamento depende do tipo do lado esquerdo. Por exemplo, um `Range` verifica se o lado direito está no intervalo, e um `Object` verifica se o lado direito é uma instância do `Object`.

```Crystal
(1..3) == 1  # => false
(1..3) === 1 # => true

String == "foo"  # => false
String === "foo" # => true
```

## Case com várias expressões

Os `case` permitem corresponder a várias expressões num único caso, com cada valor possível separado por uma vírgula.
O código é executado se alguma das expressões corresponder.
Isto pode ser útil para um único caso com vários valores possíveis.

```Crystal
case 1
when 1, 2
  puts "One or two"
else
  puts "Other"
end
```

## Case com intervalos

Os `case` também podem verificar se um valor está num intervalo.
Para isso, basta usar um intervalo como expressão do `when`.

```Crystal
case var
when 1..3
  puts "One to three"
else
  puts "Other"
end
```

## Case sem expressão de case

Quando não é precisa uma expressão de `case`, é possível omiti-la.
Ao fazê-lo, cada expressão do `when` passa a ser avaliada quanto ao seu valor de verdade.
E faz com que se comportem como instruções if-else-if.

```Crystal
case
when 1 == 1
  puts "One is equal to one"
when 1 > 2
  puts "One is greater than two"
else
  puts "Other"
end
```

## When numa só linha

O Crystal permite instruções `case` numa só linha.
Podes usá-lo quando tens uma instrução simples de uma só linha.
A forma numa só linha escreve-se como `when <expression> then <statement>.`
E, quando usada na cláusula `else`, escreve-se como `else <statement>`.

```Crystal
case var
when 1 then puts "One"
when 2 then puts "Two"
else puts "Other"
end
```

## Case com tipos

O `case` permite fazer correspondência com tipos.
A comparação usa o operador `is_a?` para verificar o tipo da variável.
Por exemplo, isto permite um ramo para cada tipo de um tipo união.

```Crystal
case var
when Int32
  puts "Int32"
when String
  puts "String"
else
  puts "Other"
end
```

## Objeto implícito

O `case` permite usar um objeto implícito.
Isto permite, por exemplo, que a expressão do `when` seja uma chamada de método sobre a expressão do `case`.
Consoante o método devolva um valor verdadeiro ou falso, o caso corresponderá ou não.

```Crystal
case 1
when .odd?
  puts "Odd"
when .even?
  puts "Even"
end
```
