# Instalação

O Free Pascal Compiler versão 3.2.2 pode ser instalado diretamente a partir do gestor de pacotes, para uma grande variedade de plataformas e sistemas.
Se não estiver disponível para o teu sistema ou plataforma, ou se quiseres instalar o Free Pascal no teu diretório pessoal, podes obter os binários em [Free Pascal - Download][fpc-download], descompactar o ficheiro tar, executar o ```install.sh``` e acrescentar o ```$HOME/fpc-3.2.2/bin``` à variável de ambiente ```PATH```.

Para outras opções de instalação e/ou uma descrição mais detalhada, consulta [Installing the Free Pascal Compiler - Free Pascal wiki][fpc-install-wiki].

[fpc-download]: https://www.freepascal.org/download.html
[fpc-install-wiki]: https://wiki.freepascal.org/Installing_the_Free_Pascal_Compiler
