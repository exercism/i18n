# Dicas

## Geral

- Uma rotina que responde com texto declara-se `: STR`. Uma que responde
  com um número inteiro declara-se `: INT`.
- Dois argumentos do mesmo tipo podem partilhar uma declaração:
  `full_title(piece, composer : STR) : STR`.

## 1. Indica o nome da peça e de quem a escreveu

- Três pedaços de texto unidos com `+`: a peça, depois `" by "` e, por fim, o
  compositor.
- Os espaços estão dentro das aspas. O `+` não acrescenta nada por si.

## 2. Mede uma linha

- `.size`, sem parênteses a seguir.

## 3. As primeiras letras

- O `.head` recebe o número entre parênteses: `title.head(count)`.

## 4. As últimas letras

- O `.tail` é o `.head` a contar a partir do outro extremo.

## 5. Encurta um título longo

- Seis letras do início, depois `"..."` unido com `+`.
- O número de letras é sempre seis, por isso podes escrevê-lo diretamente na
  chamada em vez de o passares como argumento.
