# Test Runners

Um Test Runner é um programa que corre os testes de um exercício contra o código de um estudante.

Os Test Runners dão-nos duas vantagens:

1. Permitem programar no navegador, onde um estudante pode iterar sobre uma solução e ver se os testes passam ou falham.
2. Permitem-nos dar informação aos mentores sobre se o código de um estudante "funciona" ou não.

## Criar um Test Runner

Se estiveres interessado em criar um Test Runner, consulta a [documentação dos Test Runners](/docs/building/tooling/test-runners) para mais informações.
