# Anexo às instruções

## Registos

| Registo | Utilização      | Tipo    | Descrição                       |
| -------- | --------------- | ------- | ------------------------------- |
| `$a0`    | valor de entrada | endereço | primeira string, terminada em null  |
| `$a1`    | valor de entrada | endereço | segunda string, terminada em null |
| `$v0`    | valor de saída   | número inteiro | distância de Hamming        |
| `$t0-9`  | temporário      | qualquer | para armazenamento temporário   |
