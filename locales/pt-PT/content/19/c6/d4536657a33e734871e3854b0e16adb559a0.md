# Apêndice de instruções

## Instruções específicas do percurso

Para algo um pouco diferente, também podes experimentar uma solução com uma função `unfold`. Provavelmente já conheces `foldLeft/Right`: «mapeiam» uma coleção inteira para outra coisa (normalmente algo que não é uma coleção). `unfoldLeft/Right` são as operações «inversas»: «mapeiam» algo (normalmente algo que não é uma coleção) para uma coleção. Por isso, fazer `unfold` é uma adição lógica e faz parte do repertório padrão da programação funcional.

Este exercício pode ser encarado como um caso para fazer `unfold`: «mapear» um `Int` para uma `String` (que é, naturalmente, de forma implícita, uma `Seq[Char]`).

Infelizmente, `unfoldLeft/Right` não está incluído na biblioteca de coleções do Scala. Mas podes tirar a implementação [daqui][unfold].

[unfold]: http://daily-scala.blogspot.de/2009/09/unfoldleft-and-right.html
