# Introdução

As funções recursivas são funções que se chamam a si próprias.

Uma função recursiva tem de ter pelo menos um _caso base_ e pelo menos um _caso recursivo_.

Um _caso base_ devolve um valor sem voltar a chamar a função. Um _caso recursivo_ volta a chamar a função, modificando o valor de entrada para que este venha, em algum momento, a corresponder ao caso base.

Muitas vezes, cada caso é escrito na sua própria cláusula de função.

```elixir
# base case
def count([]), do: 0

# recursive case
def count([_head | tail]), do: 1 + count(tail)
```
