# Introdução

O modificador `const` pode ser (e, de um modo geral, deve ser) aplicado a qualquer campo cujo valor seja conhecido em tempo de compilação e não se altere durante o tempo de vida do programa.

```csharp
private const int num = 1729;
public const string title = "Grand" + " Master";
```

O modificador `readonly` pode ser (e, de um modo geral, deve ser) aplicado a qualquer campo que não possa ser declarado `const` e cujo valor não se altere durante o tempo de vida do programa, sendo esse valor definido por um inicializador inline ou durante a instanciação (pelo construtor ou por um método chamado pelo construtor).

```csharp
private readonly int num;
private readonly System.Random rand = new System.Random();

public MyClass(int num)
{
    this.num = num;
}
```
