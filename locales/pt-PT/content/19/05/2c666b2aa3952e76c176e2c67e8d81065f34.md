# Introdução

O operador ternário condicional serve para escrever uma expressão condensada que devolve um de dois valores alternativos, com base numa condição.
É frequentemente designado apenas por "operador ternário".
O nome vem do facto de o operador ter três operandos: `predicate ? consequent-expression : alternative-expression`
Pode ser usado como alternativa a condicionais if-else curtas.

Tal como nas condicionais `if`, o JavaScript faz uma conversão implícita de tipos para avaliar a condição.
Se a condição for truthy, é devolvido o operando do lado esquerdo dos dois pontos.
Caso contrário, o resultado da expressão ternária é o operando do lado direito dos dois pontos.

```javascript
const year = 2020;

year > 2000 ? 'in the past years' : 'a long time ago';
// => 'in the past years'
```
