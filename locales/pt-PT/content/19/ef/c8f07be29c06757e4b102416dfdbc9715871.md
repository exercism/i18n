# Instruções

Neste exercício vais processar linhas de registo.

Cada linha de registo é uma string com o seguinte formato: `"[<LEVEL>]: <MESSAGE>"`.

Existem três níveis de registo diferentes:

- `INFO`
- `WARNING`
- `ERROR`

Tens três tarefas, e cada uma recebe uma linha de registo e pede-te que faças algo com ela.
Há muitas formas de resolver estas tarefas: escolhe os teus métodos preferidos dos exemplos acima e vê o que consegues arranjar.

## 1. Obter a mensagem de uma linha de registo

Implementa o método `LogLineParser#message` para devolver a mensagem de uma linha de registo:

```ruby
LogLineParser.new('[ERROR]: Invalid operation').message
# => "Invalid operation"
```

Qualquer espaço em branco no início ou no fim deve ser removido:

```ruby
LogLineParser.new("[WARNING]:  Disk almost full\r\n").message
# => "Disk almost full"
```

## 2. Obter o nível de registo de uma linha de registo

Implementa o método `LogLineParser#log_level` para devolver o nível de registo de uma linha de registo, que deve ser devolvido em minúsculas:

```ruby
LogLineParser.new('[ERROR]: Invalid operation').log_level
# => "error"
```

## 3. Reformatação de uma linha de registo

Implementa o método `LogLineParser#reformat`, que reformata a linha de registo, colocando a mensagem primeiro e o nível de registo depois, entre parênteses:

```ruby
LogLineParser.new('[INFO]: Operation completed').reformat
# => "Operation completed (info)"
```
