# Apêndice
## Bónus

Preserva os agrupamentos de grafemas, ou seja

```julia
myreverse("hi 👋🏾") == "👋🏾 ih"
myreverse("as⃝df̅") == "f̅ds⃝a"
```

Provavelmente vais achar a biblioteca padrão [`Unicode`][ref-unicode] útil para esta tarefa bónus.

Para ativares o teste dos grafemas, acrescenta `const TEST_GRAPHEMES = true` ao âmbito global do teu ficheiro.

[ref-unicode]: https://docs.julialang.org/en/v1/stdlib/Unicode/
