# Introdução

O [Zen of Python][zen-of-python] afirma que deve haver "uma _forma óbvia_ de fazer algo em Python".
Para o Python 3.6+, a [**interpolação literal de strings**][string-interpolation] ([**`f-string`s**][f-string]) é muitas vezes a forma óbvia e preferida de formatar strings:

```python
>>> adjective = "easy"
>>> f"This is an {adjective} way to format strings!"
'This is an easy way to format strings!'
```

No entanto, dada a longa história do Python e os diferentes casos de uso, não é de estranhar que existam **três** outras formas comuns de fazer formatação de strings em Python:

1. [`str.format()`][str-format] é versátil e muito poderoso, e é compatível tanto com o [`gnu gettext`][gettext] como com a maioria das versões do Python.
2. Se o que precisas é de simplicidade, segurança e/ou muita internacionalização, o [`string.Template()`][string-template] pode ser usado para mitigar riscos quando é preciso tratar dados de entrada e para envolver strings de tradução.
3. O operador `%` é geralmente considerado obsoleto para código novo, embora ainda funcione no Python moderno.
  Deve ser usado sobretudo por compatibilidade com bases de código mais antigas.
  A formatação com `%` pode causar problemas ao mostrar carateres não ASCII e Unicode e tem mais erros e menos funcionalidade do que os outros métodos.
  Consulta a tua distribuição específica do Python para saberes os detalhes de suporte, caso pretendas usá-lo.

Se quiseres ir mais longe, [tudo sobre formatação][all-about-formatting] e [Python String Formatting Best Practices][formatting-best-practices] são bons pontos de partida.
