# Dicas

## Geral

- Um [valor int][ints] pode ser definido como um ou mais algarismos consecutivos.
- Os literais de [string][string] são uma sequência de carateres rodeada por aspas duplas.

## 1. Define o tempo esperado no forno em minutos

- Tens de definir uma [função][functions] sem argumentos.
- Tens de devolver um [int][ints].

## 2. Calcula o tempo restante no forno em minutos

- Tens de definir uma [função][functions] com um único argumento.
- Tens de devolver um int a partir de uma função.
- O argumento da função é um [int][ints].
- Podes usar o [operador matemático de subtração][ints] para subtrair valores.

## 3. Calcula o tempo de preparação em minutos

- Tens de definir uma [função][functions] com um único argumento.
- Tens de devolver um int a partir de uma função.
- O argumento da função é um [int][ints].
- Podes usar o [operador matemático de multiplicação][ints] para multiplicar valores.

## 4. Calcula o tempo total de trabalho em minutos

- Tens de definir uma [função][functions] com dois argumentos.
- Tens de devolver um int a partir de uma função.
- O argumento da função é um [int][ints].
- Podes invocar uma das outras funções que definiste anteriormente.
- Podes usar o [operador matemático de adição][ints] para somar valores.

## 5. Cria uma notificação de que a lasanha está pronta

- Tens de definir uma [função][functions] sem argumentos.
- Tens de devolver uma [string][string].
