# Sobre

Em Swift, uma `String` é uma coleção ordenada de valores `Character` que representa texto legível por humanos. As strings de Swift suportam totalmente carateres Unicode e emoji.

Crias uma string com um literal de string, colocando o texto entre aspas duplas (`"`). Os caracteres especiais usam sequências de escape: por exemplo, `\n` representa uma nova linha, e `\"` representa uma aspa dupla escapada dentro de um literal de string.

Uma string vazia escreve-se como um par de aspas duplas sem nada entre elas (`""`).

```swift
let hello = "Hello, World!"
let sausage = "Weißwurst is a tasty sausage."
var family = "This is my family: 👨‍👩‍👦‍👦, this is our dog: 🐶"
var empty = ""
```
