# Dicas

## General

- `NestedValue` é uma união de etiquetas recursiva: cada valor é `Value(number)`, `Null` ou `NestedArray(children)`.
  Usa `match` para distinguir estes casos e associar os respetivos conteúdos.

- `List.join_map` pode ser útil quando uma função mapeia cada filho para uma lista e queres concatenar os resultados.
