# Sobre

Um template é uma string ou um ficheiro usado para produzir qualquer tipo de saída em string, consoante os dados de entrada.

```haxe
var sample = "My name is ::name::";
var template = new haxe.Template(sample);
var myName = {name: "Joe"};
var output = template.execute(myName);

trace(output); // My name is Joe
```

Entre outras coisas, também podes usar condições para verificar dentro dos templates:

```haxe
var sample = "::if isAwake:: I'm awake ::else:: Zzzzz ::end::";
var template = new haxe.Template(sample);
var awake = {isAwake: false};
var output = template.execute(awake);

trace(output); // Zzzzz
```
