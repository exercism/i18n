# Anexo às instruções

## Instruções específicas do percurso

No exercício "Yacht", vais criar um verbo que calcula a pontuação de um único lançamento de cinco dados no jogo Yacht, com base na categoria escolhida.

Para este exercício, o teu verbo vai receber dois argumentos:

- **Argumento esquerdo**: uma string que representa a categoria de pontuação a aplicar ao lançamento dos dados.
- **Argumento direito**: uma lista de inteiros que representa os cinco dados lançados.

O teu verbo deve ser definido de modo a tratar estes parâmetros de entrada da seguinte forma:

```j
  category =. 'Full House'
  dice     =. 1 3 3 3 5
  
  category scoreYacht dice
```
