# Instructions

Neste exercício tens de implementar algumas funções para manipular uma lista de linguagens de programação.

## 1. Define uma função que devolve uma lista de linguagens vazia

Define a função `new`, que não recebe argumentos e devolve uma lista vazia.

```haskell
new
-- -> []
```

## 2. Define uma função que acrescenta uma linguagem à lista

Define a função `add/2`, que recebe 2 argumentos (uma _lista de linguagens_ e um literal de string de uma _linguagem_).
Deve devolver a lista resultante, com a nova linguagem colocada no início da lista dada.

```haskell
add new "Clojure"
-- -> ["Clojure"]
add ["Clojure"] "Haskell"
-- -> ["Haskell", "Clojure"]
```

## 3. Define uma função que remove uma linguagem da lista

Define a função `remove`, que recebe 1 argumento (uma _lista de linguagens_).
Deve devolver a lista sem o primeiro elemento. Assume que a lista tem sempre pelo menos um elemento.

```haskell
remove ["Haskell", "Clojure", "Erlang"]
-- -> ["Clojure", "Erlang"]
```

## 4. Define uma função que devolve o primeiro elemento da lista

Define a função `first`, que recebe 1 argumento (uma _lista de linguagens_).
Deve devolver a primeira linguagem da lista.
Assume que a lista tem sempre pelo menos um elemento.

```haskell
first ["Elixir", "Haskell", "Clojure", "Prolog"]
-- -> "Elixir"
```

## 5. Define uma função que devolve quantas linguagens há na lista

Define a função `count`, que recebe 1 argumento (uma _lista de linguagens_).
Deve devolver o número de linguagens na lista.

```haskell
count ["Prolog", "Elm"]
-- -> 2
```

## 6. Define uma função que determina se a lista inclui uma linguagem funcional

Define a função `isFunctionalList`, que recebe 1 argumento (uma _lista de linguagens_).
Deve devolver um valor Boolean.
Deve devolver `True` se _"Haskell"_ for uma das linguagens da lista.

```haskell
isFunctionalList ["Haskell"]
-- -> True
```
