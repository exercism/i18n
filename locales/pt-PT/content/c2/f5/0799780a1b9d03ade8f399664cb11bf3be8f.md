# Introdução

Felt é um dos tipos escalares em Cairo, tal como os números inteiros e os Boolean, e é representado pela palavra-chave `felt252`.
O `felt252` é um tipo de dados fundamental em Cairo, do qual derivam todos os outros tipos de dados.
O `felt252` também pode ser usado para guardar [representações curtas de strings][felts] com um comprimento máximo de 31 carateres.

Por exemplo:

```rust
    let felt: felt252 = 100;
    let felt_as_str: felt252 = 'Hello Starknet!';

    let _felt = felt + felt_as_str;
```

[felts]: https://starknet-by-example.voyager.online/getting-started/basics/bytearrays-strings.html#short-strings
