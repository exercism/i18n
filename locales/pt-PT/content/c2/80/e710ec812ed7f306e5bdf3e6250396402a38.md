# Dicas

## 1. Gera um planeta aleatório

- Isto parece uma [amostragem][ref-sample] a partir de um vetor de entrada.
- É possível haver duplicados, por isso faz a amostragem com reposição.

## 2. Gera um número de registo aleatório para uma nave estelar

- A parte numérica é uma amostragem de um intervalo.
- Há várias formas de construir a string, incluindo [`sprintf()`][ref-sprintf] e [`str_glue()`][ref-str_glue].

## 3. Gera aleatoriamente uma frota de naves estelares

- A Introdução fala sobre baralhar os elementos.

## 4. Gera uma data estelar aleatória

- Queremos um número de vírgula flutuante com [distribuição uniforme][ref-runif] entre um limite inferior e um limite superior.
- Podes ignorar, nesta tarefa, os pormenores sobre limites inclusivos ou exclusivos.
