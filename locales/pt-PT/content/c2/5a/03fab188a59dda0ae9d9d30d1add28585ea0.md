# Instruções

Implementa a operação `accumulate`, que, dada uma coleção e uma operação a aplicar a cada elemento dessa coleção, devolve uma nova coleção com o resultado da aplicação dessa operação a cada elemento da coleção de entrada.

Dada a coleção de números:

- 1, 2, 3, 4, 5

E a operação:

- elevar um número ao quadrado (`x => x * x`)

O teu código deve ser capaz de produzir a coleção dos quadrados:

- 1, 4, 9, 16, 25

Dá uma vista de olhos à suite de testes para veres a assinatura esperada da função.

## Restrições

Não mexas na funcionalidade collect/map/fmap, ou lá como lhe chamam, que a tua biblioteca padrão oferece!
Resolve este exercício sozinho, recorrendo a outras ferramentas básicas.
