# Introdução

O Elixir é uma linguagem dinamicamente tipada, o que significa que não faz verificações de tipos em tempo de compilação. Ainda assim, as especificações de tipos podem ser usadas como forma de documentação.

Podes adicionar uma especificação de tipos a uma função com o atributo de módulo `@spec`, imediatamente antes da definição da função. Depois de `@spec` vem o nome da função e uma lista com os tipos de todos os seus argumentos, entre parênteses e separados por vírgulas. O tipo do valor devolvido é separado dos argumentos da função por dois pontos duplos `::`.

```elixir
@spec longer_than?(String.t(), non_neg_integer()) :: boolean()
def longer_than?(string, length), do: String.length(string) > length
```

## Tipos

Os tipos mais usados incluem:

- Boolean: `boolean()`
- strings: `String.t()`
- números: `integer()`, `non_neg_integer()`, `pos_integer()`, `float()`
- listas: `list()`
- um valor de qualquer tipo: `any()`

Alguns tipos também podem ser parametrizados; por exemplo, `list(integer)` é uma lista de números inteiros.

Os valores literais também podem ser usados como tipos.

Uma união de tipos pode ser escrita com a barra vertical `|`. Por exemplo, `integer() | :error` significa ou um número inteiro ou o átomo literal `:error`.

Podes encontrar uma lista completa de todos os tipos na [secção "Typespecs" da documentação oficial][types].

## Nomear os argumentos

Os argumentos na especificação de tipos também podem ter nome, o que é útil para distinguir vários argumentos do mesmo tipo. O nome do argumento, seguido de dois pontos duplos, vem antes do tipo do argumento.

```elixir
@spec to_hex({hue :: integer, saturation :: integer, lightness :: integer}) :: String.t()
```

## Tipos personalizados

As especificações de tipos não se limitam aos tipos incorporados. Podes definir tipos personalizados com o atributo de módulo `@type`. Uma definição de tipo personalizado começa com o nome do tipo, seguido de dois pontos duplos e depois do próprio tipo.

```elixir
@type color :: {hue :: integer, saturation :: integer, lightness :: integer}

@spec to_hex(color()) :: String.t()
```

Um tipo personalizado pode ser usado no mesmo módulo onde é definido, ou noutro módulo.

[types]: https://hexdocs.pm/elixir/typespecs.html#types-and-their-syntax
