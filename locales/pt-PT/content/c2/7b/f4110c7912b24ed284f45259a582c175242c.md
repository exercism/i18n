# Introdução

## Números

Os dois tipos de números mais comuns em Ruby são:

- **Números inteiros:** números sem algarismos depois do separador decimal (números inteiros). Exemplos: `-6`, `0`, `1`, `25`, `976` e `500000`.
- **Números de vírgula flutuante:** números com um ou mais algarismos depois do separador decimal. Exemplos: `-2.4`, `0.1`, `3.14`, `16.984025` e `1024.0`.

São implementados através das classes `Integer` e `Float`.

Estas classes têm métodos que convertem valores de um tipo no outro. Os números `Integer` são exatos até à unidade inteira, enquanto o `Float` tem uma precisão fracionária em relação ao número inteiro:
- `Integer#to_f`: Converte num novo número de vírgula flutuante
- `Float#ceil`: Arredonda para cima até ao número inteiro mais próximo
- `Float#floor`: Arredonda para baixo até ao número inteiro mais próximo
- `Float#round`: Arredonda para o número inteiro mais próximo
- `Float#to_i`: Trunca para o número inteiro mais próximo

## Condicionais

Ruby tem aquilo a que se chamam expressões de controlo de fluxo. Estas são usadas para controlar a forma como o programa é executado e recebem um valor verdadeiro ou falso.
Existem operadores que podem ser usados para criar valores verdadeiros ou falsos, conhecidos como [operadores de comparação][comparison-operators].

Existem duas expressões de controlo principais que determinam que código é executado e que código não é.
Ou seja, qual dos ramos será executado.

Essas duas são: `if` e a expressão `unless`.

## Operadores de comparação

Os [operadores de comparação][comparison-operators] são usados para comparar valores e devolver um valor `true` ou `false`.
Os operadores seguintes exigem que os dois valores a comparar sejam do mesmo tipo.
Se os valores não forem do mesmo tipo, o compilador dá um erro.
Aqui está uma lista dos operadores e um exemplo de quando dão um valor `true`:

| Método | Descrição             | Exemplo |
| ------ | --------------------- | ------- |
| <      | menor que             | 4 < 5   |
| <=     | menor ou igual        | 4 <= 4  |
| >      | maior que             | 3 > 1   |
| >=     | maior ou igual        | 2 >= 2  |

Os operadores de igualdade e de desigualdade podem ser usados para comparar qualquer tipo de valor, ao contrário dos operadores já mencionados.
O operador `==` é usado para verificar se dois valores são iguais, o que inclui verificar o tipo do valor.
O `!=` funciona da mesma forma, mas devolve `true` se os valores não forem iguais e `false` se forem iguais.
Aqui está uma lista dos operadores de igualdade e de desigualdade e um exemplo de quando dão um valor `true`:

| Método | Descrição   | Exemplo |
| ------ | ----------- | ------- |
| ==     | igual       | 4 == 4  |
| !=     | diferente   | 5 != 4  |

## Condicional `if`

A condicional [`if`][if] é usada para verificar se uma determinada condição é "verdadeira" ou "falsa".
Se a condição for verdadeira, o código dentro da condicional `if` é executado.
Uma condicional `if` termina com a palavra-chave `end`.

```ruby
value = 1
if value == 1
  "1 is equal to 1"
end
# => "1 is equal to 1"

if value > 2
  "1 is greater than 2"
end
# => nil
```

## Condicional `unless`

A condicional `unless` funciona de forma muito semelhante à condicional `if`, mas executa o código dentro da condicional `unless` se a condição for falsa.

```ruby
value = 1
unless value == 1
  "1 is not equal to 1"
end
# => nil

unless value > 2
  "1 is not greater than 2"
end
# => "1 is not greater than 2"
```

## Cláusula `else`

A cláusula `else` pode ser usada em conjunto com a condicional `if`.
A cláusula `else` é executada se o ramo `if` não for executado.

```ruby
value = 1
if value == 1
  "1 is equal to 1"
else
  "1 is not equal to 1"
end
# => "1 is equal to 1"
```

## Cláusulas `if` em cascata

A cláusula `elsif` pode ser usada em conjunto com a condicional `if`.
A cláusula `elsif` é executada se o ramo `if` não for executado e a condição da cláusula `elsif` for verdadeira.
As cláusulas `elsif` podem ser encadeadas e a primeira condição verdadeira é executada.
Também pode haver uma cláusula `else` no final da condicional `if`, que é executada se nenhuma das anteriores tiver sido verdadeira.

```ruby
value = 1
if value != 1
  "1 is not equal to 1"
elsif value > 2
  "1 is greater than 2"
else
  "1 is not equal to 1 and 1 is not greater than 2"
end
# => "1 is not equal to 1 and 1 is not greater than 2"
```
