# Testes

Faz com que o primeiro teste compile, seja ligado e passe, seguindo as [três regras do desenvolvimento orientado a testes][3-tdd-rules].

O makefile incluído pode ser usado para criar e executar os testes com a tarefa `test`.

```console
$ make test
```

Cria apenas as funções de que precisas para resolver os erros do compilador e fazer o teste falhar.
Depois, escreve apenas o código suficiente para fazer o teste passar.
Quando terminares, passa para o teste seguinte.

À medida que avanças pelos testes, aproveita para refatorar a tua implementação para melhorar a legibilidade e a expressividade e depois passa para o teste seguinte.

Tenta usar os recursos padrão do C99 em vez de escreveres os teus próprios algoritmos ou mecanismos de baixo nível à mão.

## Verificação de fugas de memória

O makefile inclui também uma compilação que verifica alguns erros comuns relacionados com fugas de memória e acessos fora dos limites a arrays.
Para executar estas verificações, usa o seguinte na linha de comandos:

```console
$ make memcheck
```
