# Instalação

Vamos usar o *PolyML* como a nossa implementação de Standard ML.

Se estás a usar o Windows, podes descarregar um instalador em [https://github.com/polyml/polyml/releases](https://github.com/polyml/polyml/releases).
Encontras instruções gerais para Linux/OS X/Free BSD em [https://github.com/polyml/polyml#readme](https://github.com/polyml/polyml#readme).

Se quiseres instalar a partir do código-fonte, o processo é bastante simples:

```sh
$ git clone https://github.com/polyml/polyml.git
$ cd polyml
$ ./configure
```

Se quiseres instalá-lo numa localização personalizada, por exemplo `$HOME/.local`:

```sh
$ ./configure --prefix=$HOME/.local
```

Último passo:

```sh
$ make compiler
$ make install
```

Verifica se ficou instalado corretamente:

```sh
$ poly
```

Se vires o intérprete, está tudo pronto!
Caso contrário, provavelmente terás de adicionar `$HOME/.local/bin` (ou `<you prefix>/bin`) ao teu `$PATH`.
