# Dicas

## Geral

- Não te preocupes com o estado de funcionamento em que a máquina se encontra; por exemplo, não estará a funcionar quando a ligares à corrente.

## 1. Luz de depuração

- Tens de definir uma classe com o nome `JuiceMaker`.
- Tens de definir um [método de classe][class-methods] que devolve `true`.

## 2. Inicializar a máquina

- Cria um [construtor][new-initialize] para a classe `JuiceMaker`.
- Cria uma [variável de instância][instance-variable] `@running` que é definida como `false`.
- Cria uma [variável de instância][instance-variable] `@fluid` que é definida com o valor do argumento passado ao construtor.

## 3. Ligar a máquina

- Define um método de instância chamado `start`.
- Define a [variável de instância][instance-variable] `@running` como `true`.

## 4. Estado da máquina

- Define um método de instância chamado `running?`.
- Devolve a [variável de instância][instance-variable] `@running`.

## 5. Adicionar sumo

- Define um método de instância chamado `add_juice`, que recebe um número inteiro como argumento.
- Define a [variável de instância][instance-variable] `@fluid` como a soma do valor atual de `@fluid` com o argumento passado ao método.

## 6. Desligar a máquina

- Define um método de instância chamado `stop`, que recebe um número inteiro como argumento.
- Define a [variável de instância][instance-variable] `@running` como `false`.
- Define a [variável de instância][instance-variable] `@fluid` como o valor atual de `@fluid` menos cinco vezes o argumento passado ao método.

[new-initialize]: https://crystal-lang.org/reference/latest/syntax_and_semantics/new%2C_initialize_and_allocate.html
