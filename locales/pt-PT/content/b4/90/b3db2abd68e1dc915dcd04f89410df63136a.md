# Introdução

## Propriedades

Uma propriedade em C# é um membro de uma classe que dá acesso aos dados dentro dessa classe.
Quem chama pode definir ou obter (get) os dados. As propriedades podem ser implementadas
automaticamente ou ter um campo de suporte. Incluem um acessador set e/ou um acessador get.
Nalgumas outras linguagens, um "mutator" é mais ou menos equivalente a um acessador set e um
"accessor" é mais ou menos equivalente a um acessador get, embora a composição da sintaxe seja
completamente diferente.

Ao definir uma propriedade, o valor de entrada pode ser validado, formatado ou manipulado de
outra forma e, de facto, qualquer operação programática acessível ao código da classe pode ser
executada.

Da mesma forma, ao obter uma propriedade, os dados podem ser calculados ou formatados e, mais
uma vez, qualquer operação programática disponível para a classe pode ser executada.

As propriedades têm modificadores de acesso (`public`, `private` etc.) da mesma forma que
outros membros da classe, mas o acessador set pode ter um nível de acesso independente do
acessador de obtenção (get) e vice-versa. Uma propriedade não tem de ter ambos os acessadores,
pode ter apenas um (get ou set).

A sintaxe básica para expressar propriedades pode assumir duas formas:

### Propriedades suportadas por campo/expressão:

```csharp
private int myField;
public int MyProperty
{
    get { return myField; }
    set { myField = value; }
}
```

### Propriedades autoimplementadas

```
public int MyProperty { get; private set; } = 42;
```

A inicialização é opcional.
