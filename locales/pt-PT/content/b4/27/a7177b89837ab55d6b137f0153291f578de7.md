## Variáveis

As variáveis são nomes simbólicos que se referem a valores ou a contentores.
Os nomes das variáveis podem começar com, ou sem, um caráter especial chamado [sigil][sigils], seguido de um identificador.
Um sigil também pode ser seguido de um [twigil][twigils].

Variáveis com sigils diferentes guardam tipos diferentes de estruturas de dados.

```raku
my $scalar; # Assigned value will be stored as-is
my @array;  # Assigned value will be coerced into an array
my %hash;   # Assigned value will be coerced into a hash
my &code;   # Assigned value must be a code object
```

Os twigils que vais ver com mais frequência são `^` e `:`, que funcionam como atalhos para as assinaturas de blocos de código.
O `^` é para parâmetros posicionais.
O `:` é para parâmetros nomeados.

```raku
{ $^a + $^b }; #`[same as] ->  $a,  $b { $a + $b }; # Called with (1, 2)
{ $:a + $:b }; #`[same as] -> :$a, :$b { $a + $b }; # Called with (a => 1, b => 2)
```

## Contentores

Os contentores são o que permite modificar uma variável.

As variáveis declaradas com `constant`, e as variáveis sem sigil (declaradas com um `\` antes do identificador), não têm contentores e referem-se diretamente a valores.

```raku
my $foo = 1;
$foo = 2;

constant $bar = 3;
my \baz = 4;

# The following will fail
$bar = 5;
baz  = 6;
```

## Tipos

As variáveis podem ser declaradas com uma restrição de tipo.
As restrições de tipo também podem ter coerções, dando um tipo aceite como argumento ao tipo desejado.

```raku
my Bool   $foo = True; # Booleans only.
my Bool() $bar = 0;    # Accepts type `Any`. Coerced to False.

my Str(Bool(Int)) $baz;
$baz = 1;   # "True"
$baz = "1"; # "1"
```

Usar restrições de tipo é uma forma de tirar partido de rotinas de despacho múltiplo.

```raku
multi foo (Int $bar) { say 'Type of arg to $bar is Int!' }
multi foo (Str $bar) { say 'Type of arg to $bar is Str!' }
```

Em Raku, os tipos são apenas outro tipo de objeto.
Declarar uma `class`, um `role` ou um `enum` são formas de criar os teus próprios objetos de tipo.
Por exemplo, o tipo incorporado `Bool` é construído com um enum: `enum Bool <False True>`.

Também podes criar restrições de tipo simples baseadas noutros tipos com a palavra-chave `subset`.
Podes restringir ainda mais este novo tipo com uma cláusula `where`.
Uma cláusula `where` também pode ser usada numa assinatura.

```raku
subset PositiveInt of Int where * > 0;

sub is-even (PositiveInt $n where  %% 2) { say "$n is even!" }
```
