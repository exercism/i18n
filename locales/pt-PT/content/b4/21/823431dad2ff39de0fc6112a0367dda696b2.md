# Instruções

Tens a contabilidade de uma pequena empresa e, todos os dias, chegam
transações em linhas de texto desorganizadas. Vais usar expressões regulares
para validar montantes, extrair valores pelo símbolo que os marca e
sinalizar linhas que precisam de uma análise mais atenta.

## 1. Validar um montante

Um montante bem formado é um `$`, um ou mais algarismos e uma parte de
cêntimos *opcional*, composta por um ponto seguido de exatamente dois
algarismos: `$100` ou `$100.50`, mas não `$100.5`. Define `valid-amount?`,
que devolve `t` quando a string *inteira* é um montante bem formado.

```factor
"$100.50" valid-amount? .   ! => t
"$100"    valid-amount? .   ! => t
"$100.5"  valid-amount? .   ! => f
```

## 2. Extrair os valores em dólares

Define `dollar-amounts`, que devolve todos os números que aparecem
imediatamente a seguir a um `$` na linha (apenas os algarismos, sem o
`$`), por ordem.

```factor
"spent $100 and $25 today" dollar-amounts .
! => { "100" "25" }
```

## 3. Extrair as percentagens

Define `percentages`, que devolve todos os números que são
imediatamente seguidos por um `%`.

```factor
"up 5% then down 12%" percentages .
! => { "5" "12" }
```

## 4. Sinalizar uma linha

Define `flagged?`, que devolve `t` quando a linha menciona `refund` ou
`chargeback` em qualquer combinação de maiúsculas e minúsculas.

```factor
"Issued a REFUND today" flagged? .   ! => t
"a normal sale"         flagged? .   ! => f
```
