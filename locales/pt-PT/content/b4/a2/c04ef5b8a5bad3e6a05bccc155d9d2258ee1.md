# Instruções

És o comissário do navio, responsável pela gestão do inventário da despensa. O inventário é uma tabela de hash em que cada chave é o nome de um item e o valor é a quantidade em stock.

## 1. Criar um inventário a partir de uma lista

Define `create-inventory` para receber uma sequência de nomes de itens e devolver uma tabela de hash que associa cada nome único à respetiva contagem.

```factor
{ "coal" "wood" "wood" "diamond" "diamond" "diamond" } create-inventory .
! => H{ { "coal" 1 } { "wood" 2 } { "diamond" 3 } }
```

## 2. Adicionar mais itens

Define `add-items` para receber um inventário e uma sequência de itens e devolver um novo inventário cujas contagens foram incrementadas para cada item listado. O inventário original não deve ser modificado.

```factor
H{ { "coal" 1 } } { "wood" "iron" "coal" "wood" } add-items .
! => H{ { "coal" 2 } { "wood" 2 } { "iron" 1 } }
```

## 3. Decrementar contagens

Define `decrement-items` para receber um inventário e uma sequência de itens e devolver um novo inventário cujas contagens foram diminuídas em uma unidade para cada item listado. As contagens nunca podem ficar abaixo de zero, e os itens que ainda não estão no inventário devem ser omitidos (não são inseridas entradas negativas).

```factor
H{ { "coal" 3 } { "diamond" 1 } { "iron" 5 } }
{ "diamond" "coal" "iron" "iron" } decrement-items .
! => H{ { "coal" 2 } { "diamond" 0 } { "iron" 3 } }
```

## 4. Remover um item por completo

Define `remove-item` para receber um inventário e um item e devolver um novo inventário com esse item removido. Se o item não estiver presente, devolve uma cópia inalterada.

```factor
H{ { "coal" 2 } { "wood" 1 } { "diamond" 2 } } "coal" remove-item .
! => H{ { "wood" 1 } { "diamond" 2 } }
```

## 5. Listar os itens disponíveis

Define `list-inventory` para receber um inventário e devolver um array de pares `{ name quantity }` que contém apenas os itens cuja quantidade é maior que zero, ordenados alfabeticamente por nome.

```factor
H{ { "coal" 7 } { "wood" 11 } { "diamond" 2 } { "iron" 7 } { "silver" 0 } }
list-inventory .
! => { { "coal" 7 } { "diamond" 2 } { "iron" 7 } { "wood" 11 } }
```
