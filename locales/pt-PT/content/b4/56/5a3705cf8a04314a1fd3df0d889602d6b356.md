# Ajuda

Se estiveres com dificuldades, podes recorrer a um dos seguintes recursos:

- [a etiqueta `c++-faq` no StackOverflow](https://stackoverflow.com/tags/c%2b%2b-faq/info)
- [FAQ de C++ do isocpp.com](https://isocpp.org/faq)
- O [CppReference](http://en.cppreference.com/) é uma referência em wiki à linguagem C++ e à biblioteca padrão
- [C traps and pitfalls](http://www.slideshare.net/LegalizeAdulthood/c-traps-and-pitfalls-for-c-programmers) é útil se estiveres a começar com C++, mas já tiveres programado em C
