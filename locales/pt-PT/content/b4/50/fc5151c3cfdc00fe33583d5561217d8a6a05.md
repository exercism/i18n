# Números em Phix

Existem dois tipos de dados em Phix para guardar números, o integer e o atom.
Os integer são com sinal e um bit menores do que a palavra da máquina e, por isso (atenção, spoiler), insuficientes para esta tarefa, mesmo em 64 bits.
Os atom conseguem guardar valores integer de maior precisão, o que é suficiente pelo menos em 64 bits, que é certamente o que estás a usar quando corres online no site
exercism.org, e provavelmente na CLI, desde que seja isso que instalaste: basta executar 'p' numa consola de terminal e ele mostra-to.

## Máquinas de 32 bits

No entanto, mesmo os atom em 32 bits continuam a não ser suficientemente precisos ou grandes para completar este exercício. Para contornar isso,
podes, em alternativa, devolver uma string, que deve/pode ser exata, sem vírgulas nem underscores, mas não és obrigado a fazê-lo em 64 bits.
Podes construir essas strings manualmente ou usar uma biblioteca de precisão arbitrária, como a [mpfr][mpfr].

Uma versão de Phix de 32 bits continua a ser essencial para testar adequadamente no desktop/Phix antes de usar p2js, uma vez que o JavaScript é intrinsecamente
de 32 bits (ou, mais precisamente, talvez 53 bits), mesmo num navegador de 64 bits a correr numa máquina de 64 bits.

Os limites exatos do que pode ser guardado nos integer e nos atom do Phix estão, naturalmente, detalhados com mais pormenor no [manual][manual].

[mpfr]: http://phix.x10.mx/docs/html/mpfr.htm
[manual]: http://phix.x10.mx/docs/html/atoms.htm
