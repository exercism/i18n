# Anexo às instruções

## Registos

| Registo | Utilização           | Tipo    | Descrição                                                                             |
| ------- | -------------------- | ------- | ------------------------------------------------------------------------------------- |
| `$a0`   | parâmetro de entrada | inteiro | número                                                                                |
| `$v0`   | valor devolvido      | inteiro | classificação (`1` = `perfect`, `2` = `abundant`, `3` = `deficient`, `-1` = `error`)   |
| `$t0-9` | temporário           | qualquer| usado para armazenamento temporário                                                   |
