# Dicas

## Geral

- Não te preocupes com a forma como os argumentos são obtidos; concentra-te apenas em combiná-los para devolver o resultado pretendido.

## 1. Define se o pac-man pode comer um fantasma

- A função tem de devolver um valor [Boolean][boolean].
- Podes usar o operador [Boolean][boolean] [`and/2`][boolean-and] para combinar os argumentos e obteres um resultado.

## 2. Define se o pac-man pontua

- A função tem de devolver um valor [Boolean][boolean].
- Podes usar o operador [Boolean][boolean] [`or/2`][boolean-or] para combinar os argumentos e obteres um resultado.

## 3. Define se o pac-man perde

- A função tem de devolver um valor [Boolean][boolean].
- Podes usar os operadores [Boolean][boolean] [`and/2`][boolean-and] e [`not/1`][boolean-not] para combinar os argumentos e obteres um resultado.

## 4. Define se o pac-man ganha

- A função tem de devolver um valor [Boolean][boolean].
- Podes usar os operadores [Boolean][boolean] [`and/2`][boolean-and] e [`not/1`][boolean-not] para combinar os argumentos e os resultados de uma das funções implementadas anteriormente.

[boolean]: https://hexdocs.pm/elixir/basic-types.html#booleans-and-nil
[boolean-and]: https://hexdocs.pm/elixir/Kernel.html#and/2
[boolean-or]: https://hexdocs.pm/elixir/Kernel.html#or/2
[boolean-not]: https://hexdocs.pm/elixir/Kernel.html#not/1
