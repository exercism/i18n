# Sobre

As constantes em Gleam são uma forma de dar nomes a valores. São definidas com a palavra-chave `const`.

```gleam
pub const pi: Float = 3.14159

pub fn circle_area(radius: Float) -> Float {
  radius *. radius *. pi
}
```

Quando são definidas com a palavra-chave `pub`, as constantes do módulo podem ser acedidas a partir de outros módulos. Caso contrário, só podem ser acedidas dentro do próprio módulo onde são definidas.
