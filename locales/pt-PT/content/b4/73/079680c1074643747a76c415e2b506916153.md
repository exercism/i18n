# Introdução

A Julia, tal como a maioria das linguagens de programação, oferece uma grande variedade de tipos de coleção.

Alguns são ordenados por natureza (incluindo `Vectors` e `Arrays` de dimensão superior), por isso podemos aceder aos elementos pela sua posição.
Outras coleções não têm ordem (`Sets`, `Dicts`) e os elementos têm de ser acedidos por chave ou por valor.

No caso mais simples, supõe que temos um `Vector` de `Ints` e o queremos ordenar por ordem crescente.

```julia-repl
julia> v = [3, 2, 4, 1]
4-element Vector{Int64}:
 3
 2
 4
 1

julia> sort(v)
4-element Vector{Int64}:
 1
 2
 3
 4

# sort descending
julia> sort(v, rev=true)
4-element Vector{Int64}:
 4
 3
 2
 1
```

Simples!
A função `sort()` tem um nome óbvio e, aparentemente, devolve o `Vector` ordenado.

_Só estava a brincar!_
A esta altura do currículo, suspeitas talvez (e com razão) que há nuances que precisamos de discutir.

## Funções que alteram vs. funções que não alteram

Depois de correr `sort(v)`, como fica o `v`?

```julia-repl
julia> v
4-element Vector{Int64}:
 3
 2
 4
 1

julia> issorted(v)
false
```

O vetor original fica inalterado.
`sort()` é uma função ***que não altera*** os argumentos e devolve uma _cópia_ do seu argumento.

Em muitos contextos, isto é um bom design: temos uma [função pura][wiki-pure-func] cujo comportamento é fácil de analisar, mesmo em código paralelo e distribuído.

Por outro lado, imagina que tínhamos um `array` com mil milhões de strings e o queríamos ordenar.

A ordenação será provavelmente lenta.
Além disso, temos de copiar tudo (_lento!_) e alocar memória suficiente (_vários gigabytes!_) para guardar a cópia.

Compara com este código bastante semelhante:

```julia-repl
# v is as previously

julia> issorted(v)
false

julia> sort!(v)
4-element Vector{Int64}:
 1
 2
 3
 4

julia> v
4-element Vector{Int64}:
 1
 2
 3
 4

julia> issorted(v)
true
```

Agora, o `Vector` de entrada é ordenado no próprio local, sem copiar, e a ordem original perde-se definitivamente.

Isto pode ser eficiente, pode ter erros e provocar efeitos secundários inesperados, pode ser confuso para outras pessoas que usem o teu código.
_Escolhe com cuidado!_

`sort!()` é uma "função que altera os argumentos" e, por convenção (_muito forte_), qualquer função que altere os seus argumentos tem um `!` acrescentado ao nome, como aviso para quem programa.

## Ordenar por quê?

Ordenar valores `Int64` é relativamente simples: até as crianças pequenas percebem que 2 é maior do que 1 e menor do que 3.

Outros tipos podem ser mais complicados, mas, em geral, `x < y` se `isless(x, y) == true`.
A Julia fornece implementações de `isless()` para a maioria dos tipos padrão.

Por exemplo, os carateres Unicode (as maiúsculas vêm antes das minúsculas, no caso das letras europeias):

```julia-repl
julia> j = collect("Julia")
5-element Vector{Char}:
 'J': ASCII/Unicode U+004A (category Lu: Letter, uppercase)
 'u': ASCII/Unicode U+0075 (category Ll: Letter, lowercase)
 'l': ASCII/Unicode U+006C (category Ll: Letter, lowercase)
 'i': ASCII/Unicode U+0069 (category Ll: Letter, lowercase)
 'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)

julia> sort(j)
5-element Vector{Char}:
 'J': ASCII/Unicode U+004A (category Lu: Letter, uppercase)
 'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)
 'i': ASCII/Unicode U+0false069 (category Ll: Letter, lowercase)
 'l': ASCII/Unicode U+006C (category Ll: Letter, lowercase)
 'u': ASCII/Unicode U+0075 (category Ll: Letter, lowercase)
```

Também podemos aplicar uma função arbitrária aos elementos antes de ordenar, como `abs`, para ignorar o sinal, ou `uppercase`, para ordenar sem distinguir maiúsculas de minúsculas:

```julia-repl
julia> nums = [3, -2, -4, 1]
4-element Vector{Int64}:
  3
 -2
 -4
  1

julia> sort(nums)
4-element Vector{Int64}:
 -4
 -2
  1
  3

julia> sort(nums, by=abs)
4-element Vector{Int64}:
  1
 -2
  3
 -4

# j is from "Julia", as previously

julia> sort(j, by=uppercase)
5-element Vector{Char}:
 'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)
 'i': ASCII/Unicode U+0069 (category Ll: Letter, lowercase)
 'J': ASCII/Unicode U+004A (category Lu: Letter, uppercase)
 'l': ASCII/Unicode U+006C (category Ll: Letter, lowercase)
 'u': ASCII/Unicode U+0075 (category Ll: Letter, lowercase)

julia> vecs = [[1, 3], [4, 2], [3, 4], [2, 1]];

julia> sort(vecs)  # by default sorts by the first element of the (2-element) vectors
4-element Vector{Vector{Int64}}:
 [1, 3]
 [2, 1]
 [3, 4]
 [4, 2]

julia> sort(vecs, by=last)
4-element Vector{Vector{Int64}}:
 [2, 1]
 [4, 2]
 [1, 3]
 [3, 4]
```

## Ordenar por índices

Se os elementos a ordenar forem objetos grandes, pode ser mais fácil trabalhar com o seu índice de posição.

```julia-repl
julia> langs = ["Julia", "C++", "Python", "Elixir"]
4-element Vector{String}:
 "Julia"
 "C++"
 "Python"
 "Elixir"

julia> inxs = sortperm(langs)  # => Integers
4-element Vector{Int64}:
 2
 4
 1
 3

julia> langs[inxs]  # sort the entire vector
4-element Vector{String}:
 "C++"
 "Elixir"
 "Julia"
 "Python"

julia> langs[inxs[1:2]]  # slice the indices
2-element Vector{String}:
 "C++"
 "Elixir"
```

Como `langs` é um Vector, cada índice é um número inteiro no [intervalo][concept-range] `1:length(langs)`.
O resultado de `sortperm()` é uma [permutação][wiki-permutation] destes números inteiros, correspondente a uma ordenação do vetor de entrada.

## Ordenação parcial

O teu programa precisa de ordenar a entrada inteira?
Nos casos em que só interessam os primeiros ou os últimos elementos, pode ser bastante mais rápido fazer uma [ordenação parcial][wiki-partial-sort].

A Julia fornece as funções `partialsort()` e `partialsort!()`, que garantem que o elemento ou intervalo de elementos especificado fica correto, mas não dão qualquer garantia quanto ao resto da entrada.

O segundo argumento pode ser um número inteiro ou um intervalo, que representa o índice ou os índices da entrada ordenada:

```julia-repl
julia> vsq = [9, 4, 16, 1];  # would be [1, 4, 9, 16] after a full sort

julia> partialsort(vsq, 4)
16

julia> partialsort(vsq, 2:3)
2-element view(::Vector{Int64}, 2:3) with eltype Int64:
 4
 9
```
