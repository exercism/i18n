# Introdução

A maioria dos programas tem dependências de algumas bibliotecas. Geri-las à mão pode ser um martírio. Felizmente, o ecossistema Rust vem com o `cargo` incluído! O `cargo` consegue gerir as dependências de um projeto.

Em Rust, vais ver muitas vezes pacotes externos referidos como "crates". Um crate é uma unidade de compilação em Rust. Um crate pode ser compilado para um binário ou para uma biblioteca.

Na maioria das vezes, adicionar uma dependência externa é tão simples como acrescentar uma linha ao teu ficheiro `Cargo.toml`.
