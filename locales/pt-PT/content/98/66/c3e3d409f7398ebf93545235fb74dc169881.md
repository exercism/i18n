# Acerca de

Um **objeto** JSON é, usando terminologia de outras linguagens, um "hash", um "map" ou um dicionário.

O JSON define um _objeto_ como:

> Um objeto é um conjunto não ordenado de pares **nome**/**valor**.
> Um objeto começa com `{` chaveta esquerda e termina com `}` chaveta direita.
> Cada _nome_ é seguido de `:` dois pontos e os pares _nome/valor_ são separados por `,` vírgula.

O _nome_ **tem de ser uma string**.
Outra palavra para _nome_ é _chave_.

O _valor_ pode ser de qualquer tipo JSON.
_Valores_ diferentes no mesmo objeto podem ser de tipos diferentes, como neste exemplo.

<!-- prettier-ignore -->
```json
{
  "name": "Jane",
  "age": 42,
  "pets": ["cat", "fish"],
  "address": {"street": "123 Main St", "city": "Springfield"}
}
```

<!-- prettier-ignore-end -->

Repara que **não pode** haver uma vírgula depois do _último_ par chave-valor.

## Criar objetos

Usa chavetas para reunir os pares nome/valor.
Mesmo que os nomes tenham de ser strings, não precisam de estar entre aspas se forem **semelhantes a identificadores** (compostos por carateres alfanuméricos e underscore, e que não comecem por um algarismo).

```jq
{name: "Jane", age: 42}
```

É válido usar chaves que não sejam _semelhantes a identificadores_.
Basta colocá-las entre aspas.

```jq
{"first name": "Jane", "last name": "Lopez", age: 42}
```

Se o nome for o resultado de uma expressão, a expressão **tem de** estar entre parênteses.

```sh
$ echo "Jane" | jq -Rc '{.: 42}'
jq: error: syntax error, unexpected '.' (Unix shell quoting issues?) at <top-level>, line 1:
{.: 42}
jq: error: May need parentheses around object key expression at <top-level>, line 1:
{.: 42}
jq: 2 compile errors

$ echo "Jane" | jq -Rc '{(.): 42}'
{"Jane":42}
```

### Notações abreviadas

Alguns casos frequentes de construção de objetos têm sintaxe abreviada.

1. Reutilizar pares chave-valor de um objeto de entrada.

   ```sh
   $ jq -n '$ENV | {USER: .USER, EDITOR: .EDITOR}'
   {
     "USER": "glennj",
     "EDITOR": "vim"
   }
   ```

   `$ENV` é um objeto que contém os pares nome-valor do ambiente.

   Os pares repetitivos `key: .key` podem ser escritos apenas como `key`

   ```sh
   $ jq -n '$ENV | {USER, EDITOR}'
   {
     "USER": "glennj",
     "EDITOR": "vim"
   }
   ```

1. Da mesma forma, há uma forma abreviada quando se usam variáveis.

   ```sh
   $ jq -cn '"foo" as $a | "bar" as $b | {a: $a, b: $b}'
   {"a":"foo","b":"bar"}

   $ jq -cn '"foo" as $a | "bar" as $b | {$a, $b}'
   {"a":"foo","b":"bar"}
   ```

## Indexação

Os valores são obtidos de um objeto com **notação de ponto**.

```jq
{name: "Jane", age: 42} | .age    # => 42
```

Se não puderes referir a chave como um identificador, usa **notação de parênteses retos**.

```jq
"name" as $key | {name: "Jane", age: 42} | .$key    # => error
"name" as $key | {name: "Jane", age: 42} | .[$key]  # => "Jane"
```

Se a chave não estiver no objeto, o resultado é `null`.

```jq
{name: "Jane", age: 42} | .sport  # => null
```

### Indexação de valores aninhados

Vais descobrir que esta é uma ação que precisas de fazer repetidamente ao analisar resultados de consultas a APIs.

Dado um objeto que contém valores de arrays ou de objetos, podemos "encadear" expressões de indexação.

```jq
{
  "name": "Jane",
  "age": 42,
  "pets": ["cat", "fish"],
  "address": {"street": "123 Main St", "city": "Springfield"}
}
| (
  .pets[1],       # => "fish"
  .address.city   # => "Springfield"
)
```

## Adicionar ou alterar pares chave-valor

Para adicionar um novo par chave-valor a um array, ou para atualizar o valor de uma chave existente, usa o operador de atribuição `=`, com uma expressão de indexação do lado esquerdo.

```jq
{name: "Jane", age: 42} | .sport = "tennis" | .age = 21
# => {
#      "name": "Jane",
#      "age": 21,
#      "sport": "tennis"
#    }
```

O operador `+` _funde_ objetos.

```jq
{Richard: 54} + {Jane: 42}
# => {
#      "Richard": 54,
#      "Jane": 42
#    }
```

## Remover uma chave

Usa a função `del` para remover uma chave.
Devolve o objeto atualizado.

```jq
{name: "Jane", age: 42} | del(.age)   # => {"name": "Jane"}
```

O parâmetro de `del` é uma **expressão de indexação** (com notação de ponto ou de parênteses retos) que corresponde a uma chave no objeto.
O `jq` chama-lhe uma **expressão de caminho**.
Não basta fornecer uma string.

```jq
{name: "Jane", age: 42} | del(name)        # error: name/0 is not defined
{name: "Jane", age: 42} | del("name")      # error: Invalid path expression with result "name"
{name: "Jane", age: 42} | del(.name)       # OK
{name: "Jane", age: 42} | del(.["name"])   # OK
```

## Pertença

- Para testar se o objeto tem uma chave, usa a função `has`.

  ```jq
  {name: "Jane", age: 42} as $example
  |
    ($example | has("name")),    # => true
    ($example | has("sport"))    # => false
  ```

- Testa se uma chave está num objeto com `in`.

  ```jq
  {name: "Jane", age: 42} as $example
  |
    ("name"  | in($example)),    # => true
    ("sport" | in($example))     # => false
  ```

## Listar as chaves ou os valores

Usa a função `keys` para devolver uma lista de todas as chaves.

```jq
{name: "Jane", age: 42} | keys   # => ["age", "name"]
```

Repara que `keys` _ordena_ as chaves.
Para obteres as chaves na ordem original, usa `keys_unsorted`.

Não há uma função equivalente para listar todos os _valores_.
No entanto, o filtro `.[]` produz os valores do objeto como um _stream_, e esse stream pode ser capturado com o construtor de array `[...]`.

```jq
[{first: "Jane", last: "Lopez", status: "awesome!"} | .[]]
# => ["Jane", "Lopez", "awesome!"]
```

## Iteração

- A função `map_values(filter)` aplica o filtro a cada _valor_ no objeto.

  ```jq
  {first: "Jane", last: "Lopez", status: "awesome!"}
  | map_values(ascii_upcase)
  # => {"first": "JANE", "last": "LOPEZ", "status": "AWESOME!"}
  ```

- Para iterar sobre um objeto, temos primeiro de o converter num array de objetos chave-valor.
  A função `to_entries` faz isso.

  ```jq
  {name: "Jane", age: 42} | to_entries
  # => [
  #      {
  #        "key": "name",
  #        "value": "Jane"
  #      },
  #      {
  #        "key": "age",
  #        "value": 42
  #      }
  #    ]
  ```

  Neste ponto, podemos usar funções de iteração de arrays, como `map`.

- A função `from_entries` é a inversa: converte um array de objetos chave-valor num objeto.

  ```jq
  [
    {"key":"name", "value":"Jane"},
    {"key":"age", "value":42}
  ] | from_entries                  # => {"name": "Jane", "age": 42}
  ```

- Para aplicar um filtro a _cada_ par chave-valor num objeto, usa a função `with_entries(filter)`.

  Por exemplo, dado um objeto que associa um nome a uma idade, as chaves e os valores podem ser trocados da seguinte forma.

  ```jq
  {"Jane": 42, "Richard": 54}
  | with_entries({key: (.value | tostring), value: .key})
  ```

  produz

  ```json
  {
    "42": "Jane",
    "54": "Richard"
  }
  ```

  `with_entries(filter)` é o mesmo que

  ```jq
  to_entries | map(filter) | from_entries
  ```
