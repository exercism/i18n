# Apêndice às instruções

## Except

O valor devolvido da função `guess` é do tipo `Except String Result`.

Um [`Except ε α`][except] representa um cálculo que pode resultar num erro do tipo `ε` ou produzir um valor bem-sucedido do tipo `α`.
É uma mónada, o que permite compor este tipo de cálculos.

## Programação reativa

Por razões práticas, este exercício não exige uma abordagem de programação reativa.
Em vez disso, considera implementar uma [máquina de estados finitos][finite-state-machine].
