# Construtores de strings

Uma `STR` nunca muda. Por isso, o `+` não lhe pode acrescentar nada: tem de criar uma string totalmente nova com o conteúdo de ambas.

Isso é aceitável uma vez. Dentro de um ciclo, já não é:

```sather
   -- don't
   script ::= "";
   loop
      script := script + lines.elt!;
   end;
```

Cada volta copia tudo o que já foi construído para uma string nova e deita fora a antiga. Dez linhas dão dez cópias, cada uma maior do que a anterior. Cem linhas dão cem. O trabalho cresce com o *quadrado* do número de linhas, e um ciclo que parece inofensivo torna-se a parte lenta do programa.

## FSTR

Uma `FSTR` é uma string que *pode* ser alterada: um **construtor de strings**. Acrescentar-lhe algo escreve normalmente no espaço que já tem, por isso um ciclo sobre cem linhas faz aproximadamente o trabalho de cem linhas, em vez de cem cópias.

```sather
   script ::= #FSTR;
   loop
      script := script + lines.elt!;
   end;
   return script.str;
```

Há três coisas a reparar.

**`#FSTR` cria uma vazia.** `#FSTR(100)` cria uma com espaço já reservado para cem carateres, o que vale a pena fazer quando se sabe o tamanho.

**Tens de voltar a atribuir o resultado.** `script := script + ...`, nunca `script + ...` sozinho. Normalmente o resultado é o mesmo construtor que lá estava, mas quando este fica sem espaço é um novo, maior, e ignorar o resultado deixar-te-ia a escrever no antigo.

**`.str` no fim.** Uma rotina que promete `: STR` tem de devolver uma `STR`, e `.str` cria uma a partir do construtor.

## O que se pode acrescentar

O `+` numa `FSTR` aceita uma string, um caráter, um número inteiro ou um Boolean, por isso normalmente não é preciso converter primeiro:

```sather
   line ::= #FSTR;
   line := line + 1 + ". " + "Enter" + '!';   -- "1. Enter!"
```

## Novas linhas

`"\n"` dentro de uma string é uma nova linha: um só caráter, escrito com dois.

```sather
   script := script + "Enter" + "\n" + "Exit";
```
