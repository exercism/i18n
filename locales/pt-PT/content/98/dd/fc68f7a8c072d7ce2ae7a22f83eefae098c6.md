# Dicas

## 1. Determina se vais precisar de carta de condução

- Usa o [operador de igualdade][equality-operator] para verificar se o teu parâmetro de entrada é igual a uma determinada string.
- Usa um dos dois [operadores lógicos][logical-operators] que aprendeste no conceito de Boolean para combinar os dois requisitos.
- **Não** precisas de uma condicional para resolver esta tarefa. Podes devolver diretamente a expressão boolean que construíres.

## 2. Escolhe entre dois veículos potenciais para comprar

- Usa um [operador de comparação][comparison-operators] para determinar que opção vem primeiro na ordem lexicográfica.
- Usa um [modelo de string][string-templates] para criar a frase de recomendação.

## 3. Calcula uma estimativa para o preço de um veículo usado

- Usa uma [condicional if-else if-else][if-statement] para determinar a percentagem.
- Nas duas condições if, usa [operadores de comparação][comparison-operators] para comparar a idade do carro com os valores limite.
- Para calcular o resultado, aplica a percentagem ao preço original. Por exemplo, `30% of x` pode ser calculado dividindo `30` por `100` e multiplicando por `x`.
