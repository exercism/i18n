# Dicas

## 1. Define a aprovação

- Podes definir tipos personalizados com a sintaxe `pub type Name { Variant1 }`.

## 4. Define a atividade

- Podes definir tipos personalizados que contêm dados com a sintaxe `pub type Name { Variant1(SomeType) }`.

## 5. Classifica a atividade

- Podes fazer correspondência de padrões com as variantes de um tipo personalizado através de expressões case.
- Se quiseres acrescentar uma condição adicional a um padrão, podes adicionar uma guarda ao padrão com a palavra-chave `if`.
