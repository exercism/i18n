# Dicas

Este exercício centra-se num tipo composto definido com uma palavra-chave e em uniões de tipos.

## 1. Define uniões de tipos

- Vê o exemplo na introdução em que um tipo é nomeado.

## 2. Implementa o tipo composto Player

- Todos os campos devem ser *anotados com tipos*, dois deles com uniões de tipos.
- Vê o exemplo `Node` na introdução para um exemplo concreto de campos anotados com tipos.
- Todos os campos devem ter os valores predefinidos indicados nas instruções.

## 3. Apresenta-te

- Podes usar um [operador ternário][control-flow] para uma solução numa só linha.
- A função `ismissing` é útil aqui.

## 4. Implementa os métodos de incremento

- Os argumentos dos métodos têm de ser anotados com os tipos corretos para `name` e `mana`.
- Vê mais exemplos de assinaturas de funções / anotação de argumentos na introdução.
- Os [operadores ternários][control-flow] também podem ser usados aqui para soluções numa só linha.
- Pode ser útil estudar/rever o conceito de `Multiple Dispatch`, se for preciso.

## 5. Implementa a função de título

- Usa a tua função `increment`.
- Podes usar um [operador ternário][control-flow] para uma solução numa só linha.

## 6. Implementa a função de reanimação

- Usa a tua função `increment`.
- Devolve um jogador modificado se estiver morto, ou um jogador inalterado se estiver vivo.


[control-flow]: https://docs.julialang.org/en/v1/manual/control-flow/#man-conditional-evaluation
