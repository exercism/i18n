# Anexo às instruções

## Palavras

Define um tuplo `custom-set` e declara-o como uma instância do mixin `set` com `INSTANCE: custom-set set`.

- `<custom-set> ( -- set )`: constrói um conjunto vazio.
- `>custom-set ( seq -- set )`: constrói um conjunto a partir de uma sequência, ignorando silenciosamente os duplicados.

Depois, fornece métodos `M:` (do `sets`) para `members`, `in?`, `adjoin` e `set-like` em `custom-set`. Com a declaração `INSTANCE:` e esses quatro métodos definidos, `null?`, `union`, `intersect`, `diff`, `subset?`, `set=` e `intersects?` do vocabulário `sets` funcionam todos no teu conjunto através das implementações predefinidas do protocolo: os testes chamam essas palavras diretamente.

`adjoin ( elt set -- )` é uma operação que modifica o conjunto: adiciona `elt` a `set` no local, se ainda não estiver presente.
