# Instruções

Neste exercício vais trabalhar num agendador de marcações para um salão de beleza em Nova Iorque que abriu a 15 de setembro de 2012.

## 1. Interpreta a data da marcação

Implementa o método `AppointmentScheduler.schedule()` para interpretar uma representação textual de uma data de marcação e convertê-la no `LocalDateTime` correspondente:

```java
AppointmentScheduler scheduler = new AppointmentScheduler();
scheduler.schedule("7/25/2019 13:45:00");
// => LocalDateTime.of(2019, 7, 25, 13, 45, 0)
```

## 2. Verifica se uma marcação já passou

Implementa o método `AppointmentScheduler.hasPassed()`, que recebe uma data de marcação e verifica se a marcação ficou algures no passado:

```java
AppointmentScheduler scheduler = new AppointmentScheduler();
scheduler.hasPassed(LocalDateTime.of(1999, 12, 31, 9, 0, 0));
// => true
```

## 3. Verifica se a marcação é à tarde

Implementa o método `AppointmentScheduler.isAfternoonAppointment()`, que recebe uma data de marcação e verifica se a marcação é à tarde (>= 12:00 e < 18:00):

```java
AppointmentScheduler scheduler = new AppointmentScheduler();
scheduler.isAfternoonAppointment(LocalDateTime.of(2019, 03, 29, 15, 0, 0))
// => true
```

## 4. Descreve a hora e a data da marcação

Implementa o método `AppointmentScheduler.getDescription()`, que recebe uma data de marcação e devolve uma descrição dessa data e dessa hora:

```java
AppointmentScheduler scheduler = new AppointmentScheduler();
scheduler.getDescription(LocalDateTime.of(2019, 03, 29, 15, 0, 0))
// => "You have an appointment on Friday, March 29, 2019, at 3:00 PM."
```

## 5. Devolve a data de aniversário

Implementa o método `AppointmentScheduler.getAnniversaryDate()`, que devolve a data de aniversário deste ano, que é 15 de setembro:

```java
AppointmentScheduler scheduler = new AppointmentScheduler();
scheduler.getAnniversaryDate()
// => LocalDate.of(<current year>, 9, 15)
```
