# Ciclos while e until

Um ciclo é uma estrutura de controlo que permite executar código repetidamente com base numa determinada condição.

## Ciclos while

Um ciclo while é uma estrutura de controlo que permite executar código repetidamente com base numa determinada condição.
O código dentro de um ciclo while continua a ser executado enquanto a condição for avaliada como verdadeira.
Os ciclos while são frequentemente usados quando o número de iterações é desconhecido à partida, mas podem ser usados em qualquer situação em que seja necessário um ciclo.

A condição é avaliada antes de o código dentro do ciclo ser executado, o que significa que, se a condição for falsa, o código dentro do ciclo nunca será executado.

```crystal
i = 0
while i < 3
  puts i
  i += 1
end

# Output:
# 0
# 1
# 2
```

Quando queres iterar sobre uma string, podes percorrer o comprimento da string.

```crystal
str = "Hello"
i = 0
while i < str.size
  puts str[i]
  i += 1
end

# Output:
# H
# e
# l
# l
# o
```

## Ciclos until

Os ciclos until funcionam da mesma forma que os ciclos while, exceto que o código dentro do ciclo continua a ser executado até a condição ser avaliada como verdadeira.
É a mesma diferença que existe entre `if` e `unless`.

```crystal
i = 0
until i == 3
  puts i
  i += 1
end
```

### Ciclos infinitos

Um erro comum com os ciclos while é entrar num "ciclo infinito", que nunca termina.
Um ciclo infinito pode ser causado por uma condição que _nunca_ é avaliada como verdadeira ou falsa.
Isto deve-se muitas vezes a um erro do programador; por exemplo, esquecer-se de incrementar a variável do ciclo.
Mas, por vezes, um ciclo infinito é a forma mais clara de implementar a lógica do programa.
Ou é essencial repetir para sempre; por exemplo, um servidor HTTP espera por uma ligação de entrada, trata-a e depois espera pela ligação seguinte.

## Break

A palavra-chave `break` pode ser usada para sair de um ciclo antecipadamente.
Isto pode ser conveniente quando queres sair de um ciclo antecipadamente sob determinadas condições.

```crystal
i = 0
while i <= 3
  puts i
  i += 1
  if i == 2
    break
  end
end

# Output:
# 0
# 1
```

## Next

A palavra-chave `next` pode ser usada para saltar para a iteração seguinte de um ciclo.
Isto pode ser conveniente quando queres saltar iterações específicas de um ciclo.

```crystal
i = 0
while i <= 3
  i += 1
  if i == 2
    next
  end
  puts i
end

# Output:
# 1
# 3
```

## Tipos durante a execução de um ciclo

O tipo da variável pode ser diferente durante a execução de um ciclo.
No exemplo seguinte, o tipo de `a` é `Int32 | String` porque pode ser `Int32` ou `String` na primeira parte do ciclo.
A variável `a` só terá o tipo `Int32 | String` na primeira parte do ciclo, uma vez que, quando o ciclo começa, contém `Int32` e, na segunda iteração, contém uma `String`.
Este sistema de múltiplos tipos será explicado em detalhe mais à frente.
Mas, uma vez que temos a certeza de que a segunda parte do ciclo só conterá `String`, o tipo de `a` é `String` na segunda parte do ciclo.
Em tempo de execução, nunca conterá simultaneamente `Int32` e `String`.

```crystal
i = 0
a = 4
while i < 3
  p typeof(a)
  # => Int32 | String
  a = "4"
  p typeof(a)
  # => String
  i += 1
end
```
