# Dicas

## Geral

- A sintaxe `0b00` pode ser usada para especificar um inteiro em sintaxe binária em vez de sintaxe decimal.

## 1. Codifica o ácido nucleico num valor binário

- O tipo de nucleótido pode ser alvo de correspondência de padrões com uma expressão case.

## 2. Descodifica o valor binário no ácido nucleico

- A sintaxe binária de inteiros pode ser usada em padrões.
- Devolve `Error(Nil)` se o inteiro não for um nucleótido válido.

## 3. Codifica uma lista de ADN

- A função `encode_nucleotide` pode ser usada para codificar um único nucleótido.

## 4. Descodifica um array de bits de ADN

- A sintaxe binária de inteiros pode ser usada dentro de um padrão de array de bits.
- Devolve `Error(Nil)` se o array de bits restante não for suficientemente longo para conter um nucleótido.
