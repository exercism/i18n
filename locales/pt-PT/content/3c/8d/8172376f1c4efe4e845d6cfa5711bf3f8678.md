# Introduction

Um método é uma função com um argumento especial, o *recetor*.
O recetor aparece na sua própria lista de argumentos, entre a palavra-chave `func` e o nome do método.

```go
func (receiver type) MethodName(parameters) (returnTypes) {
}
```

Só podes definir um método com um recetor cujo tipo esteja definido no mesmo pacote que o método.

```go
package person 

type Person struct {
	Name string
}

func (p Person) Greetings() string {
	return fmt.Sprintf("Welcome %s!", p.Name)
}
```

O método do tipo struct pode ser chamado com a notação de ponto.

```go
p := Person{Name: "Bronson"}
fmt.Println(p.Greetings())
// Output: Welcome Bronson!
```

Repara como chamámos o método `Greetings()` à instância `p` de `Person`.
É exatamente como chamas métodos numa linguagem de programação orientada a objetos.

Lembra-te: um método é apenas uma função com um argumento recetor.
Os métodos ajudam a evitar conflitos de nomes, pois, como um método está associado a um tipo de recetor específico, podes ter o mesmo nome de método em tipos diferentes.

```go
import "math"

type rect struct {
	width, height int
}
func (r rect) area() int {
	return r.width * r.height
}

type circle struct {
	radius int
}
func (c circle) area() float64 {
	return math.Pow(float64(c.radius), 2) * math.Pi
}
```

Há dois tipos de recetores: os recetores de valor e os recetores de ponteiro.

Todos os métodos que vimos até agora têm um recetor de valor, o que significa que recebem uma cópia do valor passado ao método. Por outras palavras, qualquer modificação feita ao recetor dentro do método não é visível para quem o chama.

Podes declarar métodos com recetores de ponteiro para modificar o valor para o qual o recetor aponta.
Para isso, coloca um `*` antes do nome do tipo.
Por exemplo, com o tipo `rect`, um recetor de ponteiro seria declarado como `*rect`.
Essas modificações também são visíveis para quem chama o método.

```go
type rect struct {
	width, height int
}
func (r *rect) squareIt() {
	r.height = r.width
}

r := rect{width: 10, height: 20}
fmt.Printf("Width: %d, Height: %d\n", r.width, r.height)
// Output: Width: 10, Height: 20

r.squareIt()
fmt.Printf("Width: %d, Height: %d\n", r.width, r.height)
// Output: Width: 10, Height: 10
```
