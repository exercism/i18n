# Dicas

## Geral

- Lê sobre processos no [guia oficial Getting Started][getting-started-processes].
- Lê [este artigo de blog][mullen-processes] sobre processos em Elixir.

## 1. Inicia a máquina

- A máquina deve correr num processo novo. Existe [uma função incorporada que inicia um novo processo][kernel-spawn-1].
- Usa uma função anónima de aridade 0 quando iniciares um novo processo. Esta função ainda não precisa de fazer nada.

## 2. Reporta o estado da máquina

- Vais precisar de uma nova função com nome. Podes dar-lhe, por exemplo, o nome `loop`.
- Esta nova função deve aceitar um argumento, o estado.
- A função anónima de aridade 0 do passo anterior pode chamar a nova função com nome, passando o estado inicial.
- A nova função com nome precisa de responder a mensagens.
- Existe [uma função incorporada que espera que uma mensagem chegue à caixa de correio do processo][kernel-receive].
- Existe [uma função incorporada que envia uma mensagem a outro processo][kernel-send].
- Usa recursão para esperar por mais do que uma mensagem.

## 3. Distribui números

- Este passo é conceptualmente igual ao passo anterior. A única diferença é a necessidade de atualizar o estado da máquina.

## 4. Para a máquina

- Este passo não exige enviar mensagens como resposta.
- Um processo termina se não tiver mais código para executar.
- Quando precisares de criar um bloco de código "vazio" em Elixir, podes usar `nil` como única expressão desse bloco de código.
- Este é um caso base da função recursiva.

## 5. Ignora mensagens inesperadas

- Este passo não exige enviar mensagens como resposta.
- Podes usar `_` para corresponder a todas as mensagens que não corresponderam aos padrões anteriores.
