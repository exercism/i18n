# Introdução

A expressão `let` serve para criar um âmbito local e é útil em algumas situações:

- Para simplificar expressões
- Para dar nome aos resultados de expressões intermédias
- Para dividir uma expressão em partes mais pequenas, quando começa a ficar grande

Podes fazer quase tudo dentro de uma expressão `let`, incluindo desestruturação (vais encontrar mais detalhes sobre isto em exercícios posteriores), mas não é possível definir um novo Custom Type nem um Type Alias.

```elm
let
  cube x = x * x * x
in
  cube a + cube b + cube c
```

```elm
beginWithPattern : Size -> Padding -> Pattern -> GameOfLife
beginWithPattern minimumSize padding pattern =
    let
        size = calculateSize minimumSize padding pattern

        center = Size.center size

        centeredPattern = Pattern.centerAt center pattern

        dimensions = { width = size, height = size }

        deadCells = Matrix.create dimensions Dead
    in
    GameOfLife (bringPatternToLife deadCells centeredPattern)
```
