# Acerca de

Um String buffer é uma forma eficiente de construir uma string grande, acrescentando-lhe pequenos elementos. Ao contrário da String, uma instância de StringBuf não é imutável, no sentido em que pode ser passada como argumento a funções que a modificam, acrescentando-lhe mais valores.

```haxe
var a = new StringBuf();
a.add("Hello");
trace(a.toString()); // Hello
a.add("Haxe!");
trace(a.toString()); // HelloHaxe
```
