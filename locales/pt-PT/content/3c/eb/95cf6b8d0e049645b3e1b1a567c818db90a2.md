# Dicas

## 1. Calcula o valor de qualquer carta

- Um [`switch`][ref-switch] à moda antiga funciona bem aqui, porque só precisa de lidar com uma única carta em cada chamada.
- Usar [`case_match`][ref-case_match] é outra opção, mas, neste caso, não se podem omitir as aspas à volta das strings.

## 2. Implementa a lógica de decisão da primeira jogada

- O [`case_when`][ref-case_when] é útil nesta tarefa.
- A tarefa pode ser resolvida em R base com uma série de condicionais, mas de forma menos elegante.

[ref-case_match]: https://dplyr.tidyverse.org/reference/case_match.html
[ref-case_when]: https://dplyr.tidyverse.org/reference/case_when.html
