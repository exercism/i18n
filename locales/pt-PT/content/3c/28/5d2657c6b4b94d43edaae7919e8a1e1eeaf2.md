# Introdução

## Recursividade

Uma função recursiva é uma função que se chama a si própria.

Uma função recursiva tem de ter pelo menos um _caso base_ e pelo menos um _caso recursivo_.

Um _caso base_ devolve um valor sem voltar a chamar a função. Um _caso recursivo_ chama a função outra vez, modificando o valor de entrada para que em algum momento corresponda ao caso base.

Muitas vezes, cada caso é escrito na sua própria cláusula de função.

```elixir
# base case
def count([]), do: 0

# recursive case
def count([_head | tail]), do: 1 + count(tail)
```
