# Instalação

## Instalação

Encontras instruções de instalação detalhadas em [elixir-lang.org/install](https://elixir-lang.org/install.html).

Para tirares o máximo da tua experiência de aprendizagem no Exercism, recomendamos que instales localmente as mesmas versões da linguagem que são usadas para correr os testes às tuas submissões de exercícios.
Essas versões são **Erlang/OTP 26 e Elixir 1.16**.

Para verificar que versões tens instaladas, executa `elixir --version` na tua linha de comandos.
