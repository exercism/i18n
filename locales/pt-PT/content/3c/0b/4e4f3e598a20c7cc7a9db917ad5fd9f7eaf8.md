# Introdução

Os objetos podem guardar o seu próprio estado através da definição de _variáveis de instância_, que são criadas ao colocar `@` antes do nome de uma variável.

```ruby
@name = 2
```

Normalmente, os objetos definem o seu estado inicial num método `initialize`, que é chamado automaticamente quando se chama `new` numa classe.

```ruby
class Airplane
  def initialize
    @wings = 2
  end
end
```

O método `initialize` também pode receber argumentos, para que cada instância possa começar com um estado personalizado:

```ruby
class Suitcase
  def initialize(locked)
    @locked = locked
  end
end
```

Considera que as variáveis de _instância_ são privadas e não devem ser lidas nem alteradas a partir do exterior. Deves usar métodos de _instância_ para obter e definir variáveis de instância:

```ruby
class Suitcase
  #...

  def locked? # Query methods should be named with a trailing `?`
    @locked
  end

  def unlock! # Methods which mutate state should have trailing `!`
    @locked = false
  end
end
```
