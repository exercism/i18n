# Introdução

O Hashmap é uma coleção usada para armazenar pares chave-valor. Permite usar tipos arbitrários como chaves e valores. O Hashmap tem funções de inserção e consulta rápidas e é muito útil, por exemplo, para contar frequências, guardar relações, etc. O Hashmap também tem a poderosa API `entry`, que o torna ergonómico de usar.
