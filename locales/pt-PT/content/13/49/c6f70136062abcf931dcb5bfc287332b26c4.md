# Booleanos

O Haskell tem um tipo conhecido como [`Bool`][bools].
É uma enumeração de `True` e `False`.

## Operadores lógicos

O Haskell tem três operadores lógicos (`not`, `||`, `&&`) que combinam booleanos e criam expressões que produzem valores diferentes.

### E(`&&`)

O [operador _e_][and] em Haskell é representado por `&&` e devolve `True` se ambos os valores forem `True`; caso contrário, devolve `False`.
Quando usas o operador _e_, coloca-se um booleano do lado direito do `&&` e outro do lado esquerdo.

```haskell
True && True
-- -> True

True && False
-- -> False
```

### Ou(`||`)

O [operador _ou_][or] em Haskell é representado por `||` e devolve `True` se **pelo menos um** dos valores dados for `True`. 
Se ambos os valores forem `False`, devolve `False`.
Quando usas o operador _ou_, deves colocar um booleano do lado direito do `||` e outro do lado esquerdo.

```haskell
True || True
-- -> True

True || False
-- -> True

False || False
-- -> False
```

### Não(`not`)

O operador _não_ em Haskell é representado por `not` e devolve `True` se o booleano dado for `False` e devolve `False` se receber `True`.
Quando usas o operador _não_, deves colocar o booleano depois do operador (`not`).

```haskell
not True
-- -> False

not False
-- -> True
```

## Usar parênteses(`()`)

Quando trabalhas com booleanos, podes usar parênteses para decidir que booleanos são avaliados primeiro.
O resultado pode ser diferente consoante a forma como os parênteses são usados.
Em Haskell, o que está dentro dos parênteses é avaliado primeiro.

```haskell
True && False && False || True
-- -> True

True && False && (False || True)
-- -> False
```

Como o que está dentro dos parênteses é avaliado primeiro, no exemplo seguinte o operador _não_ aplica-se à expressão dentro dos parênteses.

```haskell
not True && False
-- -> False

not (True && False)
-- -> True
```

~~~~exercism/note
Só deves usar parênteses quando estes afetam o resultado; caso contrário, devem ser omitidos.
~~~~
