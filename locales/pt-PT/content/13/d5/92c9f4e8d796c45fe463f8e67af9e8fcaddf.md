# Introdução

## Tabelas de hash

Em Common Lisp, as tabelas de hash são estruturas de dados para armazenar dados associativos.
Fazem o mapeamento de chaves (que podem ser qualquer objeto) para valores (que podem ser qualquer objeto).
Noutras linguagens, este conceito pode ser designado por mapas, dicionários ou hashes.

### Criar tabelas de hash

As tabelas de hash podem ser criadas com a função `make-hash-table`.

`(make-hash-table) ; => #<HASH-TABLE :TEST EQL :COUNT 0 {10024AD2B3}>`

(Repara que a forma como uma tabela de hash é impressa depende da implementação, por isso pode aparecer de forma diferente no teu REPL.)

### Obter valores a partir das chaves

Para obter um valor a partir de uma chave da tabela de hash, usas a função `gethash`:

```lisp
*h* ; => #<HASH-TABLE :TEST EQL :COUNT 3 {10024AD2B3}>`
(gethash :foo *h*) ; => :bar
                   ;    T
```

A `gethash` devolve [vários valores][concept-multiple-values], que serão explicados noutro conceito.

### Inserir valores

Para inserir um valor numa tabela de hash, usas `setf` com `gethash` assim:

`(setf (gethash :foo *hash-table*) :bar) : => :bar`

Isto modifica o valor da chave `:foo` na tabela de hash `*hash-table*` para `:bar`.
A expressão devolve o valor.

A utilização de `setf` será explicada noutro conceito.
