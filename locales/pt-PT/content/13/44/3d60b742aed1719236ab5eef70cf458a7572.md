# Instruções

Continuando o tema do jogo dos magos e guerreiros, está na altura de acrescentar um método de lançamento de dados para todas as ocasiões. Este será o tradicional dado de 18 faces, com os números de 1 a 18. Os jogadores também geram uma força do feitiço.

## 1. Permite que um jogador de _magos e guerreiros_ lance um dado.

Implementa um método `RollDie()` na classe `Player`.

```csharp
var player = new Player();
player.RollDie();
// => >= 1 <= 18
```

## 2. Os jogadores precisam da sua força. Proporciona uma forma de gerar a força do feitiço

Implementa um método `GenerateSpellStrength()` na classe do jogador. A força do feitiço está entre 0,0 e até, mas sem incluir, 100,0.

Repara que a força do feitiço tem de ser um número real (não um número inteiro) para reduzir a possibilidade de empate quando se comparam as forças de dois adversários.

```csharp
var player = new Player();
player.GenerateSpellStrength();
// => >= 0.0 < 100.0
```
