# Ajuda

## Executar os testes

O percurso de Factor usa o **Factor 0.101**. Depois de
[o instalar](https://exercism.org/docs/tracks/factor/installation),
corre o seguinte a partir do diretório deste exercício:

```
factor -roots=. -run=exercism-tools <exercise>
```

Por exemplo, para `hello-world`:

```
factor -roots=. -run=exercism-tools hello-world
```

Cada exercício inclui um pequeno vocabulário `exercism-tools`
que conduz a execução dos testes. O executor termina com estado
0 quando todos os testes passam, e com um estado diferente de
zero, juntamente com informação de diagnóstico, se algum teste
falhar.

### Testes ignorados

Por predefinição, só é executado o primeiro teste. O mecanismo
é a linha `STOP-HERE` no ficheiro de testes: no momento da
análise, diz ao analisador lexical do Factor para ignorar tudo
o que está abaixo dela, pelo que o executor só vê os testes
que estão acima. Assim que o primeiro teste passar, podes
ativar mais testes de duas formas:

- **Apaga a linha `STOP-HERE`** para ativar de uma vez todos os
  testes restantes.
- **Move a linha `STOP-HERE` mais para baixo** para ativar os
  testes um a um, ou tarefa a tarefa. Os exercícios de conceitos
  agrupam os testes sob marcadores `TASK:`. Mover o `STOP-HERE`
  para imediatamente antes do próximo `TASK:` é um passo natural.

Quando todos os testes passarem, resolveste o exercício.

## Submeter a tua solução

A partir do diretório do exercício:

```
exercism submit <exercise>/<exercise>.factor
```

Por exemplo:

```
exercism submit hello-world/hello-world.factor
```

Se o `.meta/config.json` do exercício listar mais do que um
ficheiro de solução (alguns exercícios de conceitos dividem a
solução por um subvocabulário auxiliar), passa todos os
ficheiros que editaste ao `exercism submit`.

## Submeter soluções incompletas

Podes submeter uma solução mesmo com testes a falhar. Isso
permite-te ver como outras pessoas abordaram o exercício e pedir
feedback de um mentor sobre o que já tens até agora.

## Obter mais ajuda

- A [categoria Factor no fórum do Exercism](https://forum.exercism.org/c/programming/factor/)
  é o melhor sítio para perguntas e feedback específicos do percurso.
- O [Discord do Exercism](https://exercism.org/r/discord) tem
  canais tanto para ajuda geral como para percursos individuais.
- A documentação oficial do Factor é pesquisável e exaustiva. Dois bons pontos de partida:
  - [O manual do Factor](https://docs.factorcode.org/content/article-handbook.html),
    em estilo de referência e organizado por vocabulário.
  - [O livro de receitas do Factor](https://docs.factorcode.org/content/article-cookbook.html),
    com exemplos curtos e idiomáticos organizados por tema.
- O [tutorial de Factor](https://andreaferretti.github.io/factor-tutorial/)
  de Andrea Ferretti é uma introdução rápida e simpática à linguagem
  e ao ambiente de desenvolvimento.
