# Snippet Extractor

O [Snippet Extractor][snippet-extractor] recebe a submissão de um estudante e extrai dela as primeiras dez linhas de código "interessantes".
O snippet extraído aparece em várias páginas do site.

Por predefinição, são mostradas as primeiras dez linhas, ignorando as linhas vazias iniciais.
Estas primeiras dez linhas _podem_ incluir coisas como comentários, que normalmente não são ideais para apresentar num snippet.

## Personalizar a extração de snippets

Recomendamos que cada percurso [personalize a extração de snippets][snippet-extractor-customize], pelo menos para remover comentários do código-fonte.
Para personalizar a extração de snippets, precisas de:

1. Adicionar um ficheiro `lib/languages/<track_slug>.txt` que configura a extração de snippets.
   Este ficheiro pode usar o [modo básico][basic-mode] ou o [modo expandido][extended-mode].
   A maioria dos percursos usa o modo expandido, porque dá mais flexibilidade.
2. Adicionar um ou mais casos de teste a um diretório `tests/<track_slug>/<test_slug>`.
   Cada diretório de teste vai precisar de dois ficheiros:

   1. `tests/<track_slug>/<test_slug>/code.<track_extension>`: o código no qual executar o extrator de snippets
   2. `tests/<track_slug>/<test_slug>/expected_snippet.<track_extension>`: o snippet esperado

Vê [este exemplo de pull request][example-pr] que personaliza a extração de snippets para a linguagem Arturo.
