# Dicas

## Geral

- Tenta dividir um problema num caso base e num caso recursivo
  Por exemplo, imagina que queres contar quantos biscoitos há no pote de biscoitos com uma abordagem recursiva
  Um caso base é um pote vazio: tem zero biscoitos.
  Se o pote não estiver vazio, o número de biscoitos no pote é igual a um biscoito mais o número de biscoitos no pote depois de retirar um biscoito.

## 1. Implementa uma função que some os números de um array

- A recursão consiste em iterar sobre os elementos do array, adicionando cada um a um acumulador.
- O caso base é um array vazio, cuja soma é igual a zero.
- O caso recursivo adiciona o primeiro elemento à soma do resto do array.
- Recorda a indexação e o fatiamento de arrays a partir do [conceito Arrays][arrays-concept] para separar o primeiro elemento do array dos restantes elementos.

## 2. Inverte um array

- A recursão consiste em iterar sobre os elementos do array, adicionando cada um a outro array por ordem inversa.
- O caso base é um array vazio.
- Lembra-te de que o [operador `+`][manual-addition] concatena quando aplicado a arrays.

## 3. Mapeia um array

- A recursão consiste em iterar sobre os elementos do array, adicionando ao array acumulador o resultado de aplicar o filter ao elemento.
- Para aplicar o parâmetro filter a um elemento, usa a sintaxe de pipe habitual: `.element | filter`.
- O caso base é um array vazio.

[arrays-concept]: https://exercism.org/tracks/jq/concepts/arrays
