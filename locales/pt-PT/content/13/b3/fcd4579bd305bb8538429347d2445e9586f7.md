# Sobre

Uma string em Factor é uma sequência de carateres e partilha o [protocolo `sequences`][sequence-protocol] completo (`length`, `nth`, `head`, `tail`, `map`, `filter`, etc.) a par dos seus vocabulários dedicados.

```factor
"hello"  length .       ! => 5
"hello"  reverse .      ! => "olleh"
"abcdef" 3 head .       ! => "abc"
```

As palavras específicas de strings vivem sobretudo em [`splitting`][splitting], [`ascii`][ascii] e [`unicode`][unicode]:

| palavra | vocabulário | o que faz |
|---------|-------------|-----------|
| `split1` | [`splitting`][splitting] | corta na primeira ocorrência |
| `split` | [`splitting`][splitting] | corta em qualquer caráter de um conjunto |
| `harvest` | [`sequences`][sequences] | descarta os pedaços vazios de um resultado de split |
| `replace` | [`splitting`][splitting] | substitui uma substring |
| `surround` | [`sequences`][sequences] | envolve com um prefixo e um sufixo |
| `glue` | [`sequences`][sequences] | junta duas strings com um separador |
| `join` | [`sequences`][sequences] | junta um array de strings com um separador |
| `>lower` | [`ascii`][ascii] | converte para minúsculas (ASCII) |
| `>upper` | [`ascii`][ascii] | converte para maiúsculas (ASCII) |
| `[ blank? ] trim` | [`sequences`][sequences] | remove espaços em branco no início e no fim |
| `first`, `second`, `third`, `fourth` | [`sequences`][sequences] | o elemento inicial |
| `first2`, `first3` | [`sequences`][sequences] | desempacota dois ou três elementos iniciais |
| `>string` | [`strings`][strings] | transforma uma sequência de carateres numa string |
| `1string` | [`strings`][strings] | envolve um único caráter numa string de um caráter |
| `CHAR: x` | parser | um literal de um único caráter (por exemplo, `CHAR: A` → `65`) |

Para conversões de ida e volta entre números e strings, [`math.parser`][math.parser] fornece `number>string` e `string>number`. Para saída com strings de formatação, [`formatting`][formatting] fornece `sprintf` e afins.

Para conversão de maiúsculas e minúsculas ou classificação de carateres com suporte a Unicode, usa as palavras correspondentes em [`unicode`][unicode].
