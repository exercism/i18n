# Dicas

## Geral

- Este [artigo][time-overview] é uma visão geral de datas, horas e fusos horários no .NET.
- A estrutura `DateTime` está documentada [aqui][date-time].

## 1. Fornece equivalentes em hora local das marcações UTC (Tempo Universal Coordenado) para os administradores

Procura um membro adequado de `DateTime` que faça a conversão de UTC para hora local.

## 2. Agenda marcações em Nova Iorque, Londres e Paris

Usa a classe [`TimeZoneInfo`][time-zone-info] e seleciona os ids de fuso horário adequados a partir das instruções da tarefa. Lembra-te de que o Windows e o OSX/Linux têm ids diferentes.

O método [`RuntimeInformation.IsOSPlatform()`] é essencial para teres caminhos de código que visam sistemas operativos diferentes.

## 3. Fornece alertas aos clientes a intervalos antes da marcação

Uma abordagem é usar [`TimeSpan`][time-span] para fazer cálculos com horas.

## 4. Se o horário de verão mudou recentemente, enviamos uma mensagem aos clientes a lembrá-los disso.

`TimeZoneInfo` tem os métodos adequados para isto.

## 5. Usa o formato de data e hora local para introduzir marcações

Dá uma vista de olhos a `DateTime.Parse()` e a [`CultureInfo`][culture-info].
