# Instruções

O teu clube de netball precisa de ter a classificação calculada após cada jornada.

As quatro tarefas ficam na classe `NETBALL_LADDER`.

## 1. Pontos na classificação

Uma vitória vale 4 pontos e um empate 2. As derrotas não valem nada.

```sather
NETBALL_LADDER::ladder_points(3, 1)
-- => 14
```

## 2. Diferença de golos

Golos marcados menos golos sofridos. Pode ser negativa.

```sather
NETBALL_LADDER::goal_difference(180, 205)
-- => -25
```

## 3. Quartos completos jogados

Um quarto tem 15 minutos. Dado um número de minutos, quantos quartos completos dá isso?

```sather
NETBALL_LADDER::whole_quarters(38)
-- => 2
```

## 4. Minutos decorridos no quarto

Dado o mesmo número de minutos, em que ponto do quarto atual estamos?

```sather
NETBALL_LADDER::minutes_into_quarter(38)
-- => 8
```
