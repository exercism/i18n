# Apêndice às instruções

## Registos

| Registo | Utilização     | Tipo    | Descrição                   |
| -------- | --------- | ------- | ----------------------------- |
| `$a0`    | parâmetro de entrada     | endereço | array de palavras de fatores         |
| `$a1`    | parâmetro de entrada     | inteiro | número de fatores             |
| `$a2`    | parâmetro de entrada     | inteiro | limite                         |
| `$v0`    | valor devolvido     | inteiro | soma dos múltiplos dentro do limite |
| `$t0-9`  | temporário | qualquer     | usado para armazenamento temporário    |
