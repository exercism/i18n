# Instruções

Converte uma frase no seu acrónimo.

Os apaixonados por tecnologia adoram as suas TLA (acrónimos de três letras)!

Ajuda a gerar algum jargão escrevendo um programa que converte um nome longo como Portable Network Graphics no seu acrónimo (PNG).

A pontuação é tratada da seguinte forma: os hífenes são separadores de palavras (tal como o espaço em branco); toda a outra pontuação pode ser removida da entrada.

Por exemplo:

| Entrada                   | Saída |
| ------------------------- | ------ |
| As Soon As Possible       | ASAP   |
| Liquid-crystal display    | LCD    |
| Thank George It's Friday! | TGIF   |
