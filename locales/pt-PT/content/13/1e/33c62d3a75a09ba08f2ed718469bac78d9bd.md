# Instalação

O percurso da linguagem C exige que tenhas o seguinte software instalado no teu sistema:

* Um compilador de C moderno
* A ferramenta de construção Make

A IDE Xcode da Apple combina o compilador e o sistema de construção nativo numa única IDE (ambiente de desenvolvimento integrado).
Os ambientes Linux disponibilizam normalmente o compilador e o sistema de construção nativo como ferramentas de linha de comandos separadas.

## Linux

Os utilizadores de Linux precisam do gcc ou do clang como compilador, e o `make` será necessário para a construção nativa.
O Make vem pré-instalado na maioria dos sistemas unix, mas está provavelmente disponível através do teu gestor de pacotes.
Nas distribuições baseadas em Debian e Ubuntu, tudo o que precisas pode ser instalado com `sudo apt-get install build-essential`, caso ainda não esteja presente.

## MacOS

Os utilizadores de MacOS podem instalar o gcc ou o clang com o [Homebrew][] através de `brew install gcc` ou `brew install llvm`.

## Windows

Aos utilizadores do Windows 10 recomenda-se que usem o [Windows Subsystem for Linux][] e que sigam as instruções para Linux acima.

Se estiveres a usar uma versão anterior do Windows, ou se o WSL Bash não estiver disponível para ti, podes usar o [MSYS][] ou o [mingw-w64][].

[Homebrew]: https://brew.sh
[Windows Subsystem for Linux]: https://docs.microsoft.com/en-gb/windows/wsl/about
[MSYS]: https://www.msys2.org
[mingw-w64]: http://mingw-w64.org
