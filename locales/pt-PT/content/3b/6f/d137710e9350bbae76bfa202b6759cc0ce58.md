# Criar ficheiros com o configlet

Quando adicionas uma nova abordagem, um novo artigo ou um novo exercício, tens de criar ficheiros com nomes muito específicos.
Também é preciso adicionar ou atualizar ficheiros de configuração.
Com o comando `create`, o [configlet](/docs/building/configlet) pode fazer tudo isto por ti.

## Utilização

O comando `create` pode ser usado para criar os ficheiros necessários para adicionar uma nova abordagem, um novo artigo ou um novo exercício, bem como para modificar quaisquer ficheiros de configuração.

```shell
configlet [global-options] create [command-options]

Options for create:
      --approach <slug>           The slug of the approach
      --article <slug>            The slug of the article
      --practice-exercise <slug>  The slug of the practice exercise
      --concept-exercise <slug>   The slug of the concept exercise
  -e, --exercise <slug>           Only operate on this exercise
  -o, --offline                   Do not update the cached 'problem-specifications' data
```

## Criar um exercício de prática

A [documentação sobre como adicionar um exercício de prática](/docs/building/tracks/practice-exercises/add) tem instruções detalhadas.

## Criar um exercício de conceito

Para criar um exercício de conceito, é preciso especificar o seu slug:

```shell
configlet create --concept-exercise bird-watcher
```

Isto cria os ficheiros necessários do exercício de conceito, tal como especificado na [documentação dos exercícios de conceito](/docs/building/tracks/concept-exercises).

Claro que isto é apenas o primeiro passo para criar um exercício.
Depois tens de:

- Adicionar testes ao ficheiro de testes
- Adicionar uma implementação exemplar
- Definir o conteúdo do ficheiro stub
- Escrever a introdução em `.docs/introduction.md`
- Escrever as instruções em `.docs/instructions.md`
- No ficheiro `.meta/config.json` do exercício:
  - Adicionar o nome de utilizador do GitHub dos autores do exercício à chave `authors`
- No ficheiro `config.json` do percurso:
  - Verificar/atualizar a dificuldade do exercício
  - Adicionar conceitos à chave `concepts`
  - Adicionar conceitos à chave `prerequisites`

## Criar uma abordagem

Para criar os ficheiros de uma abordagem, é preciso especificar o slug da abordagem e do exercício a que pertence:

```shell
configlet create --approach recursion --exercise collatz-conjecture
```

Isto cria os ficheiros necessários da abordagem, tal como especificado na [documentação das abordagens](/docs/building/tracks/approaches).

## Criar um artigo

Para criar os ficheiros de um artigo, é preciso especificar o slug do artigo e do exercício a que pertence:

```shell
configlet create --article performance --exercise collatz-conjecture
```

Isto cria os ficheiros necessários do artigo, tal como especificado na [documentação dos artigos](/docs/building/tracks/articles).
