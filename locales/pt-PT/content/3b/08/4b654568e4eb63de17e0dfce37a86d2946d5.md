# Dicas

## Geral

Os valores devolvidos pelas funções são de um tipo específico, por isso presta atenção.

## 1. Define um vetor com nomes

- A informação necessária para os nomes e os valores está nas instruções.
- A forma de construir um vetor com nomes é abordada em detalhe na introdução.

## 2. Devolve o valor associado a uma banda

- Podes usar o teu vetor com nomes `resistor_bands` para fazer isto facilmente.
- Tens de devolver apenas um valor numérico.

## 3. Devolve o valor associado a duas bandas

- A tua função `band_value` pode ser útil aqui.
- As dicas sobre a indexação de vetores com nomes estão na introdução.
- Há várias formas de construir o número, sendo as mais comuns a manipulação de strings ou a via numérica.
- O número devolvido tem de ser apenas um valor numérico.

## 4. Devolve os ohms associados às três bandas

- Tanto `band_value` como `two_band_value` são úteis aqui.
- Os dois primeiros valores do vetor correspondem ao valor de duas bandas, enquanto o terceiro é o multiplicador.
- Mais uma vez, podes obter o número através da manipulação de strings ou de meios numéricos.
- O número devolvido tem de ser apenas um valor numérico.
