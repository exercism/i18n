## Como este exercício é implementado em Python: recursão

Este exercício foi concebido para ser resolvido com [concept:python/recursion](), em vez de ciclos.
Uma função recursiva é uma função que se chama a si própria, o que é útil para resolver problemas que se definem em termos de si mesmos.
Para evitar recursão infinita (mais concretamente, para evitar o transbordamento da pilha), usa-se aquilo a que se chama um "caso base".
Quando se atinge o caso base, é devolvido um valor não recursivo. Isso permite que a chamada anterior se resolva e devolva o seu valor, e assim sucessivamente, propagando-se pela pilha até a primeira chamada devolver a resposta.
Podíamos escrever uma função recursiva para calcular o fatorial de 5, ou seja, 5! (isto é, 5 * 4 * 3 * 2 * 1), assim:

````python
def factorial(number):
  if number <= 1:  # base case
    return 1

  return number * factorial(number - 1) # recursive case

print(factorial(5)) # returns 120
````

Por fim, convém notar que o Python limita o número de vezes que se podem fazer chamadas recursivas (1000 por predefinição) e não otimiza a [recursão de cauda][tail-recursion].

## Mensagens de exceção

Por vezes é necessário [lançar uma exceção][raising].
Quando o fazes, deves incluir sempre uma **mensagem de erro significativa** que indique qual é a origem do erro.
Isso torna o teu código mais legível e ajuda bastante na depuração.
Nos casos em que sabes que a origem do erro é de um determinado tipo, podes optar por lançar um dos [tipos de erro incorporados][built-in-errors], mas deves continuar a incluir uma mensagem significativa.

Este exercício em particular exige que uses a [instrução raise][raise-statement] para "lançar" vários `ValueErrors` se à função `rows()` for passado um número negativo.
Os testes só passam se fizeres `raise` da `exception` e incluíres uma mensagem com ela.

Para lançar um `ValueError` com uma mensagem, escreve a mensagem como argumento do tipo de `exception`:

```python
# if the rows function is passed a negative number.
raise ValueError("number of rows is negative")
```
