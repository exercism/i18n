# Dicas

## Geral

- Há três [operadores Boolean][boolean-operators] para trabalhar com valores Boolean.
- É possível combinar vários operadores numa única expressão.

## 1. Verifica se é possível fazer um ataque rápido

- O operador lógico NOT (`!`) pode ser colocado antes de uma expressão para negar o seu valor.

## 2. Verifica se é possível espiar o grupo

- Normalmente, os operadores Boolean são usados para avaliar se duas ou mais expressões são verdadeiras ou não.

## 3. Verifica se é possível dar sinal ao prisioneiro

- Os operadores Boolean são executados pela ordem da sua precedência (da mais alta para a mais baixa): `!`, `&&`, `||`.
- Em geral, recomenda-se o uso de parênteses para tornar a tua intenção mais clara.
- Para mais detalhes, consulta a secção sobre a precedência de operadores na [documentação oficial do Julia][operator-precedence].

## 4. Verifica se a opção 'Libertar Prisioneiro' deve ser mostrada

- Os operadores Boolean são executados pela ordem da sua precedência (da mais alta para a mais baixa): `!`, `&&`, `||`.
- Em geral, recomenda-se o uso de parênteses para tornar a tua intenção mais clara.
