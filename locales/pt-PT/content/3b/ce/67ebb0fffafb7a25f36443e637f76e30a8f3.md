# Dicas

## Geral

- Considera o código fornecido nos namespaces das famílias como algo dado e não o modifiques.
- Não copies os valores para o teu código, chama os métodos.

## 1. Toma o teu lugar à frente das famílias e dispõe os teus papéis

- O namespace tem de se chamar `EstateExecutor` para a tua solução passar nos testes.

## 2. Descobre o número secreto da conta

- Tens de chamar cada `bank_number_part` com o `secret_modifier` da lista de parâmetros.

## 3. Último passo: introduz o código secreto

- Podes chamar métodos de namespaces aninhados desta forma: `OuterNamespace::InnerNamespace::my_method`.

- Não te esqueças de adicionar os fragmentos azul e vermelho separadamente antes de multiplicares as duas partes.
