# Mutabilidade

O Cairo, com a sua conceção orientada a blockchain, implementa por omissão um modelo de memória imutável.
Isto significa que, depois de um valor ser escrito na memória, não pode ser sobrescrito, apenas lido.
No entanto, o Cairo fornece um mecanismo para criar variáveis mutáveis através da palavra-chave `mut`.
Quando uma variável é declarada como mutável e o valor é alterado, o novo valor é escrito numa nova célula de memória, e a variável é atualizada para apontar para a nova célula.
Este mecanismo permite flexibilidade sem perder os benefícios da imutabilidade.

No exemplo abaixo, a variável `x` é declarada como imutável.
Se o valor de `x` for alterado, o compilador dá um erro.

```rust
let x = 5;
x = 2; // Error: cannot assign twice to immutable variable
```

Podemos declarar `x` como uma variável mutável com a palavra-chave `mut`.
Isto permite que o valor de `x` seja alterado depois de a variável ser declarada.

```rust
let mut x = 5;
x = 10;
```

No fim de contas, decidir se usas mutabilidade ou não depende de ti e do que consideres mais claro nessa situação em particular.

## Constantes

Tal como as variáveis imutáveis, as constantes são valores associados a um nome que não podem ser alterados, mas há algumas diferenças entre constantes e variáveis:

- As constantes são declaradas com a palavra-chave `const`
- Não podes usar `mut` com constantes
- O tipo do valor tem de ser sempre indicado explicitamente
- As constantes só podem ser declaradas no âmbito global
- As constantes só podem ser definidas com expressões constantes, não com o resultado de um valor calculado em tempo de execução

```rust
struct AnyStruct {
    a: u256,
    b: u32
}

enum AnyEnum {
    A: felt252,
    B: (usize, u256)
}

const ONE_HOUR_IN_SECONDS: u32 = 3600;
const STRUCT_INSTANCE: AnyStruct = AnyStruct { a: 0, b: 1 };
const ENUM_INSTANCE: AnyEnum = AnyEnum::A('any enum');
const BOOL_FIXED_SIZE_ARRAY: [bool; 2] = [true, false];
```

É possível usar a macro `consteval_int!` para criar uma variável `const` que é o resultado de um cálculo.

```rust
const ONE_HOUR_IN_SECONDS: u32 = consteval_int!(60 * 60);
```

## Sombreamento

É possível, e muitas vezes idiomático, reutilizar o nome de uma variável à medida que um determinado valor é transformado, voltando a declará-la com várias invocações de `let`.
Isto é conhecido como _sombreamento_.
Com efeito, a segunda variável sobrepõe-se à primeira e passa a ser ela a receber todos os usos do nome da variável, até ser ela própria sombreada ou até o âmbito terminar.

```rust
fn main() {
    let s: ByteArray = "my string";
    let s: ByteArray = s + " and a shadow";
    {
        let s: ByteArray = "a nested shadow";
        println!(s); // emits "a nested shadow"
    }
    println!(s); // emits "my string and a shadow"
}
```

Com o sombreamento, podemos até alterar o tipo da variável, reutilizando o mesmo nome.

```rust
fn main() {
    let x: u64 = 2;
    println!("x is u64, value: {}", x);               // prints "x is u64, value: 2"
    let x: ByteArray = format!("fizz");               // converts x to a ByteArray, type annotation is required
    println!("x is now ByteArray, value: \"{}\"", x); // prints 'x is now ByteArray, value: "fizz"'
}
```
