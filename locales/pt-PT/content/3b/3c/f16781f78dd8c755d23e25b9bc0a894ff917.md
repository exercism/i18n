# Instruções

Neste exercício vamos simular o primeiro turno de um jogo de [Blackjack](https://en.wikipedia.org/wiki/Blackjack).

Vais receber duas cartas e vais poder ver a carta do distribuidor que está virada para cima. Todas as cartas são representadas por uma string como "ace", "king", "three", "two", etc. Os valores de cada carta são:

| carta | valor | carta | valor |
| :---: | :---: | :---: | :---: |
|  ace  |  11   | eight |   8   |
|  two  |   2   | nine  |   9   |
| three |   3   |  ten  |  10   |
| four  |   4   | jack  |  10   |
| five  |   5   | queen |  10   |
|  six  |   6   | king  |  10   |
| seven |   7   | other |   0   |

**Nota**: Normalmente, os ases podem valer 1 ou 11, mas para simplificar vamos assumir que só podem valer 11.

Dependendo das tuas duas cartas e da carta do distribuidor, existe uma estratégia para o primeiro turno do jogo, em que tens as seguintes opções:

    - Stand (S)
    - Hit (H)
    - Split (P)
    - Automatically win (W)

Embora ainda não seja a ideal, vais seguir a estratégia que o teu amigo Alex tem vindo a desenvolver, que é a seguinte:

Categoria: Mão grande

- Se tiveres um par de ases, tens sempre de os dividir.
- Se tiveres um Blackjack (duas cartas cuja soma dá 21) e o distribuidor não tiver um ás, uma figura ou um dez, ganhas automaticamente. Se o distribuidor tiver alguma dessas cartas, tens de ficar e esperar que a outra carta seja revelada.

Categoria: Mão pequena

- Se as tuas cartas somarem 17 ou mais, deves ficar sempre.
- Se as tuas cartas somarem 11 ou menos, deves pedir sempre.
- Se as tuas cartas somarem um valor no intervalo [12, 16], deves ficar sempre, a menos que o distribuidor tenha um 7 ou mais, caso em que deves pedir sempre.

A lógica global já está implementada. Tens quatro tarefas:

## 1. Calcula a pontuação de qualquer carta.

Implementa uma função que calcule o valor numérico de uma carta a partir do seu nome, usando condicionais.

```java
parseCard("ace")
// returns 11
```

## 2. Determina se duas cartas formam um Blackjack.

Implementa uma função que devolve `true` se duas cartas formarem um Blackjack e `false` caso contrário.

```java
isBlackjack("queen", "ace")
// returns true
```

## 3. Implementa a lógica de decisão para pontuações de mão superiores a 20 pontos.

Implementa uma função que devolve a representação em string de uma decisão a partir das tuas cartas. Esta função só é chamada se o `handScore` for superior a 20. Recebe 2 argumentos: `isBlackJack` e `dealerScore`. Deve implementar os pontos da lista da categoria "Mão grande" acima.

```java
isBlackJack = true
dealerScore = 7
largeHand(isBlackJack, dealerScore)
// returns "W"
```

## 4. Implementa a lógica de decisão para pontuações de mão inferiores a 21 pontos.

Implementa uma função que devolve a representação em string de uma decisão a partir das tuas cartas. Esta função só é chamada se o `handScore` for inferior a 21. Recebe 2 argumentos: `handScore` e `dealerScore`. Deve implementar os pontos da lista da categoria "Mão pequena" acima.

```java
handScore = 15
dealerScore = 12
SmallHand(handScore, dealerScore)
// returns "H"
```
