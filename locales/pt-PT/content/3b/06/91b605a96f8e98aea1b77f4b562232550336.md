# Instruções case

```sather
   case zone
   when 0 then return 0;
   when 1, 2 then return 550;
   else return 920;
   end;
```

## Como funciona a correspondência

O valor a seguir a `case` é comparado com cada valor de `when` usando `=`, de cima para baixo. A primeira correspondência é executada, e só essa. As restantes partes `when` são ignoradas, e a execução continua depois do `end`.

Pode usar-se qualquer tipo que suporte `=`: `INT`, `CHAR`, `STR`, `BOOL`.

## A cláusula else

Um `case` sem correspondência e sem `else` provoca um erro fatal em tempo de execução. Escreve sempre um. Quando os casos restantes genuinamente não devam acontecer, diz isso aí em vez de o omitir:

```sather
   else
      raise "unknown zone: " + zone;
   end;
```

O `raise` vem mais tarde; até lá, devolver um valor predefinido razoável não faz mal.

## Quando preferir if

O `case` compara um valor com constantes. Qualquer outra coisa pede `if`:

```sather
   -- ranges
   if age < 13 then ... elsif age < 16 then ... end;

   -- more than one value at a time
   if score >= 8 and sings then ... end;
```

Tentar forçar um intervalo num `case` produz algo mais longo e pior do que o `if` que substitui.

## O case como expressão

O `case` é uma instrução, não uma expressão, por isso isto não é Sather:

```sather
   -- wrong
   fare := case zone when 1 then 550 else 920 end;
```

Devolve um valor de dentro de cada ramo, ou atribui a uma variável dentro de cada ramo.
