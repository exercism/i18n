# Instruções

Como aspirante a maga, a Elyse precisa de praticar o básico.

Tem uma pilha de cartas que quer manipular.

Para facilitar um pouco as coisas, só usa as cartas de 1 a 10.

A pilha de cartas é representada por um `Array`, com a base da pilha na frente do array e o topo da pilha na parte de trás.

## 1. Insere uma carta no topo da pilha

Implementa a função `insert_top`, que devolve uma cópia da pilha com a nova carta fornecida adicionada ao topo da pilha.

```rust
let stack = array![5, 9, 7, 1];
insert_top(stack, 8);
// -> [5, 9, 7, 1, 8]
```

## 2. Remove a carta do topo da pilha

Implementa a função `remove_top_card`, que devolve uma cópia da pilha sem a carta do topo.

Se a pilha dada estiver vazia, a pilha original deve ser devolvida, sem alterações.

```rust
let stack = array![3, 2, 6, 4, 8];
remove_top_card(stack);
// -> [3, 2, 6, 4]
```

## 3. Insere uma carta na base da pilha

Implementa a função `insert_bottom`, que devolve uma cópia da pilha com a nova carta fornecida adicionada à base da pilha.

```rust
let stack = array![5, 9, 7, 1];
insert_bottom(stack, 8);
// -> [8, 5, 9, 7, 1]
```

## 4. Remove uma carta da base da pilha

Implementa a função `remove_bottom_card`, que devolve uma cópia da pilha sem a carta da base.

Se a pilha dada estiver vazia, a pilha original deve ser devolvida, sem alterações.

```rust
let stack = array![8, 5, 9, 7, 1];
remove_bottom_card(stack);
// -> [5, 9, 7, 1]
```

## 5. Verifica o tamanho da pilha

Implementa a função `check_size_of_stack`, que verifica se o tamanho da pilha é igual a um dado `stack_size` ou não.

```rust
let stack = array![3, 2, 6, 4, 8];
check_size_of_stack(stack, 4);
// -> false
```
