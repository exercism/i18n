# Instruções

A Daphne tem andado a trabalhar num sistema para correr e registar os resultados das suas experiências. Parte do código tornou-se um pouco verboso e repetitivo, por isso pediu-te que escrevesses algumas expressões `use` para o ajudar a limpá-lo.

## 1. Define a função `with_retry`

Por vezes, as experiências podem falhar devido a um erro pontual, por isso, se uma experiência falhar, a Daphne quer tentá-la novamente para ver se funciona à segunda.

Define a função `with_retry`, que recebe como argumento uma função que devolve um resultado.

Se a função devolver um valor `Ok`, a função `with_retry` deve devolver esse valor.

Se a função devolver um valor `Error`, a função `with_retry` deve chamar a função outra vez e devolver o resultado dessa chamada.

A Daphne vai usar a função assim:

```gleam
pub fn main() {
  use <- with_retry
  // Perform the experiment here
}
```

## 2. Define a função `record_timing`

A Daphne regista quanto tempo cada experiência demora a correr, chamando uma função de registo de tempo antes e depois de cada experiência.

Define a função `record_timing`, que recebe dois argumentos:
- Uma função de registo de tempo, que não recebe argumentos e devolve `Nil`.
- Uma função de experiência, que não recebe argumentos e devolve um resultado.

A função `record_timing` deve chamar a função de registo de tempo, depois chamar a função de experiência, depois chamar outra vez a função de registo de tempo e, por fim, devolver o resultado da função de experiência.

A Daphne vai usar a função assim:

```gleam
pub fn main() {
  use <- record_timing(time_logger)
  // Perform the experiment here
}
```

## 3. Define a função `run_experiment`

As experiências são compostas por três fases. A preparação, a ação e o registo. As três fases devolvem resultados e cada fase precisa do resultado bem-sucedido da fase anterior para correr.

Define a função `run_experiment`, que recebe quatro argumentos:
- O nome da experiência, como `String`.
- Uma função de preparação, que não recebe argumentos e devolve um resultado.
- Uma função de ação, que recebe como argumento o valor `Ok` da função de preparação e devolve um resultado.
- Uma função de registo, que recebe como argumentos o valor `Ok` das funções de preparação e de ação e devolve um resultado.

Se as três funções forem bem-sucedidas, a função `run_experiment` deve devolver `Ok(#(experiment_name, recording_data))`.

Se alguma das funções devolver um valor `Error`, a função `run_experiment` deve devolver esse valor.

A Daphne vai usar a função assim:

```gleam
pub fn main() {
  use setup_data, action_data <- run_experiment("Test 1", setup, action)
  // Record the results here
}
```
