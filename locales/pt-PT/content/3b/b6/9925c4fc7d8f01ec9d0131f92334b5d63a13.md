# Recursos de aprendizagem recomendados

O Exercism disponibiliza exercícios e feedback, mas pode ser difícil dar o primeiro passo para quem está a aprender ABAP pela primeira vez. Estes recursos gratuitos podem ajudar-te a começar:

* SAP Learning Journey [Learning the Basics of ABAP Programming](https://learning.sap.com/courses/learn-the-basics-of-abap-programming-on-sap-btp)
* [ABAP for Newbies Community](https://pages.community.sap.com/topics/abap/abap-for-newbies)
* [ABAP Language Documentation](https://help.sap.com/doc/abapdocu_latest_index_htm/latest/en-US/index.htm)
* [ABAP Starter](https://github.com/Keller-Michael/ABAP_starter)
* [ABAP Cheat Sheets](https://github.com/SAP-samples/abap-cheat-sheets)

Se estás a começar com ABAP, recomendamos que completes as seguintes unidades da SAP Learning Journey:

- Getting Started
- ABAP Language Basics
- Local Classes 

Depois disso, estarás pronto para resolver exercícios de ABAP no Exercism.

Se chegares a exercícios mais complexos, sugerimos que faças também as seguintes unidades:

- Structures
- Complex Internal Tables

Estes tópicos podem ser úteis para resolver exercícios mais difíceis no Exercism.
