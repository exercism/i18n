# Introdução

## Boolean

O tipo `Bool` é um dos blocos de construção da linguagem.
Serve para descrever se algo é verdadeiro ou falso, com os respetivos valores `True` e `False`.

Os Boolean podem ser combinados com os operadores `&&` ("E") e `||` ("OU"), e negados com a função `not`.

Os Boolean também são extremamente úteis para criar ramificações no teu código que só são executadas quando determinadas condições se verificam.
Em Elm, isto faz-se com uma expressão `if-then-else`, usada da seguinte forma.

```elm
if someCondition || (someOtherCondition && anotherCondition) then
    doSomething
else
    doSomethingElse
```
