# Instalação

Precisas do [Vim](http://www.vim.org) para fazer os exercícios:

- [macOS](#macos)
- [Ubuntu / Debian](#ubuntu--debian)
- [Windows](#windows)
- [Código-fonte](#source)

## macOS

O sistema operativo já traz o Vim por predefinição, mas é uma versão irremediavelmente desatualizada.

É provável que uses o [MacPorts](https://www.macports.org) ou o [Homebrew](https://brew.sh) para instalar software.

Homebrew:

```
$ brew update
$ brew install vim
```

MacPorts:

```
$ sudo port install vim +huge
```

Se quiseres uma interface gráfica, dá antes uma vista de olhos ao [MacVim](https://macvim-dev.github.io/macvim).

## Ubuntu / Debian

Instala uma versão completa do Vim com suporte para interface gráfica (`gvim`):

```
$ sudo apt-get update
$ sudo apt-get install vim-gtk
```

## Windows

Com o [Chocolatey](https://chocolatey.org):

```
C:\> choco install vim
```

Ou descarrega e instala diretamente a partir [daqui](http://www.vim.org/download.php#pc).

## Código-fonte

Se quiseres compilar a versão mais recente do Vim, consulta o [repositório oficial no GitHub](https://github.com/vim/vim).
