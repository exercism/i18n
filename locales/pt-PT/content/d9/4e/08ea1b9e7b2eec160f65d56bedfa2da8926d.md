# Introdução

Um vetor é um array unidimensional.
Podem conter elementos de tipos diferentes.

## Criar vetores

Os vetores podem ser criados através da função `vector` ou usando a sua forma de leitura `#()`

```lisp
(vector 1 t "foo" 'b) ; => #(1 T "foo" B)
#(2 nil "bar" a)      ; => #(2 NIL "bar" A)
```

Como são arrays, também podem ser criados com `make-array`:

```lisp
(make-array 3 :initial-element 'x)        ; => #(X X X)
(make-array 3 :initial-contents '(a b c)) ; => #(A B C)
```

## O predicado de vetores

Para verificar se um objeto é um vetor, basta usar o predicado `vectorp`.

## Aceder aos elementos

Para aceder aos elementos de um vetor, usa `aref`. Os índices começam em zero:

```lisp
(aref #(1 2 3) 1) ; => 2
(aref #(a b c) 0) ; => A
```
