# Introdução

## Constantes

As constantes em Gleam são uma forma de dar nomes a valores. Definem-se com a palavra-chave `const`.

```gleam
pub const pi: Float = 3.14159

pub fn circle_area(radius: Float) -> Float {
  radius *. radius *. pi
}
```

Quando são definidas com a palavra-chave `pub`, as constantes de módulo podem ser acedidas a partir de outros módulos; caso contrário, só podem ser acedidas dentro do módulo onde são definidas.

## Ordens

O módulo `gleam/order` da biblioteca padrão do Gleam contém o tipo `Order`, que serve para comparar valores.

A definição de `Order` é esta:

```gleam
pub type Order {
  Gt
  Eq
  Lt
}
```

O tipo tem três variantes, cada uma usada para representar a relação entre um valor e outro valor:

- `Gt` - o valor é _maior do que_ o outro valor.
- `Eq` - o valor é _igual a_ o outro valor.
- `Lt` - o valor é _menor do que_ o outro valor.

Se um tipo de dados puder ser comparado por tamanho, é comum o módulo definir uma função `compare` que devolve um valor do tipo `Order`. Por exemplo, `gleam/float` e `gleam/int` definem funções `compare` que operam sobre números de vírgula flutuante e inteiros, respetivamente.

```gleam
int.compare(1, 2)
// -> Lt

int.compare(2, 2)
// -> Eq

float.compare(1.0, 2.0)
// -> Lt
```

As funções de ordenação, como `list.sort`, recebem habitualmente uma função que devolve um valor do tipo `Order`, permitindo a quem chama definir como a lista deve ser ordenada.

```gleam
list.sort([3, 7, 3, 1], by: int.compare)
// -> [1, 3, 3, 7]
```
