# Introdução

No PHP, uma variável pode ser chamada como uma função ao aplicar-lhe parênteses [`()`]. Quando o PHP tenta invocar a função, vai procurar uma função com o mesmo nome que o valor da variável.

```php
function foo(): string
{
    return "foo() invoked";
}

$func = 'foo';
$func(); // This calls foo()
```
