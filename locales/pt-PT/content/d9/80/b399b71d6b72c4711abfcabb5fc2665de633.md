# Dicas

## 1. Determina o número total de aves que contaste até agora

- Consulta a introdução do exercício para ver um exemplo de como usar um ciclo for para iterar sobre um array.
- Usa uma variável auxiliar para guardar a contagem total e aumenta essa variável à medida que percorres o array.
- Pensa no valor inicial correto para essa variável auxiliar.
- Volta ao [conceito de array][concept-arrays] para relembrar como obter valores de um array.

## 2. Calcula o número de aves visitantes numa determinada semana

- Esta tarefa é semelhante à primeira.
  Podes copiar o teu código como ponto de partida.
- Pensa em que índices do array precisas de considerar para a semana número 1 e 2, respetivamente.
- Agora, encontra uma forma geral de calcular o primeiro e o último índice a considerar.
- Com isso, podes montar o ciclo for para iterar apenas sobre a secção relevante do array.

## 3. Corrige um erro de contagem

- Mais uma vez, precisas de montar um ciclo for para iterar sobre todo o array de contagem de aves.
- Desta vez, só precisas de visitar entradas alternadas do array.
- Altera o passo para que a variável contadora aumente de acordo após cada iteração.
- No corpo do ciclo for, podes usar o operador de incremento para alterar o valor de um elemento de um array no próprio local.
