# Instruções

A Lucy tem uma loja de autocolantes online, onde vende autocolantes giros com as linguagens de programação preferidas de toda a gente. Pessoas de todo o mundo compram-lhe os autocolantes e ela está a ter dificuldades em lidar com as diferentes moedas.

Cria um programa que a Lucy possa usar para calcular preços e ter a certeza de que está sempre a usar a moeda correta.

## 1. Define os tipos `Usd`, `Eur` e `Jpy`

Estes tipos servem para representar as diferentes moedas que os clientes da Lucy usam para comprar os autocolantes dela.

Devem ser usados como tipos fantasma e não precisam de ter construtores.

## 2. Define o tipo `Money`.

O tipo `Money` deve ter um campo `Int` para a quantia de dinheiro, um parâmetro de tipo fantasma de moeda e deve ser um tipo opaco.

## 3. Define as funções `dollar`, `euro` e `yen`

Define as funções `dollar`, `euro` e `yen` que recebem um argumento `Int` e devolvem um valor `Money` com a moeda correta.

## 4. Define a função `total`

Define a função `total`, que recebe uma lista de valores `Money` e devolve a quantia total de dinheiro na lista.

```gleam
total([euro(120), euro(200), euro(145)])
// -> euro(465)
```
