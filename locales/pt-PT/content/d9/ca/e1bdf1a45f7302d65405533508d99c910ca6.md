# Introdução

Uma *palavra genérica* declara uma operação que pode ter implementações diferentes consoante a classe do seu argumento. Os métodos são adicionados com `M:`.

```factor
USING: kernel math ;

GENERIC: area ( shape -- n )

TUPLE: square side ;
TUPLE: circle radius ;

M: square area side>> dup * ;
M: circle area radius>> dup * 3.14159 * ;
```

```factor
T{ square { side 4 } } area .    ! => 16
T{ circle { radius 2 } } area .  ! => 12.56636
```

`GENERIC:` declara a palavra e o seu efeito de pilha. `M:` define um método para uma classe específica. Em tempo de execução, o Factor faz o despacho com base na classe do argumento que está no topo da pilha.

Podes perguntar ao genérico para que classes tem métodos e adicionar ou remover métodos depois disso. Não existe nenhuma sintaxe especial de herança: qualquer classe de tuplos é automaticamente elegível para receber métodos definidos.
