# Instruções

És um mixologista experiente e preparas bebidas saborosas para o público apreciar nas suas noites de saída.
Mas pensaste que podias tornar a tua vida mais fácil se escrevesses um pouco de código para te ajudar no trabalho.

## 1. Determina quanto tempo demora a preparar um pedido

Bebidas diferentes demoram tempos diferentes a preparar:

- `"beer"`, `"soda"` e `"water"` demoram 0,5 minutos cada.
- Os `"shot"` demoram 1,0 minutos e os `"mixed drink"` demoram 1,5 minutos,
- Os `"fancy drink"` demoram 2,5 minutos,
- Os `"frozen drink"` demoram 3,0 minutos.

Implementa a função `timeToPrepare(drinks:)`, que recebe o argumento `drinks`, o qual contém um array de strings que representam as bebidas a preparar.
A função deve devolver o tempo total necessário para preparar todas as bebidas do array.

```swift
timeToPrepare(drinks: ["beer", "frozen drink", "shot"])
// returns 4.5
```

## 2. Reabastece a tua reserva de gomos de lima

Uma das primeiras coisas que tens de fazer quando começas o turno é garantir que o teu caixote de gomos de lima está cheio para o turno que se segue.
Vais ter limas de tamanhos diferentes, que dão quantidades diferentes de gomos: consegues 6 gomos de uma lima "small", 8 gomos de uma lima "medium" e 10 de uma lima "large".

Enquanto ainda precisares de mais gomos e ainda tiveres limas para cortar, retira a primeira lima do array e subtrai o número adequado de gomos à quantidade de que precisas.
Continua até já não precisares de mais gomos ou até acabarem as limas.

Implementa a função `makeWedges(needed:limes:)`, que recebe os argumentos `needed`, que contém o número de gomos que precisas de cortar, e `limes`, que contém um array de strings que representam os tamanhos das limas que tens disponíveis para cortar.
A função deve devolver o número de limas que cortaste.

```swift
makeWedges(needed: 25, limes: ["small", "small", "large", "medium", "small"])
// returns 4
```

## 3. Termina o teu turno

Parabéns! O teu longo dia de trabalho está quase a acabar e em breve vais para casa trabalhar na tua nova aplicação.
Mas ainda tens uma série de pedidos de bebidas para preparar antes de passares os pedidos ao turno seguinte e ires embora.

Enquanto ainda tiveres tempo no teu turno, prepara o primeiro pedido do array e remove depois esse pedido do array.
Podes então subtrair ao tempo que resta do teu turno o tempo que demorou a preparar esse pedido, de acordo com a tua função `timeToPrepare(drinks:)`.

Implementa a função `finishShift(minutesLeft:remainingOrders:)`, que recebe o número de minutos que restam do teu turno (garantidamente superior a 0) e um array não vazio de pedidos de bebidas.
A função deve devolver o array dos pedidos que ainda não conseguiste preparar antes do fim do teu turno.

```swift
finishShift(minutesLeft: 5, remainingOrders: [["beer", "frozen drink", "shot"], ["fancy drink", "soda"], ["beer", "beer", "water"], ["mixed drink", "frozen drink"]])
// returns [["beer", "beer", "water"], ["mixed drink", "frozen drink"]]
```

## 4. Regista determinados pedidos

Para garantir que a beer e a soda se mantêm frescas, precisas de acompanhar os pedidos de ambas, juntamente com as horas a que foram feitos.

Implementa a função `orderTracker(orders: [(drink: String, time: String)]) -> (beer: (first: String, last: String, total: Int)?, soda: (first: String, last: String, total: Int)?)` que, dada uma lista de pedidos e de horas, devolve um par de tuplos opcionais com as horas do primeiro e do último pedido de beer e de soda, juntamente com o número total de pedidos de cada uma, e `nil` se não tiver sido feito nenhum pedido dessas bebidas. Não precisas de acompanhar mais nenhuma bebida.

Implementa a função `orderTracker(orders:)`, que recebe um array de tuplos, em que cada tuplo contém a bebida pedida e a hora a que o pedido foi feito.
A função deve devolver um tuplo com a primeira e a última hora a que foi pedido beer, o número total de pedidos de beer, a primeira e a última hora a que foi pedido soda e o número total de pedidos de soda.
Deve ser devolvido como um tuplo com o formato: `(beer: (first: String, last: String, total: Int)?, soda: (first: String, last: String, total: Int)?)`.

```swift
let orders = [
    (drink: "beer", time: "10:01"), (drink: "frozen drink", time: "10:02"),
    (drink: "shot", time: "10:05"), (drink: "fancy drink", time: "10:06"),
    (drink: "soda", time: "10:09"), (drink: "beer", time: "10:15"), (drink: "beer", time: "10:22"),
    (drink: "water", time: "10:26"), (drink: "mixed drink", time: "10:28"),
    (drink: "frozen drink", time: "10:33"),
]

orderTracker(orders: orders)

// returns (beer: (first "10:01", last "10:22", total 3), soda: (first "10:09", last "10:09", total 1))
```
