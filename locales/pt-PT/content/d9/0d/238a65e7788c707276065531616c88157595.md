# remove a função main e corrige o nome do pacote

Remove a função `main`, volta a pôr no pacote o nome `twofer` e corre os testes.

Uma função `main` serve de ponto de entrada de um programa. O Exercism usa TDD ([desenvolvimento orientado a testes](http://testfirst.org/about#tdd)).
Isto significa que o código é executado ao correr os testes para que estes passem. Para correr os testes, usa `go test` no terminal.
Os testes passam se a funcionalidade estiver implementada corretamente.
