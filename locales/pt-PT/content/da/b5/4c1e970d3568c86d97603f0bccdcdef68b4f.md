# Break, Continue

Quando usas uma estrutura de controlo de ciclos ou de iteração, as palavras-chave `break` e `continue` podem ajudar a controlar o fluxo de um programa.
A palavra-chave `break` sai do contexto do ciclo para o âmbito externo, terminando assim o ciclo.
A palavra-chave `continue` ignora o resto da iteração atual e reinicia o contexto do ciclo no início da iteração seguinte.
Embora seja pouco comum, podes indicar um número junto da palavra-chave para controlar quantos contextos abandonar ou em quantos saltar para a iteração seguinte.

```php
<?php
$i = 1;
while ($i <= 10) {

    if ($i <= 5) {
        i += 1;
        continue;
    }
    break;
}
```

No exemplo anterior, `continue` é executado cinco (5) vezes, mas na sexta (6) iteração `break` é executado, fazendo com que o código saia do ciclo.
