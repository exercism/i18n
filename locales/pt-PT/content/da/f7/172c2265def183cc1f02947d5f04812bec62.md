# Sobre

O `<iota>` do Factor produz uma sequência *virtual* dos números inteiros
`0, 1, …, n-1`. Percorrê-la com `map` dá origem a uma sequência tabulada
em que cada elemento é uma função da sua posição:

```factor
USING: math sequences ;

5 <iota> [ sq ] map .         ! => { 0 1 4 9 16 }
8 <iota> [ 1 + ] map .        ! => { 1 2 3 4 5 6 7 8 }
```

Duas peças permitem-te transformar uma sequência de códigos inteiros numa
string:

| palavra   | papel                                                    |
|-----------|---------------------------------------------------------|
| `CHAR:`   | literal em tempo de análise que empilha o ponto de código de um caráter |
| `>string` | converte uma sequência de pontos de código numa string  |

Combinadas, formam o padrão habitual para construir uma linha de carateres
indexada pela posição:

```factor
USING: kernel math sequences strings ;

10 <iota> [ 2 mod zero? [ CHAR: O ] [ CHAR: . ] if ] map >string .
! => "O.O.O.O.O."
```

Escolher o caráter com `if` (ou `?`) dentro da quotation mantém a decisão de
cada posição junto do índice do qual depende.
