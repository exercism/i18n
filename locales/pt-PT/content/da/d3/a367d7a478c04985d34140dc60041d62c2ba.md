# Instruções

Neste exercício vais escrever mais algum código relacionado com a preparação e a confeção da tua fantástica lasanha do teu livro de receitas preferido.

Tens quatro tarefas.
A primeira está relacionada com a confeção propriamente dita; as outras três são sobre a preparação perfeita.

## 1. Estima o tempo de preparação

Para a próxima lasanha que vais preparar, queres garantir que reservas tempo suficiente para poderes desfrutar da confeção.
Já planeaste que camadas a tua lasanha vai ter.
Agora queres estimar quanto tempo a preparação vai levar, com base nisso.

Implementa uma função `PreparationTime` que aceita um slice de camadas como `[]string` e o tempo médio de preparação por camada, em minutos, como um `int`.
A função deve devolver a estimativa do tempo total de preparação, com base no número de camadas, como um `int`.
Go não tem valores por omissão para funções.
Se o tempo médio de preparação for passado como `0` (o valor inicial por omissão de um `int`), deve usar-se o valor por omissão de `2`.

```go
layers := []string{"sauce", "noodles", "sauce", "meat", "mozzarella", "noodles"}
PreparationTime(layers, 3)
// => 18
PreparationTime(layers, 0)
// => 12
```

## 2. Calcula as quantidades de massa e molho necessárias

Além de reservares o tempo, também queres garantir que tens molho e massa suficientes para cozinhar a lasanha dos teus sonhos.
Por cada camada de massa na tua lasanha, vais precisar de 50 gramas de massa.
Por cada camada de molho na tua lasanha, vais precisar de 0,2 litros de molho.

Define a função `Quantities`, que recebe um slice de camadas como parâmetro, do tipo `[]string`.
A função determina então a quantidade de massa e de molho necessárias para preparar a tua refeição.
O resultado deve ser devolvido como dois valores: `noodles` como um `int` e `sauce` como um `float64`.

```go
Quantities([]string{"sauce", "noodles", "sauce", "meat", "mozzarella", "noodles"})
// => 100, 0.4
```

## 3. Adiciona o ingrediente secreto

Há algum tempo, visitaste um amigo e comeste lasanha em casa dele.
Estava incrível e tinha algo de especial.
O amigo enviou-te a lista de ingredientes e disse-te que o último item da lista era o "ingrediente secreto" que tornava a refeição tão especial.
Agora também queres adicionar esse ingrediente secreto à tua receita.

Escreve uma função `AddSecretIngredient` que aceita dois slices de ingredientes do tipo `[]string` como parâmetros.
O primeiro parâmetro é a lista que o teu amigo te enviou; o segundo é a lista de ingredientes da tua própria receita.
O último elemento da tua lista de ingredientes é sempre `"?"`.
A função deve substituí-lo pelo último item da lista do teu amigo.
**Nota:** a `AddSecretIngredient` não devolve nada; deves modificar diretamente a tua lista de ingredientes.
A lista com os ingredientes do teu amigo **não** deve ser modificada.
Além disso, como o `slice` é passado para uma função como ponteiro, as alterações aos dois argumentos `[]string` passados para `AddSecretIngredient` são feitas diretamente.

```go
friendsList := []string{"noodles", "sauce", "mozzarella", "kampot pepper"}
myList := []string{"noodles", "meat", "sauce", "mozzarella","?"}

AddSecretIngredient(friendsList, myList)
// myList => []string{"noodles", "meat", "sauce", "mozzarella", "kampot pepper"}
```

## 4. Ajusta a receita

As quantidades indicadas no teu livro de receitas só dão para uma lasanha de duas porções.
Como queres cozinhar para mais pessoas da próxima vez, queres calcular as quantidades para diferentes números de porções.

Implementa uma função `ScaleRecipe` que recebe dois parâmetros.

- Um slice de valores `float64` necessários para 2 porções.
- O número de porções que queres cozinhar.

A função deve devolver um slice de `float64` com as quantidades necessárias para o número de porções pretendido.
No entanto, queres manter a receita original.
Isto significa que o argumento `quantities` não deve ser modificado nesta função.

```go
quantities := []float64{ 1.2, 3.6, 10.5 }
scaledQuantities := ScaleRecipe(quantities, 4)
// => []float64{ 2.4, 7.2, 21 }
```
