# Instruções

A máquina Take-A-Number básica estava a vender muito bem, mas alguns utilizadores queixavam-se da falta de funcionalidades avançadas em comparação com outros modelos disponíveis no mercado.

O fabricante ouviu o feedback dos utilizadores e decidiu lançar um modelo de luxo com mais funcionalidades, e, mais uma vez, coube-te a tarefa de escrever o software desta máquina.

As novas funcionalidades do modelo de luxo incluem:
- Manter o registo dos números que estão atualmente em fila.
- Definir o número mínimo e máximo. Isto permite usar várias máquinas Take-A-Number de luxo para colocar clientes em fila para departamentos diferentes da mesma instalação, e distinguir os departamentos pelo intervalo de números.
- Permitir que determinados números saltem a fila, para dar um atendimento prioritário a grávidas e a idosos.
- Encerramento automático, para evitar deixar a máquina ligada durante todo o fim de semana e desperdiçar energia.

A lógica de negócio da máquina já foi implementada pelo teu colega e encontra-se no módulo `TakeANumberDeluxe.State`. Agora, a tua tarefa é envolvê-la num `GenServer`.

## 1. Iniciar a máquina

Usa o comportamento `GenServer` no módulo `TakeANumberDeluxe`.

Implementa a função `start_link/1` e o callback `GenServer` necessário.

O argumento passado a `start_link/1` é uma keyword list. Contém as chaves `:min_number` e `:max_number`. Os valores dessas chaves têm de ser passados à função `TakeANumberDeluxe.State.new/2`.

Se `TakeANumberDeluxe.State.new/2` devolver um tuplo `{:ok, state}`, a máquina deve iniciar-se, usando o estado devolvido como seu estado. Se, em vez disso, devolver um tuplo `{:error, error}`, a máquina deve parar, indicando o erro devolvido como motivo da paragem.

```elixir
TakeANumberDeluxe.start_link(min_number: 1, max_number: 9)
# => {:ok, #PID<0.174.0>}

TakeANumberDeluxe.start_link(min_number: 9, max_number: 1)
# => {:error, :invalid_configuration}
```

Talvez tenhas reparado que a função `TakeANumberDeluxe.State.new/2` também recebe um terceiro argumento opcional, `auto_shutdown_timeout`. Vamos usá-lo no último passo deste exercício.

## 2. Comunicar o estado da máquina

Implementa a função `report_state/1` e o callback `GenServer` necessário. A máquina deve responder a quem a invoca com o seu estado atual.

```elixir
{:ok, machine} = TakeANumberDeluxe.start_link(min_number: 1, max_number: 10)
TakeANumberDeluxe.report_state(machine)
# => %TakeANumberDeluxe.State{
#      max_number: 10,
#      min_number: 1,
#      queue: %TakeANumberDeluxe.Queue{in: [], out: []},
#      auto_shutdown_timeout: :infinity,
#    }
```

## 3. Colocar novos números na fila

Implementa a função `queue_new_number/1` e o callback `GenServer` necessário.

Deve chamar a função `TakeANumberDeluxe.State.queue_new_number/1` com o estado atual da máquina.

Se `TakeANumberDeluxe.State.queue_new_number/1` devolver um tuplo `{:ok, new_number, new_state}`, a máquina deve responder a quem a invoca com o novo número e definir o novo estado como seu estado. Se, em vez disso, devolver um tuplo `{:error, error}`, a máquina deve responder a quem a invoca com o erro e não alterar o seu estado.

```elixir
{:ok, machine} = TakeANumberDeluxe.start_link(min_number: 1, max_number: 2)
TakeANumberDeluxe.queue_new_number(machine)
# => {:ok, 1}

TakeANumberDeluxe.queue_new_number(machine)
# => {:ok, 2}

TakeANumberDeluxe.queue_new_number(machine)
# => {:error, :all_possible_numbers_are_in_use}
```

## 4. Atender o próximo número da fila

Implementa a função `serve_next_queued_number/2` e o callback `GenServer` necessário.

Deve chamar a função `TakeANumberDeluxe.State.serve_next_queued_number/2` com o estado atual da máquina e o seu segundo argumento opcional, `priority_number`.

Se `TakeANumberDeluxe.State.serve_next_queued_number/2` devolver um tuplo `{:ok, next_number, new_state}`, a máquina deve responder a quem a invoca com o número seguinte e definir o novo estado como seu estado. Se, em vez disso, devolver um tuplo `{:error, error}`, a máquina deve responder a quem a invoca com o erro e não alterar o seu estado.

```elixir
{:ok, machine} = TakeANumberDeluxe.start_link(min_number: 1, max_number: 10)
TakeANumberDeluxe.queue_new_number(machine)
# => {:ok, 1}

TakeANumberDeluxe.serve_next_queued_number(machine)
# => {:ok, 1}

TakeANumberDeluxe.serve_next_queued_number(machine)
# => {:error, :empty_queue}
```

## 5. Reiniciar o estado

Implementa a função `reset_state/1` e o callback `GenServer` necessário.

Deve chamar a função `TakeANumberDeluxe.State.new/2` para criar um novo estado a partir do `min_number` e do `max_number` do estado atual. A máquina deve definir o novo estado como seu estado. Não deve responder a quem a invoca.

```elixir
{:ok, machine} = TakeANumberDeluxe.start_link(min_number: 1, max_number: 10)

TakeANumberDeluxe.reset_state(machine)
# => :ok
```

## 6. Implementar o encerramento automático

Modifica o arranque da máquina. Deve ler o valor da chave `:auto_shutdown_timeout` na keyword list passada como `init_arg` e passá-lo como terceiro argumento a `TakeANumberDeluxe.State.new/3`. Usa o valor predefinido `:infinity` se `:auto_shutdown_timeout` não tiver sido indicado.

Modifica o reinício do estado da máquina para também passar `auto_shutdown_timeout` a `TakeANumberDeluxe.State.new/3`.

Modifica os valores devolvidos por todos os callbacks implementados (`init/1` e todos os callbacks `handle_*`) para definirem um timeout. Usa o valor da chave `:auto_shutdown_timeout` do estado atual da máquina. Não adiciones o timeout ao valor devolvido `{:stop, reason}` de `init/1`: os timeouts só se aplicam depois de o servidor ter iniciado o seu ciclo de receção.

Implementa um callback `GenServer` para tratar a mensagem `:timeout` que será enviada à máquina se esta não receber outras mensagens dentro do timeout indicado. Deve terminar o processo com o motivo `:normal`.

Certifica-te também de que tratas quaisquer mensagens inesperadas, ignorando-as.

```elixir
{:ok, machine} =
  TakeANumberDeluxe.start_link(
    min_number: 1,
    max_number: 10,
    auto_shutdown_timeout: :timer.hours(2)
  )

# after 3 hours...

TakeANumberDeluxe.queue_new_number(machine)
# => ** (exit) exited in: GenServer.call(#PID<0.171.0>, :queue_new_number, 5000)
#        ** (EXIT) no process: the process is not alive or there's no process currently associated with the given name, possibly because its application isn't started
#       (elixir 1.13.0) lib/gen_server.ex:1030: GenServer.call/3
```
