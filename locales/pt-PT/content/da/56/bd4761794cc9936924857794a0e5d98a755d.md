# Instalação

Vais precisar de acesso a uma base de dados Oracle montada. Se ainda não tens uma instalada, aqui ficam algumas opções:
* obtém um espaço de trabalho gratuito em https://apex.oracle.com
* descarrega o VirtualBox da Oracle e corre uma das imagens disponíveis gratuitamente; na altura em que isto foi escrito, a mais fácil para começar talvez seja a _Database App Development VM_. A imagem é bastante grande...
* descarrega e instala uma versão do próprio Oracle DB. As licenças de programador são gratuitas.
