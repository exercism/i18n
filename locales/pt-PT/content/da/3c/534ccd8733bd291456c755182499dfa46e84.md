# Introdução

Uma função em Cairo permite-te agrupar código numa unidade reutilizável, o que torna os teus programas mais modulares e mais fáceis de compreender.
Em Cairo, as funções são compostas pela palavra-chave `fn`, seguida do nome da função, de uma lista de parâmetros entre parênteses e de um bloco de código que define o que a função faz.

## Parâmetros de função

Em Cairo, todos os parâmetros de função têm de ter um tipo explícito.
Ao contrário de algumas linguagens, Cairo não infere tipos e não existem valores predefinidos para os parâmetros, por isso todos os parâmetros são obrigatórios.

```rust
// Function with no parameters
fn print_hello() {
    // Function body
}

// Function with two parameters
fn print_greeting_name(greeting: ByteArray, name: ByteArray) {
    // Function body
}
```

## Parâmetros vs. argumentos

É importante distinguir entre `parameters` e `arguments`:

- **Parâmetros** são os nomes das variáveis usados na definição da função, como `greeting` e `name` na função `print_greeting_name`.
- **Argumentos** são os valores reais passados à função quando esta é chamada.

```rust
// Calling the function with arguments
print_greeting_name(123, 456)
```

## Instruções e expressões

O corpo de uma função é composto por uma série de instruções, que podem terminar, opcionalmente, numa expressão.

- As instruções são comandos que executam alguma ação e não devolvem um valor.
- As expressões são avaliadas e produzem um valor resultante.

Criar uma variável e atribuir-lhe um valor com a palavra-chave `let` é uma instrução.

```rust
let y = 6;
```

Mas o `6` na instrução acima é uma expressão que é avaliada para o valor `6`.

Chamar uma função é uma expressão, uma vez que é sempre avaliada para um valor: o valor devolvido explícito da função, se for indicado, ou o tipo 'unit' `()` caso contrário.

## Valores devolvidos

As funções de Cairo podem devolver valores ao código que as chama.
Os valores devolvidos são indicados depois dos parâmetros, separados por uma seta `->`.
Em Cairo, o valor devolvido da função é sinónimo do valor da última expressão no bloco do corpo da função.
Podes sair de uma função mais cedo com a palavra-chave `return`, indicando um valor.

```rust
// Function returning the last (and only) expression
fn hello(name: ByteArray) -> ByteArray {
    "Hello " + name
}

// Function returning using the `return` keyword
fn double_if_even(value: u32) -> u32 {
    if value % 2 == 0 {
        return value * 2;
    }
    return value;
}
```

## Invocar funções

Para chamares uma função em Cairo, basta usares o nome da função seguido dos argumentos entre parênteses.

```rust
// Calling a function with no parameters
print_hello()

// Calling a function with one parameter
let greeting = hello("John")

// Calling a function with multiple parameters
print_greeting_name("Howdy", "Joel")
```
