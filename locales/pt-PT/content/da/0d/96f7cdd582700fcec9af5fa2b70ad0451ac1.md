# Introdução

A [forma especial with][with] permite focar-te no «caminho ideal» de uma série de passos que podem falhar e tratar das falhas mais tarde.

```elixir
with {:ok, id} <- get_id(username),
     {:ok, avatar} <- fetch_avatar(id),
     {:ok, image_type} <- check_valid_image_type(avatar) do
  {:ok, image_type, avatar}
else
  :not_found ->
    {:error, "invalid username"}

  {:error, "not an image"} ->
    {:error, "avatar associated to #{username} is not an image"}

  err ->
    err
end
```

Em cada passo, se uma cláusula corresponder, a cadeia continua até o bloco `do` ser executado. Se uma correspondência falhar, a cadeia para e é devolvida a cláusula que não correspondeu. Podes ainda usar um bloco `else` para apanhar as correspondências falhadas e alterar o valor devolvido.

[with]: https://hexdocs.pm/elixir/Kernel.SpecialForms.html#with/1
