# Testes

Se descarregaste um exercício com a ferramenta CLI, deves ver um ficheiro Uiua com o nome do exercício e um ficheiro `tests.ua`.
Este ficheiro contém todos os casos de teste, que correspondem aos que o executor de testes corre quando envias a tua solução.
Podes acrescentar casos de teste adicionais, à vontade, para fazer experiências.
No entanto, alterar os testes não afeta o processo do executor de testes online.

## Testes locais

Para correres os testes de um exercício, abre um terminal na pasta do exercício e executa o comando `uiua test tests.ua`.

Por exemplo, a saída de um exercício `hello-world` sem alterações pode ter este aspeto:

```bash
$ uiua test tests.ua
Error: Goodbye, Mars!
  at tests.ua:3:1
3 | ⍤⤙≍ "Hello, World!" Hello
    ─
Test failed
```

A linha `Error` mostra a saída real do teu código.
O número da linha indica a localização do resultado esperado em `tests.ua`.
Uma solução correta produz:

```bash
$ uiua test tests.ua
Test passed
```
