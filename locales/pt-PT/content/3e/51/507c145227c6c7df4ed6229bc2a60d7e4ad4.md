## Introdução

Um ponteiro é uma variável ou constante cujo valor é o endereço de outra variável ou constante.
Os ponteiros são uma característica poderosa e potencialmente perigosa do C.
Pode ser difícil compreender os ponteiros.

As variáveis e as constantes guardam o seu valor numa posição de memória.
Essa posição na memória é conhecida como o endereço da variável ou constante.

Para obter o endereço de uma variável usamos o operador de endereço, que é `&`.
```c
int i = 5;
int *i_address = &i;
```

Um tipo seguido de um `*` seguido de um identificador é a forma de declarar um ponteiro para uma variável desse tipo.
O `*` é conhecido como o operador de indireção, porque se refere indiretamente ao valor cujo endereço o ponteiro guarda.

Quando criamos um array assim

```c
int my_ints[] = {1, 2};
```

O valor de `my_ints` é na verdade o seu endereço, que também calha ser o mesmo que o endereço do seu primeiro elemento.
O endereço do seu segundo elemento será o endereço do primeiro elemento mais o tamanho de um `int` no sistema.

É por isso que os ponteiros são declarados com um determinado tipo.
Se um ponteiro não soubesse para que tipo aponta, não saberia quantos bytes avançar ao somar-lhe `1`.
Somar `1` a um ponteiro não significa necessariamente que estamos a somar um byte ao endereço.
Significa que estamos a somar `1` vez o comprimento do seu tipo em bytes.
