# Anexo às instruções

## Dicas

Este exercício é sobre [refatoração de código](https://en.wikipedia.org/wiki/Refactoring), por isso fornecemos-te uma solução que já passa nos testes.

O desafio é reescrevê-la até teres orgulho nela, e aprenderes algo pelo caminho.

Se não sabes por onde começar, aqui ficam algumas ideias:

- Tenta reduzir a repetição ao mínimo.
- Tenta tornar o código mais legível.

Sem pressa.

Muda uma coisa de cada vez e verifica se a tua solução continua a passar nos testes.

Diverte-te!
