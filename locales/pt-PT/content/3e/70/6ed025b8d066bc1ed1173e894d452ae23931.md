# Introdução

Existem dois mecanismos principais para formatar strings em C#/.NET. O uso de `String.Format()` e a interpolação de strings.

## Formatação composta

`String.Format()` recebe uma string (designada na documentação por _formato composto_) composta por texto fixo e marcadores de posição (conhecidos na documentação por itens de formato), e um número variável de argumentos. O valor devolvido resolve cada item de formato com o argumento correspondente e combina os valores resolvidos com o texto fixo.

```csharp
string.Format("I had {0} bitcoins on {1}, the day I forgot my password.", 55.5, new DateTime(2010, 2, 25));
// => "I had 55.5 bitcoins on 2/25/2010 00:00:00, the day I forgot my password." - US settings
```

Este mecanismo é tecnicamente conhecido como _formatação composta_.

## Interpolação de strings

As strings interpoladas são prefixadas com um `$` e incluem expressões de tempo de execução entre chavetas. O item de formato tem a seguinte sintaxe: `$"{<interpolationExpression>}"`. Eliminam a necessidade de uma lista separada de argumentos. O resultado é funcionalmente equivalente ao mecanismo `String.Format()`.

```csharp
var loadsOf = 55.5;
var thatDay = new DateTime(2010, 2, 25);
$"I had {loadsOf} bitcoins on {thatDay}, the day I forgot my password."
// => "I had 55.5 bitcoins on 2/25/2010 00:00:00, the day I forgot my password." - US settings
```

## Itens de formato

O texto entre chavetas, os marcadores de posição no caso do formato composto e as expressões interpoladas no caso da interpolação de strings são designados por _item de formato_.

Um item de formato pode ser composto por até 3 partes. A primeira é a expressão ou o marcador de posição de argumento obrigatório, como se vê no código de exemplo acima. Além disso, existe um alinhamento opcional (introduzido por uma vírgula, ",") e uma _string de formato_ opcional (introduzida por dois pontos, ":").

`{<interpolationExpression>[,<alignment>][:<formatString>]}`

O _alinhamento_ especifica o comprimento do "campo" onde o texto é colocado, preenchido à esquerda com espaços se o alinhamento for positivo ou à direita se for negativo.

A _string de formato_ especifica a forma do texto de saída, como por exemplo se devem ser incluídos separadores de milhares para um número ou se deve ser apresentada apenas a parte da data de um objeto `DateTime`.

O código seguinte ilustra a apresentação da parte da data de um objeto `DateTime` e de um número de vírgula flutuante na forma exponencial.

```csharp
var loadsOf = 55.5;
var thatDay = new DateTime(2010, 2, 25);
$"I had {loadsOf:E} bitcoins on {thatDay:d}, the day I forgot my password."
// => I had 5.550000E+001 bitcoins on 02/25/2010, the day I forgot my password. - US settings

string.Format(
    "I had {0:E} bitcoins on {1:d}, the day I forgot my password.",
    loadsOf, thatDay)
// => I had 5.550000E+001 bitcoins on 02/25/2010, the day I forgot my password. - US settings
```

Existem formatações padrão e personalizadas tanto para números como para datas. Não há uma diferença vital entre _personalizada_ e _padrão_, exceto que tens a oportunidade de compor strings de formato personalizadas a partir de letras de formato.

## Cultura

Cada thread tem uma cultura predefinida `Thread.CurrentThread.CurrentCulture` encapsulada numa instância de `CultureInfo`. A cultura do thread determina como as datas e os números são formatados em relação a variações regionais, como a diferença no formato de data convencional entre o Reino Unido _DD/MM/YYYY_ e os EUA _MM/DD/YYYY_.

`CultureInfo` implementa a interface `IFormatProvider`, que pode ser passada a certas sobrecargas de `String.Format()`. Isto pode ser usado para substituir a cultura do thread.
