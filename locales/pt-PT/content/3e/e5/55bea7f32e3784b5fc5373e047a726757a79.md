# Instruções

Tens várias lojas de fatias de pizza na tua terra e queres criar uma aplicação web que te permita comparar duas configurações de pizza diferentes para saberes quem te dá a fatia maior.

## 1. Escreve uma função que calcule o tamanho das fatias e que devolva nil para valores de entrada inválidos.

Implementa a função `sliceSize(diameter: Double?, slices: Int?) -> Double?` que, dado o diâmetro de uma pizza e o número de fatias por pizza, devolve a área de uma fatia.
Para diâmetros negativos e para um número de fatias inferior a 1, devolve `nil`, pois não existe uma pizza com diâmetro negativo nem forma de dividir uma pizza em menos de 1 fatia.
Se algum dos parâmetros for `nil`, devolve também `nil`

```swift
sliceSize(diameter: 16, slices: 12)
// Returns 16.75516081914556
sliceSize(diameter: nil, slices: 8)
// Returns nil
```

## 2. Processa os dados da tua aplicação web para determinar a fatia maior.

A tua aplicação web vai passar quatro strings à tua função, `biggestSlice(diameterA: String, slicesA: String, diameterB: String, slicesB: String) -> String`.
A primeira e a segunda strings são o diâmetro e o número de fatias da primeira pizza, respetivamente, e a terceira e a quarta são o diâmetro e o número de fatias da segunda pizza, respetivamente.

Implementa `biggestSlice` de modo a que tente converter o diâmetro e o número de fatias de cada pizza num `Double` e num `Int`, respetivamente.
Se for possível obter ambos os valores a partir das strings, usa a tua primeira função para tentar calcular a área; caso contrário, a área dessa fatia é `nil`.
Assim que tenhas as áreas das duas fatias, compara-as usando as seguintes regras:

1. Se a área da fatia A for um `Double` e a da fatia B for `nil`, devolve "Slice A is bigger". Se for ao contrário, devolve "Slice B is bigger".
2. Se ambas as áreas forem `Double`s, devolve "Slice A is bigger" ou "Slice B is bigger", conforme a fatia que tiver a área maior.
3. Se ambas as áreas forem `nil`, ou se ambas forem `Double`s e forem iguais, devolve "Neither slice is bigger".

~~~~exercism/note
Mesmo que os valores de entrada resultem numa área de fatia igual a 0, a fatia continua a ser considerada válida e deve ser vista como maior do que uma fatia com uma área `nil`.
~~~~

```swift
biggestSlice(diameterA: "10", slicesA: "6", diameterB: "14", slicesB: "12")
// Returns "Slice A is bigger"
biggestSlice(diameterA: "10", slicesA: "6", diameterB: "12", slicesB: "8")
// Returns "Slice B is bigger"
biggestSlice(diameterA: "Pepperoni", slicesA: "6", diameterB: "Sausage", slicesB: "12")
// Returns "Neither slice is bigger"
```
