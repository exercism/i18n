# Introdução

Uma **word** é o nome que o Factor dá a uma função. Partindo da pilha de dados de `basics`, este conceito é sobre como definir as tuas próprias words: fazer aritmética, dar nome a valores fixos e compor words a partir de outras words.

Uma definição começa com `:`, indica um efeito de pilha, depois o corpo e, por fim, `;`. O compilador verifica se o corpo corresponde ao efeito declarado:

```factor
: square ( x -- x*x ) dup * ;

4 square .    ! => 16
```

As words de aritmética de inteiros `+`, `-` e `*` retiram dois números da pilha e empilham o resultado. Vivem no vocabulário `math`, por isso um ficheiro que as use precisa de `math` na sua linha `USING:`. O topo da pilha é o operando da direita:

```factor
2 3 + .    ! => 5
8 3 - .    ! => 5    (8 - 3, not 3 - 8)
2 3 * .    ! => 6
```

O `CONSTANT:` dá nome a um valor fixo. Uma constante é, ela própria, uma word. Ao chamá-la, empilhas o valor:

```factor
CONSTANT: pi 3

pi pi * .    ! => 9
```

O corpo de uma word pode chamar qualquer word que já esteja no âmbito, incluindo as que definiste antes no mesmo ficheiro:

```factor
: double    ( x -- 2x ) 2 * ;
: quadruple ( x -- 4x ) double double ;

5 quadruple .    ! => 20
```

Um `?` no fim das saídas é a convenção para «um Boolean», e tanto as words como as constantes usam `lowercase-kebab-case`.
