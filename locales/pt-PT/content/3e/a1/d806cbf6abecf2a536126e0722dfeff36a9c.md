# Introdução

Uma `string` em C# é um objeto que representa texto imutável como uma sequência de carateres Unicode (letras, algarismos, pontuação, etc.). Usam-se aspas duplas para definir uma instância de `string`:

```csharp
string fruit = "Apple";
```

As strings manipulam-se chamando os seus métodos. Depois de uma string ser construída, o seu valor nunca pode mudar. Qualquer método que pareça modificar uma string devolve, na verdade, uma nova string.

É possível concatenar (somar) várias strings entre si. A forma mais simples de o fazer é usar o operador `+`.

```csharp
string name = "Jane";
"Hello " + name + "!";
// => "Hello Jane!"
```

Para qualquer formatação de strings mais complexa do que a simples concatenação, é preferível usar a interpolação de strings. Para usar a interpolação numa string, coloca o símbolo de dólar (`$`) no início da string. Depois, podes usar chavetas (`{}`) para aceder às variáveis dentro da tua string.

```csharp
string name = "Jane";
$"Hello {name}!";
// => "Hello Jane!"
```
