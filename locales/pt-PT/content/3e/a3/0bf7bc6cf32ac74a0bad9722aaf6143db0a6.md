# Introdução aos arrays

O Bash disponibiliza dois tipos de parâmetros: valores "escalares" e arrays.
Um valor escalar pode ser uma string ou um número; representa uma única "coisa".

Na maioria das vezes, os valores escalares são suficientes para guardar os teus dados.
Mas às vezes precisas de guardar uma lista de valores escalares.
Neste caso, vais usar um _array_.

Existem dois tipos de arrays:

* Os arrays com índices numéricos associam uma chave inteira a um valor do tipo string.
  (Noutras linguagens, isto pode chamar-se "lista" ou "sequência".)
* Os arrays associativos associam uma chave do tipo string a um valor do tipo string.
  (Noutras linguagens, isto pode chamar-se "mapa" ou "dicionário".)

As primeiras secções deste documento abordam os arrays com índices numéricos (daqui em diante, simplesmente "arrays").
Os detalhes sobre os arrays associativos aparecem no final.

~~~~exercism/caution
Os arrays do Bash _só_ conseguem guardar valores escalares.
Não é possível criar um array bidimensional (array de arrays).
~~~~

## Declarar e inicializar uma variável do tipo array

Podes inicializar um array atribuindo uma lista de elementos entre parênteses (possivelmente vazia) a uma variável.

```bash
myarray=("one" "two" "three")
```

Tal como acontece em qualquer atribuição de variável, não pode haver espaços à volta do sinal de igual.

Repara que não há vírgulas a separar os elementos; é uma lista de strings separada por espaços.

Na verdade, a quantidade de espaços dentro dos parênteses é completamente arbitrária.
Podes usar mudanças de linha; usa tantas quantas quiseres para melhorar a legibilidade.

```bash
myarray=(
    "first element"
    "second element"
    "this is the last element"
)
```

Atribuir uma lista de strings a uma variável do tipo array desta forma guarda a primeira string no índice zero, a seguinte no índice um, a próxima no índice dois, e assim por diante.

É possível inicializar um "array esparso" especificando os índices de que precisas.

```bash
raindrops=([3]="Pling" [5]="Plang [7]="Plong")
```

~~~~exercism/note
Para reforçar: os índices dos arrays começam em zero.
Este excerto imprime "true":

```bash
myarray=("one" "two" "three")
[[ "${myarray[0]}" == "one" ]] && echo true || echo false
```
~~~~

Podes usar o comando `declare` (ou `local` dentro de uma função) para indicar que uma variável vai conter um array.

```bash
declare -a myarray
```

É mais idiomático limitar-te a atribuir uma lista entre parênteses (eventualmente vazia) para inicializar a variável.

## Aceder aos elementos de um array

Como viste na nota acima, a sintaxe para aceder a um elemento de um array é `${myarray[$index]}`.
O índice é indicado entre parênteses retos.
As chavetas são obrigatórias.

~~~~exercism/note
Nos arrays com índices numéricos, o índice é uma expressão aritmética.
O manual do Bash [indica][arithmetic]:

> Numa expressão aritmética, as variáveis da shell também podem ser referenciadas pelo nome sem usar a sintaxe de expansão de parâmetros.

Isto significa que o `$` não é obrigatório para uma expansão de variável "simples".
Podes aceder aos elementos assim, o que é um pouco mais fácil de ler:

```bash
i=5
echo "${myarray[i]}"
# ..............^
```

[arithmetic]: https://www.gnu.org/software/bash/manual/bash.html#Shell-Arithmetic
~~~~

Se o índice indicado não existir no array, o resultado da expansão é uma string vazia.

## Atribuir valores a um array

Para atribuir um valor a uma entrada específica do array, usa esta sintaxe:

```bash
myarray[10]="hello"
```

Para _acrescentar_ a um array, usa o operador de atribuição com concatenação `+=` e usa parênteses:

```bash
myarray+=("new element 1" "new element 2")
```

## Iterar sobre um array

Normalmente vais precisar de iterar sobre os _valores_ de um array.
Usa um ciclo for (que viste no conceito [Ciclos][looping]):

```bash
myarray=("one" "two" "three")
for value in "${myarray[@]}"; do
    echo "$value"
done
```

Repara na sintaxe especial para expandir o array: `"${myarray[@]}"`.
Esta forma de expansão de parâmetros substitui os valores do array como palavras separadas.
É mais ou menos equivalente a:

```bash
for value in "${myarray[0]}" "${myarray[1]}" ... "${myarray[n]}"
```

A forma `"${myarray[@]}"` funciona com arrays esparsos, expandindo apenas os valores definidos.

Esta expansão especial, em que o índice é um arroba (`@`), só é especial dentro de aspas duplas.

#### Outras expansões especiais de parâmetros

Aqui ficam mais duas sintaxes especiais de que precisamos para iterar sobre um array.
Estão descritas no manual em [Shell Parameter Expansion][man-expn].

Para saber o _comprimento_ de um array, usa `${#myarray[@]}`, com um `#` antes do nome.
O "comprimento" de um array é o número de elementos que contém.

Para extrair a lista de _índices_ de um array, usa `"${!myarray[@]}"`, com um `!` antes do nome e a expansão entre aspas duplas.
Nos arrays com índices numéricos, os índices são expandidos por ordem numérica.

### Iterar sobre os índices de um array

Às vezes precisas do índice e também do valor.
Há duas formas de o fazer.

1. Quando sabes que os índices formam uma sequência ininterrupta, podes usar um ciclo for _aritmético_.

   ```bash
   for ((i = 0; i < ${#myarray[@]}; i++)); do
       echo "$i -> ${myarray[i]}"
   done
   ```

   Repara na sintaxe `${#myarray[@]}`, com o caráter `#` à frente do nome do array.
   Como os arrays usam índices a começar em zero, o último índice do array é um a menos que o comprimento do array.

2. Quando o array é esparso, podes usar esta forma:

   ```bash
   for index in "${!raindrops[@]}"; do
       echo "$index -> ${raindrops[index]}"
   done
   ```

   Repara na sintaxe `${!myarray[@]}`, com o caráter `!` à frente do nome do array.

## Inspecionar um array

Se quiseres ver o conteúdo de um array, usa o comando `declare` com a opção `-p`:

```bash
a=("the 'first' element"
   second
   third
   'the "last" element')
declare -p a
```

Isto imprime o conteúdo com a formatação canónica de aspas da shell.

```bash
declare -a a=([0]="the 'first' element" [1]="second" [2]="third" [3]="the \"last\" element")
```

## Arrays associativos

Para reforçar, os arrays associativos usam strings como índices, não números.
Tudo o que foi escrito acima se aplica aos arrays associativos, mas com pequenas diferenças.
Em geral, usamos o termo "chave" e não "índice": os arrays associativos associam chaves a valores.

### Declarar um array associativo

Ao contrário dos arrays, os arrays associativos **têm** de ser declarados.
Usa a opção `-A` do `declare` (ou `local` dentro de uma função):

```bash
declare -A mymap

myfunc() {
    local -A my_local_map
    # ...
}
```

### Inicializar um array associativo

Os pares chave-valor são indicados dentro da lista entre parênteses:

```bash
mymap=([first]=foo [second]=bar [third]=baz)
declare -p mymap
```

Isto imprime:

```
declare -A mymap=([second]="bar" [first]="foo" [third]="baz")
```

~~~~exercism/note
Tem em atenção que os arrays associativos **não têm ordem**.
~~~~

A declaração e a inicialização podem acontecer numa só linha.

```bash
declare -A mymap=([first]=foo [second]=bar [third]=baz)
```

Nas versões mais recentes do Bash, a inicialização pode usar uma lista `(key value key value ...)`.

```bash
declare -A mymap=(first foo second bar third baz)
```

### Aceder aos valores

Usa-se a mesma sintaxe de antes para aceder aos elementos: `${mymap[$key]}`.

As chaves dos arrays associativos não são avaliadas num contexto aritmético.
É precisa a sintaxe habitual de expansão de parâmetros.

### Atribuir valores a um array associativo

A atribuição usa a mesma sintaxe de antes:

```bash
mymap[$key]="$value"
```

### Iterar

Podes usar um ciclo `for value in "${mymap[@]}"` para iterar.
No entanto, normalmente também queres a chave junto do valor.

Usa a sintaxe `"${!mymap[@]}"` que vimos acima.

```bash
for key in "${!mymap[@]}"; do
    echo "$key -> ${mymap[$key]}"
done
```

Isto imprime

```
second -> bar
first -> foo
third -> baz
```

Para reforçar, as chaves não têm ordem.
