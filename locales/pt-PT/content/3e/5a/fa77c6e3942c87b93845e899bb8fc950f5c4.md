# Instruções

Converte um número hexadecimal, representado como uma string (por exemplo, "10af8c"), no seu equivalente decimal recorrendo apenas aos princípios básicos (ou seja, não, não podes usar bibliotecas internas ou externas para fazer a conversão).

Na web, usamos hexadecimal para representar cores, por exemplo, verde: 008000,
azul-petróleo: 008080, azul-marinho: 000080).

O programa deve lidar com strings hexadecimais inválidas.
