# Instruções

Neste exercício vais trabalhar num agendador de marcações para um salão de beleza.

Tens três tarefas, todas elas relacionadas com datas de marcações.

## 1. Verifica se uma marcação já passou

Implementa a sub-rotina `appointment_has_passed`, que recebe uma string de data e verifica se a marcação já ficou no passado:

```perl
appointment_has_passed("2019-07-25T13:45:00")
// => true
```

As strings de data são passadas no formato de data e hora ISO 8601: `YYYY-mm-ddTHH:MM:SS`

Vais precisar de implementar a sub-rotina privada `_parse_datetime`.
Sugerimos-te um par de módulos:

- [Time::Piece][time-piece] é um módulo do núcleo do Perl.
- [DateTime::Tiny][datetime-tiny] está disponível no CPAN.

## 2. Verifica se a marcação é à tarde

Implementa a função `is_afternoon_appointment`, que recebe uma string de data e verifica se a marcação é à tarde (>= 12:00 e < 18:00):

```perl
is_afternoon_appointment("2019-07-25T13:45:00")
// => true
```

## 3. Descreve a hora e a data da marcação

Implementa a função `describe_appointment`, que recebe uma string de data e devolve uma descrição dessa data e dessa hora:

```perl
describe_appointment("2019-07-25T13:45:00")
// => "You have an appointment on 07/25/2019 1:45 PM"
```

Repara que a hora está no intervalo 0-12 e não tem zero à esquerda nem espaço.

[time-piece]: https://perldoc.perl.org/Time::Piece
[datetime-tiny]: https://metacpan.org/pod/DateTime::Tiny
