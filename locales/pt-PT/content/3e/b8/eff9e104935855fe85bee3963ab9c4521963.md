# Dicas

## Geral

- Neste exercício, todos os endereços de memória estão alinhados a 16 bytes, por isso as instruções de movimento alinhadas (`movdqa` para inteiros, `movaps` para números de vírgula flutuante) são adequadas.
  Um endereço alinhado também pode ser usado diretamente como operando de origem na memória.

## 1. Converter uma imagem para a ordem de visualização

- Dentro de cada pixel de 4 bytes, a conversão troca o byte no deslocamento `0` (vermelho) com o byte no deslocamento `2` (azul), e deixa os deslocamentos `1` (verde) e `3` (alfa) no mesmo lugar.
  O mesmo padrão repete-se nos quatro pixels.
- Podes usar uma instrução [shuffle][pshufb] para reordenar os bytes no local, de acordo com os índices de um vetor de controlo.
- O vetor de controlo pode ser definido na memória.
- Pode haver mais do que um bloco, e cada bloco tem 16 bytes.

## 2. Preencher uma região com uma cor

- A cor é um único pixel de 4 bytes.
  Para a guardar 16 bytes de cada vez, tens primeiro de a [espalhar][pshufd] pelas quatro vias de um registo `xmm`.
- Um pixel de 4 bytes tem primeiro de ser [movido][pinsrd] para um registo `xmm` antes de ser espalhado.
- Todos os blocos preenchidos são idênticos, por isso o registo preenchido pode ser criado uma só vez e depois reutilizado.
- Pode haver mais do que um bloco, e cada bloco tem 16 bytes.

## 3. Entrelaçar duas linhas de varrimento

- Podes usar instruções [unpack][unpack] para intercalar os bytes de dois operandos.
- Ambas as instruções unpack vão buscar o primeiro byte de cada par ao operando de destino, e o segundo ao operando de origem.

## 4. Empacotar uma linha com o brilho aumentado

- Podes usar instruções [pack][pack] para estreitar as vias e, ao mesmo tempo, limitar os seus valores.
- As instruções pack vão buscar as vias baixas ao operando de destino, e as vias altas ao operando de origem.

## 5. Separar as coordenadas em x e y

- Podes usar [shuffles de vírgula flutuante][shufps] para selecionar e reordenar as vias de dois operandos.
- As coordenadas `x` ficam nas vias pares (`0` e `2`) de cada operando de entrada, e as coordenadas `y` nas vias ímpares (`1` e `3`).
