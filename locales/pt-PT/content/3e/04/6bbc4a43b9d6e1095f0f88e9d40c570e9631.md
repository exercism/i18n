# Instruções

A Elyse, futura maga, continua o seu treino. Vão ser-lhe dadas várias pilhas de cartas com que precisa de fazer os seus truques.
Para tornar as coisas um pouco mais fáceis, só usa as cartas de 1 a 10.

Neste exercício, usa métodos incorporados para analisar o conteúdo de um array.

## 1. Encontra a posição de uma carta

A Elyse quer saber a posição (o índice) de uma carta na pilha.

```javascript
const card = 2;
getCardPosition([9, 7, 3, 2], card);
// => 3
```

## 2. Determina se uma carta está presente

A Elyse quer determinar se uma carta está presente na pilha, ou seja, se a pilha contém um `number` específico.

```javascript
const card = 3;
doesStackIncludeCard([2, 3, 4, 5], card);
// => true
```

## 3. Determina se cada carta é par

A Elyse quer saber se todas as cartas são pares, ou seja, se cada número na pilha é um `number` par.

```javascript
isEachCardEven([2, 4, 6, 7]);
// => false
```

## 4. Verifica se a pilha contém uma carta ímpar

A Elyse quer saber se há um número ímpar na pilha.

```javascript
doesStackIncludeOddCard([3, 2, 6, 4, 8]);
// => true
```

## 5. Obtém a primeira carta ímpar da pilha

A Elyse quer saber o valor da primeira carta ímpar.

```javascript
getFirstOddCard([4, 2, 8, 7, 9]);
// => 7
```

## 6. Determina a posição da primeira carta par

A Elyse quer saber a posição da primeira carta par.

```javascript
getFirstEvenCardPosition([5, 2, 3, 1]);
// => 1
```
