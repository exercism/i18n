# Dicas

## Geral

- Lê sobre o [comportamento `Access`][access-behaviour] na documentação.

## 1. Extrai dados de uma estrutura de mapas aninhados

- Começa por dividir o caminho em tokens, para o poderes usar. Podes recorrer às [funções do módulo `String`][string-module].
- Escreve uma função recursiva que percorra a estrutura de mapas aninhados para obteres o valor ou devolveres `nil`.

## 2. Refatoriza com as funções incluídas

- Dá uma vista de olhos às várias [funções do módulo `Kernel`][kernel-module], para encontrares uma que possa encurtar ou simplificar a tua abordagem.

[kernel-module]: https://hexdocs.pm/elixir/Kernel.html#functions
[string-module]: https://hexdocs.pm/elixir/String.html#functions
[access-behaviour]: https://hexdocs.pm/elixir/Access.html
