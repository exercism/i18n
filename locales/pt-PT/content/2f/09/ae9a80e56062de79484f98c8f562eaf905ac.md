# Acerca de

A principal construção orientada a objetos em C# é a _classe_, que combina dados ([_campos_][fields]) e comportamento ([_métodos_][methods]). Os campos e os métodos de uma classe são conhecidos como os seus _membros_.

O acesso aos membros pode ser restringido através de modificadores de acesso, sendo os dois mais comuns:

- [`public`][public]: o membro pode ser acedido por qualquer código (sem restrições).
- [`private`][private]: o membro só pode ser acedido por código da mesma classe.

É habitual especificar um modificador de acesso para todos os membros. Se não for especificado nenhum modificador de acesso, o valor predefinido é `private`.

Esta agregação de dados e comportamento relacionados, a par da restrição do acesso aos membros, é conhecida como [encapsulamento][encapsulation], um dos conceitos centrais da orientação a objetos.

A combinação dos valores dos campos de um objeto num determinado momento é conhecida como o [estado][object-state] do objeto.

Podes pensar numa classe como um modelo para criar instâncias dessa classe. Para [criar uma instância de uma classe][creating-objects] (também conhecida como _objeto_), usa-se a [palavra-chave `new`][new]:

```csharp
class Car
{
}

// Create two car instances
var myCar = new Car();
var yourCar = new Car();
```

Os [campos][fields] têm um tipo e podem ser definidos em qualquer parte de uma classe.
Os campos públicos são definidos em [PascalCase][pascal-case] e os campos privados em [camelCase][camel-case], com o prefixo `_`:

```csharp
class Car
{
    // Accessible by anyone
    public int Weight;

    // Only accessible by code in this class
    private string _color;
}
```

Podes, opcionalmente, atribuir um valor inicial a um campo. Se um campo _não_ especificar um valor inicial, é-lhe atribuído o [valor predefinido][default-values] do seu tipo. Os valores dos campos de uma instância podem ser acedidos e atualizados com a notação de ponto.

```csharp
class Car
{
    // Will be set to specified value
    public int Weight = 2500;

    // Will be set to default value (0)
    public int Year;
}

var newCar = new Car();
newCar.Weight; // => 2500
newCar.Year;   // => 0

// Update value of the field
newCar.Year = 2018;
```

Os campos privados são normalmente atualizados como efeito secundário da chamada de um método. Estes métodos normalmente não devolvem nenhum valor e, nesse caso, o tipo devolvido deve ser [`void`][void]:

```csharp
class CarImporter
{
    private int _carsImported;

    public void ImportCars(int numberOfCars)
    {
        // Update private field
        _carsImported = _carsImported + numberOfCars;
    }
}
```

Repara que não é habitual usar campos públicos em classes de C#. Ou se usam campos privados, ou outros tipos de membros que serão abordados nos exercícios seguintes.

Dentro de uma classe, a [palavra-chave `this`][this] refere-se à própria classe. Isto é especialmente útil se um parâmetro tiver o mesmo nome que um campo:

```csharp
class CarImporter
{
    private int carsImported;

    public void SetImportedCars(int carsImported)
    {
        // Update private field from public method
        this.carsImported = carsImported;
    }
}
```

A estrutura de classes e métodos proporciona uma forma natural de limitar a visibilidade de elementos do programa, como campos e métodos, e de evitar o conhecido [problema do estado global][so-global-state-problem]. Os campos, métodos e outros membros públicos têm de ser qualificados com o nome do objeto, `object.field` ou `object.method()` (o nome da classe, no caso dos membros estáticos), para serem vistos por código fora da classe. As variáveis e os parâmetros declarados dentro de um método só são visíveis dentro desse método.

Um cuidado a ter com esta abordagem é que, se o nome de um campo for igual ao nome de uma variável ou de um parâmetro de um método, o código dentro desse método ignora o campo, o que pode não ser o que pretendes. De um modo geral, deves evitá-lo sempre que possível, embora seja um padrão comum nos construtores. Se fizer sentido que o campo e a variável tenham o mesmo nome, qualifica o nome do campo com a palavra-chave `this` dentro do método.

Estes [modificadores de acesso][access-modifiers] podem ser usados para limitar ainda mais a visibilidade.
