# Instruções adicionais

## Formato do tabuleiro

O tabuleiro é representado por uma string terminada em nulo, com um caráter de nova linha no final de cada linha.

Um exemplo seria `"X  \n XO\nOX \n"`

## Registos

| Registo  | Utilização     | Tipo    | Descrição                                                               |
| -------- | -------------- | ------- | ----------------------------------------------------------------------- |
| `$a0`    | valor de entrada | endereço | string de entrada terminada em nulo                                    |
| `$v0`    | valor de saída  | inteiro | estado do jogo (`1` = `ongoing`, `2` = `draw`, `3` = `win`, `-1` = `error`) |
| `$t0-9`  | temporário     | qualquer | para armazenamento temporário                                          |
