# Introdução

## Strings

Uma `string` em C# é um objeto que representa texto imutável como uma sequência de carateres Unicode (letras, algarismos, pontuação, etc.). As aspas duplas servem para definir uma instância de `string`:

```csharp
string fruit = "Apple";
```

### Métodos

As strings são manipuladas através dos [métodos incorporados][docs-string-methods] da string.
Por exemplo, para remover os espaços em branco de uma string, podes usar o [método Trim][tutorial-docs.microsoft.com-trim-white-space] assim:

```csharp
string name = " Jane "
name.Trim()
// => "Jane"
```

Uma vez construída, uma string nunca pode mudar de valor.
Quaisquer métodos que pareçam modificar uma string devolvem, na verdade, uma nova string.

### Concatenação

É possível concatenar (somar) várias strings umas com as outras. A forma mais simples de o fazer é usar o operador `+`.

```csharp
string name = "Jane";
"Hello " + name + "!";
// => "Hello Jane!"
```

### Formatação

Para qualquer formatação de strings mais complexa do que uma simples concatenação, dá-se preferência à interpolação de strings. Para usar interpolação numa string, coloca o símbolo de dólar (`$`) antes dela. Depois, podes usar chavetas (`{}`) para aceder a quaisquer variáveis dentro da tua string.

```csharp
string name = "Jane";
$"Hello {name}!";
// => "Hello Jane!"
```
