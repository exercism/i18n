# Executores de testes

Um executor de testes é um programa que corre os testes de um exercício contra o código de um aluno.

Os executores de testes dão-nos duas vantagens:

1. Permitem programar no navegador, onde o aluno pode iterar numa solução e ver se os testes passam ou falham.
2. Permitem-nos fornecer aos mentores informação sobre se o código do aluno "funciona" ou não.

## Contribuir para os executores de testes

Cada linguagem tem o seu próprio executor de testes, escrito nessa linguagem.
O site funciona como orquestrador entre os executores de testes e as submissões dos alunos.

Cada executor de testes vive na organização GitHub do Exercism, num repositório chamado `<track_slug>-test-runner` (por exemplo, [`exercism/ruby-test-runner`](https://github.com/exercism/ruby-test-runner)).
Podes consultar os executores de testes existentes [aqui](https://github.com/search?q=topic%3Aexercism-test-runner&type=repositories).

Se quiseres ajudar num executor de testes existente, abre uma issue no respetivo repositório a perguntar se há alguma coisa em que possas ajudar.
Se quiseres criar um executor de testes para uma linguagem que ainda não tem nenhum, segue as instruções para [criar um executor de testes](/docs/building/tooling/test-runners/creating-from-scratch).
