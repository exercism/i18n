# Instalação

## Instalar o tclsh

A única ferramenta de que precisas é o intérprete TCL, o `tclsh`.

No Windows, o melhor sítio para obter o Tcl é [o instalador do Tcl da Magicsplat][magicsplat].

No MacOS e em sistemas operativos do tipo Unix, o `tclsh` já vem instalado.
Normalmente, a versão instalada será a 8.6.*algo*.
Para instalares a versão estável atual, a 9.0:
 - no MacOS, usa o [Homebrew][brew].
 - no Linux, verifica o teu gestor de pacotes.
 - ou [descarrega o código-fonte][download] e [compila-o][build].

Para resolveres exercícios através da interface web do Exercism, o test runner (em fevereiro de 2023) usa a versão 8.7a4 do Tcl.

## Usar a shell interativa do tclsh

É comum abrires uma sessão interativa do [`tclsh`][tclsh] para testar comandos enquanto escreves código.
No entanto, o tclsh oferece apenas um intérprete REPL muito básico, sem edição de linha de comandos nem histórico de comandos.
Para uma experiência melhor, existe um programa chamado `rlwrap` que acrescenta a funcionalidade do readline:

```bash
rlwrap tclsh
```

Para instalares o rlwrap:
 - no MacOS, usa o [Homebrew][brew].
 - no Linux, verifica o teu gestor de pacotes.
 - ou [descarrega o código-fonte][rlwrap-download] e [compila-o][rlwrap-build].

É tão prático que vais querer usá-lo sempre: acrescenta isto ao teu ~/.bashrc

```bash
command -v rlwrap && alias tclsh='rlwrap tclsh'
```

## Que versão usar?

A versão estável atual é a 9.0.
Como indicado acima, a versão 8.6 continua a ser amplamente utilizada.

Podes verificar que versão do `tclsh` tens instalada com o seguinte comando:

```bash
echo 'puts [info patchlevel]' | tclsh
```
