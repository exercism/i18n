# Instruções adicionais

## Registos

| Registo | Utilização | Tipo    | Descrição                                                          |
| -------- | --------- | ------- | ------------------------------------------------------ |
| `$a0`    | entrada   | endereço | string de entrada terminada em null                     |
| `$v0`    | saída     | boolean | validade da string de entrada (`0` = `false`, `1` = `true`) |
| `$t0-9`  | temporário | qualquer | usado para armazenamento temporário                     |
