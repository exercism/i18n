# Introdução

As listas de palavras-chave são uma estrutura de dados de chave-valor.

```elixir
[month: "April", year: 2018]
```

As listas de palavras-chave são listas de `{key, value}` [tuplos][exercism-tuples], e também podem ser escritas como tal, mas a sintaxe mais curta é mais utilizada.

```elixir
[month: "April"] == [{:month, "April"}]
# => true
```

As chaves numa lista de palavras-chave têm de ser [átomos][exercism-atoms], mas os valores podem ser qualquer coisa. Cada chave pode ser usada mais do que uma vez. Os pares de chave-valor numa lista de palavras-chave estão ordenados.

Podes trabalhar com listas de palavras-chave usando as mesmas abordagens que usas para listas, ou podes usar o módulo `Keyword`.

[exercism-tuples]: https://exercism.org/tracks/elixir/concepts/tuples
[exercism-atoms]: https://exercism.org/tracks/elixir/concepts/atoms
