# Sobre

- O Pony tem tipagem estática. Isto significa que *tens* de definir os tipos de dados dos teus programas com antecedência. Se disseres ao Pony que a variável `x` é um número inteiro, não podes atribuir-lhe uma string.
- O sistema de tipos do Pony é o que torna possíveis as garantias do Pony.
  - Se o teu programa compilar, não vai rebentar.
  - Nunca vai haver uma exceção não tratada.
  - Não existe `null`, por isso o teu programa nunca vai tentar desreferenciar `null`.
  - Nunca vai haver uma corrida de dados.
  - Nunca vai haver um bloqueio mútuo.
  - O teu código será sempre seguro em termos de capabilities (proteção contra ataques à cadeia de abastecimento).
- O Pony não te deixa converter tipos. Todas as mudanças de tipo têm de acontecer através de uma função que cria uma nova instância do novo tipo.
- O sistema de tipos do Pony é diferente do de quase todas as outras linguagens, por isso vamos abordá-lo em pequenos passos.

## Primitives

- Os primitives são a forma mais simples de organizar código no Pony.
  - Podes pensar neles como um contentor, ou espaço de nomes, para funções.
  - Não têm campos (para isso temos as classes).
  - São definidos com a palavra-chave `primitive`.

## Funções

- As funções são definidas com a palavra-chave `fun`.
  - As funções têm de estar dentro de um `primitive` (ou de uma `class` ou de um `actor`, mas isso fica para depois).
  - As funções podem ter argumentos à entrada e um valor devolvido. Têm de ser tipadas.
  - Se declarares o tipo que a função devolve, ela *tem* de devolver um valor desse tipo. O Pony não tem o conceito de Null.

```pony
primitive Greeter
  // A Function that takes a String, and returns a different String
  fun hello(name: String): String =>
    "Hello " + name + "!"
```

## Comentários

Podes usar comentários para deixar notas, lembretes, ou simplesmente para retirar temporariamente código do código-fonte. Como já viste acima, os comentários de uma linha usam `//`. Os comentários de várias linhas usam o estilo C: `/*` e `*/`.

## Variáveis

- As variáveis começam sempre por uma letra minúscula
  - Vamos declará-las com `var`. (O `let` e o `embed` ficam para depois.)
  - Se o Pony conseguir determinar o tipo da variável, determina-o por ti.
  - O tipo da variável é verificado em tempo de compilação e nunca pode mudar.
  - Quando estás a começar com o Pony, recomendamos que sejas explícito com o tipo.

```pony
var name: "Bob"
var bettername: String = "Bobby"
```
