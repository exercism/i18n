# Introdução

O Clojure usa o tipo subjacente `java.lang.Character`, que é uma quantidade de 16 bits usada para representar os componentes de texto mais pequenos que é possível endereçar.
Vários `char`s podem formar uma string como `"word"`, ou cada `char` pode ser processado de forma independente. Os seus literais escrevem-se assim: `\a \b \c`.

Os `char`s do Clojure suportam a codificação UTF-16 do Unicode. Por isso, além do conjunto de carateres latinos, é possível representar praticamente todos os sistemas de escrita usados no mundo, por exemplo a letra grega `'β'`.

Existem muitos métodos de biblioteca para inspecionar e manipular `char`s. Pode aceder-se a eles por interop, como métodos da classe `Character`. O Clojure inclui também uma biblioteca de utilitários de string integrada, `clojure.string`, que oferece muitas funções poderosas para trabalhar com carateres.
