# Instruções

Neste exercício vais escrever código para acompanhar uma lista de linguagens de programação que queres aprender no Exercism.
Tens seis tarefas, e todas elas implicam lidar com listas.

## 1. Cria uma nova lista

Para acompanhares as linguagens que queres aprender, vais precisar de criar uma nova lista.
Define a constante `newList`, que contém uma nova lista vazia.

```elm
newList
    --> []
```

## 2. Define uma lista existente

Neste momento, tens uma folha de papel com as linguagens que queres aprender: Elm, Clojure e Haskell.
Define a constante `existingList` para representar esta lista.

```elm
existingList
    --> [ "Elm", "Clojure", "Haskell" ]
```

## 3. Adiciona uma nova linguagem a uma lista

À medida que exploras o Exercism e encontras linguagens mais interessantes, vais querer adicioná-las à tua lista.
Implementa a função `addLanguage` para adicionar uma nova linguagem ao início da tua lista.

```elm
addLanguage "TypeScript" [ "JavaScript", "CoffeeScript" ]
    --> [ "TypeScript", "JavaScript", "CoffeeScript" ]
```

## 4. Conta as linguagens da lista

Contar as linguagens à mão é incómodo.
Implementa a função `countLanguages` para contar o número de linguagens da tua lista.

```elm
countLanguages [ "C#", "Racket", "Rust", "Ruby" ]
    --> 4
```

## 5. Inverte a lista

A certa altura, dás conta de que a tua lista está, na verdade, ordenada ao contrário!
Implementa a função `reverseList` para inverter a tua lista.

```elm
reverseList [ "Prolog", "C", "Idris", "Assembly" ]
    --> [ "Assembly", "Idris", "C", "Prolog" ]
```

## 6. Verifica se a lista é entusiasmante

Embora gostes de todas as linguagens, o Elm tem um lugar especial no teu coração.
Por isso, ficas mesmo entusiasmado com uma lista de linguagens se:

- O primeiro elemento da lista for o Elm.
- Ou o segundo elemento da lista for o Elm e a lista contiver três linguagens ou menos.

Implementa a função `excitingList` para verificar se uma lista de linguagens é entusiasmante:

```elm
excitingList [ "Nim", "Elm" ]
    --> True
```
