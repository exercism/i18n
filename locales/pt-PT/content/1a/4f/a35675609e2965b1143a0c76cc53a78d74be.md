# Introdução
## Switch

Uma [instrução switch][switch] permite-te comparar um valor com vários valores possíveis.
Permite-te escrever código mais conciso do que se usares várias condicionais `else-if`.
Uma instrução switch começa com a palavra-chave `switch`, seguida do valor a comparar.
Depois, podes definir os casos com a palavra-chave `case`, seguida do valor com que queres comparar.
A palavra-chave `default` serve para definir o caso por omissão, quando nenhum dos casos corresponde.
Tal como as condicionais `else-if`, as instruções `switch` só executam o bloco de código associado ao primeiro caso que corresponde.

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

Considera o seguinte exemplo:

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

Em vez disso, podíamos escrever:

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```

## Ciclos while

Um [ciclo while][while-loops] é uma instrução de controlo de fluxo que permite executar código enquanto uma determinada condição for verdadeira.
O Swift disponibiliza dois tipos de ciclos while: os ciclos while e os ciclos repeat-while.
A condição do ciclo while é avaliada antes de o corpo do ciclo ser executado; se a condição for falsa, o corpo do ciclo não chega a ser executado.
Os ciclos while em Swift têm a seguinte estrutura:

```swift
while <#condition#> {
  <#code#>
}
```

Aqui, o ciclo é executado enquanto o `count` for maior que 0 e imprime assim os números 2 e 1 e a palavra "Liftoff!".

```swift
var count = 2
while count > 0 {
  print("\(count)…")
  count -= 1
}
print("Liftoff!")

// prints:
// 2…
// 1…
// Liftoff!
```

Um [ciclo repeat-while][while-loops] é semelhante a um ciclo while, mas a condição é avaliada depois de o corpo do ciclo ser executado.
Isto significa que o corpo do ciclo é sempre executado pelo menos uma vez, mesmo que a condição seja falsa.
Os ciclos repeat-while em Swift têm a seguinte estrutura:

```swift
repeat {
  <#code#>
} while <#condition#>
```

Aqui, o ciclo só é executado uma vez, porque a condição é falsa.
Como é um ciclo repeat-while, o corpo do ciclo é executado uma vez antes de a condição ser avaliada.

```swift
var count = 2
repeat {
  print("\(count)…")
} while count < 0
print("Liftoff!")
```

## Transferência de controlo

O Swift tem um conjunto de instruções que permitem alterar o fluxo de controlo normal dos ciclos.
São conhecidas como instruções de transferência de controlo.
Já viste o `return`; este conceito vai apresentar outras, incluindo o `continue`, o `break` e os rótulos.
Não vamos abordar o `fallthrough` neste conceito, mas podes ler sobre ele no [livro do Swift][fallthrough].

### Continue

Por vezes, é necessário saltar antecipadamente para a iteração seguinte de um ciclo, sem completar o resto das instruções da iteração atual do ciclo.
Para isso, podes usar a palavra-chave `continue`.
Quando o `continue` é executado, o ciclo passa para a verificação seguinte, para ver se a iteração seguinte do ciclo pode ser executada, ou seja, o `while` nos ciclos while e repeat-while ou a verificação de se há mais um elemento na sequência, nos ciclos for-in.

```swift
count = 1
while count < 6 {
  count += 1
  if count == 4 { continue }
  print(count)
}

// prints:
// 2
// 3
// 5
```

### Break

O break serve para sair de um ciclo mais cedo.
Quando o `break` é executado, o ciclo termina de imediato e o programa continua com a primeira instrução depois do ciclo.

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  if !fruit.count.isMultiple(of: 2) { break }
  print(fruit)
}

// prints:
// banana
// grapes
```

### Rótulos

Quando os ciclos estão aninhados, há alturas em que podemos querer usar `break` ou `continue` para sair ou reiniciar os ciclos exteriores que contêm o ciclo em que o `break` ou o `continue` são usados.
Em casos como estes, podemos usar rótulos para indicar o ciclo que queremos terminar ou reiniciar.
Podemos dar um rótulo a um ciclo colocando um nome seguido de dois pontos antes do `while`, do `repeat` ou do `for` que inicia o ciclo.

Para veres o efeito de usar rótulos desta forma, repara no ciclo seguinte.

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  print("\n--- \(fruit) ---")
  for letter in fruit {
    guard letter != "n" else { break outerLoop }
    print(letter)
  }
}

// prints:
// --- banana ---
// b
// a
```
