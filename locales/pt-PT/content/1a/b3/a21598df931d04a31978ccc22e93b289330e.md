# Testes

  ## Resumo rápido

  1. Faz as tuas alterações no ficheiro `<myFileName>.u`
  2. Guarda o ficheiro `<myFileName>.u`
  3. Se o ficheiro passar na verificação de tipos, executa os comandos `add` ou `update` do UCM
    * Se o ficheiro não passar na verificação de tipos, altera o código no teu ficheiro `<myFileName>.u` até ele compilar. Lembra-te de fazer `update` às tuas funções depois das alterações!
  4. Executa o comando `load <myFileName>.test.u` na CLI do UCM para trazeres os testes para o âmbito e executá-los

  ## Passo a passo

  Se estás a trabalhar num problema do Exercism na linha de comandos, o mais provável é implementares a tua solução no diretório com o nome do exercício em questão. Por exemplo, se o exercício for o `hello-world`, deves abrir o `ucm` a partir da linha de comandos depois de teres feito `cd` para `~/exercism/unison/hello-world`. Faz as alterações da tua implementação no ficheiro `hello.u` e, quando estiveres satisfeito com a implementação, introduz o comando `add` ou `update` na Unison codebase manager CLI (UCM) para adicionares o teu trabalho do ficheiro à base de código.

  O ficheiro que contém os testes de cada exercício tem o sufixo `.test.u`. Vais querer usar o comando `load` do UCM para trazeres os testes para o âmbito e executá-los. O comando `load` recebe um caminho de ficheiro como argumento. Eis como isso pode parecer para o exercício hello world:

  ```
  .> load hello.test.u
  ```

  Deves ver uma mensagem do UCM sobre os termos que foram trazidos para o âmbito e, mais importante, o resultado da execução do teste:

  ```

    ⍟ These new definitions are ok to `add`:

      hello.test : Test.Test
      tests      : [Result]

  Now evaluating any watch expressions (lines starting with
  `>`)... Ctrl+C cancels.


    6 | test> tests = runAll [hello.test]

    🚫 FAILED
  ```

  Digamos que os teus testes não passaram à primeira. Volta a editar o teu ficheiro `myExercise.u` e, depois de guardares, podes fazer `update`

  ```
  I found and typechecked these definitions in ~/Exercism/unison/hello-world/hello.u. If you do an
  `add` or `update`, here's how your codebase would change:

    ⍟ These names already exist. You can `update` them to your new definition:

      hello : Text

  .> update

  ⍟ I've updated these names to your new definition:

    hello : Text
  ```

  A seguir, podemos voltar a carregar os testes para ver se algo mudou!

  ```
  .> load hello.test.u
    Now evaluating any watch expressions (lines starting with `>`)... Ctrl+C cancels.


    6 | test> tests = runAll [hello.test]

    ✅ Passed : Passed 1 tests.
  ```
