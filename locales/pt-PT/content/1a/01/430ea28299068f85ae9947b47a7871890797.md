# não compares valores do tipo Boolean com true ou false

Comparar valores do tipo Boolean com true ou false é redundante.
Usar `==` gera um valor do tipo Boolean, por isso não é necessário compará-lo com outro valor do tipo Boolean fixo no código.
Se quiseres inverter o valor do tipo Boolean, usa o operador `!`.

```crystal
# Rather than:
some_bool == true
some_bool == false

# Consider:
some_bool
!some_bool
```
