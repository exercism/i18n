# Dicas

## Geral

- `MACRO:` está em [`macros`][macros]. Os blocos de construção estão em `kernel` (`dup`, `curry`), `sequences` (`append`, `concat`, `<repetition>`, `map`) e `quotations` (`>quotation`).
- O corpo de uma macro tem de deixar **uma quotation** na pilha. Se o teu corpo produz um array de código, termina com `>quotation`.
- Para verificar o teu raciocínio, executa as palavras do corpo sobre um literal no listener e vê a quotation que recebes de volta: deve ser o código linear da linha "compila para" da tarefa.

## 1. Duas vezes

- Recebes `[ A ]` e queres `[ A A ]`. Faz uma cópia e junta-as: `dup append`.

## 2. N repetições

- Recebes `[ A ] n` e queres `n` cópias unidas.
- `<repetition>` constrói as cópias, mas o seu efeito é `( length elt -- repetition )`: a contagem tem de ficar no topo, por isso faz `swap` primeiro.
- Depois achata e converte: `swap <repetition> concat >quotation`.

  ```factor
  ! stack: [ 1 + ] 3
  swap <repetition>     ! 3 copies of [ 1 + ]
  concat >quotation     ! => [ 1 + 1 + 1 + ]
  ```

## 3. Compõe várias

- Já recebes o array de quotations; só precisas de o achatar numa única. `concat >quotation` é o corpo todo.

## 4. Iteração desenrolada

Recebes uma sequência e uma quotation, por exemplo `{ 10 20 30 } [ + ]`, e queres `[ 10 + 20 + 30 + ]`. Constrói isso em três passos.

**Um elemento.** Incorporar um elemento na quotation é exatamente o que `curry` faz:

```factor
10 [ + ] curry .   ! => [ 10 + ]
```

**Cada elemento.** Queres fazer `map` disso sobre a sequência, mas o `map` só passa um valor de entrada à quotation de mapeamento (o elemento), ao passo que também precisas de ter `[ + ]` à mão de cada vez. Por isso, incorpora primeiro `[ + ]` na quotation de mapeamento, outra vez com `curry`:

```factor
! stack: { 10 20 30 } [ + ]
[ curry ] curry    ! => { 10 20 30 } [ [ + ] curry ]
map                ! runs  10 [ + ] curry,  20 [ + ] curry, …
                   ! => { [ 10 + ] [ 20 + ] [ 30 + ] }
```

`[ curry ] curry` lê-se como "coloca a pequena quotation `[ curry ]` na pilha e incorpora depois `[ + ]` nela", o que dá `[ [ + ] curry ]`. Mapear isso sobre um elemento `e` executa `e [ + ] curry`, que é `[ e + ]`.

**Junta-as.** Termina da mesma maneira que as outras tarefas:

```factor
concat >quotation  ! => [ 10 + 20 + 30 + ]
```

- O corpo todo: `[ curry ] curry map concat >quotation`.
