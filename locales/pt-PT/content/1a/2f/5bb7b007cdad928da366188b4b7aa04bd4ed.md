# Introdução

O Factor tem dois valores Boolean: `t` (true) e `f` (false). Sempre que é preciso uma resposta de «sim/não», as palavras empilham um destes valores na pilha.

Os operadores Boolean vivem em [`kernel`][kernel]:

```
and ( a b -- ? )
or  ( a b -- ? )
not ( a -- ? )
```

```factor
t f and .   ! => f
t f or .    ! => t
f not .     ! => t
```

`f` é também o único valor *falso* do Factor. Todos os outros valores (strings vazias, zero, arrays vazios) são tratados como verdadeiros.

[kernel]: https://docs.factorcode.org/content/vocab-kernel.html
