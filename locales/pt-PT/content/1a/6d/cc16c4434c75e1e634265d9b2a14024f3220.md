# Introdução

O C# tem operadores integrados para as operações matemáticas habituais:

- `+`: adição
- `-`: subtração
- `/`: divisão
- `*`: multiplicação
- `%`: resto

Há também dois operadores especiais:

- `++`: incremento
- `--`: decremento

Estes operadores somam ou subtraem uma unidade a um valor.
