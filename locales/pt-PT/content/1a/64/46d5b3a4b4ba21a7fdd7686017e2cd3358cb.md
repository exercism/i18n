# Depuração

Para ajudar na depuração, podes tirar partido do facto de que toda a saída da consola será capturada e apresentada na janela de resultados dos testes.
Podes mostrar qualquer valor passando-o a `@show`.

`@show` mostra uma expressão e o seu resultado, ao mesmo tempo que devolve o resultado.

```julia
@show uppercase("hello") # HELLO will be shown as debug output
```

```julia-repl
julia> function f(a, b)
           @show a b
           return (@show a^b) / 1000
       end
f (generic function with 1 method)

julia> f(3, 5)
a = 3
b = 5
a ^ b = 243
0.243
```

Também podes usar [`println`](https://docs.julialang.org/en/v1/base/io-network/#Base.println) ou qualquer outro método que escreva a saída para [`stdout`](https://en.wikipedia.org/wiki/Standard_streams#Standard_output_(stdout)).
