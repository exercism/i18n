# Dicas

## Geral

- Um número de vírgula flutuante é devolvido em `xmm0`.
- Os primeiros 8 argumentos de vírgula flutuante são passados em `xmm0` a `xmm7`.

## 1. Calcula o valor diário a partir de um valor por hora

- Um número de vírgula flutuante é devolvido em `xmm0`.
- Os primeiros 8 argumentos de vírgula flutuante são passados em `xmm0` a `xmm7`.
- Um inteiro de 64 bits pode ser convertido num número de vírgula flutuante de precisão dupla usando `cvtsi2sd`.
- Um valor imediato (um número constante) tem de ser guardado num registo de uso geral antes de ser convertido num número de vírgula flutuante.
- Dois números de vírgula flutuante de precisão dupla podem ser multiplicados com `mulsd`.

## 2. Calcula um preço com desconto

- Um número de vírgula flutuante é devolvido em `xmm0`.
- Os primeiros 8 argumentos de vírgula flutuante são passados em `xmm0` a `xmm7`.
- Dois números de vírgula flutuante de precisão dupla podem ser divididos com `divsd`.
- Um número de vírgula flutuante de precisão dupla pode ser subtraído de outro com `subsd`.

## 3. Calcula o valor mensal a partir de um valor por hora e de um desconto

- Um número de vírgula flutuante é devolvido em `xmm0`.
- Os primeiros 8 argumentos de vírgula flutuante são passados em `xmm0` a `xmm7`.
- Podes usar `roundsd` para arredondar um número de vírgula flutuante de precisão dupla, usando um terceiro operando para indicar o modo de arredondamento.
- O número para arredondar para cima (teto) é `2`.
- Podes usar `cvtsd2si` para converter um número de vírgula flutuante de precisão dupla num inteiro de 64 bits.

## 4. Calcula o número de dias úteis a partir de um orçamento, de um valor por hora e de um desconto

- Um número de vírgula flutuante é devolvido em `xmm0`.
- Os primeiros 8 argumentos de vírgula flutuante são passados em `xmm0` a `xmm7`.
- Podes usar `roundsd` para arredondar um número de vírgula flutuante de precisão dupla, usando um terceiro operando para indicar o modo de arredondamento.
- O número para arredondar para baixo (chão) é `1`.
- Podes usar `cvtsd2si` para converter um número de vírgula flutuante de precisão dupla num inteiro de 32 bits.
