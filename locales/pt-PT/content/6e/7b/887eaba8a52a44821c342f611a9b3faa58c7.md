# Instruções

Implementa uma função que, dados dois pontos no plano de coordenadas 2D, produz um terceiro ponto de modo a que a ligação desses pontos resulte num triângulo equilátero. A função devolve dois pontos, porque há dois possíveis pontos "terceiros" que produzem um triângulo equilátero a partir dos dois pontos iniciais. Vale a pena notar que um triângulo equilátero é definido como uma forma de três lados em que todos os três lados têm o mesmo comprimento.

A função recebe dois tuplos de Python, cada um a especificar as coordenadas x e y de cada ponto, como números de vírgula flutuante. Por exemplo, (0.0, 0.0) e (1.0, 1.0) podem ser entradas.

A função deve devolver um tuplo composto por dois tuplos, cada um a especificar as coordenadas x e y de cada ponto, como números de vírgula flutuante. Por exemplo, ((0.0, 0.0), (1.0, 1.0)) pode ser um resultado possível.

A função deve lançar a exceção integrada do Python ArithmeticError se o solucionador Z3 produzir um resultado que não seja satisfatível. Também deve ser lançada uma exceção ArithmeticError se os dois pontos de entrada forem iguais.

A função não deve usar a função "set_option()" da biblioteca z3 para definir parâmetros globais. Isto é feito dentro dos casos de teste para garantir que os números de vírgula flutuante têm a precisão esperada (número de casas decimais).

Como a interpretação do modelo de uma variável Real do Z3 é uma instância de AlgebraicNumRef, IntNumRef ou RatNumRef, é fornecida uma função para converter essa instância num número de vírgula flutuante.
