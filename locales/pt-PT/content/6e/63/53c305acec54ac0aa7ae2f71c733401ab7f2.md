# Instruções

Neste exercício vais implementar um conjunto parcial de rotinas utilitárias para ajudar um programador a limpar nomes de identificadores.

Ao longo das 6 tarefas vais construir gradualmente as funções `transform`, para converter carateres individuais, e `clean`, para converter strings.

Um identificador válido é composto por zero ou mais letras, underscores, hífenes, pontos de interrogação e emojis.

Se for passada uma string vazia à função `clean`, deve ser devolvida uma string vazia.

## 1. Substitui todos os hífenes encontrados por underscores

Implementa a função `transform` para substituir todos os hífenes por underscores.

```fsharp
transform '-'  // => "_"
```

## 2. Remove todos os espaços em branco

Remove todos os carateres de espaço em branco.
Isto inclui os espaços em branco no início e no fim.

```fsharp
transform ' '  // => ""
```

## 3. Converte camelCase em kebab-case

Modifica a função `transform` para converter camelCase em kebab-case

```fsharp
transform 'D'  // => "-d"
```

## 4. Omite os carateres que são algarismos

Modifica a função `transform` para omitir os carateres numéricos.

```fsharp
transform '7'  // => ""
```

## 5. Substitui as letras gregas minúsculas por pontos de interrogação

Modifica a função `transform` para substituir todas as letras gregas no intervalo de 'α' a 'ω'.

```fsharp
transform 'β' // => "?"
```

## 6. Combina estas operações para atuar sobre uma string

Implementa a função `clean` para aplicar estas operações a uma string completa.

Os carateres que ficam fora das regras devem passar sem alterações.

```fsharp
clean "  a2b Cd-ω😀  " //  => "ab-cd_?😀"
```

## Construir uma string a partir de carateres

Este tópico será abordado em detalhe mais à frente no currículo.

Por agora, pode ser útil saberes que existe uma [função de ordem superior][higher-order-function] chamada [`String.collect`][string-collect] que converte uma coleção de `char`s numa string, usando uma função que tu forneces.

```fsharp
let transform ch = $"{ch}_"
String.collect transform "abc"  // =>  "a_b_c_"
```
