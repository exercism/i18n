# Introdução

O Elixir proporciona uma sintaxe elegante para trabalhar com dados binários, como já vimos com a forma especial `<<>>` disponibilizada para trabalhar com [cadeias de bits][exercism-bitstrings].

O tipo binário é uma especialização do tipo cadeia de bits. Enquanto as cadeias de bits podem ter qualquer comprimento (qualquer número de [bits][wiki-bit]), os binários são aqueles em que o número de bits é divisível por 8. Ou seja, ao trabalhar com binários, pensamos frequentemente nas coisas em termos de [bytes][wiki-byte] (8 bits). Um byte pode representar números inteiros de `0` a `255`. É comum trabalhar com valores de byte em [hexadecimal][wiki-hexadecimal], `0x00 - 0xFF`.

Os literais binários são definidos com a forma especial de cadeia de bits `<<>>`. Ao definir um literal binário, podemos usar literais inteiros e de string. Valores inteiros superiores a 255 provocam overflow e apenas os últimos 8 bits do inteiro são utilizados. Por predefinição, o modificador `::binary` é aplicado ao valor. Podemos concatenar binários com o operador `<>/2`.

```elixir
<<255>> == <<0xFF>>
# Overflowing bits are truncated
<<256>> == <<0>>
<<2, 4, 6, 8, 10, 12, 14, 16>> == <<0x02, 0x04, 0x06, 0x08, 0x0A, 0x0C, 0x0E, 0x10>>
```

Um _byte nulo_ é outro nome para `<<0>>`.

## Correspondência de padrões em dados binários

A [correspondência de padrões][exercism-pattern-matching] é até estendida aos binários, e podemos fazer correspondência de padrões sobre uma porção de dados binários tal como faríamos com uma lista.

```elixir
# Ignore the first 8 bytes, match and bind the remaining to `body`
<<_::binary-size(8), body::binary>>
```

Tal como acontece com outros tipos de correspondência de padrões, podemos usar isto em assinaturas de funções para fazer correspondência ao escolher entre várias cláusulas de função.
