# Anexo às instruções

## Implementação

Define uma função, `cost`, que calcula o custo de uma determinada lista de livros com base nos descontos definidos.

`cost` devolve o custo total (depois dos descontos) em cêntimos.
Por exemplo, para um único livro, o custo é de 800 cêntimos, o que equivale a 8,00 $.
Para este exercício, só são necessários cálculos com números inteiros.
