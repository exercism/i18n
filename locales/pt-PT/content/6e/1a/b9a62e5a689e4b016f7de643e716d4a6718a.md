# Introdução

## Anulabilidade

Em C#, o literal `null` é usado para denotar a ausência de um valor. Um tipo _anulável_ é um tipo que permite valores `null`.

Antes do C# 8.0, os tipos de referência eram sempre anuláveis e os tipos de valor não. Um tipo de valor pode tornar-se anulável acrescentando-lhe um ponto de interrogação (`?`).

```csharp
string nullableReferenceType = "hello";
nullableReferenceType = null; // Valid as type is nullable

int nonNullableValueType = 5;
nonNullableValueType = null; // Compile error as type is not nullable

int? nullableValueType = 5; // Define nullable value type
nullableValueType = null;   // Valid as type is nullable
```

Aceder ao membro de uma variável nula não causa um erro de compilação, mas faz com que seja lançada uma `NullReferenceException` em tempo de execução:

```csharp
string sentence = null;

// Throws NullReferenceException at runtime
sentence.Length;
```

Para contrariar este tipo comum de erro, o C# 8 permite aderir a uma funcionalidade que torna os tipos de referência não anuláveis por predefinição:

```csharp
string nonNullableReferenceType = "book";
nonNullableReferenceType = null; // Compile warning (no error!)

string? nullableReferenceType = "movie";
nullableReferenceType = null; // Valid as type is nullable
```

Para trabalhar em segurança com valores anuláveis, verifica se são `null` antes de os usar:

```csharp
string NormalizedName(string? name)
{
    if (name == null)
    {
        return "UNKNOWN";
    }

    // Value is not null at this point, so no compile warning
    // and no runtime NullReferenceException being thrown
    return name.ToUpper();
}

NormalizedName(null); // => "UNKNOWN"
NormalizedName("Elisabeth"); // => "ELISABETH"
```

O operador `??` permite devolver um valor predefinido quando o valor é `null`:

```csharp
string? name1 = "John";
name1 ?? "Paul"; // => "John"

string? name2 = null;
name2 ?? "George"; // => "George"
```

O operador `?.` permite chamar membros em segurança num valor que pode ser `null`:

```csharp
string? fruit = "apple";
fruit?.Length; // => 5

string? vegetable = null;
vegetable?.Length; // => null
```
