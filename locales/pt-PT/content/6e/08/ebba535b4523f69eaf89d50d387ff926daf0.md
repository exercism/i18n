# Instruções

O clássico exercício introdutório. Basta dizer "Hello, World!".

["Hello, World!"](http://en.wikipedia.org/wiki/%22Hello,_world!%22_program) é o tradicional primeiro programa de quem está a começar a programar numa nova linguagem ou ambiente.

Os objetivos são simples:

- Escreve uma função que devolve a string "Hello, World!".
- Corre os testes e certifica-te de que passam.
- Submete a tua solução e verifica-a no site.

Se tudo correr bem, ficas pronto para ir buscar o teu primeiro exercício a sério.
