# Introdução

Em Common Lisp, uma função pode ter parâmetros opcionais. Estes são designados na lista lambda pela palavra-chave `&optional`. Um parâmetro fica ligado ao valor `nil` se não for especificado. Se houver vários parâmetros opcionais, são ligados por ordem. Podem especificar-se valores predefinidos para os parâmetros opcionais. Por fim, pode especificar-se um símbolo para cada parâmetro opcional, o qual fica ligado a verdadeiro ou falso consoante esse parâmetro tenha sido, ou não, fornecido por quem chama a função (a isto dá-se o nome de "supplied-p parameter").

```lisp
(defun optional-parameters (&optional x (y 'default) (z nil z-supplied-p))
  (list x y (if z-supplied-p (list :z-was-supplied z)
                             (list :z-was-not-supplied z))))

(optional-parameters)          ; => (NIL DEFAULT (:Z-WAS-NOT-SUPPLIED NIL))
(optional-parameters 5 nil 10) ; => (5 NIL (:Z-WAS-SUPPLIED 10))
```
