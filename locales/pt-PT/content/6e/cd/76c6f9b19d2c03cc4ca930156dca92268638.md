# Introdução

Muitas vezes, queremos escrever código que possa ramificar consoante uma condição. Embora haja muitas formas de o fazer em Elixir, uma das mais simples é usar `cond/1`.

Na sua forma mais simples, `cond` segue o primeiro caminho que é avaliado como `true`, de entre um ou mais ramos:

```elixir
cond do
  x > 10 -> :this_might_be_the_way
  y < 7 -> :or_that_might_be_the_way
  true -> :this_is_the_default_way
end
```

Se nenhum caminho for avaliado como `true`, o runtime lança um erro.
