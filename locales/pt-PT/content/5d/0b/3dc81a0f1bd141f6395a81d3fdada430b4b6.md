# Dicas

## Geral

- A classe `string` tem muitos [métodos incorporados][methods] úteis.

## 1. Obter a mensagem de uma linha de registo

- Existem [vários métodos][index-of] para encontrar o índice em que determinado texto ocorre numa `string`.
- Remover espaços em branco é [algo incorporado][trim].

## 2. Obter o nível de registo de uma linha de registo

- Uma `string` pode ser convertida para minúsculas com um [método incorporado][to-lower].

## 3. Reformular uma linha de registo

- Existe um [operador incorporado][plus-operator] para concatenar strings.
