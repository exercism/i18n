# Introdução

Às vezes, quando uma função recebe muitos argumentos, pode ser difícil lembrares-te da ordem pela qual os deves passar. Para tornar a leitura mais fácil, o Gleam permite etiquetar os argumentos com um nome.

Para etiquetar um argumento, indica o nome da etiqueta antes do nome do argumento, separados por um espaço.

```gleam
pub fn replace(
  in string: String,
  each target: String,
  with replacement: String
) -> String {
  // ...
}
```

Quando chamas uma função com argumentos etiquetados, podes passar os argumentos por qualquer ordem. Todas estas chamadas a `replace` são equivalentes:

```gleam
replace(in: "🍔🍔🍔" each: "🍔", with: "🍕")

replace(each: "🍔", in: "🍔🍔🍔", with: "🍕")

replace(with: "🍕", each: "🍔", in: "🍔🍔🍔")
```

As etiquetas são sempre opcionais. Mesmo que uma função tenha argumentos etiquetados, podes continuar a chamá-la sem etiquetas.

```gleam
replace("🍔🍔🍔", "🍔", "🍕")
```
