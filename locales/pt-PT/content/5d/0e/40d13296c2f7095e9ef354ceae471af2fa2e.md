# Anexo às instruções

## Registos

| Registo | Utilização              | Tipo    | Descrição                        |
| ------- | ----------------------- | ------- | -------------------------------- |
| `$a0`   | parâmetro de entrada    | endereço | frase terminada em null         |
| `$a1`   | parâmetro de entrada e de saída | endereço | string de resultado terminada em null |
| `$t0-9` | temporário              | qualquer | para armazenamento temporário   |
