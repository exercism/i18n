# Introdução

Um parâmetro de método pode tornar-se opcional se lhe atribuíres um valor predefinido. Quando chamas um método com parâmetros opcionais, não precisas de passar um valor para eles. Se não passares qualquer valor a um parâmetro opcional, é usado o valor predefinido desse parâmetro.

Os parâmetros opcionais _têm_ de ficar no fim da lista de parâmetros; não podem ser seguidos de parâmetros não opcionais.

```csharp
class Card
{
    static string NewYear(int year = 2020)
    {
        return $"Happy {year}!";
    }
}

Card.NewYear();     // => "Happy 2020!"
Card.NewYear(1999); // => "Happy 1999!"
```
