# Introdução

Os conceitos de covariância e contravariância em PHP são importantes, uma vez que o PHP obriga a que estas regras sejam seguidas ao estender classes ou interfaces.

A covariância preserva a relação entre dois tipos, enquanto a contravariância inverte essa relação. Em suma, significa que, ao estender classes e sobrescrever funções, podes permitir tipos mais ou menos específicos para os parâmetros do teu método e podes fazer com que o método devolva tipos menos ou mais específicos.

## Exemplos

Considera a seguinte classe:

```php
class Calculator 
{
    public function add(int $x, int $y): int 
    {
        return $x + $y;
    }
}
```

Se estendermos a classe, podemos permitir mais tipos de parâmetros do que os declarados originalmente, mas não podemos devolver nada além dos tipos devolvidos originais.

```php
class Floatulator extends Calculator
{
    // This is valid
    public function add(int|float $x, int|float $y): int 
    {
        return (int)($x + $y);
    }
}
```

A seguinte classe estendida não é válida porque não é permitido devolver tipos adicionais ou mais abrangentes:

```php
class BrokenCalculator extends Calculator 
{
    // This is invalid and will not compile
    public function add(int|float $x, int|float $y): int|float{
        return $x + $y;
    }
}
```
