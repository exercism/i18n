# Introdução

O Ruby é uma [linguagem orientada a objetos][object-oriented-programming] dinâmica.
No Ruby, tudo é um [objeto][object].

Existem duas formas principais de associar objetos a nomes no Ruby: usar variáveis ou constantes.
As variáveis escrevem-se sempre em [snake case][snake-case].
Ao longo da sua existência, uma variável pode referenciar objetos diferentes.
Por exemplo, `my_first_variable` pode ser definida e redefinida várias vezes com o operador `=`:

```ruby
my_first_variable = 1
my_first_variable = "Some string"
my_first_variable = SomeComplexObject.new
```

As constantes, no entanto, destinam-se a ser atribuídas uma única vez.
Têm de começar por uma letra maiúscula e, normalmente, escrevem-se totalmente em maiúsculas, com as palavras separadas por underscores.

Por exemplo:

```ruby
MY_FIRST_CONSTANT = 10

# Redefining not allowed
# MY_FIRST_CONSTANT = "Some String"
```

O Ruby está organizado em classes.
As classes são definidas com a palavra-chave `class` seguida do nome da classe.
Os objetos são geralmente criados ao instanciar classes com o método `.new`.

Por exemplo:

```ruby
# Define the class
class Calculator
  #...
end

# Create an instance of it and assign it to a variable
my_first_calc = Calculator.new
```

As unidades de funcionalidade são encapsuladas em métodos, à semelhança das _funções_ noutras linguagens.
Um método pode, opcionalmente, ser definido com argumentos posicionais e/ou argumentos de palavra-chave, que são definidos e chamados com a sintaxe `:`.
Os métodos devolvem implicitamente o resultado da última instrução avaliada ou podem devolver explicitamente um objeto através da palavra-chave `return`.
Os métodos são invocados com a sintaxe `.`.

```ruby
class Calculator

  # Unnamed params
  def add(num1, num2)
    return num1 + num2 # Explicit return
  end

  # Named params
  def multiply(num1:, num2:)
    num1 * num2 # Implicit return
  end
end

calc = Calculator.new
calc.add(1, 3)
calc.multiply(num1: 2, num2: 5)
```
