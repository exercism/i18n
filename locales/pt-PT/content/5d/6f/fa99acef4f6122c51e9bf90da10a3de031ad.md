# Correr os testes

## Descarregar um exercício

Usa a [CLI do Exercism][cli] para descarregar o exercício em que queres trabalhar.

```sh
exercism download --track=dart --exercise=hello-world
```

Depois, entra no diretório do exercício.

```sh
cd /path/to/exercism/dart/hello-world
```

## Instalar as dependências

Antes de correres os testes, descarrega as dependências do exercício.

```sh
dart pub get
```

## Correr os testes

```sh
dart test
```

## Compreender os resultados dos testes

```sh

  Expected: <3>
    Actual: <0>

  package:matcher                    expect

To run this test again: dart test test/binary_search_test.dart -p vm --plain-name 'finds a value in the middle of an array'
```

## Trabalhar os testes um a um

A maioria dos exercícios tem vários testes e, por omissão, todos menos o primeiro estão ignorados.

```dart
void main() {
  final twoFer = TwoFer();

  group('TwoFer', () {
    test('no name given', () {
      final result = twoFer.statement();
      expect(result, equals('One for you, one for me.'));
    }, skip: false);

    test('a name given', () {
      final result = twoFer.statement('Alice');
      expect(result, equals('One for Alice, one for me.'));
    }, skip: true);

    test('another name given', () {
      final result = twoFer.statement('Bob');
      expect(result, equals('One for Bob, one for me.'));
    }, skip: true);
  });
}
```

Para trabalhares os testes um a um, muda `skip: true` para `skip: false` em cada teste à medida que avanças.
Em alternativa, corre todos os testes de uma vez sem editares o ficheiro.

```sh
dart test --run-skipped
```

Ao submeteres, todos os testes são executados pelo test runner online, incluindo os ignorados.

## Como resolver o erro "Could not find a command named frontend_server.dart.snapshot"

Imagina que tens um exercício que já resolveste e submeteste e ao qual voltas passado algum tempo.
Podes encontrar este erro quando o testas:

```sh
$ dart test
...
Could not find a command named "/path/to/frontend_server.dart.snapshot".
```

A [solução][solution] é apagar o ficheiro `pubspec.lock`.
Depois, corre outra vez o comando do dart.
