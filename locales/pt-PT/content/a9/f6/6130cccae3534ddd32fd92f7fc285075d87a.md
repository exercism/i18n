# Sobre

O Elm é uma linguagem encantadora para construir aplicações web fiáveis.
Tem mensagens de erro amigáveis, um excelente desempenho, ficheiros pequenos e não tem exceções em tempo de execução.

Provavelmente, a parte mais famosa e mais copiada do Elm é The Elm Architecture, que é um padrão simples para estruturar aplicações web e é assim que todas as aplicações web em Elm são escritas.

A ideia central é que o teu código é construído à volta de um `Model` do estado da tua aplicação, de uma forma de fazer `update` ao teu modelo e de uma forma de fazer `view` ao teu modelo.

O `Model` contém o estado da aplicação: todos os dados de que a aplicação precisa.
Se imaginares uma aplicação simples com uma caixa de texto e texto que mostra o inverso desse texto, o modelo teria o seguinte aspeto.
Também podes ver este exemplo no [Guia do Elm][elm-guide-text-fields].

```elm
type alias Model =
  { text : String
  }
```

`update` é uma função que é chamada com uma `Msg` quando há uma alteração (como quando o utilizador clica num botão).
Recebe a `Msg` e o `Model` atual e devolve um novo `Model`.

```elm
type Msg
  = TextChanged String

update : Msg -> Model -> Model
update msg model =
  case msg of
    TextChanged newText ->
      { model | text = newText }
```

`view` é uma função que devolve HTML para mostrar ao utilizador no navegador.
Recebe o `Model` atual e devolve um `Html Msg` (o tipo que o Elm usa para representar HTML).

```elm
view : Model -> Html Msg
view model =
  Html.div []
    [ Html.input
      [ Html.Attributes.placeholder "Text to reverse"
      , Html.Attributes.value model.text
      , Html.Events.onInput TextChanged
      ]
      []
    , Html.div [] [ Html.text (String.reverse model.text) ]
    ]
```
