# Introdução

## Arrays

Em Ruby, um **array** (a que também se chama _vetor_) é uma coleção ordenada de qualquer objeto, indexada por números inteiros.
A indexação de arrays começa em `0`.
Um índice negativo é considerado relativo ao fim do array. Por exemplo, um índice de `-1` indica o último elemento do array, `-2` é o penúltimo elemento, e assim por diante.

### Criar arrays

Normalmente, os arrays criam-se com a notação `[]`.
Podem conter objetos de qualquer tipo.

```ruby
array = [1, "two", 3.0]
```

### Referência a elementos

Os elementos de um array podem ser obtidos através dos seus índices com o método `#[]`.
Isto devolve o elemento no índice indicado, ou devolve um subarray que começa no índice inicial e se prolonga por um comprimento especificado.
Os índices negativos contam a partir do fim do array.

```ruby
a = [ "a", "b", "c", "d", "e" ]

a[2]       #=> "c"
a[6]       #=> nil
a[1, 3]    #=> [ "b", "c", "d" ]

a[-1]      #=> "e"
a[-2]      #=> "d"
a[-3, 2]   #=> ["c", "d"]
```

### Métodos auxiliares

Há muitos métodos auxiliares úteis nos arrays.
Aqui ficam alguns dos mais comuns:

```ruby
fibonacci = [0, 1, 1, 2, 3, 5, 8, 13]

fibonacci.size      #=> 8
fibonacci.sum       #=> 33
fibonacci.reverse   #=> [13, 8, 5, 3, 2, 1, 1, 0]
```

## Enumeração

Em vez de usar ciclos para percorrer coleções, em Ruby usamos a enumeração.

A enumeração é o ato de percorrer uma coleção (neste caso, um array) e realizar alguma ação sobre cada objeto.  A enumeração é um conceito fundamental em Ruby e é usada para coisas como ordenar, agrupar, mapear, reduzir e muito mais.

Uma enumeração para imprimir cada palavra de um array seria assim:

```ruby
words = ["the", "cat", "sat"]
words.each do |word|
  puts word
end

# Output:
# the
# cat
# sat
```

Neste exemplo, chamámos o método `.each` ao nosso array e passámos um _bloco_ que recebe um parâmetro (`word`) e o imprime.

Vamos ver os _blocos_ com muito mais detalhe mais adiante no percurso, mas por agora pensa neles como funções anónimas que podem receber zero ou mais argumentos.
Podem ser definidos com a sintaxe `do...end` (acima) ou com a sintaxe `{}` (abaixo).

Aqui ficam outros exemplos de métodos de arrays que usam blocos:

```ruby
fibonacci = [0, 1, 1, 2, 3, 5, 8, 13]

fibonacci.count  { |number| number == 1 }   #=> 2
fibonacci.any?   { |number| number == 6 }   #=> false
fibonacci.select { |number| number.odd? }   #=> [1, 1, 3, 5, 13]
fibonacci.all?   { |number| number < 20 }   #=> true
fibonacci.map    { |number| number * 2  }   #=> [0, 2, 2, 4, 6, 10, 16, 26]
```
