# Sobre
Um ciclo é uma forma de executar repetidamente uma ou mais instruções em conjunto.
Cada execução de um conjunto de instruções chama-se uma iteração.

## Ciclo while

Um ciclo `while` executa um conjunto de instruções enquanto uma expressão Boolean no topo do ciclo for verdadeira.
Quando a expressão Boolean for falsa, o ciclo deixa de ser executado e a execução passa para a linha de código seguinte ao ciclo.

Se a expressão Boolean for falsa desde o início, o ciclo `while` não é executado nenhuma vez e a execução passa para a linha de código seguinte ao ciclo.

```c
int main() {
    int i = 0;
    while (i < 5) {
        printf("Number is %i\n", i++);
    }    
    return 0;
}
```

É importante que exista uma condição para terminar o ciclo; caso contrário, trata-se de um ciclo infinito que bloqueia todo o progresso do código.
Se o código acima tivesse o `++` removido de `i`, seria um ciclo infinito.

## Ciclo do

Um ciclo `do` tem a sua expressão Boolean testada no fim do ciclo.
Um ciclo `do` é sempre executado pelo menos uma vez, como no exemplo seguinte

```c
do {
    printf("Enter the Answer to the Ultimate Question of Life: ");
    scanf("%d", &answer);
} while (answer != 42); 
// Note that a semicolon is needed after the Boolean expression.
```

Com um ciclo `while`, isto seria mais verboso

```c
printf(""Enter the Answer to the Ultimate Question of Life: ");
scanf("%d", &answer);
while (answer != 42) {
    printf(""Enter the Answer to the Ultimate Question of Life: ");
    scanf("%d", &answer);
}
```

## Ciclo for

Muitas vezes, um ciclo atualiza uma variável e termina quando a variável atinge um determinado valor.
Um ciclo `for` é uma forma de inicializar, atualizar e testar uma ou mais variáveis numa só linha, entre parênteses.
A primeira secção serve para inicializar a variável, a segunda para a testar e a terceira para atualizar o valor da variável.

```c
for (int i = 0; i < 5; i++) {
    printf("Number is %i\n", i);
}
```

Isto é menos verboso do que o ciclo `while` equivalente, e, no entanto, continua a ser legível.

As secções de inicialização e de atualização do ciclo `for` podem tratar de mais do que uma variável, usando o operador vírgula para separar as expressões dentro das condições.

```c
    int i, j;
    for (i = 0, j = 5; i < 5 && j > 2; i++, j--) {
        printf("i is %i\n", i);
        printf("j is %i\n", j);
    }
    printf("After the loop");
```

Isto imprime

```
i is 0
j is 5
i is 1
j is 4
i is 2
j is 3
After the loop
```

Nenhuma das secções do ciclo `for` precisa de ser definida.
Uma expressão de teste vazia é avaliada como verdadeira, pelo que um ciclo `for` pode ser usado para definir um ciclo infinito assim

```c
int i = 0;
for (;;) {
    printf("Number is %i\n", i++);
    if (i == 5) break;
}
```

Isto é semelhante ao ciclo `while`, na medida em que `i` é inicializado antes do ciclo e é incrementado dentro do ciclo.
Além disso, `i` é testado dentro do ciclo e o ciclo termina com a instrução `break`.

## Instrução break

Por vezes, um ciclo pode precisar de terminar perante uma condição especial que não é testada na sua expressão Boolean.
A instrução `break` termina o ciclo e a execução passa para a linha de código seguinte ao ciclo.

```c
int i, j, k;
for (int i = 0, j = 5, k = 3; i < 5 && j > 2; i++, j--) {
    printf("i is %i\n", i);
    printf("j is %i\n", j);
    if (k == 3) break;
}
printf("After the loop");
```

Isto imprime

```
i is 0
j is 5
After the loop
```

## Instrução continue

Por vezes, um ciclo pode precisar de iniciar a iteração seguinte sem concluir a iteração atual.
A instrução `continue` interrompe a execução da iteração atual e retoma a execução no início da iteração seguinte.

```c
int i, j;
for (int i = 0, j = 4; i < 4 && j > 0; i++, j--) {
    if (i == j) continue;
    printf("i is %i\n", i);
    printf("j is %i\n", j);
}
printf("After the loop");
```

Isto imprime

```
i is 0
j is 4
i is 1
j is 3
i is 3
j is 1
After the loop
```

Não imprime os valores de `i` e `j` quando ambos são `2`.
