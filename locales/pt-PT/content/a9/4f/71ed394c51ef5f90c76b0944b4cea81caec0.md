# Introdução

A função `switch()` pode ser um substituto conciso para uma longa série de testes `if` ... `else if`.
A variável sobre a que se faz o switch é, habitualmente, uma string e, nesse caso, as aspas podem ser omitidas do seletor.

```R
star <- function(type) {
  switch(type,
    M = , # will "fall through" if no value given
    K = "red dwarf",
    G = "Earth-like",
    "bigger star" # only correct for O,B,A,F
  )
}

> star("M")
[1] "red dwarf"
```

Repara que as opções só passam à seguinte se o valor ficar em branco, tal como acontece com `M` no exemplo acima.
Não é necessário incluir instruções `break`, ao contrário do que acontece nalgumas outras linguagens.

Quando se faz switch sobre tipos `character`, o último valor é um valor predefinido, como aqui.
Com tipos inteiros, não é possível indicar nenhum valor predefinido.

## Funções no `dplyr`

O `switch` do R base é bastante limitado: só faz correspondência exata com um único valor de entrada.
Isso parecia razoável quando o R foi lançado, em 1993, mas precisa de ser melhorado para o uso moderno.

~~~~exercism/note
Como referido no conceito [`Conditionals`][concept-conditionals], a coleção de pacotes `tidyverse` foi concebida para complementar (e por vezes substituir) a funcionalidade do R base sem afetar a compatibilidade com versões anteriores.

Podes trazer o pacote `dplyr` para o âmbito adicionando `library(dplyr)` (para o pacote individual) ou `library(tidyverse)` (para a coleção completa) ao início do teu código.

A biblioteca `dplyr` disponibiliza duas funções extra relacionadas com o `switch`.

### As funções `recode_values` e `replace_values`

Estas duas funções relacionadas permitem um mapeamento vetorizado, ao estilo do switch, de valores antigos para valores novos.

A principal diferença entre elas é que `recode_values()` cria um vetor totalmente novo, enquanto `replace_values()` permite atualizações parciais a um vetor existente.

A correspondência continua a ser exata, mas:

- As opções à esquerda podem ser vetores, e a correspondência acontece se algum dos elementos corresponder.
- As opções à esquerda e os resultados à direita são ligados com um til `~` em vez de `=`.
- Em todos os casos é possível especificar um valor predefinido.

```R
library(dplyr)

x <- c("a", "b", "a", "d", "b", NA, "c", "e", "z")
recode_values(
  x,
  "a" ~ 1,
  "b" ~ 2,
  "c" ~ 3,
  c("d", "e") ~ 4, # either "d' or "e" will match
  NA ~ 0,          # matches missing values
  default = 100   # note the different syntax for the default
)
#> [1]   1   2   1   4   2   0   3   4 100
```

### A função `case_when`

`case_when` leva a sintaxe de `case_match` mais longe, ao permitir qualquer expressão lógica à esquerda do `~`.

O vetor de entrada (`x` no exemplo abaixo) não é fornecido como argumento; só precisa de já estar definido.

```R
x <- 1:10
case_when(
  x < 3 ~ "low",
  between(x, 3, 5) ~ "mid",
  between(x, 6, 8) ~ "high",
  .default = "what?"
)
#>  [1] "low"   "low"   "mid"   "mid"   "mid"   "high"  "high"  "high"  "what?" "what?"
```

A função `between()` também faz parte do `dplyr`.
