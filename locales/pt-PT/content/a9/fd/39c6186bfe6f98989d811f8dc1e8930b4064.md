# Dicas

## Geral

- As [estruturas e as classes][structs-and-classes] partilham uma sintaxe de definição semelhante.

## 1. Define uma estrutura Size

- As propriedades têm de ser definidas como `var`s se puderem ser alteradas.
- Às propriedades height e width devem ser atribuídos os valores por omissão de 80 e 60, respetivamente.
- Os métodos de uma estrutura têm de ser marcados como `mutating` se alterarem propriedades da estrutura.

## 2. Define uma estrutura Position

- As propriedades têm de ser definidas como `var`s se puderem ser alteradas.
- Às propriedades x e y deve ser atribuído o valor por omissão de 0.
- Os métodos de uma estrutura têm de ser marcados como `mutating` se alterarem propriedades da estrutura.

## 3. Define uma classe Window

- As estruturas podem ser inicializadas com valores de propriedades diferentes através de [inicializadores membro a membro][memberwise-initializers].
- As propriedades constantes devem ser definidas com `let`.
- A propriedade `contents` deve ser opcional, pois pode não ter valor.
- Tens de definir um inicializador vazio para a classe (`init() {}`).

## 4. Adiciona um método para redimensionar janelas

- O método deve receber um parâmetro `to` do tipo `Size`.
- É possível extrair height e width do parâmetro `to` usando a notação de ponto.

## 5. Adiciona um método para mover janelas

- O método deve receber um parâmetro `to` do tipo `Position`.
- É possível extrair x e y do parâmetro `to` usando a notação de ponto.

## 6. Adiciona um método para definir o conteúdo de uma janela

- Em Swift, é possível ter dois métodos com o mesmo nome, mas com parâmetros diferentes.
- Define um método com o parâmetro `title` que define a propriedade `title`.
- Define um método com o parâmetro `text` que define a propriedade `contents`.
- Define um método que imprime o título e o conteúdo da janela.

## 7. Cria um inicializador para a classe Window

- A classe deve ter dois inicializadores: um que não recebe parâmetros e outro que recebe parâmetros.
- O novo inicializador deve ter os parâmetros `title` e `contents` e também deve permitir os parâmetros opcionais `size` e `position`
    Se não forem fornecidos parâmetros, devem ser usados os valores por omissão.
- Os parâmetros opcionais podem ser obtidos através de [valores por omissão dos parâmetros][default-parameters-vales].
