# Sobre

Em Haxe, os iteradores servem para iterar sobre um valor com um ciclo `for`. Há dois tipos de iteradores:

- `Iterator`, que itera sobre um valor.
- Dados `Iterable`, que tornam possível iterar sobre um tipo de dados.

Estes dois conceitos são representados por `Iterator<T>` e `Iterable<T>`:

```haxe
typedef Iterator<T> = {
  function hasNext():Bool;
  function next():T;
}

typedef Iterable<T> = {
  function iterator():Iterator<T>;
}
```

Qualquer classe que se unifique com um destes tipos pode ser iterada com um ciclo `for`. Se uma classe definir os métodos `hasNext` e `next`, é considerada um iterador; caso contrário, se definir um método `iterator`, é considerada um tipo iterável:

```haxe
class MyStringIterator {
  var str:String;
  var i:Int;

  public function new(str:String) {
    this.str = str;
    i = 0;
  }

  public function hasNext():Bool {
    return i < str.length;
  }

  public function next():String {
    return str.charAt(i++);
  }
}
```

No exemplo acima, a classe `MyStringIterator` é considerada um iterador, uma vez que implementa os métodos `hasNext` e `next`, o que a torna compatível com `Iterator<String>`.

```haxe
class MyArrayWrap<T> {
  var arr:Array<T>;

  public function new(a:Array<T>) {
    this.a = a;
  }

  public function iterator() {
    return a.iterator();
  }
}
```

Aqui, a classe `MyArrayWrap` é considerada um tipo de dados iterável, uma vez que é compatível com `Iterable<Array<T>>`.
