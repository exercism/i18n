# Introdução

O operador `|>` chama-se operador de pipe. Pode ser usado para encadear chamadas de funções umas às outras, de forma que o valor devolvido pela chamada anterior é passado à chamada seguinte.

```gleam
"hello"
|> string.uppercase
|> string.append("?!")
// -> "HELLO?!"
```

O código acima é equivalente ao seguinte:

```gleam
string.append(string.uppercase("hello"), "?!")
```

O operador de pipe passa o valor como primeiro argumento da chamada de função, ou como único argumento de uma nova chamada, escolhendo a opção que resulte no tipo correto.

```gleam
100
|> function_that_takes_two_arguments(1)

// Is equivalent to
function_that_takes_two_arguments(100, 1)
```

```gleam
100
|> function_that_returns_a_function(1)

// Is equivalent to
function_that_returns_a_function(1)(100)
```

Por vezes queremos passar o valor para outra posição. Nesse caso, podemos usar o marcador de posição `_` para indicar onde o valor deve ser inserido.

```gleam
100
|> some_function(1, _, 2)
```
