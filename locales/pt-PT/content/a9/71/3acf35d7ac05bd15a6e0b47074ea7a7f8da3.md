# Introdução

Uma string em Factor é uma sequência de carateres. A maioria das palavras do vocabulário [`sequences`][sequences] funciona com strings, além das palavras dedicadas ao tratamento de strings em [`splitting`][splitting], [`ascii`][ascii] e afins.

## Literais de string

As strings escrevem-se entre aspas duplas. As sequências de escape habituais são suportadas: `\n`, `\t`, `\r`, `\\`, `\"`:

```factor
"hello, world" .                 ! => "hello, world"
"first\nsecond" print            ! prints two lines
```

## Comprimento e indexação

Como uma string é uma sequência, as palavras `length` e `nth` de [`sequences`][sequences] funcionam diretamente com ela.

`length` devolve o número de carateres:

```factor
"hello" length .    ! => 5
```

`nth` recebe um índice com base em 0 e a sequência, e devolve o elemento nessa posição. No caso de uma string, o elemento é um *caráter*, ou seja, um ponto de código (um número inteiro), e não uma substring de um único caráter:

```factor
0 "hello" nth .     ! => 104   (CHAR: h)
4 "hello" nth .     ! => 111   (CHAR: o)
```

## De um caráter de volta a uma string

Para transformar um único ponto de código numa string de um só caráter, usa `1string ( char -- str )` do vocabulário [`strings`][strings]. `CHAR:` é a forma usada pelo analisador sintático para um ponto de código literal:

```factor
CHAR: A 1string .                ! => "A"
0 "hello" nth 1string .          ! => "h"
```

## Divisão

O vocabulário [`splitting`][splitting] corta uma string em partes.

`split1` corta na *primeira* ocorrência de um separador e devolve as duas metades:

```
split1 ( seq subseq -- before after )
```

```factor
"foo: bar" ": " split1 .s
! => "foo"
! => "bar"
```

`split` corta em *qualquer* um dos carateres de um conjunto de separadores, podendo produzir partes vazias:

```factor
"[ERROR]: Stack overflow" "[]" split .
! => { "" "ERROR" ": Stack overflow" }
```

`harvest` (em [`sequences`][sequences]) descarta as partes vazias:

```factor
"[ERROR]: Stack overflow" "[]" split harvest .
! => { "ERROR" ": Stack overflow" }
```

## Escolher uma parte

Depois de dividires uma string num array de partes, `first`, `second`, `third` e `fourth` (em [`sequences`][sequences]) devolvem a parte nessa posição:

```factor
"apple,bee,carrot,duck" "," split first .    ! => "apple"
"apple,bee,carrot,duck" "," split second .   ! => "bee"
"apple,bee,carrot,duck" "," split third .    ! => "carrot"
"apple,bee,carrot,duck" "," split fourth .   ! => "duck"
```

Quando queres todas as primeiras partes na pilha de uma só vez, `first2` e `first3` desempacotam duas ou três delas num único passo:

```factor
"apple,bee,carrot,duck" "," split first2 .s
! => "apple"
! => "bee"

"apple,bee,carrot,duck" "," split first3 .s
! => "apple"
! => "bee"
! => "carrot"
```

No caso de uma string, `first` devolve o primeiro **caráter** (um ponto de código) e não uma substring:

```factor
"hello" first .                         ! => 104   (CHAR: h)
```

## Aparar

`[ blank? ] trim` (de [`sequences`][sequences], com `blank?` do vocabulário [`ascii`][ascii]) remove os espaços em branco no início e no fim:

```factor
"  Disk full \r\n" [ blank? ] trim .
! => "Disk full"
```

## Conversão entre maiúsculas e minúsculas

`>lower` e `>upper` (de [`ascii`][ascii]) devolvem uma nova string com as maiúsculas e minúsculas convertidas:

```factor
"WARNING" >lower .    ! => "warning"
"hello" >upper .      ! => "HELLO"
```

## Junção

Duas palavras de [`sequences`][sequences] montam strings:

`surround` envolve uma string com um prefixo e um sufixo:

```
surround ( seq pre post -- new-seq )
```

```factor
"warning" "(" ")" surround .    ! => "(warning)"
```

`glue` junta duas strings com um separador entre elas:

```
glue ( s1 s2 sep -- s )
```

```factor
"Disk full" "(error)" " " glue .    ! => "Disk full (error)"
```
