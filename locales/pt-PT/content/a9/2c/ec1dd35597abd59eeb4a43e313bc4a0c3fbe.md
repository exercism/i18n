# Instalação

O [Godot Engine][godot-engine] é usado para executar código GDScript.
O Godot Engine funciona em Windows, Linux, macOS e Android.



## Instalar o Godot Engine

O Godot Engine pode ser descarregado diretamente do [site do Godot Engine][godot-engine].
O download contém um único executável, cujo nome inclui a versão do Godot Engine.
Este ficheiro tem de ser renomeado para `godot` e colocado numa das diretorias do `$PATH`.
Depois de concluíres a instalação, podes verificar se o CLI foi instalado com sucesso ao executar este comando num terminal:

```bash
godot --version
```

Este track usa o Godot versão 4.7.2.
