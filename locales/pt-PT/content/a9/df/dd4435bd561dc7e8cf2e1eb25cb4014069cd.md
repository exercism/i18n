# Introdução

Os dicionários em Gleam são a estrutura de dados para guardar informação em pares chave-valor. Noutras linguagens, também podem ser conhecidos como arrays associativos, hashes ou dicionários.

Pode usar-se qualquer tipo nas chaves e nos valores de um dicionário, e este não garante a ordem das suas entradas quando são acedidas ou devolvidas.

## Trabalhar com dicionários

Os dicionários são criados e manipulados com funções do módulo `gleam/dict`.

```gleam
// Create an empty dict
let dict1 = dict.new()

// Create a dict with some values
let dict2 = dict.from_list([
  #("name", "Gleam"),
  #("colour", "Pink"),
])

// Add a value to a dict
let dict3 = dict.insert(dict2, "website", "https://gleam.run")

// Get a value from a dict
let name = dict.get(dict3, "name")
// -> Ok("Gleam")
```
