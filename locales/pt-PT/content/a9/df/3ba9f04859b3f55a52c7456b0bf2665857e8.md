# Instruções

Enquanto continuas o teu trabalho na _Instruments of Texas_, estão a ser feitos progressos na implementação em Elixir da calculadora RPN. A tua equipa gostaria de poder lançar erros mais específicos do que os erros genéricos fornecidos pela biblioteca padrão. Estás a fazer alguma investigação, mas decidiste implementar dois novos erros que implementam o _Exception Behaviour_.

## 1. Erro de divisão por zero

Dividir um número por zero produz um resultado indefinido, que a equipa decide ser melhor representado por um erro.

Implementa o módulo `DivisionByZeroError` com a mensagem de erro: `"division by zero occurred"`

```elixir
raise DivisionByZeroError
# => ** (DivisionByZeroError) division by zero occurred
```

## 2. Erro quando ocorre um underflow da pilha

As calculadoras RPN usam uma _pilha_ para acompanhar os números antes de serem adicionados. A equipa representa esta _pilha_ com uma lista de números (inteiros e de vírgula flutuante), por exemplo: `[3, 4.0]`. Cada operação precisa de um número específico de números na pilha para realizar o seu cálculo. Quando não há números suficientes na pilha, isto chama-se um erro de underflow da pilha. Implementa a exceção `StackUnderflowError`, que fornece uma mensagem predefinida e contexto extra opcional.

```elixir
raise StackUnderflowError
# => ** (StackUnderflowError) stack underflow occurred

raise StackUnderflowError, "when dividing"
# => ** (StackUnderflowError) stack underflow occurred, context: when dividing
```

## 3. Escreve uma função de divisão

Implementa a função `divide/1`, que recebe uma pilha _(uma lista de dois números)_ e:

- lança um erro de _underflow da pilha_ quando a pilha não contém números suficientes
- lança um erro de _divisão por zero_ quando o divisor é 0 (repara que a pilha de números está guardada por ordem inversa)
- realiza a divisão quando não é lançado nenhum erro

```elixir
RPNCalculator.Exception.divide([])
# => ** (StackUnderflowError) stack underflow occurred, context: when dividing

RPNCalculator.Exception.divide([0, 100])
# => ** (DivisionByZeroError) division by zero occurred

RPNCalculator.Exception.divide([4, 16])
# => 4
```

> Repara que a ordem da lista está invertida!
