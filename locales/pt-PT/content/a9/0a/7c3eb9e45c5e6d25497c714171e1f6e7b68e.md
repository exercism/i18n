# Introdução

[Estruturas e classes][structs-and-classes] são os principais blocos de construção para criar tipos personalizados em Swift.
Ambas permitem-te agrupar propriedades (dados) e métodos (comportamento) relacionados em unidades reutilizáveis.
A maioria dos tipos fundamentais em Swift, incluindo `Int`, `Double`, `String` e tipos de coleção como `Array` e `Dictionary`, está implementada como estruturas.

Para guias detalhados sobre cada tipo, consulta:

- [concept:swift/structs]()
- [concept:swift/classes]()

## Como escolher entre estruturas e classes

Embora tanto as estruturas como as classes te permitam definir tipos personalizados, diferem fundamentalmente na forma como são passadas na memória:

- **As estruturas são tipos de valor**: quando atribuis ou passas uma estrutura, o Swift faz uma cópia independente dos seus dados.
As alterações feitas a uma cópia não afetam as outras cópias.
- **As classes são tipos de referência**: quando atribuis ou passas uma instância de uma classe, o Swift partilha uma referência à instância existente.
As alterações feitas através de uma referência afetam imediatamente todas as outras referências que apontam para a mesma instância.

O Swift valoriza a segurança e um comportamento previsível, o que faz das estruturas a recomendação predefinida para a maioria dos tipos personalizados.
Usar tipos de valor garante que alterar dados numa parte do teu programa não provoca efeitos secundários inesperados noutras partes.

Em geral:

- **Usa uma estrutura** quando modelas dados que representam valores independentes (como coordenadas, formas, dimensões geométricas ou registos formatados).
- **Usa uma classe** quando modelas entidades que têm identidades distintas ou requisitos partilhados de ciclo de vida (como controlos de interface, ligações a bases de dados ou identificadores de ficheiros).
