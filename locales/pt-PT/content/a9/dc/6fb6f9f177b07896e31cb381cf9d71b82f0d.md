# Instruções (apêndice)

## Estrutura do projeto

Os exercícios de Clojure no exercism usam o [leiningen](http://leiningen.org/) para configurar e executar o teu código, e seguem a [estrutura de diretórios padrão do leiningen](https://github.com/technomancy/leiningen/blob/master/doc/TUTORIAL.md#directory-layout).

Vais encontrar um ficheiro de testes chamado `hello_world_test.clj` dentro da pasta `test`.
Escreve o teu código em `src/hello_world.clj`. Deve usar o namespace `hello-world` para que os testes o consigam detetar.

## Executar os testes

Executa os testes com o comando `lein test` e faz com que passem:

```
$ lein test

lein test hello-world-test

Ran 3 tests containing 3 assertions.
0 failures, 0 errors.
```

Depois, submete o exercício com:

```
$ exercism submit src/hello_world.clj
```

Para instruções mais detalhadas e recursos de aprendizagem, consulta a [página da linguagem Clojure do exercism](http://exercism.io/languages/clojure).
