# Dicas

## 1. Determina quanto tempo demora a misturar um sumo

- Cria uma [instrução switch][mdn-switch] para a variável `name`.
- Os diferentes casos devem representar os diferentes nomes de sumos.
- Usa o caso `default` para abranger todos os outros nomes.
- Tem em atenção que, por predefinição, os casos seguem uns para os outros, por isso certifica-te de que fizeste algo para evitar esse comportamento.

## 2. Reabastece a reserva de gomos de lima

- Usa um [ciclo while][mdn-while] para cortar uma lima a seguir à outra.
- Volta a ver o [conceito de arrays][concept-arrays] para descobrires uma forma de remover as limas da lista pela ordem correta.
- Cria uma [instrução switch][mdn-switch] para obteres o número de gomos consoante o tamanho da lima.
- Tens de controlar duas coisas: quantas limas já foram cortadas e quantos gomos ainda faltam.
- Podes combinar duas condições para o ciclo com [operadores lógicos][concept-booleans].

## 3. Termina o turno

- Usa um [ciclo do-while][mdn-do-while] para tratar de uma encomenda a seguir à outra.
- Volta a ver o [conceito de arrays][concept-arrays] para descobrires uma forma de remover as bebidas da lista pela ordem correta.
- Já tens uma função que determina quanto tempo demora a preparar uma bebida; usa-a para reduzir o tempo que resta em conformidade.
- Podes combinar duas condições para o ciclo com [operadores lógicos][concept-booleans].
