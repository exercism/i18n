Como futura maga, a Elyse precisa de praticar o básico.
Tem um baralho de cartas que quer manipular.

Para facilitar um pouco, usa apenas as cartas de 1 a 10.

## 1. Obter uma carta de um baralho

Devolve a carta na posição `idx` do baralho dado.

```julia-repl
julia> idx = 2;

julia> card([1, 3, 4, 1], idx)
3
```

## 2. Trocar uma carta no baralho

Troca a carta na posição `idx` pela nova carta fornecida e devolve o baralho ajustado.
Repara que isto vai alterar (modificar) o vetor de entrada, e não há problema.

```julia-repl
julia> idx = 2; new_card = 6;

julia> replace_card!([1, 3, 4, 1], idx => new_card)
[1, 6, 4, 1]
```

## 3. Inserir uma carta no topo do baralho

Insere uma nova carta no topo do baralho e devolve o baralho.

```julia-repl
julia> new_card = 8;

julia> insert_card_at_top!([1, 3, 4, 1], new_card)
[1, 3, 4, 1, 8]
```

## 4. Remover uma carta do baralho

Remove a carta na posição `idx` do baralho e devolve o baralho.

```julia-repl
julia> idx = 2;

julia> remove_card!([1, 3, 4, 1], idx)
[1, 4, 1]
```

## 5. Remover a carta do topo do baralho

Remove a carta do topo do baralho e devolve o baralho.

```julia-repl
julia> remove_card_from_top!([1, 3, 4, 1])
[1, 3, 4]
```

## 6. Inserir uma carta no fundo do baralho

Insere uma nova carta no fundo do baralho e devolve o baralho.

```julia-repl
julia> new_card = 8;

julia> insert_card_at_bottom!([1, 3, 4, 1], new_card)
[8, 1, 3, 4, 1]
```

## 7. Remover uma carta do fundo do baralho

Remove a carta no fundo do baralho e devolve o baralho.

```julia-repl
julia> remove_card_at_bottom!([1, 3, 4, 1])
[3, 4, 1]
```

## 8. Verificar o tamanho do baralho

Verifica se o tamanho do baralho é igual a um dado `deck_size` ou não.

```julia-repl
julia> deck_size = 4;

julia> check_deck_size([1, 3, 4, 1], deck_size)
true

julia> check_deck_size([1, 3, 4, 1, 5], deck_size)
false
```
