# Apêndice às instruções

## Palavras

`convert ( rows -- str )` recebe a grelha como um array de strings,
uma string por linha, e devolve os algarismos reconhecidos como uma única
string. Várias linhas de células são unidas na saída por
vírgulas (`,`).

## Erros

Lança uma destas strings (exatamente como escritas) quando a entrada estiver mal formada:

- `"Number of input lines is not a multiple of four"`
- `"Number of input columns is not a multiple of three"`
