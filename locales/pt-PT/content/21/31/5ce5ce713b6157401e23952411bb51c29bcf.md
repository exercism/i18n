# Instruções

Estás de volta à cozinha, a aperfeiçoar a receita de lasanha d'[A Deliciosa Lasanha da Leah][lasagna]. As tarefas aqui pedem-te que faças malabarismos com vários parâmetros de entrada ao mesmo tempo, e é exatamente aí que os *locals*, os vínculos com nome do Factor, se revelam úteis.

## 1. Determina o estado de cozedura

Define `cooking-status` para recolher da pilha a leitura de um temporizador e devolver uma string de estado.

- `0` → `"Lasagna is done."`
- `f` (o temporizador nunca foi definido) → `"You forgot to set the timer."`
- qualquer outro número → `"Not done, please wait."`

```factor
12 cooking-status .   ! => "Not done, please wait."
0 cooking-status .    ! => "Lasagna is done."
f cooking-status .    ! => "You forgot to set the timer."
```

## 2. Estima o tempo de preparação

Define `preparation-time` para receber um array com os nomes das camadas e uma média de minutos por camada, e devolver o tempo total de preparação.

```factor
{ "sauce" "noodles" "sauce" "meat" "mozzarella" "noodles" } 3 preparation-time .
! => 18
```

## 3. Calcula a massa e o molho necessários

Define `quantities` para receber um array com os nomes das camadas e devolver *dois* valores: os gramas de massa necessários (50 g por camada de massa) e os litros de molho necessários (`1/5` de litro por camada de molho).

```factor
{ "sauce" "noodles" "sauce" "meat" "mozzarella" "noodles" } quantities .s
! => 100
! => 2/5
```

## 4. Adiciona o ingrediente secreto

Uma pessoa amiga envia-te uma lista de ingredientes; o *último* item é o segredo dela. Define `add-secret-ingredient` para receber a lista dela e a tua, e devolver a tua lista com o segredo acrescentado no fim.

```factor
{ "noodles" "sauce" "mozzarella" "kampot pepper" }
{ "noodles" "meat" "sauce" "mozzarella" }
add-secret-ingredient .
! => { "noodles" "meat" "sauce" "mozzarella" "kampot pepper" }
```

## 5. Ajusta a receita

A receita do livro de cozinha dá duas porções. Define `scale-recipe` para receber uma receita (um hashtable que associa o nome de cada ingrediente à respetiva quantidade) e um número de porções pretendido, e devolver uma nova receita ajustada em conformidade.

```factor
H{ { "noodles" 200 } { "sauce" 1/2 } { "mozzarella" 1 } { "meat" 100 } }
4 scale-recipe .
! => H{ { "noodles" 400 } { "sauce" 1 } { "mozzarella" 2 } { "meat" 200 } }
```
