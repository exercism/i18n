# Dicionários

Os dicionários em Cairo são armazenamentos de pares chave-valor, semelhantes a mapas ou tabelas de hash noutras linguagens.

No entanto, têm algumas características únicas devido ao modelo de memória imutável do Cairo.

## Conceito central

O tipo `Felt252Dict<T>` fornece a funcionalidade de dicionário em Cairo, com `felt252` como tipo das chaves e qualquer tipo suportado `T` como tipo dos valores.

```rust
use core::dict::Felt252Dict;

fn main() {
    let mut balances: Felt252Dict<u64> = Default::default();
    balances.insert('Alice', 100);
    let balance = balances.get('Alice'); // Returns 100
}
```

## Características importantes

Ao contrário dos dicionários noutras linguagens, os dicionários de Cairo têm algumas propriedades especiais:

1. As chaves têm de ser valores `felt252`.
2. Todas as chaves começam implicitamente com o valor zero.
3. Não podes apagar entradas, só podes atualizar valores.
4. Os valores têm de implementar o trait `Felt252DictValue`.

## Nota sobre desempenho

Devido ao modelo de memória imutável do Cairo, as operações sobre dicionários têm complexidade $O(n)$, em que $n$ é o número de operações efetuadas sobre o dicionário.

Cada operação cria uma nova entrada que regista a alteração.

## Trabalhar com tipos complexos

Para tipos que não implementam `Felt252DictValue` (como arrays ou structs), podes envolvê-los em `Nullable<T>`:

```rust
let mut dict: Felt252Dict<Nullable<Span<felt252>>> = Default::default();
dict.insert(0, NullableTrait::new(array![1, 2, 3].span()));
```

## Gestão de memória

Os dicionários implementam o trait `Destruct`, o que significa que são automaticamente "comprimidos" (validados e otimizados) quando saem do âmbito.

Isto faz parte do sistema de provas do Cairo e acontece nos bastidores.

Lembra-te: embora os dicionários possam parecer menos eficientes do que noutras linguagens, foram concebidos desta forma para funcionar com o modelo de memória único do Cairo e com os requisitos do sistema de provas.
