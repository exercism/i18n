# Anexo às instruções

## Instruções específicas do percurso

O compilador Phix conhece normalmente todos os pacotes padrão que são distribuídos com ele e incorpora-os automaticamente quando é necessário. No entanto, nem sempre é esse o caso, tal como não o seria para os components que criaste como parte de uma aplicação.
Este exercício (muito simples) não envolve mais do que localizar o pacote padrão de números complexos que é distribuído com o Phix e torná-lo disponível para os testes correrem.

Podes usar a [online][[online] cópia da documentação, embora, se tiveres instalado uma cópia localmente, possas achar que tem melhores recursos de pesquisa, especialmente a versão chm, que normalmente se encontra em `C:\Program Files[ (x86)]\Phix\docs\phix\`.

Se quiseres aprender como está implementada a aritmética dos números complexos, não há melhor do que examinar o código-fonte desse component padrão. Pelo menos, de um modo geral: não vou negar que possa haver algoritmos ligeiramente melhores por aí para uma ou duas coisas, que podem ser mais rápidos, mais precisos, ou ambos.

[online]:(http://phix.x10.mx/docs/html/phix.htm)
