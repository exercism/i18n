# Introdução

Um `Tuple` é bastante semelhante a um `Vector` (um `array` unidimensional) em muitos aspetos.
No entanto, há algumas diferenças importantes.

- Os tuplos escrevem-se entre parênteses `( )` em vez de parênteses retos `[ ]`, embora os parênteses possam ser omitidos quando o significado não é ambíguo.
- Os tuplos não têm de ser homogéneos: o tipo de cada elemento é guardado de forma independente.
- Os tuplos são imutáveis.

A imutabilidade permite mais otimizações do compilador e torna os tuplos mais eficientes do que os vetores, por isso são preferíveis sempre que a mutabilidade não é necessária.

```julia-repl
julia> t = (3, 5.2, "xyz")
(3, 5.2, "xyz")

# Non-homogeneous:
julia> dump(t)
Tuple{Int64, Float64, String}
  1: Int64 3
  2: Float64 5.2
  3: String "xyz"

julia> t[2]
5.2

# Immutable:
julia> t[2] = 7.3
ERROR: MethodError: no method matching setindex!(::Tuple{Int64, Float64, String})
```

Existe também um construtor `Tuple()`, que transforma qualquer coleção iterável num tuplo.
Convenientemente, isto trata uma string como uma coleção iterável de carateres.

```julia-repl
julia> Tuple("Julia")
('J', 'u', 'l', 'i', 'a')
```

Em qualquer tuplo, é possível aceder aos elementos pelo índice ou percorrê-los com um ciclo.

Qualquer tuplo puramente numérico pode também ser usado em funções matemáticas como `sum()`, exatamente como os vetores.

## Desempacotamento

Um tuplo pode ser desempacotado em elementos individuais através de atribuição múltipla.
Para os elementos que não são necessários, usa o sublinhado `_` como variável fictícia.

```julia-repl
julia> tup = (1, "Julia", true)
(1, "Julia", true)

julia> num, name, _ = tup
(1, "Julia", true)

julia> uppercase(name), 2num
("JULIA", 2)
```

Quem programa em Python está bem familiarizado com esta sintaxe de atribuição múltipla.

## Tuplos nomeados

Um `Tuple` contém apenas valores.
Um `NamedTuple` associa cada valor a um nome.

Os campos individuais podem depois ser acedidos com a notação de "ponto":

```jullia-repl
julia> nt = (a = 1, b = 7.3)
(a = 1, b = 7.3)

julia> dump(nt)
@NamedTuple{a::Int64, b::Float64}
  a: Int64 1
  b: Float64 7.3

julia> nt.b
7.3
```

O nome é guardado internamente como um `Symbol` (um tipo imutável, e o nome é precedido de dois pontos `:`), por isso há uma sintaxe alternativa disponível:

```julia-repl
julia> nt[:b]
7.3
```

É fácil obter separadamente os nomes (também chamados "chaves") ou os valores:

```julia-repl
julia> nt
(a = 1, b = 7.3)

julia> keys(nt)
(:a, :b)

julia> values(nt)
(1, 7.3)
```

Repara que a iteração sobre um tuplo nomeado produz apenas os _valores_, e os _nomes_ são ignorados.

Os tuplos (nomeados ou não) são uma forma muito comum de transferir dados estruturados de e para funções.
A imutabilidade é benéfica neste caso de uso, pois garante a segurança dos dados e permite otimizações mais agressivas do compilador.
