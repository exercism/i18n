# Instruções

Foste contratado como especialista em expressões regulares numa empresa que está a desenvolver um Chatbot.

Está numa fase de desenvolvimento muito básica, por isso a tua missão é usar expressões regulares para melhorar a capacidade do chatbot de compreender e gerar linguagem natural.

Para efeitos de aprendizagem, resolve estas tarefas com expressões regulares.

## 1. Verifica se o comando é válido

Além de inteligente, o Chatbot é também um assistente leal.

Para perguntar algo ao chatbot, o utilizador tem de dizer a palavra «**Chatbot**» na primeira posição do comando.

Não importa se a palavra-chave está em MAIÚSCULAS ou em minúsculas.
O que importa aqui é a posição da palavra.

Implementa a função `is_valid_command()` que ajuda o Chatbot a reconhecer quando o utilizador está a dar um comando.

```R
is_valid_command("Chatbot, play a song from the 80's.")
[1] TRUE
> is_valid_command("Hey Chatbot, where is the closest pharmacy?")
[1] FALSE
> is_valid_command("CHATBOT, do you have a solution for this challenge?")
[1] TRUE
```

## 2. Remove os emojis encriptados

O Chatbot tem dificuldade em compreender como as pessoas usam emojis para expressar as suas emoções.

Quando o chatbot recebe mensagens dos utilizadores, cada emoji é representado por «_emoji_» seguido do respetivo número _id_.

Implementa o método `remove_emoji()` para receber uma string e remover toda a encriptação dos emojis ao longo da mensagem.

As linhas que não contêm texto de emoji devem ser devolvidas sem alterações.

Limita-te a remover a string do emoji. Não tentes ajustar os espaços em branco.

```R
remove_emoji("I love playing videogames emoji3465 it's one of my hobbies")
[1] "I love playing videogames  it's one of my hobbies"
```

## 3. Verifica se o número de telefone é válido

Como as funcionalidades do chatbot são transferidas para uma aplicação móvel, espera-se que o utilizador escreva um número de telefone durante a conversa.

O problema é que o chatbot só consegue ler e validar um número com um formato específico.

Se o número for válido (corresponder à sequência de carateres especificada pela **expressão regular**), o chatbot responde com uma mensagem a agradecer ao utilizador e a confirmar o número. Se o número for inválido, a função informa o utilizador de que o número de telefone não é válido.

O formato esperado é: (+##) ###-###-###

```R
check_phone_number("(+34) 659-771-594")
[1] "Thanks! You can now download me to your phone."
> check_phone_number("659-771-594")
[1] "Oops, it seems like I can't reach out to 659-771-594"
```

## 4. Cumprimenta o utilizador

Para guardar os dados de todas as pessoas que conversaram com ele, o chatbot consegue obter o nome completo a partir do perfil do utilizador neste formato: **«Smith, John»**.

Assim, queremos que o nosso chatbot seja muito educado e cause uma boa impressão.

Escreve a função `nice_to_meet_you()` que recebe uma string com o nome completo do utilizador e devolve a string **«Nice to meet you, John Smith»**

```R
nice_to_meet_you("Smith, John")
#> Nice to meet you, John Smith
```

## 5. Obtém a ligação de um site

O Chatbot é um software muito curioso. Apesar de conseguir pesquisar na internet sobre um determinado tema, gosta de perguntar aos utilizadores por sites ou URL interessantes onde possa encontrar informação relevante.

Exemplo de conversa:

- **Chatbot**: Olá, utilizador, gostava de aprender a programar em JavaScript. Conheces algum site interessante onde o possa aprender?
- **Utilizador**: Aprendi muito no [exercism.org](http://exercism.org)

Implementa a função `get_URL()` que consegue devolver um array só com a ligação de cada site.

```R
get_URL("I learned a lot from exercism.org")
[1] "exercism.org"
```
