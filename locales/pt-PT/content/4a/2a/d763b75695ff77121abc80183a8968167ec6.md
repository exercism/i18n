# Instruções

Foste contratado como Especialista em Expressões Regulares numa empresa que está a desenvolver um Chatbot.

Está numa fase de desenvolvimento muito básica.
A tua missão é usar expressões regulares para melhorar a capacidade do Chatbot de compreender e gerar linguagem natural.

## 1. Verifica se o comando é válido

Além de ser inteligente, o Chatbot também é um assistente leal.
Para pedir algo ao Chatbot, o utilizador tem de dizer a palavra "**Chatbot**" na primeira posição do comando.
Não importa se a palavra-chave está em MAIÚSCULAS ou minúsculas.
O importante é a posição da palavra.

Implementa a função `is_valid_command` que ajuda o Chatbot a reconhecer quando o utilizador está a dar um comando.

```jq
"Chatbot, play a song from the 80's." | is_valid_command
# => true
"Hey Chatbot, where is the closest pharmacy?" | is_valid_command
# => false
"CHATBOT, do you have a solution for this challenge?" | is_valid_command
# => true
```

## 2. Remove os emojis encriptados

O Chatbot tem dificuldade em compreender como as pessoas usam emojis para expressar as suas emoções.
Quando o Chatbot recebe mensagens dos utilizadores, cada emoji é representado pela string "emoji" seguida de um _número de id_.

Implementa o método `remove_emoji`, que recebe uma string e remove todos os emojis da mensagem.

As linhas que não contêm emojis devem ser devolvidas sem alterações.
Remove apenas a string do emoji.
Não ajustes os espaços em branco.

```jq
"I love playing videogames emoji3465 it's one of my hobbies" | remove_emoji
# => "I love playing videogames  it's one of my hobbies"
```

## 3. Verifica se o número de telefone é válido

Em algum momento da interação com o Chatbot, o utilizador vai fornecer um número de telefone.
O Chatbot só consegue ligar para um número com um formato específico.

Implementa a função `check_phone_number`.

Se o número for válido, o Chatbot responde com uma mensagem a agradecer ao utilizador e a confirmar o número.
Se o número for inválido, o Chatbot informa o utilizador de que o número de telefone não é válido.

O formato esperado é `(+NN) NNN-NNN-NNN`, em que N é um algarismo.

```jq
"chatbot my phone number is (+34) 659-771-594" | check_phone_number
# => "Thanks! Your phone number is OK."
"chatbot, call me at 659-771-594" | check_phone_number
# => "Oops, it seems like I can't reach out to 659-771-594."
```

## 4. Obtém o link do site

O Chatbot é um software muito curioso.
Apesar de conseguir procurar na internet um tema específico, gosta de perguntar aos utilizadores por sites interessantes para visitar e encontrar informação relevante.

Exemplo de conversa:

> **Chatbot**: Olá, Utilizador, gostava de aprender a programar em JavaScript. Conheces algum site interessante onde possa aprender?

> **Utilizador**: Aprendi muito no exercism.org, há lá coisas excelentes.

Implementa a função `get_domains` que devolve um array de domínios de sites.

```jq
"I learned a lot from exercism.org and google.com" | get_domains
# => ["exercism.org", "google.com"]
```

## 5. Cumprimenta o utilizador

Um Chatbot educado fala com os utilizadores pelo nome.
Quando um utilizador se apresenta, o nosso Chatbot deteta o nome e responde com uma saudação amigável.

Escreve a função `nice_to_meet_you`.

Se a string de entrada contiver "My name is Someone.", captura o nome e devolve a string "Nice to meet you, Someone.".

```jq
"My name is Jean-Luc" | nice_to_meet_you
# => "Nice to meet you, Jean-Luc"
```

## 6. Análise de CSV muito simples

Cedendo à «febre das funcionalidades», vamos adicionar ao Chatbot uma função de análise de CSV.

Implementa a função `parse_csv` que recebe uma string e devolve um array dos campos resultantes.
O separador de campos deve ser «vírgula mais espaços em branco opcionais».

Não nos vamos preocupar com nenhum dos casos limite do formato CSV (como campos que contêm vírgulas).

```jq
"first, second,third,   fourth" | parse_csv
# => ["first", "second", "third", "fourth"]
```
