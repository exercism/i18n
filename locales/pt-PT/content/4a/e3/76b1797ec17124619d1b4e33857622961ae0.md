# Introdução

As funções têm ligação externa por predefinição e podem ser chamadas a partir de qualquer outro ficheiro do projeto.
Para saberes mais sobre ligação, consulta o [conceito de ligação](../linkage/introduction.md#Introduction).
Uma função `static` só pode ser chamada dentro do ficheiro de código-fonte onde é definida.

Por exemplo

```c
// file scope, internal linkage
// can only be called from within this file
static void some_function()
{
    // code snipped
}

// file scope, external linkage by default
// can be called from any other file in the project
int main()
{
    // code snipped
}
```
