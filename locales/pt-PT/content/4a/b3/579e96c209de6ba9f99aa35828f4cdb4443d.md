# Introdução

Muitas vezes é útil agrupar uma coleção de itens e tratar esses grupos como unidades. Em Rust, chamamos a esse grupo uma struct, e a cada item um dos campos da struct. Uma struct define o conjunto geral de campos disponíveis, mas um exemplo particular de uma struct chama-se instância.

Além disso, as structs podem ter métodos definidos nelas, que têm acesso aos campos. Nesse caso, a própria struct é referida como `self`. Quando um método usa `&mut self`, os campos podem ser alterados, ou mutados. Quando um método usa `&self`, os campos não podem ser alterados: são imutáveis. Controlar a mutabilidade ajuda o borrow-checker a garantir que classes inteiras de erros de concorrência simplesmente não acontecem em Rust.

Neste exercício, vais implementar dois tipos de métodos numa struct. Os primeiros são geralmente conhecidos como getters: expõem os campos da struct ao mundo, sem deixar que mais ninguém mute esse valor. Em Rust, estes métodos partilham idiomaticamente o nome do campo que expõem, ou seja, se tivermos um método getter que obtém um campo da struct chamado `name`, o método chama-­‑se simplesmente `name()`.

Também vais implementar métodos de outro tipo, geralmente conhecidos como setters. Estes alteram o valor do campo. Os setters não são muito comuns em Rust: se um campo pode ser modificado livremente, é mais comum torná-lo simplesmente público. No entanto, são úteis se a atualização do campo dever ter efeitos secundários, ou para controlo de acesso: um setter marcado como `pub(crate)` permite que outros módulos dentro do mesmo crate atualizem um campo privado, que não pode ser afetado pelo mundo exterior.

As structs existem em três variantes: structs com campos nomeados, structs de tupla e structs unitárias. Para este exercício de conceito, vamos explorar a primeira variante: structs com campos nomeados.

As structs são definidas usando a palavra­‑chave `struct`, seguida do nome capitalizado do tipo que a struct descreve:

```rust
struct Item {}
```

Tipos adicionais são depois introduzidos no corpo da struct como _campos_ da struct, cada um com o seu próprio tipo:

```rust
struct Item {
    name: String,
    weight: f32,
    worth: u32,
}
```

Por fim, os métodos podem ser definidos nas structs dentro de um bloco `impl`:

```rust
impl Item {
    // initializes and returns a new instance of our Item struct
    fn new() -> Self {
        todo!()
    }
}
```

Com esta breve introdução à sintaxe das structs já tratada, vai em frente e dá uma olhada nas [instruções](instructions.md) deste exercício!
