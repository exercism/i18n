# Instruções

Se queres construir algo com um Raspberry Pi, provavelmente vais usar _resistências_. Para este exercício, precisas de saber duas coisas sobre elas:

- Cada resistência tem um valor.
- As resistências são pequenas, tão pequenas que, se imprimisses o valor da resistência nelas, seria difícil de ler.

Para contornar este problema, os fabricantes imprimem nas resistências bandas codificadas por cores, para indicar os seus valores de resistência. Cada banda tem uma posição e um valor numérico.

As primeiras 2 bandas de uma resistência têm um esquema de codificação simples: cada cor corresponde a um único número. Por exemplo, se imprimissem uma banda brown (valor 1) seguida de uma banda green (valor 5), isso daria o número 15.

Neste exercício vais criar um programa útil para não teres de decorar os valores das bandas. O programa vai receber nomes de cores e devolver um número de dois algarismos, mesmo que receba mais do que duas cores!

As cores das bandas estão codificadas da seguinte forma:

- black: 0
- brown: 1
- red: 2
- orange: 3
- yellow: 4
- green: 5
- blue: 6
- violet: 7
- grey: 8
- white: 9

A partir do exemplo acima:
brown-green deve devolver 15, e
brown-green-violet deve devolver 15 também, ignorando a terceira cor.
