# Introdução

## Uniões discriminadas

O tipo união discriminada representa um número fixo de casos com nome. Cada valor de uma união discriminada corresponde a exatamente um dos casos com nome.

Uma união discriminada define-se com a palavra-chave `type`, com os casos separados por carateres pipe (`|`):

```fsharp
type Season =
    | Spring
    | Summer
    | Autumn
    | Winter
```

Cada caso de uma união discriminada pode ter dados associados, e casos diferentes podem ter tipos de dados diferentes. Se nenhum dos casos tiver dados associados, a união discriminada é semelhante ao que outras linguagens costumam chamar de _enumeração_ (ou _enum_).

```fsharp
type Number =
    | Integer of int
    | Float of float
    | Invalid
```

Criar um valor para um caso específico pode ser feito referindo o seu nome (por exemplo, `Success`). Como os nomes dos casos são apenas funções construtoras, os dados associados podem ser passados como um argumento normal de função. Se outra união discriminada tiver definido um caso com o mesmo nome, tens de usar o nome completo (por exemplo, `Result.Success`).

```fsharp
let byName = Integer 2
let byFullName = Number.Invalid
```

As uniões discriminadas têm _igualdade estrutural_, o que significa que dois valores do mesmo caso e com os mesmos dados (opcionais) são equivalentes.

Embora se possam usar expressões `if/elif/else` para trabalhar com uniões discriminadas, a forma recomendada de o fazer é através da correspondência de padrões, com o _padrão de identificador_:

```fsharp
let describe number =
    match number with
    | Integer i -> sprintf "Integer: %d" i
    | Float d  -> sprintf "Float: %f" d
    | Invalid   -> "Invalid"
```
