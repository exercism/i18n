# Anexo às instruções

## Dicas

Os testes deste exercício são diferentes dos testes que costumas ver. Normalmente, um teste verifica se, para um determinado valor de entrada, a saída corresponde ao valor esperado. A isto chama-se _testes baseados em valores_. No entanto, este exercício usa _testes baseados em propriedades_, em que os testes verificam se, para um intervalo de valores de entrada, a saída tem uma determinada propriedade. As duas diferenças principais que distinguem os testes baseados em propriedades dos testes baseados em valores são:

1. Um teste baseado em propriedades não trabalha com um único valor de entrada, mas com muitos.
1. Um teste baseado em propriedades verifica propriedades, não valores concretos.

Neste exercício, todos os testes verificam uma propriedade da forma do diamante que o teu código deve produzir. Além disso, todos os testes verificam se a propriedade que testam se aplica a todas as letras de entrada válidas ('A' a 'Z').

Para facilitar os testes baseados em propriedades, os testes deste exercício recorrem aos pacotes [FsCheck](https://www.nuget.org/packages/FsCheck) e [FsCheck.Xunit](https://packages.nuget.org/packages/FsCheck.Xunit/2.2.0). Para saberes mais sobre o FsCheck, podes consultar a documentação do framework [aqui](https://fscheck.github.io/FsCheck/).

Se quiseres mais informações sobre testes baseados em propriedades, consulta [este artigo](http://www.erikschierboom.com/2016/02/22/property-based-testing/).
