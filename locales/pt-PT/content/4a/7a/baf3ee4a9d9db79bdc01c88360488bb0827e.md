# Aprender

O Exercism disponibiliza exercícios e feedback, mas pode ser difícil dar o primeiro passo para quem está a aprender Pascal pela primeira vez. Estes recursos podem ajudar-te a começar:

* [Pascal Tutorial](https://www.tutorialspoint.com/pascal/index.htm) parece um bom ponto de partida para te familiarizares com Pascal, caso nunca tenhas tido contacto com esta linguagem. Não precisas do Delphi para completar os exercícios abordados neste tutorial. Pode ser um bom sítio para praticar antes de te lançares nos exercícios daqui, que já exigem o Delphi.
* [Pascal-Programming.info](http://www.pascal-programming.info/index.php) também parece ter um bom tutorial para quem está a começar na linguagem.
* Há muitas mais fontes online para aprender Pascal, demasiadas para listar aqui.
