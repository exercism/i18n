# Dicas

## Geral

- Lê sobre o módulo `Enum` no [guia oficial de primeiros passos][getting-started-enum] ou em [elixirschool.com][elixir-school-enum].
- Espreita a documentação para consultares a [lista completa de funções do módulo `Enum`][enum-functions].

## 1. Ordenar os artigos por preço

- Existe uma [função incorporada][enum-sort-by] para ordenar enumeráveis com uma função de ordenação.

## 2. Encontrar todos os artigos com preços em falta

- Existe uma [função incorporada][enum-filter] para filtrar enumeráveis.

## 3. Atualizar os nomes dos artigos

- Existe uma [função incorporada][enum-map] para transformar todos os elementos de um enumerável.
- Existe uma [função incorporada][string-replace] que consegue substituir todas as ocorrências de uma string por outra diferente.

## 4. Incrementar a quantidade do artigo

- Os mapas implementam o protocolo enumerável.
- As funções do `Enum` convertem mapas numa lista de tuplos `{key, value}`.
- Existem duas funções diferentes que conseguem transformar uma lista de tuplos `{key, value}` de volta num mapa com uma função de transformação. [Uma delas devolve sempre um mapa novo][map-new], enquanto [a outra te deixa escolher o colecionável][enum-into].

## 5. Calcular a quantidade total do artigo

- Os mapas implementam o protocolo enumerável.
- As funções do `Enum` convertem mapas numa lista de tuplos `{key, value}`.
- Existe uma [função incorporada][enum-reduce] para reduzir um enumerável a um único valor.
