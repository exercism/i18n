# Dicas

## Geral

- `H{ } clone` é a forma correta de criar uma tabela de hash nova e mutável: os literais `H{ }` podem ser partilhados entre chamadas.
- `inc-at` de [`assocs`][assocs] soma 1 ao valor de uma chave (ou insere-o como 1, se essa chave não existir).

## 1. Construir um inventário a partir de uma lista

- Começa com `H{ } clone` e `inc-at` para cada elemento. Uma quotation de fry `'[ _ inc-at ]` captura a tabela de hash, para a poderes passar a `each`.
- Envolve a iteração em `[ … ] keep`, para que a tabela de hash seja o valor que fica na pilha.

## 2. Adicionar mais itens

- A estrutura é a mesma da tarefa 1, só que partes de um `clone` do inventário recebido em vez de um inventário vazio.

## 3. Decrementar contagens

- Usa `key?` primeiro: só se alteram os itens que já estão no inventário.
- `change-at` aceita uma quotation `( old -- new )`; combina-a com `[ 1 - 0 max ]` (com `max` de [`math.order`][math.order]), para que a contagem nunca fique negativa.

## 4. Remover um item por completo

- `delete-at` altera a tabela de hash e não devolve nada. Faz primeiro `clone`, depois `delete-at`, e deixa o clone na pilha.

## 5. Listar os itens disponíveis

- `>alist` converte a tabela de hash numa sequência de pares.
- `[ second 0 > ] filter` mantém apenas os itens que estão em stock.
- `sort-keys` (em [`sorting`][sorting]) ordena uma alist pela chave.

[assocs]: https://docs.factorcode.org/content/vocab-assocs.html
[math.order]: https://docs.factorcode.org/content/vocab-math.order.html
[sorting]: https://docs.factorcode.org/content/vocab-sorting.html
