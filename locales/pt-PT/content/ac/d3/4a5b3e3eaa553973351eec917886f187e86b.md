# Instruções

Neste exercício vais processar linhas de log.

Cada linha de log é uma string formatada da seguinte forma: `"[<LVL>]: <MESSAGE>"`.

Estes são os diferentes níveis de log:

- `TRC` (trace)
- `DBG` (debug)
- `INF` (info)
- `WRN` (warning)
- `ERR` (error)
- `FTL` (fatal)

Tens três tarefas, e cada uma delas tem de ser concluída para forneceres a funcionalidade necessária.

## 1. Cria o enum LogLevel

Define um enum `LogLevel` com seis casos correspondentes aos níveis de log acima, mais um caso unknown para níveis de log em falta ou não padrão.

- `trace`
- `debug`
- `info`
- `warning`
- `error`
- `fatal`
- `unknown`

## 2. Interpreta o nível de log

A seguir, implementa o inicializador de `LogLevel` para interpretar o nível de log de uma linha de log:

```swift
LogLevel("[INF]: File deleted")
// Returns LogLevel.info
LogLevel("Something went wrong!")
// Returns LogLevel.unknown
```

## 3. Converte a linha de log para o formato curto

O nível de log de uma linha de log é bastante extenso.
Para reduzir o espaço em disco necessário para guardar as linhas de log, foi criado um formato curto: `"<ENCODED_LEVEL>:<MESSAGE>"`.

O nível de log codificado é um mapeamento simples de um nível de log para um número:

- `trace` - `0`
- `debug` - `1`
- `info` - `4`
- `warning` - `5`
- `error` - `6`
- `fatal` - `7`
- `unknown` - `42`

Implementa o método `shortFormat(message: String) -> String`, que devolve a linha de log no formato curto como `String`:

```swift
let overflow = LogLevel.error
overflow.shortFormat(message: "Stack overflow")
// Returns "6:Stack overflow"
```
