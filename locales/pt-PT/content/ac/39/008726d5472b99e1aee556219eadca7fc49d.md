# Instruções

Determina se um triângulo é _equilateral_, _isosceles_ ou _scalene_.

Um triângulo _equilateral_ tem os três lados com o mesmo comprimento.

Um triângulo _isosceles_ tem pelo menos dois lados com o mesmo comprimento.
(Por vezes é definido como tendo exatamente dois lados com o mesmo comprimento, mas para efeitos deste exercício vamos dizer pelo menos dois.)

Um triângulo _scalene_ tem todos os lados com comprimentos diferentes.

## Nota

Para que uma forma seja um triângulo, todos os lados têm de ter comprimento > 0, e a soma dos comprimentos de dois lados quaisquer tem de ser maior ou igual ao comprimento do terceiro lado.

Em equações:

Sejam `a`, `b` e `c` os lados do triângulo.
Então todas as três expressões seguintes têm de ser verdadeiras:

```text
a + b ≥ c
b + c ≥ a
a + c ≥ b
```

Vê a [desigualdade triangular][triangle-inequality]
