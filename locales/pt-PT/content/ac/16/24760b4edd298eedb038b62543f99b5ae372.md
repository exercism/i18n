# Dicas

## Geral

- [Ruby for beginners: Nothingness and the truth][rfb-nothingness-and-truth]

## 1. Verifica se um visitante tem um passe de diversões

- Converte o pass_id num objeto Boolean.
- Vê a classe [`BasicObject`][basicobject-class], que contém métodos que a maioria das classes herda.

## 2. Verifica se um visitante tem altura para uma atração

- Compara a altura mínima da atração com a altura do visitante.
- Vê o módulo [`Comparable`][comparable-module], que contém métodos para comparar objetos que podem ser usados quando são incluídos.
  - A classe [Integer][integer-class] inclui o módulo [`Comparable`][comparable-module].

## 3. Verifica se um visitante pode andar na atração

- Combina os métodos de instância que criaste com um [operador Boolean][pr-boolean-operator] para devolver o resultado.
