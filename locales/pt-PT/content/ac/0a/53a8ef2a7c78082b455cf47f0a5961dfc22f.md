# Geradores

Um `generator` é uma função ou expressão que devolve um tipo especial de [iterador][iterator] chamado [`generator iterator`][generator-iterator].
Os `Generator-iterator`s são [preguiçosos][lazy iterator]: não guardam os seus `values` em memória, mas _geram_ os seus valores quando é preciso.

Uma função geradora é semelhante a qualquer outra função, mas contém uma ou mais [expressões yield][yield expression].
Cada `yield` suspende a execução do código, guardando o estado de execução atual (_incluindo todas as variáveis locais e as instruções try_).
Quando o gerador é retomado, recupera o estado a partir da suspensão, ao contrário das funções normais, que são reiniciadas a cada chamada.


## Construir um gerador

Os geradores são construídos de forma muito semelhante a outras funções com ciclos ou recursivas, mas exigem uma [expressão `yield`](#the-yield-expression), que vamos explorar em detalhe um pouco mais à frente.

Um exemplo é uma função que devolve os _quadrados_ de uma determinada lista de números.
Tal como está escrita, todos os dados de entrada têm de ser processados antes de se poder devolver algum valor:

```python
>>> def squares(list_of_numbers):
...     squares = []
...     for number in list_of_numbers:
...         squares.append(number ** 2)
...     return squares
```

Podes converter essa função num gerador assim:

```python
>>> def squares_generator(list_of_numbers):
...     for number in list_of_numbers:
...         yield number ** 2
```

A razão para isto é que usas um gerador quando não precisas de produzir todos os valores _de uma só vez_.
Isto poupa memória e poder de processamento, uma vez que só é calculado o valor com que estás _a trabalhar neste momento_.


## Utilizar um gerador

Os geradores podem ser usados em vez da maioria dos `iterables` em Python.
Isto inclui _funções_ ou _objetos_ que exigem um `iterable`/`iterator` como argumento.

Para usar o gerador `squares_generator()`:

```python
>>> squared_numbers = squares_generator([1, 2, 3, 4])

>>> for square in squared_numbers:
...     print(square)
...
1
4
9
16
```

Os valores dentro de um `generator` também podem ser produzidos ou acedidos através da função `next()`.
`next()` chama o método `__next__()` de um objeto gerador-iterador, "avançando" ou avaliando o código até à sua expressão `yield`, que depois "cede" ou devolve um valor:

```python
>>> squared_numbers = squares_generator([1, 2])

>>> next(squared_numbers)
1
>>> next(squared_numbers)
4
```

Quando um `generator-iterator` é totalmente consumido e já não tem mais valores para devolver, lança um erro `StopIteration`.

```python
>>> next(squared_numbers)
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
StopIteration
```


~~~~exercism/note

Os gerador-iteradores são um subconjunto especial de [iteradores][iterator].
Os `Iterators` são o mecanismo ou protocolo que permite iterar sobre _iterables_.
Os gerador-iteradores e os iteradores devolvidos pelos [`iterables`][iterables] comuns de Python comportam-se de forma muito semelhante, mas há algumas diferenças importantes a ter em conta:

- São _[avaliados de forma preguiçosa][lazy evaluation]_; a iteração é _unidirecional_ e não há forma de "voltar atrás" para um valor anterior.
- São _consumidos_ ao iterar sobre os valores devolvidos; não há forma de os reiniciar ou guardar em memória.
- Não podem ser ordenados nem invertidos.
- Não são tipos de sequência e _não_ têm `indexes`. 
  Não podes referenciar um valor anterior ou futuro através de adição ou subtração, nem podes usar a notação de parênteses retos (`[]`) ou fatiamento.
- Não podem ser usados com a função `len()`, uma vez que não têm comprimento.
- Podem ser _finitos_ ou _infinitos_. Tem cuidado ao recolher todos os valores de um `generator-iterator` _infinito_!

## A expressão yield

A [expressão yield][yield expression] é muito semelhante à expressão `return`.
Ao contrário da expressão `return`, o `yield` cede valores a quem o chama num _ponto específico_, suspendendo a avaliação ou o retorno de quaisquer valores adicionais até que sejam pedidos.
Quando o `yield` é avaliado, pausa a execução da função que o contém e devolve os valores da função _nesse momento_.
A função permanece então _no âmbito_, e quando `__next__()` é chamado, a execução é retomada até o `yield` voltar a ser encontrado.


~~~~exercism/note
A utilização de expressões `yield` é proibida fora de funções.
~~~~

```python
>>> def infinite_sequence():
...     current_number = 0
...     while True:
...         yield current_number
...         current_number += 1

>>> lets_try = infinite_sequence()
>>> lets_try.__next__()
0
>>> lets_try.__next__()
1
```


## Porquê criar um gerador?

Os geradores são úteis em muitas aplicações.

Quando trabalhas com uma coleção de valores potencialmente grande, podes não querer colocá-los todos em memória.
Um gerador pode ser usado para trabalhar com dados maiores peça a peça, poupando memória e melhorando o desempenho.

Os geradores também são muito úteis quando um processo ou cálculo é _complexo_, _dispendioso_ ou _infinito_:

```python
>>> def infinite_sequence():
...     current_number = 0
...     while True:
...         yield current_number
...         current_number += 1
```

Agora, sempre que `__next__()` é chamado no objeto `infinite_sequence`, devolverá o _número anterior_ + 1.
