# Dicas

## Geral

- Lê sobre [structs][getting-started-structs] no guia Getting Started.
- Lê sobre [`defstruct`][docs-defstruct] na documentação.
- Vê o [Elixir Casts - #106: Intro to Structs][elixir-casts].

## 1. Cria um carro telecomandado novo em folha

- O atributo de módulo `@enforce_keys` pode ser usado para especificar os valores obrigatórios. Tem de ser definido antes de chamares `defstruct`.
- O campo `nickname` não deve ter um valor predefinido especificado.
- A função `new/0` deve inicializar o `nickname` com o valor `"none"`.

## 2. Cria um carro telecomandado novo em folha com uma alcunha

- Usa [`multiple-function-clauses`][multiple-fn-clauses] para reutilizar o nome da função, mas aceitar argumentos diferentes.
- Considera um [`default-argument`][default-arg] para a função.

## 3. Mostra a distância

- Nas funções que aceitam apenas um tipo específico de struct, certifica-te de que fazes uma correspondência de padrões para verificar o argumento.
- Usa o _operador de acesso estático_ para obter os valores dos campos.

## 4. Mostra a percentagem da bateria

- Nas funções que aceitam apenas um tipo específico de struct, certifica-te de que fazes uma correspondência de padrões para verificar o argumento.
- Usa o _operador de acesso estático_ para obter os valores dos campos.

## 5. Conduzir altera a bateria e a distância percorrida

- Nas funções que aceitam apenas um tipo específico de struct, certifica-te de que fazes uma correspondência de padrões para verificar o argumento.
- Usa o _operador de acesso estático_ para obter os valores dos campos.
- Revê a introdução sobre a atualização de structs.

## 6. Tem em conta a condução com a bateria descarregada

- Se a bateria estiver descarregada, a função deve devolver o struct sem alterações.
