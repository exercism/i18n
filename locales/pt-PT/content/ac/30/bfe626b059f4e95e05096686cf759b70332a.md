# Preferir a concatenação de strings

Embora `String.format` e `String.formatted()` sejam métodos fantásticos e poderosos, são mais lentos para um problema que só exige uma concatenação simples de `String` com o operador `+`.
Para mais informações sobre o desempenho de `String.format` e `String.formatted()`, consulta [Java String Concatenation: Which Way Is Best?](https://redfin.engineering/java-string-concatenation-which-way-is-best-8f590a7d22a8).
