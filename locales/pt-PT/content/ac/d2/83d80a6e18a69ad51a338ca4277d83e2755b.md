# Dicas

## Geral

- Há muitas formas de resolver este exercício, e planear a tua estratégia é uma parte essencial do desafio.
- Tal como noutras tracks, os dados de entrada são um `Vector{String}`.
- Como a Julia tem um [tipo `Matrix`][matrix] nativo na linguagem base, podes achar mais fácil converter o tabuleiro para algum tipo de `Matrix` (`String`, `Char`, `Int`...).
- Tem atenção aos casos-limite, que fazem subir a dificuldade do exercício de Fácil para Médio.
  - É possível fazer uma jogada que ganha em 2 dimensões em simultâneo.
  - Que combinações de dimensões são possíveis e válidas?

## Para quem tem inclinação para a matemática

- O [módulo `LinearAlgebra`][linearalgebra] está disponível no test runner.
- Pode conter funções úteis, como [`diag()`][diag].
- Isto não passa de uma opção para quem tiver essa inclinação. Usar álgebra linear não é, de modo algum, essencial.
