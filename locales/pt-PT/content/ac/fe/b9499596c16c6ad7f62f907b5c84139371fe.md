# Instruções

Estás a trabalhar na implementação de um sistema de monitorização de saúde.
Como parte disso, precisas de acompanhar as estatísticas de saúde dos utilizadores.

Vais começar com algumas funções ainda por implementar num bloco `impl`, além da seguinte definição de struct:

```rust
pub struct User {
    name: String,
    age: u32,
    weight: u32,
}
```

O teu objetivo é implementar os métodos ainda por implementar no `struct` `User` definido no bloco `impl`.

Por exemplo, o método `new` deve devolver uma instância do `struct` `User` com o nome, a idade e o peso indicados.

```rust
let mut bob = User::new("Bob", 32, 72);
// Returns: a User with name "Bob", age 32, and weight 72
```

O método `weight` deve devolver o peso do `User`.

```rust
bob.weight();
// Returns: 72
```

O método `set_age` deve definir a idade do `User`.

```rust
bob.set_age(33);
// Updates Bob's age to 33; happy birthday Bob!
```

Diverte-te!
