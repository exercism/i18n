# Instruções

O teu amigo acabou de te enviar uma mensagem com um segredo importante.
Como não queria que fosse fácil para os outros lê-la, a mensagem foi encriptada com uma série de manipulações de bits.
Vais precisar de escrever um programa para ajudar a desencriptar a mensagem.

## 1. Deslocar os bits de volta

O primeiro passo para desencriptar a mensagem é desfazer o deslocamento do processo de encriptação, deslocando os bits de volta para a esquerda.
O número de posições a deslocar pode variar de mensagem para mensagem.

Implementa o método `Secrets.shift_back`, que recebe um valor e o número de posições a deslocar para a esquerda.

```crystal
Secrets.shift_back(0b0001, 2)
# => 0b0100
```

## 2. Aplicar uma máscara de bits

O passo seguinte é aplicar uma máscara de bits para extrair o valor de determinados bits.
A máscara aplica-se efetuando um AND bit a bit entre o valor e a máscara.

Implementa o método `Secrets.apply_mask`, que recebe um valor e aplica uma máscara.

```crystal
Secrets.apply_mask(0b0110, 0b0101)
# => 0b0100
```

## 3. Definir alguns bits

Deslocar bits para a esquerda acrescentou alguns bits 0 novos.
Alguns destes novos bits têm de ser definidos como 1.
O OR bit a bit é útil para definir certos bits como 1 e preservar os restantes.

Implementa o método `Secrets.set_bits`, que recebe dois valores e efetua um OR bit a bit.

```crystal
Secrets.set_bits(0b0110, 0b0101)
# => 0b111
```

## 4. Reverter o XOR

Parte do processo de encriptação aplica um XOR com um valor combinado.
Para voltar ao valor original, basta aplicar novamente o XOR ao valor encriptado com o valor combinado.
No entanto, devido a um mal-entendido, o teu amigo inverteu os bits do valor combinado (ou seja, aplicou um NOT bit a bit ao valor combinado) antes de aplicar o XOR. 

Implementa o método `Secrets.reverse_xor`, que recebe os valores encriptado e combinado e calcula o valor original.

```crystal
Secrets.reverse_xor(0b1100, 0b0101)
# => 0b(0110)
```
