# Resolver exercícios

A principal forma como o Exercism te ajuda a aprender é através da resolução de exercícios.

Há duas formas de resolver exercícios no Exercism:

1. [Online, através do editor do navegador do site](/docs/using/solving-exercises/using-the-online-editor)
2. [Na tua máquina local, através da CLI](/docs/using/solving-exercises/working-locally)

## Qual das opções devo escolher?

Usar o editor online ou a CLI tem vantagens e desvantagens diferentes:

|            | Editor online                          | CLI                                          |
| ---------- | -------------------------------------- | -------------------------------------------- |
| Instalação | Não                                    | Sim (por exemplo, o SDK)                     |
| Edição     | Navegador                              | O teu editor preferido                       |
| Testes     | Executar os testes no site             | Executar os testes localmente                |
| Depuração  | Suporte limitado (apenas para alguns percursos) | Suporte total (dependendo do teu ambiente) |

Em geral, o editor online é ideal para começar novos percursos, enquanto que a abordagem baseada na CLI é ótima se quiseres usar o teu próprio ambiente de programação personalizado.
