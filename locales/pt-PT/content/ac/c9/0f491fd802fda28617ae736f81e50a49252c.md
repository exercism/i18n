# Introdução

Uma função permite agrupar código numa unidade reutilizável.
É composta pela palavra-chave `func`, pelo nome da função e por uma lista, separada por vírgulas, de zero ou mais parâmetros e respetivos tipos, entre parênteses curvos.

## Parâmetros de função

Todos os parâmetros têm de ser tipados explicitamente; não há inferência de tipos para os parâmetros.
Não existem valores predefinidos para os parâmetros, por isso todos os parâmetros de função são obrigatórios.

```go
import "fmt"

// No parameters
func PrintHello() {
    fmt.Println("Hello")
}

// Two parameters
func PrintGreetingName(greeting string, name string) {
  fmt.Println(greeting + " " + name)
}
```

Parâmetros do mesmo tipo podem ser declarados em conjunto, seguidos de uma única declaração de tipo.

```go
import "fmt"

func PrintGreetingName(greeting, name string) {
  fmt.Println(greeting + " " + name)
}
```

## Parâmetros vs. argumentos

Vamos ver rapidamente dois termos que muitas vezes se confundem: `parameters` e `arguments`.
Os parâmetros de função são os nomes definidos na assinatura da função, como `greeting` e `name` na função `PrintGreetingName` acima.
Os argumentos de função são os valores concretos que passamos aos parâmetros de função quando invocamos a função.
Por exemplo, no exemplo abaixo, `"Hello"` e `"Katrina"` são os argumentos passados aos parâmetros `greeting` e `name`:

```go
PrintGreetingName("Hello", "Katrina")
```

## Valores devolvidos

Aos parâmetros da função seguem-se zero ou mais valores devolvidos, que também têm de ser tipados explicitamente.
Um único valor devolvido fica sem parênteses; vários valores devolvidos são envolvidos em parênteses.
Os valores são devolvidos ao código que fez a chamada através da palavra-chave `return`.
Uma função pode ter várias instruções `return`.
A execução da função termina assim que encontra uma dessas instruções `return`.
Se uma função tiver de devolver vários valores, estes são separados por vírgulas.

```go
func Hello(name string) string {
  return "Hello " + name
}

func HelloAndGoodbye(name string) (string, string) {
  return "Hello " + name, "Goodbye " + name
}
```

## Invocar funções

Invocar uma função faz-se indicando o nome da função e passando argumentos para cada um dos parâmetros da função, entre parênteses.

```go
import "fmt"

// No parameters, no return value
func PrintHello() {
    fmt.Println("Hello")
}
// Called like this:
PrintHello()

// One parameter, one return value
func Hello(name string) string {
  return "Hello " + name
}
// Called like this:
greeting := Hello("Dave")

// Multiple parameters, multiple return values
func SumAndMultiply(a, b int) (int, int) {
    return a+b, a*b
}
// Called like this:
aplusb, atimesb := SumAndMultiply(a, b)
```

## Valores devolvidos nomeados e return nu

À semelhança dos parâmetros, os valores devolvidos também podem ter nome, se quisermos.
Se usarmos valores devolvidos com nome, uma instrução `return` sem argumentos devolve esses valores.
É a isto que se chama um return "nu".

```go
func SumAndMultiplyThenMinus(a, b, c int) (sum, mult int) {
    sum, mult = a+b, a*b
    sum -= c
    mult -= c
    return
}
```

## Passagem por valor vs. passagem por referência

Também é importante clarificar o conceito de passagem por valor e de passagem por referência.

Primeiro, vamos clarificar a passagem por valor.
No exemplo abaixo, quando passamos a variável `val` à função `MultiplyByTwo`, passamos uma cópia de `val`.
Por causa disso, `newVal` tem o valor atualizado `4`, mas a variável original `val` continua a ser `2`.
Nos bastidores, o Go faz essencialmente uma cópia do valor original, para que apenas essa cópia, também conhecida como `v`, seja modificada pela função.

```go
val := 2
func MultiplyByTwo(v int) int {
    v = v * 2
    return v
}
newVal := MultiplyByTwo(val)
// newval is 4, val is still 2 because only a copy of its value was passed into the function
```

Em rigor, no Go todos os argumentos são passados por valor, ou seja, é feita uma cópia do valor ou dos dados fornecidos à função.
Mas se não quiseres fazer uma cópia dos dados que são passados a uma função e quiseres alterar esses dados dentro da função, deves usar `pointers` como argumentos, ou seja, passagem por referência.

## Ponteiros

Usamos um `pointer` para conseguir a passagem por referência.
Ao passar argumentos do tipo `pointer` para uma função, podemos modificar os dados subjacentes que são passados à função, em vez de operar apenas sobre uma cópia desses dados.

Por agora, basta saberes que os tipos ponteiro se reconhecem pelo `*` à frente do tipo na assinatura da função.

```go
func HandlePointers(x, y *int) {
    // Some logic to handle integer values referenced by pointers x and y
}
```

Se o conceito de `pointer` te parecer confuso, não há problema.
Temos uma secção dedicada mais à frente no currículo, para te ajudar a dominar os ponteiros.

## Exceções

Repara que `slices` e `maps` são exceções à regra mencionada acima.
Quando passamos um `slice` ou um `map` como argumentos a uma função, são tratados como tipos ponteiro, mesmo que não haja um `*` explícito no tipo.
Isto significa que, se passarmos um slice ou um map a uma função e modificarmos os seus dados subjacentes, as alterações refletem-se no slice ou map original.
