# Introdução

Compreender as referências é essencial para usar Perl de forma eficaz.
Como as referências são escalares, e os arrays e os hashes só podem conter escalares, as referências são fundamentais para aninhar estas estruturas de dados.

Podes criar referências para variáveis e sub-rotinas existentes com o operador de barra invertida `\`:

* `\$scalar` para criar uma referência para um escalar (pode ser qualquer escalar, por exemplo, `\1`, não apenas uma variável).
* `\@array` para criar uma referência para um array.
* `\%hash` para criar uma referência para um hash.
* `\&sub` para criar uma referência de código.

Também podes criar aquilo a que se chama uma referência anónima para arrays, hashes e sub-rotinas:

* `['Alice', 'Bob', 'Charlie']` para criar uma referência anónima para um array.
* `{foo => 'a', bar => 'b', baz => 'c'}` para criar uma referência anónima para um hash.
* `sub { return 1 }` para criar uma referência anónima de código.

AVISO: as chavetas em Perl podem ser ambíguas em certos contextos. Se não estiveres a obter a referência de hash que esperas, acrescenta um sinal de mais no início para desambiguar, por exemplo, `+{}`. Vê [Chavetas][perlrefcurlybrackets] para mais informações.

Podes aceder às referências com o operador seta `->`:

* `$ref->[0]` para aceder a um elemento dentro de uma referência para um array.
* `$ref->{foo}` para aceder a um valor dentro de uma referência para um hash.
* `$ref->($arg)` para chamar uma sub-rotina através de uma referência de código.

Podes aceder aos dados dentro de estruturas de dados complicadas, como arrays multidimensionais e hashes aninhados, encadeando índices, por exemplo, `$ref->{foo}[0]{bar}` (o mesmo que `$ref->{foo}->[0]->{bar}`).

Se quiseres desreferenciar um array ou um hash inteiro, podes usar o operador seta seguido de `@*` ou `%*`, respetivamente, por exemplo, `$ref->@*` ou `$ref->%*`.
Também podes obter fatias de uma referência para um array ou hash substituindo o `*` por um índice, por exemplo, `$ref->@[0..2]` ou `$ref->@{'Foo', 'Bar'}`.
No caso das fatias, a variação do sigil aplica-se aqui da mesma forma que acontece com as variáveis de array e de hash.

[perlrefcurlybrackets]: https://perldoc.perl.org/perlref#Curly-Brackets
