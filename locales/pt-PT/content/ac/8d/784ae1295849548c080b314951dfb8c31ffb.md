# não uses o valor da data

Usa [`Date#getTime`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Date/getTime)
em vez de [`Date#valueOf`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Date/valueOf).
São funcionalmente equivalentes, mas `valueOf` está marcado da seguinte forma:

> Este método é normalmente chamado internamente pelo JavaScript e não
> explicitamente no código.
