# Dicas

## 1. Converter a representação binária em número inteiro

- Existe um [método incorporado][string-to_i] para converter uma string com uma representação binária num número inteiro, dada a base.

## 2. Obter o bit menos significativo de um número inteiro

- Existe um [método incorporado][integer-bit] para obter um bit de um número inteiro, dado um índice.
- O bit menos significativo é o bit que está mais à direita.
  Encontra-se na posição 0.

## 3. Obter o valor hexadecimal de um canal de cor

- Existe um [método incorporado][integer-to_s] para converter um número inteiro numa string com uma representação hexadecimal, dada a base.
- O método pode receber um argumento opcional para especificar a precisão do número de algarismos gerados.

## 4. Obter o valor hexadecimal a partir de RGB

- Podes usar métodos já definidos para obter o valor hexadecimal de um canal de cor.
