# Introdução

## Charlists

As charlists são criadas com o sigil `~c`.

```elixir
~c"hello"
```

~~~~exercism/note
Repara que, em versões mais antigas do Elixir, as charlists são representadas como `'hello'`, com aspas simples.
~~~~

Embora sejam muito parecidas com strings, os dois tipos de dados são bastante diferentes um do outro. Uma charlist é uma lista de números inteiros. Os números inteiros representam os valores Unicode de um determinado caráter, também conhecidos como pontos de código.

```elixir
[65, 66, 67]
# => ~c"ABC"
```

Podes colocar um `?` antes de um caráter para obter o seu ponto de código.

```elixir
?A
# => 65

[?:, ?)]
# => ~c":)"
```

Como as charlists são listas, podes trabalhar com elas tal como com qualquer outra lista: com recursão e correspondência de padrões.

```elixir
[first_letter | _] = ~c"cat"
first_letter
# => 99
```

Podes concatenar duas listas com `++`.

```elixir
~c"hi" ++ ~c"!"
# => ~c"hi!"
```

Quanto mais longa for a primeira lista, mais lenta é a concatenação, por isso evita acrescentar repetidamente elementos a listas de comprimento arbitrário.

## Case

`case` é uma estrutura de controlo de fluxo que nos permite comparar um determinado valor com vários padrões. As cláusulas de uma expressão `case` são avaliadas de cima para baixo, até se encontrar uma correspondência.

```elixir
age = 15

case age do
  0 -> ~c"infant"
  age when age < 4 -> ~c"baby"
  age when age < 13 -> ~c"child"
  age when age < 18 -> ~c"teenager"
  _ -> ~c"adult"
end

# => ~c"teenager"
```
