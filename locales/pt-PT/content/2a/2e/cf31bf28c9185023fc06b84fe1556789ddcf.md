# Introdução

Os números inteiros são números sem separador decimal.

Os tipos inteiros podem armazenar apenas números positivos (sem sinal) ou números positivos e negativos (com sinal).

Alguns exemplos são -6, 0, 1, 25 e 976.

Repara que podes usar underscores para melhorar a legibilidade de números mais longos: `1_000_000`.
