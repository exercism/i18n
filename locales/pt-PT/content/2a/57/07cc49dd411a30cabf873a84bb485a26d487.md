# Visibilidade

Quando usas classes para organizar código, a visibilidade das propriedades, métodos e constantes pode incentivar abstrações e responsabilidades adequadas.
A visibilidade das propriedades, métodos e constantes é definida pelo uso das palavras-chave `public`, `private` ou `protected` no momento em que são declaradas.
A visibilidade refere-se sempre a uma utilização externa da propriedade, método ou constante da classe.
Ou seja, se uma propriedade é declarada `public`, é observável e utilizável por chamadas externas.
As propriedades, métodos e constantes privados não são observáveis nem utilizáveis por chamadas externas.

```php
<?php

class SecretDocument
{
    private $encryption_key;

    public $title;

    public function __construct($encryption_key, $title)
    {
        $this->encryption_key = $encryption_key;
        $this->title = $title;
    }
}

$document = new SecretDocument('secret_password', 'Secret Plans');
$title = $document->title; // => succeeds
$key = $document->encryption_key; // => fails
```

As propriedades, métodos e constantes protegidos só são observáveis por eles próprios e por quaisquer classes filhas (por herança).

```php
<?php

class Shape
{
    protected $color = "blue";
}

class Square extends Shape
{
    public function getColor()
    {
        return $this->color;
    }
}

$square = new Square();
$color = $square->getColor(); // => succeeds
```
