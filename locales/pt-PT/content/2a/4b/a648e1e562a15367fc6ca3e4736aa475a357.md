# Testes

Há duas formas diferentes de preparar a execução dos testes com Objective-C:

- Criar um projeto Xcode com um target de testes que executa os testes.
- Usar a gem `objc` do Ruby como utilitário para executar os testes.

Ambos os métodos estão descritos com mais detalhe aqui: https://exercism.org/tracks/objective-c/tests
