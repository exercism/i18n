# Introdução

Os números de vírgula flutuante são números com um ou mais algarismos depois do separador decimal. Usam o formato de vírgula flutuante de precisão dupla de 64 bits.

```elixir
float = 3.45
# => 3.45
```

## Trabalhar com números

Nos módulos [`Integer`][integer-functions] e [`Float`][float-functions] encontras algumas funções úteis para trabalhar com estes tipos. Os operadores aritméticos básicos estão definidos no módulo [`Kernel`][kernel-arithmetic-operators].

## Conversão

Os inteiros e os números de vírgula flutuante podem ser misturados numa única expressão aritmética. Usar um número de vírgula flutuante numa expressão garante que o resultado também é um número de vírgula flutuante.

```elixir
2 * 3
# => 6

2 * 3.0
# => 6.0
```

No entanto, numa divisão, o resultado é sempre um número de vírgula flutuante, mesmo que só se usem inteiros.

```elixir
6 / 2
# => 3.0
```

Para converter um número de vírgula flutuante num inteiro, podes descartar a parte decimal com [`trunc/1`][trunc-1].
