# Instruções

Enquanto te preparavas para fazer biscoitos para os teus amigos, descobriste que tens de converter algumas das medidas usadas na receita. Como só conheces o sistema métrico, precisas de arranjar uma forma de converter as medidas de pastelaria americanas mais comuns em mililitros (mL), para te facilitar a vida.

Usa esta tabela de conversão na tua solução:

| Unidade a converter | volume | em mililitros (mL) |
| --------------- | ------ | ------------------- |
| mL              | 1      | 1                   |
| Chávena americana          | 1      | 240                 |
| Onça líquida americana  | 1      | 30                  |
| Colher de chá americana     | 1      | 5                   |
| Colher de sopa americana   | 1      | 15                  |

Como és um programador talentoso em formação, decides usar os mililitros como unidade de transição para facilitar a conversão de qualquer unidade da lista para qualquer outra (mesmo para ela própria).

## 1. Obtém a componente numérica de um tuplo de volume

Implementa a função `KitchenCalculator.get_volume/1`. Dado um tuplo de volume, deve devolver apenas a componente numérica.

```elixir
KitchenCalculator.get_volume({:cup, 2.0})
# => 2.0
```

## 2. Converte o tuplo de volume em mililitros

Implementa a função `KitchenCalculator.to_milliliter/1`. Dado um tuplo de volume, deve converter o volume em mililitros usando a tabela de conversão.

Usa várias cláusulas de função e correspondência de padrões para criar as funções para cada unidade. Os átomos usados para denotar cada unidade são: `:cup`, `:fluid_ounce`, `:teaspoon`, `:tablespoon`, `:milliliter`. Devolve o resultado da conversão envolvido num tuplo.

```elixir
KitchenCalculator.to_milliliter({:cup, 2.5})
# => {:milliliter, 600.0}
```

## 3. Converte o tuplo de volume em mililitros para outra unidade

Implementa a função `KitchenCalculator.from_milliliter/2`. Dado um tuplo de volume e a unidade pretendida, deve converter o volume para a unidade pretendida usando a tabela de conversão.

Usa várias cláusulas de função e correspondência de padrões para criar as funções para cada unidade. Os átomos usados para denotar cada unidade são: `:cup`, `:fluid_ounce`, `:teaspoon`, `:tablespoon`, `:milliliter`

```elixir
KitchenCalculator.from_milliliter({:milliliter, 1320.0}, :cup)
# => {:cup, 5.5}
```

## 4. Converte de qualquer unidade para qualquer unidade

Implementa a função `KitchenCalculator.convert/2`. Dado um tuplo de volume e a unidade pretendida, deve converter o volume indicado para a unidade pretendida.

```elixir
KitchenCalculator.convert({:teaspoon, 9.0}, :tablespoon)
# => {:tablespoon, 3.0}
```
