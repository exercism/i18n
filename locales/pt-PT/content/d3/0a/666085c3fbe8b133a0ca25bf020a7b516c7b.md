# Sobre

O tipo booleano em Lua tem os dois valores booleanos tradicionais: `true` e `false`. Estes valores podem ser atribuídos a uma variável, combinados com operadores lógicos (`and`, `or`, `not`) e usados em testes condicionais (por exemplo, em estruturas de controlo).

```lua
local is_true = true
local is_false = false

true and true  --> true
true and false --> false
false or true  --> true
false or false --> false
not false      --> true
not true       --> false

-- prints 0
if is_true == true then
  print(0)
else
  print(1)
end
```

Os testes condicionais e os operadores lógicos consideram tanto o `false` como o `nil` como falsos, e tudo o resto como verdadeiro.
```lua
1 and 2          --> 2
nil and 2        --> nil
false and 2      --> false
1 or 2           --> 1
false or 'hello' --> "hello"
nil or false     --> false
```

Tanto o `and` como o `or` usam *avaliação de curto-circuito*, o que significa que avaliam o segundo operando apenas quando é necessário. Todas as operações são avaliadas de acordo com a [precedência de operadores](https://www.lua.org/manual/5.4/manual.html#3.4.8), em que o `not` é avaliado antes do `and` e do `or`.

Dado que apenas `false` e `nil` são considerados falsos e tudo o resto é verdadeiro, uma construção comum em Lua é:
```lua
x = x or y
```

Isto é equivalente a:
```lua
if not x then
  x = y
end
```

É bastante comum usar isto em funções, para atribuir um valor predefinido se um parâmetro não tiver valor (for `nil`):
```lua
local function hello(name)
  name = name or "World"
  print("Hello " .. name)
end

hello()       --> "Hello World"
hello('Mars') --> "Hello Mars"
```
