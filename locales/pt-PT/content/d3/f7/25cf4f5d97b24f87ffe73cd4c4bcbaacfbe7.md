# Sobre

O ColdFusion (CFML) é uma linguagem de script da JVM cuja sintaxe é semelhante a C ou JavaScript.
Compila JIT para bytecode que corre na JVM, mas é dinâmica e de tipagem fraca, o que a torna rápida e fácil de desenvolver.
O CF é uma linguagem multiparadigma, que suporta programação orientada a objetos clássica e programação funcional.

O CFML tem ainda uma linguagem de templates baseada em etiquetas, incorporada, que o torna ideal para aplicações web.
Corre num contentor J2EE com muitas bibliotecas incluídas, que o tornam muito produtivo, sem necessidade de instalar muitos pacotes.
O CFML tem suporte nativo para ficheiros zip, geração de PDF e Excel, e-mails, FTP, HTTP, sistemas de ficheiros S3, bibliotecas de segurança ESAPI, controladores JDBC e APIs JSON e REST.

O CFML também pode tirar partido de qualquer projeto Java, bastando colocar os jars no projeto e instanciar diretamente objetos Java no teu código.
Podes saber mais sobre a sintaxe básica e os tipos de dados de primeira classe neste guia: [Modern ColdFusion (CFML) in 100 Minutes](https://modern-cfml.ortusbooks.com/)
