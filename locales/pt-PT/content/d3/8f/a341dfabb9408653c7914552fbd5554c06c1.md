# Introdução

Trabalhas numa empresa que vende tipos de letra através do seu site.
Gostariam de mostrar uma frase diferente de cada vez que alguém vê um tipo de letra no site.
Para dar uma ideia abrangente do tipo de letra, as frases aleatórias devem usar **todas** as letras do alfabeto inglês.

Estão a organizar um concurso para recolher sugestões de frases que possam usar.
És tu que verificas as submissões para ver se são válidas.

```exercism/note
A palavra pangrama vem do grego, παν γράμμα, pan gramma, que significa "todas as letras".

O pangrama inglês mais conhecido é:

> The quick brown fox jumps over the lazy dog.
```
