# Anexo às instruções

## Instruções específicas do track

Certifica-te de que a tua solução é suficientemente geral para se poder escalar facilmente para nomes mais longos, com mais letras e algarismos.
Isto também costuma dar origem a código de melhor qualidade.

Sugestão (isto não é testado explicitamente):
Para garantires que tens sempre um nome único, podes implementar a tua própria cache ou usar um `Stream` com a cache incorporada.
