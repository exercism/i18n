# Introdução

O Pyret tem duas primitivas Boolean distintas, `true` e `false`.
Estes dois valores representam se uma afirmação ou condição é válida ou não.

```pyret
"a" == "a" # true
"a" == "b" # false
```

O Pyret disponibiliza os operadores `and` e `or` que podem combinar valores Boolean.

O operador and devolve true se ambos os lados forem verdadeiros e false em todas as outras combinações.

```pyret
true and true # true
true and false # true
false and true # false
false and false # false
```

O operador or devolve true se pelo menos um dos lados for verdadeiro e false se ambos os lados forem falsos.

```pyret
true or true # true
true or false # true
false or true # true
false or false # false
```

`not()` é uma função incorporada que inverte true em false ou false em true.

```pyret
not(true) # false
not(false) # true
```
