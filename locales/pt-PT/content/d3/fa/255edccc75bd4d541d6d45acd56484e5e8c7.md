# Instalação

## Windows (recomendado)

Estás a usar um sistema operativo Windows?

Prime `Windows Key`, escreve `cmd` e prime `enter`.

> O Batch já está instalado no teu sistema se o teu sistema operativo for o Windows.

Se estás a usar um sistema operativo diferente, podes instalar o Batch seguindo as instruções abaixo.

## Mac OS

1. O Gatekeeper não pode estar configurado para bloquear pacotes não assinados.
2. Abre a aplicação Terminal.
3. Corre o seguinte comando para instalar o Batch:

```bash
brew install --cask --no-quarantine wine-stable
```

## Ubuntu

1. Se o teu sistema for de 64 bits, ativa a arquitetura de 32 bits (se ainda não o fizeste):

```bash
sudo dpkg --add-architecture i386
```

2. Adiciona o repositório do WineHQ:

```bash
sudo mkdir -pm755 /etc/apt/keyrings
sudo wget -O /etc/apt/keyrings/winehq-archive.key https://dl.winehq.org/wine-builds/winehq.key
sudo apt update
```

3. Instala o WineHQ:

```bash
sudo apt install --install-recommends winehq-stable
```

## Fedora

1. Ativa o repositório do Wine:

```bash
# Fedore 39
dnf config-manager --add-repo https://dl.winehq.org/wine-builds/fedora/39/winehq.repo

# Fedora 40
dnf config-manager --add-repo https://dl.winehq.org/wine-builds/fedora/40/winehq.repo
```

2. Instala o WineHQ:

```bash
dnf install winehq-stable
```
