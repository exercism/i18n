# usa interpolação de strings, não concatenação de strings

Usa a [interpolação de strings](https://csharp.net-tutorials.com/operators/the-string-interpolation-operator/) para construir uma string dinamicamente, em vez de recorreres à concatenação de strings. A principal vantagem é haver menos «ruído»: enquanto a concatenação de strings exige que se acrescente `+` entre cada string, a interpolação de strings não tem essa limitação. Por isso, o código com interpolação de strings costuma ser um pouco mais fácil de ler.
