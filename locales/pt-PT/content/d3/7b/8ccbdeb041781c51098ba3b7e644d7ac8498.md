# Dicas

## 1. Acompanhar as rondas de poker

- A função [`list`][list] devolve uma lista composta pelos argumentos que lhe são passados.

## 2. Manter todas as rondas no mesmo sítio

- A função [`concat`][concat] pode ser usada para concatenar duas listas.

## 3. Encontrar rondas anteriores

- A função [`some`][some] devolve o primeiro valor logicamente verdadeiro de uma coleção.
- A função [`boolean`][boolean] é útil nos casos em que uma função devolve um valor, mas os testes esperam um boolean.

## 4. Calcular a média dos valores das cartas

- Recorda-te dos operadores aritméticos básicos, como [`/`][division] e [`+`][addition].
- Uma coleção de números pode ser somada com [`apply`][apply] ou [`reduce`][reduce].
- A função [`count`][count] devolve o número de itens de uma coleção.
- A função [`/`][division] devolve um tipo ratio quando opera sobre inteiros. Podes usar [`double`][double] para converter um ratio num decimal.

## 5. Médias alternativas

- Existem funções de sequência para devolver o [`first`][first] ou o [`last`][last] elemento de uma coleção sequencial.
- Para encontrares a carta do meio, podes dividir o número de cartas por 2, arredondar para o inteiro mais baixo com [`int`][int] e obter a carta nesse índice com [`nth`][nth].
- Usa [`or`][or] para determinar se uma das condições é verdadeira.

## 6. Mais técnicas de cálculo de médias

- Uma forma de obter as cartas em índices pares/ímpares seria fazer [`map`][map] de uma função com [`nth`][nth] sobre um [`range`][range], que aceita um argumento `step` opcional.

## 7. Regras da ronda bónus

- Recorda-te de como usar [`if`][if] do exercício sobre condicionais.
- Podes devolver todos os itens de uma coleção exceto o último com [`butlast`][butlast].
