# CLI

## Submeter a solução

Quando já não houver testes ignorados e estiverem todos a passar, podes submeter a tua solução com `exercism submit numbers.js`.

## Submeter soluções incompletas

É possível submeter uma solução incompleta para poderes ver como outras pessoas completaram o exercício.
