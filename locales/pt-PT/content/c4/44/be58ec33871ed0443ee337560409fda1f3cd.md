# Introdução

## Números

O ABAP tem vários tipos numéricos. Neste exercício, vais usar dois deles:

- `i` para valores inteiros, como um número de dias.
- `p` para valores decimais empacotados, como um valor por hora ou um desconto.

```abap
DATA billable_days TYPE i VALUE 22.
DATA rate_per_hour TYPE p LENGTH 8 DECIMALS 2 VALUE '89.89'.
```

Os números empacotados definem o seu comprimento máximo e o número de casas decimais.
Os literais decimais são habitualmente escritos como valores de texto e convertidos para o tipo decimal de destino pelo compilador ou com `CONV`.

```abap
TYPES discount_rate TYPE p LENGTH 8 DECIMALS 6.

DATA discount TYPE discount_rate.
discount = CONV discount_rate( '0.15' ).
```

### Arredondamento

O ABAP disponibiliza funções numéricas incorporadas para arredondamento.
A função `floor` arredonda para baixo até ao número inteiro mais próximo, e a `ceil` arredonda para cima até ao número inteiro mais próximo.

```abap
DATA full_months TYPE i.
full_months = floor( 70 / 22 ).

DATA rounded_cost TYPE i.
rounded_cost = ceil( '14527.2' ).
```

## Operadores Aritméticos

O ABAP suporta operadores aritméticos para cálculos com valores numéricos.

```abap
DATA day_rate TYPE p LENGTH 8 DECIMALS 2.
day_rate = rate_per_hour * 8.
```

Os operadores básicos são:

- `+` para a adição.
- `-` para a subtração.
- `*` para a multiplicação.
- `/` para a divisão.
- `MOD` para o resto de uma divisão inteira.

```abap
DATA remaining_days TYPE i.
remaining_days = num_days MOD 22.
```

O ABAP avalia a multiplicação e a divisão antes da adição e da subtração.
Podes usar parênteses para tornar explícita a ordem pretendida.

```abap
DATA discounted_rate TYPE p LENGTH 8 DECIMALS 2.
discounted_rate = monthly_rate * ( 1 - discount ).
```
