# Introdução

A _sobrecarga de métodos_ permite que vários métodos da mesma classe tenham o mesmo nome. Os métodos sobrecarregados têm de se distinguir entre si de uma das seguintes formas:

- Pelo número de parâmetros
- Pelo tipo dos parâmetros

Não existe sobrecarga de métodos com base no tipo devolvido.

O compilador infere automaticamente qual dos métodos sobrecarregados deve chamar, com base no número de parâmetros e no tipo destes.
