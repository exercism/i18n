# Apêndice às instruções

## Registos

| Registo | Utilização            | Tipo    | Descrição                                          |
| -------- | -------------------- | ------- | -------------------------------------------------- |
| `$a0`    | valor de entrada     | inteiro | número de algarismos de entrada                    |
| `$a1`    | valor de entrada     | inteiro | base dos algarismos de entrada                     |
| `$a2`    | valor de entrada     | inteiro | base dos algarismos de saída                       |
| `$a3`    | valor de entrada/saída | endereço | array de palavras de algarismos que pode ser sobrescrito |
| `$v0`    | valor de saída       | inteiro | número de algarismos de saída, -1 se o valor de entrada for inválido |
| `$t0-9`  | temporário           | qualquer | usado para armazenamento temporário                |
