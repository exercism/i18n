# Sobre

Quando os tipos não podem ser convertidos implicitamente, tens de usar um [operador de conversão explícita][cast-operator].
O operador de conversão não é mais do que o tipo de destino entre parênteses antes do valor que queres converter:

```csharp

int i = 7;
byte b = (byte)i; // Explicit cast from int to byte
```

Usar uma conversão explícita é potencialmente perigoso. Os dois erros mais comuns são:

- Converter para um tipo incompatível. Isto vai lançar uma exceção em tempo de execução.
- Converter para um valor numérico que é insuficientemente "largo". Isto pode resultar num conflito de sinal ou, no caso dos números inteiros, numa exceção de overflow.

Nota: uma expressão do tipo `int` pode ser convertida explicitamente para `char`. Isto pode resultar num `char` inválido.

[cast-operator]: https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/operators/type-testing-and-cast#cast-expression
