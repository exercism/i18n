# Sobre

As [strings verbatim][verbatim-strings] permitem strings com várias linhas. São introduzidas com um @. Podem ser usadas com interpolação de strings. Basta acrescentar um "\$" antes da aspa de abertura.

```csharp
string str = @"
See no wretched
quotes everywhere
";
```

[verbatim-strings]: https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/strings/#regular-and-verbatim-string-literals
