# Apêndice às instruções

## Definir um tipo indutivo

Este exercício espera que o valor devolvido seja um [tipo indutivo][inductive] `Classification` que tens de definir.

Este tipo tem de ter uma instância de [BEq][beq], ou seja, tem de admitir um teste de igualdade Boolean, e uma instância de [Repr][repr], ou seja, os valores do tipo podem ser formatados para apresentação.

Podes consultar [esta página][instance] sobre declarações de instâncias.
O Lean consegue [gerar instâncias][deriving] automaticamente para muitas classes.

## Subtipos

O argumento da função `classify` é um [subtipo][subtype] chamado `Positive`:

```
def Positive := { x : Nat // x > 0 }
```

Os subtipos representam elementos de um determinado tipo que satisfazem um predicado.
`Positive` representa os elementos de `Nat` que são maiores que `0`.

Qualquer elemento de um subtipo pode ser visto como um par formado por um valor do tipo subjacente e uma prova, no sentido matemático, de que esse valor satisfaz o predicado correspondente.

Os subtipos impõem invariantes ao nível do tipo, garantindo que não é possível construir valores mal formados.
