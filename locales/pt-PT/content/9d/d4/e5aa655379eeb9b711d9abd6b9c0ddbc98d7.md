# Instruções

Neste exercício, vais implementar uma forma de acompanhar as pontuações mais altas do jogo mais popular do teu salão de jogos local.

## 1. Adicionar jogadores ao quadro de pontuações

Para adicionar um(a) jogador(a) ao quadro de pontuações, define dois métodos `add_player!` que recebem os seguintes argumentos:

- O primeiro argumento é o dicionário de pontuações.
- O segundo argumento é o nome de um(a) jogador(a), como string.
- O terceiro argumento é a pontuação, como número inteiro.
  Este argumento é opcional: quando não é indicado nenhum valor, a pontuação deve ser definida como 0.

```julia-repl
julia> scores = Dict{String, Int}()
Dict{String, Int64}()

julia> add_player!(scores, "Liselot", 486373)
Dict{String, Int64} with 1 entry:
  "Liselot" => 486373

julia> add_player!(scores, "Éimhín")
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0
```

## 2. Remover jogadores do quadro de pontuações

Para remover um(a) jogador(a) do quadro de pontuações, define `remove_player!`, que recebe 2 argumentos:

- O primeiro argumento é o dicionário de pontuações.
- O segundo argumento é o nome do(a) jogador(a), como string.

```julia-repl
julia> scores = Dict(
           "Liselot" => 486373,
           "Éimhín"  => 0,
       )
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0

julia> remove_player!(scores, "Liselot")
Dict{String, Int64} with 1 entry:
  "Éimhín" => 0
```

## 3. Atualizar a pontuação de um(a) jogador(a)

Para atualizar a pontuação de um(a) jogador(a) substituindo a pontuação anterior, define `update_score!`, que recebe 3 argumentos:

- O primeiro argumento é o dicionário de pontuações.
- O segundo argumento é o nome do(a) jogador(a), como string, cuja pontuação queres atualizar.
- O terceiro argumento é a pontuação que queres guardar como nova pontuação mais alta.

```julia-repl
julia> scores = Dict(
           "Liselot" => 486373,
           "Éimhín"  => 0,
       )
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0

julia> update_score!(scores, "Éimhín", 89479) # TODO: Should this return the dict?
89479

julia> scores
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 89479
```

## 4. Reiniciar a pontuação de um(a) jogador(a)

Para reiniciar a pontuação de um(a) jogador(a), define `reset_score!`, que recebe 2 argumentos:

- O primeiro argumento é o dicionário de pontuações.
- O segundo argumento é o nome do(a) jogador(a), como string, cuja pontuação queres reiniciar.

```julia-repl
julia> scores = Dict(
           "Liselot" => 486373,
           "Éimhín"  => 0,
       )
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0

julia> reset_score!(scores, "Liselot") # TODO: Should this return the dict?
0

julia> scores
Dict{String, Int64} with 2 entries:
  "Liselot" => 0
  "Éimhín"  => 0
```

## 5. Obter uma lista de jogadores

Para obteres uma lista de jogadores, define `players`, que recebe 1 argumento:

- O primeiro argumento é o dicionário de pontuações.

```julia-repl
julia> scores = Dict(
           "Liselot" => 486373,
           "Éimhín"  => 0,
       )
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0

julia> players(scores)
2-element Vector{String}:
 "Liselot"
 "Éimhín"
```
