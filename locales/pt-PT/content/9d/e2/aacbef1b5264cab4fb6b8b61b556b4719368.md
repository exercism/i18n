# Testes

Um REPL de ClojureScript permite-te executar código com facilidade e obter feedback imediato, e também podes usá-lo para correr testes.

## Leiningen
Para abrir um REPL com a Clojure CLI, entra no diretório que contém o exercício e executa:
``` bash
$ clojure -m cljs.main -re node
```

Tem em atenção que o Node tem de estar instalado no teu sistema.

Quando estiveres pronto para trabalhar num exercício e tiveres criado um ficheiro para guardar a tua solução (como `bob.cljs`), podes correr os testes no terminal com `$ clojure -A:test`.

Primeiro, faz `require` do namespace de teste:
``` clojure
=> (require 'bob-test)
nil
;; and the test namespace
=> (require 'cljs.test)
```

Muda o ns para o namespace de teste:
```clojure
=> (ns bob-test)
nil
```

Depois, chama `run-tests` sobre `bob-test`:
``` clojure
=> (cljs.test/run-tests)

Testing bob-test

Ran 14 tests containing 14 assertions.
0 failures, 0 errors.
{:test 14, :pass 14, :fail 0, :error 0, :type :summary}
```

Para correr os testes de um exercício com a Clojure CLI, basta chamar:
``` bash
$ clojure -M:test

Testing bob-tests

Ran 14 tests containing 14 assertions.
0 failures, 0 errors.
```
