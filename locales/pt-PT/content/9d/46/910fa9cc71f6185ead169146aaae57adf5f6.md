# Aprender

- [The Zig Programming Language Documentation][documentation] é uma excelente visão geral de todas as funcionalidades da linguagem que o Zig oferece a quem o usa.
- [Awesome Zig][awesome-zig] é uma boa coleção de projetos Zig feitos por várias pessoas.
  A coleção inclui projetos com código Zig bem desenvolvido.
- [Zighelp][zighelp] é uma excelente introdução que explica as funcionalidades da linguagem que o Zig tem para oferecer.
- [Ziglings][ziglings] é altamente recomendado.
  Aprende Zig corrigindo pequenos programas com erros.
- [Zig SHOWTIME][zig-showtime] é um programa transmitido em direto, onde membros da comunidade Zig partilham código e ideias.

[awesome-zig]: https://github.com/catdevnull/awesome-zig
[documentation]: https://ziglang.org/documentation/master/
[zighelp]: https://zighelp.org/
[zig-showtime]: https://zig.show/
[ziglings]: https://codeberg.org/ziglings/exercises
