# sem type alias para o cronómetro

Neste exercício, deves definir `Stopwatch` como um tipo opaco.
Usar `type alias Stopwatch` define `Stopwatch` como um type alias, o que expõe a sua estrutura interna.
Em vez disso, usa `type Stopwatch` para esconder a estrutura interna e impedir que outros módulos desconstruam ou atualizem diretamente os valores de `Stopwatch`.
