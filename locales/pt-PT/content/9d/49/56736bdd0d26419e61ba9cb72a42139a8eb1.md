# Dicas

## 1. Obter uma carta de uma pilha

- Os índices de `Vector` começam em `1`.
- Podes obter o `n`-ésimo valor de um vetor `v` com `v[n]`.

## 2. Trocar uma carta na pilha

- Os `Vector`s são mutáveis: podes alterar o seu conteúdo a qualquer momento atribuindo um novo valor.

## 3. Inserir uma carta no topo da pilha

- Existe um método [`push!`][push] em Base para adicionar um novo valor ao fim de uma coleção.

## 4. Remover uma carta da pilha

- Existe um método [`deleteat!`][deleteat] em Base para eliminar um elemento de um `Vector` num determinado índice.

## 5. Remover a carta do topo da pilha

- Existe um método [`pop!`][pop] em Base para remover um elemento no fim de uma coleção.

## 6. Inserir uma carta no fundo da pilha

- Existe um método [`pushfirst!`][pushfirst] em Base para inserir um novo valor no início de uma coleção.

## 7. Remover uma carta do fundo da pilha

- Existe um método [`popfirst!`][popfirst] em Base para remover um elemento no início de uma coleção.

## 8. Verificar o tamanho da pilha

- Existe um método [`length`][length] em Base para obter o comprimento de uma coleção.
