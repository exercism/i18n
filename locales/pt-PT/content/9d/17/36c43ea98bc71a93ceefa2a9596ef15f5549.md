# Introdução

Quando modelas dados que só podem assumir um conjunto específico de estados possíveis, como os dias da semana, as direções da bússola ou os botões de um comando, os tipos básicos como `Int` ou `String` têm grandes desvantagens.
Com inteiros ou strings, o teu código tem de verificar constantemente se há valores inválidos (como um código de estado `999` ou um erro de escrita como `"leftt"`), e quem lê o código não consegue perceber facilmente o que os números representam.

O Swift resolve este problema com as [_Enumerações_][enumerations] (muitas vezes abreviadas para *enums*).
Uma enumeração define um tipo comum para um conjunto de valores relacionados e com nome. Como o compilador conhece todos os casos possíveis de antemão, pode verificar a exatidão e a completude do teu código em tempo de compilação.
As enumerações também podem ter métodos, inicializadores e propriedades calculadas.

## Definir enumerações

Para definir uma enumeração, usa a palavra-chave `enum` seguida do nome do tipo, com os casos indicados dentro de chavetas.
Por convenção do Swift, o nome do tipo usa `UpperCamelCase`, enquanto cada caso usa `lowerCamelCase`:

```swift
enum NESButton {
    case up
    case down
    case left
    case right
    case a
    case b
    case select
    case start
}
```

Também podes definir vários casos numa única linha, separados por vírgulas:

```swift
enum NESButton {
    case up, down, left, right, a, b, select, start
}
```

Para te referires a um caso de uma enumeração, escreve o nome do tipo da enumeração, um ponto (`.`) e o nome do caso. Quando o tipo é conhecido ou pode ser inferido pelo compilador, podes omitir o nome do tipo e usar a sintaxe abreviada com o ponto:

```swift
var lastPressed = NESButton.up

// Swift infers the type, so you can omit the type name:
lastPressed = .down

let konamiCode: [NESButton] = [.up, .up, .down, .down, .left, .right, .left, .right, .b, .a]
```

## Métodos e inicializadores

As enumerações podem definir métodos e inicializadores personalizados tal como as classes e as estruturas. Dentro de um método de uma enumeração, `self` refere-se ao valor do caso atual:

```swift
enum Coin {
    case heads
    case tails

    init(_ value: Int) {
        if value.isMultiple(of: 2) {
            self = .heads
        } else {
            self = .tails
        }
    }

    func flip() -> Coin {
        switch self {
        case .heads: return .tails
        case .tails: return .heads
        }
    }
}

let tails = Coin(13)     // .tails
let heads = Coin(0)      // .heads
let flipped = heads.flip() // .tails
```

## Valores brutos

Os casos de uma enumeração podem ser preenchidos previamente com valores predefinidos chamados [_valores brutos_][raw-values].
Todos os valores brutos de uma enumeração têm de ser do mesmo tipo (como `Int`, `String` ou `Character`):

```swift
enum NESButton: Character {
    case up = "⬆️"
    case down = "⬇️"
    case left = "⬅️"
    case right = "➡️"
    case a = "🅰️"
    case b = "🅱️"
    case select = "✅"
    case start = "🚦"
}

print(NESButton.left.rawValue) // Prints "⬅️"
```

Podes inicializar uma enumeração a partir de um valor bruto com `init(rawValue:)`. Como pode ser fornecido um valor bruto inválido, este inicializador devolve um opcional:

```swift
let upButton = NESButton(rawValue: "⬆️") // Optional(NESButton.up)
let invalid = NESButton(rawValue: "🙄")  // nil
```

O Swift pode atribuir automaticamente valores brutos a enumerações de `String` e de `Int`:

- Nas enumerações de `String`, o valor bruto de cada caso é, por predefinição, o nome do caso.
- Nas enumerações de `Int`, os valores brutos começam em `0` e aumentam de 1 em 1, salvo indicação em contrário.

```swift
enum Planet: Int {
    case mercury = 1, venus, earth, mars
}

print(Planet.earth.rawValue) // Prints 3
```
