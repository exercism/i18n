# Instalação

Para estes problemas, usamos o popular simulador MIPS [MARS](https://dpetersanderson.github.io/Help/MarsHelpIntro.html). Descarrega o arquivo jar do MARS a partir do [GitHub](https://github.com/dpetersanderson/MARS/releases) e coloca-o num local de fácil acesso. Instala também o Java SDK, caso ainda não o tenhas.
