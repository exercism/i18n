# Introdução

## Conversão explícita

A conversão explícita e a conversão de tipos são duas formas diferentes de passar uma expressão de um tipo de dados para outro.

Uma expressão pode ser convertida para outro tipo com o operador de conversão `(<type>)`.

```csharp
long l = 1000L;
int i = (int)l;

object o = new Random();
Random r = (Random)o;
```

Se os tipos não forem compatíveis, é lançada uma instância de `InvalidCastException`. No caso dos números, isto indica que o tipo de destino não consegue representar o valor convertido. No caso das classes, um dos tipos tem de derivar do outro (o que também se aplica, de forma trivial, às structs).

Uma alternativa à _conversão explícita_ é a _conversão de tipos_ com o operador `is`. Esta aplica-se tipicamente a tipos de referência e a tipos anuláveis.

```csharp
object o = new Random();
if (o is Random rand)
{
    int ii = rand.Next();
    // now, do something random
}
```

Se precisares de detetar o tipo exato de um objeto, o `is` pode ser demasiado permissivo, uma vez que devolve true para uma classe e para qualquer uma das classes e interfaces das quais ela deriva, direta ou indiretamente. Neste caso, a solução passa por `typeof` e `Object.GetType()`.

```csharp
object o = new List<int>();

o is ICollection<int> // true
o.GetType() == typeof(ICollection<int>) // false
o is List<int> // true
o.GetType() == typeof(List<int>) // true
```
