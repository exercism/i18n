# Instructions

Neste exercício vais escrever código para ajudar uma empresa de letreiros a criar mensagens personalizadas para os seus letreiros.

## 1. Cria um conjunto de strings úteis

Define as seguintes strings constantes que serão usadas para criar letreiros:

- `birthday`: Contém o valor "Birthday"
- `valentine`: Contém o valor "Valentine's Day"
- `anniversary`: Contém a string "Anniversary"

## 2. Cria um conjunto de carateres úteis

Define os seguintes carateres constantes que serão usados para criar letreiros:

- `space`: Contém o valor " " (um único espaço)
- `exclamation`: Contém o valor "!"

## 3. Combina frases para construir mensagens

Implementa a função `buildSign(for:name:)`, que recebe o argumento `for`, que contém uma das três strings que definiste na primeira tarefa, e o argumento `name`, que é uma string que contém o nome da pessoa a quem o letreiro se destina.
Deves usar concatenação para construir a mensagem do letreiro e lembra-te de reutilizar as constantes já definidas.
A função deve devolver a mensagem do letreiro como string.

```swift
buildSign(for: birthday, name: "Otto")
// returns "Happy Birthday Otto!"

buildSign(for: anniversary, name: "Valentina")
// returns "Happy Anniversary Valentina!"
```

## 4. Cria um letreiro de graduação

Implementa a função `graduationFor(name:year:)`, que recebe o argumento `name`, uma string que contém o nome da pessoa a quem o letreiro se destina, e o argumento `year`, um inteiro que contém o ano de graduação da pessoa.
Deves usar strings de modelo para construir a mensagem do letreiro.
A função deve devolver a mensagem do letreiro como string.

```swift
graduationFor(name: "Padma", year: 2023)
// returns "Congratulations Padma!\nClass of 2023"
```

## 5. Calcula o custo de um letreiro

Implementa a função `costOf(sign:)`, que recebe o argumento `sign`, uma string que contém a mensagem do letreiro.
O letreiro tem um preço base de 20 na moeda indicada. Além disso, cada letra custa 2 (os espaços em branco são incluídos no cálculo).
A função deve devolver o custo do letreiro como um inteiro.

```swift
costOf(sign: "Happy Birthday Grandma!")
// returns 66
```
