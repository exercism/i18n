# Sobre

A "estatística" é um tema vasto e complexo, com muitas vertentes.

Algumas dessas vertentes foram abordadas no conceito [`Randomness`][randomness], que é um tema separado mas relacionado.

Na sua forma mais simples, a estatística pode envolver formas de resumir uma coleção iterável de dados num único valor.
Quem está a começar com Julia pode surpreender-se com o quão poucas funções a linguagem traz incorporadas por omissão:

- [`sum`][sum], para somar números.
- [`min`][min] e [`max`][max], para obter os valores extremos dos parâmetros indicados.
- [`extrema`][extrema], para obter o tuplo (min, max) de um iterável.
- [`length`][length], para contar todos os valores.
- [`count`][count], para contar apenas os valores que cumprem determinado critério.

```julia-repl
julia> v = collect(1:0.2:3)
11-element Vector{Float64}:
 1.0
 1.2
 ... # display truncated
 3.0

julia> mean(v)
2.0

julia> extrema(v)
(1.0, 3.0)

julia> length(v)
11

julia> min('g', 'a', 'c')
'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)

julia> count(isodd, 1:5)  # 1, 3, and 5 are odd
3
```

Este conjunto limitado de funções é uma decisão deliberada para minimizar o inchaço da Julia base, passando outras funções para uma cascata de outros módulos e pacotes.

## O módulo `Statistics`

Como faz parte da biblioteca padrão, é provável que o [`Statistics`][statistics] já venha pré-instalado. Por isso, basta acrescentar `using Statistics` no início do programa para o trazer para o espaço de nomes.

Este módulo contém o nível seguinte de funções comuns, que provavelmente serão amplamente usadas por um subconjunto de programadores.

Muitas das funções do `Statistics` pressupõem alguns conhecimentos de base sobre o tema.
Os exemplos mais simples incluem:

- [`mean`][mean], aquilo a que muitas pessoas chamariam média (o mesmo resultado que `sum / length`).
- [`median`][median], o valor do meio depois de ordenar.
- [`std`][std], [desvio padrão][stddev]: uma medida de quão dispersos estão os valores.
- [`var`][var], variância: o quadrado do `std`, que em geral é mais rápido de calcular.

Cada função costuma ter várias opções, e há _muitas_ mais funções. Se tiveres interesse, consulta a [documentação][statistics].
