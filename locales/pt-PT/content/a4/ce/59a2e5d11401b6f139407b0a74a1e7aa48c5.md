# camelCase

[comment]: # "Este erro é gerado quando uma variável/tipo não usa camelCase/PascalCase"
[comment]: # "requer 2 parâmetros:"
[comment]: # "- wrong: nome com a capitalização errada"
[comment]: # "- correct: nome com a capitalização correta"

A comunidade Elm tem uma forte preferência por usar camelCase nos nomes de variáveis e PascalCase nos tipos.

Encontrámos o nome `%{wrong}`, que deve ser substituído por `%{correct}`.
