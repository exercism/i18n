# Introdução

A forma especial `import` permite-te usar funções de um módulo externo sem usar o nome do módulo.

Importar um módulo externo inteiro pode criar conflitos com funções locais já existentes. Para evitar isto, há duas opções disponíveis: `:except` e `:only`. Ambas esperam uma lista de palavras-chave, em que a chave é o nome da função e o valor é a aridade da função.

Normalmente, as importações são adicionadas no início da definição do módulo.

```elixir
defmodule Square do
  import Integer, only: [pow: 2]

  def area(a), do: pow(a, 2)
end
```
