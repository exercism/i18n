# Acerca de

[A sobrecarga de métodos][method-overloading] é um conceito fundamental em Java, que permite que uma classe tenha mais do que um método com o mesmo nome, desde que cada método tenha uma lista de parâmetros diferente.
Esta funcionalidade é um aspeto fundamental da programação orientada a objetos do Java e proporciona uma forma de realizar operações semelhantes com diferentes tipos ou números de parâmetros de entrada.
A sobrecarga de métodos melhora a legibilidade e a organização do código, ao permitir que métodos que desempenham funções semelhantes partilhem o mesmo nome.
É importante notar que a sobrecarga é determinada pela assinatura do método, que inclui o nome do método e a lista de parâmetros.

## Pontos-chave

- **A assinatura é o que conta**: o tipo de retorno não faz parte da assinatura do método, por isso mudar apenas o tipo de retorno de um método não constitui sobrecarga.
- **Diferenças nos parâmetros**: os métodos sobrecarregados têm de diferir no número ou no tipo de parâmetros.
- **Utilização**: a sobrecarga é frequentemente usada para oferecer formas mais intuitivas de usar um método com diferentes tipos de valores de entrada.

## Exemplos de sobrecarga de métodos

Considera uma classe `Calculator` capaz de somar números.
A sobrecarga permite diferentes tipos de operações de soma:

```java
public class Calculator {

    public int add(int a, int b) {
        return a + b;
    }

    public double add(double a, double b) {
        return a + b;
    }

    public int add(int a, int b, int c) {
        return a + b + c;
    }
}
```

## Boas práticas

- **Clareza**: os métodos sobrecarregados devem ser usados de forma a tornar o código mais intuitivo.
  - O comportamento dos métodos sobrecarregados deve ser relacionado e consistente.
- **Evitar a ambiguidade**: certifica-te de que cada método sobrecarregado tem um propósito claro e que as diferenças nas listas de parâmetros são suficientemente significativas para evitar confusão.
- **Documentação**: documenta devidamente cada versão dos métodos sobrecarregados.
  - Uma documentação clara ajuda outros programadores a compreender o propósito e a utilização de cada variante do método.
- **Tipos de retorno consistentes**: embora os tipos de retorno possam variar nos métodos sobrecarregados, é geralmente uma boa prática mantê-los consistentes sempre que possível, para evitar confusão.
- **Limitar a sobrecarga**: evita abusar da sobrecarga de métodos.
  - O excesso de sobrecarga pode tornar o código mais difícil de ler e de manter.

## Conclusão

A sobrecarga de métodos é uma funcionalidade poderosa do Java que, quando usada corretamente, pode melhorar bastante a legibilidade e a flexibilidade do teu código.
Permite que os métodos sejam mais versáteis e se adaptem a contextos diferentes, tornando os teus programas Java mais modulares e mais fáceis de manter.
