# Nulo

É um tipo de valor primitivo com um único valor: `null`.
É frequentemente usado para representar o nada.
É considerado «falso», mas é distinto de `false` e de outros valores falsos.

```php
<?php

is_null(null); // => true
isset(null); // => false

null == true; // => false
null === true; // => false

null == false; // => true
null === false; // => false
```

## Trabalhar com valores nulos

Em PHP, os valores nulos podem ser uma causa comum de erro, uma vez que são frequentemente devolvidos em vez de um estado de erro ou para representar o nada.
Evitar que surjam erros exige muitas vezes uma «verificação de nulos» para confirmar que o valor não é nulo antes de o utilizar.

```php
<?php

$value = null;

$value->doSomething(); // throws an error as a null value is not an object instance.

if (!is_null($value)) {
    $value->doSomething(); // succeeds
}
```

A verificação repetida de nulos pode ser propensa a erros, por isso o PHP fornece dois operadores para trabalhar com valores nulos: o operador de acesso seguro a nulos `?->` e o operador de coalescência de nulos `??`.

```php
<?php

$value = null;
$result = $value?->doSomething(); // => return null rather than error
$result = $result ?? "default"; // => "default" is assigned to $result
```
