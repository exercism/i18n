# Introdução

Em Clojure, associar um valor a um nome designa-se por _var_. As vars de topo (globais) são semelhantes a constantes noutras linguagens, mas são habitualmente redefinidas para facilitar o desenvolvimento dinâmico.

As vars de topo definem-se com `def`:

```clojure
(def fingers 10)
```

A macro `defn` pode ser usada para definir uma função que recebe zero ou mais argumentos. Uma função devolve sempre o resultado da última expressão do seu corpo.

```clojure
(defn add [x y]
  (+ x y))
```

Para invocar uma função, indicas o nome dela e passas um argumento para cada um dos parâmetros da função.

```clojure
(def five (add 2 3))
```

Em Clojure, só podes usar funções e valores _depois_ de estarem definidos. Usá-los antes de estarem definidos dá origem a um erro de compilação.

```clojure
;; Compile error as `add` has not yet been defined
(def seven (add 3 4))

(defn add [x y]
  (+ x y))
```

Em Clojure, os espaços em branco não têm qualquer significado além da formatação.

As funções e as vars de Clojure organizam-se em namespaces. Um namespace agrupa funcionalidade relacionada e é definido com a macro `ns`:

```clojure
(ns calculator)

(def pi 3.14)

(defn add [x y]
  (+ x y))
```

Clojure suporta dois tipos de comentários. Os comentários de uma linha são precedidos por `;` e a forma `comment` serve para impedir a avaliação de tudo o que está entre `(comment` e `)`.
