# Dicas

## Geral

- Existem três operadores lógicos '!`(logical NOT), '||` (OU lógico) e `&&` (E lógico) quando trabalhas com valores Boolean.
- É possível combinar vários operadores numa única expressão.

## 1. Verifica se é possível fazer um ataque rápido

- O operador lógico NÃO (`!`) pode ser colocado antes de uma expressão para negar o seu valor.

## 2. Verifica se é possível espiar o grupo

- Os operadores lógicos são habitualmente usados para avaliar se duas ou mais expressões são verdadeiras ou não.

## 3. Verifica se é possível dar sinal ao prisioneiro

- Os operadores lógicos executam-se pela ordem da sua precedência (da mais alta para a mais baixa): `!`, `&&`, `||`.
