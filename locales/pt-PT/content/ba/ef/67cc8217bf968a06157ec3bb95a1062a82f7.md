# Dicas

## 1. Criar uma nova lista

- O Common Lisp tem uma [função com um nome bastante descritivo][hyper-list] para criar uma _LIST_.

## 2. Adicionar coisas à lista.

- Para adicionar algo ao início de uma lista, o idiomático é *CONS*truir uma nova lista com o item como `car` e a lista como `cdr`. Na Hyperspec podes encontrar uma [página][hyper-cons] que descreve esta função.

## 3. Qual é a próxima coisa (ou coisas) da lista?

- O Common Lisp tem uma função de uso geral para obter um elemento [a partir de qualquer índice de uma lista][hyper-nth].
- Também tem [vários auxiliares][hyper-first-tenth] para aceder a índices abaixo de 11
- Os índices das listas começam em zero.

## 4. Remover uma coisa da lista.

- Uma forma idiomática de remover o primeiro elemento de uma lista é usar uma função que consegue separar o `cdr` da lista do `car` da lista. Na Hyperspec encontras uma [página][hyper-rest] que descreve uma das funções que fazem isto.

## 5. Listas maiores a partir de listas mais pequenas

- O Common Lisp tem uma função [especificamente para adicionar uma lista à frente de outra][hyper-append]

## 6. Quanto mais comprida?

- O Common Lisp tem uma função [de nome óbvio][hyper-length] para obter o comprimento de uma lista.
