# Instruções

Estás a dar as deixas para o espetáculo da tua escola. O diretor de cena
quer as falas padrão escritas para que qualquer pessoa consiga operar a mesa.

Tens quatro tarefas, todas na classe `STAGE_DIRECTIONS`.

## 1. Anuncia o início

Devolve a fala que abre o espetáculo.

```sather
STAGE_DIRECTIONS::opening_line
-- => "The curtain rises."
```

## 2. Anuncia o intervalo

Devolve a fala que é anunciada ao intervalo.

```sather
STAGE_DIRECTIONS::interval_line
-- => "Interval. Fifteen minutes."
```

## 3. Anuncia o fim

Devolve a fala que fecha o espetáculo.

```sather
STAGE_DIRECTIONS::closing_line
-- => "The curtain falls."
```

## 4. Dá a deixa final

A deixa final é a mesma fala que fecha o espetáculo. Em vez de escreveres
o texto outra vez, chama a rotina que já escreveste.

```sather
STAGE_DIRECTIONS::final_cue
-- => "The curtain falls."
```
