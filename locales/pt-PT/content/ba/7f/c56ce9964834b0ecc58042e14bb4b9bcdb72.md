# Introdução

Muitas linguagens têm uma forma como `null` ou `none` para indicar um valor inexistente.
Como o R foi concebido para lidar com grandes volumes de dados (muitas vezes desorganizados), tem várias formas de representar o nada.

O objetivo geral é assinalar valores em falta ou suspeitos à medida que são encontrados e, em seguida, continuar sem lançar uma exceção.

## NULL

Se um valor não existe realmente, é representado por `NULL`. Isto é provavelmente o mais próximo do que o C ou o Python fariam.

```R
v <- c() # zero-length vector
v
#> NULL
is.null(v)
#> [1] TRUE
```

Em muitos contextos, os valores `NULL` são simplesmente ignorados:

```R
c(2, 3, NULL, 5)
#> [1] 2 3 5
```

## NA

Para situações em que um valor existe, mas não sabemos qual é, usa-se `NA`. Por exemplo, ao contar veículos que circulam numa estrada, os observadores humanos podem ficar doentes ou os sensores automáticos podem avariar, mas o trânsito continua a fluir.

```R
v <- c(1, 2, NA, 4, 5)
v
#> [1]  1  2 NA 4  5
is.na(v) # test for data gaps
#> [1] FALSE FALSE  TRUE FALSE FALSE
```

Assim, `NA` é um marcador de posição, que avisa os humanos de que precisam de tomar uma decisão sobre como lidar com isto.

## Vetores vazios

Talvez surpreendentemente, o R não tem uma forma padrão de verificar se algo está vazio, embora alguns pacotes de terceiros implementem as suas próprias funções, como `is.empty()`.

Até gerar um vetor vazio não é assim tão óbvio.
Vimos numa secção anterior que `c()` sem argumentos devolve `NULL`, e não um vetor.

```R
is.vector(c())
#> [1] FALSE
```

Funções como `logical()` ou `integer()` recebem um argumento que especifica o comprimento desejado, que pode ser zero.

```R
z <- logical(0)
is.vector(z)
#> [1] TRUE
length(z)
#> [1] 0
```

Também podemos gerar um vetor e depois remover todos os elementos, como descrito no [Conceito de vetores][concept-vectors].
Isto resulta num vetor de comprimento 0, de um tipo adequado.

```R
v <- 5
v[-1]  # delete the first element
#> numeric(0)
```
