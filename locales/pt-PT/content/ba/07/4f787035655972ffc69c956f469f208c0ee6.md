# Introdução

Lembra-te de que um programa `jq` é um _pipeline de expressões_.
**A atribuição de variáveis** segue esta regra: uma _atribuição de variável_ é uma expressão com este aspeto:

```jq
... | expr as $varname | ...
```

## A saída do filtro é a entrada

Tal como a _expressão de identidade_ `.`, a saída de uma _atribuição de variável_ é igual à sua entrada.
Definir o valor da variável é um efeito secundário.

Exemplo, que mostra que o `.` depois da atribuição é a mesma coisa que a entrada inicial:

```sh
$ jq -c -n '42 | (. * 2) as $double | [., $double]'
[42,84]
```

## Âmbito da variável

O âmbito da variável é «lexical»: a variável fica no âmbito até ao fim do pipeline.
As variáveis definidas dentro de funções (chegaremos às funções mais adiante) são «locais» à função.

## Nomes de variáveis

A variável tem de começar por `$`.
O resto do nome da variável é um **identificador**: começa com uma letra ou um underscore, seguido de letras, números ou underscores.

## Atribuição por desestruturação

Do manual:

> É possível declarar várias variáveis com uma única expressão `as`, fornecendo um padrão que _corresponde à estrutura da entrada_ (a isto chama-se «desestruturação»).

Exemplos:

```jq
[1, 2, 3] as [$a, $b, $c]
| [$a, $b, $c]     # => [1, 2, 3]
```

```jq
{"foo": "bar", "len": [10, 20]} as {foo: $f, len: [$h, $w]}
| [$f, $h, $w]     # => ["bar", 10, 20]
```

Fazer corresponder o nome da variável à _chave do objeto_ oferece um atalho:

```jq
{"x": 4, "y": 7} as {$x, $y}
| [$x, $y]         # => [4, 7]
```

```jq
{"foo": "bar", "len": [10, 20]} as {$foo, $len}
| [$foo, $len]     # => ["bar", [10, 20]]
```

## Constantes

Como mostra o exemplo acima, as variáveis são úteis para guardar constantes.
É melhor dar um nome às constantes do que ter «números mágicos» a aparecer no código.

## Muitas vezes, as variáveis não são necessárias

Muitas vezes, o código fica mais legível se omitires as variáveis.

Considera calcular a média de uma lista de números

```jq
[2, 4, 8, 7]
| add as $sum
| length as $len
| $sum / $len
```

em comparação com

```jq
[2, 4, 8, 7] | add / length
```

Isto realça um dos aspetos mais poderosos do `jq`: a entrada de um filtro é fornecida a _todas_ as subexpressões:

- o array de entrada `[2,4,8,7]` é passado ao `add` (que soma os números aplicando o operador `+` a todos os elementos)
- _em paralelo_, `[2,4,8,7]` também é passado ao `length`
- quando estas subexpressões terminam, os seus resultados são divididos, devolvendo a média dos números do array de entrada.

## Operadores do `jq` de que vais precisar para o exercício de aprendizagem

### Operador alternativo: `//`

A expressão `a // b` produz `b` se `a` for false ou null; caso contrário, produz `a`.
No contexto de definir uma variável, isto é muito prático para fornecer um valor predefinido:

```jq
(.input.theAnswer // 42) as $answer | ...
```

### Operadores aritméticos

- `+`, `-` e `*` são os habituais operadores numéricos de adição, subtração e multiplicação.
