# Introdução

## Operador pipe

O operador `|>` chama-se operador pipe. Podes usá-lo para encadear chamadas de funções, de modo a que o valor devolvido pela chamada de função anterior seja passado à chamada de função seguinte.

```gleam
"hello"
|> string.uppercase
|> string.append("?!")
// -> "HELLO?!"
```

O código acima é equivalente ao seguinte:

```gleam
string.append(string.uppercase("hello"), "?!")
```

O operador pipe passa o valor como primeiro argumento da chamada de função, ou como único argumento de uma nova chamada, consoante a opção que tiver o tipo correto.

```gleam
100
|> function_that_takes_two_arguments(1)

// Is equivalent to
function_that_takes_two_arguments(100, 1)
```

```gleam
100
|> function_that_returns_a_function(1)

// Is equivalent to
function_that_returns_a_function(1)(100)
```

Por vezes queremos passar o valor para outra posição. Nesse caso, podemos usar o marcador `_` para indicar onde o valor deve ser inserido.

```gleam
100
|> some_function(1, _, 2)
```
