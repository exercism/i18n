# Introdução

## Formato - Noções básicas

O Common Lisp tem um conceito, o The Printer, que inclui todas as funções para escrever representações textuais de dados Lisp. Uma dessas funções é a `format`, que permite ao programador formatar os dados como quiser.

As capacidades da `format`, e do Printer de Lisp em geral, são um tema vasto; aqui vamos descrever as noções básicas da utilização da `format`.

### A função FORMAT

A função `format` recebe pelo menos dois argumentos: um fluxo para onde imprimir e uma string de controlo que define o que imprimir e como.

Os fluxos são um conceito à parte e serão descritos noutro lugar. Mas, para já, só precisas de saber que a impressão é feita para o fluxo e que há dois valores especiais para este argumento: `t` e `nil`. `t` significa imprimir para a saída padrão (na verdade, o fluxo ao qual está associada a variável `*standard-output*`), e `nil` significa criar uma string e devolvê-la.

Repara que a `format` é sempre avaliada como `nil`, exceto nesse último caso, em que `nil` é indicado como o fluxo. É uma forma comum de fazer simplesmente interpolação ou construção de strings.

```lisp
(format nil "hello world") ; => "hello world"
(format t "hello world")   ; => NIL (but "hello world" is printed to standard output)
```

### Diretivas de formato

A string de controlo pode conter "diretivas de formato", que dão instruções à `format` sobre o que imprimir e como interpretar os restantes parâmetros passados à `format`. De certa forma, a string de controlo é um programa que a `format` vai interpretar e executar. Todas as diretivas começam com `~` e são seguidas de um caráter (_por exemplo_, `~A`, `~D`, `~&`). Não importa se o caráter está em maiúscula ou em minúscula.

A maioria das diretivas de formato limita-se a interpolar na saída um dos argumentos da `format`. Diz-se que a diretiva "consome" o argumento. Algumas diretivas não consomem argumentos, ou consomem mais do que um. Há até uma diretiva que te permite saltar dentro da lista de argumentos ou ignorar argumentos.

### Formatação básica

Uma diretiva de formato muito versátil é a `~A`. Imprime uma versão 'legível por humanos' dos dados.

```lisp
(format nil "Value = ~a" 10)                ; => "10"
(format nil "hello ~a" "world")             ; => "hello world"
(format nil "The list is: ~A" (list 1 2 3)) ; => "The list is: (1 2 3)"
```

Outra diretiva de formato útil é a `~S`. Imprime uma versão 'legível por máquinas' dos dados. Isto pode ser muito útil se quiseres conseguir interpretar a saída produzida como dados Lisp. Para muitas coisas, o resultado é igual ao da `~A`, mas repara que, no caso das strings, por exemplo, a saída inclui as aspas (escapadas quando incluídas noutra string), para que o valor possa ser lido de volta como o parâmetro string.

```lisp
(format nil "~s" 10)            ; => "10"
(format nil "~s" "hello world") ; => "\"hello world\""
(format nil "~s" (list 1 2 3))  ; => "(1 2 3)"
```

Mais duas diretivas muito úteis são a `~%` e a `~&`. A primeira emite um caráter de nova linha, enquanto a segunda emite uma "linha nova". A diferença é que a `~%` emite sempre uma nova linha, ao passo que a `~&` só a emite se não estiveres já no início de uma linha. Nenhuma delas consome um argumento.

```lisp
(format nil "~%new~%lines") ; => "
                                  new
                                  lines"

(format nil "~&new~&lines"  ; => "new
                                  lines"
```

Por fim, a `~~` é uma diretiva simples que emite um `~` literal.
