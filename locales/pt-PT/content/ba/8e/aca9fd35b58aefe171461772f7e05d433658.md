# Correr os testes

Para correr o teste de um determinado exercício, entra na pasta com `cd` e corre o seguinte:

```bash 
box task run TestRunner
# Or start up a test watcher that will rerun when files change
box task run TestRunner --:watcher
```

Os testes recorrem a uma biblioteca chamada TestBox, que suporta testes no estilo xUnit e BDD. Todos os conjuntos de testes são escritos no [estilo BDD](https://testbox.ortusbooks.com/content/primers/bdd/specs.html), que usa closures para definir especificações de teste. Não precisas de te preocupar em instalar o TestBox. O executor de testes da CLI trata disso por ti. Apenas precisas de estar ligado à internet na primeira vez que o correres. Podes ler mais sobre isto aqui:

[https://testbox.ortusbooks.com](https://testbox.ortusbooks.com)
