# Instalação

O Exercism permite-te programar e testar o teu código ABAP diretamente no navegador. Não é necessária nenhuma instalação adicional. No entanto, se preferires programar e testar no teu próprio sistema, podes obter um sistema ABAP de avaliação.

Claro que é possível que o teu empregador já trabalhe com SAP. Verifica com o teu departamento de TI se podes ter acesso a um sandbox de desenvolvimento ABAP e como o obter.

## Que versão escolher?

Aconselhamos a usar uma versão atual da plataforma ABAP com suporte ativo. Atualmente, é o **ABAP 7.5 ou superior**. Encontras detalhes sobre as versões atuais e os respetivos prazos no [SAP Developer Center](hhttps://developers.sap.com/tutorials/mission-get-started-with-abap-development-on-premise).

## O que instalar?

Recomendamos que uses o [ABAP Cloud Developer Trial](https://hub.docker.com/r/sapse/abap-cloud-developer-trial) mais recente. Baseia-se no ABAP 7.58. Podes instalar o sistema SAP ABAP como imagem Docker ou alojado na SAP Cloud Appliance Library. Além disso, precisas de instalar o SAP GUI, para Windows ou para Java, consoante o teu sistema operativo. Podes descarregar o SAP GUI [aqui](https://www.sap.com/products/try-sap/trials-downloads.html?search=sap+gui).

Para mais detalhes, consulta este blog da [SAP Community](https://community.sap.com/t5/technology-blog-posts-by-sap/abap-cloud-developer-trial-2023-available-now/ba-p/14057183).
