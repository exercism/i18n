## 1. Explica as cores do vinho

- Tens de escrever a informação dada na tabela como uma lista de palavras-chave.
- Dá uma vista de olhos a alguns [exemplos][keyword-examples] de como definir uma lista de palavras-chave.

## 2. Obtém todos os vinhos de uma determinada cor

- Existe uma [função incorporada][keyword-get-values] para obter a lista de todos os valores de uma determinada chave.

## 3. Obtém todos os vinhos de uma determinada cor engarrafados num determinado ano

- Existe uma [função incorporada][keyword-get] para obter um único valor de uma determinada chave.
- Não precisas de implementar a filtragem das garrafas por ti próprio. Só precisas de usar condicionalmente a função `filter_by_year/2` já implementada.

## 4. Obtém todos os vinhos de uma determinada cor engarrafados num determinado país

- Existe uma [função incorporada][keyword-get] para obter um único valor de uma determinada chave.
- Não precisas de implementar a filtragem das garrafas por ti próprio. Só precisas de usar condicionalmente a função `filter_by_country/2` já implementada.
