# Introdução

O Haxe é fortemente tipado, mas o sistema de tipos pode ser contornado quando for necessário. Atribuir um valor a um nome chama-se definir uma variável. Uma variável pode ser definida especificando explicitamente o seu tipo ou deixando o compilador do Haxe inferir o tipo. Por isso, as duas definições de variável seguintes são equivalentes:

```haxe
var explicitVariable:Int = 10; // Explicitly typed
var implicitVariable = 10; // Implicit typed
```

Uma variável pode ser atualizada com o operador `=`:

```haxe
var number = 0; // Initial value
number = 1; // Updated value
```

O compilador lança um erro quando tentas atribuir um valor cujo tipo é diferente do da variável:

```haxe
var number = 1; // Variable number is of integer type
number = "Hello" // Error trying to assign a string to an integer variable
```

Uma função que está dentro de uma classe chama-se _método_. Os métodos podem ter zero ou mais parâmetros. Todos os parâmetros têm de ser tipados explicitamente. Tal como os parâmetros, o tipo devolvido de um método não pode ser inferido e tem de ser especificado. Os valores são devolvidos pelos métodos com a palavra-chave `return`:

```haxe
function add(x:Int, y:Int):Int {
  return x + y;
}
```

Um método invoca-se indicando a sua classe e o nome do método e passando os argumentos:

```haxe
var sum = add(1, 2) // sum = 3
```

O âmbito no Haxe é definido entre os carateres `{` e `}`.

O Haxe suporta dois tipos de comentários. Os de uma só linha são precedidos por `//` e os comentários de várias linhas são inseridos entre `/*` e `*/`.
