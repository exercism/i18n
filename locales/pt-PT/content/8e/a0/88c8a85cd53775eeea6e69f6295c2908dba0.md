# Instruções

Neste exercício vais escrever código para ajudar um freelancer a comunicar com os seus clientes sobre os preços de certos projetos.
Vais escrever alguns métodos utilitários para calcular rapidamente os custos para os clientes.

```exercism/note
O parâmetro `rate_per_hour` e o método `day_rate` estão relacionados com dinheiro.
As unidades de medida são dinheiro por unidade de tempo: horas e dias, respetivamente.
```

## 1. Calcula o valor diário a partir de um valor por hora

Um cliente contacta o freelancer para se informar sobre os seus preços.
O freelancer explica que **_trabalha 8 horas por dia._**
No entanto, o freelancer só conhece o seu valor por hora para o projeto.
Ajuda-o a estimar um valor diário a partir de um valor por hora.

```abap
DATA(freelancer_rates) = NEW zcl_freelancer_rates( ).

freelancer_rates->day_rate( 89 ).
// => 712
```

O valor diário não precisa de ser arredondado nem alterado para uma precisão "fixa".

## 2. Calcula o número de dias de trabalho a partir de um orçamento fixo

Noutro dia, um gestor de projeto propõe ao freelancer trabalhar num projeto com um orçamento fixo.
Dado o orçamento fixo e o valor por hora do freelancer, ajuda-o a calcular o número de dias que trabalharia até o orçamento se esgotar.
O resultado _tem_ de ser **arredondado por defeito** para o número inteiro mais próximo.

```abap
freelancer_rates->days_in_budget(
  budget        = 20000
  rate_per_hour = 89 ).
// => 28
```

## 3. Calcula o valor com desconto para projetos grandes

Muitas vezes, os clientes do freelancer contratam-no para projetos que se prolongam por vários meses.
Nesses casos, o freelancer decide oferecer um desconto por cada mês completo, e os dias restantes são faturados ao valor diário.
O teu excelente equilíbrio entre a vida profissional e pessoal significa que só trabalhas 22 dias em cada mês civil, por isso **_cada mês tem 22 dias faturáveis._**
Ajuda-o a estimar o custo desses projetos, dado um valor por hora, o número de dias faturáveis que o projeto inclui e uma taxa de desconto mensal.
O desconto é sempre passado como um número, em que `42%` passa a `0.42`. O resultado _tem_ de ser **arredondado por excesso** para o número inteiro mais próximo.

```abap
freelancer_rates->price_with_monthly_discount(
  rate_per_hour = 89
  num_days      = 230
  discount      = '0.42' ).
// => 97972
```
