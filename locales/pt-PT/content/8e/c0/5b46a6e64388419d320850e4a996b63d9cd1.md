# Apêndice às instruções

## Implementação

É possível ficar sem nomes de robôs. Quando todos os nomes possíveis de robôs já tiverem sido atribuídos, deve ser devolvido um erro.

## Teste bónus

Quando conseguires que o `go test` passe, vais ver que há um teste no conjunto de testes chamado `TestCollisions` que é ignorado por predefinição, uma vez que pode demorar muito tempo.
Este teste cria novos robôs até já não ser possível atribuir mais nomes novos ao robô.

Para fazer com que o teste corra, remove esta linha:

```go
t.Skip("skipping test as it can take a long time to run if solution is sub-optimal.")
```

Para que este teste passe, tens de garantir que o nome de um robô não foi usado antes e que os nomes podem ser atribuídos de forma eficiente.
