# Introdução

O Swift tem um conjunto de instruções que podem ser usadas para alterar o fluxo normal de controlo dos ciclos.
São conhecidas como instruções de transferência de controlo.
Já viste o `return`; este conceito vai apresentar outras, que incluem `continue`, `break` e rótulos.

## Continue

Por vezes é necessário saltar antecipadamente para a iteração seguinte de um ciclo, sem completar o resto das instruções da iteração atual do ciclo.
A palavra-chave `continue` pode ser usada para isso.
Quando o `continue` é executado, o ciclo salta para a verificação seguinte para ver se a próxima iteração do ciclo pode ser executada, ou seja, o `while` nos ciclos while e repeat-while ou a verificação de se há outro elemento na sequência nos ciclos for-in.

```swift
count = 1
while count < 6 {
  count += 1
  if count == 4 { continue }
  print(count)
}

// prints:
// 2
// 3
// 5
```

## Break

O `break` é usado para sair de um ciclo antecipadamente.
Quando o `break` é executado, o ciclo termina imediatamente e o programa continua com a primeira instrução a seguir ao ciclo.

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  if !fruit.count.isMultiple(of: 2) { break }
  print(fruit)
}

// prints:
// banana
// grapes
```

## Rótulos

Quando os ciclos estão aninhados, há alturas em que se pode querer usar `break` ou `continue` para sair ou reiniciar os ciclos exteriores que contêm o ciclo onde o `break` ou o `continue` são usados.
Em casos como estes, podem usar-se rótulos para especificar o ciclo a sair ou a reiniciar.
Um ciclo pode ser rotulado colocando um nome seguido de dois pontos antes do `while`, `repeat` ou `for` que inicia o ciclo.

Para ver o efeito de usar rótulos desta forma, considera o seguinte ciclo.

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  print("\n--- \(fruit) ---")
  for letter in fruit {
    guard letter != "n" else { break outerLoop }
    print(letter)
  }
}

// prints:
// --- banana ---
// b
// a
```

## Fallthrough

A palavra-chave `fallthrough` é usada para passar para o case seguinte de uma instrução switch.
Isto significa que o código dentro do case seguinte será executado sem verificar a(s) sua(s) condição(ões).
Isto faz com que a instrução switch se comporte como noutras linguagens de programação, onde a instrução `break` não é necessária para sair da instrução switch depois de um case corresponder.
Podes ler mais sobre o `fallthrough` no [livro do Swift][fallthrough].

```swift
let value = 1
switch value {
case 1:
  print("One")
  fallthrough
case 2:
  print("Two")
}

// prints:
// One
// Two
```
