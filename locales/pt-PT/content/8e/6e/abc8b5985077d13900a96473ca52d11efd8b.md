# Testes

## Clojure CLI

Os exercícios de Clojure no Exercism vêm com um ficheiro `deps.edn` com um alias `:test` para invocar o [cognitect-labs test-runner](https://github.com/cognitect-labs/test-runner):

``` bash
$ clj -X:test
```

## Leiningen

O Leiningen também pode ser usado para correr os testes do exercício, executando o seguinte comando a partir do diretório do exercício:

```bash
lein test
```

## REPL

Para correres os testes do exercício com o REPL, executa o seguinte comando a partir do diretório do exercício:

```bash
$ clj
```

-ou-

```bash
$ lein repl
```

Depois, faz `require` do namespace de testes do exercício e do namespace de testes de Clojure):

```clojure
;; replace <exercise> with the exercise's name
=> (require '<exercise>-test)
```

Depois, chama `run-tests` em `<exercise>-test`:

```clojure
;; replace <exercise> with the exercise's name
=> (clojure.test/run-tests '<exercise>-test)
```
