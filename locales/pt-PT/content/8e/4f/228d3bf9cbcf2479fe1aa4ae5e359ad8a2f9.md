# Dicas

Alguns dos testes (não todos) assumem que o valor é `Int32`, por isso evita forçá-lo a ser outra coisa.

## 1. Desloca os bits para trás

- Isto é um deslocamento para a direita.
- Repara na indicação de que os resultados devem ser preenchidos à esquerda com zeros.

## 2. Ativa alguns bits

- Os bits ativam-se com um OR bit a bit com uma máscara. Isto é extremamente comum.

## 3. Inverte bits específicos

- Há uma piada antiga entre programadores: os criptógrafos descobriram o XOR e esqueceram-se de ler o resto do manual.

## 4. Limpa bits específicos
