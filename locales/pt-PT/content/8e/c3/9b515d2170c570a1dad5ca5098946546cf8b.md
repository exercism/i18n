# Anexo às instruções

## Notas de implementação

`Range` deve devolver uma lista de todos os ternos pitagóricos com lados no intervalo de `min` a `max`, inclusive.

`Sum` deve devolver uma lista de todos os ternos pitagóricos em que a soma `a+b+c` (o perímetro) é igual a `p`.
Os três elementos de cada terno devolvido têm de estar por ordem, `t[0] <= t[1] <= t[2]`, e a lista de ternos tem de estar em ordem lexicográfica.
