# Sobrecarga de operadores

A sobrecarga de operadores é uma funcionalidade presente em algumas linguagens de programação que permite redefinir operadores padrão, como a adição (`+`), a subtração (`-`), a multiplicação (`*`) e a divisão (`/`), para funcionarem com tipos definidos pelo utilizador.

Assim, a sintaxe do código pode tornar-se mais intuitiva, ao permitir que as operações sobre tipos definidos pelo utilizador sejam escritas da mesma forma que as operações sobre tipos primitivos.

Em Cairo, a sobrecarga de operadores consegue-se através da implementação de traits específicos.

Cada operador tem um trait associado, e sobrecarregar esse operador implica fornecer uma implementação desse trait para um tipo personalizado.
No entanto, é essencial usar a sobrecarga de operadores com bom senso.

O uso indevido pode gerar confusão e tornar o código mais difícil de manter, por exemplo quando o operador sobrecarregado não tem qualquer significado semântico.

Considera um exemplo em que é preciso combinar duas `Potions`.

As `Potions` têm dois campos de dados, mana e health.

Combinar duas `Potions` deve somar os respetivos campos.

```rust
struct Potion {
    health: felt252,
    mana: felt252,
}

impl PotionAdd of Add<Potion> {
    fn add(lhs: Potion, rhs: Potion) -> Potion {
        Potion { health: lhs.health + rhs.health, mana: lhs.mana + rhs.mana }
    }
}

fn main() {
    let health_potion: Potion = Potion { health: 100, mana: 0 };
    let mana_potion: Potion = Potion { health: 0, mana: 100 };
    let super_potion: Potion = health_potion + mana_potion;
    // Both potions were combined with the `+` operator.
    assert(super_potion.health == 100, '');
    assert(super_potion.mana == 100, '');
}
```

No código acima, estamos a implementar o trait `Add` para o tipo `Potion`.

A função add recebe dois argumentos: `lhs` e `rhs` (lado esquerdo e lado direito).

O corpo da função devolve uma nova instância de `Potion`, com os valores dos seus campos a resultarem de uma combinação de `lhs` e `rhs`.

Como mostra o exemplo, sobrecarregar um operador exige especificar o tipo concreto que está a ser sobrecarregado.

O trait genérico sobrecarregado é `Add<T>`, e definimos uma implementação concreta para o tipo `Potion` com `Add<Potion>`.
