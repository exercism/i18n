# Introdução

Uma `String` em Julia é uma sequência imutável e finita de carateres [Unicode](https://en.wikipedia.org/wiki/Unicode), em codificação [UTF-8](https://en.wikipedia.org/wiki/UTF-8).

Um literal `String` é uma sequência de carateres entre aspas duplas:

```julia-repl
julia> "Christopher"
"Christopher"
```

As strings podem ser concatenadas através do operador `*`:

```julia-repl
julia> "Christopher" * " " * "Paolini"
"Christopher Paolini"
```

~~~~exercism/advanced
Se tens curiosidade em saber porque é que a Julia usa `*` em vez de `+` para concatenar strings, dá uma vista de olhos ao [Manual de Julia](https://docs.julialang.org/en/v1/manual/strings/#man-concatenation).
~~~~

Alguns carateres especiais precisam de ser escapados com uma barra invertida à frente:

```julia-repl
julia> println("\t or spaces?")
         or spaces?
```

A Julia inclui muitas funções úteis para trabalhar com strings por predefinição:

```julia-repl
julia> lowercase("TEST")
"test"

julia> titlecase("TEST")
"Test"
```
