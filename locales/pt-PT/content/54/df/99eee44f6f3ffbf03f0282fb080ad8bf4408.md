# Dicas

## 1. Cria a classe Alien

- Lembra-te de que os `object methods` recebem sempre `self` como primeiro parâmetro.
- Lembra-te dos underscores duplos em _ambos_ os lados de `__init__()`.
- As variáveis de instância são exclusivas da instância da `class` (_objeto_) que as possui.
- As variáveis de classe são iguais em todas as instâncias de uma `class`.

## 2. O método `hit`

- Lembra-te de que os `object methods` recebem sempre `self` como primeiro parâmetro.
- Podes optar por deixar a saúde do Alien descer abaixo de zero, ou exigir que isso não aconteça.

## 3. O método `is_alive`

- Lembra-te de que os `object methods` recebem sempre `self` como primeiro parâmetro.
- O 0 pode não ser a única condição de 'morte', depende de como o `hit()` está implementado.

## 4. O método `teleport`

- Lembra-te de que os `object methods` recebem sempre `self` como primeiro parâmetro.
- Os atributos de instância podem ser atualizados a partir de um método com `self.<attribute> = <new attribute value>`.

## 5. O método `collision_detection`

- Lembra-te de que os `object methods` recebem sempre `self` como primeiro parâmetro.
- Este método parece um excelente lugar para usar algum tipo de placeholder…

## 6. Contador de Aliens

- Os atributos de classe são iguais em todas as instâncias de uma `class`.
- O ideal era que este contador fosse incrementado sempre que alguém _criasse um novo Alien_.
- Os atributos de classe podem ser alterados a partir de um método de instância usando o _nome da classe_: `Alien.<class attribute name>`.
- O `__init__()` é considerado um método de instância, uma vez que _inicializa um novo objeto_.

## 7. Criação de objetos

- Um `tuple` seria um _único_ parâmetro.
- O construtor de Alien recebe _2 parâmetros_.
- Desempacotar o que está _dentro_ do tuple daria dois parâmetros.
- A função autónoma está fora da `class`.
