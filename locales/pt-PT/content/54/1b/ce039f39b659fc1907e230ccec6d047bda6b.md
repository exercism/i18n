# Acerca de

Os números de vírgula flutuante são números com um ou mais algarismos depois do separador decimal.

```gleam
let float = 3.45
// -> 3.45
```

Estes números também têm o seu próprio conjunto de operadores.

```gleam
1.0 +. 1.4 // -> 2.4
5.0 -. 1.5 // -> 3.5
5.0 /. 2.0 // -> 2.5
3.0 *. 3.1 // -> 9.3

2.0 >. 1.0  // -> True
2.0 <. 1.0  // -> False
2.0 >=. 1.0 // -> True
2.0 <=. 1.0 // -> False
```

Também podes adicionar underscores aos números de vírgula flutuante para maior clareza.

```gleam
1_000_000.0 // One million
```

Também podes usar notação científica com números de vírgula flutuante:

```gleam
1.01e3 // -> 1010
15.1e-3 // -> 0.0151
```
