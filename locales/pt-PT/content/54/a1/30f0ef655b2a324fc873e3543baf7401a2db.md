# Dicas

## Geral

- Em Python, `None` é frequentemente usado como marcador de posição para representar a **ausência de um valor** numa variável, num objeto ou num argumento.

## 1. Cria um novo mapa de lugares

Lembra-te de que precisas de criar primeiro um dicionário vazio. A seguir, cria uma _chave_ por cada lugar disponível e define os respetivos _valores_ como um **marcador de posição**, para indicar que o lugar está disponível mas ainda não foi atribuído.

## 2. Distribui as reservas

- Se não houver uma lista de convidados, vais querer devolver um `new_seating_chart()` preenchido com marcadores de posição. Um `default argument` na tua função pode ser útil aqui. Se houver uma lista de convidados, podes começar com um `new_seating_chart()` e depois percorrer de 1 até ao número de convidados, atribuindo-os aos lugares por ordem.

## 3. Encontra todos os lugares disponíveis

- Podes percorrer todos os pares (chave, valor) de um dicionário chamando `dict.items()`. Podes verificar se uma variável ou um valor é None com um `if statement` -- `if var is None` devolve True se o valor for `None`. Podes adicionar elementos a uma `list` chamando `list.append()`

## 4. Lotação atual

- Podes percorrer todos os valores do objeto dict chamando `dict.values()`. Um lugar está disponível quando o seu valor é `None`.

## 5. Acomoda os convidados em espera

- Precisas de encontrar o número atual de lugares vazios e verificar se é maior ou igual ao número de convidados em espera. Se for possível acomodar os convidados, tens de chamar `find_all_available_seats()` para obteres uma lista dos números de lugares aos quais os podes atribuir. Lembra-te de que `range()` pode receber qualquer tipo de número como argumento....**incluindo** o número devolvido pela chamada a `len()` sobre uma lista. Lembra-te também de que `list[index_number]` devolve o **valor** que está no **número de índice** dentro dos parênteses retos.

## 6. Esvazia os lugares

- Dado o `dict` do mapa de lugares e uma `list` de números de lugares, vais querer indicar que o lugar está agora disponível para outro convidado, substituindo o nome do convidado por um marcador de posição. Percorrer a lista de números de lugares e procurar esses lugares no dicionário pode ajudar aqui.
