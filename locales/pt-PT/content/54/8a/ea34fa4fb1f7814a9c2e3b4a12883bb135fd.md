# Testes

## No Exercism

Cada exercício é fornecido como uma única classe ABAP (com um ou mais métodos). Normalmente, são dadas as definições dos métodos com parâmetros de entrada e de saída. A tua tarefa é completar a implementação do método de acordo com as especificações do exercício.

Quando tiveres código que queres testar, seleciona «Executar os testes». Isto vai desencadear a execução da classe de teste ABAP correspondente e os resultados aparecem ao fim de alguns segundos. Se houver erros, volta ao teu código e ajusta-o em conformidade. Se todos os testes passarem, parabéns! Completaste o exercício e podes submeter a tua solução.

### Resolução de problemas

Nos bastidores, o teu código ABAP é compilado e executado com o chamado [abaplint transpiler](https://github.com/abaplint/transpiler). Esta é ainda uma solução relativamente recente. Se tiveres problemas que não consegues resolver, abre um issue no [GitHub](https://github.com/abaplint/transpiler/issues).

### Depuração e registo

Não há nenhum depurador disponível quando executas exercícios de ABAP no site do Exercism. Isso pode dificultar perceber porque é que os teus testes estão a falhar. No entanto, há uma forma engenhosa de registar dados no teu código (Nota: isto não funciona em nenhum sistema ABAP).

Aqui está um [exemplo](https://exercism.org/tracks/abap/exercises/affine-cipher/solutions/mbtools). A primeira imagem mostra o código do exercício com alguns testes a falhar. Cada teste falhado mostra os valores esperados e os valores reais:

![exercício sem registo](https://github.com/exercism/abap/blob/main/docs/logging_01.png?raw=true)

Para tornar a depuração mais fácil, acrescenta uma ou várias chamadas a `console=>log()` e passa os dados intermédios ao método. Usar mudanças de linha (`\n`) ajuda a estruturar a saída. Quando executares os testes, vais ver a saída da consola nos resultados dos testes:

![exercício com registo](https://github.com/exercism/abap/blob/main/docs/logging_02.png?raw=true)

Nota: a saída da consola só é visível nos testes falhados. Se estiveres a publicar a tua solução, talvez queiras remover as instruções de registo para que a tua iteração publicada seja mais fácil de ler para os outros membros da comunidade.

## No teu próprio sistema

### Percurso completo

A forma mais fácil de começar a praticar no teu próprio sistema é clonar [este repositório](https://github.com/exercism/abap) com o [abapGit](https://github.com/abapGit/abapGit). Isto vai criar os stubs e as classes de teste para todos os exercícios que estão atualmente disponíveis.

### Exercícios individuais

Abre as tuas ABAP Development Tools (ou as transações `SE24` ou `SE80`, se tiveres um sistema mais antigo) e cria uma nova classe ABAP com o mesmo nome da classe do exercício. Implementa também o stub da classe e a classe de teste, copiando e colando o código do site do Exercism.

### Implementar soluções

Agora podes editar a classe de um exercício e implementar uma solução. Depois, executa os testes unitários ABAP para verificar se passa em todos os testes. Depois de terminares e de os testes passarem, copia e cola o teu código no editor do exercício no site do Exercism. Executa também os testes aí.

### Testar e completar o exercício

Quando programas e testas no teu próprio sistema, é usado o compilador e o ambiente de execução padrão do SAP ABAP. Se os teus testes falharem, é provável que o problema esteja no teu código. Vê com mais atenção.

Se o teu código passar nos testes unitários, copia e cola a implementação da tua classe no exercício no site do Exercism e seleciona «Executar os testes». Claro que os testes também devem passar aí. Se não passarem, consulta a secção de resolução de problemas acima.
