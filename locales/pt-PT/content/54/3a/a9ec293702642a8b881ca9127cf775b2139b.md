# Aprendizagem

A linguagem de programação Pascal tem uma longa história, e grande parte da documentação online está direcionada a principiantes. A maioria destes tutoriais aborda programas de consola, nos quais imprimes informação para o ecrã e/ou lês a entrada do utilizador. Por exemplo, um dos tutoriais para principiantes mais comuns é um programa que imprime 'Hello World' no ecrã:

```pascal
program HelloWorld;
begin
  writeln('Hello World!');
end.
```

Quando executado a partir de uma consola ou terminal, este programa imprime 'Hello World' no ecrã.

Aqui no Exercism, usamos testes automáticos para garantir que as tuas soluções estão corretas e, por isso, precisamos de usar uma **unit** em vez de um **program**. A principal diferença é que vais ter de devolver um valor de uma função em vez de imprimir algo para o terminal:

```pascal
writeln('Hello World!');
```

passou a ser

```pascal
result := 'Hello World!'
```

Os comandos write/writeln continuam a ser úteis para mostrar informação ou obter uma representação textual do resultado de um comando, de uma operação matemática, etc.
