# Anexo às instruções

## Palavras

`smallest` e `largest` devolvem cada um **dois** valores na pilha: o
valor do palíndromo (ou `f`, se não existir nenhum no intervalo) e um
array de pares de fatores.

- `smallest ( mn mx -- value factors )`
- `largest  ( mn mx -- value factors )`

Cada par em `factors` é um array de 2 elementos `{ a b }`. Lança a
string `"min must be <= max"` se `mn > mx`.
