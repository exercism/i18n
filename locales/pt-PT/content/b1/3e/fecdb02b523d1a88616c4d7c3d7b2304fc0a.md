# Introdução

Trabalhar com dados binários é um conceito importante em qualquer linguagem, e o Elixir oferece uma sintaxe elegante para escrever, fazer correspondência e construir dados binários.

Em Elixir, os dados binários são designados pelo tipo bitstring. O _tipo_ de dados binários (que não deve ser confundido com dados binários em geral) é uma forma específica de bitstring, que vamos discutir num exercício mais adiante.

Os literais de bitstring são definidos com a forma especial de bitstring `<<>>`. Ao definir um literal de bitstring, este é definido em segmentos. Cada segmento tem um valor e um tipo, separados pelo operador `::`. O tipo especifica quantos bits serão usados para codificar o valor. O tipo pode ser omitido por completo, assumindo por omissão um valor inteiro de 8 bits.

```elixir
# This defines a bitstring with three segments of a single bit each
<<0::1, 1::1, 0::1>>
```

Especificar o tipo como `::1` é uma forma abreviada de escrever `::size(1)`. Tens de usar a sintaxe mais longa se o tamanho em bits vier de uma variável.

## Binário

Ao escrever literais de inteiros binários, podemos escrevê-los diretamente em notação de base 2, prefixando o literal com `0b`. Repara que, de qualquer forma, serão apresentados como números decimais nos resultados dos testes ou quando usares o iex.

```elixir
<<0b1011::4>> == <<11::4>>
# => true
```

## Truncar

Se o valor do segmento ultrapassar a capacidade do tipo do segmento, será truncado a partir da esquerda.

```elixir
<<0b1011::3>> == <<0b0011::3>>
# => true
```

## Inserir no início e no fim

Podes inserir tanto no início como no fim de um bitstring existente usando a forma especial. O tipo `::bitstring` tem de ser usado no bitstring existente se este tiver um tamanho desconhecido.

```elixir
value = <<0b110::3, 0b001::3>>
new_value = <<0b011::3, value::bitstring, 0b000::3>>
# => <<120, 8::size(4)>>
```

## Concatenar

Podemos concatenar bitstrings guardados em variáveis com a forma especial. O tipo `::bitstring` tem de ser usado ao concatenar dois bitstrings de tamanhos desconhecidos.

```elixir
first = <<0b110::3>>
second = <<0b001::3>>
concatenated = <<first::bitstring, second::bitstring>>
# => <<49::size(6)>>
```

## Correspondência de padrões

Também se pode fazer correspondência de padrões para obter valores a partir da forma especial. Tens de saber o número de bits de cada fragmento que queres capturar, com uma exceção: o tipo `::bitstring` pode ser usado para fazer correspondência de padrões num bitstring de tamanho desconhecido, mas só pode ser usado no último fragmento.

```elixir
<<value::4, rest::bitstring>> = <<0b01101001::8>>
value == 0b0110
# => true
```

## Inspecionar bitstrings

~~~~exercism/note
Os bitstrings podem ser apresentados (pelo executor de testes ou no iex) num
formato diferente do formato usado para os criar. Isto causa frequentemente
confusão quando se está a aprender bitstrings.
~~~~

Por omissão, os bitstrings são apresentados em fragmentos de 8 bits (um byte), mesmo que os tenhas criado com fragmentos de tamanho diferente.

```elixir
<<2011::11>>
# => <<251, 3::size(3)>>
```

Se criares um bitstring que representa uma string codificada em UTF-8 e imprimível, é apresentado como string.

```elixir
<<>>
# => ""

<<65, 66, 67>>
# => "ABC"
```
