# Sobre

A biblioteca padrão do Gleam implementa um tipo `Queue` no módulo `gleam/queue`. É semelhante ao tipo `List`, mas com algumas diferenças importantes:

- O tipo `Queue` não tem uma sintaxe literal que possa ser usada para construir filas ou fazer correspondência de padrões sobre elas.
- Os elementos podem ser adicionados e removidos de forma eficiente tanto à frente como atrás do tipo `Queue`, enquanto o tipo `List` só consegue adicionar e remover elementos de forma eficiente pela frente.

Na maioria das vezes vais querer usar o tipo `List`, mas quando precisares de adicionar e remover a partir do fim de uma coleção, o tipo `Queue` é uma boa escolha.

As filas podem ser criadas com as funções `queue.new` e `queue.from_list`:

```gleam
let empty = queue.new()
let one_to_four = queue.from_list([1, 2, 3, 4])
```

Os elementos podem ser adicionados à fila com as funções `queue.push_front` e `queue.push_back`:

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])
let one_to_five = queue.push_back(one_to_four, 5)
let zero_to_five = queue.push_front(one_to_five, 0)
```

Os elementos podem ser removidos da fila com as funções `queue.pop_front` e `queue.pop_back`:

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])

queue.pop_back(one_to_four)
// -> Ok(#(4, queue.from_list([1, 2, 3])))

queue.pop_front(one_to_four)
// -> Ok(#(1, queue.from_list([2, 3, 4])))

queue.pop_front(queue.new())
// -> Error(Nil)
```

Uma fila pode ser convertida numa lista com a função `queue.to_list`:

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])
queue.to_list(one_to_four)
// -> [1, 2, 3, 4]
```

## Igualdade de filas

Devido à forma como as filas são implementadas, duas filas com os mesmos elementos pela mesma ordem podem não ser iguais segundo o operador `==`, que compara valores estruturalmente. Por exemplo:

```gleam
let empty = queue.new()
let a = queue.push_front(empty, 1)
let b = queue.push_back(empty, 1)
a == b
// -> False
```

Se precisares de comparar duas filas quanto à igualdade, podes usar a função `queue.is_logically_equal`.

```gleam
queue.is_logically_equal(a, b, fn(x, y) { x == y })))
// -> True
```
