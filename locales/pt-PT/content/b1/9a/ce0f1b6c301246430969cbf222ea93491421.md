# Sobre

As [strings][strings] em Haxe são objetos imutáveis que representam texto como uma sequência de carateres Unicode (letras, algarismos, pontuação, etc.). Usam-se aspas duplas para definir uma instância de `string`:

```haxe
var fruit:String = "Apple";
```

Podes manipular uma string chamando um dos seus [métodos ou propriedades][string-api]. Como os valores de string nunca podem mudar depois de serem definidos, todos os métodos de manipulação de strings devolvem uma nova string.

Uma string é delimitada por aspas duplas (`"`). Alguns carateres especiais precisam de [escape][escaping] com o caráter barra invertida (`\`). Além disso, as strings em Haxe são multilinha e permitem construir literais de string longos com facilidade:

```haxe
var escaped:String = "c:\\test.txt";
var multiline:String = "
- apple
- pear
- banana";
```

A forma mais simples de concatenar strings é usar o [operador `+`][plus-operator].

```haxe
var name:String = "Jane";
trace("Hello " + name + "!");
// => "Hello Jane!"
```

Para formatação de strings mais complexa, dá-se preferência à [interpolação de strings][interpolation]. Isto faz-se envolvendo a string em plicas (`'`) e usando o cifrão (`$`) para acionar a interpolação de variáveis. Também é possível avaliar expressões completas usando `${expr}`, em que `expr` é qualquer expressão válida em Haxe:

```haxe
var name:String = "Jane";
trace('Hello $name!');
// => "Hello Jane!"
trace('HELLO ${name.toUpperCase()}!');
// => "HELLO JANE!"
```
