# Anexo às instruções

## Palavras

- `tick ( matrix cols -- matrix' )` — avança a grelha uma geração e
  devolve a grelha nova.

Cada linha da grelha é representada como um número inteiro de 64 bits;
`cols` é o número de colunas (no máximo 64). Por exemplo,

```
    0 1 0
    1 0 0
    1 1 0
```

é representada como

```
0b010
0b100
0b110
```
