# Instruções

Neste exercício, vais criar um `TranslationService` que oferece serviços básicos de tradução aos membros gratuitos e tradução avançada aos membros premium, com garantias de qualidade.

**A API**

Encontraste uma API de tradução do espaço sideral que satisfaz qualquer `request` de tradução num tempo razoável.
Queres tirar partido disso.
Os tradutores espaciais são extremamente inconstantes e odeiam redundância, por isso também disponibilizam satélites de _API storage_ onde podes fazer `fetch` de traduções antigas sem os incomodar.

**_Obter uma tradução_**

`api.fetch(text)` obtém uma tradução de `text` a partir do _API storage_ e devolve uma `promise` que fornece dois valores:

- `translation`: a tradução propriamente dita
- `quality`: a qualidade expressa como um número

Se uma tradução não for encontrada no _API storage_, a API lança um erro `NotAvailable`.
As traduções podem ser adicionadas com o método `api.request`.
Se 'text' não for traduzível, a API lança um erro `Untranslatable`.

```javascript
api.fetch('jIyaj');
// => Promise({ resolved: 'I understand' })
```

**_Pedir uma tradução_**

Algumas traduções existem de certeza, mas ainda não foram adicionadas ao _API storage_. É essa a diferença entre `NotAvailable` ( não está no armazenamento, mas pode ser pedida ) e `Untranslatable` ( não pode ser traduzida ).

`api.request(text, callback)` pede que uma tradução de `text` seja efetuada e adicionada ao _API storage_.
Quando termina, a função `callback` é chamada.

- Em caso de sucesso, é passado `undefined` à `callback`: isto indica que a tradução foi bem-sucedida e está acessível através do método `api.fetch`.
- Em caso de falha, é passado um `error` à `callback`: isto indica que algo correu mal.
  A API do espaço sideral é _instável_, o que significa que falha com frequência.
  Se isso acontecer, podes voltar a chamar `api.request`.

```javascript
api.request('majQa’', callback);
// => undefined
//
// later: the passed callback is called with undefined
//        because it was successful.
```

**⚠ Aviso! ⚠**

<!-- prettier-ignore-start -->
~~~~exercism/caution
A API faz a sua magia teletransportando os vários tradutores quando chega um `request`.
É uma ação muito dispendiosa, por isso não deve ser chamada quando *existe* uma tradução disponível.
Infelizmente, nem toda a gente lê o manual, por isso há um sistema para expulsar os maus atores.

Se for chamado um `api.request` para um `text` que já está disponível, a API lança um `AbusiveClientError` nesta chamada **e em todas as chamadas seguintes**.
Certifica-te de que *nunca* pedes uma tradução se algo já foi traduzido.
~~~~
<!-- prettier-ignore-end -->

## 1. Obter uma tradução, ignorando a qualidade

O serviço gratuito só disponibiliza traduções que estão atualmente no _API storage_.

Implementa um método `free(text)` que dá aos membros gratuitos as traduções que já existem no _API storage_.
Ignora a qualidade e propaga os erros lançados pela API.

- Devolve a tradução se a conseguir obter, independentemente da qualidade
- Propaga qualquer erro da API de tradução
- Usa o método `api.fetch` (`api.fetch` devolve uma `promise`)

```javascript
service.free('jIyaj');
// => Promise<...> resolves "I understand."

service.free("jIyajbe'");
// => Promise<...> rejects Error("Not yet translated")
```

## 2. Obter um lote de traduções, tudo ou nada

Implementa um método `batch([text, text, ...])` para membros gratuitos que traduz um array de textos com o serviço gratuito e devolve todas as traduções ou um único erro.

- Resolve com todas as traduções (pela mesma ordem), se estiverem todas disponíveis
- Rejeita com o primeiro erro que encontrar
- Rejeita com um erro `BatchIsEmpty` se não for dado nenhum texto

```javascript
service.batch(['jIyaj', "majQa'"]);
// => Promise<...> resolves ["I understand.", "Well done!"]

service.batch(['jIyaj', "jIyajbe'"]);
// => Promise<...> rejects new Error("Not yet translated")

service.batch([]);
// => Promise<...> rejects BatchIsEmpty()
```

## 3. Pedir uma tradução, tentando de novo no máximo 2 vezes

Implementa um método `request(text)` para utilizadores premium, que _pede_ que uma tradução seja adicionada ao _API storage_.
O pedido deve tentar de novo automaticamente se ocorrer uma falha.
Não deve fazer mais de **3 chamadas** para o mesmo pedido (_não irrites os tradutores espaciais!!!_).

- Se `api.request` não devolver um erro, resolve com `undefined`
- Se `api.request` devolver um erro, tenta de novo no máximo duas vezes
- Se esgotares as tentativas, rejeita com o último erro recebido

```javascript
service.request("jIyajbe'");
// => Promise<...> resolves (with nothing), can now be retrieved using the fetch API
```

## 4. Obter uma tradução, inspecionar a qualidade ou pedi-la

Implementa um método `premium(text, quality)` para utilizadores premium que obtém uma tradução.
Se uma tradução for `NotAvailable`, pede a tradução e obtém-na depois de ter sido adicionada ao _API storage_.
O método só deve devolver a tradução se esta cumprir um determinado limite de `quality`.

- Se `api.fetch` resolver, verifica a qualidade antes de resolver
- Se `api.fetch` rejeitar, _pede_ a tradução em vez disso
- Se `api.request` rejeitar, propaga o erro

```javascript
service.premium("jIyajbe'", 100);
// => Promise<...> resolves "I don't understand."

service.premium("'arlogh Qoylu'pu'?", 100);
// => Promise<...> rejects QualityThresholdNotMet()

service.premium("'arlogh Qoylu'pu'?", 40);
// => Promise<...> resolves "What time is it?"
```

**Nota**

<!-- prettier-ignore-start -->
~~~~exercism/note
A tradução correta de `'arlogh Qoylu'pu'?` é **How many times has it been heard?**.
~~~~
