# Instruções

Neste exercício vais escrever código para analisar uma linha de montagem numa fábrica de automóveis.

## 1. Calcula o número de carros funcionais produzidos por hora

Implementa uma função que recebe o número de carros produzidos por hora e a taxa de sucesso e calcula o número de carros produzidos com sucesso por hora. A taxa de sucesso é dada em percentagem, de `0` a `100`:

```lua
cars.calculate_working_cars_per_hour(1547, 90)
--> => 1392.3
```

**Nota:** o valor devolvido deve ser um número de vírgula flutuante.

## 2. Calcula o número de carros funcionais produzidos por minuto

Implementa uma função que recebe o número de carros produzidos por hora e a taxa de sucesso e calcula quantos carros são produzidos com sucesso a cada minuto:

```lua
cars.calculate_working_cars_per_minute(1105, 90)
-- => 16
```

**Nota:** o valor devolvido deve ser um número inteiro.

## 3. Calcula o custo de produção 

Cada carro custa normalmente $10.000 a produzir individualmente, independentemente de ter sucesso ou não. Mas com um pouco de planeamento, é possível produzir 10 carros em conjunto por $95.000. Por exemplo, 37 carros podem ser produzidos da seguinte forma:
37 = 3 x grupos de dez + 7 carros individuais

Assim, o custo para 37 carros é:
3 \* 95,.000 + 7 \* 10.000 = 355.000

Implementa uma função que calcula o custo de produzir um determinado número de carros, independentemente de terem sucesso ou não:

```lua
cars.calculate_cost(37)
-- => 355000

cars.calculate_cost(21)
-- => 200000
```

**Nota:** o valor devolvido deve ser um número inteiro.
