# Dicas

## Geral

- Não te preocupes com a forma como os argumentos são obtidos; concentra-te apenas em combiná-los para devolver o resultado pretendido.
- O Unison tem [regras específicas para a precedência de operadores][operator-precedence]; lembra-te de usar parênteses se precisares de ordenar a aplicação de funções de outra forma.

## 1. Define se o Pac-Man pode comer um fantasma

- Tens de definir uma função com 2 argumentos. O primeiro argumento é um valor do tipo [boolean][boolean] que indica se o Pac-Man tem uma pastilha de energia ativa. O segundo argumento é um valor do tipo [boolean][boolean] que indica se o Pac-Man está a tocar num fantasma.
- A função tem de devolver um valor do tipo [boolean][boolean].
- Podes usar o operador [boolean][boolean] `&&` para combinar os argumentos e obter um resultado.

## 2. Define se o Pac-Man marca pontos

- Tens de definir uma função com 2 argumentos. O primeiro argumento é um valor do tipo [boolean][boolean] que indica se o Pac-Man está a tocar numa pastilha de energia. O segundo argumento é um valor do tipo [boolean][boolean] que indica se o Pac-Man está a tocar numa pastilha.
- A função tem de devolver um valor do tipo [boolean][boolean].
- Podes usar o operador [boolean][boolean] `||` para combinar os argumentos e obter um resultado.

## 3. Define se o Pac-Man perde

- Tens de definir uma função com 2 argumentos. O primeiro argumento é um valor do tipo [boolean][boolean] que indica se o Pac-Man tem uma pastilha de energia ativa. O segundo argumento é um valor do tipo [boolean][boolean] que indica se o Pac-Man está a tocar num fantasma.
- A função tem de devolver um valor do tipo [boolean][boolean].
- Podes usar os operadores [boolean][boolean] `&&` e `not` para combinar os argumentos e obter um resultado.

## 4. Define se o Pac-Man ganha

- Tens de definir uma função com 3 argumentos. O segundo argumento é um valor do tipo [boolean][boolean] que indica se o Pac-Man comeu todas as pastilhas. O primeiro argumento é um valor do tipo [boolean][boolean] que indica se o Pac-Man tem uma pastilha de energia ativa. O segundo argumento é um valor do tipo [boolean][boolean] que indica se o Pac-Man está a tocar num fantasma.
- A função tem de devolver um valor do tipo [boolean][boolean].
- Podes usar os operadores [boolean][boolean] `&&` e `not` para combinar os argumentos e os resultados das funções invocadas.

[boolean]: https://elixir-lang.org/getting-started/basic-types.html#booleans
