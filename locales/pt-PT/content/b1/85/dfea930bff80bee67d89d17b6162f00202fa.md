# Anexo às instruções

## Registos

| Registo | Utilização | Tipo | Descrição |
| -------- | --------- | ------- | ------------------------------------------- |
| `$a0`    | parâmetro de entrada | endereço | string de carateres hexadecimais terminada em nulo |
| `$v0`    | valor devolvido | inteiro | valor decimal da string de entrada |
| `$t0-9`  | temporário | qualquer | usado para armazenamento temporário |
