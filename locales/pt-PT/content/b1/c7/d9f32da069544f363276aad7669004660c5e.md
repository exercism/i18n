# Dicas

## Geral

- Todas as palavras de leitura e de escrita estão em [`io.files`][io.files]; a codificação `utf8` que todas aceitam vem de [`io.encodings.utf8`][utf8].

## 1. Lê todas as leituras

- `file-lines` devolve um array de linhas com as quebras de linha removidas.

## 2. Encontra a leitura mais recente

- Lê as linhas com `file-lines` e depois usa a palavra `last` (de
  `sequences`).

## 3. Lê o registo em bruto

- `file-contents` devolve o ficheiro como uma única string, com as quebras de linha e tudo.

## 4. Regista uma leitura

- Abre o ficheiro para acrescentar dados ao fim e faz `print` da leitura dentro da quotation:
  `with-file-appender ( path encoding quot -- )`. A leitura é usada dentro da quotation,
  enquanto o path é consumido antes dela, por isso as locals de `::` mantêm o corpo legível:
  `:: record-reading ( reading path -- ) path utf8 [ reading print ]
  with-file-appender ;`.

## 5. Reescreve o registo

- `set-file-lines` escreve cada elemento de uma sequência na sua própria linha e acrescenta
  as quebras de linha por ti.
