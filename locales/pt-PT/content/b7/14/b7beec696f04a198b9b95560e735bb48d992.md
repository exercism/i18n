# Instruções

Tens uma boutique de moda online. A tua grande promoção anual está a chegar, por isso precisas de fazer o inventário para garantir que está tudo pronto.

Cada artigo do inventário é representado por um mapa, e o inventário completo é uma lista desses mapas.

```elixir
%{
  name: "White Shirt",
  price: 40,
  quantity_by_size: %{s: 3, m: 7, l: 8, xl: 4}
}
```

## 1. Ordenar os artigos por preço

Implementa a função `sort_by_price/1`. Deve receber o inventário e devolvê-lo ordenado pelo preço dos artigos, por ordem crescente.

```elixir
BoutiqueInventory.sort_by_price([
  %{price: 65, name: "Maxi Brown Dress", quantity_by_size: %{}},
  %{price: 50, name: "Red Short Skirt", quantity_by_size: %{}},
  %{price: 50, name: "Black Short Skirt", quantity_by_size: %{}},
  %{price: 20, name: "Bamboo Socks Cats", quantity_by_size: %{}}
])

# => [
#      %{price: 20, name: "Bamboo Socks Cats", quantity_by_size: %{}},
#      %{price: 50, name: "Red Short Skirt", quantity_by_size: %{}},
#      %{price: 50, name: "Black Short Skirt", quantity_by_size: %{}},
#      %{price: 65, name: "Maxi Brown Dress", price: 65, quantity_by_size: %{}}
#    ]
```

## 2. Encontrar todos os artigos sem preço

Depois de ordenares o inventário por preço, reparaste que deves ter cometido um erro ao fazer o inventário e esqueceste-te de preencher os preços de alguns artigos.

Implementa a função `with_missing_price/1`. Deve receber o inventário e devolver uma lista dos artigos que não têm preço.

```elixir
BoutiqueInventory.with_missing_price([
  %{price: 40, name: "Black T-shirt", quantity_by_size: %{}},
  %{price: nil, name: "Denim Pants", quantity_by_size: %{}},
  %{price: nil, name: "Denim Skirt", quantity_by_size: %{}},
  %{price: 40, name: "Orange T-shirt", quantity_by_size: %{}}
])

# => [
#      %{price: nil, name: "Denim Pants", quantity_by_size: %{}},
#      %{price: nil, name: "Denim Skirt", quantity_by_size: %{}}
#    ]
```

## 3. Atualizar os nomes dos artigos

Reparaste que alguns nomes de artigos têm uma palavra que já não gostas de usar. Agora precisas de atualizar todos os nomes de artigos com essa palavra.

Implementa a função `update_names/3`. Deve receber o inventário, a palavra antiga que queres remover e uma palavra nova que queres usar em vez dela. Deve devolver uma lista de artigos com os nomes atualizados.

```elixir
BoutiqueInventory.update_names(
  [
    %{price: 40, name: "Black T-shirt", quantity_by_size: %{}},
    %{price: 70, name: "Denim Pants", quantity_by_size: %{}},
    %{price: 65, name: "Denim Skirt", quantity_by_size: %{}},
    %{price: 40, name: "Orange T-shirt", quantity_by_size: %{}}
  ],
  "T-shirt",
  "Tee"
)

# => [
#      %{price: 40, name: "Black Tee", quantity_by_size: %{}},
#      %{price: 70, name: "Denim Pants", quantity_by_size: %{}},
#      %{price: 65, name: "Denim Skirt", quantity_by_size: %{}},
#      %{price: 40, name: "Orange Tee", quantity_by_size: %{}}
#    ]
```


## 4. Aumentar a quantidade do artigo

Alguns artigos estavam a vender especialmente bem, por isso encomendaste mais, em todos os tamanhos.

Implementa a função `increase_quantity/2`. Deve receber um único artigo e um número `n`, e devolver esse artigo com a quantidade de cada tamanho aumentada em `n`.

```elixir
BoutiqueInventory.increase_quantity(
  %{
    name: "Polka Dot Skirt",
    price: 68,
    quantity_by_size: %{s: 3, m: 5, l: 3, xl: 4}
  },
  6
)

# => %{
#      name: "Polka Dot Skirt",
#      price: 68,
#      quantity_by_size: %{l: 9, m: 11, s: 9, xl: 10}
#    }
```

## 5. Calcular a quantidade total do artigo

Para saberes quanto espaço precisas no teu armazém, tens de saber quantas unidades tens de cada artigo no total.

Implementa a função `total_quantity/1`. Deve receber um único artigo e devolver quantas peças tens no total, em qualquer tamanho.

```elixir
BoutiqueInventory.total_quantity(%{
  name: "Red Shirt",
  price: 62,
  quantity_by_size: %{s: 3, m: 6, l: 5, xl: 2}
})

# => 16
```
