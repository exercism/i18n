# Tipos de números

O Crystal tem uma variedade de tipos de números para diversos fins.
Por exemplo, alguns tipos são mais rápidos, mas têm um intervalo de valores possíveis mais pequeno do que outros.
Alguns têm um intervalo de valores possíveis mais amplo, mas são mais lentos.

No Crystal, existem tipos de inteiros com sinal e sem sinal.
Os tipos de inteiros com sinal podem ser positivos ou negativos.
Os tipos de inteiros sem sinal só podem ser positivos.

## Tipos de inteiros com sinal

Estes são os [tipos de inteiros com sinal][int] no Crystal:

| Tipo     | Tamanho (bits) | Intervalo                                                                                                   |
| -------- | -------------- | ----------------------------------------------------------------------------------------------------------- |
| `Int8`   | 8              | -128 a 127                                                                                                  |
| `Int16`  | 16             | -32_768 a 32_767                                                                                            |
| `Int32`  | 32             | -2_147_483_648 a 2_147_483_647                                                                              |
| `Int64`  | 64             | -9_223_372_036_854_775_808 a 9_223_372_036_854_775_807                                                      |
| `Int128` | 128            | -170_141_183_460_469_231_731_687_303_715_884_105_728 a 170_141_183_460_469_231_731_687_303_715_884_105_727 |

Os tipos mais pequenos usam menos memória e são mais rápidos do que os tipos maiores, mas têm um intervalo de valores possíveis mais pequeno.

Quando sabes que os valores vão estar dentro de um determinado intervalo, o melhor é usar o tipo mais pequeno possível para poupar memória e melhorar o desempenho.

O tipo de inteiro predefinido é `Int32`.
Para declarares um inteiro com um tipo específico, podes usar o nome do tipo como sufixo, acrescentando `<number>_I <bit>`.

```crystal
1_i8.class
# => Int8
```

Podes usar o método `to_i<bit>` para converter entre diferentes tipos de inteiros.
O método `to_i` converte para o tipo de inteiro predefinido, `Int32`.

```crystal
1_i8.to_i16.class
# => Int16

2_i16.to_i.class
# => Int32
```

## Tipos de inteiros sem sinal

Estes são os tipos [inteiro sem sinal][uint] no Crystal:

`UInt8`, `UInt16`, `UInt32`, `UInt64`, `UInt128`

A única diferença entre inteiros com sinal e sem sinal é que os inteiros sem sinal só podem ser positivos.
Para declarares um inteiro sem sinal com um tipo específico, podes usar o nome do tipo como sufixo, acrescentando `<number>_u<bit>`.
Podes usar o método `to_u<bit>` para converter entre diferentes tipos de inteiros sem sinal.
O método `to_u` converte para o tipo de inteiro sem sinal predefinido, `UInt32`.

```crystal
1_u8.to_u16.class
# => UInt16
```

## Tipos de vírgula flutuante

Estes são os tipos de vírgula flutuante no Crystal:

| Tipo      | Tamanho (bits) | Intervalo            |
| --------- | -------------- | -------------------- |
| `Float32` | 32             | 1.2E-38 a 3.4E+38    |
| `Float64` | 64             | 2.3E-308 a 1.7E+308  |

Existem dois [tipos de vírgula flutuante][float] diferentes; um é mais preciso do que o outro.

O tipo de vírgula flutuante predefinido é `Float64`.

Podes usar o método `to_f<bit>` para converter entre diferentes tipos de vírgula flutuante.
O método `to_f` converte para o tipo de vírgula flutuante predefinido, `Float64`.

## Tipo depois de uma operação

Quando executas uma operação entre dois números, o resultado será do tipo do número com maior precisão.
A vírgula flutuante é mais precisa do que um inteiro, e um inteiro é mais exato do que um inteiro sem sinal.
Depois, o `Float64` é mais preciso do que o Float32, e assim por diante.

```crystal
(1_u8 + 2_u64).class
# => UInt64

(1_u8 + 2_i64).class
# => Int64

(1_u8 + 2.0_f64).class
# => Float64
```

## Vai mais fundo: inteiros sem sinal vs inteiros com sinal

~~~~exercism/advanced
Nos bastidores, o que distingue os inteiros sem sinal dos inteiros com sinal é que os inteiros com sinal usam o primeiro bit para guardar o sinal.
O sinal é positivo ou negativo.
Nos inteiros sem sinal, o primeiro bit é usado para guardar o valor.
Assim, para um inteiro com sinal de 32 bits, o valor máximo é 2^31 - 1.
Para um inteiro sem sinal de 32 bits, o valor máximo é 2^32 - 1.

Se quiseres saber mais sobre a distinção entre valores com sinal e sem sinal, podes ler mais sobre isso na [Wikipedia](https://en.wikipedia.org/wiki/Signedness).
~~~~
