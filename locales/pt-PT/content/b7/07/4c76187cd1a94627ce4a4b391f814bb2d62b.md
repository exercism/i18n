# Testes

Há um script Perl com a extensão `.t` na pasta `t/`. Este script será usado para testar a tua solução.
Podes correr os testes com o comando:

```bash
`prove`
```

Encontras documentação sobre as asserções usadas nos ficheiros de teste em [Test2::Manual::Testing::Introduction][test2-manual].

[test2-manual]: https://metacpan.org/pod/Test2::Manual::Testing::Introduction
