# Introdução

O Swift oferece uma variação da sua sintaxe quando se lida com closures, conhecida como closures à direita. As closures à direita surgem quando o último parâmetro da lista de parâmetros de uma função tem um tipo de função. Neste caso, se estiveres a passar uma closure, esta pode ser escrita _depois_ do parêntese de fecho e a etiqueta do argumento é omitida. Repara que, se a função tiver apenas um parâmetro, os parênteses podem ser omitidos por completo.

```swift
func fetchURL(_ urlString: String,
              uponReceipt handleResult: (String) -> ()
             )  -> () {
  if let url = URL(string: urlString), let htmlString = fetch(url) {
    handleResult(htmlString)
  }
}

fetchURL("https://www.swift.org") { print($0) }
// prints the fetched html string

["apple", "ball", "carrot"].sorted { $0.count < $1.count }
```
