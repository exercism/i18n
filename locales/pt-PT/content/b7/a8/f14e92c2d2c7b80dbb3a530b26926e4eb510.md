# Impressão

A impressão em Cairo permite-te mostrar mensagens e valores na consola, o que torna mais fácil depurar programas ou comunicar informação durante a execução.

O sistema de impressão é versátil e simples, e fornece ferramentas para formatar e apresentar dados de vários tipos.

## Noções básicas de impressão

Cairo fornece duas macros principais para imprimir texto na consola:

- **`println!`**: imprime a saída numa nova linha.
- **`print!`**: imprime a saída na mesma linha, sem acrescentar uma nova linha.

Ambas as macros recebem um `ByteArray` como argumento principal, que pode ser uma string simples ou uma string formatada com placeholders para valores.

```rust
// Printing a simple message
println!("Hello, Cairo!");

// Printing with values
let x = 10;
let y = 20;
println!("Values: x = {}, y = {}", x, y);
```

No exemplo acima:

- Os placeholders `{}` são substituídos pelos valores de `x` e `y`.
- O `println!` garante que a saída termina com uma nova linha.

## Formatação de strings

Por vezes, podes precisar de criar uma string formatada sem a imprimir de imediato.

A macro `format!` permite-te fazer isso.

Funciona de forma semelhante ao `println!`, mas devolve um `ByteArray` em vez de enviar a saída para a consola.

```rust
let s1: ByteArray = "tic";
let s2: ByteArray = "tac";
let s3: ByteArray = "toe";

// Create a formatted string
let result = format!("{s1}-{s2}-{s3}");

println!("{}", result); // Output: tic-tac-toe
```

Neste exemplo:

- O `format!` combina `s1`, `s2` e `s3` numa única string, separando-as com hífenes (`-`).
- A string resultante pode ser reutilizada ou impressa mais tarde.

## Imprimir tipos de dados personalizados

Por predefinição, Cairo só consegue imprimir tipos básicos, como números inteiros e strings.

Se tentares imprimir um tipo personalizado, como uma struct, vais encontrar um erro, a menos que o tipo implemente os traits `Display` ou `Debug`.

### Usar `Display` para formatação personalizada

O trait `Display` permite-te definir como um tipo personalizado deve ser impresso.

Aqui está um exemplo:

```rust
use core::fmt::{Display, Formatter, Error};

struct Point {
    x: u8,
    y: u8,
}

impl PointDisplay of Display<Point> {
    fn fmt(self: @Point, ref f: Formatter) -> Result<(), Error> {
        write!(f, "Point({}, {})", *self.x, *self.y)
    }
}

let p = Point { x: 3, y: 4 };
println!("{}", p); // Output: Point(3, 4)
```

Neste exemplo:

- A função `fmt` define como a struct `Point` é convertida numa string imprimível.
- A macro `write!` acrescenta a string formatada ao `Formatter`.

### Depurar com `Debug`

Para fins de depuração, Cairo fornece o trait `Debug`.

Podes derivá-lo automaticamente para a maioria dos tipos, o que torna rápido e fácil imprimir os detalhes internos das tuas structs.

```rust
#[derive(Debug)]
struct Point {
    x: u8,
    y: u8,
}

let p = Point { x: 3, y: 4 };
println!("{:?}", p); // Output: Point { x: 3, y: 4 }
```

Neste exemplo:

- O `#[derive(Debug)]` gera automaticamente a implementação do trait `Debug`.
- O placeholder `{:?}` diz ao `println!` para usar o trait `Debug` na formatação.

## Impressão em hexadecimal

Cairo permite imprimir números inteiros em formato hexadecimal com o placeholder `{:x}`.

```rust
let value: u32 = 255;
println!("{:x}", value); // Output: ff
```

Isto é especialmente útil quando trabalhas com representações de dados de baixo nível.
