# Introdução

Em Haxe, as exceções são uma forma segura de tratar erros que ocorrem durante a execução do código. Todas as exceções devem conter uma mensagem que descreve o erro. Podemos _lançar_ exceções com a palavra-chave `throw`:

```haxe
public function main(num:Int) {
  if (num < 10) {
    throw "Argument num cannot be greater than 10";
  }
  // ...
}
```

Quando uma exceção é lançada, o código procura uma parte que esteja encarregada de tratar o erro. Se não encontrar nenhuma, mostra a mensagem de erro e, ao mesmo tempo, interrompe a execução do programa.

Para tratar exceções em Haxe, usamos o bloco `try-catch`. Esta instrução de bloco é composta por um bloco `try` e um ou mais blocos `catch`. O bloco `try` _tenta_ executar uma parte do código, enquanto o bloco `catch` fica à espera de que seja lançada uma exceção para a _capturar_, de modo a que a execução não seja interrompida. Quando o bloco `catch` captura uma exceção, também executa tudo o que está dentro do bloco:

```haxe
try {
  if (num < 10) {
    throw "Argument num cannot be greater than 10";
  }
} catch (e) {
  // All exceptions will be caught here
  trace(e.message); // Argument num cannot be greater than 10
}
```

O tipo do argumento do bloco `catch` deve ser omitido.
