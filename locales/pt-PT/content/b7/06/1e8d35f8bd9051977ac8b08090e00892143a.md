# Getters e setters

Getters e setters são métodos que te permitem ler e escrever o valor de uma propriedade de um objeto.
O Crystal tem macros, o que facilita definir getters e setters para uma propriedade.
As macros são uma forma de gerar código em tempo de compilação, o que será abordado mais adiante no conceito de macro.

Em Ruby, estes métodos são definidos com os métodos `attr_reader`, `attr_writer` e `attr_accessor` e, à primeira vista, são muito semelhantes à implementação do Crystal.
O Crystal definiu-os como macros `getter`, `setter` e `property`.

## Getters

O getter é uma macro que define um método que devolve o valor de uma variável de instância.
Isto significa que já não tens de escrever `@` antes da variável de instância quando queres aceder-lhe (em métodos, excluindo o initialize); em vez disso, podes chamar o método que a macro getter definiu.

A macro getter pode aceitar várias variáveis de instância, separando-as por vírgulas.

```crystal
# This:
class Person
  @name : String
  @age : Int32

  def name
    @name
  end

  def age
    @age
  end
end

# Is the same as this:
class Person
  @name : String
  @age : Int32

  getter name, :age
end
```

Como podes ver, usar o getter reduz a quantidade de código que escreves e torna-o mais fácil de ler.
Além disso, Ruby e Crystal diferem no seguinte: o Crystal aceita tanto o nome da variável como o símbolo como argumentos para a macro getter.
Os símbolos serão abordados mais adiante no conceito de símbolo.

## Setters

O setter é uma macro que define um método que atribui o valor de uma variável de instância.
Esta macro não é assim tão comum e, em vez dela, costuma usar-se a macro `property`.
Os métodos criados serão algo como `name_of_method=`; é o `=` que permite definir a propriedade.

Esta definição de método é um pouco especial, pois o argumento que o método recebe fica depois do sinal `=`.
Vários outros métodos especiais do Crystal usam esta sintaxe, como o método `+`.

Tal como acontece com a macro getter, quando queres atualizar o valor de uma variável de instância depois de definires um setter, podes chamar o método que a macro setter definiu.

```crystal
# This:
class Person
  @name : String
  @age : Int32

  def name=(name : String)
    @name = name
  end

  def age=(age : Int32)
    @age = age
  end
end

# Is the same as this:
class Person
  @name : String
  @age : Int32

  setter name, :age
end
```

## Property

A macro property define tanto um getter como um setter para uma variável de instância.

```crystal
class Person
  @name : String
  @age : Int32

  property name, :age
end
```
