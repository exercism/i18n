# Instruções adicionais

## Palavras

Implementa:

- `grep ( pattern flags files -- lines )`

`pattern` é a string de pesquisa, `flags` é um array de zero ou mais das strings de flags `"-n"`, `"-l"`, `"-i"`, `"-v"` e `"-x"`, e `files` é um array de um ou mais nomes de ficheiros. Devolve as linhas correspondentes (com os prefixos de nome de ficheiro e de número de linha que forem pedidos) como um array de strings.

Quando é dada a flag `-l`, devolve um array com os nomes dos ficheiros que contêm pelo menos uma correspondência.

## Leitura de ficheiros

Lê as linhas de um ficheiro com `file-lines`, passando uma codificação:

```factor
USING: io.encodings.utf8 io.files ;

"iliad.txt" utf8 file-lines
! => { "Achilles sing, O Goddess! Peleus' son;" ... }
```

Os três ficheiros de exemplo (`iliad.txt`, `midsummer-night.txt` e `paradise-lost.txt`) vêm com o exercício no diretório de trabalho, por isso basta lê-los pelo nome.
