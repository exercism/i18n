# Convenção do Ameba

**Linha %{line_number}** :  %{message} foi assinalado pela Ameba.

Isto significa que este código não segue as convenções gerais de [estilo de código][code style].
Embora este tipo de problema, em geral, não afete a forma como o código é _executado_, pode prejudicar
a legibilidade ou o desempenho de ferramentas automáticas, como geradores de documentação ou executores de testes.

[code style]: https://crystal-lang.org/reference/latest/conventions/coding_style.html
