# Instruções

Um violino afina-se de ouvido, com base numa nota de referência. As cordas
estão muito afastadas em termos de altura e os números envolvidos não são
inteiros.

As cinco tarefas vão todas para a classe `TUNING_THE_STRINGS`.

## 1. Subir uma oitava

Uma nota uma oitava acima tem o dobro da frequência.

```sather
TUNING_THE_STRINGS::octave_up(440.0d)
-- => 880.0d
```

## 2. Descer uma oitava

Uma oitava abaixo é metade.

```sather
TUNING_THE_STRINGS::octave_down(440.0d)
-- => 220.0d
```

## 3. A meio caminho

Dadas duas frequências, devolve a que fica exatamente a meio das duas.

```sather
TUNING_THE_STRINGS::midpoint(440.0d, 442.0d)
-- => 441.0d
```

## 4. Quanto está desafinado?

Quando duas notas estão próximas mas não são iguais, ouves um batimento por
segundo por cada ciclo de diferença entre elas. Devolve a distância entre as
frequências. A resposta nunca é negativa, seja qual for a nota mais aguda.

```sather
TUNING_THE_STRINGS::beats_per_second(441.5d, 440.0d)
-- => 1.5d
```

## 5. Dividir o tempo de prática

Dados um número de minutos e um número de músicos, quantos minutos cabem a
cada um? Os minutos e os músicos são números inteiros, mas a resposta pode
não ser.

```sather
TUNING_THE_STRINGS::minutes_each(45, 2)
-- => 22.5d
```
