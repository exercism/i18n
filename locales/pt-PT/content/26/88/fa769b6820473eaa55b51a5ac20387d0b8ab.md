# Dicas

## 1. Estima o tempo de preparação

- Usa a [função incorporada `len()`][len-builtin] para determinar o número de camadas (o comprimento da slice de camadas).

## 2. Calcula as quantidades necessárias de massa e molho

- Primeiro, cria duas variáveis para acompanhar a quantidade de massa e de molho.
- Usa um ciclo for para percorrer as camadas.
- Se encontrares uma camada `'noodles'` ou `'sauce'` no teu ciclo, aumenta a quantidade guardada na variável correspondente.

## 3. Adiciona o ingrediente secreto

- Volta a ver [slices][concept-slices] para descobrires como obter um elemento de uma slice e como substituir um elemento numa slice.
- O índice do último elemento de uma slice `a` é `len(a) - 1`.

## 4. Escala a receita

- Primeiro, cria uma nova slice com o mesmo tamanho da slice de entrada
- Usa um [ciclo for][for-loop] para percorrer a slice de entrada e gerar a slice de saída
