# Instruções

Um anagrama é um rearranjo de letras que forma uma nova palavra.
Dada uma palavra e uma lista de candidatos, seleciona a sublista de anagramas da palavra dada.

Dada a palavra `"listen"` e uma lista de candidatos como `"enlists" "google"
"inlets" "banana"`, o programa deve devolver uma lista que contenha
`"inlets"`.
