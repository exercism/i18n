# Instalação

Este track depende do [Wren Console][wren-console] do início ao fim para proporcionar um ambiente de execução local para Wren. Isto significa que assumimos que toda a execução de Wren no teu computador acontece através do [Wren Console][wren-console]. Não confundas isto com a <abbr title="Interface de linha de comandos">CLI</abbr> oficial do Wren. Num mundo perfeito, poderias usar esse ambiente de execução, mas neste momento [tem](https://github.com/wren-lang/wren-cli/pull/74) [vários](https://github.com/wren-lang/wren/pull/1006) [problemas](https://github.com/wren-lang/wren-cli/issues/108) [diferentes](https://github.com/wren-lang/wren-cli/pull/105) que o tornam uma escolha pouco ideal para aprender Wren com o Exercism.

O Wren Console deriva do Wren CLI, resolve estes problemas e acrescenta funcionalidades que tornam a tua experiência de aprendizagem mais fluida. Não te preocupes: os conhecimentos e os conceitos da linguagem Wren que vais aprender aqui aplicam-se onde quer que venhas a usar Wren no futuro.

## Visão geral da instalação

- Instala o Git para teres o comando `git`
- Instala o [Wren Console][wren-console] para teres o comando `wrenc`

### Instalar o Git

Vais precisar do executável `git` instalado e no teu path. É assim que o Wren Package instala pacotes (como o conjunto de testes de que vais precisar para testar os teus exercícios, etc.).

- **Windows** - O [download oficial do Git](https://git-scm.com/download/win) é um bom ponto de partida.
-  **Linux** - O teu gestor de pacotes preferido deve dar-te uma ajuda.
- **Mac** - Todas as versões recentes do Mac OS trazem o `git` já incluído.

Podes confirmar que o Git está instalado com `git --version`:

```
$ git --version
git version 2.31.1
```

Não te preocupes se a versão exata não coincidir, normalmente não é assim tão importante.


### Instalar o Wren Console

#### Windows

Muito provavelmente vais querer [descarregar a versão mais recente][releases] do GitHub. Depois disso, tens de descompactar e copiar o executável `wrenc` para o teu path.

Também podes [compilar a partir do código-fonte][build-from-source] com o Visual Studio.

#### Linux

Podes [descarregar a versão mais recente][releases] do GitHub ou [compilar a partir do código-fonte][build-from-source].

```sh
wget -c https://github.com/joshgoebel/wren-console/releases/download/v0.3.1/wren-console-v0.3.1-linux.tar.gz
tar xzf wren-console-v0.3.1-linux.tar.gz
```

E certifica-te de que está disponível no teu `PATH`.

```sh
cp bin/wrenc /usr/local/bin/
```


#### Mac

A instalação mais fácil é através do tap e da fórmula [Homebrew][homebrew] do Exercism:

```
brew tap exercism/wren
brew install wren-console
```

Em alternativa, podes [descarregar a versão mais recente][releases] do GitHub e instalá-la manualmente como mostram as instruções para Linux. Compilar a partir do código-fonte também é bastante simples, se estiveres familiarizado com este tipo de coisas.

### Testar a instalação

Depois de achares que tens o executável instalado corretamente, é boa ideia testar se está tudo a funcionar.

1. Abre um _terminal_ (`Terminal`, `cmd`, `Powershell`, `bash`, ...)
2. Executa `wrenc -v`

Deves ver as versões do `wrenc` e do Wren listadas:

```
wrenc v0.3.1 (wren v0.4.0)
```

**Nota**: É importante que abras uma janela de terminal _nova_. As janelas de terminal abertas podem não ter sido atualizadas depois de a instalação terminar. Isto significa que os terminais abertos não sabem que foi instalado um novo programa.

> _**Ajuda**_: `'wrenc' is not recognised`
>
> Provavelmente não colocaste o `wrenc` no teu PATH... No MacOS e no Linux podes alterar o teu path acrescentando o seguinte a
> `~/.bash_profile` ou `~/.zshrc`:
>
> ```bash
> export PATH=/path/to/your/wrenc/:$PATH
> ```
> **Não faço ideia se isto está correto.**
> No Windows, abre o start menu e procura por "environment variables". Tens
> de editar a entrada `PATH` e _acrescentar_ aqui o caminho para os binários
> do `wrenc`. Normalmente estão em `C:\Program Files\nodejs`. Se navegares
> até lá com o `File Explorer`, deves encontrar `node.exe`, `npm.bat` e
> `npx.bat`.
>
> Fecha todos os terminais abertos e abre um novo.

## Requisitos dos exercícios

Segue [estas instruções][cli-walkthrough] para descarregar a CLI `exercism` para o teu sistema operativo.

Depois de a CLI estar toda configurada, descarrega o primeiro exercício, `hello-world`:

```bash
$ exercism download --exercise=hello-world --track=wren
```

Cada exercício precisa depois de alguns pacotes Wren para correr os testes. Para os instalares, executa este comando dentro do diretório do exercício:

```bash
$ wrenc package.wren install
```
