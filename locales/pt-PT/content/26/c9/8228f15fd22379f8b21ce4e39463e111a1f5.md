# Sobre

O Cairo é uma linguagem inspirada no Rust que pretende facilitar o cálculo de valores fidedignos em máquinas em que não confias, recorrendo a [provas de validade][zkp].
É uma linguagem de programação concebida para uma CPU virtual com o mesmo nome, capaz de provar de forma eficiente a execução de qualquer programa que nela corra.
Isto significa que podes realizar operações demoradas numa máquina em que não confias e verificar o resultado muito rapidamente numa máquina mais barata.

Um dos principais casos de uso do Cairo é escrever contratos inteligentes para a [Starknet](https://www.starknet.io/), uma Layer 2 construída sobre o Ethereum. Em vez de todos os participantes da rede verificarem todas as interações dos utilizadores, apenas um nó, designado provador, executa os programas e gera provas de que os cálculos foram feitos corretamente. Estas provas são depois verificadas por um contrato inteligente na Ethereum. Isto exige muito menos poder computacional, o que aumenta a capacidade de processamento e reduz os custos das transações, sem pôr em causa a segurança da Ethereum.

Outro caso de uso notável do Cairo é o treino de modelos de IA. Imagina que tens um conjunto de dados enorme e queres treinar um modelo de IA com ele, mas não tens a infraestrutura necessária. Podes pagar a um grande fornecedor de modelos de IA para treinar a IA com os teus dados e devolver-te o modelo treinado. Como o fornecedor usou o Cairo para escrever e treinar o seu modelo de IA, pode produzir uma "prova" que podes usar para verificar que usou de facto todo o conjunto de dados que lhe deste, garantindo a integridade do processo de treino e assegurando que não foram usados outros dados nem dados parciais.

O Cairo é bastante diferente das linguagens de programação tradicionais, sobretudo na forma como executa os programas e otimiza o desempenho. Os programas podem ser executados por um provador, tal como noutras linguagens, embora com algum custo de desempenho devido à virtualização da linguagem. Quando as provas são verificadas, a eficiência é crucial, pois a verificação pode acontecer em máquinas pequenas. O Cairo tem várias vantagens que tornam a verificação mais rápida. Uma delas, bastante notável, é o [não determinismo][np], a ideia de que podes, em teoria, usar um algoritmo diferente para verificar e para calcular. Vejamos o exemplo de ordenar um array em Cairo: o provador tem de ordenar o array, enquanto o verificador só precisa de confirmar que o array está ordenado, o que é muito mais barato. Além disso, o modelo de memória do Cairo é imutável, ou seja, os valores não podem ser alterados depois de escritos. O Cairo oferece abstrações que ajudam os programadores a lidar com estas restrições, mas não simula totalmente a mutabilidade. Isto significa que os programadores têm de estar atentos à gestão de memória e às estruturas de dados para otimizarem o desempenho.
