# Sobre

Podes tornar um parâmetro de um método opcional atribuindo-lhe um valor por omissão. Ao chamar um método com parâmetros opcionais, quem chama não é obrigado a passar um valor para eles. Se não for passado nenhum valor a um parâmetro opcional, é usado o seu valor por omissão.

Os parâmetros opcionais têm de ficar no fim da lista de parâmetros; não podem ser seguidos de parâmetros não opcionais.

```haxe
class Card {
  static function newYear(year = 2021):String {
    return "Happy " + year;
  }
}

Card.newYear(); // Happy 2020
Card.newYear(1990); // Happy 1990
```

O parâmetro opcional pode ser definido como `null` com o operador `?` antes do nome da variável:

```haxe
function newYear(?year:Int) {
  if (year != null)
    return "It's " + year;
  return "Year is null";
}

newYear(); // Year is null
```
