# Sobre

As [expressões `throw`][throw-expressions] são uma alternativa às instruções `throw` e, em particular, podem aumentar o poder das expressões ternárias e de outras expressões compostas.

```csharp
string trimmed = str == null ? throw new ArgumentException() : str.Trim();
```

Se `str` for `null` no código acima, é lançada uma exceção.

[throw-expressions]: https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/keywords/throw#the-throw-expression
