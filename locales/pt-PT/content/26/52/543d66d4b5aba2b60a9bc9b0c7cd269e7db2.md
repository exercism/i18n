# Introdução

Um método é uma função com um argumento especial: o _recetor_.
O recetor aparece na sua própria lista de argumentos, entre a palavra-chave `func` e o nome do método.

```go
func (receiver type) MethodName(parameters) (returnTypes) {

}
```

Só podes definir um método com um recetor cujo tipo esteja definido no mesmo pacote que o método.

```go
type Person struct {
    Name string
}

func (p Person) Greetings() string {
	return fmt.Sprintf("Welcome %s!", p.Name)
}

s := Person{Name: "Bronson"}
fmt.Println(s.Greetings())
// Output: Welcome Bronson!
```

Há dois tipos de recetores: os recetores de valor e os recetores de ponteiro.

Os métodos com um recetor de valor operam sobre uma cópia do valor que lhes é passado. Por isso, qualquer modificação feita ao recetor dentro do método não é visível para quem chama o método.

Podes declarar métodos com recetores de ponteiro para modificar o valor para o qual o recetor aponta.
Para isso, coloca um `*` antes do nome do tipo: por exemplo, com o tipo `rect`, um recetor de ponteiro declara-se como `*rect`.
Essas modificações também são visíveis para quem chama o método.

```go
type rect struct {
	width, height int
}
func (r *rect) squareIt() {
	r.height = r.width
}

r := rect{width: 10, height: 20}
fmt.Printf("Width: %d, Height: %d\n", r.width, r.height)
// Output: Width: 10, Height: 20

r.squareIt()
fmt.Printf("Width: %d, Height: %d\n", r.width, r.height)
// Output: Width: 10, Height: 10

```
