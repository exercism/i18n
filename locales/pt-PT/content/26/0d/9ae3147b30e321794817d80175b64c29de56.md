# Sobre

Grande parte das características do [Red](https://www.red-lang.org) vem do facto de a base da sua criação ter sido o [Rebol](http://www.rebol.com), e o desenvolvimento do Red começou como uma alternativa de código aberto da comunidade. Entretanto, o desenvolvimento do Rebol parou e o Red está constantemente a evoluir.

## Legado do Rebol

Tal como o Rebol, o Red é uma linguagem de programação **de uso geral**. Podes usá-la para criar qualquer aplicação que queiras. Para ser o mais familiar possível para os programadores, são implementados **vários paradigmas**: *imperativo*, *funcional*, *de objetos*, *simbólico* e *reativo*. Apesar de toda a sua cadeia de ferramentas caber num download de 1,5 MB, tem implementações de **Interface Gráfica do Utilizador** para todos os principais sistemas operativos (Windows, Linux, macOS) e não tem dependências de bibliotecas externas.

O Red esforça-se por ser **o mais simples possível**. Foi concebido com os compromissos mais utilizáveis e com predefinições sensatas, de modo a permitir concluir qualquer tarefa sem nos sentirmos sobrecarregados com o número de escolhas. Está focado na **legibilidade** humana, por isso o açúcar sintático é reduzido ao mínimo e os programas tentam assemelhar-se a frases de linguagem natural. Como resultado, o Red e o Rebol são [altamente expressivos](https://redmonk.com/dberkholz/2013/03/25/programming-languages-ranked-by-expressiveness/).

Uma característica invulgar do Red é a sua **homoiconicidade**, o que faz com que um programa em Red possa ser manipulado como qualquer estrutura de dados do Red. Por isso, o Red e o Rebol são também formatos de dados. Um facto curioso é que o [JSON foi inspirado no Rebol](http://www.rebol.com/article/0522.html).

## Red

Em comparação com o Rebol, o Red melhorou bastante. Pode ser **compilado** para um único executável para cada plataforma suportada, a partir de qualquer uma delas. Assim, podes compilar programas de Windows no Linux ou programas de macOS no Windows. Existe também uma **consola REPL** disponível, tanto em linha de comandos como gráfica, que permite manipular dados instantaneamente com comandos Red, escrevendo-os um a um.

O que também distingue o Red é o seu dialeto, o Red/System, que faz do Red uma linguagem **full stack**, permitindo desenvolver código de baixo nível como em C.

## Missão

* Trazer a **diversão** de volta à programação
* Combater a complexidade do software

## Desenvolvimento

O Red é de código aberto. O seu desenvolvimento está alojado no [repositório do GitHub](https://github.com/red/red). Atualmente, o projeto está em **fase alfa**, por isso espera que as coisas mudem e se estraguem.
