# Instruções

Como quase toda a gente que tem um trabalho, a Layla, a alienígena do Lisp, às vezes precisa de fazer relatórios para dar informações a outras pessoas. Pergunta-te se a podes ajudar a formatar os dados que tem para esses relatórios.

## 1. Formatar valores trimestrais

A primeira coisa de que a Layla precisa é de uma função, `format-quarter-value`, que recebe dois parâmetros: o trimestre do calendário e o valor, e que os formata para um relatório. Deve resultar numa string.

```lisp
(format-quarter-value "last" 3.14) ; => "The value last quarter: 3.14"
(format-quarter-value "this" 0) ; => "The value this quarter: 0"
```

## 2. O relatório dos dois trimestres

A Layla agradece-te a função `format-quarter-value` e diz que vai ser muito útil na *próxima* função de que precisamos.

O relatório seguinte tem de mostrar o trimestre e o valor de dois trimestres, impressos em duas linhas.

Além disso, a saída tem de ser enviada para o stream fornecido como primeiro argumento.

Por exemplo: `(format-two-quarters t "last" 3.14 "this" 0)` produz o seguinte na saída padrão:

```

The value last quarter: 3.14
The value this quarter: 0

```

Repara nas linhas em branco à volta.

## 3. Legível para humanos vs. para alienígenas do Lisp

A Layla esqueceu-se de te dizer que os alienígenas do Lisp gostam de ver os valores de uma forma que seja legível como dados Lisp. Por isso, precisamos de uma nova função que possa ser lida como dados Lisp (mais uma vez, para o stream indicado):

```lisp
(format-two-quarters-for-reading nil "last" 3.14 "this" 0) ; =>

"(\"The value last quarter: 3.14\" \"The value this quarter: 0\")"
```
