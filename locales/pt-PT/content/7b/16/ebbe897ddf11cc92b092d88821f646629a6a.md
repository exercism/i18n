# Apêndice das instruções

## Mensagens de exceção

Por vezes, é necessário [lançar uma exceção](https://docs.python.org/3/tutorial/errors.html#raising-exceptions). Quando o fazes, deves incluir sempre uma **mensagem de erro significativa** para indicar qual é a origem do erro. Isto torna o teu código mais legível e ajuda muito na depuração. Nas situações em que sabes que a origem do erro será de um determinado tipo, podes optar por lançar um dos [tipos de erro incorporados](https://docs.python.org/3/library/exceptions.html#base-classes), mas deves continuar a incluir uma mensagem significativa.

Este exercício em particular exige que uses a [instrução raise](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement) para "lançar" vários `ValueErrors` se à classe `Tree()` for passada uma árvore que não pode ser reorientada, ou se não for possível encontrar um caminho entre um `start node` e um `end node`.
Os testes só passam se tanto usares `raise` com o tipo de `exception` esperado como incluíres a mensagem esperada com ele.

Verifica com atenção os testes e os resultados esperados.
