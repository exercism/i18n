# Política de entrada do clube de poesia

## História

Abriu um novo clube de poesia na cidade e estás a pensar ir. Como já houve incidentes no passado, o clube tem uma política de entrada muito específica que tens de dominar antes de tentares entrar.

Há duas portas no clube de poesia, ambas vigiadas. Para conseguires entrar, tens de descobrir a palavra-passe desse dia:

### Porta da frente

1. O guarda recita um poema, uma linha de cada vez;
   - Tens de responder com a letra adequada.
2. O guarda diz-te todas as letras com que respondeste de uma só vez;
   - Tens de formatar as letras como uma palavra com maiúscula inicial.

Por exemplo, um dos seus escritores favoritos é Michael Lockwood, que escreveu o seguinte poema _acróstico_, o que significa que a primeira letra de cada frase forma uma palavra:

```text
Stands so high
Huge hooves too
Impatiently waits for
Reins and harness
Eager to leave
```

Quando o guarda recita **Stands so high**, respondes **S**; quando recita **Huge hooves too**, respondes **H**.

Por fim, a palavra-passe que escreves é `Shire`, e podes entrar.

### Porta de trás

Na parte de trás do clube encontras os poetas mais conceituados, algo como a zona VIP. Como isto não é para todos, o processo da porta de trás é um pouco mais complicado.

1. O guarda recita um poema, uma linha de cada vez;
   - Tens de responder com a letra adequada.
2. O guarda diz-te todas as letras com que respondeste de uma só vez, _mas às vezes há espaços depois de cada frase_:
   - Tens de formatar as letras como uma palavra com maiúscula inicial
   - e pedir com educação, acrescentando `, please`

Por exemplo, o poema mencionado antes também é _telestíquio_, o que significa que a última letra de cada frase forma uma palavra:

```text
Stands so high
Huge hooves too
Impatiently waits for
Reins and harness
Eager to leave
```

Quando o guarda recita **Stands so high**, respondes **h**; quando recita **Huge hooves too**, respondes **o**.

Por fim, a palavra-passe que escreves é `Horse, please`, e podes festejar com os poetas conceituados.
