# Instruções

Vossa Majestade está a organizar um jantar na capital da [União de Kalmar][kalmar_union], Copenhaga.
É a maior festa do ano e todos os nobres estão convidados.
Mas espalham-se rumores pelo país de que há um plano para envenenar Vossa Majestade.

Sua Majestade pediu-te, a ti, detetor de venenos real, que descobrisses se alguma comida ou bebida está envenenada.
Sua Majestade planeia servir apenas **Mushroom pasties** como comida, mas para beber há uma variedade de bebidas.

## 1. Verifica se a comida está correta

Há uma grande probabilidade de a comida estar envenenada se não for o que Sua Majestade encomendou.
Se a comida não for o que Sua Majestade encomendou, deve ser deitada fora.

Implementa o método `check_food?`, que recebe o argumento `food`, que contém o nome da comida como uma `String`.
O método deve devolver a comida se for `Mushroom pasties`; caso contrário, deve devolver `nil`.

```crystal
CastleDinner.check_food?("Mushroom pasties")
# => "Mushroom pasties"

CastleDinner.check_food?("Bread")
# => nil
```

## 2. Verifica se a bebida está envenenada

É possível que a bebida esteja envenenada, mas é um pouco mais difícil de saber.
A bebida está envenenada se **não** incluir a letra `i` no nome, não importa se está em maiúscula ou minúscula.
A bebida deve ser deitada fora se estiver envenenada.

Implementa o método `check_drink?`, que recebe o argumento `drink`, que contém o nome da bebida como uma `String`.
O método deve devolver a bebida se não estiver envenenada; caso contrário, deve devolver `nil`.

```crystal
CastleDinner.check_drink?("Apple juice")
# => "Apple juice"

CastleDinner.check_drink?("Tea")
# => nil
```

## 3. Substitui a bebida

Vossa Majestade não quer deixar os convidados preocupados com veneno na comida.
Por isso, se a bebida estiver envenenada, deve ser substituída por uma nova bebida, mais concretamente **Apple juice**.

Implementa o método `replace_drink`, que recebe o argumento `drink`, que contém o nome da bebida como uma `String`.
O método deve devolver a bebida se não estiver envenenada; caso contrário, deve devolver `"Apple juice"`.

```crystal
CastleDinner.replace_drink("Orange juice")
# => "Orange juice"

CastleDinner.replace_drink("Tea")
# => "Apple juice"
```
