# Instruções

Neste exercício vamos simular a primeira jogada de um jogo de [Blackjack](https:#en.wikipedia.org/wiki/Blackjack).

Vais receber duas cartas e vais poder ver a carta destapada do dealer. Todas as cartas são representadas por uma string como "ace", "king", "three", "two", etc. Os valores de cada carta são:

| carta | valor | carta   | valor |
| :---: | :---: | :-----: | :---: |
|  ace  |  11   | eight   |   8   |
|  two  |   2   | nine    |   9   |
| three |   3   |  ten    |  10   |
| four  |   4   | jack    |  10   |
| five  |   5   | queen   |  10   |
|  six  |   6   | king    |  10   |
| seven |   7   | *other* |   0   |

**Nota**: Normalmente, os ases podem valer 1 ou 11, mas, para simplificar, vamos assumir que só podem valer 11.

Dependendo das tuas duas cartas e da carta do dealer, existe uma estratégia para a primeira jogada, na qual tens as seguintes opções:

- Ficar (S)
- Pedir carta (H)
- Dividir (P)
- Ganhar automaticamente (W)

Embora ainda não seja a ideal, vais seguir a estratégia que o teu amigo Alex anda a desenvolver, que é a seguinte:

- Se tiveres um par de ases, tens sempre de os dividir.
- Se tiveres um Blackjack (duas cartas que somam 21) e o dealer não tiver um ás, uma figura ou um dez, ganhas automaticamente. Se o dealer tiver alguma dessas cartas, tens de ficar e esperar que a outra carta seja revelada.
- Se as tuas cartas somarem um valor dentro do intervalo [17, 20], deves ficar sempre.
- Se as tuas cartas somarem um valor dentro do intervalo [12, 16], deves ficar sempre, a não ser que o dealer tenha um 7 ou mais; nesse caso, deves pedir carta sempre.
- Se as tuas cartas somarem 11 ou menos, deves pedir carta sempre.

## 1. Calcula o valor de uma carta qualquer.

Implementa uma função `parse_card` para calcular o valor numérico de uma carta:

```R
parse_card("ace")
# => 11
```

## 2. Implementa a lógica de decisão para a primeira jogada.

Escreve uma função `first_turn` que implementa a lógica de decisão descrita acima:

```R
first_turn(card1, card2, dealer_card)
```

Aqui estão alguns exemplos dos resultados esperados:

```R
first_turn("ace", "ace", "jack") == "P"
first_turn("ace", "king", "ace") == "S"
first_turn("five", "queen", "ace") == "H"
```
