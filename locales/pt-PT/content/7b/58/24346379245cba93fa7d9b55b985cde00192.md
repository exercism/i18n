# Introdução

Os [ciclos `repeat-while`][repeat-loops] são semelhantes aos ciclos `while`, mas com uma diferença fundamental: a verificação da condição acontece *depois* de o corpo do ciclo ser executado, e não antes.
Por isso, um ciclo `repeat-while` executa o seu bloco de código pelo menos uma vez, garantidamente.

```swift
repeat {
    print("This runs at least once")
} while false

print("Loop done")

// Prints:
// This runs at least once
// Loop done
```

[repeat-loops]: https://docs.swift.org/swift-book/LanguageGuide/ControlFlow.html#ID126
