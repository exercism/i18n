# Testes

## Clojure CLI

Os exercícios de Clojure no Exercism vêm com um ficheiro `deps.edn` com um alias `:test` para invocar o [cognitect-labs test-runner](https://github.com/cognitect-labs/test-runner):

``` bash
$ clj -X:test
```

Isto vai analisar o diretório `test` do teu projeto à procura de testes definidos com `clojure.test` e executá-los.

## Leiningen

Para executar os testes de um exercício com Leiningen, basta chamar:

``` bash
$ lein test

lein test bob-test

Ran 14 tests containing 14 assertions.
0 failures, 0 errors.
```
