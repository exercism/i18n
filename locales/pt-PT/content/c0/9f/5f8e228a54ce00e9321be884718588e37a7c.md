# Instruções

O trabalho no projeto do carro telecomandado continua. A largura de banda do sistema de telemetria é escassa e foi-te pedido que implementes um protocolo de mensagens para comunicar dados de telemetria.

Os dados são transmitidos num buffer (vetor de bytes). Quando se enviam números inteiros, o tamanho do buffer é reduzido através do protocolo descrito abaixo.

Cada valor deve ser representado no menor tipo inteiro possível (os tipos `byte` e `sbyte` não estão incluídos, pois a poupança seria trivial):

| De                         | Para                      | Tipo     |
| -------------------------- | ------------------------- | -------- |
| 4_294_967_296              | 9_223_372_036_854_775_807 | `long`   |
| 2_147_483_648              | 4_294_967_295             | `uint`   |
| 65_536                     | 2_147_483_647             | `int`    |
| 0                          | 65_535                    | `ushort` |
| -32_768                    | -1                        | `short`  |
| -2_147_483_648             | -32_769                   | `int`    |
| -9_223_372_036_854_775_808 | -2_147_483_649            | `long`   |

O valor deve ser convertido no número de bytes adequado ao tipo que lhe for atribuído. O buffer completo é composto por um byte que indica o número de bytes adicionais no buffer (_byte de prefixo_), seguido dos bytes que contêm o número inteiro (_bytes de carga útil_).

Alguns dos tipos usam um número idêntico de bytes (por exemplo, os tipos `uint` e `int`). Normalmente, teriam o mesmo _byte de prefixo_, mas isso tornaria a descodificação problemática. Para contornar isto, o protocolo introduz um pequeno truque: nos tipos com sinal, o valor do _byte de prefixo_ é `256` menos o número de bytes adicionais no buffer.

Na comunicação, só são enviados o byte de prefixo e o número de bytes seguintes indicado pelo prefixo. Internamente, é usado um buffer de 9 bytes (com zeros à direita, se necessário), tanto pelas rotinas de envio como pelas de receção.

## 1. Codifica um valor inteiro pronto a enviar

Implementa o método estático `TelemetryBuffer.ToBuffer()` para codificar um buffer com o parâmetro passado ao método.

```csharp
// Type: ushort, bytes: 2, signed: no, prefix byte: 2
TelemetryBuffer.ToBuffer(5)
// => {0x2, 0x5, 0x0, 0x0, 0x0, 0x0, 0x0, 0x0, 0x0 };

// Type: int, bytes: 4, signed: yes, prefix byte: 256 - 4
TelemetryBuffer.ToBuffer(Int32.MaxValue)
// => {0xfc, 0xff, 0xff, 0xff, 0x7f, 0x0, 0x0, 0x0, 0x0 };
```

## 2. Descodifica um buffer recebido

Implementa o método estático `TelemetryBuffer.FromBuffer()` para descodificar o buffer recebido e devolver o valor sob a forma de um `long`.

```csharp
TelemetryBuffer.FromBuffer(new byte[] {0xfc, 0xff, 0xff, 0xff, 0x7f, 0x0, 0x0, 0x0, 0x0 })
// => 2147483647
```

Se o byte de prefixo tiver um valor inesperado, deve ser devolvido `0`.
