# Introdução

Além da condicional, existe também a instrução `switch` para executar lógica de forma condicional. Utiliza-se quando é preciso comparar uma única variável com várias variantes. Para uma variável x, a instrução `if` em Haxe tem a seguinte sintaxe.

```haxe
var a = 2;

switch (a) {
  case 0:
    trace("a is 0");
  case 1:
    trace("a is 1");
  case 2:
    trace("a is 2");
  default:
    trace("a is something else");
}

// a is 2
```

O caso `default` é executado quando nenhum dos outros casos corresponde.
