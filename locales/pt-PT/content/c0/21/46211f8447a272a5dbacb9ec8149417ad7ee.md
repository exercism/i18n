# Introdução

Cairo disponibiliza dicionários como parte das suas bibliotecas principais, representados pelo tipo `Felt252Dict<T>`.

Em Cairo, o tipo das chaves de um dicionário está limitado a `felt252`, o que é diferente de outras linguagens, onde é possível definir o tipo da chave.

Para criar um dicionário, podes usar o método `default` do trait `Default`, assim:

```rust
let mut foo: Felt252Dict<u32> = Default::default();
```

As operações básicas mais utilizadas são:

1. `insert(felt252, T) -> ()` para escrever valores numa instância de dicionário e
2. `get(felt252) -> T` para ler valores a partir dela.

E é assim que usarias estas operações:

```rust
let mut foo: Felt252Dict<u32> = Default::default();
// Add a value to the dictionariy
foo.insert('bar', 42);
// Here we update the element of 'bar'
foo.insert('bar', 73);
// To retrieve a dictionary value, you can use
baz = foo.get('bar');
```

Se tentares obter o valor de uma chave que não existe no dicionário, é devolvido o valor zero do tipo de valor.

Isto pode baralhar-te, sobretudo se o valor predefinido do teu tipo de valor (por exemplo, 0 para um número inteiro) for um valor válido.

Também significa que não há forma de eliminar dados de um dicionário.

Algo a ter em conta quando integrares esta estrutura no teu código.
