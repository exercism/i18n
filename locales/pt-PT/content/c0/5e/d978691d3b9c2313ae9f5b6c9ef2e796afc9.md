# Dicas

## Geral

- Os [tuplos][tuple] são estruturas de dados imutáveis, com um tamanho fixo, que podem conter qualquer tipo de dados.
- Podem usar-se símbolos para representar estados finitos: este exercício usa `:cup`, `:fluid_ounce`, `:teaspoon`, `:tablespoon`, `:milliliter` para identificar as unidades utilizadas.

## 1. Obter a componente numérica de um par de volume

- Considera indexar o tuplo para devolver a componente numérica do par de volume.

## 2. Converter o par de volume em mililitros

- Usa a lógica de fluxo de controlo para determinar qual a lógica a aplicar, consoante a unidade.
- Implementa o método de conversão de todas as unidades para mililitros, incluindo de mililitros para mililitros.

## 3. Converter o par de volume em mililitros para outra unidade

- Usa a lógica de fluxo de controlo para determinar qual a lógica a aplicar, consoante a unidade.
- Implementa o método de conversão de mililitros para todas as unidades, incluindo de mililitros para mililitros.

## 4. Converter de qualquer unidade para qualquer unidade

- Reutiliza os métodos já criados para fazer a conversão no método `KitchenCalculator.convert`.
