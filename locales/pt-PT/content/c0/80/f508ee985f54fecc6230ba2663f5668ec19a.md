# Dicas

## Geral

- Consulta a [documentação do `elm/parser`][elm-parser]
- A introdução apresenta todos os conceitos necessários para resolver o exercício

## 1. Analisa o preço da pizza

- O [parser `int`][int] é dedicado a analisar números inteiros
- Mais do que um parser consegue tratar o €, mas o [`symbol`][symbol] é o mais adequado
- O [operador `(|.)`][(|.)] consegue analisar duas coisas, mas manter apenas uma

## 2. Analisa o indicador de vegetariano

- O [parser `oneOf`][oneOf] consegue tentar diferentes possibilidades
- Há mais do que uma forma de analisar uma string específica; neste caso, o [`keyword`][keyword] ou o [`symbol`][symbol] são adequados
- Há mais do que uma forma de devolver `True` quando um parser tem sucesso, e uma boa é usar o [`succeed`][succeed]

## 3. Analisa os nomes das pizzas e dos ingredientes

- O [parser `chompWhile`][chompWhile] é dedicado a analisar carateres arbitrários
- A [função `isAlpha`][isAlpha] consegue validar carateres ASCII maiúsculos e minúsculos
- A [função `map`][map] pode ser usada para modificar o conteúdo de um parser
- A [função `String.toLower`][toLower] consegue pôr uma string em minúsculas

## 4. Analisa uma lista de ingredientes

- O [parser `sequence`][sequence] é dedicado a analisar listas de itens
- Usa todas as funções adequadas que já definiste

## 5. Analisa uma pizza completa

- Com o [operador `(|=)`][(|=)] é bastante simples manter mais do que uma coisa numa pipeline
- Usa `Pizza` como construtor de tipo com o [`succeed`][succeed]
- Mais do que um parser consegue tratar ":" e "-", mas o [`symbol`][symbol] é o mais adequado
- O [parser `spaces`][spaces] é útil para eliminar espaços a mais
- Usa todas as funções adequadas que já definiste

## 6. Analisa um menu completo

- O [parser `sequence`][sequence] é dedicado a analisar listas de itens
- Lembra-te de que `spaces` também consome carateres de nova linha, o que pode interferir com o teu separador
- O [parser `end`][end] é dedicado a verificar se chegaste ao fim de uma string
- O [operador `(|.)`][(|.)] consegue analisar duas coisas, mas manter apenas uma
- Usa todas as funções adequadas que já definiste

## 7. Analisa nomes de ingredientes com várias palavras

- O [parser `chompWhile`][chompWhile] é dedicado a analisar carateres arbitrários
- A [função `isAlpha`][isAlpha] consegue validar carateres ASCII maiúsculos e minúsculos
- A [função `andThen`][andThen] pode ser usada para inspecionar o conteúdo de um parser
- A [função `problem`][problem] devolve um parser que chegou a um impasse
- A [função `String.toLower`][toLower] consegue pôr uma string em minúsculas
- A [função `String.trim`][trim] consegue eliminar os espaços em branco nas extremidades de uma string
