# Introdução

Todas as instâncias de uma struct ou de uma class têm uma propriedade implícita chamada `self`, que se refere à própria instância.
A utilização mais comum de `self` é distinguir entre uma propriedade de instância e um parâmetro com o mesmo nome:

```swift
struct Position {
    var x = 0

    mutating func move(x: Int) {
        // Here, 'self.x' refers to the struct's property,
        // while 'x' refers to the parameter passed to the method.
        self.x = x
    }
}
```

Os tipos de Swift também fornecem uma palavra-chave `Self` com maiúscula inicial, que se refere ao *tipo* da instância, e não à própria instância.
