# Introdução

Um ficheiro é apenas um fluxo com um nome no disco. O vocabulário [`io.files`][io.files] dá-te duas formas de trabalhar com um: palavras de conveniência de ficheiro inteiro, que leem ou escrevem tudo numa única chamada, e formas de abrir fluxos, para quando queres ler ou escrever de forma incremental.

Todas as palavras que mexem num ficheiro recebem uma **codificação**, o esquema que transforma bytes em carateres e vice-versa. Para texto, isso é quase sempre [`utf8`][utf8] de `io.encodings.utf8`.

## Ler um ficheiro inteiro

```
file-contents   ( path encoding -- str )
file-lines      ( path encoding -- seq )
```

`file-contents` devolve o ficheiro inteiro como uma única string; `file-lines` devolve um array com as suas linhas, sem as quebras de linha.

```factor
USING: io.encodings.utf8 io.files prettyprint ;

"sunny\ncloudy\n" "forecast.txt" utf8 set-file-contents

"forecast.txt" utf8 file-contents .
! => "sunny\ncloudy\n"

"forecast.txt" utf8 file-lines .
! => { "sunny" "cloudy" }
```

## Escrever um ficheiro inteiro

```
set-file-contents   ( str path encoding -- )
set-file-lines      ( seq path encoding -- )
```

Ambas **substituem** o conteúdo do ficheiro (criando-o se for preciso). `set-file-contents` escreve uma string tal e qual; `set-file-lines` escreve cada elemento de uma sequência na sua própria linha, acrescentando as quebras de linha por ti.

```factor
USING: io.encodings.utf8 io.files prettyprint ;

{ "sunny" "cloudy" } "forecast.txt" utf8 set-file-lines
"forecast.txt" utf8 file-contents .
! => "sunny\ncloudy\n"
```

## Acrescentar a um ficheiro

Para acrescentares a um ficheiro sem apagares o que já lá está, abre-o com um combinador `with-…` e escreve no fluxo ambiente dentro da citação:

```
with-file-appender   ( path encoding quot -- )
with-file-reader     ( path encoding quot -- )
with-file-writer     ( path encoding quot -- )
```

```factor
USING: io io.encodings.utf8 io.files prettyprint ;

"sunny\ncloudy\n" "forecast.txt" utf8 set-file-contents
"forecast.txt" utf8 [ "rainy" print ] with-file-appender
"forecast.txt" utf8 file-contents .
! => "sunny\ncloudy\nrainy\n"
```

Tal como todos os combinadores `with-…`, estes são âmbitos de destruição: o ficheiro é fechado quando a citação termina, mesmo que esta lance um erro.
