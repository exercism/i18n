# Dicas

## Geral

- Este desafio consiste em criar uma [_pilha_][Baeldung: The Stack Data Structure] com uma [lista ligada simples][singly linked list].
- Ao contrário das pilhas suportadas por `lists`, `collections.deque` ou `queue.LifoQueue`, pedimos-te que cries [`classes`][classes tutorial] `Node` e `LinkedList` personalizadas para guardar e ligar elementos.

![Diagrama que representa uma pilha implementada com uma lista ligada. Um círculo com contorno tracejado chamado New_Node encontra-se no extremo esquerdo, com duas setas pontilhadas a apontar para a direita. New_Node diz "(becomes head) - New_Node - next = node_6". A seta pontilhada de cima tem a etiqueta "push" e aponta para Node_6, acima e à direita. Node_6 diz "(current) head - Node_6 - next = node_5". Node_1 tem uma seta pontilhada a apontar para a direita, para um nó que diz "None".](https://assets.exercism.org/images/tracks/python/simple-linked-list/linked-list.svg)

- [Real Python: Linked Lists][Real Python Linked Lists], [Towards Data Science: Demystifying the Linked List][towards data science demystifying the linked list] e [ADS Stack in Python][Koder Dojo Coding an ADS Stack in Python] podem ser úteis para reveres os detalhes da implementação.
- A tua `LinkedList` deve aceitar um argumento `list` no seu _construtor_, mas não deve usar uma `list` para guardar nós ou elementos.
- `len()` é uma função incorporada para a maioria dos objetos Python.
Para que os _objetos personalizados_ suportem `len()`, é preciso definir o método especial [`__len__`][__len__].
- Em Python, a iteração é suportada para a maioria dos objetos do tipo sequência, contentor ou coleção.
Para que um objeto _personalizado_ suporte ciclos ou reordenação, é preciso definir o método especial `__iter__`.
[Implementing an iterator for a class][implementing iterators] pode ajudar-te a perceber como.
