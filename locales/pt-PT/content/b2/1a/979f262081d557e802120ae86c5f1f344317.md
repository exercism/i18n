# Instruções


És o maître d' de um restaurante de hotel.
A tua tarefa é gerir a disposição dos lugares na sala de jantar de acordo com o número de lugares disponíveis hoje, o número de reservas e os clientes que aparecem sem reserva e estão à espera de um lugar.
Para os efeitos deste exercício, os lugares são atribuídos pelo primeiro lugar vazio disponível.


Neste exercício, tens 6 desafios diferentes de organização da sala de jantar para completar.


## 1. Cria o mapa de lugares de hoje

Define a função `new_seating_chart(<size=22>)`, que recebe um argumento size que representa o número de lugares que vão ser postos na sala de jantar hoje.
Se não for indicado nenhum `size`, a função deve devolver um mapa de lugares com 22 lugares.
Os valores dos lugares devem ter `None` como marcador, para indicar que estão disponíveis para atribuir a um cliente.


## 2. Organiza as reservas

Define a função `arrange_reservations(<guest_names>)` com 1 parâmetro para uma lista de nomes de clientes.
Isto representa o número de pessoas que têm lugares reservados na sala de jantar hoje.


Esta função deve devolver um mapa de lugares em `dict` com o tamanho predefinido (22 lugares), com os clientes atribuídos a lugares pela ordem em que aparecem na lista de reservas.
Todos os lugares não atribuídos devem ficar com o valor `None`.
Se não houver clientes, deve ser devolvido um mapa de lugares "vazio", com `None` em todos os lugares.


```python
>>> arrange_reservations(guests=["Walter", "Frank", "Jenny", "Carol", "Alice", "George"])
...
{1: 'Walter', 2: 'Frank', 3: 'Jenny', 4: 'Carol', 5: 'Alice', 6: 'George', 7: None, 8: None, 9: None, 10: None, 11: None, 12: None, 13: None, 14: None, 15: None, 16: None, 17: None, 18: None, 19: None, 20: None, 21: None, 22: None}
```


## 3. Encontra todos os lugares "vazios"

Define a função `find_all_available_seats(<seats>)`, que recebe 1 parâmetro (_um dicionário com o mapa de lugares_) e devolve uma `list` com os números dos lugares que estão disponíveis para os clientes que estão à espera neste momento.
Se um lugar estiver vazio, o seu valor no dicionário será `None`. Os lugares ocupados terão o nome do cliente.


```python
>>> seats = {1: None, 2: 'Frank', 3: 'Jenny', 4: None, 5: 'Alice', 6: 'George', 7: None, 8: 'Carol', 9: None, 10: None, 11: None, 12: 'Walter'}

>>> find_all_available_seats(seats)
[1,4,7,9,10,11]
```

## 4. Capacidade atual de lugares vazios

Define a função `current_empty_seat_capacity(<seats>)`, que recebe 1 parâmetro: o `dict` com as reservas de lugares existentes.
A função deve devolver o número total de lugares vazios.

>>> curr_empty_seat_capacity({1: "Occupied", 2: None, 3: "Occupied"})

## 5. Devemos esperar?

Define a função `accommodate_waiting_guests(<seats>, <guests>)`, que recebe dois parâmetros.
O primeiro parâmetro será um `dict` com o mapa de lugares.
O segundo parâmetro será uma `list` com os clientes que apareceram sem reserva, de forma inesperada.
Primeiro, tens de descobrir quantos lugares estão disponíveis e se, neste momento, consegues sequer dar lugar aos clientes que apareceram sem avisar.

Se não tiveres lugares suficientes, devolve o `dict` do mapa de lugares sem alterações.

Se _houver_ lugares disponíveis, atribui lugares aos clientes no mapa de lugares e devolve-o atualizado.
**Dica:** Podes usar as funções definidas anteriormente para fazer os cálculos por ti.


```python
# Guests cannot be accommodated.
>>> starting_reservations = {1: 'Carol', 2: 'Alice', 3: 'George', 4: None, 5: None, 6: None, 7: 'Frank', 8: 'Walter'}
>>> accommodate_guests(starting_reservations, ["Mort", "Suze", "Phillip", "Tony"])
...
{1: 'Carol', 2: 'Alice', 3: 'George', 4: None, 5: None, 6: None, 7: 'Frank', 8: 'Walter'}


# Guests can be accommodated.
>>> starting_reservations = {1: None, 2: None, 3: None, 4: 'Carol', 5: 'Alice', 6: 'George', 7: None, 8: None, 9: None, 10: None, 11: None, 12: None, 13: None, 14: None, 15: None, 16: None, 17: None, 18: 'Frank', 19:  'Jenny', 20: None, 21: None, 22: 'Walter'}
>>> accommodate_guests(starting_reservations, ["Mort", "Suze", "Phillip", "Tony"])

```

## 6. Lugares vazios

Define a função `empty_seats(<seats>, <seat_numbers>)`, que recebe dois parâmetros.
O primeiro parâmetro será um dicionário com o mapa de lugares.
O segundo parâmetro é uma lista de números de lugares que precisas de "libertar", isto é, de esvaziar: tens de atribuir `None` ao valor desses números de lugares.

Devolve o `dict` dos lugares depois de atualizares os valores dos lugares "a esvaziar".

```python
>>> empty_seats(seats={1: "Alice", 2: None, 3: "Bob", 4: "George", 5: "Gloria"}, seat_numbers=[5,3,1])
{1: None, 2: None, 3: None, 4: "George", 5: None}
```
