# Ajuda

Se tiveres dificuldades, podes recorrer a um dos seguintes recursos:

- [/r/javascript](https://www.reddit.com/r/javascript) é o subreddit de JavaScript.
- O [StackOverflow](https://stackoverflow.com/questions/tagged/javascript+exercism) podes usá-lo para procurar o teu problema e ver se já foi respondido. Também podes fazer perguntas e responder às dos outros.
- O [Registo de problemas do Github](https://github.com/exercism/javascript/issues) é onde acompanhamos o desenvolvimento e a manutenção dos exercícios de JavaScript no Exercism. Mas se nenhuma das ligações acima te ajudar, podes abrir um problema aqui.
