# Instruções

Ao trabalhar numa fábrica, surge a necessidade de criar a mensagem impressa nos crachás dos funcionários. Decides implementar esta função em JavaScript.

Um crachá precisa do `id` do funcionário, do `name` do funcionário, bem como do departamento onde este trabalha.

## 1. Cria o texto do crachá

Implementa uma função chamada `printBadge` que devolve o texto a imprimir no crachá.

O nome do funcionário é sempre fornecido, mas o número de `id` do funcionário e o nome do departamento podem ser `null`. O número de `id` do funcionário, se for fornecido, deve ficar entre parênteses retos (por exemplo, `[20]`).

O crachá de um proprietário não deve ter `id` nem `department`.

```javascript
printBadge(20, 'Bob', 'Marketing');
// => '[20] Bob - MARKETING'
```
