# Apêndice às instruções

Cada linha da grelha é representada por uma palavra.

Por exemplo,

```
    0 1 0
    1 0 0
    1 1 0
```

é representada por

```
0x2
0x4
0x6
```

A grelha tem no máximo 32 colunas.

## Registos

| Registo | Utilização   | Tipo    | Descrição                   |
| -------- | ------------ | ------- | --------------------------- |
| `$a0`    | parâmetro de entrada        | inteiro | número de linhas            |
| `$a1`    | parâmetro de entrada        | inteiro | número de colunas           |
| `$a2`    | parâmetro de entrada        | endereço | grelha para a geração atual |
| `$a3`    | parâmetro de entrada e saída | endereço | grelha para a geração seguinte |
| `$t0-9`  | temporário    | qualquer | utilizados para armazenamento temporário |
