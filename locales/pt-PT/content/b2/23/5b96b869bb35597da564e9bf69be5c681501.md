# Anexo às instruções

## Instruções específicas do track

Este exercício centra-se em adicionar métodos à estrutura `Array` em Swift.
A forma mais simples de o fazer é recorrer a [extensões][extensions].

```swift
extension Array {
  // Write your code for the 'Strain' exercise in this file.
}
```

Podes encontrar a documentação do `Array` [aqui][array].

[array]: https://developer.apple.com/documentation/swift/array
[extensions]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/extensions/
