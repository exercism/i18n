# Instruções adicionais

## Formato da saída

Devolve as plantas do aluno como uma string terminada em null, usando uma vírgula e um espaço como separadores.

## Registos

| Registo  | Utilização   | Tipo    | Descrição                     |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | entrada      | endereço | diagrama do jardim           |
| `$a1`    | entrada      | endereço | nome do aluno                |
| `$a2`    | entrada/saída | endereço | string de saída terminada em null |
| `$t0-9`  | temporário   | qualquer | usado para armazenamento temporário |
