# Instruções

Neste exercício vais analisar números de telefone.

Pedem-te para implementares 2 funcionalidades.

Os números de telefone que são passados às rotinas estão garantidamente no formato
NNN-NNN-NNNN, por exemplo 212-515-9876, e não são nulos.

## 1. Analisa um número de telefone

A tua análise deve devolver 3 dados:

1. Uma indicação de se o número tem indicativo de Nova Iorque, ou seja, 212 como os primeiros 3 algarismos
2. Uma indicação de se o número é falso, por ter 555 como prefixo nas posições 5 a 7 (a contar a partir de 1)
3. Os últimos 4 algarismos do número.

Implementa o método (estático) `PhoneNumber.Analyze()` para produzir a informação do número de telefone.

```csharp
PhoneNumber.Analyze("631-555-1234");
// => (false, true, "1234")
```

## 2. Deteta se um número de telefone tem um prefixo falso (555)

Implementa o método (estático) `PhoneNumber.IsFake()` para detetar se o número de telefone é falso, usando a informação do número de telefone produzida na tarefa 1.

```csharp
PhoneNumber.IsFake(PhoneNumbers.Analyze("631-555-1234"));
// => true
```
