# Dicas

## 1. Cria um novo visitante

- Volta a ver o [conceito "Objetos"][concept-objects] para descobrires como criar um objeto com determinadas chaves e valores.

## 2. Invalida o bilhete

- Usa o operador de atribuição `=` para definir a propriedade `ticketId` do objeto visitante como `null`.
- No fim, devolve o objeto visitante.

## 3. Determina o estado do bilhete

- Volta a ver o [conceito "Condicionais"][concept-conditionals] para descobrires como devolver valores diferentes da função consoante a condição.
- Usa a notação de parênteses retos para acederes ao valor do `ticketId` indicado no objeto.
- Usa o operador de igualdade estrita `===` para verificares se é `null` ou `undefined`.

## 4. Melhora a resposta do estado do bilhete

- Obtém o valor de um determinado `ticketId` com a notação de parênteses retos, como na tarefa anterior.
- Não é preciso nenhuma condicional para resolveres esta tarefa.
- Usa antes o [operador de coalescência nulo][mdn-nullish-coalescing] `??`.

## 5. Determina a versão dos termos e condições

- Volta a ver o [conceito "Objetos"][concept-objects] para saberes como aceder a valores aninhados e começa por escrever a expressão que obtém a versão.
- Depois, usa o operador de [encadeamento opcional][mdn-optional-chaining] para tratares do caso em que o objeto `gtc` não existe.
- Não é preciso nenhuma condicional para resolveres esta tarefa.
