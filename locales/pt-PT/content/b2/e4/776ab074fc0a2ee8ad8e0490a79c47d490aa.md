# Introdução

O _operador ternário_ é uma alternativa leve e compacta para _condicionais if/else_ simples. É normalmente usado em instruções return (mas não só) e precisa apenas de uma única linha para tomar a decisão: devolve o valor da esquerda se a expressão for `true` e o valor da direita se for `false`, como se mostra a seguir:

```java
boolean expr = 0 != 200;

// Ternary statement
int value = expr ? 22 : 33;
// => 22
```

Muitas expressões _if/else_ simples podem ser simplificadas com _operadores ternários_.
