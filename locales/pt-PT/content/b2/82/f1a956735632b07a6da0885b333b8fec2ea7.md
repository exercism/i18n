# Sobre

Em Swift, não podes indexar uma string com um número inteiro (como `string[3]`).
Como as strings de Swift são compostas por carateres Unicode de comprimento variável, para encontrar um caráter é preciso percorrer os carateres anteriores.

Para acederes a um caráter numa posição específica, tens de calcular um índice do tipo `String.Index`.
Estes índices chamam-se *índices opacos*, porque a sua estrutura interna é gerida pelo Swift em vez de ser manipulada diretamente como números inteiros em bruto:

```swift
let csv = "apple,pear,peach,orange,cherry,lime,gooseberry"
let index = csv.index(csv.startIndex, offsetBy: 21)
print(csv[index])
// Prints "g"

print(index)
// Prints internal representation: Index(_rawBits: ...)
```
