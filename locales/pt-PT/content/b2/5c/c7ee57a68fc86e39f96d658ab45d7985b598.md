# Testes

Os exercícios usam todos o framework [Pester][pester] para criar mocks e testes.
Todos os testes vão estar num ficheiro chamado `[Exercise].tests.ps1`, como é norma no framework Pester.
Se estiveres na pasta certa (ou seja, a que contém `[Exercise].ps1` e `[Exercise].tests.ps1`).
Podes correr os testes a partir do PowerShell chamando:

``` PowerShell
Invoke-Pester
```

Isto vai correr todos os ficheiros `.tests.ps1` que encontrar na pasta.

Se estiveres a usar outra shell que não o PowerShell, podes correr os testes chamando:

``` PowerShell
pwsh -Command "Invoke-Pester"
```

## Correr os testes no Visual Studio Code

Certifica-te de que tens [a extensão do PowerShell][extension] instalada no Visual Studio Code.

Podes correr os testes no Visual Studio Code de algumas formas:

- Correr o script `.Tests.ps1` a partir do menu Debug. Os atalhos de teclado são: `F5` ou `Shift + F5`
- No próprio editor, clicando na ligação "Run Tests" por cima da palavra-chave `Describe` no próprio código de teste
- Configurar uma Task para correr o framework Pester

[pester]: https://github.com/pester/Pester
[extension]: https://marketplace.visualstudio.com/items?itemName=ms-vscode.PowerShell
