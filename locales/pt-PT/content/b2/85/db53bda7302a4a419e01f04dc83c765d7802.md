# Instruções

Neste exercício, vamos simular o primeiro turno de um jogo de [Blackjack][blackjack].

## 1. Calcula o valor de qualquer carta.

Vais receber duas cartas e vais poder ver a carta virada para cima do crupiê.
Todas as cartas são representadas por uma string como "ace", "king", "three", "two", etc. Os valores de cada carta são:

| carta | valor |  carta  | valor |
| :---: | :---: | :-----: | :---: |
|  ace  |  11   |  eight  |   8   |
|  two  |   2   |  nine   |   9   |
| three |   3   |   ten   |  10   |
| four  |   4   |  jack   |  10   |
| five  |   5   |  queen  |  10   |
|  six  |   6   |  king   |  10   |
| seven |   7   | _other_ |   0   |

~~~~exercism/note
Normalmente, os ases podem valer 1 ou 11, mas, para simplificar, vamos assumir que só podem valer 11.
~~~~

Implementa o método `Blackjack.parse_card`, que recebe uma carta como string enquanto argumento.
O método deve devolver o valor da carta como um número inteiro.

```ruby
Blackjack.parse_card("ace")
# => 11
```

## 2. Dá nome a intervalos de valores.

A pontuação do jogador tem de ser categorizada em intervalos de valores.
A pontuação do jogador calcula-se somando os valores das duas cartas do jogador.
Os intervalos usados são:

| intervalo |  valor   |
| :-------: | :------: |
|    low    | [4, 11]  |
|    mid    | [12, 16] |
|   high    | [17, 20] |
| blackjack |   [21]   |

Implementa o método `Blackjack.card_range`, que recebe como argumentos duas cartas sob a forma de strings.
O método deve devolver o nome do intervalo de valores em que as duas cartas se inserem.

```ruby
Blackjack.card_range("ten", "king")
# => "high"
```

## 3. Implementa a lógica de decisão para o primeiro turno.

Consoante as tuas duas cartas e a carta do crupiê, existe uma estratégia para o primeiro turno do jogo, em que tens as seguintes opções:

- Ficar (S)
- Pedir carta (H)
- Dividir (P)
- Ganhar automaticamente (W)

Ainda que não seja ótima, vais seguir a estratégia que o teu amigo Alex tem vindo a desenvolver, que é a seguinte:

- Se tiveres um par de ases, tens sempre de os dividir.
- Se tiveres um Blackjack (duas cartas que somam um valor de 21), e o crupiê não tiver um ás, uma figura ou um dez, ganhas automaticamente.
  Se o crupiê tiver alguma dessas cartas, tens de ficar e esperar que a outra carta seja revelada.
- Se as tuas cartas somarem um valor dentro do intervalo [17, 20], deves ficar sempre.
- Se as tuas cartas somarem um valor dentro do intervalo [12, 16], deves ficar sempre, a não ser que o crupiê tenha um 7 ou mais, caso em que deves pedir carta sempre.
- Se as tuas cartas somarem 11 ou menos, deves pedir carta sempre.

Implementa o método `Blackjack.first_turn`, que recebe como argumentos três cartas sob a forma de strings.
O método deve devolver a decisão que deves tomar, sob a forma de uma string.

```ruby
Blackjack.first_turn("ace", "ace", "two")
# => "P"
```
