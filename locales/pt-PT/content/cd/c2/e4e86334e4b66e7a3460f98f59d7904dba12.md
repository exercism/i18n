## 1. Captura a informação necessária para gerar os cartões com regex

- `\p{L}` corresponde a qualquer tipo de letra de qualquer língua.
- Podes usar a seguinte expressão para capturar a informação:
  ```julia
  re = r"""»(.*)«                     # title
           \ –\ (.*?)                 # name
           (?:\ \((.*?)\)|)           # optional pronouns
           (?:,\ from\ (.*?)|).       # optional organisation
           \ Start:\ (.*?),\          # start time
           (?:Q&A:\ (.*?),\ |)        # optional Q&A time
           End:\ (.*)                 # end time
        """x
  ```
