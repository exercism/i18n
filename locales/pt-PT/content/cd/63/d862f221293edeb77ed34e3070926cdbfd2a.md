# preferir uma constante extraída para o nível superior

Em vez de definires a constante _dentro_ da função, considera extraí-la para o nível
superior. As constantes, as funções e as classes que não levam `export` não são
acessíveis a partir de fora do ficheiro.

```javascript
const %{name} = %{value}

export const gigasecond = (...)
```
