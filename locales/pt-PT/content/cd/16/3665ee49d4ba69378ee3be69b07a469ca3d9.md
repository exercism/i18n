# Getters e setters

Os getters e os setters são métodos que te permitem ler e escrever o valor de uma propriedade de um objeto.
O Crystal tem macros, o que torna mais fácil definir getters e setters para uma propriedade.
As macros são uma forma de gerar código em tempo de compilação, algo que será abordado mais à frente no conceito de macros.

Em Ruby, estes métodos são definidos com os métodos `attr_reader`, `attr_writer` e `attr_accessor` e, à superfície, são muito semelhantes à implementação do Crystal.
O Crystal definiu-os como as macros `getter`, `setter` e `property`.

## Getters

Getter é uma macro que define um método que devolve o valor de uma variável de instância.
Isto significa que já não precisas de escrever `@` antes da variável de instância quando queres aceder-lhe (em métodos, exceto no initialize); em vez disso, podes chamar o método que a macro getter definiu.

A macro getter pode aceitar várias variáveis de instância, separando-as por vírgulas.

```crystal
# This:
class Person
  @name : String
  @age : Int32

  def name
    @name
  end

  def age
    @age
  end
end

# Is the same as this:
class Person
  @name : String
  @age : Int32

  getter name, :age
end
```

Como podes ver, usar getter reduz a quantidade de código que escreves e torna-o mais fácil de ler.
Além disso, o Ruby e o Crystal diferem no facto de o Crystal aceitar tanto o nome da variável como o símbolo como argumentos para a macro getter.
Os símbolos serão abordados mais à frente no conceito de símbolos.

## Setters

Setter é uma macro que define um método que atribui o valor a uma variável de instância.
Esta macro não é muito comum e, em vez dela, costuma usar-se a macro `property`.
Os métodos criados terão o aspeto `name_of_method=`; é o `=` que faz com que a propriedade possa ser definida.

Esta definição de método é um pouco especial, pois o argumento que o método recebe vem depois do sinal `=`.
Vários outros métodos especiais do Crystal usam esta sintaxe, como o método `+`.

Tal como acontece com a macro getter, quando queres atualizar o valor de uma variável de instância depois de definires um setter, podes chamar o método que a macro setter definiu.

```crystal
# This:
class Person
  @name : String
  @age : Int32

  def name=(name : String)
    @name = name
  end

  def age=(age : Int32)
    @age = age
  end
end

# Is the same as this:
class Person
  @name : String
  @age : Int32

  setter name, :age
end
```

## Property

Property é uma macro que define tanto um getter como um setter para uma variável de instância.

```crystal
class Person
  @name : String
  @age : Int32

  property name, :age
end
```
