# Introdução

As expressões regulares em Gleam seguem a especificação **PCRE** (**P**erl **C**ompatible **R**egular **E**xpressions, ou seja, expressões regulares compatíveis com Perl), à semelhança de outras linguagens populares como Java, JavaScript ou Ruby.

O módulo `gleam/regex` disponibiliza funções para trabalhar com expressões regulares.

~~~~exercism/note
Este exercício parte do princípio de que já sabes a sintaxe das expressões regulares, incluindo classes de carateres, quantificadores, grupos e capturas.

Se precisares de refrescar os teus conhecimentos sobre expressões regulares, consulta uma destas fontes: [Regular-Expressions.info](https://www.regular-expressions.info), [Rex Egg](https://www.rexegg.com/), [RegexOne](https://regexone.com/), [Regular Expressions 101](https://regex101.com/), [RegExr](https://regexr.com/).
~~~~

A forma mais comum de criar expressões regulares é usar a função `regex.from_string`.

```gleam
let assert Ok(re) = regex.from_string("test")
```

A função `regex.from_string` devolve um `Error` se a sintaxe da expressão regular for inválida, por isso, neste caso, é usada uma asserção `let` para garantir que a expressão regular é válida.

A função `regex.check` pode ser usada para verificar se uma expressão regular corresponde a uma string.

```gleam
let assert Ok(re) = regex.from_string("test")

regex.check(re, "this is a test")
// -> True

regex.check(re, "this is too")
// -> False
```


## Capturas

Se quiseres capturar substrings com uma expressão regular, podes usar a função `regex.scan` para devolver uma lista de correspondências.

```gleam
let assert Ok(re) = regex.from_string("[oi]n a (\\w+)")
regex.scan(with: re, content: "I am on a boat in a lake.")
// -> [
//   Match(
//     content: "on a boat",
//     submatches: [Some("boat")]
//   ),
//   Match(
//     content: "in a lake",
//     submatches: [Some("lake")]
//   )
// ]
```

## Modificadores

O comportamento de uma expressão regular pode ser alterado se a criares com a função `regex.compile` e passares as opções.

```gleam
let options = regex.Options(case_insensitive: True, multi_line: False)
let assert Ok(re) = regex.compile("[A-Z]", with: options)
regex.check(re, "abc123")
// -> True
```
