# Dicas

## Geral

- Presta muita atenção à sintaxe dos ponteiros.
  Vais usar `*` (operador de desreferenciação) e `->` (acesso a membros através de um ponteiro).
- Certifica-te de que verificas os ponteiros nulos (`nullptr`) quando é necessário, para evitares aceder a memória inválida.
- Podes correr os testes mesmo que o teu código não esteja completo; uma estrutura aproximada chega para veres os resultados dos testes.
- Todas as funções usadas pelos testes têm de estar declaradas no ficheiro de cabeçalho.
- Se o teu programa rebentar ou tiver um comportamento inesperado, muitas vezes é por causa da desreferenciação de um ponteiro nulo.
  Verifica duas vezes se tratas `nullptr` corretamente.
- Quando usas aritmética de ponteiros, garante que ficas dentro dos limites do array de sensores.
  Ultrapassar a capacidade do array pode causar problemas de memória.

## 1. Verifica a ligação do sensor (`connection_check`)

- A tarefa consiste, essencialmente, em verificar se um ponteiro é nulo ou não.
- Usa o operador de comparação `!=` para verificares se um ponteiro é válido.
- Se não tiveres a certeza de que estás a verificar o ponteiro corretamente, pensa no que `nullptr` representa (a ausência de um endereço de memória válido).


## 2. Conta a atividade dos sensores (`activity_counter`)

- Tens de iterar sobre o array de sensores.
  Em C++, um array pode ser tratado como um ponteiro para o seu primeiro elemento.
- Usa aritmética de ponteiros (`sensor_array + i`) para acederes ao sensor no índice `i`.
- O operador `->` serve para aceder a um membro da struct através de um ponteiro.

### Exemplo

```cpp
int sum = (sensor_array + i)->activity; // Access activity using pointer arithmetic
```

## 3. Controlo do alarme (`alarm_control`)

- Primeiro, verifica se o ponteiro é nulo antes de acederes ao sensor.
- Usa o operador `->` para acederes ao membro `activity` da struct `pillar_men_sensor`.
- Pensa com cuidado no que deve acontecer se o nível de atividade do sensor for `0`.
  O alarme deve disparar?

## 4. Verificar anomalias nos dados com a função `uv_alarm`

- Usa o operador `&` para passares um ponteiro para o array de dados do sensor à função `uv_light_heuristic`.
- Garante que verificas corretamente se o ponteiro é nulo antes de acederes aos dados do sensor.
- Compara o resultado de `uv_light_heuristic` com o valor `activity` do sensor para determinares se o alarme deve disparar.
