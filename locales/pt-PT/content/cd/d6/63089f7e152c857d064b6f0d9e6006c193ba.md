# Debug

Quando um teste falha, é apresentada uma mensagem a descrever o que correu mal e com que valor de entrada. Também podes tirar partido do facto de que tudo o que for impresso para a "saída padrão" será igualmente mostrado.
Podes escrever para a saída padrão com `println!`:

```rust
println!("Debug message");
```

Usa chavetas `{}` para imprimir o valor de uma variável ou expressão:

```rust
let secret_number = 4321;
println!("My banking password is {}, which is better than {}.", secret_number, 1200 + 34);
```

Repara que nem todos os tipos podem ser impressos desta forma, apenas aqueles que podem ser apresentados aos utilizadores de forma inequívoca.
Por exemplo, os vetores (listas) não podem ser impressos assim, porque não é claro como é que um vetor deve ser apresentado aos utilizadores!
Para esses outros tipos, podes dizer à macro `println!` para usar _formatação de debug_ com: `{:?}`.
Esta representação destina-se apenas a ser vista pelos programadores.
Um exemplo:

```rust
let words = vec!["hello", "world"];
println!("words that are often combined: {:?}", words);
```

Existe ainda a prática macro `dbg!`, que podes usar para fazer debug a expressões grandes em linha, sem precisares de as decompor em declarações de variáveis separadas.

Suponhamos que temos a seguinte expressão:

```rust
"hello world".split(' ').collect::<Vec<_>>().join("-")
```

Agora gostaríamos de ver o que a chamada a `collect` devolve.
Poderíamos fazer o seguinte:

```rust
let my_temporary_debug_variable = "hello world".split(' ').collect::<Vec<_>>();
println!("{:?}", my_temporary_debug_variable);
my_temporary_debug_variable.join("-")
```

Mas isso é maçador!
Não queremos reescrever as nossas belas expressões só para conseguirmos fazer debug delas.
E agora, um grande aplauso para: `dbg!`

```rust
dbg!(
    "hello world".split(' ').collect::<Vec<_>>()
).join("-")
```

Os espaços em branco servem apenas para maior clareza.
Podes envolver qualquer expressão em `dbg!()`, o que vai imprimir esse valor (com formatação de debug).
Depois, podes continuar a usar o valor numa expressão maior, como se o `dbg!` nem sequer estivesse lá.

Bom debug!
