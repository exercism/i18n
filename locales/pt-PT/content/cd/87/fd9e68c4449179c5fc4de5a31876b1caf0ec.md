# marcador de posição

## Geral

- A [função numérica][rand-func] `rand` pode gerar números aleatórios.
- A [função numérica][srand-func] `srand` será útil para definir a semente do `rand`.

## Geração do labirinto

Podes usar qualquer algoritmo para gerar um labirinto perfeito. O [backtracking recursivo][recursive-backtracker] é uma boa escolha.
