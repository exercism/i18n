# Instruções

Neste exercício, tens de implementar algumas regras do [Pac-Man][Pac-Man], o clássico jogo de arcada dos anos 80.

Há seis tarefas no total; quatro delas são regras relacionadas com os estados do jogo.

> _Não te preocupes com a forma como os argumentos são obtidos nas funções, concentra-te apenas em combinar os argumentos para devolver o resultado pretendido._


## 0. Define um estado de poder

Define uma variável chamada `PowerOn` com um valor que represente que o poder está mesmo ligado.

```powershell
> $PowerOn
True
```

## 1. Define se o Pac-Man come um fantasma

Define a função `EatGhost`, que recebe dois parâmetros (_se o Pac-Man tem uma pastilha de poder ativa_ e _se o Pac-Man está a tocar num fantasma_) e devolve um valor Boolean que indica se o Pac-Man consegue comer o fantasma.
A função deve devolver `True` apenas se o Pac-Man tiver uma pastilha de poder ativa e estiver a tocar num fantasma.

```powershell
> EatGhost -ActivePower $false -TouchingGhost $true
False
```

## 2. Define se o Pac-Man marca pontos

Define a função `Score`, que recebe dois parâmetros (_se o Pac-Man está a tocar numa pastilha de poder_ e _se o Pac-Man está a tocar num ponto_) e devolve um valor Boolean que indica se o Pac-Man marcou pontos.
A função deve devolver `True` se o Pac-Man estiver a tocar numa pastilha de poder ou num ponto.

```powershell
> Score -TouchDot $true -TouchPowerPellet $true
4
```

## 3. Define se o Pac-Man perde

Define a função `Lose`, que recebe dois parâmetros (_se o Pac-Man tem uma pastilha de poder ativa_ e _se o Pac-Man está a tocar num fantasma_) e devolve um valor Boolean que indica se o Pac-Man perde.
A função deve devolver `True` se o Pac-Man estiver a tocar num fantasma e não tiver uma pastilha de poder ativa.

```powershell
> Lose -ActivePower $false -TouchingGhost $true
True
```

## 4. Define se o Pac-Man ganha

Define a função `Win`, que recebe três parâmetros (_se o Pac-Man comeu todos os pontos_, _se o Pac-Man tem uma pastilha de poder ativa_ e _se o Pac-Man está a tocar num fantasma_) e devolve um valor Boolean que indica se o Pac-Man ganha.
A função deve devolver `True` se o Pac-Man comeu todos os pontos e não perdeu com base nos parâmetros definidos na parte 3.

```powershell
> Win -EatenAllDots $false -ActivePower $true -TouchingGhost $false
False
```

## 5. Escreve a sinopse da condição de vitória

Volta à última função e acrescenta uma secção `Synopsis` ao bloco de comentários, como descrição breve de como ganhar o jogo.
A descrição deve ter, no mínimo, dez carateres.

```powershell
function MyFunc($Arg) {
    <#
    .DESCRIPTION
    This is a demonstration of the comment-based help with the description keyword.
    #>
}
```
