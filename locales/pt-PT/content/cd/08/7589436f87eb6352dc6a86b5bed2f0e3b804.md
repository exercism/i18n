# Instruções

Cada um de nós herda dos nossos pais biológicos um conjunto de instruções químicas conhecidas como ADN, que influenciam a forma como o nosso corpo é construído. Toda a vida conhecida depende do ADN!

> Nota: Não precisas de perceber nada sobre nucleótidos ou ADN para completar este exercício.

O ADN é uma longa cadeia de outras substâncias químicas e as mais importantes são os quatro nucleótidos: adenina, citosina, guanina e timina. Uma única cadeia de ADN pode conter milhares de milhões destes quatro nucleótidos e a ordem em que aparecem é importante!
Chamamos "sequência de ADN" à ordem destes nucleótidos num pedaço de ADN.

Representamos uma sequência de ADN como uma coleção ordenada destes quatro nucleótidos e uma forma comum de o fazer é com uma string de carateres, como "ATTACG" para uma sequência de ADN de 6 nucleótidos.
'A' de adenina, 'C' de citosina, 'G' de guanina e 'T' de timina.

Dada uma string que representa uma sequência de ADN, conta quantos nucleótidos de cada tipo estão presentes.
Se a string contiver carateres que não sejam A, C, G ou T, então é inválida e deves assinalar um erro.

Por exemplo:

```
"GATTACA" -> 'A': 3, 'C': 1, 'G': 1, 'T': 2
"INVALID" -> error
```
