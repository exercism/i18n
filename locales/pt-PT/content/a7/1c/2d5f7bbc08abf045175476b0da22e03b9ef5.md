# Instruções

A Lucy, a alienígena de Lisp, gosta de números e acha que alguns deles são "magníficos".

Ela pede-te ajuda para escrever funções que tornem os números mais magníficos.

O que a Lucy acha que torna um número magnífico pode mudar, por isso as funções têm de ser flexíveis.

## 1. Torna magnífico

Para transformar uma lista de números numa lista de números mais magníficos, vais precisar de escrever uma função `make-magnificent-maybe` que recebe uma função a aplicar aos números e uma lista de números.
Deve resultar numa lista de números mais magníficos (de acordo com a função fornecida).

```lisp
(make-magnificent-maybe #'square '(1 2 3)) ; => (1 4 9)
(make-magnificent-maybe #'1+ '(1 2 3))     ; => (2 3 4)
```

## 2. Só os melhores

Depois de (esperemos) tornar os números mais magníficos, a Lucy quer ver apenas os números que são verdadeiramente magníficos.

Ela sabe com toda a certeza que 1 *nunca* é magnífico, por isso vais precisar de o remover.

Mas, fora isso, a Lucy muda de ideias às vezes, por isso, mais uma vez, vai dar-te uma função que te diz se um número é magnífico ou não.

Vais precisar de escrever uma função `only-the-best` que recebe uma função e uma lista de números e devolve apenas os melhores números (não o `1` e não os números para os quais a função devolve verdadeiro).

```lisp
(only-the-best #'evenp '(1 2 3 4 5)) ; => (3 5)
(only-the-best #'oddp '(1 3 5))    ; => ()
```
