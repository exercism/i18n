# Sobre

O JavaScript tem um operador de incremento e um de decremento.
Modificam uma variável no local.
`++` soma 1 a um número, `--` subtrai 1 a um número.

```javascript
let i = 3;
i++;
// i is now 4

let j = 0;
j--;
// j is now -1
```

O exemplo acima mostra o operador de incremento/decremento pós-fixo.
Neste caso, o operador é colocado depois da variável e o valor devolvido pela expressão é o valor da variável _antes_ do aumento/diminuição.

```javascript
let a = 3;
let b = a++;
// a = 4
// b = 3
```

Existe também a variante de prefixo, em que o operador é colocado antes da variável.
Nesse caso, o valor devolvido é o valor da variável _depois_ do aumento/diminuição.

```javascript
let a = 3;
let b = ++a;
// a = 4
// b = 4
```
