# Dicas

## Geral

- `case` (em [`combinators`][combinators]) é a ferramenta certa para fazer correspondência com valores iguais; `cond` é a ferramenta certa para predicados com guardas.
- Os símbolos (`yes`, `no`, `maybe`, `korean`, …) já estão declarados através de `SYMBOLS:` no ficheiro do exercício.

## 1. Classifica a cozinha

- Um `case` com duas cláusulas que mapeia `korean` e `turkish` para os respetivos valores de aprovação.

## 2. Classifica o género do filme

- Faz correspondência com `romance` e coloca `[ drop no ]` como predefinição para os restantes. Lembra-te de que o ramo predefinido vê o valor original no topo: faz `drop` antes de empilhares o resultado.

## 3. Classifica o passeio

- Usa `cond` (também em `combinators`): cada guarda é `[ dup N > ]`. O corpo precisa de fazer `drop` aos quilómetros antes de empilhar a aprovação.

## 4. Classifica a atividade

- A atividade é `{ tag value }`. Usa `first2` para empilhar ambos na stack, depois `swap` para que a tag fique no topo: é com isso que o `case` faz correspondência.
- Os ramos para `board-game` e `chill` veem o valor (`f`) ainda na stack; faz `drop` antes de empilhares a aprovação.
- Os ramos para `movie`, `restaurant` e `walk` veem o valor relevante ainda na stack, por isso podes chamar diretamente o teu word da tarefa 2/1/3.
