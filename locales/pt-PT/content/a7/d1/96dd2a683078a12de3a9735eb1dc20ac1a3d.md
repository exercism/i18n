# Dicas

## 1. Determina quanto tempo demora a misturar um sumo

- Volta a ver o conceito [Switch][concept-switch] para encontrares formas de abordar isto.

## 2. Reabastece a reserva de gomos de lima

- Faz um ciclo até que se cumpra uma das condições indicadas nas instruções.
- Pode ser útil, embora não seja obrigatório, ter uma pequena função auxiliar que relacione o tamanho das limas com o número de gomos que cada uma dá.
- Mais uma vez, o conceito [Switch][concept-switch] pode sugerir abordagens práticas.
- Devolve quantas limas foram realmente cortadas.

## 3. Lista os tempos de mistura de cada pedido na fila

- Nesta fase do programa, a abordagem mais fácil usa um ciclo `for` sobre `orders`, mas também pode ser feita com `seq_along`.
- Uma tarefa anterior pode fornecer uma função útil.
- Usa [`print()`][print-function] para mostrar os tempos por ordem (vê o exemplo na introdução).
- Neste exercício não deves devolver nada.

## 4. Termina o turno

- Faz um ciclo enquanto houver pedidos e ainda restar algum tempo.
- Devolve um vetor com os pedidos que não foram iniciados.
