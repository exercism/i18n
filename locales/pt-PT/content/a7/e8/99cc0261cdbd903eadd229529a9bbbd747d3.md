# Introdução

## Herança

A herança é um conceito central na POO (Programação Orientada a Objetos).
Representa uma relação é-um.
Significa literalmente, em programação, o mesmo que em inglês: herdar características do progenitor (em programação, essas características são normalmente funções e variáveis).

Considera uma classe, `Animal`, como mostrada,

```java
//Creating an Animal class with bark() as a member function.
public class Animal {

    public void bark() {
        System.out.println("This is an animal");
    }

}
```

`Animal` é uma classe progenitora, porque as propriedades desta classe podem ser estendidas a todos os animais em geral.

Considera um animal chamado `Lion`, com uma classe como esta,

```java
//Lion class is a child class of Animal.
public class Lion extends Animal {

    @Override
    public void bark() {
        System.out.println("Lion here!!");
    }

}
```

~~~~exercism/note
A anotação `Override` serve para indicar que um método numa subclasse está a sobrepor um método da sua superclasse.
Não é estritamente necessária, mas é uma boa prática utilizá-la.
~~~~

Agora, sempre que fazemos,

```java
Animal animal = new Lion(); //creating instance of Animal, of type Lion
animal.bark();
```

Nota: inicializamos a classe `Animal` com `Lion`.
O resultado será algo como

```java
Lion here!!
```

Segundo a POO, existem muitos tipos de herança, mas o Java só suporta alguns deles (multi-nível e hierárquica).
Para saberes mais sobre isto, lê [isto][java-inheritance].
