# Introdução

Em C++, os Boolean são representados pelo tipo `bool`.
Um `bool` é `true` ou `false`.

## Operadores lógicos

O C++ suporta três operadores booleanos: `!` (NOT), `&&` (AND) e `||` (OR).
Também podes usar as versões alternativas `not`, `and` e `or`.

```cpp
true || false // => true
true && false // => false
!true // => false
not false // => true
```

## Precedência

Cada um dos três operadores booleanos tem uma _precedência de operadores_ diferente.
Por consequência, são avaliados por esta ordem: `!` primeiro, `&&` a seguir e, por fim, `||`.
Se quiseres forçar uma ordem diferente, podes envolver uma expressão booleana entre parênteses (ou seja, `()`), uma vez que os parênteses têm uma precedência de operadores ainda mais elevada.

```cpp
!true && false   // => false
!(true and false) // => true
```

## Conversão

Se usares `true` ou `false` num sítio onde se espera um número, são convertidos em `1` e `0`, respetivamente.
Se usares um número numa operação booleana, tudo exceto `0` é tratado como `true`, incluindo os valores negativos.

```cpp
!true && 0.0   // => false
true + true + false // => 2
```
