# Introdução

Bombas, válvulas, mangueiras: tudo o que retém um recurso do sistema operativo (um ficheiro aberto, uma ligação de rede) tem de ser *libertado* quando já não precisas dele. O vocabulário [`destructors`][destructors] do Factor envolve tudo isto num framework que garante a limpeza, mesmo quando um erro interrompe o teu código a meio.

## A classe e o genérico

Uma classe passa a fazer parte do framework ao estender `disposable` e implementar o genérico `dispose*`:

```factor
USING: accessors destructors kernel ;

TUPLE: pump < disposable opened ;

: <pump> ( -- pump )
    pump new-disposable t >>opened ;

M: pump dispose* f >>opened drop ;
```

`new-disposable ( class -- obj )` aloca o tuplo *e* regista-o no framework: uma exceção entre a alocação e o ponto seguro seguinte não deixa escapar o recurso. O framework garante que `dispose*` corre **no máximo uma vez** por objeto; chamadas repetidas a `dispose` não fazem nada.

## A interface pública usa `dispose`

```
dispose          ( obj -- )                ! release; safe to call twice
with-disposal    ( disposable quot -- )    ! scope one resource
with-destructors ( quot -- )               ! open a registry scope
&dispose         ( obj -- obj )            ! dispose on normal *or* failure exit
|dispose         ( obj -- obj )            ! dispose only if the scope unwinds
```

`with-disposal` é a forma para um único recurso: coloca na pilha o disposable para a citação interior e liberta-o à saída.

```factor
USING: destructors io ;

<pump> [
    "pumping" print
] with-disposal
! pump released on the way out — even if `print` had thrown
```

Para mais do que um recurso, abre um âmbito de registo com `with-destructors` e regista cada aquisição. `&dispose` (e comercial) significa "liberta sempre à saída, tanto no sucesso como no erro". `|dispose` (barra vertical) significa "liberta **apenas** em caso de erro"; é útil quando o caminho de sucesso entrega o recurso a quem chama e que passa a ser responsável por ele.

```factor
[
    <pump> &dispose
    <pump> &dispose
    ! ... use the pumps ...
] with-destructors
! both pumps released
```

Para um simples try/finally sem registo, [`cleanup`][cleanup] (em `continuations`) é a primitiva de nível mais baixo, mas `with-destructors` é o Factor moderno e idiomático.
