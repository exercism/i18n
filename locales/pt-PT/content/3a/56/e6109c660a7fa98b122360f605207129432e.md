# Dicas

## Geral

- Não te preocupes com a forma como os argumentos são obtidos; concentra-te apenas em combiná-los para devolver o resultado pretendido.

## 1. Define se o pac-man pode comer um fantasma

- A função tem de devolver um valor [bool][bool].
- Podes usar o operador [bool][bool] `&&` para combinar os argumentos e obter um resultado.

## 2. Define se o pac-man marca pontos

- A função tem de devolver um valor [bool][bool].
- Podes usar o operador [bool][bool] `||` para combinar os argumentos e obter um resultado.

## 3. Define se o pac-man perde

- A função tem de devolver um valor [bool][bool].
- Podes usar os operadores [bool][bool] `&&` e `!` para combinar os argumentos e obter um resultado.

## 4. Define se o pac-man ganha

- A função tem de devolver um valor [bool][bool].
- Podes usar os operadores [bool][bool] `&&` e `!` para combinar os argumentos e os resultados de uma das funções implementadas anteriormente.

[bool]: https://gleam.run/book/tour/bools.html
