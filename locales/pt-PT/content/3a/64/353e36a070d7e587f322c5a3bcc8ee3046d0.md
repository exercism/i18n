# Sobre

PureScript é uma linguagem de programação puramente funcional e estaticamente tipada, com inferência de tipos global.

**Funcional** significa que as funções são valores de primeira classe.
As funções são uma ferramenta de abstração importante e poderosa.
Em PureScript, a computação é modelada como a avaliação de expressões compostas por aplicações de funções, e não como a execução de uma sequência de instruções.

**Puramente funcional** significa que é possível saber se uma computação tem ou não efeitos secundários. Ou seja, se uma computação altera uma variável global, lê dados de entrada, escreve num socket, etc., isso vai refletir-se no tipo da computação.

**Estaticamente tipada** significa que todas as computações têm um tipo que é conhecido antes de o programa ser executado.

**Inferência de tipos global** significa que o compilador consegue descobrir o tipo das computações de todo o programa sem que o programador tenha de especificar esse tipo.
