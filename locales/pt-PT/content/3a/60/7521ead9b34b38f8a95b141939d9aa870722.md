# Introdução

## O operador ternário

Uma condicional ternária é uma forma mais curta de escrever condicionais `if/else` simples.
Se uma condicional `if/else` tiver apenas dois ramos, um para quando a condição é verdadeira e outro para quando é falsa, pode ser reescrita como uma condicional ternária.

As condicionais ternárias usam uma combinação dos símbolos `?` e `:` para dividir uma condicional:

```ruby
condition ? true_branch : false_branch
```

O código à esquerda do `?` é a condição, e o código à direita contém os dois ramos possíveis, separados pelo `:`.
Se a condição for _verdadeira_, executa-se o código à _esquerda_ do `:`.
Se a condição for _falsa_, executa-se o código à _direita_ do `:`.

Por exemplo:

```ruby
if traffic_light == 'green'
  cross_the_road
else
  wait
end
```

pode ser reescrito como:

```ruby
traffic_light == 'green' ? cross_the_road : wait
```
