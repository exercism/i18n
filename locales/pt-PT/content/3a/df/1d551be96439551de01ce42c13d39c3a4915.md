# Instruções

A tua tarefa é criar um programa que implemente o Crivo de Eratóstenes para encontrar números primos.

Um número primo é um número que só é divisível por 1 e por si próprio.
Por exemplo, 2, 3, 5, 7, 11 e 13 são números primos.

O Crivo de Eratóstenes é um algoritmo antigo que funciona assim: tomas uma lista de números e riscas todos os números que não são primos.

Um número que **não** é primo chama-se "número composto".

Para usares o Crivo de Eratóstenes, começas por criar uma lista de todos os números entre 2 e o número que recebeste.
Depois repetes os passos seguintes:

1. Encontra o próximo número não marcado na tua lista. Esse número é primo.
2. Marca todos os múltiplos desse número primo como compostos (não primos).

Continuas a repetir estes passos até percorreres todos os números da tua lista.
No final, todos os números não marcados são primos.
