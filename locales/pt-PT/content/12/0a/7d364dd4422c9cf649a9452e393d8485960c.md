# Anexo às instruções

## Registos

| Registo | Utilização | Tipo | Descrição |
| -------- | ------------ | ------- | ----------------------------------- |
| `$a0`    | parâmetro de entrada | número inteiro | limite |
| `$a1`    | parâmetro de entrada e de saída | endereço | array de destino para os números primos |
| `$v0`    | saída | número inteiro | número de primos |
| `$t0-9`  | temporário | qualquer | usado para armazenamento temporário |
