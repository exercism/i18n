# Dicas

## 1. Calcular a soma dos números na máquina de slot

- Podes usar o [join][mdn-join] para juntar os algarismos.
  Além disso, converte implicitamente os números em strings.
- Volta a consultar a secção de introdução para descobrires como converter uma string num número.
- Soma os números depois de os converteres.

## 2. Determinar se um número é um palíndromo

- Podes resolver esta tarefa tratando o número como uma string e verificando se a string é igual à sua versão invertida.
- Para isso, primeiro tens de converter o número numa string.
  Volta a consultar a secção de introdução para descobrires como fazer isso.
- Para inverter a string, usa `split` para a dividir num array, `reverse` para inverter o array e `join` para a juntar de novo.
- Por fim, podes [comparar][concept-comparison] a string original com a string invertida.

## 3. Gerar uma mensagem de erro para dados inválidos do utilizador

- Podes usar [condicionais][mdn-if-statement] para verificar as diferentes condições.
- Primeiro, deves tratar o caso em que o valor não contém nenhum caráter.
  Ao escreveres a condição para isso, aproveita a conversão implícita para Boolean e o facto de `null`, `undefined` e a string vazia serem todos falsy.
- A seguir, trata do caso em que o valor de entrada não é um número nem `0`.
  Usa a conversão explícita para `Number` que aprendeste na introdução.
  Depois, podes mais uma vez contar com a conversão implícita para Boolean e com o facto de `NaN` e `0` serem falsy.
- O [operador lógico NOT][mdn-not] `!` pode ser útil para formular as condições.
