# Condicionais

Uma **condicional** escolhe entre duas formas de agir dependendo de se algo é verdadeiro.

```sather
   verdict(score : INT) : STR is
      if score >= 5 then
         return "Recalled";
      else
         return "Thank you";
      end;
   end;
```

Ao ler isto: `if`, depois uma pergunta que responde `true` ou `false`, depois `then`. As linhas depois de `then` são executadas quando a resposta é verdadeira, e as linhas depois de `else` são executadas quando é falsa. `end;` fecha tudo.

## Mais do que duas formas

`elsif` acrescenta outra pergunta, feita apenas quando as anteriores deram falso.

```sather
   verdict(score : INT) : STR is
      if score >= 8 then
         return "Cast";
      elsif score >= 5 then
         return "Recalled";
      else
         return "Thank you";
      end;
   end;
```

A ordem importa. Uma pontuação de `9` é apanhada pela primeira pergunta e nunca chega à segunda, mesmo que `9 >= 5` também seja verdadeiro. Escrever as condições na ordem errada é a forma habitual de errar isto.

Escreve-se `elsif`, não `elseif` nem `else if`.

## Omitir o else

`else` pode ser omitido quando não há nada a fazer nesse caso.

```sather
   if late then
      apologise;
   end;
```

Uma rotina que tem de devolver algo precisa que todos os caminhos devolvam algo, por isso, neste exercício, todos os `if` mantêm o seu `else`.
