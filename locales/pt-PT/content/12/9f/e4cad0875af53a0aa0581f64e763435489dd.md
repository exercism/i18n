# Sobre

[concept:csharp/enumerables]() pode ser iterado com um [ciclo `foreach`][foreach-statement]:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // Output the vowel
    System.Console.Write(vowel);
}

// => aeiou
```

Um ciclo `foreach` é composto por três partes:

1. A declaração: define a variável que vai conter o valor da iteração. Esta variável só pode ser usada dentro do ciclo.
2. O objeto iterável: o objeto que pode ser iterado.
3. O corpo do ciclo.

## Ciclos for vs foreach

No entanto, em geral um ciclo `foreach` é preferível a um ciclo `for` pelas seguintes razões:

- Um ciclo `foreach` garante que itera _todos_ os valores. Com um ciclo `for`, é fácil deixar escapar elementos, por exemplo devido a um erro de um a mais ou um a menos.
- Um ciclo `foreach` é mais _declarativo_: o teu código comunica _o que_ queres fazer, em vez de um ciclo `for` que comunica _como_ o queres fazer.
- Um ciclo `foreach` é à prova de erro, enquanto com ciclos `for` é fácil cometer um erro de um a mais ou um a menos.
- Um ciclo `foreach` funciona com todos os tipos de coleção, incluindo aqueles que não suportam o uso de um indexador para aceder aos elementos.

Para garantir que um ciclo `foreach` itera _todos_ os valores, o compilador não permite atualizar uma coleção dentro de um ciclo `foreach`:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // This would result in a compiler error
    // vowel = 'Y';
}
```

Um ciclo `for` tem, ainda assim, algumas vantagens em relação a um ciclo `foreach`:

- Podes começar ou parar no índice que quiseres.
- Podes usar a condição de terminação (Boolean) que quiseres.
- Podes saltar elementos personalizando o incremento da variável do ciclo.
- Podes percorrer coleções de trás para a frente fazendo a contagem decrescente.
- Podes usar ciclos `for` em cenários que não envolvem coleções.

Tópicos relacionados:

- Deves ter em conta que o C# suporta [arrays multidimensionais][multi-dimensional-arrays] como `int[,] arr = new int[10, 5]`, que podem ser muito úteis.
- Deves também saber que podes instanciar objetos do tipo [`System.Array`][system-array-object] com `Array.CreateInstance`. Esses objetos são pouco úteis, sobretudo para interoperabilidade com código VB.NET. Não são intercambiáveis com arrays padrão (`T[]`). Podem ter um limite inferior diferente de zero.
