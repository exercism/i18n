# O tipo tuplo

Um tuplo é um tipo de dados composto versátil e eficiente em Cairo, que te permite agrupar vários valores de tipos diferentes numa única entidade.
Os tuplos têm um comprimento fixo: depois de declarados, o tamanho não pode mudar.

## Criar tuplos

Para criar um tuplo, escreves uma lista de valores separados por vírgulas dentro de parênteses.
Cada posição do tuplo tem um tipo específico, e esses tipos podem ser diferentes entre si.

```rust
fn main() {
    let tup: (u32, u64, bool) = (10, 20, true);
}
```

Um tuplo pode conter vários valores de tipos de dados diferentes, incluindo outros tuplos.
Por exemplo:

```rust
fn main() {
    let nested_tup: ((i32, u64), (u8, bool)) = ((10, 3), (5, false));
}
```

Aqui, a variável `nested_tup` é um tuplo que contém dois tuplos, o que mostra que os tuplos podem ter outros tuplos como elementos.

## Desestruturar tuplos

Para acederes aos valores individuais de um tuplo, podes usar correspondência de padrões para o desestruturar.
Assim, divides o tuplo nas suas partes constituintes.

```rust
fn main() {
    let tup = (500, 6, true);

    let (x, y, z) = tup;

    println!("x is: {x}"); // prints "x is: 500"
    println!("y is: {y}"); // prints "x is: 6"
    println!("z is: {z}"); // prints "z is: true"
}
```

## Declarar e desestruturar ao mesmo tempo

Também podes declarar e desestruturar um tuplo ao mesmo tempo.

```rust
fn main() {
    let (x, y): (felt252, felt252) = (2, 3);
}
```

## O tipo unit `()`

O tipo unit é um tipo especial em Cairo que tem apenas um valor: `()`.
É representado por um tuplo sem elementos.
O tamanho do tipo unit é sempre zero e é garantido que não existe no código compilado.

Em Cairo, todas as expressões devolvem um valor e, quando uma expressão não devolve nada, devolve implicitamente `()`.
Isto pode ser útil para funções que precisam de devolver um valor, mas não têm nenhum valor significativo para devolver.

## Declaração de tipo de tuplo com nome

Um tuplo com nome permite-te criar um alias de tipo mais descritivo para um tuplo, o que melhora a legibilidade do código.

```rust
type Point = (u32, u32);

fn main() {
    let point: Point = (10, 8);
    println!("{point:?}"); // prints "(10, 8)"
}
```

Neste exemplo, `Point` é um tipo de tuplo com nome que representa um par de inteiros sem sinal de 32 bits, o que torna o código mais expressivo.
