# Anexo às instruções

## O comando `apply` do Tcl

Os casos de teste podem parecer confusos.
Espera-se que implementes isto: 

```tcl
set myList {alpha beta gamma delta}
listOps::filter $myList {{word} {expr {[string length $word] == 4}}
```

Porque é que esse último argumento tem tantas chavetas?

Lembra-te de que o comando `proc` é definido assim:

```tcl
proc procName argList body
```

O Tcl tem um comando `apply`:

```tcl
apply func ?arg1 arg2 ...?
```

este "func" é uma lista de dois elementos `{argList body}` que é, essencialmente, um proc anónimo (ou "lambda").
O comando `apply` invoca esse proc anónimo, passando-lhe os argumentos de que precisa.

Por exemplo, estes são equivalentes:

```tcl
# using proc
proc myReverse {str} {return [string reverse $str]}
puts [myReverse "Hello, World!"]

# using apply
puts [apply {{str} {string reverse $str}} "Hello, World!"]

# or, store the func in a variable
set func {{str} {string reverse $str}}
puts [apply $func "Hello, World!"]
```

Usar o `apply` torna mais simples passar blocos de código de um lado para o outro.

Ref.: [`apply`](https://tcl.tk/man/tcl8.6/TclCmd/apply.htm), [`proc`](https://tcl.tk/man/tcl8.6/TclCmd/proc.htm).
