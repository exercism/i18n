# Dicas

## Geral

- As lentes não são muito usadas em Roc, porque a sintaxe de atualização de registos cobre muito bem a maioria dos casos de uso.
  Por exemplo, considera este registo aninhado:

  ```roc
  bob = { hair: { color: Brown, length: Long }, mouth: Smiling, height: 6.0 }
  ```

  Agora vamos cortar o cabelo ao Bob:

  ```roc
  new_bob = { ..bob, hair: { ..bob.hair, length: Short } }
  ```

  Não precisas de lentes!

- Dito isto, embora as lentes sejam raras em Roc, são comuns noutras linguagens como Haskell e Scala, por isso podes ter curiosidade em saber como se implementam em Roc.
  Também é uma boa forma de praticar algumas funcionalidades avançadas de Roc, como tipos parametrizados e registos que contêm funções.
  De facto, eis uma forma de representar uma lente em Roc:

  ```roc
  Lens(whole, part) := {
      get : whole -> part,
      set : whole, part -> whole,
  }
  ```

  Este é um tipo parametrizado: `whole` e `part` podem ser quaisquer tipos.
  Normalmente, `whole` é um registo, enquanto `part` pode ser qualquer tipo de campo.
  O campo `get` contém uma função que devolve uma `part` específica do `whole` indicado, enquanto o campo `set` contém uma função que devolve uma cópia do `whole` indicado, mas com uma `part` específica substituída pela `part` recebida.

  Por exemplo, eis uma lente para obter ou definir o cabelo de uma pessoa:

  ```roc
  hair_lens = {
      get: |person| person.hair,
      set: |person, hair| { ..person, hair },
  }
  ```

  Podemos usar esta lente para focar o cabelo do Bob, assim:

  ```roc
  bob_hair = bob |> hair_lens.get
  ```

  E podemos mudar-lhe o cabelo assim:

  ```roc
  new_hair = { ..bob.hair, length: Short }
  new_bob = bob |> (hair_lens.set)(new_hair)
  ```

- Nota: os parênteses à volta de `hair_lens.set` são obrigatórios; sem eles, Roc procuraria uma função chamada `set` no tipo de `hair_lens`.

- As lentes tornam-se especialmente úteis quando começas a compô-las, permitindo-te obter e definir partes profundamente aninhadas.
  Isso pode ser feito implementando uma função como esta:

  ```roc
  compose : Lens(outer, inner), Lens(inner, part) -> Lens(outer, part)
  ```

  Depois de implementares esta função, podes usá-la para criar uma lente de comprimento do cabelo assim:

  ```roc
  length_lens = {
      get: |hair| hair.length,
      set: |hair, length| { ..hair, length },
  }
  hair_length_lens = compose(hair_lens, length_lens)

  ```

  Agora já podes cortar o cabelo ao Bob outra vez:

  ```roc
  set_hair_length = hair_length_lens.set
  new_bob = bob |> set_hair_length(Short)
  ```

- Também podes querer implementar uma função que te permita aplicar qualquer transformação a uma parte aninhada:

  ```roc
  over : Lens(whole, part), whole, (part -> part) -> whole
  ```

  Depois de a implementares, podes usar `over` assim:

  ```roc
  cut_hair = |current_length| match current_length {
      Long => Short
      Short => Bald
      Bald => Bald
  }
  new_bob = hair_length_lens |> over(bob, cut_hair)
  ```

- Recomendamos que passes primeiro os testes com a sintaxe de atualização de registos de Roc e que só depois experimentes usar lentes.
