# Dicas

## Geral

- O [tutorial de números do Python][python-numbers-tutorial] e os [tipos numéricos do Python][python-numeric-types] podem ser uma ótima introdução.

## 1. Estimar o valor após a troca

- Podes usar o [operador de divisão][division-operator] para obteres o valor da moeda trocada.

## 2. Calcular a moeda restante após uma troca

- Podes usar o [operador de subtração][subtraction-operator] para obteres o valor do troco.

## 3. Calcular o valor das notas

- Podes usar o [operador de multiplicação][multiplication-operator] para obteres o valor das notas.

## 4. Calcular o número de notas

- Precisas de dividir `amount` por `denomination`.
- Precisas de usar conversão de tipo para `int` para obteres o número exato de notas.
- Para remover as casas decimais de um `float`, podes convertê-lo em `int`.

  **Nota:** O operador `//` também faz divisão inteira. Mas, se o operando tiver `float`, o resultado continua a ser `float`.

## 5. Calcular o que sobra depois de trocar em notas

- Precisas de encontrar o resto de `amount` que não corresponde a uma `denomination` inteira.
- O operador de módulo `%` pode ajudar a encontrar o resto.

## 6. Calcular o valor após a troca

- Precisas de calcular a percentagem `spread` de `exchange_rate` usando o operador de multiplicação e somá-la a `exchange_rate` para obteres a moeda trocada.
- É preciso calcular a taxa real. Lembra-te de somar a _taxa_ de câmbio e a _comissão_ de câmbio.
- Podes obter o dinheiro trocado afetado pela comissão usando a operação de divisão e a conversão de tipo para `int`.
