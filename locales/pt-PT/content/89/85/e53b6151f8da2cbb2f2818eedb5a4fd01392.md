# Introdução

Em JavaScript, um array é uma estrutura do tipo lista, sem comprimento fixo, que pode conter qualquer tipo de primitivos ou objetos, incluindo tipos mistos.

Para criar um array, adiciona elementos entre parênteses retos `[]`.
Para ler a partir do array, coloca o índice entre parênteses retos `[]` depois do identificador.
Os índices de um array começam em zero.

Por exemplo:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers[2];
// => 3
```

Para obteres o número de elementos que estão num array, usa a propriedade `length`:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.length;
// => 4
```

Para alterar um elemento do array, atribuis um valor ao índice:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers[0] = 'one';
numbers;
// => ['one', 'two', 3, 'four']
```

## Métodos

Alguns dos [métodos][array_methods] disponíveis em todos os objetos Array podem ser usados para adicionar ou remover elementos de um array.

### push

> O método `push()` adiciona um ou mais elementos ao fim de um array e devolve o novo comprimento do array.[^1]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.push(5); // => 5
numbers;
// => [1, 'two', 3, 'four', 5]
```

### pop

> O método `pop()` remove o último elemento de um array e devolve esse elemento.
> Este método altera o comprimento do array.[^2]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.pop(); // => four
numbers;
// => [1, 'two', 3]
```

### shift

> O método `shift()` remove o primeiro elemento de um array e devolve o elemento removido.
> Este método altera o comprimento do array.[^3]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.shift(); // => 1
numbers;
// => ['two', 3, 'four']
```

### unshift

> O método unshift() adiciona um ou mais elementos ao início de um array e devolve o novo comprimento do array.[^4]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.unshift('one'); // => 5
numbers;
// => ['one', 1, 'two', 3, 'four']
```

### splice

> O método splice() altera o conteúdo de um array, removendo ou substituindo elementos existentes e/ou adicionando novos elementos no local. Este método devolve um array com os elementos eliminados.[^5]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.splice(2, 1, 'one'); // => [3]
numbers;
// => [1, 'two', 'one', 'four']
```
