# Dicas

## 1. Obter a primeira letra de uma frase

- Volta a consultar a introdução para descobrires como obter uma determinada letra de uma string.
- Os índices começam a contar a partir do 0.

## 2. Capitalizar uma palavra

- Capitalizar significa ter um único caráter _maiúsculo_, seguido de carateres _minúsculos_.
- Por isso, primeiro tens de extrair a primeira letra e convertê-la [para maiúsculas][mdn-to-upper-case].
- Depois tens de determinar o resto da string (tudo o que vem depois do primeiro caráter).
  O [método slice][mdn-slice] pode ajudar-te nisso.
- Depois de aplicares a conversão [para minúsculas][mdn-to-lower-case], podes combinar a primeira letra com o resto usando o operador de adição `+`.

## 3. Obter a última letra de uma frase

- Volta a consultar a introdução para descobrires como obter uma determinada letra de uma string.
- O índice da última letra pode ser obtido a partir da propriedade `.length` da string e do facto de os índices começarem a contar em 0.
- As strings têm um método [trim][mdn-trim] que remove os espaços em branco no início e no fim.

## 4. Ser educado

- Reutiliza uma função existente para capitalizar a palavra.
- O operador de adição `+` pode ser usado para concatenar duas strings.
