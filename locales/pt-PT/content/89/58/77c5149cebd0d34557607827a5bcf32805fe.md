# Introdução

Suponhamos que queremos somar um array de números.
Há muitas formas de atingir este objetivo.

- Em muitas linguagens, este problema exprime-se como um ciclo com uma variável acumuladora.
- Este problema pode ser escrito como uma função recursiva.
  Em pseudocódigo, podíamos ter isto.

  ```none
  function Add(X, Sum=0):
    if X is empty then
      return Sum
    else
      return Add(rest(X), Sum + first(X))
    end
  end
  ```

  Este método de dividir o problema em partes mais pequenas também pode ser descrito como "reduzir em direção ao caso base".

**Reduce** é uma forma de combinar todos os elementos de uma estrutura de dados num único valor.
O processo itera sobre a estrutura de dados, aplicando uma função a cada elemento para atualizar o resultado acumulado.

No `jq`, este processo está implementado no [filtro `reduce`][jq-man-reduce].
Noutras linguagens, pode chamar-se "fold", "fold-left", "inject" ou "aggregate".

A expressão `reduce` do `jq` tem este aspeto.

```jq
reduce STREAM_EXPRESSION as $var (INITIAL_VALUE; UPDATE_EXPRESSION)
```

- `STREAM_EXPRESSION` é um _fluxo_ de itens, cada um guardado, por sua vez, na variável `$var`.
  - Lembra-te: para obteres um fluxo a partir de um array, usa o [filtro iterador `.[]`][jq-man-iterator]: `$myArray | .[]`.
- `INITIAL_VALUE` é o valor inicial do resultado acumulado (conhecido como "acumulador").
- A `UPDATE_EXPRESSION` combina ("dobra") o valor atual ($var) no acumulador.
  - No contexto desta expressão, `.` é o valor do acumulador.
  - A saída da expressão é guardada no acumulador para ser usada na iteração seguinte.
  - Depois da última iteração, o resultado acumulado é a saída do `reduce`.

Vamos ver um exemplo: somar os números de um array.
O filtro `add` faz exatamente isto, mas vamos ver como implementá-lo.

Se usarmos `[10, 20, 30, 40]` como valor de entrada e tomarmos zero como estado inicial, é este o aspeto de cada passo.

| \#  | estado | elemento | redutor | resultado |
| :-: | :----: | :------: | :-----: | :-------: |
|  1  |   0    |    10    | 0 + 10  |    10     |
|  2  |   10   |    20    | 10 + 20 |    30     |
|  3  |   30   |    30    | 30 + 30 |    60     |
|  4  |   60   |    40    | 60 + 40 |    100    |

Em sintaxe `jq`, isto corresponde a este código.

```jq
0 + 10 | . + 20 | . + 30 | . + 40
```

Podemos exprimir isso com o filtro `reduce`.

```jq
[10, 20, 30, 40] | reduce .[] as $n (0; . + $n)     # => 100
```

## Algumas coisas a ter em conta

- Na expressão de redução, `.` é o acumulador.
  Se o valor de entrada for um objeto que precisas de referenciar dentro da função de redução, tens de o guardar numa variável.

  ```jq
  {"apple": 10, "banana": 16, "carrot": 4}
  | . as $obj
  | reduce (keys | .[]) as $key (0; . + $obj[$key])     # => 30
  ```

- O acumulador pode ser de qualquer tipo de dados.
  Por exemplo, podes querer inverter um array.

  ```jq
  ["A", "B", "C", "D"]
  | reduce .[] as $elem ([]; [$elem] + .)       # => ["D", "C", "B", "A"]
  ```
