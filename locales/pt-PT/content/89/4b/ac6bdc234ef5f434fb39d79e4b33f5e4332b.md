# Sobre

Um *conjunto disjunto* (uma estrutura de união-busca) mantém uma coleção
de valores repartidos por grupos que não se sobrepõem e responde
depressa a uma pergunta: estes dois valores estão no mesmo grupo? Faz
parte do vocabulário [`disjoint-sets`][disjoint-sets].

`<disjoint-set>` constrói uma estrutura vazia. Os valores, os *átomos*,
acrescentam-se com `add-atom`, ou em bloco com `add-atoms`; cada um
começa num grupo só para si:

```
<disjoint-set> ( -- disjoint-set )
add-atom       ( atom disjoint-set -- )
add-atoms      ( seq disjoint-set -- )
```

```factor
USING: disjoint-sets ;

<disjoint-set>
{ "a" "b" "c" "d" } over add-atoms   ! four singleton groups
```

`equate` une os grupos que contêm dois átomos. A união é transitiva: a
partir do momento em que `a` é equiparado a `b` e `b` a `c`, os três
partilham um só grupo.

```
equate ( atom1 atom2 disjoint-set -- )
```

Cada grupo é identificado por um único membro canónico, o seu
*representante*. `representative` devolve-o, e dois átomos pertencem ao
mesmo grupo precisamente quando os seus representantes são iguais.
`equiv?` faz esse teste diretamente:

```
representative ( atom disjoint-set -- representative )
equiv?         ( atom1 atom2 disjoint-set -- ? )
```

```factor
USING: disjoint-sets ;

<disjoint-set>
{ "a" "b" "c" "d" } over add-atoms
"a" "b" pick equate
"b" "c" pick equate
"a" "c" pick equiv? .          ! => t   (transitively connected)
"a" "d" pick equiv? .          ! => f
"a" over representative
"c" pick representative = .     ! => t   (same representative)
```

Qual é o átomo escolhido como representante de um grupo é um detalhe
interno: pode ser qualquer membro do grupo, e pode mudar à medida que os
grupos se fundem. Nunca dependas de um átomo em particular ser o
representante; depende apenas de que dois átomos do mesmo grupo estejam
de acordo.

`disjoint-set-members` devolve todos os átomos que foram acrescentados.

A estrutura é *mutável*: `equate` e `add-atom` alteram o conjunto
disjunto no próprio local, em vez de devolverem um novo. A implementação
usa união por ordem com compressão de caminhos, pelo que uma longa
sequência de chamadas a `equate` e a `representative` tem, na prática,
um tempo constante em cada uma.
