# Dicas

## 1. Verifica quantas aves visitaram hoje

- "Hoje" significa a última entrada no vetor `birds_per_day`.
- A última entrada em `v` pode ser acedida através do índice `length(v)`.
- A função [`tail(v, n)`][ref-tail] é conveniente para ler (mas não para modificar) o fim de um vetor.
  O argumento `v` é o vetor, `n` é o número de entradas a devolver, com um valor predefinido de 6.

## 2. Incrementa a contagem de hoje

- Podes usar o índice `length(v)` para aceder à entrada de hoje.
- Em alternativa, soma o vetor de comprimento 7 adequado.
- Para construir um vetor com entradas repetidas, a função [`rep()`][ref-rep] pode ser útil.
