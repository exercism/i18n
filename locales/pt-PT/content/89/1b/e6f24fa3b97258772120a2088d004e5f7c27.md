# Testes

Como o OCaml é uma linguagem compilada, tens de compilar a tua submissão e o código dos testes antes de poder correr os testes. 
Usamos o [`dune`](https://dune.build/) para compilar.
Cada pasta tem um ficheiro dune que especifica como compilar e também um Makefile que delega ao dune.

Para compilar e correr os testes, basta escrever, a partir da pasta do exercício:

```bash
make
```

## Criar o teu primeiro módulo OCaml

Para criar um módulo que possa ser usado com o teste do exercício `bob`, coloca o seguinte num ficheiro chamado `bob.ml`:

```ocaml
open Base 

let response_for input = failwith "TODO"
```
