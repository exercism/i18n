# Sobre

Os [closures][closures] em Swift são blocos de código autónomos que podem receber parâmetros para desencadear o seu cálculo e devolver valores.
Os closures também capturam valores do seu ambiente e usam-nos nos seus cálculos.
Como são autónomos, podem ser passados de um lado para o outro num programa como qualquer outro valor, ou atribuídos a constantes e variáveis.

Os closures podem parecer muito com as funções de Swift, e realmente parecem, e por uma boa razão.
Em Swift, as funções são casos especiais de closures: têm obrigatoriamente um nome e são definidas com uma sintaxe ligeiramente diferente.

Embora, tecnicamente, as funções em Swift sejam closures, quando as pessoas falam de «closures» em Swift estão a referir-se a [expressões de closure][closure-expressions].
As expressões de closure escrevem-se com uma lista de parâmetros, seguida de um tipo devolvido e da palavra-chave `in`, seguida do corpo do closure, tudo entre um par de chavetas:

```swift
{ (a: Double, b: Double) -> Double in
  return (a + b) / 2.0
}
```

Isto define uma expressão de closure do tipo `(Double, Double) -> Double`, que pode ser executada de forma semelhante a uma função deste tipo, aplicando-a a parâmetros do tipo adequado:

```swift
{ (a: Double, b: Double) -> Double in
  return (a + b) / 2.0
}(10.0, 15.0)
// returns 12.5
```

Como não é muito prático escrever a expressão de closure completa sempre que se quer executá-la, os closures podem ser atribuídos a nomes, como qualquer outro valor em Swift.
Depois, podem ser chamados aplicando o nome aos parâmetros:

```swift
let mean = { (a: Double, b: Double) -> Double in
  (a + b) / 2.0
}

mean(13.0, 100.0)
// returns 56.5
```

Como se vê acima, os closures, tal como as funções normais, podem omitir a palavra-chave `return` se o corpo do closure for uma única expressão.

Na maioria das vezes, os closures são usados com funções de ordem superior, quer passados como parâmetros, quer devolvidos como resultados:

```swift
[11, 75, 3, 99, 53].contains(where: { (x: Int) -> Bool in x > 100 })
// returns false

["apple", "ball", "carrot"].sorted(by: { (s1: String, s2: String) -> Bool in s1.count < s2.count })
// returns ["ball", "apple", "carrot"]

func makeAdder(base: Int) -> (Int) -> Int {
  { (x: Int) -> Int in base + x }
}
```
