# Crachás com nomes

## História

Neste exercício vais escrever código para imprimir crachás com nomes para os funcionários de uma fábrica. Os funcionários têm um ID, um nome e o nome do departamento. As etiquetas dos crachás dos funcionários são formatadas da seguinte forma: `"[id] - [name] - [DEPARTMENT]"`.

Devido a uma particularidade do sistema informático, os novos funcionários às vezes ainda não têm um ID quando começam a trabalhar na fábrica. Como os crachás são obrigatórios, recebem um crachá temporário sem o prefixo do ID.

Até o dono da fábrica tem de usar um crachá em todos os momentos. No entanto, o dono não tem departamento. Neste caso, a etiqueta deve imprimir `"OWNER"` em vez do nome do departamento.

## Tarefas

Estas são tarefas de exemplo que se enquadram no exercício dos crachás dos funcionários:

- Imprime um crachá para um funcionário
- Imprime um crachá para um novo funcionário
- Imprime um crachá para o dono
