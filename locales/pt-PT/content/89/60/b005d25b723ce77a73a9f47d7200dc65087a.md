# Introdução

## Módulos

Até agora, todos os exercícios que viste usavam classes.
Por vezes não precisamos do custo de criar um objeto com estado, por isso usamos antes `module`.

Um módulo é muito semelhante a uma classe (na verdade, `Module` é o pai de `Class` na hierarquia de objetos). A principal diferença é que, em vez de usarmos métodos de instância, usamos métodos de classe.
Os métodos de classe começam por `self.` e são chamados diretamente num módulo.

Por exemplo:

```ruby
module Speaker
  def self.echo(something)
    "#{something} ... #{something}"
  end
end

Speaker.echo("Hello")   #=> "Hello ... Hello"
```

## Ciclos

Há várias formas de escrever ciclos em Ruby, mas como tendemos a usar enumeração em vez de ciclos em geral, o ciclo mais comum é talvez o `while`:

```ruby
counter = 0

while counter < 5
  counter += 1
end
```

Também podes usar o seu irmão `until`:

```ruby
counter = 0

until counter == 5
  counter += 1
end
```
