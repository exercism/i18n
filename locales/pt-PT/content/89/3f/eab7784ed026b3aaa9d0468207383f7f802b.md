# Instruções

Como futura maga, a Elyse precisa de praticar alguns básicos.
Tem uma pilha de cartas que quer manipular.

Para facilitar um pouco as coisas, só usa as cartas de 1 a 10, por isso a sua pilha de cartas pode ser representada por um vetor de números.
A posição de uma determinada carta corresponde ao índice no vetor.

## 1. Retirar uma carta da pilha

Para tirar uma carta, devolve a carta que está no índice `position` da pilha dada.

```julia-repl
julia> stack = [1, 2, 4, 1];
julia> position = 3;
julia> get_item(stack, position)
4
```

## 2. Trocar uma carta na pilha

Faz um pouco de prestidigitação e troca a carta que está no índice `position` pela carta de substituição fornecida.
Devolve a pilha ajustada.

```julia-repl
julia> stack = [1, 2, 4, 1];
julia> position = 3;
julia> replacement_card = 6;
julia> set_item!(stack, position, replacement_card)
[1, 2, 6, 1]
```

## 3. Inserir uma carta no topo da pilha

Faz aparecer uma carta, inserindo uma nova carta no topo da pilha.
Devolve a pilha ajustada.

```julia-repl
julia> stack = [5, 9, 7, 1];
julia> new_card = 8;
julia> insert_item_at_top!(stack, new_card)
[5, 9, 7, 1, 8]
```

## 4. Remover uma carta da pilha

Faz desaparecer uma carta, removendo da pilha a carta que está na `position` dada.
Devolve a pilha ajustada.

```julia-repl
julia> stack = [3, 2, 6, 4, 8];
julia> position = 3;
julia> remove_item!(stack, position)
[3, 2, 4, 8]
```

## 5. Remover a carta do topo da pilha

Faz desaparecer uma carta, removendo a carta que está no topo da pilha.
Devolve a pilha ajustada.

```julia-repl
julia> stack = [3, 2, 6, 4, 8];
julia> remove_item_from_top!(stack)
[3, 2, 6, 4]
```

## 6. Inserir uma carta no fundo da pilha

Faz aparecer uma carta, inserindo uma nova carta no fundo da pilha.
Devolve a pilha ajustada.

```julia-repl
julia> stack = [5, 9, 7, 1];
julia> new_card = 8;
julia> insert_item_at_bottom!(stack, new_card)
[8, 5, 9, 7, 1]
```

## 7. Remover uma carta do fundo da pilha

Faz desaparecer uma carta, removendo a carta que está no fundo da pilha.
Devolve a pilha ajustada.

```julia-repl
julia> stack = [8, 5, 9, 7, 1];
julia> remove_item_at_bottom!(stack)
[5, 9, 7, 1]
```

## 8. Verificar o tamanho da pilha

Verifica se o tamanho da pilha é igual a `stack_size` ou não.

```julia-repl
julia> stack = [3, 2, 6, 4, 8];
julia> stack_size = 4;
julia> check_size_of_stack(stack, stack_size)
false
```
