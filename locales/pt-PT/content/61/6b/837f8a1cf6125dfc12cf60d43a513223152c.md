# Sobre

Muitos [tipos de membros de struct e class][expression-bodied-members] (sendo os campos a principal exceção) podem usar a sintaxe de membro com corpo de expressão. Definir um membro com uma expressão produz, muitas vezes, código mais conciso e legível do que os blocos/instruções tradicionais.

```csharp
public int Times3(int input) => input * 3;

public int Interesting => 1729;
```

Os membros com corpo de expressão não podem ter blocos com várias instruções, mas quem tem experiência com programação funcional deve ser avisado de que tudo o que um membro tradicional faz também pode ser feito com um destes membros. A "expressão" pode ser uma operação de atribuição que cria efeitos secundários, ou a invocação de um método, o que significa que tudo é possível.

[expression-bodied-members]: https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/statements-expressions-operators/expression-bodied-members
