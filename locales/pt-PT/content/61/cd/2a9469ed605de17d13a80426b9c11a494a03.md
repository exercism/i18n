# Introdução

[Nil][nil-dictionary] é uma palavra inglesa que significa «nada» ou «zero».
Em Ruby, o `nil` é usado para expressar a _ausência_ de um objeto.
Noutras linguagens de programação, valores `null` ou `none` podem desempenhar um papel semelhante.

```ruby
# I do not have a favorite color
favorite_color = nil
```

O Ruby atribui a qualquer variável de instância o valor predefinido `nil` quando esta é encontrada pela primeira vez, até lhe ser atribuído outro valor.

[nil-dictionary]: https://www.merriam-webster.com/dictionary/nil
