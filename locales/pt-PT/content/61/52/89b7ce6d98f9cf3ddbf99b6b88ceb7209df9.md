# Introdução

## Atributos

Um [C# `Attribute`](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/attributes/) é uma forma de decorar uma declaração para lhe associar metadados: uma classe, um método, um enum, um campo, uma propriedade ou quaisquer [outras declarações suportadas](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/attributes/#attribute-targets).

Podes aplicar um atributo adicionando-o na linha anterior à declaração, usando um `ClassAttribute` e um `FieldAttribute`:

```csharp
[Class]
class MyClass
{
    [Field]
    int myField;
}
```

Estes metadados declarativos apenas associam informação estruturada adicional ao código e não alteram o seu comportamento. No entanto, esses metadados são usados por outras partes do código para alterar o comportamento do seu alvo, ou para acrescentar, alterar, remover ou restringir algumas das suas funcionalidades.

Existem muitos [atributos predefinidos e reservados](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/attributes/general#conditional-attribute), por exemplo: `Flags`, `Obsolete`, `Conditional` e `Experimental`. Cada um tem um significado semântico específico que pode ser consultado na documentação do C#. Repara que o nome completo de um atributo como [`Flags`](https://docs.microsoft.com/en-us/dotnet/api/system.flagsattribute) tem a forma `<Name>Attribute` (por exemplo, `FlagsAttribute`).

## Enums de flags

O [tipo `enum`](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/builtin-types/enum) do C# representa um conjunto fixo de constantes nomeadas (uma enumeração).

Normalmente, um membro de um `enum` só pode referir-se a exatamente uma dessas constantes nomeadas. No entanto, por vezes é útil referir-se a mais do que uma constante. Para isso, pode-se anotar o `enum` com o [atributo `Flags`](https://docs.microsoft.com/en-us/dotnet/api/system.flagsattribute).

Um enum de flags pode ser definido da seguinte forma (usando a notação binária de inteiros `0b`):

```csharp
[Flags]
enum PhoneFeatures
{
    Call = 0b00000001,
    Text = 0b00000010
}
```

Uma instância de `PhoneFeatures` com o valor `0b00000011` tem as flags `Call` _e_ `Text` definidas.

Por predefinição, o tipo `int` é usado para os valores dos membros do enum. Pode-se usar um tipo inteiro diferente especificando o tipo na declaração do enum:

```csharp
[Flags]
enum PhoneFeatures : byte
{
    Call = 0b00000001,
    Text = 0b00000010
}
```
