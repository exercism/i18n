# Instruções

Neste exercício vamos simular o primeiro turno de um jogo de [Blackjack][blackjack].

## 1. Calcular o valor de qualquer carta.

Vais receber duas cartas e vais poder ver a carta virada para cima do dealer.
Todas as cartas são representadas por uma string como "ace", "king", "three", "two", etc.
Os valores de cada carta são:

| carta | valor |  carta  | valor |
| :---: | :---: | :-----: | :---: |
|  ace  |  11   |  eight  |   8   |
|  two  |   2   |  nine   |   9   |
| three |   3   |   ten   |  10   |
| four  |   4   |  jack   |  10   |
| five  |   5   |  queen  |  10   |
|  six  |   6   |  king   |  10   |
| seven |   7   | _outra_ |   0   |

~~~~exercism/note
Normalmente, os ases podem valer 1 ou 11, mas, por uma questão de simplicidade, vamos assumir que só podem valer 11.
~~~~

Implementa o método `Blackjack.parse_card`, que recebe como argumento uma carta sob a forma de string.
O método deve devolver o valor da carta como um número inteiro.

```Crystal
Blackjack.parse_card("ace")
# => 11
```

## 2. Nomear intervalos de valores.

A pontuação do jogador tem de ser categorizada em intervalos de valores.
As pontuações do jogador calculam-se somando os valores das duas cartas do jogador.
Os intervalos usados são:

|  intervalo  |  valor   |
| :---------: | :------: |
|    low      | [4, 11]  |
|    mid      | [12, 16] |
|   high      | [17, 20] |
| blackjack   |   [21]   |

Implementa o método `Blackjack.card_range`, que recebe duas cartas como argumentos, sob a forma de strings.
O método deve devolver o nome do intervalo de valores em que as duas cartas se enquadram.

```Crystal
Blackjack.card_range("ten", "king")
# => "high"
```

## 3. Implementar a lógica de decisão para o primeiro turno.

Dependendo das tuas duas cartas e da carta do dealer, existe uma estratégia para o primeiro turno do jogo, na qual tens as seguintes opções:

- Ficar (S)
- Pedir carta (H)
- Dividir (P)
- Ganhar automaticamente (W)

Embora ainda não seja a ideal, vais seguir a estratégia que o teu amigo Alex está a desenvolver, que é a seguinte:

- Se tiveres um par de ases, tens sempre de os dividir.
- Se tiveres um Blackjack (duas cartas cuja soma dá 21) e o dealer não tiver um ás, uma figura ou um dez, ganhas automaticamente.
  Se o dealer tiver alguma dessas cartas, tens de ficar e esperar que a outra carta seja revelada.
- Se a soma das tuas cartas estiver no intervalo [17, 20], deves ficar sempre.
- Se a soma das tuas cartas estiver no intervalo [12, 16], deves ficar sempre, a não ser que o dealer tenha um 7 ou mais, caso em que deves pedir carta sempre.
- Se a soma das tuas cartas for 11 ou menos, deves pedir carta sempre.

Implementa o método `Blackjack.first_turn`, que recebe três cartas como argumentos, sob a forma de strings.
O método deve devolver, como string, a decisão que deves tomar.

```Crystal
Blackjack.first_turn("ace", "ace", "two")
# => "P"
```
