# Instruções

A Mary é uma grande fã da série de televisão _Star Trek: The Next Generation_.
Joga muitas vezes jogos de interpretação de papéis com papel e caneta, nos quais ela e os amigos fingem ser a tripulação da _Starship Enterprise_.
A personagem da Mary é o Capitão Picard, o que significa que tem de manter o diário de bordo do capitão.
Adora a parte criativa do jogo, mas não gosta de inventar dados aleatórios na hora.

Ajuda a Mary a criar geradores aleatórios para dados que aparecem habitualmente no diário de bordo do capitão.

~~~~exercism/note
A implementação inicial deste exercício recebe uma instância de `java.util.Random` como argumento do construtor.
Isto permite que os testes do exercício passem uma instância com uma semente predefinida, o que torna os resultados dos testes previsíveis.

Por isso, espera-se que uses a instância de `java.util.Random` fornecida na tua implementação.
~~~~

## 1. Gera um planeta aleatório

A _Starship Enterprise_ encontra muitos planetas nas suas viagens.
No universo de Star Trek, os planetas dividem-se em categorias com base nas suas propriedades.
Por exemplo, a Terra é um planeta de classe `M`.
Todas as classes planetárias possíveis são: `D`, `H`, `J`, `K`, `L`, `M`, `N`, `R`, `T` e `Y`.

Implementa o método `randomPlanetClass()`.
Deve devolver uma das classes planetárias, de forma aleatória.

```java
captainsLog.randomPlanetClass();
// => "K"
```

## 2. Gera um número de registo de nave estelar aleatório

A Enterprise (número de registo `NCC-1701`) não é a única nave estelar a voar por aí!
Quando se encontra com outra nave estelar, a Mary precisa de registar o número de registo dessa nave.

Os números de registo começam com o prefixo "NCC-" e depois usam um número de `1000` a `9999` (inclusive).

Implementa o método `randomShipRegistryNumber()` que devolve um número de registo de nave estelar aleatório.

```java
captainsLog.randomShipRegistryNumber();
// => "NCC-1947"
```

## 3. Gera uma data estelar aleatória

De que serve um diário de bordo se não inclui datas?

Uma data estelar é um número de vírgula flutuante.
As aventuras da _Starship Enterprise_ na primeira temporada de _The Next Generation_ decorrem entre as datas estelares `41000.0` e `42000.0`.
O "4" representa o século XXIV e o "1" representa a primeira temporada.

Implementa o método `randomStardate()` que devolve um número de vírgula flutuante entre `41000.0` (inclusive) e `42000.0` (exclusive).

```java
captainsLog.randomStardate();
// => 41458.15721310934
```
