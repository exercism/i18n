# Dicas

## Geral

- A contagem de aves por dia está guardada num campo chamado `birdsPerDay`.
- A contagem de aves por dia é um array que contém exatamente 7 números inteiros.

## 1. Verifica quais eram as contagens na semana passada

- Como guardamos a semana passada, só precisamos de devolver os valores dessa semana.

## 2. Verifica quantas aves visitaram hoje

- Lembra-te de que as contagens estão ordenadas por dia, da mais antiga para a mais recente, e o último elemento representa o dia de hoje.
- Podes aceder ao último elemento usando o seu índice (fixo), tendo em conta que a contagem começa em zero, ou calculando esse índice a partir do tamanho do array.

## 3. Incrementa a contagem de hoje

- Atribui ao elemento que representa a contagem de hoje o valor da contagem de hoje mais 1.

## 4. Verifica se houve um dia sem aves a visitar

- Podes iterar sobre o array com um ciclo `for`.
- Outra solução é usar a Java Stream API.

## 5. Calcula o número de aves visitantes nos primeiros dias

- Podes usar uma variável para guardar a contagem do número de aves visitantes.
- Podes iterar sobre o array com um ciclo `for`.
- Podes atualizar a variável dentro do ciclo.
- Lembra-te: os arrays são indexados a partir de `0`.

## 6. Calcula o número de dias movimentados

- Podes usar uma variável para guardar o número de dias movimentados.
- Podes iterar sobre o array com um ciclo `foreach`.
- Podes atualizar a variável dentro do ciclo.
- Podes usar uma instrução condicional dentro do ciclo.
