# Instalação

A forma mais fácil de instalar Ceylon é simplesmente **não** o instalar.
Deves conseguir resolver a maioria dos exercícios com o nosso [IDE web](http://try.ceylon-lang.org/).

No entanto, se preferires, podes instalar a distribuição de linha de comandos. A forma mais fácil de o fazer é através do [SDKMAN](http://sdkman.io/), por isso tens de o instalar primeiro se ainda não o tens; depois basta escrever `sdk install ceylon` no teu terminal.

Os utilizadores de OSX também podem instalar através do [gestor de pacotes Homebrew](http://mxcl.github.com/homebrew/).

As instruções de instalação para outras plataformas, bem como para o Ceylon IDE, um plugin para o Eclipse, estão disponíveis no [site oficial](http://ceylon-lang.org/download/).
