# Instruções

Neste exercício, estás a jogar um jogo de adivinhar números com um amigo.
As regras são simples: escolhes secretamente um número entre `1` e `100` e o teu amigo tenta adivinhar que número escolheste.
Para ajudares o teu amigo, respondes de forma diferente consoante a proximidade da tentativa ao número que escolheste (`42`).
Estas são as regras para os diferentes valores de entrada possíveis:

- Se a tentativa for `42`: "Correct"
- Se a tentativa for `41` ou `43`: "So close"
- Se a tentativa for menor que `41`: "Too low"
- Se a tentativa for maior que `43`: "Too high"

Tens quatro tarefas para codificares as respostas às tentativas.

## 1. Responde a uma tentativa correta

Implementa a função `reply` para responderes a uma tentativa correta:

```haskell
reply 42
-- -> "Correct"
```

## 2. Responde a uma tentativa próxima

Modifica a função `reply` para responderes a tentativas próximas:

```haskell
reply 41
-- -> "So close"
```

## 3. Responde a tentativas demasiado baixas

Modifica a função `reply` para responderes a tentativas demasiado baixas:

```haskell
reply 25
-- -> "Too low"
```

## 4. Responde a tentativas demasiado altas

Modifica a função `reply` para responderes a tentativas demasiado altas:

```haskell
reply 88
-- -> "Too high"
```
