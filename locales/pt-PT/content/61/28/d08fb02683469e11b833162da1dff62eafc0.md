# Instruções

Enquanto trabalhas na _Instruments of Texas_, tens como tarefa trabalhar numa calculadora experimental escrita em C#. Estás a construir uma estrutura de testes para verificar várias funções da calculadora, começando pela multiplicação. Vais ver que há uma preocupação especial quando os dois operandos da multiplicação são negativos.

A classe `Calculator` já te foi fornecida e não deve ser modificada.

## 1. Completa a definição da exceção definida pelo utilizador `CalculationException`

Completa a definição do construtor de `CalculationException`, que terá de armazenar (envolver) qualquer exceção lançada pela calculadora, bem como os operandos que estão a ser processados no momento em que a exceção é lançada.

## 2. Trata as condições de transbordo na calculadora e fornece informação melhorada a quem chama

Implementa o método `CalculatorTestHarness.Multiply()`, que deve chamar o método `Calculator.Multiply()` da instância de `Calculator` passada ao construtor, passando os valores inteiros x e y. Se ocorrer um transbordo no método `Calculator.Multiply()`, este lança uma `OverflowException`. Esta exceção deve ser capturada no método `CalculatorTestHarness.Multiply()` e envolvida numa `CalculationException`, e os valores x e y que estão a ser passados devem ser armazenados como operandos da exceção. O objeto `CalculationException` acabado de criar deve ser lançado. Podes ignorar o valor devolvido pelo método `Calculator.Multiply()` se este for bem-sucedido.

```csharp
var cth = new CalculatorTestHarness(new Calculator());
cth.Multiply(Int32.MaxValue, Int32.MaxValue);
// => throws an instance of CalculationException

var cth2 = new CalculatorTestHarness(new Calculator());
cth2.Multiply(3, 2);
// => silently exits
```

## 3. Testa a operação de multiplicação com valores de entrada válidos

Implementa o método `CalculatorTestHarness.TestMultiplication()`, que recebe dois inteiros e chama o método `CalculatorTestHarness.Multiply()`. É devolvido `"Multiply succeeded"`.

```csharp
var cth = new CalculatorTestHarness(new Calculator());
cth.TestMultiplication(6, 7);
// => "Multiply succeeded"
```

## 4. Testa a operação de multiplicação com valores de entrada negativos

Modifica o método `CalculatorTestHarness.TestMultiplication()` para que seja devolvido `"Multiply failed for negative operands. <INNER_EXCEPTION_MESSAGE>"` se ambos os argumentos inteiros forem negativos (menores que zero).

O marcador de posição `<INNER_EXCEPTION_MESSAGE>` deve ser substituído pela mensagem da exceção interna da `CalculationException`.

```csharp
var cth = new CalculatorTestHarness(new Calculator());
cth.TestMultiplication(-2, -Int32.MaxValue);
// => "Multiply failed for negative operands. " + innerException.Message
```

## 5. Testa a operação de multiplicação com valores de entrada positivos

Modifica o método `CalculatorTestHarness.TestMultiplication()` para que seja devolvido `"Multiply failed for mixed or positive operands. <INNER_EXCEPTION_MESSAGE>"` se pelo menos um dos argumentos inteiros não for negativo.

O marcador de posição `<INNER_EXCEPTION_MESSAGE>` deve ser substituído pela mensagem da exceção interna da `CalculationException`.

```csharp
var cth = new CalculatorTestHarness(new Calculator());
cth.TestMultiplication(Int32.MaxValue, Int32.MaxValue);
// => "Multiply failed for mixed or positive operands. " + innerException.Message
```
