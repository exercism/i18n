# Alias

A [forma especial `alias`][alias] permite-te encurtar ou alterar o nome pelo qual referes um módulo externo. Podes especificar um nome personalizado com a opção `:as`.

```elixir
defmodule Square do
  alias Integer, as: I

  def area(a), do: I.pow(a, 2)
end
```

Quando é usada sem argumentos, reduz o nome do módulo à sua última parte, por exemplo

```elixir
alias MyApp.Account.User
# is the same as
alias MyApp.Account.User, as: User
```

É possível agrupar vários aliases com `{}`:

```elixir
alias MyApp.Account.{User, EmailValidation}
# is the same as
alias MyApp.Account.User
alias MyApp.Account.EmailValidation
```

Normalmente, os aliases são adicionados no início da definição do módulo, mas podem ser adicionados em qualquer sítio. Têm âmbito lexical, o que significa que um alias adicionado dentro de uma definição de função não estará disponível noutra função.

Aliases não utilizados provocam avisos do compilador.

[alias]: https://hexdocs.pm/elixir/Kernel.SpecialForms.html#alias/2
