# Introdução

Por predefinição, as variáveis ficam limitadas ao âmbito em que são definidas. Se forem definidas num ficheiro fora de uma função ou de uma classe, ficam limitadas ao âmbito do ficheiro. Se forem definidas numa função ou numa classe, ficam limitadas ao âmbito dessa função ou dessa classe.

```php
<?php

$file_scoped = "I am file scoped";

function example(): void
{
  $function_scoped = "I am function scoped!";
}
```

As variáveis também podem ser declaradas especificamente com âmbito `global` ou `static`.
