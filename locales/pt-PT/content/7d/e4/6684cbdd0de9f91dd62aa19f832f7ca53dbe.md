# Introdução

## Números

Do [manual][man-types]

> O jq suporta o mesmo conjunto de tipos de dados que o JSON: números, strings, Boolean, arrays, objetos (que, em linguagem JSON, são hashes com apenas chaves do tipo string) e "null".

Vamos concentrar-nos nos **números**.

### Números e operadores numéricos

Todos os números, sejam inteiros ou não, são números de vírgula flutuante de dupla precisão IEEE754.
Isto limita-nos a 53 bits de precisão.

Com números, podes usar os operadores habituais:

- aritmética: `+`, `-`, `*`, `/`, `%`
- comparação: `==`, `!=`, `<`, `<=`, `>=`, `>`
- as [funções matemáticas][man-math] habituais

  Nas funções com um único parâmetro de entrada, canaliza o valor para a função

  ```sh
  $ jq -n '(1 | atan) * 4'
  3.141592653589793
  ```

  Nas funções com dois parâmetros de entrada, a função ignora o valor de entrada e
  espera receber esses valores como parâmetros (lembra-te de que os parâmetros
  são separados por ponto e vírgula)

  ```sh
  $ jq -n 'pow(2; 10)'
  1024
  ```

  O ponto e vírgula é o separador dos argumentos da função, não a vírgula.

### Outras expressões de `jq`

Para resolveres o exercício, vais precisar de saber o que são expressões condicionais.

#### Expressões condicionais

O `jq` usa uma [expressão `if-then-else`][if-then-else] para as **expressões condicionais**.
Enquanto _expressão_, é colocada num pipeline.

A sintaxe é: `if CONDITION then TRUE_EXPR else FALSE_EXPR end`.

A cláusula `else` é opcional.

```jq
42 | if . < 33 then "small" else "larger" end
# => "larger"
```

As condições adicionais usam `elif`

```jq
42 | if . < 33 then "small"
     elif . < 67 then "medium"
     else "large"
     end
# => "medium"
```
