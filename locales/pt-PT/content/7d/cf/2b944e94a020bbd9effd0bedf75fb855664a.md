# Sobre

Uma quotation, escrita entre `[ ]`, é o equivalente no Factor a uma função anónima ou a um bloco de código. É um valor de primeira classe que podes colocar na pilha, guardar ou passar de mão em mão, e que só é executada quando algo a *chama*.

```factor
[ 1 + ]              ! a quotation, sitting on the stack
5 [ 1 + ] call .     ! => 6
```

As quotations são sequências de palavras, e o Factor usa-as sempre que um comportamento precisa de ser adiado ou parametrizado:

- os ramos de `if` / `when` / `unless` / `cond`
- o predicado de `filter`, `count`, `any?`, `all?`
- a transformação de `map`, `each`, `reduce`
- o corpo de `times`, `while`, `loop`

O efeito na pilha de uma quotation pode normalmente ser inferido. Quando isso não é possível (tipicamente quando a quotation é guardada e só mais tarde se usa `call`), declara o efeito explicitamente: `call( a b -- c )`.

## Combinar quotations

```
compose ( quot1 quot2 -- compound )
curry   ( value quot  -- curried )
```

`compose` concatena duas quotations de ponta a ponta numa nova quotation que executa primeiro a primeira e depois a segunda. `curry` antepõe um valor fixo e devolve uma quotation que coloca esse valor na pilha antes de invocar a original. Ambas produzem quotations normais que podes usar com `call`, guardar ou passar a combinadores.

```factor
USING: kernel math ;

3 [ 2 * ] [ 1 + ] compose call .   ! 3 2 * 1 + => 7
5 [ 1 + ] curry call .             ! 5 1 +     => 6
```
