# Introdução

Vais receber uma solução exemplar para cada exercício que resolveres no Exercism.
No percurso de Julia, essas soluções contêm geralmente [docstrings](https://en.wikipedia.org/wiki/Docstring).
Depois de resolveres este exercício, vais saber como as docstrings estão estruturadas, como escrevê-las e como aceder a docstrings através do REPL.

~~~~exercism/note
Não precisas de escrever docstrings para as tuas funções enquanto resolves exercícios no percurso de Julia, se não quiseres.
~~~~

## Sintaxe

Qualquer string imediatamente antes de qualquer tipo de objeto de Julia, por exemplo uma função ou um tipo, será interpretada como uma docstring que documenta esse objeto.
Por exemplo:

```julia
"Tell a joke."
joke() = ...
```

As docstrings em Julia são formatadas com [Markdown](https://en.wikipedia.org/wiki/Markdown).
Isto permite usar funcionalidades como indentação, blocos de código ou texto a negrito nas docstrings.

~~~~exercism/note
Podes encontrar uma lista das funcionalidades de Markdown suportadas na [documentação da biblioteca padrão de Markdown](https://docs.julialang.org/en/v1/stdlib/Markdown/).
~~~~

Uma docstring mais complexa pode ter este aspeto:

````julia
"""
    mean(x, y)

Compute the mean value of `x` and `y`.
"""
mean(x, y) = (x + y) / 2
````

O Julia Manual contém algumas convenções que deves seguir:

> - Mostra sempre a assinatura de uma função no topo da documentação, com uma indentação de quatro espaços, para que seja impressa como código Julia.
> - Inclui uma única frase de uma linha a descrever o que a função faz ou o que o objeto representa, depois do bloco de assinatura simplificada.
>    Se for preciso, dá mais detalhes num segundo parágrafo, após uma linha em branco.
>    Ao documentar funções, a frase de uma linha deve usar a forma imperativa ("Faz isto", "Devolve aquilo") em vez da terceira pessoa (não escrevas "Devolve o comprimento...").
>    Deve terminar com um ponto final.
> - Não te repitas.
>    Como o nome da função é dado pela assinatura, não é preciso começar a documentação com "A função `mean`...": vai direto ao assunto.
> - Usa acentos graves para identificar código e equações.
> - Coloca os caracteres `"""` de início e de fim em linhas próprias.

~~~~exercism/note
A lista acima cobre apenas as convenções de que podes precisar ou que podes encontrar no contexto do Exercism.
Podes encontrar uma lista completa e não abreviada no [Julia Manual](https://docs.julialang.org/en/v1/manual/documentation/).
Outras convenções para documentar conceitos mais avançados de Julia serão introduzidas a par do conceito, em exercícios posteriores.
~~~~

## Aceder a docstrings

Podes procurar docstrings no REPL escrevendo `?` seguido do nome da função ou do objeto, por exemplo:

```julia-repl
help?> println
search: println printstyled print sprint isprint

  println([io::IO], xs...)


  Print (using print) xs followed by a newline. If io is not supplied, prints to stdout.

  Examples
  ==========

  julia> println("Hello, world")
  Hello, world

  julia> io = IOBuffer();

  julia> println(io, "Hello, world")

  julia> String(take!(io))
  "Hello, world\n"
```

Isto também pode ser usado como uma pesquisa básica, por exemplo se tiveres dúvidas sobre a grafia exata de uma função:

```julia-repl
help?> printline
search:

Couldn't find printline
Perhaps you meant println, pipeline, @inline or print
  No documentation found.

  Binding printline does not exist.
```
