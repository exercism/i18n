# Instruções

Neste exercício tens de implementar alguns métodos para manipular um array de linguagens de programação.

## 1. Define um método que devolva um array de linguagens vazio

Define o método `LanguageList.list`, que não recebe argumentos e devolve um array vazio do tipo `Array(String)`.

```crystal
LanguageList.list()
# => []
```

## 2. Define um método para adicionar uma linguagem ao array

Define o método `LanguageList.add`, que recebe 2 argumentos (um _array de linguagens_ e um literal de string de uma _linguagem_).
O método deve devolver o array com a nova linguagem adicionada ao fim do array.

```crystal
language_list = LanguageList.list()
# => []
language_list = LanguageList.add(language_list, "Crystal")
# => ["Crystal"]
language_list = LanguageList.add(language_list, "Ruby")
# => ["Crystal", "Ruby"]
```

## 3. Define um método para remover uma linguagem do array

Define o método `LanguageList.remove`, que recebe 1 argumento (um _array de linguagens_).
O método deve devolver o array sem o último elemento.
Assume que o array terá sempre pelo menos um elemento.

```crystal
language_list = LanguageList.list()
# => []
language_list = LanguageList.add(language_list, "Crystal")
# => ["Crystal"]
language_list = LanguageList.add(language_list, "Ruby")
# => ["Crystal", "Ruby"]
language_list = LanguageList.remove(language_list)
# => ["Crystal"]
```

## 4. Define um método que devolva o enésimo elemento do array

Define a função `LanguageList.at`, que recebe 2 argumentos (um _array de linguagens_ e um índice).
O método deve devolver a linguagem no índice n do array.
Assume que haverá sempre uma linguagem no índice.

```crystal
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Crystal")
# => ["Crystal"]
language_list = LanguageList.add(language_list, "Ruby")
# => ["Crystal", "Ruby"]
LanguageList.at(language_list, 1)
# => "Ruby"
```

## 5. Define um método para analisar uma string de linguagens

Define o método `LanguageList.parse`, que recebe 1 argumento (um literal de string de linguagens separadas por vírgulas).
O método deve devolver um array de linguagens.

```crystal
LanguageList.parse("Crystal, Ruby")
# => ["Crystal", "Ruby"]
```
