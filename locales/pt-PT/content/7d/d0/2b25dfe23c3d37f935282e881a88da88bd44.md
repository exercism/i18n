# Dicas

## 1. Verifica quais eram as contagens na semana passada

- Os [vetores][vectors] são representados em Clojure com parênteses retos (`[ ]`)

## 2. Verifica quantos pássaros visitaram hoje

- A função [`peek`][peek] pode ser usada para devolver o último elemento de um vetor.

## 3. Incrementa a contagem de hoje

- A função [`update`][update] pode ser usada para devolver um novo vetor com um elemento diferente num determinado índice.

- A função [`count`][count] pode ser usada para determinar o comprimento do vetor.

- As funções [`inc`][inc] e [`dec`][dec] podem ser usadas para incrementar e decrementar valores inteiros.

## 4. Verifica se houve um dia sem pássaros visitantes

- A função [`every?`][every?] pode ser usada para verificar se todos os elementos de uma coleção satisfazem um determinado predicado.

- O predicado [`pos?`][pos?] devolve `true` se um número for maior que zero.

- A função [`not`][not] devolve `true` se uma expressão for avaliada como falsa.

## 5. Calcula o número de pássaros visitantes nos primeiros dias

- A função [`take`][take] pode ser usada para devolver uma sequência com os primeiros n elementos de uma coleção.

- A função [`reduce`][reduce] pode ser usada para somar uma coleção de valores.

## 6. Calcula o número de dias movimentados

- A função de ordem superior [`filter`][filter] pode ser usada para devolver uma sequência com os elementos de uma coleção que satisfazem um determinado predicado.

## 7.  Verifica se a semana é ímpar

- A função [`=`][equality] pode ser usada para testar a igualdade.
