# Sobre

Existem algumas construções básicas de [controlo de fluxo](https://clojure.org/guides/learn/flow) em Clojure. O `if` é a condicional mais importante: é constituída por uma condição, um "then" e um "else" opcional. O `if` só avalia o ramo selecionado pela condição.

```clojure
(if (even? 2) "even" "odd")
```

O `cond` é uma série de testes e expressões. Cada teste é avaliado por ordem e, para o primeiro teste verdadeiro, a expressão é avaliada e devolvida.

```clojure
(cond (= x 5) "Expression to evaluate when x equals 5"
      (> x 7) "Expression to evaluate when x is greater than 7"
      :else   "Expression to evaluate in all other cases")
```
