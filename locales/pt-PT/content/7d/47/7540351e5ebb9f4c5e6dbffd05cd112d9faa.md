# Apêndice às instruções

## Formato do jardim

O jardim é representado como uma string terminada em null, com um caráter de nova linha no fim de cada linha.

Um exemplo seria `"   \n * \n   \n"`

## Registos

| Registo | Utilização   | Tipo    | Descrição                     |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | entrada      | endereço | string de entrada terminada em null  |
| `$a1`    | entrada/saída | endereço | string de saída terminada em null |
| `$t0-9`  | temporário   | qualquer | para armazenamento temporário        |
