# Introdução

## Sobrecarga de operadores

Os principais operadores aritméticos e de comparação podem ser adaptados para serem usados pelas tuas próprias classes e estruturas. A isto chama-se _sobrecarga de operadores_.

A maioria dos operadores tem a forma:

```csharp
static <return type> operator <operator symbols>(<parameters>);
```

Os operadores de conversão têm a forma:

```csharp
static (explicit|implicit) operator <cast-to-type>(<cast-from-type> <parameter name>);
```

Os operadores comportam-se da mesma forma que os métodos estáticos: o símbolo do operador ocupa o lugar do identificador do método, e ambos têm parâmetros e um tipo devolvido. As regras de tipos para os parâmetros e para o tipo devolvido seguem a tua intuição. Podes contar com o compilador para te dar orientações detalhadas.
