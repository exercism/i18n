# Artigos

Cada exercício pode ter artigos associados, que exploram algum aspeto interessante do exercício.

## Tópicos

Tópicos possíveis que um artigo pode explorar:

- Comparar o desempenho de abordagens diferentes
- Qualquer coisa interessante que te lembre!

## Considerações gerais

- Se o teu artigo se basear em código que escreveste, considera fazer commit desse código (dentro do diretório do artigo)
  - Um exemplo é um artigo sobre desempenho, para o qual foi escrito código de medição de desempenho

## Para que exercícios escrever artigos?

Para qualquer exercício, desde que haja algo interessante para explorar.

## Ficheiros

Cada artigo tem de acrescentar os dois ficheiros seguintes:

- `.articles/<article-slug>/content.md`: descrição do artigo (vê [a documentação](/docs/building/tracks/practice-exercises#file-articles-article-slug-content-md))
- `.articles/<article-slug>/snippet.md`: excerto que apresenta o artigo (vê [a documentação](/docs/building/tracks/practice-exercises#file-articles-article-slug-snippet-txt))

Depois, precisas de acrescentar ou atualizar:

- `.articles/config.json`: metadados dos artigos (vê [a documentação](/docs/building/tracks/practice-exercises#file-article-config-json))
