# Testes

## Escrever o código

Escreve o teu código em `src/lib.cairo`.
Os exercícios vêm com um ficheiro stub em `src/lib.cairo` que te mostra as assinaturas do código que vais precisar de escrever.

Na maioria dos exercícios, o melhor é escreveres todo o teu código no ficheiro `src/lib.cairo`.
Se quiseres dividir a tua solução por vários ficheiros, consulta o [capítulo sobre módulos][chapter-modules] do The Cairo Book.

[chapter-modules]: https://book.cairo-lang.org/ch07-02-defining-modules-to-control-scope.html

## Executar os testes

Para executares os testes, primeiro tens de mudar o teu diretório de trabalho para o diretório do exercício que queres testar:

```bash
cd path/to/exercise
```

E, em seguida, executa o seguinte comando:

```bash
scarb cairo-test
```

Por predefinição, só o primeiro teste é que está ativado.
Quando estiveres pronto para passar o teste seguinte, remove a flag `ignore` desse teste (`#[ignore]`).

Para executares todos os testes, incluindo os ignorados, podes remover a flag `ignore` de todos os testes ou basta executares:

```bash
scarb cairo-test --include-ignored
```

Não hesites em escrever o mínimo de código possível para os testes passarem.
As falhas nos testes vão indicar-te o que deves escrever a seguir.

Como o Cairo verifica todo o código em tempo de compilação, é possível que os teus testes não compilem enquanto não escreveres o código necessário.
Mesmo os testes marcados como `ignore` são verificados em tempo de compilação.
Podes [comentar][comments] os testes que não compilem, começando cada linha com `//`.
Depois, quando estiveres pronto para trabalhar nesse teste, podes descomentá-lo.
O Cairo também tem uma macro especial chamada `panic!()`, que podes usar em partes do código ainda inacabadas para que o teu programa compile.

[comments]: https://book.cairo-lang.org/ch02-04-comments.html
