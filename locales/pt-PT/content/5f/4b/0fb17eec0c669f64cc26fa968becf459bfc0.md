# Anexo às instruções

## Implementação

Este exercício exige que chames uma função que é passada como argumento.
Em Uiua, podes fazer isto através de [macros](https://www.uiua.org/tutorial/macros), que é a forma como este exercício espera que o resolvas.

```exercism/note
Percebes logo que um binding é uma macro por causa do sufixo `!`.
```
