# Sobre

[Operadores ternários][ternary-operators] permitem definir condições if em expressões, em vez de blocos de instruções. Isto aproxima-se das abordagens de programação funcional e, muitas vezes, pode tornar o código mais expressivo e menos propenso a erros.

O operador ternário combina três expressões: uma condição seguida de uma expressão que é avaliada e devolvida se a condição for verdadeira (a parte `if`, introduzida por `?`) e de uma expressão que é avaliada e devolvida se a condição for falsa (a parte `else`, introduzida por `:`).

```csharp
int a = 3, b = 4;
int max = a > b ? a : b;
// => 4
```

[ternary-operators]: https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/operators/conditional-operator
