# Instalação

## Linux

O Bash, enquanto shell do GNU, encontra-se em qualquer sistema GNU/Linux.
O BSD e outros derivados do UNIX provavelmente exigem que sejas tu a instalá-lo.
Se estás em BSD, AIX, ou num Linux que não vem com o bash, consulta os recursos do teu sistema operativo sobre a instalação de pacotes que não fazem parte do núcleo.

Na interface gráfica que preferires, procura uma aplicação chamada "Terminal": pode estar numa secção "Administrative/System Tools".

Para verificares a versão do Bash disponível, a partir da linha de comandos ou do terminal, executa:

    echo $BASH_VERSION

Se o teu shell for o `bash`, deve mostrar algo como:

    4.4.19(1)-release

Não deves precisar de fazer mais nada: o bash deve estar instalado e no teu path, já que é o teu shell atual.

Se o teu shell não for o bash, não há razão para o mudares.
Podes escrever e executar scripts bash sem estares num shell bash.

Para verificares a versão do bash instalada, executa:

```plain
bash --version
```

Vai mostrar algo como isto:

```
GNU bash, version 4.4.19(1)-release (x86_64-pc-linux-gnu)
Copyright (C) 2016 Free Software Foundation, Inc.
License GPLv3+: GNU GPL version 3 or later <http://gnu.org/licenses/gpl.html>

This is free software; you are free to change and redistribute it.
There is NO WARRANTY, to the extent permitted by law.
```

Se não mostrar, é possível que não tenhas o bash instalado.
Deves instalá-lo com o gestor de pacotes da tua distribuição.

## Windows

No Windows 10, podes instalar o [WSL](https://docs.microsoft.com/en-us/windows/wsl/about).
Isto instala uma distribuição Linux completa (bem, os componentes sem interface gráfica) que corre nativamente no Windows.

Em alternativa, podes instalar:

* [Cygwin](https://cygwin.com/)
* [git for windows](https://gitforwindows.org/)
* [MinGW](http://mingw.org/)
* uma distribuição Linux completa [numa máquina virtual](https://docs.microsoft.com/en-us/virtualization/hyper-v-on-windows/about/)

## MacOS

Para o Apple OSX:

* abre o Finder,
* abre a pasta Applications,
* abre a pasta Utilities,
* por fim, abre a aplicação `Terminal`.

Nota que a versão do bash instalada no MacOS é muito antiga, a versão 3.2.
Isto deve-se a (i) as versões mais recentes do bash estarem licenciadas ao abrigo da GPLv3 e (ii) a Apple não querer ser obrigada a cumprir os termos dessa licença.
Além disso, a Apple já deu sinais de que o bash vai desaparecer do MacOS: o shell de início de sessão predefinido foi recentemente [alterado de bash para zsh](https://support.apple.com/en-us/HT208050).

Para obteres um bash atualizado no teu Mac:

1. instala o [Homebrew](https://brew.sh)
1. num Terminal, escreve: `brew install bash`

Isto instala um bash atualizado em (creio) `/usr/local/bin/bash` (para que o bash predefinido do sistema não seja substituído, pois outras ferramentas podem depender de /bin/bash).

Se quiseres que o bash do Homebrew seja iniciado quando escreves `bash`, edita o teu ficheiro ~/.bash_profile (ou ~/.profile) para colocar /usr/local/bin *antes* de /bin no PATH:

    PATH=/usr/local/bin:$PATH
