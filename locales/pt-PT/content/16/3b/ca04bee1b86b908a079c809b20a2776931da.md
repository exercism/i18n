# Instruções

Olá, Agente Double-Null0111.

A tua missão, se decidires aceitá-la, é escrever um par de ferramentas que te ajudem a infiltrar-te no quartel-general da UMBRA (Lacaios Unidos Realmente Horríveis) e a recuperar os planos do seu mais recente esquema verdadeiramente horrível. Vais precisar de duas ferramentas para levar a cabo esta missão.

## 1. Protege os planos secretos recuperados com uma palavra-passe

Depois de teres os planos secretos, vais precisar de os proteger para que só quem souber a palavra-passe os possa recuperar.

Para isso, vais precisar de implementar a função `protectSecret(_ secret: String, withPassword password: String) -> (String) -> String`.
Esta função devolve outra função que recebe possíveis palavras-passe como parâmetros de entrada.
Se a palavra-passe introduzida estiver correta, a nova função devolve o segredo escondido; mas se a palavra-passe estiver errada, a função devolve "Sorry. No hidden secrets here."

```swift
let secretFunction = protectSecret("Steal the world's supply of french fries!", withPassword: "5up3r53cr37")

secretFunction("Open sesame")
// Returns "Sorry. No hidden secrets here."

secretFunction("5up3r53cr37")
// Returns "Steal the world's supply of french fries!"
```

## 2. Gera uma combinação para abrir o cofre

Descobrimos que a UMBRA baseia todas as combinações dos seus cofres no número da sala onde se encontram.
As combinações dos cofres são geradas aplicando repetidamente uma função especial ao número da sala.
Assim, o primeiro número da combinação vem de aplicar a função ao número da sala, o segundo vem de aplicar a função ao primeiro número e o terceiro vem de aplicar a função ao segundo número.

No entanto, a UMBRA muda regularmente a função usada para gerar as combinações, por isso a tua ferramenta vai precisar de receber tanto um número de sala como a função adequada para gerar a combinação.

Implementa a função `generateCombination(forRoom room: Int, usingFunction f: (Int) -> Int) -> (Int, Int, Int)` para gerar a combinação de que vais precisar.

```swift
func makeCombo(_ x: Int) -> Int {
  (x * 13) % 256
}

generateCombination(forRoom: 227, usingFunction: makeCombo)
// Returns (135, 219, 31)
```
