# Introdução

Em Go, um `struct` é uma sequência de elementos com nome chamados _campos_; cada campo tem um nome e um tipo.
O nome de um campo tem de ser único dentro do struct.
Os structs podem ser comparados às _classes_ do paradigma da programação orientada a objetos.

## Definir um struct

Crias um novo struct com as palavras-chave `type` e `struct` e defines explicitamente o nome e o tipo dos campos.
Por exemplo, aqui definimos o struct `Shape`, que guarda o nome de uma forma e o seu tamanho:

```go
type Shape struct {
    name string
    size int
}
```

Os nomes dos campos nos structs seguem a convenção de Go: os campos cujo nome começa com uma letra minúscula só são visíveis para o código do mesmo pacote, enquanto os que começam com uma letra maiúscula são visíveis noutros pacotes.

## Criar instâncias de um struct

Depois de definires o `struct`, tens de criar uma nova instância, indicando os campos pelo respetivo nome, por qualquer ordem:

```go
s := Shape {
    name: "Square",
    size: 25,
}
```

Para leres ou alterares os campos de uma instância, usa a notação `.`:

```go
// Update the name and the size
s.name = "Circle"
s.size = 35
fmt.Printf("name: %s size: %d\n", s.name, s.size)
// Output: name: Circle size: 35
```

Os campos que não tenham um valor inicial atribuído ficam com o seu valor zero.
Por exemplo:

```go
s := Shape{name: "Circle"}
fmt.Printf("name: %s size: %d\n", s.name, s.size)
// Output: name: Circle size: 0
```

Podes criar uma instância de um `struct` sem usares os nomes dos campos, desde que os definas _por ordem_:

```go
s := Shape {
	"Oval",
	20,
}
```

No entanto, esta sintaxe é considerada _código frágil_, porque pode quebrar-se quando se acrescenta um campo, sobretudo se o novo campo for de um tipo diferente.
No exemplo seguinte, acrescentamos um campo extra ao `Shape`:

```go
type Shape struct {
	name        string
	description string // new field 'description' added
	size        int
}

s := Shape{
    "Circle",
    20,
}
// Since the second field of the struct is now a string and not an int,
// the compiler will throw an error when compiling the program:
// Output: cannot use 20 (type untyped int) as type string in field value
// Output: too few values in Shape{...}
```

## Funções "New"

Por vezes, é útil ter funções que nos ajudem a criar instâncias de structs.
Por convenção, estas funções chamam-se normalmente `New` ou têm nomes que começam por `New`, mas, como são apenas funções normais, podes dar-lhes o nome que quiseres.
Podem fazer-te lembrar os construtores de outras linguagens, mas em Go são apenas funções normais.

No exemplo seguinte, uma destas funções `New` é usada para criar uma nova instância de `Shape` e definir automaticamente um valor predefinido para o `size` da forma:

```go
func NewShape(name string) Shape {
	return Shape{
		name: name,
		size: 100, //default-value for size is 100
	}
}

NewShape("Triangle")
// => Shape { name: "Triangle", size: 100 }

```

Usar funções `New` pode trazer as seguintes vantagens:

* validação dos valores dados
* gestão de valores predefinidos
* como as funções `New` são frequentemente declaradas no mesmo pacote dos structs que inicializam, podem inicializar até os campos privados do struct
