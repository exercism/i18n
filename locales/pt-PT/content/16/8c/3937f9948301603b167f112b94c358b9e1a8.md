# Dicas

## 1. Gera um planeta aleatório

- O Java não fornece uma função para escolher um elemento de uma coleção aleatoriamente.
- Lembra-te de que podes obter um elemento de um array pelo seu índice, que é um número inteiro.

## 2. Gera um número de registo aleatório de uma nave estelar

- A classe `java.util.Random` fornece um método para gerar um `int` aleatório entre 0 e um máximo indicado.

## 3. Gera uma data estelar aleatória

- O método da classe `java.util.Random` para gerar um `double` aleatório devolve sempre um número entre `0.0` e `1.0`.
