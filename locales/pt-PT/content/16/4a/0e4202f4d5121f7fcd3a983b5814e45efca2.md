# Introdução

Muitos programas precisam de valores aleatórios (_aparentemente_) para simular acontecimentos do mundo real.

Exemplos comuns e familiares incluem:
- O lançamento de uma moeda ao ar: um valor aleatório de `('Heads', 'Tails')`.
- O lançamento de um dado: um número inteiro aleatório de 1 a 6.
- Baralhar um baralho de cartas: uma ordenação aleatória de uma lista de cartas.
- A criação de árvores e arbustos numa simulação gráfica tridimensional.

Gerar valores _verdadeiramente_ aleatórios com um computador é um [desafio técnico surpreendentemente difícil][truly-random], por isso podes ver estes resultados referidos como "pseudoaleatórios".

Na prática, uma biblioteca bem concebida como o módulo [`random`][random] da biblioteca padrão do Python é rápida, flexível e dá resultados amplamente suficientemente bons para a maioria das aplicações em modelação, simulação e jogos.

Para esta breve introdução, mostramos as quatro funções mais usadas do módulo.
Incentivamos-te a explorar a documentação completa de [`random`][random], pois há muitas ferramentas e opções.

Antes de poderes utilizar as ferramentas do módulo `random`, tens primeiro de o importar:

```python
>>> import random

# Choose random integer from a range
>>> random.randrange(1000)
360

>>> random.randrange(-1, 500)
228

>>> random.randrange(-10, 11, 2)
-8

# Choose random integer between two values (inclusive)
>>> random.randint(5, 25)
22

```

Para evitares escrever o nome do módulo, podes importar funções específicas pelo nome:

```python
>>> from random import choice, choices

# Using choice() to pick Heads or Tails 10 times
>>> tosses = []
... for side in range(10):
...    tosses.append(choice(['H', 'T']))    

>>> print(tosses)
['H', 'H', 'H', 'H', 'H', 'H', 'H', 'T', 'T', 'H']


# Using choices() to pick Heads or Tails 8 times
>>> picks = []
... picks.extend(choices(['H', 'T'], k=8))
... print(picks)
['T', 'H', 'H', 'T', 'H', 'H', 'T', 'T']
```



## `randrange()` e `randint()`

Como se mostra no primeiro exemplo acima, a função `randrange()` tem três formas:

1. `randrange(stop)` dá um número inteiro `n` tal que `0 <= n < stop`
2. `randrange(start, stop)` dá um número inteiro `n` tal que `start <= n < stop`
3. `randrange(start, stop, step)` dá um número inteiro `n` tal que `start <= n < stop`
    e `n` está na sequência `start, start + step, start + 2*step...`

Para o caso mais comum, em que `step == 1`, `randint(a, b)` pode ser mais conveniente e legível.
Os resultados possíveis de `randint()` _incluem_ o limite superior, por isso `randint(a, b)` é o mesmo que usar `randrange(a, b+1)`.



## `choice()` e `choices()`

Estas duas funções assumem que estás a partir de uma [sequência][sequence-types] ou de outro contentor.
Normalmente será uma `list` ou, com algumas limitações, um `tuple` ou um `set` (_um `tuple` é imutável e um `set` não tem ordem_).

A função `choice()` devolve um elemento escolhido ao acaso de uma dada sequência, e `choices()` devolve um número especificado de elementos (`k`) escolhidos ao acaso de uma dada sequência.
Nos exemplos mostrados acima, assumimos uma moeda equilibrada, com igual probabilidade de sair cara ou coroa, mas também se podem especificar pesos.

Por exemplo, se um saco tiver 10 bolas vermelhas e 15 bolas verdes e quisermos tirar uma ao acaso:


```python
>>> random.choices(['red', 'green'], [10, 15])
['red']
```
