# Anexo às instruções

## Palavras

Define dois tuplos wrapper que estendem `disposable` (de
`destructors`) e guardam o stream subjacente a par dos contadores
inteiros `bytes` e `ops`:

- `metered-input < disposable` com os campos `stream`, `bytes` e `ops`.
- `metered-output < disposable` com os campos `stream`, `bytes` e `ops`.

Constrói cada um com `new-disposable` (em vez de `new`) para que o
wrapper fique registado no framework dos destrutores.

- `<metered-input> ( stream -- m )`: envolve um stream de entrada.
- `<metered-output> ( stream -- m )`: envolve um stream de saída.

Declara cada tuplo como instância do mixin de stream adequado:

```
INSTANCE: metered-input  input-stream
INSTANCE: metered-output output-stream
```

Depois, fornece métodos `M:` que delegam no stream subjacente
ao mesmo tempo que atualizam os contadores:

- Para `metered-input`: [`stream-read1`][stream-read1],
  [`stream-read-unsafe`][stream-read-unsafe],
  [`stream-element-type`][stream-element-type] (delegar) e
  [`dispose*`][dispose*].
- Para `metered-output`: [`stream-write1`][stream-write1],
  [`stream-write`][stream-write], [`stream-flush`][stream-flush]
  (delegar) e [`dispose*`][dispose*].

Cada leitura ou escrita bem-sucedida deve somar a `bytes>>` o número
de bytes transferidos e incrementar `ops>>` em um. Uma leitura que
chega ao fim do ficheiro continua a contar como uma op, mas transfere
zero bytes. `dispose*` deve passar diretamente para o stream
subjacente.
