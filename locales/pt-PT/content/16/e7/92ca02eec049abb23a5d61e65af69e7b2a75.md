# Introdução

O módulo `gleam/order` da biblioteca padrão do Gleam contém o tipo `Order`, que serve para comparar valores.

A definição de `Order` é esta:

```gleam
pub type Order {
  Gt
  Eq
  Lt
}
```

O tipo tem três variantes, cada uma delas usada para representar a relação entre um valor e outro valor:

- `Gt` - o valor é _maior_ que o outro valor.
- `Eq` - o valor é _igual_ ao outro valor.
- `Lt` - o valor é _menor_ que o outro valor.

Se um tipo de dados pode ser comparado por grandeza, é comum o módulo definir uma função `compare` que devolve um valor `Order`. Por exemplo, `gleam/float` e `gleam/int` definem funções `compare` que operam sobre números de vírgula flutuante e inteiros, respetivamente.

```gleam
int.compare(1, 2)
// -> Lt

int.compare(2, 2)
// -> Eq

float.compare(1.0, 2.0)
// -> Lt
```

As funções de ordenação, como `list.sort`, costumam receber uma função que devolve um valor `Order`, o que permite a quem chama definir como a lista deve ser ordenada.

```gleam
list.sort([3, 7, 3, 1], by: int.compare)
// -> [1, 3, 3, 7]
```
