# Dicas

## 1. Determina se a lasanha está pronta

- Usa uma [condicional][mdn-if-else] para devolver um resultado com base numa condição.
- A melhor forma de resolver esta tarefa é verificar primeiro as duas condições específicas.
- Lembra-te de que os parâmetros em falta serão `undefined` e podes verificar se uma variável é `undefined` com o operador de igualdade estrita `===`.

## 2. Estima o tempo de preparação

- Usa um parâmetro por omissão para definir o tempo médio de preparação, caso não tenha sido indicado quando a função foi chamada.
- Volta a consultar os [arrays][concept-arrays] para descobrires como determinar o número de camadas (o comprimento do array de camadas).

## 3. Calcula as quantidades necessárias de massa e de molho

- Primeiro, cria duas variáveis para acompanhar a quantidade de massa e de molho.
  Define-as com `let` para poderes alterar o valor mais tarde no teu código.
  Atribui também um valor inicial adequado.
- Usa um [ciclo for][concept-for-loops] para percorrer as camadas.
- Se encontrares uma camada `'noodles'` ou `'sauce'` no teu ciclo, aumenta a quantidade guardada na variável correspondente.
- Usa um [objeto][concept-objects] para devolver os dois resultados.

## 4. Adiciona o ingrediente secreto

- Volta a consultar os [arrays][concept-arrays] para descobrires como obter um elemento de um array e como adicionar algo ao fim de um array.
- O índice do último elemento de um array `a` é `a.length - 1`.
- A função não deve ter uma instrução `return`.

## 5. Escala a receita

- Primeiro, calcula o fator que precisas de aplicar a todas as quantidades, com base nas porções pretendidas.
- Uma forma de garantir que os argumentos não são modificados é usar um novo objeto para guardar os resultados.
- Usa um [ciclo `for...in`][mdn-for-in] para percorrer todas as entradas da receita original e preencher o objeto em conformidade.
