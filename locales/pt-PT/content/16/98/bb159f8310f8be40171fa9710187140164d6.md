# Instruções

O teu amigo Johannes adora fazer hardware DIY (faz tu mesmo).
Acabou de construir uma máquina de sumos e está muito entusiasmado com isso.
O objetivo do Johannes é conseguir fazer sumo fresco todas as manhãs.

A máquina de sumos do Johannes tem imensas funcionalidades sofisticadas.
Como um sistema de medição incorporado, que te diz quanto sumo está no copo.
Também tem um temporizador, que te diz há quanto tempo a máquina está a funcionar.

O Johannes não é o melhor a programar, mas quer fazer um programa para controlar a máquina.
Por isso, pediu-te que o ajudasses.

## 1. Luz de debug

A máquina tem uma luz de debug, é um mecanismo simples: se a máquina tiver corrente, a luz de debug está ligada.
O programa só funciona se a luz de debug estiver ligada.

Este método deve ser um método de classe chamado `JuiceMaker`.

Define o método de classe `JuiceMaker.debug_light_on?`, que devolve `true`.

```crystal
JuiceMaker.debug_light_on?
#=> true
```

## 2. Inicializar a máquina

Quando a máquina é ligada, deve criar uma instância de uma classe chamada `JuiceMaker`.
A máquina deve ter um estado inicializado.
O estado inicializado deve conter as seguintes informações:

1. Se a máquina está a funcionar ou não. Isto deve ser sempre `false` quando a máquina é ligada.
2. A quantidade de sumo no copo; este será um sensor que mede a quantidade de sumo no copo.

Define o estado inicializado, que recebe a quantidade de sumo no copo como parâmetro, e constrói o estado inicializado.
O estado inicializado deve conter uma variável de instância `@running`, definida como `false`, e uma variável de instância `@fluid`, baseada num argumento dado quando a classe é inicializada.

```crystal
JuiceMaker.new(5)
#=> #<JuiceMaker:0x10f0b8 @running=false, @fluid=5>
```

## 3. Ligar a máquina

A máquina pode ser ligada e desligada.
Precisas de definir um método para ligar a máquina.
Quando a máquina é ligada, o estado de funcionamento deve ser definido como `true`.

Define o método `JuiceMaker#start`, que liga a máquina.

```crystal
juice_maker = JuiceMaker.new(5)
juice_maker.start

juice_maker
#=> #<JuiceMaker:0x10f0b8 @running=true, @fluid=5>
```

## 4. Estado da máquina

A máquina tem de te conseguir dizer qual é o seu estado.
Deve devolver `true` se a máquina estiver a funcionar e `false` se não estiver a funcionar.

Define o método `JuiceMaker#running?`, que devolve o estado da máquina.

```crystal
juice_maker = JuiceMaker.new(5)
juice_maker.start

juice_maker.running?
#=> true
```

## 5. Adicionar sumo

A máquina consegue adicionar sumo ao copo.
A máquina consegue dizer quanto sumo foi adicionado ao copo.
A máquina precisa de ajuda para saber quanto sumo há no copo depois de o sumo ser adicionado.

Define o método `JuiceMaker#add_fluid`, que recebe a quantidade de sumo adicionada como parâmetro e atualiza a quantidade de sumo no copo.

```crystal
juice_maker = JuiceMaker.new(5)
juice_maker.add_fluid(5)

juice_maker
#=> #<JuiceMaker:0x10f0b8 @running=false, @fluid=10>
```

## 6. Desligar a máquina

A máquina pode ser ligada e desligada.
Precisas de definir um método para desligar a máquina.
Este método só será chamado quando a máquina estiver a funcionar.
Quando a máquina é desligada, o estado de funcionamento deve ser definido como `false`.
A máquina também precisa de ajuda para determinar quanto sumo há no copo depois de ser desligada.
A máquina consome cinco unidades de sumo por minuto.

Define o método `JuiceMaker#stop`, que recebe o número de minutos que a máquina esteve a funcionar como parâmetro e devolve a quantidade de sumo no copo depois de a máquina ser desligada.

```crystal
juice_maker = JuiceMaker.new(5)

juice_maker.start
juice_maker
#=> <JuiceMaker:0x10f0b8 @running=true, @fluid=5>

juice_maker.stop(1)
#=> #<JuiceMaker:0x10f0b8 @running=false, @fluid=0>
```
