# Introdução

## Arrays

O JSON define um **array** (em português, um _vetor_) como:

> Um array é uma coleção ordenada de valores.
> Um array começa com `[`, o parêntese reto de abertura, e termina com `]`, o parêntese reto de fecho.
> Os valores são separados por `,`, uma vírgula.

Os arrays podem conter zero ou mais valores JSON de _qualquer tipo_.
Os elementos de um array não precisam de ser todos do mesmo tipo.

### Criar arrays

Usa parênteses retos para reunir elementos num array.

```jq
[1, 2, 3]
```

Os elementos de um _stream_ podem ser capturados num array envolvendo-o em parênteses retos.

```jq
range(5)     # => a stream of 5 numbers
[range(5)]   # => the array [0, 1, 2, 3, 4]
```

### Tamanho

A função `length` devolve o número de elementos de um array.

### Indexação e fatiamento

A indexação de arrays começa em zero.

Obtém um elemento de um array com uma expressão entre parênteses retos:
`.[2]` obtém o terceiro elemento.

Os índices negativos contam de trás para a frente a partir do fim do array:
`.[-1]` obtém o último elemento; `.[-2]` é o penúltimo.

Uma **fatia** é uma subsequência do array.
`.[10:15]` devolve 5 elementos a partir do índice 10; o índice final _não é incluído_.

Existem ainda algumas funções de conveniência:

- `first` obtém o primeiro elemento.
- `last` obtém o último elemento.
- `nth(n)` obtém o elemento no índice `n`.

### Iteração

O `jq` fornece muitas funções para as tarefas de iteração mais comuns:

- `map(expr)` devolve um novo array em que a `expr` é aplicada a cada elemento, um a um.

  ```jq
  [1, 2, 3] | map(. * 10)    # => [10, 20, 30]

  ```

- `select(expr)` é uma função que aplica a `expr` a um _único valor_;
  se o resultado da expressão for verdadeiro, o valor é devolvido;
  se o resultado for falso, _nada_ é devolvido: não `null`, mas mesmo nada.

  Para aplicar isso a um array, combina-a com `map`.

  ```jq
  [range(10)] | map(select(. % 2 == 0))    # => [0, 2, 4, 6, 8]
  ```

  Em alternativa, aplica `select` a um _stream_ e recolhe os resultados.

  ```jq
  [range(10) | select(. % 2 == 0)]    # => [0, 2, 4, 6, 8]
  ```

- `any(condition)` e `all(condition)` devolvem um valor Boolean que indica se algum dos elementos do array passa a condição, ou se todos passam.

  ```jq
  [1, 2, 3, 4] | any(. > 4)    # false
  [1, 2, 3, 4] | any(. >= 4)   # true

  [1, 2, 3, 4] | all(. >= 4)   # false
  [1, 2, 3, 4] | all(. <= 4)   # true
  ```
