# Sobre

O Haxe suporta reflexão de tipos e campos em tempo de execução. Para usar a reflexão corretamente, é necessário compreender que tipo de operações são suportadas e quais não são. Dada a natureza dinâmica da reflexão, isto nem sempre pode ser determinado em tempo de compilação.

A API de reflexão é composta por duas classes:

- `Reflect`: uma API leve que funciona melhor com estruturas anónimas, com suporte limitado para classes.
- `Type`: uma API mais robusta para trabalhar com classes e enums.

Os métodos disponíveis estão detalhados na API de [Reflect][reflect] e [Type][type].

No exemplo seguinte, usamos o alvo JavaScript:

```haxe
class Main {
  public static function main() {
    trace(Type.resolveClass("Main"));
  }
}

// This outputs
// class Test { static main() { console.log("Test.hx:3:",$hxClasses["Test"]); } }
```

[reflect]: https://api.haxe.org/Reflect.html
[type]: https://api.haxe.org/Type.html
