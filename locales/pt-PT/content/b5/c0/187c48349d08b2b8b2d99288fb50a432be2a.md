# Instruções

A tua tarefa é pegar numa lista de marcadores de um jogo e contar quantos golos cada jogador marcou.

`PlayerName` é um alias de tipo para `String`, para tornar o código mais fácil de ler e para distinguir este uso de `String` de outros usos de `String`.

## 1. Agregar os marcadores

Primeiro, implementa `updateGoalCountForPlayer` para inicializar ou incrementar a contagem de golos de um jogador.
Depois, implementa a função `aggregateScorers` para contar quantos golos cada jogador marcou, utilizando `updateGoalCountForPlayer`.
Esta função recebe uma `List PlayerName` (os nomes dos jogadores que marcaram os golos, que pode conter nomes de jogadores repetidos) e devolve um `Dict PlayerName Int` com todos os jogadores da lista e quantos golos marcaram.

```elm
aggregateScorers [ "Betty", "Cedd", "Betty" ]
--> Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ]
```

## 2. Remover os jogadores irrelevantes

Implementa a função `removeInsignificantPlayers` para filtrar os jogadores que marcaram menos golos do que o limite.

```elm
removeInsignificantPlayers 2 (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
--> Dict.fromList [ ( "Betty", 2 ) ]
```

## 3. Reiniciar a contagem de golos de um jogador

Implementa a função `resetPlayerGoalCount` para reiniciar a zero os golos marcados por um jogador.

```elm
resetPlayerGoalCount "Cedd" (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
--> Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 0 ) ]
```

## 4. Formatar a contagem de golos de um único jogador

Implementa a função `formatPlayer` para formatar a contagem de golos de um único jogador como uma string. Se o jogador não existir no dicionário, assume que tem uma contagem de golos de zero.

```elm
formatPlayer "Betty" (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
--> "Betty: 2"
```

## 5. Formatar a contagem de golos de todos os jogadores

Implementa a função `formatPlayers` para formatar a contagem de golos de todos os jogadores como uma string. Os jogadores devem ser ordenados por nome de jogador.

```elm
formatPlayers (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
--> "Betty: 2, Cedd: 1"
```

## 6. Combinar jogos

Implementa a função `combineGames`, contando o número total de golos que cada jogador marcou nos dois jogos.

```elm
combine Games
  (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
  (Dict.fromList [ ( "Betty", 2 ), ( "Mario", 3 ) ] )
--> Dict.fromList [ ( "Betty", 4 ), ( "Cedd", 1 ), ( "Mario", 3 ) ]
```
