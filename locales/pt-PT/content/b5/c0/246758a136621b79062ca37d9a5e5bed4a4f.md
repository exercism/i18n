# Introdução

Em Common Lisp, a lista de argumentos de uma função é conhecida como uma ['lambda list'][lambda-list].
Uma lambda list pode ter argumentos de tipos diferentes.
Esses tipos diferentes são designados com o recurso a ['lambda list keywords'][lambda-list-keyword], que começam todos por `&`.
Os tipos mais usados são os de argumentos optional, keyword e rest.
Todos os parâmetros de uma lambda list a seguir a um determinado lambda list keyword serão desse tipo.
Um lambda list keyword só pode ser usado uma vez numa lambda list.

As lambda lists também são usadas noutras construções que serão abordadas mais à frente, como a desestruturação e as macros.
