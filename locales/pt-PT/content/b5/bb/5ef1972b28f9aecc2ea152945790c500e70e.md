# Instruções

O projeto do carro de controlo remoto que iniciastе no exercício `classes` correu bem (parabéns!) e, devido a vários acordos de patrocínio recentes, há dinheiro no orçamento para melhorias.

Parte do orçamento está a ser usada para fornecer alguma telemetria.

Para manter os patrocinadores contentes, foi instalado no carro um painel que mostra os nomes dos patrocinadores enquanto este percorre a pista.

Vais notar que a introdução destas novas tecnologias sofisticadas reduziu drasticamente a duração da bateria do carro.

## 1. Mostrar os nomes dos patrocinadores no carro de controlo remoto

Implementa `SetSponsors()` para receber um ou mais nomes de patrocinadores e guardá-los no carro.

Repara que o argumento do método `SetSponsors()` é garantidamente não nulo.

Implementa `DisplaySponsor()` para mostrar o patrocinador selecionado. O primeiro patrocinador indicado tem `sponsorNum` 0, o segundo, 1, e assim por diante.

```csharp
var car = RemoteControlCar.Buy();
car.SetSponsors("Exercism", "Walker Industries", "Acme Co.");
var sp2 = car.DisplaySponsor(sponsorNum: 1);
// => "Walker Industries"
```

## 2. Obter os dados de telemetria do carro

Implementa o método `RemoteControlCar.GetTelemetryData()`.

`GetTelemetryData()` deve disponibilizar a percentagem de bateria e a distância percorrida em metros através de parâmetros `out`.

`GetTelemetryData()` deve devolver `false` se o argumento `serialNum` for menor do que o valor recebido anteriormente. (Há aqui alguma questão relacionada com o envolvimento de vários nós de telemetria.) Neste caso, `serialNum` será definido com o valor mais alto de `serialNum` anterior e tanto a percentagem de bateria como os metros percorridos serão definidos como `-1`. Quando a chamada tem sucesso, `serialNum` mantém-se inalterado.

```csharp
var car = RemoteControlCar.Buy();
car.Drive();
car.Drive();
int serialNum = 4;
car.GetTelemetryData(ref serialNum, out int batteryPercentage, out int distanceDrivenInMeters);
// => true, 4L, 80, 4

serialNum = 1;
car.GetTelemetryData(ref serialNum, out batteryPercentage, out distanceDrivenInMeters);
// => false, 4L, -1, -1
```

## 3. Adicionar funcionalidade para que o sistema de telemetria obtenha o consumo de bateria por metro

Implementa o método `TelemetryClient.GetBatteryUsagePerMeter()`.

Este método vai chamar `RemoteControlCar.GetTelemetryData()`. Se `GetTelemetryData()` devolver `false` ou o carro não tiver sido conduzido, esta rotina deve devolver "no data". Se `GetTelemetryData()` devolver `true`, deve ser devolvida uma mensagem com o seguinte formato "usage-per-meter=BATTERY-USAGE-PER-METER". Em que o cálculo é (100 - percentagem de bateria atual) a dividir pela distância percorrida em metros até ao momento.

```csharp
var car = RemoteControlCar.Buy();
car.Drive();
car.Drive();
var tc = new TelemetryClient(car);
int serialNum = 4;
tc.GetBatteryUsagePerMeter(serialNum);
// => "usage-per-meter=5"

serialNum = 1;
tc.GetBatteryUsagePerMeter(serialNum);
// => "no data"
```
