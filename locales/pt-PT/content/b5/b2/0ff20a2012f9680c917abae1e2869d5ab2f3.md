# Instruções

Implementa operações básicas sobre listas.

Em linguagens funcionais, operações sobre listas como `length`, `map` e
`reduce` são muito comuns. Implementa uma série de operações básicas sobre
listas, sem usares funções existentes.

O número exato e os nomes das operações a implementar dependem do track,
para evitar conflitos com nomes existentes, mas as operações gerais que vais
implementar incluem:

* `append` (*dadas duas listas, adiciona todos os elementos da segunda lista ao fim da primeira lista*);
* `concatenate` (*dada uma série de listas, combina todos os elementos de todas as listas numa única lista achatada*);
* `filter` (*dado um predicado e uma lista, devolve a lista de todos os elementos para os quais `predicate(item)` é True*);
* `length` (*dada uma lista, devolve o número total de elementos que contém*);
* `map` (*dada uma função e uma lista, devolve a lista dos resultados de aplicar `function(item)` a todos os elementos*);
* `foldl` (*dada uma função, uma lista e um acumulador inicial, dobra (reduz) cada elemento no acumulador a partir da esquerda usando `function(accumulator, item)`*);
* `foldr` (*dada uma função, uma lista e um acumulador inicial, dobra (reduz) cada elemento no acumulador a partir da direita usando `function(item, accumulator)`*);
* `reverse` (*dada uma lista, devolve uma lista com todos os elementos originais, mas por ordem inversa*);
