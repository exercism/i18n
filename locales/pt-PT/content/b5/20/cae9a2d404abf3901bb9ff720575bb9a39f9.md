# Introdução

Para que um objeto possa ser comparado com outro objeto, tem de implementar a interface `IComparable<T>`.
Esta interface tem um único método que é preciso implementar: `int CompareTo(T other)`.

O método `CompareTo` pode devolver um de três valores:

- Valor menor que zero: o objeto atual é menor que o outro objeto.
- Valor maior que zero: o objeto atual é maior que o outro objeto.
- Valor igual a zero: o objeto atual é igual ao outro objeto.
