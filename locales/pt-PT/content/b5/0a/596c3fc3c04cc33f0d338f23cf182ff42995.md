# Testes

Para executar os testes, executa o seguinte comando no diretório do exercício:

```shell
make
```

## Testes ignorados

Resolver um exercício significa fazer com que todos os seus testes passem.
Por predefinição, só um teste (o primeiro) é executado quando corres os testes.
Isto é intencional: permite-te concentrar-te apenas em fazer esse teste passar.
Assim que ele passar, podes ativar o teste seguinte removendo a linha `TEST_IGNORE();`.
Quando todos os testes estiverem ativados e a tua implementação os fizer passar, resolveste o exercício!
