# Dicas

## 1. Renomear uma coluna

- Lembra-te de que tens de modificar o conjunto de dados `trees`, que fica disponível se chamares `library(datasets)`.
- Podes (ou não) querer converter o `data.frame` inicial num `tibble`.
- Vê a Introdução para saberes como alterar o nome de uma coluna.

## 2. Adicionar as colunas girth e weight

- Vê a Introdução para saberes como adicionar colunas.
- As novas colunas podem ser calculadas a partir das colunas existentes.
- Não te esqueças de arredondar para a precisão pedida.

## 3. Cópia do conjunto de dados para o pomar

- Tens de mover colunas de sítio e ordenar linhas (vê a Introdução).

## 4. Cópia do conjunto de dados para o cliente

- Vais precisar de ficar apenas com um subconjunto de colunas.
- Na cópia só devem ficar as árvores com altura entre o mínimo e o máximo *e* com peso abaixo do máximo.
