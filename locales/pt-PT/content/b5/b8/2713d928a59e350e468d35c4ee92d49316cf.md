# Instruções

Dado um array aninhado de qualquer profundidade, devolve um array completamente achatado.

Repara que alguns percursos de linguagem podem incluir valores semelhantes a null no array de entrada, e a forma como estes valores são representados varia consoante o percurso.
Esses valores devem ser excluídos do array achatado.

Além disso, o valor de entrada pode ser de um tipo de dados diferente e conter tipos diferentes, consoante o percurso.

Consulta o conjunto de testes para mais detalhes.

## Exemplo

entrada: `[1, [2, 6, null], [[null, [4]], 5]]`

saída: `[1, 2, 6, 4, 5]`
