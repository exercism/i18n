# Anexo às instruções

## Formato dos parâmetros de entrada

Cada dominó é armazenado como um único byte, com a metade esquerda no
[nibble] alto e a metade direita no [nibble] baixo. Por exemplo,
as pedras `[2|1]`, `[2|3]` e `[1|3]` são representadas pelos bytes
`0x21 0x23 0x13`.

## Registos

| Registo | Utilização | Tipo    | Descrição                                      |
| -------- | --------- | ------- | ------------------------------------------------ |
| `$a0`    | parâmetro de entrada | endereço | array de bytes das pedras                       |
| `$a1`    | parâmetro de entrada | inteiro | número de pedras                                 |
| `$v0`    | valor de saída | boolean | as peças de dominó podem encadear-se (`0` = `false`, `1` = `true`) |
| `$t0-9`  | temporário | qualquer | utilizados para armazenamento temporário       |


[nibble]: https://en.wikipedia.org/wiki/Nibble
