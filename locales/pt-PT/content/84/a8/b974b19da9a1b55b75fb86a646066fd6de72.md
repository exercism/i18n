# Introdução

No Haxe, uma hierarquia de classes pode ser definida através de _herança_, o que permite que uma classe derivada (`Car`) herde o comportamento e os dados da sua classe base (`Vehicle`).

Na classe base, podes:

- Métodos que podem ser sobrescritos
- Métodos abstratos que têm de ser implementados pelas classes derivadas

```haxe
abstract class Vehicle {
  public function new() {}

  // Can be overridden
  public function drive() {
    // ...
  }

  // Must be implemented
  public abstract function getSpeed():Int;
}

class Car extends Vehicle {
  public function new() {
    super(); // Runs the parent class' constructor
  }

  public override function drive() {
    // ...
  }

  public function getSpeed():Int {
    // ...
  }
}
```

Se a classe base tiver um construtor, usamos `super()` para o chamar:

```haxe
abstract class Vehicle {
  var wheels:Int;

  public function new(wheels:Int) {
    this.wheels = wheels
  }
}

class Car extends Vehicle {
  var color:String;

  public function new(wheels:Int, color:String) {
    super(wheels);
    this.color = color;
  }
}

```
