# Dicas

## 1. Torna tudo magnífico

- O mapeamento é o processo correto para aplicar uma função a cada elemento de uma sequência.
- O `mapcar` é uma boa função para mapear uma função sobre uma lista.

## 2. Apenas o melhor

- A filtragem é o processo correto para remover um ou mais itens de uma sequência, dando origem a uma nova sequência.
- O `remove` pode remover de uma sequência os valores iguais a um item específico.
- O `remove-if` pode remover os valores para os quais uma função de predicado devolve um valor verdadeiro.
