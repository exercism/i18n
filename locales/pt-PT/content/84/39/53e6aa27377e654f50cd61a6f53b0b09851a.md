# Instruções

Neste exercício, vais ajudar namorados do liceu a declarar o seu amor nas redes sociais, gerando um coração em ASCII com as iniciais deles:

```
❤ J.  +  M. ❤
```

## 1. Limpa o nome

Implementa o método `HighSchoolSweetheart.clean_up_name`.
Deve receber um nome e remover todos os carateres `-`, substituindo-os por um espaço.
Deve também remover os espaços em branco no início e no fim do nome.

```crystal
HighSchoolSweetheart.clean_up_name("Jane-Ann")
# => "Jane Ann"
```

## 2. Obtém a primeira letra do nome

Implementa o método `HighSchoolSweetheart.first_letter`.
Deve receber um nome e devolver a sua primeira letra.
Certifica-te de que reutilizas o `HighSchoolSweetheart.clean_up_name` que definiste no passo anterior.

```crystal
HighSchoolSweetheart.first_letter("Jane")
# => "J"
```

## 3. Formata a primeira letra como uma inicial

Implementa o método `HighSchoolSweetheart.initial`.
Deve receber um nome e devolver a sua primeira letra, em maiúscula, seguida de um ponto.
Certifica-te de que reutilizas o `HighSchoolSweetheart.first_letter` que definiste no passo anterior.

```crystal
HighSchoolSweetheart.initial("Robert")
# => "R."
```

## 4. Coloca as iniciais dentro do coração

Implementa o método `HighSchoolSweetheart.pair`.
Deve receber dois nomes e devolver as iniciais com corações emoji à volta.
Certifica-te de que reutilizas o `HighSchoolSweetheart.initial` que definiste no passo anterior.

```crystal
HighSchoolSweetheart.pair("Blake Miller", "Riley Lewis")
# => "❤ B.  +  R. ❤"
```
