# não uses Date.parse

Usa [`Date#getTime`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Date/getTime),
uma vez que `Date.parse(%{parameter.name})` não é uma boa escolha.

O `Date.parse` deve ser chamado com uma `string` e, por isso, não foi
_pensado_ para ser usado desta forma. A razão pela qual funciona é que o `Date.parse`
começa por converter o valor de entrada numa `string` e volta depois a analisá-la para
obter uma data. Estas conversões extra são desnecessárias.
