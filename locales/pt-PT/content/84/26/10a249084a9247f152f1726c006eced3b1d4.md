# Testes

Podes usar o editor online no site do Exercism para resolver os exercícios.
Ou podes descarregar os exercícios para o teu computador, resolvê-los localmente e depois submetê-los ao Exercism.

Se quiseres trabalhar localmente, vais precisar do programa [`bats`][bats].
Consulta a página [Testar na track de Bash][test-bash] para saberes como o instalar.

O teu código vai ser testado no test runner de jq do Exercism, com [`jq` versão **1.8**][jq].

[bats]: https://github.com/bats-core/bats-core
[test-bash]: https://exercism.org/docs/tracks/bash/tests
[jq]: https://jqlang.org/manual/
