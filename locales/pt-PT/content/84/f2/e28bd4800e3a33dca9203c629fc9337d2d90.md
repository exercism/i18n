# Dicas

## Geral

- Cada tarefa compara um valor com uma lista fixa, e é para isso que o `case` serve.
- Todos os `case` precisam de um `else`, mesmo quando os ramos acima parecem completos.
  Sem ele, um valor que não corresponde a nada faz o programa parar.

## 1. A tarifa de uma zona

- Três ramos `when` e um `else`. O `else` cobre todos os números que não são uma zona.
- A zona 0 e uma zona desconhecida não custam nada, mas são casos diferentes;
  escrevê-los como ramos separados mostra a intenção.

## 2. Que tipo de bilhete?

- `'c'` e `'s'` dão a mesma resposta, por isso partilham um ramo:
  `when 'c', 's' then`.
- Aspas simples: o argumento é um `CHAR`, não um `STR`.

## 3. Que tipo de dia?

- Dois ramos, um com dois dias e outro com cinco.
- As strings comparam-se com `=` tal como os números, por isso funcionam num
  `case` sem alterações.

## 4. O limite diário

- Já tens uma rotina que transforma um dia num tipo de dia. Chama-a e depois
  faz `case` sobre a resposta.
- Fazê-lo assim significa que a lista de dias é escrita uma só vez. Repeti-la
  aqui é o erro que esta tarefa foi concebida para apanhar.
