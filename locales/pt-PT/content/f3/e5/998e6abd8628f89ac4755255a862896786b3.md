# Introdução

## Binários

O Elixir oferece uma sintaxe elegante para trabalhar com dados binários, como já vimos com a forma especial `<<>>` disponibilizada para trabalhar com [bitstrings][exercism-bitstrings].

O tipo binário é uma especialização do tipo bitstring. Enquanto os bitstrings podem ter qualquer comprimento (qualquer número de [bits][wiki-bit]), os binários são aqueles em que o número de bits é divisível por 8. Ou seja, quando trabalhamos com binários, pensamos muitas vezes em termos de [bytes][wiki-byte] (8 bits). Um byte pode representar números inteiros de `0` a `255`. É comum trabalhar com valores de byte em [hexadecimal][wiki-hexadecimal], `0x00 - 0xFF`.

Os literais binários definem-se com a forma especial de bitstring `<<>>`. Ao definir um literal binário, podemos usar literais inteiros e de string. Valores inteiros superiores a 255 sofrem overflow e só os últimos 8 bits do inteiro são usados. Por predefinição, o modificador `::binary` é aplicado ao valor. Podemos concatenar binários com o operador `<>/2`.

```elixir
<<255>> == <<0xFF>>
# Overflowing bits are truncated
<<256>> == <<0>>
<<2, 4, 6, 8, 10, 12, 14, 16>> == <<0x02, 0x04, 0x06, 0x08, 0x0A, 0x0C, 0x0E, 0x10>>
```

Um _null-byte_ é outro nome para `<<0>>`.

### Pattern matching em dados binários

O [pattern matching][exercism-pattern-matching] é até estendido aos binários, e podemos fazer pattern matching numa porção de dados binários, tal como faríamos com uma lista.

```elixir
# Ignore the first 8 bytes, match and bind the remaining to `body`
<<_::binary-size(8), body::binary>>
```

Tal como acontece com outros tipos de pattern matching, podemos usar isto em assinaturas de funções para corresponder ao selecionar entre várias cláusulas de função.
