# Dicas

## 1. Cria uma lista vazia

Criar uma lista vazia é como criar uma lista com elementos. Podes fazê-lo com `list` ou com `quote` sobre uma lista vazia.

## 2. Adiciona uma nova linguagem à lista

O Clojure tem uma função de base que [acrescenta um elemento ao início de uma lista](https://clojuredocs.org/clojure.core/cons).

## 3. Verifica a última linguagem adicionada

Tal como outras Lisps, o Clojure tem uma função que [devolve o primeiro elemento de uma lista](https://clojuredocs.org/clojure.core/first).

## 4. Remove a primeira linguagem da lista

Da mesma forma, o Clojure também tem uma função para [devolver uma lista sem o primeiro elemento](https://clojuredocs.org/clojure.core/rest).

## 5. Conta as linguagens da lista

O [número de elementos](https://clojuredocs.org/clojure.core/count) de uma lista pode ser devolvido facilmente com uma função de base do Clojure.

## 6. Junta tudo

Lembra-te de que as chamadas de funções podem ser aninhadas.
