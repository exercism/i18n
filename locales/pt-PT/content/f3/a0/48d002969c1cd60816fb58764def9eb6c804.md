# Instruções

O Karl quer acompanhar uma lista de linguagens para aprender no site do Exercism.
O Karl precisa de conseguir adicionar novas linguagens, remover as antigas e verificar se certas linguagens estão na lista.
Seria muito entusiasmante se o Karl quisesse aprender Java ou Kotlin!

## 1. Define uma função para verificar se a lista de linguagens está vazia

O Karl precisa de saber se a sua lista de linguagens alguma vez fica vazia, para poder ir procurar mais para aprender!
Define um método chamado `isEmpty` que devolve `true` se não houver linguagens na lista.

```java
if (languageList.isEmpty()) {
    findMoreLanguagesToLearn();
}
```

## 2. Define uma função para adicionar uma linguagem à lista

O Karl está ansioso por aprender Kotlin e Python!
Ajuda o Karl a começar, definindo um método chamado `addLanguage` que recebe a linguagem que ele quer aprender e adiciona-a à lista.

```java
languageList.addLanguage("Kotlin");
languageList.addLanguage("Python");
```

## 3. Define uma função para remover uma linguagem da lista

O Karl decidiu que não quer aprender Scala neste momento.
Ajuda o Karl a removê-la da lista, definindo um método chamado `removeLanguage` que recebe a linguagem que ele está a remover e remove-a da lista.

```java
languageList.removeLanguage("Scala");
```

## 4. Define uma função para devolver o primeiro elemento da lista

O Karl quer lembrar-se da primeira linguagem que adicionou à lista (que ainda está na lista).
Define um método chamado `firstLanguage` que devolve a primeira linguagem da lista.

```java
String kotlin = languageList.firstLanguage(); // "Kotlin"
```

## 5. Define uma função para devolver quantas linguagens estão na lista

O Karl precisa de saber quantas linguagens está a tentar aprender.
Ajuda o Karl a encontrar a resposta, definindo um método chamado `count` que devolve o número de linguagens na lista.

```java
int two = languageList.count(); // 2
```

## 6. Define uma função para determinar se uma linguagem está na lista

O Karl está a tentar lembrar-se se queria aprender Python ou Ruby.
Define um método chamado `containsLanguage` que recebe a linguagem sobre a qual está a perguntar, para que o Karl possa descobrir!

```java
boolean learningPython = languageList.containsLanguage("Python"); // true
boolean learningRuby = languageList.containsLanguage("Ruby"); // false
```

## 7. Define uma função para determinar se a lista é entusiasmante

Se o Karl quiser aprender Java ou Kotlin, isso é muito entusiasmante!
Define um método chamado `isExciting` que devolve true se o Karl quiser aprender Java ou Kotlin.

```java
javaLanguageList.isExciting() // true
neitherKotlinNorJavaLanguageList.isExciting() // false
```
