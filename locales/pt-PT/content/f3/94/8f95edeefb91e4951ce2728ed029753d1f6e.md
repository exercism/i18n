# Introdução

## Listas

Dado que o nome da linguagem que estamos a usar, Lisp, significa _LIST Processing_, poderias pensar que a linguagem tem recursos para lidar com listas de itens, e tens razão!

Apesar de Common Lisp ter outras estruturas de dados além das listas, as listas continuam a ser muito usadas.

Uma lista em Common Lisp é uma sequência de itens. Também é chamada de **cons** (sobretudo por razões históricas).
Os próprios itens não têm de ser do mesmo tipo.
Por exemplo, podes ter uma lista de `1`, `two`, `"III"`.

### Criar listas

Podes simplesmente escrever uma lista citada assim: `'(1 two "III")`, o que faz com que uma lista seja criada e avaliada (é avaliada como `(1 two "III")`).

Há também duas funções principais usadas para criar listas: `list` e `cons`.

`list` recebe zero ou mais argumentos e é avaliada como uma lista criada com esses valores:

```lisp
(list 1 'two "III") ; => (1 two "III")
```

`cons` recebe dois itens e cria uma lista em que o primeiro item é o seu `car` (a cabeça da lista) e o segundo item é o seu `cdr` (o resto da lista):

```lisp
(cons 1 2)            ; => (1 . 2) ;; (a list without `nil` as its `cdr` is printed in this way)
(cons 1 nil)          ; => (1)
(cons 1 (cons 2 nil)) ; => (1 2)
```

As funções `car` e `cdr` podem ser usadas para aceder ao `car` e ao `cdr` de uma lista.

(`first` e `rest` são sinónimos de `car` e `cdr` e funcionam exatamente da mesma forma.)

### Comprimento e acesso aleatório

O comprimento de uma lista pode ser determinado com `length`.
Uma lista vazia tem comprimento zero.

Podes aceder a um item arbitrário com `nth` (repara que as listas têm índices a começar em zero).

Pedir um índice maior do que o comprimento da lista _não_ é um erro.
Em vez disso, é avaliado como `nil`:

```lisp
(nth 23 '(short list)) ; => nil
```

Há também vários métodos auxiliares para aceder aos primeiros itens de uma lista: `first`, `second`, `third`, e por aí fora até `tenth`. Porreiro, não?

### Combinar listas

Duas ou mais listas podem ser combinadas com `append`:

```lisp
(append '(a b c) '(1 2 3)) ; => (A B C 1 2 3)
(append '(a b c) '())     ; => (A B C)
```

Cada argumento dado a `append` tem de ser uma lista.
