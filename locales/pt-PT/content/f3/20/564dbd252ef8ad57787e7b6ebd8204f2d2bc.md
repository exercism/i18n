# Instruções

Neste exercício vais processar linhas de registo.

Cada linha de registo é uma string com o seguinte formato: "[<LEVEL>]: <MESSAGE>*".

## 1. Obtém a mensagem de uma linha de registo

Implementa a função `LogLevels.message()` para devolver a mensagem de uma linha de registo, sem os espaços em branco no início e no fim.

## 2. Obtém o nível de registo de uma linha de registo

Implementa a função `LogLevels.logLevel()` para devolver o nível de registo de uma linha de registo em minúsculas.

## 3. Reformata uma linha de registo

Implementa o método `LogLevels.reformat()` que recebe uma linha de registo e uma string de localização e a reformata numa mensagem com duas linhas.
A primeira linha tem o formato `<LEVEL>@<LOCATIOON>:`, em que:

* `<LEVEL>` é o nível de registo em minúsculas (como em 2. Obtém o nível de registo de uma linha de registo).
* `<LOCATION>` é a localização indicada como segundo parâmetro.

A segunda linha contém exatamente dois espaços, seguidos da mensagem de registo (como em 1. Obtém a mensagem de uma linha de registo):

```kotlin
reformat("[TRACE]: Start of function", 2, 8)
// => "trace@208:
  Start of function"
```
