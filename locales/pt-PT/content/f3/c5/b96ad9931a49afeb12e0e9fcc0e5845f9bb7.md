# Instruções

Neste exercício, foi-te pedido que escrevas o software de um dispositivo de encriptação que funciona através de transformações sobre dados. Precisas de uma forma flexível de criar funções complicadas, combinando funções mais simples entre si.

Em cada tarefa, devolve uma função anónima que possa ser invocada a partir do âmbito de chamada.

## 1. Cria um somador

Implementa `secret_add`. Esta deve devolver uma função que recebe um argumento e lhe soma o argumento passado a `secret_add`.

```gleam
let adder = secret_add(2)
adder(2)
// -> 4
```

## 2. Cria um subtrator

Implementa `secret_subtract`. Esta deve devolver uma função que recebe um argumento e subtrai-lhe o segredo passado a `secret_subtract`.

```gleam
let subtractor = secret_subtract(2)
subtractor(3)
// -> 1
```

## 3. Cria um multiplicador

Implementa `secret_multiply`. Esta deve devolver uma função que recebe um argumento e o multiplica pelo segredo passado a `secret_multiply`.

```gleam
let multiplier = secret_multiply(7)
multiplier(3)
// -> 21
```

## 4. Cria um divisor

Implementa `secret_divide`. Esta deve devolver uma função que recebe um argumento e o divide pelo segredo passado a `secret_divide`.

```gleam
let divider = secret_divide(3)
divider(32)
// -> 10
```

## 5. Cria um combinador de funções

Implementa `secret_combine`. Esta deve devolver uma função que recebe um argumento e lhe aplica, por ordem, as duas funções passadas a `secret_combine`.

```gleam
let multiply = secret_multiply(7)
let divide = secret_divide(3)
let combined = secret_combine(multiply, divide)

combined(6)
// -> 14
```
