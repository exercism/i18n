# Instruções

Neste exercício, vais construir o tratamento de erros de uma calculadora simples de números inteiros.
A calculadora deve suportar operações de adição, multiplicação e divisão, devolvendo o resultado como uma string formatada.
Vais também implementar o tratamento de erros para lidar com operações ilegais e com a divisão por zero.

O objetivo é teres uma calculadora funcional que devolve uma string no seguinte formato:

```rust
SimpleCalculator::calculate(16, 51, "+"); // => returns "16 + 51 = 67"

SimpleCalculator::calculate(32, 6, "*"); // => returns "32 * 6 = 192"

SimpleCalculator::calculate(512, 4, "/"); // => returns "512 / 4 = 128"
```

## 1. Implementa as operações da calculadora

A função principal desta tarefa é `SimpleCalculator::calculate`, que recebe três argumentos: dois números inteiros e um `ByteArray` que representa a operação.
Implementa as seguintes operações:

- **Adição** com o símbolo `+`
- **Multiplicação** com o símbolo `*`
- **Divisão** com o símbolo `/`

## 2. Trata as operações ilegais

Se o símbolo da operação for outra coisa que não `+`, `*` ou `/`, a calculadora deve entrar em pânico ou devolver um erro:

- Se a operação for uma string vazia, entra em pânico com uma mensagem de erro de `ByteArray` `"Operation cannot be an empty string"`.
- Para qualquer outra operação inválida, devolve `Result::Err("Operation is out of range")`.

```rust
SimpleCalculator::calculate(100, 10, "-"); // => returns Result::Err("Operation is out of range")

SimpleCalculator::calculate(8, 2, ""); // => panics with "Operation cannot be an empty string"
```

## 3. Trata os erros de divisão por zero

Quando tentas dividir por `0`, a calculadora deve entrar em pânico com uma mensagem de erro a indicar que a divisão por zero não é permitida.
O resultado devolvido deve ser um valor `felt252` de `'Division by zero is not allowed'`.

```rust
SimpleCalculator::calculate(512, 0, "/"); // => panics with 'Division by zero is not allowed'
```
