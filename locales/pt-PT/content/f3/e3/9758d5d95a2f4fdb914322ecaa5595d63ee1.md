# Palavras-chave estáticas de classe

Uma classe é uma unidade de organização de código em PHP, que representa muitas vezes uma instância de uma coisa/serviço/procedimento.
Com as palavras-chave `static` e `self`, as propriedades e os métodos podem existir em referência à classe, para todas as instâncias (ou para nenhuma).

```php
<?php

class Book
{
    static $genre = 'Adventure';

    static function getGenre()
    {
        return self::$genre;
    }
}

// Usage
$genre = Book::$genre;
$genre = Book::getGenre();
```

## Limitação

Os métodos estáticos de uma classe só podem chamar outras propriedades estáticas ou outros métodos estáticos da própria classe.
