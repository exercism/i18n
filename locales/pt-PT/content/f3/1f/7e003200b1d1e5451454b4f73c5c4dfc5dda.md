# Apêndice às instruções

## Dica de desempenho

Todas as entradas e saídas estão em ASCII.
As `String`s e as `&str` do Rust são utf8, por isso, embora se possa esperar que `"Hello".chars()` seja simples, na verdade tem de verificar cada caráter para ver se tem 1, 2, 3 ou 4 `u8`s de comprimento.
Se soubermos que uma `&str` é ASCII, podemos chamar `.as_bytes()` e referir os dados subjacentes como um `&[u8]` (uma fatia de bytes).
Iterar sobre uma fatia de bytes ASCII é muito mais rápido, porque não há pontos de código envolvidos. Cada byte ASCII tem um `u8` de comprimento.
