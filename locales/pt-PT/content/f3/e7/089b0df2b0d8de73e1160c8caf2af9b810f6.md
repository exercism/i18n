# Instruções

O teu amigo acabou de te enviar uma mensagem com um segredo importante.
Para que não fosse fácil para os outros lê-la, a mensagem foi cifrada através de uma série de manipulações de bits.
Vais precisar de escrever os métodos que ajudam a desencriptar a mensagem.

## 1. Desloca os bits de volta

O primeiro passo para desencriptar a mensagem é desfazer o deslocamento do processo de cifra, deslocando os bits de volta para a direita.
Haverá passos seguintes no processo de desencriptação que assumem que são inseridos 0s do lado esquerdo.

Implementa o método `Secrets.shiftBack`, que recebe um valor e o número de posições a deslocar e efetua o deslocamento.

```java
Secrets.shiftBack(0b1001, 2);
# => 0b0010
```

## 2. Coloca alguns bits a 1

De seguida, há alguns bits que precisam de ser colocados a 1.

Implementa o método `Secrets.setBits`, que recebe um valor e uma máscara e devolve o resultado de colocar a 1 os bits do valor.
Um bit do valor deve ser colocado a 1 quando o bit correspondente na máscara também for 1.
Todos os outros bits devem permanecer inalterados.

```java
Secrets.setBits(0b0110, 0b0101);
# => 0b0111
```

## 3. Inverte bits específicos

Alguns bits são invertidos durante a cifra.
Será preciso invertê-los de volta para desencriptar a mensagem.

Implementa o método `Secrets.flipBits`, que recebe um valor e a máscara.
A máscara indica quais os bits do valor a inverter.
Se o bit na máscara for 1, o bit é invertido no valor.
Todos os outros bits permanecem inalterados.

```java
Secrets.flipBits(0b1100, 0b0101);
# => 0b1001
```

## 4. Limpa bits específicos

Por último, também há certos bits que desencriptam sempre para 0.

Implementa o método `Secrets.clearBits`, que recebe um valor e uma máscara.
Os bits em `value` devem ser colocados a 0 onde o bit na máscara for 1.
Todos os outros bits devem permanecer inalterados.

```java
Secrets.clearBits(0b0110, 0b0101);
# => 0b0010
```
