# Aprender

## Aprender C a partir do zero

Em geral, o Exercism parte do princípio de que já conheces a sintaxe e os mecanismos de uma linguagem num determinado percurso.
No entanto, conhecer a sintaxe de uma linguagem é apenas o primeiro passo para te tornares especialista nessa linguagem.
O Exercism permite-te praticar a resolução de problemas e trocar ideias com outros programadores que resolveram o mesmo problema.
É dessa troca de ideias que ganhamos experiência e intuição para nos tornarmos melhores programadores.

Se estás a começar agora com a linguagem C, deves primeiro dedicar algum tempo a aprender o básico da linguagem.
Aqui ficam alguns recursos que te podem ajudar a dar os primeiros passos:

* [Learn C][]
* [CS50x][]

O [CodeChef][] é uma interface web simples, em forma de formulário, para um compilador de C, que te permite experimentar pequenos programas.
Por vezes, é mais fácil fazer uma experiência rápida desta forma do que construir algo localmente num ambiente de desenvolvimento integrado.

## Desenvolvimento orientado a testes em C

O Exercism parte do princípio de que já conheces o conceito de desenvolvimento orientado a testes.
Cada exercício vem com uma série de testes já escritos para ti.
Avanças no exercício teste a teste, escrevendo a implementação de forma incremental até satisfazer os testes.

Se és novo no desenvolvimento orientado a testes, recomenda-se vivamente que comeces por uma [visão geral rápida de algumas frameworks de testes para C][test-frameworks] ou que leias o livro [Test-Driven Development for Embedded C][tdd], de James Grenning.
Estes recursos abordam o [Unity][] e o [CppUTest][]; este percurso usa o Unity.
