# Introdução

Os tuplos são uma forma leve de agrupar um conjunto fixo de tipos de dados arbitrários.
Um tuplo não tem um nome específico; dar um nome a uma estrutura de dados transforma-o numa `struct`.
Os campos de um tuplo não têm nomes; acede-se a eles por desestruturação ou por posição.

## Criação

Os tuplos são sempre criados com uma expressão de tuplo:

```rust
// pointless but legal
let unit = ();
// single element
let single_element = ("note the comma",);
// two element
let two_element = (123, "elements can be of differing types");
```

Os tuplos podem ter um número arbitrário de elementos.

## Acesso por desestruturação

É possível aceder aos elementos de um tuplo por desestruturação.
Isto significa apenas atribuir nomes de variáveis aos elementos individuais do tuplo, o que o consome.

```rust
let (elem1, _elem2) = two_element;
assert_eq!(elem1, 123);
```
