# Testes

Cada exercício contém um ficheiro de testes.
Executa os testes com o programa `bats`.
```bash
bats test-hello-world.bats
```

É preciso instalar o `bats`.
Consulta a página [Testing on the Bash track][bash] para saberes como instalar o `bats` no teu sistema.

### O bats está implementado em bash

O ficheiro bats é um script bash, com algumas funções especiais reconhecidas pelo comando `bats`.
Vais encontrar testes com este aspeto:
```sh
gawk -f some-exercise.awk <<< "some,input,here"
```
Essa sintaxe `<<<` é uma [Here String][here-string] do bash.
Envia a string do lado direito para a entrada padrão do programa do lado esquerdo.
É ([aproximadamente][so]) o mesmo que
```sh
echo "some,input,here" | gawk -f some-exercise.awk
```

## Ajuda para as funções assert

Os testes usam funções da biblioteca [bats-assert][bats-assert].
Aí encontras ajuda para as várias funções `assert*`.

## Testes ignorados

Resolver um exercício significa fazer passar todos os testes.
Por predefinição, só um teste (o primeiro) é executado quando corres os testes.
Isto é intencional, porque assim podes concentrar-te apenas em fazer passar esse teste.
Assim que passar, podes ativar o teste seguinte comentando ou removendo as

    [[ $BATS_RUN_SKIPPED == true ]] || skip

anotações que estão antes dos outros testes.

## Ultrapassar os skips

Para executar todos os testes, incluindo os que têm anotações `skip`, podes correr:
```bash
BATS_RUN_SKIPPED=true bats test-some-exercise.bats
```

Pode ser prático usar uma função wrapper para escrever menos: em `bash` podes fazer:
```bash
bats() {
    BATS_RUN_SKIPPED=true command bats *.bats
}
```
Depois, basta correr os testes com:
```bash
bats
```

## Saída de depuração

```exercism/caution
Isto funciona localmente com o `bats`, mas **não** no editor online do Exercism.
```

Quando corres os testes, o `bats` captura tanto o stdout como o stderr para os comparar com a saída esperada.
Se imprimires mensagens de depuração para o stdout ou o stderr, estas são incluídas na saída capturada e podem fazer com que o teste falhe.

Para imprimir informações de depuração sem afetar os resultados dos testes, o `bats` disponibiliza o descritor de ficheiro **3** para esse efeito.
Tudo o que for impresso no ficheiro `/dev/fd/3` é mostrado durante a execução dos testes, mas não é incluído na saída capturada usada para as asserções.

Exemplo:

```awk
BEGIN {
    # This debug message will not interfere with test output comparison
    print "a debug message" > "/dev/fd/3"

    # Normal program output (this is what your tests will see and compare)
    print "Hello, World!"
}
```

Exemplo de execução:

```none
$ bats test-hello-world.bats
test-hello-world.bats
 ✓ Say Hi!
a debug message

1 test, 0 failures
```

Isto permite-te ver saída de depuração útil sem afetar os testes.

Esconder os detalhes numa função pode melhorar a legibilidade se a usares em vários pontos do teu código:

```awk
BEGIN {
    debug("starting ...")
}

# do stuff here ...

END {
    debug("... finished")
}

function debug(msg) {print msg > "/dev/fd/3"}
```
