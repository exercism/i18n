# Sobre

`Enum` é um módulo muito útil que fornece um conjunto de algoritmos para trabalhar com enumeráveis. Oferece:

- ordenação ([`sort/2`][enum-sort/2], [`sort_by/2`][enum-sort_by/2]),
- filtragem ([`filter/2`][enum-filter/2]),
- agrupamento ([`group_by/3`][enum-group_by/3]),
- contagem ([`count/2`][enum-count/2])
- pesquisa ([`find/3`][enum-find/3]),
- encontrar valores mínimos/máximos ([`min/3`][enum-min/3], [`max/3`][enum-max/3]),
- redução ([`reduce/3`][enum-reduce/3], [`reduce_while/3`][enum-reduce_while/3]),

E muito mais! Consulta a documentação do [módulo `Enum`][enum-functions] para veres a lista completa.

## Enumerável

Em geral, um _enumerável_ é qualquer dado sobre o qual se possa iterar, ou seja, uma coleção. Em Elixir, um enumerável é qualquer tipo de dados que implemente o [protocolo][exercism-protocols] `Enumerable`. São eles:

- [`List`][list]
- [`Map`][map]
- [`Range`][range]
- [`Stream`][stream]
- [`MapSet`][mapset]
- [`Function`][function]
- [`Date.Range`][date-range]
- [`IO.Stream`][io-stream]
- [`File.Stream`][file-stream]

Não te preocupes se ainda não conheces todos.

Qualquer pessoa pode implementar o protocolo `Enumerable` para a sua própria estrutura de dados personalizada.

## Reduce

`Enum.reduce/2` permite-te _reduzir_ todo o enumerável a um único valor. Para tal, usa-se uma variável especial chamada _acumulador_. O acumulador transporta o estado intermédio da redução entre iterações. Isto faz dele uma das funções mais poderosas para enumeráveis. Muitas outras funções especializadas podem ser substituídas pela `reduce`, que é mais geral. Por exemplo...

Encontrar o valor máximo:

```elixir
Enum.max([4, 20, 31, 9, 2])
# => 31

Enum.reduce([4, 20, 31, 9, 2], nil, fn x, acc ->
  cond do
    acc == nil -> x
    x > acc -> x
    x <= acc -> acc
  end
end)

# => 31
```

E até fazer o mapeamento (mas obriga a inverter o resultado depois):

```elixir
Enum.map([1, 2, 3, 4, 5], fn x -> x + 10 end)
# => [11, 12, 13, 14, 15]

Enum.reduce([1, 2, 3, 4, 5], [], fn x, acc -> [x + 10 | acc] end)
# => [15, 14, 13, 12, 11]
```

## Mapeamento de mapas

- Com [`Map.new/2`][map-new]:
  ```elixir
  %{a: 1, b: 2}
  |> Map.new(fn {key, value} -> {key, value * 10} end)
  ```

- Com [`Enum.into/3`][enum-into]:
  ```elixir
  %{a: 1, b: 2}
  |> Enum.into(%{}, fn {key, value} -> {key, value * 10} end)
  ```

- Com [`Enum.map/2`][enum-map]:
  ```elixir
  %{a: 1, b: 2}
  |> Enum.map(fn {key, value} -> {key, value * 10} end)
  |> Enum.into(%{})
  ```
