# Apêndice às instruções

## Instruções específicas do percurso

Vais ter de implementar o teu próprio operador de igualdade para o objeto `ComplexNumber`.
Isto coloca-te o desafio de comparar dois números de vírgula flutuante.
Pode ser útil usar o método `isApproximatelyEqual(to:absoluteTolerance:)`, que podes encontrar na biblioteca [Numerics][swift-numberics].
Por questões de desempenho, só terás acesso à parte `RealModule`.
Para a importar, basta escreveres `import RealModule` no topo do ficheiro.
Uma tolerância de `0.00001` deve ser suficiente para passar nos testes.
A biblioteca já está importada no projeto, por isso só tens de a importar no teu ficheiro.

Também podes implementar o teu próprio método para comparar os dois números complexos.

[swift-numberics]: https://github.com/apple/swift-numerics
