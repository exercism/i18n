# Introdução

Por vezes, uma parte do estado tem de ser partilhada entre várias palavras, sem a teres de passar pelos seus efeitos de pilha de cada vez. As *variáveis dinâmicas* do Factor, declaradas com `SYMBOL:`, dão a cada palavra acesso a um valor guardado num namespace.

```factor
USING: namespaces ;

SYMBOL: counter

0 counter set-global
counter [ 1 + ] change-global
counter get-global .       ! => 1
```

`set-global` e `get-global` operam sobre o namespace global.
`set` e `get` operam sobre o âmbito dinâmico *atual* e são normalmente usados dentro de um bloco `with-variable` quando queres uma ligação com âmbito, em vez de uma para todo o processo.

`SYMBOLS: a b c ;` declara vários símbolos de uma só vez.
