# Testes

Para correres os testes, segue estes passos:

- Vai para o diretório do problema (por exemplo, `~/Exercism/hello-world`).
- Inicia uma sessão `jconsole` (por exemplo, escrevendo `jconsole` ou `ijconsole`) num terminal.
- Carrega o teu ficheiro de solução (por exemplo, `load 'hello-world.ijs'`)
- Carrega a framework de testes unitários escrevendo `load  'general/unittest'`
- Testa a tua solução escrevendo `unittest 'test.ijs'`.
<br></br>
- Em alternativa, é possível correr os testes numa única linha, assim: `jconsole -js "load 'hello-world.ijs'" "echo unittest 'test.ijs'" "exit 0"`.

## Testes ignorados

Ao início, apenas o teste inicial estará ativo.
Esta abordagem incentiva-te a resolver o exercício passo a passo.
Cada teste inclui um noun acima da sua definição, com um nome terminado em _'\_ignore'_.
Para correr o teste, muda o seu valor para 0.

### Exemplo:

```
    leap_test_02_ignore=: 1 NB. Change this value to 0 to run this test
    test_leap_test_02  =: monad define
    ...                     NB. test definitions
    )
```
