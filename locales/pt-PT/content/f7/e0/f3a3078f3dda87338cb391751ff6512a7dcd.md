# Instruções

És assistente de ensino e estás a corrigir exames de alunos.
Manter o registo dos resultados manualmente está a tornar-se aborrecido e propenso a erros.
Decides tornar as coisas um pouco mais interessantes criando algumas funções para contar e calcular os resultados da turma.

## 1. Arredondar as notas

Embora possas dar "pontuação parcial" às questões do exame, as notas finais do exame têm de ser `int`s.
Por isso, antes de fazeres mais alguma coisa com as notas da turma, tens de percorrer as notas e converter as notas de `float` em `int`s. Felizmente para ti, o Python tem a função integrada [`round()`][round] que podes usar.

Cria a função `round_scores(student_scores)`, que recebe uma `list` de `student_scores`.
Esta função deve _consumir_ a `list` de entrada e `return` uma nova lista com todas as notas convertidas em `int`s.
A ordem das notas na `list` resultante não é importante.

```python
>>> student_scores = [90.33, 40.5, 55.44, 70.05, 30.55, 25.45, 80.45, 95.3, 38.7, 40.3]
>>> round_scores(student_scores)
...
[40, 39, 95, 80, 25, 31, 70, 55, 40, 90]
```

## 2. Alunos sem nota positiva

Enquanto corrigias o exame, reparaste que alguns alunos não estavam a ter um desempenho tão bom como esperavas.
Mas distraíste-te e esqueceste-te de anotar exatamente _quantos_ alunos.

Cria a função `count_failed_students(student_scores)`, que recebe uma `list` de `student_scores`.
Esta função deve contar o número de alunos que não têm nota positiva e devolver essa contagem como um número inteiro.
Para ter nota positiva no exame, um aluno precisa de uma nota superior a **40**.

```python
>>> count_failed_students(student_scores=[90,40,55,70,30,25,80,95,38,40])
5
```

## 3. Os "melhores"

O professor a quem estás a dar assistência quer encontrar o grupo de alunos que teve o melhor desempenho neste exame.
O que conta como "melhor" varia, por isso tens de encontrar as notas que sejam **maiores ou iguais** ao limiar atual.

Cria a função `above_threshold(student_scores, threshold)`, que recebe `student_scores` (uma `list` de notas) e `threshold` (o limiar da "nota mais alta") como parâmetros.
Esta função deve devolver uma `list` com todas as notas que sejam `>=` a `threshold`.

```python
>>> above_threshold(student_scores=[90,40,55,70,30,68,70,75,83,96], threshold=75)
[90,75,83,96]
```

## 4. Calcular as notas com letras

O professor a quem estás a dar assistência gosta de atribuir notas com letras, além de notas numéricas.
Como é raro os alunos tirarem 100 num exame, os limiares inferiores das "notas com letras" são calculados com base na nota mais alta obtida e aumentam de forma uniforme entre a nota mais alta e o limiar de reprovação de **<= 40**.

Cria a função `letter_grades(highest)`, que recebe a nota "mais alta" do exame como argumento e devolve uma `list` de limiares inferiores de notas para cada intervalo de notas "ao estilo americano": `["D", "C", "B", "A"]`.


```python
"""Where the highest score is 100, and failing is <= 40.
       "F" <= 40
 41 <= "D" <= 55
 56 <= "C" <= 70
 71 <= "B" <= 85
 86 <= "A" <= 100
"""

>>> letter_grades(highest=100)
[41, 56, 71, 86]


"""Where the highest score is 88, and failing is <= 40.
       "F" <= 40
 41 <= "D" <= 52
 53 <= "C" <= 64
 65 <= "B" <= 76
 77 <= "A" <= 88
"""

>>> letter_grades(highest=88)
[41, 53, 65, 77]
```

## 5. Associar nomes a notas

Tens uma lista de notas de exame por ordem decrescente e outra lista com os nomes dos alunos, também ordenada por ordem decrescente das respetivas notas.
Gostarias de associar cada nome de aluno à sua nota e imprimir a classificação geral da turma.

Cria a função `student_ranking(student_scores, student_names)`, com os parâmetros `student_scores` e `student_names`.
Associa cada nome de aluno da `list` student_names à respetiva nota da `list` student_scores.
Podes assumir que cada `list` de argumentos estará ordenada da nota mais alta para a mais baixa.
A função deve devolver uma `list` de strings com o formato `<rank>. <student name>: <student score>`.

```python
>>> student_scores = [100, 99, 90, 84, 66, 53, 47]
>>> student_names =  ['Joci', 'Sara','Kora','Jan','John','Bern', 'Fred']
>>> student_ranking(student_scores, student_names)
...
['1. Joci: 100', '2. Sara: 99', '3. Kora: 90', '4. Jan: 84', '5. John: 66', '6. Bern: 53', '7. Fred: 47']
```

## 6. Uma nota "perfeita"

Embora uma nota "perfeita" de 100 seja rara num exame, é interessante saber se pelo menos um aluno a alcançou.

Cria a função `perfect_score(student_info)`, com o parâmetro `student_info`.
`student_info` é uma `list` de listas com o nome e a nota de cada aluno: `[["Charles", 90], ["Tony", 80]]`.
A função deve `return` _o primeiro_ par `[<name>, <score>]` do aluno que tirou 100 no exame.

Se não houver nenhuma nota de 100 em `student_info`, deve ser devolvida uma lista vazia `[]`.

```python
>>> perfect_score(student_info=[["Charles", 90], ["Tony", 80], ["Alex", 100]])
["Alex", 100]

>>> perfect_score(student_info=[["Charles", 90], ["Tony", 80]])
[]
```
