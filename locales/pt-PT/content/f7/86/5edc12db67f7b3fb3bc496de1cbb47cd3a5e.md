# Dicas

## Geral

- Não te preocupes com tipos de números específicos; para já, usa `Int32` e `Float64`.
- `Int32` e `Float64` são os tipos de números predefinidos em Crystal, por isso não precisas de os especificar.

## 1. Converte a temperatura de Celsius para Kelvin

- Podes usar o operador aritmético (`+`) para somar números.

## 2. Arredonda a temperatura

- Podes usar o método `round` para arredondar um número a um determinado número de casas decimais.
- O método `round` recebe um argumento, `places`, que indica o número de casas decimais para as quais arredondar.

## 3. Converte a temperatura de Celsius para Fahrenheit

- Podes usar o operador aritmético (`*`) para multiplicar números.
- Podes usar parênteses (`()`) para agrupar operações.

## 4. Obtém o número de sensores em falta

- Podes usar o operador aritmético (`-`) para subtrair números.
- Podes usar o operador aritmético (`%`) para obter o resto de uma divisão.
