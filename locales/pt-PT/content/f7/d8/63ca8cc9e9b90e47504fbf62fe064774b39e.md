# Dicas

## 1. Define se o Pac-Man pode comer um fantasma

* A função tem de devolver um valor Boolean.
* Podes usar o operador lógico `and` para combinar os argumentos e obter um resultado.

## 2. Define se o Pac-Man marca pontos

* A função tem de devolver um valor Boolean.
* Podes usar o operador Boolean `or` para combinar os argumentos e obter um resultado.

## 3. Define se o Pac-Man perde

* A função tem de devolver um valor Boolean.
* Podes usar os operadores Boolean `and` e `not` para combinar os argumentos e obter um resultado.

## 4. Define se o Pac-Man vence

* A função tem de devolver um valor Boolean.
* Podes usar os operadores Boolean `and` e `not` para combinar os argumentos e os resultados de uma das funções implementadas anteriormente.
