# Dicas

## Geral

- Um [mapa][maps] é uma estrutura de dados associativa de pares chave-valor.
- O Elixir oferece [muitas funções úteis do módulo Map na biblioteca padrão][map-module].

## 1. Define um novo mapa de pontuações máximas

- Deve devolver um [mapa][maps] vazio.
- As funções do [módulo Map][map-module] ou as formas literais podem ser úteis.

## 2. Adiciona jogadores ao mapa de pontuações máximas

- O mapa resultante deve ser devolvido.
- O [módulo Map][map-module] contém funções úteis para manipular mapas. [Uma delas][map-put] coloca um valor num mapa associado a uma determinada chave.

## 3. Remove jogadores do mapa de pontuações

- O mapa resultante deve ser devolvido.
- O [módulo Map][map-module] contém funções úteis para manipular mapas. [Uma delas][map-delete] elimina uma chave de um mapa.

## 4. Reinicia a pontuação de um jogador

- O mapa resultante deve ser devolvido com a pontuação do jogador reiniciada num valor inicial.
- O [módulo Map][map-module] contém funções úteis para manipular mapas. [Uma delas][map-put] coloca um valor num mapa associado a uma determinada chave.

## 5. Atualiza a pontuação de um jogador

- O mapa resultante deve ser devolvido com a pontuação atualizada do jogador.
- O [módulo Map][map-module] contém funções úteis para manipular mapas. [Uma delas][map-update] atualiza um valor num mapa associado a uma determinada chave.

## 6. Obtém uma lista de jogadores

- O [módulo Map][map-module] contém funções úteis para manipular mapas. [Uma delas][map-keys] devolve uma lista de todas as chaves de um mapa.
