# Introdução

O [tipo `enum`](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/builtin-types/enum) do C# representa um conjunto fixo de constantes com nome (uma enumeração).

Normalmente, um membro de um `enum` só pode referir-se a exatamente uma dessas constantes com nome. No entanto, por vezes é útil referir mais do que uma constante. Para isso, podes anotar o `enum` com o [atributo `Flags`](https://docs.microsoft.com/en-us/dotnet/api/system.flagsattribute)

Um enum de flags pode ser definido da seguinte forma (usando a notação binária de inteiros `0b`):

```csharp
[Flags]
enum PhoneFeatures
{
    Call = 0b00000001,
    Text = 0b00000010
}
```

Uma instância de `PhoneFeatures` cujo valor é `0b00000011` tem as flags `Call` _e_ `Text` ativas.

Por predefinição, o tipo `int` é usado para os valores dos membros do `enum`. Podes usar um tipo inteiro diferente indicando o tipo na declaração do `enum`:

```csharp
[Flags]
enum PhoneFeatures : byte
{
    Call = 0b00000001,
    Text = 0b00000010
}
```
