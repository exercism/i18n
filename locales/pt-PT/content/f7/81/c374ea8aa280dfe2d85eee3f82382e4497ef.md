# Dicas

## Geral

- Lê sobre enumerables e streams no [guia oficial Getting Started][getting-started-streams].
- Lê a documentação oficial sobre [streams][stream].

## 1. Faz uma jogada de um dado de 6 faces

- Os ranges implementam o _protocolo Enumerable_.
- Há uma [função incorporada][enum-random] para escolher um valor aleatório a partir de um enumerable.

## 2. Continua a lançar enquanto tirares seis

- Há uma [função incorporada][stream-repeatedly] que cria um stream gerado ao chamar uma função repetidamente.
- Há uma [função incorporada para streams][stream-transform] que funciona de forma semelhante a `Enum.reduce/3`.

## 3. Permite usar um dado viciado

- Usa o [operador de captura][special-forms-capture] para capturar a função `roll/0`.
