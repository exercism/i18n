# Instruções

Tens uma loja de moda online. Cada artigo do teu inventário é um array de 2 elementos `{ name price }`, e o inventário completo é um array de artigos.

Um preço em falta é registado como `f`.

## 1. Ordena o inventário por preço

Define `sort-by-price` para devolver um novo array com os artigos ordenados por preço, por ordem crescente.

```factor
{ { "Maxi Brown Dress" 65 } { "Red Skirt" 50 } { "Bamboo Socks Cats" 20 } }
sort-by-price .
! => { { "Bamboo Socks Cats" 20 } { "Red Skirt" 50 } { "Maxi Brown Dress" 65 } }
```

## 2. Encontra os artigos sem preço definido

Define `with-missing-price` para devolver um array só com os artigos cujo preço é `f`.

```factor
{ { "Black T-shirt" 40 } { "Denim Pants" f } { "Orange T-shirt" 40 } }
with-missing-price .
! => { { "Denim Pants" f } }
```

## 3. Conta os artigos caros

Define `expensive-items` para receber um inventário e um limiar de preço, e devolver quantos artigos custam estritamente mais do que o limiar.

```factor
{ { "Skirt" 50 } { "Coat" 120 } { "Hat" 25 } { "Dress" 80 } }
50 expensive-items .
! => 2

{ { "Skirt" 50 } { "Coat" 120 } { "Hat" 25 } { "Dress" 80 } }
0 expensive-items .
! => 4
```

## 4. Encontra o artigo mais barato

Define `cheapest-item` para devolver o artigo com o preço mais baixo. Os artigos sem preço (`f`) não aparecem nos dados de entrada.

```factor
{ { "Skirt" 50 } { "Coat" 120 } { "Hat" 25 } } cheapest-item .
! => { "Hat" 25 }
```

## 5. Soma todos os preços

Define `total-price` para devolver a soma de todos os preços. Os artigos sem preço (`f`) não aparecem nos dados de entrada.

```factor
{ { "Skirt" 50 } { "Coat" 120 } { "Hat" 25 } } total-price .
! => 195
```

## 6. Formata um artigo como etiqueta de preço

Define `format-price-tag` para devolver, para um artigo, uma string da forma `"name: $price"`. Os artigos sem preço (`f`) não aparecem aqui.

```factor
{ "Skirt" 50 } format-price-tag .
! => "Skirt: $50"
```
