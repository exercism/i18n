# Instruções

A tua equipa de design está a passar das transformações CSS para Factor em parte do seu trabalho de layout. Para agradar ao resto da equipa, vais construir transformações pequenas e reutilizáveis, na forma de quotations que recebem um ponto 2D e devolvem um ponto 2D.

Um ponto é um array de 2 elementos `{ x y }`.

## 1. Translada as coordenadas

Define `translate-2d` para retirar dois valores `dx` e `dy` da pilha e devolver uma quotation que translada um ponto em `(dx, dy)`.

```factor
{ 4 8 } 2 0 translate-2d call( p -- p' ) .
! => { 6 8 }
```

## 2. Escala as coordenadas

Define `scale-2d` da mesma forma, devolvendo uma quotation que escala um ponto em `(sx, sy)`.

```factor
{ 6 -3 } 2 2 scale-2d call( p -- p' ) .
! => { 12 -6 }
```

## 3. Compõe duas transformações

Define `compose-transformations` para receber duas quotations de transformação `f` e `g` e devolver uma única quotation que aplica primeiro `f` e depois `g`.

```factor
{ 0 1 } 2 0 translate-2d 2 2 scale-2d compose-transformations
call( p -- p' ) .
! => { 4 2 }
```

## 4. Aplica uma transformação

Define `apply-transformation` para retirar um ponto e uma quotation de transformação da pilha e devolver o ponto transformado.

```factor
{ 4 8 } 2 0 translate-2d apply-transformation .
! => { 6 8 }
```

## 5. Transforma vários pontos de uma só vez

Define `transform-points` para receber um array de pontos e uma quotation de transformação, e devolver o array de pontos transformados.

```factor
{ { 0 0 } { 1 1 } { 2 2 } } 1 0 translate-2d transform-points .
! => { { 1 0 } { 2 1 } { 3 2 } }
```
