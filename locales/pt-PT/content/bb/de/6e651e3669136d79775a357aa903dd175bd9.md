## Representações de PHP

O [representador de PHP][github-php-representer] aplica as seguintes normalizações:

- Todos os comentários são removidos
- Todos os espaços em branco são normalizados
- Os identificadores (classes, funções e variáveis) são normalizados para um valor de substituição
  - Os identificadores que não distinguem maiúsculas de minúsculas são normalizados para o mesmo valor de substituição
  - As funções com alias são normalizadas (https://www.php.net/manual/en/aliases.php)
- As strings (entre plicas, entre aspas, heredoc e nowdoc) são todas convertidas para plicas (https://www.php.net/manual/en/language.types.string.php)
  - As strings interpoladas são normalizadas para concatenação: `"this is $a variable"` => `'this is ' . $a . ' variable'`
  - A concatenação é simplificada: `'testA' . 'testB' . 'testC'` => `'testAtestBtestC'`
- Os arrays são normalizados para a sintaxe curta: `array('a', 'b')` => `['a', 'b']`
- As conversões `(float)` e `(real)` são normalizadas para `(double)`

[github-php-representer]: https://github.com/exercism/php-representer
