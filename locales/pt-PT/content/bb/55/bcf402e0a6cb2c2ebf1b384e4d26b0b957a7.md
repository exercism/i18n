# Instruções

Este exercício aborda a análise de ficheiros de registo.

Após uma revisão de segurança recente, pediram-te que limpasses os ficheiros de registo arquivados da organização.

Todas as strings passadas aos métodos são garantidamente não nulas e sem espaços no início nem no fim.

## 1. Identifica as linhas de registo corrompidas

Precisas de ter uma ideia de quantas linhas de registo no teu arquivo não cumprem as normas atuais. Acreditas que um teste simples revela se uma linha de registo é válida. Para ser considerada válida, uma linha deve começar por uma das seguintes strings:

- [TRC]
- [DBG]
- [INF]
- [WRN]
- [ERR]
- [FTL]

Implementa o método `LogParser.IsValidLine()` para devolver `false` se uma string não for válida e `true` caso contrário.

```csharp
var lp = new LogParser();
lp.IsValidLine("[ERR] A good error here");
// => true
lp.IsValidLine("Any old [ERR] text");
// => false
lp.IsValidLine("[BOB] Any old text");
// => false
```

## 2. Divide a linha de registo

Uma nova equipa juntou-se à organização e descobriste que os ficheiros de registo deles usam um separador estranho para os "campos". Em vez de algo sensato como dois pontos ":", usam uma string como "<--->" ou "<=>" (porque fica mais bonito), na verdade qualquer string que tenha "<" como primeiro caráter e ">" como último caráter e, entre eles, qualquer combinação dos seguintes carateres: "^", "\*", "=" e "-".

Implementa o método `LogParser.SplitLogLine()`, que recebe uma linha e devolve um array de strings, cada uma com um campo.

```csharp
var lp = new LogParser();
lp.SplitLogLine("Section 1<===>Section 2<^-^>Section 3");
// => {"Section 1", "Section 2", "Section 3"}
```

## 3. Conta o número de linhas que contêm uma palavra-passe entre aspas

A equipa precisa de saber que palavras-passe aparecem em texto entre aspas, para que possam ser examinadas manualmente.

Implementa o método `LogParser.CountQuotedPasswords()` para dar uma indicação da provável dimensão do trabalho manual.

Identifica as linhas de registo em que a string literal "password", que pode estar em qualquer combinação de maiúsculas e minúsculas, está rodeada por aspas.
Deves ter em conta a possibilidade de haver conteúdo adicional entre as aspas, antes e depois de "password".

As linhas passadas à rotina podem ou não ser válidas de acordo com a tarefa 1. Processamo-las da mesma forma, sejam ou não válidas.

```csharp
string lines =
    "[INF] passWord " + Environment.NewLine + // contains 'password' but not surrounded by quotation marks
    "\"passWord\"" + Environment.NewLine + // count this one
    "[INF] User saw error message \"Unexpected Error\" on page load." + Environment.NewLine + //does not contain 'password'
    "[INF] \"The secret password was added by the user\""; // count this one

var lp = new LogParser();
lp.CountQuotedPasswords(lines);
// => 2
```

## 4. Remove artefactos do registo

Descobriste que algum processamento a montante dos registos tem vindo a espalhar pelos registos o texto "end-of-line" seguido de um número de linha (sem espaço entre eles).

Implementa o método `LogParser.RemoveEndOfLineText()` para receber uma string, remover o texto end-of-line e devolver uma string "limpa".

As linhas que não contenham o texto end-of-line devem ser devolvidas sem alterações.

Limita-te a remover a string end-of-line. Não tentes ajustar os espaços em branco.

```csharp
var lp = new LogParser();
lp.RemoveEndOfLineText("[INF] end-of-line23033 Network Failure end-of-line27");
// => "[INF]  Network Failure "
```

## 5. Lista as linhas com palavras-passe extremamente fracas para que os culpados possam ser castigados

Antes de eliminar as palavras-passe do ficheiro, precisamos de listar todos os casos em que as palavras-passe começam com o texto "password".

Implementa o método `LogParser.ListLinesWithPasswords()` para imprimir a palavra-passe infratora seguida da linha completa.

As linhas com palavras-passe entre aspas já foram removidas e processas as linhas independentemente de serem válidas (de acordo com a tarefa 1).

As linhas que contenham uma palavra-passe infratora devem ser devolvidas com o prefixo "<password>: ".

As linhas que não contenham uma palavra-passe infratora devem ser devolvidas com o prefixo "--------: ".

```csharp
var lp = new LogParser();
lp.ListLinesWithPasswords(new string[] {"my passwordsecret is great"});
// => "passwordsecret: my passwordsecret is great"
lp.ListLinesWithPasswords(new string[] {"my password secret"});
// => {"--------: my password secret"}

```
