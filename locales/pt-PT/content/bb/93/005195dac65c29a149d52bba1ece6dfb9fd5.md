# Classes com estado

Todas as classes até agora foram uma caixa de rotinas. Cada uma recebia os seus argumentos, calculava uma resposta e esquecia tudo.

Uma classe pode, em vez disso, **guardar** coisas na memória. Um marcador tem de o fazer: o resultado depende agora de todos os golos desde que o jogo começou.

## Atributos

O `attr` dá a uma classe algo para guardar.

```sather
class SCOREBOARD is

   attr home_score : INT;
   attr away_score : INT;

end; -- class SCOREBOARD
```

Cada `attr` dá origem a uma rotina que lê o valor e a outra que o altera:

```sather
   board.home_score            -- read it
   board.home_score := 4;      -- change it
```

Atributos do mesmo tipo podem partilhar uma declaração, tal como acontece com os argumentos:

```sather
   attr home_score, away_score : INT;
```

## Objetos

Uma classe com atributos é um molde para criar **objetos**. Cada objeto tem as suas próprias cópias dos atributos, por isso dois marcadores guardam resultados independentes.

O `new` cria um objeto. Fica dentro de uma rotina chamada `create`, que depois preenche o objeto e o devolve:

```sather
   create(home, away : STR) : SAME is
      board ::= new;
      board.home_team := home;
      board.away_team := away;
      return board;
   end;
```

`SAME` significa "esta classe". Escrever `SCOREBOARD` ali diria o mesmo, mas `SAME` continua a funcionar se a classe mudar de nome.

## Criar um

O `#` chama o `create`:

```sather
   board ::= #SCOREBOARD("Vixens", "Magpies");
```

Tens vindo a usar o `#` desde o exercício `rehearsal-script`; o `#FSTR` é exatamente isto.

## Rotinas que alteram o objeto

Dentro da classe, um atributo usa-se pelo nome, sem nenhum objeto à frente. Refere-se ao objeto sobre o qual a rotina foi chamada.

```sather
   home_goal is
      home_score := home_score + 1;
   end;
```

O `home_goal` não declara nenhum tipo devolvido, porque não devolve nada; em vez disso, altera o objeto. Chama-o como instrução:

```sather
   board.home_goal;
```

## Os atributos começam vazios

Um atributo que ninguém atribuiu vale zero para um `INT`, `false` para um `BOOL` e void para uma string ou um objeto. Por isso, um marcador novo mostra 0 a 0 sem que nada tenha de o indicar.
