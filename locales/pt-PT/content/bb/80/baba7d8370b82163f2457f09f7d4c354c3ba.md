# Introdução

## Carateres

O tipo primitivo `char` do Java é uma representação de 16 bits de um único caráter.
Vários `char`s podem formar uma string, como `"word"`, ou os `char`s podem ser processados individualmente.
Um literal `char` é rodeado por aspas simples (por exemplo, `'A'`).

```java
char lowerA = 'a';
char upperB = 'B';
```

## Obter os `char`s de uma `String`

O método `String.toCharArray` devolve os carateres de uma String como um array.
Como referido nos arrays, podes usar um ciclo `for` para percorrer o array.

```java
String text = "Hello";
char[] asArray = text.toCharArray();

for (char ch: asArray) {
    System.out.println(ch);
}

// Outputs:
// H
// e
// l
// l
// o
```

## A classe Character

Existem muitos métodos incorporados da biblioteca para inspecionar e manipular `char`s.
Podes encontrá-los como métodos estáticos da classe `java.lang.Character`.
Aqui estão alguns exemplos:

```java
Character.isWhitespace(' ');    // true
Character.isWhitespace('#');    // false

Character.isLetter('a');        // true
Character.isLetter('3');        // false

Character.isDigit('6');         // true
Character.isDigit('?');         // false
```

## Adicionar um `char` a uma `String`

Podes usar o operador `+` para adicionar um `char` a uma `String`.

```java
'a' + " banana"     // => "a banana"
"banana " + 'a'     // => "banana a"
```

~~~~exercism/caution
Tem cuidado para _não_ usares `+` para juntar dois `char`s e formar uma `String`!
Adicionar dois `char`s desta forma dá um `int`, _não_ uma `String`!
Por exemplo:

```java
'b' + 'c';
// => 197 (not the String "bc")
```

Isto acontece porque o Java promove o `char` a um `int` (ver [4.2 Tipos e valores primitivos ][jls-primitives] da [Java Language Specification][jls-main]).

[jls-main]: https://docs.oracle.com/javase/specs/jls/se21/html/
[jls-primitives]: https://docs.oracle.com/javase/specs/jls/se21/html/jls-4.html#jls-4.2
~~~~

No entanto, quando há muitos carateres para adicionar, pode ser mais eficiente usar um `StringBuilder`:

```java
StringBuilder builder = new StringBuilder();
builder.append('a');
builder.append('b');
builder.append('c');

String builtString = builder.toString();
// => abc
```
