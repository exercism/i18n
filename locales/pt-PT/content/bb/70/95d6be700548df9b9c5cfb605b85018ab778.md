# Sobre

Um número de vírgula flutuante é um número com zero ou mais algarismos depois do separador decimal. Alguns exemplos são `-2.4`, `0.1`, `3.14`, `16.984025` e `1024.0`.

O F# tem três tipos de vírgula flutuante:

- `single`: 4 bytes (~6-9 algarismos de precisão). Escreve-se como `2.45f` ou `2.45F`. O tipo `float32` pode ser usado como alias.
- `float`: 8 bytes (~15-17 algarismos de precisão). Este é o tipo mais comum. Escreve-se como `2.45` ou usando notação exponencial, como `2.3E+32` ou `2.3e+32`. O tipo `double` pode ser usado como alias.
- `decimal`: 16 bytes (28-29 algarismos de precisão). Normalmente usado quando se trabalha com dados monetários, pois a sua precisão dá origem a menos erros de arredondamento. Escreve-se como `2.45m` ou `2.45M`.

Cada tipo de vírgula flutuante tem a sua própria [precisão, intervalo aproximado e tamanho][floating-point-types]. A precisão indica quantos algarismos depois do separador decimal podem ser armazenados. Isto significa que tentar armazenar PI num `single` só vai armazenar os primeiros 6 a 9 algarismos (com o último algarismo arredondado).

A conversão entre diferentes tipos de vírgula flutuante é feita com os [operadores de conversão][conversion-operators]:

```fsharp
let floatFromSingle = float 2.45f
```

Tem sempre cuidado ao verificar se valores de tipos de vírgula flutuante são iguais, pois valores que podem parecer representar o mesmo valor podem, na verdade, ser diferentes. Vê [este artigo][precision-in-comparisons] para mais informações (os exemplos de código estão em C#).

Podes encontrar uma breve introdução aos números de vírgula flutuante em [0.30000000000000004.com][0.30000000000000004.com]. A [página Float Toy][evanw.github.io-float-toy] tem uma boa explicação gráfica de como os bits de um número de vírgula flutuante são convertidos num valor de vírgula flutuante efetivo.
