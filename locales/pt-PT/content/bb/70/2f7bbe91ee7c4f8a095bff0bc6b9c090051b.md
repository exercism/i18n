# Instruções

A tua tarefa é determinar o que o Bob responde a alguém quando lhe dizem algo ou lhe fazem uma pergunta.

O Bob só responde uma de cinco coisas:

- **"Sure."**
  Esta é a resposta quando lhe fazes uma pergunta, como "Como estás?"
  A convenção usada para as perguntas é que estas terminam com um ponto de interrogação.
- **"Whoa, chill out!"**
  Esta é a resposta quando GRITAS COM ELE.
  A convenção usada para os gritos é TODAS AS LETRAS MAIÚSCULAS.
- **"Calm down, I know what I'm doing!"**
  É o que ele diz quando lhe gritas uma pergunta.
- **"Fine. Be that way!"**
  É assim que ele responde ao silêncio.
  A convenção usada para o silêncio é nada, ou várias combinações de carateres de espaço em branco.
- **"Whatever."**
  É o que ele responde a tudo o resto.
