# Ajuda

Se estiveres com dificuldades, podes recorrer a um dos seguintes recursos:

- O [/r/fsharp](https://www.reddit.com/r/fsharp) é o subreddit de F#.
- Podes usar o [StackOverflow](http://stackoverflow.com/questions/tagged/f%23) para procurar o teu problema e ver se já foi respondido. Também podes colocar perguntas e responder a outras.

## Pacotes

O percurso de F# suporta um número limitado de pacotes.
Consulta a [lista de pacotes suportados](https://exercism.org/docs/tracks/fsharp/packages) para saberes quais.
