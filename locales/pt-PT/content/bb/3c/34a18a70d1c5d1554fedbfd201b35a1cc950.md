# Dicas

## Geral

- O vocabulário [`sequences`][sequences] abrange quase tudo, incluindo `sum`.

## 1. Contagem de hoje

- `last` devolve o elemento final de uma sequência.

## 2. Incrementar a contagem de hoje

- `unclip-last` retira o último elemento para que o possas transformar, e `suffix` acrescenta um elemento a uma sequência. Juntos, dão-te um padrão não destrutivo para «modificar o último elemento».

## 3. Houve algum dia sem aves?

- `any?` recebe uma sequência e uma quotation de predicado e devolve `t` se o predicado se verificou para pelo menos um elemento.
- A quotation de predicado para «este número é zero?» é `[ zero? ]`.

## 4. Somar os primeiros dias

- `head` recebe uma sequência e um número `n` e devolve os primeiros `n` elementos.
- Depois, soma o resultado.

## 5. Contar os dias movimentados

- `count` recebe uma sequência e um predicado, tal como `any?` faz, mas devolve *quantos* elementos corresponderam.

## 6. Preencher os dias em falta

- `pad-tail` recebe uma sequência, um comprimento de destino e um elemento de preenchimento, e estende a sequência até esse comprimento acrescentando cópias do elemento. Se a sequência já for suficientemente longa, é devolvida sem alterações.
