# Introdução

## Expressões case

Em Gleam, podes usar uma expressão `case` para executar código condicionalmente. Com uma expressão `case`, podes testar um valor contra um ou mais _padrões_. Um exemplo desse tipo de padrão é o _padrão literal_, que compara um valor com um valor literal (por exemplo, `1` ou `"hello"`).

As expressões `case` escrevem-se com a palavra-chave `case`:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    1 -> "One"
  }
}
```

Embora isto possa parecer-se com instruções `switch` noutras linguagens, a correspondência de padrões começa a destacar-se quando também usas outros padrões. Um desses padrões é o _padrão variável_, que te permite atribuir um valor a uma variável. Neste exemplo, à variável `i` será atribuído o valor de `number` se este não for `0`:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i -> "Non zero"
  }
}
```

Nalguns casos, podes querer adicionar uma condição adicional a um padrão. Isto é conhecido como uma _guarda_ (cláusula), que pode ser adicionada com a palavra-chave `if`:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i if i < 0 -> "Negative number"
  }
}
```

Por razões de desempenho, só são permitidos operadores matemáticos e booleanos básicos nas guardas. Não podes usar outras funções nas guardas.

No exemplo acima, nem todos os valores de entrada possíveis têm um padrão correspondente. O compilador deteta isto e emite um erro. Isto é conhecido como _verificação exaustiva_. Para resolveres o aviso, tens de tratar todos os casos. Para isso, podes usar o _padrão de descarte_, que é um padrão que corresponde a qualquer valor:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i if i < 0 -> "Negative number"
    _ -> "Positive number"
  }
}

// No compiler error
```

Podes comparar vários padrões numa só cláusula, usando `|` para separar cada padrão. Só podes adicionar uma guarda por cláusula:

```gleam
pub fn describe(number: Int) -> String {
  let yell = True
  case number {
    0 -> "Zero"
    3 | 5 -> "One of the first odd prime numbers"
    2 | 4 | 6 | 8 if !yell -> "One of the even numbers less than 10"
    i if i % 2 == 0 && yell -> "[Yelling] I'm telling you! It's a even nunber"
    i if i < 0 -> "Negative number"
    _ -> "Positive number"
  }
}
// No compiler error
```

As expressões `case` testam um valor contra cada padrão de cima para baixo, até encontrarem um padrão correspondente e executarem a lógica associada a esse padrão. A ordem dos padrões é importante!
