# Sobre

Os tipos de C# podem ser definidos dentro do âmbito de uma classe ou de um struct. O tipo envolvente fornece uma espécie de espaço de nomes. Acede-se ao tipo através do tipo envolvente, com a sintaxe de ponto.

```csharp
class Outer
{
    public interface IInner {}
    public enum EInner {}
    public class CInner {}
    public struct SInner {}
}

var outer = new Outer();
var inner = new Outer.CInner();
```

## Níveis de acesso

Podem aplicar-se níveis de acesso aos tipos interiores. Por exemplo, se uma classe for `private`, não pode ser vista fora do âmbito do tipo envolvente e, naturalmente, as instâncias também não podem ser vistas nem usadas fora desse âmbito.

Os membros privados da classe exterior estão no âmbito de todos os membros da classe interior, mas apenas os membros não privados da classe interior estão no âmbito dos membros da classe exterior. Para aceder aos membros da classe exterior, é preciso fornecer à classe interior uma instância da classe exterior.

Isto pode ver-se no exemplo seguinte:

```csharp
class Outer
{
    public class InnerImpl
    {
        private Outer outer;

        public int Interesting = 42;

        public InnerImpl(Outer outer, int interesting)
        {
            this.outer = outer;
            Interesting = interesting;
        }

    }

    public InnerImpl Inner;
    public Outer()
    {
        Inner = new InnerImpl(this, 42);
    }
}

var outer = new Outer();
outer.Inner.Interesting
// => 42
var inner = new Outer.InnerImpl(outer, 1729);
outer.Inner.Interesting
// => 1729
```

## Impedir a instanciação independente

Existe um padrão para impedir que um tipo instanciável seja criado fora do tipo envolvente. Expõe uma interface pública, mas mantém a classe que a implementa privada.

```csharp
class Outer
{
    public interface IInner
    {
        void DoSomething();
    }

    private class InnerImpl : IInner
    {
        private Outer outer;
        public InnerImpl(Outer outer)
        {
            this.outer = outer;
        }
        public void DoSomething()
        {
            outer.DoSomethingElse();
        }
    }

    public IInner Inner;

    public Outer()
    {
        Inner = new InnerImpl(this);
    }
    private void DoSomethingElse()
    {
    }
}

var outer = new Outer();
outer.Inner.DoSomething();

// NOT var inner = new Outer.Inner(outer);
```

## Nota para programadores de Java

As classes aninhadas do C# são um cruzamento entre as classes aninhadas estáticas e as classes interiores do Java. Em C#, os membros privados da classe envolvente estão no âmbito dos membros da classe aninhada, mas não existe sintaxe especial para as instanciar e ligar a uma instância da classe envolvente. Tens de usar alguma variação do padrão ilustrado nos exemplos acima.

O C# tem, de facto, classes aninhadas estáticas, mas estas são simplesmente classes envolvidas com comportamento estático.
