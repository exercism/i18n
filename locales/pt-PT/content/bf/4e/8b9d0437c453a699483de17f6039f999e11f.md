# Introdução

Em Python, [um `enum`][enum-docs] é um conjunto de nomes associados a valores `literal` ou `constant` únicos.
Os `Enums` definem-se herdando de uma classe `Enum` ou criando uma subclasse dela.
Os tipos `enum` incorporados estão disponíveis no módulo `enum`, e a classe `Enum` pode ser importada com `from enum import Enum`.


```python
from enum import Enum

class Color(Enum):
    RED = 1
    GREEN = 2
```

Repara que os valores dos membros de um `enum` podem ser quaisquer tipos de dados, como `str`, `tuple`, `float`, etc.

```python
class Color(Enum):
    RED = 'red'
    GREEN = 'green'
```

Quando atribuis o mesmo valor a dois membros de um `enum`, o membro atribuído em segundo lugar passa a ser um alias do primeiro. Não é permitido usar o mesmo nome para dois membros diferentes de um `enum`.

```python
class Color(Enum):
    RED = 1
    GREEN = 2
    ALIAS_OF_RED = 1

Color.ALIAS_OF_RED
#=> <Color.RED: 1>

Color.ALIAS_OF_RED.value
#=> 1
```

Podes iterar pelos membros do `enum` com a sintaxe padrão `for member in`:

```python
for member in Color:
    print((member.name, member.value))
#=> (RED, 1)
#=> (GREEN, 2)
```

Os membros de um `Enum` podem ser comparados com [`is` (_operador de identidade_)][identity-keyword] ou `is not`. Os operadores `==` ou `!=` (_operadores de igualdade_) funcionam da mesma forma:

```python
a = Color.RED

a is Color.RED
#=> True

a == Color.RED
#=> True
```

Para acederes a um membro do `enum` a partir de um determinado valor, podes usar `<EnumName>(<value>)`:

```python
g = Color(2)

g is Color.GREEN
#=> True

g
#=> <Color.GREEN: 2>
```

[identity-keyword]: https://www.w3schools.com/python/ref_keyword_is.asp
