# Instruções

Como aspirante a maga, a Elyse precisa de praticar o básico. Tem uma pilha de cartas que quer manipular.

Para facilitar um pouco as coisas, usa apenas as cartas de 1 a 10.

A pilha de cartas é representada por uma `queue`, com a base da pilha na frente da `queue` e o topo da pilha no fim.

## 1. Insere uma carta no topo da pilha

Implementa a função `insert_top`, que devolve uma cópia da pilha com a nova carta fornecida adicionada ao topo.

```gleam
insert_top(queue.from_list([5, 9, 7, 1]), 8)
// -> queue.from_list([5, 9, 7, 1, 8])
```

## 2. Remove a carta do topo da pilha

Implementa a função `remove_top_card`, que devolve uma cópia da pilha com a carta do topo removida. Se a pilha indicada estiver vazia, deves devolver a pilha original, sem alterações.

```gleam
remove_top_card(queue.from_list([3, 2, 6, 4, 8]))
// -> queue.from_list([3, 2, 6, 4])
```

## 3. Insere uma carta na base da pilha

Implementa a função `insert_bottom`, que devolve uma cópia da pilha com a nova carta fornecida adicionada à base.

```gleam
insert_bottom(queue.from_list([5, 9, 7, 1]), 8)
// -> queue.from_list([8, 5, 9, 7, 1])
```

## 4. Remove uma carta da base da pilha

Implementa a função `remove_bottom_card`, que devolve uma cópia da pilha com a carta da base removida. Se a pilha indicada estiver vazia, deves devolver a pilha original, sem alterações.

```gleam
remove_bottom_card(queue.from_list([8, 5, 9, 7, 1]))
// -> queue.from_list([5, 9, 7, 1])
```

## 5. Verifica o tamanho da pilha

Implementa a função `check_size_of_stack`, que verifica se o tamanho da pilha é igual a um dado `stack_size` ou não.

```gleam
check_size_of_stack(queue.from_list([3, 2, 6, 4, 8]), 4)
// -> False
```
