# CLI

## Configuração

A forma mais simples de instalar o PureScript é através do Node.js e do NPM.

Se ainda não tens o Node.js instalado no teu computador, podes descarregá-lo a partir do [site do Node.js][nodejs-website]. Assim que tiveres o Node.js a funcionar, introduz este comando no terminal para instalar o compilador PureScript e o Spago, o gestor de pacotes e ferramenta de compilação.

```shell
npm install -g purescript spago
```

Podes encontrar mais informações no [repositório do PureScript][purescript-repository].

## Requisitos

Instala as dependências do exercício:

```shell
spago install
spago build
```

## Fazer passar a suite de testes

Executa os testes com:

```shell
spago test
```

Nas suites de testes, todos os testes exceto o primeiro estão ignorados. Isto serve para te incentivar a resolver o exercício passo a passo.

Assim que conseguires passar um teste, podes ativar o seguinte alterando `xit` para `it`.

## Submeter a solução

Quando já não houver testes ignorados e estiverem todos a passar, podes submeter a tua solução com:

```shell
exercism submit src/<NAME>.purs
```

## Escrever testes personalizados

Se quiseres escrever testes adicionais e personalizados, cria um novo ficheiro `test/Custom.purs` e submete-o juntamente com a tua solução:

```shell
exercism submit src/<NAME>.purs test/Custom.purs
```
