# Introdução

Os algarismos binários acabam por corresponder diretamente aos transístores da tua CPU ou RAM, e ao facto de cada um estar "ligado" ou "desligado".

A manipulação de baixo nível, informalmente chamada "bit-twiddling", é particularmente importante nas linguagens de sistema.

As linguagens de alto nível, como a Julia, costumam abstrair a maior parte destes detalhes.
No entanto, existe toda uma gama de operações ao nível dos bits disponível na linguagem base.

***Nota:*** Para ver resultados binários legíveis por humanos no REPL, quase todos os exemplos abaixo têm de ser envolvidos numa função `bitstring()`.
Isto distrai visualmente, por isso a maioria das ocorrências desta função foi retirada.

## Operações de deslocamento de bits

Os tipos inteiros, com ou sem sinal, podem ser representados como uma string de 1s e 0s.

```julia-repl
julia> bitstring(UInt8(5))
"00000101"
```

Os deslocamentos de bits limitam-se a mover tudo para a esquerda ou para a direita um número especificado de posições.
Com os tipos `UInt`, alguns bits saem por uma extremidade e a outra extremidade é preenchida com zeros:

```julia-repl
julia> ux::UInt8 = 5
5

julia> bitstring(ux)
"00000101"

julia> ux << 2 # left by 2
"00010100"

julia> ux >> 1 # right by 1
"00000010"
```

Cada deslocamento para a esquerda duplica o valor e cada deslocamento para a direita divide-o por dois (sujeito a truncagem).
Isto é mais óbvio na representação decimal:

```julia-repl
julia> 3 << 2
12

julia> 24 >> 3
3
```

Este tipo de deslocamento de bits é muito mais rápido do que a aritmética "a sério", o que torna a técnica muito popular na programação de baixo nível.

Com os inteiros com sinal, temos de ter um pouco mais de cuidado.

Os deslocamentos para a esquerda são relativamente simples:

```julia-repl
julia> sx = Int8(5)
5

julia> sx # positive integer
"00000101"

julia> sx << 2
"00010100"

julia> -sx # negative integer
"11111011"

julia> -sx << 2
"11101100"
```

Assim, deslocar para a esquerda inteiros com sinal positivos é o mesmo que com inteiros sem sinal.

Os valores negativos são armazenados na forma de [complemento de dois][2complement], o que significa que o bit mais à esquerda é 1.
Não há problema para um deslocamento para a esquerda, mas ao deslocar para a direita, como preenchemos os bits mais à esquerda?

```julia-repl
julia> sx >> 2 # simple for positive values!
"00000001"

julia> -sx # negative integer
"11111011"

julia> -sx >> 2 # pad with repeated sign bit
"11111110"

julia> -sx >>> 2 # pad with 0
"00111110"
```

O operador `>>` faz um deslocamento aritmético, preservando o bit de sinal.

O operador `>>>` faz um deslocamento lógico, preenchendo com zeros como se o número não tivesse sinal.

## Lógica bit a bit

Vimos num Conceito anterior que os operadores `&&` (and), `||` (or) e `!` (not) se usam com valores Boolean.

Existem operadores equivalentes, `&` (and bit a bit), `|` (or bit a bit) e `~` (um til, not bit a bit), para comparar os bits de dois inteiros.

```julia-repl
julia> 0b1011 & 0b0010 # bit is 1 in both numbers
"00000010"

julia> 0b1011 | 0b0010 # bit is 1 in at least one number
"00001011"

julia> ~0b1011 # flip all bits
"11110100"

julia> xor(0b1011, 0b0010) # bit is 1 in exactly one number, not both
"00001001"
```

Aqui, `xor()` é o ou-exclusivo, usado como função.

[2complement]: https://en.wikipedia.org/wiki/Two%27s_complement
