# Correr os testes

Os exercícios que forem obtidos com o [cliente de linha de comandos do Exercism](https://exercism.io/cli) são entregues com um mínimo de três ficheiros: um ficheiro `readme.md`, um ficheiro `.dpr` e um ficheiro `.pas`. O ficheiro `.dpr` é o ficheiro de projeto do Delphi e o ficheiro `.pas` é o executor de testes. Carrega o projeto Delphi com um duplo clique no ficheiro `.dpr` ou abrindo o projeto a partir do próprio Delphi. Serás responsável por criar um novo ficheiro `.pas` com o código da tua solução, contra o qual os testes vão ser executados. Consulta o ficheiro `readme.md` para saberes como compilar e executar o teu código.

Todos os testes estão ignorados, exceto o primeiro, para que possas começar a trabalhar. Para continuares, basta comentar o atributo `[Ignore]` do teste para começares a trabalhar nele.

Certifica-te de que o [DUnitX](https://github.com/VSoftTechnologies/DUnitX) está instalado, caso ainda não o tenhas instalado com a configuração acima.
