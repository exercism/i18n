# Classes com estado

```sather
class SCOREBOARD is

   attr home_team, away_team : STR;
   attr home_score, away_score : INT;

   create(home, away : STR) : SAME is
      board ::= new;
      board.home_team := home;
      board.away_team := away;
      return board;
   end;

   home_goal is home_score := home_score + 1; end;

end; -- class SCOREBOARD
```

## attr, readonly attr, private attr

| Escrito | Lido de fora | Alterado de fora |
| --- | --- | --- |
| `attr x : INT` | sim | sim |
| `readonly attr x : INT` | sim | não |
| `private attr x : INT` | não | não |

`readonly` é a opção a usar por defeito. Deixa qualquer pessoa ver a pontuação e exige que a alteração passe por `home_goal`, que é onde estão as regras da pontuação.

## create e new

`new` cria um objeto desta classe com todos os atributos vazios. Só pode ser usado dentro da classe.

`create` é uma rotina normal com um nome combinado: `#C(args)` é exatamente `C::create(args)`. Uma classe pode ter várias, distinguidas pelos seus argumentos, e uma classe sem nenhuma simplesmente não pode ser criada com `#`.

## SAME

`SAME` designa a classe em que está escrito. Em `create`, é o tipo de retorno; também pode ser usado num argumento, e é o que faz com que uma rotina herdada se refira à classe que herda e não àquela de onde veio.

## Rotinas sem tipo de retorno

```sather
   home_goal is
      home_score := home_score + 1;
   end;
```

Sem `:` e sem tipo. Uma rotina destas é chamada como instrução e não pode aparecer numa expressão. É sinal de que o objetivo da chamada é a alteração que ela provoca.

## self

Dentro de uma rotina, `self` é o objeto sobre o qual a rotina foi chamada. Raramente se escreve, porque um atributo ou uma rotina mencionados apenas pelo nome já se referem aos de `self`. É necessário quando o objeto tem de ser passado adiante ou devolvido:

```sather
   with_goal : SAME is
      home_score := home_score + 1;
      return self;
   end;
```

`self`, `new`, `void`, `result`, `value` e `out` são todas palavras que o Sather reservou, e nenhuma pode ser usada como um nome teu.

## Referência, não valor

Acede-se a um objeto através de uma referência. Dois nomes para o mesmo placard veem a mesma pontuação:

```sather
   a ::= #SCOREBOARD("Vixens", "Magpies");
   b ::= a;         -- not a copy
   b.home_goal;
   a.home_score     -- 1
```

`immutable class`, mais à frente, é a forma de obter o outro comportamento.
