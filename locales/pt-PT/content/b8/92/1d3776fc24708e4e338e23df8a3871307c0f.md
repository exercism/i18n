# Introdução

## Verdadeiro e falso

Os estados lógicos verdadeiro e falso são representados por `true` e `false` em Ruby.
Podem ser usados como literais por si só ou como resultado de métodos lógicos ou de comparação.

```ruby
happy = true
sad = false

true && false
# => false

1 < 2
# => true
```

## _Truthy_ e _falsey_

Ao avaliar objetos em condicionais `if` ou noutros contextos do tipo Boolean, todos os objetos são avaliados como _truthy_, **exceto** `false` e `nil`.

## Fluxo de controlo

As avaliações _truthy_ e _falsey_ são úteis no contexto do fluxo de controlo.
Tal como acontece nas linguagens procedurais, o Ruby tem uma construção `if`...`else`, mas pode ser mais comum usar `if` como uma instrução de "guarda" que modifica a avaliação de uma expressão.

```ruby
def falsey
  nil || false
end

def truthy
  not falsey
end

if truthy
  # this block is evaluated
end

if falsey
  # this block is not evaluated
else
  # this block is evaluated
end

1 + 1 if truthy
# this will evaluate and return 2

2 + 2 if falsey
# the numbers are not added because of the modifier, nil is returned
```

O Ruby disponibiliza `unless` para tornar o código mais fácil de ler.
Por exemplo, em vez de `eat_desert if not too_full`, também podemos escrever `eat_desert unless too_full`.

```ruby
3 + 3 unless truthy
# the numbers are not added because of the modifier, nil is returned

4 + 4 unless falsey
# this will evaluate and return 8
```
