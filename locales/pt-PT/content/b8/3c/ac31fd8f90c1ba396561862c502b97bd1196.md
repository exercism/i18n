# Introdução aos arrays

Em Java, os arrays (vetores) são uma forma de armazenar vários valores do mesmo tipo numa única estrutura.
Ao contrário de outras estruturas de dados, os arrays têm um tamanho fixo depois de criados.
Podes atribuir elementos a um array ou obtê-los a partir dele através de um índice.
Os arrays em Java usam indexação a partir do zero: o índice do primeiro elemento é 0, o do segundo é 1, etc.

Aqui está a sintaxe padrão para inicializar um array:

```java
type[] variableName = new type[size];
```

O `type` é o tipo dos elementos do array, que pode ser um tipo primitivo (por exemplo, `int`) ou uma classe (por exemplo, `String`).

O `size` é o número de elementos que este array vai conter (o qual não pode ser alterado mais tarde).
Depois de criar o array, os elementos são inicializados com os seus valores predefinidos (normalmente `0`, `false` ou `null`).

```java
// Declare array with explicit size (size is 2)
int[] twoInts = new int[2];
```

Os arrays também podem ser definidos com uma notação abreviada que te permite criar o array e definir o seu valor ao mesmo tempo:

```java
// Two equivalent ways to declare and initialize an array (size is 3)
int[] threeIntsV1 = new int[] { 4, 9, 7 };
int[] threeIntsV2 = { 4, 9, 7 };
```

Como o compilador já consegue determinar quantos elementos o array terá, o comprimento pode ser omitido.

Os elementos do array podem ser atribuídos e acedidos através de uma notação de índice com parênteses retos:

```java
// Assign second element by index
twoInts[1] = 8;

// Retrieve the second element by index and assign to the int element
int secondElement = twoInts[1];
```

Aceder a um índice fora dos índices válidos do array resulta numa `IndexOutOfBoundsException`.

Podes manipular arrays chamando os métodos ou as propriedades de uma instância de array, ou usando os métodos estáticos definidos na classe `Arrays` (normalmente só usados em código genérico).
A propriedade `length` contém o comprimento de um array.
Podes aceder-lhe assim:

```java
int arrayLength = someArray.length;
```

O Java também disponibiliza uma classe utilitária muito útil, [`java.util.Arrays`](https://docs.oracle.com/en/java/javase/11/docs/api/java.base/java/util/Arrays.html), que tem muitos métodos úteis relacionados com arrays (por exemplo, `Arrays.equals`).

O Java também suporta [arrays multidimensionais](https://www.programiz.com/java-programming/multidimensional-array) como `int[][] arr = new int[3][4];`, que podem ser muito úteis.

O facto de um array também ser uma _coleção_ significa que, além de acederes a valores por índice, podes iterar sobre _todos_ os seus valores usando um ciclo `for-each`:

```java
char[] vowels = { 'a', 'e', 'i', 'o', 'u' };

for(char vowel: vowels) {
    // Output the vowel
    System.out.print(vowel);
}

// => aeiou
```

Se quiseres mais controlo sobre quais valores iterar, podes usar um ciclo `for`:

```java
char[] vowels = { 'a', 'e', 'i', 'o', 'u' };

for (int i = 0; i < 3; i++) {
    // Output the vowel
    System.out.print(vowels[i]);
}

// => aei
```
