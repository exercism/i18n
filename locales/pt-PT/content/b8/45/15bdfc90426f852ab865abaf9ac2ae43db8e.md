# Introdução

## Números

Em F# existem dois tipos diferentes de números:

- Inteiros: números sem algarismos à direita do separador decimal (números sem parte fracionária). Alguns exemplos são `-6`, `0`, `1`, `25`, `976` e `500000`.
- Números de vírgula flutuante: números com zero ou mais algarismos à direita do separador decimal. Alguns exemplos são `-2.4`, `0.1`, `3.14`, `16.984025` e `1024.0`.

Os dois tipos numéricos mais comuns em F# são `int` e `float`. Um `int` é um inteiro de 32 bits e um `float` é um número de vírgula flutuante de 64 bits.

A aritmética faz-se com os operadores aritméticos habituais. Os números podem ser comparados com os operadores de comparação numérica habituais e com os operadores de igualdade (`=`) e de desigualdade (`<>`).

A conversão entre tipos de números faz-se através de operadores de conversão incorporados. Estes operadores de conversão têm o nome do tipo para o qual vão converter. O F# _não_ suporta conversão automática entre tipos de números.

## Condicionais

A forma mais comum de executar código condicionalmente no F# é usar uma expressão `if/elif/else`:

```fsharp
if x = 5 then
    printfn "Expression to evaluate when x equals 5"
elif x > 7 then
    printfn "Expression to evaluate when x greater than 7"
else
    printfn "Expression to evaluate in all other cases"
```

As condições usadas numa expressão `if/elif/else` têm de ser do tipo `bool`. O F# não tem o conceito de valores _truthy_.
