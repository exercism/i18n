# Introdução

O [pacote `strings`](https://pkg.go.dev/strings) disponibiliza funções para trabalhar com strings.
Abaixo estão algumas das funções do pacote; consulta a documentação para ver as restantes!

| Categoria             | Função                                              | Objetivo                                                            |
| --------------------- | --------------------------------------------------- | ------------------------------------------------------------------- |
| Conversão de maiúsculas/minúsculas | [ToLower](https://pkg.go.dev/strings#ToLower) | Converter uma string em minúsculas                                  |
| Conversão de maiúsculas/minúsculas | [ToUpper](https://pkg.go.dev/strings#ToUpper) | Converter uma string em maiúsculas                                  |
| Pesquisa              | [Contains](https://pkg.go.dev/strings#Contains)     | Verificar se uma string contém uma substring específica             |
| Pesquisa              | [Count](https://pkg.go.dev/strings#Count)           | Contar as ocorrências não sobrepostas de uma substring              |
| Pesquisa              | [HasPrefix](https://pkg.go.dev/strings#HasPrefix)   | Verificar se uma string começa com uma substring específica         |
| Pesquisa              | [HasSuffix](https://pkg.go.dev/strings#HasSuffix)   | Verificar se uma string termina com uma substring específica        |
| Pesquisa              | [Index](https://pkg.go.dev/strings#Index)           | Devolver o índice da primeira ocorrência de uma substring, ou -1    |
| Modificação           | [Replace](https://pkg.go.dev/strings#Replace)       | Substituir até n ocorrências de uma substring                       |
| Modificação           | [ReplaceAll](https://pkg.go.dev/strings#ReplaceAll) | Substituir todas as ocorrências de uma substring                    |
| Modificação           | [TrimSpace](https://pkg.go.dev/strings#TrimSpace)   | Remover os espaços em branco no início e no fim                     |
| Divisão ou junção     | [Fields](https://pkg.go.dev/strings#Fields)         | Dividir uma string em palavras pelos espaços em branco              |
| Divisão ou junção     | [FieldsSeq](https://pkg.go.dev/strings#FieldsSeq)   | Obter cada palavra uma de cada vez                                  |
| Divisão ou junção     | [Join](https://pkg.go.dev/strings#Join)             | Juntar um slice de strings com um separador                         |
| Divisão ou junção     | [Split](https://pkg.go.dev/strings#Split)           | Dividir uma string em partes por um separador                       |
| Divisão ou junção     | [SplitSeq](https://pkg.go.dev/strings#SplitSeq)     | Obter cada parte uma de cada vez                                    |

```go
import (
    "fmt"
    "strings"
)

// Case conversion
strings.ToLower("Gopher")              // "gopher"
strings.ToUpper("Gopher")              // "GOPHER"

// Searching
strings.Contains("Apple", "le")        // true
strings.Index("Apple", "le")           // 3
strings.Index("Apple", "xyz")          // -1
strings.Count("test", "t")             // 2
strings.HasPrefix("Gopher", "Go")      // true
strings.HasSuffix("Gopher", "er")      // true

// Modifying
strings.TrimSpace("  hello  ")         // "hello"
strings.Replace("aabbcc", "b", "x", 1) // "aaxbcc"
strings.ReplaceAll("aabbcc", "b", "x") // "aaxxcc"

// Splitting or Joining
strings.Fields("  a b\tc  ")               // []string{"a", "b", "c"}
strings.Split("a,b,c", ",")                // []string{"a", "b", "c"}
strings.Join([]string{"a", "b", "c"}, ",") // "a,b,c"

// You do not need to worry about this range syntax yet.
// It is covered later in the range iteration concept.
for word := range strings.FieldsSeq("  a b\tc  ") {
    fmt.Println(word)
}
// Output:
// a
// b
// c

for part := range strings.SplitSeq("a,b,c", ",") {
    fmt.Println(part)
}
// Output:
// a
// b
// c
```
