# Anexo às instruções

## Dicas

Podes pensar nesta estrutura de dados como uma [`Rose Tree`](https://en.wikipedia.org/wiki/Rose_tree).
Recebes um tipo de dados `'a tree` que representa esta estrutura de dados.

**Notas**

- Neste exercício, `Empty` representa `null`
- A lista aninhada é representada por `List [...]`.
- O exemplo de entrada é representado por `List [Elem 1, List [Elem 2, Elem 3, Empty, Elem 4], List [Empty], Elem 5]`
