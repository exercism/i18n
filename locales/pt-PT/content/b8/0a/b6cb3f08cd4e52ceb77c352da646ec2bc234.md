# Dicas

## 1. Encontra a carta no baralho

- Existe um [método integrado][index] que consegue encontrar o primeiro elemento da coleção que cumpre a condição especificada no bloco e devolver o seu índice, ou `nil` se não for encontrado nenhum elemento.

## 2. Coloca todos os carateres em maiúscula

- Existe um [método integrado][map] para transformar todos os elementos da coleção.
- Existe um [método integrado][capitalize] para capitalizar as palavras de uma `String`.

## 3. Calcula o nível de poder de todas as cartas

- Podes usar o [método `sum`] para calcular o nível de poder total de todas as cartas.
- O método `sum` também pode aceitar um bloco para transformar os elementos antes de os somar.

## 4. Descodifica uma carta

- Existe um [método integrado][each_char_with_index] para iterar sobre os carateres de uma `String` com um índice.
