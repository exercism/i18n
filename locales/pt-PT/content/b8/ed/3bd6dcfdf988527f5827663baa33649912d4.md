# Sobre

Às vezes não precisas do custo extra de criar um objeto com estado.
Nesses casos, podes usar um `module`.

Um módulo é muito semelhante a uma classe (na verdade, `Module` é o antecessor de `Classes` na hierarquia de objetos). A principal diferença é que, em vez de usarmos métodos de instância, usamos métodos de classe.
Os métodos de classe começam por `self.` e são chamados diretamente num módulo.

Por exemplo:

```ruby
module Speaker
  def self.echo(something)
    "#{something} ... #{something}"
  end
end

Speaker.echo("Hello")   #=> "Hello ... Hello"
```
