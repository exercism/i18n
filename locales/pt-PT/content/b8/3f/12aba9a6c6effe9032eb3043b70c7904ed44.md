# Roteiro

Este documento apresenta uma visão geral dos principais temas em que os contribuidores e os responsáveis pela manutenção provavelmente se vão focar nos próximos meses.

## Visão geral dos temas

- Melhorar os exercícios de conceito existentes (ver [questão de acompanhamento](https://github.com/exercism/javascript/issues/1415))
- Criar exercícios de conceito adicionais (ver a visão geral do programa abaixo)
- Definir as listas `prerequisites` e `practices` para todos os exercícios de prática (ver [questão de acompanhamento](https://github.com/exercism/javascript/issues/960))
- Melhorar o [test runner](https://github.com/exercism/javascript-test-runner/)
  - Corrigir bugs
  - Saída mais agradável quando as variáveis são definidas fora do caso de teste
  - Ligar os testes às tarefas
- Adicionar comentários do [analyzer](https://github.com/exercism/javascript-analyzer/) a todos os exercícios de conceito existentes
- Melhorar/atualizar/rever várias documentações (diretrizes de contribuição, como implementar um exercício de conceito, docs, exercises/shared, pasta de referência)

## Visão geral do programa

### Conceitos que já existem ou para os quais já foi criada uma questão

- `basics`
- `strings` (incl. métodos de string)
- `numbers`
- `booleans`
- `conditionals` (if/else) e `comparison`
- `for-loops` e `increment-decrement`
- `while-loops`
- `conditionals-switch`
- `objects` (como coleções de pares chave-valor)
- `null-undefined`
- `functions`
- `type-conversion` (incl. truthy/falsy)
- `template-strings`
- `conditionals-ternary`
- `callbacks`
- `arrow-functions`
- `classes` e `prototypes`
- `inheritance`
- `errors`
- `arrays` (incl. manipulação de arrays com push, pop, etc.)
- `array-loops`
- `array-analysis`
- `array-transformation`
- `array-destructering`
- `rest-and-spread`
- `promises`
- `recursion`
- `closures`
- `sets`
- `randomness`
- `regular-expressions`
- `dates`
- `async-await`
- `type-checking`

### Possíveis conceitos futuros

- getters/setters, flags, descritores
- `proxy`

- `immutability` (incl. freeze; pode ser combinado com o conceito de variáveis)
- `object-helpers` (p. ex. Object.assign)
- carateres e codepoints
- this e âmbito (incl. call/bind)
- iteradores e "enumeradores"
- geradores/yield
- geradores e iteradores assíncronos
- operadores bit a bit
- módulos, imports, exports, imports dinâmicos
- duck typing
- API de internacionalização
- `bigint`
- `symbol`
- comentários JSDoc
- assincronia, event loop
- setTimeout/setInterval
- eventos
- "tudo é um objeto", às vezes (relação entre funções, arrays e primitivos e os objetos, p. ex. tipos boxed)
