# Sobre

[Intervalos][range] representam um intervalo entre dois valores.
Os intervalos são habitualmente usados com tipos como `Int`, `String` e `Character` para iterar sobre sequências, obter fatias de coleções ou verificar se um valor está dentro dos limites.

O Swift disponibiliza dois operadores principais de intervalos:

- **Operador de intervalo fechado (`...`)**: inclui o valor inicial e o final (`1...5` inclui 1, 2, 3, 4 e 5).
- **Operador de intervalo semiaberto (`..<`)**: inclui o valor inicial mas exclui o final (`1..<5` inclui 1, 2, 3 e 4).

```swift
let closed = 1...5
let halfOpen = 1..<5
```

~~~~exercism/note
Quando chamas um método diretamente num literal de intervalo, coloca a expressão do intervalo entre parênteses para que o compilador avalie primeiro o intervalo:

```swift
(1...5).contains(3) // Returns true
// 1...5.contains(3) // Error: value of type 'Int' has no member 'contains'
```
~~~~

## Converter um intervalo num Array

Podes converter um intervalo de números num `Array` com o inicializador `Array(_:)`:

```swift
let range = 1...5
let numbers = Array(range)
// numbers is [1, 2, 3, 4, 5]
```

## Obter fatias de um Array com intervalos

Podes usar intervalos para extrair subsecções de um array:

```swift
let array = [10, 20, 30, 40, 50]
let slice = array[1...3]
// slice contains [20, 30, 40]
```

## Propriedades e métodos dos intervalos

As operações mais comuns com intervalos incluem:

| Membro                  | Descrição                                                  | Exemplo                              |
| ----------------------- | ---------------------------------------------------------- | ------------------------------------ |
| `count`                 | Devolve o número de elementos do intervalo                 | `(1...5).count` devolve `5`          |
| [`contains(_:)`][contains] | Devolve `true` se o intervalo incluir o valor indicado  | `(1...5).contains(3)` devolve `true` |

## Intervalos de um só lado

O Swift também suporta intervalos de um só lado (parciais), em que omites o valor inicial ou o final:

- `array[2...]`: do índice 2 até ao fim da coleção.
- `array[...2]`: do início da coleção até ao índice 2, inclusive.
- `array[..<2]`: do início da coleção até ao índice 2 (sem o incluir).

## Intervalos de String e Character

Também podes criar intervalos entre carateres ou strings que estão em conformidade com `Comparable`:

```swift
let letters = "a"..."z"
print(letters.contains("m")) // Prints true
print(letters.contains("A")) // Prints false
```
