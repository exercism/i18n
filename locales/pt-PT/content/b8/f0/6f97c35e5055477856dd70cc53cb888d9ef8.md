# Dicas

## Geral

- `n <iota>` produz uma sequência virtual dos números inteiros
  `0, 1, …, n-1`.
- `map` (em [`sequences`][sequences]) executa a tua quotation em cada
  elemento e recolhe os resultados.
- `>string` (em [`strings`][strings]) transforma uma sequência de
  códigos de caráter numa string.

## 1. Bandeirinhas do alfabeto

- `CHAR: a` é interpretado como o número inteiro `97`. Se somares o
  índice `i`, obténs o código da `i`-ésima letra minúscula.

## 2. Bandeirinhas de contagem

- `mod` (em [`math`][math]) devolve o resto da divisão inteira.
- Os códigos de caráter dos algarismos são consecutivos (`CHAR: 0`,
  `CHAR: 1`, …), por isso `CHAR: 0 +` transforma um número inteiro
  em `0..9` no algarismo correspondente.

## 3. Bandeirinhas às riscas

- `even?` (em [`math`][math]) é `t` para números inteiros pares e `f`
  caso contrário.
- Dentro da quotation de `map`, o `if` escolhe um de dois literais de
  caráter com base no teste.

## 4. Bandeirinhas com marcadores

- `5 mod zero?` é `t` exatamente nas posições `0`, `5`, `10`, … .

## 5. Bandeirinhas de vale

- `-5 5 [a..b)` (em [`ranges`][ranges]) é o intervalo semiaberto
  `-5, -4, …, 4`.
- `abs` (em [`math`][math]) transforma um número inteiro negativo no
  seu simétrico positivo, deixando os números inteiros não negativos
  como estão.
