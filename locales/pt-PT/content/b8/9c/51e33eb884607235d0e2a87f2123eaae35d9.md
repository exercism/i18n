# Dicas

- Vais precisar da função `format` neste exercício.

## 1. Formatar valores trimestrais

- A função `format` devolve sempre `nil`, a menos que o parâmetro de stream seja `nil`.
- Podes usar `~A` para formatar um valor.

## 2. O relatório de dois trimestres

- A tua função anterior é perfeita para criar as duas linhas necessárias.
- Podes usar `~%` e `~&` para criar novas linhas.

## 3. Legível para humanos vs. alienígenas de Lisp

- A tua função anterior de formatação de trimestres é perfeita para criar as strings necessárias.
- Podes usar `~S` para formatar valores de forma legível.
