# Introdução

## Boolean em Julia

Os valores verdadeiro ou falso são representados pelo tipo `Bool`.
Contém apenas dois valores: `true` e `false`.

```julia-repl
julia> true
true

julia> false
false
```

## Operadores Boolean

Existem três operadores Boolean em Julia.

O `&&` é o "e" Boolean.
Avalia para `true` se as expressões de *ambos* os lados do `&&` forem `true`.

```julia-repl
julia> true && true
true

julia> true && false
false
```

O `||` é o "ou" Boolean.
Avalia para `true` se uma expressão em *qualquer* dos lados do `||` for `true`.

```julia-repl
julia> true || true
true

julia> false || true
true
```

O `!` é o "não" Boolean.
Inverte os valores `true` e `false`.

```julia-repl
julia> !true
false

julia> !false
true
```

Para expressões mais longas e mais complicadas, o melhor é usar parênteses para deixar bem clara a tua intenção.

```julia-repl
julia> (true || false) && (false && true)
false
```
