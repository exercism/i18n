# Introdução

Uma `string` em Clojure é uma string Java, que é um objeto que representa texto imutável como uma cadeia de carateres Unicode (letras, algarismos, pontuação, etc.) e é definida da seguinte forma:

```clojure
(def fruit "Apple")
```

A biblioteca `clojure.string` disponibiliza muitas funções padrão de manipulação e processamento de strings. Além disso, todos os métodos Java habituais para operar sobre strings estão disponíveis através da interoperabilidade.
