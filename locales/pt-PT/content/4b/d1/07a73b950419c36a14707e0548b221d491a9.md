# Sobre

O PHP disponibiliza vários operadores para realizar operações aritméticas. O PHP segue a ordem de operações matemática habitual para os seus operadores aritméticos. Os operadores que o PHP disponibiliza são:

* Identidade (+)
* Negação (-)
* Adição (+)
* Subtração (-)
* Multiplicação (*)
* Divisão (/)
* Módulo (%)
* Exponenciação (**)

Vamos ver cada um deles e como podem ser usados:

## Identidade (+)

O operador de identidade (+) atua sobre um único valor (operador unário). O resultado é o valor `float` ou `int` da variável.

```php
$value = '42';
$answer = +$value; // 42 (int)
```

## Negação (-)

O operador de negação atua sobre um único valor (operador unário) e devolve o simétrico do valor numérico.

```php
$forward = 65;
$reverse = -$forward; // -65
```

## Adição (+) e subtração (-)

O operador de adição soma os dois valores que estão de cada lado dele, enquanto o operador de subtração subtrai o valor da direita ao valor da esquerda.

```php
$apples = 5;
$yourApples = 0;

$apples = $apples - 2; // 3
$yourApples = $yourApples + 2; 2
```

## Divisão (/)

O operador de divisão dá o resultado da divisão do valor da esquerda pelo valor da direita. Se o valor da direita for 0, provoca um erro `DivisionByZeroError`.

```php
$slicesOfPizza = 8;
$people = 4;
$slicesPerPerson = $slicesOfPizza / $people; // 2
```

## Multiplicação (*)

O operador de multiplicação devolve o resultado da multiplicação dos valores da esquerda e da direita.

```php
$tires = 4;
$priceOfTire = 250;
$totalCost = $tires * $priceOfTire; // 1000
```

## Módulo (%)

O operador de módulo devolve o resto da divisão do valor da esquerda pelo valor da direita. Este operador é muito útil para determinar se um número divide outro sem deixar resto, para saber se um valor é par ou ímpar e para muito mais.

```php
$value = 3;
$isOdd = $value % 2;
if ($isOdd === 1) {
    echo 'Yes, it is odd!';
} else {
    echo 'It is even.';
}
```

## Exponenciação (**)

O operador de exponenciação serve para elevar o valor da esquerda à potência do valor da direita. Antes do PHP 5.6, tinhas de usar a função `pow` para fazer o mesmo.

```php
$sideLength = 13;
$areaOfSquare = $sideLength ** 2; // 169
```

O operador de exponenciação aceita inteiros e números de vírgula flutuante em ambos os lados, por isso podes usá-lo para calcular raízes quadradas (ou outras raízes) ou valores exponenciais mais complexos.

```php
$squareArea = 144;
$side = $squareArea ** .5; // 12
```

## Ordem das operações

O PHP segue a ordem de operações habitual da matemática. Isto significa que, em vez de as operações serem feitas da esquerda para a direita, cada operador tem uma precedência e as operações são resolvidas de acordo com essa precedência. A ordem das operações é:

* parênteses
* exponenciação
* multiplicação, divisão
* adição, subtração

A multiplicação e a divisão têm o mesmo nível de precedência entre si. Do mesmo modo, a adição e a subtração têm o mesmo nível de precedência.

Isto significa que o valor abaixo seria 17 em vez de 10, uma vez que a multiplicação tem uma precedência mais alta do que a adição:

```php
$value = 2 + 3 * 5;
```

O PHP também disponibiliza vários operadores de atribuição úteis que combinam operadores aritméticos com a atribuição, quando fazes uma operação sobre uma variável e atribuis o resultado de volta à própria variável. Estes serão abordados no conceito `Assignment Operators`.
