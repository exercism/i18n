# Pausar as contribuições da comunidade

Alguns repositórios não têm recursos para fazer a triagem e a revisão de issues ou pull requests de utilizadores que não são maintainers.
A pausa das soluções da comunidade.
Se um repositório tiver este fluxo de trabalho ativado, deixa automaticamente um comentário numa nova issue ou num novo pull request de alguém que _não_ seja membro da organização do Exercism no GitHub.
O comentário sugere ao utilizador que abra primeiro um tópico no fórum do Exercism.

## Ativar o fluxo de trabalho

Adiciona o [ficheiro .github/workflows/pause-community-contributions.yml](https://github.com/exercism/github-actions/blob/b5424c17f661f5529493258a1ad480013351aa9e/.github/workflows/pause-community-contributions.yml) ao teu repositório.

## Desativar o fluxo de trabalho

Remove o ficheiro do fluxo de trabalho do teu repositório.

## Fonte

O fluxo de trabalho está definido no ficheiro `.github/workflows/pause-community-contributions.yml`.
