# Introdução

## Booleanos em Julia

Os valores booleanos são representados pelo tipo `Bool`.
Contém apenas dois valores: `true` e `false`.

```julia-repl
julia> true
true

julia> false
false
```

## Operadores Boolean

Há três operadores Boolean em Julia.

`&&` é o operador Boolean "e".
É avaliado como `true` se as expressões em *ambos* os lados de `&&` forem `true`.

```julia-repl
julia> true && true
true

julia> true && false
false
```

`||` é o operador Boolean "ou".
É avaliado como `true` se uma expressão em *qualquer* dos lados de `||` for `true`.

```julia-repl
julia> true || true
true

julia> false || true
true
```

`!` é o operador Boolean "não".
Troca os valores `true` e `false`.

```julia-repl
julia> !true
false

julia> !false
true
```

Para expressões mais longas e complicadas, é melhor usares parênteses para deixares clara a tua intenção.

```julia-repl
julia> (true || false) && (false && true)
false
```
