# Sobre a conversão de tipos

O Go exige uma conversão explícita entre tipos diferentes.
Por exemplo, isto provoca um erro de compilação:

```go
var x int = 42
var f float64 = x // compiler error x is an int not a float64
```

A conversão entre tipos (também conhecida como **casting**) faz-se através de uma função com o nome do tipo de destino.
Um valor `v` é convertido para o tipo `T` usando `T(v)`.
Por exemplo, para converter um `int` num `float64`, tens de fazer o seguinte:

```go
var x int = 42 // x has type int
f := float64(x) // f has type float64 (ie. 42.0)
```

O mesmo se aplica a quaisquer tipos personalizados:

```go
type Id int
var number int = 121 // number has type int
userId := Id(number) // userId now has type Id
```

## Conversão entre tipos primitivos e strings

Existe um pacote `strconv` para converter entre tipos primitivos (como `int`) e `string`.

```go
import "strconv"

var intString string = "42"
var i, err = strconv.Atoi(intString)

var number int = 12
var s string = strconv.Itoa(number)
```

AVISO: usar o método de casting habitual não tem este comportamento.
Por exemplo:

```go
var num int = 65
str := string(num) // str is now "A" not "65"
```

Aqui ficam alguns dos outros métodos de conversão mais comuns:

| Método      | Objetivo                     |
| ----------- | ---------------------------- |
| ParseBool   | Converte `string` em `bool`  |
| FormatBool  | Converte `bool` em `string`  |
| ParseFloat  | Converte `string` em `float` |
| FormatFloat | Converte `float` em `string` |
| ParseInt    | Converte `string` em `int`   |
| FormatInt   | Converte `int` em `string`   |
