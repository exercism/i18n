# Anexo às instruções

## Adicionar um método à struct Int

Este exercício centra-se em adicionar métodos à struct `Int` do Crystal.
Para isso, tens de definir uma struct com o nome `Int`.
E colocar o método dentro dessa struct.

```crystal
struct Int
  # your solution here
end
```

Podes encontrar o código-fonte da classe `Int` [aqui][int].
