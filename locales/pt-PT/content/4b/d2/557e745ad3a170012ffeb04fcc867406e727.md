# Instalação

## Utilizadores de Windows

Instala o [Windows Subsystem for Linux][wsl-link] e consulta a secção seguinte.

## Utilizadores de Linux/Mac

### Instalar com o brew

Esta é a forma mais fácil de instalar o Chapel.
Dá-te uma instalação básica e funcional, adequada para percorreres o track do Exercism.
Utilizadores mais avançados podem querer compilar o Chapel a partir do código-fonte (secção seguinte).

0. Se ainda não o fizeste, instala o gestor de pacotes [brew][brew-link].
1. Primeiro, certifica-te de que o brew está atualizado, correndo `brew update`
2. Instala o Chapel correndo `brew install chapel`
3. Verifica se a instalação foi bem-sucedida correndo `chpl --version`

Isto instala o compilador de Chapel (`chpl`), o gestor de pacotes `mason`, que vamos usar para correr os testes, e a ferramenta de geração de documentação `chpldoc`. Esta última não é necessária para o Exercism, mas é bom tê-la se (quando :) ) quiseres desenvolver as tuas próprias bibliotecas em Chapel.

### Compilar o Chapel a partir do código-fonte

Utilizadores mais avançados podem querer compilar o próprio Chapel a partir do código-fonte. Para isso,

1. Instala os [pré-requisitos][prereqs-link]
2. [Descarrega][download-link] o arquivo da versão mais recente do Chapel e extrai-o.
3. Primeiro, tens de preparar a instalação e configurar o local onde queres instalar o Chapel.
Isto pode ser feito correndo o script `configure` fornecido.
Basta correr

```
./configure
```

para instalar os binários, as bibliotecas e os ficheiros partilhados em `/usr/local/`; podes alterar isto com a opção `--prefix`.
Por exemplo, se quiseres instalar o Chapel em `~/.chapel`, podes fazer

```
./configure --prefix=~/.chapel
```

4. Para instalar o compilador e as ferramentas, corre 

```
make
make mason
make chpldoc
make install
```

5. Certifica-te de que a pasta `/dir/for/install/bin` está na tua variável `PATH`. 

Para mais informações sobre as diferentes formas de instalar o Chapel e trabalhar a partir do código-fonte, consulta a página [Compilar o Chapel][building-link] da documentação.
