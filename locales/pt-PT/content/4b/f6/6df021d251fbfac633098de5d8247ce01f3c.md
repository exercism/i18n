# Parâmetros variádicos

Os [_parâmetros variádicos_][variadic-parameters] em Swift permitem que sejam passados zero ou mais valores do mesmo tipo para um único parâmetro de uma função.
Isto é indicado acrescentando `...` à anotação de tipo do parâmetro.

Estes valores são automaticamente agrupados num array com elementos do mesmo tipo que o tipo do parâmetro variádico.

```swift
func geometricMean(_ numbers: Double...) -> Double {
  var total = 1.0
  for number in numbers {
      total *= number
  }
  return pow(total, 1.0 / Double(numbers.count))
}

geometricMean(1, 2, 3, 4, 5)
// Returns 2.605171084697352
```

Quando usas parâmetros variádicos, o Swift tem duas limitações:

1. O Swift só permite que as funções tenham um parâmetro variádico. Foi decidido que esta restrição será removida numa versão futura do Swift, mas, para já, continua em vigor.
2. Se uma função tiver parâmetros que se seguem ao parâmetro variádico na definição, o primeiro parâmetro a seguir ao parâmetro variádico tem _obrigatoriamente_ de ter uma etiqueta de argumento.

[variadic-parameters]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/functions/#Variadic-Parameters
