# Instruções

Vais inicializar buffers vazios e listar os cinco primeiros números, ou elementos, da sequência de Fibonacci.

A sequência de Fibonacci é um conjunto de números em que o elemento seguinte é a soma dos dois anteriores. Começamos a sequência pelo um. Assim, os dois primeiros elementos são 1 e 1.

## 1. Cria um buffer com `count` zeros.

Cria uma função que cria um buffer com `count` zeros.

```rust
let my_buffer = create_buffer(5);
// [0, 0, 0, 0, 0]
```

## 2. Lista os cinco primeiros elementos da sequência de Fibonacci

Cria uma função que devolve os cinco primeiros números da sequência de Fibonacci.
Os seus cinco primeiros elementos são `1, 1, 2, 3, 5`

```rust
let first_five = fibonacci();
// [1, 1, 2, 3, 5]
```
