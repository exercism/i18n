# Testes

Podes correr os conjuntos de testes dos exercícios de PureScript a partir do diretório do exercício com a ferramenta spago:

    cd <exercism-workspace>/purescript/<exercise name>
    spago test

em que `<exercism-workspace>` é o diretório de trabalho da CLI.

Por exemplo:

    cd ~/exercism/purescript/accumulate
    spago test
