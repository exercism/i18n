# Sobre

As estruturas de dados que podem conter zero ou mais elementos são conhecidas como _coleções_.
Um **array** (ou _vetor_) em Ruby é uma coleção que mantém a ordem pela qual os seus objetos são adicionados.
Os arrays podem conter qualquer objeto.
Os objetos podem ser adicionados a um array ou obtidos a partir dele através de um índice.
A indexação de arrays em Ruby é baseada em zero, o que significa que o índice do primeiro elemento é sempre zero:

```ruby
# Declare an array containing two values
two_ints = [1,2]

# Assign first and second element by index
two_ints[0] = 7
two_ints[1] = 8

# Retrieve the second element by index
two_ints[1] # => 8

# Check the length of the array
two_ints.size # => 2
```

Em Ruby, existem várias formas de criar um Array:

- Usando o construtor literal `[]` _(mais comum)_
- Chamando explicitamente `Array.new`
- Chamando o método `Array()` do Kernel

O método `Array.new` suporta dois argumentos opcionais: o tamanho inicial do array e um objeto predefinido.

Quando são fornecidos um tamanho e um valor predefinido, o array é preenchido com `size` cópias do objeto predefinido.

```ruby
a = Array.new(2, Hash.new)
# => [{}, {}]
```

Como todos os elementos do Array armazenam o mesmo hash, alterações a um deles afetam todos.

```ruby
a[0]['cat'] = 'feline'
a # => [{"cat"=>"feline"}, {"cat"=>"feline"}]

a[1]['cat'] = 'Felix'
a # => [{"cat"=>"Felix"}, {"cat"=>"Felix"}]
```

Se queres várias cópias, deves usar a versão com bloco, que usa o resultado desse bloco cada vez que um elemento do array precisa de ser inicializado:

```ruby
a = Array.new(2) {Hash.new}
a[0]['cat'] = 'feline'
a # => [{"cat"=>"feline"}, {}]
```

Outra característica dos arrays em Ruby é que eles incluem o módulo [Enumerable][enumerable-module], que adiciona muitos métodos úteis para iterar, procurar, ordenar, filtrar, etc. elementos de um array.

[enumerable-module]: https://docs.ruby-lang.org/en/master/Enumerable.html
[for-loop]: https://launchschool.com/books/ruby/read/loops_iterators#forloops
