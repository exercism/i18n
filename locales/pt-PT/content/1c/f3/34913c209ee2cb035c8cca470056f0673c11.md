# Instruções

Neste exercício vais escrever código para manteres o registo de indicativos de chamada internacionais através de um hashmap de indicativos de chamada internacionais.

O mapa usa um número inteiro para as chaves (o indicativo de chamada) e uma string (o nome do país) para os valores.

Tens 11 tarefas que envolvem indicativos de chamada.

## 1. Cria um hashmap pré-preenchido

Existe um hashmap pré-preenchido que contém os seguintes 3 indicativos de chamada: "United States of America", com o indicativo 1, "Brazil", com o indicativo 55, e "India", com o indicativo 91. Define a var `countries` para guardar o hashmap pré-preenchido:

```clojure
countries
;;=> {1 "United States of America", 55 "Brazil", 91 "India"}
```

## 2. Adiciona um país a um mapa

Adiciona "United Kingdom", com o indicativo de chamada 44, ao mapa criado na tarefa 1:

```clojure
(add-country countries 44 "United Kingdom")
;;=> {1 "United States of America", 44 "United Kingdom", 55 "Brazil", 91 "India"}
```

## 3. Obtém o nome do país que corresponde a um indicativo

Obtém o nome do país com o indicativo de chamada 55

```clojure
(country-name countries 55)
;;=> "Brazil"
```

## 4. Atualiza o nome de um país

Altera o nome de "United States of America" para "Les États-Unis":

```clojure
(update-map countries 1 "Les États-Unis")
;;=> {1 "Les États-Unis", 55 "Brazil", 91 "India"}
```

## 5. Verifica se um país existe no mapa

Verifica se existe um registo de Brazil no mapa criado na tarefa 1

```clojure
(code-exists? countries 55)
;;=> true
```

## 6. Tenta atualizar o nome de um país que não está no mapa

Tenta alterar o nome de um país com um indicativo que não está no mapa, por exemplo 999. Isto não deve provocar qualquer alteração no mapa:

```clojure
(update-map countries 999, "Newlands")
;;=> {1 "United States of America", 44 "United Kingdom", 55 "Brazil", 91 "India"}
```

## 7. Remove um país do mapa

Remove India do mapa:

```clojure
(remove-country countries 91)
;;=> {1 "United States of America", 55 "Brazil"}
```

## 8. Encontra o país com o nome mais longo

Percorre os valores do mapa para encontrares o que tem o nome mais longo:

```clojure
(longest-name countries)
;;=> "United States of America"
```
