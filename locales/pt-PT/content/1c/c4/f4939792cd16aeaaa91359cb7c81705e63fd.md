# Instruções

És um observador de aves entusiasta que mantém registo de quantas aves visitaram o teu jardim nos últimos sete dias.

Tens cinco tarefas, todas relacionadas com o número de aves que visitaram o teu jardim.

## 1. Verifica quais foram as contagens da semana passada

Guardas as contagens de aves em formato JSON.
Um array principal armazena arrays de contagens semanais.
Cada contagem semanal é um array de sete números inteiros, um número por cada dia da semana.
Acrescentas sempre as novas semanas ao fim do array principal.
Implementa o filtro que devolve as contagens da semana passada.

```sh
$ cat bird-counting-data.json
[
  ...,
  [0, 2, 5, 3, 7, 8, 4],
  [4, 5, 9, 10, 9, 4, 3]
]

$ jq -f bird-count.jq < bird-counting-data.json
{
  "last_week": [0, 2, 5, 3, 7, 8, 4],
  ...
```

## 2. Verifica quantas aves visitaram ontem o teu jardim

Implementa o filtro que devolve quantas aves visitaram o teu jardim ontem.
As contagens de aves estão ordenadas por dia: o primeiro elemento é a contagem do dia mais antigo e o último elemento é a contagem de hoje.

```jq
$ jq -f bird-count.jq < bird-counting-data.json
{
  ...
  "yesterday": 4,
  ...
```

## 3. Calcula o número total de aves que visitaram o jardim

Implementa o filtro que devolve o número total de aves que visitaram o teu jardim esta semana.

```jq
$ jq -f bird-count.jq < bird-counting-data.json
{
  ...
  "total": 44,
  ...
```

## 4. Calcula o número de dias movimentados

Há dias mais movimentados do que outros.
Um dia movimentado é aquele em que cinco ou mais aves visitaram o teu jardim.
Implementa o filtro que devolve o número de dias movimentados esta semana.

```jq
$ jq -f bird-count.jq < bird-counting-data.json
{
  ...
  "busy_days": 4,
  ...
```

## 5. Verifica se houve algum dia sem aves a visitar o jardim

Implementa o filtro que devolve `true` se, esta semana, houve algum dia em que zero aves visitaram o teu jardim; caso contrário, devolve `false`.

```jq
$ jq -f bird-count.jq < bird-counting-data.json
{
  ...
  "has_day_without_birds": false
}
```
