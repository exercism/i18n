A GNU Affero General Public License é uma licença livre, de copyleft, para software e outros tipos de obras, concebida especificamente para garantir a cooperação com a comunidade no caso de software de servidor de rede.

As licenças da maioria do software e de outras obras práticas destinam-se a retirar-te a liberdade de partilhar e alterar as obras. Pelo contrário, as nossas Licenças Públicas Gerais têm como objetivo garantir-te a liberdade de partilhar e alterar todas as versões de um programa, para assegurar que este se mantém software livre para todos os seus utilizadores.

As nossas Licenças Públicas Gerais destinam-se a assegurar que tens a liberdade de distribuir cópias de software livre (e cobrar por elas, se quiseres), que recebes o código-fonte ou o podes obter se o desejares, que podes alterar o software ou usar partes dele em novos programas livres, e que sabes que podes fazer estas coisas.

Um benefício secundário de defender a liberdade de todos os utilizadores é que as melhorias feitas em versões alternativas do programa, se tiverem uma utilização generalizada, ficam disponíveis para outros programadores as incorporarem. Muitos programadores de software livre sentem-se animados e encorajados pela cooperação resultante. No entanto, no caso do software usado em servidores de rede, este resultado pode não se verificar. A GNU General Public License permite criar uma versão modificada e dar ao público acesso a ela num servidor sem nunca publicar o seu código-fonte.

A GNU Affero General Public License foi concebida especificamente para garantir que, nesses casos, o código-fonte modificado fica disponível para a comunidade. Exige que o operador de um servidor de rede forneça aos utilizadores desse servidor o código-fonte da versão modificada que aí está a ser executada. Por conseguinte, a utilização pública de uma versão modificada, num servidor acessível ao público, dá ao público acesso ao código-fonte da versão modificada.
