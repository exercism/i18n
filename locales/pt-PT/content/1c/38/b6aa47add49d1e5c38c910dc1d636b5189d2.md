# Dicas

- A documentação do pacote `Bitwise` está [aqui][bitwise-docs].

## 1. Desloca os bits para trás

- Há duas funções para deslocar bits para a direita, mas [só uma][bitwise-shiftRightZfBy] insere sempre um 0.

## 2. Ativa alguns bits

- [Uma das funções bit a bit][bitwise-or] coloca sempre um bit a 1 quando os bits de ambos os valores são 1.

## 3. Inverte bits específicos

- Há [uma função bit a bit][bitwise-xor] que inverte um bit onde a máscara é 1.

## 4. Limpa bits específicos

- [Uma das funções bit a bit][bitwise-and] limpa os bits onde o bit da máscara é 0.
- Mas podes ter de a combinar com [outra função][bitwise-complement] para limpar os bits onde a máscara é 1.

## 5. Desencripta uma mensagem

- Aplica as outras funções que escreveste ao valor de entrada pela ordem seguinte, usando o resultado de uma como valor de entrada da seguinte:

1. `setBits`
2. `flipBits`
3. `shiftBack`
4. `clearBits`

Para o passo 4, tens de converter para decimal o número binário com o 1.º e o 5.º bits a 1 (10001).
