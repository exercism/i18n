# Anexo às instruções

## Bónus

Testa a tua função com esta string: `uüu` e vê o que acontece.
Tenta escrever uma função que inverta esta string corretamente.
Dica: grapheme clusters

Para o teste de bónus correr, remove a flag de ignore (`#[ignore]`) do último teste e executa os testes com:

```bash
cargo test --features grapheme
```

Vais precisar de usar bibliotecas externas (um `crate`, no jargão do Rust) para a tarefa de bónus.
Um bom sítio para procurar é o [crates.io](https://crates.io/), o repositório oficial de crates.
Lembra-te de que o nosso test runner só suporta um conjunto limitado de crates.
A lista completa está [neste ficheiro](https://github.com/exercism/rust-test-runner/blob/main/local-registry/Cargo.toml) na secção `[dependencies]`.

[Consulta a documentação](https://doc.rust-lang.org/cargo/guide/dependencies.html) para instruções sobre como usar crates externas nos teus projetos.
