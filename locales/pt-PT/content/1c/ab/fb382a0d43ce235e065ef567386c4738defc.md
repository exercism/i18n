# Anexo às instruções

## Espera, é impossível!

Implementar estas operações de listas sem usar _nenhuma_ função incorporada é praticamente impossível em Roc, porque precisas de uma forma de acrescentar elementos ao fim de uma lista ou de os inserir no início.
Noutras linguagens podes usar operadores como `:` em Haskell ou `+=` em Python, mas em Roc tens de usar as [funções `List`](https://www.roc-lang.org/builtins/main/#Builtin.List).

Por isso, neste exercício podes usar `List.append` (mas evita usar qualquer outra função incorporada).

Muitas linguagens de programação funcional usam listas ligadas como o principal tipo de coleção.
Inserir um elemento no início ou retirar o primeiro elemento de uma lista ligada é eficiente, por isso nessas linguagens implementarias as operações de listas com `List.prepend`.
Em Roc, no entanto, uma `List` é um array (um bloco contíguo de bytes).
Os arrays têm propriedades diferentes das listas ligadas, como a capacidade de aceder eficientemente a elementos por índice e de acrescentar novos elementos.
Por isso, em Roc usamos `List.append` com frequência e raramente usamos `List.prepend`.

## Nomenclatura

O Roc usa nomes ligeiramente diferentes dos que estão listados nas instruções gerais:

- `concat` em vez de `append`
- `join` em vez de `concatenate`
- `len` em vez de `length`
- `fold` em vez de `foldl`
- `fold_rev` em vez de `foldr`

No entanto, os seguintes nomes de funções são padrão em Roc:
- `filter`
- `map`
- `reverse`

## Dica

Experimenta usar:

```roc
match list {
    [] => ...
    [first, .. as rest] => ...
}
```

ou

```roc
match list {
    [] => ...
    [.. as rest, last] => ...
}
```
