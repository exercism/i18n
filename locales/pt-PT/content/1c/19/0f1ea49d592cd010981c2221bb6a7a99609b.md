# Introdução

A maioria dos programas tem dependências de algumas bibliotecas. Gerir essas dependências à mão pode ser penoso. Felizmente, o ecossistema Rust vem de série com o `cargo`! Com o `cargo`, é possível gerir as dependências de um projeto.

Em Rust, vais ver frequentemente pacotes externos a serem chamados "crates". Um crate é uma unidade de compilação em Rust. Um crate pode ser compilado para um binário ou para uma biblioteca.

Na maior parte dos casos, adicionar uma dependência externa é tão simples como acrescentar uma linha ao teu ficheiro `Cargo.toml`.

Neste exercício, as dependências [`enum-iterator`](https://docs.rs/enum-iterator/1.2.0/enum_iterator/) e [`int-enum`](https://docs.rs/int-enum/0.5.0/int_enum/) foram adicionadas para ti.
