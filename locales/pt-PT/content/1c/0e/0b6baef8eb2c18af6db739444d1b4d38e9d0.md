# Sobre

[Nil][nil-dictionary] é uma palavra inglesa que significa «nada» ou «zero». Em Elixir, `nil` é um valor especial que representa uma _ausência_ de valor.

```elixir
# I do not have a favorite color
favorite_color = nil
```

`nil` é um átomo, mas normalmente escreve-se `nil`, não `:nil`. Os valores Boolean `true` e `false` também são átomos.

[//]: # (elixir-formatter-disable-next-block)

```elixir
nil === :nil
# => true

true === :true
# => true
```

Podes verificar se o valor de uma variável é `nil` com o [`==`][kernel-equal], com correspondência de padrões, ou com a [guarda `is_nil`][kernel-is-nil].

```elixir
def call(phone_number) do
  if phone_number == nil do
    :error
  end
end
```

```elixir
def call(phone_number) when is_nil(phone_number) do
  :error
end
```

```elixir
def call(nil) do
  :error
end
```
