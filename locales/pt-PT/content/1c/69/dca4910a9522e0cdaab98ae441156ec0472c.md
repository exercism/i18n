# Introdução

O tipo `char` do F# é um valor de 16 bits que representa os componentes endereçáveis mais pequenos do texto, imutável por predefinição.

Os `char` podem ser definidos como literais com aspas simples:

```fsharp
let ch = 'A'
// => val ch: char = 'A'
```

Strings são uma sequência de carateres.

Podes obter um `char` individual a partir de uma string com indexação (a começar em zero):

```fsharp
"Exercism"[4] //  =>  'c'
```

Iterar sobre uma string devolve um `char` em cada passo.

O próximo exemplo usa uma função de ordem superior e uma função anónima, por conveniência.
Estes conceitos serão abordados devidamente mais adiante no programa, mas, por agora, são uma forma concisa de escrever um ciclo sobre os carateres de uma string.

```fsharp
Seq.map (fun c -> c, int c) "F#"  //  =>  [('F', 70); ('#', 35)]
```

Como mostrado acima, um `char` pode ser convertido no seu valor `int`.
Isto também funciona (*pelo menos algumas vezes*) noutros sistemas de escrita:

```fsharp
Seq.map (fun c -> c, int c) "東京"  //  =>  [('東', 26481); ('京', 20140)]
```

Ao comparar carateres, é usado o Int16 subjacente:

```fsharp
'A' < 'D'  // =>  true
```

Além disso, um `int` pode ser convertido em `char`:

```fsharp
char 77  // => 'M'
```

A biblioteca `System.Char` contém o conjunto completo de métodos esperados numa linguagem .NET, como as conversões para maiúsculas e minúsculas:

```fsharp
'a' |> System.Char.ToUpper  // =>  'A'

'Q' |> System.Char.ToLower  // =>  'q'
```
