# Introdução

Em Factor, combinas words simplesmente escrevendo-os um a seguir ao outro: a ordem em que os escreves *é* a forma como se ligam. (Os programadores chamam a isto *composição de funções*.) O corpo de um word é ele próprio uma sequência de words: cada um consome alguns valores da pilha e coloca o seu resultado na pilha, e o word seguinte retoma a partir do ponto onde o anterior ficou. Então, definir

```factor
! DOCTEST: SKIP   (cleanupname is hypothetical here — the exercise's job)
: firstletter ( name -- letter ) cleanupname first 1string ;
```

já *é* a composição de `cleanupname`, `first` e `1string`.

Este exercício também introduz as **quotations**, um pedaço de código que podes guardar como valor e executar mais tarde, em vez de o executar de imediato.

## Quotations

Uma quotation é um pedaço de código envolvido em parênteses retos. Não é executada quando é escrita; fica na pilha como um valor:

```factor
[ 2 * ] .       ! => [ 2 * ]
```

O `call` executa uma quotation:

```factor
3 [ 2 * ] call .    ! => 6
```

Escreves uma quotation quando precisas de passar código como dados: para ser executado mais tarde, ou para ser passado a um *combinator*, um word que recebe uma quotation como parâmetro de entrada.

## `compose`

`compose ( quot1 quot2 -- combined )` junta duas quotations numa só, executando-as pela ordem em que estão escritas:

```factor
[ 2 * ] [ 1 + ] compose .    ! => [ 2 * 1 + ]
```

Normalmente vais achar que definir um word pequeno com `:` ... `;` se lê melhor do que com `compose`, mas o `compose` dá jeito quando precisas de construir quotations no momento. Quando os blocos de construção ainda não são quotations, `>quotation ( seq -- quot )` (de [`quotations`][quotations]) transforma uma sequência de valores e referências a words numa quotation que pode ser chamada:

```factor
USING: quotations sequences ;

{ [ 1 ] [ 2 + ] [ 3 * ] } concat >quotation call .   ! => 9
```

## Aplicar uma quotation a dois valores de entrada

`bi@ ( x y quot -- ... )` executa a quotation sobre `x` e novamente sobre `y`, deixando ambos os resultados na pilha:

```factor
3 4 [ 2 * ] bi@ .s
! => 6
! => 8
```

A tarefa `couple` do exercício recebe dois nomes; `bi@` é a forma natural de aplicar `initial` a cada um.

## Alguns words de string

O exercício precisa de alguns words pequenos para strings, retirados de três vocabulários: [`sequences`][sequences], [`ascii`][ascii] e [`strings`][strings]:

- `replace ( seq old new -- new-seq )` (em `splitting`) — substituição de substrings.
- `[ blank? ] trim` (`trim` em `sequences`, `blank?` em `ascii`) — remove espaços em branco no início e no fim.
- `1string ( char -- str )` (em `strings`) — envolve um único caráter numa string.
- `>upper ( str -- upper )` (em `ascii`) — converte uma string em maiúsculas.
- `append ( s1 s2 -- s )` (em `sequences`) — concatena duas strings.
- `prepend ( s1 s2 -- s )` (em `sequences`) — concatena `s2` e depois `s1` (`append` com os valores de entrada na ordem inversa).
- `glue ( s1 s2 sep -- s )` (em `sequences`) — concatena duas strings com um separador entre elas.
- `surround ( seq pre post -- new )` (em `sequences`) — envolve uma string com um prefixo e um sufixo.

Os caracteres Unicode podem ser escritos como `\u{XXXX}` dentro de uma string, em que `XXXX` é o ponto de código em hexadecimal. O coração `\u{2764}` (❤) aparece neste exercício.

## Saída formatada

Quando `append`/`glue`/`surround` não são suficientemente expressivos, [`formatting`][formatting] fornece o `sprintf`, ao estilo do printf:

```
sprintf ( inputs... format-string -- str )
```

O `%s` interpola uma string, o `%d` um número inteiro, o `%f` um número de vírgula flutuante; os modificadores opcionais de largura, precisão e preenchimento colocam-se entre o `%` e a letra do tipo:

```factor
USING: formatting ;

"Alice" "Bob" "%s & %s" sprintf .   ! => "Alice & Bob"
3.14159 "%.2f" sprintf .             ! => "3.14"
42 "%05d" sprintf .                  ! => "00042"
```

Para converter entre números e strings nos dois sentidos, [`math.parser`][math.parser] tem `number>string` e `string>number`:

```factor
USING: math.parser ;

42 number>string .       ! => "42"
"3.14" string>number .   ! => 3.14
```
