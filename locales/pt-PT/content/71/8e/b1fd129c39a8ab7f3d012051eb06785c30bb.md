# Instruções

A tua associação comunitária pediu-te para implementares uma aplicação simples de registo para gerir as inscrições no jardim comunitário. A struct `Plot` já te foi fornecida.

## 1. Abre o jardim

Implementa a função `CommunityGarden.start/1`. Esta deve receber uma lista de opções opcional (keyword list) para passar ao _processo agent_. O estado inicial do jardim deve ser inicializado de modo a representar uma coleção vazia de canteiros. Deve devolver um tuplo `:ok` com o pid do jardim.

```elixir
{:ok, pid} = CommunityGarden.start()
# => {:ok, #PID<0.112.0>}
```

## 2. Lista os registos

Implementa a função `CommunityGarden.list_registrations/1`. Esta deve receber o `pid` do jardim comunitário. Deve devolver uma lista dos canteiros guardados que estão registados.

```elixir
CommunityGarden.list_registrations(pid)
# => []
```

> Neste momento, ainda não adicionámos a possibilidade de registar um canteiro, por isso esta lista deve estar vazia

## 3. Regista canteiros a uma pessoa

Implementa a função `CommunityGarden.register/2`. Esta deve receber o `pid` do jardim comunitário e um nome para registar o canteiro. Quando for bem-sucedida, deve devolver a struct `Plot` com o id do canteiro e a pessoa a quem este foi registado.

Os ids devem ser incrementais e únicos. Podes manter um contador de ids no estado do agent.

```elixir
CommunityGarden.register(pid, "Emma Balan")
# => %Plot{plot_id: 1, registered_to: "Emma Balan"}
CommunityGarden.list_registrations(pid)
# => [%Plot{plot_id: 1, registered_to: "Emma Balan"}]
```

## 4. Liberta canteiros

Implementa a função `CommunityGarden.release/2`. Esta deve receber o `pid` e o `id` do canteiro a libertar. Deve devolver `:ok` em caso de sucesso. Quando um canteiro é libertado, o id não é reutilizado, serve apenas como identificador único.

```elixir
CommunityGarden.release(pid, 1)
# => :ok
CommunityGarden.list_registrations(pid)
# => []
```

## 5. Obtém um canteiro registado

Implementa a função `CommunityGarden.get_registration/2`. Esta deve receber o `pid` e o `id` do canteiro a verificar. Deve devolver o canteiro se este estiver registado, e `:not_found` se não estiver registado.

```elixir
CommunityGarden.get_registration(pid, 1)
# => %Plot{plot_id: 1, registered_to: "Emma Balan"}
CommunityGarden.get_registration(pid, 7)
# => {:not_found, "plot is unregistered"}
```
