És responsável por escrever um serviço que ingere eventos. Cada evento tem uma data associada, mas reparas que estão a ser submetidos 3 formatos diferentes ao endpoint do teu serviço:

- `"01/01/1970"`
- `"January 1, 1970"`
- `"Thursday, January 1, 1970"`

Consegues ver que há algumas semelhanças entre cada um deles e decides escrever alguns padrões de expressão regular que podes compor.

## 1. Faz corresponder o dia, o mês e o ano de uma data

Implementa `day`, `month` e `year` para devolver um padrão de string que, quando executado, corresponde aos componentes numéricos de `"01/01/1970"` (`dd/mm/yyyy`). A data e o mês podem aparecer como `1` ou `01` (preenchidos à esquerda com zeros).

Não te preocupes com a verificação de erros. Podes assumir que te será sempre passado um componente numérico válido.

```clojure
(day "31")
;;=> "31"
(month "12")
;;=> "12"
(year "1970")
;;=> "1970"
```

## 2. Faz corresponder o dia da semana e o mês do ano

Implementa `day-name` e `month-name` para devolver um padrão de string que, quando executado, corresponde, respetivamente, a qualquer dia da semana e a qualquer mês do ano escritos por extenso.

```clojure
(day-name "Tuesday")
;;=> "Tuesday"
(month-name "June")
;;=> "June"
```

## 3. Captura o dia, o mês e o ano

Implementa `capture-day`, `capture-month`, `capture-year`, `capture-day-name`, `capture-month-name` para devolver um mapa que associa os respetivos componentes aos nomes: `"day"`, `"month"`, `"year"`, `"day-name"`, `"month-name"`

```clojure
(capture-month-name "December")
;;=> {:month-name "December"}
```

## 4. Combina as capturas para capturar a data completa

Implementa `capture-numeric-date`, `capture-month-name-date` e `capture-day-month-name-date` para devolver um mapa dos componentes da parte 3, usando o respetivo formato de data.

```clojure
(capture-numeric-date "01/01/1970")
;;=> {:day "01", :month "01", :year "1970"}
```
