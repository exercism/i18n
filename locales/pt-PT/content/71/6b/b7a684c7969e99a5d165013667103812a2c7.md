# Anexo às instruções

## Dicas

Para completares este exercício, tens de criar o tipo de dados `Allergen`,
com as instâncias `Eq` e `Show`, e implementar as seguintes funções:

- `allergies`
- `isAllergicTo`

Vais encontrar uma declaração de dados de exemplo e assinaturas de tipos já no lugar,
mas és tu que tens de definir as funções e criar um tipo de dados,
um newtype ou um sinónimo de tipo que faça sentido.
