# Introdução

## Noções básicas

O Java é uma linguagem de tipos estáticos, o que significa que o tipo de uma variável é conhecido em tempo de compilação.
Atribuir um valor a um nome chama-se definir uma variável.
Uma variável define-se especificando explicitamente o seu tipo.

```java
int explicitVar = 10;
```

A atualização do valor de uma variável faz-se com o operador `=`.
Aqui, o `=` não representa igualdade matemática.
Limita-se a atribuir um valor a uma variável.
Uma vez definida, o tipo de uma variável nunca pode mudar.

```java
int count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning a different type
// count = false;
```

O Java é uma [linguagem orientada a objetos][object-oriented-programming] e exige que todas as funções sejam definidas numa _classe_.
A palavra-chave `class` serve para definir uma classe.

```java
class Calculator {
    // ...
}
```

Uma função dentro de uma classe chama-se _método_.
Cada método pode ter zero ou mais parâmetros.
Todos os parâmetros têm de ter um tipo explícito; não há inferência de tipos para parâmetros.
Do mesmo modo, o tipo do valor devolvido também tem de ser explícito.
Os valores são devolvidos pelos métodos através da palavra-chave `return`.
Para permitir que um método seja chamado por outras classes, é preciso acrescentar o modificador de acesso `public`.

```java
class Calculator {
    public int add(int x, int y) {
        return x + y;
    }
}
```

Invocar/chamar um método faz-se indicando o nome da classe e do método e passando argumentos para cada um dos parâmetros do método.

```java
int sum = new Calculator().add(1, 2);  // here the  "add" method has been called to perform the task of addition
```

Em Java, o âmbito define-se entre os caracteres `{` e `}`.

O Java suporta dois tipos de comentários.
Os comentários de uma linha são precedidos de `//` e os comentários de várias linhas são inseridos entre `/*` e `*/`.

[object-oriented-programming]: https://docs.oracle.com/javase/tutorial/java/javaOO/index.html
