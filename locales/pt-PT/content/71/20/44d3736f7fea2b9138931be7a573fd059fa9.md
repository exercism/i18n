# Introdução

Uma `list` em F# é uma coleção imutável de zero ou mais valores. Todos os valores de uma lista têm de ter o mesmo tipo. Como as listas são imutáveis, depois de uma lista estar construída, o seu valor nunca pode mudar. Quaisquer funções/operadores que pareçam modificar uma lista (por exemplo, adicionar um elemento) devolvem, na verdade, uma nova lista.

As listas podem ser definidas da seguinte forma:

```fsharp
let empty = []
let singleValue = [5]
let threeValues = ["a"; "b"; "c"]
```

A forma mais comum de adicionar um elemento a uma lista é através do operador `::` (cons):

```fsharp
let twoToFour = [2; 3; 4]
let oneToFour = 1 :: twoToFour
// => [1; 2; 3; 4]
```

Uma lista de F# tem uma _cabeça_ (o primeiro elemento) e uma _cauda_ (tudo o que vem depois do primeiro elemento). A cauda de uma lista é, ela própria, uma lista.

As listas são manipuladas quer por funções e operadores definidos no módulo `List`, quer manualmente através de correspondência de padrões, com os padrões _list_ e _cons_:

```fsharp
let describe list =
    match list with
    | [] -> "Empty list"
    | head::tail -> sprintf "Non-empty list with head: %d" head

describe []        // => "Empty list"
describe [1]       // => "Non-empty with head: 1"
describe [5; 7; 9] // => "Non-empty with head: 5"
```

Também podes _descartar_ um valor durante a correspondência de padrões; quando _não_ te importas com um valor num determinado caso (ou seja, não vais _usar_ esse valor), podes usar um sublinhado (`'_'`) para o indicar:

```fsharp
let describe list =
    match list with
    | [] -> "Empty list"
    | [x] -> "List with one item"
    | [_; y] -> "List with two items (first item ignored)"
    | _ -> "List with many items (all items ignored)"

describe []        // => "Empty list"
describe [1]       // => "List with one item"
describe [5; 7]     // => "List with two items (first item ignored)"
describe [5; 7; 9] // => "List with many items (all items ignored)"
```

O `'_'` sozinho deve vir sempre em _último_ lugar na correspondência de padrões; qualquer valor que _não_ corresponda a nenhum dos outros casos será tratado por este caso.
