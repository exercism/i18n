# Introdução

As strings em Gleam são cadeias de carateres imutáveis, rodeadas por aspas duplas. Suportam carateres Unicode e podem ter várias linhas.

```gleam
let greeting = "Hello, Joe! 📞"

let multi_line_string = "one
two
three"
```

É possível unir strings com o operador `<>`:

```gleam
let name = "Mike"
"Hello, " <> name <> "!"
// -> "Hello, Mike!"
```

O módulo [`gleam/string`][stdlib] da biblioteca padrão fornece funções para trabalhar com strings.

É possível fazer correspondência de padrões com strings em expressões case:

```gleam
pub fn on_an_excellent_adventure(name: String) -> Bool {
  case name {
    "Bill" -> True
    "Ted" -> True
    _ -> False
  }
}
```

Se quiseres fazer correspondência com o início de uma string e atribuir o resto a uma variável, podes usar o padrão do operador `<>`:

```gleam
pub fn profession(name: String) -> String {
  case name {
    "Dr " <> rest -> rest <> " is a doctor"
    _ -> "I'm not sure what " <> name <> " does"
  }
}
```

[stdlib]: https://hexdocs.pm/gleam_stdlib/gleam/string.html
