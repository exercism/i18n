# Testes

## Correr os testes

Quando estás no diretório de um exercício, deves ver dois subdiretórios:

* `Sources/<Exercise>` contém a tua solução para o exercício
* `Tests/<Exercise>Tests` contém os testes que deves correr para o exercício

Se estiveres no diretório certo (ou seja, aquele que contém `Sources` e `Tests`), podes correr os testes desse exercício com o comando `swift test`:

```bash
$ pwd
/Users/johndoe/Code/exercism/swift/hello-world

$ ls
HELP.md  Package.swift  README.md  Sources  Tests

$ swift test
```

Quando um teste passar, remove `.enabled(if: RUNALL)` na instrução `@Test` para ativares o teste seguinte. Em alternativa, podes correr todos os testes com a variável de ambiente `RUNALL` definida como `true` no Linux ou no macOS:

```bash
$ export RUNALL=true
```

Ou, se estiveres a usar o PowerShell no Windows:

```powershell
set RUNALL=true
```

## Submeter a tua solução

Para submeteres uma solução ao Exercism, tens de estar no diretório que contém os diretórios `Sources` e `Tests`.

```bash
$ exercism submit 
```
