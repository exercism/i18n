# Instruções

Neste exercício, vais gerir um sistema de inventário.

O inventário deve ser organizado pelo nome do item e deve manter o registo do número de itens disponíveis.

Vais ter de tratar da adição de itens a um inventário.
Sempre que um item aparece numa determinada lista, a quantidade desse item no inventário deve aumentar em `1`.
Também vais ter de tratar da remoção de itens de um inventário, diminuindo as quantidades em `1` quando tal for pedido.

Por fim, vais ter de implementar uma função que devolva todos os pares chave-valor de um determinado inventário como uma `list` de `tuples`.


## 1. Criar um inventário a partir de uma lista

Implementa a função `create_inventory(<input list>)` que cria um "inventário" a partir de uma lista de itens fornecida como entrada.
Deve devolver um `dict` que contém cada nome de item associado à respetiva quantidade.

```python
>>> create_inventory(["coal", "wood", "wood", "diamond", "diamond", "diamond"])
{"coal":1, "wood":2, "diamond":3}
```

## 2. Adicionar itens de uma lista a um dicionário existente

Implementa a função `add_items(<inventory dict>, <item list>)` que adiciona uma lista de itens ao inventário recebido:

```python
>>> add_items({"coal":1}, ["wood", "iron", "coal", "wood"])
{"coal":2, "wood":2, "iron":1}
```

## 3. Decrementar itens do inventário

Implementa a função `decrement_items(<inventory dict>, <items list>)`, que recebe uma `list` de itens.
A tua função deve subtrair `1` à contagem de um item por cada vez que esse item aparece na `list`:

```python
>>> decrement_items({"coal":3, "diamond":1, "iron":5}, ["diamond", "coal", "iron", "iron"])
{"coal":2, "diamond":0, "iron":3}
```

A contagem de itens no inventário não pode ficar abaixo de 0.
 Se o número de vezes que um item aparece na `list` de entrada exceder a contagem disponível, a quantidade registada para esse item deve permanecer em 0.
 Depois de a contagem chegar a zero, os pedidos adicionais de remoção devem ser ignorados.

```python
>>> decrement_items({"coal":2, "wood":1, "diamond":2}, ["coal", "coal", "wood", "wood", "diamond"])
{"coal":0, "wood":0, "diamond":1}
```

## 4. Remover uma entrada do inventário por completo

Implementa a função `remove_item(<inventory dict>, <item>)`, que remove um item e a sua contagem do inventário:

```python
>>> remove_item({"coal":2, "wood":1, "diamond":2}, "coal")
{"wood":1, "diamond":2}
```

Se o item não for encontrado no inventário, a função deve devolver o inventário original sem alterações.

```python
>>> remove_item({"coal":2, "wood":1, "diamond":2}, "gold")
{"coal":2, "wood":1, "diamond":2}
```

## 5. Devolver todo o conteúdo do inventário

Implementa a função `list_inventory(<inventory dict>)`, que recebe um inventário e devolve uma lista de `tuples` `(item, quantity)`.
A lista só deve incluir os itens _disponíveis_ (_com uma quantidade superior a zero_):

```python
>>> list_inventory({"coal":7, "wood":11, "diamond":2, "iron":7, "silver":0})
[('coal', 7), ('diamond', 2), ('iron', 7), ('wood', 11)]
```
