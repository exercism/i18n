# Introdução

A maioria das palavras de sequência do Factor devolve *novas* sequências e deixa os seus valores de entrada intactos, mas os arrays e os vectors também suportam **mutação no próprio local** quando queres registar estado que evolui ao longo do tempo.

`set-nth` e `change-nth` alteram uma fenda no próprio local, e funcionam tanto com um array como com um vector. `<array>` constrói um array mutável de comprimento fixo; os literais `V{ }`, `<vector>`, `push` e `pop` formam o conjunto exclusivo dos vectors, já que os arrays não podem mudar de comprimento.
`clone` duplica a sequência para que as mutações seguintes não passem para o original.

```factor
USING: arrays kernel sequences ;

5 0 <array>                 ! a fresh array { 0 0 0 0 0 }
dup 7 2 swap set-nth        ! { 0 0 7 0 0 } — set position 2 to 7
.

V{ } clone                  ! a fresh, empty vector
"alice" over push           ! V{ "alice" }
"bob" over push             ! V{ "alice" "bob" }
dup pop .                   ! "bob"
.                           ! V{ "alice" }
```
