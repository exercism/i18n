# Instruções

Estás a trabalhar na implementação de um sistema de monitorização de saúde. Como parte disso, precisas de manter registo das estatísticas de saúde dos utilizadores.

Vais começar com algumas funções esboçadas num bloco `impl`, bem como com a seguinte definição de struct:

```rust
pub struct User {
    name: String,
    age: u32,
    weight: f32,
}
```

O teu objetivo é implementar os métodos esboçados na `struct` `User` definida no bloco `impl`.

Por exemplo, o método `new` deve devolver uma instância da `struct` `User` com os valores especificados de nome, idade e peso.

```rust
let mut bob = User::new(String::from("Bob"), 32, 155.2);
// Returns: a User with name "Bob", age 32, and weight 155.2
```

O método `weight` deve devolver o peso do `User`.

```rust
bob.weight();
// Returns: 155.2
```

O método `set_age` deve definir a idade do `User`.

```rust
bob.set_age(33);
// Updates Bob's age to 33; happy birthday Bob!
```

Diverte-te!
