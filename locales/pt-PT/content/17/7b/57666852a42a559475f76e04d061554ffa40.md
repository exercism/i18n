# Instruções

A tua empresa foi contratada para gerar registos CSV a partir de dados introduzidos pelo utilizador.

Precisamos de um builder para um registo CSV de acordo com a norma definida na [RFC 4180](https://tools.ietf.org/html/rfc4180).

Apesar de existir uma especificação formal, a tua empresa só precisa de implementar as seguintes funcionalidades:
- criar um novo builder de registos
- adicionar um campo individual ao registo
- serializar o registo com escape básico

O escape básico significa:

- Os campos que contenham quebras de linha, aspas duplas ou vírgulas devem ser envolvidos em aspas duplas.

- Se forem usadas aspas duplas para envolver campos, uma aspa dupla que apareça dentro de um campo tem de ser escapada precedendo-a com outra aspa dupla.


## 1. Cria um novo builder

Vais precisar de implementar o método `new` para criar um novo builder.

```rust
let mut builder = CsvRecordBuilder::new();
```

## 2. Adiciona campos individuais ao registo

Vais precisar de implementar o método `add` para acrescentar campos ao teu builder de registos.
O `add` recebe fatias de string imutáveis, `&str`, como argumento.

```rust
builder.add("ant");
builder.add("ba\"t");
builder.add("cat");
```


## 3. Serializa o registo com escape básico

Vais precisar de implementar o método `build`.
O `build` consome o builder e devolve um registo CSV.
```rust
let record = builder.build();
// Note that from now on we cannot use `builder`
assert_eq!(&record, r#"ant,"ba""t",cat"#);
```
