# Apêndice das instruções

## Implementação

Podes usar funcionalidades da própria linguagem para construir e desconstruir arrays através de desestruturação, bem como o literal de array `[]`, mas não deves usar nenhuma função de `Array.prototype`.

Para conseguires testar a tua solução, certifica-te de que o `forEach` está implementado.

```typescript
const list = List.create(1, 2)
list.forEach((item) => console.log(item))
// =>
//    1
//    2
```
