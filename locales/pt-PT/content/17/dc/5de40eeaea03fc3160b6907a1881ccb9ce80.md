# Instruções

Neste exercício trabalhas numa pizzaria que faz entregas aos clientes.

Ofereces três tipos de pizza:

- Margherita: \$7
- Caprese: \$9
- Formaggio: \$10

Os clientes também podem escolher duas opções adicionais por um pequeno custo extra:

1. Molho extra: \$1
1. Ingredientes extra: \$2

Quando os clientes fazem uma encomenda, é acrescentada uma taxa adicional se encomendarem apenas uma ou duas pizzas:

- 1 pizza: \$3
- 2 pizzas: \$2

Tens três tarefas, todas elas sobre pizzas e os respetivos preços.

## 1. Define os tipos de pizza e as opções

Define o tipo personalizado `Pizza` para representar os diferentes tipos de pizza e as opções:

- `Margherita`
- `Caprese`
- `Formaggio`
- `ExtraSauce`
- `ExtraToppings`

`ExtraSauce` e `ExtraToppings` devem envolver o tipo `Pizza`.

## 2. Calcula o preço da pizza

Implementa a função `pizza_price` para calcular o preço de uma pizza:

```gleam
pizza_price(Caprese)
// -> 9
```

## 3. Calcula o preço de uma encomenda

Implementa a função `order_price` para calcular o preço de uma encomenda de pizzas:

```gleam
order_price([Margherita, Formaggio])
// -> 19
```
