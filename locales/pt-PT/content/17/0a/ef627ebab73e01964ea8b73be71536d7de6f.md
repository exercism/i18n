# Dicas

## 1. Calcula o valor de uma carta qualquer.

- O método `Blackjack.parse_card` deve receber uma string (por exemplo, `"ace"`) e devolver o valor correspondente (por exemplo, 11).
- Define uma instrução [`case`][case] e atribui o valor da carta como resultado desse case.
- O rei, a dama, o valete e o 10 podem ser tratados com um único case.
- O case pode ter uma cláusula `else`.
  Em qualquer caso, a função deve devolver `0` para cartas desconhecidas.

## 2. Dá nome a intervalos de valores.

- Calcula a pontuação do jogador somando os valores das duas cartas do jogador.
- Define uma instrução [`case`][case] e atribui o nome do intervalo como resultado desse case.
- O switch pode usar objetos [`Range`][range] como casos para verificar se um valor está dentro de um intervalo.

## 3. Implementa a lógica de decisão para a primeira jogada.

- Calcula a pontuação do jogador somando os valores das duas cartas do jogador.
- Podes usar uma grande instrução [`case`][case] sobre a pontuação do jogador
  (talvez com condicionais `if` aninhadas sobre a pontuação do dealer em alguns casos),
- ou podes distinguir categorias separadas de pontuação do jogador (por exemplo, "small hands"
  com uma pontuação inferior a 12, "medium hands" com uma pontuação no intervalo 12..20 e
  "large hands" com uma pontuação superior a 20) e escrever funções separadas para
  todas (ou algumas) dessas categorias.

[case]: https://www.rubyguides.com/2015/10/ruby-case/
[range]: https://docs.ruby-lang.org/en/master/Range.html
