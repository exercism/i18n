# Introdução

Tal como a maioria das linguagens de programação, o Gleam tem "efeitos secundários", por isso as funções podem ler e alterar o estado do mundo, além de devolverem um valor.

O módulo `gleam/io` da biblioteca padrão do Gleam fornece funções para imprimir strings na consola.

```gleam
io.println("Hello, Joe!")
// Hello, Joe!
// -> Nil
```

Outros pacotes podem fornecer outras funções de IO, como o `simplifile`, um pacote que fornece funções para ler e escrever ficheiros.

```gleam
simplifile.read("favourite-colour.txt")
// -> Ok("Pink\n")
```
