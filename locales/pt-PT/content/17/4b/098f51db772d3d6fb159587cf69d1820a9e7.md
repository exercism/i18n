# Introdução

A função `switch()` pode ser um substituto conciso para uma longa série de testes `if` ... `else if`.
A variável sobre a qual se faz o switch é, habitualmente, uma string e, nesse caso, as aspas podem ser omitidas do seletor.

```R
star <- function(type) {
  switch(type,
    M = , # will "fall through" if no value given
    K = "red dwarf",
    G = "Earth-like",
    "bigger star" # only correct for O,B,A,F
  )
}

> star("M")
[1] "red dwarf"
```

Repara que as opções só passam para a seguinte se o valor for deixado em branco, como acontece com `M` no exemplo acima.
Não é preciso incluir instruções `break`, ao contrário do que acontece em algumas outras linguagens.

Quando se faz o switch sobre o tipo `character`, o valor final é um valor predefinido, como aqui.
Com tipos inteiros, não é possível indicar nenhum valor predefinido.

## Funções em `dplyr`

O `switch` do R base é bastante limitado: só faz uma correspondência exata com um único valor de entrada.
Isto parecia razoável quando o R foi lançado, em 1993, mas precisa de melhorias para o uso moderno.

~~~~exercism/note
Como foi referido no Conceito [`Conditionals`][concept-conditionals], a coleção de pacotes `tidyverse` foi concebida para complementar (e, por vezes, substituir) a funcionalidade do R base sem afetar a compatibilidade retrocompatível.

O pacote `dplyr` pode ser trazido para o âmbito adicionando `library(dplyr)` (para o pacote individual) ou `library(tidyverse)` (para a coleção completa) ao topo do teu código.

A biblioteca `dplyr` fornece duas funções extra relacionadas com o `switch`.

### As funções `recode_values` e `replace_values`

Estas duas funções relacionadas permitem um mapeamento vetorizado, semelhante ao switch, de valores antigos para valores novos.

A principal diferença entre elas é que `recode_values()` cria um vetor completamente novo, enquanto `replace_values()` permite atualizações parciais de um vetor existente.

A correspondência continua a ser exata, mas:

- As opções à esquerda podem ser vetores, e o valor de entrada corresponde se algum elemento corresponder.
- As opções à esquerda e os resultados à direita são ligados com uma tilde `~` em vez de `=`.
- Em todos os casos é possível indicar um valor predefinido.

```R
library(dplyr)

x <- c("a", "b", "a", "d", "b", NA, "c", "e", "z")
recode_values(
  x,
  "a" ~ 1,
  "b" ~ 2,
  "c" ~ 3,
  c("d", "e") ~ 4, # either "d' or "e" will match
  NA ~ 0,          # matches missing values
  default = 100   # note the different syntax for the default
)
#> [1]   1   2   1   4   2   0   3   4 100
```

### A função `case_when`

A função `case_when` leva a sintaxe do `case_match` um passo mais além, ao permitir qualquer expressão lógica à esquerda do `~`.

O vetor de entrada (`x` no exemplo abaixo) não é fornecido como argumento, só precisa de já estar definido.

```R
x <- 1:10
case_when(
  x < 3 ~ "low",
  between(x, 3, 5) ~ "mid",
  between(x, 6, 8) ~ "high",
  .default = "what?"
)
#>  [1] "low"   "low"   "mid"   "mid"   "mid"   "high"  "high"  "high"  "what?" "what?"
```

A função `between()` também faz parte do `dplyr`.
