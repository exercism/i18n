# Instruções

És o sinalizador de uma embarcação de patrulha costeira. A bolsa de hoje precisa de cinco pequenas palavras prontas antes de começar o turno da manhã.

## 1. Colocar um valor em forma de código-fonte

O diário de bordo regista cada observação em *forma de código-fonte do Factor*: o mesmo texto que o analisador sintático vai ler de volta. Define `quote-value` para converter qualquer valor na respetiva string em forma de código-fonte.

```factor
123 quote-value .   ! => "123"
"hi" quote-value .  ! => "\"hi\""
```

## 2. Retirar a moldura da bandeira

As bandeiras de sinalização que chegam vêm emolduradas por um caráter marcador em cada extremidade. Define `flag-body` para devolver tudo o que está *entre* os dois marcadores: retira o primeiro caráter, retira o último caráter.

Devolve uma fatia (uma vista) em vez de copiar.

```factor
"#NS-1024#" flag-body .   ! => "NS-1024"
```

## 3. Dividir uma bandeira

Cada bandeira traz um pequeno código de prefixo seguido da carga útil. Define `split-flag` para receber uma bandeira e um comprimento de cabeçalho, e devolver *tanto* a fatia do cabeçalho como a fatia do corpo.

```factor
"NS-1024" 2 split-flag .s
! => "NS"
! => "-1024"
```

## 4. Triangular a partir de duas leituras

Duas leituras de sinal consecutivas dão três medidas derivadas: a sua *diferença* `a - b`, o seu *ponto médio* `(a + b) / 2` e a sua *razão* `a / b`. Cada medida usa as duas leituras.

Define `triangulate` para devolver as três a partir de um par de leituras.

```factor
100 50 triangulate .s
! => 50
! => 75
! => 2
```

## 5. Resumir três leituras

Três leituras consecutivas são resumidas na sua **soma**, no seu **produto** e no seu **máximo**. Cada estatística usa as três leituras.

Define `triangle-stats` para devolver as três.

```factor
5 3 8 triangle-stats .s
! => 16
! => 120
! => 8
```
