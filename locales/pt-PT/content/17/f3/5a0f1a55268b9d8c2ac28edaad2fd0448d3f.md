# Introdução

Podes usar uma instância da classe `java.util.Random` para gerar números aleatórios em Java.

## Números inteiros aleatórios

Podes gerar um número inteiro aleatório com o método `nextInt()`.
Isto gera um valor no intervalo de `Integer.MIN_VALUE` a `Integer.MAX_VALUE`.

```java
Random random = new Random();

random.nextInt();
// => -1169335537
```

Para limitar o intervalo de valores gerados, usa `nextInt(int)`.
Isto gera um valor no intervalo de `0` (inclusive) até ao limite superior indicado (exclusive).

Por exemplo, isto gera um número aleatório de `0` a `9`.

```java
Random random = new Random();

random.nextInt(10);
// => 6
```

E isto gera um número aleatório de `10` a `19`.

```java
Random random = new Random();

10 + random.nextInt(10);
// => 11
```

## Números de vírgula flutuante aleatórios

Podes gerar um número de vírgula flutuante aleatório com o método `nextDouble()`.
Isto gera um valor no intervalo de `0.0` a `1.0`.

```java
Random random = new Random();

random.nextDouble();
// => 0.19250004204021398
```

E isto gera um número aleatório de `100.0` a `200.0`.

```java
Random random = new Random();

100.0 + 100.0 * random.nextDouble();
// => 111.31849856260328
```
