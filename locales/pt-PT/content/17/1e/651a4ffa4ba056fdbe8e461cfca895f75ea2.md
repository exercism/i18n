# Introdução

Uma `string` em C++ é um objeto mutável que representa texto como uma sequência de carateres (letras, algarismos, pontuação, etc.).
Trabalhas com strings chamando os métodos da string.

## Biblioteca de strings

Em C++, o tipo string e as funções associadas têm de ser incluídas a partir da biblioteca de strings antes de serem usadas.
Podes fazê-lo adicionando `#include <string>` no topo do teu ficheiro.
Passam então a fazer parte do namespace `std`.
O nome totalmente qualificado do tipo string é `std::string`.
O literal de string usa o caráter de aspas duplas: `"`.

```cpp
#include <string>
std::string w_berry_quote{"A well-made sentence, I think, is a thing of beauty."};
```

## Operações comuns com strings

Podes usar o operador `+` para concatenar strings:

```cpp
std::string original_title{"The School of Rock"};
std::string sequel_indicator{"Electric Boogaloo"};
std::string next_movie_title = original_title + " 2: " + sequel_indicator;
```

Para usares a biblioteca de strings, precisas de saber que é possível chamar uma função que pertence a um objeto.
A estas chamamos funções membro.
Mais adiante no percurso, vais aprender mais sobre as funções membro e o conceito de classe associado.

```cpp
std::string qualification{"awesome"};
// 1st argument: from the index to the end of the string:
std::string who_is_awesome = qualification.substr(5);
// => "me"

// 2nd optional argument for the length:
std::string material{"haunted books"};
std::string ghost = material.substr(8, 3);
// => "boo"
```


A função `find` também é muito útil.
É chamada como função membro da string e recebe uma string como argumento.
`find` devolve a posição, com o índice a começar em zero, da _primeira_ ocorrência na string.

```cpp
std::string new_release{"apple released a new app!"};
new_release.find("app");
// => 0
new_release.find("e");
// => 4
```

Existe também a função `std::to_string`, que podes usar para converter números inteiros e valores de vírgula flutuante em string.

```cpp
int num{92};
double exponent{0.92e2};
std::string msg{ std::to_string(num) + " can also be written as " + std::to_string(exponent)};
// => 92 can also be written as 92.0000000
```
