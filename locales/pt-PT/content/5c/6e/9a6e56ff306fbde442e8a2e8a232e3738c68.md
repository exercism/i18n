# Introdução

O facto de um array ser também uma _coleção_ significa que, além de acederes a valores por índice, podes iterar sobre _todos_ os seus valores com um ciclo `foreach`:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // Output the vowel
    System.Console.Write(vowel);
}

// => aeiou
```
