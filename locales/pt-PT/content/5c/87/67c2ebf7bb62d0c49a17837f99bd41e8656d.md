# Introdução

## Tipos fantasma

Os tipos fantasma são parâmetros de tipo de um tipo personalizado que não são utilizados em nenhum dos construtores de valores desse tipo.

Isto é um pouco abstrato, por isso aqui está um exemplo:

```gleam
pub type Length(unit) {
  Length(amount: Float)
}
```

Neste exemplo, o parâmetro de tipo `unit` não é utilizado no construtor de valores `Length`, por isso `unit` é um tipo fantasma.

Este parâmetro de tipo não utilizado pode parecer inútil, mas pode ser usado para adicionar mais restrições à forma como os valores `Length` podem ser usados.

Por exemplo, podíamos ter uma função `double`, que multiplica o comprimento. Funciona com comprimentos de qualquer unidade, por isso o parâmetro de tipo é uma variável de tipo genérica.

```gleam
// This function accepts all Length values
pub fn double(length: Length(unit)) -> Length(unit) {
  Length(length.amount *. 2.0)
}
```

Também podíamos ter uma função `add_inch`, que só funciona se o comprimento estiver em polegadas.

```gleam
// A unit type for inches. It is never constructed so we don't
// define any constructors for it.
pub type Inches

pub fn add_inch(length: Length(Inches)) -> Length(Inches) {
  Length(length.amount +. 1.0)
}
```

A função `add_inch` não aceita comprimentos com qualquer outro parâmetro de unidade. O tipo fantasma foi usado para garantir que apenas a unidade correta é utilizada.

Também podemos escrever uma função que garanta que dois valores de comprimento são da mesma unidade, usando a mesma variável de tipo para ambos.

```gleam
pub fn add(a: Length(unit), b: Length(unit)) -> Length(unit) {
  Length(a.amount +. b.amount)
}
```
```gleam
let two_meters: Length(Meters) = Length(2.0)
let two_inches: Length(Inches) = Length(2.0)

add(two_meters, two_meters)
// -> Length(4.0): Length(Meters)

add(two_meters, two_inches)
// Type error! The unit type parameters do not match.
```

Os tipos fantasma podem funcionar bem com tipos opacos. Se outros módulos não conseguirem construir valores `Length`, podemos garantir que não são construídos com um tipo de unidade inválido e que só as funções definidas acima podem ser usadas com eles.
