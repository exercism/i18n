# Instruções

Neste exercício vais brincar com um carro telecomandado, que finalmente conseguiste comprar depois de poupares dinheiro suficiente.

Os carros começam com a bateria cheia (100%).
Cada vez que conduzes o carro com o telecomando, este percorre 20 metros e gasta um por cento da bateria.
A alcunha do carro só é conhecida quando este é criado.

O carro telecomandado tem um ecrã de LED sofisticado que mostra duas informações:

- A distância total percorrida, apresentada como: `"<METERS> meters"`.
- A carga restante da bateria, apresentada como: `"Battery at <PERCENTAGE>%"`.

Se a bateria estiver a 0%, já não consegues conduzir o carro e o ecrã da bateria mostra `"Battery empty"`.

## 1. Cria um carro telecomandado novo

Implementa a função `new_remote_control_car/0` para devolver um objeto de carro telecomandado novo:

```jq
new_remote_control_car
# => {
#      "battery_percentage": 100,
#      "distance_driven_in_meters": 0,
#      "nickname": null
#    }
```

## 2. Cria um carro telecomandado novo com uma alcunha

Implementa a função `new_remote_control_car/1` para devolver um objeto de carro telecomandado novo com uma alcunha fornecida:

```jq
new_remote_control_car("Blue")
# => {
#      "battery_percentage": 100,
#      "distance_driven_in_meters": 0,
#      "nickname": "Blue"
#    }
```

## 3. Mostra a distância

Implementa a função `display_distance/0`, que recebe um objeto de carro como parâmetro de entrada e apresenta a string da distância tal como aparece no ecrã de LED:

```jq
new_remote_control_car | display_distance
# => "0 meters"
```

## 4. Mostra a percentagem da bateria

Implementa a função `display_battery/0`, que recebe um objeto de carro como parâmetro de entrada e apresenta a string da percentagem da bateria tal como aparece no ecrã de LED:

```jq
new_remote_control_car | display_battery
# => "Battery at 100%"
```

Se a bateria estiver a 0%, o ecrã da bateria mostra "Battery empty".

## 5. Conduzir altera a bateria e a distância percorrida

Implementa a função `drive/0` que:

- recebe um objeto de carro como parâmetro de entrada
- atualiza o número de metros percorridos em 20
- gasta 1% da bateria
- devolve o objeto de carro modificado

```jq
new_remote_control_car("Red") | drive
# => {
#      "battery_percentage": 99,
#      "distance_driven_in_meters": 20,
#      "nickname": "Red"
#    }
```

## 6. Tem em conta conduzir com a bateria descarregada

Atualiza a função `drive/0` para não aumentar a distância percorrida nem diminuir a percentagem da bateria quando a bateria está descarregada (a 0%):

```jq
{
  battery_percentage: 0,
  distance_driven_in_meters: 2000,
  nickname: "Red"
} | drive
# => {
#      "battery_percentage": 0,
#      "distance_driven_in_meters": 2000,
#      "nickname": "Red"
#    }
```
