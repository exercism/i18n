# Instruções

Implementa um sistema reativo básico.

A programação reativa é um paradigma de programação focado em como os valores são calculados em função uns dos outros, para que uma alteração a um valor se propague automaticamente aos restantes, como numa folha de cálculo.

Implementa um sistema reativo básico com células com valores que se podem definir (células de "entrada") e células com valores calculados em função de outras células (células de "cálculo"). Implementa as atualizações de modo a que, quando um valor de entrada é alterado, os valores se propaguem até atingir um novo estado estável do sistema.

Além disso, as células de "cálculo" devem permitir registar callbacks de notificação de alterações. Chama os callbacks de uma célula quando o valor da célula num novo estado estável tiver mudado em relação ao estado estável anterior.
