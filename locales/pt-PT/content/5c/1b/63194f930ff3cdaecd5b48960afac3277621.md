# Introdução

Muitos programas precisam de valores (aparentemente) aleatórios para simular acontecimentos do mundo real.

Entre os exemplos mais comuns e familiares estão:

- O lançamento de uma moeda: um valor aleatório que é `"H"` ou `"T"`.
- O lançamento de um dado: um número inteiro aleatório de 1 a 6.
- Baralhar um baralho de cartas: uma ordenação aleatória de uma lista de cartas.

Gerar valores verdadeiramente aleatórios com um computador é um [desafio técnico surpreendentemente difícil][web-truly-random], por isso podes ver estes resultados referidos como «pseudoaleatórios».

***Importante***: Este Conceito *não* aborda números aleatórios criptograficamente seguros, que são um desafio muito mais difícil.

No entanto, o R deriva de um pacote de estatística e é frequentemente usado para simulações, por isso oferece uma grande variedade de formas de gerar valores aleatórios.
Os resultados são suficientemente bons para a maioria das aplicações de modelação, simulação e jogos.

## [Amostragem com ou sem reposição][yt-sampling-with-replacement]

Imagina que tens um saco com 3 bolas vermelhas e 4 bolas verdes e que tiras uma bola do saco ao acaso.
Para obteres uma segunda bola, há duas possibilidades:

1. Voltas a pôr a primeira bola no saco e agitas tudo bem antes de tirar outra.
   O número de bolas é agora o mesmo de antes (7) e *a proporção de vermelhas para verdes também é a mesma*.
2. Pões a primeira bola em cima da mesa antes de tirar uma segunda.
   Agora só há 6 bolas no saco e *a proporção de vermelhas para verdes depende da cor da primeira bola*.

O cenário 1 é com reposição, o cenário 2 é sem reposição e *dão resultados diferentes*.

## Valores discretos com `sample`

Para escolher entre um número limitado de valores discretos, podes usar `sample()` com ou sem reposição.
Isto é útil para números inteiros, strings, etc.

```R
sample(1:10, 5) # no repeats by default
#> [1] 8 3 4 2 6

sample(1:10, 5, replace = TRUE) # repeats are OK
#> [1] 10 10  7 10  9

languages <- c("Fortran", "R", "Python", "Julia")
sample(languages, 1)
#> [1] "Python"

sample(c("H", "T"), 5, replace = TRUE) # coin flips
#> [1] "T" "T" "H" "H" "H"

sample(c(TRUE, FALSE), 5, replace = TRUE) # alternative coin flips
#> [1] FALSE  TRUE FALSE  TRUE  TRUE
```

A amostragem integra-se bem em pipelines de dados.
Por exemplo, para gerar strings alfanuméricas aleatórias:

```R
library(stringr)

c(letters, LETTERS, 0:9) |> sample(50) |> str_flatten()
#> [1] "5tX71jhbM9zUmKrpENBQyGYaZdJPVAx06leSF2s8gcfw3OviIH"
```

## Baralhar

Várias outras linguagens têm uma função especial para baralhar uma sequência.

O R não tem uma função de baralhar.
*Porquê?*

Para perceberes isto, olha outra vez para a função `sample`.

A forma completa é `sample(x, size, replace = FALSE, prob = NULL)`, em que `x` é (normalmente) a sequência de onde se retiram as amostras e `size` é o número de itens a escolher.

Já falámos de `replace`, cujo valor predefinido corresponde a amostragem sem reposição.
Por agora, ignora `prob`, que te permite atribuir pesos diferentes aos vários elementos de `x`.

O que acontece se omitirmos `size` e dermos apenas `x`?

```R
x <- letters[1:6]
x
#> [1] "a" "b" "c" "d" "e" "f"
sample(x)
#> [1] "e" "a" "f" "b" "c" "d"
```

Ao típico estilo do R, o padrão é vetor à entrada, vetor à saída, e `size` assume por defeito `length(x)`.

«Retirar uma amostra de todos os elementos de `x` sem reposição» é apenas uma forma mais técnica de dizer «baralhar `x`».

*Por isso*, não existe uma função `shuffle`, porque `sample` já faz exatamente o que precisamos!

## Trabalhar com distribuições

Os exemplos acima descreviam casos em que todos os resultados são igualmente prováveis.
Por exemplo, `sample(1:100)` tem a mesma probabilidade de dar qualquer número inteiro de 1 a 100.

A isto chama-se uma distribuição `uniform`.

Muitas situações do mundo real são muito menos simples do que isto.
Por isso, os estatísticos criaram uma grande variedade de `distributions` para descrever matematicamente resultados do «mundo real».

## Números de vírgula flutuante

### Distribuição uniforme

Para uma distribuição igualmente ponderada de números de vírgula flutuante, usa `runif()` (concentra-te em «**r**andom-**unif**orm» e resiste à tendência natural mas *errada* de ler «run if»).
Tanto `min` como `max` podem ser especificados, mas por defeito são 0 e 1.

```R
runif(5)  # generate 5 values
#> [1] 0.3038506 0.3527959 0.3319309 0.4846354 0.4386279

# generate 5 non-negative values <= 100.0
runif(5, max = 100)
#> [1] 79.70762 51.62232 52.85281 71.08571 63.94380
```
