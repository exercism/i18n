# Instruções

Neste exercício vais construir o tratamento de erros para uma calculadora simples de números inteiros.
Para simplificar, são fornecidos métodos para calcular a adição, a multiplicação e a divisão.

O objetivo é teres uma calculadora a funcionar que devolva uma String com o seguinte padrão: `16 + 51 = 67`, quando recebe os argumentos `16`, `51` e `+`.

```java
CalculatorConundrum calculator = new CalculatorConundrum();

calculator.calculate(16, 51, "+");
// => returns "16 + 51 = 67"

calculator.calculate(32, 6, "*");
// => returns "32 * 6 = 192"

calculator.calculate(512, 4, "/");
// => returns "512 / 4 = 128"
```

## 1. Implementa o método calculate para suportar algumas operações básicas

O método principal a implementar nesta tarefa é o método `CalculatorConundrum.calculate()`.
Recebe três argumentos.
Os dois primeiros argumentos, `operand1` e `operand2`, são números inteiros sobre os quais vai ser aplicada uma operação.
O terceiro argumento, `operation`, é do tipo String e, para este exercício, é necessário implementar as seguintes operações:

- adição, usando a String `+`
- multiplicação, usando a String `*`
- divisão, usando a String `/`

## 2. Trata as operações ilegais

Atualiza o método `CalculatorConundrum.calculate()` para tratar operações ilegais:

- Quando o argumento `operation` é `null`, deve ser lançada uma `IllegalArgumentException` com a mensagem `Operation cannot be null`.
- Quando o argumento `operation` é `""`, deve ser lançada uma `IllegalArgumentException` com a mensagem `Operation cannot be empty`.
- Quando o argumento `operation` é uma operação diferente de `+`, `*` ou `/`, deve ser lançada uma `IllegalOperationException` com a mensagem `Operation '{operation}' does not exist`.

```java
calculator.calculate(10, 1, null);
// => throws IllegalArgumentException with message "Operation cannot be null"

calculator.calculate(10, 1, "");
// => throws IllegalArgumentException with message "Operation cannot be empty"

calculator.calculate(10, 1, "-");
// => throws IllegalOperationException with message "Operation '-' does not exist"
```

## 3. Trata a exceção lançada ao dividir por zero

Em Java, tentar dividir por zero lança uma `ArithmeticException`.
Atualiza o método `CalculatorConundrum.calculate()` para apanhar esta exceção e depois lançar uma `IllegalOperationException` com a mensagem `Division by zero is not allowed` e a `ArithmeticException` apanhada como causa.

```java
calculator.calculate(512, 0, "/");
// => throws IllegalOperationException with message "Division by zero is not allowed"
```
