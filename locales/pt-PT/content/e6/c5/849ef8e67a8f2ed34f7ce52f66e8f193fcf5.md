# Instalação

## Início rápido

``` shellsession
$ bash <(curl -s https://raw.githubusercontent.com/borkdude/babashka/master/install)
```

Por predefinição, isto instala-se em `/usr/local/bin`. Para alterar isto, indica o nome do diretório:

``` shellsession
$ bash <(curl -s https://raw.githubusercontent.com/borkdude/babashka/master/install) /tmp
```

## Brew

Os binários para Linux e macOS são disponibilizados através do brew.

Instalar:

    brew install borkdude/brew/babashka

Atualizar:

    brew upgrade babashka

## Arch (Linux)

O `babashka` está [disponível](https://aur.archlinux.org/packages/babashka-bin/) no [Arch User Repository](https://aur.archlinux.org). Podes instalá-lo com o teu assistente [AUR](https://aur.archlinux.org) preferido, como o
[yay](https://github.com/Jguer/yay), o [yaourt](https://github.com/archlinuxfr/yaourt), o [apacman](https://github.com/oshazard/apacman) e o [pacaur](https://github.com/rmarquis/pacaur). Aqui está um exemplo com o `yay`:

    yay -S babashka-bin

## Windows

No Windows, podes instalar com o [scoop](https://scoop.sh/) e o bucket
[scoop-clojure](https://github.com/littleli/scoop-clojure).

## Descarregar

Também podes descarregar um binário do
[Github](https://github.com/borkdude/babashka/releases). Para Linux, existe um
binário estático disponível que pode ser usado no Alpine.

## Docker

Vê a imagem no [Docker hub](https://hub.docker.com/r/borkdude/babashka/).
