# Introdução

[Intervalos][range] representam um intervalo entre dois valores.
Os intervalos são frequentemente usados com tipos como `Int`, `String` e `Character` para iterar sobre sequências, fatiar coleções ou verificar se um valor está dentro dos limites.

O Swift fornece dois operadores de intervalo principais:

- **Operador de intervalo fechado (`...`)**: Inclui tanto o valor inicial como o final (`1...5` inclui 1, 2, 3, 4 e 5).
- **Operador de intervalo semiaberto (`..<`)**: Inclui o valor inicial mas exclui o valor final (`1..<5` inclui 1, 2, 3 e 4).

```swift
let closed = 1...5
let halfOpen = 1..<5
```

~~~~exercism/note
Ao chamares um método diretamente num literal de intervalo, coloca a expressão do intervalo entre parênteses para que o compilador avalie primeiro o intervalo:

```swift
(1...5).contains(3) // Returns true
// 1...5.contains(3) // Error: value of type 'Int' has no member 'contains'
```
~~~~

## Converter um intervalo num array

Podes converter um intervalo de números num `Array` usando o inicializador `Array(_:)`:

```swift
let range = 1...5
let numbers = Array(range)
// numbers is [1, 2, 3, 4, 5]
```

## Fatiar um array com intervalos

Podes usar intervalos para fatiar subsecções de um array:

```swift
let array = [10, 20, 30, 40, 50]
let slice = array[1...3]
// slice contains [20, 30, 40]
```

## Propriedades e métodos dos intervalos

As operações comuns em intervalos incluem:

| Membro                  | Descrição                                                | Exemplo                              |
| ----------------------- | ---------------------------------------------------------- | ------------------------------------ |
| `count`                 | Devolve o número de elementos no intervalo                | `(1...5).count` devolve `5`          |
| [`contains(_:)`][contains] | Devolve `true` se o intervalo incluir o valor especificado | `(1...5).contains(3)` devolve `true` |

## Intervalos unilaterais

O Swift também suporta intervalos unilaterais (parciais), em que omites o valor inicial ou o valor final:

- `array[2...]`: Do índice 2 até ao fim da coleção.
- `array[...2]`: Do início da coleção até ao índice 2, inclusive.
- `array[..<2]`: Do início da coleção até ao índice 2, exclusive.

## Intervalos de strings e carateres

Também podes criar intervalos entre carateres ou strings que estão de acordo com `Comparable`:

```swift
let letters = "a"..."z"
print(letters.contains("m")) // Prints true
print(letters.contains("A")) // Prints false
```
