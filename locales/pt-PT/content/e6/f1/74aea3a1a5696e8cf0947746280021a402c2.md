# Instruções

Neste exercício, vais implementar a lógica da missão para um novo jogo de RPG que um amigo está a desenvolver.

A personagem principal do jogo é a Annalyn, uma rapariga corajosa com um cão de estimação feroz e leal. Infelizmente, o desastre acontece: o seu melhor amigo foi raptado enquanto procurava bagas na floresta.

A Annalyn vai tentar encontrar e libertar o seu melhor amigo, podendo levar o cão com ela nesta missão.

Depois de passar algum tempo a seguir o rasto do seu melhor amigo, encontra o acampamento onde ele está preso. Acontece que há dois raptores: um cavaleiro poderoso e um arqueiro astuto.

Depois de encontrar os raptores, a Annalyn pondera quais das seguintes ações pode realizar:

- _Ataque rápido_: pode fazer-se um ataque rápido se o cavaleiro estiver a dormir, pois ele demora algum tempo a vestir a armadura, ficando assim vulnerável.
- _Espionagem_: pode espiar-se o grupo se pelo menos um deles estiver acordado. Caso contrário, espiar é uma perda de tempo.
- _Sinalizar o prisioneiro_: pode sinalizar-se o prisioneiro com sons de aves se o prisioneiro estiver acordado e o arqueiro estiver a dormir, pois os arqueiros são treinados em sinalização com aves, pelo que poderiam intercetar a mensagem.
- _Libertar o prisioneiro_: a Annalyn pode tentar entrar furtivamente no acampamento para libertar o prisioneiro.
  Isto é arriscado e só pode resultar de uma de duas formas:
  - Se a Annalyn tiver o cão com ela, pode resgatar o prisioneiro se o arqueiro estiver a dormir.
    O cavaleiro tem medo do cão e o arqueiro não terá tempo de se preparar antes de a Annalyn e o prisioneiro conseguirem escapar.
  - Se a Annalyn não tiver o cão, então ela e o prisioneiro têm de ser muito furtivos!
    A Annalyn pode libertar o prisioneiro se este estiver acordado e o cavaleiro e o arqueiro estiverem ambos a dormir, mas se o prisioneiro estiver a dormir não pode ser resgatado: o prisioneiro assustar-se-ia com o aparecimento súbito da Annalyn e acordaria o cavaleiro e o arqueiro.

Tens quatro tarefas: implementar a lógica que determina se as ações acima estão disponíveis, com base no estado das três personagens encontradas na floresta e na presença ou não do cão da Annalyn.

## 1. Verifica se é possível fazer um ataque rápido

Implementa o método `can_fast_attack()`, que recebe um valor Boolean que indica se o cavaleiro está acordado. Este método devolve `TRUE` se for possível fazer um ataque rápido com base no estado do cavaleiro. Caso contrário, devolve `FALSE`:

```R
knight_is_awake <- TRUE
can_fast_attack(knight_is_awake)
# => FALSE
```

## 2. Verifica se é possível espiar o grupo

Implementa o método `can_spy()`, que recebe três valores Boolean, indicando se o cavaleiro, o arqueiro e o prisioneiro, respetivamente, estão acordados. O método devolve `TRUE` se for possível espiar o grupo, com base no estado das três personagens. Caso contrário, devolve `FALSE`:

```R
knight_is_awake <- FALSE
archer_is_awake <- TRUE
prisoner_is_awake <- FALSE
can_spy(knight_is_awake, archer_is_awake, prisoner_is_awake)
# => TRUE
```

## 3. Verifica se é possível sinalizar o prisioneiro

Implementa o método `can_signal_prisoner()`, que recebe dois valores Boolean, indicando se o arqueiro e o prisioneiro, respetivamente, estão acordados. O método devolve `TRUE` se for possível sinalizar o prisioneiro, com base no estado das duas personagens. Caso contrário, devolve `FALSE`:

```R
archer_is_awake <- FALSE
prisoner_is_awake <- TRUE
can_signal_prisoner(archer_is_awake, prisoner_is_awake)
# => TRUE
```

## 4. Verifica se é possível libertar o prisioneiro

Implementa o método `can_free_prisoner()`, que recebe quatro valores Boolean. Os três primeiros parâmetros indicam se o cavaleiro, o arqueiro e o prisioneiro, respetivamente, estão acordados. O último parâmetro indica se o cão da Annalyn está presente. O método devolve `TRUE` se for possível libertar o prisioneiro com base no estado das três personagens e na presença do cão da Annalyn. Caso contrário, devolve `FALSE`:

```R
knight_is_awake <- FALSE
archer_is_awake <- TRUE
prisoner_is_awake <- FALSE
pet_dog_is_present <- FALSE
can_free_prisoner(knight_is_awake, archer_is_awake, prisoner_is_awake, pet_dog_is_present)
# => FALSE
```
