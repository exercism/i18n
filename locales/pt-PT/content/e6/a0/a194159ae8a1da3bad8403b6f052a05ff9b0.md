# Introdução

As listas em C# são coleções de valores primitivos ou de instâncias de structs ou de classes. São implementadas na biblioteca de classes base como `List<T>`, em que `T` é o tipo do item da lista. A API expõe um conjunto rico de métodos para criar e manipular listas.

Os itens podem ser adicionados e removidos das listas. Estas crescem e encolhem conforme necessário.

```csharp
var listOfStrings = new List<string>();
```
