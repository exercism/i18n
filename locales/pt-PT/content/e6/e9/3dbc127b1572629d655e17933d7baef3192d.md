# Sobre

O CoffeeScript é uma linguagem que transpila para JavaScript, usada para criar sites dinâmicos (tanto no navegador como no servidor).
O transpilador é usado para transformar código CoffeeScript em JavaScript antes de o executar, de modo a manter a compatibilidade e o mesmo desempenho do JavaScript, oferecendo ao mesmo tempo muitas funcionalidades novas!

O CoffeeScript foi criado para oferecer uma forma simplificada de escrever JavaScript, com base numa mistura das linguagens Ruby e Python.
Uma diferença é o uso de indentação e setas para substituir o código verboso das funções em JavaScript, e introduz funcionalidades úteis das linguagens funcionais, incluindo a correspondência de padrões.

O CoffeeScript é uma de muitas linguagens novas que transpilam para JavaScript, incluindo TypeScript e Flow. A comunidade está a crescer e este tipo de linguagens é muito popular.
