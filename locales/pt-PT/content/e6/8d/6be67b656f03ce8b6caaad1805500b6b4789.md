# Dicas

## Geral

- `TUPLE:` e `boa` são declarados em vocabulários adjacentes ao `kernel`, por isso não é preciso nenhum USING especial para declarar a classe. As palavras de acesso vêm do [`accessors`][accessors].

## 1. A classe base

- `TUPLE: dragon name color age ;` declara a classe com os seus três campos, pela ordem indicada. `<dragon>` é uma única linha: `dragon boa`.

## 2. Os que cospem fogo

- Ao usar `<`, indicas a classe-mãe e os campos dela são herdados: `TUPLE: fire-dragon < dragon flame-temp ;`. O construtor `boa` recebe primeiro os campos da classe-mãe.

## 3. Os que cospem gelo

- A mesma forma da tarefa 2, mas com um campo extra diferente. As subclasses irmãs não interagem entre si: tanto `fire-dragon` como `ice-dragon` são subclasses diretas de `dragon`.

## 4. Os habitantes do vulcão

- Define `volcano-dragon` como subclasse de `fire-dragon` (não de `dragon` diretamente), para que herde tanto os campos de `dragon` como o `flame-temp` de `fire-dragon`. O construtor `boa` recebe cinco valores: name, color, age, flame-temp, lava-volume.

## 5. Envelhecer qualquer dragão

- `change-age` é o acessor que altera o valor: `( tuple quot -- tuple )` aplica a quotation à idade atual e escreve o resultado de volta. `[ 1 + ] change-age drop` incrementa a idade e descarta o tuplo devolvido. Como todos os descendentes herdam o campo, a mesma palavra funciona em todos eles.

[accessors]: https://docs.factorcode.org/content/vocab-accessors.html
