# Dicas

## 1. Tornar `preparation-time-in-minutes` mais fácil de usar

- Um "parâmetro rest" recolhe numa lista todos os argumentos que os outros parâmetros não consomem.
- Um "parâmetro rest" designa-se, na lista de parâmetros lambda, com a palavra-chave `&rest`.
- Podes usar a função `length` para obter o número de itens de uma lista.

## 2. Permitir alterar o tempo de forno esperado

- Um parâmetro opcional pode ser indicado ou não.
- Um parâmetro opcional pode ter um valor predefinido.
- Os parâmetros opcionais designam-se com a palavra-chave `&optional`.

## 3. A Lilly lembra-se de outro estilo de cozedura preferido

- Podes especificar um "parâmetro supplied-p" juntamente com o parâmetro opcional para determinar se quem chama forneceu o parâmetro.

## 4. Dividir as sobras

- Os parâmetros de palavra-chave têm nome e são opcionais.
- Os parâmetros de palavra-chave designam-se com a palavra-chave `&key`.

## 5. Fazer suposições

- Os parâmetros de palavra-chave podem ter valores predefinidos.

## 6. Quantidade normal de sobras

- Os parâmetros de palavra-chave podem ter um "parâmetro supplied-p", tal como os parâmetros opcionais.
