# Dicas

Usar números complexos para rotações em 2D pode deixar tudo muito mais limpo e numericamente mais preciso.

## 1. Construir um número complexo a partir de coordenadas cartesianas

- O método [`complex(x, y)`][complex] incorporado é mais eficiente do que atribuir `x + im*y`.
- Consulta a introdução para uma revisão.

## 2. Construir um número complexo a partir de coordenadas polares

- Há algumas formas equivalentes de o fazer (por exemplo, `exp`, `cis`, `cispi`).
- Consulta a introdução e as instruções para uma revisão mais aprofundada.

## 3. Efetuar uma rotação de vetor em 2D

- A [fórmula de Euler][euler] é a tua amiga aqui e podes usar a tua função `euler`.
- Há métodos para obter a parte [real][real] e a parte [imaginária][imaginary] de um número complexo, ou ambas!

## 4. Efetuar um deslocamento radial

- A tua função `euler` pode ser útil, ou não...
- O método [`angle`][angle] incorporado pode ser usado para encontrar rapidamente um argumento a partir de um número complexo.
- O método [`abs`][abs] pode ser usado para encontrar o módulo de um número complexo.

## 5. Encontrar a canção pretendida

- Esta é uma boa oportunidade para compor as tuas funções `rotate` e `rdisplace`.
