# Arrays

Em Cairo, um vetor é uma estrutura de dados que te permite armazenar uma coleção de elementos do mesmo tipo.
Os arrays em Cairo têm opções de modificação limitadas.
Só podes acrescentar elementos ao fim de um array e remover elementos do início.
Na verdade, os arrays são filas cujos valores não podem ser modificados.

## Construção de arrays

Os arrays constroem-se principalmente com o trait `ArrayTrait`, usando uma destas 4 formas de construir um array de elementos `[1, 2]`:

```rust
// 1. Passing the type to the `ArrayTrait`
let mut arr_type_in_trait = ArrayTrait::<felt252>::new();
arr_type_in_trait.append(1);
arr_type_in_trait.append(2);

// 2. Setting the type on the variable itself
let mut arr_explicit_type: Array<felt252> = ArrayTrait::new();
arr_explicit_type.append(1);
arr_explicit_type.append(2);

// 3. Using the `array!` macro
let mut arr_from_macro: Array<felt252> = array![1, 2]; // assign values in-line

// 4. Allowing the compiler to infer the type from the type of values being assigned to it
let mut arr_implicit_type = ArrayTrait::new(); // compiler "knows" this is a `felt252` array
arr_implicit_type.append(1);
arr_implicit_type.append(2);
```

> Cada chamada a `append()` coloca um novo número no fim do array.

## Remover elementos de um array

A única forma de remover elementos de um array em Cairo é pelo início.
Esta operação é feita pelo método `pop_front()`, que devolve um `Option` que pode ser desembrulhado, contendo o elemento removido, ou `Option::None` se o array estiver vazio.

```rust
fn main() {
    let mut a = array![10, 1, 2];
    let first_value = a.pop_front().unwrap(); // `unwrap()` is used to get the value from `Option`
    println!("The first value is {}", first_value); // prints "The first value is 10"
}
```

## Aceder a valores num array

Para acederes aos elementos de um array, podes usar os métodos `get()` ou `at()`, que devolvem tipos diferentes.
O equivalente a `arr.at(index)` é o operador de indexação `arr[index]`.

### Usar o método get()

O método `get()` é como procurar um item numa lista pelo seu número.
Funciona assim:

- `arr.get(index)` permite-te obter um item numa posição específica (índice) do array.
- Devolve um `Option::Some(value)` se o item existir no índice indicado, ou `Option::None` se o índice estiver fora dos limites.

Este método é ideal quando queres tratar casos em que o índice pode ser inválido sem que o teu programa rebente.

```rust
fn main() {
    let arr: Array<u32> = array![1, 2, 3];

    let index = 1;

    match arr.get(index) {
        Option::Some(value) => { println!("Element at index {}: {}", index, value.unbox()); },
        Option::None => { println!("Index {} is out of bounds!", index); }
    }
}
```

### Usar o método at()

O método `at()` dá-te diretamente um instantâneo do elemento num índice específico, usando a operação `unbox()` para extrair o valor guardado da caixa.
Uma forma abreviada deste método é usar o operador de indexação `arr[index]`.
Se tentares aceder a um índice que não existe (fora dos limites), o programa entra em pânico com um erro.

```rust
fn main() {
    let a: Array<u32> = array![5, 8];

    println!("First: {}", *a.at(0)); // prints "First: 5"
    println!("Second: {}", a[1]); // prints "Second: 8"
    println!("Third: {}", a[2]); // panics with 'Index out of bounds'
}
```

## Métodos relacionados com o tamanho

Para determinares o número de elementos de um array, usa o método `len()`.
O valor devolvido é do tipo `usize`.

Se quiseres verificar se um array está vazio ou não, podes usar o método `is_empty()`, que devolve `true` se o array estiver vazio e `false` caso contrário.

## `Span`

`Span` é uma struct que representa um instantâneo de um `Array`.
Foi concebido para dar acesso seguro e controlado aos elementos de um array sem modificar o array original.
O `Span` é especialmente útil para garantir a integridade dos dados e evitar problemas de empréstimo ao passar arrays entre funções ou ao realizar operações só de leitura.

> Todos os métodos fornecidos por `Array` também podem ser usados com `Span`, exceto o método `append()`.

Para criares um `Span` de um `Array`, chama o método `span()`:

```rust
let my_array: Array<u32> = array![1, 2, 3];
let my_span: Span<u32> = my_array.span();
```

## O tipo `Array` de tamanho fixo

Escrevemos os valores de um array de tamanho fixo como uma lista separada por vírgulas, entre parênteses retos.
O tipo do array escreve-se com parênteses retos, indicando o tipo de cada elemento, um ponto e vírgula e, por fim, o número de elementos do array.

```rust
let arr: [u64; 5] = [1, 2, 3, 4, 5];
```

> Nota: só os arrays de tamanho fixo podem ser usados como constantes

Podes aceder aos elementos de um array de tamanho fixo desconstruindo o array ou convertendo-o num `Span`, que suporta indexação.

```rust
fn main() {
    let arr = [1, 2, 3, 4, 5]; // implicit `felt252` array type

    // Accessing elements of a fixed-size array by deconstruction
    let [a, b, c, _, _] = arr;
    println!("c: {}", c); // c: 3
    
    // Accessing elements of a fixed-size array by index
    let my_span = arr.span();
    println!("my_span[2]: {}", my_span[2]); // my_span[2]: 3
}
```
