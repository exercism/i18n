# Instruções

As audições para a peça da escola terminaram e o encenador precisa de ter as decisões por escrito.

As quatro tarefas ficam na classe `CASTING_CALL`.

## 1. O veredicto

Todos os candidatos são avaliados numa escala de zero a dez. Com oito ou mais, ficam no elenco; entre cinco e sete, são chamados de novo; abaixo de cinco, recebem um agradecimento.

```sather
CASTING_CALL::audition_outcome(8)
-- => "Cast"
CASTING_CALL::audition_outcome(6)
-- => "Recalled"
CASTING_CALL::audition_outcome(2)
-- => "Thank you"
```

## 2. Que grupo?

Os candidatos com menos de 13 anos são Juniors. Dos 13 aos 15, são Middles. A partir dos 16, Seniors.

```sather
CASTING_CALL::age_group(13)
-- => "Middles"
```

## 3. Quando voltar

Os Juniors são chamados de novo às quatro, os Middles às cinco e todos os outros às seis.

```sather
CASTING_CALL::callback_time("Middles")
-- => "5pm"
```

O argumento é o nome de um grupo, escrito exatamente como na tarefa 2.

## 4. O que escrever na folha

Quem tiver uma pontuação de oito ou mais e souber cantar é um `"Lead"`. Oito ou mais sem saber cantar é `"Speaking part"`. Todos os outros são `"Chorus"`.

```sather
CASTING_CALL::casting_note(9, true)
-- => "Lead"
CASTING_CALL::casting_note(9, false)
-- => "Speaking part"
CASTING_CALL::casting_note(4, true)
-- => "Chorus"
```
