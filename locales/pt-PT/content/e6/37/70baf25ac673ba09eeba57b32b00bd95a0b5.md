# Introdução

Quando uma quotation precisa de *recordar* valores do ambiente que a rodeia, o Factor oferece duas ferramentas: `curry`/`compose` da [`kernel`][kernel], e a sintaxe fry `'[ … ]` da [`fry`][fry].

O `curry` incorpora um valor no início de uma quotation:

```
curry ( value quot -- newquot )
```

```factor
3 [ + ] curry .          ! => [ 3 + ]
10 3 [ + ] curry call .  ! => 13
```

O `compose` junta duas quotations:

```factor
[ 1 + ] [ 2 * ] compose .       ! => [ 1 + 2 * ]
5 [ 1 + ] [ 2 * ] compose call . ! => 12
```

Para mais do que uma ou duas capturas, o fry é mais claro. Cada marcador `_` é preenchido, por ordem, com um valor retirado da pilha:

```factor
2 3 '[ _ _ + + ] .    ! => [ 2 3 + + ]
```

O fry também chega às quotations aninhadas.

[fry]: https://docs.factorcode.org/content/vocab-fry.html
