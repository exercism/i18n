## 1. Calcula o valor de uma carta

- As instruções [cmp][cmp] e [test][test] são úteis para definir flags de acordo com certas condições testadas.
- As instruções [jmp][jmp] e [jcc][jcc] são úteis para ramificar consoante as flags definidas anteriormente.
- Quando chamas uma função, a função chamada pode alterar um registo que estás a usar.
- Podes usar `cmp` para comparar duas cartas, definindo as flags adequadas.
- Podes usar `je` ou `jz` para ramificar se um número for igual ao outro.
- Podes usar `jl` para ramificar se um número for menor do que o outro.

## 2. Determina qual das cartas tem um valor mais alto

- Quando chamas uma função, a função chamada pode alterar um registo que estás a usar.
- Depois de definires a função `value_of_card`, podes chamá-la a partir de outras funções.
- Podes usar `cmp` para comparar duas cartas, definindo as flags adequadas.
- Podes usar `jg` para ramificar se um número for maior do que o outro, e `jl` para ramificar se for menor.
- Se ambas as cartas tiverem o mesmo valor, a segunda é devolvida em `rdx`. Caso contrário, `rdx` deve ser definido como 0.
