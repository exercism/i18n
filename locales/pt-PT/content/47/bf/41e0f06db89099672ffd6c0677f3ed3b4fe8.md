# Instalação

A versão atual do Elm é a 0.19.1.
As instruções de instalação mudam à medida que a linguagem evolui.
Para instruções de instalação atualizadas, consulta as
[instruções de instalação do guia do Elm][elm-install].

[elm-install]: https://guide.elm-lang.org/install/elm.html

## Ferramentas adicionais

**elm-test**

A ferramenta usada para correr os testes a partir da linha de comandos chama-se elm-test.
Atualmente, o elm-test requer o Node.js e o npm, por isso, se ainda não o fizeste,
[instala primeiro o Node.js e o npm][npm-install].
Depois de teres o npm instalado, podes instalar o elm-test com:

```shell
npm install --global elm-test@latest-0.19.1
```

Mais informações disponíveis na [página inicial do elm-test no npm][elm-test].

[npm-install]: https://www.npmjs.com/get-npm
[elm-test]: https://www.npmjs.com/package/elm-test

**elm-format**

A maioria dos programadores de Elm usa o elm-format para formatar o seu código Elm.
É uma ferramenta de formatação de código sem configuração.
Pode parecer um pouco frustrante ao início, se não estiveres habituado
a ferramentas de formatação automática, mas, depois de te habituares,
começas a perguntar-te como é que conseguías programar sem ela.
Também pode ser instalado com o npm:

```shell
npm install --global elm-format@latest-0.19.1
```

Mais informações disponíveis na [página inicial do elm-format no GitHub][elm-format].

[elm-format]: https://github.com/avh4/elm-format

**Editor de texto**

O suporte para Elm é bom, pelo menos, no [IntelliJ][intellij],
e em editores de texto compatíveis com o [servidor de linguagem do Elm][els],
como o VS Code, o Sublime Text ou o Vim.

[els]: https://github.com/elm-tooling/elm-language-server
[intellij]: https://github.com/klazuka/intellij-elm

## Erros de permissão com o npm

Podes estar a deparar-te com um erro de permissões EACCESS com o npm
ao instalar o elm-test ou o elm-format.
Se for esse o caso, segue as instruções no site do npm.
[Resolver erros de permissões EACCES ao instalar pacotes globalmente][eaccess].

[eaccess]: https://docs.npmjs.com/resolving-eacces-permissions-errors-when-installing-packages-globally
