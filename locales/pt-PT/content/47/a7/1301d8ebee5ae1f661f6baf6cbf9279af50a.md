# Dicas

## 1. Define o intervalo de filas e colunas

- Há um [operador][swift-range-docs] para criar um intervalo, que podes usar tanto com strings como com números inteiros.

## 2. Verifica se a casa é válida

- Há um [método][contains-docs] para verificar se um valor está dentro de um intervalo.

## 3. Obtém a linha

- Cada linha deve ter 8 de comprimento.
- Para cada linha, a começar em 1, tens de deslocar o início e o fim em 8.
- Podes usar um intervalo para obter um subarray do array.
