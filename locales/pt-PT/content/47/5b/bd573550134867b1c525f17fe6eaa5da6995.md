# Anexo às instruções

## Dicas

Precisas de implementar a função

```haskell
value :: (Color, Color) -> Int
```

que aceita apenas duas cores e produz a componente numérica da resistência do resistor.

**Bónus - testes de propriedades:**

Este exercício é uma boa oportunidade para escreveres alguns [testes de propriedades](https://en.wikipedia.org/wiki/Property_testing). Se nunca escreveste nenhum, aqui ficam alguns recursos:

1. [School of Haskell](https://www.schoolofhaskell.com/user/pbv/an-introduction-to-quickcheck-testing).
2. [Real world Haskell](http://book.realworldhaskell.org/read/testing-and-quality-assurance.html)

Fornecemos um exemplo de teste de propriedade QuickCheck no ficheiro de testes.

Exemplos de propriedades que podem ser testadas:

- `value (x, y) >= 10` para todos os `(x, y)` em que `x` não é `Black`

- Chamar `show` a `value (x, y)` produz a `String` que se obtém ao aplicar `reverse` ao resultado de chamar `show` a `value (y, x)`.

- Todas as cores têm nomes únicos. (Para quaisquer duas cores, se as cores forem diferentes, os nomes também são.)
