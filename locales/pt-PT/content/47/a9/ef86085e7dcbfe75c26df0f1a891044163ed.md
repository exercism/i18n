# Introdução

O operador `|>` chama-se operador pipe. Pode ser usado para encadear chamadas de funções, de modo a que o valor devolvido pela chamada de função anterior seja passado como primeiro argumento da chamada de função seguinte.

```elixir
"hello"
|> String.upcase()
|> Kernel.<>("?!")

# => "HELLO?!"
```
