# Ajuda

## Instalação do Rust

Consulta a [página de ajuda do Exercism][help-page] para saberes como instalar o Rust e para encontrares recursos de aprendizagem.

## Submeter a solução

Em geral, deves submeter todos os ficheiros em que implementaste a tua solução (`src/lib.rs` na maioria dos casos). Se estiveres a usar crates externas, considera submeter também o ficheiro `Cargo.toml`. Isto torna o processo de revisão mais rápido e mais claro.

## Comentários, problemas e pull requests

Vai ao [fórum](https://forum.exercism.org/c/programming/rust/) e cria uma publicação para deixar os teus comentários sobre um exercício ou se quiseres ajudar a implementar novos exercícios.
Os membros da equipa da track de Rust terão todo o gosto em ajudar!

O [repositório da track][github] no GitHub é onde vivem todos os exercícios de Rust.

Se quiseres saber mais sobre o Exercism, dá uma vista de olhos ao [guia de contribuição].

## Submeter soluções incompletas
É possível submeter uma solução incompleta, para veres como outras pessoas resolveram o exercício.
