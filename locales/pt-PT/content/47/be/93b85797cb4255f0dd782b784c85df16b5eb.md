# utilização de cabeçalho de função

[comment]: # (Este erro é apresentado quando a solução usa um cabeçalho de função)

Um cabeçalho de função (uma definição de função sem corpo) só é necessário para funções com argumentos predefinidos que têm várias cláusulas.

```elixir
# necessary function header
def hello(what \\ "World")
def hello("Alice"), do: "Hello, darling!"
def hello(name), do: "Hello, #{name}!"
```

Para funções com argumentos predefinidos que têm apenas uma cláusula, podes especificar os argumentos predefinidos diretamente nessa cláusula.

```elixir
# preferred
def bye(name \\ "World"), do: "See you, #{name}!"

# not preferred - unnecessary function header
def bye(what \\ "World")
def bye(name), do: "See you, #{name}!"
```

A função `two_fer/1` só precisa de uma cláusula, por isso não precisa de um cabeçalho de função.
