# Tuplas

As tuplas são uma forma leve de agrupar um conjunto fixo de dados de tipos arbitrários. Uma tupla não tem um nome específico; dar um nome a uma estrutura de dados transforma-a numa `struct`. Os campos de uma tupla não têm nomes; acede-se a eles por desestruturação ou por posição.

## Sintaxe

As tuplas são uma lista de campos rodeada por parênteses:

- `()` é o `unit type`, que é um [caso especial](https://doc.rust-lang.org/std/primitive.unit.html)
- **(** _expressão_ **,)** é uma expressão de tupla de um único elemento
- **(** _Tipo_ **,)** é um tipo de tupla de um único elemento
- **(** _expressão_ **,** ... **)** é uma expressão geral de tupla
- **(** _Tipo_ **,** ... **)** é um tipo geral de tupla

### Criação

As tuplas são sempre criadas com uma expressão de tupla:

```rust
// pointless but legal
let unit = ();
// single element
let single_element = ("note the comma",);
// two element
let two_element = (123, "elements can be of differing types");
```

As tuplas podem ter um número arbitrário de elementos.

### Acesso por desestruturação

É possível aceder aos elementos de uma tupla por desestruturação. Isto significa apenas atribuir nomes de variáveis aos elementos individuais da tupla, consumindo-a.

```rust
let (elem1, _elem2) = two_element;
assert_eq!(elem1, 123);
```

### Acesso por posição

Também é possível aceder aos elementos de uma tupla através de um índice posicional numérico. A indexação, como sempre, começa em 0.

```rust
let notation = single_element.0;
assert_eq!(notation, "note the comma");
```

## Structs de tuplas

Também te será pedido que trabalhes com structs de tuplas. Tal como as structs normais, são tipos com nome; ao contrário das structs normais, têm campos anónimos. A sua sintaxe é muito semelhante à sintaxe normal de tuplas. É possível usar tanto a desestruturação como o acesso posicional.

```rust
struct TupleStruct(u8, i32);
let my_tuple_struct = TupleStruct(123, -321);
let borrowed_neg = &my_tuple_struct.1;
let TupleStruct(borrowed_byte, _) = &my_tuple_struct;
assert_eq!(borrowed_neg, &-321);
assert_eq!(borrowed_byte, &123);
```

### Visibilidade dos campos

Todos os campos de tuplas anónimas são sempre públicos. No entanto, os campos das structs de tuplas têm visibilidade individual, que é privada por omissão, tal como os campos das structs padrão. Podes tornar os campos públicos com o modificador `pub`, tal como numa struct padrão.

```rust
// fails due to private fields
mod tuple { pub struct TupleStruct(u8, i32); }
fn main() { let _my_tuple_struct = tuple::TupleStruct(123, -321); }
```

```rust
// succeeds: fields are public
mod tuple { pub struct TupleStruct(pub u8, pub i32); }
fn main() { let _my_tuple_struct = tuple::TupleStruct(123, -321); }
```
