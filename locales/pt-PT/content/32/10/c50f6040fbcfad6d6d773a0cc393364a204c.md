# Sobre

As tuplas são usadas frequentemente para agrupar informação de forma informal. Um padrão comum em Elixir é agrupar os valores devolvidos por uma função com um estado.

```elixir
File.read("hello.txt")
# => {:ok, "World"}

File.read("invalid.txt")
# => {:error, :enoent}
```

- Os literais de tuplas são delimitados por chavetas, `{}`.
- As tuplas podem conter qualquer tipo de dados em memória contígua, que é alocada quando a tupla é criada.
- As tuplas permitem acesso de leitura em tempo constante.
- Ao manipular uma tupla, em vez de alterar a tupla existente, é criada uma nova.
- As características de desempenho das tuplas tornam-nas ideais para guardar informação relacionada em conjunto, mas não para guardar coleções de itens que seja necessário iterar ou que possam crescer ou diminuir. Neste último caso, [uma lista é mais adequada][getting-started-lists-or-tuples].
- Os módulos [`Kernel`][kernel-module] e [`Tuple`][tuple-module] têm funções úteis para trabalhar com tuplas.
