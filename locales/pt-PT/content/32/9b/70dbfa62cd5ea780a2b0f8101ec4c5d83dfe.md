# Introdução

Além da condicional, o JavaScript também tem a instrução switch para executar lógica de forma condicional.
Usa-se quando é preciso comparar uma única variável com várias variantes.
A comparação é feita verificando a igualdade estrita (`===`); consulta o [conceito de comparação][concept-comparison].
Para uma variável `x`, a instrução switch em JavaScript tem a seguinte sintaxe.

<!-- prettier-ignore-start -->
```javascript
switch (x) {
  case option1:
    // code that is executed when "x === option1" is true
    break;
  case option2:
    // code that is executed when "x === option2" is true
    break;
  default:
    // code that is executed when x does not equal any of the options
}
```
<!-- prettier-ignore-end -->

O caso `default` é opcional e usa-se quando queres executar algum código se nenhuma das outras opções corresponder à variável.

As instruções `break` acima são necessárias porque, por predefinição, todos os casos são "fallthrough" em JavaScript.
Isso significa que, sem qualquer instrução `break`, todo o código dos casos abaixo da primeira opção correspondente seria executado, mesmo que `x` não correspondesse a essas opções.
Este comportamento de "fallthrough por predefinição" é uma armadilha comum quando se usa `switch` em JavaScript.
Dentro de uma função, também se pode usar `return` em vez de `break` para evitar este problema.
