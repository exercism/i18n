# Dicas

## Geral

- Lê sobre [compreensões][elixir-comprehensions] no guia de introdução.
- Lê sobre [listas][elixir-lists] no guia de introdução.
- Lê sobre [mapas][elixir-maps] no guia de introdução.
- Lê sobre [listas de palavras-chave][elixir-kwlists] no guia de introdução.

## 1. Sugere uma combinação

- Na compreensão de listas, usa dois _geradores_ para criar o produto cartesiano.

## 2. Filtra as combinações de roupa que chocam

- Podes usar _pattern matching_ para desconstruir no _gerador_ e associar os campos a uma variável.
- Usa uma expressão _filter_ para devolver false quando as cores de base coincidem.

## 3. Filtra por preço da combinação

- Há várias [funções de listas de palavras-chave][kw-module] disponíveis para obteres opções de uma lista de palavras-chave.
- Usa uma expressão _filter_ para devolver false quando o preço da combinação for superior ao preço máximo.
