# Apêndice às instruções

A exponenciação de números racionais com um número real exige calcular um número elevado a uma potência não inteira, uma funcionalidade que não está disponível nativamente em WebAssembly.

No entanto, também podes exprimir `x ^ y` como `x ^ y = exp(y * ln(x))`.

E, felizmente, é possível usar séries diferentes para calcular a exponencial e o logaritmo natural.

## Função exponencial

A melhor solução para a exponencial é uma [série de Taylor](https://en.wikipedia.org/wiki/Taylor_series):

```
exp(x) ≃ 1 + x + x ^ 2 / 2! + x ^ 3 / 3! + x ^ 4 / 4! + ... + x ^ n / n!
```

## Função logarítmica (para x positivo)

Há várias formas de calcular eficientemente um logaritmo natural. Uma delas é uma série baseada numa [tangente hiperbólica inversa](https://en.wikipedia.org/wiki/Logarithm#Inverse_hyperbolic_tangent):

```
ln(x) / 2 ≃ y + y ^ 3 / 3 + y ^ 5 / 5 + ... + y ^ n / n where y = (x - 1) / (x + 1)
```

Há também outra série de Taylor para calcular o logaritmo natural:

```
ln(x) = (x - 1) - (x - 1) ^ 2 / 2 + (x  - 1) ^ 3 / 3 - (x - 1) ^ 4 / 4 ... + (x - 1) ^ n / n
```

Só é precisa para `x` entre 0 e 2. No entanto, também podemos usar `ln(x) = - ln(1 / x)`

## Exponenciação com expoentes inteiros

Para a exponenciação com expoentes inteiros, é melhor usar multiplicação e um ciclo ou recursão, tanto por razões de desempenho como de precisão. Para mais desempenho, podes usar o [método de Horner](https://en.wikipedia.org/wiki/Horner%27s_method) para reduzir o número de multiplicações.
