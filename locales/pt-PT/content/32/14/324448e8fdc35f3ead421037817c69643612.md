# Instruções

Enquanto planeiam uma noite de jogos com amigos, o grupo decide revisitar os favoritos da sua infância. O teu amigo alemão propõe o _Mensch ärgere Dich nicht_ (_Homem, não te irrites_), um clássico em muitos países europeus (semelhante ao _Ludo_ inglês ou ao _Parcheesi_ norte-americano).

Para te preparares para o jogo, decides implementar a função de lançamento de dados em Elixir.

Em _Mensch ärgere Dich nicht_, os jogadores lançam um dado de 6 faces para determinar o próximo movimento. Se tiverem sorte e tirarem um 6, podem lançar e mover outra vez.

## 1. Faz um lançamento de um dado de 6 faces

Implementa a função `d6/0`, que escolhe aleatoriamente um número inteiro entre 1 e 6 em cada chamada.

```elixir
MenschAergereDichNicht.d6()
# => 1
MenschAergereDichNicht.d6()
# => 5
```

## 2. Continua a lançar enquanto tirares seis

Implementa a função `roll/0`. Deve devolver um stream de lançamentos de dados. Os lançamentos de dados devem seguir as regras do jogo. Se sair um seis, posso lançar outra vez. Caso contrário, para de lançar. Usa a função `d6/0` definida no passo anterior.

```elixir
MenschAergereDichNicht.roll() |> Enum.to_list()
# => [5]
MenschAergereDichNicht.roll() |> Enum.to_list()
# => [6, 3]
```

## 3. Permite usar um dado viciado

Para facilitar o teste do teu código, permite usar um dado viciado.

Estende a função `roll/0`. Deve aceitar um argumento opcional: uma função. Se o argumento for passado, usa-o para fazer o lançamento do dado. Caso contrário, recorre à função `MenschAergereDichNicht.d6/0`.

```elixir
MenschAergereDichNicht.roll(fn -> 3 end) |> Enum.to_list()
# => [3]
```
