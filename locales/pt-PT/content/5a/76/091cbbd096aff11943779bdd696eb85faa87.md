## General

- Para definir uma string, podes usar aspas duplas `"`.
- Para concatenar strings, podes usar o operador `+`.
- Podes usar `#{}` para interpolar uma string.

## 1. Dá as boas-vindas a um novo convidado na festa

- Podes concatenar uma string com outra string usando o operador `+`.

## 2. Dá as boas-vindas a um novo convidado que faz anos hoje

- Para converter um número numa string, podes usar o método `to_s`.

## 3. Dá indicações

- Para arredondar um número, podes usar o método `round`.
- Para obteres um caráter numa string, podes usar o método `[]`, que recebe um número inteiro, que é um índice.
