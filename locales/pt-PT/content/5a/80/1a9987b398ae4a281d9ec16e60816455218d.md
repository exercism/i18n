# Introdução

O Elixir suporta muitas funções para trabalhar com bits no _módulo Bitwise_.

- `band/2`: AND bit a bit
- `bsl/2`: deslocamento à esquerda bit a bit
- `bsr/2`: deslocamento à direita bit a bit
- `bxor/2`: XOR bit a bit
- `bor/2`: OR bit a bit
- `bnot/1`: NOT bit a bit

Aqui tens um exemplo de como usar uma função bit a bit:

```elixir
Bitwise.bsl(1, 3)
# => 8
```

Todas as funções bit a bit só funcionam com números inteiros.

Se estiveres a correr a versão 1.9 ou inferior do Elixir, terás de chamar `require Bitwise` no início da definição do módulo para poderes usar o módulo _Bitwise_.
