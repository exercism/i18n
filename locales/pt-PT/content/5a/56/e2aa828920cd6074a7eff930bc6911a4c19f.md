# Instruções

A Mary é uma grande fã da série de televisão _Star Trek: The Next Generation_. Muitas vezes joga jogos de interpretação de papel e lápis, onde ela e os amigos fingem ser a tripulação da _Starship Enterprise_. A personagem da Mary é o Capitão Picard, o que significa que ela tem de manter o diário de bordo do capitão. Ela adora a parte criativa do jogo, mas não gosta de gerar dados aleatórios no momento.

Ajuda a Mary a criar geradores aleatórios para dados que aparecem frequentemente no diário de bordo do capitão.

## 1. Gera um planeta aleatório

A _Starship Enterprise_ encontra muitos planetas nas suas viagens. Os planetas no universo de Star Trek são divididos em categorias com base nas suas propriedades. Por exemplo, a Terra é um planeta de classe M. Todas as classes planetárias possíveis são: D, H, J, K, L, M, N, R, T e Y.

Implementa a função `random_planet_class/0`. Deve devolver uma das classes planetárias aleatoriamente.

```elixir
CaptainsLog.random_planet_class()
# => "K"
```

## 2. Gera um número de registo aleatório para a nave estelar

A Enterprise (número de registo NCC-1701) não é a única nave estelar a voar por aí! Quando se encontra com outra nave estelar, a Mary precisa de registar o número de registo dessa nave.

Os números de registo começam com o prefixo "NCC-" e depois usam um número de 1000 a 9999 (inclusive).

Implementa a função `random_ship_registry_number/0` que devolve um número de registo de nave estelar aleatório.

```elixir
CaptainsLog.random_ship_registry_number()
# => "NCC-1947"
```

## 3. Gera uma data estelar aleatória

Qual é a utilidade de um diário de bordo se não incluir datas?

Uma data estelar é um número de vírgula flutuante. As aventuras da _Starship Enterprise_ da primeira temporada de _The Next Generation_ ocorrem entre as datas estelares 41000.0 e 42000.0. O "4" representa o século XXIV, o "1" a primeira temporada.

Implementa a função `random_stardate/0` que devolve um número de vírgula flutuante entre 41000.0 (inclusive) e 42000.0 (exclusive).

A implementação deve usar uma função Erlang.

```elixir
CaptainsLog.random_stardate()
# => 41458.15721310934
```

## 4. Formata a data estelar

No diário de bordo do capitão, as datas estelares são geralmente arredondadas a uma única casa decimal.

Implementa a função `format_stardate/1` que recebe um número de vírgula flutuante e devolve uma string com o número arredondado a uma única casa decimal.

A implementação deve usar uma função Erlang.

```elixir
CaptainsLog.format_stardate(41458.15721310934)
# => "41458.2"
```
