# Instruções específicas de SQLite

* A coluna **digits** contém uma lista de números inteiros codificada em JSON.
  Exemplo:
  ```json
  [1,0,1,0,1,0]
  ```
* A coluna **result** deve conter dados codificados em JSON: um objeto com os algarismos como números inteiros ou uma descrição de eventuais erros.
  Exemplos:
  ```json
  {"digits":[1,0,1,0,1,0]}
  ```
  ou
  ```json
  {"error":"some error description"}
  ```

## Esquema da tabela

```sql
CREATE TABLE IF NOT EXISTS "all-your-base" (
  input_base  INTEGER NOT NULL,
  digits      TEXT    NOT NULL, -- json array
  output_base INTEGER NOT NULL,
  result      TEXT              -- json object
);
```
