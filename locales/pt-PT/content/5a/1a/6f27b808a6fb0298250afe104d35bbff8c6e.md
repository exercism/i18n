# Clonar o percurso ABAP

## Pré-requisitos

1. Sistema ABAP versão 7.4 ou superior
2. abapGit v1.115.0 ou superior
3. Autorizações para implementar pacotes, programas e classes ABAP

## Instalar o abapGit

O percurso ABAP com todos os exercícios está implementado como um repositório abapGit. Para clonar o percurso para o teu próprio sistema, tens primeiro de instalar o abapGit.

1. Vai a [https://github.com/abapGit/abapGit](https://github.com/abapGit/abapGit)
2. Descarrega o ficheiro `zabapgit_standalone.prog.abap`
3. Cria o programa `zabapgit_standalone` no teu próprio sistema
4. Carrega o código-fonte de `zabapgit_standalone.prog.abap` para o programa `zabapgit_standalone`
5. Ativa o programa

## Instalar o percurso ABAP do Exercism

### Repositório online

Usa este método se o teu sistema estiver ligado à Internet e tiver acesso a GitHub.com (abordagem recomendada).

1. Executa o abapGit

![Repositório online do abapGit](https://github.com/exercism/abap/blob/main/docs/clone_01.png?raw=true)

2. Em "Repository Overview", seleciona "New Online"
3. Introduz os seguintes valores
- URL: `https://github.com/exercism/abap`
- Package: `$exer`
- Display Name: `Exercism - ABAP Track`

Nota: se o nome do pacote for demasiado longo, como `$exercism`, vais receber um erro ao tentar importar o repositório. Mantém o nome curto como indicado acima.

![Repositório online do abapGit](https://github.com/exercism/abap/blob/main/docs/clone_02.png?raw=true)

4. Seleciona "Create Online Repository". Deves ver uma lista de objetos com o estado "A":

![Repositório online do abapGit](https://github.com/exercism/abap/blob/main/docs/clone_03.png?raw=true)

5. Seleciona "Pull" para clonar todos os objetos para o teu sistema. Quando terminar, deves ver todos os objetos com o estado em branco

![Repositório online do abapGit](https://github.com/exercism/abap/blob/main/docs/clone_04.png?raw=true)

### Repositório offline

Usa este método se o teu sistema *não* estiver ligado à Internet.

1. Vai a [https://github.com/exercism/abap](https://github.com/exercism/abap)
2. Descarrega o ficheiro ZIP do repositório

![Repositório offline do abapGit](https://github.com/exercism/abap/blob/main/docs/clone_10.png?raw=true)

3. Executa o abapGit
4. Em "Repository Overview", seleciona "New Offline"
5. Introduz os seguintes valores
- Repository Name: `Exercism - ABAP Track`
- Package: `$exer`

![Repositório offline do abapGit](https://github.com/exercism/abap/blob/main/docs/clone_11.png?raw=true)

6. Seleciona "Create Offline Repository"

![Repositório offline do abapGit](https://github.com/exercism/abap/blob/main/docs/clone_12.png?raw=true)

7. Seleciona "Import ZIP" e escolhe o ficheiro ZIP que descarregaste. Deves ver uma lista de objetos com o estado "A":

![Repositório offline do abapGit](https://github.com/exercism/abap/blob/main/docs/clone_13.png?raw=true)

8. Seleciona "Pull ZIP" para clonar todos os objetos para o teu sistema. Quando terminar, deves ver todos os objetos com o estado em branco

![Repositório offline do abapGit](https://github.com/exercism/abap/blob/main/docs/clone_14.png?raw=true)

## Desinstalar o percurso ABAP do Exercism

Podes remover todos os objetos do teu sistema da seguinte forma:

1. Executa o abapGit
2. Vai ao repositório `Execism - ABAP Track`
3. Seleciona "Advanced > Uninstall"
4. Confirma a eliminação de todos os objetos e do repositório

## Resolução de problemas

- Em caso de problemas de ligação, consulta [Configuração de SSL](https://docs.abapgit.org/user-guide/setup/ssl-setup.html)
- Em caso de erro `Package $EXERCISM_DIFFERENCE-OF-SQUARES exceeds ABAP 30-characters name limit`, usa um nome de pacote mais curto, como `$exer`.
- Alguns ficheiros vão mostrar diferenças depois de fazeres pull para o teu sistema ABAP. As diferenças relacionadas com caracteres de fim de ficheiro ou marcas de ordem de bytes podem ser ignoradas.
