# Char

`Char` é um tipo de dados em Crystal que representa um ponto de código [Unicode][unicode] de 32 bits.
O seu tamanho torna-os eficientes em termos de memória e dá-lhes propriedades específicas que as Strings não têm.
São criados com plicas (`'`) e só permitem que se coloque lá dentro um único ponto de código Unicode.

```crystal
'a' # => 'a'
'a'.class # => Char
```

É bastante comum trabalhar com Chars quando se trabalha com Strings em Crystal, já que vários métodos da classe String devolvem Chars ou recebem Chars como argumentos.
Por exemplo, o método [`String#[]`][index] devolve um Char, e o método [`String#chars`][chars] devolve uma coleção de Chars.

## Incremento e decremento

Como um char é um ponto Unicode de 32 bits, suporta incremento e decremento. Assim, se tiveres `'a'`, podes obter `'b'` somando um.

```crystal
'a' + 5
# => 'f'

'z' - 25
# => 'a'
```

Existe também o método [`Char#succ`][succ], que devolve o char seguinte na tabela Unicode, e o [`Char#pred`][pred], que devolve o char anterior na tabela Unicode.

```crystal
'a'.succ
# => 'b'

'z'.pred
# => 'y'
```

## Concatenação

Como os Chars só servem para representar um ponto Unicode de 32 bits, não é possível concatenar dois chars.
Por isso, os Chars só podem ser concatenados com Strings.

```Crystal
'a' + "bc"
# => "abc"

'a' + 'b'
# => error: expected argument #1 to 'Char#+' to be Int or String, not Char
```

## Métodos de propriedades

Crystal tem alguns métodos para obter informações sobre um caráter, como saber se é um número ou uma letra, ou se está em maiúsculas ou minúsculas.
Eis uma lista de alguns dos métodos. Para a lista completa, consulta a [API de Char][char-api]:

| Method                           | Description                                          |
| -------------------------------- | ---------------------------------------------------- |
| [`Char#number?`][number]         | Devolve `true` se o Char for um número               |
| [`Char#letter?`][letter]         | Devolve `true` se o Char for uma letra               |
| [`Char#lowercase?`][lowercase]   | Devolve `true` se o Char estiver em minúsculas       |
| [`Char#uppercase?`][uppercase]   | Devolve `true` se o Char estiver em maiúsculas       |
| [`Char#ascii?`][ascii]           | Devolve `true` se o Char for um caráter ASCII        |
| [`Char#whitespace?`][whitespace] | Devolve `true` se o Char for um caráter de espaço em branco |

## Conversão

### Converter entre pontos de código e Chars

Como um Char é um ponto de código Unicode de 32 bits, podes converter entre Chars e pontos de código (Int).
Podes fazê-lo com o método [`Char#ord`][ord], que devolve o ponto de código do Char, ou com o método [`Int#chr`][chr], que devolve o Char correspondente ao ponto de código.

```crystal
'a'.ord
# => 97

97.chr
# => 'a'
```

### Converter entre tipos

Tal como acontece com outros tipos de dados, os chars têm alguns métodos para converter entre tipos.
O mais comum é o método `Char#to_s`, que converte o Char numa String. No entanto, existem também o método `Char#to_i`, que converte o Char num Int, e o método `Char#to_f`, que converte o Char num Float.

```crystal
'a'.to_s
# => "a"

'4'.to_i
# => 4

'a'.to_i
# => Error: Invalid integer: a (ArgumentError)
```

## Caracteres de escape

Tal como acontece com as Strings, há certos carateres que não podem ser escritos diretamente e, para os escrever, precisas de os escapar.
Podes usar o caráter `\` para escrever uma sequência de escape seguida do caráter que queres escapar.

Estes são os carateres especiais em Crystal:

| Value    | Description                   |
| -------- | ----------------------------- |
| `\a`     | Alerta                        |
| `\b`     | Retrocesso                    |
| `\e`     | Escape                        |
| `\f`     | Avanço de página              |
| `\n`     | Avanço de linha ou nova linha |
| `\r`     | Retorno de carro              |
| `\t`     | Tabulação horizontal          |
| `\v`     | Tabulação vertical            |
| `\\`     | Barra invertida               |
| `\'`     | Plica                         |
| `\"`     | Aspas                         |
| `\377`   | Caráter ASCII octal           |
| `\xFF`   | Caráter ASCII hexadecimal     |
| `\uFFFF` | Caráter Unicode hexadecimal   |
