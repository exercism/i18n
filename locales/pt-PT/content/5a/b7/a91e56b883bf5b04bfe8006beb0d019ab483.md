# Introdução

## Boolean em R

Os valores verdadeiros ou falsos são representados pelo tipo `logical`.
Este contém apenas dois valores: `TRUE` e `FALSE`.

```R
TRUE
#> [1] TRUE
FALSE
#> [1] FALSE
typeof(TRUE)
#> [1] "logical"
```

## Operadores Boolean

Há cinco operadores Boolean em R, mas apenas três são relevantes nesta fase do programa de estudos.
Os outros dois serão importantes quando trabalhares com vetores, abordados em vários conceitos posteriores.

`&&` é o operador Boolean «and».
É avaliado como `TRUE` se as expressões de *ambos* os lados de `&&` forem `TRUE`.

```R
TRUE && TRUE
#> [1] TRUE
TRUE && FALSE
#> [1] FALSE
```

`||` é o operador Boolean «or».
É avaliado como `TRUE` se uma expressão de *qualquer* dos lados de `||` for `TRUE`.

```R
TRUE || TRUE
#> [1] TRUE
FALSE || TRUE
#> [1] TRUE
```

`!` é o operador Boolean «not».
Troca os valores `TRUE` e `FALSE`.

```R
!TRUE
#> [1] FALSE
!FALSE
#> [1] TRUE
```

Para expressões mais longas e complicadas, é melhor usares parênteses para deixares clara a tua intenção.

```R
(TRUE || FALSE) && (FALSE && TRUE)
#> [1] FALSE

TRUE || FALSE && (FALSE && TRUE)
#> [1] TRUE
```
