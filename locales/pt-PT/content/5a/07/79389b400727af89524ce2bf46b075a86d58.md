# Acerca de

Além da condicional `if`, existe também a instrução `switch` para executar lógica de forma condicional. Usa-se quando é preciso comparar uma só variável com várias alternativas. Para uma variável x qualquer, a instrução switch do Haxe tem a seguinte sintaxe.

```haxe
var a = 2;

switch (a) {
  case 0:
    trace("a is 0");
  case 1:
    trace("a is 1");
  case 2:
    trace("a is 2");
  default:
    trace("a is something else");
}

// a is 2
```

O caso `default` executa-se quando nenhum dos outros casos corresponde.
