# Instruções

A tua tarefa é encontrar a disposição perfeita dos lugares à mesa.
Vais fazê-lo declarando _factos_ (coisas que são sempre verdadeiras) e _regras_ (coisas que são verdadeiras sob certas condições).

## 1. Lista as pessoas conversadoras

Define o facto `chatty` para representar as pessoas conversadoras.
O facto `chatty` recebe um único argumento: o nome em minúsculas da pessoa conversadora.

```prolog
chatty(gustavo).
true.
```

## 2. Lista quem gosta de quem

Define o facto `likes` para representar quem gosta de quem.
O facto `likes` recebe dois argumentos:

1. O nome em minúsculas da pessoa que gosta da outra
2. O nome em minúsculas da pessoa de quem se gosta

```prolog
likes(esteban, malena).
true.
```

## 3. As pessoas que gostam uma da outra formam um bom par

Define a regra `pairing` como verdadeira quando as duas pessoas gostam uma da outra.
A regra `pairing` recebe dois argumentos:

1. O nome em minúsculas da primeira pessoa
2. O nome em minúsculas da segunda pessoa

```prolog
pairing(malena, esteban).
true.
```

## 4. As pessoas conversadoras emparelham com qualquer pessoa

Define a regra `pairing` como verdadeira quando (pelo menos) uma das duas pessoas que estão a ser emparelhadas é conversadora.

```prolog
pairing(valeria, jaime).
true.
```

## 5. Verifica a disposição dos lugares

Define a regra `seating` como verdadeira quando todos os cinco pares são bons pares.

A regra `seating` recebe cinco argumentos:

1. O nome em minúsculas da primeira pessoa
2. O nome em minúsculas da segunda pessoa
3. O nome em minúsculas da terceira pessoa
4. O nome em minúsculas da quarta pessoa
5. O nome em minúsculas da quinta pessoa

Usa os factos e as regras que acabaste de definir para verificar a disposição dos lugares.

```prolog
seating(esteban, jaime, gustavo, malena, valeria).
false.
```
