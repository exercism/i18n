# Introdução

Um bloco é um conjunto de instruções e declarações agrupadas numa única unidade sintática.
Os blocos são frequentemente, mas nem sempre, definidos entre chavetas.
Os blocos podem estar aninhados dentro de funções e dentro de outros blocos.

Uma função comporta-se um pouco como um bloco.
O identificador de uma variável definida numa função não pode ser visto fora da função, tal como o identificador de uma variável definida num bloco não pode ser visto fora do bloco.
Duas variáveis em duas funções podem ter o mesmo nome, uma vez que as duas funções não se veem uma à outra, tal como duas variáveis em dois blocos podem ter o mesmo nome, uma vez que os dois blocos não se veem um ao outro.
Mas as funções e os blocos não são idênticos.
Uma função não pode estar aninhada dentro de outra função, mas um bloco pode estar aninhado dentro de outro bloco.

No exemplo seguinte, a variável `number` é definida dentro da função `main`.
A variável `flag` é definida dentro do bloco `if`, que está aninhado dentro da função `main`.
As variáveis definidas dentro de um bloco só são válidas dentro desse bloco.
Por isso, tentar compilar o código origina um erro de compilação.

```c
#include <stdio.h>

int main() {

  int number = 1;

  if (number == 1) {
      int flag = 1;
      printf("%d", flag);
  }

  // this line generates a compilation error
  // error: 'flag' undeclared (first use in this function)
  printf("%d", flag);
    
}
```

A mensagem de erro pode ser confusa, porque `flag` _é_ usada mais acima na função.
No entanto, a variável `flag` é definida dentro de um bloco dentro da função.
O bloco interior consegue "ver" a variável `number` na sua função exterior, mas a função exterior não consegue "ver" a variável `flag` definida dentro do seu bloco interior.
Quando a execução sai do bloco, a variável `flag` é automaticamente destruída e deixa de estar disponível para o programa.
A própria função `main` vê o identificador `flag` pela primeira vez na última instrução `printf`.
Se a última instrução `printf` for removida, o programa compila e imprime `1` quando é executado.
Isto acontece porque a variável `flag` é válida no bloco que contém a primeira instrução `printf`.

A partir do `C99`, as instruções `if`, `for`, `while` e `do` de uma só linha também são consideradas blocos.
No exemplo seguinte, embora `i` não esteja definida entre chavetas, só existe no bloco definido pela instrução `for` e não é visível para a função `main` exterior.

```c
#include <stdio.h>

int main() {

    for (int i = 0, j = 11; i < j; i+=2)
        printf("%d", i);

    // this line generates a compilation error
    // error: 'i' undeclared (first use in this function)
    printf("%d", i);
    
}
```

Se a última instrução `printf` for removida, o programa compila e imprime `0 2 4 6 8 10 ` quando é executado.
Algumas linguagens, como Go e Rust, são explícitas ao afirmar que as instruções condicionais e de ciclo de uma só linha constituem um bloco.
Exigem que essas instruções de uma só linha continuem a ser envolvidas por chavetas.
