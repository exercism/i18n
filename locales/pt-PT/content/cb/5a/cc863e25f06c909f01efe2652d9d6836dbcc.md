# Instruções

Como entusiasta de xadrez, queres escrever a tua própria versão do jogo.
Sim, já devem existir imensas implementações de xadrez disponíveis online, mas a tua vai ser única!

Começas por implementar um tabuleiro de xadrez.

O jogo de xadrez vai ser jogado num tabuleiro com oito casas de largura e oito casas de comprimento.
As casas são identificadas por uma letra e um número.

## 1. Define o intervalo de fileiras e colunas

O jogo vai ter de armazenar as fileiras do tabuleiro.
As fileiras são as linhas horizontais do tabuleiro e estão numeradas de 1 a 8.

O jogo também vai ter de armazenar as colunas do tabuleiro.
As colunas são as linhas verticais do tabuleiro e são identificadas pelas letras de A a H.

Define as constantes `ranks` e `files`, que armazenam o intervalo de fileiras e de colunas, respetivamente.

```swift
ranks
// Returns 1..8

files
// Returns "A".."H"
```

## 2. Verifica se a casa é válida

O jogo vai ter de verificar se uma casa é válida.
Uma casa é válida se a fileira e a coluna estiverem dentro dos intervalos das fileiras e das colunas.

Define o método `isValidSquare(rank:file:)`, que recebe os argumentos `rank`, que contém um `Int` com a fileira, e `file`, que contém uma `String` com a coluna.
O método deve devolver `true` se a fileira e a coluna estiverem dentro do intervalo das fileiras e das colunas, e devolver `false` caso contrário.

```swift
isValidSquare(rank: 1, file: "A")
// Returns true
```

## 3. Obtém a linha

O jogo vai armazenar todas as casas do tabuleiro num array unidimensional.
As casas são formadas por uma string com a fileira e a coluna, por exemplo, "1A", "8B", "4G", etc.
Para obter a linha de uma casa, o jogo vai ter de calcular o índice da primeira casa da linha.

Define o método `getRow(rank:)`, que recebe o argumento `rank`, que contém um `Int` com a fileira.
O método deve devolver um array de strings que representam as casas da linha.

```swift
let board = ["1A", "1B", "1C", "1D", "1E", "1F", "1G", "1H", "2A", ..., "8H"]
getRow(board, rank: 1)
// Returns ["1A", "1B", "1C", "1D", "1E", "1F", "1G", "1H"]
```
