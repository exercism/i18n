# Luhn: usar um trait personalizado

Antes de fazeres este exercício, provavelmente deves fazer primeiro o exercício Luhn original e o seu sucessor, «Luhn: usar o trait From».

Para obteres o exercício Luhn original, executa

```shell
exercism download --exercise=luhn --track=rust
```

Para obteres o exercício «Luhn: usar o trait From», executa

```shell
exercism download --exercise=luhn-from --track=rust
```

No exercício Luhn original só validavas strings, mas o algoritmo de Luhn também pode ser aplicado a números inteiros.

Em «Luhn: usar o trait From» implementaste um trait From, o que também exigia que criasses uma struct Luhn.

Em vez de criares uma struct só para fazer a validação, que tal validares os próprios tipos primitivos (ou seja, String, u8, etc.)?

Neste exercício vais criar e implementar um [trait](https://doc.rust-lang.org/book/ch10-02-traits.html) personalizado que faz a validação.
