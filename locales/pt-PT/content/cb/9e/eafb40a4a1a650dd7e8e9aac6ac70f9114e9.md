# Instruções

Os alunos mais atentos terão reparado que o tipo `TreasureChest` do exercício anterior não era assim tão seguro!

Se usaste a função `get_treasure`, tinhas de fornecer a palavra-passe, mas mesmo assim podias desestruturar o tipo `TreasureChest` para obter o tesouro sem precisares de saber a palavra-passe.

Vamos corrigir isso com um tipo opaco.

## 1. Define o tipo opaco `TreasureChest`.

O `TreasureChest` contém dois campos:
- Uma palavra-passe, que é uma `String`.
- Um tesouro, que é um tipo genérico.

O tipo `TreasureChest` tem de ser opaco.

## 2. Define a função `create`.

Esta função recebe dois argumentos:
- Uma palavra-passe, que é uma `String`.
- Um valor de tesouro de qualquer tipo.

A função devolve um `TreasureChest` que contém a palavra-passe e o valor.

Se a palavra-passe tiver menos de 8 carateres, a função deve devolver um erro com a mensagem `Password must be at least 8 characters long`.

## 3. Define a função `open`.

Esta função recebe dois argumentos:

- Um `TreasureChest`.
- Uma palavra-passe, que é uma `String`.

Se a palavra-passe corresponder à palavra-passe do `TreasureChest`, a função deve devolver o tesouro; caso contrário, deve devolver um erro com a mensagem `Incorrect password`.
