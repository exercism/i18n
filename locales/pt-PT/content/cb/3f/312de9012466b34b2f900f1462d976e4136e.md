# usar o operador de coalescência nula em vez de is null or empty

Em vez de usares `string.IsNullOrEmpty` para determinar se deves usar o nome predefinido, experimenta o [operador de coalescência nula](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/operators/null-coalescing-operator) para simplificares o código e tem em conta a diferença de comportamento.
