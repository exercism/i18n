# Instruções

Neste exercício vais brincar com um carro telecomandado, para o qual finalmente poupaste dinheiro suficiente para o comprar.

Os carros começam com a bateria cheia (100%). Cada vez que conduzes o carro com o comando, ele percorre 20 metros e gasta um por cento da bateria.

O carro telecomandado tem um ecrã LED vistoso que mostra duas informações:

- A distância total percorrida, apresentada como: `"Driven <METERS> meters"`.
- A carga restante da bateria, apresentada como: `"Battery at <PERCENTAGE>%"`.

Se a bateria estiver a 0%, já não consegues conduzir o carro e o ecrã da bateria mostra `"Battery empty"`.

Tens seis tarefas e cada uma delas trabalha com instâncias de carros telecomandados.

## 1. Comprar um carro telecomandado novo em folha

Implementa o método (_estático_) `JedliksToyCar.buy()` para devolver uma instância de um carro telecomandado novo em folha:

```java
JedliksToyCar car = JedliksToyCar.buy();
```

## 2. Mostrar a distância percorrida

Implementa o método `JedliksToyCar.distanceDisplay()` para devolver a distância tal como aparece no ecrã LED:

```java
JedliksToyCar car = JedliksToyCar.buy();
car.distanceDisplay();
// => "Driven 0 meters"
```

## 3. Mostrar a percentagem da bateria

Implementa o método `JedliksToyCar.batteryDisplay()` para devolver a percentagem da bateria tal como aparece no ecrã LED:

```java
JedliksToyCar car = JedliksToyCar.buy();
car.batteryDisplay();
// => "Battery at 100%"
```

## 4. Atualizar o número de metros percorridos ao conduzir

Implementa o método `JedliksToyCar.drive()` que atualiza o número de metros percorridos:

```java
JedliksToyCar car = JedliksToyCar.buy();
car.drive();
car.drive();
car.distanceDisplay();
// => "Driven 40 meters"
```

## 5. Atualizar a percentagem da bateria ao conduzir

Atualiza o método `JedliksToyCar.drive()` para atualizar a percentagem da bateria:

```java
JedliksToyCar car = JedliksToyCar.buy();
car.drive();
car.drive();
car.batteryDisplay();
// => "Battery at 98%"
```

## 6. Impedir a condução quando a bateria está descarregada

Atualiza o método `JedliksToyCar.drive()` para não aumentar a distância percorrida nem diminuir a percentagem da bateria quando a bateria está descarregada (a 0%):

```java
JedliksToyCar car = JedliksToyCar.buy();

// Drain the battery
// ...

car.distanceDisplay();
// => "Driven 2000 meters"

car.batteryDisplay();
// => "Battery empty"
```
