# Instruções

Neste exercício vais definir algumas constantes para serem usadas no funcionamento de um banco.

Tens cinco tarefas:

## 1. Representa a taxa de juro fixa de um empréstimo

Cria a constante numérica não tipada `FixedInterestRate` para guardar o valor de 5% (5/100) e depois implementa a função `GetFixedInterestRate` para a devolver:

```go
GetFixedInterestRate()
// => 0.05
```

## 2. Representa o número de dias de um ano

Cria a constante `DaysPerYear` com o tipo `int` para guardar o valor 365 e depois implementa a função `GetDaysPerYear` para a devolver:

```go
GetDaysPerYear()
// => 365
```

## 3. Representa os meses do ano

Num bloco, usa o enumerador de Go para criar doze constantes numéricas não tipadas que guardem os valores de 1 a 12 para os meses do ano.
Dá-lhes os nomes `Jan`, `Feb`, `Mar`, etc. e depois implementa a função `GetMonth` para devolver o valor de um determinado mês:

```go
GetMonth(Jan)
// => 1
```

## 4. Representa um número de conta

Cria a constante string não tipada `AccountNo` para guardar o valor XF348IJ e depois implementa a função `GetAccountNumber` para a devolver:

```go
GetAccountNumber()
// => "XF348IJ"
```
