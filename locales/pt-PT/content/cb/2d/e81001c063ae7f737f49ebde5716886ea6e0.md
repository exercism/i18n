# Anexo às instruções

## Implementar as tuas próprias operações sobre listas

O Rust tem um sistema de iteradores rico; usá-los para resolver este exercício é trivial.
Tenta resolver o exercício sem recorreres a métodos de iteradores como 
`map()`, `flatten()`, `filter()`, `count()`, `fold()`, `chain()`, `rev()` e semelhantes.
Os métodos `next()` e `next_back()` não contam.

## Evitar alocações

É possível resolver o exercício sem introduzir alocações de memória adicionais na solução.
Vê se consegues criar o teu próprio tipo de iterador em vez de criares um iterador a partir de uma coleção.
