# Anexo às instruções

## Como este exercício está estruturado para o percurso de Python

Os testes deste exercício esperam que a tua solução seja implementada em Python como uma `class` RelativeDistance.
Se ainda não conheces as `class`es em Python, o [concept:python/classes]() e a [`classes` na documentação oficial do Python][classes in python] são bons pontos de partida.


O `RelativeDistance` deve ser inicializado (_vê o [`__init__()`][init] para mais informações_) com `family_tree`, um dicionário em que as `keys` são indivíduos e os `values` são `list`s com os filhos desse indivíduo.
Também vais precisar de implementar um [método][methods] `degree_of_separation`, que devolve o grau de separação entre `person_a` e `person_b`, que são indivíduos na árvore genealógica recebida.


É-te dada uma implementação esboçada do [método especial][special-methods] `__init__`, usado para criar uma instância da classe `RelativeDistance`, assim como um esboço do método `degree_of_separation`.
Primeiro, vais precisar de personalizar o `__init__` com um atributo adequado em `self` (_a instância_) para representar os dados de `family_tree`.
Depois podes acrescentar a tua lógica ao método `degree_of_separation` para calcular o grau de separação entre `person_a` e `person_b`.


## Mensagens de exceção

Por vezes é necessário [lançar uma exceção][raising-exceptions].
Quando o fizeres, deves incluir sempre uma **mensagem de erro significativa** que indique qual é a origem do erro.
Isto torna o teu código mais legível e ajuda imenso no debugging.
Nas situações em que sabes que a origem do erro é de um determinado tipo, podes optar por lançar um dos [tipos de erro incorporados][base-error-classes], mas deves continuar a incluir uma mensagem significativa.

Este exercício em particular exige que uses a [instrução raise][raise-statement] para “lançar” vários `ValueError`s.
No primeiro cenário, vais precisar de lançar um `ValueError` quando uma ou ambas as pessoas passadas ao método `RelativeDistance.degree_of_separation` não estiverem presentes na árvore genealógica.

```python
# Example when Person A is not in the tree.
raise ValueError("Person A not in family tree.")
```

Se ambas as pessoas estiverem presentes na árvore genealógica, vais precisar de lançar um `ValueError` quando não existir uma ligação válida entre elas, tal como definido pelas regras.

```python
# Example when there are no valid connections.
raise ValueError("No connection between person A and person B.")
```

Os testes só passam se usares `raise` com o tipo de `exception` esperado e incluíres também a mensagem esperada.
Verifica com atenção os testes e os resultados esperados, porque estas instruções não são exaustivas.
