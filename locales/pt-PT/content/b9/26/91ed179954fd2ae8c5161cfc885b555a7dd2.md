# Introdução

Os comentários permitem-te deixar notas no código sem afetar a forma como este é executado.
Os comentários de uma só linha começam com `//`, e os comentários de várias linhas ficam entre `/*` e `*/`:

```go
// This is a single-line comment.

/*
This is a
multiline comment.
*/
```

Os comentários têm propósitos diferentes consoante o sítio onde aparecem.

## Comentários de código

Os comentários de código explicam por que razão algo é feito, e não o que é feito.
Usa-os quando o motivo por detrás de uma decisão não é óbvio a partir do código:

```go
results = results[1:] // skipping the header row
```

## Comentários de documentação

Os comentários de documentação ficam imediatamente antes de uma declaração, sem nenhuma linha em branco a separar o comentário da declaração.
O [`godoc`][godoc] analisa-os para gerar a documentação do pacote.
Um comentário de documentação deve ser uma frase completa que começa com o nome do identificador e termina com um ponto final.

Os comentários de pacote começam com o nome do pacote:

```go
// Package kelvin provides tools to convert temperatures to and from Kelvin.
package kelvin
```

Os comentários de função começam com o nome da função:

```go
// CelsiusFreezingTemp returns an integer value equal to the temperature at which water freezes in degrees Celsius.
func CelsiusFreezingTemp() int {
	return 0
}
```

[godoc]: https://go.dev/blog/godoc
